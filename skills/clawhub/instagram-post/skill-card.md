## Description:

Helps an agent publish or schedule Instagram photos, carousels, and Reels through PostWire, with optional cross-posting to other social platforms.

This skill is ready for commercial/non-commercial use.

## Publisher:

[perufitlife](https://clawhub.ai/user/perufitlife)

### License/Terms of Use:

MIT-0

## Use Case:

Social media managers and other users can ask an agent to prepare and, after confirmation, publish or schedule Instagram media with captions through PostWire. The skill also supports optional cross-posting to Facebook, TikTok, or YouTube Shorts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: PostWire handles uploaded media, captions, connected social accounts, and an API key.

Mitigation: Use only if you trust PostWire with this content and access; keep the API key private.

Risk: Publishing, scheduling, or cross-posting can create unintended public account activity.

Mitigation: Review the final media, caption, target platforms, and schedule, and obtain explicit confirmation before posting.
