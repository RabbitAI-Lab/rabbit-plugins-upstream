## Description:

A practical guide to starting Rust projects, understanding ownership and errors, and choosing common crates and development tools.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers use this skill when starting a Rust CLI, service, or library, resolving ownership and error-handling questions, and selecting crates, tooling, and project conventions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Copied setup examples can install tools, run remote scripts, or modify Cargo configuration.

Mitigation: Review each command and its source before executing it in your environment.

Risk: Release and build examples may use Docker or AWS, GitHub, and crates.io credentials.

Mitigation: Review access and secret handling before running these examples; use only the permissions needed.
