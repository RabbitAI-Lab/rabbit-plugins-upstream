# 八字命理分析（v2）

基于 lunar_python 的确定性排盘 + 透明可复核的启发式解读。**排盘计算全部交给脚本**，
你的工作是收集输入、跑脚本、结合命理知识解读结果。不要手工推演干支（易错），
不要虚构脚本没算的内容。

## 环境（一次性）

```bash
[ -x ~/.venvs/bazi/bin/python ] || { python3 -m venv ~/.venvs/bazi && ~/.venvs/bazi/bin/pip install lunar_python; }
```

已存在即跳过。所有命令用 `~/.venvs/bazi/bin/python` 执行，不要用系统 python3。

## 使用流程

### 1. 收集信息（缺什么问什么，一次问全）

- 出生日期：公历或农历（农历请给数字 年-月-日；闰月要说明"闰几月"）
- 出生时辰：HH:MM 或"不知道"（不知道≠不排，走三柱模式，见下）
- 性别：必问，大运顺逆取决于它
- 关注领域：综合/子女/婚姻/事业/财运/格局

### 2. 运行脚本

```bash
~/.venvs/bazi/bin/python <skill-dir>/scripts/bazi_analysis.py \
  --date 1990-05-15 --time 10:30 --gender 男 --focus 综合 --json
```

- 农历加 `--lunar`；闰月加 `--leap`（配合 --date 的月份）
- 不知时辰：**省略 --time**。脚本自动进入三柱模式：时柱置空、子女宫相关星曜不输出、
  结果带"提示"字段。解读时必须向用户转述这一局限，不得脑补时柱。
- 23:00-24:00 出生：默认 `--sect 1`（曰分早晚子时，日柱按次日）；用户明确要
  "子时不换日"口径时改 `--sect 2`，并把两种口径的差异讲给用户。
- 加 `--json` 拿到完整结构化数据（四柱/藏干/十神/地势/空亡/命宫/身宫/胎元/胎息/
  强弱得分/大运/流年），解读用人类可读模式也行，但 JSON 更不易漏信息。

### 3. 解读输出的口径

脚本已算好：四柱+纳音+地势(长生十二神)+旬空+藏干(主/余/杂气)+干支十神、
命宫/身宫/胎元/胎息、日主强弱（含得分与依据）、喜用五行、按性别的子女星/婚姻星、
大运（顺逆/起运精确到日）、动态未来 N 年流年与命局的合冲关系。

你的增值在**串起来讲**：
- 先复述盘面事实（四柱、日主、强弱结论及其依据），再讲专项星落在哪柱的含义
- 强弱与喜用是启发式（脚本输出里带得分和计数依据），如实说明"这是一个可复核的
  估算口径"，不要包装成铁口直断
- 流年"合/冲某支"要点出该支所在柱位的人事含义（年=长辈/根基，月=事业/父母宫，
  日=配偶/自身，时=子女/晚年）——三柱模式没有时柱就不谈子女宫流年

十神含义表、地支关系细则、各领域断法口诀见 `references/interpretation.md`，
按用户问题按需加载，不要一次读入。

### 4. 收尾提醒（每次必带，一句即可）

八字属传统文化模型，结果仅供娱乐参考；重大决策靠现实信息。

## 常见坑

- 用户报"农历四月廿一"：先换算成数字 4-21 传 --lunar；中文数字脚本不认。
- 用户只给了年份+生肖等模糊信息：追问完整生日，不要猜。
- 未知时辰时 `--focus 子女` 的结论置信度低（子女宫在时柱），转述时要强调。
- 农历闰月是高频错误点：1990/2020 闰四月、2023 闰二月。拿不准就先只排公历确认。
