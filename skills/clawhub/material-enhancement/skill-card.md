## Description:

Enhances clothing fabric texture in product photos using a high-resolution image of the same item as a reference.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

E-commerce image editors and sellers can improve visible fabric texture on an otherwise acceptable clothing product photo. They provide the original photo and a clear high-resolution reference of the same item, then use the generated image for review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill sends images and prompts to an external image service, and the security scan is incomplete.

Mitigation: Review the scan status, confirm the package source and intended tool access with the publisher, and send images or prompts only to providers you are comfortable using.
