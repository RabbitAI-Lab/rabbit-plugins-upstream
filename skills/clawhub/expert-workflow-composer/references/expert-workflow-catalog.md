## 任务清单与依赖拓扑

按执行链路组织的专家工作流编排任务清单，附任务间关系和元操作映射提示。

**域间逻辑流**：EWC0（任务协调）→ EWC1 / EWC2 / EWC4（专家市场发现、需求解析、灵感生成三入口并列）→ EWC3（专家编排）→ EWC5（守护校验）→ EWC6（深化）。三条典型全链路：①需求驱动——EWC0-01 → EWC1 → EWC2 → EWC3 → EWC5 → 落地；②灵感驱动——EWC0-01 → EWC4 → EWC3 → EWC5 → 落地（用户采纳灵感后）；③市场更新——EWC1（重扫）→ EWC6-02 → EWC6-03。守护三道门（EWC5-01/02/03）固定串联在编排设计与落地之间。

### 依赖拓扑摘要

以下为专家工作流编排任务的主要依赖链路，执行框架可据此自动编排管线：

#### 一、域内链路

**任务协调链路**: EWC0-01 → EWC0-02 → EWC0-03
**市场发现链路**: EWC1-01 → EWC1-02 → EWC1-03
**需求解析链路**: EWC2-01 → EWC2-02 → EWC2-03
**专家编排链路**: EWC3-01 → EWC3-02 → EWC3-03 / EWC3-04 / EWC3-05（四层落地互斥，由 EWC3-01 路由决定）
**灵感生成链路**: EWC4-01 → EWC4-02 → EWC4-03
**守护校验链路**: EWC5-01 → EWC5-02 → EWC5-03（三道门固定串联）
**深化链路**: EWC6-01；EWC6-02（市场触发，独立成线）；EWC6-03 ← EWC6-01 / EWC6-02

#### 二、跨域协同链路

**需求驱动主链路**: EWC0-01 → EWC2-01 → EWC2-02 → EWC2-03 → EWC3-01 → EWC3-02 → EWC5-01 → EWC5-02 → EWC5-03 → EWC3-03 / EWC3-04 / EWC3-05 → EWC0-03
**灵感驱动链路**: EWC0-01 → EWC4-01 → EWC4-02 → EWC4-03 → EWC3-01（用户采纳灵感后进入编排）→ EWC3-02 → EWC5 → 落地
**专家查询链路**: EWC0-01 → EWC1-01 → EWC1-02 → EWC1-03
**守护贯穿**: EWC5-01/02/03 固定位于 EWC3-02 与 EWC3-03/EWC3-04/EWC3-05 之间，任何编排方案不得绕过
**市场更新链路**: EWC1-01（重扫）→ EWC6-02 → EWC6-03

#### 三、路由链路

- EWC0-01 → EWC1-01（专家查询）
- EWC0-01 → EWC2-01（需求驱动编排）
- EWC0-01 → EWC4-01（灵感浏览）
- EWC0-01 → EWC6-01（方案迭代）
- EWC0-01 → EWC6-02（市场更新适配）
