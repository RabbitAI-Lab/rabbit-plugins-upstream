## EWC5 守护校验域范本

> **素材声明**：本范本示范中的专家与专家团以抽象角色填充（示例专家团：主理人＋成员甲（生成）、成员乙（校验）），所有角色名均为示范占位，实际编排时替换为实时检索与实际枚举结果；示范对象为"技能资产包端到端托管"编排方案（H3 路由，协作链见 EWC3 范本），依次走三道门。仅作任务示范，实际执行以实时检索与实际枚举结果为准，严禁虚构专家。

### EWC5-01 编排方案可行性校验范本

**场景**：EWC3-02 角色协作链定型后，进入第一道门。

**输入**：定稿协作链；EWC1 扫描与枚举结果；EWC2-02 匹配映射表。

**执行过程**：
1. 专家存在性核对：协作链引用的各角色均经实际核对确认存在（本示范以抽象角色填充，实际核对以实时检索与实际枚举结果为准）；
2. 能力覆盖核对：洞察/生成/校验/交付四段各有归属；
3. 衔接核对：上游产出＝下游输入（类型判定报告→资产包文件→校验报告→修复回执→最终交付物），跨成员环节均经主理人中转；
4. 层次落地核对：H3 所需成建制团队与多轮循环条件齐备；
5. 输出校验结果表。

**产出**（校验结果表示范）：

| 校验项 | 结果 | 说明 |
|--------|------|------|
| 专家存在性 | PASS | 协作链引用的各角色均经实际核对确认存在 |
| 能力覆盖 | PASS | 洞察（主理人）、生成（成员甲）、校验（成员乙）、交付（主理人）各有归属 |
| 协作链衔接 | PASS | 每环节产出＝下一环节输入；跨成员环节均标注主理人中转 |
| 层次可落地性 | PASS | H3：成建制团队承接、生成-校验-修复多轮循环可行 |

**FAIL 分支示范**：若生成段专家不可用，则"能力覆盖"FAIL——方案退回 EWC3-02 更换候选（市场候选以占位行标注"待用户在专家市场页确认"，不得虚构填充），更换后重新过门，不得带伤下传。

**校验点**：
- 任一项不通过即 FAIL，方案退回 EWC3 修改
- 修复后须重新过本道门

### EWC5-02 风险识别与确认守护范本

**场景**：第一道门 PASS 后，识别风险并取得确认。

**输入**：协作链逐步骤读写属性与调度成本；EWC2-03 可用性核对表。

**执行过程**：
1. 逐步骤扫描读写属性与调度成本：环节 2/4（资产包文件生成与修复）为写入类操作；H3 整体调度涉及多轮接力成本；
2. 风险分级（写入/隐私/成本/不可逆）；
3. 写入类操作与调度成本逐项向用户确认并留存记录；
4. 团队铁律提示（涉及专家团调度，不可省略）；
5. 可用性缺失项引导（本示范无缺失；缺失时按 EWC2-03 引导动作执行）。

**产出**（风险与确认报告示范）：

| 风险项 | 类型 | 等级 | 确认状态 |
|--------|------|------|---------|
| 资产包文件写入（环节 2/4，成员甲） | 写入 | 中 | 已确认（用户对话内明确回复"确认生成"，记录可追溯） |
| 需求信息表内容处理 | 隐私 | 低 | 仅用于本次生成，不外传 |
| 生成→校验→修复多轮接力调度成本 | 成本 | 中 | 成本预估已向用户展示，用户对话内明确回复"确认调度"（记录可追溯） |
| 资金类操作 | 资金 | — | 本方案无此类操作 |

**团队铁律提示记录**：已向用户提示——建团队仅限主理人执行；成员产出由成员本人输出，主理人严禁代写；跨成员信息流均经主理人中转。提示内容写入方案"调度与中转约定"栏。

**校验点**：
- 写入类操作必须先经用户明确确认，确认记录可追溯
- 成本预估先展示后确认，确认后方可调度
- 涉及专家团时铁律提示不可省略
- 只读优先原则在替代方案能力等价时适用

### EWC5-03 方案定稿检查范本

**场景**：第二道门 PASS 后，定稿检查。

**输入**：按 templates/workflow-plan-template.md 填充的方案；EWC5-01/02 记录；EWC3-01 路由判定。

**执行过程**：
1. 模板字段完整性检查：对照模板 1~9 节逐节核对（H3 方案第 4 节"调度与中转约定"必填）；
2. 确认记录检查：写入确认与调度成本确认记录齐备且可追溯；
3. 与 EWC3-01 路由判定一致性检查：方案编排层次与路由判定一致；
4. 依赖引用有效性检查：引用的专家、模板路径均真实存在；
5. 全部通过即定稿。

**产出**（定稿检查单示范）：

| 检查项 | 结果 | 说明 |
|--------|------|------|
| 模板字段完整 | PASS | 模板 1~9 节逐节填充；第 4 节含团队铁律遵守方式与多轮接力安排 |
| 确认记录齐备 | PASS | 写入确认（资产包文件生成）与成本确认（多轮接力调度）记录可追溯 |
| 层次路由一致 | PASS | 方案编排层次 H3 与 EWC3-01 路由判定一致 |
| 依赖引用有效 | PASS | 协作链引用的各角色均经实际核对确认存在；模板路径真实存在 |

**定稿版本号**：1.0.0（首次定稿）。三道门全 PASS，允许进入 EWC3-04 落地执行。

**校验点**：
- 检查单全 PASS 才允许进入 EWC3-03/EWC3-04/EWC3-05 落地执行
- 任一 FAIL 退回对应任务修复后复检
