## EWC2 需求解析域范本

> **素材声明**：本范本示范中的专家与专家团以抽象角色填充（示例专家团：主理人＋成员甲（生成）、成员乙（校验）），所有角色名均为示范占位，实际编排时替换为实时检索与实际枚举结果；市场候选一律以占位行标注"运行时从市场检索结果选取"，严禁虚构。仅作任务示范，实际执行以实时检索与实际枚举结果为准。

### EWC2-01 需求解析与任务建模范本

**场景**：用户提出："我要上线一个技能资产包，从需求定稿到规范校验全流程帮我做出来。"

**输入**：用户原始需求语句。

**执行过程**：
1. 需求要素提取（逐项对照六要素）；
2. 缺失要素核对：目标与产出齐备；复杂度与协作诉求齐备，无需追问（若缺失，一次集中追问，不逐条骚扰；复杂度与协作诉求缺失时默认按 H1 单专家直调处理并向用户提示该默认）；
3. 任务卡建模。

**产出**（任务卡示范）：

| 要素 | 内容 |
|------|------|
| 目标 | 产出完整技能资产包并通过规范校验 |
| 输入 | 需求信息表、规范字段表、结构范本 |
| 产出 | 技能资产包全量文件＋校验报告＋修复回执 |
| 复杂度 | 多阶段（生成→校验→修复循环） |
| 协作诉求 | 分工接力，须有门禁把关 |
| 涉及对象 | 资产生成角色、规范校验角色 |
| 备注 | 复杂度与协作诉求齐备，不适用"H1 默认" |

**校验点**：
- 目标与产出不可缺省，缺失必须追问（一次集中追问，不逐条骚扰）
- 复杂度与协作诉求缺失时默认按 H1 处理并向用户提示该默认
- 任务卡六要素齐备后方可进入 EWC2-02

### EWC2-02 需求到专家的匹配映射范本

**场景**：承接上节任务卡。

**输入**：任务卡；EWC1-02 展示结果（本地已装清单＋市场快照区）。

**执行过程**：
1. 任务卡拆解为四段能力需求：洞察（需求受理与类型判定）→生成（资产包文件生成）→校验（规范校验与门禁）→交付（整合汇编）；
2. 对照清单逐段匹配（仅映射扫描或枚举确认存在的专家与专家团）；
3. 调度路径标注；
4. 映射表输出。

**产出**（匹配映射表示范）：

| 段位 | 能力需求 | 候选专家/专家团 | 职责 | 调度路径 |
|------|---------|----------------|------|---------|
| 洞察 | 需求受理与类型判定 | 示例专家团主理人（抽象示例） | 编排调度、需求受理与类型判定 | 团队整体承接，主理人内部分工 |
| 生成 | 资产包文件生成 | 示例专家团成员甲（抽象示例） | 产出文件生成 | 经主理人中转调度 |
| 校验 | 规范校验与门禁 | 示例专家团成员乙（抽象示例） | 规范校验执行、把关与提交指引 | 经主理人中转调度 |
| 交付 | 交付汇编 | 示例专家团主理人（抽象示例） | 交付汇编 | 团队整体承接 |

**多候选并列方案**（可选）：市场侧如存在独立"资产生成"或"规范校验"类单专家，可作并列候选——（占位）运行时从市场检索结果选取（本会话检索受限，标注"待用户在专家市场页确认后补充"），严禁虚构。

**校验点**：
- 仅映射 EWC1 扫描或枚举确认存在的专家与专家团；匹配不到时如实说明并建议替代路径，严禁虚构专家或能力
- 每段调度路径必须标注，写入段进入 EWC5-02 确认流程
- 无对应专家的段位如实说明，不虚构专家

### EWC2-03 可用性与调度条件核对范本

**场景**：承接上节映射表，逐专家核对可用性与调度条件。

**输入**：匹配映射表中的专家清单；本地已装状态；平台专家检索状态。

**执行过程**：
1. 逐专家/专家团核对可用状态与调度条件；
2. 成本预估生成（按协作链环节与预期轮次估算）；
3. 缺失项标记与引导；
4. 汇总为可用性核对表，写入编排方案模板"前置与授权"栏。

**产出**（可用性核对表示范）：

| 专家/专家团 | 可用状态 | 调度条件 | 成本预估 | 缺失项 | 引导动作 |
|------------|---------|---------|---------|--------|---------|
| 示例专家团 | 抽象示例（实际状态以核对结果为准） | 团队整体承接；建团队仅限主理人；成员经主理人中转 | 预计生成→校验→修复 2~3 轮接力，环节明细随协作链展示后确认 | 无 | 不适用 |
| （占位） | 待确认 | 待确认 | 待确认 | 市场检索受限 | 请打开专家市场页确认候选专家后补充 |

**前置提示汇总**（供方案模板"前置与授权"栏引用）：专家团调度成本预估须经用户确认后方可调度；市场候选专家在检索受限时不得虚构，待用户确认。

**校验点**：
- 市场候选专家在检索受限时标注"待用户在专家市场页确认"，严禁虚构
- 专家团成员须经其主理人调度，不得绕过
- 成本预估须向用户展示并取得确认后方可调度
