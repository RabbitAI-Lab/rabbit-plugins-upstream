# 专利解读 · PatentMax

拿到一个专利号，看不懂权利要求在说什么？这个技能用大白话讲清这件专利**保护的到底是什么、还有没有效**，把独立权利要求拆成一条条「要同时满足的技术特征」，再找几件相似专利放在一起对照。

**不需要 API Key 就能用。** 专利数据来自 PatentMax 专利库，覆盖中国及美国、欧洲、日本、韩国、WIPO。

使用问题、企业采购：访问 **ip930.com**，右下角「联系客服」。

## 运行环境（必读，所有命令都适用）

部分 WorkBuddy 等环境的命令行不完整，`cat`、`ls`、`sleep`、`rm` 等可能找不到。为保证任何电脑都能跑通：

- 脚本路径一律写**绝对路径**：`$DIR/scripts/patentmax_client.py`（`$DIR` 是本技能所在目录），不要写 `cd ... && ...`（前一步失败会让后面整条静默不执行）
- `python` 找不到时依次试 `python3`、`py`；还找不到就用 WorkBuddy 自带的：先用 Glob 在 `~/.workbuddy/binaries/python/versions/` 下找到 `python.exe`，用它的完整路径。**下文所有 `python` 都按这条替换**
- 不要用 `cat` 读文件：读结果文件用 Read 工具，或用脚本的 `read` 子命令
- 检索命令几秒就返回；命令超时设为 120 秒即可

## 什么时候用

| 用户说 | 怎么做 |
| --- | --- |
| 「帮我解读一下 CN×××」「这个专利讲的是什么」 | ✅ 用 |
| 「这件专利还有效吗」「保护范围是什么」 | ✅ 用 |
| 「我的产品会不会侵犯这件专利」 | ⚠️ 只能列出要比对的技术特征，不下侵权结论 |
| 「想绕开这件专利」 | ❌ 用规避设计 |
| 「这个方向有哪些专利」 | ❌ 用专利检索或开题专利调研 |

## 第 1 步：先问清楚（最多一轮）

1. 公开号或申请号（例如 CN119846485B）；只有名称的，先按标题检索找到号码再确认
2. 最想弄清什么：讲了什么 / 保护范围 / 还有没有效 / 和我的方案像不像（不说就全讲）

用户给了号码就直接开始，不再追问。

## 第 2 步：怎么做

1. **取原文**：`brief --patent <号> --json-out b.json`，再用 `read --file b.json` 看权利要求（¥0.10）。用户关心「还有没有效、有没有转让许可」时才加 `--legal` 取法律事件流水（另收费，先说一声）。
2. **白话摘要**：三句话讲清它解决什么问题、用什么办法、带来什么效果，不用专利腔。
3. **拆独立权利要求**：把权利要求 1（和其他独立权利要求）拆成 A、B、C……一条条技术特征，每条后面用白话解释。说明「全部特征同时具备才落入保护范围」。
4. **从属权利要求要点**：一句话概括每条从属权利要求加了什么限定。
5. **法律状态和期限**：写检索结果里的法律状态；发明专利保护期自申请日起 20 年、实用新型 10 年，按申请日推算的到期年份**只作参考，以官方登记簿为准**。
6. **相似专利**：`similar --patent <号> --limit 5`，挑 3 件最接近的，一句话说差在哪。
7. **写解读卡**（见下一节）。

**费用：** 一件专利通常 ¥0.10～0.30（单篇 ¥0.10、相似专利一次、法律流水按需）；每天前 30 次检索和单篇免费（免费试用也算）。 开始前用一句话告诉用户大概花多少。

## 第 3 步：交付

写一个文件 `专利解读_<公开号>.csv`，列依次为：

| 项目 | 内容 | 出处 |
| --- | --- | --- |

- 用 Write 工具写成 UTF-8（带 BOM）的 CSV；项目依次为：名称、公开号、申请人、申请日、法律状态、到期年份（推算，仅参考）、白话摘要、独立权利要求特征 A / B / C……（每个特征一行）、从属权利要求要点、相似专利 1～3
- 「出处」写权项号（如 权1、权3）或「检索结果」；白话解释不能改变权利要求的意思

在对话里依次给出：
- 三句话白话摘要
- 独立权利要求特征清单（A、B、C……，每条一句白话）
- 法律状态和推算的到期年份（注明以官方登记簿为准）
- 3 件相似专利各一句话
- 解读卡文件的位置

`专利解读_<公开号>.csv` 最后加一行：`数据来源：PatentMax 专利库（ip930.com）`。

## 命令速查

```bash
python "$DIR/scripts/patentmax_client.py" brief --patent CN119846485B --json-out b.json          # 著录 + 权利要求，¥0.10
python "$DIR/scripts/patentmax_client.py" read --file b.json                                      # 看权利要求（不花钱）
python "$DIR/scripts/patentmax_client.py" brief --patent CN119846485B --legal --json-out bl.json # 要法律事件流水时才加 --legal（另收费）
python "$DIR/scripts/patentmax_client.py" similar --patent CN119846485B --limit 5 --json-out sim.json
```

每条命令都加 `--json-out <文件>`，再用 `read` 或 Read 工具看结果（Windows 上直接读控制台输出会乱码）。
检索式写法、全部命令和参数见 `references/tools.md`、`references/query-syntax.md`。

## 出错时

- 输出里有 `"error": true` 或退出码不是 0：这一步没跑成，**不能写成「没检索到」**；原样把 `message` 告诉用户，网络问题就原样重跑同一条命令
- 第一次运行时输出里有「[PatentMax] 已自动领取免费试用……」：把这句话原样转告用户一次
- 出现 `"free_trial": true`：免费试用用完或过期，`message` 里写着怎么办（注册 PatentMax 再送 ¥50 体验额度），原样转告

## 它不做什么

- **不下侵权结论。** 是否落入保护范围要逐条比对全部技术特征，还涉及等同原则，需要专利代理人或律师判断
- 到期年份是按申请日推算的，没算年费是否缴纳、有没有提前失效，以官方登记簿为准
- 白话解释只为帮助理解，正式引用以权利要求原文为准

**每一条专利信息都必须来自接口返回值**，不凭记忆补公开号、申请人、日期或法律状态。
