## Use Case:

SHEIN sellers and clothing e-commerce teams use this skill to prepare product image sets, detail-page visuals, and promotional graphics from product photos using the qhkit/青虎 service.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Product images are uploaded to the qhkit/青虎 service for generation.

Mitigation: Use only images approved for upload to that service and review its data-handling terms before use.

Risk: The workflow requires an API token and may install or update qhkit globally.

Mitigation: Handle the token securely; in restricted environments, review and pin the package and approve persistent installation or PATH changes first.

Risk: Submitting image generation consumes credits.

Mitigation: Check the estimate, present the settings and expected charge, and obtain explicit approval before submitting.
