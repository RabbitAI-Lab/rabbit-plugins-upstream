# Cruise Finder Tool

A powerful tool that assists users in finding the best cruises based on their preferences and requirements.

由 [CruiseSkillBridge](https://cruiseskillbridge.com) 发布到 [ClawHub](https://clawhub.ai)。

## 安装

```bash
openclaw skills install @OWNER/ola-tool-cruise-finder
```

> 将 `OWNER` 替换为 ClawHub 发布者 handle。
