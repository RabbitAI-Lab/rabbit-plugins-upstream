## Description: <br>
Searches Israel Rail train schedules with the railil CLI, including fuzzy station matching, date and time filters, and text, JSON, table, or Markdown output. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[lirantal](https://clawhub.ai/user/lirantal) <br>

### License/Terms of Use: <br>


## Use Case: <br>
External users and developers can use this skill to have an agent install and invoke the railil CLI for Israel Rail route searches, schedule lookup, and machine-readable trip results. <br>

### Deployment Geography for Use: <br>
Global; the schedule data and route queries are specific to Israel Railways. <br>

## Known Risks and Mitigations: <br>
Risk: Global npm installation adds executable code to the user's environment. <br>
Mitigation: Inspect the npm package before installation or run the CLI in a disposable or isolated environment when stricter controls are needed. <br>
