## Description:

Guides an adult learner through an unfamiliar field over about two weeks while maintaining a self-contained Markdown domain map that serves as a learning artifact, cross-session memory, and AI interface.

This skill is ready for commercial/non-commercial use.

## Publisher:

[harrylabsj](https://clawhub.ai/user/harrylabsj)

### License/Terms of Use:

MIT-0

## Use Case:

External learners use this skill to enter an unfamiliar domain, build a question-led domain map, test understanding with examples, and continue later from the saved map. Developers and agent users can use the generated map as a portable Markdown interface for continuing learning with another AI.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The Markdown domain map may contain the user's goals, background, and learning notes.

Mitigation: Review the map before sharing it with another AI or saving it in a broader personal knowledge system.

Risk: The skill may write the domain map to a path the user provides or confirms.

Mitigation: Confirm the target path, read back the saved file when possible, and treat the generated map as user-controlled content.

Risk: Some claims in a domain map may be unverifiable during a session.

Mitigation: Keep unsupported claims marked as pending verification and prefer original works, papers, university or research sources, and formal publications for high-risk or disputed facts.
