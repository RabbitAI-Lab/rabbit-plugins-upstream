## Description:

Domain Navigator guides an adult learner through an unfamiliar field and maintains a self-contained Markdown domain map for learning, cross-session continuity, and reuse with other AI systems.

This skill is ready for commercial/non-commercial use.

## Publisher:

[harrylabsj](https://clawhub.ai/user/harrylabsj)

### License/Terms of Use:

MIT-0

## Use Case:

External learners use this skill to enter a new subject area, build a question-led map, test understanding with cases, and preserve progress in a user-controlled Markdown file.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The Markdown study map can include learning goals, background, progress, and feedback that may be sensitive if shared broadly.

Mitigation: Keep the map in a controlled location, avoid unnecessary sensitive details, and redact it before pasting into third-party AI tools.
