# 橱柜柜体用哪种最好？其实爱咋咋地5.15

橱柜柜体到底哪一种好？好多业主都在问。于是利用多年的经验包括自己使用的经验，使劲寻找着答案。最终答案却是：根本没有哪种最好，最好的也就是适合自己的那种。

第一种：刨花板柜体

此刨花板并非常说的实木颗粒板，你可以叫刨花板为低级颗粒板也行，两者区别是刨花板也是木屑加胶压制，只不过粗糙了点，各种木屑混压；而颗粒板工艺稍有升级，木屑质地比较均匀，比所谓刨花板稍好，也可以称之为高级刨花板。还有一种所谓更高级的露水河，记住在刨花板打上这三个字也可以搞定。

第二种：实木颗粒板柜体

千万不要认为叫做实木颗粒板和实木有什么关系，否则你真的OUT了，这就好比我们常用的木门叫做实木复合一样，只不过里头的木条是实木，也就是说实木颗粒里头的木屑是实木的而已，这和刨花板没有什么大的区别，其工艺虽然升级，但是在如今国内利欲熏心的大环境下，有的颗粒板比过去刨花板更烂。这就和小姐和女士的区别一样，名字区别而已。

▲上图就是防潮板，其实就是在刨花板里头添加的绿色防潮颗粒，至于管用不谁用谁知道。所以我们常常把刨花板都叫做防潮板，其实还是有细微差别，以上实木颗粒和刨花板我们常常叫做防潮板其实是不对的，概念不对，其实差别很小。不过提醒，不要认为防潮板真的防潮，那就是一个模棱两可的概念而已，能经受一盆水的浸泡叫做防潮板，两盆水就能泡烂也是防潮板，防潮只是相对的，和防火板一样，有一个临界点，真正的防潮板和防火板是压根没有的，这就是我们博大的汉语的神奇魅力。

第三种：密度板柜体

▲上图可以看到密度板和刨花板的本质区别，是不是看上去密度板结实一点？不要被表面的东西迷惑。密度板也叫作纤维板，顾名思义就是用植物纤维做的，极其害怕水，所以密度板是不能用到橱柜柜体的。

第四种：实木多层板柜体

▲上图就是实木多层的板材，相对于颗粒板刨花板，稳定性要好得多，相对环保度也比较好，做橱柜柜体性价比比较高

第五种：实木板柜体

平时所说的纯实木橱柜市面极少极少，大部分商家做法都是，柜体实木多层或者刨花板，柜门做成实木指接板或者实木板，统称为实木橱柜。上图就是实木指接板像是锯齿状交叉拼起来的，做橱柜柜体有点奢侈，如果要用也不反对，代价太高，性价比不高。

纯实木有没有？所谓的纯实木就是整板，压根不可能有那么粗的树木好不好，也是拼板做出的，和指接板是有很大区别的，不过别以为纯实木做柜体是最好的，因为是纯实木更害怕潮湿变形，所以用到家具可以，橱柜还是谨慎。

第六种：不锈钢柜体

这里的不锈钢绝不是你想象的市面上普通的用不锈钢包板材那种，是从台面到柜体到柜门全部无缝焊接的纯不锈钢橱柜，造价是昂贵的，一般老百姓还真的承受了，基本配置下来地柜一米将近一万都有，当然是最最耐用结实的，就是消费不起。

▲总结：实木多层，防潮板，密度板，不锈钢，实木指接板，实木板，砖砌其实性价比最高的还是实木多层，不论从价位还是耐用度都不错。
