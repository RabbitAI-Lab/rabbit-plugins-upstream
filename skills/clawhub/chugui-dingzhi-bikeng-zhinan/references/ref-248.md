# 全屋定制选板材，随便检测，不环保10倍赔偿11.19

事情是这样的：业主咨询，某品牌出了一种新板材，还是人造板，基材基本和颗粒板类似，但是号称无醛，而且信誓旦旦告诉业主，如果安装完成检测不合格全砸或者10倍赔偿。问是否靠谱。

首先，只要是人造板就不会无醛，这是肯定的。目前全宇宙无醛的衣柜材质只有以下几个：水泥、玻璃、各类金属，或者直接和兵马俑一个材质。
所以可以判定和卖房的第三方置业一样：嘴炮而已。目的就是让你掏钱，至于后期怎么样，钱收了再说。这不就是大部分无良商家的做法吗？
再次，假如商家说的随便检测，这个检测的机构是他们指定还是消费者可以随便找？如果你辛辛苦苦检测以后，人家不承认，白做。如果他们检测，这都不用检测，肯定合格。所以这里一定要在合约里头写清楚。
检测不合格10倍赔偿？例如你定制了3万的柜子，假如真的不合格，得赔你30万。这好事你相信不？真的有这个好事，无良商家会直接拿出10万灭你的口，也不会给你赔偿。这才是事实。
最后假如一切都按照承诺的进行，好吧，你想想你家什么时候做的全屋定制，难道是毛坯房直接定制的？肯定不是，而是所有基础工程都做完了以后才定制，到了安装，你检测不合格，能说明人家污染超标吗？
很简单一个道理，你家如果铺木地板就有的扯皮了，你木地板难道没有污染？你家墙面没有污染？你家铺砖用了胶水没有污染？你家做了这么多造型难道没有用胶水？此时，你就明白了，这个压根没法界定！
有人说了大不了把所有定制搬到露天检测那就是纯甲醛放露天也检测不出来，那也是合格的好不好。
当然更聪明的人就说了：基础做完，安装定制柜子之前，先检测房子是否超标，如果合格再次安装定制，然后再次检测，如果不合格肯定是柜子的问题。好吧，事情没有这么简单，如果这么简单，商家就不会满嘴跑火车了。
你即使按照上面的做了，人家就超标了？不是，因为你检测你的基础装修不超标，并不代表污染是零，只是在合理范围之内。人家完全可以说，人家本身合格，加上你基础的零星污染后，总量肯定超标。完了，又陷入了死循环了。
此时时间静止，商家可以无限期拖死你，等你打官司，你以为真的到了法治时代了？那你也太高看时代了，一切法治脱离人治就是搞笑表演。
回到开头业主咨询的问题，到底能用不？可以用，但是前提是，你永远不要在人类社会较真。只有一个办法，控制总量。这是老百姓唯一的保命法则。
无法判断板材的环保，那就用少量的；无法判断奶粉是否有毒，那就一个礼拜更换一个品牌；无法判断牙膏的真假，那就每天早晚用不同的品牌；无法判断餐饮的卫生状况，那就每天换着店面吃；无法知道哪天自己就中奖了，那就……
