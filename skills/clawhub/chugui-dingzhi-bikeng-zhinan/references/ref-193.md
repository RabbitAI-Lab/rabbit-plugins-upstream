# 衣柜柜门，推拉和平开哪个好？9.30

直接下定义，有条件能做平开，坚决不要做推拉门。原因如下：

1.不美观，衣柜除了收纳还得有颜值，本身空间小才做推拉，导致视觉更乱
2.缩小衣柜面积，推拉门至少两扇才称之为推拉，但是两个轨道就会占据衣柜将近五分之一的面积，缩小了衣柜内部空间
3.轨道寿命短，比起普通平开门的铰链，轨道更容易出问题
4.打开门的空间很小，最多只能开启一半的空间，并不能像平开门一样全部打开
5.压根不会节省任何空间，相反必须牺牲内部空间来成就轨道的位置

那为什么那么多人做了推拉门衣柜？
1.不知道平开门的好处，使用习惯问题
2.家里空间极小，床铺挨着衣柜门，没法满足平开门

▲如图可以看出来，两扇移门怎么打开也只能打开一半的空间，而且两个轨道的厚度严重侵占了衣柜内部空间。正常衣柜进深国标是60CM，除过门板以及背板厚度，一般柜内空间实际在55CM左右；但是如果做推拉门，柜内空间几乎不到50CM
▲因为推拉门的形式，导致视觉上更高调，凸显其缺点，所以让本身很小的空间看起来更加凌乱；
▲并不是所以板材都能满足通顶定制，门板越大更容易变形，造价也高，所以就会出现下方推拉，上方平开的视觉突兀感，不协调感，对于美家装修来说，这种颜值确实不如平开门
▲如图同样是衣柜，同时是一样的空间，哪种更好看，显而易见
▲空间极窄情况下，只要能保证柜门打开，平开门与床头柜的冲突是多虑了，注意上图，床头柜跟前的柜门是断开设计的，打开上头照样挂衣服进去，而且刚好下方空间被利用，一点都不会冲突
▲只要有床头柜的空间，就有平开门的开启空间，移门衣柜压根节省不了空间，反而牺牲内部空间；至于与床头的冲突问题，太多方法可以实现了《床头柜挡衣柜门？这些办法解决》
总结：千万不要相信推拉门节省空间了，只要放床头柜，平开门就能正常做；颜值方面，任何好看的美家都不会出现推拉门衣柜；而且国产板材压根满足了通顶定制，上吊柜平开和下方柜门推拉让本身小的空间显得更难看。
