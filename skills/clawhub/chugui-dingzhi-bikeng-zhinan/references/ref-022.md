# 橱柜定制翻车实录：这8个‘隐藏雷区’，90%人已中招！

其实远远不止橱柜，家里其他定制也是一样的，大部分人除过考虑价格以外，会犯各种错误。今天重点盘点橱柜定制的错误，有的影响功能，有的影响颜值，总之一样的价格不一样的价值，基本都花了冤枉钱。01.不断加钱。这个几乎大部分定制商会做的事情，也是大部分业主只看低价和优惠，不看人而犯的错误。定制并不是定制盒子，和装修一样，一定要前期把所有需要单独加钱的事情沟通清楚，千万不要碰套餐定制，否则后期稍有变化百分百加钱。和装修类似，其实这些坑并不能怪坏人太坏，只能说自己修行不够而已。想要不被坑，唯有让自己强大，而不是诅咒坏人死绝---这个几乎不能。所以不要死记硬背什么避坑指南，没有独立的思考和清醒的个人判断认知，即使避坑指南倒背如流也是没有任何用处的。《一次性到位，橱柜哪来这么多附加费用？》02.吊柜上方多此一举挡板①第一种是定制商设计水平问题；②第二种先装吊柜后吊顶的错误导致。
厨房铝扣板吊顶，地面还是瓷砖，不会有太大误差，但是做了很宽的边线，如果不是先装橱柜后吊顶的话，就是定制商能力有限，看似有价格，但是降低价值了，虽然不影响使用。《厨房吊柜与吊顶翻车，太常见了》用生活经验都能想到，肯定是先吊顶才能安装橱柜，否则如图必须有很宽的板子满足吊顶，不知道是不是为了节省吊柜上方的吊顶钱？这样做一旦配合不好就会露出上方难看的挡板犯这种错误的基本都是自装，顺序错误，而所有散工都是按照自己方便自己来的，结果是先装橱柜连吊柜高低都不协调，等吊顶做完发现吊柜低了少做了一节，用挡板封住，这个完全就是翻车的做法。你稍微找一家有良心的装修团队，有一个是团队操作，其他不是团队操作，也会给你说清楚正确顺序，不会犯这种低级的错误。正确做法应该是先吊顶，而且吊顶高度不是随心所欲，必须是定制商给的高度，这样吊柜与吊顶才能严丝合缝，不仅仅是美观，更是定制的价值。03.有洗碗机定制水平有限上图虽然不影响使用，但是影响颜值，定制同样价格，别人家100分，这个最多80分，这就是价值所在。旁边是免拉手，给洗碗机安装拉手本身就是多此一举，而且右边为了不影响开柜门加了很宽的固定板，太浪费了。《有时候洗碗机不影响使用，但是颜值翻车了》洗碗机不论上方是固定挡板还是超薄抽屉，都必须保证拉手是相通的，而不是直接截断，看似很小的细节，但是美观和翻车就在这些细节，定制商是否有经验和有敬业精神都能看出来。为了洗碗机上方超薄抽屉却做成了翻车的结果，超薄抽屉不是东施效颦，不是牺牲把手的连续性的，这样的定制商其实不可能替你着想。洗碗机做薄抽屉，也得保证左右缝隙对齐，有免拉手，免拉手一定要拉通保证水平视觉的美观。洗碗机嵌入设计，两边露立板，定制商犯了严重的错误，虽然不影响功能，但是颜值上输得一塌糊涂如果你家橱柜只仅限于不影响功能，那定制商完全毫无价值，甚至价格并不低，多看看别人细节设计，这才是定制价值，也是装修价值。04.橱柜免拉手没有做通不要说业主了，就是一般的定制商不愿意给你着想，也不愿意提高自己的审美和工艺，几乎都会犯上图的错误，免拉手转角断开，看似细节很小，但细节才能看出真心和专业与否。橱柜定制上图才是价值，免拉手当然是拉通更好看，别小看这些小的细节，就是这些小细节叠加决定装修的价值的。05.橱柜台面一定做垫板橱柜垫板一定要做，按照目前的做法，不要后挡水以及下挂，最好的做法是木垫板，有人说木垫板不防潮，这个可以忽略，都在石材下方压的，何况橱柜柜体都是木质的，比垫板受潮几率更大。木垫板做法可以嵌入立板下方，这样石材直接放置以后，免拉手不会露出垫板的横截面，所以木垫板才是最合适的。06.亮光柜门的廉价感总听别人说亮光柜门好打理，结果做出来这种效果实在一言难尽，总感觉没有半点高级感。花了几十万，装修前自信满满，以为花钱了就会有高级感，结果证明自己自信过头了，压根不懂审美，东抄西抄，结果抄出一个全小区最丑的厨房。不论是哑光柜门还是亮光柜门都是好打理的，但是亮光柜门更不耐划，痕迹更明显，而且最致命的是这种亮光自带廉价感属性，让整体厨房更不高级装修里头任何东西最好不要大面积亮光，否则百分百没有高级感，虽然不影响功能性，但是整体颜值审美完全失败。07.舍不得镶嵌冰箱，结果越住越乱装修前花了一堆堆积建材的冤枉钱，甚至电视墙造型几千不心疼，结果厨房放冰箱不做定制，不仅丑，后期越住越乱装修前心疼钱，不考虑品质只考虑低价，入住以后发现收纳不够，然后购买一些所谓收纳神器弥补，结果是一样凌乱，后悔已经迟了厨房收纳一定是装修前规划，而不是入住了买各种盒子架子来弥补错误，不仅凌乱还得打理油烟，完全是出力不讨好。多看看别人的做法，不仅实用而且高级，这才是装修的价值所在。收纳是一个厨房整洁的前提条件，没有一定的收纳，厨房不仅凌乱，而且后期油烟更难打理，会越住越乱，越乱越不想收拾08.空间小不要做深色橱柜，没有高级感只会翻车以为自己家是豪宅是没有用的，当空间小的时候，橱柜全部黑色是必然翻车的橱柜不是不能做深色，而是要深浅搭配，满足风格和层次，同时要照顾本身空间的明亮和大小。家里空间小果断采用浅色系，但是不要用亮光柜门试图拯救光线，只会更翻车。
