# 装修避坑技能库

11个装修避坑 AI Skill，基于20年装修实战经验，内置完整知识库，开箱即用。

## 技能列表

| # | 技能名称 | 说明 |
|---|---------|------|
| 1 | 全屋定制不踩雷 | 全屋定制避坑指南，涵盖板材选择、五金配件、计价方式、合同签订等 |
| 2 | 老房改造不踩雷 | 老房/二手房改造避坑，拆除、水电、防水、结构安全全覆盖 |
| 3 | 装修合同审核 | 装修合同审查要点，识别不平等条款、隐藏增项、付款陷阱 |
| 4 | 装修报价审核 | 装修报价单审查，识别漏项、重复收费、单价陷阱 |
| 5 | 装修方案诊断 | 户型方案诊断，布局合理性、动线优化、收纳规划 |
| 6 | 装修流程不踩坑 | 装修全流程攻略，从收房到入住每个环节的关键节点 |
| 7 | 装修环保避坑 | 装修环保知识，甲醛治理、材料选择、通风方案 |
| 8 | 装修翻车急救 | 装修翻车案例与补救方案，施工错误怎么挽回 |
| 9 | 装修避坑问答 | 装修高频问答，覆盖全流程常见疑问 |
| 10 | 装修增项避雷 | 装修增项陷阱识别与防范，合同增项条款审查 |
| 11 | 装修公司避雷指南 | 装修公司筛选与避雷，资质审核、报价对比、合同风险 |

## 使用方法

### OpenClaw / Code Agent

将对应技能文件夹放入你的 Agent skills 目录，Agent 会自动识别并加载。

### Cursor / Claude / 其他支持 Skill 的 AI 工具

参考各平台文档，将技能文件夹导入。
