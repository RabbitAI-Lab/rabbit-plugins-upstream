# 所有橱柜门都在这，你要造哪样？12.2

今天系统的谈一下橱柜门板，大家装修的时候可以参考，自己需要做哪一种

▲第一种：亚克力门板，表明光滑，亮度高，无法做造型，只能是平板造型，可以选择隐形把手或者明装把手都是可以的。内部基材一般是密度板或者颗粒板，也有用实木多层做基材的，外面亚克力板子压制，通俗讲就是一种热塑性塑料而已。

▲各种颜色都有，也有仿木纹颜色，选购根据设计风格决定。

★质量有高低之分，作为普通家庭用橱柜亚克力门板其实就是选择颜色，至于质量只能看做工，亚克力的纯度你压根无法鉴定。所以选择好喜欢的颜色直接定制即可。

优点：亮度高，光滑，易打理。缺点：不耐划，不耐磕碰，质量次的亚克力可能存在变色情况，无法清理和改变。

▲第二种：模压吸塑门板，非常流行，非常火的橱柜门板了。因为其基材是密度板，所以就决定可以做任意造型，多变灵活，满足任何风格的需要，所以才能大行其道。

★质量主要看覆膜质量，质量好边缘整洁圆润，几乎覆膜和基材融为一体的；质量次的一般很明显表面粗糙，边缘位置容易脱胶，甚至有出现色差，气泡，在定制的时候发现这种情况立即更换。

优点：适应任何风格，能做出任何造型，颜色各种各样，高光哑光、纯色木色应有尽有；缺点：哑光门板时间久了容易附着油烟，需要用清洁制品定时清理，亮光门板不耐划，不耐磕碰，很容易有划痕。

▲第三种：木色门板，这里一定注意，哑光平板木色的材质各种各样都可以做到：
1.用颗粒板直接做平板，各种木色都有，无法做造型。
2.用实木多层做平板，各种颜色都有，无法做造型

以上两者，当然选择实木多层，有人说实木多层做柜门面积大容易变形，这个只要是板材面积大了都会变形，分质量高低，像橱柜门这么小，任何板材都不会变形的。

3.用模压吸塑也可以做出这种木色的效果，各种木色都有，可以做出任意造型。
4.用双饰面板同样可以做出这种木色的效果，基材密度板、刨花板、颗粒板，表面三聚氰胺板压制而成。双饰面板可以做出简单的拼框造型
5.用亚克力同样可以做出这种木色的效果

▲第三种：玻璃门板，分为实心和空心，一般空心就是钢化玻璃，木质框架或者金属框架，背后是铝箔效果。实心做法一般基材有颗粒板或者多层板，外面是普通玻璃，颜色各种各样。像上图白色的就是实心有基材的普通玻璃效果

★玻璃橱柜效果简约，搭配现代风，光泽度好，好打理，不害怕附着油烟

▲第四种：实木门板，分为实拼接纯实木和框架纯实木。不可能是整张实木，是容易变形的。购买的时候一定问清都是实木拼接，还是框架实木，中间人造板贴皮制作。当然各种人造板直接贴皮烤漆也可以做出实木效果，但是那就不是实木柜门了

▲第五种：烤漆门板，光泽度非常好，非常适合现代家庭，把手可以做到彻底隐形，容易清理，基材一般是密度板，但是不耐磨耐划

以上五种橱柜门板，经常用的就是模压和各种木色的，玻璃门板相对来说最好打理，但是做不出各种造型，各有长短。不推荐烤漆，太难伺候，作为老百姓过日子，除过美观以外还得考虑耐用实在。

至于你家用哪一种，这个需要设计师根据你家风格，厨房格局光线决定，不是随便用的。
