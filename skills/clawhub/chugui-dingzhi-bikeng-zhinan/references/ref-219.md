# 灰色系橱柜的颜值，百看不厌5.7

关于橱柜的专题非常多，大家可以移步《关于橱柜吊柜，一篇解决》，这里专题合集都有。今天看看灰色橱柜的颜值，以及别人家的搭配。

▲下深上浅非常适合厨房空间，主色调灰色系以后，地柜采用深灰色浅造型，吊柜采用白色肤感系列同样浅造型，统一搭配金色的把手；墙面是经典的小白砖，地面采用北欧花砖点缀，一个轻奢现代的厨房完美呈现--柜门直接可以采用吸塑肤感系列实现。
▲深灰色与浅灰色搭配，瓷砖采用大理石偏深色系的，这样搭配非常显档次，但是前提是你家厨房必须大，必须光线通透，否则绝对不能这样搭配，会显得压抑沉闷，而且死气沉沉。
▲接近于白色的浅灰，非常清爽，又不是纯白的呆板，搭配上小碎花的瓷砖，看上去更小资，现代，非常适合小空间厨房，不论开放还是封闭都行

▲灰色系的AB色搭配，也就是下深上浅的原则，搭配大理石浅色墙砖，平板极简，让空间清爽干净，又有视觉层次
▲高级灰的平板极简，采用拉槽式暗把手设计，空间干净清爽，搭配浅色大理石瓷砖更显现代明亮
▲深灰色平板与深色台面搭配，旁边高柜采用白色搭配，同样采用大理石瓷砖，深浅对比，有质感，也有档次，适合大空间或者开放布局的厨房

▲统一水泥灰的平板定制，深色台面布局，搭配同样灰色系的地砖，在光线明亮的前提下，显得素雅稳重
▲深灰色尽量避免上下柜同色，即使瓷砖很亮，在阴天的时候，厨房会显得压抑，让小空间更显逼仄，最好吊柜采用更浅的灰色或者直接白色，兼顾空间的各个时间段
▲很小的厨房，如果光线还可以，可以采用稍浅的灰色搭配，可以让空间更时尚稳重，也耐脏简洁

▲如果是超大空间，可以随时开放空间的，可以采用大面积浅灰色搭配，一定要用大面积白色进行中和，否则必然本末倒置，牺牲了空间感和光线感
▲下灰上白，采用浅灰色搭配，永远不会出错，不仅可以让空间有层次，而且可以让空间更清爽干净，现代感极强
▲如果厨房相对较大，而且光线非常充足，可以尝试采用统一的灰色定制，也可以加入少量简单造型来丰富一下视觉层次感
▲大面积浅色瓷砖与浅灰色橱柜是绝配，可以让层次丰富，而且不会显得压抑，根据实际光线选定灰色的深浅，大面积定制和选择色块往往会和预想出入。

▲最保险的做法是让灰色不要单独存在，采用白色进行中和，即使面积大光线暗，也不会有压抑感
▲如果不想定制出来太过于压抑而后悔，最好的办法就是直接采用下深上浅的方式，提亮空间，也能有层次感
