# 衣柜定制，到底做不做边线？8.18

首先得搞清楚什么是边线，然后才能搞明白这个东西到底有什么用。

▲如上图红圈标注的地方，就是衣柜定制里头的边线，材质与柜门材质统一，看起来更整齐。
作用：1.防止三边墙体或者地面顶面不平直，预留空隙，后期安装可以调整；2.可以类似门套安装，镶嵌位置刚好压住缝隙，减少后期衣柜与墙面的缝隙误差3.突出墙体安装，厚度与踢脚线一致，满足踢脚线的完美收口
▲如上图所示，做衣柜两边靠墙如果没有边线，墙体有误差，就会出现如图的缝隙不均匀情况，所以如果有边线可以解决此类问题
▲如上图镶嵌衣柜没有采用边线，此种做法，必须保证三面墙达到百分百笔直，否则后期衣柜安装缝隙无法处理，所以边线的做法完全可以杜绝这类问题。而且上图做法，下方踢脚线会突出墙体，形成一个突兀的断面
▲如图同样镶嵌做法，采用了三边边线，避免了墙体的误差带来的缝隙，同时边线突出隔墙安装，刚好完美遮盖假墙与衣柜的缝隙问题，同时下方踢脚线与边线完美接口
▲注意上图，边线突出墙体安装，压住缝隙，同时让踢脚线与边线完美接口，如果不突出安装，此时踢脚线就会有个断面露出
▲再看一下上图，没有边线的操作，就会导致踢脚线无法有接口，必须露出一个突兀的横截面
以上就是衣柜边线的作用，是必须做吗？当然不是，如果你的墙体能达到百分百笔直，完全不需要边线，或者说不需要这么宽的边线。
▲如上图的做法，可以没有边线，但是靠内为了柜门开启，必须裸露原有立板，同时为了对称好看，另一侧同样裸露立板，上方直接柜门与吊顶严丝合缝，是不是好看简洁多了。想要这个效果，你必须保证墙面和顶面的百分百垂直笔直
▲注意如图做法，没有边线，甚至没有露出侧板，怎么实现？其实采用柜门压立板的做法，完全可以，但是这个条件依然是保证墙体必须百分百垂直，并且柜门并不是全盖立板，而是预留1-2毫米缝隙，才能保证柜门能正常开启。但是这种做法太难了，除非两边都是石膏板新墙，上方是吊顶，地面保证笔直才行，否则很难找到这种全屋定制的操作▲注意看一下铰链的不同使用带来的效果，左图就是全盖立板做法，但是实际操作靠墙是不能完全盖的，需要预留1-2毫米缝隙，否则这个柜门是无法正常开启的。
总结：边线并不是必须，需要根据实际情况决定，像目前的精装修房子，如果不做任何处理，直接定制，能满足定制都不错了，想要墙面笔直压根不可能；毛坯房可以不？这个看你掏多钱做的工艺，大部分是不可以，除非两边新砌隔墙，上方有吊顶，而且还得保证地面是笔直没有误差的，才能实现。
