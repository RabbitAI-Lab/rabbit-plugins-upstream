# 小小踢脚线，不注意也得翻车12.2

翻车案例有专辑，大家可以翻阅《装修翻车错误专题》，今天看一下踢脚线翻车的案例，大家借鉴避免。▲如图踢脚线与内嵌衣柜，因为内嵌衣柜与墙体平齐，此时踢脚线无法收口，就会露出难看的横截面▲当然有人采用塑料的踢脚线装饰帽，如上图，但是还是突兀难看▲其实完美也简单的做法，内嵌衣柜让边线突出柜体，和门套一个道理，然后踢脚线刚好收口，而且边线突出可以遮挡衣柜与墙体的缝隙《全屋定制条子边线，为了掩盖工艺不精吗？》▲当然如果你嫌内嵌衣柜边线突出墙面难看，可以直接采用上图的踢脚线收口方式，不要让横截面露出来，也是可以的▲踢脚线的选择要考虑门套的厚度，一定不能超过门套厚度，否则就出现上图的样子，突出难看的棱角▲如图带弧边的踢脚线与门套无法完全收口，所以选择踢脚线一定要与木门相配套考虑
▲安装踢脚线需要配套墙角的收口，而非直接衔接，如图弧形阳角墙体，直角收口导致非常难看▲如图所示弧形墙体，采用裁割踢脚线的做法，减少缝隙和翻车▲木门和踢脚线一定是一家做，而且定门的时候踢脚线也得同步进行，否则颜色就不要和门接近做法，这种接近又有色差的做法，等于完全翻车了▲简单做法，踢脚线与木门颜色保持一致▲找不到颜色一致的踢脚线，也可以直接撞色，层次感更好，或者采用极窄黑色也是可以的▲跟风做了内嵌极窄金属黑色踢脚线，才知道过日子这才是智商税，平时打扫能累死人▲传统的门套线以及踢脚线都是6-8公分左右，导致视觉厚重，而且显得又矮又墩▲实际上所有订制品都是可以设计的，上图门套线与踢脚线统一4公分搭配，不仅视觉上轻巧，同时整体空间可以更加简洁▲楼梯踢脚线收口，乍看没毛病，细品这是个什么东西▲专业工人改正过来以后的样子，要舒服多了▲踢脚线阴角不裁割，直角碰上就行，这个碰到不懂的业主还以为大家都是这么做的▲正确做法如图所示，45度裁割拼接
▲木门和踢脚线分开买，安装以后，只剩下业主在懵逼状态下凌乱了。本来一块做可以对比颜色，而且省钱，但是总认为找散工分开能便宜，这个代价到底孰大孰小▲这个是踢脚线不掏钱吗？横向碰到桌腿就行，非得多此一举给桌子腿做个踢脚线，为了收口头疼，这个明显是外行的做法▲这是什么鬼？定制不拆除踢脚线，这能懒到什么地步▲正确做法定制衣柜后面是不需要踢脚线的，直接对上就可以完美收口▲如图就是装修里头协调的问题，你如果找散工，所有工种分开找，类似这种问题太多了；定制不管踢脚线，一个不管一个，导致一个和一个冲突▲瓷砖缝隙没有留均匀或者因为裁割问题，不处理墙面就会导致后期压不住《安装踢脚线，盖不住瓷砖缝隙，怪谁？》▲贪图便宜，用木地板送的PVC踢脚线，虽然颜色没有翻车，但是难看的堵头露出来了
▲实际上用实木踢脚线，和门套一致的话，直接碰门套即可
▲无踢脚线是土豪的做法，如果是刚需还是算了；你如果还用拖把拖地不要用，你如果嫌贵找散工装修不要做，你如果舍不得用防水乳胶漆不要做，否则用不了多久，你还得乖乖装上踢脚线。▲既然衣柜都不做见光板了，踢脚线就没有必要延伸了，否则白色与木色对比强烈更突兀▲学别人做内嵌踢脚线，压根没有注意白色与墙面颜色的层次处理，反而显得廉价
