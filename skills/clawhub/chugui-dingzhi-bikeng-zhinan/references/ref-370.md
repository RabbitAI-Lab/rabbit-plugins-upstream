# 厨房地柜和吊柜之间都忽视了，赶紧看看10.9

说实话大部分人都不愿意动太多心思在装修上，买房已经够了，其他不敢奢望，唯望实用装修赶紧住新房。如果你想要自己家与众不同或者有点情趣，今天就重点谈一下厨房橱柜和吊柜之间那一方天地。

◆暖暖的厨房加一点冷色调在橱柜和吊柜之间，是不是很是新颖，用板材或者黑板漆都可以有这个效果

◆加上一排和橱柜颜色相似的腰线也是可以的，总之只要喜欢

◆在没有火源的另一边加上原木效果也是可以的

◆其他地方瓷砖正铺，只在橱柜和吊柜之间菱形铺贴，效果马上见分晓

◆砖砌橱柜上面加一圈彩色瓷砖，省去了挡水，而且美观

◆加上简约腰线和淡雅的花砖也是可以有不同效果

◆配上黑色瓷砖另一种感觉，而且还很耐脏

◆彩色瓷砖和彩色油漆也可以，色彩越跳跃越能激起食欲

◆菱形拼花是做的最多也是费用最低的一种做法

◆其他正铺，吊柜下方菱形铺贴，很简单

◆也可以使用马赛克，拼出自己的风格

◆彩色瓷砖直接铺，不多花一分钱，但是可以与众不同

◆是不是很好看，后悔自家装修早了？

◆美丽的女人可能会喜欢这样的颜色

◆艺术玻璃镜面不仅美观，而且可以放大空间，尤其是好打理
