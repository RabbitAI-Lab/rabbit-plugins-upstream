# 电视墙翻车，客厅就毁了5.10

今天列举一下电视柜定制翻车事故，大家可以看看，避免自己家装修犯同样的错误

▲电视满墙柜在公共区域，把握两点永远不会错，第一弱化柜体存在感，第二颜值。但是左图明显是随心所欲了，套色颜色混乱，这一个就翻车了，第二还是大部分全屋定制的边线问题，舍不得用柜门材质，采用柜体做，导致视觉雪上加霜，更乱了
▲上图颜值就不说了，竖向的木板莫名其妙，这个好看吗？最重要的是电视墙虽然留有50管，但是电视柜竟然不留空，路由器以及电器怎么散热，信号怎么能覆盖？
▲悬空电视柜中间需要镂空，留出插座位置，以及路由器的空间，这里才能保证散热和后期信号的覆盖
▲上图同样是手机拍摄，不要看是否广角镜头，只看定制的颜值，左右很明显，左图还是错误的采用柜体作为封边，压根不考虑颜值，这就是业主不懂的时候，找全屋定制全靠运气，人好了给你设计到位，应付的话就是左图效果，但是业主不懂，以为这已经很美了
▲公平一点都用手机图比较，左图错误的用了亮光云石板柜门，而且错误的把G型把手用到了大面积的柜子上，导致亮光毫无内涵，而且金色的G型把手，让本身丑的视觉加入了土豪元素，显得更没有品位
▲左图太厚重了，悬空电视柜一般高度厚度保证在20-25公分即可，过于厚重，视觉显得不轻巧，反而压抑
▲颜色搭配混乱不堪，把手突兀，边线封板厚重，导致整体翻车
▲哪怕不做玻璃柜门也行，定制最忌对称，而且左图明显缺个照片，看得人瘆得慌
▲购买成品电视柜需要考虑空间和需求，这个宜家的明显太厚重了，这种过去淘汰的产品了，八九十年代非常火，放到今天完全脱离时代，只考虑功能不考虑颜值，不如直接超薄定制电视墙满墙柜了《客厅收纳，才是电视墙最大价值》
▲不是所有和金色有缘的都代表富贵，有时候很土豪，就像过去脖子上很粗的金链子一样，同样犯了全屋定制高调的错误
▲悬空电视柜是有一定的要求标准的，不能太厚，厚重了必然翻车，一般在20公分左右的厚度足够，视觉要轻盈很多
▲好吧，有这个钱不如做个收纳柜或者放个成品电视柜，装修紧张，非得弄个看似自己很有钱的石材电视墙，彻底翻车，越看越晦气
▲电视墙有门学别人做隐形门，其实不如务实落地，功能和后期的家具搭配，才是家里好看的重点
▲刚需真的要认清现实，不是你贴多少网红造型房子就能变豪宅，这种东施效颦反而让家里更没有品位，落地务实反而会让家里更温馨
▲这个是东施效颦的典型了，人家用岩板，你用大块瓷砖，纹路假到不如乳胶漆变色了
▲说是这个是当前流行的电视墙，花了近一万元，实在无法理解，大家品品
▲翻车没有翻车，比较就会发现差距，全屋定制真的不是定制盒子，没有那么随意
▲电视墙小的话千万不要勉强自己去提升所谓档次，简单实用才是最美的，否则适得其反
