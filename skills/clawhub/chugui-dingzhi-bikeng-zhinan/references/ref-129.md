# 简单的衣柜门，也能翻车？4.5

▲如图的翻车是生活常识问题，自己分不清现实与理想的距离。要不就是看开发商样板间这样做，非常高级，要不就是看网图这样做感觉高大上。摆拍和生活是两回事，实际生活衣服花花绿绿，能高级才怪，而且玻璃柜门还贵，得不偿失。▲这个翻车是审美的问题，怨不得别人，丑反而高调了，必然翻车。也就是你自己没有审美和经验，一定要找比你厉害的人。否则你本身没有经验也没有审美，定制商审美还不如你，那你两皆大欢喜，压根不知道什么叫做美，肯定翻车了。▲先不看柜门审美，就这露出木色的做法，就说明你被外行忽悠了，这种定制商还能存活下来，也太没有天理了。钱不一定少花，但是结果从审美到功能全部错误。床头柜位置柜门也打不开了▲全屋定制和装修一样，价值在于你找的人有起码的审美和替你着想的人品，否则你只看价格便宜，其实最终倒霉的还是自己。一个柜门一个明装把手没错，错在装这么大难看的把手，也就是柜子已经够丑了，把手是丑上加丑。至于上下木色露出以及侧面板子颜色不一样，这个是低价必然的结果。▲同样花钱，甚至丑的更高，原因在哪？这就是定制的价值，和装修价值是一回事，你以为装修就是刷墙铺地？你以为全屋定制就是定制盒子，那完蛋了▲线条宽窄不一样而且还是和柜门不同色，当然省钱的做法；把手一看就是八十年代的爷爷奶奶辈的做法，也就是你找的全屋定制完全就是盒子商，不是定制商，连一丁点审美都不具备▲妥妥的墓碑风，你能接受亮光而且灰色，谁也救不了了。什么叫做一拍即合，一个没有审美的业主碰到一个定制盒子的商家，这结果只能翻车了。▲右侧做了见光板，颜色和柜门不一样，那见光板的意义在哪？这个是做错了而已▲知道为啥会出现两种颜色吗？注意柜体是木色的，柜门是单独材质，用柜体做边线成本就低，丑那是业主的事情，这就是为什么给你这样做的原因，图纸审核那一关都没法通过的▲业主审核图纸，定制照着做，出来就是这样的，但是和人家邻居高级的比较这个必然翻车。所以一分价钱一分货是有道理的，当你当时只图低价去定制的时候，一定注定结局了。▲你们看上图，就知道为什么哪种超级烂的定制无人知晓，因为大部分业主不懂装修和定制，甚至有的不愿意耗费时间去琢磨自己家里，反而有时间琢磨价格怎么低，这样就会导致明明翻车的衣柜反而看不出任何问题。▲一定要具备简单的审美，弱化存在感，其实和做人低调一个道理。本身审美不行就不要学别人花里花哨，这就会导致丑而且高调，必然是翻车的结果了。▲如果认为装修就是材料的堆积，定制就是各种盒子的堆积，那装修必然会出现钱没有少花，价值一点没有了。▲好装修也能被定制毁掉，因为定制占有面积很大，所以装修基础再好，你找的定制商不行，装修原有的价值也荡然无存了。▲定制和装修是紧密配合协调的，互相交织的，只要你任何一方没有审美和经验支撑，全部价值归零，这就是装修找专业人以及良心人的重要性。不比不知道，一比恨不能砸掉重新装修了。▲这种做法不得不佩服定制商的胆量，也不得不佩服业主的容忍度。审美和容忍度真的是绝配。▲如图其实翻车的是把手而已，过去人不懂，以为一个柜门必须有一个把手，其实这个是多此一举，采用极简把手，两个对开门一个把手即可，弱化存在感，才是装修的价值，兼顾装修的实用和美感
