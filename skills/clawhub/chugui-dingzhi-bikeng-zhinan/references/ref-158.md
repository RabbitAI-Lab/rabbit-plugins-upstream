# 橱柜转角利用，没有那么复杂6.25

▲如上图的橱柜转角，几乎每一家都会遇到过，但是究竟怎么做能更好利用空间，其实每一家都有每一家的生活习惯，不论多么花里胡哨的设计，关键是能用到就行。今天看看都有哪些做法，最推荐第一种。

第一种：对开柜门，更换铰链

▲预算有限，刚需定制，直接做成对开门设计，这种是最实惠的，更换铰链就可以达到这种效果，只不过打开的时候，一扇门打开再打开另一扇门，开启空间最大化，转角位置可以放置一些不常用的锅具。最实惠也是老百姓装修不多花一分钱就可以解决问题的。

▲转角空间其实并不常打开，所以做成层板，就可以满足家里一些不常用锅具的收纳，完全满足功能。
第二种：转角折叠联动门
▲其实和对开门类似，只不过是朝一个方向开启的，两个门采用铰链联动开启，也是同样满足功能，只不过这种两门相连总感觉不结实的感觉。所以首推对开门的做法。
▲合理利用转角空间，省钱是肯定的，刚需房子不用多花一分钱
▲当然还有比较高端的巴士铰链，用到转角橱柜门也是可以的，但是一个门的五金便宜的都在四五百，所以不在刚需考虑范围，不推荐。
第三种：定制转角斜面橱柜（不推荐）
▲如图所示把转角位置定制成为斜面处理，利用斜面作为切菜区，此处一定注意这个是小户型为了满足基本的功能才做的，否则斜面处理会极大的浪费厨房空间，显得会更拥挤
▲如图利用斜面满足一个水槽的位置，作为小户型没有空间做水槽，满足基本功能才做，如果正常可以放水槽，坚决不要这样斜面操作，会占用本身很逼仄的厨房空间。
第四种：其他刚需不推荐的做法
▲如图所示类似的各种五金拉篮，或者角柜的做法，要不你是土豪，要不你是豪宅，有钱就行，否则不推荐。
