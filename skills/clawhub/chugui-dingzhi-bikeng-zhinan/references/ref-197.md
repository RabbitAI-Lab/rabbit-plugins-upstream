# 全屋定制之柜门，哪种更好？9.11

因为大部分都是刚需，今天不谈所谓高端产品，只谈适合老百姓的柜门产品。

一般刚需的话，柜门可以采用多层板、吸塑、PET柜门，三种完全可以满足刚需功能。

第一、吸塑柜门

吸塑柜门，基材是高密度板，可以做平板也任意造型；表面高温吸膜，可以做出亮光以及肤感系列。一般板材尺寸1220mm*2440mm。

▲如图吸塑柜门肤感平板柜门，视觉上干净质感，手感上也顺滑，无把手反弹器设计，非常有颜值

▲如图吸塑柜门带造型设计，也可以有各种颜色可以选择。

▲如图吸塑高光柜门，可以用到任何地方。用到厨房好打理，不过高光吸塑同样也有缺点，高光不耐划，很短时间侧面看都是划痕，因为高光必然让划痕更明显，有得必有失。

▲吸塑柜门的横切面，基材为高密度压缩板，所以可以采用电脑刻任意造型。

▲吸塑柜门还有一个优点，做整体百叶门，非常统一，例如橱柜天然气表的百叶，鞋柜百叶等等。这是其他材质很难达到的效果。
▲如图吸塑平板系列，天然气表的百叶门，整体材质以及颜色非常统一，视觉上更美观一些
▲如图吸塑百叶门鞋柜，可以做假百叶，也可以做真百叶透气，材质非常统一。这是其他材质无法满足的优点。
▲吸塑门颜色可以达到上千种颜色，非常丰富，几乎满足所有定制风格的需求；也可以做浴柜柜门，颜值效果都不错。
第二、多层柜门
多层柜门，就是实木多层的柜门。颜色和吸塑一样，但是没有吸塑那么种类繁多，多为木纹色，纯色很少。一般板材尺寸1220mm*2440mm。
▲卫生间浴柜门平板系列，采用多层做柜体和柜门，材质统一，人造板只要封边不被破坏，不大量泡水，是没有任何问题的；可以有各种木纹颜色，在满足自然木色的条件下，有时候比实木更有颜值，更适合搭配
▲一般在厨房木色与白色搭配的时候，地柜可以采用多层柜门，更耐磕碰，木质的纹路比吸塑能更真实自然；吊柜就可以采用纯色吸塑柜门或者PET柜门。因为多层很少有纯色系列，而且满足不了肤感的柔和和档次
▲在做衣柜木色柜门的时候，一般选择多层满足，耐磕碰，纹路比吸塑要逼真自然；但是多层柜门不宜过高，太高变形的几率就大了。
▲木色系列做柜门，而且还要造型，除非用吸塑或者实木了，多层和PET 都无法满足这个要求。
第三、PET柜门
PET柜门，基材是高密度板，可以做平板，无法做造型；可以做出亮光以及肤感系列。大家肯定听过云石柜门，其实和PET类似，只不过云石柜门高光系列，采用的是UV漆，而PET采用的是塑料，乍听很廉价，但是却很环保，因为大家天天喝的矿泉水瓶子材质就是PET，还有各种药品使用的塑料瓶子几乎都是PET。
颜色纯度较高，做柜门表面的话，可以做出亮光和柔光效果，也就是肤感效果；和云石柜门比较，环保性要稍高；云石高光柜门主要是仿石材纹路，不过随着审美提高，纯色的更易于让人接受。
PET在规格上可以做到2.7米，所以这一点是多层和吸塑无法比的，但是不推荐做这么高，变形几率太大。
▲左为吸塑柜门，右为PET柜门，两者明显的区别是封边；吸塑因为是覆膜的，在门的正面是看不到柜门四周的封边的，但是PET和多层一样，是有封边条的，所以正面都可以看到封边条的厚度以及痕迹；特别是纯白色PET，因为封边条只是与柜门颜色相近，所以非常明显。
▲只不过采用同色封边，不仔细看是看不到的。与吸塑相比较，PET耐磕碰更好，柔光效果比吸塑要略胜一筹；但是高光板的话和吸塑高光一样，不耐划痕。
▲PET柔光柜门，有封边同色封边，其实不仔细看看不到。
▲PET高光柜门，喜欢亮光的可以尝试，但是划痕是无法避免的

▲碰到PET有百叶门的时候，此时就不如吸塑那么美观了，必须用PET做框架，内嵌各种颜色的铝合金百叶，颜值上不如吸塑统一材质好看。
▲同样多层也是一样的，只能和PET一样采用框架镶嵌铝合金百叶的做法。
常用的还有金属玻璃门搭配，在全屋定制里头颜值也颇高，大家可以参考这篇《全屋定制，你家用玻璃门吗？》
