# 全屋定制不要盲目，这样做环保9.8

一、首先，有钱千万别用人造板。橡木，楠木，红木，檀木，什么名贵用什么，绝对环保。前提是你真的有钱。

二、老百姓怎么办？没有选择余地，于是只能退而求其次。所以，大部分业主问，做衣柜用什么板材。问的是人造板，而非实木。有钱用人造那真的是要钱不要命。

三、全屋定制的大概内容（每家不尽相同）：
1.进门鞋柜，包括门厅能做的储物柜。（后台回复“鞋柜”看案例）
2.餐厅餐边柜，或者酒柜，有的是储物柜镶嵌电器或者冰箱。（后台回复“餐边柜”看案例）
3.西厨橱柜吊柜等，岛台等（后台回复“西厨”看案例）
4.中厨橱柜吊柜等（后台回复“橱柜”看案例）
5.所有卧室的衣柜，书房书架书柜（后台回复“衣柜”看案例）
6.阳台储物柜等
7.过道镶嵌柜等
以上大概就是全屋定制的范围，每一家有所差别。

四、老百姓装修全屋定制，一定是在人造板里头考虑最环保的。首先记住一点，人造板里头名字带实木的，压根和实木没有任何关系。如实木颗粒板等，这是文化的问题，总认为带实木的就是实木。看事物看本质，不要被花拳绣腿迷惑。

五、老百姓定制柜子，谨记颗粒板不要用，其他生态板和多层都可以做柜子，其中一定要看到板材的本来面目，因为同样板材质量参差不齐，多钱都有。

六、定制柜子都需要问清什么问题，大家可以参考《定制人造板衣柜，一定问清这些细节8.14》

七、一定根据自己家入住人口决定做那些地方的柜子。如家有小孩，小孩尚小，和父母同住一屋。主卧不建议定制人造板柜子，先买个实木斗柜放置物品，等孩子分房睡的时候，儿童房全套成品实木家具，然后主卧再次定制人造板即可。最大范围保证孩子的空间是安全的。

八、如果新装修房子孩子已经分房睡，儿童房一定是全套实木成品家具，切记最好不要做任何人造板的柜子。其他房间可以做人造板衣柜。

九、人造板的甲醛释放在十年之久，任何方法不能加快甲醛的释放，也就是无论采取什么办法，甲醛始终在释放，所以唯一能做的就是尽量通风。别想着装修完了检测一下《装修完了检测空气意义何在？砸了重装？7.29》
