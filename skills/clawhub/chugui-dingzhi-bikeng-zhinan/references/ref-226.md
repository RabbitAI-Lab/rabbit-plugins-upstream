# 衣柜除过整体柜门，还可以怎么去做？4.6

关于全屋定制的专题，可以在《全屋定制，你想知道的都在这里》查看，需要看衣柜相关的可以在《衣柜衣帽间收纳柜》里头查看，一般后台分别回复定制以及衣柜，这两个链接是自动发送的，也可以收到。

今天看看衣柜除过普通的做法，还有那些更好看，形式上不一样的做法。

▲如图是常见衣柜的定制，就是为了放置衣物，大面积柜门即可，只是造型有所区别。

▲这个就属于个性做法，故意不通顶，漏出一部分，下方也是不挨地，形成对称格局，利用的刚好是中间的通柜门收纳衣物，下方可以作为床头柜的补充，放置随手物品，当然这个是比较个性化的做法，自己需要根据自己的喜好和使用考虑
▲如图上半部分粉色平板衣柜，下方灰色两层抽屉，可以分类收纳各种小的衣物，皮质的把手很有高级感
▲除过纯粹的衣柜以外，也可以利用衣柜镂空满足更多功能，例如留出来化妆台空间或者书桌空间，多了功能，而且视觉上更整洁美观

▲女孩房可以采用粉色平板衣柜，视觉更灵活一点，同时布局书桌，靠近书桌位置镂空刚好满足书籍的放置，一个空间三个功能都能实现
▲也可以局部镂空，专门作为随手挂衣的地方，衣柜看起来更灵活，使用更加方便
▲没有衣帽间可以专门预留一块地方，专门放置女士的包包等比较私人的物品
▲除过木质的门以外，也可以采用长虹玻璃的金属门，空间元素更多，更通透，也不会感觉凌乱
▲局部镂空可以打破平板的沉闷，让视觉上更有质感层次；同时满足了随手放置书籍展示品的功能，颜值更高
▲儿童房的话，衣柜下方可以适当镂空，可以让孩子随手放置玩具和书籍，比较方便实用
▲如果衣柜和床并排放置，完全可以舍弃床头柜，利用衣柜侧面镂空就可以满足床头柜功能，而且更美观有高级感
▲敞开设计，下方做成抽屉分类收纳，上方简单层板，装上挂衣杆，即可满足基本的衣服收纳
▲局部镂空，不为别的，就是可以随手放展示品或者物品书籍，也能视觉上更灵活
