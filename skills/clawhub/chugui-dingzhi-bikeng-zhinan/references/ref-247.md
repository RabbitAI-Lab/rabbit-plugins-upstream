# 120㎡精装修，舍得花钱随便折腾都比原来美

精装修很是尴尬，除过令人堪忧的质量以外，就是千篇一律的中式审美，丑到如此统一，算是宇宙独一份了。

那买了的人怎么办？你无法改变政策，只能去适应它，大部分人会直接买家具能住就行，买房已经压力山大了，谁又闲钱再次折腾。但是有一少部分不满意这种风格，希望通过局部的改造改变原来的现状。其实很简单，只是局部去改，该花的家具钱是一份钱都不会少的《精装修房子，入住需要做哪些改造？》

今天看看这套120平的精装修，看看怎么改造的。基础墙面以及电路改造18000元；全屋定制3万；

▲房子原有的结构，精装修结构一般都不想大的改动，所以只能在保证原有格局的基础上，进行局部墙面以及家具的布局
▲改造之前房子的原状，标配的深色木地板，屎黄色的墙面，中式枣红色的木门。难道是消费者的大众审美有问题？还是上层领导就这个水平？

▲这是装修完成后的样子。墙面全部重新打磨，改变局部颜色，采用业主比较喜欢的灰色与蓝色进行点缀，让看起来更明亮，打破原来的沉闷老旧；其他就是根据风格喜好搭配的灯具以及家具布局，包括所有新定制的收纳。
▲原始客厅区域，当时开发商的电源位置根本无法满足生活所需，在做墙面的同时进行电路的局部改造。
▲原始结构没有做改动，只是把墙面局部电源做了修改，墙面重新打磨，简单蓝灰色上下层次变色而已；为了满足业主的书籍收纳，沙发背后定制了简单的展示书柜，平时用来收纳书籍，以及业主喜欢的各种小玩意，让客厅温馨又能有家的感觉；
因为原始地面以及木门颜色就比较深，为了让空间更轻巧、明亮，沙发选择了现代的品质橘色，细腿悬空，同时搭配同款的单椅以及圆几，让空间感轻盈现代，同时采用灰色蓝色相间的地毯，大面积覆盖原有的深色木地板，减弱木地板的厚重感
▲电视墙实用考虑，不做任何花里胡哨的造型，没有购买成品电视柜，而是定制落地的电视柜，满足一部分收纳，同时靠近阳台位置悬空书柜，用功能性代替造型存在，更实惠，空间更饱满
▲考虑的现代明亮，客厅灯具选择北欧金属的分子灯，视觉能灵活，同时这种灯具的光源可以随意更换瓦数，比较实用，后期可以根据自己的要求改变空间的明暗度，这是最方便的地方；角落的黑色落地灯作为点缀，让沙发区更时尚温馨；窗帘选择了同样灰色低调的布局，选择下垂感极好的纯棉材质，视觉柔和温馨
▲沙发后面的书柜局部采用无背板布局，露出原墙的白色与蓝色，就是为了让呼吸顺畅，减弱书柜的压抑感
▲轻巧时尚的家具，书柜的灯光布局，可以让视觉更现代轻盈，打破原有的沉闷和老气
▲胡桃木与黑色搭配的圆几边几，可以满足平时随时放物需求，又不会占地方，而且视觉上非常轻巧时尚
▲餐厅空间，地方小，没有办法，又得满足餐边柜的收纳，还得容纳餐桌；靠近原来吊顶下方定制了餐边柜，采用餐桌与餐边柜一体的形式，满足就餐和收纳
▲原来的颜色过于暖色沉闷，所以定制的时候采用大面积灰色进行打破，局部浅木色与白色点缀，让视觉上更灵活，同时兼顾颜色上的过渡，不至于太过于突兀
▲用大面积白色当然更能提升亮度，但是与原来的深色木地板对比会显得突兀，所以采用了蓝灰色半截墙的涂刷，让地面到顶面形成过渡空间，还能提升层次，同时又间接打破原有非黑即黄的审美
▲灰白木色的餐边柜，左下角预留业主少量的藏酒区域，右侧打开侧板，局部灯光点缀，提升餐边柜的轻盈视觉
▲进门口的凹陷区刚好定制鞋柜，本来设计与餐边柜一体的灰白木，但是业主喜欢玻璃，想要进门更明亮，于是最终加入了一些玻璃元素，最终的样子还是能接受的
▲主卧原有的样子，同样是深色木地板，窗户还是黑色的边框，导致空间又小又压抑
▲装修后的样子，原来的结构没有改动，只能采用衣柜与床并排的做法，背景采用清新的壁布做了层次铺贴。重新接线加装了床头吊线灯，让空间更现代时尚；衣柜定制同时考虑到空间色彩的过渡性，没有直接采用纯白颜色，而是采用了灰色的与黑色把手的搭配，让整体颜色不会显得突兀凌乱
▲床尾是成品的轻巧的化妆台，同样是灰色与金色搭配，小巧不占地，同时灰色轻盈，金色的轻奢，可以给主卧提升整体档次
▲丝绒与金色搭配，天生的复古现代范，同时灰色元素又与窗帘呼应
▲这是儿童房原状，比主卧还小，一样的颜色搭配，这样的审美，真不知道祖国的花朵会怎么想自己的国度
▲墙面重新涂刷淡淡的粉色乳胶漆，为了环保本身不想做背景壁布，但是业主又嫌太单调，目前暂时不住，最终只能挑选了粉色火烈鸟的壁布，搭配了可爱的卡通床头，粉色与灰色双色窗帘搭配，有了公主房的味道
▲面积不大，还得减弱原有深色地板的感觉，整体采用灰色与粉色搭配，让空间既有合理过渡，又能充满童趣
▲空间小，只能采用1.2米的床铺，一个床头柜，定制衣柜以后，刚好预留正常的通道
▲剩余一间北向房间，作为单独书房使用，采用黑白灰的书桌书柜定制，放上灰色的布艺沙发来满足基本功能，同时大面积的灰色可以中和一下原有的地板 深色压抑；窗户采用透光竹帘，可以让光线始终明亮
▲两人位书桌刚好布局在窗户下方，光线通透，平时可以满足两人同时办公
▲书房全景，一边放了灰色的沙发床，平时偶尔来朋友，拉出来可以满足次卧的功能
▲精装修的阳台无力吐槽，封闭阳台以后，原来开发商的真石漆不想改动，这样就可以节省一笔费用，局部改动下水和电源位置，定制了洗衣柜，刚好满足洗烘机的布局以及满足一个小的洗衣池的功能，不想吊顶所以吊柜又不能做太高，上方就露出一部分了

▲客厅前后对比，其实产生的费用，除过墙面和局部电源以外，剩余就是全屋定制，家具灯具每家都必须花钱，但是在做基础改动的时候，会建议客户家具颜色以及软配的做法，这样也业主节省了一大笔设计费用

▲餐厅前后对比，该花的家具以及灯具钱，谁家都躲不过，但是我们做局改的时候，业主就可以得到免费的家具搭配指导以及软装指导，在极少的费用下可以达到整体的完美

▲主卧前后对比，卧室基础花费更少，基本就是乳胶漆变色，局部电路改造，剩余的家具以及灯具窗帘样式，都是免费指导客户完成的，非常实惠

▲儿童房前后对比，掏一个基础改造和全屋定制的费用，得到全房的免费指导，然后完成整体搭配，这在西安精装修市场，比起那些动不动一平方几百元的设计费来的更加实惠

▲书房装修前后对比，基础就是改变了墙面颜色，局部改了电源位置而已，然后局部全屋定制，购买成品的沙发床而已

▲阳台前后对比，原来的真石漆没有改动，局部改了电路和水路，然后做了定制，比较简单的做法END
