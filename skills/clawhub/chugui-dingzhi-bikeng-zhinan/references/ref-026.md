# 橱柜台面3种挡水，两种都淘汰了，自己傻傻还在做

做橱柜都有台面，除过现有非常贵的不锈钢以外，主流做法还是石英石台面。装修是与时俱进的，落后的工艺以及做法会慢慢被淘汰的，石英石台面的挡水也是一样的，有些早都淘汰，省钱而且更实用，何乐不为呢？第一、传统直角挡水<早该淘汰>放到5年前的话，没有人问一句：台面后挡水的作用是什么？为什么要累赘的做它？但其实这个是装修工艺进步的必然趋势。第一过去的瓦工工艺不行，也没有昂贵的工费支撑瓦工去做更高的工艺，装修行业还不太卷的时候，墙面是无法达到横平竖直的，而后挡水此时第一个作用就是挡住后面难看的缝隙而已。后挡水的弊端是显而易见的，当然没有新工艺的代替，谁也没有办法改变，除非就是谁家人勤快一点，否则后挡水的缝隙几乎不是黑色就是黄色，家家户户都一样，好像也没有太大问题。第二、弧形挡水只不过是另外一种进步，也属于淘汰的工艺最初的圆弧后挡水其实就是为了解决直角挡水缝隙脏的问题，但是独立收费，间接其实就是追求更大利润的结果。但圆弧处并非一体，工艺不好，会有很明显的缝隙，而且脏了以后一样的难看，并没有和直角挡水有太大区别。虽然现在有号称可以做出一体圆弧后挡水的工艺，但是意义在哪里？在于多收钱而已。把简单事情复杂化，然后故意不说更落地简单的工艺，其实就是为了多赚钱而已。后记：不论是后挡水怎么变化，但其实都属于被时代淘汰的做法。如果现在还有人纠结做直角挡水还是圆弧挡水，完全就是被割韭菜而已。第三、无挡水无下挂不仅简单而且实用装修的最大价值永远都是简单实用，而非故意复杂花里胡哨，然后用来割韭菜的做法。所以没有挡水没有下挂为什么能这么火，就是最简单落地的道理。无挡水极简干净，后期一定采用美缝处理，任何再好的玻璃胶都会变色发霉的，唯有美缝可以更长久耐变色，只要擦拭永远如新。后记：装修有更简单落地的办法，千万不要人为去搞复杂，否则不是堆积建材，基本就是为了多收割利润，所以独立思考更重要，不要再用这种已经被时代淘汰的挡水条了。
