# 隐藏柜子厚度，全屋定制看起来简单10.19

废话少说，今天说的这个隐藏柜子厚度，其实理解起来很简单，就是不要把柜子的厚度暴露在外，这样视觉上就不会有挤压感，不论你是大户型豪宅还是小户型，这种做法百试不爽。

▲人有天生丽质，其实做全屋定制也有。好的地方就可以成功了一半。
如图鞋柜位置，如果你家做鞋柜刚好是固定的凹陷区，这样的地方再好不过，完全符合隐藏柜子厚度的理念。你看不到侧面厚度，只能看到柜门以及符合美学比例的各种套色和镂空，设计起来也相对简单一点。
想要自己家的全屋定制看上去能高级一点，业主唯一的途径就是多看看人家好看的，剩下的交给设计师处理；当然如果业主的审美是上个世纪的，那全屋定制多丑你也看不出来，商家就喜欢你这样的。所以，要做到自己心里有数。

▲如果你家做鞋柜的地方天生不丽质呢？当然靠设计就可以搞定；如图所示，鞋柜完全达不到天生丽质的凹陷区，可以采用新砌墙的方式实现，这样同样可以实现只看见柜门，看不到柜体厚度的效果。
不要心疼半包的费用了，大部分人犯错并不知道自己犯错，所以逼着装修机构只能最丑的做，给你完美你舍不得一点费用，算了，丑的便宜，还能赚点。
要会算账，你新砌石膏板+轻钢龙骨那点费用，要远远低于全屋定制的费用的；所以砌墙定制面积就小，你算算到底是吃亏还是占便宜了？不仅满足颜值和隐藏柜体厚度，总价还便宜，还有颜值，你在犹豫什么？

▲客厅公共区域也是一样的，不要再说做柜子压抑了，成就一面墙，如果压根看不到柜子厚度，怎么可能压抑，充其量还是一面墙而已；关键看审美设计以及自己对审美的接受程度了。
同样一个道理，公共区域一般很少有天生的凹陷区，大部分都需要单独砌墙实现，让柜体厚度消失，就不会压抑和难看。
▲卧室也是同样道理，左图是新砌墙隐藏柜体厚度；右图是天生凹陷区，自然隐藏厚度，完美实现颜值和功能。
总结一下：隐藏厚度一是本身空间就有，第二就是创造条件满足。其实费用只有低，而并不会高，但是体现设计的价值所在以及成就刚需房基本的审美。
