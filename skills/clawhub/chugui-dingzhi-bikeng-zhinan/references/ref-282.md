# 有什么诀窍，可以找到好的全屋定制？2.1

首先得知道大的方法，全屋定制最关键的其实就两点：板材+设计。

好的板材靠什么获取？靠钱！便宜又实惠只不过是自欺欺人而已；

设计靠什么？经验！如果没有经年经验，充其量那是定制盒子，压根谈不上定制。

而大部分人找板材看什么？品牌！但是却不知道这才是错误的开始。这就和认识人一样，你看人好坏难道看人的名字吗？叫做雷锋就高大上，叫二狗就人品不行？你肯定不这样认为。但是你凭什么用一个名字去判断板材的好坏？而大部分把这种认为叫做“品牌”。殊不知已经错到根子上了。

品牌是什么？是口碑，是经年使用以后百姓得出的口碑；绝对不是昨天一文不名，今天广告铺天盖地，你叫它品牌。这不是品牌，这是广而告之。

真正好的板材只有树种材质，没有所谓品牌；真正的好人是为人处世，和叫什么名字无关；比如老家做家具用后院的老榆树，让工人现场做，这个板材叫什么品牌呢？难道不比人造的颗粒板贴个露水河高级？

人造板也是一样的，不论什么人造板都有好坏，不论贴什么牌子。同样一个牌子里头中高低档都有，商家怎么可能放过某一群体的钱不挣呢？所以看板材要看实际的东西，而不是上面贴个标签。何况全屋定制到你家，你连个标签都看不到。

那全屋定制到家里怎么能知道商家是否用的什么板材？这个很简单，安装铰链必须打孔，橱柜衣柜免不了有打孔的地方，甚至有现场裁割的板材，横截面都可以看到。

如果你找的是一个人品端正的商家，这些就不用看，人家光明正大赚钱是不会在这些地方动手脚；相反，除非是价格非常高或者非常低，给你打折优惠，这些商家明显人品不正，采用大众爱占便宜的心理的做法，让你进入人以群分的圈套而已。一旦上当受骗，你得考虑原因，而不是一味埋怨，否则不光在定制上，在任何事你还得吃亏。

定制商人品正不正从以下几点，立马能看出来：
1.你明明用的都是人造板，红口白牙说板材是E0级。这类商家是不懂常识，采用术语糊弄人而已，坚决不找。人造板没有环保的，这才是真相。

2.红口白牙说颗粒板比实木都好，大家都在用，绝对环保。注意，这个大家都在用就是心理暗示，随大流吃亏不寂寞。赚你的钱，要你全家的命，你还帮着数钱。

3.不问你家入住人口，一股脑恨不得都给你家做上人造板柜子的，这类商家不能用，看似为你好，实则是赚你的钱，间接要你家人的命而已。

4.用大部分厂家都用颗粒板来糊弄你，绝口不提颗粒板的制作原料，低成本的板材做法才是商家趋之若鹜的真相。

5.儿童房使劲让你定制人造板，这种人可以说是人渣，你如果连这个都分辨不出来，如同和别人一伙谋害你家孩子；就好比好多人无知的认为儿童房铺木地板对孩子好一样，这种无知真的是亲手葬送家人的健康。

6.二道贩子，没有自己厂子的定制商尽量不找。因为你找的就是二道贩子，中间加点钱给你做而已。动不动加个抽屉多钱，板材厚度多钱，其实这都是二道贩子而已。人员工资，店面营销这些费用都得加到中间环节

7.只会做衣柜而不做橱柜和浴柜或者洗衣柜的商家不找，要不就是二道贩子，要不就是只做赚钱的，少的不愿意去做，这种商家你找他干啥？全屋定制，顾名思义就是全屋统一定制。

从定制商的设计看好坏，还是一样，不替你着想都是害你。

1.不考虑见光板。这种设计太次，要不不懂，要不故意不说低价签单而已

2.衣柜不通顶或者不知道镶嵌做法，充其量就是定制盒子而已；

3.橱柜吊柜不挨吊顶，这是最恶劣的，用低价切入来糊弄不懂行的业主而已

以上三点逃不过低价的猫腻，就是抓住你不懂行，用低价吸引你给家里做盒子而已。
