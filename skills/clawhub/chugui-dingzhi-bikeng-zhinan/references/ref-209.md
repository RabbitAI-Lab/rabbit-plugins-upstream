# 全屋定制信口雌黄，直接淘汰6.27

关于全屋定制已经谈了很多内容了，大家可以在专题里头多看看《全屋定制，你想知道的都在这里》。今天继续给大家送一些干货，大家用生活经验去看待。

一、全屋定制重点是设计，设计才是全屋定制的灵魂，否则就是打造各种盒子；
这里的设计第一是外观设计，视觉上要与整体装修风格协调，同时要达到统一美观；
第二是内部格局使用习惯设计，这是最难点，因为千人千面，生活习惯的不同个性要求不同，对于你合适的可能对于别人是最厌恶的，所以每一家全屋定制几乎都是从零开始。
关注价格是一方面，但是撇开设计和要求只看价格，不啻是自己坑自己；如果商家只是在价格上进行诱惑，一定小心，自己把握好定力，否则吃亏的是你自己，最终还是打造各种集装箱盒子塞到家里而已
二、看板材看实质，不要看名字，你看名字和看衣服标签一个道理，不看质量只盯着标签是你在广告听过的，误认为听过的就是所谓品牌---这几乎渗透在国人的细胞里头了，不是鄙视品牌，而是不要抛开质量看品牌，就好比你地摊上买个一百元的LV一样。
就和看人一个道理，你不能从人名判断人品吧，那怎么能从品牌判断板材好坏呢？
板材大类就两种，一种人造，一种天然实木。
人造板的各种品牌是为了合理销售，只有合理注册上税才能上市销售，所以必须有标签，就是你们所谓的品牌。但实际上市面上百分之九十的板材品牌自己是不生产板材的。这就好比某米的产品一样，你难道认为他开了几百家厂子生产电器不成？当然不是，代加工然后合理合法贴上自己的注册品牌即可销售。
只有人造板才有品牌之说，天然实木没有品牌，除非加工成成品家具，实木只有树种，例如榆木、橡木、松木等。
人造板一般不需要刷漆的，内部填充各种木屑或者不知名杂物，外表大部分就是三聚氰胺饰面，造价比实木要低很多，制作成本以及对环境的破坏较低，造价使其占用市场份额的唯一长处，否则《衣柜用什么材料？有钱疯子才用人造板》
不要再问什么品牌的板材好了，好比你问：叫什么名字的人品好一样滑稽。难道叫刘德华的都是好人，叫狗蛋的都是人渣？
三、以上搞不清楚，定制的环保无从谈起，因为全靠商家吹牛，遍地的人造板都信口雌黄自己的环保。其实用生活经验都可以明白，但是大部分人接受正统教育，已经被洗脑干净了。
人造板的环保在什么时候绝对成立？1.你家只用半个平方的时候，绝对成立；2.你只看废纸一张的环保证书的时候，绝对成立
因为以上和你家都没有半毛钱关系，你家就用半个平方？肯定不是；
证书就更可笑了，就和学历一个道理，教授都有人品？有教师证就代表此人肯定为人师表？
生活已经告诉你：绝对不可能！但是是什么让你相信人造板只在理论上成立的环保证书呢？天啊，如果这能相信，我就是好人一枚，不信看证明总量才是判断环保的唯一保险的方法，而不是证书。
是药三分毒，一个道理，你把药不限量吃一下试试。人造板也是一样的，官方是单位面积环保并不是无害，而是单位面积的污染对你伤害不大，并不是没有污染。
这个单位面积的环保证书，你非得往你家几十平方的面积上自欺欺人的比较，窃喜自己用的是大品牌，却不知污染正在一点点毫无声息的侵害孩子的健康。
