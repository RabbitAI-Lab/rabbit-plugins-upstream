# 全屋定制悬空设计，不仅仅是美观7.23

在全屋定制里头，除过板材和做工以外，最最重要的就是设计了，如果没有设计的支撑，全屋定制充其量就是定制盒子而已。无比较无伤害，价格和价值的区别太明显了。《全屋定制要会设计，无对比无伤害》，今天看看定制里头的悬空技巧案例。
01
具体案例▲床头柜不要成品，采用定制悬空，和床头背景一体，不仅视觉完整统一，更轻盈时尚，下方如果能有灯光点缀，就更有颜值了。最适合空间小的卧室，可以让空间整体通透，不会有压抑感《卧室床头柜悬空，好看且不占地》
▲同理，电视柜悬空也可以减轻视觉的压抑感，让空间更具活力和通透，不至于有落地的厚重感《电视柜悬空或者隔板，颜值不错》
▲定制书桌也是一个道理，采用悬空隔板的形式，可以让视觉轻盈，空间满足功能的同时不会产生繁琐厚重之感《悬空书桌，能节省更多空间》
▲电视墙收纳柜的定制，下方木色落地电视柜与上方收纳柜，颜色上层次分明，同时悬空镂空设计，满足储物功能，还能让视觉更轻盈，减少大面积柜子的压迫感
▲如上图的石材电视柜，如果落地就是另外一个感觉了，悬空可以让视觉更具轻盈，没有空间的填充厚重，满足功能还能照顾的空间的通畅
▲过道收纳柜也是一个道理，整体落地肯定没有悬空布局轻盈，灯光的点缀更具活力。
▲浴柜也是一个道理，悬空布局视觉要轻盈多了。但是如果浴柜是在小空间，还是务实好，直接带腿落地，不会藏污纳垢，而且结实度和使用方面要比悬空好用实惠
▲飘窗柜也是一样，如果可以做成悬空布局，下方可以灯光点缀，比直接落地更让小空间时尚，视觉轻盈简洁，而且还能满足灯光的层次布局
▲卧室里头利用衣柜的定制，延伸悬空一个小的化妆台，不仅视觉延伸感，同时视觉更轻盈灵活，更具时尚高级感
▲如图儿童房悬空书桌，不仅仅是满足功能那么简单，视觉上减少空间的臃肿，更通透时尚
▲即使使用成品电视柜的时候，带细腿的悬空样式，要比直接落地更让空间轻盈时尚，同时视觉不会有压迫紧凑感
▲家里的端景或者玄关柜，能用带腿悬空不要采用直接落地，空间本身小，一定要保证视觉的轻盈极简，否则落地必然视觉有了厚重感
▲餐冰柜也是一样的道理，如果可以，下方悬空灯光点缀，与上方空间同时悬空布局，效果要更好，视觉更轻盈。如上图对于精装修房子改造后期定制非常有借鉴意义，吊顶没法动，而且吊顶太窄，就可以采用新砌隔墙，悬空餐边柜的形式，满足收纳的同时，视觉档次更高
▲如上图的西橱柜的套色做法，其实并不是为了视觉的好看，而是下方局部形成视觉悬浮感，减少大面积收纳柜的厚重感
