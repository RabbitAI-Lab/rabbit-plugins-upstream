# 橱柜台面需要外挡水吗？这是过去式了12.9

▲上图红圈画的就是挡水沿，叫做橱柜内挡水，作用就是为了封闭橱柜和墙面之间的缝隙，做到严丝合缝，防止缝隙藏污纳垢，这个内挡水几乎家家户户都有，万一台面有水也好清理，不至于有缝隙流到橱柜内部

▲外挡水很少见，就是在橱柜台面外沿做的突出来的部分

▲橱柜外沿挡水如果是不锈钢台面的话，一般直接一体成型做的突出挡水；

如果是人造石的话也是一体成型做的突出挡水；但是如果是石英石或者大理石的话，就不是一体的，是单独的挡水条用胶粘住，然后打磨，看起来是一体，其实是完全和台面是分离的

这个外挡水的作用其实和内挡水是一个道理，比如台面有积水，不至于留下来到地面，或者刚好橱柜抽屉打开，流入抽屉内部，导致木质柜体变形。

一般的话水槽如果是台上盆才会出现台面积水情况，在洗碗洗菜可能有溅水情况，如果你做的是台下盆，溅水的几率很小。外挡水几乎没有什么作用了。反过来，即使你做台上盆，台面有积水也是很少的，慢慢蔓延开来，抹布直接就处理了，也不会等到水流满地的。所以看起来外挡水就是个鸡肋。

还有现在的刚需房厨房空间都比较小，为了使空间看起来更大，一般做法是牺牲国标进深，比如，国标橱柜是60公分进深，做成55公分完全可以使用，但是视觉上厨房要大很多，如果是这样，你再做个外挡水，你家案板都放不下，甚至刚好案板压在外挡水上，此时外挡水不仅没有挡水作用，反而不方便了。

从视觉上看没有外挡水更简洁，舒服；加个外挡水牺牲整体美观性，实际生活上往往一点都不便利。所以如果你再看到别人家有外挡水，不要羡慕和跟风了，实际生活真的用不上，而且极其不美观。
