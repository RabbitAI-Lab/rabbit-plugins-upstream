# 全屋定制“留空”，你以为为了好看？装完才懂，原来是为了功能实用！

全屋定制做满墙柜为什么非得留空？如果你的留空只是为了好看，那可能是盲目跟风。其实全屋定制里头有些留空，不是为了颜值，只是为了满足更多功能而已。今天盘点一下全屋定制里头留空延伸功能的做法，大家定制的时候一定要三思后行。01.鞋柜留空是为了功能。鞋柜很明显有两个地方留空，第一最下方必备的放鞋区域；第二上方进门随手置物区。装修的目的就是为了减少家务，让人变“懒”，其实就是家的方便之道。但是有人就是为了考验人性，给鞋柜不留空，结果自己没有这个生活习惯，进门鞋子全部堆积随意放置，反而更乱。鞋柜下方留空是必备做法，并不是随意去做，留空的多少需要根据入住人口决定，太多多余留空可能会导致平时积灰，反而适得其反。家里鞋柜小，但是入住人多的时候，就可以考虑下放两层镂空，来满足更多鞋子的进门收纳。鞋柜最下方踢脚抽不要盲目跟风，这个是鞋柜深度过深，例如60cm深度的时候，很难放鞋和取鞋，才做的设计；正常深度的鞋柜不要模仿，反而鸡肋。鞋柜中间留空不是为了好看，否则可能沦为家里的杂物堆积区。现代家庭大部分都是智能锁，压根都不需要钥匙；而进门的包包又大又乱，最好收纳进柜子内部，所以进门的留空刚需是为了开关以及门禁的放置，顺便加上灯光照明和营造氛围用的。02.餐边柜留空不是为了颜值。餐边柜留空都是为了功能，不是为了装饰，否则可能会堆积杂物。太多没有目的性的留空，只会后期堆积杂物，这个是人惰性的问题，尽量不要去挑战人性。少量功能性留白满足必备电器的放置即可，同时满足就餐时候随手置物。极小空间餐边柜下放留空，为了隐藏占用过道的餐桌椅的做法。还有一种留空，是为了嵌入餐桌，满足小空间过道的最大化。内部不做隔板的留空，是为了收纳家里人多的时候的备用凳『与其费心给丑陋的备用凳找“家”，不如让其化身家居风景线，才是收纳的境界』电器柜的留空以及抽拉板设计，是为了方便电器的更好使用。03.满墙柜留空也有目的性。客厅满墙柜目的就是收纳和弱化存在感，切不可大面积留空，反而凌乱和堆积杂物。高估了自己的收拾能力以及满脑子都是美好生活的憧憬。脱离了人性真实的烟火气，最终只能是堆积杂物。满墙柜如果只是为了收纳杂物，不做任何留白是最好的做法，弱化存在感，家里始终保持整洁干净。家里有小孩，下方局部留空只是为了孩子小收纳玩具方便，大一点收纳书籍方便而已。局部少量留空只是为了满足路由器信号以及放置音响使用。电视为了留空黑色只是为了视觉上让比例协调，而下方的留空是为了满足辅助光，营造氛围感的。04.阳台柜留空也有目的性。阳台也是一样的，如果没有目的性的留空只会让空间更乱。阳台开放留空太多，必然会乱，怎么做都不会好看和整齐。如果只为了满足收纳，不留空是最好的，平板柜门弱化存在感，空间更能整洁干净。即使零镶嵌洗烘机，下方留空也只是为了满足扫地机器人进出，尽量保留空间整洁干净。即使侧面隐藏晾衣服，也可以采用隐藏设计，保证空间的整洁。『有洗烘机，隐藏晾衣更清爽！』05.浴柜留空的目的性。浴柜下方留空，就是为了满足扫地机器人的出入以及可以收纳各种脸盆。镜柜上下留空，第一为了满足龙头安装，第二实现隐藏灯带满足照明以及见光不见灯的氛围感。带化妆台功能的浴柜，下方留空专门为了隐藏化妆凳以及放腿。镜柜下方内部留空，是为了方便收纳吹风机以及隐藏电动牙刷，也方便充电。浴柜靠近马桶，侧面留空刚好满足随手置物的功能。06.卧室定制的留空功能衣柜侧面留空，第一实现开关位置最大化衣柜定制；第二实现了次净衣的收纳。儿童房衣柜的留空，孩子小一点收纳玩具，大一点收纳书籍。卧室门背后的留空，加上挂衣杆，用来收纳次净衣放置脏衣篮的地方。衣柜侧面靠床头，局部留空，是为了实现一个床头柜的功能。床头靠衣柜，一部分留空同样是为了兼顾床头柜的功能。衣柜靠近窗户留空，满足了挂机功能以及窗帘的功能。07.橱柜留空功能化厨房收纳充足的前提下，地柜留空放置小推车，专门作为临时放菜的位置。厨房层高过高的时候，吊柜可以分段设计，靠近灶具局部留空，满足随手拿取调料功能。厨房高柜留空抽拉板设计，是为了满足电器不用移动更方便使用。靠近灶具利用高柜留空，实现随手拿取调料的方便。
