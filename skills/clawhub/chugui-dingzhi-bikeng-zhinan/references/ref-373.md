# 为什么好看的橱柜，装到自己家丑爆了？8.27

我想好多业主都有如此疑问：为什么当初看的那么漂亮的橱柜放到自己家怎么这么老土？甚至于不堪？

像极了我们当初的买房考察，我们及其愚蠢的穿梭于开发商精心设计的样板间里头，全家老少在样板间驻足，羡慕，感叹，原地憧憬自己买了这里的房子该多么幸福。

可是当我们真的买房装修后才发现，为什么自己的户型和样板间一模一样，就是装不出人家的感觉。

像极了我们穿梭于装修公司精心设置好的样板间了，羡慕人家的家具搭配，羡慕人家的灯光效果，嫉妒人家的豪华，可从来不想那里头砸了多少金钱。

像极了我们装修的时候看着装修公司精心做的效果图，却痴心妄想装出来和效果图一模一样。

像极了我们相亲的时候，拿着异性经过精心处理的照片而想入非非。可是真实的世界我们往往视而不见，或者是我们故意视而不见

成人世界的自欺欺人像我们赖以生存的空气，我们时刻都在上瘾般消磨时光

商家的橱柜展厅最少都在二三十平方，你家多少？6平？十几平？还是只有四五平？这就好比凤姐看见范冰冰穿旗袍好看，自己也买来穿是一样的效果。

你见过展厅有烟道吗？可咱家有。
你见过展厅有管道吗？可咱家有。
你见过展厅有集成吊顶吗？可咱家有。
你见过展厅有天然气丑陋的表吗？可咱家有。
展厅的脚下是一个厅，我们的脚下却只是立足而已。

希望以后业主在买任何东西的时候，一定要想一想自己的实际情况，不要再被那么幼稚的营销或者表面所利用。
