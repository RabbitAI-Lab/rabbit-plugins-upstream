# 衣柜与踢脚线，各种收口方式12.3

踢脚线与衣柜收口是非常细节的问题，在大的装修里头，这些是最容易忽视的地方，实际做出来不注意往往就会出现遗憾或者翻车。第一、踢脚线与边线的配合▲定制衣柜后面不需要踢脚线，这个是铁律，一定谨记。如果是精装修定制，一定拆除踢脚线以及石膏线，否则没法施工和安装，要不就会导致翻车。如图所示，衣柜旁边有踢脚线，一定注意踢脚线的厚度，采用衣柜边线满足踢脚线收口问题▲如上图所示，书桌地柜右边一定要有边线，否则踢脚线刚好顶住柜门，导致后期柜门无法打开
▲如图，衣柜有个18的侧板，其实一是为了衣柜更完整，第二就是为了踢脚线刚好碰到侧板收口，此时如果踢脚线厚度厚于侧板的话，就会露出难看的横截面，所以一定是踢脚线薄于侧板厚度，或者一样的厚度▲如果不想加边线，此时柜下一定要做挡板，而且挡板高度一定高于踢脚线，这样踢脚线刚好与挡板收口，而不会影响上方柜门或者抽屉的开启▲如图不想做下方挡板，就必须做左侧立板，否则踢脚线就会导致柜门无法打开第二、踢脚线与衣柜的垂直收口▲如图踢脚线与衣柜侧面垂直收口，毛坯房装完衣柜，然后装木门和踢脚线，一次就可以搞定▲如图就是一个独立衣柜定制，两边踢脚线收口的完美演示；右侧不会翻车，注意左侧一定要有一个单独的侧板与踢脚线同厚度或者比踢脚线厚，这样才能保证收口完美，视觉整洁。千万别只图颜值，非得要柜门挨着墙体，此时下方必须有挡板收口，否则柜门无法打开▲如图所示，如果不要左侧挨墙的立板，柜门紧靠墙体，衣柜下方必须有挡板高于踢脚线，这样才能保证踢脚线与挡板的收口，而不会影响柜门的开启▲当然你如果感觉踢脚线收口硬碰不好看，也可以定制的时候下方做衣柜挡板，这样踢脚线可以围绕四周，但是总感觉多此一举▲如图做法就是错误的，第一定制衣柜后面是不需要踢脚线的，会影响衣柜安装，否则就出现这种难看的裁割，其实不要踢脚线节省费用，踢脚线直接碰到衣柜侧面即可收口▲如图书桌下方没有背板，要装踢脚线，只需要横向一字安装即可，不需要绕桌腿，否则如上图，没有收口了▲如上图所示，直接背后一字踢脚线安装即可，就可以完美收口▲实际定制推荐书桌背后做背板，而且悬空做法，这里是18的板子，第一承重，第二防止后期使用踢脏墙面，这个才是推荐的做法，压根不需要踢脚线《书桌定制，这个几乎被大部分人忽视了》第三、内嵌衣柜的踢脚线收口方式▲如果是内嵌衣柜，建议做边线，第一可以压住衣柜与墙体的缝隙，第二完美实现踢脚线与边线的收口，此时一定注意，边线厚度要厚于踢脚线▲有人采用如图的做法，不推荐，这个就是加一个立板高于墙体，虽然实现了踢脚线的收口，但是立板与墙体难看的缝隙后期用玻璃胶，太难看，如果缝隙误差大的话一定会翻车的▲如图有隔墙的镶嵌衣柜，上图做法是柜体突出隔墙一个踢脚线的厚度，此时刚好满足踢脚线的收口▲如图所示，为了避免踢脚线收口问题，直接定制柜子下方采用挡板，这样踢脚线完全不存在收口问题，围绕一周，当然浪费一踢脚线而已，但是当衣柜颜色与踢脚线对比强烈的时候，就有损颜值了▲如图所示，同样是内嵌衣柜，但是衣柜与隔墙平齐而且是一门到底，此时踢脚线只能硬收口，做不好就会露出难看的横截面▲当然如果工艺稍好一点如上图所示，收口能美观一点，但是避免不了高度的突兀感▲如图是另一种做法，隔墙突出衣柜，此时踢脚线拐角刚好与衣柜侧板收口，也是一种办法，但是隔墙与衣柜的突兀感又比较强烈了第四、不镶嵌，衣柜一边与墙体平齐▲如图衣柜不做内嵌，就会出现衣柜边缘与墙体平齐，此时踢脚线一种做法如图，直接到衣柜跟前强行停止收口即可▲第二种做法如上图，踢脚线延伸一体和柜体平齐，然后收口，此时如果柜体和踢脚线颜色一样或者相近是最完美的▲如图同样是柜体一侧与墙体平齐，此时木色踢脚线延伸收口，但是不一样的颜色对比，总感觉别扭▲如图同样做了延伸，但是白色与深木色的强烈对比更不好看，此时宁愿不延伸，到墙体位置直接收口即可
