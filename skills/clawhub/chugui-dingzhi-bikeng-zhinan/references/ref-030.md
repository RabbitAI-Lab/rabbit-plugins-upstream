# 衣柜定制总踩坑？记好这3点，保你万无一失！

其实衣柜定制前人已经给过太多经验了，最重要的其实就三点，第一少做层板，不要太多叠衣服；第二必须有抽屉，内衣分类收纳；第三衣服只是用来挂的，否则衣柜里头必乱。今天盘点一下，这三点的具体做法，大家借鉴参考一下。第一、尽量少做层板，减少衣服的叠放。定制不要贪心，大部分定制如果投影面积计价，千万不要以为多做隔板就能占便宜，入住就会发现收纳衣物叠放，衣服永远皱巴巴，取衣服一件全部拉乱，非常反人类的做法。衣柜被塞的满满当当的，衣服一拿就乱，总是很难找到想穿的那件，收纳用品也买了不少，但总是治标不治本，而且层板如果是固定的，压根无法整改。每次打开衣柜，各种衣服就从头顶落下来。一股无名的火就从天灵盖直冲脑门。层板多，衣服都堆叠在一起，拿也不好拿，放也不好放，收拾也总收不利索， 看着就烦躁，莫名的怒火就蹭蹭的上来层板太多采用收纳盒，不就是自欺欺人吗？只是把凌乱摆整齐，关上门一个样子，取衣服的时候一样的凌乱，除非收纳盒收纳床品。衣柜做局部层板，是专门为了收纳床品，分类收纳，这样的层板才是有价值的。第二、衣柜肯定少不了抽屉。不论衣柜多大，最起码一个衣柜做两个抽屉，满足内衣和袜子的分类收纳《衣柜少了抽屉，哪能算定制》衣柜做了外置大抽屉，三个600深、900宽的大抽屉。衣柜其余地方都做的挂衣区，没有叠放区。衣柜千万不要做内抽，这个是反人类做法，一点生活经验都没有；内抽每次拿东西需要打开柜门，繁琐，而且有铰链位置，内抽就会导致缩小，完全是出力不讨好的做法。衣柜外抽的做法不仅仅满足了分类收纳，同时外抽可以间接缩短柜门的大小，防止超大柜门导致变形问题。第三、衣柜大部分功能是挂衣服的叠被区预留了500mm的高度，收纳过季被褥及不常用物品。 挂衣区预留了950mm的高度，放置外套，衬衫，卫衣等高度亲测够够的，底下还有剩余空间。裤挂区预留了800mm的高度，至少能挂30条以上，做的横杆衣杆，相比较于抽拉裤架更结实耐用一些。衣柜没有做格子，衣服全部挂起来。根据家里的实际需要划分区域规划，实在空间小行李箱可以舍弃专用位置。挂衣区：空间允许的情况下，挂衣区当然是越多越好啦！可以根据自家需要选择短/中长/长的不同尺寸。衣柜打开，主要以挂衣区为主，懒人真的很讨厌叠衣服，生活也变得更加简单舒适后记：衣柜把握以上三点，基本功能上不会出问题，不至于入住发现各种遗憾的弊端。
