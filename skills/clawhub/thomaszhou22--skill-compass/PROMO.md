## Hacker News

**Title:**
```
Show HN: Diagnostic tool that fixes AI agent skills so they trigger reliably
```

**URL:** `https://github.com/Thomaszhou22/skill-compass`

**Text:**
```
Built a diagnostic tool for AI agent skills that identifies why skills aren't triggering and provides fixes.

Common problems it catches:
- Vague descriptions that don't match user intent
- Missing trigger keywords
- Conflicts between multiple skills
- Description too long (token budget issues)
- Incorrect YAML frontmatter

Works with OpenClaw, Claude Code, agentskills.io, and any platform using SKILL.md format.

The tool analyzes your skill descriptions and provides specific recommendations to improve trigger accuracy.

Open source, MIT licensed. Useful if you're building custom skills for AI agents and wondering why they don't activate when expected.
```

Been building custom skills for AI agents and kept running into the same problem: skills wouldn't trigger when they should.

Built Skill Compass to diagnose and fix this. It analyzes skill descriptions and identifies:
