## Description:

AI game asset generation and game development powered by CellCog for character-consistent art, sprites, tilesets, music, UI, 3D models, GDDs, level design, and game prototypes from a single prompt.

This skill is ready for commercial/non-commercial use.

## Publisher:

[cellcog](https://clawhub.ai/user/cellcog)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and game teams use this skill to request cohesive game assets, design documents, interface elements, 3D models, and prototypes through CellCog. It is suited for generating production-oriented asset concepts and files from detailed game briefs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and any intentionally provided files are sent to CellCog as an external service.

Mitigation: Do not include secrets, credentials, unreleased confidential assets, proprietary code, or restricted content unless project policy permits CellCog to process it.

Risk: Generated game assets and prototypes may require review before use in a shipped game.

Mitigation: Review generated outputs for accuracy, suitability, licensing expectations, and project standards before integrating them into production builds.
