## Description:

Create, search, and manage Bear notes via grizzly CLI.

This skill is ready for commercial/non-commercial use.

## Use Case:

People using Bear on macOS can use this skill to create, read, append to, and search notes, and to list tags through the grizzly CLI. Bear must be running, and some operations require a Bear API token.
