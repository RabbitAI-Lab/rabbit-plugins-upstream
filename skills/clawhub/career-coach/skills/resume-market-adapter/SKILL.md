# Resume Market Adapter — 双轨简历精修器

> 同一份真实经历，按目标市场（中国 / 国际）生成两套结构、关键词、隐私策略不同的简历，而不是把英文简历机翻成中文、或反之。

## 能力

- 建立 **证据账本（evidence ledger）**：把经历拆成「职责 / 技术动作 / 结果 / 影响范围 / 证据来源 / 可公开程度」六字段，作为所有版本的唯一事实源
- **中国市场适配**：中文结构、信息密度、职级与业务结果表达、面向中文 JD 与国内招聘平台的关键词
- **国际市场适配**：Resume 与 CV 的边界、ATS 关键词映射、行动动词、一页/两页判断、LinkedIn/GitHub 一致性
- **地区化隐私风险提示**：对中国、美国、英国、欧盟市场分别提示年龄、性别、婚姻、照片、薪资、公司内部数据等敏感项
- **双版本差异对照**：输出保留 / 重排 / 翻译 / 脱敏 / 删除的决策与原因
- **双轨质检**：同时跑 ATS 兼容性清单与人工可读性清单，避免只追关键词分

## 使用方式

在 Claude Code 中使用 `/resume-market-adapter` 调用。

```
/resume-market-adapter 把这份经历做成中国版和国际版简历
/resume-market-adapter 这份中文简历投美国岗，要改哪些
/resume-market-adapter 生成中美双版并给差异对照表
```

## 工作流

1. **采集事实源** — 让用户提供原始简历 / 经历素材，先建证据账本，标注事实、用户估算、待核验三类
2. **判明目标** — 确认目标国家/地区、语言、岗位、公司类型、JD、公开程度与隐私约束
3. **选适配规则** — 按目标市场自动切换中国或国际规则集（详见 [references/resume-market-adapter.md](../../references/resume-market-adapter.md)）
4. **生成双版** — 从同一账本生成两版：结构、关键词、隐私处理按市场分化
5. **差异对照** — 输出两版差异表：哪些保留 / 重排 / 翻译 / 脱敏 / 删除，及原因
6. **双轨质检** — 跑 ATS 清单 + 人工可读性清单；输出证据缺口、风险表述与待用户确认项

## 中国市场适配要点

- 结构可按国内习惯保留「基本信息」区，但照片、薪资、年龄是否放入需按岗位取舍（非默认必放）
- 表达重信息密度：职级（P7/T11/高级）、业务结果、项目职责、技术栈要前置到首屏
- 关键词对齐中文 JD 与国内平台（BOSS / 猎聘 / 拉勾）高频词，而非英文 ATS 的翻译
- 行业黑话与国内公司职级体系直接用，不必转译为英文说法

## 国际市场适配要点

- 区分 **Resume**（美 / 加 / 澳，1 页，成就导向）与 **CV**（英 / 欧学术或研究岗，可 2 页以上）
- 默认脱敏：年龄、性别、婚姻、照片、国籍、薪资一律不写，规避反歧视（discrimination）风险
- 行动动词开头（Led / Built / Reduced / Drove），量化影响 bullet
- 英文简历、LinkedIn、GitHub / Portfolio 三者术语与经历保持一致，避免互相矛盾

## 跨市场共用铁律

- **禁止虚构**：数字、职级、成果必须从证据账本来；待核验项明确标「待确认」，不补编造数字
- **可公开程度**字段决定哪些信息进公开投递版、哪些只在私聊上下文讨论
- 同一事实源保证两版不自相矛盾，不因目标市场而美化或编造经历

## 适用场景

- 同时考虑中国大厂、外资企业与海外技术岗的用户
- 已有英文 / 中文简历，想按另一市场重构而非机翻
- 不清楚哪些个人信息在某市场该保留还是脱敏

## 限制

- 不替代 [resume-optimizer](../resume-optimizer/SKILL.md)（ATS 检测）与 [resume-writer](../resume-writer/SKILL.md)（爆破点撰写），三者路径兼容、可串联使用
- 不提供目标市场本地化法律合规的最终裁定，只给风险提示，重大投递请以当地法务意见为准
- 简历投递结果受市场、岗位、时机等多重因素影响，本技能只提升相关性与合规度
