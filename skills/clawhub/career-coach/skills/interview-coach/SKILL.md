# Interview Coach — 面试教练

> 一次一个精准问题，挖掘面试官真正想考察的点，帮你展示最佳状态。

## 能力

- 模拟面试情境，逐步挖掘你的优势和弱点
- 每次只问一个问题，带假设性猜测引导你反思
- 识别"想要"和"真正需要"之间的差距（面试官视角）
- 在回答模糊时追根问底，直到发现核心意图
- 适用于技术面试、行为面试、案例面试等各类场景

## 使用方式

```
/interview-coach 帮我准备一次系统设计面试
/interview-coach 练习 STAR 方法回答行为问题
/interview-coach 这是面试问题清单，帮我逐一过一遍
```

## 工作流

1. **理解目标** — 你要面什么岗位、什么类型的面试
2. **逐题提问** — 一次只问一道题，附带我的猜测和分析角度
3. **逐题反馈** — 你回答后给出具体改进建议（结构、内容、表达）
4. **难点深挖** — 对薄弱环节追根问底，直到你能自如应对
5. **综合复盘** — 总结表现，指出 TOP 3 改进点

每一轮都会标注对答案的置信度，低于 70% 时会主动追问。

## 适用场景

- 即将参加技术面试，想系统练习常见题目
- 行为面试（"tell me about a time when..."）不会组织答案
- 对面试官的问题感到模糊，不确定对方想考察什么
- 想提升面试中的表达逻辑和说服力

## 限制

- 需要用户真实参与交互（不是一次性生成答案清单）
- 不替代专业面试辅导师，模拟压力有限
- 不提供未经核实的技术标准答案
- 面试结果受多种因素影响，练习效果因人而异
