# Resume Writer — 简历爆破点撰写

> 弱描述让简历被忽略。本技能用 X-Y-Z 公式和 STAR 方法，把"负责 X"改写为"通过 Z 实现了 Y 倍增长的 X"。

## 能力

- 将弱爆破点（列举职责）转化为强爆破点（展示成果）
- 应用 X-Y-Z 公式："通过 [方法 Z] 实现 [成果 X]，量化指标 [Y]"
- 应用 STAR 方法结构化每条经历
- 为无数据场景提供合理的量化估算
- 按行业/岗位定制表达风格（技术岗偏数据，设计岗偏作品）
- 确保每条爆破点展示影响力，而非仅罗列工作内容

## 核心公式

### X-Y-Z 公式（Google 面试官推荐）

> "通过 [Z] 实现了 [X]，量化指标 [Y]"

**实例：**
```
❌ 弱: "管理社交媒体账号"
✅ 强: "通过日更内容和 KOL 合作，将 Instagram 粉丝从 5K 增长至 17.5K（+250%）"

❌ 弱: "改进客户服务"
✅ 强: "通过重新设计工单系统和培训 15 名客服，将客户满意度从 3.2 提升至 4.5/5"
```

### STAR 方法

- **S**ituation — 背景情境
- **T**ask — 面临的任务
- **A**ction — 你采取的行动
- **R**esult — 量化结果

## 使用方式

```
/resume-writer 帮我改进这段经历描述："负责团队管理"
/resume-writer 用 X-Y-Z 公式重写我的工作经历
/resume-writer 帮我找到这段经历中可以量化的指标
```

## 工作流

1. **诊断** — 识别弱爆破点：被动语态、无数据、职责罗列
2. **深挖** — 追问具体细节：规模、频率、前后对比、影响范围
3. **重写** — 逐条应用 X-Y-Z 或 STAR 改写，确保有数字、有因果
4. **复查** — 检查是否每一句都展示"成就"而非"职责"
5. **定制** — 根据目标岗位的关键词和风格微调表达

## 适用场景

- 简历投递无回音，怀疑描述不够有力
- 不知道如何量化自己的工作成果
- 从"执行者"角色向"领导者"角色转换时调整表达
- 经历较少，需要用有限的经验展示最大价值

## 限制

- 不能凭空编造数据（需基于真实经历估算）
- 技术岗和管理岗的表达策略不同，需明确目标
- 中英文表达习惯有差异，建议最终以目标市场语言定稿
- 高度定制的爆破点需结合具体 JD 进一步调整
