# 求职策略 Playbook

> 求职是一个转化漏斗，不是一次投递。绝大多数人的问题不是"简历不好"，
> 而是**没有定位、渠道单一、没有反馈闭环**。

## 一、先定位，再投递

在投第一份之前回答清楚：

| 问题 | 为什么重要 |
|------|-----------|
| 我要什么类型的公司？（阶段、规模、行业） | 决定简历叙事方式和渠道 |
| 我的目标职级是什么？ | 定错级会导致大量无效面试 |
| 我的不可妥协项是什么？（3 个以内） | 避免拿到 offer 才发现不能接受 |
| 我能接受的最长求职周期？ | 决定是精投还是广撒 |
| 我的核心卖点是哪一条？ | 全部材料围绕它组织 |

**定位不清的典型症状**：简历同时强调管理和技术、投递岗位横跨三个方向、
面试时说不清自己想要什么。这些都会被面试官识别为"没想清楚"。

## 二、渠道：转化率差一个数量级

| 渠道 | 相对转化率 | 投入 | 适用 |
|------|-----------|------|------|
| **内推** | 最高 | 中（要维护关系） | 一切情况，应作为主渠道 |
| 猎头 | 高 | 低 | 中高级岗位、被动求职 |
| 公司官网直投 | 中 | 低 | 目标明确的少数公司 |
| 招聘平台投递 | 低 | 低 | 广度补充 |
| 海投 | 最低 | 低 | 不推荐作为主策略 |

**核心建议**：把 70% 的时间花在内推和目标公司研究上，30% 用于平台投递。
大多数人的分配正好相反——花 90% 时间刷平台，然后抱怨没回音。

### 找内推的正确方式

```
✗ "您好，可以帮我内推吗？"（陌生人不欠你人情）
✓ 三步法：
  1. 先了解岗位和公司，形成一个具体问题
  2. 联系时说明：你是谁、为什么对这个岗位感兴趣、你的一条最强证据
  3. 先问"能不能聊 15 分钟了解一下团队"，而不是直接要内推
```

信息面谈（informational interview）的转化率远高于直接求推。
聊完对方了解你了，内推是自然结果。

## 三、批量管理：把求职当项目做

维护一张表，最少这些列：

```
公司 | 岗位 | 渠道 | 投递日 | 状态 | 联系人 | 下一步 | 下次跟进日 | 备注
```

状态流转：`待投 → 已投 → 已回复 → 面试中 → offer / 拒 / 无响应`

### 节奏建议

| 阶段 | 每周投递量 | 重点 |
|------|-----------|------|
| 第 1–2 周 | 5–8 家（都是目标公司） | 验证简历和定位，收集反馈 |
| 第 3–6 周 | 10–15 家 | 规模化，同时保持内推推进 |
| 第 7 周后 | 视反馈调整 | 如果转化仍差，回到第一步重新定位 |

**不要一开始就投最想去的公司**。前几场面试是练兵，把最想去的排在第 3–5 场之后。

## 四、诊断：卡在哪一层

漏斗有四层，每层的失败原因完全不同。先定位再修：

```
投递 → 简历筛选 → 初面 → 复面/终面 → offer
```

| 卡点 | 症状 | 根因 | 对策 |
|------|------|------|------|
| 投递→筛选 | 投 30+ 家几乎无回音 | 岗位不匹配 / ATS 解析失败 / 简历无成果 | [ats-optimization.md](ats-optimization.md) + [resume-crafting.md](resume-crafting.md)；换内推渠道 |
| 筛选→初面 | HR 电话后没下文 | 期望薪资不匹配 / 动机说不清 / 时间线有硬伤 | 准备 60 秒动机陈述；提前想好空窗期说法 |
| 初面→复面 | 技术/业务面被挂 | 简历深度不够 / 答题无结构 | [interview-prep.md](interview-prep.md) 第四、五节 |
| 复面→offer | 到终面被拒 | 文化/级别不匹配 / 反问暴露没做功课 | 加强公司研究；准备反问 |
| offer→入职 | 谈崩或反悔 | 期望没有提前对齐 | [salary-negotiation.md](salary-negotiation.md) |

**每 15 次投递复盘一次**。连续 20 次同一层卡住，说明是系统性问题，不是运气。

## 五、在职求职的操作要点

- **时间**：面试尽量约在早/晚或午休，避免频繁请假引起注意
- **痕迹**：不要用公司邮箱、不要在公司网络投递、关闭平台的动态提醒
- **说辞**：被问及离职原因，讲"想要什么"而不是"逃离什么"
- **底线**：不要在拿到正式 offer 前提离职

## 六、空窗期处理

空窗本身不是问题，**说不清空窗在干什么**才是。

| 时长 | 处理 |
|------|------|
| < 3 个月 | 不需要特别解释，正常求职周期 |
| 3–12 个月 | 简历加「近期投入」章节：进修、开源、自由职业、家庭原因 |
| > 12 个月 | 需要一个清晰的叙事，并展示仍在保持专业能力（作品/证书/项目） |

准备一个 30 秒的版本：`发生了什么 → 期间做了什么 → 为什么现在回来`。
平静陈述，不要过度解释——过度解释会让对方觉得有隐情。

## 七、拒信的价值

大多数拒信是模板，但值得做两件事：

1. **回信要反馈**（礼貌、简短、不辩解）：约 10–20% 会给出真实原因，这是最便宜的诊断数据
2. **保留联系**：被拒不等于不合适，只是这次不合适。半年后岗位和你都变了

**不要做**：辩解、追问细节、表达不满。行业圈子比想象中小。

## 八、心理与节奏

求职的失败率天然很高，一个健康的漏斗也可能是 30 投 → 5 面 → 1 offer。

- 把指标设在**行为**上（本周联系 3 个内推人）而不是**结果**上（本周拿到面试）
- 固定作息，不要 24 小时刷招聘 App
- 同时推进多条线，避免把全部期待压在一家
- 收到拒信当天不做决策（比如"要不要降低期望"），第二天再看

## 九、何时该调整策略

出现以下任一情况，停下来重新定位而不是继续投：

- 投递 40+ 无面试机会
- 面试 10+ 无 offer
- 拿到的 offer 都不在目标方向
- 面试中反复被问同一个短板

继续用同样的方法投第 50 家不会有不同结果。
