# 薪酬谈判 Playbook

> 谈判不是零和博弈，也不是"敢不敢开口"的胆量测试。它是一次**信息不对称下的定价协商**。
> 谁掌握的信息多、谁的替代选项好，谁的空间就大。

## 一、谈判前：三件事决定结果

### 1. 建立市场基准

在开口前必须知道三个数：

| 数 | 含义 | 怎么得到 |
|----|------|---------|
| **市场中位** | 同城 + 同岗位 + 同年限的中位数 | 招聘平台薪资区间、同行私聊、猎头 |
| **该公司区间** | 这家公司该职级的带宽 | 猎头、内部人、招聘平台的历史数据 |
| **你的底线** | 低于此不接受 | 现有薪资 + 换工作成本 + 机会成本 |

**信息来源优先级**：猎头 > 内部人 > 平台数据 > 公开报告。
公开报告滞后且口径混乱，只能作为量级参考。

### 2. 明确自己的 BATNA

BATNA = 谈判失败时你最好的替代方案。它是唯一真正的筹码。

```
强 BATNA：手上有另一个 offer / 现职稳定不急着走
弱 BATNA：已离职 + 无其他 offer + 有现金压力
```

BATNA 弱时不要硬来，转而争取非现金项（见第五节）。
BATNA 强时也不要虚张声势——虚构 offer 被识破会直接终止流程。

### 3. 准备价值论述

谈判的说服力来自"我值这个价"的证据，不是"我需要这么多"。

```
✗ "我房贷压力比较大，希望能到 X"
✓ "根据我了解的市场，这个职级的区间大概在 A–B。结合我在 [具体能力] 上的经验，
   以及我上一份工作 [具体成果]，我希望能到 B 这个水平。"
```

## 二、时机：什么时候谈

```
HR 初筛（问期望）→ 面试过程 → 拿到口头 offer → 正式 offer → 入职
                                    ↑
                              真正的谈判窗口
```

**原则：越晚谈越有利**。在对方决定"要你"之前谈，你只是候选人之一；
决定之后谈，替换你的成本已经产生。

## 三、被问期望薪资怎么办

这是最早也最关键的一关。三种应对，按优先级：

### A. 反问（首选）

```
"我对这个岗位很感兴趣。贵司对这个职级有既定的薪酬区间吗？
 我想先了解一下，看是否匹配。"
```

很多公司会给区间。拿到区间后，把期望定在区间的上三分之一。

### B. 给区间 + 附条件（次选）

对方坚持要你先说时：

```
"基于我了解的市场情况和目前的水平，我的期望在 A 到 B 之间，
 具体也要看整体包的构成和职级。"
```

区间下限设在**你实际想要的数字**（对方几乎必然按下限谈），
上限不超过下限的 1.2–1.3 倍。

### C. 推迟（BATNA 强时可用）

```
"我现在更想先了解岗位和团队。等双方都觉得合适了，
 我相信薪酬上不会是障碍。"
```

**不要做**：直接报出现有薪资（很多地区已立法禁止询问，你也没有义务回答）、
报一个自己都心虚的高数字、说"都可以"。

## 四、拿到 offer 后的谈判动作

### 标准流程

```
1. 表达感谢 + 明确兴趣（先给确定性，降低对方防御）
2. 要求书面完整 offer（所有构成项）
3. 争取 2–5 天考虑时间（合理，不要立刻答应也不要拖太久）
4. 提出一次调整请求（集中、有依据、给出接受信号）
5. 对方回应后决策
```

### 提出请求的模板

```
"非常感谢，我对这个岗位和团队都很有兴趣，基本已经决定加入。
 只有一点想沟通：base 部分 [具体数字]。
 原因是 [市场依据 / 另一个 offer / 你的独特价值]。
 如果能到 [目标数字]，我可以立刻确认接受。"
```

三个要素缺一不可：**明确的数字**、**客观依据**、**接受信号**。
没有接受信号的谈判会被当成"还在货比三家"，对方反而会保守。

### 幅度参考

| 情况 | 合理争取幅度 |
|------|------------|
| 无其他 offer、市场持平 | 5–10% |
| 有可比 offer | 10–20% |
| 对方明显急招 / 你有稀缺能力 | 20%+ |

**只谈一轮**。第二轮追加会显著消耗好感，除非对方主动开了新条件。

## 五、不只谈 base：整包思维

base 谈不动时，这些项往往有空间且审批链更短：

| 项目 | 弹性 | 备注 |
|------|------|------|
| 签字费 | 高 | 一次性，不影响薪酬带宽，最容易批 |
| 股票/期权 | 中高 | 问清总量、行权价、归属节奏、稀释情况 |
| 职级 | 中 | 影响长期，比一次性加薪更值钱 |
| 年假 / 远程天数 | 中 | 不花钱，常被忽略 |
| 入职时间 | 高 | 可以换喘息期 |
| 首次调薪时点 | 中 | 争取"6 个月后 review"而非满一年 |
| 培训/设备预算 | 高 | 金额不大但容易给 |

**职级比薪资重要**：同样的钱，进 P6 和进 P7 的三年后差距巨大。
如果只能争一样，优先争职级。

## 六、股权：必须问清的五个问题

1. 总股数是多少，我拿到的占比是多少？（只给股数不给占比 = 无法估值）
2. 行权价 / 授予价是多少？
3. 归属节奏？（常见 4 年 1 年 cliff）
4. 离职后行权窗口多久？（很多是 90 天，实际上等于放弃）
5. 上一轮估值和时间？有没有优先清算权？

问不出这些的公司，把股权按 0 估值来做决策。

## 七、常见错误

| 错误 | 后果 |
|------|------|
| 在拿到 offer 前主动谈薪 | 过早暴露底牌，还可能被筛掉 |
| 虚构竞争 offer | 被要求出示或被识破，直接出局 |
| 一次提出五六项调整 | 显得难搞，对方逐条砍 |
| 情绪化（威胁、抱怨、诉苦） | 关系受损，即使拿到也影响后续 |
| 口头承诺不落纸 | 入职后无法兑现，且无凭据 |
| 谈完还继续谈 | 极少数情况下 offer 会被撤回 |

## 八、内部涨薪：和外部谈判不同

内部谈判的逻辑不是"市场价"，是"预算与相对分配"。

- **时机**：绩效周期前 1–2 个月，不是调薪结果出来后
- **对象**：先说服直属上级（他去争预算），不要越级
- **材料**：过去一年的成果清单 + 承担的超出职级的职责 + 市场参考
- **说法**：讲"我的职责已经在 X 层面"，而不是"别人拿得比我多"
- **备选**：预算冻结时，争取职级、项目机会、明确的调薪时间点

**外部 offer 逼宫要谨慎**：短期常有效，但会被标记为"随时会走的人"，
且加薪后一年内往往仍会被优先列入优化名单。除非你真的愿意走，否则不要用。

## 九、决策：不只看钱

拿到多个 offer 时，建议按这个顺序权衡：

```
1. 这份工作能让我三年后更值钱吗？（能力增长 + 履历质量）
2. 直属上级值不值得跟？
3. 公司/业务是在增长还是收缩？
4. 总包差异是否大到足以覆盖前三项的差距？
```

薪资是唯一可以在三年内追回来的变量，其余三项不行。
