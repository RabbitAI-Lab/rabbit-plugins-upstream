# 个人品牌与职业档案 Playbook

> 简历是你主动投出去的，个人档案是让机会主动找上门的。两者的目标不同：
> 简历要**说服**特定岗位的读者，档案要**被检索到**并让陌生人快速判断"值不值得聊"。

## 一、档案 vs 简历：不要复制粘贴

| 维度 | 简历 | LinkedIn / 职业档案 |
|------|------|-------------------|
| 读者 | 已知岗位的招聘方 | 未知的招聘者、同行、潜在合作方 |
| 目标 | 通过筛选 | 被搜到 + 引发对话 |
| 语气 | 第三人称、克制 | 第一人称、有温度 |
| 内容 | 针对该岗位裁剪 | 完整职业面貌 + 方向信号 |
| 长度 | 1–2 页硬上限 | 可长，但要分层可扫读 |

把简历原文粘贴到档案里是最常见的浪费。

## 二、被搜到：招聘者的检索行为

招聘者在平台上的典型操作是**按关键词 + 地区 + 年限筛选**，然后扫一遍标题和摘要决定点不点开。
所以优化优先级是：

```
标题（权重最高）> 摘要前 2 行 > 技能标签 > 经历标题 > 经历正文
```

### 标题（Headline）写法

默认标题是「当前职位 @ 公司」，这是浪费。它是唯一在搜索结果里全文显示的字段。

```
✗ 软件工程师 @ 某某科技
✗ 追求卓越 | 终身学习者 | 热爱技术
✓ 后端工程师 | 高并发系统 · Go/Kubernetes | 支撑日活千万级服务
✓ 产品经理 | B 端 SaaS · 从 0 到 1 | 前咨询顾问
```

结构：`岗位 | 专长领域 · 核心技术 | 一个差异化信号`

三个约束：包含你希望被搜到的关键词、能看出级别与方向、不用空洞形容词。

### 摘要（About）写法

前 2 行会被折叠前显示，必须是钩子。四段式：

```
第 1 段（2 行）：我是谁 + 最强的一个证据
第 2 段：专注方向和方法论，你解决什么类型的问题
第 3 段：可选——一个具体的代表作或数字
第 4 段：现在在找什么 / 欢迎什么样的联系
```

用第一人称写。第 4 段的方向信号非常重要——没有它，招聘者不知道该不该联系你。

### 技能标签

按**你希望被搜到的顺序**排列，把最核心的 3 个置顶。
标签是精确匹配，写具体技术名而不是"编程"这类大词。

## 三、被点开后：让人 30 秒读完

- **经历部分**：每段 3–5 条，写法同简历（见 [resume-crafting.md](resume-crafting.md) 四级阶梯），
  但可以多一点第一人称的语气和上下文
- **头像**：清晰正脸、干净背景。有头像的档案被查看率显著更高
- **背景图**：放作品、团队照或干净的纯色。空着=默认灰，浪费一块黄金位置
- **自定义链接**：改成 `姓名` 而不是一串随机字符，方便放进简历和邮件签名
- **推荐语**：3–5 条来自不同角色（上级、平级、下属）的推荐，比自述可信得多。
  主动找人写时，给对方提供一个具体的项目和你希望被强调的点

## 四、内容与可见度（可选但杠杆很高）

不是每个人都要做内容，但如果你的目标包含"让机会找上门"，最低成本的做法：

| 投入 | 做法 | 效果 |
|------|------|------|
| 极低 | 有意义的评论（不是"很赞"），每周 2–3 条 | 在同行视野里出现 |
| 低 | 每月 1 篇复盘：一个具体问题怎么解决的 | 建立专业标签 |
| 中 | 开源项目、技术分享、行业社群运营 | 形成可验证的作品集 |

原则：**围绕一个方向持续输出** > 什么都聊。三年发 30 篇同主题的复盘，
比发 300 篇杂帖更能建立标签。

## 五、跨平台一致性

招聘者会交叉搜索。确保这些地方的核心信息一致：

- 职位名称与时间线（不一致会被当成简历造假）
- 头像（同一张，便于识别）
- 方向定位（LinkedIn 写后端、GitHub 全是前端项目，会造成困惑）

不一致本身不是问题，**无法解释的不一致**才是。

## 六、求职中的可见度管理

| 状态 | 建议 |
|------|------|
| 在职、暗中看机会 | 关闭"更新提醒"再改档案；用 recruiter-only 的求职开关；不要一次性大改 |
| 在职、公开找 | 摘要第 4 段明确写方向；打开求职标识 |
| 离职中 | 标题可写目标岗位而非"待业"；用「近期投入」填补时间线 |

**在职偷偷改档案的头号事故**：忘记关闭动态提醒，一次性更新触发全网通知，同事和老板都看到了。
改之前先关，改完过几天再开。

## 七、检查清单

- [ ] 标题包含目标岗位关键词，不是默认的「职位 @ 公司」
- [ ] 摘要前 2 行能独立成立，是钩子不是套话
- [ ] 技能标签前 3 个是你最想被搜到的词
- [ ] 每段经历有成果不只有职责
- [ ] 有头像、有背景图、自定义链接已改
- [ ] 至少 3 条推荐语
- [ ] 明确的方向信号（在找什么）
- [ ] 与简历、GitHub、个人站的信息一致
- [ ] 在职者：改动前已关闭动态提醒
