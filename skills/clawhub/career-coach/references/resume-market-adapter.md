# 双轨简历精修 Playbook（中国 / 国际）

> 同一份真实经历，按目标市场生成两套简历。核心不是翻译，而是**结构、关键词、隐私策略**的重新适配。
> 本篇是方法论（L2），具体落地动作见 [skills/resume-market-adapter/SKILL.md](../skills/resume-market-adapter/SKILL.md)。

## 一、先建证据账本（唯一事实源）

所有版本都从同一张账本生成，禁止各写各的。每条经历拆成六字段：

| 字段 | 含义 | 示例 |
|------|------|------|
| 职责 | 你在岗位上的本职范围 | 负责订单服务的稳定性与容量规划 |
| 技术动作 | 你具体做了什么、用什么 | 用 Kubernetes + HPA 重构弹性伸缩，引入 Prometheus 告警 |
| 结果 | 可量化的产出 | P99 从 1.2s 降到 280ms，大促零故障 |
| 影响范围 | 业务/组织层面的波及 | 支撑日均 3000 万单，覆盖 6 条业务线 |
| 证据来源 | 数字/表述的可核验出处 | 监控大盘、复盘文档、主管可佐证 |
| 可公开程度 | 公开投递 / 仅私聊 / 脱敏后 | 结果可公开；内部故障根因仅私聊 |

每条标三类之一：**事实**（可直接用）、**用户估算**（相对值可写，精确值标「约」）、**待核验**（明确标「待确认」，不补编造）。

## 二、中国市场 vs 国际市场：规则对照

| 维度 | 中国市场 | 国际市场（美/加/澳/英/欧） |
|------|----------|----------------------------|
| 结构首屏 | 基本信息 + 职级 + 业务结果前置 | 姓名 + 定位句 + 核心成就前置 |
| 长度 | 1–2 页，资深可 2 页 | Resume 1 页；CV（学术/欧）可 2 页+ |
| 照片 | 部分岗位（如前台/销售）可选，技术岗一般不放 | 一律不放 |
| 年龄/生日 | 国内常写，但非必须；按岗位取舍 | 不放（反歧视） |
| 婚姻/性别 | 一般不写 | 不放 |
| 薪资 | 可不写；谈薪阶段另议 | 不放；期望薪资单独谈 |
| 职级表达 | 用国内体系（P7/T11/高级/专家） | 用 scope（Led a team of 8）而非 title 翻译 |
| 关键词 | 对齐中文 JD + BOSS/猎聘/拉勾高频词 | 对齐英文 JD + ATS 解析词 |
| 动词 | 中文动作动词（主导/搭建/落地） | 英文行动动词（Led/Built/Reduced） |
| 一致性 | 简历与内推/猎头沟通一致 | 简历 + LinkedIn + GitHub/Portfolio 一致 |

**关键判断**：国际版不是中文版的翻译，而是重新组织——把"职级"翻译成"scope 与影响"，把"业务结果"翻译成"量化 bullet"，并脱敏所有受保护特征。

## 三、隐私风险矩阵（地区化提示）

| 信息 | 中国 | 美国 | 英国/欧盟 |
|------|------|------|-----------|
| 照片 | 技术岗一般不放；前台/销售可选 | 不放 | 不放 |
| 年龄/生日 | 非必须，按岗位取舍 | 不放 | 不放（GDPR） |
| 性别 | 不放 | 不放 | 不放 |
| 婚姻/家庭 | 不放 | 不放 | 不放 |
| 国籍 | 可写（如"中国籍"） | 工作签证状态可备注，不写国籍歧视项 | 不放 |
| 薪资现状 | 简历不写，谈薪另议 | 不放 | 不放 |
| 公司内部数据 | 脱敏（用"某业务线"而非真名） | 脱敏 | 脱敏（GDPR） |

默认策略：**国际市场一律脱敏受保护特征**；中国市场按岗位决定是否保留基本信息区，但薪资与内部数据仍建议脱敏。

## 四、双轨检查清单

### ATS 兼容性清单（两版通用）

- [ ] 标准章节标题（Experience / Education / Skills 或 工作经历/教育背景/技能）
- [ ] 无表格、文本框、分栏、图片型排版
- [ ] 标准字体（Arial/Calibri/Georgia，10–12pt）
- [ ] 关键词与 JD 命中（中英分别对齐各自 JD）
- [ ] 文件名规范：`姓名_岗位_简历.pdf` / `FirstName_LastName_Resume.pdf`
- [ ] 无特殊字符、无页眉页脚关键信息

### 人工可读性清单（两版通用）

- [ ] 15 秒扫读能说清"这人干什么、什么级别"
- [ ] 每段经历 ≥2 条带量化/范围的成果
- [ ] 无「负责/参与/协助」开头 bullet（国际版无 weak verb）
- [ ] 所有数字本人能解释推导，无编造
- [ ] 时间线无解释不了的空白
- [ ] 两版不自相矛盾（同一事实表述一致）
- [ ] 隐私项按市场规则处理（见矩阵）

## 五、双版本差异对照方法论

生成后输出一张表，逐条说明决策：

| 内容 | 中国版 | 国际版 | 决策 | 原因 |
|------|--------|--------|------|------|
| 职级 P7 | 保留并前置 | 转写为 "Led team of 8, scope: X" | 重排+翻译 | 国际无 P 级语境 |
| 生日 | 可不写（默认脱敏） | 不放 | 删除 | 反歧视 |
| 量化结果 | 保留原数 | 保留原数 | 保留 | 同一事实源 |
| 内部故障根因 | 脱敏为"某业务线" | 脱敏 | 脱敏 | 公司内部数据 |

模板：**保留**（事实一致）/ **重排**（顺序按市场习惯）/ **翻译**（术语对齐）/ **脱敏**（隐私风险）/ **删除**（市场不适或受保护特征）。

## 六、示例输入输出

### 示例 A — 中文技术岗 JD → 中国版

**输入 JD（节选）**：高级后端工程师，5 年以上经验，精通 Go / 微服务 / Kubernetes，有高并发经验，负责过核心交易链路。

**输入素材（证据账本条目）**：职责=订单服务稳定性与容量规划；技术动作=K8s+HPA 重构弹性伸缩、引入 Prometheus；结果=P99 1.2s→280ms、大促零故障；影响=日均 3000 万单、6 条业务线；来源=监控大盘；公开=可公开。

**中国版输出（节选）**：
```
张伟 | 高级后端工程师 | 138-xxxx | city
核心能力：Go / 微服务 / Kubernetes / 高并发架构
工作经历
某电商 高级后端工程师（2021–至今）
- 主导订单服务弹性伸缩重构（Kubernetes + HPA），大促零故障
- P99 响应 1.2s 降至 280ms，支撑日均 3000 万单、6 条业务线
- 引入 Prometheus 全链路监控，故障定位时效显著提升
```
要点：职级与业务结果前置，用中文动作动词，关键词对齐 JD（高并发/微服务/核心链路）。

### 示例 B — 英文国际岗 JD → 国际版

**输入 JD（节选）**：Senior Backend Engineer, 5+ yrs, Go / microservices / Kubernetes, high-throughput systems, owned critical path.

**国际版输出（节选）**：
```
Wei Zhang | Senior Backend Engineer | city, country | email
Summary: Backend engineer with 5+ yrs building high-throughput services in Go.
Experience
E-commerce Co. — Senior Backend Engineer (2021–Present)
- Led elastic-scaling rebuild of the order service on Kubernetes + HPA; zero incidents during peak sales
- Cut P99 latency from 1.2s to 280ms, supporting 30M orders/day across 6 business lines
- Drove full observability with Prometheus, cutting MTTR significantly
```
要点：无照片/年龄/薪资；职级转写为 scope（Led team / scope）；行动动词开头；LinkedIn 与 GitHub 用同一套经历与术语。

**差异对照**：职级"高级"→ scope 表述（重排+翻译）；生日/薪资→删除（脱敏）；P99 与 30M 订单→两版保留（同一事实）；中文"主导/引入"→"Led/Drove"（翻译）。

## 七、与既有子技能的协作

- [resume-writer](../skills/resume-writer/SKILL.md)：负责把单条经历写成 X-Y-Z / STAR 爆破点，本技能在其之上做市场分化
- [resume-optimizer](../skills/resume-optimizer/SKILL.md)：负责 ATS 关键词匹配与格式检测，本技能生成后可用它做最终扫描
- 串联顺序建议：证据账本 → [resume-writer](../skills/resume-writer/SKILL.md) 起草 bullet → 本技能按市场分化 → [resume-optimizer](../skills/resume-optimizer/SKILL.md) 终检

## 八、诚信边界

可以做：优化表达、跨市场重排、术语翻译、隐私脱敏、相对量化。

不可以做：虚构公司/职级、编造精确数字、把团队成果写成个人、把待核验项当事实写、为迎合某市场美化经历。背调与深度面试会暴露，代价远大于收益。
