## Description:

Read Remind (remind.com) classes, chats, messages, and notification settings from a shell by capturing a signed-in browser session with fpx and querying Remind's GraphQL API with curl.

This skill is ready for commercial/non-commercial use.

## Publisher:

[chrischall](https://clawhub.ai/user/chrischall)

MIT-0

## Use Case:

Developers and technically comfortable Remind users use this skill to retrieve account, class, chat, message, and notification data from Remind in scripts or one-shot shell workflows without running the remind-mcp server.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow captures reusable Remind session credentials into a local plaintext file.

Mitigation: Use an isolated browser profile where practical, keep the session file permissions restricted, and remove the session file when finished.

Risk: The artifact includes write-capable GraphQL examples even though the skill is read-oriented.

Mitigation: Avoid mutation examples unless the user explicitly intends to change settings or send real messages, and review permissions before execution.
