Risk: Web research may surface stale, incorrect, or weakly sourced public information.

Mitigation: Review source links, timestamps, and verification status before using reports or publishing derived content.

Risk: Generated AI-impact analysis could be mistaken for career, business, or investment advice.

Mitigation: Keep forward-looking judgments informational, retain the skill's disclaimers, and require user review before publication.

Risk: The skill writes local Markdown outputs for social and content workflows.

Mitigation: Run it in a workspace intended for generated content and review files before distribution.
