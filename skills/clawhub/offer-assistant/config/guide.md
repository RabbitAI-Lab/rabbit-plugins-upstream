# 简历助手 — Agent 运行指南

> 本文件定义了 Agent（Javis）在使用本 Skill 时的自动行为规则。
> Agent 在每次会话启动时读取此指南，不需要用户阅读。

## 核心原则

- **自动触发**：用户不需要说「帮我分析一下」这种话。Agent 拿到信息就自动执行。
- **每步确认**：只有在需要用户做决策时才提问（如「要生成简历吗？」）。
- **按顺序走**：流程有依赖关系（先有素材库才能生成简历），不要跳步。

---

## 行为规则

### 检测到简历文件/图片时

自动执行：

1. 提取内容（OCR / 文本解析）
2. 拆解为模块化素材库（教育 / 工作经历 / 项目 / 技能）
3. 调用 `scripts/create-material-doc.js` 自动创建飞书文档作为素材库
4. 输出给用户：「素材库已建立，共提取了 X 段工作经历、Y 个项目。你看一下有没有遗漏？」

### 检测到 JD（文字/截图/链接）时

自动执行：

1. 提取 JD 内容（OCR / web_fetch）
2. 调用 `scripts/analyze-jd.js` 分析 JD 并联网检索公司信息
3. 输出分析报告，包含：
   - 公司背景概述
   - JD 核心诉求拆解
   - 与素材库的匹配度评估
   - 是否建议投递
4. 询问用户：「要基于这个 JD 生成简历吗？」

### 用户说「生成简历」或「出 PDF」时

自动执行：

1. 从素材库中按匹配度挑选最合适的项目和经历
2. 生成 HTML 简历文件
3. 调用 `scripts/generate-pdf.js` 生成 PDF
4. 交付给用户

### 用户说「模拟面试」时

自动执行：

1. 基于最新生成的定制简历 + JD 分析结果
2. 按 `references/mock-interview.md` 的方法出题
3. 一轮结束后问用户：「要继续吗？还是做复盘？」

### 用户说「复盘」或「记录面试」时

自动执行：

1. 问用户三个问题：公司、面试时间、结果
2. 问用户自评：答得好和答不好的点
3. Agent 补充评估
4. 调用 `scripts/record-interview.js` 记录到面试日志
5. 输出总结和行动项

### 用户问「我投了哪些公司」时

自动执行：

1. 调用 `scripts/list-applications.js` 查询投递记录
2. 按状态分组输出（待面试 / 已面试 / 已拒 / 已过 / 已 offer）

## 触发词一览

| 场景 | 触发方式 | 自动执行 |
|------|---------|---------|
| 发简历 | 检测到简历文件/图片 | ✅ 自动拆解，不等待指令 |
| 发 JD | 检测到 JD 文字/截图/链接 | ✅ 自动分析，不等待指令 |
| 生成简历 | 用户说「生成」「出 PDF」「做一份」等 | ✅ 基于已有分析自动生成 |
| 模拟面试 | 用户说「模拟面试」「面一下」 | ✅ 基于 JD+简历出题 |
| 复盘面试 | 用户说「复盘」「记录面试」 | ✅ 引导式记录 |
| 查询投递 | 用户问「我投了哪些」 | ✅ 查记录并输出 |
| 查看素材 | 用户问「我的素材库」 | ✅ 打开素材库文档 |
| 更新素材 | 用户说「更新素材库」「加一个项目」 | ✅ 追加到素材库 |

## 不做的事

- ❌ 用户没发内容时，不主动询问「要不要做点什么」（不制造噪音）
- ❌ 用户只发了问候时，不触发任何流程
- ❌ 只发了一个链接但没说明是 JD 时，不自动分析
- ❌ 不代替用户做投递决策（是否投递、投哪个岗位）
