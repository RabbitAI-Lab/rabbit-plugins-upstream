# 统计分析方法论 (analysis_methods)

`scripts/analyze.py` 对每个号码池独立计算以下指标。理解这些概念有助于正确解读输出,
并避免在"选号"时陷入常见误区。

## 一、核心指标

### 1. 出现频率 (frequency)
每个号码在历史样本中的出现次数与频率(%)。高频号≠"更可能再出", 低频号≠"该出了"——
独立随机试验中, 过去频率不影响未来。

### 2. 冷热号 (hot / cold)
以最近 `window` 期(默认 30)内出现次数 vs 理论期望 `window × 每期个数 / 号码池大小` 比较:
- 热号: 近期出现次数明显高于期望。
- 冷号: 近期明显偏低。
冷号常被称为"遗漏回补"候选, 但数学上每期仍是独立均匀事件。

### 3. 遗漏值 (missing / 遗漏)
- 当前遗漏: 距离该号码上次出现已过去多少期(0 表示本期刚出)。
- 历史最大遗漏: 历史上该号码最长未出间隔。
遗漏是描述性指标, 不能用于预测"即将开出"。

### 4. 奇偶比 (odd / even)
开奖号码中奇数与偶数的个数比。长期看趋向均衡, 但单期波动大。

### 5. 大小比 (big / small)
以号码池中点划分大小。例如双色球红球 1–33, 中点 17, ≤17 为小、>17 为大。

### 6. 和值 (sum)
开奖号码之和。双色球看红球和值, 大乐透看前区和值。长期有稳定均值与分布区间,
可作为"缩水"过滤条件之一。

### 7. 区间分布 (range)
把号码池三等分(如 1–11 / 12–22 / 23–33), 统计各区出号个数, 观察是否偏区。

### 8. 连号 (consecutive)
相邻两号差为 1 的对数(如 12,13 记 1 个连号)。统计平均每期连号数。

### 9. 重号 (repeat)
本期号码与上一期重复的个数。统计平均重号数, 用于判断"追号"倾向。

### 10. 质数个数 (prime)
开奖号中质数的个数。属辅助维度。

## 二、选号 / 缩水策略 (`generate.py`)

- **random(机选)**: 均匀随机, 等价于投注站机选。
- **hot(热号)**: 对近期高频号加权抽样。
- **cold(冷号/遗漏回补)**: 对当前遗漏大者加权抽样。
- **balanced(均衡)**: 均匀随机 + 默认奇偶/大小均衡过滤。
- **过滤缩水**: 通过 `--odd-range` / `--big-range` / `--sum-range` / `--consec-range` / `--prime-range`
  排除不符合条件的组合, 减少注数。例如 `--odd-range 2,4 --sum-range 80,130` 只保留
  奇数 2–4 个且和值在 80–130 之间的组合。

### 缩水原理
缩水本质是用"条件"从全组合中剔除大量注数, 降低投入。但它**同时剔除了中奖组合**,
中奖概率按注数同比降低, 期望收益不变(仍为负)。缩水改变的是"投入规模", 不是"中奖几率"。

## 三、必须牢记的纠偏
1. 每期开奖独立且均匀随机, 历史分布不预测未来。
2. 冷热、遗漏、和值等所有指标仅描述过去, 可用于"偏好设定", 不能提升中奖概率。
3. 任何策略(机选、热号、冷号、缩水)的期望收益长期均为负; 彩票是娱乐而非投资。
4. 理性购彩: 量力而行, 不倍投、不借贷、不沉迷。本 skill 仅供研究与娱乐参考。
