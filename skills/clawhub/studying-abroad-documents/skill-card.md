## Description:

根据学生背景与目标院校或专业，策划、撰写、改写和润色英文留学申请文书，覆盖个人陈述（PS/SOP）、推荐信草稿、联系潜在导师的套磁邮件以及留学英文简历或学术 CV。

This skill is ready for commercial/non-commercial use.

## Use Case:

Students and applicants use this skill to draft, revise, and polish English study-abroad application materials, including PS/SOP essays, recommendation letter drafts, outreach emails, resumes, and academic CVs. It helps align application documents with confirmed facts, program requirements, and role-appropriate academic English.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Application materials may contain inaccurate or unsupported claims if user-provided facts are incomplete.

Mitigation: Review every generated document against user materials and official program requirements; keep placeholders for unconfirmed details.

Risk: Drafting study-abroad documents can involve personal academic, career, and application information.

Mitigation: Avoid sharing unnecessary sensitive identifiers and remove irrelevant personal data before use.

Risk: Recommendation letter drafts could be mistaken for final recommender-approved letters.

Mitigation: Treat recommendation letters as drafts for recommender review, correction, and approval before submission.
