## Description:

Designs technical architecture plans from requirements, covering technology selection, system architecture, data models, deployment plans, and deployable Markdown solution documents.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to turn PRDs or feature requirements into practical technical architecture documents, including stack rationale, architecture shape, data modeling, deployment planning, and MVP-to-scale evolution.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate for broad architecture-related Chinese prompts when a more specialized skill is intended.

Mitigation: Use specific prompts or explicitly name the desired skill when routing architecture work.

Risk: Architecture recommendations can be incomplete or mismatched to real project constraints if the PRD or requirements are underspecified.

Mitigation: Review the generated architecture against project scale, team skills, security needs, operating budget, and deployment constraints before implementation.
