## Description:

Check an academic paper, thesis or essay for originality with OpenPlag Labs (free, no account). Use when the user asks to check a document for plagiarism, overlap, citation problems or originality, in any of eight languages (English, Hebrew, Arabic, Russian, French, Spanish, German, Chinese).

This skill is ready for commercial/non-commercial use.

## Use Case:

External users can ask an agent to check one academic paper, thesis, or essay for originality, overlapping passages, citation context, and potential sources. After the user confirms, the agent submits the chosen document and relays the result summary and report link.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The document selected for checking is sent to the external OpenPlag Labs service.

Mitigation: Get the user's confirmation before submission, and avoid sensitive material unless the user has reviewed and accepts the service's handling of it.
