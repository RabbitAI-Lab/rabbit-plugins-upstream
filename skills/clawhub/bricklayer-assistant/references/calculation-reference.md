## 计算公式

### 砖块数量计算

```
单墙面积(m²) = 长(m) × 高(m) - 门窗洞口面积(m²)
12墙每平方米砖数 = 64 块（标准砖）
24墙每平方米砖数 = 128 块（标准砖）
18墙每平方米砖数 = 96 块（标准砖）
37墙每平方米砖数 = 192 块（标准砖）
砖总用量 = 单墙面积 × 每平方米砖数 × (1 + 损耗率)

损耗率参考：
- 标准砖砌筑：3%
- 多孔砖砌筑：3%
- 加气块砌筑：5%（易碎）
- 异形/弧形墙：额外+5%
```

### 砂浆用量计算

```
砌筑砂浆(m³) = 墙体体积(m³) - 砖净体积(m³)

简化估算（标准砖）：
- 12墙每m²用砂浆：约0.056 m³
- 24墙每m²用砂浆：约0.11 m³

水泥用量(kg) = 砂浆量(m³) × 水泥比例 × 水泥密度(1500 kg/m³)
砂用量(m³) = 砂浆量(m³) × 砂比例

以 1:3 水泥砂浆为例（1m³砂浆）：
- 水泥：0.25 m³ × 1500 = 375 kg ≈ 7.5袋（50kg/袋）
- 砂：0.75 m³

以 1:2.5 水泥砂浆为例（1m³砂浆）：
- 水泥：0.286 m³ × 1500 = 429 kg ≈ 8.6袋
- 砂：0.714 m³
```

### 抹灰砂浆估算

```
墙面抹灰(m²) = 墙长(m) × 墙高(m) × 面数
每m²抹灰（厚度15mm）砂浆用量 ≈ 0.018 m³

简化：每100m²抹灰（双面，厚15mm）：
- 水泥(1:3)：约 675 kg（13.5袋/50kg）
- 砂：约 1.35 m³
```

### 瓷砖用量计算

```
单砖面积(m²) = 砖长(m) × 砖宽(m)
瓷砖片数 = 铺贴面积(m²) ÷ 单砖面积(m²) × (1 + 损耗率)

损耗率参考：
- 正铺/直铺：5%
- 工字铺/错位铺：8%
- 菱形铺/斜铺：12-15%
- 人字铺/鱼骨拼：15-20%
- 小空间(<5m²)：额外+5%
- 大板砖(≥600×1200)：8%（破损风险高）

瓷砖胶用量：
- 薄贴法（3-5mm厚）：约 3-5 kg/m²
- 厚贴法（8-10mm）：约 8-10 kg/m²
- 每袋20kg瓷砖胶覆盖面积：
  - 薄贴：4-6 m²/袋
  - 厚贴：2-2.5 m²/袋
```

### 填缝剂用量

```
填缝剂用量(kg/m²) = (砖长+砖宽) × 缝宽 × 缝深 × 填缝剂密度
                  ÷ (砖长 × 砖宽) × 1.5(损耗系数)

简化参考（2mm缝宽，标准深度）：
- 300×300：约 0.5 kg/m²
- 300×600：约 0.35 kg/m²
- 600×600：约 0.25 kg/m²
- 800×800：约 0.2 kg/m²
```
