## 报价策略建议

1. **面积计算**：门窗洞口面积≤0.3m²不计，>0.3m²全扣
2. **起步价**：贴砖不足10m²按10m²计价（小面积起步费）
3. **辅材包**：水泥/砂/瓷砖胶等辅材，按实际用量+5-10%管理费
4. **阳角处理**：海棠角/45度碰角单独收费（15-25元/m）
5. **地面保护**：完工后地面保护措施费用单独列（5-10元/m²）

## 总价估算公式

```
总报价 = 人工费 + 材料费 + 辅材费 + 运输费 + 管理费(5-10%) + 垃圾清运费

人工费 = 各项目工程量(m²) × 对应清工单价
材料费 = 主材实际购买价格（瓷砖/砖等由业主购买则不计）
辅材费 = 水泥/砂/瓷砖胶/防水涂料等实际用量 × 采购价 × 1.05(损耗)
```

> ⚠️ 以上价格仅供参考，各地区差异较大。建议到本地建材市场和业主群了解最新行情。签署合同前明确计价方式（建筑面积/实际施工面积）、付款节点、质保期限。
