# 瓷砖排版指南

## 基本铺贴方式

### 1. 正铺（直铺/对齐铺）
- **方式**：砖与砖对齐，横竖缝成直线
- **损耗率**：约5%
- **优点**：简洁大方、施工最快
- **适用**：所有空间，极简风格首选

### 2. 工字铺（1/2错位铺）
- **方式**：上下排砖错开1/2长度
- **损耗率**：约8%
- **优点**：模仿木地板效果、增加层次感
- **要点**：砖长度方向平直度要好，否则错位处高低差明显

### 3. 三七分/二八分（随意错位铺）
- **方式**：错开30%/20%砖长
- **损耗率**：约8-10%
- **优点**：比工字铺更自然随意
- **适用**：木纹砖、长条砖

### 4. 菱形铺
- **方式**：砖旋转45度铺贴
- **损耗率**：12-15%
- **优点**：视觉延伸感强、小空间显大
- **注意**：起铺点必须精确，否则全屋偏斜

### 5. 人字铺/鱼骨拼
- **方式**：V字形交替排列
- **损耗率**：15-20%
- **优点**：复古、高级感
- **注意**：费用高、施工慢、只适合小面积或特色区域

## 排版核心原则

### 起铺点选择

```
优先级排序：
1. 大空间中心线 → 确保主要区域砖缝对称居中
2. 门厅/入口 → 进门第一眼视觉完整，不出现小条砖
3. 主墙面 → 电视背景墙/沙发背景墙起铺
4. 避开小条砖 → 边角裁切砖宽度≥原砖的1/3
```

### 墙地对缝

- 墙砖从地面砖缝向上延续，视觉统一
- 墙砖压地砖（卫生间必备）：墙砖最后一排后贴，压在地砖上，水不会渗入缝中

### 大板砖排版特殊要求

- 600×1200以上大板砖，排版需提前CAD画图确认
- 起铺点偏差>2mm累积到最后会变成大问题
- 大板上墙必须使用瓷砖胶+背胶双保险
- 大板切割破损率高，多备5-8%损耗

## 排版计算器逻辑

```
输入：空间尺寸(L×W)，砖尺寸(l×w)，铺贴方式，留缝宽度(s)

1. 计算横排砖数 = ceil(L / (l + s))
2. 计算竖排砖数 = ceil(W / (w + s))
3. 边角裁切宽度 = (空间宽度 - 竖排砖数×(w+s) + s)  应≥原砖1/3宽
4. 如边角<1/3，调整起铺点偏移半砖宽度重新计算
5. 损耗率 = 计算方法（铺贴方式）损耗基准
6. 最终片数 = 横排×竖排 × (1 + 损耗率)
```

## 阴阳角处理

| 位置 | 处理方式 | 注意事项 |
|------|---------|---------|
| 阳角(外转角) | 45度海棠角碰角 | 留1-2mm伸缩缝，打美缝剂 |
| 阳角(替代) | 阳角收边条 | 颜色搭配、材质(不锈钢/铝合金/PVC) |
| 阴角(内转角) | 留2mm缝 | 打美缝剂/填缝，不可顶死 |
| 管口/开关 | 开孔器开圆孔 | 切口在遮挡范围内 |

## 排版效果评估

一个"好的排版"做到：
- ✅ 主要区域砖缝居中对称
- ✅ 没有<5cm的窄条砖
- ✅ 墙地对缝（卫生间）
- ✅ 过门石处断开（功能区独立热胀冷缩）
- ✅ 走廊/过道砖缝居中

一个"差的排版"特征：
- ❌ 进门就看到不完整的小条砖
- ❌ 走廊砖缝歪向一边
- ❌ 厨房客厅砖缝对不上
- ❌ 边角裁切宽度不一，视觉效果凌乱
