# 施工工艺标准

## 1. 砌墙施工工艺

### 工艺流程
```
放线定位 → 基层清理 → 砖块浇水湿润 → 排砖撂底 → 
拌制砂浆 → 砌筑(分段分层) → 拉结筋/构造柱施工 → 
勾缝清理 → 养护(≥7天)
```

### 施工要点

| 步骤 | 要求 | 常见错误 |
|------|------|---------|
| 放线 | 弹墙身线+门窗口线，误差≤3mm | 放线不准导致墙体歪斜 |
| 润砖 | 砖含水率15%左右（断面吸水深度≥10mm） | 不润砖→吸走砂浆水分→强度不够 |
| 排砖撂底 | 先干摆一层，调整灰缝（10mm） | 不预排→顶部出现碎砖 |
| 铺浆 | 砂浆饱满度≥80%，每皮砖挂线找平 | 铺浆不饱满→墙体承载力差 |
| 拉结筋 | φ6钢筋，伸入墙内≥500mm，末端弯钩 | 漏放/间距不对 |
| 马牙槎 | 先退后进，每步≤300mm | 顺序搞反影响抗震 |
| 养护 | 砌筑后覆盖浇水养护≥7天 | 不养护→砂浆强度不足 |

### 砌筑质量偏差标准
| 项目 | 允许偏差(mm) |
|------|------------|
| 轴线位移 | ≤10 |
| 墙面垂直度(每层) | ≤5 |
| 表面平整度 | ≤8(清水墙≤5) |
| 水平灰缝平直度 | ≤10(清水墙≤7) |
| 水平灰缝厚度(10皮累计) | ≤8 |

## 2. 抹灰施工工艺

### 工艺流程
```
基层处理 → 浇水湿润 → 挂钢丝网(不同材料交界) → 
打饼(灰饼)冲筋 → 底层抹灰 → 中层抹灰 → 
面层抹灰压光 → 养护
```

### 施工要点

| 步骤 | 厚度(mm) | 砂浆 | 间隔时间 |
|------|---------|------|---------|
| 基层处理 | - | 界面剂/凿毛 | 施工前1天 |
| 底层抹灰 | 12-15 | 1:3水泥砂浆 | - |
| 中层抹灰 | 5-8 | 1:2.5水泥砂浆 | 底层7成干 |
| 面层抹灰 | 3-5 | 1:2水泥砂浆 | 中层7成干 |
| 总厚度 | ≤25(内墙) | - | - |

### 关键控制点
- **挂网**：不同材料交接处挂钢丝网，宽度≥200mm，两侧各搭接≥100mm
- **冲筋**：间距1.2-1.5m，保证大面积平整
- **阴阳角**：做水泥护角，高≥2m，每侧宽≥50mm
- **分层**：每遍厚度≤10mm，一次太厚必开裂
- **养护**：喷水养护≥3天（水泥砂浆）

## 3. 贴墙砖施工工艺

### 工艺流程
```
基层检查(空鼓/平整度) → 排砖预排 → 弹分格线 → 
瓷砖挑选/泡水(瓷片) → 瓷砖切割/倒角 → 
拌制粘结砂浆/瓷砖胶 → 铺贴(从下往上) →
调整检查 → 填缝/美缝 → 清洁保护
```

### 施工要点

| 步骤 | 关键要求 |
|------|---------|
| 基层检查 | 空鼓率≤5%，平整度≤3mm/2m，不合格先处理 |
| 瓷砖泡水 | 瓷片/釉面砖泡水≥2h至不冒泡；玻化砖不泡水但需刷背胶 |
| 弹线分格 | 预排后弹水平线+垂直线，确保非整砖放在次要位置 |
| 铺贴顺序 | 从下往上贴，先贴标准点(第一皮砖) |
| 粘结材料 | 瓷片用1:2水泥砂浆；玻化砖/大板用C2瓷砖胶+背胶 |
| 留缝 | 瓷片1-2mm，玻化砖2-3mm，大板3-5mm |
| 填缝 | 铺贴24h后清理砖缝，48h后填缝/美缝 |
| 阳角 | 45°海棠角碰角，留1-2mm伸缩缝打美缝剂 |

## 4. 贴地砖施工工艺

### 工艺流程
```
基层检查处理 → 找平层施工 → 弹线分格 → 
试铺预排 → 干铺砂浆拌制 → 铺贴(从内向外) →
振实找平 → 调整检查 → 养护(≥2天) → 填缝 → 保护
```

### 干铺法（推荐）
| 步骤 | 操作要求 |
|------|---------|
| 找平层 | 水泥砂浆1:3，厚度30-50mm |
| 干硬性砂浆 | 水泥:砂=1:3，手握成团落地即散 |
| 结合层 | 纯水泥浆或1:1稀浆，铺在干砂浆上 |
| 铺贴 | 砖背面刮水泥浆，放在干砂浆上橡胶锤敲实 |
| 平整度 | 2m靠尺检查，相邻砖高差≤0.5mm |

### 排水坡度（卫生间/阳台）
- 地漏处为最低点，坡度≥1%（即每米高差≥10mm）
- 整个地面向地漏方向放坡，不得有积水
- 地漏周围50cm范围内坡度加大至2%

## 5. 防水施工工艺

### 工艺流程
```
基层清理 → 节点加强处理(管根/墙角) → 
涂刷第一遍防水 → 干燥 → 涂刷第二遍防水 → 
养护(≥24h) → 闭水试验(24h) → 防水保护层
```

### 节点加强
- 管根：凿开V型槽→嵌填密封膏→做附加层
- 阴角：做R角圆弧→附加层防水≥300mm宽
- 门槛石：侧面+底部做防水坎

### 防水高度标准
| 区域 | 地面防水 | 墙面防水高度 |
|------|---------|------------|
| 卫生间淋浴区 | ✓ | ≥1800mm |
| 卫生间其他区 | ✓ | ≥300mm |
| 厨房 | ✓ | ≥300mm |
| 阳台 | ✓ | ≥100mm |
| 洗衣机位 | ✓ | ≥1200mm |

### 闭水试验标准
- 蓄水深度：20-30mm
- 蓄水时间：≥24小时
- 验收标准：水位无明显下降，楼下顶面及管道周边无渗漏痕迹

## 6. 地面找平施工工艺

### 工艺流程
```
基层清理 → 标高控制(打点/冲筋) → 
浇水湿润 → 刷界面剂/水泥浆 → 铺设砂浆 →
刮平压实 → 压光收面 → 养护(≥7天)
```

### 找平层厚度
- 水泥砂浆找平：≥20mm
- 细石混凝土找平：≥30mm
- 自流平找平：3-5mm（需先做基层找平）

### 质量要求
- 平整度：≤3mm/2m（普通）/≤2mm/2m（铺木地板前）
- 表面无起砂、无空鼓、无裂缝
- 与基层粘结牢固，无脱层
