# 常见质量问题诊断与解决

## 1. 瓷砖空鼓

### 现象
用响鼓锤敲击瓷砖，发出"咚咚"空心声；严重时瓷砖边角翘起。

### 原因分析（按可能性排序）

| 原因 | 占比 | 说明 |
|------|------|------|
| 基层空鼓/疏松 | 30% | 基层未处理好，瓷砖跟着空 |
| 铺贴砂浆不饱满 | 25% | 砖背面砂浆覆盖率<80% |
| 瓷砖未泡水 | 20% | 瓷片吸水太快，吸走砂浆水分 |
| 干铺砂浆水分不足 | 15% | 干铺法砂浆太干，无法充分水化 |
| 收缩应力 | 10% | 水泥收缩+温度变化导致脱粘 |

### 解决方案

| 空鼓程度 | 处理方法 | 注意事项 |
|---------|---------|---------|
| 边角小空鼓(<20%) | 灌浆法：沿砖缝注射水泥浆 | 空鼓面积不能太大 |
| 中间空鼓/大面积 | 撬砖重铺：清除旧砂浆→基层处理→重贴 | 备同批次砖2-3片 |
| 整面墙大面积空鼓 | 全部铲除→基层重新拉毛→重贴 | 排查基层质量 |

### 预防措施
- ✅ 基层空鼓、疏松先处理再贴砖
- ✅ 瓷片提前泡水≥2小时
- ✅ 贴砖时10字交叉法揉压，使砂浆饱满
- ✅ 大板砖必须用双保险（瓷砖胶+背胶）
- ✅ 贴砖完成24h后轻敲自检，及时补救

## 2. 瓷砖开裂

### 现象
砖面出现裂纹，从细如发丝到贯穿性断裂。

### 原因分析

| 原因 | 判断依据 |
|------|---------|
| 基层沉降 | 裂缝贯穿多块砖，沿建筑结构延伸 |
| 温度应力 | 裂缝规则、平行排列 |
| 砖质量问题 | 裂缝在铺贴前已有暗伤 |
| 切割损伤 | 裂缝从切割边开始 |
| 外力冲击 | 局部碎裂，呈放射状 |

### 解决方案
- **沉降裂缝**：先处理结构问题（加固/注浆），再换砖
- **温度裂缝**：换砖时加大留缝宽度(3-5mm)
- **质量问题**：整批排查，问题砖全部更换
- **切割损伤**：加强切割工艺，切口打磨
- **冲击破损**：换砖+加保护垫

## 3. 墙面掉砖/墙砖脱落

### 现象
整块或数块瓷砖从墙面脱落，严重时大面积脱落。

### 原因分析

| 原因 | 特征 |
|------|------|
| 基层强度不够 | 脱落后基层砂浆也掉落 |
| 玻化砖未刷背胶 | 砖背面干净，粘结层附着在墙上 |
| 瓷砖胶质量差 | 粘结层粉化、强度低 |
| 防水层上直接贴砖 | 光滑防水面粘结力不够 |
| 瓷砖胶施工不正确 | 未用齿形刮刀，空气排不出 |

### 解决方案
- **全部铲除**：脱落区域+周边空鼓区域全部清除
- **基层处理**：凿毛/拉毛/刷界面剂
- **玻化砖/大板砖**：必须刷背胶+瓷砖胶双保险
- **防水层贴砖**：防水层干透后刷界面剂拉毛
- **正确施工**：齿形刮刀45-60°角，单次刮胶面积≤1m²

## 4. 墙面/地面渗水

### 现象
背面墙体潮湿、发霉，或楼下天花板滴水。

### 原因分析

| 原因 | 排查方法 |
|------|---------|
| 防水层破损 | 闭水试验时水位明显下降 |
| 管根处理不到位 | 渗水集中在管道周边 |
| 地漏周边漏水 | 地漏处防水层断开 |
| 门槛石处渗水 | 门槛石外侧地面潮湿 |
| 墙地面交接处 | 交接处防水上翻不够 |

### 解决方案

| 渗水位置 | 解决方案 |
|---------|---------|
| 管道根部 | 凿开→清理→嵌填密封膏→附加层防水→闭水试验 |
| 地漏周边 | 更换地漏周边防水，确保防水卷进地漏内壁 |
| 门槛石 | 门槛石底部+两侧都做防水，形成闭合 |
| 整面渗水 | 铲除瓷砖→重做防水(2-3遍)→闭水试验→重贴砖 |

## 5. 抹灰开裂

### 现象
抹灰面出现裂纹，从细裂纹到结构裂缝不等。

### 分类与处理

| 裂缝类型 | 特征 | 处理方案 |
|---------|------|---------|
| 收缩裂纹（龟裂） | 细密网状、表面浅层 | 表面打磨→刷界面剂→薄批面层 |
| 基层交界裂缝 | 直线状、在梁柱与砖墙交界处 | 切割V型槽→填弹性密封胶→挂网批灰 |
| 结构裂缝 | 宽度>0.5mm、贯穿性 | 判断是否结构性→报业主/监理→加固处理 |
| 空鼓裂缝 | 敲击有空响 | 铲除空鼓区→挂网重抹 |

## 6. 砂浆粉化/强度不够

### 现象
砂浆疏松、一捻就碎，指甲能划出痕迹。

### 原因
- 水泥过期/受潮
- 配比中水泥太少
- 加水过多
- 冬季施工未保温
- 养护不够

### 解决方案
- 确认水泥是否在保质期内（出厂≤3个月）
- 严格按配比，不凭感觉
- 控制加水量（湿性砂浆以刮刀挂浆不流挂为准）
- 低于5℃停止水泥砂浆施工
- 砌筑/抹灰后覆盖浇水养护≥7天

## 问题快速诊断流程图

```
敲击发现问题
├── 空响 → 用粉笔标记空鼓区 → 判断面积
│   ├── <20%边角 → 灌浆修补
│   └── >20%或中间 → 返工重铺
├── 实响但有开裂 → 判断裂缝类型
│   ├── 细裂纹 → 表面修补
│   ├── 贯穿多层 → 排查结构沉降
│   └── 规则平行 → 温度裂缝，重铺+加大留缝
└── 渗水痕迹 → 定位水源
    ├── 管口周边 → 管根防水加强
    ├── 地板边缘 → 门槛石/墙地交接处理
    └── 中间大面积 → 整体防水重做
```
