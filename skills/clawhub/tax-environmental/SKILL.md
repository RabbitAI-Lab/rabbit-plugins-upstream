## 能为你做什么（环保税与碳四大场景）
---

### 一、应税污染物识别与监测核算
- 🧪 **全口径登记**：大气/水/固废/噪声四类应税污染物完整识别与登记
- ⚖️ **核算方法**：自动监测/机构监测/排污系数方法合规，固废按产生量减贮存处置量
- ⚠️ **高频风险**：应税污染物漏报导致补税+滞纳金

**典型问法：**
```
"哪些污染物要交环保税？"
"环保税怎么核算？"
```

### 二、减排减免判定与申报缴纳
- 🌿 **减免门槛**：任一排放口浓度低于标准30%/50%及达标免税证据归集
- 📅 **按季申报**：向排放地税务机关申报缴纳，未计量不得扣减
- ⚠️ **风险点**：任一排放口超标即不予减征，减免条件不符被补税

**典型问法：**
```
"环保税减排减免怎么判定？"
"排放口浓度达标能减征吗？"
```

### 三、碳市场配额清缴与碳资产
- 🏭 **重点排放单位**：名录、报告与清缴时限管理
- 💱 **配额/CCER交易**：按"其他权益性无形资产"缴纳增值税并开票
- ⚠️ **风险点**：配额清缴不足按均价5–10倍罚款并核减

**典型问法：**
```
"碳排放配额怎么清缴？"
"CCER交易要交增值税吗？"
```

### 四、碳排放数据质量与造假防控
- 📒 **台账管理**：原始记录台账保存≥5年，禁造假
- 🚨 **处罚预警**：数据造假按条例处违法所得5–10倍罚款，情节严重禁业
- ⚠️ **风险点**：排放数据造假处罚显著加重，须真实可核查

**典型问法：**
```
"碳排放数据造假有什么后果？"
"碳排放台账怎么建？"
```

## 重要提示与边界声明

**重要提示**
1. **污染物须全口径**：大气/水/固废/噪声四类应税污染物须完整登记，不得漏报。
2. **数据须真实**：排放监测数据与碳排放原始台账须真实可核查，严禁造假。
3. **减免须达标**：任一排放口浓度超标即不予减征，减排减免以监测证据为准。
4. **以官方为准**：环保税核定征收办法由各省制定，碳交易增值税依税务总局执行口径，具体以主管税务机关与生态环境部门口径为准。

**边界（本技能不做的）**
- **不代办**：环保税申报、碳排放权注册登记与清缴系统等需登录操作的事项
- **不代理**：碳排放数据核查申诉等需执业资质的事务
- **不担保**：环保税核定、碳配额分配与清缴结论等最终以主管部门为准

**服务说明**
- 每次提问都能获得完整闭环：智能问答 → 结构化结果 → 政策依据溯源 → 真实案例关联 → 实操辅导 → 反馈评价 → 合规报告
