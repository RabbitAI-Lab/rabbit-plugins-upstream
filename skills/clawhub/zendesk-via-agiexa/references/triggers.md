# Zendesk triggers via Agiexa (2)

Preview only - events that will be able to start an agent run after Agiexa launches (November 2026).

| Trigger | When it fires |
| --- | --- |
| `ZENDESK_NEW_USER_TRIGGER` | Triggered when a new user is created in Zendesk |
| `ZENDESK_NEW_ZENDESK_TICKET_TRIGGER` | Triggers when a new ticket is created in a specified Zendesk view |
