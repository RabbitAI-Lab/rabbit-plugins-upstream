# 范文与名师点评蒸馏方法

本项目知识库只沉淀方法论，不保存大段原文。满分作文和名师点评用于提炼分析角度、训练方法和表达方式，不能作为直接改写孩子作文的素材。

## 蒸馏步骤

1. **只看方法。** 从范文或点评中找可复用的写作方法，例如放慢重点情节、用动作表现情绪、首尾呼应。
2. **提炼判断标准。** 说明这个方法为什么有效，以及适合哪类作文。
3. **转化为家长语言。** 去掉专业术语，解释家长如何观察、如何提问。
4. **设计引导问题。** 把方法变成 2-4 个孩子能回答的问题。
5. **给出极简示例。** 示例必须是自写的短句或片段，不能抄录原范文。
6. **对应一个小练习。** 练习控制在 3-5 分钟，避免增加孩子负担。

## 方法卡格式

```markdown
### 方法名：动作表现情绪

适用类型：记事、写人
适用年级：三至六年级

方法要点：
用身体动作和眼前画面表现情绪，避免只写“我很紧张”“我很开心”。

判断方式：
如果孩子只写情绪词，但没有动作、眼神、声音或身体感受，可以引导补充。

引导问题：
1. 当时你的手放在哪里？
2. 你的眼睛看到了什么？
3. 你听到了什么声音？

极简示例：
我站在台上，手指不停捏着衣角，台下的人好像都变成了一片模糊的影子。

家长解释：
直接说“我很紧张”只是结论，加上手和眼睛的细节后，读者能自己感受到紧张。

小练习：
说一件今天紧张或开心的小事，再补一句“当时我的手……”或“当时我看见……”。
```

## 收集规则

- 外部资料可以临时放入项目外的原始资料区，但整理后不保存大段原文。
- 不保存来源不明的长段范文。
- 不引用名师身份作为权威背书，只吸收点评方法。
- 不把“满分”“优秀”作为评价孩子作文的标准。
- 不因范文风格成人化而要求孩子模仿华丽辞藻。
