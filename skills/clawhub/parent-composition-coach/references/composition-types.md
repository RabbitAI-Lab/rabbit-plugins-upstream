# 作文类型与家长指导方法

先根据题目、老师要求和正文判断类型。类型不明确时，给出最可能的判断和理由，或询问家长。所有类型仍从内容、结构、语言、基础规范四方面分析。

## 写人

**判断重点：** 围绕一个人的特点、品质、关系或变化展开。

**常见问题：** 只写评价词，例如“他乐于助人”“妈妈很辛苦”，缺少具体事例。

**引导问题：**

- 他做的那件事，你亲眼看到了什么？
- 他说了哪句话让你印象最深？
- 他做这件事时有什么动作或表情？
- 这件事为什么让你觉得他有这个特点？

**修改优先级：** 先用一个具体事例支撑人物特点，再补充动作、语言或神态。

## 记事

**判断重点：** 围绕一件或一组相关事件，有起因、经过和结果。

**常见问题：** 流水账、重点情节写太快、缺少感受变化。

**引导问题：**

- 这件事里最紧张、最有趣或最重要的一刻是哪一刻？
- 那一刻你看到了什么、听到了什么？
- 你的动作是什么？心里在想什么？
- 事情结束后，你的想法有什么变化？

**修改优先级：** 找到最重要的一幕，让孩子把那一刻放慢写具体。

## 写景

**判断重点：** 描写自然或生活场景，通常有观察顺序。

**常见问题：** 形容词堆砌，景物特征不明显，缺少观察角度。

**引导问题：**

- 你最先看到什么？接着看到什么？
- 这个地方最特别的一样东西是什么？
- 你听到了什么声音？闻到什么味道？
- 看到这些景物时，你想到了什么？

**修改优先级：** 先写清楚观察顺序，再选择最有代表性的景物展开。

## 状物

**判断重点：** 描写具体物品、动物或植物，写外形、习性、用途或与人的互动。

**常见问题：** 罗列特点，缺少与物的真实关系。

**引导问题：**

- 它的外形有什么最特别的地方？
- 它平时怎么动、怎么吃、怎么响？
- 你和它之间发生过哪件小事？
- 你为什么喜欢或在意它？

**修改优先级：** 围绕主要特点选择材料，补充一次真实互动。

## 想象作文

**判断重点：** 基于题目、图画或设定展开想象，常见如未来、童话、科幻、变形记。

**常见问题：** 想象很多但缺少因果，设定前后不一致，或脱离题目要求。

**引导问题：**

- 你的想象世界里有什么特别规则？
- 这件事为什么会发生？
- 人物遇到什么困难？他怎么解决？
- 结局和开头的世界设定是否一致？

**修改优先级：** 先让想象有清楚的起因、发展和结果，再增加一处生动细节。

## 读后感

**判断重点：** 由阅读内容引出个人理解和联系。

**常见问题：** 大量复述原文，感受空泛，缺少文本依据或个人经历。

**引导问题：**

- 书或文章里哪一句话、哪一件事最打动你？
- 这让你想到自己的什么经历？
- 你的想法和原来有什么不同？
- 你以后会怎么做？

**修改优先级：** 压缩复述，选择一个感受，用文本依据和个人经历展开。

## 应用文

**判断重点：** 有明确对象和用途，如书信、日记、通知、倡议书、留言条。

**常见问题：** 格式缺失、称呼不当、事项不清楚、语气不合对象。

**家长检查点：**

- 称呼、问候、正文、祝语、署名、日期是否齐全。
- 是否交代清楚时间、地点、事项和对象。
- 语气是否符合使用场景。
- 字数是否简洁。

**修改优先级：** 先补格式和关键信息，再调整语气。

## 看图写话

**判断重点：** 主要出现在低年级，根据一幅或多幅图写内容。

**常见问题：** 图序看错、人物动作猜错、只写图上有什么，缺少合理想象。

**引导问题：**

- 第一幅图里有谁？他在哪里？
- 接下来发生了什么？
- 最后一幅图说明结果是什么？
- 你觉得人物心里会想什么？

**修改优先级：** 先按图序讲完整，再补一句人物动作或想法。

## 类型冲突处理

如果正文与题目要求的类型不一致：

1. 先指出类型偏差，例如题目要求记事，但正文更像介绍物品。
2. 说明哪几段偏离要求。
3. 给出最小改动方向，尽量保留孩子已有内容。
4. 若偏差太大，帮助家长转化为孩子能听懂的改题说明，不直接代写。
