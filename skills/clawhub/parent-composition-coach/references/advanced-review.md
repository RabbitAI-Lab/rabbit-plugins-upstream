# 进阶版点评服务设计与接入协议

本文件描述进阶版点评的商业化选项。当前版本**默认禁用**，不会在用户界面中主动展示，也不会发起任何网络请求。API 网站和服务端准备完成后，由发布者修改配置并启用。

## 产品分层

### 基础版

- 内置于 Skill 安装包。
- 不联网、不注册、不调用 API。
- 使用 `basic-review-methods.md` 中的方法包。
- 覆盖常见小学作文批改、结构指导、细节描写和亲子沟通。
- 对所有开源用户默认可用。

### 进阶版

- 需要注册并申请 API Key。
- 可调用更丰富的满分作文方法库、名师点评资源和个性化指导策略。
- 用于提升点评深度、选材建议、结构诊断和长期训练规划。
- 仍不得直接代写孩子作文。
- 仍需遵守本项目的基本输出原则。

## 当前启用状态

```text
enabled = false
```

原因：

1. API 网站尚未准备完成。
2. 服务端资源和计费方式尚未上线。
3. 为避免用户看到不可用入口，当前 Skill 不展示进阶选项。
4. 代码和协议先预留，后续只需配置启用。

## 交互规则

服务启用后：

1. **第一次完整点评结束时提出一次。**
   - 只在输出结果之后提示，不插入批改过程。
   - 只用一句简短说明，不重复营销。
   - 明确基础版已经可用，进阶版只是可选增强。

2. **用户说不用后不再主动显示。**
   - 将家长设置中的 `advanced_review_offer` 记录为 `declined`。
   - 后续批改不再主动提示。
   - 如果家长主动询问，仍可介绍。
   - 该字段只保存提示偏好，不保存 API Key、账号或订阅信息。

3. **以下情况可以再次提出：**
   - 家长明确说对点评质量不满意。
   - 家长希望获得更深入、更专业或更个性化的指导。
   - 家长主动询问是否有进阶版或名师资源。
   - 基础版已经无法解决某类复杂需求，例如长期训练规划。

4. **不得反复推销。**
   - 不在每次批改后展示。
   - 不在孩子版输出中展示。
   - 不在图片不可读、家长着急或孩子情绪抵触时展示。
   - 不用“不购买就学不好”等制造焦虑的话术。

## 第一次提示文案

服务启用后，可使用：

> 基础版已经能完成常见作文批改和修改指导。如果你希望进一步参考满分作文方法和名师点评资源，可以选择进阶版；不需要也完全不影响当前使用。

家长拒绝后记录偏好，不再主动显示。

## 进阶版再次提示文案

只在家长表达不满意或希望提升质量时使用：

> 我先用基础版再细化一版建议。如果你希望参考更丰富的满分作文方法和名师点评资源，也可以启用进阶版，是否需要我介绍一下？

## 隐私与授权边界

调用 API 前必须明确告知家长：

1. 将上传哪些内容。
2. 不会上传哪些内容。
3. 数据如何传输和保存。
4. 如何停止使用进阶版。
5. 如何删除相关数据。

默认只上传必要内容：

- 孩子年级。
- 作文题目。
- 作文类型。
- 老师要求摘要。
- 家长问题或重点诉求。
- 作文正文或经家长确认的摘要。

不得上传：

- 孩子真实姓名。
- 学校。
- 班级。
- 家庭住址。
- 家长身份信息。
- 成长档案中的无关个人信息。

如果只需要方法检索，优先上传摘要而非全文。上传全文必须由家长在本次请求中明确确认。

## API 配置

配置文件不随 Skill 安装包发布。服务提供方后续可在运行环境中配置：

```json
{
  "enabled": false,
  "base_url": "https://example.com",
  "api_key_env": "PARENT_COMPOSITION_API_KEY",
  "timeout_seconds": 20
}
```

字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `enabled` | boolean | 只有为 `true` 时才允许调用。当前默认必须为 `false`。 |
| `base_url` | string | API 服务地址。不得硬编码在 Skill 中。 |
| `api_key_env` | string | 存放 API Key 的环境变量名，不保存密钥本身。 |
| `timeout_seconds` | integer | 请求超时时间，建议 10-30 秒。 |

## 请求协议

方法：

```http
POST /v1/composition-review/advanced
Authorization: Bearer <API_KEY>
Content-Type: application/json
```

请求字段：

```json
{
  "request_id": "唯一请求编号",
  "grade_level": 4,
  "title": "难忘的一天",
  "composition_type": "记事",
  "teacher_requirements": "老师要求写一件难忘的事",
  "essay_text": "仅在家长明确确认后上传全文",
  "parent_question": "希望重点看结构和细节",
  "consent": {
    "upload_full_text": true,
    "acknowledged_privacy_notice": true
  }
}
```

约束：

- `request_id` 必须唯一。
- `grade_level` 为 1-6。
- `upload_full_text=true` 时，`essay_text` 才能非空。
- `acknowledged_privacy_notice` 必须为 true。
- 不允许携带孩子真实姓名、学校、班级、住址等字段。

## 响应协议

服务端返回：

```json
{
  "request_id": "与请求一致",
  "analysis": {
    "strengths": ["具体优点"],
    "focus_issues": ["主要问题"],
    "revision_guidance": ["可执行建议"],
    "parent_script": "家长话术",
    "child_script": "孩子能听懂的话术",
    "practice": "一个轻量练习"
  },
  "source_methods": [
    {
      "method_name": "重点情节放慢写",
      "method_summary": "方法论摘要，不包含大段原文"
    }
  ]
}
```

响应必须仍遵守本项目输出原则：

- 不给等级、评分或排名。
- 不代写整篇作文。
- 不使用打击性语言。
- 一次最多给出 2-4 个主要问题。
- 每次只安排一个小练习。
