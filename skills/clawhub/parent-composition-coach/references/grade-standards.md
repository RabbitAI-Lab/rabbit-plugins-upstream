# 小学家长版年级标准

本文件把小学写作要求转化为家长能理解的标准。使用时先看年级，再结合题目、作文类型和老师要求综合判断。不要给等级、分数或排名。

## 一至二年级

**发展重点：** 愿意写、写完整、写清楚。

### 家长观察点

- 是否愿意表达一件真实的事或一幅图的内容。
- 能否把一句话说完整。
- 图片顺序是否看懂。
- 常用字、标点是否明显错误。
- 是否写出简单感受，例如开心、害怕、喜欢。

### 常见问题

- 只写“很好玩”“很开心”，缺少具体画面。
- 看图顺序跳跃。
- 句子残缺，例如缺主语或缺动作。
- 句号、逗号使用不稳定。

### 修改优先级

1. 先保护表达兴趣，不急于追求辞藻。
2. 让孩子把一件事按顺序说完整。
3. 只处理最明显的错字、漏字和标点。
4. 用提问引导一个具体细节，例如“你当时看到了什么？”

## 三至四年级

**发展重点：** 段落清楚、事情完整、加入具体描写。

### 家长观察点

- 事件是否有开头、经过和结果。
- 是否分成合理段落。
- 经过部分是否写清关键变化。
- 是否加入动作、语言、神态或心理。
- 中心是否能让读者明白。
- 语句是否通顺，标点和错字是否影响阅读。

### 常见问题

- 流水账：每件事都写，但都不具体。
- 重点情节太快，铺垫太长。
- 只有结论，没有画面，例如“我很开心”“他很善良”。
- 段落之间跳跃。
- 结尾突然总结，缺乏自然收束。

### 修改优先级

1. 找到全文最重要的一段，让它慢下来。
2. 引导孩子补充动作、语言、神态或心理中的一种。
3. 检查开头是否进入太慢。
4. 每次只围绕一个中心修改。

## 五至六年级

**发展重点：** 中心明确、选材恰当、详略有取舍、表达有真实感。

### 家长观察点

- 中心是否明确，材料是否服务中心。
- 是否选择了较有个人特点的材料。
- 详略是否合理，重点是否充分展开。
- 开头、结尾和过渡是否自然。
- 描写和修辞是否服务表达，而不是堆砌。
- 情感是否真实，思考是否有具体依据。

### 常见问题

- 材料普通或重复，缺少个人经历。
- 想写的东西太多，导致中心分散。
- 重点不突出，每段平均用力。
- 语言追求华丽，但缺少真实细节。
- 结尾强行升华，与前文脱节。
- 读后感复述原文太多，个人感受太少。

### 修改优先级

1. 先确定这篇文章最想表达什么。
2. 删除或压缩与中心关系弱的材料。
3. 展开最有个人特点的一处。
4. 让结尾从真实感受出发，不强行拔高。

## 使用提示

- 年级只是基准，不是限制。写作基础较弱的孩子先降低难度，写作较强的孩子可适当提高要求。
- 一至二年级优先保护兴趣；三至四年级优先建立具体描写；五至六年级优先训练中心和详略。
- 老师的题目要求优先于通用标准。
- 如果家长未提供年级，必须先询问；确实无法询问时，只给通用建议，并说明标准可能随年级变化。
