# 百度知道回答自动发布

> 帮你把已经写好的回答内容，自动填到百度知道的指定问题里并提交发布，省去手动复制粘贴和来回切换页面的麻烦。

---

## 这个技能能帮你做什么

- 把本地保存的回答文稿，自动填写到百度知道的指定问题下并发布
- 自动使用你已登录的百度账号，不需要在技能里再输一次密码
- 遇到登录过期、滑块、短信验证码时，会暂停等你手动处理，不会自动绕过
- 同一个问题重复运行不会重复发布，避免不小心多发
- 发布完成后，会清楚告诉你成功、待审核还是失败，以及失败原因

---

## 适合什么场景

- 内容运营、品牌推广团队需要批量在百度知道下回答行业相关问题
- 已经准备好了标准化的回答文稿（FAQ、产品说明、专业解答等），需要快速发布到对应问题下
- 希望减少手动复制粘贴、切换账号、等待页面加载的重复劳动
- 需要留存每次发布的记录，方便后续对账或复盘

---

## 使用前需要准备什么

- 在匠厂客户端已添加百度知道账号（扫码或手动登录一次，账号信息由匠厂统一管理）
- 本地已准备好回答文稿文件（.md 或 .txt 均可），内容是最终要发布的回答正文
- 已知目标问题的百度知道链接（形如 `https://zhidao.baidu.com/question/XXXXXXX`）
- 网络可正常访问百度知道，账号未被风控限制
- 首次使用时，可能需要在浏览器弹出后手动完成登录或验证码

---

## 执行后你会得到什么

- 任务是否成功完成的明确结论
- 使用的账号编号、问题链接、回答文稿路径
- 发布状态：成功 / 待审核 / 失败
- 平台返回的提示信息（如「提交成功」「内容审核中」等）
- 当次发布的记录编号，便于后续查询
- 如果是重复运行同一幂等键，会直接告诉你「已发布过，无需重复操作」

---

## 注意事项

- 请确认回答文稿内容符合百度知道社区规范，避免广告、违规内容导致账号被封
- 同一账号短时间内频繁发布可能触发风控，建议合理控制频率
- 如果遇到滑块验证、短信验证码，技能会暂停等待，请及时在弹出的浏览器中完成
- 回答内容一旦提交成功，可能无法直接撤回，请发布前仔细核对
- 涉及医疗、法律、金融等敏感领域的回答，请确保内容专业、合规
- 不建议在未核对文稿内容的情况下批量发布

## 常见问题

### 为什么任务执行到一半需要我操作？

> 可能是百度账号登录过期、触发了滑块或短信验证码，或者页面出现了二次确认。请根据 Agent 的提示，在弹出的浏览器窗口中完成相应操作，技能会自动继续。

### 为什么发布状态显示「待审核」？

> 百度知道对部分回答会进行内容审核，这是平台正常流程。待审核的回答通常会在一段时间后自动通过或被驳回，具体以百度知道平台规则为准。

### 如果发布失败了怎么办？

> Agent 会告诉你失败原因（如内容为空、编辑器未就绪、提交超时等）。请根据提示修改回答文稿或检查账号状态后重试。同一幂等键的重试不会产生重复发布。

### 可以一次发布到多个问题吗？

> 当前每次任务只发布到一个问题。如需批量发布，可以分多次运行，或联系开发者评估批量能力。

### 发布记录在哪里查看？

> 所有发布记录保存在本地数据库中，可以通过匠厂客户端的「数据管理」页面查看，也可以让 Agent 帮你查询最近的发布记录。
