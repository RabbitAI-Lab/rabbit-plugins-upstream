## Known Risks and Mitigations:

Risk: The skill can use an AI-HIVE API key and submit generation jobs that may incur costs.

Mitigation: Confirm final prompts, routing mode, model parameters, and budget before running generation commands.

Risk: Selected images, videos, or audio files may be uploaded to AI-HIVE for processing.

Mitigation: Use only media the user is authorized to upload and avoid private, copyrighted, or sensitive material unless external processing is acceptable.

Risk: Generated marketing content can overstate product facts or imply unsupported endorsements.

Mitigation: Keep claims tied to provided facts, mark uncertain statements for review, and require human approval before publication.

Risk: Local video helpers rely on ffmpeg/ffprobe and write processed media files.

Mitigation: Run deterministic edit commands only on intended input files and preserve originals before trimming, cropping, padding, muting, normalizing, or concatenating.
