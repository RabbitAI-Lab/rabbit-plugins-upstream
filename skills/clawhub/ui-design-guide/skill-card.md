## Description:

Use when users need visual direction, interface hierarchy, layout decisions, design specifications, or prototypes before implementing a Web or mini program UI.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and interface designers use this skill to define visual direction, hierarchy, color, typography, layout strategy, and prototype expectations before building web or mini program interfaces.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may lead an agent to download remote UI assets into a project.

Mitigation: Use trusted HTTPS asset sources, avoid private or internal URLs, and review downloaded assets before shipping.

Risk: Design or implementation proposals could introduce incorrect or misleading UI guidance.

Mitigation: Review generated design specifications and any produced interface code before deployment.
