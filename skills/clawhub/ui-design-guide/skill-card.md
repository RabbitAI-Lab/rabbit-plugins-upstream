## Description: <br>
Use when users need visual direction, interface hierarchy, layout decisions, design specifications, or prototypes before implementing a Web or mini program UI. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[binggg](https://clawhub.ai/user/binggg) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and design-focused coding agents use this skill to establish interface direction, hierarchy, layout, typography, color, and prototype guidance before building Web or mini program UIs. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Rigid visual-style rules could override brand systems, platform conventions, accessibility needs, or non-Latin script support. <br>
Mitigation: Review the design specification before implementation and narrowly override the default prohibitions when approved brand, accessibility, localization, or platform requirements apply. <br>
