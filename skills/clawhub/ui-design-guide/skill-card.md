## Description:

Use when users need visual direction, interface hierarchy, layout decisions, design specifications, or prototypes before implementing a Web or mini program UI.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and designers use this skill to define visual direction, interface hierarchy, aesthetic constraints, and prototype guidance before implementing web or mini-program UI.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may tell an agent to fetch external visual assets into a project.

Mitigation: Keep downloads limited to trusted HTTPS sources and review downloaded files before use.

Risk: The style rules may conflict with an existing brand, design system, or accessibility requirement.

Mitigation: Treat real project brand, design-system, and accessibility constraints as higher-priority requirements and document narrow overrides.
