## Description:

Helps agents define visual direction, interface hierarchy, and design specifications before building web or mini-program interfaces.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT-0

## Use Case:

Designers and frontend developers use this skill to establish an aesthetic direction, design specification, and interface prototype before implementing web or mini-program UIs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The opinionated workflow can influence a broad range of UI tasks.

Mitigation: Use it only when a new visual direction is needed, and review proposed design choices against project requirements.

Risk: Suggested shell commands may download external assets into a project.

Mitigation: Review download commands and approve each asset URL before running them.
