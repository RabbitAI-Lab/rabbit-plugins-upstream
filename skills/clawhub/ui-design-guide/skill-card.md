## Description:

Use when users need visual direction, interface hierarchy, layout decisions, design specifications, or prototypes before implementing a Web or mini program UI.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and product teams use this skill to define a concrete visual direction, interface hierarchy, palette, typography, layout strategy, and self-audit checklist before producing Web or mini program UI work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill's rigid visual rules could conflict with a real product design system, localization need, accessibility requirement, or platform convention.

Mitigation: Treat the skill as design guidance and override its defaults when verified product, accessibility, localization, or platform constraints require different fonts, colors, icons, or layouts.

Risk: Design proposals could introduce incorrect or misleading UI guidance if applied without review.

Mitigation: Review generated design specifications and scan resulting implementation work before deployment.
