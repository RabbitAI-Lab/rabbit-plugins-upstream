## Description: <br>
Use when users need visual direction, interface hierarchy, layout decisions, design specifications, or prototypes before implementing a Web or mini program UI. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[binggg](https://clawhub.ai/user/binggg) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and design-focused agents use this skill to establish visual direction, hierarchy, color, typography, and layout before building web or mini program interfaces. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill applies strongly opinionated UI design preferences that may conflict with established brand, accessibility, localization, or approved design-system requirements. <br>
Mitigation: Review the proposed design direction against project constraints and override the skill's defaults when approved brand, accessibility, localization, or design-system requirements apply. <br>
Risk: Generated design specifications, code, or shell-command audit suggestions may be incomplete or unsuitable for the target project. <br>
Mitigation: Review generated files and commands before relying on them, and run the project's normal design, accessibility, and code checks before deployment. <br>
