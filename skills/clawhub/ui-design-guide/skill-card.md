## Description:

Use when users need visual direction, interface hierarchy, layout decisions, design specifications, or prototypes before implementing a Web or mini program UI.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and design-focused agents use this skill to choose visual direction, interface hierarchy, layout, typography, and prototype guidance before implementing web or mini program interfaces.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill's opinionated design rules may conflict with brand standards, accessibility requirements, locale or script support, or an approved design system.

Mitigation: Treat those external requirements as higher priority and override the skill's default visual rules when they conflict.

Risk: The skill may steer agents toward distinctive aesthetics and away from common fonts, colors, emojis, and centered layouts even when a more conventional interface is required.

Mitigation: Review the design specification before implementation and narrow or replace the aesthetic constraints for the target product.
