## Description:

Use when users need visual direction, interface hierarchy, layout decisions, design specifications, or prototypes before implementing a Web or mini program UI.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and designers use this skill to define interface direction before implementation, including purpose, aesthetic direction, color palette, typography, layout strategy, and platform-specific next steps for Web or mini program UI work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated guidance may recommend downloading remote UI assets.

Mitigation: Review remote asset URLs before allowing shell downloads, prefer HTTPS sources, and avoid private or internal hosts.

Risk: The skill has strict visual preferences that may conflict with brand, locale, platform, or accessibility requirements.

Mitigation: Override the visual defaults when project constraints require it, and keep overrides explicit in the design specification.
