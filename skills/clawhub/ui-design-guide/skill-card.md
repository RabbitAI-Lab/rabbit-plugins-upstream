## Description:

Use when users need visual direction, interface hierarchy, layout decisions, design specifications, or prototypes before implementing a Web or mini program UI.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and design-focused agents use this skill to define a visual direction, interface hierarchy, layout strategy, palette, typography, and prototype plan before implementing Web or mini program user interfaces.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill allows agents to download public web assets with shell commands during UI work.

Mitigation: Use trusted HTTPS sources only, avoid private or internal URLs, keep downloads scoped to project asset paths, and review downloaded files before production use.
