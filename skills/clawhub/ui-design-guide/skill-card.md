## Description:

Guides agents through visual direction, interface hierarchy, layout decisions, design specifications, and prototypes before implementing a web or mini program UI.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and design-focused agents use this skill to plan web or mini program interfaces before implementation. It helps define aesthetic direction, visual hierarchy, palette, typography, layout strategy, prototype behavior, and self-audit checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Remote visual assets may be downloaded into prototypes from untrusted or inappropriate hosts.

Mitigation: Use trusted HTTPS URLs, avoid private or internal hosts, and review downloaded files before adding them to a project.

Risk: Generated UI direction, prototype code, or audit commands may be incorrect or unsuitable for the target product.

Mitigation: Review the generated design specification and code before deployment, and run the skill's self-audit and normal project scans.
