## Description:

Provides visual direction, design specifications, and interface prototypes for web and mini-program UIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT

## Use Case:

Developers and designers use this skill to plan interface hierarchy, layout, typography, and visual style before building web or mini-program prototypes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Suggested visual assets may be downloaded from remote sources into a project.

Mitigation: Use trusted HTTPS sources and avoid internal or private URLs.

Risk: Default font, color, and icon rules may conflict with brand, locale, accessibility, or an existing design system.

Mitigation: Override the defaults when project requirements call for it.
