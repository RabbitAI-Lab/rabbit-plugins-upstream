## Description:

Use when users need visual direction, interface hierarchy, layout decisions, design specifications, or prototypes before implementing a Web or mini program UI.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and product teams use this skill to define visual direction, interface hierarchy, layout strategy, typography, and prototype expectations before building web or mini program interfaces.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can guide an agent to download remote UI assets with broad shell commands, which may fetch untrusted URLs or unexpected binaries.

Mitigation: Use only trusted HTTPS asset URLs, avoid private or internal hosts, and verify downloaded files before incorporating them into a project.
