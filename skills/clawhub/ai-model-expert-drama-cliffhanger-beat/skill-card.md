## Known Risks and Mitigations:

Risk: AI-HIVE credentials could be exposed if real API keys are copied into shared artifacts.

Mitigation: Keep the API key in a revocable environment variable or protected local config file, and do not publish real keys in skills, screenshots, or repositories.

Risk: User-selected uploads may contain private or unlicensed media.

Mitigation: Upload only media the user is authorized to process, and avoid private, confidential, or unlicensed source materials.

Risk: Generated commands may submit external image or video tasks that consume account balance.

Mitigation: Review commands, model choices, routing mode, pricing information, and task IDs before running or retrying generation.
