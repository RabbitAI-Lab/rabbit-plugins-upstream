## Description:

Author or edit custom HyperFrames video compositions for longer or multi-scene pieces, brand and sizzle reels, montages, loops, title cards, footage remixes, and companion-flow builds.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and creative operators use this skill to plan, build, edit, verify, and render custom HyperFrames video projects when a specialized workflow does not fit or a companion co-creation flow is requested.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Mutable, unpinned HyperFrames CLI skill updates can change reviewed behavior before use.

Mitigation: Pin or preinstall an audited HyperFrames version and avoid automatic skill updates during normal use.

Risk: The workflow depends on the HyperFrames npm package, registry, and skill-update channel.

Mitigation: Install only in environments where those channels are trusted, and run the skill in a dedicated video project workspace.
