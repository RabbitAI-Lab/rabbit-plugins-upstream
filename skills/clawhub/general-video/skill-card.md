## Description:

Guides agents in creating or editing custom HyperFrames video compositions, including multi-scene videos, montages, loops, title cards, and footage remixes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[heygen-com](https://clawhub.ai/user/heygen-com)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to plan, build, check, and, after approval, render custom video compositions when a specialized workflow is not a fit.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow runs an unpinned HyperFrames CLI that can change at runtime and modify project files.

Mitigation: Review update steps and project changes before execution; prefer a pinned or locally locked CLI version.

Risk: Media or provider features may require authenticated access.

Mitigation: Check authentication status before provider actions and use an available offline option when appropriate.
