## Description:

Guides an agent in creating or editing custom HyperFrames video compositions for multi-scene pieces, montages, title cards, and footage remixes.

This skill is ready for commercial/non-commercial use.

## Use Case:

Video creators and developers use this skill to plan, build, and refine custom HyperFrames videos when a specialized workflow does not fit or a collaborative brief calls for a bespoke composition.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill runs and updates unpinned HyperFrames tooling, which can change after installation.

Mitigation: Use a trusted HyperFrames package source and a pinned or vetted version in managed environments; review updates before running them.

Risk: Authenticated media providers may incur charges or access account-connected resources.

Mitigation: Check provider authentication status and review the intended output and costs before using paid media capabilities.
