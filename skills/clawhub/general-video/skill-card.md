## Description:

Authors or edits custom HyperFrames compositions for longer or multi-scene videos, brand and sizzle reels, montages, static loops, title cards, footage remixes, and companion-flow freeform builds when no specialized workflow fits.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and content teams use this skill to create or edit custom HyperFrames video compositions, especially longer or multi-scene pieces and companion-flow work that does not fit a specialized video workflow.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Mutable unpinned npx HyperFrames commands can execute changing registry code or update local skills.

Mitigation: Use a version-pinned or locally locked HyperFrames CLI, review updates before running the workflow, and install only when the HyperFrames package and update channel are trusted.

Risk: The workflow can scaffold project files, install video blocks, use configured media providers, and affect related HyperFrames skills.

Mitigation: Run it in the intended project workspace, verify provider authentication and permissions before media actions, and review generated files and validation results before final render.
