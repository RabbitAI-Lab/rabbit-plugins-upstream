## Description: <br>
Emoji Translator converts Chinese or English text to emoji, reads emoji back into text, and supports inline emoji insertion, keyword search, category browsing, and meme-style emoji additions. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[eelowl](https://clawhub.ai/user/eelowl) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and agent users use this skill to translate chat text into emoji-rich output, explain emoji strings, search for matching emoji, and browse emoji by category for bilingual Chinese and English conversations. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Emoji conversion may process user-provided text that contains sensitive information. <br>
Mitigation: Avoid sending sensitive text for emoji conversion unless local agent processing is acceptable. <br>
Risk: Common emoji-related phrases can trigger the skill during normal conversation. <br>
Mitigation: Install it only when emoji translation from those phrases is desired. <br>
