# 电商UV荧光板 · 产品图处理技能包

## 这是什么

把「一张角色原图 / PSD」变成「可直接发给客户的A5板宣传图」的完整流程。
核心资产：**过去十几轮迭代踩坑后固化的规则** —— 包边怎么处理横竖版、紫光图层读哪一层、尺寸怎么变形、宣传册怎么控制在10MB内。

## 输入 / 输出

| 输入 | 输出 |
|------|------|
| 原图 `.png/.jpg` | A5包边板子（内包边、横竖自适应） |
| `.psd` 文件（含抠图图层） | 紫光灯效果图（发光贴合抠图形状） |
| 一批角色文件夹 | 分册宣传册（封面+分类+二维码，单册<10MB） |

## 核心流程

```
原图/PSD
  ├─ 1. 抠图（读PSD最上方可见非背景图层）──→ 紫光效果图
  ├─ 2. 包边（内包边，横板旋转包边素材）──→ A5板子图
  └─ 3. 宣传册（分类→分册→封面→压缩）──→ 交付图
```

## 规则清单（踩坑沉淀，必须遵守）

### A. 抠图（紫光效果的灵魂）
- **读取PSD最上方可见、非"背景"命名的图层** 作为发光部位。
  - psd_tools 迭代是自底向上的，取最后一个可见且非背景的图层就是最上方图层。
  - 不要用"猜哪个图层"的启发式——用户明确要求：直接读最上方图层。
- 图层是组的跳过；不可见的跳过；名为"背景"的跳过；无透明像素的跳过。
- 若取不到抠图 → 回退为整图紫光效果，不要报错中断。

### B. 紫光效果（uv）
- 基础：整图压暗到 50%，保持背景可读。
- 发光区：抠图形状高斯模糊 2.5px 做紧贴光晕（**光晕要紧贴抠图形状，不允许发散到整图**）。
- 抠图主体颜色增强：`原色×1.45 + (28,10,54)` 向紫白偏移。
- 抠图核心区（alpha>0.55）再提亮到 `原色×1.55`，保证荧光感。
- 抠图内部加极淡紫色环境光 (34,9,52)×0.04，只作用于抠图区域内。
- 最终输出 RGB，自动裁剪。

### C. 包边（A5板子）
- **内包边**：图片拉伸铺满整个画布，金色边框覆盖在画布边缘上，**不留白边**。
- 尺寸：
  - 竖版：1052 × 1494
  - 横版：1494 × 1052（包边素材旋转90°）
- 尺寸有略微不对的 → 变形拉伸也要把整个包边完整包进去，不能裁掉边框。
- 高定卡：用钻石包边素材（`钻石包边.png`），不是普通包边。
- 高位双面：**不包边**，正反两张图左右并排成一张。

### D. 宣传册
- 分类排版：每个分类用花边框整体框起来，标题用缎带式/花边标题。
- 背景：渐变底色（不要纯色），每类可配低透明度角色背景图。
- 卡片：左边正常图，右边紫光效果图，上面可放紫光演示小图。
- 封面 + 结尾二维码页。
- 命名：全部英文（角色名可直接作为标注）。
- 大小：每册控制在 **10MB 以内**，不降像素（用压缩算法而不是缩小尺寸）。
- 排列：按人物图片数量从多到少排列。

## 已知坑（改版前先看这里）

1. **紫光发散** = 没有用抠图做蒙版，光晕直接糊全图。必须走 `uv_from_cut`。
2. **包边不显示/只显示两边** = 横版没旋转边框素材，或图片没铺满画布。
3. **竖版被压扁拉长** = 横竖判断反了（`宽>高`才是横版）。
4. **抠图部位偏移** = 抠图图层和图片尺寸不一致，必须 `resize` 到同一尺寸再合成。
5. **宣传册超10MB** = 用降尺寸救急会糊；正确做法是压缩编码质量。
6. **makima/3 特殊处理** = 该文件不走文件夹内png，直接从其PSD提取原图合成（用户要求）。
