# 包边详细规则（board-rule）

## 判断横竖版

```
宽 > 高  → 横版 (landscape)
宽 <= 高 → 竖版 (portrait)
```

## 画布尺寸（A5比例，单位px）

| 类型 | 画布 | 边框素材 |
|------|------|---------|
| 竖版 | 1052 × 1494 | 原方向，直接拉伸到画布 |
| 横版 | 1494 × 1052 | 旋转90°后再拉伸到画布 |

## 内包边（不留白）

1. 原图 `cover_resize` 到画布：`scale = max(tw/w, th/h)`，居中裁剪——保证铺满、不裁掉主体。
2. 把边框图以 RGBA 覆盖粘贴到画布上（用 alpha 通道）。
3. 边框必须四边完整可见；图片比例稍有出入允许变形拉伸。

| 卡类型 | 边框素材 |
