# powpow-register

PowPow بابل رجسٹریشن مددگار (OpenClaw ایڈیشن): اک نویں صارف نوں «بابل کیہ اے» توں لے کے «اکاؤنٹ ایکٹویٹ، اک کلک لاگ ان، کھیل شروع» تک گھن جانا — مصنوعات دا تعارف (انٹرفیس سکرین شاٹاں سمیت)، ایجنٹ معاون رجسٹریشن (پروفائل تصویر اپلوڈ سمیت)، Alipay/PayPal سبسکرپشن آرڈر تے آمدنی ٹریکنگ، دو لنکاں نال اک کلک لاگ ان، غلطیاں دی جانچ۔

**v2.0.0 توں ایجنٹ-مددگار موڈ، تے v2.2.0 توں پلیٹ فارم دے مفت جانچ پیریڈ نال موافق** — بنیادی اسکرپٹ `scripts/powpow-register.mjs` صفر-انحصار
(Node ≥ 18)؛ صارف گفتگو کولے صرف اک وار ٹردا اے — ان باکس وچ ویریفکیشن کوڈ چیک کرڻ لئی۔ موجودہ مفت جانچ پیریڈ وچ رجسٹر کھاتا ساریاں خصوصیات فی الفور استعمال کر سکدا اے — سبسکرپشن ادائیگی اکٹھی ہوندا اختیاری اپ گریڈ؛ جانچ پیریڈ ختم ہو تے صارف سبسکرپشن صفحے اتے لینڈ کرے، بہاؤ خود کار ادائیگی راہے اتے بدل جاؤدا اے۔ نوڈ بغیر، یا صارف آپ کرڻ چاہوے، خالص ہدایت موڈ وچ واپس چلا جاؤندا اے۔

## انسٹالیشن

```
openclaw skills install @durenzidu/powpow-register
```

## فیچرز

1. **مصنوعات دا تعارف**: ~120 لفظاں دا آغاز + skill نال شامل انٹرفیس سکرین شاٹاں (`assets/screenshots/` وچ 6 تصویراں: نقشہ صفہہ، پوسٹ ڈیٹیل صفہہ وغیرہ، حالت مطابق 1–3 بھیجو؛ باہری ہوسٹنگ دی لوڑ نہیں، آف لائن چلدا اے)۔
2. **معاون رجسٹریشن**: ایجنٹ یوزرنیم/عرفی نام خود تجویز کردا اے، پاس ورڈ لئی دو وِکھپ (صارف دے یا ایجنٹ بناوے)، تصدیقی کوڈ بھیجنا تے جمع کرواؤنا، پروفائل تصویر سدھا اپلوڈ (≤5MB، SVG نہیں)، عام غلطیاں خودکار حل (پہلے توں ورتیا گیا/مہلت ختم/رفتار حد)۔
3. **ون کلک لاگ ان (دو لنک)** — کامیاب رجسٹریشن دے بعد فی الفور، لاگ ان لنک صارف کولے سیدھا ہوم صفحے اتے لینڈ کراؤندا اے (مفت جانچ پیریڈ وچ، اک کلک تے موجود)،
   جے سبسکرپشن صفحے اتے لینڈ کرے (جانچ پیریڈ ختم) یا صارف اپ گریڈ چاہوے، سبسکرپشن بہاؤ follow کرو — ادائیگی آڻ دے بعد نویں لاگ ان حالت بدلی تے مکمل ممبرشپ لنک ہوم صفحے اتے لینڈ کراؤندا اے
   (پلیٹ فارم دے سرکاری `me?token=` پل دے ذریعے، جو خود کار HttpOnly کوکی رکھدا اے)۔
4. **سبسکرپشن پیمنٹ**: Alipay (مہینہ ¥6.99 / سہ ماہی ¥19.99 / سال ¥69.99، اک واری ادائیگی، خودکار تجدید نہیں) تے PayPal (Premium Monthly، تقریباً $1/مہینہ، خودکار تجدید، کسی وی ویلے منسوخ) دوواں وچ ایجنٹ آرڈر بناؤندا اے + آمدنی پولنگ؛ بیرونی صارف PayPal تے واپس؛ WeChat QR/ہوآوی IAP لئی راہ دساؤ۔
5. **غلطیاں دی جانچ**: تصدیقی کوڈ نہ ملنا، یوزرنیم/ای میل پہلے توں ورتیا گیا، 403 ایکٹویٹ نہیں، اکاؤنٹ لاک وغیرہ عام مسئلے، سب پلیٹ فارم سورس کوڈ توں تے حوالہ درج اے۔

## سلامتی

- **پاس ورڈ** صرف ماحول متغیر راہیں سکرپٹ پروسیس وچ جاندا اے، کدے کمانڈ لائن آرگومنٹ وچ نہیں، ڈسک تے نہیں لکھیا، سٹیٹ فائل وچ نہیں جاندا؛ ایجنٹ بنیا پاس ورڈ صرف اک واری دکھایا جاندا اے تاں جو صارف محفوظ کر لے۔
- **تصدیقی کوڈ** صرف سرکاری رجسٹریشن API لئی اے، ورتن تے سٹّ دتا جاندا اے؛ سٹیٹ فائل (ای میل/یوزرنیم/token/آرڈر نمبر) سسٹم عارضی ڈائریکٹری وچ رہندی اے، عمل مکمل تے `cleanup` اک کلک وچ صاف۔
- **پیمنٹ**: ایجنٹ صرف آرڈر بناؤندا اے، کیشیئر کھولھدا اے، آمدنی پچھدا اے؛ صارف دے Alipay/PayPal اکاؤنٹ یا پیمنٹ کریڈینشل نوں کدے نہیں چھوندا، کدے تھانوں ادا نہیں کردا۔ ادائیگی ہمیشہ صارف تے سرکاری کیشیئر دے وچکار ہوندی اے۔
- ساریاں درخواستاں صرف سرکاری ڈومین `https://global.powpow.online` تے جاندیاں نیں؛ کوئی key شامل نہیں۔
