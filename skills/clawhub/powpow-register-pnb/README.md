# powpow-register

PowPow بابل رجسٹریشن مددگار (OpenClaw ایڈیشن): اک نویں صارف نوں «بابل کیہ اے» توں لے کے «اکاؤنٹ ایکٹویٹ، اک کلک لاگ ان، کھیل شروع» تک گھن جانا — مصنوعات دا تعارف (انٹرفیس سکرین شاٹاں سمیت)، ایجنٹ معاون رجسٹریشن (پروفائل تصویر اپلوڈ سمیت)، Alipay سبسکرپشن آرڈر تے آمدنی ٹریکنگ، دو لنکاں نال اک کلک لاگ ان، غلطیاں دی جانچ۔

**v2.0.0 توں ایجنٹ-معاون موڈ اے**: کور سکرپٹ `scripts/powpow-register.mjs` انحصار توں آزاد (Node >= 18)، صارف پورا عمل گفتگو وچ رہندا اے، صرف دو واری عارضی طور تے باہر جانا اے: ای میل تے جا کے تصدیقی کوڈ ویکھنا، Alipay کیشیئر تے ادا کرنا۔ Node نہ ہووے یا صارف خود کرنا چاہوے تاں خودکار طور تے صرف ہدایت والے موڈ تے واپس۔

## انسٹالیشن

```
openclaw skills install @durenzidu/powpow-register
```

## فیچرز

1. **مصنوعات دا تعارف**: ~120 لفظاں دا آغاز + skill نال شامل انٹرفیس سکرین شاٹاں (`assets/screenshots/` وچ 6 تصویراں: نقشہ صفہہ، پوسٹ ڈیٹیل صفہہ وغیرہ، حالت مطابق 1–3 بھیجو؛ باہری ہوسٹنگ دی لوڑ نہیں، آف لائن چلدا اے)۔
2. **معاون رجسٹریشن**: ایجنٹ یوزرنیم/عرفی نام خود تجویز کردا اے، پاس ورڈ لئی دو وِکھپ (صارف دے یا ایجنٹ بناوے)، تصدیقی کوڈ بھیجنا تے جمع کرواؤنا، پروفائل تصویر سدھا اپلوڈ (≤5MB، SVG نہیں)، عام غلطیاں خودکار حل (پہلے توں ورتیا گیا/مہلت ختم/رفتار حد)۔
3. **اک کلک لاگ ان (دو لنک)**: رجسٹریشن کامیاب ہون تے فوری «اادھا لاگ ان» لنک سبسکرپشن صفہے تک؛ پیمنٹ آؤن تے نویں لاگ ان حالت نال مکمل ممبر لنک ہوم پیج تک (پلیٹ فارم دے سرکاری `me?token=` پل راہیں، HttpOnly cookie خود لگ جاندا اے)۔
4. **سبسکرپشن پیمنٹ**: Alipay چینل وچ ایجنٹ آرڈر بناؤندا اے (مہینہ ¥6.99 / سہ ماہی ¥19.99 / سال ¥69.99، اک واری ادائیگی، خودکار تجدید نہیں) + آمدنی پولنگ؛ بیرونی صارف PayPal تے واپس؛ WeChat QR/ہوآوی IAP لئی راہ دساؤ۔
5. **غلطیاں دی جانچ**: تصدیقی کوڈ نہ ملنا، یوزرنیم/ای میل پہلے توں ورتیا گیا، 403 ایکٹویٹ نہیں، اکاؤنٹ لاک وغیرہ عام مسئلے، سب پلیٹ فارم سورس کوڈ توں تے حوالہ درج اے۔

## سلامتی

- **پاس ورڈ** صرف ماحول متغیر راہیں سکرپٹ پروسیس وچ جاندا اے، کدے کمانڈ لائن آرگومنٹ وچ نہیں، ڈسک تے نہیں لکھیا، سٹیٹ فائل وچ نہیں جاندا؛ ایجنٹ بنیا پاس ورڈ صرف اک واری دکھایا جاندا اے تاں جو صارف محفوظ کر لے۔
- **تصدیقی کوڈ** صرف سرکاری رجسٹریشن API لئی اے، ورتن تے سٹّ دتا جاندا اے؛ سٹیٹ فائل (ای میل/یوزرنیم/token/آرڈر نمبر) سسٹم عارضی ڈائریکٹری وچ رہندی اے، عمل مکمل تے `cleanup` اک کلک وچ صاف۔
- **پیمنٹ**: ایجنٹ صرف آرڈر بناؤندا اے، کیشیئر کھولھدا اے، آمدنی پچھدا اے؛ صارف دے Alipay اکاؤنٹ یا پیمنٹ کریڈینشل نوں کدے نہیں چھوندا، کدے تھانوں ادا نہیں کردا۔ ادائیگی ہمیشہ صارف تے Alipay سرکاری کیشیئر دے وچکار ہوندی اے۔
- ساریاں درخواستاں صرف سرکاری ڈومین `https://global.powpow.online` تے جاندیاں نیں؛ کوئی key شامل نہیں۔
