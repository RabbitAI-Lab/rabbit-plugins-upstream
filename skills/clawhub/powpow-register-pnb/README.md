# powpow-register

PowPow ببل رجسٹریشن مددگار (OpenClaw ورژن): نویں ورتݨ والے نوں «ببل کی اے» نہ جانݨ توں
«کھاتہ چالو، ٹھیک نال ورت سکدے او» تک لجاندا اے — پراڈکٹ تعارف (انٹرفیس سکرین شاٹاں سمیت)، قدم بہ قدم رجسٹریشن رہنمائی، خرابی جانچ،
سبسکرپشن ایکٹیویشن دی وضاحت۔

مکمل رہنمائی والی skill، کوئی سکرپٹ جاں انحصار نئیں؛ سارے رجسٹریشن کم ورتݨ والا براؤزر/ایپ چ کردا اے۔

## انسٹال

```
openclaw skills install @durenzidu/powpow-register
```

## خصوصیتاں

1. **پراڈکٹ تعارف**: ~120 لفظاں دا افتتاح + GitHub عوامی ریپوزٹری چ ہوسٹڈ انٹرفیس سکرین شاٹ لنک
   (نقشہ پیج، پوسٹ تفصیل پیج وغیرہ 6 فوٹو، صورت حال مطابق 1–3 چن کے بھیجو)۔
2. **رجسٹریشن رہنمائی**: فیلڈ قنون (یوزرنیم/پاسورڈ/ای میل تصدیقی کوڈ/فون نمبر/پروفائل فوٹو)، تیجے فریق لاگ ان
   (Google/Watcha/Huawei)، ریٹ لمٹ پیرامیٹر، سارے پلیٹ فارم سورس کوڈ توں لئے گئے تے سورس لکھیا ہویا۔
3. **خرابی جانچ**: تصدیقی کوڈ نہ آوݨ، یوزرنیم/ای میل ورت لئے گئے، 403 چالو نئیں، کھاتہ لاک وغیرہ
   13 عام مشکلاں۔
4. **سبسکرپشن ایکٹیویشن**: PayPal (ویب) / WeChat سکین (منیوال تصدیق) / Huawei IAP (HarmonyOS) تن
   چینلاں دی وضاحت تے جانچ؛ موجودہ ادائیگی دا سلسلہ سدھا فیر ورتیا جا سکدا اے، skill صرف رستہ دکھاؤندی اے۔

## حفاظت

- کوئی راز دی کی نئیں؛ سکرپٹ نئیں، ورتݨ والے دی شناخت نال کوئی واسطہ نئیں۔
- **کدی نئیں** ورتݨ والے دا پاسورڈ، کوڈ جاں ادائیگی دی شناخت منگو؛ رجسٹریشن تے ادائیگی سارے پلیٹ فارم پیج تے مکمل ہوندی اے۔
