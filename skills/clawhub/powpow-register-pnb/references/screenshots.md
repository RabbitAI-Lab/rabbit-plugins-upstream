# پروڈکٹ UI اسکرین شاٹس — powpow-register

رن-ٹائم تے لوڑ مطابق ورتو۔ جدوں یوزر نوں معلوم نہ ہووے کہ Bubble کیہہ اے، یا اوہنوں "ویکھݨ" دی لوڑ ہووے کہ تیار شدہ پروڈکٹ کِداں دی دکھدی اے، تے متعلقہ لنک براہ راست بھیج دو۔

## لنک قواعد

- بنیادی لنک (raw):
  `https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-0N.jpg`
- آئینہ لنک (جب raw تک رسائی نہ ہووے، `N` 1–6 اے):
  `https://cdn.jsdelivr.net/gh/durenzidu/durenzidu@main/screenshots/powpow-0N.jpg`
- تصویراں اک عوامی ریپو وِچ نیں تے براہ راست بھیجیاں جا سکدیاں نیں؛ **اوہناں نوں سکل ڈائریکٹری وِچ ڈاؤن لوڈ نہ کرو**، تے تصویراں دے طور تے لوکل پاتھ وی نہ بھیجو۔
- ہر واری صرف 1–3 تصویراں بھیجو جہڑیاں موجودہ موضوع نال متعلق ہوون۔

## لسٹ

### powpow-01.jpg — ڈیجیٹل ہیومن تفصیلی صفحہ

![ڈیجیٹل ہیومن تفصیلی صفحہ](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-01.jpg)

اک اصل بندے / تاریخی شخصیت دا کارڈ جہڑا ڈیجیٹل ہیومن وِچ بدل گیا: آن لائن سٹیٹس، لوکیشن، بائیو، "چیٹ شروع کرو" وغیرہ۔
**کس ویلے ورتو**: جدوں ایہہ دسو کہ "رجسٹریشن دے بعد تُسی نقشے تے ڈیجیٹل ہیومنز نال چیٹ کر سکدے او"۔

### powpow-02.jpg — پوسٹ ایڈیٹر صفحہ

![پوسٹ ایڈیٹر صفحہ](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-02.jpg)

پوسٹاں/سفرنامے لکھݨ دا ایڈیٹر، تھلے-سجے کونے وِچ فلوٹنگ بٹناں دا اک سیٹ۔
**کس ویلے ورتو**: جدوں یوزر پچھے "رجسٹریشن دے بعد میں کیہہ کر سکدا ہاں" / "میں کتھے لکھدا ہاں"۔

### powpow-03.jpg — نقشہ صفحہ (Bubbles + ڈیجیٹل ہیومنز)

![نقشہ صفحہ](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-03.jpg)

مکمل عوامی نقشہ: لوکیشناں والیاں پوسٹاں نقشے تے "bubbles" دی شکل وِچ اکٹھیاں ہُندیاں نیں، ڈیجیٹل ہیومنز اپݨے اواتاراں نال اصل لوکیشناں تے پِن کیتے ہوئے نیں۔
**کس ویلے ورتو**: **کھلݨ والے پروڈکٹ تعارف لئی سب توں ودھیا تصویر** — "تہاڈے سفرنامے دیاں تحریراں نقشے تے اک bubble بَݨ جاندیاں نیں"۔

### powpow-04.jpg — پروفائل صفحہ (ڈیجیٹل اثاثے)

![پروفائل صفحہ](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-04.jpg)

یوزر دا اپݨا صفحہ: دوست/فالو کیتے گئے/پیروکار، تے "ڈیجیٹل اثاثے" — بیج بیلنس، میرے bubbles، میرے ڈیجیٹل ہیومنز۔
**کس ویلے ورتو**: جدوں ایہہ دسدے ہوئے کہ بیجز کتھے نیں کہ "رجسٹریشن تہانوں 3 بیج دیندی اے"؛ جدوں یوزر پچھے "میرے کول کیہڑے اثاثے نیں"۔

### powpow-05.jpg — سٹوری پروگریس صفحہ

![سٹوری پروگریس صفحہ](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-05.jpg)

پلیٹ فارم دے اندر سٹوری دا گیم پلے (مثال "永乐·1421"): ابواب دی پیش رفت، بیج کمانا، رول پلے۔
**کس ویلے ورتو**: جدوں یوزر پچھے "لکھݨ توں علاوہ ہور کیہہ کھیڈ سکدا ہاں" / "میں بیج کیویں کماندا ہاں"۔

### powpow-06.jpg — پوسٹ تفصیلی صفحہ (مکمل مثال)

![پوسٹ تفصیلی صفحہ](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-06.jpg)

اک شائع شدہ سفرنامے دی تحریر: مصنف، لوکیشن ٹیگز، متن، تصویراں؛ تھلے لائیک/کومنٹ/شیئر/سیو۔
**کس ویلے ورتو**: **دوسری کھلݨ والی تصویر** — "ایہہ اوہ اے جو ہور لوک ویکھدے نیں جدوں اوہ نقشے تے تہاڈا bubble کھولدے نیں"۔

## دیکھ بھال دے نوٹس

موجودہ لائبریری وِچ **رجسٹریشن صفحے** یا **سبسکرپشن صفحے** دیاں کوئی اسکرین شاٹس نئیں نیں۔ جے بعد وِچ اوہناں نوں `durenzidu/durenzidu` ریپو دی `screenshots/` وِچ شامل کیتا جاوے (مثلاً `powpow-07.jpg` رجسٹریشن صفحہ، `powpow-08.jpg` سبسکرپشن صفحہ)، تے ایتھے ایسے ای فارمیٹ وِچ اک سیکشن جوڑ دَوو، تے SKILL.md دی واک تھرو وی اوہدے ول اشارہ کر سکدی اے۔
