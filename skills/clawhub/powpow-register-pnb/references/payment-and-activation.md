# سبسکرپشن ایکٹویشن تے پیمنٹ — powpow-register

## نتیجہ (پہلاں جواب)

**Alipay تے PayPal دوواں سبسکرپشناں دا agent آرڈر تے ٹریکنگ کر سکدا اے۔**
Alipay اک واری ادائیگی، خودکار تجدید نہیں، مینلینڈ/Alipay والے صارفاں لئی موزوں؛ PayPal مہینہ وار خودکار تجدید، کسی وی ویلے منسوخ، بیرون ملک/Alipay نہ والے صارفاں لئی موزوں۔ WeChat QR (دستی تصدیق) تے Huawei IAP وی نیں، پر skill خود نہیں کردا۔

پیمنٹ حصے دی ذمہ داری دی حد: ایجنٹ **آرڈر بنا سکدا اے، کیشیئر کھولھ سکدا اے، آمدنی پچھ سکدا اے**؛ صارف دے Alipay/PayPal
اکاؤنٹ/پیمنٹ کریڈینشل نوں **کدے** نہیں چھوندا، «تھانوں ادا کرن» دا وعدہ کدے نہیں کردا۔ ادا کرن دا عمل ہمیشہ صارف خود سرکاری کیشیئر تے کردا اے۔

## Alipay چینل (vibepay، اہم)

اک واری ادائیگی دا نظام: اک واری ادا کرو متعلق مہلت کھل جاندی اے، **خودکار تجدید نہیں**۔ پیک `src/lib/alipay-vibepay.ts` وچ لکھے نیں (`ALIPAY_PACKAGES`):

| key | planId | نام | قیمت | مہلت |
|---|---|---|---|---|
| `monthly` | alipay-monthly | مہینہ ممبرشپ | ¥6.99 | 30 دن |
| `quarterly` | alipay-quarterly | سہ ماہی ممبرشپ | ¥19.99 | 90 دن |
| `yearly` | alipay-yearly | سالانہ ممبرشپ | ¥69.99 | 365 دن |

### انٹرفیس معاہدہ (skill سکرپٹ وچ بنھیا گیا اے، ایجنٹ سدھا درخواست نہیں بناؤندا)

| انٹرفیس | طریقہ | وضاحت |
|---|---|---|
| `/api/payment/alipay/create-order` | POST | `Authorization: Bearer <JWT>` لوڑ اے (pending صارف وی چلدا اے)۔ body `{package}` → `{paymentHtml, outTradeNo, amount, planName}` دیندا اے؛ `paymentHtml` Alipay گیٹ وے تے خود جمع ہون والا فارم صفہہ اے |
| `/api/payment/alipay/query` | GET `?outTradeNo=` | ایہ وی Bearer جانچ۔ `paid` / `pending` / `closed` / `unknown` دیندا اے |
| `/api/payment/alipay/notify` | POST (Alipay سرور کال بیک) | سائنئچر پنج عنصر جانچ (سائن، app_id، رقم میل، TRADE_SUCCESS/TRADE_FINISHED، وپار دا اکلوپن) → **idempotent** آرڈر اپڈیٹ + سبسکرپشن بناؤ + اکاؤنٹ ایکٹویٹ۔ skill اس انٹرفیس نوں کدے نہیں چھوندا |
| `/payment/alipay/return` | براؤزر واپسی صفہہ | کھلا راہ اے، ادا کرن تے «支付成功» دی تصدیق دکھاندا اے، صفہہ اندر پچھ کے اصل حالت جانچدا اے |

- ادا نہ ہویا آرڈر **2 گھنٹے وچ خود بند**؛ صارف وچکار چھڈ دے → سدھا دوبارہ `create-order`، پرانے آرڈر دی فکر نہ کرو۔
- سکرپٹ `paymentHtml` عارضی HTML فائل وچ لکھدا اے، ایجنٹ سسٹم کمانڈ نال کھولھے Alipay کیشیئر وچ لنگھ جاندا اے
  (QR سکین یا Alipay وچ لاگ ان کے ادا کرو)۔

### ایکٹویشن چین (خودکار، دستی لوڑ نہیں)

notify سائنئچر جانچ لنگھے → `paymentOrders` ادا شدہ نشان لگدا اے → `user_subscriptions` بندا/اگے ودھدا اے
(`planId`، `currentPeriodEnd` durationDays مطابق گن کے، تجدید پرانے ختم ہون دی تریخ تے اگے ودھدی اے) →
`users.accountStatus: active` + `subscriptionStatus: ACTIVE` → واپسی صفہہ پچھدا رہندا اے، paid ہون تے کامیابی دکھاندا اے۔

### ادا کرن توں بعد لازمی نویں لاگ ان حالت بدلو (اہم)

JWT وچ سبسکرپشن دعوا ہوندا اے (pending اکاؤنٹ دا `NONE`)۔ **پیمنٹ آؤن نال صرف ڈیٹابیس اپڈیٹ ہوندا اے، جاری شدہ JWT نہیں بدلدا** —
پرانے token دا دعوا اجے وی NONE، سدھا اس نال لاگ ان لنک بناؤ تے «ممبر نہیں» لگدا اے۔
اس لئی skill `paid` / PayPal `ACTIVE` دی تصدیق توں بعد پہلے `refresh-login` چلاندا اے (دوبارہ لاگ ان نواں JWT، دعوا ACTIVE بن جاندا اے)،
فیر لنک 2 بناؤندا اے۔ ایہ ڈیزائن سلوک اے، سوراخ دی مرمت نہیں۔

## PayPal سبسکرپشن چینل (skill کردا اے، ویب ہارمونی نہیں)

صرف اک Premium Monthly پلان اے (تقریباً $1/مہینہ، `/api/subscription/plans` دے جواب مطابق)، **مہینہ وار خودکار تجدید**، صارف کسی وی ویلے PayPal بیک اینڈ تے منسوخ کر سکدا اے۔

### انٹرفیس معاہدہ (skill سکرپٹ وچ بنھیا گیا اے، agent سدھا درخواست نہیں بناؤندا)

| انٹرفیس | طریقہ | وضاحت |
|---|---|---|
| `/api/subscription/plans` | GET | Bearer جانچ، دستیاب پلاناں دی لسٹ دیندا اے (ہن صرف 1) |
| `/api/subscription/create` | POST | body `{planId}` → دیندا اے `{subscriptionId, approveUrl, status}`؛ status عام طور تے `APPROVAL_PENDING` |
| `/api/subscription/create` | GET | Bearer جانچ، دیندا اے `{activeSubscription, allSubscriptions}`؛ agent پولنگ کردا اے `activeSubscription.subscription.status === 'ACTIVE'` |
| `/api/subscription/verify` | POST | کامیابی صفہہ خود کال کردا اے (cookie نال)، webhook نہ آن تے PayPal API نوں خود کال کے ایکٹویٹ کردا اے |
| `/subscription/success` | براؤزر واپسی صفہہ | PayPal اجازت توں بعد اتردا اے، خود verify پولنگ کردا اے؛ ایکٹویٹ ہون تے ہوم/اصل صفحے تے واپس |
| `/subscription/cancel` | براؤزر صفہہ | صارف منسوخ کرے یا فیل ہووے تاں اتردا اے، دوبارہ شروع کر سکدا اے |

### agent عمل

```
create-order --provider paypal  # → approveUrl دیندا اے تے لوکل HTML فائل وچ لکھدا اے
HTML فائل کھولھو                  # → براؤزر PayPal اجازت صفحے تے لنگھدا اے
query (ہر 10–15s)               # → ACTIVE تک پولنگ
refresh-login                   # → نواں JWT (سبسکرپشن دعویٰ ACTIVE)
login-link --target home        # → اصل لاگ ان لنک بناؤندا اے
```

- 1 گھنٹے وچ نہ مکمل ہووے والی PENDING سبسکرپشن بیک اینڈ خود صاف کردا اے، دوبارہ شروع کر سکدے او۔
- جے صارف دوبارہ `create-order` چلاؤے، بیک اینڈ اجے وی چالو `APPROVAL_PENDING` سبسکرپشن دوبارہ ورتدا اے، 409 توں بچن لئی۔
- Alipay وانگوں: ادائیگی آؤن تے صرف DB اپڈیٹ ہوندا اے، پرانا JWT خود ریفریش نہیں ہوندا، **ضرور** پہلے `refresh-login` فیر ہوم لنک بھیجو۔

## سبسکرپشن صفہہ دے چار چینل

سبسکرپشن صفہہ `src/app/(public)/subscription/page.tsx` رن ماحول مطابق دکھاندا اے:

| چینل | ماحول | نظام | ایکٹویشن طریقہ |
|---|---|---|---|
| **Alipay (اہم)** | ویب | `AlipayPaymentSection` vibepay انٹرفیس (اتلے جدول) | notify سرور پاسے خودکار ایکٹویٹ، سیکنڈاں وچ |
| PayPal سبسکرپشن | ویب (ہارمونی نہیں) | `/api/subscription/create` → PayPal اجازت تے لنگھدا اے؛ مہینہ خودکار تجدید کدے وی منسوخ ہو سکدی اے (`/api/subscription/manage`) | PayPal Webhook (`BILLING.SUBSCRIPTION.*`) خود active کردا اے |
| 微信扫码订阅 | ویب (ہارمونی نہیں) | صفہہ دے تھلے «微信扫码订阅»: QR سکین کے پیسے بھیجو | **دستی تصدیق**، آمدنی دیر ہو سکدی اے؛ ادا کرن تے جلدی فیل نہ سمجھو |
| ہوآوی اِن ایپ خریداری | ہارمونی ایپ اندر | نیٹو `NativeBridge.purchaseSubscription()` | `/api/subscription/activate-huawei` ہوآوی آرڈر دی تصدیق توں بعد ایکٹویٹ کردا اے |

PayPal پلان تے قیمت `/api/subscription/plans` توں ڈائنامک آندے نیں؛ صفہہ دا پکا متن: Auto-renews. Cancel anytime.

## حالت تے لنگھنا

- Alipay ادا کرن تے → واپسی صفہہ کامیابی دکھاندا اے؛ PayPal کامیاب → `/subscription/success` → اکاؤنٹ active →
  `next` پیرامیٹر والے اصل صفہے تے خود واپس (نہ ہووے تے ہوم پیج)۔
- پہلے توں سبسکرائبڈ صارف سبسکرپشن صفہہ تے آوے → "You're All Set!" دکھاندا اے، 3 سیکنڈ توں بعد خود ہوم پیج تے لنگھ جاندا اے۔
- پیمنٹ فیل/منسوخ (PayPal) → `/subscription/cancel`، دوبارہ شروع کر سکدے او۔

## جانچ

| واقعہ | حل |
|---|---|
| Alipay ادا کیتا پر `query` اجے وی pending | notify بہت کدے کدے دیر کردا اے؛ 30 سیکنڈ اڈیک کے دوبارہ پچھو۔ اجے وی نہ ہووے تاں صارف نوں براؤزر وچ واپسی صفہہ دی حالت ویکھن دو، فیر وی نہ ہووے تے پلیٹ فارم سپورٹ نال رابطہ کرو (dongtao@outlook.com)، `outTradeNo` دسّو |
| Alipay ادا کیتا، لنک 2 وچوں وی روکیا جاندا اے | `refresh-login` رہ گیا اے (پرانے JWT دا دعوا اپڈیٹ نہیں ہویا) — پہلے `refresh-login` فیر `login-link` |
| PayPal `query` ہمیشہ PENDING | صارف نے اجے PayPal تے اجازت نہیں دتی؛ براؤزر وچ اجازت دا لنک کھلیا ہووے یقینی کرو۔ اجازت دے دتی ہووے تاں وی PENDING رہے تاں شاید webhook دیری اے — صارف نوں کامیابی صفحے تے چند سیکنڈ انتظار یا ریفریش کرن لئی کہو |
| PayPal `query` توں 409 آوے | نامکمل PayPal سبسکرپشن اے؛ 1 گھنٹے انتظار کرو خودکار میاڈ لئی، یا براؤزر وچ پرانی اجازت مکمل کرو |
| PayPal ادائیگی ہو گئی، لنک 2 وچ وی رکدا اے | Alipay وانگوں: پہلے `refresh-login` فیر `login-link` |

| ادا کرن توں بعد وی 403 (PayPal) | Webhook کدے کدے دیر کردا اے، دوبارہ لاگ ان کے حالت ریفریش کرو |
| WeChat ادا کیتا پر ایکٹویٹ نہیں ہویا | دستی تصدیق غیر ہم وقت اے، چند گھنٹے وچ وی نہ کھلے تے پلیٹ فارم سپورٹ نال رابطہ کرو |
| سبسکرپشن صفہہ "No subscription plans available" دسّے | `/api/subscription/plans` وچ کوئی PayPal پلان دستیاب نہیں، پلیٹ فارم پاسی کنفیگریشن دا مسئلہ اے؛ چینی صارف Alipay تے بدل دو بس |

## تاریخی نوٹ

¥9.90/¥99 اک واری ادائیگی، سینڈ باکس دے key نہ ہووے تے نقلی ادائیگی تے لنگھ جاندا اے)، سبسکرپشن صفہہ UI وچ کدے جڑیا نہیں، vibepay نال کوئی تعلق نہیں۔ skill اس نوں کدے نہیں چھوندا؛ `alipay-vibepay.ts` ہی موجودہ چینل اے۔
