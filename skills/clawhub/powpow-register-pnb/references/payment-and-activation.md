# سبسکرپشن ایکٹیویشن تے ادائیگی — powpow-register

## نتیجہ (جواب پہلاں)

**موجودہ ادائیگی دے طریقے جِداں دے تِداں دوبارہ ورتے جا سکدے نیں — رجسٹریشن معاون سکل نوں کسے وی ادائیگی ڈیولپمنٹ دی لوڑ نئیں۔**

وجوہات:

1. رجسٹریشن API (`src/app/api/auth/register/route.ts`) pending اکاؤنٹ بݨاؤندے ویلے پہلاں ای اک JWT cookie + pendingUserToken HttpOnly cookie جاری کردا اے، ایس لئی جدوں تک یوزر `/subscription` تے پہنچدا اے اوہ پہلاں ای لاگ اِن ہُندا اے — تِناں ادائیگی چینل ایسے سبسکرپشن صفحے نال جڑے ہوئے نیں، تے اوہناں ساریاں دا کم اوہو ای pending اکاؤنٹ چالو کرنا اے۔
2. login API pending اکاؤنٹاں لئی 403 + `redirectTo: '/subscription'` واپس کردا اے تے cookies اوہو جِداں سیٹ کردا اے — دیر نال ادائیگی کرن والا یوزر ہمیشہ اوہو صفحے تے مڑ بھیجیا جاندا اے۔
3. ایس لئی رجسٹریشن رہنمائی سکل دی ذمہ داری دی حد صرف اِنی اے: "یوزر نوں `/subscription` تے لجاؤ"؛ کسے نویں ادائیگی API، کسے نویں آرڈر ماڈل یا backend تبدیلیاں دی لوڑ نئیں۔

نوٹ وی کرو: ادائیگی دا قدم (PayPal JS SDK بٹن، WeChat QR-کوڈ دستی تصدیق، native Huawei IAP) **ایہہ ظاہر کردا اے کہ کمانڈ-لائن/چیٹ سکل یوزر دی طرفوں ادائیگی نئیں کر سکدی تے نہ ای کرنی چاہیدی اے**۔ کسے script راہیں ادائیگی APIs نوں بلا کے یوزر لئی ادائیگی کرن دی کوشش نہ کرو، تے یوزر توں ادائیگی دے اسناد نہ منگو۔

## سبسکرپشن صفحے دے تن چینل

سبسکرپشن صفحہ `src/app/(public)/subscription/page.tsx` رن-ٹائم ماحول دے مطابق خودکار طور تے موزوں چینل دکھاندا اے:

| چینل | ماحول | میکانزم | ایکٹیویشن |
|---|---|---|---|
| PayPal سبسکرپشن | Web (غیر-HarmonyOS) | `/api/subscription/create` اک PayPal سبسکرپشن بݨاندا اے → تصدیق لئی PayPal وَل ری ڈائریکٹ کردا اے؛ ہر مہینے خودکار تجدید ہُندی اے، کسے وی ویلے منسوخ کرو (`/api/subscription/manage`) | PayPal Webhook (`BILLING.SUBSCRIPTION.*`) خودکار طور تے `accountStatus` نوں active سیٹ کردا اے |
| WeChat QR-کوڈ سبسکرپشن | Web (غیر-HarmonyOS) | صفحے دے تھلے "سبسکرائب کرن لئی WeChat سکین کرو" سیکشن: سکین کر کے رقم منتقل کرو، **دستی تصدیق دے بعد چالو ہُندا اے** (`WechatQrPaymentSection`) | دستی تصدیق؛ رقم دیر نال آ سکدی اے — یوزر دے ادائیگی کرن دے فوراً بعد اِینوں ناکامی نہ آکھو |
| Huawei in-app خریداری (IAP) | HarmonyOS App دے اندر | PayPal/WeChat Pay HarmonyOS WebView وِچ دستیاب نئیں نیں، ایس لئی صفحہ native `NativeBridge.purchaseSubscription()` ورتدا اے | `/api/subscription/activate-huawei` Huawei آرڈر دی تصدیق کر کے فیر چالو کردا اے |

منصوبے تے قیمتاں `/api/subscription/plans` (PayPal منصوبے) توں متحرک طور تے پڑھیاں جاندیاں نیں؛ صفحے دی مستقل عبارت ایہہ اے: خودکار تجدید۔ کسے وی ویلے منسوخ کرو۔

## سٹیٹس تے ریڈائریکٹس

- ادائیگی کامیاب → `/subscription/success` (PayPal callback `subscriptionId` نال آؤندا اے) → اکاؤنٹ active → `next` پیرامیٹر نال دسیا گیا اصل صفحے تے خودکار واپسی (جے کوئی نہ ہووے تے ہوم پیج)۔
- پہلاں سبسکرائب شدہ یوزر سبسکرپشن صفحے تے آوے → "سارا کجھ تیار اے!" دکھاندا اے، 3 سیکنڈاں بعد خودکار طور تے ہوم تے مڑ جاندا اے۔
- ادائیگی ناکام/منسوخ → `/subscription/cancel`، نویں کوشش شروع کیتی جا سکدی اے۔

## مسائل دا ازالہ

| علامت | حل |
|---|---|
| ادائیگی دے باوجود وی 403 | PayPal: Webhook کدی کدی دیر نال آؤندا اے — سٹیٹس تازہ کرن لئی دوبارہ لاگ آؤٹ/لاگ اِن کرو (login ڈیٹابیس دی تازہ ترین حالت دوبارہ چیک کردا اے)؛ WeChat: دستی تصدیق مکمل نئیں ہوئی، تھوڑا انتظار کرو؛ Huawei: دیکھو کہ in-app ادائیگی دا کامیابی والا صفحہ آیا سی کہ نئیں |
| سبسکرپشن صفحہ "کوئی سبسکرپشن منصوبے دستیاب نئیں" دکھاندا اے | `/api/subscription/plans` تے کوئی ورتݨ جوگے PayPal منصوبے نئیں — ایہہ پلیٹ فارم پاسے دا کنفیگریشن مسئلہ اے؛ یوزر نوں تھوڑی دیر بعد دوبارہ کوشش کرن لئی کہو |
| WeChat راہیں ادائیگی کیتی پر چالو نئیں ہویا | دستی تصدیق غیر متزامن اے؛ جے کجھ گھنٹیاں وِچ چالو نہ ہووے، تے پلیٹ فارم سپورٹ نال رابطہ کرو (dongtao@outlook.com) |

## نوٹ: Alipay

کوڈبیس وِچ Alipay ویب ادائیگی کوڈ دا اک سیٹ موجود اے (`src/lib/alipay.ts`، `/api/payment/create-order`، اک واری خریداری دا ماڈل: ریگولر ممبرشپ ¥9.90 / پریمیم ممبرشپ ¥99؛ جدوں sandbox کلید سیٹ نہ ہووے تے خودکار طور تے mock ادائیگی تے ڈیگریڈ ہو جاندا اے) **پر ایہہ سبسکرپشن صفحے دی UI نال جڑیا ہویا نئیں** — ایہہ غیر فعال/محفوظ کوڈ اے۔ جے کدی سبسکرپشن صفحے تے Alipay فعال کرن دی لوڑ پوے، تے ایہہ تیار بݨیا کوڈ جوڑ دو — ایہہ ایس سکل نال کوئی تعلق نئیں رکھدا تے ایتھے صرف پلیٹ فارم پاسے دے فیصلیاں لئی حوالے دے طور تے نوٹ کیتا گیا اے۔
