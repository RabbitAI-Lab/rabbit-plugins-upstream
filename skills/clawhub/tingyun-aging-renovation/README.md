# 适老化改造评估与监理顾问

> 为子女出资、父母使用的适老化改造做决策辅助：能力评估、优先级排序、改造项清单、材料选型、费用区间、补贴查询方向与验收清单。不替代医生诊断与专业机构结论，需人工复核。技术触发词「老人能力评估、改造优先级、施工验收清单」。口语触发词「各项改造大概多少钱、我所在的城市有没有居家适老化改造补贴」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

居家适老化改造评估监理顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我打算给独居的父母家做适老化改造，预算3万块，先改哪几项更划算？请给我一个改造优先级清单
- 我妈78岁，用拐杖，上个月洗澡时滑了两次。居家评估要覆盖哪些能力维度？给我一份评估表
- 父母住老破小，卫生间门口有15厘米高差，还没有扶手。预算有限的情况下先改哪几项？
- 各项改造大概多少钱？我该怎么对比不同施工方的报价，才不会被坑？
