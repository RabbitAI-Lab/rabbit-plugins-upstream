# 改造项清单、尺寸要求、材料选型与费用区间

用途：方案阶段把"要改什么"落到具体项、具体尺寸、具体材料、具体钱数。
本文为清单与选型参考，不构成法律专业意见，需人工复核。费用为常见区间参考，各地、各品牌、各施工方差异较大，以本地实际报价为准。

---

## 一、按空间的改造项清单

依据《城市居家适老化改造指导手册》的七个方面划分（通用性改造、入户空间、起居（室）厅、卧室、卫生间、厨房、阳台），并区分**基础型**（满足基本生活需求与安全便利）与**提升型**（改善生活品质）。

### 1. 通用性改造（贯穿全屋）

| 项目 | 基础型做法 | 关键尺寸/要求 |
|---|---|---|
| 地面 | 防滑砖、防滑贴、防滑地胶、防滑垫 | 室内地面摩擦系数 ≥0.5 |
| 高差 | 门槛剔除或设坡面过渡；相邻空间高差处理 | 门口高差 ≤15mm，斜面纵坡 ≤1:10；卧室、厨房、卫生间、阳台与相邻空间高差 <15mm 并设坡面 |
| 扶手体系 | 按使用点位设置，沿行动路线连贯 | 单层 850~900mm；双层下层 650~700mm；圆形直径 30~45mm；墙面净距 40~50mm；端部回勾 ≥100mm；起点终点水平延伸 ≥300mm |
| 照明 | 基础照明 + 夜间路径照明 | 卫生间一般照度约 200lx（参照 JGJ 450—2018 相关要求）；卧室床头设照明开关 |
| 插座 | 常用点位增设安全型插座 | 常用插座高度 600~800mm；卫生间用防水型 |
| 通行 | 通道净宽与家具布置 | 无障碍通道净宽 ≥1.20m |
| 家具 | 避免尖锐与突出；座面不过软过深；茶几略高于沙发 | 通行与起身支撑需求 |

### 2. 入户空间

- 门口高差与门槛处理
- 入户坡道（轮椅坡道纵坡 ≤1:12；受限且高差 ≤150mm 时 ≤1:10；每段提升高度 ≤750mm；净宽 ≥1.20m）
- 门扇：门开启后通行净宽新建扩建 ≥900mm、既有改造 ≥800mm；门槛与挡块去除；平开门内外侧设扶手（操作部分距地 0.85~1.00m）
- 门厅竖向扶手
- 玄关换鞋凳（高度与扶靠结合）
- 鞋柜与置物架高度调整

### 3. 起居（室）厅

- 沙发座面高度与深度调整（起身可借力）
- 茶几高度略高于沙发，减少弯腰取物
- 桌边扶手与起身支撑点
- 地面防滑与抗冲击处理
- 通道家具重排，留出通行与转身空间
- 家具边角防撞处理
- 照明与开关位置调整（减少摸黑走动）

### 4. 卧室

- 床边护栏或抓杆
- 床头照明开关（伸手可及）与床头感应夜灯
- 床高调整（能坐起、能站稳）
- 紧急呼救装置
- 衣柜高度与挂衣杆下移（低位挂衣杆距地 ≤1.20m）
- 地面防滑
- 通往卫生间的夜间路径照明
- （提升型）护理床、防褥疮床垫、可移动坐便器

### 5. 卫生间（风险集中的空间）

- 防滑地面处理与排水改造
- 门槛剔除、挡水条改坡面过渡、干湿分离
- 蹲便器改坐便器
- 坐便器两侧安全抓杆：轮椅接近侧设可垂直或水平 90° 旋转的水平抓杆（距坐便上沿 250~350mm，长度 ≥700mm），另一侧 L 形抓杆（水平段距上沿 250~350mm、长 ≥700mm；竖向段设于坐便前端 150~250mm，顶部距地 1.40~1.60m）
- 淋浴坐台：高度 400~450mm，深 400~500mm，宽 500~550mm
- L 形淋浴抓杆：水平段距地 700~750mm、长 ≥700mm；竖向段顶部距地 1.40~1.60m；控制开关距地 ≤1.00m；手持喷头支架高度 1.20m；软管长度 ≥1.50m
- 洗手盆下方容膝空间（台面距地 ≤800mm；水嘴中心距侧墙 ≥550mm；容膝区宽 ≥750mm、高 ≥650mm、距地高 250mm 起、进深 ≥450mm）
- 救助呼叫装置：坐便附近设置，需满足坐在坐便上和跌倒在地面的人都能使用
- 照明与夜间照明
- 门槛消除、地面防滑（系数 ≥0.5）

### 6. 厨房

- 操作台面高度（700~850mm）与下方容膝空间
- 灶具防干烧、燃气报警
- 柜体与抽屉高度调整、把手形式调整（低位与易握）
- 冰箱、烤箱位置与开门空间
- 地面防滑与照明
- 水槽与工作台操作空间分隔

### 7. 阳台

- 地面防滑、排水
- 晾晒装置高度（减少举高与踮脚）
- 阳台与室内高差处理
- 盆栽与绿植布置，避免阻挡通行

## 二、材料与施工选型要点

### 扶手

| 维度 | 选型要点 | 常见问题 |
|---|---|---|
| 材质 | 尼龙、喷塑钢管、不锈钢、木质；表面防滑、热惰性好 | 表面过滑、握感差 |
| 截面 | 圆形直径 30~45mm 或矩形 30~45mm，易抓握 | 截面过细抓不住，过粗老人使不上劲 |
| 固定方式 | 膨胀螺丝打孔固定于承重基层；基层类型需现场确认 | 打在空心砖、装饰板或轻质隔墙上，一掰就松 |
| 端部 | 向墙面或向下延伸，回勾收尾 | 平端断头，握持时易滑脱 |
| 色彩 | 与墙面有明显颜色或亮度对比 | 与墙面同色，老人找不到 |
| 连贯性 | 沿行动路线连续，不分段 | 只在转角装一段，走到中间无依托 |

**关于墙体**：扶手打进什么墙体，决定能用多久。开工会前必须让施工方说明墙体类型与固定方式；打不住就改方案（如加装支撑件、改变位置），不要将就。

### 防滑

| 维度 | 选型要点 |
|---|---|
| 材料 | 防滑砖、防滑贴片、防滑地胶、防滑涂层（按现状选择） |
| 判据 | 处理后摩擦系数 ≥0.5；重点看湿态表现 |
| 排水 | 防滑必须配合排水，否则积水反而更滑 |
| 观感 | 光面砖 + 防滑垫的组合要检查垫子是否移位、卷边（移位的垫子本身成为绊倒点） |

### 门槛与高差

- 优先**拆除门槛**而非加斜坡垫（长期使用的斜坡垫会移位）
- 必须保留门槛时，做固定式坡面过渡（坡度 ≤1:10）
- 石材门槛改坡面需确认与地面材质的接缝处理

### 照明

- 感应灯用于夜间路径；注意**感应灵敏度与延时**（人来才亮、亮度是否够）
- 开关位置改为伸手可及（床头、坐便旁、进门处）
- 避免强光刺激造成眩光；卫生间与卧室用柔和均匀光

### 紧急呼叫

| 类型 | 适用 | 注意 |
|---|---|---|
| 拉绳式 | 跌倒后手可及范围 | 拉绳末端须落在地面可拉到的位置（不是墙上高处） |
| 按键式 | 坐便旁、床旁 | 位置需满足"坐在坐便上和跌倒在地面的人都能使用" |
| 联网报警 | 独居、子女异地 | 需确认信号覆盖与响应方（家属 / 社区 / 物业），并有断电断网备用方案 |
| 人体存在感知 | 夜间失能老人 | 隐私与误报处理 |

### 智能与监测设备

- 跌倒监测、体征监测、烟感、燃气报警：按实际风险选，不必成套
- **先问"谁来响应"**：设备只负责发现，不负责救助
- 定期演练与更换电池计划要写进方案

## 三、费用区间参考

以下为市场常见区间的粗略参考，用于判断"报价是否离谱"，不作为定价依据。

| 改造项 | 常见区间 | 说明 |
|---|---|---|
| 单处扶手（含安装） | 数百元上下 | 与点位数量、墙体条件、是否定制相关 |
| 全屋扶手体系 | 数千至数万元 | 点位多时按点位累加 |
| 卫生间地面防滑处理 | 数百至数千元 | 面积与做法差异大 |
| 门槛/高差处理（固定坡面） | 数百至数千元 | 拆门槛成本低于重做地面 |
| 淋浴椅 / 坐台 | 数百元上下 | 折叠式与固定式价差明显 |
| 坐便器加高 / 坐便椅 | 数百至数千元 | |
| 感应夜灯（单个） | 数十至数百元 | |
| 紧急呼叫装置（单套） | 数百至数千元 | 联网型偏高端 |
| 照明整体升级（卫生间/卧室） | 数百至数千元 | |
| 家具调整与辅助件 | 数百至数千元 | |
| 门拓宽（含拆改与加固） | 数千元起 | 涉及墙体拆改 |
| 卫生间深度改造（拆改、防水、管线） | 数千元至数万元 | 拆改项差异极大 |
| 全屋基础型改造 | 数千至两万元区间 | 视面积与点位 |
| 全屋含系统设备改造 | 两万元至数万元 | 设备占比高 |

**报价对比方法**：
1. 要求**分项报价**（拆到每一项：材料、人工、辅料），拒绝"全包一口价"
2. 对照上面的尺寸与做法要求，核对报价里写的是"按规范做"还是"按师傅习惯做"
3. 问清**是否含隐蔽工程**（基层、防水、电路、防水涂料）与**成品保护**
4. 问清**质保范围与责任划分**（扶手松动、防水渗漏、设备故障分别谁负责）
5. 警惕两种话术："这个用不了几年"（降低标准诱导降配）、"我们做过很多老人家庭都这么装"（用经验替代规范）

## 四、有限预算下的排序模板

### 1万级预算
1. 防滑处理（卫生间 + 厨房）2. 关键点位扶手（马桶侧、淋浴区、床边、门口）3. 门槛与高差处理 4. 夜间照明

### 3万级预算
1万级全部 + 5. 如厕洗浴辅助（坐便加高、淋浴椅）6. 紧急呼叫装置 7. 家具高度与动线调整 8. 照明局部升级

### 5万级以上
3万级全部 + 卫生间局部深度改造（拆门槛、防滑重做、扶手体系、照明重做）9. 门拓宽或坡道 10. 部分智能监测设备

**排序铁律**：任何预算下，**安全项先做、可延后项往后放**；不要为了"看起来完整"先做硬装再补防滑。**先消掉会摔的地方，再谈住得体面。**
