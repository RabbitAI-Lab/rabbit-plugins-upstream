# 老人能力评估表与风险信号

用途：居家适老化改造前的评估工具，以及"该不该做整体评估"的判断依据。
本文是评估与信息整理辅助，不替代医生诊断与有资质评估人员的结论，需人工复核。

---

## 一、评估的基本逻辑：不是问"能行吗"，是问"发生过什么"

老人自评"我挺好的"与实际能力之间存在系统性偏差，原因有三：
- 对风险的感知阈值随年龄下降（老人不觉得自己会滑）
- 长期形成的应对习惯掩盖了能力下降（扶着墙走已成自然，不会提）
- 不愿意被看作"需要人照顾"

因此评估要用**事件法**而非**评价法**：

| 提问方式 | 效果 | 建议 |
|---|---|---|
| "您洗澡方便吗？" | 老人答"方便"，信息为零 | 换成"上次洗澡是什么时候？洗一次大概多久？有没有滑过或者扶墙扶得比较多？" |
| "晚上起夜方便吗？" | 老人答"还行" | 换成"起夜的时候开灯吗？开的是哪一盏？地上有没有东西？上次差点绊倒是什么时候？" |
| "需要人帮忙吗？" | 老人答"不需要" | 换成"上次洗澡、上下楼、出门买东西，分别是谁陪着？" |

**三类必问**：
1. 过去半年的一次意外或"差点出事"（含具体时间、地点、当时在做什么）
2. 生活的缩减（少洗澡、少出门、不敢上下楼、不敢独自如厕）
3. 现有辅具与代劳安排（谁在帮、帮到什么程度、用什么工具）

## 二、七维度评估表

对每一维度判定三档：**能独立完成 / 需协助或需扶靠 / 需设备替代**。

### 维度1：起居（穿衣、洗漱、上下床、起身）

| 观察点 | 判断线索 | 对应改造方向 |
|---|---|---|
| 上下床 | 是否需要手撑床沿才能坐起；床高是否低于膝盖以下太多 | 床高调整、床边护栏与抓杆、床头照明开关 |
| 穿衣 | 是否坐着穿裤；套头衫是否费力 | 宽松易穿衣物（辅具类，非硬装） |
| 洗漱 | 站位能否保持平衡；台面前是否需要弯腰 | 洗脸台高度与容膝空间、可抽拉式龙头 |
| 起身 | 从椅子起身是否需要撑扶、是否需要人拉 | 椅子高度与扶手、沙发与座面深度调整 |

### 维度2：如厕

| 观察点 | 判断线索 | 对应改造方向 |
|---|---|---|
| 起身与坐下 | 蹲便器起蹲是否吃力；坐便器坐高是否合适 | 蹲改坐、坐便器加高垫、坐便椅 |
| 如厕中支撑 | 能否自己稳住重心 | 马桶侧安全抓杆（水平抓杆距坐便上沿 250~350mm，长度 ≥700mm；另一侧 L 形） |
| 夜间如厕 | 夜间去卫生间的路径照明与地面状况 | 感应夜灯、路径无障碍、扶手连贯 |
| 求助能力 | 如厕中跌倒后能否够到呼叫装置 | 坐便附近救助呼叫装置，需满足"坐在坐便上和跌倒在地面的人都能使用" |
| 排泄后清洁 | 擦拭与整理是否需协助 | 助洁器具、抬高式辅助器具 |

### 维度3：洗浴

| 观察点 | 判断线索 | 对应改造方向 |
|---|---|---|
| 进出浴室 | 是否有门槛或挡水条；地面是否积水 | 门槛剔除或设坡面过渡（门口高差 ≤15mm）、坡度 ≤1:10 |
| 站立稳定 | 洗澡时是否需扶墙；能否单手完成 | L 形安全抓杆（水平段距地 700~750mm，长度 ≥700mm；竖向段顶部距地 1.40~1.60m） |
| 坐下洗 | 能否安全坐下并站起 | 淋浴坐台（高度 400~450mm，深 400~500mm，宽 500~550mm）、折叠淋浴椅 |
| 洗浴中照明 | 光线是否充足、是否有强光刺激 | 卫生间照明与夜间照明，避免强光直射 |
| 滑倒风险 | 地面材质是否为光面砖、是否积水 | 防滑处理（室内地面摩擦系数 ≥0.5）、排水与挡水条 |

### 维度4：动线

| 观察点 | 判断线索 | 对应改造方向 |
|---|---|---|
| 入户 | 门口高差、台阶、是否有坡道 | 门槛处理、坡道（纵坡 ≤1:12）、扶手 |
| 主要路径 | 卧室到卫生间、厨房到餐桌的路径是否通畅 | 通道净宽 ≥1.20m、地面高差消除 |
| 楼梯 | 能否扶栏上下、上下是否有视觉提示 | 楼梯扶手连续、踏步防滑与颜色区分、提示标识 |
| 门槛与挡块 | 家中门挡、门槛石、地面装饰块 | 拆除或改坡面、门去掉挡块 |
| 家具布局 | 通行是否需绕开家具、转身是否困难 | 家具重排与尺寸调整、去除尖角 |

### 维度5：感知

| 观察点 | 判断线索 | 对应改造方向 |
|---|---|---|
| 视力 | 是否能看清地面高差与障碍；是否有白内障等既往诊断 | 照明提升、色彩与材质对比、门槛视觉提示 |
| 听力 | 能否听到呼叫装置、门铃声 | 视觉震动式呼叫装置、闪烁提示灯 |
| 认知与判断 | 是否能识别危险、是否会误操作设备 | 设备选型简化、误触防护；认知异常时转专业评估 |
| 感觉 | 对温度、疼痛的感知是否下降 | 恒温设备、防烫措施 |

### 维度6：应急

| 观察点 | 判断线索 | 对应改造方向 |
|---|---|---|
| 独处时长 | 每天独处多长时间、有无失联风险 | 紧急呼叫与定位设备 |
| 呼叫能力 | 跌倒后能否自己按下按钮或拉动拉绳 | 拉绳式（低位）与按键式呼叫装置并存 |
| 呼叫对象 | 谁会响应、多久能到 | 呼叫对象清单与响应机制、联网报警 |
| 夜间响应 | 夜间跌倒如何被发现 | 人体存在感知、门磁、照明联动 |
| 备用方案 | 无人响应时的第二通道 | 双设备 + 定期演练 |

### 维度7：社交

| 观察点 | 判断线索 | 对应改造方向 |
|---|---|---|
| 外出能力 | 是否还愿意出门、能否往返 | 楼道与单元门改造、坡道与电梯、助行工具适配 |
| 社区参与 | 是否参加社区活动、是否有稳定社交 | 动线与出行的可达性 |
| 与家人同住 | 是否需要与子女同住、何种条件下愿意 | 居住安排与照护动线规划 |
| 活动空间 | 是否有安全的活动与晾晒区域 | 阳台与客厅的安全活动区、园艺空间 |

## 三、风险信号清单（出现即需上调优先级）

| 信号 | 含义 | 动作 |
|---|---|---|
| 半年内跌倒过（含轻微） | 风险已被证实 | 立即做防滑、扶手、照明三项，上调为必做 |
| 洗澡次数减少 | 环境在限制生活 | 优先改造卫浴，不接受"老人不愿意改"作为延后理由 |
| 起夜找不到灯或找不到路 | 夜间路径存在明确缺陷 | 路径照明优先做 |
| 独居且无呼叫装置 | 跌倒后无人知晓 | 紧急呼叫列为必做 |
| 已有认知障碍诊断或表现异常 | 环境改造作用有限，且存在走失风险 | 转专业机构评估，优先考虑照护方案与防走失 |
| 反复跌倒 | 原因可能不在环境 | 建议就医排查，同时做环境改造 |
| 起身需人扶 | 起坐能力下降 | 扶手与坐便高度列为必做 |
| 房屋有台阶且无坡道、扶手 | 进出即高风险 | 入口改造优先 |

## 四、能力等级参照与改造适用范围

参照《老年人能力评估规范》（GB/T 42195—2022）：

- **一级指标**：自理能力、基础运动能力、精神状态、感知觉与社会参与
- **二级指标**：进食、穿脱衣物、平地行走、上下楼梯、记忆、理解能力、视力、听力、社会交往能力等，共 26 个方面
- **能力等级**（5 级）：能力完好 → 能力轻度受损（轻度失能）→ 能力中度受损（中度失能）→ 能力重度受损（重度失能）→ 能力完全丧失（完全失能）

**适用范围提醒**（依《老年人居家环境适老化改造通用要求》MZ/T 218—2024）：
- 适用于按 GB/T 42195—2022 评估后，结果为**能力完好、能力轻度受损、能力中度受损**的老年人的居家环境适老化改造
- **不适用于**能力重度受损、能力完全丧失的老年人的居家环境适老化改造

**操作建议**：评估到"中度受损"时，方案应从"防跌倒"扩展到"照护动线 + 辅具 + 环境"，并引入照护方参与；已属重度受损或完全丧失时，**不要用常规适老化改造清单硬套**，应转有资质的照护机构做整体照护方案与居住安排评估。

## 五、要不要做整体评估的判断

| 情形 | 建议 |
|---|---|
| 老人基本自理，仅有个别隐患点 | 不做整体评估，做单项改造 + 观察 |
| 老人独居、80 岁以上、半年内跌倒过 | 做整体评估 |
| 有慢性病、多病共存、用药较多 | 做整体评估，并让医疗方参与环境需求确认 |
| 存在认知障碍或精神状态异常 | 做整体评估，且需专业人员参与 |
| 准备做全屋改造、涉及承重或管线改动 | 做整体评估 + 设计 |
| 预算较大（涉及多空间系统改造） | 做整体评估 |
| 子女与老人对改造范围分歧明显 | 先做整体评估，用评估结论作为客观依据打破分歧 |
| 房屋有加装电梯、外墙、单元门等公共部分改造诉求 | 转社区与相关主管部门路径，非居家改造范围 |

**评估 vs 咨询的区别**：咨询是子女问"该改哪几项"；评估是专业人员上门测量、观察、记录、分级，并出评估结论。**评估结论应当由具备资质的人员出具**，顾问负责把评估需求说清楚、把结果翻译成方案。
