# 行业与标讯专项检索模板（天机我要查 (免费版) · 扩展维度）

> 本文件为 `SKILL.md` 的扩展模板集，覆盖招标/中标、资质/证书、知识产权、行业格局、关联关系五类场景。
> 全部基于公开网络检索；**标讯与资质类时效极强，务必标注采集时间并以官方平台核验**。

## 1. 招标 / 中标 / 采购动态

适用：判断企业投标活跃度、中标能力、政府/国企客户结构、履约记录。

```
"{企业全称}" 中标 公告
"{企业全称}" 招标 采购 项目
"{企业全称}" 投标 候选人 公示
"{企业全称}" 政府采购 合同 验收
```

权威 / 垂直源（`site:` 限定）：

| 平台 | 域名 |
|------|------|
| 中国政府采购网 | ccgp.gov.cn |
| 全国公共资源交易平台 | ggzy.gov.cn |

## 2. 资质 / 证书 / 许可

```
"{企业全称}" 资质 等级 证书
"{企业全称}" 行政许可 资质审批
"{企业全称}" 体系认证 ISO 9001
```

行业垂直口径：

- 建筑：建筑业企业资质、四库一平台（全国建筑市场监管公共服务平台）

- 食品：食品生产/经营许可（属地市场监管局）

## 5. 关联关系 / 股权穿透

```
"{企业全称}" 对外投资 控股 子公司

"{企业全称}" 分支机构 分公司 办事处
```

> 关联推测仅作线索，**不下确定性结论**；重名企业须以统一社会信用代码区分，避免误判关联。

## 使用建议

1. 标讯类：优先 `site:` 限定官方/垂直平台，排除聚合站噪声。
2. 资质/证书类：以**发证机关官网**为准，web 检索仅作线索。
3. 时效性：招标/中标信息变动快，报告中标注采集时间，过期重查。
4. 交叉验证：高风险结论至少 2 个独立来源印证。
