# 天机我要查 (免费版)（tianji-open）

天机我要查 (免费版)（TianJi-Open）是一款开源免费的企业公开信息聚合与尽职调查辅助助手。基于网络公开检索，把分散在各渠道的企业信息整理成**可溯源、可行动**的结构化报告。

## 功能

- 工商基本信息、股东与实控人、经营风险（诉讼 / 失信 / 处罚 / 异常）、融资上市、新闻舆情、联系方式一站式聚合
- 逐条附来源、标注采集时间与核验要求，结果可信可查
- 内置检索语法模板与权威数据源清单（见 `references/`）
- 可选 `baidu-search` 技能批量加速

## 用法

在对话中直接说「查一下 XX 公司」「XX 有没有被处罚」等即可触发；多维度与批量用法见 `SKILL.md` 与 `references/`。

## 依赖

- **必选**：对话内置网络搜索（开箱即用）
- **可选**：`baidu-search` 技能（批量加速；未安装不影响核心功能）

## 合规与边界

- 仅使用已公开信息，遵守《个人信息保护法》，不收集个人敏感信息
- 结果仅供参考，不替代专业尽职调查；高风险结论须以官方渠道核验
