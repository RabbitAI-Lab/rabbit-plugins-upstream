## Description:

End-of-session reflection and memory curation with deja-vu. Review what was decided, what commands broke and what repaired them, and record durable project rules or decisions with deja remember so the next session starts with them.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers use this skill at the end of a work session to review project decisions and recurring command friction, then curate durable project facts for future sessions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Incorrect or unsuitable project facts saved to persistent notes could mislead future sessions or expose sensitive information.

Mitigation: Review proposed facts before confirming them, save only durable non-secret information, and inspect existing notes first to avoid duplicates or contradictions.

Risk: The supplied artifact does not establish the external deja CLI's implementation or storage behavior.

Mitigation: Approve only project facts you want retained across sessions, and avoid saving secrets.
