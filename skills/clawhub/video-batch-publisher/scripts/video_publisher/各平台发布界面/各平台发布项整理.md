一、B站中的发布项
1.1 标题：从excel中读取"标题"项
1.2 创作声明：下拉框，选择内容为"含AI生成内容"的选项。
1.3 分区：下拉框，选择内容为"亲子"的选项。
1.4 标签：固定为"亲子、阅读打卡、知识积累、原创"。然后根据类型添加"成语故事、古诗词、民俗故事"等，按照界面上的选项填充
1.5 简介：从excel中读取"描述"项
1.6 定时发布：应该是一个checkbox，你帮我看看对不对，然后勾选上之后，会出来三个下拉框，第一个时区不用管。第二个是日期：根据excel中的发布日期截取日期（yyyy-MM-dd）格式。第三个是时间：根据excel中的发布日期截取时间（可以加一个默认值20:00）
1.7 提交：有两个按钮"存草稿"，"立即投稿"
1.8（补充） 封面：选择“0_cover.png” 或者 "0_cover_350.png"。成语故事的文件夹下是有两个封面图的横屏（0_cover_350.png），竖屏（"0_cover_300.png"）。竖屏只在抖音平台用到，其他平台统一用 成语："0_cover_350.png" ，古诗词："0_cover.png"，其他分类的封面先按成语的来（主要是根据视频的尺寸来的，如果视频是横屏的就会有两个封面，竖屏只有一个封面，这个以后添加类型的时候再说）

二、抖音发布项
2.1 作品描述：这里可以输入两个内容：标题和简介，然后标题对应的html元素为：<input class="semi-input semi-input-default" type="text" placeholder="填写作品标题，为作品获得更多流量" value="">
			描述对应的html我没找到，我输入内容后对应的容器是div。* 标题限制为30个字，如果超出的话，优先清除里面的标点符号和书名号，还是不够就把“一听就会”删掉。
2.2 设置封面：这里有两个封面：竖封面3:4，横封面4:3。点击后会出现弹出层，先上传横封面。然后如果是成语故事需要上传竖封面（0_cover_300.png），如果是古诗词不用重新上传，直接点击设置竖封面，平台会直接使用横封面的图片。然后点击“完成”按钮就行。
2.3 添加合集：两个下拉款：1.不用管。2.请选择合集:选项内容跟类型一致（成语故事、古诗词、民俗故事、知识科普等）如果没有找到要写到日志里，我会去平台上做调整
2.4 自主声明：下拉框，选择内容为"内容由AI生成"的选项。
2.5 发布时间：选择定时发布，日期格式为 yyyy-MM-dd HH:mm 跟excel中的发布日期一致
2.6 提交：发布、暂存离开


三、快手中的发布项
3.1 作品描述：从excel中读取"描述"项
3.2 封面设置：古诗词选择“0_cover.png”，成语故事选"0_cover_350.png"。
3.3 作者声明：下拉框，选择选择内容为"内容为AI生成"的选项。
3.4 加入合集：下拉框，选项内容跟类型一致（成语故事、古诗词、民俗故事、知识科普等）
3.5 发布时间：单选框（立即发布、定时发布），选择定时发布，日期格式为 yyyy-MM-dd HH:mm:00 跟excel中的发布日期一致，快手的时间需要到秒，所以我们自动补充00秒就行
3.6 提交：点击“发布”按钮提交就行

四、小红书中的发布项
4.1 上传完视频后，上传封面：古诗词选择“0_cover.png”，成语故事选"0_cover_350.png"。
4.2 填写标题：excel中解析出来的标题。*标题限制为20个字，超出的话，先清除里面的“+|《》”符号，然后是“3岁”，“必背”，“古诗”，“第”，“集”。
4.3 输入描述：excel中解析出来的描述。
4.4 加入合集：下拉框，选项内容跟类型一致（成语故事、古诗词、民俗故事、知识科普等）
4.5 原创声明：首先是勾选复选框，然后出来的弹出层里，勾选我已同意....。 最后点击“声明原创”按钮。
4.6 添加内容类型声明：下拉框，选择内容为"笔记含AI合成内容"的选项。
4.7 定时发布：选择发布日期，日期格式为 yyyy-MM-dd HH:mm 跟excel中的发布日期一致
4.8 提交：暂存离开、定时发布

五、视频号中的发布项
5.1 上传视频后，在封面预览的图片上点击上传封面：古诗词选择“0_cover.png”，成语故事选"0_cover_350.png"。
		如果有两个封面，第一个封面上传后，点击第二个封面的时候，会出来一个层里面有两个按钮“直接编辑”，“使用素材”。点击“使用素材”就行了
5.2 视频描述：excel中解析出来的描述。
5.3 短标题：excel中解析出来的标题。*标题限制为16个字，超出的话，按顺序删减“每天”，“一首”，“古诗”，空格，“第”，“集”，书名号“《》”。
5.4 添加到合集：下拉框，选项内容跟类型一致（成语故事、古诗词、民俗故事、知识科普等）。
5.5 定时发表：单选框，选择定时
5.6 发表时间：选择发布日期，日期格式为 yyyy-MM-dd HH:mm 跟excel中的发布日期一致。
5.7 声明原创：首先是勾选复选框，然后出来的弹出层里，勾选我已同意....。 最后点击“声明原创”按钮。
5.8 提交：保存草稿，发表
