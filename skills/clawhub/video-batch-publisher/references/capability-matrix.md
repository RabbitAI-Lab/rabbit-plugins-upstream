## 登录方式（统一）
- 首次运行在独立浏览器标签页**手动扫码/账号登录一次**
- 登录态持久化在 `browser_cache`（user_data_dir），后续复用
- `browser_singleton.is_login_state_valid` 检测登录失效时，工具会等待用户重新登录

## 发布模式
- `publish`：正式发布
- `draft`：存草稿（部分平台支持，由 `publish_mode` 控制）

## 与 Excel 的约定（当前强约束）
待发布行需满足：`视频草稿=✓` 且 `视频完成=✓` 且目标平台列为空/未发布。
列结构：`序号 / 名称 / 标题 / 描述 / 视频草稿 / 视频完成 / 发布日期 / 抖音 / 视频号 / 快手 / B站`。
> ⚠️ 这是产品化最大耦合点（见 evaluation.md 第 3 项），通用版需让"源就绪列"可配置。
