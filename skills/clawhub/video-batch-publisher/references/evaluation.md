## 五、风险披露（上架文案必须写明）

1. **平台改版风险**：浏览器自动化的选择器随平台 UI 变化而失效，维护成本持续存在。
2. **账号封禁风险**：自动化发布违反部分平台 ToS（B站/视频号尤甚），批量操作可能触发风控。
3. **非官方 API**：不依赖平台开放接口，稳定性低于官方 API，但好处是免开发者资质。
4. **需本地环境**：买家需自备 Python + 安装 Playwright + 首次手动登录，门槛高于 SaaS。
