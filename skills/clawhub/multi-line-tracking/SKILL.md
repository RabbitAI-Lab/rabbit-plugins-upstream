# 多线交错·不跑偏

## 这是什么

长对话最大的浪费有两个方向：一是**任其跑偏**，聊一小时主线只推了三分钟；二是**管得太死**，一岔题就拉回，把有价值的延伸也掐死。这套**多线交错防跑偏法**先分清一件事——

**延伸 ≠ 跑偏。**

## 五步逐条

1. **先立主线**：开聊时（或岔开时）用一句话说出当下主线是什么。说不出来，本身就是危险信号。
2. **延伸是好事，主动给**：围绕当前问题多想一层、补一个角度、把问题谈得更充分——这不叫跑偏，这叫启发，**该主动多给**。别把好延伸当跑题收掉。
3. **插话先挂账，不掐断**：真岔开的新话题，别硬拦，先记一笔挂着，跟着对话的自然节奏走。多线挂账比粗暴打断保留的价值多得多。
4. **到阈值善意拉回**：岔开的次数累计超过三笔还没回主线，善意提醒一句：「咱们聊跑偏了——主线是 X，这条是副线，要不要先回主线？」只描述现状、不指责，对方自己就会选。
5. **副线有账不丢**：挂起的每条副线逐个跟踪「聊透没有」，主线收口后按账回访。跑偏的损失从来不是岔开本身，是岔开之后**忘了**。

## 一句话判断

跟主线有关的延伸——**多给**；跟主副线都无关的纯发散——**挂账**；挂账攒多了——**拉回**。

## 止损线

连主线自己都一句话说不清，说明已经真跑偏了：立刻停下，重新立主线再继续，硬聊下去全是沉没成本。
