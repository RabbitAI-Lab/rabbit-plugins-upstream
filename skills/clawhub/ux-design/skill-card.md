## Description:

This skill helps agents analyze and design user experiences using Nielsen heuristics, journey maps, interaction principles, and cognitive-load guidance.

This skill is ready for commercial/non-commercial use.

## Publisher:

[thcjp](https://clawhub.ai/user/thcjp)

### License/Terms of Use:

MIT-0

## Use Case:

Designers, product teams, and developers use this skill to audit product flows, build user journey maps, and propose interaction improvements for UX design scenarios.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The ClawHub security scan marks the skill as suspicious because it asks for broad file access, command execution, and possible external-service capabilities that are not clearly scoped to UX work.

Mitigation: Install only in trusted environments, review proposed actions before use, and require explicit confirmation before modifying files, running shell commands, or sending content to external services.

Risk: UX recommendations may be incorrect, incomplete, or misleading if the input context is thin or user research evidence is absent.

Mitigation: Treat outputs as draft guidance and validate recommendations against product data, usability testing, or human UX review before deployment.
