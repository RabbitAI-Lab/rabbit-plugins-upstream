# 复查单规范

本文件规定答复里「复查单」的写法。目的是：**别人拿着这份答复，不再问我一句，就能自己把结论复核一遍。**

适用范围：所有未命中题库、走过第 2 级检索的题目。题库命中的题按 §一 的 T0 处理。

---

## 一、输出分档

| 档 | 触发条件 | 输出内容 | 篇幅 |
|---|---|---|---|
| **T0 题库命中** | `lookup.cjs` 返回 `matched` | 四行 + 一行 `复查单：题库命中（entry_id=…，未联网）` | ≤ 6 行，**不出现任何外部 URL** |
| **T1 轻量** | 规则卡／题内推导／单一官方 API，无受阻、无下载产物、置信度 ≥ 80% | 四行 + 步骤（2–5 行）+ 网站表（1–3 行）+ 缺口（无则写"无"） | 8–15 行 |
| **T2 完整** | 出现下列任一：下载了文件、扫描件转图像识别、有 `blocked`/`error` 渠道、来源冲突、置信度 < 80% | 四行 + 全量步骤 + 网站表 + 产物 + 缺口 | 15–30 行 |

**置信度 < 80% 一律 T2**。理由：低置信度本身就是"证据有缺口"的自述，必须让人看到缺口长什么样。

---

## 二、步骤（Steps）

### 2.1 阶段码

| 码 | 阶段 | 典型动作 | 何时结束 |
|---|---|---|---|
| S1 | 题库比对 | 写题目 JSON → `lookup.cjs` | 命中即止，不进 S2 |
| S2 | 题型分流 | 按 `retrieval.md` 判 calculation / basic-rule / record / fulltext / statistics / mixed | 得到唯一最短路径 |
| S3 | 定向检索 | 检索词原文、命中的来源类型 | 拿到候选原文入口 |
| S4 | 取原文 | 官方 API / `curl` / 浏览器；记最终 URL、文件大小、页数 | 拿到可读正文 |
| S5 | 可读性判定 | 文本提取为空 → 判"无文本层"→ 转页面图像；页码偏移校验 | 得到可读载体 |
| S6 | 版本与出处核对 | 书名/作者/版次/年份/机构是否与题干一致 | 确认是否可作为指定来源 |
| S7 | 交叉印证 | 第二来源只证"方向"，不替换题目指定工具的口径 | 关键缺口收敛 |
| S8 | 选项逐项判定 | A/B/C/D 各标 `supported` / `refuted` / `unknown` | 全部选项有判定 |
| S9 | 收口 | 写缺口一句 + 置信度 | — |

阶段码可以跳号（题目简单就只到 S4），但**顺序不能乱**，也不能为凑数补一个没执行的阶段。

### 2.2 每步记四件事

```text
S5 可读性判定  pypdf 提取全文仅 16 字符 → 判"无文本层" → 140dpi 渲染 17 页   [ok]
```

`输入/动作 → 输出 → 状态`。输出必须是**可验证的观察**（字符数、页数、HTTP 状态、返回字段值），不是"查了一下""确认了"。

### 2.3 状态枚举

| 状态 | 含义 | 反例（不算这个状态） |
|---|---|---|
| `ok` | 达成目标，拿到可复用证据 | — |
| `empty` | **确证**目标库无该条目 | 语法报错、加载中、权限错误 **不算** `empty` |
| `blocked` | 登录、验证码、机构权限、IP 范围挡住 | 网络超时不算（那是 `error`） |
| `error` | 报错、超时、429、格式不支持 | — |
| `skipped` | 主动跳过，**必须写理由** | 没想过要做的步骤不能事后标 `skipped` |

### 2.4 粒度

一步 = 一个**可被判成败**的动作，判据是"复查者照此重跑能得到同样的输出"。

- 同一站点的多次检索可合为一步，但检索词要**全列**。
- "下载 → 提取文本为空 → 渲染图像 → 识别" 至少拆成 **两步**（取原文、可读性判定），这是最容易被人跳过、也最容易被复查者质疑的一环。

## 三、网站清单（Sites）

| 列 | 写法 | 常见错误 |
|---|---|---|
| 名称 | 官方全称（读秀学术搜索） | "某数据库""相关网站" |
| URL | **实际到达页**，不是首页；含会话参数的去掉参数并标"（已去会话参数）" | 只写域名；写搜索结果页链接 |
| 用途 | 一句话说明"为哪个结论服务" | 写"参考" |
| 检索词 | 原文照抄，可直接复制 | 写"搜索了相关信息" |
| 结果 | `ok` / `empty` / `blocked` / `error` + 半句说明 | 只写"查到"或留空 |
| 定位 | PDF 第 n 页 / 页面区块 / 字段名；没有写 `—` | 写"见原文" |
| 时间 | 取证时点，到分钟（2026-10-23 16:24） | 写日期不写时间 |
| 档案 | 对应 `references/sites/<站>.json`，没有写 `—` | 编一个不存在的档案名 |

**必须入表的三种情况**：

1. 成功的来源（否则"依据"无处可点）；
2. 明确空结果的库（否则复查者会以为漏查）；
3. **受阻与报错的渠道**（否则答复会显得比实际更有底）。

**禁止写入**：候选/计划访问但没去的站点；账号、Cookie、令牌、验证码；候选选择器或"猜测的接口"。

---

## 四、产物与缺口

- **产物**：本次落盘的文件（题目 JSON、下载的 PDF、渲染的页面 PNG、截图）。写绝对路径，方便复查者直接打开同一份字节。
- **缺口**：一句"取得后能改变结论或提高置信度"的关键信息。没有就写"无"。
  - 反例："还需进一步核实"（不可行动）
  - 正例："原书第五章第一节正文未取得（读秀 `login.jsp` 需机构账号）；取得后可把 72% 提到 95% 以上"

---

## 五、两条硬约束

1. **不得事后补编。** 没做的步骤不写；做了但最终没用的也要写（隐瞒会让人以为漏查）。
2. **失败必须留痕。** `blocked` / `error` 不写进表，等于把"没查到"伪装成"查到了"。

## 六、样例

### 6.1 T0 题库命中

`entry_id` 取自 `lookup.cjs` 返回的 `result.sources[0].entry_id`，行号取 `line`：

```text
答案：A、B、C、D。
依据：题库命中，条目解析为"PDF 转 Word／合并／拆分／压缩"四项。
来源：本地题库 references/question-bank.json（entry_id=M01:official，line 28）
置信度：95%（高）
复查单：题库命中（entry_id=M01:official，未联网）
```

题库命中**不给外部 URL**，即使条目里带 `referenced_urls`——那是题库作者的记录，本次并未访问。

### 6.2 T1 轻量（规则卡）

```text
答案：B。
依据：检索 20 篇命中 9 篇相关、库内相关 15 篇 → 查全率 60%、查准率 45%，与选项 B 一致。
来源：题内数据 + 规则卡 references/rules.json（retrieval-metrics）
置信度：93%（高）
复查单
S2 题型分流  计算题，数据齐全 → 不外搜                    [ok]
S8 选项判定  按 0.60 / 0.45 读四个选项，唯一匹配 B          [ok]
网站：无（未联网，未开浏览器）
缺口：无
```

来源：本地题库未命中 → 同类教材正文 + 出版目录核版本（详见网站表）
置信度：72%（中）

复查单
S1 题库比对   输入 q1.json（single／4 选项）→ lookup.cjs → miss（0 候选）              [empty]

## 七、复查者的三步操作

1. **重跑题库**：`node <SKILL>/lookup.cjs <题目JSON>`，确认 `status` 与 S1 一致（命中题到此为止，不必往下看）。
2. **点 URL 对定位**：逐个打开网站表里的 URL，按"定位"列找到那句话/那个字段，与"依据"比对是否同一段文字。
3. **看缺口**：缺口是否只影响置信度、不影响选项判定；若缺口正好可能推翻答案，答案应标记"待核验"。

若第 2 步发现某个 `blocked` 站点在自己的网络/账号下其实能打开，补齐该节正文后答案可能改变，请把结果反馈回来。

## 八、常见错误对照

| 写错的 | 写对的 | 问题 |
|---|---|---|
| 来源：某教材与网络资料 | 来源：`pdfyl.ertongbook.com/19/30931833.pdf` 第 3 页版权页 | 无法点开核验 |
| 检索了一下相关信息 | 检索词 `信息伦理 核心要素 信息检索与利用` | 无法复现 |
| 读了 PDF，确认内容 | 提取全文 16 字符 → 判无文本层 → 140dpi 渲染后识别 | 抹掉了最关键的一步判断 |
| 查了读秀，没找到 | 读秀 `login.jsp` blocked（需机构账号） | "没查到"与"进不去"混为一谈 |
| 已核验 | 未访问的链接不写；访问了但被挡就写 blocked | 页面打开 ≠ 已核验 |
