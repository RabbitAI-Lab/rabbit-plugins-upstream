## Description:

Guides an agent through turning a creative idea into a user-reviewed video-production plan, expanding it into canvas shapes, and applying the workflow to a canvas.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers can use this skill to turn a creative idea into a staged story, character, scene, and shot plan, then expand and apply that plan to a canvas.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected local media may be sent to dLazy hosted services, which could expose sensitive content.

Mitigation: Check that prompts and media are suitable for the service before running the workflow.

Risk: The documented install and generation paths leave it unclear whether to use the canvas handoff or direct CLI generation.

Mitigation: Review the CLI install details and confirm the intended execution path before installing or running the workflow.
