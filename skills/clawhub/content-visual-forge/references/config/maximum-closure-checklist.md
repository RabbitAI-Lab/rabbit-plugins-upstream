# Maximum Closure Checklist

用于判断本 Skill 是否接近最大闭环。

## 1. 输入闭环

- [ ] 已识别输入源类型
- [ ] 已完成 Source Lock
- [ ] 已明确内容边界和不确定项

## 2. 路由闭环

- [ ] 已选择输出模式
- [ ] 已选择执行模式
- [ ] 已说明选择原因

## 3. 内容闭环

- [ ] 内容来自当前输入源
- [ ] 未混入历史示例
- [ ] 没有过度扩写事实

## 4. 视觉闭环

- [ ] 与输出模式匹配
- [ ] 公众号文内图没有页码胶囊
- [ ] 知识卡允许页码但文内图不允许
- [ ] 文字密度合适
- [ ] 视觉导演：社交平台组图已输出内容类型、传播目标、读者情绪、信息密度、三套风格方向和反模式扫描
- [ ] 视觉导演：页面角色节奏已定义且角色有变化
- [ ] 插画语法：启用时已声明 scene_role、subject_focus、composition_axis、camera_distance、texture_level、text_load
- [ ] 插画语法：blocked_mimicry 已声明，未复制具体艺术家或图鉴构图

## 5. 质检闭环

- [ ] 内容忠实度已检查
- [ ] 中文可读性已检查
- [ ] 视觉一致性已检查
- [ ] 反抄袭已检查
- [ ] 风险动作黑名单已扫描
- [ ] 素材来源策略已检查（使用外部素材时）
- [ ] 插画语法一致性已检查（启用时）

## 6. 重试闭环

- [ ] 已判断是否需要重试
- [ ] 已写明重试原因
- [ ] 已给出重试策略

## 7. 生产闭环

- [ ] 已判断是否需要工程化渲染
- [ ] 已提供结构化数据
- [ ] 已提供模板或渲染建议
- [ ] 已输出 Run Log
