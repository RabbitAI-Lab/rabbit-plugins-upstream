# 防抄袭规范

当用户提供参考图、截图、已有信息图、竞品图、网页排版时，本 Skill 只能提取：

- 主题范围
- 内容逻辑
- 信息层级
- 风格倾向
- 色彩气质
- 可视化类型
- 风格因子（线条、光线、空间、材质、构图逻辑、情绪）

不得复制：

- 独特构图
- 完整版式
- 图标摆放组合
- 装饰元素组合
- 原文标题和口号
- 设计细节组合
- 原图字体造型
- 品牌识别元素

## 安全改写策略

1. 更换页面结构：例如从四宫格改为路线图。
2. 更换视觉隐喻：例如从阶梯改为地图。
3. 更换装饰系统：例如从花草角标改为纸张纹理。
4. 重写文案表达。
5. 保留比例和大致风格气质，但不保留独特版式。

## 参考图提示词必须写明

> Use the reference image only for style direction. Do not copy its layout, composition, icon placement, typography, decorative elements, or text expression.

## 画家图鉴补充

当参考来源是画家风格图鉴时，优先读取本地 snapshot，不把图鉴图片或画家名作为可复制对象。先转换成宽风格家族与风格因子，再重组为服务当前内容的新画面。
