# WeChat Image Count Rules

公众号图片数量不应固定，必须结合内容类型、文章长度、阅读节奏判断。

## 一、文章类型判断

### 1. 教程 / 方法论文章

适合：
- 封面图
- 3–6 张结构图 / 步骤图 / 框架图

默认建议：
```text
1 张封面 + 3–6 张文内结构图
```

### 2. 观点文章

适合：
- 封面图
- 2–3 张文内重点图
- 1 张尾图可选

默认建议：
```text
1 张封面 + 2–3 张文内图
```

### 3. 影评 / 散文 / 情绪随笔

适合：
- 封面图
- 1–2 张氛围图
- 1 张结尾尾图

默认建议：
```text
1 张封面 + 1–2 张氛围图 + 1 张尾图
```

### 4. 短文

适合：
- 只做封面
- 或封面 + 1 张尾图

默认建议：
```text
1 张封面
```

### 5. 产品介绍 / 项目介绍

适合：
- 封面图
- 功能亮点图
- 使用场景图
- 对比图

默认建议：
```text
1 张封面 + 2–4 张功能 / 场景图
```

## 二、文内图禁止项

公众号文内图默认禁止：

- 右上角页码胶囊
- 大段解释文字
- 每张图都像独立卡片
- 过多图标和列表
- 不必要的标题重复
- 小红书 carousel 风格

## 三、文内图推荐项

- 留白
- 情绪感
- 与段落内容对应的视觉隐喻
- 一句短句或无文字
- 统一色调
- 适合作为阅读停顿
