# Risk Action Blacklist

本文件列出 `content-visual-forge` 在生成视觉资产时必须明确避免的高风险动作。命中任一项时，优先停止、降级、重写脚本或切换工程化渲染，不要继续生成。

## Source And Facts

- 不得在 Source Lock 未完成时生成图片。
- 不得把历史示例、旧项目主题或常见知识混入当前来源。
- 不得把无法读取的截图、模糊扫描件或不完整转写稿当作已确认事实。
- 不得为了填满页面补写来源中没有的论点、数据、步骤、品牌结论或产品能力。

## Output Routing

- 不得跳过 Output Mode Router 或 Execution Mode Router。
- 不得把公众号文内配图误做成小红书高密度组图。
- 不得把 `social-card` 和 `knowledge-carousel` 混成同一套输出；前者服务传播论证，后者服务知识结构。
- 不得在一个主任务里混用多个输出模式而不拆分子任务。

## Text And Typography

- 不得默认把小字号中文、长段中文、表格、代码或多层列表交给图像模型排版。
- 不得为了塞进画面把标题、正文、脚注或截图说明缩到手机缩略图不可读。
- 不得在未请求时加入考试名、等级标签、课程体系标签或营销口号。
- 不得让标题压住人脸、产品关键部位、UI 主操作区、代码、表格或证据截图。

## Platform And Layout

- 不得在未声明平台规格、安全区和命名规则时生成社交卡或公众号封面对。
- 不得把微信公众号 `21:9` 主封面硬裁成 `1:1` 方封面。
- 不得把主封面的完整长标题硬塞进方封面。
- 不得用随机装饰圆点、贴纸、渐变团块或嵌套卡片填补 3:4 下半部分空洞。
- 不得让同组卡片每页都像同一个模板换字。

## Design Enhancement

- 不得让设计增强改写 Source Lock、输出模式、执行模式、平台规格或内容事实。
- 不得为了“高级感”删除关键证据、降低信息密度到失真，或牺牲截图可读性。
- 不得只输出“更高级”“更好看”“增强设计感”这类不可执行描述；必须落成 visual tokens、layout variants、CSS notes 或 QA。
- 不得把额外设计能力缺失当作失败条件；使用默认设计规则继续。
- 不得在社交平台组图中跳过视觉导演判断而直接堆页面；必须先给出内容类型、传播目标、读者情绪、信息密度、页面角色和反模式扫描。
- 不得把外部小红书视觉 Skill 的风格库原文、示例图构图或模板输出格式当成可复制资产。

## References, Copyright, And Assets

- 不得复制外部模板、CSS 类名、shader、slide layout ID、版式组合、装饰组合、图标摆放组合或视觉签名。
- 不得把参考图里的原文标题、口号、品牌识别元素或字体造型搬进新图。
- 不得要求模型直接仿写在世或近期活跃艺术家的个人风格。
- 不得把 Qiaomu style atlas 的图片路径当作本地可用生产素材。
- 不得使用未授权 logo、产品图、人脸、IP 角色或品牌资产作为商用成品素材。
- 不得把免费图库图片称为“无版权”并跳过来源、许可证、署名和商用限制记录。
- 不得在 HTML / CSS 渲染中硬编码来源不明的远程背景图、纹理、照片或 logo。

## Engineering Rendering

- 不得在批量、商用或文字必须精确的任务中坚持直接生图排字。
- 不得在渲染模板缺字段、样例数据不匹配或截图不可读时标记为可交付。
- 不得忽略 Playwright / 渲染脚本失败并继续声称已产出 PNG。

## Required Reaction

命中黑名单时按顺序处理：

1. 回到 Source Lock、Output Mode Router、Execution Mode Router 或页面脚本，修正根因。
2. 如果是文字稳定性问题，切换 `engineering_rendering`。
3. 如果是素材缺失，记录缺口并改为信息图、抽象视觉、prompt package 或请求用户补充素材。
4. 如果是版权或仿写风险，重新提取宽风格因子，不复制具体作品、模板或品牌元素。
5. 如果是外部素材授权不明，按 `asset-source-policy.md` 改用 CSS 纹理、公共素材、用户授权素材或请求确认。
6. 如果连续两次仍失败，停止交付并在 Run Log 中记录阻断原因。
