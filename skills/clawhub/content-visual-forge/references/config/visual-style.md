# 视觉规范：温润书卷知识卡

## 1. 基础画幅

- 默认比例：3:4
- 推荐尺寸：1080 × 1440、1086 × 1448 或同等 3:4 竖版
- 适用平台：小红书、公众号图文、知识卡片、课程图解

## 2. 色彩系统

### 主背景

- 奶油白
- 米白色
- 浅纸张纹理
- 不使用高饱和纯白背景

### 主色

- 深墨绿
- 鼠尾草绿
- 橄榄绿

### 强调色

- 珊瑚橙
- 暖橘红
- 仅用于关键词、下划线、问号、页内重点

### 辅助色

- 浅棕
- 淡灰绿
- 淡米黄

## 3. 固定视觉组件

- 左上角植物线条徽标
- 右上角页码胶囊
- 大标题区域
- 副标题 / 解释句
- 圆角信息卡
- 虚线总结框
- 灯泡 / 星标 / 靶心等总结图标
- 植物枝叶装饰

## 4. 图标语言

- 扁平插画
- 线面结合
- 低饱和绿色为主
- 珊瑚橙点睛
- 不使用复杂写实照片
- 不使用过度 3D 化图标

## 5. 风格稳定规则

1. 每组图必须共享同一背景、页码、装饰系统。
2. 一组图最多使用 6 种核心图标隐喻。
3. 每页信息密度相近。
4. 视觉变化来自内容结构，而不是任意换风格。
5. 参考图只作为风格锚点，不复制构图。
