# 布局系统

## 1. 标准页面结构

默认页面采用：

```text
顶部装饰区
↓
主标题区
↓
副标题 / 核心解释区
↓
主体卡片区
↓
底部总结框
```

## 2. 页面类型

### A. 封面页

适合：系列开头。

组成：

- 大标题
- 核心问题
- 来源说明
- 3—4 个关键词卡片
- 底部引导句

### B. 总览页

适合：展示结构、层级、地图。

组成：

- 大标题
- 二级结构
- 3—5 个分组
- 总结句

### C. 对比页

适合：旧 vs 新、问题 vs 方法、误区 vs 正解。

组成：

- 左右双栏
- 中间箭头
- 2—4 个对比点
- 底部结论

### D. 步骤页

适合：方法论、流程、SOP。

组成：

- 3—6 个步骤卡
- 箭头 / 时间线 / 阶梯
- 每步一句话说明

### E. 分层页

适合：等级、阶段、难度、能力边界。

组成：

- 三段或多段卡片
- 阶梯 / 进度条 / 层级地图
- 底部提炼

### F. 总结页

适合：收束和行动建议。

组成：

- 大结论
- 3 条建议
- 收藏 / 行动提醒

## 3. 信息密度规则

AI 直接生图模式：

- 主标题：8—18 个汉字
- 副标题：12—28 个汉字
- 单张卡片：最多 20 个汉字
- 底部总结：最多 40 个汉字
- 每页总中文字符数建议不超过 140

工程化渲染模式：

- 可承载更多文字
- 但仍建议每页只讲一个核心观点
