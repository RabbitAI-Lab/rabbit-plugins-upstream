# Platform Specs

用于平台化社交图片、公众号封面和工程化渲染输出。这里记录的是尺寸、命名和构图规则，不绑定外部模板或素材。

## 小红书 / Rednote

默认输出：

- 尺寸：`1080 x 1440`
- 比例：`3:4`
- 文件：文字型图片优先 PNG；纯照片可按需 JPEG
- 推荐组图：1 张封面 + 4-8 张内容页；必要时加总结页

安全区：

- 左右边距：72-96px
- 顶部边距：72-112px
- 底部边距：80-120px
- 所有文字、关键图像和页码必须在安全区内

命名：

```text
output/social-01-cover.png
output/social-02-<topic>.png
output/social-03-<topic>.png
```

内容页规则：

- 每页只承载一个核心观点。
- 标题尽量控制在 12-30 个中文字符。
- 正文以 2-4 个短句、短项目或一个短段落为主。
- 有截图 / 产品图时，减少文字，把图像证据区放大。
- 下半部分持续空洞时，合并页面、补功能性元素，或切换为更稀疏的页面角色。

## 微信公众号封面对

当用户要求公众号正式封面、主封面 + 方封面、跨平台复用封面时，默认生成一组：

1. `21:9` 主封面
2. `1:1` 方封面
3. 可选组合预览，用于人工检查二者是否属于同一视觉系统

### 21:9 主封面

- 尺寸：`2100 x 900`
- 比例：`21:9`
- 用途：公众号文章主封面
- 可承载完整标题、短副标题和视觉证据
- 标题默认靠中左或稳定安全带，不要让画面中部空洞

### 1:1 方封面

- 尺寸：`1080 x 1080`
- 比例：`1:1`
- 用途：列表、分享、缩略图等方形场景
- 默认使用短标题，不默认放副标题
- 除非用户明确要求，不直接复用大图的长标题和复杂构图

短标题规则：

- 从长标题提取核心对象和最强动作。
- 优先 4-10 个中文字符。
- 必要时拆成两行短标题。
- 删除解释性从句、长修饰语和背景铺垫。
- 不把 `21:9` 完整标题硬塞进 `1:1`。

命名：

```text
output/wechat-21x9-cover.png
output/wechat-1x1-cover.png
output/wechat-cover-pair-preview.png
```

## 截图与照片放置

- 原始素材应保存到任务资产目录，并记录来源。
- UI 截图、代码、表格、长窗口优先 `object-fit: contain`。
- 人像、产品物体、场景照片可用 `object-fit: cover`，但必须声明裁切安全。
- `object-position` 需要根据主体位置设置，不使用默认居中蒙混。
- 截图页要给截图足够面积，不能把截图压成装饰。

## 工程化渲染建议

社交卡和公众号封面对适合使用单 HTML 多 frame：

```text
task-folder/
  index.html
  assets/
  output/
```

每个输出 frame 使用稳定 id：

```text
social-01-cover
social-02-point
wechat-21x9-cover
wechat-1x1-cover
wechat-cover-pair-preview
```

渲染后必须检查实际像素尺寸。
