# Character Card Style Spec

## 定位

用于英文用户或初学者的单字学习卡，强调：

- 友好
- 清晰
- 可爱
- 可批量生成
- 中文、拼音、英文三线清楚分区

## 画面规格

- 比例：3:4
- 结构：上标题区 + 主字区 + 信息模块区 + 底部记忆区
- 文案密度：短句化，避免长段

## 默认色彩

- 奶油白背景
- 标题可用多彩字：绿 / 蓝 / 橙 / 粉
- 模块标签：柔和浅绿、浅蓝、浅橙、浅紫
- 边框：缝线感 / 虚线感 / 贴纸边框

## 默认模块

1. Title / Banner
2. Main Character
3. Pinyin
4. Meaning
5. Common Words
6. Example Sentence
7. Useful Phrase
8. Memory Tip

## 文案规则

- 默认不要自动加入考试名称或考试标签。
- 可使用中性标签：
  - `Chinese Character Card`
  - `Single Character`
  - `Beginner Chinese`
  - `Learn one character at a time`
- 若用户明确要求某课程体系标签，再追加。

## 插画规则

- 插画必须和字义相关
- 风格：儿童插画、贴纸感、小物件、轻松亲切
- 不复制参考图具体人物姿态和装饰位置
