# 字体与中文文字规范

## 1. 字体气质

- 标题：现代宋体感 / 书卷感 / 教育感
- 正文：清晰、端正、易读
- 强调词：可用粗体、珊瑚橙、手绘下划线

## 2. 中文生图安全规则

AI 直接生图时：

1. 避免长段落。
2. 避免密集表格。
3. 避免一页超过 6 个复杂术语。
4. 避免多层嵌套列表。
5. 数字和英文缩写要少而明确。
6. 关键词优先短词化。
7. 重要文本不放在极小字号。

## 3. 标题规范

推荐标题类型：

- “到底变了什么？”
- “先看总定义”
- “真正的升级逻辑”
- “第 X 步：……”
- “从 A 到 B”
- “不是 A，而是 B”

## 4. 文案压缩规则

长句转短句：

```text
原文：这项方法能够帮助写作者在结构与创意之间找到平衡，并逐步扩展为完整小说。
卡片文案：
结构不死板，创意不失控。
从一句话，长成一部小说。
```

## 5. 工程化文字规则

工程化渲染时：

- 文字必须由程序渲染。
- 不依赖生图模型生成中文。
- 图片背景和图标可由 AI 生成。
- 导出前必须人工或脚本校对文字。
