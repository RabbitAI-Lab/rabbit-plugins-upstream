# Workflow 02 · Output Mode Router

在完成 Source Lock 之后，先判断本次任务属于哪一种输出模式。

## 可选模式

1. `knowledge-carousel`
2. `wechat-inline-image`
3. `social-card`
4. `cover-card`
5. `character-card`
6. `vocabulary-card`
7. `grammar-card`
8. `phrase-card`

## 判定逻辑

### 适合 `knowledge-carousel`

当内容源具备以下特征时：

- 有明显章节结构
- 适合拆成 6–12 页
- 每页能承载一个核心点
- 目标是解释、总结、图解、科普、方法论传播

### 适合 `wechat-inline-image`

当内容源具备以下特征时：

- 目标是公众号正文配图、段落分隔图、情绪过渡图或尾图
- 不需要小红书式高信息密度卡片
- 不需要固定 6 页或右上角页码胶囊
- 重点服务阅读节奏、情绪承接或段落结构

### 适合 `social-card`

当内容源具备以下特征时：

- 目标是小红书 / Rednote / 社交平台 3:4 组图
- 需要形成一组可滑动、可传播、可截图复用的视觉论证
- 内容适合拆成 4-8 页，每页一个观点
- 需要平台规格（1080×1440）、内容压缩阶梯和页面角色编排
- 有截图、产品图或照片作为视觉证据

与 `knowledge-carousel` 的区别：

- `knowledge-carousel` 优先讲清知识结构，适合方法论、教程、科普
- `social-card` 优先形成传播性视觉论证，适合产品更新、工具介绍、清单、对比、避坑、购买建议

### 适合 `cover-card`

当内容源具备以下特征时：

- 目标是公众号封面、头图、首图或海报封面
- 需要移动端标题可读
- 需要封面 Prompt、背景图提示词或标题排版规范
- 正式发布时可走无文字背景图 + 后期排版

### 适合 `character-card`

当内容源具备以下特征时：

- 核心对象是一个汉字
- 需要解释拼音、英文义项、常用词、例句、记忆点
- 目标是做单张学习卡
- 结构化字段比长篇分镜更重要

### 适合 `vocabulary-card` / `grammar-card` / `phrase-card`

当内容源具备以下特征时：

- 核心对象是词表、语法点、短语或句型
- 需要批量生成结构统一的学习卡
- 文字准确性高于画面随机性
- 商用、批量或教学场景优先进入工程化渲染
