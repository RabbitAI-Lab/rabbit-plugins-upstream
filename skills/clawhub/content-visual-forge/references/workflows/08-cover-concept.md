# Workflow 08 · Cover Concept

仅当输出模式为 `cover-card` 时使用。

## 目标

根据文章标题、摘要、正文与传播意图，生成封面概念包。

## 需要完成的步骤

1. 内容意图分析
2. 风格路由
3. 本地图鉴风格转译（如用户要求画家 / 流派 / 图鉴风格）
4. 视觉概念设计
5. 构图与留白策略
6. 中文标题排版策略
7. 预览图或正式封面路径判定

## 关键规则

- 封面必须服务文章主题
- 高级感来自克制、留白、秩序和对比
- 正式封面优先无文字背景图 + 后期标题排版
- 小字号中文默认不交给图像模型
- 画家图鉴默认读取本地 snapshot，只能转译为风格因子，不默认仿写具体艺术家
