# 工作流 01：Source Lock

## 目标

在进入卡片创作前，锁定当前内容源，防止内容跑偏、历史样例串台、模板内容误用。

## Source Lock 必须回答的问题

1. 当前内容源是什么？
2. 它真正讲的主题是什么？
3. 它的核心主线是什么？
4. 哪些内容是事实？
5. 哪些内容是可解释推断？
6. 哪些内容不能出现？
7. 适合拆成几页？
8. 每页大致讲什么？

## 标准输出

使用 `assets/templates/source-lock-report.md`。

## 内容边界写法

必须明确写出：

```md
## 禁止偏离项

- 不得生成与当前输入源无关的主题。
- 不得套用历史示例。
- 不得把参考图内容当作当前主题。
- 不得虚构原文没有的事实。
```

## 生图前闸门

只有满足以下条件，才允许进入分页脚本和生图：

- [ ] 已识别输入源类型
- [ ] 已总结原始主题
- [ ] 已列出核心结构
- [ ] 已列出禁止偏离项
- [ ] 已给出建议分页
- [ ] 已标注不确定信息

## 快速 Source Lock

当用户明确要求“直接生成”时，也必须在内部完成简版 Source Lock：

```md
源类型：
主题：
主线：
禁止偏离：
页数：
```

不得跳过。
