# Task: Layout Typography

## 目标
将长标题转化为适合公众号封面的标题结构。

## 输出
- original_title
- cover_title_loyal_version
- cover_title_marketing_version
- subtitle
- line_breaks
- title_position
- font_mood
- color_suggestion
- cover_design_family
- theme_preset
- grid_axis
- title_safe_zone
- text_weight_plan
- mobile_readability_notes

## 标题策略
1. 原标题适合文章，不一定适合封面。
2. 封面标题可以二次创作，但不能歪曲文章。
3. 必须输出“忠实版”和“传播版”。
4. 如果使用 `editorial-ink` 或 `swiss-grid`，必须同时声明主题预设、标题安全区和字号 / 字重阶梯。

## 示例
原标题：
很多人学不好 AI，不是因为笨，而是被第一批名词吓住了

忠实版：
```text
学不好 AI
不是因为笨

而是被第一批名词
吓住了
```

传播版：
```text
学 AI
先别怕那些名词

给初学者的
第一张地图
```
