# Visual Complexity Budget

## 目的
防止公众号封面在移动端缩略图中变得混乱。

## 默认预算
```yaml
max_primary_objects: 3
max_secondary_objects: 4
max_concept_nodes: 5
max_color_families: 4
decorative_readable_text: 0
```

## AI 入门知识地图类封面建议
主要对象最多保留：
1. 台灯
2. 手绘地图
3. 空白笔记本

辅助对象可选：
- 铅笔
- 杯子
- 植物
- 少量图标节点

应避免：
- 大量书籍
- 墙上密集纸张
- 过多便签
- 每个节点都写术语
- 多层标题
