# Typography Layout

## 标题长度处理
### 1-8 字
可大字突出。

### 9-16 字
建议 2 行。

### 17 字以上
建议改写为主标题 + 副标题。

## 必须输出两版标题
1. 忠实版：保留原题核心意思。
2. 传播版：更适合封面点击和视觉表达。

## 排版禁忌
- 廉价描边
- 强投影
- 过度渐变
- 字体过多
- 字太密
- 贴边
- 压在复杂背景上

## 安全区
四周边距建议 8%-12%。

横版封面常见标题区：
- 右侧 35%-40%
- 左侧 35%-40%
- 中央偏上
- 大面积墙面、天空、桌面、水面等低干扰区域

## 字号 / 字重阶梯

- 大标题越大，字重越轻；小标签和 metadata 字重应更稳。
- 中文标题必须优先改短，其次换行，再考虑降字号。
- 移动端封面不得依赖小于 16px 等效视觉的小字传达核心信息。
- `swiss-grid` 封面使用单一 accent，`editorial-ink` 封面使用纸感与墨色层级。
