# Safety and Copyright

## 风格描述
可以使用艺术流派和公版审美语言：
- 印象派
- 古典油画
- 东方水墨
- 现代 editorial
- 手绘插画

避免直接要求模仿在世艺术家的独特风格。

## 画家图鉴使用边界

外部画家风格图鉴只能作为观察参考，用来提取线条、色彩、光线、空间、材质、构图和情绪等风格因子。

允许：

- 使用宽艺术流派、历史时期、媒介和视觉语言
- 把公版艺术家的影响转译成风格因子
- 为同一主题比较多个风格方向

禁止：

- 要求模型直接复刻在世或近期活跃艺术家的个人风格
- 复制图鉴图片的构图、装饰组合、主体摆放或可识别签名
- 复刻具体名作、电影镜头、漫画分镜、品牌视觉或 IP 世界观
- 把未授权图鉴图片作为商用成品素材

## IP 风险
不要要求生成特定动漫、电影、游戏、品牌 IP 的角色、Logo 或可识别元素。

## 商用建议
正式公众号封面应避免：
- 明显复刻名画构图
- 未授权品牌 Logo
- 特定 IP 形象
- 可能误导读者的新闻摄影式画面
