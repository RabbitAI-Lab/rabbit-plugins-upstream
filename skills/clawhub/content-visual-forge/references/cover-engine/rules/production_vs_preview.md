# Production vs Preview

## Preview Image
用途：
- 看风格
- 看构图
- 看创意方向
- 快速演练

允许：
- 直接生成带标题图
- 主标题直接进入图像
- 少量副标题

不允许：
- 作为最终商用交付
- 出现小尺寸中文
- 密集装饰文字

## Production Cover
用途：
- 正式发布
- 商用交付
- 公众号首图

必须：
- 优先无文字背景图
- 后期叠加中文标题
- 经过质量门禁
- 保证移动端缩略图可读

## 关键判断
如果用户说“生成图片”，默认 preview_image。
如果用户说“正式 / 发布 / 商用 / 最终”，必须 production_cover。
