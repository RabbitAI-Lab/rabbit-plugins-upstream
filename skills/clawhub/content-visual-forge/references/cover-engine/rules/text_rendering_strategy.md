# Text Rendering Strategy

## 核心原则
图像模型不稳定生成中文小字，因此必须区分文字等级。

## Level 1：主标题
可在 preview_image 中尝试直接生成。正式封面中仍建议后期叠加。

## Level 2：副标题
默认后期叠加。如果 direct_image 预览中使用，必须极短。

## Level 3：装饰性小字
默认禁止图像模型生成。

包括：
- 书脊标题
- 便签小字
- 笔记页文字
- 地图标注
- 本子封面字
- 墙面纸张字
- 角标说明
- 长副标题
- 手写段落

## 替代方案
- 空白纸张
- 抽象线条
- 不可读纹理
- 图标
- 几何节点
- 路线
- 色块
