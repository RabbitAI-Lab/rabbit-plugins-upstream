# Text Adapter

## 适用输入

- 用户粘贴的一段话
- 小红书文案
- 公众号草稿
- 课程大纲
- 方法论笔记
- 访谈文字片段

## 处理流程

1. 判断文本长度和密度。
2. 提取主题、观点、论据、案例、行动建议。
3. 如果内容太散，进行结构增强，但必须标注为“基于原文的组织”。
4. 如果内容太短，只能做低保真扩展，不能虚构事实。
5. 进入 Source Lock。

## 内容增强规则

可以做：

- 重组结构
- 压缩标题
- 增加过渡页
- 提炼用户痛点
- 设计行动建议

不能做：

- 增加无来源数据
- 增加用户没说过的案例
- 把观点写成事实
- 换主题
