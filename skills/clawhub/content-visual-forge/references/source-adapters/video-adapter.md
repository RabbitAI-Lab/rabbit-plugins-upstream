# Video Adapter

## 适用输入

- 视频链接
- 视频文件
- YouTube / B站 / 小红书 / 抖音视频
- 视频字幕
- 视频转写稿

## 处理流程

1. 判断是否能读取视频内容。
2. 优先使用字幕 / 转写稿。
3. 没有字幕时，要求用户提供转写稿、摘要或关键时间段。
4. 如果可读取画面，提取视觉段落和屏幕文字。
5. 建立时间轴摘要。
6. 进入 Source Lock。

## Source Lock 必须包含

```md
- 视频标题：
- 视频时长：
- 可读取内容：字幕 / 转写稿 / 画面 / 用户摘要
- 时间轴结构：
  - 00:00–01:20：
  - 01:20–04:30：
- 核心观点：
- 适合转卡片的段落：
```

## 强规则

如果没有字幕、转写稿或足够摘要，不得声称已理解完整视频。
