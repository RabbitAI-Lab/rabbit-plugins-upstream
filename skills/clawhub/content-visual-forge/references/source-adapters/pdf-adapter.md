# PDF Adapter

## 适用输入

- PDF 文件
- 扫描版 PDF
- 教材章节
- 白皮书
- 课程讲义
- 方法论资料

## 处理流程

1. 判断 PDF 是否可解析文本。
2. 如果有文本：提取标题、目录、小标题、表格、关键段落。
3. 如果无文本：读取页面渲染图，进行视觉理解，必要时做少量 OCR。
4. 逐页建立摘要。
5. 提炼全局主线。
6. 进入 Source Lock。

## 输出字段

```md
- PDF 标题：
- 页数：
- 可解析程度：文本可解析 / 扫描图像 / 混合
- 每页摘要：
- 核心主题：
- 关键结构：
- 可视化线索：
- 不确定信息：
```

## 风险

- 扫描 PDF 文字可能识别错误。
- 图表内容可能被忽略。
- 页面视觉结构可能比文本更重要。

## 强规则

如果 PDF 无法解析文本，必须使用页面图像理解，不得直接套示例主题。
