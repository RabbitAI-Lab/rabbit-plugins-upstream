# Webpage Adapter

## 适用输入

- 博客文章
- 官网页面
- 产品介绍页
- 新闻报道
- 文档页面
- 公众号网页

## 处理流程

1. 抓取网页正文。
2. 去除导航、广告、评论、推荐栏。
3. 提取标题、作者、发布时间、正文小标题。
4. 保留关键引用、表格、图片说明。
5. 判断网页是否需要最新信息核验。
6. 进入 Source Lock。

## 输出字段

```md
- URL：
- 页面标题：
- 作者 / 机构：
- 发布时间：
- 正文主线：
- 小标题结构：
- 关键观点：
- 需要核验的信息：
```

## 风险

- 网页内容可能动态加载。
- 网页可能包含大量无关模块。
- 文章时间可能过旧。

## 强规则

不能把网页标题当作全部内容。必须阅读正文或明确说明无法读取正文。
