# Image Adapter

## 适用输入

- 截图
- 已有信息图
- 课件截图
- 白板照片
- 手写笔记
- 表格图片

## 处理流程

1. 先判断图片是内容源、风格参考，还是两者兼有。
2. 如果是内容源：提取文字、图表、结构、重点。
3. 如果是风格参考：只提取风格，不提取主题事实。
4. 如果既是内容又是参考：分别标注“内容可用部分”和“风格可用部分”。
5. 进入 Source Lock。

## 防抄袭规则

当输入为已有信息图时：

- 可提取内容逻辑。
- 可参考大致风格气质。
- 不得复制原图布局、构图、装饰元素、图标组合。

## 输出字段

```md
- 图片角色：内容源 / 风格参考 / 混合
- 可读文字：
- 视觉结构：
- 可复用内容：
- 不可复制元素：
```
