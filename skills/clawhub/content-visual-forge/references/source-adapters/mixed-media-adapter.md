# Mixed Media Adapter

## 适用输入

用户同时提供多个来源，例如：

- PDF + 自己补充文字
- 网页 + 截图
- 视频字幕 + 参考图
- PPT + 品牌视觉规范

## 处理流程

1. 列出全部来源。
2. 判断每个来源角色：主内容 / 补充内容 / 风格参考 / 事实核验。
3. 建立优先级。
4. 标注冲突信息。
5. 形成统一 Source Lock。

## 来源优先级默认规则

1. 用户明确指定的主内容源
2. 用户粘贴的补充要求
3. 当前上传文件
4. 网页 / 外部资料
5. 历史样例 / examples，只能作为格式参考

## 输出字段

```md
- 来源列表：
- 每个来源角色：
- 主内容源：
- 风格参考源：
- 冲突信息：
- 最终内容边界：
```
