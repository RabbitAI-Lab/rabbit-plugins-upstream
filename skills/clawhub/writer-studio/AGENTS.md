# Writer Studio — Agent 入口

> 本仓库是 skills-repo 组织下的写作技能库。Agent 在处理 writer-studio 相关任务时加载本文件。

## 技能清单

| 技能 | 文件 | 用途 |
|------|------|------|
| copywriter | [skills/copywriter/SKILL.md](skills/copywriter/SKILL.md) | 短文案写作（标题/CTA/广告/着陆页） |
| technical-writer | [skills/technical-writer/SKILL.md](skills/technical-writer/SKILL.md) | 技术文章全流程写作 |
| content-writer | [skills/content-writer/SKILL.md](skills/content-writer/SKILL.md) | 长文内容创作（博客/指南） |
| seo-checker | [skills/seo-checker/SKILL.md](skills/seo-checker/SKILL.md) | 博客 SEO 发布前检查 |

## 适用场景

- 独立开发者撰写产品博客和技术文章
- 从选题到发布的完整写作工作流
- 转化型短文案优化（着陆页/广告/邮件）
- 发布前 SEO 质量验收

## 技能来源

所有技能改编自 skills.sh 社区的成熟技能（安装量 ≥1K），详情见各 SKILL.md 的 source 字段。
