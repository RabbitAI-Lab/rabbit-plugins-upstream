# 轻量需求卡

从用户输入中提取下列信息。空白项由 Agent 调研或提出建议，不要求产品经理先写完整 PRD。

## 最小输入

- 需求名称
- 关联页面或可定位入口
- 当前问题及不解决的影响
- 目标用户
- 期望结果

## 用户可选补充

- 已知规则
- 明确范围外
- 产品经理已确定的决策
- 希望 Agent 调研并给建议的问题
- 页面链接、截图、历史文档或相关数据

## Agent 必须补齐

- 涉及角色、角色目标及权限边界
- 核心业务场景和用户故事
- 页面现状与目标差距
- 默认值、合法值、前置状态、可见性、可编辑性和生效时机
- 存量数据与历史口径
- 异常和边界场景
- 范围内、范围外及 Given/When/Then 验收标准
- 完整 URL、路由截图和完整页面证据

## 缺失信息处理

1. 页面或附件可发现：自行调研并标为 `Observed`。
2. 低风险业务默认值：标为 `Recommended`，统一提交产品确认。
3. 会改变业务行为：作为产品决策项，不自行冻结。
4. 属于技术实现：不要求产品经理决策，也不写进业务规则。
5. 页面状态不可访问：标为 `Unverified`，但仍需明确目标业务行为。

## 常见产品决策

- 角色和权限复用边界
- 用户界面用词、枚举和默认值
- 哪些业务状态允许查看、创建、修改、撤销
- 新旧字段是否联动或互相推断
- 存量数据、历史统计和生效时点
- 重复操作、并发修改、批量部分失败及重试结果
- 操作人、时间、原因等追溯要求
