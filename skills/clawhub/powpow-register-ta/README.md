# powpow-register

PowPow குமிழி பதிவு உதவியாளர் (OpenClaw பதிப்பு): ஒரு புதிய பயனரை "குமிழி என்றால் என்னவென்றே தெரியாத" நிலையிலிருந்து
"கணக்கு செயல்படுத்தப்பட்டது, ஒரு-கிளிக் உள்நுழைவு, விளையாடத் தொடங்கிவிட்டோம்" என்ற நிலைக்கு அழைத்துச் செல்லும் —
தயாரிப்பு அறிமுகம் (இடைமுக ஸ்கிரீன்ஷாட்கள் உட்பட), agent முகவராகப் பதிவு செய்தல் (சுயவிவரப் படம் பதிவேற்றம் உட்பட),
அலிபே/PayPal சந்தா ஆர்டர் உருவாக்கம் மற்றும் பணம் வருகை கண்காணிப்பு, இரட்டை இணைப்பு ஒரு-கிளிக் உள்நுழைவு, பிழை ஆய்வு.

**v2.0.0 முதல் இது முகவர்-உதவி பயன்முறை, v2.2.0 முதல் தளத்தின் இலவச சோதனை காலத்துடனும் தழுவி கொள்கிறது**: மைய ஸ்கிரிப்ட் `scripts/powpow-register.mjs` சார்பு இல்லாதது
(Node ≥ 18); பயனர் உரையாடலை ஒரே ஒரு முறை விட்டு வெளியேறுகிறார்: இன்பாக்ஸில் சரிபார்ப்பு குறியீட்டைப் பார்க்க. தற்போதைய இலவச சோதனை காலத்தில் பதிவு செய்யப்பட்ட கணக்கு உடனடியாக எல்லா அம்சங்களையும் பயன்படுத்தலாம் — சந்தா பேமெண்ட் விருப்பம்; சோதனை காலம் முடிந்து பயனர் சந்தா பக்கத்தில் இறங்கினால் ஓட்டம் தானாகவே பேமெண்ட் பாதைக்கு மாறும். Node இல்லாமல், அல்லது பயனர் தானே செய்ய விரும்பும்போது, தானாகவே தூய வழிமுறை பயன்முறைக்குத் திரும்பும்.

## செயல்பாடுகள்

1. **தயாரிப்பு அறிமுகம்**: ~120 சொற்கள் தொடக்க உரை + skill உடன் தொகுக்கப்பட்ட இடைமுக ஸ்கிரீன்ஷாட்கள்
   (`assets/screenshots/` இல் 6 படங்கள்: வரைபடப் பக்கம், பதிவு விவரப் பக்கம் போன்றவை; சூழலுக்கேற்ப 1–3 படங்களைத் தேர்ந்து அனுப்பலாம்;
   வெளி படத் தளம் தேவையில்லை, ஆஃப்லைனிலும் பயன்படும்).
2. **முகவராகப் பதிவு**: agent பயனர்பெயர்/புனைப்பெயரைத் தாமாகப் பரிந்துரைத்தல், கடவுச்சொல் இரண்டில் ஒன்று
   (பயனர் தருவது அல்லது agent உருவாக்குவது), சரிபார்ப்புக் குறியீடு அனுப்பி சமர்ப்பித்தல், சுயவிவரப் படம் நேரடிப் பதிவேற்றம்
   (≤5MB, SVG அல்ல), வழக்கமான பிழைகளைத் தானாகக் கையாளுதல் (ஏற்கனவே உள்ளது/காலாவதி/வீத வரம்பு).
3. **ஒரே கிளிக் உள்நுழைவு (இரட்டை இணைப்புகள்)**: வெற்றிகரமான பதிவுக்கு உடனடியாக, உள்நுழைவு இணைப்பு பயனரை நேரடியாக முகப்பு பக்கத்திற்கு அழைத்து செல்கிறது (இலவச சோதனை காலத்தில் ஒரே கிளிக் பயன்படுத்தக்கூடியது);
   சந்தா பக்கத்தில் இறங்கினால் (சோதனை காலம் முடிந்தது) அல்லது பயனர் மேம்படுத்த விரும்பினால் சந்தா ஓட்டத்தைப் பின்பற்றுங்கள் — பணம் வந்த பிறகு புதிய உள்நுழைவு நிலைக்கு மாற்றப்பட்டு, முழு உறுப்பினர் இணைப்பு முகப்பு பக்கத்திற்கு அழைத்து செல்கிறது
   (தளத்தின் அதிகாரப்பூர்வ `me?token=` பாலம் வழியாக, இது தானாகவே HttpOnly குக்கீ நட்டு விடுகிறது).
4. **சந்தா பணம் செலுத்துதல்**: அலிபே (மாதம் ¥6.99 / காலாண்டு ¥19.99 / ஆண்டு ¥69.99,
   ஒருமுறை பணம் செலுத்தி தகுந்த காலம், தானாகப் புதுப்பிக்காது) மற்றும் PayPal (Premium Monthly, சுமார் $1/மாதம்,
   தானாகப் புதுப்பிக்கும், எப்போது வேண்டுமானாலும் ரத்து செய்யலாம்) இரண்டிலும் agent முகவராக ஆர்டர் + பணம் வருகைப் போலிங்;
   வீசாட் QR/ஹுவாவே IAP க்கு வழி காட்டப்படும்.
5. **பிழை ஆய்வு**: சரிபார்ப்புக் குறியீடு வராமல் இருப்பது, பயனர்பெயர்/மின்னஞ்சல் ஏற்கனவே இருப்பது, 403 செயல்படுத்தப்படாதது,
   கணக்கு பூட்டப்பட்டது போன்ற வழக்கமான சிக்கல்கள் — அனைத்தும் தளத்தின் மூல குறியீட்டிலிருந்து, ஆதாரங்களுடன்.

## பாதுகாப்பு

- **கடவுச்சொல்** சூழல் மாறி வழியாக மட்டுமே ஸ்கிரிப்ட் செயல்முறைக்குள் நுழையும், கட்டளை வரி அளவுருவில் ஒருபோதும்
  இருக்காது, வட்டில் எழுதப்படாது, நிலைக் கோப்பில் இருக்காது; agent உருவாக்கிய கடவுச்சொல் ஒரு முறை மட்டுமே
  காட்டப்பட்டு பயனர் சேமிக்கப் பயன்படும்.
- **சரிபார்ப்புக் குறியீடு** அதிகாரப்பூர்வ பதிவு இடைமுகத்திற்கு மட்டுமே, பயன்படுத்தியதும் கைவிடப்படும்; நிலைக் கோப்பு
  (மின்னஞ்சல்/பயனர்பெயர்/token/ஆர்டர் எண்) கணினியின் தற்காலிக அடைவில் சேமிக்கப்பட்டு, செயல்முறை முடிந்ததும்
  `cleanup` ஒரு கிளிக்கில் அழிக்கப்படும்.
- **பணம் செலுத்துதல்**: agent ஆர்டரை உருவாக்குவது, பணம் செலுத்தும் பக்கத்தைத் திறப்பது, பணம் வருகையை விசாரிப்பது
  மட்டுமே; பயனரின் அலிபே/PayPal கணக்கு அல்லது பணம் செலுத்தும் சான்றுகளை ஒருபோதும் தொடாது, பணம் செலுத்தித் தர
  மாட்டாது. பணம் செலுத்துதல் எப்போதும் பயனருக்கும் அதிகாரப்பூர்வ பணம் செலுத்தும் பக்கத்திற்கும் இடையிலேயே நடக்கும்.
- அனைத்து கோரிக்கைகளும் அதிகாரப்பூர்வ டொமைன் `https://global.powpow.online` மட்டுமே; எந்த key ம் இல்லை.
