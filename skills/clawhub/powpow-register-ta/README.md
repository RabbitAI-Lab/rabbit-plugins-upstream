# powpow-register

PowPow குமிழி பதிவு உதவியாளர் (OpenClaw பதிப்பு): ஒரு புதிய பயனரை "குமிழி என்றால் என்னவென்றே தெரியாத" நிலையிலிருந்து
"கணக்கு செயல்படுத்தப்பட்டது, ஒரு-கிளிக் உள்நுழைவு, விளையாடத் தொடங்கிவிட்டோம்" என்ற நிலைக்கு அழைத்துச் செல்லும் —
தயாரிப்பு அறிமுகம் (இடைமுக ஸ்கிரீன்ஷாட்கள் உட்பட), agent முகவராகப் பதிவு செய்தல் (சுயவிவரப் படம் பதிவேற்றம் உட்பட),
அலிபே சந்தா ஆர்டர் உருவாக்கம் மற்றும் பணம் வருகை கண்காணிப்பு, இரட்டை இணைப்பு ஒரு-கிளிக் உள்நுழைவு, பிழை ஆய்வு.

**v2.0.0 முதல் agent முகவர் முறை**: மைய ஸ்கிரிப்ட் `scripts/powpow-register.mjs` பூஜ்ஜிய சார்புநிலை
(Node ≥ 18), பயனர் முழுவதும் உரையாடலை விட்டு வெளியேற மாட்டார், இரண்டு முறை மட்டும் சிறிது நேரம் வெளியே செல்வார்:
மின்னஞ்சலில் சரிபார்ப்புக் குறியீட்டைப் பார்ப்பது, அலிபே பணம் செலுத்தும் பக்கத்தில் பணம் செலுத்துவது.
Node இல்லை அல்லது பயனர் தாமாகச் செய்ய விரும்பினால், தானாக தூய வழிகாட்டுதல் முறைக்குத் திரும்பும்.

## செயல்பாடுகள்

1. **தயாரிப்பு அறிமுகம்**: ~120 சொற்கள் தொடக்க உரை + skill உடன் தொகுக்கப்பட்ட இடைமுக ஸ்கிரீன்ஷாட்கள்
   (`assets/screenshots/` இல் 6 படங்கள்: வரைபடப் பக்கம், பதிவு விவரப் பக்கம் போன்றவை; சூழலுக்கேற்ப 1–3 படங்களைத் தேர்ந்து அனுப்பலாம்;
   வெளி படத் தளம் தேவையில்லை, ஆஃப்லைனிலும் பயன்படும்).
2. **முகவராகப் பதிவு**: agent பயனர்பெயர்/புனைப்பெயரைத் தாமாகப் பரிந்துரைத்தல், கடவுச்சொல் இரண்டில் ஒன்று
   (பயனர் தருவது அல்லது agent உருவாக்குவது), சரிபார்ப்புக் குறியீடு அனுப்பி சமர்ப்பித்தல், சுயவிவரப் படம் நேரடிப் பதிவேற்றம்
   (≤5MB, SVG அல்ல), வழக்கமான பிழைகளைத் தானாகக் கையாளுதல் (ஏற்கனவே உள்ளது/காலாவதி/வீத வரம்பு).
3. **ஒரு-கிளிக் உள்நுழைவு (இரட்டை இணைப்பு)**: பதிவு வெற்றியானதும் "அரை-உள்நுழைவு" இணைப்பு சந்தாப் பக்கத்திற்கு நேரடியாக;
   பணம் வந்ததும் புதிய உள்நுழைவு நிலைக்கு மாறி, முழு உறுப்பினர் இணைப்பு முதன்மைப் பக்கத்திற்கு நேரடியாக
   (தளத்தின் அதிகாரப்பூர்வ `me?token=` பாலம் வழியாக, HttpOnly cookie தானாக நடப்படும்).
4. **சந்தா பணம் செலுத்துதல்**: அலிபே தடத்தில் agent முகவராக ஆர்டர் உருவாக்கம் (மாதம் ¥6.99 / காலாண்டு ¥19.99 / ஆண்டு ¥69.99,
   ஒருமுறை பணம் செலுத்தி தகுந்த காலம், தானாகப் புதுப்பிக்காது) + பணம் வருகையைப் போலிங் செய்தல்; வெளிநாட்டு
   பயனர்கள் PayPal க்குத் திரும்பலாம்; வீசாட் QR/ஹுவாவே IAP க்கு வழி காட்டப்படும்.
5. **பிழை ஆய்வு**: சரிபார்ப்புக் குறியீடு வராமல் இருப்பது, பயனர்பெயர்/மின்னஞ்சல் ஏற்கனவே இருப்பது, 403 செயல்படுத்தப்படாதது,
   கணக்கு பூட்டப்பட்டது போன்ற வழக்கமான சிக்கல்கள் — அனைத்தும் தளத்தின் மூல குறியீட்டிலிருந்து, ஆதாரங்களுடன்.

## பாதுகாப்பு

- **கடவுச்சொல்** சூழல் மாறி வழியாக மட்டுமே ஸ்கிரிப்ட் செயல்முறைக்குள் நுழையும், கட்டளை வரி அளவுருவில் ஒருபோதும்
  இருக்காது, வட்டில் எழுதப்படாது, நிலைக் கோப்பில் இருக்காது; agent உருவாக்கிய கடவுச்சொல் ஒரு முறை மட்டுமே
  காட்டப்பட்டு பயனர் சேமிக்கப் பயன்படும்.
- **சரிபார்ப்புக் குறியீடு** அதிகாரப்பூர்வ பதிவு இடைமுகத்திற்கு மட்டுமே, பயன்படுத்தியதும் கைவிடப்படும்; நிலைக் கோப்பு
  (மின்னஞ்சல்/பயனர்பெயர்/token/ஆர்டர் எண்) கணினியின் தற்காலிக அடைவில் சேமிக்கப்பட்டு, செயல்முறை முடிந்ததும்
  `cleanup` ஒரு கிளிக்கில் அழிக்கப்படும்.
- **பணம் செலுத்துதல்**: agent ஆர்டரை உருவாக்குவது, பணம் செலுத்தும் பக்கத்தைத் திறப்பது, பணம் வருகையை விசாரிப்பது
  மட்டுமே; பயனரின் அலிபே கணக்கு அல்லது பணம் செலுத்தும் சான்றுகளை ஒருபோதும் தொடாது, பணம் செலுத்தித் தர
  மாட்டாது. பணம் செலுத்துதல் எப்போதும் பயனருக்கும் அலிபேவின் அதிகாரப்பூர்வ பணம் செலுத்தும் பக்கத்திற்கும் இடையிலேயே நடக்கும்.
- அனைத்து கோரிக்கைகளும் அதிகாரப்பூர்வ டொமைன் `https://global.powpow.online` மட்டுமே; எந்த key ம் இல்லை.
