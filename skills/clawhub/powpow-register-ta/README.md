# powpow-register

PowPow பப்பிள் பதிவு உதவியாளர் (OpenClaw பதிப்பு): புதிய பயனரை «பப்பிள் என்றால் என்ன» தெரியாத நிலையில் இருந்து
«கணக்கு செயல்பட்டு பயன்படுத்தத் தயார்» நிலைக்கு அழைத்துச் செல்லுங்கள் — தயாரிப்பு அறிமுகம் (இடைமுக ஸ்கிரீன்ஷாட்கள் உட்பட),
படிப்படியான பதிவு வழிகாட்டி, பிழை கண்டறிதல், சப்ஸ்கிரிப்ஷன் செயல்படுத்தல் விளக்கம்.

முழுமையாக வழிகாட்டி-வகை skill, எந்த ஸ்கிரிப்ட்டும் இல்லை, எந்த சார்பும் இல்லை; அனைத்து பதிவு செயல்களையும் பயனர்
உலாவி/யாப்பில் தானே முடிக்கிறார்.

## நிறுவல்

```
openclaw skills install @durenzidu/powpow-register
```

## அம்சங்கள்

1. **தயாரிப்பு அறிமுகம்**: ~120 வார்த்தை அறிமுகம் + GitHub பொது களஞ்சியத்தில் ஹோஸ்ட் செய்யப்பட்ட இடைமுக ஸ்கிரீன்ஷாட் இணைப்புகள்
   (வரைபட பக்கம், பதிவு விவர பக்கம் உட்பட 6 புகைப்படங்கள், சூழலுக்கு ஏற்ப 1–3 அனுப்புங்கள்).
2. **பதிவு வழிகாட்டி**: புல விதிகள் (பயனர் பெயர்/கடவுச்சொல்/மின்னஞ்சல் சரிபார்ப்புக் குறியீடு/மொபைல் எண்/சுயவிவர புகைப்படம்),
   மூன்றாம் தரப்பு உள்நுழைவு (Google/Watcha/ஹுவாவே), ரேட்-லிமிட் அளவுருக்கள், அனைத்தும் தள மூலக் குறியீட்டிலிருந்து மூலம் சுட்டிக்காட்டப்பட்டுள்ளன.
3. **பிழை கண்டறிதல்**: சரிபார்ப்புக் குறியீடு வராதது, பயனர் பெயர்/மின்னஞ்சல் ஏற்கனவே பயன்பாட்டில் இருப்பது, 403 செயல்படாதது, கணக்கு
   பூட்டப்பட்டது உள்ளிட்ட 13 பொதுவான சிக்கல்கள்.
4. **சப்ஸ்கிரிப்ஷன் செயல்படுத்தல்**: PayPal (வெப்) / WeChat ஸ்கேன் (கைமுறை உறுதிப்படுத்தல்) / ஹுவாவே IAP (HarmonyOS) மூன்று
   வழிகளின் விளக்கம் மற்றும் தீர்வு; தற்போதைய செலுத்தும் சங்கிலியை நேரடியாக மீண்டும் பயன்படுத்தலாம், skill வெறுமனே வழி காட்டுகிறது.

## பாதுகாப்பு

- எந்த சாவியும் (key) இல்லை; ஸ்கிரிப்ட் இல்லை, பயனரின் நற்சான்றுகளை (credentials) தொடாது.
- **ஒருபோதும் கேட்காது** பயனரின் கடவுச்சொல், சரிபார்ப்புக் குறியீடு அல்லது செலுத்தும் ஆதாரம்; பதிவு மற்றும் செலுத்துதல் அனைத்தும் தளப்
  பக்கங்களில் நடக்கும்.
