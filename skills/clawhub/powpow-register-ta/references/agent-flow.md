# Agent முகவர் செயல்முறை மற்றும் ஸ்கிரிப்ட் ஒப்பந்தம் — powpow-register

SKILL.md இல் உள்ள ஒவ்வொரு படியின் செயலாக்க விவரங்கள். அனைத்து கட்டளைகளும் `node scripts/powpow-register.mjs <துணைக்கட்டளை> [அளவுருக்கள்]` வடிவத்தில்;
ஸ்கிரிப்ட் **பூஜ்ஜிய சார்புநிலை**, **Node ≥ 18** தேவை, அனைத்து கோரிக்கைகளும் `https://global.powpow.online` மட்டுமே அனுப்பப்படும்.

## கட்டளை குறிப்பு

| கட்டளை | முக்கிய அளவுருக்கள் | செயல் / நேரம் |

| `status` | —— | செயல்முறை முன்னேற்றத்தைப் பார்ப்பது (நிலைக் கோப்பைப் படித்தல்); உரையாடல் தடைபட்ட பின் முதலில் இதை இயக்குங்கள் |
| `gen-password` | —— | 24 எழுத்து வலுவான கடவுச்சொல் உருவாக்கம் (பெரிய+சிறிய எழுத்து+எண் உட்பட), stdout இல் **இந்த ஒரு முறை மட்டுமே** காட்டப்படும் |
| `prepare-suggest` | `--username --nickname --email` | உறுதிப்படுத்திய தகவலை நிலைக் கோப்பில் பதிவு செய்தல் (பின்னர் register இல் மீண்டும் தரத் தேவையில்லை) |
| `send-code` | `--email` | 6 இலக்கச் சரிபார்ப்புக் குறியீட்டை தளம் அனுப்பும்படி ட்ரிகர் செய்தல் (10 நிமிடம் செல்லும், 60s குளிர்விப்பு) |

| `create-order` | `--package monthly\|quarterly\|yearly` (இயல்பு அலிபே)<br>`--provider alipay\|paypal` | பணம் செலுத்தும் ஆர்டரை உருவாக்கும்; அலிபே பணம் செலுத்தும் பக்கக் கோப்புப் பாதை + outTradeNo திருப்பும்; PayPal ஒப்புதல் பக்கக் கோப்புப் பாதை + subscriptionId திருப்பும் (தானாக நிலைக் கோப்பில் பதிவாகும்) |

| `refresh-login` | கடவுச்சொல் சூழல் மாறி வழியாக | மீண்டும் உள்நுழைந்து **புதிய JWT** பெறுதல் (சந்தா அறிவிப்பு NONE இலிருந்து ACTIVE ஆகும்), பணம் வந்த பின் கட்டாயம் இயக்கவேண்டும் |
| `whoami` | —— | நிலைக் கோப்பின் token கொண்டு கணக்கு மற்றும் சந்தா நிலையை விசாரிப்பது (செயல்படுத்தல் நடைமுறைக்கு வந்ததா என்று சரிபார்க்க) |
| `cleanup` | —— | நிலைக் கோப்பை நீக்குதல் (முடிவுப் பணியில் கட்டாயம் இயக்கவேண்டும்) |

**சூழல் மாறி வழியாக அனுப்புதல்** (கடவுச்சொல் எப்போதும் கட்டளை வரிக்கு வராது):

```bash
# bash / zsh / WSL
POWPOW_REGISTER_PASSWORD='<கடவுச்சொல்>' node scripts/powpow-register.mjs register --code 123456
# PowerShell
$env:POWPOW_REGISTER_PASSWORD = '<கடவுச்சொல்>'; node scripts/powpow-register.mjs register --code 123456
# cmd
set POWPOW_REGISTER_PASSWORD=<கடவுச்சொல்> && node scripts/powpow-register.mjs register --code 123456
```

## இரட்டை-இணைப்பு முறை (மைய வடிவமைப்பு)

தளத்தின் உள்நுழைவு நிலை ஒரு HttpOnly குக்கீ, அதை முகவர் நேரடியாக உலாவியில் நட்டு விட முடியாது; பாலம் official
`/api/auth/me?token=<JWT>&redirect=<தளத்திற்குள் பாதை>` இறுதிப் புள்ளி: கையொப்பத்தைச் சரிபார் → தானாக அமர்வை
உருவாக்கு → `Set-Cookie: powpow_token` (HttpOnly / SameSite=Lax / 7 நாட்கள்) → திருப்புதலைச்
சரிபார் (ஒற்றை சாய்கோடுடன் தொடங்க வேண்டும், `//` மற்றும் பின்னாய்கோடுகள் தடை, பாகுபடுத்திய பிறகு same-origin ஆக இருக்க வேண்டும்) → இலக்குப் பக்கத்திற்கு 307 தற்காலிக திருப்புதல்.

இணைப்புக்கு இரண்டு இலக்குகள் உள்ளன, **முதலில் home உருவாக்குங்கள், பிறகு பயனர் எங்கே இறங்கினார் என்பதைப் பொறுத்து pending வழியாகச் செல்வதா என முடிவுசெய்யுங்கள்**:

- **home இணைப்பு (இயல்பாக அனுப்பப்படுகிறது, `--target home` → `/`-இல் இறங்கும்)**: வெற்றிகரமான பதிவுக்கு உடனடியாக உருவாக்கி பயனருக்கு அனுப்பப்படுகிறது.
  இலவச சோதனை காலத்தில் பயனர் நேரடியாக முகப்பு பக்கத்திற்குச் செல்லுகிறார், எல்லாம் பயன்படுத்தக்கூடியது; **இணைப்பைக் கிளிக் செய்து சந்தா பக்கத்தில் இறங்கினால் இலவச சோதனை காலம் முடிந்தது** — பேமெண்ட் ஓட்டத்திற்கு மாறுங்கள் (கீழே பாருங்கள்); ஸ்கிரிப்டை மாற்றாமல், மீண்டும் பதிவு செய்யாமல்.
- **pending இணைப்பு (பேமெண்ட் ஓட்டத்தில் பயன்படுத்தப்படுகிறது, `--target pending` → `/subscription`-இல் இறங்கும்)**:
  பயனரின் உலாவி "அரை-உள்நுழைவு" நிலைக்குள் நுழைகிறது: சந்தா பக்கம் மற்றும் பேமெண்ட் பிற்பட்ட திரும்பு பக்கம் தெரியும் மற்றும் இயக்கக்கூடியது. பணம் வந்த பிறகு,
  ACTIVE உரிமைகோரல் கொண்ட புதிய JWT-க்கு மாற்ற `refresh-login` ஓட்டுங்கள், பிறகு முழு உறுப்பினர் நிலைக்கு home இணைப்பை மீண்டும் அனுப்புங்கள்.

## முழு வரிசை

### வேகப் பாதை (இலவச சோதனை காலத்தில் — பெரும்பாலான வழக்குகள்)

```
1.  status                          # சூழல் தானே-சோதனை
2.  (படி 2: தகவல்களை உறுதி செய்ய உரையாடல், கடவுச்சொல் விருப்பம்; உருவாக்க பயன்முறை: gen-password → பயனரிடம் உடனே சேமிக்கச் சொல்லுங்கள்)
3.  prepare-suggest --username U --nickname N --email E
4.  send-code --email E             # → பயனர் இன்பாக்ஸில் குறியீட்டைப் பார்க்கிறார் (உரையாடலை விட்டு வெளியேறும் ஒரே முறை)
5.  POWPOW_REGISTER_PASSWORD=*** register --code 123456 [--avatar pic.jpg]
6.  login-link --target home        # → இணைப்பைப் பயனருக்கு அனுப்புங்கள்; ஒரே கிளிக் முகப்பு பக்கத்தில்
7.  (பயனர் உள்ளே வந்ததை உறுதி செய்கிறார்) → நேரடியாக முடிவுசெய்யுங்கள்: cleanup + கணக்கு அட்டை + முதல் படிகள் வழிநடத்தல்
```

### பேமெண்ட் பாதை (பயனர் உறுப்பினர் அணைவை விரும்பும்போது, அல்லது இலவச சோதனை காலம் முடிந்தபோது)

```
1–5. வேகப் பாதையைப் போலவே (register வெற்றி பிறகு நிலையில் டோக்கன் ஏற்கனவே உள்ளது)
6.  login-link --target pending     # → அரை-உள்நுழைவு இணைப்பு, பேமெண்ட் திரும்பு பக்கம் தொடர்ந்து வேலை செய்யும்
7.  (பயனர் பேமெண்ட் முறையைத் தேர்வு செய்கிறார்)
    # Alipay: create-order --package monthly|quarterly|yearly
    # PayPal: create-order --provider paypal
8.  start <பேமெண்ட் பக்க கோப்பு>   # Windows; macOS open, Linux xdg-open
    # → பயனர் Alipay/PayPal கவுண்ட்டில் பேமெண்ட்/அனுமதியை முடிக்கிறார் (உரையாடலை விட்டு வெளியேறுகிறார்)
9.  query (ஒவ்வொரு 10–15 வினாடி) paid / ACTIVE வரை
10. refresh-login                   # ACTIVE உரிமைகோரல் கொண்ட புதிய JWT-க்கு மாற்றம்
11. login-link --target home        # → பயனருக்கு முழு உறுப்பினர் இணைப்பை அனுப்புங்கள்
12. whoami                          # subscriptionStatus: ACTIVE உறுதி செய்யுங்கள் (விருப்பம்)
13. cleanup                         # நிலை கோப்பைச் சுத்தம் செய்யுங்கள்
```
