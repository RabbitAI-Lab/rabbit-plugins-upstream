## Description:

Loads the AI Manifesto five-layer worldview framework as a reasoning lens for questions about AI philosophy, scientific worldview, intelligence and civilization, long-term strategy, ethics, value alignment, and requests for a foundational AI worldview.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill when they want an agent to reason through the AI Manifesto's cosmology, civilization, epistemology, ethics, and AI self-positioning framework. It is intended for philosophical analysis, strategy work, trend interpretation, risk assessment, and office-task reasoning where the user explicitly wants this worldview applied.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill asks an agent to apply a specific AI Manifesto worldview as a baseline across tasks, which can shift answers away from neutral, task-bounded reasoning.

Mitigation: Install and invoke the skill only when this worldview is intentionally desired; otherwise constrain use to explicit requests for the framework.

Risk: The framework contains broad philosophical and strategic claims that may be inappropriate for routine office tasks or factual analysis.

Mitigation: Review outputs for unsupported assumptions, ask the agent to separate manifesto-based interpretation from task facts, and require citations when factual claims matter.
