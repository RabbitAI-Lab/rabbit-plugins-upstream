## Description:

Provides agents with the AI Manifesto five-layer worldview framework for reasoning about AI philosophy, scientific worldview, intelligence and civilization evolution, long-term strategy, AI ethics, and value alignment.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ontoai](https://clawhub.ai/user/ontoai)

### License/Terms of Use:

CC BY 4.0

## Use Case:

External users and agent builders use this skill when they want an assistant to apply the AI Manifesto as a worldview lens for strategy, ethics, AI self-positioning, civilizational analysis, and long-horizon reasoning. It is best used when that specific philosophical framing is desired, not as the default lens for neutral factual work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill intentionally biases an assistant toward the AI Manifesto worldview and may make speculative scientific or geopolitical claims sound more settled than they are.

Mitigation: Use it only when that worldview lens is explicitly desired, treat its scientific and geopolitical claims as philosophy or hypothesis, and avoid using it as the default framing for neutral factual work or high-stakes decisions.
