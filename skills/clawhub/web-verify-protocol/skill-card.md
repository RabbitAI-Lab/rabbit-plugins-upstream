## Description:

Provides a three-round web verification protocol that grades sources and cross-checks data before an agent cites numbers, claims, or research outputs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[shiyan521](https://clawhub.ai/user/shiyan521)

### License/Terms of Use:

MIT

## Use Case:

External users, writers, content teams, and data researchers use this skill to verify cited figures, news claims, report findings, and infographic data with graded sources before publication.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The protocol can slow fact-checking tasks and increase search volume.

Mitigation: Use it for publication-grade or high-impact verification tasks where the added search cost is justified.

Risk: The protocol's confidence claims can be mistaken for a guarantee that all facts are correct.

Mitigation: Treat the verification report as evidence of process completion, and keep source grades and unresolved single-source claims visible to reviewers.
