# 家有楼梯，装修小心翻车10.18

翻车的专题已经很多了，今天看看楼梯翻车的案例，自己家如果有楼梯的话，可以借鉴参考一下，避免翻车。
现浇楼梯不是不能铺瓷砖，现在的瓷砖规格多大都有，为什么要用小规格拼接？这样不是一样浪费两块瓷砖？而且一般瓷砖用到楼梯，第一没有档次，第二最容易影响后期耐用度，都楼梯房子了，要不用石材，要不用原木，这个钱完全没有必要节省，就好比都买豪车了，何必心疼油钱？楼梯整体采用岩板，这个费用不是一般人能承受的，但是左图踢脚线明显小气多了，而且难看又丑；右图是整改以后的样子，大气多了。左图翻车的样子，右图是整改以后的样子，你们喜欢哪个？不言而喻肯定右图好，这个属于审美和工艺都翻车了乍看好像没有毛病，因为是半成品，但是当你试着踩上去的时候，才发现，这玩意是让人用的踏步？没有图纸，没有监管，随意施工效果图只是参考样子，具体材质需要亲自挑选的，但是效果图岩板的昂贵是有道理的，天然石材纹路必然是随机大花纹的，这个肯定翻车。自己装修没有全盘规划，找的现浇楼梯，压根不考虑房间大梁位置，结果现浇完了发现下楼梯每次都得碰头，楼梯现浇高度没有考虑大梁，现在唯一的做法只能楼梯重新做，承重的大梁是无法改造的。千小心万小心，但是没有防住玻璃颜色，结果这个绿玻拆除不是，留着心里不舒舒，当初做的时候也不知道特意强调超白玻有时候装修和金钱没有绝对的关系，上图的小空间楼梯并不是缺钱，缺的是审美而已；当然如果后期整体设计能搭配好是没有问题的，但是从工地现状来看，明显是压根没有设计的听说过五颜六色的白，但是却忽视了五颜六色的木色，结果导致木地板颜色和楼梯踏步完全不统一，又得费钱又得费时间整改了瓷砖色差不是一个色号，这种翻车要不没有补救机会，要不就很简单解决，就怕同色号瓷砖没有了，那就彻底完蛋，除非把所有瓷砖全部砸掉统一更换了做岩板楼梯一定要注意，量尺寸需要量取每一个踏步的尺寸，而不是量一个踏步尺寸，否则百分百出问题，因为楼梯不论怎么做都会有误差，只来量一个踏步这种后果就会导致岩板报废重做。如此花纹，翻车的人认为真接受不了，像是脏水流下来一样，但是喜欢的人喜欢得不得了，很有艺术感，所以做的时候一定要规划和考虑成熟不要看岩板做楼梯好看，耐用才是王道，否则如图又硬又脆，磕碰是无法避免的，而且只能修复，也没法更换。
