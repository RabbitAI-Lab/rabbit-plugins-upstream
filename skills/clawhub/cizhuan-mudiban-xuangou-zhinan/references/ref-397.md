# 厨房装修13个错误，还有人再犯

作者: 西安装修课堂
发布时间: 2022年7月25日

金厨银卫，该注意的点非常多。集中列一下厨房常犯的错误，避免继续犯。

第一、厨房防水。
做不做防水完全取决于有没有地漏。没地漏只顾低头做防水，爆管了水照样流出厨房跑到客厅，泡的不是厨房而是楼下家具，损失更大。没有地漏就完全不做防水，把重点放到所有上水角阀和软管质量上，定期检查更换软管和角阀。

第二、厨房凉霸。
装修时梦想装凉霸带来凉意，就是个风扇，夏天50度厨房吹风也是50度，和凉意没关。别跟风买这个鸡肋。有条件直接装1P挂机，几百元搞定，一天用不了几毛钱，这才是该想办法拥有的。

第三、厨房垃圾处理器。
属于非常占地方的设备，水槽下方本就小，还有下水、上水管、必备净水器，再加处理器几乎没置物空间。生活习惯油腻、天天鸡鸭鱼肉的，最好别用，会导致下水管挂脏变厚，细下水管先遭殃，久了流水不畅；高层住户总有一天主管道堵住，家家户户遭殃。并非所有垃圾都能处理，每天还得手提垃圾下楼倒。结合饮食习惯购买，并非每家都适合，特别是高层住宅，且噪音不可忽略。

第四、厨房内置垃圾桶。
做过饭的人都不会有这脑洞。国人厨房夏季温度五六十度，每天把垃圾藏橱柜下方，不是养虫就是养细菌，光想都不卫生，是不合理的设计。

第五、吊柜留缝隙。
两种可能：找套餐装修低价切，层过高不做吊柜只能留缝；或没找套餐、全屋定制没经验。挨着吊顶又高，只能留缝隙安装。

第六、台面前挡水。
没用。厨房操作要勤打理，做这个只怕流水，石英石早不堪入目了；实际台面常打理，不用担心水流地面。有人说防鸡蛋滚地，大材小用，放碗里不好吗？而且有前挡水案板永远倾斜。这玩意单独加钱，不如把台面质量提一档。

第七、台面去掉后挡水。
网上不少自媒体鼓吹不做后挡水直接美缝。美缝要掏钱，不做后挡水给你减钱吗？墙面能达到要求吗？后挡水是为调节橱柜误差，做了后挡水照样美缝，不影响打理使用。弧形挡水和前挡水一样要单独付费，有美缝普通挡水一样好打理。

第八、厨房只有一盏灯。
不论大小只做一盏灯，没生活经验。晚上操作永远有背光处。正确做法：有吊柜的操作台面都预留手扫灯，保证晚上无背光区，水电规划时就得考虑。水槽在窗边容易背光，还得考虑单独吊灯或头顶筒灯。

第九、厨房用了双槽。
双槽有错吗？没有。人家双槽大槽60公分小槽30公分，完全满足。你买双槽不看尺寸，家里只能满足60公分水槽，却买两边一样大的双槽，两边都放不下锅具，才是鸡肋。刚需满足不了只能用单槽解决，并非谁家都能用双槽，前提是人家双槽大槽比你家单槽还大。

第十、止逆阀安装到瓷砖上。
看起来正规，但没生活经验。止逆阀目的为连接烟管不漏烟，这样只能用免钉胶粘贴，后期更换得哭——全瓷瓷砖用背涂胶贴，再用免钉胶沾止逆阀，换时除非敲碎瓷砖，吊顶吊柜做好后没操作空间，敲碎还可能连带旁边瓷砖，搞不好拆除吊柜吊顶。正确做法：吊顶前或贴砖时让烟机上门预埋，直接装到烟道上，螺丝加打胶密封，后期卸一两块铝扣板就能轻松换。

第十一、厨房大规格瓷砖上墙。
卖瓷砖的巴不得业主墙面用1500*750上墙，价高利润好。要大气直接用岩板一面墙一片。地砖上墙除套路看不出大气。把水电全投到无实用功能，橱柜却舍不得洗碗机、大手工水槽，本末倒置。大规格上墙必须纯胶粘贴，后面磕碰更换得砸成碎片，影响范围越来越大。

第十二、橱柜转角斜面处理。
把直角橱柜做斜面更好利用转角，但仅限超大厨房。刚需房弊大于利，定制费用更高。正确做法：换大角度铰链保证两对开门，转角无死角利用，空间还宽敞。

第十三、厨房用轨道插座。
轨道插座成了美观代名词，除新颖无任何长处。生产是为弥补装修水电不足、后期无法加插座时延伸更多插座，非装修前标配。价格高，安全性没单独五孔实在。适合精装或装完发现插座不够的地方，新房提前规划能不用尽量不用。
