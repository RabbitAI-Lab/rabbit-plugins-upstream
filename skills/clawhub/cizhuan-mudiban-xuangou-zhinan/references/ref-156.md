# 30㎡挑高LOFT，一个人住真好

这种极小空间的loft非常受年轻人的青睐，因为小，所以一般是单层的价格买两层；而且挑高的户型自由分割，不论是自住还是投资，都是非常实惠的。

▲这是毛坯状态的全景，就是一个开间户型，可以自由分割，层高大概在五米二左右；实际比这个小，广角拍出来显得更大。除去公摊以后仅剩下20平左右

▲这是设计后的平面布局，一楼左手预留的下水位置作为单独卫生间分割，采用局部玻璃砖墙体刚好满足采光需求；同时借用了钢结构的柱子做了极简的楼梯布局。进门过道右手刚好定制开放式厨房，满足偶尔烹饪的需求；
二楼采用客厅挑空，局部满足卧室的需求，隔层做了延伸，让视觉上更美观，同时延伸楼上卧室空间
▲门厅空间，因为空间非常小，所以尽量以浅色为主，让空间干净清爽。地面通铺的是水磨石瓷砖。进门右手浅色的复古绿瓷砖搭配白色的橱柜定制，满足偶尔的简单烹饪需求；左手利用新分割卫生间镶嵌鞋柜，满足进门的基本收纳；橱柜对面曲线全身镜布局，视觉上更柔和自然
▲这种公寓型房子一般都没有天然气入户，所以只能采用电磁炉，平时几乎不会做饭，满足偶尔的烹饪需求即可；复古绿的浅色搭配极简白色橱柜，让进门口也能清爽干净
▲白色与绿色的清新，同时无把手极简视觉，让杂物收纳起来，空间更干净整洁
▲紧挨橱柜的是客厅的收纳柜，同样延续白色极简，弧形的造型贯穿始终，让视觉上小空间更柔和优雅
▲客厅全景，右手顶天立地的收纳柜满足公共区域的所有收纳，卧室延伸的弧形隔层刚好让衣柜完美统一
▲衣柜上拱形的极简造型与所有弧形呼应协调，优雅简洁
▲因为空间实在太小，所以采用两人位的沙发靠窗户布局，旁边卡通墨绿的单人沙发搭配，同时角落的浅绿色冰箱又与厨房绿色瓷砖呼应，白色与绿色贯穿始终，空间清新又有自然气息

▲网红款浅绿色冰箱角落布局，颜色上与厨房的墙面遥相呼应，清新简单；冰箱上头是壁挂新风，满足品质生活

▲客厅折叠餐桌的布局，可以随时收起来，也可以展开满足就餐以及办公需求
▲极简很有范的家具布局，角落高大绿植点缀，一副抽象挂画斜靠布局，让简单空间也有了高级艺术感

▲客厅角落，时尚优雅玻璃花瓶简单点缀出清新氛围

▲新分割卫生间以后，墙角做了弧形处理，与所有圆弧呼应，让空间更柔和；玻璃砖墙体后面是卫生间，引光入室；借用钢结构柱子延伸旋转极简楼梯，弧形的扶手延伸上楼，灰色的油漆处理，同样是简单干净
▲极简轻巧富有艺术感的楼梯，让小空间更轻盈简洁
▲楼上看旋转楼梯，灰色的柔和简单，空间更显通透

▲二楼上来床尾安排衣柜定制，利用过道空间刚好做了收纳衣帽间，采用长虹玻璃移门分割，让视觉更通透

▲床头一侧延伸的平台，其实是为了增加楼上的视觉空间，不显得压抑，同时完美实现一楼收纳柜的定制
▲卧室全景，背景采用暖咖色涂刷延伸到顶，半圆形的床头搭配，与整体弧形元素呼应，优雅舒适
▲床头透明的方几布局，极简很有艺术感
▲卫生间门同样采用拱形的长虹玻璃，与整体弧形造型呼应协调；非常有艺术感的瓷砖搭配
▲淋浴处利用玻璃砖墙体，引光入室，虽小但是非常精致，金色的入墙花洒同样品质搭配

▲刚好利用凹陷区定制浴柜，拱形的镜子搭配呼应，采用暗藏灯带提升空间质感和温馨度
