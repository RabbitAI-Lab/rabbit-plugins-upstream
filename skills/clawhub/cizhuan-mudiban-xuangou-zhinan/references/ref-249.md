# 衣柜在地砖/地板之上？还是之下？11.22

关于衣柜定制方面的知识可以后台直接回复“全屋定制”，有关于板材环保以及定制的常识。

有关衣柜案例的知识后台直接回复“衣柜”，在家具板块里头各种家具案例都有。

今天有业主咨询：定制衣柜是先放衣柜还是先铺木地板。其实作为北方地区，已经N年没有用过木地板了。遍地地暖房，有房也不敢任性装呀《装修铺地板还是地砖？你们错得一塌糊涂！11.14》

一、房子铺瓷砖。
如果是瓷砖地面，不论是定制还是买成品，都不用说，肯定是先地面再进行柜子进场。即使是现场让工人做，也是一样的，水电瓦木油，按照顺序也应该铺完瓷砖才开始现场木工做柜子，所以不论怎么做柜子都在瓷砖之上。

二、房子铺木地板。
铺木地板就得注意了。如果你家是买成品柜子，压根不能把衣柜放到水泥地上，然后再铺木地板的，肯定是完工以后，成品柜子放到木地板上头。

如果你家是定制衣柜呢？同样道理，一定是放在木地板之上的，唯一需要注意的事情是，木地板是最后一道工序，但是衣柜量尺寸一般在瓦工结束以后就可以，不可能等到木地板铺完了才去量尺寸，时间大量浪费。所以在完工结束，找平层做好以后，衣柜尺寸需要减掉木地板的厚度，业主需要提前看好木地板，固定好厚度尺寸，这样衣柜定制的时间就绰绰有余。等到木地板铺完后，直接进行衣柜安装即可。

如果你家是工人现场做，这里先声明，不要让工人用人造板现场打柜子。《人造板别让工人做，环保靠封边6.14》除非是实木。

如果你买实木板子现场工人做柜子，这里就注意了。还是一样瓦工做完开始木工，但是全房铺木地板，不可能等木地板铺完再做柜子。如果你家铺实木地板，铺完地板现场做柜子，柜子完了地板也就报废了，这是不现实的。

▲看上图，业主现场打柜子，木地板铺好了才开始做，而且不做任何保护，如果是强化地板可能划痕避免不了，如果实木地板，做完柜子，地板几乎报废。所以各位业主一定切记，不敢这样做装修，否则木工赔不起你家地板的。

▲正确的做法是，你家如果铺木地板，如果是现场做柜子，找平层做完就要制作，做好柜子以后，木地板只铺剩余地面，然后四周踢脚线压住即可。也就是衣柜在木地板之下了。
