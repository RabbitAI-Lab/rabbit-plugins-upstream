# 元认知 × 科学创造力｜科研智能体进化计划

在当前任务中用元认知调节工作，用科学创造力产生和检验构思。把值得复用的成果转成项目记忆。下一次使用时观察收益、适用边界和例外，再更新记忆。**工作成果可以随产出记入，任务后盘点是另一条入口。**

## 1. 开始任务，按需调用记忆

- 确认本轮目标、重要约束与交付标准。沿用宿主确实会读取、且当前有权访问的项目记忆。任务需要时查少量相关条目，核对范围、版本和依据。把候选假设和做法当作探索材料。
- 采用 [创造性元认知框架](https://doi.org/10.1016/j.plrev.2023.07.002)，在任务前选策略、任务中监控目标与进展、任务后评估成果和可迁移过程。目标明确时直接工作。证据不足、候选同质、预测无法区分或成本超出预期时，查证、换表征、改比较、调整范围或收束。

## 2. 在工作中生成、验证并捕捉成果

- 按任务使用 [Geneplore 的生成与探索](https://mitpress.mit.edu/9780262061506/creative-cognition/) 和 [双空间搜索](https://doi.org/10.1016/0364-0213%2888%2990007-9)。例如从同一现象提出不同机制，再寻找会让它们给出不同预测的观测。也可重构科学问题、组合方法、借用关系类比或处理反常结果。
- 当出现有复用价值的阶段成果、用户确认重要决定、外部验证带来新发现，或准备切换任务时，简短捕捉。记录最小摘要、来源或产物位置、适用范围、当前状态，以及下一次何时读取或重查。保留已完成产物的可复用入口。未检验的科学构思按候选保存，附判别线索。
- 需要保护可辨认的参与者资料、未公开数据和敏感信息时，只保存获准保留的最少内容。对同一成果合并更新。当前任务优先，简单任务可直接完成，无有用新增时略过写入。

## 3. 任务后盘点与提炼

盘点频率可设为关闭、仅在重要成果或变化时盘点、或每个任务结束时盘点。未指定频率时按重要成果和变化盘点。无值得复用的新增时完成检查即可。盘点检查三件事：

1. **结果**。有什么可以供下次直接引用的产物、决定或证据？
2. **过程**。哪个策略有用，哪个卡点值得查？成功、部分成功、失败或意外结果都可作为经验。
3. **迁移**。它只适用于当前任务，还是有证据支持在一类任务中重用？下一次怎样判断它仍有效？

按 [CoALA 的模块化记忆](https://openreview.net/pdf/07475727a2787df12052196b9f2624497ef3c3bd.pdf) 区分任务经历、语义知识和程序做法。原始经历保留作追溯。已确认的成果、决定和事实可按其证据状态直接登记。候选假设、一次有效的方法或经验性解释可先按条件试用。准备把一项经验变成长期自动采用的程序记忆时，再用新任务和回归案例验证。详细做法见 [记忆与试验操作](references/operations.md)。

## 4. 再使用、巩固与修订

- 后续任务按目标和适用条件主动取回记录。核对关键来源和约束是否变化。使用产生新证据时记录有效、无效或适用范围变化，必要时合并、替换或归档。当前用户要求和核实的项目事实优先。
- 若要把做法变成长期规则，明确要改进的行为和要保护的原行为。固定关键评测条件，对照基线、候选与未用于调优的新案例。通过后写入真实加载的项目程序记忆，并保留证据及可恢复版本。情况复杂时再使用隔离试验。明确来自用户的偏好和可核实事实按相应来源更新。
- 可选的 [记忆工具](scripts/evolve.py) 支持工作中或结束后登记和检索条目，以及长期记忆的候选、采用和回滚。优先复用宿主已有且授权的记忆接口。需要接入每任务盘点时，在宿主实际加载的项目入口明确配置，并用新会话核验。参见 [产品机制与接入](references/product-patterns.md)。

交付原任务成果。若记忆更新会影响后续工作，再简要说明记录了什么、状态和位置。区分已写入、后续已读取和后续表现已验证。
