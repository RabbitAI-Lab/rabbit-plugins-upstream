## Description: <br>
Find and rank GitHub developers by location, technology, and role. Search for candidates, get scored profiles with tech stack matches, activity, and contact info. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[mordka](https://clawhub.ai/user/mordka) <br>

### License/Terms of Use: <br>


## Use Case: <br>
Recruiters, sourcers, and talent teams use this skill to search GitHub developers by location, role, and technology stack, then review scored candidate profiles and contact-oriented fields. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Recruiting searches and results can include personal data such as email, social handles, hireability, company, and location. <br>
Mitigation: Use returned data only for legitimate, compliant recruiting or research, avoid bulk unsolicited outreach, and retain only necessary data. <br>
Risk: Search criteria are sent to githunt.ai for processing. <br>
Mitigation: Install and use the skill only where sending recruiting search criteria to GitHunt's API is acceptable. <br>
