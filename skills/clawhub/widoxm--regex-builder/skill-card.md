## Description:

Write, explain, and test regular expressions. Use when the user needs to match, extract, validate, or replace text with a pattern, or asks what a regex does.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, analysts, and other text-processing users use this skill to create readable regular expressions, explain existing patterns, and test matches against positive and negative examples.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated regex patterns or test snippets may be incorrect, overmatch, or run inefficiently on very large or sensitive inputs.

Mitigation: Review generated patterns and run snippets only on small representative data before applying them broadly.
