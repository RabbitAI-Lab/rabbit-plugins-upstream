# Klik Action Readiness

An educational, non-executing companion skill for deciding whether an AI may
prepare a bounded next step from remembered Context.

It makes five conditions reviewable before preparation: a supporting source,
freshness, scope, existing authority, and an observable expected result. It
returns a person to the decision when work requires new access, material
judgment, or an external commitment.

The skill does not access accounts, run tools, send messages, make commitments, or authorize execution. It asks only for redacted context and must not be used
to collect credentials, recordings, transcripts, client data, financial data,
health data, or other sensitive information.

## When To Use It

- A prior Session may be relevant, but it is unclear whether the Context is
  still current.
- A person or agent needs a reviewable plan before preparing follow-through.
- A workflow needs to identify exactly where a human decision must return.
