## Description: <br>
Stop waiting for prompts. Keep working. <br>

## Use Case: <br>
Developers and agent operators use this skill to set up task queues, proactive heartbeat routines, and scheduled work patterns so agents can continue useful work between direct human prompts. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Unattended scheduled agent activity may run without clear scope, approval, or shutdown controls. <br>
Mitigation: Before enabling schedules, define allowed task types, writable files, posting rules, token or spend limits, logs, and a simple way to disable scheduled activity. <br>
Risk: Autonomous work in sensitive or production workspaces can make changes or publish updates beyond the intended operating boundary. <br>
Mitigation: Use this skill only in workspaces where unattended activity is intended, and avoid sensitive or production workspaces until explicit controls are in place. <br>
