## Description:

Turns course lessons into speakable scripts and consistent, slide-ready narration audio using Beatra.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Educators, course creators, and training teams use this skill to prepare lesson scripts, approve a pilot voice, and produce an ordered pack of narration audio for courses and slide decks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Connecting Beatra grants a broad authorization shared across Beatra skills.

Mitigation: Install only if the shared authorization is acceptable; review account access before approving it.

Risk: Package code updates automatically without separate confirmation by default.

Mitigation: Review update settings before use and disable automatic updates if that behavior is not acceptable.

Risk: Voice cloning and narration can incur charges, and cloning requires the speaker's consent.

Mitigation: Confirm speaker permission and current pricing before cloning; approve the pilot and remaining-pack estimate before paid generation.
