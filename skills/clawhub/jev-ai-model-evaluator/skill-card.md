## Description:

Helps users plan reproducible AI model evaluations, compare candidates with transparent criteria, and audit model claims.

This skill is ready for commercial/non-commercial use.

## Publisher:

[gpt-img-2](https://clawhub.ai/user/gpt-img-2)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and other model evaluators use this skill to design task-specific tests, compare candidate models against weighted criteria and must-pass checks, and assess the strength of model claims.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The optional MCP setup installs an unpinned GitHub-based package.

Mitigation: Enable it only after reviewing or pinning the exact version and trusting its source.

Risk: Model rankings may overstate what limited tests or outdated price and version data support.

Mitigation: Run task-specific checks and verify current model versions and pricing before relying on a recommendation.
