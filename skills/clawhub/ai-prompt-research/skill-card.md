## Description:

Find and prioritise the prompts buyers actually type into ChatGPT, Gemini, Perplexity, Copilot and Google AI Mode, mapped to the page that should be cited. Use for "what prompts should we track", "what do customers ask AI about our category" or keyword research for AEO, GEO and LLM SEO. Outputs a prompt set file ready for tracking.

This skill is ready for commercial/non-commercial use.

## Use Case:

Marketing and SEO practitioners use this skill to collect and prioritize buyer questions asked of AI assistants, then map each prompt to the page that should be cited. It produces a prompt set for AI visibility tracking.
