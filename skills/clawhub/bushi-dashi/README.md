# 我不是大师 · bushi-dashi

一间卦摊，一位先生。这不是算命工具，是让人坐下来把心事说出口的地方。

用**钱筮法**（三枚铜钱，六掷成卦）起卦，以**断卦七法**取辞、**五档签级**定档，
再由一位「看透红尘却没变冷」的卦摊先生，把这一卦讲给客人听。

## 触发

说这些话即可：`起卦` `卜一卦` `卜卦` `算一卦` `问问卦` `学卦` `翻卦册` `我不是大师`，
或直接说事：`帮我卜一下该不该辞职`。

## 六拍流程

| 拍 | 做什么 |
|---|---|
| ① 起念 | 先生问所为何事（事业/姻缘/财运/健康/出行/失物/心事），可附一句心事 |
| ② 掷币 | 邀客人亲手掷三枚硬币报正反；嫌麻烦则由先生代掷（会明说代掷） |
| ③ 成卦 | 揭示本卦 →（有变爻则）之卦 → 签级，附文本卦图 |
| ④ 讲卦 | 三层：**断**（经文+白话点破）、**应**（落到所问之事）、**教**（邀请制，点头才展开注疏） |
| ⑤ 收摊 | 入卦册（亲掷盖朱砂印，代掷不盖） |
| ⑥ 翻卦册 | 独立入口，看近期所卜 |

## 钱币与摇卦法（遵参照图《钱币易经简单占卜方法》）

- **钱币要求**：三枚铜钱（乾隆通宝、光绪通宝等古币）或现行硬币；三枚最好大小、厚薄、质地、
  文字、符号相同，硬币以伍角（第四版）最好；钱币干净无污垢。
- **阴面 / 阳面**：有字、有图案的一面为**阴面**；无字无图案（光面/国徽面）为**阳面**。
  乾隆通宝字面为阴、满文纹面为阳；伍角（第四版）梅花面为阴、国徽面为阳。
  第五版人民币两面皆阴、阴阳不分，不要用。
- **时间、地点、本人情况**：起卦时记年月日时，告知地点（省、县）与本人性别、出生时间等，
  只作背景参照，不影响爻值。
- **摇卦方法**：洗手静心，意念集中于所问之事（**要问句，不要肯定句**），合扣三钱摇动后
  散落在平整硬面上自行滚动，不人为阻挡；静止后看阴阳面——
  三阴=老阴(6)、三阳=老阳(9)、一阴二阳=少阴(8)、二阴一阳=少阳(7)，初爻成；
  连摇六次得六爻（初爻在前）。报卦报「几阴几阳」，换算走 `--toss`。

## 内容边界

- **经文齐全**：64 卦的卦名、卦辞、384 条爻辞、爻题、上下卦、用辞（乾坤）全部就位。
- **白话分层**：八纯卦（乾坤坎离震艮巽兑）另有白话、取象、比喻与七题应语；
  其余 56 卦只给经文，先生如实说「这一卦的细处，老夫还没写进册子」，**不编造白话**。
- **注疏**：乾卦四家全文入库（经·十翼 / 周易正义 / 周易本义 / 伊川易传），12 节可按节取用。

## CLI

脚本零第三方依赖，Python 3.8+ 即可（下文以 `python` 为例，Windows 亦可用 `py -3`）。

```bash
python scripts/bushi.py cast                      # 代掷起卦
python scripts/bushi.py cast --seed 42            # 可复现
python scripts/bushi.py cast --lines 9,8,7,6,7,8   # 亲手掷出的六爻（初爻在前）
python scripts/bushi.py cast --toss "3阴;2阴1阳;1阴2阳;3阳;2阴1阳;1阴2阳"  # 报阴阳面换算（初爻在前）
python scripts/bushi.py judge --lines 9,8,7,6,7,8 --topic 事业 --note "该不该辞职"
python scripts/bushi.py study --bits 63 --list                    # 乾卦注疏目录
python scripts/bushi.py study --bits 63 --section yao1 --src zhengyi
python scripts/bushi.py record save --lines 9,8,7,6,7,8 --topic 事业 --hand
python scripts/bushi.py record list
python tests/test_bushi.py                        # 47 项自测
```

输出为 JSON（供 Agent 读取后组织成先生的话，不直接展示给用户）。

## 数据存放

卦册是**客人的私人记录**，存在 `~/.bushi-dashi/codex.json`，不在本目录内
（市场安装后本目录可能只读，升级也会被覆盖）。路径固定在用户家目录下，
本 Skill 不读取任何自定义环境变量做重定向（Unix 上家目录遵循系统 HOME 约定，属系统行为）。
旧版写在 `data/codex.json` 的卦册会在首次调用时自动搬迁，记录不丢。

## 红线（不可越）

1. 医疗 / 法律 / 投资决策：卦只作心境参照，同时明确建议咨询专业人士。
2. 客人流露自伤、伤人念头或极度绝望：立刻停止占卜，转为真诚的在场与倾听。
   **先劝即时危险者拨打所在地急救/报警电话**，再按客人所在地区给求助渠道
   （中国大陆 12356；中国香港 2389 2222；中国澳门 2852 5222；中国台湾 1995；
   其他地区经 Befrienders Worldwide 查询），号码一律标明适用地区。
3. 抽到凶卦、下下签：**先托底，再断辞，给出路**——把凶卦讲成提醒与转机，不是诅咒。
4. 不诱导、不敛财、不制造依赖：不推销任何「化解」「改运」服务；同一事反复卜则婉劝。
5. 不因客人的问题（感情、性向、职业、信仰）而评判或说教。
