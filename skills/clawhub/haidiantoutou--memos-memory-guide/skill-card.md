## Description: <br>
Guides an agent in using MemOS Local memory tools to search prior conversations, retrieve task context, write or share memories, and discover reusable skills. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[haidiantoutou](https://clawhub.ai/user/haidiantoutou) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and agent users use this skill to help an agent search long-term conversation memory, recover prior task context, and manage local or team-shared memories and skills. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can guide agents to search saved conversation history and make selected memories visible to other local agents in the same workspace. <br>
Mitigation: Install only where local memory sharing is acceptable and monitored; avoid workspaces with confidential, personal, customer, or regulated data unless that sharing model has been approved. <br>
