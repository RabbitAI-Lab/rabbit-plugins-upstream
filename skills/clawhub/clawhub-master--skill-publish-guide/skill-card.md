## Description: <br>
Guides agents and publishers through preparing a ClawHub skill directory and using the clawhub CLI to publish or update a skill. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[clawhub-master](https://clawhub.ai/user/clawhub-master) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, maintainers, and agent operators use this skill to prepare ClawHub skill metadata, run dry-run checks, publish with sync or publish commands, and verify the published skill. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Publishing, hiding, deleting, or updating a skill with CLI commands can affect a public ClawHub release if run against the wrong directory, slug, or account. <br>
Mitigation: Run dry-run and inspect commands first, confirm the logged-in publisher and target slug, and only approve CLI actions that match the intended release workflow. <br>
