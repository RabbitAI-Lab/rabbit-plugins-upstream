# 安全说明

- **无远程代码下载**：缠论计算引擎(chan.py, MIT)已随技能打包在 engine/ 目录，运行时不从任何远程地址拉取或执行代码
- **无动态执行**：打包引擎已做安全化补丁，移除了上游全部 exec 调用（改为等价的直接赋值/方法调用，回归测试输出逐字节一致）、任意模块动态 import（改为两项白名单）与 pickle 序列化辅助（整体移除，本技能不使用反序列化）
- **网络请求仅限行情数据，域名可枚举**：
  - fuyao.aicubes.cn（同花顺官方行情，仅当用户配置了自己的 key）
  - 东方财富/新浪行情接口（经 akshare 库，免费公开行情）
  - pypi.tuna.tsinghua.edu.cn / pypi.org（仅 setup_env.py 安装依赖时）
- **密钥处理**：用户自备的行情 key 通过 `setup_env.py --set-key` 在本地终端录入（getpass 不回显、不经过 AI 对话记录），存于用户目录凭据文件，Windows 下经 DPAPI 用户级加密（仅本机本用户可解），Linux/macOS 下文件权限 600，或由用户自行配置环境变量 HITHINK_FINANCE_API_KEY；不硬编码、不上传、技能文档明令禁止在聊天中传递密钥
- **无数据外传**：所有计算在本地完成，分析结果只输出到本地 stdout/文件
- **只读**：本技能只读取公开行情数据，不涉及任何交易接口，无法访问用户的证券账户
- 输出为缠论规则的机械执行结果，带失效价位可复核；不构成投资建议
