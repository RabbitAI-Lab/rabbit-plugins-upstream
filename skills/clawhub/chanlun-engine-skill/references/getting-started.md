# 新手三步上手指南

不需要懂编程，不需要知道"API"是什么。整个准备工作就是：用同花顺账号登录一个网页，复制一串字符。

## 第一步：拿数据钥匙（免费，大约 2 分钟）

分析股票需要行情数据，数据来自同花顺官方，用一把"钥匙"来取。申请方法：

1. 打开网页 [fuyao.aicubes.cn/admin](https://fuyao.aicubes.cn/admin)
2. 用你的**同花顺账号**登录（就是你手机上看行情用的那个同花顺 App 的账号；没有的话下载同花顺 App 注册一个）
3. 登录后点「签发 / 创建 API Key」
4. 复制出现的那串以 `sk-fuyao-` 开头的字符。这就是你的数据钥匙，只显示一次，先存在备忘录里，不要发给别人

三个常见疑问：

- **收费吗？** 目前免费。
- **安全吗？** 这把钥匙只能读取行情数据（K线、涨跌停这些公开信息），碰不到你的股票账户，更碰不到钱。不想用了随时回那个网页作废它。
- **和我的炒股账户有关系吗？** 没有任何关系，它不知道你持仓什么，也下不了单。

## 第二步：把钥匙交给 AI 存好

最省事的方式：**直接把钥匙发给你的 AI 助手**，说一句"帮我存好这个数据钥匙"。它会立即把钥匙加密存进你本机（Windows 用系统级加密，只有你这台电脑的你能解开），存好后你可以删掉聊天里那条消息；不放心随时回申请网页作废重签一把。

介意钥匙出现在聊天记录里的话，也可以自己在终端录入（输入过程不显示任何字符）：

```
python scripts/setup_env.py --set-key
```

两种方式效果相同，之后取数自动走官方源。

## 第三步：开始分析

对 AI 说：

> 帮我用缠论分析贵州茅台

你会得到一份包含四样东西的分析：

1. **操作判定**：现在是买入候选、持有、卖出减仓，还是等待观察
2. **持仓者和空仓者分开的建议**：手里有票和没票的人，动作不一样
3. **关键价位**：止损或失效价位，到了这个价就是判断错了，认错离场
4. **观察条件**：如果是"等待"，明确告诉你等什么信号、看什么价位

换任何股票名字或代码都可以。想扫全市场找最近出现买点的股票，对 AI 说"帮我扫描全市场的缠论买点"（这个功能耗时约 2 分钟，建议在配置好数据库的电脑或服务器上跑）。

## 遇到问题

把报错原样发给你的 AI 助手，它会按本技能的说明排查。装不上、跑不通的问题多数出在 Python 版本（需要 3.11 以上），让 AI 带你装就行。
