## 开源实现的通病（选型时的坑）

1. **线段三派分裂**：chan.py 提供三种算法可选（chan/1+1/break，后两种已弃用）；czsc 1.0 核心干脆不做线段（作者立场：以笔为a0，"5分钟笔等价1分钟线段"）
2. **中枢递归妥协**：原文中枢由"次级别走势类型"重叠构成（35课递归定义），几乎所有实现用笔/段直接替代（笔段分形派），本引擎同此，已声明
3. **背驰被量化取代力度原义**：原文背驰=力度比较无量化定义，MACD 仅辅助（24课标题自明）；实现普遍把 MACD 面积/峰值当定义本身
4. **区间套几乎无人真做**：需多级别联立递归到分钟级
5. **数据源决定上限**：递归起点从某K线周期起步已是妥协；日K-only 场景只能做日-周-月粗糙三层

## 为什么"心算缠论"被禁止（证据）

- 两套确定性脚本引擎（自写v5t vs chan.py）同数据对拍：笔对齐率 0.87-1.0，**中枢对齐率仅 0.0-0.42**，买卖点数量差数倍
- 社区 8 个缠论 Agent skill 中 6 个认真实现（含 czsc 作者本人的官方 skill）全部走"脚本算结构"路线；唯一纯 LLM 裸算的实现自曝"背驰判断取决于你选哪个高点，这是判断问题"
- 结构对口径极敏感 → LLM 心算=第三套随温度漂移、不可复现的口径
