## Known Risks and Mitigations:

Risk: Credential-checking or debugging advice could expose financial balances or confidential information.

Mitigation: Disable discovered-key validation unless the exact action is expressly authorized, and do not treat financial-balance requests as identity checks.

Risk: Queries derived from private logs or code could disclose sensitive information to search providers.

Mitigation: Review and sanitize those queries before sending them to external search providers.

Risk: Optional tools or active testing could exceed the user's authorized scope.

Mitigation: Install optional tools selectively and keep active testing within written scope.
