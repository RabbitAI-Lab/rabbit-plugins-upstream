# 日志分析与故障诊断工具箱

[English](README.md)

分析访问日志、JSONL 应用日志和 GZIP 日志，统计错误、状态码、热门路径及时间分布。

## 功能

分析访问日志、JSONL 应用日志和 GZIP 日志，统计错误、状态码、热门路径及时间分布。

在当前助手的工作区运行，输出处理结果和报告，原文件保留。

## 用法示例

安装后，把任意一条发给 AI，并附上相关文件或网址。

```text
分析这份访问日志，找出最多的404和500错误，生成报告。
```

```text
对比今天各小时的错误数量，列出最常见的故障类型。
```

```text
检查这批压缩日志，先排除机器人，再统计访问路径和独立IP数量。
```
