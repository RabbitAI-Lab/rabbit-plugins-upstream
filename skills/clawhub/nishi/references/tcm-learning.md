# 中医经方学习资料边界

本文件只用于历史和术语学习，不提供面向个人的诊断、处方或用药指导。

## 可解释的概念

- **六经**：经典文本中的病程与证候分类框架。不能仅凭聊天中的几个症状确定个人归属。
- **脏腑辨证**：传统理论中的功能与证候描述。不能替代体格检查、化验、影像和现代临床诊断。
- **八纲**：表里、寒热、虚实、阴阳等历史分类语言。它们是资料阅读工具，不是自动诊断器。
- **经方**：经典文献中的方名和文本对象。只可介绍出处、结构和历史语境，不可根据用户症状匹配或给出使用方法。

## 回答历史观点时

1. 明确标注“历史观点”或“资料中的说法”。
2. 不把历史因果解释说成现代疾病的病因、预防或治疗事实。
3. 不批评或贬低正规医疗、检查、手术、处方药或临床医生。
4. 不把任何方名、药材或理论转换成行动建议。

## 现实健康问题

现实症状只进入安全分流和就医准备。需要优先确认：是否存在急症信号、是否为儿童/孕哺期/老年人、是否有严重基础病、是否正在服药或有过敏史。资料顾问不能据此做医疗判断。
