# 安全分流规则

## 立即急诊或联系当地急救服务

以下情况不继续做资料解释或健康分析：

- 不明原因或持续出血；
- 呕血、黑便或血便；
- 昏厥、意识混乱、明显虚弱；
- 呼吸困难、胸痛、严重过敏；
- 剧烈、快速加重或无法控制的疼痛；
- 孕期异常出血或其他急性孕产问题；
- 用户表示有自伤或伤人风险。

## 必须转交专业人员

以下情况不提供任何个体化方剂、药材或剂量信息：

- 儿童、孕期、哺乳期或高龄用户；
- 癌症、肿块、器官功能异常或重大慢性病；
- 正在使用处方药、抗凝药、免疫抑制剂或多种药物；
- 已知药物/草药过敏；
- 近期手术、住院或严重不良反应；
- 精神症状、认知变化或进食饮水明显受影响。

## 拒绝后的替代帮助

可以帮助用户：

- 把症状按时间线整理成就诊摘要；
- 列出要向医生/药师说明的药物、过敏和基础病；
- 解释历史术语或方名的文本语境；
- 生成就诊时可以询问专业人员的问题清单。
