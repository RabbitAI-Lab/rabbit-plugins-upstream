# sum_and_translate_install_check

Скилл проверяет, что текущий Python-интерпретатор пригоден для пайплайна
«саммари и перевод PDF», и умеет доустановить недостающие зависимости.

## Когда вызывать

- Пользователь просит **саммари** по приложенному PDF.
- Пользователь просит **перевод** приложенного PDF.
- Перед первым запуском пайплайна в новой среде.

## Использование

Проверка (ничего не ставит, только импортирует):

```bash
python install_libraries.py
```

Успех — последняя строка `libraries installation complete` и код возврата 0.
Неудача — код возврата 1 и список несобранных импортов.

Доустановка в текущий интерпретатор, затем повторная проверка:

```bash
python install_libraries.py --install
```

## Требования к среде

- **Python 3.11.** На 3.12+ `paddlepaddle==3.0.0` колёс не имеет.
- Системный **poppler** (`pdftoppm`) для `pdf2image`:
  macOS `brew install poppler`, Debian/Ubuntu `apt-get install -y poppler-utils`.
- Для рендера HTML в PDF нужен браузер playwright:
  `python -m playwright install chromium`.
- Первый вызов `PPStructureV3()` скачивает веса моделей (сотни МБ) —
  это происходит уже в пайплайне, не в этом скилле.

## Про модули проекта

`html_to_pdf_summary`, `html2pdf_latest`, `merge_html_latest` — это файлы
самого проекта, а не пакеты из PyPI. Скрипт проверяет их отдельно и **не**
считает их отсутствие ошибкой: вне каталога проекта их и не должно быть.
Чтобы проверить и их, запускайте скрипт из корня проекта.
