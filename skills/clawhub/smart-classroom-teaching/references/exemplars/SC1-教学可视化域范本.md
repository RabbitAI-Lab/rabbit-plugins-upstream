## 范本说明
- 对应域: SC1 教学可视化域
- 覆盖任务: SC1-01 自然语言要素解析、SC1-02 图形标准化、SC1-03 平面转3D、SC1-04 函数曲线生成
- 适用场景: 将对话式自然语言描述转化为图形、公式、3D 模型与函数曲线
- 使用方式: 仅借鉴结构与风格，不复制内容

## 任务要求总览

| 任务 | 必选组件 | 可选组件 | 格式 |
|------|---------|---------|------|

## 各任务结构框架与示例

### SC1-01 自然语言要素解析
**结构框架**：原描述 → 要素类型 → 结构化表达
**示例**：
- 原描述：「画一个直角三角形，直角边 3 和 4」
- 要素类型：几何图形
- 结构化表达：{图形: 直角三角形, 直角边: 3, 4}

### SC1-02 图形标准化
**结构框架**：草图意图 → 目标图形 → 补全规则 → 标准图形（含参数）
**示例**：
- 草图意图：「一个三角形，标注直角」
- 目标图形：直角三角形
- 补全规则：加直角标记、标边长
- 标准图形：直角标记 + 边长标注（附 SVG）

### SC1-03 平面转3D
**结构框架**：平面图形 → 立体结构 → 可拆解部件 → 观察要点
**示例**：
- 平面图形：三角形
- 立体结构：三棱柱
- 可拆解部件：底面 / 顶面 / 侧面
- 观察要点：顶点、棱、面的位置关系

### SC1-04 函数曲线生成
**结构框架**：算式 → 曲线特征 → 关键点 → 动态描述
**示例**：
- 算式：y = x²
- 曲线特征：开口向上、顶点 (0,0)
- 关键点：(-2,4)、(0,0)、(2,4)
- 动态描述：对称轴为 y 轴，随 x 增大先减后增
