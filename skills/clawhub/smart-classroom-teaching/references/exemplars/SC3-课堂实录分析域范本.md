## 范本说明
- 对应域: SC3 课堂实录分析域
- 覆盖任务: SC3-01 教学结构分析、SC3-02 教学行为分析、SC3-03 教学策略分析、SC3-04 微课切片生成、SC3-05 诊断报告生成
- 适用场景: 从课堂记录提取结构化分析并生成循证诊断报告
- 使用方式: 仅借鉴结构与风格，不复制内容

## 任务要求总览

| 任务 | 必选组件 | 可选组件 | 格式 |
|------|---------|---------|------|
| SC3-01 教学结构分析 | 课堂记录、环节划分、结构逻辑、时间标注 | 时长占比、对比基准 | 教学结构图 |
| SC3-02 教学行为分析 | 课堂记录、教师行为分类、学生行为分类、互动频次 | 行为时间线、互动热区 | 行为分析表 |
| SC3-03 教学策略分析 | 策略识别、有效性评估、改进方向 | 策略对比、建议优先级 | 策略分析报告 |
| SC3-04 微课切片生成 | 知识点、切片脚本、时长估算 | 字幕要点、配套练习 | 微课切片脚本 |
| SC3-05 诊断报告生成 | 教学纪要、思维导图、诊断结论、改进建议 | 多维评分、前后对比 | 诊断报告 |

## 各任务结构框架与示例

### SC3-01 教学结构分析
**结构框架**：课堂记录 → 环节划分 → 结构逻辑 → 时间/流程标注
**示例**：环节划分为「复习导入(5') → 探究(15') → 精讲(12') → 小结(5')」，标注各环节时间。

### SC3-02 教学行为分析
**结构框架**：记录梳理 → 教师行为分类 → 学生行为分类 → 互动频次 → 结论
**示例**：教师行为「讲解为主、追问 2 次」；学生行为「分组探究参与度高」；互动频次统计表。

### SC3-03 教学策略分析
**结构框架**：策略识别 → 有效性评估 → 改进方向
**示例**：策略「配方→公式迁移」；评估「有效降低推导难度」；改进「增设针对性追问」。

### SC3-04 微课切片生成
**结构框架**：知识点 → 切片结构（导入/讲解/例题/小结）→ 脚本 → 时长估算
**示例**：知识点「求根公式推导」，5 分钟切片脚本，含导入/推导/例题/小结。

### SC3-05 诊断报告生成
**结构框架**：教学纪要 → 思维导图 → 诊断结论（结构/行为/策略）→ 改进建议
**示例**：纪要概括流程；思维导图展开课题分支；结论分三维；建议按优先级排序。
