### 依赖拓扑摘要

以下为智慧课堂教学任务的主要依赖链路，执行框架可据此自动编排管线。

#### 一、域内链路

**教学可视化链路**: SC1-01 → SC1-02 → SC1-03；SC1-01 → SC1-04
**虚拟人思辨链路**: SC2-01 → SC2-02 / SC2-03 / SC2-04
**课堂实录分析链路**: SC3-01 → SC3-02 → SC3-03 → SC3-05；SC3-01 → SC3-04
**因材施教链路**: SC4-01 → SC4-02；SC4-01 → SC4-03
**多模态交互链路**: SC5-01 → SC5-02
**教学资源链路**: SC6-01 → SC6-02；SC6-01 → SC6-03
**内容安全链路**: SC7-01 → SC7-02；SC7-01 → SC7-03

#### 二、跨域协同链路

**完整教学分析链路**: SC3-01 → SC3-02 → SC3-03 → SC3-05 → SC4-03
**个性化答疑链路**: SC4-01 → SC4-02；SC2-02 → SC4-02（虚拟人诘问支撑答疑）
**指令驱动链路**: SC5-01 → SC5-02 → SC1/SC3/SC6（指令分发到各域）

#### 三、守护贯穿链路

SC7（内容审核/教育伦理/隐私脱敏）作为 G 类守护单元，在 SC1-SC6 各域的产出环节贯穿插入，尤其强制于 SC3 诊断报告、SC4 学情分析、SC6 资源生成的交付前校验。

#### 四、知识图谱

**实体节点类型**：任务节点（SC1-01~SC7-03，24 个任务）、域节点（SC1~SC7）、元操作节点（S/C/A/O/I/G）、产出节点（诊断报告/课件/话术等）。

**关系边类型**：依赖边（→）、组合边（⇉/⇇）、输入边、输出边、守护边（G 贯穿）。

**推理能力**：路径推导（从入口任务到产出任务的最优路径）、任务推荐、依赖分析、并行识别。
