## 范本标准格式模板

每个域范本文件遵循以下标准格式：

```
## 范本说明
- 对应域: {域代号} {域名}
- 覆盖任务: {任务ID列表}
- 适用场景: {场景描述}
- 使用方式: 仅借鉴结构与风格，不复制内容

## 任务要求总览
| 任务 | 必选组件 | 可选组件 | 格式 |
|------|---------|---------|------|

## 各任务结构框架与示例
### {任务ID} {任务名}
**结构框架**：...
**示例**：...
```

## 使用约束

1. 样本法模仿产出时仅借鉴结构和风格，不直接复制示例内容。
2. 范本均须脱敏，不得含真实学生姓名、学校名称或可识别个人信息。
3. 范本仅供结构与风格参考，实际产出须基于当下任务的具体输入。
