## Description:

Turns product specifications, manuals, catalogs, or ecommerce listings into shopping videos with multilingual voiceover and an optional virtual host.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Sellers and marketers use this skill to create product ads and cross-border shopping videos from product information or ecommerce listings.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and attached product files may be sent to the third-party dLazy service.

Mitigation: Attach only files you are comfortable uploading and review content before sending.

Risk: The dLazy login flow stores an API key in local CLI configuration.

Mitigation: Protect the local key and rotate or revoke it through the dLazy dashboard if needed.

Risk: Using the third-party CLI may install a persistent global executable.

Mitigation: Review the CLI before use and choose the pinned npx option if a global installation is unwanted.
