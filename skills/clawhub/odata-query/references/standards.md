# Normative OData v4 references

Use these primary sources when provider behavior is ambiguous or a less common construct is required:

- [OData Version 4.01, Part 1: Protocol](https://docs.oasis-open.org/odata/odata/v4.01/odata-v4.01-part1-protocol.html)
- [OData Version 4.01, Part 2: URL Conventions](https://docs.oasis-open.org/odata/odata/v4.01/odata-v4.01-part2-url-conventions.html)
- [OData JSON Format Version 4.01](https://docs.oasis-open.org/odata/odata-json-format/v4.01/os/odata-json-format-v4.01-os.html)
- [OData Common Schema Definition Language (CSDL) XML Representation Version 4.01](https://docs.oasis-open.org/odata/odata-csdl-xml/v4.01/odata-csdl-xml-v4.01.html)
- [OData Version 4.0 standards index](https://docs.oasis-open.org/odata/odata/v4.0/)
- [OData vocabularies](https://github.com/oasis-tcs/odata-vocabularies)

Prefer the service's declared version and metadata over assuming every optional feature in the specification is implemented. Provider documentation may define authentication, throttling, custom query options, and stricter limits without changing OData query semantics.
