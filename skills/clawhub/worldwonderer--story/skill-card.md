## Description:

Routes Chinese-language web-novel writing requests to companion skills and can open a local workspace dashboard.

This skill is ready for commercial/non-commercial use.

## Publisher:

[worldwonderer](https://clawhub.ai/user/worldwonderer)

### License/Terms of Use:

MIT

## Use Case:

Chinese-language fiction writers use this skill to select writing, analysis, research, review, and cover workflows, manage the active book, and browse project files locally.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The local dashboard can browse, edit, and delete workspace files.

Mitigation: Start it only for workspaces you trust and keep access on localhost.

Risk: Update commands can replace installed skills or project copies.

Mitigation: Review the proposed commands and approve updates before changing an installation.
