## 2026-09-04（周五）· v2.0.0 【更名 + 授信量化专章】
- **【重大更名】** `real-estate-filing-query` → **`real-estate-risk-analyst`**。
  原因：本 skill 能力早已覆盖房企分析、去化口径判定、货值与授信量化，「备案查询」已名不副实。
  定位重写为 **房地产风险分析全链路（采集 → 去化 → 货值 → 授信）**：采集是手段，风险/授信研判是目的。
  配套同步：2 个自动化 prompt 的 `@skill` 调用、3 个 skill 的 7 处交叉引用、`scripts/` 内硬编码路径，全部切到新名（避免断链）。
  历史文档与旧对话中出现的旧名均指本 skill。
- **新增「授信量化：四档去化口径与结清触发点」专章**（深圳六家实战）。
  既有 A/B/C 三档都把「首次登记（竣工未确权）」计入已处置 → 系统性高估现金回笼。
  补第四档 **D 现金回笼率 = 已售·网签 / 总套数**（最保守，只看真卖出去多少）。
  实证：翠湖大厦 A=100% 但 D=11.4%（468 套是首次登记）；深铁熙府 A=100% 但 D=0%（2080 套全安居房，不可变现）。
  **结论：偿债来源是销售回款不是竣工登记，结清能力须以 D 为主、A 为辅。**
- 两条实测铁律入章：①**状态互斥·禁双重扣减**（五类状态互不重叠，有效可变现 = 在售×(1−业态折扣)，不可再乘风险占比；云谷里 39 套 → 正确 80 套）；
  ②**缺失严禁当 0**（分项为「—」时置 None、显示「—」，不得 `or 0` 参与计算；万科麓山贵阳曾因此被误算 D=0% 并误报"回笼严重不足"）。
- 补录 **headless 反检测启动参数铁律**：WAF 拦截时先加 `--disable-blink-features=AutomationControlled` 重试（零成本），
  而非直接上 CDP。2026-09-03 实测：裸 launch 拿不到 token 致底数停更 15 天无人知晓，加参数后一次即通（采到 4,417 证/2,936 项目）。
  排障第一动作是**比对启动参数**，勿误判为"引导页项目选错"。
- 补录 **韧性采集器「连续退避封顶」**：退避序列走到最后一阶仍无退出条件时，遇 IP 级持久封禁会无限空转
  （东莞实测 40+ 小时零产出）。须设连续退避计数 + 成功复位 + 达上限写 flag 后退出。
- 隐私脱敏（公开发布）：移除 `scripts/` 内 2 处硬编码私人路径，改为环境变量/`%~dp0` 动态定位。
