# 瑞数 / 政窗 专项（动态 token 反爬识别与应对）

> 主文档「反爬类型库」仅列速查；本分册给可落地动作。技术细节另见 `references/real-estate-guide.md`。
> 最近更新：2026-08-12

## 一、是什么
瑞数（Ruishu）/ 政窗类防护是**动态令牌 + JS 挑战**型 WAF：页面为 Vue/React SPA，关键 API 需服务端动态下发的 `token`（每次请求不同），裸 HTTP 直连必失败。

## 二、识别信号
1. 平台是 SPA，源码头里看不到数据，需 XHR 才返回 JSON。
2. 直接 `curl` / `requests` 接口返回 403 / 空 / 「非法请求」。
3. 浏览器 Network 里接口带 `token` / `sign` / `key` 参数，且每次刷新值不同。
4. 页面加载时有短暂 JS 执行（挑战）后才出数据。

## 三、标准应对（深圳平台已验证）
1. **必须用 Playwright（浏览器）**，不能裸 HTTP。
   ```python
   from playwright.async_api import async_playwright
   async with async_playwright() as p:
       b = await p.chromium.launch(headless=True,
           args=["--disable-blink-features=AutomationControlled"])
   ```
2. **拦截 response 提取 token / 数据**，不要自己算签名：
   ```python
   page.on("response", lambda r: _capture(r))   # 命中目标 API 即存响应
   await page.goto(url, wait_until="networkidle")
   ```
3. **用同域 `page.evaluate(fetch)` 发 API**（带浏览器 cookie / 动态 token）：
   ```js
   const resp = await fetch(u, {method:'POST', headers:{'X-Requested-With':'XMLHttpRequest'}, body:p});
   ```
4. **关键坑（深圳实测）**：
   - 房源接口必须用 5 位 `key` 作 fybId；19 位 `value` 会返回 500「程序异常」。
   - 详情页默认只回 1 单元，须拦截 `getBuildingDictToPublicity` 看 `gnqmcList`，多单元须逐单元抓。
   - 状态词表随项目不同，勿硬编码 4 种；剩余货值口径「已卖出/已登记」= `{已备案, 已售, 首次登记}`。

## 四、降级
若 Playwright 在某环境不可用，该城市归入 D/E 类，转「官方证级（若有开放 API）+ 外网补价」模式，来源列改黄底标注。
