## 一、城市分类（A–E）

| 类 | 含义 | 典型城市 | 自动化策略 |
|----|------|----------|------------|
| A | 纯匿名可自动化（逐套/证级均可 API） | 深圳、成都、佛山、珠海、南京、重庆、苏州、西安、武汉、郑州、厦门、青岛 | 直接 Playwright 拦截落盘 / 纯 requests |
| B | 逐套销控表可自动化，备案价需小程序/依申请公开 | 广州（阳光家缘） | 销控表 API 实拉逐套，备案价另补 |
| C | 证级可自动化，逐套需登录/小程序 | 多数省会 | 证级直采，逐套降级外网 |
| D | 持续性需用户操作（小程序/扫码） | 合肥、东莞、惠州、廊坊、天津、济南模式整合 | 官方证级 + 外网补价，来源着色 |
| E | 基本不可自动化（强登录/无公开接口） | 极少数 | 仅外网整合，红底标注 |

> 贵阳例外：属 D 但筑房网有匿名证级开放 API 可拿全量（翻页全库 6245 条），仅逐套一房一价锁登录。
> **粤安居（广东省数字住房 yueanju.zfcxjst.gd.gov.cn）已实测排除（2026-08-19）**：小程序仅预售证基础信息，无逐套房源/备案价 → 大湾区 D 城不得依赖该通道，回退"政务网证级+外网补价"。

## 〇、新城市（非省会地级市）检索方法论（2026-08-19 沉淀）

0. **【铁律·地域锁定】用户指定"XX城市楼盘"时，检索范围 = 该城市，至多扩展到所在省份；禁止跨省数据混入**（佛山→天津=检索失控）。具体：
   - 关键词必带城市/区域限定（`佛山 保利中嘉花园`），不加限定词的裸楼盘名会被搜索引擎命中异地同名盘。
   - **引用"聚合词条"（百度百科/百科类）时逐字段核对城市归属**——百科"中嘉花园"词条把佛山(乐从/保利/2020)和天津(红桥/国通/2006)两地混在一个页面，2026-08-19 曾误取天津字段当佛山用，被用户纠正。
   - 官方平台有搜索框（佛山`请输入您要查找的项目名称或推广名称或项目地址或开发商`）→ **搜索框直查，不要全量翻页**（佛山全库 5,976 楼盘翻 200 页才定位，搜索框一次命中）。
   - 拿到的每一条数据先过"城市归属校验"再入表；来源含两城以上时拆开标注。
1. **无市级统一匿名接口预期**（运城/晋府六号案例）：直接走外网聚合平台，关键词模板 = `城市 + 楼盘名 + 预售证/备案价`。
2. **证号体系可反查平台层级**：`晋商房预售运字`→运城；`并商房预售字`→太原；`FZ许`→福州；`大房预许字第`→大连。看到证号前缀即知归属与官方渠道。
3. **官方给均价的渠道优先**：太原行政审批局"新增预售许可项目"系列（唯一含获批参考均价）；平台参考价（如安居客 8500 vs 官方 12000-13000）以官方为准。
4. **楼盘聚合页含全证列表**：58 爱房参数页（运城 8 证全列+绑定楼栋）、贝壳（大连 11 证）比搜索引擎摘要更全 → 取证号直接进这些页。
5. **推广名≠备案名是常态**：福州天汇公馆=万科城市之光、太原北寒村城改=中海国际社区、大连红旗足球公园南侧改造地块=保利溪湖瑧悦 → 检索必须双名互换，官方库按备案名搜。
6. **同名歧义必带城市前缀 + 官方核验**：佛山保利中嘉花园=乐从次新盘(官方备案"中嘉花园"ID66954,保利2020竣工821户) vs 天津中嘉花园(红桥/国通2006) → 采集前先官方平台按名搜索确认归属，勿信百科聚合词条。
7. **营销软文污染警示**（厦门五缘公馆案例）：推广名在官方库无备案名命中 + 外网软文证号/开发商互斥 + 虚假 400 电话 → 判定软文不可采信，需人工在官方平台按地块/开发商反查。

## 二、反爬类型速查

> 主文档「反爬/失真类型库」已迁出至此，主文档仅保留索引。瑞数细节见 `references/瑞数专项.md`。

| 类型 | 特征 | 对策 |
|------|------|------|
| nginx Referer 校验 | 裸 curl 403，浏览器正常 | Playwright 同域 `page.evaluate(fetch)` 带 cookie |
| IP 信誉 / WAF | `ERR_NETWORK_CHANGED`、间歇性 403 | 浏览器指纹伪装 + 重试 + 降速 |
| 瑞数(Ruisu/WaterDRM) 五秒盾 | HTTP 412 + meta id `hmYiCp5tA9K0` + 随机路径混淆 JS 挑战 + 成功后设双 cookie | Playwright stealth 难稳过 → 定性 E；攻坚见 `references/瑞数专项.md` |
| 瑞数(WAF 自适应升级) | 多次探测后 412 响应体从 ~60KB 缩至 ~3KB（纯挑战页） | 一旦升级封锁停止试探，换 IP/间隔数小时或直接定性；用响应体大小判等级 |
| 瑞数(全域名覆盖) | 同 WAF 保护整个域名及子域/API/开放数据平台 | 别指望子域裸奔，探同城其他局委域名 |
| 顶象(Dingxiang) 风控 | 交互触发 captcha，数据 XHR 被拦；无感验证对非白名单 IP 弹码 | 项目级/证级可过，仅逐套被拦 → 用户本机住宅 IP 大概率进白名单 |
| 阿里云 WAF(acw_sc__v2) | renderData textarea + arg1 挑战 JS，执行后设 cookie 并 reload | Playwright 访问目标 URL 自动通过；curl/requests 会 405 |
| HTTP/2 空响应 | Chromium 取空、curl --http1.1 才 200 | 换 curl --http1.1 验证；逐套多在登录后 → 定性 D |
| PNG 价格反爬 | 单价/总价渲染为图片，HTML 无文本 | 其他字段照采，价格 OCR(tesseract)；找明文替代接口 |
| 小程序独家入口 | web 端 521/空/仅项目级，逐套锁小程序 | 持续性需用户 → 定性 D；贵阳例外走开放API直采证级 |
| 无制度基础 | 城市无官方备案价（济南官方回复"开发商自行定价"） | 定性 D，无法可依 |
| 域名劫持/不可达 | 原官网域名被出售/入口全 412 | 定性 E |
| 模板占位符失真 | 页面顶部统计数字跨项目恒等 | 忽略，按楼栋逐采求和 |
| list-mode 陷阱 | 默认只显示当前楼层少量行 | 切"楼盘模式"或调整栋 API |
| hidden-DOM 静默失真 | 隐藏 DOM 点击返回 200 但视图未刷新 | 直接调 API，不依赖隐藏 DOM 点击 |
| 价格不可见规则 | 仅"可售/期房待售"公开价，已售/已备案 `***` | 平台规则非异常，总价/面积回算单价 |
| 关键词忽略 | 列表接口不认关键词参数 | 全量翻页 + 本地过滤（贵阳实证） |

## 三、状态码图例

### 广州·阳光家缘（销控表）
| 字段 | 码 | 含义 | 授信口径 |
|------|----|------|----------|
| status | 1 | 可售（期房待售） | 未售 |
| status | 2 | 已签《商品房买卖合同》 | 已售 |
| status | 3 | 已备案（合同登记确认） | 已售 |
| status | 4 | 已过户（所有权转移） | 已售 |
| status | 5 | 不可售/限制（抵押/查封） | 限制 |
| pledgeStatus | 0/1/2 | 无抵押/已抵押/已解押 | 关注抵押 |

> 去化口径：status ∈ {2,3,4} 均计「已售/权属已转移」，勿仅按 2 计算（易低估）。

### 贵阳·筑房网（预售证）
- `sellSummaryList`：分用途（住宅/商业）批准套数与面积 —— **供应口径**，与外网成交（网签）**不可相减推库存**。
- 交叉校验：官方住宅批准套数 vs 外网宣称总户数，差异 ≤30% 可背书外网体量可信度。

## 四、数据质量校验类型（参考 scripts/validate.py）
- 重复证号 / 重复房源
- 空值关键字段（预售证号、面积）
- 面积异常（0、负数、离群 z-score > 3）
- 价格缺口占比（>30% 须外网交叉验证，单列 Sheet）
