# 深圳·山樾湾花园（汉京山樾湾）安居房去化核实 · 实战案例

> 沉淀日期：2026-08-24 ｜ 类型：安居型商品房去化核实标准路径首例 ｜ 对应 skill 专章：「安居型商品房（保障房）去化核实标准路径」

## 一、项目背景

- 备案名：**山樾湾花园**（推广名 汉京山樾湾），南山，开发商 深圳市新建投资发展有限公司
- 平台数据（深圳市房地产信息平台，2026-08-24 采集）：**2 证 / 5003 套 / 2 栋 / 8 单元**
- 状态分布：**安居房 4900（97.9%）/ 司法查封 91 / 期房待售 12**
- 证级备案均价（接口 `averagePriceTotal`）：002号 44,357.48 元/㎡、003号 43,791.37 元/㎡

## 二、核心问题

用户问："状态是安居房，是不是意味着无法确认是否售出，能否有其他官方渠道核实佐证？"

根因：**政府平台对安居型商品房只标"安居房"一个聚合标签，不区分"已签约配售"与"待配售"**——单套去化率平台层面算不出来，也不能默认"已售"或"未售"。

## 三、四步核实法落地（标准路径实证）

### 1. 平台采集走安居房适配口径
- 把"安居房"从 `SOLD_STATUSES` 剥离，单独成列，不计入审慎去化；
- 单套配售明细价平台不公开（`askpricetotalB`/`askpriceeachB` 全 `null`）→ 不回算，标注"政府定价不公开·不测算"；
- 货值仅测算期房待售 12 套（真实有价），安居房标注"不测算"；
- **关键纠偏**：证级备案均价平台公开（~4.4 万/㎡），须如实填「预售许可证清单」Sheet，避免与"单套价不公开"矛盾；
- 普通商品房 8-Sheet 管道**直接套会失真**：安居房误判已售 + 1 套 2.36 亿商业异常值拉爆均价（得出失真 10 万/㎡、2690 万总价均值）。

### 2. 住建局配售批次线交叉印证
- 渠道：南山区住建局 `szns.gov.cn/nsqzjj` "安居型商品房配售通告"（命名 `住保售〔2026〕0xx号`）
- **059号（山樾湾花园项目）选房结果公示（2026-08-11）**：房源池 1654 套（两房1065+三房589，覆盖1栋A-F座+2栋A-G座）
- **064号配售通告（2026-08-18）**：本批次 1563 套（两房989+三房574含62无障碍），认购期 2026-08-18 至 2026-09-01 18:00，**认购中、尚未选房**

### 3. 选房结果公示 xlsx 提取实际签约套数（去化硬证据）
- 059 批次发 4 个 xlsx 附件：两房/三房 × 选房结果 / 已选房源
- 在「已选房源」文件筛 `状态`="已选定" → **112 套**（两房92+三房20），选定率 6.8%
- **双重交叉校验**：同批次「选房结果」文件"选定项目=山樾湾花园 且 有选定房号"计数 = 112 套，与「已选房源」一致 ✅
- 下载附件用 curl 直链（通告页附件 URL 规律：`.../attachment/1/<分段>/<id>/<通告id>.xlsx`）

### 4. 查封用途隔离判断（授信关键）
- 平台"司法查封"状态逐套标用途 → 核验 91 套的 `useage`：**全部为"商铺"（商业配套），0 套住宅/安居房**
- 楼栋分布：1栋商业 37 + 2栋商业 54，面积合计 6127.46 ㎡
- 结论：查封风险与 4900 套安居房本体**完全隔离**，不侵蚀保障房房源池

## 四、核心结论（证据闭环）

1. **证伪"安居房=已全部售出"**：截至 059 批次结束实际签约去化仅 112 套（6.8%），绝大多数仍待配售
2. **也证伪"安居房=全未售"**：112 套已有明确购房人（签约中）= 已售出
3. **4900 套去向**：059+064 两批次共拿出约 3217 套推向配售市场（有重叠），仍有相当体量未进入任何公开批次
4. **进度上限**：064 批次认购 2026-09-01 截止，选房结果尚未发布；检索 065+ 批次无公开记录 → 官方渠道当前时点已到天花板（时间未到，非遗漏），须 2026-09 选房后复查

## 五、授信口径

- 安居房既不能当"库存可售"（无市场化变现），也不能默认"已售"
- 91 套商铺司法查封须逐套查册核债权顺位（政务系统本环境不可直调，已生成查册清单 Excel 供用户持权办理）
- 剩余房源 2026-09 选房后复查

### 9.3 第一批次待查→转正（核心实战）
- **难点**：① 搜索引擎只收录"认购资格核查"和 2025/2026 批次，第一批次选房结果公示页未被索引；② gkmlpt 文章页对**不存在的 post 也返回 200 + `<title>出错了</title>`**（软404），HTTP 状态码不可信；③ 页面 JS 动态加载、页内不互链。
- **解法（可复用·gkmlpt 软404 扫描法）**：
  1. post ID 路径段号 = ID 截**前 5 位**（11217682→11217、11298183→11298）；
  2. 真实 post ID 零散非整百，须 **`seq` 步长 1 + `xargs -P 40` 并发**扫描候选区间；
  3. 按日增量（约 1640/天）从已知锚点（选房通告 11212857 → 第二批次 11298183）估算第一批次窗口（→11229xxx~11245xxx），收敛扫描；
  4. **甄别真页靠 `<title>` 是否含项目关键词**（过滤"出错了"软404）；
  5. 命中 `post_11217682`（山樾湾花园项目（第一批次）安居型商品房选房结果公示）。
- **逐套校验**：下载「已选房源」xlsx（两房最新 04/01、三房最新 03/29），筛 `状态="已选定"`：
  - 两房 1540 套全量 → **613**；三房 770 套全量 → **185**；合计 **798 套（A 级）** → "待查"转正。
