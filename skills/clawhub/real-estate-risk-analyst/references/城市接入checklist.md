# 城市接入 checklist（填表式 SOP）

> 目的：把「探测 SOP」从口述经验变成**逐城填表**，避免不同人/不同次接入走样、漏步。
> 用法：每接入一个新城市，依次填完六步，填完即固化 `extract_<city>.py` + 写 `status.txt`。
> 配套：五类成功范式见 SKILL.md「五类成功范式」；反爬类型全表见 `references/类型库.md`；瑞数攻坚见 `references/瑞数专项.md`。

---

## Step 0 · 基本信息

| 字段 | 填写 |
|------|------|
| 城市 | |
| 主管平台 | 住建局 / 房管局 / 发改委 / 政务服务网 |
| 官方域名 | （域名常变，以本次 WebSearch 实测为准） |
| 接入日期 | |
| 操作人 / Agent | |

---

## Step 1 · 入口确认

- [ ] WebSearch 确认官方入口（gov.cn 域名，注意域名可能变更）
- [ ] 是否存在**「公开信息公示页」**（无需登录，含「一房一价 / 详情」链接）？→ 是则**优先走公开页**
- [ ] 是否存在**「查询 SPA」**（需 CAS / 验证码 / 登录）？→ 作为 fallback
- [ ] 同城是否有**其他局委域名**（fgw / zfzl / data 等）可绕开主站反爬拿证级兜底？
- [ ] **入口结论**：`公开页优先` / `SPA fallback` / `仅公告无逐套` / `双系统并存`

---

## Step 2 · 反爬识别（⚠️ 必实测，不沿用旧分类表）

- [ ] 探针实测：请求平台首页 / 列表 API，记录真实响应
- [ ] 是否**瑞数**？检查 `meta id=hmYiCp5tA9K0` 或 412 响应体 ~3KB 纯挑战页
- [ ] WAF 类型（nginx Referer 校验 / 阿里云 `acw_sc__v2` / 顶象无感验证 / IP 信誉 / 其他）
- [ ] **412 响应体大小判级**：~60KB = 首次挑战（页面内容仍在，可解析静态链接）；~3KB = 已升级封锁 → **立即停止试探**，换 IP / 数小时后 / 定性 E
- [ ] 是否「关键词被忽略、必须翻全库本地过滤」型（贵阳筑房网实证）？
- [ ] **分类判定**：
  - [ ] **A** 纯匿名可自动化持续
  - [ ] **B** 待解 IP 封（用户本机住宅 IP 大概率可进白名单）
  - [ ] **C** 待一次性环境（如装 Tesseract 跑 OCR）
  - [ ] **D** 需用户协助（小程序 / 扫码 / 注册登录 / 无制度基础）
  - [ ] **E** 反爬或不可达（瑞数 headless 不可过 / 域名劫持 / 无入口）
- [ ] **证据记录**（curl / Playwright 实测现象，写进 `status.txt`）

---

## Step 3 · API 探针（命中即固化脚本）

- [ ] **列表 API**：URL / 方法 GET·POST / 鉴权（动态 token / cookie）/ 是否支持关键词检索
- [ ] **详情 API**：楼栋 / 单元 / 逐套端点链路
- [ ] ⚠️ **逐套是否按 (楼栋, 单元) 范围返回**？是则必须枚举全部楼栋+单元逐组合取数（防漏抓 84% 房源）
- [ ] **价格可见性**：可售公开 / 已售 `***` 或留空 / 完全无价（经 API 不返回，需小程序 PDF 或依申请公开）
- [ ] **状态码图例**：向官方销控表页或文档核验（如广州 1可售/2已售/3已备案/4已过户/5不可售），**授信口径**明确哪些计「已售/权属已转移」
- [ ] 命中即写 `extract_<city>.py` 骨架（换城市只改配置与字段映射，逻辑零重写）

---

## Step 4 · 字段映射（标准化）

**标准字段**（统一键名，便于跨城合并）：
`城市 / 来源 / 匿名 / 采集时间 / 项目名 / 预售证号 / 楼栋 / 单元 / 楼层 / 房号 / 建筑面积 / 套内 / 分摊 / 备案总价 / 备案单价 / 状态 / 用途 / 抵押 / 查封`

- [ ] 官方字段 → 标准字段**逐列映射表**（中文键名）
- [ ] **状态词表**：遍历输出全部状态，不硬编码 4 种（深圳含首次登记/司法查封/锁定等）
- [ ] 单元枚举：用枚举接口 `gnqmcList` 核对单元数，>1 单元须逐单元全量抓

---

## Step 5 · 脚本固化与落盘

- [ ] `extract_<city>.py` 落 `skill/scripts/` 或项目根目录
- [ ] 数据落 `output_cross/<city>_data/houses.json`（统一结构：`city/source/anonymous/captured_at/house_count/projects[]`）
- [ ] **采集完整性校验**：每证房源面积合计 == 预售证详情 `presellarea`，全对上即证明无漏栋漏单元
- [ ] **来源着色**：官方绿底 `C6EFCE` / 外网黄底 `FFEB9C` / 尽调红旗红底
- [ ] **质量校验**：接 `scripts/validate.py`（`validate_houses` / `validate_permits`）

---

## Step 6 · 收口（写 `status.txt`）

- [ ] **结论**：分类（A–E）+ 可采粒度（逐套 / 证级 / 无）
- [ ] **证据**：探针现象 + 数据量（套数 / 证数）
- [ ] **下一步**：本机一次性动作（装 OCR / 住宅 IP 跑）/ 待解 / 定性 E 不无限对抗
- [ ] **回写**：更新 SKILL.md 城市分类表 A–E 与对应「XX 专区」小节

---
