# 嵌入式驱动模板库（1.0.0）

**移植驱动前先查这里，9 款预验证驱动直接取用。**

DHT11 读出来全是 0、MPU6050 三轴不动、HC-05 发 AT 没反应——这些坑 90% 出在移植和初始化顺序上。本技能把 9 款毕设/创客最常用驱动的可编译源码、移植适配层、接线表、坑清单打包成检索库，还带外设初始化顺序查询，STM32/51/ESP32/Arduino 用户都能用。

## 它解决什么问题

| 你遇到的 | 它给你的 |
|----------|----------|
| 驱动代码网上抄来跑不通 | 9 款预验证驱动：C 逻辑测试 107 项断言全通过、gcc -Wall -Wextra 逐款零警告（2026-10-27 实跑） |
| 换个芯片不会改 | 算法层纯 C99 平台无关，平台差异全部收在 port 适配层（每款 4-6 个接口，改完即用） |
| 不知道接哪些脚 | 每款带接线表：引脚对照、供电要求、典型坑 |
| 配置都对就是读不到数 | 外设初始化顺序查询：占哪些外设、HAL 符号要哪些、顺序硬要求（取自适配层注释原句） |
| 上电就读到全 0 | 坑清单：供电/时序/初始化顺序的实战坑（如 MPU6050 不解除睡眠永远读不到数） |

## 覆盖的 9 款驱动

DHT11 温湿度 / DS18B20 单总线温度 / ESP8266-AT 响应解析 / HC-05 蓝牙 AT / HC-SR04 超声波 / MPU6050 六轴 / SG90 舵机 / SSD1306 OLED / 28BYJ-48 步进电机——温湿度、测距、显示、无线、姿态、电机几大类都齐了。

## 内置能力（AI 自动调用）

- **驱动查询**：列出 9 款驱动及验证记录，或取单款全文（源码+适配层+接线表）
- **接线与避坑**：每款驱动的引脚对照与按翻车率排序的坑清单
- **初始化顺序总览**：按总线类型（I2C/UART/PWM/GPIO）筛选，看每款驱动占哪些外设、有什么硬要求

装好后直接说人话："MPU6050 接 I2C 哪些脚" / "SSD1306 有没有现成驱动" / "这个驱动移到我的芯片要注意什么"。

## 包结构

- `SKILL.md` —— 技能说明书（AI 按需读取，上下文负担小）
- `scripts/` —— 检索引擎（driver_templates.py + engine.py，纯标准库，Python 3.9+）
- `assets/` —— 驱动文件库（`<驱动名>__<文件名>` 平铺，因平台 Skill 包仅支持两级目录）
- `tests/` —— 编译测试台（9 份 stub 假端口 + C 台 + Python 台，可本地复跑验证）
- `README_安装说明.md` —— 本文件（给人看的安装与能力概览）

## 定位边界

模板是**移植参考**，不是即拷即用的完整工程——按你芯片的 HAL/LL 库适配 port 层后使用；验证口径是算法逻辑交叉验证 + C 编译零警告，**未做上板实测**；不生成新驱动代码（用 embedded-code-generator）、不做协议一致性判定（随嵌入式联调专家包提供）。

## 配套技能（如已安装）

| 阶段 | 技能包 |
|------|--------|
| 生成新的通用 C 模块 | embedded-code-generator |
| 传感器数据不对先分坑 | embedded-debug-trees（选型坑 vs 接线坑） |
| 实机调试取证 | mcu-debug-mcp（serial/analyze 系列） |

没装也不影响本技能独立使用。

---
*本技能驱动数据与 mcu-debug-mcp（PyPI: mcu-debug-mcp）同源；引擎与其 core.py 同一判定逻辑。*


## 复核命令（结论可自己重跑）

验证口径不是自述，包内带完整测试台，拿到包就能复跑：

```bash
python tests/test_driver_logic_py.py      # Python 交叉验证台：49 tests OK
python tests/run_c_tests.py               # C 编译+运行台：107 checks 0 failed（需 gcc）
```
