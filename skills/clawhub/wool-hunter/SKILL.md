```bash
cd ~/.workbuddy/skills/薅羊毛助手 && python scripts/xiaxiayouhui.py search '{关键词}'
```

- 用表格展示，突出多平台比价结果 🔥
- 输出首行直接给「最低价」结论（来自 cheapest 字段）
- 按到手价升序排列，同商品多平台标注最低价
- 服务状态：已实测验证可用（2026-10-15 实测：拼多多/苏宁/淘宝返回数据，京东/抖音部分关键词无数据属正常）

```
| 🔥 淘宝 | xxx  | ¥88  | ¥58    | 30元券 | xxx  |
```


每日精选：


**降级规则**：若 `xiaxiayouhui.xyz` 请求失败/超时/返回 `success:false`，自动降级到 ③ Coze 智能体兜底，并在回复中注明「跨平台比价服务未返回数据，以下是通用检索结果」。注意：个别平台（如京东/抖音）返回 `success:false` 属正常，只要有任一平台有数据就正常展示，不必整体降级。

**搜索覆盖的真实规律：CPS 联盟收录制（必读，2026-10-15 三组对照实测）**

虾虾优惠的数据源是各平台 **CPS 推广联盟库**（淘宝客 / 多多进宝 / 唯品会联盟等）。**商品能否被搜到，取决于它有没有开推广计划，与价格高低无关。** 三组对照实测：

| 关键词 | 实测结果 | 归因 |
|--------|---------|------|
| 抽纸 | 拼多多 5 / 苏宁 5 / 淘宝 5，`cheapest` ¥7.01 | 日用品普遍开推广 |
| 小米 17 Ultra | **唯品会 5 条全真机** ¥6999-8499（券后 6199 起）、淘宝 1 条真机 ¥7999（券后 6719） | 小米渠道开放，唯品会官方店有推广计划 |
| 华为 Mate 80 Pro Max | 只返回手机壳/膜/保护套，且京东、淘宝双双 `success:false` | 华为 Mate/Pura/X 系列渠道管控严，第三方联盟基本无收录 |

由此得出执行规则：

1. **不要**因为某次搜不到就判定该 API 不可用——先换关键词、看其他平台
2. **每次必须**逐条扫 `goods_name`，排除「手机壳/膜/保护套/保护壳/钢化膜/数据线/充电器/支架/滤镜」等配件词，再判断有没有本体
3. 多平台交叉看：常见情况是 tb/pdd 只返回配件、但 **vip（唯品会）/sn（苏宁）有真机**，别只盯着一个平台就下结论
4. 确认无本体时（尤其华为 Mate / Pura / X 系列、RS 非凡大师等强管控机型），回复中必须写明「该商品未在第三方推广联盟收录，以下结果仅为配件」，然后转 **WebSearch + 品牌官方页面**核实
5. 高价数码（>¥2000）价格一律强制分两栏呈现：
   - **官方指导价**（品牌商城 / 官网）
   - **渠道实付价**（京东自营 / 拼多多百亿补贴 / 淘宝百亿补贴 / 线下经销商）
   二者价差常达 1000-2500 元，只报一个价会误导用户
6. 主动提示：国补（常见 10%-15%，有地区限制）、以旧换新、618/双11 大促节点、新旧代机型价格倒挂

**重要（交叉验证铁律）**：WebSearch 返回的第三方比价站/参数站数据（中关村在线、爱企查 AI 摘要、京东第三方店参数表）**只能当线索，不能当结论**，已实测查出多类错误：入网型号标错（京东某店把 BRE-AL00a 当 Mate 80 Pro Max，官方实为 SGT-AL10）、标题与参数表自相矛盾（标题 16GB+1TB、参数表写 512GB）、凭空多出参数（ZOL 写「峰值亮度 8000nits」，华为官方页无此项）。**型号与参数必须以品牌官方商品页为准**（如 `vmall.com/product/comdetail`），并注意入网型号通常不区分存储容量和特殊版本（Mate 80 Pro Max 标准版与风驰版共用 SGT-AL10）。
