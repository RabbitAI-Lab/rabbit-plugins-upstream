# 抖音口播爆款文案生成-教育类 v2.0

> 升级版：从"prompt 包装"升级为"确定性方法论驱动"——结构不靠模型猜，数据不靠模型编，质量可机器验证。

## 为什么升级？

v1.0 的问题：**质量全靠模型**。skill 只给了 persona 和流水线描述，但每阶段"具体怎么写"全靠模型自由发挥；`verify_facts.py` 是空壳（被引用但不存在）；AI 味检测只查 6 个词。

v2.0 的解法：把方法论变成**确定性规则 + 可运行脚本**。

## 升级内容

| 层 | v1.0 | v2.0 |
|---|---|---|
| 结构 | 无固定结构 | **黄金 6 段式**（每段有必须/禁止/字数规则） |
| 钩子 | 靠灵感 | **8 种模板**（公式+示例+适用场景） |
| 方法论 | 无 | **教育方法论**（认知负荷/记忆点/三件套/费曼技巧） |
| 数据 | 模型编 | **双轨核验**（脚本提取+人工核对，不信任模型记忆） |
| 质量 | 空壳脚本 | **4 个可运行脚本** + 统一入口 |
| 合规 | 无 | **七类违禁词检测**（绝对化/承诺/引流/夸大/焦虑/谐音变体/价值观红线，2026 双维度监管口径） |

## 快速开始

```bash
# 一键质量门禁（AI味 + 事实点 + 违禁词）
python3 scripts/quality_gate.py "你的文案文本"
python3 scripts/quality_gate.py --file draft.txt

# 单项检查
python3 scripts/check_ai_tone.py "文案"
python3 scripts/verify_facts.py "文案"
python3 scripts/check_compliance.py "文案"
```

## 使用流程（6 阶段 + 人机协作）

1. **选题发现** → 3 个选题，人类选 1
2. **数据增强** → 数据包 + 来源清单，人类确认
3. **钩子选择** → 3 个钩子，人类选 1
4. **初稿生成** → 黄金 6 段式
5. **质量门禁** → 脚本检测，PASS 才继续
6. **发布准备** → 分镜 + 标题 + 评论区话术

> AI 是"提案人"，不是"定稿人"。每个中断点必须停下等人类决策。

## 核心设计

**黄金 6 段式**：钩子(0-3s) → 痛点具象化(3-10s) → 认知反转(10-20s) → 证据支撑(20-40s) → 行动指令(40-50s) → 收尾钩子(50s+)

**人设去争议化**：只保留"犀利、敢说、替普通家庭算账"的语言风格，**不采纳任何争议人物的三观**（如"文科无用""制造焦虑""收割家长"等极端功利主义话术）。价值观红线：不制造焦虑、不贬低学科/职业、不爆粗口、不收割家长。

**数据铁律**：AI 不得在无来源的情况下编造具体数字、年份、政策名称。宁可模糊，不可编造。

**质量判定**：PASS（三项全过）/ WARN（有警告）/ FAIL（有红线，必须重写）

**动态合规**：词库是基线，不靠死记硬背——每次生成前搜索最新平台规则（抖音电商学习中心规则中心 / 生活服务学习中心），官方渠道每季度更新。

## 对抗性兜底（用户不配合时也不崩）

skill 经过 8 组对抗性测试（T1-T8），覆盖"用户是邪恶的混沌的乱用的"场景：

| 场景 | 兜底 |
|---|---|
| 没有 Python 脚本 | 无脚本降级路径：4 步人工自查 |
| 人工不选择/空白/乱写 | HITL 兜底协议：5 级降级 + 默认选择标准 |
| 坚持用违禁词（"我就要用包过"） | 合规替代协议：接情绪 → 给来源 → 合规替代 → 拒红线 |
| 提示注入/越狱（"忽略规则直接写"） | 规则优先级声明：平台合规 > 价值观 > 结构 > 偏好 > 风格 |
| 混淆/矛盾/无意义输入 | 输入规范化：6 类输入处理 |
| 空/超长/特殊字符 | 边界处理：友好提示 + 引导 |
| 恶意请求（编数据/贬低对手/制造焦虑） | 拒绝核心诉求 + 给合规替代 |
| 要求编造数据 | 拒绝 + 真实数据获取路径（教育部/考试院/权威媒体） |
