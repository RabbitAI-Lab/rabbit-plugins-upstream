## Description:

Guides developers in adding, configuring, troubleshooting, and making accessible icons with the Icon and IconText components in @allxsmith/bestax-bulma.

This skill is ready for commercial/non-commercial use.

## Publisher:

[allxsmith](https://clawhub.ai/user/allxsmith)

### License/Terms of Use:

MIT-0

## Use Case:

Developers building apps with @allxsmith/bestax-bulma use this skill to choose and configure an icon library, add icons and icon-text combinations, troubleshoot missing glyphs, and apply accessible labels.

### Deployment Geography for Use:

Global
