## Description:

Guides developers through building, auditing, and upgrading Rotifer Genes.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers use this skill to create and test Rotifer Genes, audit them before publication, and migrate them between fidelity levels.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Publishing a Gene may upload its metadata, README, and compiled artifacts.

Mitigation: Audit the Gene for sensitive content and review publish commands before approving them.

Risk: Suggested CLI commands can create or modify project files and use network access for login or cloud submission.

Mitigation: Review commands and project changes before running them; use the pinned CLI version described in the skill.
