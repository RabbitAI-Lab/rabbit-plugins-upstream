# Get Order Split Attributes

> 官方文档：https://partner.tiktokshop.com/docv2/page/get-order-split-attributes-202309

## LinkFox 转发映射（本 skill）

| 项 | 值 |
|----|----|
| 具名 api | `get_order_split_attributes` |
| 脚本 | `scripts/get_order_split_attributes.py` |
| 网关 | `POST /tiktokShop/developerProxy` |
| appType | **`erp`（固定）** |
| 上游 path | `fulfillment/202309/orders/split_attributes` |
| method | `GET` |
| shop_cipher | 是（Query `shop_cipher`；脚本可在单店时自动解析） |
| 令牌 | 网关按 `openId` + `appType=erp` 从库取 token（`ttsAccessToken` 已废弃忽略；401/过期时自动刷新并重试一次） |

### developerProxy 示例

```json
{
  "appType": "erp",
  "openId": "7010...",
  "path": "fulfillment/202309/orders/split_attributes",
  "method": "GET",
  "queryString": "shop_cipher=GCP_...&order_ids=576461413038785752"
}
```

### 脚本示例

```bash
python scripts/fulfillment_api.py '{"api":"get_order_split_attributes","openId":"...","order_ids":["5764..."],"shop_cipher":"GCP_..."}'
```

## 官方接口原文（TikTok Shop Partner Center）

> Partner Center 页面需登录；以下按官方 Open API 约定与公开 SDK/参考整理。完整字段以 Partner Center 为准。

# Path: /fulfillment/202309/orders/split_attributes
# Method: [GET]
# Function Description
Get order split attributes — whether an order can be split / must be split, and related reasons / split groups. Use before calling Split Orders when you need to fulfill an order in multiple packages.

## Agent 注意事项

1. 先用 **`linkfox-tiktok-shop-order`** 拿到订单号，再查拆单属性。
2. `can_split=false` 时向用户解释 `reason`；`must_split=true` 时说明必须拆单及 `must_split_reasons`。
3. 真正执行拆单走后续 Split Orders（`fulfillment/202309/orders/{order_id}/split`，可后续纳入本 skill）。
