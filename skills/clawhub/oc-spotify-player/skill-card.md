## Description:

Terminal Spotify playback/search via spogo (preferred) or spotify_player.

This skill is ready for commercial/non-commercial use.

## Use Case:

People using an agent can search Spotify, control playback, inspect or select Spotify Connect devices, and manage liked tracks from terminal commands. A Spotify Premium account and either spogo or spotify_player are required.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup can access browser session credentials when importing cookies.

Mitigation: Before importing cookies, consider whether you are comfortable granting that access and use a browser profile whose session credentials you are willing to use for setup.
