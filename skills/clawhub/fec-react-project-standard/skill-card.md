## Description:

Guides developers in designing and reviewing React and TypeScript project structure, component boundaries, hooks, routing, state, and API conventions.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers use this skill to design or review maintainable React and TypeScript applications, including project layout, feature boundaries, state ownership, error handling, and performance conventions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation may apply these conventions where a narrower workflow or existing team standard is more suitable.

Mitigation: Check the task scope and existing project conventions before applying recommendations.

Risk: The guidance prefers Chinese comments, which may conflict with a team's language policy.

Mitigation: Follow the project's established comment language and review generated comments before adoption.
