## Description: <br>
Convert vector GIS data between Shapefile, GeoJSON, KML, GPX, GeoPackage, and CSV formats using Python standard library tooling. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[ruiduobao](https://clawhub.ai/user/ruiduobao) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and GIS practitioners use this skill to guide local vector data conversion, inspect file metadata, transform CRS values, control coordinate precision, filter fields, and clip features by bounding box. <br>

### Deployment Geography for Use: <br>
Global <br>
