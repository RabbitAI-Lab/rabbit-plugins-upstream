# 小白问询话术

一次只问一句。不出现税收居民、TIN、身份证、买入价、金融机构编号。

1. 您想算哪一年的税？可以说 2024、2025，或者说单子上写的哪年。
2. 这一年您主要住在哪儿？大部分时间在国内、国内国外两边跑、基本上住在国外，或者说我也不清楚。
   若选两边跑、住国外或我也不清楚：这一年在中国住满半年了吗？家里是不是还在国内？
3. 钱放在哪几家了？可以说富途那个、华泰那个，也可以不说，直接把单子传上来。
4. 把这一年能找到的月结单、年结单都传上来。能找到多少传多少。这些单子只在这台电脑上处理，不用传到网上。
5. 这一年有没有分过红、收过利息，或者外国已经扣过税？不知道就说不知道。
