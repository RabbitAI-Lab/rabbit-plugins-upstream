# 英语音标标注技能

## 功能简介

本技能能够将英语文本自动标注国际音标(IPA)、轻重音符号以及升降调标记，帮助用户更好地理解和掌握英语发音规则。

## 安装方法

### 方法一：使用安装脚本（推荐）
1. 下载本技能包
2. 运行 `install.bat` 文件
3. 重启 OpenClaw 会话

### 方法二：手动安装
```bash
clawhub install english-phonetic-skill
```

## 使用方法

### 基本用法
直接在 OpenClaw 中输入英语文本，技能会自动标注音标、轻重音和升降调。

### 示例

#### 单词标注
输入：hello
输出：həˈləʊ ↘

#### 句子标注
输入：How are you today?
输出：haʊ ɑː juː təˈdeɪ ↗

#### 段落标注
输入：Good morning, everyone. Today we will learn about phonetics.
输出：ɡʊd ˈmɔːnɪŋ, ˈevriwʌn → təˈdeɪ wiː wɪl lɜːn əˈbaʊt fəˈnetɪks ↘

## 标注规范

### 音标系统
- 使用国际音标(IPA)标准
- 支持英式发音和美式发音
- 支持单词级和句子级标注

### 轻重音标记
- 主重音：ˈ（标在重读音节前）
- 次重音：ˌ（标在次重读音节前）
- 轻读音节：不标记或使用 ə 表示弱化

### 升降调标记
- 升调：↗（表示疑问、未完待续）
- 降调：↘（表示陈述、命令、结束）
- 平调：→（表示列举、过渡）
- 降升调：↘↗（表示犹豫、保留）

## 适用场景

## 注意事项

1. 标注结果仅供参考，实际发音可能因地区、个人习惯而有所差异
2. 建议结合音频材料进行发音练习
3. 对于专业语音学研究，建议使用专业语音分析软件
