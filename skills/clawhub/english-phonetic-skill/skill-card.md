## Description:

英语文本音标标注技能，能够将英语文本标明国际音标(IPA)、轻重音符号、升降调标记以及中文拼音对照读音，适用于英语学习、发音教学和语音分析场景，特别适合中文母语者通过拼音快速掌握英语发音.

This skill is ready for commercial/non-commercial use.

## Use Case:

External learners, English teachers, and language-focused developers use this skill to annotate English words, sentences, or short passages with IPA, stress marks, intonation cues, and Chinese pinyin approximations for pronunciation learning and analysis.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The installation script adds a persistent OpenClaw skill to the local environment.

Mitigation: Install only when the user wants this pronunciation annotation helper, and review the simple install command before running it manually.

Risk: Chinese pinyin approximations can oversimplify English sounds and regional pronunciation differences.

Mitigation: Use the pinyin line as a memory aid alongside IPA notation, audio examples, and teacher or expert review when accuracy matters.
