# 基金申请指南

## 主要基金类型

### 国家自然科学基金 (NSFC)

| 类型 | 资助期限 | 资助强度 | 申请条件 |
|------|---------|---------|---------|
| 面上项目 | 4年 | ~55万 | 高级职称或博士学位 |
| 青年科学基金 | 3年 | ~30万 | 男<35岁, 女<40岁 |
| 重点项目 | 5年 | ~300万 | 高级职称 |
| 重大项目 | 5年 | ~2000万 | 高级职称 |
| 优秀青年科学基金 | 3年 | ~200万 | 男<38岁, 女<40岁 |
| 国家杰出青年科学基金 | 5年 | ~400万 | 45岁以下 |
| 创新研究群体 | 5年 | ~1000万 | 团队 |

## 申请书核心要素

### 立项依据 (40%权重)
1. 研究背景（1页）：领域现状与趋势
2. 科学问题（1页）：核心问题凝练
3. 研究意义（0.5页）：理论/实践价值
4. 文献综述（1-2页）：已有研究、空白、本项目定位

### 研究内容与方案 (40%权重)
1. 研究目标（0.5页）：明确、具体、可考核
2. 研究内容（1-2页）：3-4个内容模块
3. 关键科学问题（0.5页）：2-3个核心难题
4. 研究方案（2-3页）：技术路线+实验设计
5. 可行性分析（1页）：基础/条件/团队

### 创新与成果 (15%权重)
1. 创新点（0.5页）：2-3个，理论/方法/应用
2. 预期成果（0.5页）：论文/专利/人才
3. 年度计划（0.5页）：里程碑

### 研究基础 (5%权重)
1. 前期成果：相关论文/项目
2. 团队组成：PI+成员分工
3. 实验条件：设备/数据/平台

## 常见否决原因

1. 创新性不足（"只是follow别人"）
2. 科学问题不清晰（"想做什么说不清楚"）
3. 可行性存疑（"方案过于宏大，看不出怎么做"）
4. 研究基础薄弱（"这个团队做不出来"）
5. 写作质量问题（格式/逻辑/图表）

## 预算编制

### 直接费用
- 设备费
- 材料费
- 测试化验加工费
- 差旅/会议费
- 国际合作交流费
- 劳务费（研究生/博士后）
- 专家咨询费
- 出版/知识产权费

### 管理费
- 一般为直接费用的5%
