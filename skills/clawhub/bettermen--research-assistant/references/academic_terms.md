# 学术术语词典

## 研究方法术语

| 英文 | 中文 | 说明 |
|------|------|------|
| Randomized Controlled Trial (RCT) | 随机对照试验 | 金标准实验设计 |
| Quasi-experiment | 准实验 | 无随机分配 |
| Cross-sectional study | 横断面研究 | 单时间点观察 |
| Longitudinal study | 纵向研究 | 长时间追踪 |
| Case-control study | 病例对照研究 | 回顾性比较 |
| Cohort study | 队列研究 | 前瞻性追踪 |
| Meta-analysis | 荟萃分析/元分析 | 多研究统计综合 |
| Systematic review | 系统综述 | 标准化文献综合 |
| Grounded theory | 扎根理论 | 定性研究方法 |
| Ethnography | 民族志 | 田野调查方法 |
| Phenomenology | 现象学 | 体验描述方法 |
| Mixed methods | 混合方法 | 定量+定性结合 |
| Ablation study | 消融实验 | 移除组件的对照实验 |
| Benchmark | 基准测试 | 标准数据集评估 |

## 统计术语

| 英文 | 中文 | 说明 |
|------|------|------|
| p-value | p值 | 统计显著性 |
| Effect size | 效应量 | 实际意义大小 |
| Confidence interval (CI) | 置信区间 | 参数估计区间 |
| Type I error (α) | I类错误 | 假阳性 |
| Type II error (β) | II类错误 | 假阴性 |
| Statistical power | 统计功效 | 1-β |
| Null hypothesis (H0) | 零假设 | 无效应假设 |
| Alternative hypothesis (H1) | 备择假设 | 有效应假设 |
| Standard deviation (SD) | 标准差 | 数据离散度 |
| Standard error (SE) | 标准误 | 均值估计精度 |
| Odds ratio (OR) | 比值比 | 关联强度 |
| Hazard ratio (HR) | 风险比 | 生存分析 |
| Cohen's d | 科恩d值 | 标准均值差 |
| R-squared (R²) | 决定系数 | 解释方差比例 |
| Bayesian inference | 贝叶斯推断 | 先验+数据更新 |
