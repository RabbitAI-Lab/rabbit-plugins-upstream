# AI 科研全流程助理 (Research Assistant)

覆盖从 idea 到 publication 的科研全生命周期。输入一句话研究方向或上传论文/数据，12 大模块按需调度，生成交互式 HTML 可视化报告。

## 能做什么

输入研究方向/问题/论文/数据，一站式完成：

| # | 模块 | 典型场景 | 产出 |
|---|------|---------|------|
| 1 | 🔍 文献检索 | "帮我找强化学习在推荐系统中的应用论文" | 文献列表+相关性评分+趋势图 |
| 2 | 📖 文献阅读 | 上传论文PDF/粘贴摘要 | 结构化摘要+方法论拆解+局限性 |
| 3 | 📝 文献综述 | "帮我写气候变化对农业影响的综述" | 综述框架+证据综合+研究空白 |
| 4 | 💡 研究选题 | "我想研究大语言模型安全对齐" | 创新点评估+可行性+研究问题 |
| 5 | 🧪 研究设计 | "设计一个验证XX假设的实验" | 方法论+对照组+统计方案 |
| 6 | 📊 数据分析 | 上传数据/描述变量 | 统计方法+代码(Python/R)+解读 |
| 7 | ✍️ 论文写作 | "帮我写引言/方法/讨论部分" | 分节撰写+学术风格+逻辑连贯 |
| 8 | 🔧 润色校对 | 粘贴论文段落 | 语法/风格/一致性检查+建议 |
| 9 | 📎 引用管理 | "帮我生成APA格式参考文献" | 格式化引用+验证+交叉检查 |
| 10 | 🎯 投稿选刊 | "我的论文关于NLP，推荐期刊" | 期刊匹配+影响因子+投稿建议 |

## 快速开始

### 输入方式

支持四种输入方式，自动识别：

1. **研究方向/问题**: "我想研究量子机器学习在药物发现中的应用" → 自动路由到相关模块
2. **论文PDF/文本**: 上传论文 → 自动触发文献阅读与理解模块
3. **数据文件**: 上传CSV/Excel → 自动触发数据分析模块
4. **模块指令**: "帮我做文献综述" / "帮我润色这段论文" → 直接执行指定模块

### 典型用法

```
科研助手，帮我做以下工作：
1. 搜索近3年"自动驾驶感知融合"相关论文
2. 总结关键方法和进展
3. 识别研究空白和可切入方向
```

## 十二大模块详解

---

### 模块 1：文献检索与发现

**触发**: "帮我找XX方面的论文" / "搜索XX领域文献" / "最近XX有什么新研究"

**工作流**:
1. 理解研究主题，提取核心关键词和同义词
2. 多渠道检索策略：
   - 通过WebSearch搜索 Semantic Scholar、Google Scholar、arXiv 等
   - 构建检索式（布尔逻辑、MeSH术语、PICO框架）
3. 结果筛选与排序：按相关性、引用量、时间、期刊等级
4. 构建文献引用网络：识别种子论文→扩展→绘制知识图谱
5. 趋势分析：发表趋势、热门主题演进、关键作者/机构

**输出**:
- 文献列表表格（标题/作者/年份/期刊/引用量/相关性）
- 研究趋势折线图
- 引用网络关系图
- 关键论文深度解析（Top 3-5）

**检索策略参考**: `references/search_strategies.md`

---

### 模块 2：文献阅读与理解

**触发**: 上传论文PDF / 粘贴论文摘要/正文 / "帮我读这篇论文"

**工作流**:
1. 识别输入类型（PDF原文/摘要/引文信息）
2. 结构化提取：
   - 一句话总结（TL;DR）
   - 研究问题/假设
   - 方法论（实验设计/数据来源/分析手段）
   - 关键发现与数据
   - 创新点与贡献
   - 局限性
   - 未来研究方向
3. 批判性评估：
   - 方法论严谨性（样本量/对照组/偏倚控制）
   - 结论与证据匹配度
   - 可重复性评估
4. 与我已知研究的关联分析（如果用户提供了研究背景）

**输出**:
- 论文结构化解读卡
- 方法论质量评分雷达图
- 与其他论文的对比表（如提供多篇）
- 可引用的关键数据点

**术语支持**: `references/academic_terms.md`

---

### 模块 3：文献综述生成

**触发**: "帮我写XX的文献综述" / "梳理XX领域研究现状" / "做XX的系统综述"

**工作流**:
1. 明确综述范围与研究问题（PICO/SPIDER框架）
2. 文献搜索与筛选（设定纳入/排除标准）
3. 结构化综述框架：
   - 引言：研究背景与意义
   - 方法：文献检索策略
   - 主题归类：按研究方法/理论流派/时间线/研究维度分类
   - 证据综合：共识/争议/矛盾
   - 研究空白：未被充分研究的领域
   - 未来方向
4. 生成综述正文，确保：
   - 逻辑连贯（不是堆砌摘要）
   - 批判性视角（不只有正面结论）
   - 引用标注（可追踪到具体文献）

**输出**:
- 综述框架结构图
- 主题分类鱼骨图/矩阵
- 综述正文（分章节）
- 参考文献列表
- 研究空白与机会热力图

---

### 模块 4：研究选题与创新

**触发**: "帮我想几个研究方向" / "评估这个idea的创新性" / "XX领域有什么可以做"

**工作流**:
1. 领域扫描：当前热点、经典问题、交叉方向
2. 创新机会识别：
   - 方法迁移法：将A领域方法应用于B领域
   - 问题升级法：从简化场景推广到复杂场景
   - 空白填补法：识别文献中明确指出的limitation/future work
   - 技术驱动法：新技术出现带来的新研究机会
3. 选题评估六维度：
   - 创新性：与现有工作的差异度
   - 可行性：数据/算力/时间/技能要求
   - 影响力：潜在引用量与领域关注度
   - 可发表性：目标期刊/会议的接受度
   - 适配性：与研究者的背景匹配度
   - 风险：技术风险、竞争风险

**输出**:
- 创新机会六维雷达图
- 选题对比矩阵（多个idea横向对比）
- 可行性评估仪表盘
- 推荐行动路线

---

### 模块 5：研究设计与方法

**触发**: "帮我设计实验" / "这个研究用什么方法" / "怎么设计对照组"

**工作流**:
1. 研究方法匹配：
   - 基于研究问题类型（探索性/描述性/解释性/预测性）
   - 推荐定量/定性/混合方法
2. 实验设计：
   - 变量定义（自变量/因变量/控制变量/混淆变量）
   - 实验范式选择（组间/组内/混合/准实验）
   - 对照组设计
   - 随机化与盲法
   - 样本量计算（功效分析）
3. 数据收集方案：
   - 数据来源（一手/二手/公开数据集）
   - 测量工具（量表/仪器/爬虫）
   - 数据质量保障（信度/效度）
4. 统计分析计划：
   - 假设检验方法选择
   - 效应量估计
   - 多重比较校正

**输出**:
- 研究设计流程图
- 变量关系图（自变量→因变量）
- 样本量计算与统计功效
- 甘特图时间线

---

### 模块 6：数据采集与分析

**触发**: 上传数据文件 / 描述变量 / "帮我分析这些数据"

**工作流**:
1. 数据理解：
   - 变量类型识别（连续/分类/有序/计数）
   - 数据质量检查（缺失值/异常值/分布）
2. 统计方法推荐：
   - 单变量分析：描述统计、分布检验
   - 双变量分析：t检验/Mann-Whitney、卡方/Fisher、相关性
   - 多变量分析：回归、ANOVA/ANCOVA、因子分析
   - 高级方法：结构方程建模、多层线性模型、生存分析、时间序列
3. 代码生成：
   - Python (pandas/scipy/statsmodels/scikit-learn) 或 R (tidyverse/lme4/ggplot2)
   - 含详细注释和结果解读
4. 可视化：
   - 自动选择合适的图表类型
   - 箱线图/小提琴图/散点图/热力图/森林图

**输出**:
- 数据质量报告
- 统计方法推荐清单（含适用条件）
- 分析代码（可直接运行）
- 结果可视化图表
- 结果解读（用统计学语言）

---

### 模块 7：论文写作辅助

**触发**: "帮我写引言" / "帮我写讨论部分" / "帮我组织论文结构"

**工作流**:
1. 论文结构规划：
   - 基于IMRaD结构（Introduction/Methods/Results/and Discussion）
   - 或目标期刊特定格式
2. 分节撰写：
   - **引言**: 背景→研究空白→研究问题→研究意义→论文结构
   - **方法**: 研究设计→参与者→材料→流程→数据分析
   - **结果**: 描述统计→推断统计→效应量→图表说明
   - **讨论**: 主要发现→与已有研究对比→理论/实践意义→局限性→未来方向
   - **摘要**: 目的→方法→结果→结论（结构化摘要）
3. 写作原则：
   - 逻辑连贯：段落间有过渡，论点有递进
   - 学术风格：客观、精准、简洁，避免口语化
   - 证据驱动：每个论断有引用或数据支撑
   - 批判性：不只是描述，还有分析

**输出**:
- 论文大纲结构图
- 分节写作（用户指定章节）
- 写作质量检查清单
- 常见错误规避提示

---

### 模块 8：润色与校对

**触发**: 粘贴论文段落 / "帮我润色这段" / "检查语法和学术风格"

**工作流**:
1. 语言质量检查：
   - 语法错误（主谓一致/时态/冠词/介词）
   - 拼写错误
   - 冗余表达（精简30%为目标）
   - 模糊用语替换
2. 学术风格优化：
   - 句式多样性：避免全篇简单句
   - 专业术语一致性
   - 被动/主动语态平衡
   - 连接词优化
3. 逻辑一致性：
   - 术语前后统一
   - 数据引用一致
   - 缩写首次定义
4. 输出润色版+修改对照表

**输出**:
- 原文vs润色版并排对比
- 修改点列表（语法/风格/逻辑分类）
- 整体评分（语言质量/学术风格/逻辑一致性）
- 一键替换建议

### 模块 9：引用管理

**触发**: "帮我生成参考文献格式" / "转换引用格式" / "检查引用是否正确"

**工作流**:
1. 输入识别：
   - 粘贴原始引用信息（自动解析作者/标题/期刊/年份/卷/页/DOI）
   - 上传.bib文件
   - DOI列表批量导入
2. 格式转换：支持期刊论文/会议论文/书籍/学位论文/预印本/专利/网页
3. 输出格式：APA 7th / MLA 9th / Chicago / IEEE / Harvard / GB/T 7714 / Vancouver
4. 质量检查：
   - 作者名格式一致性
   - 期刊名缩写标准化
   - DOI/URL有效性
   - 引用完整性（所有必填字段）

**输出**:
- 格式化后的引用列表
- 格式合规检查结果
- 缺失信息标注
- 多种格式同时输出

**格式规范**: `references/citation_styles.md`

### 模块 10：投稿选刊

**触发**: "推荐投稿期刊" / "我的论文适合哪个期刊" / "投稿策略"

**工作流**:
1. 论文画像提取：
   - 研究领域与子领域
   - 方法论类型（实验/理论/综述/案例）
   - 创新程度与影响力预估
   - 论文长度与图表数量
2. 期刊匹配：
   - 按领域匹配（SCI/SSCI/AHCI/EI/CSSCI/北大核心）
   - 按影响因子区间分层（冲刺/匹配/保底）
   - 按审稿周期和接受率
   - 按开放获取政策和版面费
3. 投稿策略：
   - 冲-稳-保三层梯度推荐
   - 格式要求速查
   - 投稿信（Cover Letter）模板生成
   - 审稿意见预判与应对

**输出**:
- 期刊推荐列表（按梯度分层）
- 期刊对比表（IF/审稿周期/接受率/OA）
- 投稿策略建议
- Cover Letter模板

### 模块 11：基金申请

**触发**: "帮我写基金申请书" / "国自然申请书" / "项目申报"

**工作流**:
1. 基金类型识别：
   - 国家自然科学基金（面上/青年/重点）
   - 国家社科基金
   - 省级/校级基金
   - 国际基金（NIH/NSF/ERC）
2. 申请书结构生成：
   - 立项依据：研究背景→科学问题→研究意义
   - 研究内容：目标→内容→关键科学问题
   - 研究方案：技术路线→实验设计→可行性
   - 创新点：理论创新/方法创新/应用创新
   - 预期成果：论文/专利/人才培养
   - 研究基础：前期成果/团队/条件
   - 经费预算：分项预算与说明
3. 评审要点对齐：
   - 创新性权重
   - 可行性权重
   - 研究基础权重

**输出**:
- 申请书框架大纲
- 分模块撰写内容
- 技术路线流程图
- 预算表
- 评审自查清单

**政策参考**: `references/funding_guide.md`

### 模块 12：学术汇报

**触发**: "帮我准备组会PPT" / "答辩PPT" / "学术报告"

**工作流**:
1. 汇报类型识别：
   - 组会汇报（15-20分钟）
   - 学术会议报告（15-30分钟）
   - 学位答辩（30-45分钟）
   - 海报展示
2. 内容组织：
   - 故事线设计（问题驱动/方法驱动/发现驱动）
   - 幻灯片结构：背景(1-2)→问题(1)→方法(2-3)→结果(3-5)→讨论(1-2)→致谢(1)
   - 每页核心信息提炼（核心信息一句话原则）
3. 视觉设计建议：
   - 图表vs文字比例（70:30）
   - 配色方案（学术风格）
   - 字体与字号建议
4. Q&A准备：
   - 预判高频问题（方法论/样本量/推广性/对比）
   - 准备回答要点

**输出**:
- 幻灯片大纲（分页内容规划）
- 讲稿脚本
- 图表布置方案
- 预判Q&A清单
- 排练检查清单

## 多模块联动

科研助理支持多模块串联执行：

```
科研助手，帮我完成以下全流程：
1. 搜索近3年"多模态大模型幻觉检测"论文
2. 对Top5论文做结构化阅读
3. 生成一篇文献综述
4. 识别研究空白，推荐3个可研究选题
```

AI将按序执行各模块，最终生成一份整合的交互式HTML报告。

- 📋 表格结构化信息
- 🔗 文献超链接（DOI/Google Scholar）

- 📥 一键导出（PDF/JSON格式的引用和报告数据）
