# Lawful blackout/outage continuity checklist

## Individual or household
- [ ] Use manufacturer-approved charging/battery equipment safely
- [ ] Preserve battery and save essential lawful offline information
- [ ] Use official provider/employer/school/emergency information channels
- [ ] Record only a minimal, redacted outage timeline
- [ ] Do not install unknown tools, certificates, profiles, or bypass software

## Authorized organization
- [ ] Follow approved UPS/generator and facilities procedures
- [ ] Activate offline help, static status, text-first and queued-work modes
- [ ] Use preapproved alternate-work/connectivity procedures only
- [ ] Send timestamped, factual, privacy-safe status updates
- [ ] Log decisions, approval, impact, and rollback conditions
