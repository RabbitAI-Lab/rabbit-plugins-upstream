# Validation checklist

- [ ] Authorization and scope recorded
- [ ] Minimum necessary evidence collected
- [ ] Sensitive data redacted
- [ ] No bypass, scan, flood, exploit, or covert-networking guidance used
- [ ] Facts separated from hypotheses
- [ ] Confidence and alternatives stated
- [ ] Provider/service escalation is accurate
- [ ] Change approval and rollback exist where applicable
- [ ] Public report is aggregated and privacy-safe
