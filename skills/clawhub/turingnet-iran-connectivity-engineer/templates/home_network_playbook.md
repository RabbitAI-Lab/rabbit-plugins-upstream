# Home network: safe playbook

1. Record time, broad symptom, and modem/router indicator lights; do not share serial numbers.
2. Check whether another owned device has the same issue.
3. Compare Ethernet and Wi-Fi only if available and safe.
4. Verify device date/time and captive-portal status.
5. Check one known-good public service and the affected service.
6. Restart owned equipment only after recording status; avoid factory reset.
7. If widespread on the same provider, send a redacted ISP ticket with timestamps and impact.
