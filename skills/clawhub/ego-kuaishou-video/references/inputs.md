# 调用方提供的输入（通用）

本技能**不绑定**任何产品目录，也**不下载**视频。调用方自己准备本地文件。发布前确认调用方有权发布该文件。

| 字段 | 必填 | 说明 |
|------|------|------|
| `video` | 发布时必填 | 本机视频绝对路径，例如 `/absolute/path/to/video.mp4` |
| `desc` | 发布时必填 | 作品描述。话题写在同一字符串里，例如 `描述 #话题1 #话题2` |
| `spaceId` | 否 | 登录 handOff 或中断后续跑时传入。不要为了重试新开一个 space |
| `keep` | 否 | `1` 保留浏览器页。默认关闭：`finish({ keep: [] })` |
| `comment` | 评论时必填 | 后台评论正文。只走创作者评论管理 |
| `titleHint` | 否 | 标题片段。对不上当前选中的作品就退出，避免评论发错视频 |

系列栏目（播客、课程等）应在**自己的发布清单**里给出上表字段，不要把产品路径写进本技能。

评论要原创、自然，符合平台规范。不要批量刷评。
