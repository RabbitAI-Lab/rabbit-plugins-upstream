## Description:

Collects marked shortcut and ponytail comments into a one-shot debt ledger so deferred work stays visible.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dietrichgebert](https://clawhub.ai/user/dietrichgebert)

### License/Terms of Use:

MIT-0

## Use Case:

Developers scan repository comments for deliberate shortcuts and review a file-grouped debt ledger with limits, upgrade triggers, and missing-trigger flags.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The report displays matching repository comments, which may contain information not intended for sharing.

Mitigation: Review the ledger before sharing it and request a persistent file only when needed.
