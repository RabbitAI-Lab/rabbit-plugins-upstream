## Description:

Generate a daily AI news newsletter for a Chinese audience from fresh web sources and return the newsletter body and article summaries in Simplified Chinese.

This skill is ready for commercial/non-commercial use.

## Publisher:

[j3ffyang](https://clawhub.ai/user/j3ffyang)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, AI practitioners, and newsletter operators use this skill to gather fresh AI news, filter and verify candidate articles, and produce a daily Simplified Chinese newsletter with structured article metadata.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill requires Brave and Firecrawl API keys and makes network requests to search and fetch news pages.

Mitigation: Install only if those API keys and network requests are acceptable, and review API usage limits and costs before running it.
