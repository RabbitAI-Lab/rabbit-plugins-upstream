# Code Of Conduct

## Our Standard

Contributors must communicate professionally, review ideas on technical merit,
respect privacy, and avoid harassment, discrimination, threats, or publication
of another person's private information.

Examples of expected behavior include:

- Giving specific, actionable, and respectful feedback
- Declaring conflicts of interest
- Protecting customer and contributor data
- Accepting maintainers' decisions about project scope

## Enforcement

Report conduct concerns privately to the repository maintainers. Maintainers
may edit or remove contributions, comments, issues, or other participation that
violates this standard, and may temporarily or permanently restrict access.

This code applies in repository spaces and when representing the project in
public spaces.
