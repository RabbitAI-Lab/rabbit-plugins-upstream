> 目的：证明「第 0 关 接料辨体 + 九转提炼」在真实链接上可跑通，产出真实方法卡（非占位）。

## 输入（真实）
- 用户甩链接：`https://jamesclear.com/atomic-habits-summary`
- 意图：「把这本《Atomic Habits》炼成方法卡」

## 第 0 关 接料辨体（路由判定）
- 域名 `jamesclear.com`，`http(s)` 且非视频平台 → 命中**网页适配器**。
- 调用：`WebFetch url prompt="提取四定律框架与系统vs目标原文"`，返回正文（含真实四定律、习惯环、系统优于目标、身份习惯等）。
- 结果：得到纯文本原料，进入九转。

## 九转执行（真实步骤）
1. **收料定标**：原料=习惯养成方法论书摘；目标=可复用「行为改变方法卡」。
2. **辨体选型**：网页/文章 → 论点透镜（核心论点+支撑+局限）。
3. **粗炼取料**：原样摘「四定律（obvious/attractive/easy/satisfying）+ 逆向（invisible/unattractive/difficult/unsatisfying）」「习惯环 cue→craving→response→reward」「系统优于目标」「身份投票」。
4. **淬炼抽象**：把"Clear 怎么讲习惯"抽象为可迁移模式——「改行为=改线索/阻力/反馈四环」「成果由系统定不由目标定」。
5. **成丹定型**：落成 2 张标准卡（见下）。
6. **对勘校验**：与常识/已有知识无冲突；四定律为广验证框架 → 标【板上钉钉】/【八成·需看原始材料】。
7. **归库集成**：写入 `~/.workbuddy/methodology-library/habits.md`（按主题"习惯与行为改变"分文件）。
8. **回炼闭环**：记方法层信号（L3·helpful）。
9. **交付**：结构化方法卡集（habits.md）。

## 产出真卡（节选，完整见 methodology-library/habits.md）
- 卡 1「行为改变四定律（建立好习惯）」：显化/吸引/简化/满足 四步 + 习惯环前提 + 两分钟法则坑 + 来源 jamesclear.com/atomic-habits-summary。
- 卡 2「系统优于目标」：目标→流程改写 + 身份投票法 + 硬 deadline 边界反例 + 来源《Atomic Habits》p.27。
