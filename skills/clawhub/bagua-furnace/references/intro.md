# 八卦炉 是什么

八卦炉是一个「知识炼金」技能——专门把书、课程、笔记、视频、录音稿、群聊，以及你甩来的网页/PDF/短视频链接，自动辨类型、转成纯文本，再提炼成可复用的「方法论卡」，反哺扫地僧等谋士层技能，让它从只会学术变得更通用。

它先「接料辨体」：网页用 WebFetch 抽正文、PDF 用 Read 读全文、抖音等短视频用 douyin_copy_extract 取口播文案、音视频用字幕优先+Whisper 兜底转写、图片用 OCR。然后走九转流水线把原料炼成标准方法卡（名称/适用/操作/前提/坑/迁移/边界/来源），落进本地方法论库，扫地僧随时可调用。

适合谁：手头有大量知识素材、想把它们固化成可迁移方法的人；或觉得扫地僧"太学术"想给它补通用料源的人。

怎么用：说「把这本书炼成方法卡」或「提炼这段视频的方法论」，八卦炉会先判类型、再开炼，交付一套带溯源的方法卡。
