# 提炼透镜（辨体选型 · 第 2 关）

不同原料用不同「透镜」看，提炼效率差十倍。下面是各类型的标准透镜与抽取重点。

## 书 → 章节论点透镜
- 按章找结构：**主张 → 论据 → 反例 → 心法**。
- 抽「作者反复强调的是哪条底层模式」，而非逐章摘要。
- 重点字段：适用情境、前提假设、常见坑（书里常藏在反面案例）。

## 课程 → 模块透镜
- 按模块找：**步骤 / 框架 / 检查清单**。
- 课程多为"怎么做"，抽可操作的 SOP 与决策树。
- 重点字段：核心操作、迁移场景。

## 群聊 → 决策洞见透镜
- 先**过滤闲聊 / 表情 / 客套**，只留：某人怎么决策、踩了什么坑、达成了什么共识。
- 抽「群体智慧里的可迁移判断」，标注谁说的（溯源）。
- 重点字段：常见坑、边界反例（群聊场景易过度拟合）。

## 视频 / 录音稿 → 叙事透镜
- 按时间线抽：**问题 → 做法 → 结果 → 心法**。
- 口播类先走 `douyin_copy_extract` / ASR 转写，再提炼。
- 重点字段：来源溯源（必须带链接+时间戳，方便回看）。

## 笔记 → 私人知识透镜
- 用户自己的反思/连接：抽「我学到的 / 我质疑的 / 我想试的」。
- 价值在"连接"——把新笔记和已有方法库里的卡做关联。
- 重点字段：迁移场景（用户自己跨项目怎么用）。

## 网页 / 文章 → 论点透镜
- 抽：**核心论点 + 支撑证据 + 局限**。
- 用 WebFetch 取正文后，先判"这是观点文还是实证文"，实证文置信度可标高。
- 重点字段：置信度、边界反例。

## 通用萃取口诀（九转共用）
- **粗炼取料**：原样摘，别忙着总结（保留溯源锚点）。
- **淬炼抽象**：问"去掉这个具体场景，它还成立吗？"——成立的就是可迁移模式。
- **对勘校验**：和已有卡/常识撞一下，冲突就标低置信度。
