# 合规清单（抖音 / 快手 漫剧）

逐条过。任何一条打勾失败，改分镜，不要改说法糊弄。

## 硬红线（出现即重做）

1. 血腥：伤口、血浆、断肢、尸体特写。悬疑不需要这些，需要的是"看不见"。
2. 跳吓：突然贴近镜头的鬼脸、突然爆音、画面骤亮骤暗。
3. 恐怖形象：腐烂皮肤、扭曲五官、红眼、长舌、爬行姿态。
4. 迷信定性：出现"鬼""索命""诅咒""招魂""阴间"等词，或把超自然说成真实存在。
5. 真实品牌：便利店、饮料、手机、监控设备的可识别 logo 与包装文字。
6. 危险模仿：把充电线、刀具、阳台、电梯井当作可操作道具演示。
7. 未成年人受害或施害的具体情节。
8. 宣称"根据真实事件改编""真实录像"，除非有可核验来源。

## 软风险（改写即可）

| 风险点 | 改法 |
| --- | --- |
| 恐怖氛围过重 | 用空旷、静音、缺失（无影子/无倒影/监控无人）替代怪物 |
| 出现"鬼"字 | 改成"它""那个人""不该出现的东西" |
| 结尾解释超自然 | 删掉解释，切黑留白 |
| 监控画面出现鬼影 | 改成空画面 + 商品轻晃，更高级也更安全 |
| 封面惊悚标题 | 用疑问句："他为什么没有影子？" |
| BGM 压得太满 | 峰值抽掉音乐，只留环境音 |
| 画面出现可读文字 | 招牌改虚构，价签虚化 |

## 平台细节

- 抖音：竖屏 1080×1920，前 3 秒必须给钩子；发布时勾选"内容由 AI 生成"；标题不做绝对化断言。
- 快手：同类要求，另外对"灵异"标签更敏感，标签用"悬疑短剧""原创漫剧"，别用"灵异"。
- 通用：片尾或简介加一行"剧情演绎，纯属虚构"。
- AI 生成画面若涉及近似真人面孔，做明显风格化，避免肖像权争议。

## 发布前 60 秒检查

1. 有没有一帧出现血或伤口。
2. 有没有突然的高分贝音效。
3. 有没有真实 logo 或可读品牌名。
4. 有没有"鬼""真实事件"这类词。
5. AI 标识有没有勾选。
6. 封面和标题是不是疑问句而非断言。
