# 绘图提示词配方

## 通用结构

中文（即梦）：主体与外观 → 动作神态 → 环境时间天气 → 光线与色彩 → 镜头景别焦段 → 材质与风格 → 画幅

英文（MJ）：subject and wardrobe → action → setting and weather → lighting and palette → shot size and lens → film / render look → parameters

一条提示词只解决一个画面问题。想同时表达"她很害怕且外面在下雨且货架很乱"，模型会全部做差。

## 外观锚点

第一部片子先定死一套锚点，之后每镜原样复制，不要换说法。

示例（本 Skill 样例角色）：24 岁亚洲女性、低马尾、耳边碎发、深蓝工作马甲、白衬衫、胸前工牌、无浓妆。

复制时保持完全相同的中文表述；换成"年轻女孩""二十多岁的女生"就会换脸。

## 即梦用法

1. 模型选图片生成，比例 9:16，清晰度 2K，一次出 4 张。
2. 有角色参考时上传正面半身图，参考强度 0.6–0.75；强度过高会锁死姿势，场景会跟着变。
3. 负面词填在"不希望呈现的内容"里，不要写进正文。
4. 同一镜头先跑构图，再跑细节；构图不对不要靠加词救，直接改景别描述。
5. 图生视频单段 5 秒，运动幅度提示词控制在"轻微""缓慢"级别，竖屏大幅运镜必糊。

## Midjourney 用法

基础参数：`--ar 9:16 --style raw --v 6.1 --s 150`

- 写实 CG：加 `cinematic still, photoreal CG, volumetric light, 35mm`，不要加 `8k, hyperreal` 堆料。
- 角色一致性：`--cref <图片URL> --cw 100`；换服装时降到 `--cw 60`。
- 负面：`--no text, watermark, logo, extra fingers, deformed hands, cartoon, low resolution`
- 需要干净构图时用 `--no crowd, clutter`，比在正文里写"空无一人"更稳。

## 负面词基线

每镜都要带这七项：文字、水印、logo、畸形手、多余手指、卡通、低清。

按题材追加：

- 悬疑夜景：过曝、噪点、塑料皮肤、游客照、正面打光
- 室内便利店：真实品牌包装、可读价签、货架杂乱、广角畸变过度
- 人物特写：浓妆、网红脸、磨皮过度、假睫毛、长指甲
- 结尾反转：鬼脸、血浆、扭曲五官、红眼、腐烂皮肤（不是怕吓人，是怕限流）

## 常见失败与修法

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 地上还是出现影子 | 否定词写进正文反而被强化 | 正文只写"地面只有湿鞋印"，影子交给负面词 |
| 角色每镜不同脸 | 锚点换词、无参考图 | 固定锚点原文复制 + cref |
| 画面像游戏截图 | 堆了 unreal engine、octane | 换成 film still、35mm、natural falloff |
| 竖屏构图空 | 只写了中景 | 明确"竖构图，人物占画面下三分之二" |
| 视频一动就崩 | 运动词太猛 | 改"slow push in""subtle handheld"，幅度≤10% |

## 出片链路

分镜表 → 即梦出图（每镜 4–6 张选 1）→ 即梦/可灵图生视频 5s → 剪辑拼 52s → 配音与音效 → 字幕 → 封面（用第 3 或第 6 镜，钩子最强）。
