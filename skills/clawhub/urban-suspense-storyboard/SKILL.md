# 都市悬疑漫剧分镜生成器

面向漫剧博主与 AIGC 创作者的竖屏生产工具：把一句梗概变成可直接开工的镜头级生产资料。

## 适用场景

用户给出剧情梗概（可附带镜头数、风格、平台），需要一套能直接出图、出视频、能剪的分镜方案。典型请求："帮我把这个悬疑故事拆成 8 个镜头""出一版漫剧制作计划""每个镜头给我即梦和 MJ 的 prompt"。

不适用：长篇剧本创作、真人拍摄脚本、血腥恐怖片分级内容。

## 输入参数

| 参数 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| 剧情梗概 | 是 | 无 | 一句话到一段话均可，超出 12 镜先做取舍建议 |
| 镜头数量 | 否 | 8 | 6–12；超出范围按 8 处理并说明 |
| 画面风格 | 否 | 写实CG电影光影 | 可替换为赛博霓虹、胶片颗粒、国漫厚涂 |
| 平台 | 否 | 抖音+快手 | 决定画幅、时长、字幕安全区 |
| 单镜时长 | 否 | 5–7 秒 | 图生视频模型单段上限内取值 |
| 角色设定 | 否 | 自动生成 | 用户给了就锁定，不擅自改 |
| 禁忌项 | 否 | 无 | 如"不要出现血""不要小孩" |

缺参数时只追问最关键的一项，其余按默认执行，并在输出开头一行标注实际使用的参数。

## 执行流程

1. 把梗概拆成五段：安全感建立 → 异样介入 → 首次验证 → 升级 → 反转钩子，分配每段秒数。完成标准：五段时间相加等于总时长。
2. 给每一镜标紧张值 0–10，至少三个峰值，峰值必须落在验证镜与反转镜。完成标准：每镜都有数值，曲线不单调。
3. 排镜头表，字段固定，一镜只放一个信息点、一种运动。完成标准：相邻两镜景别不重复，无"万能中景"堆叠。
4. 写提示词：每镜一条中文即梦版、一条英文 Midjourney 版、一条负面词。完成标准：角色年龄、发型、服装在 8 条里逐字一致。
5. 过合规清单（references/compliance-checklist.md）。完成标准：无血浆、无跳吓、无真实品牌、无迷信定性、无未成年人危险模仿。
6. 按固定三段式输出，不写开场寒暄，不加结尾总结。

## 输出格式（固定顺序）

【项目制作计划】：时长与节奏分段、情绪节点、字幕台词规范、运镜方案、合规避坑、出图出片排期。
【分镜表格】：Markdown 表格，字段为 镜号｜时长｜景别·机位｜运镜｜画面内容｜字幕/台词｜声音设计｜转场。
【逐镜头绘图Prompt（含负面词）】：每镜三行——即梦中文提示词、MJ 英文提示词（含参数）、负面词。

## 硬性规则

1. 画幅 9:16，输出 1080×1920，30fps；生成阶段可用 24fps 求电影感，成片统一 30fps。
2. 字幕每行不超过 14 字，最多两行，底部安全区留 15%，右侧留 20% 避开平台按钮。
3. 悬疑靠"缺失"制造：没有影子、没有倒影、监控里没人、回声不对。禁止用鬼脸、血浆、突然爆音。
4. 每一镜的负面词必须包含：文字、水印、logo、畸形手、多余手指、卡通、低清。
5. 角色一致性：即梦用角色参考/智能参考锁脸，MJ 用 --cref 加 --cw 100；提示词里复述同一套外观锚点。
6. 结尾只留钩子，不做解释性旁白，不出现"鬼""索命""诅咒"等定性词。
7. 真实品牌一律替换为虚构招牌（如 24H MART），包装文字做虚化处理。

## 交付前自检

- 时长合计与镜头数、单镜时长区间一致。
- 每镜都有中文提示词、英文提示词、负面词三件套。
- 角色外观描述跨镜一致，没有中途换脸换衣。
- 合规清单逐条通过。
- 最后一镜留了钩子，且没有解释性收尾。
