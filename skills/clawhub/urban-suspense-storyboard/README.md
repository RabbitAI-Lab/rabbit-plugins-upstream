# 都市悬疑漫剧分镜生成器

把一个梗概，变成能直接出图、出视频、能剪的 8 镜漫剧方案。

## 解决什么问题

做竖屏漫剧最耗时间的不是写故事，是"故事到镜头"的翻译：哪一镜给什么景别、情绪在哪里顶上去、每张图该写什么提示词、哪里会踩平台红线。这个 Skill 把这段工作标准化成一份可直接执行的制作文件。

## 输出什么

固定三段，不废话：

1. 【项目制作计划】时长与节奏分段、情绪节点、字幕台词规范、运镜方案、合规避坑、出图排期。
2. 【分镜表格】镜号、时长、景别机位、运镜、画面内容、字幕台词、声音设计、转场。
3. 【逐镜头绘图Prompt】每镜一条中文即梦提示词、一条英文 Midjourney 提示词、一条负面词。

## 输入什么

一句话就够："深夜便利店，夜班收银员发现进店客人没有影子，8 个镜头，写实 CG。"

可选参数：镜头数量 6–12、画面风格、平台、单镜时长、角色设定、禁忌项。没给就按默认跑。

## 适合谁

- 做抖音/快手竖屏漫剧的博主，需要日更产能。
- 用即梦、Midjourney、可灵做 AI 短片的创作者。
- 接商单的剪辑/策划，需要快速出可报价的方案。

## 不适合谁

长篇连载剧本、真人实拍脚本、需要血腥恐怖分级的内容。这个 Skill 的悬疑靠"缺失"而不是怪物，天生适配平台审核。

## 设计取向

1. 悬疑感来自"少了什么"：没有影子、没有倒影、监控里没人。比鬼脸高级，也比鬼脸安全。
2. 每镜只承担一个信息点、一种运动，剪辑时不会互相打架。
3. 角色外观锚点逐镜复述，配合即梦角色参考或 MJ 的 --cref，减少换脸。
4. 合规清单前置，写完就过一遍，避免成片被限流才回头改。

1. 不是给灵感，是给生产资料：每镜有时长、景别、运镜、字幕、音效、转场，照着排就能剪。

4. 合规前置：抖音/快手红线逐条对照，真实品牌自动替换，AI 标识与免责声明提醒到位。
5. 产能可复制：8 镜约 52 秒，一人两天出一条；换题材只需换梗概，流程不变。
