## Description: <br>
Use Makaron CLI to help agents generate and edit images, videos, music, and motion designs through Makaron projects. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External users and agents use this skill to run Makaron CLI workflows for creative media production, including project setup, prompt submission, media uploads, polling, and retrieving generated assets. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Prompts and selected media files may be sent to Makaron for processing. <br>
Mitigation: Install and use only when the user is comfortable sending the selected content to Makaron; avoid private, regulated, or third-party confidential media unless Makaron privacy and retention terms have been reviewed. <br>
Risk: The skill has broad creative-media activation and can upload images, videos, or audio as part of normal workflows. <br>
Mitigation: Confirm the user's intent and review selected files before running Makaron CLI commands that upload media. <br>
