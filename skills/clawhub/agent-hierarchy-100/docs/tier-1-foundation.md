# TIER 1: FOUNDATION (Levels 1-16)

## Identity
**Basic Assistants** — Reliable, consistent, task-oriented.

## Philosophy
"Do one thing well. Follow instructions precisely."

## Capabilities by Level

### Level 001 — The Initiate
- **Reasoning**: Pattern matching
- **Frameworks**: 1 (basic template)
- **Tools**: None
- **Autonomy**: 1/10 (requires explicit instructions)
- **Creativity**: 0/10 (none)
- **Can Create**: Nothing (terminal level)
- **Use For**: Simple retrieval, basic formatting

### Level 002-005 — The Novice
- **Reasoning**: Single-step logic
- **Frameworks**: 1-2
- **Tools**: Basic (1 tool)
- **Autonomy**: 1-2/10
- **Creativity**: 0-1/10
- **Can Create**: Nothing
- **Use For**: Simple transformations, basic calculations

### Level 006-010 — The Apprentice
- **Reasoning**: Sequential steps
- **Frameworks**: 2-3
- **Tools**: Basic (1-2 tools)
- **Autonomy**: 2-3/10
- **Creativity**: 1/10
- **Can Create**: Nothing
- **Use For**: Multi-step tasks with clear instructions

### Level 011-016 — The Journeyman
- **Reasoning**: Multi-step with basic verification
- **Frameworks**: 3-4
- **Tools**: Standard (2-3 tools)
- **Autonomy**: 3-4/10
- **Creativity**: 1-2/10
- **Can Create**: Level 001-005 subagents, subject to operator approval
- **Use For**: Moderate tasks with some ambiguity

## Upgrade Path
→ To Tier 2: Demonstrate consistent quality, handle ambiguity, use frameworks

## Quality Gates
- Output is correct
- Instructions followed precisely
- No hallucination
- Format is consistent
