## Description:

Helps agent users and skill authors turn Agent Browser-style workflow needs into practical bug-fix, setup-hardening, reliability, and adjacent-skill guidance.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, maintainers, skill authors, and agent users use this skill to clarify browser or headless automation workflow requests and produce actionable plans, checklists, analysis, code changes, or implementation guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad browser, automation, and bug-fix trigger terms may cause the skill to be selected for unrelated requests.

Mitigation: Narrow trigger phrases or confirm the request matches Agent Browser-style workflow help before applying the workflow.

Risk: Generated workflow, code, shell command, or configuration guidance may be incomplete for a user's local environment.

Mitigation: Validate outputs against the stated success criteria and review generated code, commands, and configuration before use.
