## Description:

Guides agents and skill authors through planning, creating, and validating reliable browser-related productivity workflows and supporting artifacts.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

AI-agent users, skill authors, and maintainers use this skill to turn browser workflow needs into practical plans, checklists, code, or other artifacts. It makes assumptions and validation criteria explicit so the resulting workflow can be reviewed and improved.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger terms may activate the skill for requests unrelated to browser workflow work.

Mitigation: Invoke it explicitly when the request is ambiguous, and check that the proposed workflow matches the user's actual goal.
