## Description:

Helps users adapt Agent Browser style workflows by clarifying needs, planning fixes or adjacent solutions, producing practical deliverables, and checking results against the original need.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

AI-agent users, skill authors, and maintainers use this skill to turn browser workflow requests into practical plans, checklists, analyses, or implementation support, then review the deliverable against the stated need.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation terms may cause the skill to be invoked for unrelated requests.

Mitigation: Check that the request concerns browser workflows, automation, or a related fix before applying the workflow.
