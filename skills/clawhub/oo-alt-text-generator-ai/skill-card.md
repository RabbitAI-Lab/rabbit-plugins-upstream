## Description:

Alt Text Generator AI generates concise, accessibility-friendly alt text for publicly reachable image URLs through an OOMOL-connected account.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to generate accessibility-focused alt text for image URLs while relying on OOMOL to manage the connected Alt Text Generator AI credentials.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: First-time setup includes one-line remote installer commands for the oo CLI.

Mitigation: Prefer a verified, pinned, or inspectable installation method before running the CLI.

Risk: The skill depends on OOMOL-managed account access for Alt Text Generator AI.

Mitigation: Install only if OOMOL is an acceptable provider and connect only the account scopes intended for this use.
