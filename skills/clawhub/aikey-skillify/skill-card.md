## Description:

Turns a completed, verified workflow into a reusable local agent skill with explicit gates, observable rules, and usage checks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[iamzifei](https://clawhub.ai/user/iamzifei)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill after completing a repeatable task to capture the proven steps, checks, and stopping conditions in a reusable local skill. It is intended for workflows with a verified result, rather than untested ideas.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow depends on companion configuration, shared rules, and a listing script that are not included in this package and remain unverified.

Mitigation: Confirm those companion files are present and review them before using the workflow.

Risk: Saved skill files, evaluation records, or workflow memory may contain private details.

Mitigation: Review generated and saved material for sensitive information before sharing it.
