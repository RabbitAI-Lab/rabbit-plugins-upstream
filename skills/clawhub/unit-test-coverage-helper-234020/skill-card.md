## Description: <br>
Helps developers and QA teams add useful unit tests, identify coverage gaps, and create repeatable regression-test workflows for existing codebases. <br>

This skill is ready for commercial/non-commercial use. <br>

[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

## Use Case: <br>
Developers, software maintainers, QA engineers, open-source contributors, and product teams use this skill to plan and produce practical unit-test coverage improvements for existing projects. It guides requirement restatement, constraint checks, implementation planning, and validation notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill has broad testing and quality triggers, so it may activate for general testing requests that are not specifically about unit-test coverage. <br>
Mitigation: Use it when the user explicitly needs help adding unit tests, finding coverage gaps, or creating regression-test workflows. <br>
Risk: Generated test guidance or code may not fully match the target project's behavior or quality bar. <br>
Mitigation: Review proposed tests before committing them and run the project's test and coverage commands to verify behavior. <br>
