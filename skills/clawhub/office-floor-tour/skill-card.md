## Description:

Turns each seller-supplied, labeled office-floor still into a short floor-tour video clip.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

External users and office-listing teams use the skill to prepare one labeled tour clip for each seller-provided office-floor still, without adding unrequested floors or imagery.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The shared authorization includes unrelated voice-management access, and installation details are reported automatically.

Mitigation: Prefer task-specific authorization if available, review the installation-reporting disclosure, and revoke access in the Beatra Console when it is no longer needed.
