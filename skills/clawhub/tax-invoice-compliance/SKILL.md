## 能为你做什么（数电票合规四大场景）
---

### 一、受票方防范与供应商筛查
- 🛡️ **准入筛查**：核查对方经营范围、注册地址真实性、开票额度异常，防范取得虚开发票
- 📋 **四流校验**：合同、票据、资金、货物流向一致，留存物流单据
- ⚠️ **高频风险**：取得涉嫌虚开发票导致进项转出与补税

**典型问法：**
```
"怎么防范取得虚开发票？"
"收到异常凭证怎么办？"
```

### 二、空壳虚开特征识别
- 🚨 **典型特征**：同地址/IP批量注册、无实际经营场所、短期暴力开票、进项不匹配、开票后走逃失联、资金回流
- 🔍 **以数治税**：大数据比对进销项、货物流、资金流、IP、注册地址精准识别
- 🛡️ **自身合规**：规范注册与开票，远离空壳虚开模式

**典型问法：**
```
"空壳虚开有哪些特征？"
"数电票合规要注意什么？"
```

### 三、四流一致与资金回流
- 🔗 **闭环印证**：合同流、票据流、资金流、货物流须一致，杜绝资金经个人账户回流
- 📑 **证据留存**：物流单据、资金凭证、业务真实性证据链
- ⚠️ **高风险**：四流不一致、资金回流直接指向虚开嫌疑

**典型问法：**
```
"四流一致怎么理解？"
"资金回流有什么风险？"
```

### 四、异常凭证与善意取得抗辩
- 📨 **异常应对**：收到异常扣税凭证通知及时进项转出，配合核查
- ⚖️ **善意抗辩**：证明不知情、真实交易、合理对价，争取不罚仅补税
- 🔄 **内控闭环**：建立数电票全生命周期管理（开具、接收、查验、抵扣、归档）

**典型问法：**
```
"善意取得虚开怎么抗辩？"
"异常凭证进项转出后还能抵扣吗？"
```

---

### 五、反向开票经营所得个税预缴率（国家税务总局公告2026年发布的第12号公告）
- 🧾 **三流合一优惠档**：自然人出售者通过"三流合一反向开票"销售报废产品，年销售额（不含增值税）≤60万元部分减按0.25%预缴，>60万元部分仍按0.5%
- 📑 **传统反向开票**：其他方式的反向开票仍按0.5%预缴
- ⚠️ **风险**：跨企业年销售额未累计、误用0.25%档导致预缴不足

**典型问法：**
```
"反向开票个税预缴率怎么算？"
"三流合一反向开票0.25%怎么适用？"
```

### 成品油零售“交易即开票”与加油机作弊防范
- ⛽ **交易即开票**：成品油零售领域全面推广“交易即开票”，消费者付款即获数电票；受票方须加强油费发票真实性查验，防范加油机作弊虚开发票
- 🔍 **四流一致**：油费报销须合同/订单、资金、物流（加油记录）、发票一致，异常加油点发票重点核查
- ⚠️ **风险**：接受作弊加油机虚开油票、变名发票（如油料变配件）抵扣，面临进项转出与处罚

**典型问法：**
"成品油交易即开票怎么防范虚开？"
"加油费发票合规要注意什么？"

## 重要提示与边界声明

**重要提示**
1. **受票须筛查**：加强供应商准入，四流一致，防范取得虚开发票。
2. **自身不触红线**：规范注册与开票，远离空壳虚开模式。
3. **异常须及时**：收到异常凭证及时转出并配合核查，争取善意取得抗辩。
4. **以官方为准**：发票监管规则时效性强，具体以税务机关最新口径为准。

**边界（本技能不做的）**
- **不代办**：发票开具、勾选认证等需登录系统的事项
- **不代理**：税务稽查应对代理等需执业资质的事务
- **不担保**：虚开定性、稽查结论等最终以税务机关或司法机关认定为准

- 每次提问都能获得完整闭环：智能问答 → 结构化结果 → 政策依据溯源 → 真实案例关联 → 实操辅导 → 反馈评价 → 合规报告
