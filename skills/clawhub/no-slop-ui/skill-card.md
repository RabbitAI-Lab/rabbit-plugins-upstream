## Description:

Build or review frontend UI for clean, restrained, human-designed interfaces without generic AI visual patterns.

This skill is ready for commercial/non-commercial use.

## Publisher:

[leostehlik](https://clawhub.ai/user/leostehlik)

### License/Terms of Use:

## Use Case:

Developers and coding agents use this skill when building or reviewing a visible frontend interface. It provides visual guardrails and a checklist for checking generated UI against the product workflow and the project's existing design system.

### Deployment Geography for Use:

Global
