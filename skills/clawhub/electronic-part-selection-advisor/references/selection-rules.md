# 选型与替代料硬规则

> 这份文件是**行业规则层**，已由使用者（元器件分销/硬件团队）填入真实做法。
> 标注 `【本司】` 的条目是该公司实际业务口径，**优先级高于任何通用行业惯例**——与通用规则冲突时以本司为准。

## 0. 本司业务定位（2026-10-04 确认，规则层据此裁剪）

| 维度 | 本司口径 | 对规则的影响 |
|---|---|---|
| 主营品类 | **功率与电源**（MOS / Drv / 电源 IC / 电感）、**连接器 / 结构件** | 规则重心压在这两类；主动器件、被动器件、射频高速、光耦隔离 **按需**查，非主营品类不主动展开 |
| 车规 | **做车规** | 车规件是主要业务，**不做替代建议**（认证绑定原厂），但车规降额与验证要求必须写全 |
| 医疗 / 军工航天 / 出口管制 | **均不做** | 医疗植入、军工航天品类不进入本司方案；出口管制件不碰（无相关业务） |
| 安规 CCC/UL/CB | **可以做** | 安规件可承接，但属禁替清单（见 §3） |
| RoHS / REACH | **可以做** | 常规要求，写入交付物声明 |
| 客户品牌白名单 | **无** | 不需要维护白名单，也不受客户指定品牌限制 |
| 价格口径 | **只算授权代理公开价** | **禁止引用内部成交价**（见 SKILL.md 铁律 5b）。不写具体价，只给渠道类型 + 日期 + 可核实出处 |

**禁替逻辑说明（Q3 与 Q6 的关系）**：本司**做车规**，但车规器件**列入禁替**——两者不矛盾。车规认证（AEC-Q）与主机厂认证绑定，换料等于重新认证，成本高于省下的价差。因此本司在车规件上的价值是**正品保障 + 追溯**，不是替代降本。

## 1. 关键参数清单（缺一项就不许下结论）

### 主营品类（重点展开）

**功率与电源**
| 器件 | 必查参数 |
|---|---|
| MOSFET | VDS、ID、RDS(on) @ 实际栅压（不是 25°C 的标称值）、Vgs(th)、Qg/Qg@特定栅压、SOA、封装（RDFN/TO/BGA 散热焊盘）、Tj max、θJA |
| 驱动 IC | 栅极驱动电压、源极驱动 vs 栅极驱动、驱动电流、UVLO、负压关断能力、Miller 钳位、传播延迟、兼容拓扑 |
| 电源 IC（DC-DC / LDO / PMIC） | 输入范围、输出电流、开关频率、环路补偿兼容性、软启动、OVP/OTP/UVLO 保护项、效率曲线、封装与散热 |
| 功率电感 | 感值、**饱和电流 @ 实际温升**、温升电流、DCR、屏蔽结构、磁芯材质、封装、 AEC-Q 版本 |
| 肖特基/整流 | VRRM、IF、VF@额定电流、trr、封装、结温、**车规版温度范围** |

**连接器 / 结构件**
| 器件 | 必查参数 |
|---|---|
| 连接器 | 脚数、间距、额定电流（**降额后**）、耐压、镀层厚度与类型、插拔次数（mating）、工作温度、防水/防尘等级、锁扣结构、UL 认证号、VOC/RoHS |
| 结构件 | 材质、表面处理、尺寸公差、工作温度、阻燃等级、屏蔽/接地设计 |

### 非主营（客户问到再查，别主动堆）
- 被动件、主动器件、射频高速、光耦隔离：按 §1 原表参数查即可，不额外深挖。

## 2. 替代料判定流程（不可跳步）

```
1) 同封装 + 同脚位（pin-to-pin 可直换）
2) 参数全覆盖（关键参数 ≥ 原器件，不是"差不多"）
3) 降额复核（工作点留 ≥20% 余量；电源/功率件更严）
4) 环境复核（温度/湿度/振动/盐雾）
5) 合规性复核（AEC-Q / 安规 / 出口管制）
6) 样品验证（至少功能 + 温升；关键件加老化/高低温循环）
7) 小批量（50–200 pcs）→ 良率与一致性确认
8) 量产 + 双源备案
```

**判定三分**：
- **可直接替**：1–5 全过，参数有原文来源 → 直接给结论
- **需评估**：参数有一项待确认或需打样 → 给结论 + 待办清单
- **不可替**：命中禁替清单 → 必须给理由与替代方案

### 2a. 本司实战基线（2026-10-04 确认）

**最易被低估的环节 = 第 4 步（环境复核）**，不是参数比对。→ **选型精力应重点投在环境适应性验证上**：
温度 / 湿度 / 振动 / 盐雾这四项，是实际最容易卡住的地方。参数表对齐得再漂亮，过不了环境复核也换不了。
**交付时必须显式给出这四项的实测或厂商数据，不能只给"符合规格"。**

**降额规则：全部按 20% 执行。** 不分类别、不因器件类型调整——功率件、电阻电容、连接器一律 20%。

> ⚠️ 注意区分：**替代动机阈值**（价差够不够值得走流程）与**工程降额**（工作点余量）不是一回事，两个数别混用。

**决策链：签字人是总经理。** 技术端不能自己拍板换料——**替代建议最终由总经理签字**，所以交付物必须写成"可直接给总经理看"的口径：结论明确、理由完整、风险已标，不出现"技术上或许可以"这类模糊表述。

**周期预期：从"想换"到"量产用上"约 30 天。** 给客户报交期时按 30 天起算，不要乐观估计。

## 2b. 国产替代判定（本司专用，2026-10-04 确认）

**四条硬标准，全过才算"能国产替代"，缺一条即降级为"需评估"：**

| # | 标准 | 判定方式 |
|---|---|---|
| 1 | **功能实际对齐** | **本司实际瓶颈**——不只是 datasheet 标称一致，要逐项核对实际工作点下的功能表现。这是本司的第一道闸，优先级最高。 |
| 2 | **需过客户验证** | 必须走完客户侧验证流程并留记录。**未过客户验证一律不给"可直接替"结论。** |
| 3 | **同封装同尺寸** | pin-to-pin，不接受需要改板或改外围的方案。 |
| 4 | **降本必须能覆盖验证与导入成本** | 幅度不足不构成替代动机——**认证与验证的人力成本会吃掉全部价差**。不足以覆盖时，直接建议不替。 |

**判定顺序（严格按序，前一条不过就不用看后面）**：
```
功能实际对齐？ → 否 → 不可替
     ↓ 是
客户验证过了？ → 否 → 需评估（不可标"可直接替"）
     ↓ 是
同封装同尺寸？   → 否 → 不可替（需改板，出本司范围）
     ↓ 是
降本够覆盖验证与导入成本？ → 否 → 建议不替（价差覆盖不了验证成本）
     ↓ 是
✅ 可国产替代
```

**通用三查（公开版遗留，作为补充而非替代）**：原厂是否在产 / 有无第二供应商 / 是否 pin-to-pin。

## 3. 禁替 / 高风险清单（命中即不许直接给"可替"）

**本司禁替（2026-10-04 确认）**
| 类别 | 本司口径 | 为什么 |
|---|---|---|
| **车规 AEC-Q 全系** | **禁替**（本司做车规，但不做车规替代） | 认证与主机厂绑定，换料=重新认证，周期与成本高于价差。本司在车规件上的价值是**正品与可追溯**，不是降本。 |
| **医疗 / 军工 / 航天** | **不承接**（业务范围外） | 本司不做这些品类，不进入方案讨论。 |
| 出口管制 / 实体清单件 | **不碰** | 无相关业务。 |
| 保险丝 / Y 电容 / X 电容 | **禁替** | 安规件，失效即触电/起火，必须认证件原厂同型号。 |
| 光耦 / 隔离栅 | **禁替** | 同上，安规隔离件。 |
| 客户指定品牌 | **无此约束** | 本司无品牌白名单限制。 |

**通用高风险（外行草稿遗留，本司仍适用）**
| 类别 | 为什么高风险 |
|---|---|
| 电源拓扑主控 / 驱动 IC | 内部环路补偿参数不同，可能点亮但工况不稳 |
| 射频与高速收发 | 阻抗与寄生参数不匹配，EMI 与误码 |
| 精密基准 / 高精度 ADC/DAC | 温漂与噪声决定系统精度 |
| 存储颗粒/闪存 | 白片/黑片/散新风险，寿命与数据保持 |

**命中任一，输出必须含"需原厂/认证确认"与"建议打样 + 第三方复核"**，并提示采购走双源备案。

## 3b. 七条雷区（实战教训，优先级最高）

> 这七条不是行业惯例，是本司实际付出代价换来的。**违反任何一条造成的损失，远大于选型本身的价值。**
> 雷区一~三来自 10-04；雷区四~七来自 10-05 的 原用件 国产替代案（同一案返工三轮）。
> **雷区六的判定部分已升级为独立标准 `pin-to-pin-judgment.md`（PPJ-1），本条只保留措辞纪律。**

### ⚠️ 补充雷区（2026-10-05 亲历，原用件 替代案，两条料同时栽在同一处）

> 起因：一份报告只看「封装型号字符串相同」就判 pin-to-pin，结果两料都判错。
> **代价：已推荐给客户的首选料被推翻两次，报告返工两轮。** 教训值两条规则。

#### 雷区四：封装机械尺寸吻合 ≠ pin-to-pin，两者必须分开验

**真实事故（原用件 → 国产替代）**：
- 候选 A（候选料二）：选 SOIC-8 型号后**外形尺寸逐项吻合**（E1 3.80/3.90/4.00、e 1.27 BSC 全部对上）。
  但 pin5 定义不同：被替料是 `VL`（逻辑电源 5V），候选料是 `NIC`（No Internal Connection）——
  **我据此判「失去基准、必须改板」，这是判重了**（详见雷区六）。
- 候选 B（候选料一）：**封装完全一致但一度被误判为「封装大一级」**。原因是把原厂型号后缀读错
  （`原用件` 的 `R` 是 SOIC 窄体 R-8，`RM` 才是 MSOP；渠道页把 BRZ 误标为 MSOP）。

**规则**：
- **pin-to-pin = 封装机械尺寸吻合 ∧ 逐脚定义一致**，两个条件缺一不可，**必须分别取证、分别下结论**。
- 型号后缀**必须回原厂订购指南逐字读**（Ordering Guide / Package Option 表），**严禁凭渠道页的 Package/Cases 字段**——
  渠道页错标同族型号是常态（例如把 SOIC-8 错标成 MSOP-8）。
- **冷门脚重点核**：NC / NIC / DNC（内部无连接）、VL / VLOGIC（逻辑电源）、NC 兼做电压参考的脚。
  这些脚在功能框图上不显眼，却是 pin-to-pin 最常见的分歧点——**尤其注意多电源脚**。
- 判定表里「同封装同尺寸」这一条（§2b 标准 3）**只覆盖机械维度，不等于 pin-to-pin**，
  执行时须额外补一次逐脚核对，两者都过才能写「可直换」。

#### 雷区五：原厂文档瑕疵必须显式记录，不可自行脑补圆场

**真实问题**：候选料一 原厂 datasheet 第 2 页管脚表标题误写为「候选料一同系列 芯片管脚说明」；
其 pin2 备注栏写「悬空」，但同一行的功能列写「S1 端，可以作为输入/输出」——**原厂自相矛盾**。

**规则**：
- 原厂文档出现**型号名笔误、同表格内自相矛盾、单位缺失、表格串行**时，
  **一律记为待澄清项并向原厂求证**，不许在报告里替原厂"圆回来"或挑一个读法直接用。
- 报告里必须单列「原厂文档瑕疵」小节，写明位置、原文、矛盾点、求证对象与联系方式。
- 原厂没给的参数（如某项未公开的动态指标）**就写"原厂未给"**，
  不许用同系列料的值代填、不许用宣传稿的营销值冒充 datasheet 值。

#### 雷区六：pin 定义有差异时，禁止用结论词代替判定（**判定走 pin-to-pin-judgment.md**）

> ⚠️ **本文档只讲措辞纪律。判定本身走 `pin-to-pin-judgment.md`（PPJ-2 标准）**，
> 由 §3 测试项与 §6 合成表机械产出。下面这些词之所以成雷区，正是因为一度没有标准可依。

**真实事故（原用件 → 候选料二，2026-10-05，同一颗料连改三次）**：
候选料二 的 pin5 是 `NIC`，原用件 的 pin5 是 `VL`。
第一次见差异即判「失去基准 → **必须改板**」；重核后改判「**零改板可换**」「**无害差异**」「**综合最优**」；
用户当场指出「候选料二 和 国际大厂甲 的物料引脚定义不一致」——**用户是对的**。

**三次都不是新事实驱动的，是判据没定死。** 根因：拿 §4「能不能工作」的推理结果去改写 §3「是不是 pin-to-pin」的结论。
→ 由此立 PPJ 标准。**标准立后仍复发一次**（PPJ-1 的 T8 拿"符号相同"当"功能相同"），修订为 PPJ-2。

**PPJ-2 的核心修正（用户指出，极重要）**：
「逐脚功能等价」的判定依据必须是**功能类别一一对应**，**不能是 Mnemonic 逐字比对**。
`D` 与 `COM` 符号不等但**都是开关公共端** → 功能等价，判等价；`S1`↔`NC`、`S2`↔`NO` 同理。
**反之符号相同功能不同也要判不等价**（都叫 NC 但一个接信号、一个空脚）。
Mnemonic 只用于①依 datasheet 功能描述**确定类别** ②提高报告可读性，**不作判定依据**。

**符号名是厂商命名习惯，功能才是电路事实。** 混用二者就是把手段当目的。

**措辞禁用表（写交付物前逐行自检）**：

| ❌ 禁止 | ✅ 应写成 |
|---|---|
| pin-to-pin（用于功能不等价的料） | 封装机械兼容 + 存在 n 处功能不等价（定位到具体脚） |
| 无害差异 / 无影响 / 本质上兼容 | 功能差异，**影响未判定**，须实测验证 |
| 零改板可换 | 理论上无需改板，须实机验证 |
| 综合最优 / 首选 | 性能指标最优，但存在功能不等价，标「需评估」 |
| 直接给「能替 / 不能替」 | 查 PPJ-2 §6 合成表 |
| 把"我认为无害"写成"经确认无害" | 我的推理是 X，datasheet 写的是 Y，差 Z，须实测 |

**判断口诀：这句话有 datasheet 页码吗？没有就是在替原厂/客户下结论。**

**另记：差异性质要分类，不能笼统说"不一致"** ——
`D` vs `COM` 是**命名差异**（功能相同），`VL` vs `NC` 是**功能缺失**（一方少一个功能）。
两者的客户含义完全不同：前者无需处理，后者可能需要改板。**报告里必须写清是哪一种。**

- **命名体系要查来源**：遇到符号不同（D/S1/S2 vs COM/NC/NO vs K1/K2）时，
  **必须查清哪一套是行业标准**（如查 国际大厂丙/国际大厂乙 同类料的原厂 pinout），
  这直接决定「这个差异是厂商 idiosyncrasy 还是跨厂标准差」。
- **凡标「需评估」就必须列出可执行的验证项**（谁测、测什么、判据是什么），
  不许只写「需评估」三个字就交差。

#### 雷区七：功能类别不同的料不是「参数差一点」，是根本不可替代

**真实事故（原用件 vs 候选料三）**：
候选料三 初判理由是「Ron 270Ω 太高」，但实际**架构都不同**：
原用件 = 1 位 IN 的 **SPDT**（8 脚）；候选料三 = 3 位地址（A0/A1/A2）+ EN 的 **8:1 多路复用器**（16 脚）。

**规则**：
- 比对前**先确认功能类别**（SPDT / SPST / MUX / 矩阵 / 多通道）、**位宽**、**脚数**；
  三者任一不同即**物理不可能替代**，不必再看参数。
- Ron 高只是**参数级否决**；架构/脚数不同是**类别级否决**，理由强得多，写报告时要说清是哪一层。
- 厂商目录里型号相邻的料（如 4438 与 候选料二）**极易混淆**——
  见到 ZJG44xx / ZJG46xx 等同前缀型号，先确认功能类别再比参数，**不要按编号相近就当同类**。


### 雷区一：不得以消费品物料替代工业级

**有过惨痛教训。** 消费级与工业级在可靠性、温漂、寿命、认证上不是一个量级的东西——参数表看着能对上，实际用在工业环境上就是定时炸弹。

**规则**：
- 判定替代时**必须问清原器件是消费级 / 工业级 / 车规级**，并明确写出。
- **消费级物料一律不得作为工业级工况的替代方案**，哪怕参数完全覆盖、价格再低。
- 无法确定原器件等级时，**直接判「不可替」并要求确认**，不许假设。

### 雷区二：必须与技术端确认测试结果，不许凭空想象器件能否满足客户要求

**参数达标 ≠ 器件达标。** 客户工况千差万别，datasheet 只能证明"在标准条件下满足"，**证明不了"在客户那台机器上满足"**。

**规则**：
- 凡涉及"能否满足客户要求"的结论，**必须引用技术端实测或客户验证结果**。
- **拿不到测试结果时，输出只能是「需评估」，并明确写出"缺技术端实测数据"**——不许用 datasheet 推演后给"满足"的结论。
- 技术端确认结果要有记录，可追溯到人和时间。

### 雷区三：敏感物料必须每一环亲自盯住，不能完全信任下游

**典型事故**：帮人找一颗受进口限制的敏感物料，下游贸易商明确答复"可以提供"；等订单下来、款项已付，贸易商才告知该物料属进口敏感、**拿不到**。最终只能走退款处理，**信任受损，精力与时间大量消耗。**

**教训**：**越是好说话、越是非标、越是有"特殊渠道"的供应商，越要在付款前把话说死。**

**规则（敏感物料专用，逐环确认，每环留痕）**：
1. **货源性质先问清**——是原厂、授权代理，还是贸易商？是否自有渠道？能否出具合规证明？
2. **合规限制先自查**——该物料是否涉及进口管制、终端用途限制、最终用户限制。**不确定就当"涉及"处理。**
3. **贸易商的"能供"不算数**——口头承诺、聊天记录、报价单都**不能作为唯一依据**。要求书面确认 + 可追溯的货源证明。
4. **付款前再确认一次**——尤其在客户已下单、已预付的节点，**付款前是最后的止损窗口**。
5. **敏感物料不接受"先做后补"**——绕单、借用资质、变更品名一律不做。
6. **给客户的答复留余地**——涉及敏感物料时，**不要向客户承诺"一定能供"**，只能说"正在核实渠道，确认后回复"。

**写进交付物的话术**：涉及敏感/受管制物料时，交付物必须包含一句
> 「该物料涉及合规与货源双重核验，需在付款前完成最终确认，本司不承担因渠道变更导致的交付延误。」

**通用原则：不能完全信任下游接口。** 无论物料是否敏感，**关键承诺必须由本司自己向客户闭环**，不要把客户的期望建立在下游的答复上。

## 4. 供应链风险四查

1. **生命周期**：Active / NRND / EOL / Premium（预停产）。EOL 要给出 **LTB（最后采购日）** 与替代型号时间线。
2. **单点货源**：只有一家原厂/代理商 → 标高风险，建议第二供应商。
3. **变更通知**：PCN（产品变更）/ PDN（停产通知）要查最近 12 个月。
4. **来路**：授权代理 vs 独立分销（散新/翻新/贴牌）。价格明显低于市场价 = 假货红旗。

## 5. 呆滞库存处置顺序（别一上来就低价出清）

```
1) 内部替代消化：能否用这批料满足其他机型/BOM 项
2) 交叉替代：型号升级或降规格后是否仍然可用
3) 换货/退回供应商：看原采购条款（部分可退、部分可换同等价值料）
4) 客户/同行盘活：找需要该型号的同行或下游（这是分销的强项）
5) 折价出清：最后手段，先算清呆滞 holding 成本 vs 折价损失
6) 报废：需在账务与合规上留痕
```
**每步都要有数字**：库存数量、年限、占用金额、holding 成本/年、折价底线价。

## 6. 中国场景补充（2026）

- 进口断供是常态，**国产替代必须先过 §2b 四条硬标准**（功能对齐 → 客户验证 → 同封装 → 降本够覆盖验证与导入成本），再谈三查。
- 涉及**实体清单 / 出口管制**的器件：本司不碰此类业务，若客户强问，输出"该品类超出本司业务范围"并给合规复核提示，**不给"能买"的结论**。
- 授权代理与独立分销混杂，**报价单必须写清"渠道类型 + 日期"**，避免售后扯皮。
- 采购合同侧：价格、交期、最小起订、质保、滞港与关税责任、汇率条款，都要在交付物里点名。
