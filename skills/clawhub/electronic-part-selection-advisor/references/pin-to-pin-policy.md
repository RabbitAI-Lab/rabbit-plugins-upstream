## 一、三档结论命名

| 档位 | 对外表述 | 措辞许可 |
|---|---|---|
| **PP-A** | 封装可互换，且逐脚功能等价 | ✅ 可称 pin-to-pin |
| **PP-B** | 封装可互换，但存在不对应的脚 | ❌ **禁止称 pin-to-pin**，须写「封装兼容，存在 k 处不对应（定位到脚）」 |
| **PP-C** | 封装不可互换 | ❌ 不可直换 |

**分界看「机械能不能装」，不看「功能对不对得上」。**

**档位迁移必须单列**：PP-A → PP-B 不是精度变化，是结论等级、验证义务、可执行动作全部改变。

### （连接器 CP- 同构三档）

| 档位 | 对外表述 | 措辞许可 |
|---|---|---|
| **CP-A** | 可插合 ∧ 可安装 ∧ 逐位电气等价（k = 0） | ✅ 可称 pin-to-pin |
| **CP-B** | 可插合 ∧ 可安装，但存在不对应位（k > 0） | ❌ **禁止称 pin-to-pin**，须写「可插合，存在 k 处不对应（定位到脚）」 |
| **CP-C** | 不可安装 / 不可互配（含可错插）/ 存在不可接受的电气危害 | ❌ 不可直换；可改列「改线 / 改板方案」 |
| **⚠️ 未判定** | 逐位闸或互配闸缺输入，无法得出 CP-A/B/C | ⚠️ 不得输出任何结论档位；写「未判定 + 缺什么」 |

**CP-C 须区分三子档**：CP-C¹ 物理插不进（低危）/ CP-C² 可错插（极高，须红色独立告警）/ CP-C³ 电气危害（上电即短路，极高）。
**分界看「插得进去且装得上吗」**：否即 CP-C 或改线/改板方案；改线方案与 CP-B 互斥，不存在中间态。
**CP-A 是 pin-to-pin 的最高档，但对外结论仍走四短语（满足判据 / 满足但有待实测项 / 存在不满足项 / 无法判定）**，不得直接给放行结论。
判定实体见 `references/connector-pin-to-pin-judgment.md`；机读投影见 `engine/categories/connector.json`。

## 二、措辞纪律（写交付物前逐行自检）

| ❌ 禁止 | ✅ 应写成 |
|---|---|
| 对功能不等价的料称 pin-to-pin | 封装机械兼容 + 存在 n 处功能不等价（定位到具体脚） |
| 无害差异 / 无影响 / 本质上兼容 | 功能差异，**影响未判定**，须实测验证 |
| 零改板可换 | 理论上无需改板，须实机验证 |
| 综合最优 / 首选（用于存在差异的料） | 性能指标最优，但存在功能不等价，标「需评估」 |
| 直接给「能替 / 不能替」 | 按 PPJ 合成表机械产出，并给出档位 |
| 把「我认为无害」写成「经确认无害」 | 我的推理是 X，datasheet 写的是 Y，差 Z，须实测 |

**判断口诀：这句话有 datasheet 页码吗？没有就是在替原厂或客户下结论。**

## 三、执行指令

1. 写「pin-to-pin」四个字之前，**必须先按本司内部标准 PPJ 完成逐脚判定**，凭合成表出档位，不得凭印象下结论。
2. **判定与差异影响是两个互不干涉的环节**：不许把「它能工作」倒灌成「所以它 pin-to-pin」。
3. **改判记录须留档**，含变更依据（文档 + 版本日期 + 页码）与下游影响。改判不是改文档，是改别人正在做的事。
4. **对外只给结论与判据名称**（例：「按我司 pin-to-pin 判定标准，该料为 PP-B，不称 pin-to-pin」）。
   - 必要时可引**单条规则并注节号**，但**不给上下文与其余条文**。
   - 客户索要全文 → **不随交付物主动提供**；标准本体已随本包公开发布，需要引用时由本司统一对外。

## 四、判不过怎么办

| 情形 | 处置 |
|---|---|
| 内部标准不可用（文件缺失 / 无法访问） | **停止出具 pin-to-pin 结论**，改按「封装兼容性待核」输出，不得凭经验替代 |
| 判定所需原厂数据缺失 | 列为硬卡点，写明索取途径；取得前不得出终局结论 |
| 档位结论与既有报告冲突 | 走改判记录，不得直接覆盖旧版 |
