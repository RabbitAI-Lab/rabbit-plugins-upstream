## §0 先决问题：替换场景（**连接器特有，PPJ 无此项**）

**半导体只有「本体 + PCB」两体；连接器是「本体 + 配对端 + PCB」三体。**
不先确定"换哪一端"，整套判定无从谈起。

**任何连接器判定开始前，必须先答 S1–S3 中的哪一种，并写进输出。**

| 场景 | 定义 | 互配闸（M1–M8）判什么 | 严苛度 |
|---|---|---|---|
| **S1 单端替换** | **只换本端**，原配对端（插头 / 插座）保持不变 | 候选必须与**原配对端**实际插合并保持；M5/M6/M7 的比对对象 = **候选 vs 原配对端** | **最严** |
| **S2 两端同换** | 本端与配对端**一并换成**候选系列的两端 | 只需**候选两端彼此**互配；M5/M6/M7 的比对对象 = **候选 A 端 vs 候选 B 端** | 中 |
| **S3 新设计** | 本端换料，配对端尚未确定 / 另行新设计 | **互配闸 M1–M8 整体不判**（记「不适用」，非「⚠️」），只判 PCB 安装界面（A1–A7） | 最松 |

### §0.0 场景决定互配闸的比对对象（**最易判错处，强制**）

| 场景 | 性别（M1）核什么 | M5/M6/M7 比谁 | §3.1.3「跨厂商默认不成立」是否适用 |
|---|---|---|---|
| **S1** | 候选与原配对端**性别互补**（公对母） | 候选 vs **原配对端** | ✅ 适用 |
| **S2** | 候选两端**彼此性别互补** | 候选 **A 端 vs B 端** | ❌ 不适用（两端同属候选系列，互配由该系列自身保证） |
| **S3** | 无配对端，不判 | **不判** | ❌ 不适用 |

**S2/S3 不得沿用 S1 的比对对象**；**S3 不得输出任何互配结论**（含"可插合""互配成立"字样）。

**未列于上表的项，比对对象一律为「候选 vs 原件」**（与场景无关）：
**M2 间距 / M3 位数 / M4 排数 / M8 插合后本体尺寸** —— 这四项比的是"新件相对旧件有没有变"，故不随 S1/S2/S3 改变；
其中 **M1 的品类归口、M2/M3/M4 的属性**取**原件**，**M1 的性别**取**原配对端（S1）/候选两端（S2）**（见上表）。

**M3 的例外（强制，勿与上句读成矛盾）**：**M3 的比对对象是「候选位数 vs 原件位数」**，
但**候选位数 > 原件时，M3 不直接判"不过"**，而是**转入 §3.1.1 的例外规则**（多余位作空位区**预判**，机械仍须过 M5 / M8）。
即：**「比候选 vs 原件」说的是比对**对象**，"位数不等即不过"只对"候选 < 原件"成立**；候选多于原件属**待复核**，不是 M3 直接不过。
**禁止**：把"M3 一律比候选 vs 原件"读成"位数不等 M3 就不过"，从而跳过 §3.1.1 直接判 CP-C。

**禁止**：不写场景就给结论；用 S2/S3 的宽松结论去回答 S1 的问题。

**默认取值**：未明确说明时**一律按 S1 判**，并在输出中显式标注「场景未声明，按 S1 从严」。放宽须由需求方书面认可。

### §0.1 连接器品类（**唯一归类口径**）

**判定前必须先定品类。** M1 与 §5b.3 **共用本表**，两处不得各立一套品类名。

品类按**配对界面**归类；**锁扣形式、性别、pitch、位数均不改变品类归属**，只作为子类标注（影响权重，不影响归类）。

| 序号 | 品类（canonical） | 涵盖 / 子类 | 典型 |
|---|---|---|---|
| **C1** | **板对板（B2B）** | 无锁扣 / 带锁扣 / 浮动式 / 夹层 | 排针排母、夹层连接器 |
| **C2** | **线对板（W2B）** | 无锁扣 / 带锁扣 / 端子台 / IDC | 杜邦、JST 系列、螺钉端子台 |
| **C3** | **线对线（W2W）** | 插拔式 / 压接式 | 航插、线束对接 |
| **C4** | **FFC/FPC** | 上 / 下 / 双面接触；翻盖 / 抽屉 / 后掀 | 软排线座 |
| **C5** | **圆型（M8/M12/航插）** | 按编码分（A/B/D/X 码） | M12 传感器连接器 |
| **C6** | **标准接口件** | RJ45 / USB / HDMI / D-SUB / SD / SIM / PCIe 插槽 | 标准互配接口 |
| **C7** | **大电流 / 电源端子** | 刀片 / 电池座 / 大电流插拔 | 电池连接器、电源端子 |
| **C8** | **高速差分连接器** | 背板 / 高速板对板 / 高速线束 | 有 SI 指标要求的连接器 |

**归类优先级**：
1. 先按**配对界面**定主类（不看"装在哪块板"、不看"带不带锁扣"）。
2. 跨类者（如"带锁扣的板对板"）→ 主类仍为 **C1**，锁扣仅作子类标注。
3. **C8 优先级最高**：只要该料有阻抗 / 插损要求，即归 **C8**，并同时标注其机械主类（C8 的判定权重与其余品类不同）。

**禁止**：两个部位（M1 / §5b.3）使用不同品类名；以"带不带锁扣""用在哪里"替代品类归类。

## §1 术语定义

**连接器语境下，「pin-to-pin」只有一个含义：可插合 ∧ 可安装 ∧ 逐位电气等价。**

判定为 pin-to-pin **必须**同时满足：
- **可插合**（§3.1 M1–M8 全过）
- **可安装**（§3.2 A1–A7 全过）
- **逐位电气等价**（§3.5：k = 0，n = N）

**三处与半导体判定的根本差异，判定前必须先接受：**

| # | 差异 | 后果 |
|---|---|---|
| ① | **pin 定义不由 datasheet 给出，而由客户设计给出** | 逐位判定的依据必须是**原设备的位定义表**（线序表 / 原理图），不是手册；拿不到 → 该闸 ⚠️ 未判定，不许推测 |
| ② | **存在配对端，且可能不同步更换** | 互配闸取代单纯的封装闸，成为第一道门槛（见 §0） |
| ③ | **线序物理上可改**（线端连接器改接线即可换位） | 存在合法出口「改线方案」，单列于**附则**，**不属于 pin-to-pin（CP）判定** |

**禁止的表述方式**：
- 用"能插进去""插得挺紧""试了能用"替代插合闸判定
- 把 §4（换了能不能工作）的推理结论**倒灌进** §3（是不是 pin-to-pin）
- 用"改一下线序就行"把 CP-B 说成 CP-A —— 改线即**改线方案**，与 pin-to-pin（CP）判定互斥（附则）
- 用位数相同推断 pin-to-pin（位数相同 ≠ 插合界面相同 ≠ 逐位等价）

**核心纪律：§3 只回答"是不是 pin-to-pin"，§4 只回答"能不能工作"。两者互不干涉。**

### §1.1 术语表（本文件内使用，缺一即判定不可靠）

| 术语 | 定义 | 备注 |
|---|---|---|
| **N** | **被替代（原件）连接器的位数** | 候选多余位**不计入 N**（见 §3.1.1） |
| **n / k** | n = 等价位数，k = 不对应位数；**k = N − n** | CP-A 判据 = k = 0 |
| **NM** | **原位无金属端子**（原连接器该位为空位 / 缺针） | 与 **NC** 的区别：NM 是"没端子"，NC 是"有端子但无网络"。二者**不等价** |
| **NC** | 该位有端子但原理图上无网络（未使用） | 只与 NC 等价 |
| **空位区** | 候选连接器上**未被位定义表占用、且不改变插合界面**（pitch 序列与外形尺寸）的多余位区域 | 认定须确认：① 该位确无信号引出；② 不改变 M5/M8 结果。**"多出来的脚不用就行"不构成空位区认定** |
| **盖章数据** | 带**原厂签章或正式发布版次**的 datasheet / 测试报告 / 承认书 | **不含**选型手册摘页、电商参数页、销售口头或邮件提供的参数。判定表"未拿到盖章数据"即指缺此类文件 |
| **品类** | 按 §0.1 唯一归类口径确定的连接器类别（C1–C8） | 判定前必须先定 |

## §2 判定结论

| 代号 | 定义 | 可用措辞 |
|---|---|---|
| **CP-A** | 可插合 ∧ 可安装 ∧ 逐位电气等价（k = 0，n = N） | ✅ **可称 pin-to-pin** |
| **CP-B** | 可插合 ∧ 可安装，但存在**不对应位**（k > 0） | ⚠️ **禁止称 pin-to-pin**，只能写「可插合，存在 k 处不对应」 |
| **CP-C** | **不可安装**，或**不可互配**（含 ① 插不进去；② 防呆不互锁但**可错插**），或**存在不可接受的电气危害**（多余 / 空置端子造成**上电即失效的短路**，见 §3.10；**不限于 PWR / GND**） | ❌ 不可直换（可改列「改线 / 改板方案」，见附则；电气危害类**不可用改线掩盖**，须先消除短路） |
| **⚠️ 未判定** | 逐位闸或互配闸**缺输入文件**，无法得出 CP-A/B/C | ⚠️ **不得输出任何结论档位**；写「未判定 + 缺什么」 |

**N = 被替代连接器的位数**（pin count / positions）。计数写作 **n/N 与 k/N**，**禁止把 N 写死为任意固定值**，也**禁止用候选位数充当 N**（候选多余位见 §3.1.1）。

**CP-C 的三个子情形**（输出须区分）：

| 子档 | 情形 | 危险等级 |
|---|---|---|
| **CP-C¹** | 物理插不进 / 装不上 | 低：显性失效，现场即可发现 |
| **CP-C²** | **可错插**（防呆不互锁但物理可插入） | **极高**：见 §3.1.2 与 §8.2，**必须红色独立告警** |
| **CP-C³** | **电气危害**：可插合、可安装，但多余 / 空置端子造成**上电即失效的短路**（§3.10 不通过）—— 含 ① 涉 **PWR / GND**；② 涉**已分配信号网络**（SIG↔SIG 的活动网络短路、DIFF 对内 / 对间短路、HSIG 短路等） | **极高**：**可插合且能通电**，静态插合检查发现不了，上电即短路 / 冲突 / 烧毁 |

**CP-C³ 的触发判据（**不限 PWR / GND**）**：短路是否把**两个本不连通的「已用网络」**
（PWR / GND / 已分配信号的 SIG / DIFF / HSIG，依**原设备位定义表**判断）电气连通 →
是 → **上电即失效，判 CP-C³**。**信号短路与电源短路同属电气危害，不得因"不涉电源"降格为 CP-B。**
**「已用网络」的完整操作定义（含 NC / NM / 同网络冗余 / GND-SHLD 的处理）见 §3.10。**

**CP-C³ 的定档依据**：短路属于「**不可接受风险**」，且**不属于 k 的计数范围**——`k` 只用于区分 CP-A 与 CP-B（见 §2.1），
故 §3.8 第 ⑤ 类中**造成上电即失效短路**者**不计入 k、直接判 CP-C³**，以免出现「计入 k → 按 §2.1 应判 CP-B」的自相矛盾。

**CP-B 不得因"差异无害"升级为 CP-A。** 无害与否属 §4，不属 §3。

### §2.1 CP-B 的边界定义

**CP-B 的成立前提：可插合 ∧ 可安装（M1–M8 与 A1–A7 全过）。**

| | 情形 | 归属 |
|---|---|---|
| ① | 可插合∧可安装 + 逐位全部对应（k = 0） | **CP-A** |
| ② | 可插合∧可安装 + 存在不对应位（k > 0） | **CP-B** |
| ③ | 不可插合，或不可安装（**A1–A6 任一 ❌**；**A7 除外** —— 见 §3.2） | **CP-C**（可错插 → CP-C²） |
| ④ | 缺位定义表 / 缺原配对端图纸 | **⚠️ 未判定**（不是 CP-C） |
| ⑤ | 可插合∧可安装，但多余 / 空置端子造成**上电即失效的短路**（§3.10 不通过；**不限 PWR / GND**，含已分配信号网络的短路） | **CP-C³**（电气危害；**该情形不计入 k**，优先于 ②；「已用网络」定义见 §3.10） |

**关键分界：先答「插得进去且装得上吗？」→ 是，才进入 CP-A/CP-B；否，就是 CP-C 或改线/改板方案。**
**⑤ 优先于 ②：一旦命中电气危害，直接落 CP-C³，不再按「k > 0」判 CP-B。**

**⑤ 命中时其他不对应位的处理（强制）**：
CP-C³ 命中时，若同时还存在其他 k > 0 的不对应位（如位 4 是 PWR↔SIG 能力不足），
**这些不对应位仍须逐位如实列出**（作为**改板方案的输入**，见附则），
但**不再计入 k 的统计口径**——**k 只在 CP-A / CP-B 的分档中有效**，CP-C³ 档位下 k 不再是分档依据。
输出中须分两段：**① 电气危害（CP-C³，短路位逐位指明）；② 其他不对应位清单（供改板，标注"不影响 CP-C³ 定档"）**。

### §2.2 CP-B 不允许位重映射

**判定过程中禁止交换位序来"凑"等价。**

| 情形 | 归属 |
|---|---|
| 存在不对应，**但改线序可达成对应** | **不是 CP-B**，改列「**改线方案**」（附则） |
| 存在不对应，且**改线也无法**达成对应（如位能力不足） | **CP-B**，§4 通常判「不可用」 |
| 不可插合，但经改板/换配对端可使用 | **不是 CP-C**，改列「**改板方案**」 |

**CP-B 与「改线方案」互斥，不存在中间态。**

> **与 PPJ 的重要差别**：半导体几乎没有合法的"重映射出口"（改飞线属违规操作），
> 而连接器**改线是常规工艺**。因此本文件特设「改线方案」出口 ——
> 但出口存在，**不等于可以在判定中摇映射**。

## §3 机械闸

### §3.1 互配闸（M1–M8）—— 判定「插得进去且插得牢」

**M1–M8 全过（或按场景不适用），才谈得上"可插合"。任一不过 → CP-C。**

> **比对对象随场景改变**（§0.0）：S1 比「候选 vs 原配对端」；S2 比「候选两端之间」；S3 整体不判。
> **M1–M8 中任一项缺其必需输入文件（原配对端外形图 / 装配图、双方 datasheet、键位尺寸图等）→ 该项记 ⚠️ 未判定**，
> 整闸不得判 ✅，结论走「⚠️ 未判定」行（§6.1）。**不得因缺图纸而判过。**（原 v1.1 仅覆盖 M5/M6/M7，
> 但 **M1 性别、M8 插合后本体尺寸**同样依赖外部文件，v1.2 一并纳入。）

| # | 测试项 | 判定阈值 | 公差 / 依据来源 |
|---|---|---|---|
| **M1** | 品类、接口形态**与性别** | 同一品类（按 **§0.1** 归一）；**性别须互补**（见 §3.1.0） | — |
| **M2** | 间距 pitch | **标称值相同**（参照 PPJ 的 BSC 口径，不要求公差区间全等） | ① datasheet → ② 行业标准 |
| **M3** | 位数 positions | **相同即过**；候选多于原件时见 §3.1.1 | — |
| **M4** | 排数 / 排列 | 单排 / 双排 / 错位跨排 / 环形均须一致 | — |
| **M5** | **插合界面配合尺寸** | 比对对象按 §0.0；界面尺寸须落在**双方公差重叠区间** | 双方 datasheet 外形图 |
| **M6** | **导向与防呆结构** | 见 §3.1.2（**三选一，不是二选一**） | 双方外形图 + 装配图 |
| **M7** | **锁紧 / 保持机构** | 锁扣形式须同类（摩擦 / 卡扣 / 螺钉 / 卡口 / 推拉自锁） | datasheet + 产品图 |
| **M8** | 插合后本体尺寸 | 插合高度 / 宽度：**候选 max ≤ 原件 max**（干涉校核） | 双方 datasheet |

#### §3.1.0 性别（公母 / plug-receptacle）判定 —— **S1 下插得进去的第一物理前提**

**M1 内含本项，但判定顺序上必须先于 M5/M6/M7。**

| 场景 | 判定 |
|---|---|
| S1 | 候选性别须与原配对端**互补**；**性别不一致 → M1 直接不过 → CP-C** |
| S2 | 候选两端须**彼此互补** |
| S3 | 不判 |

**⚠️ 特别提醒**：M5 的"公差重叠区间"**不能用于跨性别比对**——公头插针尺寸与母头插孔尺寸本来就"不重叠"，
若漏判性别而直接套 M5，会把根本插不进去的两颗料判过。**性别未核 → M5/M6/M7 结论无效。**

**性别中立连接器（genderless / hermaphroditic）的处理（仅限此类，强制）**：

部分品类**无明确公母之分**（如某些**板对板（C1）**、**FFC/FPC（C4）**，或同系列件既可作公端亦可作母端）。

- **仅当原配对端与候选双方均属性别中立品类** → **M1 的"性别"子项记 ⬜ 不适用**（**仅限此情形**，须在输出中注明理由，见 §6.0 允许清单）；
  互配判定**转而由 M5（配合尺寸）+ M6（防呆）承担**，**不得**因性别中立而**跳过 M5 / M6**。
- **「性别中立」的认定以双方 datasheet 明确标注为准**（如标注 genderless / hermaphroditic / 无极性 / 同系列双向可配）；
  **不得凭"看起来没有公母"自行认定**。
- **仅一方**属性别中立（一方有明确公母、另一方无）→ **不适用本例外**（M1 性别子项**不得**记 ⬜ 不适用），
  须按下列两步判（**不得一律记 ⚠️ 未判定**）：
  1. **性别中立方的 datasheet 明确其可同时作为公端或母端**（如标注「可配公端亦可配母端」「无极性」「同系列双向可配」）→
     **M1 性别子项按「互补」判过**，**不记 ⚠️**；但须在输出中**注明依据**「依据性别中立件 datasheet 的双向兼容声明」；
  2. **性别中立方的双向兼容性未明确** → M1 性别子项记 **⚠️ 未判定**，须**索取该件 datasheet 确认**后方可判。
  **禁止**：仅凭"看起来没有公母"就认定双向兼容（认定标准同本段上句，须 datasheet 明标）。

#### §3.1.1 位数不等的处理

| 情形 | 判定 |
|---|---|
| 候选位数 **<** 原件 | ❌ 不过（必有信号无落点） |
| 候选位数 **>** 原件，**且多余位可认定为空位区** | 多余位作**预判**归入 §3.6 的 `NC`（无信号引出）列清单；**机械仍须由 M5 / M8 复核**，复核不过 → ❌ |
| 候选位数 > 原件，但外形随之变长 | ❌（M5 或 M8 不过） |

**多余位与 N 的关系（强制）**：**N 只计原件位数**；候选多余位**不计入 N、也不计入 n**，另列「**多余位清单**」。
仅当多余位造成短路（§3.10）或机械不过（M5/M8）时，才影响判定结果。
**禁止**：把候选位数当作 N，从而人为抬高 n/N。

**空位区认定的两步走（避免循环）**：① 本表先作**预判**（该位无信号引出即暂认空位区）；
② 最终认定须由 **§3.10 短路校核 + M5/M8 干涉校核**复核确认。**预判 ≠ 认定**，复核不过即回落为不对应 / ❌。

**禁止**：以"多出来的脚不用就行"替代 M5/M8 的机械校核。

#### §3.1.2 M6 防呆判定 —— **三种结果（连接器最致命的隐性项）**

**这是本文件区别于 PPJ 的核心设计。防呆只有三种结局，不许合并：**

| 结果 | 物理表现 | 判定 | 危险等级 |
|---|---|---|---|
| **同构** | 导向槽、键位、切角完全一致 | ✅ 过 | 无 |
| **互斥** | 防呆结构相异 → **插不进去** | ❌ 不过（→ CP-C¹） | **低**：显性失效，装不上就被发现 |
| **可错插** | 防呆结构相异，但**仍能物理插入**（导向不足 / 少一个键 / 键位偏窄） | ❌ **不过 + 必须标红单列告警**（→ CP-C²） | **极高**：能插进去但错位或反插，上电即损毁，且**装配现场不会发现** |

**写明要求**：M6 判「可错插」时，输出中必须独立成段写明：

> 【⚠️ 高风险】该候选与原配对端**防呆不互锁但可物理插入**，存在反插 / 错位插入风险。
> 现场不可凭"插得进去"判定可换。

**判定依据**：必须以**双方外形图 + 键位尺寸**逐处比对，禁止依据产品照片或"看起来一样"。

**「可错插」的可执行判据（三条同时成立才判可错插，缺一即按其余两档处理）：**

1. **防呆结构确实相异**（键位数 / 键位位置 / 键宽 / 导向槽形状至少一项不同）——否则为「同构」。
2. **在至少一个"非唯一装配姿态"下仍能插合到位**：以双方外形图叠合，**穷举候选相对原配对端的全部插入姿态**，
   若存在某个错误姿态（反插 / 错位 / 旋转）能满足导向并插到底 → 命中。
3. **装配现场无法自然排除**：该错误姿态**不产生目视可见的阻挡、不触发工装防错**，操作者可无察觉地插入。

**反例（判「互斥」而非「可错插」）**：错误姿态被导向槽物理挡死、或插入力明显超出规格值而无法到底 → 属「插不进去」，判互斥。

**禁止**：以"键位差得不多""应该插不反"作为判定；**可错插的结论必须能指出具体姿态与对应键位尺寸差**。

#### §3.1.3 标准化接口 vs 厂商专用接口

| 类别 | 举例 | 互配口径 |
|---|---|---|
| **标准互配接口** | USB、RJ45、D-SUB、HDMI、M8/M12（同编码）、PCIe 插槽、SD / SIM 座 | 互配由**行业标准**保证；M5/M6 按同规格判。重点转为**位定义与载流**（§3.5、§5） |
| **厂商专用互配** | 绝大多数板对板、FFC/FPC、线对板端子台 | 互配**仅由该厂商同系列**保证 |

**默认铁律：跨厂商的厂商专用型连接器，S1 场景下互配闸默认判「不成立」，**
除非有**原厂书面互配声明**（Second-source 协议 / 互配声明函）或同行业标准覆盖。
**"尺寸都一样"不构成互配证据。**
**本铁律仅适用 S1**（S2/S3 见 §0.0）。

#### §3.1.4 原配对端磨损（**S1 特有，判定入口**）

**S1 只换本端、保留原配对端，而原配对端可能已插拔多次、存在磨损。**
本文件所有 M 闸 / E 闸的判据都是"候选 vs 原件（或原配对端）"，**若不记录配对端自身状态，会把"磨损的旧配对端 + 新候选"判成全新配合**。

| 情形 | 判定 |
|---|---|
| 原配对端**已使用**，且**已插拔次数已知** | **必须记录该次数**；E5（插拔寿命）须按**配对端剩余寿命**校核，而非按候选全新寿命 |
| 原配对端**已使用**，但**磨损状态未知**（无插拔记录 / 无外观检查） | **M5 / M7 判定须加注**「配对端状态未知，插合可靠性须实测确认」；E2 / E5 / E6 / E7 **一律记 ⚠️ 待实测**（不得按全新值判过） |
| 原配对端**全新 / 未使用** | 按常规判定（本项不额外加注） |

**禁止**：S1 下默认原配对端为全新；用候选的全新 datasheet 值代表"候选 vs 已磨损配对端"的实际配合。
**§4 ③「插合后保持与应力」须增加「配对端磨损」检查项**（见 §4.1 ③）。

**磨损 ⚠️ 的档位归属（强制，防与 §6.1 / §6.2 打架）**：
本项（§3.1.4）E2 / E5 / E6 / E7 的 ⚠️ 属**「可挂条件的待实测项」**，
与 E1–E12 其余 ⚠️ **同性质**（可由实测或原厂补数升级），
**不是** E13 式的"准入缺失"（E13 ⚠️ 不可挂条件，见 §5b.4 / §6.2）。

故当 **CP-A ∧ 降额过 ∧ 其余可靠项均满足**时，本项目导致的 ⚠️ **可进入「有条件通过」**，但须同时满足：

1. **实测方案（§6.3）必须包含原配对端状态检查**（原配对端外观、已插拔次数记录、接触电阻实测），**不得只测候选件**；
2. **实测前的动作约束须额外点明配对端**：写明「**不得批量下单，须先确认原配对端状态**」（在 §6.2 通用约束"不得下批量订单"之外单列）。

**若配对端磨损经实测确认不可接受 → 本项 ⚠️ 升为 ❌ → 结论降为「需评估」。**

### §3.2 安装闸（A1–A7）—— 判定「装得上板 / 装得上机」

**本闸不依赖配对端，S1/S2/S3 均须判。缺输入（如未给焊盘图 / 未给耐温曲线）→ 该项记 ⚠️ 未判定，须列缺口。**

**本闸的失败后果分两类（强制，防把 A7 误判成"装不上"）**：

| 项 | 不过后果 | 依据 |
|---|---|---|
| **A1–A6** | **不可安装** → **CP-C**（§2.1 ③） | 焊不上 / 装不进 / 上不了贴片机，属装配不可能 |
| **A7（屏蔽脚 / 接地固定脚）** | **不判「不可安装」**，而是**转 §3.5 逐位闸计 k** → **CP-B** | 缺接地脚是**电气角色**问题，机械仍装得上；计入 k 才如实反映"能装但不能等价换" |
| **A7 的例外** | 若接地脚差异**同时导致 A2 footprint 不兼容**（焊盘位置 / 孔径对不上）→ 按 **A2 判 CP-C** | 机械确实装不上时，机械结论优先 |

**禁止**：把 A7 缺接地脚写成"不可安装 / 插不进"（会把 CP-B 误升为 CP-C）；也**禁止**把 A2 焊盘不兼容写成"进 §3.5 计 k"（会把 CP-C 误降为 CP-B）。

| # | 测试项 | 判定阈值 |
|---|---|---|
| **A1** | 安装方式 | SMT / THT（波峰焊）/ 压接 / 螺钉面板安装 / 免焊IDC —— 须同类 |
| **A2** | PCB 焊盘图形 footprint | 焊盘位置、尺寸、孔径须兼容；**候选不可超出原 footprint 边界**（干涉） |
| **A3** | 引脚尺寸与共面度 | SMT 引脚共面度 ≤ 规范值；引脚截面不超出焊盘 |
| **A4** | **耐焊接温度** | 绝缘体耐温须覆盖回流/波峰曲线峰值；只标 UL94 未标耐温 → ⚠️ 数据缺失 |
| **A5** | **包装方式** | 编带 / 管装 / 托盘：SMT 料**无编带 → 判 ❌**（不可上贴片机）。若确需保留，另列「**产能风险**」为**单独说明项**，**不得作为通过理由**，不得改变 ❌ 判定 |
| **A6** | 板厚 / 面板开孔 | 适用压接式与面板式，须落在双方标称范围 |
| **A7** | 屏蔽脚 / 接地固定脚 | 位置与数量须对应（缺一个接地脚 = **电气角色不相容** → **转 §3.5 计 k，不判不可安装**；本项后果见 §3.2 闸头两类表） |

### §3.5 逐位电气等价判定（对应 PPJ 的 T8）

```
Step 1  索取原设备的位定义表（线序表 / 原理图），列出每一位承载什么及其电气需求
        —— 依据必须是原设备设计文件，不是两颗料的 datasheet
Step 2  对每一位，把「原工序位」与「候选同位」归入 §3.6 的位功能类别
Step 3  类别不同 → 该位计【不对应】，计入 k
Step 4  类别相同 → 查该位的电气能力是否覆盖原设备需求（§3.7）
        覆盖     → 计【等价】，不计入 k
        不覆盖   → 计【不对应（电气角色不相容）】，计入 k
Step 5  统计 n（等价）与 k（不对应），输出 n/N 与 k/N
Step 6  独立执行 §3.10 多余 / 空置端子短路校核（不因 k = 0 而免除）
```

**等价 = 类别相同 ∧ 该位电气能力 ≥ 原设备需求。**

**判定所需的输入文件缺失时（拿不到原设备线序表）→ 本闸整体记 ⚠️ 未判定，不许用"位数相同"蒙混。**
**逐位闸 ⚠️ 未判定时，无 CP 档位，结论走 §6.1 的「⚠️ 未判定」行。**

### §3.6 位功能类别表（FCT-Connector）

| 代码 | 位类别 | 归类依据（**原设备线序表 / 原理图**） |
|---|---|---|
| **PWR** | 电源位（带载流需求） | 原理图走电源网络；须记录每位的实际电流 |
| **GND** | 地 / 回流位 | 走 GND 网络 |
| **SIG** | 普通单端信号位 | 一般 IO / 低速信号 |
| **DIFF** | 差分对成员位 | 成对出现，须记录配对的另一位编号 |
| **HSIG** | 高速 / 射频信号位 | 有阻抗或插损要求的信号 |
| **SHLD** | 屏蔽位 / 机壳地位 | 接屏蔽层或金属壳 |
| **NC** | 空位（**有端子但无网络**） | 原理图上该位无网络；**注意区分"该位无端子"（= NM）与"有端子但未用"（= NC）**。**标注「预留」「NC 预留」「不贴」「DNP」且当前无任何电气连接的网络，归 `NC`**（判据 = 是否实际连接，见 §3.10） |
| **NM** | **原连接器该位无金属端子**（空位 / 缺针） | 原设备设计文件标注为空位；定义见 §1.1 |

**`NC` 自成一类，且只与 `NC` 等价。**
**`NM` 与 `NC` 不等价**（一个没端子、一个有端子），**分类时不得合并**。

**`NC` / `NM` 不参与 §3.7 的能力校核**（无载流、无信号可校）：Step 4 对本类只做"类别是否同属无信号"的比对，
**不查电气能力**；其唯一附加校验是 **§3.10 短路校核**（有多余端子时）。

| 对照 | 判定 | 是否计入 k |
|---|---|---|
| NM ↔ 候选**无端子**位 | 等价（两侧都无端子） | ❌ |
| **NM ↔ 候选有端子位** | **判等价**（悬空的端子无害），**但该端子必须通过 §3.10 短路校核**；短路则改判【不对应】 | ❌（不短路时） |
| **NC ↔ 候选有端子位** | 等价（都无信号） | ❌ |
| **NM 或 NC ↔ 候选位承载 PWR / GND** | 若候选该位引入电源 / 地网络 → 类别不对应 | ✅ |

### §3.7 逐位能力校核（Step 4 的判据）

| 位类别 | 候选必须满足 | 典型不覆盖情形 |
|---|---|---|
| PWR | **该位额定载流 ≥ 原设备该位实际电流**（取实测或设计值，含浪涌） | 电源位分散换到小电流位 |
| GND | 回流位数量 ≥ 原设计；每地脚载流覆盖 | 地位数减少 → 回流阻抗上升 |
| SIG | 无特殊要求，通常自动满足 | — |
| DIFF | **差分对的两位须相邻且为同一对**；不允许被拆到两个差分对 | 差分对被拆开 → 失效（**C8 品类下本项与 E10 为 AND 关系，E10 达标不掩盖拆对，见 §5b.3**） |
| HSIG | 阻抗连续性须由同系列保证（跨预算 ⟶ 见 §5b E10） | 换成不同 SI 等级的同 pin 数件 |
| SHLD | 屏蔽结构与接地方式须对应 | 屏蔽改非屏蔽：往往是致命但静态测试查不出 |

### §3.8 差异计数规则（k 的定义）

| 差异类型 | 定义 | 是否计入 k | 归入 |
|---|---|---|---|
| **① 命名差异** | 位号体系不同，但方位与内容一致（如对方按逆时针编号） | ❌ **不计入** | 报告可读性记录 |
| **② 规格差异** | 类别相同、能力覆盖，但值不同（如额定载流 3A vs 5A，均够用） | ❌ **不计入** | §5 / §5b 比对表 |
| **③ 类别不对应** | 类别不同（如 PWR ↔ SIG、DIFF ↔ NC、NM/NC ↔ PWR） | ✅ **计入 k** | 判 CP-B，转 §4 |
| **④ 电气角色不相容** | 类别相同但该位能力不足以覆盖需求（如 PWR 位仅 1A，需求 3A） | ✅ **计入 k** | 判 CP-B，转 §4 |
| **⑤ 多余端子短路**（§3.10 不通过） | 候选在原件空缺处 / 原 NM 处的端子与相邻网络短路 | **分两种**：<br>· 短路**仅涉未用位**（NM / NC / 空位）/ 悬空端子 / 无网络外壳 / **同网络冗余** / **一端已用一端未分配** → ✅ 计入 k<br>· 短路**连通两个本不连通的已用网络**（PWR / GND / 已分配的 SIG / DIFF / HSIG；定义见 §3.10）→ **不计入 k**（直接定档，见右列） | · 仅涉未用位 → 判 **CP-B**，转 §4<br>· 连通已用网络（**不限 PWR / GND**）→ **直接判 CP-C³（电气危害）**，不再进 CP-B |

**判定口诀：先看类别，类别相同再看能力是否覆盖。命名不同不是差异，规格够用後的余量差异也不是差异。**

**k = N − n。CP-A 的判据是 k = 0。**

**CP-C³ 档位下 k 不再是分档依据**：一旦第 ⑤ 类命中"连通已用网络"，直接落 CP-C³（见 §2.1 ⑤）；
此时**其他不对应位仍须逐位列出**（供改板方案），但**不计入 k 的统计口径**——`k` 只在 CP-A / CP-B 的分档中有效。

### §3.9 输出格式（强制）

```
【替换场景】S1 / S2 / S3（未声明则写"未声明，按 S1 从严"）
【品类】按 §0.1 的 C1–C8
【互配闸比对对象】候选 vs 原配对端（S1） / 候选两端之间（S2） / 不适用（S3）
【逐位结果】n/N 等价，k/N 不对应（N = 原件位数；候选多余位另列）
【配对端状态】S1 下原配对端是否已使用 / 已插拔次数（若有）；未知则注明"配对端状态未知"
【多余位清单】位号 + 是否落入空位区 + §3.10 短路校核结论（如有）
【不对应项明细】逐位列出：位号 / 原位类别与需求 / 候选位类别与能力 / 差异性质
【命名差异项】单列，不计入 k（如有）
【输入依据】原设备位定义来源（文件名 + 版本 / 日期）
```

**示例（自洽：7 + 1 = 8）**：
> 【替换场景】S1
> 【逐位结果】7/8 等价，1/8 不对应（N = 8，原件位数；候选 10 位 → 多余 2 位列于下方）
> 【不对应项】位 4：PWR（需求 3A）↔ PWR（额定 1A）—— **电气角色不相容**
> 【多余位清单】位 9、10：落入空位区，无信号引出，§3.10 校核无短路 → 不计入 n/N
> 【命名差异项】无
> 【输入依据】原线序表 `xxx_wirelist_v2.xlsx`（2026-09-11）

### §3.10 多余 / 空置端子短路校核（**独立强制项，不因 k = 0 而免除**）

**本项不属 §4**（§4 只对 CP-B 生效，而短路风险在 CP-A 上同样存在）。**必须独立执行，且 CP-A 输出中亦须给出一行结论。**

| 情形 | 校核内容 | 不通过后果 |
|---|---|---|
| 候选在原件空位 / 原 NM 处**有端子** | 该端子是否与相邻铜箔、相邻位、外壳短路；是否需飞线或绝缘处理 | 短路**仅涉未用位**（NM / NC / 空位）/ 悬空端子 / 无网络外壳 → 该位计【不对应】，计入 k，判 CP-B；**短路连通两个本不连通的已用网络（PWR / GND / 已分配 SIG / DIFF / HSIG，不限 PWR / GND）→ 直接判 CP-C³（电气危害），不计入 k** |
| 候选多余位引出信号 | 该信号是否悬空安全、是否改变网络 | 连通已用网络 → 判 CP-C³；仅涉未用位 → 计入 k，转 §4 |

**电气危害的判据（**核心是"上电即失效"，不限于 PWR / GND**）**：
按**原设备位定义表**判断短路所连的两个网络是否**均已分配使用**——
- **两个已用网络被短接**（电源短路、地短路、SIG↔SIG 活动网络短路、DIFF 对内 / 对间短路、HSIG 短路）→ 上电即短路 / 冲突 / 失效，**判 CP-C³**；
- **仅涉未分配位 / 悬空端子 / 无网络外壳**（NM、NC、空位之间）→ 无上电失效后果，**计【不对应】，计入 k，判 CP-B**。

**「已用网络」的操作定义（强制，§3.8 ⑤ 与本节共用；判定依据 = 原设备位定义表）：**

> **「已用网络」= 原设备位定义表中该位已分配具体电气功能（网络名 / 类别）、且该网络在原理图上有实际电气连接的网络**，
> 即 **PWR、GND、已分配的 SIG / DIFF / HSIG**。
> **判定以「是否实际连接」为准，不以「是否已给网络名」为准。**

**「同一网络」的判定口径（强制，防用地分割电路绕过 CP-C³）**：

判断两个位是否属**同一网络**，**以原理图的网络名为准，不以 PCB 上的实际连通为准**。
典型争议：**GND 与 AGND**（数字地 / 模拟地）即使在 PCB 上**通过 0Ω 电阻 / 磁珠 / 电容单点连接**，仍**视为两个不同的已用网络**。
**理由**：单点连接元件在生产中可能被**改值、换型、虚焊乃至省略**，把它们短接等于**取消原设计的分区与单点阻抗**，属电气危害。
因此：**候选件把 GND 位与 AGND 位短接 → 判 CP-C³**（不是 CP-B）。
**反向**：若位定义表本身就把两地标为**同一网络名**（如都标 `GND`），则属同一网络内的冗余短接，按「同网络冗余」行处理——**计入 k，判 CP-B**。

**GND ↔ SHLD 适用同一口径（强制，消除与下表的歧义）**：本对照表「GND ↔ SHLD 短接」行的"本就分离 / 本就连通"，**一律按原理图网络名判，不按 PCB 实际连通判**——
- 原理图标为**不同网络名**（`GND` 与 `SHLD`）**→ 本就分离**，**即使 PCB 上通过 0Ω 电阻 / 磁珠 / 电容连接** → 候选短接二者 **判 CP-C³**；
- **只有原理图本身就把两地标为同一网络名** → 才算"本就连通"，按**同网络冗余**处理：**计入 k，判 CP-B**。
**（下表最后一行「GND ↔ SHLD 短接」即本条的应用，两者同一口径，不需另找依据。）**

**「预留网络」的归属（强制，消解与 §3.6 `NC` 的张力）**：

原理图上给网络名**不等于**该网络「已用」——须看**是否实际连接**：

| 原理图标注 | 是否有实际电气连接 | 归属 | 是否「已用网络」 |
|---|---|---|---|
| 已给网络名，**且有实际连接**（连到某器件 / 某网络，哪怕该功能**当前未启用**） | 有 | 按该网络**实际类别**归 PWR / GND / SIG / DIFF / HSIG | ✅ **是** |
| 已给网络名，但**明确标注「预留」「NC 预留」「不贴」「DNP」**，且**当前无任何电气连接** | 无 | 归 **`NC`**（见 §3.6） | ❌ **否** |
| 标注「不贴 / DNP」但该网络**仍实际连到其他在用网络**（如预留位直接并到 PWR） | 有 | 按**实际所连网络**归类 | ✅ **是**（「不贴」指不装器件，不代表该网络孤立） |

> **「是否上电活动」不改变归属**——已分配、已实际连接但**当前暂未启用**的网络**仍属**已用网络；
> **表中确实无网络**的位（`NC`）或**无端子**的位（`NM` / 空位）**不属**已用网络。
> **禁止**：仅凭「原理图上给了网络名」就认定为已用网络（会把 `NC 预留` 位误当活动网络，导致无害短接被误判 CP-C³）；
> 也**禁止**：仅凭「标注预留 / DNP」就一律归 `NC`（若其网络实际连到在用网络，仍属已用网络）。

| 短接所连的两端 | 是否「连通两个本不连通的已用网络」 | 判定 |
|---|---|---|
| **两端均为未分配位**（NC↔NC、NM / 空位 / 悬空端子 / 无网络外壳之间） | ❌ 否 | 计【不对应】，计入 k，**判 CP-B** |
| **两端为同一网络的不同位**（如两个 GND 位之间、两位同属 PWR / 同一 SIG 网络） | ❌ 否（属**同网络冗余连接**，非"两个本不连通"的网络） | 计 k，**判 CP-B**（原为同网络，短接不产生上电失效） |
| **一端已用、另一端未分配**（如 PWR↔NC、GND↔NM） | ❌ 否（未构成"两个已用网络"） | 计 k，**判 CP-B**（把已用网络引到死点，属 §4 功能问题而非即失效短路）；**但若该多余端子还同时桥接另一个已用网络，则按下一行判** |
| **两端为两个**不同**的已用网络**（PWR↔GND、PWR↔SIG、SIG↔SIG 异网、DIFF 对内 / 对间、HSIG↔任意） | ✅ **是** | **上电即短路 / 冲突 / 失效 → 判 CP-C³** |
| **GND ↔ SHLD 短接** | **见上方「GND ↔ SHLD 适用同一口径」段** | 原理图**不同网络名** → 判 **CP-C³**；原理图**同一网络名** → 计 k，判 **CP-B** |

**要点**：判 CP-C³ 的关键是"**是否把两个原本电气隔离的已用网络接通**"，
**而不是"是否涉电源"**。同网络内的冗余短接、未分配位之间的短接，**均不构成**电气危害。

**电气危害（CP-C³）不可用「飞线 / 绝缘处理」在判定阶段消除**——那是改板方案的范畴，须先按 CP-C³ 出结论，改板后另行重判。

**"多出来的脚不用就行"不构成豁免。**

## §4 差异影响判断（CP-B 必做，**不得回写 §3**）

§3 判出 k > 0 后，才允许问「该差异是否阻断功能」。
**此问只能产出验证清单，不能产出「所以兼容」。**

### §4.0 强制产出物 —— 四栏缺一不可

| 栏 | 检查什么 | 数据来源 | 缺失后果 |
|---|---|---|---|
| **① 差异位的功能影响** | 该位换后出现什么**具体**后果（某路断电 / 差分不成对 / 屏蔽断开） | 原设备原理图 + 线序表 | → 差异影响未判定 |
| **② 外围与装配兼容性** | 端子压接/焊接方式、线径范围、屏蔽层处理方式是否仍成立 | 装配图 + 线材规格 + 压接规范 | → 差异影响未判定 |
| **③ 插合后保持与应力** | 插合后有无松脱风险、线材应力方向是否改变、是否需要新的应力消除 | 双方 datasheet + 装配图 | → 差异影响未判定 |
| **④ 电气应力与可靠性** | 该位电压 / 电流 / 温升是否超出候选额定；ESD、IP 等级、温度范围 | 双方 datasheet | → 差异影响未判定 |

> 注：**「多余端子是否短路」已移至 §3.10**，属 §3 强制项，本节不再承担（原 v1.0 将其列于本表第 ② 栏，
> 会造成"指派给一个只在 CP-B 才启动的节点"的循环，v1.1 已修正）。

### §4.1 四栏判定要点

**① 差异位的功能影响** —— 必须落到具体后果，不许写「可能影响」。
- PWR↔SIG：该路**带载能力骤降**，大电流时发热 / 压降超标
- DIFF 成员↔NC：差分对缺一，链路不通或误码率飙升
- SHLD↔NC：**屏蔽层悬空**，EMC 恶化 —— **静态功能测试查不出，EMC 测试才暴露**
- GND↔NC：回流路径减少，地弹与串扰上升

**② 外围与装配兼容性**
- 候选端子适用的**线径范围**是否覆盖现有线材（AWG 是关键约束）
- 压接 / 焊接 **工具与端子是否配套**（端子常需原厂专用压接工具）
- **不许推测**，须查装配图

**③ 插合后保持与应力**
- **锁紧「形式」的同类性已由 M7（§3.1）判定完毕——形式不同 = M7 ❌ = CP-C¹，不属本节**；
  本节只判**形式同类前提下的保持能力**：摩擦保持的保持力是否足够、卡扣多次插拔后是否失效、螺柱是否需加防松
- 锁紧形式虽同类但**保持能力退化**（如卡扣改用较软材质、保持力下降）→ **属本节差异影响**，须实测确认
- **振动场景下的松脱风险必须实测**
- 线材出线方向改变是否导致弯折半径不足
- **配对端磨损（S1 必查，见 §3.1.4）**：原配对端已插拔次数 / 磨损状态；磨损的配对端会使保持力、接触电阻劣化，须据此复核，不许默认全新

**④ 电气应力与可靠性**
- 逐位：最大电压 / 最大电流 vs 候选该位额定
- 全局：绝缘材料 CTI、耐压、**UL94 阻燃等级**、IP 防护等级
- 温度范围与 ESD 是否满足

### §4.2 结论生成规则

**四栏全部完成且均无阻断项** → 可写「**理论上不阻断，须实测确认**」。
**任一栏缺失或存在阻断项** → **只写「差异影响未判定」**，并列出缺哪一栏。

**禁止**：用某一栏结论替代四栏；在四栏未完成时写「基本能用」；把 §4 结论回写进 §3。

**CP-A 不进入本节**（k = 0，无可验证项）。
**⚠️ 未判定（§2）也不进入本节**（CP 档位未出，无可验证对象）。

> **与 §6.1 的口径一致性（强制）**：§6.1 的 CP-B 行**不再写死**"差异影响未判定"，
> 而是按本节的产出结果二选一：四栏全完成且无阻断项 → 「理论上不阻断，须实测确认」；
> 否则 → 「差异影响未判定（缺 [栏号]）」。**两处不得给出互相矛盾的措辞。**

### §4.3 验证清单格式

| # | 验证项 | 方法 | 判据（须量化） | 责任方 |
|---|---|---|---|---|
| V1 | … | … | 定量阈值 | 技术端 |

**写「测一下看看」「确认能用」不算验证项。**

### §4.4 输入版本变更的失效联动（**强制**）

§3 逐位判定与 §4 四栏检查均**依赖「原设备原理图 + 线序表」**。**线序表一旦换版本，下游结论不得沿用。**

**线序表版本变更（含位定义调整、位号重排、网络增删）后：**

| 必须动作 | 说明 |
|---|---|
| **§3.5 逐位判定必须重跑** | 旧版 n/N、k/N 作废；须基于新版线序表重算 |
| **§4 四栏结论自动失效** | 四栏全部须基于新版线序表重新填写，不得沿用旧版结论 |
| **变更记录须写明** | **新旧线序表版本号 + 差异位**（哪几位、原定义 → 新定义） |
| **§3.10 短路校核须重跑** | 位网络定义变了，短路判定随之变 |

**部分变更的处理（避免过度重跑，同时防止漏判）**：

| 变更范围 | 处理 |
|---|---|
| **仅部分位定义调整**（如仅位 5 的网络 / 类别变化；**位号未重排、网络无增删**） | **可只重跑受影响的位**：即 ① 该位本身；② 与之配对的 **DIFF 另一位**；③ **§3.10 短路校核所涉网络**（该位连着的新旧网络）。**未受影响位的旧版结论可沿用**，但输出中须**逐位注明**「基于线序表 vX.Y 的位 N 结论，未经 vX.Z 重跑」 |
| **位号重排**（位序 / 编号变化）或**网络增删**（网络表有新增 / 删除项） | **必须全表重跑**：§3.5 与 §4 四栏全部作废重填，**不得部分沿用** |

**「受影响位」的完整定义（强制，防漏位）** —— 部分变更时，须**同时**覆盖下列四类，**缺一不得算"已确定受影响集合"**：

| # | 类别 | 说明 |
|---|---|---|
| ① | **变更位本身** | 网络 / 类别被调整的那一位 |
| ② | **与变更位构成 DIFF 对的另一位** | 差分对成员须成对重跑（§3.7） |
| ③ | **与变更位共同构成同一电气功能的位** | 如 **PWR 位变更 → 与其并接的同一电源网络各位、与其构成回流路径的 GND 位**；位定义调整常牵动整组回流 / 供电网络 |
| ④ | **§3.10 短路校核所涉网络的所有位** | 该位**新旧**网络所连、可能因短路判定翻转而受影响的所有位 |

**第③类「同一电气功能」的判定口径（与 §3.10「同一网络」同一原则，强制）**：以**原理图网络名**为准。
`GND` 与 `AGND` 若原理图标为**不同网络名**，**不属「同一电气功能」**——变更 GND 位时，AGND 位**不进**受影响集合。
**例外**：原理图上**明确标注两者属同一网络条目**（如同一网络下并列标 `GND` / `AGND` 并注明单点连接）时才计入。
**仅凭 PCB 上有 0Ω 电阻 / 磁珠连接，不足以认定同属一个电气功能。**
**两处同原则但用途不同（防混）**：§3.10 用它判「短路是否构成电气危害」（可产出 CP-C³ 档位）；本处用它判「哪些位须纳入重跑集合」（**只影响集合，不直接产出档位**）。**同一对网络在 §3.10 可能判 CP-C³，在这里只是"纳入重跑"。**

**四类的重叠处理（强制，防"重复计入"与"误判为不完整"）**：
上表四类**可能相互重叠**（典型：PWR 位变更时，与其同电源网络的位既是 ③「同一电气功能」、也可能属 ④「短路校核所涉网络」）。
**重叠时取并集，不必去重**——重叠不影响"受影响位集合"的完整性，去重与否不改变须重跑的位清单。
**关键是不得遗漏任何一类**；若对某一位是否命中某一类**存疑 → 一律按命中处理**（保守取并集）。
**禁止**：以"该位已在 ③ 中列过"为由，跳过 ④ 的短路校核重跑。

**重叠位的重跑口径（强制，防把"只重跑一次"与"不得跳过 ④"读成矛盾）**：
**「只重跑一次」指的是"该位只列一次、只走一遍流程"，不是"只做其中一项"。**
**一遍流程 ＝ 两个动作，两个动作都要做**：① **§3.5 逐位判定**（该位的类别 / 能力 / 对应关系）；② **§3.10 短路校核**（该位新旧网络是否因短路判定而翻转）。
某一位同时命中多类时，上述两个动作**各做一次即可**，**该位在清单里只列一次**。
**「取并集」说的是"受影响位清单"取并集，不是"重跑次数"按类别累加。**
上文禁止句的意思是"**不得因该位已在 ③ 中列过，就不做 ④ 的短路校核**"，**不是"要按类别跑两遍"**。

**兜底铁律：若无法确定"受影响位"的完整集合 → 一律全表重跑，不得部分重跑。**
宁可多跑，不可因集合不全而漏判（③④ 两类最易被漏）。

**变更记录须逐位标注**：受影响位清单、未受影响位清单，以及**各自依据的线序表版本号**。

**禁止**：线序表换版后只更新一处、其余沿用旧版；凭"应该没影响"跳过重跑。
**本项属 §7.1 改判记录的必填输入变化**（依据文档版本/日期为必填项）。

## §5 降额闸 —— 载流与耐压

**与 PPJ 的最大差别：连接器的额定载流随温度升高而下降，降额是常态而非例外。**

### §5.1 载流降额

**公式**：占用率 = **实际工作电流** ÷ **实际工作环境温度下的额定载流**；**阈值 ≤ 80%**

**数据来源必须是「降额曲线 × 实际温度」的取值，不是 datasheet 首页的常温值。**

| 数据情况 | 判定 |
|---|---|
| 厂商给了降额曲线（current rating vs ambient temp） | 按**实际最高工作环境温度**查表取值再算占用率 |
| 只给了单一温度下的额定值，**无降额曲线** | ⚠️ **数据缺失** |
| 给了额定值但**温度条件不明** | ⚠️ **数据缺失** |

**禁止**：用常温（通常 20–25°C）额定值去判定高温（如 70°C 机内）工况。

### §5.2 群组降额（多条位同时带载）

多根相邻针脚同时通电会**互相加热**，总载流不可简单相加。

**首选判据**：按厂商**群组降额系数**（group derating factor / multiple-contact derating）折算。

**保守兜底（厂商未给群组系数、但给了单针降额曲线时）—— 不得直接记 ⚠️**：

很多连接器 datasheet 给了单针降额曲线，却没给群组降额系数。此时**不得直接标 ⚠️ 数据缺失而不做任何估算**，须按下列保守规则折算后再判：

| 相邻同时带载针脚数 | 群组降额系数（保守值） |
|---|---|
| 2–3 针 | × 0.80 |
| 4–6 针 | × 0.75 |
| ≥ 7 针 | × 0.70 |

- **「相邻同时带载针脚数」的计数规则（强制）**：
  1. **同一排内，连续带载的针脚视为一组**；取**各组中针数最多者**作为该排的计数值。
  2. **非连续带载（中间有间隔）的针脚不合并计数**：如第 1、2 针带载、第 3 针空、第 4、5 针带载 → 该排计 **2 针**（两个 2 针组，取最大 2），**不得**按 4 针计。
  3. **多排同时带载时，取各排计数值中的最大值**（取最不利排）；**若上下排位置对应且同时带载**（热场叠加），
     **加严一档**（如 3 针 ×0.80 → 按 4–6 针 ×0.75），并标注「**多排叠加，保守加严**」。
- **「加严一档」的跨档规则（强制，防跨档时无定义）**：
  - 「加严一档」= **向更严的针数档位**移动一档，**档位序列为** 2–3 针（×0.80）→ 4–6 针（×0.75）→ ≥7 针（×0.70）；
  - **6 针 ×0.75 加严一档 → 按 ≥7 针 ×0.70**；**3 针 ×0.80 加严一档 → 按 4–6 针 ×0.75**；
  - **≥7 针档为下限，不再继续加严**（×0.70 已是最严档位，不得再自创更小系数）；
  - **加严只加一档，不叠加**（不因"双排对应 + 三排对应"而连加两档）。
- 折算结果用于**占用率**计算（占用率 ≤ 80% 仍守 **§5.1** 阈值）。
- **必须标注**「**保守估算**（系数来源：行业通行保守值，**须技术端确认**）」，并登记在缺口清单。
- 结论档位**最高只能「有条件通过」**，**不得「可直接替」**；**实测方案（§6.3）必须包含群组同时载流的温升实测**。

**厂商连单针降额曲线也未给** → 仍记 ⚠️ **数据缺失**（无任何折算起点，属 §5.4 的"数据缺失"）。

### §5.3 耐压降额

**公式**：占用率 = 工作电压（含浪涌峰值）÷ 额定耐压；**阈值 ≤ 80%**
**须同时核 爬电距离（creepage）与电气间隙（clearance）**，尤其中高压场合。

### §5.4 降额闸的状态取值

**降额闸只有三态：✅ 过 / ❌ 不过 / ⚠️ 数据缺失。**
**本闸没有「⚠️ 待实测」这一取值**（与可靠性闸 §5b 不同，措辞不得混用，见 §6.0）。
**本闸也没有「⬜ 不适用」**——载流与耐压对任何连接器都适用，不得以"不适用"回避。

| 降额闸 ⚠️ 的含义 | 来源 | 结论档位 |
|---|---|---|
| **数据缺失**（无降额曲线 / 温度条件不明） | datasheet 无该项 | **只能「需评估」**，**禁止**「有条件通过」 |

**降额闸为 ⚠️ 或 ❌ 时，均不得进入「有条件通过」**（§6.2）。
原因同 PPJ：**载流与耐压是安全问题，不许挂条件。**

**本闸只管"安全余量"，不管"可靠性"。** 可靠性由 §5b 独立判定，两者 AND 且**不互相抵消**。

**CP-A + 降额通过 + 本闸不过 → 结论仍不是「可直接替」。**

### §5b.1 必比参数清单

> **适用性分级**：**E1–E9、E11、E13 为全品类必比项**；**E10 仅高速场景必比**；**E12 仅 FFC/FPC 品类（C4）必比**。
> 不适用时记 **⬜ 不适用**（见 §6.0，不是 ⚠️），**不得留空**；**"不适用"仅限 E10 / E12 两项**，E1–E9 / E11 / E13 **一律不得记不适用**。

### §5b.2 比对纪律

- **每个数必须带三标签**：① 环境温度 ② 测试电流/电压条件 ③ 寿命阶段（初始 / N 次后）
- **初始只对初始，寿命后只对寿命后**，混比无效
- 同一颗料有多张额定表 → **须写明取自哪一张**（不同线径 / 不同位数常给不同载流）
- 对方没给的条件 = **缺口**，不许用相邻条件值代填

### §5b.3 品类决定权重（**判定前必须先定品类，口径见 §0.1**）

| 品类（§0.1） | 第一致命 | 次要 | 常被误当成瓶颈的项 |
|---|---|---|---|
| **C1 板对板（B2B）** · 无锁扣 | **振动下拉脱 / 焊点疲劳**、插合高度 | 共面度、保持力（E6） | 接触电阻绝对值（E1） |
| **C2 线对板（W2B）** · 带锁扣 | **防呆（§3.1.2）+ 锁扣失效 + 拔出力（E6）** | 端子保持力、线材应力 | 同 |
| **C3 线对线（W2W）** | **防松 / 锁紧可靠性（E6、E8 振动下瞬断）+ 拔出力 + 线束应力** | 端子保持力、密封等级（若有） | 接触电阻绝对值（E1） |
| **C4 FFC/FPC** | **锁扣形式（翻盖 / 抽屉 / 后掀）+ 插合方向 + 厚度（E12）** | 接触区长度、插拔寿命（E5） | pitch |
| **C5 圆型 M8/M12** | **编码（A/B/D 码）+ 螺纹规格 + IP 等级（E9）** | 载流（§5）、屏蔽 | 位数 |
| **C6 标准接口件（RJ45 / USB / HDMI）** | **屏蔽接地结构 + 镀层厚度（E11）+ 载流（§5）** | SI 特性（E10） | 外形尺寸 |
| **C7 大电流 / 电源端子** | **载流降额（§5）+ 温升（E7）+ 压接可靠性** | 拔出力（E6） | 接触电阻（E1） |
| **C8 高速差分连接器** | **E10 阻抗连续性与插损**（**与 §3.7 DIFF 相邻性为 AND，见下**） | 差分对相邻性（§3.7） | 位数与 pitch |

**权重只影响"先看哪项"，不改变"必比项缺一不可"的规则。**
**本表必须覆盖 §0.1 的全部品类（C1–C8），不得缺行**；新增品类时本表同步增行。
**E13（环保合规）为全品类准入项，任一品类均不得因权重低而跳过。**

**C8 品类下 §3.7 DIFF 相邻性与 E10 的关系（强制，防"E10 过即掩盖拆对"）**：
C8 品类下，**§3.7 的 DIFF 相邻性规则（属 §3.5 逐位判定）与 E10 的 SI 规则是 AND 关系，不得互相抵消**：
- **差分对被拆开**（两位不相邻 / 被拆到两个不同差分对）→ **§3.5 判 k > 0 → CP-B**，
  **不得因 E10（阻抗 / 插损）达标而把此差异降格为 CP-A**；
- **E10 只判 SI 特性（阻抗 / 插损 / 回损 / 串扰）是否达标，不判差分对是否被拆开**；
- 两者**各自独立**，**任一不过都不得输出「可直接替」**；同时不过则**两条理由都要写**。

### §5b.4 可靠性闸结论

| 情况 | 判定 |
|---|---|
| E1–E13 中**全部适用项**满足 | ✅ 过 |
| 任一项**已核实**不满足 | ❌ 不过 |
| 任一项**一方未给**（E13 除外） | ⚠️ **待实测**，不得记「过」也不得记「不过」 |
| **E13（环保合规）未给合规文件** | ⚠️ **待实测（准入缺失）** —— **本项 ⚠️ 不得进入「有条件通过」，只能进「需评估」**；准入项缺文件 = **无法准入**，不是可挂条件的待测参数 |

**E13 为准入项，与其余 E# 的 ⚠️ 语义不同**：其余 E# 的 ⚠️ 是"参数待测"（可挂条件实测后放行）；
**E13 的 ⚠️ 是"不具备准入资质"**——须**补齐合规文件**方可准入，**不得以"先有条件通过、后补 RoHS 报告"处理**。

**禁止**：把「未给」记为 ✅ 或 ❌；⚠️ 不给实测方案（§6.3，缺失则本轮判定未完成）。

**⚠️ 升级为 ✅/❌ 的唯一途径：实测出数，或原厂补发数据（E13 为补发合规文件）。**

## §6 结论合成规则

**结论只由 §6.1 查表生成，不得在表外生成。**

### §6.0 闸状态与各闸的 ⚠️ 口径（**不得混用措辞**）

**闸状态共四态**（含「不适用」）：

| 状态 | 含义 | 何时用 |
|---|---|---|
| **✅ 过** | 已核实数值满足判据 | 两边都有数据，候选优于 / 等于原件 |
| **❌ 不过** | 已核实数值不满足 | 两边都有数据，候选劣于原件 |
| **⚠️** | 数据缺失 / 未判定 / 待实测 | 任一方未给该参数，或缺输入文件 |
| **⬜ 不适用** | 该闸按定义**本就不参与本次判定** | 非"缺数据"，而是"该类项不适用于本场景 / 本品类" |

**⚠️ 不得记为「过」或「不过」。** 缺数据记为合格或不合格均属错记。
**⬜ 不适用 ≠ ⚠️**：**不得把"没数据"写成"不适用"来回避取证**，也不得把"不适用"写成"⚠️"。

**允许记「⬜ 不适用」的完整清单**（除此以外一律不得用不适用）：

| 项 | 条件 |
|---|---|
| **互配闸 M1–M8（整闸）** | **仅 S3**（配对端未定，无互配对象） |

**S3 的后果（写进输出）**：互配闸整闸不适用 → **"可插合"这一前提未被验证**，
故 S3 的结论**只覆盖「可安装 ∧ 逐位电气等价」，不得表述为"可插合"或"可直换"**（见 §6.1 S3 行）。

| **CP-C¹（插不进 / 装不上 / 无编带等 A1–A6 不过 §3.2）** | — | — | **不可直换**；若可改线 / 改板 / 改包装工艺使用 → 改列对应方案（见附则）。其中 **A5（无编带）属「改包装 / 改工艺方案」出口**（措辞：CP 判定为 CP-C¹（不可安装：无编带）＋ 改工艺方案：×× 工序可解）；**改工艺不抹掉 CP-C¹、不升档** |

**多行同时命中的处理（强制，防漏附实测方案）**：

一次判定**可能同时命中多行**（典型：**§5.2 群组降额保守兜底** 与 **可靠性 ⚠️ 待实测** 同时成立 → 同时命中本表第 2 行与第 3 行）。此时：

1. **档位取各行中最严者**（三档严宽序：可直接替 > 有条件通过 > 需评估）。
2. **各行要求须并列满足，不得只按其中一行输出。**
3. **两行同时命中且档位同为「有条件通过」时，两套实测方案都要附**：既附「**群组同时载流温升实测**」（§6.3），又附**对应 E# 的实测方案**（§6.3）；**措辞须同时列出两项待实测内容**（例：「待实测：① 群组同时载流温升（因群组降额系数为保守估算）；② [列明 E#] 可靠性项」）。
4. **取最严档位为「需评估」时，其他行的实测方案不必附**——「需评估」的含义是**须先解决缺陷 / 补齐输入**（§6.2），实测方案在该档位下无实际意义（E13 缺文件时，测得再准也不能准入）。
   **但须在输出中留一句后续提示**：「若解决 [最严行的缺陷 / 缺口，如 E13 合规文件] 后重跑，还须附 [其他行的实测方案，如群组同时载流温升实测]」——**提示是给重跑用的，不是本轮的方案**。

**禁止**：只按命中的其中一行输出；只附其中一套实测方案；或按"较宽的一行"取值。
**禁止**：档位已是「需评估」却仍把其他行的实测方案写成已附齐（会给人"只差实测"的错觉，与"须先解决准入 / 缺陷"矛盾）。

**示例（CP-B ＋ 群组兜底同时命中）**：档位取最严 = **「需评估」**；**措辞须同时体现两项、并列输出（不是"以某行为主"）**：① **CP-B 行的差异影响结论**（四栏：理论上不阻断 / 未判定缺哪栏）；② **群组兜底的后续提示**（"若差异影响经实测确认不阻断、且重跑后成立 CP-A，仍须附群组同时载流温升实测"）。
**示例（群组兜底 ＋ E13 ⚠️ 同时命中）**：档位 = **「需评估」**（E13 是准入项），**群组温升实测本轮不附**，措辞并列列出：① E13 准入缺失（须补 RoHS / REACH）；② 后续提示"补齐合规文件后重跑，仍须附群组同时载流温升实测"。

**任何一闸为「❌ 不过」，最高只能是「需评估」。**
**降额不过 + 可靠性不过 → 两条理由都要写。**

**「⚠️ 未判定」不得掩盖已核实的 ❌（强制，防已查实的安全项被"未判定"吞掉）**：
"未判定"只覆盖**无从判定**的那一部分闸；若**同时另有闸已核实为 ❌**（如降额闸实测占用率 95%），
则**该 ❌ 必须并列输出**，措辞为「**需评估 —— [闸名] 不过（已核实：[具体数值]）＋ [闸名] 未判定（缺 [输入文件]），两条并列**」。
**禁止**：因某闸未判定，就只写"需评估 —— 未判定"，把已核实的 ❌ 省略掉。

**与「多行同时命中」的交互（强制）**：若同时存在**「已核实 ❌」＋「⚠️ 未判定」＋「群组降额保守兜底」**等**三种及以上**情形 →
① **档位按最严取**（本例为「需评估」）；② **并列列出全部已核实的 ❌**（各写具体数值）**与全部未判定项**（各写缺哪份输入）；
③ **群组兜底的温升实测方案按上文第 4 条处理**——最严档为「需评估」时本轮不附，但在后续提示中列出「解决 [X] 后重跑仍须附群组温升实测」。

### §6.2 「有条件通过」的严格定义

**成立条件（三条全满足）**：
1. **CP-A**（k = 0，§3 全过）
2. **降额闸 ✅ 过**（不接受 ⚠️ 数据缺失；**若采用 §5.2 群组降额保守兜底估算，仍属"过"，但须附群组温升实测方案**）
3. **可靠性闸内无 ❌ 不过项**，仅有 ⚠️ 待实测项，**且 ⚠️ 项中不含 E13（环保合规）**

**E13 例外（强制）**：**E13 为准入项，其 ⚠️ 不得进入「有条件通过」，只能进「需评估」。**
准入项缺文件 = **无法准入**，不是"待实测后挂条件放行"；须补齐 RoHS / REACH 文件后方可重跑（见 §5b.4）。

**必须同时写明（缺一即降级为「需评估」）**：
- 待实测的**具体参数编号**（E#）
- 该参数的**判据方向**（须 ≤ 原件 / 须 ≥ 某阈值）
- **实测方案**（§6.3）
- **实测前的动作约束**：**不得下批量订单**（可送样、可小批试产，须明示）
- **采用群组降额保守兜底时（§5.2）**：须附「**群组同时载流温升实测**」方案（§6.3），并写明**系数来源**与「**须技术端确认**」（否则不得进本档位）

**不成立的情形**：降额 ❌/⚠️ ｜ 可靠性有 ❌ 项 ｜ **可靠性 ⚠️ 项含 E13** ｜ CP-B / CP-C（含 C¹ / C² / C³）｜ ⚠️ 未判定 ｜ 待实测项无实测方案。

**「配对端磨损未知」的 ⚠️ 属可挂条件（强制口径）**：
§3.1.4 因**原配对端磨损状态未知**导致的 E2 / E5 / E6 / E7 ⚠️，**与普通待实测项同性质，可进「有条件通过」**
（**不属** E13 的不可挂条件类，不受上一段"含 E13"的限制）。
但须**额外**满足两条：① 实测方案（§6.3）**含原配对端状态检查**；② 动作约束**另写明**「**不得批量下单，须先确认原配对端状态**」。

**三个输出档位的严格定义（强制 —— 与 CP 档是两回事，不得混用）**：

| 输出档位 | 成立条件（全部满足） | 含义 / 可做与不可做 |
|---|---|---|
| **可直接替** | ① **CP-A**（k = 0）② 降额闸 **✅ 过**（**非保守估算**）③ 可靠性闸**全部适用项 ✅ 过** ④ **已取得盖章数据**（§1.1） | 可称 pin-to-pin，**可下批量订单**。四条缺一即降档，**不得凭"估计没问题"给本档** |
| **有条件通过** | ① CP-A ② 降额闸 ✅ 过（**不接受 ⚠️ 数据缺失；若采用群组降额保守兜底估算，仍属"过"，但须附群组温升实测方案**，§6.1 第 2 行）③ 可靠性闸无 ❌ 项、仅 ⚠️ 待实测（**不含 E13**）④ 附实测方案（§6.3）+ 动作约束（不得批量下单） | **尚未可直接替**：机械与安全余量已确认，**只差实测数据**；实测通过即可升为「可直接替」 |
| **需评估** | **其余一切情形的兜底档**：存在已核实的缺陷 / 差异 / 降额问题（含各闸 ❌），**或**关键输入缺失（⚠️ 未判定、降额 ⚠️ 数据缺失、E13 准入缺失、无盖章数据、**群组降额仅保守估算且未附群组温升实测方案**） | **须先解决问题或补齐输入**，再谈实测与时序。**不得表述为"可以先试一下"**，也不得暗示"问题不大" |

**三档组合判定顺序（强制，防把「群组降额保守估算」当成独立档位条件）**：

**群组降额保守估算（§5.2）本身不决定档位**，它只做两件事：① **排除「可直接替」**（保守估算不是厂商给的系数）；② **触发"须附群组同时载流温升实测方案"**。**最终档位由其余闸的状态决定**：

| 群组降额 | 可靠性闸 | CP 档 | **最终档位** |
|---|---|---|---|
| 保守兜底 **＋ 已附**群组温升实测方案 | 无 ❌、仅 ⚠️（**不含 E13**） | CP-A | **有条件通过** |
| 保守兜底 ＋ 已附方案 | **有 ❌**，或 ⚠️ **含 E13** | CP-A | **需评估** |
| 保守兜底 ＋ 已附方案 | 任意 | **非 CP-A**（CP-B / C / ⚠️ 未判定） | **需评估** |
| 保守兜底 **＋ 未附**群组温升实测方案 | 任意 | 任意 | **需评估**（方案不完整即降级） |
| **降额闸 ⚠️ 数据缺失**（无载流 / 耐压曲线，或温度条件不明） | 任意 | 任意 | **需评估（一律）** |

**否决项（优先于上表所有组合）**：**降额闸一旦为 ⚠️ 数据缺失 → 一律「需评估」**（§5.4：降额闸没有「待实测」态，⚠️ 不得进入「有条件通过」）。
**群组降额走保守兜底 ≠ 降额闸整体为「过」**：保守兜底只解决**群组系数缺失**；若**耐压降额数据缺失**、或**连单针载流曲线也没有**（那连兜底都无从折算），降额闸仍是 ⚠️ 数据缺失，仍须「需评估」。
**禁止**：因为"群组降额有保守系数了"就跳过耐压降额与温度条件，把降额闸记成「过」。

**读法**：**只有「CP-A ＋ 可靠性无 ❌ 仅 ⚠️（不含 E13）＋ 已附方案」这一条组合才给「有条件通过」**，其余组合一律「需评估」。
**禁止**：把"已附群组温升实测方案"读成「有条件通过」的**充分条件**（漏掉 CP-A 与可靠性两个前提）。

**三档与 CP 档的关系（强制，最易混）**：
- **CP 档（§2）回答"是不是 pin-to-pin"**（可插合 ∧ 可安装 ∧ 逐位等价）；
- **输出档（本表）回答"这料现在能不能用"**。
- **CP-A ≠ 可直接替**：CP-A 仍可能因**可靠性 ⚠️ 待实测**、**群组降额仅保守估算**、**无盖章数据**而只到「有条件通过」或「需评估」。
- **CP-B / CP-C（C¹/C²/C³）/ ⚠️ 未判定 一律不可能「可直接替」**（§6.1）。

**判别口诀：「有条件通过」≠「可以先替了看看」。**

### §6.3 待实测项的方案格式（强制）

| 参数 | 测什么 | 怎么测 | 通过判据 | **样品数量** | 责任方 | 期限 |
|---|---|---|---|---|---|---|
| E2 寿命后接触电阻 | 500 次插拔后的接触电阻 | 按 IEC 60512 方法插拔后测四线法 | ≤ XX mΩ（原件同条件下 YY mΩ） | **≥ 3 颗** | 技术端 | 送样后 X 周 |

**样品数量为必填列，缺即方案不完整。** 连接器存在**批次一致性**，测 1 颗与测 30 颗的结论置信度不同。**最低要求（缺省值）**：

| 实测类别 | 最低样品数量 |
|---|---|
| **接触电阻 / 插拔寿命 / 端子保持力类**（E1、E2、E5、E6） | **≥ 3 颗** |
| **振动 / 冲击 / 机械寿命类**（E8） | **≥ 5 颗** |
| **温升 / 载流 / 群组降额类**（E7、§5 降额） | **≥ 3 颗** |
| **环境 / 腐蚀类**（E9） | **≥ 3 颗** |
| **绝缘 / 耐压类**（E3、E4） | **≥ 3 颗** |
| **镀层 / 厚度 / 高速特性类**（E10、E11、E12） | **≥ 3 颗**（**E11 若走切片 / 金相法，属破坏性，须独立备样**，见下表） |

**E11 的双重要求（强制，防把"≥ 3 颗"与"独立备样"混为一谈）**：

**E11（镀层类型 + 厚度）若走切片 / 金相 / 剖切法**：最低样品数量 **≥ 3 颗（按上表）**，**且须独立备样**。
「**≥ 3 颗**」与「**独立备样**」是**两个独立要求，须同时满足**：前者定**数量下限**，后者定**批次归属**，**不互相替代、不互相减免**。
独立备样**不得与 E5+E2 组共用、不得与 E8 独立组混用、不得加入非破坏性复用组**（三组分开登记，见本节末）。
**E11 若走 XRF / 电镜等无损法**：按非破坏性规则**可复用**，最低数量仍 **≥ 3 颗**；**报数时须注明所用法别**（同一批 E11 结论不得以无损法样本数冒充切片法样本数）。
**无损法为什么也要 ≥ 3 颗（强制，防被"可复用"带偏）**：≥ 3 颗取的是**批次一致性覆盖**——连接器镀层厚度存在批间差异，测 1 颗代表不了这一批。
**「可复用」指同一颗样品可依次测多项**（如 E11 ＋ E1 ＋ E3），**不指"可复用就能少测"**。
**禁止**：以"样品可复用"为由把 E11 的最低数量降到 1 颗；也禁止用同一颗的多次读数充当多颗样本数。

**破坏性 / 非破坏性测试的样品使用规则（强制）**：

| 类别 | 测试项 | 样品使用规则 |
|---|---|---|
| **破坏性测试（独立备样）** | **E8（振动 / 冲击 / 机械寿命）** | 样品**不得复用**，须按上表最低数量**独立备样**；同一颗测完 E8 **不得**再用于其他项 |
| **破坏性测试（同批共用）** | **E5（插拔寿命）→ E2（寿命后接触电阻）** | E2 与 E5 **共用同一批样品**（见下），**不各自独立备样**；该批样品测完 **不得**再用于其余任何项 |
| **非破坏性测试** | **E1、E3、E4、E6、E7、E9**（**E11 无损法不在本行归属，见下行「方法相关」**；此处仅说明其无损分支可与本行各项同颗依次测量） | 同一颗样品**可依次测量多项**，但须确保**前一项测试不改变后一项的测量条件**（如 E7 温升测试后须恢复至室温再测 E1）。**「≥ 3 颗」是样品数量下限，「可依次测多项」是同一颗的复用方式，两者不冲突**——即**取 3 颗，每一颗都依次测**。**若 E11 走无损法**，可与其他非破坏性项同颗依次测量（如 E11 → E1 → E3）；**E11 的归属与样品规则以「方法相关」行为准**（无损法归非破坏性分支、切片 / 金相法归破坏性分支） |
| **方法相关（按测法定性质）** | **E11（镀层类型 + 厚度）** | **XRF / 电镜等无损法 → 非破坏，可复用**；**切片 / 金相 / 剖切法 → 破坏性，须独立备样**，**不得复用、不得与 E5+E2 组混用**。**报数时须注明所用法别**（同一批 E11 结论不得以无损法样本数冒充切片法样本数） |

**E2 与 E5 的样品共用规则（强制，消解"E2 取自 E5 后同批"与"E2 独立备样"的冲突）**：

**E2 与 E5 共用同一批样品**——先取 **≥ 3 颗**样品完成 **E5**（插拔至规定寿命节点），**再在同一批样品上测 E2**（寿命后接触电阻）。
**E2 不另取新样品**；但 **E5 的备样数须同时满足 E2 的最低数量要求**（即 E5 备样 **≥ 3 颗**，测完 E5 后**全部**用于 E2）。

即：**E2 与 E5 是一个「样品组」（同批、先 E5 后 E2），不是两个独立备样组**；须与 **E8 的独立备样组**分开登记。
**样品数量报数时须区分批次**：**E5+E2 共用组、E8 独立组、非破坏性复用组三组分开登记**，**不得把复用的同一颗计成多颗**。

**可按品类细化**（细化入口：**本表 + 品类扩展文件**），但**不得低于上表缺省值**，也**不得以"样品不足"为由免测**。
**注**：**§5b.3 只定"先看哪项"的权重，不含样品数量**——原 v1.5 写"可在 §5b.3 中细化"，指向该表属**悬空指针**，v1.6 已修正为指向本表与品类扩展文件。

**判据禁止写「符合要求」「与原件相当」** —— 必须可量化。
**若缺基准值**（如原件未给），写「先测候选件绝对值，并同时测一颗已知合格参照件建立基准」，**不许因缺基准就放弃该项**。

## §7 改判与改标准纪律

| 允许 | 禁止 |
|---|---|
| 发现新事实（新版 datasheet、实测数据、客户提供的新线序表）→ 更新输入值后重跑 | 凭"重新想了一遍"改判 |
| 发现标准本身有漏洞 → **改标准全文** | 同一批输入值下改判 |
| 客户提出新判定口径 → 先改标准，再重跑 | 口头改判、不留痕 |

**每次改判必须能回答：新增/变化的是哪一个具体输入值（哪份文档、哪一页、哪个数值）。**
答不出来 = 是在改判，不是在判定。

### §7.1 改判记录必填项

| # | 必填 | 示例 |
|---|---|---|
| 1 | **判据项** | `M6 防呆结构` / `位 4 载流能力` / `E5 插拔寿命` |
| 2 | **旧值** | `双方键位一致 → 同构` |
| 3 | **新值** | `候选缺第 2 键位 → 可错插` |
| 4 | **旧档位 → 新档位** | `CP-A → CP-C` |
| 5 | **依据文档 + 版本/日期 + 页码** | `JAE XX series Drawing Rev.C, sheet 2, 2026-08-11`<br>**标准改版导致的改判** → 写**现行版本号**（唯一有效版本，见 §7.2）；**输入文件变化** → 写 `datasheet 名称 + 版本 + 页码`；**两者同时发生** → 两者都写，不得只写其一<br>**职责边界**：§7.2 的「标影响范围 ＋ 受影响在办判定重跑」是**标准维护者改版时**的动作；§7.1 是**判定者在个案中**的动作。判定者**只需在改判记录中注明现行版本号**，改版处置本身由标准维护者按 §7.2 执行 |
| 6 | **变更类型** | 新增事实 / 修正读数 / 改判据口径 |
| 7 | **触发人 + 日期** | `用户，2026-10-05` |
| 8 | **已重跑全表**：是 / 否 | — |
| 9 | **下游影响** | `降额闸连带从 ✅ 改判 ⚠️，结论档位不变` |

**改判记录一律追加，不得覆盖或删除。**

### §7.2 标准改版的处置规则（**版本变更后，已出 / 在办判定怎么办**）

> **定稿说明（自本版起进入稳定期）**：本标准自本版起进入稳定期。后续修订**仅限重大变更**（新增品类、判据口径变更、档位定义变更）；**日常边界情形的澄清以「附录：待澄清事项」形式累积，不单独发版**——澄清条目**不改变现行版本号**，随下一次重大变更一并纳入正文。
> **判据（防"以澄清之名改判据"）**：澄清只解决"边界怎么判"；**一旦某条澄清实际改变了判据阈值或档位归属，它就不是澄清，而是重大变更** → 须按 §7.2 处置并递增版本号。

> 与 §7.1 的区别：§7.1 记「某次判定的输入值变了」；本节记「**标准本身改了，已出结论怎么办**」。
> **本标准不设逐条修订流水记录**——修订历史与判定无关；只保留**现行版本号**（见文件头）及其对已出结论的**处置规则**。

**改版本的影响范围与重跑要求（强制）**：

**版本号只有一个有效值 —— 现行版本号（强制口径）**：本标准**同时只有一个有效版本**，即文件头声明的现行版本号；**历史版本一律不再作为有效口径**，任何新判定、新交付**默认且只能按现行版**。
**引用旧结论时不写旧版本号**，统一写「**本结论出自旧版，须按现行版复核**」——这样既保留"可能已过时"的提示，又不制造"多个版本并行有效"的错觉。
**禁止**：在输出中并列罗列多个版本号、或以"按某旧版判定"为由回避按现行版复核。

| 修订性质 | 对已出 / 在办判定的处置 |
|---|---|
| **改判据口径 / 档位定义**（如触发判据由窄改宽、某闸不过的后果被修正） | ① 修订时**必须写明影响范围**（涉及哪些闸 / 哪些品类）；② **受影响的在办判定须按新版重跑**；③ 已交付的判定**不必一律作废**，但**再次引用时须按现行版复核**；结论出自旧版的，**写「本结论出自旧版，须按现行版复核」**，必要时应主动提示"口径已变" |
| **补漏 / 补强**（新增定义、新增输出项，不改变既有判据结论） | **无需重跑**。**若本次补漏 / 补强新增了输出必含项**（如新增「所依据的标准版本号」这类必含项）：已出结论再次引用无需重跑，但**再次对外交付时须按现行版格式补全必含项**（如补注现行版本号）；**仅内部引用**可只口头说明。**「补全必含项」的范围＝仅限无需重新判定即可补填的格式项**（标准版本号、输出日期、判定人等）；**若新增的必含项须重新判定才能填写**（新增闸状态、新增位比对项等），**该结论须按现行版重跑，不适用"补全"**。**判据（怎样算"需要重新判定"）**：看该必含项的值**是否依赖本次判定的具体输入值**——**依赖**（某闸状态、某位比对结果、某 E# 实测值、k 值）→ **须重跑**；**不依赖**（标准版本号、输出日期、判定人）→ **可补填** |
| **仅文字 / 排版修正** | 不影响任何结论，无需处置 |

**「补漏 / 补强」与「改判据口径」的边界（强制，防两行都像）**：
- **只增加输出项 / 定义 / 说明，不改变任何既有闸的判定阈值、档位归属或结论措辞** → 归「**补漏 / 补强**」；
- **改变了任何既有闸的判定阈值、档位归属或结论措辞**（哪怕只是把措辞改严）→ 归「**改判据口径**」。

**两行重叠或难以区分时，按更严的一行处理**（即按「改判据口径」：标明影响范围 ＋ 受影响的在办判定重跑）。
**例**：新增「短路校核结论」这类**依赖本次输入值**的输出项——形式上是补漏，但旧结论不补即失真，**实务上按「改判据口径」处理**。
**「按改判据口径处理」的含义**：该修订**兼有两重性质**——形式上是「补漏 / 补强」（新增输出项），后果上等同「改判据口径」（旧结论失真）。
**处置时按更严的一行执行**（标明影响范围 ＋ 受影响的在办判定重跑）；**但「补漏 / 补强」行的「已出结论再次引用无需重跑」仍适用于未受影响的部分**（即：只重跑受影响的，不必全部作废）。

**任何判定输出均须写明所依据的标准版本号**（见 §6.4 第 18 项；**唯一有效值＝现行版本号**）——**未注明版本的结论视为不可追溯**。

## 附则：Pin-to-Pin（CP）判定与「改线方案 / 改板方案 / 改包装工艺方案」的分工

Pin-to-Pin 判定只回答「**不改线、不改板、不改装配工艺**」能不能换。改线 / 改板 / 改工艺是另外三条路径。

| | Pin-to-Pin 判定 | **改线方案** | 改板方案 | **改包装 / 改工艺方案** |
|---|---|---|---|---|
| 前提 | 不改线不改板不改工艺 | **可改接线序**（多为线端） | 需改板 / 换配对端 | **可改装配工艺或包装形态**（如无编带件改人工贴装 / 另配托盘 / 追加二次编带） |
| 输出 | CP-A / CP-B / CP-C | 改哪几根线 + 可行性 + 工时量级 | 改板可行性 + 改哪里 + 成本量级 | **改哪一道工序 / 换什么包装 + 可行性 + 成本与产能影响** |
| 分界 | 存在不对应即为 CP-B，不许摇映射 | 靠改线才达成对应 → **走改线方案** | 装不上 / 连不上 → 走改板 | **机械与电气均成立、仅装配工艺或包装不匹配（典型：§3.2 A5 无编带）→ 走本方案** |

**改包装 / 改工艺方案的要点（强制）**：本方案的产出**不等于 CP 结论**，须**并列**写出「**CP 判定为 CP-C¹（不可安装：无编带）** ＋ **改工艺方案：×× 工序可解**」——
**禁止**用"改工艺能解决"把 CP-C 抹掉，也**禁止**因走改工艺方案就把结论升档。

**禁止**：
- 把改线方案写成「CP-B 但改根线就行」—— 允许重映射会使 CP-B 退化
- 改线后对外仍称 pin-to-pin —— **改过线就不是 pin-to-pin**

**改线方案出口存在 ≠ 可以在判定中重映射位序。** 判定必须先按同位一一对应走完。

**注**：**CP-C²（可错插）走改线 / 改板路径时，§8.2 告警段仍须保留**（改板不消除错插风险，除非同时改 keying）。
**注**：**CP-C³（电气危害）不得由改线化解**；须先以改板消除短路，改板后按新界面**重新判定**（原结论 CP-C³ 保留，不得改写）。

## §8 常见错误用法（自检）

| ❌ 错误 | ✅ 正确 | 后果 |
|---|---|---|
| 不写替换场景（S1/S2/S3）就给结论 | 场景是判定第一要素 | 结论答非所问 |
| 用 S2 的宽松结论去交付 S1 的需求 | S1 才最严，默认按 S1 | 现场插不进原配对端 |
| S2/S3 沿用 S1 的比对对象（候选 vs 原配对端） | 见 §0.0：S2 比候选两端、S3 整体不判 | 判错对象 |
| S3 仍输出「可插合」「互配成立」 | S3 无配对端，M1–M8 记不适用 | 结论越权 |
| **不核性别（公母）就判插合** | M1 须核性别互补（§3.1.0） | **根本插不进，且 M5 会误判过** |
| 认为"插得进去"= 可插合 | 必须核 M5 配合尺寸 + M6 防呆 + M7 锁紧 | 松脱 / 错位隐患 |
| M6 只判"同构 / 不同"，漏掉「可错插」 | 三结果：同构 / 互斥 / **可错插** | **可插但错位的致命隐患被漏掉** |
| 用常温载流额定判高温工况 | 按实际温度查降额曲线 | 高温下温升超标、烧蚀 |
| 多针同时载流直接把额定值相加 | 按群组降额系数折算 | 局部过热 |
| 位数相同就判可换 | 还需 M5/M6/M7 + 逐位判定 | 误判 |
| 不同 lock 形式却说"都是带扣的" | M7 须同类（卡扣≠螺钉≠推拉自锁） | 振动下松脱 |
| 逐位判定依据用 datasheet 而非客户线序表 | 依据必须是原设备设计文件 | 判错对象 |
| 拿不到线序表就按位数蒙 | 整闸记 ⚠️ 未判定 | 结论建立在推测上 |
| 差分对被拆开仍计等价 | 成员须同对且相邻 | 链路不通 |
| 屏蔽位换成空位仍计等价 | 属类别不对应，计入 k | EMC 恶化，静态测试查不出 |
| 只比初始接触电阻，不比寿命后 | 初始对初始，寿命后对寿命后 | 用几次后失效 |
| 拿不同寿命节点（或加速寿命不同阶段）的数直接对比 | 必须同寿命节点（如同为 500 次） | 数据不可比 |
| 忽略线径适用范围 | 适用于实际 AWG 才成立 | 压不紧 / 压不进 |
| 忽略压接工具与端子配套 | 端子须与原厂工具匹配 | 压接质量不合格 |
| 可靠性闸把「未给」记为过 | 记为 ⚠️ 待实测 | 缺口伪装成通过 |
| 降额闸 ⚠️ 仍给「有条件通过」 | 降额必须 ✅ 过 | 载流安全余量被挂条件 |
| **降额闸记「⚠️ 待实测」** | 降额闸只有「数据缺失」，无「待实测」（§6.0） | **口径混用，无法判断是缺数还是缺文件** |
| 实测方案写「确认能用」 | 写可量化判据 | 技术端无法执行 |
| 改判后不重跑全表 | 记「已重跑全表：是/否」 | 关联闸状态已变却未察觉 |
| 依据写「重新核了一下」 | 写文档名 + 版本 + 页码 + 日期 | 不可复查 |
| 覆盖旧改判记录 | 一律追加 | 改判链断裂 |
| **改标准不留痕** | 改版时按 §7.2 标明影响范围与重跑要求，并递增版本号 | 标准改版后已出结论无从处置 |
| **漏比 E11 镀层 / E12 FFC 厚度 / E13 环保合规** | 按 §5b.1 适用性分级必比 | **第一致命项 / 准入项漏判** |
| **把多余位算进 N** | N 只计原件位数，多余位另列 | 分母注水，n/N 偏高 |
| **CP-A 免掉 §3.10 短路校核** | §3.10 独立强制，k = 0 亦须给结论 | 悬空端子短路漏判 |
| **把「没取到数据」写成「不适用」** | ⬜ 不适用只有 §6.0 那**五项**能用（含 M1 性别子项），其余缺数据一律 ⚠️ | **缺口伪装成不需要** |

### §8.1 标准的实用性检验（**发布新版本前必做**）

**判定标准若导致「绝大多数候选都过不了」，须先检查标准本身，不淘汰候选。**

**连接器特有的先验**：一般而言，
**跨厂商的专用型连接器几乎不可能达到 CP-A**（§3.1.3）。这不是标准过严，是物理事实。
因此回测**必须覆盖标准件与非标准件两类**，否则回测无意义。

| 回测日期 | 回测人 | 案例（品类 / 场景） | 已知合格结论 | 标准判定结果 | 是否一致 | 不一致原因 |
|---|---|---|---|---|---|---|
| YYYY-MM-DD | （人） | 案例 1 | （已知合格结论） | （标准判定结果） | ☐ 一致 ☐ 不一致 | |
| YYYY-MM-DD | （人） | 案例 2 | | | ☐ 一致 ☐ 不一致 | |
| YYYY-MM-DD | （人） | 案例 3 | | | ☐ 一致 ☐ 不一致 | |

**每一格都须填写，不得留空。**
- 案例数 **3~5 个**，须覆盖不同品类（按 §0.1 的 C1–C8），**至少 1 个已知结论为 CP-A 或「可直接替」的案例**（**不强制**该案例必须是"同厂同系列后缀不同"）
- **至少含 1 个「同厂同系列只是后缀不同」的案例**；**该案例的标准判定结果允许为「CP-A + 可靠性闸 ⚠️」（即"有条件通过"）**——后缀差异可能落在镀层（E11）或接触电阻（E1/E2），不必强求 k = 0 且可靠性全过。**只要标准给出的结论与已知结论一致即可**
- **至少含 1 个标准互配接口**（如 RJ45 / M12 同编码）
- **至少含 1 个 S2 或 S3 场景案例**（否则 §0.0 的分支从未被验证）；**该案例优先选 S2**——
  **S2 的互配闸判「候选两端彼此互配」，若 k = 0 可判 CP-A，故 S2 案例可同时充当上面那个「CP-A 案例」**；
  **S3 案例不可能是 CP-A 案例**（S3 不得输出「可直接替」，只能写「可安装 ∧ 逐位电气等价」），
  故若选 S3 案例，须**另备**一个 CP-A 案例。**优先用 S2 以减轻案例数量压力。**
- **案例数下限与要求数的关系（强制，防为凑数牺牲覆盖）**：**「3~5 个」是数量区间，不是覆盖率的替代**——
  上述四项要求（**CP-A / 同厂同系列后缀不同 / 标准互配接口 / S2 或 S3**）**若可通过重合满足**（如 S2 案例兼作 CP-A、同厂同系列案例兼作 CP-A），**最小值可为 3 个**；
  **若无法重合**（如选了 S3 案例、而 S3 不能兼作 CP-A，且各案例品类又须不同），**案例数须相应扩至 4~5 个**。
  **不得为满足「3~5 个」的字面要求而牺牲覆盖完整性**；**真正的下限是"覆盖上述四项要求"，不是"3 这个数字"**。
- **不一致且无法说明原因 → 禁止发布该版本**

**回测记录不得删除或改写。**

### §8.2 「可错插」的强制告警条款

**M6 判为「可错插」（→ CP-C²）时，无论最终结论档位为何、无论是否另走改线/改板方案，输出中必须保留以下独立段落：**

> 【⚠️ 高风险 · 防呆不互锁】
> 候选件与原配对端**防呆结构不匹配但可物理插入**，存在**反插 / 错位插入**风险。
> 现场**不得**以"能插进去"作为可换依据。若确需使用，必须：
> ① 改 keying（若结构允许）；② 装配工序增加**唯一装配位**约束；③ 首件通电前人工复核。

**本条款不可因"客户催得急"而省略。**
