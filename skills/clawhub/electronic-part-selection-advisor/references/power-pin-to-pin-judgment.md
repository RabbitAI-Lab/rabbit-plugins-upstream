## §0 范围边界与定位（必读）

**电源管理芯片的"pin-to-pin"是受限命题。** 数字 / 模拟 IC 做 pin-to-pin，外围是被动的；  
PMIC 的外围电路本身就是功率级（电感、输出电容、FB 分压、补偿网络），所谓"引脚兼容"只保证脚位能对上，  
**但 Vref 不同 → 分压电阻须重算、fsw 不同 → 电感须重选、外部补偿 → RC 网络须重配**。  
脚位对上 ≠ 板子不用改。

**因此本标准的定位是「L1 引脚级闸门 + L2 工程复核输入生成器」：**

- PPJ（L1）只判**引脚级能否直插**，产出一张**结构化的 L2 工程复核清单**（§6.5），交由有实测经验的工程师复核；
- 环路稳定性、热设计、补偿重配、Vref 分压重算、fsw→L/C 重选——均属**标准之外的工程判断（L2）**，不在 L1 结论内；
- **即便最优档 PM-A，也不得视为"可直替"**：PM-A = 引脚级可直插，但功率级须 L2 复核，结论强度封顶为「满足但有待实测项」。

> **红线**：本文件及由其生成的任何报告**不得出现放行语**（"可直接替""可下批量订单""放心使用"等）。  
> L1 结论强度上限 = 「满足但有待实测项」；L2 意见由工程师以「满足但有待实测项 / 存在不满足项 / 无法判定」强度给出，  
> 责任靠结论强度免除，不靠一句"不承担"。

### §0.1 品类归属矩阵

| 品类（§0.1 归属矩阵）                                                  | 是否进本文件 | 处理                                              |
| -------------------------------------------------------------- | ------ | ----------------------------------------------- |
| **LDO 线性稳压器**（含**无 SW / BST / COMP 的线性类**——判别口径：不含外置功率级的开关器件）  | 否      | 归入通用半导体 PPJ（外围仅为进出电容，无电感 / 无补偿环路）               |
| **开关稳压（buck / boost / buck-boost / 反激）**                       | **是**  | 本文件 PM-A/B/C，最佳档封顶 + 强制 L2 路由                   |
| **多通道开关稳压**（如双通道 Buck，每通道独立 FB / COMP / SW / BST，**无 I²C 配置**） | **是**  | 按「**多组引脚**」分别判 T8，每组判定结果**并列输出**；任一组不过即不得判 PM-A |
| **带 I²C 配置 / 寄存器定义不同 / 无引脚可比的复杂 PMIC**                         | 否      | 引脚级判据基本不适用 → 落「无法判定」或直交 L2，不得套用 PM 档位           |

> **"多通道"与"复杂 PMIC"的分界**：判据是**引脚级是否仍可逐组比对**。多通道开关稳压虽有两套 FB / COMP / SW / BST，但**每组仍是标准 FCT 引脚**，T8 可分别适用 → 进本文件；带 I²C 配置 / 寄存器定义的器件，其功能由寄存器而非引脚决定，引脚级判据不适用 → 落「无法判定」。
>
> **关于"多轨"**：多轨（多路独立输出）**若每轨均通过标准 FCT 引脚控制、无 I²C 配置**，即属上表的「多通道开关稳压」→ **进本文件**，按多组引脚分别判。若靠寄存器分配输出轨，则归「复杂 PMIC」→ 不进。

## §1 术语定义

- **引脚级可直插**：机械可装（T1–T7 全过）且逐脚功能类别等价（§3.2，k = 0）。
- **PM-A**：引脚级可直插（机械全过 ∧ k = 0），降额闸与性能闸均通过或仅待实测。  
  **≠ 可直替**——这是整份文件的核心差异点：PM-A 只证明引脚级可直插，功率级重设计（Vref 分压 / fsw→L-C / 补偿 / 环路 / 热）一律属 L2（§6.5），结论强度封顶「满足但有待实测项」。
- **PM-B**：机械可装，但存在 k > 0 处不对应（脚位 / 功能类别不对应），且**改板 / 飞线也无法达成功能对应**。  
  （注：本定义与通用半导体 PPJ 的 PP-B **完全一致**——PP-B 同样是"改板也无法达成对应"；"可经改板达成对应"的情形不归 PM-B，改列「改板方案」，见 §2.2。）
- **改板方案**（**不属 PM-A/B/C 任一档**）：**可经改板 / 飞线达成功能对应，但非引脚级可直插**。**机械可装与否均可**——有两种入口：  
  **入口 A（引脚可装）**：机械可装（T1–T7 全过），但同号脚存在不对应（k > 0），可经改板 / 飞线达成功能对应（如引脚定义不同，飞线换位可解决）；  
  **入口 B（引脚不可装）**：机械**不可**装（T1–T7 任一不过），但可经改板（**飞线 / 转接板 / 换封装焊盘**）达成功能对应（如 SOT23-6 ↔ SOT89，**视具体设计**可能可救）。  
  两种入口均按本文件 **§7 附则（PM 判定与「改板方案」的分工）** 重新判定改制后板级，**不得**套用 PM 档位结论，也**不得**给出"可直替"暗示（§2.2）。
- **PM-C**：机械不可装（封装 / 脚数不符），**且改板亦无法达成对应**。  
  **拓扑不一致不属 PM-C**——它是独立的「范围外」出口，见 §2.2。
- **拓扑不一致**：器件拓扑与原件不同。**两轴判定**（§2.2）：① **拓扑类别**——buck ↔ boost ↔ buck-boost ↔ 反激 ↔ LDO ↔ sepic 不可互替；② **整流方式**——同步整流 ↔ 非同步整流不可互替（续流路径一条走内置低边 MOS、一条走外置肖特基二极管，属功能根本不同）。**任一轴双方都给且不同**，脚位对上亦无意义 → 判「**存在不满足项**」（§2.2 范围外），**不套用任何 PM 档位**。

> **改板方案与 PM-C 的严宽度关系**（§3.2 引用）：**PM-A ＜ 改板方案 ＜ PM-B ＜ PM-C ＜ 范围外·拓扑不一致**。  
> **PM-C 严于改板方案（入口 B）的原因是：机械不可装属硬约束，需换板才能用——不是"改改外围"能解决的。若换封装 / 飞线 / 转接板能达成对应，则该候选属「改板方案」（入口 B），不判 PM-C。**  
> 该序只用「严宽度低 / 高」表述，**不得写成「优先于」**（见 §3.2 术语约定）。

- **L2 工程复核清单**：本文件 §6.5 强制产出物，列明须人工关闭的项（Vref / fsw / 补偿 / 环路 / 热 / EN-PGOOD / 保护 / 软启动 / UVLO / ILIM / MODE）。

**核心纪律：§3 只回答"是不是引脚级可直插"，§4/§5/§5b 只回答"引脚级电气是否可承受"。  
功率级重设计（§6.5）一律不在此二问之内，必须路由 L2。**

## §2 判定结论

| 档位       | 含义                          | 结论强度                  | 是否含 L2 路由 |
| -------- | --------------------------- | --------------------- | --------- |
| **PM-A** | 引脚级可直插，降额 / 性能闸通过或仅待实测      | **满足但有待实测项**（封顶，不得更高） | **强制**    |
| **PM-B** | 引脚级可装但 k > 0 不对应，且改板也无法对应   | 需人工核算（封装兼容，差异影响未判定）   | 强制        |
| **PM-C** | 机械不可装（封装 / 脚数不符），且改板亦无法达成对应 | 存在不满足项（不可直换）          | 视情形       |

**不进 PM 档位的两个出口**（**不属 PM-A/B/C 任一档**，详见 §2.2）：

| 出口            | 含义                                                        | 结论强度              |
| ------------- | --------------------------------------------------------- | ----------------- |
| **改板方案**      | 可经改板 / 飞线 / 转接板达成对应（非引脚级可直插）；**入口 A 引脚可装 / 入口 B 引脚不可装均可** | 需人工核算（须重新判定改制后板级） |
| **范围外·拓扑不一致** | 拓扑与原件不同（**两轴**：拓扑类别 buck ↔ boost ↔ 反激 ↔ LDO，**或**整流方式 同步 ↔ 非同步） | 存在不满足项            |

**PM-A ≠ 可直替。** PM-A 不得因"引脚级全过"升级为「满足判据 / 可直接替」；功率级不确定性属 L2，不属 L1。

### §2.1 PM-B 的边界定义（与通用 PPJ 同构）

> **与通用 PPJ 的口径关系（必须明示）**：  
> 通用 PPJ §2.2 规定——"可经改板 / 飞线达成对应"**不是** PP-B，改列「改板方案」；PP-B 是"改板也无法达成对应"。  
> 本标准**采用同一口径**：PM-B = 改板也无法达成对应；"可经改板达成对应" → 不判 PM-B，改列「改板方案」。  
> **PM-B 与 PP-B 是同一个东西**，不得读成"PM-B = 需改板"。

- 同号脚存在不对应（功能类别或电气角色），且**改板 / 飞线也无法**达成功能对应 → 判 **PM-B**，转 §4 + L2（需人工核算）；
- 同号脚存在不对应，但**可经改板 / 飞线**达成功能对应 → **不判 PM-B**，改列「**改板方案**」（见 §2.2），不套用 PM 档位；
- 机械不可装 → 落 **PM-C 候补**，按 §2.1 三态表分流为**改板方案（入口 B）**&#x6216; **PM-C**；拓扑不一致 → 判「**范围外·拓扑不一致**」（见 §2.2，**不归 PM-C**）；
- 判定顺序：先答「拓扑一致吗？」→ 不一致即范围外出局；再答「机械能装吗？」→ 能装才进 §3 走 PM-A/PM-B / 改板方案；装不上再按改板可行性分流为 PM-C 或改板方案。

**"改板能否达成对应"的取值口径**：机器判不出飞线能否救，须由判定者按下列三态声明（缺数据填「未判定」，不得留空）：

| 取值      | 含义              | 出口                                                                                                 |
| ------- | --------------- | -------------------------------------------------------------------------------------------------- |
| **可行**  | 经改板 / 飞线可达成功能对应 | **改板方案**（§2.2），不套用 PM 档位                                                                           |
| **不可行** | 改板亦无法达成对应       | **PM-B**                                                                                           |
| **未判定** | 尚未评估            | **⚠️ 未判定**（同通用 PPJ §6.0：**不套用任何 PM 档位**，走 §6.1「⚠️ 未判定 → 需评估」行）。**须由原判定者补充输入后重跑，或路由 L2 工程师分流后方可定档** |

> **「未判定」不等于 PM-B**：与通用 PPJ §6.0 一致，输入缺失时不得输出 PM-A / PM-B / PM-C 任一档，只落「需评估」，须索取后重跑。

**本三态表同样适用于「机械不可装」场景的分流**（§6.1 PM-C 行的分流规则出处在此）：

| 场景                 | 可行                     | 不可行      | 未判定    |
| ------------------ | ---------------------- | -------- | ------ |
| **k > 0**（同号脚不对应）  | 改板方案                   | PM-B     | ⚠️ 未判定 |
| **机械不可装**（PM-C 候补） | 改板方案（**该候选本就不属 PM-C**） | **PM-C** | ⚠️ 未判定 |

> **两个场景的差别只在"不可行"那一格**：k > 0 不可行 → PM-B；机械不可装不可行 → PM-C。**「可行」与「未判定」两格完全相同**。  
> **拓扑不一致不走本表**——它固定出「范围外」，与改板可行性无关。

**两个场景同时命中时的处理（强制）**：同一候选可能**同时**满足「k > 0」与「机械不可装」（例如既有同号脚不对应、封装族又不同）。此时**两个场景各自独立取三态值**，再按 §3.2 严宽度序取更严的出口：

| 双命中组合                          | 整机出口                                                | 依据                                |
| ------------------------------ | --------------------------------------------------- | --------------------------------- |
| 两场景**都判「可行」**                  | **改板方案**（两入口不并行，输出**一个**「改板方案」）                     | 同一出口，不叠加                          |
| **任一场景判「不可行」** → 按更严的「不可行」出口定档 | k > 0 不可行 → PM-B；机械不可装不可行 → PM-C；**两场景都不可行 → PM-C** | PM-C（④）严于 PM-B（③）                 |
| **任一场景判「未判定」**                 | **⚠️ 未判定**                                          | 缺输入优先，不得用另一场景的结论代替（同 §3.2「缺输入优先」） |

> **两场景的改板可行性可以相反**：例如 k > 0 经飞线可救，但封装不可装（SOT23-6 ↔ SOT89）救不了——场景 1「可行」→ 改板方案，场景 2「不可行」→ PM-C，**整机取 PM-C**（机械不可装不可行）。  
> **引用时须写明取自哪个场景**：如「机械不可装场景：不可行」与「k > 0 场景：可行」并存时，整机结论写「PM-C（机械不可装场景不可行）」。**不得只写「改板不可行」而不分场景**——否则无法复核是哪个闸判死的。

### §2.2 范围外与不套用 PM 档位的出口

- **改板方案**（**不属 PM-A/B/C 任一档**）：**可经改板 / 飞线达成功能对应，但非引脚级可直插**。**机械可装与否均可**——有两种入口：
  - **入口 A（引脚可装）**：机械可装（T1–T7 全过），但同号脚存在不对应（k > 0），可经改板 / 飞线达成功能对应（如引脚定义不同，飞线换位可解决）；
  - **入口 B（引脚不可装）**：机械**不可**装（T1–T7 任一不过），但可经改板（**飞线 / 转接板 / 换封装焊盘**）达成功能对应（如 SOT23-6 ↔ SOT89，**视具体设计**可能可救）。
  两种入口均按 **§7 附则（PM 判定与「改板方案」的分工）** 所述分工重新判定改制后板级；**不得**套用 PM 档位结论，也**不得**给出"可直替"暗示。
  > **入口 B 为什么也需要改板方案出口**：机械不可装本身不是"判死"——SOT23-6 ↔ SOT89 **视具体设计，用转接板或飞线可能可救**（能否可救取决于间距、引脚数量、信号速率、机械干涉等）。**是否可救须按 §2.1 三态表逐案声明，不由本定义预先断言**。若把这类候选一律判 PM-C，会把**有救的**候选误判为不可救。因此 PM-C 与改板方案（入口 B）互斥，**同一候选只出现其中一行**（分流见 §2.1 三态表、§6.1 PM-C 行）。
- **拓扑不一致**：**两轴判定**（v1.2 起）。**轴 1 拓扑类别**：buck ↔ boost ↔ buck-boost ↔ 反激 ↔ LDO ↔ sepic 不可互替；**轴 2 整流方式**（v1.2 新增）：**同步整流 ↔ 非同步整流不可互替**——续流路径一条走内置低边 MOS、一条走外置肖特基二极管，外置二极管焊盘作废或平白多一颗外置器件，效率与 EMI 特性全变，属**功能根本不同**，脚位对上也无意义。**任一轴双方都给且不同 → 直接判「存在不满足项（拓扑不一致）」**；**任一方未给某一轴 → 该轴不判失败**（记待核），不把缺数据当不符。**本项是拓扑不一致的唯一出口，不归 PM-C、也不走改板方案**（§1、§6.1 同此口径）；
  > **机读匹配规则**（投影：`engine/categories/power.json` → `topology.axes`）：拓扑类别轴**有序匹配**——buck-boost 必须先于 buck（「buck-boost」含「buck」子串，顺序反了会把升降压误判成 buck/boost）；整流方式轴按关键词**最早出现位置**定值——「非同步」含「同步」子串，固定关键词顺序会把「非同步」误判成「同步」。
- **带 I²C 配置 / 寄存器定义不同 / 无引脚可比的复杂 PMIC**（含「靠寄存器分配输出轨」的多轨）：引脚级判据基本不适用，判「无法判定（缺输入 / 不属 L1 范围）」，交 L2；**注意：多轨本身不是排除项**，分界见 §0.1——每轨由标准 FCT 引脚控制且无 I²C 的多轨属「多通道开关稳压」，进本文件按 §3.2 分组判定；
- 以上出口**不得**给出 PM-A/PM-B/PM-C 中的任一"可直换"暗示。

## §3 机械测试项与引脚等价

### §3.1 封装类（T1–T7，取自原厂 datasheet 外形图）

复用通用层 §3.1 / §3.1.1（JEDEC MS-012 等通用公差）：T1 封装族、T2 本体宽 E1、T3 封装长 D、  
T4 引脚总跨 E、T5 脚距 e、T6 本体总高 A、T7 脚数。**脚数必须相同；封装族不同（如 SOT23-6 ↔ SOT89）即机械不可装。**

**机械不可装本身不直接定档**——须按 §2.1 三态表分流：可改板（飞线 / 转接板 / 换封装焊盘）→ **改板方案（入口 B）**；不可改板 → **PM-C**；未判定 → **⚠️ 未判定**。

### §3.2 引脚功能等价（T8）

对每个脚号，把该脚归入以下 **PMIC 功能类别（FCT）**，类别不同 → 计入 k；类别相同 → 查电气角色相容性。

| 代码     | 标签           | 常见符号                |
| ------ | ------------ | ------------------- |
| PWR-IN | 电源输入 / 功率输入端 | VIN / PVIN / VCC    |
| SW     | 开关节点         | SW / LX / PHASE     |
| BST    | 自举 / 高端驱动    | BST / BOOT          |
| FB     | 反馈（误差放大输入）   | FB / VFB            |
| COMP   | 补偿节点         | COMP / VC           |
| EN     | 使能           | EN / SHDN / RUN     |
| PGOOD  | 电源好指示        | PGOOD / PG          |
| BIAS   | 偏置 / 逻辑电源    | VCC / BIAS / VDD    |
| GND    | 地            | GND / AGND / PGND   |
| NC     | 无连接          | NC / DNC            |
| SS     | 软启动          | SS / TR / SOFTSTART |
| RT/FSW | 开关频率设置       | RT / FSW / FREQ     |
| ILIM   | 限流设置         | ILIM / LIM / ISET   |
| MODE   | 模式选择         | MODE / FCCM / DCM   |
| SYNC   | 同步输入 / 输出    | SYNC / CLKOUT       |

**未列出引脚功能的归类规则**：不在上表的引脚（如 SLEW / PGOOD 延时设定 / 独立 BIAS 设定等）须人工归入最接近的类别，并在输出中注明**归类依据**；无法归类的，该脚判为 **⚠️ 未判定**，整闸不得出 PM-A/B/C（须转 L2 或「无法判定」）。

**多通道器件（§0.1）的分组判定**：多通道开关稳压按**通道组**分别判 T8——每组各有 FB / COMP / SW / BST，各自独立得出 k 值与档位，**各组结果并列输出**。  
**任一组不过（k > 0 或机械 / 拓扑不过）→ 整机不得判 PM-A**，按下表定档；不得因"其中一组兼容"就判 PM-A。

**整机定档（多通道）**：

1. **缺输入优先**：任一组为「⚠️ 未判定」或「无法判定」→ **整机亦落「需评估」**，不得因其他组通过而放行。此时须先补齐该组缺失输入后重跑，**不得取其他组的档位代替**。
2. 其余情形按**严宽度最高的那一组**定档。

**§3.2 严宽度序（唯一权威表，§1 / §6.1 / §8 / §8 投影均引用本表，各处不得自定序）**

| 严宽度       | 档位 / 出口       | 含义                                                             |
| --------- | ------------- | -------------------------------------------------------------- |
| ① 最低（最宽松） | **PM-A**      | 引脚级可直插（封顶「满足但有待实测项」，功率级须 L2 复核）                                |
| ② 低       | **改板方案**      | 可经改板 / 飞线 / 转接板达成对应（非引脚级可直插）；**引脚可装（入口 A）或不可装（入口 B）均可**，见 §2.2 |
| ③ 中       | **PM-B**      | k > 0 **且改板也无法对应**                                             |
| ④ 高       | **PM-C**      | 机械不可装，且改板亦无法达成对应                                               |
| ⑤ 最高（最严格） | **范围外·拓扑不一致** | 拓扑与原件不同（buck ↔ boost ↔ 反激 ↔ LDO，**或同步 ↔ 非同步整流**），脚位对上亦无意义（§2.2）                |

**定档规则：取严宽度最高的那一组，即 ① < ② < ③ < ④ < ⑤（从宽松到严格）。**

> **为何改板方案排在 PM-B 之前（② < ③）**：PM-B 是"**改板也救不了**"，改板方案是"**可以改板救**"——后者明显更宽松，故 ② < ③。  
> **为何改板方案比 PM-C 宽松（② < ④）**：**两者机械可装性相同**（PM-C 也可能是"改板 / 转接板也救不了的机械不可装"），差别只在**改板能不能救**——改板方案是"**可以改板救**"，PM-C 是"**改板也救不了**"，后者明显更严。**注意：入口 B 的改板方案本身也可能是机械不可装的**（如 SOT23-6 ↔ SOT89 靠飞线／转接板），故**不能用"机械可装与否"区分二者**，必须看改板可行性三态（§2.1）。  
> **为何拓扑不一致最严（⑤）**：它不是"装不上"或"改板能救"的问题，而是**功能根本不同**——外围电感、电容、反馈网络、补偿全须重算，改板无从谈起。**整流方式不同（同步 ↔ 非同步）同理**：续流路径一条在内置低边 MOS、一条在外置肖特基二极管，外置二极管焊盘作废或平白多一颗外置器件，效率与 EMI 特性全变。  
> **术语约定**：本标准一律用「严宽度低 / 高」表述，**不使用「优先于」**——「优先」在中文里可读成"更优"或"更严"，两个方向都会误读。

> **例**（一律按"取严宽度最高"）：一组 PM-A + 一组 PM-B → 整机 **PM-B**；一组 PM-A + 一组改板方案 → 整机 **改板方案**；一组改板方案 + 一组 PM-B → 整机 **PM-B**（PM-B 严于改板方案）；一组 PM-C + 一组改板方案 → 整机 **PM-C**；一组 拓扑不一致 + 一组 PM-A → 整机 **范围外·拓扑不一致**。  
> **注意**：PM-C 只出现在"机械"层，与逐脚 k 值无关；k 值再大也不会退化成 PM-C。  
> **注意**：「改板方案」与「范围外·拓扑不一致」**都不是 PM 档位**（§2.2）；落在该位只表示整机结论取该出口，**不得据此输出 PM-A/B/C 任一档**。

**引脚等价的局限性（PMIC 特有）**：即便同号脚 FCT 相同，以下仍须在 §3.2 中**记录**，判定归 L2，不在 §3.2 内判定：

- FB 脚的 **Vref 基准电压**是否一致（不一致 → 分压电阻须重算，见 §6.5）；
- EN / PGOOD 的**极性**（active-high / low、开漏 / 推挽）——须在 §3.2 记录，由 L2 确认接法；
- COMP 脚是否存在（内部补偿 vs 外部补偿）。

## §5 降额闸（与 PM 判定独立，AND 关系）

**公式**：候选件绝对最大额定 ≥ 原件绝对最大额定（相对比较，依据引擎通用层 §相对比较口径）。  
**阈值**：占用率 ≤ 80%（候选 abs_max 须覆盖原件工作点）。

**数据来源**：两份原厂 datasheet 的绝对最大额定栏。缺项 → 判 ⚠️ 数据缺失。

**PMIC 专属扩展——热阻折算**：开关稳压的失效 dominantly 是热失效。除 Vin_max / Iout_max / Vsw_max 外，  
须核算 **Pd 与 θJA**：

- 功耗估算（**按拓扑选择公式；L1 只做粗筛，具体公式与损耗系数须由 L2 工程师确认**）：
  - **Buck（降压）**：Pd ≈ (VIN − VOUT) × IOUT × 效率损耗系数；
  - **Boost（升压）**：Pd ≈ VOUT × IOUT × (1 − η) / η；
  - **Buck-Boost**：须按工作模式（升压段 / 降压段 / 直通）分别估算，不得套用单一公式；
  - 亦可直接按导通损耗 + 开关损耗实测值估算。
- 温升 ΔT = Pd × θJA；要求 Tj = Ta + ΔT ≤ 原件 Tj_max（或系统允许结温）；
- **同封装名但不同散热设计**（带 / 不带外露散热焊盘、不同引线框架、不同焊盘铺铜面积）θJA 可能相差 2 倍以上 → 须逐项比对 θJA，不得仅看封装名。

**降额闸状态**：✅ 过 / ❌ 不过 / ⚠️ 数据缺失（无"待实测"）。⚠️ 数据缺失只能「需评估」，禁止「有条件通过」。

**全局兜底（强制）**：**无论走本表哪一行**，只要存在任一未过关的闸项（降额 ❌ 不过 / 性能 ❌ 不过 / 任一 Pw# ❌ 不过），报告**均不得出现「可直接替」**。本兜底与 §6.2 禁止放行语互为呼应：§6.2 管措辞，本条管闸态。

**任何一闸为 ❌ 不过，最高只能是「需评估」。降额不过 + 性能不过 → 两条理由都要写（见上表 PM-A「❌ 不过 / ❌ 不过」行）。**

**PM-B / 改板方案 / 范围外 三类与降额、性能闸的关系**（避免"任意"被误读）：

- **PM-B**：降额闸与性能闸**仍照判、并列记录**（§5 / §5b 与 PM 判定独立、AND 关系），但两闸的过 / 不过**不改变 PM-B 档位**——PM-B 已因"k > 0 且改板也无法对应"落「需评估」。两闸的**缺口项与不过项仍须列入输出**，供后续 L2 或改板评估参考。
- **PM-C 与「改板方案」两行互斥（防同案双报）**：PM-C 的成立要件是「机械不可装 **且改板亦无法达成对应**」；改板方案**入口 B** 处理的正是"机械不可装但**可**经改板 / 转接板 / 换封装焊盘达成对应"。**判别只看一件事：改板能不能救**——**能 → 改板方案行（入口 B）；不能 → PM-C 行**。同一候选在报告中**只出现其中一行**。三态取值见 §2.1。
  > **不得用"机械可装与否"来分流**：入口 B 的改板方案本身就是机械不可装的，用机械可装性分流会把有救的候选误判成 PM-C。
- **「拓扑不一致」只有一个出口 = 范围外行**：拓扑不一致**不属 PM-C**（§1、§2.2），也不属改板方案；它固定走「范围外·拓扑不一致」行输出「存在不满足项」。**不得**因机械也不可装就改判 PM-C——两者的不合格原因不同（一个是装不上，一个是功能不同），结论措辞也不同（「不可直换」vs「存在不满足项」）。

- **⚠️ 未判定**："任意"表示**不适用**——未判定意味着输入缺失、**整闸尚未开始**，降额闸与性能闸**均不判**（既不是"待判定"，也不是"已判过"）。须索取缺失输入后重跑，重跑后按实际闸状态取值。
- **改板方案 / 范围外**："任意"表示**不适用**——这两类不进入 PM 档位体系，降额闸与性能闸**不判**（不是"待判定"，也不是"已判过"）。

### §6.2 禁止放行语（强制）

无论 **PM-A / PM-B / PM-C / 改板方案 / ⚠️ 未判定 / 范围外（拓扑不一致、复杂 PMIC）**，
**报告均不得出现**"可直接替""可下批量订单""放心使用""推荐采用该替代"等放行语。  
PM-A 经 suggest_tier 映射后产品级措辞为「满足但有待实测项」，并须附 §6.5 L2 复核清单；  
**实测 / L2 复核通过前不得下批量订单**（可送样、可小批试产，须明示）。

### §6.3 待实测项方案格式（强制，同通用层 §6.3）

性能闸 ⚠️ 待实测项须附实测方案（测什么 / 怎么测 / 通过判据 / 样品 ≥ 3 颗不同 lot / 责任方 / 期限）。  
降额闸 ⚠️ 数据缺失须写明索取 abs max 的具体途径（原厂渠道 / 文档版本号），或按 JEDEC 推断并标注推断值。

### §6.4 输出措辞必含项（同通用层 §6.4）

n/N 与 k/N、不对应项逐脚明细、各闸四态与依据、缺口清单、数据获取方案、实测前动作约束、§6.5 L2 复核清单、**所依据的标准版本号（唯一有效值＝现行版本号；见 §7.2）**。

| #    | 复核项                 | 为什么必须人工                            | 关闭方式                          |

| L2-1 | **FB / Vref 分压重算**  | Vref 不同 → 分压电阻须按新 Vref 重算，脚位对上 ≠ 板子能用 | 工程师按候选 Vref 重算 FB 分压，确认输出电压精度 |
| L2-2 | **fsw → 电感 / 电容重选** | fsw 不同 → 外部 L/C 可能须重选，原 BOM 须评估 | 工程师按候选 fsw 重算 L 值、输出电容的 ESR 与容值 |
| L2-3 | **补偿网络重配**          | 外部补偿（TYPE II/III）→ RC 网络须重配；内部补偿则免 | 工程师确认补偿类型，外部补偿须重算 RC          |
| L2-4 | **环路稳定性上机验证**       | 标准不判环路；同料不同拓扑 / 不同补偿 → 稳定性须实测      | 工程师做负载阶跃 / 波特图实测              |
| L2-5 | **热设计 / θJA 实测校核**  | 同封装不同 θJA；Pd 估算须上机复核               | 工程师按实际 Pd × θJA 核算 Tj，热像仪实测   |
| L2-6 | **EN / PGOOD 极性确认** | active-high/low、开漏/推挽差异 → 逻辑接法须改   | 工程师核对使能与 PGOOD 极性、上拉配置        |
| L2-7 | **保护阈值核对**          | OVP / OCP / SCP / OTP 阈值须 ≥ 原件或标注  | 工程师核对保护动作点与系统保护协调             |
| L2-8 | **软启动时间 tss 核对**     | tss 不同 → 上电时序可能不满足系统要求        | 工程师核对 tss 与系统上电时序裕量              |
| L2-9 | **UVLO 阈值核对**        | UVLO 不同 → 系统启动 / 关断点可能偏移       | 工程师核对 UVLO 上升 / 下降阈值与系统协调         |
| L2-10 | **限流阈值 ILIM 核对**     | ILIM 不同 → 过流保护点可能不匹配          | 工程师核对 ILIM 与系统过流保护协调             |
| L2-11 | **MODE 逻辑电平核对**     | MODE 脚高 / 低电平定义可能不同（FCCM / DCM） | 工程师核对 MODE 接法与期望工作模式             |

> **本清单为最小集，不穷尽**：L2 工程师须根据具体应用补充其他复核项（本表已含 L2-1~L2-11；应用相关的其他项由承接工程师增量补充并在报告中列明）。

> **L2 工程复核输入纪律**：清单为 L1 的标准化输出，不暗示任何一项"已通过"。工程师承接后须逐项给出 L2 意见，  
> 不得因"L1 已判 PM-A"而跳过任一项。客户机密与利益冲突按《L2 前置条款（电源管理）》处置（该文件为 **L2 承接流程单独提供的前置协议**，**不在本标准范围**、不随本标准发布；**本标准读者不自行生成，须由承接 L2 的流程方提供**——缺失时该批 L2 结论不得出具，按 §6.5 待复核项挂起）。

## §7 改判与改标准纪律

| 允许                                | 禁止          |
| --------------------------------- | ----------- |
| 发现新事实（新原厂文档 / 实测数据）→ 更新 §3 输入值后重跑 | 凭"重新想了一遍"改判 |
| 发现标准本身有漏洞 → **改标准全文**             | 同一批输入值下改判   |
| 客户提出新判定口径 → 先改标准，再重跑              | 口头改判、不留痕    |

**每次改判必须能回答：新增 / 变化的是哪一个具体输入值（哪份原厂文档、哪一页、哪个数值）。** 答不出来 = 是在改判，不是在判定。

### §7.1 改判记录必填项

**必须记成「从什么变成什么，依据哪一版文档」。**

| # | 必填 | 格式 | 示例 |
|---|---|---|---|
| 1 | **判据项** | 哪一项判据（T1–T7 / T8 FCT / Pw1–Pw6 / 降额） | `T8 逐脚功能等价` |
| 2 | **旧值** | 改判前的值 / 结论 | `8/8 等价，0 处不对应 → k=0` |
| 3 | **新值** | 改判后的值 / 结论 | `7/8 等价，1 处不对应（pin5 EN→NC）→ k=1` |
| 4 | **旧档位 → 新档位** | 结论档位的迁移 | `PM-A → PM-B` |
| 5 | **依据文档 + 版本 / 日期** | 文档名、版本号或 Release 号、页码、访问日期 | `候选料 datasheet Release A (Dec.2025) p4` |
| 6 | **变更类型** | 新增事实 / 修正读数 / 改判据口径 | `改判据口径` |
| 7 | **触发人 + 日期** | 谁提出、什么时候 | `用户，2026-10-05` |
| 8 | **是否已重跑全表** | 是 / 否 | `是，全表重跑` |
| 9 | **下游影响** | 档位变化影响谁、要不要通知、已通知谁 | `档位由PM-A 降为 PM-B，须重新送样；已告知技术端` |

**第 4 项须单列**：数值变化只影响描述精度，档位变化影响结论等级、验证义务与可执行动作。

**第 9 项须填写**：档位降级后，此前基于旧档位推进的动作（送样、下单、验证安排）须回头确认。

**纪律**：一律**追加**，不许覆盖或删除旧记录；依据文档须为可复查实体（原厂 PDF / 官方规格页 / 实测报告）；同一批输入值下的改判**一律禁止**。

### §7.2 改判记录与标准修订的分工，及版本变更后旧结论的处置

> **定稿说明（自 v1.1 起进入稳定期）**：本标准自 v1.1 起进入稳定期。后续修订**仅限重大变更**（新增品类 / 品类归属调整、判据口径变更、档位定义变更）；**日常边界情形的澄清以「附录：待澄清事项」形式累积，不单独发版**——澄清条目**不改变现行版本号**，随下一次重大变更一并纳入正文。
> **判据（防"以澄清之名改判据"）**：澄清只解决"边界怎么判"；**一旦某条澄清实际改变了判据阈值或档位归属，它就不是澄清，而是重大变更** → 须按本节处置并递增版本号。

**与 §7.1 的分工**：§7.1 记「某次判定的**输入值**变了什么」；本节记「**标准本身改了，已出 / 在办结论怎么办**」。

| | 改判记录（§7.1） | 标准修订（本节） |
|---|---|---|
| 记什么 | **输入值**变了什么 | **判据**变了什么 |
| 影响 | 本次判定的结论 | 以后所有判定的口径 |
| 触发 | 新文档 / 新实测 / 修正读数 | 发现标准漏洞 / 客户新口径 |

**两者性质不同，不许混成一张表。**

#### §7.2.1 版本变更后，已出 / 在办判定怎么办

**版本号只有一个有效值 —— 现行版本号（强制口径）**：本标准**同时只有一个有效版本**，即文件头声明的现行版本号；**历史版本一律不再作为有效口径**，任何新判定、新交付**默认且只能按现行版**。
**引用旧结论时不写旧版本号**，统一写「**本结论出自旧版，须按现行版复核**」——既保留"可能已过时"的提示，又不制造"多个版本并行有效"的错觉。
**禁止**：在输出中并列罗列多个版本号、或以"按某旧版判定"为由回避按现行版复核。
**本标准不设逐条修订流水记录**——修订历史与判定无关；只保留**现行版本号**及其对已出结论的**处置规则**。

| 修订性质 | 对已出 / 在办判定的处置 |
|---|---|
| **改判据口径 / 档位定义**（如 PM-B 定义变更、降额阈值收严、某一闸不过的后果被修正） | ① 修订时**必须写明影响范围**（涉及哪些闸 / 哪些档位）；② **受影响的在办判定须按新版重跑**；③ 已交付的判定**不必一律作废**，但**再次引用时须按现行版复核**；结论出自旧版的**写「本结论出自旧版，须按现行版复核」**，必要时应主动提示"口径已变" |
| **补漏 / 补强**（新增 FCT 类别、新增 L2 清单项、新增输出项，不改变既有判据结论） | **无需重跑**。**若本次补漏新增了输出必含项**：已出结论再次引用无需重跑，但**再次对外交付时须按现行版格式补全必含项**；**仅内部引用**可只口头说明。**「补全必含项」的范围＝仅限无需重新判定即可补填的格式项**（标准版本号、输出日期、判定人等）；**若新增的必含项须重新判定才能填写**（新增闸状态、新增逐脚比对项等），**该结论须按现行版重跑，不适用"补全"** |
| **仅文字 / 排版修正** | 不影响任何结论，无需处置 |

**「补漏 / 补强」与「改判据口径」的边界（强制，防两行都像）**：
- **只增加输出项 / 定义 / 说明，不改变任何既有闸的判定阈值、档位归属或结论措辞** → 归「**补漏 / 补强**」；
- **改变了任何既有闸的判定阈值、档位归属或结论措辞**（哪怕只是把措辞改严）→ 归「**改判据口径**」。

**两行重叠或难以区分时，按更严的一行处理**（即按「改判据口径」：标明影响范围 ＋ 受影响的在办判定重跑）。
**例**：新增「软启动 tss 比对」这类**依赖本次输入值**的输出项——形式上是补漏，但旧结论不补即失真，**实务上按「改判据口径」处理**；处置时按更严的一行执行（标明影响范围 ＋ 受影响的在办判定重跑），**但「补漏 / 补强」行的「已出结论再次引用无需重跑」仍适用于未受影响的部分**。

**任何判定输出均须写明所依据的标准版本号**（见 §6.4；**唯一有效值＝现行版本号**）——**未注明版本的结论视为不可追溯**。

### 附则：PM 判定与「改板方案」的分工

PM 判定只回答「不改板能不能换」。改板方案是另一条路径，两者互不替代：

| | PM 判定 | 改板方案 |
|---|---|---|
| 前提 | **不改板** | 需改板（换封装 / 改走线 / 飞线 / 转接板） |
| 输出 | PM-A / PM-B / PM-C | 改板可行性 + 改哪里 + 成本量级 |
| 分界 | **改板也换不了**才走 PM | **改板能换**就走改板（不论机械是否可装） |

**禁止**把改板方案写成「PM-B 但可凑合用」——允许重映射会使 PM-B 退化为 PM-C。
**「改板可行性」未评估时不得断言 PM-B**：按 §2.1 落「⚠️ 未判定」，不得因"尚未评估"而默认判成"改板也救不了"。

## §8 常见错误用法（自检）

| ❌ 错误 | ✅ 正确 | 后果 |
|---|---|---|
| 把 PM-A 读成「可直接替」 | PM-A 只说明「机械可装 + 逐脚 / 逐位 FCT 全对应（k=0）」，封顶结论为「满足但有待实测项」，不等于工况已验证 | 误放行；未实测的环路稳定性 / 温升 / 纹波被当作已验证 |
| 降额 ❌ 不过仍写「有条件通过」 | 降额闸与性能闸是 **AND** 关系，任一 ❌ 即不得出现任何形式的条件通过 | 违反 §6.1 全局兜底 |
| 「改板可行性」未评估，直接判 PM-B | 未声明即落「⚠️ 未判定」，按 §2.1 走「需评估」，交人工分流 | 把「尚未评估」当成「改板也救不了」，误判 PM-B |
| 把改板方案写成「PM-B 但可凑合用」 | 改板方案**不套用 PM 档位**；重映射允许即 PM-B 会退化为 PM-C（见 §7 附则） | 档位体系失去可分辨性 |
| 拓扑不一致（buck ↔ boost、同步 ↔ 非同步）只比 FCT 得出 PM-A | 先过拓扑一致性闸（**两轴**：拓扑类别 + 整流方式，§2.2）：**任一轴不一致**直接判「存在不满足项（拓扑不一致）」 | 电感 / 电容 / 反馈网络全部错配（类别不同），或续流路径实现方式不同、外置二极管焊盘作废（整流方式不同），误放行 |
| 多通道 PMIC 只判其中一组即定整机档 | 按 §3.2 分组判定，**再按 §3.2 严宽度序取严宽度最高的一组**（PM-A ＜ 改板方案 ＜ PM-B ＜ PM-C ＜ 范围外·拓扑不一致）汇总；**不得在本表自定序** | 其余通道的失效被掩盖 |
| 拓扑不一致判成 PM-C（或因机械也不可装而改判 PM-C） | 拓扑不一致**只有一个出口** = 「范围外·拓扑不一致」行，输出「存在不满足项」（§1 / §2.2 / §6.1 三处同此口径） | 结论措辞错位（"存在不满足项"被降成"不可直换"），且掩盖了"功能根本不同"这一真实原因 |
| 机械不可装**不查改板可行性**就直接判 PM-C | 机械不可装**本身不定档**，须按 §2.1 三态表分流：可改板（飞线 / 转接板 / 换封装焊盘）→ **改板方案（入口 B）**；不可改板 → **PM-C**；未判定 → **⚠️ 未判定**（§3.1 / §6.1 同此口径） | 把**有救的**候选误判为不可救——如 SOT23-6 ↔ SOT89 **视具体设计**靠飞线 / 转接板可能可救，判 PM-C 等于凭空否决可行替代 |
| 铭牌 / 符号名相似即认定引脚等价 | 按 §3.2 FCT 逐脚 / 逐位比对电气属性（电压域、方向、上下拉、阈值） | 符号同名但功能不同，接入即损坏 |
| LDO（含无 SW / BST / COMP 的线性稳压器）投入本标准判定 | 归通用半导体 PPJ；复杂 PMIC（I²C / 寄存器定义）落「无法判定」或 L2 | 判据集不适用，结论无效 |
| 功耗估算一律套 Buck 公式 | 按 §5 分拓扑选公式：Buck / Boost / Buck-Boost 各用各的 | 估算值失真，L2 复核输入错误 |
| 判据表中把「任意」读作「待判定」 | 「任意」= 该闸态组合**不参与**本行判定；「待判定」是**输入缺失**，须走 ⚠️ 未判定 | 把不适用项当成缺数据，报告充满假缺口 |
| 各节自定严宽序，或用「优先于」表述档位关系 | 一律引用 **§3.2 严宽度序**（PM-A ＜ 改板方案 ＜ PM-B ＜ PM-C ＜ 范围外·拓扑不一致），取严宽度最高者；表述只用「严宽度低 / 高」 | 同一组多通道按不同节定档会得出**相反结论**；「优先于」方向不可辨（更优 or 更严）——例如「PM-B + 改板方案」按不同序汇总，可能被整成 PM-B（正确）或改板方案（错误） |
| 报告只写档位不写标准版本号 | 按 §6.4 写明现行版本号、输出日期、判定人 | 结论不可追溯，无法按 §7.2 复核 |
| 在对外材料中出现「可直接替」「可下批量订单」 | 结论只写「满足判据 / 满足但有待实测项 / 存在不满足项 / 无法判定（缺输入）」 | 越过标准定位，形成放行承诺 |

> - **M-14 拓扑不一致单一出口**：verdict 带拓扑语义时出口 tier 必须是范围外类、不得为 PM-x；拓扑 verdict 的措辞必须是「存在不满足项」；**PM-x 档位的 tier / explain 不得出现「拓扑」字样**。
> - **M-15 机械不可装须查改板可行性**：机械检查不过时，verdict 不得直接是 PM-C——须先读 `key_params._改板可行性` 三态：可行 → 改板方案（入口 B）；不可行 → PM-C；缺失 / 不可解析 → ⚠️ 未判定。**「机械不可装」与「PM-C」不是同义词**（§3.1 / §6.1 同此口径）。
