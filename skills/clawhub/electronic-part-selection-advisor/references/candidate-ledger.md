# 候选遍历台账与判定锁定

> 配套文件。作用只有一个：**让判定可复现、可举证、可交付**。
> 无本台账的判定结论，不进入对客交付物。

---

## 格式规范（机器可读，校验器按此解析）

本台账须能被 `scripts/verify_report.py` 解析。**解析不了 = 没做**，不是"格式稍有出入"。

### 表头十列（列名须精确包含下列关键字）

| 列名 | 填写要求 |
|---|---|
| 候选型号 | 完整型号，含后缀 |
| 厂商 | 用于统计遍历家数（按厂商去重计数） |
| 封装 | 封装型号 |
| 封装取证源 | `原厂 Ordering Guide（两源一致）` / `原厂 datasheet（单源）` / `待核`；**写「渠道页」直接 FAIL**（铁律 6o） |
| 关键参数 | **必须写成 `值@条件`**，条件须含供电与温度两个标签（6g）。例：`10.7Ω@±15V, 25°C` |
| 状态 | 四值之一：通过 / 出局 / 待核 / 未核 |
| 出局／待核判据 | 出局填判据编号；待核填缺什么、向谁索取；未核填为什么没核到 |
| 分层 | 仅「通过」项必填：合规 / 需豁免 / 需评估 |
| 豁免三件套 | **分层为「需豁免」时必填**，其余填 `—`。写法见下 |
| 取证来源 | 取证三件套：来源 + 位置（章节号/表号/页码）+ 日期（YYYY-MM-DD） |

### 「豁免三件套」写法（校验器按此解析）

用全角竖线 `｜` 分段，四段缺一即 FAIL：

```
超:<量化到数值> ｜ 改工况:<放宽后的工况 + 后果> ｜ 接受应力:<维持工况须补什么验证> ｜ 替代:<不豁免时的替代型号>
```

- `超:` 后必须给到**数值**，只写"超了"不算。
- 两条路径须**分列**，合并成一句即 FAIL——对客户这是两个不同决策。
- `替代:` 不得填自身型号（校验器会比对「候选型号」列）。

### 声明块（台账末尾，独立 `## DECLARATION` 段）

```
## DECLARATION
终局态: 是｜否
未核项: <数字>
遍历家数: <数字>
客户不穷举声明: 无｜<有则说明>
```

**声明须与台账自洽**：未核项必须等于台账中状态为「未核」的行数；遍历家数必须等于厂商去重数。
对不上即 FAIL——这是防"声明一套、台账一套"。

### 用法

```
python scripts/verify_report.py <台账文件.md>
```

退出码 0 = 通过；非 0 = 禁止交付。

## 一、遍历台账（Candidate Ledger）

### 判什么

每份判定报告必须附台账。台账回答一个问题：**候选池是否穷举，且穷举过程可举证。**

### 怎么判

1. **一行一料**。每个进入视野的候选占一行，不允许合并、不允许省略。
2. **状态四值，不许第五种**：
   - `通过` — 进入下一轮比对
   - `出局` — 必须填「出局判据编号」，指向具体规则条款
   - `待核` — 必须填「缺哪一项数据、向谁索取」
   - `未核` — 必须填「为什么没核到」，不接受空白
   - 状态仅此四值，分层归属不新增第五种：`通过` 的料须在备注列另标**合规 / 需豁免 / 需评估**（见第二节）。
3. **交付门槛**：`未核` 项为 0，或有客户书面确认的不穷举范围声明。否则结论只能标「阶段结论」，不得作为交付物定价。
4. **遍历范围声明**：写明扫了哪些渠道、覆盖多少家厂商、判据覆盖到哪一层。范围声明本身计入交付物。

### 表格模板

| 候选型号 | 厂商 | 封装（含取证来源） | 关键参数（值 + 测试条件） | 状态 | 出局／待核判据 | 取证来源 + 位置 + 日期 |
|---|---|---|---|---|---|---|
| | | | | | | |

**取证三件套**（见 `data-sources.md`「字段级取证可信度」）：末列必须写全 ① 来源 ② 位置（章节号 / 表号 / 页码）③ 日期。
**缺任一项 → 该行不得参与判定**，不只是标注提醒。
封装、脚位、abs max 属高风险字段，**两源一致才标「已核」**，单源标「待核」。

### 判不过怎么办

- `未核` 不为 0 且无客户豁免 → 退回补遍历，不出报告。
- `出局` 无判据编号 → 该行无效，退回补判据。
- 关键参数未带测试条件 → 该行不得参与跨器件比对（见参数比对铁律），退回补齐。
- 取证三件套缺项，或封装取自渠道页字段 → 该行不得参与判定，回原厂 Ordering Guide 重取证。
- 高风险字段单源取证 → 该料降为「待核」，整份结论降为阶段结论。

## 二、筛选分层与豁免归属

### 判什么

候选进比对表前必须先分层。分层的依据是**性质**，不是「谁有权决定」。
三层性质不同，混在一起会导致淘汰与标注错位：把可豁免的判成出局（白白丢候选），或把物理不可行的当成可豁免（把风险甩给客户）。

| 层 | 性质 | 问的问题 | 归属 |
|---|---|---|---|
| **A 硬约束层** | 物理可行性 | 能不能用 | 无人可豁免，判负即出局 |
| **B 降额层** | 可靠性准则 | 敢不敢用 | 客户豁免，**算在我方，决定在客户** |
| **C 性能层** | 适用性 | 好不好用 | 客户取舍，不淘汰，只标注 |

### 怎么判

1. **顺序不可颠倒：A → B → C。** A、B 未判完之前，性能参数不得进入视野。
1b. **A / B 的分界是「超的是哪条线」，不是「超了多少」**：
   - 超过原厂**绝对最大额定值**（abs max）→ **A 层**，物理不可行，出局，无人可豁免。
   - 未超 abs max，但超过本司**降额线** → **B 层**，可靠性准则，需豁免。
   二者不得互转：A 层不得因"只超一点"降为 B 层，B 层不得因"接近 abs max"升为 A 层。
1c. **封装与脚位的层级随输入指纹「可改板与否」切换**：
   - 不改板 → 封装/脚位不符属 **A 层**，出局。
   - 允许改板 → 不算出局，标「需改板」并写明改板范围。
   未取得客户明确答复前，按**不改板**处理。
2. **A 层判负即出局**，必须带判据编号，不得转为「需豁免」。
3. **B 层不算出局，但计算必须前置。** 豁免意味着工况改变，而工况改变会改变性能参数的取值；
   因此 B 层超限时，须**在豁免后的工况下重算**性能参数，再进 C 层。
   **决定权后移，计算权不让出**——否则比出来的数是错的。
4. **C 层不淘汰**，只标「需评估」+ 实测方案。
5. **每个需豁免项必须给三样，缺一即无效标注**：
   - 超了多少（量化到数值）
   - 豁免后需补什么验证
   - 不豁免时，替代是哪一颗
6. **需豁免项须拆成两条路径分列，不得合并成一句**：

   | 路径 | 客户要决定的 | 后果 |
   |---|---|---|
   | 改工况（放宽工作点） | 我能不能接受这个工况 | 性能参数全部重算 |
   | 接受应力（维持工况） | 我能不能担这个风险 | 须补可靠性验证 |

   对客户这是两个完全不同的决策，合并输出等于替客户做选择。
7. **豁免须书面确认才生效。** 台账记录确认状态与日期；未确认前，该料只能列在「需豁免候选」，不得作为首选。
8. **交付物三类分列**：合规候选 / 需豁免候选 / 需评估候选。每颗料带标签走，不混在一个池子里让客户自己翻。

### 判不过怎么办

- 顺序颠倒（C 层结论先于 A 层出现）→ 本次判定作废，重跑。
- 需豁免项缺第 5 条任一样 → 退回补全，不得作为候选交付。
- 两条豁免路径被合并成一句 → 退回拆分。
- A 层判负项被写成「需豁免」→ 判为错层，退回重判。

## 三、判定锁定与改判台账

### 判什么

判定必须**等幂**：输入指纹不变，结论不得变。
若结论变了，必须能指出**变化的具体输入值**——哪份文档、哪页、哪个数。答不出来即为无效改判。

### 怎么判

1. **输入指纹**在每份报告中固定列出，四项：
   - 应用工况（含供电、温区、信号链路位置）
   - 客户限定范围（明确排除的厂商／品类／封装）
   - 可改板与否
   - 参数优先级排序依据
2. **改判台账**逐次记录，不覆盖前次：

| 版本 | 输入指纹是否变化 | 变化的具体输入值 | 变化前结论 | 变化后结论 | 变更依据 |
|---|---|---|---|---|---|
| | | | | | |

3. 输入指纹未变而结论变了 → 判定过程本身出错，不是改判。须回头修流程，不得归档为新版。

### 判不过怎么办

- 无法指出变化输入值 → 本次改判作废，结论回到上一版本。
- 同一输入指纹下出现两次以上结论翻转 → 暂停交付，先修遍历或参数对齐环节。

## 四、终局态门槛

### 判什么

交付结论必须处于**终局态**：首选料的判定已跑完，不存在「待核对」的关键项。

### 怎么判

终局态三条，缺一即降为阶段结论：

1. 首选料的判定所依赖的原厂数据**已取得**（含 pinout 表），而非厂商口头或标称。
2. 厂商标称项（如「管脚兼容」）**已逐项核对**，核对前不得按该项成立判定。
3. 需实测或需索取的数据，已在报告中列为**硬卡点**，并标明由谁取得、取得前该结论不可用。
4. **首选料须出自「合规候选」**。列为首选的「需豁免候选」必须已取得客户书面豁免并登记入台账（见第二节第 7 条），否则只能作为备选。

### 判不过怎么办

未达终局态 → 报告抬头标「阶段结论」，不得用于量产替代决策，不得按终局结论定价。
