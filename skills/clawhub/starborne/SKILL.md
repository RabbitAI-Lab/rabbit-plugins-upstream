# STARBORNE 设计规则

> 本文件是引擎实际运行的**真实规则**，干净版，唯一权威来源。  
> 一句话定位：一个**用文字模拟暗黑式刷子爽感**的文字游戏——花钱抽、真实随机掉落、货舱收藏、卖/拆/升。

---

## 1. 核心循环（经济）

```
开局赠 300 Credits → 花钱抽(单抽5/十连45) → 真实随机掉落 → 进【货舱】
        ↓                                   ↑
   卖不要的装备换钱 ←──────────────┘
   没钱兜底：数羊（每5只=1钱，满100只额外奖30）
```

- \*\*钱（Credits）\*\*是唯一的硬资源。没有战斗、没有生命值。
- **抽直接花"钱"**：单抽 `5`、十连 `45`（十连为单抽 9 折）。
- **开局赠 `300` 钱**作为启动资金，解决"怎么开始赚钱"。
- **赚钱**：卖不要的装备（唯一来源）；没钱时数羊兜底（不卡死）。
- **数羊（严格逐只报数）**：`数羊 1 2 3 …` 把羊一只只枚举出来，引擎**与自然数序列 1,2,3… 逐位比对**，任意一位不等于它该有的自然数（漏的/重的/顺序错的/非整数，本质都是"某一位对不上"）即**判违例、0 钱**。每 5 只 = 1 钱（基础）；**每满 100 只额外 +30 钱**。即数满 100 只 = 50 钱（= 一次十连）。裸数字（如 `数羊 7`）不再被信任，必须给出完整连续数列。

### 卖价

| 档位    | 普通 | 行星 | 帝国 | 银河 | 远古 | 虚空 |
| ----- | -- | -- | -- | -- | -- | -- |
| 卖得（钱） | 2  | 5  | 15 | 50 | 50 | 50 |

> 银河/远古/虚空**统一封顶 50 钱**（避免暗金被贱卖）。

## 2. 六档稀有度

按概率定档，颜色沿用原始六档。

| 序 | 档位 | 颜色   | 掉落概率 | 生成方式       | 是否唯一     |
| - | -- | ---- | ---- | ---------- | -------- |
| 1 | 普通 | ⬜ 白  | 50%  | 随机         | 否        |
| 2 | 行星 | 🔵 蓝 | 30%  | 随机         | 否        |
| 3 | 帝国 | 🟡 黄 | 13%  | 随机         | 否        |
| 4 | 银河 | 🟠 橙 | 5%   | 随机         | 否        |
| 5 | 远古 | 🟢 绿 | 1.5% | **固定暗金名册** | 是（名册内）   |
| 6 | 虚空 | 🟣 紫 | 0.5% | **固定 2 件** | 是（仅 2 件） |

- 前四级（普通/行星/帝国/银河）= **纯随机生成**（滚词缀），名字每次实例独立。
- 后两级（远古/虚空）= **暗金（unique）**：固定名字 + 固定风味描述，掉落时从该档名册随机选一件模板，但每次都发**新的实例 ID**（可拥有"两把同模板的虚空"）。

## 3. 三层 ID 模型（核心架构）

每件掉落的物品由三层 ID 描述，互不混用：

| 层级               | 名称                  | 作用            | 现状                                 |
| ---------------- | ------------------- | ------------- | ---------------------------------- |
| **① 实例 ID（iid）** | 每次掉落新发、绝对唯一         | 货舱追踪、卖/拆/升的句柄 | `uuid4` 底层键 + 时间戳+UUID短码展示码        |
| **② 基础类别模板 ID**  | 装备"种类" = 槽位 + 基础模板名 | 定义类别：武器/盔/甲…  | `SLOT_TEMPLATES`（**143 种**，见 §3 ②） |
| **③ 暗金模板 ID**    | 固定名+固定风味的唯一条目       | 远古名册 / 虚空 2 件 | `UNIQUE_ROSTER` / `VOID_ITEMS`     |

### ① 实例 ID（iid）—— 时间戳 + UUID 短码（去中心化）

- **编码格式**：`档位码-槽位码-后缀`，例如 `P-HD-ggy2a0f2`、`G-WT-gkxwf1d1`。三段含义：
  - 档位码：普通 `P` / 行星 `B` / 帝国 `E` / 银河 `G` / 远古 `A` / 虚空 `V`
  - 槽位码：武器 `WPN` / 头部 `HD` / 铠甲 `BD` / 足部 `FT` / 腰部 `WT` / 饰品 `AC` / 特殊 `SP` / 杂物 `JD`
  - 后缀（8 位）= **时间戳 base36 后 4 位**（大致顺序/进度感）+ **UUID 前 4 位**（唯一兜底）
- **底层唯一键 `uid`**：每件装备落库时由 `uuid.uuid4().hex`（128 位）生成并保存，是查找（卖/拆/升）的真实主键，**不依赖任何外部计数器**。
- **健壮性**：唯一性由 UUID 保证（碰撞概率 ≈ 2⁻¹²⁸，可忽略）；时间戳仅是展示用顺序感，即使时间戳回拨/损坏也不影响唯一性。**实例身份与存档内任何计数完全解耦**，存档计数损坏也不会导致重复或崩溃。
- **命令输入**：① 完整 `uid`（最精确，引擎优先匹配）；② 完整编码（如 `卖 P-HD-ggy2a0f2`）；③ 兼容旧存档的纯序号（如 `卖 12`）。

### ② 基础类别模板（SLOT_TEMPLATES）—— "掉落物种类大全"的地基

装备按 **7 个槽位**分类，每个槽位下列出基础模板名（共 **143 种**，腰带稍少、饰品最多）：

| 槽位 | 数量 | 来源构成（原创科幻 / 魔兽3经典 / 星际1战役）                                                                     |
| -- | -- | ---------------------------------------------------------------------------------------------- |
| 武器 | 34 | 震击枪等原创 15 + 攻击之爪/科勒匕首/风暴战锤/萨满之矛/食人魔力量斧/法球×6 + C-14高斯步枪/阿克莱特冲击炮/聚变切割器/喷火器/双管机炮/导弹舱/U-238贫铀弹/灵能刃 |
| 头部 | 13 | 全原创（作战头盔、蒸馏面罩…深空盔）                                                                             |
| 铠甲 | 21 | 作战护甲等原创 14 + 法师长袍/智力斗篷 + 马克V战斗服/新钢铁装甲/泰坦反应堆/几丁质装甲/虫族甲壳                                         |
| 足部 | 14 | 沙行靴等原创 13 + 速度之靴                                                                               |
| 腰部 | 11 | 悬浮腰带等原创 10 + 巨人力量腰带                                                                            |
| 饰品 | 33 | 护身符等原创 22 + 加速手套/回复指环/索比面具/王者之冠/阿利亚之笛/死亡面罩 + 凯达琳水晶/神经突触/肾上腺/灵能发射器/圣物                           |
| 特殊 | 17 | 悬浮战车等原创 15 + 等离子护盾/引力引擎                                                                        |

> 共 **143 种**基础模板，三源混搭（原创科幻 + 魔兽3经典装备 + 星际争霸1战役具名件）。完整清单见 `starborne.py` 的 `SLOT_TEMPLATES`。魔兽3件保留"之"字（攻击之爪/速度之靴/火焰之球…为 2字+1字 结构，去"之"失味）；仅"科勒的匕首"因 2字+2字 结构去"的"成"科勒匕首"，避免与 P1 前缀"碎星的"叠出双"的"。

- 随机档掉落流程：`选档位(rng) → 选该槽基础模板(rng) → 滚词缀生成名字`。命名段数按档分级（越长越隆重）：
  - **普通 / 行星** → 两段 `P1前缀 + 基础`（破烂本就该短；普通另含 13% JUNK 整名分支）
  - **帝国 / 银河** → 三段 `P1前缀 + P2修饰 + 基础`（开始隆重）
  - **远古 / 虚空** → 不走随机词缀，取固定暗金名
- **P2 修饰词是 7 槽通用的公共池（35 词，见 `P2` 常量）**，不分槽位专有——星际大乱炖，各类修饰可混搭任意装备。实现层沿用原始「冲突规避规则」：修饰首字不与基础名首字相同、且修饰词不埋于基础名中，规避「脉冲脉冲步枪」式叠字与双重修饰。P2 与 **P4 高级属性词缀池（14 词：永恒/湮灭/星核/超载/共鸣/觉醒/创世/灭世/浩劫/禁忌/无限/超维/宿命/涅槃）零重叠**，P4 仅供远古/虚空档高级前缀、严禁进 P2（当前随机档不实际生成 P4，词池保留于 `P4_HIGH`）。
- **可扩展性**：新增装备"种类"只需往 `SLOT_TEMPLATES` 加条目，**掉落逻辑自动覆盖，无需改其他代码**。

### ③ 暗金模板（UNIQUE_ROSTER / VOID_ITEMS）—— 固定唯一物

- `UNIQUE_ROSTER`（远古名册）：字典，`key` 形如 `"A01"…"A12"`，`value = {name, en, slot, flavor}`。掉落时等概率选一件模板。
- `VOID_ITEMS`（虚空，仅 2 件）：`key` 沿用历史编号 `"99536"/"99537"`，`value` 同上结构。
- 生成的实例带 `"unique": True, "template_id": 该key`，与随机档区分。

## 4. 暗金编码与可扩充性

**能随便增。** 新增一件暗金 = 往对应字典加一条，引擎自动纳入掉落池。建议统一编码规范：

| 档位 | key 前缀      | 示例           | 容量               |
| -- | ----------- | ------------ | ---------------- |
| 远古 | `A` + 2 位序号 | `A13`、`A14`… | A01–A99（最多 99 件） |
| 虚空 | `V` + 2 位序号 | `V01`、`V02`… | V01–V99          |

> 当前虚空仍沿用历史编号 `99536/99537`，不影响功能；后续新虚空建议改用 `V` 前缀与远古的 `A` 区分。每条暗金只需填 4 个字段：`name`（中文名）、`en`（英文名）、`slot`（归属槽位）、`flavor`（一句风味描述）。

## 5. 装备槽（仅作类别分类，无穿戴）

- 装备按 7 个槽位分类（武器/头部/铠甲/足部/腰部/饰品/特殊，见 §3 ②），**仅用于掉落时确定类别与实例 ID 的槽位码**，不参与任何玩法限制。
- **无"穿/脱下/已装备"概念**：装备是收藏品/可卖/可拆/可升，没有硬性槽位数量限制。

## 6. 拆解 / 升级 / 合成

### 拆解

全部六档都能拆，但**前三级（普通/行星/帝国）空手而归**（不出材料，等于销毁）；4 级及以上出材料：

| 拆解档位 | 产出材料                                  |
| ---- | ------------------------------------- |
| 银河   | 星尘结晶                                  |
| 远古   | 太古原石                                  |
| 虚空   | Gem of the Space 或 Mirror of the Void |

### 升级

`升级 [实例ID]`：逐级提升 `普通 → 行星 → 帝国 → 银河 → 远古 → 虚空`，各耗对应材料（普通/行星/帝国耗星尘结晶，银河耗太古原石，远古升虚空耗 1 个虚空材料）。

> **重要区分**：通过升级"升到"远古/虚空的物品，**仍是随机生成物、非唯一**（名字不变、无暗金模板、无风味描述）；只有"摇出来"的远古/虚空才是真正的固定暗金。

### 合成（反向）

`2 星尘结晶 → 1 太古原石`（缓解材料瓶颈）。

### 材料自动掉落

掉落时按档位有概率额外掉材料：银河 2.5%、远古 0.75%、虚空 0.25%。

## 8. 扩展清单（留作后续）

1. **装备种类扩充**（§3 ②）：往 `SLOT_TEMPLATES` 加车辆/法器等新槽或新基础模板。
2. **暗金增删**（§4）：按 `A`/`V` 编码规范往名册加条目。
3. **顶层物品大类**：当前掉落只产出"装备 + 材料"。消耗品/货币类（如口粮、Credits 直接掉）可按需接入 `SLOT_TEMPLATES` 同级的大类表。
4. **穿戴系统回流**（如需）：若想恢复"穿装备"玩法，再定义槽位上限与穿戴增益，实例 ID 的槽位码已为此预留。
