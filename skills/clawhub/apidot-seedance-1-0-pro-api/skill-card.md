## Known Risks and Mitigations: <br>
Risk: APIDOT_API_KEY or private prompt and media data could be exposed in browser code, logs, screenshots, public repositories, or chat output. <br>
Mitigation: Keep API keys in server-side environment variables or a backend secret manager, and avoid logging private prompts, media URLs, generated video URLs, callback URLs, or credentials. <br>
Risk: Seedance 1.0 Pro request fields, pricing, limits, or availability may be outdated if copied from memory or from a different video model family. <br>
Mitigation: Verify current APIDot model pages and API docs before preparing payloads or making product, reliability, or commercial claims. <br>
