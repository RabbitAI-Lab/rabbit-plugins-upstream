## Description:

Restructure one page passage by passage so ChatGPT, Perplexity, Copilot, Claude and Google AI Overviews can lift accurate, self-contained answers that name your brand.

This skill is ready for commercial/non-commercial use.

## Publisher:

[romeoseo](https://clawhub.ai/user/romeoseo)

### License/Terms of Use:

MIT-0

## Use Case:

SEO and content teams use this skill to revise one existing web page so its sections answer buyer questions clearly and carry checkable facts. It returns a passage-level before-and-after diff, fact sources, identified blockers, and a re-test plan.
