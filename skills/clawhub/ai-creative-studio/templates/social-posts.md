# Social post scaffolds (US)

Copy the block for the platform you are shipping to. Every block expects a
normalized brief: `product`, `audience_short`, `offer`, `proof[]`, `cta`, `tone`.

---

## TikTok (9:16, 15-30s, captions ON)

```
HOOK (0-2s): <hook text>
ON-SCREEN: <proof, max 6 words>

CAPTION:
<hook text>

<proof_first>

<cta>

#<category> #<audience> #<use_case> #fyp
```

- 3-5 hashtags, lowercase+PascalCase mix, no banned/spam tags.
- Pin a comment that answers the most common objection.
- First comment must not be a link (TikTok down-ranks link comments).

---

## Instagram feed (4:5)

```
IMAGE: <image id from prompt_set.json>
ALT TEXT: <product> - <one short factual description>. No text.

CAPTION (first 125 characters carry the hook):
<hook text>

<proof_first>
<one line of value>
<cta>

. . .
#<category> #<audience> #<use_case>
```

- 3-5 hashtags.
- First comment: add the link + the FAQ answer.

---

## Instagram Stories (9:16, 5 frames)

```
Frame 1: <hook text>            (text only, high contrast)
Frame 2: <proof_first>           (product shot)
Frame 3: <proof_first>           (lifestyle shot)
Frame 4: <offer>                (price + shipping)
Frame 5: <cta>                  (swipe up / link sticker)
```

---

## LinkedIn (1200-1800 chars, no emoji walls)

```
<hook text>

<one short paragraph: the problem, in plain language>

<proof_first>. <what that means for the reader's week>

-<three short bullets, no emoji>
-<proof> -> <what it changes>

<cta>
```

---

## X (under 280 characters, link last)

```
<hook text> <proof_first_short>. <cta> <link>
```

---

## Facebook post (image + text)

```
<hook text>

<proof_first>

<cta>
```

## Email (see the email sequence in the creative pack)

```
Subject: 30-45 characters, no emoji, no RE:
Preview: 40-90 characters that continue the subject
Body: one idea, one CTA, one link
```
