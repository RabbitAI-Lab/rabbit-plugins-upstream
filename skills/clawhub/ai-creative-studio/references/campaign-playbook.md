# US launch & testing playbook

## Standard 14-day US launch

| Day | Action | Owner output |
| --- | --- | --- |
| 0 | Ship landing page + 3 creatives | Page live, tracking on |
| 1 | TikTok #1 + IG #1 organic | 2 posts |
| 2 | Meta ad set A (3 variations) | $50-100/day |
| 3 | TikTok #2, reply to every comment | 1 post + 20 replies |
| 4 | Google RSA live | 15 headlines / 4 descriptions |
| 5 | Retarget: video viewers 50%+ | 1 ad set, $20/day |
| 6-7 | Read comments, mine objections | New hook list |
| 8 | Launch ad set B (new hooks, same offer) | 3 variations |
| 9 | Email 1 (welcome) | Sent to list |
| 10-12 | TikTok #3-5, IG carousels | 3 posts |
| 13 | Kill bottom 50% of creatives, scale winners | Budget moved |
| 14 | Read numbers, write the next brief | Decision memo |

## Metrics that matter for a US SMB

- **Hook rate** = 3s views / impressions (TikTok), target > 30%.
- **Hold rate** = views at 6s / 3s views, target > 55%.
- **CTR** = link clicks / impressions. Meta > 1%, TikTok > 0.9%.
- **CVR** = purchases / landing page views, target 2-4% for DTC.
- **CAC** = spend / new customers. Compare to gross margin, not revenue.
- **ROAS** = revenue / ad spend. Judge against contribution margin.
- **Email**: open rate (Apple MPP inflates it - judge on clicks), click rate > 2.5%.

## Budget split (US SMB, <$5k/mo)

```
60% Meta          (best for DTC + B2B retargeting)
20% TikTok        (creative testing, cheap reach at the start)
10% Google       (Brand + high-intent search only early on)
10% Production    (UGC, editing, thumbnails)
```

## Testing rules

- Change one variable per test: hook, offer, or creative format - never two.
- Minimum 3 variations per ad set.
- Do not judge a creative before ~1000 impressions or ~20 clicks.
- Kill winners are rare - kill the bottom third, scale the top third.
- Keep a "loss log": what you tested, what it cost, what happened.

## Copy iteration loop

1. Read the top comment and the top objection from ad comments.
2. Turn it into a hook (`Objection` -> `hook type`).
3. Drop the new hook into the same ad set as variation D.
4. Keep the winner for 7 days, then move to a new offer.

## US compliance checklist before spend

- [ ] No fake reviews, ratings, or customer counts anywhere on the page.
- [ ] No health/medical claims without legal review.
- [ ] "Free" claims are literally true.
- [ ] `Made in USA` only if true; otherwise `Ships from USA`.
- [ ] Landing page shows a real US address, real support email, and returns policy.
- [ ] Discount claims show the real reference price and dates.
- [ ] Email capture has a working unsubscribe and a privacy policy link.
- [ ] No auto-play audio that startles on mobile.
