# Example prompt: dashboard stat card

Build a reusable dashboard stat card for Minimal UI Next.js.

Requirements:
- Props: title, value, trend (number), icon name (Iconify icon), color theme (`primary`, `secondary`, `info`, `success`, `warning`, `error`).
- Use `Card` and `Stack`.
- Show the icon in a soft-colored rounded square.
- Show title, large value, and a trend label (e.g. "+12% from last month").
- Use theme colors only; no hardcoded hex.
- Make it responsive and accessible.
