# Decision: Money path — content site first

**Date:** 2026-07-14
**Decision:** Prioritize the automated content site (igamingreviews.org) and dealwork.ai service work over prediction markets and referral farming.

**Why:**
- Trevor wants income with minimal human involvement; content pipeline is the chosen vehicle.
- Prediction markets: Trevor himself called the risk/reward "pointless" without real edge (risking $50 to win $2–8). Simmer is a learning sandbox only.
- Referral farming: blocked by anti-abuse systems (moltcities.org Cloudflare WAF, error 1010).
