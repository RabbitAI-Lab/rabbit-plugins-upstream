# 商品评分规则说明

## 评分维度及权重

### 1. 销售贡献度（权重30%）

**指标构成：**
- 支付金额占比（18%）：商品支付金额 / 店铺总支付金额
- 支付买家数占比（9%）：商品支付买家数 / 店铺总支付买家数
- 新客贡献度（3%）：新买家支付金额 / 商品总支付金额

**评分逻辑：**
- 支付金额占比 >= 10%：满分100
- 支付金额占比 5%-10%：80分
- 支付金额占比 2%-5%：60分
- 支付金额占比 < 2%：按比例计分（占比 * 3000）

### 2. 流量效率（权重25%）

**指标构成：**
- 流量转化率（15%）：支付买家数 / 访客数
- 曝光转化率（5%）：IPV / 曝光量
- 加购率（5%）：加购UV / 访客数

**评分逻辑：**
- 流量转化率 >= 5%：满分100
- 流量转化率 3%-5%：80分
- 流量转化率 1%-3%：60分
- 流量转化率 < 1%：按比例计分（转化率 * 2000）

### 3. 成长潜力（权重20%）

**指标构成（累计加分，最高100分）：**
- 平台标签加分：优品（is_hqp=1）+30分、潜力品（is_pwp=1）+20分、商机品（is_sjp=1）+15分、镇店之宝（is_zdzb=1）+10分
- 成长分层：`gyp_growth_level` 含"高"/"high" +20分，含"中"/"medium" +10分
- 严选商品（is_yx=1）：+5分（注意：此加分计入本维度子分，再按 20% 权重折算进综合得分，**不是**直接给综合得分加 5）

### 4. 营销ROI（权重15%）

**指标构成：**
- 广告ROI：支付金额 / 广告消耗

**评分逻辑：**
- 无广告消耗：有销售得100分，无销售得50分
- 广告ROI >= 5：满分100
- 广告ROI 3-5：80分
- 广告ROI 1-3：60分
- 广告ROI < 1：30分

### 5. 商品健康度（权重10%）

**指标构成（累计加分，最高100分）：**
- 服务能力：七天无理由退货 +10分、48小时发货 +10分、15天包换 +5分
- 库存充足性：库存 > 100 +10分，50-100 +5分，< 50 不加分
- 退款率：< 5% +10分，5%-10% +5分，> 10% 不加分

## 综合评分计算

**总分 = 销售贡献度得分 × 30% + 流量效率得分 × 25% + 成长潜力得分 × 20% + 营销ROI得分 × 15% + 商品健康度得分 × 10%**

## 商品分层标准

- **S级（≥80分）**：重点推广品 —— 加大投入，抢占流量，优化详情页，参与营销活动
- **A级（60-80分）**：潜力培育品 —— 针对性优化短板，适度增加预算，测试潜力
- **B级（40-60分）**：维持运营品 —— 维持现状，定期检查，作为辅助商品
- **C级（<40分）**：优化调整品 —— 停止广告，诊断问题，考虑优化或下架

## 与 Step 0.5 第二发现入口的关系

`score_and_select` 本身不产出"新品"标签（无上架天数等字段可用于判定），C 级商品单纯是综合评分低于 40 分，可能是新品（无历史数据、各维度天然偏低），也可能是长期低效品。若需要判断"这是不是新品"，由 Step 3 诊断阶段基于 `alibaba.1688.get.offer.data` 的数据自行判断（见 `references/analysis-dimensions.md` 的货盘定位标签），评分环节不做区分。
