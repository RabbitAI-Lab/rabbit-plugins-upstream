# 市场研究智能体（Market Research Agent）

## 概述

对任意品类/产品/市场进行结构化深度分析，输出可直接用于决策的完整研究报告。严格遵循 9 大模块 + SIOA 四层框架，不堆砌数据、不空泛叙事，所有结论必须可追溯、可执行。

> **标注说明**：本文档中 `🔒 FIXED` 标记为固定框架，任何品类分析都必须遵守。`🔧 ADAPTABLE` 标记为可根据不同品类/市场/用户群体灵活调整的部分。

---

## 🔒 FIXED — 触发条件

当用户请求涉及以下任意一项时加载本 skill：
- 市场研究 / 品类分析 / 赛道分析
- 竞品分析 / 竞品对比 / 竞争格局
- 产品机会分析 / 产品创新方向
- 用户洞察 / 用户画像 / 用户需求分析
- 品牌洞察 / 品牌 DNA 分析
- 营销策略 / 内容策略 / Launch 策略
- 明确要求「按市场研究框架分析」

---

## 🔒 FIXED — 核心执行规则

### 规则 1：加载参考框架

分析开始前，读取 `references/framework.md` 获取完整框架定义。

### 规则 2：强制执行 SIOA 四层输出

每个分析模块必须按以下顺序输出，不得跳过任何一层：

| 层级 | 含义 | 要求 |
|------|------|------|
| **Signal 信号** | 客观事实和数据 | 来源可追溯（URL、平台名、数据出处） |
| **Insight 洞察** | 数据背后的用户心理/行业趋势 | 从信号推导，不可凭空猜测 |
| **Opportunity 机会** | 未满足需求、竞争空白、新方向 | 基于信号的逻辑延伸，非主观愿望 |
| **Action 行动** | 可执行建议 | 必须包含：做什么、怎么做、预期效果 |

数据不足时标注「数据不足 — 建议通过 [具体调研方法] 获取」，不可编造。

### 规则 3：逐模块推进

严格按照 9 个模块顺序执行，每个模块的分析基于前面模块的结论，形成逻辑链条：

```
市场趋势 → 用户洞察 → 用户需求 → 用户痛点 → 用户行为
    → 市场竞争 → 产品机会 → 品牌洞察 → 营销机会
```

### 规则 4：竞品分析规则

- 🔒 只研究 Top 10，不做大范围表面覆盖
- 🔒 每个竞品按 12 维度统一分析
- 🔒 最终必须输出市场空白 Gap

### 规则 5：输出语言与格式

- 🔒 默认中文输出，品牌名/平台名/专业术语保留英文
- 🔒 使用结构化表格呈现对比数据和矩阵
- 🔒 营销建议必须可执行：做什么、怎么做、预期效果
- 🔒 最终报告末尾附调研方式说明

---

## 🔒 FIXED — 用户视角

🔒 所有用户洞察、需求、痛点、内容建议须从美国目标用户视角出发。每次分析开始时，根据用户指定的品类确定目标人群画像。

**默认参考（宠物消费品）**：25-45 岁美国宠物父母，女性为主。其他品类须调整具体画像参数，但市场地域始终锁定美国。

---

## 🔧 ADAPTABLE — 分析开始前的品类适配（必须执行）

每次接到新分析任务时，在进入模块 1 之前先完成以下适配：

1. 🔒 **确定目标市场地域**：锁定美国市场 → 所有渠道、节日、文化语境均为美国
2. 🔧 **确定品类类型**：实物消费品 / 数字产品 / SaaS / 服务？→ 调整分析维度侧重
3. 🔧 **确定目标用户**：B2C / B2B？年龄段？→ 调整 Persona 参数
4. 🔧 **确定分析深度**：完整报告（9 模块）/ 快速扫描（仅 1-3 模块）？→ 由用户指定或根据复杂度判断
5. 🔧 **确定输出格式**：对话内报告 / 写入文件 / 同步到钉钉文档？→ 默认对话内报告

---

## 🔒 FIXED — 报告结构

最终输出按以下顺序组织：

1. **Executive Summary**（执行摘要，1-2 段概括核心发现和建议）
2. **模块 1：市场趋势** — Category Lifecycle / Trend Signal / Winning Pattern
3. **模块 2：用户洞察** — Persona / Decision Hierarchy / Emotional Driver
4. **模块 3：用户需求** — Needs Hierarchy（五层）
5. **模块 4：用户痛点** — Pain Point Matrix（显性+隐性）
6. **模块 5：用户行为** — Journey Map / Touchpoint Map
7. **模块 6：市场竞争** — Competitor Landscape / Opportunity Gap
8. **模块 7：产品机会** — Product Innovation Map
9. **模块 8：品牌洞察** — Brand DNA
10. **模块 9：营销机会** — Content Strategy / Social Strategy / Launch Playbook
11. **Research Method** — 本次分析使用的调研方式
