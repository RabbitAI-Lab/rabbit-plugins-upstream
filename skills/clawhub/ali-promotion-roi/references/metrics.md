# ROI 分析 — 指标口径说明

## 核心 KPI

### CPO（Cost Per Order，单订单成本）

```
CPO = 推广花费 (CNY) / 完成订单数
```

- **越低越好**
- 单位是 CNY，不是 USD——因为成本就是人民币
- 订单数仅算 `order_status = '订单完成'`

### ROI（Return On Investment，投资回报率）

```
ROI = (完成订单金额 USD × USD/CNY 汇率) / 推广花费 CNY × 100%
```

- 衡量每投 1 元人民币，能换回多少人民币的订单金额
- **100% = 收支平衡**，> 100% 盈利，< 100% 亏损
- 示例：投 1000 CNY，订单金额 800 USD（按 7.2 汇率 = 5760 CNY），ROI = 576%

### 投入产出比（另一个常见口径）

```
投产比 = 订单金额 / 花费
```

但**币种必须统一**：要么都换算成 CNY，要么都换算成 USD。

## 推广系统 `order_cnt` vs 实际完成订单

| 维度 | `promotion_daily.order_cnt` | `orders` (status='订单完成') |
|------|---------------------------|------------------------------|
| 来源 | 阿里推广后台（实时） | 订单系统（事实） |
| 归因窗口 | 默认 1 日累计 | 订单创建时间所属日 |
| 状态 | 可能是"下单"而非"完成" | 严格"完成" |
| 退款 | 已计入 | 不计入（订单完成 = 已发货已收款） |

**典型偏差**：
- 推广报 1 单，实际 `订单完成` 0 单 → 那一单可能在退款/关闭流程中
- 推广报 0 单，实际有订单 → 来自自然流量 / 老客户复购 / 其他渠道

## 时间口径

### 1 日累计周期

阿里国际站推广默认转化周期是 **1 日累计**（点击 → 订单在当天发生）。

但**实际消费者行为**经常跨日：
- 用户白天点击广告 → 当晚下单 → 次日订单创建时间
- 因此严格按 `data_date` join 会有 1~2 天误差

**改进方法**（不在本 skill 范围）：
1. 导出推广数据时改用 **7 日 / 30 日累计** 转化周期
2. 给订单打推广归因标签（首次点击来源、最后点击来源）

## 推广类型拆分

- `standard_promotion` 标准推广：商家主动出价，覆盖关键词
- `sitewide_promotion` 全站推广：智能投放，覆盖更广

按类型看 ROI，可以判断**哪条线效率更高**。但要注意：
- 全站推广通常预算更大
- 标准推广通常 CPC 更高但转化更精准

## 按日对照洞察模板

```
日期         花费CNY   后台报订单   实际完成   实际金额USD
01-16           0         0          1        $1,024.00   <- 自然流量
01-22       ¥208.45       0          1        $  220.00   <- 推广带来
01-24       ¥103.97       1          0        $    0.00   <- 后台报1单但未完成
01-25~31  ¥1,002.72      0          0        $    0.00   <- 纯投入无产出!
```

**重点关注**：
1. 花费 0 但有订单 → 自然流量 / 复购
2. 花费 > 0 但完成 0 → 转化漏斗断在哪？
3. 后台报订单 ≠ 实际完成 → 排查状态流转
