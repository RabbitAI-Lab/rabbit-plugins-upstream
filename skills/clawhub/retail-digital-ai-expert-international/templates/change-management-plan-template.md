## 3. ADKAR Change Plan

### 3.1 Awareness

**Goal**: Everyone knows "why we are changing" and "what it means for me."

| Activity | Audience | Timing | Channel | Key Message |
|----------|----------|--------|---------|-------------|
| CEO All-Staff Letter | All Staff | | Email / Enterprise Messaging (Slack/Teams) | Change vision + leadership commitment |
| Change Kick-Off | Management | | In-Person Meeting | Industry trends + competitive landscape + cost of inaction |
| Store Briefings | Store Staff | | Store Manager Morning Huddle | "The store next door adopted this and saw commissions increase by XX" |

### 3.2 Desire

**Goal**: Everyone is willing to participate in the change.

| Activity | Audience | How to Motivate | Owner |
|----------|----------|-----------------|-------|
| Model Store Visit | Store Managers | See firsthand — "adoption = better results" | |
| Personal Benefit Alignment | Store Associates | "Commission up by XX" + "No more overtime stocktaking" | |
| Competitive Pressure | Management | "Competitor ____ has already achieved ____" | |

### 3.3 Knowledge

**Goal**: Everyone knows how to use the new system.

| Course | Audience | Duration | Format | Assessment |
|--------|----------|:--------:|--------|------------|
| New System Overview | All Staff | 30 min | Video | — |
| Checkout Operations (Basic) | Store Associates | 1 hr | Hands-On + Video | 3 consecutive error-free transactions |
| Checkout Operations (Advanced) | Store Managers / Key Staff | 2 hr | Hands-On + Scenarios | Pass all 5 scenarios |
| Inventory Management | Store Managers / Warehouse | 1.5 hr | Hands-On | Stocktake variance <2% |
| Membership Management | Associates / Managers | 1 hr | Hands-On | Complete enrollment + lookup independently |
| Reports & Analytics | Store Managers / Management | 2 hr | Demo + Hands-On | Interpret 3 reports independently |
| System Administration | IT | 4 hr | Hands-On | Resolve common issues independently |

### 3.4 Ability

**Goal**: Everyone can use the system proficiently — muscle memory.

| Activity | Timing | Format |
|----------|--------|--------|
| Sandbox Practice Period | 2 weeks before go-live | Free practice in sandbox environment, unlimited attempts |
| Buddy System | 2 weeks after go-live | One "Digital Champion" per store as mentor |
| Peak-Hour Simulation | 1 week before go-live | Simulated peak-hour operational assessment |
| On-Site Support | 1–2 weeks after go-live | IT + vendor on-site, real-time Q&A |

### 3.5 Reinforcement

**Goal**: New behaviors become new habits.

| Activity | Timing | Format |
|----------|--------|--------|
| Operations Dashboard | Ongoing after go-live | Daily report: who is using / not using / making errors |
| Instant Rewards | 1 month after go-live | "Zero-Error Award" — $50–100 instant payout |
| Monthly "Digital Star" | Ongoing after go-live | Recognition + announcement + bonus |
| KPI Integration | Starting month 2 after go-live | System usage rate included in performance evaluation |
| Bi-Weekly Retrospective | Ongoing after go-live | Issues → Feedback → Optimization → Update |

## 5. Resistance Management

### 5.1 Typical Resistance Patterns & Responses

| Resistance Type | Typical Comment | Response Strategy |
|-----------------|-----------------|-------------------|
| **Owner** | "Too expensive / not sure about the value" | Build the business case → small-scale pilot → let the data speak |
| **Store Manager** | "No time to learn / this adds to my workload" | Prove the system reduces workload (e.g., scheduling saves 2 hr/week) |
| **Veteran Associate** | "I've done checkouts for 15 years without a system" | Respect experience + demonstrate efficiency gains + incentive bonuses |
| **Mid-Career Associate** | "I can't use this / it's too hard" | Video tutorials + 1-on-1 buddy mentoring + extra practice opportunities |
| **Franchisee** | "HQ is micromanaging me again" | Start with supply chain (cost savings) → show benefits → voluntary adoption |
| **IT Department** | "Another new system to learn" | Career path + certification + promotion opportunities |

### 5.2 Resistance Escalation Mechanism

```
Level 1: Individual non-usage → Direct manager conversation → Understand reasons → Provide support
Level 2: Continued non-usage → Change Lead intervention → Custom coaching plan
Level 3: Open resistance → Management meeting → Warning → Reassignment
```
