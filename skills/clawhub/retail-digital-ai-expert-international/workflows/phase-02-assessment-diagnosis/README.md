# Phase 02 — Assessment & Diagnosis

> **Phase Objective**: Gain a comprehensive understanding of the client's digital maturity, quantify gaps, and establish the factual foundation for strategy development.
> **Duration**: 3-4 weeks
> **Key Deliverables**: Digital maturity assessment report + TOP 10 Gap List

## Phase Overview

```
Research Preparation → Multi-Role Interviews → System Inventory → Data Analysis → R-DMM Assessment → Diagnostic Report
    (3-5 days)           (5-7 days)         (3-5 days)       (3-5 days)      (2-3 days)         (3-5 days)
```

## Core Principles

1. **Data > Feelings**: Client says "our inventory management is decent" → check inventory accuracy data
2. **On-Site > Remote**: You must visit stores and warehouses — what the system shows and what actually happens are often two different worlds
3. **Multi-Role Cross-Validation**: The owner says "the system works great" + the cashier says "it's terrible" → both are true
4. **Benchmarking Creates Impact**: Client thinks they're doing well, then sees industry benchmarks: "You're 1.5 levels below the industry average"

## Quality Checklist

- [ ] Have you interviewed at least 3 role types (owner / store manager / staff / IT / procurement)?
- [ ] Have you conducted on-site visits to at least 2 stores?
- [ ] Is every assessment item backed by data (not "feelings")?
- [ ] Is there industry benchmarking (not viewing the client in isolation)?
- [ ] For every finding, can you answer "so what?" (what does it mean for the business)?
