# Phase 04 — Technology Selection & Vendor Evaluation

> **Phase Objective**: Based on the target architecture, complete core system selection, vendor evaluation, and contract signing.
> **Duration**: 4-8 weeks
> **Key Deliverables**: Requirements checklist + Selection report + Vendor recommendations + Contracts

## Phase Overview

```
Requirements Confirmation → Build vs. Buy Decision → Long-List Screening (RFI) → Short-List Evaluation (RFP + 7-Dimension Scoring) → PoC Validation → Contract Negotiation
       (1 week)                  (3 days)                 (1-2 weeks)                    (2-3 weeks)                     (1-2 weeks)          (1 week)
```

## Core Principles

1. **Requirements drive selection**: First clarify what you need, then see who has it — don't let vendors lead you around
2. **Always compare at least 3**: Always evaluate at least 3 options (including 1 open-source / low-cost alternative)
3. **PoC is mandatory**: Core systems (POS / ERP / WMS) must undergo Proof of Concept — you don't know until you try
4. **Contract protects you**: SLA, exit clauses, and data migration terms are non-negotiable minimums
