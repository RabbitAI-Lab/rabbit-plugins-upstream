# Phase 07 — Implementation & PMO

> **Phase Objective**: Execute system deployment, integration, data migration, training, pilot, and full rollout according to plan.
> **Duration**: 8-16 weeks (depending on project complexity)
> **Key Deliverables**: Live systems + Acceptance report + Operations handover documentation

## Phase Overview

```
Detailed Planning → System Configuration → Integration Development → Data Migration → UAT Testing → Training → Pilot Go-Live → Full Rollout → Acceptance
     (1 week)           (2-4 weeks)            (2-4 weeks)         (1-2 weeks)    (1-2 weeks)  (2-3 weeks)  (2-3 weeks)    (2-4 weeks)   (1 week)
```

## Core Principles

1. **Pilot first, never "big bang"**: Start with 1-3 pilot stores → validate → then full rollout
2. **Data migration is the #1 pitfall**: Always allow 2x the time you think it will take
3. **The 30/70 rule**: Before go-live, 30% of effort is on technology, 70% on people and process
4. **Rollback plan must be ready**: Every go-live window must have a "way back" plan
