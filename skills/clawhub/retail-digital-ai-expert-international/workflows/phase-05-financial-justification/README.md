# Phase 05 — Financial Justification & Investment Decision

> **Phase Objective**: Based on selection results, complete TCO/ROI modeling, prepare the investment memo, and drive management approval.
> **Duration**: 2-4 weeks
> **Key Deliverables**: TCO model + ROI business case report + Investment memo

## Phase Overview

```
TCO Modeling → Benefit Quantification → ROI Calculation → Sensitivity Analysis → Investment Memo → Management Presentation
  (3-5 days)       (3-5 days)             (1-2 days)         (1-2 days)          (3-5 days)            (1 day)
```

## Core Principles

1. **Every number has a source**: Annotate each assumption with its origin (client data / industry benchmark / vendor commitment)
2. **Conservative estimates**: Use pessimistic values for benefits and optimistic values for costs — the resulting ROI is your floor
3. **Three-scenario analysis**: Pessimistic / Base / Optimistic — let decision-makers see the full picture
4. **Always calculate the cost of doing nothing**: Efficiency losses + opportunity costs + competitive erosion
