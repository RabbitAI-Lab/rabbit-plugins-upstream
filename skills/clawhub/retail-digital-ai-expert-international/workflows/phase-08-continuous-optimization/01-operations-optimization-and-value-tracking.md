# 01 — Operations Optimization & Value Tracking

> **Trigger**: System is live and running stably
> **Deliverables**: Monthly operations report + Health dashboard + Continuous optimization program + Phase 2 opportunity list

---

## 1. The Critical First 90 Days Post Go-Live

### Cadence

| Time | Focus | Key Actions |
|------|------|------|
| **Day 1** | Go-live day | Full on-site support, real-time monitoring, rapid response (<15 minutes) |
| **Day 2-7** | Week 1 stabilization | On-site support, daily bulletin, high-frequency issue fixes |
| **Week 2-4** | Stable operation | Gradual on-site withdrawal, remote support, weekly reports |
| **Month 2** | Habit formation | System DAU stable >85%, operational efficiency meets targets |
| **Month 3** | Value emergence | First batch of business KPI improvement data visible |

## 4. Continuous Optimization Flywheel

```
Collect Feedback ──→ Analyze & Classify ──→ Optimize & Improve ──→ Train / Notify ──→ Evaluate Impact
      ↑                                                                                      │
      └──────────────────────────────────────────────────────────────────────────────────────┘
```

### Feedback Collection Mechanisms

| Channel | Frequency | Owner |
|------|:---:|------|
| In-system "Feedback" button | Anytime | Product |
| Weekly store callback (phone) | Weekly | Customer Success |
| Monthly user satisfaction survey | Monthly | Customer Success |
| Quarterly business review meeting | Quarterly | PM + Business Lead |

### Optimization Priority

| Level | Criteria | Response Time |
|:---:|------|:---:|
| **P0 Fix Immediately** | Affects checkout / core business | Within 24 hours |
| **P1 Near-Term Optimization** | Affects efficiency but has workaround | Within 2 weeks |
| **P2 Schedule in Iteration** | Improves experience but not urgent | Next iteration cycle |
| **P3 Long-Term Consideration** | Nice to have | Add to backlog |

## 5. Phase 2 Planning

### Phase 2 Opportunity Identification

| Source | Method |
|------|------|
| Top 5 frontline feedback items | Collect most-complained-about / most-requested features |
| Data insights | System data reveals where efficiency can still be significantly improved |
| Industry trends | What new capabilities have competitors launched |
| New AI use cases | AI technology maturity changes → new use cases become feasible |

### Phase 2 Project Prioritization

Use the AI Scorecard: `tools/ai-use-case-priority-scorecard.md`

### Phase 2 Recommendation Report Structure

```
1. Phase 1 results review (data + value)
2. Current outstanding issues (exported from health dashboard)
3. Phase 2 opportunity list (source + expected value + investment)
4. Prioritization (RICE + scoring)
5. Phase 2 roadmap recommendation (timeline + budget + resources)
6. Organizational capability upgrade recommendations
```
