# 01 — Change Management Strategy

> **Trigger**: 4-6 weeks before system go-live
> **Deliverables**: Change management plan + training program + communication plan + resistance response playbook

---

## 1. Unique Change Management Challenges in Retail

| Challenge | Description | Impact |
|------|------|------|
| **Low frontline digital literacy** | Staff over 40 may have never used a smart POS | Steep learning curve |
| **High employee turnover** | Retail annual turnover rates of 60-100% | Training investment can be "wasted" |
| **Checkout is the lifeline** | POS failure during peak hours = queues + complaints + revenue loss | Go-live must be 100% stable |
| **Sales associates' habits die hard** | "I'm great at recommending verbally" → resistance to smart guided selling | Must prove "using the system = higher commission" |
| **Owner makes the call** | In SMBs, the owner's attitude decides everything | Must win the owner over first |

---

## 2. ADKAR — Retail-Specific Implementation

| ADKAR | For Owner / Store Manager | For Frontline Staff / Sales Associates | Key Actions |
|------|------|------|------|
| **A**wareness | "Competitors who adopted this system improved inventory turnover by 15 days" | "With the new POS, checkout is twice as fast — go home 30 minutes earlier" | CEO all-hands email + store briefings |
| **D**esire | ROI calculation + competitor case studies + industry trends | Personal benefit tie-in: "Commission up by $[X]/month" | Flagship store visits + personal benefit statement |
| **K**nowledge | Manager bootcamp + BI report training | 3-minute video tutorials + sandbox practice + buddy system | Training + exam + retake |
| **A**bility | Data-driven decisions: "Dashboard → Analysis → Decision" | Checkout / inventory lookup / member operations → muscle memory | Peak-hour simulation + on-site support |
| **R**einforcement | KPI linkage + digital metrics in performance reviews | Immediate positive feedback + zero-error operation rewards + monthly "Digital Star" award | Daily reports + rewards + retrospectives |

---

## 3. Five-Step Training Method

```
Watch Once (3-5 min video) → Do Once (20 min hands-on) → Teach Once (train a colleague) →
Test Once (peak-hour simulation) → Reward Once (immediate reward)
```

| Step | Method | Duration | Pass Standard | Remediation if Not Met |
|------|------|:---:|------|------|
| Watch Once | Short video tutorial (3-5 min per scenario) | 5-15 min | Watched = complete | Rewatch |
| Do Once | Sandbox environment + buddy observing | 20-30 min | Independently complete 1 full workflow | Practice 3 more times |
| Teach Once | Employee teaches another new colleague | 15 min | Being able to teach = truly learned | Re-learn, then re-teach |
| Test Once | Peak-hour simulation practical exam | 15 min | 3 operations, 0 errors | Retake (max 3 attempts) |
| Reward Once | Pass = immediate reward (cash / points / public recognition) | Immediate | Reward received = behavior reinforced | — |

## 4. Change Communication Plan

| Phase | Timing | Communication Content | Channel | Audience |
|------|------|------|------|------|
| **Warm-Up** | 4-6 weeks before go-live | "Why change" + "industry trends" + "what competitors are doing" | All-hands email / management meetings / store morning huddles | All |
| **Training** | 2-4 weeks before go-live | Training schedule + learning resources + reward mechanism | Slack/WeCom channels / bulletin boards / morning huddles | All |
| **Go-Live Week** | Go-live week | Daily bulletin (progress + shout-outs + issues + tomorrow's focus) | Slack/WeCom channels | Management + stores |
| **Stabilization** | 1-4 weeks post go-live | Weekly report (data + best practices + Q&A) | Email / Slack/WeCom | Management + stores |
| **Sustainment** | 1 month+ post go-live | Monthly "Digital Star" awards + quarterly retrospectives | All-hands email + recognition events | All |

## 5. Resistance Management

### Resistance Warning Signals

| Signal | What It Means |
|------|------|
| System daily active usage rate declining | People are starting to abandon it |
| Abnormal frequency of "system is broken" reports from a specific store | Possibly deliberately finding excuses not to use it |
| "The old way was just fine" | Internal resistance |
| Franchisees secretly using the old system | Enforcement insufficient or incentives misaligned |

### Tiered Response

| Level | Manifestation | Response |
|:---:|------|------|
| L1 | Individual staff not using | Direct supervisor intervention → understand the reason → provide coaching |
| L2 | Entire store / region not using | Change lead intervention → customized coaching plan → deadline for compliance |
| L3 | Open resistance / spreading negativity | Formal management conversation → written warning → reassignment as last resort |

## 6. Change Success KPIs

| Metric | Target | Measurement Method | Frequency |
|------|:---:|------|:---:|
| System daily active usage rate | >85% | System backend DAU statistics | Daily |
| Training pass rate | >95% | Exam scores | Pre-go-live |
| Checkout operation time | <25 sec/transaction | POS system statistics | Weekly |
| Employee satisfaction | >80% | Anonymous survey | Monthly |
| Operation error rate | <2% | System log analysis | Weekly |
| Change health score | >80% green | Five-dimension assessment | Monthly |

---

## 7. Common Pitfalls

1. **Training only once**: Train once and assume everyone has it → must have "Watch → Do → Teach → Test → Reward" closed loop
2. **Neglecting older workers**: Design 1-on-1 coaching specifically for colleagues who "aren't great with smartphones"
3. **No immediate reward**: "Using it will pay off" is too distant → "Learn it today, earn $50 today" works instantly
4. **Communicating change only once**: Requires repeated communication — Warm-Up + Training + Go-Live Week + Stabilization + Sustainment
