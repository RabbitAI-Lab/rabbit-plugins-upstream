# Phase 06 — Change Management & Organization Design

> **Phase Objective**: Ensure that after system go-live, "people actually use it and use it well." Build the digital organization and capabilities.
> **Duration**: Ongoing (start change management 4-6 weeks before go-live)
> **Key Deliverables**: Change management plan + Training program + Digital organization design

## Phase Overview

```
Change Impact Analysis → ADKAR Five-Stage Plan → Communication & Training → Digital Org Design → Continuous Reinforcement
       (1 week)              (1-2 weeks)              (3-4 weeks)            (1-2 weeks)            (Ongoing)
```

## Core Principles

1. **Change management = 50% of system success**: The best system that nobody uses = failure
2. **Training investment >= 30% of system investment**: Teaching staff how to use the system matters more than choosing the right one
3. **Reduce burden before adding value**: Make staff feel "this makes my job easier" not "they're micromanaging me again"
4. **Immediate rewards > distant promises**: A $50 cash reward for learning today beats "this will help your career"
