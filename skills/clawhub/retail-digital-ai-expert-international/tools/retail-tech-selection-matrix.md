## 4. Dimension Scoring Criteria

### 4.1 Retail Format Fit (Weight 25%)

| Score | Criteria |
|:---:|------|
| 1 | Cannot support your format's core requirements |
| 2 | Barely supported; requires extensive customization |
| 3 | Supports basic requirements but lacks industry best practices |
| 4 | Well supports your format; multiple peer reference cases |
| 5 | Industry-best; the benchmark choice for your format |

How to evaluate:
- Does the demo cover your core scenarios?
- Are there at least 3 reference customers of similar scale/format?
- Does the product roadmap align with your business direction?

### 4.2 TCO - Total Cost of Ownership (Weight 20%)

| Score | Criteria |
|:---:|------|
| 1 | Far exceeds budget (>150%) |
| 2 | Over budget (100-150%) |
| 3 | Within budget range (80-100%) |
| 4 | Under budget (60-80%) |
| 5 | Far under budget (<60%) |

TCO includes:
- Software subscription / license fees (all modules)
- Implementation fees (deployment + customization + integration)
- Hardware costs (POS / servers / networking)
- Training fees
- Annual maintenance / support fees
- Hidden costs (data migration / system switchover / learning curve)

### 4.3 API & Extensibility (Weight 15%)

| Score | Criteria |
|:---:|------|
| 1 | Virtually no API or extremely incomplete API |
| 2 | Basic API exists but incomplete; poor documentation quality |
| 3 | API covers major functions; basic documentation available |
| 4 | Comprehensive RESTful API + Webhooks + developer docs + SDK |
| 5 | API-first architecture + open platform + ISV ecosystem + Marketplace |

### 4.4 Omnichannel Capability (Weight 12%)

| Score | Criteria |
|:---:|------|
| 1 | Offline and online completely separate |
| 2 | Deployed but channels remain siloed |
| 3 | Basic online-offline connection (products/orders) |
| 4 | Unified online-offline inventory / orders / members |
| 5 | Unified Commerce Platform + AI-powered smart omnichannel |

### 4.5 Implementation & Training (Weight 10%)

| Score | Criteria |
|:---:|------|
| 1 | No implementation methodology; left to self-manage |
| 2 | Basic implementation plan but minimal training |
| 3 | Standard implementation process + training materials |
| 4 | Mature implementation methodology + systematic training + go-live support |
| 5 | Industry-best implementation + systematic training + change management + continuous enablement |

### 4.6 Stability & Support (Weight 10%)

| Score | Criteria |
|:---:|------|
| 1 | Frequent failures; support unreachable |
| 2 | Occasional failures; slow response (>24 hours) |
| 3 | Generally stable; business-hours response (<8 hours) |
| 4 | High-availability SLA (99.9%+) + 24/7 support + fast response (<2 hours) |
| 5 | 99.99%+ SLA + disaster recovery + proactive monitoring + dedicated service manager |

### 4.7 Data Sovereignty & Compliance (Weight 8%)

| Score | Criteria |
|:---:|------|
| 1 | Data cannot be exported / migrated |
| 2 | Only basic data export (CSV) |
| 3 | Batch export via API; basic compliance |
| 4 | Full data portability + privacy compliance + security certifications (ISO 27001 / SOC 2) |
| 5 | Full data control + on-premises deployment option + audit logs + highest security standards |

## 9. Contract Negotiation - Key Clauses

| Clause | Recommended Bottom Line | Negotiation Strategy |
|------|------|------|
| Price | — | 3-year contract, pay for 2; or request first-year discount |
| SLA | 99.5%+ | Include in contract with penalty clauses |
| Exit Clause | Complete data export | Specify export format + timeline + cost (should be $0) |
| Implementation Timeline | Written into contract | Delay penalties (e.g., 0.1% daily penalty) |
| Data Ownership | 100% client ownership | Explicitly stated + regular backups |
| Renewal Price Increase | Cap on increase | Contract annual increase not to exceed X% |
| PoC | Complete before contract | Do not sign if core scenarios fail PoC |
