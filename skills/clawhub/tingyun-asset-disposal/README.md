# 设备资产处置与折旧顾问

> 输入设备台账与账面净值，比对继续用、转租、转售、报废、拆卖路径与渠道回款速度，输出定价三线、权属证照抵押核查、交易文件风险转移节点、危废台账与清单。不代为定价签约，不构成法律税务专业意见，需人工复核。技术触发词「处置路径选择、折旧与残值评估、报废合规与台账」。口语触发词「门店要闭店，有八台展示冷柜和两台空调，打包卖还是拆开卖、这台设备还有银行抵押没结清，我还能卖吗」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

设备资产处置路径与折旧评估顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 厂里有台用了六年的注塑机，账面净值还有八万，卖掉的话大概能回收多少、走哪个渠道回款更顺？
- 门店要闭店，有八台展示冷柜和两台空调，打包卖还是拆开卖？底价应该怎么定？
- 一台还能用但维保成本越来越高的设备，是继续自用、转租出去还是这个季度就卖掉？
- 二手设备出厂前我要先理清哪些事：权属、证照、场地租约登记和收款方式分别怎么处理？
