# 报废环保合规与交易文件要点

> 本页用于处置前的权属/证照/抵押/租约核查、固废与危废台账步骤、交易文件条款清单与风险转移节点写法，以及税务与发票的待确认问题。
> 涉及法律与税务的部分只提供框架与核查动作，不构成法律税务专业意见，需人工复核。

---

## 一、处置前核查：四类事项

处置前核查没做完就签约，是这类事情里常见的返工来源。四类事项按下面顺序查，前一项没过就先别谈价。

### 1.1 权属核查

| 核查项 | 怎么查 | 过不了怎么办 |
|---|---|---|
| 购置凭证 | 原始发票、购置合同、付款凭证是否齐全 | 凭证缺失会影响权属证明与买方接受度，先补齐或说明来源 |
| 资产卡片 | 是否已登记入账、账实是否一致 | 账实不符先做账务处理再处置 |
| 是否为租赁物 | 融资租赁、售后回租、分期付款未付清的设备，所有权常在出租方 | 不得自行处置；需与出租方协商回购或由其处置 |
| 股东投入或代管 | 是否有代管协议、权属约定 | 按协议约定处理，明确处置收益归属 |
| 是否已抵质押 | 动产抵押登记、应收账款质押、融资担保 | 未涤除的抵押需取得抵押权人同意或先行涤除 |

**抵押查询的可行途径**：全国企业破产重整案件信息网与动产融资统一登记公示系统可查询部分动产担保登记情况；企业自身的征信报告与财务台账也常能反映担保情况。查到有登记而没有解除凭证时，不要仅凭抵押权人口头同意就推进，先取得书面文件。

### 1.2 证照核查

| 设备类别 | 需要处理的事项 |
|---|---|
| 特种设备（压力容器、压力管道、起重机械、场内机动车辆、电梯等） | 办理使用登记注销或变更；需检验的先做定期检验或停用报备 |
| 车辆（货车、叉车属于场内机动车辆的部分） | 车辆过户、证照注销 |
| 涉及排放的设备 | 确认是否有排污许可、排放口登记、在线监测设备，处置前先办理变更或注销 |
| 需前置审批或资质配套的设备 | 确认该设备是否属于许可或资质要件，处置是否影响资质延续 |

**证照注销与设备移交的顺序**：先办注销或变更，再交设备。反过来做（先拉走设备，证照还挂着）容易出现无法到场核验、登记机关要求设备在场才能注销的情形。

### 1.3 抵押与在押核查

- 查是否存在动产抵押、是否登记、抵押权人是谁、担保范围是否覆盖这台设备
- 是否存在司法查封、扣押（可通过对企业登记与司法公开信息的查询线索核实）
- 抵押权人同意处置的形式要求：书面同意函、还款并取得解除证明、或由抵押权人主导的处置安排
- **隐瞒已抵押设备转让的后果**：合同可能被解除、需承担违约责任，严重的还涉及债权人撤销权问题。这属于必须如实披露的事项，不能用"我也不知道"作为抗辩

### 1.4 租约与场地核查

| 核查项 | 说明 |
|---|---|
| 设备是否属于租赁物 | 常见于租赁场地内的定制设备、附属于租赁物的机器 |
| 租赁合同是否限制转让 | 有的合同要求承租方书面同意才能转让设备 |
| 闭店/退租时的设备归属约定 | 租赁合同可能约定"租赁物在租期结束时归出租方所有"，或约定残值归属 |
| 设备是否已计入装修与固定投入 | 若已计入装修摊销，需与房东或租方明确处置归属与补偿方式 |
| 场地腾退时间表 | 决定处置的时间窗口，与定价时间折价配合使用 |

**时间窗口倒排表（建议做法）**：以场地腾退日为终点倒排——设备拆除与吊装安排、报价与谈判截止日、合同签署日、付款与交割日、证照注销日、危废清运与台账归档日。每一步留出缓冲，避免"设备已经拉走但证照销不掉、款项还没到账"的悬空状态。

## 二、固废与危废合规

### 2.1 处置过程中常见的废弃物

| 废弃物 | 属性 | 处理方向 |
|---|---|---|
| 废矿物油、废油桶、含油抹布、油污手套 | 危险废物 | 分类收集、标识、按规定台账、通过电子联单转移、委托有资质单位处置 |
| 废电池、含汞/镉部件、含重金属的部件 | 危险废物或需专门关注 | 同上，拆解时不得随意丢弃或按废品出售 |
| 废制冷剂、含制冷剂的部件 | 需专门回收处理 | 交由具备资质单位回收，不得随车转运 |
| 废切削液、废涂料、废胶 | 视成分可能属危险废物 | 先判别属性，属性不明时按较严口径处理 |
| 废钢、废有色金属、废塑料 | 一般工业固体废物 | 分类计量、按规定台账与申报，可交有资质回收方 |
| 包装物、吸附材料、抹布（非含油） | 一般工业固废 | 分类收集处置 |

### 2.2 台账与步骤（一般固废与危废共通）

```
第 1 步：属性判别（是否落入危险废物名录，是否豁免管理）
第 2 步：分类收集与标识（不同类别分开，不混装）
第 3 步：贮存管理（固定场所、标识牌、防渗防漏、防流失）
第 4 步：台账记录（产生量、贮存量、转移量、去向）
第 5 步：转移手续（电子联单或当地要求的转移联单）
第 6 步：委托有资质单位处置并索取资质文件与处置凭证
第 7 步：年度申报与台账归档
```

**两条硬约束**：
1. **危险废物不得以"当废品处理"的方式交由无资质主体清运。** 这不是选择题，是行政与刑事责任的常见入口。
2. **台账是事后能证明自己合规的关键凭据。** 处置早就结束了，账补不回来。

### 2.3 委托处置前的资质核查

| 核查项 | 怎么查 |
|---|---|
| 危险废物经营单位资质 | 查当地生态环境部门公开的持证单位名录，确认其许可范围覆盖所委托的废物类别 |
| 转移联单要求 | 确认当地是电子联单还是纸质联单，以及提交时限 |
| 处置单位的接收范围 | 有些单位只收特定类别，超出范围会退回 |
| 结算与凭证 | 要求提供处置量确认单与合规凭证，作为台账附件 |

## 三、交易文件条款清单与风险转移节点

### 3.1 必备条款清单

| 条款 | 要写清什么 | 常见漏项 |
|---|---|---|
| 标的清单（作为附件） | 名称、型号规格、序列号/机号、数量、成色、所在地点 | 只写"及配套设备"，后续争议极大 |
| 成交价与支付方式 | 金额、是否含税、付款节点与比例、付款账户 | 未写是否含运、含拆装 |
| 交付方式与地点 | 交付时点、交付地点、装卸与吊装责任、谁承担运输 | 责任空白导致装卸途中损坏无人认 |
| **所有权与风险转移节点** | 具体时点，如"交付并验收合格时转移" | 只写"交付后"，验收环节责任不清 |
| 验收程序与标准 | 验收期限、验收方式（现场/试机）、不合格的处理方式 | 无验收标准，买方验机后主张不符 |
| 随机配件与随附资料 | 专用工具、备件、合格证、说明书、图纸、维修记录 | 配件事后被剔、资料缺失导致买方无法使用 |
| 权利瑕疵担保与声明 | 是否存在抵押、查封、权利限制的声明与担保 | 未披露已抵押 |
| 环保与安全责任划分 | 拆解作业责任、危废清运责任、作业期间的安全责任 | 危废处理责任未分配 |
| 违约责任 | 逾期付款、逾期交付、资料未齐、披露不实的处理方式 | 只有"协商解决" |
| 争议解决方式 | 管辖法院或仲裁机构 | 空白 |
| 合同生效与份数 | 生效条件、份数、附件效力 | 附件未写明与正文具有同等效力 |

### 3.2 风险转移节点的三种写法与后果

| 写法 | 含义 | 适用 |
|---|---|---|
| "所有权与毁损灭失风险自交付时转移" | 交出去那一刻风险走 | 卖方想尽快脱手、买方具备接货与运输能力 |
| "自交付并验收合格时转移" | 验收通过才走 | 买方需要时间检验、卖方希望把验收期风险留给自己 |
| "自价款付清时转移" | 钱到账才走 | 卖方资金压力大、需要控制先交付后付款的风险 |

**选哪一条看三件事**：谁承担运输、谁承担验收期损耗、谁承担付款违约风险。三者与风险节点要对齐，否则会出现"钱没到货先走了，货验收没过钱又回不来"。

### 3.3 三条容易被忽略的条款

1. **附件与正文具有同等效力的表述**。附件清单（逐台逐序列号）是防漏项的关键，缺了这句，附件可能不被认定为合同组成部分。
2. **披露事项清单**。把已知瑕疵（故障项、待修项、无原厂备件、无随机资料、证照已注销）逐条列明并写明买方已知悉。**如实披露是把交易做成、把合同站住的前提**，不是自曝短板。
3. **环保与作业责任归属**。尤其是拆解类交易，约定谁负责拆解、谁负责危废分类与转运、作业期间的人身与财产事故由谁承担。

## 四、税务与发票：待确认问题清单

**以下是框架，不是结论。** 设备处置涉及的增值税与企业所得税处理，依赖企业纳税人身份、资产取得方式、购入时间、开票与抵扣情况、当地执行口径，**必须由税务专业机构确认**。本节只给"该去问什么"。

### 4.1 需要确认的问题

| 序号 | 待确认问题 | 为什么要问 |
|---|---|---|
| 1 | 处置已抵扣过进项税的动产，应适用哪种计税方式与征收率 | 直接决定开票税率与税负 |
| 2 | 已抵扣进项税的部分在处置时如何处理 | 涉及进项转出问题 |
| 3 | 处置收入与账面净值差额在企业所得税上如何体现 | 涉及资产损失的处理方式 |
| 4 | 资产损失税前扣除需要哪些留存备查资料 | 资料不齐会影响税前扣除 |
| 5 | 是否需向买方开具发票、发票品名如何表述 | 影响买方能否抵扣，也影响本方合规 |
| 6 | 若设备已办理过"加速折旧"或税前扣除，处置时如何衔接 | 存在重复扣除风险 |
| 7 | 转让与出租在税务处理上的差别 | 若考虑转租路径，需先分清口径 |
| 8 | 报废处置取得的残值收入如何处理 | 报废路径下仍有残值收入 |
| 9 | 涉及的印花税等附加税费的承担方 | 金额不大但常被漏 |

### 4.2 给税务专业机构的资料包

把下面这套资料一次性备齐，能显著缩短确认周期：

1. 资产购置合同与发票（证明取得时间与原始金额）
2. 固定资产卡片（折旧方法、已提折旧、减值准备）
3. 处置方案说明（处置路径、渠道、成交价、是否含运）
4. 交易合同与附件清单（风险转移节点、交付方式）
5. 残值收入或处置损益计算表
6. 若涉及危废，提供危废处理的相关凭证与联单编号

### 4.3 口头提醒的三条

1. **处置前不要先开票后交易**，也不要用"先收款后补票"倒着来。开票与合同、交付、款项的顺序保持一致。
2. **发票品名要能被买方接受**，也要与资产台账对得上。品名写得太笼统，后续抵扣和核销都会有麻烦。
3. **账面处置损益不是税务结果**。会计上的处置损益口径与税法上的所得确认口径不完全一致，两边分开算。
