# 折旧残值评估与处置清单模板

> 本页用于核对账面净值、测算可回收价值区间，并提供可直接套用的设备处置清单模板。
> 估值测算属规划性推演，不构成评估结论，不构成法律税务专业意见，需人工复核。

---

## 一、折旧方法差异与账面净值核对

### 1.1 常用折旧方法对比

同一台设备，折旧方法不同，账面净值可能差出一大截。拿到净值先确认方法，再谈折损。

| 方法 | 计算方式 | 前期 vs 后期净值 | 适用特征 | 对处置判断的影响 |
|---|---|---|---|---|
| 年限平均法 | 年折旧额 =（原值 - 预计净残值）÷ 预计使用年限 | 均匀 | 各项差异小、损耗均匀 | 净值随年份线性下降，残值直观 |
| 工作量法 | 单位工作量折旧额 =（原值 - 预计净残值）÷ 预计总工作量 | 按使用强度 | 使用强度差异大（运输设备、加工设备） | 忙时折旧快，闲置设备账面净值虚高 |
| 双倍余额递减法 | 前期按账面净值双倍计提，后几年改直线法 | 前期高后期低 | 技术更新快、需加速折旧 | 账面净值下降快，处置时账面损失显得大 |
| 年数总和法 | 折旧率按年序递减 | 前期高后期低 | 前期效率高、后期效益低 | 与双倍余额递减接近 |

### 1.2 账面净值核对清单

处置测算前逐项核对：

| 核对项 | 怎么核对 | 不一致时怎么办 |
|---|---|---|
| 折旧方法 | 问财务确认用的是哪一种、是否变更过 | 让财务出具台账口径说明 |
| 原值口径 | 是否含运费、安装费、调试费、备件 | 口径不同，可回收价值折算基数也不同 |
| 预计净残值率 | 合同或制度定的比例是多少 | 残值率定高了，账面净值会被压低 |
| 累计折旧 | 提足折旧后是否仍在计提 | 提足后账面净值为零，不代表设备无价值 |
| 减值准备 | 是否已计提资产减值 | 已计提减值时，处置损益的基数是减值后的净值 |
| 在建/待验收 | 是否有已付未转固的设备 | 未转固部分权属与发票处理不同，需单独确认 |
| 已提折旧年限 | 实际使用年限与折旧年限是否一致 | 长期超期使用的设备，净值低不代表成色好 |

**核对顺序建议**：先拿固定资产台账的原值与累计折旧，再拿一张购置发票或合同做交叉验证，末尾再用净值。

### 1.3 一个必须纠正的常见误判

> "这台设备账面还有三十万，卖掉太亏，继续放着。"

折旧已经把成本摊销掉了，账面净值高只说明这台机器**新**，不说明它**有用**。判断该不该卖，要比的是：

```
继续持有一年总成本 = 维保 + 能耗 + 场地占用 + 资金占用成本 + 故障停机损失 + 环保合规成本
继续持有一年总产出 = 该设备带来的产出增量（或替代它所需的采购与培训成本）

处置净得 = 成交价 - 全部处置成本 - 税费
```

**账面处置损失是折旧的结果，不是决策错误。** 拖着一台吃场地、吃能耗、随时报修的机器，才是持续亏损。

## 二、账面净值到可回收价值：四道折损

### 2.1 测算结构

```
账面净值（原值 - 累计折旧 - 已提减值）
  − 技术性贬值
  − 经济性贬值
  − 功能性折损
  + / − 处置环节费用
  = 可回收价值区间
```

### 2.2 四道折损逐项判断

**① 技术性贬值（工艺与配件）**
- 同型号是否已停产？停产年限？
- 是否有新一代机型替代？能耗、精度、自动化水平差距多大？
- 关键备件是否仍可采购？原厂是否已退出该机型服务？
- 耗材是否专供？耗材断供等于整机失去使用价值
- 剩余经济寿命：按现折旧政策还能用几年

**② 经济性贬值（供需与用途）**
- 该品类在本地是否供过于求？同款挂牌量是否明显增加？
- 二手需求是否集中在少数热门机型？
- 该设备对买方是刚需还是可选？买方是自用还是转手？
- 是否有更低价的新机替代（低端化贬值）

**③ 功能性折损（成色与状态）**
- 已使用年限与累计工时/开机小时
- 是否已发生大修、重大故障、是否经过技改
- 待修项清单与预估费用：主轴、液压、电气、电池
- 外观与锈蚀、密封件老化
- 随机资料与专用工具是否齐全（齐全度直接影响成交价）

**④ 处置环节费用（加减项）**
- 拆除、吊装、搬运、运输与保险
- 仓储（超过免费存放期的部分）
- 平台佣金、中介服务费
- 评估、检测、拆卸人工
- 危废与固废处理费（报废路径下必须计入）
- 税费（具体处理需税务专业机构确认）

### 2.3 估值口径对比

| 口径 | 怎么算 | 用途 | 局限 |
|---|---|---|---|
| 账面净值法 | 会计折旧结果 | 内部口径、与财务对账 | 与市场价无必然关系 |
| 市场比价法 | 参考同款近期成交与挂牌价，取可比区间 | 定价主线 | 依赖成交样本是否真实充分 |
| 收益现值法 | 剩余使用期内净现金流折现 | 判断继续用还是卖 | 对剩余寿命与产出预测敏感 |
| 成本重置法 | 重置成本 − 实体贬值 − 功能贬值 − 经济贬值 | 缺市场样本时参考 | 依赖重置成本与贬值率判断 |
| 重量计价法 | 按过磅重量 × 废料单价 | 拆解路径 | 只适用于按重量结算的渠道 |

**实用做法**：以市场比价法定市场线，用成本重置法与收益现值法校验下限，用重量计价法定报废路径的兜底值。三条结果出现明显背离时，多半是某一项假设有问题，回查而不是取平均。

## 三、设备处置清单模板（可直接套用）

### 3.1 台账与权属信息

| 字段 | 填写说明 |
|---|---|
| 资产编号 | 固定资产卡片编号 |
| 设备名称 | 标准名称 |
| 型号规格 | 铭牌上的完整型号 |
| 序列号/机号 | 出厂序列编码，附件清单必填 |
| 数量与单位 | 台/套/批 |
| 存放地点 | 具体到车间/楼层/铺位 |
| 购置日期 | 合同或发票日期 |
| 原值（元） | 财务台账口径 |
| 累计折旧（元） | 财务台账口径 |
| 减值准备（元） | 已计提金额 |
| 账面净值（元） | 原值 - 累计折旧 - 减值 |
| 折旧方法 | 年限平均/工作量/双倍余额递减/年数总和 |
| 已使用年限 | 实际使用年限，与折旧年限不一致时注明 |
| 状态 | 在用 / 闲置 / 故障 / 待修 / 封存 |
| 权属类型 | 自有 / 融资租赁 / 售后回租 / 股东投入 / 代管 |
| 抵押状态 | 无 / 已登记未涤除 / 已涤除（注明查询日期） |
| 是否特种设备 | 是（填类别）/ 否 |
| 使用登记证号 | 特种设备填编号与登记机关 |
| 是否涉及环保/危废 | 是（填类别）/ 否 |
| 随机资料清单 | 合格证、说明书、图纸、维修记录、原始发票复印件 |

### 3.2 处置方案信息

| 字段 | 填写说明 |
|---|---|
| 拟处置路径 | 继续用 / 转租 / 转售 / 拆卖 / 报废 |
| 选择理由 | 产能、能耗、工艺、替代方案 |
| 拟处置渠道 | 二手市场 / 品牌回购 / 拍卖 / 平台撮合 / 拆解 |
| 保留线（底价，元） | 可回收价值下限 + 合规成本 |
| 市场线（元） | 同款近期成交参考价 |
| 快速回款线（元） | 市场线下调 10%-20% |
| 谈判时间折价上限 | 每 30 天 3%-8% |
| 询价记录 | 见 2.4 表 |
| 交易文件名称 | 转让协议 / 买卖合同 / 承揽合同等 |
| 所有权与风险转移节点 | 写明具体时点，如"交付并验收合格时" |
| 付款节奏 | 定金 / 到货款 / 尾款比例与节点 |
| 随附资料交付清单 | 附件中逐项列出 |
| 环保责任划分 | 危废清运、拆解作业由谁负责 |
| 税费处理待确认事项 | 交由税务专业机构确认的问题 |

### 3.3 执行与回填

| 字段 | 填写说明 |
|---|---|
| 责任人 | 每一项动作的具体负责人 |
| 计划完成日 | 每个节点的时间点 |
| 证照注销/变更完成日 | 特种设备填 |
| 抵押解除证明 | 涤除后归档 |
| 危废转移联单编号 | 如涉及 |
| 台账登记完成日 | 资产卡片注销日 |
| 实际成交价（元） |  |
| 实际处置成本（元） | 拆装运输佣金税费合计 |
| 处置损益（元） | 成交价 - 账面净值 - 处置成本 |
| 处置结果说明 | 成交情况、未成交原因、后续安排 |

### 3.4 使用建议

1. **一台一表，不要一张表管所有设备**。批量处置时，型号、成色、权属状态差异很大，混在一张表里看不出差异。
2. **附件清单单独做**。序列号、随机配件、资料逐项列出，与主表分离，避免签字时漏项。
3. **填表顺序**：先填权属与限制栏，再填处置方案，末尾回填执行栏。权属栏填不出来，后面全部作废。
4. **处置完成后归档三样**：签署的合同与附件清单、结算与付款凭证、证照注销与台账登记记录。
