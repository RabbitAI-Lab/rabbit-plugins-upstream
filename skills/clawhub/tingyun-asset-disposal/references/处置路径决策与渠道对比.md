# 处置路径决策与渠道对比

> 本页用于判断一台（批）设备该继续用、转租、转售、拆卖还是报废，并比较五类处置渠道的回款速度与净得收益。
> 涉及法律与税务的部分只提供判断框架与待确认问题，不构成法律税务专业意见，需人工复核。

---

## 一、五条处置路径的判断表

### 1.1 判断顺序（按顺序问，不要跳步）

处置路径不是并列选项，是一条**降级序列**：先问还有没有生产价值，再问有没有二手市场，再问部件值不值拆，剩下才是报废。跳步的代价是把还有残值的资产当成零处理，同时把该付的环保成本省错了地方。

```
第 1 层：还创造价值吗？
├─ 是 ── 本企业用得上吗？
│        ├─ 用得上 ──→ 继续用（先算持有成本是否已超过价值）
│        └─ 用不上、别人用得上 ──→ 转租
└─ 否（工艺淘汰 / 能耗不达标 / 零件断供 / 故障成本过高）
         ├─ 整机仍有人要 ──→ 转售
         ├─ 整机需求弱、部件有市场 ──→ 拆卖
         └─ 部件也无价值 ──→ 报废（仍须履行固废/危废义务）
```

### 1.2 五条路径对照表

| 路径 | 价值回收形式 | 适合的设备特征 | 主要代价 | 不可逆点 | 常见误判 |
|---|---|---|---|---|---|
| 继续用 | 未来产出 | 仍在产线承担功能、替换成本高、涉及资质要求 | 持有成本：维保、能耗、占地、占用资金、故障停机 | 沉没持有成本逐日累积 | 以为账面净值高就该卖 |
| 转租 | 租金流 | 成色好、通用性强、本企业用不上、市场上有人缺设备 | 租金与管理成本、租约期内难再处置、设备仍在表内 | 租约期内再处置受限 | 以为转租等于变现，其实钱是分期进来 |
| 转售 | 一次性现金 | 通用机型、成色好、二手需求活跃 | 折价、处置成本、税费 | 过户后设备不再属于本企业 | 以为挂出去就等于卖掉 |
| 拆卖 | 部件现金 | 整机需求弱但部件有市场、机型有多个可独立流通的模块 | 拆解人工、部件价值不确定、危废处理、拆坏即归零 | 拆开不可复原 | 以为拆了能多卖，实际上多数整机拆卖折损更大 |
| 报废 | 无回收 | 无价值、工艺淘汰、处置成本高于残值 | 环保与台账义务、无现金回收 | 注销后不能再用 | 以为报废就是把车拉走，忽略危废与台账 |

### 1.3 继续用 vs 转租的判断

| 判断项 | 继续用 | 转租 |
|---|---|---|
| 产能紧张程度 | 满产或接近满产，停机会损失产出 | 有富余产能或设备不在关键路径上 |
| 设备专用性 | 高度专用，外部用不了 | 通用，外部愿意接 |
| 维护能力 | 本企业有熟练维修与备件 | 本企业维护成本高，租户自担 |
| 合规资质 | 设备本身是资质要件之一 | 转租不改变资质持有要求，需先确认 |
| 租约与合同 | 贷款合同可能限制转让 | 需先核对租赁合同是否允许转租 |

### 1.4 转售 vs 拆卖 的判断

拆卖常见的适用条件（需同时满足）：

1. 整机在本地市场几乎没有需求（专用型号、已停产、非标设备）；
2. 存在 3 个以上可独立流通的高价值模块（主板、动力单元、模组、电机、电池包等）；
3. 拆解本身不产生需要额外处置的危险废物，或危废处理成本已计入；
4. 有承接方愿意按件收货，或有可对接的零件回收渠道。

**不满足第 2 条就不要拆。** 多数通用设备的整机报价高于部件合计，拆开卖是把一个能一次成交的单子变成几十个零散交易，工时与纠纷成本吃掉了差价。

## 二、五类处置渠道对比

### 2.1 渠道对比表

| 渠道 | 回款速度 | 价格水平（相对账面净值） | 适合设备 | 主要风险 | 议价空间 |
|---|---|---|---|---|---|
| 二手市场上门收购 | 快，3-15 天 | 偏低，约 20%-40% | 通用设备、量大件少 | 现场验货压价、条款粗、配件被剔 | 大 |
| 品牌原厂或授权商回购 | 较慢，15-45 天 | 偏高，约 50%-70% | 在回购名录内的机型、成色好 | 机型范围有限、审批与物流占时间 | 中 |
| 公开拍卖 | 慢，30-90 天 | 波动大，可能高于快速出售也可能流拍 | 批量同型号、需要公允定价 | 需现场验机、周期长、流拍风险 | 大 |
| 线上资产处置平台撮合 | 中，15-30 天 | 中上，约 30%-50% | 零散设备、需要留痕、多方竞价 | 竞价门槛与履约担保、竞价后反悔风险 | 中 |
| 拆解回收按重量计价 | 快，当场到数日 | 低，随大宗商品价格波动 | 无回收价值、有重量 | 环保处理成本高、需配合分类 | 小 |

> 价格为经验区间，用于判断量级与相对关系，不构成估价结论。实际成交价取决于型号、成色、市场供需与付款条件，须以实际询价与合同为准。

### 2.2 渠道选择决策树

```
第 1 步：设备在回购名录内吗？
├─ 是 ──→ 品牌回购（净得高），同时并行询价快速收购作底价参照
└─ 否
第 2 步：设备通用、当地有活跃二手需求吗？
├─ 是 ──→ 先走线上撮合与二手市场两条线，竞价定市场线
│        └─ 两条线报价都低于保留线 → 转拆卖评估
└─ 否
第 3 步：批量数量 ≥ 3 台同型号？
├─ 是 ──→ 公开拍卖（用公允定价抬价），同时准备流拍后的打包转售方案
└─ 否 ──→ 二手市场上门收购（快）或拆解按重量计价
第 4 步：所有渠道报价都低于可回收价值 + 合规成本？
└─ 是 ──→ 转报废流程（仍需履行固废/危废义务与台账）
```

### 2.3 渠道使用要点

**二手市场上门收购**
- 上门验机是压价的主要节点，尽量把设备状态整理到位再约（清理、拍照、备齐资料、随机工具归箱）
- 谈价按"设备+随机配件+资料"作为一个包谈，别让配件被单独剔掉
- 现金当场结清是这一渠道的主要价值；要求当场结清写进单据

**品牌原厂或授权商回购**
- 先确认机型是否在当期回购名录内、是否设批量门槛
- 时间和物流是主要成本，报价时把拆装、运输、保险计入再比
- 回购条款常含"复检后调整价格"的表述，谈判时把复检口径与容差写清

**公开拍卖**
- 起拍价设置按"快速出售价 + 一定溢价"倒推，不是按期望值设定
- 提前准备资产说明与图片资料，资料质量直接影响竞买意愿
- **必须预先设定流拍预案**：流拍后转打包转售或拆卖，不要让资产长期悬置

**线上资产处置平台撮合**
- 竞价规则、竞拍担保比例、履约担保方式要先看清再报名
- 报名前把设备成色与瑕疵在平台披露清楚，避免后续争议

**拆解回收**
- 计量方式（过磅、计台、计重）、单价是否随大宗商品波动，要写明结算口径
- 危废必须由有资质单位单独处置，不得与普通废品混同结算

## 三、定价策略：三条线与时间折价

### 3.1 三条定价线

| | 快速回款线 | 市场线 | 保留线（底价） |
|---|---|---|---|
| 定价依据 | 市场预期价下调 10%-20% | 同款近期成交价 | 可回收价值下限 + 不可省的合规与处置成本 |
| 目标周期 | 7 天内结款 | 15-30 天 | 不设时限 |
| 适用场景 | 现金流紧张、设备继续占地、停产在即 | 常规处置 | 有替代方案、不急、品类惜售 |
| 谈判用法 | 先报这条，争取当场成交 | 报价起点，用空间换时间 | 低于这条不成交，直接换渠道 |

### 3.2 时间折价

- 经验区间：**每延后 30 天，可接受折价 3%-8%**
- 作用是给谈判设上限，防止无限拖；不是无底线降价的授权
- 计算逻辑：延后期间继续承担占地、资金占用、保管与维保成本，同时承担行情下行与技术贬值
- 若 30 天内无人接盘，说明价格或渠道有问题，此时应换渠道而不是继续降价

### 3.3 净得收益的完整口径

谈判前必须把到手金额算清楚，不能只比报价：

```
净得收益 = 成交价
         - 拆除与吊装费
         - 运输费与保险
         - 仓储费（超过免费期的部分）
         - 平台佣金或中介服务费
         - 税费（具体处理需税务专业机构确认）
         - 危废与固废处理费
         - 评估、检测、拆卸人工等杂费
         + 渠道返利或以旧换新抵扣
```

**比较渠道时要比净得，不是比报价。** 报价高 15% 但要拆装、运输、拖两个月的渠道，净得可能低于上门收购。

### 3.4 谈判节奏建议

1. 多渠道并行询价至少 2 条，形成可比区间
2. 用"市场线"开价，"快速回款线"做成交底
3. 把付款节奏写进报价（当场结清 > 到货结 > 分期），付款条件换价格通常比硬砍价有效
4. 留出保留线作为内部决策线，不对外报
5. 记录每次报价与报价方，便于后续核对真实市场区间
