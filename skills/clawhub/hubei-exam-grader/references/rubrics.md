# 判分规则细则与错因标签

## 答案归一化

### 单项选择题

- 取学生答案的首个字母，转大写后与标准答案比对。
- `B 、b、(B)、B.` 都视为 `B`。
- 传回 `AB` 或 `A、B` 之类多选时，若标准答案是单选则直接判错（多选了）。

### 判断题

| 学生写法 | 归一化 |
|---|---|
| 对、正确、√、T、t、True、Y、Yes | 对 |
| 错、错误、×、X、F、False、N、No | 错 |
| 其他任何写法 | 原样保留，判错 |

## 操作题评分锚点

操作题答案必须落在**可执行的软件操作**上，各模块的给分锚点：

### 模块 2 操作系统（Windows 10）
给分点 = 是否写清入口（设置/控制面板/右键菜单）+ 关键选项名 + 确认动作。例：隐藏文件扩展名要写到「查看 → 显示 → 文件扩展名」开关，只写「把扩展名关了」算 0.5。

### 模块 3 计算机网络
给分点 = 配置界面/命令（`ipconfig`、`ncpa.cpl` 等）+ 参数值正确。IP 地址、子网掩码、网关任一数值错误即 0.5 以下。

### 模块 4 文字处理（WPS）
给分点 = 菜单路径完整 + 对象选择正确。邮件合并必须提到数据源与插入合并域两个环节，缺一 0.5。

### 模块 5 电子表格（WPS）
给分点 = 函数名与参数顺序正确 + 引用方式（相对/绝对）正确。函数思路对但漏了嵌套函数或绝对引用符号 → 0.5。例：`=ROUND(AVERAGE(A1:A10),2)` 漏 ROUND 只写 AVERAGE 是 0.5。

### 模块 6 演示文稿（WPS）
给分点 = 视图/母版入口 + 效果设置目标对象。只说「加个动画」不给分，要写对象与效果类型。

### 模块 7 程序设计（C99）
给分点 = 程序逻辑正确 + 输入输出格式符合题意。语法小错（漏分号）但逻辑完整 → 0.5；逻辑错误 → 0。

### 模块 8 数据库（MySQL）
给分点 = SQL 语句可执行且语义正确。关键词大小写不扣分；列名、表名、条件逻辑错误按影响范围给 0 或 0.5。例：忘记 WHERE 导致全表更新 → 0。

### 模块 9 图像处理（Photoshop CS6）
给分点 = 工具名 + 图层操作 + 参数。混合模式/羽化值等参数错 → 0.5；选错工具 → 0。

## 八类错因标签

| 标签 | 判定 | 典型例子 |
|---|---|---|
| 概念混淆 | 用了相近但错误的概念 | 1KB=1000B（十进制）；存储过程与触发器张冠李戴 |
| 审题不清 | 概念会，但答非所问 | 问「正确的」选了「错误的」；要求升序写成交互 |
| 计算失误 | 思路对，算错数 | 进制转换中途算错；循环边界差 1 |
| 记忆不牢 | 纯记忆点答错 | 快捷键、默认端口、函数名拼写 |
| 步骤遗漏 | 方法对，漏关键步骤 | 合并邮件没插数据源；导出没选格式 |
| 参数错误 | 步骤对，参数值错 | 羽化 10px 写成 20px；ROUND 第二参数漏写 |
| 操作顺序错误 | 步骤都对但顺序颠倒 | 先新建图层再选工具（应先选区）；先排序后筛选 |
| 不会做 | 完全空白或胡乱作答 | 空答；与题目无关的答案 |

选择原则：一道错题只标一个主因。先判断「会不会」（不会做），再判断「对不对」（概念混淆），再看「细不细」（遗漏/参数/顺序），最后才考虑审题、计算、记忆。拿不准时优先「概念混淆」，因为它对应的知识点复习价值最高。

## 复习建议

`review` 字段引用知识点编号（对照出题方提供的考纲目录），格式如「复习知识点 5.4 常用函数」。不知道该题知识点时写「建议讲解本题对应考点」。
