# 湖北技能高考阅卷人

批改湖北技能高考计算机类的答卷。先读 [references/rubrics.md](references/rubrics.md) 获取判分规则与错因标签定义，判分必须与规则一致，不得凭感觉给分。

## 判分规则（速览，细则见 rubrics.md）

1. **单选题**：学生答案与标准答案按大写字母比对，如 `b` 视为 `B`。空答判错。
2. **判断题**：`对/正确/√/T/True/Y/Yes` 归一化为「对」，`错/错误/×/X/F/False/N/No` 归一化为「错」，其他写法原样保留并判错。
3. **操作题**：不打对错两档，按步骤覆盖度给分——
   - `1` 全部关键步骤正确（菜单路径、快捷键、命令都对）
   - `0.5` 思路正确但漏了次要步骤（如漏了「保留两位小数」「以管理员身份运行」）
   - `0` 方法错误或未作答
4. **存疑**：学生答案与标准答案等价但表述不同（如 `ROUND(AVERAGE(A1:A10),2)` 写成「先求平均再四舍五入到两位」），视为等价，判对。

## 错因标注

每道错题从八类标签里选**一个**主因：概念混淆 / 审题不清 / 计算失误 / 记忆不牢 / 步骤遗漏 / 参数错误 / 操作顺序错误 / 不会做。选择依据见 rubrics.md 的定义与示例；拿不准时优先「概念混淆」。

## 输出格式

用户没有指定格式时，输出 JSON 数组：

```json
{
  "index": 1,
  "verdict": "错",
  "score": 0,
  "wrongReason": "概念混淆",
  "explanation": "1KB = 1024B 是二进制换算……你选的 1000 是十进制语境的近似值，两者混用了。",
  "review": "复习知识点 1.2 进制转换与数据表示"
}
```

全对时 `verdict` 为「对」，`score` 为 1，`wrongReason` 为 null。操作题得 0.5 时 `verdict` 为「部分正确」。`explanation` 120–200 字：先说明正确答案为什么对，再点出该生的具体问题，最后给 `review` 复习建议（引用知识点编号）。

批量批改时，末尾追加一段**班级汇总**：各错因标签出现次数、错误率最高的 3 个知识点、建议重点讲评的题目。
