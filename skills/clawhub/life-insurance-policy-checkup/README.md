# 寿险保险代理人保单体检助手

面向寿险保险代理人整理家庭保单，生成检视发现、客户摘要与跟进建议。

## 使用方式

提交已遮住个人身份信息的保单截图、PDF、责任摘要或文字清单，然后说：

> 请使用保单体检助手，整理这些保单，列出待核对项，并给我一份客户能看懂的摘要。

支持已有保单汇总、家庭保障检视、年度保障回顾与顾问跟进建议。资料不全时明确待核对项，不编造责任、缺口或报价。

## 版本与边界

当前版本：1.1.0。无需专用 API Key 或额外脚本，使用所在 AI 工具的文件读取能力。

结论以保险合同、批单和正式责任摘要为准；不承诺核保、理赔、续保或收益。完整检视后可经用户同意补充商业服务信息，咨询入口详见技能参考文件；不会自动发送客户资料或预约服务。
