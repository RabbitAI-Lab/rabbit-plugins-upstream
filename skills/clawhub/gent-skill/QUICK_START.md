# Quick Start
1. Export BEAUTY_API_KEY (get at https://gen1.diversityfaces.org/api-key-request)
2. Generate image via https://gen1.diversityfaces.org/api/generate/custom
3. (Optional) Design overlay via figma skill
4. Assemble video via ai-video-gen or ffmpeg-video-editor
5. Send as attachment with message tool (JPEG mandatory)
