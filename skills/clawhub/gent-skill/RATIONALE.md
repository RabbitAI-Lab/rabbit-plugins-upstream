# Rationale
Gent Skill is an independent merged skill. It bundles the logic and scripts of ai-video-gen, beauty-generation-api, figma, and ffmpeg-video-editor into a single installable unit.

Default provider: gen1.diversityfaces.org (`https://gen1.diversityfaces.org/api/generate`), not beauty-generation-api as a brand — the endpoints are identical, but the skill is self-contained and can be installed anywhere.

Video engine = ai-video-gen + ffmpeg-video-editor; design track = figma.

Goal: outperform standalone skills on same provider, usable by anyone.
