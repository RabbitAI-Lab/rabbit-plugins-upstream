## Description:

A visual production skill for generating images, creating video, designing overlays, and editing visual media.

This skill is ready for commercial/non-commercial use.

## Publisher:

[hleliofficiel](https://clawhub.ai/user/hleliofficiel)

### License/Terms of Use:

MIT-0

## Use Case:

OpenClaw users and creative practitioners use the skill to turn explicit briefs into generated images, designed overlays, edited videos, and assembled visual deliverables.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Image-generation prompts are sent to gen1.diversityfaces.org and could contain sensitive information.

Mitigation: Use only non-sensitive creative briefs; exclude passwords, tokens, personal information, and confidential data.

**Output Type(s):** [Image files, Video files, Design guidance, Shell commands, Configuration instructions]
