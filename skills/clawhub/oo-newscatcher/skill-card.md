## Description:

NewsCatcher helps agents search articles, retrieve latest headlines, list indexed sources, and check subscription allowance through an OOMOL-connected NewsCatcher account.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to run read-only NewsCatcher searches, headline retrieval, source listing, and subscription checks from an agent through their connected OOMOL account.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: First-time setup may install the oo CLI or create a persistent OOMOL login session.

Mitigation: Review setup steps and trust OOMOL's oo CLI before allowing installation or account connection.
