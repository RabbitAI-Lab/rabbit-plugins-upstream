## Use Case:

Developers and engineers use this skill to design and review REST API contracts, including resource naming, HTTP semantics, pagination, filtering, error responses, versioning, authentication, authorization, and rate limiting.

## Known Risks and Mitigations:

Risk: API design examples could be applied to production routes without project-specific review, especially for destructive operations and authentication patterns.

Mitigation: Review generated API contracts and examples against production security, authorization, and data-handling requirements before implementation.
