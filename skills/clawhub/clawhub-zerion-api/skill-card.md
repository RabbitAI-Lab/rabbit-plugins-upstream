Developers, analysts, and research teams use this skill to query Zerion wallet data for portfolio analysis, transaction review, DeFi position discovery, token and NFT checks, gas price lookup, and cross-chain comparisons. <br>

## Known Risks and Mitigations: <br>
Risk: Wallet addresses and query context may reveal sensitive or customer-linked financial activity. <br>
Mitigation: Query wallet identifiers only with authorization and avoid submitting customer-linked or personally sensitive addresses unless approved. <br>
Risk: A Zerion API key could be exposed through source control, logs, or screenshots. <br>
Mitigation: Use a dedicated Zerion API key, keep it out of source control, logs, and screenshots, and rotate it if exposed. <br>
