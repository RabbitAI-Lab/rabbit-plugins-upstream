## Description: <br>
Ssl Toolkit Free helps personal-site operators configure HTTPS, manage TLS certificates, check certificate status, troubleshoot common SSL errors, and produce basic Nginx or Apache configuration guidance. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External developers, site owners, and operators use this skill for personal blogs, small websites, and local development environments that need HTTPS setup, certificate renewal checks, SSL error diagnosis, and basic web-server configuration. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The activation scope can trigger during unrelated project-management, task-planning, progress-tracking, or team-collaboration work. <br>
Mitigation: Use the skill only for explicit SSL/TLS, HTTPS, certificate, or web-server configuration tasks, and revise the trigger scope before deployment. <br>
Risk: Suggested certbot, acme.sh, Nginx, Apache, and cron commands can change live certificate and web-server state. <br>
Mitigation: Require user confirmation, current backups, dry-run validation where supported, and post-change HTTPS checks before applying commands on production systems. <br>
