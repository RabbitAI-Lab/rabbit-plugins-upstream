## Description:

Add a complete favicon set (favicon.svg with dark mode, favicon.ico, Apple Touch and PWA icons, site.webmanifest and the HTML head tags) to a website, using the free favicongenerator.io MCP server or REST API.

This skill is ready for commercial/non-commercial use.

## Publisher:

[7and1](https://clawhub.ai/user/7and1)

### License/Terms of Use:

MIT-0

## Use Case:

Website developers use this skill to choose a favicon source, generate a site icon set, save the assets and manifest, add the HTML head tags, and check the deployed files.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Brand names or designs sent for generation are disclosed to favicongenerator.io.

Mitigation: Avoid sending confidential branding unless disclosure to the external service is acceptable.

Risk: Generated shell commands and HTML may need adjustment for the site's setup.

Mitigation: Review the returned commands and markup before applying them.
