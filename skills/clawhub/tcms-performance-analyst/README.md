# TCMS Performance Analyst

**Part of the `tcms-*` family** — brand-side content skills for tech-product marketing teams.
*Not for neutral third-party industry research — that is `industry-deep-dive-pipeline`'s job.*

## What it does

Monthly analysis of published output, content-calendar variance, channel performance, product-line coverage, and knowledge-base health, with next-month recommendations.

It never fabricates metrics (marks gaps DATA_MISSING) or auto-modifies the calendar / triggers writing. For single-article pre-publish review use `tcms-compliance-reviewer`.

## Trigger phrases

月度报告, 效果分析, 内容复盘, 月度复盘, 数据复盘, 发文统计, monthly report, content review, performance analysis

## Pipeline position

`tcms-planner` (brief) → `tcms-writer` (draft) → `tcms-compliance-reviewer` (review) → `tcms-adapter` (channels) → **`tcms-performance-analyst`** (monthly report)
