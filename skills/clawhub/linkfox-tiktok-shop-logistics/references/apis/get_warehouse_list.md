# Get Warehouse List

> 官方文档：https://partner.tiktokshop.com/docv2/page/get-warehouse-list-202309

## LinkFox 转发映射（本 skill）

| 项 | 值 |
|----|----|
| 具名 api | `get_warehouse_list` |
| 脚本 | `scripts/get_warehouse_list.py` |
| 网关 | `POST /tiktokShop/developerProxy` |
| appType | **`erp`（固定）** |
| 上游 path | `logistics/202309/warehouses` |

## 官方接口原文（TikTok Shop Partner Center）

> Partner Center 页面需登录；以下按官方 Open API 约定与公开参考整理。完整字段以 Partner Center 为准。

# Path: /logistics/202309/warehouses
# Method: [GET]
# Function Description
Get the warehouse list of the shop, including sales warehouses and return warehouses. Use warehouse IDs when creating products with multi-warehouse inventory or updating stock.

## Agent 注意事项

1. 多仓刊登：先本接口拿 `warehouse_id`，再在 `linkfox-tiktok-shop-product` 的库存字段里指定仓库。
2. 区分 `SALES_WAREHOUSE` 与 `RETURN_WAREHOUSE`（同址也可能有不同 id）。
3. `effect_status=RESTRICTED/DISABLED` 时提醒用户该仓库存可能不可售。
