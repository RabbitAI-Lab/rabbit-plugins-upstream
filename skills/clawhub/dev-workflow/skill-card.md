## Description:

Guides development and bug-fix tasks through branch creation, requirement confirmation, testing, user acceptance, and release.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers use this Chinese-language checklist to plan feature and bug-fix work, confirm requirements or reproduce defects, check tests, and seek user acceptance before release.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation on coding tasks may slow small changes with mandatory process steps.

Mitigation: Apply the checklist when the task warrants it, and confirm the expected process with the user for quick edits.

Risk: Required branch creation and test setup may not fit the target repository's workflow.

Mitigation: Check the repository's branching and test conventions with the user before making changes.
