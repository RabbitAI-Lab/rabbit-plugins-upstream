# Chicago quick reference (17th ed., both systems)

## Notes-bibliography (NB)

### Note templates (first citation, full form)

| Type | Note form |
|---|---|
| Book | `First Last, Title of Book (Place: Publisher, Year), 25.` |
| Chapter | `First Last, "Chapter Title," in Book Title, ed. Editor (Place: Publisher, Year), 45-52.` |
| Journal | `First Last, "Article Title," Journal Name Volume, no. X (Year): 33-35.` |
| Web | `First Last, "Page Title," Site Name, Month Day, Year, URL.` |
| Two authors | `First Last and First Last, ...` |
| 4+ authors | `First Last et al., ...` |
| Shortened | `Last, Short Title, 26.` |

### Bibliography templates

| Type | Bibliography form |
|---|---|
| Book | `Last, First. Title of Book. Place: Publisher, Year.` |
| Chapter | `Last, First. "Chapter Title." In Book Title, edited by Editor. Place: Publisher, Year.` |
| Journal | `Last, First. "Article Title." Journal Name Volume, no. X (Year): xx-xx.` |
| Web | `Last, First. "Page Title." Site Name. Month Day, Year. URL.` |

## Author-date (AD)

| Situation | Form |
|---|---|
| Parenthetical | (Smith 2024, 12) |
| Two authors | (Smith and Jones 2024) |
| 4+ authors | (Smith et al. 2024) |
| Reference list | `Smith, John. 2024. Title of Book. Place: Publisher.` |

## Signature rules

- NB: commas inside notes; periods in bibliography entries. Note punctuation differs from bibliography punctuation.
- `Ibid.` deprecated in 17th ed.; use shortened citations instead.
- Headline capitalization; titles italic for books/journals, quotation marks for articles/chapters in notes and bibliography.
- Page numbers in notes have no `p.`/`pp.`: just the number.
- Bibliography alphabetical; `3-em dash` for repeated authors is optional legacy.
- Pick one system per document; never mix.
