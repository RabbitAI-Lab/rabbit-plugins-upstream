## Description:

Chicago style both systems: notes-bibliography (footnotes) and author-date. Covers system selection, note forms, bibliography, shortened citations. Use for papers requiring Chicago.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vhsgreed](https://clawhub.ai/user/vhsgreed)

### License/Terms of Use:

MIT-0

## Use Case:

Writers, students, and agents use this skill to format Chicago notes-bibliography or author-date citations, bibliography entries, shortened notes, and reference lists for papers requiring Chicago style.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Citation details may not match an instructor's required Chicago edition or local style guide.

Mitigation: Verify generated citations against the required Chicago edition, assignment instructions, or local style guide before submission.

Risk: The notes-bibliography and author-date systems can be mixed accidentally in one document.

Mitigation: Confirm the required Chicago system before formatting and check that the final document uses only that system.
