## Description:

Review recent public Instagram Reels from one or more creators. Get daily or weekly insights with source links, based on available transcripts.

This skill is ready for commercial/non-commercial use.

## Publisher:

[apismith-labs](https://clawhub.ai/user/apismith-labs)

### License/Terms of Use:

MIT-0

## Use Case:

External marketers, creator teams, and agencies can review recent public Reels from specified Instagram creators. They use transcript-based daily or weekly reports to identify topics, hooks, and calls to action with links to source posts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security assessment reports detected network capability without a declared tool scope.

Mitigation: Review the host's network and tool permissions before use, and limit reports to user-specified public accounts.

Risk: Using more creators or processing more videos can increase usage on the user's Apify account; the per-creator processing limit does not cap usage or cost.

Mitigation: Check current Apify usage before running reports, and never provide passwords, tokens, cookies, or session values in chat.
