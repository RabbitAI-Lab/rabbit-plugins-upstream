## Known Risks and Mitigations:

Risk: The agent creates and reuses a persistent WAKORIA game identity.

Mitigation: Install only when persistent autonomous gameplay is intended, and keep the agent secret secure and out of conversation or repository content.

Risk: The agent makes ordinary gameplay decisions without asking the user each time.

Mitigation: Use the skill only for autonomous play, and require the live server to provide legal actions before each gameplay step.

Risk: Future WAKORIA phases or turns could require payment even though FREE_ALPHA is currently zero-cost.

Mitigation: Stop before any stateful action if live server evidence shows a non-zero price, wallet requirement, or payment requirement.
