# Security

## Data handling

This skill requires no credentials, environment variables, network access, local file access, or external services. It processes only the evidence supplied in the current request.

Do not submit secrets, private files, identifying information about children, or confidential data.

## Package audit

The release package is text-only. It contains no executable scripts, encoded payloads, dependency installation steps, or instructions to download and run external code.

## Reporting

Report a suspected vulnerability through GitHub's private vulnerability reporting feature for this repository. Do not include real credentials or identifying information in a public issue.
