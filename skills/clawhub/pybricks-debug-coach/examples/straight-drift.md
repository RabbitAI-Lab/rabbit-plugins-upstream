# Straight drift

## Input

The robot should drive straight 300 mm but drifts right. Three runs show the same behavior. Telemetry reports heading changes of +11, +10, and +12 degrees. No robot-reference mapping is supplied.

## Expected coaching behavior

- Cite repeatability and heading change.
- Name one likely first cause with uncertainty.
- Change one variable only, such as halving drive speed.
- Define an observable pass threshold before retesting.
- List the missing motor mapping as an evidence gap.
- Do not rewrite the drive program.
