## Description:

Write UGC (creator-style) video ad scripts that sound like a person, not an ad. Picks a format beyond the overused testimonial, sizes the script to the video length by words per second, structures it beat by beat (hook, problem, demo, proof, ask), and writes it so it works with the sound off and when an AI video model or voice reads it.

This skill is ready for commercial/non-commercial use.
