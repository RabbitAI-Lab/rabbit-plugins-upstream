# 85㎡旧房改造，一点北欧，一点美式，装出高级感

本套房属于旧房改造，已经入住N年了，原来属于小两口父母入住，时间久了，给父母新买的房子，然后作为小两口的婚房改造。属于比较老旧的装修，对于一辈子一次的婚房来说，肯定全部拆除重新来过。从造价来说，要比一般的毛坯造价高多了，为了幸福，也是值得的。

户型：两室两厅一厨一卫
造价：拆除8千，半包4万，主材4.5万，定制1.5万，家具家电设计师推荐，业主自购
▲原始图纸，入门就是餐厅和门厅的共用空间；左手是厨房，奇葩的是进入卫生间必须先进入厨房，这个实在无法忍受，不知道当初开发商设计的时候出于什么考虑？厨房带一个洗衣阳台，空间零碎而且很不合理；两个卧室夹着客厅空间，而且没有阳台。
业主要求：虽然是婚房，但是后期肯定有小孩，所以从环保考虑，一切木地板和壁纸都不使用；先改变进入厨房才能进入卫生间的尴尬；增加光线的明度，硬装上尽量简单，给后期软配留有空间；希望通过简单的墙面变色突出空间的明度和质感
▲设计图纸。1.入门左手的厨房门做了向内推移，把卫生间彻底留在外头，改变过去进入卫生间必须进厨房的尴尬，同时砸掉厨房阳台，打通空间，让厨房延伸至阳台，拓展空间的同时，让视觉空间更通透；
2.厨房门内移以后，卫生间对面刚好设计干区空间，改变过去牙刷和马桶共处的环境。装修房子本身就是品质的提升，否则就失去装修的意义了；
3.进门就是餐厅本身很小，所以为了满足基本的就餐需求，采用轻巧的家具配置；直对面利用墙体定制玄关柜，同时弥补门口鞋柜收纳的不足；其他没有改变，保留原来的结构
▲没有改造之前的入户，左手就是厨房移门，卫生间对面就是突兀的冰箱，厨房因为有洗衣间分割，导致光线非常昏暗

▲重新装修以后，厨房门内移，进门左手成品的鞋柜放置，基本满足两人的进门收纳；鞋柜上方为了视觉美观，采用墙挂干枝以及马卡龙的挂衣钩布置，满足功能的同时还能保证进门的颜值

▲门厅新装修的全景，把厨房门内移，保留原来的垭口门洞，门口白色的成品小鞋柜满足进门收纳；门口餐厅采用原木轻巧餐桌椅满足就餐需求；原来的枣红色难看的防盗门采用门毡的形式包装成灰色，与室内统一协调
▲进门右手的餐厅，本身空间小，旁边还有小卧室的门，更局促了。采用轻巧的原木餐桌椅，搭配条凳的方式，满足基本的需求；墙面高级灰的变色与白色木门与踢脚线层次分明，简洁素雅；餐厅背景一边绿植挂画，另一边铁艺隔板摆上精美摆设，营造清新就餐区
▲桌子上清雅的摆设，淡雅桌旗装饰，莫兰迪的水壶，搭配古朴的中式花瓶，非常有意境
▲网购的铁艺隔板，摆上小巧的水养绿植，一本书籍和挂画搭配，艺术气息和高级感扑面而来

▲网购的每一个小摆设，都能看出小两口对未来生活的憧憬

▲没有装修之前的进门情况，直对定制的黄色的收纳柜，加上地面木地板的昏暗，导致进门处压抑，显得非常拥堵。客餐厅还做了拱形的垭口，和风格格格不入
▲新装修以后，地面采用600*600的灰色仿古砖，墙面淡淡的烟灰色，重新定制的白色与木色套色的收纳柜，视觉要清新时尚多了。角落还能放置全身镜，满足生活的功能性需求
▲白色与木色的自然清新，刚好作为进门直对的玄关，同时弥补进门鞋柜的收纳不足
▲没有改造之前的客厅空间，深色地板不仅不环保而且让光线更昏暗，原来父母辈喜欢的L型布局沙发臃肿庞大，占据了客厅太多空间；颜色太沉重的窗帘把仅有的一点光线全挡住了
▲新装修以后，首先改变窗帘的颜色，采用浅色麻质布帘和纱帘让视觉上干净，让光线一览无余；把原来深色的窗户改成了落地窗，颜色做成了白色明亮；同时采用同样浅色麻质的沙发搭配，轻巧的原木家具统一提升空间质感，电视墙简单PU线条，统一墨绿的变色处理对比，空间又有美式的优雅
▲原木的自然质感与墨绿的碰撞，有自然的清爽，又有复古的优雅，非常适合婚房的搭配

▲艺术玻璃的电视柜移门，视觉通透灵巧，旁边高大绿植的装扮增加生活气息

▲客厅浅色布艺沙发搭配，可以让空间更明亮，角落空间不放边几，放置成品斗柜，可以满足一部分收纳，同时上头还能摆放装饰提升颜值，铜质的轻巧落地灯与组合挂画搭配，清新而且复古
▲整体装修上硬装基本非常简单，就是铺灰色仿古砖，墙面变色而已，不做吊顶，普通石膏线拉出层次感即可，为后期软配和家具留够充足的空间，否则小空间就会非常压抑

▲主卧落地窗光线还是可以，只不过过去的黄色的衣柜，而且做得很大，深色木地板

▲新装修以后，因为主卧进门直对的是一节墙体以及衣柜的侧面，所以借用空间做了局部的镂空收纳柜，可以进门放置包包作为展示作用，和衣柜完全融为一体，进门也不会很呆板
▲更换掉原来的深色木地板，采用木纹砖环保代替，同样采用灰色系变色，冷色窗帘与纱帘布局，视觉更轻盈明亮

▲背景其实是脏粉变色，其他墙面是高级灰布局，侧墙定制灰色平板衣柜，满足收纳还要保证视觉干净。床尾是开放式书柜，可以随手放杂物，同时衣帽架保证晚上衣服的悬挂

▲空间其实并不大，所以两边分别采用壁灯和落地灯搭配，视觉更灵活，背景就是简单一副挂画装饰，右上角后面要装空调，害怕视觉太乱
▲没有装修前的次卧空间，因为空间小为了多收纳，导致吊柜非常压抑，而且成品床布局，让空间拥挤
▲新装修以后的次卧，采用榻榻米定制的形式，不仅满足衣柜收纳，同时借用飘窗做了L型转角书桌，上方为了不至于挡住光线，采用隔板代替书架，平时作为书房使用，以后这里可以作为儿童房使用《家里有小孩，怎么做全屋定制更环保？》
▲原来的厨房，进门右手就是卫生间，也就是进入卫生间必须进入厨房，而且采用的是美式的格子瓷砖，混搭红色的玻璃橱柜门，带的洗衣间还分割了空间，导致空间不仅小而且昏暗
▲新装修以后的厨房，不仅内移推拉门，改变进卫生间必须进厨房的尴尬。进门左手安排冰箱位置，统一采用浅色石材瓷砖搭配，地面通铺客厅灰色仿古砖裁割的瓷砖，防滑而且耐脏。橱柜采用地柜木色与吊柜白色清新搭配，同时打通洗衣间，让空间更宽敞，光线更明亮
▲站洗衣间看厨房全景，L型布局功能性满足，灰色调木色和白色视觉更清新明亮
▲卫生间原来的样子，本身空间小，采用格子的深灰色墙砖导致自然光更昏暗
▲卫生间新装修以后，因为把干区做到了外面，里头就是马桶和淋浴，空间大多了。墙面采用白色的面包砖，地面成品的六边形瓷砖灰色点缀，视觉明亮多了，搭配非常有质感的黑色五金，平时浴帘遮挡满足基本功能
▲厨房门内移以后，卫生间门口刚好定制浴柜，干湿分离，镜柜收纳，借用左侧墙面还做了壁龛收纳，不仅视觉美观，增加收纳，最重要的是满足了健康需求END
