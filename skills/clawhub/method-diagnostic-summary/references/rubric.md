# Method 部分「全面诊断汇总」评分规则

> 适用对象：`method-diagnostic-summary` Skill 的汇总报告
> 评分基础：本汇总 Skill 不直接打分，而是调用 6 个分项 Skill（structure / logic / cohesion / conventions / grammar / vocabulary）的结果，按预设权重加权汇总，输出 Method 节**整体诊断评级**
> 满分：**100 分**

---

## 一、维度权重表

Method 节整体评分由 **6 个分项 Skill** 的得分加权汇总得到。权重基于 Method 节的**学术规范核心优先级**与**顶刊审稿人敏感度**设定：

| # | 维度 | 对应 Skill | 权重 | 适用判定 |
|---|------|------------|------|----------|
| 1 | **结构** | `method-structure-diagnostic` | **25%** | Method 6 大模块是否齐全、是否可复现、是否按层次子段组织 |
| 2 | **语法** | `method-grammar-diagnostic` | **20%** | 动词时态、主动/被动语态归属、介词、冠词、可数性 |
| 3 | **逻辑** | `method-logic-diagnostic` | **20%** | 方法选择论证链、假设—设计—测量—分析链条、Option 1/2/3 定位、局限即时披露 |
| 4 | **词汇** | `method-vocabulary-diagnostic` | **15%** | 学术术语精确性、技术动词选择、对比/因果/让步连接词、量尺锚点用语 |
| 5 | **衔接** | `method-cohesion-diagnostic` | **10%** | 时序衔接准确性、段落过渡自然性、模块间逻辑连贯性、指代与承接清晰性 |
| 6 | **规范** | `method-conventions-diagnostic` | **10%** | 引用格式与标注、Option 1/2/3 标注、伦理与透明声明、术语与格式一致性 |
| | **合计** | — | **100%** | — |

**权重设定理由**：

- **结构 (25%)**：Method 节的核心目标是"读者能完整复现研究"。模块缺失、子模块要素不齐全、漏斗式样本流程断裂是顶刊审稿人最敏感的硬性指标，单点缺失足以判稿。
- **语法 (20%)**：时态、语态、介词、冠词的混乱会让读者无法判断「这工作是谁做的」；教材 p.113–115 把这列为"highly detrimental to the success of your research paper"。
- **逻辑 (20%)**：方法选择若无合理论证、设计无自洽性、变量与控制说明不完整，整篇论文的可信度受损。
- **词汇 (15%)**：技术动词与名词短语选择影响表达精确性，但不构成"结构性问题"。
- **衔接 (10%)**：时序衔接错误会让读者回读，但不至于完全失读；段落过渡与指代问题通常影响可读性而非可复现性。
- **规范 (10%)**：引用标注、伦理声明、格式一致性是"硬合规"问题，单点缺失不致命但不可累计；但若出现虚假引用 / IRB 缺失 / 预注册偏离未声明，将由分项 Skill 强制降档（参见 `method-conventions-diagnostic` rubric 强制降档规则）。

## 二、综合得分计算方式

### 2.1 标准计算公式

```
综合得分 = Σ (各维度得分 × 权重)

其中：
- 各维度得分 = 6 个分项 Skill 的原始得分（0–100 分）
- 权重 = 该维度对应的百分比
```

**示例**：

| 维度 | 权重 | 分项 Skill 得分 | 加权得分 |
|------|------|----------------|----------|
| 结构 | 25% | 92 | 92 × 0.25 = 23.00 |
| 语法 | 20% | 85 | 85 × 0.20 = 17.00 |
| 逻辑 | 20% | 88 | 88 × 0.20 = 17.60 |
| 词汇 | 15% | 90 | 90 × 0.15 = 13.50 |
| 衔接 | 10% | 80 | 80 × 0.10 = 8.00 |
| 规范 | 10% | 78 | 78 × 0.10 = 7.80 |
| **合计** | **100%** | — | **86.90 → 87 分** |

### 2.2 综合得分四舍五入

最终得分 = round(综合得分 × 100) / 100，保留两位小数（四舍五入）。

### 2.3 缺失维度的处理

若某一维度无对应文本（如 Method 节无 Measures 段，结构维度无法打分），按以下规则处理：

| 情况 | 处理 |
|------|------|
| 维度对应文本完全缺失（如 Methods 节没有 Measures 段） | 该维度按 0 分计算，并在报告中标注"模块缺失，未评估" |
| 维度对应文本极短不足以诊断（<500 词） | 该维度按 50 分保守赋值，并在报告中标注"样本不足，保守赋值" |
| 维度评估被用户显式跳过 | 该维度权重按比例分摊到其他维度 |

**权重再分配示例**（假设规范维度被跳过）：

```
原总权重：25% + 20% + 20% + 15% + 10% + 10% = 100%
跳过规范后：25% + 20% + 20% + 15% + 10% = 90%
再分配后：结构 25/90 × 100% ≈ 27.8%，语法 20/90 ≈ 22.2%，逻辑 20/90 ≈ 22.2%，词汇 15/90 ≈ 16.7%，衔接 10/90 ≈ 11.1%
```

## 三、整体等级划分

| 综合得分区间 | 等级 | 含义 | 投稿建议 |
|------------|------|------|----------|
| **90–100** | 优秀（A） | 几乎所有 6 个维度都达标；Method 节在结构 / 论证 / 语言 / 规范上均达到顶刊投稿水平；具备接近顶刊 Method 节的整体质量 | 可直接投稿顶刊（JPSP / JEP:G / Developmental Psychology / PSPB 等） |
| **80–89** | 良好（B） | 关键维度基本达标；可能存在少量中等问题或个别轻微问题；不影响整体可读性、可复现性、可信度 | 可投稿顶刊或主流 SSCI 期刊；建议修改 1 轮后投稿 |
| **70–79** | 合格（C） | 多项中等检查存在缺口，或个别严重检查项不达标；存在可见的论文质量短板 | 建议修改 1–2 轮后投稿；优先整改严重问题 |
| **60–69** | 待改进（D） | 多项严重检查项不达标，或大量中等检查存在缺口；Method 节存在可复现性 / 学术诚信 / 结构完整性的硬伤 | 需结构性补写后方可投稿；建议请导师 / 同行评审后再投稿 |
| **<60** | 不合格（F） | 大量严重问题未解决；Method 节未达到学术规范最低标准 | 必须重写；建议配合各分项 Skill 全维度整改后重新提交诊断 |

## 四、强制降档规则（沿用分项 Skill 的强制规则）

汇总评级时，**强制降档规则优先于综合得分判定**。当任一分项 Skill 触发强制降档条件时，整篇 Method 节评级上限受其限制：

### 4.1 各分项 Skill 强制降档条件

| 分项 Skill | 强制降档条件 | 评级上限 |
|-----------|--------------|---------|
| `method-structure-diagnostic` | 5 大核心模块（Participants / Design / Measures / Procedure / Analysis）缺失 ≥ 2 个 | D 档（最高 69 分） |
| `method-logic-diagnostic` | 严重违例 ≥ 3 处 | D 档（最高 69 分） |
| `method-cohesion-diagnostic` | 严重违例 ≥ 3 处 | D 档（最高 69 分） |
| `method-conventions-diagnostic` | 1 处严重问题 | B 档（最高 89 分） |
| `method-conventions-diagnostic` | 2 处严重问题 | C 档（最高 79 分） |
| `method-conventions-diagnostic` | 3 处及以上严重问题 | D 档（最高 69 分） |
| `method-grammar-diagnostic` | 严重时态 / 语态错误 ≥ 3 处 | D 档（最高 69 分） |
| `method-vocabulary-diagnostic` | 严重术语 / 短语错误 ≥ 3 处 | C 档（最高 79 分） |

### 4.2 学术诚信底线（一票否决）

以下问题一旦触发，无论综合得分高低，**强制 F 档**：

- 虚假引用（引用未做的工作）
- IRB / 伦理委员会批准编号缺失（有人体被试的研究）
- 知情同意程序未描述（有人体被试的研究）
- 预注册与实际数据完全不符（如宣称预注册但未预注册、预注册分析与实际分析矛盾）
- 数据 / 代码 / 材料公开声明为假（OSF 链接失效 / 数据集不可访问）

**判断说明**：学术诚信问题不能以"修改后重投"为由搁置；触发一票否决条件时，需在修改后重新诊断。

### 4.3 强制降档的优先级

```
1. 一票否决条件（学术诚信） > 2. 强制降档条件（各分项 Skill） > 3. 综合得分判定
```

**示例**：

```
综合得分：87 分（按权重计算结果）
触发条件：method-conventions-diagnostic 触发 1 处严重问题（虚假引用）
强制降档：B 档（最高 89 分）
最终评级：B 档（87 分）
```

```
综合得分：87 分（按权重计算结果）
触发条件：method-conventions-diagnostic 触发 2 处严重问题（虚假引用 + IRB 缺失）
强制降档：C 档（最高 79 分）
最终评级：D 档（综合得分已被强制降档超越，F 档触发 → 实际 F 档）
```

## 五、单维度评级辅助表

为便于解读每个维度的独立表现，汇总报告除综合得分外，**同步呈现每个维度的子评级**。子评级沿用各分项 Skill 的 5 档等级：

| 子得分区间 | 子评级 |
|----------|--------|
| 90–100 | 优秀（A） |
| 80–89 | 良好（B） |
| 70–79 | 合格（C） |
| 60–69 | 待改进（D） |
| <60 | 不合格（F） |

**子评级的意义**：

- 帮助定位"哪个维度最弱"（最弱维度即整改优先级最高的维度）
- 帮助判断"是否某一维度异常低拖累了综合得分"（如某维度 < 60 即使综合得分 ≥ 80，仍需重点整改）
- 整改时按子评级排序：F 维 → D 维 → C 维 → B 维 → A 维

---

## 六、得分门槛与投稿建议矩阵

综合评级 + 各维度子评级共同决定投稿建议：

| 综合评级 | 必备条件 | 投稿建议 |
|----------|---------|----------|
| **A (90–100)** | 所有 6 个维度子评级 ≥ B；无任何严重问题 | 可直接投稿顶刊 |
| **B (80–89)** | 所有 6 个维度子评级 ≥ C；最多 1 个维度子评级 = C；无任何严重问题 | 建议修改 1 轮后投稿顶刊 / 主流 SSCI |
| **C (70–79)** | 最多 2 个维度子评级 ≤ D；严重问题 ≤ 1 处 | 建议修改 1–2 轮后投稿；优先整改 D 维度与严重问题 |
| **D (60–69)** | 严重问题 2–3 处或多项 D 维度 | 需结构性补写；建议请导师 / 同行评审后再投稿 |
| **F (<60)** | 严重问题 ≥ 4 处或存在一票否决条件 | 必须重写；不推荐当前版本投稿 |

## 八、汇总 Skill 的特殊职责

`method-diagnostic-summary` Skill 与其他 6 个分项 Skill 的职责边界：

| Skill | 职责 |
|-------|------|
| **6 个分项 Skill** | 单维度诊断 + 单维度评分 + 单维度修改建议 |
| **method-diagnostic-summary（本 Skill）** | 调用 6 个分项 Skill + 按权重加权汇总 + 输出综合评级 + 定位最弱维度 + 给出投稿建议 |

**禁止行为**：
- 汇总 Skill 不得直接进行单维度诊断（应调用分项 Skill）
- 汇总 Skill 不得自行修改分项 Skill 的评分（必须以分项 Skill 输出为准）
- 汇总 Skill 不得新增分项 Skill 未识别的违例（汇总报告的核心是"整合"而非"扩展"）

**必须行为**：
- 汇总 Skill 必须依次调用 6 个分项 Skill（或用户显式指定的维度组合）
- 汇总 Skill 必须按本文件第一节权重表加权计算
- 汇总 Skill 必须检查强制降档条件并优先于综合得分
- 汇总 Skill 必须按最弱维度排序整改优先级
