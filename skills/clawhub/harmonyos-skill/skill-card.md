## Description: <br>
Harmonyos Skill helps developers build HarmonyOS 7 (API 26) apps with ArkTS and ArkUI code, migration guidance, API checks, and implementation patterns. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[fff-119](https://clawhub.ai/user/fff-119) <br>

### License/Terms of Use: <br>

## Use Case: <br>
Developers and engineers use this skill to draft HarmonyOS application code, plan ArkTS and ArkUI architecture, migrate deprecated APIs, and check implementation patterns for HarmonyOS 7 compatibility. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The security review found suspicious self-learning behavior that can persistently modify knowledge from conversations. <br>
Mitigation: Install only when this behavior is acceptable, disable automatic persistence by default, and require an explicit reviewed diff before any knowledge-base or skill-file update. <br>
Risk: Generated HarmonyOS code and migration guidance may be version-specific or unsuitable for a target project without review. <br>
Mitigation: Review generated code, validate it against the intended HarmonyOS API level, and test it in DevEco Studio before relying on it. <br>
