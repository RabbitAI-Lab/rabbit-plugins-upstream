## Known Risks and Mitigations:

Risk: AI-HIVE API keys may be exposed if users paste real credentials into chat, logs, screenshots, or shared files.

Mitigation: Use limited AI-HIVE API keys, keep examples as placeholders, and avoid storing or sharing real keys outside the local configuration file.

Risk: Video or image generation can incur cost, especially for batch or repeated tasks.

Mitigation: Review model routing, pricing snapshots, prompts, and task parameters before submitting generation jobs; run small samples before batches.

Risk: Uploaded media may contain private, copyrighted, trademarked, or otherwise unauthorized material.

Mitigation: Upload only assets the user has rights to use, and limit unverified references to abstract structure or newly created concepts.

Risk: Generated outputs and downloaded task results may be saved locally under user download paths.

Mitigation: Review output locations, remove sensitive files when no longer needed, and avoid using private material unless local storage is acceptable.

Risk: Ad scripts or generated claims may overstate product performance, platform outcomes, or commercial results.

Mitigation: Mark unverified facts for review, require source support for product and business claims, and avoid promises about traffic, sales, ranking, approval, or return on investment.
