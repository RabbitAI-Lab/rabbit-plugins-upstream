## Description: <br>
Deepgram speech-to-text, text-to-speech, voice agents, and audio intelligence API reference, documentation navigation, recipes, starters, and MCP setup for building Deepgram integrations. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineers use this skill to look up Deepgram REST and WebSocket API details, choose models and starter apps, generate focused implementation guidance, and configure Deepgram MCP access for AI coding tools. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: MCP setup can persistently connect a coding tool to Deepgram services with broad tool or account access. <br>
Mitigation: Prefer project-scoped MCP configuration, review whether hosted MCP access is appropriate for sensitive code or prompts, and use the local CLI MCP only after confirming the allowed Deepgram account actions. <br>
