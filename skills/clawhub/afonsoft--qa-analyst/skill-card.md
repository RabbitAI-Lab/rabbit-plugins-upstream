## Description:

QA Analyst guides agents through requirements review, test planning, test case creation, execution, defect reporting, root-cause analysis, and re-validation, with user-facing clarifications in Portuguese (pt-BR).

This skill is ready for commercial/non-commercial use.

## Publisher:

[afonsoft](https://clawhub.ai/user/afonsoft)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, engineers, and QA reviewers use this skill to structure quality assurance work before and after implementation, including requirement review, test planning, coverage checks, defect reports, and regression re-validation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad QA-related trigger wording may activate the skill for general quality discussions.

Mitigation: Confirm the user wants a structured QA workflow before applying plans, templates, or defect-reporting steps.

Risk: The skill requires user-facing questions and clarifications in Portuguese (pt-BR).

Mitigation: Use it where Portuguese interaction is expected, or explicitly adapt language expectations before deployment.

Risk: The skill may suggest document updates or GitHub issue creation as part of QA tracking.

Mitigation: Review proposed file changes and issue content before allowing repository updates or external tracking actions.
