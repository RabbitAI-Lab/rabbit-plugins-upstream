# 本地处理说明

这些脚本只读用户提供的UTF-8文本或CSV，不联网、不读取或保存密钥。输入单文件上限2MiB。输出目录必须不存在，避免覆盖已有成果；错误时修正参数或拆分文件，只重跑未完成部分。

TXT/Markdown直接作为文本读取；PDF、Word、图像需由宿主环境先提取成新文本。字符偏移以统一换行LF后的Unicode字符计数，非字节偏移；CSV来源行号为记录结束的物理行，多行单元格可能跨行。不要冒充原PDF页码。

CSV第一行是列名，不接受重复表头或字段数错位。默认UTF-8带BOM输出，脚本保留原值在明细JSON中；Excel可能解释为公式的显示单元格前加单引号，不执行公式，不改变明细里的原始值。

## 号码识别
覆盖两字母代码+4至14位数字+种类字母及可选数字的常见公开号候选，包括号码内空白、全角和斜杠写法；另识别带CN/ZL前缀的12位中国申请号及小数点校验位。只作候选提取，未验证国家/种类代码、校验位或存在性，不支持所有历史格式；换行断开的号码和OCR误字应人工核对。每次出现都保留，不自动联网，不归并专利族。超过10000处候选须按章节拆分。

## 文献引用
默认列：公开号、标题、公开日、申请人、责任者。可用--number-column、--title-column、--date-column、--applicant-column、--responsible-column指定已有列名。申请日不是公开日，申请人不自动当作者。默认是通用编号阅读格式；若要国标或期刊格式，先核对用户提供的规则及当前版本，再从保留的字段表重排，不声称自动认证。

## 版本对比
两侧均须有文本，每侧不超过2000行；超限按对应章节拆分，不截断。统一换行，其余空格和文字保留。差异为行级对齐，不是法律判断；不自动判定段落移动，重复段落可能有多种对齐。HTML内容与文件名均转义，文件离线可读，无脚本或外部请求。

## 数据质检
--required指定必填列，--date-columns指定日期列，--number-column指定号码列。默认检查公开号、标题、申请人、公开日必填，申请日/公开日的日期格式和先后关系。年、年月精度保留并提示，不补日期。日期先后只提示复核字段口径，不判定法律事实。公开号只做内部格式和重复标识提示；A/B保持不同，不自动归并、删除或修改原行。
