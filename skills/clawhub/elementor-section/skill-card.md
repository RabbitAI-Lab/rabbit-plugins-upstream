## Description:

Turns a section of a live website into an Elementor template for import into WordPress.

This skill is ready for commercial/non-commercial use.

## Publisher:

[soraiabarroso](https://clawhub.ai/user/soraiabarroso)

### License/Terms of Use:

MIT-0

## Use Case:

WordPress and Elementor users turn a chosen website section into a styled template they can import into their own site.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The target page URL and requested section are shared with MiroMiro, and extraction uses API credits.

Mitigation: Confirm the user is comfortable sharing the URL and spending credits before requesting extraction; only retry with rendering when needed.

Risk: Copied website content may include text, logos, or images the user cannot republish.

Mitigation: Replace copied text, logos, and images unless the user owns or has permission to use them.
