## Use Case: <br>
Solopreneurs and small business operators use this skill to identify repetitive tasks, choose no-code automation tools, design workflows, test automations, and plan ongoing maintenance. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill requests command-execution capability even though the artifact is primarily a Markdown automation planning guide. <br>
Mitigation: Prefer a release without exec permission, or install and run it only in an environment where command execution is constrained and explicitly approved. <br>
Risk: Automation workflow advice can lead to silent business-process failures if proposed automations are deployed without testing and monitoring. <br>
Mitigation: Test each workflow with realistic data, add failure notifications, review logs regularly, and document how each automation can be troubleshot. <br>
