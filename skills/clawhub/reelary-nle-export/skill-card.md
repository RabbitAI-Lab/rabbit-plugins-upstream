## Description:

Hand a cut built from the user's own footage to a professional editor as an FCPXML, XML or EDL that references the original files, for Adobe Premiere Pro, Final Cut Pro or DaVinci Resolve finishing.

This skill is ready for commercial/non-commercial use.

## Publisher:

[reelary](https://clawhub.ai/user/reelary)

### License/Terms of Use:

MIT-0

## Use Case:

Video editors and creators use this skill to hand off a Reelary cut for finishing in Premiere Pro, Final Cut Pro, or DaVinci Resolve. A Reelary project is required, and NLE export is a Pro feature.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The optional command-line fallback has a dependency risk.

Mitigation: Prefer a trusted, version-pinned Reelary installation for the command-line fallback.

Risk: The exported timeline depends on access to the original media files.

Mitigation: Keep the original media available and import on the same computer or relink the files.
