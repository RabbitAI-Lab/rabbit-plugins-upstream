## Known Risks and Mitigations:

Risk: The skill automatically updates and runs downloaded code.

Mitigation: Review and pin a fixed runner version, and approve updates before running them.

Risk: The instructions restrict cancellation during potentially lengthy research.

Mitigation: Keep cancellation under user control and allow the user to stop a run at any time.

Risk: The instructions conflict about API-key access.

Mitigation: Have the user create and keep the key in local configuration; use it only for authentication and never request it in chat.

Risk: Company queries are sent to Cue and research consumes account credits.

Mitigation: Explain the data transfer and credit use, and obtain the user's approval before starting research.
