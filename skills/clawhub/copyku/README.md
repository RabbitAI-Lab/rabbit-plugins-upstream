# Copyku - AI Copywriting Expert 🌍

AI Copywriting Expert untuk digital marketing, social media, landing page, iklan, brand positioning. Multi-language (6 bahasa), 30+ tone, A/B testing, email sequences, SEO meta, bulk mode, dan 6 industry templates.

---

## 🚀 Quick Start

```bash
clawhub install copyku
```

## ⚡ 3-Mode Workflow

### 🚀 Mode 1: Quick Copy (Cepat)
Langsung sebutkan kebutuhan:
```
copyku, caption produk kopi
copyku, headline kursus online
copyku, landing page ebook bisnis
copyku, WhatsApp promo skincare (EN)
```

### 🎯 Mode 2: Guided (Step-by-Step)
```
copyku, guided
```
Copyku akan bertanya step-by-step:
1. Bahasa (id/en/zh/ja/ms/ar)
2. Nama produk
3. Target market
4. Platform
5. Tujuan
6. Tone

### ⚙️ Mode 3: Advanced (Full Control)
```
language: id
product: Kopi Kenangan
target_market: karyawan muda
platform: Instagram
tone: Storytelling
objective: closing
awareness: product
ab_testing: true
output_format: markdown
industry: food
bulk_count: 5
seo_meta: true
```

## 📐 Copy Formulas

- **AIDA** - Attention → Interest → Desire → Action
- **PAS** - Problem → Agitation → Solution
- **BAB** - Before → After → Bridge
- **4U** - Urgent, Unique, Useful, Ultra-specific
- **SSC** - Story → Sell → Close
- **PASOC** - PAS + Offer + CTA
- **Short AIDA** - WhatsApp/SMS optimized
- **Hook-Pattern Interrupt** - TikTok/Reels format
