## [1.7.0] - 2026-07-26

### 🌍 Multi-Language Extended
- Tambah 4 bahasa baru: zh (中文), ja (日本語), ms (Bahasa Melayu), ar (العربية)
- Total 6 bahasa: id, en, zh, ja, ms, ar
- Output mengikuti pilihan bahasa user

### 📱 Auto Char Limit
- Auto-adjust karakter per platform:
  - Instagram: 2200 char
  - TikTok: 300 char
  - LinkedIn: 3000 char
  - Twitter/X: 280 char
  - WhatsApp: 659 char
  - SMS: 160 char
  - Telegram: 4096 char

### 📧 Email Sequence
- Drip campaign: welcome, launch, cart abandonment
- Welcome: 3-5 email selamat datang + brand story
- Launch: 5-7 email pre-launch → launch → post-launch
- Abandon: 3 email cart abandonment + urgency

### 🔍 SEO Meta Copy
- Meta title (60 char), meta description (155 char)
- OG title (60 char), OG description (200 char)
- SEO-optimized output

### 🏭 Industry Templates
- 6 template industri: F&B, Fashion, Health, EdTech, SaaS, Property
- Pre-built focus per industri
- Auto-select berdasarkan input user

### 📦 Bulk Mode
- Generate 5-10 copy sekaligus untuk content calendar
- Multi-variation output dalam satu request

### 🧪 Copyku Lab (A/B Testing)
- Generate 2-3 variasi copy per request
- Rationale untuk setiap variasi

### ⚙️ Advanced Fields
- competitor_context, value_prop, guarantee, compliance_notes
- output_format: plain, markdown, html
- ab_testing, bulk_count, seo_meta, email_sequence, industry

### 🛡️ Peningkatan Ethical
- Compliance notes untuk industri sensitif
- Realistis untuk jaminan/garansi
