# my-style-writer 🍯

> 「我的风格文章创作」— 让 AI 学会你的写作 DNA，替你写出「你自己味道」的文章

一个 [WorkBuddy](https://www.workbuddy.cn) 技能（Skill），实现三件事：

**风格学习 → 替身写作 → 公众号排版输出**

写出来的文章不是「AI 味」，而是「你味」。

---

## ✨ 核心功能

### 1. 风格学习与分析（学习你的写作 DNA）

扫描文章库中的 Markdown 历史文章，从多个维度提炼你的写作风格特征：

- **用词偏好** — 高频词汇、惯用口语、行业术语、语气词
- **句式结构** — 句长分布、长短句节奏、设问/反问习惯
- **段落节奏** — 段落长度、分段频率、视觉呼吸感
- **语气语调** — 口语化程度、人称使用模式、人格化 IP
- **修辞手法** — 对比、设问、比喻、金句密度、Emoji 使用模式
- **叙事视角** — 个人经历 vs 客观分析、参与者/旁观者立场
- **结构组织** — 标题编号习惯、开头/结尾模式、CTA 风格

分析结果沉淀为**风格档案**（`references/style-profile.md`），支持定量统计 + 定性提炼双通道，可人工校准。

### 2. 替身式创作

当你提供创作主题或素材时，技能以风格档案为基础进行创作：

- 严格遵循风格档案中的特征描述
- 模仿语调、节奏、用词习惯
- 保持句式结构和段落节奏一致
- 复用档案中记录的高频词汇和句式模板

目标是「替身写作」——读者看不出是 AI 写的。

### 3. 公众号 HTML 模板输出

公众号支持部分 HTML 标签，技能通过模板实现生动丰富的排版效果：

- 模板包含完整样式定义（配色、字体、间距）
- 使用 `{{占位符}}` 语法标记可填充位置（标题、作者、日期、正文段落、配图位置等）
- 创作完成自动填充，输出公众号后台可直接粘贴的 HTML


## 🚀 快速开始

### 第一步：搭建文章库

把你写过的公众号文章（Markdown 格式）放入 `article-library/` 目录。

文件名建议使用 `YYYY-MM-DD_平台_标题.md` 格式，例如：

```
2026-07-19_山观未来_OpenClaw小龙虾怎么就凉透了.md
```

### 第二步：学习风格

在 WorkBuddy 中对智能体说：

> 「分析我的写作风格」/「学习我的写作 DNA」

技能会扫描文章库，运行 `scripts/analyze_style.py` 做定量统计，再结合定性阅读生成风格档案。

也可以手动运行脚本：

```bash
python scripts/analyze_style.py article-library/ references/style-profile.md
```

### 第三步：替身写作

> 「用我的风格写一篇关于 XXX 的文章」

技能读取风格档案 → 按你的口吻创作 → 套用模板输出排版成品。

### 第四步：发布到公众号

将输出的 HTML 全选复制，粘贴到公众号后台编辑器即可。图片位置会标记为「此处插入配图」，上传替换即可。

## 📝 模板占位符说明

模板使用 `{{占位符名称}}` 语法，创作时自动填充：

| 占位符 | 填充内容 |
|--------|---------|
| `{{文章主标题}}` | 文章标题 |
| `{{作者}}` | 作者笔名 |
| `{{日期}}` | 发布日期 |
| `{{引导语内容}}` | 文章导语 |
| `{{二级标题}}` | 章节标题 |
| `{{正文段落内容}}` | 正文段落 |
| `{{引用内容}}` / `{{出处}}` | 引用块 |
| `{{二维码图片地址}}` | 关注二维码 |

自定义模板只需把 HTML 文件放入 `templates/` 目录，保留占位符即可被识别。

## 🧬 风格档案示例

仓库中的 [`references/style-profile.md`](references/style-profile.md) 是一份真实分析产出的风格档案示例（来自公众号「山观未来」主理人的 7 篇文章），包含：

- 风格定位、用词偏好、句式结构、段落节奏
- 语气语调、修辞手法、结构组织、叙事视角
- 写作禁忌清单、句式模板库
- 不同文章类型（分析/教程/测评）的风格变体说明

可作为你自己风格档案的参照格式。

## 💡 适用场景

- 公众号长期更新，想保持个人风格的一致性
- 用 AI 辅助初稿，但受不了「机器味」
- 系列文章（如工具测评、装修指南）需要统一语感
- 多平台分发，需要快速产出风格一致的内容

---

## ⚠️ 已知限制

- 风格分析基于文章样本，样本越多（建议 ≥5 篇）档案越准
- 定量脚本侧重统计特征，语气/观点类特征需结合定性分析
- 文章新增后需重新运行分析以更新档案
