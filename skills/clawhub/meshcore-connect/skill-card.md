## Description:

Connect an OpenClaw gateway to a MeshCore LoRa mesh node in minutes — install the maintained channel plugin (@fintlp/openclaw-meshcore), run the probe-first setup wizard, and verify the first DM over radio. Use when a user wants their AI agent reachable via MeshCore, off-grid messaging, or LoRa mesh comms.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and gateway operators use this skill to connect an OpenClaw agent to a MeshCore LoRa node for off-grid direct messaging, configure access safely, and verify that radio replies work.

## Known Risks and Mitigations:

Risk: Installing the recommended plugin adds third-party code to the gateway, and mesh conversations may expose gateway capabilities.

Mitigation: Keep pairing enabled, approve only trusted contacts, and limit the tools available to mesh conversations.
