# 🎧 Smart Playlist DJ

智慧情境播放列表 DJ — 根據時間、天氣、心情自動生成最佳歌單。

## 功能

- 🌤️ 天氣感知（wttr.in 即時天氣）
- ⏰ 時段分析（早晨/工作/傍晚/睡前）
- 🎵 智能評分（Genre + BPM + Rating）
- 🎧 macOS Music.app 整合

## 快速開始

```bash
python3 scripts/dj_main.py              # 自動偵測情境
python3 scripts/dj_main.py work        # 專注工作歌單
python3 scripts/dj_main.py morning     # 晨間喚醒
python3 scripts/music_player.py now     # 現在播放什麼
```
