## Description:

Provides a structured internship reflection workflow that helps users generate a tailored Markdown review template and refine it section by section using the STAR+L methodology.

This skill is ready for commercial/non-commercial use.

## Publisher:

[sylvie345](https://clawhub.ai/user/sylvie345)

### License/Terms of Use:

MIT

## Use Case:

Students, interns, and early-career professionals use this skill to turn internship notes, work logs, and memories into a structured reflection document for job applications, school reports, or personal records. The skill is especially oriented toward media, marketing, design, and general office internship roles.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Internship diaries, work logs, and note-system exports may contain personal information or employer-confidential material.

Mitigation: Share only the notes needed for the review and remove confidential or sensitive material before using the skill.

Risk: Template generation can write to a user-specified path and may overwrite existing notes if the destination is ambiguous.

Mitigation: Specify an exact output destination and confirm whether an existing file should be replaced before allowing file writes.

Risk: Reflection drafts may contain unsupported metrics or overstated claims if source notes are incomplete.

Mitigation: Keep only claims that can be backed by the user's records, use approximate ranges when appropriate, and avoid inventing performance data.
