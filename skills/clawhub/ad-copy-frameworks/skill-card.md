## Description:

Write ad copy that fits each platform. Eight copy frameworks (PAS, AIDA, BAB, FAB, 4U, objection-first, proof-first, offer-stack) with when to use each, the exact field lengths for Google, Microsoft, Meta, LinkedIn, TikTok, Pinterest, Reddit and X ads (including how CJK, emoji and links are counted), and how to write 15 distinct responsive search ad headlines.

This skill is ready for commercial/non-commercial use.

Marketers and copywriters use this skill to choose an ad copy framework and draft platform-specific advertising text. It helps fit copy to platform field limits and produce distinct responsive search ad headline variations.
