# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-18

### What's New

- ✨ Initial open-source release based on Gallup Q12 employee engagement framework
- ✨ Complete Q12 questionnaire with 12 original questions and management implications for each
- ✨ Four-level mountain model (Base Camp → Camp 1 → Camp 2 → Camp 3) with progressive engagement hierarchy
- ✨ Three survey versions: Standard (12Q), Lite (8Q), Focused (variable) for different scenarios
- ✨ Result interpretation engine with three-tier engagement classification (Engaged / Not Engaged / Actively Disengaged)
- ✨ High-risk combination detection: Q1+Q4+Q5, Q3+Q6+Q12, Q7+Q8, Q9+Q10
- ✨ Per-item improvement library with quick-win (1 week) and mid-term (1-3 months) actions
- ✨ 90-day structured improvement plan template with milestones and expected outcomes
- ✨ Global and regional benchmark data (Global 23%, Asia-Pacific 17%, China 17-18%)
- ✨ Bilingual support: English + Chinese
- ✨ Bilingual README (README.md + README_CN.md)
- ✨ Landing page with warm-paper design preset
