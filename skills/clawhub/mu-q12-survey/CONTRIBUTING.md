# Contributing to mu-q12-survey

Thank you for your interest in contributing! This project is a knowledge-based AI Prompt Skill built on the Gallup Q12 engagement framework. Here's how you can help.

## Ways to Contribute

- **Report issues** — Found a typo, inaccurate data, or unclear guidance? Open an issue.
- **Suggest improvements** — Have ideas for new survey versions, additional risk patterns, or better improvement actions? We'd love to hear them.
- **Translate** — Help improve the English or Chinese translations.
- **Share use cases** — Tell us how you used this skill with your team.

## How to Submit Changes

1. Fork the repository
2. Create a branch: `git checkout -b feature/your-feature-name`
3. Make your changes to `SKILL.md` or other files
4. Commit with a clear message: `git commit -m "Add: focus version for remote teams"`
5. Push: `git push origin feature/your-feature-name`
6. Open a Pull Request

## Content Guidelines

- All survey methodology must be traceable to Gallup's publicly available research
- Improvement actions must be specific and actionable (not generic advice like "communicate more")
- Benchmark data must cite the source year and report name
- No inducing or leading questions in survey design — options must always include negative feedback options
- Conclusions must be based on actual collected data, never fabricated

## Code of Conduct

Be respectful, constructive, and inclusive. We follow the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) code of conduct.
