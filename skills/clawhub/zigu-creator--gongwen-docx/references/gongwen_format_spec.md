# GB/T 9704-2012 党政机关公文格式规范摘要

> 本文件为公文格式核心规范摘要，生成公文时参考。

## 1. 适用范围

适用于各级党政机关制发的公文。其他机关、企事业单位可参照执行。

## 2. 版面要求

### 2.1 页边与版心尺寸
- 用纸：A4（210mm×297mm）
- 天头（上白边）：37mm±1mm
- 订口（左白边）：28mm±1mm
- 版心尺寸：156mm×225mm

### 2.2 字体和字号
- 如无特殊说明，公文各要素一般用3号仿宋体字
- 特定情况可适当调整

### 2.3 行数和字数
- 一般每面排22行
- 每行排28个字
- 撑满版心，特定情况可调整

### 2.4 文字颜色
- 如无特殊说明，公文中文字颜色均为黑色

## 3. 公文格式各要素

公文格式各要素分为版头、主体、版记三部分。本技能主要处理主体部分。

### 3.1 主体要素

#### 标题（7.3.1）
- 一般用2号小标宋体字
- 编排于红色分隔线下空二行位置
- 分一行或多行居中排布
- 回行时做到词意完整，排列对称，长短适宜，间距恰当
- 标题排列应使用梯形或菱形

#### 主送机关（7.3.2）
- 编排于标题下空一行位置
- 居左顶格，回行时仍顶格
- 最后一个机关名称后标全角冒号
- 如主送机关过多导致首页不能显示正文，应移至版记

#### 正文（7.3.3）
- 公文首页必须显示正文
- 一般用3号仿宋体字
- 编排于主送机关名称下一行
- 每个自然段左空二字，回行顶格
- 文中结构层次序数依次用：
  - 第一层："一、"（黑体字）
  - 第二层："（一）"（楷体字）
  - 第三层："1."（仿宋体字）
  - 第四层："（1）"（仿宋体字）

#### 附件说明（7.3.4）
- 如有附件，在正文下空一行左空二字编排"附件"二字
- 后标全角冒号和附件名称
- 多个附件用阿拉伯数字标注顺序号（如"附件：1.×××××"）
- 附件名称后不加标点符号
- 附件名称较长需回行时，与上一行首字对齐

## 5. 行距说明

公文标准行距为固定值。每面22行，每行28字，版心高度225mm。

- 225mm ÷ 22行 ≈ 10.23mm/行
- 10.23mm ≈ 29pt（1pt = 0.3528mm）
- 因此行距固定值设为29pt

## 6. 常见字体替代方案

| 标准字体 | Windows自带 | 替代方案 |
|---------|------------|---------|
| 方正小标宋简体 | 否 | 宋体加粗（本脚本默认） |
| 仿宋_GB2312 | 否 | 仿宋（simfang.ttf） |
| 楷体_GB2312 | 否 | 楷体（simkai.ttf） |
| 黑体 | 是 | 黑体（simhei.ttf） |

如需严格对标标准字体，可下载安装：
- 方正小标宋简体（公文标题专用）
- 仿宋_GB2312
- 楷体_GB2312

## 7. 注意事项

1. **首页必须显示正文** — 标题不可过长占满首页
2. **层次序数严格按序** — 不可跳级，不可混用（如"一、"后直接跳"1."）
3. **数字使用** — 公文中的数字除部分约定俗成外，一般用阿拉伯数字
4. **标点符号** — 使用全角标点
5. **附件名称后不加标点** — 这是常见错误点
