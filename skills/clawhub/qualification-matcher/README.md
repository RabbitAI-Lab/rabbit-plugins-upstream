# 标书资质匹配系统 v21.0 用户手册

## 1. 系统简介
本工具专为招投标场景设计，能够自动解析招标文件中的资质要求，并与企业自有资质库进行智能匹配，快速生成评分明细表，大幅减少人工核对工作量。

## 2. 运行环境
- 操作系统：Windows 7 / 10 / 11（64位）
- 无需安装 Python 或其他依赖，直接运行提供的 EXE 文件即可。
- 需要联网（调用阿里云大模型 API）。

## 3. 安装与首次配置
### 3.1 获取程序
将整个 `资质匹配系统Skill` 文件夹复制到本地任意目录（建议路径不含中文、空格）。

### 3.2 准备资质库
1. 进入 `template` 文件夹，将 `资质库_模板.xlsx` 复制到上一层目录（与 `资质匹配系统.exe` 同级）。
2. 重命名为 `资质库.xlsx`。
3. 用 Excel 打开该文件，在“资质矩阵”工作表的第一行空白处填入贵公司的名称（可多列，每列一个公司）。
4. 在对应的资质行和公司列交叉格中填写：
   - `有`：表示具备该资质，但未分级。
   - 具体等级：如 `一级`、`二级`、`甲级`、`CMMI三级` 等（需与“等级方向说明”中的定义一致）。
5. 保存并关闭 Excel。

> **注意**：模板中已内置行业常见资质名称、等级方向说明、别名，您只需填充公司持有情况，无需重新录入资质名称。也可以根据实际情况进行增删

### 3.3 获取 API Key
1. 访问 [阿里云 DashScope 控制台](https://dashscope.console.aliyun.com/)。
2. 开通模型服务（免费额度足够日常使用），创建 API Key。
3. 复制生成的 Key，后续填入程序设置。

### 3.4 启动程序
双击 `资质匹配系统.exe`，程序界面将出现。

### 3.5 配置程序
- 点击右上角 **⚙️ 设置**，填写您的 API Key。
- 确认其他选项（默认已开启全部智能匹配功能，推荐保持默认）。
- 点击“保存”。

### 3.6 准备招标文件
将需要分析的招标文件（支持 `.docx`、`.pdf`、`.xlsx`）放入程序自动创建的 `招标文件` 文件夹中，也可在程序内通过“浏览”任意选择。

## 4. 使用流程
1. 在程序主界面，点击 **1. 选择招标文件**，选择目标标书。
2. 在 **2. 参评公司** 区域勾选要评估的公司（默认全选）。
3. 点击 **▶ 开始分析**。
4. 等待分析完成（视标书长度和网络情况，通常 30 秒 ~ 3 分钟）。
5. 结果将保存到 `输出结果` 文件夹，Excel 文件名为 `评分结果_年月日_时分秒.xlsx`。

## 5. 结果解读
输出 Excel 包含两个工作表：
- **资质匹配明细**：每条规则一行，每家公司两列（匹配资质、得分），最后一列为备注（如有存疑会注明）。
- **得分排名**：各公司总分及排名。

备注中可能出现的关键信息：
- `[大模型判断]`：该项匹配由 AI 辅助决策，建议人工复核。
- `未注明具体等级，仅“有”`：资质库中该资质未填写具体级别，系统已按最优情况计分，需确认。
- `置信度中等，存疑`：匹配结果可能存在偏差，请检查。

## 6. 高级功能
- **智能提取**：若招标文件是纯文本 PDF/Word 且无表格，程序会自动调用大模型提取评分规则。
- **规则增强**：开启后会自动补全标准编号缩写（如 ISO9001 → 质量管理体系认证）。
- **语义检索**：基于 Embedding 向量匹配，可识别同义描述（如“等保”匹配“网络安全等级保护”）。
- **刷新公司列表**：修改资质库后，点击 **🔄 刷新公司列表** 无需重启程序。

## 7. 常见问题
**Q：双击 EXE 没有反应或报错？**  
A：请检查是否被杀毒软件拦截，尝试添加信任；确保文件路径不含中文或特殊字符；确认已安装 VC++ 运行库（大多数系统已有）。

**Q：提示“未找到资质库文件”？**  
A：请按步骤 3.2 正确放置 `资质库.xlsx`。

**Q：分析时提示 API 错误或限流？**  
A：阿里云免费 API 有调用频率限制，可稍后重试；或检查 API Key 是否有效。

**Q：匹配结果不准确怎么办？**  
A：可在资质库的“资质别名”Sheet 中添加更多同义词映射，或调整设置中的“语义相似度阈值”。

**Q：想用自己的完整资质库替换模板？**  
A：可以，只需保证 Excel 包含 `资质矩阵`、`等级方向说明`、`资质别名` 三个 Sheet，且格式与模板一致。

**Q：是否可以离线使用？**  
A：不可以，匹配和提取依赖云端大模型，必须联网。
