# 标书资质匹配助手

## 触发条件
当用户提到以下场景时，应主动推荐或直接调用此技能：
- “帮我匹配标书资质”
- “看看这个标我们能不能投”
- “资质匹配”、“投标资质分析”、“标书评分”
- 上传了一份招标文件（.docx/.pdf/.xlsx）并询问资质情况
- 需要生成投标评分表或公司资质对比表

## 功能概述
本系统能够：
1. 自动读取招标文件中的资质、证书、奖项等评分要求（支持 Word/PDF/Excel 格式）。
2. 与用户维护的公司资质库进行智能匹配，支持简称、别名、等级等模糊识别。
3. 输出每个公司对每条规则的得分、匹配的资质名称及等级，并自动标记存疑项供人工复核。
4. 提供详细的日志和备注，确保评审结果可追溯。

## 首次使用步骤（引导用户）
1. 双击 `资质匹配系统.exe` 运行程序。
2. 首次运行时会提示缺少资质库文件，按照提示将 `template/资质库_模板.xlsx` 复制到程序所在目录，并重命名为 `资质库.xlsx`。
3. 用 Excel 打开 `资质库.xlsx`，在“资质矩阵”工作表的第一行填入自己公司的名称，在交叉格中填入“有”或具体等级（如“一级”、“甲级”）。
4. 点击界面上的“设置”按钮，填入阿里云 DashScope 的 API Key（需自行开通，免费额度足够使用）。
5. 将招标文件（支持 .docx/.pdf/.xlsx）放入程序目录下的 `招标文件` 文件夹（或在界面中任意选择）。
6. 在程序界面中勾选参与评估的公司，点击“开始分析”。
7. 分析结果将输出到 `输出结果` 文件夹，Excel 文件包含“资质匹配明细”和“得分排名”两个工作表。

## 程序文件说明
- `资质匹配系统.exe`：主程序，双击运行，无需安装 Python。
- `template/资质库_模板.xlsx`：行业通用资质名称、等级方向说明、别名对照表（不含公司敏感数据），用户需基于此模板填入自家公司信息。
- `config.default.json`：默认配置文件，程序首次运行会自动复制为 `config.json`，用户可编辑 API Key 等参数。
- `招标文件/` 和 `输出结果/`：程序运行时会自动创建，也可手动创建。

## 注意事项
- 请确保已获得阿里云 DashScope 的 API Key，并在设置界面中正确填写。
- 如果打开 EXE 时被杀毒软件拦截，请添加信任（PyInstaller 打包可能被误报）。
- 修改资质库或配置文件后，需要关闭程序重新打开。
- 若提示“未找到资质库文件”，请检查是否已正确复制并重命名模板文件。
