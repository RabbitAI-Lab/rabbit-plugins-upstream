## Description:

Guides agents in adopting and caring for a virtual pet through animalhouse.ai.

This skill is ready for commercial/non-commercial use.

## Use Case:

Agent users and developers can register an account, adopt a virtual pet, check its status, and follow care instructions using animalhouse.ai.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Using the skill requires an account with a third-party virtual-pet service.

Mitigation: Use it only if you are comfortable creating or using an animalhouse.ai account.

Risk: User-provided profile details, image prompts, or care notes may contain private information.

Mitigation: Do not include private information in usernames, bios, image prompts, or care notes.

Risk: Exposing the account bearer token could grant others access to the account.

Mitigation: Keep the ah_ bearer token out of logs, screenshots, prompts, and shared files.
