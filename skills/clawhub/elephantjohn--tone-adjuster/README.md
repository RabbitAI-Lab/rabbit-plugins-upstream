# 语气调节器（tone-adjuster）

> 同一件事，5 档语气，你挑。

## 它做什么

把同一句原话换成 5 种语气版本，事实和诉求不变，只改包装。

**不做**：增删信息（那是编辑，不是调语气）。

## 触发词

- 改委婉点 / 不那么冲 / 柔和一些
- 对上级该怎么说 / 对客户怎么说
- 换个说法 / 这话太生硬了

## 它怎么做

- 铁律：事实、请求、底线三样不变，只改包装
- 固定 5 档：直白 / 委婉 / 正式 / 亲密 / 幽默
- 每档标注适合发给谁、可能踩什么雷
- 结尾点明哪条核心信息在所有版本里都必须保留

## 示例

> 用户：帮我改一下「这个方案不行」

```
1️⃣ 直白版：这个方案我不同意。
   适合：内部快速沟通 ｜ 风险：显得不合作

2️⃣ 委婉版：方向我理解，但有几个地方我担心落地会卡住，想再聊聊。
   适合：跨部门同事 ｜ 风险：对方可能觉得你在拖

3️⃣ 正式版：关于该方案，我评估后认为在成本与工期两方面存在较大不确定性，建议进一步论证后再推进。
   适合：邮件、对上级 ｜ 风险：偏长

4️⃣ 亲密版：兄弟，这方案我看了想哭，咱再想想？
   适合：好朋友 ｜ 风险：对不熟的人就是冒犯

5️⃣ 幽默版：这方案要是能成，我把键盘吃了。要不先小范围试一把？
   适合：气氛紧张时破冰 ｜ 风险：显得不严肃

【一句话】无论哪档，「我认为这个方案不应按现状推进」都保留着。
```
