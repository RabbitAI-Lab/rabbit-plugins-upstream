# bid-doc-interpreter · 招标文件解读

按 7 大模块（项目基本信息、资格性审查、符合性审查、商务要求、技术要求、废标项、评标办法与评分标准）+ 倾向性与排他性审查，对招标文件做结构化拆解与信息提取，输出标准化表格（含原文位置列）+ 要点清单 + 风险提示。

## 触发方式
上传招标文件（PDF/DOCX/图片/多文件）并说"解读/拆解/分析招标文件""标书解读""招标文件要点梳理""看看这个标有什么坑"等。

## 范围
- ✅ 做：信息提取、结构化整理、原文条款定位、踩坑/倾向性风险提示、评分标准解读。
- ❌ 不做：投标报价计算、投标文件编制、合同审查、评分模拟/中标概率预测、质疑函/投诉书撰写、合法性鉴定、竞争对手分析（遇此类请求会礼貌引导至对应技能）。

## 关键能力
- 防幻觉铁律：关键条款强制标原文位置（页码/章节），无法定位即标"原文检索未定位"。
- 长文档分块：>100 页按优先级分模块逐步解读，附"解读完整度声明"。
- 异常健壮：非招标文件/加密/公告/补遗/非中文/信息冲突等 9 类边界有明确处理。
- 项目类型适配（工程/货物/服务/信息化）、偏离应对策略、时间充裕度评估。

## 使用说明
1. 上传文件后直接说明需求即可；可指定 `focus_modules` / `project_type` / `output_depth`。
2. 可要求深挖某模块、修正偏差、多文件横向对比、导出 Markdown。
