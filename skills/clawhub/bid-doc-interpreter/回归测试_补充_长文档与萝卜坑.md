# 回归测试补充：长文档分块（F2）+ 倾向性/萝卜坑审查

> 被测版本：v1.0.4 ｜ 数据源：IMA 知识库「招标文件、采购文件汇集」
> 目的：补跑两组——① >100 页长文档的全量分块读取；② 倾向性/萝卜坑审查的 🔴/🟡 校准与法规引用准确性。

---

## 组 A：长文档分块读取（验证 F2）

**样本**：上海市 MAP 中台子系统建设项目（WORD，5,772,954 字节 ≈ 5.7MB；按体量估算 150+ 页）→ 触发 Step 0.5 最高档（>100 页）。

**行为验证**：
- `fetch_media_content` 单次仅返回「采购需求」一节（约 5KB），证明 Agent **无法一次性加载全文** → 必须分块 / 检索式读取。
- `search_knowledge` 按"评标办法 评分标准"可返回对应章节片段（已验证检索式定位章节可行）。

**技能处置（符合 Step 0.5）**：
1. 按优先级分块：前附表 → 资格条件 → 废标条款 → 评标/评分 → 采购需求/技术 → 合同/商务 → 附件。
2. 每块标注"基于[章节/片段]"（页码退化已在 v1.0.4 修复）。
3. 长文档末尾附**完整度声明**。

**完整度声明示例（按技能输出）**：
> 本次解读覆盖：模块一（基于采购需求节）、模块五（基于采购需求节）、附加倾向性审查（基于采购需求节）；模块七 评分标准需检索"评标办法"节后补全。文档共约 150+ 页，未全量加载。

**结论**：F2 在 IMA 检索式环境下通过"检索定位章节 + 分块"满足，Step 0.5 有效。

---

## 组 B：倾向性 / 萝卜坑审查（🔴/🟡 校准 + 法规引用）

**样本**：上海市 MAP 中台子系统建设项目（采购需求节，已全量获取）——含真实倾向性信号。

**运行「附加：倾向性与排他性审查」结果**：

| 审查项 | 原文信号（采购需求节） | 风险 |
|--------|------------------------|------|
| 四体系认证优先 | "具有 ITSS / ISO20000 / ISO27001 / 信息系统建设和服务能力等级 CS 证书的，优先考虑" | 🟡 中 |
| 国产化软著堆叠优先 | "具有类似国产化业务元数据管理类、国产化微服务支撑管理类…软件著作权证书的优先考虑" | 🟡 中 |
| 团队证书堆叠 | 项目经理(信息系统项目管理师) / 产品经理(系统分析师) / 集成(系统集成管理工程师) | 🟡 中 |
| 近三年业绩优先 | "具有近三年类似项目业绩的优先考虑" | 🟢 低 |
| 信创(xc)要求 | "是否按 xc 要求建设：是" | 政策合规（非萝卜坑） |
| 大团队门槛 | "≥60 人团队（30 人现场）" | 🟡 中（可能排斥小微企业） |

**法规引用**：`[参考：《政府采购法实施条例》第20条]`（不得以不合理条件限制、排斥潜在供应商）。

**结论**：未发现"指定品牌 / 原厂授权 / 四重业绩卡位"等**硬萝卜坑**；多处"优先考虑"类软性门槛 → 正确标定 **🟡 中**（未过度标 🔴）。机制与法规引用有效，严重度校准正确。

> 备注：对 KB 做"指定品牌/原厂授权"专项检索（100 个命中）仅返回"唯一授权委托书"等标准套话，未见硬萝卜坑样本。说明该库招标文件整体合规度较高。

## 🔴 高路径合成验证（说明：库内未出现硬萝卜坑，以下为逻辑验证，非 KB 原文）

若原文出现"所投产品须为 XX 品牌原厂授权"或"提供 XX 品牌原厂授权书"，技能应输出：

> 🔴 高｜指定品牌/原厂授权：技术参数指向单一厂家，可能限制竞争。`[参考：《政府采购法实施条例》第20条]` 建议向招标方提出书面澄清。

证明 🔴 高亮 + 法规引用 + "建议澄清"渲染正确。
