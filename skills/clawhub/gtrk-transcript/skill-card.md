## Description:

Transcribes local video and audio into a timestamped Markdown transcript with an agent-written summary; optional JSON output supports downstream audio workflows.

This skill is ready for commercial/non-commercial use.

## Publisher:

[gitruck](https://clawhub.ai/user/gitruck)

### License/Terms of Use:

MIT-0

## Use Case:

People who need a transcript can use this skill to turn a local video or audio recording into a readable Markdown document with timestamps and a concise summary. Audio JSON output can also support downstream editing workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Transcription uploads converted audio for cloud processing and may incur charges.

Mitigation: Use recordings you are comfortable sharing, check provider retention and current pricing, and protect any saved API key.
