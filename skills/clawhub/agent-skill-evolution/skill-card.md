## Description:

Use when evolving OpenClaw skills from static to adaptive, self-improving, agentic capabilities with benchmarking, red-teaming, regression protection, and continuous evolution loops.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to assess, evolve, test, and safely roll back OpenClaw skill changes across benchmarking, red-teaming, regression checks, maturity assessment, and capability gap analysis.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Open-ended continuous evolution language can encourage unattended skill changes.

Mitigation: Run the skill only under active supervision and require explicit user approval before modifying or deploying skills.

Risk: Skill updates can introduce regressions, misleading guidance, or unsafe behavior.

Mitigation: Use rollback copies, benchmark before and after changes, red-team candidates, and scan updated skills before deployment.

Risk: Long-running improvement loops can exceed the intended scope of a release task.

Mitigation: Set per-run limits, define the target skill and acceptance criteria upfront, and stop after the approved validation cycle.
