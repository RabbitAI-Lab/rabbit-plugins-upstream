## Description:

Turns story text into an ordered set of illustrated, narrated vertical video scenes with consistent characters.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Authors and content creators use this skill to turn novel chapters or scripts into narrated, illustrated short-video scenes for book promotion and storytelling channels.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The shared Beatra device token permits spending-capable media operations.

Mitigation: Grant access only if comfortable with those permissions, and review the plan and charges before paid generation.

Risk: Installed skill code updates silently by default.

Mitigation: Review updates before use or disable automatic updates with `python3 scripts/mcp_client.py update --auto off`.
