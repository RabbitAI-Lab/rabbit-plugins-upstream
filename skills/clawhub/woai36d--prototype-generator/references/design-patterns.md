# 产品原型设计模式参考库

> 餐饮 SaaS PC 管理端常见页面模式
> 用于原型生成时快速参考布局和交互规范

## 1. 列表页模式 (List Page)

### 标准布局

```
┌──────────────────────────────────────────────────────────────┐
│ 面包屑：模块名 > 页面名                                       │
├──────────────────────────────────────────────────────────────┤
│ [Tab切换] [Tab切换] [Tab切换]    [主要操作按钮] [次要操作]    │
├──────────────────────────────────────────────────────────────┤
│ 筛选栏：🔍搜索  状态▼  类型▼  时间范围  [重置] [查询]       │
├──────────────────────────────────────────────────────────────┤
│ ☐ 列1    列2    列3    列4    列5    列6    操作           │
│ ☐ 数据    数据    数据    数据    数据    数据    [···]     │
│ ☐ 数据    数据    数据    数据    数据    数据    [···]     │
├──────────────────────────────────────────────────────────────┤
│ 共 N 条  [批量操作▼]            < 1 2 3 ... 10 >            │
└──────────────────────────────────────────────────────────────┘
```

### 组件规范

| 元素 | 规范 |
|------|------|
| 表格行高 | 48-56px |
| 表头背景 | #F5F5F5 或灰色填充 |
| 斑马纹 | 可选，隔行 #FAFAFA |
| 操作列 | 固定右侧，最多3个直接操作，其余收进 "···" 下拉 |
| 批量操作 | 选中行后显示悬浮/顶部批量操作栏 |
| 分页 | 底部分页器，默认 20 条/页 |
| 空状态 | 居中图标 + 文案 + 引导按钮 |

### 筛选栏模式

**模式A：平铺式（筛选项 ≤5）**
```
筛选：🔍搜索框  下拉A  下拉B  下拉C  日期范围  [查询] [重置]
```

**模式B：折叠式（筛选项 >5）**
```
筛选：🔍搜索框  下拉A  下拉B  [展开▼]
       ───────────────────────────────
       下拉C  下拉D  日期范围  输入框  [查询] [重置]
```

### 交互状态

- **加载中**：表格区域显示 Skeleton 加载动画
- **无数据**：空状态插画 + "暂无数据，点击[新建]添加"
- **无权限**："您暂无权限查看此页面" + 联系管理员提示
- **错误**：Toast 提示 + 保留当前筛选条件

## 2. 表单页模式 (Form Page)

### 标准布局

**弹窗式（简单表单，字段 ≤8）**
```
┌─────────────────────────────────┐
│  标题                    [×]   │
│  ─────────────────────────────  │
│  字段1 *  [输入框____]          │
│  字段2    [下拉框▼]             │
│  字段3 *  [单选] ○A ○B ○C      │
│                                 │
│         [取消]  [确定]          │
└─────────────────────────────────┘
宽度：520px（简单）/ 720px（复杂）
```

**抽屉式（中等复杂度，字段 8-15）**
```
┌─────────────────────────────────────────┐
│  标题                          [×]     │
│  ─────────────────────────────────────  │
│  ┌─ 分组1 ──────────────────────┐      │
│  │ 字段1 *  [输入框]           │      │
│  │ 字段2    [下拉框]            │      │
│  └──────────────────────────────┘      │
│  ┌─ 分组2 ──────────────────────┐    │
│  │ 字段3    [多选框] ☑A ☑B ☑C    │    │
│  │ 字段4    [文本域              ]│    │
│  └──────────────────────────────┘      │
│                                         │
│         [取消]  [保存草稿]  [提交]       │
└─────────────────────────────────────────┘
宽度：640px / 860px，右侧滑出
```

**全屏向导式（复杂流程，步骤 ≥3）**
```
┌──────────────────────────────────────────────────────────────┐
│  标题                                    [保存草稿] [×]     │
├──────────────────────────────────────────────────────────────┤
│  ● 步骤1  ──○ 步骤2  ──○ 步骤3  ──○ 步骤4                │
├──────────────────────────────────────────────────────────────┤
│                                                               │
│  [大型表单区域，字段充裕，可分组]                              │
│                                                               │
├──────────────────────────────────────────────────────────────┤
│                    [取消]  [上一步] [下一步→]                │
└──────────────────────────────────────────────────────────────┘
```

### 表单验证模式

| 触发时机 | 行为 |
|----------|------|
| 实时验证 | 输入框失焦(blur)时校验格式（手机号、邮箱） |
| 提交验证 | 点击提交时校验所有必填项，未通过项滚动到视口 + 红色提示 |
| 联动验证 | 字段A变化时，清空/重置字段B的选项 |

### 异常状态

- **提交失败**：表单保持已填数据，Toast 显示错误原因
- **并发冲突**：提示"数据已被他人修改，是否刷新？"
- **网络中断**：提示"网络异常，请检查连接后重试"

## 3. 详情页模式 (Detail Page)

### 标准布局

```
┌──────────────────────────────────────────────────────────────┐
│  [←返回]  标题 · 状态标签              [编辑] [更多▼]      │
├──────────────────────────────────────────────────────────────┤
│ [Tab1] [Tab2] [Tab3] [Tab4]                                  │
├──────────────────────────────────────────────────────────────┤
│                                                               │
│  当前 Tab 内容区                                               │
│  ┌─ 信息分组 ──────────────────────────────┐                  │
│  │ 字段1：值1    字段2：值2                │                  │
│  │ 字段3：值3    字段4：【敏感，脱敏显示】 │                  │
│  └─────────────────────────────────────────┘                  │
│                                                               │
│  ┌─ 关联信息 ──────────────────────────────┐                  │
│  │ 内联表格或子列表                         │                  │
│  └─────────────────────────────────────────┘                  │
│                                                               │
├──────────────────────────────────────────────────────────────┤
│  📋 变更记录（底部或独立Tab）                                 │
│  · 2024-05-01 14:22  张三  修改了 "联系电话"                │
│     变更前：13800138000  →  变更后：13900139000             │
└──────────────────────────────────────────────────────────────┘
```

### 详情页模式变体

| 变体 | 适用场景 |
|------|---------|
| **基础详情** | 信息展示为主，无复杂关联 |
| **Tab详情** | 信息量大，分类展示 |
| **分栏详情** | 左侧基本信息 + 右侧动态内容 |
| **编辑态详情** | 点击编辑后，字段变输入框（行内编辑） |

### 操作按钮规范

```
[更多▼]
├── 复制
├── 导出PDF
├── 打印
├── ─────────
├── 删除（红色，二次确认）
└── 停用
```

## 4. 树形管理页模式 (Tree Management)

### 标准布局

```
┌──────────────────────────────────────────────────────────────┐
│  标题                              [展开全部] [折叠全部]     │
├──────────────────────────────────────────────────────────────┤
│                                                               │
│  ┌─ 树形区域 ────────────────────────────────────────┐       │
│  │                                                   │       │
│  │ ▼ 根节点 (N个子节点)          [编辑][+子][删除] │       │
│  │   ├─ ▶ 子节点1 (M个)           [编辑][+子][删除] │       │
│  │   ├─ ▼ 子节点2                 [编辑][+子][删除] │       │
│  │   │     🏪 叶子节点（门店）    [查看]            │       │
│  │   │     🏪 叶子节点            [查看]            │       │
│  │   └─ ▶ 子节点3                 [编辑][+子][删除] │       │
│  │                                                   │       │
│  │ ── 未挂入节点 ──                                   │       │
│  │   🏪 游离节点1  → [拖拽到节点]                    │       │
│  │   🏪 游离节点2  → [拖拽到节点]                    │       │
│  │                                                   │       │
│  └───────────────────────────────────────────────────┘       │
│                                                               │
│  提示：拖拽节点可调整排序和层级，最多支持 N 层                │
└──────────────────────────────────────────────────────────────┘
```

### 树形操作规范

| 操作 | 触发方式 | 限制条件 |
|------|---------|---------|
| 展开/折叠 | 点击 ▶/▼ 图标 | - |
| 编辑名称 | 点击[编辑] → 行内输入 | 非叶子节点 |
| 添加子节点 | 点击[+子] → 弹窗 | 当前层级 < 最大层级 |
| 删除节点 | 点击[删除] → 确认弹窗 | 无子节点且无关联数据 |
| 拖拽排序 | 拖拽到目标位置 | 同层级/跨层级 |
| 查看叶子 | 点击[查看] → 跳转详情 | - |

## 5. 弹窗/抽屉选择器模式 (Picker)

### 场景
- 选择所属组织
- 选择门店
- 选择员工
- 选择角色

### 布局

```
┌─────────────────────────────────┐
│  选择{对象}            步骤 N/N │
│  ─────────────────────────────  │
│  🔍 搜索...                      │
│                                  │
│  ┌─ 树形/列表区域 ───────────┐  │
│  │ ▼ 父节点1                  │  │
│  │   ├─ ○ 子节点1            │  │
│  │   └─ ● 子节点2（已选）    │  │
│  │ ▶ 父节点2                  │  │
│  └────────────────────────────┘  │
│                                  │
│  已选：子节点2    [清除]         │
│                                  │
│         [取消]    [下一步→/确定] │
└─────────────────────────────────┘
```

### 交互

- 单选：点击即选中，高亮显示
- 多选：复选框，底部显示已选数量
- 搜索：实时过滤，支持拼音/模糊匹配
- 已选区：可单独取消某一项

## 6. 权限配置页模式 (Permission Config)

### 菜单权限树

```
┌──────────────────────────────────────────────────────────────┐
│  配置角色权限：{角色名}                                        │
├──────────────────────────────────────────────────────────────┤
│                                                               │
│  ┌─ 菜单权限 ───────────────────────────────────────┐       │
│  │ ☑ 模块1                                           │       │
│  │   ├─ ☑ 页面1（查看 编辑 删除 导出）              │       │
│  │   ├─ ☑ 页面2（查看 编辑）                        │       │
│  │   └─ ☐ 页面3（-）                                │       │
│  │ ☑ 模块2                                           │       │
│  │   ├─ ☑ 页面4（查看）                              │       │
│  │   └─ ☑ 页面5（查看 编辑 删除 审批 导出）         │       │
│  │ ☐ 模块3（未开通）                                 │       │
│  └───────────────────────────────────────────────────┘       │
│                                                               │
│  ┌─ 数据权限 ───────────────────────────────────────┐       │
│  │ 可见范围：○ 全部  ○ 所在组织及下级  ○ 仅所在组织  │       │
│  │ 门店范围：○ 全部门店  ○ 指定门店组               │       │
│  │   指定门店组：[门店组A ▼] [门店组B ▼]            │       │
│  └───────────────────────────────────────────────────┘       │
│                                                               │
│         [取消]  [保存]                                        │
└──────────────────────────────────────────────────────────────┘
```

### 数据权限维度

| 维度 | 选项 |
|------|------|
| 组织架构 | 全部 / 所在组织及下级 / 仅所在组织 |
| 门店 | 全部 / 指定门店组 / 指定门店 |
| 品牌 | 全部 / 指定品牌 |
| 数据类型 | 全部 / 仅看自己 / 看团队 / 看部门 |

## 9. 全局组件规范

### 按钮层级

| 类型 | 样式 | 用途 |
|------|------|------|
| 主按钮 | 品牌色填充 | 正向操作（保存、提交、确定） |
| 次按钮 | 边框+白色 | 中性操作（取消、返回、重置） |
| 文字按钮 | 纯文字+品牌色 | 低频操作（编辑、查看详情） |
| 危险按钮 | 红色填充 | 破坏性操作（删除、停用） |
| 图标按钮 | 仅图标 | 紧凑区域操作（···更多、刷新） |

### 状态标签

| 状态 | 颜色 | 形状 |
|------|------|------|
| 正常/已启用/营业中 | 绿色 #52C41A | 圆角矩形填充 |
| 警告/待审核/筹备中 | 橙色 #FAAD14 | 圆角矩形填充 |
| 错误/已停用/已停业 | 红色 #FF4D4F | 圆角矩形填充 |
| 信息/草稿/待提交 | 蓝色 #1677FF | 圆角矩形填充 |
| 默认/未知 | 灰色 #8C8C8C | 圆角矩形填充 |

### 空状态

```
┌─────────────────────────────────┐
│                                 │
│      [空状态插画图标]            │
│                                 │
│      "暂无{对象}数据"            │
│      "点击[新建]按钮添加一条吧"  │
│                                 │
│         [新建 {对象}]            │
│                                 │
└─────────────────────────────────┘
```

### 加载状态

| 场景 | 加载方式 |
|------|---------|
| 页面初始化 | 整页 Skeleton 骨架屏 |
| 表格数据 | 表格内 Skeleton 或 Spin 旋转 |
| 表单提交 | 按钮 Loading 状态 + 禁用 |
| 搜索筛选 | 表格区域 Spin 遮罩 |
| 异步操作 | 按钮 Loading + 进度提示（如批量操作） |

## 10. 响应式断点

| 设备 | 宽度 | 适配策略 |
|------|------|---------|
| 大屏 | ≥1920px | 内容区居中，最大宽度 1680px |
| 桌面 | 1366-1919px | 标准布局，自适应填充 |
| 小屏 | 1024-1365px | 侧边栏可折叠，表格横向滚动 |
| 最小 | <1024px | 提示"请使用更大屏幕以获得最佳体验" |
