## Description: <br>
Prototype Generator helps create and validate product prototype specifications from PRD documents, competitor screenshots, and optional API documentation. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[woai36d](https://clawhub.ai/user/woai36d) <br>

### License/Terms of Use: <br>

## Use Case: <br>
Product managers, designers, and developers use this skill to turn PRDs, screenshot folders, and optional API docs into Markdown prototype documents with page structures, flows, UI behavior, exception states, and validation checklists. <br>
