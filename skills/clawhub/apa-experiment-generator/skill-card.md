## Description:

Generates APA 7th edition Method sections for psychology experiment designs across cognitive, social, developmental, educational, clinical, and questionnaire-based paradigms.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zxw-wwwww](https://clawhub.ai/user/zxw-wwwww)

### License/Terms of Use:

MIT-0

## Use Case:

Students, researchers, and academic writers use this skill to draft structured Method sections for psychology papers or theses from a research question, selected paradigm, and variable design. It can optionally provide OpenSesame or PsychoPy-style Python loop logic when the user asks for experiment code.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated Method text may imply APA compliance, ethics approval, study-design validity, or statistical support that has not been independently verified.

Mitigation: Review generated text against the actual study protocol, institutional ethics requirements, APA guidance, and analysis plan before using it in coursework, theses, or publications.

Risk: Broad writing-related triggers could activate the skill in unrelated academic drafting contexts.

Mitigation: Narrow triggers or invoke the skill explicitly when accidental activation would create irrelevant or misleading Method-section content.
