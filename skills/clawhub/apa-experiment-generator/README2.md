# 全能心理学实验范式生成器 🧪

一个专为心理学高年级本科生、研究生及科研人员打造的 OpenClaw Skill。

## 🎯 一句话介绍
还在为 APA 格式头疼？还在为了 Method 部分怎么写发愁？本 Skill 能够根据你的实验构想，**一键生成符合 APA 第 7 版规范的论文 Method (方法) 章节**。

## ✨ 支持的范式库 (Coverage)

| 领域 | 支持范式 |
|---|---|
| **认知神经科学** | Stroop (色词/情绪), Go/No-Go, Oddball, 点探测 (Dot-Probe), Flanker, n-back, 任务切换 (Task Switching), Posner 线索靶子 |
| **社会心理学** | 内隐联想测验 (IAT), 启动范式 (Priming), Cyberball (网络掷球) |
| **发展与教育** | 昼夜 Stroop, 延迟满足 (棉花糖实验), 错误信念任务 (心理理论) |
| **临床与问卷** | 静息态 EEG/fMRI 数据处理描述, 量表信效度分析流程 |

## 🚀 使用方法

在聊天中输入触发词 `/写方法节`，并描述你的实验设计。

### 示例指令
> 帮我写一个关于手机依赖的 Go/No-Go 任务，被试内设计，按键反应。

> 生成一个 Stroop 实验的 APA 方法，并给我 OpenSesame 的代码结构。

> 我要写一篇关于社交焦虑的点探测 (Dot-Probe) 实验，帮我写方法部分。

## 📦 输出内容

- **被试 (Participants)**: 样本量估算与伦理描述。
- **设计与材料 (Design and Materials)**: 变量定义与刺激属性。
- **程序 (Procedure)**: 试次时间轴与实验流程。
- **数据分析 (Data Analysis)**: 剔除标准与统计方法。
- **代码 (Code)**: OpenSesame / PsychoPy 伪代码结构（可选）。
