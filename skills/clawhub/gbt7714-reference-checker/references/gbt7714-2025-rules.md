# 参考文献著录规则速查（依据 GB/T 7714—2025 整理）

> **关于本文件的说明（使用前请阅读）**
> 本文件依据《信息与文献 参考文献著录规则》（GB/T 7714—2025，2025-12-02 发布，2026-07-01 实施，代替 GB/T 7714—2015）整理，用于**自行编写的参考文献格式检查**。
> **本文件不包含标准原文，也不复现标准附录中的官方示例。** 文中所有示例均为便于理解著录格式而**自行编写**，重点演示各类型条目的要素构成与排列顺序；示例中的书名、刊名、出版年、页码等信息**仅用于演示格式结构，不代表对具体出版物信息的确认**，正式引用时请以实际出版物为准。
> GB/T 7714 系列标准受著作权保护，著作权归国家标准化管理委员会，专有出版权属标准出版单位。**如需依据标准原文核对，请通过正规渠道获取或在全国标准信息公共服务平台（openstd.samr.gov.cn）检索查阅。**
> 检查中遇到本文件未覆盖或无法确认的情形，应标记"存疑"并提示用户核对标准正式文本，不要臆断。

## 一、适用范围与核心概念

**适用**：本文件用于检查作者、编制者著录的参考文献表（论文、报告、投稿稿件的文末文献表）。

**核心概念**（用于识别文献类型）：

| 概念 | 要点 |
|---|---|
| 参考文献 | 位于文末或文中，用于识别、定位和检索信息资源的数据 |
| 电子资源 | 以数字方式存储、需通过计算机或网络使用的信息资源 |
| 连续出版物 | 分部分连续发行、有数字或年代标识、计划无限期发行的出版物（期刊、报纸等） |
| 析出文献 | 构成另一文献组成部分的文献（期刊文章、图书中的篇章、会议论文等） |
| 合订题名 | 无总题名的汇编文献中，各作品的题名 |
| 数据集 | 相关数据的逻辑集合（dataset） |
| 预印本 | 尚未通过同行评议但已公开使用的文稿（preprint） |
| 永久标识符 | 确保永久存取的唯一标识符（DOI、CSTR、URN 等） |
| 顺序编码制 | 正文用序号标注、文末表按序号排序的体系 |
| 著者-出版年制 | 正文用责任者+出版年标注、文末表按字顺+出版年排序的体系 |
| 责任者 | 对信息资源的创造、积累或保管负责的实体（个人、机关团体等） |

## 二、2025 版相对 2015 版的主要变化

1. **新增类型与标识**：档案 [A]、地图 [CM]、数据集 [DS/OL]、预印本 [PP/OL]；EB 由"电子公告"改为**网站、网页**；"普通图书"改称"图书"。
2. **术语调整**：新增"会议录""数据集""预印本""责任者""永久标识符"等。
3. **结构调整**：原"著录细则"改为"著录通则"；每种文献类型单列**著录项目与必备性**。
4. **日期术语**：改为"创建/发布或修改日期""引用日期"。
5. **电子资源要求强化**：URL 为必备；网页、数据集、预印本的 [引用日期] 必备。
6. **标引体系成章**：第 9 章完整规定顺序编码制与著者-出版年制的正文标注与文末表规则。

## 三、著录用符号

> 国标符号均为**前置符**。顺序编码制条目以方括号序号 [1][2]… 开头；著者-出版年制条目首项前**不用任何标识符号**。

| 符号 | 置于何项之前 | 演示 |
|---|---|---|
| `.` | 题名、其他责任者、版本、出版信息、年卷期、获取路径、永久标识符；条目结尾 | 黄仁宇. 万历十五年[M]. 北京：中华书局，2006：92. |
| `:` | 副题名、出版者、页码、学位授予单位、报告编号、专利申请号、档号 | …：92. |
| `,` | 同一著作方式的责任者之间、"等/译"字样前、出版年、年与卷号之间 | 于洋，刘晨，李默，等. …2018，44（6）：23-30. |
| `;` | 同一责任者的合订题名之间；同一期刊连载文献的后续年卷期页码之前 | 呐喊；彷徨…；2015，31（2）：20-25；2015，31（3）：26-30 |
| `//` | 析出文献的出处（所在专著、会议录） | 王力. …[M]//中国语言学会. … |
| `( )` | 期号、版次、创建或修改日期、非公元纪年出版年 | 2018，44（6）；1936（民国二十五年） |
| `[ ]` | 文献序号、类型与载体标识、引用日期、自拟信息（[出版地不详] 等） | [1]…；[2025-03-06] |
| `/` | 合期号/合卷号之间；文献载体标识前 | 2019（3/4）；[J/OL] |
| `-` | 起讫页码、起讫序号之间 | 23-30；[2-4] |

**标点层级（易错，须逐条核）**：
- **中文条目**：分隔用的逗号与冒号用全角（，：），著录句点用半角"."；**西文条目一律半角（, : .）**。同一条目内不得全半角混用。
- 期刊"年，卷（期）"结构：有卷号时 `2018，44（6）`；**无卷号时直接 `2013（1）`**，期号前不加逗号。

## 四、著录通则要点

### 1. 责任者

- **个人责任者姓前名后**：中文姓名照录；欧美责任者用西文著录时，姓全部著录、名缩写为首字母（如 `Einstein A`）；汉语拼音著录中国人名时，姓在前，**名宜用全称**（如 `Li Jiangning`）。
- **责任者数量**：同一著作方式的责任者不超过 3 个时全部照录；超过 3 个只著录前 3 个，其后加"，等"（中文）或 ", et al"（西文）。
- **无责任者**：著者-出版年制下该项注"佚名"（西文 `Anon`）；**顺序编码制下可省略责任者，直接著录题名**。
- **机关团体责任者**：按信息源著录；名称由上级到下级分级著录、级别间用"."（西文如 `Stanford University. Department of Civil Engineering`）；用汉字书写的机关名称直接著录全称。
- **译著**须标注译者：`题名. 译者，译.`

### 2. 题名

- 按信息源所载内容著录；无题名时可自拟，置于 [ ] 内。
- 同一责任者的**多个合订题名著录前 3 个**，之间用"；"；不同责任者的合订题名可只著录第一个。
- **不著录并列题名**（外文原题名不必并列著录）。
- 副题名/其他题名信息用"："与正题名分隔。

### 3. 类型标识与载体标识

- 电子资源**同时著录**文献类型标识与载体标识（如 [J/OL]、[M/OL]）。
- 标准类文献的 [S] 为可选项。

### 4. 版本

- 第 1 版可不著录；其他版本应著录（如 `3版`、`新1版`、`V1.0`、`5th ed`、`Rev. ed`）。
- 古籍版本按信息源客观照录（如"刻本""抄本""影印本"）。

### 5. 出版信息

- 顺序：**出版地 → 出版者 → 出版日期**。
- 出版地著录城市名；同名异地宜加省/州/国限定（如 `Cambridge, Mass.`）；多个出版地只著第一个。
- 无出版地：中文著录"[出版地不详]"，外文"[S.l.]"，电子资源可省略。无出版者：中文"[出版者不详]"，外文"[s.n.]"。
- 出版年用阿拉伯数字；其他纪年置于 ( ) 内。
- **期刊在线出版日期、报纸出版日期、报告发布日期、专利公告日期、档案形成日期用 YYYY-MM-DD 格式。**

### 6. 创建/发布或修改日期与引用日期

- 电子资源的创建、发布、修改与引用日期均用 YYYY-MM-DD，分别置于 ( ) 与 [ ] 内，形态为 `(创建或修改日期)[引用日期]`。
- 无创建/修改日期时圆括号部分可省略，但 **[引用日期] 必备**。

### 7. 页码

- 引文参考文献**必须著录引文页码**；页码前用"："。
- **无页码但有文章编号时，将文章编号按页码著录**。
- 引自序言、扉页等可按实际著录。

### 8. 获取路径与永久标识符

- URL 为电子资源必备，置于条目末尾、永久标识符之前。
- 永久标识符（DOI、CSTR 等）**有则必备**，置于条目最末；**URL 中已包含该标识符时不再重复著录**。

## 六、各类型著录要素与演示条目

> 通用要素顺序（顺序编码制）：`[序号] 责任者. 题名：副题名[类型/载体标识]. 其他责任者. 版本. 出版地：出版者，出版年：页码. URL. 永久标识符.`
> **以下演示条目均为自编，用于体现要素构成与顺序；文献信息请以实际出版物为准。**

必备：题名、[M]；责任者/版本/出版地/出版者/出版年/引文页码有则必备。

- 在线出版、尚未分配卷期页时，以**在线出版日期**替代卷期页位置：`责任者. 题名[J/OL]. 刊名，在线出版日期. URL.`

## 七、标引体系（第 9 章）

检查前先判定采用哪种体系，再核对对应规则；文末表须与正文标注体系一致。

### 7.1 顺序编码制

**正文标注**：
- 按引用出现先后**连续编码**，序号置于 [ ] 内。
- 同一处引用多篇：序号在 [ ] 内全部列出，间用"，"（如 [1,3]）；**连续序号用短横线**（如 [2-4]）。
- 多次引用同一文献：标注首次引用序号，**引文页码置于 [ ] 外**（如 [2]260、[4]15-16）。

**文末表**：按正文序号依次列出。

### 7.2 著者-出版年制

**正文标注**：
- 标注 = **责任者姓氏 + 出版年**，置于 ( ) 内，如 (Crane, 1972)、(张忠智，1997)；正文已提及责任者时只标出版年。
- 多责任者：欧美文献标第一责任者姓 + "et al."；中国文献标第一责任者 + "等"。
- 同一责任者同年多篇：出版年后加 a、b、c 区分。
- 多次引用同一文献：**引文页码以角标注于 ( ) 外**。

**文末表**：
- 条目以责任者开头、**出版年紧随其后**（如"尼葛洛庞帝，1996. 数字化生存[M]. …"），**首项前不使用任何标识符号**。
- 排序：先按**文种集中**（中文、日文、西文、俄文、其他），再按**责任者字顺 + 出版年**；中文可按汉语拼音或笔画排列。
- 同责任者同年多篇以 a、b、c 排序。

## 八、常见错误清单（检查重点）

| # | 常见错误 | 正确做法 |
|---|---|---|
| 1 | 类型标识缺失或错误（网页用 [J]、图书电子版漏 [/OL]） | 按类型与载体选正确标识 |
| 2 | 数据集/预印本/档案/地图未用新标识 | [DS/OL]、[PP/OL]、[A]、[CM] |
| 3 | 电子资源缺 URL | URL 为电子资源必备 |
| 4 | 网页/网站/数据集/预印本缺 [引用日期] | [引用日期] 必备；(创建或修改日期) 有则必备 |
| 5 | 有 DOI/永久标识符却未著录 | 有则必备，置于最末；URL 已含则不重复 |
| 6 | 期刊卷期结构错误 | `年，卷（期）：页码`；无卷号时 `年（期）：页码` |
| 7 | 页码前用"."而非"：" | 引文页码前用"：" |
| 8 | 析出文献未用"//"或用错 | 专著/文集篇章用 [M]//、会议论文 [C]//；期刊文章不用 // |

| 13 | 标准条目格式错误 | `标准编号 标准名称[S].`（编号与名称间空一格、不加句点）；**不著出版地/出版者** |
| 14 | 报纸缺版次或日期格式错 | `报纸名，YYYY-MM-DD（版次）` |
| 15 | 版本项缺失（非第 1 版）或位置错 | 非第 1 版须著录，置于出版地之前 |

## 九、易错类型的非常规要素

| 类型 | 易错点 |
|---|---|
| 标准 [S] | **不著出版地、出版者、出版年**；编号与名称间空一格不加句点；连接号用一字线"—" |
| 报告 [R] | **不著出版地、出版者**；只著发布日期（YYYY-MM-DD）与引文页码 |

| 报纸 [N] | 须著**版次**（有则必备） |

## 十、问题分级

- **错误（❌）**：必备要素缺失、要素顺序错误、类型/载体标识错误、正文与文后表体系不一致、新旧国标关键项不符——必须修改。
- **不规范（⚠️）**：标点全半角、空格、缩写等不影响识别与检索的偏差——建议修改。
- **提示（💡）**：可选要素缺失（缺创建/修改日期、有 DOI 未提供、版本缺失）——视期刊或学校要求补充。
- **存疑（❓）**：规则或示例无法确认、新旧国标衔接细节——提示用户核对标准正式文本。
