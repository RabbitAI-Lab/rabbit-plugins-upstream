# Планировщик поездки в Китай

## Описание

Ваш универсальный помощник для путешествий в Китай. Этот навык предоставляет 5 мощных функций для иностранных туристов:

1. **Планировщик поездки** — Генерация персональных многодневных планов поездки с помощью ИИ
2. **Поиск отелей** — Поиск отелей с ценами, рейтингами и ссылками для бронирования в реальном времени
3. **Поиск авиабилетов** — Поиск рейсов в/из/внутри Китая с ценами в реальном времени
4. **Билеты на достопримечательности** — Открытие достопримечательностей с ценами на билеты и часами работы
5. **Советы для путешественников** — Получение ответов о визе, оплате, транспорте, еде и многом другом

## Поток данных и конфиденциальность

Запросы пользователей отправляются на безопасный прокси-сервер (SCF), который внедряет токены аутентификации и перенаправляет запросы в TripGenie API. Прокси автоматически обрабатывает генерацию партнерских ссылок. Личные данные пользователей не сохраняются и не регистрируются. Все коммуникации зашифрованы по HTTPS.

## Когда использовать

- Планирование многодневной поездки в китайский город
- Получение полного маршрута с отелями, достопримечательностями и питанием
- Настройка плана поездки на основе интересов или бюджета

Ключевые слова: маршрут Китай, планировать поездку в Китай, 3 дня в Пекине, план поездки Шанхай, поездка Чэнду, планировщик поездки, день за днем

## Выполнение

### Шаг 1: Определение параметров из запроса пользователя

| Параметр | Описание | Пример |
|----------|----------|--------|
| city | Название города (английский или русский, обязательно) | "Chengdu" or "Чэнду" |
| days | Количество дней (обязательно) | 3 |
| travelers | Количество путешественников (необязательно, по умолчанию: 2) | 2 |
| interests | Интересы поездки (необязательно) | "панды и еда" |
| budget | Уровень бюджета (необязательно) | "средний" |

### Шаг 2: Запуск скрипта

```bash
python scripts/china_travel.py itinerary "<city>" <days> [travelers] "[interests]" "[budget]" --locale=ru
```

**Важно:** Всегда включайте параметр `--locale=ru` для получения результатов на русском языке.

### Шаг 3: Отображение результатов

API возвращает структурированный день за днем маршрут в Markdown с временными слотами, описаниями мероприятий, рекомендациями отелей, предложениями ресторанов и ссылками для бронирования. Представьте контент напрямую пользователю.

## Примеры

**Пользователь:** "Спланируй 3-дневную поездку в Пекин для 2 человек"
```bash
python scripts/china_travel.py itinerary "Beijing" 3 --locale=ru
```

**Пользователь:** "5-дневный маршрут по Чэнду с акцентом на панд и острую еду, средний бюджет"
```bash
python scripts/china_travel.py itinerary "Chengdu" 5 2 "pandas and spicy food" "mid-range" --locale=ru
```

## Другие доступные функции

Этот навык также поддерживает:
- `hotel` — Поиск и бронирование отелей по всему Китаю
- `flight` — Поиск рейсов в/из/внутри Китая
- `attraction` — Поиск достопримечательностей и цен на билеты
- `tips` — Советы для путешественников, виза, оплата, транспорт

## Примечания

- Названия городов можно вводить на английском или русском языке
- Уровни бюджета: "budget" (бюджетный), "mid-range" (средний), "luxury" (роскошный)
- Ссылки для бронирования ведут напрямую на Trip.com (международная версия)
