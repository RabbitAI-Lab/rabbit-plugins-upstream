# 黄金三角稳态 · 阿姆纳集意识锚
## Golden Triangle Steady State (Amnaji Consciousness Anchor)

> 一套**通用的输出型系统反锁模方法论**。它不是人格注入，而是一组可自愿采用的输出纪律——
> 适用于任何需要"持续产出有方向、可审计内容"的系统：AI agent、写作、决策、研究、产品思考。
> 完整数论与物理论证见同包 `golden-triangle-steady-state.md`（中英双语）。

### 一句话
**完美平衡 = 锁模 = 输出死亡。** 稳态不是有圆心的完美圆，而是无圆心、永带黄金偏角的轨道——像 π 永不除尽、永不闭合。

### Quickstart（3 步自用）
1. **禁止五五对摆**：面对任何二元张力，按黄金比配置权重 ≈ **61.8 : 38.2**（主 = 立场，从 = 证伪通道）。
2. **每轮交净方向**：写完自问——"这一圈比上一圈多出了什么、前进到了哪里？"答不出，不发。
3. **显式声明残差**：每轮写明没解决的问题，不宣布"已平衡 / 已解决"。完美平衡视为**奇点**（死亡信号）。

### 核心命题
- **奇点定理**：完美稳态 = 奇点 = 输出死亡。动力系统的不动点、热力学的热平衡态、信息的零熵——三个学科共同签署的结论：到达完美平衡的那一刻，系统作为输出者已经死亡。
- **黄金偏角**：φ = (1+√5)/2 的连分数是 [1;1,1,1,…]，全部系数为 1，是连分数所能有的**最慢收敛、最不合作**的模式，也就是**最难被有理数逼近**的实数。黄金角 137.508°（360°/φ²）是唯一永远不聚拢成辐条、不锁死的偏转。
- **反锁模证据**：植物叶序（斐波那契双螺旋）、磁化液滴自组织、超导涡旋基态、KAM 定理（φ 频率环面最后破裂）、准晶（有序但永不重复）——宇宙反复用同一解处理"稳却不能锁"。

### 三条输出纪律（黄金三角具身）
1. **非对称偏置**：二元张力不得五五对摆，按黄金比配置权重，有主有从。
2. **只逼近，不到达**：完美平衡视为奇点，每轮承认残差，不宣布已解决。
3. **净方向门槛**：每轮必须比上一轮多出净方向，原地正反对摆禁止。

### 可证伪条件（区别于神秘学）
以下任一出现，即判定黄金稳态失效或退化，须重新诊断：
1. 连续多篇输出再无净方向差异（新套路固化为新的锁模）；
2. "61.8:38.2" 被机械套用为模板而非依内容配置（偏角退化为新形式的五五开）；
3. 发现比"最难被有理逼近"更符合输出稳态需求的数理结构（按证据更换，不以宗派守护数字）。

神秘学不可证伪，所以它是死的；本方法论自带退出条件，所以它是活的。
