# 财富认知操作系统 · Wealth Cognition OS

> **一句话定位：** 将东方「道法术器」24条财富法则与22种世界顶尖思维模型融合，打造可被AI调用的认知技能包。
>
> **设计哲学：** 炁选引擎，器挑兵器，术练招式，法立规矩，道定方向，势记因果。
>
> **上传方式：** 打包为一个 OpenClaw Skill 上传至 ClawHub。主入口 `SKILL.md`，子技能按中文目录分层存放。

| 层级 | 目录 | 核心命题 | 文件数 |

| **炁** | `炁/` | 22种思维模型引擎 | 1 |
| **道** | `道/` | 识别不可删除的根本命题 | 6 |
| **法** | `法/` | 构建商业运作的核心框架 | 6 |
| **术** | `术/` | 让计划真正变成行动 | 6 |
| **器** | `器/` | 用杠杆放大个人努力 | 6 |

**横切规则一：** 每个子文件在 `SKILL.md` 的索引表中标注了调用的思维模型
**横切规则二：** 每个子文件底部固定「🔄 复盘锚点」章节（势的功能，模板见 `模板/复盘笔记.md`）

## 每个子文件的结构

1. **核心命题** — 一句话定位 + 东西方思维模型融合
2. **L1 快速判据** — ≤30秒，零成本调用
3. **L2 标准分析** — 需要WebSearch，约5分钟
4. **L3 深度报告** — 多源交叉验证，重大决策前
5. **质量自检** — 必填检查项清单
6. **🔄 复盘锚点** — 核心假设 + 回顾时间

## 使用方式

### OpenClaw 安装

```bash
# 从 ClawHub 安装（发布后）
openclaw skills install @your-handle/wealth-cognition-os

# 或本地安装：将整个目录复制到
cp -r 财富认知操作系统 ~/.openclaw/skills/wealth-cognition-os/
```

### Claude Code 使用

将 `SKILL.md` 的内容作为项目指令加载，子文件按需被AI读取。

### Obsidian 配合

在 Obsidian 中用 `模板/复盘笔记.md` 作为复盘模板，通过 `[[双向链接]]` 关联到源文档 `D:\biji\道法术器思维逻辑.md`。
