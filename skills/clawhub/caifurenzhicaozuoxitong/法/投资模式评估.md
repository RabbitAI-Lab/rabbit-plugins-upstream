# 投资模式评估

> **概率思维——投资是计算期望值后下注，不是追求100%确定性。**

投资与赌博的核心区别不在于风险高低，而在于是否存在正的期望值以及是否进行了理性的仓位管理。本文件提供三层分析框架，帮助你从"感觉靠谱"到"计算后下注"。

**免责声明：本文件仅为思维框架参考，不构成任何投资建议。所有投资决策的风险由决策者自行承担。市场有风险，决策需谨慎。**

---

## L1 — 快速判据（≤30秒）

在接触任何投资机会时，用以下五个问题完成第一层过滤。任何一个问题答不上来，就意味着你还不具备下注的基本条件。

| 判据 | 核心问题 | 通过标准 |
|------|----------|----------|
| **投资vs赌博** | 这个决策的期望值是否为正？（不是"有没有可能赚"，而是"概率加权后是否大于1"） | 必须有量化估算 |
| **期望值速算** | 上行收益×上行概率 − 下行损失×下行概率 = ？ | 必须为正 |
| **仓位上限** | 如果这笔投资归零，你的生活是否不受影响？ | 必须"是" |
| **亏得起的钱** | 这笔钱来自"可投资资产"还是"生活费"？ | 必须是前者 |
| **退出条件** | 什么情况下你会卖出/退出？是否写下来了？ | 必须有成文标准 |

**速判操作模板：**

```
投资标的：____________________
期望值速算：（赚_____×_____%）−（亏_____×_____%）= _____
最大仓位：不超过总可投资资产的_____%
资金来源：[ ] 可投资资产 [ ] 生活费 [ ] 借贷
退出条件：出现____________________时立即退出
```

**红牌警告清单（出现任何一条即停止，不进入L2）：**

- 无法计算期望值（意味着你只是在赌）
- 仓位超过总资产的20%（集中度风险失控）
- 使用了生活费或借贷资金（违反"亏得起的钱"原则）
- 没有成文的退出条件（情绪将在关键时刻接管决策）
- 决策基于"这次不一样"的信念（历史上这四个字代价最大）

## L2 — 标准分析（~5分钟）

### 第一步：概率矩阵构建

将不确定的未来结构化为一棵决策树，而非一个单一预测。

**概率矩阵模板：**

| 情景 | 概率（%） | 预期回报（%） | 概率加权回报（%） |
|------|-----------|---------------|-------------------|
| 最佳情景 | | | |
| 基准情景 | | | |
| 最差情景 | | | |
| **加权总计** | **100%** | — | **（填计算结果）** |

**情景定义的参考维度：**

- 宏观环境：利率、通胀、政策方向
- 行业趋势：渗透率、竞争格局、技术替代
- 公司/项目特定：管理执行、产品里程碑、客户获取

**概率校准原则：**
- 如果你从未给某个情景分配过低于10%的概率，你的估计过于自信
- "尾部风险"的概率虽然低（1-5%），但必须独立列出
- 最佳和最差情景的回报估计，要追问"为什么不能比这更好/更差"

### 第二步：凯利公式仓位计算

凯利公式告诉你：在已知胜率和赔率的情况下，理论上的最优仓位。

```
凯利仓位 f = (p × b − q) / b

其中：
p = 获胜概率
q = 失败概率 = 1 − p
b = 赔率 = 预期盈利 / 预期亏损
```

**凯利公式应用示例表：**

| 胜率(p) | 赔率(b) | 凯利仓位(f) | 实用建议（半凯利） |
|---------|---------|-------------|-------------------|
| 60% | 1:1 | 20% | 10% |
| 40% | 3:1 | 20% | 10% |
| 80% | 0.5:1 | 40% | 20% |
| 30% | 5:1 | 16% | 8% |

**仓位管理的补充约束（凯利的局限）：**

1. **凯利假设你知道精确的概率**——但现实中你永远不知道。因此实际仓位应为凯利建议的50%（半凯利）。
2. **凯利不考虑流动性**——如果无法及时平仓，应进一步降低仓位。
3. **凯利不考虑相关性**——如果这个投资与你的主要收入来源（比如你所在的行业）高度相关，应降低仓位。

### 第三步：蒙特卡洛思维框架

你不需要实际运行蒙特卡洛模拟，但你需要用蒙特卡洛的思维方式思考：

**关键问题：**
- 影响回报的关键变量有哪些？（列出3-5个）
- 这些变量的可能范围是什么？（不是点估计，是范围）
- 这些变量之间是否相关？（比如：销量上升时往往单价下降）

**变量敏感性排序：**

| 变量 | 最可能值 | 合理区间 | 对最终回报的影响度 | 排序 |
|------|----------|----------|-------------------|------|
| | | | | |
| | | | | |
| | | | | |

识别"关键变量"——那个对最终结果影响最大的变量，把你80%的研究时间花在理解它上面。

### 第四步：相关性检查

你真正的风险不是单个投资的波动，而是你的"全部身家"是否都暴露在同一类风险之下。

**隐性相关性检查表：**

| 你的资产/收入 | 与投资标的的关联 | 关联强度 | 应对措施 |
|-------------|-----------------|----------|----------|
| 主要职业收入 | 是否在同一行业？ | | |
| 房产 | 是否在同一区域/受同一政策影响？ | | |
| 已有投资 | 是否与标的同质化？ | | |
| 家庭收入来源 | 是否多元化？ | | |

**黄金原则：如果投资失败时你的主要收入来源也同时受损，说明你的"真实仓位"远比你账面上显示的大。**

### 第五步：弹孔思维

引用二战时亚伯拉罕·沃尔德的"幸存者偏差"洞察：不要只研究成功案例，要研究失败案例中那些没有回来的飞机——它们被击中的部位才是致命弱点。

**弹孔思维清单：**

1. 这个领域里死了的公司/项目，它们的致命伤是什么？
2. 我目前的投资假设中，有没有和那些失败案例相同的前提假设？
3. 如果这个投资失败了，最可能的失败原因是什么？（写下三个）
4. 有没有一种失败模式，是我目前完全看不到的？（盲点探测）

## L3 — 深度报告（重大决策前）

### 投资组合影响分析

一项新投资不应该被孤立地评估，而应该放在整个投资组合的背景下审视：

**加入前后组合对比：**

| 组合指标 | 加入前 | 加入后 | 变化方向 |
|----------|--------|--------|----------|
| 预期年化回报 | | | |
| 最大回撤预估 | | | |
| 夏普比率估算 | | | |
| 行业集中度（最大行业占比） | | | |
| 流动性覆盖（月支出的倍数） | | | |

**你需要的不是一个"完美"的投资，而是一个让你的整体组合更接近最优的投资。**

### 敏感性分析

对L2中识别出的"关键变量"进行压力测试：

**压力测试矩阵：**

| 关键变量 | 当前假设 | 恶化20% | 恶化50% | 完全失效 |
|----------|----------|---------|---------|----------|
| | | 回报=___ | 回报=___ | 回报=___ |
| | | 回报=___ | 回报=___ | 回报=___ |
| | | 回报=___ | 回报=___ | 回报=___ |

**判断标准：如果在"恶化50%"那一列，你的整体生活仍然不受影响，说明仓位和风险管理是健康的。**

## 质量自检清单

- [ ] 每个情景的概率总和为100%，且包含至少一个负面情景
- [ ] 实际仓位不超过半凯利公式的建议值
- [ ] 投资资金来自"可投资资产"而非生活费或借贷
- [ ] 有成文的退出条件，且包含"什么时候不做什么"的清晰规则
- [ ] 完成了相关性检查——投资失败不会同时冲击主要收入来源
- [ ] 至少研究了三个该领域/该策略的失败案例
- [ ] 组合层面的最大回撤在可承受范围内
- [ ] 关键变量的恶化50%压力测试通过
- [ ] 决策依据有书面记录（用于事后复盘，而非记忆中的合理化）

## 🔄 复盘锚点

每次投资复盘时，回到以下四个锚点：

1. **决策质量锚点**：区分"结果"和"决策质量"。一个坏结果可能来自好决策（运气不好），一个好结果可能来自坏决策（运气好）。复盘只评判决策质量——当时的概率估计是否合理？仓位管理是否遵守纪律？

2. **期望值锚点**：实际结果落在概率矩阵的哪个区间？如果持续落在最差情景，是否意味着概率估计存在系统性偏差？

3. **纪律锚点**：退出条件是否被执行？如果没有，是什么情绪或认知偏差阻止了执行？记录下来，这是你最大的敌人。

4. **进化锚点**：这次投资经历让你的投资体系进化了什么？它应该被编码为一条新的原则，写入下次L1判据中。

**复盘记录模板：**

```
日期：____________________
投资标的：____________________
初始期望值估算：____________________
实际结果：____________________
决策质量评分（1-10）：______
结果与决策是否一致：[ ] 好决策+好结果 [ ] 好决策+坏结果 [ ] 坏决策+好结果 [ ] 坏决策+坏结果
学到的一条原则：____________________
下次L1中应该增加/修改的判据：____________________
```
