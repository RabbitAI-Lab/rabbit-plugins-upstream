# 商业模式画布

> **第一性原理重构价值交换图——不问行业惯例，只问"客户真正愿意为什么付费"。**

商业模式不是一张填满的九宫格表格，而是一张价值交换的逻辑地图。本文件提供从30秒快速判断到重大决策前深度报告的三层分析框架，帮助你穿透行业惯例，直抵商业本质。

---

## L1 — 快速判据（≤30秒）

在电梯里遇到一个项目，用下面五个问题完成第一轮筛选。每个问题只需回答"是/否/说不清"——出现两个以上"说不清"即意味着需要进入L2分析。

| 判据 | 核心问题 | 通过标准 |
|------|----------|----------|
| **价值清晰度** | 客户是否能用一句话说清你为什么值得付费？ | 必须"是" |
| **天花板判断** | 目标市场是否存在天然的规模上限（地域、人群、频次）？ | 最好"否" |
| **复购逻辑** | 客户是否有自然理由再次购买（消耗品/订阅/升级）？ | 必须"是" |
| **护城河** | 如果今天有个团队抄你，六个月后你们谁赢？ | 必须"你赢" |
| **单位经济** | 单笔交易毛利是否覆盖获客成本且有盈余？ | 必须"是" |

**速判结论速查表：**

| 五个问题结果 | 行动建议 |
|-------------|----------|
| 五项全"是" | 值得进入L2深度分析 |
| 4个"是"+1个"说不清" | 标记风险点，进入L2 |
| 2-3个"说不清"或1个"否" | 商业模式存在结构性问题，不急于推进 |
| 2个以上"否" | 立即停止，重新思考价值假设 |

## L2 — 标准分析（~5分钟）

### 第一步：第一性原理拆解

在填入任何画布表格之前，先回答三个元问题：

1. **客户到底在买什么？** （不是你的产品功能，而是他愿意掏钱的那个"被满足的状态"）
   - 举例：星巴克的客户买的不是咖啡，是"第三空间的使用权"
   - 举例：爱马仕的客户买的不是包，是"阶层信号的可携带载体"

2. **为什么是你而不是别人？** （这是护城河的起点，不是品牌口号的起点）
   - 结构性的优势来源：规模效应、网络效应、转换成本、数据飞轮、专利壁垒
   - 非结构性的优势来源：先发优势、品牌认知、运营效率——这些都可以被追赶

3. **为什么是现在而不是三年前或三年后？** （时机窗口判断）
   - 技术成熟度是否恰好到达拐点？
   - 用户习惯是否已经养成？
   - 基础设施是否已经就位？

### 第二步：九要素画布（第一性原理版）

不以行业惯例填空，而以"如果从零设计这个价值交换系统"的视角填充每一格。

| 画布模块 | 核心问题（第一性原理视角） | 填写要求 |
|----------|---------------------------|----------|
| **价值主张** | 如果客户明天失去你的产品，他失去的到底是什么？ | 用客户的日常语言，不用行业术语 |
| **客户细分** | 谁在为这个"失去的东西"感到真实的痛苦？ | 区分付费者、使用者、决策者 |
| **客户关系** | 客户希望以什么频率、什么方式与你互动？ | 是"客户主动找你"还是"你主动找客户" |
| **渠道通路** | 客户在什么场景下最容易做出购买决定？ | 区分认知渠道、评估渠道、购买渠道 |
| **收入来源** | 客户天然认为应该按什么单位付费？（次/月/年/效果） | 对标客户心智中的"价格锚点" |
| **核心资源** | 哪些资源如果消失，整个模式立即崩塌？ | 区分"必须自建"vs"可外部获取" |
| **关键业务** | 每周必须完成的三件最重要的事是什么？ | 不是to-do list，是模式运转的齿轮 |
| **重要伙伴** | 哪些环节自己做不如让别人做？ | 区分"交易型伙伴"vs"战略型伙伴" |
| **成本结构** | 最贵的那个成本项是否随着规模扩大而递减？ | 判断是规模经济型还是规模不经济型 |

### 第三步：护城河识别矩阵

| 护城河类型 | 识别信号 | 脆弱性检查 |
|-----------|----------|------------|
| **网络效应** | 每新增一个用户，所有老用户的价值都提升 | 是否只在特定规模下成立？是否存在多归属风险？ |
| **转换成本** | 客户离开你不仅意味着失去服务，还意味着失去数据/关系/积分 | 转换成本是否足够高于竞争对手的补贴力度？ |
| **规模效应** | 单位成本随规模下降的斜率是否显著 | 是否有最小有效规模门槛？竞争对手是否已经跨过？ |
| **品牌护城河** | 客户愿意为你的名字支付溢价 | 溢价是否可量化？10%还是50%？ |
| **数据飞轮** | 更多用户→更多数据→更好产品→更多用户 | 数据的边际价值是否递减？隐私法规是否构成风险？ |

### 第四步：LTV/CAC 速算

```
LTV = 客户平均月付费 × 毛利率 × 平均留存月数
CAC = 总营销费用 / 获取新客户数

健康标准：LTV / CAC ≥ 3
警戒标准：LTV / CAC < 1（商业模式不可持续）
回收期标准：CAC回收期 < 12个月
```

**LTV/CAC 诊断矩阵：**

| 指标状态 | 诊断结论 | 应对方向 |
|----------|----------|----------|
| LTV/CAC > 5 | 可能投放不足，有增长空间 | 加大获客投入 |
| 3 ≤ LTV/CAC ≤ 5 | 健康区间 | 维持并优化 |
| 1 ≤ LTV/CAC < 3 | 获客效率偏低 | 优化转化漏斗或提升客单价 |
| LTV/CAC < 1 | 不可持续 | 根本上重构获客模型或盈利模型 |

## L3 — 深度报告（重大决策前）

在投入重大资源（资金、团队、时间）之前，完成以下三个维度的深度推演。

### 1. 商业模式变异推演

考虑至少三种"变异路径"——你的商业模式在什么条件下会演变成完全不同的事物？

- **上行变异**：如果核心假设比预期好2倍（规模更大、频次更高、客单价更高），模式如何演变？
- **下行变异**：如果核心假设比预期差50%，模式是否仍然成立？最低生存线在哪里？
- **跨界变异**：如果相邻行业的巨头进入你的领域，他们最可能从哪个画布模块切入？

### 3. 收入流多元化路径

收入来源过度集中是商业模式最大的隐性风险。绘制收入多元化路线图：

- **当前状态**：前三大客户/产品的收入占比
- **12个月目标**：通过什么新收入流将集中度降低？
- **36个月愿景**：收入结构中应该出现哪些"反脆弱"成分（无论市场好坏都稳定的收入）？

**收入健康度检查：**

| 指标 | 安全线 | 警戒线 | 当前状态 |

| 最大产品线收入占比 | <30% | >60% | |
| 经常性收入占比 | >50% | <30% | |

## 质量自检清单

在完成商业模式分析后，逐条核对：

- [ ] 价值主张是用客户的语言描述的，而非行业术语
- [ ] 画布的每一个模块与价值主张之间存在明确的逻辑箭头
- [ ] 护城河的来源是可验证的结构性优势，而非主观判断
- [ ] LTV/CAC 计算的基础假设（留存率、毛利率、获客成本）有数据支撑
- [ ] 至少推演了三种商业模式变异路径
- [ ] 收入来源具有多元化潜力，不依赖单一客户或单一产品
- [ ] 如果核心假设（市场规模、增长率、单价）各下调30%，模式依然成立
- [ ] 竞争对手即使完全复制你的产品，也无法在6个月内追平核心优势

## 🔄 复盘锚点

每次商业模式复盘时，回到以下四个锚点问题：

1. **价值锚点**：客户愿意付费的理由是否仍然成立？市场是否出现了更便宜/更快的替代方案？
2. **效率锚点**：LTV/CAC 比率是在改善还是恶化？趋势比绝对值更重要。
3. **护城河锚点**：与上一次复盘相比，护城河是加宽了还是变窄了？为什么？
4. **边界锚点**：商业模式的自然边界在哪里？我们是否已经或正在接近这个边界？

**复盘节奏建议：**

| 复盘频率 | 复盘内容 | 参与人 |
|----------|----------|--------|
| 每月 | LTV/CAC 趋势、收入集中度 | 运营团队 |
| 每季 | 画布全要素审视、护城河宽度评估 | 核心管理层 |
| 每年 | L3深度报告、商业模式变异推演 | 创始团队+外部顾问 |
