# 推广模式构建

> **追求自我增强的增长闭环，而非单次流量采买。亚马逊飞轮——更低价格→更多客户→更多卖家→更好选择→更低价格。**

增长不是预算的线性函数。最好的推广模式是设计一套自我增强的系统——每一分钱的投入不仅带来客户，更能降低下一次获客的成本。本文件提供三层分析框架，帮助你将推广从"成本中心"转变为"增长引擎"。

---

## L1 — 快速判据（≤30秒）

用四个问题快速判断一个推广模式是否具备自增强潜力。

| 判据 | 核心问题 | 通过标准 |
|------|----------|----------|
| **增长引擎类型** | 你的主要增长动力属于哪一类？（付费/病毒/内容/销售） | 必须能说出主导引擎 |
| **K因子** | 平均每个用户带来多少个新用户？ | >0.5才有自传播潜力，>1.0才是真正病毒性 |
| **网络效应** | 用户增加是否让产品对所有用户变得更好？ | 必须能够清晰描述机制 |
| **获客可复制性** | 今天的获客方式，明天是否还管用？成本是否在降低？ | 趋势必须向好 |

**增长引擎类型诊断：**

| 类型 | 特征 | 适合场景 | 天花板 | 度量核心 |
|------|------|----------|--------|----------|
| **付费引擎** | 广告→点击→转化→收入→更多广告预算 | 高毛利产品 | 受制于LTV/CAC | ROI, CAC回收期 |
| **病毒引擎** | 用户→邀请→新用户→更多邀请 | 社交/协作/展示类产品 | 受制于用户基数和K因子 | K因子, 病毒循环周期 |
| **内容引擎** | 内容→SEO流量→用户→更多内容→更多SEO流量 | 信息/教育/工具类产品 | 受制于搜索引擎/平台算法 | 内容产出速度, 自然流量占比 |
| **销售引擎** | 销售触达→演示→成交→招聘更多销售 | 高客单价B2B产品 | 受制于销售人效 | 销售人效, 销售周期 |

**单引擎vs多引擎判断原则：** 初创期聚焦一个主导引擎，增长期叠加第二个引擎，成熟期至少维持两个以上引擎的运转。

## L2 — 标准分析（~5分钟）

### 第一步：增长飞轮设计

亚马逊的增长飞轮是经典模板，但每个商业模式都需要设计自己的飞轮。

**通用增长飞轮设计公式：**

```
A增长 → B改善 → C增加 → A进一步增长
```

**要求：** 每一环之间的因果关系必须是可验证、可度量的，而非"可能"或"应该"。

**飞轮设计自检：**

1. 飞轮的每一步是否能用一句话说清因果机制？
2. 每一步是否有可追踪的度量指标？
3. 飞轮运转一圈需要多长时间？（周期越短，复利效应越强）
4. 飞轮的驱动力来自内部（产品机制）还是外部（预算投放）？（内部驱动更可持续）

**飞轮健康度诊断表：**

| 飞轮状态 | 判断信号 | 应对 |
|----------|----------|------|
| 加速旋转 | 每次循环的成本在降低，产出在提升 | 加大投入，放大飞轮 |
| 匀速旋转 | 投入产出比例稳定 | 寻找加速杠杆 |
| 减速旋转 | 每次循环的边际产出递减 | 检查飞轮哪一环出现瓶颈 |
| 停止/倒转 | 投入不再带来增长 | 根本性检查产品-市场匹配 |

### 第二步：漏斗构建与诊断

推广不是"把钱花出去"，而是"把流量转化为收入的设计工程"。

**标准转化漏斗：**

| 漏斗层级 | 定义 | 典型转化率参考 | 诊断问题 |
|----------|------|---------------|----------|
| **认知** | 听说过你的产品/品牌的潜在客户 | — | 目标人群的认知率是多少？ |
| **兴趣** | 主动搜索/点击/访问 | 认知→兴趣: 1-5% | 认知到兴趣的跳转率是否在下降？ |
| **考虑** | 注册/试用/询价 | 兴趣→考虑: 5-20% | 落地页是否清晰传达了价值？ |
| **转化** | 首次付费 | 考虑→转化: 10-30% | 付费门槛是否合理？是否有免费体验路径？ |
| **留存** | 持续使用/复购 | 次月留存: 20-60% | 首次价值感知时间是否足够短？ |
| **推荐** | 主动推荐给他人 | 留存→推荐: 5-25% | 推荐行为被奖励了吗？推荐路径够不够短？ |

**漏斗瓶颈定位法：** 不要同时优化所有层级。找到"最大落差"的那一环节——相邻两层转化率差距最大的地方——把它作为本周期的最优先优化目标。

### 第三步：渠道矩阵

单一渠道的增长是不可持续的。构建渠道矩阵，平衡"付费"与"免费"、"短期"与"长期"。

**渠道评估矩阵：**

| 渠道 | 类型 | 当前ROI | ROI趋势 | 可扩展性 | 竞争强度 | 战略评分 |
|------|------|---------|---------|----------|----------|----------|
| | 付费/免费/混合 | | ↑/→/↓ | 高/中/低 | 高/中/低 | |
| | | | | | | |
| | | | | | | |

**评分标准（1-5分）：**
- ROI: 5=极高, 1=亏损
- ROI趋势: ↑加分, ↓减分
- 可扩展性: 5=投入10倍预算仍有效, 1=天花板已明显
- 竞争强度: 低=容易突围, 高=竞争激烈（注意：低竞争+高ROI的组合是最佳窗口）

**渠道策略矩阵（基于评分结果）：**

| 评分区间 | 策略 | 资源分配建议 |
|----------|------|-------------|
| 4-5分 | 主力加码 | 投入50-60%的推广资源 |
| 3分 | 维持测试 | 投入20-30%，持续优化后可能升级 |
| 1-2分 | 缩减或放弃 | 降至10%以下，或完全关闭 |

### 第四步：网络效应类型与设计

网络效应是增长飞轮最强大的加速器。但不是所有网络效应都生来平等。

**网络效应分类与诊断：**

| 类型 | 定义 | 案例 | 脆弱性 | 强化策略 |
|------|------|------|--------|----------|
| **直接网络效应** | 用户越多，产品对每个用户的价值越大 | 微信、电话 | 需要跨过临界规模 | 降低初始使用门槛 |
| **双边网络效应** | 供给端越多，需求端越有价值（反之亦然） | 淘宝、滴滴 | 两端都需要冷启动 | 一侧补贴，另一侧收费 |
| **数据网络效应** | 更多用户→更多数据→更好产品→更多用户 | 搜索引擎、推荐算法 | 数据边际价值递减 | 确保数据采集的广度与深度 |
| **社交网络效应** | 朋友在用→我也要用 | 朋友圈、Instagram | 隐私风险、审美疲劳 | 强化身份认同和内容独占性 |
| **平台/生态网络效应** | 第三方开发者增加→平台价值增加 | iOS、微信小程序 | 平台规则变化引发开发者流失 | 降低开发门槛，确保利益分配公平 |

**网络效应冷启动策略：**

1. **最小网络单元**：满足最小可运行网络的最小用户数和内容量是多少？先在这个规模内跑通价值闭环。
2. **单侧切入**：双边市场中先集中资源吸引供给侧还是需求侧？选择更稀缺、更难替代的一侧。
3. **人工替代**：在用户量不足以形成网络效应时，用人工/运营替代网络效应。例如：早期约会软件自己当托，早期电商自己上架商品。

## L3 — 深度报告（重大决策前）

### 1. 竞对增长路径还原

"还原"竞争对手的增长路径——不是猜他们怎么做，而是从公开信息倒推他们的增长逻辑。

**竞对增长路径还原模板：**

| 还原维度 | 竞对A | 竞对B | 我们的差异 |
|----------|-------|-------|-----------|
| 冷启动方式 | | | |
| 主导增长引擎 | | | |
| K因子/病毒系数估算 | | | |
| 获客成本估算 | | | |
| 用户留存曲线形状 | | | |
| 内容/SEO策略 | | | |
| 渠道组合 | | | |
| 品牌定位 | | | |

**从竞对还原中学什么：**
- 他们试过错的方向是什么？（找到他们尝试过但放弃了的渠道/策略）
- 他们的增长是否高度依赖单一渠道？（如果是，这个渠道的政策变化就是他们的风险点）
- 他们的增长是否可以复制？（如果可以，意味着没有护城河）

### 2. 增长天花板推演

每种增长模式都有一个隐性天花板。在它到来之前推演它，而不是在它到来之后反应。

**增长天花板探测框架：**

| 天花板类型 | 信号 | 挑战 | 突破策略 |
|-----------|------|------|----------|
| **渠道天花板** | 主力渠道的边际ROI持续下降 | 还没有找到第二个有效渠道 | 启动第二渠道、转向内容/品牌 |
| **市场天花板** | 核心人群的渗透率达到40-60% | 剩余人群获客成本远高于早期 | 拓展相邻人群、国际化 |
| **产品天花板** | 用户活跃但无法向上销售 | 付费转化率停滞 | 产品线延伸、价格分层 |
| **注意力天花板** | 内容触达率下降、通知点击率降低 | 用户对营销信息免疫 | 从推送到拉回、创造主动回访场景 |

**天花板预警信号清单：**
- 连续两个季度CAC上升超过20%
- 自然流量占比下降（意味着对算法的依赖在增加）
- 用户首次付费后的激活时间在变长
- NPS在下降但尚未反映在流失率上（滞后指标）

## 质量自检清单

- [ ] 识别了当前的主导增长引擎，并清楚其天花板在哪里
- [ ] 增长飞轮的每一步都有可追踪的度量指标，因果链条可验证
- [ ] 转化漏斗的"最大落差"环节已被定位，且是当前优化的优先目标
- [ ] 渠道矩阵至少包含一个付费渠道和一个免费/自然渠道
- [ ] 网络效应类型已被明确识别，冷启动策略有具体方案
- [ ] 竞对增长路径已被还原，且识别了他们的增长脆弱点
- [ ] 增长天花板至少从三个维度被评估：渠道、市场、产品
- [ ] 有一个明确的"预警信号清单"，用数据而非直觉判断增长是否在恶化

## 🔄 复盘锚点

每次增长复盘时，回到以下四个锚点：

1. **飞轮锚点**：增长飞轮是在加速、匀速还是减速？如果减速，哪一环是瓶颈？
2. **渠道锚点**：渠道矩阵的多样性是在增加还是减少？如果过度依赖单一渠道，替代方案是否已经启动？
3. **效率锚点**：CAC（获客成本）的趋势——它是在上升、持平还是下降？如果是上升，LTV是否在以更快的速度增长来对冲？
4. **天花板锚点**：距离最近的增长天花板还有多远？警报信号是否已经被触发？

**复盘节奏建议：**

| 复盘频率 | 复盘内容 | 参与人 |
|----------|----------|--------|
| 每周 | 关键漏斗指标、渠道ROI波动 | 增长团队 |
| 每月 | 渠道矩阵评估、CAC趋势、飞轮转速 | 市场+产品团队 |
| 每季 | 竞对增长动态、增长天花板探测 | 核心管理层 |
| 每年 | 增长引擎切换评估、第二增长曲线启动条件 | 创始团队+战略顾问 |
