# 战略布局推演

> **普通人看一步，高手看三步——二阶思维 + 灯塔思维。贝佐斯的Prime会员：一阶看"免运费亏钱"，二阶看"用户锁定和数据积累"，三阶看"平台生态的底层骨架"。**

战略不是"明年做什么"的年度计划，而是"如果从十年后回头看今天，什么是最重要的事"的逆向思考。本文件提供三层分析框架，帮助你从一阶反应升级为多阶推演，从年度规划升级为灯塔导航。

---

## L1 — 快速判据（≤30秒）

面对任何战略决策，先用四个问题迫使你跳出"一阶本能反应"。

| 判据 | 核心问题 | 通过标准 |
|------|----------|----------|
| **一阶思维** | 这个决策的"直接后果"是什么？（普通人止步于此） | 一句话说清 |
| **二阶思维** | 别人会如何回应你的行动？这个回应又会导致什么？ | 必须推演出至少一个反馈循环 |
| **三阶思维** | 这个决策在三年后改变了什么游戏规则？ | 必须描述"格局"层面的变化 |
| **警示信号** | 当前是否有人因为短期利益在做伤害长期的事？ | 必须例举至少一个信号 |

**一阶/二阶/三阶思维对比模板：**

| 思维层级 | 关注的问题 | 典型案例：是否降价获取市场份额 |
|----------|-----------|-------------------------------|
| **一阶** | 降价→销量上升→市场份额增加 | "降价后当月销量增长了30%" |
| **二阶** | 竞对跟进降价→全行业利润率下降→行业吸引力降低→优秀人才流出 | "三个月后竞对全线跟进，行业进入价格战" |
| **三阶** | 价格战淘汰弱者→行业集中度提升→剩者为王，但赢家需要足够的现金储备撑到那一天 | "两年后行业只剩三家，我们在价格战前储备了24个月的现金流" |

**如果你只能看到一阶，你是在"反应"；能看到二阶，你是在"博弈"；能看到三阶，你才是在"布局"。**

**警示信号清单（出现任何一个，说明战略可能正在被短期主义腐蚀）：**

- 削减研发预算以达成季度利润目标
- 核心用户的NPS在下降，但因为"增长数字好看"被忽视
- 竞争对手在投资一个"看起来不赚钱"的业务线，你不知道为什么
- 公司在用"降价"作为唯一的竞争手段
- 最优秀的人在离开，不是去了竞争对手，而是离开了整个行业

## L2 — 标准分析（~5分钟）

### 第一步：二阶推演链

将战略决策展开为一条因果链条，推到第二阶、第三阶。

**二阶推演链模板：**

```
我方行动：[描述你的战略选择]
    ↓
一阶效果（直接）：[我方行动的直接结果是什么？6-12个月内]
    ↓
竞对反应（对一阶效果的回应）：[谁最可能做出反应？他们最可能的回应是什么？]
    ↓
二阶效果（竞对反应带来的结果）：[行业结构/竞争格局/客户行为发生了什么变化？]
    ↓
我方的二阶应对：[面对二阶效果，我们的下一步棋是什么？]
    ↓
三阶格局：[这个棋局最终会把行业引向何方？]
```

**二阶推演检查要点：**

1. **竞对反应是否被低估？** 大多数战略失败的根源在于：假设竞争对手不会反应。
2. **时间延迟是否被考虑？** 战略效果往往有6-18个月的延迟。在效果显现之前，你是否会动摇？
3. **非市场参与者是否被忽略？** 监管者、供应商、互补品厂商——他们也可能是二阶变量。
4. **自身能力是否被高估？** 你的组织是否真的具备执行这个战略的能力和耐力？

### 第二步：灯塔思维——从终点倒推

不要从"我们现在能做什么"出发。从"十年后我们想成为什么"出发，一步一步倒推回来。

**灯塔推演模板：**

```
2035年的我们：____________________（用一段话描述你想成为的形态）

要成为那样，2032年我们必须已经完成：____________________

要完成2032年的目标，2029年我们必须已经具备：____________________

要具备2029年的能力，今天我们必须开始做：____________________
```

**灯塔设定的锚点原则：**

| 锚点 | 问题 | 要求 |
|------|------|------|
| **不变的需求** | 十年后客户仍然需要但尚未被满足的是什么？ | 基于人性的不变，而非技术风口 |
| **不可逆的趋势** | 哪些变化是十年后回头看"一定会发生"的？ | 人口、能源转型、AI渗透——长期确定性 |
| **不做的勇气** | 为了成为"那个"，你今天必须拒绝什么？ | 战略的本质是选择不做什么 |

**贝佐斯的"不变"哲学应用：** "我经常被问未来十年什么会变，但几乎没人问我未来十年什么不变。实际上第二个问题更重要——你可以围绕那些不变的东西建立长期的战略。"

**不变的锚点示例：**
- 客户永远想要更低的价格
- 客户永远想要更快的送达
- 客户永远想要更多的选择
- 这些"不变"比任何技术预测都更可靠

### 第三步：竞对博弈矩阵

将竞争格局建模为一个博弈——你的每一步行动，都要考虑到对手可能的多步回应。

**博弈推演矩阵：**

| 如果我方选择... | 竞对最可能的回应 | 我方的第二步应对 | 最终均衡状态 |
|---------------|-----------------|-----------------|-------------|
| 行动方案A | | | |
| 行动方案B | | | |
| 行动方案C | | | |

**博弈中常见的战略陷阱：**

| 陷阱 | 描述 | 避免方法 |
|------|------|----------|
| **囚徒困境式价格战** | 双方都认为降价是最好的个别选择，但都不降价对双方最好 | 寻找非价格维度的差异化 |
| **赢家诅咒式竞购** | 在竞拍/抢市场中出价过高，赢了标的但输了回报 | 预先设定"走开价"，超过坚决放弃 |
| **协和式沉船** | 已经投入太多所以不愿放弃，继续投入更多 | 只考虑未来成本和收益，沉没成本不是成本 |
| **模仿陷阱** | 竞对做什么你就做什么，失去了自己的战略独特性 | 回归"我们的独特优势是什么" |

### 第四步：决策可逆性评估

并非所有战略决策都同等重要。"不可逆决策"和"可逆决策"需要完全不同的决策流程。

**决策类型二分法：**

| 决策类型 | 特征 | 决策流程 | 案例 |
|----------|------|----------|------|
| **第一类（不可逆）** | 一旦做出几乎无法回头，或回头的代价极高 | 深度分析、多方意见、缓慢决策 | 收购另一家公司、放弃核心业务线、重大资本支出 |
| **第二类（可逆）** | 可以快速试验，不行就撤回，代价可控 | 快速试验、数据驱动、快速迭代 | 新功能上线、定价调整、渠道测试 |

**自问两个问题判断决策类型：**
1. 如果这个决策是错的，六个月后我能多容易地回到原点？
2. 在"做了但错了"和"没做但对了"之间，哪个代价更大？

**原则：第一类决策像乌龟（慢而慎重），第二类决策像兔子（快而频繁）。大多数公司把这两类搞反了。**

## L3 — 深度报告（重大决策前）

### 1. 多场景规划

不要做一个"最可能"的预测，构建三个场景：基准、上行、下行。

**场景规划模板：**

| 维度 | 基准场景 | 上行场景 | 下行场景 |
|------|----------|----------|----------|
| **核心假设** | 趋势延续 | 核心假设好于预期2倍 | 核心假设差于预期50% |
| **概率** | 50-60% | 15-25% | 15-25% |
| **行业格局** | | | |
| **我们的位置** | | | |
| **战略重心** | | | |
| **关键里程碑** | | | |

**场景规划的核心原则：**

- 为基准场景配置资源（不要为上行场景过度投入）
- 为下行场景保留缓冲（现金、可选方案、B计划）
- 确保上行场景发生时你有能力快速抓住（"可选性"比"确定性"更重要）

### 2. 战略节奏

好的战略不仅在空间上正确，在时间上也正确。太快和太慢都是战略失误。

**战略节奏框架：**

| 阶段 | 时间范围 | 核心任务 | 关键指标 | 常见错误 |
|------|----------|----------|----------|----------|
| **播种期** | 0-2年 | 建立核心能力、验证价值假设 | 产品-市场匹配度、学习速度 | 过早追求规模——用增长掩盖产品问题 |
| **增长期** | 1-5年 | 扩大规模、占领市场、建立护城河 | 市场份额、增长速率、效率指标 | 过早追求盈利——在应该抢地盘的时候开始守财 |
| **收割期** | 3-10年 | 最大化现金流、防御竞争、布局第二曲线 | 利润率、现金流、市场份额稳定性 | 过度收割——榨干了品牌但没培养未来 |

**节奏自检问题：**

1. 我们现在处在播种、增长还是收割阶段？
2. 上一阶段的"毕业条件"是否真的满足了，还是我们跳级了？
3. 如果市场环境突然恶化（下行场景触发），各阶段的节奏如何调整？

---

## 质量自检清单

- [ ] 每一个战略决策都完成了至少二阶推演（推演到竞对反应及其结果）
- [ ] 灯塔思维已经应用——有明确的"十年后我们在哪里"的图景，且倒推到了今天必须开始做什么
- [ ] 竞对博弈矩阵已经构建——不是假设他们不反应，而是推演了他们最可能的反应
- [ ] 决策被正确分类为第一类（不可逆）或第二类（可逆），并采用了匹配的决策流程
- [ ] 多场景规划完成——至少有基准、上行、下行三个场景及其对应的资源分配
- [ ] 战略节奏与当前所处阶段相匹配——没有在播种期追求收割期的指标
- [ ] "不做什么"被明确写下来了——战略的边界和战略本身同等重要
- [ ] 至少识别了一个"警示信号"——当前正在发生的短期主义行为

## 🔄 复盘锚点

每次战略复盘时，回到以下四个锚点：

1. **二阶锚点**：上次做的战略决策，实际发生的二阶效果（竞对反应、市场变化）是什么？与当时的推演相比，差异在哪里？差异是因为"推演逻辑错了"还是"出现了未预料的新变量"？

2. **灯塔锚点**：距离灯塔是在接近还是在偏离？过去一个周期的行动，有哪些是"重要但不紧急的灯塔建设"，有哪些是"紧急但不重要的救火"？两者的比例是否健康？

3. **博弈锚点**：竞争对手实际做出了什么你当时没有推演到的动作？这个"意料之外"揭示了他们对竞争格局的什么不同理解？

4. **节奏锚点**：我们当前所处阶段的"毕业条件"是否已经达成？如果已经达成，是否在进入下一阶段？如果还没有，我们是在耐心播种还是在焦虑中盲目加速？

**复盘节奏建议：**

| 复盘频率 | 复盘内容 | 参与人 |
|----------|----------|--------|
| 每月 | 战略决策的短期执行进展、警示信号扫描 | 战略执行团队 |
| 每季 | 二阶推演的"回测"——上次推演vs实际情况 | 核心管理层 |
| 每半年 | 灯塔距离评估、战略节奏检查、竞争格局变化 | 创始团队+核心管理层 |
| 每年 | 完整L3流程：多场景更新、灯塔重新校准、战略大方向确认 | 董事会+创始团队+外部顾问 |
