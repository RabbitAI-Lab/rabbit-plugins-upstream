# 营销文案生成

> **核心命题：人们不买你做什么，他们买你为什么做。信息的传递不等于信息的到达，到达不等于理解，理解不等于行动。**

营销文案的本质是在正确的时间、通过正确的渠道、用正确的叙事结构，将价值主张转化为客户行动。本手册提供从Why清晰度30秒测试到完整品牌叙事体系的三层框架。

---

## L1 快速判据（≤30秒）

### 一、Why清晰度测试（10秒）

闭上眼睛回答：**"我们的存在让世界哪一点不同了？"**

- 能用一句话（≤15字）讲清楚 → 通过
- 需要解释"我们做什么"而非"为什么做" → 不通过，进入L2
- 答案和3个竞品几乎一样 → 严重不通过，必须进入L2重构

### 二、差异化测试（10秒）

把品牌名遮住，你的文案是否能被客户识别出是你而非竞品？

- 是 → 通过
- 不确定 → 差异化不足
- 完全看不出 → 你的文案是行业通用模板

### 三、行动测试（10秒）

读完文案后，客户是否知道**下一步该做什么**？

- [ ] 有一条唯一的、清晰的行动指令（CTA）？
- [ ] CTA的门槛足够低（不是"立即购买"而是"免费试用"或"领取资料"）？
- [ ] 文案最后一句是否制造了紧迫感或好奇心缺口？

### 四、营销类型速判

| 类型 | 触发信号 | 适用策略 |
|------|----------|----------|
| **情感驱动** | 决策由情绪主导（奢侈品、娱乐、生活方式） | 用故事构建情感共鸣，Why放在最前面 |
| **数据驱动** | 决策由理性主导（B2B、SaaS、金融服务） | 用ROI数据构建信任，How和What优先 |
| **身份驱动** | 决策由社会认同主导（教育、社群、潮流） | 用"谁在用"构建归属感，社交证明优先 |
| **恐惧驱动** | 决策由风险规避主导（保险、安全、医疗） | 用"如果不做会怎样"构建紧迫感 |

> **如果以上四项中任一项未通过，立即进入L2分析。**

## L2 标准分析（~5分钟）

### 第一步：黄金圈构建（Simon Sinek框架）

```
外层 What  → 你卖什么产品/服务
中层 How   → 你用什么方式做得与众不同
内核 Why   → 你存在的意义，你相信什么
```

**黄金圈文案构建模板**：

| 层次 | 错误写法 | 正确写法 |
|------|----------|----------|
| Why | "我们致力于提供最好的XX" | "我们相信每个小企业主都值得拥有大公司的数据武器" |
| How | "用AI和大数据技术" | "用你也能看懂的方式，把复杂数据变成一句话建议" |
| What | "一套数据分析软件" | "每天早上8点，一条短信告诉你今天该做什么" |

**实操练习**：写下你的What → 连续追问5个"为什么重要" → 最后的答案才是你的Why。

### 第二步：空雨伞叙事结构

这是最普适的文案叙事框架，适用于90%的场景：

```
空（事实/现状）→ 雨（问题/危机/洞察）→ 伞（解决方案/行动号召）
```

| 步骤 | 功能 | 文案模板示例 | 字数占比 |
|------|------|------------|----------|
| **空** | 建立相关性，让读者点头 | "90%的淘宝卖家不知道，他们的主图在手机端被截断了30%" | 20% |
| **雨** | 制造紧迫感，让读者焦虑 | "这意味着你精心设计的卖点，客户根本看不到" | 30% |
| **伞** | 提供解决方案，让读者行动 | "用我们的一键主图适配工具，自动适配所有屏幕尺寸。免费检测你的店铺→" | 50% |

**变体：双空雨伞（对比型）**

| 步骤 | 功能 | 示例 |
|------|------|------|
| 空A（旧世界） | 描述痛苦的现状 | "还在用Excel手动对账到凌晨？" |
| 空B（新世界） | 描述理想的状态 | "5分钟自动生成财务报告" |
| 伞 | 桥接方案 | "XX财务助手，让AI替你加班" |

### 第三步：客户分型文案适配

| 客户类型 | 核心动机 | 标题公式 | 文案重点 | 视觉风格 |
|----------|----------|----------|----------|----------|
| **实用型** | 省钱/省时间/提效率 | "如何在[X]天内实现[Y]" | 数据+对比+ROI | 简洁、功能展示 |
| **情感型** | 感受/体验/故事 | "那个[人物]最后怎么样了" | 故事+画面感+情绪词 | 色彩丰富、人物为主 |
| **社交型** | 认同/归属/地位 | "和你一样的[X]人都在用" | 社交证明+社群+身份标签 | 真人场景、群体 |
| **探索型** | 新鲜/独特/新知 | "关于[X]，你之前知道的都是错的" | 新知+反常识+好奇心 | 视觉冲击、概念图 |
| **安全型** | 风险规避/确定性 | "如果不[X]，你可能会[Y]" | 风险量化+保障+案例 | 专业、信任符号 |

### 第四步：渠道适配策略

| 渠道 | 用户状态 | 文案长度 | 黄金结构 | 关键要素 |
|------|----------|----------|----------|----------|
| **短视频** | 被动接收、注意力碎片化 | 前3秒定生死 | 钩子(3s) → 空(5s) → 雨(10s) → 伞(5s) | 视觉冲击+字幕+强CTA |
| **图文（公众号/小红书）** | 主动浏览、可停留 | 标题>正文 | 标题(空+好奇心) → 正文(雨+伞) | 标题决定打开率、开头决定阅读率 |
| **直播** | 实时互动、冲动消费 | 循环话术 | 痛点(3min) → 方案(2min) → 逼单(1min) | 节奏感+限时限量+社交证明 |
| **搜索广告** | 主动搜索、意图明确 | 30字以内 | 关键词匹配+差异化卖点+CTA | 搜索词意图匹配度 |
| **落地页** | 已产生兴趣、深度了解 | 不限 | 完整空雨伞+信任构建+CTA | 加载速度+移动适配+信任元素 |
| **邮件/短信** | 已有关系、精准触达 | 50-150字 | 个性化开头+价值摘要+低门槛CTA | 打开率（标题）+点击率（CTA） |

## L3 深度报告（重大决策前）

### 一、品牌叙事体系构建

#### 品牌故事三层结构

| 层级 | 内容 | 使用场景 | 示例 |
|------|------|----------|------|
| **起源故事** | 创始人为什么创立这个品牌 | 品牌页、关于我们、媒体采访 | "当我看到父亲因为看不懂合同被坑了3万块……" |
| **价值故事** | 我们如何改变了某个客户的命运 | 案例页、销售话术、社交媒体 | "张姐用了我们的方法，一个月多赚了5000" |
| **愿景故事** | 我们相信的未来是什么样的 | 招聘、融资、行业演讲 | "我们相信未来的理财不再是富人的特权" |

#### 品牌语调（Tone of Voice）定义

| 维度 | 选择（二选一） | 你的选择 |
|------|--------------|---------|
| 正式 vs 口语 | 像写论文 vs 像和朋友聊天 | |
| 热情 vs 克制 | 充满感叹号和情绪词 vs 冷静理性 | |
| 幽默 vs 严肃 | 可以开玩笑 vs 保持专业 | |
| 个人 vs 机构 | 用"我/我们" vs 用"XX公司/平台" | |

**原则：选定了就不要摇摆——品牌语调的一致性比选哪种更重要。**

### 二、内容矩阵规划

#### 内容类型 × 客户阶段矩阵

| 内容类型 | 认知阶段 | 考虑阶段 | 决策阶段 | 留存阶段 |
|----------|----------|----------|----------|----------|
| 认知型内容（行业洞察/趋势） | ★★★ | ★★ | ★ | |
| 教育型内容（方法/指南） | ★ | ★★★ | ★★ | ★★ |
| 证明型内容（案例/评价） | | ★★ | ★★★ | ★ |
| 产品型内容（功能/演示） | | ★ | ★★★ | ★ |
| 社群型内容（活动/UGC） | | | ★ | ★★★ |

#### 发布节奏建议

| 频次 | 平台 | 内容类型 | 备注 |
|------|------|----------|------|
| 每日 | 短视频平台 | 认知型（轻） | 1条/天，重在曝光而非转化 |
| 每周2-3次 | 公众号/博客 | 教育型（中） | 深度内容，建立专业信任 |
| 每周1次 | 私域/社群 | 社群型（互动） | 维系关系，收集反馈 |
| 每月1-2次 | 直播 | 产品型+证明型（重） | 集中转化 |
| 每季度1次 | 全渠道 | 品牌叙事（深） | 品牌故事/大事件 |

## 质量自检清单

### 文案基本功

- [ ] 标题是否通过了"遮住品牌也认得出来"测试？
- [ ] 第一句话是否让人想读第二句话？
- [ ] 是否有且只有一个明确的CTA？
- [ ] 是否避免了行业黑话（用妈妈能听懂的话写）？
- [ ] 是否在3处以上用"你"而非"我们"？
- [ ] 数据是否有来源标注（杜绝"90%的人都……"这种无源数据）？
- [ ] 是否有社交证明（评价/案例/数据/权威背书）？
- [ ] 移动端阅读是否舒适（每段不超过3行）？

### 转化漏斗检查

- [ ] 不同渠道的文案是否做了适配而非简单复制粘贴？
- [ ] 从广告到落地页的信息是否一致（杜绝标题党）？
- [ ] 是否有针对不同客户类型的文案分支？
- [ ] 放弃购买后的挽回文案是否准备好了？

## 🔄 复盘锚点

### 每篇核心文案发布后（第7/30天）必复盘

| 指标 | 目标 | 实际 | 改进方向 |
|------|------|------|----------|
| 曝光量 | | | 渠道选择和标题质量 |
| 点击率（CTR） | | | 标题+封面吸引力 |
| 完读率/完播率 | | | 内容节奏和钩子设计 |
| 互动率（赞/评/转） | | | 情感共鸣度 |
| CTA点击率 | | | CTA位置+文案+门槛 |
| 转化率 | | | 整体叙事逻辑+信任构建 |
| 客户反馈内容 | | | 收集评论区真实声音 |

### 复盘核心问题

1. **前3秒Hook效果：** 如果是视频，0-3秒的完播率是多少？<70%说明Hook失败。
2. **信息传达到了吗：** 如果不看你的文案，让一个读者复述核心信息，他们能说出来吗？
3. **行动门槛合理吗：** 客户没行动的原因更可能是因为"不想做"还是"不知道怎么做到"？
4. **这个内容有复用价值吗：** 能否改编成另一个渠道的内容（如短视频改图文、图文改直播脚本）？
5. **竞品在说什么：** 抽查3个竞品最近的内容，你的文案是否有足够的差异性？

---

> **最好的营销文案不是说服客户购买，而是帮助客户做出他们本来就想做的决定。**
