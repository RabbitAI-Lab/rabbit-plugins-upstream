# 会计风控守门

> **核心命题：逆向思维——先列出"哪些财务错误会导致企业死亡"，再系统性规避。大多数企业不是死于亏损，而是死于现金流断裂；不是死于没有利润，而是死于把借来的钱当成了赚到的钱。**

> **免责声明：本手册内容仅供企业管理参考与思维框架借鉴，不构成任何专业财务、税务或法律建议。所有涉及财务、税务、法律的决策，请务必咨询持牌专业人士（注册会计师、税务师、律师）。企业具体情况千差万别，通用框架无法替代专业判断。**

## L1 快速判据（≤30秒）

### 五条财务死亡清单

以下是导致中小企业死亡的五大财务杀手。逐一核对，全部"安全"才算通过。

| 编号 | 死亡陷阱 | 危险信号 | 你的状态 | 致命等级 |
|------|----------|----------|----------|----------|
| **1** | **现金流断裂** | 账上现金不足支付未来3个月的固定支出 | ⚠️ 安全 / 🔴 危险 | ☠️☠️☠️☠️☠️ |
| **2** | **虚假收入/应收账款黑洞** | 应收账款总额 > 3个月营收，或单笔>20%总应收 | ⚠️ 安全 / 🔴 危险 | ☠️☠️☠️☠️ |
| **3** | **公私不分** | 老板个人账户和公司账户混用，个人消费走公司账 | ⚠️ 安全 / 🔴 危险 | ☠️☠️☠️☠️ |
| **4** | **税务违规** | 存在未申报收入、虚开发票、或长期零申报/亏损申报 | ⚠️ 安全 / 🔴 危险 | ☠️☠️☠️☠️☠️ |
| **5** | **隐形负债** | 存在未披露的担保、对赌协议、或有负债、高息民间借贷 | ⚠️ 安全 / 🔴 危险 | ☠️☠️☠️☠️ |

> **以上任意一项为"危险"，立即停止其他工作，优先解决该问题。这不是经营问题，是生存问题。**

### 补充速判指标

| 指标 | 安全线 | 警戒线 | 死亡线 |
|------|--------|--------|--------|
| 流动比率（流动资产/流动负债） | >2.0 | 1.0-2.0 | <1.0 |
| 速动比率（流动资产-存货）/流动负债 | >1.0 | 0.5-1.0 | <0.5 |
| 资产负债率 | <50% | 50-70% | >70% |
| 利息保障倍数（息税前利润/利息支出） | >3倍 | 1.5-3倍 | <1.5倍 |
| 月现金消耗率 | <月收入 | 接近月收入 | 持续>月收入 |

## L2 标准分析（~5分钟）

### 第一步：现金流压力测试

**执行三道压力测试**：

```
情景A（温和）：收入下降10%，应收账款回款延迟15天
情景B（严重）：收入下降30%，最大客户延迟付款60天
情景C（极端）：收入下降50%，两个最大客户同时违约
```

| 项目 | 情景A | 情景B | 情景C |
|------|-------|-------|-------|
| 当前现金余额 | | | |
| 预计现金流入（30天） | | | |
| 预计固定支出（30天） | | | |
| 预计可变支出（30天） | | | |
| **30天后现金余额** | | | |
| **能支撑多少天** | | | |
| **断流日期预估** | | | |

**压力测试后的行动框架**：

| 情景结果 | 行动 |
|----------|------|
| 三种情景下都不会断流 | ✅ 现金流健康，保持监控 |
| 仅情景C会断流 | ⚠️ 准备应急融资方案（银行授信/信用贷款额度） |
| 情景B就会断流 | 🔴 立即启动节流措施+积极融资 |
| 情景A就会断流 | 🆘 进入财务紧急状态 |

### 第二步：概率财务预测

抛弃"单一答案"的财务预测，使用三点估算法：

```
预测值 = (乐观值 + 4×最可能值 + 悲观值) / 6
标准差 = (乐观值 - 悲观值) / 6
```

| 预测项目 | 乐观 | 最可能 | 悲观 | 预测值 | 标准差 |
|----------|------|--------|------|--------|--------|
| 下月收入 | | | | | |
| 下月毛利率 | | | | | |
| 下月回款额 | | | | | |
| 月末现金余额 | | | | | |

**解读**：
- 预测值 ± 1个标准差 = 68%概率区间
- 预测值 ± 2个标准差 = 95%概率区间
- 如果悲观情景下现金余额为负，说明存在实质性断流风险

### 第三步：比率健康体检

#### 盈利能力

| 指标 | 公式 | 优良 | 一般 | 危险 |
|------|------|------|------|------|
| 毛利率 | (收入-成本)/收入 | >40% | 20-40% | <20% |
| 净利率 | 净利润/收入 | >15% | 5-15% | <5% |
| ROE（净资产收益率） | 净利润/净资产 | >15% | 8-15% | <8% |

#### 运营效率

| 指标 | 公式 | 优良 | 一般 | 危险 |
|------|------|------|------|------|
| 应收账款周转天数 | 应收/日均收入 | <30天 | 30-60天 | >60天 |
| 存货周转天数 | 存货/日均成本 | <45天 | 45-90天 | >90天 |
| 总资产周转率 | 收入/总资产 | >1.0 | 0.5-1.0 | <0.5 |

#### 偿债能力

| 指标 | 公式 | 优良 | 一般 | 危险 |
|------|------|------|------|------|
| 流动比率 | 流动资产/流动负债 | >2.0 | 1.0-2.0 | <1.0 |
| 已获利息倍数 | EBIT/利息 | >5倍 | 2-5倍 | <2倍 |

### 第四步：逆向崩溃排查

**假设公司明天突然倒闭，最可能的原因是什么？**

不要从"现在有什么问题"出发，而是从"死亡原因"反向排查：

| 死亡原因 | 排查问题 | 预防措施 |
|----------|----------|----------|
| 现金流枯竭 | 我们的现金还能维持多久？ | 保持3-6个月的固定支出储备 |
| 大客户流失 | 最大客户占收入多少%？失去他会怎样？ | <20%收入来自单一客户 |
| 关键人员流失 | 财务/核心技术掌握在谁手里？ | 交叉培训+流程文档化 |
| 合规风险爆发 | 有没有埋着的"雷"（税务/劳动/合同）？ | 定期合规审计 |
| 银行抽贷 | 如果银行明天要求还贷，我们能还吗？ | 多渠道融资，不把鸡蛋放一个篮子里 |
| 供应商断供 | 核心供应商有替代方案吗？ | 关键物料至少2家供应商 |

### 第五步：奥卡姆精简——财务流程去冗

| 精简项 | 常见冗余 | 精简后的健康状态 |
|--------|----------|----------------|
| 费用审批 | 每一笔都要CEO签 | 分级授权：<1000部门批，<10000分管副总批，>10000CEO批 |
| 报表数量 | 每月生成20+张报表没人看 | 保留5张核心报表（现金流/损益/应收/存货/人效） |
| 账户结构 | 10+个银行账户无法对账 | 精简到必要数量，确保每账户可追溯 |
| 科目体系 | 5级科目明细没人分得清 | 3级以内，确保每笔账能归到正确科目 |
| 对账流程 | 手工+Excel+邮件来回 | 尽可能自动化银行/平台对账 |

## L3 深度报告（重大决策前）

### 一、财务架构优化

#### 法律实体架构

| 架构模式 | 适用场景 | 核心考虑 |
|----------|----------|----------|
| **单一公司** | 业务单一，年收入<1000万 | 简单，但无风险隔离 |
| **控股+运营** | 业务多元或有资产持有需求 | 风险隔离，但税务筹划需专业意见 |
| **品牌+供应链分离** | 轻资产品牌+重资产生产 | 不同业务适用不同税务和风险管理 |
| **境内+境外** | 跨境业务 | 涉及转让定价、外汇管理，必须专业机构参与 |

**重要提示**：架构设计涉及复杂的税务和法律考量，必须由持牌专业机构根据具体情况设计，切勿按模板照搬。

#### 资金管理三原则

```
1. 隔离原则：公司资金和个人资金物理隔离，不得有任何混用
2. 预算原则：所有支出必须在预算框架内，超预算需要独立的审批流程
3. 对账原则：银行流水和账务系统至少每月对一次，差异必须当月处理
```

| 日期 | 事项 | 负责人 |

## 质量自检清单

### 日常财务纪律

- [ ] 是否做到了公司账户和个人账户的完全分离（没有任何一笔个人消费走公司账）？
- [ ] 是否有月度预算且实际支出与预算的偏差<15%？
- [ ] 是否每月核对银行流水和账务系统（且差异在当月处理完毕）？
- [ ] 应收账款是否有专人跟进（且账龄90天以上的应收占比<10%）？
- [ ] 税务申报是否在截止日前完成（从未逾期）？
- [ ] 是否有至少3个月的固定支出储备金（且这笔钱不用于任何其他用途）？
- [ ] 重要合同（借款/担保/投资/合作）是否有法律和财务双重复核？

### 财务风险红线（绝对不应触碰）

| 红线 | 说明 |
|------|------|
| 🚫 公私账户混用 | 不仅税务风险，更可能导致法人资格的"刺破公司面纱"——个人对公司债务承担连带责任 |
| 🚫 虚开发票 | 刑法第205条——虚开增值税专用发票罪，量刑可至无期徒刑 |
| 🚫 隐匿收入逃税 | 金税系统+银行流水可追溯，侥幸心理的代价远超省下的税款 |
| 🚫 高息民间借贷 | 利率超过法定上限部分不受法律保护，且常伴随暴力催收风险 |
| 🚫 用流动资金做长期投资 | 期限错配是现金流断裂的经典前奏 |
| 🚫 口头担保/对赌 | 所有担保和对赌必须以书面形式，且经法律审核——口头承诺是隐形负债的温床 |

## 🔄 复盘锚点

### 每月财务复盘

| 复盘项 | 数据来源 | 关键问题 |
|--------|----------|----------|
| **预算偏差** | 预算 vs 实际报表 | 偏差最大的3个项目是什么原因（收入少在哪/费用多在哪）？ |
| **现金流预测准确性** | 上月预测 vs 实际现金余额 | 预测偏差是否在±10%以内？偏差来自收入端还是支出端？ |
| **应收账款健康** | 应收账款账龄表 | 有没有新增的逾期应收？有没有"客户说下周付但说了三次"的情况？ |
| **异常交易** | 银行流水+账务系统 | 有没有大额、异常、或无法合理解释的交易？ |
| **税务合规** | 税务申报记录 | 所有应申报税种是否都在截止日前完成？有没有新出台的税务政策可能影响？ |
| **隐形负债扫描** | 合同台账+管理层确认 | 有没有新增的担保、对赌、或有负债？有没有"我觉得应该没问题的"口头承诺需要书面化？ |

### 复盘核心问题

1. **如果公司明天突然关门，我们有没有欠员工的钱、欠税务局的钱、欠供应商的钱——而且账上的钱够不够还？**
2. **上个月我做过的最危险的财务决定是什么？（如果回答"没有"，说明复盘不够诚实——每个经营者每天都在做包含财务风险的决定。）**
3. **我们最大的客户如果下周说"我们要延迟90天付款"，我们还能正常运转吗？**
4. **财务数据我每个月都在看，但我真的看懂了吗？还是只看了"银行余额"这一个数字？**
5. **有没有一笔钱我们花了，但我说不清楚它带来了什么回报？** ——这种支出是最应该被砍掉的。
6. **下一次市场下行（一定会有），我们准备好了吗？**

---

> **会计不是记给税务局看的——会计是记给你自己看的。好的财务记录让你在做每一个重大决定时都知道你在哪、你有多少弹药、你离悬崖还有多远。风控不是不冒险，是知道你冒的是什么险，以及最坏的结果你是否承受得起。**
