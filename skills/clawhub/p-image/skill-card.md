## Description:

Use when someone explicitly wants the fastest, cheapest photo generation — mood boards, bulk panels, or quick iterations — not when controlled photoreal or in-image text is needed.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Creators and developers use this skill to generate quick photos, mood-board images, and batches of visual variations from text prompts through Pruna's image API.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Optional companion-skill installation commands can fetch changing versions.

Mitigation: Review or pin companion skill versions before installation.

Risk: Image prompts and generation parameters are sent to Pruna's API.

Mitigation: Avoid confidential prompts and use the API only when this data sharing is acceptable.
