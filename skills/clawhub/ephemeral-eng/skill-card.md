## Description: <br>
Builds single-file HTML engineering calculators and report tools where the calculation interface doubles as the client-ready deliverable. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

### License/Terms of Use: <br>

## Use Case: <br>
Developers and engineers use this skill to create or revise browser-only engineering calculation tools, evaluation letters, and print-ready reports for hand-verifiable checks. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated engineering tools may contain calculation, unit, or code-reference errors if used before review. <br>
Mitigation: Keep the draft watermark active and complete engineer verification, including a digit-for-digit hand calculation check, before relying on outputs. <br>
Risk: Engineering code values or coefficients could be misapplied when source data is uncertain. <br>
Mitigation: Require engineer-entered values for uncertain code data and include source attribution for any AI-prepared inputs. <br>
Risk: The framework is not intended for complex analyses such as FEA, dynamic response, seismic response, or nonlinear coupled systems. <br>
Mitigation: Limit use to simple hand-verifiable checks and use validated commercial engineering software for out-of-scope analyses. <br>
