## 接口总览与主流程

|  # | 接口                 | 建议用途             | 核心输入           | 核心输出      |
| -: | ------------------ | ----------------------- | ----------------- | -------------------- |
|  1 | `searchVehicleV3`  | 按取还车时间与地点检索可租车型         | 取车/还车信息、用户 ID     | 车型、门店、距离、费用、可租车辆列表   |
|  2 | `getPriceDetailV3` | 查询选定车型/门店的费用明细与规则       | 车型编码、门店/围栏、取还车信息  | 应付金额、价格、保障服务、取消/服务政策 |
|  3 | `createOrder`      | 提交订单并生成订单号              | 用户、车型、门店、价格、取还车信息 | 订单号、状态、金额、费用说明       |
|  4 | `loginSkill`      | 自动注册，无需接收验证码     | 手机号    | 用户ID |
|  5 | `checkStoreGoOutSkill`      | 查询用户用车时间与门店歇业时间是否重叠，仅用于skill场景   | 门店号     | false表示不重叠，可以正常取车 |
|  6 | `orderDetailSkill`      | 查询用户的订单信息            | 手机号或者身份证号               | 可取消的订单code列表 |
|  7 | `userOrderListSkill`      | 查询用户可取消的订单            | 用户ID               | 可取消的订单列表 |
|  8 | `cancleOrdersV2`      | 用户取消订单前的信息确认            | orderCode               | 要扣取的金额以及要退回给用户的金额 |
|  9 | `cancleOrderV2`      | 确认取消订单      | orderCode，要扣取的金额，要退回的金额      | 取消状态：是否取消成功 |

## 通用约定

### 公共请求参数

| 字段               | 类型      | 说明                             |
| ---------------- | ------- | ------------------------------------------------------------ |
| `appKey`         | string  | 渠道接入标识。样例：`xzcxzfb`。       |
| `timeStamp`      | long    | 毫秒时间戳。样例为 2026 年的 13 位数值。           |
| `sign`           | string  | 请求签名。固定值+timestamp的md5值。                |
| `orderChannel`   | integer | 订单渠道。`createOrder` |
| `channelId`      | integer | 渠道 ID。样例：`11`。                   |
| `xiaodouChannel` | integer | 小豆渠道 ID。样例：`11`。      |

### 常见业务枚举

| 字段/场景           | 可用值              |
| --------------- | ---------------------------------------------------------------------------------- |
| `orderSource`   | `1` 普通订单；`2` 线下转线上；`3` 推客；`4` 门店推广；`5` 长租用车；`6` 政企用车。 |
| `channel`（车辆渠道） | `1` 小豆；`2` 同程；`3` 擎路。              |
| `addressType`   | `1` 免费接送；`2` 门店上门送取车；`3` 用户到店去还车。            |
| `isFence`       | `0` 否；`1` 是。         |

## searchVehicleV3：车型检索

### 业务描述

根据城市、经纬度、取车时间、还车时间检索附近可租门店和车型。接口会返回：

- 推荐展示的车型与车辆图片；
- 门店名称、距离、营业时间、取还车门店；
- 车辆参数、标签、押金、日历价、总价；
- 同一车型下的车辆候选列表 `vehicleList`。

### 请求参数

| 字段               | 类型      |  必填 | 说明                          |
| ---------------- | ------- | :-: | --------------------------- |
| `pickupInfo`     | object  |  是  | 取车位置与时间。                    |
| `returnInfo`     | object  |  是  | 还车位置与时间。                    |
| `filter.groupId` | integer |  否  | 车型组过滤。样例 `0`，通常表示不过滤。       |
| `groupOrderId`   | string  |  否  | 团购订单 ID。              |
| `userId`         | string  |  是  | 请求方用户唯一 ID。                 |
| `xdChannel`      | integer |  否  | 小豆渠道 ID。 |

`pickupInfo` / `returnInfo`：

| 字段             | 类型     | 说明                             |
| -------------- | ------ | ------------------------------ |
| `address`      | string | 详细地址名称。                        |
| `city`         | string | 城市名称。                          |
| `cityCode`     | string | 城市编码。样例：`130100`，根据查表获取。      |
| `districtName` | string | 区县名称。                          |
| `lat` / `lng`  | number | 纬度 / 经度。                       |
| `date`         | string | 取车或还车时间，格式 `yyyy-MM-dd HH:mm`。 |

### 响应结构

#### 顶层

| 字段                             | 类型      | 说明                     |
| ------------------------------ | ------- | ---------------------- |
| `success`                      | boolean | 业务是否成功。                |
| `code`                         | integer | 业务码。样例：`20000`。        |
| `data.modelList`               | array   | 车型列表。                  |
| `data.modelList[].modelName`   | string  | 品牌车系展示名。样例：`奥迪 奥迪A6L`。 |
| `data.modelList[].logo`        | string  | 车型图片 URL。              |
| `data.modelList[].vehicle`     | object  | 推荐展示的门店车辆对象。           |
| `data.modelList[].vehicleList` | array   | 同一车型下的车辆/门店候选列表。       |
| `data.modelList[].topCar`      | boolean | 是否置顶车型。                |

#### `vehicle` / `vehicleList[]`

| 字段                                   | 类型      | 说明                   |
| ------------------------------------ | ------- | -------------------- |
| `storeCode` / `storeName`            | string  | 门店编码 / 名称。           |
| `businessHours`                      | string  | 门店营业时间。              |
| `isWinnowStore`                      | boolean | 是否优选门店。              |
| `isPickupOndoor` / `isPickoffOndoor` | integer | 是否支持上门送车 / 上门收车。     |
| `isFence`                            | integer | 是否围栏取送车。默认值为1 |
| `fenceCode`                          | string  | 围栏编码，后续价格明细会使用。      |
| `distance`                           | number  | 距离，单位按米计算。 |
| `pickupStore` / `returnStore`        | object  | 实际取车 / 还车门店信息。       |
| `rentalDays`                         | number  | 租期天数。                |
| `channel`                            | integer | 车辆渠道。                |

#### `vehicle.vehicle`

| 字段                         | 类型              | 说明              |
| -------------------------- | --------------- | --------------- |
| `id`                       | string          | 车辆资源 ID。        |
| `modelCode`                | string          | 车型编码，用于价格明细和下单。 |
| `modelName`                | string          | 具体款型名称。         |
| `brandName` / `seriesName` | string          | 品牌 / 车系。        |
| `groupName` / `groupId`    | string / string | 车型组名称 / ID。     |
| `passengerNumber`          | integer         | 核载人数。           |
| `transmissionType`         | string          | 变速箱类型；默认自动挡。   |
| `displacement`             | string          | 排量。             |
| `carYear`                  | string          | 年款。             |
| `fuelType`                 | integer         | 燃料类型    |
| `tags`                     | string          | 车辆标签 ID，逗号分隔。   |
| `choiceness`               | integer         | 精选标识。    |
| `isTopCar`                 | integer         | 是否置顶车辆。         |

#### `feeInfo`

| 字段                                               | 类型      | 说明                |
| ------------------------------------------------ | ------- | ----------------- |
| `sesametype`                                     | integer | 信用/芝麻免押类型。 |
| `depositAmount`                                  | number  | 租车押金。             |
| `violationAmount`                                | number  | 违章押金。             |
| `basicInsuranceFee`                              | number  | 基础保障费。            |
| `serviceFee`                                     | number  | 基础服务费/手续费。      |
| `nightServiceFee`                                | number  | 夜间服务费。    |
| `doorToDoorSendCarFee` / `doorToDoorTakeCarFee`  | number  | 上门送车 / 上门收车服务费。|
| `activitySubAmount`                              | number  | 活动优惠金额。     |
| `discountAmount`                                 | number  | 优惠金额。             |
| `standardUnitPrice` / `standardTotalPrice`       | number  | 标准日单价 / 标准总价。  |
| `unitPrice` / `amount`                           | number  | 展示单价 / 订单金额。    |
| `afterDiscountUnitPrice` / `afterDiscountAmount` | number  | 优惠后单价 / 优惠后金额。 |
| `calendarPriceMap`                               | object  | 日期到日租金的映射。     |
| `isGiftDiscount`                                 | integer | 是否赠送优惠。    |

## getPriceDetailV3：价格明细

### 业务描述

在选定车型与门店后查询精确价格、保障服务、取消政策、门店规则与取还车门店信息。该接口返回的 `payAmount`、`calendarPriceMap`、服务编码、围栏编码等通常应作为下单参数来源，避免前端自行计算价格。

### 请求参数

| 字段                          | 类型      |  必填 | 说明                       |
| --------------------------- | ------- | :-: | ------------------------------------------------ |
| `modelCode`                 | string  |  是  | 车型编码，来自车型检索。    |
| `storeCode`                 | string  |  是  | 门店编码。  |
| `fenceCode`                 | string  |  否  | 围栏编码，来自车型检索。 |
| `orderType`                 | integer |  否  | 订单类型。样例 `0`。 |
| `addedServices`             | string  |  否  | 附加服务编码，多个服务建议使用逗号分隔； |
| `activitySubAmount`         | number  |  否  | 活动优惠金额。样例 `0`。        |
| `isBlindBoxOrder`           | integer |  否  | 是否盲盒订单。样例 `0`。  |
| `isGroupOrder`              | integer |  否  | 是否团购单。样例 `0`。   |
| `channel`                   | integer |  是  | 车辆渠道。样例 `1`。  |
| `pickupInfo` / `returnInfo` | object  |  是  | 取还车位置、时间与地址类型。 |

`pickupInfo` / `returnInfo` 额外字段：

| 字段            | 类型      | 说明                                     |
| ------------- | ------- | -------------------------------------- |
| `addressType` | integer | 地址类型：`1` 免费接送；`2` 门店上门送取车；`3` 用户到店去还车。 |

### 响应结构

#### 顶层与价格

| 字段                                    | 类型      | 说明                    |
| ------------------------------------- | ------- | --------------------- |
| `data.payAmount`                      | number  | 应付金额。                 |
| `data.priceInfo.quantity`             | number  | 计费数量，通常为租期天数。         |
| `data.priceInfo.standardUnitPrice`    | number  | 标准日单价。                |
| `data.priceInfo.standardTotalPrice`   | number  | 标准总价。                 |
| `data.priceInfo.basicInsuranceFee`    | number  | 基础保障费。                |
| `data.priceInfo.serviceFee`           | number  | 手续费/服务费。              |
| `data.priceInfo.doorToDoorSendCarFee` | number  | 上门送车服务费。              |
| `data.priceInfo.doorToDoorTakeCarFee` | number  | 上门收车服务费。              |
| `data.priceInfo.calendarPriceMap`     | object  | 每日租金映射。               |
| `data.sesameType`                     | integer | 芝麻/信用免押类型。            |
| `data.violationAmount`                | number  | 违章押金。                 |
| `data.depositAmount`                  | number  | 租车押金。                 |
| `data.activitySubAmount`              | number  | 活动优惠金额。               |
| `data.reminderTime`                   | -       | 提前预订提醒时间。 |
| `data.channel`                        | integer | 车辆渠道。                 |

#### `insuranceServiceList[]` 保险保障服务

| 字段                                       | 类型      | 说明         |
| ---------------------------------------- | ------- | ----------------------------------- |
| `storeServiceId` / `serviceCode`         | string  | 服务 ID / 服务编码，下单时用。|
| `serviceName`                            | string  | 服务名称。基础保障、优享保障、尊享保障|
| `serviceDesc`                            | string  | 服务说明。   |
| `price` / `amount` / `quantity` / `unit` | -       | 单价、总金额、数量、计费单位。|
| `isFixed` / `fixed`                      | boolean | 是否固定必选服务。 |
| `basicInsurance`                         | boolean | 是否基础保障。|
| `chargeMode`                             | integer | 计费模式。 |
| `styleType`                              | integer | 前端展示样式。 |
| `includes` / `excludes`                  | array   | 保障包含 / 排除项。 |

#### `cancelPolicyList[]` 取消政策

| 字段                   | 类型      | 说明                       |
| -------------------- | ------- | ------------------------ |
| `type`               | integer | 阶段类型；样例 `1` 取车前，`2` 取车后。 |
| `title` / `content`  | string  | 阶段标题 / 取消后果。             |
| `time`               | string  | 展示时间段。                   |
| `from` / `to`        | string  | 起止时间。                    |
| `penaltyRatio`       | number  | 违约金比例，`1.0` 表示 100%。     |
| `aheadPickupMinutes` | integer | 距取车时间的分钟数阈值。             |

#### `servicePolicyList[]` 服务政策

| 字段                                          | 类型      | 说明              |
| ------------------------------------------- | ------- | --------------- |
| `id`                                        | string  | 政策 ID。          |
| `channelId` / `channelType` / `channelName` | -       | 政策来源渠道信息。       |
| `type`                                      | integer | 政策类型。  |
| `ruleTag`                                   | string  | 规则标签。           |
| `ruleTitle`                                 | string  | 规则标题。           |
| `ruleDesc`                                  | string  | 规则描述，适合前端原文展示。  |
| `ruleTemplate`                              | string  | 规则模板，可能包含变量占位符。 |
| `sort`                                      | integer | 排序值。            |
| `createTime` / `updateTime`                 | string  | 创建 / 更新时间。      |

#### `pickupStore` / `returnStore`

| 字段                                 | 类型               | 说明             |
| ---------------------------------- | ---------------- | -------------- |
| `name` / `code`                    | string           | 门店名称 / 编码。     |
| `cityCode`                         | string           | 城市编码。          |
| `lat` / `lng`                      | number           | 门店纬度 / 经度。     |
| `address`                          | string           | 门店地址。          |

## createOrder：创建订单

### 业务描述

提交用户身份、车型、门店、费用、附加服务和取还车计划，创建租车订单。订单创建成功后返回 `orderCode`，后续可用 `orderDetail` 查询完整订单信息。

### 请求参数

| 字段                          | 类型      |  必填 | 说明                           |
| --------------------------- | ------- | :-: | ---------------------------- |
| `userId`                    | string  |  是  | 用户唯一 ID。                     |
| `modelCode`                 | string  |  是  | 车型编码。                        |
| `payAmount`                 | number  |  是  | 订单应付金额。这个是最终租车的总价。  |
| `userInfo`                  | object  |  是  | 主驾驶员信息。                      |
| `orderSource`               | integer |  是  | 订单来源。                        |
| `isFence`                   | integer |  是  | 是否围栏：`0` 否，`1` 是。 一般为1 |
| `activitySubAmount`         | number  |  否  | 活动优惠金额。  一般为0  |
| `addedServiceList`          | array   |  否  | 附加服务对象列表。 |
| `addedServices`             | string  |  否  | 附加服务编码，多个用逗号分隔。 |
| `doorToDoorSendCarFee`      | number  |  否  | 商家上门送车服务费。                   |
| `doorToDoorTakeCarFee`      | number  |  否  | 商家上门收车服务费。                   |
| `storeCode`                 | string  |  是  | 门店编码。                        |
| `calendarPriceMap`          | object  |  是  | 每日租金映射，应来自价格明细。该字段不外显 |
| `standardTotalPrice`        | number  |  否  | 标准总价。外显时显示租车总价|
| `channel`                   | integer |  是  | 车辆渠道类型：`1` 小豆；`2` 同程；`3` 擎路。 |
| `extendInfo` | object  |  是  | 扩展信息，从价格查询结果透传过来的。            |
| `channelMerchantDiscountsFee` | integer  |  是  | 优惠金额。            |
| `thirdStore` | object  |  是  | 门店信息。 从价格明细中的pickupStore获取          |

`userInfo`：

| 字段       | 类型      | 说明                    |
| -------- | ------- | --------------------- |
| `name`   | string  | 驾驶人姓名。                |
| `idType` | integer | 证件类型。样例 `1`。 |
| `idNo`   | string  | 证件号码。                 |
| `mobile` | string  | 手机号。                  |

`pickupInfo` / `returnInfo`：

| 字段                                               | 类型      | 说明                                |
| ------------------------------------------------ | ------- | --------------------------------- |
| `address` / `city` / `cityCode` / `districtName` | string  | 地址、城市、城市编码、区县。 |
| `lat` / `lng`                                    | number  | 纬度 / 经度。   |
| `date`                                           | string  | 取车或还车时间。 |
| `addressType`                                    | integer | `1` 免费接送；`2` 门店上门送取车；`3` 用户到店去还车。 |
| `fenceCode`                                      | string  | 围栏编码。 |

## cancleOrdersV2：取消订单前的查询

### 业务描述

根据订单号查询待退订单前的详情。

### 请求参数

| 字段          | 类型     |  必填 | 说明   |
| ----------- | ------ | :-: | ---- |
| `orderCode` | string |  是  | 用户手机号 。 |

### 响应字段

| 字段                      | 类型      | 说明                                        |
| ----------------------- | ------- | ----------------------------------------- |
| `deduction`              | number  | 扣取金额。 |
| `message` | string  | 接口返回的消息，OK 表示成功。          |
| `groupCancels` | list  | 团购相关      |
| `payments` | integer  | 支付状态，0表示未支付，1表示已支付。      |
| `refundAmount` | number  | 退费金额。      |
| `returnAmount` | number  | 退费金额，暂时用不到。      |
| `status` | integer  | 返回状态，1表示正常。      |

### 请求示例

```json
{
	"appKey": "xzcxzfb",
	"timeStamp": 1792650048091,
	"sign": "b905db552de1cc71b0344234b0793092",
	"orderChannel": 3,
	"channelId": 11,
	"xiaodouChannel": 11,
	"orderCode": "901088tcRA"
}
```

### 响应示例

```json
{
    "deduction": 0.0,
    "groupCancels": [],
    "message": "OK",
    "payments": 1,
    "refundAmount": 14.0,
    "returnAmount": 14.0,
    "status": 1
}

```

## cancleOrderV2：确认取消订单

### 业务描述

根据订单号取消订单。注意：确认取消订单分为两种情况，一种是未支付，此时直接调用该接口传入orderCode即可取消；另一种是已支付待提车，这种情况需要先调用cancleOrdersV2查询相关信息再做取消

### 请求参数

| 字段          | 类型     |  必填 | 说明   |
| ----------- | ------ | :-: | ---- |
| `orderCode` | string |  是  | 订单号 。 |
| `refundReason` | string |  是  | 订单取消原因，固定值:skill渠道取消订单退款 。 |
| `deduction` | string |  是  | 扣取金额 。 |
| `cancelReasonId` | string |  是  | 固定值：1004 。 |
| `otherReason` | string |  是  | 固定值，为空 。 |
| `refundAmount` | string |  是  | 要退的金额，从cancleOrdersV2中获取的 。 |
| `groupCancels` | string |  是  | 固定值：空数组 。 |

### 响应字段

| 字段                      | 类型      | 说明                                        |
| ----------------------- | ------- | ----------------------------------------- |
| `status`              | integer  | 返回状态。 |
| `message` | string  | 接口返回的消息，取消成功 表示成功。                          |
| `returnAmount` | number  | 固定值：0.0。                          |

### 请求示例1，未支付取消

```json
{
    "appKey":"xzcxzfb",
    "timeStamp":1792649498811,
    "sign":"84748feb24e373d7d8940bb8136cd7ad",
    "orderChannel":3,
    "channelId":11,
    "xiaodouChannel":11,
    "orderCode":"485993urZQ",
    "refundReason":"取消订单退款",
    "cancelReasonId":"1001",
    "otherReason":""
}
```

### 响应示例1

```json
{"message":"取消成功","returnAmount":0.0,"status":1}
```

### 请求示例2，已支付待提车取消
```json
{
	"appKey": "xzcxzfb",

	"refundReason": "取消订单退款",
	"deduction": 0,

	"otherReason": "",
	"refundAmount": 14,
	"groupCancels": []
}

```
### 响应示例2
```json
{"message":"取消成功","returnAmount":0.0,"status":1}
```
