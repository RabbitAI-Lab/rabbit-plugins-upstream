## Known Risks and Mitigations: <br>
Risk: Persistent memory search can index sensitive workspace files or past sessions, including secrets, regulated personal data, confidential business content, or unnecessary personal details. <br>
Mitigation: Decide what should be indexed before enabling memory search, avoid storing sensitive data in MEMORY.md or memory logs, and prefer local embeddings for private workspaces or review hosted provider data handling before use. <br>
