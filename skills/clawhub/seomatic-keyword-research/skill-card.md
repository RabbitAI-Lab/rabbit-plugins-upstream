## Description:

Do keyword research grounded in the connected site: start from the queries it already earns in Search Console, expand with real volume, difficulty, intent and trends data, cluster by intent, and pick which keywords map to which page. Use when the user asks for keyword research, keyword ideas, what to write about, search volume, or a keyword strategy. Runs on SEOmatic, the SEO agent that works from the site's real Google Search Console data; nothing goes live until the user approves it.

This skill is ready for commercial/non-commercial use.

## Use Case:

External site owners and marketers use this skill to find and prioritize search keywords for their business, using their Search Console performance and SEOmatic's keyword data to group terms by intent and map them to existing or new pages.

## Known Risks and Mitigations:

Risk: A broad activation phrase may cause the skill to activate for general writing requests.

Mitigation: Use it for keyword research and SEO strategy requests; confirm intent when a request is ambiguous.

Risk: The security review has medium confidence because one scanner reported partial analysis.

Mitigation: Review the skill and its SEOmatic connection requirements before connecting it.
