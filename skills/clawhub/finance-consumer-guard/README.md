# 金融消保合规护栏 (finance-consumer-guard)

在银行理财 / 保险 / 基金 / 资管等金融产品的营销文案、销售话术、广告、官网介绍、对外宣传**发布前**，
实时检测"保本保收益（刚兑）、收益承诺夸大、风险弱化误导、过往业绩误导、无资质代客理财、广告极限词"相关的
高频违规 / 高风险表述，按风险分级输出命中与整改建议。纯本地运行，零网络请求。

## 检测范围（6 类）

| 类别 | 风险 |
|------|------|
| 保本保收益 / 刚兑红线 | high |
| 收益承诺 / 夸大 | high |
| 风险弱化 / 误导 | high |
| 过往业绩误导 | medium |
| 无资质 / 代客理财 | high |
| 广告极限词 | medium |

## 快速开始

```bash
python3 scripts/guard.py --text "本理财产品保本保收益，稳赚不赔，低风险高收益"

# JSON 输出（Agent 消费）
python3 scripts/guard.py --text "我们代客理财，保证操盘收益" --format json

# 列出类别
python3 scripts/guard.py --list-categories
```

## 依据（全文公开）

- 《关于规范金融机构资产管理业务的指导意见》（银发〔2018〕106号，资管新规）
- 《商业银行理财业务监督管理办法》（银保监会2018年第6号）
- 《理财公司理财产品销售管理暂行办法》（银保监会2021年第4号）
- 《保险销售行为管理办法》（2024年施行）
- 《中华人民共和国广告法》第二十五条

国家金融监督管理总局 / 人民银行 / 证监会官网可查。所引用法规原文属政府公开信息，请以官方发布版本为准。
