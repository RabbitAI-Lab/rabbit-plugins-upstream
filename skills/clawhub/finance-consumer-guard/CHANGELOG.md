# Changelog

## v1.0.0 (2026-08-09)

- 初始发布：金融消保合规护栏
- 覆盖《关于规范金融机构资产管理业务的指导意见》（银发〔2018〕106号，资管新规，打破刚兑）、《商业银行理财业务监督管理办法》（银保监会2018年第6号）、《理财公司理财产品销售管理暂行办法》（银保监会2021年第4号）、《保险销售行为管理办法》（2024年施行）、《中华人民共和国广告法》第二十五条
- 6 类检测：保本保收益(刚兑) / 收益承诺夸大 / 风险弱化误导 / 过往业绩误导 / 无资质代客理财 / 广告极限词，共 36 条违规表述
- 检测内核（scripts/guard.py）与规则包（scripts/rules/terms.py）分离，纯 stdlib、零网络、零动态执行
- 风险分级 high/medium/low + 逐条整改建议；JSON/文本双输出；重叠命中智能去重
- 与深度检查 / 审计工具（check / audit 形态）构成"轻 guard + 重 check / audit"组合
