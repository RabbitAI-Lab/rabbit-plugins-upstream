## Known Risks and Mitigations: <br>
Risk: Remote installer commands may execute code from the network. <br>
Mitigation: Review the installer commands before running them and prefer least-privilege installation where practical. <br>
Risk: Grok Build can edit files, run shell commands, use the network, and rely on authenticated browser sessions. <br>
Mitigation: Run it with the least privilege practical for the project and review proposed changes before accepting them. <br>
