## Description:

Redesigns GitHub READMEs or creates project-specific visual assets, with preview and visual verification.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dtsola](https://clawhub.ai/user/dtsola)

### License/Terms of Use:

MIT

## Use Case:

Developers and repository maintainers use this skill to improve a GitHub README or create standalone SVG, raster, and animated visuals while reviewing previews before changes are published.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Unreviewed README edits, publication, or GIF output overwrites.

Mitigation: Review proposed diffs and previews; require explicit approval before editing, committing, pushing, opening a PR, or overwriting GIF output.
