# 文档格式化排版（gongwen-format）安装说明

**版本**：v2.1.0 ｜ **作者**：胡立敏 ｜ **类型**：Claude Code 技能（Skill，兼容 cc-haha 桌面端）

一个把 Word 或 Markdown 文档一键排版为符合党政机关公文国标（GB/T 9704-2012 / GB/T 33476.2-2016）的 Claude Code 技能：字体字号行距标题自动合规、表格美化（表头黑体/数据仿宋/居中）、图片防裁剪处理、图题表题规整、大纲级别导航层级树。**只改格式，不改正文内容。**

---

## 一、包内容清单

```
gongwen-format/
├── SKILL.md                 技能说明（frontmatter 含 name/display_name/author/version/description）
├── 安装说明.md              本文件
├── references/
│   └── guobiao-params.md    国标参数速查表（字号/字体/边距/版记/页码）

│   ├── format.py            Word → 国标排版（主入口）

```

## 二、安装方法（三选一）

### 方法 1：复制到技能目录（推荐）

1. 把整个 `gongwen-format/` 目录复制到 Claude Code 用户技能目录：
2. 选择「导入 / 从文件夹安装」，选中解压后的 `gongwen-format` 文件夹
3. 安装完成后，在技能列表确认显示中文名「文档格式化排版」

### 方法 2：手动复制（迁移到新电脑）

把整个 `gongwen-format` 文件夹复制到目标机器的技能目录：

```
Windows:  C:\Users\<用户名>\.claude\skills\gongwen-format\
macOS:    ~/.claude/skills/gongwen-format/
```

然后**新建会话**（技能在会话启动时扫描，中途新增需重开会话生效）。

### 方法 3：对话内安装

在 Claude Code / cc-haha 对话里说：「帮我把这个文件夹安装为技能」，Agent 会按规范完成安装与校验。

## 三、运行依赖（一次性准备）

技能的排版引擎依赖 Python + python-docx：

| 依赖 | 要求 | 安装 |
|---|---|---|
| Python | ≥ 3.10 | 官网安装即可 |
| python-docx | 任意近期版本 | `pip install python-docx`（推荐装入独立 venv）|

推荐建独立虚拟环境（不污染系统 Python）：

```bash
python -m venv "%USERPROFILE%\.gongwen-check-venv"
"%USERPROFILE%\.gongwen-check-venv\Scripts\pip.exe" install python-docx
```

> 排版时 Agent 会自动寻找可用的 Python；无环境时会提示安装。字体（仿宋/黑体/楷体/方正小标宋）由 Word/WPS 在缺字体时自动回退，无需额外安装。

## 六、已知边界（使用前知悉）

1. 不自动改正文页脚页码（避免破坏原页脚域）；页码国标为 4 号宋体、`— 1 —` 一字线、单页右/双页左，需在 Word 手工设置（自动化版本规划中）
2. 不探测印章是否加盖，只调整落款日期右空字数
3. 信函/命令/纪要等特定格式公文的专属版式暂不支持
4. Markdown 图片需本地文件路径；Word 原有页眉/页脚内容不会被改动

## 七、版本记录

- **v2.1.0**（2026-09-11，胡立敏）：章节层级与编号体系重大升级。
  - **章节序号自动编号（Word numPr）**：Markdown `#/##/###/####` 自动映射公文 4 级（一、/（一）/1.），挂 Word 自动编号（abstractNumId=100；ilvl 0–3 对应 chineseCounting / chineseCounting / decimal / decimal，lvlText 为 `%1、`/`（%2）`/`%3.`/`（%4）`）；手册、技术文档的章节层级坍塌问题彻底解决。
  - **编号字体修正**：自动编号各级 `w:lvl` 补齐 `w:rPr`（rFonts + sz），一级黑体、二级楷体、三级/四级仿宋，统一三号（16pt），与对应章节标题 run 字体、字号一一对应。
  - **四级标题支持**：新增 `#####` → 第 4 级「（1）」仿宋三号（16pt）、大纲 5 级；Word 路径启发式 `^[（(]\d+[)）]` 识别四级编号；`classify.py` 层级 4 由带圈数字改为「（1）」式；严格对齐 GB/T 9704-2012 §7.3.3.2「一、→（一）→1.→（1）」。
  - **新增序号正确性检查器 `layer-numbering`（检查器第 10 项）**：`checks/check_numbering.py` 扫描含层次序数前缀或 numPr 的段落——层级跳跃 / 同层序号重复 = ERROR；不连续缺号 / 序号回退 / 起点非一级 / 嵌套不符 = WARN；Word 路径 `check.py` 自动纳入，md 路径排版后在变更报告生成独立「## 层次序号正确性检查」专节（❌/⚠️ 标记）。
  - **复查与打包**：三处文本 Grep + 四份 docx 二进制扫描 + zip 内文本二次扫描，确认双平台安装包内容一致、解压即用；产出 `gongwen-format-v2.1.0.zip`（通用版）与 `gongwen-format-qwen-v2.1.0.zip`（千问版），各 26 条目、解压即用。
- **v2.0.0**（2026-09-05，胡立敏）：重建版。新增表格美化、图片防裁剪与居中、图题表题角色（IMAGE/CAPTION）、大纲级别导航层级（标题 1 级→"一、"2 级→"（一）"3 级→"1."4 级）、Markdown 表格/图片语法支持、超宽图片等比缩放。
- v1.x：早期脚本版（已废弃）。
