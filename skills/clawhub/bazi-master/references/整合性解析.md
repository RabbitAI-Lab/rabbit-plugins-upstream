# 整合性解析（人生综合论断）

> 本文件定义"整合性解析"这一输出维度：把前面所有静态分析（旺衰 / 用神 / 格局 / 十神 / 神煞 / 大运）**合成一段连贯的人生叙事**，覆盖性格内核、人生节律（过去与当下）、财运、家庭六亲、健康，并落到改善方向。
> 它与"逐维度分析"互补：逐维度讲"是什么、为什么"，整合解析讲"这人这一生大致怎么走、钱从哪来、家是什么样"。

---

## 一、为什么要整合

八字是静态的"出厂设置"，大运是动态的"使用节律"。分开看十神容易变成术语堆砌；整合解析的价值在于：

- 把**大运时间轴**套到人生上，区分"过去（已走过的运）""当下（当前运）""未来（未到之运）"。
- 把**用神喜忌**落到具体领域（财、家、业），给出方向而非标签。
- 把**宫位 + 六亲十神**合成家庭画像（父母、配偶、子女各自在哪一柱、是什么十神、旺衰如何）。

---

## 二、整合框架（输出顺序）

### 1. 性格内核（一句话定性）

综合：**日主旺衰 + 主导十神（最旺的十神）+ 关键神煞**。

- 食伤旺 → 聪秀、表达强、不服管、主意大。
- 官杀旺 → 自律 / 压力大、责任感强、易遇权威张力。
- 印旺 → 思虑重、喜学习、偏被动 / 依赖。
- 财旺 → 务实、重物质、会来事。
- 比劫旺 → 重义气、朋辈影响大、竞争者多。

一句定性示例："外表温和、内里主意极硬；靠本事吃饭，不喜被人管。"

### 2. 人生节律（过去 + 当下 + 趋势）

- 先用**起运岁数 + 顺逆**定时间轴（见《排盘算法全书》大运章）。
- 用每段大运干支 + 用神喜忌，判定十年顺逆。
- **过去**：哪些大运已走完？是助运（用神到位）还是逆运（忌神当道）？对性格养成、家境、学业、早期事业的影响。
- **当下**：结合**求测年份**定当前落在哪一个大运、哪一步流年；此运基调如何。
- **趋势**：未来 5–10 年关键转折（用神运何时到、忌神运何时退）。
- 用"限运"辅助切片：年柱 1–18、月柱 19–35、日柱 36–53、时柱 54+（见《大运流年论断》）。

### 3. 财运

- 看原局**财星**（正财 / 偏财）有无、透干与否、旺衰、是否被用神生扶或被比劫 / 忌神所夺。
- 看哪些大运**带财**（财星透干或被引动）：身旺喜财 → 财运得财；身弱 → 财来财去、不胜财。
- 结合行业用神：用金水则金水相关财，用木火则木火相关。
- 给方向：财从哪来（主业 / 偏财 / 技艺）、何时利、何时宜守。

### 4. 家庭与六亲

按**四柱宫位 + 六亲十神**合成：

| 宫位 | 代表 | 六亲十神取法 |
|------|------|--------------|
| 年柱 | 祖上 / 幼年环境 | 祖父辈、早年家境 |
| 月柱 | 父母宫 + 兄弟宫 | 偏财为父、正印为母；比劫为兄弟姐妹 |
| 日支 | 配偶宫 | 男看正财、女看官杀；藏干看配偶特质 |
| 时柱 | 子女宫 + 晚年 | 食伤为子女；空亡 / 冲克看子女缘 |

- 结合神煞（桃花、孤辰寡宿、空亡落宫）补细节，不夸大。
- 只论"关系性质与趋势"，不臆测具体事件、不夸张灾厄。

### 5. 健康（简要 + 免责）

- 五行偏枯、过旺过弱对应的脏腑：金（肺 / 大肠）、木（肝 / 胆）、水（肾 / 膀胱）、火（心 / 小肠）、土（脾胃）。
- 冲克、空亡落宫提示的薄弱系统。
- **必加免责**：命理非医学诊断，以现代医学为准。

### 6. 改善方向（收尾，交还主动权）

- 用神方位 / 行业 / 季节。
- 1–3 条可操作建议，扣住"命是出厂设置，运是使用方式"。

---

## 三、整合解析的纪律

- 不脱离前面维度凭空编故事；每一句人生叙事都要能指回"大运 / 十神 / 用神 / 宫位"某一处。
- 过去 / 当下必须基于**大运时间轴**与求测年份，不张冠李戴。
- 家庭六亲只论"关系性质与趋势"，不臆测具体事件、不夸张灾厄。
- 健康必免责。

## 四、合成示例（以庚金日主、食伤旺、印透为例，示意笔法）

> "你这人，内里是块硬金属，外面被水冲得发亮——聪明、会表达，但不服管。前二十年走的是水木泄身的运，像被推着走，学业和性子都磨得急；真正定下来是三十往后，土金运一来，印星把根扎住，才从'想得多'变成'做得到'。财上你不是守财型，钱跟着本事和时机走，四十前后火运引财，是实打实能攒住的一段。家上，你配偶宫坐的是实底，另一半是个能扛事的人；子女宫略空，孩子的事别催、别按自己剧本来。健康留意肾水和脾胃，少熬、少硬扛。改运不在改命，在你肯不肯把那身硬气，落到一个具体的行当里。"

（注：上段仅示范"如何把维度织成叙事"，真实输出须用被测者自己的排盘数据，逐句回溯依据。）
