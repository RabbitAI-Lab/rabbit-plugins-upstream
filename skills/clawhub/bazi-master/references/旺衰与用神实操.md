# 旺衰与用神实操

> 旺衰是"日主有多强"，用神是"命局该补什么"。这两步决定后面所有论断的方向。
> 本文件给一套**可执行**的判读流程，避免"凭感觉说旺弱"。

---

## 一、判断日主旺衰（得令 · 得地 · 得势）

### 1. 得令（看月支——最重要的一项）

月支是"天时"。日干五行在月支的状态：

- **当令（旺/相）**：日干与月支同五行（比劫月令）、或月支生日干（印月令）→ 得令，身偏旺。
- **休**：日干生月支（食伤月令，我泄气）→ 次弱。
- **囚**：日干克月支（财月令，我耗气）→ 偏弱。
- **死**：月支克日干（官杀月令）→ 最弱（但若有根有印可救）。

> 简记：月支生我/同我 = 得令（强）；月支我生/我克/克我 = 不得令（弱）。**得令是旺衰的第一票。**

### 2. 得地（看日支、年支、时支的地根）

- 日支（坐下）为本气根最有力；年、时支有本气根也算。
- 长生、禄（临官）、旺（帝旺）、墓库 之地支 = 强根；
- 仅余气、墓中藏干微弱 = 弱根/无根。
- 日主在地支**无任何本气根** → 大概率身弱（除非得令+得势极强）。

### 3. 得势（看天干比劫、印星的多寡）

- 天干有比肩、劫财帮身，或有正印、偏印生身 → 得势。
- 帮身之星多且透干 → 即使不得令也可转旺。

### 4. 综合定档

| 得令 | 得地 | 得势 | 结论 |
|------|------|------|------|
| ✓ | ✓ | ✓ | 身旺（偏强） |
| ✓ | ✓ | ✗ | 身旺 |
| ✓ | ✗ | ✓ | 身旺（虚浮之旺） |
| ✗ | ✓ | ✓ | 中和偏旺 |
| ✓ | ✗ | ✗ | 中和 |
| ✗ | ✓ | ✗ | 中和偏弱 |
| ✗ | ✗ | ✓ | 中和偏弱（靠印比撑） |
| ✗ | ✗ | ✗ | 身弱 |

> 实务中很少有绝对"中和"，多判为"身弱""身旺""中和偏X"。存疑时宁判中和，不强行定旺弱。

## 二、取用神（三层法：调候 → 格局 → 病药）

### 第一层：调候用神（看寒暖燥湿，急所先顾）

- 冬生（亥子丑月）、初春（寅月）→ 寒，喜**丙丁火**暖局。
- 夏生（巳午未月）→ 热，喜**壬癸水**润局。
- 未戌月（燥土）→ 燥，喜**壬癸水**。
- 辰丑月（湿土）→ 湿，喜**丙丁火**。
- 具体日干+月令的调候用神，查《穷通宝鉴调候》十干四季表（已是本 skill 内置参考）。

> 调候为"急"：寒命无火、热命无水，纵成格也减分。调候用神常是全局第一喜神。

### 第二层：格局用神（看月令取格后的喜忌）

先定格局（见《格局判定》），再取该格局的"成格之用"：

- 正官格：喜财生官、印护官；忌伤官克官、七杀混官。
- 七杀格：喜食神制杀、印星化杀；忌财生杀、身弱无依。
- 正印/偏印格：喜官杀生印、比劫护印；忌财星坏印。
- 正财/偏财格：喜食伤生财、官星护财；忌比劫夺财。
- 食神格：喜财星引化、身旺任之；忌印星夺食、偏印倒食。
- 伤官格：喜佩印（伤官配印）、喜财（伤官生财）；忌见官无制。

### 第三层：病药用神（看全局之"病"）

- **身弱官杀重** → 病在官杀，药在印（化杀生身）或比劫（帮身抗杀）。
- **身旺无泄** → 病在壅塞，药在食伤（泄秀）或财（耗身）。
- **身弱财旺** → 病在财耗，药在比劫（分担）或印（生身）。
- **身旺比劫林立** → 病在争，药在官杀（制比）或食伤（泄比）。
- **寒暖失调** → 病在偏枯，药在调候（见第一层）。

### 第四层：扶抑收口

- **身旺** → 喜 克（官杀）、泄（食伤）、耗（财）；忌 生（印）、扶（比劫）。
- **身弱** → 喜 生（印）、扶（比劫）；忌 克（官杀）、泄（食伤）、耗（财）。

> **最终用神 = 调候、格局、病药三层的交集/公约数**。若三层冲突，以"救急"为先（调候或去病），再论格局纯杂。

### 忌神

用神的反面即忌神。忌神被大运流年引动 → 该运该年不顺；用神得地为运 → 顺遂。

## 三、用神有力与否（决定"贵贱"）

- 用神**透干 + 有根 + 无伤** → 用神有力，命局层次高。
- 用神**虚浮（无根）或被冲克合化** → 用神无力，怀才不遇、起伏大。
- 用神**远在年柱、或被合走** → 助力迟缓、外强中干。

> 判完用神后，要能回答一个问题："这个命，靠什么成事？靠什么栽跟头？"——答不出，说明旺衰用神没定准。
