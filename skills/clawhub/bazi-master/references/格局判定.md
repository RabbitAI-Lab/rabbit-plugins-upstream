# 格局判定

> 格局是命局的"主旋律"。定格局不是为了贴标签，而是为了**锁定成格之用神**（见《旺衰与用神实操》第二层）。
> 本文件给一套从月令取格、识别特殊格局、判断成破格的流程。

---

## 一、正格（八格）——以月令取格

月支是格局的"提纲"。取格顺序：

1. **看月支本气**（见藏干表）所藏十神。
2. **本气透干** → 直接取本气十神为格（如月支本气为正官且天干透正官 → 正官格）。
3. **本气未透、中气/余气透干** → 可取透出者为"杂气格"（如辰月戊为本气未透，乙/癸透出则取透出者）。
4. 月支本气与日干关系决定格名（见下表）。

| 月支本气十神 | 正格名 | 月支本气十神 | 正格名 |
|--------------|--------|--------------|--------|
| 正官 | 正官格 | 正财 | 正财格 |
| 七杀 | 七杀格（偏官格） | 偏财 | 偏财格 |
| 正印 | 正印格 | 食神 | 食神格 |
| 偏印 | 偏印格 | 伤官 | 伤官格 |
| 比肩/劫财 | 建禄/月劫格（特殊，不以"比劫格"论） | | |

> 例：月支为子（本气癸水=日干壬之劫财？需按日干定）→ 若日干为丙，子水为正官本气透则正官格。关键：月支藏干 + 日干十神，二者结合。

## 二、特殊格局（日主无依或一行独旺）

满足下列条件之一，可判特殊格局（此时"扶抑用神"失效，改用"顺其势"）：

| 格局 | 条件 | 取用 | 特征 |
|------|------|------|------|
| 从强/从旺 | 日主极旺，满局比劫印星，无一点克泄 | 顺其旺势，喜印比，忌财官 | 刚强自立、大起大落 |
| 从财 | 日主无根，满盘财星 | 喜食伤生财、官杀护财 | 富屋贫人、靠财立足 |
| 从杀 | 日主无根，满盘官杀 | 喜财生杀、顺其势 | 贵气凛然、压力为伴 |
| 从儿 | 日主无根，满盘食伤 | 喜财星引化 | 才华横溢、以才立身 |
| 化气 | 两干相合且化神当令成势 | 专用所化五行 | 气象独成、变局 |
| 专旺 | 五行纯一（如稼穑土、炎上火） | 顺其一行 | 气势凝一、偏才偏艺 |
| 两气成像 | 仅两行成象（如木火通明） | 顺两行、通关为用 | 秀气外露、才情 |

> ⚠️ "从格"的硬条件：日主在四柱地支**必须无根**（无本气禄旺根）。只要有一处强根，便不能从，仍按正格论旺衰。这是新手最常误判处。

## 三、成格与破格

- **成格**：用神有力、配合有情（如正官格有财生、有印护，官清印正）→ 层次高。
- **破格**：用神被冲克、合化，或忌神猖獗（如正官格见伤官无制、见七杀混杂）→ 格败，纵有运也多波折。
- **救应**：破格处有它神化解（如伤官见官而有财通关、有印护官）→ 格虽破而能救，层次回弹。

---

## 四、格局判读的输出要点

定格局后，要能一句话说清：
1. 这是什么格？（正格/从格/专旺/两气）
2. 成格还是破格？（用神是否有力、有无救应）
3. 这个格的"用神"和"忌神"是什么？（交回《旺衰与用神实操》）

> 格局只是"骨架"，血肉是十神强弱、旺衰用神、大运流年。不可脱离全局孤立论格。
