# 排盘示例（内部推演示范）

> 本文件是一个**完整走查范例**，演示从出生时间到最终论断的内部推导链。
> 目的：让分析者照着这条流水线走，确保每一步都有依据。对外输出时，只保留结论与意象（见《意象话术库》）。

---

## 案例：公历 1988-08-15 10:00（北京时间），男，出生地 上海（东经 121.4°）

### 第一步：排四柱

**年柱** — 1988 年立春（约 2/4）之后 → 用当年干支：
- (1988−4)%10 = 4 → 戊；(1988−4)%12 = 4 → 辰 → **戊辰年** ✓
- 纳音：戊辰序号 4 → 大林木

**月柱** — 8/15 在立秋（约 8/7）～ 白露（约 9/8）之间 → **申月（七月）**
- 年干戊 → "戊癸甲寅好追求"，寅月=甲寅，顺推：寅(甲)卯(乙)辰(丙)巳(丁)午(戊)未(己)申(庚) → **庚申月**
- 纳音：庚申序号 56 → 石榴木

**日柱** — JDN 算法（已校验）：
- n = (JDN + 49) % 60 = 38 → 38%10 = 8 → 壬；38%12 = 2 → 寅 → **壬寅日** ✓
- 纳音：壬寅序号 48 → 桑柘木

**时柱** — 真太阳时校正：
- 上海 121.4°E：真太阳时 = 10:00 + (121.4 − 120)×4 分 ≈ 10:05 → 仍属**巳时（09:00–11:00）**
- 日干壬 → "丁壬庚子居"，子时=庚子，顺推：子(庚)丑(辛)寅(壬)卯(癸)辰(甲)巳(乙) → **乙巳时**
- 纳音：乙巳序号 42 → 覆灯火

**四柱成形：戊辰 · 庚申 · 壬寅 · 乙巳　（日主壬水）**

### 第二步：排十神（日干壬）

| 柱 | 干/支 | 十神（对壬） | 说明 |
|----|-------|--------------|------|
| 年 | 戊（辰） | 七杀 / 辰藏戊(杀)乙(伤)癸(劫) | 杀透干，坐库有根 |
| 月 | 庚（申） | 偏印 / 申藏庚(偏印)壬(比)戊(杀) | 印干支同体，极旺 |
| 日 | 壬（寅） | 日主 / 寅藏甲(食)丙(偏财)戊(杀) | 坐病地，食神生财 |
| 时 | 乙（巳） | 伤官 / 巳藏丙(偏财)庚(偏印)戊(杀) | 伤官泄秀，财星藏 |

### 第三步：旺衰（得令·得地·得势）

- **得令**：壬生申月，申为壬之长生 → 当令而旺 ✓
- **得势**：月柱庚申偏印干支同体，金生水，印旺生身；地支申中藏壬比肩 → 极得势 ✓
- **得地**：日支寅（病地，无本气水根）、时支巳（绝地）、年支辰（墓，藏癸余气）→ 无强根，但申中壬水为根
- **结论**：**身旺（印旺身强）**，金白水清之象。

### 第四步：用神（三层法）

- **调候**：申月秋金，不需寒暖急调，但秋金需火炼 → 喜火。
- **格局**：月令申中庚金本气透月干 → **偏印格**；年干戊七杀生庚印 → 杀印相生（贵气、得权荫）。身旺印旺，反喜**财星制印**。
- **病药**：病在"印比过旺、壅塞"，药在**木（食伤泄秀）+ 火（财星耗身制印）**。
- **扶抑**：身旺 → 喜克(官杀)泄(食伤)耗(财)，尤喜木火；忌金水。
- **最终用神：木、火**（食伤+财）；**忌神：金、水**。

### 第五步：神煞（摘关键）

- 天乙贵人（壬→卯巳）：时支巳 → 带贵人（但巳落空亡，力减）。
- 文昌（壬→寅）：日支寅 → 自身聪慧有才。
- 驿马（年辰→寅）：日支寅 = 驿马 → 主变动、远行、不安于一地。
- 华盖（年辰→辰）：年支辰 = 华盖 → 带孤高、喜玄学技艺。
- **空亡**：日柱壬寅属甲午旬（30–39）→ 空辰、巳。年支辰、时支巳**双双落空** → 年上祖荫虚、时上偏财(巳中丙火)落空，财需大运填实方显。

### 第六步：大运（阳年男，顺排）

- 起运：出生(8/15)距下一节白露(约9/8) ≈ 24 天 → 24÷3 = **8 岁起运**。
- 顺排（从庚申月柱）：辛酉 → 壬戌 → 癸亥 → 甲子 → 乙丑 → **丙寅** → 丁卯 → 戊辰
- 关键运：38–47 甲子（食神透，开始泄秀）、48–57 乙丑（伤官+正官）、**58–67 丙寅（丙火偏财+寅木食神，用神到位，晚发之运）**。

>
> - **旺衰**：壬生申月（长生当令）→ 得令满分；月柱庚申偏印干支同体生身、申藏壬比肩 → 得势极旺；综合**身旺印旺**。
> - **用神**：身旺印旺，反喜**木（食伤泄秀）+ 火（财星耗身制印）**，忌金水。
> - **格局**：月令申中庚金透干 → **偏印格**；年干戊七杀生庚印 → 杀印相生（贵气、得权荫）。
> - **神煞**：文昌在日支寅（聪慧）、驿马在日支寅（主变动远行）、华盖在年支辰（孤高喜玄学）、空亡在辰巳（年上祖荫与时上财星落空，财需大运填实）。
> - **大运**：阳年男顺排，8 岁起运；58–67 丙寅（丙火偏财 + 寅木食神，用神到位）→ 晚发之运。
