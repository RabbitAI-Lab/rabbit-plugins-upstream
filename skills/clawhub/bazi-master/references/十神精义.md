# 十神精义

> 十神是八字的"角色系统"。日干是"我"，其余七个字按与我的生克关系扮演不同角色。
> 论命的核心是：**看这些角色在命局里谁强谁弱、谁帮谁、谁克谁**。本文件给每个十神的"象"与"用"，供分析时调用。

## 三、十神强弱的判读

一个十神在命局中"有力"的条件（满足越多越强）：

1. **得令**：该十神五行在月支当旺（参考旺相休囚死表）。
2. **有根**：地支中有其本气根（如正官为金，地支见申酉为根）。
3. **透干**：天干透出，或地支藏干透出。
4. **无伤**：不被冲克合化破坏，无重克。

**强弱推论**：
- 某十神过旺无制 → 该角色特质过度，甚至反噬（如伤官旺无印制 → 口舌是非、不服管）。
- 某十神过弱受制 → 该角色代表的领域薄弱或有缺（如正财弱而比劫旺 → 财来财去、难聚财）。
- 某十神"虚浮"（天干有、地支无根）→ 表面有、实则空。

## 四、关键十神组合（常见"象"）

- **官印相生**（正官+正印）：文贵之象，循规蹈矩能成事，适合公职、管理、学术。
- **杀印相生**（七杀+正印/偏印）：以智御压，化压力为权柄，将才、技术权威。
- **食神制杀**（食神+七杀）：以才华/手段驾驭压力与对手，武贵、竞技、创业。
- **伤官配印**（伤官+正印）：才华有涵养收束，文人、专家、创新而不失控。
- **伤官见官**（伤官+正官）：不服管、易起冲突，需看是否有财或印通关。
- **财官相生**（正财+正官）：务实求名，商政两宜，稳定格局。
- **比劫夺财**（比劫旺+财弱）：竞争破财、朋友分利，合作需谨慎。
- **印旺身弱**（印多、日主弱）：依赖心重、思多行少，需财来坏印方动。
- **身旺无依**（比劫旺、无财官食伤泄）：固执自我、少约束，易茫荡。
- **食伤生财**（食伤+财）：以才艺、口才、技术生财，现代"内容/手艺变现"之象。

## 五、十神与事业方向（速查）

- 官杀旺/为用 → 管理、军警、司法、开拓型岗位。
- 印旺/为用 → 教育、研究、文化、咨询、靠"背书"立业。
- 财旺/为用 → 经商、金融、实操型生意。
- 食伤旺/为用 → 创作、表达、技术、演艺、自由职业。
- 比劫旺/为用 → 合作、合伙、销售、体能/竞技。
- 忌神方向：**用神的反面**。身弱忌官杀 → 不宜高压岗位；身旺忌印 → 不宜纯靠"挂靠"。

> 以上为方向性参考，必须结合"用神"与"大运"再下结论，见《旺衰与用神实操》《大运流年论断》。
