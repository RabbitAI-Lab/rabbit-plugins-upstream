> 本文件是 bazi-master 的"内功心法"。它的作用是：让分析者拿到一个公历出生时间，**不依赖任何外部排盘工具，就能自行推出四柱、大运、十神、神煞、纳音、十二长生**。

## 二、年柱（以立春为界）

**公式（公历年份 Y，且已过当年立春）：**

- 年干 = 天干[(Y − 4) % 10]
- 年支 = 地支[(Y − 4) % 12]

**立春分界铁律**：年柱的切换点是**立春**，不是春节。出生在立春之前 → 用**上一年**的干支；出生在立春及之后 → 用当年干支。

> 校验：2000 年立春（约 2 月 4 日）之后，(2000−4)%10=6→庚，(2000−4)%12=4→辰 → 庚辰年 ✓。
> 2000 年 1 月 1 日尚在立春前 → 用 1999：(1999−4)%10=5→己，(1999−4)%12=3→卯 → 己卯年 ✓（与黄历一致）。

**快速定生肖**：年支即生肖（子鼠、丑牛、寅虎、卯兔、辰龙、巳蛇、午马、未羊、申猴、酉鸡、戌狗、亥猪）。

## 三、月柱（以"节"为界，五虎遁起干）

### 3.1 月支：由出生所在"节气区间"决定

月支的切换点是十二**节**（不是中气）。下列区间以"节"为起点，**含起点、不含下一个节**：

| 月支 | 月令名 | 节气区间（含起点，至下一节前） |
|------|--------|-------------------------------|
| 寅 | 正月 | 立春 ～ 惊蛰 |
| 卯 | 二月 | 惊蛰 ～ 清明 |
| 辰 | 三月 | 清明 ～ 立夏 |
| 巳 | 四月 | 立夏 ～ 芒种 |
| 午 | 五月 | 芒种 ～ 小暑 |
| 未 | 六月 | 小暑 ～ 立秋 |
| 申 | 七月 | 立秋 ～ 白露 |
| 酉 | 八月 | 白露 ～ 秋分 |
| 戌 | 九月 | 秋分 ～ 寒露 |
| 亥 | 十月 | 立冬 ～ 大雪 |
| 子 | 十一月 | 大雪 ～ 小寒 |
| 丑 | 十二月 | 小寒 ～ 立春 |

> ⚠️ 月支以十二"节"（立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒）为分界，不是中气。
> 常见错误：把"子月"写成立冬～大雪或立春～惊蛰。正确是 **子月 = 大雪～小寒**（十一月）、**丑月 = 小寒～立春**（十二月）、**亥月 = 立冬～大雪**（十月）。
> 校验：2000-01-01 在大雪（约 12/7）与小寒（约 1/6）之间 → 子月（十一月）✓（与黄历"冬月"一致）。

二十四节气公历大致日期（每年 ±1 天，排盘时以当年实际日期为准）：

```
立春 2/4   雨水 2/19  惊蛰 3/6   春分 3/21  清明 4/5   谷雨 4/20
立夏 5/6   小满 5/21  芒种 6/6   夏至 6/21  小暑 7/7   大暑 7/23
立秋 8/8   处暑 8/23  白露 9/8   秋分 9/23  寒露 10/8  霜降 10/23
立冬 11/7  小雪 11/22 大雪 12/7  冬至 12/22 小寒 1/6   大寒 1/20
```

### 3.2 月干：五虎遁口诀（由年干推正月寅月的天干，再顺推）

```
甲己之年丙作首  → 寅月=丙寅
乙庚之岁戊为头  → 寅月=戊寅
丙辛之岁寻庚起  → 寅月=庚寅
丁壬壬位顺行流  → 寅月=壬寅
戊癸甲寅好追求  → 寅月=甲寅
```

从寅月（正月）起，按月支顺序（寅→卯→辰→…→丑）顺推天干，即得各月天干。

> 校验：2000 年为己卯年，年干=己 → "甲己之年丙作首"，寅月=丙寅。顺推至子月（十一月）：寅(丙)→卯(丁)→辰(戊)→巳(己)→午(庚)→未(辛)→申(壬)→酉(癸)→戌(甲)→亥(乙)→**子(丙)**→丑(丁)。故 2000-01-01 月柱 = **丙子** ✓（与黄历一致）。

## 四、日柱（儒略日算法，已校验）

这是最容易出错的一柱，用下方经过锚点验证的算法，**禁止用"大概"推**。

**第一步：算儒略日数 JDN（公历 Y/M/D）**

```
a = (14 − M) // 12
y = Y + 4800 − a
m = M + 12×a − 3
JDN = D + (153×m + 2)//5 + 365×y + y//4 − y//100 + y//400 − 32045
```

**第二步：算日干支序号**

```
day_index = (JDN + 49) % 60
日干 = 天干[day_index % 10]
日支 = 地支[day_index % 12]
```

> 校验（多源黄历一致）：
> - 2000-01-01：JDN=2451545 → (2451545+49)%60=54 → 54%10=4→戊，54%12=6→午 → **戊午** ✓
> - 2000-01-02：JDN=2451546 → 55 → 己未 ✓
> - 2000-01-07：JDN=2451551 → 0 → 甲子 ✓
> - 2024-02-10（春节）：= 甲辰年 丙寅月 甲辰日（可自行代入验证，岁日同干支）

> 说明：JDN 以正午为基准，但日柱按"出生那一天的日历日"取即可，与具体钟点无关（钟点决定的是时柱）。

## 五、时柱（真太阳时 + 五鼠遁）

### 5.1 真太阳时校正（决定时辰）

八字时辰必须用**出生地的真太阳时（地方太阳时）**，不是北京时间。

```
真太阳时 ≈ 北京时间 + (出生地经度 − 120°) × 4 分钟/度
```

- 出生地在东经 120° 以西（如深圳 114°、成都 104°、新疆 87°）→ 真太阳时比北京时间**晚**，减时间；以东（如东北 130°）→ 比北京时间**早**，加时间（每度 4 分钟）。
- 校验：东经 87°（新疆）≈ 北京时间 − 2 小时 12 分；东经 130°（东北）≈ 北京时间 + 40 分。
- 若出生地跨时区或经度偏差大（如新疆、西藏），必须校正，否则时辰可能整错。
- 真太阳时本身还有 ±16 分钟的"时差方程"季节修正，一般排盘可忽略，但临界时刻（如 23:00 前后）需提示不确定性。

**十二时辰（按真太阳时）：**

| 时辰 | 地支 | 真太阳时范围 |
|------|------|--------------|
| 子 | 子 | 23:00 – 01:00（注意：23:00 起即次日子时） |
| 丑 | 丑 | 01:00 – 03:00 |
| 寅 | 寅 | 03:00 – 05:00 |
| 卯 | 卯 | 05:00 – 07:00 |
| 辰 | 辰 | 07:00 – 09:00 |
| 巳 | 巳 | 09:00 – 11:00 |
| 午 | 午 | 11:00 – 13:00 |
| 未 | 未 | 13:00 – 15:00 |
| 申 | 申 | 15:00 – 17:00 |
| 酉 | 酉 | 17:00 – 19:00 |
| 戌 | 戌 | 19:00 – 21:00 |
| 亥 | 亥 | 21:00 – 23:00 |

> ⚠️ 23:00–24:00 属于**次日子时**（晚子时），日柱已翻到第二天；排盘时要先按真太阳时确定日期，再定日柱和时柱，避免"日子错一天"。

### 5.2 时干：五鼠遁口诀（由日干推子时天干，再顺推）

```
甲己还加甲  → 子时=甲子
乙庚丙作初  → 子时=丙子
丙辛从戊起  → 子时=戊子
丁壬庚子居  → 子时=庚子
戊癸何方发，壬子是真途  → 子时=壬子
```

从子时（子）起，按子→丑→寅…→亥顺推天干。

> 校验：2000-01-01 日干=戊 → "戊癸…壬子是真途"，子时=壬子 ✓；若丑时则癸丑，寅时甲寅，依此类推。

## 九、大运（起运数 + 顺逆排）

### 9.1 顺逆规则（由年干阴阳 + 性别定）

- **阳年（年干为甲丙戊庚壬）男 / 阴年（乙丁己辛癸）女** → **顺排**（从月柱向后的干支顺序推）
- **阴年男 / 阳年女** → **逆排**（从月柱向前的干支顺序推）

### 9.2 起运岁数（三天为一岁）

1. 顺排：数**出生日到下一个"节"**的天数。
2. 逆排：数**出生日到上一个"节"**的天数。
3. 换算：`起运岁数 = 天数 ÷ 3`；余数：1 天 = 4 个月，1 时辰 ≈ 10 天（取整或说明"约 X 岁 X 个月起运"）。
   - 例：出生距下一节 18 天 → 6 岁起运；27 天 → 9 岁起运。

### 9.3 大运干支

从月柱开始，按顺/逆方向在六十甲子中依次取，每柱管十年，一般排 8 柱（80 年）。

> 例：月柱 丙子，顺排 → 丁丑、戊寅、己卯、庚辰…；逆排 → 乙亥、甲戌、癸酉、壬申…

## 十、排盘自检清单（输出前必核）

- [ ] 年柱：立春分界是否正确（冬春之交最易错）
- [ ] 月柱：节气区间是否对应正确月支；五虎遁是否顺推无误
- [ ] 日柱：用 JDN 公式算出，而非凭记忆
- [ ] 时柱：是否做了真太阳时校正；23:00 后是否为晚子时（日柱已翻）
- [ ] 十神：四柱每个干支按日干逐一对应，无遗漏
- [ ] 大运：顺逆方向、起运岁数是否自洽
- [ ] 神煞、纳音：查表而非臆造

> 任一环节存疑，先向用户核实出生时间/地点，或在输出中注明"时辰临界，存疑"，**绝不带错盘硬推**。
