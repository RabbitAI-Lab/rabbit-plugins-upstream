## Known Risks and Mitigations:

Risk: Broad JavaScript development assistance can involve reading, writing, or executing commands in project workspaces.

Mitigation: Use the skill only in projects where developer-tool access is acceptable, and review proposed edits or commands before applying them.

Risk: The artifact includes a generic API_KEY environment variable example that could be misused with real secrets.

Mitigation: Do not place real secrets into the generic API_KEY example unless a specific trusted integration requires it, and keep secrets out of source control.
