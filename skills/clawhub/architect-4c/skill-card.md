## Description:

Use Simon Brown's C4 model only when explicitly invoked to generate Mermaid architecture diagrams and documentation from source code, design notes, or discussions. Cover system context, containers, components, and code, with dynamic and deployment views as needed.

This skill is ready for commercial/non-commercial use.

## Publisher:

[agenticweb4](https://clawhub.ai/user/agenticweb4)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to document a software system with C4 context, container, component, and code views, plus dynamic or deployment views when useful. It produces Mermaid diagrams with explanations and evidence-based notes about unresolved architecture details.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Architecture diagrams and documentation can expose internal system details when shared.

Mitigation: Review generated files for sensitive details before sharing.
