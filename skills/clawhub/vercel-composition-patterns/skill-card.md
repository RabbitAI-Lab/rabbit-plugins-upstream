## Description: <br>
React composition guidance for refactoring boolean prop proliferation, building flexible component libraries, designing reusable APIs, and applying compound components, render props, context providers, component architecture, and React 19 API patterns. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineering agents use this skill to maintain, generate, review, or refactor React codebases with scalable composition patterns and fewer brittle component modes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: React 19-specific recommendations may not match projects on React 18 or earlier. <br>
Mitigation: Confirm the project's React version and local conventions before applying React 19 API recommendations. <br>
Risk: Composition guidance can be over-applied to simple components or conflict with established local component patterns. <br>
Mitigation: Use the rule files as review guidance and adapt proposed refactors to the existing codebase conventions. <br>
