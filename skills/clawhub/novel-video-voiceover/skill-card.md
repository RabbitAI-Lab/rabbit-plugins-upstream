## Description:

Creates multi-voice narration for novel promo videos and audiobooks, with WAV audio, speaker-labeled SRT subtitles, and per-line timing through the Miragea API.

This skill is ready for commercial/non-commercial use.

## Publisher:

[yanghhu](https://clawhub.ai/user/yanghhu)

### License/Terms of Use:

MIT-0

## Use Case:

External creators, authors, and audio teams can turn authorized novel or story scripts into multi-voice narration for promo videos, audiobook samples, and serialized stories, with aligned subtitles and line timings.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security review reports a mismatch between the advertised voiceover workflow and assessed code, and notes capability and resource-use concerns.

Mitigation: Review the script behavior for the intended workflow, check current API capabilities, and try a short input with --dry-run before generating audio.

Risk: The security guidance flags an API timeout concern.

Mitigation: Set bounded --timeout and --wait-timeout values for API requests and task waits.
