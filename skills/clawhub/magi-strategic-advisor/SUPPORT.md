# Support

Thank you for using MAGI Strategic Advisor. This document describes where to
get help, report problems, and request changes.

## Where to Ask

| Need | Channel |
|---|---|
| Usage questions, ideas, general discussion | GitHub Discussions |
| Bug reports and feature requests | GitHub Issues |
| Documentation clarifications | GitHub Issues (label: documentation) |
| Security vulnerabilities | See `SECURITY.md` (private reporting only) |

## Before You File

1. Read `README.md` and `SKILL.md` for the documented behavior.
2. Read `README FOR AI.md` for the authoritative repository contract.
3. Search existing issues and discussions to avoid duplicates.

## What to Include

- For bugs: exact reproduction steps, environment (OS, Python version), the
  affected file or script, and the observed versus expected behavior.
- For feature requests: the user scenario, the expected benefit, and any
  alternatives you considered.

## Response Expectations

This project is maintained by volunteers on a best-effort basis. Maintainers
aim to acknowledge new issues within a few business days, but no SLA is
guaranteed for general support. Security reports follow the response
timelines defined in `SECURITY.md`.

## Scope of Support

- Supported: the skill package as published on the default branch.
- Not supported: third-party forks, modified copies, or integrations that
  deviate from the documented contract.
