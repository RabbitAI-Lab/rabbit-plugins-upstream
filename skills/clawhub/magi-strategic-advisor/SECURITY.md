# Security Policy

## Reporting a Vulnerability

Please do not disclose security vulnerabilities in public issues. Report them
privately to the repository maintainers with:

- A description of the vulnerability
- Steps to reproduce it
- The affected file or version
- Any suggested mitigation

Maintainers will acknowledge valid reports and coordinate remediation and
disclosure with the reporter.

## Supported Versions

Only the latest version on the default branch is actively supported unless a
release explicitly states otherwise.
