# Security Policy

## Reporting a Vulnerability

Please do not disclose security vulnerabilities in public issues or
discussions. Report them privately through one of the following channels,
in order of preference:

1. GitHub Private Vulnerability Reporting:
   <https://github.com/JohnSmithfan/MAGI-Strategic-Advisor/security/advisories/new>
2. The contact address published on the maintainer's GitHub profile:
   <https://github.com/JohnSmithfan>

A useful report includes:

- A description of the vulnerability and its potential impact
- Steps to reproduce it
- The affected file, script, or version
- Any suggested mitigation

## Response Timeline

| Stage | Target |
|---|---|
| Acknowledgment of the report | Within 5 business days |
| Triage and severity assessment | Within 10 business days |
| Fix or mitigation plan communicated | Within 30 days of triage |
| Coordinated public disclosure | After a fix ships, or 90 days after the report, whichever comes first |

Reporters are credited in public disclosures unless they ask to remain
anonymous.

## Supported Versions

| Version | Supported |
|---|---|
| Latest release on the default branch | Yes |
| Older releases | No, unless a release explicitly states otherwise |

## Disclosure Policy

Fixes are released as patch or minor versions according to SemVer, and the
corresponding CHANGELOG.md entry is grouped under `Security`. Disclosure is
coordinated with the reporter.
