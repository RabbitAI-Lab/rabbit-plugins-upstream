# 剪辑交付前自检清单

任何一项不通过，先修复再交付。

## A. 用途与结构（6 项）

- [ ] 明确了成片用途（PDP/广告/review/社媒/引流）
- [ ] 时长符合该用途的建议区间
- [ ] 结构符合用途模板（hook→证明→CTA 等）
- [ ] 一条成片只承载一个核心主张
- [ ] 多卖点素材已建议拆成多条
- [ ] must-keep 片段全部包含在内

## B. 开头质量（5 项）

- [ ] 前 3 秒出现产品或效果
- [ ] 无 logo 动画、寒暄、频道介绍
- [ ] hook 与正片承诺一致，无标题党断层
- [ ] hook 片段本身画质/曝光可用
- [ ] 提供了至少一个备选 hook（素材允许时）

## C. 片段选择（6 项）

- [ ] 保留片段按证明力排序选出
- [ ] 最强效果/对比片段已保留
- [ ] 演示已压缩为"起手+结果"
- [ ] 无重复动作、双遍演示
- [ ] 无 setup、空镜、口误、长停顿
- [ ] 删除的 >5s 片段都写了删除理由

## D. 衔接与技术（6 项）

- [ ] 硬切都在动作完成点或句子边界
- [ ] 无句中断裂的口播
- [ ] 时间倒序跳切已标注过渡建议
- [ ] 曝光/色调跳变已标注
- [ ] 音频断点已标注
- [ ] 时间码与源素材对得上（抽查 2 处）

## E. 转化要素（5 项）

- [ ] 有 CTA 或已建议补结尾卡
- [ ] 价格/促销信息按需求包含或明确排除
- [ ] 效果展示无过度承诺（避免退货风险）
- [ ] 关键信息不依赖音频也能看懂（静音播放场景）
- [ ] 建议了需要补的字幕/封面

## F. 交付完整性（5 项）

- [ ] 按 output-template.md 输出
- [ ] 每个保留片段有时间码 + 理由 + 角色
- [ ] 遗留问题清单完整（字幕/尺寸/补拍）
- [ ] 备选版本给出了适用场景
- [ ] 有一句话交付说明

## 快速红线（任一命中即打回）

- 前 3 秒还在放 logo 或打招呼
- 没有时间码
- 删掉了最强证明片段
- 只说"剪短了"没说"为什么这么剪"
