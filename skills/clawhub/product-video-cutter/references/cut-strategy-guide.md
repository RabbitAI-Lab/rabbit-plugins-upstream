# 按用途的结构模板与时长矩阵

不同投放位置的观众意图不同，结构必须不同。先定用途，再套结构。

## 用途矩阵

| 用途 | 建议时长 | 观众状态 | 结构 | 删减重点 |
|---|---|---|---|---|
| 信息流广告 | 15-30s | 被打断，无耐心 | hook(3s) → 证明(8-15s) → CTA(3-5s) | 删所有铺垫和细节 |
| PDP 主图视频 | 30-60s | 已有意向，要细节 | 场景(5s) → 演示(20-30s) → 参数/证明(10s) → 定妆(3s) | 删品牌故事和口号 |
| 达人页 review | 30-60s | 找真实反馈 | 人脸观点(5s) → 真实使用(20-30s) → 优缺点(10s) | 删摆拍感强的棚拍段 |
| 社媒短视频 | 15-45s | 找乐子/灵感 | hook(3s) → 过程或反转(20-30s) → 轻 CTA | 删硬广感强的段落 |
| 站外引流 | 15-30s | 冷流量 | 冲突/场景(5s) → 最强证明(10-15s) → 悬念 CTA | 只留一个卖点 |
| 详情页嵌入(功能点) | 10-20s | 逐项对比中 | 单功能演示，无 hook 无 CTA | 删与该功能无关的一切 |

## 三条结构原则

### 1. 单视频单主张

一条成片只讲一个核心卖点。素材里有三个卖点时，优先出三条短片而不是一条长片。多卖点会互相稀释记忆点。

### 2. 证明力排序

保留优先级从高到低：
实拍效果 > before/after 对比 > 第三方实测/数据 > 功能演示 > 用户口播评价 > 官方口播描述。
时长不够时从队尾开始删。

### 3. 密度优先于完整

演示可以跳步：展示"起手动作 + 最终结果"，跳过中间过程。观众补全能力很强，完整流程留给说明书。

## 时长删减操作顺序

超时时按此顺序删：

1. 开场铺垫（logo、寒暄、背景介绍）—— 无条件删
2. 重复动作 / 第二遍演示 —— 保留最清晰的一遍
3. 口播中的语气词、停顿、重复表述
4. 演示过程的中段（保留起手和结果）
5. 次要卖点整段 —— 挪到备选版本
6. CTA 压缩为结尾卡

永远最后删：最强证明片段。如果删到证明片段还超时，说明目标时长定错了，回报用户。

## 衔接规则

- 硬切点选在：动作完成瞬间、语句句号处、镜头运动静止点
- 避免：句子中间、动作进行中、变焦过程中切断
- 时间倒序跳切（后面的画面接前面的动作）需加过渡提示
- 音频优先：宁可画面跳，不让口播断在半句
