# 企查查站点适配器（qcc）

> 目标站点：企查查（www.qcc.com）。满足「MCP + 网页版并存」：官方 MCP `qcc-company`
> 按次扣积分，网页版 SVIP 会员可无限查看。

## 1. 站点与登录态

- **站点名**：企查查（qcc.com）
- **入口 URL**：`https://www.qcc.com/`
- **登录态确认方式**：点击右上角头像，弹出菜单含「退出登录」即已登录；未登录则无该入口。
- **会员类型**：SVIP（网页版会员）。官方 MCP `qcc-company` 为按次积分计费，SVIP 不含 API 额度。

## 2. URL 规律

- **搜索页 URL**：`https://www.qcc.com/web/search?key={关键词}`（关键词需 URL 编码）
- **企业详情页**：`https://www.qcc.com/firm/{md5}.html`
- **人物（老板）详情页**：`https://www.qcc.com/pl/{md5}.html`
- ⚠️ **均为 md5 哈希，不是信用代码直拼**：`firm/91310000XXXXXXXXXX.html`（示例信用代码已打码）
  会被重定向回首页，必须从搜索页提取真实 href。
- **取真实 href**：
  ```js
  Array.from(document.querySelectorAll('a'))
    .filter(a => /关键词|人名/.test(a.textContent) && a.href && a.href.includes('qcc.com'))
    .map(a => ({t: a.textContent.trim().slice(0,50), h: a.href}))
  ```

## 3. 字段定位（DOM）

- **数据容器**：关联企业/对外投资/任职明细表均在 `.tablist` 容器内（页面可能并列多个 tablist）。
- **关键词定位法**：
  - 对外投资表 → 用「被投资企业名称」定位；
  - 担任法人表 → 用「担任法定代表人起止时间」定位；
  - 所属集团表 → 用「集团名称」定位（列：集团名称/集团人员角色/集团主公司/实际控制人/集团成员/重要风险）。
- **全文本抓取**：`bsk evaluate "document.body.innerText"` 一次取全文本（含简介、统计数字、
  近期动态、新闻舆情、合作伙伴、上榜榜单），再按标题关键词切片解析。
- **统计数字**：搜「全部关联企业 / 担任法定代表人 / 对外投资 / 在外任职 / 作为最终受益人 /
  控制企业 / 所属集团」后的数字。

## 4. 歧义 / 同名甄别

- **同名人物风险高**：搜索结果常有多个同名人物（独立董事/监事/股东等）。
- **判定方法**：进入人物页后，用「简介 + 所属集团 + 新闻舆情」三处交叉验证：
  - 简介是否含目标独有头衔（如「某投资机构董事长」）；
  - 所属集团/明细是否高度一致指向目标（如全是同一投资机构的基金）；
  - 新闻舆情是否出现目标相关事件。
- **典型坑**：人物页 `<title>` 可能显示其「兼任的上市公司」（如「某人 - 某上市公司」），
  ≠ 主营身份。这是多重身份，非脏数据，勿误判。

## 5. 反爬 / 风控

- **会话**：bsk session 会因 Agent Window 被关闭/并行操作而频繁失效，操作要紧凑。
- **分页**：`.pagination` 里的「2」「>」点击后可能不刷新（SPA 懒加载）。点不动就抓当前页
  （前 10 条常已覆盖核心），报告标注「前 N 家 / 共 M 家」。
- **borrow 用户标签**：`bsk tab borrow` 会打扰用户、常被取消，优先在 agent 标签直接导航。

## 6. 备注

- 工商登记数据 T+0 实时同步；财务/年报依赖企业公示周期，可能滞后。
- 金额单位「万元/亿元」需随值标注；日期 `YYYY-MM-DD`。

## 典型抓取案例（脱敏示例）

**目标**：某投资机构创始合伙人「李某」的投资关系图谱（此处为虚构演示，不含任何真实人物/企业数据）。
**步骤**：搜索「机构名称」→ 从结果提取李某人物页 `pl/{md5}.html`（真实 md5 从搜索页提取）
→ 抓 `body.innerText` → 定位 `.tablist` 取对外投资/担任法人/所属集团明细 → 三处交叉验证身份。
**产出**：深色金融风 HTML（人物画像 + 指标卡 + ECharts 力导向关系图 + 明细表 + 动态时间线）。
**字段示例**：关联企业、对外投资、间接投资、最终受益人、所属集团等维度的数量与明细（均用占位符表示）。
