# 站点适配器模板（复制本文件，改为你的站点）

> 复制为 `recipes/{站点名}.md`，逐项填写。写完即可被通用五步法驱动。

## 1. 站点与登录态

- **站点名**：
- **官网/入口 URL**：
- **登录态确认方式**：如何判断已在浏览器登录？（例：点击头像出现「退出登录」/ 页面无「立即登录」按钮）
- **会员类型**：网页版会员叫什么（SVIP/VIP/Pro）？是否有按次计费的 MCP/API？

## 2. URL 规律

- **搜索页 URL 模板**：`https://.../search?key={关键词}`（关键词是否需 URL 编码？）
- **详情页 URL 规律**：是 ID 直拼还是内部哈希？（例：企查查为 `/firm/{md5}.html`，需从搜索页提取真实 href）
- **取真实 href 的 JS**：`Array.from(document.querySelectorAll('a')).filter(a=>a.href&&/关键词/.test(a.textContent)).map(a=>a.href)`

## 3. 字段定位（DOM）

- **数据容器**：关键表格/字段在哪个 class / 容器？（例：企查查为 `.tablist`）
- **关键词定位法**：用哪个表头关键词区分不同明细表？（例：用「被投资企业名称」定位对外投资表）
- **全文本抓取**：`document.body.innerText` 是否能拿到主要字段？

## 4. 歧义 / 同名甄别

- **目标对象判定**：如何确认是目标而非同名者？（例：用「简介 + 归属 + 关联舆情」交叉验证）
- **典型坑**：页面标题可能显示的是「兼任身份」而非「主营身份」，需额外验证。

## 5. 反爬 / 风控

- **频控**：批量抓取需间隔多久？是否触发验证码/滑块？
- **分页**：分页控件能否正常翻页？点不动时的取舍策略。
- **登录态时效**：会话多久过期？是否需要重新登录。

## 6. 备注

- 数据时效（T+0 / 滞后）、单位约定、其他注意事项。
