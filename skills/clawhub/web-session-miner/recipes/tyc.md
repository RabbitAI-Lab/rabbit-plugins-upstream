# 天眼查站点适配器（tyc）

> 目标站点：天眼查（www.tianyancha.com）。满足「MCP + 网页版并存」：官方 MCP `tyc-mcp`
> 按次扣积分，网页版 VIP 会员可无限查看。

## 1. 站点与登录态

- **站点名**：天眼查（tianyancha.com）
- **入口 URL**：`https://www.tianyancha.com/`
- **登录态确认方式**：首页右上角出现「登录/注册」即**未登录**；已登录则显示用户头像/昵称。
- **会员类型**：VIP（网页版会员）。官方 MCP `tyc-mcp` 为按次积分计费，VIP 不含 API 额度。

> ⚠️ **硬前置（与企查查的关键差异）**：天眼查**搜索即强制登录**——未登录访问
> `https://www.tianyancha.com/search?key={关键词}` 会 302 重定向到
> `https://www.tianyancha.com/login?from=...`。因此**必须先登录**才能抓取，无法像企查查
> 那样未登录预搜索。登录方式为**扫码**（微信 / 小程序二维码），可用 `bsk request-help`
> 引导用户扫码登录。

## 2. URL 规律

- **搜索页 URL**：`https://www.tianyancha.com/search?key={关键词}`（关键词 URL 编码；需登录）
- **企业详情页 URL**：`https://www.tianyancha.com/company/{数字ID}`（**已实证**：数字自增 ID，
  如某企业为 `/company/{数字ID}`，与企查查的 md5 哈希不同）
- **人物（老板）详情页 URL**：待确认（推测 `/human/{id}` 或类似）

## 3. 字段定位（DOM）

- **核心定位法**：天眼查数据**直接在 `document.body.innerText` 里**（无企查查的 `.tablist`
  容器），用关键词切片定位即可，比企查查更简单：
  - 股东信息表 → 用「持股比例」或「股东名称」定位（列：股东名称 / 持股比例 / 认缴出资额 /
    认缴出资日期 / 首次持股日期 / 关联产品机构）；
  - 工商信息 → 用「企业名称」定位（企业类型/注册资本/参保人数等）；
  - 主要人员 / 对外投资 / 实际控制人 / 最终受益人 → 用对应表头关键词定位。
- **导航 tab**：股东信息 / 主要人员 / 对外投资 / 控制企业 / 变更记录 / 实际控制人 / 最终受益人 等。

## 4. 歧义 / 同名甄别

- 与企查查同类风险：同名企业/人物需交叉验证（简介 + 归属 + 舆情）。

## 5. 反爬 / 风控

- **登录门槛高**：搜索强制登录，登录态过期需重新扫码。
- **验证码风险**：批量抓取可能触发滑块/验证码，需控制频率。

## 6. 备注

- 工商数据 T+0；金额单位「万美元/万元」需随值标注；日期 `YYYY-MM-DD`。
