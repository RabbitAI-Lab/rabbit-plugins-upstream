# Shopee 接口总览

| 能力 | 脚本 | Agent 接口 |
| --- | --- | --- |
| 站点列表 | `scripts/shopee_site_list.py` | `GET /api/v1/shopee/site/ai-list` |
| 商品搜索 | `scripts/shopee_goods_search.py` | `GET /api/v1/shopee/goods/ai-search` |
| 商品详情与历史 | `scripts/shopee_goods_info.py` | `GET /api/v1/shopee/goods/ai-info` |
| 店铺详情 | `scripts/shopee_mall_info.py` | `GET /api/v1/shopee/mall/ai-info` |
| 子类目列表 | `scripts/shopee_category_list.py` | `GET /api/v1/shopee/category/ai-list` |
| 类目父链 | `scripts/shopee_category_info.py` | `GET /api/v1/shopee/category/ai-info` |

当前没有 Shopee 图搜、关键词库查询、评论正文读取、店铺名称搜索、广告、订单或 Seller Centre 写操作接口。图片上传不是 Shopee 图搜能力。
