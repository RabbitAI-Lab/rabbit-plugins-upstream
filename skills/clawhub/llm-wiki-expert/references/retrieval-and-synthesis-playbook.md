# 检索、有据综合与能力升级手册

## 1. 检索阶梯

从最便宜、最可解释的方法开始：

```text
Level 0  wiki/index.md + 目录导航
Level 1  rg 全文检索 + frontmatter 过滤
Level 2  Manifest、反向链接、同义词和字段索引
Level 3  BM25/SQLite FTS 等词法索引
Level 4  Embedding + hybrid retrieval + rerank
```

只有评测显示当前层级的召回不足，且语料规模与查询价值足以覆盖运维成本时才升级。向量数据库不是 Wiki 成熟度徽章。

## 2. 查询计划

每次查询先写简短计划：

1. 将问题拆成实体、关系、时间范围和输出约束。
2. 读取 `wiki/index.md` 确认主题入口。
3. 用精确词、同义词、缩写和稳定 ID 搜索。
4. 打开命中页面及其来源、相邻概念和状态字段。
5. 对强断言回到 `raw/` 核对。
6. 综合答案，列出冲突、未知和时间边界。

```bash
rg -n -i "tool[- ]?call|工具调用|protocol" wiki/ raw/
rg -l "status: (disputed|stale)" wiki/
```

不要把 `rg` 命中行直接当答案；必须读取上下文和页面状态。

## 3. 答案证据标签

| 标签 | 使用条件 | 表达方式 |
|------|----------|----------|
| Wiki 明示 | 页面直接陈述且来源有效 | “Wiki 记录……”并链接页面/来源 |
| 基于证据推断 | 多条证据支持但无直接结论 | “据此可推断……”并列推理链 |
| 存在冲突 | 权威来源结论不一致 | 并列口径与适用条件 |
| 已过期风险 | 页面或来源超过 SLO | 给出最后审查日期 |
| 未知 | Wiki 无足够证据 | 明确缺什么，不用模型先验补齐 |

置信度不是随意的百分比。优先说明证据数量、直接性、新鲜度和冲突状态。

## 4. 综合结构

专业查询输出建议包含：

```markdown
## 结论
直接回答问题，限定时间和适用范围。

## 证据链
- 页面 A → 原始来源 A
- 页面 B → 原始来源 B

## 冲突与未知
哪些结论仍不确定，为什么。

## 后续验证
需要补充的来源或测试。
```

综合不是把各页摘要串联。它需要消除重复、对齐术语、区分事实与解释，并让每个关键结论能回到证据。

## 5. 何时使用语义检索

满足以下多数条件再考虑 Level 4：

- Wiki 超过数百个较长页面，人工导航和词法检索持续漏召回。
- 用户问题常用与正文完全不同的表达。
- 已有至少 30–50 条代表性评测问题，可比较 Recall@K。
- 团队能够承担切块、Embedding 更新、权限过滤和索引漂移治理。
- 混合检索显著优于全文检索，而非只展示漂亮 Demo。

不适用信号：页面少、术语稳定、要求精确字段匹配、权限模型尚未明确、没有离线评测。

## 6. RAG 设计要点

若升级为 RAG：

- 切块保留页面 ID、标题层级、状态、日期、来源和访问级别。
- 先做词法 + 向量混合召回，再用可解释的 rerank。
- `deprecated`、`stale`、`disputed` 不应与 `active` 无差别排序。
- 引用必须回到稳定页面/来源，不能只指向不可复现的 chunk ID。
- 页面变更后增量更新向量，并能检测陈旧索引。
- 权限过滤在检索前执行，不把私有片段召回后再遮盖。

## 7. 查询结果晋升

结果只有在下列问题全部回答“是”时才晋升：

```text
未来会再次被问到吗？
结论是否超越单页摘录？
证据是否稳定且可引用？
能否归入现有页面或形成清晰新边界？
晋升后谁负责更新？
```

晋升优先更新现有概念页；只有知识边界和生命周期独立时才新建页面。查询日志保留原问题、检索路径和未命中点，帮助改进同义词与评测集。

## 8. 评测指标

- `Recall@K`：标准相关页面是否进入前 K。
- `MRR`：第一个正确页面的位置。
- 引用覆盖率：关键结论中有可验证来源的比例。
- 引用正确率：引用是否真正支持对应结论。
- 弃答正确率：证据不足时是否拒绝编造。
- 新鲜度命中率：是否优先当前版本并提示过期内容。

## 9. 完成检查表

- [ ] 查询拆解了实体、关系、时间与输出约束
- [ ] 先读索引，再全文检索，再按证据升级
- [ ] 强断言回到原始来源核对
- [ ] 答案区分明示、推断、冲突、过期和未知
- [ ] RAG 决策由评测收益而不是技术偏好驱动
- [ ] 查询晋升具有复用价值、稳定证据与责任人
- [ ] 评测覆盖召回、引用、弃答和新鲜度
