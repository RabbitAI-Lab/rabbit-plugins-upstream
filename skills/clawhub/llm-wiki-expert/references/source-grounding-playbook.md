# 来源、证据与溯源手册

## 1. 证据层契约

`raw/` 保存“当时获得的来源”，`wiki/` 保存“当前可用的解释”。两者不可混淆：原文禁止静默改写，Wiki 页面则允许随新证据重编译。

每个来源至少记录：稳定 ID、标题、来源类型、原始 URL 或位置、作者/机构、发布日期、摄取日期、许可或访问限制、内容哈希、摄取方式和状态。

```bash
shasum -a 256 raw/articles/tool-protocol.md
rg -n "timeout|30 seconds|30 秒" raw/ wiki/
```

哈希证明本地副本是否变化，不证明来源真实性。

## 2. 来源优先级

| 层级 | 来源 | 适合支持 | 注意事项 |
|------|------|----------|----------|
| A | 规范、论文原文、官方源码/文档、正式决策 | 精确事实与核心结论 | 仍需检查版本和发布日期 |
| B | 作者演讲、官方博客、维护者说明 | 背景、意图和更新解释 | 可能简化技术细节 |
| C | 高质量二手分析、权威教材 | 综合和教学解释 | 关键事实回溯到一手来源 |
| D | 论坛、社媒、聚合摘要、模型回答 | 线索和待核实假设 | 不单独支撑高风险结论 |

同层级来源冲突时，不按数量投票；比较版本、适用范围、测量方法和直接性。

## 3. 精确事实工作流

数字、日期、名称、API 行为、引语和“首次/唯一/全部”等强断言必须先定位后写作：

1. 用索引和 `rg` 找候选来源。
2. 打开命中前后足够上下文。
3. 确认版本、适用条件和单位。
4. 将结论写在 Wiki 页面，并在同一段落链接来源。
5. 若不同来源冲突，保留各自说法和适用条件。

禁止根据搜索摘要、文件名或模型记忆填写精确事实。

## 4. 摄取格式

文本型来源优先保存为 Markdown，并在 frontmatter 后保留原文。网页可保存正文提取版，同时记录原始 URL、抓取时间和提取工具。PDF、图片、音视频等二进制文件保留原文件，并生成单独的文本转写/提取文件；转写不能覆盖二进制来源。

对动态网页，可同时保存：

```text
raw/articles/source-id.md          # 可检索正文
raw/refs/source-id.snapshot.html   # 允许且必要时的快照
raw/refs/source-id.metadata.json   # 抓取与哈希信息
```

受版权或访问控制限制时，只保存允许的元数据、摘录和个人笔记，不把受限全文复制进可发布仓库。

## 5. 增量与重复判断

先比较 URL、稳定标识和内容哈希，再做语义判断：

- 完全相同哈希：重复，不重新编译。
- 同一稳定来源新版本：保留旧版，标记 `superseded_by`。
- 不同来源表达同一事实：可增强置信度，但仍各自登记。
- 新来源只复述已知内容：记录“无实质增量”，不制造冗余页面。
- 新来源改变结论或适用范围：创建更新任务并标记受影响页面。

## 6. 冲突表示

冲突不能通过选择一句“看起来合理”的话消失。页面应记录：

```markdown
## 冲突与限制

- 来源 A（版本 2.1）规定默认超时为 30 秒。
- 来源 B（版本 1.8）记录为 60 秒，适用于旧运行时。
- 当前结论：2.1 及以后使用 30 秒；1.8 的历史部署仍可能为 60 秒。
```

无法解释的冲突将页面状态设为 `disputed`，并创建审计项。审计结论需要说明接受、部分接受、拒绝或延期的理由。

## 7. 时间与过期

“最新”是查询时条件，不是永久事实。页面的 `updated` 表示最后一次证据审查日期；来源还应保留其自身 `published` 和 `ingested` 日期。高漂移主题可以设置较短新鲜度 SLO，稳定理论页面可设置较长周期。

当来源链接失效但内容仍可验证时，标记访问状态；当核心事实无法再验证时，降低页面状态或明确未知，不继续展示为当前结论。

## 8. 安全与隐私

- 摄取前确认授权范围、许可、个人信息和商业秘密。
- 凭据、Token、Cookie、私钥和未脱敏账号信息不得进入 Wiki。
- 私有来源的派生结论继承访问限制，不能因“只是摘要”自动公开。
- 记录来源位置时避免把带凭据的 URL 原样写入元数据。
- 对删除请求保留最小审计记录，不保留被要求删除的敏感正文。

## 9. 完成检查表

- [ ] 原文、转写和 Wiki 解释清晰分层
- [ ] 来源具有 URL/位置、日期、作者/机构、许可和哈希
- [ ] 精确事实已定位到上下文，不依赖摘要或模型记忆
- [ ] 冲突按版本、范围或方法解释；未解决时显式标记
- [ ] 重复、更新与无实质增量有一致判定
- [ ] 动态和失效来源有访问状态与新鲜度处理
- [ ] 私有数据、许可和派生信息遵守同一访问边界
