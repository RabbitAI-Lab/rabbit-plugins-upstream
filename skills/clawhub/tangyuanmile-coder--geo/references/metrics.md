# 数据口径与计算

所有统计先确定范围：同一单日、已确认题库、白名单采样组合及具体平台／意图／问题。先取该范围实际回答和卡片，再计算比例，禁止平均百分比。

令：

- N：该范围有效回答数（包含无卡回答）。
- A：该范围含任意有效商品卡的回答数。
- E：该范围全部商品卡展示次数（同答同卡去重）。
- B：正文提及目标品牌的回答集合。
- P：正文明确提及目标商品／已确认类目范围的回答集合。
- C：同答含目标范围商品卡的回答集合。
- e：目标范围商品卡展示次数。
- F：目标范围商品位于第1卡位的回答集合。
- R：目标范围卡片的展示序号之和。

| 指标 | 计算 | 显示边界 |
|---|---|---|
| 品牌提及次数 | \|B\| | 仅有监测品牌时；同答出现多次计1条，不限正向推荐 |
| 商品卡提及次数 | e | 同商品不同卡片分别计次；不以回答数代替 |
| 商品卡回答覆盖率 | \|C\| / N | 与含卡回答占比、SOV分别列示 |
| 商品卡承接率 | \|B∩C\| / \|B\| | 即目标品牌→目标商品卡；不是目标品牌全部商品卡 |
| 商品卡SOV | e / E | 未知品牌卡片仍计分母；不是点击或销售份额 |
| 首卡率 | \|F\| / A | 分母为全部含卡回答，不是目标商品出卡回答 |
| 平均卡位 | R / e | 每次卡片的顺序都进入；不是每答最佳卡位均值 |
| 品牌→正文商品承接率 | \|B∩P\| / \|B\| | 正文品牌与商品独立识别 |
| 正文商品→商品卡转卡率 | \|P∩C\| / \|P\| | 不要求正文一定出现品牌 |

无品牌时不展示目标品牌提及次数及两个以品牌为起点的承接指标；品牌榜仍可展示各实际品牌的正文、出卡与品牌级承接。无品牌类目没有虚拟目标，整体展示E、A/N、可区分具体商品数和已确认出卡品牌数；竞争指标落到具体商品行。

目标包含多个商品时，C和F按回答并集统计，e和R按卡片合计。不能把各商品覆盖率相加。客户报告明确列出目标集合及其范围。

## 正文与商品卡状态

有品牌模式四状态：B∩C、B\C、C\B、非(B∪C)，互斥且合计N。

八状态：B、P、C分别是／否的笛卡尔积，每答只进入一项，合计N。零样本状态保留，0不能解释为逻辑不可能。卡片不回填正文，不强行假设“有目标卡必有正文品牌”。删除“八状态下的其他商品卡”交叉表，不在附录恢复。

无品牌具体商品可展示P与C的四状态，不制造B。无品牌类目不展示目标品牌／目标商品的八状态表。

## 品牌双榜

独立扫描清理后的正文，补全实际出现的品牌；不以卡片品牌集合限制正文品牌榜。

- 正文榜：品牌被提及的回答数降序；正文提及率=该品牌正文回答数/N。
- 商品卡品牌榜：已核验品牌全部商品卡次数降序；品牌SOV=该品牌卡次数/E。
- 品牌级商品卡承接率=正文提及该品牌且同答出现其任一商品卡的回答数/正文提及该品牌回答数。

“品牌级任一商品”与“目标指定商品”承接率必须在标题、说明中明确区分。未知品牌保留为待确认归属，不参与已确认品牌Top榜名次，但卡片事件不从E移除。

## 榜单、竞品和品牌内占比

每个局部范围按商品卡提及次数降序；同次数按出卡回答数降序，再按商品名称、内部归并标识升序。明确这一排序规则，不伪造并列名次。

平台与意图榜Top10；目标不在Top10时附列实际排名，没出卡则0、无排名。不同问题可能有完全不同Top商品，因此逐题各平台独立列榜，在附录展示，不用固定全局竞品列的问题矩阵。

有品牌竞品为同题库中实际出现、归属已确认的其他品牌商品Top5，排除同品牌商品与未知品牌。无品牌模式按具体商品展示整体Top20份额及Top5竞争位置，不称为某品牌竞品。商品数不够时只列真实条目。

品牌内商品卡占比=单一商品卡次数/目标品牌全部商品卡次数。包含目标商品及同品牌其他商品，所有分子合计等于品牌卡片总数；这是品牌内分母，不能写作全品牌SOV。

## 电商信息

按榜单局部范围、来源和店铺聚合，列示最低至最高采样报价与“有报价次数/该项卡片次数”。不把缺失、区间字符串或无法判断的金额当成0；不从其他平台或其他意图借价格。真0元可保留，但有原始报价证据。价格没有统一规格，不作单价性价比推断。店名不代表授权资质。

## 显示与对账

比例和均值保留两位小数，使用四舍五入。分母为0显示“不适用”，不显示0%、100%、NaN或无穷。表下注明相应范围、公式、实际分子/分母；四状态与八状态合计N，商品次数合计E，三平台次数合计整体。显示舍入可能使占比合计略偏100%，底层使用未舍入数值。
