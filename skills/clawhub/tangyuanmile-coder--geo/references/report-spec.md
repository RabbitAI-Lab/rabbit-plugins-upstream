# 客户静态报告结构

本模板继承已经确认的商品诊断报告样式。`assets/report.css` 是原正文样式；`assets/fixed-navigation.css` 是独立的固定导航样式。不要为迎合其他通用 GEO 模板替换为品牌综合得分或六／七部分报告。

## 固定结构与模式差异

| 部分 | 有品牌＋商品/类目 | 无品牌商品/类目 |
|---|---|---|
| 封面 | 名称、单日、有效回答、正文品牌/目标卡数据概览 | 名称、单日、有效回答及实际具体商品概览 |
| 一、诊断范围与样本概况 | 品牌、名称层级、已确认目标集合、实际平台样本、完整题库、意图和归并边界 | 明确未预设品牌；类目下不造虚拟商品；相同样本与题库说明 |
| 二、整体表现 | 七项核心指标及两项正文转卡补充；四状态、八状态；目标商品承接分平台；两层展示结构；品牌双榜与同品牌对照 | 具体商品可保留无品牌的目标商品指标及P/C四状态；类目整体只显示样本与实际商品卡总览；保留品牌双榜和两层结构 |
| 三、各平台商品Top榜单 | 平台Top10；意图×平台Top3速览；各意图各平台独立Top10；目标高亮、榜外补列 | 每个平台和意图展示实际的具体商品，保留品牌、电商来源、店铺和采样价格 |
| 四、竞品对比与竞争力 | 目标＋外部Top5商品的整体/三平台SOV；目标品牌内部商品卡展示分布；首卡率和平均卡位对比 | 具体商品Top20整体/平台SOV、实际Top5首卡/卡位比较；不假造目标品牌内部表 |
| 数据明细附录 | 完整品牌对照、各平台品牌明细、品牌别名、逐题平台Top10、逐题八状态、与正文相同竞品范围的指标明细 | 品牌明细、别名及逐题具体商品Top10；无品牌不展示目标品牌八状态 |

有品牌＋类目时，正文“商品”指已确认的目标类目范围；商品卡目标仍由该品牌多个具体商品构成。不要把类目命中率写成某一个具体系列命中率。

## 已删除模块

- “八种状态下的其他商品卡”交叉表：直接删除，不移入附录。
- 同品牌其他商品的旧完整指标表：替换为“目标品牌商品卡展示分布”，不要在附录恢复旧表。
- 固定商品列的“问题竞争矩阵”：删除，不移入附录；以逐意图、逐问题独立的平台商品榜表达差异。
- 不增加趋势、同场领先率、规格包装拆分、原因分析、结论建议或综合得分。

其他已经确认的模块保持；无数据时保留适用模块并说明范围和缺失，不以删模块掩盖样本问题。输入模式不适用的目标品牌内容按模式隐藏，不能填虚构0值。

## 静态与导航

交付一个能离线打开的HTML，内联CSS，不依赖 CDN、脚本、外部图片或账户登录。全部信息展开，允许原生锚点导航，不要筛选器、折叠、分页按钮或必须交互才能获取的数据。

固定导航8项：总览、**诊断范围**、整体表现、品牌双榜、平台榜单、搜索意图、竞品对比、数据附录。第1节标题固定为 **诊断范围与样本概况**。桌面单行，手机两行；打印时隐藏导航，不隐藏报告内容。所有锚点须正确跳转，标题不能被导航盖住。

## 口径说明位置

- 指标卡紧邻计算口径表，列实际分子／分母。
- 平台及意图榜上方写样本量；下方写该局部范围的覆盖率、SOV、首卡率及卡位口径。
- 目标商品承接分平台表明确品牌与目标商品名称；品牌双榜对照明确“该品牌全部商品”。
- 电商信息旁写来源／店铺报价范围、报价次数、价格未统一规格及非当前售价。
- 竞品首表只展示份额，减少与前面指标重复；同品牌展示表明确品牌内分母。

客户正文使用业务名称，不展示原始字段、内部编码、原始文件名、账号信息或本机路径。信息必须来自当前配置与实际数据，不能复制示例品牌、日期、历史样本量或商品次数。

## 交付验证

1. 从当前原始样本重放，核验五组合、单日、问题匹配与实际采样量。
2. 核验正文卡片分离、归属映射、去重与卡位，以及所有整体/局部指标分子分母。
3. 检查两种输入和两种名称层级、目标缺失、零卡、未知品牌、榜外目标及不齐样本。
4. 比对原CSS，检查无已删除模块及无生造模块。
5. 真实浏览器检查桌面浅色、手机浅色、桌面深色，点击全部8个导航并查看长榜单。
6. 最终HTML与审计记录的SHA256一致；没有文件系统 hidden 标记，不能仅因为脚本结束就宣称交付验证完成。
