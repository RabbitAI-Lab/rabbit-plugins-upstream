## Description: <br>
Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
API developers, backend teams, developer-experience teams, and maintainers use this skill to plan, generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. It supports practical workflows, checklists, analysis, code-oriented changes, and verification notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger wording around OpenAPI, Swagger, REST APIs, and API documentation may invoke the skill for requests that only need general API discussion. <br>
Mitigation: Use explicit invocation or tighten trigger phrasing when the skill should only handle OpenAPI generation, improvement, or validation tasks. <br>
Risk: Generated API documentation can be incomplete or misleading if the provided routes, schemas, or authentication behavior are stale. <br>
Mitigation: Review outputs against the current API implementation and run the selected OpenAPI validation or contract checks before publishing. <br>
