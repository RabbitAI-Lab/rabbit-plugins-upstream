# Model Advisor — 智能模型选择顾问

> WorkBuddy 技能 | 根据任务类型自动推荐最优AI模型，平衡效率、质量与Token成本

---

## 功能亮点

- [ANALYZE] **智能检测** — 自动识别5大任务类型（量化交易、代码、文档、对话、隐私）
- [BEST] **精准推荐** — 根据任务特征从12+模型中推荐最优选择
- [COST] **成本优化** — Token成本计算 + 分层使用策略，大幅节省开支
- [CMD] **一键切换** — 输出模型切换命令，即换即用
- [OK] **持续学习** — 记录用户偏好，推荐越用越准

---

## 适用人群

| 用户类型 | 痛点 | 解决方案 |
|---------|------|---------|
| AI重度用户 | 不知12个模型如何选 | 自动检测任务类型 + 精确推荐 |
| 成本敏感用户 | Token消耗过快 | 分层策略，节省30-50%成本 |
| 量化交易员 | 需要强推理模型 | 精准推荐Pro级别模型 |
| 开发者 | 代码质量 vs 成本难平衡 | 根据代码复杂度分档推荐 |
| 隐私敏感用户 | 不想数据上云 | 推荐本地模型（零成本） |

## 快速开始

### 安装

从 WorkBuddy 技能市场搜索 "model-advisor" 安装，或导入 `.skill` 文件。

### 使用

**自动触发（推荐）**：直接发起任务，技能自动分析并推荐。

**手动触发**：

```
用什么模型分析股票？  → 显式推荐
帮我写个Python脚本   → 自动推荐代码模型
总结这个PDF报告       → 自动推荐文档模型
```

## 使用示例

### 示例1：量化交易

**用户输入**：帮我分析今天A股的强势股，给出评分和买入建议

**技能输出**：

```
[ANALYZE] 任务类型检测：量化交易分析
[BEST] 推荐模型：Deepseek-V4-Pro (deepseek-v4-pro)
[INFO] 推荐理由：股票评分和买入建议需要强推理能力
[COST] Token成本：高 (~¥0.042/次)
[CMD] 切换命令：/model deepseek-v4-pro
```

### 示例2：代码编写

**用户输入**：帮我写一个Python函数，计算股票MACD指标

**技能输出**：

```
[ANALYZE] 任务类型检测：代码编写
[BEST] 推荐模型：DeepSeek-V3.2 (deepseek-v3-2-volc)
[INFO] 推荐理由：代码能力强，特别适合Python量化代码编写
[COST] Token成本：中 (~¥0.03/次)
[CMD] 切换命令：/model deepseek-v3-2-volc
```

### 示例3：日常问答

**用户输入**：什么是MACD指标？怎么计算？

**技能输出**：

```
[ANALYZE] 任务类型检测：日常对话/Q&A
[BEST] 推荐模型：Deepseek-V4-Flash (deepseek-v4-flash)
[INFO] 推荐理由：简单概念解释，低成本模型即可
[COST] Token成本：极低 (~¥0.003/次)
[CMD] 切换命令：/model deepseek-v4-flash
```

### 分层策略节省效果

使用分层策略（简单任务用Flash，中等用Turbo，复杂用Pro），相比全Pro模式可节省 **40-60%** Token成本。
