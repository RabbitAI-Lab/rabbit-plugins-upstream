# 智能模型选择顾问 (Model Advisor)

## 概述

本技能根据任务类型、Token成本、响应速度等多维度，为用户推荐最适合的AI模型，实现效率、质量、成本的最优平衡。

### 2.5 Token 成本计算

#### 成本等级定义

| 等级 | 描述 | 适用场景 |
|------|------|---------|
| 零 | 本地模型，无API成本 | 隐私任务、大量重复任务 |
| 极低 | <¥0.001/1K tokens | 简单问答、快速查询 |
| 低 | ¥0.001-0.005/1K tokens | 日常对话、简单代码 |
| 中 | ¥0.005-0.01/1K tokens | 复杂代码、中等推理 |
| 高 | >¥0.01/1K tokens | 强推理、复杂分析 |

#### 典型任务成本估算

假设单次任务平均消耗 **2K input + 1K output = 3K tokens**：

| 模型 | 成本等级 | 单次估算 | 100次/天 | 1000次/月 |
|------|---------|---------|----------|-----------|
| Deepseek-V4-Flash | 极低 | ~¥0.003 | ¥0.3 | ¥3 |
| Kimi-K2.5 | 低 | ~¥0.015 | ¥1.5 | ¥15 |
| GLM-5.0-Turbo | 低 | ~¥0.015 | ¥1.5 | ¥15 |
| DeepSeek-V3.2 | 中 | ~¥0.03 | ¥3 | ¥30 |
| GLM-5.1 | 中 | ~¥0.03 | ¥3 | ¥30 |
| Deepseek-V4-Pro | 高 | ~¥0.06 | ¥6 | ¥60 |
| Hy3 preview | 高 | ~¥0.06 | ¥6 | ¥60 |
| 本地模型 | 零 | ¥0 | ¥0 | ¥0 |

#### 成本优化建议

1. **分层使用策略**
   - 简单任务 → Flash模型（成本最低）
   - 中等任务 → Turbo模型（平衡）
   - 复杂任务 → Pro模型（质量优先）

2. **上下文管理**
   - 及时清理无关对话历史
   - 避免重复发送大段文本
   - 使用简洁的prompt

3. **批量处理**
   - 相似任务批量处理
   - 复用上下文，减少重复token消耗

4. **本地模型使用**
   - 隐私敏感任务 → 本地模型
   - 大量重复任务 → 本地模型
   - 离线环境 → 本地模型

#### 成本计算公式

```
总成本 = (Input Tokens × Input Price + Output Tokens × Output Price) × 次数

示例（Deepseek-V4-Pro）：
- Input: ¥0.014/1K tokens
- Output: ¥0.014/1K tokens
- 单次任务: 2K input + 1K output = 3K tokens
- 单次成本: (2 × 0.014 + 1 × 0.014) = ¥0.042
```

## 使用流程

### 步骤1：检测任务类型

分析用户请求，识别关键词：

```
IF 包含["股票","选股","评分","回测","行情","A股"] → 量化交易
ELIF 包含["代码","函数","调试","bug","实现","Python"] → 代码编写
ELIF 包含["PDF","文档","报告","总结","分析文档"] → 长文档处理
ELIF 包含["本地","隐私","离线","敏感"] → 隐私任务
ELSE → 日常对话
```

### 步骤2：应用推荐规则

根据检测到的任务类型，参考上方的「任务类型→推荐模型映射」表，选择最优模型。

### 步骤3：输出推荐结果

以以下格式输出推荐：

```
[ANALYZE] 任务类型检测：[检测到的任务类型]
[BEST] 推荐模型：[模型名称] ([模型ID])
[INFO] 推荐理由：[简要说明为什么推荐这个模型]
[COST] Token成本：[成本等级]
[CMD] 切换命令：/model [模型ID]
```

### 步骤4：记录用户反馈（可选）

如果用户接受了推荐或手动选择了其他模型，记录偏好用于优化未来的推荐。

## 自动化推荐触发词

### 主动触发场景（技能应自动执行）

当用户发起以下类型的新任务时，**主动分析并推荐模型**：

| 任务特征 | 检测关键词 | 动作 |
|---------|-----------|------|
| 量化交易 | "股票"、"选股"、"评分"、"回测"、"行情"、"A股"、"交易" | 自动推荐推理型模型 |
| 代码编写 | "写代码"、"函数"、"实现"、"Python"、"脚本" | 自动推荐代码型模型 |
| 调试修复 | "调试"、"bug"、"修复"、"报错" | 自动推荐代码理解强的模型 |
| 文档处理 | "PDF"、"文档"、"报告"、"总结"、"分析文档" | 自动推荐长上下文模型 |
| 简单问答 | "什么是"、"解释"、"怎么"、"为什么"、"帮我" | 自动推荐低成本模型 |
| 隐私任务 | "本地"、"隐私"、"离线"、"敏感数据" | 自动推荐本地模型 |

### 显式触发词（用户明确询问）

当用户提到以下关键词时，触发模型推荐：

| 触发词 | 动作 |
|-------|------|
| "用什么模型" | 分析当前任务并推荐 |
| "切换模型" | 显示可用模型列表+推荐 |
| "模型推荐" | 完整推荐流程 |
| "最优模型" | 根据任务类型推荐最优 |
| "当前模型" | 显示当前模型配置 |
| "模型列表" | 显示所有可用模型 |

### 日常任务中的自动应用

**本技能应在以下日常场景主动应用**：

1. **会话开始**：检测用户第一个任务，主动推荐最优模型
2. **任务切换**：检测到任务类型变化（从代码→文档），建议切换模型
3. **Token优化提醒**：长对话时，主动建议切换到低成本模型
4. **模型性能反馈**：任务完成后，询问推荐是否满足需求

## 注意事项

1. **Auto模式**：如果用户没有特殊需求，建议保持Auto模式，系统会自动选择
2. **本地模型前提**：使用本地模型需要已安装Ollama且模型已下载
3. **成本敏感**：对于高频简单任务，优先推荐Flash模型节省Token
4. **质量优先**：对于量化交易等关键任务，优先推荐Pro模型保证质量
