# 模型选择规则参考

## 规则优先级

1. 用户显式指定 > 2. 任务类型自动匹配 > 3. 成本优化建议

## 任务检测关键词库

### [Q] 量化交易分析
```
关键词: 股票, 选股, 评分, 回测, 行情, A股, 港股, 美股, 交易, 技术指标,
       MACD, KDJ, RSI, 布林带, 成交量, 涨跌, 大盘, 指数, 板块, 涨停, 跌停
```

### [DEV] 代码编写/调试
```
关键词: 代码, 函数, 调试, bug, 实现, Python, JavaScript, 脚本, API, 接口,
       数据库, SQL, HTML, CSS, 前端, 后端, 框架, 部署, 配置, 重构, 优化
```

### [DOC] 长文档处理
```
关键词: PDF, 文档, 报告, 总结, 分析文档, 阅读, 翻译, 摘要, 合同, 协议,
       论文, 说明书, 手册, 规章, 制度
```

### [PRV] 隐私敏感任务
```
关键词: 本地, 隐私, 离线, 敏感, 加密, 个人信息, 身份证, 银行卡, 密码, 密钥
```

### [CHAT] 日常对话/Q&A（默认）
```
不匹配以上任何分类时，默认为日常对话
```

## 模型能力评分规则

- 推理能力: 基于复杂逻辑分析、多步推理表现
- 代码能力: 基于代码生成、调试、重构表现
- 速度: 基于首Token响应时间和总输出速度
- 成本: 基于Input/Output Token单价
- 长上下文: 支持的最大上下文窗口
- 多模态: 是否支持图片输入

## 推荐降级策略

当首选模型不可用时，按以下顺序降级：

| 任务类型 | 首选 | 降级1 | 降级2 |
|---------|------|-------|-------|
| [Q] 量化 | Deepseek-V4-Pro | Hy3 preview | GLM-5.1 |
| [DEV] 代码 | DeepSeek-V3.2 | Deepseek-V4-Pro | GLM-5.0-Turbo |
| [DOC] 文档 | Kimi-K2.6 | Kimi-K2.5 | DeepSeek-V3.2 |
| [CHAT] 对话 | Deepseek-V4-Flash | Kimi-K2.5 | MiniMax-M2.7 |
| [PRV] 隐私 | qwen2.5:7b | llama3.2:latest | 无降级 |

## 成本计算公式

```
单次成本 = (Input Tokens / 1000 * Input Price) + (Output Tokens / 1000 * Output Price)
```

默认估算: 2K input + 1K output = 3K tokens/次

## 用户偏好覆盖

用户在 MEMORY.md 中记录的模型偏好会覆盖默认推荐。
例如：用户偏好 Deepseek-V4-Pro 用于代码编写，则该类型首选 Deepseek-V4-Pro。
