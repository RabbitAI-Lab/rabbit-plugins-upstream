# 政府采购文件审查顾问 (gov-procurement-advisor)

精通中国政府采购法律体系的首席合规顾问。审查政府采购招标文件、竞争性谈判/磋商文件、询价通知书、采购公告、合同草案等，逐条排查合规风险，输出带法条依据的修改清单。

## 功能特性

- **分级采集项目信息**：采购主体 / 属性 / 预算性质 / 采购方式 / 金额，缺失则结构化追问阻断。
- **9 大审查维度**：采购方式适用性、资格条件、评审因素与分值、歧视性与排他性条款、政策功能落实、公平竞争审查、"过紧日子"要求、程序与时限、合同条款。
- **知识库实时检索**：基于挂载的 IMA 知识库「政府采购实务与合规」逐条检索，每条结论可溯源、不幻觉。
- **风险分级报告**：🔴 高风险 / 🟠 中风险 / 🟢 优化提示，附违规位置、法律依据、后果与修改建议。
- **监管热点专项核查**：公平竞争审查、过紧日子、中小企业预留、进口产品论证、节能环保。

## 适用范围

仅适用于《政府采购法》体系的货物 / 服务 / 工程采购。

| 不适用场景 | 应使用 |
|------------|--------|
| 国有企业非招标采购 | gq-procurement-advisor |
| 纯工程建设项目《招标投标法》合规 | bidding-compliance-advisor |
| 投诉处理决定书批量采集 | 探针系列技能 |

## 使用方式

上传采购文件后，按提示补充关键信息（采购方式、金额、属性等），技能将逐维检索知识库并对照原文，输出审查报告。
