## Known Risks and Mitigations: <br>
Risk: APIDot API keys or private media workflow data could be exposed through client-side code, public repos, logs, screenshots, or chat output. <br>
Mitigation: Keep APIDOT_API_KEY server-side, avoid logging prompts, media URLs, callback URLs, generated video URLs, or credentials, and use a backend secret manager where available. <br>
Risk: APIDot model fields, availability, limits, or commercial terms may change after this documentation-only skill release. <br>
Mitigation: Verify the current APIDot docs and model page before preparing real requests or making live API calls. <br>
