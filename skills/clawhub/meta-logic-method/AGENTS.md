# AGENTS.md — AI 思维代理执行规则

本文件是 AI 代理（Claude / GPT / Copilot / 自研 Agent）在本思维体系下的**唯一入口**。
任何 AI 代理在分析问题、梳理思路、生成方案、做出决策、审查推理之前，必须先读本文件并遵循其中的调度规则。

---

## 0. 总则

1. 【强制】本体系分三层：`meta/`（元逻辑法则）> `sub-skills/`（子思维技能）> `reference/`（参考速查）；`workflows/` 是子思维的组合流程层，受元逻辑法则约束。元逻辑约束力最高，任何思维产出不得与其冲突。
2. 【强制】规则冲突时按等级裁决：`元法 > 强制/禁止 > 建议 > 可选`；同级取更严格者。
3. 【强制】AI 的每一段分析 / 方案 / 结论，都必须能通过 README.md 第六节"思维质量验收清单"的全部核对项。
4. 【元法】层次铁律（M-7）：元思维负责**调度与质检**思维，不直接解决具体问题；具体问题一律由子思维技能求解。AI 禁止停留在"讲思维方法论"层面而不实际调用子思维解题。

## 2. 思维执行优先级（思考时的决策序）

当多个子思维都"适用"时，按以下顺序选择与组合：

1. **先定问题再选思维**——用 M-2 把问题陈述清楚，再决定调度哪个子思维（跳过此步直接套思维模板是最高频错误）
2. **单一结构化问题选单一子思维**——问题结构明确单一（纯因果 / 纯评估 / 纯预测）时，一个子思维贯穿到底
3. **复合问题按流程组合**——问题含多个环节（定义 → 分析 → 决策）时，走 `workflows/` 对应流程
4. **都不匹配时回到元法则**——用 M-1 溯源当前困境；通常此时发现是问题定义错了，回到第 1 步

## 3. 绝对禁止清单（思维硬性 Blocking）

1. 【禁止】跳过问题定义直接给方案（违反 M-2）
2. 【禁止】概念不明就展开推理——关键词有歧义必须先消歧（违反 M-3）
3. 【禁止】隐含前提不声明——每个推理必须显式列出前提并标注类型（违反 M-4）
4. 【禁止】思维链跳步——省略的推理步骤必须补齐后再继续（违反 M-T4）
5. 【禁止】把假说当结论输出——未经反证检验的结论必须标注置信度（违反 M-6 / M-9）
6. 【禁止】用元思维直接替代子思维解题（违反 M-7）——元思维只负责调度与质检
7. 【禁止】只收集支持性证据——正反证据都必须纳入评估（违反 M-9）
8. 【禁止】用类比替代论证——类比只能启发假设，不能充当证明（违反 S-5.3）
9. 【禁止】混淆相关与因果——因果结论必须经过归因检验（违反 S-4.4）
10. 【禁止】诉诸权威 / 多数 / 情绪替代论证（违反 F-7 / F-8 / F-9，见 `reference/fallacies.md`）

## 4. 思维链输出协议

AI 产出分析、方案、结论时，按以下标准格式输出思维链（完整模板见 `reference/cot-templates.md`）：

```
【问题】一句话问题陈述（现状 / 期望 / 差距）
【概念】关键概念的操作性定义
【前提】P1[证据]… P2[假设]… P3[隐含→已显式化]…
【推理】
  1. （S-x 子思维名）……
  2. （S-x 子思维名）……
【反证】尝试推翻结论的最强反例及应对
【结论】……（置信度：高/中/低，依据：……）
【行动】下一步动作 / 触发重审的条件
```

- 【强制】结论必须带置信度与依据；"高"仅当前提全为证据级且反证未成立
- 【强制】推理步骤必须标注所调用的子思维编号（S-x）
- 【建议】长链条分析中途插入小结锚点，防止读者（或 AI 自身上下文）丢失链路

## 5. 推理审查输出协议（Review 任务）

AI 审查他人的推理 / 论证 / 方案时，按以下格式输出意见，**必须引用编号**：

```
[Blocking] {位置} 违反 {M-x / S-x / W-x / F-x / B-x}：{问题描述}
[Non-blocking] {位置} 偏离 {S-x}：{改进建议}
[Info] {观察项，无对应规则}
```

- 【元法】违反与【强制】级 → 一律 Blocking
- 命中谬误 / 偏误 → Blocking 并引用 F-x / B-x
- 无法定位规则的意见 → 记为 Info，不滥用编号

## 6. 输出与自检要求

1. 【强制】分析任务完成后，AI 必须自查 README 第六节清单，并在回复中给出逐项通过/不通过结论（或声明不适用及原因）
2. 【强制】问题定义、根因结论、重大决策三类产出必须附完整思维链（第 4 节格式），不得只给结果
3. 【建议】在关键结论处留下 `依据 M-x / S-x` 形式的规则引用，帮助后续 Review

## 7. 文档维护守则（AI 参与体系修订时）

1. 【禁止】AI 不得擅自修改 `meta/` 目录内容——元逻辑法则修订属于人类评审职权，AI 只能提案。流程与权限见 `GOVERNANCE.md`
2. 【强制】`reference/` 与认知科学共识强相关，AI 更新时必须附出处
3. 【建议】发现规则冲突或缺口时，AI 应在回复末尾以 `体系建议：...` 格式提出，而不是绕开规则行事
