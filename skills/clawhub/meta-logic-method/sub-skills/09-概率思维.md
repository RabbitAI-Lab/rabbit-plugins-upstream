# S-9 概率思维（Probabilistic Thinking）

> 派生自（主）：M-6 可谬法则。在不确定中判断：用置信度替代非黑即白，用证据更新信念（贝叶斯），用期望值与基率校准决策输入。概率思维是"承认不知道"之后的最优思考方式。

## 适用判据

- **用**：预测、风险评估、证据不全时的判断、需要随新信息修正立场的场景
- **不用**：确定性规则场景（S-3 更快更硬）；纯历史归纳（S-4 已覆盖）

## S-9.1 概率语言强制【强制】

判断输出必须使用概率语言（"约 70% 会发生""两种可能分别是 6:4"），【禁止】二元断言（"肯定会 / 绝对不会"）——除非该判断已被 S-3 演绎证明为必然。

## S-9.2 基率优先【强制】

评估个案概率前，先问**参考类基率**："这类事情通常的发生率是多少？"
先验从基率来，个案信息再做修正（基率忽略 B-12 是预测错误的第一大来源）。
示例：该项目延期概率 → 先查同类项目基率（70% 延期），再考虑"这次团队很强"修正到 55%——而不是从"这次感觉不一样"直接出发。

## S-9.3 贝叶斯更新【强制】

新证据到达时按方向更新信念，而非维持原判：

```
后验 ∝ 先验 × 证据似然
```

操作三问：
1. 看到证据前我的判断是多少（先验）？
2. 若我的判断为真，看到这个证据的概率多大？若判断为假呢？（似然比）
3. 更新后我的判断是多少，幅度与证据强度匹配吗？

【禁止】两极更新：对已有信念只做 0% 或 100% 的跳跃（小证据大更新 = 过度反应；强证据零更新 = 信念固化，B-1）。

## S-9.4 期望值与尾部风险【强制】

决策输入 = 各结果的概率 × 价值（期望值），同时显式评估**尾部**：

- 期望值为正但存在不可承受的尾部损失（破产、不可逆伤害）→ 期望值失效，一票否决（S-11.3 最坏情况线；不可逆伤害参见 S-11.4 可逆性）
- 小概率 × 大损失的乘积必须单列，禁止用"概率很低"稀释（"就 1% 概率" × 全部数据丢失 ≠ 小事）

## S-9.5 校准训练【建议】

量化预测后记录下来，事后核对：说 70% 的事情是否真的十次里中了七次？长期校准是概率思维可检验的证明（M-9 的概率版）。

## 反模式

- 锚定不更新（B-13）：先入为主的数字一路到底
- 赌徒谬误（F-13）：独立事件被赋予记忆（连输五把下次该赢了）
- 精确感谬误：小样本下输出"73.5%"式的伪精确——粗刻度（60% / 70% / 80%）更诚实

## 与其他子思维的组合

- 先验来源：S-4 归纳出的频率
- 更新后的判断喂给 S-11 决策（期望值、可逆性）
- 与 S-2 溯因互补：溯因找"哪个解释最像"，概率给"多像"的量化
- 偏误警惕配套 `reference/biases.md`（B-2 / B-12 / B-13）

## 示例

判断：这次发布是否会有重大故障？
基率（S-9.2）：历史同规模发布重大故障率约 8%。
证据更新（S-9.3）：本次预发环境全量回归通过（若真有隐患，该测试通过概率约 0.5；若无隐患，通过概率约 0.95，似然比约 2:1）→ 后验降至约 4%；但本次包含数据库 schema 变更（该类变更历史故障率约为基率 3 倍，先验上调至约 24%）→ 重算后验约 14%。
产出：约 14% 故障概率（中置信度），含 schema 变更这一尾部风险单列 → 建议增加灰度 + 回滚预案后再发（S-9.4 → S-11）。
