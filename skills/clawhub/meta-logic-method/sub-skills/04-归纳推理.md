# S-4 归纳推理（Induction）

> 派生自（主）：M-6 可谬法则。从具体案例 / 样本上升到规律。归纳永远无法保证结论为真（黑天鹅问题），因此**归纳结论 = 规律 + 置信度 + 适用范围**，三者缺一即违规。

## 适用判据

- **用**：从案例 / 数据 / 历史经验总结规律、提炼模式、建立初步通则供后续演绎使用
- **不用**：个案决策直接外推（样本不足）、需要确定性结论的合规判断（S-3）

## S-4.1 样本代表性检查【强制】

概括前必查：样本是怎么来的？覆盖目标总体了吗？

| 检查项 | 问题 | 对应偏误 |
| --- | --- | --- |
| 抽样方式 | 是随机 / 全量，还是"恰好被看见的"？ | 可得性启发（B-3） |
| 幸存覆盖 | 失败案例在样本里吗？ | 幸存者偏差（B-5） |
| 范围匹配 | 样本来自 A 场景，结论要用于 B 场景吗？ | 外推假设未声明（M-P2） |

样本代表性不足时，【禁止】输出规律，只允许输出"待验证观察"。

## S-4.2 概括与适用范围【强制】

归纳输出的规律必须显式附带适用范围（总体 / 条件 / 时间窗）："在我们观测的 30 个 B 端项目中（范围），需求变更主要发生在评审后两周内（规律），中置信度（强度）"。
【禁止】丢弃适用范围把规律普适化。

## S-4.3 置信度分级【强制】

| 强度 | 依据 |
| --- | --- |
| 低 | 个案 / 少量轶事（n < 5 视为轶事） |
| 中 | 可重复的多次观察、样本过代表性检查 |
| 高 | 大样本 + 对照 / 反例检验通过（此时接近实证规律，但仍保留可谬声明） |

## S-4.4 相关不等于因果【强制】

观察到 X 与 Y 一起出现，仅支持"X 与 Y 相关"。宣布因果前必须排除并至少考虑：

1. **反向因果**：是 Y 导致 X 吗？
2. **第三变量**：Z 同时导致 X 和 Y？（混杂因素）
3. **巧合**：样本量下这种共现出现的概率有多大？

未被排除前，表述必须停留在"相关"；因果声明需经 S-2 溯因的干预性检验（改变 X，Y 变吗？）。
【禁止】在分析产出中出现"数据表明 A 导致 B"式的无检验因果断言。

## 反模式

- 【禁止】以偏概全（F-11）：从"我遇到的三个客户都……"推出"客户都……"
- 【禁止】轻率归纳后当作公理喂给演绎链（污染下游，S-3.3）
- 隐瞒不利案例：只汇报支持规律的样本（确认偏误，B-1；德州神枪手，F-16）

## 与其他子思维的组合

- 为 S-2 溯因提供候选解释来源（历史模式库）
- 为 S-9 概率思维提供先验（归纳出的频率 → 贝叶斯先验）
- 归纳出的规律是 S-5 类比迁移的"源域"候选

## 示例

观察：三个技术团队引入代码评审后缺陷率下降。
轻率归纳：代码评审降低缺陷率（缺失范围与置信度）。
合规归纳：在这三个规模相近（20 人内）的团队中，引入评审后缺陷率下降（中置信度；样本经幸存覆盖检查：另有两个引入评审但无改善的团队被找到，规律修正为"评审 + 评审意见闭环跟踪才与缺陷率下降相关"）。
