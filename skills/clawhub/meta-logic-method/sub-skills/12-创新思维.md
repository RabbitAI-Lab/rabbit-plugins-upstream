# S-12 创新思维（Creative / Lateral Thinking）

> 派生自（主）：M-10 迁移法则；（辅）：M-2 问题先行法则。打破既有思路的路径依赖：重新表述问题、审计约束真假、远域联想、大量产出后再筛选。创新是**可流程化**的发散—收敛过程，不是等灵感。

## 适用判据

- **用**：常规思路已穷尽或明显失效、需要差异化破局、方案空间被"不可能"封死时
- **不用**：常规路径未验证有效前（先验证常规，再创新——创新有成本）；纯评估 / 判断类任务

## S-12.1 问题重述【强制】

发散前至少产出三种重新表述（换表征框架）：

1. 换视角："如何让用户少等待？" → "如何让等待不烦？"
2. 换层级：上移（"如何优化这个表单？" → "用户到底要完成什么？能不能不要表单？"）、下移（拆成子问题）
3. 反向表述（接 S-10）："如何让用户根本不需要来客服？"

多数"无解"问题死于表述锁死在一个框架里——重述本身就是最高杠杆的创新动作。

## S-12.2 约束审计【强制】

把"不可能 / 必须要 / 不能动"的约束逐条列出，逐条审计（与 S-1 联动）：这是**硬约束**（物理 / 法规 / 预算红线），还是**自设约束**（历史惯例、部门墙、"老板可能不喜欢"）？
自设约束标记为"可谈判"，硬约束保留。方案空间通常在审计后扩大数倍。

## S-12.3 发散工具集【强制（至少用一种）】

| 工具 | 操作 | 适用 |
| --- | --- | --- |
| SCAMPER | 对现有对象做 替代/合并/调整/修改/他用/消除/重排 七问 | 改良型创新 |
| 远域类比 | 从生物 / 历史 / 其他行业找同构问题（S-5） | 破局型创新 |
| 随机联想 | 强制把随机对象与问题连接，找结构相似 | 打破定势 |
| 组合矩阵 | 两列已有要素强制两两组合 | 要素重组 |
| 假设条件法 | "如果 X 免费了 / 无限了 / 违法了，会怎么做？" | 松绑想象 |

**发散期纪律**：【禁止】批判任何产出（含自己的）——批判是收敛期的事（过早批判是创意第一杀手）。数量目标先行（先凑够 15 个点子再谈质量）。

## S-12.4 收敛筛选【强制】

切换到收敛模式（与发散显式分离，间隔或换人均可）：用 S-11 判据筛选——新颖度 × 可行性矩阵，选出 2~3 个进入验证；对最激进的选项问"最小验证版本是什么"（降低门槛而非直接否决）。

## S-12.5 最小验证【强制】

收敛后的创意未经检验只是猜想（M-6）：构建**最小可信实验**（原型 / 试点 / A/B / 伪门测试），用真实反馈替代内部辩论。验证假设清单：这个创意依赖哪些假设？最小实验优先证伪哪个（M-9）？

## 反模式

- 【禁止】会议室里用"可行吗"实时枪毙每个新点子（发散 / 收敛混流）
- 【禁止】把新颖当价值：创新的判据仍是问题与目标（M-2），不是"没人做过"
- 灵感等待症：跳过 S-12.1 / S-12.3 的流程化操作，声称"没灵感"

## 与其他子思维的组合

- S-1 提供约束审计、S-5 提供远域联想、S-10 提供反向表述
- 收敛后接 S-11 筛选与 S-9 评估成功概率
- 完整流程见 `workflows/04-创新破局.md`

## 示例

问题："客服成本太高，如何优化？"（原框架：降本 = 裁客服 / 压工资）
重述（S-12.1）："用户为什么需要找客服？" → 约束审计（S-12.2）："客服必须人工"是自设约束 → 发散产出 15 条（节选）：FAQ 机器人 / 自助退款 / 商详页前置答疑 / 删除最易引起咨询的 SKU 特性）→ 收敛：前置答疑（可行性高）+ 删除易混淆 SKU 特性（S-1 式激进项）→ 最小验证：两个品类 A/B 测试，两周看咨询率变化。
