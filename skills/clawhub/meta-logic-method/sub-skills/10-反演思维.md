# S-10 反演思维（Inversion）

> 派生自（主）：M-9 反证法则。正着想不通时倒过来想："怎样才能**必然失败 / 一定搞错**？"把失败路径反转为防御清单。反演的杠杆在于：失败的清单往往比成功的清单短、具体、可执行。

## 适用判据

- **用**：风险排查、查缺补漏、清单制作、premortem（事前验尸）、正面思路陷入僵局时
- **不用**：发散创意（S-12）、从零正向构建方案（先有正向方案，反演才有对象）

## S-10.1 目标取反【强制】

把"如何让 X 成功"改写为"如何让 X **彻底失败**"。取反必须具体（"怎么让这次迁移失败"而非"怎么失败"），否则失败路径会发散失焦。

## S-10.2 失败路径穷举【强制】

列出失败路径，按来源分类扫描（防遗漏）：

| 来源 | 追问 |
| --- | --- |
| 自己 | 我最可能犯什么错？（我历史错误模式） |
| 他人 | 相关方怎么"帮倒忙"？ |
| 环境 | 什么外部变化会打断？ |
| 时间 | 什么会拖到窗口关闭 / 士气耗尽？ |
| 已知未知 | 哪些"我们还没搞清楚"的项可能引爆？ |

## S-10.3 反转为防御清单【强制】

每条失败路径反转为可执行的防御项（动词开头、可检查），形成清单；【禁止】只列风险不给对策（风险列表不是产出，防御清单才是）。
转化模板："若发生 X 则失败" → "行动：事前做 Y / 触发 Z 信号时立即 W"。

## S-10.4 premortem 执行【强制】

用于重要决策时，事前验尸的固定步骤：

1. 设定："已是六个月后，方案彻底失败了。"
2. 各自独立写下失败原因（独立先行，防止锚定 B-13 / 群体思维 B-14）
3. 汇总去重，按"概率 × 杀伤力"排序（S-9.4）
4. Top 3 威胁回写到方案：要么防御（S-10.3），要么触发方案重审

## 反模式

- 反演瘫痪：失败清单越列越长，任何行动都显得危险——反演产物是**可执行**的防御清单，不是不作为的理由
- 只反演一次：方案大改后旧清单失效，须重跑 S-10.2
- 【禁止】用反演伪装否定："你看有这么多风险所以别做了"——风险须过概率评估（S-9），不可能为零

## 与其他子思维的组合

- 事前风险扫描：S-9（概率）× S-10（路径）= 风险矩阵
- 方案流程固定组合：W-3.5（决策前 premortem）、W-4.6（创新方案小步验证的失败预案）
- 防御清单的失效检测接 S-8.4（二阶效应：防御动作本身也会有副作用）

## 示例

目标取反：怎么让新系统上线彻底失败？
失败路径（节选）：① 培训不足，用户弃用；② 新旧系统双跑期数据不一致无人裁决；③ 上线周撞上季度结算高峰。
反转为防御清单：① 上线前完成两轮培训并考核通过才放行（准入门槛）；② 指定双跑数据裁决人，差异 24 小时内必须归档结论（责任到人）；③ 上线窗口避开结算周，写入发布日历（硬约束）。
premortem 汇总后 Top1 威胁为 ②，回写方案增设"数据裁决看板"。
