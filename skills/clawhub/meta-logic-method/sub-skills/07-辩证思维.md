# S-7 辩证思维（Dialectic）

> 派生自（主）：M-6 可谬法则。处理"两个都有一点对"的对立：让正题与反题各自以最强形态出场，在更高层寻找综合（合题）或判定各自的适用边界。辩证反对的是和稀泥，追求的是**结构化的第三种答案**。

## 适用判据

- **用**：观点 / 派系相持不下、权衡型争论（快 vs 稳、集中 vs 分布）、有价值的矛盾需要转化
- **不用**：事实层面的单对错问题（对就是对，用 S-3 / S-6 裁决，无需辩证）；价值分歧转 S-11 显式权衡

## S-7.1 对立命题规范【强制】

把争论收敛为两个（或多个）规范命题，各自用最强形态表述（钢人，非稻草人）：
- 正题 A："X 应当……，因为……（最强理由）"
- 反题 ¬A："X 不应当……，因为……（最强理由）"
命题写不清晰的争论，先回 M-P1 / M-P6 对齐概念与分歧层级。

## S-7.2 各自成立域检验【强制】

为每个命题找**它确实成立的条件域**（在什么前提、场景、目标下它是对的）。
两域完全不重叠 → 这是伪对立（双方在答不同问题，按 M-P6 定位后分歧消解）；两域重叠 → 真矛盾，进入 S-7.3。

## S-7.3 综合或划界【强制】

真矛盾的两条出路，二选一并显式声明：

1. **合题**：找到保留双方核心诉求的第三方案（"既要……又要……"须给出机制，不是口号）——检验标准：合题同时削弱正反双方的最强理由
2. **划界**：判定各命题的适用边界与切换条件（"场景 P 下按正题，场景 Q 下按反题，切换信号是……"）

【禁止】和稀泥式折中："都对都有道理""折中一下各让一步"——无机制、无边界的折中等于没有结论（违反 M-5 / M-T1）。

## S-7.4 矛盾作为信号【建议】

把"感觉别扭 / 矛盾"当作信号而非噪音：矛盾点常指向双方共享的一个未审查前提（挖出它，矛盾常自动消解），或指向一个更深的问题定义缺陷（回 M-2）。

## 反模式

- 【禁止】稻草人化对方（F-5）后"获胜"——赢的是稻草人，不是分歧
- 虚假两难（F-17）：把连续谱问题伪装成二选一再辩证
- 用"辩证"话术回避结论："这事儿要辩证地看"然后不给出 S-7.3 的产出

## 与其他子思维的组合

- 输入端接 M-P6 分歧定位（先确认是推理分歧还是价值分歧）
- 合题方案需过 S-6 批判（合题是否真削弱双方理由）与 S-11 决策（可落地性）
- 划界条件即"触发重审条件"（S-11.6）的思想来源

## 示例

争论："发布要快（A）" vs "质量要稳（¬A）"。
成立域检验：A 在"市场验证期、错误成本低"域成立；¬A 在"核心支付链路、错误代价高"域成立——真矛盾，因两条都主张全域适用。
划界产出：非核心功能灰度快发（A 域），核心链路保留完整回归门禁（¬A 域）；切换信号 = 故障影响的金额阈值与可回滚性。双方最强理由均被机制吸收，非和稀泥。
