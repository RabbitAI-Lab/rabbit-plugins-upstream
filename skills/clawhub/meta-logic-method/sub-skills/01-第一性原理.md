# S-1 第一性原理思维（First Principles）

> 派生自（主）：M-1 溯源法则。把问题拆解到不可再拆的基础事实 / 公理，再自底向上重构解决方案，剥离一切"向来如此"的习惯性假设。

## 适用判据

- **用**：怀疑路径依赖（"行业都这么做"）、成本 / 约束分析、从零设计新方案、既有方案僵化需要重构时
- **不用**：时间紧迫的常规执行（惯例此时是效率工具）、纯预测类问题（改用 S-9）

## S-1.1 假设清单化【强制】

把当前做法 / 方案中所有"被视为理所当然"的假设逐条列出。逐条标记：这是**基础事实**（物理 / 数学 / 法律等硬约束），还是**习惯性假设**（历史选择、他人做法、从无人质疑）？
【禁止】把"大家都这么做""大厂也这样"当作事实——这些是待检验的习惯性假设。

## S-1.2 下沉到底【强制】

对每个习惯性假设追问"为什么"，直到触达不可再拆的事实层（能被验证或被证伪的最小单元）。
终止条件：答案是可验证的事实（"电池能量密度的物理上限是 X"）而非另一层惯例（"供应商报价就这样"）。

## S-1.3 自底向上重构【强制】

从事实层出发，重新推导解决方案：只承认下沉到底的事实与显式声明的设计选择（标注 `[假设]`），不继承任何未经重构的旧假设。
新方案与旧方案的每处差异，必须能指出"旧方案在此采纳了习惯性假设 X，而 X 不成立 / 可替换"。

## S-1.4 成本收益复核【建议】

第一性方案的落地成本（时间 / 迁移 / 组织阻力）必须显式评估——理想方案若不可落地，须在 S-11 决策思维中与渐进方案公平比较，而非直接否决。

## 反模式

- 【禁止】为拆解而拆解：把拆解本身当产出，重构环节缺失（M-L1：拆解是手段）
- 【禁止】把第一性原理当"否定一切惯例"的锤子：惯例被检验后若成立，应显式承认其为基础事实
- 拆解深度的迷失：下沉超过解决问题所需即停止——拆解深度服务于问题（M-2）

## 与其他子思维的组合

- 入口常接 S-3 演绎（从事实层推出方案）与 S-10 反演（新方案会怎么失败）
- 出口常接 S-11 决策（第一性方案 vs 渐进方案的取舍）；创新场景与 S-12 组合（见 W-4）

## 示例

问题：公司官网改版报价 50 万，是否合理？
拆解：官网 = 域名 + 静态资源 + CDN + 少量表单逻辑（事实层）→ 50 万报价中约 47 万买的不是这些事实，而是"定制开发流程"这一习惯性假设 → 重构：静态站点生成 + 托管服务，成本数量级下降；剩余差异（设计能力）是真实价值还是可替换假设，逐项检验。
