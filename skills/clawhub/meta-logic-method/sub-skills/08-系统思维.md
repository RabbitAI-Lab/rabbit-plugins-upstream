# S-8 系统思维（Systems Thinking）

> 派生自（主）：M-8 组合法则。把对象看作**要素 + 关系 + 反馈回路**的整系统，而非孤立零件的线性堆叠。系统思维解释"为什么局部都对了，整体还是出问题"。

## 适用判据

- **用**：牵一发动全身的问题、反复发作的顽疾、优化整体而非局部、评估干预的连锁反应
- **不用**：边界清晰的单点因果（用 S-2 更快）、组件间无强耦合的简单问题

## S-8.1 系统边界与要素【强制】

第一步画边界：什么在系统内、什么当作外部输入（环境）？边界声明是分析的前提——边界画错，后面全错。
边界内列要素时区分**存量**（可积累的状态：库存、债务、信任、技术债）与**流量**（存量的变化率：发布频率、入不敷出）。

## S-8.2 反馈回路识别【强制】

找出至少一条回路（系统思维的核心动作）：

| 回路类型 | 结构 | 后果 |
| --- | --- | --- |
| 增强回路（R） | A → B → 更多 A | 指数增长 / 指数崩塌（复利、口碑、债务） |
| 调节回路（B） | A → 抑制 A 的机制 | 趋向目标或天花板（恒温器、市场饱和） |
| 延迟回路 | A → （延迟）→ B | 振荡、过冲、误判因果（今天招聘 → 半年后到岗） |

【强制】对每个"反复发作的顽疾"回答：**维持它的调节回路是什么？**——顽疾不是没有原因，而是有回路在维持它（例如：加班 → 人才流失 → 人手更紧 → 更多加班，R 回路）。

## S-8.3 杠杆点排序【强制】

干预点按杠杆从低到高（务实版）：

1. 参数调整（调阈值、加资源）——最常用，杠杆最低
2. 回路结构（改变信息流 / 激励方向）
3. 系统目标（回路为之服务的目标本身）
4. 心智模型（目标背后的预设，回 S-1）

【强制】每个候选方案标注它作用在哪一层——只给参数级方案却宣称解决结构性问题，是系统思维的红旗。

## S-8.4 二阶效应预演【强制】

对每个干预方案回答："然后呢？"至少推演两跳（干预 → 直接效果 → 回路反应 → 效果）。
经典陷阱：增强回路被误当线性关系（补贴 → 增长，但补贴停 → 回路反转 → 增长崩塌）；延迟导致的振荡（按当期信号加码，延迟到货时已过剩）。

## 反模式

- 线性单因思维："找到那个 bad apple 就解决了"（回路仍在，换个人照样坏）
- 局部优化：优化单个存量而恶化整系统（仓库零库存 → 物流崩）
- 边界漂移：分析中途悄悄扩 / 缩边界而不声明（M-P5 的系统版）

## 与其他子思维的组合

- 根因分析的宏观侧（S-2 找"哪个原因"，S-8 找"什么结构让这个原因反复出现"，组合见 W-2.4）
- 干预方案的副作用排查接 S-10 反演
- 输出杠杆点后接 S-11 决策（杠杆高 ≠ 现在就该动，变革阻力是真实约束）

## 示例

现象：某团队缺陷修不完，加测试人力后缺陷反而更多。
回路识别：加人 → 排期压力略降 → 承接更多需求（外部激励未变）→ 缺陷流入率上升 → 修不完（B 回路被更强的 R 回路压制）。
杠杆分析：加测试是参数级（第 1 层）；把"承接需求数"从考核改为"逃逸缺陷率"是回路结构级（第 2 层）——后者才是杠杆点。
二阶预演：改考核 → 短期需求吞吐下降（团队开始说"不"）→ 需求质量上升 → 两个月后返工率下降。预演结论：接受短期吞吐代价。
