# S-11 决策思维（Decision Making）

> 派生自（主）：M-8 组合法则；（辅）：M-6 可谬法则。在多个可选项之间拍板：规范决策语句、生成真选项、评估、显式承担后果。决策思维的产出不只是"选了什么"，更是"**为什么这么选 + 什么情况下重审**"。

## 适用判据

- **用**：多方案取舍、资源分配、进退两难、需要留下决策记录（ADR）的场景
- **不用**：只有单一选项时（那是执行问题，不是决策问题——先回 S-12 生成选项）；纯预测问题（S-9）

## S-11.1 决策语句规范【强制】

每个决策先写成规范语句：**在 [约束] 下，为达成 [目标]，从 [选项集] 中选择，判据是 [判据]**。
四要素（约束 / 目标 / 选项集 / 判据）缺一的"决策"是感觉，不是决策。判据必须在看选项**之前**声明——先定判据再看选项，防止为心仪选项量身定制判据（B-2 动机推理）。

## S-11.2 选项生成下限【强制】

真实选项 ≥ 3（含"不行动 / 维持现状"）。只有两个选项时强制追问第三选项（两个都不要呢？混合呢？分阶段呢？）——二选一是虚假两难（F-17）最常见的发生地。

## S-11.3 期望值与最坏情况双评【强制】

每个选项同时评估两条线：

1. **期望值线**：各结果概率 × 价值（S-9.4），处理常规情形
2. **最坏情况线**：这个选项的最坏结果是什么？承受得起吗？

期望值占优但最坏情况不可承受的选项，不得仅凭期望值选中。

## S-11.4 可逆性分级【强制】

每个选项标注可逆性：

| 类型 | 定义 | 决策速度 |
| --- | --- | --- |
| 双向门 | 可退回（灰度、试点、可下线实验） | 快决策，错了再退 |
| 单向门 | 不可逆 / 退回代价极高（架构底座、公关声明、数据删除） | 慢决策，全流程（含 S-10.4 premortem） |

【禁止】用双向门的速度做单向门的决策。

## S-11.5 偏误自查【强制】

拍板前对照自查（`reference/biases.md`）：

- 沉没成本（B-9）：我是在为已投入的成本辩护，还是在为未来选优？
- 损失厌恶（B-4）：避免损失的恐惧是否被放大了 2 倍权重？
- 现状偏误（B-15）：维持现状这个选项是否被免检放行？

## S-11.6 决策记录与重审条件【强制】

决策输出固定包含（模板见 `reference/cot-templates.md` R-4）：

1. 决定 + 一句话理由（引用判据）
2. 放弃选项的放弃理由（防止事后翻案时遗忘当时的判据）
3. 置信度（M-6）
4. **触发重审的条件**（新证据 / 里程碑未达 / 环境变化的具体信号）

无重审条件的决策是赌注；有重审条件的决策是实验。

## 反模式

- 伪决策：选项早已内定，流程是表演（违反 S-11.1 判据前置）
- 决策拖延：用"再调研一下"无限推迟——延迟本身也是选择，其代价须计入
- 【禁止】把可逆决策当单向门反复开会，把单向门决策当可逆随手拍板（双向错配）

## 与其他子思维的组合

- 输入：S-12 生成选项、S-9 评估概率、S-10 排查风险、S-1 拆解目标
- 完整流程见 `workflows/03-方案设计与决策.md`
- 决策记录是 `workflows/05-复盘与思维沉淀.md` 的复盘对象（M-10）

## 示例

决策语句：在两个月窗口内，为把查询延迟从 800ms 降到 200ms，从 {加缓存, 换存储引擎, 优化索引+SQL} 中选择，判据是 [延迟达标概率 × 改动风险，先可逆后不可逆]。
评估：优化索引 = 双向门 + 期望延迟 350ms（不达标但低风险）；加缓存 = 双向门 + 达标概率高；换引擎 = 单向门，排除出本轮。
决定：先加缓存 + 索引优化组合（置信度中）；放弃理由：换引擎达标但单向门风险与两个月窗口不匹配。
重审条件：两周后灰度数据延迟未低于 300ms → 重启换引擎评估。
