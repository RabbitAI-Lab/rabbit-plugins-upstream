# S-6 批判性思维（Critical Thinking）

> 派生自（主）：M-9 反证法则；（辅）：M-3 概念明晰法则、M-4 前提显式法则。对一段论证做结构化审查：主张是什么、理由是什么、假设藏在哪里、证据够不够硬。既审他人，也审自己（动机推理是最大敌人）。

## 适用判据

- **用**：评估论证 / 报告 / 方案、Review 他人推理、发表重要观点前的自查
- **不用**：纯粹的开放发散（过早批判扼杀创意，W-4.4 阶段禁止批判）；事实核查可独立完成的简单场景

## S-6.1 论证重构【强制】

把被审内容重构为标准结构（不论原文多混乱）：

1. **主张**：作者要我接受什么结论？
2. **理由**：作者给出什么支持？
3. **假设**：连接理由与主张的未言明桥梁是什么？（M-P2）
4. **证据**：理由背后有可核查的出处吗？证据级还是传闻级（M-P3）？

重构不出主张 → 原文无论证，只是表态；重构本身就是最有价值的审查产出。

## S-6.2 论证形式检查【强制】

对照 `reference/fallacies.md` 逐类扫描：

- 形式谬误（F-1 ~ F-4）：推理结构无效？循环论证？
- 言据谬误（F-5 ~ F-9）：靠歪曲 / 类比 / 权威 / 大众 / 情绪替代论证？
- 因果与归纳谬误（F-10 ~ F-13）：样本、因果、概率误用？
- 语言谬误（F-14 ~ F-15）：歧义偷换、含混？
- 统计与结构谬误（F-16 ~ F-18）：统计操纵（德州神枪手）、虚假两难、特设修补？
- 其他高频（F-19 ~ F-20）：预设问题、诉诸人身

命中任一谬误 → 按 AGENTS.md 第 5 节格式引用 F-x 输出 Blocking 意见。

## S-6.3 证据质量分级【强制】

| 级别 | 形式 | 强度 |
| --- | --- | --- |
| A | 系统性证据（元分析、RCT、可复现实验） | 强 |
| B | 对照观察、大样本统计、多源交叉印证 | 中 |
| C | 个案、轶事、专家个人经验 | 弱 |
| D | 传闻、匿名信源、"我听说" | 不可用作前提 |

关键前提的证据级别必须显式标注（M-P3），C 级及以下支撑的结论，置信度封顶为"低"。

## S-6.4 强度评级与钢人自查【强制】

输出审查结论时给出论证强度评级（成立 / 部分成立 / 不成立 / 无法评估），并对**自己给出的审查意见**做钢人自查：把原论证补到最强形态后，我的意见还成立吗？（钢人 steelman，对立面是稻草人，F-5）
【禁止】审查自己不喜欢的论证时降标准，审查自己认同的论证时升标准——审查前先声明立场与利益相关（B-2 动机推理的自曝）。

## S-6.5 自审清单【建议】

发表重要观点前，用本技能反向自审：我的主张三问（M-1）答得上来吗？我的证据是几级？我找过反例吗（M-9）？

## 反模式

- 【禁止】稻草人（F-5）：把对方观点歪曲到荒谬再攻击
- 【禁止】为批判而批判：审查意见必须指向论证质量，不指向表达者
- 批判瘫痪：无限度质疑导致无法行动——批判的终点是"置信度 + 行动"（S-11），不是怀疑本身

## 与其他子思维的组合

- 谬误 / 偏误识别依赖 `reference/fallacies.md` 与 `reference/biases.md`
- 对量化论证（数据、预测）叠加 S-9 概率思维审查
- 是 Review 类任务的默认入口技能（AGENTS.md 调度表）

## 示例

被审论证："某大厂推行了 996 并成为行业第一，所以高强度工时带来竞争力。"
重构：主张 = 高工时 → 竞争力；理由 = 单案例共现；假设 = 大厂成功可归因于工时（未言明）；证据 = C 级个案。
检查：归纳谬误 F-11（以偏概全）+ 因果谬误（S-4.4：第三变量——人才密度、资本、时机均未排除）。
评级：不成立。钢人自查：补成"在人才与资本可比的两组公司中，工时与竞争力的相关性如何？"——仍无数据支撑，意见维持。
