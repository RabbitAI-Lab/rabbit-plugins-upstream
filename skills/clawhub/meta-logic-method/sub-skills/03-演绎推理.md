# S-3 演绎推理（Deduction）

> 派生自（主）：M-4 前提显式法则；（辅）：M-3 概念明晰法则。从前提必然推出结论：前提为真且形式有效，结论**必真**。这是唯一能给出确定性结论的推理形式——因此它的前提也必须承受最严格的审查。

## 适用判据

- **用**：规则 / 合规 / 逻辑判断（法条、契约、需求规格、数学证明）、由既定前提推业务结论、验证某解释的预测（配合 S-2）
- **不用**：前提不确定或不完备的现实预测（S-9）、从个案推规律（S-4）

## S-3.1 前提形式化【强制】

把前提写成清晰命题（可判真假的陈述句），逐条编号并标注类型（M-P3）。
【禁止】含混前提入场："系统应该比较安全"不是命题，无法参与演绎。

## S-3.2 有效性检查【强制】

检查从前提到结论的推理形式是否有效（前提真时结论**不可能**假）。常用有效形式：

| 形式 | 结构 |
| --- | --- |
| 肯定前件 | 若 P 则 Q；P；故 Q |
| 否定后件 | 若 P 则 Q；非 Q；故非 P |
| 假言三段论 | 若 P 则 Q；若 Q 则 R；故若 P 则 R |
| 析取三段论 | P 或 Q；非 P；故 Q |

【禁止】两种高频无效形式：
- 肯定后件：若 P 则 Q；Q；故 P（无效，F-2）
- 否定前件：若 P 则 Q；非 P；故非 Q（无效，F-1）

## S-3.3 真实性独立检查【强制】

有效性 ≠ 真实性。形式有效但前提为假时，结论依然不可信。两问分离：

1. 形式有效吗？（推理结构）
2. 前提为真吗？（逐条回查，M-P3 的 `[证据]` 前提是否真的有出处）

结论确定性 = 形式有效性 **AND** 全前提为真；两者缺一，确定性声明作废。

## S-3.4 约束传播【建议】

演绎结论的适用范围随前提传播：某前提仅在条件 X 下成立 → 结论也仅在 X 下成立。输出结论时必须继承前提的适用条件，禁止丢弃条件做普适化声明。

## 反模式

- 【禁止】用三段论包装偏见：先有结论，再倒推挑选前提（动机推理）
- 【禁止】把统计倾向写成全称命题："用户都喜欢 X" → 应为"多数用户倾向 X"（全称命题一个反例即崩塌）
- 前提堆栈过深：五层以上前提链，任一环为假则全链失效——链长时逐环标注置信度

## 与其他子思维的组合

- 为 S-2 溯因做检验（解释 → 预测 → 演绎出可观察事实 → 验证）
- 为 S-6 批判性思维提供论证形式核查工具
- 与 S-9 互补：演绎给确定性（窄），概率给不确定下的判断（宽）

## 示例

前提：P1 `[证据]` 需求规格要求"删除操作必须二次确认"；P2 `[证据]` 该页面的删除按钮当前无二次确认。
推理（肯定前件）：违反规格的行为 = 缺陷；该页面删除无确认 = 违反 P1；故该行为为缺陷。
结论（确定性）：缺陷成立，置信度高——P1、P2 均为可核查的证据级前提。
