# 术语表（Glossary）

> 全体系术语的中英对照与一句话定义。概念有歧义时先查本表（M-P1 / M-P6）；本表未覆盖的新术语，首次使用处必须内联定义。

## 思维体系层

| 术语 | 英文 | 定义 |
| --- | --- | --- |
| 元逻辑 | Meta-logic | 关于思维本身合法性的一套法则体系（M-x） |
| 元认知 | Metacognition | 对自身思维过程的认知与监控（M-1 三问的心理学基础） |
| 思维链 | Chain of Thought | 问题→前提→推理→结论→行动的五环节显式结构（M-T1） |
| 溯源 | Tracing to Source | 沿思维链向上一环节回溯、定位断点的操作（M-1 / M-T2） |
| 断点 | Breakpoint | 思维链中缺失或失效的环节（M-T3） |
| 子思维技能 | Sub-thinking Skill | 从元法则派生的可直接执行推理方法（S-x） |
| 思维流程 | Thinking Workflow | 多个子思维按场景编排的固定序列（W-x） |

## 推理方法层

| 术语 | 英文 | 定义 |
| --- | --- | --- |
| 溯因推理 | Abduction | 从现象反推最佳解释（结论是假说，S-2） |
| 演绎推理 | Deduction | 前提真且形式有效则结论必真（S-3） |
| 归纳推理 | Induction | 从样本上升到规律（永不确定，S-4） |
| 第一性原理 | First Principles | 拆解到不可再拆的事实再自底向上重构（S-1） |
| 反演 | Inversion | 倒过来想"如何必然失败"（S-10） |
| 操作性定义 | Operational Definition | 可观察、可判定的概念定义（M-P1） |
| 钢人 | Steelman | 把对方观点补到最强形态再回应（稻草人的反面，S-7.1） |
| 稻草人 | Strawman | 歪曲对方观点到荒谬再攻击（F-5） |
| 奥卡姆剃刀 | Occam's Razor | 同等解释力下假设更少者优先（S-2.3） |
| 黑天鹅问题 | Black Swan Problem | 归纳永远无法排除未观测反例的根本局限（S-4 前提） |
| 5 Whys | Five Whys | 连问为什么定位根因的实践约定（W-2.3） |

## 概率与决策层

| 术语 | 英文 | 定义 |
| --- | --- | --- |
| 先验 | Prior | 看到证据前的初始判断（S-9.3） |
| 后验 | Posterior | 证据更新后的判断（S-9.3） |
| 基率 | Base Rate | 参考类事件的基础发生率（S-9.2） |
| 似然比 | Likelihood Ratio | 证据在"判断为真 / 为假"两种情况下的出现概率之比（S-9.3） |
| 贝叶斯更新 | Bayesian Updating | 用新证据按似然修正信念（S-9.3） |
| 期望值 | Expected Value | 各结果概率 × 价值的加和（S-9.4） |
| 尾部风险 | Tail Risk | 小概率 × 大损失的组合，须单列（S-9.4） |
| 单向门 / 双向门 | One-way / Two-way Door | 不可逆 / 可逆决策，决定决策速度（S-11.4） |
| 事前验尸 | Premortem | 假设"已失败"倒推原因的风险预演（S-10.4） |
| 触发重审条件 | Reconsideration Trigger | 预先声明的重开决策的具体信号（S-11.6） |
| 决策记录 | ADR (Architecture Decision Record) | 决定 + 放弃选项 + 置信度 + 重审条件的归档（R-4；术语借自软件架构实践，此处泛化为任意重要决策） |

## 系统思维层

| 术语 | 英文 | 定义 |
| --- | --- | --- |
| 存量 / 流量 | Stock / Flow | 可积累的状态 / 存量的变化率（S-8.1） |
| 反馈回路 | Feedback Loop | 输出反哺输入形成的闭环（S-8.2） |
| 增强回路 | Reinforcing Loop | 自我放大 → 指数增长 / 崩塌（S-8.2） |
| 调节回路 | Balancing Loop | 自我抑制 → 趋向目标或天花板（S-8.2） |
| 延迟 | Delay | 回路中的时间滞后，导致振荡与误判（S-8.2） |
| 杠杆点 | Leverage Point | 干预系统中产出变化最大的位置（S-8.3） |
| 二阶效应 | Second-order Effect | 干预引发的连锁反应的下一跳（S-8.4） |
| 混杂因素 | Confounder | 同时导致两事件的第三变量（S-4.4） |

## 创新与验证层

| 术语 | 英文 | 定义 |
| --- | --- | --- |
| 发散 / 收敛 | Divergence / Convergence | 产出选项的扩展期 / 压缩期，两期纪律互斥（S-12.3 / S-12.4） |
| SCAMPER | — | 替代 / 合并 / 调整 / 修改 / 他用 / 消除 / 重排七问（S-12.3） |

| 伪门测试 | Fake Door Test | 先摆"门"验证需求再投入建设的实验（W-4.6） |

| 特设性修补 | Ad hoc Rescue | 给被证伪的解释打不可证伪的补丁（F-18） |
