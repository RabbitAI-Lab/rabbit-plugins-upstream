# R — 思维链输出模板（CoT Templates）

> AI 与人类按本体系产出分析 / 决策 / 审查时的标准输出格式。模板是骨架：条目可按任务裁剪，但**置信度与重审条件不可裁剪**（M-6 / S-11.6）。
> 与 AGENTS.md 第 4、5 节协议配套；W-x / S-x 流程的产出环节直接引用本文件对应模板。

---

## R-1 通用思维链模板（默认模板）

适用：AGENTS.md 第 4 节思维链输出协议；W-1.5 混乱思维梳理输出。

```markdown
【问题】一句话问题陈述（现状 / 期望 / 差距 / 约束）
【概念】关键概念的操作性定义（有歧义的概念必须出现）
【前提】
  P1 [证据] ……（出处）
  P2 [假设] ……
  P3 [隐含→已显式化] ……
【推理】
  1. （S-x 名称）……
  2. （S-x 名称）……
  3. ……（小结锚点：当前链路走到哪，下一步去哪）
【反证】尝试推翻结论的最强反例：……；应对：……
【结论】……（置信度：高 / 中 / 低；依据：……）
【行动】下一步：……；触发重审的条件：……
```

规则：
- 前提三级标注必选其一：[证据] / [假设] / [公理]（M-P3）
- 推理步骤必须标注所调用的子思维 S-x（AGENTS.md 4）
- 置信度"高"仅当前提全为 [证据] 级且反证未成立（M-6）

## R-2 问题定义书与根因链模板

适用：W-2.6 输出。

```markdown
# 问题定义书
- 现状：（可观察事实，量化）
- 期望：（标准 / 目标，来源注明）
- 差距：现状 − 期望
- 约束：（时间 / 资源 / 不可动项）
- 影响：（损失 / 优先级）

# 根因链
- 诱因（本次触发）：……
- 结构性根因（让触发必然发生的结构 / 回路）：……
- 验证状态：
  - 复现关：[✓/✗] ……
  - 消除关：[✓/✗] ……
  - 反证关：[✓/✗] ……
- 结论：……（置信度：……；未过三关的标注为"当前最优假说"）

# 建议入口
→ 转 W-3 做方案设计（问题编号：……）
```

## R-3 论证审查报告模板

适用：S-6 批判性思维输出；Review 任务（AGENTS.md 第 5 节）。

```markdown
# 论证审查报告
## 重构
- 主张：……
- 理由：……
- 假设（未言明桥梁）：……
- 证据分级：A / B / C / D（S-6.3）

## 意见
[Blocking] {位置} 违反 {M-x / S-x / F-x / B-x}：{问题描述}
[Non-blocking] {位置} 偏离 {S-x}：{改进建议}
[Info] {观察项}

## 钢人自查
补强后的原论证：……；我的意见是否仍成立：是 / 否（理由）

## 评级
论证强度：成立 / 部分成立 / 不成立 / 无法评估
```

## R-4 决策记录模板（ADR 风格）

适用：S-11.6 / W-3.6 输出；重大决策归档。

```markdown
# 决策记录：{标题}
- 日期：……　决策人：……　可逆性：双向门 / 单向门
- 决策语句：在 [约束] 下，为达成 [目标]，从 [选项集] 中选择，判据是 [判据]

## 决定
（选择 + 一句话理由，引用判据）

## 放弃选项记录
- 选项 B：放弃理由……
- 选项 C：放弃理由……
（防止事后翻案时遗忘当时的判据）

## 评估摘录
- 期望值：……　- 最坏情况：……　- premortem（单向门必做）：Top 威胁与回写项……

## 置信度与重审
- 置信度：高 / 中 / 低（依据：……）
- 重审条件：（新证据 / 里程碑未达 / 环境变化的具体信号）……
- 验收里程碑：（何时、用什么指标验收）……
```

## R-5 复盘报告模板

适用：W-5 输出。

```markdown
# 复盘报告：{事件}
## 事实回放
（时间线，零评价）
## 结果对比
（预期 vs 实际，逐项；差距归因：候选解释 ≥ 3，含"运气"）
## 思维链复盘
- 当时的前提：哪些被证伪？……
- 当时的推理：哪步跳了？……
- 子思维缺位：本该用 S-x 的地方用了……
- 思维错误模式："我在 [场景] 倾向犯 [错误]"（个人思维 bug 清单 ±）
## 模式沉淀
- 成功机制：……（适用范围：……）
- 失败断点：……（预警信号：……）
- 置信度：低（样本 n=…）→ 下次验证场景：……
## 行动
- 改物：……　- 改制：体系建议：……　- 改脑：预警信号绑定……
```
