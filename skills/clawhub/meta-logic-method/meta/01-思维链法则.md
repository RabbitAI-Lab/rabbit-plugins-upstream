# 01-思维链法则（M-T 系列）— 结构、溯源与断点诊断

> 派生自 M-5 思维链显式法则。本文件定义思维链的标准结构、溯源方向与断点诊断方法，是 `workflows/01-混乱思维梳理流程.md` 的法则基础。

---

## M-T1 思维链五环节【强制】

任何完整思维链必须包含五环节，顺序固定：

```
Q（问题）→ P（前提）→ R（推理）→ C（结论）→ A（行动）
```

- Q：要解决的问题，含现状 / 期望 / 差距（M-2）
- P：前提清单，含类型标注（M-P3）
- R：从 P 到 C 的可检验推理步骤
- C：结论 + 置信度（M-6）
- A：行动 + 触发重审条件（S-11.6）

五环节齐全的思维链才是**可审查**的思维链；缺任一环节的思维产出视为半成品。

## M-T2 溯源方向【强制】

诊断或梳理思维时，沿链**向上一环节回溯**：结论不明 → 回看推理；推理不通 → 回看前提；前提存疑 → 回看概念与问题定义。
根因（断点）通常在结论的**上游**，不在结论本身——"结论错了"是症状，不是病因。

## M-T3 断点诊断法【强制】

对混乱表达按以下顺序定位断点（逐环检查，发现断点即停）：

1. **找结论**：从情绪化 / 琐碎表达中提取事实性陈述与核心主张（"他到底想说什么？"）
2. **回溯推理**：这个主张是怎么得出的？说得出步骤吗？（说不出 → 推理断点）
3. **回溯前提**：推理依赖哪些前提？前提说出口了吗？（没说 → 前提断点，最常见）
4. **回溯概念**：关键词双方理解一致吗？（不一致 → 概念断点）
5. **回溯问题**：真正要解决的问题是什么？（答不上 → 问题断点）

## M-T4 禁止跳步【禁止】

推理步骤之间不允许存在未说明的跃迁。省略的步骤必须补齐后再继续——补齐方式：写出"由 X 到 Y，中间经过了 Z"。
跳步是隐含前提（M-P2）最主要的藏身处。

## M-T5 思维链记录格式【建议】

思维链落笔时使用标准格式（完整模板见 `reference/cot-templates.md`）：

```
【问题】…
【概念】…
【前提】P1[证据]… P2[假设]… P3[隐含→已显式化]…
【推理】1. … 2. …（标注 S-x）
【反证】…
【结论】…（置信度 / 依据）
【行动】…
```

## M-T6 多链并行与分链对比【建议】

存在多个观点 / 方案冲突时，先**各自独立成链**（每条链五环节完整），再做链间对比（对比点：概念是否一致、前提是否相容、推理强度差异）。
【禁止】在未分链的情况下混辩——多条链交织争论是"越吵越乱"的结构性原因。
