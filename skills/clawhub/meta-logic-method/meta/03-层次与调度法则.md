# 03-层次与调度法则（M-L 系列）— 元思维与子思维的分层调度

> 派生自 M-7 层次法则、M-8 组合法则。本文件回答：元思维到底干什么、不干什么；具体问题如何被调度到子思维。

---

## M-L1 元思维不直接解题【元法】

元法则回答"**什么是合法的思维**"，不回答"这个具体问题的答案是什么"。
接到具体问题（"该选 A 还是 B""这个 bug 为什么出现"）时，停留在元层讨论（"我们要先定义什么是选择……"）超过必要的问题澄清时间，即视为违反本条。
元思维的合法性产出只有两类：

1. **调度**：判断问题结构 → 选择子思维 / 流程（查 AGENTS.md 调度表）
2. **质检**：对产出的思维链做验收（README 第六节清单）

## M-L2 子思维调度强制【强制】

接到具体问题，必须判断问题结构并调度至少一个子思维（S-x），推理步骤必须标注所用子思维。
判断问题结构的快速分类法：

| 问题结构 | 特征 | 调度 |
| --- | --- | --- |
| 溯因型 | "为什么会出现 X？" | S-2 溯因 |
| 评估型 | "这个说法 / 方案成立吗？" | S-6 批判 |
| 预测型 | "X 会怎样？" | S-9 概率（辅 S-4 归纳） |
| 构造型 | "如何做出 / 改进 X？" | S-1 / S-12 / S-11 |
| 冲突型 | "两个都对 / 相持不下" | S-7 辩证 |
| 复合型 | 含多个上述环节 | 走 workflows（M-L3） |

## M-L3 复合问题必须走流程【强制】

问题含两个以上环节（如"理清需求 → 找根因 → 出方案"）时，禁止现场随意拼凑子思维，必须按 `workflows/` 对应流程编排；流程缺失某环节时，按该流程文档的步骤逐项执行，不得凭感觉跳过。
现有流程与适用场景见 `workflows/` 目录；新场景无现成流程时，参照现有流程的结构（输入 → 有序步骤 → 输出格式）自建，并遵循 M-L4 质检。

## M-L4 元思维质检职责【强制】

任何思维产出在输出前，必须用元法则完成三查（质检，非解题）：

1. **链完整性查**：五环节是否齐全（M-T1）？推理是否无跳步（M-T4）？
2. **前提显式查**：前提是否全部列出并分级（M-P2 / M-P3）？关键概念是否明晰（M-P1）？
3. **结论可谬查**：是否经过反证（M-9）？置信度是否与前提强度匹配（M-6）？

## M-L5 子思维冲突裁决【建议】

两个子思维对同一问题给出相反结论时（如 S-4 归纳说"历史数据支持"、S-10 反演说"最坏情况不可接受"）：

1. 回到元层定位分歧（M-P6：概念 / 前提 / 推理 / 价值分歧？）
2. 若为前提分歧：检验双方前提的证据强度，取强汰弱
3. 若为价值分歧：转 S-11 决策思维显式权衡风险偏好，而非假装一方"错了"
4. 裁决后记录：为何采信 A 而非 B——该记录是后续复盘（M-10）的关键素材
