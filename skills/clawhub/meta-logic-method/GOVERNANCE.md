# GOVERNANCE.md — 体系治理（本思维体系自身的治理规则）

> 本文件管理 `meta-logic-method/` 思维体系自身的版本、修订、弃用与豁免。
> AGENTS.md 第 7 节（文档维护守则）的流程化落地。版本历史见 `CHANGELOG.md`。

---

## 1. 版本语义（SemVer 映射）

本体系整体采用语义化版本 `MAJOR.MINOR.PATCH`：

| 变更类型 | 版本位 | 示例 |
| --- | --- | --- |
| 元法则条目（M-x）新增 / 修改 / 删除 | MAJOR | 新增元法则、修改 M-7 语义 |
| 【强制】级 S-x / W-x 条目新增或语义变更 | MINOR | 新增子思维技能、新增流程 |
| 【建议】级条目调整、笔误澄清、示例修订 | PATCH | 修正错别字、补充示例 |
| `reference/` 随认知科学共识同步更新 | MINOR | 谬误 / 偏误清单扩充（须附出处，AGENTS.md 7.2） |

**版本号唯一登记处**：`CHANGELOG.md` 首行。每个条目必须写明：版本、日期、变更层级、影响面。

## 2. 修订流程

```
提案 → 评审 → 合入 → 周知
```

1. **提案**：任何人（含 AI）可以提案。AI 提案格式固定为回复末尾的 `体系建议：...`（AGENTS.md 7.3 / R-6 模板）
2. **评审**：
   - 元法则层（`meta/`）：人类评审（体系作者 + 至少一名使用者），全票通过
   - 子思维层（`sub-skills/`）：维护者评审
   - 流程层（`workflows/`）：维护者评审，且须有一次以上实战使用记录
   - 参考层（`reference/`）：核对认知科学出处后更新
3. **合入**：修改文档 + 更新 `CHANGELOG.md` + 重新生成 `INDEX.md`，同一提交内完成，禁止拆分
4. **周知**：MAJOR 变更公告并组织一次示范演练；MINOR 变更周报同步

## 4. 编号守则

1. 编号（M-x / S-x / W-x / F-x / B-x / R-x）**只增不复用**：废弃条目保留编号与 `已废弃（见 x.x）` 标注，防止历史引用悬空
2. 文档文件编号（`01-`、`02-` 前缀）同样不复用；新增文档接续排号
3. 跨文档引用只允许引用编号 + 文件路径，禁止复制规则正文（单一事实来源）
4. 派生关系（元法则 → 子思维）变更属 MAJOR：须同步更新 `meta/00-总纲.md` 派生关系表与 README 第二节

## 5. 弃用流程（Deprecation）

```
标记 Deprecated（注明替代条目）→ 宽限期（≥1 个 MINOR 周期）→ 删除正文、保留编号占位
```

- 弃用标记期内双重合规（旧写法不判违规，但 Review 提示迁移）
- 宽限期结束，按违反替代条目处理

## 6. 例外豁免

【元法】级条目无偏离许可（README 第三节）。确有场景需要临时偏离【强制】级条目时：

1. 豁免必须**书面化**：在本节末尾登记（条目、理由、责任人、到期日）
2. 豁免有**期限**：到期自动失效，续期需重新评审
3. 豁免不得用于同类新场景：仅限登记时声明的具体场景
