# W-4 创新破局流程

> 输入：常规思路失效的问题、被封死的方案空间、需要差异化的局面。
> 输出：经最小验证的创新假设（而非"创意清单"）。
> 调度：S-12 创新思维（主）+ S-1（约束审计）+ S-5（远域联想）+ S-9 / S-10（验证与风险）。
> 场景：增长僵局、同质化竞争、"不可能"约束下的破局、产品差异化。

---

## W-4.1 问题重述【强制】

执行 S-12.1：至少三种重述（换视角 / 换层级 / 反向），选出一个**打开空间**的重述作为本流程的问题定义（重述后的问题仍须过 M-2 规范化——重述不是逃离问题，是逼近真问题）。

## W-4.2 约束审计【强制】

执行 S-12.2 + S-1：列出全部"不可能 / 必须"，逐条标记硬约束（保留）/ 自设约束（标记"可谈判"并注明谈判对象）。
产出：约束账本——方案空间 = 硬约束内的全部路径；账本让团队看见"被封死的空间"里有多少是自己封的。

## W-4.3 远域联想【强制】

执行 S-5 完整流程：目标域问题结构化 → 跨域扫描同构问题（生物 / 军事 / 历史 / 其他行业，S-5.1 提取机制而非表层）→ 结构映射检验（S-5.2）→ 登记失配项（S-5.4 负类比）。
产出：至少 2 条机制级假设（"若机制 M 在本域成立，则……"——假设形态，非方案形态，S-5.3）。

## W-4.4 强制发散【强制】

执行 S-12.3：选定发散工具（SCAMPER / 组合矩阵 / 假设条件法至少其一），数量下限 15 条，发散期禁止批判（纪律由流程主持者执行——会议场景显式宣布"接下来 20 分钟禁止说不行"）。

## W-4.5 收敛筛选【强制】

切换收敛模式（与 W-4.4 显式分离）：新颖度 × 可行性矩阵初筛 → S-11 判据复筛 → 产出 2~3 个候选；对最激进候选问"最小可信版本是什么"（S-12.4，降门槛而非否决）。

## W-4.6 最小验证【强制】

对候选逐一回答（S-12.5 + M-9）：

1. 它依赖的关键假设是什么？（按可证伪性排序，最可证伪的优先）
2. 最小实验是什么？（原型 / 试点 / A/B / 伪门测试，规模最小但反馈真实）
3. 实验失败路径（S-10.1 取反）与止损线是什么？

【禁止】未经 W-4.6 直接全量投入——创新方案的置信度只能由实验给出（M-6），不能由热情给出。

## 反模式

- 【禁止】在 W-4.4 阶段批判（流程最常见死法）
- 【禁止】把 W-4.3 的类比假设当已验证结论（S-5.3）
- 重述后的"新问题"脱离原目标约束（重述漂移：越改越爽，离原始目标越来越远——每轮重述回查 M-2 约束）

## 示例（微型，节选）

僵局：工具类 App 付费转化率 2%，行业打法（功能付费墙）全部失效。
重述（W-4.1）："怎么让用户付费" → "用户完成什么任务时**缺了我们才不行**？"
约束审计（W-4.2）："工具必须免费"= 自设约束（可谈判）；"用户是价格敏感型" = 待检验假设。
远域联想（W-4.3）：剃须刀（吉列）机制 = 耗材复购承载利润 → 映射：高频消耗品 = 模板 / 素材 / 云同步（失配登记：刀片有物理独占性，数字素材可盗版 → 防御方向：便利性而非独占性承载付费）。
发散（W-4.4）：23 条，收敛（W-4.5）出 3 个，最激进候选"按产出量计费"最小版本 = 单一功能用量计费 A/B。
验证（W-4.6）：关键假设 = 高量用户对按量付费的接受度 > 功能墙；止损线 = A/B 转化低于现状 50% 即回滚。
