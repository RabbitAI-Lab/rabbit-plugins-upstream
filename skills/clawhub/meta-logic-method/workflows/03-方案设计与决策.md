# W-3 方案设计与决策流程

> 输入：已定义的问题（W-2 产出）或明确的决策需求。
> 输出：带置信度与重审条件的决策记录（ADR 风格）。
> 调度：S-1 第一性原理（目标拆解）+ S-12（选项生成）+ S-9 / S-10（评估与风险）+ S-11（拍板）。
> 场景：技术选型、方案评审、资源分配、路线取舍。

---

## W-3.1 目标与约束显式化【强制】

先把"要达成什么"拆干净（S-1）：

- **真目标**：表面要求背后的实际目的（"要一份周报"的真目标可能是"让上级可感知进展"——真目标打开方案空间）
- **硬约束**：预算 / 时间 / 法规 / 技术红线（不可谈判）
- **软约束**：偏好 / 惯例 / 组织阻力（可谈判，标注为可谈判）

目标必须可判达标（"快"→"P95 < 200ms"），否则 W-3.6 无从验收。

## W-3.2 选项生成【强制】

用 S-12.3 发散工具生成选项，下限三条（S-11.2，含"维持现状"）；常规选项 + 至少一条非常规选项（远域类比 / 约束审计产出的激进项）。
【禁止】发散期批判（S-12.3 纪律）；【禁止】只带一个方案进评审会——单方案评审是伪评审。

## W-3.3 选项评估【强制】

对每个选项过四查（逐项留下记录，禁止合并为一句话评价）：

| 查项 | 工具 | 回答 |
| --- | --- | --- |
| 判据符合度 | S-11.1 先行声明的判据 | 达标程度？ |
| 期望值 | S-9.4 | 各结果概率 × 价值？ |
| 最坏情况 | S-11.3 | 扛得住吗？ |
| 可逆性 | S-11.4 | 双向门 / 单向门？ |

## W-3.4 反演查漏【强制】

对评估后的领先选项执行 S-10.1 ~ S-10.3：目标取反 → 失败路径 → 反转为防御清单；防御项回写进方案正文（"方案"= 原方案 + 防御清单，二者不得分离交付）。

## W-3.5 premortem（单向门决策必做）【强制】

单向门选项（S-11.4）追加 S-10.4 事前验尸：独立写失败原因 → 汇总排序（S-9.4）→ Top 威胁回写方案或触发重审。
双向门选项可豁免本步，改为"最小试点 + 退回预案"。

## W-3.6 决策输出【强制】

按 S-11.6 输出决策记录（模板 `reference/cot-templates.md` R-4）：决定 + 理由 + 放弃选项记录 + 置信度 + **重审条件** + 验收里程碑（W-3.1 的目标在何时、用什么指标验收）。

## 反模式

- 【禁止】判据后置：看完选项再定判据（为心仪选项量身定做，S-11.1）
- 【禁止】用演示效果替代期望值评估（可得性启发 B-3 的会议版）
- 沉没成本入判据：已投入的调研 / 采购成本不进入 W-3.3 评估（B-9）
- 决策记录缺失重审条件 → 违反 S-11.6，决策退化为赌注

## 示例（微型，节选）

目标（W-3.1）：日志查询 P95 < 3s（真目标：值班 10 分钟内定位故障）；硬约束：存储预算 X；软约束：运维只熟悉 ELK（标注可谈判）。
选项（W-3.2）：A 优化 ELK 索引 / B 换列式存储 / C 采样 + 冷热分层（含现状 D）。
评估（W-3.3，节选）：C 期望值最优且双向门（采样比可调），A 部分达标低风险，B 单向门超预算出局。
反演（W-3.4）：C 失败路径 = 采样丢失关键错误 → 防御：错误类日志全量不采样，写入验收用例。
决策（W-3.6）：选 C，置信度中；放弃记录：A 因上限不达标放弃、B 因单向门 + 超约束放弃；重审条件：两周后 P95 未 < 3s 或漏采错误 ≥ 1 次 → 重审 B。
