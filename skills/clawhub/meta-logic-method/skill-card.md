## Description:

For explicit requests to structure thinking, define problems, analyze root causes, weigh decisions, generate ideas, review reasoning, or reflect on outcomes, this skill guides the agent through a meta-logic framework.

This skill is ready for commercial/non-commercial use.

## Use Case:

## Known Risks and Mitigations:

Risk: Broad activation wording could cause the methodology to be applied during routine reasoning tasks.

Mitigation: Load the skill only for explicit thinking-methodology requests, and follow its stated exclusion for ordinary coding, build, and debug tasks unless the user invokes the system by name.
