## Description:

Helps agents use Modellix to generate and edit images, videos, and audio, including speech synthesis and transcription.

This skill is ready for commercial/non-commercial use.

## Publisher:

[modellix](https://clawhub.ai/user/modellix)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to select Modellix media models, submit generation or transformation requests, and retrieve images, videos, audio, or transcripts. It also helps them inspect model schemas and troubleshoot requests.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Preflight can automatically install or update the global Modellix CLI from npm.

Mitigation: Review the CLI before use and set MODELLIX_CLI_AUTO_UPDATE=0 when automatic changes are not permitted.

Risk: Paid model requests can incur charges, and an uncertain submission may still be running.

Mitigation: Approve paid submissions and batch jobs explicitly; check task history before retrying an uncertain submission.

Risk: API credentials and submitted prompts or media pass through Modellix services.

Mitigation: Use session-only credentials by default, review media before sending, and require approval before saving credentials or using a non-default endpoint.

Risk: File cleanup or upload-quota recovery can delete stored files.

Mitigation: Require explicit approval for deletions and verify the files selected for removal.
