## Description: <br>
Chat UI helps developers add React/Next.js chat interfaces with containers, messages, inputs, typing indicators, avatars, and streaming-oriented patterns from ui.inference.sh. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[okaris](https://clawhub.ai/user/okaris) <br>

### License/Terms of Use: <br>


## Use Case: <br>
Developers and engineers use this skill to install and compose chat UI building blocks for custom messaging interfaces and AI assistants in React or Next.js projects. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill uses remote npx and shadcn registry install commands that introduce routine third-party supply-chain risk. <br>
Mitigation: Review the referenced registry content and added skills before installation, and prefer pinned versions or reviewed commits where possible. <br>
Risk: Adding UI components can change project dependencies, styling, and application behavior. <br>
Mitigation: Install only in projects where third-party chat UI components are intended and review generated changes before committing them. <br>
