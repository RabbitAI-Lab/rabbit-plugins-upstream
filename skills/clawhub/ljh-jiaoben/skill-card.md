## Description:

Selling script reviewer that checks a full e-commerce sales script against a seven-step persuasion chain and flags missing steps, missing visual support, and weak conversion structure.

This skill is ready for commercial/non-commercial use.

## Publisher:

[handsomeng](https://clawhub.ai/user/handsomeng)

### License/Terms of Use:

MIT-0

## Use Case:

External e-commerce creators, marketers, and operators use this skill to diagnose sales scripts before publishing. It produces a structured review of persuasion-chain coverage, visual support for claims, repeated or missing selling points, and prioritized fixes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can create onboarding state and write review conclusions or deliverables to local archive files.

Mitigation: Use it only in a workspace where local recordkeeping is acceptable, decline archive creation when offered, and avoid submitting confidential scripts unless archiving is disabled or storage location has been checked.

Risk: The skill displays off-platform WeChat contact information during onboarding.

Mitigation: Use official platform channels for support and treat external contact paths as third-party community links.
