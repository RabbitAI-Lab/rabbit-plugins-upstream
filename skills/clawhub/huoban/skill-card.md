External users, developers, and operations teams use this skill to design Huoban zero-code applications, compare low-code platform options, plan Excel migrations, and draft API or webhook integration examples. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: API examples could modify or delete Huoban records if run with production credentials or broad tokens. <br>
Mitigation: Use least-privilege Huoban tokens, test in a sandbox, and require confirmations before update or delete actions. <br>
Risk: Webhook examples could expose an unauthenticated endpoint if deployed directly. <br>
Mitigation: Secure webhook endpoints before public exposure with authentication, validation, and controlled network access. <br>
