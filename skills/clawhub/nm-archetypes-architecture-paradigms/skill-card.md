## Description: <br>
Selects and routes to the right architecture paradigm. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[athola](https://clawhub.ai/user/athola) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and architects use this skill to compare software architecture paradigms, select a suitable pattern for a system context, and route to a more specific paradigm skill for implementation guidance. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can trigger broadly for architecture, pattern, selection, implementation, or ADR discussions and may influence high-level design choices. <br>
Mitigation: Review recommendations against the project context and have maintainers validate any architecture decision before implementation. <br>
Risk: The skill may suggest loading related architecture-specific skills. <br>
Mitigation: Install and review dependent skills before relying on their detailed implementation guidance. <br>
