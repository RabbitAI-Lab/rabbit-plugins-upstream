# 小递查查批量快递查询 · 客户上手指南

> 适用对象：第一次使用本技能的客户。目标：从「没有账号」到「批量查完快递并拿到报表」，全程约 2 分钟，大部分步骤自动完成。

---

## 一、我能用它做什么

- 一次性查询**很多个**快递单号的物流轨迹（支持顺丰、中通等 1000+ 家快递公司）。
- 自动统计：已签收多少、超时多少、平均签收时效、各快递公司分布。
- 一键导出 **Excel 可用的 CSV / 完整 JSON / 可读报告 TXT**。

---

## 二、完整流程（3 步）

### 第 1 步：注册小递查查账号（仅首次需要）

如果你还没有小递查查账号，告诉助手这两句话即可：

> 「我要注册小递查查并批量查快递」
> 我的手机号是 **138xxxx**（请填你自己的）/ 密码是 **\*\*\*\***

助手会：
1. 自动弹出浏览器，打开注册页，并**帮你把手机号、密码填好**；
2. 页面顶部会出现蓝色引导横幅，照着做就行。

### 第 2 步：你亲手完成 2 个安全校验（必须本人操作）

这是小递查查的安全机制，任何工具都**无法替你自动完成**，请按页面横幅提示操作：

1. 点 **「获取验证码」**，手机收到短信后把验证码填进去；
2. 完成 **滑块验证**（把拼图拖到正确位置）；
3. 点 **「注册」** 按钮。

> 注册成功后会自动登录，页面顶部横幅会变成「✅ 注册成功，API Key 已就绪」，窗口会自动关闭。你**什么都不用再做**。

### 第 3 步：把单号交给助手，开始批量查询

把要查的单号给助手，例如：

- 直接贴一批：`SF1234567890, ZTO7654321, YTO88888888`
- 或发一个文件（每行一个单号，顺丰/中通可在单号后加逗号加手机后四位）：

  ```
  SF1234567890,9378
  ZTO7654321,1234
  YTO88888888
  ```

助手会并发查询、出统计、生成报表（CSV/JSON/TXT），给你下载。

## 三、常见问题（FAQ）

**Q1：注册时一直收不到短信验证码？**
- 检查手机号是否填错、是否欠费停机；
- 稍等后重新点「获取验证码」（部分运营商有 60 秒间隔限制）；
- 仍收不到，按下方「四、遇到问题怎么办」第 1 步核对凭据，或直接把提示发回给助手。

**Q2：滑块验证总是失败？**
- 用电脑 Chrome 浏览器，网络稳定时再试；
- 清除浏览器缓存后重试；
- 持续失败请把页面报错原文发回给助手，由助手继续排查。

**Q3：提示「凭据校验未通过 / PlatformID 错误」？**
- 通常是账号未完成实名或激活：先跑一次 `onboard.py --validate-only` 确认凭据本身没问题，再把报错发回给助手核对账号状态；
- 若凭据齐全但仍报错，把接口返回的原始 Message 一起发给助手。

**Q4：顺丰/中通查出来是「未知 / 暂无轨迹」？**
- 这两家**必须填手机号后四位**（Tel）。在单号后加 `,手机后四位`，或用 `--tel` 统一补；
- 提交前助手会**提前列出没填后四位的单号**（顺丰、中通、申通、圆通、韵达、百世、极兔、EMS 这几家必填），按提示补齐再查即可，不必等看到一堆失败才发现；
- 若已填仍异常，可能是单号无效或尚未揽收。

**Q5：我能用自己的账号还是必须新注册？**
- 已有小递查查网页账号：直接给助手手机号+密码，选择登录模式即可，无需重复注册。

**Q6：我的凭据安全吗？**
- 凭据仅保存在你本机 `~/.workbuddy/xdcc-credentials.env`，不会上传到任何第三方；请勿将文件发给他人。

## 四、遇到问题怎么办（自助排查）

本技能包**不内置任何外部联系渠道**（第三方即时通讯账号、电子邮箱、外部站点地址
一律不写入），兜底全部落在会话内。
卡住时按下面三步走，基本能定位问题：

| 步 | 操作 | 能定位什么 |
|---|---|---|
| 1 | 打开 `~/.workbuddy/xdcc-credentials.env`，确认三个键都在且非空：`XDCC_PLATFORM_ID` / `XDCC_MEMBER_ID` / `XDCC_API_KEY` | 凭据是否写全、有没有被误删 |
| 2 | 执行 `onboard.py --validate-only` | 当前凭据是否仍有效（过期/被重置会在这里暴露） |
| 3 | 把报错原文发回给助手 | 助手带着上下文继续协助处理 |

### 常见报错对照

- **「接口返回 Code=500 / PlatformID错误」** → 第 1 步：多半是凭据缺键或 MemberID 填错（MemberID 等于注册账号的 UserID，不是 PlatformID）。
- **「注册/登录超时未取得凭证」** → 页面里是否真点了「获取验证码」、短信码是否填对、滑块是否过了；这三个没做完 `userToken` 不会出现。
- **「GetUserApiKey 返回异常」** → 账号可能未完成实名或激活，走第 2 步复核。
- **「缺依赖 Playwright」** → 装一下浏览器自动化依赖：`pip install playwright && playwright install chromium`。

> 提示里出现的任何排查步骤，都可以直接复制发给助手让它接着查。
