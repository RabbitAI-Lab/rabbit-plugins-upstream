# 合法性校验规则与多模态采集边界

## 1. 参数校验规则

### 目的地校验

| 条件 | 处理方式 |
|------|----------|
| 目的地为空 | **错误**：请用户提供目的地 |
| 目的地模糊（如"三亚"是城市、"海南"是省） | 确认用户具体是指城市还是大区域 |
| 非地理名称 | **警告**：无法识别目的地，请提供城市/地区名称 |

### 天数字校验

| 条件 | 处理方式 |
|------|----------|
| days < 1 | 设为最小值 1 |
| days > 30 | 提示"超过30天建议分段规划" |
| 小数（如2.5） | 向下取整并告知用户 |

### 人数校验

| 条件 | 处理方式 |
|------|----------|
| travelers < 1 | 设为最小值 1 |
| travelers > 20 | 提示建议联系旅行社定制 |
| 带儿童（X大Y小） | 分别存储，应用于住宿和景点筛选 |

### 预算校验

| 条件 | 处理方式 |
|------|----------|
| 预算下限 > 上限 | 自动交换上下限 |
| 预算 < 200元/天/人 | 警告预算紧张，推荐免费景点 |
| 未指定预算 | 标记为"待确认"，输出时按三档比价 |
| 人均预算 | 自动乘以人数得总预算 |

### 日期校验

| 条件 | 处理方式 |
|------|----------|
| 过去日期 | 错误：请重新选择 |
| 节假日名称 | 映射到当年公历日期 |
| 相对日期（今天/明天） | 计算绝对日期 |

## 2. 多模态采集能力边界

### 图片输入

| 图片类型 | 可提取信息 | 可靠性 |
|----------|-----------|--------|
| 地标建筑照片 | 识别目的地 | 高 |
| 景点风景照 | 推断目的地类型 | 中 |
| 行程截图 | 提取天数/景点名 | 中高 |
| 美食照片 | 推断美食偏好 | 低中 |
| 门票/收据 | 提取价格/景点名 | 中 |

**不可靠或无法提取的场景：**
- 无标志性建筑的街景 → 无法确定目的地
- 拼图/拼贴照片 → 不稳定
- 模糊低分辨率图片 → 无法提取有用信息

**处理协议：**
1. 用视觉能力描述图片内容
2. 提取可识别的旅行参数
3. 告知用户：从图片中识别到{内容}，以下信息无法获取请补充：{缺失字段}

### 链接/URL 输入

| 链接类型 | 可提取信息 |
|----------|-----------|
| 马蜂窝/穷游攻略 | 目的地、推荐景点、预算提示 |
| 景点官网 | 开放时间、门票价格、评分 |
| 酒店页面 | 价格区间、位置区域 |
| 小红书笔记 | 目的地、打卡点、行程天数 |

**限制：**
- 部分网站反爬导致 WebFetch 无法读取
- 长页面可能截断，关键信息遗漏
- 个人社交内容不可靠

**处理协议：**
1. 使用 WebFetch 读取内容
2. 提取相关参数
3. 告知用户从链接获取了哪些信息，请确认
