# 每日行程编排规则

## 1. 每日标准时间线

```
08:00-09:00  🍳 早餐
09:00-12:00  🎯 上午行程（1-2个景点）
12:00-13:30  🍜 午餐
13:30-14:00  ☕ 午休
14:00-17:30  🎯 下午行程（1-2个景点）
17:30-18:30  🛌 回酒店休息
18:30-20:00  🍽️ 晚餐
20:00-       🌙 晚间活动/自由探索
```

## 2. 特殊日调整

| 场景 | 调整 |
|------|------|
| **到达日（Day 1）** | 10:00后开始活动，含入住和交通时段，行程较轻 |
| **返程日（Last Day）** | 16:00前结束，含退房和去车站/机场时段 |
| **有小孩/老人** | 增加休息次数，减少景点密度 |
| **夏季高温** | 增加午休（12:00-15:00避开高温） |
| **轻松节奏** | 每天≤2个景点 |
| **紧凑节奏** | 每天3-4个景点，缩短午休 |

## 3. 编排原则

| 原则 | 说明 |
|------|------|
| 就近原则 | 同区域景点安排同一天 |
| 类型穿插 | 人文+自然+美食交替，避免疲劳 |
| 顺路原则 | 按地理位置顺序游览，不走回头路 |
| 时间匹配 | 考虑景点营业时间（博物馆周一闭馆） |

## 4. 交通信息展示格式

```
🚇 {景点A} → {景点B}
   方式：{地铁/公交/打车/步行}
   耗时：{duration}
   费用：{cost}元
```

### 默认交通估算

| 距离 | 默认方式 | 耗时 | 费用 |
|------|---------|------|------|
| <1km | 步行 | 10-15分钟 | 0 |
| 1-5km | 地铁/公交 | 20-40分钟 | 2-6元 |
| 5-15km | 地铁 | 30-50分钟 | 3-8元 |
| >15km | 打车 | 30-60分钟 | 20-80元 |

## 5. 每日注意事项生成

```
⚠️ 第{n}天注意事项
🌤️ 天气：{天气概况（根据季节+目的地）}
👔 着装：{穿搭建议}
📱 预约：{需要预约的景点及方式}
💡 小贴士：{实用建议}
```

### 季节注意模板

| 季节 | 着装 | 警示 |
|------|------|------|
| 春(3-5月) | 薄外套、长裤、防晒 | 花粉过敏；清明雨季带伞 |
| 夏(6-8月) | 短袖短裤、防晒霜 | 防暑降温；台风/暴雨预警 |
| 秋(9-11月) | 长袖T恤、薄外套 | 昼夜温差大 |
| 冬(12-2月) | 羽绒服、围巾、手套 | 防寒保暖；路面结冰 |

## 6. 酒店分区域规则

3天以上旅游行程，根据景点分布在不同区域安排住宿：

| 天数 | 推荐策略 | 示例 |
|------|----------|------|
| 1-2天 | 固定一处住宿 | 全程住市中心 |
| 3-5天 | 2个区域轮换 | 前2天住A区，后2天住B区 |
| 6天+ | 按路线依次住宿 | 城市A→城市B→城市C各住2晚 |
