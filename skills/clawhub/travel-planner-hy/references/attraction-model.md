# 景点数据模型与检索规范

## 1. 景点数据字段

| 字段 | 必填 | 类型 | 说明 | 示例 |
|------|------|------|------|------|
| name | ✅ | string | 景点名称 | "洪崖洞民俗风貌区" |
| type | ✅ | string[] | 类型标签 | ["人文", "网红打卡"] |
| ticketPrice | ✅ | number | 门票价格(元)，0=免费 | 0 |
| rating | | number | 评分(/5) | 4.6 |
| openingHours | | string | 开放时间 | "11:00-23:00" |
| estimatedDuration | | string | 建议游玩时长 | "1.5-2小时" |
| description | | string | 简要介绍 | "重庆地标建筑，以夜景闻名" |
| highlight | | string | 特色亮点 | "夜景灯光秀、巴渝民俗表演" |
| reservationRequired | | boolean | 是否需要预约 | false |
| address | | string | 地址 | "渝中区嘉陵江滨江路88号" |

### 类型标签

| 标签 | 说明 | 范例景点特征 |
|------|------|-------------|
| 自然风光 | 山川/湖泊/海滩/森林 | 山、湖、海、瀑布 |
| 人文历史 | 博物馆/古迹/寺庙 | 历史建筑、文物陈列 |
| 娱乐休闲 | 主题公园/游乐场 | 过山车、水上项目 |
| 购物 | 商业街/商场/夜市 | 步行街、免税店 |
| 美食 | 美食街/特色餐厅区 | 小吃街、夜市排档 |
| 网红打卡 | 拍照/摄影点 | 独特视角、社交媒体热点 |
| 亲子 | 儿童友好 | 动物园、科技馆、儿童乐园 |

## 2. 检索策略

### 搜索查询模板

| 场景 | 查询模板 | 示例 |
|------|----------|------|
| 通用 | "{destination} 景点推荐" | "重庆 景点推荐" |
| 类型定向 | "{destination} {preference} 景点" | "重庆 人文历史 景点" |
| 价格查询 | "{destination} 景点门票价格" | "重庆 景点门票价格" |
| 免费景点 | "{destination} 免费景点" | "重庆 免费景点" |
| 亲子定向 | "{destination} 亲子景点" | "重庆 亲子游 景点" |
| 高评分 | "{destination} 高评分景点" | "重庆 高评分景点 排行榜" |

### 执行步骤

1. **广度优先**：先执行通用搜索，获取全景
2. **定向补充**：根据用户偏好执行类型搜索（不超过3次）
3. **价格核实**：专门搜索门票价格信息

### 提取规则

- 结构化：将搜索结果映射到景点数据字段
- 不完整数据：标记"待核实"，不猜测
- 多源冲突：优先最新数据和官方渠道
- 最低要求：景点必须至少有 name + type + ticketPrice 三项

### 无结果的兜底

如果联网搜索未能返回有效景点信息：
1. 尝试更换关键词和拼写
2. 国际化目的地改用英文搜索
3. 仍为空 → 使用通用知识推荐知名景点，标注"来源于通用知识库，非实时搜索结果"
