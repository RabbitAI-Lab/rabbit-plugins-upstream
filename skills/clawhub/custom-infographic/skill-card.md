## Description:

Generate a professional infographic from an article, document, URL, or topic, using 21 layouts and 21 visual styles.

This skill is ready for commercial/non-commercial use.

## Use Case:

Users creating infographics can turn an article, document, URL, or topic into a visual summary or poster, choosing a layout, visual style, aspect ratio, and language.
