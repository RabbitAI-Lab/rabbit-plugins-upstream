## Description: <br>
Inverts burden of proof for code additions <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[athola](https://clawhub.ai/user/athola) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and code reviewers use this guidance skill to challenge proposed code, file, configuration, and abstraction additions before accepting them into a task or review. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad activation terms can make an agent challenge additions more often than intended. <br>
Mitigation: Use the skill when stricter review or refactor scrutiny is desired, and tie challenges to the active task requirements. <br>
Risk: A guidance-only verdict can reject useful work if the need has not been documented yet. <br>
Mitigation: Provide concrete evidence, reproduction steps, or requirement links before treating an addition as justified. <br>
