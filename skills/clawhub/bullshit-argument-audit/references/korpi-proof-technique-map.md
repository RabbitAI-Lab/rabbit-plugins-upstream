# Korpi Proof Technique Map

Source: https://www.korpisworld.com/Mathematics/math%20leftovers/methods_of_mathematical_proof.htm

This page is a parody list of bad mathematical proof techniques. For the skill, interpret it as a cross-domain taxonomy of bogus support moves.

## Normalized Categories

| Korpi-style technique | General argument failure | Common non-math signals |
|---|---|---|
| Obviousness, A.F.K.T., triviality | Unsupported assertion | "obviously," "everyone knows," "no need to explain" |
| General agreement, majority rule | Social proof as evidence | votes, likes, audience applause, internal consensus |
| Imagination, convenience, supplication | Wishful thinking | "let's assume," "we need this to be true" |
| Necessity, importance, funding | Consequences as proof | "too important to be wrong," budget/prestige as validation |
| Plausibility, intuition, gut feeling | Vibe-based proof | sounds right, feels right, cloud-shaped diagrams |
| Intimidation, terror, profanity | Coercive rhetoric | mockery, status threats, hostile dismissal |
| Lack of time, postponement, avoidance, omission | Deferred or missing support | appendix/future/details skipped; audience must fill gaps |
| Definition, tautology, semantic shift, design | Meaning manipulation | redefining terms, circular definitions, moving goalposts |
| Plagiarism, lost reference, authority, eminent authority, personal communication | Citation theater | vague or private sources, famous-name substitution |
| Wishful citation, ghost reference, inaccessible literature, mutual reference, forward reference | Bad sourcing | source mismatch, non-existent support, circular/inaccessible citations |
| Example, picture, hasty generalization, accumulated evidence | Evidence scope inflation | anecdote as proof, demo as proof, no counterexample found |
| Poor analogy, tessellation | False analogy | "just like" without testing relevant differences |
| Mumbo-jumbo, cumbersome notation, illegibility, obfuscation | Technical fog | jargon, equations, charts, unreadable slides, long non-sequiturs |
| Simplification, reduction to wrong problem, logic by context | Wrong target | proving an easier/different claim, relying on spec/deck presence |
| Deception | Attention diversion | cuts, omissions, sleight of hand, buried assumption |

## Audit Heuristics

- A technique is only a finding if it affects the support for a claim.
- Quote or cite the local passage/timestamp that triggered the finding.
- Pair every critique with a repair path.
- Avoid saying "fallacy" as a mic drop; explain the missing bridge.
- For media, visual polish and speaker confidence are evidence only of presentation quality, not truth.
