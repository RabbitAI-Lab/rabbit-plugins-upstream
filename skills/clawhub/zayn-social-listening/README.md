# SOCIAL_LISTENING() 社媒与网络舆情分析

- Skill：`zayn-social-listening`
- 用途：分析公开平台的账号、内容、互动、评价、争议和重复问题。
- 适用：品牌、企业或竞争对手舆情；不适用仅凭情绪词自动定性。
- 输入：目标、市场、平台、时间、目的、主题。
- 最低条件：主体和账号可区分，样本边界明确。
- 流程：账号确认→采样→来源分级→主题与互动→信号归类→限制说明。
- 输出：活跃度、主题、正负信号、争议、代表性、推断和来源。
- 证据与风险：匿名内容只作线索，单条评论不代表整体。
- 协作：风险线索转 business-risk，竞争情报转 competitor-analysis。
- 示例：分析某品牌过去 12 个月在 LinkedIn、Reddit 和评论站的重复问题。
- 版本：v1.0.0
