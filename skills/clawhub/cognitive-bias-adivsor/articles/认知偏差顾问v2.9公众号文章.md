# 查理·芒格警告：比无知更危险的，是你已经十年没跨出过自己的领域

前两周团队面试了一个候选人。

简历很漂亮，技术背景扎实。我问了一个他领域之外的问题——不是刁难，就是想看看他遇到不懂的东西时的反应。

他愣了一下，然后开始用术语兜圈子。整整三分钟，没有说出「我不确定」四个字。

后来我问了同样的问题给另一个候选人。她想了 10 秒，说「这个我不懂，但我很好奇——你能不能给我一个方向，我自己去查？」

第二个候选人我们发了 offer。

**查理·芒格在《人类误判心理学》中把「好奇心倾向」列为第 6 条。**他写道：好奇心能帮助人"防止或减少其他心理倾向带来的不良后果"——换句话说，好奇心不是锦上添花的性格特质，是你对抗认知偏差的防火墙。你不是没有好奇心，你是默认关掉了它。

我们做的 AI Skill「认知偏差顾问」最近更新了 v2.9.0，核心就是把这个偏差注入到三个场景的诊断流程里：学习、决策、看人。

## 一、你觉得你在思考，其实你只是在自己熟悉的圈子里打转

先做一个测试。以下三种情况，你中了几条：

**学习上：** 你最近三个月看的书、听的播客、刷的文章，是不是都在你自己的专业领域里？有没有哪怕一本是跨学科的——生物学、地质学、哲学、法律？

**决策时：** 你思考一个问题的过程中，有没有主动问过自己「关于这件事，我还有什么不知道的」？还是默认自己掌握的信息已经够了？

**看人时：** 你评估一个人，看的是他「已知的技能」还是「对未知的态度」？

这三条背后的偏差是同一个：**好奇心缺失**。

什么意思？不是说你没有好奇心。是你默认关闭了「信息获取」这个通道，然后告诉自己「我已经知道得够多了」。

举个例子：我认识一个做了十二年管理的团队负责人。他的书架上有六十多本管理经典，从德鲁克到柯林斯，每一本都画满了线。但你问他还看领域之外的书吗，他想了想，说「没时间，管理本身都学不完」。

问题不是他不够勤奋。恰恰相反，他太勤奋了——以至于没有多余的精力去发现「还有别的东西值得学」。十二年的积累成了他最大的盲区。

这就是好奇心缺失的典型表现。不是不学，是在同一个圈子里越学越深，深到看不见圈外面还有路。

## 二、「我不懂」不是缺陷，是入场券

去年和一位老朋友吃饭。他聊起自己行业最近的变化，说了几个新概念。我没完全跟上，但我点了下头，假装听懂了。

回家路上我就在想——我为什么要装？不是因为那些概念多复杂，是因为到了这个年纪，**「不懂」莫名约等于「掉价」**。

这不止是我的问题。上课不敢举手说没听懂，开会不敢承认不了解某个概念，看文章遇到不认识的词自动跳过去。久而久之，大脑养成了一个习惯：**遇到不懂，自动绕开。**

这不是能力问题，是习惯问题。而习惯的代价比你想象的大：

- **学习上**：你永远在已知的区间里打转，进步曲线越来越平
- **决策上**：你以为自己考虑了所有角度，其实只考虑了「你知道的角度」
- **看人上**：你招来的人跟自己越来越像——都只知道同一套东西

v2.9.0 在三个领域都加入了好奇心自检：

### 学习领域

当你说「学不会」「效率低」时，AI 现在会多问一个问题：

> 「你最近是否只在自己熟悉的领域里学习？有没有刻意引入新学科的视角？」

如果答案是「没有」，它会给出两个具体策略：

**策略 1 —— 跨领域好奇心日**：每周固定一天，花 30 分钟阅读一个完全陌生领域的入门材料。不要求精通，只需要意识到「原来还有人在用这种方式思考问题」。

**策略 2 —— 「不懂」日志**：遇到不懂的概念不要跳过，记下来。每周选一个深挖 15 分钟。把「我居然不知道这个」的羞耻感，转化成「这里有新地图」的兴奋感。

### 决策领域

决策分析时多了三道自检题：

> ① 关于这个问题，我还有什么不知道的？我是否已经提前关闭了信息获取？
> ② 我是否只在自己熟悉的框架内思考？
> ③ 从另一个学科的角度，这个问题会有什么不同答案？

举个例子：你在考虑要不要买房。正常的思考角度是「房价走势 / 收入 / 贷款 / 地段」。但如果用生物学家的视角——「这个区域的人口密度和绿地分布对心理健康影响如何？」用哲学家的视角——「拥有一个房子和拥有一个家，是同一件事吗？」

不要求你成为生物学家或哲学家。只要求你**意识到还有其他角度**。这个意识本身就降低了偏差。

### 管理领域

评估候选人时多了两个观察维度：

> ① 这个人遇到不懂的事情时是兴奋还是焦虑？
> ② 这个组织是否鼓励提问和探索，还是只奖励「已知」的正确答案？

管理的策略里多了一条：「提问奖励制度」——设立「最好问题奖」，奖励提出好问题的人，而非只奖励给答案的人。

## 三、从 v2.8 到 v2.9：两个偏差，一个逻辑

v2.8.0 做的功能叫「单向门→双向门转换」——遇到重大决策，先别急着分析，先问能不能把它变成可以退回来的事。

逻辑是：**投入越大，你的偏差越强。** 认知失调、避免不一致、确认偏误——都会因为「我已经投入了」而被放大。

v2.9.0 做的功能叫「好奇心倾向自检」——遇到任何问题，先别急着在自己已知的框架里找答案，先问还有什么不知道的。

逻辑是：**知道得越多，你以为自己不知道的就越少。** 你在一个领域深耕了十年，遇到任何问题，手会自动伸向熟悉的工具包——不是工具包不好，是它可能不是最适合眼前这个问题的。

两个版本做的是同一件事：**在你开始「分析」之前，先拉你出来看一眼。**

## 四、怎么装

先说明一下：认知偏差顾问是一个 AI Skill，装到你的 AI 助手（Claude、ChatGPT 等支持 Skill/插件功能的客户端）里就能用。装完不需要额外配置。

选一个你方便的方式：

**方式一 · ClawHub（推荐）**

在 AI 客户端里输入一行命令即可：

```
clawhub skill install cognitive-bias-advisor
```

**方式二 · SkillHub.cn**

浏览器打开 skillhub.cn，搜索「认知偏差决策顾问」，点击安装。或者用命令行：

```
skillhub install cognitive-bias-advisor-pro
```

**方式三 · GitHub（技术用户）**

```
git clone https://github.com/jacksu/cognitive-bias-advisor.git
```

装好之后，在 AI 对话框里说「我在纠结一个决定」，或者「学某样东西总是学不会」，Skill 会自动介入，按场景引导你排查偏差。

## 五、今天就能做的 3 件事

不需要装任何东西：

**① 回顾你过去三个月的输入——书、文章、播客、视频——有没有一个来自你的专业领域之外的？**

如果没有，明天花 30 分钟，找一个完全陌生的领域，读一篇入门文章。不是要你转行，是要你意识到「还有人在用完全不同的方式思考问题」。

**② 拿你现在最纠结的一个问题，问自己一句：关于这个问题，我还有什么不知道的？**

写下来。至少列三条。你列出来的这些「不知道」，才是真正值得花时间去了解的东西——而不是你已经知道的那些。

**③ 下一次团队开会，在讨论完所有「已知」之后，加一句：「我们还有什么是没考虑到的？」**

不需要答案。只需要有人说出这句话。好奇心是一种组织文化，而文化的起点，往往是某个人先说出了「我不确定」四个字。
