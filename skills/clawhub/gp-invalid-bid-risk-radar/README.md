# 政采无效投标风险雷达（gp-invalid-bid-risk-radar）

> 版本：v2.1.1 ｜ 体系：政府采购法（财政性资金项目）

政采无效投标风险雷达——专攻政府采购项目（公开招标/邀请招标/竞争性谈判/竞争性磋商/询价/单一来源）中的无效投标条款、资格性/符合性审查硬性要求、政策性合规陷阱及隐性风险点提取。从采购文件中**精准提取**可能导致单个供应商投标/响应被拒绝（无效投标）的条款与隐性风险，输出可逐项核对的**结构化检查清单**，便于审核人员封标前逐项核对。

> 本版本为**政府采购法体系版本**（财政性资金项目）。工程/招投标法体系（施工总承包/EPC/工程量清单等）为口径不同的独立版本（"废标风险雷达"招投标版），不混入本版本。

## 功能特性

- **Step 0–11 全流程**：边界路由 → 项目概览与采购方式锁定 → 供应商适配预筛 → 资格性审查（采购人/代理机构） → 符合性审查（评标委员会） → 投标保证金专项 → ★号条款扫描 → 法规锚定 → 政策性合规（中小企业/节能环保/进口/信创） → 隐性风险四步挖掘 → 条款冲突检测 → 风险分级 → 结构化输出 → 增量扫描与救济路径。
- **术语铁律**：严格区分"废标"（项目整体终止）与"无效投标"（单个供应商被拒），输出开头即声明，避免误导。
- **体系感知 · 法规锚定（Step 2.5）**：挂载 IMA 政采主源 `政府采购实务与合规`（KB `7463496212028405`，政采密度≈89%），对隐性/推断类风险补强法律依据、提升置信度；判例佐证 `招投标评标否决AI知识库`（KB `7460608999968055`，须标 `[工程体系·仅供参考]`），严禁跨体系误用。
- **渐进式披露**：Step 6 政策性合规全表、Step 7 政采专属陷阱清单、Step 8 冲突类型下沉 `references/`，按需加载，控 token 同时保持 SKILL.md 编排清晰。
- **统一提取表**：每项风险含「条款出处 / 具体要求 / 风险等级 / 置信度 / 检查动作 / 是否满足 / 责任人 / 备注」，可直接打印打勾。
- **增量扫描协议**：澄清/补遗文件对比原文件输出「变更对照表」，仅重评变更点，版本号递增，不重新生成全量清单。
- **救济路径内置**：每次输出末尾附质疑（7 工作日）/投诉（15 工作日）法定路径速查。

## 使用方式

1. 上传政府采购招标文件（PDF / DOCX / 图片 / 扫描件，含公告、投标人须知及前附表、评标办法、合同条款、技术规格、投标文件格式要求等）；
2. 技能自动识别采购方式 → 资格/符合性/保证金/★/政策合规/隐性风险多维扫描 → IMA 政采库法规锚定 → 输出分级检查清单；
3. 查看三层递进结果（风险概览 → 分级检查清单 → 封标前确认表）；支持「只看高危」「展开第 X 项」「导出完整版」「增量扫描补遗」。

## 能力边界

| 做 | 不做 |
|---|---|
| 从采购文件提取无效投标风险条款与隐性风险点 | 不做法律定性裁决（是否无效由审查主体认定） |
| 输出结构化检查清单 + 封标前确认表 | 不替代全文解读 / 翻译、投标文件撰写、合同审查 |
| 体系感知的法规锚定与判例佐证 | 不做评标打分、质疑/投诉文书代写 |
| 政采口径为主，工程/招投标独立版本分流 | 不提供报价策略与评分拆解建议、不协助编造资质业绩 |
