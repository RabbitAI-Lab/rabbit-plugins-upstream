## Description:

Browse and summarize websites, extract content from URLs, and search the web for information.

This skill is ready for commercial/non-commercial use.

## Publisher:

[thcjp](https://clawhub.ai/user/thcjp)

## Use Case:

External users, developers, and agents use this skill to visit URLs, summarize webpage content, search online, and extract relevant data from web pages.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate for broad web or content-related prompts.

Mitigation: Use it for explicit requests to visit a URL, search online, summarize a webpage, or extract webpage data.

Risk: Webpage results can be incomplete when sites block automated access, require login, rely heavily on JavaScript, or contain video/audio content.

Mitigation: Review extracted content against the source page and note access limitations when summarizing or using results.
