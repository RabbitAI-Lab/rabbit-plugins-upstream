## Known Risks and Mitigations: <br>
Risk: The bundle persistently installs many agent skills, changing the available workflows and instructions in an agent environment. <br>
Mitigation: Run the installer with --dry-run first, review the bundled skills, and install only into the intended skills directory. <br>
Risk: Several bundled skills describe broad file-reading, file-writing, shell-command, repository-changing, external research, or git automation workflows. <br>
Mitigation: Use least-privilege tool permissions, avoid --force unless replacement is intended, and review sensitive repository or deployment actions before execution. <br>
