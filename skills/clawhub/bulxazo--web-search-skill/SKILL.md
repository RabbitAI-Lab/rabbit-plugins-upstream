# 웹 검색 스킬 (Web Search Skill)

## 개요
이 스킬은 웹 검색 도구를 활용하여 실시간 정보, 최신 뉴스, 금융 데이터 등을 조회하고 분석하는 기능을 제공합니다.

## 사용 방법
1. **검색 실행**: 특정 주제나 질문에 대해 `web_search` 도구를 호출하여 관련 정보를 검색합니다.
2. **정보 추출**: 검색 결과에서 필요한 정보를 추출하고 요약합니다.
3. **전문 분야 연동**: 수집된 정보를 LEGAL, FINANCE, CODING, SALES, SUPPORT, MARKETING 등 적절한 도메인으로 분류하여 전문적인 답변을 생성합니다.

## 도구 활용
- `web_search`: 실시간 웹 검색 수행
- `web_fetch`: 특정 URL의 콘텐츠 상세 읽기

## 주의사항
- 검색 결과의 신뢰성을 확인하고, 필요한 경우 출처를 명시합니다.
- 개인정보나 보안이 필요한 데이터는 검색 대상에서 제외합니다.
