## Description:

Web Search Skill helps agents search the web for current information, extract relevant details, and produce sourced, domain-aware answers.

This skill is ready for commercial/non-commercial use.

## Publisher:

[bulxazo](https://clawhub.ai/user/bulxazo)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent users use this skill to retrieve current web information, summarize search results, and route findings into professional domains such as legal, finance, coding, sales, support, and marketing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Search queries and fetched URLs may be sent to external web services, which can expose private, confidential, or security-sensitive information.

Mitigation: Avoid submitting sensitive information unless the surrounding agent and tools provide appropriate privacy controls.

Risk: Web search results can be outdated, incomplete, or unreliable.

Mitigation: Check result reliability and cite sources when using retrieved information in responses.
