## Description:

Helps TikTok Shop sellers create product image sets, detail-page graphics, and promotional images using Qinghu AI.

This skill is ready for commercial/non-commercial use.

## Publisher:

[autoagc](https://clawhub.ai/user/autoagc)

### License/Terms of Use:

MIT-0

## Use Case:

TikTok Shop sellers and marketing teams use this skill to turn product photos into storefront image sets, product-detail graphics, and campaign visuals.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Product images are uploaded to the Qinghu/qhkit service, and an API key is required.

Mitigation: Use only images approved for upload and handle the API key securely.

Risk: Generation consumes credits and requires an installed package.

Mitigation: Review or pin the package version and confirm the estimated credit cost and generation settings before submission.
