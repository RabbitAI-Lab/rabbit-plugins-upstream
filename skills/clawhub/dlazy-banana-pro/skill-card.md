## Description:

Generate and edit images with Nano Banana Pro using text prompts and optional reference images.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and other agent users can generate new images from prompts or edit images using supplied reference images, then save the resulting assets locally.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and reference images are sent to dLazy's hosted service, and generation consumes account credits.

Mitigation: Only submit prompts and images you are comfortable sharing with dLazy, and review the estimated cost and available credits before generation.

Risk: The CLI uses a saved API key to access the account.

Mitigation: Protect the saved API key and review the pinned CLI before installation.
