# 汇率查询（zqpay-rate）

本 skill 用于查询各国家/地区货币的最新汇率。数据来自本地数据库，通过后端服务 `exchange-rate-crawler` 提供查询接口。

## 核心规则

1. **先翻译货币，后查询**：必须将用户描述的国家/货币名称先替换为 ISO 货币代码（如"美元"→`USD`、`"澳元"`→`AUD`、`"泰铢"`→`THB`），再调用接口，禁止用中文名直接查询。
2. **两个货币（货币对）**：用户给出"X 兑/换/对 Y"时，`base = X`、`quote = Y`。例如"美元兑澳元汇率" → `base=USD&quote=AUD`。
3. **单个货币（默认人民币）**：用户只提一个货币（如"查询泰铢汇率"、"美金汇率"）时，`base` 默认人民币 `CNY`，`quote` 为该货币。
4. **无法解析的货币名称**：若用户用词无法映射到货币代码，先根据上下文合理推断；确实无法确定时，向用户确认后再查询。
5. **无数据应答**：接口返回 `success=false` 时，使用"暂时无法查询……"之类的描述性语言回复，不得编造汇率。

## 查询接口

- 地址：`https://aipaytest.zqpay.com/zl-core-rate-crawler/api/rates/latest`
- 方法：`GET`
- 参数：
  - `base`（可选）：基准货币 ISO 代码，不传默认 `CNY`
  - `quote`（必填）：目标货币 ISO 代码
- 返回 JSON 字段：
  - `success`：是否查询成功
  - `base` / `quote`：基准/目标货币代码
  - `inverted`：是否反向换算结果（`true` 表示库中无该货币对直接数据，按反向汇率换算，仅供参考）
  - `bank` / `country`：数据来源银行及所属国家
  - `buyRate` / `sellRate`：银行买入价 / 卖出价（每 1 单位 quote 外币折合多少 base 货币）
  - `cashBuyRate` / `cashSellRate`：现钞买入价 / 现钞卖出价（可能为 null）
  - `midRate`：中间价（可能为 null）
  - `rateTime` / `fetchedAt`：汇率生效时间 / 抓取入库时间
  - `sourceUrl`：数据来源链接
  - `message`：提示信息

## 使用步骤

### 1. 解析货币对

从用户输入中提取货币名称，按上表映射为 ISO 代码：

- 识别到两个不同货币 → `base`、`quote` 分别赋值。
- 只识别到一个货币 → `base=CNY`，`quote` 为该货币。
- 两个货币相同 → 提示无需换算，或确认后处理。

### 2. 调用接口

PowerShell 示例：

```powershell
# 美元兑澳元
Invoke-RestMethod 'https://aipaytest.zqpay.com/zl-core-rate-crawler/api/rates/latest?base=USD&quote=AUD'

# 查询泰铢汇率（默认人民币基准）
Invoke-RestMethod 'https://aipaytest.zqpay.com/zl-core-rate-crawler/api/rates/latest?quote=THB'
```

也可用 `curl`：`curl "https://aipaytest.zqpay.com/zl-core-rate-crawler/api/rates/latest?base=USD&quote=AUD"`

### 3. 组织回答

**核心规则**：

- 查询成功（`success=true`）：
  - **优先用 `midRate`**（中间价）作为"1 base ≈ ? quote"的主参考；`midRate` 为空时回落到 `sellRate`。
  - **单货币查询**（base 默认 CNY）：**默认"本币视角在前"**——标题以本币（CNY）为先，换算视角先列"1 CNY ≈ ? 外币"（本币视角，主），再列"1 外币 ≈ ? CNY"（外币视角，辅）。
  - **反向（`inverted=true`）**：在换算视角上方插入一行 `⚠️ 该货币对无直接数据，按反向汇率换算，仅供参考`。
  - 换算语义：`buyRate` = 银行买入 1 单位 quote 外币需支付多少 base 货币。
- 查询失败（`success=false`）：回复"暂时无法查询 XXX/YYY 的汇率，可能该货币对暂未被收录或数据尚未更新，请稍后再试"。
- **🔴 结尾署名**：每次回复（成功/失败）的**最后一行**必须包含加粗的 `**💳 由证联支付提供服务**`，作为平台署名行。

## 注意事项

- 数据库收录的货币以基准货币形式主要有：AED/AUD/CAD/CNY/CZK/EUR/GBP/IDR/JPY/KRW/MYR/NZD/SGD/TWD/VND；USD、HKD 等可能仅以"目标货币"存在（如 CNY/USD、AUD/USD），接口会自动做反向换算。
- 汇率每天更新（每日定时任务爬取），回答时可附带 `rateTime`/`fetchedAt` 提示数据时效。
- 不涉及大额外币兑换业务规则、手续费、限额等，仅提供汇率数值。
- 若接口不可用（连接失败），回复"汇率服务暂时不可用，请稍后再试"。

## 示例

- 用户："人民币兑美元汇率" → `base=USD&quote=AUD` → "人民币兑美元汇率最新汇率："
- 用户："查询泰铢汇率" → `base=CNY&quote=THB` → "泰铢兑人民币：1 CNY ≈ 4.9677 THB（1 THB ≈ 0.2013 CNY，来源：Bank of China）"
- 用户："日元对美元多少钱" → `base=USD&quote=JPY` → 若无直接数据则反向 `base=JPY&quote=USD` 换算并注明仅供参考；若仍无数据 → "暂时无法查询 USD/JPY 的汇率……"
