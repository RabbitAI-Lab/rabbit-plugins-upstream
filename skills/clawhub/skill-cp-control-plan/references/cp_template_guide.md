## 概述

控制计划（Control Plan）是质量管理体系中的核心文件，用于记录和传达过程控制策略。它描述了产品/过程参数监控的完整方案，确保生产过程持续稳定地满足顾客要求。

### 适用标准
- IATF 16949:2016（汽车行业）
- AIAG Control Plan手册
- 企业内部质量标准

## 控制计划结构要素

### 标准字段说明

| 字段名称 | 说明 | 填写要求 |
|---------|------|---------|
| 过程步骤 | 工序编号与名称 | 按工艺流程顺序编号 |
| 过程描述 | 输入、输出、设备、工装 | 简明扼要描述 |
| 编号 | 特性唯一标识 | 建议采用项目编码 |
| 过程/产品特性 | KPC/KPP名称 | 明确区分 |
| 特殊特性符号 | SC/CC标识 | 依据顾客要求 |
| 规格/极限 | USL/LSL/TARGET | 明确数值单位 |
| 测量方法 | 量具、方法、频次 | 包括MSA计划 |
| 控制方法 | 防错/SPC/检验 | 具体措施 |
| 失控反应计划 | 发现异常时的措施 | 明确责任人 |

## 关键特性识别

### 特殊特性分类

```
特殊特性 (Special Characteristics)
├── 产品特殊特性 (Product SC)
│   ├── 影响安全的产品特性
│   ├── 影响法规的产品特性
│   └── 顾客指定的产品特性
└── 过程特殊特性 (Process SC)
    ├── 影响安全的过程参数
    ├── 影响产品的过程参数
    └── 影响关键特性的过程参数
```

### 标识符号约定

| 符号 | 含义 | 颜色 | 使用场景 |
|------|------|------|---------|
| ▲ | 安全相关特殊特性 | 红色 | 政府法规/安全要求 |
| ● | 关键特性 | 蓝色 | 顾客指定 |
| ◆ | 重要特性 | 黄色 | 内部定义 |

## 控制方法选择

### 控制层级金字塔

```
         ┌─────────────┐
         │   预防为主   │
         │  (Poka-Yoke)│
         └──────┬──────┘
         ┌──────┴──────┐
         │   检测+控制  │
         │   (SPC)     │
         └──────┬──────┘
         ┌──────┴──────┐
         │   100%检验  │
         │ (自动检测)  │
         └──────┬──────┘
         ┌──────┴──────┐
         │   抽样检验   │
         │  (首件/巡检) │
         └─────────────┘
```

### 控制方法选择矩阵

| 过程能力(CPK) | 推荐控制方法 | 检验频次 |
|--------------|-------------|---------|
| CPK ≥ 1.67 | 自动化防错 | 连续/自动 |
| 1.33 ≤ CPK < 1.67 | SPC控制图 | 每小时 |
| 1.0 ≤ CPK < 1.33 | SPC+检验 | 每班次 |
| CPK < 1.0 | 100%检验 | 持续 |

## 响应计划设计

### 失控反应流程

```
检测到异常 → 停止生产 → 隔离产品 → 通知质量 → 分析原因 → 纠正措施 → 持续监控
    ↓
1. 立即停止该工序
2. 标识并隔离可疑产品
3. 通知质量工程师/班组长
4. 使用QRQC/8D方法分析
5. 实施临时/永久措施
6. 验证效果并更新控制计划
```

### 常用反应措施示例

| 异常类型 | 立即措施 | 长期措施 |
|---------|---------|---------|
| 超规格 | 调整工艺参数 | 分析变差来源 |
| 趋势异常 | 增加检验频次 | 设备预防性维护 |
| 测量系统失效 | 停用该量具 | 重新进行MSA |
| 人员操作失误 | 重新培训 | 增加防错装置 |

## 附录：常见问题

### Q1: 如何确定抽样方案？
**A**: 基于过程能力、风险等级和顾客要求。参考GB/T 2828.1或ANSI/ASQ Z1.4。

### Q2: 何时需要更新控制计划？
**A**: 发生以下情况时：
- 工艺变更（ECN）
- 过程能力下降
- 顾客要求变更
- 新设备/工装引入
- 不良率上升

### Q3: 控制计划由谁批准？
**A**: 通常为：工艺工程师编制 → 质量工程师审核 → 质量经理批准。

### Q4: 如何确保控制计划执行？
**A**: 
1. 将控制计划纳入作业指导书
2. 定期审核执行情况
3. 使用SPC系统自动监控
4. 纳入质量绩效考核
