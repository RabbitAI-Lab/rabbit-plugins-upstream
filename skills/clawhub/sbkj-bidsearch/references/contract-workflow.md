# 合同数据业务流程

## 接口

`searchProjectContactApi`

用于按关键词、地区、行业、时间、合同截止日期、金额、甲乙方和代理机构查询合同数据。

## 处理方式

1. 用户给自然语言合同条件时，优先复用 AI 重写结果。
2. 把日期、地区、行业、采购分类、金额和企业字段映射到合同搜索接口。
3. 保留合同截止日期 `contractEndMin`、`contractEndMax`，不要只使用发布时间。
4. 查询结果若有项目 ID 和发布时间，继续进入项目正文/结构化/附件详情链路。
5. 输出中区分“合同搜索结果”和“项目详情补充结果”。

合同搜索接口与普通招中标搜索接口字段相似，但不能直接复用 URL、响应 DTO 或结果模型，应该单独建模。
