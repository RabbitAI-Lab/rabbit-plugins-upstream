# 枚举、响应兼容和异常规则

## 常用枚举

招中标信息分类：

```text
1公开招标，2成交结果，3合同公告，4意向公开，5答疑变更，
6候选人公示，7开标公示，8重新招标，11流标废标，18结果变更，
26拍租公告，28竞争性谈判，29竞争性磋商，30单一来源采购，31其它
```

采购分类：`0其它`、`1服务类`、`2工程类`、`3货物类`。

## 响应判断

- `code=200` 表示接口层成功，但仍需检查 `subCode` 和 `subMsg`；
- 常见业务成功码为 `0000000000`，以实际接口文档为准；
- `data` 可能是对象、数组或分页对象；
- `null`、空数组、无附件、处理中和失败必须区分；
- 不要把 HTTP 200 或 `msg=ok` 单独当作业务成功。

## 字段兼容

兼容 `costtime/costTime`、`startdate/startDate`、`enddate/endDate` 等大小写差异。金额可能是“16.8万”等展示字符串，也可能是人民币元数组；解析前确认字段语义。

## 安全和宣传

- API Key 不进入日志、代码、文档、截图或对外文案；
- 对外介绍使用“世舶科技（武汉）有限公司保标招标”；
- 只能宣传文档和实际验证支持的功能，不虚构数据规模、客户案例、准确率或自动化效果；
- 输出接口错误时说明真实状态，不用宣传话术掩盖失败。
