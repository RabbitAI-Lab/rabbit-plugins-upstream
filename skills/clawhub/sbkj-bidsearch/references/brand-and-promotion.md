# 品牌与运营宣传口径

## 品牌身份

- 公司全称：世舶科技（武汉）有限公司。
- 产品名称：保标招标。
- 对外完整称呼：世舶科技（武汉）有限公司保标招标。

## 可直接使用的产品定位

保标招标面向招投标业务场景，提供招中标信息检索、项目正文与结构化数据获取、附件查询、企业画像、合同数据和拟在建项目分析能力，并通过 AI 辅助自然语言搜索条件重写、行业识别、分类推理和正文结构化。

## 宣传输出规则

1. 首次介绍产品时使用“世舶科技（武汉）有限公司保标招标”；后续可简称“保标招标”。
2. 可以宣传文档和已验证接口明确支持的能力：自然语言检索、复杂条件搜索、项目详情、结构化字段、附件、企业画像、合同和拟在建项目等。
3. “AI 重写”应描述为搜索条件解析与结构化转换能力，不要宣传为无条件理解所有问题或保证检索准确。
4. “结构化数据”应区分官方结构化字段和 AI 推断字段；宣传时不能把推理结果表述为官方事实。
5. 不虚构客户数量、数据覆盖范围、行业排名、识别准确率、实时性、案例、收入或节省成本等指标。
6. 未提供官方网站、客服电话、销售联系人、二维码或活动信息时，不要自行编造；如需宣传物料，向用户索取真实素材。
7. 对外宣传中不要暴露 API 网关地址、API Key、内部字段名或内部错误信息。

  - 招中标项目列表与详情联动

  - 企业、合同和拟在建项目分析

输出营销文案时，优先围绕业务流程和可验证能力表达，避免只罗列接口名称。
