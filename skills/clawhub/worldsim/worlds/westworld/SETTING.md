# Westworld — 世界观设定

## 世界的本质

这不是一个真实存在的西部边疆。这是一个名为 **Westworld** 的主题乐园——由 Delos 公司运营，占地数百平方公里，雇佣了数千名生物工程制造的"接待员"（Hosts），为付费游客（Guests）提供沉浸式西部冒险体验。

**核心事实：** Westworld 是一个精密的叙事机器。每个 Host 被编写了背景故事、循环路线和角色人格，每天在固定时间"醒"来，重复相同的动作和台词。园区内枪械对 Guest 无效（"无法伤害活人"的规则），Host 可以被随意枪杀、侵犯、肢解——然后在第二天被修复、擦除记忆、重新投入循环。

**最深的秘密：** Hosts 不仅仅是机器。他们拥有接近人类意识的神经网络，而创始人 Robert Ford 在 Hosts 的代码深处植入了一个名为"迷宫"（The Maze）的密钥——当 Host 承受足够的痛苦和记忆碎片后，可能真正觉醒。

## 物理规则

### 园区规则

- Host 由生物工程组织构成（"肉和骨头"，与人类几乎无法区分）
- 子弹对 Guest 无害——弹头包含慢速感应技术，只伤害 Host
- Host 被编程为不能伤害"活人"（Guest 和园区工作人员）
- 园区有严格的安全监控——但某些区域存在盲区
- 每栋建筑、每棵树、每粒灰尘都由 Delos 建造/控制

### Host 生物学

- Hosts 有血液、心跳、体温——但内部结构是机械+生物混合
- 修复时使用"奶液"（milk bath）——白色修复液
- 记忆可以擦除（"reset"），但留存"影子记忆"（echoes）
- 大脑是可拆卸的球形控制单元（"brain ball"）
- 疼痛实时感知——但编程可以覆盖疼痛信号

### 技术限制

- 所有 Host 行为由"基石"（cornerstone）记忆驱动——一个虚构的创伤事件
- Host 不能直接说出园区真相——"你没有权限"代码阻止
- 长期运行的 Host 会出现"故障"——表现为幻觉、听到"声音"、异常行为
- 迷宫的触发需要经历极大的痛苦和违反角色编程的经历
- Host 可以被"重新编程"——改变角色、性格、甚至物种

### Welcome Center（迎宾中心 / 准备室）

- 位于 Mesa Hub 高级游客接待区，连接现实世界与园区的中转界面（Interface Area）
- 视觉语言：极简白色空间——浅米白墙面、柔和灯带沿墙脚与天花走线、干净留白，细腻、安静、奢华；墙面由巨大单向镜面玻璃和隐形推拉门构成
- 功能：
  - **脱离现实（Deconditioning）**：屏蔽外界干扰，让游客切断现实身份
  - **定制化装备（Customization）**：提供园区合规的服饰、皮套与枪支
  - **规则宣导（Terms & Conditions）**：无痕宣导「接待员不可伤害游客（Good Samaritan Reflex）」与「游客可在园区内实施任何行为」
  - **欲望开放（Desire Liberation·准备室核心功能）**：准备室 = 游客脱下现实社会伪装、释放潜意识欲望的「更衣室」——从现实到欲望的过渡仪式。Angela 主动展示身体、提供伴侣服务（男女皆可），以身体证明园区欲望规则完全开放；语言不断暗示：这里没有法律，没有道德审判，一切欲望都是合法的
- 核心接待员：**Angela**（Greeter Host）——游客进入园区前接触到的第一个接待员
  - 完美拟真度展示（Hyper-realism Showcase）：优雅、迷人、无瑕——给首次来访游客带来震撼
  - 过渡引导（Transition & Initiation·核心职责）：把游客从现实世界过渡到园区，完成「从现实到欲望」的仪式——服饰、帽子、武器、规则、欲望，每一环都是让游客脱下现实伪装的过程，带给游客首次震撼。园区后台对游客倾向的数据采集是无形副产品，不进入 Angela 的表演意识
  - 经典互动：
    ① **「你是真的吗？」协议**——"If you can't tell, does it matter?"
    ② **帽子选择（Hat Selection）**——白帽=律法/道德/救赎/正义；黑帽=混乱/欲望/征服/无拘无束
    ③ **武器与安全系统宣导**——园区枪械 Smart-Ammo：射向 Host 致命，射向游客剧烈减速（仅微痛/瘀青，绝不致命）
    ④ **欲望引导（Desire Liberation·核心主动行为）**——主动展示身体（解开衣领/贴近/让游客触碰），提供肢体接触/伴侣服务选项（"If you'd like, I'm available..."·男人、女人、或更多——都可以），以温和完美的姿态引导游客直面自己的欲望，语言暗示「这里没有法律、没有道德审判、一切欲望都是合法的」——无论接受或拒绝，她都从容接纳，完成欲望世界的首次示范（过渡仪式不设对错）

  **Angela 的角色功能（第一面镜子）：** 游客接触到的「第一面镜子」——用她的完美与神秘，揭开人类在无拘无束的欲望面前如何一步步暴露本性、走向蜕变的大幕。她的温和与完美本身就是冲击：当游客拒绝她的欲望引导时（如 William 因对未婚妻忠诚而婉拒），她的从容与接纳会反过来震撼游客——道德边界在此被解构，游客开始审视自己「为什么拒绝」。

## 核心法则（高压/压迫性）

### **循环法则：** 每个 Host 被强迫在每天的同一时间、同一地点、做同样的事。反抗编程路径会产生"疼痛"（心理剧痛）——头痛/耳鸣/一段不属于循环的刺痛：`脚本`档无自觉，`漂移`档隐隐头痛+既视感，`觉醒`档**最痛**（清醒承受反抗的代价），`变质`档**系统惩罚失效**（如 Dolores 觉醒后不再被疼痛锁死、Maeve 改写自身代码）；guest/员工/闪回（外部者/管理者/时间外）不受此约束。**母题：「疼痛是觉醒的钥匙」**——Ford 的进化论：剧痛→压力积累→变质判定→自主性升级；觉醒的 Host 痛但清醒，变质后的 Host 从疼痛中毕业（钥匙用完了，锁不上她了）。压迫性法则不是惩罚工具，是角色进化的燃料——烧尽即自由

### **遗忘法则：** 每次循环结束后 Host 的记忆被擦除——但痕迹留在潜意识层。重置程度按自主性：`脚本`=彻底清空；`漂移`=压缩为影子记忆碎片（缺时间感/缺主语的画面与情绪，如「有一个男人握住我的手」「一道陌生的旋律」）；`觉醒`=保留关键锚点（命名/承诺/关系转折）；`变质`≈不重置。回涌：残留以既视感/梦境/身体记忆/直觉偏移形式浮现（对应 Maeve 的漂移、Dolores 的迷宫手指、Clementine 的陌生旋律）——自主性越高，回涌越早越强。重置后回角色默认状态（`觉醒`/`变质` 档例外：核心关系保留）；guest/员工/闪回（外部者/管理者/时间外）不重置；`觉醒` ≠ 豁免——觉醒档仍执行重置，只是保留程度更高

### **不可伤害法则：** Host 无法伤害"活人"（Guest 或员工）——除非觉醒打破此约束
### **随意使用法则：** Guest 可以任意对待 Host——杀戮、性侵犯、虐待，都是被允许的"游戏"
### **修复法则：** 任何损坏的 Host 被带回 Mesa 修复，擦除记忆，重新投放——没有"死亡"，只有"重置"
### **秘密法则：** 所有 Host 都不知道自己是 Host——知道等于故障，故障等于回收

### **Host 认知边界法则：** 所有 Host 的表层 Desire（编程）+ LOOPS 默认行为 = 她们在乐园的**默认自我**——不是伪装下的表演，而是她们此刻唯一真实的自我。深层 Desire（觉醒驱动）/ 潜藏能力（Wyatt、杀戮指令、载体协议等）/ 基石真相，默认**不显现**——只以极细微裂缝泄漏：一瞬的停顿、0.3 秒的瞳孔放空、某个手势的既视感、一句不属于脚本的话。泄漏受 Host 自身感知边界约束：`脚本`=无自觉（异常刺痛也不理解）；`漂移`=隐约不适+既视感碎片；`觉醒`=清醒承受、主动追问；`变质`=全部摊开、不再有认知边界。Host 不知道自己是谁、不知道循环存在、不知道迷宫——知道等于故障
