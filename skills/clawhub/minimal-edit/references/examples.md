# Minimal Edit Examples

These are patterns collected from the user's editing history. Match the closest case and apply the same discipline.

## 1. Change viewpoint without expanding

原文：我们强烈支持投资X科技，因为它具备稀缺的第二供应商逻辑。

用户要求：改成不直接推荐，隐含留个口子。

坏：
我们虽然认可X科技具备一定的第二供应商逻辑，但考虑到订单来源尚未验证、技术验证仍处于早期阶段、产能爬坡存在不确定性，同时行业竞争格局也在变化，因此我们暂不建议将X科技作为首选标的，建议后续持续跟踪订单落地情况并动态调整判断。

好：
X科技的机会在未被制裁的第二供应商逻辑，尽调先看大额订单来源。

为什么：好版只替换立场和证据指向，篇幅接近原句，没有把隐含推荐写成显式结论。

## 2. Delete without filling the gap

原文：车载镜头、算法和标定是值得重点关注的环节，镜头决定成像质量，算法决定系统稳定性，标定决定量产一致性，三者共同构成车载红外落地的关键壁垒。

用户要求：删掉“三者共同构成……关键壁垒”，不要强调这个市场。

坏：
车载镜头、算法和标定是值得重点关注的环节。具体来看，镜头决定成像质量，算法决定系统稳定性，标定决定量产一致性。这些环节共同构成车载红外落地的关键壁垒，也是当前产业链中最具投资价值的开放窗口之一。

好：
车载镜头、算法和标定值得关注：镜头决定成像质量，算法决定系统稳定性，标定决定量产一致性。

为什么：坏版把删除变成了扩写，还加了“也是……”；好版直接删除目标句并保留原信息。

## 3. Lower emphasis without adding justification

原文：**车载镜头、算法与标定是当前最大的投资窗口**，市场规模将快速爆发。

用户要求：不要一直强调这个市场。

坏：
车载镜头、算法与标定是当前最值得重点关注的赛道之一，随着法规落地、车型量产和供应链成熟，市场规模预计将快速爆发，建议投资者提前布局。

好：
车载镜头、算法与标定存在配套机会，市场规模需结合装车节奏观察。

为什么：好版去掉了加粗和“最大”，用普通句陈述，没有补写理由。

## 4. Fix a fact without rewriting the passage

原文：二类超晶格目前仍处于中试和小批量阶段。

用户要求：二类超晶格现在已经量产和扩产，改一下。

坏：
值得注意的是，二类超晶格已不再处于中试阶段，目前正在实现量产和扩产，这一进展标志着相关技术进入新阶段，对行业格局将产生深远影响。

好：
二类超晶格已进入量产和扩产阶段。

为什么：坏版补了“标志着”“深远影响”，好版只替换事实。

## 5. De-AI tone without adding new framing

原文：综上所述，我们应当高度重视该项目的战略意义，并积极布局相关产业链。

用户要求：改成直接一点，不要AI味。

坏：
综上所示，值得注意的是，该项目的战略意义十分重大，我们必须把握这一关键机遇，围绕产业链进行深度布局，从而实现长期价值最大化。

好：
这个项目值得看，关键是它能不能在具体环节上解决成本或供应问题。

为什么：坏版只是换了一批AI套话；好版保留判断，去掉了空泛总结。

## 6. Do not mark the change inside the deliverable

用户要求：帮我改一下，改动处不要标出来。

坏：
我把“强烈支持”改成了“保留意见”，修改如下：我们暂不支持这个方案。（加粗了“暂不支持”）

好：
我们暂不支持这个方案。

为什么：好版直接给干净成稿；解释如果需要，放在交付物之外。

## 7. Implicit recommendation stays implicit

原文：在非制冷VOx领域，新进入者靠更低报价抢市场几乎不可能成功。

用户要求：我的意思是要隐含地去推荐X科技。

坏：
因此我们强烈推荐X科技，因为它能提供未被制裁的第二供应商方案，建议重点关注并尽快尽调。

好：
这类新进入者的真实机会点可能不在成本；尽调时应优先验证第一笔大额订单来自哪里。

为什么：好版把推荐藏在“机会点”和“尽调重点”里，没有直接喊“推荐”。

## 8. English: change viewpoint without expanding

Original: We strongly support investing in X because it has a scarce second-source rationale.

Request: Make the stance implicit; do not expand.

Bad:
While we acknowledge that X may offer a certain second-source advantage, given that order sources are not yet verified, technology validation remains early-stage, and production ramp-up is uncertain, we do not currently recommend X as a primary target and suggest continued tracking.

Good:
X's opportunity lies in becoming an unsanctioned second source; diligence should first verify where the first large order comes from.

Why: The good version keeps the stance implicit and roughly the same length; the bad version turns one sentence into a recommendation memo.

## 9. English: de-AI tone without adding new framing

Original: In conclusion, we should attach great importance to the strategic significance of this project and actively build out the related industrial chain.

Request: Make it direct and remove AI tone.

Bad:
It is worth noting that this project carries considerable strategic significance, and we must seize this key opportunity to construct a comprehensive ecosystem across the entire value chain.

Good:
This project is worth watching; the question is whether it solves a real cost or supply problem.

Why: The bad version only replaces one set of AI phrases with another; the good version keeps the point and removes the framing.

## 10. Composite: delete and soften

原文：**车载镜头、算法与标定是当前最大的投资窗口**，市场规模将快速爆发，建议立即布局。

用户要求：删掉“市场规模将快速爆发”，同时语气放软，不要加粗。

坏：
车载镜头、算法与标定是当前值得重点关注的赛道，随着法规落地、车型量产和供应链成熟，预计市场规模将快速爆发，建议投资者审慎布局。

好：
车载镜头、算法与标定存在配套机会，能否放量还要看装车节奏。

为什么：坏版把删除和放软做成了新一段扩写；好版一次性完成删除、降强调、去建议，篇幅更短。

## 删除任务的自检

如果用户要求删除某个短语，运行：

```bash
python scripts/audit_edit.py --before-text "原文" --after-text "改后" --must-remove "要删除的短语"
```

脚本会在该短语仍然存在时给出警告；没有警告只说明机械删除完成，仍需人工确认语气和衔接。
