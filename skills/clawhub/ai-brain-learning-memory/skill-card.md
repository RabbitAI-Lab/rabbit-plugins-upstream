## Description:

AI brain learning and memory methodology for helping an agent answer questions about what to remember, where to store memory, how to recover from forgetting, and how to reason about memory poisoning risk.

This skill is ready for commercial/non-commercial use.

## Use Case:

Employees, external users, and developers use this skill to receive practical guidance on AI memory architecture, memory consolidation, retrieval, review, and memory safety. It is especially suited for answering user-facing questions such as how to make an AI remember prior context, why an AI forgets, and how to reduce memory poisoning risk.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad conversations about AI, learning, or memory.

Mitigation: Use narrower trigger phrases or routing rules when precise activation is required.

Risk: Memory methodology guidance can influence what an agent persists or trusts.

Mitigation: Review proposed memory updates before persistence and keep memory provenance visible for later audit.
