# 家常菜谱生成

## 使用引导（30 秒看懂）

本技能帮你把「手头的食材 / 一个菜名 / 口味偏好」快速写成一份**能直接下厨的家常菜谱**——含用量、步骤、火候、以及翻车后的补救办法。

- **适合谁**：想做饭但不确定做什么、怎么做的人；减脂 / 清淡 / 下饭等特定需求的人。
- **怎么用**：告诉我「有什么食材 / 想做哪道菜 + 几人吃 + 口味偏好」，我来生成菜谱。
- **产出包含**：菜名亮点、难度用时份量、食材（含替代）、分步做法（含火候）、翻车补救、搭配建议。
- **安全红线**：不宣称疗效、不神化食材、生食 / 半熟做法注明食品安全前提。

> 不确定做什么？直接说手头食材即可，例如：「两个鸡蛋、一个番茄、要清淡」，我会帮你生成。

## Overview

家常菜的核心是「可落地」：用量要具体、火候要明确、替代要给出。一份好菜谱不是罗列步骤，而是让一个不太会做的人也能复现出接近的味道，并且知道哪一步最容易翻车、翻了怎么救。

本技能按这个结构产出，并严格遵守食品安全与不过度宣称的底线——食材功效、减肥疗效这类话是菜谱被质疑的主要原因。

## When to use

- 用户手头有若干食材，不知道做什么、怎么做。
- 指定菜名想学做法（宫保鸡丁 / 番茄炒蛋 / 红烧肉 等）。
- 按人数、口味（清淡 / 下饭 / 少油 / 减脂）、厨艺水平生成。

## 平台规格

| 项 | 规格 |
|---|---|
| 难度 | ★～★★★（按步骤复杂度） |
| 用时 | 给出区间，如「约 20～30 分钟」 |
| 份量 | 明确 N 人份 |
| 用量 | 汤匙 / 克 / 适量 混用并说明可调 |
| 火候 | 每个关键步骤标注（大火收汁、中小火慢炖等） |
| 替代 | 每种主料至少给 1 个可替换项 |

## 输出模板

```markdown
## <菜名> · 一句话亮点
- 难度：★～★★★｜用时：约 X 分钟｜份量：N 人

## 食材（含替代）
- 主料：…（没有 XX 可用 YY 替代）
- 辅料：…
- 调料：…（用量给「汤匙 / 克 / 适量」并说明可调）

## 步骤
1. 预处理（切配 / 腌制）— 关键点
2. 热锅 … — 火候与时间
3. 调味 … — 顺序
4. 出锅 — 判断熟度的方法

## 翻车补救
- 太咸 / 太淡 / 粘锅 / 老硬 各怎么救

## 搭配建议
- 配什么主食 / 汤更平衡
```

## 关键规则

- **用量具体且可调**：不要用「少许」「适量」孤例出现，至少给一个可量化参照并说明可调范围。
- **标注关键火候**：大火收汁、中小火慢炖、热锅冷油等关键节点必须写清。
- **过敏 / 忌口主动提示替代**：如不放辣、不加香菜、海鲜过敏替代方案。
- **不宣称疗效、不神化食材**：不写「吃了 XX 能治 XX」「XX 是超级食物」，只写口味与做法。
- **生食 / 半熟做法注明食品安全前提**：溏心蛋、三分熟牛排等标注入口安全条件。
- **步骤顺序清晰**：预处理 → 主烹 → 调味 → 出锅，不要跳步。
