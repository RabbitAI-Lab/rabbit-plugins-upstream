## Token / 认证错误码

| 错误码 | 说明 |
|--------|------|
| 101008 | 无效的 refresh_token 或 token 已过期 |
| 101040 | 签名验证失败 - 签名不匹配 |
| 101043 | 签名验证失败 - 时间戳过期 |
| 101100 | Agent 授权码不存在或已过期，需要重新登录威思客系统并获取新的授权码 |

## 通用 HTTP 错误

| HTTP 状态码 | 说明 |
|-------------|------|
| 400 | 请求参数错误 |
| 401 | 未授权（token 无效或过期） |
| 403 | 无权限访问 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 客户端错误分类

| 类型 | 触发条件 |
|------|---------|
| AbortError | OAuth 回调超时（10分钟） |
| TypeError | 网络连接失败 |
| SyntaxError | 服务器返回非 JSON 格式响应 |

## 错误处理策略

1. **401 错误**: 自动刷新 token 并重试一次；如果刷新失败，清除本地 token 并要求重新登录
2. **400 + 101040/101043**: 签名失败，通常是时间戳偏差或签名计算错误，需要检查系统时间
3. **400 + 101008**: refresh_token 失效，需要重新登录
4. **101100**: Agent 授权码不存在或已过期，引导用户重新登录威思客系统并复制新的授权码
5. **202105（预约人不存在）**: 检查 creatorId 是否正确、token 中的 userId 是否有效
6. **其他 4xx**: 检查请求参数是否正确
7. **5xx**: 服务器错误，建议稍后重试
