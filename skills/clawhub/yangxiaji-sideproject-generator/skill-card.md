## Description: <br>
Generates personalized AI side-project recommendations and a phased 100-day action plan from a user's work status, time availability, skills, AI interests, and starting resources. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[freedompixels](https://clawhub.ai/user/freedompixels) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
External users interested in AI side projects use this skill to answer five guided questions and receive a recommended direction, risk notes, a 100-day execution plan, a short self-introduction template, and a first-week checklist. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Running the optional Python script can create or overwrite my_ai_sideproject_plan.md in the current directory. <br>
Mitigation: Run it in a dedicated working directory or rename any existing my_ai_sideproject_plan.md file before execution. <br>
