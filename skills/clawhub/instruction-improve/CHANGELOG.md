# v1.4.7

- 新增 `topics` 命令：逐条评论话题标签的汇总与单话题详情（趋势 / 原句 / 本品 vs 竞品 / 标签洞察），免费。
- `reviews` 新增 `--topic` 按话题筛，返回行带 `tags[]`（维度 / 话题 / 原句），引用原句不再靠模型复述。
- 标准工作流第 12 条：用户问「抱怨最多的是什么 / 某问题最近变多了吗 / 竞品在这点上如何」先走 `topics`。
- CLI 接口与计费规则延续 v1.4.6，不提高最低支持版本。

# v1.4.7

- 用一句自然语言发起评论简析、竞品比较、Listing 优化等任务，优先复用对话中的商品与目标。
- 简短请求优先返回数据范围、问题与评论依据、趋势判断；不强制展示技术日志或完整报告。
- 优先读取已有数据；不追问接口没有提供的变体范围选项，不将新入库的历史评论当成近期趋势。
- 安装说明明确浏览器授权、目录识别、配置保留与连接检查；增加可复制的使用示例。
- 写清账户免确认策略、只报价不执行及单独开启持续监控的边界。
- 延续 v1.4.5 的 CLI 接口和计费规则，本次不提高最低支持版本。
