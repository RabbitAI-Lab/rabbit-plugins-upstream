## Description:

Create LinkedIn document carousels and post visuals with Canvora — correct aspect ratio, safe zones for LinkedIn's UI chrome, B2B content shaping. Use when the user wants a LinkedIn carousel, document post, swipe post for LinkedIn, or B2B thought-leadership visuals.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers can use this skill to shape professional LinkedIn carousel or post content and prepare Canvora generation commands. It guides format selection, slide planning, and delivery of the finished visuals as a PDF document post.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Carousel generation sends the submitted content and brand assets to Canvora.

Mitigation: Use only content and brand assets the user is comfortable sending to Canvora.

Risk: Carousel generation spends Canvora account credits at 15 credits per slide.

Mitigation: State the slide count and its credit cost in the same message as the generation run.

Risk: Generated visuals may need review before publication.

Mitigation: Review the finished visuals before publishing.
