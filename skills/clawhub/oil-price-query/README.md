# 中国油价查询技能

基于 [v1.apizero.cn](https://v1.apizero.cn) 免费 API 的中国各省实时油价查询工具。

## 功能特性

- **查询指定省份的实时油价数据**
- **支持省份全称和简称查询**（如"江苏"或"江苏省"）
- **显示油价更新日期和下次调整时间**
- **显示各油品类型及详细价格信息**
- **自动计算油价涨跌趋势和幅度**
- **美观的终端输出格式**

> **重要提示**：本工具使用 `v1.apizero.cn` API，该 API 仅提供**省级汇总数据**，不包含城市级别（如"南京"）的油价信息。

## 核心限制

⚠️ **仅支持省级查询**：本工具无法查询城市级油价（如"南京"、"北京"等城市代码），因为 API 返回的是省级汇总数据。

## 为什么无法查询城市级油价？

本工具使用的 `v1.apizero.cn` API 仅提供**省级汇总数据**，返回结构如下：

```json
{
  "code": 0,
  "data": {
    "province": "江苏",
    "prices": [
      {
        "name": "92 号汽油",
        "price": 8.58,
        "unit": "元/升"
      }
    ]
  }
}
```

**关键限制**：
- API 返回的是省份简称（如"江苏"而非"江苏省"）
- `prices` 数组包含该省份所有城市的油价数据
- **但不包含城市代码对应的单独条目**（如南京的城市代码 `320000` 不在返回数据中）
- 因此，查询"南京"或传入南京城市代码时，**无法获取城市级油价数据**

如需查询具体城市油价，建议使用其他提供城市级数据的 API。

## 注意事项

1. ⚠️ **仅支持省级查询**：无法查询城市级油价（如"南京"、"北京"等）
2. 支持省份全称和简称查询
3. 部分省份可能不提供某些油品类型（如 89 号汽油、-10 号柴油）
4. 油价数据来源于免费 API，可能延迟更新
5. API 返回的涨跌趋势为**预测值**，以官方发布为准
6. 建议使用省份简称查询（如"江苏"），但全称也可正常工作

## 数据来源

- **API 地址**：https://v1.apizero.cn/api/oil-price
- **API 说明**：免费开放的油价数据 API，提供全国省级油价信息
- **访问方式**：HTTP GET 请求，参数为省份名称的 URL 编码值
