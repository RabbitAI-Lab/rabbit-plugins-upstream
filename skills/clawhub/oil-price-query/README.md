# 中国油价查询技能

基于 360 地图 API 的中国各省实时油价查询技能。

## 功能特性

- ✅ 查询单个或多个省份的实时油价
- ✅ 查询指定省份的历史油价变化
- ✅ 全国所有省份油价概览对比
- ✅ 支持省份全称和简称查询
- ✅ 自动计算油价涨跌趋势
- ✅ 美观的终端输出格式

## 快速开始

### 一键安装

```bash
cd ~/.openclaw/workspace/skills/oil-price-query/scripts
./install.sh
```

### 使用方法

安装完成后，可以在终端运行：

```bash
# 查询北京实时油价
oil_price.sh 北京

# 查询多个省份
oil_price.sh 北京 上海 广州

# 查询广东历史油价
oil_history.sh 广东

# 查看全国油价概览
oil_all.sh
```

## 支持查询

| 查询类型 | 命令 | 说明 |
|---------|------|------|
| 实时油价 | `oil_price.sh [省份]` | 查询当前油价 |
| 历史油价 | `oil_history.sh [省份]` | 查询历史调价记录 |
| 全国概览 | `oil_all.sh` | 查看所有省份油价 |

## 数据说明

- **92#汽油**：适用于大多数家用车（原 93 号汽油）
- **95#汽油**：适用于中高端车辆（原 97 号汽油）
- **98#汽油**：适用于高性能车辆
- **0#柴油**：普通柴油
- **89#汽油**：主要用于部分出租车和老式车辆（部分省份已停售）
- 价格单位：人民币元/升（元/L）

## 数据来源

- 实时油价：https://map.360.cn/app/qcms?req=oil_price
- 省份编码：https://map.360.cn/cms/map/data/region.json

## 注意事项

1. 支持省份全称和简称查询
2. 部分省份可能不提供 89 号汽油或 98 号柴油
3. 油价数据可能延迟更新
4. 历史油价数据以官方发布为准
