# 中国油价查询

查询中国各省/直辖市的实时油价和历史油价数据。

## 快速使用

```bash
# 查询单个省份实时油价
~/.openclaw/workspace/skills/oil-price-query/scripts/oil_price.sh 北京

# 查询多个省份实时油价
~/.openclaw/workspace/skills/oil-price-query/scripts/oil_price.sh 北京 上海 广州

# 查询指定省份历史油价
~/.openclaw/workspace/skills/oil-price-query/scripts/oil_history.sh 北京

# 查询全国所有省份实时油价概览
~/.openclaw/workspace/skills/oil-price-query/scripts/oil_all.sh
```

## 支持查询

- **实时油价**：查询当前各省份 92/95/98 号汽油及 0 号柴油价格
- **历史油价**：查询指定省份的历史油价变化记录
- **全国概览**：查询所有省份的实时油价对比

## 数据说明

### 汽油类型
- **89#汽油**：主要用于部分出租车和老式车辆（部分省份已停售）
- **92#汽油**：适用于大多数家用车（原 93 号）
- **95#汽油**：适用于中高端车辆（原 97 号）
- **98#汽油**：适用于高性能车辆
- **0#柴油**：普通柴油

### 价格单位
- 人民币元/升（元/L）

### 数据来源
- 来源：360 地图油价接口
- 接口地址：https://map.360.cn/app/qcms?req=oil_price
- 省份编码数据：https://map.360.cn/cms/map/data/region.json

## 注意事项

1. **省份名称匹配**：支持省份全称和常用简称（如：北京/京、广东/粤）
2. **数据实时性**：油价数据可能延迟更新，以官网数据为准
3. **部分省份无 89#汽油**：部分省份（如内蒙古、辽宁、吉林、黑龙江、河南、湖北、湖南等）已取消 89 号汽油供应
4. **98#汽油普及**：98 号汽油在部分省份可能不销售
5. **0#柴油**：部分省份可能不提供柴油价格数据
6. **API 访问限制**：360 地图接口可能有访问频率限制
7. **省份编码**：使用标准行政区划代码（6 位数字）

## API 接口说明

### 实时油价接口
- **地址**：`https://map.360.cn/app/qcms?req=oil_price&cityid={省份代码}`
- **参数**：`cityid` - 省份行政区划代码（6 位）
- **返回格式**：JSON 格式
  ```json
  {
    "date": "2026 年 5 月 8 日",
    "next_date": "2026 年 5 月 21 日",
    "cities": [
      {
        "city": "北京市",
        "adcode": "110000",
        "data": [
          {"name": "89 号汽油", "price": "8.16", "last": "7.92"},
          {"name": "92 号汽油", "price": "8.72", "last": "8.46"},
          ...
        ]
      }
    ]
  }
  ```

### 历史油价接口
- **地址**：`https://map.360.cn/app/qcms?req=oil_history&cityid={省份代码}`
- **参数**：`cityid` - 省份行政区划代码（6 位）
- **返回格式**：JSON 数组，包含历史调整记录

### 省份编码数据
- **地址**：https://map.360.cn/cms/map/data/region.json
- 包含全国各省、市、县区的行政区划代码

## 开发说明

本技能基于 360 地图油价查询接口开发，支持：
- 按省份/直辖市查询实时油价
- 按省份/直辖市查询历史油价
- 全国油价对比分析
- 智能识别省份名称和简称
- 自动计算油价涨跌趋势
- 格式化美观的输出

### 实现原理
1. 通过省份名称或简称匹配省份编码
2. 使用 curl 请求 360 地图 API 获取油价数据
3. 使用 Python 解析 JSON 并格式化输出
4. 自动判断油价涨跌趋势并添加 emoji 标识
5. 支持全国油价概览对比

### 依赖
- Python 3.x
- curl 命令
- bash shell
