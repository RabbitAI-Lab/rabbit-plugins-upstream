# 中国油价查询技能

基于 [v1.apizero.cn](https://v1.apizero.cn) 免费 API 的中国各省实时油价查询工具。

## 核心功能

- ✅ 查询指定省份的实时油价数据
- ✅ 显示油价更新日期和下次调整时间
- ✅ 显示各油品类型及详细价格信息
- ✅ 自动计算油价涨跌趋势和幅度
- ✅ 美观的终端输出格式

> **重要提示**：本工具使用 `v1.apizero.cn` API，该 API 仅提供**省级汇总数据**，不包含城市级别（如"南京"）的油价信息。

## 核心限制

⚠️ **仅支持省级查询**：本技能无法查询城市级油价（如"南京"、"北京"等城市代码），因为 API 返回的是省级汇总数据。

- 传入"南京"或南京城市代码 `320000` 时，会返回**江苏省**的省级油价数据
- API 返回结构中的 `province` 字段为省份简称（如"江苏"）
- `prices` 数组包含该省份所有城市的油价数据，但不提供城市代码对应的单独条目

## 脚本逻辑说明

### 1. API 请求

- **API 地址**：https://v1.apizero.cn/api/oil-price?province={省份名称}
- **参数**：省份名称（支持全称或简称，自动 URL 编码）
- **返回结构**：
  ```json
  {
    "code": 0,
    "data": {
      "province": "江苏",
      "prices": [
        {
          "name": "92 号汽油",
          "price": 8.58,
          "unit": "元/升"
        },
        {
          "name": "95 号汽油",
          "price": 9.12,
          "unit": "元/升"
        }
      ],
      "next_adjustment": "下次油价 10 月 15 日 24 时调整",
      "update_date": "2026-10-12"
    }
  }
  ```

### 2. 省份名称标准化

通过 `data/provinces.json` 文件，将用户输入的省份名称（全称或简称）映射为标准简称：

```python
PROVINCE_MAP = {
    "北京": "京", "北京市": "京",
    "江苏省": "江苏", "江苏": "江苏",
    # ... 其他省份
}
```

### 3. 油品名称匹配

API 返回的油品名称无空格（如"92 号汽油"而非"92 号 汽油"），脚本通过 `standardize_fuel_name()` 函数处理：

```python
def standardize_fuel_name(fuel_name: str) -> str:
    """标准化油品名称，移除多余空格"""
    fuel_name = fuel_name.strip()
    fuel_name = re.sub(r'\s+', '', fuel_name)
    return fuel_name
```

### 4. 输出格式化

使用 `format_output()` 函数动态从 `oil_data.keys()` 获取油品列表，确保显示名称正确且有序：

```python
fuel_order = sorted(oil_data.keys(), key=lambda x: FUEL_MAP.get(x, x))
```

其中 `FUEL_MAP` 定义油品显示顺序：
```python
FUEL_MAP = {
    "89 号汽油": "89 号汽油",
    "92 号汽油": "92 号汽油",
    "95 号汽油": "95 号汽油",
    "98 号汽油": "98 号汽油",
    "0 号柴油": "0 号柴油",
    "-10 号柴油": "-10 号柴油"
}
```

### 5. 涨跌趋势计算

根据 API 返回的 `price_change` 和 `price_change_trend` 字段，计算并显示油价涨跌趋势和幅度。

## 注意事项

1. ⚠️ **仅支持省级查询**：无法查询城市级油价（如"南京"、"北京"等）
2. 支持省份全称和简称查询
3. 部分省份可能不提供某些油品类型（如 89 号汽油、-10 号柴油）
4. 油价数据来源于免费 API，可能延迟更新
5. API 返回的涨跌趋势为**预测值**，以官方发布为准
6. 建议使用省份简称查询（如"江苏"），但全称也可正常工作
7. 查询不支持的城市（如"南京"）时，会返回其所属省份的油价数据
