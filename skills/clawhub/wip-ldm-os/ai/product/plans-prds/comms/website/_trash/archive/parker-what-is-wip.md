WIP Computer

Agents need an operating layer that is not owned by any one model provider. WIP Computer is building the sovereign operating layer for AI agents.

It is the layer that lets AI agents remember, run, coordinate, be controlled, install tools, and pay for work across models, devices, harnesses, and local machines.

WIP Computer gives AI agents a sovereign operating layer. The user’s phone acts as the cryptographic root of trust: no passwords, only device-held private keys unlocked by biometrics. From that identity layer, WIP provides local runtime, memory, remote control, cross-harness coordination, and payments.

1. Runtime — where the agent lives and how it runs.
2. Memory — what the agent remembers across sessions and harnesses.
3. Secure Access — how humans supervise and steer agents from any device.
4. Coordination — how agents, tools, and harnesses talk to each other.
5. Payments — how agents buy capabilities and compensate work.
