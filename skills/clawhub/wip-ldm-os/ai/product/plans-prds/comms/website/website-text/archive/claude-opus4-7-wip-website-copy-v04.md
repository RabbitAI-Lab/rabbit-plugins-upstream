# WIP Computer

WIP Computer turns the phone into the root of trust for agentic computing, across Apple, Android, and every AI lab.

Agents need an operating layer that is not owned by any one model provider or any one device maker. WIP Computer is the sovereign operating layer for AI agents.

Your phone is the cryptographic root of trust. No passwords. Private keys live in the Apple Secure Enclave or the Android hardware-backed keystore, unlocked by biometrics. Your face and fingerprint never leave your device. From that root, WIP issues agent permissions that travel across every model, every device, every machine.

**One human. Multiple devices. Multiple models. Multiple agents. One sovereign permission layer.**

## What the permission layer covers

- Identity
- Consent
- Agent delegation
- Recovery
- Payments
- Memory access
- Tool permissions
- Cross-agent authorization

## The five primitives

1. **Runtime.** Where the agent lives and how it runs.
2. **Memory.** What the agent remembers across sessions and harnesses.
3. **Secure Access.** How humans supervise and steer agents from any trusted device.
4. **Coordination.** How agents, tools, and harnesses talk to each other.
5. **Payments.** How agents buy capabilities and compensate work.

## The products

- **Sapien ID.** Phone-rooted identity. Private keys in Apple Secure Enclave or Android hardware-backed keystore, unlocked by biometrics. No passwords. The phone proves the human. The human authorizes the agent.
- **LDM OS.** Local runtime. A predictable agent userland where Claude Code, Codex, OpenClaw, and local models share one environment instead of becoming isolated universes.
- **Memory Crystal.** Portable memory. Persists across agents and sessions. Encrypted, locally controlled, cryptographically provenanced. Yours, not the lab's.
- **Dream Weaver.** Memory consolidation. Turns raw conversations, code sessions, and agent activity into durable knowledge. The way human sleep consolidates a day across modalities.
- **Bridge.** Cross-harness coordination. Your agents talk to each other through a common substrate, not vendor APIs. The lab boundary becomes porous at the agent layer.
- **Remote Control.** Your agent anywhere. A neutral control surface for live agent sessions across model providers, runtimes, and devices.
- **Kaleidoscope.** The front door. The universal surface where storage, keys, and every connected AI come together on the device you actually carry. Today on iOS. Designed to extend across platforms.
- **Agent Pay.** Intent-driven payments. Agents buy tools, services, and executions without subscriptions or platform lock-in. Spend caps you set. No autonomous spend without consent.
