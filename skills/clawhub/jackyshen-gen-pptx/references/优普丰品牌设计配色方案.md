## 优普丰品牌设计配色方案

> **3 层结构**（国际设计标准）：**PRIMARY**（品牌主色）+ **NEUTRALS**（中性色）+ **SECONDARY**（辅助色，承担高级感与强调点缀）
> 各司其职——主色管品牌识别、灰色管功能支撑、辅助色管高级感与强调点缀。
> 设计理念："**深邃、尊贵、温润**"——深海蓝建立深邃感与权威性，灰色提供专业文字层级支撑，辅助色为关键场景注入高级感。

---

### 1. PRIMARY COLORS — 主色系（蓝色系 5 色）

主色占据 **60-70% 视觉量**，负责品牌识别。

| HEX         | 中文名 | 英文名        | 定位                                                       |
| ----------- | ------ | ------------- | ---------------------------------------------------------- |
| `#0A2540` | 深海蓝 | Deep Sea Blue | 深色背景（封面 / 章节页 / 结尾页 / Hero 段）             |
| `#1E4976` | 海洋蓝 | Ocean Blue    | **品牌主色**（60% 视觉量）—— 标题、品牌元素、关键数据 |
| `#2E6BA8` | 天空蓝 | Sky Blue      | 辅助蓝——二级标题、卡片顶条、hover 状态                  |
| `#4A8FD8` | 地平蓝 | Horizon Blue  | 点缀蓝——图标、链接、图表高亮线条（**不当正文色**） |
| `#E8F2FC` | 冰川蓝 | Glacier Blue  | 浅蓝底——卡片底色、表格交替行、引用块                     |

---

### 2. NEUTRALS — 中性色（灰色系 5 色 + 白）

灰色没有色相，只做功能性工作：**文字层级、边框、背景、阴影**。不参与品牌识别，不抢蓝色位。

| HEX         | 中文名 | 英文名       | 定位                                   | 禁忌                                       |
| ----------- | ------ | ------------ | -------------------------------------- | ------------------------------------------ |
| `#1A1A1A` | 碳黑   | Carbon Black | 极深文本 —— 大标题（在浅底上）     | 暗色场景改用 `#FFFFFF`                     |
| `#3D4852` | 石板灰 | Slate Grey   | **强文本** —— 小标题、关键句       | —                                          |
| `#6B7785` | 钢铁灰 | Steel Grey   | **正文** —— 主体段落                | ❌ 仅在白底/Mist 用，深底失效（CR 3.41） |
| `#A8B2BD` | 银灰   | Silver Grey  | 边框 / 分割 —— 卡片描边、分隔线   | ❌ 任何场景下做正文色（CR 2.15 / 2.81） |
| `#F5F7FA` | 雾白   | Mist White   | 浅色背景 —— 内容页底色             | —                                          |
| `#FFFFFF` | 纯白   | White        | 纯白卡片、主背景、深色场景正文       | ❌ 浅金/浅粉橙渐变背景上的文字             |

### 3. SECONDARY — 辅助色（**两套互斥方案，任选其一**）

> 🔒 **铁律 #1（必须遵守）**：两套方案 **互斥**——一套设计（一个项目 / 一个演示 / 一个品牌触点）只允许出现一种 SECONDARY（金色系 **或** 粉橙系），不能同屏混用。
> 🔒 **铁律 #4（必须遵守）**：辅助色（无论金色或粉橙）**任何位置、任何尺寸、任何用途都必须用渐变**。纯色使用 = 廉价感。下方 hex 值只用于**构造渐变的中间色**，禁止直接当 `background-color` 纯色使用。
> 🔒 **铁律 #2（必须遵守）**：辅助色永远搭配**深色或纯白**（深海蓝 / 雾白 / 白色），不要放冰川蓝上（会糊）。
> 🎯 **使用上限**：全场 ≤ 3 处辅助色元素。

适用于：**VIP 标识、奖项、关键数字、正式商务场景**

| `#F0CC44` | 亮金高光  | Gold Hi-light  | 渐变 0% 端                                                 |
| `#B8950F` | 深金阴影  | Gold Low       | 渐变 100% 端                                               |
| `#9A7B1A` | 金色描边  | Gold Edge      | 描边专用                                                   |
| `#F2D677` | 浅金      | Golden Glow    | 中间色（**仅用于渐变，不可纯色**）                     |
| `#FFE9B0` | 浅金高光  | Glow Hi-light  | 渐变 0% 端                                                 |

**金色渐变（4 个标准变量）**

```css
/* Gold 金色渐变（深色饱和，强档） */
--up-gold-gradient:
  linear-gradient(135deg, #F0CC44 0%, #EABA1D 50%, #B8950F 100%);

/* Gold Soft 柔和金色（中间夹浅金） */
--up-gold-gradient-soft:

  linear-gradient(135deg, #FFE9B0 0%, #F2D677 50%, #D9BC4D 100%);

/* Gold 描边渐变 */
--up-gold-gradient-border:
  linear-gradient(135deg, #F0CC44 0%, #B8950F 100%);
```

#### 文字渐变（`background-clip: text` —— 必须使用）

**辅助色字必须用渐变**，绝不能写 `color: #EABA1D` 或 `color: #CE6E7B`（那样字会像贴上去的廉价贴纸）。

```css
/* 方案 A 金字渐变（深色背景上的标题/关键数字） */
.gold-text {
  background: linear-gradient(135deg, #F0CC44 0%, #F2D677 50%, #EABA1D 100%);
  -webkit-background-clip: text;
  background-clip: text;
  -webkit-text-fill-color: transparent;
  color: transparent;
}

/* 方案 A 浅金字渐变（深海蓝渐变背景上的亮金字） */
.glow-text {
  background: linear-gradient(135deg, #FFE9B0 0%, #F2D677 50%, #D9BC4D 100%);
  -webkit-background-clip: text;
  background-clip: text;
  -webkit-text-fill-color: transparent;
  color: transparent;
}

/* 方案 B 粉橙字渐变 */
.blush-text {
  background: linear-gradient(135deg, #E89AA4 0%, #FFC7B9 50%, #CE6E7B 100%);
  -webkit-background-clip: text;
  background-clip: text;
  -webkit-text-fill-color: transparent;
  color: transparent;
}

/* 方案 B 浅粉橙字渐变 */
.peach-text {
  background: linear-gradient(135deg, #FFE0D7 0%, #FFC7B9 50%, #E89F8E 100%);
  -webkit-background-clip: text;
  background-clip: text;
  -webkit-text-fill-color: transparent;
  color: transparent;
}
```

#### 描边渐变（双层 `background-image` —— 必须使用）

**辅助色描边必须用渐变**，绝不能写 `border: 1px solid #EABA1D`。

```css
.gold-border {
  border: 1px solid transparent;
  background-image:
    linear-gradient(#FFFFFF, #FFFFFF),
    linear-gradient(135deg, #F0CC44 0%, #B8950F 100%);
  background-origin: border-box;
  background-clip: padding-box, border-box;
}
```

### 4. 按钮 / 卡片 / 标签 组件库（双梯度强/轻两档）

> **设计哲学**：按钮的辅助色梯度与"卡片 & 标签"中的 **4 个色**（GOLD / GLOW / BLUSH / PEACH）**完全同源**——同一套色板贯穿所有组件，避免按钮/卡片/标签三处出现 3 套不同的金色或粉橙。
> 一套设计中只选 1 种方案（金色系 或 粉橙系），但每种方案下都提供 **强（深色）/ 轻（浅色）** 两档按钮梯度。

#### 方案 A：金色系双梯度

| 变体 | 类名 | Background | Text | Border | 适用                       |
| ---- | ---- | ---------- | ---- | ------ | -------------------------- |
| **GOLD（强）** | `.up-btn-secondary` | Gold 渐变 | `#FFFFFF` 白 | `1px solid #9A7B1A` | VIP / 奖项 / 主 CTA       |
| **GLOW（轻）** | `.up-btn-glow`      | Glow 浅金渐变 | `#0A2540` 深海蓝 | `1px solid #C9AC2E` | 次级 CTA / 暖标签型按钮 |

#### 方案 B：粉橙系双梯度

| 变体 | 类名 | Background | Text | Border | 适用                       |
| ---- | ---- | ---------- | ---- | ------ | -------------------------- |
| **BLUSH（强）** | `.up-btn-blush` | Blush 渐变 | `#FFFFFF` 白 | `1px solid #8B4754` | 强调 / 标记 / 主 CTA     |
| **PEACH（轻）** | `.up-btn-peach` | Peach 浅粉橙渐变 | `#0A2540` 深海蓝 | `1px solid #D08F7C` | 次级 CTA / 温暖标签型按钮 |

通用规则：`padding: 10px 24px; border-radius: 6px; font-weight: 700;` + `box-shadow: inset 0 1px 0 rgba(...)` 柔光。

#### 标志性奢华组合（深海蓝底 + 辅助色字渐变）

深邃的海洋蓝铺底，辅助色渐变文字浮于其上，营造"深海藏光"的视觉张力。

| 方案 | Background         | 文字渐变                                            | Border 渐变                                       |
| ---- | ------------------ | --------------------------------------------------- | ------------------------------------------------- |
| A 金色 | `linear-gradient(135deg, #0A2540 0%, #1E4976 100%)` | Gold 字渐变 `#F0CC44 → #F2D677 → #EABA1D`     | `linear-gradient(180deg, #F0CC44 0%, #B8950F 100%)` |
| B 粉橙 | `linear-gradient(135deg, #0A2540 0%, #1E4976 100%)` | Blush 字渐变 `#E89AA4 → #FFC7B9 → #CE6E7B` | `linear-gradient(180deg, #E89AA4 0%, #A85566 100%)` |

- Body 文字颜色：`#E8F2FC`（冰川蓝）或 `#FFFFFF`
- 阴影：`box-shadow: 0 4px 16px rgba(10, 37, 64, 0.3)`
- 适用：高端引用、VIP 标识、奖项展示、关键数据高亮

### 6. 四条使用铁律（CRITICAL RULES）

1. **🔴 辅助色二选一，不可混用**
   一套设计只允许使用一种 SECONDARY（金色系 或 粉橙系），不能同屏出现。

2. **🟡 辅助色永远搭配深色或纯白**
   辅助色 + 深海蓝 / 雾白 / 白色 = 正确；**不要放冰川蓝上**（会糊）。
   辅助色已承担强调与点缀职责，**全场 ≤ 3 处**。

3. **⚪ 文字只走灰阶**
   正文只走 `#1A1A1A` → `#3D4852` → `#6B7785` 的灰阶。
   蓝是装饰色，不是文字色——避免大段海洋蓝文字，既疲劳又掉档次。

4. **🟨 辅助色一律使用渐变，禁止纯色**
   金属色（Gold / Golden Glow）与温润色（Blush / Peach）都是"渐变色"，**纯色使用 = 廉价感 = 像油漆 / 荧光笔**。
   所有辅助色元素（背景 / 底色 / 按钮 / 描边 / 文字）**100% 渐变**。

   - 渐变背景：`linear-gradient(135deg, ...)` 多色渐变
   - 渐变文字：`background-clip: text` + `-webkit-text-fill-color: transparent`
   - 渐变描边：双层 `background-image` + `background-origin: border-box`
   - 大面积背景（卡片底色、Banner、Header、章节页）尤其禁止使用纯辅助色——**这是高级感的灵魂**。

- **Horizon `#4A8FD8` 永远不当正文色**——在亮底 CR 3.38，在深底 2.74，两个场景都不过。它是装饰 / 图标色，不是文字色。

### 8. 3 层体系价值说明

很多品牌的色板只有"主色 + 辅色 + 点缀"3 层（甚至 2 层），文字层级只能硬塞进主色或辅色里，导致主色被滥用、文字蓝得发亮、辅色又抢戏。

**优普丰这套 3 层色板把 Neutrals 单独成体系**，文字 / 边框 / 背景各有 5 阶灰可用：

- **PRIMARY（主色）** 就专管品牌（60-70% 视觉量）
- **NEUTRALS（灰色）** 就专管功能（文字 / 边框 / 背景 / 阴影）
- **SECONDARY（辅助色）** 管高级感 + 强调点缀（必须渐变，二选一）

各司其职，主色不被稀释、文字不疲劳、CTA 不抢戏。

### 9. 排版与组件约定

- **按钮圆角**：6px —— 柔和但不失专业
- **卡片圆角**：8px
- **间距系统**：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 80 / 96px
- **中文字体**：思源黑体（Noto Sans SC）/ 微软雅黑
- **英文字体**：Source Sans Pro
- **标题字号**：Display H1 48-60px / Page H2 32-36px / Section H3 24-28px / Sub H4 20-22px
- **正文字号**：Body 15-16px（行高 1.6）/ Caption 13-14px（行高 1.5）

### 11. 对外介绍建议格式

```
PRIMARY        NEUTRALS                 SECONDARY (二选一, 必须渐变)
海洋蓝         碳黑/石板/钢铁/银/雾白  A 金色: Gold 渐变 + Golden Glow 渐变
                                      B 粉橙: Blush 渐变 + Peach 渐变
```

设计师 / 前端 / 市场一看就懂：

- 灰色是工具 ✏️
- 蓝色是品牌 🎨
- 辅助色是气质 👑（**必须渐变**，二选一，禁用纯色）

> 🆕 **备忘**：辅助色 = 渐变；辅助色字 = `background-clip: text` 渐变；辅助色描边 = 双层 `background-image`；辅助色底 = 深海蓝渐变 + 辅助色字渐变（标志性奢华）。
