# 咨询 / 汇报 / 商务类 PPT 常见页面布局库

> **为什么需要这个文件？**
> 当 Agent 拿到一节内容时，第一步不是"配图"也不是"选颜色"——而是判断**这页内容的结构是什么**：
> 上下结构？左右对比？矩阵？时间轴？辐射？数据型？
> 选错布局 = 表达不出"咨询味"。这个文件是布局的**索引与决策树**，不是实现细节。
>
> **使用流程**：判断内容结构 → 在下面 8 类里找到匹配的 Layout → 按 SKILL.md 主体里「对于每张幻灯片」的间距/字号/配色规则落到 PPT。

---

## 1. 单一核心观点

用于封面、章节页、Executive Summary、KPI 页。

| Layout | 结构 | 典型用途 |
|---|---|---|
| Title + Hero | 标题 + 中央核心视觉 | 封面、章节页、核心结论 |
| Title + Key Message | 标题 + 一句话结论 + 视觉 | Executive Summary |
| Big Number | 大数字 + 解释文字 | KPI、成果、规模、增长 |
| Quote / Statement | 大号核心观点 + 来源/说明 | 管理层观点、客户声音 |
| Full-width Visual | 全宽图表 / 图片 / Diagram | 核心发现、案例 |
| Text + Highlight | 文字 + 局部高亮 | 核心洞察 |

---

## 2. 上下结构

用于普通汇报页、咨询报告结论→证据链、数据分析。

| Layout | 结构 | 典型用途 |
|---|---|---|
| Title → Content | 标题 → 主体 | 普通汇报页 |
| Title → Insight → Evidence | 结论 → 证据 | 咨询报告常用 |
| Title → Chart → Takeaway | 图表 → 结论 | 数据分析 |
| Title → Process | 标题 → 流程图 | 方法论、流程 |
| Title → Before / After | 上下 Before / After | 转型、改进 |
| Title → Timeline | 时间轴 | Roadmap、项目历程 |

---

## 3. 左右结构

用于对比、双信息并列、主+补、问题+方案。

| Layout | 结构 | 典型用途 |
|---|---|---|
| 50 / 50 Split | 左右各 50% | 对比、两类信息 |
| 60 / 40 Split | 左 60% + 右 40% | 主内容 + 补充信息 |
| 40 / 60 Split | 左 40% + 右 60% | 结论 + 大图表 |
| Text + Chart | 左文字 + 右图表 | 分析结论 |
| Chart + Commentary | 左图表 + 右解释 | 数据汇报 |
| Problem + Solution | 左问题 + 右方案 | 咨询方案 |
| Current + Target | 左现状 + 右目标 | 转型规划 |
| Internal + External | 左内部 + 右外部 | 内外部分析 |

| Hub + Cards | 中心主题 + 周围模块 | 能力地图 |

## 6. 矩阵结构

用于优先级、定位、分类、Gap 分析、组合管理。

| Layout | 结构 | 典型用途 |
|---|---|---|
| 2×2 Matrix | X × Y | 优先级、定位、分类 |
| 3×3 Matrix | 三维等级 | 能力成熟度、机会分析 |
| Heatmap | 行 × 列 + 强弱 | 风险、能力、场景 |

| Impact × Effort | 影响 × 投入 | 优先级 |

| Layout | 结构 | 典型用途 |

## 选择流程（5 步决策）

1. **判断核心信息类型**：观点 / 流程 / 对比 / 分类 / 时间 / 数据？
2. **判断内容块数量**：1 块 / 2 块 / 3-5 块 / 矩阵？
3. **判断主从关系**：并列 / 主次 / 因果 / 递进？
4. **在上表中匹配 Layout**：优先用最简洁的表达，不要硬上复杂布局。
5. **落到代码**：参照 SKILL.md 主体的字号 / 间距 / 配色规则实现。

## 避免的常见错误

- **一页讲 5 件事**：内容塞不下就拆页；不要把 4×4 矩阵塞到 50/50 Split 里。
- **结构选错**：把"因果"画成"并列"、把"时间"画成"矩阵"——表达力立刻坍塌。
- **同套 PPT 全用一种 Layout**：20 页里至少 4-5 种布局搭配，否则视觉疲劳。
- **忽略留白**：每页至少 0.5" 边距，内容块之间 0.3"-0.5"。
