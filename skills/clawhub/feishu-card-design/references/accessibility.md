# 飞书卡片可访问性与国际化

> **版本**：1.0.4 | **本文件作用**：定义卡片可访问性（无障碍）+ 国际化（多语言）规范
> **目标**：让视障用户、海外用户、不同语言用户都能正常使用卡片

---

## 1. 可访问性原则

### 1.1 WCAG 2.1 AA 标准

飞书卡片应满足 WCAG 2.1 AA 级标准：

- **1.4.3 对比度**：文字与背景色对比度 ≥ 4.5:1
- **1.4.11 非文字对比度**：UI 组件对比度 ≥ 3:1
- **2.1.1 键盘可访问**：所有操作可用键盘完成
- **2.4.4 链接目的**：链接文本明确目的
- **3.3.2 标签清晰**：表单字段有清晰标签

### 1.2 飞书卡片特殊考虑

- 视障用户使用屏幕阅读器读卡片内容
- 色盲用户无法区分红绿色块
- 老年用户需要更大字号
- 移动端单手操作需要大按钮

---

## 2. 对比度检查

### 2.1 推荐配色对比度

| 背景 | 文字色 | 对比度 | 评价 |
|------|--------|--------|------|
| `blue-50` (#F0F4FF) | 黑色 (#000000) | 19.6:1 | ✅ 优秀 |
| `turquoise-50` (#E2F8F5) | 黑色 | 19.0:1 | ✅ 优秀 |
| `yellow-50` (#FBF4DF) | 黑色 | 18.5:1 | ✅ 优秀 |
| `grey-50` (#f5f6f7) | 黑色 | 19.3:1 | ✅ 优秀 |
| `green-50` (#E4FAE1) | 黑色 | 19.0:1 | ✅ 优秀 |
| `red-50` (#FEF0F0) | 黑色 | 19.5:1 | ✅ 优秀 |

**结论**：所有 `*-50` 系列背景色与黑色文字对比度都 ≥ 4.5:1，符合 WCAG AA 标准。

### 2.2 禁止配色

| 背景 | 文字色 | 对比度 | 评价 |
|------|--------|--------|------|
| `blue-50` | 白色 (#FFFFFF) | 1.3:1 | ❌ 不达标 |
| `grey-50` | 浅灰色 | 1.5:1 | ❌ 不达标 |
| 任何 `*-50` | 任何 `*-50` | < 2:1 | ❌ 不达标 |

**规则**：所有 `*-50` 系列背景必须配黑色文字（默认）。

## 3. 色盲友好设计

### 3.1 色盲类型

| 类型 | 占比 | 不能区分 |
|------|------|---------|
| 红绿色盲（红色盲） | 1% 男 | 红色 |
| 红绿色盲（绿色盲） | 6% 男 | 绿色 |
| 蓝黄色盲 | 0.01% | 蓝黄 |
| 全色盲 | 0.005% | 所有颜色 |

### 3.2 色盲友好策略

#### 策略 1：颜色 + 图标双重编码

不要只用颜色传达信息，配合 emoji 或图标：

```json
// ✅ 推荐：颜色 + emoji
{
  "background_style": "red-50",
  "elements": [{"tag": "markdown", "content": "🚨 **告警**：MOC 缺失"}]
}

// ✅ 推荐：颜色 + emoji
{
  "background_style": "green-50",
  "elements": [{"tag": "markdown", "content": "✅ **成功**：检查通过"}]
}

// ❌ 禁止：仅用颜色
{
  "background_style": "red-50",
  "elements": [{"tag": "markdown", "content": "**告警**：MOC 缺失"}]
}
```

#### 策略 2：避免红绿对比

红绿色盲无法区分 red-50 和 green-50，因此：

- ❌ 不要在同一张卡片同时使用 red-50 和 green-50
- ✅ 用 red-50 + yellow-50 或 green-50 + yellow-50 代替

#### 策略 3：文字明确说明

在文字中明确说明状态，不依赖颜色：

```json
{
  "tag": "markdown",
  "content": "**状态**：❌ 失败（需立即修复）\n\n**当前评分**：54 分（C 级）"
}
```

## 4. 字号与间距

### 4.1 推荐字号

| 元素 | 推荐字号 | 说明 |
|------|---------|------|
| H1 (#) | 20-24px | 标题，每个 column_set 最多 1 个 |
| H2 (##) | 16-18px | 二级标题 |
| H3 (###) | 14-16px | 三级标题（推荐） |
| 正文 | 14px | 默认字号 |
| 小字 | 12px | footer markdown 引用（`>` 开头）|

### 4.2 老年用户友好

为老年用户考虑（视力衰退）：
- 正文不小于 14px
- 重要信息用 H3 (###) 而非纯文字
- 关键数字加粗 `**30** 篇归档`
- 行间距足够（默认 padding 即可）

### 4.3 间距规范

| 元素 | 推荐 padding |
|------|-------------|
| column_set | `10px 12px`（上下 10px，左右 12px） |
| body | `16px 16px 16px 16px` |
| button 之间 | 默认间距（无特殊设置） |
| hr 上下 | 默认间距 |

## 5. 屏幕阅读器友好

### 5.1 语义化结构

屏幕阅读器按 DOM 顺序读取，因此：
- 标题用 `#`/`##`/`###`（屏幕阅读器可识别为标题）
- 列表用 `-` 或 `1.`（屏幕阅读器可识别为列表）
- 引用用 `>`（屏幕阅读器可识别为引用）

### 5.2 避免纯视觉信息

```json
// ❌ 禁止：仅靠颜色区分
{
  "tag": "markdown",
  "content": "🔴 红色项目需立即处理\n🟢 绿色项目可延后"
}

// ✅ 推荐：颜色 + 文字
{
  "tag": "markdown",
  "content": "**🔴 立即处理**：MOC 缺失\n**🟢 可延后**：日志格式优化"
}
```

### 5.3 按钮文本明确

```json
// ✅ 推荐：明确动作
{
  "tag": "button",
  "text": {"tag": "plain_text", "content": "📄 查看完整云文档"}
}

// ❌ 禁止：模糊动作
{
  "tag": "button",
  "text": {"tag": "plain_text", "content": "点击这里"}
}
```

## 6. 国际化（i18n）

### 6.1 多语言策略

| 场景 | 推荐策略 |
|------|---------|
| 国内团队 | 中文（默认） |
| 跨国团队 | 中英双语 |
| 海外团队 | 英文（单独版本） |

### 6.2 中英双语示例

```json
{
  "header": {
    "title": {"tag": "plain_text", "content": "20260719-Daily Report-30 archived-18 atoms-1 seed"},
    "subtitle": {"tag": "plain_text", "content": "2026-07-19 · Mining + Value Index"},
    "template": "turquoise"
  },
  "body": {
    "elements": [
      {
        "tag": "column_set",
        "background_style": "turquoise-50",
        "columns": [{
          "tag": "column",
          "background_style": "turquoise-50",
          "elements": [{
            "tag": "markdown",
            "content": "### 📦 Archive Summary\n\n- New archives: 30 articles\n- Atoms extracted: 18\n- Main seed: 1"
          }]
        }]
      }
    ]
  }
}
```

### 6.3 翻译要点

| 中文 | 英文 | 注意 |
|------|------|------|
| 存量日报 | Daily Stock Report | "Stock" 在英文有"股票"歧义，可改 "Inventory Report" |
| 增量日报 | Daily Flow Report | "Flow" 表达"增量" |
| 行动清单 | Action List | 直译即可 |
| 健康报告 | Health Report | 直译即可 |
| 周报 | Weekly Review | 用 Review 而非 Report（更主动） |
| 月报 | Monthly Report | 直译即可 |
| 主种子 | Main Seed | 直译即可 |
| Atoms | Atoms | 保留英文（已是术语） |
| Concept | Concept | 保留英文（已是术语） |

### 6.4 日期格式

| 语言 | 日期格式 | 示例 |
|------|---------|------|
| 中文 | YYYYMMDD | 20260719 |
| 英文 | YYYY-MM-DD | 2026-07-19 |
| 国际 | YYYY-MM-DD | 2026-07-19 |

**注意**：标题中的日期保持 `YYYYMMDD` 紧凑格式（节省宽度），subtitle 中用 `YYYY-MM-DD` 标准格式。

## 7. 文化敏感性

### 7.1 Emoji 文化差异

| Emoji | 中文含义 | 英文含义 | 注意 |
|-------|---------|---------|------|
| 🚨 | 告警 | Alert | 通用 |
| ✅ | 通过 | Pass | 通用 |
| ❌ | 失败 | Fail | 通用 |
| ⚡ | 亮点 | Lightning | 通用 |
| 🎯 | 目标 | Target | 通用 |
| 📊 | 统计 | Chart | 通用 |
| 🤖 | 机器人 | Robot | 通用 |
| 🌱 | 发芽 | Sprout | 海外可能不熟 |
| 📦 | 包裹 | Package | 通用 |

### 7.2 颜色文化差异

| 颜色 | 中文含义 | 英文含义 | 注意 |
|------|---------|---------|------|
| 红色 | 告警/喜庆 | 告警/危险 | 西方红色仅告警 |
| 绿色 | 成功/安全 | 成功/Go | 通用 |
| 黄色 | 亮点/警告 | 亮点/Caution | 通用 |
| 蓝色 | 主推/信息 | 信息/专业 | 通用 |
| 紫色 | 高贵/趋势 | 高贵/创意 | 通用 |

## 8. 可访问性自检清单

- [ ] 所有 `*-50` 背景色配黑色文字
- [ ] 颜色 + emoji 双重编码信息
- [ ] 不在同一张卡片同时使用 red-50 和 green-50
- [ ] 按钮文本明确动作（"查看文档"而非"点击"）
- [ ] 标题用 `#`/`##`/`###`（屏幕阅读器友好）
- [ ] 列表用 `-` 或 `1.`（屏幕阅读器友好）
- [ ] 正文不小于 14px
- [ ] 关键数字加粗
- [ ] subtitle 中用 `YYYY-MM-DD` 标准日期格式
- [ ] 海外用户多的场景提供英文版
