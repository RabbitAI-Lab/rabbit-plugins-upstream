## Description:

Provides information about Agiexa's planned Google Sheets integration for Shopify, including previewed workflows and an optional waitlist.

This skill is ready for commercial/non-commercial use.

## Use Case:

Merchants and store owners use this skill to learn about Agiexa's planned Google Sheets and Shopify workflows and how to request a waitlist signup. The documented tools and triggers are preview features and cannot be used before launch.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The documented Google Sheets and Shopify tools and triggers are preview features and cannot be called before Agiexa launches.

Mitigation: Describe them as planned capabilities, check current availability, and do not promise or attempt automation before launch.

Risk: Joining the waitlist sends an email and role to Agiexa, and may also send an optional link or message; the security review says privacy wording needs clarification.

Mitigation: Obtain explicit consent before submission, confirm the fields being sent, omit optional details unless supplied by the user, and advise against including sensitive information.

Risk: Publisher security claims in the skill have not been independently verified.

Mitigation: Attribute security statements to Agiexa and avoid presenting them as independently verified facts.
