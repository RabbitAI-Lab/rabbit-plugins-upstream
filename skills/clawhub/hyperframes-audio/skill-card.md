## Description:

HyperFrames Audio guides agents in mixing already placed HyperFrames audio tracks, including fades, crossfades, track gain, automation, ducking or voiceover carve, and effect chains for EQ, dynamics, saturation, delay, reverb, chorus, phaser, and bitcrush.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and content automation agents use this skill to adjust HyperFrames audio mixes after media has already been placed in a composition. It helps author fades, crossfades, gain staging, automation, voiceover carve, and Web Audio effect chains while keeping sourcing and clip timing outside its scope.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The carve workflow can overwrite data-fx-carve, data-fx-chain, and data-automation attributes in a HyperFrames composition file.

Mitigation: Run with --dry-run first and keep the composition under version control or backed up before applying changes.

Risk: Incorrect attribute quoting or manually tagging effects with fromCarve can cause existing work to be missed or replaced on the next carve.

Mitigation: Follow the documented double-quoted attribute format and reserve fromCarve for nodes generated by the carve workflow.
