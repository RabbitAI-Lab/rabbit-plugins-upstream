## Description: <br>
SuperDesign provides frontend design guidelines for building modern landing pages, dashboards, and user interfaces. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

### License/Terms of Use: <br>


## Use Case: <br>
Developers and agents use SuperDesign when creating frontend UI components, landing pages, and dashboards that need layout planning, theming, animation guidance, and accessibility checks. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated frontend HTML may include third-party CDN scripts or unpinned latest dependencies. <br>
Mitigation: Review, approve, and pin external scripts and libraries before shipping production code. <br>
Risk: Generated prototypes may reference external image services or placeholder assets. <br>
Mitigation: Replace placeholders with approved assets and verify licensing, privacy, and availability before production use. <br>
