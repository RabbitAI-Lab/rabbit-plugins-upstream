## Description:

Guides agents in using GPT Image 2.6 on varg, including model choices, image settings, costs, API calls, and prompt recipes for posters, infographics, prints, character sheets, and storyboards.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

## Use Case:

Developers and creative professionals can use this guide to choose GPT Image 2.6 settings, prepare prompts, estimate costs, and generate or edit images through varg. It covers text-heavy layouts such as posters, infographics, travel prints, character sheets, and storyboards.

### Deployment Geography for Use:

Global
