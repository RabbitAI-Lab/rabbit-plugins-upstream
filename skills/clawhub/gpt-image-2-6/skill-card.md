## Description:

Provides guidance for using GPT Image 2.6 on varg, including model selection, image sizing, cost estimation, and prompts for common visual layouts.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and other agent users use this guide to prepare and estimate GPT Image 2.6 image generation or editing requests through varg. It also helps them choose model settings and review generated text before using an image.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Selected photos are sent to varg and its model providers for processing, and generated outputs may be accessible by public link.

Mitigation: Avoid confidential images until you understand retention and link access.

Risk: Image generation uses paid credits and larger or higher-quality requests can cost more.

Mitigation: Set a spending limit and estimate each request before submitting it.
