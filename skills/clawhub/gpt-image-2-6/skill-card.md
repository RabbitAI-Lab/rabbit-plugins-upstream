## Description:

Provides guidance and prompt recipes for using GPT Image 2.6 on varg, including model selection, settings, sizing, pricing, image edits, and troubleshooting.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and creators use this guide to choose GPT Image 2.6 settings and build image-generation or editing prompts for posters, infographics, prints, character sheets, and storyboards.
