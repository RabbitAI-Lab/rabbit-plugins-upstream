# 嵌入式代码生成器（1.1.0）

**15 类量产级 C 代码模板，复制即用，测试背书。** PI控制器/RS485收发切换/低通滤波/CRC校验/环形缓冲区/SVPWM/软件I2C主机/SPI主机/ADC均值滤波/有限状态机框架/DMA环形接收缓冲/软件定时器/命令行shell/轻量断言框架/按键扫描消抖，含 Doxygen 注释、参数校验、错误处理。

**为什么值得用**：并发/时序敏感的模块（环形缓冲、DMA 追新数据、软件定时器回绕、按键消抖弹跳）自己手写最容易踩坑——这里每个模板都经过 18 个 gcc 测试套件（518 项断言）算法验证 + 静态审查器闭环扫描（0 高危 0 中危），坑已经替你踩过。

> **新增 5 类**：DMA 环形接收缓冲（循环模式不丢包）、软件定时器（回绕安全）、命令行 shell（表驱动解析）、轻量断言框架（量产不停机故障记录）、按键扫描消抖（长短按+连按自动重复）。全部 15 类免费开放。

> 这是一个跨平台的 **Agent Skill（智能体技能）包**，不是独立软件。把它装进任意支持「Agent Skills / 技能」标准的 AI 助手（如 Claude Code、扣子Coze、Cursor、各类兼容Agent平台），AI 就能在对话中自动调用它。

---

## 包内容
- `SKILL.md` —— 技能说明书（AI 读这个来决定何时、如何调用）
- `templates/` —— 15 类模板（.h/.c 文件对，C99、无动态内存、C++ 兼容）
- `tests/` —— 自检测试（18 个测试覆盖全部 15 类模板算法，含 Makefile，`make test` 一键运行）

## 系统要求
- 无需任何第三方库；仅运行自检测试需要 gcc（支持 C99 即可），直接复制模板则零依赖

## 安装方法

### 方式一：在支持的 Agent 平台里导入
- **扣子 Coze**：技能/技能草稿 → 上传技能 → 选择本 zip（或解压后的文件夹）→ 发布到「我的技能」
- **Claude Code / Cursor 等**：把解压后的整个文件夹放进 Agent 的 skills 目录（各平台位置见其文档，通常为 `~/.claude/skills/` 或工作区 `.skills/`），重启会话即可
- **其它兼容 Agent Skills 标准的平台**：导入 zip 或把文件夹加入技能目录，平台识别到 `SKILL.md` 即自动加载

### 方式二：当现成代码库直接用（不需要任何 AI）

```
# 无需任何运行步骤；把 templates/ 下对应的 .h/.c 复制进工程即可
```

## 使用
装好后，直接用自然语言跟 AI 说需求即可，例如：「给我一个环形缓冲区的C代码」。
AI 会自动读取 SKILL.md 并调用脚本，你无需记命令。

## 自检测试

包内附带 `tests/` 目录回环自检，可验证核心模板算法正确性。在包根目录执行：

```
make test
```

- 环境要求：gcc（支持 C99 即可），无其他依赖
- 覆盖全部 15 类模板：CRC-8/MAXIM、CRC-16/MODBUS、CRC-16/CCITT-FALSE（位翻转 + 查表两种编译配置）、Modbus RTU 标准帧；环形缓冲区 FIFO 顺序、满缓冲 REJECT/OVERWRITE 两种策略、空/满边界与参数校验；软件 I2C 位级从机模拟（START/ACK/WriteThenRead/时钟拉伸）；SPI 四种模式边沿精确采样与全双工回环；ADC 基本均值与去极值均值（满量程累加防溢出）；FSM 表驱动转移、守卫链、on_entry/on_exit 时序；DMA 环形缓冲回绕/追圈重同步/drain 模式；软件定时器单次/周期/Stop重启/回调自停/uint32 回绕精确触发；shell argc/argv 切分/CRLF 剥离/负值透传/reply 截断保护；断言故障记录/池满覆盖/复位钩子分支；按键扫描按下/释放双侧消抖、弹跳拒绝、长按单次+连调节奏、跨回绕精确触发、双键独立、高低有效两种极性各编译一套
- 预期输出：518 项断言全部 `[PASS]`，末尾 `=== ALL TESTS PASSED ===`，编译零警告；任一断言失败时 `make` 返回非 0
- `make clean` 清理编译产物

## 兼容性说明
- 所有模板为**纯 C99**，不依赖外部库，无需动态内存分配（不使用 malloc/free）、不联网、不消耗 AI 额度。
- 已在 gcc 13+（C99）实测通过；不依赖特定操作系统（Windows / macOS / Linux 均可）。
- 各平台导入入口名称略有差异，但包结构（SKILL.md + 模板）是开放标准，通用。
