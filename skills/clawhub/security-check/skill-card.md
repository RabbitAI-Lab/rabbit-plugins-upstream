## Description:

Submits an authorized web app or API domain to Rheono for a read-only security check and an emailed report.

This skill is ready for commercial/non-commercial use.

## Publisher:

[samir-abis](https://clawhub.ai/user/samir-abis)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and site owners use this skill to request a security check for a web app or API they own or are authorized to test. Rheono emails the report to the address they provide.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Submitting an unauthorized target can initiate probes of someone else's live site or API.

Mitigation: Require the user to confirm ownership or testing authorization before submitting the domain.

Risk: The target domain and report email address are shared with Rheono.

Mitigation: Tell the user what will be sent and proceed only if they are comfortable sharing both details.
