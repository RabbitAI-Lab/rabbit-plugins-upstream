## Description: <br>
Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
API developers, backend teams, developer-experience teams, and maintainers use this skill to turn REST API documentation requests into practical OpenAPI or Swagger artifacts, workflows, checklists, implementation support, and validation notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad activation wording may select this skill for ambiguous software-data prompts. <br>
Mitigation: Clarify the user's API documentation goal before producing artifacts when the request is ambiguous or outside OpenAPI and Swagger work. <br>
