# 片段类型：衔接

## 原文片段

Data import was managed with the rio package (Becker et al., 2024), and data wrangling was performed using the tidyverse suite (Wickham & RStudio Team, 2023). The primary effect sizes (correlations with survey weights) were calculated using the wCorr package (Sikali et al., 2023). All main meta-analyses and graphics were conducted using the metafor package (Viechtbauer, 2025), with figures optimized for vector graphics via svglite (Wickham et al., 2025). The umbrella reviews were performed utilizing the specialized metaumbrella package (Gosling et al., 2025). Benjamini–Hochberg (BH)-adjusted p values were computed using the base R package stats (R Core Team, n.d.).

## 来源文献

Díaz-Guerra et al., 2026, Journal of Personality and Social Psychology
