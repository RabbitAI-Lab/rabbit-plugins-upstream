# 心理学实证论文 Method 部分「衔接与连贯维度」检查清单

> 标准依据：《Science Research Writing》(2nd ed.) §2.4.2 的八组时序衔接词汇（Group 1–8）、因果—目的连接词、对比连接词，以及 Generic Methods Model 的六模块叙事逻辑；正例惯例来自 JPSP / JEP:G / Developmental Psychology / PSPB 等顶刊实证论文的衔接方式。

## 一、时序衔接准确性

### 1.1 时间参照点（Group 1：实验/观察开始之前）

- [ ] 描述实验前既有状态或预备条件时使用「先前」类词汇：prior to、previously、beforehand、in advance、earlier、formerly、originally
- [ ] 引用同一研究系列前一实验时使用 prior study / earlier experiment / previous work 等回指
- [ ] 预备环节（知情同意、人口学、预筛问卷）作为时间锚点放在程序叙述的最前端

### 1.2 起首步骤（Group 2：实验或描述的第一步）

- [ ] 程序总起句明确「第一步是什么」，常用 first、firstly、at first、at the beginning、to begin with、initially
- [ ] 系列实验的复用句式一致（如「Materials and procedures were identical to Study X, with the following changes」）
- [ ] 程序段落的开篇即给出时间锚点，不写「我们做了某个实验」式的零起点

### 1.3 步骤顺序（Group 3：流程与步骤）

- [ ] 步骤严格按实际执行的时间顺序排列，不预先讲述结论或后置步骤
- [ ] 多步骤程序显式编号（First / Second / Third / Fourth / Lastly）或分阶段命名（Phase 1 / Step 1 / Stage A）
- [ ] 步骤衔接使用精确序列词：then、next、followed by、following、subsequently、afterwards、secondly，而非仅靠「然后」类口语词
- [ ] 多步骤分析方案每步以目的状语（to + verb）起句，使步骤与目的显式对应（Verhoef / Damian 五步链样板）

### 1.4 短时距（Group 4：事件间隔很短）

- [ ] 描述快速衔接的事件时使用 shortly after、soon、quickly、immediately after
- [ ] 程序中相邻操作的时间窗（如 24 hr between sessions、48 hr–72 hr after）显式标注
- [ ] 短时距与长时距不混用同一时间副词，避免「soon / later」滥用

### 1.5 后段/长时距（Group 5：序列后段或较长间隔）

- [ ] 描述相对靠后的阶段使用 later、later on、eventually、towards the end、in due course
- [ ] 跨波次研究给出绝对天数与相对间隔（132 days after T0; 34 days after T1）
- [ ] 长期时间线在每个时点重申相对位置（Thielmann 多波次样板）

### 1.6 同时性/接口（Group 6：两事件同时或刚好衔接）

- [ ] 两操作并发或前后紧接时使用 simultaneously、at the same time、meanwhile、in the meantime、while、when
- [ ] 表达「A 紧接着 B」时使用 as soon as、immediately、directly、instantly、straight away、at once、at that point
- [ ] 一事件结束恰好为另一事件开始时用 until / once 标识转换点
- [ ] 同时发生事件可附带因果暗示时显式标注因果（when / while → as）

### 1.7 收尾步骤（Group 7：最后一步/序列末端）

- [ ] 程序末尾步骤用 finally、lastly、in the end、at the end 显式收束
- [ ] 最终样本、最终数据集、最终得分在收尾处给出（Hence, the final sample was... / Therefore, ...）
- [ ] 多阶段流程结束时给总时长或总次数（10 sessions in total / averaged across five waves）

### 1.8 后续延伸（Group 8：实验/观察结束之后）

- [ ] 实验结束后追加动作（事后说明、再次测量、随访）使用 afterwards、subsequently
- [ ] 后续追加内容与主干程序明确区分（Olaru「beyond the scope of the current investigation」式标注）

### 1.9 刺激/材料时序的可复现性

- [ ] 视频/音频等动态刺激的每一拍标注精确秒数（1 s / 2 s / 1 min），时间轴完整连贯（Thiele 十一秒视频模板）
- [ ] 改编范式用 (a)/(b)/(c)/(d) 或子步骤嵌套呈现，每子步骤时长与衔接规则（If the toddler cried...）一并交代
- [ ] 程序性应急规则（If X happened, then Y）以条件句形式嵌入时序链

## 二、段落过渡自然性

### 2.1 段首句与总-分结构

- [ ] 每段以段落入口句（paragraph-entry sentence）开场，先立焦点再填充细节
- [ ] 段落入口句常用起首短语：First / Next / In addition / Beyond... / Building on the established measurement model / We then provided...
- [ ] 段落入口句与前一段内容存在显式衔接（原因—结果、整体—局部、对照—补充），不孤立起句
- [ ] 大段开头给出主题句后，段内严格按 general → specific 顺序展开

### 2.2 跨段递进连接

- [ ] 跨段使用显式递进词：Next、Following this、Subsequently、Then、Building on...
- [ ] 跨段使用对比/补充连接：In contrast、Conversely、Further、Additionally、Beyond...
- [ ] 跨段使用回指总括：Hence、Therefore、In summary、Summarizing the major results
- [ ] 跨段使用结构提示：As in Studies 1–3、Comparable to Study X、Building on the established measurement model

### 2.3 段落间的逻辑承接（转折 / 因果 / 让步）

- [ ] 转折关系显式标注（However、Nevertheless、Yet、Although、Whereas、By contrast），不靠读者脑补
- [ ] 让步-转折链完整：Although X → nevertheless Y → As such, we supplemented Z（Phillips 单题→多题补充样板）
- [ ] 因果链显式：Because A → Therefore B / Hence B；或 As a result、Consequently、Thus、Accordingly
- [ ] 取舍论证显式：While X 提供 Y, Z was chosen for...（Benítez-Agudelo 单题选择样板）
- [ ] 假设-推导链：先重述假设（in such a way that...）→ 图示 → step-by-step 推导（Urban 样板）

### 2.4 段落内的衔接颗粒度

- [ ] 段内句间衔接不依赖读者脑补：每句都能从上一句或段落入口句推出
- [ ] 段内避免「罗列式无连接」的多句堆砌（连续 5 句以句号断开而无任何衔接词）
- [ ] 段内使用最小化承接词：Thus、Specifically、In all cases、Most of the tests、Moreover
- [ ] 段内同一概念使用一致术语，无中途更换同义表达造成断裂

### 2.5 跨段落主题切换

- [ ] 主题切换前显式过渡：Beyonds the facial stimuli that were used, two conversation topics were developed（Petsko 样板）
- [ ] 从方法描述切换到理论解释时显式标注：This procedure is based on research finding that...（Vail 样板）
- [ ] 从结果描述切换到结果解释时显式标注：Accordingly / This means that / As a result

### 2.6 图/表/公式的衔接

- [ ] 图表/公式出现处使用引导短语：Figure 2 illustrates / Table 4 details / as shown in Figure 1, Panel A / Eq. (1)
- [ ] 引导句包含「图/表内容概括 + 阅读指引」，避免仅写「(see Figure 1)」
- [ ] 图与表分工明确（路径系数归 Figure 2，假设检验汇总归 Table 4），避免重复
- [ ] 图/表编号与正文叙述顺序一致（图 1 在图 2 之前被引用）

## 三、模块间逻辑连贯性

### 3.1 Methods 整体结构的六模块逻辑（Generic Methods Model）

- [ ] Method 起首为研究概述句，重述研究目标/缺口（restate the aim/gap from the Introduction）
- [ ] 概述后给出材料的来源（were obtained from / were a kind gift from）
- [ ] 提供材料/方法的细节 + 理由 + 严谨性证据（in order to / with the aim of / tightly / precisely）
- [ ] 必要时描述图/表的内容与解读
- [ ] 与既有方法比较：完全相同（as described by）/ 相似（adapted from）/ 显著不同（unlike / instead of），并说明差异意义
- [ ] 必要时给出现有方法背景（用一般现在时）+ 选择理由
- [ ] 局限/问题首次出现即提及，并使用最小化措辞（slightly、negligible、minimal）

### 3.2 子模块间过渡（Participants / Measures / Procedure / Analysis）

- [ ] Participants → Design/Measures：先介绍样本，再说明样本如何被分配到条件
- [ ] Measures → Procedure：测量顺序与程序时间窗口匹配（如果程序先于测量，先讲程序）
- [ ] Procedure → Analysis：分析方案与程序产出（变量类型、数据结构）一致
- [ ] 子模块标题命名符合目标期刊惯例，避免自定义标签打乱节奏

### 3.3 分析方案内部衔接

- [ ] 分析方案总览段以「We first / We then / We used / Lastly」四步或五步概括三步骤以上分析
- [ ] 每步分析以目的状语开头：to distinguish / to examine / to test / to control for / to scrutinize
- [ ] 分析步骤与前言假设一一对应（Verhoef 五步 / Damian 五步样板）
- [ ] 括号内即时标注例外与口径（only measured with one item / social satisfaction was only...）
- [ ] 软件/包引用随分析步骤一并交代（metafor / Mplus / tidyverse），不集中堆放
- [ ] 总览段尾预留与详细段的对接（We provide a more detailed description of each of these steps below.）

### 3.4 排除/筛选漏斗的衔接

- [ ] 排除流程按时间漏斗顺序：起始样本 → 逐条限制 → 每步人数与理由 → 最终样本
- [ ] 每步排除使用显式时序词：Initially → However → Afterward → Then → Finally → Hence
- [ ] 每步排除理由具名（less than 18 years old / failed attention checks / < 80% survey completion / Mahalanobis & Cook's distances）
- [ ] 排除人数明确（50 / 116 / 69 / 5），与各步骤理由一一对应
- [ ] 选择效应自查：识别潜在偏差来源 → 推断后果 → 引出对照检验 → 量化比较（van Scheppingen 样板）

### 3.5 系列实验/多研究的模块间衔接

- [ ] 系列实验描述采用「基线 + 差异清单」结构：Materials and procedures were identical to Study X, with the following changes
- [ ] 每条差异以 First / Second / Third 编号，并附改动动机（neutralize gender cues / add control condition）
- [ ] 跨研究复用元素显式回指：on similar 11-point scales as in Experiments 1a–1c / as described above
- [ ] 跨研究样本口径一致（As in Studies 1–c），避免重新定义
- [ ] 多研究间分析策略一致（pre-registered analysis plan / same analytic pipeline）

### 3.6 控制变量与对照条件的衔接

- [ ] 每个控制变量的入选都附理由：To control for the possibility that / Although…does not predict…so we included it
- [ ] 控制变量与可能混淆源一一对应，不孤立列出（Landis 混淆源清单样板）
- [ ] 操纵检验与因变量的角色关系显式标注：As a manipulation check, we assessed...（Kteily 样板）
- [ ] 控制条件与实验条件在句法上平行呈现：whereas / a parallel question / similar procedure（Zhou 样板）

### 3.7 测量决策链的衔接

- [ ] 测量工具介绍按「工具来源（含链接）→ 任务构成 → 效度证据 → 计分规则 → 信度」顺序推进
- [ ] 既有工具与改编工具的关系标注：adapted from / a (modified) version of / revised version of
- [ ] 改编透明：改编后的条目原文/锚点/反向计分说明完整给出
- [ ] 单题/多题测量取舍论证完整：Although single-item → nevertheless reliance → As such, supplemented → Further, another gap → 再补充（Phillips 样板）
- [ ] 同一构念的多版本（不同版本刺激 / 多种人格问卷）作为内部复制因素显式声明（Petsko 话题样板）

## 四、指代与承接清晰性

### 4.1 代词的先行项明确

- [ ] 首次引入术语时即给缩写与全称：henceforth also referred to as the target person / hereafter referred to as X
- [ ] 跨段落指代同一概念时使用一致术语，不中途切换近义表达（避免 participants / subjects / individuals 混用造成指代断裂）
- [ ] 代词 it / they / this 的先行项在本句或上一句明确可定位
- [ ] 多义词在上下文中通过同位语/of-短语明确化（the actor / the listener / the speaker）

### 4.2 符号体系的一致性

- [ ] 路径分析/中介模型使用稳定的 X / M / Y 符号，三符号在叙述中前后一致（Haider 样板）
- [ ] 数学符号 λ / β / Δ 等与文字描述双向对应（March 细菌生长曲线样板）
- [ ] 缩写首次出现给全称，后续段落直接用缩写不重复展开
- [ ] 同一变量在不同模块使用同一名称（如 SES / control beliefs），不切换成 income / cognitive control

### 4.3 引用位置的承接

- [ ] 引用 reference 紧跟所归属的方法/语句处（X et al., 2010 直接接在 adapted from X et al. 之后），不全部堆放句末
- [ ] 引用格式符合目标期刊（作者-年份制 vs 编号制）
- [ ] 方法描述与既有文献关系明确三分：完全相同（as described by/in）/ 相似（adapted from）/ 显著不同（unlike, instead of），并说明差异意义
- [ ] 改编/调整的具体差异点显式列出：with the following modifications / except for / with some changes
- [ ] 引用既承担「定位出处」又承担「承认前人贡献」，避免单一堆叠造成归属不清

### 4.4 跨章节交叉引用

- [ ] 测量用途指向具体分析章节：partners' responses... (see discriminant analyses section) / (see alternative explanations section)（Park 样板）
- [ ] 程序中嵌入的指导语原文化呈现并清晰标注（adapted from Cikara et al., 2014）
- [ ] Analysis 部分对 Measures / Procedure 的引用回到具体子模块名称，不使用「上述方法」的模糊指代
- [ ] Supplemental Materials 在正文 Method 中显式引用（details are given in the online supplemental materials）

### 4.5 跨实验/跨研究的指代衔接

- [ ] 系列实验中复用材料/程序以回指短语承接：as in Experiments 1a–1c / as described above / using the same measures
- [ ] 跨研究复用样本以回指短语承接：the final sample of Study 3 / as in Studies 1–c
- [ ] 系列实验的变量命名、缩写、量表锚点完全一致，不为每个实验重新定义

### 4.6 句法层面的承接

- [ ] 长句首部与前句尾部在指代上衔接（前一动作 → 紧随的目的 / 结果 / 对象）
- [ ] where / which / that 引导的定语从句的先行词在前句清晰可定位
- [ ] 介词短语 of / with / for 的链式嵌套不超过三层，避免指代断裂
- [ ] 数据呈现（n = / α = / M = SD =）与所修饰变量在同一句内直连，不分散到多个独立短句
- [ ] 表格/图中的变量名与正文叙述使用同一全称或同一缩写

### 4.7 综述与决策的承接

- [ ] 综述既有方法时使用综述连接词：have shown / documented / previously reported / found that
- [ ] 由综述衔接到本研究选择时显式标注：However / Nevertheless / As such / Therefore / Based on...
- [ ] 决策取舍的两端都给出（A 的优势 → 但 A 的不足 → 因此选 B），不单向陈述（Benítez-Agudelo / van Scheppingen 样板）
- [ ] 「本研究的目的」与「前人未解决的问题」显式绑定（Our aim was to address this gap by...）
