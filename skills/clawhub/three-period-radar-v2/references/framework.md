## 1. 趋势八态与判定规则

对每个周期（月/周/日）用同一套规则分类（脚本 `classify_period` 已实现）：

| 状态 | 条件（收盘价/MA5/MA10 + MACD） |
|---|---|
| 强势多头 | 价>MA5>MA10 且 DIF>DEA 且 DIF>0 |
| 多头 | 价>MA5>MA10 且 DIF>DEA（DIF 未上零轴） |
| 偏多 | 价>MA5 且 MA5>MA10，但 MACD 未金叉 |
| 弱多试探 | 价>MA5 但 MA5<MA10（均线即将金叉） |
| 横盘 | 其余过渡态 |
| 偏空 | 价<MA5 且 MA5<MA10，但 MACD 未死叉 |
| 弱空试探 | 价<MA5 但 MA5>MA10（均线即将死叉） |
| 空头 | 价<MA5<MA10 且 DIF<DEA（DIF 未破零轴） |
| 强势空头 | 价<MA5<MA10 且 DIF<DEA 且 DIF<0 |

均线参数：日线 MA5/10/20/60，周线 MA5/10/20，月线 MA3/5/10；MACD 统一 (12,26,9)。周线=日线 resample W-FRI，月线=resample 月末。

## 2. 27 组合的实战策略表

月/周/日各 3 态共 27 种，实战归纳为 8 核心组合 + 横盘组合：

| 月 | 周 | 日 | 场景 | 操作 |
|---|---|---|---|---|
| 涨 | 涨 | 涨 | 三周期共振多 | 重仓持股，让利润奔跑 |
| 涨 | 涨 | 跌 | 大多头回调 | 牛市洗盘，逢低吸纳 |
| 涨 | 跌 | 涨 | 大多头反弹 | 力度有限，谨慎不追高 |
| 涨 | 跌 | 跌 | 大多头调整 | 减仓观望，等周线企稳 |
| 跌 | 涨 | 涨 | 大空头反弹 | 熊市诱多，逢高减仓 |
| 跌 | 涨 | 跌 | 大空头回落 | 反弹结束，空仓 |
| 跌 | 跌 | 涨 | 大空头反抽 | 最弱结构，反弹是逃命机会 |
| 跌 | 跌 | 跌 | 三周期共振空 | 空仓，禁止左侧抄底 |

横盘组合要点：**月线横盘时，谁先打破平衡谁定未来数月方向**——周线是先行指标，日线是触发器。月横+周涨+日涨=底部酝酿（关注月线能否金叉确认）；月横+周跌+日跌=顶部破位（果断离场）。

铁律：大周期管小周期；共振则加速；背离则转折（月周向上+日线暴跌=买点，月周向下+日线暴涨=卖点）；任一周期横盘不重仓。

## 3. 周期转化机制

- 月线=格局层（数月数年才变，几乎无法骗线）；周线=方向层/桥梁；日线=操作层（可骗线，需周线确认）。
- **自上而下**：大周期方向不变时，小周期逆势波动空间被压缩（牛市日线大跌=买点；熊市日线大涨=卖点）。
- **自下而上（反转路径）**：日线先变（苗头期，背离/结构破坏）→ 周线确认（MACD 金叉/死叉，可建仓）→ 月线跟随（定局期，可重仓/清仓）。
- 例：月线 MACD 金叉+DIF 零轴上、周线调整中时，等周线重新金叉即"月线多+周线多+日线回踩"的经典共振买点。

## 4. 趋势反转判断

反转是结构转换过程：原趋势衰竭 → 结构破坏（破趋势线/均线/前低）→ 反向试探 → 确认（回踩不创新低再发力）。

- 最可靠预警：**MACD 顶/底背离**（价创新高/低而 DIF 不创新高/低），辅以量价背离、KDJ/RSI 极值拐头。
- 单周期反转信号假信号率高；可靠反转需多周期共振：日线背离 + 周线 MACD 转向 + 月线走平/转向 = 大级别顶/底。
- 真反转：连续 K 线确认 + 放量 + 颈线突破后回踩不破。假反转：单根 K 线、无量、大周期不配合。

## 5. 买点 checklist 与止损纪律

### 三周期共振买入 checklist（逐项核对，缺一不可）

```
□ 月线：MACD金叉 或 DIF>0且拐头向上
□ 周线：MACD金叉 + MA5>MA10 + 收盘价>MA20
□ 日线：MACD金叉 + 收盘价>MA5>MA10 + 无顶背离
□ 成交量：近5日均量 > 近20日均量 × 1.2
□ 位置：股价处于20日区间上1/3区域
```

**规则**：7个问题全部打勾 → 可以执行；任何一个不打勾 → 不写理由，不交易；写理由超过3行 → 说明你在找借口，不交易。

### 止损铁律

| 情况 | 操作 |
|------|------|
| 日线 MA20 跌破 | 减仓/离场 |
| 周线 MACD 死叉 | 清仓 |
| 单票亏损达-10% | 无条件止损，不写理由 |
| 死叉期总仓位 | ≤30% |
| 单票上限 | ≤15% |

**乖离率安全区**：BIAS(20) 在 ±10% 以内为安全；>+12% 不追高；<-12% 结合 MA60 方向判断。

### checklist_pass（布尔字段，用于准入）

**checklist_pass = True 的条件**（缺一不可）：
1. 月线：MACD金叉 或 (DIF>0 且 DIF>前月DIF)
2. 周线：MACD金叉 + MA5>MA10 + 收盘价>MA20
3. 日线：MACD金叉 + 收盘价>MA5>MA10 + 无顶背离
4. 成交量：近5日均量 > 近20日均量 × 1.2

**用法**：
- checklist_pass=True + 评分≥35 → "推荐"标签
- checklist_pass=False + 评分≥25 → "观察"标签（有潜力但条件不齐）
- checklist_pass=False + 评分<25 → "回避"标签

**核心区别**：评分用来在"通过的票"内部排序；checklist 用来过滤不合格的票。

## 7. 报告模板骨架

1. 汇总表：标的 | 评分 | checklist | 月/周/日状态 | 近20日涨跌 | 核心信号（降序）。
2. 数据截止声明 + 当日盘面修正（如有）。

4. 板块扫描时：ETF 雷达排名 → 梯队划分（可配置/观察/回避）→ 每方向候选龙头观察池（逻辑+触发+止损）。

6. 结尾：一次性免责声明（仅供技术研究，不构成投资建议）。

## 8. 日内层级联动与 K 线形态确认

雷达的月/周/日三周期解决"波段方向与结构"。当用户追问**日内买卖点、分时（60分/30分/15分）、K线形态（伞形线/乌云盖顶/吞没/十字星等）怎么用**时，按本节四层体系回答。

### 8.1 四层职权表

| 层级 | 工具 | 回答的问题 | 职权边界 |
|---|---|---|---|
| ① 方向层 | 月线、周线 | 能不能做、做多做空 | 只定方向和仓位上限，不产出买卖点 |
| ② 操作层 | 日线（均线+MACD趋势状态） | 做不做、何时做 | 产出"许可/禁令"，是开关；用趋势状态而非单次金叉死叉 |
| ③ 执行层 | 60分（定时机）→30/15分（找点位） | 今天什么点位进 | 只在①②同向时启用，不单独决策；60分空头排列=当日不动 |
| ④ 确认层 | K线形态+量能 | 这个点靠不靠谱 | 只对③的点位加减分，无发起权、无否决权 |

记忆口诀：**大周期给方向，均线给结构，MACD给动量，分时给点位，K线形态给临门确认**。层级越低假信号越多，职权必须越小。

### 8.2 K线形态使用规则

- **有效性 = 形态 × 位置 × 量能 × 大周期方向**，四项缺两项以上就是噪音。
- **只在关键位置有效**：均线（MA10/20/60）、前高前低、颈线、缺口；区间中部的形态一律无视。
- **反转形态按大周期降级**：月周多头中的日线乌云盖顶=减仓信号而非清仓；月周空头中的日线伞形线=观察信号而非买入。
- **必须等收盘确认**：盘中刺穿+收回才算，盘中截图不做数；T+1 下分时形态博隔夜，止损主动权交给隔夜，仓位减半。

### 8.3 日内决策流程

```
① 月线格局 → 横盘/空头=仓位上限2-3成
② 周线方向 → 空头=不做多
③ 日线许可 → 多头排列+MACD配合=开放买入；横盘=只观察
④ 60分时机 → 空头排列=今日不动（哪怕日线多头）
⑤ 30/15分点位 → 回调到支撑+拐点结构
⑥ 形态+量能确认 → 关键位置出伞形/吞没+缩量企稳或放量反攻 → 执行
⑦ 止损同步 → 破日MA10(短线)/MA20(波段)离场，周MACD死叉清仓
```

### 8.4 T+1 制度限制（A股特有）

- **14:30后禁止开新仓**：分时买点过了14:30不再有效，隔夜系统性风险抹掉分时精确优势。
- **趋势末端不用15分钟**：已涨/跌很多时，15分钟容易买在转折点。
- **尾盘30分钟只看收线**：盘中波动无意义，等收线确认结构。

### 8.5 持仓周期与层级匹配

| 持仓周期 | 该用的层级 | 不该看的 |
|---|---|---|
| 波段（数周-数月） | 月+周+日 | 15分钟（看了只会被震出去） |
| 短线（数日） | 周+日+60分 | 月线只用于定仓位上限 |
| 日内/T+1隔夜 | 日+60分+15分 | 月周只判多空不判点位 |

### 8.6 三个高频误用

1. **形态迷信**：日线乌云盖顶就清月线级持仓——形态只管它所在的周期，日线形态最多管3-5天。
2. **层级跳跃**：日线未转多就用15分金叉抄底——小周期信号在大周期逆势里胜率最低、毒性最大。
3. **指标堆叠求确认**：同层级指标（MA/MACD/KDJ）本质同源，重复确认不涨胜率只涨犹豫；每层一主一辅即可。

### 8.7 铁律

**只能用方向层否决执行层，绝不用执行层推翻方向层。** 用户拿分时/K线形态信号来论证逆大周期操作时，明确驳回并指出层级错误。

## 9. 大盘-板块-个股空间维度联动

第 8 章是**时间维度**（月→周→日→分时），本章是**空间维度**（大盘→板块→个股）。两个维度正交，叠加才是完整体系。

### 9.1 空间三层职权表

| 层级 | 角色 | 回答的问题 | 工具 |
|---|---|---|---|
| 大盘（指数） | 环境/水位 | 允许多大仓位 | 上证/沪深300/创业板指的月周日三周期状态 |
| 板块 | 主线/风口 | 钱往哪流、站哪个队伍 | 板块ETF雷达排名、板块指数趋势 |
| 个股 | 标的/执行 | 买哪只、什么点位 | 第 8 章四层职权体系 |

核心逻辑：**大盘是水，板块是船，个股是船上的货**。板块是个股的"庇护所与放大器"——主线板块的跟风股常比冷门板块的龙头走得顺。

### 9.2 完整决策顺序（先空间后时间）

```
第一步（空间·环境）：大盘三周期状态 → 定仓位上限
   月金叉+周线上穿=可重仓；月死叉=≤3成；三周期共振空=空仓/只做T
第二步（空间·主线）：板块ETF雷达排名 → 定方向
   只做排名前1/3的板块；个股所在板块排名后1/3=直接降一档处理
第三步（空间·标的）：板块内选股 → 龙头优先
   同板块选三周期状态最顺的（共振多>周多日多>仅日多）
第四步（时间·执行）：对选中个股走第 8 章四层职权体系
   日线许可→60分时机→15分点位→K线形态确认
```

口诀：**空间维度决定"做什么、做多大"，时间维度决定"什么时候做"。**

### 9.3 空间三维交叉矩阵

| 大盘 | 板块 | 个股三周期 | 结论 |
|---|---|---|---|
| 多 | 主线强 | 共振多 | 满仓级机会，让利润奔跑 |
| 多 | 主线强 | 日回调 | 黄金坑，逢低吸纳 |
| 多 | 弱板块 | 个股强 | 可做但降仓，独木难支 |
| 震荡 | 主线强 | 共振多 | 结构性行情主战场，半仓以上做主线 |
| 震荡 | 弱 | 任意 | 不做 |
| 空 | 强 | 个股强 | 反弹性质，轻仓快进快出 |
| 空 | 空 | 任意 | 空仓，没有例外 |

注意"震荡市+强主线"是 A 股最常见的赚钱结构（指数不涨但板块轮动）：个股三周期满分但板块退潮时要降档，大盘平平但板块主升时要敢做。

### 9.4 三条硬规则

1. **大盘有一票否决权（只否决仓位，不否决标的）**：大盘三周期共振空时，个股形态再好仓位上限 3 成且只做最短周期。
2. **板块强度 > 个股形态**：三周期状态相近的两只票，选板块排名高的——板块主升放大个股胜率与空间。
3. **龙头与跟风分开处理**：龙头按正常体系做；跟风股必须更苛刻——大盘或板块任一走弱先砍跟风，退潮时它跌最快。
