## F0 输入收集问卷（Step 0 使用）

## F1 自我评估框架（Step 1）

### F1.1 三圆模型（爱做 ∩ 擅长 ∩ 有回报）
- **爱做**：回忆心流时刻——做什么事不觉得累、愿意主动钻研（如「调通一个难 bug」「把复杂方案讲清楚」）。
- **擅长**：有证据支撑的能力——量化成果、被认可的事、考过的试。禁止「自我感觉良好」式条目。
- **有回报**：市场愿付费——对应岗位真实存在且薪资水位达标（以调研数据为准，不靠想象）。
- **三圆交集** = 主攻方向；两圆交集 = 备选/过渡方向；只有一圆 = 记为「待验证假设」，用低成本实验（项目/访谈/试课）验证后再投入。

### F1.2 ikigai 四问核对（防遗漏）
| 问题 | 对应证据要求 |
|---|---|
| 你热爱什么？ | 具体活动/主题，可举例 |
| 你擅长什么？ | ≥3 条可验证成果或技能 |
| 世界需要什么？ | 对应市场岗位/需求 |
| 什么能让你谋生？ | 目标岗位薪资调研数据 |

### F1.3 画像卡输出模板（Step 1 输出）
| 维度 | 结论 | 证据/标注 |
|---|---|---|
| 定位陈述（一句话） | 我以【≥1 具体技能名词】切入【1 个具体行业/岗位簇】，价值主张是【可验证差异化】 | —— |
| 优势（Top 3） | … | 每项附证据 |
| 短板（Top 3，影响目标达成者） | … | 每项标注是否被目标岗位硬性要求 |
| 驱动力排序 | 1.… 2.… | 来自 F1.1 |
| 红线清单 | 不可妥协项 | 来自输入/默认画像 |

**定位句公式**：`以{具体技能}切入{具体行业}，用{可验证成果/差异化}换取{量化回报目标}`。缺具体名词即为不合格。

## F2 行业与岗位调研框架（Step 2）

### F2.1 双轴九宫格：行业吸引力 × 个人匹配度
- 两轴均为 1–5 分（整数），**每个分数必须给出依据**。
- **行业吸引力（5 项各 1–5，取均值）**：薪资水位、岗位增速、人才缺口、地域可得性、进入壁垒（壁垒低为高分）。
- **个人匹配度（5 项各 1–5，取均值）**：技能契合、兴趣契合、可验证成果相关度、学习成本（成本低为高分）、时间窗口可行性。
- 落位：9–25 分区——右上象限（吸引力≥3.5 且匹配度≥3.5）= 主攻；左下象限 = 淘汰并说明理由；对角线中间 = 列为「低成本验证项」。

### F2.2 单赛道调研清单（每条须产出「结论 + 来源标注」）
1. 赛道规模与近 2–3 年增速、核心驱动事件；
2. 典型岗位 3–5 个 + 各自 JD 高频要求（动词、名词、数字）；
3. 薪资带宽（初级/成长期，城市分级）与涨幅预期；
4. 人才供需现状与缺口方向；
5. 头部与腰部公司清单、地域聚集地；
6. 进入壁垒（学历/经验/证书/作品）与最快入行路径；
7. 未来 12–24 个月的收缩/扩张信号与风险点。

### F2.3 来源标注规则
- 联网有效：`来源：联网检索（YYYY-MM-DD，检索词：…）`。
- 联网失败降级：条目标注 `来源：领域知识库估算（基准约 2024–2025，非实时）`，并在报告顶部统一加 ⚠️ 声明。
- 用户自行提供：`来源：用户提供`。

### F2.4 候选方向收敛（输出 3–5 个方向）
每个方向给出一句话结论，必须指向具体岗位簇与具体证据，句式：
`方向{名称}：{吸引力得分}×{匹配度得分}，主因{1 条关键证据}，结论={主攻/备选/验证/淘汰}`。

## F3 目标设定框架（Step 3）— SMART + 目标树

- **S 具体**：含岗位名/公司类型/城市等可指认元素；**M 可测**：含数字（薪资区间、职级、作品数）；**A 可达**：对照差距矩阵可行；**R 相关**：服务于「薪资高、增长快」或用户自定义首要目标；**T 时限**：含年月。
- 目标树分层：总目标（3 年）→ 年度目标（×1）→ 季度目标（×4，近 4 个季度可细化）。
- **不合格样例**：「提升技术能力，进入 AI 行业」。
- **合格样例**：「2027-06 前入职一家一线/强二线 AI 应用公司担任 AI 应用工程师，月薪≥25k×13+，落地 2 个含评测数据的完整 Agent 项目」。

## F4 路径规划框架（Step 4）— 3 年阶段里程碑

默认节奏（可因用户约束调整）：Y1 入行补基 → Y2 纵深项目 → Y3 跃迁。

| 阶段 | 核心目标 | 关键动作（2–4 项） | 可验证里程碑（≥1） | 风险与预案 |
|---|---|---|---|---|
| 0–6 月 | 补齐门槛+做出作品 | | | |
| 6–18 月 | 入行/转岗站稳，纵深第一年 | | | |
| 18–36 月 | 从执行走向稀缺（带项目/带人/垂直稀缺技能） | | | |

- 里程碑必须可验证：`完成{可指认交付物}，达到{可检验标准}，截止{年月}`。
- 每阶段至少标注 1 个「决策检查点」（如：作品集完成度不足 60% 则放弃该方向转 B 计划）。

## F5 技能补齐框架（Step 5）— 能力差距矩阵

1. 从 Step 2 收敛方向的 1–3 个目标岗位 JD 中提取要求，分类为：**硬技能 / 软技能 / 行业知识**。
2. 与用户现有能力逐条对照 → 差距值：0=具备；1=部分/需加固；2=缺失且岗位硬要求。
3. 每条差距给：补齐方式（学习/证书/项目/求职/实习）+ 载体（具体课程名/证书名/项目名）+ 优先级（P0 影响入行、P1 影响涨薪、P2 加分）+ 周期 + 验收标准。
4. 所有项目载体可指认（给出名称与平台），禁止「系统学习 XX」式空项。

### F5.2 学习投入换算（默认每周 6–10h，可覆盖）
- 一条 40–60h 的课 ≈ 6–10 周完成（按每周 6h 计）；一个 80–120h 的项目 ≈ 3–4 个月。安排时把「单条周期」与「用户可投入时间」对齐并显式展示，防止目标不可达。

## F6 定期复盘框架（Step 6）— 90 天节奏

复盘触发点：约定日期到达 / 用户主动要求 / 重大市场信号（如目标赛道收缩）。每次复盘产出「复盘纪要」并修订计划文件。

| 检查项 | 问题 | 记录 |
|---|---|---|
| 里程碑进度 | 各里程碑完成度 %？未达成的卡点是什么？ | |
| 假设检验 | 原假设（赛道增速/门槛/自身兴趣）是否仍成立？ | |
| 市场信号 | 目标赛道薪资/岗位数/新政策变化？（注明来源） | |
| 差距矩阵更新 | 已补齐项勾除；新增差距？ | |
| 计划修订 | 保留/调整/放弃哪些方向？下个 90 天目标？ | |
| 下一步动作 | 3–5 条具体动作（含时限） | |

**复盘输出必须量化**：完成度用 %，方向判断用「保留/调整/放弃」，禁止「进展顺利/还需努力」式空话。

## F7 通用纪律速查（各步骤引用）
1. 分数必须带依据；结论必须带证据或来源。
2. 默认画像填充项必须标注「（默认画像，待确认）」。
3. 每条动作必须含可验证载体与时限。
4. 联网数据标日期，降级数据标「知识库估算」+⚠️。

## F8 求职作品（Portfolio）制作规范（M1 Step 5 / M3 简历作品位 / M4 面试作品题 通用）

**何时用**：求职证据不足、目标岗位 JD 明确要求作品/可演示项目、或需在同类候选人中制造差异化时。**作品是「证据类缺口」的主要补齐载体**——目标岗位要求「1 年+ AI 经验」而你无经验时，作品是唯一能替代年限的证据。

**三原则（违反即不合格）**
1. **可答辩**：必须亲手完成/深度使用（≥2 次），每个细节经得起追问；**禁止拿他人或 AI 示范作品冒充自己署名**——面试官追问细节答不上即反噬；
2. **证据化**：每条论断带来源与日期；二手数据多源口径不一则并列标注，不假装精确；
3. **可讲清**：3 分钟能脱稿讲完核心（含 1 句定位 + 1 个槽点 + 你的解法）。

**推荐类型（按目标岗选择）**
| 类型 | 适用岗位 | 验收特征 |
|---|---|---|
| AI/行业产品拆解（见下） | 产品/方案/运营向 | 10 节结构完整、来源齐全 |
| 竞品分析/行业观察报告 | 市场/产品/行业向 | 有对比框架与独立判断 |
| 自搭 Agent/demo（可演示） | 技术向/AI 应用向 | 现场可跑、能讲清架构取舍 |

**拆解类作品 10 节结构**：① 一句话定位（面试可背）→ ② 市场窗口（为什么是现在/为什么是它）→ ③ 用户分层（场景×证据×付费意愿）→ ④ 功能拆解（产品人版模块地图 + 演进读策略）→ ⑤ 商业模式（定价结构/单位经济学/槽点）→ ⑥ 竞争格局（对照 2–3 家）→ ⑦ 风险与治理 → ⑧ 亮点与槽点（各 3 条带证据）→ ⑨ 对目标行业的启示（3–4 条，求职差异化金句）→ ⑩ 来源清单（全标日期）。

**制作节奏（≤3h/周 时间盒内）**：W1 选对象（方法见 F8.1）+ 收集归档四类资料（纪律见 F8.2）→ W2–3 按结构逐节填充 → W4 打磨 3 分钟口头版并放进简历作品位（条目写法见 M3 步骤 3.4A）。

### F8.1 对象选型两步法（W1 第 1 步；替代"近 6 个月有动态"一句式粗筛）
**第 1 步 · 否决筛查（四条，任一命中即淘汰，不纠结）**
1. **与已示范/已有作品重复**——再拆同款会暴露"讲的是模板"而非独立工作；多份作品应构成互补格局（例：通用 Agent / Agent 平台 / 行业 Agent 应用各占一角）；
2. **用不了 ≥2 次**——体验即证据，收费/审核/内测邀请门槛挡住即砍；
3. **近 6 个月无动态**——无版本/商业化/争议事件 = 没素材可写、写出来显过时；
4. **资料密度不足**——定价/版本动态/第三方评测/竞品四类凑不齐 = 4 周填不满 10 节，只能降备选不当主选。

**第 2 步 · 四维打分（过了否决项才比；选"最能替你说话"而非"最火"）**：贴位度（拆完它面试官更信你能胜任目标岗？权重最高）｜场景熟悉度（是否已有该行业/场景认知——拆自己行业 = 白赚行业分）｜体验可得性（注册到用上多快）｜差异化（补全作品格局缺口）。
**优先级天然排序**：拆现行业 AI 落地/竞品（贴位+熟悉双满分，最优）＞ 垂直场景 Agent 代表（客服/营销/HR 等 ToB 场景）＞ 平台型竞品（资料最全但差异化弱一档，只兜底）。排除项：自搭 Agent demo 仅技术向岗位选，非技术岗投入产出比最差。
**定名最后一步 = 1 次检索验证**：确认候选近 6 个月真有动态 + 真有免费试用/自助入口，再锁定具体产品名、开收集清单。

### F8.2 资料收集与归档纪律（W1 第 2 步起）
**四类来源**：定价结构（官网价格页/单位经济学）｜版本动态（新闻稿/发布会时间线）｜第三方评测与客户案例（区分独立第三方 vs 厂商转载）｜竞品对照（2–3 家各 1 段定位笔记）。
**口径分级（每个引用必标其一）**：🅐 厂商官网/发布会自述（高效但立场最强）｜🅑 媒体/分析师转述（注明原出处）｜🅒 独立第三方评测/审计（可信度最高，注意时效与样本）。效果数字（"提效 X%"）凡出自厂商或厂商引客户证言，一律标「厂商/客户自述口径」，不冒充独立验证。
**归档文件规范**：文件名含对象 + Part 序号 + 日期（如 `W1_资料归档2_对象_主题_YYYYMMDD.md`）；开头写用途与对应作品节号（如"支撑第⑤商业模式节"）；全文逐处标口径；冲突口径**并列标注、不替厂商裁定**；文末放资料总进度清单（区分 AI 可代收集项 / 用户亲测项）。
**元观察单独标注**：如"全库 0 条独立第三方审计"这类对整个素材库的批判性判断，显式写成发现（它是作品第⑧节槽点的证据），不埋在正文里。
**用户侧动作不可代劳**：注册试用实测、拿用户所在企业真实流程做覆盖/遗漏对照，必须用户亲做并留档（截图/笔记）；AI 侧只做检索与归档。

**自查**：① 每条论断有来源？② 无「体验很好」式空话？③ 每节都答了该答的问题？④ 亮点槽点带证据？⑤ 3 分钟能脱稿？⑥ 面试追问 2 个细节答得上？⑦ 对象过了 F8.1 否决筛查四条？⑧ 归档口径分级齐全、冲突口径并列未裁定？
