# Module M2 — 岗位分析（详细执行规范）

> 求职全链路总技能（career-planning）的 **M2 岗位分析模块**，由 `SKILL.md` 路由加载。执行前先读 `SKILL.md` 全局纪律约束（6 条）与本模块自查。轻量分析方法在本文件内完成；**完整人岗匹配**衔接既有技能 `jd-resume-matcher`，**同类岗位推送**衔接 `resume-job-match`（见第 5 节生态衔接位）。

## 1 适用场景与触发

用户提供**单条 JD / 岗位链接 / 公司+岗位名**并要求：分析这个岗位怎么样、值不值得投、岗位要求与我匹不匹配、有没有坑。触发词示例：「分析下这个 JD」「这岗位适合我吗」「帮我拆解这份职位要求」。**输出**：岗位分析卡（JD 拆解 + 能力匹配 + 风险识别 + 投/备/弃结论）。

## 2 输入要求

- 必需：JD 原文（文本/链接/文件均可；链接与文件先提取全文并核对，提取失败请用户粘贴，不得臆测）。
- 建议提供：用户能力与成果摘要（可引用 M1 画像卡、简历解析结果或用户口述）。
- 不提供用户信息时：只做「JD 拆解 + 岗位质量评估 + 隐性风险」，不输出匹配评分，并明确告知补全用户侧可升级为完整分析。

## 3 分步执行流程

### 步骤 3.1 JD 原文拆解
1. 保留 JD 原文措辞，逐条编号，分类标注：
   - **职责类（做什么）**：动词+对象+量化（如「主导 3 个以上储能项目落地」）；
   - **硬性要求（必备）**：学历/年限/证书/必须技能，含数字或硬名词；
   - **软性要求（加分/倾向）**：「优先」「加分」「了解」级措辞；
   - **非能力条目**：公司描述、福利、地点等（不进匹配）。
2. 指出 JD 中**无法验证的模糊表述**（如「经验丰富」「自驱力强」）并建议招聘方量化口径——此为岗位质量信号。
3. 提炼「关键成功因素 KSF」3–5 条（决定入职后能否存活/出彩的要素）。

### 步骤 3.2 能力匹配（轻量）
1. 将 3.1 的硬性要求与用户能力逐条对照，判定：满足 / 部分满足（标注缺口点）/ 不满足。
2. 结论必须**引用 JD 原文动词名词数字**，与用户证据逐字对应；对应不上即为部分/不符合（口径同 jd-resume-matcher 纪律）。
3. 匹配等级（轻量自评，供快速决策）：A 全面满足 / B 满足核心+可补 1–2 项 / C 缺 1 项硬性门槛 / D 多项不满足。标注「轻量自评，正式结论可调用 jd-resume-matcher」。

### 步骤 3.3 风险识别
逐项扫描并给证据/疑点（无证据则标「待核实」，禁止猜测坐实）：
- **职责陷阱**：JD 职责过宽（一人多岗）、方向不清（「负责 XXX 相关」无边界）、与职级不匹配（高级岗做执行活）？
- **成长信号**：有无明确项目/技术栈/团队规模信息；岗位是新设（0–1）还是替补（维护存量）——新设偏开拓可成长但更累，替补偏稳定但空间有限（标注为倾向判断）。
- **稳定性信号**：薪资带宽过宽、JD 出现频次高（长期挂=流动性大或 HR 刷 KPI，待核实）、要求「立即到岗」且高薪（警惕传销/培训贷类骗局——给出核实动作：查公司主体、面试地点、是否收费）。
- **匹配陷阱**：JD 写的技能与真实业务是否一致（如招 C++ 却强调「沟通拓展」）？

### 步骤 3.4 机会评估与投/备/弃结论
| 维度 | 权重建议 | 评分(1–5) | 依据（必须写） |
|---|---|---|---|
| 匹配度 | 35% | | 3.2 结论 |
| 薪资带宽达标度 | 20% | | 对照用户目标/市场带宽（来源标注） |
| 成长性 | 20% | | 3.3 成长信号 |
| 稳定性/风险 | 15% | | 3.3 风险信号（风险高=低分） |
| 地点/通勤/其他约束 | 10% | | 用户约束 |

加权分 ≥3.8 投递；3.0–3.8 备选（列出补强/核实动作后再投）；<3.0 放弃（给一句话理由）。分数必须带依据，禁止只给分。

### 步骤 3.5 输出岗位分析卡（固定格式）
```
# 岗位分析卡
## 一、JD 拆解（分类条目表 + KSF 3–5 条）
## 二、能力匹配（逐条对照 + 匹配等级 A/B/C/D + 1 句结论）
## 三、风险识别（陷阱/成长/稳定/匹配 四类 + 待核实清单）
## 四、机会评估（加权表 + 投/备/弃结论 + 理由）
## 五、下一步（补强动作 / 核实动作 / 生态衔接位）
```

## 4 与其他模块/技能的流转
- M2 结论「投递」→ 流转 M5 投递优化（进入投递作战表）；
- 用户侧信息不足 → 提示可先跑 M1 生成画像卡或解析简历；
- 需完整匹配报告 → 衔接 jd-resume-matcher；需同类岗位清单 → 衔接 resume-job-match（句式见 SKILL.md 生态衔接矩阵）。

## 5 生态衔接位（强制输出句式）
「本卡为轻量分析。需要完整人岗匹配报告可执行：『请使用 jd-resume-matcher，对这份 JD【附 JD 文本/链接】与我的简历做精准匹配分析』；需要更多同类岗位可执行：『请使用 resume-job-match，按此 JD 的能力要求推荐匹配岗位』。」

## 6 模块自查
1. JD 条目是否原文对照、未意译？ 2. 模糊表述是否已指出？ 3. 风险是否区分「证据/待核实」？ 4. 结论是否带依据？ 5. 是否输出衔接位句式？
