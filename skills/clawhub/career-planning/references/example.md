# references/example.md — 全链路端到端串联示例（演示用，非真实用户）

> 用途：展示一次「从求职迷茫到谈薪准备」的完整链路应如何被路由、串联与产出，作为执行口径校准基准。用户与数据均为演示构造；联网标注为演示格式；各模块完整规范见 `module-*.md`。

## 0 用户话术与路由判定

> 用户（化名小林）：「帮我做职业规划，然后按规划里的目标岗位优化简历、排投递。顺便我有条 JD 想让你先看看。」

- 意图命中：M1（职业规划）+ M2（岗位分析：先看 JD）+ M3（简历优化）+ M5（投递排期）→ 按链路执行并先向用户说明：「将依次执行 M1→M2→M3→M5，JD 分析插在 M1 之后作为选岗输入。」
- 小林画像快照（节选）：二本计算机 / 1.5 年嵌入式开发 / C/C++ 熟练、Python 基础 / 2 个量产项目 / 深圳 / 目标薪资高增长快 / 不接受硬卡硕士岗位（其余字段走默认画像并标注待确认）。

## 1 M1 职业规划 → 产出摘要（固定章节报告）

- 就业形势速览（前置 P0，演示格式）：供需与竞争：毕业生规模高位、电控/储能岗单岗竞争加剧（联网检索 2026-09-09，仅供参考）｜招聘节奏：8 月起企业提前筛人、Q4 活跃（同上）｜薪资趋势：跳槽涨幅收窄至 1–2 成、3 成为少数（同上）｜结构性分化：电控/机器人扩招、通用岗内卷（同上）｜约束传导 ≤3 条：目标带宽按市场收窄校准、投递窗口提前、不以裸辞换方向。
- 定位陈述：以 C/C++ 系统开发与量产交付能力切入【新能源电控（BMS 方向）】，用 2 个量产项目作为可靠性证据，3 年内实现薪资显著跃迁（默认画像，待确认）。
- 调研矩阵（节选）：电控 吸引力 4.0×匹配 4.2=主攻｜机器人 4.0×3.8=备选｜AI 应用 4.6×3.2=验证｜半导体 4.4×2.6=淘汰（硕士门槛，替代入口已说明）｜网安 3.4×2.2=淘汰。来源均标注（联网检索 2026-09-09 / 知识库估算）。
- SMART：总目标「2029-09 前在深圳储能/BMS 头部公司任电控软件工程师（BMS 方向），月薪≥30k×14+，主导 1 个 SOX 模块量产」。
- 3 年路径与差距矩阵、90 天行动（略，见 module-career.md 口径）→ Step 5 末尾输出衔接位句式。

## 2 M2 岗位分析（用户插入的 JD）→ 岗位分析卡摘要

- JD 拆解：储能公司「BMS 软件工程师」——职责 5 条（含「负责 SOX 算法开发与标定」）；硬性要求：本科+、3 年+ 嵌入式/C、熟悉 CAN；加分：有量产 BMS 项目。模糊表述 1 处（「有较强的责任心」）已指出。
- 能力匹配：小林满足核心（C/C++、量产、CAN 待补）→ 匹配等级 B（轻量自评，标注可调 jd-resume-matcher 计分）。
- 风险识别：JD 挂出 2 个月（流动性待核实）；职责边界清晰、无一人多岗迹象。
- 机会评估：匹配 4.2×35% + 薪资达标 4×20% + 成长 4×20% + 稳定 3.5×15% + 约束 4×10% ≈ 4.0 → **投递（S 级）**。
- 生态衔接位：已给出 jd-resume-matcher / resume-job-match 调用句式。

## 3 M3 简历优化 → 简历优化报告摘要

- 结构诊断：2 段经历只有职责无结果数字（列出 4 个【需你补数】位）。
- 亮点提炼：「负责 BMS 相关模块维护」→「主导 1 个量产项目电源管理模块的稳定性重构，故障率下降 XX%（【需你补数】）」。
- 简历×岗位映射（对齐 M2 JD）：命中「C/C++ 嵌入式、量产」；部分命中「CAN」（补：在校/业余做过 CAN 上位机？待确认）；缺失「3 年+」（以 1.5 年+项目密度说明，不虚构）。
- 表达优化：自我评价 3 行空话删除，压成 1 句证据式定位。

## 4 M5 投递排期 → 投递作战表摘要

- 节奏：在职状态 → 每周 8–15 个；周一–周三上午为主；分 3 批（练手→目标→冲刺），本批含上表 S 级岗位。
- 排序：S 级 3 个（含 M2 岗位）、A 级 6 个、B 级若干——每岗 1 句理由。
- 版本管理：`小林_BMS软件工程师_XX储能_20260909_v1.1.pdf` + 版本说明（记录 M3 改动与对应 JD 条目）。

## 5 串联链路的跨模块传递核对

- M1 目标岗位簇「电控/BMS」→ M2 实际 JD → M3 映射表与微调版本 → M5 排序与版本索引：岗位名、JD 原文要点、简历版本号均显式传递，无凭空猜测。
- 用户后续可继续：M4 面试准备（拿 M2 KSF 押题）→ M6 谈薪（用 M1 目标薪资做锚点）。示例到此为止，其余模块产物结构见对应 module 文件与 USAGE.md 表格。
