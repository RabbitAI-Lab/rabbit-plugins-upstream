# SECURITY.md — 安全策略与漏洞上报

## 漏洞报告渠道
如果你发现本技能存在安全漏洞，请按以下方式上报：

- **邮箱**：[ClawHub 上联系作者 @sunsettide]
- **GitHub Issues**：（待创建）
- **ClawHub 社区**：通过 ClawHub 技能页面提交安全反馈

## 响应承诺
- 安全报告将在 **48 小时内**确认收到
- 严重漏洞将在 **14 天内**修复并发布新版本
- 修复完成后向报告者致谢（如报告者同意）

## 禁止
- 请不要在 GitHub Issues 或公共渠道公开披露未修复的漏洞
- 请不要利用漏洞对用户系统进行破坏性操作
- 发现漏洞后请先通过上述渠道联系作者

## 安全策略
本技能遵循以下安全原则：
1. **最小权限**：仅在需要时请求管理员权限
2. **数据隔离**：所有操作在本地执行，无数据外发
3. **可追溯**：本地操作日志可供审计
4. **透明**：完整披露技能的能力范围和风险
