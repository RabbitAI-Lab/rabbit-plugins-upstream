# MONTHLY_REPORT() 月报复盘与业务结果分析

**Skill ID：** `zayn-monthly-report`

**版本：** `v0.1.0`

**状态：** Draft for testing

## 核心用途

从当月日报、周报、项目记录和业务数据中识别目标达成、关键结果、结果密度、资源投入、等待阻塞、关闭能力和下月重点。

## 适用与不适用

- 适用：月报、月度复盘、月会汇报、整月业务结果分析、忙但月度成果不清的分析。
- 不适用：单日日报使用 `zayn-daily-report`；整周周报使用 `zayn-weekly-report`；半年或年度复盘分别使用 `zayn-midyear-report`、`zayn-annual-report`；类型不明使用 `zayn-report`。

## 输入与流程

提供月份、岗位、月初目标、月度记录、重点项目、项目结果、关键指标、新增/关闭事项、等待阻塞、下月目标和支持需求。先检查参数，再区分动作与结果，分析月度趋势、结构问题和关闭判断。

## 输出

核心结论、目标达成、关键成果、项目阶段分布、工作量与结果质量、等待阻塞、主要问题、可保留方法、3 至 5 个下月结果型目标及管理支持。

## 与其他 Skill 的关系

由 `zayn-report` 路由；需要升级或领导选择时交给 `zayn-escalate` 或 `zayn-decision`。

## 快速示例

若只有“本月发了 40 份报价”，不能视为月度成果；必须补充明确反馈、进入下一阶段、成交、暂停或退出等可验证结果。

支持现有模板和销售/非销售岗位流程。
