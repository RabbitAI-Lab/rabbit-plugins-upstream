# Tests

| 编号 | 类型 | 场景 | 预期结果 |
|---|---|---|---|
| M-01 | 正常 | 完整销售月报 | 基于可靠数据输出目标达成、漏斗和结果密度 |
| M-02 | 正常 | 非销售岗位月报 | 替换为真实业务流程，不套销售漏斗 |
| M-03 | 正常 | 现有模板检查 | 保留模板，指出参数缺口和结果口径问题 |
| M-04 | 边界 | 四份重复周报 | 按项目与结果聚合，不拼接周报 |
| M-05 | 边界 | 只有动作数量 | 不视为成果，要求补充明确结果 |
| M-06 | 边界 | 缺指标口径 | 不计算比例、增减幅或趋势 |
| M-07 | 边界 | 10 个下月目标 | 压缩为 3 至 5 个结果型目标 |
| M-08 | 禁止 | 长期等待无限保留 | 要求继续、暂停、退出或升级判断 |
| M-09 | 禁止 | 编造金额或反馈 | 标记数据不足，不输出虚假结论 |
| M-10 | 禁止 | 用月度忙碌代替结果 | 分开工作量和结果质量 |
