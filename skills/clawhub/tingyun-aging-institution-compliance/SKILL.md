# 养老机构运营合规自查助手

## 一、这个技能解决什么问题

养老机构最怕的不是"不知道有标准"，而是**知道有标准，但不知道检查那天会看什么、拿什么出来**。

2026-07-30，市场监管总局会同民政部发布《养老机构基本规范》《养老机构重大事故隐患判定准则》两项**强制性国家标准**，2027-08-01 实施，设 1 年过渡期。前者从选址与建筑、设施与设备、入院出院管理、基础服务、安全管理、运营管理、评价与改进 7 个方面提出 **90 项具体要求**；后者把重大事故隐患划分为 **25 条直接判定要素、28 条综合判定要素和 2 类排除情形**。

官方给了标准，也给了地方检查清单（辽宁民政厅 2026-10-29 版：64 项，33 项必查 + 31 项抽查）。**但这两样东西都不是给机构自己用的**——标准写的是要求，清单写的是检查表，**"我这家现在缺什么、缺了怎么补、补完怎么证明"没有任何一方给**。

**问题性质是"证据不可自证"，不是"标准不清楚"。** 检查组到现场，问的是"上个月 3 号你做了什么，记录在哪"。绝大多数机构不是没做事，是**做了但证明不了**，或者**制度在墙上但记录断了**。

本技能做的事：**把检查项逐条落成可勾选的判定表 → 分出必须先处理的 → 算出缺多少人和缺多少证 → 生成整改台账 → 配齐留痕清单。**

## 二、适用与不适用

**适用：**
- 养老院、敬老院、日间照料中心、托养机构的**运营主体**（不是住着的人/家属）
- 新国标过渡期内 wanting 做一次全面差距盘点
- 收到检查通知前需要提前自查
- 上一次检查有整改项未闭环，需要重建台账
- 集团化养老需要统一下属机构的自查口径

**不适用：**
- ❌ **不做合规结论**。不输出"合格/不合格"，最终认定权在民政、消防、住建等主管部门
- ❌ **不做法律意见**，不代办任何许可、备案、审批
- ❌ **不做建筑结构安全鉴定、消防验收、特种设备检验**——这些必须有资质
- ❌ **不做人身伤害事故的因果认定或责任划分**（如老人跌倒是谁的责任）
- ❌ **不做养老机构的等级评定申报**（那是另一套评分办法）
- ❌ **不替代机构的安全生产管理主体责任**

**这个技能的定位是自查工具，不是合规服务。** 用了它不代表能过检查；不用它不代表过不了。

## 三、怎么用（四个动作，按顺序）

### 动作一：把机构信息填进去

需要这几组数（有多少填多少，缺的地方脚本会标"需人工确认"）：

```json
{
  "institution": {
    "name": "XX养老院",
    "beds_total": 150,
    "staff": {
      "nursing_total": 18,
      "nursing_certified": 15,
      "kitchen_total": 6,
      "kitchen_health_cert": 5,
      "fire_control_room_certified": 2,
      "security_fire_certified": 1
    },
    "residents_by_level": {"自理": 60, "半失能": 50, "全失能": 40}
  },
  "standards": {
    "ratio_selfcare": 10,
    "ratio_partial": 6,
    "ratio_full": 3
  }
}
```

### 动作二：跑自查，拿到判定表与风险清单

```bash
python scripts/compliance_check.py --input institution.json            # 可读报告
python scripts/compliance_check.py --input institution.json --json     # JSON 输出
python scripts/compliance_check.py --init                             # 生成输入模板
```

脚本会输出：
- **六类 64 项的完整判定清单**（每项带检查依据、必查/抽查标记）
- **护理员配比测算**（分档加总，与在岗持证人数一起看）
- **证书到期预警表**（90/30 天两级预警 + 过期红色标记）
- **整改优先级排序**（P0 立即 / P1 限期 / P2 计划 / P3 观察）
- **归档目录结构建议**

### 动作三：把 64 项逐条填成三态

脚本给的是**待填的骨架**，机构对着填。填的时候按这个判断顺序：

```
问自己三个问题：
1. 这项我能不能拿出【最近一个完整周期内】的记录？
   → 拿不出          → 需人工确认（可能是没做，也可能只是没找到）
   → 拿得出，往下走
2. 记录内容跟现场实际一致吗？
   → 不一致          → 不符合（这一档更严重，涉及记录真实性）
   → 一致，往下走
3. 依据条款我满足吗？（看 references 里的检查依据列）
   → 满足            → 符合
   → 不满足/拿不准   → 不符合 或 需人工确认（按你能不能确定来定）
```

⚠️ **三态里"需人工确认"是必须的，不是可选的。** 拿不准的一律放这里，不要硬选"符合"。这个状态的存在就是为了把判断权交还给现场的人。

### 动作四：生成整改台账与留痕清单

不达标的项目进入台账。**六个字段缺一不闭环**：

```
问题描述（客观事实+位置+时间）｜依据条款（标准号/文号）｜整改措施（人+动作+时间）
｜责任人（姓名+岗位）｜完成时限（具体日期）｜复查结果（复查人+日期+结论）
```

**最后一项空着 = 没闭环。** 这是最常见的断点：问题有、措施有、时限有，就是没人复查。

## 四、这个技能的核心方法论

### 方法论 1：三态输出，而不是二元判定

检查结论只输出**符合 / 不符合 / 需人工确认**，绝不输出"合格/不合格"。

理由很硬：
- 认定权在主管部门，机构或第三方说了不算
- "合格"会被直接引用到验收、投标、补贴等场合，风险外溢
- 现场状态会变，今天符合明天可能不符合

**"需人工确认"这一档不是和稀泥**，它是"证据不足就下不了结论"这一事实的诚实表达。找不到记录 ≠ 没做事。把它硬塞进"不符合"，会导致无用整改；硬塞进"符合"，会导致更大风险。

### 方法论 2：先找证据，再做判断

判定的起点是"记录在哪"，不是"我们做没做"。

- **有制度 ≠ 在执行** —— 上墙的服务标准只能证明"有制度"，证明不了"在执行"
- **拿不出记录 = 需人工确认**，不是"不符合"
- **记录与现场矛盾 = 不符合**，而且是更严重的一档

### 方法论 3：分档加总算护理员，不是总数平均

```
所需护理员数 = Σ (该护理等级人数 ÷ 该等级配比)，向上取整
```

自理 1:10、半失能 1:6、全失能 1:3（耒阳市项目口径，**必须换成本地要求**）。
混在一起平均算，重照护机构会被查出配比不足，轻照护机构则人浮于天。

### 方法论 4：必查项优先，且先拆硬伤

**33 项必查优先于 31 项抽查**（辽宁口径；各地划分不同）。
整改排序按 **必查性 × 后果严重度 × 整改难度**。先做能立即消除的（换材料、封堵、停用），再做需要工程量的，最后做需要第三方检测的。**先拆能被一眼看见的硬伤。**

### 方法论 5：P0 红线要单独扫一遍

**消防类 10 项在辽宁清单里全部为必查项**，且依据都带 GB48014。命中直接判定要素 = 重大事故隐患，不走综合判断。

建议把 GB48014 的 25 条直接判定要素单独做一次红线扫描（见 references/标准解读第四节），别等检查当天。

### 方法论 6：整改证据要三件套

**整改前照片 + 同机位整改后照片 + 有签认的复查记录**，缺一样等于没改。

**同机位对比**是最有说服力的形式。做整改时顺手拍两张，比事后补拍强得多。

### 方法论 7：档期型检查要提前量

护理员每半年 1 次安全教育、每年 1 次满意度测评、每年 1 次应急演练、健康证明每年体检换证、特种设备检验有效期届满**前一个月**提出定期检验要求。

这些都有固定节律。设 90 天预警窗口，倒推排期，比被动等着过期强。

## 五、输出物清单

跑完一轮，机构应该拿到这几样：

| 交付物 | 内容 | 给谁看 |
|---|---|---|
| **判定结论表** | 64 项逐条三态结论 + 依据 + 证据索引 | 检查组 |
| **整改台账** | 六字段闭环台账，按 P0-P3 排序 | 检查组（通常先看这个） |
| **证据归档册** | 6 分册 + 目录页 + 扫描件命名规则 | 检查组 |
| **护理员配比测算表** | 分档加总结果 vs 在岗在册人数 | 内部管理 |
| **证书到期预警表** | 三级预警（90 天黄 / 30 天橙 / 过期红） | 内部管理 |
| **差距分析** | 按 GB48013 七方面归类的差距清单 | 管理层 |

## 六、边界与免责（这部分不能删）

⚠️ **必须写在交付物首屏：**

> 本表为依据公开标准与地方检查清单编制的**对照自查辅助材料**，用于帮助机构梳理自查要点、准备证据、跟踪整改。
> **不构成法律意见，不出具合规合格结论。**检查结论由民政、消防、住建等主管部门依法作出。
> 地方检查清单以辽宁省民政厅 2026-10-29 版为示例，**各地条目数、分类与必查/抽查划分不同**，使用前须替换为本地区主管部门现行清单。
> 标准的具体条款以正式发布文本为准；本材料未复制标准正文。
> 记录应当真实，**不得补记、不得编造**。发现历史记录缺失应如实说明。

**具体不做的事**：
- 不代替现场检查，不代替主管部门认定
- 不做建筑结构安全鉴定、消防验收、特种设备检验（须有资质）
- 不代办任何许可、备案、审批
- 不出具事故责任认定
- 不代办养老机构等级评定
- 不提供规避检查的方法

## 八、脚本用法

```bash
# 生成输入模板
python scripts/compliance_check.py --init

# 可读报告
python scripts/compliance_check.py --input institution.json

# JSON 输出（便于接入机构自有台账系统）
python scripts/compliance_check.py --input institution.json --json

# 覆盖本地配比口径
python scripts/compliance_check.py --input institution.json --ratio-selfcare 8 --ratio-partial 5 --ratio-full 4

# 只出护理员配比与证书预警
python scripts/compliance_check.py --input institution.json --staffing-only
```
