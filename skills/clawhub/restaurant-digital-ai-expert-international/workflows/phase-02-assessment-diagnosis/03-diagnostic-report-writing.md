# 03-Diagnostic Report Writing

## Triggers
- After the R-DMM assessment is complete, write the formal diagnostic report

## Use Template

Use `templates/digital-maturity-assessment-report-template.md` as the standard format.

## Report Writing Guide

### Core Principle: From "Finding" to "Insight" to "Recommendation"

```
Finding (What) -> Insight (So What) -> Recommendation (Now What)

X "Systems are not integrated" (finding only)
V "POS, CRM, and inventory systems are not integrated, causing store managers to spend 1 hour/day on manual reconciliation = $12,000/year in annual labor waste + 15% reconciliation error risk (insight) -> Recommend completing POS-CRM-inventory three-way integration within 3 months (recommendation)"
```

### Report Structure (per Template)

| Section | Core Content | For the CEO | For the Technical Team |
|---------|-------------|:---:|:---:|
| Executive Summary | 1 page: Composite score + Top 3 Findings + Top 3 Actions | ***** | *** |
| Business Current State | Location overview + System inventory + Data assets | **** | **** |
| Five-Dimension Assessment | Each dimension score + evidence + gap analysis | *** | ***** |
| Benchmarking Analysis | You vs. same-format average vs. leading | ***** | *** |
| Quick Win Opportunities | What can be done in 0-3 months: low investment, fast results | ***** | **** |
| Recommendations & Next Steps | Phased action roadmap | ***** | **** |

### Report Length Guidance

| Client Size | Total Pages | Executive Summary | Detailed Analysis |
|-------------|:---:|:---:|:---:|
| 1-10 locations | 8-12 pages | 1 page | Keep as concise as possible |
| 10-100 locations | 15-25 pages | 1 page | Include charts/graphs |
| 100+ locations | 25-40 pages | 1-2 pages | Full elaboration |

### Pitfalls to Avoid
1. **Don't use overly formal business language** -- small restaurant owners find it awkward. Natural, direct language works best.
2. **Numbers must not be guessed** -- for data that is not 100% certain, mark as "Estimate, +/-15%"
3. **Don't try to impress the owner with your industry knowledge** -- the owner knows their business better than you do. Don't lecture them on how to run a restaurant.
4. **Don't only present problems without solutions** -- the core value of a diagnostic report lies in answering "so what now?"

## Quality Checks
- [ ] Every finding is supported by data
- [ ] Every recommendation specifies "who does what, and how long until results are visible"
- [ ] The report has an executive summary that conveys the message in one page
- [ ] Formatting is clean and consistent (professional fonts, 1.5 line spacing)
- [ ] Non-technical readers can understand 80%+ of the content
- [ ] No recommendations propose leaps across stages that are premature
