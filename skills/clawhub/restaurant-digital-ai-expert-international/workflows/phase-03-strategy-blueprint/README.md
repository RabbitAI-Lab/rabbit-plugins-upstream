# 03-Strategy & Blueprint Design

Based on diagnostic results, this phase develops the restaurant digital strategy, target architecture, and 3-year roadmap.

## Sub-Processes

| # | Process | Deliverable |
|---|--------|-------------|
| 01 | Digital Strategy Formulation | Digital vision + strategic objectives + design principles |
| 02 | Target Architecture Design | Target system architecture diagram + data architecture diagram |
| 03 | 3-Year Roadmap Development | Phased roadmap + investment estimate + milestones |
| 04 | AI Strategy (if applicable) | AI scenario roadmap + prioritization + ROI |

## Key Principles

- **The vision must be explainable in one sentence**: "In 3 years, our 300 locations will operate as if guided by a single brain"
- **Architecture must be realistic**: Benchmark against peers of similar scale, not McDonald's (if the client has only 50 locations)
- **The roadmap must have flexibility**: 3-year plan -- Year 1 detailed, Year 2 outlined, Year 3 framework only
