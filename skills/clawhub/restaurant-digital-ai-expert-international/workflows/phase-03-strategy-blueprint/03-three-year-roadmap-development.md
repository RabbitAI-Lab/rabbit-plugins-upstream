# 03-3-Year Roadmap Development

## Triggers
- After strategy and target architecture are confirmed, develop the phased implementation roadmap

## Use Template

Use `templates/digital-transformation-roadmap-template.md` as the standard format.

## Roadmap Development Guide

### Phase Breakdown Principles

```
Phase 1 (Months 0-6): Foundation Building -- "You can't build upper floors without a foundation"
  -> Only do 1-3 of the most critical things
  -> Goal: stable, usable, adopted
  -> Budget: 25-35% of total 3-year budget

Phase 2 (Months 7-18): Capability Enhancement -- "Foundation is solid, time to expand"
  -> System interconnection, data begins to generate value
  -> Goal: visible efficiency gains, data-driven decision-making
  -> Budget: 35-45% of total 3-year budget

Phase 3 (Months 19-36): Intelligent Upgrade -- "With data in place, it's time for AI"
  -> AI scenario implementation, organization digitalization
  -> Goal: AI delivers measurable business value
  -> Budget: 25-35% of total 3-year budget
```

### Planning Template for Each Phase

For each project within each Phase:

```
Project Name: [XX]
Objective: [one sentence]
Scope: [which locations/departments are covered]
Pre-requisites: [what must be completed first]
Investment: [people / money / time]
Deliverables: [outputs + KPI improvements]
Dependencies: [depends on which systems / teams / external factors]
Risks: [Top 3 risks + mitigation measures]
Exit Criteria: [what counts as "done"?]
```

### Quick Win Priority Principle

Phase 1's first month should include a "quick win":
- **Quick win definition**: <30 days to implement, <$15,000 investment, visible results (supported by data)
- **Quick win purpose**: Build team confidence, show ROI to the owner, pave the way for subsequent projects
- **Typical quick wins**: QR code ordering go-live (save 1 FTE during peak), delivery data auto-reconciliation (save store managers 30 min/day)

### Franchise Rollout Cadence (Special Consideration for Franchise Brands)

| Phase | Rollout Strategy | Target Franchisee Coverage |
|-------|------------------|:---:|
| M1-M3 | 5-10 pilot franchisees (voluntary) | 3-5% |
| M4-M6 | Results-driven, attract second wave | 15-25% |
| M7-M12 | Supply chain system soft bundling (new locations onboard directly) | 40-60% |
| M13-M24 | Legacy franchisees gradually transition | 80%+ |
| M25+ | All franchisees on unified platform | 95%+ |

## Deliverables
- 3-year phased roadmap
- Detailed project inventory per phase (including investment / output / dependencies / risks)
- Milestone definitions
- Total investment estimate

## Quality Checks
- [ ] Phase 1 has fewer than 3 projects (fewer is better)
- [ ] Every project has clear exit criteria
- [ ] Franchisee rollout cadence is considered (if applicable)
- [ ] At least 1 quick-win project goes live within Month 1
- [ ] Investment estimates have a basis (not guesses)
