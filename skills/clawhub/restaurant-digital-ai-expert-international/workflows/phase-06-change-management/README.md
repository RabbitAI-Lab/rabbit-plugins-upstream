# 06-Change Management & Organization Design

The biggest barrier to digital success is not technology -- it is people and organization. 70% of project failures are caused by change management issues.

## Sub-Processes

| # | Process | Deliverable |
|---|--------|-------------|
| 01 | Change Management Strategy | ADKAR analysis + communication plan + stakeholder map |
| 02 | Digital Organization Design | Digital organization structure + roles + incentive mechanisms |

## Key Principles

- **Change is not training**: Teaching people to use a system is training. Getting people to WANT to use a system is change management -- they are completely different.
- **Make the store manager money**: If a store manager refuses to use the system, 90% of the time it is because "the system adds work without adding income."
- **Organizational capability before technical capability**: First solve "who is responsible," then solve "which system to use."
- **The owner must lead from the front**: If the owner does not use the system to review reports, why would a store manager use the system to enter data?
