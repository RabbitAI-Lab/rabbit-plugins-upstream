# Franchise Digital Management Framework

## Instructions
Use this template to design a digital management and control system for multi-unit franchise brands. The core objective is "soft lock-in" -- using data and systems to tether franchisees into the ecosystem so that leaving feels unthinkable because the value delivered is too high. See also: [Digital Maturity Assessment](./digital-maturity-assessment-report-template.md) to baseline your franchise system, and [AI Scenario Priority Scorecard](./ai-scenario-priority-scorecard-template.md) to prioritize enablement-layer AI investments.

---

## 1. Five-Layer Franchise Digital Management Model

```
Layer 5: Brand Enablement -- Help franchisees earn more
  -> AI site selection / marketing enablement / operational optimization
  -> Franchisees stay because "they earn more with us"

Layer 4: Data Transparency -- HQ sees clearly, manages effectively
  -> Real-time revenue / inventory / loyalty data
  -> HQ always knows the true operating picture

Layer 3: Process Standardization -- Franchisees follow the playbook
  -> Digital SOP + system enforcement + inspections
  -> Franchisees "copy the homework" instead of guessing

Layer 2: Supply Chain Consolidation -- Franchisees source from HQ / approved vendors
  -> Centralized procurement + supply + quality control
  -> Guarantees product consistency + HQ earns procurement margin

Layer 1: Terminal Control -- POS / KDS / Loyalty
  -> Payment + kitchen display + member data entry points
  -> All data enters the ecosystem here
```

## 2. Digital Management Tools by Layer

### Layer 1: Terminal Control (Mandatory, Full Coverage)

| Control Point | Digital Tool | Mechanism | Mandatory? |
|---------------|-------------|-----------|:----------:|
| POS payments | Unified POS system | Unauthorized POS prohibited | Mandatory |
| QR / scan-to-order | Unified ordering platform + unified menu | Menu, pricing, and discount permissions controlled by HQ | Mandatory |
| Payment channels | Unified payment gateway | All payments flow through HQ-designated channels | Mandatory |
| Loyalty system | Unified loyalty platform | Member data owned by HQ; cross-location redeemable | Mandatory |
| KDS (Kitchen) | Unified KDS | Production standardization + expediting + monitoring | Recommended -> Mandatory |

### Layer 2: Supply Chain Consolidation

| Control Point | Digital Tool | Mechanism | Mandatory? |
|---------------|-------------|-----------|:----------:|
| Core ingredients | Inventory management + supplier management | Core ingredients from approved suppliers only | Mandatory (quality assurance) |
| Non-core ingredients | Inventory management | May self-source from approved supplier list | Recommended |
| Packaging / branded materials | Procurement platform | Brand-compliant (unified VI) packaging via HQ central procurement | Mandatory (brand consistency) |
| Bulk pricing | Procurement platform | HQ negotiates centrally; franchisees enjoy group pricing | Franchisee benefit |
| Inventory visibility | Inventory management | HQ can view franchisee inventory levels | Monitoring |

### Layer 3: Process Standardization

| Control Point | Digital Tool | Mechanism | Mandatory? |
|---------------|-------------|-----------|:----------:|
| SOP standardization | Digital SOP + training system | Key-position SOPs digitized + assessment | Mandatory |
| Food safety self-inspection | Digital inspection | Daily self-inspection + photo upload | Mandatory |
| Mystery shopper | Inspection system | Third-party inspections + digital scoring + ranking | Spot-check |
| Equipment maintenance | IoT + work orders | Preventive maintenance reminders + ticket closure | Recommended |
| License / permit management | Permit management system | Business license / food service permit auto-expiry alerts | Recommended |

### Layer 4: Data Transparency

| Control Point | Digital Tool | Mechanism | Mandatory? |
|---------------|-------------|-----------|:----------:|
| Real-time revenue | POS data -> HQ BI | Revenue visible in real time + anomaly alerts (below baseline) | Mandatory |
| Inventory transparency | Inventory data -> HQ | HQ can view each location's inventory | Mandatory |
| Loyalty data | CRM -> HQ | HQ centrally manages all member data | Mandatory |
| Performance ranking | BI leaderboard | Multi-dimension ranking (revenue / cost / customer rating) | Recommended |

### Layer 5: Brand Enablement

| Enablement Area | Digital Tool | Value | Franchisee Perception |
|-----------------|-------------|-------|-----------------------|
| AI site selection | Site selection model | More accurate new-location selection -> higher success rate | "Following HQ's data makes opening stores safer" |
| Marketing enablement | HQ marketing hub | HQ runs unified campaigns -> locations participate directly | "I don't need to plan campaigns myself" |
| Operational diagnostics | AI operations analysis | Auto-identify operational issues + push improvement suggestions | "Like having a consultant on retainer" |
| Peer benchmarking | BI benchmarks | Peer group comparison -> see exactly where the gap is | "I see the gap and know what to fix" |

## 3. Phased Franchisee Digital Rollout

| Phase | Timing | Action | Franchisee Coverage Target |
|-------|--------|--------|:--------------------------:|
| Champion | M1--M3 | Select 5--10 highly cooperative franchisees for voluntary pilot | 3--5% |
| Attraction | M4--M6 | Use champion results data to attract second-wave franchisees | 15--25% |
| Lock-in | M7--M12 | Supply chain system integration (new franchisees get full suite from Day 1) | 40--60% |
| Coverage | M13--M24 | Legacy franchisees gradually migrated | 80%+ |
| Unification | M25+ | All franchisees on unified platform | 95%+ |

## 4. Franchisee Segmentation & Management Strategy

| Segment | Profile | Digital Strategy |
|---------|---------|------------------|
| **Type A -- Champion** | Highly cooperative, strong performance | Priority access to new features -> become "Digital Ambassador" -> participate in vendor selection -> video case study -> mentor new franchisees |
| **Type B -- Follower** | Neither proactive nor resistant | Stimulate with champion data -> prove "system helps you earn more" -> gradual adoption |
| **Type C -- Sideliner** | Says yes verbally; slow to act | Compare Type A profitability vs. Type C -> create urgency -> drive action |
| **Type D -- Resister** | Firmly refuses | Don't push now -> wait until 80% of franchisees are on board -> non-digital franchisees will naturally be marginalized |

## 5. Franchise Digital KPIs

### Franchisee-Facing KPIs

| KPI | Definition | Target | Tied To |
|-----|-----------|:------:|---------|
| System usage rate | Daily POS usage rate; data completeness | > 95% | Franchisee rating |
| Data timeliness | Daily revenue reported within 2 hours of closing | > 90% | Franchisee rating |
| Food safety self-check completion | Daily food safety checklist completion rate | 100% | Franchise qualification |
| Centralized procurement ratio | Amount sourced through system / total procurement spend | > 70% | Rebate + rating |

### HQ-Facing KPIs

| KPI | Definition | Target |
|-----|-----------|:------:|
| Franchisee system coverage | % of franchisees using unified systems | >= 95% |
| Data visibility rate | % of locations with real-time operational data visible to HQ | >= 90% |
| Franchisee system satisfaction | Franchisee satisfaction score | >= 4.0 / 5 |

## 6. Common Franchise Digital Conflicts & Resolutions

| Conflict | Franchisee View | HQ View | Resolution |
|----------|-----------------|---------|------------|
| POS data not shared | "Why should HQ see my revenue?" | "If you don't share data, how can I analyze why others earn more than you?" | Lead with enablement before control; let franchisees taste the benefit of transparency first |
| Mandatory centralized procurement | "HQ is profiting off my purchasing" | "Central procurement ensures quality + you would definitely pay more sourcing alone" | Publish side-by-side comparison: centralized price vs. market retail price |
| Who pays for the system | "I have to pay to use the system too?" | "The system delivers long-term value to you" | HQ subsidizes 50--100% initially -> cost-share after results are proven |
| Loyalty data ownership | "Members I cultivated belong to my store -- why share with the whole brand?" | "Loyalty members are a brand asset, not a single-location asset" | Clarify in franchise agreement upfront + brand enablement benefits flow back to the store |

## 7. Franchisee Digital Investment Cost-Sharing Model

| Digital Investment | HQ Share | Franchisee Share | Notes |
|--------------------|:--------:|:----------------:|-------|
| POS system (hardware) | 0% | 100% | Store equipment; franchisee purchases directly |
| POS system (software) | 50--100% | 0--50% | HQ subsidizes initially; cost-sharing after value is proven |
| Supply chain system | 100% | 0% | HQ infrastructure; franchisee uses for free |
| CRM / Loyalty system | 100% | 0% | Unified brand asset |
| Delivery aggregator integration | 50% | 50% | Mutual benefit |
| BI / Reporting | 100% | 0% | HQ provides to franchisees |
| AI tools | 100% | 0% | HQ enablement tools |

## 8. Exit & Data Migration

When a franchisee exits the franchise system:

| Data | Handling |
|------|----------|
| Loyalty / Customer data | Belongs to brand HQ; not returned to franchisee (must be pre-agreed in the franchise agreement) |
| Store operational data | Exportable for the franchisee (revenue / orders / cost records) |
| Inventory / procurement data | Exportable for the franchisee |
| System accounts | Immediately deactivated; all system access revoked |
| Data deletion | Loyalty data retained (brand asset); store operational data retained for X months then deleted per data retention policy |
