# Track, submit and follow up

Use the chosen role, current applicant preferences, final documents and existing application history. Reuse an existing tracker; otherwise keep a simple application log in the user's career project. No separate service is needed.

## Keep the record useful

For each application, retain the employer, role/requisition, original listing URL, document revision, relevant dates, current state, completion evidence and next action. Link the application's saved research and files. Different requisitions remain distinct; a renamed URL alone does not create a new application.

Start the record when preparing a chosen application. Discovery results belong in the shortlist until selected. Update the affected entry; keep prior submissions and approved revisions.

Use clear states:
- Prepared: the documents are ready; no submission has been established.
- Submitted: a confirmation page, receipt, employer portal status or equivalent evidence establishes completion.
- Blocked: a tool or employer barrier prevents progress.
- User action needed: a specific login, answer, attestation or human step remains.
- Unconfirmed: the operation may have completed, but its outcome is unresolved.

Record interviews, replies, offers and withdrawals as they happen. Prepared files and a successful click are not proof of a submitted application.

## Submit within the agreed scope

Work through the chosen application or batch. Ask for missing answers needed to complete it. Read the actual current employer form and instructions. Use the correct résumé/letter revision and accepted application answers; obtain genuinely missing required information from the applicant.

Use available supported browser/application tools. Check required fields, file selections and the current form before final submission.

Upload PDF or Word (.docx) according to the applicant's choice and the employer's accepted file types. Use PDF when both are accepted and no preference is saved. If the employer needs a different format, export that copy from the final approved wording. Record which files were actually submitted.

Some employers block automation or require a human step. Preserve prepared files and completed fields where practical; state the exact remaining action and give the correct page/files.

Before a send, inspect existing history for that requisition and intended action. After sending, retain the observed confirmation. If the response times out or the page is ambiguous, check the portal, receipt or existing status before retrying. Keep it unconfirmed if the outcome cannot be established; provide a handoff instead of risking a duplicate.

## Follow up from actual events

Use the employer's timeline, the application's real dates, prior contacts and the applicant's preferences to suggest a useful follow-up. Check for a reply, withdrawal or scheduled interview before drafting. Write a short relevant message and choose a sensible next action; do not invent urgency or repeated outreach.

Use available tools to send the requested follow-up or set the requested reminder. Save the message, recipient, observed send status and any agreed reminder. An unclear send outcome uses the same unconfirmed-state handling as an application.

## Finish the handoff

Report what was prepared or actually sent, the current state and the remaining action. Deliver usable files and the direct application link when a person must finish. Resume the affected step later without rerunning employer research or rewriting good documents.
