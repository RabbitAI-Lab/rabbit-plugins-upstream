## Description:

Helps users discover and install agent skills when they ask questions like "how do I do X", "find a skill for X", "is there a skill that can...", or express interest in extending capabilities.

This skill is ready for commercial/non-commercial use.

## Publisher:

[xztzmr](https://clawhub.ai/user/xztzmr)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent operators use this skill to find, assess, and install existing skills when a user need may already be covered by the open agent skills ecosystem.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill guides agents toward broad third-party skill discovery and installation through mutable, potentially unpinned commands.

Mitigation: Review target skill source and revision before installation, prefer verified or pinned CLI versions, avoid global installation unless needed, and keep confirmation prompts when a checkpoint is desired.
