## Description:

Save a person to ConnectMachine from what the user describes, with where and when they met.

This skill is ready for commercial/non-commercial use.

## Publisher:

[shekhar1130](https://clawhub.ai/user/shekhar1130)

### License/Terms of Use:

MIT-0

## Use Case:

People using ConnectMachine can save a new contact from a description of someone they met, including relevant meeting context. The skill checks for an existing contact and asks for clarification when needed.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Using the skill saves the supplied personal details and meeting notes to ConnectMachine.

Mitigation: Include only information intended for storage and resolve any duplicate-contact questions before proceeding.
