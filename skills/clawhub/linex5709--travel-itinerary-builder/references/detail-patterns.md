# 行程写作参考：内容深度与表达模式

本文档提炼自首尔6日亲子游手册，供生成新行程时参照。

## 每日主题风格

每日标题应兼具信息性和故事感：

| 日 | 标题 | 模式 |
|---|------|------|
| D1 | 落地首尔：数字与溪流的初体验 | [状态]：[A主题]与[B主题]的[情感词] |
| D2 | 体能迷宫与高空系留气球 | [特征A]与[特征B] |
| D3 | 汉江征服者与潮流艺术区 | [身份标签]与[场景类别] |
| D4 | 职场大探险：KidZania 全日作战 | [主题定性]：[核心项目] [时间覆盖] |
| D5 | 室内森林与月光彩虹喷泉 | [场景A]与[场景B] |
| D6 | 匠心回忆与归途市场 | [核心体验]与[过渡/告别标签] |

## 每日描述句式模板

```
今日是[主题定位词]。上午[活动A及关键时间]，下午[活动B及关键节点]。[两个时段之间的衔接逻辑
——为什么这样安排、预留了多少交通时间]。[体力消耗预判 + 特别提醒——天气/人流/时间压力]。
```

实例：
> 今日是体能消耗最高的一天。上午在汉江水上运动释放能量，中午稍作休整后转战首尔最潮的艺术
> 街区圣水洞。上午务必早出发以避开午间高温，下午全程以室内/半室内为主。

## 景点推荐理由 (why) 的写作层次

每个景点的 why 必须覆盖以下 4 个维度，按此顺序：

1. **体验独特性**（1句）：这个体验为什么不可替代？在别的城市做不到吗？
2. **孩子/同伴适配度**（1-2句）：年龄、体力、兴趣匹配度
3. **体力消耗与节奏**（1句）：累不累、室内外、冷气覆盖
4. **情感/教育价值**（1句）：会留下什么回忆、学到什么

## 操作步骤 (how) 的密度标准

- 每个景点 **4-5 步**
- 每步标注 **【区域/楼层】** 和 **预估耗时**
- 每步包含 **具体动作**（不是"逛一逛"，而是"在XX处做YY"）
- 至少 1 步涉及 **孩子的专属任务或视角**
- 最后 1 步往往是 **拍照点/出口/衔接下一站**

示例对比：

| 不合格 | 合格 |
|--------|------|
| "参观艺术馆" | "【2F K-Pop Ground】操作控制台上的按钮实时改变背景颜色和灯光效果，拍照非常出片" |
| "在汉江边玩" | "【18:30-19:30 江上航行+野餐】大人操控方向盘，孩子当导航员。在船上享用炸鸡和饮品" |

## Tips 的覆盖清单

每条 tips 至少包含以下 5 项中的 3 项：

- [ ] 价格/门票信息（₩ 韩元 / ¥ 人民币）
- [ ] 预约/购票方式（提前多久、在哪里）
- [ ] 穿着/装备建议
- [ ] 最佳时段/人流预警
- [ ] 备选方案/雨天应对

## 交通指引格式

统一格式：`从 [起点] [交通方式] 至 [终点]，约 [X] 分钟。[关键出口/地标]。`

地铁线路标注格式：`X号线 [站名] 站 [X]号出口`

时间凑整规则：
- 步行 < 5 分钟：写"步行即达"或"零步行距离"
- 步行 5-15 分钟：写具体分钟数
- 地铁：写具体线路 + 耗时（如"约 25 分钟"）
- 含换乘：分段写法（如"乘 3 号线至钟路 3 街站换乘 5 号线，全程约 35-40 分钟"）

## 工具箱条目

每条工具箱卡片 5-8 行，包含：
- 具体名称（不是"酒店"而是"明洞/忠武路区域"）
- 具体数字（票价 ₩17,000、车程 60 分钟）
- 行为指引（不是"可以坐机场巴士"，而是"乘坐 6015 路机场巴士可直达酒店门口"）
- 原因解释（不是"Google Map 不可用"，而是"Google Map 在韩国基本不可用——因为韩国法律限制地图数据出口"）

## 语气基调

- 知识渊博但不炫耀（"首尔夏日夜晚最具仪式感的体验"）
- 场景化描述（让读者脑中有画面："潺潺流水配上两岸灯光"）
- 对孩子说话的口吻（"孩子的任务是指挥官" "会笑得停不下来"）
- 诚实警告（"空调极强，务必穿薄外套" "人多拥挤，牵好孩子的手"）
