# 类比工厂（analogy-factory）

> 一个概念，5 个来自完全不同领域的类比。

## 它做什么

为同一个概念批量生产类比，每个来自一个独立领域，合起来逼近完整理解。

**不做**：只给一个类比（那个交给「通俗解释」）。

## 触发词

- 多给几个比方 / 换个比喻 / 还有什么类比
- 用不同角度类比 / 多举几个例子
- 帮我从别的角度理解

## 它怎么做

- 5 个类比必须来自 5 个互不重叠的领域
- 每个类比一句话讲完（≤ 40 字），标注它对应概念的哪一面
- 结尾指出哪个最贴切、哪个会误导人

## 示例

> 用户：给「神经网络」多来几个类比

```
1. 做饭视角：像一口大锅，几百种调料按比例倒进去 → 对应：多层加权求和
2. 交通视角：像城市路网，每个路口决定要不要放行 → 对应：激活函数
3. 游戏视角：像打怪升级，打错一次就调属性 → 对应：反向传播
4. 自然视角：像大脑神经元互相打电话 → 对应：连接权重
5. 家庭视角：像一大家子投票决定晚饭吃啥，每人分量不同 → 对应：权重差异

【最贴切的】第 4 个，因为神经网络本来就是模仿神经元设计的
【容易误导的】第 5 个，因为投票不是商量出来的，是训练出来的
```
