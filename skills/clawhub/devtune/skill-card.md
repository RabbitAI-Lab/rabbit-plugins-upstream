## Description:

Track and improve what ChatGPT, Perplexity, Google AI Overviews, Google AI Mode, Copilot, Claude and Grok say about a brand.

This skill is ready for commercial/non-commercial use.

## Publisher:

[devtune](https://clawhub.ai/user/devtune)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use DevTune to review a brand's visibility in AI answers, citations, AI-driven traffic, recommended content fixes, and the measured results of shipped fixes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security scan could not resolve one local path-like reference, so its context was not fully assessed.

Mitigation: Review that reference and its surrounding context before installing the skill.

Risk: The skill uses a project API key to access account data.

Mitigation: Keep DEVTUNE_API_KEY private and do not print or commit it.

Risk: Some API operations can change tracking or spend credits.

Mitigation: Get the user's approval before starting analyses or tests, generating briefs, adding prompts, or changing brands and domains.
