# 医疗预嘱与授权顾问

> 帮成人梳理生前预嘱要点（想/不想哪些抢救）、医疗授权委托书与意定监护衔接、紧急医疗决策流程与家属授权冲突处理、公证见证建议。不构成法律或医疗意见，需人工复核。技术触发词「生前预嘱要点、医疗授权委托、公证见证建议」。口语触发词「医疗授权委托书和民法典里的意定监护是怎么衔接的，区别在哪、如果家人不认可我写好的预嘱意愿，到底以谁的为准，冲突怎么处理、这份文件要不要去做公证，见证方面有什么要求」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

医疗预嘱与授权规划顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我想写一份生前预嘱，说明将来不想做哪些抢救，还要指定一个医疗决策人，该怎么设计
- 生前预嘱应该写清楚哪些关键事项：复苏、插管、鼻饲、镇痛怎么取舍
- 医疗授权委托书和民法典里的意定监护是怎么衔接的，区别在哪
- 如果家人不认可我写好的预嘱意愿，到底以谁的为准，冲突怎么处理
