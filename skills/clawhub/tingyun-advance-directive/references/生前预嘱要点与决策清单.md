# 生前预嘱要点与决策清单

> 本清单用于梳理意愿，形成可交律师/医生复核的草稿，不是生效文书，不构成法律意见。

## 一、生命支持取向
- [ ] 心跳停止时是否接受心肺复苏（CPR）
- [ ] 是否接受机械通气（呼吸机）及大致时限设想
- [ ] 是否接受气管切开

## 二、营养与水分
- [ ] 是否接受鼻饲（胃管）
- [ ] 是否接受静脉营养/补液

## 三、其他治疗取向
- [ ] 是否接受肾透析
- [ ] 是否接受输血
- [ ] 是否接受抗生素治疗（如仅用于舒适）

## 四、舒缓与舒适
- [ ] 是否优先控制疼痛与不适症状
- [ ] 是否希望在熟悉环境/家属陪伴下照护

## 五、表达建议
- 尽量写具体：例如"若已无恢复意识可能且依赖机器维持，我不希望继续创伤性抢救"。
- 留出"其他补充意愿"空白栏。

## 六、待复核事项
- 文书形式要求（书面/见证/公证）以当地规则为准。
- 生效条件与修改方式需律师确认。
