# 医疗授权与冲突处理

## 医疗授权委托书要点
- 指定决策人：姓名、与本人关系、联系方式。
- 授权范围：日常医疗同意、重大治疗选择、是否包含放弃/拒绝治疗的授权。
- 生效条件：通常自本人无法表达时生效，需明确触发情形。
- 形式：书面签署，建议有见证人；是否公证以当地规则与风险考量而定。

## 与意定监护的衔接
- 医疗授权聚焦医疗决定；意定监护（《民法典》第三十三条）覆盖失能后更广泛的照护与财产安排。
- 两者可并行设立，文书各自独立。
- 关系：医疗授权处理"具体治不治"，意定监护处理"谁总体负责"。

## 紧急医疗决策流程
1. 有生效授权书 → 被指定人依授权表态。
2. 无授权且无法表态 → 近亲属按顺序协商，争议以机构/当地规则为准。
3. 危及生命 → 机构依法先施救再补手续。

## 家属授权冲突处理
- 合规书面预嘱/授权优先于事后家属口头分歧。
- 有指定决策人 → 以其意见为准；无指定 → 按当地顺位协调。
- 僵局 → 医疗机构伦理协调、调解或司法渠道，不自裁。

## 公证与见证建议
- 涉及重大医疗取舍的授权，公证可增强证据效力，但是否需要以当地规则与个人风险为准。
- 至少两名无利害关系的见证人签署，避免亲属利益冲突。
- 上述均需律师结合当地规定复核。
