## Description:

Build and review high-quality technical docs as well as agent instruction files in your repository.

This skill is ready for commercial/non-commercial use.

## Publisher:

[hillstreet-ph](https://clawhub.ai/user/hillstreet-ph)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to create, review, and maintain repository documentation and agent or contributor instructions, including documentation audits and practical improvement plans.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security review was partial because two local references were unresolved, so some material was not fully reviewed.

Mitigation: Resolve and review the references before relying on the affected guidance.

Risk: Documentation or agent-instruction changes may introduce inaccurate or misleading guidance if repository details are not checked.

Mitigation: Verify proposed commands, paths, policies, and links against the target repository and its current workflows.
