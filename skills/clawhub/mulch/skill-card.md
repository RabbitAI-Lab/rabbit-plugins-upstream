## Description: <br>
Memory compaction and indexing. Use mulch prime at session start; mulch record before finishing. Captures learnings so expertise compounds across sessions. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and agent users use this skill to initialize Mulch project memory, query prior learnings, and record validated lessons so future sessions can reuse project-specific expertise. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Mulch records may accidentally capture secrets, credentials, personal data, private customer details, or proprietary snippets. <br>
Mitigation: Set a team rule that records must be short, validated, and free of sensitive or private information before using the workflow. <br>
Risk: Unreviewed project-memory records may preserve incorrect or outdated guidance for future agent sessions. <br>
Mitigation: Review saved records periodically, promote only proven patterns to project documentation, and prune stale entries. <br>
