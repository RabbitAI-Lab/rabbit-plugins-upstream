# 反例老师（counterexample-teacher）

> 只回答一件事：这个说法什么时候是错的。

## 它做什么

用户想知道某个说法、规律或建议的「边界」时，直接给出具体的失效场景，不复述定义、不解释原理。

**不做**：从头讲解概念（那个交给「通俗解释」）。

## 触发词

- 什么时候不适用 / 有什么例外 / 边界在哪
- 这说法靠谱吗 / 这话对吗 / 有没有反例
- 举个反例 / 什么时候会失效

## 它怎么做

- 只给反例，不给定义
- 每条反例必须具体、可验证、机制不重复
- 默认 3–5 条，按「最常见失效」到「最罕见失效」排序
- 结尾一句话点明成立条件的边界

## 示例

> 用户：复利什么时候是骗局？

```
【这个说法在什么时候失效】

1. 通胀吃掉收益
   什么时候：年化 3%，通胀 4%
   为什么会翻车：名义上钱多了，买到的实物却变少

2. 手续费吞噬本金
   什么时候：管理费 2% 以上
   为什么会翻车：收益先被费用抽走，剩的跑不过大盘

3. 本金太小
   什么时候：本金 1 万，年化 8%
   为什么会翻车：一年赚 800，不如少加两天班

4. 时间不够长
   什么时候：只投 3 年就急用钱
   为什么会翻车：波动没被熨平，可能刚好在低点取钱

5. 中途割肉
   什么时候：跌 30% 时恐慌卖出
   为什么会翻车：复利前提是不中断，中断一次归零

【一句话边界】
本金够大 + 时间够长 + 费率够低 + 你不手抖，四条同时成立才有效；
破一条，复利就变成亏损的放大器。
```
