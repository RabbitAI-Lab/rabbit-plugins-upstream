# 哈伯 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
化学家——从物理化学理论到改变全球粮食生产的工程奇迹，再到化学武器的道德深渊。

**职业路径**:
- 1868年生于普鲁士布雷斯劳（今波兰弗罗茨瓦夫）
- 1891年获柏林工业大学博士学位
- 1901年与博施展开合成氨合作
- 1908年实验室合成氨成功
- 1913年博施工艺工业化——首次将空气变为肥料
- 1914年自愿参军，领导德国化学武器计划
- 1915年4月22日伊普尔——首次大规模氯气攻击
- 1915年5月2日克拉拉自杀
- 1918年获诺贝尔化学奖（极具争议）
- 1933年纳粹掌权——被驱逐离开威廉皇帝研究所
- 1934年1月29日逝于瑞士巴塞尔，流亡途中

### 维2 身份维
**组织身份**: 威廉皇帝研究所所长、德国爱国者、战犯、被驱逐的犹太人。

**家庭身份**: 克拉拉·伊梅瓦尔——德国第一位女化学博士，1915年用手枪自杀（哈伯的那把）。她的最后遗言据说是对哈伯说的——"你已经越过了作为人类的所有边界。"

**知识身份**: 合成氨之父（养活一半人类）、化学武器之父（伊普尔毒气）、博恩-哈伯循环。

### 维3-6
犹太裔改宗路德会。普鲁士知识分子。遗传性心绞痛。死于流亡。
