# 吉登斯 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
英国社会学家——从古典理论综合到现代性分析再到首相的学术顾问。

**职业路径**:
- 1959年：赫尔大学本科（社会学和心理学）
- 1961年：伦敦政治经济学院硕士
- 1974年：剑桥大学博士
- 1987-2003年：剑桥大学社会学教授
- 1997-2003年：伦敦政治经济学院院长
- 1998年：出版《第三条道路》——在英国大选前成为布莱尔的"理念基础"
- 2003年后：荣誉退休教授——活跃于全球政策智库

### 维2 身份维

**家庭身份**: 伦敦工薪阶级家庭——第一个上大学的人。

**社会身份**: "第三条道路"的学术设计师——这使他在学院激进左翼中成为"新自由主义的帮凶"，在政治右翼中成为"社会主义的复活"。

**知识身份**: 结构理论的综合者；晚期现代性的分析者。
