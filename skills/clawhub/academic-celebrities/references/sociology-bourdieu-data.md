# 布迪厄 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
社会学家——从民族志田野到统计数据分析到宏大理论——布迪厄的学术道路是一个从"外围到中心"的运动。

**职业路径**:
- 1951年：进入巴黎高等师范学院（哲学系）
- 1954-1955年：巴黎大学哲学教师资格考试
- 1955-1958年：在法国军队服役，被派往阿尔及利亚（当时的法国殖民地，正值独立战争）
- 1958-1960年：阿尔及尔大学任教。这段经历是他的"民族志田野"——在卡比利亚地区做人类学调查——"前资本主义惯习"的发现——理解为什么资本主义不能简单地'吃下'一个农业社会
- 1964年：《继承者》（与帕斯隆合著）——"大学不是民主化的工具"
- 1970年：《再生产》——教育系统是一台将社会不平等转化为"能力差异"的符号转换机
- 1979年：《区隔》——大规模问卷调查+理论分析的结合——品味的社会地图
- 1981年：当选法兰西学院社会学讲座教授
- 1993年：《世界的苦难》——与22位研究者合作的访谈调查
- 2002年：因癌症去世

### 维2 身份维

**组织身份**: 法兰西学院的教授——但他在法兰西学院中以"好斗的异见者"著称。

**家庭身份**: 父亲是贝亚恩地区的邮差。母亲来自农民家庭。布迪厄的一个关键童年记忆：他考上巴黎高师后——父亲送他到火车站——"父亲穿着一件星期天才会穿的夹克——但他的步态泄密了——邮差的身体在'大事'中不知道怎样站。"

**社会身份**: 反新自由主义的公共知识分子——1995年法国大罢工时他拿着扩音器站在铁路工人中——"我和一个邮差的儿子站在你们这里。"
**知识身份**: "惯习-场域-资本"的理论组合。法国甚至全球社会学"必须引用"的思想家。

### 维3 名人维
布迪厄的文化参考：埃利亚斯（身体的驯化历史）、马克思（资本的逻辑）、韦伯（"支配"的合法性）、潘诺夫斯基（"惯习"一词来源于潘氏的经院艺术研究中的"habit"）。
