# 老子 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
周王室守藏室之史（国家图书馆/档案馆馆长）——中国古代最神秘的哲学家，道家学派的开创者和最高象征。

**职业/事迹**:
- 据司马迁《史记》记载：姓李名耳字聃，楚国苦县（今河南鹿邑）人
- 周王室"守藏室之史"——掌管王室藏书和国家档案
- 孔子曾赴周向老子问礼——老子回答："子所言者，其人与骨皆已朽矣，独其言在耳。"
- 见周王室衰落，骑青牛出函谷关西去——关令尹喜请求他著书
- 于是写下"五千余言"——《道德经》，后"不知所终"

### 维2 身份维
**组织身份**: 周王室史官——中国古代最高的官方知识保管机构。

**知识身份**: "道家学派始祖"——《道德经》是翻译次数仅次于《圣经》的世界文本。"道可道，非常道；名可名，非常名"——对语言局限性的警示比维特根斯坦早了两千多年。

### 维3 名人维
老子——中国哲学史上最神秘的人物。连"老子"这个称呼（"老先生"）都不是真名。他的出生、生平、死亡都笼罩在传说中——据说他母亲怀胎81年（道教说法），生下来就白发苍苍（故称"老"子）。画像中的老子：白发白须、骑着青牛、一副与世无争的超然。

### 维4-6
- 时代：约前6世纪（春秋末期）——周王室衰微、礼崩乐坏、诸侯争霸
- 出生地：楚国苦县（今河南鹿邑）——地处中原南部的楚国
- 语言：古代汉语——《道德经》大量使用韵文（"道"文体本身即"哲学"与"诗歌"的合一）
- 思想来源：据传来自"黄帝书"（黄老之学）和上古巫史传统。"反者道之动，弱者道之用"可能来自对"水"和"婴儿"等自然现象的观察
- 后世影响：道教（被奉为"太上老君"）、魏晋玄学（王弼注老子）、中国美学（"大音希声，大象无形"）、政治哲学（"无为而治"）、中医（身体的小宇宙观）、武术（太极拳的"以柔克刚"）
