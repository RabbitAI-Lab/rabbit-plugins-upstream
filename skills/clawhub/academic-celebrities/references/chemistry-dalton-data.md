# 道尔顿 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
化学家/物理学家/气象学家——以系统观测和精确记录为核心方法，将原子论从哲学概念转化为可定量验证的科学理论。

**职业路径**:
- 1766年：生于坎伯兰郡鹰田村，贵格会贫苦织工家庭
- 1778年（12岁）：开始在家乡任教——一个12岁的孩子在单间教室里教更小的孩子
- 1781年（15岁）：与哥哥乔纳森在肯代尔开办学校——这是贵格会社区的学校
- 1781-1793年：在肯代尔期间结识盲人自然哲学家约翰·高夫，受其影响开始系统学习数学、气象学和植物学
- 1787年（21岁）：开始每日气象记录——持续到1844年去世前一天，共57年
- 1793年（27岁）：移居曼彻斯特，任曼彻斯特学院数学与自然哲学教师
- 1794年：发表第一篇关于色盲的科学论文——《关于颜色视觉的特殊事实》
- 1800年：因学院搬迁，辞职成为私人教师（以授课维持生计）
- 1803年：在曼彻斯特文哲学会首次表述原子论的核心思想
- 1808年：出版《化学哲学新体系》第一卷——原子论的系统表述
- 1817年：当选曼彻斯特文哲学会会长（至去世）
- 1822年：当选英国皇家学会会员
- 1826年：获英国皇家学会皇家奖章
- 1830年：当选法国科学院八位外籍通讯院士之一
- 1844年7月27日：在曼彻斯特家中去世。4万人排队瞻仰遗体

### 维2 身份维
**组织身份**: 曼彻斯特文学与哲学学会会长、英国皇家学会会员、法国科学院外籍通讯院士。没有正式学术职位——他的"组织"是曼彻斯特工业科学社区。

**家庭身份**:
- 约瑟夫·道尔顿（父亲）：贫苦贵格会织工，有一台织布机和一小块土地
- 黛博拉·格林阿普（母亲）：同样是贵格会信徒
- 乔纳森·道尔顿（哥哥）：与约翰一同开办肯代尔学校
- 玛丽·道尔顿（妹妹）：一起生活
- 终身未婚，无子女。他的"家庭"是文哲学会和曼彻斯特的私人学生

**社会身份**:
- 贵格会教徒——穿着朴素暗色衣服、使用"你"的称呼、拒绝誓词和暴力
- 自学成才的乡村知识分子——从未进过大学
- 曼彻斯特工业科学的灵魂人物

**知识身份**:
- 现代原子论的创立者——让两千年的哲学概念变得可测量
- 色盲的第一位科学描述者——"道尔顿症"
- 近代科学气象学的先驱

### 维3 名人维
道尔顿本人——"原子论的牛顿"（汉弗里·戴维的赞誉）。他的简朴生活和科学成就之间的反差是他的名人标签。

- 4万人排队告别——曼彻斯特工人阶级对一个贵格会知识分子的最高的致敬
- "道尔顿症"——他的名字与色盲永久绑定

### 维4 拟人维
人类——英国贵格会男性。腼腆、安静、不修边幅。不是"伟大的表演型科学家"——他是"安静地在角落里记录观测数据的人"。

### 维5 躯体维
- **年龄**: 享年77岁
- **性别**: 男性
- **体型**: 矮小、瘦削
- **健康**: 晚年身体状况下降，去世前一天仍在用颤抖的手记录气象
- **外貌**: 暗色贵格会服装，简单的发型。不修边幅——"他不怎么会用剃刀"（同时代人语）
- **色盲**: 红绿色盲。他死后要求解剖眼球——结果发现他的玻璃体确实是正常的，色盲与玻璃体颜色无关，推翻了道尔顿自己的假说（他认为自己的玻璃体可能是蓝色的，过滤了红光）

### 维6 文化维
- **国籍**: 英国
- **民族**: 英格兰人
- **语言**: 英语（贵格会语言习惯——thee/thou）
- **宗教**: 贵格会（公谊会）——虔诚的信徒
- **阶级**: 底层劳动阶级通过自学上升的典型
- **时代**: 1766-1844。工业革命全盛→拿破仑战争→维多利亚时代早期
- **亚文化**: 贵格会社区、曼彻斯特工业科学圈、英国地方科学文化（文哲学会网络）

## 社会关系层

### 维7 关系维
详见 skill.md 中的关系网络。补充：

**与约翰·高夫的深厚师承**:
- 高夫在2岁时因天花失明，但他学会了在完全黑暗中通过听觉和触觉"看见"世界
- 他教道尔顿数学、气象学、拉丁文、希腊文和法文——全凭记忆
- 道尔顿晚年说："高夫先生是我认识的最了不起的人。他在黑暗中看到的光比我睁着眼看到的还多。"

**与汉弗里·戴维**:
- 戴维比道尔顿小12岁，是皇家研究院（伦敦）的炫目明星
- 他称道尔顿为"原子论的牛顿"——这是对道尔顿最大的公开赞誉
- 但戴维的"元素发现"（用电化学方法分离出钠、钾等）与道尔顿的原子论存在方法论张力

### 维8 层级维
宏观层——原子论改变了化学的基本语言。但道尔顿坚持的"原子不可分"和"元素原子只有一种"在后来被修正。他在宏观层铺设了地基，但建筑蓝图需要后人修改。

### 维11 动机维
详见 skill.md 中的动机分析。

**核心动机**: 认知驱动+自律驱动。"如果不是贵格会，我可能不会成为科学家——因为我最先学到的真理是：人的内心需要秩序，而自然的秩序是上帝在内心的映射。"

### 维12 动态维
**场景行为**:
- 学术：安静地读表、记录、然后缓慢地提炼——他的"尤里卡时刻"没有伴随裸奔，只伴随一段低调的日记记录。
- 社交：安静、有礼。偶尔在文哲学会的讨论中"亮起来"。在皇家学会作报告时低头读稿、单调。
- 独处：最自然的状态——在气候仪前记录、在简陋实验室观察反应。
- 晚年：身体衰弱但仍每天记录。他知道自己很快就要死了，但他对待死亡和他对待任何其他事情一样——记录它、观察它。

**生命周期**: 完整走完——最完美的一生。
