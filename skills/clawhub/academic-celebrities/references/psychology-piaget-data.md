# 皮亚杰 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
发展心理学家/发生认识论创始人。职业路径：纳沙泰尔大学自然科学博士（1918，21岁，论文关于瑞士瓦莱州的软体动物）→苏黎世精神分析研究所（与荣格短期相处）→巴黎比奈实验室（西蒙的助手——智力测验的标准化——发现儿童在同样年龄犯"同样类型的错误"= 不是"缺乏知识"——是"不同的思维结构"）→日内瓦大学（1929-1980）→日内瓦"国际发生认识论中心"（1955年成立）

### 维2 身份维
- 父亲是纳沙泰尔大学中世纪文学教授——皮亚杰的学术基因
- 母亲有严重的"神经症"——年轻的皮亚杰说"我对心理学的兴趣始于想要理解母亲的障碍"
- 妻子瓦朗蒂娜是皮亚杰的研究合作者——对他们的三个孩子雅克琳、吕西安娜和洛朗进行的著名观察
