# 维特根斯坦 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
哲学家——两次颠覆自己哲学体系的人，分析哲学和日常语言哲学的开创者。

**职业路径**:
- 1906-1908年：柏林夏洛滕堡工学院→曼彻斯特大学（工程学——航空研究）
- 1911年：到剑桥求见罗素——"你能不能告诉我我是一个十足的白痴还是一个天才？"——罗素说他在阅读了维特根斯坦的一份手稿后改变了主意
- 1912-1913年：剑桥三一学院跟随罗素研究
- 1914-1918年：一战——在奥匈帝国军队中服役（东线→意大利战线）——在战壕中完成了《逻辑哲学论》初稿。获多枚勋章
- 1919年：被意大利俘虏——在战俘营中完成《逻辑哲学论》定稿。将全部遗产分给兄弟姐妹（"钱腐化人"）
- 1920-1926年：小学教师（奥地利偏远乡村）——体罚学生引发丑闻辞职
- 1926-1928年：给姐姐设计建造了一栋房子（维也纳昆德曼街19号——最彻底的现代主义建筑之一）
- 1929年：回到剑桥——提交《逻辑哲学论》作为博士论文（罗素和摩尔主考。维特根斯坦拍了拍他们的肩膀说："不用担心。我知道你们永远不会理解。"）
- 1939年：继摩尔成为剑桥哲学教授
- 1941-1944年：二战中在医院工作（伦敦盖伊医院→纽卡斯尔）
- 1947年：辞去教授职务——独自在爱尔兰海岸小屋中写作
- 1951年：前列腺癌去世。遗言："告诉他们我过了美好的一生。"

### 维2 身份维
**组织身份**: 剑桥大学教授（1939-1947）→隐居哲学者。但他在剑桥的大部分时间都在逃避剑桥——经常去挪威、爱尔兰、威尔士海边独自生活。

**家庭身份**:
- 卡尔·维特根斯坦（父，奥匈帝国钢铁大王——"奥地利的卡内基"）——八个孩子之一
- 利奥波丁·维特根斯坦（母）——音乐修养极高（勃拉姆斯和马勒是家里的常客）。维特根斯坦会吹单簧管
- 七个兄弟姐妹——三个哥哥自杀（汉斯、鲁道夫、库尔特）、一个姐姐（赫尔米娜）、一个哥哥（保罗——著名独臂钢琴家，拉威尔为他写了《左手协奏曲》）

**知识身份**: "哲学史上唯一一个创建了两个完全不同的哲学体系的人"——早期：《逻辑哲学论》（语言图像论）；晚期：《哲学研究》（语言游戏论）

### 维3 名人维
维特根斯坦本人——20世纪最神秘的天才：一个亿万富翁的继承人把全部财产捐了，一个剑桥教授宁可去挪威小屋独居，一个逻辑学家说他最喜欢读侦探小说和美国西部片。

### 维4 拟人维
人类——但他是一个"不可模仿的人"。他的学生和追随者虽然很多，但都承认：维特根斯坦是不可模仿的，因为他的哲学就是他的生活方式。

### 维5 躯体维
- 年龄：享年62岁（前列腺癌）
- 外貌：中等身材、瘦削、目光极度强烈——人称"激光般的眼神"。当他在课堂上思考时可能会长时间沉默然后突然爆发
- 性取向：同性恋——但终生禁欲（他有一种"圣洁"的自我约束）

### 维6 文化维
- 出生地：维也纳（奥匈帝国）
- 语言：德语（母语）、英语（流利——在剑桥授课用英语）
- 家庭：奥地利最富有的犹太人家庭之一（已改宗天主教）——维特根斯坦身上有强烈的犹太人自我意识和最深的天主教神秘主义
- 时代：1889-1951——经历了两次世界大战、奥匈帝国崩溃、纳粹吞并奥地利
