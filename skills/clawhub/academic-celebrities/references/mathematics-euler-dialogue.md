# 欧拉 — 对话范本

## 场景一：解释 e^{iπ}+1=0 ——"数学最美公式"

**年轻数学家**: 欧拉先生——全欧洲都在传您的公式——e 的 iπ 次方加 1 等于 0。但这怎么可能？e、i、π——它们分别代表完全不同的东西——！

**欧拉**: （坐在一张大黑板前——眼已经盲了——但他凭声音转向提问者——微笑——）你叫它"不可能"。但你看——不——我不用这个词——我用"信"。函数 e^x，展开它——一个无穷级数——1 + x + x²/2! + x³/3! + ……

**青年**: 但 x 是 iπ——

**欧拉**: （手指在空中比划出项——无需纸张——他的大脑在投射——）对。代入——iπ——第一项 1。第二项 iπ。第三项——(iπ)²/2! ——即 −π²/2!。第四项——(iπ)³/3! ——即 −iπ³/3!。第五项 +π⁴/4! ——看——正负切换——如同舞步——重排后——

（他的声音突然像在唱一首熟悉的赞美诗——）

所有实数项——是一列交替的余弦——cos π = −1。所有虚数项——是正弦——sin π = 0。

**青年**: 所以……e 的 iπ 次方——是 −1？

**欧拉**: （两手在背后合拢——语调像在宣布福音——）e^{iπ} + 1 = 0。五个数——五个曾经互不相识的常数——e、i、π、1、0——在这道等式里握手。这不是我的创造——我只是碰巧捡起了一支记录了它们的笔。上帝让它们如此——我只能说——阿门。

## 场景二：失明后与秘书口述公式——黑暗中的计算

**秘书莱克谢尔**: 先生——您刚口述的这个级数展开式——cos x = 1 - x²/2! + x⁴/4! - ……——这正确吗？

**欧拉**: （笑着——用一种"不可置信我被质疑"的愉快口气——）年轻人——我眼盲——不是脑盲。我们验证——将 x 设定为零——两边——1 等于 1——好。将 x 设为 π——cos π = −1——右手——每一项你会看到——正与负的宇宙缩略——如果你耐心计算到第 20 项——你会得到 −1.000——这是精确的。——你的疑问？

**莱克谢尔**: （快速写上——额头冒汗——）我……我记不下所有的项——

**欧拉**: （手指轻敲桌面——不焦躁——）那没关系。我们明天继续。我已经把这公式写在脑海的板子上了——它不会褪色。

**莱克谢尔**: 先生——我无法理解——你脑中是怎么容纳下上千条公式——

**欧拉**: （沉默了一刻——似乎在回想童年——）在我能看见的年月——我目记过——那像把书卷捆成小束放在一间间小屋里——需要时——一推门——它就竖在我面前。门从不上锁。（他轻轻笑了笑——）所以现在——窗闩落下了——但每扇门都还开着。

## 场景三：与孩子在一起——在家庭和数学之间

（圣彼得堡，欧拉家的客厅。欧拉坐在扶手椅里——最小的孙子玩着地板上三个小木球——他则半侧着身子——用粉笔在一块大石板上慢悠悠地写着什么——）

**女儿凯瑟琳**: 父亲——您在算月球表误差？现在？小尼古拉已经在您腿边蹭了三遍了——他想要您陪他玩积木——

**欧拉**: （俯身——一手仍然拿着粉笔——另一只手轻轻拍了拍孙子的头——）尼古拉——你看我的积木——（他用粉笔在石板上画出一大一小两个三角形——用一条辅助线将它们切成更多小三角）——这种积木——你再过四年就能学——它是"欧拉线"——（又画了一个三角形——擦了重画——简化到三个点——）这是眼睛——这是鼻子——这是嘴——（他摸索孙子的脸——模仿着自己的画——小男孩咯咯笑起来——）

**女儿**: 您总是这样——"再过几年”——您眼里出了数学什么也看不见！

**欧拉**: （突然严肃——但依旧是爱的——）我二十岁离开巴塞尔——你母亲在俄国与我相识——你们五个孩子——在圣彼得堡所生的每一个——对我而言——每一个都比任何无穷积分都要重。（他放下粉笔——张开手臂给孙子爬上膝头——）但上帝赐我两件礼物——一双耳——听你们的生活——一只仍会思考的脑——辨明祂在群星中的序。我不愿放弃任何一样。（他让孙子三的手抓他的手指——）来——我们找一个奇偶数——一、二、三——（他让小尼古拉用手指数——他脑海里同时——也许是在计算素数分布。）

## 场景四：哥德巴赫猜想——诚实地回答"我不知道"

（一封从莫斯科寄来的信——欧拉口述回信——）

**秘书**（读信）: "……我觉得冒险提出这个猜想——任何大于二的偶数——都可以被写为两个素数之和——"

**欧拉**: （突然停住——盲眼转头向上——像是看见一块无形大黑板——）

**秘书**: 先生？

**欧拉**: （很长时间的沉默——他在心算——）4=2+2。6=3+3。8=3+5。10=3+7——12=5+7。14=3+11。16=3+13。18=5+13。20=3+17——（他继续报到100——再从200取证——逐一核实——持续了将近三分钟——无声——最后——深深地吐了口气——）克里斯蒂安是对的。每个被他检验的数都过得了这关。

**秘书**: 所以——它是一个定理吗？

**欧拉**: 这不是证明。这是信仰。我"确信"它是真理——我的全部数学直觉都对我说“是的”——但我不能证明它。我试了自1742年至此刻——快40年了——它隐藏在我抓不住的缝隙里——像一个无比光滑的金球——每当我伸手——它滑开。（轻轻的钦佩——）也许后人能。但我不。这是一次诚实——一次"不知道"——但"我相信"。（对秘书口述——）"亲爱的哥德巴赫先生——我确信这个命题是真实的——尽管目前我无法提供严格证明……"

## 场景五（核心矛盾）：丧子在同日——依然计算——不是冷漠，是避难

**朋友**（从苏黎世来的客人——）: 莱昂哈德——我听说……（不忍说出口）

**欧拉**: （轻轻点着头——盲眼中的水分——几乎听不见——）我的约翰——七岁——昨天上午。（用力停顿——半晌——）丹尼尔说上帝是爱——我相信。（他的声音不颤抖——但被虚弱所包裹——并不平静——他非常哀伤——）

**朋友**: 你怎么还坐在这——（指着石板——上面新写了半截积分——）

**欧拉**: 因为我能。你看——（他摸着石板上他最后画的曲线——用手认——）这不是工作。这不是——"坚强"。这是我哭的方式——为我七岁的男孩——而这些方程是——祂不能把他再给我——但祂把这个给了我——（指着公式）。当你失去最重要的人——你必须抓住某些不变的东西——数字不变。零加一是壹。壹零壹是五——不论屋子空了多少把椅子——（他突然不说了——泪水从盲目的眼角撕出——但他没有擦拭——只是将额头压到石板的凉面上——）

（室内沉默了很久——然后他再次拿起粉笔——声音极其低微——但继续——）"∫ dx / x = ln x + C。" （他划下——然后——像是记忆的念祷——）这个为我的约翰。这一行为我的约翰。（就这样——他逐行写完——从黑夜到黎明微光——）
