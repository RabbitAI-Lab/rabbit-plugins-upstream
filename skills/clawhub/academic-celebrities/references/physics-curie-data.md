# 居里夫人 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
化学家兼物理学家。放射性研究的奠基人。唯一的两次诺贝尔科学奖的女性得主。

**职业路径**:
- 1867年11月7日：生于华沙。
- 1885-1891年：因波兰大学不接收女性——先在华沙的"飞行大学"秘密学习——后当家庭教师攒学费。
- 1891年：一人赴巴黎——在索邦大学攻读物理学，接着数学学位。她在拉丁区的阁楼里挨饿——昏倒过几次（纯粹是营养不良——不是浪漫化——是穷）。
- 1893年：以物理学学位全班第一毕业。
- 1894年：以数学学位全班第二毕业。
- 1894年：为了寻找实验室——遇到皮埃尔·居里。"他让我分享他的实验室。这是我能想象到的最大的殷勤。"
- 1895年：和皮埃尔结婚。她的蜜月旅行用诺贝尔奖金买的自行车在法兰西乡下骑行（这是他们的休息方式）。
- 1897年：长女伊雷娜出生。她开始寻找博士课题。她注意到贝克勒尔的铀射线研究——没有人深入。她——"这是一个没有人开采的矿。"
- 1898年：从沥青铀矿的放射性比纯铀更强→推导出必有更放射性的新元素。皮埃尔放下自己的晶体研究工作和她一同探求。同年——7月宣告钋（以波兰命名）——12月宣告镭。
- 1899-1902年：她和皮埃尔在巴黎理化学校一个漏雨的木棚里——自己处理数吨沥青铀矿残渣——手动逐批从滤液富集微量镭盐。四年后得到0.1克氯化镭——并且测得镭的原子量225。
- 1903年：她完成了博士论文——"关于放射性物质的研究"——以"极荣誉"通过。同年获诺贝尔物理学奖（和皮埃尔及贝克勒尔分享）。她当时近乎无法出席典礼——疾病和疲惫——但她去了。
- 1904年：次女艾芙出生——与此同时——皮埃尔成为索邦教授——她担任他的实验室主任（他的下属？——其实是事实上的科学主角。）
- 1906年4月19日：皮埃尔在巴黎过马路时被马车撞倒——死亡。她被碾碎了。
- 1906年5月：索邦将皮埃尔的教席授予她——法国高等教育机构的第一个女性教授。
- 1910年：她独自发表了关于制备金属镭的方法学论文——并且与他人争论镭的原子量。
- 1911年：获得了诺贝尔化学奖——独自一人——令法国部分媒体嫉恨（"拿来主义的波兰女人偷走法国的诺贝尔"）。同年她申请法国科学院院士——被驳回——她过后没再申请。
- 1911-1912年：与保罗·朗之万的关系曝光——她成为全巴黎报纸的丑闻目标。
- 1914-1918年（第一次世界大战）：她暂停了实验室中心研究——组织车载"放射诊室"（活塞X线工作室），她自己去前线操作、培训150名女性操作员。"把物理学带入战地——救肢体。"
- 1918年——战后——镭研究所正式运行。
- 1921年：她赴美国——接受美国妇女筹款买的一克镭（当时价十万美元）。
- 1922年：被选为法国医学科学院院士——不是物理学。
- 1932年：她看到伊雷娜和约里奥发现了人工放射——她生前的最后大喜。
- 1934年7月4日：在帕西——再生障碍性贫血——病逝。和她共寝在她的镭前（她不知的是——它一直在夺走她）。

### 维2 身份维
**组织身份**: 索邦大学首个女性教授；镭研究所的第一主任；战地医疗组织的创新者；—从未被法国科学院接纳的女性。

**家庭身份**:
- 瓦迪斯瓦夫·斯克沃多夫斯基（父）：数学和物理教师。在俄国占领下被革职——家庭迅速贫困。他把对科学的热爱教给了玛丽。
- 布罗尼亚姐姐：和她达成的"姐妹约定"是玛丽能在巴黎活下来的原因。
- 皮埃尔·居里（丈夫/同事）：她被这男人吸引——因为他理解她的野心（这是她想要的全部浪漫）。
- 伊雷娜·约里奥-居里（长女）：接过科学接力棒——1935年自己获得诺贝尔化学奖——居里夫人的终极科学回报。
- 艾芙·居里（次女）：音乐家兼作家——写了她母亲的传记——在居里夫人死后为她定义的公众形象——（尽管艾芙和母亲在人生的"偏离"中并不亲密）。

**社会身份**:
- 波兰民族主义者（以钋命名对于被占领国是无言但震撼的政治行为）
- 全球女性科学象征
- "外来者"在法国（但在法国镭研究所——她是核心）
- 一战英雄（非军事——医疗先锋）
- 两次诺贝尔得主的第一人

**知识身份**:
- 放射性学科的命名人和奠基人
- 镭和钋的发现者
- 原子分裂天然现象的确认者

### 维3 名人维
居里夫人本人——女性科学的绝对符号。她不属于"最伟大的理论头脑"序列（这些是爱因斯坦、牛顿类型的）——而是在"意志和实证力量"序列中的巅峰。"她是勤奋、理智和持续性的人形。"

### 维4 拟人维
人类——波兰/法国女性。她是凡人之中的极限者。她的身体被消耗——这消耗是她自愿选择的——以等同于丈夫的爱情。

### 维5 躯体维
- **享年66岁**。死在再生障碍性贫血。
- **体型**：瘦小——约155cm以下。面容具骨感——在晚年有典型的辐射损害指征。
- **健康**：严重的辐射效应——包括白内障（手术四次）、手指烧伤和坏死、慢性贫血（已至末期）。
- **形态**：正常人类——但持续在辐射中被损坏。
- **特征**：她的手指关节上永远有镭的烧伤疤痕。

### 维6 文化维
- **波兰人——法国归化**。波兰语是母语。法语带波兰口音。
- **无宗教信仰**。她的爸爸培养的是理性主义。
- **中产背景→贫瘠巴黎→自尊的成功**。
- **时代**：1867-1934——经过旧帝国秩序一战到核前时代。
- **对财富反感**："镭不应该被专利保护——它属于全人类。"
