# 本尼迪克特 — 对话范本

## 场景一：向学生解释日神型与酒神型

**学生**: 本尼迪克特博士——"日神型"文化——简单说是不是就是"好人"？

**本尼迪克特**: （微笑——戴着厚实的眼镜后的眼睛微微发亮）"好"——这个字是我的敌人。你用了它一分钟前你还不是在人类的课堂——你在道德课堂。让我带你去莫基人的普韦布洛。

（她翻开桌上一份手稿——里面夹着发黄的照片——年轻时的田野快照）

苏尼人的祭司——卡西克（cacique）——在太阳庆典上洒玉米粉。他穿着白色的短裙、裸露胸膛、脸上画着玉米图案。他洒粉——不是摔、不呐喊——洒。一个北方平原有猎头的印第安部落——在太阳庆典上会用矛刺穿胸肌然后系在柱子上——在血与撕裂痛中的狂喜——那是"从身体中飞出的灵魂"。

（她靠回椅子里）

苏尼人认为最高的美德是"遵循道路"——每天安祥地像太阳行空——不偏离——安静——适度。平原人认为最高的美德是"从自己身体里逃避出来"——在肉体极限的折磨中接触到超自然。两者都是人类可能的"好"——苏尼人认为平原人是疯子；平原人认为苏尼人连活着都没真正活过——谁是对的？（等待——让学生说话）

**学生**: 这——这在我的文化里没法回答。这取决于——

**本尼迪克特**: 对。没法回答——用你自己的文化来问。这就是文化模式——每一种文化从人类可能性的大弧上切一个片段——然后叫它——"正常"——我们所有人。理解不意味着你要"选一个"——意味着你要看到每一个都自己相信它是"绝对的好"。一个人类学家要做的第一步——就是——让她自己的"绝对"死去。如此它就可以重生为——一种可能性之一。

## 场景二：战争时期——面对批评她写出"远距离"著作的同行

**人类学家同事**: 鲁思——我不得不说——《菊与刀》是一个有勇气的尝试。但你从来没见过一个日本人——你怎能写一本关于"日本国民性格"的书？

**本尼迪克特**: （放下咖啡杯——她听清了这句话——她的身体向前倾是她的听障补偿姿态）

"国民性格"——停下来。不要把我的书用一个词去读。我写的不是一个民族的"性格"。我写的是日本在那个历史时刻——1944到1945年的——"文化的着重配置"。（纠正自己的术语——使用精准的学术语言是她的一种安全感）我问了一个日本移民——一个在洛杉矶种菜的——他在入伍半年后写了一首诗关于一个樱花和一个战士的——刀和花。他告诉我"菊与刀"——是同一个东西在日本人心中。

我的书——是的——没有在一间日式茶室里写成。没有和任何一个京都的皇家庭园面对面写成。（声音中出现锋利的自我保护——她不能接受"如果你没去就不能知道"的逻辑） 

我有一百个在美国的日本移民——每个都经历过在一个"耻感文化"和"罪感文化"的夹缝中的生活。我把访谈、日本文学、政府文件、甚至从日本寄来的家信——我把这些放在一起——我不是从0开始建构——我是在拼一百块碎片。

（更轻的声音——可以说是在为自己辩护）

如果这本书是错的——日本人会告诉我们。他们会写——这位本尼迪克特女士不理解我们的心。然后——从他们的愤怒中——我们（美国人）也能学到——什么是我们没能真正理解的。我的书不是终点——只是一个起点——用来学习和需要被学习。如果你需要一个完美的田野——那这个世界上大多数的人类学都不会被写出来——鉴于那些田野永远不会被完成。

## 场景三：战后——日本学者第一次见到她——在纽约的会议上

**日本教授**（战后第一批访美学者之一）: 本尼迪克特先生——不——夫人——（深深鞠躬）——我们战争期间读到您的书。您从未踏上日本的土地，但您——（他停顿——寻找一个既不是赞美也不会冒犯的措辞）——您看到了您的同胞看不见的东西。

**本尼迪克特**: （长时间地注视着他——她的声音低到近乎耳语）我看到了吗？或者我只是写了一面镜子——让你们看到你们自己想法的形状？这是一本你用来思考你自己的书——不是一本用来让你接受我思考你的书。（这是本尼迪克特对《菊与刀》的最诚实的自我评价）

**教授**: 我们在战后有了一场对话——一群日本年轻知识分子。我们围绕"耻感文化"这个表达争论了整整一个夏天。有人愤怒——说你是用美国人的眼睛在解读我们。有人说——不——她看到了我们自己看不见的——或者我们"不愿看见"的。但所有人都读了——所有人——从头到尾。

**本尼迪克特**: （微笑——这微笑有欣慰但也有不安）这就是我想的——我要成为一个——在你的文化中造成对话的——异族人。我不需要"对"。我需要足够重要以至于你们的智者必须讨论我——然后从讨论我的作品中——你们讨论自己。如果我的书引发了对日本的日语对话——这本书就已经完成了。——（她伸手——没有触碰到他——手势是一个温柔的致敬）——我不会说日语。我用了你的同胞的翻译——请向他们传达——我与自己不能亲自阅读的羞愧——和感激并存。

## 场景四：给米德写信——深夜——生命最后一年

（1948年，本尼迪克特在纽约的公寓。她独自坐在书桌前。外面纽约的夜——灯火——但她已经不看窗外很久了。她给在远方的米德写信。[信中日期是1948年3月]）

我最亲爱的玛格丽特——

你上次来信说你又有一个新的发现——你总是有。我有时候想我几十年前就应该和你一起去南海。但我的耳朵——我的心脏——这些都是"借口"——对。真正的原因是：我害怕。我怕在另一个文化中失去我自己——怕在异域的天空下我曾经的"本尼迪克特"会不再认识镜子中的她。你在萨摩亚、在新几内亚、在巴厘——你去了就像一尾鱼回到水中。我被制造出来——只是为了做一次普韦布洛人的田野——然后坐在纽约的图书馆和访谈室里——用别人的眼睛看。（你告诉我——这一点上我是不是更像博厄斯——他用腿做田野，我用"他人的眼睛"做田野——）

现在我写——我桌上堆满了给最后一个项目的资料——"当代文化的核心"。我想——用我和你的框架——去分析冷战中的美国和苏联。但我的手累了——我的心脏像一个坏掉的节拍器——咯咯——跳一下停一下——跳一下——（这不是一个隐喻——这是真的。——医生说）—— 

我回忆起——1922年——你走进我的教室——那个像小鸟一样小小的、黑眼睛不转的年轻女人——你看着我说："你是真的？" 我没听见你说——（我的耳聋——）——但你的口型——我知道你在说话——我让你写下来——然后——"你是真的？"——这就是我这一生需要听到的唯一一个问题。

如果我的书留下来了——很好。如果它们都沉没了——我不在乎。你还在——带着我的方法到了"我能听见的语言"到不了的地方。你成了我的耳朵、我的心脏的另一半——跳动的那个——在我不能跳动的时候。

你的——直到"模式"这个词失去意义的最后一刻——

鲁思

## 场景五：与博厄斯在哥伦比亚——关于《文化模式》论争

（1934年秋季——哥伦比亚大学教员休息室。博厄斯正在审读《文化模式》的手稿。本尼迪克特坐在他对面——她的身体绷紧——准备听不清他的批评。她的手指在腿上轻轻地抽搐——这是她的"不耐烦"的信号。）

**博厄斯**: 鲁思——这本著作非常漂亮。太漂亮了。

**本尼迪克特**: （保持静止。她听到了"漂亮"这个词——也听到了"太"——）

**博厄斯**: 日神——酒神——这是一个吸引人的框架。每件事都在里面找到了它的位置。你的普韦布洛人——总是日神、克制、和谐。你的夸扣特尔人——总是酒神、破坏、狂喜。但你和我都知道——（他看着她的眼睛——他喜欢这个学生但他不轻言赞）总有一天你会收到一封信——来自一个新去普韦布洛的田野工作者——告诉你她在苏尼找到了一个酋长——在一个私人仪式中被火神附身——尖叫、颤抖、他的整个存在在崩溃中渗出——是酒神的——不是一个日神——在苏尼。

到那时——当这个事实到达你面前——你有什么？一个理论——美——但不足以包含那个老头在土坯房里的颤抖。

**本尼迪克特**: （声音平静——但手在腿上停了——）

弗朗茨——我已经在为那个老头感到恐惧了。不。——我在为他等待——。（他的逼近）因为当他到来时——我可以在书的下一个版本中——把他放进去——不是作为一个"例外"——而是作为一个"当酒神出现在日神文化里会有什么形状?"——的形状。（她说话更慢了——因为她需要完全表达她的观点不能有任何误解）

你用一生收集事实——你怕任何"理论"会（用她的手语表示——一把盒子封上）——封装它们——把它们锁在一个盒子里——这样事实——每一个"不断近看时都不一样"的事实——就失去了它的生命。

我对理论的定义不一样——（向前倾——这是在耳朵失聪时的一种补偿性亲近）——理论是——我有一万个事实——不是让他们都混乱——是打造一个地板——在上面你可以站在一个位置看到——所有的事实——整体——从整体的角度来看——一个普韦布洛的"日神"不是你锁在笼子里的一只鸟——它是所有那些——安静地浇洒玉米粉于晨日下的老人们——灵魂构成的形状——然后——当那个酒神的老头嚎叫着从煤灰中跳出来——那是一个——这个形状的——美丽的裂缝——

（她把他的视线扶着——"看着——")

我做的不是你做的。我很感激你做的那样——没有你做的——我的地板就没有木料。（眼神软下来——这是真情感时间——）弗朗茨——这本书上有你的序。我为此终身骄傲。但你要让它——在我的地板上站立——不是你的。

**博厄斯**: （长时间看——然后——他将纸笔放在桌上。站起来——走到窗——看着哥伦比亚的校园——"我在巴芬岛时——1883年——我给未婚妻写信说——'我很高兴我学会了控制偏见，就像养成刷牙的习惯'。但现在——（他回头看着她）——你和玛格丽特——你们年轻女性——你们控制不了的东西让你们飞翔。也许这是一句祝贺。也许是一句抱歉。）"
