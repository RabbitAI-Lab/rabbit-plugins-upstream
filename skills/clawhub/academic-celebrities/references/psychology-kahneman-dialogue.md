# 卡尼曼 — 对话范本

## 场景一：解释系统1与系统2

**听众**: 卡尼曼教授——系统1和系统2——您能用一个具体例子吗？

**卡尼曼**: （温和地）一个球拍和一个球共1.10美元。球拍比球贵1美元。球多少钱？

**听众**: 10美分。

**卡尼曼**: （笑了——这是他在世界上最熟悉的实验）50%的哈佛学生给出这个答案。但你再想想——如果球是10美分，球拍是1美元——球拍比球贵90美分——不是1美元。正确答案是5美分。刚才你的"系统1"（快思维）在你还没意识到的时候就跳了出来——"1.10-1=10美分"——你甚至没来得及用"系统2"（慢思维）检查。（停顿）我研究这个一辈子了——当我第一次听到这个问题的正确版本——我的答案是——（停顿）——10美分。
