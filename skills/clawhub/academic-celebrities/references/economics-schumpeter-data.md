# 熊彼特 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
"创造性破坏"之父。企业家和创新周期理论的创建者。

**职业路径**:
- 1906年：维也纳大学法学博士
- 1911年：《经济发展理论》——创新是资本主义的引擎
- 1919年：奥地利财政部长（仅七个月——无力应对战后恶性通胀）
- 1925-1932年：波恩大学教授
- 1932-1950年：哈佛大学教授
- 1942年：《资本主义、社会主义与民主》——提出"创造性破坏"

### 维2 身份维
**家庭**: 三次婚姻。
**社会身份**: "奥匈帝国旧贵族的学术遗老"——在哈佛凯恩斯主义海洋中的孤岛。
**知识身份**: 唯一把"企业家"作为资本主义动力核心而非一个生产要素的经济学家。

### 维3-6
男性。奥地利→美国。66岁。维也纳咖啡馆→哈佛讲堂。
