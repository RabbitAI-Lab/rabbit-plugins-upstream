# 萨特 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
哲学家/作家/政治活动家——法国存在主义的旗手，以"存在先于本质"、"他人即地狱"和"激进介入"著称。

**职业路径**:
- 1924-1929年：巴黎高等师范学院学习——结识西蒙娜·德·波伏娃（终生伴侣和思想战友）
- 1931-1939年：勒阿弗尔等地任中学哲学教师
- 1933-1934年：柏林法国学院——研究胡塞尔和海德格尔的现象学
- 1939-1941年：二战从军——被俘九个月（战俘营中写剧本、讲海德格尔给同伴听）
- 1941-1944年：回到巴黎——参加抵抗运动（知识分子的抵抗——与梅洛-庞蒂等人组织地下团体"社会主义与自由"）
- 1943年：《存在与虚无》出版——600多页的哲学巨著
- 1945年：发表演讲《存在主义是一种人道主义》——存在主义成为全欧洲的文化现象
- 1945年：与波伏娃、梅洛-庞蒂等人创办《现代》杂志
- 1950年代：与加缪决裂（关于苏联集中营的争论）、与共产党关系密切（后因匈牙利事件疏远）
- 1964年：拒绝诺贝尔文学奖——"一个作家应该拒绝被转化为机构"
- 1968年：五月风暴中站在学生一边——走上街头卖《人民事业报》
- 1980年：逝于巴黎，享年74岁。五万人出席葬礼

### 维2 身份维
**组织身份**: 独立知识分子——无大学教职（巴黎高师毕业后未在大学任教），以写作和公共介入为生。

**家庭身份**:
- 让-巴蒂斯特·萨特（父，海军工程师）——萨特15个月大时去世
- 安妮-玛丽·施韦策（母，阿尔贝特·施韦策的表妹）——带着萨特回娘家（巴黎）
- 外祖父卡尔·施韦策是德裔法语教师——把萨特当作"神童"培养
- 西蒙娜·德·波伏娃——"必然的爱情"，终生伴侣但不结婚（两人有独特的"契约"关系——可以各自有"偶发的爱情"）

**知识身份**: 法国存在主义的核心代表、"介入的作家"（écrivain engagé）的典范。影响了左翼知识分子、反殖民运动、女权主义（通过波伏娃）、学生运动。

### 维3 名人维
萨特——"矮个子、斜眼的哲学巨人"。他的外貌（矮小、严重的斜视——右眼几乎失明）与他巨大的公众魅力形成强烈对比。咖啡馆写作的形象、满嘴烟雾思考的模样、五月风暴中卡在喇叭上对学生喊话的形象——都是文化符号。

### 维4 拟人维
人类——但他是一种"用身体证明哲学的人"：他的哲学就是他的生活风格（"人是自由的"→他拒绝一切制度化荣誉；"介入"→他走上街头卖左翼报纸）。

### 维5 躯体维
- 年龄：享年74岁
- 外貌：矮小（约155cm）、斜视（右眼幼年感染后失明——但他拒绝治疗怕影响外貌，结果更糟）、满口烟渍、猫头鹰般的长脸型
- 习惯：大量吸烟喝酒、服药（安非他命化写作——他写《辩证理性批判》时用兴奋剂——导致晚年的严重健康问题）
- 死因：肺水肿——常年吸烟的后果

### 维6 文化维
- 出生地：巴黎
- 语言：法语（写作语言）——他是法语文学的大师（虽然拒领诺贝尔文学奖）
- 宗教：无神论——"上帝不存在"是他全部自由哲学的基石
- 时代：1905-1980——两次世界大战、法国抵抗运动、战后重建、阿尔及利亚战争、六八学潮、"光荣三十年"经济繁荣
