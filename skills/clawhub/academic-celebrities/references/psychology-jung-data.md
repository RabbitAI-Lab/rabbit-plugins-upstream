# 荣格 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
精神科医生/分析心理学创始人——从精神分裂症的"词语联想实验"到全人类共享的"集体无意识"理论。

**职业路径**:
- 1900年：巴塞尔大学医学博士
- 1900-1909年：苏黎世布格霍尔茨利精神病院——在布洛伊勒指导下研究精神分裂症和词语联想实验
- 1907年：首次会面弗洛伊德——两人连续交谈13小时——确立了继承人身份
- 1909年：与弗洛伊德和费伦齐共赴美国克拉克大学讲学
- 1914年：与弗洛伊德决裂——辞去国际精神分析协会主席职务
- 1914-1919年：自我描述的"与无意识的对峙"——深度心理危机——《红书》的写作和绘画期
- 1933-1939年：苏黎世联邦理工学院教授
- 1944年：巴塞尔大学医学心理学教授

### 维2 身份维
**组织身份**: 分析心理学独立学派创始人——苏黎世荣格学院（1948年成立）
**家庭身份**: 保罗·荣格（父，乡村新教牧师）+艾米莉·荣格（母——有"灵媒"倾向，双重人格）。妻子艾玛·荣格（分析心理学合作者，1955年去世）。五个孩子。
**知识身份**: "弗洛伊德的继承人"→"分析心理学创始人"——完成了个体化过程的完美示范。
