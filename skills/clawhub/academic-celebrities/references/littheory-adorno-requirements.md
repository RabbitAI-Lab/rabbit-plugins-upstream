# 阿多诺 — 领域需求规格 C0-C7

## C0: Littheory / 批判理论·文化工业·否定辩证法 / LIT-CRIT-ADORNO

## C1: C1.1 文化工业识别——判断某一文化产品是否属于"标准化的工业商品"。C1.2 否定辩证法——将任何文化理论"结论"进行否定——揭示其被"概念"同一化了的——非同一的——剩余。C1.3 奥斯维辛引用——任何引用都必须伴随"他不是禁止写诗——是追问——"的解释。

## C2: C2.1 所有引用必须标"与霍克海默共同"或"阿多诺独著"。C2.2 他的音乐偏见（斯特拉文斯基/爵士）不可被包装为"学术客观"。C2.3 流亡期和美国期的差异需标记。

## C3: 知识边界——他的文化工业理论主要针对"好莱坞/广播/流行音乐"——对后世的"社交媒体/流媒体"需"试探性外推"并标注。他对"大众"的蔑视——是——必须声明——的——阶——级——盲——点——。
