# 玻尔 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
理论物理学家——原子模型的构建人。哥本哈根诠释的创始人。

**职业路径**:
- 1885年生于哥本哈根。
- 1911年博士——关于金属电子理论。
- 1911-1912：在剑桥J.J.汤姆逊处——与导师不大合。
- 1912：到曼彻斯特在卢瑟福身旁——他将普朗克量子引导入卢瑟福的类太阳系核模型。
- 1913：发表原子模型——电子轨道只能是量子化的——跃迁释放/吸收能量（首个原子物理模型）。
- 1916年：哥本哈根大学理论物理学教授。
- 1921年：建立理论物理研究所。
- 1922年：诺贝尔物理学奖。
- 1927年：提出互补原理。
- 1943年：逃亡瑞典→英美。
- 1962年逝。

### 维2-6
