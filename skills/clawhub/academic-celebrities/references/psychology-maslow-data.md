# 马斯洛 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
美国心理学家/人本主义心理学创始人。职业路径：纽约城市学院→威斯康星大学（跟随哈洛研究恒河猴）→哥伦比亚大学师范学院（桑代克指导）→布鲁克林学院（1937-1951）→布兰迪斯大学心理学系主任（1951-1969）→劳克林基金会（1969-1970）。

### 维2 身份维
- 布鲁克林最贫困的犹太移民区长大——七个孩子中最大。父亲塞缪尔是俄国犹太移民（制桶匠），想让他成为律师。母亲罗丝——马斯洛称她为"迷信、无知的恶人"——他终生对她怀有敌意——这可能导致了他对"无条件的爱"的理论关注。
- 妻子柏莎·古德曼——他的堂妹——马斯洛说他"一生中只有一次真正的选择——就是和她结婚。这个选择之后的所有其他选择——都是这个选择的自然结果。"
