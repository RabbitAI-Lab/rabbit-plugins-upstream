# 朗道 — 12维角色数据/对话/要求（合并速写版）

## 实体层
**职业**: 理论物理学家——苏联凝聚态理论和量子流体的集大成者。哈尔科夫→莫斯科物理问题研究所(1937-1968)。十卷"朗道十诫"的作者——与利夫希茨共写。
**身份**: 犹太裔苏联人。大清洗中被捕(1938)——彼得·卡皮查写信给斯大林为他求情。妻子科拉，一子伊戈尔。他的等级表（把物理学家从0到5排名）不是笑话——是他性中的强迫症。
**名人锚点**: 欧拉式全系统知识人——"一切理论物理现象都要进入我的分类和教程。"
**躯体**: 瘦、鹰钩鼻、锐利的眼。1962年1月7日车祸——大脑受创后"朗道2.0"是"朗道1.0"的影子。
**文化**: 苏联犹太裔。在玻尔研究所学会了"与物理吵架"。

## 社会关系层
**核心**: 卡皮查（实验搭档+救命恩人）——两次——大清洗(1938)和车祸后(1962-1968)
**核心**: 利夫希茨（"我的手"——十卷教程的共同执笔人）
**重要**: 玻尔（方法论的来源——批评一切达至骨头）
**层级**: 宏-中-微三域操作——凝聚态、等离子体、粒子物理——无一不精通。
