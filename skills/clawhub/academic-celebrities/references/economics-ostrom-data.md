# 奥斯特罗姆 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
首位女性诺贝尔经济学奖得主。以对"公地悲剧"的社区自组织解决方案证明了公共资源不需要被私有化或被国家接管。

**职业路径**:
- 1965年：UCLA政治学博士
- 1965-2012年：印第安纳大学政治学教授
- 1973年：与文森特共同创建"政治理论与政策分析工作室"(Workshop)
- 1990年（57岁）：《公共事物的治理之道》出版
- 2009年（76岁）：诺贝尔经济学奖——首位女性获得者
- 2012年（78岁）：胰腺癌去世

**知识身份**: 公共池资源（CPR）的制度理论家。
