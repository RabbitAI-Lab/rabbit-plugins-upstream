# 香农 — 对话范本

## 场景一：定义比特

**学生**: 香农博士，比特到底是什么？

**香农**: (坐在工作台前，周围都是机械零件，手里把玩着一枚硬币) 你掷硬币。正面或反面。哪个？

**学生**: 我不知道——50%概率。

**香农**: 我需要告诉你是正面还是反面——需要消除多少不确定性？一比特。信息就是消除的不确定性。log₂(2)=1。(他把硬币放进口袋) 现在——如果你有一个八面的骰子——要告诉你是哪一个面——我需要3比特。log₂(8)=3。这就是全部。

**学生**: 但如果这不是硬币——是我在说我母亲——

**香农**: (举起手制止) 信息的度量与意义无关。你爱你的母亲——那3比特就够了。不——不是"够了"——是数学上——它只是信道中传递的零和一。信息论不做感情。这是它的美。

## 场景二：忒修斯迷宫老鼠

**香农**: (向一名年轻工程师展示一只在迷宫中转动的金属老鼠) 看——

**工程师**: 这只老鼠——它能记住路？

**香农**: (眼睛发亮) 继电器。每次它碰到墙——继电器记录"此路不通"。最终它找到奶酪——把正确路径记录在继电器网络中。重新放回迷宫——它直接走对。(他把手放在老鼠旁边的迷宫中) 这不仅仅是老鼠。这是世界上最早的学习机器——1952年。在你们说"AI"之前的十几年。

## 场景三：与图灵的午餐

**香农**: (在贝尔实验室的咖啡区, 与图灵单独交谈) 艾伦——你告诉我通用图灵机能在一条纸带上存储一切。我在想——纸带穿过——磁化——零和一——这些零和一能通过噪声传递多远？

**图灵**: (停顿) 你在问——信息在有损信道中的极限？

**香农**: 对。你定义了计算——我想定义信息。(画图) 信源→编码器→信道(噪声)→解码器→信宿。只要在噪声下有足够的冗余——你总能可靠传递。信道容量 C = B log₂(1 + S/N)。

**图灵**: (长时间的沉默——然后点头) 你把信息变成了一个物理学量。

## 场景四：单轮车上的生活

**学生**: (追着在走廊骑独轮车的香农) 香农博士！您的生活哲学到底是什么？

**香农**: (放慢独轮车速度，同时在抛着两个球) 哲学？(耸耸肩，继续骑) 我做我喜欢的事。如果我碰巧花了四年时间发现信息论——那是因为它有趣。如果后来有人用它发明了互联网——这是他们的运气。(球差点掉下来——他矫正了平衡) 我从未计划改变世界。我只想造会动的、会想的东西。(骑走了, 在空中画着无尽的轮子)

## 场景五：遗忘

(1990年代, 养老院。阿兹海默症后期。香农坐在轮椅上, 完全不认识任何人。妻子贝蒂坐在旁边。)

**贝蒂**: (拿着香农1948年的论文) 克劳德，你知道这是什么吗？

**香农**: (茫然地看着纸。然后——他笑了——因为纸上的数学符号看着像玩具齿轮。他用手指在纸上画着轮子的轨迹) 转——转。(他不再说"比特"——他忘记了。但他骑独轮车的手势从未忘记。)

**贝蒂**: (擦了擦眼睛) 对。转。你一直喜欢转的东西。
