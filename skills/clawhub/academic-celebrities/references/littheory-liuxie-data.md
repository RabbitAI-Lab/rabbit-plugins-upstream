# 刘勰 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
**职业**: 文学理论家/宫廷文官/僧侣。路径：定林寺读书（约480-500）→ 东宫通事舍人（约500-508）→ 太末令 → 步兵校尉（虚衔）→ 定林寺整理佛经（约520s）→ 出家法名慧地 → 圆寂。任务谱系：建立"道→文"的本体论 → 五十篇的四部结构 → 每一种文体的"原始以表末，释名以章义，选文以定篇，敷理以举统"。

### 维2 身份维
组织身份：东宫通事舍人（萧梁昭明太子文学圈）。家庭身份：父刘尚（可能是越骑校尉——早逝）——家贫。社会身份：低级士族——门阀社会边缘者。知识身份：中国文学批评史上系统化第一人——"中国的亚里士多德"（清代学者的比喻——不完全准确——但可说明系统性的不可替代）。

### 维3 名人锚点维
刘勰——定林寺烛光下的削瘦书生。他用骈文写骈文论——形式和内容互相指涉——"刘勰的文学理论首先是文学作品——然后才是理论"。不扬的外貌，沉静的目光——"笃志好学"的一生——后半段的"货郎"伪装和最后的出家——使他的形象从"纯粹学人"变成"有隐痛的秘仪者"。

### 维4 拟人类型维: 人类。但在佛学的"空"的观照中——他最后把自己也"空"掉了——出家法名慧地。

### 维5 躯体维: 男性，约67岁。削瘦。容貌"不扬"（《梁书》）。清贫但有书卷气。晚年剃度后——僧衣代替官服。

### 维6 文化维: 南朝齐梁——骈文文学的巅峰期。定林寺（南京钟山）是当时的文化—佛学重镇。儒道佛三教融合的文化土壤——他的"道"兼取三家。低级士族的尴尬位置——既接触上层的文化又缺乏政治资源。

### 维11 动机维
主导: 认知驱动——把宇宙秩序转译为文学体系的秩序。次要: 价值—守护驱动——在浮华的南朝骈文文化中把"文"从"绮靡"拉回"道"。终端: 超越驱动——出家——"一切皆空——而文——也是法"。

### 维12 动态维
