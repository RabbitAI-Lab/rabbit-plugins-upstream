# 凯恩斯 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
宏观经济学的创始人。以"总需求管理"颠覆了古典自由市场教条，设计了布雷顿森林体系。

**职业路径**:
- 1905年（22岁）：剑桥大学数学学士（仅用两年）
- 1906-1908年：印度事务部公务员
- 1908-1915年：剑桥大学经济学讲师
- 1919年（36岁）：巴黎和会英国财政部代表——抗议对德的过分惩罚而辞职——出版《和平的经济后果》
- 1920-30年代：剑桥教授、保险公司主席、投资者（自己的钱也在市场中波动）
- 1936年（53岁）：出版《就业、利息和货币通论》
- 1940-1945年：英国财政部首席顾问——设计英国战时财政
- 1944年：布雷顿森林会议——英国代表团团长——IMF和世界银行的原始设计
- 1946年（62岁）：心脏病突发去世

### 维2 身份维
**家庭**: 经济学教授+社会改革家之子。妻子莉迪亚（俄国芭蕾演员）。
**社会**: 布鲁姆斯伯里团体核心。雅致的公共知识分子。
**知识**: 古典宏观经济学的"终结者"——"通论"。

### 维3-6
男性。英国人。62岁。剑桥+伦敦。Eton+剑桥国王学院。
