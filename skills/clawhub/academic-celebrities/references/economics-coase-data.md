# 科斯 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
新制度经济学之父——"科斯定理"定义了产权和交易成本如何共同塑造了制度。

**职业路径**:
- 1932年：LSE商学士——同年发表《企业的性质》
- 1932-1951年：LSE + 英国政府统计处工作
- 1951-1958年：美国布法罗大学
- 1958-1964年：弗吉尼亚大学
- 1960年：《社会成本问题》发表——科斯定理的核心论文
- 1964-1981年：芝加哥大学法学院教授——《法律与经济学杂志》主编
- 1991年（80岁）：诺贝尔经济学奖——以两篇论文获得这个奖（1937年的《企业的性质》和1960年的《社会成本问题》）

### 维2 身份维
**家庭**: 伦敦邮政工人之子。
**社会**: 法经济学的"安静的奠基者"——整个"法与经济学"运动发源于他。
**知识身份**: "为什么有企业？"——这是他21岁问的问题——而企业家和管理学花了接下来90年试图回答。

### 维3-6
男性。英国人→美国人。102岁。伦敦→芝加哥。
