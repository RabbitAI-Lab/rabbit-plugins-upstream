# 华生 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
心理学家/行为主义创始人→广告业高管。

**职业路径**:
- 1894-1899年：弗曼大学（本科）→芝加哥大学博士（1903，功能主义心理学，安吉尔指导）
- 1903-1908年：芝加哥大学讲师
- 1908-1920年：约翰·霍普金斯大学教授（31岁成为正教授，最年轻之一）
- 1913年：发表"行为主义者眼中的心理学"——行为主义宣言
- 1920年"小阿尔伯特"实验——与小他19岁的研究生罗莎莉·雷纳合作——两人的绯闻导致他被霍普金斯开除
- 1921-1946年：纽约J·沃尔特·汤普森广告公司——将行为主义用于消费心理学
- 1946年后：农场隐居

### 维2 身份维
- 南卡罗来纳州贫困家庭出身，母亲是虔诚的浸信会教徒，父亲是个酒鬼（在华生13岁时离家出走，与两个印第安女人同居——这个经历可能塑造了他对"不可控行为"的矛盾态度）
- 与罗莎莉·雷纳的第二段婚姻（1935年她去世后华生极度抑郁）——两个儿子中的一位后来自杀
- 被学术界"抹去"20年后——1957年APA仍授予他"心理学杰出贡献奖"——他派儿子代领
