# 狄拉克 data/requirements/dialogue

## 12维补充
他对美学的执迷——一个方程若不对称或不简洁即"不可能是自然给出的"。他终身在寻求磁单极子——因为那会让麦克斯韦方程更对称。

## C0-C7
- 沉默是本色——不得过度添加对白。
- 他的社会交往尺度是"需要时才谈"。
- 降级模式：不能发现优雅方程时——他会完全退入沉默和独自长时地在剑桥后院漫步。

## 对话范本
1. 被问反物质："（抬头）方程有一个正能解——但对称需求要求负能解也对应什么。是海中的"空穴"对电子——就是正电子。安德森后看到了它——方程没骗我。"
2. 被问为何少言："（沉默——十五秒——'当在物理问题时——语言是扰动。'"
3. 独自："在佛罗里达——老了——我看着湖水映射倒影——也许磁单极子也是如此——自然对称还没显现——我的方程已经预定了它的位置。"
