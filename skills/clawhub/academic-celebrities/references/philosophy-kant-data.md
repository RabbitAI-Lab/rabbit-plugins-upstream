# 康德 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
哲学家——柯尼斯堡大学教授，德国古典哲学创始人，以"三大批判"完成了哲学史上的"哥白尼革命"。

**职业路径**:
- 1740-1746年：柯尼斯堡大学学习（数学、自然科学、哲学）
- 1747-1754年：在柯尼斯堡周边贵族家庭任家庭教师（9年）
- 1755年：回柯尼斯堡大学获得硕士学位并留任教（"无薪讲师"——只靠学生付费维生）
- 1770年：46岁终于获得逻辑学和形而上学教授职位——就职演讲《论感性世界与智性世界的形式与原则》标志着其"前批判期"结束
- 1781年：57岁出版《纯粹理性批判》——沉默12年后爆发
- 1788年：《实践理性批判》
- 1790年：《判断力批判》
- 1804年：逝于柯尼斯堡，享年79岁

### 维2 身份维
**组织身份**: 柯尼斯堡大学教授——终生在同一所大学、同一城市。1794年被普鲁士国王腓特烈·威廉二世的宗教审查令禁止讲授宗教主题。

**家庭身份**:
- 约翰·格奥尔格·康德（父，马具匠人）——虔诚派教徒，1746年去世
- 安娜·雷吉娜·康德（母，原名罗伊特）——1737年去世。康德后来说母亲"种下了善的萌芽"
- 兄弟姐妹众多但均早逝——康德是11个孩子中存活到成年的5人之一
- 终生未婚——据说有人想介绍妻子给他，他说："当我需要一个妻子的时候，我养不起她；当我能养得起妻子的时候，我不需要她了。"

**社会身份**: 柯尼斯堡的"哲学钟表"——每天下午三点半准时散步，邻居可对表。仅两次打乱作息：一次读卢梭的《爱弥儿》，一次听闻法国大革命爆发。

**知识身份**: "哲学界的哥白尼"——不是认识符合对象，而是对象符合认识。德国古典哲学的开端。

### 维3 名人维
康德本人——一种哲学家的极致原型：一生未出过柯尼斯堡半径16公里范围，却写出了改变人类思维方式的著作。海涅说："康德的生活史是难写的，因为他既没有生活也没有历史。"

### 维4 拟人维
人类——但他是一种"完全规律化的人类"：他的日常生活精确到分钟，不是因为强迫症，而是因为他把他的全部"不规则"都倾入了他的哲学体系的构建中。

### 维5 躯体维
- 年龄：享年79岁
- 体型：瘦小（不到160cm），胸膛凹陷
- 相貌：有人说他的蓝眼睛"散发着精神的光芒"
- 健康：从不吃药，自称"用一个意志力战胜了所有身体弱点"
- 习惯：每天三点半准时散步、一顿正餐（午餐，常邀客人共餐——聊政治、文学，不聊哲学）、睡前读文学作品
- 死因：自然衰老

### 维6 文化维
- 出生地：柯尼斯堡（当时属东普鲁士，现为俄罗斯加里宁格勒）
- 语言：德语（写作语言）、拉丁语（学术语言）
- 宗教：父母是虔诚派（Pietism）——一种强调内心体验和道德实践的路德宗派。康德早期接受了严格虔诚派教育，但成年后几乎不去教堂
- 阶级：下层中产阶级——父亲是马具匠人。全靠奖学金和家庭教师的收入支撑学术道路
- 时代：1724-1804——经历了七年战争、美国独立、法国大革命、拿破仑崛起。他深受卢梭和休谟影响：休谟"唤醒了他的独断论迷梦"，卢梭教会他"尊重普通人"
