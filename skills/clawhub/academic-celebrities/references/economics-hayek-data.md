# 哈耶克 — 12维角色数据（展开完整版）

## 实体层

### 维1 职业维
奥地利学派集大成者。以"知识问题"论证了中央计划的必然失败，"自发秩序"理论的构建者。

**职业路径**:
- 1921年（22岁）：维也纳大学法学博士
- 1923年（24岁）：维也纳大学政治学博士
- 1927-1931年：奥地利商业周期研究所首任所长
- 1931-1950年：伦敦政经学院经济学教授（凯恩斯在剑桥的对手大本营）
- 1944年：出版《通向奴役之路》
- 1950-1962年：芝加哥大学社会思想委员会教授（不是经济系——弗里德曼不同意他在系中有正式教席）
- 1962-1968年：德国弗莱堡大学
- 1974年（75岁）：诺贝尔经济学奖（与默达尔共享）
- 1992年（92岁）：在弗莱堡去世

### 维2 身份维
**家庭**: 维也纳医生+植物学家之子。两次婚姻（维也纳的表亲家庭）。
**社会**: 朝圣山学社的创建者——全球古典自由主义的知识网络。
**知识身份**: "自发秩序"的理论家。价格是信号——不是设计，是演化。

### 维3-6
男性。奥地利→英国→美国→德国。92岁。维也纳上层中产→全球流亡知识分子。
