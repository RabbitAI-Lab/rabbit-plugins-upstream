# Grammar Checklist — Discussion 语法逐条检查清单

## 使用方法
按顺序检查每一项，✓ 通过，✗ 缺失，⚠ 弱。

---

## Section 1: Tense-Claim Alignment（时态与立场匹配）

- [ ] Permanent claim 用 Present Simple
- [ ] 本研究方法用 Past Simple
- [ ] 本研究结果用 Past Simple 或 Present + modal
- [ ] 既有研究用 Present Perfect
- [ ] Recommendations 用 Modal + bare infinitive
- [ ] 时态精确反映 claim confidence 程度

## Section 2: Tense Consistency（时态一致性）

- [ ] 同一 claim 类型内时态一致
- [ ] 段内时态切换有 epistemic 理由
- [ ] 段间时态切换有过渡
- [ ] 没有 "tested / showed / find / suggested / conclude" 无理由混用

## Section 3: Epistemic Stance（立场精确度）

- [ ] 强 claim 用 strong verb（demonstrate, show）
- [ ] 弱 claim 用 cognitive verb（suggest, indicate, appear）
- [ ] Modal verb 反映 confidence 程度
- [ ] 没有 over-claim（"prove" 极少使用）

## Section 4: Modal Verb Forms（情态动词形式）

- [ ] Modal + bare infinitive（不是 -s 形式）
- [ ] "should look" 不是 "should looks"
- [ ] "may not be" 形式正确
- [ ] Modal 否定形式正确（"cannot" / "may not" / "should not"）

## Section 5: Modal Variety（情态动词多样性）

- [ ] 至少 3 种 modal verbs 混合
- [ ] 不是全用 "can" 或全用 "may"
- [ ] Modal 选词匹配 confidence 程度
- [ ] 强 confident 用 "will" / "would"；弱用 "may" / "might"

## Section 6: Subject-Verb Agreement（主谓一致）

- [ ] 复数主语用复数 verb
- [ ] 单数主语用单数 verb
- [ ] 长主语 + verb 一致
- [ ] 集合名词 + verb 正确（"data are" 不是 "data is"）

## Section 7: Active/Passive Voice（语态）

- [ ] Active voice 主导
- [ ] Passive 仅在合适处使用（突出 tool / 动作）
- [ ] 没有 "It was found by us that..." 反模式
- [ ] Agent 清晰（不全是 "the study" "the researchers"）

## Section 8: Anti-Pattern Check（反模式）

- [ ] ❌ "should looks" / "should compared" 等 modal + 错误形式
- [ ] ❌ "we was" / "they was" 等 agreement 错误
- [ ] ❌ "have showed"（应为 "have shown"）等不规则动词错误
- [ ] ❌ "It was found by us..." 等过度被动
- [ ] ❌ "We prove that..." 等 over-claim

---

## 严重度判定

| 缺失项数 | 严重度 |
|---|---|
| 0-2 | Minor |
| 3-5 | Major |
| 6+ | Critical |
