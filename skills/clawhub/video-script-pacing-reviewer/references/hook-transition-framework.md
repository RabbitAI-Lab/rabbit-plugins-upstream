# Hook & Transition Framework — 钩子与过渡框架

## 钩子类型

### 开头钩子（0–5 秒）
| 类型 | 强度 | 适用场景 |
|------|------|---------|
| 反常识 | ⭐⭐⭐⭐⭐ | 知识、科普、教程 |
| 痛点共鸣 | ⭐⭐⭐⭐ | 种草、教程、评测 |
| 数据冲击 | ⭐⭐⭐⭐ | 科普、行业分析 |
| 悬念/预告 | ⭐⭐⭐⭐ | 故事、教程、评测 |
| 视觉奇观 | ⭐⭐⭐ | 产品展示、旅行、美食 |
| 利益直给 | ⭐⭐⭐ | 投放素材、种草 |

### 中段锚点（每 60 秒）
| 类型 | 说明 |
|------|------|
| 转折 | "但这里有个问题……" |
| 新信息 | 引入之前没提过的概念 |
| 情绪变化 | 从理性讲理到感性共鸣 |
| 反转 | 颠覆前面的假设 |
| 互动 | "你猜结果怎样？" |
| 视觉变化 | 镜头/场景/风格的切换 |

### 结尾钩子（最后 15 秒）
- 回收开头的承诺（callback）
- 明确 CTA（关注/点赞/购买）
- 留悬念（系列内容）

## 过渡质量检查

### 好的过渡
- 上一段的结论自然引出下一段的前提
- 信息有递进关系（不是并列堆砌）
- 节奏有变化（不是匀速到底）

### 坏的过渡（"掉节奏"）
| 问题 | 症状 |
|------|------|
| 断崖式跳转 | 上一段高潮结束，下一段从零开始爬坡 |
| 机械并列 | 段落之间没有逻辑连接，只是"第一…第二…第三…" |
| 重复赘述 | 每段开头都重新铺垫背景 |
| 能量递减 | 前面高能，后面越来越平，没有回升 |

## 过渡诊断方法

对每一对相邻段落（A→B），问：
1. B 的开头是否承接了 A 的结尾？
2. A→B 的信息是否有递进？
3. 观众从 A 到 B 是否需要"重新进入"？（如果需要 = 掉节奏）
4. A→B 的情绪/能量走向是什么？（应该有变化，不是一直平或一直降）
