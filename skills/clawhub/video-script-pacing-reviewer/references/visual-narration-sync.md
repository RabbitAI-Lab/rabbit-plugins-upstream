# Visual-Narration Sync — 画面与旁白配合规则

## 核心原则

旁白和画面是两条独立的信息通道。最好的状态是互相强化，最差的状态是互相干扰。

## 配合模式

### ✅ 强化型（最佳）
旁白和画面讲同一件事，但用不同维度：
- 旁白讲原理，画面展示实例
- 旁白讲数据，画面展示图表
- 旁白讲故事，画面展示场景

### ⚠️ 补充型（可接受）
旁白和画面各讲各的，但加起来信息完整：
- 旁白讲功能，画面展示操作
- 旁白讲背景，画面展示产品

### 🔴 冲突型（需修改）
- 画面在动但旁白讲太慢 → 观众走神（画面比旁白快）
- 旁白信息密集但画面静止 → 信息过载（旁白比画面快）
- 画面展示 A 但旁白讲 B → 认知分裂

## 检查清单

| 问题 | 检查方法 |
|------|---------|
| 画面比旁白快 | 这段旁白字数 ÷ 语速 > 画面时长？ |
| 旁白比画面快 | 这段旁白字数 ÷ 语速 < 画面时长？ |
| 认知分裂 | 画面核心元素和旁白核心信息有关联吗？ |
| 缺少视觉引导 | 旁白提到的东西画面有没有出现？ |
| 纯文字无画面 | 是否整段只有字幕/旁白没有画面变化？ |

## 语速与画面节奏匹配

| 语速 | 适合画面节奏 |
|------|-------------|
| 快（>250 字/分钟） | 快速切换、动画、数据可视化 |
| 中（200–250 字/分钟） | 正常节奏，产品展示、操作演示 |
| 慢（<200 字/分钟） | 静态画面、情感画面、沉浸式画面 |
