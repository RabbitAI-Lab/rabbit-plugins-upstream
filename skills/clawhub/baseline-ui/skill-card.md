## Description:

Quickly polishes UI code by reviewing spacing, hierarchy, typography, interactions, and layout against an opinionated design baseline.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and designers use this skill to apply consistent UI conventions or review a specific file for violations and concrete code-level fixes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Opinionated UI rules may conflict with a project's established design conventions.

Mitigation: Review proposed changes against existing project conventions before applying them.
