## Description: <br>
Use this skill when the user wants printable puzzle worksheets, including PDF activity sheets for classrooms, kids, parties, newsletters, or activity books; it produces print-ready word search, crossword, and sudoku PDFs with solution pages locally via the PuzzleTide CLI. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External users, educators, activity-book creators, and developers use this skill to generate printable puzzle worksheets and packets as local PDF or SVG files with PuzzleTide CLI commands. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Installing the PuzzleTide Node CLI changes the user's local environment. <br>
Mitigation: Ask before installing packages and have the user review npm installation prompts before approval. <br>
Risk: Generated puzzle PDFs or SVGs may need review before classroom, newsletter, party, or activity-book use. <br>
Mitigation: Preview generated files and adjust difficulty, paper size, seed, title, or solution-page options before distribution. <br>
