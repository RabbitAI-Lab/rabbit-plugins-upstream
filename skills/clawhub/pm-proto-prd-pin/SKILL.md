# 交互式原型 PRD 打点标注与多版本规约生成器 (PM Prototype PRD Pin V6)

## 📖 概述

`pm-proto-prd-pin` 是一套**零外部依赖、即插即用**的高性能原型交互规约标注引擎（纯原生 Vanilla JS + CSS + Node/Python 本地微服务）。
它能为任何已有的静态 HTML 原型（后台管理系统、电商前台、移动端 H5 等）瞬间赋予专业的产品经理（PM）交互式打点标注、多版本管理、**交互式可视化表格直编**、纯净无边框逐行即时可视化文档工作台、纯白 Mermaid 流程图动态防截断渲染、全景文档大屏展示与真实磁盘持久化能力。

---

## 🎯 核心能力与设计规范

### 0. 🌐 原生全球多语言架构体系 (Native Multi-Language i18n)
- **四国语言无缝内建支持**：
  - 🇨🇳 **简体中文 (`zh-CN`)**
  - 🇺🇸 **English (`en`)**
  - 🇯🇵 **日本語 (`ja`)**
  - 🇰🇷 **한국어 (`ko`)**
- **全要素动态本地化**：
  - 包含抽屉边缘胶囊、抽屉标题、管理模式按钮、搜索占位符、操作卡片按钮、打点编辑器全量表单、表格直编工具栏、流程图渲染栏、全景 PRD 大屏所有元数据与目录、弹窗冲突处理对话框等 100% 字典覆盖；
- **运行时无感知热切换与本地记忆**：
  - 抽屉顶部提供多语言切换下拉菜单，切换后即刻热重绘所有组件与徽标，并将偏好持久化至 `localStorage('prd_ui_lang')`；
- **强制前置语言与构建方式选择规范 (Mandatory Inception Step)**：
  - **在使用本 Skill 执行构建时，Agent 必须首先向用户确认期望使用的语言框架（中文 / 英文 / 日文 / 韩文）**；
  - 最终生成出来的原型框架、`window.INITIAL_PRD_DATA` 需求规约数据、业务规则模板、以及表头字典，必须严格采用用户指定的对应语言！

### 1. 📊 交互式可视化表格直编 (Visual Table Editor)
- **彻底告别 Markdown 竖线管道符 (`| col |`) 困扰**：
  - 表格插入或渲染后，直接呈现为所见即所得的真实 HTML 表格；
  - **多行数据与单元格多行排版完整支持 (Multi-Row & Multi-Line)**：
    - 表格默认全量完整展开所有数据行与表头，杜绝任何高度塌陷；
    - **单元格内多行排版**：按 `Shift + Enter` 可直接在单元格内换行（底层自动转为 `<br>` 合法 Markdown），支持复杂多行规约；
    - **键盘极速录入**：按 `Enter`（无Shift）自动跳至下一行同列单元格（若已在末行则自动新建行）；按 `Tab` 自动跳至右侧下一格（末尾自动加行）；
  - **点击单元格直接打字**：所有表头 `<th>` 与单元格 `<td>` 均支持 `contenteditable="true"`，PM 点击任意单元格即可像在 Word / Excel 中一样直观修改内容；
  - **一键快捷增删行列**：
    - `➕ 加一行`：在表格末尾追加一行空单元格并自动聚焦；
    - `➕ 加一列`：在表格右侧追加一列并自动生成新表头；
    - `➖ 删末行` / `➖ 删末列`：快速移除不需要的数据行/列；
    - `🗑️ 删表格`：一键移除当前表格块；
  - **自动双向序列化**：当 PM 在单元格打字或操作增删行列时，系统底层毫秒级自动将表格结构转换并同步为标准 Markdown 表格存储，无感知落盘。

---

### 2. ✍️ 纯净无边框逐行即时可视化工作台 (Borderless Live In-Line Editor)
- **沉浸式纯净文档质感**：
  - 彻底去除每行繁琐的外框与阴影，还原干净真实的文档编写体验；
  - 移除末尾多余的「新增一行/段落」按钮，PM 在空白区域点击或敲击回车即可顺畅流转；
- **工具条操作无缝焦点锁定 (Focus-Preserving Toolbar)**：
  - 点击加粗 `B`、斜体 `I`、标题 `H3`/`H4`、代码块等任意格式按钮或插入表格/模板时，**焦点持续锁定在当前编辑的那一行**，绝不会因点击工具栏失焦而跳转到文档最底部；
  - 自动保留选区高亮与光标位置，插入后立即无缝继续打字；
- **当前行源码输入，非编辑行全自动实时高保真渲染**：
  - 鼠标点击任意文字/标题段落，该行就地展开为无框源码输入；
  - 敲击 `Enter` 自动在下方创建新行；敲击 `Backspace` 在空行自动回退；
  - 敲击 `Esc` 或点击外部，整篇文档立即 100% 恢复为高保真排版；
- **全文本纯源码备用模式 (`📄 纯文本源码`)**：
  - 顶部保留 `[ ✨ 可视化即时直编 | 📄 纯文本源码 ]` 开关，方便 PM 批量复制或大段导入。

---

### 3. 🏷️ 完整多版本打点管理体系 (Multi-Version PRD Management)
- **版本数据模型与向后兼容**：
  - 内存与本地文件采用版本注册表（`versionRegistry`）统一维护各版本打点数据：
    ```javascript
    window.PRD_VERSION_REGISTRY = {
      "activeVersion": "v1.0.0",
      "versions": {
        "v1.0.0": [ /* pins */ ],
        "v1.1.0": [ /* pins */ ]
      }
    };
    ```
- **严格版本物理隔离 (Strict Version Isolation & Zero Cross-Contamination)**：
    - 页面大头针徽标、右侧抽屉列表、打点详情气泡、以及全文 PRD 文档大屏**仅展示当前所选激活版本的数据**；
    - 互相版本的打点**完全物理隔离、互不可见**；
    - **新建版本一律为全新空白版本 (Default Clean Blank Slate)**：
      - 点击「➕」或「➕ 新建空白版本...」时，系统直接创建一个全新的空打点版本（打点数：0），无需手动清空，方便 PM 从零开始标注下一迭代需求；
      - 若 PM 需要基于当前版本派生副本，可选择「📋 复制当前版本副本」；
  - **抽屉顶部版本切换工具栏**：
  - 抽屉顶部常驻版本下拉选择器：`🏷️ v1.0.0 (20项) ▾`，点击瞬切目标版本；
  - 菜单包含：历史版本瞬切、`➕ 新建空白版本`、`📋 复制当前版本副本`、`📂 上传版本数据`、`🗑️ 删除当前版本`。
- **上传 JS 文件与同版本智能冲突处理 (Conflict Modal)**：
  - 用户上传 `.js` / `.json` 文件时弹出冲突模态框：
    - 🔴 **【覆盖现有版本】**：清空当前版本旧打点，完全替换为上传内容；
    - 🟢 **【追加合并】**：保留旧打点，将上传打点追加至末尾并重新编号；
    - 🔵 **【另存为新版本】**：自动命名为 `[版本]_imported`。

### 4. 🔄 纯白底色 Mermaid 矢量图表引擎与动态防截断渲染 (Pure White & Safe ViewBox)
- **纯白底色独立容器**：
  - 全局消除暗色背景干扰，Mermaid 统一渲染在纯白优雅卡片内；
- **动态防截断与 ViewBox 底部扩展补偿**：
  - 渲染完成后自动分析 SVG `viewBox`，并动态注入 `+ 28px` 底部安全高度，彻底杜绝任何复杂流程图底部文字与节点截断！
- **行内快捷修改**：图表右上角提供 `✏️ 编辑流程图` 按钮，点击即可修改 Mermaid 代码并一键完成渲染。

---

### 5. 🔍 标题完全模糊搜索与检索系统 (Fuzzy Title Search)
- **纯标题完全模糊匹配算法**：
  - 支持中英文子串包含、空格多关键词分词（如输入 `订单 履约`）、以及字符流顺序模糊检索；
  - 键入关键词即时毫秒级过滤右侧抽屉需求卡片与页面打点徽标，快速定位目标规约；
  - 右侧提供一键清空按钮 `✕`，支持快速重置全量列表与无匹配友好空状态提示。

### 6. 🔒 右侧抽屉安全管理锁模式 (Management Lock Mode)
- **日常安全浏览模式（默认）**：
  - 卡片隐藏排序/删除按钮，禁用拖拽，彻底防止日常查阅和定位误触；
- **排序与删除管理模式（点击 `⚙️ 排序管理` 开启）**：
  - 抽屉浮现橙色提示条与 `✓ 完成退出`；
  - 开放卡片 `⠿` 拖拽手柄、`🔢 移至`（直接输入数字跳转序号）、`▲`、`▼` 及 `🗑️ 删除`。

### 6. 纯净界面与独立新网页 PRD 大屏 (Document View & New Tab)
- **清除多余胶囊**：彻底移除全局右上角 `.prd-top-doc-wrapper`；
- **抽屉常驻入口**：在右侧抽屉底部常驻 `📑 查看完整PRD` 按钮；
- **独立新网页打开 (`↗️ 在新网页打开`)**：
  - 在独立新标签页中打开纯净 PRD 大屏文档，带固定 TOC 目录大纲；
  - 适配打印排版，按 `Ctrl+P / Cmd+P` 一键导出交付级 PDF。
