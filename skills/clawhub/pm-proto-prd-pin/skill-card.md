Mitigation: Use no sensitive PRD data during evaluation and confirm which external services receive content.

Mitigation: Inspect the installer’s target directory effects before running it.

Risk: The security analysis was partial and cannot establish that unreported behavior is safe.

Mitigation: Review the skill before use and evaluate it in a disposable project without sensitive data.
