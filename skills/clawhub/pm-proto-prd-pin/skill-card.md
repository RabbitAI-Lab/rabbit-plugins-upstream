## Description:

Adds an interactive, grouped PRD annotation and specification system to HTML, Vue, React, and Next.js prototypes, with editing, navigation, persistence, and Markdown export.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and product teams use this skill to add grouped, editable PRD pins to web prototypes, then manage, persist, navigate, and export their specifications.
