## Description:

Helps developers design and troubleshoot DocSpring HTML/CSS templates, check rendered pages, and convert PDF templates to HTML.

This skill is ready for commercial/non-commercial use.

## Publisher:

[docspring](https://clawhub.ai/user/docspring)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to create or update DocSpring HTML templates, diagnose layout and rendering issues, and verify changes with previews before publishing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Sensitive customer information could be exposed if it is used in template previews.

Mitigation: Use made-up sample data for tests, as the skill recommends, and review data-handling requirements before submitting sensitive information.

Risk: The security review was partial and has medium confidence.

Mitigation: Review the skill’s guidance and consider complete scan coverage before installing if that matters for your use case.
