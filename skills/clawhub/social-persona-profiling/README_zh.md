# 社交人格侧写（Social Persona Profiling）

基于社交痕迹——头像、profile/封面背景、昵称、可见性设置、聊天行为、分享内容、自述标签——跨平台（微信、WhatsApp、Instagram、LinkedIn、Telegram、X）跨文化地做人物侧写、关系分析，或给出"接下来该怎么办"的行动指导。

一个 WorkBuddy / OpenClaw skill。

**版本**：v1.0.0（2026-08-07）

## 功能

- **大五人格（OCEAN）**作为科学主轴做特质估计
- 辅助框架：自我呈现与自我监控（Goffman/Snyder）、Higgins 自我差异、防御机制（Vaillant）、依恋与 burnout 信号
- **三层画像**：外在人设 / 内显真实 / 自述标签
- **关系危机归因** + 按场景（职场/亲密/朋友/防骗）的**行动指导**

## 诚实性保障

- 三层置信度分级（客观事实 / 行为推断 / 工作假设）
- 年龄、文化、平台、性格基线、数字化世代的调节变量校正
- 投射对称性检查、巴纳姆效应过滤、过度推断清单
- 伦理边界：拒绝操纵/PUA 意图；不用于歧视性决策（招聘/信贷/背调）

## 文件

- `SKILL.md`——核心指令（硬规则、步骤、输出格式、陷阱）
- `references/psych-frameworks.md`——理论工具箱（7 个框架按效度排序）
- `references/moderators.md`——调节变量（年龄/文化/平台/性格/世代）
- `references/consulting-playbook.md`——按场景的"接下来怎么办"指导

## 使用

```
"分析这个人的头像/profile——他什么性格？"
"帮我理解这段关系 / 我接下来该怎么办？"
```
