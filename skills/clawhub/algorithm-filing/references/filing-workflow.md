# 分步填报流程指引

> 系统入口：https://beian.cac.gov.cn
> 咨询电话：(010)82990520 / (010)82990521

---

## 前置准备（材料准备阶段）

### 时间估算：2-3 个月

在登陆系统之前，必须先完成以下工作：

1. **对接属地网信办**
   - 主动联系企业注册地的网信部门
   - 了解当地是否有额外要求（如北京要求更严）
   - 获取备案材料模板（上线备案表、安全评估模板等）
   - 确认提交方式和审核流程

2. **内部安全自评估**
   - 成立安全评估工作小组（技术 + 安全 + 合规 + 法务）
   - 开展语料安全、模型安全、内容安全全维度自评
   - 撰写安全评估报告（60-90 页）
   - 准备配套证据材料

3. **准备核心材料**
   - 上线备案表（主表）→ 仔细填写四大类信息
   - 安全评估报告 → 逐条对齐 GB/T 45654-2025
   - 模型服务协议 + 隐私政策 → 各约 5-10 页
   - 拦截关键词列表 → ≥ 17 类风险，建议 5000+ 词条
   - 评估测试题集 → ≥ 2000 生成 + 500 拒答
   - 测试账号 → 20 个 + 配套文档

## 第一步：主体注册

### 操作步骤

1. 访问 https://beian.cac.gov.cn
2. 点击「填报人员入口」→「开始填报」
3. 注册账号（使用企业邮箱）
4. 完成实名认证

### 填写内容

| 字段 | 说明 | 注意事项 |
|------|------|---------|
| 主体名称 | 营业执照上的全称 | 与营业执照完全一致 |
| 统一社会信用代码 | 18 位 | 核对无误 |
| 主体类型 | 企业法人/事业单位等 | 按营业执照选 |
| 注册地 | 省-市-区 | 精确到区 |
| 详细地址 | 实际经营地址 | 能收快递的地址 |
| 网址 | 企业官网 | 选填但建议填写 |
| 月活跃用户量 | 所有产品合计 | 可估算 |
| 法定代表人姓名 | 与身份证一致 | |
| 法定代表人证件号 | 身份证号 | |
| 算法安全责任人 | 姓名+证件+手机+邮箱 | 必须为公司在职员工 |

### 上传附件

- `算法备案承诺书`：系统下载模板 → 填写 → 法人签字 → 盖章 → 扫描 PDF
- `落实算法安全主体责任基本情况`：系统下载模板 → 填写 → 盖章 → 扫描 PDF

### 提交等待

- 主体审核时间：3-5 个工作日
- 通过后进入下一步

## 第二步：算法信息填报

### 2.1 选择算法类型

进入「备案信息」页面，选择算法类型：

| 产品情况 | 选择类型 | 角色 |
|---------|---------|------|
| 自研/微调大模型 | 生成合成（深度合成） | 服务提供者 |
| 仅提供 API | 生成合成（深度合成） | 服务技术支持者 |
| 涉及个性化推送 | 个性化推送类 | 服务提供者 |
| 涉及搜索排序 | 排序精选类 | 服务提供者 |

### 2.2 填写算法基础属性信息

| 字段 | 填写要点 |
|------|---------|
| 算法名称 | 格式：品牌名 + 功能 + 算法类型，如"XX大模型文本生成算法" |
| 算法类型 | 按上表选择 |
| 应用领域 | 如：智能客服、AI写作、AI绘画、虚拟人 |
| 上线时间 | 已上线填实际日期，未上线填预计日期 |

### 2.3 上传核心附件

- `算法安全自评估报告`：系统下载模板 → 按框架填写 → 盖章 → 扫描 PDF
- `拟公示内容`：系统下载模板 → 通俗描述算法 → 盖章 → 扫描 PDF

### 2.4 填写算法详细属性信息

参考页面右侧说明文字，逐项填写：

**算法数据**：
- 数据来源（自采/采购/开源/用户反馈）
- 数据规模
- 数据类型（文本/图像/音频/视频/多模态）
- 数据标注情况
- 个人信息处理情况

**算法模型**：
- 模型名称和版本
- 模型架构（Transformer/Diffusion/MoE 等）
- 参数规模
- 开发方式（自研/基于开源微调/调用第三方）
- 训练方式

**算法策略**：
- 算法原理概述
- 主要技术路线
- 输入输出模态

**算法风险与防范机制**：
- 已识别的安全风险
- 风险防范措施
- 投诉举报机制
- 人工干预机制

> 💡 **保存草稿**：页面下方有「保存至草稿箱」按钮，建议填写过程中定期保存。

## 第三步：产品及功能信息填报

### 操作步骤

返回主页 → 点击「产品及功能信息」

### 3.1 添加产品信息

| 字段 | 填写要点 |
|------|---------|
| 产品名称 | 与 APP Store/应用商店一致 |
| 服务形式 | APP / 网站 / 小程序 / API（可多选） |
| 访问地址 | APP 填写下载链接，网站填写域名 |
| 服务状态 | 已上线 / 未上线 |
| 服务对象 | 面向公众 / 面向特定群体 |
| 是否实名认证 | 是 / 否 |
| 是否需前置许可 | 如有 ICP 许可证等填写 |

### 3.2 添加功能访问路径

- 路径名称：如"首页 → AI 创作 → 文本生成"
- 上传路径截图（每步截图，合成一张长图或分包上传）

### 3.3 添加功能信息

- 功能名称
- 功能介绍（50-200 字）
- 使用的算法（从已填写的算法中选择关联）

## 第四步：提交审核

### 操作步骤

1. 返回「备案信息」页面
2. 确认所有信息填写完整、准确
3. 确认所有附件已上传且格式正确
4. 勾选「我承诺上述填报信息真实有效」
5. 点击「提交」

### 提交后

- 状态变为「审核中」
- 系统会显示预计审核时间
- 保持联系人手机畅通

---

## 审核周期与跟进

### 审核分两阶段

| 阶段 | 审核方 | 审核内容 | 周期 |
|------|--------|---------|------|
| 初审 | 属地网信办 | 材料完整性、格式规范性 | 15-20 工作日 |
| 复审 | 国家网信办 | 算法合理性、数据合规性、安全措施有效性 | 2-3 个月 |

### 审核状态查询

在系统「进度查询」查看状态：

| 状态 | 含义 | 操作 |
|------|------|------|
| 待提交 | 尚未提交 | 继续填写 |
| 审核中 | 已提交，正在审核 | 等待，保持联系畅通 |
| 需补正 | 材料不全/有问题 | 按提示修改后重新提交 |
| 审核通过 | 备案成功 | 下载备案编号，进行公示 |
| 不予备案 | 不符合条件 | 查看原因，整改后重新申请 |

### 驳回处理

如果状态变为「需补正」：
1. 仔细阅读驳回意见（通常列出具体问题）
2. 逐条对整改
3. 修改完成后重新提交
4. 常见驳回原因见 [常见驳回原因](common-rejection-reasons.md)

---

## 第五步：审核通过后

### 5.1 获取备案编号

- 格式：`网信算备 XXXXXXXX 号`
- 下载备案证书/通知书

### 5.2 公示备案信息

- **必须在产品显著位置公示**：
  - APP：启动页 / 设置页 / 关于页
  - 网站：页脚 / 关于我们
  - 小程序：设置页 / 关于
- 公示内容：备案编号 + 公示链接

### 5.3 添加AI标识

- AI 生成内容需添加显著标识（"AI 生成"水印/标签）
- 不能放在角落小字——"显著、醒目"是硬性要求
- 提供关闭 AI 功能的选项（如适用）

## 大模型备案 vs 大模型登记流程区分

### 大模型备案流程（自研/微调）

```
线下准备（2-3月）→ 属地网信办初审 → 国家网信办复审 → 公示
```

- 全程 **线下+线上**混合
- 先办大模型备案 → 再办算法备案
- 两者通过后统一公示

### 大模型登记流程（调用API）

```
线上提交 → 属地网信办审核 → 发放上线编号
```

- 相对简化，不需全套大模型备案材料
- 但需证明底层模型已备案
- 周期 3-4 个月

## 时间线总览

```
时间轴（总计 4-6 个月）

月份 1-2：  [材料准备]  安全评估报告撰写 + 证据材料收集
月份 2-3：  [属地初审]  对接网信办 + 材料提交 + 初审
月份 3-4：  [系统填报]  主体注册 + 算法信息填报 + 产品关联
月份 4-5：  [国家复审]  等待技术专家评审
月份 5-6：  [公示上线]  获取备案号 + 产品公示
```

> ⚠️ 2026 年起，各应用商店上架审核强制要求备案凭证，请将此时间纳入产品上线计划。
