# A股个股深度投资报告生成器

为用户提供专业的A股个股深度投资研究报告，覆盖光通信、半导体、PCB、新材料、电子元器件等科技制造领域。

## 触发方式

用户提供公司名称（中文简称即可），即可触发报告生成。支持：
- 单个公司：「帮我写一份中际旭创的投资报告」
- 批量公司：「帮我写长飞光纤、华工科技、胜宏科技的投资报告」
- 指定日期：「现在是2026年8月6日，帮我写xxx的投资报告」

## 报告命名规则

文件名格式：`{主营业务}_{公司简称}_投资报告.md`

示例：
- `光模块_中际旭创_投资报告.md`
- `光纤光缆_长飞光纤_投资报告.md`
- `PCB_胜宏科技_投资报告.md`

主营业务需简短概括公司最核心的业务板块（2-4字）。

## 工作流程

### 1. 信息搜集

对每个公司，使用 `mimo_web_search` 搜索以下信息：
- `公司名 2025年报 主营业务 营收 利润` — 获取最新年报数据
- `公司名 2026 业绩预期 机构预测` — 获取市场一致预期
- `公司名 最新消息 利好 利空` — 获取近期消息面

搜索时以2025年年报数据为基础，2026年预测数据为重点。

### 2. 报告撰写

参考 `references/template.md` 中的完整模板结构撰写报告。每个章节必须填写完整，不得留空或写「待补充」。

关键要求：
- **公司概况**：200-300字简介，包含核心竞争力定位
- **业务构成**：拆分至各业务板块，给出营收占比、毛利率、增速
- **财务预测**：给出2026E/2027E的营收和利润预测，附增速假设
- **分部估值**：SOTP法，各业务分别给予PE倍数，算出目标市值和每股价值
- **投资逻辑**：3-5条核心逻辑，分短中长期催化剂
- **六维分析**：每维度给出具体分析和1-5星评分
- **交易计划**：建仓区间、止损位、目标位、持仓周期
- **综合评分**：加权计算总分

### 3. 输出规则

- 报告写入用户指定的文件夹（默认工作区根目录）
- 使用 `write` 工具写入 `.md` 文件
- 批量报告时，先搜集完所有公司数据，再逐个写入
- 报告底部附免责声明

## 六维分析框架

每份报告底部必须包含以下六个维度的深度分析：

| 维度 | 权重 | 核心关注点 |
|------|------|-----------|
| 政策面 | 15% | 产业政策、财税补贴、贸易政策、监管趋势 |
| 基本面 | 25% | 行业空间、竞争格局、公司质地、财务健康度 |
| 技术面 | 15% | 趋势、均线、支撑压力、量价关系、形态、MACD/KDJ/RSI |
| 情绪面 | 15% | 市场情绪周期（冰点/发酵/高潮/退潮）、行业情绪、个股情绪 |
| 消息面 | 15% | 近期利好/利空消息梳理、综合判断 |
| 资金面 | 15% | 北向资金、主力资金、融资融券、机构持仓、大宗交易 |

每维度评分1-5星，加权计算综合得分。

## 批量生成策略

当用户要求生成多份报告（>5个公司）时：
1. 先用多个并行 `mimo_web_search` 搜集所有公司基础数据（每轮4个并行搜索）
2. 分批搜集完毕后，逐个用 `write` 写入报告文件
3. 每写完一批（3-5个），给用户简要进度反馈
4. 全部完成后，输出汇总清单

## 注意事项

- 数据以2025年年报为基础，预测至2026E/2027E
- 所有财务数据需注明来源（年报/机构预测/估算）
- 估值和交易计划仅为参考，报告末尾必须附免责声明
- 报告中的「当前」指用户指定的日期（默认今天）
- 技术面分析基于近期K线走势，需搜索最新股价信息
