## Description:

Creates promotional videos, social ads, and product demos from a website URL using dLazy's website-to-video workflow.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers provide a website URL and prompt to create a promotional video, social ad, or product demo, and can continue work in a selected project.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected attachments are sent to dLazy, and use may consume service credits.

Mitigation: Choose the intended project, share only attachments approved for upload, and account for service-credit use.

Risk: A saved API key can continue to grant access to the dLazy organization.

Mitigation: Revoke the saved API key when it is no longer needed.
