## Description:

Helps turn website URLs into promotional videos, social ads, or product demos using the dLazy website-to-video assistant.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and marketing teams use this skill to turn a website link into a promotional video, social ad, or product demo through the dLazy service.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts, website URLs, and attached files are sent to the third-party dLazy service.

Mitigation: Share only content you are comfortable sending to dLazy; review attachments before upload.

Risk: A saved API key or global CLI installation may remain on the device after use.

Mitigation: Use the on-demand npx option to avoid a global install, and rotate or revoke the API key when access is no longer needed.
