## Known Risks and Mitigations:

Risk: Prompts, URLs, options, project context, and explicitly attached files may be sent to dLazy's hosted service.

Mitigation: Attach only files intended for upload and review URLs or project context before invoking the skill.

Risk: Using the global install path persists the dLazy CLI locally and API authentication may be stored in the user's CLI configuration.

Mitigation: Use the npx invocation when a global CLI is not desired, and rotate or revoke the dLazy API key when access is no longer needed.
