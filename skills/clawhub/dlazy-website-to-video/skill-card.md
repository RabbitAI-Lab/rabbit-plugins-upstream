## Description:

Creates promotional, social-ad, or product-demo videos from a website URL by deriving the site's branding and building a storyboard and video on a Remotion template.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers can provide a website URL to create a promotional video, social ad, or product demo based on the site's branding.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security scan was partial; CLI login and project-listing steps were reported alongside the video-generation purpose, and some referenced material was unavailable for review.

Mitigation: Before installing, confirm those CLI actions are expected and review the unavailable install and API references if relevant.

Risk: Files attached to chat are uploaded to dLazy media storage.

Mitigation: Attach only files you are comfortable sharing with the service.
