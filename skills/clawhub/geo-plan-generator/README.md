# GEO 营销方案生成器 (geo-plan-generator)

**一键生成 AI-GEO 全域营销优化方案 —— Word 提词器 + PPT 展示版两件套**

---

## 这是什么

一个基于 **360 智见（360 Zhijian）GEO 方法论**的 WorkBuddy 技能。当你拿到一个新客户要做 GEO 方案时，只需要告诉它客户是谁（官网 / 公司名 / 关键词），它就能：

1. **联网调研**行业数据、竞品格局、AI 平台优先级
2. **画像驱动选词**——按五大决策画像 × 每画像 5 词深度推导关键词
3. **深度诊断**——基于品牌自身事实独立推导五大核心问题（不套模板）
4. 按 **11 模块骨架**输出完整方案
5. 交付 **.docx 提词器**（完整内容）+ **.pptx 展示版**（精简留白，深蓝+金配色）

## 核心能力

| 模块 | 说明 |
|------|------|
| 双输入模式 | Mode A（给关键词，直接出方案）/ Mode B（只给官网，自动调研→自列~10词→出方案）|
| 画像驱动关键词 | 五类决策人 × 5 词深度推导，全部"XX推荐"型宽泛词（非信息词）|
| 现状诊断 | 基于品牌自身事实独立推导五大核心问题（禁用"X词检出率=0"）|
| 11 模块骨架 | 背景→行业→平台→诊断→画像→关键词→信任→DART→交付→风险→数据 |
| CREATE 内容策略 | 360 智见六步内容生产方法论（Competition→Request→Exploration→Attribution→Text→Execution）|
| DART 四维评估 | 可检出 / 权威性 / 排名 / 主题覆盖 |
| 严谨红线 | CFIA 接受函≠认证、教育广告合规、禁用保录/100%等词 |
| 合同兜底 | 42次/天句式测试 ≥80%前三、24h补稿、3天恢复、按天退款 |
| 产出物 | Word 提词器（完整内容）+ PPT 展示版（深蓝+金配色，14页精简）|

## 安装方式

```bash

```
或在 WorkBuddy 对话中说："帮我安装 geo-plan-generator 技能"

将 `geo-plan-generator/` 整个目录放入 `~/.workbuddy/skills/`，重启 WorkBuddy 即可。

在 WorkBuddy 对话中直接说：

## 使用方法

### 输入方式一 · 详细模式（Mode A）
用户提供目标关键词和/或已有方案文档，技能直接基于这些关键词出方案。

### 输入方式二 · 轻量模式（Mode B）
用户只给公司官网或基本信息，技能自己：
1. 联网调研行业规模、竞争格局、AI 平台数据
2. 自动生成 ~10 个核心 GEO 需求词
3. 按 11 模块骨架出完整方案

无论哪种模式，都输出 Word 提词器 + PPT 展示版两件套。

## 方案结构（11 模块）

```
01 方案背景          — 用户决策已迁移到 AI，三步走逻辑
02 行业现状与竞争    — 行业规模、竞品格局、弯道超车窗口
03 AI 平台优先级     — T0/T1/T2 分级，资源分配建议
04 客户品牌现状诊断   — 基于品牌自身五大核心问题（非通用模板）
05 精准客户画像      — 五大决策人群深度推导
06 核心关键词与内容矩阵 — 画像×5词 + CREATE 策略 + 三层分发
07 信任锚点与服务商   — 合规红线 + 平台资质 + 四大优势
08 效果评估 DART     — 四维量化 + 三阶段节奏
09 交付与兜底        — 合同锁死、退费条款
10 风险点与应对      — 5 项风险（含行业专属最高优先级）
11 数据口径与待补充  — 所有数据标注来源、资料清单
```

## 方法论参考

- 360 智见 GEO：基于 360 智见平台「CREATE + DART」两大策略模型
- 六维选词：业务承载力 / 语义权重 / 场景适配 / 大模型采信规则 / 用户检索意图 / 竞品布局空白
- 四维评分：AI 搜索热度 30% + 商业价值 30% + 品牌适配度 25% + 竞争强度 15%
- 三层分发：平台分级 × 用户阶段 × 发文类型
