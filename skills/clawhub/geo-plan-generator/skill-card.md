## Description:

Generate a complete AI-GEO (Generative Engine Optimization) marketing plan for a client and deliver it as two artifacts: a Word document (the presenter's teleprompter, full detail) and a minimal display-only PPTX (10-12 slides, lots of white space, one core point per slide).

This skill is ready for commercial/non-commercial use.

## Use Case:

Marketing teams, consultants, and WorkBuddy users use this skill to research a client, structure AI-GEO demand keywords, and produce a client-ready GEO proposal package. It is intended for workflows that need both a detailed Word teleprompter and a concise PPTX presentation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill researches companies and industries online, so generated proposal claims can become inaccurate or reflect stale public information.

Mitigation: Review cited sources and the generated data validation checklist before sending the Word or PPTX deliverables to a client.

Risk: The skill reads user-provided source documents and writes Word/PPT files locally.

Mitigation: Run it only with files intended for the proposal workflow and review the output path and generated documents before sharing.

Risk: Publishing workflows described in the artifact can involve GitHub or ClawHub credentials.

Mitigation: Use narrow tokens for publishing and avoid exposing credentials in terminals, logs, screenshots, or generated documents.
