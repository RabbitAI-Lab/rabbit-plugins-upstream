## Description:

Statista (statista.com). Use this skill for ANY Statista request — searching and reading data. Whenever a task involves Statista, use this skill instead of calling the API directly.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

External users can search Statista statistics, market indicators, and Consumer Insights, then retrieve chart data for a statistic identifier through their connected Statista account.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup directs the agent to run an unverified remote CLI installer without a separate approval step.

Mitigation: Review and approve CLI installation separately, prefer a pinned and verified release, and review or disable automatic skill synchronization.
