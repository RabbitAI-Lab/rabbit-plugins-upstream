# 小红书文案与运营完全指引

本文件为 viral-copywriting skill 的小红书专项 reference，整合了14本小红书/爆款内容专著的精华，覆盖从账号定位、内容创作、封面设计、标题公式、种草语言、运营增长到商业变现的全链路。

---

## 一、平台认知：小红书的本质

### 1.1 平台底层特征

| 特征 | 含义 | 对营销的启示 |
|------|------|-------------|
| 用户为消费而来 | 90%用户有主动搜索行为 | 内容必须可被搜到 |
| 社区氛围强 | "姐妹种草"比品牌广告可信 | 用真人视角代替官方口吻 |
| 内容长尾效应 | 一篇笔记发半年后还能被搜到 | 做优质内容比追热点更值 |
| 去中心化 | 新人也有机会爆款 | 起号期就要做好优质内容 |

### 1.2 小红书 vs 抖音 vs 其他平台

| 对比维度 | 抖音 | 小红书 |
|---------|------|--------|
| 用户状态 | 被动刷 | 主动搜 |
| 内容价值 | 娱乐消遣 | 消费决策参考 |
| 流量分配 | 中心化（大V霸榜） | 去中心化（新人也能爆） |
| 内容生命周期 | 1-3天 | 6个月以上 |
| 用户心态 | "好无聊刷一下" | "我要买XX，搜一下" |
| 流量来源 | 算法推荐为主 | 推荐+搜索（各约50%） |
| 核心受众 | 泛人群 | 年轻女性为主，泛生活方式 |

### 1.3 用户来小红书想得到什么

1. 避雷 —— "这个东西值不值得买"
2. 攻略 —— "去XX怎么玩/怎么学/怎么吃"
3. 共鸣 —— "原来不止我一个人这样"
4. 审美 —— "看好看的东西"
5. 憧憬 —— "我也想变成这样"

### 1.4 一篇"红"笔记的3个必要条件

- 可执行 —— 看完知道怎么干 → 收藏高
- 真体验 —— 人格化、有情绪 → 信任高
- 有颜值 —— 至少配图清爽 → 点击高

## 二、账号定位

### 2.1 定位公式

**你的定位 = 垂直领域 + 独特视角 + 目标人群**

```
❌ "分享生活日常"（太宽泛）
✅ "一个程序员妈妈的育儿好物测评"（垂直×人设×人群）
✅ "3年HR教你写简历：面试通过率提升80%"（专业×结果承诺）
```

**定位宣言模板：**
"我是[身份]，帮[人群]，解决[问题]"
- "我是10年HR，帮职场新人避开求职坑"
- "我是二胎妈妈，帮焦虑妈妈找到高效带娃法"

### 2.2 定位三原则

1. 够窄 —— 先切一个细分领域，做深再做宽
2. 有辨识度 —— 视觉风格、人设、语言风格至少有一项能让人记住
3. 可商业化 —— 这个方向能接广告/卖产品/引流私域

### 2.3 定位"三不"原则

- 不贪多 —— 一个号只说一件事
- 不模糊 —— 用户看完3篇笔记就知道你做什么的
- 不跟风 —— 看到别人做啥你做啥，最后哪个都不精

### 2.4 定位四步法

1. 市场调研 —— 这个赛道有没有人在做？他们的数据如何？
2. 自我分析 —— 能提供什么差异化价值？什么只有我能说？
3. 目标画像 —— 你的理想粉丝是什么样的？Ta需要什么？
4. 定位宣言 —— 一句话说清楚"我是谁，我为谁提供什么"

## 三、标题写作（小红书特供版）

### 3.1 小红书标题规则

- 字数限制：不超过20字（含标点和emoji）
- 位置要求：前20字必须包含核心搜索词
- 与封面关系：标题+封面文字需一致

### 3.2 标题关键词布局公式

**核心词 + 长尾词 + 情绪词/数字**

```
❌ "新手怎么学化妆"（太普通）
✅ "零基础学化妆｜3分钟初学眼妆教程｜学生党必看"
✅ "化妆新手别踩这5个坑！手残党也能画的日常妆"
```

### 3.3 标题五大类型

| 类型 | 原理 | 示例 |
|------|------|------|
| 含痛点 | 击中用户焦虑 | "牙黄不敢笑？亲测3个月美白方案" |
| 含数字 | 具体降低认知成本 | "5个面试必答题，答错直接淘汰" |
| 制造悬念 | 迫使用户点开看 | "千万别买戴森，除非……" |
| 身份标签 | 吸引同一人群 | "00后打工人的第一只轻奢包" |
| 场景代入 | 用户觉得就是自己 | "下班后累到不想动，就做这个菜" |

### 3.4 标题三个版本法

每个内容写3个标题：

| 版本 | 思路 | 示例 |
|------|------|------|
| 利益版 | 用户能得到什么 | "看完这篇，你的简历通过率提升50%" |
| 好奇版 | 用户会想知道答案 | "HR不会告诉你的5个简历秘密" |
| 对比版 | 制造反差 | "同样的简历，改了3行字面试邀约翻倍" |

### 3.5 标题自检

- 标题能否在5秒内让用户觉得"与我有关"？
- 用户读完标题是否知道"这对我的好处是什么"？
- 核心关键词是否在标题里？

## 四、封面设计

### 4.1 封面"三秒法则"

在双列瀑布流中，用户只用3秒决定点不点。

### 4.2 三大封面流派

| 流派 | 特点 | 适合内容 |
|------|------|---------|
| 大字报型 | 封面3-6个大字，直接说内容 | 干货/攻略 |
| 对比型 | 使用前后/好vs坏 | 美妆/健身/家居 |
| 氛围型 | 高颜值高清图，不叠加文字 | 穿搭/探店/生活 |

### 4.3 封面制作三不原则

1. 不复杂 —— 一眼看过去知道讲什么
2. 不虚假 —— 封面和内容一致，否则用户会反感
3. 不刺眼 —— 颜色搭配舒适，不要荧光色

### 4.4 封面规格

- 比例：3:4（1080×1440px）
- 安全区域：上下预留80-120像素
- 设计完成后缩至手机最小尺寸自测

### 4.5 七种高点击封面风格

| 风格 | 适用场景 | 优势 |
|------|---------|------|
| 极简大字报 | 干货分享、观点类 | 信息流中格外突出，收藏率高 |
| 真人出镜+情绪 | 美妆、穿搭、生活 | 拉近距离，情绪感染力强 |
| 前后对比图 | 减肥、护肤、改造 | 最直观说服力 |
| 思维导图学霸款 | 教程、方法论 | 专业感强，收藏率极高 |
| 拼图留空加字 | 产品展示、攻略 | 展示多张同时保持干净 |
| 涂鸦贴纸风 | 工具贴、生活技巧 | 视觉丰富，适合年轻用户 |
| 纯色底+文字 | 干货型、知识类 | 花哨封面中反而突出 |

## 五、文案写作

### 5.1 小红书文案的人格密码

#### 三种最受欢迎人设

| 人设 | 语气 | 适合领域 |
|------|------|---------|
| 闺蜜分享型 | "姐妹！这个真的绝了！" | 美妆、穿搭、好物 |
| 老师指导型 | "新手必看！这3个坑千万别踩" | 知识、技能、职场 |
| 踩坑复盘型 | "花了8000块才明白的道理" | 理财、装修、健身 |

#### 同一产品三种口吻示例

- 闺蜜型："姐妹们我不允许还有人不知道这个！上次逛街发现的宝藏店铺……"
- 老师型："如何选对粉底色号？3步教会你，从此不踩雷"
- 踩坑型："花了一万块买粉底液才明白：色号不是越白越好"

### 5.2 标准三段式框架

```
【钩子】一句话让我想点开
【肚皮】干货/体验/方法
【尾巴】互动/收藏引导
```

### 5.3 首段钩子（前30字决定生死）

| 钩子类型 | 示例 |
|---------|------|
| 痛点型 | "如果你也长了闭口，这3个坑千万别踩" |
| 悬念型 | "千万别买这个，除非你做好了真香的准备" |
| 结果型 | "跟着练了30天，我的马甲线终于回来了" |
| 反常识型 | "你以为喝水越多皮肤越好？错了" |

#### 开头三连击法

**身份锚定 + 痛点唤醒 + 利益预告**

"作为一个连续创业失败3次的人（锚定），我每天都在焦虑要不要放弃（痛点）。直到第4次，我做了这3个改变（预告），终于活过来了。"

### 5.4 "有用"比"好看"更重要

| 维度 | 差的笔记 | 好的笔记 |
|------|---------|---------|
| 视角 | "我做了什么" | "你能学到什么" |
| 内容 | 流水账式记录 | 有步骤、有方法、有建议 |
| 价值 | 自我感动 | 别人看完觉得"学到了" |
| 标题 | "今天去旅游" | "3天2晚丽江攻略：人均2000玩到爽" |

### 5.5 正文的伞状结构

```
一句核心结论（伞柄）
一两个支撑论据（伞骨）
若干具体方法/案例（伞面）
```

示例（职场笔记）：
- 伞柄："面试时被问到'你为什么离开上一家公司'，这样回答最加分"
- 伞骨："不要只说前公司坏话 / 不要含糊其辞 / 不要暴露情绪"
- 伞面："我整理了3个高情商回答模板，直接套用👇"

### 5.6 阶梯式展开

```
第一步：最简单/最基础的操作
第二步：进阶操作
第三步：高阶技巧/坑
```

### 5.7 口语化的7个技巧

1. 把"您"改成"你" —— 小红书不需要敬语
2. 多分段 —— 一段最多3行，留白让眼睛休息
3. 用短句 —— 一句只说一件事
4. 用语气词 —— "真的绝了""太可了吧""没想到这么……"
5. 加emoji —— 小红书特色，但不滥用（每段1个即可）
6. 用"你"开头 —— 让读者产生代入感
7. 少用成语和书面语 —— 越像人话越好

```
❌ "在如今竞争激烈的护肤品市场，选择一款适合自己的产品至关重要"
✅ "选护肤品真的太容易踩雷了！花了好多钱才找到适合自己的"
```

### 5.8 种草语言对照表

| 书面语/广告词 | 小红书种草语言 |
|-------------|--------------|
| "蕴含天然植物提取物" | "成分党狂喜！8种植物提取，温和不刺激" |
| "采用高科技封装工艺" | "真的，用了它我才知道什么叫锁鲜技术" |
| "能有效改善肌肤状态" | "用了两周，皮肤肉眼可见变亮了" |
| "性价比极高的入门选择" | "百元价位里的战斗机！新手首推" |
| "这件衣服面料很舒服" | "穿上身的那一刻，就像被云朵轻轻包裹着，柔软到不想脱下来" |

### 5.9 安全表达（合规替代版）

| 想表达的意思 | 安全的说法 |
|------------|-----------|
| 这个东西最好 | "在我用过的同类产品中，这个最让我惊喜" |
| 效果特别明显 | "身边的人都说我最近状态变好了" |
| 性价比高 | "这个价位的产品里，它的表现真的超出预期" |
| 比竞品好 | "之前也试过其他几个，最后留下了这个" |

### 5.10 配图要求

- 数量：6张以上（多图展示充足信息）
- 排版：统一滤镜、统一字体风格
- 重点标注：在图片上加箭头/圈/文字标注
- 信息图：把核心信息做成图，方便用户保存

### 5.11 视频笔记要求

- 前3秒必须有内容（不要"大家好今天我要介绍的是……"）
- 字幕必须有（很多用户静音刷视频）
- 时长建议：30-60秒，太长完播率低

## 六、素人博主专项

### 6.1 素人博主的"三条路"

| 路线 | 适合人群 | 难度 | 变现速度 |
|------|---------|------|---------|
| 知识型 | 有专业背景（设计/HR/育儿/健身） | ★★ | 中等，靠课程+咨询 |
| 经验型 | 踩过坑的人（装修/育儿/理财/整牙） | ★ | 快，靠好物推荐 |
| 兴趣型 | 某方面特别爱研究（穿搭/做饭/探店） | ★★★ | 慢，但上限高 |

### 6.2 找到自己的标签（三个自问）

1. 朋友最常找我咨询什么？（你的天然优势领域）
2. 我踩过什么坑，花了多少冤枉钱？（你的共鸣点）
3. 我每天花最多时间做什么？（你的内容素材库）

### 6.3 素人爆款的4个必须

1. 必须解决一个具体问题 —— "今天午饭吃什么？"而不是"健康饮食指南"
2. 必须让用户觉得"我也行" —— 不要用滤镜把效果美化成"不可能达到"
3. 必须有可复制的步骤 —— 只要三步/五步，不要抽象
4. 必须有真实的情绪 —— "我当时崩溃了" > "根据相关研究"

### 6.4 素人vs大V的内容区别

| 对比 | 大V | 素人 |
|------|-----|------|
| 优势 | 品牌资源、数据团队 | 真实感、接地气、无距离 |
| 内容风格 | 精致/专业 | 粗糙但真实 |
| 用户信任 | "他们收了钱的" | "真人在用，可信度更高" |
| 推荐打法 | "XX品牌首发" | "被问疯了的XX，自用了半年" |

### 6.5 真实感的4个写作技巧

1. 不要完美开头 —— ❌"今天给大家分享一个很棒的方法" / ✅"坦白说，我也走了很多弯路才找到这个方法"
2. 写数字但不要太精确 —— ❌"我用了32天7小时" / ✅"坚持了一个多月，效果自己都没想到"
3. 承认自己不够好 —— ❌"用了这个，皮肤立刻变好" / ✅"虽然还有痘印，但比一个月前好太多了"
4. 加入"当时在想什么" —— ❌"我选择了A方案" / ✅"当时纠结了很久，最后还是选了A，因为……"

### 6.6 素人"3×3"选题矩阵

| 时间维度\受众 | 新手 | 进阶 | 硬核玩家 |
|-------------|------|------|---------|
| 准备前 | "学XX之前必须知道的5件事" | "XX入门要花多少钱？" | "XX认证/考证路径" |
| 过程中 | "第1个月做了什么" | "踩过最大的坑" | "我不推荐的3种方法" |
| 结果展示 | "30天对比" | "半年效果复盘" | "和高手交流后的反思" |

## 七、企业号运营

### 7.1 企业号 vs 个人博主

| 维度 | 个人博主 | 企业号 |
|------|---------|-------|
| 目标 | 涨粉变现 | 品牌曝光+线索转化 |
| 内容重心 | 人设 | 产品价值+使用场景 |
| 变现方式 | 广告/带货 | 私信/表单/店铺 |
| 用户期待 | 看内容 | 了解产品或服务 |

### 7.2 "三三三"法则

#### 三个内容方向

| 类型 | 比例 | 目的 | 示例 |
|------|------|------|------|
| 种草型 | 40% | 让用户"想要" | 产品使用场景、效果展示 |
| 干货型 | 40% | 让用户"信任" | 行业知识、选购指南、避坑贴 |
| 促销型 | 20% | 让用户"下单" | 限时福利、新品首发、活动信息 |

#### 三个核心角色

1. 行业老师 —— "教你选（你家品类的）好产品"
2. 朋友推荐 —— "真实体验分享，说产品也说不完美"
3. 品牌发言人 —— "新品速递、品牌故事、活动预告"

#### 三个避免

1. 避免"公司发言稿" —— 不要用"我们公司致力于……"
2. 避免"通篇广告" —— 80%的内容先给用户价值，再推产品
3. 避免"没人情味" —— 企业号也要有固定人设

### 7.3 获客闭环

```
笔记曝光 → 点击阅读 → 产生兴趣 → 关注/收藏 → 私信/表单(留资) → 转化
```

### 7.4 留资方法（合规版）

- 私信自动回复诱饵："回复'资料'领取完整攻略"
- 笔记中埋诱饵："篇幅有限，完整清单放在主页/私信了"
- 评论区引导："想了解更多，私信我即可"
- 置顶笔记做引流：置顶一条专门讲"你能获得什么"

### 7.5 企业号健康数据参考

| 指标 | 及格线 | 优秀线 |
|------|-------|-------|
| 单篇平均曝光 | 5000 | 2万+ |
| 笔记点击率 | 12% | 20%+ |
| 互动率 | 5% | 10%+ |
| 私信转化率 | 2% | 5%+ |

## 八、算法与流量

### 8.1 三层推荐漏斗

```
初始曝光（200-500浏览）
  → 点击率≥15% → 进入中级池（2000-5000）
  → 互动率≥8% → 进入高级池（2万-10万+）
  → 收藏率≥5% + 长尾搜索 → 成为长期爆款
```

### 8.2 CES评分（核心算法）

```
CES = 点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8
```

关注权重最高，互动深度决定推荐量。

### 8.3 各层级门槛

| 层级 | 曝光量 | 晋级条件 |
|------|-------|---------|
| 冷启动 | 0-200 | 前2小时CTR≥8% |
| 初级 | 200-500 | 互动率≥5% |
| 中级 | 5000-2万 | 收藏率≥3% |
| 高级 | 10万-500万 | 转化率>2% |

### 8.4 数据指标健康范围

| 指标 | 健康值 | 含义 |
|------|-------|------|
| 点击率 | >15% | 标题+封面OK |
| 收藏率 | >5% | 内容"有用" |
| 评论率 | >1% | 内容有讨论空间 |
| 互动率 | >8% | 综合指标，越高越容易被推荐 |

### 8.5 数据异常排查表

| 现象 | 可能原因 | 解决 |
|------|---------|------|
| 曝光突然归零 | 内容被限流/违规 | 检查通知、申诉 |
| 点击率<10% | 标题或封面不行 | 换标题重发 |
| 互动率<3% | 内容不够好 | 优化内容质量 |
| 单篇爆好其他都差 | 运气成分大 | 拆解爆款规律，复制 |

## 十一、互动引导

### 11.1 引导评论的6种句式

| 句式 | 示例 |
|------|------|
| 选A还是B | "你们更喜欢第1套还是第2套穿搭？" |
| 求分享 | "还有什么宝藏店铺？评论区安利给我！" |
| 求认同 | "不会只有我一个人这么觉得吧？" |
| 求建议 | "求大数据把我推给懂行的姐妹！" |
| 答读者问 | "关于XX的问题，评论区问我，我来回答" |
| 接龙互动 | "一人说一句XX，我先来！" |

### 11.2 互动提升5个小心机

1. 抛出选择题 —— "A和B你选哪个？评论区告诉我"
2. 制造赞同感 —— "相信不止我一个人这样"
3. 留下讨论空间 —— "你们觉得这样对吗？"
4. 引导分享 —— "@你的闺蜜/朋友来看"
5. 设置利益诱饵 —— "前100位收藏送XX"

### 11.3 高级互动策略

| 策略 | 操作 | 效果 |
|------|------|------|
| 抢沙发 | 发完笔记马上自己评论 | 带动第一条互动氛围 |
| 建话题 | 在评论区留一个讨论方向 | 增加评论深度 |
| 巧用@ | @同领域博主互动 | 互相引流 |
| 评论抽奖 | "第X楼送XX" | 刺激大量评论 |
| 粉丝提问 | 评论区征集问题→写成新笔记 | 流量循环 |

### 11.4 评论回复3秒原则

- 及时 —— 24小时内回复所有评论（算法加分）
- 有内容 —— 不要只回"谢谢"，多聊两句
- 有价值 —— 用户问了问题，你的回应对其他读者也有用

### 11.5 引导关注（小红书CES权重最高×8）

小红书CES评分中，关注权重是点赞的8倍。引导关注不是求关注，而是让读者"忍不住想关注你"。

**① 利益钩子法**
- "关注后私信我，免费帮你诊断账号定位"
- "关注后点击合集，查看全部10篇教程"
- "新关注的粉丝私信「资料」直接领取，不用转发"

**② 下期预告绑定**
- "下期讲XX（评论区呼声最高的话题），关注别错过！"
- "本周五更新「XX系列」第3篇，关注后第一时间收到"

**③ 人格化连接**
- "我是XX，在这个行业做了8年。每天分享真实经验，不写通稿"
- "觉得有用就关注我，以后每次更新都会推送到你首页"

**④ 价值承诺**
- "这个账号只写「XX领域」实操干货，不讲大道理"
- "我每周更新3篇，全部是亲测有效的方法论"

**⑤ 系列内容绑定**
- "这是「XX入门到精通」的第5篇，前4篇关注后点合集免费看"

**⑥ 文末关注引导卡片模板**
```
━━━━━━━━━━━━
📌 关于「账号名称」
🔹 定位：XX领域实操干货
🔹 更新：每周3篇原创
🔹 特色：只讲方法论+真实案例
👉 觉得有用就关注我，解锁更多技巧
━━━━━━━━━━━━
```

**小红书关注引导三忌：**
1. 不能放微信号/二维码/外部链接
2. 不要生硬"求关注求点赞"
3. 不要篇幅过长——关注引导控制在1-2句话最自然

## 十二、数据复盘

### 12.1 每天要看的

1. 昨日曝光 —— 有没有波动异常
2. 昨日新增关注 —— 哪些笔记在涨粉
3. 评论待回复 —— 及时回复

### 12.2 每周要分析的

| 分析维度 | 看什么 | 怎么优化 |
|---------|--------|---------|
| 点击率 | 哪个标题最好 | 把低点击的标题风格淘汰 |
| 收藏率 | 哪类内容收藏高 | 加大这类内容产出 |
| 评论率 | 哪类内容引起讨论 | 多写有争议/有观点内容 |

### 12.3 如何判断是否该放弃一个方向

发8-10篇同方向内容后，如果：
- 自然流量始终<1000 → 方向需要调整
- 收藏率始终<3% → 内容不够"有用"
- 评论始终<5条 → 内容没有讨论空间

不要"等到爆"，要"试到对"。

## 十三、薯条投放

### 13.1 什么时候该投

| 情况 | 投不投 | 说明 |
|------|--------|------|
| 数据差的笔记 | 不投 | 内容质量有问题，投了也浪费 |
| 自然流跑得好的 | 投 | 趁热打铁，扩大爆款曝光 |

### 13.2 投放三步走

1. 看自然数据 —— 发出去24小时，点击率≥15%才投
2. 小额测试 —— 先投100元，看能不能带动自然流量
3. 放大投入 —— 数据持续向好，追加到500-1000元

## 十四、起号实操

### 14.1 新手最容易犯的5个错误

1. 上来就发广告 —— 先做价值输出
2. 内容太杂 —— 系统无法判断你是谁
3. 不看数据 —— 发了就不管了
4. 标题随便写 —— "今天吃的蛋糕"毫无搜索价值
5. 封面不精致 —— 小红书用户对审美有基本要求

### 14.2 冷启动期策略（前1-2个月）

- 坚持每周3-5更 —— 保持活跃度
- 每篇做好关键词布局 —— 让系统知道你是谁
- 多互动 —— 去同领域热门笔记下互动蹭曝光
- 不删数据差的笔记 —— 删了会被降权

### 14.3 起号3个千万不要

1. 不要"准备好了再开始" —— 先发30条，边发边优化
2. 不要追求每一条都完美 —— 完播的爆款 > 精美的数据差
3. 不要频繁改定位 —— 发了20条还没数据再考虑换方向

## 十五、变现路径

### 15.1 从0到1的变现流程

```
内容积累 → 粉丝增长 → 品牌邀约 → 置换/佣金 → 广告变现
  1-2个月     500粉      3-6个月     持续运营     1万粉+
```

### 15.2 各阶段策略

| 阶段 | 粉丝 | 核心任务 | 变现方式 |
|------|------|---------|---------|
| 冷启动 | 0-500 | 攒内容、找定位 | 先不想变现 |
| 品牌好感 | 500-5000 | 内容质量稳定输出 | 品牌置换、好物推荐 |
| 变现入轨 | 5000-2万 | 数据稳定，有爆款 | 品牌合作（报价提升） |
| 成熟博主 | 2万+ | 系统化内容矩阵 | 广告+直播+私域 |

### 15.3 变现原则

- 不用不测不推荐 —— 亲自试用是素人最大的信任资产
- 隐晦不等于真诚 —— 标明"合作"/"广告"，用户反而更信任
- 不要降价接单 —— 一个低价的合作拉低的是整个账号的商业价值

### 15.4 尽早开通的功能

1. 好物推荐（0粉就能开）—— 笔记里挂商品链接赚佣金
2. 品牌合作（500粉即可）—— 官方接单平台
3. 直播带货 —— 有粉丝基础后可尝试

## 十六、内容不红的5个排查维度

## 十七、平台红线与禁忌

### 17.1 最容易违规的内容

| 红线 | 解释 | 规避方法 |
|------|------|---------|
| 医疗效果承诺 | "3天美白""一周瘦10斤" | 改为"个人体验""改善"等柔性表达 |
| 虚假比价 | "全网最低价" | 没有官方授权不要写 |
| 过度引流 | 直接放微信号/二维码 | 用主页简介引导 |
| 抄袭搬运 | 直接盗图/抄袭文案 | 原创+实拍 |
| 敏感话题 | 政治/宗教/医美前后对比 | 避开就是避开 |

### 17.2 绝对不能说

1. 绝对化用语 —— "最好""第一""唯一"
2. 医疗效果承诺 —— "治疗""治愈""根除"
3. 贬低竞品 —— "比XX强多了""XX都是智商税"
4. 过度承诺 —— "用了三天就变白"
5. 价格虚标 —— "原价999现价99"但无依据
