## Description: <br>
Writes, reviews, and debugs type-safe TypeScript: type errors, narrowing, generics, tsconfig strictness, and declaration files. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[ivangdavila](https://clawhub.ai/user/ivangdavila) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to diagnose TypeScript compiler and module-resolution problems, design safer types and generics, configure tsconfig strictness, validate runtime boundaries, and migrate JavaScript or TypeScript codebases with less type-safety debt. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may reuse TypeScript-specific preferences or memory stored under ~/Clawic/data/typescript/. <br>
Mitigation: Review or delete those files before use when prior context should not influence the agent's guidance. <br>
