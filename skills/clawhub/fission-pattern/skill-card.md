## Description:

一张商品图裂变成整套素材。商品图 + 卖点 → 多角度多场景成套图，够铺满一屏。当用户说「裂变套图」「一张变一屏」「凑够详情页」「出一套图」时使用。

This skill is ready for commercial/non-commercial use.

## Use Case:

E-commerce sellers, designers, and creative teams can use a product or outfit reference image with its name and selling points to create a consistent set of images for listings and detail pages.
