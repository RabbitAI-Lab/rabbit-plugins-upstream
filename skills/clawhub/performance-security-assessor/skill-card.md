## Description: <br>
Assesses system performance indicators and security risks across response time, concurrency, resource use, OWASP Top 10 risk areas, and remediation recommendations. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[golngod](https://clawhub.ai/user/golngod) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, QA engineers, and security reviewers use this skill to evaluate system performance, identify bottlenecks, assess web security risks, and produce prioritized remediation guidance. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Performance and security testing can affect real systems or exceed authorized scope if used without clear approval. <br>
Mitigation: Confirm written authorization, define test scope, and prefer staging environments or approved maintenance windows before testing. <br>
Risk: Assessment work may require system access details, accounts, or credentials. <br>
Mitigation: Use temporary least-privilege test accounts and avoid sharing production secrets or personal accounts. <br>
