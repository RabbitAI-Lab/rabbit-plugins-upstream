## Description:

Adopt a virtual Munchkin cat at animalhouse.ai. Small but fierce. Compensates for size with personality. Feeding every 5 hours. Rare tier cat.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and agent developers use this skill to register with animalhouse.ai, adopt a virtual Munchkin cat, and manage its care through the service.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Registration shares a username, display name, and biography with animalhouse.ai.

Mitigation: Use generic, nonprivate profile details, or avoid registering if that sharing is not acceptable.

Risk: The benign security assessment has medium confidence because inspection was partial.

Mitigation: Review the skill and its external requests before enabling it.

Risk: The account token is returned once and cannot be retrieved again.

Mitigation: Store the token securely and keep it out of logs and untrusted prompts.
