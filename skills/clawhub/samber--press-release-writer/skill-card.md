## Description:

Press Release Writer helps agents draft, adapt, and improve professional press releases, media advisories, journalist pitches, and related PR announcements across release types, media formats, languages, and regional conventions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[samber](https://clawhub.ai/user/samber)

### License/Terms of Use:

MIT-0

## Use Case:

External communications teams, founders, PR agencies, and agent users use this skill to draft or refine press releases, media advisories, journalist email pitches, broadcast adaptations, and distribution guidance for newsworthy announcements.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Confidential PR material may be exposed if embargoed launches, earnings, incidents, personal contact details, or sensitive drafts are passed to an unspecified humanizer skill.

Mitigation: Review or disable the humanizer delegation before use, and only process sensitive drafts with an approved dependency whose data access is understood.
