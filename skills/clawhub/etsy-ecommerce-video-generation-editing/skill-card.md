## Known Risks and Mitigations:

Risk: The skill requires an AI Hive API key and may upload selected product photos, videos, or audio to AI Hive for processing.

Mitigation: Install only if that processing is acceptable; review media before use, avoid buyer personal data before order confirmation, and keep the API key file protected.

Risk: Generated listing media could misrepresent an Etsy product, maker process, personalization, vintage condition, or rights-cleared content.

Mitigation: Use the documented authenticity checks before publication: preserve actual product details and condition, use placeholders before customer confirmation, and verify rights for music, patterns, text, and reference materials.
