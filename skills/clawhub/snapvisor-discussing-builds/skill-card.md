## Description:

Summarizes discussions on SnapVisor builds, tests, and media, and helps users manage comments and threads after confirmation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[devino](https://clawhub.ai/user/devino)

### License/Terms of Use:

MIT-0

## Use Case:

Reviewers and project teams use this skill to catch up on SnapVisor build, test, and media discussions, then reply, react, manage threads, or follow builds with approval.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: SnapVisor access allows comments and thread state to be changed or removed.

Mitigation: Grant comment-management access only if needed, review proposed text, and confirm each change before it is made.
