## Description: <br>
MultiDesktop helps agents guide Windows users through managing multiple desktop configurations, switching desktop folder paths, and configuring per-desktop wallpapers through GUI and CLI workflows. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External users and developers use this skill to operate or automate MultiDesktop on Windows, including adding, deleting, listing, editing, and switching desktop profiles with optional wallpaper settings. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Switching profiles can persistently change the Windows Desktop folder path and wallpaper settings. <br>
Mitigation: Use folders the user controls, keep backups of important desktop files, and verify the selected profile before switching. <br>
Risk: Deleting or switching the wrong desktop configuration can disrupt the user's expected desktop layout. <br>
Mitigation: Confirm the target desktop profile name and path before delete or switch operations. <br>
