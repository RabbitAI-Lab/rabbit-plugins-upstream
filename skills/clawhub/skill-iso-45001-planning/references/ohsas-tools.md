## 风险评估工具

### 风险矩阵（5x5）

```
严重性 →
可能性 ↓  轻微  较小  中等  重大  灾难
        (1)   (2)   (3)   (4)   (5)
-----------------------------------------
频繁(5)   5    10    15    20    25
很可能(4) 4     8    12    16    20
可能(3)   3     6     9    15    18
罕见(2)   2     4     6    12    15
不可能(1) 1     2     3     5    10

风险等级：
极高风险（红色）：16-25 → 立即处理，暂停作业
高风险（橙色）：10-15 → 优先处理
中风险（黄色）：6-9 → 计划改进
低风险（绿色）：1-5 → 可接受
```

### LEC法（作业条件风险评估）

适用于作业活动的风险评估：

**公式**: D = L × E × C

| 因素 | 含义 | 取值范围 |
|------|------|----------|
| L | 可能性 | 1-10 |
| E | 暴露频率 | 0.5-10 |
| C | 后果严重性 | 1-100 |
| D | 风险值 | 计算得出 |

**L值（可能性）**:

| 分数 | 含义 |
|------|------|
| 10 | 完全可以预料 |
| 6 | 相当可能 |
| 3 | 可能，但不经常 |
| 1 | 可能性小，完全意外 |
| 0.5 | 很不可能，可以设想 |
| 0.1 | 极不可能 |

**E值（暴露频率）**:

| 分数 | 含义 |
|------|------|
| 10 | 连续暴露 |
| 6 | 每天工作时间内暴露 |
| 3 | 每周一次或偶然暴露 |
| 2 | 每月一次暴露 |
| 1 | 每年几次暴露 |
| 0.5 | 非常罕见暴露 |

**C值（后果严重性）**:

| 分数 | 含义 |
|------|------|
| 100 | 大灾难，多人死亡 |
| 40 | 灾难，数人死亡 |
| 15 | 严重伤残 |
| 7 | 重伤，有死亡可能 |
| 3 | 轻伤，需要救护 |
| 1 | 轻微，有小伤 |

**D值（风险等级）**:

| D值 | 风险等级 | 处理要求 |
|------|----------|----------|
| >400 | 极其危险 | 立即停止作业 |
| 200-400 | 高度危险 | 立即整改 |
| 70-200 | 显著危险 | 限期整改 |
| 20-70 | 一般危险 | 注意整改 |
| <20 | 稍有危险 | 可以接受 |

## 常用计算公式

### 工伤事故统计指标

**1. 工伤事故频率（千人重伤率）**
```
千人重伤率 = (重伤人数 / 平均职工人数) × 1000
```

**2. 工伤事故频率（百万工时伤害率）**
```
百万工时伤害率 = (伤亡人数 / 实际总工时) × 10^6

其中：实际总工时 = 平均职工人数 × 250天 × 8小时
```

**3. 工伤事故严重率**
```
工伤事故严重率 = (总损失工时 / 实际总工时) × 10^6
```

**4. 工伤事故死亡率**
```
死亡率 = (死亡人数 / 平均职工人数) × 10^4
```

### 职业病相关指标

**5. 职业病发病率**
```
职业病发病率 = (新发职业病人数 / 接尘/接毒人数) × 100%
```

**6. 职业健康检查异常率**
```
职业健康检查异常率 = (检查异常人数 / 检查总人数) × 100%
```

### 设备设施完好率

**7. 设备完好率**
```
设备完好率 = (完好设备台数 / 设备总台数) × 100%
```

**8. 特种设备检验合格率**
```
特种设备检验合格率 = (检验合格数 / 检验总数) × 100%
```

### 培训相关指标

**9. 培训覆盖率**
```
培训覆盖率 = (实际培训人数 / 应培训人数) × 100%
```

**10. 培训合格率**
```
培训合格率 = (培训合格人数 / 实际培训人数) × 100%
```
