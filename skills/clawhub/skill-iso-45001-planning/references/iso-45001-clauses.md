## 第4章 组织环境

### 4.1 理解组织及其环境

**要求**:组织应确定与职业健康安全管理体系相关联的问题，包括：
- 外部问题：法律法规、技术发展、市场竞争、社会文化等
- 内部问题：组织架构、管理理念、资源条件、企业文化等

**实施要点**:
1. 收集内外部信息（SWOT/PEST分析）
2. 识别对体系有影响的关键因素
3. 定期更新以适应变化

### 4.2 理解相关方需求

**要求**:确定与OH&S管理体系相关的相关方及其需求：

| 相关方类别 | 典型代表 | 主要需求 |
|------------|----------|----------|
| 内部 | 员工、管理层 | 安全健康的工作环境 |
| 外部 | 客户、供应商 | 合规要求、合同责任 |
| 监管 | 安监部门、卫生部门 | 法规符合性 |
| 社区 | 周边居民 | 环境安全、职业健康 |

### 4.3 确定OH&S管理体系的范围

**要求**:明确体系边界和适用性，形成文件化信息

**范围文件应包含**:
- 组织名称、地点、规模
- 覆盖的生产经营活动
- 纳入/排除的场所或活动
- 适用的相关方要求

### 4.4 OH&S管理体系

组织应按标准要求建立、实施、维护和持续改进OH&S管理体系

## 第5章 领导力

### 5.1 领导力与承诺

**最高管理者职责**:
- 对OH&S管理体系有效性负责
- 确保职业健康安全方针和目标制定
- 确保体系融入组织业务流程
- 提供资源保障
- 促进持续改进

### 5.2 职业健康安全方针

**方针要求**:
1. 适合组织宗旨、规模及风险特点
2. 包含防止伤害和健康损害的承诺
3. 包含遵守法规的承诺
4. 包含持续改进的承诺
5. 提供框架用于设定目标
6. 定期评审保持适宜性

### 5.3 组织角色、职责与权限

**职责分配要点**:
- 文件化职责分配
- 确保各层级人员了解自身职责
- 特别明确管理者代表职责
- 员工职责通常在工作描述中体现

### 5.4 策划措施

最高管理者应确保：
- 策划满足体系要求
- 体系与战略方向一致
- 体系与其他业务过程整合

## 第6章 策划

### 6.1 应对风险和机遇的措施

#### 6.1.1 策划总则

组织应策划建立OH&S管理体系的措施，包括：
- 确定需应对的风险和机遇
- 确定需满足的合规义务
- 确保措施有效实施

#### 6.1.2 危险源辨识

**危险源分类**:

| 类别 | 示例 |
|------|------|
| 物理性 | 机械、运动部件、高温、表面尖利、噪声、振动、辐射 |
| 化学性 | 气体、粉尘、烟雾、液体 |
| 生物性 | 细菌、病毒、真菌 |
| 心理社会性 | 压力、疲劳、工作暴力、骚扰 |
| 组织管理 | 流程缺陷、人机工效问题 |

**辨识范围**:
- 常规活动（正常工况）
- 非常规活动（异常、紧急情况）
- 所有作业人员
- 工作场所设施
- 考虑不可预见情况

#### 6.1.3 确定适用法规

组织应：
- 确定适用于危险源和职业健康安全的法规
- 建立获取法规的渠道
- 跟踪法规变化
- 评估合规状态

#### 6.1.4 策划措施

**基于风险评估的策划**:
- 消除危险源（最佳选择）
- 替代（用低危替代高危）
- 工程控制（隔离、密闭、通风）
- 管理措施（程序、培训、监视）
- PPE（最后防线）

**层级控制（由高到低）**:
```
消除 → 替代 → 工程控制 → 管理控制 → PPE
  ↑（效果由高到低）
```

### 6.2 职业健康安全目标及策划

#### 6.2.1 目标设定

**目标要求**:
- 与方针一致
- 可测量（可行时）
- 考虑风险控制要求
- 考虑法规要求
- 考虑相关方期望
- 设置达成时间
- 定期评审更新

#### 6.2.2 策划实现目标

应确定：
- 责任部门/人员
- 所需资源
- 完成时间
- 验证方法
- 形成管理方案

## 第7章 支持

### 7.1 资源

最高管理者应确保足够资源：
- 人力资源
- 基础设施
- 技术资源
- 财务资源

### 7.2 能力

**人员能力管理**:
1. 确定能力需求（岗位要求）
2. 评估现有能力差距
3. 制定培训计划
4. 实施培训
5. 评价培训效果
6. 保存能力证据

**能力证据示例**:
- 学历证书
- 培训记录
- 技能鉴定
- 工作经验
- 内部评价

### 7.3 意识

员工应了解：
- 职业健康安全方针
- 自身职责
- 危险源及风险
- 不符合的后果
- 改进建议的渠道

### 7.4 沟通

**沟通要求**:

| 要素 | 内容 |
|------|------|
| 内部沟通 | 上下级、部门间信息传递 |
| 外部沟通 | 与相关方、监管部门的交流 |
| 参与 | 员工在体系策划、评审、改进中的参与 |
| 协商 | 与员工代表协商相关事项 |

### 7.5 文件化信息

#### 7.5.1 创建与更新

- 标识和描述（标题、日期、作者等）
- 格式和媒体（纸质/电子）
- 评审和批准

#### 7.5.2 文件控制

| 控制要求 | 说明 |
|----------|------|
| 批准发布 | 确保文件充分性 |
| 版本标识 | 清晰标识版本号 |
| 可识别性 | 便于检索查找 |
| 发放控制 | 确保使用场所获得有效版本 |
| 防护 | 防止损坏、丢失、泄密 |
| 保存处置 | 规定保存期限和销毁方式 |

#### 7.5.3 记录控制

- 保持清晰、可识别、可追溯
- 防护损坏、变质、丢失
- 规定保存期限和责任人

## 第8章 运行

### 8.1 运行策划与控制

**控制要点**:
- 建立运行准则
- 实施控制措施
- 变更管理（评审后方可实施）
- 外包过程控制
- 采购控制

### 8.2 变更管理

**变更评审内容**:
- 变更对OH&S绩效的影响
- 变更可能引入的新危险源
- 资源需求
- 职责分配调整

### 8.3 外包

**外包控制要求**:
- 确保外包过程受控
- 考虑对组织OH&S绩效的影响
- 在组织OH&S管理体系中明确控制措施

### 8.4 采购

**采购控制要素**:
- 供应商资质审核
- 采购物品/服务OH&S评价
- 合同中OH&S要求
- 入厂检验/验收

### 8.5 承包方

**承包商管理要点**:
- 资质预审
- 入厂安全交底
- 作业过程监督
- 绩效评价与退出机制

### 8.6 应急准备与响应

**应急管理流程**:

```
识别潜在紧急情况 → 预防措施 → 响应准备 
       ↓                              ↓
    定期演练 ← 评审改进 ← 实际响应
```

**应急预案内容**:
- 紧急情况类型
- 响应职责与权限
- 人员疏散路线
- 应急联络方式
- 应急设施位置
- 处置程序
- 演练计划

## 第9章 绩效评价

### 9.1 监视、测量、分析与评价

#### 9.1.1 监视测量内容

| 类型 | 示例 |
|------|------|
| 主动监视 | 安全检查、巡检、设备检测 |
| 被动监视 | 事故统计、事件分析 |
| 合规性监视 | 法规符合性检查 |
| 绩效评价 | KPI趋势分析 |

#### 9.1.2 合规性评价

**合规性评价周期**:
- 定期评价（通常每年）
- 法规变化时及时评价
- 组织变化时及时评价

**合规性证据**:
- 检测报告
- 许可证
- 检查记录
- 处罚记录

### 9.2 内部审核

**审核策划**:
- 年度审核计划
- 审核范围与频次
- 审核准则

**审核实施**:
1. 审核准备（检查表、通知）
2. 首次会议
3. 现场审核
4. 审核发现汇总
5. 末次会议

**审核输出**:
- 符合项/不符合项
- 审核结论
- 改进建议

### 9.3 管理评审

**评审输入**:
- 审核结果
- 合规性评价结果
- 相关方反馈
- 目标达成情况
- 事件/不符合分析
- 资源需求

**评审输出**:
- 改进决定
- 体系变更需求
- 资源决策
- 目标调整

## 第10章 改进

### 10.1 事件、不符合与纠正措施

#### 事件分类

| 类型 | 定义 | 处置要求 |
|------|------|----------|
| 事故 | 造成伤害或损失的意外事件 | 报告、调查、处置 |
| 未遂事件 | 可能导致伤害但未发生的事件 | 报告、调查、分析 |
| 隐患 | 可能导致事故的状态 | 识别、评估、控制 |

#### 调查流程

```
发生事件 → 紧急处置 → 报告 → 调查 → 原因分析 
       ↓                              ↓
    预防措施 ← 纠正措施 ← 制定措施 ← 报告评审
```

#### 纠正措施流程

1. 评审不符合/事件
2. 确定原因
3. 评估类似风险
4. 确定并实施措施
5. 评审措施有效性
6. 必要时更新体系

### 10.2 持续改进

**改进途径**:
- 方针目标评审更新
- 风险评估结果应用
- 管理评审输出落实
- 最佳实践引入
- 技术创新应用

**改进评价指标**:
- 事故率趋势
- 合规性达标率
- 员工满意度
- 体系审核结果
