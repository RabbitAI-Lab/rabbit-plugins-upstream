# 跨会议知识库模板（kb_template）

> meeting-kb-skill 构建的知识库索引骨架与使用指南。

## 输出格式

```markdown
# 跨会议知识库 · {日期}

> 由多场会议纪要多源聚合，按类型沉淀，便于跨会议检索与复用。每条注明来源会议与章节。

## 决策（n）
- 【来源会议 · 章节】决策内容
## 结论（n）
- 【来源会议 · 章节】结论内容
## 行动项（n）
- 【来源会议 · 章节】行动项内容  _(负责人 X · DDL Y)_
## 风险（n）
- 【来源会议 · 章节】风险内容
```

## 四类条目

| 类别 | 说明 | 典型关键词 | 结构化字段 |
|---|---|---|---|
| **决策** | 会议中拍板的事项，最具复用价值 | 决定/拍板/定下来/决议/定案 | — |
| **结论** | 会议达成的共识性结论 | 结论/要点/共识/总结/明确为 | — |
| **行动项** | 待办与负责人、截止日，便于追踪 | 行动项/待办/跟进/负责人/截止/@ | `负责人` + `DDL`（v2 起） |
| **风险** | 未关闭的风险与待决事项 | 风险/问题/阻塞/待决/延后/卡点 | — |

## 归类规则

1. **优先按章节标题归类**：`## 决策` → 决策；`## 行动项/待办` → 行动项；`## 风险/问题` → 风险；`## 结论` → 结论。
2. **无章节时关键词匹配**：按特异性优先级（决策 > 行动项 > 风险 > 结论），**一行只归一个类别**，避免重复。
3. **自动去重**：归一化（全/半角、标点、大小写）后相同条目只保留一次。

## 触发示例（给用户参考）

本 Skill 支持以下自然语言触发方式，用户无需记命令：

| 场景 | 推荐话术 |
|---|---|
| 建知识库 | 「帮我建一个会议知识库」「把这几场会议沉淀一下」 |
| 查决定 | 「上次关于XX是怎么定的？」「之前会议说支付方案怎么弄来着」 |
| 看待办 | 「这周哪些行动项要跟进？」「还有哪些没做完的」 |
| 查人员 | 「张伟在会议上领了什么任务？」 |
| 找风险 | 「目前项目有什么风险？」 |
| 写材料 | 「帮我把最近的会议结论汇总写周报」「根据纪要做复盘」 |

> 💡 完整触发话术表见 SKILL.md §「🎯 一句话触发」。

## v3 输入校验（可靠性保障）

脚本在读取文件时会执行以下检查，**不再静默跳过问题文件**：

| 检查项 | 处理方式 |
|---|---|
| 二进制文件检测（null 字节占比） | 打印 `[警告]` 并跳过 |
| 空文件 | verbose 模式显示 `[跳过]` |
| 编码异常（非 UTF-8） | 自动尝试 GBK 兼容读取，发出警告 |
| 内容过短（<10 字符） | 发出警告提示可能不是有效纪要 |
| 构建结束 | 输出扫描摘要（总扫描 / 有效 / 跳过 / 告警） |

> 使用 `--verbose` 参数可查看每个文件的详细诊断信息。常见问题排障见 README.md §「常见问题与排障」。

## 局限

- 本地模式为关键词检索，未做语义向量（如需可接嵌入模型）。
- 每条带【来源会议 · 章节】可追溯；结论冲突时并列展示，由人判断。
