## Use Case:

External users, independent professionals, and creators use this skill to select and run the most relevant OPC module for capability diagnosis, positioning, business validation, pricing, content planning, delivery workflows, and action review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated reports and copied templates may contain career, income, pricing, customer, and business-plan details.

Mitigation: Review the destination path and contents before sharing generated files, and avoid placing sensitive outputs in shared directories.

Risk: Report or template workflows may write local files and could overwrite existing work if paths are reused.

Mitigation: Ask the agent to show the destination path before execution and approve overwrites only when intended.
