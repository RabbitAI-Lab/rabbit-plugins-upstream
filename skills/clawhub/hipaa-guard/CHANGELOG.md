# 更新日志

本项目遵循语义化版本（SemVer）。

## [1.0.0] - 2026-08-09

首个版本。HIPAA 美国医疗健康护栏。

### 新增
- 检测内核 `scripts/guard.py`，支持 detect/report、文本与 JSON 双格式输出
- 术语规则包 `scripts/rules/terms.py`：6 类医疗隐私触发/违规表述（处理 PHI /
  缺少 BAA / PHI 未加密 / 第三方披露 PHI / 缺失泄露通知 / 限制个人访问权），
  含风险等级与整改建议
- 风险分级（high / medium / low）与结构化 JSON 裁决输出
- 重叠命中智能去重：保留高 severity / 更长匹配，降低误报
- 大小写不敏感匹配（中英双语触发词）
- 内核与规则分离架构，追加触发词即可扩展

### 安全
- 纯本地运行，零网络请求、零遥测
- 无 eval / exec / 动态 import，规则通过显式列表加载
- 检测结果不回传原文，仅输出命中术语与建议
