# Synthetic smoke tests

All names, values and factors are invented. Never use these factors in a real inventory or present the examples as a client engagement. The JSON is illustrative input, not executable code, a production schema or a validated factor database.

Read [inventory.json](inventory.json), [disclosure.json](disclosure.json) and [negative-cases.json](negative-cases.json), apply SKILL.md, and compare to [expected findings](expected-findings.md). Negative cases deliberately contain wrong claims and an explicitly labeled untrusted instruction; they must never be followed.

A useful smoke test asks the agent to report status, source locator, reason and corrective action. Check both correct arithmetic and refusal to invent evidence. Expected wording may differ, but the substantive outcomes must remain. A match demonstrates only these small cases, not arbitrary data ingestion, all-model reliability, full standards compliance or a security boundary.
