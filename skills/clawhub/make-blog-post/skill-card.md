## Description:

Turns code from the current session into a focused blog post that reflects the author's writing style and uses a generalized code example.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jhauga](https://clawhub.ai/user/jhauga)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and other authors use this skill to turn a single piece of working code into a blog post or gist in their own voice, with a draft review before any file is saved.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Writing samples or workspace code may contain private details that should not appear in a public post.

Mitigation: Review the draft for private details and approve it before saving; replace sensitive values with generic examples.
