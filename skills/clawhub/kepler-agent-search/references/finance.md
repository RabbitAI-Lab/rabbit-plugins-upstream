# 财经与股票搜索

## 概述

专注于财经资讯和股票行情的搜索能力，适用于投资研究和财经分析。

## 支持平台

### 东方财富 (Eastmoney)
- **引擎标识**: `"eastmoney"`
- **适用场景**: 股票资讯、基金信息、财经新闻、研报数据
- **特点**: A股数据全面，资讯更新及时

```yaml
query: "贵州茅台"
engines: ["eastmoney"]
max_results: 10
```

## 内容类型

- **个股资讯**: 特定股票的最新动态
- **行业分析**: 行业板块的整体情况
- **基金数据**: 基金净值、排名等信息
- **研报观点**: 机构研究报告摘要
- **财经新闻**: 宏观经济、政策动态

## 使用技巧

### 搜索优化
1. **股票代码**: 可直接搜索股票代码如 "600519"
2. **股票名称**: 搜索公司全称或简称如 "贵州茅台"
3. **行业关键词**: 如 "新能源"、"半导体"、"白酒"
4. **基金搜索**: 基金代码或名称如 "易方达蓝筹"

### 数据应用
1. **基本面分析**: 公司财报、业绩公告
2. **技术面分析**: 股价走势、成交量
3. **消息面分析**: 公司公告、行业新闻
4. **研报参考**: 机构观点、目标价

## 示例

```yaml
# 搜索个股
query: "宁德时代"
engines: ["eastmoney"]

# 搜索行业
query: "新能源 汽车"
engines: ["eastmoney"]

# 搜索基金
query: "张坤 基金"
engines: ["eastmoney"]

# 搜索研报
query: "贵州茅台 研报"
engines: ["eastmoney"]
```

## 深度使用

### 读取个股页面
```yaml
tool: mcp__kepler__web_reader
url: "https://quote.eastmoney.com/sh600519.html"
format: "markdown"
```

### 读取基金页面
```yaml
tool: mcp__kepler__web_reader
url: "https://fund.eastmoney.com/005827.html"
format: "markdown"
```

## 数据类型

### 行情数据
- 实时股价、涨跌幅
- 成交量、成交额
- 市值、市盈率

### 资讯数据
- 公司公告
- 行业新闻
- 研报摘要

### 财务数据
- 营收、利润
- 资产负债
- 现金流量

## 注意事项
- 股市有风险，数据仅供参考
- 实时行情可能有延迟
- 投资建议请咨询专业人士
- 注意数据的时效性和准确性
