# 社交媒体搜索

## 概述

中文社交媒体平台搜索，适用于生活方式、消费决策、知识问答等场景。

## 支持平台

### 知乎 (Zhihu)
- **引擎标识**: `"zhihu"`
- **适用场景**: 中文知识问答、经验分享、专业讨论
- **内容类型**: 专栏文章、问题回答、用户观点

```yaml
query: "Python 异步编程"
engines: ["zhihu"]
max_results: 10
```

### 小红书 (Xiaohongshu)
- **引擎标识**: `"xhs"`
- **适用场景**: 生活方式、消费决策、探店攻略、产品种草
- **内容类型**: 用户笔记、图文分享、真实体验

```yaml
query: "上海咖啡探店"
engines: ["xhs"]
max_results: 10
```

## 平台特点对比

| 平台 | 内容特点 | 最佳用途 | 内容质量 |
|------|----------|----------|----------|
| 知乎 | 深度讨论、专业回答 | 知识获取、决策参考 | ⭐⭐⭐⭐ |
| 小红书 | 真实体验、图文丰富 | 消费决策、生活灵感 | ⭐⭐⭐ |

## 使用技巧

### 知乎搜索优化
1. **专业问题**: 使用领域关键词，如 "分布式系统 CAP 定理"
2. **经验分享**: 加上 "经验"、"总结"，如 "面试经验 总结"
3. **热门内容**: 知乎热榜话题直接搜索

### 小红书搜索优化
1. **探店攻略**: 地点 + 类型，如 "上海 咖啡店"
2. **产品种草**: 产品名 + "测评" 或 "推荐"
3. **生活方式**: 场景 + 需求，如 "独居 收纳"

### 内容读取
- **知乎专栏**: `zhuanlan.zhihu.com/p/xxxxx`
- **知乎回答**: `zhihu.com/question/xxxxx`
- **小红书笔记**: `xiaohongshu.com/explore/xxxxx`

## 示例

```yaml
# 知乎技术讨论
query: "微服务架构 知乎"
engines: ["zhihu"]

# 小红书探店
query: "杭州 法餐 推荐"
engines: ["xhs"]

# 知乎经验分享
query: "互联网大厂 面试经验"
engines: ["zhihu"]

# 小红书产品测评
query: "iPhone 15 测评"
engines: ["xhs"]
```

## 注意事项
- 部分知乎内容需要登录才能查看完整内容
- 小红书笔记图片信息丰富，文字可能较简略
- 社交媒体内容偏向主观体验，需交叉验证
