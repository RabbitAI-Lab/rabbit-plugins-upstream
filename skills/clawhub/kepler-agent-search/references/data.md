# 行业数据与报告搜索

## 概述

专注于互联网数据和行业报告的搜索能力，适用于市场调研和商业分析。

## 支持平台

### 199it (互联网数据中心)
- **引擎标识**: `"199it"`
- **适用场景**: 行业报告、数据分析、市场研究
- **特点**: 中文互联网数据丰富，报告质量高

```yaml
query: "2024 电商行业报告"
engines: ["199it"]
max_results: 10
```

## 内容类型

- **行业报告**: 各行业年度/季度分析报告
- **数据分析**: 用户行为、市场数据
- **趋势研究**: 互联网发展趋势
- **竞品分析**: 主要企业数据对比

## 使用技巧

### 关键词优化
1. **年份筛选**: 加上年份如 "2024"、"2023"
2. **行业关键词**: 如 "电商"、"社交媒体"、"AI"
3. **报告类型**: 如 "白皮书"、"研究报告"、"行业分析"

### 报告筛选
1. **权威机构**: 优先选择知名研究机构报告
2. **发布时间**: 注意报告的时效性
3. **数据交叉**: 多个来源数据交叉验证

## 示例

```yaml
# 电商行业报告
query: "2024 电商行业 发展报告"
engines: ["199it"]

# 社交媒体数据
query: "社交媒体 用户数据 2024"
engines: ["199it"]

# AI行业分析
query: "人工智能 行业报告"
engines: ["199it"]

# 消费趋势
query: "Z世代 消费趋势 报告"
engines: ["199it"]
```

## 数据应用

### 市场调研
- 行业规模数据
- 竞争格局分析
- 用户画像研究

### 商业分析
- 趋势预测
- 机会识别
- 风险评估

## 注意事项
- 部分详细报告可能需要付费或登录
- 数据时效性很重要，优先使用最新报告
- 注意报告发布机构的权威性
- 数据引用时请注明来源
