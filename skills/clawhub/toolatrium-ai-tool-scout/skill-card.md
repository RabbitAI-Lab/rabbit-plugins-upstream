## Description:

Helps users shortlist and compare AI SaaS tools by workflow fit, current evidence, transparent scoring, and commercial-disclosure checks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[gpt-img-2](https://clawhub.ai/user/gpt-img-2)

### License/Terms of Use:

MIT-0

## Use Case:

Individuals and teams evaluating AI software use this skill to define requirements, compare candidates against dated evidence, identify blockers, and explain a recommendation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The optional MCP installation runs an unpinned GitHub package through npx, allowing remote code execution.

Mitigation: Review or pin the GitHub source before enabling the MCP, and enable only the helper tools needed.

Risk: Outdated product claims, pricing, privacy terms, or undisclosed commercial relationships could mislead software selection.

Mitigation: Verify current vendor sources and sponsorship or affiliate relationships before acting on recommendations.
