## Description:

Find and compare AI SaaS tools using the user's job, workflow requirements, current evidence, transparent scoring, and commercial-disclosure checks.

This skill is ready for commercial/non-commercial use.

## Use Case:

Individuals and teams selecting AI software use this skill to build evidence-backed shortlists, compare candidates against hard requirements, and identify claims that need verification.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The optional MCP helper executes third-party code when installed.

Mitigation: Review its source, prefer a pinned commit or trusted release, and enable only the tools needed.

Risk: Outdated vendor claims or commercial placement could distort tool recommendations.

Mitigation: Verify current claims with dated sources and disclose sponsored or affiliate relationships.
