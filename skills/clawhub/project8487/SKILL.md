# 周报助手 (Weekly Report Assistant)

## 概述

此技能旨在帮助开发者通过分析其在 Git 仓库中的个人提交记录，快速生成周报。它会自动提取过去 7 天内的提交信息，并将其归纳为 3 个核心工作重点。

## 使用指南

当用户要求“总结上周工作”、“写周报”或“查看我最近做了什么”时，请执行以下步骤：

1. **获取提交记录**：运行 `scripts/get_git_logs.py`。该脚本会根据当前配置的 `git config user.name` 获取过去一周的非合并（non-merge）提交。
2. **分析记录**：仔细阅读获取到的提交哈希、日期和提交说明（Subject）。
3. **归类与总结**：
    - 将零散的提交按功能模块或任务目标进行分类。
    - 识别出本周最重要的 3 项成果或进展。
    - 忽略琐碎的提交（如 "fix typo"、"fmt" 等），除非它们是主要工作的组成部分。
4. **输出周报**：按照以下格式输出 3 点总结：
    - **[工作重点 1]**: 描述具体内容及价值（例如：完成了 X 模块的重构，解决了 Y 性能瓶颈）。
    - **[工作重点 2]**: 描述具体内容及进展。
    - **[工作重点 3]**: 描述具体内容及后续计划。

## 示例请求

- “帮我写一下这周的周报。”
- “我这周都忙了些什么？总结 3 点。”

## 资源

### scripts/
- `get_git_logs.py`: Python 脚本，用于执行 `git log` 并返回过去 7 天的提交记录。
