# S5: VOC评论采集

## 输入
competitors: S1竞品ASIN列表, target_asin, enable_voc

## 依赖
S1

## 操作
1. 若enable_voc=false则跳过
2. 选择目标ASIN + TOP 3竞品（按S1评分降序）
3. 对每个ASIN调用linkfox-voc-review-analysis
4. 提取: 好评高频卖点, 差评痛点分类, 未满足需求

## 输出
voc_data: {asin: {positive_points: [], negative_points: [], unmet_needs: []}}

## 用途
被S8(SWOT研判的劣势和机会维度)和S9(报告VOC章节)消费
