# S6: 首页词归因分析

## 输入
traffic_keywords: S3输出的全部ASIN流量词数据

## 依赖
S3

## 操作
调用scripts/keyword_overlap_analyzer.py：
1. 对每个关键词，找出所有在该词上首页(page=1)的ASIN
2. 分类: 唯一首页词(仅1个ASIN在首页) vs 重复首页词(2+个ASIN在首页)
3. 统计每个ASIN的: 首页词总数, 唯一首页词数, 重复首页词数, 唯一词搜索量占比
4. 对重复首页词，列出共争者ASIN和各自排名
5. 输出竞争战场列表（按搜索量降序）

## 输出
keyword_analysis: {
  per_asin: {asin: {total_p1, unique_p1, shared_p1, unique_vol, unique_pct}},
  battlefields: [{keyword, searches, asins_on_p1: [{asin, position}]}]
}

## 用途
被S8(SWOT的流量护城河分析)和S9(报告流量章节)消费
