# S7: ABA TOP3交叉对比

## 输入
aba_data: S4输出的ABA数据, traffic_keywords: S3数据

## 依赖
S4

## 操作
调用scripts/aba_overlap_analyzer.py：
1. 找出多个ASIN同时进入ABA TOP3的关键词（交叉战场）
2. 对每个交叉词，列出各ASIN的ABA排名和点击占比
3. 统计每个ASIN的ABA统治力: #1词数, 总上榜词数, 独占词数(仅自己上榜)
4. 对比目标ASIN vs 各竞品的ABA覆盖面

## 输出
aba_analysis: {
  per_asin: {asin: {aba_total, rank1, rank2, rank3, unique_aba_kws}},
  cross_battlefields: [{keyword, asins: [{asin, aba_rank, click_share, conv_share}]}]
}

## 用途
被S8(SWOT的ABA统治力分析)和S9(报告ABA章节)消费
