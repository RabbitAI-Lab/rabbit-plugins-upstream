# S9: HTML报告生成（11章标准模板）

> 使用 `scripts/generate_report_fragment.py` 自动生成HTML片段，Agent只需准备JSON数据，无需手写HTML。

## 输入
全部前序步骤的输出(S1-S8 + S6b + S6c)

## 依赖
S2-S8

## 操作

### Step 1: 准备报告JSON数据

Agent将各步骤输出整理为结构化JSON：

```json
{
  "header": {"title":"...", "subtitle":"...", "meta":"..."},
  "kpi": [{"label":"...", "value":"...", "change":"...", "direction":"up/down/flat"}],
  "sections": [
    {"type":"table", "title":"第2章 竞品筛选结果", "headers":[...], "rows":[[...]], "source":[...]},
    {"type":"chart", "title":"第3章 市场全景", "charts":[{"id":"...", "height":300, "option":{...}}], "source":[...]},
    {"type":"swot", "title":"第10章 SWOT分析", "strengths":[...], "weaknesses":[...], "opportunities":[...], "threats":[...], "source":[...]},
    {"type":"insights", "title":"第11章 核心发现", "summary":"...", "items":[{"priority":"high", "text":"..."}], "source":[...]}
  ],
  "footer":"..."
}
```

支持的section类型：
- `table`: 数据表格（headers + rows）
- `chart`: ECharts图表（charts数组，每个含id/height/option）
- `swot`: SWOT四象限（strengths/weaknesses/opportunities/threats）
- `insights`: 摘要+优先级行动建议（summary + items）
- `comparison`: 对比卡片（cards数组，每个含title/body）
- `skip`: 跳过标注（reason）

### Step 2: 生成HTML片段

```bash
python scripts/generate_report_fragment.py --stdin < report_data.json > fragment.html
```

脚本自动处理：
- HTML转义
- 组件class名（无需记忆layouts）
- ECharts初始化代码（自动放入ECHARTS_SCRIPTS块）
- 数据源标注（data-source）
- 表格num列右对齐

### Step 3: 注入模板

```bash
python ../../../.claude/skills/linkfox-report-generator/scripts/inject_report.py \
  --content-file fragment.html --language zh --title <slug>
```
