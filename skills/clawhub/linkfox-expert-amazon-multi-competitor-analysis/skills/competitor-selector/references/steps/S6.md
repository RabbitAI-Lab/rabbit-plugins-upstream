# S6: 锁定输出

## 输入
- direct_competitors: S5直接竞品评分结果
- rising_stars: S5潜力股评分结果
- benchmarks: S5标杆评分结果
- max_competitors: 最终竞品数量上限（默认10）

## 依赖
S5

## 操作
1. 直接竞品按总分降序，取TOP 3-5
2. 上升潜力股按总分降序，取TOP 1-2
3. 标杆头部按总分降序，取TOP 1-2
4. 总数控制在max_competitors以内
5. 若某类无合格者（无ASIN达到3.5分），该类留空并注明原因
6. 生成最终JSON结构

## 输出
最终交付JSON:
{
  "target_asin": "B0XXXXX",
  "product_type": "standard",
  "search_date": "2026-08-07",
  "direct_competitors": [
    {"asin":"...", "brand":"...", "price":0, "bsr":0, "reviews":0, "score":0, "scores":{...}}
  ],
  "rising_stars": [...],
  "benchmarks": [...],
  "summary": {"total": 7, "direct": 4, "rising": 1, "benchmark": 2}
}

## 用途
最终交付物。如需报告，handoff给linkfox-report-generator。
