# S0: 商品类型判定

## 输入
- asin: 目标ASIN
- marketplace: 站点
- product_type: 用户指定或auto

## 依赖
无

## 操作
1. 若product_type≠auto，直接使用用户指定类型，跳到S1
2. 调用linkfox-amazon-product-detail拉取目标ASIN详情
3. 从返回中提取itemSpecifications字段
4. 自动判定逻辑：
   - 规格字段≥5个且包含可量化参数(容量/尺寸/电压/功率等) → 标品
   - 规格字段≤2个且无明确量化参数 → 非标品
   - 规格字段3-4个 → 混合
5. 提取目标主图URL（用于S2非标品/混合路径）
6. 提取五点描述+规格表（用于S4标品路径功能对比）

## 输出
- product_type: standard / non-standard / mixed
- target_image_url: 主图URL
- target_features: 五点+规格结构化文本
- target_price: 当前售价
- target_bsr, target_reviews: 基线指标

## 用途
被S2（决定候选池生成路径）和S4（决定重合度过滤路径）消费
