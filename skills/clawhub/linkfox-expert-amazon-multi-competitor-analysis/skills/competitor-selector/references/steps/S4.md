# S4: 重合度过滤（AIGC对比 — 禁止跳过）

> **硬性规则**：AIGC对比是判断"是否为直接竞品"的核心依据，**禁止跳过、禁止使用默认值**。未经AIGC对比的ASIN不得进入S5评分环节。

## 输入
- product_type: S0判定结果
- filtered_candidates: S3输出的候选
- target_features: S0输出的目标特征（五点+规格）
- target_image_url: S0输出的目标主图URL
- overlap_threshold: 重合度阈值（默认0.8）

## 依赖
S3

## 操作

### 标品路径（功能重合度 ≥80%）

**Step 1: 批量拉取候选详情**
- 调用linkfox-amazon-product-detail（每批最多40个ASIN）
- 提取每个候选的五点描述(aboutItemFivePoint) + 规格表(itemSpecifications)

**Step 2: 构建目标特征清单**
- 从目标的五点描述中提取功能特征（如：蓝牙5.3、64GB内置、2.4寸屏、内置扬声器、FM收音、HiFi解码、Line-in录音、计步器）
- 从规格表提取参数特征（如：memory_storage_capacity=64GB, screen_size=2.4inches, connectivity_technology=Bluetooth）
- 合并为目标特征清单（通常8-15项）

**Step 3: AIGC逐个对比（GEM_3_FLASH）**
- 调用linkfox-aigc-textgen，prompt:
```
你是产品功能对比专家。请对比以下两个商品的功能特征清单，计算功能重合度。

目标商品特征: {target_features_json}
候选商品特征: {candidate_features_json}

请输出JSON:
{
  "target_features": ["特征1", "特征2", ...],
  "candidate_features": ["特征1", "特征2", ...],
  "shared_features": ["共有特征1", ...],
  "missing_in_candidate": ["候选缺失的特征", ...],
  "extra_in_candidate": ["候选独有的特征", ...],
  "overlap_count": N,
  "total_count": M,
  "overlap_ratio": 0.0-1.0,
  "assessment": "highly_similar/similar/partially_different/different"
}
overlap_ratio = shared_features数 / target_features总数
```

**Step 4: 边界精筛（GEM_3_1_PRO，仅对0.60-0.80的case）**
- 对FLASH判定为边界case的，用PRO做深度功能对比
- 输出精确的overlap_ratio和assessment

**Step 5: 硬过滤**
- overlap_ratio ≥ 0.80 → 进入核心候选池
- 0.60 ≤ overlap_ratio < 0.80 → 进入宽泛候选池（不进入直接竞品评分）
- overlap_ratio < 0.60 → 排除

### 非标品路径（外观重合度 ≥80%）

**Step 1: 获取候选主图**
- 从S3的Keepa数据或Amazon Product Detail中提取每个候选的主图URL

**Step 2: AIGC图片对比（GEM_3_FLASH，批量）**
- 每次最多1目标+9候选图
- prompt:
```
你是产品外观对比专家。图1是目标商品主图，图2-{N}是候选商品主图。
请逐一对比图1与每张候选图，从5维评估：
1. 形状轮廓相似度(0-100)
2. 设计语言相似度(0-100)  
3. 颜色配色相似度(0-100)
4. 材质质感相似度(0-100)
5. 结构细节相似度(0-100)
输出JSON数组，每个候选一个对象:
{
  "candidate_index": N,
  "shape": 0-100,
  "design": 0-100,
  "color": 0-100,
  "material": 0-100,
  "detail": 0-100,
  "overall_overlap_ratio": (shape+design+detail)/300,
  "key_differences": ["差异点1", ...]
}
```

**Step 3: 边界精筛（GEM_3_1_PRO）**
- 对overall_overlap_ratio在0.60-0.80之间的用PRO精筛

**Step 4: 硬过滤**
- 同标品路径Step 5

### 混合路径（交叉比对）

**Step 1: 候选分类**
- A∩B（关键词+图片双路命中）→ 高置信，仍需AIGC确认至少一条路径≥0.80
- 仅A（仅关键词命中）→ 必须补AIGC外观对比
- 仅B（仅图片命中）→ 必须补AIGC功能对比

**Step 2: AIGC对比（两条路径都不能跳过）**
- 仅A的候选：补外观对比（同非标品路径）
- 仅B的候选：补功能对比（同标品路径）
- A∩B的候选：取两条路径中较低的那个overlap_ratio作为最终值

**Step 3: 硬过滤**
- 同标品路径Step 5

## 输出
- core_candidates: [{asin, overlap_ratio, overlap_assessment, shared_features, missing_features}] — overlap_ratio ≥ 0.80
- broad_candidates: [{asin, overlap_ratio, ...}] — 0.60 ≤ overlap_ratio < 0.80
- excluded: [{asin, overlap_ratio, reason}] — overlap_ratio < 0.60

## 用途
**被S5消费（三模型评分）**：
- overlap_ratio ≥ 0.80 是进入直接竞品评分的**硬性前置条件**
- overlap_ratio直接影响S5中"功能差异化"维度的评分
- overlap_ratio < 0.80的ASIN不得参与直接竞品评分，仅可参与标杆头部评分
