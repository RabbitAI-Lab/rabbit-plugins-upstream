# S5: 三模型评分

## 输入
- core_candidates: S4输出的核心候选（含overlap_ratio）
- aba_data: S4b输出的ABA反查数据
- target keepa data: 目标ASIN的BSR/评论/价格/月销/转化率/上架时间
- target aba data: 目标ASIN的ABA上榜词数
- marketplace: 站点

## 依赖
S4, S4b

## 操作
调用 scripts/competitor_selector.py 对每个候选执行三类评分：

**1. 直接竞品6维可达性评分**：
- BSR差距(20%) + 评论数差距(15%) + 转化率差距(15%) + 价格竞争力(10%) + 功能重合度(25%) + 上架时间(10%)
- 硬性前置: S4 overlap_ratio ≥ 0.80（不满足直接排除）
- 总分≥3.5入选
- 完整规则见 references/scoring-model.md

**2. 上升潜力股5维增长性评分**：
- 销量增长趋势(35%) + 评论成长空间(20%) + BSR改善(20%) + 转化率(15%) + 上架时间(10%)
- 硬性排除: 当月销量=0/Deal尖峰/上架<3月/BSR>50000
- 总分≥3.5入选
- 需Keepa history=1数据（6月月销历史）

**3. 标杆头部5维领先度评分**：
- BSR领先度(25%): ≤目标×0.2=5分, ≤×0.3=4分, ≤×0.5=3分, ≤×0.8=2分, >×0.8=1分
- 评论壁垒(20%): ≥目标5x=5分, ≥3x=4分, ≥2x=3分, ≥1.5x=2分, <1.5x=1分
- 销量规模(20%): 月销≥目标3x=5分, ≥2x=4分, ≥1.5x=3分, ≥1x=2分, <1x=1分
- ABA统治力(20%): 核心词ABA#1=5分, 上榜≥20词=4分, 5-19词=3分, 1-4词=2分, 未上榜=1分
- 价格相关性(15%): 同价位±30%=5分, 0.5-2x=4分, 0.3-3x=3分, 0.2-5x=2分, 其他=1分
- 硬性门槛: 至少1维显著领先（评论≥1.5x 或 ABA≥5词 或 销量≥1.5x 或 BSR<目标）
- 总分≥3.5入选，无达标者取最高分1个为准标杆
- ABA数据来自S4b

## 输出
- direct_competitors: [{asin, score, scores_breakdown, overlap_ratio}]
- rising_stars: [{asin, score, scores_breakdown, sales_trend}]
- benchmarks: [{asin, score, scores_breakdown, lead_dimensions}]

## 用途
被S6消费（最终选择）
