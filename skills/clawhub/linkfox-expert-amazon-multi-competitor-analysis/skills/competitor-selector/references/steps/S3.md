# S3: 价格过滤 + Keepa数据拉取

## 输入
- candidate_pool: S2输出的候选池
- target_price: S0输出的目标价格
- price_tolerance: 价格浮动比例（默认0.2）
- marketplace: 站点

## 依赖
S2

## 操作
1. 计算价格区间: [target_price × (1-tolerance), target_price × (1+tolerance)]
2. 过滤候选池，保留价格在区间内的ASIN
3. 对过滤后的候选ASIN批量拉取Keepa数据（history=1）
   - linkfox-keepa-product-request, 每批最多5个ASIN
   - 提取: salesRank, reviewCount, monthlySalesUnits(1-12月前), salesRank30/90/180, price, availableDate
4. 排除目标ASIN的变体（同品牌+相同BSR+相同评论数）

## 输出
- filtered_candidates: [{asin, keepa_data:{bsr, reviews, monthly_sales_history, rank_30, rank_180, price, launch_date}}]

## 用途
被S4消费（重合度过滤）和S5消费（评分）
