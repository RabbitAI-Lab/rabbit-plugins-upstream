# ⚡ 触发方式详解

## 自动触发（推荐）

在对话中只要提及以下任一意图词，本技能会自动激活：

- 设计意图词：「设计 agent」「创建智能体」「优化智能体」「做一个」「帮我写个」
- 范式词：「人物蒸馏」「岗位型专家」「设计一个专家」
- 英文词：「design agent」「create agent」

完整触发词列表见 SKILL.md YAML 前页 `trigger_words` 字段，无需用户记忆。

## 快捷命令

> 快捷命令等价于直接描述需求，效果完全相同——只是减少了自然语言歧义。命令映射见 [SKILL.md §触发场景](SKILL.md)。如果习惯直接说「帮我设计一个税务顾问」，完全不需要记忆这些命令。

## 触发配置

触发行为可通过 YAML 前页的 `trigger_words` 字段自定义。在 SKILL.md 的 YAML 区修改 `trigger_words` 列表即可增加或移除触发词，修改后下次对话生效。
