## Description:

Helps users register a PowPow account, verify their email, activate membership through Alipay, and sign in using one-click links in a guided conversation.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users can complete PowPow account registration and membership activation with conversational help for email verification, payment, and sign-in. The user supplies account details and completes payment themselves.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Account login state can mix between overlapping users on a shared agent host.

Mitigation: Run each user's workflow in an isolated host or session; avoid concurrent registrations in a shared workspace.

Risk: The agent handles passwords, email codes, and one-click login links.

Mitigation: Keep credentials and sign-in links private, confirm the intended account before use, and clear temporary account state after registration.

Risk: The agent opens a payment page generated by the PowPow service.

Mitigation: Verify the payment destination and amount; have the user complete payment themselves through the official Alipay checkout.
