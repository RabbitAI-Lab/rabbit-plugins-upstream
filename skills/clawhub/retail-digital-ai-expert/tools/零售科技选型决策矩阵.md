## 四、各维度评分细则

### 4.1 业态匹配度（权重25%）

| 评分 | 标准 |
|:---:|------|
| 1 | 不能支持你的业态核心需求 |
| 2 | 勉强支持，需大量定制 |
| 3 | 能支持基础需求，但行业最佳实践不足 |
| 4 | 良好支持你的业态，有多家同行案例 |
| 5 | 行业最佳，是你的业态的标杆选择 |

如何评估：
- Demo演示覆盖你的核心场景了吗？
- 有没有至少3家同等规模/业态的客户参考？
- 产品路线图是否符合你的业务方向？

### 4.2 TCO总拥有成本（权重20%）

| 评分 | 标准 |
|:---:|------|
| 1 | 远超预算(>150%) |
| 2 | 超出预算(100-150%) |
| 3 | 在预算范围内(80-100%) |
| 4 | 低于预算(60-80%) |
| 5 | 远低于预算(<60%) |

TCO计算包含：
- 软件订阅/许可费(含所有模块)
- 实施费(部署+定制+集成)
- 硬件费(POS/服务器/网络)
- 培训费
- 年运维/支持费
- 隐性成本(数据迁移/系统切换/学习曲线)

### 4.3 API与扩展性（权重15%）

| 评分 | 标准 |
|:---:|------|
| 1 | 基本无API或API极不完善 |
| 2 | 有基础API但不完整，文档质量差 |
| 3 | API覆盖主要功能，有基础文档 |
| 4 | 完善的RESTful API+Webhook+开发者文档+SDK |
| 5 | API-first架构+开放平台+ISV生态+Marketplace |

### 4.4 全渠道能力（权重12%）

| 评分 | 标准 |
|:---:|------|
| 1 | 线下/线上完全独立 |
| 2 | 部署了但各渠道割裂 |
| 3 | 线上线下有基础打通(商品/订单) |
| 4 | 线上线下库存/订单/会员统一 |
| 5 | 统一商务平台(URCP)+AI智能全渠道 |

### 4.5 实施与培训（权重10%）

| 评分 | 标准 |
|:---:|------|
| 1 | 无实施方法论，放任自理 |
| 2 | 有基础实施计划但培训少 |
| 3 | 标准实施流程+培训材料 |
| 4 | 成熟实施方法论+系统培训+上线支持 |
| 5 | 行业最佳实施+系统培训+变革管理+持续赋能 |

### 4.6 稳定性与支持（权重10%）

| 评分 | 标准 |
|:---:|------|
| 1 | 故障频繁，客服找不到人 |
| 2 | 偶有故障，响应慢(>24小时) |
| 3 | 基本稳定，工作时间可响应(<8小时) |
| 4 | 高可用SLA(99.9%+)+7×24支持+快速响应(<2小时) |
| 5 | 99.99%+SLA+灾备+主动监控+专属服务经理 |

### 4.7 数据主权与合规（权重8%）

| 评分 | 标准 |
|:---:|------|
| 1 | 数据无法导出/迁移 |
| 2 | 只能导出基础数据(CSV) |
| 3 | 可通过API批量导出，有基础合规 |
| 4 | 完整数据可迁移+隐私合规+安全认证(ISO27001/等保) |
| 5 | 数据完全可控+本地化部署选项+审计日志+最高安全标准 |

## 九、合同谈判关键条款

| 条款 | 建议底线 | 谈判策略 |
|------|------|------|
| 价格 | — | 签3年付2年或要求首年折扣 |
| SLA | 99.5%+ | 写入合同，附赔偿条款 |
| 退出条款 | 数据完整导出 | 明确导出格式+时效+费用(应为0) |
| 实施周期 | 写入合同 | 延期处罚(如日罚款千分之一) |
| 数据所有权 | 客户100%拥有 | 明确约定+定期备份 |
| 续约涨价 | 涨幅上限 | 约定年涨幅不超过X% |
| PoC | 合同前完成 | 核心场景没跑通不进合同 |
