# Phase 01 — 商机开发与签约

> **阶段目标**：从第一次接触客户到签订合同的全流程方法。
> **周期**：2-6周（取决于客户规模和复杂度）
> **核心产出**：项目建议书(Proposal) + 工作说明书(SOW)

## 阶段概览

```
初次客户沟通 → 需求澄清与问题诊断 → 项目建议书Proposal → 合同与SOW谈判
     (1-2次)         (1-2周)              (1周)              (1-2周)
```

## 核心原则

1. **听 > 说**：第一次沟通，70%时间听客户说，30%时间提问和总结
2. **问对问题**：不问你"预算多少"（没人会说），问"你觉得这套系统值多少钱"
3. **讲人话**：对中小零售老板，用"收银系统"而不是"POS解决方案"
4. **前期价值**：第一次沟通就要让客户觉得"这人真懂零售"，不只是懂技术

## 质量检查清单

- [ ] 客户能清晰说出他要解决什么问题吗？（不是"我要数字化"，是"我要库存准到95%以上"）
- [ ] 客户的真实预算范围我清楚吗？（至少知道上限和下限）
- [ ] 决策者是谁？决策流程是什么？
- [ ] Proposal用了客户自己的话描述问题吗？（不是你的术语）
- [ ] 每个建议有ROI估算吗？

## 常见陷阱

1. **急于给方案**：还没搞清楚问题就推系统 → 客户觉得你在"推销"
2. **过度承诺**：为了拿项目承诺做不到的事 → 项目必败
3. **忽视隐性决策者**：只跟IT经理谈，没接触老板/CEO → 项目被砍
4. **方案太技术化**：对零售老板讲"API/Microservices/MACH" → 老板听不懂
