# 03 — 项目建议书Proposal

> **触发条件**：需求澄清完成，客户要求正式建议书
> **前置输入**：问题诊断报告 + 客户沟通纪要
> **产出**：正式Proposal（15-25页）+ 演示PPT（10-15页）

---

## 一、Proposal核心原则

1. **一页纸能讲清楚**：执行摘要必须在1页内讲完所有关键信息
2. **用客户的语言**：客户说"收银系统"你就用"收银系统"，不要说"POS终端"
3. **每个建议绑定ROI**：不要只说"建议上ERP"，要说"上ERP后库存周转从45天降到32天=释放¥XX万现金流"
4. **结论先行**：金字塔原则——先给结论，再给论据，最后给细节

---

## 二、Proposal标准结构（9章）

### 第1章：执行摘要（1页）

> 最重要的一页——CEO只看这一页

```
我们理解您的挑战：
  1. _____（用客户自己的话）
  2. _____

我们的建议：
  一句话概括 → 通过____，在____个月内，实现____

核心数据：
  - 投入：¥____万（3年）
  - 回报：¥____万（3年），ROI ____%
  - 时间：____个月回收，____个月完成

为什么是我们：
  一句话——"我们专注零售数字化，已经帮XX家零售商..."
```

### 第2章：我们理解您的挑战（2-3页）

- 客户现状描述（展示你做了功课）
- 核心痛点提炼（TOP3-5个）
- 每个痛点量化："不解决的代价"
- 行业对标："行业领先者已经在做____"

### 第3章：我们的解决方案（4-6页）

- 目标架构图（一图胜千言）
- 核心系统推荐（每个系统：选谁 + 为什么 + 多少钱）
- 分阶段实施路径（Phase 1→2→3）
- 快赢项目（0-3个月见效的）

### 第4章：实施路线图（2-3页）

- 时间线（甘特图/里程碑表）
- 关键里程碑和交付物
- 资源需求（团队/硬件/预算）

### 第5章：投资与回报（2-3页）

- TCO明细（一次性 + 年费 × 3年）
- 收益量化（5类收益 × 3年）
- ROI + 回收期 + 敏感度分析
- 不做投资的代价

### 第6章：风险与缓解（1-2页）

- TOP5风险 + 概率 + 影响 + 缓解措施

### 第7章：为什么选择我们（1-2页）

- 零售专注（不是什么都做）
- 案例（至少3个类似规模/业态）
- 团队（核心成员背景）
- 方法论文（R-DMM等独有工具）

### 第8章：项目团队（1页）

| 角色 | 姓名 | 背景 | 投入 |
|------|------|------|:---:|
| 项目负责人 | | | |
| 零售业务专家 | | | |
| 技术架构师 | | | |

### 第9章：下一步建议（1页）

1. Proposal评审与讨论（日期）
2. 详细诊断启动（日期）
3. 合同与SOW签署（日期）

## 三、Proposal写作技巧

### SCQA叙事法

| 要素 | 零售场景 |
|------|------|
| **S**ituation | "中国零售SaaS渗透率63.8%，数字化已是标配" |
| **C**omplication | "但您目前的系统各店独立、库存不准、会员不可识别" |
| **Q**uestion | "如何在6个月内改变现状，追上行业领先水平？" |
| **A**nswer | "我们建议分三阶段：统一POS→全渠道→AI赋能" |

### 给不同受众的定制

| 受众 | 关注点 | Proposal侧重 |
|------|------|------|
| CEO/老板 | ROI、竞争、战略 | 第1/5/6章加重 |
| CTO/IT负责人 | 技术架构、可行性、集成 | 第3/4章加重 |
| CFO | TCO、回收期、风险 | 第5/6章加重 |
| 加盟商 | 我能得到什么好处 | 加盟商专属Chapter |

## 四、Proposal演示指南

### 10-15页PPT结构

```
Slide 1:  标题页
Slide 2:  执行摘要（1页核心信息）
Slide 3-4: 我们理解您的挑战
Slide 5-7: 解决方案
Slide 8:   路线图
Slide 9:   投资回报
Slide 10:  风险
Slide 11:  为什么是我们
Slide 12:  下一步
```

### 演示禁语

| ❌ 不要说 | ✅ 应该说 |
|------|------|
| "我们的方案基于MACH架构..." | "这个系统可以像搭积木一样灵活扩展" |
| "ROI测算基于DCF模型..." | "您投入¥XX万，XX个月回本，3年多赚¥XX万" |
| "我们采用敏捷开发方法论..." | "我们每2周让您看到进展" |

## 五、质量自检清单

- [ ] 执行摘要能在2分钟内讲完吗？
- [ ] 每个建议有"why"（为什么）+ "what"（做什么）+ "how"（怎么做）+ "how much"（多少钱）？
- [ ] ROI计算有数据支撑吗（不是拍脑袋）？
- [ ] 竞争对手可能怎么攻击我们的方案？我们准备好回应了吗？
- [ ] Proposal用客户的品牌色/LOGO了吗？（细节体现用心）
- [ ] 排版整齐、无错别字、图表清晰吗？
