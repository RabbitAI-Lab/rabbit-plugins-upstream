# 02 — 需求澄清与问题诊断

> **触发条件**：初次沟通后客户有初步意向
> **前置输入**：客户沟通纪要 + 公开信息
> **产出**：问题诊断报告（3-5页）+ 初步建议方向

---

## 一、MECE五维诊断框架

将客户问题按以下五个维度MECE分解——不重不漏：

### 维度1：客流（流量问题）

| 检查点 | 诊断问题 | 数字化归因 |
|------|------|------|
| 选址流量 | 门前日均人流？进店率？ | AI选址、客流统计 |
| 线上流量 | 小程序UV？电商访客？ | SEO/SEM、内容种草、平台流量 |
| 会员触达 | 能触达多少会员？触达率？ | 会员基数、MA触达率 |
| 外卖/O2O流量 | 美团/饿了么/京东到家曝光？ | O2O入驻、评分、配送覆盖 |
| 竞对分流 | 周边新开了什么店？ | 竞品监测、差异化 |

### 维度2：转化率（成交问题）

| 检查点 | 诊断问题 | 数字化归因 |
|------|------|------|
| 商品力 | 品类结构合理吗？SKU宽度/深度？ | 品类分析、ABC分析、价格带 |
| 陈列 | 陈列是否吸引人？动线是否合理？ | Planogram、热力图、AI陈列 |
| 定价 | 价格有竞争力吗？促销有效吗？ | 竞品比价、动态定价、促销ROI |
| 导购 | 导购知道顾客要什么吗？ | AI导购、客户画像、产品知识库 |
| 体验 | 收银快吗？排队吗？环境好吗？ | POS速度、自助收银、环境IoT |

### 维度3：客单价（价值问题）

| 检查点 | 诊断问题 | 数字化归因 |
|------|------|------|
| 连带率(UPT) | 每单平均几件？ | 智能推荐、关联陈列 |
| 品类升级 | 顾客在买高端还是低端？ | 价格带分析、品类迁移 |
| 会员价值 | 会员客单vs非会员？ | CDP标签、会员分层、权益设计 |

### 维度4：毛利率（利润问题）

| 检查点 | 诊断问题 | 数字化归因 |
|------|------|------|
| 采购成本 | 采购价比竞对高吗？ | SRM、集采平台、供应商比价 |
| 损耗 | 报损率多少？原因？ | 效期管理、AI防损、报损分析 |
| 促销过度 | 促销占比多少？是否过度？ | 促销ROI分析、过度促销预警 |
| 定价偏低 | 定价策略是否过于保守？ | 定价模型、毛利分析 |

### 维度5：成本结构（效率问题）

| 检查点 | 诊断问题 | 数字化归因 |
|------|------|------|
| 人力成本 | 人效(万/人/年)?排班合理？ | 排班AI、自助收银、人效BI |
| 库存成本 | 库存周转？滞销占比？ | 智能补货、需求预测、库存优化 |
| 租金 | 坪效多少？ | 坪效BI、门店优化 |
| 能耗 | 电费/水费合理吗？ | IoT能耗管理 |
| IT成本 | IT投入占营收？系统冗余？ | TCO分析、系统整合 |

## 二、诊断三步法

### Step 1: 数据收集（1-3天）

| 数据类型 | 具体数据 | 来源 |
|------|------|------|
| 财务数据 | 营收/毛利/净利/成本结构（12个月） | 财务系统/Excel |
| 运营数据 | 客流量/客单价/转化率/UPT/周转（12个月） | POS/ERP |
| 商品数据 | SKU数/品类/ABC分类/售罄率/缺货率 | 进销存 |
| 会员数据 | 会员数/复购率/流失率/储值 | CRM |
| 系统数据 | 系统清单/使用率/满意度 | IT |

### Step 2: 问题定位（1-2天）

用5-Why深入根因：

```
"库存不准" →
  Why? → "盘点不及时" →
  Why? → "店员嫌麻烦" →
  Why? → "盘点一次要2小时" →
  Why? → "没有PDA/扫描枪，全靠手写" →
  Why? → "老板觉得没必要买"

根因：不是"库存不准"，是"老板没意识到问题的代价"
```

### Step 3: 量化影响（1天）

每个问题都要算"不解决的代价"：

| 问题 | 量化计算 | 年损失 |
|------|------|:---:|
| 库存不准 | 准确率80%→超卖/缺货/盘亏：¥XX万库存×15%偏差 | ¥XX万 |
| 没有会员 | 无法触达老客→复购率低：月营收×复购率差×毛利 | ¥XX万 |
| 手工对账 | 店长每天30min×365天×¥XX/h | ¥XX万 |

## 三、诊断报告结构（3-5页）

```
第1页: 核心发现（1句话结论 + TOP3问题 + 不解决的代价总计）
第2页: MECE五维分析（五维雷达图 + 关键差距）
第3页: 根因分析（3-5个核心问题的5-Why根因）
第4页: 初步建议方向（3个方向 + 投入/收益估算）
第5页: 下一步建议（详细诊断/选型/试点）
```

---

## 四、常见陷阱

1. **问题太长**：列了20个问题→客户不知道先解决哪个→聚焦TOP3
2. **没有量化**："效率低"→客户不理解→"每天浪费30分钟=年损失¥XX"
3. **归因太浅**："POS太旧"→为什么不换？→根因是"老板不知道新POS多好用"
4. **方案太早**：还在诊断就给出具体系统推荐→先确认问题再开药方
