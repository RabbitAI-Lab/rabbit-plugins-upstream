## 一、TCO建模框架

### 1.1 成本7大类

| # | 成本类别 | 包含内容 | 估算方法 |
|---|------|------|------|
| 1 | **软件/SaaS** | 许可费/订阅费/年费/附加模块 | 厂商报价 |
| 2 | **硬件** | POS机/服务器/网络/平板/PDA/ESL/IoT | 厂商报价+市场价 |
| 3 | **实施与部署** | 安装/配置/部署/测试 | 厂商报价×1.2（留有buffer） |
| 4 | **集成与定制** | API对接/定制开发/数据迁移 | 实施方报价+自估额外20% |
| 5 | **培训与变革** | 培训费/培训期间效率损失/变革沟通 | 培训报价+效率损失=1-2周营收降20-40% |
| 6 | **持续运维** | 年维护费/升级/技术支持/云资源 | 年费通常=软件费的15-22% |
| 7 | **隐性成本** | 系统切换中断/学习曲线/数据清洗/未来退出 | 详见下表 |

### 1.2 隐性成本量化

| 隐性成本 | 估算方法 | 示例 |
|------|------|------|
| 切换期效率下降 | 1-3个月效率降20-40% × 相关人力成本 | 50个店员×2周学习×30%效率降=XX元 |
| 数据清洗与补录 | 估计人天数 × 人天成本 | 3人×10天=30人天=XX元 |
| 老系统并行运行 | 老系统年费×并行月数÷12 | 老POS年费¥5万×3月并行=¥1.25万 |
| 未来退出/迁移 | 数据导出+新系统导入成本（5年摊销） | 预估¥5-10万÷5 |

### 1.3 各业态TCO基准参考

| 业态 | 年均TCO/店 | 占营收% | 主要成本构成 |
|------|:---:|:---:|------|
| 夫妻便利店 | ¥2,000-5,000 | 0.1-0.3% | POS订阅+支付手续费 |
| 社区超市 | ¥8,000-20,000 | 0.5-1.0% | POS+进销存+小程序 |
| 服装专卖 | ¥15,000-50,000 | 1.0-2.5% | POS+ERP+CRM+全渠道 |
| 大卖场 | ¥50,000-200,000 | 2.0-4.0% | 全套SaaS+IoT+BI |

## 二、收益量化

### 2.1 收益5大类

| # | 收益类别 | 量化方法 | 置信度 |
|---|------|------|:---:|
| 1 | **人力节省** | 节省人时×薪酬×(1-切换期损失) | 高 |
| 2 | **成本降低** | 采购成本降幅×年采购额 | 中高 |
| 3 | **损耗减少** | 损耗率降幅×年损耗额 | 中 |
| 4 | **库存优化** | 库存降幅×资金成本率 | 中高 |
| 5 | **营收增长** | 增量渠道GMV×毛利率 | 中低 |

### 2.2 收益量化示例

| 收益来源 | 计算公式 | 年收益(万元) |
|------|------|:---:|
| 收银效率提升 | 省X小时/天×365天×XX元/h÷10000 | |
| 采购成本降低 | 年采购额XX万×降价X% | |
| 损耗减少 | 年损耗XX万×降幅X% | |
| 库存持有成本降低 | 平均库存XX万×降幅X%×资金成本X% | |
| 线上增量营收 | 日增量XX单×客单XX元×365天×毛利率% | |

## 三、ROI计算

### 3.1 标准公式

```
3年ROI = （3年总收益 - 3年TCO）/ 3年TCO × 100%
回收期（月） = 总TCO / 年化收益 × 12
```

### 3.2 ROI基准参考

| 投资类型 | 行业3年ROI中位数 | 回收期中位数 |
|------|:---:|:---:|
| POS/收银 | 250% | 8个月 |
| ERP/进销存 | 200% | 12个月 |
| CRM/CDP | 280% | 8个月 |
| WMS | 180% | 14个月 |
| 全渠道OMS | 220% | 10个月 |
| AI客服 | 350% | 4个月 |
| AI推荐 | 250% | 6个月 |
