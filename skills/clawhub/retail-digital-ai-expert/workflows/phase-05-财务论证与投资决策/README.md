# Phase 05 — 财务论证与投资决策

> **阶段目标**：基于选型结果，完成TCO/ROI建模，编写投资建议书，推动管理层审批。
> **周期**：2-4周
> **核心产出**：TCO模型 + ROI商业论证报告 + 投资建议书

## 阶段概览

```
TCO建模 → 收益量化 → ROI计算 → 敏感度分析 → 投资建议书 → 管理层汇报
 (3-5天)   (3-5天)   (1-2天)    (1-2天)    (3-5天)      (1天)
```

## 核心原则

1. **所有数字有出处**：每个假设标注来源（客户数据/行业基准/厂商承诺）
2. **保守估计**：收益取悲观值，成本取乐观值→这样算出的ROI才是底线
3. **三情景分析**：悲观/基准/乐观→让决策者看到全景
4. **不做投资的代价也要算**：效率损失+机会成本+竞争落后
