# Phase 06 — 变革管理与组织设计

> **阶段目标**：确保系统上线后"有人用、用得好"，建立数字化组织和能力。
> **周期**：持续（上线前4-6周启动变革管理）
> **核心产出**：变革管理计划 + 培训方案 + 数字化组织设计方案

## 阶段概览

```
变革影响分析 → ADKAR五阶段计划 → 沟通与培训 → 数字化组织设计 → 持续固化
    (1周)          (1-2周)        (3-4周)        (1-2周)        (持续)
```

## 核心原则

1. **变革管理 = 系统成功的50%**：系统再好没人用=失败
2. **培训投入 ≥ 系统投入的30%**：教会店员比选对系统更重要
3. **先减负后增效**：让店员感受到"用了更轻松"而不是"又来管我了"
4. **即时奖励 > 远期承诺**：学会奖励¥50现金 > "用了升职加薪"
