# Phase 04 — 技术选型与供应商评估

> **阶段目标**：基于目标架构，完成核心系统选型、供应商评估和合同签订。
> **周期**：4-8周
> **核心产出**：需求清单 + 选型报告 + 供应商推荐 + 合同

## 阶段概览

```
需求清单确认 → 自建vs采购决策 → 长名单筛选(RFI) → 短名单评估(RFP+七维评分) → PoC验证 → 合同谈判
   (1周)          (3天)           (1-2周)           (2-3周)            (1-2周)      (1周)
```

## 核心原则

1. **需求驱动选型**：先清楚要什么，再去看谁有——不要被厂商带着走
2. **至少3家对比**：永远比较至少3家（含1家开源/低成本选项）
3. **PoC必做**：核心系统（POS/ERP/WMS）必须做PoC——不上手不知道
4. **合同保护自己**：SLA、退出条款、数据迁移是底线
