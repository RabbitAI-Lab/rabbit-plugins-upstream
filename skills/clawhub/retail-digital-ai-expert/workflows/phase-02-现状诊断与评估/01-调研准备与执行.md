# 01 — 调研准备与执行

> **触发条件**：项目启动（签约或Pre-study阶段）
> **产出**：调研计划 + 访谈纪要 + 材料收集清单 + 门店走访记录

---

## 一、调研前准备（签约后3-5天）

### 1.1 材料收集清单（提前发客户）

```
□ 组织架构图
□ 门店清单（地址/面积/员工数/开业时间）
□ 现有系统清单（系统名/版本/上线年份/覆盖范围）
□ 系统架构图（如有）
□ 12-24个月财务数据（营收/毛利/净利/成本明细）
□ 12-24个月运营数据（客流量/客单价/转化率/库存周转/损耗率）
□ 会员数据（会员数/复购率/储值额/流失率）
□ IT预算及实际支出（过去2年+今年计划）
□ 现有数字化项目清单/IT规划（如有）
□ 组织架构中IT岗位及职责
```

### 1.2 角色访谈计划

| 角色 | 人数 | 时长 | 核心问题方向 |
|------|:---:|:---:|------|
| **CEO/老板** | 1 | 90min | 战略、愿景、痛点感知、预算意愿 |
| **COO/运营负责人** | 1 | 90min | 运营流程、门店管理、考核机制 |
| **CTO/IT负责人** | 1 | 90min | 系统现状、技术债务、团队能力 |
| **店长（2-3家不同门店）** | 2-3人 | 60min/人 | 日常运营、系统使用体验、最大痛点 |
| **店员/导购** | 2-3人 | 30min/人 | POS体验、会员操作、培训情况 |
| **采购/供应链负责人** | 1 | 60min | 供应商管理、采购流程、库存管理 |
| **财务负责人** | 1 | 60min | 对账流程、成本核算、IT支出 |

## 二、各角色访谈提纲

### CEO/老板（90分钟）

| # | 问题 | 目的 |
|---|------|------|
| 1 | "您对3年后的企业有什么想象？" | 愿景和野心大小 |
| 2 | "目前让您最睡不着觉的经营问题是什么？" | 核心痛点 |
| 3 | "数字化对您意味着什么？" | 数字化认知水平 |
| 4 | "如果竞争对手全面数字化而您没有，会怎样？" | 紧迫感 |
| 5 | "您愿意为数字化投入多少？心里有预算范围吗？" | 预算意愿 |
| 6 | "之前在数字化上花过钱吗？效果如何？" | 历史经验（好/坏） |
| 7 | "谁在您公司应该负责数字化这件事？" | 组织准备度 |
| 8 | "如果这个项目成功，对您个人意味着什么？" | 个人动机 |

### 店长（60分钟）

| # | 问题 |
|---|------|
| 1 | "您一天的工作是怎么开始的？最花时间的3件事？" |
| 2 | "您现在用的系统好用吗？有什么特别想吐槽的？" |
| 3 | "库存准吗？多久盘一次？盘一次要多久？" |
| 4 | "您怎么知道哪个好卖哪个不好卖？" |
| 5 | "总部让您做的事，哪些是您觉得没必要的？" |
| 6 | "店员用系统怎么样？有不会用的吗？" |
| 7 | "如果有套新系统，您最希望它解决什么问题？" |

### 店员/导购（30分钟）

| # | 问题 |
|---|------|
| 1 | "收银/服务一个顾客要几步？感觉顺手吗？" |
| 2 | "查库存方便吗？（现场让她操作一次）" |
| 3 | "上次培训是什么时候？还记得怎么用吗？" |
| 4 | "顾客最常问您什么问题？您好回答吗？" |
| 5 | "用了系统，您觉得工作变快了还是变慢了？" |

### CTO/IT负责人（90分钟）

| # | 问题 |
|---|------|
| 1 | "现有系统清单和技术栈？哪些是自研、哪些是采购？" |
| 2 | "系统之间怎么打通的？打通到什么程度？" |
| 3 | "最大的技术债务是什么？" |
| 4 | "团队规模和技能构成？有AI/数据能力吗？" |
| 5 | "您最想换掉的系统是哪个？为什么还没换？" |
| 6 | "数据治理现状？有数据字典/主数据标准吗？" |
| 7 | "您的IT规划中未来12个月想做什么？" |

## 三、门店走访指南

### 走访目标

- 验证系统使用状况（系统显示 vs 实际使用）
- 发现系统无法反映的问题（物理流程中的断点）
- 感受一线员工情绪和态度

### 走访要点

| 观察点 | 看什么 | 问什么 |
|------|------|------|
| 收银台 | POS型号/速度/操作步骤 | "收一个顾客要按几次键？" |
| 货架区 | 价签是否准确/是否有缺货标签 | "缺货了怎么知道？" |
| 仓库/后仓 | 库存摆放/有无库位标识 | "找货要好找吗？"（跟着店员找一次） |
| 收货区 | 收货流程/有无PDA扫码 | "货到了怎么入库？" |
| 会员运营 | 是否有加微动作/社群活跃度 | "您加了多少顾客微信？" |
| 员工状态 | 表情/效率/士气 | "最近忙吗？累不累？" |

## 四、常见陷阱

1. **客户给的"标准答案"**：老板说"我们数字化意识很高"→去门店看真实使用情况
2. **只访谈管理层**：店长说的和店员说的是两套真相
3. **日程排太满**：一天最多访谈4-5人，多了信息质量下降
4. **带了方案预设**：调研是为了发现问题，不要带着答案去调研
