# Phase 02 — 现状诊断与评估

> **阶段目标**：全面了解客户数字化现状，量化差距，为后续战略制定提供事实基础。
> **周期**：3-4周
> **核心产出**：数字化成熟度评估报告 + TOP10差距清单

## 阶段概览

```
调研准备 → 多角色访谈 → 系统盘点 → 数据分析 → R-DMM评估 → 诊断报告
 (3-5天)    (5-7天)     (3-5天)    (3-5天)    (2-3天)     (3-5天)
```

## 核心原则

1. **数据 > 感觉**：客户说"我们库存管得还行"→看库存准确率数据
2. **现场 > 远程**：一定要去门店和仓库——系统显示的和实际发生的往往是两个世界
3. **多角色交叉验证**：老板说"系统挺好用的" + 店员说"太难用了"→两个都信
4. **对标才有震撼力**：客户觉得自己做得不错，一看行业基准"你们比行业平均低1.5个等级"
