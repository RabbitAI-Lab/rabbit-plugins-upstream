# 案例03：区域连锁服装品牌全渠道转型

> **业态**：服装专营专卖（区域连锁）
> **规模**：35家直营店（3省），年营收¥1.2亿
> **初始状态**：L2.0（有POS+基础ERP，但线上线下割裂、库存不准、会员不可识别）
> **目标状态**：L3.0（全渠道打通+CDP+OneID+智能配货）
> **投入**：¥85万/年
> **效果**：库存周转从90天降至55天，全渠道销售占比从0%升至22%

## 二、核心痛点

1. **库存是个黑洞**：35家店+1个总仓，库存准确率仅~82%，经常"系统有实际无"
2. **全渠道是口号**：小程序有但库存独立，天猫有但团队独立，门店完全不知道线上在卖什么
3. **会员割裂**：线上线下两套会员——门店VIP卡 vs 小程序会员，同一个人两个ID
4. **配货靠经验**：货品分配到35家店全靠老业务员的经验，爆款断货+长尾积压同时存在
5. **导购流失带走客户**：好导购离职→VIP客户失联

## 三、解决方案

### 3.1 目标架构

```
┌────────────────────────────────────────────┐
│              全渠道中台（有赞+聚水潭）         │
│  商品中心 │ 订单中心 │ 库存中心 │ 会员中心(CDP) │
└────────────────────────────────────────────┘
         │              │              │
    ┌────▼────┐   ┌─────▼─────┐  ┌────▼────┐
    │ 35家门店 │   │ 小程序+天猫 │  │  总仓    │
    │ 有赞POS  │   │ 有赞+电商  │  │ 聚水潭WMS│
    └─────────┘   └───────────┘  └─────────┘
```

### 3.2 系统选型

| 系统 | 选型 | 年费 | 核心能力 |
|------|------|:---:|------|
| POS+全渠道 | 有赞零售连锁版 | ¥15万 | POS+小程序+会员+全渠道 |
| OMS+WMS | 聚水潭 | ¥12万 | 全渠道订单路由+智能配货+WMS |
| CDP | 有赞CRM（含CDP） | ¥8万 | OneID+标签+画像+MA |
| BI | 观远数据 | ¥8万 | 零售BI+智能预警 |
| 企微SCRM | 有赞企微助手 | ¥3万 | 导购企微+会员1v1 |

### 3.3 实施路径（18个月）

| 阶段 | 月份 | 行动 | 里程碑 |
|------|------|------|------|
| **统一底座** | 1-4月 | ① 35店统一换有赞POS ② 35,000 SKU主数据治理 ③ 总仓WMS上线 | 库存准确率>92% |
| **全渠道打通** | 5-8月 | ① OMS上线（天猫+小程序+门店订单统一） ② 一盘货（线上线下共享库存） ③ 门店发货启动 | 线上订单门店发货>15% |

| **智能升级** | 13-18月 | ① BI+智能预警 ② AI智能配货（试点） ③ AI个性化推荐 | 配货效率+40% |

## 五、关键成功要素

1. **主数据治理是所有服装数字化的前提**：35,000 SKU（色×码）的主数据统一是最大工程，花了大价钱但值得
2. **门店发货（Ship from Store）是"杀手功能"**：天猫订单由最近门店发出→顾客当天收货+门店清库存=双赢
3. **导购的企微=会员资产企业化**：导购离职，客户关系留在企微上，企业可重新分配
4. **智能配货需要信任建立期**：先AI建议+人工确认（3个月）→AI自动+人工抽查（3个月）→全自动

## 六、避坑教训

1. ❌ 不要一次性全部门店切换——先2家试点→5家→全部（试点中发现POS离线场景、打印机兼容等15+问题）
2. ❌ 不要低估SKU主数据工作量——35,000 SKU录入+图片+属性标签花了6个人2个月
3. ❌ CDP的OneID打通比想象中难——手机号匹配率仅65%，加上微信UnionID才到85%
4. ✅ 让导购看到线上订单的提成——门店发货订单给门店70%佣金，导购才愿意推线上
