# 案例01：夫妻便利店数字化从0到1

> **业态**：街边夫妻老婆便利店
> **规模**：1家店，80㎡，日均营收¥3,000
> **初始状态**：L1.0（纯手工——纸质记账+单机收银机+无线上）
> **目标状态**：L1.5（基础数字化——云POS+外卖+移动支付+简单会员）
> **投入**：¥2,500/年
> **效果**：营收+25%，利润+35%，每天省1小时记账时间

---

## 一、客户画像

| 项目 | 内容 |
|------|------|
| 店主 | 王老板，45岁，夫妻经营，无IT经验 |
| 门店 | 社区街边店，周边3个小区，约2000户 |
| 品类 | 烟酒饮料零食日杂，SKU约800 |
| 日均客单 | ~100单，客单价~30元 |
| 月营收 | ~¥90,000 |
| 月毛利 | ~¥22,500（毛利率~25%） |
| 系统现状 | 一台老旧单机收银机 + 纸质账本记账 |
| 线上 | 无 |

## 二、核心痛点

1. **记账费时**：每天关门后花30-40分钟对账，还经常对不上
2. **库存盲区**：不知道什么好卖什么滞销，过期了才发现
3. **客流下滑**：周边新开了社区团购自提点，分流了部分顾客
4. **老客流失**：没有会员，不知道谁来得多、谁好久没来
5. **现金风险**：现金收银容易出错、找零麻烦、假币风险

## 三、解决方案

### 3.1 选型决策

| 对比项 | 方案A：科脉零售云POS | 方案B：美团收银 | 方案C：思迅零售 |
|------|------|------|------|
| 年费 | ¥1,800 | ¥500（基础版） | ¥1,500 |
| 硬件 | ¥800（二手平板） | ¥0（用手机） | ¥1,200 |
| 外卖打通 | 需额外对接 | 原生打通 | 需额外对接 |
| 易用性 | ★★★ | ★★★★★ | ★★★ |
| **推荐** | | ✅ **首选** | |

**选型结果**：美团收银标准版（¥500/年）+ 自购二手收银平板（¥800）

### 3.2 实施路径（3个月）

| 月份 | 行动 | 产出 | 投入 |

| 第1月 | ① 安装美团收银+平板 ② 录入800个SKU ③ 开通微信/支付宝收款 | 收银电子化 | ¥1,300 |
| 第2月 | ① 上线美团闪购+饿了么 ② 学会看当日报表 ③ 基础会员（储值+积分） | 线上渠道开通 | ¥1,200 |

## 五、关键成功要素

1. **选最简单的工具**：不是功能最多的，是一看就会的（美团收银=手机界面一样简单）
2. **外卖先做**：最快见效的增量渠道（不需要额外投入）
3. **不要追求完美库存**：800个SKU不需要全部精确管理，先管好TOP200
4. **微信群是最好的CRM**：不花钱、触达快、有人情味

## 六、避坑教训

1. ❌ 别听厂商忽悠上全套进销存——1家店用不上
2. ❌ 别为了省钱继续用单机POS——离线数据永远对不上
3. ❌ 别追求会员体系完善——积分+储值就够
4. ✅ 外卖图片要拍好——这是线上"门面"
5. ✅ 每天花5分钟看报表——比花30分钟对账好100倍

## 八、下一步方向

- 如果开第2家店→升级为科脉/有赞零售（多店管理）
- 如果外卖占比>30%→考虑小程序（省平台佣金）
- 如果会员>500→考虑企业微信（1v1触达）

---

> **案例启示**：对夫妻店来说，数字化不是"花大钱上系统"，而是"花小钱解决最痛的问题"。¥2,500/年的投入换来¥31,825/年的收益，这是零售数字化ROI最高的场景。
