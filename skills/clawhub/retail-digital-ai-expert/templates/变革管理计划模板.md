## 三、ADKAR变革计划

### 3.1 Awareness（意识唤醒）

**目标**：每个人都知道"为什么要变"、"对我有什么影响"

| 活动 | 对象 | 时间 | 渠道 | 关键信息 |
|------|------|------|------|------|
| CEO全员信 | 全员 | | 企业微信/邮件 | 变革愿景+企业承诺 |
| 变革启动会 | 管理层 | | 线下会议 | 行业趋势+竞对情况+不改变的代价 |
| 门店宣讲 | 门店员工 | | 店长晨会 | "隔壁店用了后，提成涨了XX" |

### 3.2 Desire（意愿建立）

**目标**：每个人愿意参与变革

| 活动 | 对象 | 如何激发 | 负责人 |
|------|------|------|------|
| 标杆门店参观 | 店长 | 实地看"用了=更好" | |
| 个人利益绑定 | 店员 | "提成多XX"+"不用加班盘点" | |
| 竞对压力 | 管理层 | "竞对____已经做到了____" | |

### 3.3 Knowledge（知识培训）

**目标**：每个人知道怎么用

| 课程 | 对象 | 时长 | 方式 | 考核 |
|------|------|:---:|------|------|
| 新系统概览 | 全员 | 30min | 视频 | — |
| 收银操作(基础) | 店员 | 1h | 实操+视频 | 3次0失误 |
| 收银操作(高级) | 店长/骨干 | 2h | 实操+场景 | 5场景全过 |
| 库存管理 | 店长/仓管 | 1.5h | 实操 | 盘点误差<2% |
| 会员管理 | 店员/店长 | 1h | 实操 | 独立完成入会+查询 |
| 报表与分析 | 店长/管理层 | 2h | 演示+实操 | 独立解读3张报表 |
| 系统管理 | IT | 4h | 实操 | 独立处理常见问题 |

### 3.4 Ability（能力固化）

**目标**：每个人能熟练使用，形成肌肉记忆

| 活动 | 时间 | 方式 |
|------|------|------|
| 沙箱练习期 | 上线前2周 | 沙箱环境自由练习，不限次数 |
| 师徒制 | 上线后2周 | 每店1名"数字小能手"带教 |

| 驻场支持 | 上线后1-2周 | IT+厂商驻场，随时答疑 |

### 3.5 Reinforcement（巩固强化）

**目标**：新行为成为新习惯

| 活动 | 时间 | 方式 |
|------|------|------|
| 操作数据看板 | 上线后持续 | 日报：谁在用/谁没用/谁出错 |
| 即时奖励 | 上线后1月 | "零失误奖"¥50-100即时发放 |
| 月度"数字之星" | 上线后持续 | 评选+公示+奖金 |
| KPI挂钩 | 上线后2月起 | 系统使用率纳入绩效考核 |
| 双周复盘会 | 上线后持续 | 问题→反馈→优化→更新 |

## 五、阻力管理

### 5.1 典型阻力与应对

| 阻力类型 | 典型话术 | 应对策略 |
|------|------|------|
| **老板** | "太贵了/不知道值不值" | 算细账→小范围试点→用数据说话 |
| **店长** | "没时间学/增加我工作量" | 证明系统减负(排班节省2h/周) |
| **资深店员** | "收银十几年了，不用系统也行" | 尊重经验+示范效率提升+奖金激励 |
| **中年店员** | "我不会用/太难了" | 视频教材+师徒制1v1+多练习机会 |
| **加盟商** | "总部又来管我了" | 先供应链(省钱)→看到收益→自愿接受 |
| **IT部门** | "又得学新系统" | 职业发展路径+认证+晋升机会 |

### 5.2 阻力升级机制

```
Level 1: 个人不使用 → 直接上级沟通→了解原因→提供帮助
Level 2: 持续不使用 → 变革负责人介入→定制辅导计划
Level 3: 公开抵触 → 管理层沟通→警告→调岗
```
