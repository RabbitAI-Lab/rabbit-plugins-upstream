# 零售科技供应商全景图

> 覆盖全球9大零售科技品类、80+主流供应商的深度对照。每个品类提供全球领先、中国领先、开源/免费三层次选项。

---

## 一、POS/统一商务平台（10家深度 + 8家速查）

### 1.1 全球头部

#### Oracle Retail
- **定位**：全球最完整的零售企业级全栈解决方案
- **核心产品**：Oracle Retail Xstore POS + Merchandising + Planning + Supply Chain + Insights
- **适用业态**：大型超市/百货/连锁/全球万店
- **优势**：品类管理、供应链、定价促销一体；40年零售技术积累
- **短板**：贵(6-7位数)、实施周期6-18个月、需要专业团队运维
- **中国覆盖**：有团队，但生态不如本地厂商
- **典型客户**：Walmart历史用户、全球大型百货、连锁超市
- **参考年费**：定制报价(通常¥100万-500万+/年)

#### Shopify POS
- **定位**：从线上到线下的统一商务平台，SMB首选
- **核心产品**：Shopify POS(硬件+软件) + Shopify电商 + Shopify Payments
- **适用业态**：独立零售/DTC品牌/中小连锁/快闪店
- **优势**：线上线下统一库存/订单/会员；极致易用(30分钟上手)；App生态丰富
- **短板**：大型复杂零售场景(多仓/多税率/多语言)支撑有限；中国大陆支付生态适配一般
- **典型客户**：全球DTC品牌、独立零售商、中小连锁
- **参考年费**：$29-299/月(POS订阅) + 交易费

#### NCR Voyix
- **定位**：全球零售POS巨头，超市/便利店/百货垂直深耕
- **核心产品**：NCR Voyix POS + SCO自助结账 + 数字化银行
- **适用业态**：超市/大卖场/便利店/百货
- **优势**：超市/便利店垂直能力极深；自研硬件+软件一体；140年历史
- **短板**：不进入中国零售市场；体系封闭；价格高昂
- **典型客户**：全球大型连锁超市/便利店
- **参考年费**：定制报价

#### Cegid(法国零售POS/ERP领袖，2021年收购Planday)
- **定位**：欧洲零售POS/ERP领袖，服装/美妆/奢侈/生活方式垂直深耕
- **核心产品**：Cegid Retail(Y2) + Cegid Pulse(AI) + Cegid LiveStore
- **适用业态**：服装/美妆/奢侈品牌/生活方式/专营专卖
- **优势**：AI原生(Pulse AI助手)；移动POS领先；欧洲多国合规(LFP/反欺诈法等)；全球部署
- **资本关系（已于2026-07更正，以现行为准）**：Cegid 于 2021 年收购 Planday（劳动力管理 SaaS），二者同属 Cegid 集团；集团由私募股权基金控股（原"被Planday并购后独立"表述有误，实际为 Cegid 收购 Planday）。
- **短板**：亚洲覆盖弱；奢侈品定位→价格不菲
- **典型客户**：欧洲奢侈品牌、服装连锁、美妆品牌
- **参考年费**：定制报价(¥30万-200万+/年)

### 1.2 中国头部

#### 有赞
- **定位**：中国零售SaaS头部，私域+社交电商+零售一体化
- **核心产品**：有赞零售(门店POS+进销存+会员+小程序+企微)
- **适用业态**：服装/美妆/食品/母婴/连锁专卖/社区零售
- **优势**：社交电商+私域运营一体化(直播/分销/拼团/秒杀)；企微深度打通；周周迭代
- **短板**：大型连锁能力不足；复杂供应链弱；定制化有限
- **典型客户**：中小连锁零售、品牌专卖店、DTC品牌
- **参考年费**：¥6,800-30,000元/年(按门店)

#### 微盟
- **定位**：腾讯系零售SaaS，智慧零售+企微原生
- **核心产品**：微盟智慧零售(门店POS+小程序+企微+会员+BI)
- **适用业态**：服装/美妆/家居/3C/建材
- **优势**：企微原生(SCRM深度融合)；全链路打通(引流→转化→复购→裂变)；BI能力强
- **短板**：进销存/供应链不如垂直厂商；定制化依赖生态伙伴
- **典型客户**：服装品牌连锁、3C专卖、家居建材
- **参考年费**：¥6,800-50,000元/年(按门店+功能)

#### 海鼎
- **定位**：中国连锁零售ERP+POS标杆，30年行业深耕
- **核心产品**：海鼎零售ERP + POS + WMS + 会员 + 加盟管理
- **适用业态**：连锁超市/便利店/专卖店/零食量贩/加盟品牌
- **优势**：连锁零售全场景覆盖；加盟商管理能力突出；30年行业经验；名创优品等标杆
- **短板**：产品迭代慢于互联网厂商；UI/UX较传统；外部市场依赖合作伙伴
- **典型客户**：名创优品、美宜佳、零食很忙、赵一鸣零食等万店品牌
- **参考年费**：¥5万-50万元/年(按规模)

#### 科脉
- **定位**：中小零售数字化专家，性价比之选
- **核心产品**：科脉零售云POS + 进销存 + 会员 + 小程序
- **适用业态**：中小超市/便利店/生鲜/社区零售
- **优势**：性价比高；中小零售市占率高；渠道覆盖广(代理商网络)
- **短板**：大型连锁能力弱；AI/智能化落后
- **典型客户**：中小连锁超市、便利店、社区生鲜
- **参考年费**：¥3,000-20,000元/年

#### 石基零售
- **定位**：大型零售+酒店双赛道，百货/购物中心垂直深耕
- **核心产品**：石基零售ERP + POS + 会员 + BI
- **适用业态**：百货/购物中心/大型超市/连锁品牌
- **优势**：大型百货/购物中心深度耕耘；与Oracle/微软等全球巨头合作
- **短板**：中小客户少；产品体系庞杂；国际化后的本地化适配
- **典型客户**：银泰百货(历史)、王府井、大型购物中心
- **参考年费**：¥10万-100万元/年

#### 思迅
- **定位**：中小零售POS，渠道王者
- **核心产品**：思迅零售POS + 进销存 + 基础会员
- **适用业态**：中小超市/便利店/专卖店
- **优势**：价格低；渠道覆盖极广(全国代理商)；上手简单
- **短板**：大型客户弱；全渠道/电商能力不足
- **参考年费**：¥2,000-15,000元/年
