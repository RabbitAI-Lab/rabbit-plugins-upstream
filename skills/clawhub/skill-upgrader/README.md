# Skill Upgrader for OpenClaw

Skill meta-level yang bisa **menganalisis, mendiagnosis, dan mengupgrade skill apa pun** dari basic menjadi legendary tier.

## Konsep

Skill ini adalah **"skill compiler"** — ia mengambil skill yang sudah ada dan mengoptimasi setiap aspeknya:

- **Arsitektur** → Restrukturasi untuk kekuatan maksimal
- **Reasoning** → Injeksi protokol berpikir multi-lapisan
- **Output** → Peningkatan standar kualitas ke level tertinggi
- **Robustness** → Penanganan error dan edge case
- **Extensibility** → Desain untuk evolusi masa depan

## Instalasi

### OpenClaw Lokal
```bash
cp -r skill-upgrader ~/.openclaw/skills/
```

### Kimi Claw (Browser)
1. Buka Kimi Claw → Skill Workshop
2. Upload folder `skill-upgrader`
3. Aktifkan skill

## Cara Penggunaan

Setelah aktif, minta agent untuk mengupgrade skill apa pun:

```
"Upgrade skill writing saya ke legendary tier"
"Enhance skill coding saya dengan error recovery"
"Evolve skill research saya untuk handle edge cases"
"Make skill analysis saya produce expert-level outputs"
"Upgrade skill X saya agar setara skill Y"
"Diagnosis skill Z saya — apa yang kurang?"
```

## Protokol Upgrade (6 Fase)

### Fase 1: Diagnosis
- Baca skill target secara lengkap
- Skor 10 dimensi (Purpose, Reasoning, Framework, Output, Edge Case, Context, Tools, Voice, Reference, Completeness)
- Identifikasi strengths, gaps, dan missed opportunities

### Fase 2: Architecture Upgrade
- Restrukturasi skill untuk clarity dan power
- Tambah komponen yang hilang
- Hapus redundancy dan fluff

### Fase 3: Reasoning Upgrade
- Injeksi protokol berpikir mendalam
- Tambah self-correction loops
- Install verification frameworks

### Fase 4: Output Upgrade
- Naikkan standar output
- Tambah quality gates
- Install polish protocols

### Fase 5: Meta-Upgrade
- Tambah inter-skill compatibility
- Install context intelligence
- Tambah error recovery

### Fase 6: Final Validation
- Stress test dengan edge cases
- Re-audit skor kualitas
- Produksi versi upgraded

## 7 Enhancement Layers

| Layer | Fungsi |
|-------|--------|
| **Clarity** | Visual hierarchy, progressive disclosure, instant comprehension |
| **Depth** | Multi-step reasoning, self-correction, verification |
| **Breadth** | Edge cases, variations, integration points |
| **Precision** | Specific instructions, success criteria, examples |
| **Elegance** | Voice refinement, flow, memorable phrases |
| **Robustness** | Error handling, fallbacks, graceful degradation |
| **Extensibility** | Extension points, configuration, versioning |

## 6 Stage Evolution

Skill yang diupgrade harus mendukung SEMUA stage:

| Stage | Kebutuhan |
|-------|-----------|
| **Novice** | Step-by-step, examples, templates |
| **Competent** | Frameworks, checklists, patterns |
| **Proficient** | Adaptation, combinations, advanced tips |
| **Expert** | Theory, internals, custom frameworks |
| **Master** | Teaching tools, assessment, research |
| **Legendary** | First principles, paradigms, innovation |

## 10 Quality Gates

Setiap output harus lolos:
1. Accuracy — Semua fakta benar
2. Completeness — Semua kebutuhan terpenuhi
3. Clarity — Tidak ada ambiguitas
4. Concision — Cut 20% tanpa kehilangan nilai
5. Depth — Lebih dari permukaan
6. Precision — Spesifik, terukur
7. Relevance — Semua sesuai tujuan
8. Originality — Bukan generic AI output
9. Polish — Grammar, formatting, visual hierarchy sempurna
10. Impact — Reader belajar, termotivasi, bisa bertindak

## 12 Components Legendary Skill

Skill yang diupgrade harus memiliki:
1. Crystal-clear Purpose
2. Trigger Intelligence
3. Reasoning Architecture
4. Framework Library
5. Output Specifications
6. Edge Case Protocols
7. Context Management
8. Tool Mastery
9. Voice & Persona Engine
10. Reference Architecture
11. Template System
12. Self-Improvement Loop

## Catatan

- Skill ini bekerja sebagai **meta-skill** — ia tidak mengganti skill target, tapi mengoptimalkannya
- Setelah upgrade, skill target menjadi versi "Legendary"-nya
- Proses upgrade bisa dijalankan berulang kali untuk iterasi berkelanjutan
- Open Source — bebas dimodifikasi dan didistribusikan
