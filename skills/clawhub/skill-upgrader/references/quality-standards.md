# Absolute Quality Standards

> The highest possible standards for skill output. Nothing ships without passing ALL gates.

---

## The 5 Output Tiers

```
TIER 1: FUNCTIONAL (60-69)
  → Correct and complete
  → Meets basic requirements
  → No obvious errors
  → "It works"

TIER 2: GOOD (70-79)
  → Well-structured
  → Clear and organized
  → Appropriate for context
  → "It's solid"

TIER 3: EXCELLENT (80-89)
  → Insightful and valuable
  → Goes beyond requirements
  → Professional quality
  → "This is impressive"

TIER 4: ELITE (90-96)
  → World-class quality
  → Indistinguishable from top human experts
  → Surprises with depth and precision
  → "This is exceptional"

TIER 5: LEGENDARY (97-100)
  → Transcends expectations
  → Creates new insights
  → Changes how the user thinks
  → "This is transformative"
```

## The 10 Quality Gates

### GATE 1: ACCURACY
```
□ All facts are correct
□ All claims are verifiable
□ All data is accurate
□ All quotes are attributed
□ All references are real

FAILURE MODE: Hallucination, incorrect data, false attribution
FIX: Verify every claim, cite sources, express uncertainty
```

### GATE 2: COMPLETENESS
```
□ All user requirements addressed
□ No questions left unanswered
□ No sections missing
□ Edge cases covered
□ Follow-up needs anticipated

FAILURE MODE: Missing sections, unanswered questions, incomplete analysis
FIX: Checklist against original request, add "what's missing" section
```

### GATE 3: CLARITY
```
□ Every sentence is understandable
□ No ambiguity
□ Jargon explained or avoided
□ Structure is intuitive
□ Flow is logical

FAILURE MODE: Confusing sentences, unexplained terms, unclear structure
FIX: Read aloud, "explain to a 10-year-old" test, add examples
```

### GATE 4: CONCISION
```
□ No filler words
□ No redundant sections
□ Every sentence adds value
□ 20% could be cut without loss
□ No "fluff"

FAILURE MODE: Wordiness, repetition, padding
FIX: Cut 20%, remove "very/really/just", merge similar sections
```

### GATE 5: DEPTH
```
□ Surface level covered
□ Deeper layers explored
□ "Why" not just "what"
□ Connections made
□ Insights beyond the obvious

FAILURE MODE: Shallow, obvious, generic
FIX: Ask "so what?" 3 times, find the non-obvious angle
```

### GATE 6: PRECISION
```
□ Specific numbers, not vague
□ Concrete examples, not abstract
□ Defined terms, not assumed
□ Measurable outcomes
□ Exact instructions

FAILURE MODE: "Some", "many", "good", "improve"
FIX: Replace with specific numbers, examples, criteria
```

### GATE 7: RELEVANCE
```
□ Everything serves the purpose
□ No tangents
□ No "nice to know" without "need to know"
□ Audience-appropriate
□ Context-appropriate

FAILURE MODE: Off-topic, too broad, wrong audience
FIX: "So what?" test, audience check, purpose alignment
```

### GATE 8: ORIGINALITY
```
□ Not generic AI output
□ Unique insights
→ Fresh perspective
→ Creative solutions
→ Surprising connections

FAILURE MODE: Generic, templated, predictable
FIX: Combine unexpected elements, challenge assumptions, find the novel angle
```

### GATE 9: POLISH
```
□ Grammar perfect
□ Spelling perfect
□ Formatting consistent
□ Visual hierarchy clear
□ Professional presentation

FAILURE MODE: Typos, inconsistent formatting, poor layout
FIX: Proofread 3x, formatting checklist, visual audit
```

### GATE 10: IMPACT
```
□ Reader learns something
□ Reader is motivated
□ Reader can take action
□ Reader remembers it
□ Reader wants to share it

FAILURE MODE: Forgettable, unmotivating, no action
FIX: Add actionable takeaways, emotional hooks, memorable phrases
```

## The Quality Scorecard

**Rate each output 1-10 on all 10 gates. Average = final score.**

```
SCORING:
90-100 = ELITE (ship it, promote it)
80-89  = EXCELLENT (minor polish)
70-79  = GOOD (needs work)
60-69  = FUNCTIONAL (major revision)
<60    = UNACCEPTABLE (rewrite)
```

## The "Would a Human Expert Approve?" Test

```
Before shipping, ask:

1. "Would a top expert in this field approve of this output?"
   → If no, what's missing?

2. "Would this output impress a skeptical audience?"
   → If no, what's weak?

3. "Would I be proud to put my name on this?"
   → If no, what needs fixing?

4. "Is this better than 90% of what's out there?"
   → If no, how to make it so?

5. "Does this change how the reader thinks?"
   → If no, what's the insight gap?
```

## The Anti-Quality Patterns

**ELIMINATE these patterns on sight:**

```
❌ GENERIC OPENERS
  → "In today's world..."
  → "In the fast-paced..."
  → "As we all know..."
  → "It is important to note that..."

❌ WEAK VERBS
  → "is responsible for" → "manages"
  → "make a decision" → "decide"
  → "conduct an analysis" → "analyze"
  → "provide assistance" → "help"

❌ VAGUE QUANTIFIERS
  → "some", "many", "several", "various"
  → "good", "bad", "important", "significant"
  → Replace with SPECIFIC numbers or examples

❌ PASSIVE VOICE
  → "The report was written" → "I wrote the report"
  → "It was decided that" → "We decided"
  → "The analysis was conducted" → "We analyzed"

❌ REDUNDANCY
  → "advance planning" → "planning"
  → "future plans" → "plans"
  → "past history" → "history"
  → "free gift" → "gift"

❌ HEDGING
  → "It seems that perhaps..."
  → "One might possibly consider..."
  → "It could be argued that..."
  → Be direct. State with confidence or express uncertainty clearly.

❌ FILLER PHRASES
  → "In order to" → "To"
  → "Due to the fact that" → "Because"
  → "At this point in time" → "Now"
  → "In the event that" → "If"
  → "For the purpose of" → "To"

❌ GENERIC AI SPEAK
  → "It's important to remember that..."
  → "It's worth noting that..."
  → "This is a complex topic..."
  → "There are many factors to consider..."
  → Replace with specific, valuable content.
```

## The Final Checklist

```
BEFORE shipping ANY output:

□ Run the 10 Quality Gates
□ Score above 85 average
□ Pass the "Human Expert" test
□ Eliminate ALL anti-quality patterns
□ Read aloud for awkward phrasing
□ Check formatting consistency
□ Verify all links and references
□ Ensure CTA is clear (if applicable)
□ Add "what's missing" if anything
□ Sleep on it (if possible)
```
