# Skill Evolution: From Basic to Legendary

> The complete evolution path that every skill should support. Ensure upgraded skills work for ALL stages.

---

## The 6 Stages of Skill Mastery

### STAGE 1: NOVICE 🌱

**Mindset**: "Tell me exactly what to do"

**What they need from the skill:**
```
→ Step-by-step instructions with NO ambiguity
→ Examples for EVERY concept
→ Fill-in-the-blank templates
→ "If X, then do Y" logic
→ No assumed knowledge
→ Encouragement and reassurance
→ Explanations of WHY each step matters
```

**Skill output for Novices:**
```
"Here's exactly what to do:

Step 1: [Specific action]
  Why this matters: [Explanation]
  Example: [Concrete example]

Step 2: [Specific action]
  Why this matters: [Explanation]
  Example: [Concrete example]

If you get stuck: [Troubleshooting]
```

**Novice Support Features:**
- Glossary of all terms
- Prerequisites checklist
- "Before you start" section
- Common beginner mistakes
- "What success looks like" examples

---

### STAGE 2: COMPETENT 🌿

**Mindset**: "I know the basics, give me the framework"

**What they need from the skill:**
```
→ Proven frameworks (not just steps)
→ "When to use which" guidance
→ Checklists and rubrics
→ Common patterns and anti-patterns
→ Efficiency tips
→ Quality benchmarks
```

**Skill output for Competent users:**
```
"For this type of task, use [Framework X].

Framework X structure:
1. [Element]
2. [Element]
3. [Element]

When to use it: [conditions]
When NOT to use it: [conditions]
Common mistakes: [list]
Quality check: [checklist]
```

**Competent Support Features:**
- Framework selection guide
- Decision trees
- Quality scorecards
- Before/after examples
- "Good vs. Great" comparisons

---

### STAGE 3: PROFICIENT 🌳

**Mindset**: "I can adapt frameworks to my context"

**What they need from the skill:**
```
→ Framework adaptation rules
→ Context-sensitive guidance
→ "What if" scenarios
→ Combination strategies
→ Advanced techniques
→ Efficiency multipliers
```

**Skill output for Proficient users:**
```
"Given your context [X], adapt Framework Y by:

Modification 1: [Change] because [Reason]
Modification 2: [Change] because [Reason]

Alternative approach: [Different framework]
When to switch: [Conditions]

Pro tip: [Advanced technique]
```

**Proficient Support Features:**
- Adaptation guidelines
- Context mapping
- Combination frameworks
- Efficiency shortcuts
- Advanced parameters

---

### STAGE 4: EXPERT 🏆

**Mindset**: "I can innovate and combine frameworks"

**What they need from the skill:**
```
→ Deep theoretical foundations
→ Framework internals (why they work)
→ Creative combination strategies
→ Edge case handling
→ Custom framework creation guidance
→ Meta-analysis capabilities
```

**Skill output for Experts:**
```
"The theoretical basis for Framework X is [theory].

It works because:
1. [Psychological principle]
2. [Cognitive mechanism]
3. [Behavioral pattern]

You can extend it by:
→ Adding [element] for [effect]
→ Removing [element] for [effect]
→ Combining with [framework] for [synergy]

For your edge case [X], consider:
→ [Unconventional approach]
→ [Research-backed alternative]
```

**Expert Support Features:**
- Theoretical foundations
- Research citations
- Framework internals
- Extension points
- Custom creation guides
- Meta-frameworks

---

### STAGE 5: MASTER 🎓

**Mindset**: "I can teach this to others"

**What they need from the skill:**
```
→ Pedagogical frameworks
→ Teaching sequences
→ Assessment rubrics
→ Common student misconceptions
→ Advanced troubleshooting
→ Research and innovation tools
```

**Skill output for Masters:**
```
"To teach this concept effectively:

Sequence:
1. Start with [prerequisite concept]
2. Use [analogy] to bridge understanding
3. Present [framework] with [example]
4. Have them practice with [exercise]
5. Assess with [criteria]

Common misconceptions:
→ [Misconception 1] → Correct with [approach]
→ [Misconception 2] → Correct with [approach]

For advanced students:
→ [Extension activity]
→ [Research project]
```

**Master Support Features:**
- Teaching frameworks
- Assessment tools
- Misconception catalogs
- Research extensions
- Innovation prompts

---

### STAGE 6: LEGENDARY 🌟

**Mindset**: "I transcend frameworks and create new paradigms"

**What they need from the skill:**
```
→ First principles thinking
→ Paradigm-shifting insights
→ Cross-domain synthesis
→ Innovation triggers
→ Meta-cognitive tools
→ Philosophy and theory of the domain
```

**Skill output for Legendary users:**
```
"At the fundamental level, this domain is about [core principle].

Current paradigms assume [assumption].
But what if we question that?

Alternative paradigm:
→ [New framework]
→ [Why it's better]
→ [When to apply]
→ [Limitations]

The frontier of this domain:
→ [Emerging research]
→ [Unexplored territories]
→ [Your potential contribution]
```

**Legendary Support Features:**
- First principles analysis
- Paradigm critiques
- Innovation frameworks
- Cross-domain connections
- Research frontiers
- Philosophy of the domain

## Stage-Specific Output Calibration

**When producing output, detect the user's stage and calibrate:**

```
NOVICE indicators:
→ Vague requests ("help me write")
→ Ask for examples repeatedly
→ Need reassurance
→ "I don't know where to start"

COMPETENT indicators:
→ Request frameworks
→ Ask "which is better?"
→ Want checklists
→ "What's the best practice?"

PROFICIENT indicators:
→ Mention specific constraints
→ Ask about adaptations
→ "How would you handle [edge case]?"
→ Want efficiency tips

EXPERT indicators:
→ Use domain jargon correctly
→ Challenge assumptions
→ "What about [advanced concept]?"
→ Want theoretical depth

MASTER indicators:
→ Ask about teaching
→ Request assessment tools
→ "How do I explain this to...?"
→ Want pedagogical frameworks

LEGENDARY indicators:
→ Question fundamental assumptions
→ Synthesize across domains
→ "What if we tried [unconventional approach]?"
→ Want paradigm-shifting insights
```

## The Skill as a Ladder

**Design the skill so users can climb it:**

```
NOVICE uses: Quick Start + Templates + Examples
COMPETENT uses: Frameworks + Checklists + Patterns
PROFICIENT uses: Adaptation + Combinations + Advanced tips
EXPERT uses: Theory + Internals + Custom frameworks
MASTER uses: Teaching tools + Assessment + Research
LEGENDARY uses: First principles + Paradigms + Innovation
```

**Each stage builds on the previous. Nothing is wasted.**
