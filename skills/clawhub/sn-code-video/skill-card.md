## Description:

Create and revise code-driven videos with Canvas, SVG, HTML/CSS, Three.js, Remotion, Manim, or p5.js, including sound, deterministic frame capture, visual review, and MP4 verification. Use for rendered explainers, procedural animations, motion graphics, promos, and music-synchronized films; not for general web apps, scroll-driven HTML stories, or footage generation with video models.

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: Crafted inputs can execute code or write files outside the intended output folder.

Mitigation: Review before execution, use an isolated environment with trusted project files and arguments, validate narration IDs and contact-sheet settings, and enforce directory containment in the capture service.

Risk: Narration text is sent to Microsoft's speech service for processing.

Mitigation: Use only narration text approved for external processing.
