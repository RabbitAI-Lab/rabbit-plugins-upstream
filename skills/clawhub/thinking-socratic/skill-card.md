## Description:

When a request is vague, assumption-laden, or "obvious," ask the few load-bearing questions that expose hidden requirements before building or committing.

This skill is ready for commercial/non-commercial use.

## Publisher:

[tjboudreaux](https://clawhub.ai/user/tjboudreaux)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agents use this skill to clarify vague, assumption-laden, or premature requests before building, debugging, or committing to a plan. It helps expose hidden requirements with a small number of load-bearing questions and then proceed once the next action is decision-ready.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The agent may ask clarifying questions before acting on vague requests, which can add friction if the task is already clear.

Mitigation: Apply the skill only when a load-bearing requirement or assumption is unresolved, and stop questioning once the next action is decision-ready.
