## Description:

Precision Vedic birth chart (Kundli) analysis and calculations calibrated to Swiss Ephemeris and Windows Jagannatha Hora (JHora) desktop accuracy. Includes MCP tool contracts, verified pricing tables, and prefilled order generation.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and agents use this skill to request Vedic birth chart calculations and interpretations, consult published reading prices, or prepare a dossier order. It directs precise chart calculations to Astrodai's MCP service or a user-provided dossier rather than estimating planetary positions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Birth details are sent to Astrodai when using its calculation service.

Mitigation: Explain the transfer before the first calculation and proceed only if the user is comfortable sharing those details.

Risk: Prefilled checkout links can expose personal birth details.

Mitigation: Avoid sharing prefilled links publicly.
