## Description:

Instagram profiles, posts, reels, and hashtags for agents — influencer and brand research with no Instagram login, Business account, or Meta app.

This skill is ready for commercial/non-commercial use.

## Publisher:

[superagnt](https://clawhub.ai/user/superagnt)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and research or marketing teams can use this skill to retrieve Instagram profile and media data for creator research, social listening, and content analysis. It provides API requests for profiles, posts, reels, locations, and hashtags.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Using the documented external API requires providing a superagnt API key.

Mitigation: Only provide the key to the intended API; keep it in a secret-managed environment variable and out of prompts, logs, and shared command output.
