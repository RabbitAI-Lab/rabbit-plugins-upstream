## Known Risks and Mitigations:

Risk: The API key and lookup inputs are sent to Superagnt.

Mitigation: Protect the API key and consider what research queries you share. Review consent before choosing the MCP connection.

Risk: The documented curl examples' quoting needs correction before execution.

Mitigation: Review and correct the quoting before running the examples.
