## Description:

Combines prepare a configuration entry with build a stakeholder configuration report.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wxt-ai](https://clawhub.ai/user/wxt-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Release operations teams and developers use this skill to turn release configuration notes into named configuration entries and concise stakeholder-facing report entries.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad routine release operations wording may cause the skill to be considered for release tasks outside a narrow configuration-reporting scope.

Mitigation: Confirm that the request is about release configuration entries or stakeholder report text before using the skill.

Risk: Generated configuration or report text can misstate release details when the input release note is incomplete or ambiguous.

Mitigation: Review generated entries against the authoritative release configuration before publication.
