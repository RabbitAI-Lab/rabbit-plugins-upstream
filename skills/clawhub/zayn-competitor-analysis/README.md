# COMPETITOR_ANALYSIS() 竞争对手分析

- Skill：`zayn-competitor-analysis`
- 用途：以证据比较直接、间接和替代竞争者。
- 不适用：无证据 SWOT、攻击性评价。
- 输入：对手、我方、市场、客户、目的、时间、维度。
- 最低条件：主体、竞争关系和比较边界清楚。
- 流程：画像→比较证据→重叠→差异→威胁→行动。
- 输出：对比表、优势弱点、机会、威胁、假设与来源。
- 证据：共享来源、时效、引用规则。
- 协作：research/social/market 上游，selection/opportunity 下游。
- 示例：比较我方与两家德国渠道商的产品、交付和售后差异。
- 版本：v1.0.0
