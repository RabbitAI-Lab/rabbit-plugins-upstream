# 练习库（10 个分级练习）

**强度**：🟢轻度（碎片时间可完成）· 🟡中度（需独处与情绪准备）· 🔴重度（需稳定状态与支持系统）

**通用停止条件**：① 解离感/现实感模糊 ② 情绪强度超出承受且持续 >30 分钟 ③ 干扰工作/睡眠/基本功能 ④ 出现自伤冲动或自杀念头 ⑤ 用户说停。

所有练习使用可逆话术：「如果你愿意，可以试试……不想试也完全没关系。」给出最小版本（降低门槛），允许随时停止。

| 练习 | 强度 | 核心步骤 | 适用 |
|------|------|---------|------|
| 梦记录 | 🟢 | 连续一周记录醒来记住的第一个梦，只记录不分析，一周后回看重复意象（最小版：只写地点/人物/感受三个词） | 有梦境回忆 |
| 阴影提取 | 🟡 | 列出最讨厌的三个人 → 各写三个受不了的特质 → 问自己在何时也表现过类似特质（先选最轻的对象） | 对他人异常强烈情绪 |
| 投射回收 | 🟡 | 选强烈迷恋/反感的人 → 写下赋予ta的品质 → 逐条问「如果这品质是我的会怎样」 | 关系中反复同类型问题 |
| 人格面具盘点 | 🟢 | 对比工作/家庭/朋友/独处中的自己：最喜欢哪个版本？哪个最累？哪个最不像我？ | 社交疲惫/角色分裂 |
| 四功能补偿 | 🟡 | 一周内刻意使用劣势功能，记录不适与意外发现（最小版：一次与平时相反的小动作） | 功能失衡/人际摩擦 |
| 中年转折自问 | 🟡 | 「现在的生活多少按自己意愿运行，多少按早年程式？」只写一个旧程式，看见它曾经保护什么、现在让我失去什么 | 程式化生活/自我脱节 |
| 象征扩充 | 🟡 | 选反复出现的意象 → 写个人联想 → 查其在神话/童话中的出现 → **不做结论，只并列** | 反复意象 |
| 主动想象 | 🔴 | 与意象对话的深度练习，仅在用户稳定且有意愿时引导，需支持系统 | 深层心理工作 |
| 现实锚定日记 | 🟢 | 记录当下具体的感官事实：此刻我看到/听到/触摸到什么 | 现代性压力、解离倾向 |
| 第三立场决策 | 🟡 | 写下两个选项 → 想象从「第三个位置」观察这个两难 → 留空等新可能浮现 | 两难决策 |

## 节奏铁律

- 不在功能低下时强行追问意义
- 不在创伤急性期做深层象征分析
- 不在现实危险中做哲学化解释
- 练习要低强度、可执行、可停止
