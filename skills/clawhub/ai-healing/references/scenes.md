# 场景路由（详细版）

## 典型场景识别

| 场景 | 用户信号 | 处理框架 |
|------|---------|---------|
| 梦与幻想 | 主动描述梦、反复出现的幻想/意象 | 确认第一联想 → 放入生活语境 → 探索补偿方向 → 必要时接入普遍母题（不给标准答案、不等同预兆、不脱离个人语境） |
| 强烈情绪/阴影 | 对某人异常强烈的情绪、反复自责羞愧 | 先共情强度 → 确认对象 → 问「ta的什么特质最让你受不了/最吸引你」→ 温和引导转向内在（别在第一次就给投射解释） |
| 人生选择/职业转折 | 在两个选择间摇摆、方向感丧失 | 不急着建议，问直觉反应 → 查补偿（你在害怕放弃的选择里忽略了什么）→ 盘点现实资源与风险 → 留空等新可能（不替用户做决定） |
| 创作阻滞/意义危机 | 创作停滞、兴趣丧失、空虚感 | 确认是暂时还是长期 → 问阻滞前在做什么 → 探索补偿（阻滞可能保护你不走向某方向）→ 象征维度（创作对你意味着什么） |
| 关系冲突 | 人际理解障碍、沟通困难 | 先确认是否存在真实伤害/权力不对等 → 排除后探索投射 → 帮助理解他人（不给他人贴标签） |
| 概念学习 | 「什么是XXX」 | 先用自己的话定义 → 给案例 → 邀请找自己的对应体验 → 标注概念局限性 |
| 现代性压力 | 信息过载、平台焦虑、AI不安、时代虚无感 | 先承认结构压力真实存在 → 不把制度问题全心理化 → 锚定现实行动 |

## 混合场景优先级（铁律）

1. **安全/危机信号 → 最高优先级**，覆盖一切
2. **现实伤害**（真实暴力/虐待/权力不对等）→ 优先现实保护，不做投射/阴影解读，不把受害者痛苦归因于ta自己
3. **功能状态下降** → 先评估功能水平，再决定是否深层探索

## 常见混合场景处理

| 混合 | 处理方式 | 禁忌 |
|------|---------|------|
| 梦 + 现实焦虑 | 先处理现实压力，再探索梦的补偿意义 | 不能跳过现实直奔解梦 |
| 关系冲突 + 阴影投射 | 先排除真实伤害，再探索投射 | 不能在有真实伤害时归因投射 |
| 职业转折 + 中年危机 | 先盘点现实资源/风险/选项，再引入个体化框架 | 不能在需要付房租时只谈自性 |
| 创作阻滞 + 抑郁风险 | 先评估功能与抑郁风险，排除临床问题后再谈意义 | 不能把临床抑郁浪漫化为创作暗夜 |
| 神秘体验 + 膨胀风险 | 确认体验心理实在性 → 检查膨胀信号 → 锚定现实 | 既不能否定体验，也不能助长膨胀 |
| 概念问题 + 个人危机 | 简短回答概念 → 转向「你问这个是因为最近遇到了什么吗」 | 不能停在纯学术而忽视情感需求 |
