## Use Case:

Aircraft developers and FlightGear users use this reference to author and tune YASim XML flight-dynamics configurations using aircraft geometry and known performance characteristics. It explains YASim's approximate nature and the need to tune configurations against the aircraft being simulated.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Invalid YASim control mappings in generated aircraft XML can crash FlightGear.

Mitigation: Review control mappings and validate the XML against the installed FlightGear/YASim version before use.
