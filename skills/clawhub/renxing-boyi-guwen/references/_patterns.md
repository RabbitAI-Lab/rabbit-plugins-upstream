# 常见人性模式识别指南

本文档按场景分类记录了常见的人际博弈模式。每种模式包含：特征、真实意图、识别方法。

---

## 一、职场模式

### 1. 画饼
**特征：** 许诺未来回报，但兑现条件模糊、时间点不断推迟
**话术示例：** "等项目成了，你肯定是核心""公司上市了你就是元老""下次晋升一定有你"
**真实意图：** 用低成本承诺换取当下的高付出，实际兑现意愿很低
**识别方法：**
- 看承诺是否有具体时间、可量化标准、书面记录
- 看TA过去对别人的承诺兑现率
- 看TA是否愿意先把部分承诺落到现在
**应对：** 不拒绝愿景，但要求阶段性的、当期的、可量化的回报

### 2. 职场PUA（打压型管理）
**特征：** 持续贬低能力、和其他人比较、让你觉得"离开这里就不行"
**话术示例：** "你这个水平去别的地方谁要？""XXX比你强多了""我骂你是为你好"
**真实意图：** 降低你的自我估值，减少你的议价能力和离职可能
**识别方法：**
- 批评是否具建设性（有改进方向）还是纯粹否定
- TA是否在人前给你留面子
- TA是否阻止你和外部接触
**应对：** 建立外部信息源（同行交流、面试），校准自己的市场价值

### 3. 捧杀
**特征：** 在公开场合过度抬高，让你下不来台或承担超负荷任务
**话术示例：** "这事只有你能做""你是我们团队最厉害的，这种难题肯定你出马"
**真实意图：** 可能是真心认可，也可能是：
- 让你接下烂摊子
- 把你架在火上烤（做成了是应该的，做不成是你不行）
- 让你成为众矢之的
**识别方法：**
- 看捧完之后接的是好事还是苦差
- 看TA对其他人是否也这样
- 看TA捧你的场合是私下还是公开
**应对：** 公开场合可以谦虚推让，但私下要确认任务边界和资源

### 4. 甩锅
**特征：** 事前含糊授权，事后撇清关系
**话术示例：** "我当时只是说可以考虑""你自己决定的""我不知道你会这么理解"
**真实意图：** 提前为自己留好后路
**识别方法：**
- TA是否避免留下书面痕迹（拒绝邮件确认、拒绝在群里说）
- TA的指示是否故意模糊
**应对：** 所有关键决策必须有书面确认，口头沟通后发"确认一下我们刚才说的……"的邮件/消息

### 5. 越级汇报 / 绕过你
**特征：** 下属/同事不经过你直接和你的上级沟通与你相关的事务
**真实意图：**
- 挑战你的权威和地位
- 为自己建立独立于你的关系网
- 邀功或告状
**识别方法：**
- 你从别人口中得知本应由你传达的信息
- 上级突然对某件事有你不知道的详细信息
**应对：** 不直接对抗，而是建立你和上级更频繁的同步机制，让越级变得没有必要

## 二、亲密关系模式

### 1. 情感勒索
**特征：** 用"爱"作为控制工具
**话术示例：** "你要是爱我，你就不会……""我为你了放弃了……你居然……"
**真实意图：** 用你的情感绑架你的选择权
**识别方法：**
- 对方的要求是否以你的"爱"或"在乎"为前提条件
- 如果你拒绝，对方是否用情感后果威胁
**应对：** 区分"爱"和"服从"——真正的爱不会以剥夺你的自由意志为前提

### 2. 冷暴力
**特征：** 用沉默、消失、冷漠作为惩罚或控制手段
**真实意图：**
- 惩罚你的"不听话"
- 让你主动妥协
- 回避面对问题本身
**识别方法：**
- 沟通被单方面中断，没有明确理由和恢复时间
- 对方在其他人面前正常，只对你冷漠
**应对：** 不追着求和（追=给他控制权），表明"等你准备好沟通时我在这里"，然后过自己的生活

### 3. 试探 / 服从性测试
**特征：** 提出各种要求，测试你会妥协到什么程度
**真实意图：** 建立关系中的主导权和边界
**识别方法：**
- 要求是否不断升级
- 你每次让步后，下次要求是否更大
**应对：** 早期的边界比后期的抗争重要100倍——第一次就该守住

### 4. 过度倾诉 / 情绪倾泻
**特征：** 把你当成情绪垃圾桶，但从不关心你的状态
**真实意图：** 单向索取情绪价值，你是"工具人"
**识别方法：**
- 你们的对话是不是一边倒
- 你需要TA的时候TA在不在
**应对：** 问自己"这段关系的情绪付出是对等的吗"

### 5. 拿你和别人比较
**特征：** 频繁提到"XXX的男/女朋友怎么怎么样"
**真实意图：**
- 打压你的自信
- 让你产生竞争焦虑
- 为自己的不满制造"外部证据"
**识别方法：**
- 比较是为了改进关系还是为了让你难受
- 比较的人是否存在（有时是虚构的）
**应对：** "如果你觉得TA更好，你可以选择TA。如果选择了我，就尊重我的方式。"

## 三、谈判博弈模式

### 1. 锚定效应
**特征：** 先抛出一个极端报价或立场
**真实意图：** 设定谈判的心理基准线，后续所有讨论都围绕这个锚点
**识别方法：** 对方的首次出价明显偏离合理区间
**应对：** 不被锚点牵着走，建立自己的基准线并先亮出

### 2. 红脸白脸
**特征：** 两个谈判者，一个强硬一个"帮忙"
**真实意图：** 通过两个角色的配合让你觉得"白脸"在帮你，从而接受本来不会接受的条款
**识别方法：** 两个角色明显配合，白脸在帮你对抗红脸
**应对：** 识别这是一个团队，不要对白脸产生感激之情

### 3. 虚假让步
**特征：** 在无关紧要的地方让步，让你觉得TA做出了牺牲
**真实意图：** 用小的、不痛不痒的让步换取你在大事上的让步
**识别方法：** 让步的事项是否对TA来说成本极低
**应对：** 每次对方让步时，问自己"这真的是让步吗？TA放弃了什么？"

### 4. 最后通牒 / 制造紧迫感
**特征：** "就今天，过了就没有了""另一个人也在谈"
**真实意图：** 剥夺你的思考时间，迫使冲动决策
**识别方法：** 紧迫感是人造的——你的退路还在不在？对方的需求急不急？
**应对：** 人为的紧迫感经不起等待，给自己留24小时（真正的好机会不会在24小时内消失）

### 5. 信息差
**特征：** 对方掌握你不知道的信息，利用这一点获取谈判优势
**真实意图：** 信息即是权力
**识别方法：** 你是否对关键信息一无所知而对方了如指掌
**应对：** 谈判前做功课，谈判中敢于问"这个数据你从哪来的？"

## 四、社交/家庭模式

### 1. 道德绑架
**特征：** 用道德标准剥夺你的选择自由
**话术示例：** "你是大的要让着小的""不喝酒就是不给我面子""过年了也不回家？"
**真实意图：** 满足TA的需求，但不尊重你的边界
**应对：** 区分"道德"和"绑架"——真正的道德从不强迫

### 2. 炫耀 / 凡尔赛
**特征：** 以抱怨的方式展示优越感
**真实意图：** 获取优越感和崇拜，同时降低"炫富"的攻击性
**识别方法：** "抱怨"的内容其实是别人求之不得的
**应对：** 不配合表演——不给崇拜也不给安慰，平淡带过

### 3. 打探隐私
**特征：** 以关心为名问不该问的问题
**真实意图：** 满足好奇心/八卦欲，或者作为日后利用的信息储备
**应对：** "还行吧""都挺好的"——模糊回答但保持友善姿态

### 4. 借势 / 蹭关系
**特征：** 过度强调"我认识XXX"
**真实意图：** 用别人的光环给自己增加分量
**识别方法：** 频繁引用"大佬朋友"但从不带你去见
**应对：** 不用拆穿，也不用因此高看TA——看他自身的价值

### 5. 被动攻击（Passive Aggressive）
**特征：** 不直接表达不满，用间接方式表达敌意
**表现：** 故意拖延、假装忘记、"开个玩笑别当真"、背后说坏话
**真实意图：** 有敌意但不敢正面冲突，或者不想背负"主动挑事"的名声
**应对：** 直接但温和地点破："我注意到XX，是不是有什么想和我说的？"
