# 场景分析指南

不同场景下，人性分析的侧重点不同。本文档提供了按场景分类的分析要点。

---

## 一、职场场景

### 分析重点排序
1. **利益格局** > 情感因素
   - 职场本质是利益交换场所，不要用情感逻辑去理解职场行为
   - 对方的友好/敌意首先从利益角度解读
2. **权力结构** > 个人性格
   - 上下级关系中，层级影响大于个性
   - 同级关系中，竞争赛道决定行为
3. **组织文化** > 个人善恶
   - 很多"坏行为"是被制度/文化激励出来的

### 特别关注信号
- 对方开始回避书面沟通 → 在为甩锅做准备
- 突然对你特别好 → 可能要让你接锅或背锅
- 开始打听你的职业规划 → 评估你的威胁/价值
- 在公开场合把你和某件难事关联 → 捧杀/甩锅铺垫
- 上级越过你和你的下属沟通 → 你在被边缘化

### 分析时必问的三个问题
1. 这件事的结果对每个人的利益（晋升/绩效/权力/安全感）有何影响？
2. 谁有动机让你成功？谁有动机让你失败？
3. 这个组织中，成功靠能力还是靠站队？

## 二、亲密关系场景

### 分析重点排序
1. **需求匹配度** > 是非对错
   - 很多关系矛盾不是"谁错了"，而是"需求不匹配"
   - TA要的是安全感，你要的是自由 = 不是谁错，是不匹配
2. **行为模式** > 单次事件
   - 不要被一次道歉/承诺感动，看长期行为是否有变化
   - 单次事件可能是偶然，重复模式就是本性
3. **投入产出比** > 口头表达
   - 看TA把时间、精力、资源分配给了谁
   - 口头说的爱和实际的投入对比

### 特别关注信号
- 让你在亲朋好友面前"解释"TA的行为 → TA知道自己做的不对但不想改
- 贬低你的社交圈 → 在孤立你，为加强控制做准备
- 频繁提前任/别人 → 在进行比较打压
- 不愿意确立关系边界/公开关系 → 在给自己留退路/备选
- 你表达需求时TA的反应 → 这是TA在乎你的试金石

### 分析时必问的三个问题
1. 这段关系让你变得更好还是更焦虑？
2. 如果没有"沉没成本"，你现在还会选择和TA在一起吗？
3. 你投入的和得到的是否大致平衡？

## 三、商业谈判场景

### 分析重点排序
1. **BATNA（最佳替代方案）** > 坚持程度
   - 谁有更好的备选方案，谁就有更大的权力
   - 谈判中表现出来的强硬是策略，真正的底线是"不谈了会怎样"
2. **信息不对称** > 表面立场
   - 哪一方掌握更多关键信息（成本、底线、时间压力、竞争情况）
3. **决策权** > 谈判权
   - 和你谈的人有没有最终决策权？
   - 如果只是代理人，TA的个人利益可能和公司利益不一致

### 特别关注信号
- 对方不经意透露"别人报价更低" → 施压手段，不一定有这个人
- 对方急着催你签 → 有隐藏的时间压力（预算是限时的、急需你的资源）
- 对方突然变得冷漠 → 可能是策略性冷淡，也可能是有了备选
- 对方说"我得请示一下" → 可能是真请示，也可能是给你施压
- 对方对你表现出个人层面的欣赏 → 可能是建立关系获得谈判优势

### 分析时必问的三个问题
1. 如果今天不成交，谁会损失更大？
2. 对方有什么我不知道的信息？
3. 对方的话里有多少是立场（position），多少是真实需求（interest）？

## 四、社交/家庭场景

### 分析重点排序
1. **关系定位** > 具体内容
   - 对方把你定位成什么角色（工具人/倾诉对象/攀比对象/同盟）
   - 这个角色定位决定了TA对你的行为模式
2. **面子逻辑** > 实质内容
   - 在中国社交中，"给面子"和"伤和气"比事情本身的对错更重要
   - 很多拒绝和不满不会直接表达，而是通过冷淡、回避来传达
3. **关系历史** > 当下场景
   - 一次性事件可能只是误会，重复模式才是关系本质

### 特别关注信号
- 许久不联系突然出现 → 大概率有事相求
- 频繁在朋友圈"互动"但私下不聊天 → 在维护社交存在感，不是真关心你
- 当着别人面一个态度，私下另一个态度 → 至少有一个态度是假的
- 每次见面都抱怨同一个问题但从不解决 → 需要的不是解决方案而是情绪出口

### 分析时必问的三个问题
1. 如果没有任何利益关系，TA还会这样对我吗？
2. 这段关系是滋养我还是消耗我？
3. TA把我当"人"还是当"工具"？

## 五、跨场景通用分析原则

### 原则1：言行不一致 = 有隐藏信息
人撒谎很难持续，但隐藏信息很容易。当言行不一时，一定有没说出来的东西。

### 原则2：反常即为妖
- 一个人突然对你特别好/冷淡 → 有变故
- 平时话多的人突然沉默 → 在回避/不满
- 平时沉默的人突然话多 → 有诉求/在铺垫

### 原则3：看基线，不看峰值
- 不要被偶尔的示好/示弱迷惑
- 看对方行为的基本面——长期保持的才是真实

### 原则4：每个信号都要放在大图景里看
- 孤立的一个行为可能有多种解释
- 多个信号指向同一方向，可信度就大幅上升

### 原则5：不要替对方合理化
- "他可能太忙了""她其实不是那个意思"
- 你自动替对方找借口的频率，等于你被忽视的程度
- 用事实和行为做判断，不要用"善意的想象"
