# 实验假设模板与判定标准写法

下一轮给 3 个可验证的实验。每个实验必须能回答「怎么知道它成没成」。不可验证的方向（如「优化体验」）不算实验。

## 一、单个实验的必备字段

| 字段 | 说明 | 常见错误 |
|---|---|---|
| 假设 | 一句话可证伪的陈述：「如果做 X，则 Y 会提升」 | 写成方向「多投流」不可验证 |
| 怎么验证 | 只改一个变量，其余保持不变（控制变量） | 同时改文案+人群+时段，无法归因 |
| 衡量指标 | 具体可量的指标：转化率、加群率、单粉成本 | 「效果好」「反响好」不可量 |
| 判定标准 | 什么结果说明假设成立：如「转化率从 2% 到 3% 及以上，且持续 3 天」 | 「有提升就行」无门槛 |
| 资源与风险 | 需要的预算/人力/时长，以及可能踩的坑 | 不写成本与风险 |

## 二、好的假设示例

```
假设：把落地页首屏从「功能罗列」改成「用户痛点+解决方案」，注册转化率会提升
怎么验证：同一投放计划、同一人群，A/B 各 50% 流量，跑 7 天
衡量指标：注册转化率（注册数/落地页访问数）
判定标准：实验组转化率 ≥ 对照组 1.2 倍，且统计上稳定 3 天，视为成立
资源与风险：需设计 1 版新首页（约 2 人日）；风险：样本量不足导致不显著
```

## 三、差的假设（返工）

```
假设：下次优化一下体验  ← 不可证伪，无变量
验证：随便调调  ← 无控制变量
指标：用户满意  ← 不可量
判定：有改善就行  ← 无门槛
```

## 四、判定标准写法要点

1. 必须有数字门槛（绝对提升或相对倍数）
2. 必须说明观察周期（避免拿单日波动当结论）
3. 必须说明显著性要求（如「连续 N 天」「样本量 ≥ N」）
4. 不成立时怎么办也要提一句（如「未达门槛则回滚并保持对照组方案」）

## 五、三个实验的关系

- 三个实验应覆盖不同杠杆（渠道 / 创意 / 转化路径），不要三个都测同一件事
- 资源有限时按「性价比」排优先级，标明先做哪个
- 每个实验独立可验证，不互相依赖才能同时跑
