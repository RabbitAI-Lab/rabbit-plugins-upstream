## 2.1.38 — 2026-08-29（奖金分档正确性 + 排程休眠根治）

- **修复：固定奖奖金虚高 20%~40%（正确性）**。`PRIZE_PAYOUT` 曾把"奖池≥8 亿上调档"金额写死为常态值，导致奖池<8 亿期次的中奖金额与回测 ROI 被系统性高估。改为双档表 `PRIZE_PAYOUT_BASE` / `PRIZE_PAYOUT_BOOSTED`，新增 `set_pool_mode()` / `prize_table()` / `pool_mode_label()`，默认保底档（保守口径）。

- **修复：档位标注自相矛盾**（曾输出 `5元(奖池≥8亿)`）。标注现与金额同源动态生成。
- **数据**：历史补至 26097（2915 期）；26097 期验证记录用真实预测 JSON + 真实开奖号诚实回填（第5组熵均衡 七等奖 1 注）。
- **验证**：24 项护栏 22/22 正确性全通过、三方交叉验证 51/51、AST 未定义名 0；包 69 文件 671KB。
- 诚实框架不变：任一组合一等奖概率恒 1/21,425,712，任何方法数学上不优于随机，长期玩必亏。
