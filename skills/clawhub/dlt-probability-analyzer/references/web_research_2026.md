- 奖级由 9 个合并为 **7 个**（一/二等奖=浮动奖；三~七奖=固定奖）。
- 奖池 ≥ 8 亿元时固定奖自动上调：三 6666 / 四 380 / 五 200 / 六 18 / 七 7（较 <8 亿档 5000/300/150/15/5 上调 20%~40%）。
- 返奖率由 50% 提升至 **51%**。
- 一/二等奖单期奖金总额（含追加）**各封顶 1 亿元**；单注一等奖基本 1000 万 / 追加 1800 万。

## 3. 「专家推荐」与「分析」的真相 —— 官方反诈口径（关键）

全网检索到的"彩票大师 / 精准预测 / 内部号码"**全部是诈骗**，以下为官方/权威来源核实：

- **绍兴体彩**（今日头条 2025-05-15）：陈女士被"内部人员"诱饵骗 10 万元；套路 = 发布诱饵 → 下载虚假 APP → 小额返利 → 阻止提现拉黑。体彩提醒：国家禁止互联网售彩，中奖完全随机、无法预测。
- **紫牛新闻**：两起真实案例（天津 7 万、重庆 4500 元被骗）；常见套路 4 步：诱饵引流 → 虚假场景 → 小额返利 → 大额转账拉黑。
- **金凤检察**（2026-07-29）："彩票大师"5 步诈骗剧本；防骗三句："完全随机、无内部消息、不点陌生链接不下载非官方 APP"。
- **中国体育彩票订阅号 / 扬州市辟谣平台**：凡收"荐彩费/会员费"均非法；合法渠道仅线下实体店。

**识别红线（已写进 skill 反诈闸门）：**

1. 任何"包中 / 不中包赔 / 内部数据 / 准确率 90%" = 诈骗话术。
2. 凡要求转账、充值做任务、缴"解冻金/保证金" = 诈骗。
3. 凡通过社交 / 短视频 / APP 售彩 = 非法（国家禁网售）。
4. "多买多中提高概率""稳赚不赔" = 谣言（吉林体彩"谣言粉碎机"已点名）。

**结论**：所谓"专家分析"若指向具体号码并收费 = 割韭菜；真正有价值的"专家/分析"是官方责任彩票科普与反诈教育（见 §4）。

## 4. 2026 责任彩票官方口径（"安心购彩守护行动"）

- 国家体彩中心 2026 全面启动"安心购彩守护行动"，理念：公益、健康、娱乐；倡导"多人少买、量力而行、理性购彩"。
- 购彩本质 = 娱乐非赚钱工具；理性看待概率、淡化结果。
- 防沉迷：设定预算、用闲置资金、不借贷不倍投；适度参与不影响生活工作。
- 未成年人保护：严禁向未成年人售彩/兑奖（红线）。
- 公益属性：每笔投注注入公益金（全民健身/奥运/民生）；"来之于民、用之于民"。
- 权益保护：20+ 省落地非法彩票有奖举报；购彩风格自测工具；16 省联动心理疏导。
