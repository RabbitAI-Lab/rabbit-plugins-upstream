大乐透概率分析器 · 使用指南（普通用户看这一篇就够了）
====================================================

【一句话】
这是一个「娱乐性参考组合 + 诚实分析报告」工具，不不实中奖许诺。
数学上任何选号法都不优于随机，长期玩必亏——请量力而行、理性娱乐。

【你只需要记住一条命令】
    在 scripts/ 目录下，打开命令行，运行：
        python run_dlt.py

    它会自动完成：联网取数 → 预测 → 22 项自检 → 生成报告。
    报告会复制到你的桌面（双击用浏览器打开即可），并提示预览路径。

【为什么会看到很多文件？】
    scripts/ 顶层只有 4 样东西你可能会用到：
        run_dlt.py        ← 唯一入口，你只运行它
        使用指南.txt      ← 就是本文件
        README.md         ← 更完整说明
        注册看门狗.bat     ←（Windows）一键把自动检查注册成系统任务
    其余所有文件都在 scripts/lib/ 里，是工具内部模块和数据，
    你完全不需要碰它们。想知道某个文件干嘛，见 references/scripts.md。

【离线 / 没网怎么办】
        python run_dlt.py --skip-download
    会用工具自带的离线数据跑，照常出报告（报告里会注明「本次未取到最新数据」）。

【想自己体检一下系统健不健康？】
        python run_dlt.py --healthcheck
    看到「退出码 0 / 全绿」就是一切正常。

【遇到问题】
    先看 references/faq.md（常见问题集中页，语气友好）。
    仍未解决，把运行时的提示文字发给我即可。

再次提醒：本工具仅供娱乐参考，绝不暗示「不实保中承诺 / 不实获利承诺 / 有正收益可能」。
