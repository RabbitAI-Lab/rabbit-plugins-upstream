# 大乐透一站看 · 专家观点 + 娱乐选号 + 开奖核对（免费 · 不卖号 · 讲真话）

> 大乐透一站看：全网专家观点汇总 + 娱乐选号 + 开奖即时核对中奖 + 胆拖帮你算省钱；免费、不卖号、不忽悠，把"为什么中不了"讲明白。

## 🚀 30 秒上手（唯一需要记住的一条命令）

```bash
python run_dlt.py
```

它会自动：联网取数 → 预测 → 跑 22 项自检护栏 → 把报告复制到你的桌面（双击浏览器打开）。

- 断网/离线跑：`python run_dlt.py --skip-download`
- 看"为什么彩票是不可预测的"：`python run_dlt.py --randomness`
- 系统体检（22 项护栏）：`python run_dlt.py --healthcheck`

想要一期娱乐组合、或核对某期开奖中没中？**直接用自然语言跟调用本 skill 的 AI 说**"给我这期大乐透的娱乐组合""帮我核对开奖中没中"，模型会直接出报告并预览——不用自己敲命令。

## 这是什么

一个**站在彩民这边**的大乐透分析 skill：

- **全网专家观点一站看**：聚合多渠道分析师的当期观点与推荐号（带来源，可核对）。
- **娱乐选号**：基于频率/冷热/历史的娱乐性组合生成，明确标注"不保证结果"。
- **开奖即时核对中奖**：展开推荐注、逐注算奖、对照随机基线，把"没中"变成诚实实证。
- **胆拖省钱计算**：算"这样买省 X 元、覆盖多少组合"，优化投入结构。
- **诚实打假**：用真实数据把"奇偶/和值/跨度/连号/AI预测"等套路逐一证伪。

## 诚实铁律（必读）

本 skill 产出的是**娱乐性分析报告，不承诺中奖**：

1. 大乐透红球近似完全随机，任一组合中一等奖概率恒为 **1/21,425,712**，热号/冷号/胆码无任何概率梯度。
2. 所有选号思路样本外一等奖命中 = 0，数学上任何方法都不优于随机；长期玩期望为负，请量力而行。
3. 胆拖不提高单注中奖概率，只优化投入结构。

**禁止**暗示"可确保的中奖结果"或"有正收益"。本工具不是收益工具，是帮你花得明白、防得住坑、玩得理性的伙伴。

## 使用场景

| 你的目的 | 该用哪个入口 |

| 看看这期系统推荐的娱乐组合（纯玩） | `python run_dlt.py` |

## 信任凭证

- **52/52 三方交叉验证** + **22 项永久自检护栏**（EXIT=0 才允许交付）。
- **纯本地运行**：仅依赖 Python3 标准库，无第三方包、无运行时代理、无数据外传、可完全离线。
- **三源容错**：联网优先取国内数据源，失败自动回退本地历史库并明确告知"仅供参考"。
- **跨平台一致**：Windows / macOS / Linux 均可，`run_dlt.py` 单一命令出完整报告。
