## Description:

Summarize long text into concise bullet points using an LLM.

This skill is ready for commercial/non-commercial use.

## Publisher:

[terrycarter1985](https://clawhub.ai/user/terrycarter1985)

### License/Terms of Use:

MIT-0

## Use Case:

External users and agents use this skill to turn lengthy plain text, documents, or pasted articles into a concise TL;DR and 3-5 key bullet points while preserving important names, dates, and figures.

### Deployment Geography for Use:

Global
