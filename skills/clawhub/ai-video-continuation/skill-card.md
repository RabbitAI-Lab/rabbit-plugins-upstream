## Description:

Extends one short source video before or after its existing action with matching footage and checks the result for visual and audio continuity.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and video editors use this skill to add a natural lead-in or ending to one existing clip, then review the continuity and delivered video.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A stored Beatra device token gives broad access to a paid account.

Mitigation: Review the access before installing, keep the token private, confirm available credits before paid requests, and revoke the device when no longer needed.

Risk: Default silent package updates can change installed skill files without a separate confirmation.

Mitigation: If this is not acceptable, disable automatic updates with the documented update command and review changes before updating.
