# 秋招简历测评 · 梗库与评分维度

写测评数据时的风格基准。核心原则:**搞笑但不伤人、吐槽必须落到简历真实问题上、
每条吐槽配一条能用的建议**。这是用户自己的简历,图还要发出去——自嘲可以狠,
嘲讽本人不行。

## 评分维度(满分 100)

| 维度 | 权重 | 看什么 |
|---|---|---|
| 排版与基本信息 | 10 | 一页?信息完整?错别字?联系方式漏了? |
| 教育背景 | 15 | 学校层次 vs 投递目标、GPA、奖学金、课程相关度 |
| 实习经历 | 25 | 有几段、干了什么、有没有数据、时长真实性 |
| 项目经历 | 25 | 技术含量、完成度、有没有可验证的产出、是否"编的" |
| 技能证书 | 15 | "精通"含量、证书含金量、和岗位匹配度 |
| 亮点与差异化 | 10 | 有没有任何让面试官记住的东西 |

等级线:A(90+) 满分卷 / B(75-89) 稳健 / C(60-74) 挣扎 / D(45-59) 人才库候补 /
E(<45) 已读不回。

## 面板数据要点(render_stand.py 输入)

- **stand_name(替身名,≤8字)**:给简历起毒舌替身名,是整张图的灵魂。
  参考:「泡池子之主」「已读不回使者」「人才库守卫」「offer 收割机」「面试官镇住机」
- **verdict(判词,≤10字)**:等级判词,如「满分卷 · 面试官镇住机」「挣扎区 · 泡面没调料包」
- **ability(替身能力,≤50字)**:JOJO 风格的「替身能力:『XX』——……」,前半毒舌梗,
  后半必须带一条可执行建议(如「弱点:怕十五分钟追问」→ 建议先去把每个热词过一遍嘴)
- **dimensions**:6 维固定顺序(排版/教育/实习/项目/技能/亮点),score/max 按评分表

## 梗库(按用途取用,不要硬塞)

### 状态梗
- 已读不回 / 泡池子 / 进人才库 / 石沉大海 / 海投 500 份
- 大小周 / 996 / 弹性工作(指弹性加班) / 35 岁危机 / 优化

### 简历内容梗
- 「精通 Office」= 会用 Word 打字;"熟练 Python" = print("hello world")
- GPA 3.2 写第一行 = 忏悔录;绩点不高但自信 = 「简历没有水分,全是空气」
- 实习三个月 = 打印三个月 / 端茶倒水三个月;「负责公众号运营」= 排版了 3 篇推送
- 「独立开发」= 一个人(改了别人的 README);「参与开发」= 看了两行代码
- 「学生会主席」= 组织过一次团建;「获得参与奖」= 去了就有
- 英语四级 425 = 压线过 = 英语水平(指 26 个字母都认识)
- 「自我评价:学习能力强」= 全部简历通用的一句话,等于没写

### 面试官 OS 体(用在 ability 判词里)
- 「这简历我看完了,我沉默了 30 秒,不是震撼,是不知道从哪吐槽起。」
- 「写的挺多,就是没有一个字和岗位有关系。」
- 「'抗压能力强'——指被挂了 200 次还没删掉招聘软件。」

### 抽象话(适量点缀)
- 绷不住了 / 难绷 / 典中典 / 6 / 这波啊 / 乐 / AUV

### 安全红线
- 不指名道姓骂具体公司(用「某大厂」「某厂」);不做人身攻击(长相、家境、学校歧视
  要克制——学校梗只玩「双非冲大厂」的普遍焦虑,不嘲笑具体学校)
- 不出现真实姓名/手机/邮箱/身份证号/具体公司名(发出去的图必须匿名化)
- 玩笑归玩笑,ability 判词必须带一条真实、可执行的修改建议,结尾落在鼓励上

## 语言风格

- 短句、口语化、像人话,像「毒舌学长」不是「AI 文案」
- 数字要说人话:「投了 200 份简历,已读 3 份」>「海投简历」
- 面板空间有限:stand_name ≤8 字、verdict ≤10 字、ability ≤50 字
