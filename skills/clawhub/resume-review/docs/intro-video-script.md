## 连续口播版

最近酥神的简历不是火了吗?我第一反应不是学他怎么写,而是想知道:这份简历到底能打几分。

所以我做了一个 skill,叫「简历评测」。

你丢进去一份 PDF 或 Word,它先把个人信息匿名掉,再从六个维度开始测:排版、教育、实习、项目、技能,还有简历里真正能让人记住的亮点。

但它不会给你甩一大段 AI 套话。最后直接生成一张漫画能力参数图。

简历有多离谱,替身名就有多离谱。比如酥神这份,替身叫「包装之神」,评级 A,一百分。

重点也不是单纯骂人。每个分数都得从简历原文里找依据,吐槽完还要给一条能落地的修改建议。

它不绑定某个 AI 工具。支持 skill 的 agent 可以直接装;不用 agent,提示词加脚本也能跑。

项目已经开源。把你的简历交给它,看看你的替身到底叫什么。

## 拍摄与剪辑备注

- 前 3 秒直接露出成图和大号 A,不要先自我介绍。
- 演示简历必须用公开示例或虚构内容;姓名、电话、邮箱全部打码。
- 六维雷达图建议按顺时针逐项点亮,每项配一个短促音效。
- 「一大段 AI 套话」只闪 0.5 秒,不要让观众读内容。
- 「包装之神」出现时停顿半秒,再切 A 和 100,笑点会更清楚。
- GitHub 地址至少保留 3 秒,同时放在评论区或视频简介里。
- 不要使用受版权保护的 JOJO 动画画面、角色图或配乐。成片只展示自制漫画参数面板。
