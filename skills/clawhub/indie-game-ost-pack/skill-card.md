## Description:

Build an original indie game OST pack of 8 to 15 instrumental tracks for title, explore, battle, shop, and victory. This game soundtrack studio and game BGM generator writes loop-friendly game music you own and can use commercially, then delivers a labeled soundtrack you can audition in-engine. Use it as a game music pack for indie game OST, game background music, game BGM, battle music, explore music, shop music, and original game soundtrack work.

This skill is ready for commercial/non-commercial use.

Indie game developers use this skill to plan, generate, and review a labeled set of original instrumental music beds for menus, exploration, battles, shops, and other in-game moments.

## Known Risks and Mitigations:

Risk: Authorization covers media generation, voice changes, and shared Beatra credit spending beyond music creation; no music-only grant is available.

Mitigation: Review the requested access and approve the total soundtrack budget before installation and paid generation.

Risk: Installation registration sends recurring analytics without an opt-out.

Mitigation: Review the documented registration data and privacy expectations before authorizing the skill.

Risk: The security assessment reports a weakness in removal safeguards.

Mitigation: Check other installed Beatra skills before removal and use Beatra Console to revoke shared access when needed.
