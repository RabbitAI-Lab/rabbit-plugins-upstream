## Description:

Build a labeled pack of 8 to 15 original, loop-friendly instrumental tracks for an indie game's title, exploration, battle, shop, and victory scenes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Indie game developers and studios use the skill to plan and generate an original soundtrack pack, with labeled tracks for common game scenes and loop-friendly arrangements for in-engine audition.

### Deployment Geography for Use:

Global
