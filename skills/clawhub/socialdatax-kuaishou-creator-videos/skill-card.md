### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Running the latest unpinned npm package locally exposes the SocialDataX API key to that package.

Mitigation: Prefer a pinned, reviewed package version or an already configured MCP tool; run the package only if comfortable granting it access to the API key.
