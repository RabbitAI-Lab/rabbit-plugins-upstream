# Skill Factory

Universal engineering workflow for creating production-ready Agent Skills.

## What it does

Skill Factory helps design, build, evaluate, improve, and prepare Agent Skills for publication.

It automatically chooses between:

- a single skill;
- a skill with references;
- a skill with scripts;
- a router with 2–6 variants;
- a multi-skill family.

The router architecture is retained as a specialized option rather than being the default.

## Intended use

Use it when creating or improving reusable Agent Skills, especially skills intended for public distribution.

## Package contents

- `SKILL.md` — executable factory workflow.
- `references/skill-mechanics.md` — design rationale and review guidance.
