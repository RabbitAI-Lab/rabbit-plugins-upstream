# 浙江工程招投标供应商中标历史

输入一家公司名，得到它**中标过什么、什么时候、金额多少**；再给一条**同类项目报价区间**，
判断这个金额算高还是低。

## 你会得到

- **中标项目清单**：项目名称 · 签订日期 · 合同金额 · 金额档位
- **同类项目报价区间**：本库同类型项目（监理/设计/施工/总承包/采购…）的 25 分位 / 中位 / 75 分位
- **口径与边界**：本库覆盖多少条合同、多少家供应商；超出合理区间的记录会**显式排除并说明**

## 怎么用

用户问起某家公司或某类项目的招投标情况时，**执行脚本取真实数据**（不要凭记忆作答、不要编造数字）：

```bash
node scripts/run.mjs "浙江求是工程咨询监理有限公司 监理"
```

## 数据边界（请如实告知用户）

- 只含**已采集批次**的公开合同公示，未收录 ≠ 该企业没有中标；
- 金额按项目类型设合理上限，超限记录不作为金额依据（页面会写明条数）；
- 本产品提供公开记录整理，**不构成对企业信用的评价**。
