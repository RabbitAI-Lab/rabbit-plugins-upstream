## Description:

Turn QA-approved content into a CMS draft, document, static-site file or manual handoff package, with permission checks, validation and readback. Use for "publish this to WordPress", "create a Webflow draft", "add this post to my blog repo", "prepare this for my CMS", "format this for Ghost".

This skill is ready for commercial/non-commercial use.

## Use Case:

Content teams and site developers use this skill to move QA-approved content into a CMS or static-site repository, preserve requested fields and publishing state, verify the result, or prepare a manual publishing package when direct access is unavailable.
