## Description:

cosprompt is a structured AI image-prompt generator that researches a requested character or topic, analyzes visual traits, selects a style, and produces 17-dimension prompts for tools such as Midjourney and Stable Diffusion.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External users and creators use this skill to turn a character, product, or scene idea into structured image-generation prompts. It is especially suited for character posters, cosplay posters, ecommerce posters, and character concept art workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may use web browsing to research a requested character or topic, so source material can be incomplete, outdated, or inaccurate.

Mitigation: Review the researched character or topic facts before reusing the generated prompt in a public or commercial workflow.

Risk: Generated prompts for existing characters or cosplay concepts can raise copyright, likeness, or age-appropriateness concerns.

Mitigation: Check generated prompts for rights clearance, age-appropriate framing, and platform policy fit before image generation or publication.

Risk: The declared tool permissions are broader than strictly necessary for plain prompt writing.

Mitigation: Install and run the skill only in a controlled agent environment with the minimum tool access needed for the intended task.
