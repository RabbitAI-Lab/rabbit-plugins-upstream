# 每层40m²小复式北欧极简，一个人住太美了

业主为单身女性，买此房的原因，就是为了上班能近一点，近到中午休息可以顺便回家睡觉。风格方面北欧极简，满足一人居住，同时满足偶尔来个亲朋好友可以居住，同时家里还有几只猫。

▲一楼满足一日三餐吃喝拉撒，没事撸撸猫的惬意空间。本身就是公寓型空间，所以厨房只能占用过道上设计，基本很少做饭。偶尔为之完全满足。为了空间更开放式和合理，一楼的卫生间做了三分离处理，空间虽小但是这样的功能非常完美。同时为了收纳需求，电视墙整体收纳柜满足一楼的所有储物。
▲二楼就是两间卧室而已，为了尽可能通透，只保留一间卧室的私密型，另一间卧室和楼梯平台开放式设计，平时作为休闲区，偶尔来人拉上帘子就可以满足单独卧室的需求。
▲进门过道很窄，而且进门就是开放式厨房，为了避免磕碰和满足收纳，橱柜做了斜面处理，同时左手的鞋柜同样斜面处理，满足进门的通道宽敞。白色与木色进门就是清新之风。为了避免进门非常压抑，把原来左手卫生间做了三分离布置，这样过道还能宽敞一点，同时缩小一部分卫生间面积，满足橱柜对面冰箱的放置
▲门厅的视角，因为进门口几乎没有自然光，所以头顶筒灯满足基本光线，同时把吊柜的手扫灯配置成了感应灯，平时只要人经过自动亮起，来改变门口的光线问题
▲一字橱柜满足洗切炒的功能，木色与白色对比色避免视觉的压抑。水槽上方极简挂杆收纳，拿取方便还能保证空间的整洁
▲进门左手的卫生间是非常意外的，长条形的格局，刚好满足三分离的处理，这样即使三人同时使用卫生间都能满足。黑色窄边框网红门搭配，视觉上小空间不仅有质感，而且干净简洁
▲打开门的状态，左手马桶区，右手淋浴区。直对的干区空间进深不够，采用半镶嵌的陶瓷盆满足功能
▲过道进来就是客厅以及楼梯空间，电视墙整体收纳柜储物，同时满足了几只猫的休息之所
▲客厅全景，为了收纳同时给几只猫有个住所，电视墙统一收纳柜定制，旁边做了很小的猫窝满足宠物的休息。木质的楼梯采用钢化玻璃扶手搭配，空间通透明亮
▲原来的落地窗做了假飘窗收纳，同时还能满足休闲功能，侧向借用收纳柜木色套色镂空，满足书籍的放置，平时坐飘窗休闲随手拿书非常方便
▲收纳柜里头还隐藏了洗衣机和烘干机的放置，局部隔板用来收纳各种清洁用品，下水是借用厨房水槽的下水，管路隐藏在收纳柜
▲休闲飘窗柜可以兼顾卡座功能，放上小圆桌，同时兼顾书桌和餐桌两种功能。头顶局部吊顶采用钢化玻璃创意布置，视觉通透，同时还能满足一部分采光需求
▲头顶局部的钢化玻璃吊顶，一是解决层高太低的不足，二来可以给客厅增加创意元素
▲楼梯空间，整体原木定制，台阶隐藏灯带，同时搭配透明的钢化玻璃扶手，视觉通透现代感极强
▲楼梯间，为了小空间楼梯能放大空间，楼上卧室新开了一个玻璃橱窗，一是为了几只猫可以尽情玩耍，二是让楼梯间保持空间的通透开放
▲楼梯上来的平台以及卧室里头统一定制高柜收纳，靠近楼梯口以及卧室门口局部镂空套色展示柜，可以让空间更生动，视觉更灵动
▲分割的单独卧室并不大，统一定制的地台床以及木质的护墙板，极简黑色吊灯，床头柜采用极简隔板代替，视觉更简练
▲卧室与楼梯间新开窗户，采用电子雾化玻璃分割，视觉更通透，也成了猫的乐园
▲通电以后的雾化玻璃随时可以保证隐私空间
▲打开卧室门，卧室与外面休闲空间光线互补，视觉通透
▲楼梯上来外面的空间统一休闲布置，靠窗户榻榻米地台休闲区，侧墙简单的书桌书架，平时可以作为单独的书房使用
▲加上投影，放上可以折叠的床垫兼顾沙发的坐垫，平时这里也可以作为影视厅
▲轻松实现影视厅的功能
▲拉伸布帘，楼梯的开放式空间即可成为一个完美的影视厅空间，同时偶尔亲朋好友光临，这里随时可以变为一间独立卧室
