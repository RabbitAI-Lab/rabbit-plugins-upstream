# 65㎡二手LOFT改造，两人居也能舒适温馨

因为是二手房，而且是顶楼LOFT，楼顶是斜顶没有窗户和采光，几乎没有什么功能化使用，空间显得压抑浪费。
▲没有拆除之前的样子，原房东把楼梯直接安排到了客厅中间，导致公共区域非常拥挤，一楼最大的空间几乎全部浪费，而且过去装修比较简陋，二楼没有采光还是斜顶，除过储物几乎一无是处，二楼成了完全的仓库，而且导致一楼非常压抑。▲原始结构一二楼图纸。存在的问题：1.楼梯在客厅，占用了一楼最大空间的很大部分，显得空间凌乱而且压抑2.进门是厅，客餐厅一体，空间几乎无法容纳餐厅空间3.一楼卧室门影响，导致门口收纳很难布局4.二楼是一面斜顶没有任何窗户采光，完全封闭以后，空间压抑昏暗，无法做正常的功能布局，只能做储物，空间浪费
▲设计最终的布局图。改造如下：1.把一楼的楼梯改变位置，利用一楼卧室一部分满足楼梯的重新布局，同时二楼楼梯休息平台与斜面空间共用，满足二楼空间的通畅2.客厅局部做了挑空设计，因为二楼是一面斜顶，即使封闭也无法正常站立，而且没有光线，空间本身用途不大，不如直接客厅做挑空，满足一楼空间的整体放大3.改变楼梯以后卧室门得以移动，刚好门口实现了入门的收纳布局4.利用原有厨房门洞做了开放式布局，同时利用厨房门口吧台设计，满足基本的就餐功能5.挑空以后二楼空间开放不压抑，同时利用楼道满足洗烘机的布局，刚好满足生活所需，其他空间满足家里杂物的收纳，这样一楼就可以布局更加合理实用
▲移动一楼卧室门以后，利用卧室一部分做了楼梯，进门左手刚好实现了进门的超级收纳▲全景空间，一楼空间并不大，右手是唯一一间卧室以及楼梯位置，客厅餐厅厨房一体开放布局；客厅与二楼挑空布局，可以让空间更通透，二楼过道玻璃扶手设计，过道满足洗烘机的布局▲原有厨房开放设计，利用门洞位置吧台布局，刚好满足平时的就餐，而且吧台与电视满墙柜一体延伸，空间更完整统一▲电视墙整体满墙柜收纳，镶嵌电视布局，去掉茶几，空间更显宽敞；左边玻璃门是唯一的卫生间空间▲客厅全景，简单布艺灰色沙发布局，本身跨度就小所以茶几舍弃，空间能更显宽敞一点▲开放厨房满足U型布局，满足冰箱布局，吧台兼顾就餐，白色与木色整体视觉依然清新▲柔光砖通铺厨房，放大小空间，白色吊柜下方手扫灯布局满足夜晚烹饪操作▲楼上俯视客厅，非常简单，大面积浅色放大视觉空间▲这个角度可以看到楼上过道的洗烘机布局，以及卧室门口的楼梯设计▲利用卧室空间满足楼梯的布局，黑色的与木色踏板结合，视觉上更有层次，刚好利用楼梯墙面满足全身镜的布局▲唯一的一楼卧室采用地台床设计，无主灯的布局，视觉空间更简单温馨▲侧墙满足一个小的衣帽间收纳，玻璃门与入门玻璃门统一色调▲楼上利用过道区域实现了洗烘机的镶嵌，同时收纳柜满足杂物收纳，对面的储藏室玻璃门布局，里头放一些不常用的物品▲楼梯上来的休息平台看过道的家政区▲过道家政区看楼上休息平台，因为是一面斜顶，休息平台与斜顶空间开放布局，可以作为多功能区▲楼梯采用黑色壁灯满足照明，同时又与黑色玻璃扶手呼应协调▲卫生间长条形，整体素雅的奶油色设计，中间浴柜，左右分别是马桶区以及淋浴房▲左边墙排马桶区，小窗户满足采光和通风▲浴柜右边玻璃隔离一个单独的淋浴区，满足基本功能▲马桶区看卫生间全景，整体素雅简洁
