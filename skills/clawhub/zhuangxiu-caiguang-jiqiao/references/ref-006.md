# 阳台放弃整墙吊柜，改用侧面晾衣，瞬间通透高级，告别乱糟糟！

大部分生活阳台因为有洗衣机，都会选择上方吊柜的做法，但是有的户型因为窗户或者管道的原因，无法做满墙吊柜，好多人就放弃做吊柜，浪费了空间。但其实完全可以采用局部吊柜或者侧面的形式，满足收纳，同时拓展收纳和提升颜值。01.局部吊柜做法实现收纳。好多人不是不需要吊柜，而是无法做满墙柜，不知道怎么实现局部吊柜，看看这些局部吊柜的做法，可以满足收纳，同时也不影响整体颜值。网友@猴头菇：因为洗衣机上方有窗户，刚好利用实墙和管道位置满足局部吊柜，增加收纳，也不会影响到窗户开启和采光。网友@国台酒：窗户影响吊柜，刚好采用局部定制，满足局部吊柜，可以满足一些杂物的收纳，唯一缺憾就是没有吊顶太高了，使用不便。网友@月影：洗衣机上方有窗户，上方为了多收纳，采用高柜落到台面的形式，满足一个收纳柜，可以容纳更多收纳，也不影响窗户的采光。网友@上房揭瓦：背后有窗户，只有右侧有局部空间，刚好利用起来实现一个侧面的收纳柜，满足收纳，拓展功能网友@东厂西厂：有窗户为了不影响采光，做了局部吊柜满足收纳，不影响功和光线。有窗户影响做了局部的吊柜收纳，下方开放可以满足随手置物。有窗户利用旁边做了局部吊柜，满足一部分收纳如果无法做满墙吊柜的话，任何方法都可以实现局部吊柜的收纳。有窗户没有办法做吊柜，利用管道位置做了侧面吊柜满足一部分杂物收纳，上方刚好满足侧装晾衣架，解决直对客厅晾衣凌乱的问题。利用管道前面空间，实现一个侧面的收纳柜，刚好满足一些常用洗涤用品收纳，因为是侧面开放，视觉上也不会太凌乱。02.放弃吊柜成就其他功能。网友@菠萝：一是有窗户怕影响采光，第二担心吊柜压抑，所以干脆不做吊柜，采用网购两个隔板装饰一下墙面，效果还挺好网友@纯粹咖啡：有窗户吊柜不好做，又想着能解决晾小件衣物的功能，干脆就装个晾衣杆，其实也挺好为日常琐碎且必须的晾衣功能，舍弃吊柜，上方隐藏式衣架（单杆1m）安排在洗衣台盆正上方，从客厅看它是隐藏在短墙后面，晾衣时完全不影响视觉观感。正下方洗烘机，上方本身有窗户也没法做吊柜，装个晾衣杆，刚好实现侧面晾衣服，同时窗帘遮挡，平时也看不到凌乱不要那么多收纳，舍弃吊柜，两个隔板代替花架，平时可以养一些花花草草，装点一下阳台。不装吊柜是为了实现侧面的晾衣，这样不至于直对客厅，显得凌乱。后记：不论是做局部吊柜还是不做吊柜，其实都是实用的处理办法。
