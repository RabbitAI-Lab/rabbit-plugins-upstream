# 60㎡loft住一个人，这单身公寓真美

其实LOFT小公寓对于单身来说，简直再好不过，楼上楼下也符合年轻人的生活习惯。而且这种LOFT本身房价也低，基本是买一层送一层，所以对于年轻人来说，拥有这样一个家完美。入住25万。

▲一楼空间，进门就是小门厅和卫生间，进门左手布局鞋柜，而且与餐边柜一体布局，视觉能更整齐；一个人住开放式餐厨布局，可以让采光和公共区域更加宽敞通透
▲二楼布局图，因为单身住，楼上就一间卧室足够，另外一间做了储藏室，有一个小的卫生间，这样客厅就保证挑空布局，视觉和光线完美呈现
▲门厅很小为了空间感更好，采用挑空布局；右手墙面做了龟背竹的手绘，不论冬夏进门就有自然气息；左手采用矮柜充当鞋柜收纳，台面还可以放置随手物品，摆上挂画，也能有高级感
▲摆上喜欢的装饰品，斜靠挂画，不一样的格调呼之欲出
▲门厅进来就是开放式餐厨，因为平时经常有朋友前来聚会，所以岛台与餐桌布局，可以满足更多人的共同交流；两个超级窗户保证了光线的一览无余；过道上顶天立地收纳柜镶嵌冰箱。动线四周合理，再多人也不会有通行的障碍

▲开放厨房，白色的吊柜地柜，墙面纯黑色变色，视觉对比质感，靠近窗户预留空间，上墙绿植装饰

▲大面积白色让小空间变大，木色的餐桌与地面木纹砖呼应，层次分明，空间温馨
▲过道餐边柜白色布局，刚好镶嵌双开门冰箱，局部黑色套色，与整体空间更协调统一
▲客厅空间挑空布局，因为空间太空，所以吊顶采用钛金装饰，然后选择网状的吊灯布局，视觉也非常惊艳
▲跌级吊顶布局，采用钛金收边，可以让空旷的客厅更丰富，同时搭配蛛网吊灯，黑白对比有质感，又非常酷
▲边户的好处就是光线没有问题，两边超级窗户让客厅几乎通透无死角，配上素雅纱帘平时时刻保证空间的柔和温馨；布艺灰色极具线条感的沙发搭配ins风的地毯，红色的单椅点缀提亮空间
▲客厅全景，空间不大，但是挑空布局可以让小空间放大；
▲楼梯下方定制了隐形收纳柜，大面积白色与踏步的木色对比，清新温馨
▲简单的电视柜布局，摆上电视满足基本的功能
▲楼梯侧墙排列四盏壁灯，发散灯光视觉现代时尚
▲十字光影如星星般排列，也能让客厅视觉更生动
▲全景空间，黑白对比，木色点缀，简洁中又有温馨
▲楼上空间卧室，同样是黑白搭配，卧室背景做了黑白壁龛收纳，虽然上方层高不高，但是两个窗户布局，光线非常好
▲楼梯上来隔墙分区，过道刚好布局卧室的衣柜空间，满足楼上卧室的衣物收纳
▲一楼门口卫生间，干区刚好布局洗漱区以及洗烘机，镜柜收纳，暖色灯条布局，让空间明亮又温馨
