## Description: <br>
Implement changes as small, tested, and verified vertical slices so each increment remains complete, working, and independently deployable or rollbackable. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[paudyyin](https://clawhub.ai/user/paudyyin) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and coding agents use this skill to break multi-file changes, new features, refactors, and larger implementation tasks into small vertical slices that are implemented, tested, verified, and committed incrementally. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad triggers may cause the workflow to steer coding tasks where a narrower process is preferred. <br>
Mitigation: Review the trigger list during installation and use the skill primarily for multi-file changes, refactors, and larger implementation work. <br>
Risk: The skill encourages frequent git commits, which may conflict with repositories that require stricter commit timing or review policy. <br>
Mitigation: Keep normal control over commits and commit only after the current slice has been tested or manually verified. <br>
