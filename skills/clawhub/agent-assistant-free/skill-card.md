## Description: <br>
Agent Assistant Free helps developers define AI assistant personas, voice rules, boundaries, and reusable identity templates using a goal-values-perspective framework. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[thcjp](https://clawhub.ai/user/thcjp) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and agent builders use this skill to create consistent AI assistant identity cards, behavioral tone rules, anti-voice lists, and permission boundaries for assistants in customer service, education, internal tooling, and personal assistant scenarios. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The requested command and file-write permissions are broader than expected for a Markdown persona-design helper. <br>
Mitigation: Review before installing and prefer a version that narrows trigger conditions and requires explicit user confirmation before file writes or command execution. <br>
Risk: The skill can generate assistant identity and boundary guidance for sensitive contexts such as education, personal support, or internal operations. <br>
Mitigation: Have a human reviewer confirm generated personas, boundaries, and refusal rules before deploying them in user-facing or sensitive workflows. <br>
