## Description:

Helps agents create, inspect, and edit Microsoft PowerPoint PPTX presentations with Chinese-language guidance and layout-oriented workflows.

This skill is ready for commercial/non-commercial use.

## Publisher:

[thcjp](https://clawhub.ai/user/thcjp)

### License/Terms of Use:

MIT-0

## Use Case:

External users, developers, and teams use this skill to have an agent work with local PPTX files for presentation creation, inspection, editing, layout checks, and troubleshooting.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can guide agents to read, write, and execute commands around local presentation files.

Mitigation: Give the agent explicit file paths and task boundaries, and review presentation changes before sharing or publishing.

Risk: Presentation files may contain confidential or sensitive business content.

Mitigation: Avoid providing sensitive presentation content unless it is necessary for the task, and do not provide API keys or credentials.
