## Known Risks and Mitigations: <br>
Risk: Broad trigger wording may cause the skill to be selected when a narrower workflow would be more appropriate. <br>
Mitigation: Review the user's actual goal and constraints before applying the workflow, and ask only for missing information that materially changes the output. <br>
Risk: Documentation-style guidance can still produce incorrect or incomplete plans for a user's specific environment. <br>
Mitigation: Validate each output against the stated success criteria and include visible assumptions, limits, remaining risks, and follow-up work. <br>
