# AI Tech Insight Compass

> 从信息洪流中打捞关键技术信号，30分钟生成一篇技术深度文章。

## 业务场景

**痛点**：技术团队/自媒体每天需要花3-4小时搜索AI前沿动态、阅读论文、验证GitHub项目，再花2小时撰写技术文章。信息源分散，筛选成本高，容易遗漏重要技术信号。

**解决方案**：AI Tech Insight Compass 将这一流程自动化——输入当天关注的技术关键词，30分钟内输出：

1. **多源信息聚合**： Brave Search 搜索 + GitHub Trending 验证 + arXiv 论文补充
2. **技术洞察提炼**： Summarize 自动聚合，识别关键技术突破点
3. **深度文章生成**： Tech-article-pro 按机器之心/InfoQ风格生成3000-5000字硬核技术文章
4. **一键发布**： 保存本地 + 可选推送到公众号API

## 工作流详解

### Phase 1: 信息采集（5-8分钟）

**Brave Search** 采集当日AI技术动态：
```
搜索维度1：大模型最新进展（LLM/MoE/LongContext等）
搜索维度2：具体技术方向深度搜索
搜索维度3：arXiv最新论文
```

**GitHub Trending** 验证技术趋势：
```
通过gh api查询近期创建的AI相关高星仓库
获取仓库描述、star数、相关技术栈
```

### Phase 2: 洞察提炼（3-5分钟）

**Summarize** 将多源信息聚合成结构化洞察：
- 核心技术事件/突破点
- 技术原理简述（200字内）
- 相关开源项目清单
- 行业影响评估

### Phase 3: 文章生成（15-20分钟）

**Tech-article-pro** 生成硬核技术文章：
- 参考机器之心/InfoQ写作风格
- 开篇：技术事件/论文切入（200-300字）
- 原理：核心技术机制解析（1000-1500字）
- 代码：≥4处完整代码示例（每处≥10行）
- 分析：技术优劣势、适用场景（500-800字）
- 趋势：技术发展方向判断（300-500字）

### Phase 4: 发布（2-3分钟）

- 保存到 `/root/articles/{date}/tech-insight-daily.md`
- POST到公众号API（可选）
- 创建飞书文档归档（可选）

## 使用示例

### 示例1：生成今日AI Agent技术日报

```
用户：生成一篇AI Agent技术日报

AI执行：
1. brave-search 搜索 "AI Agent 2026 最新进展" → 获取8条结果
2. brave-search 搜索 "AI Agent autonomous reasoning 论文" → 获取5条结果
3. github 查询近30天AI Agent高星仓库 → 获取3个repo
4. summarize 聚合成：核心突破、原理、代码、趋势
5. tech-article-pro 撰写《AI Agent：从工具到自主智能体》
6. 保存到 /root/articles/2026-08-10/tech-insight-daily.md
```

### 示例2：深度分析MoE大模型

```
用户：分析一下MoE大模型最新进展

AI执行：
1. brave-search 多维搜索MoE技术动态
2. github 获取MoE相关开源实现
3. summarize 提炼MoE关键洞察
4. tech-article-pro 撰写深度技术解析
```
