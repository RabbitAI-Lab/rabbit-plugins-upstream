## Description: <br>
Helps API developers, backend teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, backend and platform teams, developer-experience teams, and maintainers use this skill to turn API documentation requests into practical OpenAPI or Swagger workflows, checklists, code-oriented guidance, and validation steps. It is intended for REST API documentation generation, improvement, review, and publishing support. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger language may activate the skill for general API or documentation prompts. <br>
Mitigation: Invoke it explicitly for OpenAPI or Swagger documentation tasks, or narrow trigger language before deployment when tighter routing is needed. <br>
Risk: Generated documentation guidance can be incomplete or misleading when endpoint behavior, authentication requirements, or validation criteria are missing. <br>
Mitigation: Review outputs against the implemented API, route security expectations, examples, and validation tooling before publishing documentation. <br>
