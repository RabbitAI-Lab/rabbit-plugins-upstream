# 本地文件适配器

## 支持范围

- `.txt`、`.md`：直接读取文本。
- `.docx`：使用宿主文档能力或只读提取器读取正文、表格和可见批注；保留段落顺序。
- 文本型 PDF：使用宿主 PDF 能力提取文本，并检查页序和分栏顺序。

扫描型 PDF、图片和录音不在 V1 自动转写范围。若宿主已有 OCR，可在用户知情下读取 OCR 文本，并把 `source_type` 标记为 `local_file`、置信度按 OCR 质量调整；否则请求用户提供文本版。

## 处理步骤

1. 确认文件存在、类型可读且位于用户授权范围。
2. 只读提取文本，不覆盖来源文件。
3. 为每段建立稳定定位：`文件名 + 页码/段落号`。
4. 识别页眉页脚、目录和重复块，避免把重复内容当多次确认。
5. 对表格按行读取，保留“负责人 / 时间 / 动作”列关系。
6. 先脱敏，再进入语义判断。
7. 不把完整抽取文本写入仓库、公开 HTML 或测试日志。

## 失败降级

- 文本为空：说明文件可能为扫描件，停止语义判断。
- 顺序不可靠：标记 `close_status=insufficient_evidence`，让用户提供导出的纯文本或智能纪要。
- 文件含多场会议：请求用户指定范围，或按标题/日期切分后一次只处理一场。
- 发言人标签丢失：使用匿名发言人编号，不从段落内容猜身份。
