# 腾讯会议适配器

## 状态

该文件定义 V1.1 兼容契约。只有宿主已经安装并授权腾讯会议官方能力时才调用；V1 核心流程不依赖该连接。

## 允许的读取流程

1. 让用户选择会议或提供可解析的会议标识。
2. 优先获取智能纪要元数据，再按宿主能力分页读取转写段落。
3. 保留官方返回的说话人标签、时间戳、段落顺序和分页游标。
4. 分页完成后检查首尾连续性、重复段落和缺页。
5. 将段落映射为 `speaker`、`timestamp`、`paragraph`、`text`。
6. 运行脱敏后交给 Skill 分类工作流。

## 权限与凭证

- 只使用宿主已授权的官方 Skill 或连接器。
- 不要求用户粘贴 Token、Cookie、密码或 API Key。
- 不把凭证、请求头或完整接口响应写入日志、样例和仓库。
- 权限不足、会议敏感或企业策略禁止时立即停止，退回手动粘贴或本地导出文件。

## 语义边界

- 官方智能纪要只作为来源，不能直接当已确认结论。
- 智能纪要与逐字稿冲突时优先逐字稿，并标记来源冲突。
- 发言人映射不清时沿用官方匿名标签，不猜姓名。
- 该适配器不自动发送会后消息、不创建任务、不写回会议系统。
