本文件提供候选信号，不提供关键词直判。每次命中都要检查说话人、指代、前后文、否定、条件和后续改口。

## 明确收口信号

- 就按……走 / 就这么定 / 这个确定了
- 最终用…… / 选…… / 定……
- 这期做…… / 这期不做……
- 先停掉…… / 暂不采用……
- 结论就是…… / 我拍板……

风险点：

- “要不就按 A 走？”仍可能是提议问句。
- “可以按 A 走”可能只表达可行性。
- “大家都觉得 A 可以”属于转述，需寻找实际收口。

## 暂定与范围信号

- 先 / 暂时 / 暂定 / 目前
- 这一版 / 这期 / 首发 / 第一阶段
- 本周 / 这个月 / 现阶段
- 先跑一轮 / 先试两天 / 小范围
- 除非后面…… / 没有新情况就……

抽取时保留完整限定短语。多个范围同时出现时全部保存，例如“首发阶段本周先不改价”。

## 条件信号

- 如果 / 只要 / 等……以后 / ……之后
- 前提是 / 除非 / 没有……就
- 法务过了 / 数据给到 / 预算批了 / 样张通过
- 看……结果 / 取决于 / 以……为准

区分条件与时间顺序：

- “法务周四回复后，周五发布”可能只是时间安排；若法务意见能阻断发布，则属于条件。
- “法务通过后发布”明确属于条件。

## 主动认领信号

- 我来 / 我负责 / 我接 / 我处理
- 我周三给 / 我今晚发 / 我会补一版
- 我们团队出 / 这块我们包了
- 算我这边 / 放我这里

必须抽取具体动作和交付对象。“我来看看”需要按弱动词处理。

## 指派信号

- 小王，你……
- 媒介这边……一下
- 这块给市场 / 让 PR 来……
- 麻烦产品…… / 请法务……
- 后续由……负责

指派出现后继续向后找接受、拒绝、条件或改派。没有回应时保持 `unacknowledged_assignment`。

## 接受信号

- 好 / 好的 / 收到 / 可以 / 没问题
- 行，我来 / 明白，我周三给
- 我接着 / 放我这儿

短回应高度依赖邻接关系。发言人不明、对象不唯一或议题切换时不得当成确认。

## 弱意向信号

- 看看 / 回头看看 / 再看下
- 研究一下 / 了解一下 / 关注一下
- 尽量 / 争取 / 试试 / 想办法
- 考虑 / 评估一下 / 有空弄
- 应该可以 / 大概能 / 尽可能

弱动词加时间仍可能不够：

- “我周三看看” → 表达意向；有时间，交付物仍缺失。
- “我周三给一版评估结论” → 明确承诺；交付清楚。

## 延后信号

- 下次再说 / 下周再议 / 先放放
- 这个先挂着 / 暂时不讨论
- 等信息齐了再定 / 回头另开会

“先不做”需区分当前否定决定与延期：若明确范围为本期，可记已确认的否定决定；若只把决定推迟，记 `deferred`。

## 覆盖与改口信号

- 刚才说……现在改成……
- 前面那个作废 / 以前一版不算
- 改一下 / 还是…… / 等等，换成……
- 不对，应该…… / 我收回刚才的话

“还是 A 吧”可能回到早先方案。按议题时间线确认当前有效项，不按最近两个词机械替换。

## 否定与语气陷阱

- “不是不能做，只是本周没资源。” → 可行性未否定，当前时点受限。
- “也不是说一定要 A。” → 不构成采用 A。
- “不排除 B。” → 只表示 B 仍有可能，不构成决定。
- “差不多就这样？” → 带问号的试探性收口，寻找明确回应。
- “你看着办。” → 可能授权，也可能模糊甩回；只有任务范围和授权对象清楚时才记录为指派，不能自动形成接受。

## 省略主语与部门指向

中文会议常省略主语：

- “那就周五给一版。”若上一轮唯一明确责任人仍在发言，可结合邻接关系归因；跨多个发言轮次则保持 owner 未知。
- “这边跟一下。”必须知道“这边”指向谁；无法稳定还原时用未知团队并降低置信度。
- “还是老规矩。”需要来源中出现可引用的老规矩内容；禁止调用未提供的组织记忆补全。

## 反讽、玩笑和代述

- “那我可太愿意接了。”可能带反讽；缺少语音、表情或后续明确确认时降级。
- “小王肯定愿意。”属于他人代述，不能算小王确认。
- “老板说就这么干。”若只有二手转述，可记录低置信度决定并标注转述来源；不可伪装成老板原话。
- 笑声、表情或“哈哈”不改变承诺状态，除非后文明确收口。

## 信号组合优先级

1. 明确撤回或修正。
2. 具体收口或具体认领。
3. 条件、范围、否定。
4. 邻接回应。
5. 弱动词与泛泛赞同。
6. 仅靠关键词、角色惯例或常识推断。

越靠后，越需要更多上下文与更低置信度。
