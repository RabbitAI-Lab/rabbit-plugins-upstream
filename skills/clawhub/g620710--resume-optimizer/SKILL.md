## Quick Start

### 第一步：配置环境变量

```bash
export RESUME_API_USER_KEY="你的DeepSeek API Key"
# 可选：自定义API地址
export DEEPSEEK_BASE_URL="https://api.deepseek.com/v1"
```

### 第二步：开始优化

**完整优化（带目标岗位）：**
```bash
python3 {baseDir}/scripts/resume_optimizer.py optimize my_resume.txt \
  --target "产品经理" --jd job_description.txt
```

**只做评分诊断：**
```bash
python3 {baseDir}/scripts/resume_optimizer.py analyze my_resume.txt
```

**生成不同岗位版本：**
```bash
python3 {baseDir}/scripts/resume_optimizer.py optimize my_resume.txt \
  --target "运营经理" -o resume_operation_version.txt
```

**简历与JD匹配度分析：**
```bash
python3 {baseDir}/scripts/resume_optimizer.py match my_resume.txt --jd job_desc.txt
```

## 完整功能列表

| 命令 | 功能 | 说明 |
|------|------|------|
| `optimize` | 完整简历优化 | 评分+诊断+逐句优化+改写版简历 |
| `analyze` | 仅评分诊断 | 快速了解简历问题，不生成改写版 |
| `rewrite` | 生成优化版简历 | 只输出改写后的完整简历 |
| `match` | JD匹配度分析 | 分析简历与目标岗位的匹配程度 |

## Input Parameters

### optimize 命令参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `resume_file` | string | 是 | 简历文件路径（纯文本格式） |
| `--target` | string | 否 | 目标岗位名称 |
| `--jd` | string | 否 | 岗位JD文件路径 |
| `--industry` | string | 否 | 目标行业 |
| `--level` | string | 否 | 目标级别：entry/mid/senior/executive |
| `--format` | string | 否 | 输出格式：text/markdown/json，默认text |
| `-o, --output` | string | 否 | 保存到文件 |

### analyze 命令参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `resume_file` | string | 是 | 简历文件路径 |
| `--target` | string | 否 | 目标岗位（可选） |

## 常见问题 FAQ

**Q1: 优化后的简历能保证拿到面试吗？**
A: 不能保证。简历优化是提高通过率的重要手段，但最终能否拿到面试还受岗位匹配度、竞争激烈程度、运气等因素影响。优化后通常能提升30-50%的回复率。

**Q2: 我的简历是Word/PDF格式的，能用吗？**
A: 目前只支持纯文本格式。你可以把Word/PDF的内容复制保存为.txt文件后再使用。后续会支持更多格式。

**Q3: 优化后的简历会不会太假了？会不会和实际经历不符？**
A: AI优化是在你原有经历的基础上做语言优化和亮点突出，不会编造经历。优化的是表达方式，不是事实本身。但建议你对每一条优化内容负责，确保真实。

**Q4: 为什么要提供JD？没有JD能优化吗？**
A: 提供JD能让优化更有针对性，精准匹配岗位关键词，效果会好很多。没有JD也能优化，AI会基于目标岗位名称做通用优化。

**Q5: 支持哪些行业和岗位？**
A: 支持大部分主流行业和岗位，包括但不限于：互联网（产品/运营/技术/设计）、金融、咨询、教育、医疗、市场、销售、人力资源等。越通用的岗位效果越好。
