## Description:

Guides behavior-preserving inheritance and delegation refactoring in JavaScript, TypeScript, React, and Vue frontend code.

This skill is ready for commercial/non-commercial use.

## Publisher:

[bovinphang](https://clawhub.ai/user/bovinphang)

### License/Terms of Use:

MIT

## Use Case:

Frontend developers use this skill to select and apply small, verifiable changes to legacy inheritance hierarchies, subtype responsibilities, and delegation while preserving observable behavior.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Refactoring may change public contracts, serialization, lifecycle behavior, or subtype identity.

Mitigation: Review proposed code changes before applying them and verify affected behavior after each small step.
