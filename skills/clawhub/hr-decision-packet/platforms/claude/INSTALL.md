# Use with Claude

Claude supports custom skills uploaded as ZIP files.

1. Download the `hr-decision-packet-claude.zip` release asset.
2. In Claude, open **Customize → Skills**.
3. Select **+ → Create skill → Upload a skill**.
4. Upload the ZIP and enable **HR Decision Packet**.
5. Start with a synthetic or de-identified scenario.

The ZIP contains the same canonical skill, template, adversarial evals, and synthetic example published on ClawHub. It contains no code, dependencies, connectors, credentials, network calls, or real employee or employer data.

Individually uploaded Claude skills are private to the account. Team and Enterprise organizations may share skills internally when an organization owner enables skill sharing.
