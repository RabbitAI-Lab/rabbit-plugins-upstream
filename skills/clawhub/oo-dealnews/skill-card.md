## Description:

Search and read DealNews deals and blog posts through an OOMOL-connected account.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

Agents use this skill to retrieve DealNews latest, popular, category, and Editors' Choice deals, along with blog posts, for a user's request.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: First-time setup executes downloaded installer code, and broader changes to the agent environment are not fully explained.

Mitigation: Review setup before running; prefer a verified, pinned oo CLI installation and explicitly control changes to other agent skills.

Risk: Use may involve OOMOL authentication and usage charges.

Mitigation: Consider account authentication and usage charges before using the skill.
