## Description:

Browser Automation V2 provides OpenClaw browser automation with tab cleanup, timeout retries, concurrency locking, smart waits, and configurable runtime settings.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and automation agents use this skill to run OpenClaw browser workflows for web search, page fetching, batch page processing, screenshots, PDFs, and form filling.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Shell-based execution includes user-supplied URLs, search terms, form data, and profile values, which can create local command-execution risk.

Mitigation: Install only after replacing shell-interpolated execution with argument-based process execution and validating URL, browser reference, profile, search, and form inputs.

Risk: Form values are logged during form-filling workflows and may expose sensitive data.

Mitigation: Do not use the skill with secrets, authenticated browser sessions, or confidential form data until form-value logging is removed or redacted.

Risk: Screenshots and PDFs are generated by browser commands, but storage locations and handling expectations are not documented in the release evidence.

Mitigation: Document where screenshots and PDFs are saved, define cleanup or retention expectations, and review generated files before sharing them.

Risk: Untrusted URLs, search terms, and form inputs can drive browser actions in the local environment.

Mitigation: Restrict use to trusted inputs and isolated browser profiles until input validation and safer execution are implemented.
