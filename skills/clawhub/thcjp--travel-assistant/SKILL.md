## 主要能力
### 📋 旅行信息总览表
你告诉助手你的旅行计划，它会自动整理成一张清晰的总览表：

* 目的地、出行日期、同行人员
* 已确认事项（机票、酒店、门票）
* 待办清单（还需要做什么）
* 重要时间节点提醒

### ⚠️ 主动发现遗漏细节

每次你更新计划后，助手会自动检查这些常见遗漏：

* 护照有效期（目的地通常要求剩余6个月以上）
* 签证类型和办理周期（提前多久要申请）
* 目的地与出发地时差
* 当地货币和建议携带现金金额
* 手机漫游方案或当地SIM卡建议
* 信用卡境外使用是否需要提前申请
* 目的地插头规格（是否需要转换器）

### 🌤️ 实时天气查询
联网查询旅行期间目的地天气，给出：

* 气温范围和体感温度
* 降雨概率和建议携带雨具
* 极端天气风险提示（台风、暴雪、沙尘暴）
* 穿衣建议

### 🧳 个性化行李清单

根据目的地、旅行天数、同行人员生成专属行李清单：

* 必带证件清单
* 根据天气的穿衣建议
* 目的地特殊需求（防晒、登山装备、海滩用品）
* 常备药品建议
* 电子设备和转换插头

## 常见问题FAQ

### Q1: 如何使用助手生成行李清单？
A: 您可以通过提供目的地、旅行天数、同行人员等信息，助手会根据这些信息生成专属行李清单。

### Q2: 助手如何提醒我重要时间节点？
A: 助手会自动整理您的旅行计划，并在重要时间节点前提醒您，例如出发日期、酒店入住时间等。

### Q3: 助手如何查询目的地天气？
A: 您只需提供目的地和出行日期，助手会自动查询并给出气温、降雨概率、穿衣建议等信息。

### Q4: 助手如何发现我忽略的细节？
A: 每次您更新旅行计划后，助手会自动检查护照有效期、签证类型、时差、货币、手机漫游方案等常见遗漏细节。

### Q5: 助手支持哪些语言？
A: 助手支持中文交互，无需复杂配置即开即用。

## 故障处理体系
针对助手使用中可能遇到的常见问题,提供以下排查方案:

| 错误类型 | 原因分析 | 解决方案 |
|---------|---------|---------|
| API认证失败(401) | API密钥错误或过期 | 检查密钥配置,重新生成token |
| 接口限流(429) | 请求频率超出限制 | 降低调用频率,启用重试退避策略 |
| 响应超时(504) | 网络延迟或服务端负载过高 | 增加超时阈值,检查网络连接 |
| 文件不存在 | 路径错误或文件未创建 | 检查路径拼写,确认文件已生成 |
| 文件格式不支持 | 扩展名不在支持列表中 | 转换为支持的格式后重试 |
| 权限不足 | 当前用户无读写权限 | 检查文件权限,以管理员身份运行 |
| 命令执行失败 | 参数错误或环境依赖缺失 | 检查命令语法,确认依赖已安装 |
| 进程超时 | 命令执行时间过长 | 增加超时设置,优化命令参数 |
| 网络连接失败 | DNS解析失败或防火墙拦截 | 检查网络配置,确认代理设置 |

### 助手通用排查步骤

1. **检查输入参数**: 确认所有必填参数已提供且格式正确
2. **查看日志输出**: 定位具体错误行和异常类型
3. **验证环境配置**: 确认依赖库版本和运行环境满足要求
4. **逐步调试**: 缩小问题范围,隔离故障模块
