# Changelog

All notable changes to the Career Success Predictor skill will be documented in this file.

## [1.1.0] - 2025-07-24

### Added
- Enhanced description with richer trigger keywords (中文, 日本語, 職業転換 variations)
- Keywords metadata field for better SEO/discoverability
- Support for multilingual trigger phrases
- GitHub repository for broader accessibility
- Comprehensive README with use-case examples and design highlights

### Improved
- Clearer explanation of fit vs. readiness layers
- Better documentation of question design principles
- Enhanced scoring methodology documentation
- More detailed edge-case handling guidance

### Changed
- Updated metadata structure to include version and keywords

## [1.0.0] - 2024-12-15

### Initial Release
- Core assessment workflow (10 occupation-specific questions)
- Fit score calculation (range-based, not false precision)
- Readiness stage placement (4-stage model)
- Narrative report generation (3-minute read, story-focused)
- Multilingual support (English, Chinese, Japanese)
- Incremental evidence gathering for blurry cases
- Edge case handling (career switching, broad career names, etc.)
