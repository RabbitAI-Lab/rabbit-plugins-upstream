## Description:

Count words, characters, lines, and estimate reading time for any text.

This skill is ready for commercial/non-commercial use.

## Publisher:

[terrycarter1985](https://clawhub.ai/user/terrycarter1985)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, writers, and reviewers use this skill to quickly inspect text length, word count, line count, character count, and estimated reading time for a file or pasted content.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Using the bundled script on a sensitive document requires the document to be read locally.

Mitigation: Run it only in trusted local environments and review whether aggregate counts are acceptable to expose before sharing output.
