## Description:

Provides a step-by-step upgrade checklist for making EmpireCMS 7.5 projects compatible with PHP 8.x, including fatal-error fixes and migration checks.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and site maintainers use this skill to plan and execute a controlled EmpireCMS 7.5 migration to PHP 8.x, repairing compatibility issues one file at a time with validation checkpoints.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill guides edits to existing PHP source files and could break a live site if applied broadly.

Mitigation: Use version-controlled or backed-up code, prefer staging first, and follow the skill's per-file validation steps.

Risk: The artifact includes environment-specific local IP and path examples.

Mitigation: Review and replace local examples before applying the guidance to another environment.
