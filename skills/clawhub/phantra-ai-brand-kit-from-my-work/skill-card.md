## Description:

Builds a visual brand kit from the user’s Phantra work, confirms each evidence-based rule, then saves it as a recipe and a project look.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zeropage-onryo](https://clawhub.ai/user/zeropage-onryo)

### License/Terms of Use:

MIT-0

## Use Case:

Phantra creators use this skill to identify visual rules from their own renders, photos, prompts, project notes, and feedback. They can review each proposed rule, then save confirmed rules as a recipe and project look.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow reads the user’s Phantra creative library and project details, which may include private work.

Mitigation: Review Phantra service permissions and the separate phantra-ai-use companion before use.

Risk: External tool behavior was not verified, and scanner coverage was partial.

Mitigation: Review the available Phantra tools and their permissions before relying on them.
