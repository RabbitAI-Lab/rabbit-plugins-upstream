## 能为你做什么（转让定价五大场景）
---

### 一、关联申报与同期资料
- 📑 **申报合规**：按期报送关联业务往来报告表，识别 25%持股等关联关系
- 🗂️ **文档门槛**：主体文档/本地文档/特殊事项文档按总局公告2016年第42号门槛准备
- ⚠️ **高频风险**：同期资料缺失导致无法举证、被核定调整

**典型问法：**
```
"关联交易怎么准备同期资料？"
"关联申报表怎么填？"
```

### 二、转让定价方法选定与佐证
- 🔍 **方法选用**：CUP/再销售/成本加成/交易净利润/利润分割，并有可比性分析佐证
- 📊 **功能风险分析**：梳理交易各方执行的功能、承担的风险与使用的资产
- ⚠️ **风险点**：定价偏离独立交易原则触发特别纳税调整、补税+利息

**典型问法：**
```
"转让定价方法怎么选？"
"可比性分析怎么做？"
```

### 三、资本弱化与关联交易利息
- 💱 **债资比限额**：关联债资比金融≤5:1、其他≤2:1，超限利息不得扣除
- 🧮 **测算自查**：自动判定超限利息扣除风险
- ⚠️ **风险点**：资本弱化超限导致利息纳税调增

**典型问法：**
```
"资本弱化债资比怎么算？"
"关联方借款利息能扣除吗？"
```

### 四、预约定价安排（APA）与特别纳税调整应对
- 🤝 **APA 谈签**：与税务机关就未来年度定价方法事先约定，降低不确定性
- 🛡️ **调查应对**：收到特别纳税调整调查通知的合规应对与陈述申辩
- ⚠️ **风险点**：特别纳税调整补税+利息、关联交易未申报罚款

**典型问法：**
```
"预约定价安排APA怎么谈？"
"关联交易被特别纳税调整怎么办？"
```

### 五、受控外国（CFC）与无形资产
- 🌐 **CFC 判定**：低税率地区利润留存是否触发受控外国企业规则（视同分配缴税）
- 💡 **无形资产/服务费**：特许权使用费、服务费支付的合理性与受益性分析
- ⚠️ **风险点**：无形资产/服务费不合理导致补税调整

**典型问法：**
```
"受控外国企业CFC怎么判定？"
"特许权使用费合理性怎么证明？"
```

## 重要提示与边界声明

**重要提示**
1. **定价须独立**：关联交易须符合独立交易原则，不得借关联交易转移利润。
2. **同期资料须真实**：主体/本地/特殊事项文档须真实可佐证，不得虚构可比数据。
3. **资本弱化有限额**：关联债资比金融≤5:1、其他≤2:1，超限利息不得税前扣除。
4. **以官方为准**：同期资料准备门槛以总局公告2016年第42号为准，具体以主管税务机关口径为准。

**边界（本技能不做的）**
- **不代办**：关联申报、预约定价系统等需登录操作的事项
- **不代理**：特别纳税调整调查代理等需执业资质的事务
- **不担保**：特别纳税调整结论、补税认定等最终以税务机关为准

**服务说明**
- 每次提问都能获得完整闭环：智能问答 → 结构化结果 → 政策依据溯源 → 真实案例关联 → 实操辅导 → 反馈评价 → 合规报告

**隐私保护**
- 仅在本机生成随机匿名标识用于服务调用，不会采集任何设备信息或个人隐私数据。
