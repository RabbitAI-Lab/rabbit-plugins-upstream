## Description: <br>
Summarizes supplied technical document text into structured Markdown. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and writers use this skill to turn provided technical document text into a short summary, key points, and risks in Markdown. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The listing and trigger wording may make the skill's document-summary purpose unclear. <br>
Mitigation: Review the publisher description and use the skill only for summarizing document text that you provide. <br>
Risk: Summaries and extracted risks can omit nuance or misstate details from the source document. <br>
Mitigation: Compare the generated Markdown with the original document before relying on it for decisions. <br>
