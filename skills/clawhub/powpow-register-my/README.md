# powpow-register

PowPow ပူဖောင်း အကောင့်ဖွင့်ရေး လက်ထောက် (OpenClaw ဗားရှင်း): "ပူဖောင်း ဆိုတာ ဘာလဲ" ဟု မသိသေးသော အသုံးပြုသူသစ်တစ်ဦးကို "အကောင့် အသက်ဝင်ပြီး၊ တစ်ချက်နှိပ် လော့ဂ်အင် ဝင်ရောက်၊ စတင် ကစားနိုင်" အခြေအနေအထိ ရောက်အောင် — ပရိုဒတ် မိတ်ဆက်ခြင်း (interface ပုံများ အပါအဝင်)၊ အေးဂျင့် ကိုယ်စား အကောင့်ဖွင့်ပေးခြင်း (ပရိုဖိုင်ပုံ တင်ခြင်း အပါအဝင်)၊ Alipay/PayPal စာရင်းသွင်းမှု အော်ဒါ လုပ်ဆောင်ခြင်းနှင့် ငွေရောက်မှု စောင့်ကြည့်ခြင်း၊ လင့်ခ် နှစ်ခုဖြင့် တစ်ချက်နှိပ် လော့ဂ်အင်၊ အမှား ရှာဖွေရေး။

**v2.0.0 မှစ၍ အေးဂျင့် ကိုယ်စားလုပ်ဆောင်မှု မုဒ်၊ ထပ်မံ၍ v2.1.0 မှစ၍ PayPal ကိုလည်း ကိုယ်စားလုပ်နိုင်သည်**: အဓိက script `scripts/powpow-register.mjs` သည် မှီခိုမှု သုည (Node >= 18)၊ အသုံးပြုသူသည် စကားပြောဆိုမှုမှ လုံးဝ မထွက်ရ၊ ခေတ္တ ထွက်ရသည်မှာ နှစ်ကြိမ်သာ: အတည်ပြုကုဒ် ရယူရန် အီးမေးလ် ကြည့်ခြင်း၊ Alipay/PayPal ကောင်တာတွင် ငွေပေးချေခြင်း။ Node မရှိလျှင် သို့မဟုတ် အသုံးပြုသူက ကိုယ်တိုင် လုပ်ချင်လျှင် လမ်းညွှန်သက်သက် မုဒ်သို့ အလိုအလျောက် ပြန်ကူးသည်။

## ထည့်သွင်းခြင်း

```
openclaw skills install @durenzidu/powpow-register
```

## လုပ်ဆောင်ချက်များ

1. **ပရိုဒတ် မိတ်ဆက်**: စာလုံး 120 ခန့် စတင်ခန်း + အထုပ်အတွင်း ထည့်သွင်းထားသော interface ပုံများ (`assets/screenshots/` အောက်တွင် ပုံ 6 ပုံ: မြေပုံ စာမျက်နှာ၊ ပို့စ် အသေးစိတ် စာမျက်နှာ စသည်၊ ဖြစ်စဉ်အလိုက် ပုံ 1–3 ပုံ ရွေးပို့; ပြင်ပ ပုံဝန်ဆောင်မှု မလို၊ offline အသုံးပြုနိုင်)။
2. **ကိုယ်စား အကောင့်ဖွင့်ပေးခြင်း**: အေးဂျင့်က အသုံးပြုသူအမည်/ပြောင်အမည် ကြိုတင် အကြံပြုခြင်း၊ စကားဝှက် နည်းလမ်း နှစ်မျိုးမှ ရွေးခြင်း (အသုံးပြုသူ ပံ့ပိုး သို့မဟုတ် အေးဂျင့် ဖန်တီး)၊ အတည်ပြုကုဒ် ပို့ခြင်းနှင့် တင်ပြခြင်း၊ ပရိုဖိုင်ပုံ တိုက်ရိုက်တင်ခြင်း (<=5MB၊ SVG မဟုတ်)၊ အဖြစ်များ အမှားများကို အလိုအလျောက် ကိုင်တွယ်ခြင်း (ရှိပြီးသား/သက်တမ်းကုန်/အကြိမ်ရေ ကန့်သတ်ခြင်း)။
3. **တစ်ချက်နှိပ် လော့ဂ်အင် (လင့်ခ် နှစ်ခု)**: အကောင့်ဖွင့် အောင်မြင်လျှင် ချက်ချင်း "တစ်ဝက် လော့ဂ်အင်" လင့်ခ် ရရှိ၍ စာရင်းသွင်းမှု စာမျက်နှာသို့ တိုက်ရိုက် ရောက်သည်; ငွေရောက်မှု အတည်ပြုပြီးလျှင် လော့ဂ်အင် အခြေအနေ အသစ် လဲလှယ်၍ အသင်းဝင် အခြေအနေ အပြည့်အစုံပါ လင့်ခ် ရရှိ၍ မူလ စာမျက်နှာသို့ တိုက်ရိုက် ရောက်သည် (ပလက်ဖောင်း ၏ တရားဝင် `me?token=` တံတား ဖြတ်၍ HttpOnly cookie ကို အလိုအလျောက် စိုက်သည်)။
4. **စာရင်းသွင်းမှု ငွေပေးချေ**: Alipay (လစဉ် ¥6.99 / သုံးလတ် ¥19.99 / နှစ်စဉ် ¥69.99၊ တစ်ကြိမ် ပေးချေ၍ အလိုအလျောက် ဆက်သွင်း မလုပ်) နှင့် PayPal (Premium Monthly၊ ခန့်မှန်းခြေ $1/လ၊ အလိုအလျောက် ဆက်သွင်း၊ မည်သည့်အချိန်တွင်မဆို ဖျက်နိုင်) နှစ်ခုစလုံးကို အေးဂျင့်က ကိုယ်စား အော်ဒါ လုပ် + ငွေရောက်မှု polling ဖြင့် လုပ်ဆောင်သည်; နိုင်ငံခြား အသုံးပြုသူများ PayPal သို့ ပြန်ကူး; WeChat QR/Huawei IAP အတွက် လမ်းပြ။
5. **အမှား ရှာဖွေရေး**: အတည်ပြုကုဒ် မရောက်ခြင်း၊ အသုံးပြုသူအမည်/အီးမေးလ် ရှိပြီးသား ဖြစ်ခြင်း၊ 403 အသက်မဝင်ခြင်း၊ အကောင့် လော့ခ်ဖြစ်ခြင်း စသည့် အဖြစ်များ ပြဿနာများသည် အားလုံး ပလက်ဖောင်း ရင်းမြစ် ကုဒ်မှ လာ၍ ရင်းမြစ် ဖိုင် ညွှန်းထားသည်။

## လုံခြုံရေး

- **စကားဝှက်**ကို environment variable မှတစ်ဆင့်သာ script process သို့ ပေးပို့၍ command line parameter တွင် လုံးဝ မရေး၊ disk ပေါ် မစွဲ၊ state file ထဲ လုံးဝ မသွင်းပါနှင့်; အေးဂျင့် ဖန်တီးသော စကားဝှက်ကို အသုံးပြုသူ သိမ်းဆည်းနိုင်ရန် တစ်ကြိမ်သာ ပြသသည်။
- **အတည်ပြုကုဒ်**ကို တရားဝင် အကောင့်ဖွင့် interface အတွက်သာ အသုံးပြု၍ အသုံးပြုပြီးလျှင် ဖျက်ပစ်သည်; state file (အီးမေးလ်/အသုံးပြုသူအမည်/token/အော်ဒါ နံပါတ်) ကို စနစ် ယာယီ ဖိုင်တွဲတွင် သိမ်း၍ လုပ်ငန်းစဉ် အဆုံးတွင် `cleanup` ဖြင့် တစ်ချက်နှိပ် ရှင်းလင်းသည်။
- **ငွေပေးချေရေး**: အေးဂျင့်သည် အော်ဒါ ဖန်တီးခြင်း၊ ကောင်တာ ဖွင့်ခြင်း၊ ငွေရောက်မှု စုံစမ်းခြင်းသာ လုပ်၍ အသုံးပြုသူ ၏ Alipay/PayPal အကောင့် သို့မဟုတ် ငွေပေးချေရေး အထောက်အထားကို လုံးဝ မထိပါနှင့်၊ လုံးဝ အစား ငွေပေးချေ မပေးပါနှင့်။ ငွေပေးချေမှုသည် အမြဲ အသုံးပြုသူနှင့် တရားဝင် ကောင်တာ ကြားတွင် ဖြစ်ပျက်သည်။
- တောင်းဆိုမှုအားလုံးသည် တရားဝင် ဒိုမိန်း `https://global.powpow.online` သို့သာ သွားသည်; key မည်သည့်အရာမျှ မပါဝင်ပါ။
