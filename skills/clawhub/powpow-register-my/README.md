# powpow-register

PowPow ပူဖောင်း စာရင်းသွင်းအကူ (OpenClaw ဗားရှင်း)။ အသုံးပြုသူအသစ်ကို "ပူဖောင်းဆိုတာ ဘာလဲမသိ" မှ
"အကောင့် အသက်ဝင်ပြီး ပုံမှန်သုံးနိုင်" အထိ ပို့ဆောင်ပေးသည် — ထုတ်ကုန် မိတ်ဆက် (interface စခရင်ရှော့များ ပါဝင်သည်) ၊ အဆင့်ဆင့် စာရင်းသွင်း လမ်းညွှန် ၊
အမှားရှာဖွေခြင်း ၊ အသင်းဝင်ခြင်း အသက်သွင်းခြင်း ရှင်းလင်းချက်။

လမ်းညွှန်သက်သက် skill ၊ script မပါ ၊ dependency မပါ။ စာရင်းသွင်းခြင်း လုပ်ဆောင်ချက် အားလုံးကို အသုံးပြုသူက ဘရောက်ဆာ/အက်ပ်ထဲတွင် လုပ်ဆောင်သည်။

## တပ်ဆင်ခြင်း

```
openclaw skills install @durenzidu/powpow-register
```

## လုပ်ဆောင်ချက်များ

1. **ထုတ်ကုန် မိတ်ဆက်**: စာလုံး ~120 အဖွင့် + GitHub အများပြည်သူ repo တွင် လက်ခံဆောင်ရွက်ထားသော interface စခရင်ရှော့လင့်ခ်များ
   (မြေပုံစာမျက်နှာ ၊ ပို့စ်အသေးစိတ်စာမျက်နှာ စသည့် ပုံ 6 ခု ၊ အခြေအနေအလိုက် 1–3 ပုံ ရွေးပို့ပါ) ။
2. **စာရင်းသွင်း လမ်းညွှန်**: ကွက်လပ်စည်းမျဉ်းများ (အသုံးပြုသူအမည်/စကားဝှက်/အီးမေးလ် အတည်ပြုကုဒ်/ဖုန်းနံပါတ်/ပရိုဖိုင်ဓာတ်ပုံ) ၊ တတိယပါတီ ဝင်ရောက်ခြင်း
   (Google/Watcha/Huawei) ၊ rate limit သတ်မှတ်ချက်များ ၊ အားလုံးသည် ပလက်ဖောင်း ကုဒ်ရင်းမြစ်မှ ရရှိပြီး ရင်းမြစ် ဖော်ပြထားသည်။
3. **အမှားရှာဖွေခြင်း**: အတည်ပြုကုဒ် မရောက်ခြင်း ၊ အသုံးပြုသူအမည်/အီးမေးလ် နေရာယူထားခြင်း ၊ 403 အသက်မဝင်ခြင်း ၊ အကောင့် သော့ခတ်ခံရခြင်း စသည့်
   အဖြစ်များသည့် ပြဿနာ 13 ခု ။
4. **အသင်းဝင်ခြင်း အသက်သွင်းခြင်း**: လမ်းကြောင်း သုံးခုဖြစ်သည့် PayPal (ဝဘ်) / WeChat QR စကင်ဖတ် (လူကိုယ်တိုင် အတည်ပြု) / Huawei IAP (HarmonyOS)
   ၏ ရှင်းလင်းချက်နှင့် အမှားရှာဖွေခြင်း ။ လက်ရှိ ငွေပေးချေ လုပ်ငန်းစဉ်ကို တိုက်ရိုက် ပြန်သုံးနိုင်ပြီး skill သည် လမ်းညွှန်ရုံသာ ဖြစ်သည်။

## လုံခြုံရေး

- မည်သည့် သော့မျှ မပါဝင်ပါ။ script မရှိ ၊ အသုံးပြုသူ၏ အထောက်အထားများကို မထိတွေ့ပါ။
- အသုံးပြုသူ၏ စကားဝှက် ၊ အတည်ပြုကုဒ် သို့မဟုတ် ငွေပေးချေအထောက်အထားကို **မည်သည့်အခါမျှ မတောင်းပါနှင့်** ။ စာရင်းသွင်းခြင်းနှင့် ငွေပေးချေခြင်းသည် ပလက်ဖောင်းစာမျက်နှာပေါ်တွင် လုံးဝ ပြီးမြောက်သည်။
