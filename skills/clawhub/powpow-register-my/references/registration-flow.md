# စာရင်းသွင်းခြင်း လုပ်ငန်းစဉ် အသေးစိတ် — powpow-register

ပြဿနာရှာဖွေသည့်အခါ ကြည့်ရန် ဖြစ်သည်။ စည်းမျဉ်း အားလုံးသည် ပလက်ဖောင်း ကုဒ်ရင်းမြစ် (Next.js frontend/backend ညီညွတ်မှု စစ်ဆေးခြင်း) မှ ဖြစ်ပြီး ရင်းမြစ် ဖော်ပြထားသည်။
ပလက်ဖောင်း အပ်ဒိတ်ပါက အွန်လိုင်းပေါ်ရှိ အမှန်တကယ် အပြုအမူကို စံအဖြစ် ယူပါ။

## အဝင်ပေါက်များ

- စာရင်းသွင်းစာမျက်နှာ: https://global.powpow.online/register
- ဝင်ရောက်စာမျက်နှာ (login): https://global.powpow.online/login
- အသင်းဝင်စာမျက်နှာ: https://global.powpow.online/subscription
- မျှဝေလင့်ခ်မှ `?next=...` ပါသည်ဖြင့် ဝင်ပါက စာရင်းသွင်း + ငွေပေးချေ ပြီးပါက မူရင်းစာမျက်နှာသို့ အလိုအလျောက် ပြန်ခုန်သည်။

|---|---|---|---|

| စကားဝှက် | မဖြစ်မနေ | စာလုံး 8~100 ၊ စာလုံးအကြီး ၊ စာလုံးအသေး ၊ ဂဏန်း သုံးမျိုးလုံး ပါဝင်ရမည် | အထက်ပါအတိုင်း |
| စကားဝှက် အတည်ပြု | မဖြစ်မနေ | စကားဝှက်နှင့် တူညီရမည် (frontend စစ်ဆေးမှုသာ) | `src/app/(public)/register/page.tsx` |
| အမည်ပြောင် | ရွေးချယ်နိုင် | စာလုံး ≤100 ၊ မဖြည့်ပါက ပုံသေအဖြစ် အသုံးပြုသူအမည်ကို ယူသည် | register route |
| အီးမေးလ် | **မဖြစ်မနေ** | အီးမေးလ်ပုံစံ မှန်ကန်ရမည် ၊ စာလုံး ≤255 ၊ အီးမေးလ်တစ်ခုသည် အကောင့်တစ်ခုသာ စာရင်းသွင်းနိုင်သည် | register route |
| အီးမေးလ် အတည်ပြုကုဒ် | **မဖြစ်မနေ** | ဂဏန်း 6 လုံး ၊ **10 မိနစ် သက်တမ်း** ၊ အတည်ပြုအောင်မြင်ပါက ပျက်ပြယ်သွားသည် ၊ ပြန်ပို့ပါက ဟောင်းကုဒ်ကို သုံးပြီးသား အဖြစ် မှတ်သည် | `src/lib/email-verification.ts` |

စာမျက်နှာတွင် တတိယပါတီ ဝင်ရောက်ခလုတ် သုံးခုလည်း ပါသည်- **Google ၊ Watcha ၊ Huawei အကောင့်** (`GoogleSignInButton` /
`WatchaLoginButton` / `HuaweiLoginButton`) ။ တတိယပါတီအကောင့်တွင် ဒေသခံ စကားဝှက် မရှိဘဲ နောက်ပိုင်း စကားဝှက်ဖြင့် ဝင်ပါက
"该账号未设置密码，请使用其他方式登录" (ဤအကောင့်သည် စကားဝှက် မသတ်မှတ်ထားသေးပါ ၊ အခြားနည်းဖြင့် ဝင်ရောက်ပါ) ဟု ရရှိမည်။

## Rate Limit နှင့် ခိုးဝင်မှု ကာကွယ်ရေး သတ်မှတ်ချက်များ

| အပြုအမူ | ကန့်သတ်ချက် | ရင်းမြစ် |
|---|---|---|
| စာရင်းသွင်း ပေးပို့ခြင်း | **မိနစ်/IP/3 ကြိမ်** ၊ ကျော်ပါက 429 | `src/lib/rate-limit.ts` `REGISTER_RATE_LIMIT` |
| အတည်ပြုကုဒ် ပို့ခြင်း | IP တူ 1 ကြိမ်/မိနစ် **နှင့်** အီးမေးလ်တူ 1 ကြိမ်/မိနစ် ၊ ကျော်ပါက 429 ၊ frontend ခလုတ် စက္ကန့် 60 နောက်ပြန်ရေတွက်သည် | `src/app/api/auth/register/send-code/route.ts` |
| အတည်ပြုကုဒ် စစ်ဆေးခြင်း | အီးမေးလ်တစ်ခုလျှင် 10 မိနစ်အတွင်း အကြိမ် **5 ကြိမ်** အများဆုံး ၊ အကန့်အသတ်ရောက်ပါက ကုဒ်မှန်သော်လည်း ငြင်းပယ်ပြီး ပြန်ပို့ရသည် | `src/lib/email-verification.ts` |
| စကားဝှက် မေ့ခြင်း ကုဒ်ပို့ခြင်း | 1 ကြိမ်/မိနစ်/IP | `src/app/api/auth/forgot-password/route.ts` |
| ဝင်ရောက်ခြင်း | 5 ကြိမ်/မိနစ်/IP ၊ အကောင့်တစ်ခုတည်း ဆက်တိုက်မှား **5 ကြိမ်ဆိုလျှင် မိနစ် 30 သော့ခတ်** (423) ၊ ထိုအချိန်အတွင်း ကျန်ကြိမ်ရေ လျော့ချသော အသိပေးချက် ပြသည် | `src/app/api/auth/login/route.ts`、`rate-limit.ts` |

**ကိုယ်ရေးကိုယ်တာ ကာကွယ်မှု အပြုအမူ**: အတည်ပြုကုဒ် ပို့ခြင်း / စကားဝှက် မေ့ခြင်း အခါတွင် အီးမေးလ်သည် စာရင်းသွင်းပြီးသား ဖြစ်စေ မရှိသည်ဖြစ်စေ API သည်
အောင်မြင်ကြောင်း ဖော်ပြချက် တူညီစွာ ပြန်ပို့ပြီး အီးမေးလ် စာရင်းသွင်းပြီးခြင်း ရှိ/မရှိ မပေါက်ကြားစေပါ။

## စာရင်းသွင်းအောင်မြင်ပြီးနောက် အခြေအနေ ပြောင်းလဲမှု

1. အသုံးပြုသူကို `accountStatus: 'pending'` ဖြင့် သိမ်းသည် ၊ ကနဦး **တံဆိပ် 3 ခု** (register route) ။
2. Server သည် HttpOnly cookie နှစ်ခုကို တစ်ပြိုင်တည်း ချပေးသည်- JWT ( `/subscription` ကို တိုက်ရိုက် ဝင်ရောက်နိုင်သည်) နှင့်
   pendingUserToken (အသင်းဝင်ခြင်း လုပ်ငန်းစဉ်၏ မည်သူမည်ဝါ အတည်ပြုချက်) ။
3. စာရင်းသွင်းစာမျက်နှာသည် `pending_payment` တွေ့ပါက → `/subscription` သို့ ခုန်သည် ( `next` ပြန်ခုန်သတ်မှတ်ချက် သိမ်းထားသည်) ။
4. ငွေပေးချေပြီးပါက → `accountStatus` သည် `active` ဖြစ်သွားသည် (PayPal က Webhook ဖြင့် အလိုအလျောက် အသက်သွင်းသည် ၊ WeChat QR စကင်ဖတ်ကို
   လူကိုယ်တိုင် အတည်ပြုသည် ၊ Huawei IAP က `activate-huawei` ဖြင့် သွားသည်) ။ အသေးစိတ် `payment-and-activation.md` တွင်ကြည့်ပါ။

အသက်မဝင်သေးသော (pending) အသုံးပြုပသူက core API (feed ၊ မြေပုံ ၊ ဒစ်ဂျစ်တယ်လူသား စကားပြော ၊ check-in စသည်) ကို ခေါ်ပါက အားလုံး 403 ဖြစ်သည်။
မျှဝေထားသော ပို့စ်လင့်ခ်များ မှလွဲ၍ (အများပြည်သူ ဝင်ရောက်နိုင်ရန် ထားသည်) ။

## အဖြစ်များသော အမှားရှာဖွေ ဇယား

| ဖြစ်ရပ် (တရုတ် မူရင်း အမှားစာသား) | အကြောင်းရင်း | ဘာလုပ်ရမည် |
|---|---|---|
| 「用户名已存在」 (အသုံးပြုသူအမည် ရှိပြီးသား ဖြစ်သည်) | အသုံးပြုသူအမည် နေရာယူထားပြီး (အကြီး/အသေး မခွဲ) | အသုံးပြုသူအမည် အခြားတစ်ခု ပြောင်းပါ |
| 「邮箱已被使用」 (အီးမေးလ် သုံးထားပြီး ဖြစ်သည်) | အီးမေးလ် စာရင်းသွင်းပြီးသား | အီးမေးလ် ပြောင်းပါ ၊ သို့မဟုတ် ဝင်ရောက်ခြင်း + "စကားဝှက် မေ့ပြီ" ဖြင့် ဟောင်းအကောင့် ပြန်ရှာပါ |
| 「邮箱验证码错误或已过期」 (အီးမေးလ် အတည်ပြုကုဒ် မှားသည် သို့မဟုတ် သက်တမ်းကုန်ပြီ) | ကုဒ် ရိုက်မှား / 10 မိနစ် ကျော် / 5 ကြိမ် ထက် ပိုမှားသဖြင့် ငြင်းပယ်ခံရ | "ပြန်ပို့ပါ" ကို နှိပ်ပြီး **အသစ်ဆုံး အီးမေးလ်** မှ ကုဒ်ကို သုံးပါ |
| အတည်ပြုကုဒ် မရောက် | စက္ကန့် 60 rate limit ဖြစ်နေ သို့မဟုတ် spam/ကြော်ငြာ ဖိုဒါထဲ ရောက်နေ | နောက်ပြန်ရေတွက်ချိန် ကုန်အောင် စောင့်ပြီး ပြန်ပို့ပါ ၊ spam ဖိုဒါ ဖွင့်ကြည့်ပါ |
| 「手机号已被使用」 (ဖုန်းနံပါတ် သုံးထားပြီး ဖြစ်သည်) | ဖုန်းနံပါတ်ကို အခြားအကောင့်နှင့် ချိတ်ထားပြီး | ဖုန်းနံပါတ် ဖြုတ်ပါ (ရွေးချယ်နိုင်) သို့မဟုတ် နံပါတ် ပြောင်းပါ |
| 「注册请求过于频繁」/ 429 (စာရင်းသွင်းတောင်းဆိုမှု အလွန်များနေသည်) | စာရင်းသွင်း 3 ကြိမ်/မိနစ်/IP အကန့်အသတ် ထိမှန်နေ | မိနစ်အနည်းငယ် စောင့်ပြီး ပြန်ကြိုးစားပါ |
| 409「用户名或邮箱已被注册」 (အသုံးပြုသူအမည် သို့မဟုတ် အီးမေးလ် စာရင်းသွင်းပြီးသား) | ပေးပို့သည့်အခိုက် အခြားသူနှင့် အမည်တိုက်သည် (တစ်ပြိုင်နက် စုစည်းမှု ကြိုတင်) | အသုံးပြုသူအမည် သို့မဟုတ် အီးမေးလ် ပြောင်းပြီး ပြန်ကြိုးစားပါ |
| 「图片大小不能超过5MB」/「不支持 SVG」 (ပုံအရွယ်အစား 5MB ထက် မကျော်ရ / SVG မပံ့ပိုး) | ပရိုဖိုင်ဓာတ်ပုံ စည်းမျဉ်းနှင့် မကိုက်ညီ | ပုံ ပြောင်းပါ သို့မဟုတ် ပရိုဖိုင်ဓာတ်ပုံ ကျော်ပါ |
| စာရင်းသွင်းအောင်မြင်သော်လည်း ဝင်ရောက်ချိန် 403「请完成订阅以激活账户」 (အကောင့် အသက်သွင်းရန် အသင်းဝင်ခြင်း ပြီးမြောက်ပါ) | အကောင့်သည် pending ဖြစ်နေဆဲ | ဝင်ရောက်ပြီးနောက် စာမျက်နှာပေါ်ရှိ အညွှန်းအတိုင်း `/subscription` သွားပြီး အသင်းဝင်ခြင်း ပြီးမြောက်ပါ |
| ဝင်ရောက်ချိန် 423「账户已锁定」 (အကောင့် သော့ခတ်ထားပြီး) | စကားဝှက် ဆက်တိုက် 5 ကြိမ် မှား | မိနစ် 30 စောင့်ပါ |

## ဝင်ရောက်ခြင်း အသေးစိတ် အနည်းငယ် (အမှားရှာရန် တွဲသုံးနိုင်)

ဝင်ရောက်ခြင်းသည် **အသုံးပြုသူအမည် / အီးမေးလ် / ဖုန်းနံပါတ်** သုံးမျိုးလုံး တစ်နေရာတည်းတွင် ထည့်နိုင်သည် (မည်သည့်တစ်ခုမဆို အကောင့်အမည်အဖြစ် သုံးနိုင်သည်) ။
စကားဝှက် မေ့ပါက- ဝင်ရောက်စာမျက်နှာ → "စကားဝှက် မေ့ပြီ" → စာရင်းသွင်းထားသော အီးမေးလ် ထည့်ပြီး ဂဏန်း 6 လုံး အတည်ပြုကုဒ် ရယူပါ → ပြန်သတ်မှတ်ပါ။
