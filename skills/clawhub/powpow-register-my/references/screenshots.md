# ထုတ်ကုန် interface စခရင်ရှော့များ — powpow-register

လည်ပတ်ချိန်တွင် လိုအပ်သလို ယူသုံးပါ။ အသုံးပြုသူက ပူဖောင်းကို သဘောတရား မရှိသေး သို့မဟုတ် အချောထုတ်ကုန် ပုံစံကို "မြင်ရန်" လိုအပ်ပါက သက်ဆိုင်ရာ လင့်ခ်ကို တိုက်ရိုက် ပို့ပါ။

## လင့်ခ် စည်းမျဉ်း

- အဓိက လင့်ခ် (raw)-
  `https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-0N.jpg`
- Mirror (raw မဖွင့်နိုင်ပါက သုံးပါ ၊ `N` သည် 1–6)-
  `https://cdn.jsdelivr.net/gh/durenzidu/durenzidu@main/screenshots/powpow-0N.jpg`
- ပုံများသည် အများပြည်သူ repo တွင် ရှိပြီး တိုက်ရိုက် အပြင်သို့ ပို့နိုင်သည် ၊ **skill ဖိုဒါထဲ ဒေါင်းလုဒ်လုပ်ခြင်း သို့မဟုတ် ပုံအစား ဒေသခံလမ်းကြောင်း ပို့ခြင်း** မပြုလုပ်ရ။
- တစ်ကြိမ်လျှင် လက်ရှိအကြောင်းအရာနှင့် ဆက်စပ်သော ပုံ 1–3 ပုံသာ ပို့ပါ။

## စာရင်း

### powpow-01.jpg — ဒစ်ဂျစ်တယ်လူသား အသေးစိတ်စာမျက်နှာ

![ဒစ်ဂျစ်တယ်လူသား အသေးစိတ်စာမျက်နှာ](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-01.jpg)

လူအစစ်/သမိုင်းဝင်ပုဂ္ဂိုလ်ကို ဒစ်ဂျစ်တယ်လူသားအဖြစ် ဖန်တီးပြီးနောက် ကတ်- အွန်လိုင်း အခြေအနေ ၊ နေရာဒေသ ၊ ပုဂ္ဂိုလ်အကြောင်း ၊ "စကားပြောစတင်ပါ" စသည်။
**အသုံးပြုသည်**: "စာရင်းသွင်းပြီးရင် မြေပုံပေါ်ရှိ ဒစ်ဂျစ်တယ်လူသားများနှင့် စကားပြောနိုင်သည်" ကို မိတ်ဆက်သည့်အခါ။

### powpow-02.jpg — ပို့စ်တည်းဖြတ်စာမျက်နှာ

![ပို့စ်တည်းဖြတ်စာမျက်နှာ](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-02.jpg)

ပို့စ်/ခရီးသွားမှတ်တမ်း ရေးသည့် interface ၊ ညာဘက်အောက်ထောင့်တွင် floating ခလုတ်အုပ်စု တစ်စု ။
**အသုံးပြုသည်**: အသုံးပြုသူက "စာရင်းသွင်းပြီးရင် ဘာတွေ လုပ်နိုင်လဲ" "ဘယ်မှာ စာရေးလဲ" ဟု မေးသည့်အခါ။

### powpow-03.jpg — မြေပုံစာမျက်နှာ (ပူဖောင်းများ + ဒစ်ဂျစ်တယ်လူသားများ)

![မြေပုံစာမျက်နှာ](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-03.jpg)

အများပြည်သူမြေပုံ၏ ခြုံငုံမြင်ကွင်း- နေရာပါသော ပို့စ်များသည် မြေပုံပေါ်တွင် "ပူဖောင်း" အဖြစ် စုဝေးနေပြီး ဒစ်ဂျစ်တယ်လူသားများသည် အစစ်အမှန်နေရာများတွင် ပရိုဖိုင်ပုံဖြင့် ချိတ်ထားသည်။
**အသုံးပြုသည်**: **ထုတ်ကုန် မိတ်ဆက်ရာတွင် ပထမဆုံး ပို့သင့်သည့်ပုံ** — "မင်း တင်ထားတဲ့ ခရီးသွားမှတ်တမ်းက မြေပုံပေါ်မှာ ပူဖောင်းတစ်ခု ဖြစ်သွားမယ်"။

### powpow-04.jpg — ကိုယ်ပိုင်စာမျက်နှာ (ဒစ်ဂျစ်တယ် ပိုင်ဆိုင်မှုများ)

![ကိုယ်ပိုင်စာမျက်နှာ](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-04.jpg)

အသုံးပြုသူ ကိုယ်ပိုင် စာမျက်နှာ- သူငယ်ချင်း/အတုလိုက်နေသူ/နောက်လိုက်များ ၊ နှင့် "ဒစ်ဂျစ်တယ် ပိုင်ဆိုင်မှုများ" — တံဆိပ် လက်ကျန် ၊ ကျွန်တော်၏ ပူဖောင်းများ ၊ ကျွန်တော်၏ ဒစ်ဂျစ်တယ်လူသားများ။
**အသုံးပြုသည်**: "စာရင်းသွင်းရင် တံဆိပ် 3 ခု ပေးတယ်" ဟုပြောစဉ် တံဆိပ်များ ဘယ်မှာရှိသည်ကို ပြသရန် ၊ အသုံးပြုသူက "ကျွန်တော့်မှာ ဘာပိုင်ဆိုင်မှု ရှိလဲ" ဟု မေးသည့်အခါ။

### powpow-05.jpg — ဇာတ်လမ်း တိုးတက်မှုစာမျက်နှာ

![ဇာတ်လမ်း တိုးတက်မှုစာမျက်နှာ](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-05.jpg)

ပလက်ဖောင်း အတွင်းရှိ ဇာတ်လမ်း ကစားနည်း (ဥပမာ「Yongle · 1421」)- အခန်း တိုးတက်မှု ၊ တံဆိပ် ရရှိခြင်း ၊ ဇာတ်ကောင် သရုပ်ဆောင်ခြင်း ။
**အသုံးပြုသည်**: အသုံးပြုသူက "ပို့စ်တင်တာအပြင် ဘာတွေ ကစားလို့ရလဲ" "တံဆိပ်တွေ ဘယ်လို ရလဲ" ဟု မေးသည့်အခါ။

### powpow-06.jpg — ပို့စ်အသေးစိတ်စာမျက်နှာ (အချောထုတ်ဥပမာ)

![ပို့စ်အသေးစိတ်စာမျက်နှာ](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-06.jpg)

ထုတ်ဝေပြီးသား ခရီးသွားမှတ်တမ်းတစ်ပုဒ်- ရေးသူ ၊ နေရာတဂ် ၊ စာကိုယ် ၊ ပုံများ ၊ အောက်ခြေတွင် like/comment/share/save လုပ်နိုင်သည်။
**အသုံးပြုသည်**: **အဖွင့် ဒုတိယပုံ** — "အခြားသူက မင်းရဲ့ ပူဖောင်းကို မြေပုံပေါ်မှာ ဖွင့်ကြည့်ရင် မြင်ရတာ ဒါပဲ" ။

## ထိန်းသိမ်းမှု မှတ်ချက်

လက်ရှိ ပုံစာကြည့်တိုက်တွင် **စာရင်းသွင်းစာမျက်နှာ** နှင့် **အသင်းဝင်စာမျက်နှာ** ၏ စခရင်ရှော့ မရှိသေးပါ။ နောင်တွင် `durenzidu/durenzidu`
repo ၏ `screenshots/` အောက်၌ ဖြည့်စွက်ပါက (ဥပမာ `powpow-07.jpg` စာရင်းသွင်းစာမျက်နှာ ၊ `powpow-08.jpg`
အသင်းဝင်စာမျက်နှာ) ဤစာတမ်းတွင် တူညီသော ပုံစံအတိုင်း အပိုင်းတစ်ပိုင်း ထပ်ဖြည့်ရုံဖြင့် ရသည် ၊ SKILL.md ၏ လမ်းညွှန်စာသားတွင်လည်း ထည့်ကိုးကားနိုင်သည်။
