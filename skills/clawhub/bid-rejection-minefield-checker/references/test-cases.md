## 回归抽样依据（KB `7460608999968055`）
- 真实样本模板：`[项目名] - 否决投标记录` → 项目信息(名称/时间/来源/原文链接) + N 个投标人(名称/否决依据条款/否决理由)。
- 📌 **这类记录即路径 B「类型②」天然输入**：其逐家"投标人名称 + 否决依据条款 + 否决理由"可直接读取、分型（竞争性淘汰 vs 合规否决）后做雷区归类，输出"真实命中"，无需用户另传完整招标文件（类型①）。
- 条款定位精确（如 P14 投标人须知前附表第 10.4 条），支持证据锚定定位。
- 库按省分文件夹，各省样本量极不均衡（四川 7613 / 青海 8663 / 宁夏 2513 / 河北 2483 / 湖南 225 / 重庆 316；甘肃/陕西/西藏等多省仅 1 条）。
- 检索结果每条带 `parent_folder_id`（非空），无 `parent_folder_name`；省份须映射后硬过滤。
- 否决理由多样：低于成本、保函未响应、业绩不足、未提交投标函封面、信用双表缺失、资质无效、报价未保留两位小数、社保证明问题、暗标盖章违规等。
