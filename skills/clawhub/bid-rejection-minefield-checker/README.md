# 投标否决雷区体检（bid-rejection-minefield-checker）

> 服务于投标人：输入一个项目，输出一份投标风险体检报告——告诉你历史上同类项目都在哪些招标文件条款上死过人，以及你这份招标文件里对应的雷区位置在哪。

## 它能做什么
- **按省检索**历史否决案例（数据来自 `招投标评标否决AI知识库`，KB `7460608999968055`，约 1.9 万条，按省分文件夹）。
- **行业同义词扩张**：自动扩展行业词的上下位词与同义词（如"房建"→住宅/公建/商业楼宇），OR 拼接召回，避免官方表述不一致导致漏检。
- **双路比对**：历史高频雷区 × 你当前招标文件条款，逐条定位。
- **路径 B 双输入源**：既支持上传完整招标文件（抽取否决投标条款坐标映射），也支持上传本项目否决记录 / 评标报告（直接读取逐家投标人 + 否决依据条款 + 理由，输出"真实命中"）；竞争性淘汰（如评分未进前 N 名）严格单列，绝不计入雷区命中。
- **证据锚定定位**：每条雷区精确到你文件的条款坐标，并附历史上在此"死过"的投标人名称与原文链接（表格最多 3 个，余者收束至溯源区）。
- **案例时间范围**：概要显式呈现召回案例的时间跨度，支持"近 N 年"过滤，便于判断政策时效性。
- **封标前自查表**：基于高频雷区生成可勾选清单。

## 三策略（核心方法论）
1. **双路比对**：路径A 历史召回 + 路径B 当前文件对照，映射命中。
2. **证据锚定定位**：精确条款坐标 + 历史伤亡证据（投标人名 + 原文链接）。
3. **禁止跨省排名**：检索 / 聚类 / 排序严格限定单一省份，绝不跨省聚合。

## 它明确不做（护栏）
- ❌ 否决率 / 占比 % / 价格分布 / 投标家数 / 重招概率（无数据字段，编造即幻觉）
- ❌ 评标专家偏好推断（无依据 + 合规风险）
- ❌ 具体报价数值建议（串标风险）
- ❌ 跨省排名（各省规则独立）
- ❌ 价格分析（属独立 Skill `bid-price-intelligence`，数据物理隔离）

## 输入
目标省份（必填）｜ 行业 / 工程类型（必填）｜ 采购方式（必填）｜ 金额区间（选填）｜ 项目名称（选填）｜ 招标文件（选填上传，触发双路比对）｜ 时间窗口（选填，近 N 年）

## 与现有技能的差异
- `bid-rejection-experience`：通用问答 + 数据采集（知识库层）
- 本技能：单项目投标前风险扫描（消费场景层），输出可打印体检报告，不抢其饭碗

## 强免责
历史案例 ≠ 未来项目结论；所有"次数"仅为本省样本观察，非全量统计、非占比；以招标文件与评标委员会认定为准。
