## Description:

Extracts actionable insights from any text: word counts, reading time, top keywords, sentiment score, and structure analysis.

This skill is ready for commercial/non-commercial use.

## Use Case:

Content teams, developers, and external users use this skill to analyze text for word and character counts, reading time, top keywords, simple sentiment, and content structure.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Confidential, regulated, credential-bearing, or proprietary text could be exposed if sent to the optional remote API endpoint.

Mitigation: Analyze sensitive content locally, or use only trusted and approved endpoints with appropriate data-handling controls.
