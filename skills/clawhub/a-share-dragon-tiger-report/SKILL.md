## 四、投资哲学底座（4 本成功蒸馏 · 决策前的"心法层"）

> 本章不产生数字阈值，只提供**判断纪律**；与 `KNOWLEDGE` 45 键的量化阈值互补。冲突时以六条口径与 45 键为准，哲学层只做"降权提醒/逆向校验"。第 5 本《走在曲线之前》因文本层抽取失败未纳入（见本章末缺口说明）。

### 4.1 《我从达尔文那里学到的投资知识》（纳兰达资本）—— 避免失败优先于追求成功

- **核心**：生物进化偏爱"不作为"——宁犯**第Ⅱ类错误（踏空）**，也不犯**第Ⅰ类错误（踩雷/接板被套）**。"规则1：永远不要赔钱；规则2：不要忘记第一条。"卓越投资者首先是**卓越拒绝者**。
- **纳兰达六大禁区（命中即剔除出候选池）**：骗子/治理劣迹 · 扭亏困局故事 · 高杠杆 · 并购成瘾 · **快速迭代行业** · 利益错位的所有者。对涨停板题材股，"快速迭代 + 利益错位"两条尤其相关。
- **质量锚**：F = 历史 ROCE = EBIT ÷（净营运资本＋净固定资产），优中选优参考 **≥20%**（书中优质持仓历史中位约 42%）；客户集中度红线：前五大客户营收占比 >50% 视为稳健性恶化。
- **逆向择时**：纳兰达在系统性利空/股价"不利间断"时买入——三次危机中 **15% 的时间投入 46% 的资金**（疫情 3 个月占 2% 时间投入 22%）。极端恐慌日优先于连续涨停日。
- **卖出纪律**：唯一卖出理由 = 对企业失去信心；禁止"高卖低买 / 因为估值贵 / 因为有更便宜标的"（作者卖 Shree Cement 后涨 5 倍、损失 4 亿美元）。
- **反叙事**："所有糟糕的投资根源都是一个好故事"；团队**禁用"这次不一样"**；区分"已发生的事实"（可靠信号）与"对未来/研报的承诺"（廉价信号）。
- **与框架对齐**：一票否决项（连续两年亏损 / 半年归母≤0 / L2.5 不可交易 / 造假红旗≥2）即第Ⅰ类错误防线，触发即出局、不找理由豁免。

### 4.2 《周期、估值与人性》（凌鹏，中信出版 2023）—— 三轴交叉 + 人性反向

- **核心三原则**："周期、估值和人性"不变；传导链为**实体景气 → 估值投射 → 人性放大**。涨停板/龙虎榜恰处"人性放大"末端，须回溯前两者是否支持。
- **三轴交叉研判（每只候选必答）**：① **周期**——行业处 需求释放/量价齐升/渗透率放缓+产能释放/去产能 哪段？用"渗透率+资本开支+产能投放"判题材持续性；② **估值**——自身历史分位 + 与风格剪刀差，警惕"100 倍组合未见不回撤"、"贵是价值投资最大瑕疵"；③ **人性**——贪婪顶还是恐慌底，对照历史三次贪婪(2007.10/2015.5/2021.2)与三次恐慌(1664/熔断/2018底)。
- **阶段适应性**：17 年三阶段（"周期为王 / 成长致胜 / 茅宁共舞"）方法论不通用，禁止用上一阶段成功框架硬套当前行情。
- **科技题材定性**："一将功成万骨枯，科技投资胜率不高、赔率足够" → AI/科技题材默认**低胜率高赔率**，控制单笔仓位、预设退出。
- **与框架对齐**：任何"60 日大跌"先问分位是否已到低位（高位回调不是超跌，已固化进口径②）；情绪五阶段 + 反身性即"人性温度计"，见顶/退潮仓位压到 20%/0；"恐慌并不比狂热更理性"——暴跌同样需独立判断。

### 4.3 《数据化决策 2.0》（约恩·里塞根，Outside Insight）—— 外部数据挖趋势

- **核心**：内部数据（ERP/财报/盘面）有盲点；决策质量取决于**外部数据宽度**。"数字面包屑"——招聘广告泄露战略、官网/社媒透露焦点、专利/信用评级/诉讼、广告支出、新闻通稿"注脚"都藏信号。
- **可操作**：① 用同花顺题材归因 reason tags、北向分钟流、融资余额、股东户数、招聘/专利等"外部弱信号"**至少 2–3 类共振**才确认题材真伪；② 拒绝"去年 X+5%"式线性外推（书中案例用多因子外部模型把预测误差降低约 **15%**）；③ 领先指标优先于大众媒体确认；④ 数据缺口如实标注，不用猜测填满空白（对应"外部数据缺口·仅定性"）。

### 4.4 《2049 未来 10000 天》（凯文·凯利）—— 长期主义过滤噪音

- **核心**：无法精确预测未来，但可通过**大规模长趋势**揭示方向；"场景构建不是预测某个未来，而是预演以避免惊讶"。AI 是"未来世界的电力"，使用成本长期下降、算力需求"无穷"。
- **25 年关键词**：无形/透明/互见性/模拟/脱媒 + 信任/开源/定制/丰沛/酷——作为"长期确定性方向"清单，检验题材有无 10–25 年级产业逻辑。
- **反炒作**："最大最富有的公司是为镜像世界提供数据支持的公司"——真正大机会常在**隐形基础设施（卖铲子）**而非前台热点；"技术因不可见而成功"。
- **与框架对齐**：十五五 18 方向 / X-主题扩展的方向级判断以多年趋势为准，不被单日涨跌动摇；日频打板/低吸是战术层，须服从方向级战略判断；长期看好的方向出现短期超跌（分位≤25% + 额比≥1.0×）才是高赔率窗口；输出"多情景推演"而非单点目标价。

> **资料缺口说明**：附件《走在曲线之前》（埃利斯）PDF 为扫描/特殊编码，文本层抽取失败（仅得换页符），本版未将其列入可引用规则来源；如后续提供可复制文本版本再补入"常理预测周期"章节。此缺口不影响六条口径与 45 键阈值（均来自已成功蒸馏的语料）。

## 五、战略决策层（GCCEO 注入 · 让推理链可审计）

> 把研判从"数据罗列"升级为"有假设、有验证、有失败预演"的决策工程。GCCEO 五步框架嵌入研判流程，输出可审计的推理链。

### 5.1 Issue Tree（议题树）—— MECE 拆解当日核心问题

```
今日是否值得出手？
├── 宏观环境允许吗？（L0：风险标签 / α 折减 / 事件窗）
├── 情绪周期在哪一格？（五阶段 + 反身性 → 仓位上限）

├── 主线里有低位优质标的吗？（四层漏斗 + 交集）
└── 失败会怎样？（Pre-Mortem：若明日亏 5%，最可能的原因）
```

### 5.2 Pre-Mortem（事前尸检）—— 先假设失败，再倒推原因

出报告前强制自问："假设按本报告操作次日亏损 5%，最可能的三个原因是什么？"
标准清单：① 情绪见顶误判为发酵（连板率枯竭未识别）；② 把【预测】当【事实】（2027 展望驱动了买卖）；③ 高位回调误判超跌（chg_60d 大跌但分位仍高）；④ L2.5 漏检（ST/退市/净资产为负混入）；⑤ 造假红旗未扫描（科目接力）。预演结果写入第 12 页风险清单。

### 5.3 三情景规划（Scenario Planning）

每份报告给「升级 / 基准 / 失效」三情景（对应 v2.3 已有结构），但**主观概率只作风险开关，不单独触发调仓**（S07）。基准情形概率参考研报（55%），但标注为【主观概率】水印。

### 5.4 安全边际（Margin of Safety）

- 个股参考入场价须留 ≥30% 安全边际（相对估值锚/下 1/4 阈值），不满足则写"观察，无安全边际"。
- 打板许可连板率 <40% 时禁止打板（本身就是安全边际纪律）。

### 5.5 投行级估值锚（DCF / 可比 / PEG，GCCEO 域九）

- 成长股用 PEG：前向 PE ÷ (CAGR×100)，PEG<1 便宜、1–1.5 合理、>1.5 贵；A股成长股 PE 消化锚统一取 30×。
- 壁垒极深但 PEG>3 的标的，本质是"看涨期权"，归入 α 预算"种子层"（5–10%），不适用 PEG 框架。
- 周期股用 PB 锚（周期底 PB≤1.2、区间≤2.5），红利股用股息率价值线 ≥4.0%。

## 六、五维共振引擎（报告核心计算）

### 6.0 前置层：三轴研判 + 纳兰达否决（第四章哲学的执行落点）

```

4)【人性层｜cycle+darwin】贪婪顶还是恐慌底？是否因 FOMO/"这次不一样"想买？恐慌并不比狂热更理性
```

### 6.1 选股主链：四层漏斗 + L3 利润质量强否决（口径不变）

- **L1 行业层**：31 个申万一级行业全量算 3 年分位 / 区间位置 / 额比 / 放量月数；入池条件分位≤25%。「链」形态主题跳过 L1 否决权（口径⑤）。
- **L2 个股层**：L1 超跌池成分 + 三条固定跟踪池（AI 链 / 电力绿电 / 十五五 18 方向），逐只算分位 / 额比 / 放量月；入池条件分位≤25% 且额比≥1.0×。
- **L2.5 基础可交易性**：名称含退市/*ST/ST、成交额或换手率=0、PB<0 → 剔除并单列「不可交易清单」，**独立于 L3**。
- **L3 基本面层**：国资背景（偏好项非否决）/ 十大流通股东占比及变化方向 / 扣非净利润（半年口径）/ 增速红线（半年同比≤0 硬排除；>0 但不足上年增速 50% 减分）。
- **v2.3 利润质量强否决**：5 类红旗（净现比<0.5 连续两期 / 存货增速−营收增速>20pp / 应收增速−营收增速>20pp / 商誉÷净资产>30% / 扣非为负但归母为正）**≥2 条** → 标 `veto_suggest` 一票否决级人工复核；单条只罚分不否决。
- **分层判定矩阵（固定 7 列）**：L1行业 / L2位置 / L2放量 / L2.5可交易 / L3盈利 / L3增速(半年) / 结论，逐只 ✔/✘/—。
- **结尾必须报告**：过会数量（允许为 0）、最接近 2–3 只及缺口阈值、**±1 只敏感度**。绝不为凑结论放宽标准。

## 十一、计算口径（23 条 + v3 补充，违反即结论反向）

1. 3 年历史分位 = count(近36月收盘<现价)/36；不得以区间位置替代。
2. "60 日大幅回撤"≠"回到低位"；chg_60d 与分位并列，高位回调须标注。
3. 额比用成交额(amount)不用成交量(volume)。
4. 月度比率剔除未走完当月 `amounts[:-1]`；分位/3 年低高**保留**当月（两层处理不可混用）。
5. 额比 = 近3完整月成交额均值 ÷ 前12完整月均值；放量月数 = 近3月高于基准期中位数的月数。
6. 下 1/4 阈值 = 3年低 + 0.25×(3年高−3年低)；还需跌% = (阈值÷现价−1)×100。
7. 筹码集中度看趋势：十大流通股东占比变化方向 + 股东户数变化方向；静态集中+动态分散=假集中。
8. 十大流通股东占比>85% 自由流通盘极小，放量阈值放宽到 1.15× 或改用换手率。
9. 指数分位与个股分位可完全相反；行业不在池内仍跑成分股，行业在池内龙头高位也单独跑。
10. "区间位置>95% 且额比<0.2×"互斥组合=数据失真，剔除并注明。
11. 半年净利率显著偏离行业常态（如软件 70%+）→ 疑含非经常损益，取 NPDeductNonRecurringPL 复核。
12. data_finance 字段坑：营收同比用 TORGrowRate（非 OperatingRevenueYOY）；归母同比 NPParentCompanyYOY；扣非 NPDeductNonRecurringPL；单季 NPParentCompanyYOY_Q。
13. 亏损年份：连续两年年报亏损才否决，单年减分并标注。
14. 增速口径统一**半年**（最近半年报归母同比），年度仅作对照；报告首页写死。
15. 位置信号优先读上一期 framework 缓存比较分位/额比变化方向。
16. 「链」形态主题默认跳过 L1 否决权；L1 只作"方向整体贵不贵"定性。
17. L2 与 L3 之间执行 L2.5 基础可交易性校验，输出独立于 L3。
18. 归母扭亏但扣非仍亏≠拐点；以扣非为准。
19. 历史不足 24 个月的新设板块不参与入池，标「†」。

### 18.1 工作流 A：当日主研判（18:00，本 skill 主链路）

**触发前提（硬性双关校验，缺一不出报告）**
1. 交易日判定：`data_trade_calendar` 返回 `isTrading=true`；非交易日直接说明休市并结束。
2. 收盘状态：① 当日龙虎榜数据非空（`date=报告日`）；② 上证分时末行时间标记 ≥ `1500`。

**流水线**（中间产物必须落盘，B 与「变化方向」跟踪都读它）

```bash
# ① 取数：31 行业月线 / 候选股月线+财务 / 龙虎榜 / 板块资金 / 情绪五要素
# ② 四层漏斗 L1→L2→L2.5→L3 + 五维评分 + 情绪五阶段（仓位 30/60/70/20/0%）
# ③ 装配 v3.0 只读覆盖层
python3 strategy/build_v3_inputs.py dragon-tiger-YYYYMMDD/data.json
# ④ 装配 v3.1 GCCEO 层（幂等，只写 data.gceo；--disable 即回 16 页）
python3 strategy/build_gceo_inputs.py dragon-tiger-YYYYMMDD/data.json
# ⑤ 渲染 + 三重校验（图表墨量 / 零溢出 / PDF 页数 == HTML 区块数）
bash templates/bii/render.sh --data dragon-tiger-YYYYMMDD/data.json \
     --date YYYY-MM-DD --out dragon-tiger-YYYYMMDD/v311 \
     --predict-file dragon-tiger-YYYYMMDD/predictions.json
```

**产物**：`data.json`、`predictions.json`（**固定 5 条**，每条含 `claim` + `falsify` + `target_date`）、
`framework/`（行业/个股/AI 链中间层）、BII 双栏 `18 页` HTML + PDF、`v3/`（16 页历史版）并存对照。

**三道必守闸门**
- **观察模式闸门**：漏斗过会 0 只时，BUY 一律降级 WATCH、α 账本清零、跟踪清单标题改
  「本期无过会标的 · 全池观察榜（不构成建仓清单）」。根因是 `basis = fr.l3_pass or data["candidates"]`
  回退全池打分会凭空造出 BUY 与"−3 只观察"的负计数。
- **小本金金额自适应**：`_money(v)` 在 `abs(v) >= 10000` 显示万元、否则显示元；`_used_up` 改用
  `used_pct >= alpha_budget * 0.98`，避免 7000 元本金显示「0 万」与「空仓却报额度打满」。
- **次新股失真防护**：月线不足 15 根时 `rank=0.0` 会被误判超低位满分，须标 `is_new_stock`、
  `tech/fib` 降为中性 50、`listed_days` 按真实交易日修正并带【次新股失真】水印。

**前 16 页结论零污染**：v3/gceo 装配只写顶层覆盖层，渲染器只在 v3 开启时追加第 15–18 页；
`PRED_PNO=14` 恒定，19:15 核验正则不受页数变化影响。

### 18.2 工作流 B：次日预判核验（19:15，复盘链路）

**链路判定（最容易错的一步）**：当期报告 `predictions.json` 的 `target_date` 是**次日**，当期不可核验 →
必须回溯**前一交易日**报告（其目标日 = 今天，已收盘）。仅交易日执行。

**定位预判按内容、不按章节号**：BII 双栏在第 14 页；历史样式 A 单栏用标题「五条可证伪预测」正则定位，
且样式 A 为 3 列（#/预测/证伪信号）、**缺独立「取数来源」列**，须如实标注覆盖完整度缺口。

**判定与输出**
- 逐条三态判定：命中 / 部分命中 / 未命中；含子条件的预判必须**分腿判定**（如"资金达标"与"个股二板"分开评）。
- 三层命中率：**口径 A**（含当日已验证项，5 条）／**口径 B**（纯 T+1 前瞻 4 条，**推荐**）／覆盖完整度。
- 偏差归因必写：价位锚点跨期失真、阈值过严、口径缺口、单位换算错误；不掩盖源报告缺陷。
- 技术位独立复算：MA5/10/20/60 与 BOLL(20,2) 用 70 根日 K 脚本复算，不手工转录。
- **预算规模换算**：预算可按用户要求提升（如 `¥700,000,000`），仅在「对新报告启示」中做容量敏感度对照
  （α 上限 15% = 1.05 亿、单票占日成交比、小票名义上限），**不改写任何历史预判判定**。
- 产物：`预判核验-由YYYYMMDD报告.md` + `.csv`（5 行 + 汇总行），镜像到被核验报告目录，
  `cmp` 字节一致，md5 登记；文末标注「下一期核验目标」为当期 `predictions.json`。
- **单位纪律**：`data_sector` 的 `mainNetInflow` 原始单位为**万元**，`÷1e4` 得亿元；误用 `÷1e5` 会整体缩 10 倍。

### 18.3 工作流 C：投资大师圆桌（20:00，独立专家包）

**归属**：`investment-masters` Expert（圆桌主编伍贤聚 + 巴守值/芒思远/林知行/段行简/李观澜五位大师）。
它是**观点层**，与 A 的量化漏斗、B 的复盘校验是三套独立体系，**不共用判定口径、不互相覆盖产物**。

**SOP**
1. **主题锁定**：「重新生成报告」等指令存在主题歧义时，先一次性确认（会话真实素材做成选项），
   避免 spawn 多位大师 + 实取数后返工。
2. **Phase 1.5 强制前置取数**：`westock-mcp` 实取大盘指数、市场画像（情绪/宽度/趋势/量能）、
   板块资金（当日/5日/20日）、代表个股估值与资金，**同一份数据包**下发给全部席位。
3. **并行协作**：`TeamCreate` → 并行 spawn 五位大师，每人收到同一数据包 + **差异化切入角**
   （价值/逆向/成长分类/本分不为清单/文明购买力）→ `SendMessage` 回传第一人称产出。
4. **诚实约束**：未下发的字段（如增长率）标「待核实」，**不得编造**；不得用大师历史持仓给当日追高背书。
5. **汇编**：五人共识 + 核心分歧 → 写 body → `render.py` 套壳 → `embed_avatars.py` 内嵌头像 → HTML。
6. **收尾**：`shutdown_request` → 收齐 `shutdown_response` → `TeamDelete`；不要留下悬空任务 ID。

**验收**：4 大模块锚点齐 / 5 张第一人称 voice-card + 5 条金句 / 6 张头像内嵌且 **0 残留相对路径** /
**0 占位符残留** / 涨红跌绿配色正确 / 真实数据引用计数非空 / 可离线打开。
产物：`deliverables/investment-masters/YYYY-MM-DD/市场研判-投资大师报告.html`。

### 18.7 资金规模层（v3.1.2 · 预算到 7 亿的结构重构）

> 预算从 7000 元切到 **¥700,000,000** 时，约束性质整体改变：小本金是「买不起 1 手」，
> 机构级是「**装不下 / 冲击成本 / 单票占日成交比**」。因此这不是改数字，而是**按规模换报告结构**。

**触发闸门**：`context.equity`（或 `--equity` 覆盖）**≥ 1 亿元** → `_is_institutional()` 为真，
走机构级结构；否则**小本金路径逐字不变**（`_money()` 对旧金额的输出也不变）。

**数据契约**（`data.json` 顶层 `capital`，与 `v3` / `gceo` 平级，渲染器只读）：

```text
capital: enabled, equity, scale_tier, alpha_budget_pct, alpha_budget_yuan,
         single_name_cap_pct(0.01), participation_cap_pct(0.10),
         capacity_rows[{name, code, turnover_yi, cap_1pct_yi,
                        budget_share_pct, verdict}],
         caliber_diff, source, readonly_note
```

`capacity_rows` **必须由 `candidates.avg_turnover_20d`（westock 20 日均成交额，元）实算**，禁止手写：
`budget_share_pct = α额度 ÷ 20日均成交 × 100`；`cap_1pct_yi = 20日均成交 × 1%`。
容量分档：`<2% 可容纳` / `2–5% 需分批` / `5–15% 冲击成本偏高` / `≥15% 不可容纳`。

**结构重构落点**（本资金规模层**自身不增页**；全局页数随最外层开关为四态 20/18/16/14，见 §18.10）：

| 位置 | 小本金 | 机构级（≥1亿） |
|---|---|---|
| `_money()` | `7000元` / `0.21万` | `7.00亿` / `2.10亿`（三档：亿 / 万 / 元） |
| 图 8 `alpha_max` | `/1e4` 万元刻度 | `/1e8` 亿元刻度，刻度与柱内标签由「万」改「亿」 |
| 第 2 页 KPI | 「α 预算剩余 · 阶段预算」 | 「**α 可用额度 · 机构级 · 单票 ≤1% 名义**」 |
| **第 10 页主体** | 「α 预算：先定风险的额度」+ pq/impl 三条纪律 | 「**资金容量与执行约束**」+ 规模切换说明 + **容量表** + 【口径差异】水印 + 一条合并约束 |
| 第 10 页图注 | 「金额单位万元」 | 「金额单位亿元」+ 容量数据来源 |

**【口径差异】水印（必带）**：11-10 预判核验按阶段 II α 上限 **15% = 1.05 亿**；
本报告的 `risk.AlphaLedger` 阶段 II 为 **30% = 2.10 亿**。分母同为 7 亿、比例口径不同，
**绝对值不可直接比较**，报告只取容量方向结论，不得据此改写任何历史预判判定。

**只读边界（越界即拒）**：规模层只改**展示与容量约束**，
**不改四层漏斗、五维评分、情绪五阶段仓位、5 条预判、六条口径、`KNOWLEDGE` 45 键**。
2026-11-11 实测：7 亿下漏斗仍「候选 33 → 过会 0」，结论仍为**纪律性空仓**——
「规模不改判定」是硬契约，不得因本金变大就生成 BUY。

**页高护栏**：机构级第 10 页新增容量表后首轮实测 799px（超 5px）被 `verify_print.js` 拦下；
修法为表格 `font-size:10px;line-height:1.25` + 两条 impl 合并为一条 → 回到 **794px**。
后续若增加容量表行数，须重跑三重校验，禁止关闭阈值。

**2026-11-11 实算样例**（α 全额 2.10 亿占 20 日均成交）：中际旭创 217.16 亿 / **0.97%** 可容纳；
东山精密 92.91 亿 / **2.26%** 需分批；光洋股份 13.41 亿 / **15.66%** 不可容纳；
万科Ａ 7.75 亿 / **27.10%** 不可容纳（且被 L3 否决）；珀莱雅 2.81 亿 / **74.70%** 不可容纳。


### 18.8 选股源主口径（v3.2 · 从涨停找，不从超跌找）

> **修复背景**：报告名为「涨停板龙虎榜」，但 v2.3 四层漏斗的 L1/L2 是
> 「3 年分位 ≤25% + 额比 ≥1.0×」的**超跌反转 / 左侧低吸**判据。2026-11-11 实测进池的是
> 美容护理 / 房地产 / 食品饮料等 9 个冷门低位行业，而当日主线（通信设备 +130.17 亿 /
> 元件 +81.33 亿 / 半导体 +76.83 亿）与涨停梯队因高分位被整片挡在门外 → 过会 0。
> **选股源与报告名相反**，属方向性缺陷，不是阈值调参问题。

**开关**：`data.json.selection_mode = "limitup"`；其余值（含 `oversold`）走旧路径，
**逐字不变、可一键回滚**。`funnel.run_funnel()`、`RANK_LOW_THRESHOLD=25.0`、
`VR_THRESHOLD=1.0` 一字未改，`CALIBER_VERSION` 仍 v2.3；v3 14/14、GCCEO 23/23、
三态 14/16/18 在该补丁下全部保持；v4.0 叠加量化旁路后全局为四态 20/18/16/14，但本选股源旁路逻辑与回滚开关逐字不变、与量化层正交。

**数据契约**（`limitup` 顶层块，与 `v3` / `gceo` / `capital` 平级）：

```text
limitup: enabled, source, fetched_at, market{limit_up,limit_down,max_height},
         mainline_industries[{name,net_inflow_yi,pct}],
         pool[{code,name,change_pct,net_buy_yi,kind}],   # 涨停 且 龙虎榜净买>0
         divergence[...],                               # 涨停 但 净买<0（量价背离）
         readonly_note, caliber_diff
```

来源必须是 `westock-mcp data_lhb(date=报告日)` 全市场榜实取（`netBuyAmount` 单位元，
`÷1e8` 得亿元）；主线行业取 `data_sector` 当日主力净流入。**禁止手写、禁止编造**。

| 项 | 约定 |
|---|---|
| 主池 | 当日涨停 / 准涨停 且 龙虎榜净买 > 0 —— 「涨停且资金真进」 |

## 附录C.8 常见失败模式与陷阱

| 陷阱 | 症状 | 修法 |
|---|---|---|
| **提前触发（盘未收盘）** | 11:33 跑出报告：龙虎榜章节为空、涨停数严重偏低、成交额只有半天 | 交易日 **≠** 已收盘。见 §2 第 1 条的「收盘状态」关：须查当日 `lhb` 与 `minute` 末根 ≥1500 |
| 月线两套口径混用 | 报告之间分位/额比不可比 | rank/lo/hi **保留**当月；额比 **剔除**当月（`funnel.amount_ratio(amounts[:-1])`）|
| 用 `volume` 算额比 | 忽略价格因素 | 必须用 `amount`（成交额）|
| 字段名错位 | 同比找不到 | `data_finance` 营收同比 = `TORGrowRate`（**非** `OperatingRevenueYOY`）；归母同比 = `NPParentCompanyYOY` |
| 涨跌颜色 | 与海外习惯混淆 | 涨红 #C1272D / 跌绿 #1E8449（中国 A 股，两种样式都一样）|
| 半年 vs 年度 | 整批结论翻转 | 报告首页必须写死「半年口径」，并报告 ±N 只敏感度 |
| L2.5 与 L3 合并 | 把「不可交易」误报为「基本面不通过」 | L2.5 必须在 L3 之前，剔除结果**单独**列入「不可交易清单」|
| PPTX 复用旧数据 | 当日数据 vs 2026-09-11 硬编码混用 | v1.1 限制已知，v2.0 将 make_pptx 改造为函数式 API |
| **图表全空白（样式 B）** | 8 张 canvas 全白，但 `window.Chart` 正常、控制台报 `Unexpected token ','` 或 `s.slice is not a function` | 占位符拼出非法 JS → 整个 `<script>` 不执行。见 §12.3 坑 1 / 坑 2；生成器已内置 `node --check` 自检 |
| **PDF 导出静默无文件（样式 B）** | 脚本 exit 0 但 PDF 没落地、或只有 1 页空白 | 大 PDF 撞 WebSocket 消息上限 / 连到了 `about:blank` 标签。见 §12.3 坑 3 |
| **封面半出血** | 深色封面四周留白边 | `@page` 的 margin 会裁掉元素的负 margin —— 出血必须靠 `@page{margin:0}` + 页面自身 padding。见 §12.3 坑 4 |
| **纸张变 Letter** | PDF 是 612×792 而不是 A4 | 模板缺 `@page{size:A4 ...}`，`preferCSSPageSize` 无处可依，Chrome 按 locale 回退。→ 给样式 A 的数据版 HTML 补 `@page` |
| **表格空 `tbody` 但不报错** | 页数/溢出/墨量全绿，打开 PDF 才发现某张表是空的 | `rows` 被赋成 `[]` 而非 `list(items)`。几何判据对"内容为空"无感 → **改过页面结构必须目视抽查该页**。见 §12.3 坑 5 |
| **`set -e` 下 `[ -n "$X" ] && ARR+=()` 静默退出** | `render.sh` 传可选参数时脚本在生成前就退出、无任何输出 | AND 列表左侧为假导致整个列表返回非零。→ 改写成 `if [ -n "$X" ]; then ...; fi`。见 §12.3 坑 6 |
| **预判页定位失联（样式 B）** | 19:15 核验任务报"找不到预判节" | 第 14 页标题被改（换全角空格、改数字或量词）。→ 标题须字面保留 `9.1 次日（YYYY-MM-DD）5 条可证伪预判`。见 §12.8 |
| **BII 与 classic 结论分叉** | 同一天两份报告的过会数对不上 | L1 池误用了双条件（分位 **且** 额比）。→ L1 只判分位，额比归 L2 个股层。见 §12.10 修正 #1 |
| **表格行数无上限撑破版心** | 第 13 页页高超阈值数百 px | 跟踪清单行数不设上限（26 行）。→ `_MAX_WATCH = 11`（每行 ≈28px，版心最多容 11 行）。见 §12.10 修正 #5 |
| **产业主题股进不了 L2** | 18 个方向里只有 2 个能跳过 L1 | `CHAIN_THEMES` 名单与实际方向命名不匹配。→ 补齐 `六张网` / `新兴产业` / `未来产业` 等前缀词。见 §12.10 修正 #2 |

完整 11 项陷阱见 `docs/wealth-password-strategy.md` §10。
