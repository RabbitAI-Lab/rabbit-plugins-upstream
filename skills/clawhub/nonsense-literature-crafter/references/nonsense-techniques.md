# 废话文学手法库

以下是废话文学生成的核心手法，按需组合使用。

---

## 1. 同义反复 (Tautology)

**定义**：用不同的词语表达完全相同的含义，形成"A 就是 A"的结构。

**模式**：将原文关键词拆解为近义表达，重新组合后不增加任何新信息。

**示例**：
- 原文"好热" → "热，就是指气温达到了一个较高的水平，高温的表现形式就是让人感觉到热"
- 原文"好看" → "好看的本质就是视觉上令人愉悦，而这种愉悦感恰恰就是好看的标志"
- 原文"真香" → "香就是闻起来很不错，而不错的嗅觉体验就是我们所说的香"

**模板句式**：
- 「X 的本质/究其本质，就是呈现出 X 所应有的状态」
- 「X 这件事，说到底就是 X 本身」
- 「所谓 X，不过是以 X 的方式体现 X」

---

## 2. 因果倒置 (Causal Inversion)

**定义**：将结果说成原因，将原因说成结果，制造"A 导致 B，而 B 也导致了 A"的闭环。

**模式**：抓住原文中的两个相关现象，建立互为因果的关系。

**示例**：
- 原文"好热" → "热就热在气温不低，不低就导致了热"
- 原文"我好困" → "眼睛之所以闭着是因为你困了，而你之所以困了是因为眼睛睁不开"
- 原文"下雨了" → "地面湿了是因为下雨，而雨之所以落下来是因为地面需要被打湿"

**模板句式**：
- 「X 是因为 Y，Y 则是因为 X」
- 「X 导致了 Y 的产生，而 Y 的产生又反过来加剧了 X」
- 「之所以 X，正是因为 X 的结果就是 Y，而 Y 又无可避免地引向 X」

---

## 3. 循环论证 (Circular Reasoning)

**定义**：用结论本身来证明前提，形成逻辑上的无限循环。

**模式**：将原文陈述当成一个需要证明的命题，然后用该命题自身作为论据。

**示例**：
- 原文"我在吃饭" → "当我在吃饭的时候，说明我正在进食，而进食行为的存在就证明了我确实在吃饭"
- 原文"这个很贵" → "它之所以贵，是因为它的价格不便宜，而不便宜的东西往往被定义为贵"
- 原文"他很高" → "他高的原因在于他的身高超出了平均水平，而超出平均身高的人我们一般称之为高个子"

**模板句式**：
- 「当 X 的时候，说明 X 正在发生，而 X 的发生恰恰证明了 X 的存在」
- 「之所以说 X，是因为 X 满足了我们对于 X 的一切定义」
- 「如果我们承认 X 的特征就是 X，那么 X 无疑是典型的 X」

---

## 4. 无效修饰 (Ineffective Modification)

**定义**：添加看似深刻的形容词或修饰语，实际上没有改变任何含义。

**模式**：在关键词前后堆积"高大上"却空洞的词，如"不可否认地"、"在某种意义上"、"从某个角度来说"、"众所周知"、"正如大家所看到的"。

**示例**：
- 原文"我很累" → "不可否认地，在某种意义上来讲，我目前处于一个身体机能上的疲惫期，正如大家所看到的，这种状态下人会感到累"
- 原文"这菜好吃" → "从美食鉴赏的角度来看，这道菜在味觉层面毫无疑问地呈现出了美味应有的特质"
- 原文"路很远" → "从空间距离上讲，这段路在客观上确实具有相当的里程数"

**常用修饰词库**：
- 前置修饰：不可否认地、众所周知、从某种意义上说、究其本质、正如我们所知、在广义的层面上
- 后置修饰：这是无可争辩的事实、这是一个不争的现状、这体现了一种规律性

---

## 5. 宏大打比方 (Grand Analogy)

**定义**：用一个看似宏大但与原文信息量相同的比喻来解释原文。

**模式**：将简单现象比作宇宙规律、自然法则、人生哲理等宏大命题。

**示例**：
- 原文"今天好热" → "让人不得不感叹，果然是夏天该有的样子"
- 原文"手机没电" → "就像宇宙中的恒星终将熄灭，手机的电量也遵循着能量守恒的终极规律，用完即是它的宿命"
- 原文"堵车" → "这就像人生的道路一样，越是向前走，越会遇到停滞不前的时刻"

**常用比喻靶**：
- 自然规律（日出日落、四季更替、潮起潮落）
- 宇宙法则（熵增、相对论、量子态）
- 人生哲理（命运、宿命、选择、必然）
- 辩证关系（对立统一、量变引起质变）

---

## 6. 定义断言 (Definitional Assertion)

**定义**：用一个自创的定义来"解释"原文中的概念，但定义本身等于概念本身。

**模式**：宣告式地给出一个定义，让简单的陈述带上学术或哲学色彩。

**示例**：
- 原文"好烦" → "烦，在心理学意义上，是一种由外界刺激引发的内在不安定状态，而这种状态的外在表现就是我们所说的烦躁"
- 原文"想放假" → "放假，从劳动经济学角度来说，就是劳动者对于非工作时间的向往，这种向往本质上就是想放假"
- 原文"梦很奇怪" → "梦的奇怪，在某种程度上，恰恰是梦作为一种潜意识活动在意识层面的奇特投射"

**模板句式**：
- 「X，在 Y 学的意义上，就是 X 所呈现的状态」
- 「我们通常所说的 X，其实可以定义为：当 X 发生时，X 就发生了」
- 「从专业角度来看，X 是一种典型的 X 现象」

---

## 手法组合原则

1. **至少用 2 种手法**，通常 2-4 种，避免单薄
2. **衔接自然**：用"同时"、"不仅如此"、"更关键的是"、"说到根本"等过渡
3. **结尾升华**：最后一句用宏大打比方或哲理性总结收尾，形成"说了等于没说"的终极体验
4. **语气统一**：全程保持"一本正经讲道理"的腔调，不能突然变调侃或随意
