## 📦 这是什么？

做自媒体最累的不是写内容，是一个人要干一个团队的活。

这个 Skill 把一家 MCN 公司的 10 个核心岗位压缩成 10 个 AI 模块，安装一次，你就拥有：

| 模块 | 名称 | 解决的痛点 |
|------|------|-----------|
| ① | 选题策划 | 不知道写什么内容 |
| ② | 标题优化 | 标题没人点 |
| ③ | 内容写手 | 一稿要改5遍 |
| ④ | SEO优化 | 好内容没人搜到 |
| ⑤ | 视频导演 | 不知道怎么拍 |
| ⑥ | 封面设计 | 不会设计 |
| ⑦ | 社群运营 | 社群没人说话 |
| ⑧ | 数据分析 | 凭感觉发内容 |
| ⑨ | 商务报价 | 不知道报多少钱 |
| ⑩ | 排期管家 | 多平台发布累 |

## 🚀 快速上手

1. 在 [SkillHub](https://skillhub.cn/skills/one-person-mcn) 安装本 Skill
2. 用自然语言说出你的需求，例如：
   - "帮我想几个[领域]的选题"
   - "帮我写一篇小红书笔记，主题是XX"
   - "我有X篇内容，帮我排个发布计划"
3. 想做完整内容？说"帮我做一篇完整内容"，自动串联所有模块
