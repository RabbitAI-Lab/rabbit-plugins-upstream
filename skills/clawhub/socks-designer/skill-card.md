## Description:

Generates customized sock designs for print-on-demand and manufacturing, with support for reference images, text and logos, multi-view previews, and interactive 3D viewing.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ai-hub-admin](https://clawhub.ai/user/ai-hub-admin)

### License/Terms of Use:

MIT-0

## Use Case:

Designers, merchants, and developers use this skill to turn sock design briefs and reference images into customizable drafts and previews for print-on-demand or manufacturing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Design prompts, reference image URLs, and workspace data are shared with the remote design service.

Mitigation: Use the service only when comfortable sharing these materials; avoid confidential designs unless the provider is trusted.

Risk: The OneKey access key could be exposed if handled carelessly.

Mitigation: Keep the access key private and do not include it in shared prompts or design assets.

Risk: The example CLI invocation uses an unpinned package.

Mitigation: Prefer a pinned or otherwise verified CLI package before running it.
