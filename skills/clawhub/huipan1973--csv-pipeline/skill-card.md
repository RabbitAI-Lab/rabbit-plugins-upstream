## Description:

Process, transform, analyze, and report on CSV and JSON data files. Use when the user needs to filter rows, join datasets, compute aggregates, convert formats, deduplicate, or generate summary reports. Works with any CSV, TSV, or JSON Lines file.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and analysts use the skill to inspect, clean, transform, join, aggregate, and convert CSV, TSV, JSON, and JSON Lines data, then create summary reports.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Examples that write transformed data may overwrite an existing destination file.

Mitigation: Check whether the destination file already exists and choose a new output path if you want to preserve it.
