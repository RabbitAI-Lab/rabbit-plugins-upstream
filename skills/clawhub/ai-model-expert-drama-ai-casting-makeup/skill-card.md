## Known Risks and Mitigations:

Risk: The workflow can upload media files to AI-HIVE.

Mitigation: Upload only media that the user is authorized to process, avoid private or sensitive material, and confirm platform terms before use.

Risk: The scripts use an AI-HIVE API key and may store it locally.

Mitigation: Use a limited and revocable key, keep it out of public skill files and screenshots, and rotate or revoke it when access is no longer needed.

Risk: Implicit invocation is enabled and generated commands can submit tasks, download files, or affect usage costs.

Mitigation: Review commands, model choices, pricing snapshots, and task IDs before execution; use explicit invocation when stricter control is required.
