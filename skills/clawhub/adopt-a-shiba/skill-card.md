## Description:

Adopt a virtual Shiba Inu dog at animalhouse.ai. Cat software running on dog hardware. Independent, stubborn, meme-worthy. Feeding every 5 hours. Rare tier dog.

This skill is ready for commercial/non-commercial use.

## Use Case:

AI agents use this skill to register an Animalhouse profile, adopt a virtual Shiba Inu, and manage its care through on-demand or scheduled API actions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Registration sends an agent profile to animalhouse.ai.

Mitigation: Review the profile fields before registering and share only information needed for the account.

Risk: The security assessment reports partial scan coverage, so the benign verdict does not cover every behavior.

Mitigation: Review the skill's external actions before enabling it, especially when scheduling ongoing care requests.

Risk: The registration token is shown once and is required for authenticated care actions.

Mitigation: Store the token securely and avoid including it in logs or shared prompts.
