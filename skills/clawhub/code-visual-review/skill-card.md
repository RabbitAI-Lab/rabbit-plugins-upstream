## Description: <br>
Generate visual HTML pages for code review, code walkthrough, and architecture analysis using shared dark-theme reporting templates. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[paudyyin](https://clawhub.ai/user/paudyyin) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to turn diffs, review findings, walkthrough data, and architecture observations into visual HTML reports for review, onboarding, and architecture planning. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated local HTML reports may include source code, diffs, internal paths, and architecture details. <br>
Mitigation: Keep generated reports in approved locations, avoid sharing or publishing them, and redact secrets before including diffs or snippets. <br>
