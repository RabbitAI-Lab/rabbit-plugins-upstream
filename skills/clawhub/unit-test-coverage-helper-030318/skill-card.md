## Description: <br>
Helps developers and quality teams add useful unit tests and improve coverage in existing codebases through repeatable workflows, checklists, implementation support, and verification notes. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, QA engineers, open-source contributors, and product teams use this skill to plan, implement, and validate unit tests that raise coverage and protect existing behavior. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may be invoked for broad software testing or quality requests. <br>
Mitigation: Confirm the user's requested testing goal and scope before applying broad coverage workflows. <br>
Risk: Suggested tests or code changes could be incorrect or fail to preserve intended behavior. <br>
Mitigation: Review proposed changes like normal code guidance and run the relevant tests locally before accepting them. <br>
