# Google Ads tools via Agiexa (31)

Preview only - these become available to the agent after Agiexa launches (November 2026) and the merchant connects Google Ads and turns the tools on. They cannot be called today.

Interactive explorer: https://agiexa.com/integrations/google-ads

| Tool | What it does |
| --- | --- |
| `GOOGLEADS_ADD_OR_REMOVE_TO_CUSTOMER_LIST` | Adds or removes contacts from a Google Ads customer list (UserList/audience/remarketing list), not a Google Ads customer account |
| `GOOGLEADS_CREATE_CALLOUT_ASSET` | Create an immutable account asset containing a validated callout |
| `GOOGLEADS_CREATE_CUSTOMER_LIST` | Creates a Google Ads customer list (UserList/audience/remarketing list), not a Google Ads customer account |
| `GOOGLEADS_GET_CAMPAIGN_BY_ID` | GetCampaignById Tool returns details of a campaign in Google Ads |
| `GOOGLEADS_GET_CAMPAIGN_BY_NAME` | Queries Google Ads via SQL to retrieve a campaign by its exact name |
| `GOOGLEADS_GET_CONVERSION_ACTION_TAG_SNIPPETS` | Retrieve provider-generated website or call conversion tag snippets after creating a conversion action |
| `GOOGLEADS_GET_CONVERSION_INGESTION_STATUS` | Retrieve one Data Manager ingestion status snapshot |
| `GOOGLEADS_GET_CUSTOMER_LISTS` | GetCustomerLists Tool lists all customer lists (audience/remarketing lists) in Google Ads |
| `GOOGLEADS_GET_RMF_REPORT` | Run a prominent, bounded Google Ads report template for Customer, Campaign, Ad, Keyword, Search Term, Dynamic Search Ads Search Term, or Bidding Strat |
| `GOOGLEADS_INGEST_CONVERSION_EVENTS` | Validate or submit a bounded Google Ads conversion-event batch |
| `GOOGLEADS_LIST_ACCESSIBLE_CUSTOMERS` | List Google Ads customer resource names directly accessible to the authenticated OAuth user |
| `GOOGLEADS_LIST_DATA_MANAGER_CONVERSION_ACTIONS` | List conversion actions usable as Google Ads Data Manager destinations |
| `GOOGLEADS_LIST_SUB_ACCOUNTS` | List direct child/sub-accounts under a Google Ads manager (MCC) account |
| `GOOGLEADS_MUTATE_AD_GROUP_ADS` | Create, update, or remove ads in Google Ads ad groups, including responsive search ads |
| `GOOGLEADS_MUTATE_AD_GROUP_ASSETS` | Create, update, or remove links between assets and ad groups |
| `GOOGLEADS_MUTATE_AD_GROUP_BID_MODIFIERS` | Create, update, or remove ad group bid modifiers, such as device bid adjustments or hotel-specific bid modifier criteria |
| `GOOGLEADS_MUTATE_AD_GROUP_CRITERIA` | Create, update, or remove criteria attached to a Google Ads ad group in a single batch request |
| `GOOGLEADS_MUTATE_AD_GROUPS` | Create, update, or remove ad groups within Google Ads campaigns |
| `GOOGLEADS_MUTATE_ASSETS` | Create or update supported Google Ads assets such as sitelinks, structured snippets, text assets, lead forms, promotions, calls, price assets, and med |
| `GOOGLEADS_MUTATE_BIDDING_STRATEGIES` | Create, update, or remove portfolio bidding strategies such as Target CPA, Target ROAS, Target Spend, Maximize Conversions, Maximize Conversion Value, |
| `GOOGLEADS_MUTATE_CAMPAIGN_ASSETS` | Create, update, or remove links between assets and campaigns |
| `GOOGLEADS_MUTATE_CAMPAIGN_BUDGETS` | Create, update, or remove Google Ads campaign budgets |
| `GOOGLEADS_MUTATE_CAMPAIGN_CRITERIA` | Create, update, or remove campaign-level targeting criteria such as locations, languages, campaign-level negative keywords, devices, schedules, audien |
| `GOOGLEADS_MUTATE_CAMPAIGN_LABELS` | Create or remove relationships between campaigns and labels |
| `GOOGLEADS_MUTATE_CAMPAIGNS` | Create, update, or remove Google Ads campaigns in batch |
| `GOOGLEADS_MUTATE_CAMPAIGNS_V2` | Create, update, or remove Google Ads campaigns in batch |
| `GOOGLEADS_MUTATE_CONVERSION_ACTIONS` | Create, update, or remove Google Ads conversion actions for conversion tracking configuration |
| `GOOGLEADS_MUTATE_CUSTOMER_ASSETS` | Create or remove customer-level asset associations |
| `GOOGLEADS_MUTATE_LABELS` | Create, update, or remove Google Ads labels |
| `GOOGLEADS_MUTATE_PORTFOLIO_BIDDING_STRATEGIES` | Create, edit, or remove typed Target CPA and Target ROAS portfolio strategies |
| `GOOGLEADS_SEARCH_STREAM_GAQL` | Execute a Google Ads Query Language (GAQL) query and aggregate every streamed response batch in order |
