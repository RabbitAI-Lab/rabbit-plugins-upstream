## Description: <br>
Helps software maintainers, QA engineers, open-source contributors, and product teams add useful unit tests, raise coverage, and verify changes without breaking existing behavior. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, maintainers, QA engineers, open-source contributors, and product teams use this skill to plan, add, and validate practical unit tests for existing codebases. It is suited for workflows that need clearer regression protection, coverage improvement, implementation guidance, checklists, or verification commands. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger wording may select the skill for general testing or code-quality requests. <br>
Mitigation: Confirm the requested outcome and constraints before applying the workflow, and ask only for missing details that materially affect the result. <br>
Risk: Generated tests or code changes may encode incorrect assumptions or provide misleading coverage. <br>
Mitigation: Review proposed tests and run the relevant verification commands before merging or relying on the result. <br>
