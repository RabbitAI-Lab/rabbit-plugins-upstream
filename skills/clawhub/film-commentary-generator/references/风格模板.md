# 风格模板参考

## 一、搞笑风格

### 核心策略
以「吐槽 + 夸张 + 解构」为核心，把严肃剧情消解为笑点。

### 语气特征
- 轻松调侃、网络化语言、节奏快
- 大量使用感叹句、反问句、夸张类比
- 常用句式："注意看""万万没想到""这你敢信？""导演你是认真的吗？"

### 文案结构模板
```
[钩子] 史上最离谱的电影来了，看完我直接笑到邻居报警！
[背景] 故事要从男主角 XX 说起，他这个人吧，emmm...
[吐槽点1] 导演可能觉得观众是傻子，这个逻辑简直比我家猫还离谱
[吐槽点2] 这里我实在绷不住了，你们感受一下...
[神转折] 但更绝的是...
[结尾] 看完我只想说：导演，收下我的膝盖！
```

### 语言技巧
- **反讽法**："真是太感人了（其实很搞笑）"
- **对比法**："这演技，奥斯卡欠他一个..." 接大反差
- **cos/二次元梗**："这操作比鸣人的影分身还离谱"
- **生活化类比**："像极了周末被老妈叫起床的你"
- **弹幕式吐槽**：插入"弹幕护体""前方高能"等词汇

### 节奏控制
- 每 5-10 秒必须有一个笑点或吐槽
- 语速偏快，约 180-220 字/分钟
- 多用短句、断句，节奏利落

### 适配作品
- 烂片/雷片（最出效果）
- 经典老片（反差感强）
- 逻辑硬伤的商业片

## 二、深度风格

### 核心策略
以「主题挖掘 + 人性剖析 + 社会隐喻」为核心，让观众觉得看完有收获。

### 语气特征
- 沉稳有力、思辨性强、金句密度高
- 适当引用导演原意、原著对比、影史对照
- 常用句式："这部作品表面讲的是...实际上...""当我们透过现象看本质..."

### 文案结构模板
```
[钩子] 你以为这是一部 XXX 片？其实它藏着一个时代的密码。
[引入] 这部作品诞生于 XX 年，当时的背景是...
[主题1] 第一个层面：这是一个关于...的故事（表层叙事）
[主题2] 第二个层面：它真正在讨论的是...（深层隐喻）
[主题3] 第三个层面：放在今天看，它依然在拷问我们...
[人物] 最有意思的是 XX 这个角色，他的选择代表了...
[结尾] 所以，这不仅仅是一部电影，更是一面镜子。
```

### 语言技巧
- **设问法**："是什么让一个人甘愿放弃自由？"
- **递进法**："不只是...更是...最终是..."
- **引用法**：适当引用导演访谈、原著对比
- **对比法**：同类电影/社会现象对比
- **金句结尾**：提炼 1-2 句可传播的核心观点

### 节奏控制
- 语速适中偏慢，约 140-160 字/分钟
- 适当留白，给观众思考空间
- 关键观点前可停顿 1-2 秒

### 适配作品
- 奥斯卡获奖片 / 三大电影节影片
- 社会议题电影（阶级、种族、性别等）
- 导演风格强烈的作者电影
- 经典文艺片

## 三、悬疑催泪风格

### 核心策略
以「情绪递进 + 悬疑保持 + 情感爆发」为核心，让观众又哭又烧脑。

### 语气特征
- 代入感强、情绪起伏明显、声线有层次
- 悬念处压低声音制造紧张，情感爆发处释放
- 常用句式："你以为你猜到了？不..." "真相其实是...""看到这里我泪崩了"

### 文案结构模板（悬疑版）
```
[钩子] 这个故事从一开始就在骗你。
[悬念1] 第一个疑点出现了：为什么他说自己从来没见过那个人？
[推理] 到这里你可能觉得是 A 在撒谎，但等等...
[反转1] 原来真正的幕后黑手是...
[悬念2] 然而还没结束，最后三分钟才是全片最大的反转...
[高潮] 当真相揭晓的那一刻，我才发现前面所有细节都在暗示这件事
[结尾] 看过的人都不敢看第二遍，因为...（留悬念/升华）
```

### 文案结构模板（催泪版）
```
[钩子] 这是一部让我从头哭到尾的电影。
[铺垫] XX 和 XX 最初相遇的时候，谁也没想到命运会这样安排...
[情感累积] 他们一起经历了...（逐一铺垫催泪点）
[冲突] 直到那一天，一切都变了...
[泪点爆发] 当 XX 说出那句话的时候，我的眼泪直接掉下来
[升华] 也许这就是人生吧，有些遗憾，恰恰是最美的
```

### 语言技巧
- **悬疑留白**："但事情远没有那么简单..."
- **细节埋伏**："注意他第一次出场时的一个眼神"
- **情感共鸣**："如果是你，你会怎么选？"
- **反转金句**："你以为是喜剧，其实是悲剧"
- **BGM 暗示**："到这里配乐变了，说明..."

### 节奏控制
- 悬疑：前慢后快，信息逐层释放
- 催泪：前段铺陈中速，高潮处放缓
- 语速 150-170 字/分钟，关键处可压低至 120 字/分钟

### 适配作品
- 悬疑片 / 反转片
- 催泪爱情片
- 亲情/友情题材
- 犯罪心理片
