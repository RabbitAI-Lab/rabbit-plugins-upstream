## Description:

Identifies high-ranking pages with low click-through rates using the site's Search Console data and proposes title and meta description rewrites for review.

This skill is ready for commercial/non-commercial use.

## Publisher:

[minh42](https://clawhub.ai/user/minh42)

### License/Terms of Use:

MIT-0

## Use Case:

Site owners and SEO teams use this skill to find pages that underperform in clicks despite page-one rankings, assess competing search features, and review proposed snippet rewrites before approving any staged changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Connected Search Console and site page data may be sensitive.

Mitigation: Review the site's data access before connecting SEOmatic.

Risk: Staged edits could affect a business-critical site's search appearance after approval.

Mitigation: Review the exact proposed title and description for each task and approve only specific tasks you want applied.
