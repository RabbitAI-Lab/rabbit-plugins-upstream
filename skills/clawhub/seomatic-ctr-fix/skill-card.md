## Description:

Uses Google Search Console performance and search results to find underperforming page snippets and prepare title and meta description rewrites for approval.

This skill is ready for commercial/non-commercial use.

## Publisher:

[minh42](https://clawhub.ai/user/minh42)

### License/Terms of Use:

MIT-0

## Use Case:

SEO practitioners and site owners use the skill to identify pages with low click-through rates for their search positions, examine queries and search result features, and review evidence-based snippet rewrites. Where staging is available, proposed changes wait for user approval.

### Deployment Geography for Use:

Global
