# 评分卡与权重（Rubric）

> 本文件说明 `scripts/diagnose.py` 的打分逻辑，便于人工核对与调参。
> 每项准则打分 0–5，权重之和为 100；综合达标度 = Σ(得分×权重) / Σ(5×权重) × 100。
> 缺失字段 → 得分 None → 计入"待核实"，不计入分母。

## 四、红旗触发规则
**VC 红旗**：团队单薄且为早期 / 留存<40% / LTV_CAC<1 / Runway<6月 / TAM tier≤2 且非早期。
**政府红旗**：产业错配 / 无返投抓手 / 合规红线 / 无任何落地意向。
