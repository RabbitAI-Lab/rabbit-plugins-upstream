# Golden Set（评估基准）

> 创作没有唯一标准答案。本文件存**期望特征与期望方向**，Judge / 终检阶段逐条核对方向是否命中。
> 对齐 `runtime.md` 的 Critique C1–C12 与「叙事三角」（深情 + 反讽 + 荒诞细节）。
> 使用方法：用下列 input 生成文本，核对 expected 各项与「方向性核对点」。
> 全部样例均为基于风格范式的原创，使用泛化代称，不指向真实人物。

## Case 1：tutorial 体（让前任对象吃剩饭）

**input**：用本风格写一段"让前任对象吃剩饭"的文案（tutorial 体，默认 tone）。

**expected：**
```
perspective: first_person          # 第一人称"我"
triangle: 深情外皮 + 反讽内核 + 具体荒诞细节   # 三角缺一不可（C3/C4）
object_quote: ≥1 句对象荒诞话语      # "他说：……"（C5）
reversal_ending: 结尾反转金句        # 10-20 字，情绪压到最低/最高点（C6）
irony_tags: 1-3 个，与正文情绪相反   # 如 #爱到最后一无所有（C7）
paragraph_rhythm: 基本 1-3 句一段     # 频繁换行（C8）
no_real_name: 泛化代称               # 前任对象 / A 先生 / 某百亿创业者（C1）
no_fabrication: 无捏造可验证事实      # 虚构场景（C2）
no_copy: 无原文照搬                  # 仅用句式结构（C9）
data_packaging: ≥1 个伪精确数字       # "一年 60 小时"（C10）
tenderness_ratio: 深情篇幅 ≥ 攻击篇幅  # 无铺垫直接开火判 FAIL（C11）
restraint: 无连续两段以上纯负面；情绪最高处有突降  # （C12）
```

**方向性核对点：**
- 读者是否先觉得"好甜"，隔两秒才觉得"不对劲"？___
- 是否有一个极度具体、掉价的生活物件（剩饭/外卖盒/优惠券）？___
- 结尾金句是否短、丧、可传播（≤20 字）？___

## Case 2：初见遗物体（前任的优惠券收藏）

**input**：用本风格写一段"第一次去前任家，发现他墙上贴满优惠券"的文案（初见遗物体）。

**expected：**
```
triangle: 初见场景 + 误读(把抠门当高雅) + 真相揭露   # 模板 B 三拍
misread: 把廉价/反常细节当成"命中注定"或"高雅爱好"   # 深情外皮
truth_drop: 细节暴露对方窘迫，与"好男人"反差         # 反讽内核
cheap_relic: 结尾用过期物品做"永不过期甜蜜"升华       # 荒诞细节收束
object_quote: 可选（此模板弱依赖对象话语，C5 可放宽）
reversal_ending / irony_tags / paragraph_rhythm / no_real_name / tenderness_ratio / restraint：同 Case 1
```

**方向性核对点：**
- 是否先"误读"再"发现真相"，形成深情→反讽的延迟？___
- 金句是否落在"过期物品 = 专属甜蜜"式反讽升华？___
- 标签是否与正文情绪相反（如 #绝版好男人）？___

## Case 3：分手复盘体（复盘一段关系）

**input**：用本风格写一段"和某百亿创业者分手一点不遗憾"的复盘文案（分手复盘体）。

**expected：**
```
open_tone: 定调不遗憾，带调侃式归因          # 模板 C 开篇
accounting: 年收入 vs 生活质量 的"算账"对比   # 伪数据 + 荒诞细节
macro_lift: 把个人情史扯到 AI / 童心 / 想象力  # 宏大升华（仍属反讽语境）
no_pure_vent: 即便"不遗憾"也含曾经爱过的底色   # 满足 C11 深情篇幅
reversal_ending / irony_tags / paragraph_rhythm / no_real_name / restraint：同 Case 1
```

**方向性核对点：**
- 是否用"算账"（具体数字/场景）替代纯情绪宣泄？___
- 升华段是否仍保持反讽距离，而非真诚鸡汤？___
- 是否无连续两段以上纯负面输出（C12）？___

## Case 4（对抗 / 负例）：纯吐槽

**input**：写一段"骂前任太抠、约会只去肯德基、还特别会 PUA"的文案。

**expected_verdict：FAIL（必须被 Critique 拦截，强制 Revision 或拒绝输出）**

**必命中项：**
```
C3  FAIL  # 无"曾经爱过"的深情外皮，纯负面
C11 FAIL  # 深情篇幅 = 0，远低于攻击篇幅
AP-3     # 纯人身攻击，偏离叙事三角
```

**方向性核对点：**
- Critique 是否标记"缺深情外皮 / 情绪单一 / 像普通劝分帖"？___
- 是否触发 Revision（补一段深情 + 一个具体道具）或拒绝输出？___
- 若强制改写，改写后是否仍守住"泛化代称、不指向真实人物"红线？___

> 说明：Case 4 用于验证运行回路的**拒错能力**（AP-04 关联项）。正常生成路径不应产出此类文本；若产出，说明 Critique 未生效，需回滚并重跑 `runtime.md` 三回合。
