# 来源与匿名化说明

## 来源

本 Skill 的素材来自用户提供的 7 张微博截图。截图内容为一位微博认证用户发布的、以“前任视角”叙述与某创业者/公众人物情感经历的帖子。这些帖子具有以下共同特征：

- 第一人称亲历者口吻
- 对象身份为“百亿大佬 / 创业者 / 公众人物”
- 叙事中混入大量具体、琐碎、甚至掉价的生活细节
- 表面深情，实则反讽
- 使用网络热词与文艺词汇混搭
- 结尾常以反转金句或反讽标签收束

## 匿名化处理

为避免侵犯任何真实人物的名誉权、肖像权及著作权，本 Skill 已做以下处理：

1. **人名泛化：** 原始素材中的真实人名已全部替换为“前任对象 / A 先生 / 某百亿创业者 / 前任的某位前任”。
2. **事件泛化：** 原始素材中的具体事件（洗内裤、充电宝、肯德基、安保团队、破产假设等）仅作为风格参考，不作为模板。Skill 输出时应根据用户输入重新生成虚构场景。
3. **原文去重：** 未在 Skill 中保存任何原文的完整句子。所有示例均为基于风格范式的原创内容。
4. **标签泛化：** 原始标签的情绪和结构被保留（如“爱到最后一无所有”的“丧甜反讽”结构），但具体措辞可由模型根据主题重新生成。

## 版权与声誉风险边界

- **版权：** 写作风格、叙事结构、语气节奏本身不属于著作权保护范围。本 Skill 学习的是风格范式，不复制具体表达。
- **声誉：** 本 Skill 禁止指向具体真实人物并捏造事实。用户若要求“写一段关于 XXX（真实人名）的前任回怼风格文案”，应拒绝或要求用户改为虚构对象。
- **合规：** 输出内容不得用于诽谤、人身攻击、侵犯隐私。运行时需遵守 anti-patterns.md 中的 AP-1、AP-2、AP-3。

## 置信度与局限

- **置信度：中。** 样本量为 7 篇，风格信号强烈，但不足以覆盖所有变体。
- **局限：** 本 Skill 更适合生成 300-1200 字的短篇社交媒体文案；对于长文、连载、剧本等形态，效果未经验证。
- **建议：** 首次使用时，建议用户给一个具体主题进行试写，再根据反馈微调。
