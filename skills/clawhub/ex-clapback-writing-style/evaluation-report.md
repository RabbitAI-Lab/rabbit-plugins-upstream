## 主要问题与改进建议

1. **样本量局限：** 7 篇语料不足以覆盖所有变体。建议后续补充更多“前任视角 + 富豪对象 + 反讽”样本，特别是长文和评论区互动体。
2. **模板化风险：** tutorial 体权重过高，用户可能反复得到“和 X 学习”开头。可在 principles.md 中增加模板随机选择权重。
3. **Revision Gain 依赖人工：** 当前 runtime.md 要求模型自行执行 Judge，实际效果取决于模型能力。建议未来引入外部评估脚本或示例对比。
4. **声誉风险兜底：** 虽然已有 AP-1/AP-2，但运行时模型可能“忘记”。建议在 SKILL.md 中增加更醒目的拒绝触发词。
