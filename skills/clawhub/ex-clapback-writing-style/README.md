# 前任回怼写作风格（Ex-Clapback Writing Style）

> 一种「前任视角 + 反讽撒娇 + 富豪/创业者对象 + 日常荒诞细节」的社交媒体叙事风格 Skill。
> 表面深情款款，实则句句带刺，用小人物的琐碎反衬大人物的体面崩塌。

---

## ⚠️ 关于命名：什么是「回怼」

**「回怼」指的是回应姿态，不是语气浓度。**

它描述的是叙述者的立身位置——以一个「被消耗过、但已经走出来的人」的身份，回过头去接对方的话、拆对方的道具、把对方塞给你的荒诞原样奉还。是先认领了「我曾经在场」，然后才有资格还嘴。

它**不是**指语气更冲、骂得更狠、攻击性更强。恰恰相反：

| 误解（❌） | 正解（✅） |
|---|---|
| 回怼 = 火力全开地骂 | 回怼 = 先深情，再让深情自己塌掉 |
| 语气越冲越像 | 越克制越有杀伤力——情绪推到最高处后突然落到琐碎细节 |
| 目的是把对方说倒 | 目的是让读者自己反应过来，笑出声 |
| 可以省掉铺垫直接开火 | 没有深情外皮，就退化成纯人身攻击 |

**判据：** 一篇合格的作品里，深情段落的篇幅不应少于攻击性段落。读者读完应该先觉得「好甜」，隔两秒才觉得「不对劲」——这个延迟，就是回怼。

## 风格内核：叙事三角

每一篇合格作品必须同时压住三个角：

```
       深情
        /\
       /  \
      /    \
     /  反讽 \
    /________\
  荒诞细节
```

- **深情角：** 恋爱文学经典意象（丘比特、命中注定、一生一世、奔赴）。
- **反讽角：** 让读者意识到叙述者在「演」，对象的人设与细节形成反差。
- **荒诞细节角：** 一个极度具体、琐碎、掉价的生活物件或场景（内裤、充电宝、优惠券、外卖套餐）。

**原则：** 三个角缺一不可。缺深情 = 纯吐槽；缺反讽 = 纯娇妻文学；缺荒诞细节 = 空洞金句。

## 写作模板

| 模板 | 名称 | 适用场景 |
|---|---|---|
| A | tutorial 体（教程体） | 用户给了一个抽象主题，无参照文本 |
| B | 初见遗物体 | 用户描述了一次具体的初次见面 / 某件遗物 |
| C | 分手复盘体 | 用户要求复盘一段已结束的关系 |
| D | 流量课体 | 用户要求借某人的人设讲一个道理 |
| E | 读后感回应体 | 用户提供了另一篇文本，要求「回应 / 读后感」 |

> 详见 `style/principles.md`。

## 运行时判断回路

生成不是一次性的，必须执行 **Critique → Judge → Revision** 三回合：

1. **初稿生成**：按模板之一输出 V0。
2. **Critique**：对照 `anti-patterns.md` 逐项诊断（C1-C12）。
3. **Judge**：按五维度打分（风格保真 30% / 反讽甜度 25% / 细节具体度 20% / 节奏感 15% / AI 腔率 10%）。
4. **Revision**：综合得分 < 7.5 强制重写（最多 2 轮）。

**一票否决（C11 / C12）：**
- **C11 深情篇幅 ≥ 攻击篇幅**：深情段落字数不少于攻击性段落；无铺垫直接开火判 FAIL。
- **C12 克制度**：无连续两段以上纯负面输出；情绪最高处须有突降，否则 FAIL。

> 若 C11 或 C12 判 FAIL，无论其他维度多高，综合得分记为 < 7.5 并强制 Revision。
