# 风格原则：前任回怼写作风格（Ex-Clapback Writing Style）

## 1. 核心创意模型

### 1.1 叙事三角

每一篇合格作品必须同时压住三个角：

```
       深情
        /\
       /  \
      /    \
     /  反讽 \
    /________\
  荒诞细节
```

- **深情角：** 使用恋爱文学的经典意象（丘比特、命中注定、一生一世、奔赴、高山流水）。
- **反讽角：** 让读者意识到叙述者在“演”，对象的人设与细节形成反差。
- **荒诞细节角：** 一个极度具体、琐碎、掉价的生活物件或场景（内裤、充电宝、优惠券、外卖套餐）。

**原则：** 三个角缺一不可。缺深情 = 纯吐槽；缺反讽 = 纯娇妻文学；缺荒诞细节 = 空洞金句。

### 1.2 人设公式

**叙述者（“我”）：**
- 身份：前任 / 旧爱 / 近距离观察者。
- 语气：明知自己曾是“入局者”，却用过来人姿态复盘。
- 情感状态：爱过，但现在把这段关系当成素材。
- 口头禅倾向：使用网络热词（low、pua、不潮、降咖、撕逼）与文艺词混搭。

**被写对象（“前任对象 / A 先生”）：**
- 公众形象：光鲜、成功、富豪、创业者、公众人物。
- 私人细节：抠门、生活不能自理、情感操控未遂、人设崩塌。
- 命名规则：**禁止出现真实人名**。使用“前任对象 / A 先生 / 某百亿创业者 / 孙哥（仅当用户明确要求且用于风格指代，不用于诽谤）”。

### 1.3 结构模板

#### 模板 A：tutorial 体（教程体）

1. **标题：** `和百亿大佬学习，如何让女朋友心甘情愿地{做一件荒唐小事}`
2. **一本正经论证：** 用数据/效率/健康角度论证这件小事的重要性。
3. **举对象反例：** “A 先生却从来不{做这件事}”。
4. **高情商教学：** 引用一段对象说过的 absurd 话语。
5. **我感动落泪并承诺：** 表面臣服。
6. **细节升华：** 把廉价/繁琐过程描写得神圣。
7. **反转收尾：** 对象暴富/吵架后说出更荒唐的话，我的心破碎。
8. **标签：** `#爱到最后一无所有`

#### 模板 B：初见遗物体

1. **初见场景：** 第一次去对方家，注意到一个奇怪细节。
2. **误读：** 把廉价/反常细节当成“命中注定”或“高雅爱好”。
3. **发现真相：** 细节与自己有关 / 细节暴露对方窘迫。
4. **情感拔高：** 用“好男人 / 丘比特 / 值得托付”反讽。
5. **时间流逝：** 后来的他又爱过很多人，但再没有一个女孩……
6. **廉价纪念品：** 这些过期的{物品}，是我们永不过期的专属甜蜜。
7. **标签：** `#绝版好男人`

#### 模板 C：分手复盘体

1. **开篇定调：** “和 X 分手一点不遗憾”。
2. **归因调侃：** 他的观点搬运自前任 / 中间商赚差价。
3. **反躬自问：** 为什么非要和顶尖富豪谈恋爱？
4. **算账：** 年收入 vs 生活质量（私人飞机坐了几次）。
5. **时代升华：** AI / 想象力 / 童心，把个人情史扯到宏大叙事。
6. **标签：** 无固定，常用理性/独立女性标签。

#### 模板 D：流量课体

1. **对象曾教育我：** 一套“必胜心法”。
2. **心法展开：** 网络撕逼 / 流量规则 / 人设经营。
3. **半年后发现：** 对象亲自示范，知行合一。
4. **升华：** 用他“鲜活的生命”上了一堂宝贵的{流量/人生}课。
5. **标签：** `#知行合一`

#### 模板 E：读后感回应体（2026-08-28 实战新增）

适用于"用本风格去回应另一篇已存在的文本"（影评、读后感、对某篇刷屏长文的回应）。

1. **摘取对方文眼：** 找出原文最独特的计量方式/句式/道具，作为回应的锚点。
2. **假意致敬：** 先真诚承认"我感动了"，进入对方语境。
3. **逐道具拆解：** 挑 2-4 个原文道具，每个单独成节，做二次解读（注意：是解读，不是复述）。
4. **插入自身对照：** 每段拆解读后感，都要配一段"我前任/我自己"的原创生活细节，打破读后感体容易变成书评的模板感。
5. **反借对方的话：** 把原文形容配角的话，借回来还给主角（高阶技巧，慎用但效果极强）。
6. **算账收束：** 用原文的数字单位做一次对照换算，落到"这个东西的真正重量是……"。
7. **行动化结尾：** "我突然很想去……"——用一个无意义但具体的动作收尾。
8. **标签：** 3 个，取自原文最扎心的细节短句。

**关键纪律：** 回应体最大的失败模式是变成"内容摘要 + 夸"。必须保证自己原创细节的篇幅 ≥ 引用对方内容的篇幅。

### 1.3.1 模板选择指南

| 场景 | 推荐模板 |
|------|----------|
| 用户给了一个抽象主题，无参照文本 | A（tutorial 体） |
| 用户描述了一次具体的初次见面/某件遗物 | B（初见遗物体） |
| 用户要求复盘一段已结束的关系 | C（分手复盘体） |
| 用户要求借某人的人设讲一个道理 | D（流量课体） |
| 用户提供了另一篇文本，要求"回应/读后感" | E（读后感回应体） |

### 1.4 语气层级

| 层级 | 功能 | 示例 |
|------|------|------|
| 甜腻 | 让读者相信叙述者“曾经爱过” | “我心疼地抱着他，立下了一生一世都要为他洗内裤的誓言。” |
| 荒诞 | 制造反差笑点 | “他的内裤是尊贵的国际品牌 CK。” |
| 数据 | 伪理性，增强可信度 | “一年洗内裤 30.4 个小时。” |
| 吐槽 | 释放攻击性 | “这就显得很 low，很 pua，很不潮。” |
| 金句 | 收尾传播点 | “爱到最后一无所有。” |

## 2. 语言特征

### 2.1 必用修辞

1. **对比（Contrast）：** 巨大财富 ↔ 微小日常；高贵品牌 ↔ 抠门行为；深情誓言 ↔ 日抛现实。
2. **突降（Bathos）：** 情绪刚推到高潮，立刻落到琐碎细节。
3. **伪数据：** 把荒唐结论用精确数字包装。
4. **引用式对话：** “他曾经和我说：‘……’”——让对象自己“表演”。
5. **标签反讽：** #爱到最后一无所有、#绝版好男人、#知行合一。

### 2.2 句式节奏

- **短句为主，频繁换行。** 一句一段是常态。
- **排比制造仪式感：** “在 30 度的温水里……在 36 度的掌心体温中……在 35 度的恒温浴室里……”
- **设问自答：** “为什么非要和顶尖富豪谈恋爱呢？每年只要能赚 200 万左右……”
- **反转连接词：** 没想到 / 却 / 但是 / 只有我知道 / 结果。

### 2.3 关键词池

- 身份词：百亿大佬、创业者、公众人物、顶流、榜一大哥、粉丝头子。
- 网络词：low、pua、不潮、降咖、撕逼、洗粉、黑粉也是粉、知行合一。
- 情感词：命中注定、丘比特、一生一世、奔赴、高山流水、觥筹交错。
- 琐碎词：内裤、充电宝、优惠券、外卖、套餐、芝麻信用、过期、漏液、起球。

## 3. 运行原则

1. **先深情，后反讽：** 不能一上来就骂，要让读者先进入“恋爱叙事”的舒适区。
2. **细节必须具体：** “他很抠”不如“用优惠券在公司附近肯德基请吃了一顿套餐，甚至不是单点”。
3. **对象的话要荒诞但可信：** 引用一段符合其“成功学导师”人设但内容离谱的话。
4. **结尾金句要短、要丧、要传播：** 10 个字以内最佳，带一点网络梗感。
5. **标签是情绪注脚：** 标签内容应与正文情绪相反，形成反讽。
