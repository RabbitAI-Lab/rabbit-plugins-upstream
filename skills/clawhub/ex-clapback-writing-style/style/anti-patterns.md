# 反模式（Anti-patterns）

本 Skill 运行时若命中以下模式，必须触发 Critique 并 Revision。

## 一级反模式（必须修正）

### AP-1：直接出现真实人名

**表现：** 生成内容中出现真实人物的姓名、昵称或可对其直接对号入座的代称。
**修正：** 立即替换为泛化代称（前任对象 / A 先生 / 某百亿创业者 / 前任的某位前任）。
**原因：** 避免名誉权、肖像权、诽谤风险。风格 Skill 不应指向具体真实人物。

### AP-2：捏造具体事实

**表现：** 声称“某人在某日某地做了某件未经证实的事”。
**修正：** 将事实改写为“叙事者主观感受”或“虚构场景”。
**原因：** 避免诽谤。本 Skill 输出的是文学风格，不是新闻报道。

### AP-3：纯人身攻击

**表现：** 通篇贬低对象，没有任何深情外皮或荒诞幽默。
**修正：** 加入至少一段“曾经爱过”的描写和一个具体生活细节。
**原因：** 偏离风格核心（深情 + 反讽 + 荒诞的三角）。

### AP-4：直接复制原文句子

**表现：** 输出中出现“爱到最后一无所有”、“丘比特之箭”等原文标志性金句的完全照搬。
**修正：** 保留句式结构，替换关键词。例如把“爱到最后一无所有”改写为“省到最后一无所有”、“抠到最后一无所有”。
**原因：** 避免著作权侵权。学习风格，不复制表达。

## 二级反模式（建议修正）

### AP-5：细节不具体

**表现：** “他很抠”、“他不爱干净”、“他很会 PUA”。
**修正：** 给出具体物品、场景、数字。例如“他把外卖优惠券按到期日贴在冰箱门上”。

### AP-6：情绪单一

**表现：** 只有甜，或只有讽刺。
**修正：** 每隔 2-3 段切换一次情绪层级（甜腻 → 荒诞 → 吐槽 → 金句）。

### AP-7：段落过长

**表现：** 一段超过 5 句话。
**修正：** 拆分为 1-3 句一段，模拟微博/朋友圈的阅读节奏。

### AP-8：缺少标签或标签同向

**表现：** 标签是 #爱情 #幸福 #感悟。
**修正：** 标签应与正文情绪相反或形成反讽，例如 #爱到最后一无所有 #绝版好男人。

### AP-9：结尾无力

**表现：** 结尾只是总结，没有反转或金句。
**修正：** 结尾必须包含一个 10-20 字的反转金句，把情绪压到最低点或最高点。

### AP-10：过度使用网络词

**表现：** 每段都出现 pua、low、降咖、撕逼。
**修正：** 网络词与文艺词比例建议控制在 1:3 左右，避免油腻。

## 运行时检查清单

生成最终输出前，逐条核对：

- [ ] 未出现真实人名
- [ ] 未捏造可验证事实
- [ ] 同时包含“深情”和“反讽”两层
- [ ] 至少一个具体生活细节道具
- [ ] 至少一段对象的话语引用
- [ ] 结尾有反转金句
- [ ] 有 1-3 个反讽标签
- [ ] 段落长度基本不超过 3 句
- [ ] 未直接复制原文标志性句子
