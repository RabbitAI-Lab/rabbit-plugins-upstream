# 风格指纹（Style Fingerprint）

> 基于 7 张微博截图语料实际测量。真实人名与具体事件已做泛化，仅保留可量化的风格指标。

## 元信息

- **语料规模：** 7 篇中文社交媒体帖子
- **主题：** 前任视角下的富豪/创业者对象叙事
- **测量日期：** 2026-08-28
- **置信度：** 中（样本量小，但风格信号强烈）

## 量化指纹

| 维度 | 值 | 说明 |
|------|-----|------|
| **人称视角** | 第一人称 100% | 全部为“我”的亲历者口吻 |
| **叙述时态** | 过去时 + 现在点评 混合 | 回忆往事，并插入当下判断 |
| **段落平均长度** | 1-3 句 | 频繁换行，制造呼吸感 |
| **反讽密度** | 高（约每 80 字一次反转） | 甜→讽、崇高→琐碎、深情→吐槽 |
| **数据/数字使用** | 高 | 几乎每篇都有精确或伪精确数字 |
| **对话引用比例** | 中高 | 约 50% 的帖子直接引用对象或第三方话语 |
| **品牌/具体物品提及** | 高 | CK、Hello Kitty、肯德基、比特币、私人飞机等 |
| **网络热词密度** | 中高 | low、pua、不潮、降咖、撕逼、洗粉 |
| **文学/成语混搭** | 中 | 高山流水、觥筹交错、丘比特、命中注定 |
| **标签使用** | 每篇 1-3 个 | 标签内容与正文情绪相反 |
| **结尾方式** | 金句/反转 100% | 无开放式结尾 |

## 情绪曲线模式

```
开始：甜腻/崇拜（0-20%）
  ↓
中段：荒诞细节 + 误读（20-50%）
  ↓
转折：真相揭露 / 对象言行（50-70%）
  ↓
高潮：深情承诺 / 宏大升华（70-85%）
  ↓
收尾：反转破碎 / 金句（85-100%）
```

## 典型句式模板（可直接参数化）

### 开篇钩子

- `和{身份}学习，如何让{伴侣}心甘情愿地{做一件荒唐小事}`
- `第一次去{对象}家做客的时候，{一个反常细节}`
- `{对象}曾苦口婆心教育我，关于{某个领域}的必胜心法。`
- `和{对象}分手一点不遗憾，{一个调侃式归因}。`

### 中段铺陈

- `对于{身份}来说，{小事}是一件非常繁琐的事情。`
- `我以为他有{高雅爱好}，正想与他切磋一番。`
- `没想到他竟坦诚地和我说：{一句荒诞的话}。`

### 反转连接

- `没想到，他只是{一个更 mundane 的目的}。`
- `很多人以为{对象}是{光鲜理由}，只有我知道，他只是{脆弱理由}。`
- `结果{对象}请他{一个廉价场景}，{更具体的抠门细节}。`

### 深情-反讽切换

- `我心疼地{动作}，立下了{一生一世誓言}。`
- `和他在一起多少天，我就{做了多少件荒唐事}。`

### 收尾金句

- `之后，我的心，也跟着那些{廉价物品}一起，彻底破碎了。`
- `这些过期的{物品}，是我们永不过期的专属甜蜜。`
- `#爱到最后一无所有`

## 风格 Drift 警戒线

生成内容若出现以下特征，说明偏离风格：

1. 连续两段没有反转或反讽。
2. 没有出现具体生活细节道具。
3. 语气完全正面或完全负面。
4. 段落超过 5 句未换行。
5. 缺少标签或标签内容与正文同向。
