# 正例与负例

> 以下示例均为基于风格范式的原创示例，非语料原文。真实人名与具体事件已泛化。

## 正例

### 正例 1：tutorial 体（关于“让前任对象吃剩饭”）

```
和百亿大佬学习，如何让女朋友心甘情愿地吃他的剩饭

对于创业初期的成功男士来说，处理剩饭是一项非常考验情商的家务。
如果每天能省下 10 分钟思考“今天吃什么”，一年就能多出 60 个小时，
足够看完两季《纸牌屋》，并在下一次投资人饭局上说出“我对人性有深刻理解”。

A 先生却从来不碰剩饭。
他说：“真正高情商的男人，不会命令伴侣吃剩饭，而是让她自己发现剩饭的美味。”

于是他每天把外卖盒敞口放在桌上，让香气在 26 度的恒温客厅里自然发酵。
我推开门的那一刻，闻到的是爱，是包容，是“他心里有我”的味道。

我心疼地拿起勺子，立下了一生一世都要帮他清空冰箱的誓言。
他的剩饭是尊贵的黑松露和牛饭——虽然是我上周点的外卖。

和他在一起多少天，我就吃了多少顿隔夜饭。
后来 A 先生融资成功，再也不用吃剩饭了。
他在吵架时对我说：“以后我的剩饭，只喂狗。”

那一刻，我的心，
也和他那份发了霉的咖喱一起，
被彻底倒进了下水道。

#爱到最后一无所有
```

**符合点：** 教程结构、数据包装、深情→荒诞→反转、具体物品（剩饭）、标签反讽。

### 正例 2：初见遗物体（关于“前任的优惠券收藏”）

```
第一次去 A 先生家做客，我就看到他墙上贴满了五颜六色的优惠券。
我以为那是当代行为艺术，是他对消费主义的温柔反抗。
直到我发现，我上周买奶茶时“顺手”送他的第二杯半价券，也被他虔诚地贴在了 C 位。

这就是命中注定的感觉吗？
那一刻，我被丘比特的优惠券牢牢射中。

这是一个多么值得托付的男人。
很多男人只会说“我养你”，但真正愿意把每一张满减券都用到极致的男人，又有几个？

后来的他，又爱过很多人。
却再没有一个女孩，见过他手机里那一排排过期的团购券。
因为他的精打细算，再也凑不出一次原价约会的巨额支出。

这些泛黄的优惠券，
是我们永不贬值的专属甜蜜。

#绝版好男人
```

**符合点：** 初见场景、误读、品牌/物品具体化、时间流逝对比、金句收尾。

### 正例 3：分手复盘体

```
和 A 先生分手一点不遗憾，他最大的魅力就是活成了一个梗。
和他分手后，我直接和他的前任们组了个群，发现大家都是同款受害者，
只是中间商不同，差价各异。

丝毫没觉得，内心有哪一块缺失了。
为什么非要和公众人物谈恋爱呢？
每年只要稳定收入，生活质量根本差不了多少，
除了少了几次红毯合照，你一年到头也见不了几次他的真人。

随着 AI 技术的普及，情感劳动会越来越贵，
这是一个让想象力插上翅膀的时代。
请保持你的幽默感，和你这颗千金难买的童心。
```

**符合点：** 开篇定调、调侃归因、算账对比、宏大升华。

## 负例

### 负例 1：纯吐槽，缺少深情外皮

```
我前任太抠了，家里全是优惠券，约会只去肯德基，还特别会 PUA。
分手后我才清醒，这种男人根本不值得。
姐妹们擦亮眼睛！
```

**问题：** 没有“曾经爱过”的铺垫，没有具体荒诞细节，没有反转结构，像普通劝分帖。

### 负例 2：纯娇妻文学，缺少反讽

```
我前任是百亿大佬，虽然他工作很忙，但他对我特别好。
每次出差都会给我带礼物，我觉得自己是世界上最幸福的女人。
希望我们能复合。
```

**问题：** 完全正面，没有细节道具，没有反转，不符合本风格。

### 负例 3：空洞金句，缺少细节支撑

```
爱情就像内裤，洗多了会起球，不洗会发臭。
富豪的爱情更是如此。
爱到最后一无所有。
```

**问题：** 有金句和主题，但无具体场景、无对象话语、无数据/品牌细节，像鸡汤段子合集。

### 负例 4：段落过长，节奏拖沓

```
我和 A 先生在一起的时候，他经常让我做一些很奇怪的事情，比如每天要帮他整理袜子，还要按颜色分类，因为他觉得不同颜色的袜子代表不同的心情，而我作为他的女朋友，应该能够理解他的这种细腻情感，所以我每次都认真地帮他整理，虽然我觉得这有点离谱，但还是照做了。
```

**问题：** 一镜到底，无换行，无反转节点，读者无法呼吸。
