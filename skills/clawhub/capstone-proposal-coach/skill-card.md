## Description:

Capstone proposal coach: section frameworks, system diagram and task split, milestones with acceptance artifacts, zero-fabrication references, defense prep, AI declaration draft. Use when a student writes a project proposal, literature review, technical route, or timeline.

This skill is ready for commercial/non-commercial use.

## Publisher:

[liujycode](https://clawhub.ai/user/liujycode)

### License/Terms of Use:

MIT-0

## Use Case:

Students and supervisors use the skill to plan embedded engineering capstone proposals, organize literature supplied by the student, map technical work, set milestone artifacts, and prepare for proposal reviews. It provides coaching frameworks rather than a submission-ready proposal.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Institutional AI rules and proposal requirements may differ from the skill's general academic guidance.

Mitigation: Check the institution's current rules and proposal template, and confirm academic judgment calls with the supervisor.

Risk: Reference details or formatting could be incomplete or wrong.

Mitigation: Use only references supplied by the student and verify each source and citation against a scholarly database and the required citation style.
