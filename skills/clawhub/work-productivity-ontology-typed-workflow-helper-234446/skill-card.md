## Description: <br>
Helps AI-agent users and skill authors turn ontology-style productivity needs into practical workflows, artifacts, checklists, analysis, code changes, and verification notes. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
AI-agent users, skill authors, maintainers, and teams use this skill to clarify ontology-style productivity requests, create local-hardware-friendly workflows or artifacts, and validate the result against visible success criteria. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad activation wording may steer ordinary productivity or knowledge-work prompts into this workflow. <br>
Mitigation: Prefer explicit invocation by skill name for unrelated tasks and install it only when a general ontology/workflow planning helper is desired. <br>
Risk: Workflow outputs may include incorrect assumptions, code, configuration, or operational guidance. <br>
Mitigation: Review assumptions, limits, validation notes, and any generated code or configuration before use. <br>
