## Description:

Make faceless videos end to end with the PopNow API: topic to hook-first script, AI voiceover, matching B-roll images or clips, captions and a 9:16 or 16:9 cut for TikTok, Reels, Shorts and YouTube. Quotes every step in USD before spending. Use when the user wants faceless content, a YouTube automation video, a short explainer or a series of shorts.

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: Multi-step media generation can incur paid API charges.

Mitigation: Quote every planned step, get approval for the total before generation, and use a dedicated API key with model and spending limits.

Risk: Prompts, text and reference media URLs are sent to PopNow and the providers needed for generation; command parameters may also remain in host logs.

Mitigation: Avoid sensitive material and submit only content the user has rights to use.

Risk: Provider retention and server-side billing safeguards were not independently verified.

Mitigation: Use non-sensitive material and a dedicated key with spending limits.
