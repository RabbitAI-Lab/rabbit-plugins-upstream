## 三、方案评估矩阵

### 四维评估表

| 方案 | 新颖性(1-5) | 可行性(1-5) | 价值性(1-5) | 一致性(1-5) | 综合分 | 优先级 |
|-----|------------|------------|------------|------------|-------|-------|
| 方案1 | | | | | | ★★★ |
| 方案2 | | | | | | ★★★ |
| 方案3 | | | | | | ★★★ |
| 方案4 | | | | | | ★★★ |
| 方案5 | | | | | | ★★★ |

### 评估标准说明

| 维度 | 1分 | 2分 | 3分 | 4分 | 5分 |
|------|-----|-----|-----|-----|-----|
| **新颖性** | 已有成熟方案 | 有类似方案 | 局部新颖 | 大部分新颖 | 前所未有 |
| **可行性** | 当前无法实现 | 需要重大突破 | 需要较多投入 | 现有技术可做 | 立即可以实现 |
| **价值性** | 无明确价值 | 价值有限 | 有一定价值 | 价值明显 | 极具价值 |
| **一致性** | 大量外部引入 | 较多外部引入 | 部分外部引入 | 少量外部引入 | 完全内部资源 |

### 行动优先级判定

| 综合分 | 优先级 | 行动建议 |
|-------|-------|---------|
| 16-20 | P0 - 立即行动 | 启动原型开发，资源倾斜 |
| 12-15 | P1 - 重点推进 | 制定详细方案，申请资源 |
| 8-11 | P2 - 持续关注 | 列入创新储备库，择机启动 |
| 4-7 | P3 - 暂缓 | 记录存档，定期回顾 |
| ＜4 | 放弃 | 重新探索其他策略方向 |

## 四、创新工作坊流程模板

### 60分钟快速创新工作坊

```
## SIT创新工作坊

### 准备阶段（5分钟）
- ☐ 确定创新对象（系统名称）
- ☐ 准备白板/便签纸/工作表
- ☐ 确定参与人员

### 阶段一：系统分析（10分钟）
- ☐ 列出系统所有组件
- ☐ 列出系统所有属性
- ☐ 明确系统边界

### 阶段二：策略探索（30分钟，每种策略6分钟）
- ☐ 减法策略探索
- ☐ 除法策略探索
- ☐ 乘法策略探索
- ☐ 任务统筹策略探索
- ☐ 属性依存策略探索

### 阶段三：方案筛选（10分钟）
- ☐ 汇总所有方案
- ☐ 四维评估打分
- ☐ 选出Top 3方案

### 阶段四：行动规划（5分钟）
- ☐ 确定P0方案
- ☐ 分配责任人
- ☐ 设定下一步时间节点
```

## 五、属性依存矩阵构建工具

### 属性分类

**内部属性**（系统本身的属性）：
```
物理属性：颜色、大小、形状、重量、材质、温度、硬度、透明度
功能属性：速度、精度、容量、功率、频率、灵敏度
感知属性：气味、声音、触感、味道、视觉风格
经济属性：价格、成本、利润率、保质期
```

**外部属性**（系统环境相关的属性）：
```
用户属性：年龄、性别、职业、收入、位置、心情、健康状态
环境属性：时间、天气、季节、温度、光照、噪音
社会属性：流行趋势、节假日、政策法规、经济周期
使用属性：使用频次、使用时长、使用场景、使用人数
```

## 六、SIT工具包速查卡片

> 以下为可打印的速查卡片内容

### 卡片1：减法策略
```
┌─────────────────────────────┐
│     减法策略 (Subtraction)   │
│                             │
│ 操作：删除一个基础组件       │
│ 问：少了什么？还能用吗？     │
│ 价值：更简单、更便宜、更专注  │
│ 案例：无线耳机、无印良品     │
│ 关键：必须删除基础组件       │
└─────────────────────────────┘
```

### 卡片2：除法策略
```
┌─────────────────────────────┐
│     除法策略 (Division)      │
│                             │
│ 操作：拆分后重新组合         │
│ 问：拆开重组会怎样？         │
│ 价值：更灵活、模块化、可定制  │
│ 案例：遥控器、模块化手机     │
│ 方式：功能/物理/保留        │
└─────────────────────────────┘
```

### 卡片3：乘法策略
```
┌─────────────────────────────┐
│    乘法策略 (Multiplication) │
│                             │
│ 操作：复制+改变属性          │
│ 问：复制一个组件并改变它？    │
│ 价值：差异化、丰富选择       │
│ 案例：多摄手机、钟点房       │
│ 关键：必须改变属性！         │
└─────────────────────────────┘
```

### 卡片4：任务统筹策略
```
┌─────────────────────────────┐
│  任务统筹策略 (Task Unification)│
│                             │
│ 操作：让一个组件做更多事     │
│ 问：还能让它做什么？         │
│ 价值：一物多用、效率提升     │
│ 案例：Touch ID、扫码点餐    │
│ 关键：利用现有资源          │
└─────────────────────────────┘
```

### 卡片5：属性依存策略
```
┌─────────────────────────────┐
│  属性依存策略 (Attribute     │
│      Dependency)             │
│                             │
│ 操作：建立两个属性的关联     │
│ 问：当A变化时B会怎样？       │
│ 价值：智能化、自适应、联动   │
│ 案例：自动亮度、碰撞录制     │
│ 关键：打破不相关，建立关联  │
└─────────────────────────────┘
```
