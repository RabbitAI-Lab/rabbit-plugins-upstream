# SIT方法论详解

## SIT发展简史

### 起源
- **1990年代**：以色列学者Jacob Goldenberg、Roni Horowitz等人基于TRIZ理论，提出SIT（Systematic Inventive Thinking）
- **核心理念**：TRIZ虽强大但学习门槛高，SIT通过简化使其更适合商业和非工程领域
- **关键贡献**：提出"封闭世界"原则，将TRIZ的几十种创新原理简化为5种核心策略

### 与TRIZ的关系
| 维度 | TRIZ | SIT |
|------|------|-----|
| 起源 | 苏联，1946年，阿奇舒勒 | 以色列，1990年代 |
| 复杂度 | 高（40个创新原理+76个标准解） | 低（5个核心策略） |
| 学习门槛 | 高，需要系统培训 | 低，几小时即可掌握 |
| 适用领域 | 工程技术领域 | 商业、产品、服务等 |
| 核心原则 | 理想解、资源、矛盾 | 封闭世界、5种思维策略 |
| 量化程度 | 高（进化曲线、矛盾矩阵） | 低（定性分析为主） |

## 封闭世界原则详解

### 定义
封闭世界原则（Closed World Principle）要求：创新过程中，应尽量利用系统内部已有的组件和资源，而不是引入外部新元素。

### 为什么有效？
1. **成本更低**：利用现有资源，无需额外投入
2. **风险更小**：基于已有系统，用户接受度高
3. **执行更快**：无需重新开发新组件
4. **差异化更强**：竞争对手难以复制（因为每个系统的内部资源不同）

### 判断标准
| 级别 | 描述 | 示例 |
|------|------|------|
| ✅ 封闭世界 | 完全使用系统内部组件 | 给Home键增加指纹识别功能 |
| ⚠️ 部分封闭 | 使用系统内部组件+微调 | 在现有手机上增加一颗摄像头 |
| ❌ 开放世界 | 引入全新外部组件 | 给手机增加一个投影仪 |

### 常见误区
- 误区1：封闭世界 = 不做改变（❌ → 封闭世界是"利用现有资源做新事情"）
- 误区2：封闭世界 = 不能引入新技术（❌ → 可以使用新技术来实现封闭世界的想法）
- 误区3：封闭世界就是"保守"（❌ → 封闭世界往往产生最激进的思想实验）

## 五种策略的心理学基础

### 1. 减法策略
- **认知原理**：人类对"缺失"有天生的敏感（厌恶损失）
- **心理机制**：当熟悉的东西被移除，大脑会自动寻找替代方案
- **为什么有效**：打破"功能固定性"思维定式

### 2. 除法策略
- **认知原理**：人类倾向于将事物视为整体（格式塔心理学）
- **心理机制**：拆分后重新组合，激活新的神经连接
- **为什么有效**：打破"整体性思维"的固着

### 3. 乘法策略
- **认知原理**：对人类来说，相似但不相同的东西最能吸引注意力
- **心理机制**：差异化的复制品触发大脑的"模式识别"和"异常检测"
- **为什么有效**：在熟悉中创造陌生感

### 4. 任务统筹策略
- **认知原理**：人类倾向于"一个东西一个功能"（功能固着）
- **心理机制**：赋予新任务时，打破"功能固着"
- **为什么有效**：一物多用，效率最大化

### 5. 属性依存策略
- **认知原理**：人类善于发现事物之间的关联
- **心理机制**：建立新的依存关系，创造"智能"感
- **为什么有效**：让系统"活"起来，响应外部变化

## SIT与设计思维（Design Thinking）的对比

| 维度 | SIT | Design Thinking |
|------|-----|----------------|
| 创新起点 | 从现有系统出发 | 从用户需求出发 |
| 创新路径 | 结构化的思维策略 | 发散-收敛循环 |
| 依赖资源 | 封闭世界（内部资源） | 开放探索（不限资源） |
| 学习周期 | 几小时掌握核心方法 | 需要系统训练 |
| 结果类型 | 系统化的方案变体 | 以用户为中心的原型 |
| 最佳组合 | 先用SIT生成方案，再用Design Thinking验证迭代 | |

## SIT常见问题（FAQ）

### Q1: SIT只能用于产品创新吗？
**答**：SIT最初用于产品创新，但可广泛应用于服务设计、商业模式、营销策略、运营流程、组织管理、甚至个人成长等几乎所有领域。

### Q2: 5种策略必须按顺序使用吗？
**答**：不需要。可以根据问题特点选择1-2种策略深入使用，或逐一尝试全部5种策略全面探索。

### Q3: 如何判断哪种策略最合适？
**答**：参考策略选择指南：
- 系统太复杂 → 减法策略
- 功能太单一 → 除法策略
- 差异不够 → 乘法策略
- 资源浪费 → 任务统筹策略
- 体验不智能 → 属性依存策略

### Q4: SIT的创新方案如何落地？
**答**：SIT生成的是"创新方向"，落地需要结合：
1. 用户调研验证需求
2. 原型设计快速测试
3. 商业可行性评估
4. 迭代优化

### Q5: 团队如何使用SIT进行创新工作坊？
**答**：推荐流程：
1. 15分钟：介绍SIT核心理念
2. 10分钟：定义创新对象
3. 30分钟：5种策略逐一探索
4. 20分钟：方案筛选和评估
5. 15分钟：优化和行动计划
