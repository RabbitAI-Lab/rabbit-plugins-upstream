## Description:

Synchronizes frontend project documentation with verified project files, configuration, routes, APIs, and deployment details.

This skill is ready for commercial/non-commercial use.

## Publisher:

[bovinphang](https://clawhub.ai/user/bovinphang)

### License/Terms of Use:

MIT

## Use Case:

Developers use this skill to bring READMEs, environment and API documentation, setup guides, ADRs, and changelogs into line with project source files and tests.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Documentation updates could misstate environment variables, API behavior, deployment steps, or multilingual project facts.

Mitigation: Review changes against project files and tests, especially environment, API, deployment, and translated README details, before publishing.
