## Description:

AI-powered ClawHub skill optimizer that analyzes reviews, tracks trending topics, and rewrites metadata to boost downloads and GitHub stars.

This skill is ready for commercial/non-commercial use.

## Publisher:

[gechengling](https://clawhub.ai/user/gechengling)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and ClawHub skill publishers use this skill to analyze feedback, trends, SEO positioning, and promotional needs for ClawHub skills. It produces human-reviewed recommendations for metadata, README content, tags, thumbnails, videos, social posts, and release checklists.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Sample Python, API, and npx snippets may be copied into a real environment without review.

Mitigation: Treat all snippets as examples; inspect data flows, third-party service calls, and install commands before running them.

Risk: SEO, growth, and social promotion recommendations may overstate likely download or star improvements.

Mitigation: Review generated claims manually and replace unverifiable growth promises with evidence-based wording.

Risk: Metadata edits and social posts can create public-facing changes to a skill listing or external platform presence.

Mitigation: Require manual approval for metadata updates and social publishing, and check applicable platform rules before posting.
