## 一、店铺范围（mode / shopHint）

- 用户点名了**某一家具体店铺**（完整公司名 / 店铺名 / loginId，如「丹阳市卓美光学眼镜有限公司」「丹阳百世芬眼镜厂」）→ mode="single"，shopHint 填该名称原文
- 用户说"所有店铺 / 多店对比 / 整体 / 全部店铺" → mode="multi"，shopHint 留空
- **泛指自己的店铺不算点名**：「我的1688店铺」「我店铺」「本店」「我们店」「店铺」「1688店铺」等 → mode="multi"，shopHint 留空
- shopHint **只能从用户输入原文中摘取**，严禁编造；严禁填入技能名 / 工作流名（如 1688-shop-daily-report）、平台名（1688）或"店铺"这类泛称
- 拿不准是否点名了具体店铺 → 一律 mode="multi"、shopHint 留空（多店模式覆盖全部绑定店铺，不会漏数据）

## 二、日期（explicitDate / dayOffset / isRange）

**相对日期一律用 dayOffset（距今天数）表达，由脚本换算；需要日历日期时用上面给出的「今天」推算，不要自己猜年份。**

- 用户给了**完整日历日期**（含年月日，如 2026-08-01）→ explicitDate 填 "YYYY-MM-DD"，dayOffset 填 0
- 只给了月日、缺年份（如"8月15日"，含"8.15""8-15"等数字写法）→ 用「今天」的年份补全为 "YYYY-MM-DD" 填 explicitDate，dayOffset 填 0；若补全后的日期不早于今天（即是今天或未来），改为**上一年的同一月日**
- 只给了日、缺年月（如"3号""29日""15号"）→ 用「今天」的年月补全为 "YYYY-MM-DD" 填 explicitDate，dayOffset 填 0；若补全后的日期不早于今天（如今天是 8-26 而用户说"29日"），改为**上一个月的同一日**
- 用户给了**日期范围**（如"8月16日到8月20日""上周一整周"）→ 取范围中**不晚于昨天**的最后一天填 explicitDate，dayOffset 填 0，并填 isRange=true；整个范围都在今天或未来 → explicitDate 留空、dayOffset = 1、isRange=true
- 用户说**相对日期** → explicitDate 留空，dayOffset 填距今天数：
  - 昨天 / 昨日 = 1
  - 前天 / 前日 = 2
  - 三天前 = 3，四天前 = 4，依此类推
  - 上周今天 / 一周前 = 7
- 用户**没提日期** → explicitDate 留空，dayOffset = 1（默认昨天）
- 用户要今天 / 明天 / 未来日期 → dayOffset = 0（脚本会拦截并告知数据未回收）
- **输出前自检**：explicitDate 非空时，它必须是早于「今天」的过去日期（用户明说要看今天/未来除外）；若算出的是今天或未来，先按上面规则改为上一年/上一月再输出
- **保守规则**（「今天」为空时）：缺年份月日与日期范围一律 explicitDate 留空、dayOffset = 1
