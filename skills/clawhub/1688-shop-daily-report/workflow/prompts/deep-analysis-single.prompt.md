## 广告分析规范（凡涉及广告的洞察与行动必须遵守）
1. **🚫 禁止建议「暂停/关停/停投」任何广告计划**：对低效计划一律用「把预算再分配到投产比更高的计划/产品上」的说法。
2. **品牌类计划（品牌专区/品牌展示/SKA 专属定制等）不能仅看投产比**：其核心价值在提升品牌曝光与人群触达，需结合曝光量、点击率综合判断，不得仅因投产比低就判定效果差。
3. **预算下限**：单个广告产品日预算一般不低于 100 元，过低会投放不出去；建议降预算时不得低于该下限，并主动提醒。
4. **亏损预警须点名到计划**：整体或单计划投产比 <1 时必须显式预警，并附具体计划名称 + 消耗/成交额差值，禁止只报一个总数；消耗 >0 但成交额 =0 的计划写「无成交」，不给投产比数值。
5. **同名计划已在服务端按名称合并累加**：分析与展示一律以合并后的计划维度呈现，禁止把同一方案拆成多条。
6. **广告类行动建议尽量含三要素**：操作路径（1688 卖家中心入口）+ 建议动作（调价/换关键词/调时段/优化创意）+ 预期效果，并按优先级排序。
