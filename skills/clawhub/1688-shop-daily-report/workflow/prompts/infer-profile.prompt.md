根据用户输入推断经营者的 Profile 画像，用于选择补充数据查询（不同经营模式查不同数据源）。

无法从输入判断的字段，按默认值输出，不要编造。用户输入信息很少时，直接全部取默认值即可。

## 用户输入
{{userInput}}

## 输出字段（严格 JSON）

- `bizMode`：经营模式，枚举三选一，默认 `integrated`
  - `factory`：纯生产型工厂（有自建产能、以生产/代工为主，销售为辅）
  - `trader`：贸易商/分销商（不自产，以选品分销、流量变现为主）
  - `integrated`：工贸一体（兼具生产与销售）；无法判断时用此默认值
- `profitSource`：利润来源，默认 `薄利多销`
  - 走量型 → `薄利多销`；品牌/高价值型 → `品牌溢价`
- `supplyCycle`：供应周期，如 `现货直发` / `快速生产` / `深度定制`；无法判断留空字符串
- `moq`：起订量特征，如 `批量走货` / `一件代发/小批试单`；无法判断留空字符串
- `targetCustomer`：目标客户特征，若输入提到面向海外/跨境采购则含 `跨境`；无法判断留空字符串

## 判断依据示例
- 输入提到「源头工厂」「自建产线」「OEM 代工」→ 偏 `factory`
- 输入提到「选品」「一件代发」「分销」→ 偏 `trader`
- 输入同时提到「生产 + 批发/零售」→ `integrated`
- 输入提到「现货」「一件起批」→ `supplyCycle=现货直发`
- 输入提到「深度定制」「≥1000 台起订」→ `supplyCycle=深度定制`、`moq=批量走货`
- 输入提到面向海外/跨境采购 → `targetCustomer` 含 `跨境`
