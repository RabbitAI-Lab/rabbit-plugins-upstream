# Icon library

Use the template’s original inline SVG marks: arrow, back, bag, heart, menu,
plus, check, sun, mark, search and pin. Retain a consistent stroke width,
rounded caps and the 24-unit viewBox. Decorative marks remain separate from
functional controls. No emoji, dingbats, icon fonts or remote icon requests.

Give every icon-only button an accessible name. Decorative SVGs use
aria-hidden; content-bearing artwork has a meaningful accessible label.
Use a heart only for a working saved state, a bag for cart actions, and
an arrow for real navigation. Do not invent third-party product logos.
