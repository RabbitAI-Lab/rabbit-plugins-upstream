## Description: <br>
Helps AI-agent users, skill authors, maintainers, and teams create practical Agent Browser-style workflows, bug-fix plans, reliability improvements, checklists, analysis, code changes, and decision support. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External developers, AI-agent users, skill authors, maintainers, and teams use this skill to turn Agent Browser-style productivity needs into actionable plans, templates, checklists, scripts, code changes, or workflow guidance. It emphasizes local-hardware-friendly approaches and visible validation steps. <br>
