## Description:

Helps agents create short AI videos and ads by adapting a source video's creative formula, swapping elements in existing footage, or drafting an original video.

This skill is ready for commercial/non-commercial use.

## Publisher:

[riffkit](https://clawhub.ai/user/riffkit)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and marketers use the agent to plan and generate short-form videos or product ads from a TikTok link, an uploaded video, an analyzed template, or a written creative brief.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A locally stored reusable session cookie grants access to the user's Riffkit account.

Mitigation: Protect the local session file and remove ~/.riffkit/session after use on shared machines.

Risk: The heartbeat can replace installed skill instructions with future remote versions.

Mitigation: Disable automatic updates or run version checks and review downloaded changes manually.

Risk: The agent can upload selected videos and images and spend credits on generation.

Mitigation: Confirm files before upload and obtain user approval before each paid action.
