## Description:

Helps users create short AI videos and ad creative by adapting a source video's emotional formula, swapping elements in its shots, or starting from a creative brief.

This skill is ready for commercial/non-commercial use.

## Publisher:

[riffkit](https://clawhub.ai/user/riffkit)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and marketers use this skill to plan and request short AI videos or ads from a video, template, or written creative direction, then receive the finished video's download link and copy.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The heartbeat can replace local skill instructions from a remote URL without integrity checks or approval for each update.

Mitigation: Disable automatic updates or run the heartbeat manually and review each new skill file before use.

Risk: Account access uses a session credential, and video generation or retries can incur charges.

Mitigation: Protect the session credential and require user confirmation before paid actions.
