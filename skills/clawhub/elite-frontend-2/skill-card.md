## Description:

This skill helps agents design frontend UI for web pages, landing pages, dashboards, and React or Vue components, producing HTML, CSS, and JavaScript code.

This skill is ready for commercial/non-commercial use.

## Publisher:

[thcjp](https://clawhub.ai/user/thcjp)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, designers, and agent users use this skill to create frontend layouts, reusable React or Vue components, brand visual treatments, style guidance, and responsive UI code from design requirements.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill has broad frontend activation scope and may read or write project files during implementation.

Mitigation: Use it in a project-scoped workspace and review generated file changes before accepting them.

Risk: The skill may propose or run local shell commands as part of frontend work.

Mitigation: Review proposed commands before allowing execution and avoid granting access to secrets unless clearly required.
