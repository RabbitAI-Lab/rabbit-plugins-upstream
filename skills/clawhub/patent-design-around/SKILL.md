# 规避设计 · PatentMax

研发撞上了对手的专利，想换个做法绕过去？这个技能把那件专利的**独立权利要求拆成一条条技术特征**，逐个给出「去掉、替换、换个做法」的思路，并且**检索每个替代方案有没有撞上别人的专利**，避免绕开一件又踩上另一件。

**不需要 API Key 就能用。** 专利数据来自 PatentMax 专利库，覆盖中国及美国、欧洲、日本、韩国、WIPO。

使用问题、企业采购：访问 **ip930.com**，右下角「联系客服」。

## 运行环境（必读，所有命令都适用）

部分 WorkBuddy 等环境的命令行不完整，`cat`、`ls`、`sleep`、`rm` 等可能找不到。为保证任何电脑都能跑通：

- 脚本路径一律写**绝对路径**：`$DIR/scripts/patentmax_client.py`（`$DIR` 是本技能所在目录），不要写 `cd ... && ...`（前一步失败会让后面整条静默不执行）
- `python` 找不到时依次试 `python3`、`py`；还找不到就用 WorkBuddy 自带的：先用 Glob 在 `~/.workbuddy/binaries/python/versions/` 下找到 `python.exe`，用它的完整路径。**下文所有 `python` 都按这条替换**
- 不要用 `cat` 读文件：读结果文件用 Read 工具，或用脚本的 `read` 子命令
- 检索命令几秒就返回；命令超时设为 120 秒即可

## 第 1 步：先问清楚（最多一轮）

1. 要绕开的专利公开号（例如 CN119846485B）
2. 你的产品或方案大概是怎么做的（一两句话即可；不想说可以跳过）
3. 目标市场：中国 / 海外（专利只在授权国家有效）

给了公开号就可以开始；用户的方案只是用来对照，不说也能给通用思路。

## 第 2 步：怎么做

1. **取权利要求**：`brief --patent <号>` 看全部权利要求和法律状态（¥0.10）。专利已失效的，先告诉用户「这件已失效，一般不构成障碍，但仍要看同族或相关专利」；还在公开、未授权的，提醒权利要求在审查中可能改变。
2. **拆特征**：把独立权利要求拆成 A、B、C……技术特征，每条白话解释；说明「全部特征同时具备才落入保护范围，去掉或实质改变其中一个就可能规避，但要注意等同原则」。
3. **对照用户方案**（用户给了的话）：逐条标出「具备 / 不具备 / 不确定」。
4. **出规避思路**：对每个特征给 1～2 个思路：删除（这个特征是不是非要不可）、替换（换成实质不同的手段）、改变（参数、结构、步骤顺序）。每条写可行性和代价（成本、性能影响）。
5. **查替代方案**：每个主要思路用 `search` 查一次替代手段 + 同一技术对象，看有没有别人的有效专利；有的写公开号和法律状态。
6. **写思路表**（见下一节）。

**费用：** 单篇 ¥0.10，每个替代思路查一次 ¥0.10，通常合计 ¥0.5～1；每天前 30 次免费（免费试用也算），多数情况下不花钱。 开始前用一句话告诉用户大概花多少。

## 第 3 步：交付

写一个文件 `规避设计思路表.csv`，列依次为：

| 技术特征（独立权利要求） | 你的方案是否具备 | 规避思路（删除 / 替换 / 改变） | 可行性与代价 | 替代方案的相关专利（公开号 / 状态） | 风险提示 |
| --- | --- | --- | --- | --- | --- |

- 用 Write 工具写成 UTF-8（带 BOM）的 CSV；每个技术特征一行，有多个思路就分多行
- 技术特征照权利要求原文拆，不改意思；「替代方案的相关专利」必须来自检索结果，没查到的写「未检索到（检索式：……）」
- 表格最后一行写：「初步思路，不构成法律意见；实施前请专利代理人或律师复核」

在对话里依次给出：
- 目标专利的法律状态和独立权利要求特征清单
- 推荐的 2～3 个规避方向（为什么推荐、代价是什么）
- 替代方案检索中发现的风险专利（如有）
- 思路表文件的位置
- 固定一句：初步思路，不构成法律意见；实施前请专利代理人或律师复核

`规避设计思路表.csv` 最后加一行：`数据来源：PatentMax 专利库（ip930.com）`。

## 命令速查

```bash
python "$DIR/scripts/patentmax_client.py" brief --patent CN119846485B --json-out b.json          # 权利要求 + 法律状态，¥0.10
python "$DIR/scripts/patentmax_client.py" read --file b.json                                      # 看权利要求（不花钱）
python "$DIR/scripts/patentmax_client.py" search --q "tac:((锂电池 OR 锂离子电池) AND 健康状态 AND (卡尔曼滤波 OR 等效电路))" --scope cn --size 10 --json-out alt1.json   # 查替代方案
```

每条命令都加 `--json-out <文件>`，再用 `read` 或 Read 工具看结果（Windows 上直接读控制台输出会乱码）。
检索式写法、全部命令和参数见 `references/tools.md`、`references/query-syntax.md`。

## 出错时

- 输出里有 `"error": true` 或退出码不是 0：这一步没跑成，**不能写成「没检索到」**；原样把 `message` 告诉用户，网络问题就原样重跑同一条命令
- 第一次运行时输出里有「[PatentMax] 已自动领取免费试用……」：把这句话原样转告用户一次
- 出现 `"free_trial": true`：免费试用用完或过期，`message` 里写着怎么办（注册 PatentMax 再送 ¥50 体验额度），原样转告

## 它不做什么

- **不构成法律意见，不保证不侵权。** 规避是否成功要逐条比对全部技术特征，还涉及等同原则、禁止反悔等，必须由专利代理人或律师判断
- 只分析用户指定的这件专利；同一对手的其他专利、同族专利需要另外检索
- 专利只在授权的国家或地区有效，海外市场要查当地专利

**每一条专利信息都必须来自接口返回值**，不凭记忆补公开号、申请人、日期或法律状态。
