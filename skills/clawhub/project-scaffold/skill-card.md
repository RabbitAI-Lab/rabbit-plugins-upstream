## Description: <br>
Generate new projects with standardized structure, tooling, and configuration for web, API, mobile, CLI, or browser extension apps. <br>

This skill is ready for commercial/non-commercial use. <br>

### License/Terms of Use: <br>


## Use Case: <br>
Developers use this skill to quickly create starter project layouts, initialization commands, baseline configuration, and next-step checklists for common application types. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Scaffolding can create or modify local project files in the selected target folder. <br>
Mitigation: Review the target folder and generated file tree before committing or relying on the scaffold. <br>
Risk: Initialization commands may run package managers and download third-party dependencies. <br>
Mitigation: Review package-manager prompts, dependency choices, and generated configuration before execution. <br>
