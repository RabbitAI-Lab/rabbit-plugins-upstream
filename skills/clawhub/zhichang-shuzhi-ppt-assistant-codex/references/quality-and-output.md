# 质量与交付检查

## 战略检查

- [ ] 符合真实汇报目的和目标受众。
- [ ] SPEC明确希望听众形成的判断。
- [ ] 故事线能够推动认可、决策或下一步行动。
- [ ] 个人价值由事实、方法和成果证明。
- [ ] 敏感诉求通过承担责任和结果能力表达。

## 证据检查

- [ ] 每个核心事实都有资料或用户确认。
- [ ] 事实、推论和建议可区分。
- [ ] 已完成成果、当前进度和后续计划没有混写。
- [ ] 没有编造数据、结果或领导评价。
- [ ] 简历和入职资料中的隐私没有进入正文或备注。

## 模板检查

- [ ] 已逐页读取模板要求并形成页契约。
- [ ] 页数、固定板块、目录和冻结页均按要求保留。
- [ ] 模板说明文字已转化为内容要求，没有误留在成品中。
- [ ] 未把其他PPT的排版强行套入公司模板。
- [ ] 模板要求一页完成的内容没有拆成续页。

## 内容检查

- [ ] 每页只有一个核心判断。
- [ ] 可见文字没有变成工作流水账或资料堆积。
- [ ] 专业技术已翻译成业务和管理意义。
- [ ] 成果页回答了事项、动作、结果/数据和复盘改进。
- [ ] 计划页回答了措施、时间、效果和具体资源。
- [ ] 问题页没有归咎个人，支持需求明确到部门和输入。

## 几何与视觉检查

将PPTX渲染为图片并逐页检查：

- [ ] 所有卡片和单元格都显式设置了合适的垂直锚点。
- [ ] 没有文字贴顶而容器下半部空置的情况。
- [ ] 同组卡片的文字基线、上下内边距和视觉重心一致。
- [ ] 封面、章节页和结束页的文字组合包围框真正水平居中。
- [ ] 居中容器同时检查了文本段落对齐和文本框位置。
- [ ] 页面上下、左右视觉重量平衡，没有明显一侧空、一侧挤。
- [ ] 不存在溢出、重叠、乱码、缺图、断字或损坏母版。
- [ ] 字号、行距、内边距和图标尺寸在全稿一致。
- [ ] 非专业管理者不依赖备注也能理解页面结论。

发现任一明显问题时，修正后重新渲染该页及其同类页面，不能只在源文件中猜测已经修好。

## 备注与署名检查

- [ ] 实质内容页备注提供口播价值，没有复述正文。
- [ ] 封面、目录和结束页没有被强行加入无意义备注。
- [ ] 结束页备注默认为空。
- [ ] 页面、备注、隐藏对象和文档属性中没有强制AI署名、Skill名称、联系方式、水印或生成声明。

## 交付清单

1. PPTX文件
2. 实质内容页Speaker Notes
3. 图表与视觉素材来源清单
4. 需要补充的数据清单
5. 可替换占位内容清单
6. 核心观点—证据来源清单
7. 风险表达检查结果
8. 逐页视觉验收结果

最终结果应同时满足：外行看得懂、专业人员认可逻辑、管理者看见价值、用户能力定位得到提升、知识被沉淀为可复用资产、PPT能够推动判断或行动。
