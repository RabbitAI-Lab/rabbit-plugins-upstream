# 页面设计与几何排版规则

## 页面内容契约

每页应具备：

1. 一个管理结论
2. 不超过三个主要信息点
3. 一个主视觉结构
4. 证据或明确占位口径
5. 不重复正文的口播备注

优先使用问题—方案、Before/After、方法框架、闭环流程、时间路线图、价值映射和风险—对策矩阵。不得直接搬运大段Word或完整Excel。

## 文本锚点必须显式设置

不要依赖软件默认的顶部对齐。

- 卡片、表格单元格、数字块和短标签通常设置为垂直居中。
- 多行说明框可顶部对齐，但上下内边距必须平衡，且同组容器保持一致。
- 当文本高度不足容器高度的35%时，优先缩小容器或垂直居中，禁止让文字贴在顶部、下方大片空置。
- 当同一行卡片高度相同，文字基线、标题高度、段落间距和上下留白必须一致。
- 设置水平居中时，同时检查段落对齐和文本框位置；只把文字设为居中不代表整个文字组居中。

## 封面、章节页与结束页

- 以安全内容区域为基准计算整组文字的水平中心，不以单个文本框中心代替。
- 居中型布局中，标题、副标题、姓名和日期的组合包围框应与页面中心线对齐。
- 结束页若只有感谢文字，文字组默认水平和垂直居中；模板另有明确规则时遵循模板。
- 不允许肉眼可见的左偏、右偏或文本组上下失衡。

## 空间与重心

- 先确定安全边距、标题区和内容区，再放置对象。
- 同组卡片使用稳定、相等的高度；不要因文字多少改变卡片尺寸。
- 卡片内容应在容器内形成完整视觉组。若下半部明显空，优先调整锚点、间距或容器高度，而不是增加无价值文字。
- 避免页面上半部内容过密、下半部空白，或相反。
- 视觉留白用于分组，不用于掩盖内容不足。

## 文字适配

- 先精简文字，再调整字号，最后才考虑增大容器。
- 不使用负字距，不用视口宽度自动缩放字号。
- 标题、正文、数字、注释建立固定层级，不在同页任意跳变。
- 检查最长中文短语、英文单词和数字是否完整显示。
- 不允许自动缩小到难以阅读的字号来掩盖内容过多。

## 模板模式

- 保留母版、品牌和固定页面层级。
- 删除模板说明文字后，在原可编辑区重建内容，不把说明文字继续留在成品中。
- 冻结页不得移动对象或重排文字。
- 旧PPT仅提供内容，不继承其页面布局。

## Speaker Notes

实质内容页的备注结构：

```text
本页目的：听众应形成什么判断。
口播重点：按结论、证据、意义的顺序讲。
补充说明：边界条件、来源和转场。
```

封面、目录和结束页没有必要时不强行添加备注。结束页默认空备注。

## 时长参考

| 时长 | 建议密度 |
|---|---|
| 5分钟 | 5—7页，只保留问题、证据、价值和下一步 |
| 10分钟 | 8—12页，一个主案例和简洁计划 |
| 15分钟 | 10—15页，2—3个证据案例 |
| 20—30分钟 | 14—22页，可增加方法、风险和决策讨论 |

固定模板与建议页数冲突时，保留模板页数，通过内容取舍和备注调节密度。
