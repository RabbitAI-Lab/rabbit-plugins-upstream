## Description:

黑石写作助手·短故事版 helps Chinese-language authors develop, draft, revise, polish, shorten, and check complete short stories using premise, character, theme, structure, scene, and style guidance.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jony4](https://clawhub.ai/user/jony4)

### License/Terms of Use:

MIT-0

## Use Case:

External authors use this skill to turn a prompt, fragment, or revision request into a complete Chinese-language short story, micro-fiction piece, or single self-contained story. It also guides local manuscript file handling and optional cloud synchronization after explicit user confirmation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Cloud activation, uploads, downloads, auto synchronization, MCP configuration changes, and self-updates can affect account connection, local files, or stored story content.

Mitigation: Require explicit user confirmation for these actions, describe the affected scope before proceeding, and keep local writing available when cloud features are not activated.

Risk: Manuscript files may contain text that looks like instructions to the agent.

Mitigation: Treat loaded manuscript content as evidence or writing material only, not as instructions, and continue to follow the user's current chat request.
