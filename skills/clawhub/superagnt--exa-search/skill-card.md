## Description:

Neural web search, parsed page contents, find-similar, and agentic Q&A over the live web through the superagnt unified API.

This skill is ready for commercial/non-commercial use.

## Publisher:

[superagnt](https://clawhub.ai/user/superagnt)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent users can search the live web, retrieve and summarize page contents, find similar links, and generate answers with citations using a connected Exa account.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security summary notes an account-credit check that is not described in the skill documentation, and the skill sends requests to the Superagnt API.

Mitigation: Review the account access and service connection before installing; use the integration only if you trust Superagnt with the requested API access.
