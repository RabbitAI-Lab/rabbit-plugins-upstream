## Description:

Search the live web, retrieve page content, find similar links, and generate cited answers through the Superagnt API.

This skill is ready for commercial/non-commercial use.

## Publisher:

[superagnt](https://clawhub.ai/user/superagnt)

### License/Terms of Use:

MIT-0

## Use Case:

Developers can use this integration to give agents live web search, page-content retrieval, related-link discovery, and answers with citations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Search queries and the API key are sent through Superagnt; use of the connected Exa account is subject to its vendor-side rate limits and billing.

Mitigation: Use the integration only if you trust Superagnt with the key and queries, and check the connected Exa account's usage and billing.
