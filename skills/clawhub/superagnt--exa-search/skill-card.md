## Description:

Neural web search, parsed page contents, find-similar, and agentic Q&A over the live web through the superagnt unified API.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers and AI agent builders use an Exa account to search the live web, retrieve parsed page content, find similar links, and generate answers with citations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Using the Superagnt API key permits credit checks and external search requests through the connected service.

Mitigation: Provide the key only if you are comfortable with those requests and keep it private.

Risk: The connected account may expose actions with external or destructive effects.

Mitigation: Use only endpoints needed for the task and get explicit confirmation before destructive or outbound actions.
