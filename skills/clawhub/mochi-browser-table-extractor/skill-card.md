## Description:

Turn a selected HTML table from an authorized browser capture into a quoted CSV with source attribution.

This skill is ready for commercial/non-commercial use.

## Publisher:

[hznetnewpower](https://clawhub.ai/user/hznetnewpower)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to convert a chosen table in an authorized saved webpage capture into a quoted CSV with source attribution.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Exports retain captured page data and could expose it if shared without review.

Mitigation: Review the exported CSV and report before sharing them.
