# 片段类型：逻辑

## 原文片段

We only analyzed when dyads interacted with the focal ROIs, which represent specific objects as opposed to broad categories of nouns. We chose to focus on this subset of behaviors because it allows us to directly compare our at-home findings with research previously done in lab settings. This study and analysis plan were not preregistered. The data and code used for analyses is publicly available at https://osf.io/ehcta/.

## 来源文献

Schroer et al., 2025, Developmental Psychology

## 适配诊断点

分析对象限定（focal ROIs）给出明确理由（与实验室研究直接可比），并附加未预注册声明与数据代码开放链接，是"为什么只分析子集"的论证示范。
