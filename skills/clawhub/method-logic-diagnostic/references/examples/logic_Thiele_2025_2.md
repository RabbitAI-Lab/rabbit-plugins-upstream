# 片段类型：逻辑

## 原文片段

Eighteen additional children were tested but excluded due to fussiness (9-month-olds: n = 7, 18-month-olds: n = 2), falling asleep (9-month-olds: n = 1), crying (9-month-olds: n = 1), distraction through the parent (9-month-olds: n = 2), technical failure (18-month-olds: n = 1), not typically developing (18-month-olds: n = 1), or providing less than one valid trial per condition (9-month-olds: n = 1, 18-month-olds: n = 2). All children were born full-term (>37 weeks). The sample size for each age group was planned based on a previous study using the same study paradigm, outcome measure, and statistical analyses (Thiele et al., 2021).

## 来源文献

Thiele, M., Gredebäck, G., & Haun, D. B. M. (2025). Social connectedness without eye contact. Developmental Psychology.

## 适配诊断点

每个排除原因附分组计数、按年龄段分列，排除标准可复核；样本量规划锚定同范式/同指标/同统计的前研究而非拍脑袋，是婴儿研究的样本量逻辑样板。
