# 片段类型：逻辑

## 原文片段

Because some data sets contained multiple measures of narcissism (often with a planned missingness design), the data were restructured to form separate data sets for each measure (e.g., a NPI data set). This involved combining all the data containing a particular measure across the data sets to yield eight data sets (one for each measure), some of which had overlapping participants (n = 49,744). Information on education and race/ethnicity was inconsistently collected or was relatively homogeneous across a particular sample. Thus, we were unable to report or model differences according to these characteristics. These 42 data sets were rearranged and combined to yield eight data sets. The 42 samples were combined into eight samples (denoted by the eight different measures) to run more highly powered analyses and reduce the number of tests rather than testing our question on several smaller samples (Schimmack, 2012). A sample size of 2,721 enabled us to detect effect sizes as small as r = .05 at 83% power at α = .05.

## 来源文献

Weidmann et al., 2023, Journal of Personality and Social Psychology

## 适配诊断点

数据整合决策给出明确理由（提高功效、减少检验次数、避免小样本检验），并报告可检测最小效应量（r = .05, 83% power），是分析策略合理性的论证范例。
