# 心理学实证论文 Method 部分「逻辑与论证维度」评分细则

> 满分 **100 分**。问题分为 **严重 / 中等 / 轻微** 三档，按对应检查清单逐项扣分。本细则的所有扣分点与 `checklist.md` 的检查项一一对应，不另立条款。

## 扣分档位定义

| 等级 | 单项扣分 | 适用情形 |
|---|---|---|
| **严重** | 10–15 分 | 关键方法选择未提供合理性依据；研究设计存在明显逻辑漏洞；变量控制缺失导致结论不可靠 |
| **中等** | 5–9 分 | 部分环节缺少论证支撑；控制变量说明不完整；逻辑跳跃 |
| **轻微** | 1–4 分 | 论证可更充分；表述可更严谨 |

## 一、方法选择合理性（共 25 项）

### 1.1 方法/范式选择给出实质理由，而非默认路径（6 项）

| 检查项 | 等级 | 扣分 |
|---|---|---|
| 每项关键方法选择（实验范式、测量工具、统计模型、数据来源）均伴随"为什么是它而不是别的"的论证 | 严重 | 12 |
| 方法选择以"whereas prior work… we… because…"对比框架呈现，而非孤立陈述 | 轻微 | 3 |
| 对"理论上可行但未采用"的备选方法明确交代取舍原因 | 中等 | 6 |
| 资料来源限制（IAPS 禁止在线使用、刺激列表倍数）作为材料替换理由被显式说明 | 轻微 | 3 |
| 二级文献/二手数据使用时明示"did not have control over…"并给补救策略 | 中等 | 7 |
| 选择论证不止步于"这是常用做法"，而是与本研究具体问题挂钩 | 中等 | 5 |

### 1.2 论证链为"事实/文献支撑 → 选择 → 优势"三段式（5 项）

| 检查项 | 等级 | 扣分 |
|---|---|---|
| 选择理由以可量化事实支撑 | 严重 | 10 |
| 选择理由引用文献佐证 | 中等 | 5 |
| 优势列举采用平行结构（First/Second/Third 或 (a)/(b)/(c)） | 轻微 | 3 |
| 每条优势直接落到本研究的具体可验证收益 | 中等 | 5 |
| 论证逻辑无跳跃：每步结论从上一步推出 | 中等 | 6 |

### 1.3 与既有方法的关系明确定位（5 项）

| 检查项 | 等级 | 扣分 |
|---|---|---|
| 与前人方法的关系按三种位置归类（identical / similar / significantly different） | 严重 | 10 |
| "相同"给出文献出处；"相似"说明调整参数；"不同"说明差异点及方法学意义 | 中等 | 6 |
| 系列实验间方法继承-修改关系用"identical to X except that…"显式表达 | 中等 | 5 |
| 对工具修订或改编，引用原版来源并指明修订部分 | 中等 | 5 |
| 引用位置正确，citation 不被错误挂到他人未做的工作上 | 严重 | 12 |

### 1.4 操作化选择经得起方法学审查（5 项）

| 检查项 | 等级 | 扣分 |
|---|---|---|
| 间接测量 vs 直接测量时说明选择哪一种及理由 | 中等 | 7 |
| 经典指标选择（平行分析 vs Kaiser 准则 vs 碎石图）给出取舍理由 | 中等 | 7 |
| 多模型/多估计框架（Bayesian vs frequentist）时说明理论优势 | 中等 | 6 |
| 操纵实现方式匹配理论构念而非仅可操作性 | 严重 | 10 |
| 对照材料的构建标准明确且可复现（"matched on X and Y"，附对照例） | 中等 | 7 |

### 1.5 关键方法选择语言到位（4 项）

| 检查项 | 等级 | 扣分 |
|---|---|---|
| 使用"in order to / with the aim of / so as to / thereby"等目的状语 | 轻微 | 3 |
| 选优词与选优动词（enable / ensure / permit / allow / facilitate）配合使用 | 轻微 | 2 |
| 谨慎副词体现操作严谨（carefully / tightly / independently / repeatedly / precisely） | 轻微 | 2 |
| 本研究实际工作用过去时；标准程序/通用工具用现在时，避免混淆 | 轻微 | 3 |

## 五、评分档位说明

| 分数区间 | 等级 | 含义 |
|---|---|---|
| **90–100** | 优秀（A） | 几乎所有检查项达标。关键方法选择论证充分、设计逻辑自洽、变量与控制说明完整、局限披露诚实且有建设性。具备顶刊 Method 段的论证质量。 |
| **80–89** | 良好（B） | 关键检查项基本达标，存在少量可改进项。可能在某一两项中等检查上存在论证缺口或语言不够严谨，但不影响主要结论可信度。 |
| **70–79** | 合格（C） | 多项中等检查存在缺口，或个别严重检查项不达标。方法选择有部分论证但不够完整；变量与控制说明存在遗漏；局限披露可能不够即时或不够诚实。结论需读者自行补充假设。 |
| **60–69** | 勉强合格（D） | 多项严重检查项不达标，或大量中等检查存在缺口。方法选择缺乏论证、研究设计有明显逻辑漏洞、变量控制缺失，结论可信度受到影响。修改前不宜投稿。 |
| **<60** | 不合格（F） | 大量严重问题未解决，方法段未达到实证论文最低论证标准。需要重写 Method 后重新提交诊断。 |

## 六、评分使用提示

1. **逐项检查**：按本细则逐条对照 Method 段，每条不符合即按对应档位扣分。
2. **累加扣分**：从 100 分起算，累加所有命中项的扣分；最终得分 = 100 − Σ扣分，最低为 0。
3. **同档叠加**：同一档内的多项同时不达标时累加扣分；如四项轻微问题各扣 2–3 分，合计扣 8–12 分，已达到中等问题的总体影响。
4. **严重问题优先**：若一项严重问题与其他问题同时存在，优先处理严重问题；其结论可能影响整篇论文的可信度。
5. **示例**：某研究"假设不可检验"（−15）、"无可量化事实支撑"（−10）、"无样本量可追溯"（−10）、"未报告信度"（−10），共扣 45 分，剩 55 分，归入 F 档；提示需对假设—设计对应、方法论证链、样本量决策、心理测量学属性四项做结构性补写后方可重新提交。
