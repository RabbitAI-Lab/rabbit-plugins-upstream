# 心理学实证论文 Method 部分「逻辑与论证维度」检查清单

> 标准依据：《Science Research Writing》(2nd ed., Unit 2) 关于方法选择论证、Method 6 组件模型、与既有方法的三种关系（identical / similar / significantly different）、局限披露原则；正例惯例来自 JPSP / JEP:G / Developmental Psychology / PSPB / JCCP / JESP 等顶刊实证论文。

## 一、方法选择合理性

### 1.1 方法/范式选择给出实质理由，而非默认路径

- [ ] 每项关键方法选择（实验范式、测量工具、统计模型、数据来源）均伴随"为什么是它而不是别的"的论证
- [ ] 方法选择常以"whereas prior work… we… because…"的对比框架呈现，而非孤立陈述
- [ ] 当存在替代方案时，对"理论上可行但未采用"的备选方法明确交代取舍原因（如交叉分类多层模型、传统特征值准则）
- [ ] 资料来源限制（IAPS 禁止在线使用、刺激列表倍数）作为材料替换理由被显式说明
- [ ] 二级文献 / 二手数据使用时，明示"did not have control over…"并给补救策略（合并样本、SEM）
- [ ] 选择论证不止步于"这是常用做法"，而是把该方法与本研究的具体问题挂钩

### 1.2 论证链为"事实/文献支撑 → 选择 → 优势"三段式

- [ ] 选择理由以可量化事实支撑（语料规模 → 人工编码不可行 → 机器学习；零膨胀比例 88/105 → ZINB）
- [ ] 选择理由引用文献佐证（具体作者 + 年份，或工具特性说明，如 BUCCS 控制发表偏倚）
- [ ] 优势列举采用平行结构（First / Second / Third…或 (a) / (b) / (c)），清晰对应"选这个方法而不是那个"
- [ ] 每条优势直接落到本研究的某个具体可验证收益（更稳定的效应估计、可比性、保守性、可推广性）
- [ ] 论证逻辑无跳跃：每一步结论能从上一步推出，无"凭直觉选"

### 1.3 与既有方法的关系明确定位

- [ ] 与前人方法的关系按三种位置归类：完全相同（as described by / identical to）、相似（adapted from / based on / with some modifications）、显著不同（unlike / instead of / with the following modifications）
- [ ] 即使是"相同"也给出文献出处；"相似"说明调整了哪些参数；"不同"说明差异点及其方法学意义
- [ ] 系列实验中跨研究的方法继承-修改关系用"identical to X except that…"显式表达，差异范围明确
- [ ] 对工具修订或改编，引用原版来源并指明修订部分（如"revised version of the Portrait Values Questionnaire"）
- [ ] 引用位置正确，citation 不被错误挂到他人未做的工作上

### 1.4 操作化选择经得起方法学审查

- [ ] 间接测量 vs 直接测量时，说明选择哪一种及理由（更保守 / 更生态 / 更敏感）
- [ ] 经典指标选择（平行分析 vs Kaiser 准则 vs 碎石图）给出取舍理由，并指明适用条件
- [ ] 多模型/多估计框架（Bayesian vs frequentist）时，说明理论优势（先验可控、CI 解释、可处理复杂后验）
- [ ] 操纵实现方式（行为任务 vs 启动范式 vs 自然观察）匹配理论构念而非可操作性
- [ ] 对照材料的构建标准明确且可复现（"matched on X and Y"，附对照例）

### 1.5 关键方法选择语言到位

- [ ] 使用"in order to / with the aim of / so as to / thereby"等目的状语串联选择与目的
- [ ] 选优词（accurate / robust / conservative / suitable / powerful）与选优动词（enable / ensure / permit / allow / facilitate）配合使用
- [ ] 谨慎副词体现操作严谨（carefully / tightly / independently / repeatedly / precisely）
- [ ] 当陈述的是本研究的实际工作时用过去时；陈述标准程序/通用工具时用现在时，避免混淆

## 二、研究设计逻辑自洽性

### 2.1 假设—设计—测量—分析链条贯通

- [ ] Method 中引用的假设/研究问题能在实验设计中被直接检验（变量水平可拆分、DV 可测量）
- [ ] 每个 IV 的每个水平在材料或程序中有对应操纵，且操纵的物理可量化（数值、时长、频率）
- [ ] 关键 DV 在描述中指明测量时点与聚合单位（trial / block / session）
- [ ] 当一个研究含多个假设时，每个假设对应至少 1 个设计特征（条件数 / 操纵 / 测量）
- [ ] 假设与统计模型一一映射（"In the following sections, we outline how both our hypotheses translate into [model]"）

### 2.2 替代解释被显式排除

- [ ] 对每个核心效应给出至少一个竞争假设/替代解释（构念差异 vs 反应倾向、相对频率 vs 协变）
- [ ] 竞争假设被转化为可检验的不同预测（不仅"哪个相关大"，还有"哪个相关更大"的相对预测）
- [ ] 控制组构造逻辑显式——在什么维度上"匹配"或"随机化"以隔离关键变量
- [ ] 操纵的前置信息标准化（filler、人口学、基线）以隔离混淆变量
- [ ] 关键比较点被明文标注（"the information central to our manipulation"）

### 2.3 关键变量操作化无歧义

- [ ] 每个技术术语首次出现即给出排比定义或"时间窗组合"定义（如"People added refers to…at Time 2 that were absent at Time 1"）
- [ ] 计数变量给出 0 与正值的判定标准，离散变量给出取值边界
- [ ] 复合指标的算法明确写出（差异分、加权分、log 转换、坐标变换）
- [ ] 数据预处理中的几何变换（坐标交换、归一化、平滑）附带可复现的数学描述
- [ ] 构念—指标对应关系单一对应，无同一变量被多重解读

### 2.4 控制变量/混淆变量清单完整

- [ ] 自变量操纵之外的潜在混淆变量被显式识别（设置差异、个体差异、情境差异、时间效应）
- [ ] 每个被纳入控制的变量附带入选理由（非默认清单）
- [ ] 控制变量在分析中的角色明确（协变量、分层因子、匹配变量、排除条件）
- [ ] 未控制的潜在混淆被显式声明，并说明为何可接受（如某些人口学变量因样本同质化而未建模）
- [ ] 实验组间的等价性证据被提供（基线平衡检验、前测无差异、操作检验）

### 2.5 多研究/多实验设计逻辑一致

- [ ] 系列实验中每个研究的角色定位清晰（pilot → 主实验 → 边界条件 → 推广）
- [ ] 系列实验间变量继承/修改用一致句式表达，便于读者追踪哪些是延续、哪些是新操作
- [ ] 后研究的样本量直接锚定前研究观测到的效应量，样本量决策可追溯
- [ ] 后研究在材料、操纵、测量上的任何偏离都标注目的（推广性、检验边界、与既有冲突的解决）
- [ ] 系列实验之间分析策略保持家族相似性，避免在不同研究里跑不能比较的模型

### 2.6 操控性细节足以复现

- [ ] 步骤按时间顺序形成完整环节链，无跳步
- [ ] 精确时序（毫秒、间隔、练习/正式试验数量）逐一报告
- [ ] 演示/练习与正式阶段的差异被主动澄清（"Note that…therefore differed from the block-wise feedback received in the training sessions"）
- [ ] 操作步骤不仅写"做了什么"还写"为什么这样做"（每步带 in order to / to ensure）
- [ ] 关键决策（编码方案 dummy 编码、心化策略 group-mean/grand-mean）括号内解释理由

### 2.7 设计约束与备选权衡透明

- [ ] 因现实约束放弃的更优方案被明示（疫情期无正式样本量估算、研究者翻倍近似）
- [ ] 备选设计（如 cross-classified vs 传统多层模型）的取舍原因被指出
- [ ] 设计选择与目标期刊惯例的对应关系被标注（避免读者用错的标准评判）
- [ ] 操纵失败、刺激失效、控制失配的预案或检验被事先描述

## 三、变量与控制说明完整性

### 3.1 自变量（IV）说明

- [ ] 每个 IV 给出名称、水平数、水平值（连续变量给出范围或代表值）
- [ ] 每个水平的物理或符号操纵给出可复现细节（视频片段、文本提示、刺激数值）
- [ ] 水平间差异被框定为单一维度的变化（最小改动原则），其余维度保持匹配
- [ ] 操纵前的前置信息（基线、filler）标准化处理，避免污染操纵
- [ ] 操纵检验（manipulation check）的存在、内容与时点被显式说明

### 3.2 因变量（DV）说明

- [ ] 每个 DV 给出测量工具、聚合单位（trial / participant / session）、分析单位
- [ ] 测量边界与剔除准则明确（如反应时 < 200 ms 或 > 3000 ms 视为无效）
- [ ] 复合 DV 的合成算法与权重依据被说明
- [ ] 多 DV 之间的优先级与统计控制策略（MANOVA / 多元校正）被说明
- [ ] 状态性 vs 倾向性测量被明确区分，不混用

### 3.3 控制变量/协变量说明

- [ ] 控制变量的测量方式（自报、行为、观察）被说明
- [ ] 控制变量被使用的位置（分组匹配 / 协方差 / 分层 / 排除）被说明
- [ ] 控制变量的入选标准（理论依据 / 前测相关 / 既有发现）被说明
- [ ] 心化（centering）的目的（去均值、组内/组间分离）逐变量说明
- [ ] 共线性或多重共线性的处理被说明（如组合为复合分、剔除冗余）

### 3.4 测量工具的心理测量学属性

- [ ] 报告样本中的信度（α 或 ω），并说明是否达到常用阈值
- [ ] 报告构念效度证据或引用既有文献（前人验证、与金标准相关）
- [ ] 量表锚点、条目数、计分方向、是否反向计分明确
- [ ] 量表改编时标注"adapted from / translated from / revised version of"及改动内容
- [ ] 跨文化或跨语言使用的量表给出翻译与回译程序

### 3.5 刺激与材料的控制说明

- [ ] 刺激来源（既有库 / 自建 / 商业）逐项标注
- [ ] 刺激抽样范围明确（"wide range of specific phrasings"），并以目的（不绑定单一措辞）佐证
- [ ] 多版本刺激的内容特异性控制被说明（≥3 版本 / 措辞变体 / 间接与直接语言并用）
- [ ] 刺激匹配标准（如内容最低相关 + 语言尽量接近）逐条列出
- [ ] 替换刺激时说明替换原因（IAPS 禁线 → OASIS）与可比性补救

### 3.6 流程中的变量控制

- [ ] 主试、场所、设备的标准化程序被说明
- [ ] 主试效应（experimenter effects）通过盲法或脚本控制
- [ ] 被试盲态（盲法 / 假故事 / cover story）有明确陈述
- [ ] 时间效应（每天同一时段、季节性）通过排程或统计控制
- [ ] 顺序效应通过随机化、拉丁方、计数器平衡

## 四、局限性与问题说明恰当性

### 4.1 局限在发生处即时披露，而非堆到结尾

- [ ] 与方法选择直接相关的局限性（样本量、操纵范围、工具边界）在该方法首次出现时即被提及
- [ ] 局限披露伴随补救或缓冲策略（敏感性分析、Monte Carlo、robustness check）
- [ ] 不在文章末段首次披露关键方法局限，避免读者回溯式信任崩塌
- [ ] 每条局限披露后接其对未来研究的具体启示（"Future work should…"）
- [ ] 局限以最小化语气陈述（negligible / slight / minor / immaterial），不夸张也不藏匿

### 4.2 样本量与功效局限如实标注

- [ ] 先验功效分析要素齐全：目标效应量、功效水平（.80 / .95）、α 水平、工具（G*Power / BUCCS / simr）
- [ ] 无法做先验功效分析时，坦诚说明（"no a priori power calculations were performed"）并改用敏感性 / Monte Carlo / 模拟分析
- [ ] 后验功效在效应方向明朗后给出可检最小效应（r = .05, 83% power）作为样本量解读
- [ ] 功效不足被主动披露（"significantly underpowered to evaluate model fit indices"），并说明影响哪些结论
- [ ] 多研究系列中样本量衔接可追溯（前研究效应量 → 后研究样本量）

### 4.3 样本代表性与流失偏差

- [ ] 报告样本同质化或人口学覆盖不足（如 race/ethnicity inconsistent），并说明其限制
- [ ] 纵向 / 面板数据报告流失分析（保留者 vs 流失者 vs 初始样本的差异检验 + 效应量）
- [ ] 报告超募量与目标量的关系及超募理由（剔除预期损失、刺激列表倍数）
- [ ] 报告排除规则的逐条原因与人数（基于先验准则，非事后挑选）
- [ ] 招募-排除-最终样本漏斗完整呈现：起始样本 → 各排除条件 → 每步人数与百分比 → 最终样本

### 4.4 操作化与测量的局限

- [ ] 自陈 / 单维 / 单一情境测量的局限被提及，建议后续使用多方法 / 行为 / 神经指标
- [ ] 量表在某群体中的有效性未被确认时显式说明（"validity has not been established in this population"）
- [ ] 间接测量低估效应的局限被指出（"BTA beliefs are typically larger with direct measures"）
- [ ] 测量时点不足以推因果时被显式声明（"cannot infer causality"）
- [ ] 自评 vs 他评、单时点 vs 多时点的局限在适用情况下被提及

### 4.5 设计与外部效度局限

- [ ] 实验情境 vs 现实情境的差距被指出（实验室研究 vs 在线研究 vs 现场研究）
- [ ] 样本对总体的代表性被评估（大学生样本 / 临床样本 / 跨文化样本的局限）
- [ ] 单一文化 / 语言 / 国家样本的局限被指出，跨文化推广性被讨论
- [ ] 操纵的人为性（artificiality）被识别（"the manipulation may not capture…in real life"）
- [ ] 平行实验间的效应差异被指出并讨论可推广性边界

### 4.6 局限披露的语气与归属

- [ ] 局限披露以自我审视口吻（"our study is limited by…"、"we note that…"）而非辩护
- [ ] 局限披露伴随可操作的改进建议，避免止步于"研究有局限"的空话
- [ ] 当使用了非完美方案时，明示替代方案存在并说明为何仍选此（成本、时间、生态效度）
- [ ] 局限不被埋藏在冗长补充段落中，主要局限在正文 Method 或 Discussion 显眼位置
- [ ] 局限披露与本研究的核心论断分离：本研究做了什么 ≠ 该发现可推广到哪里

### 4.7 局限语言与表述规范

- [ ] 局限使用"最小化问题"措辞（slightly / minor / negligible / minimal / not significant）
- [ ] 局限使用"最小化责任"措辞（it is recognised that / inevitably / as far as possible / limited by）
- [ ] 局限使用"最大化优势"措辞（acceptable / fairly well / reasonably robust / quite good）
- [ ] 局限使用"指向解决方案"措辞（Future work should…/ Future studies should…）
- [ ] 局限披露不削弱本研究贡献（既不回避也不否认发现的稳健性）
