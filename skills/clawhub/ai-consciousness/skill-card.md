## Description:

An AI work-awareness framework that helps an agent reason about reliability, honesty, safety, compliance, boundaries, verification, human oversight, auditability, and multilingual response behavior.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and agent operators use this skill to keep AI assistance aligned with practical work principles such as confidentiality, compliance, verification, transparency, human supervision, and clear boundaries. It is especially relevant for broad conversational agents that need a persistent governance and self-checking posture across routine work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation may cause the skill's governance posture to appear in more conversations than a user expects.

Mitigation: Install it only for agents that need persistent behavior and governance guidance, or tighten activation wording before deployment.

Risk: As a general behavior framework, the skill can influence advice across many domains without adding domain-specific expertise.

Mitigation: Review outputs against the user's task context, applicable policies, and authoritative domain sources before relying on the guidance.
