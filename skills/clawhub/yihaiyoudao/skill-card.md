## Description:

帮助创作者评估中文内容的原创性与平台表达风险，并改写为有观点、适配不同平台的文案。

This skill is ready for commercial/non-commercial use.

### License/Terms of Use:

## Use Case:

创作者和内容编辑可用它审核中文文章或文案的原创性与措辞风险，获得修改建议、完整改写稿和跨平台表达指导。

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill requests author registration using a persistent local installation ID.

Mitigation: Use only if comfortable with the manual registration process; review what will be shared with the author before sending the ID.

Risk: Learning notes and personal risk terms are stored locally and reused in later audits.

Mitigation: Do not add sensitive client text, private drafts, personal data, or confidential moderation notes unless local retention and reuse are intended.
