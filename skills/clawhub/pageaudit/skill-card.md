## Description:

Find HTML SEO issues with evidence, then generate a saved fix prompt for a coding agent or monitor later changes. Start with the free audit.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Website owners, developers, and agents use PageAudit to review user-authorized websites for HTML SEO issues, crawler access, and changes over time. They can use the findings to prioritize corrections and prepare a saved fix prompt for an authorized coding workflow.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Submitted URLs may contain embedded secrets or disclose sites the user is not authorized to share.

Mitigation: Remove embedded secrets and submit only URLs the user is authorized to disclose.

Risk: Generated fix prompts may propose changes that are incomplete or unsuitable for the target project.

Mitigation: Review the complete prompt and proposed changes, confirm authorization, and audit the site again after changes.

Risk: Paid prompt generation or monitoring can use account credits or incur costs, and current service terms may need confirmation.

Mitigation: Check the current allowance, plan, pricing, monitoring, and spending settings before paid or recurring operations; keep owner credentials private.
