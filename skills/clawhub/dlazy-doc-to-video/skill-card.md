## Description:

doc to video, word to video, markdown to video, document to video — parse the document, outline, storyboard, voiceover, build, validate. Use when the user gives a Doc / Word / Markdown file and wants an explainer, report broadcast, or training video.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers can submit Word, Markdown, and other documents to create explainer, report, courseware, or training videos. The skill guides a hosted document-to-video workflow from outlining and storyboarding through voiceover, video generation, and validation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and attached documents are sent to dLazy for processing, and video generation can consume organization credits.

Mitigation: Review the service's privacy and retention terms, confirm the intended organization and project, check credit use, and upload only documents you are authorized to share.

Risk: The CLI saves an organization API key in local user configuration.

Mitigation: Protect the local configuration and rotate or revoke the key when it is no longer needed.
