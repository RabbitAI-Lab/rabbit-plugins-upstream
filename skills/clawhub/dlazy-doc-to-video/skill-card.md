## Description:

Turns Word, Markdown, and other documents into explainer, report, courseware, or training videos through an interactive project workflow.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

External users and content creators can provide a document and use the skill to create an explainer, report, courseware, or training video through dLazy's hosted agent.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and attached files are sent to dLazy services, and the CLI uses an organization-scoped API key.

Mitigation: Share only content approved for the service; check the active organization and service terms, and rotate or revoke the API key if needed.
