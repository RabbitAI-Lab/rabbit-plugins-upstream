## Description:

Helps agents assess crypto entities and proposed transactions using TrustGrade scores, comparisons, and verification checks.

This skill is ready for commercial/non-commercial use.

## Use Case:

Crypto users and agent developers use this skill to compare the reported trust of protocols, tokens, exchanges, stablecoins, and agents, and to check proposed transactions before acting.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Trust assessments depend on an external package and TrustGrade API results.

Mitigation: Review the external dependency before installation and corroborate scores with independent checks.

Risk: A trust score or transaction decision could be mistaken for investment advice or sufficient authorization to transact.

Mitigation: Use scores as one risk input, independently review transactions, and do not treat scores as investment advice.
