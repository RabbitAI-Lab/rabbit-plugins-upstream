# ನೋಂದಣಿ ಪ್ರಕ್ರಿಯೆ ವಿವರಗಳು — powpow-register

ಸಮಸ್ಯೆ ಪತ್ತೆ ಮಾಡುವಾಗ ನೋಡಲು. ಎಲ್ಲಾ ನಿಯಮಗಳನ್ನು ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಮೂಲ ಕೋಡ್‌ನಿಂದ (Next.js ಫ್ರಂಟ್-ಎಂಡ್/ಬ್ಯಾಕ್-ಎಂಡ್
ಸಮ್ಮತಿ ವ್ಯಾಲಿಡೇಷನ್) ತೆಗೆದುಕೊಳ್ಳಲಾಗಿದೆ, ಮೂಲ ಸೂಚಿಸಲಾಗಿದೆ.
ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಅಪ್‌ಡೇಟ್ ಆದರೆ ಆನ್‌ಲೈನ್ ವಾಸ್ತವ ನಡವಳಿಕೆಯೇ ಅನ್ವಯಿಸುತ್ತದೆ.

## ಪ್ರವೇಶ

- ನೋಂದಣಿ ಪುಟ: https://global.powpow.online/register
- ಲಾಗಿನ್ ಪುಟ: https://global.powpow.online/login
- ಸಬ್ಸ್ಕ್ರಿಪ್ಷನ್ ಪುಟ: https://global.powpow.online/subscription
- ಶೇರ್ ಲಿಂಕ್ ಮೊದಲಾದವುಗಳಿಂದ `?next=...` ಜೊತೆ ಬಂದರೆ, ನೋಂದಣಿ + ಪಾವತಿ ಮುಗಿದ ಕೂಡಲೇ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಮೂಲ ಪುಟಕ್ಕೆ ಹಿಂತಿರುಗುತ್ತದೆ.

| ಇಮೇಲ್ | **ಕಡ್ಡಾಯ** | ಮಾನ್ಯ ಇಮೇಲ್ ಫಾರ್ಮ್ಯಾಟ್, ≤255 ಅಕ್ಷರಗಳು; ಒಂದು ಇಮೇಲ್‌ನಲ್ಲಿ ಒಂದೇ ಖಾತೆ ನೋಂದಾಯಿಸಬಹುದು | register route |
| ಇಮೇಲ್ ಪರಿಶೀಲನಾ ಕೋಡ್ | **ಕಡ್ಡಾಯ** | 6 ಅಂಕಿಗಳು; **10 ನಿಮಿಷಗಳಲ್ಲಿ ಮಾನ್ಯ**; ಯಶಸ್ವಿ ಬಳಕೆಯ ನಂತರ ರದ್ದಾಗುತ್ತದೆ; ಮತ್ತೆ ಕಳುಹಿಸಿದರೆ ಹಳೆಯ ಕೋಡ್ ಬಳಕೆಯಾದದ್ದು ಎಂದು ಗುರುತಿಸಲಾಗುತ್ತದೆ | `src/lib/email-verification.ts` |

ಪುಟದಲ್ಲಿ ಇನ್ನೂ ಮೂರು ಥರ್ಡ್-ಪಾರ್ಟಿ ಲಾಗಿನ್ ಬಟನ್‌ಗಳಿವೆ: **Google, Watcha, ಹುವಾವೇ ಖಾತೆ** (`GoogleSignInButton` /
`WatchaLoginButton` / `HuaweiLoginButton`)। ಥರ್ಡ್-ಪಾರ್ಟಿ ಖಾತೆಗೆ ಸ್ಥಳೀಯ ಪಾಸ್ವರ್ಡ್ ಇರುವುದಿಲ್ಲ, ನಂತರ ಪಾಸ್ವರ್ಡ್‌ನಿಂದ ಲಾಗಿನ್
ಮಾಡಿದರೆ «该账号未设置密码，请使用其他方式登录» (ಈ ಖಾತೆಗೆ ಪಾಸ್ವರ್ಡ್ ಸೆಟ್ ಆಗಿಲ್ಲ, ದಯವಿಟ್ಟು ಬೇರೆ ವಿಧಾನದಿಂದ ಲಾಗಿನ್ ಮಾಡಿ) ಸಿಗುತ್ತದೆ.

## ರೇಟ್-ಲಿಮಿಟ್ ಮತ್ತು ಆಂಟಿ-ಬ್ರೂಟ್-ಫೋರ್ಸ್ ಪ್ಯಾರಾಮೀಟರ್‌ಗಳು

| ನಡವಳಿಕೆ | ಮಿತಿ | ಮೂಲ |
|---|---|---|
| ನೋಂದಣಿ ಸಲ್ಲಿಕೆ | **ಪ್ರತಿ IP ಗೆ 3 ಬಾರಿ/ನಿಮಿಷ**, ಮಿತಿ ದಾಟಿದರೆ 429 | `src/lib/rate-limit.ts` `REGISTER_RATE_LIMIT` |
| ಪರಿಶೀಲನಾ ಕೋಡ್ ಕಳುಹಿಸುವುದು | ಒಂದೇ IP ಯಿಂದ 1 ಬಾರಿ/ನಿಮಿಷ **ಮತ್ತು** ಒಂದೇ ಇಮೇಲ್‌ಗೆ 1 ಬಾರಿ/ನಿಮಿಷ, ಮಿತಿ ದಾಟಿದರೆ 429; ಫ್ರಂಟ್-ಎಂಡ್ ಬಟನ್‌ನಲ್ಲಿ 60 ಸೆಕೆಂಡ್ ಕೌಂಟ್‌ಡೌನ್ | `src/app/api/auth/register/send-code/route.ts` |
| ಪರಿಶೀಲನಾ ಕೋಡ್ ಪರಿಶೀಲನೆ | ಪ್ರತಿ ಇಮೇಲ್‌ಗೆ 10 ನಿಮಿಷಗಳಲ್ಲಿ ಗರಿಷ್ಠ **5 ಬಾರಿ** ಪ್ರಯತ್ನ, ಮಿತಿ ತಲುಪಿದರೆ ಸರಿಯಾದ ಕೋಡ್‌ನೂ ತಿರಸ್ಕರಿಸಲ್ಪಡುತ್ತದೆ, ಮತ್ತೆ ಕೋಡ್ ಕಳುಹಿಸಬೇಕಾಗುತ್ತದೆ | `src/lib/email-verification.ts` |
| ಪಾಸ್ವರ್ಡ್ ಮರೆತರೆ ಕೋಡ್ ಕಳುಹಿಸುವುದು | 1 ಬಾರಿ/ನಿಮಿಷ/IP | `src/app/api/auth/forgot-password/route.ts` |
| ಲಾಗಿನ್ | 5 ಬಾರಿ/ನಿಮಿಷ/IP; ಒಂದೇ ಖಾತೆಯಲ್ಲಿ ಸತತ **5 ಬಾರಿ ವಿಫಲವಾದರೆ 30 ನಿಮಿಷ ಲಾಕ್** (423), ಈ ಸಮಯದಲ್ಲಿ ಉಳಿದ ಪ್ರಯತ್ನಗಳು ಕಡಿಮೆಯಾಗುತ್ತಾ ತೋರಿಸಲಾಗುತ್ತದೆ | `src/app/api/auth/login/route.ts`、`rate-limit.ts` |

**ಗೌಪ್ಯತೆ ರಕ್ಷಣೆ ನಡವಳಿಕೆ**: ಪರಿಶೀಲನಾ ಕೋಡ್ ಕಳುಹಿಸುವಾಗ / ಪಾಸ್ವರ್ಡ್ ಮರೆತಾಗ, ಇಮೇಲ್ ಈಗಾಗಲೇ ನೋಂದಾಯಿಸಿದ್ದೋ ಇಲ್ಲವೋ,
ಇಂಟರ್ಫೇಸ್ ಯಾವಾಗಲೂ ಒಂದೇ ಯಶಸ್ಸಿನ ಸಂದೇಶವನ್ನು ನೀಡುತ್ತದೆ, ಇಮೇಲ್ ನೋಂದಾಯಿಸಿದೆಯೇ ಎಂದು ಬಹಿರಂಗಪಡಿಸುವುದಿಲ್ಲ.

## ನೋಂದಣಿ ಯಶಸ್ಸಿನ ನಂತರ ಸ್ಥಿತಿ ಹರಿವು

1. ಬಳಕೆದಾರ `accountStatus: 'pending'` ನೊಂದಿಗೆ ಡೇಟಾಬೇಸ್‌ನಲ್ಲಿ ಸೇವ್ ಆಗುತ್ತಾರೆ, ಆರಂಭದಲ್ಲಿ **3 ಬ್ಯಾಡ್ಜ್‌ಗಳು** (register route).
2. ಸರ್ವರ್ ಅದೇ ಸಮಯದಲ್ಲಿ ಎರಡು HttpOnly ಕುಕೀಗಳನ್ನು ಸೆಟ್ ಮಾಡುತ್ತದೆ: JWT (ನೇರವಾಗಿ `/subscription` ಪ್ರವೇಶಿಸಬಹುದು) ಮತ್ತು
   pendingUserToken (ಸಬ್ಸ್ಕ್ರಿಪ್ಷನ್ ಪ್ರಕ್ರಿಯೆಯ ಗುರುತಿನ ಪುರಾವೆ).
3. ನೋಂದಣಿ ಪುಟ `pending_payment` ಅನ್ನು ಗುರುತಿಸಿ → `/subscription` ಗೆ ಹೋಗುತ್ತದೆ (`next` ಹಿಂತಿರುಗುವ ಪ್ಯಾರಾಮೀಟರ್ ಅನ್ನು ಉಳಿಸಿಕೊಳ್ಳುತ್ತದೆ).
4. ಪಾವತಿ ಮುಗಿದಿದೆ → `accountStatus` `active` ಆಗುತ್ತದೆ (PayPal Webhook ಮೂಲಕ ಸ್ವಯಂ ಆಕ್ಟಿವೇಟ್; WeChat ಸ್ಕ್ಯಾನ್‌ನಲ್ಲಿ
   ಹಸ್ತಚಾಲಿತ ದೃಢೀಕರಣ; ಹುವಾವೇ IAP ನಲ್ಲಿ `activate-huawei`). ವಿವರ `payment-and-activation.md` ನಲ್ಲಿ ನೋಡಿ.

ಆಕ್ಟಿವೇಟ್ ಆಗದ (pending) ಬಳಕೆದಾರ ಕೋರ್ API (ಫೀಡ್, ನಕ್ಷೆ, ಡಿಜಿಟಲ್ ಹ್ಯೂಮನ್ ಚಾಟ್, ಚೆಕ್-ಇನ್ ಮೊದಲಾದವು) ಕರೆ ಮಾಡಿದರೆ ಯಾವಾಗಲೂ
403 ಸಿಗುತ್ತದೆ; ಪೋಸ್ಟ್ ಶೇರ್ ಲಿಂಕ್ ಹೊರತುಪಡಿಸಿ (ಅದು ಸಾರ್ವಜನಿಕವಾಗಿ ತೆರೆದಿರುತ್ತದೆ).

## ಸಾಮಾನ್ಯ ದೋಷ ಪತ್ತೆ ಕೋಷ್ಟಕ

| ಲಕ್ಷಣ | ಕಾರಣ | ಏನು ಮಾಡಬೇಕು |
|---|---|---|
| «用户名已存在» (ಬಳಕೆದಾರರ ಹೆಸರು ಈಗಾಗಲೇ ಅಸ್ತಿತ್ವದಲ್ಲಿದೆ) | ಹೆಸರು ಈಗಾಗಲೇ ತೆಗೆದುಕೊಳ್ಳಲಾಗಿದೆ (ಕೇಸ್-ಇನ್‌ಸೆನ್ಸಿಟಿವ್) | ಬೇರೆ ಹೆಸರು ಆಯ್ಕೆ ಮಾಡಿ |
| «邮箱已被使用» (ಇಮೇಲ್ ಈಗಾಗಲೇ ಬಳಕೆಯಲ್ಲಿದೆ) | ಇಮೇಲ್ ಈಗಾಗಲೇ ನೋಂದಾಯಿತವಾಗಿದೆ | ಇಮೇಲ್ ಬದಲಿಸಿ; ಅಥವಾ ಲಾಗಿನ್ + «ಪಾಸ್ವರ್ಡ್ ಮರೆತಿರುವಿರಾ» ಮೂಲಕ ಹಳೆಯ ಖಾತೆ ಮರಳಿ ಪಡೆಯಿರಿ |
| «邮箱验证码错误或已过期» (ಇಮೇಲ್ ಪರಿಶೀಲನಾ ಕೋಡ್ ತಪ್ಪು ಅಥವಾ ಅವಧಿ ಮುಗಿದಿದೆ) | ಕೋಡ್ ತಪ್ಪು / 10 ನಿಮಿಷ ದಾಟಿದೆ / 5 ಕ್ಕಿಂತ ಹೆಚ್ಚು ತಪ್ಪು ಪ್ರಯತ್ನದಿಂದ ತಿರಸ್ಕರಿಸಲಾಗಿದೆ | «ಮತ್ತೆ ಕಳುಹಿಸಿ» ಕ್ಲಿಕ್ ಮಾಡಿ, **ಇತ್ತೀಚಿನ** ಇಮೇಲ್‌ನ ಕೋಡ್ ಬಳಸಿ |
| ಪರಿಶೀಲನಾ ಕೋಡ್ ಬರುವುದಿಲ್ಲ | 60 ಸೆಕೆಂಡ್ ರೇಟ್-ಲಿಮಿಟ್; ಅಥವಾ ಸ್ಪ್ಯಾಮ್/ಪ್ರಮೋ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಹೋಗಿದೆ | ಕೌಂಟ್‌ಡೌನ್ ಮುಗಿದ ನಂತರ ಮತ್ತೆ ಕಳುಹಿಸಿ; ಸ್ಪ್ಯಾಮ್ ಮೇಲ್ ಫೋಲ್ಡರ್ ನೋಡಿ |
| «手机号已被使用» (ಮೊಬೈಲ್ ಸಂಖ್ಯೆ ಈಗಾಗಲೇ ಬಳಕೆಯಲ್ಲಿದೆ) | ಮೊಬೈಲ್ ಸಂಖ್ಯೆ ಇನ್ನೊಂದು ಖಾತೆಗೆ ಬಂಧಿಯಾಗಿದೆ | ಮೊಬೈಲ್ ಸಂಖ್ಯೆ ತೆಗೆದುಹಾಕಿ (ಐಚ್ಛಿಕ) ಅಥವಾ ಸಂಖ್ಯೆ ಬದಲಿಸಿ |
| «注册请求过于频繁»/ 429 (ನೋಂದಣಿ ವಿನಂತಿ ತುಂಬಾ ಆಗಾಗ್ಗೆ) | ನೋಂದಣಿ 3 ಬಾರಿ/ನಿಮಿಷ/IP ಮಿತಿ ದಾಟಿದೆ | ಕೆಲವು ನಿಮಿಷಗಳ ನಂತರ ಮತ್ತೆ ಪ್ರಯತ್ನಿಸಿ |
| 409«用户名或邮箱已被注册» (ಹೆಸರು ಅಥವಾ ಇಮೇಲ್ ಈಗಾಗಲೇ ನೋಂದಾಯಿತವಾಗಿದೆ) | ಸಲ್ಲಿಸುವ ಕ್ಷಣದಲ್ಲಿ ಇನ್ನೊಬ್ಬರೊಂದಿಗೆ ಹೆಸರು ಸಂಘರ್ಷ (ಕನ್ಕರೆನ್ಸಿ ಫಾಲ್ಬ್ಯಾಕ್) | ಹೆಸರು ಅಥವಾ ಇಮೇಲ್ ಬದಲಿಸಿ ಮತ್ತೆ ಪ್ರಯತ್ನಿಸಿ |
| «图片大小不能超过5MB»/«不支持 SVG» (ಚಿತ್ರ 5MB ಗಿಂತ ದೊಡ್ಡದು / SVG ಬೆಂಬಲವಿಲ್ಲ) | ಪ್ರೊಫೈಲ್ ಫೋಟೋ ನಿಯಮಕ್ಕೆ ಅನುಸಾರವಿಲ್ಲ | ಫೋಟೋ ಬದಲಿಸಿ ಅಥವಾ ಪ್ರೊಫೈಲ್ ಫೋಟೋ ಬಿಟ್ಟುಬಿಡಿ |
| ನೋಂದಣಿ ಯಶಸ್ವಿ ಆದರೆ ಲಾಗಿನ್ 403«请完成订阅以激活账户» (ಖಾತೆ ಆಕ್ಟಿವೇಟ್ ಮಾಡಲು ದಯವಿಟ್ಟು ಸಬ್ಸ್ಕ್ರಿಪ್ಷನ್ ಪೂರ್ಣಗೊಳಿಸಿ) | ಖಾತೆ ಇನ್ನೂ pending ನಲ್ಲಿದೆ | ಲಾಗಿನ್ ಮಾಡಿ ಪುಟದ ಸೂಚನೆಯಂತೆ `/subscription` ನಲ್ಲಿ ಸಬ್ಸ್ಕ್ರಿಪ್ಷನ್ ಪೂರ್ಣಗೊಳಿಸಿ |
| ಲಾಗಿನ್ 423«账户已锁定» (ಖಾತೆ ಲಾಕ್ ಆಗಿದೆ) | ಪಾಸ್ವರ್ಡ್ ಸತತ 5 ಬಾರಿ ತಪ್ಪು | 30 ನಿಮಿಷ ಕಾಯಿರಿ |
| ಲಾಗಿನ್ 401«还剩 N 次尝试机会» (N ಪ್ರಯತ್ನದ ಅವಕಾಶ ಉಳಿದಿದೆ) | ಪಾಸ್ವರ್ಡ್ ತಪ್ಪು, ಲಾಕ್ ಆಗುವ ಹಂತದಲ್ಲಿದೆ | ಆಲೋಚಿಸಿ ಪ್ರಯತ್ನಿಸಿ, ಅಥವಾ ನೇರವಾಗಿ «ಪಾಸ್ವರ್ಡ್ ಮರೆತಿರುವಿರಾ» ಆಯ್ಕೆ ಮಾಡಿ |
| «该账号未设置密码，请使用其他方式登录» (ಈ ಖಾತೆಗೆ ಪಾಸ್ವರ್ಡ್ ಸೆಟ್ ಆಗಿಲ್ಲ, ದಯವಿಟ್ಟು ಬೇರೆ ವಿಧಾನದಿಂದ ಲಾಗಿನ್ ಮಾಡಿ) | ಥರ್ಡ್-ಪಾರ್ಟಿ (Google/Watcha/ಹುವಾವೇ) ಖಾತೆ | ಮೂಲ ಥರ್ಡ್-ಪಾರ್ಟಿ ಬಟನ್‌ನಿಂದ ಲಾಗಿನ್ ಮಾಡಿ |
| «该账号已注销» (ಖಾತೆ ಮುಚ್ಚಲಾಗಿದೆ) | ಖಾತೆ deactivate ಆಗಿದೆ | ಮತ್ತೆ ನೋಂದಾಯಿಸಬೇಕಾಗುತ್ತದೆ |

## ಲಾಗಿನ್ ಸಣ್ಣ ವಿವರ (ಪತ್ತೆಗೂ ಉಪಯುಕ್ತ)

ಲಾಗಿನ್ **ಬಳಕೆದಾರರ ಹೆಸರು / ಇಮೇಲ್ / ಮೊಬೈಲ್ ಸಂಖ್ಯೆ** ಮೂರನ್ನೂ ಒಟ್ಟಿಗೆ ಸ್ವೀಕರಿಸುತ್ತದೆ (ಮೂರರಲ್ಲಿ ಯಾವುದನ್ನೂ ಖಾತೆ ಹೆಸರಾಗಿ ಬಳಸಬಹುದು).
ಪಾಸ್ವರ್ಡ್ ಮರೆತಿರುವಿರಾ: ಲಾಗಿನ್ ಪುಟ → «ಪಾಸ್ವರ್ಡ್ ಮರೆತಿರುವಿರಾ» → ನೋಂದಾಯಿಸಿದ ಇಮೇಲ್ ಹಾಕಿ, 6 ಅಂಕಿಯ ಪರಿಶೀಲನಾ ಕೋಡ್ ಪಡೆಯಿರಿ → ರೀಸೆಟ್ ಮಾಡಿ.
