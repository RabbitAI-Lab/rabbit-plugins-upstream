# ನೋಂದಾಯಿಕೆ ಪ್ರವಾಹ ವಿವರಣೆ — powpow-register

ದೋಷ ನಿವಾರಣೆಯ ಸಮಯದಲ್ಲಿ ನೋಡಲು. ಎಲ್ಲಾ ನಿಯಮಗಳು ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಮೂಲ ಕೋಡ್‌ನಿಂದ (Next.js ಮುಂಭಾಗ ಮತ್ತು ಹಿನ್ಭಾಗ ಸ್ಥಿರತೆ ಪರಿಶೀಲನೆ), ಮೂಲ ಸ್ಥಾನ ಗುರುತಿಸಲಾಗಿದೆ. ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ನವೀಕರಿಸಿದಾಗ, ಆನ್‌ಲೈನ್ ವಾಸ್ತವ ನಡವಳಿಕೆಯನ್ನು ಅವಲಂಬಿಸಿ.

## ಪ್ರವೇಶ

- ನೋಂದಾಯಿಕೆ ಪುಟ: https://global.powpow.online/register
- ಲಾಗಿನ್ ಪುಟ: https://global.powpow.online/login
- ಚಂದಾದಾರಿಕೆ ಪುಟ: https://global.powpow.online/subscription
- `?next=...` ಹೊಂದಿರುವ ಹಂಚಿಕೆ ಲಿಂಕ್ ಮುಂತಾದುದರಿಂದ ಪ್ರವೇಶಿಸಿದರೆ, ನೋಂದಾಯಿಕೆ + ಪಾವತಿ ಪೂರ್ಣಗೊಂಡ ನಂತರ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಮೂಲ ಪುಟಕ್ಕೆ ಹಿಂದಿರುಗುತ್ತದೆ.

## ಫಾರ್ಮ್ ಕ್ಷೇತ್ರಗಳು ಮತ್ತು ನಿಯಮಗಳು

| ಕ್ಷೇತ್ರ | ಬೇಕಾ | ನಿಯಮ | ಮೂಲ ಕೋಡ್ ಸ್ಥಾನ |
|---|---|---|---|
| ಪ್ರೊಫೈಲ್ ಚಿತ್ರ | ಐಚ್ಛಿಕ | ಚಿತ್ರ ≤5MB, SVG ಬೆಂಬಲಿಸುವುದಿಲ್ಲ; ಸರ್ವರ್ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಸಂಕುಚಿಸುತ್ತದೆ (>100KB ಆಗಿದ್ದರೆ 400×400 / ಗುಣಮಟ್ಟ 90) | `src/app/api/auth/register/route.ts` |
| ಬಳಕೆದಾರಹೆಸರು | ಬೇಕು | 2~50 ಅಕ್ಷರಗಳು, trim ಮಾಡಿದ ನಂತರ **ಸಣ್ಣಕ್ಷರ** ಸಂಗ್ರಹಿಸಲಾಗುತ್ತದೆ (Tom ಮತ್ತು tom ಅನ್ನು ಒಂದೇ ಬಳಕೆದಾರಹೆಸರು ಎಂದು ಪರಿಗಣಿಸಲಾಗುತ್ತದೆ, ನೋಂದಾಯಿಕೆ ಮತ್ತು ಲಾಗಿನ್ ಎರಡೂ ಕೇಸ್-ಅಸಂವೇದನಾಶೀಲ) | ಅದೇ (zod schema) |
| ಪಾಸ್‌ವರ್ಡ್ | ಬೇಕು | 8~100 ಉದ್ದ, ದೊಡ್ಡಕ್ಷರ, ಸಣ್ಣಕ್ಷರ, ಸಂಖ್ಯೆ ಎಲ್ಲವೂ ಒಟ್ಟಿಗೆ ಇರಬೇಕು | ಅದೇ |
| ಪಾಸ್‌ವರ್ಡ್ ದೃಢೀಕರಿಸಿ | ಬೇಕು | ಪಾಸ್‌ವರ್ಡ್‌ಗೆ ಸಮಾನ (ಕೇವಲ ಮುಂಭಾಗ ಪರಿಶೀಲನೆ) | `src/app/(public)/register/page.tsx` |
| ಅಪ್ಪಣನಾಮ | ಐಚ್ಛಿಕ | ≤100 ಅಕ್ಷರಗಳು; ಖಾಲಿ ಬಿಟ್ಟರೆ ಡೀಫಾಲ್ಟ್ ಬಳಕೆದಾರಹೆಸರು | register route |
| ಇಮೇಲ್ | **ಬೇಕು** | ಕಾನೂನುಬದ್ಧ ಇಮೇಲ್ ಸ್ವರೂಪ, ≤255 ಅಕ್ಷರಗಳು; ಒಂದು ಇಮೇಲ್ ಒಂದು ಖಾತೆ ಮಾತ್ರ ನೋಂದಾಯಿಸಬಹುದು | register route |
| ಇಮೇಲ್ ಪರಿಶೀಲನಾ ಸಂಕೇತ | **ಬೇಕು** | 6-ಅಂಕಿ; **10 ನಿಮಿಷ ಮಾನ್ಯ**; ಯಶಸ್ವಿ ಪರಿಶೀಲನೆಯೊಂದಿಗೆ ರದ್ದಾಗುತ್ತದೆ; ಮರುಕಳುಹಿಸುವುದು ಹಳೆಯ ಸಂಕೇತವನ್ನು ಬಳಸಲಾಗಿದೆ ಎಂದು ಗುರುತಿಸುತ್ತದೆ | `src/lib/email-verification.ts` |
| ಫೋನ್ ಸಂಖ್ಯೆ | ಐಚ್ಛಿಕ | ಮೈನ್‌ಲ್ಯಾಂಡ್ ಫೋನ್ `1[3-9]` ಪ್ರಾರಂಭ 11 ಅಂಕಿಗಳು; ಒಂದು ಫೋನ್ ಒಂದು ಖಾತೆಗೆ ಮಾತ್ರ ಬಂಧಿಸಬಹುದು | register route |

ಪುಟ ಮೂರು ಮೂರನೇ-ಪಕ್ಷ ಲಾಗಿನ್ ಬಟನ್‌ಗಳನ್ನು ಸಹ ಒದಗಿಸುತ್ತದೆ: **Google, Watcha, Huawei** (`GoogleSignInButton` /
`WatchaLoginButton` / `HuaweiLoginButton`). ಮೂರನೇ-ಪಕ್ಷ ಖಾತೆಗಳಿಗೆ ಸ್ಥಳೀಯ ಪಾಸ್‌ವರ್ಡ್ ಇರುವುದಿಲ್ಲ, ನಂತರ ಪಾಸ್‌ವರ್ಡ್ ಲಾಗಿನ್ ಬಳಸಿದರೆ
`该账号未设置密码，请使用其他方式登录` ಸಂದೇಶ ಬರುತ್ತದೆ.

## ರೇಟ್-ಲಿಮಿಟ್ ಮತ್ತು ಬ್ರೂಟ್-ಫೋರ್ಸ್ ನಿರೋಧಕ ನಿಯತಾಂಕಗಳು

| ನಡವಳಿಕೆ | ಮಿತಿ | ಮೂಲ |
|---|---|---|
| ನೋಂದಾಯಿಕೆ ಸಲ್ಲಿಕೆ | **3 ಬಾರಿ/ನಿಮಿಷ/IP**, ಮೀರಿದರೆ 429 | `src/lib/rate-limit.ts` `REGISTER_RATE_LIMIT` |
| ಸಂಕೇತ ಕಳುಹಿಸುವುದು | ಅದೇ IP 1 ಬಾರಿ/ನಿಮಿಷ **ಮತ್ತು** ಅದೇ ಇಮೇಲ್ 1 ಬಾರಿ/ನಿಮಿಷ, ಮೀರಿದರೆ 429; ಮುಂಭಾಗ ಬಟನ್ 60 ಸೆಕೆಂಡ್ ಕೌಂಟ್‌ಡೌನ್ | `src/app/api/auth/register/send-code/route.ts` |
| ಸಂಕೇತ ಪರಿಶೀಲನೆ | ಪ್ರತಿ ಇಮೇಲ್ 10 ನಿಮಿಷದೊಳಗೆ ಗರಿಷ್ಠ **5 ಪ್ರಯತ್ನ**, ಮಿತಿ ತಲುಪಿದರೆ ಸಂಕೇತ ಸರಿಯಿದ್ದರೂ ತಿರಸ್ಕರಿಸುತ್ತದೆ, ಮರುಕಳುಹಿಸಬೇಕು | `src/lib/email-verification.ts` |
| ಪಾಸ್‌ವರ್ಡ್ ಮರಳಿ-ಪಡೆಯುವಿಕೆ ಸಂಕೇತ | 1 ಬಾರಿ/ನಿಮಿಷ/IP | `src/app/api/auth/forgot-password/route.ts` |
| ಲಾಗಿನ್ | 5 ಬಾರಿ/ನಿಮಿಷ/IP; ಅದೇ ಖಾತೆ ಸತತ **5 ಬಾರಿ ವಿಫಲ 30 ನಿಮಿಷ ಲಾಕ್** (423), ಆ ಸಮಯದಲ್ಲಿ ಉಳಿದ ಪ್ರಯತ್ನಗಳು ಕಡಿಮೆಯಾಗುತ್ತವೆ ಸೂಚಿಸುತ್ತದೆ | `src/app/api/auth/login/route.ts`, `rate-limit.ts` |

**ಖಾಸಗ್ಯತೆ ರಕ್ಷಣಾ ನಡವಳಿಕೆ**: ಸಂಕೇತ ಕಳುಹಿಸುವಾಗ / ಪಾಸ್‌ವರ್ಡ್ ಮರಳಿ-ಪಡೆಯುವಾಗ, ಇಮೇಲ್ ಈಗಾಗಲೇ ನೋಂದಾಯಿತವಾಗಿದ್ದರೆ ಅಥವಾ ಇಲ್ಲದಿದ್ದರೆ, ಇಂಟರ್‌ಫೇಸ್ ಎರಡೂ ಸಂದರ್ಭದಲ್ಲಿ ಯಶಸ್ಸು ಪಠ್ಯವನ್ನು ಏಕರೀತಿಯಾಗಿ ಹಿಂತಿರುಗಿಸುತ್ತದೆ, ಇಮೇಲ್ ನೋಂದಾಯಿತವಾಗಿದೆಯೇ ಎಂಬುದನ್ನು ಬಹಿರಂಗಪಡಿಸುವುದಿಲ್ಲ.

## agent-ಸಹಾಯಕ ಮೋಡ್ ಮತ್ತು ವೆಬ್ ನೋಂದಾಯಿಕೆಯ ಸಮಾನತೆ

ಸ್ಕಿಲ್ ಸ್ಕ್ರಿಪ್ಟ್ ಅದೇ **ಸಾರ್ವಜನಿಕ API ಗುಂಪನ್ನು** (`/api/auth/register`, `send-code`, `login`,
`/api/auth/me`) ಕರೆಯುತ್ತದೆ, ಮತ್ತು ನೋಂದಾಯಿಕೆ ಪುಟ ಫಾರ್ಮ್ ಸಲ್ಲಿಕೆ ಅದೇ ಪರಿಶೀಲನೆ, ರೇಟ್-ಲಿಮಿಟ್ ಮತ್ತು ದೋಷ ಮಾರ್ಗಗಳ ಮೂಲಕ ಹೋಗುತ್ತದೆ — ಈ
ಕಡತದ ಎಲ್ಲಾ ನಿಯಮಗಳು ಎರಡೂ ಮೋಡ್‌ಗಳಿಗೆ ಸಮಾನ. ಸ್ಕ್ರಿಪ್ಟ್ ಕಾಲಕ್ರಮ ಮತ್ತು ಆಜ್ಞೆ ಒಪ್ಪಂದ `references/agent-flow.md` ನೋಡಿ.

## ನೋಂದಾಯಿಕೆ ಯಶಸ್ಸಿನ ನಂತರ ಸ್ಥಿತಿ ಹರಿವು

1. ಬಳಕೆದಾರ `accountStatus: 'pending'` ಆಗಿ ಸಂಗ್ರಹಿಸಲ್ಪಡುತ್ತಾರೆ, ಆರಂಭಿಕ **3 ಬ್ಯಾಚ್‌ಗಳು** (register route).
2. ಸರ್ವರ್ ಸಹ ಎರಡು HttpOnly cookie ಗಳನ್ನು ನಾಟುತ್ತದೆ: JWT (ನೇರವಾಗಿ `/subscription` ಪ್ರವೇಶಿಸಬಹುದು) ಮತ್ತು
   pendingUserToken (ಚಂದಾದಾರಿಕೆ ಪ್ರವಾಹ ಗುರುತಿನ ರುಜುವಾತು).
3. ನೋಂದಾಯಿಕೆ ಪುಟ `pending_payment` ಪತ್ತೆ ಮಾಡುತ್ತದೆ → `/subscription` ಗೆ ನ್ಯಾವಿಗೇಟ್ (ರೀಡೈರೆಕ್ಟ್ `next` ಉಳಿಸುತ್ತದೆ);
   agent-ಸಹಾಯಕ ಮೋಡ್‌ನಲ್ಲಿ `me?token=…&redirect=/subscription` ಬಳಸಿ ಅದೇ ಪರಿಣಾಮ ಸಾಧಿಸುತ್ತದೆ.
4. ಪಾವತಿ ಪೂರ್ಣ → `accountStatus` `active` ಆಗುತ್ತದೆ (**Alipay notify ಮೂಲಕ ಸರ್ವರ್ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಸಕ್ರಿಯಗೊಳಿಸುತ್ತದೆ**;
   PayPal Webhook ಮೂಲಕ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಸಕ್ರಿಯಗೊಳಿಸುತ್ತದೆ; WeChat QR ಮಾನವ ದೃಢೀಕರಣ; Huawei IAP `activate-huawei` ಮೂಲಕ).
   ಇನ್ನಷ್ಟು ವಿವರ `payment-and-activation.md` ನೋಡಿ.

ಸಕ್ರಿಯಗೊಳಿಸದ (pending) ಬಳಕೆದಾರ ಮುಖ್ಯ API (ಫೀಡ್, ನಕ್ಷೆ, ಡಿಜಿಟಲ್ ಮಾನವ ಸಂಭಾಷಣೆ, ಚೆಕ್-ಇನ್, ಮುಂತಾದವು) ಕರೆದಾಗ ಯಾವಾಗಲೂ 403; ಹಂಚಿದ ಪೋಸ್ಟ್ ಲಿಂಕ್ ಮಾತ್ರ ಹೊರತು (ಸಾರ್ವಜನಿಕ ಪ್ರವೇಶ ಉಳಿಯುತ್ತದೆ).

## ಸಾಮಾನ್ಯ ದೋಷ ನಿವಾರಣೆ ಕೋಷ್ಟಕ

| ಸಂಗತಿ | ಕಾರಣ | ಏನು ಮಾಡಬೇಕು |
|---|---|---|
| 「用户名已存在」 | ಬಳಕೆದಾರಹೆಸರು ಆಕ್ರಮಿಸಲ್ಪಟ್ಟಿದೆ (ಕೇಸ್ ಪರವಾಹಿಯಿಲ್ಲ) | ಬಳಕೆದಾರಹೆಸರು ಬದಲಾಯಿಸಿ |
| 「邮箱已被使用」 | ಇಮೇಲ್ ಈಗಾಗಲೇ ನೋಂದಾಯಿತ | ಇಮೇಲ್ ಬದಲಾಯಿಸಿ; ಅಥವಾ ಲಾಗಿನ್ + "忘记密码" ಹೊಳೆದು ಹಳೆಯ ಖಾತೆ ಮರಳಿ-ಪಡೆಯಿರಿ |
| 「邮箱验证码错误或已过期」 | ಸಂಕೇತ ತಪ್ಪಾಗಿ ನಮೂದಿಸಿದೆ / 10 ನಿಮಿಷ ಮೀರಿದೆ / 5 ಪ್ರಯತ್ನ ಮೀರಿ ತಿರಸ್ಕೃತ | "重新发送" ಕ್ಲಿಕ್ ಮಾಡಿ, **ಇತ್ತೀಚಿನ** ಇಮೇಲ್ ಸಂಕೇತ ಬಳಸಿ |
| ಸಂಕೇತ ಬರುವುದಿಲ್ಲ | 60 ಸೆಕೆಂಡ್ ರೇಟ್-ಲಿಮಿಟ್; ಅಥವಾ ಸ್ಪ್ಯಾಮ್/ಜಾಹೀರಾತು ಫೋಲ್ಡರ್‌ಗೆ ಹೋಗಿದೆ | ಕೌಂಟ್‌ಡೌನ್ ಮುಗಿದ ನಂತರ ಮತ್ತೆ ಕಳುಹಿಸಿ; ಸ್ಪ್ಯಾಮ್ ಫೋಲ್ಡರ್ ಪರಿಶೀಲಿಸಿ |
| 「手机号已被使用」 | ಫೋನ್ ಸಂಖ್ಯೆ ಇತರ ಖಾತೆಗೆ ಬಂಧಿಸಲ್ಪಟ್ಟಿದೆ | ಫೋನ್ ಸಂಖ್ಯೆ ತೆಗೆದುಹಾಕಿ (ಐಚ್ಛಿಕ) ಅಥವಾ ಬದಲಾಯಿಸಿ |
| 「注册请求过于频繁」/ 429 | ನೋಂದಾಯಿಕೆ 3 ಬಾರಿ/ನಿಮಿಷ/IP ಮಿತಿ ಮುಟ್ಟಿದೆ | ಕೆಲವು ನಿಮಿಷ ಕಾಯಿರಿ ನಂತರ ಮರುಪ್ರಯತ್ನಿಸಿ |
| 409「用户名或邮箱已被注册」 | ಸಲ್ಲಿಕೆಯ ಕ್ಷಣದಲ್ಲಿ ಇತರರೊಂದಿಗೆ ಹೆಸರು ಡಿಕ್ಕಿ (ಸಮಕಾಲಿಕ ರಕ್ಷಣೆ) | ಬಳಕೆದಾರಹೆಸರು ಅಥವಾ ಇಮೇಲ್ ಬದಲಾಯಿಸಿ ನಂತರ ಮರುಪ್ರಯತ್ನಿಸಿ |
| 「图片大小不能超过5MB」/「不支持 SVG」 | ಪ್ರೊಫೈಲ್ ಚಿತ್ರ ಅನುಚಿತ | ಚಿತ್ರ ಬದಲಾಯಿಸಿ ಅಥವಾ ಪ್ರೊಫೈಲ್ ಚಿತ್ರ ಬಿಡಿ |
| ನೋಂದಾಯಿಕೆ ಯಶಸ್ವಿ ಆದರೆ ಲಾಗಿನ್ 403「请完成订阅以激活账户」 | ಖಾತೆ ಇನ್ನೂ pending (ಪಾವತಿಗಿಂತ ಮೊದಲು ನಿರೀಕ್ಷಿತ ಸ್ಥಿತಿ) | ಪಾವತಿಗಿಂತ ಮೊದಲು: ಇದು ಸಾಮಾನ್ಯ, ಮೊದಲು ಚಂದಾದಾರಿಕೆ ಪೂರ್ಣಗೊಳಿಸಿ; ಪಾವತಿಸಿದ ನಂತರವೂ 403: ಹಳೆಯ JWT ಬಳಸಿದ್ದೀರಿ ಎಂದರ್ಥ, ಸ್ಕ್ರಿಪ್ಟ್ ಮೋಡ್‌ನಲ್ಲಿ ಮೊದಲು `refresh-login` ಹೊಸ ಲಾಗಿನ್ ಸ್ಥಿತಿ |
| ಲಾಗಿನ್ 423「账户已锁定」 | ಪಾಸ್‌ವರ್ಡ್ 5 ಬಾರಿ ಸತತ ತಪ್ಪು | 30 ನಿಮಿಷ ಕಾಯಿರಿ |
| ಲಾಗಿನ್ 401「还剩 N 次尝试机会」 | ಪಾಸ್‌ವರ್ಡ್ ತಪ್ಪು, ಲಾಕ್ ಆಗುವ ಹತ್ತಿರ | ಚಿಂತಿಸಿ ನಂತರ ಪ್ರಯತ್ನಿಸಿ, ಅಥವಾ ನೇರವಾಗಿ "忘记密码" ಗೆ ಹೋಗಿ |

## ಲಾಗಿನ್ ಸಣ್ಣ ಜ್ಞಾನ (ನಿವಾರಣೆಗೆ)

ಲಾಗಿನ್ **ಬಳಕೆದಾರಹೆಸರು / ಇಮೇಲ್ / ಫೋನ್ ಸಂಖ್ಯೆ** ಮೂರನ್ನೂ ಸ್ವೀಕರಿಸುತ್ತದೆ (ಮೂರರಲ್ಲಿ ಯಾವುದಾದರೂ ಖಾತೆ ಹೆಸರಾಗಿ ಬಳಸಬಹುದು). ಪಾಸ್‌ವರ್ಡ್ ಮರಳಿ-ಪಡೆಯುವಿಕೆ: ಲಾಗಿನ್ ಪುಟ → "忘记密码" → ನೋಂದಾಯಿತ ಇಮೇಲ್ ನಮೂದಿಸಿ 6-ಅಂಕಿ ಸಂಕೇತ ಪಡೆಯಿರಿ → ಮರುಹೊಂದಿಸಿ.
