# powpow-register

PowPow ಗುಳ್ಳೆ ನೋಂದಾಯಿಕೆ ಸಹಾಯಕ (OpenClaw ಆವೃತ್ತಿ): ಹೊಸ ಬಳಕೆದಾರರನ್ನು "ಗುಳ್ಳೆ ಎಂದರೆ ಏನೆಂದು ಗೊತ್ತಿಲ್ಲ" ಎಂಬುದರಿಂದ "ಖಾತೆ ಸಕ್ರಿಯಗೊಂಡಿದೆ, ಒಂದು-ಕ್ಲಿಕ್ ಲಾಗಿನ್, ಆಟ ಪ್ರಾರಂಭ" ವರೆಗೆ ಕರೆದೊಯ್ಯುತ್ತದೆ — ಉತ್ಪನ್ನ ಪರಿಚಯ (ಇಂಟರ್‌ಫೇಸ್ ಸ್ಕ್ರೀನ್‌ಶಾಟ್‌ಗಳು ಸೇರಿದಂತೆ), agent-ಸಹಾಯಕ ನೋಂದಾಯಿಕೆ (ಪ್ರೊಫೈಲ್ ಚಿತ್ರ ಅಪ್‌ಲೋಡ್ ಸೇರಿದಂತೆ), Alipay ಚಂದಾದಾರಿಕೆ ಆದೇಶ ಮತ್ತು ಬಂದಿಳಿಕೆ ಟ್ರ್ಯಾಕಿಂಗ್, ಎರಡು-ಲಿಂಕ್ ಒಂದು-ಕ್ಲಿಕ್ ಲಾಗಿನ್, ದೋಷ ನಿವಾರಣೆ.

**v2.0.0 ರಿಂದ agent-ಸಹಾಯಕ ಮೋಡ್**: ಮುಖ್ಯ ಸ್ಕ್ರಿಪ್ಟ್ `scripts/powpow-register.mjs` ಅವಲಂಬನೆಗಳಿಲ್ಲ (Node >= 18), ಬಳಕೆದಾರ ಸಂಭಾಷಣೆಯಿಂದ ಹೊರಬರುವುದಿಲ್ಲ, ಕೇವಲ ಎರಡು ಬಾರಿ ತಾತ್ಕಾಲಿಕವಾಗಿ ಹೊರಬರುತ್ತಾರೆ: ಇಮೇಲ್‌ಗೆ ಹೋಗಿ ಸಂಕೇತ ನೋಡಲು, Alipay ಕ್ಯಾಶಿಯರ್‌ನಲ್ಲಿ ಪಾವತಿಸಲು. Node ಇಲ್ಲದಿದ್ದರೆ ಅಥವಾ ಬಳಕೆದಾರ ಸ್ವತಃ ಮಾಡಲು ಬಯಸಿದರೆ, ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಶುದ್ಧ ಮಾರ್ಗದರ್ಶಿ ಮೋಡ್‌ಗೆ ಹಿಂದಿರುಗುತ್ತದೆ.

## ಸ್ಥಾಪನೆ

```

```

## ವೈಶಿಷ್ಟ್ಯಗಳು

1. **ಉತ್ಪನ್ನ ಪರಿಚಯ**: ~120 ಪದಗಳ ಆರಂಭ + ಪ್ಯಾಕೇಜ್‌ನೊಂದಿಗೆ ಸೇರಿಸಲಾದ ಇಂಟರ್‌ಫೇಸ್ ಸ್ಕ್ರೀನ್‌ಶಾಟ್‌ಗಳು (`assets/screenshots/` ಕೆಳಗೆ 6 ಚಿತ್ರಗಳು: ನಕ್ಷೆ ಪುಟ, ಪೋಸ್ಟ್ ವಿವರ ಪುಟ, ಮುಂತಾದವು, ಸನ್ನಿವೇಶಕ್ಕೆ 1–3 ಆಯ್ಕೆ ಮಾಡಿ ಕಳುಹಿಸಿ; ಬಾಹ್ಯ ಚಿತ್ರ ಹೋಸ್ಟ್ ಬೇಕಿಲ್ಲ, ಆಫ್‌ಲೈನ್ ಕಾರ್ಯಸಾಧ್ಯ).
2. **ಸಹಾಯಕ ನೋಂದಾಯಿಕೆ**: agent ಬಳಕೆದಾರಹೆಸರು/ಅಪ್ಪಣನಾಮ ಸಲಹೆ, ಪಾಸ್‌ವರ್ಡ್ ಎರಡರಲ್ಲಿ ಒಂದು (ಬಳಕೆದಾರ ಒದಗಿಸುವುದು ಅಥವಾ agent ರಚಿಸುವುದು), ಸಂಕೇತ ಕಳುಹಿಸುವಿಕೆ ಮತ್ತು ಸಲ್ಲಿಕೆ, ಪ್ರೊಫೈಲ್ ಚಿತ್ರ ನೇರ ಅಪ್‌ಲೋಡ್ (≤5MB SVG ಅಲ್ಲ), ಸಾಮಾನ್ಯ ದೋಷಗಳನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ನಿಭಾಯಿಸುವುದು (ಆಕ್ರಮಣ/ಅವಧಿ ಮೀರಿದೆ/ರೇಟ್-ಲಿಮಿಟ್).
3. **ಒಂದು-ಕ್ಲಿಕ್ ಲಾಗಿನ್ (ಎರಡು ಲಿಂಕ್‌ಗಳು)**: ನೋಂದಾಯಿಕೆ ಯಶಸ್ವಿಯಾದ ತಕ್ಷಣ "ಅರ್ಧ-ಲಾಗಿನ್" ಲಿಂಕ್ ನೇರವಾಗಿ ಚಂದಾದಾರಿಕೆ ಪುಟಕ್ಕೆ; ಪಾವತಿ ಬಂದಾಗ ಹೊಸ ಲಾಗಿನ್ ಸ್ಥಿತಿ ವಿನಿಮಯ ಮಾಡಿ ಸಂಪೂರ್ಣ ಸದಸ್ಯ ಲಿಂಕ್ ನೇರವಾಗಿ ಮುಖಪುಟಕ್ಕೆ (ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಅಧಿಕೃತ `me?token=` ಬ್ರಿಜ್ ಮೂಲಕ, HttpOnly cookie ಅನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ನಾಟುತ್ತದೆ).
4. **ಚಂದಾದಾರಿಕೆ ಪಾವತಿ**: Alipay ಮಾರ್ಗ agent-ಸಹಾಯಕ ಆದೇಶ (ಮಾಸಿಕ ¥6.99 / ತ್ರೈಮಾಸಿಕ ¥19.99 / ವಾರ್ಷಿಕ ¥69.99, ಒಂದು-ಬಾರಿ ಖರೀದಿ ಸ್ವಯಂಚಾಲಿತ ರಿನ್ಯೂವಲ್ ಇಲ್ಲ) + ಬಂದಿಳಿಕೆ ಪೋಲ್; ವಿದೇಶ ಬಳಕೆದಾರ PayPal ಗೆ ಹಿಂದಿರುಗುತ್ತಾರೆ; WeChat QR / Huawei IAP ಮಾರ್ಗದರ್ಶನ.
5. **ದೋಷ ನಿವಾರಣೆ**: ಸಂಕೇತ ಬರುವುದಿಲ್ಲ, ಬಳಕೆದಾರಹೆಸರು/ಇಮೇಲ್ ಆಕ್ರಮಿಸಲ್ಪಟ್ಟಿದೆ, 403 ಸಕ್ರಿಯಗೊಂಡಿಲ್ಲ, ಖಾತೆ ಲಾಕ್ ಮಾಡಲಾಗಿದೆ, ಮುಂತಾದ ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು, ಎಲ್ಲವೂ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಮೂಲ ಕೋಡ್‌ನಿಂದ ಮತ್ತು ಮೂಲ ಸ್ಥಾನ ಗುರುತಿಸಲಾಗಿದೆ.

## ಭದ್ರತೆ

- **ಪಾಸ್‌ವರ್ಡ್** ಕೇವಲ ಪರಿಸರ ವೇರಿಯೇಬಲ್ ಮೂಲಕ ಸ್ಕ್ರಿಪ್ಟ್ ಪ್ರೋಸೆಸ್‌ಗೆ ರವಾನಿಸಲಾಗುತ್ತದೆ, ಕಮಾಂಡ್-ಲೈನ್ ಆರ್ಗ್ಯುಮೆಂಟ್‌ಗಳಲ್ಲಿ ಎಂದೂ ಬರೆಯಬೇಡಿ, ಡಿಸ್ಕ್‌ಗೆ ಉಳಿಸಬೇಡಿ, ಸ್ಥಿತಿ ಕಡತಕ್ಕೆ ಹಾಕಬೇಡಿ; agent ರಚಿಸಿದ ಪಾಸ್‌ವರ್ಡ್ ಕೇವಲ ಒಮ್ಮೆ ಬಳಕೆದಾರ ಉಳಿಸಿಕೊಳ್ಳಲು ತೋರಿಸಲಾಗುತ್ತದೆ.
- **ಸಂಕೇತ** ಕೇವಲ ಅಧಿಕೃತ ನೋಂದಾಯಿಕೆ ಇಂಟರ್‌ಫೇಸ್‌ಗೆ ಮಾತ್ರ, ಬಳಸಿದ ನಂತರ ತ್ಯಜಿಸಲಾಗುತ್ತದೆ; ಸ್ಥಿತಿ ಕಡತ (ಇಮೇಲ್ / ಬಳಕೆದಾರಹೆಸರು / token / ಆದೇಶ ಸಂಖ್ಯೆ) ಸಿಸ್ಟಮ್ ತಾತ್ಕಾಲಿಕ ಡೈರೆಕ್ಟರಿಯಲ್ಲಿ, ಪ್ರವಾಹ ಕೊನೆಯಲ್ಲಿ `cleanup` ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಅಳಿಸುತ್ತದೆ.
- **ಪಾವತಿ**: agent ಕೇವಲ ಆದೇಶ ರಚಿಸುತ್ತದೆ, ಕ್ಯಾಶಿಯರ್ ತೆರೆಯುತ್ತದೆ, ಬಂದಿಳಿಕೆ ಪ್ರಶ್ನಿಸುತ್ತದೆ; ಬಳಕೆದಾರರ Alipay ಖಾತೆ ಅಥವಾ ಪಾವತಿ ರುಜುವಾತುಗಳನ್ನು ಎಂದೂ ಮುಟ್ಟುವುದಿಲ್ಲ, ಎಂದೂ ಪರವಾಗಿ ಪಾವತಿಸುವುದಿಲ್ಲ. ಪಾವತಿ ಯಾವಾಗಲೂ ಬಳಕೆದಾರ ಮತ್ತು Alipay ಅಧಿಕೃತ ಕ್ಯಾಶಿಯರ್ ನಡುವೆ ಪೂರ್ಣಗೊಳ್ಳುತ್ತದೆ.
- ಎಲ್ಲಾ ವಿನಂತಿಗಳು ಕೇವಲ ಅಧಿಕೃತ ಡೊಮೇನ್ `https://global.powpow.online` ಗೆ; ಯಾವುದೇ ಕೀ ಇಲ್ಲ.
