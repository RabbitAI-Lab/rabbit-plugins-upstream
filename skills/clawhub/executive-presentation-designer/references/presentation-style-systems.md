# Presentation Style Systems

Choose one system and apply it consistently.

## Minimal Executive

Best for board updates, strategy, finance, operations.

- White or near-white canvas.
- Black/gray typography with one accent color.
- Thin dividers, precise tables, clear charts.
- High information density without clutter.
- Polished, restrained, serious.

## Editorial Keynote

Best for launches, vision decks, portfolios, product narratives.

- Large type and strong visual pacing.
- Full-bleed images or bold section slides.
- Fewer words, stronger headlines.
- Asymmetry with disciplined alignment.
- Designed for live presentation.

## Dark Product Studio

Best for AI, software, developer tools, creative tech.

- Dark canvas with high-contrast text.
- Luminous but restrained accent color.
- Product screenshots, UI fragments, code or workflow diagrams.
- Avoid low-contrast gray-on-black text.

## Data Report

Best for research, analytics, market scans, performance reports.

- Dense but organized.
- Tables, charts, callouts, and evidence blocks.
- Color mapped to consistent meanings.
- Clear source notes and assumptions.

## Avoid

- Default template gradients.
- Random icon styles.
- Heavy bullet walls.
- Tiny chart labels.
- Overdecorated covers.
- Too many fonts, colors, and shape styles.
