## A. 改版战略摘要（阶段 3 · 四问）

```
【改版战略摘要】
1. 卖什么：<产品 / 服务 / 解决方案，具体到 SKU 或业务线>
2. 卖给谁：<目标客户画像：行业 / 角色 / 规模 / 痛点>
3. 市场在哪里：<地域 / 渠道 / 线上 or 线下 / 是否出海>
4. 核心竞争力：<差异化 + 证据（资质 / 案例 / 技术 / 服务）>
一句话定位：<用一句人话讲清楚"我们是做什么的、为谁、凭什么">
```
