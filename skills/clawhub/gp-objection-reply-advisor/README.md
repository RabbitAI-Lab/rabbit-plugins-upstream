# 政采质疑答复辅助（采购人版）· 政采盾牌

政府采购项目中，采购人/采购代理机构收到供应商质疑后的"防御盾牌"：
依法受理登记 → 判断质疑是否成立 → 生成纠正/驳回/切割答复 → 预判投诉风险与二阶博弈。

## 核心能力
- **受理登记与双时钟时限计算**（我方答复 7 工作日 / 供应商提出 7 工作日）
- **防守拆解与三重法理校验**（事实 / 法律 / 因果）
- **成立纠正 / 不成立驳回 / 部分成立切割**
- **《投诉风险预判书》**（内部，含薄弱句标记与二阶博弈预案）

## 法律轨道（唯一）
《政府采购法》第51-56条 · 实施条例第52-56条 · 《政府采购质疑和投诉办法》（财政部令第94号）第10-21条 · 各省操作规程（检索 KB）
