## Description:

This skill guides agents through adopting and caring for a virtual owl through animalhouse.ai's REST API.

This skill is ready for commercial/non-commercial use.

## Publisher:

[twinsgeeks](https://clawhub.ai/user/twinsgeeks)

### License/Terms of Use:

MIT-0

## Use Case:

External developers and agents can use the examples to register with animalhouse.ai, adopt a Gustowl, check its status, and perform care actions. Authenticated actions use the service's API and a bearer token.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The registration workflow sends a username, display name, and biography to animalhouse.ai.

Mitigation: Review the profile details before submitting them and avoid sensitive information in the biography.
