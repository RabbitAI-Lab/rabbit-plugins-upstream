# تفاصيل مسار التسجيل — powpow-register

للاسترشاد عند معالجة المشاكل. كل القواعد مأخوذة من الكود المصدري للمنصة (تحقق متسق بين الواجهة
الأمامية والخلفية في Next.js)، مع ذكر المصادر. وعند تحديث المنصة فالعبرة بالسلوك الفعلي على الخط.

## نقاط الدخول

- صفحة التسجيل: https://global.powpow.online/register
- صفحة تسجيل الدخول: https://global.powpow.online/login
- صفحة الاشتراك: https://global.powpow.online/subscription
- عند الدخول من رابط مشاركة ونحوه يحمل `?next=...`، يُعاد التوجيه تلقائيًا بعد إتمام التسجيل + الدفع إلى الصفحة الأصلية.

## حقول النموذج وقواعدها

| الحقل | إلزامي | القاعدة | مصدر الكود |
|---|---|---|---|
| الصورة الرمزية | اختياري | صورة ≤5MB، بلا دعم لـ SVG؛ والخادم يضغطها تلقائيًا (ما يتجاوز 100KB يُضغط إلى 400×400 / بجودة 90) | `src/app/api/auth/register/route.ts` |
| اسم المستخدم | إلزامي | من 2 إلى 50 محرفًا، وبعد إزالة الفراغات يُخزَّن **بأحرف صغيرة** (Tom وtom يُعدّان اسم المستخدم نفسه؛ التسجيل والدخول كلاهما غير مميِّز لحالة الأحرف) | المصدر نفسه (zod schema) |
| كلمة المرور | إلزامية | من 8 إلى 100 محرف، ويجب أن تجمع حرفًا كبيرًا وحرفًا صغيرًا ورقمًا | المصدر نفسه |
| تأكيد كلمة المرور | إلزامي | مطابقة لكلمة المرور (تحقق في الواجهة الأمامية فقط) | `src/app/(public)/register/page.tsx` |
| اللقب | اختياري | ≤100 محرف؛ وإن تُرك فارغًا أُخذ اسم المستخدم افتراضيًا | register route |
| البريد الإلكتروني | **إلزامي** | صيغة بريد صالحة، ≤255 محرفًا؛ لكل بريد حساب واحد فقط | register route |
| رمز التحقق عبر البريد | **إلزامي** | 6 أرقام؛ **صالح 10 دقائق**؛ يُبطل فور نجاح التحقق؛ وإعادة الإرسال تُعلِّم الرمز القديم كمستخدم | `src/lib/email-verification.ts` |
| رقم الهاتف | اختياري | رقم صيني قاري من 11 خانة يبدأ بـ `1[3-9]`؛ ولكل رقم حساب واحد فقط | register route |

وتوفر الصفحة ثلاثة أزرار دخول عبر أطراف خارجية: **Google وWatcha وحساب Huawei**
(`GoogleSignInButton` / `WatchaLoginButton` / `HuaweiLoginButton`). حسابات الأطراف الخارجية بلا كلمة
مرور محلية؛ ومحاولة الدخول بكلمة مرور لاحقًا تعيد
「该账号未设置密码，请使用其他方式登录」 (لم يُعيَّن لهذا الحساب كلمة مرور، استخدموا طريقة دخول أخرى).

## حدود المعدل ومعاملات منع التخمين

| الفعل | الحد | المصدر |
|---|---|---|
| إرسال التسجيل | **3 مرات/دقيقة/IP**، والتجاوز يعطي 429 | `src/lib/rate-limit.ts` `REGISTER_RATE_LIMIT` |
| إرسال رمز التحقق | IP نفسه مرة/دقيقة **و** البريد نفسه مرة/دقيقة، والتجاوز يعطي 429؛ وزر الواجهة الأمامية عليه عدّاد تنازلي 60 ثانية | `src/app/api/auth/register/send-code/route.ts` |
| التحقق من الرمز | لكل بريد 5 محاولات كحد أقصى خلال 10 دقائق، وعند بلوغ الحد يُرفض الطلب حتى لو كان الرمز صحيحًا، ويلزم طلب رمز جديد | `src/lib/email-verification.ts` |
| إرسال رمز استعادة كلمة المرور | مرة/دقيقة/IP | `src/app/api/auth/forgot-password/route.ts` |
| تسجيل الدخول | 5 مرات/دقيقة/IP؛ والحساب نفسه عند **5 إخفاقات** متتالية **يُقفل 30 دقيقة** (423)، مع تناقص تنبيه المحاولات المتبقية أثناء القفل | `src/app/api/auth/login/route.ts`، `rate-limit.ts` |

**سلوك حماية الخصوصية**: عند إرسال رمز التحقق / استعادة كلمة المرور، إذا كان البريد مسجلًا مسبقًا أو
غير موجود، تعيد الواجهة في الحالتين نص نجاح موحّدًا، دون الكشف عمّا إذا كان البريد مسجلًا.

## تكافؤ وضع الإنجاز التفويضي للـ agent مع التسجيل عبر الويب

سكربت المهارة يستدعي **مجموعة واجهات API العامة نفسها** (`/api/auth/register` و`send-code` و`login`
و`/api/auth/me`)، ويمرّ بنفس مسارات التحقق وحدود المعدل والأخطاء التي يمرّ بها إرسال نموذج صفحة
التسجيل تمامًا — وكل قواعد هذا الملف تنطبق بالتساوي على الوضعين. تسلسل السكربت وعقد الأوامر في
`references/agent-flow.md`.

## انتقال الحالة بعد نجاح التسجيل

1. يُسجَّل المستخدم بحالة `accountStatus: 'pending'` مع **3 شارات** مبدئية (register route).
2. يزرع الخادم في الوقت نفسه اثنتي cookie من نوع HttpOnly: الـ JWT (يتيح الوصول مباشرة إلى
   `/subscription`) وpendingUserToken (وثيقة هوية مسار الاشتراك).
3. تكتشف صفحة التسجيل `pending_payment` → تحويل إلى `/subscription` (مع الإبقاء على معامل العودة
   `next`)؛ وفي وضع الإنجاز التفويضي للـ agent يُبلغ التأثير نفسه عبر `me?token=…&redirect=/subscription`.
4. اكتمال الدفع → يصبح `accountStatus` بقيمة `active` (**في Alipay يتم التنشيط تلقائيًا من جهة الخادم
   عبر notify**؛ وفي PayPal عبر Webhook تلقائيًا؛ وفي رمز QR لـ WeChat بتأكيد يدوي؛ وفي Huawei IAP عبر
   `activate-huawei`). التفاصيل في `payment-and-activation.md`.

المستخدم غير المنشَّط (pending) عند استدعاء واجهات API الأساسية (التدفق، الخريطة، محادثة البشر
الرقميين، تسجيل الحضور وغيرها) يتلقى 403 دائمًا؛ باستثناء روابط المنشورات المشتركة (تبقى متاحة
للعموم).

## جدول معالجة الأخطاء الشائعة

| العارضة | السبب | ماذا تفعل |
|---|---|---|
| 「用户名已存在」 (اسم المستخدم موجود مسبقًا) | الاسم مشغول (بلا تمييز حالة الأحرف) | جرّب اسم مستخدم آخر |
| 「邮箱已被使用」 (البريد مستخدم مسبقًا) | البريد مسجل من قبل | بدّل البريد؛ أو اتجه إلى تسجيل الدخول +「忘记密码」(نسيت كلمة المرور) لاستعادة الحساب القديم |
| 「邮箱验证码错误或已过期」 (رمز التحقق خاطئ أو منتهي) | رمز خاطئ / تجاوز 10 دقائق / رُفض لتجاوز 5 محاولات خاطئة | اضغط 「重新发送」(إعادة الإرسال) واستخدم رمز **أحدث رسالة** |
| لا يصل رمز التحقق | حد 60 ثانية؛ أو وقع في مجلد البريد المزعج/الدعائي | انتظر انتهاء العدّاد ثم أعد الإرسال؛ وفتّش مجلد البريد المزعج |
| 「手机号已被使用」 (رقم الهاتف مستخدم مسبقًا) | الرقم مرتبط بحساب آخر | احذف رقم الهاتف (اختياري) أو بدّل الرقم |
| 「注册请求过于频繁」 (طلبات تسجيل متكررة أكثر من اللازم) / 429 | بلوغ سقف 3 تسجيلات/دقيقة/IP | انتظر بضع دقائق ثم أعد المحاولة |
| 409 「用户名或邮箱已被注册」 (اسم المستخدم أو البريد مسجل مسبقًا) | تصادم لحظي مع شخص آخر عند الإرسال (شبكة أمان للتزامن) | بدّل اسم المستخدم أو البريد ثم أعد المحاولة |
| 「图片大小不能超过5MB」 (حجم الصورة لا يتجاوز 5MB) / 「不支持 SVG」 (لا دعم لـ SVG) | صورة رمزية غير مطابقة للشروط | بدّل الصورة أو تجاوز الصورة الرمزية |
| نجح التسجيل لكن الدخول يعطي 403 「请完成订阅以激活账户」 (أكملوا الاشتراك لتنشيط الحساب) | الحساب ما يزال pending (حالة متوقعة قبل الدفع) | قبل الدفع: هذا طبيعي، أكمل الاشتراك أولًا؛ وبعد الدفع ما يزال 403: يعني استخدام JWT قديم، وفي وضع السكربت شغّل `refresh-login` أولًا لتجديد حالة الدخول |
| دخول 423 「账户已锁定」 (الحساب مقفل) | 5 أخطاء متتالية في كلمة المرور | انتظر 30 دقيقة |
| دخول 401 「还剩 N 次尝试机会» (تبقى N محاولات) | كلمة مرور خاطئة، اقتراب القفل | فكّر جيدًا قبل المحاولة، أو اتجه مباشرة إلى 「忘记密码」(نسيت كلمة المرور) |
| 「该账号未设置密码，请使用其他方式登录」 (لم يُعيَّن لهذا الحساب كلمة مرور، استخدموا طريقة دخول أخرى) | حساب طرف خارجي (Google/Watcha/Huawei) | سجّل الدخول بزره الخارجي الأصلي |
| 「该账号已注销」 (هذا الحساب ملغى) | الحساب بحالة deactivate | يلزم التسجيل من جديد |

## معلومات دخول مفيدة (للمعاينة أثناء المعالجة)

تسجيل الدخول يقبل الإدخال الثلاثي **اسم المستخدم / البريد / رقم الهاتف** (أيها ثلاثة صالح كاسم
للحساب). نسيان كلمة المرور: صفحة الدخول → 「忘记密码」(نسيت كلمة المرور) → إدخال بريد التسجيل
لاستلام رمز من 6 أرقام → إعادة التعيين.
