# powpow-register

مساعد تسجيل بابل من PowPow (إصدار OpenClaw): يأخذ المستخدم الجديد من «ما هي بابل؟» حتى
«الحساب مفعّل، يمكنك استخدامه بشكل جيد» — تقديم المنتج (مع لقطات شاشة الواجهة)، دليل التسجيل خطوة بخطوة، تشخيص الأخطاء،
وشرح تفعيل الاشتراك.

مهارة إرشادية بالكامل، بدون سكربتات أو اعتماديات؛ جميع عمليات التسجيل يقوم بها المستخدم في المتصفح/التطبيق.

## التثبيت

```
openclaw skills install @durenzidu/powpow-register
```

## المميزات

1. **تقديم المنتج**: افتتاحية من نحو 120 كلمة + روابط لقطات شاشة الواجهة المستضافة في مستودع GitHub العام
   (صفحة الخريطة، صفحة تفاصيل المنشور وغيرها — 6 صور، اختر 1–3 حسب الموقف وأرسلها).
2. **دليل التسجيل**: قواعد الحقول (اسم المستخدم/كلمة المرور/رمز التحقق بالبريد/رقم الهاتف/صورة الملف)، تسجيل دخول الطرف الثالث
   (Google/Watcha/Huawei)، معاملات حد المعدل، كلها مأخوذة من كود المنصة مع توثيق المصدر.
3. **تشخيص الأخطاء**: عدم استلام رمز التحقق، استخدام اسم المستخدم/البريد، 403 غير مفعّل، قفل الحساب وغيرها —
   13 مشكلة شائعة.
4. **تفعيل الاشتراك**: شرح القنوات الثلاث وفحصها — PayPal (ويب) / مسح WeChat (تحقق يدوي) / Huawei IAP (HarmonyOS)؛
   يمكن إعادة استخدام مسار الدفع الحالي مباشرة، والمهارة تقدم المسار فقط.

## الأمان

- لا مفاتيح سرية؛ لا سكربتات، ولا علاقة بهوية المستخدم.
- **لا تطلب أبداً** كلمة مرور المستخدم أو رمزه أو بيانات دفعه؛ التسجيل والدفع يتمان بالكامل على صفحات المنصة.
