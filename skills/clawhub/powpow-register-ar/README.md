# powpow-register

مساعد التسجيل في PowPow فقاعة (نسخة OpenClaw): يصحب مستخدمًا جديدًا من «لا أعرف ما هي فقاعة» إلى
«الحساب منشَّط، تسجيل دخول بنقرة واحدة، فلنلعب» — تقديم المنتج (مع لقطات الواجهة)، وتسجيل بإنجاز
تفويضي من الـ agent (مع رفع الصورة الرمزية)، وإنشاء طلب اشتراك Alipay/PayPal وتتبّع وصول المبلغ، وتسجيل
دخول بنقرة واحدة عبر الرابط المزدوج، ومعالجة الأخطاء.

**منذ v2.0.0 هذا وضع الوكالة، ومنذ v2.2.0 أيضًا التكيّف مع فترة التجربة المجانية للمنصة**: السكربت الجوهري `scripts/powpow-register.mjs` بدون اعتمادات
(Node ≥ 18)؛ يغادر المستخدم المحادثة مرة واحدة فقط: للتحقق من رمز التحقق في صندوق البريد. خلال فترة التجربة المجانية الحالية، الحساب المسجَّل يمكنه استخدام كل الميزات فورًا — دفعة الاشتراك اختيارية؛ إذا انتهت فترة التجربة وحطّ المستخدم على صفحة الاشتراك، ينتقل المسار تلقائيًا إلى الدفع. بدون Node، أو عندما يفضّل المستخدم فعلها بنفسه، ارتداد تلقائي إلى وضع الإرشاد الخالص.

## التثبيت

```
openclaw skills install @durenzidu/powpow-register
```

## الميزات

1. **تقديم المنتج**: افتتاحية نحو 120 حرفًا + لقطات واجهة مدمجة في الحزمة
   (`assets/screenshots/`، 6 صور: صفحة الخريطة وصفحة تفاصيل المنشور وغيرهما؛ اختر 1–3 بحسب
   المشهد؛ دون مستضيف خارجي وتعمل دون اتصال).
2. **تسجيل تفويضي**: يقترح الـ agent مسبقًا اسم المستخدم/اللقب، وكلمة مرور بالاختيار بين خيارين
   (يقدّمها المستخدم أو يولّدها الـ agent)، وإرسال رمز التحقق وتقديمه، ورفع مباشر للصورة الرمزية
   (≤5 ميغابايت وليست SVG)، ومعالجة تلقائية للأخطاء الشائعة (مشغول/منتهي/حد معدل).
3. **تسجيل الدخول بنقرة واحدة (رابطان)**: مباشرة بعد نجاح التسجيل، رابط الدخول يحمل المستخدم إلى الصفحة الرئيسية مباشرة (خلال فترة التجربة المجانية، نقرة واحدة وقابل للاستخدام)؛
   إذا حطّ على صفحة الاشتراك (انتهت فترة التجربة) أو أراد المستخدم الترقية، اتبع مسار الاشتراك — بعد وصول الأموال تُستبدل حالة دخول جديدة، ورابط العضوية الكاملة يحمله إلى الصفحة الرئيسية
   (عبر جسر `me?token=` الرسمي للمنصة، الذي يزرع كوكي HttpOnly تلقائيًا).
4. **دفع الاشتراك**: كلتا القناتين Alipay (شهري ¥6.99 / ربعي ¥19.99 / سنوي
   ¥69.99، شراء لمرة واحدة دون تجديد تلقائي) وPayPal (Premium Monthly، نحو $1 شهريًا،
   تجديد تلقائي، يمكن إلغاؤه في أي وقت) يُنشئهما الـ agent تفويضيًا مع استعلام دوري حتى وصول المبلغ؛
   ورمز QR لـ WeChat / Huawei IAP يُكتفى بالإشارة إلى الطريق.
5. **معالجة الأخطاء**: عدم وصول رمز التحقق، واسم المستخدم/البريد المشغول، و403 غير منشَّط، وقفل
   الحساب وغيرها من المشاكل الشائعة، كلها من كود المنصة المصدري مع ذكر المصادر.

## الأمان

- **كلمة المرور** تدخل عملية السكربت عبر متغير البيئة فقط، ولا تُكتب أبدًا في وسائط سطر الأوامر،
  ولا تُخزَّن على القرص، ولا تدخل ملف الحالة؛ وكلمة المرور التي يولّدها الـ agent تُعرض مرة واحدة
  ليحفظها المستخدم.
- **رمز التحقق** يُستخدم في واجهة التسجيل الرسمية فقط ويُرمى بعد استخدامه؛ وملف الحالة
  (البريد/اسم المستخدم/token/رقم الطلب) يُخزَّن في مجلد النظام المؤقت ويُمحى بكبسة واحدة عبر
  `cleanup` في نهاية المسار.
- **الدفع**: الـ agent ينشئ الطلب ويفتح صفحة الدفع ويستعلم عن وصول المبلغ فقط؛ ولا يلامس أبدًا حساب
  المستخدم في Alipay/PayPal أو بيانات دفعه، ولا يدفع عنه أبدًا. الدفع يحدث دائمًا بين المستخدم وصفحة
  الدفع الرسمية.
- كل الطلبات تُرسل حصريًا إلى النطاق الرسمي `https://global.powpow.online`؛ ولا تتضمن الحزمة أي مفاتيح.
