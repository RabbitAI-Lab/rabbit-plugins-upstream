## Description: <br>
Design stable APIs, module boundaries, and public interfaces for REST or GraphQL endpoints, inter-module contracts, and frontend-backend boundaries. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

### License/Terms of Use: <br>

## Use Case: <br>
Developers and engineers use this skill to design REST or GraphQL APIs, module contracts, component props, and frontend-backend boundaries with stable schemas, consistent errors, boundary validation, and backward-compatible changes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: API design suggestions, especially delete and update endpoint examples, could lead to unsafe behavior if accepted without review. <br>
Mitigation: Review proposed endpoint semantics, schemas, authorization behavior, and migration impact before implementation. <br>
