## Description:

Generates a Markdown weekly report from a list of completed tasks and saves it to a specified file path.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zengxianhui2023](https://clawhub.ai/user/zengxianhui2023)

### License/Terms of Use:

MIT-0

## Use Case:

People who track completed work can provide a task list and use the skill to create a Markdown weekly report saved at a chosen path.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The saved report may contain task details the user does not want stored at its destination.

Mitigation: Choose an appropriate report destination and include only task details you want saved.
