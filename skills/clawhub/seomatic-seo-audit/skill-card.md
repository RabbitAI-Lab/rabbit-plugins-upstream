## Description:

Run an SEO audit using connected Google Search Console data, a technical site crawl, on-page checks, and AI search visibility results, then produce a prioritized fix list for approval.

This skill is ready for commercial/non-commercial use.

## Publisher:

[minh42](https://clawhub.ai/user/minh42)

### License/Terms of Use:

MIT-0

## Use Case:

Site owners and SEO practitioners use this skill to assess search performance, indexing, technical issues, and AI search visibility for the connected site. It turns the available results into a prioritized list of fixes that the user can review and approve.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The broad health-check trigger may activate the skill for requests beyond SEO.

Mitigation: Confirm that the user wants an SEO audit before running it, and keep the audit focused on the connected site's SEO data and issues.
