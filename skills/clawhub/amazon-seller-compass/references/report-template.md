# 选品决策报告模板

两种模式的完整报告 Markdown 模板。实际输出可根据数据丰富度调整，但**必须覆盖以下所有章节**。

---

## 模式 A 报告模板：品类探索

```markdown
# [品类名称] 亚马逊选品分析报告
> 分析时间：YYYY-MM-DD | 目标市场：Amazon.com (US)

---

## 一、执行摘要

**[一句话结论]**：[品类名称] 整体呈 [上升/稳定/下降] 趋势，推荐重点关注 [1-2个细分赛道]，当前机会窗口为 [X] 个月。

**三个核心发现**：
1. [发现一：价格带 / 集中度 / 趋势方面最关键的洞察]
2. [发现二：消费者评论中最高频的未满足需求]
3. [发现三：竞争格局中的差异化突破口]

**建议行动**：[1-2句可执行建议]
```

## 输出规范

### 报告保存

完整报告写入文件，文件名格式：
```
[品类/产品名]_Amazon选品报告_YYYY-MM-DD.md
```

### 用户交互

- 报告写入后，在对话中给出 **300 字以内的摘要 + 结论卡片**
- 不要让用户去翻文件找结论
- 结论后附上决策框架的四个选项（🟢🟡🟠🔴）

### 数据标注规范

所有数据必须标注来源：
- `（来源：Amazon BSR 页面，2026-07-28）`
- `（来源：Google Trends，近3年数据，2026-07-28）`
- `（来源：1688搜索，2026-07-28）`
- `（估算：基于类目平均广告占比）`
