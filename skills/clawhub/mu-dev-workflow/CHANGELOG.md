# Changelog

All notable changes to this project will be documented in this file.

## [2.1.0] - 2026-08-18

### What's New

- ✨ Five-stage hard-gated workflow: Requirements → Design → Execute → Verify
- ✨ Critical Three-Question Self-Check (real problem? reinventing the wheel? edge cases?)
- ✨ Skill Intent Clarification Protocol (5 questions before creating any Skill)
- ✨ Anti-Rationalization Excuse Table (6 common skip-excuses with reality checks)
- ✨ ICE-5 Incident Closure mechanism (trigger/enforcement/failure/evidence/action)
- ✨ Sub-Agent Dual-Stage Review with Monitor mechanism and task size constraints
- ✨ Architecture Pattern Library (6 patterns + decision tree + shared components)
- ✨ Quick mode for small tasks (<1500 lines) and bug fix shortcut (<30min)

### Acknowledgments

- Inspired by [Superpowers](https://github.com/obra/superpowers) by Jesse Vincent
- Critical thinking framework based on *Asking the Right Questions* by Browne & Keeley
