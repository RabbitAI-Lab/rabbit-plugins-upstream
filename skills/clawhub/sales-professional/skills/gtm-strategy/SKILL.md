# GTM Strategy — 市场进入策略

> 产品做好了只是第一步。怎么把它卖出去、卖给谁、用什么价格、通过什么渠道——这就是 GTM 策略要回答的问题。

## 能力

- **GTM 路线图**：从 Pre-launch 到 Scale 的阶段性计划，每阶段的目标和资源需求
- **定位与信息传递**：价值主张设计、差异化表述、面向不同人群的电梯演讲
- **竞品分析**：竞品矩阵、功能对比、定位图绘制、竞争策略选择
- **定价模型**：基于价值 vs 基于成本 vs 基于竞争的定价框架、Freemium 策略
- **渠道策略**：直销/PLG/合作渠道/市场 的评估与组合设计
- **Launch 计划**：产品发布的时间线、关键活动、成功指标

## 使用方式

在 Claude Code 中使用 `/gtm-strategy` 调用。

```
/gtm-strategy 帮我的 SaaS 产品设计 GTM 路线图
/gtm-strategy 分析我们的竞品格局并建议差异化定位
/gtm-strategy 我们的产品应该用 PLG 还是 Sales-led？
```

## 工作流

1. **市场分析** — TAM/SAM/SOM 计算、市场趋势、进入时机判断
2. **客户分群** — ICP 定义、Buyer Persona、用户旅程
3. **竞品研究** — 直接/间接/替代竞品 → 定位空白
4. **策略制定** — 选择 GTM 动作（PLG/Sales-led/Channel）
5. **执行计划** — 季度 OKR、预算、团队配置、里程碑

## GTM 模式决策矩阵

| 条件 | PLG | Sales-led | Channel |
|------|-----|-----------|---------|
| 客单价 < $500/月 | ✅ | ❌ | ❌ |
| 客单价 > $5K/月 | ❌ | ✅ | — |
| 需要实施/集成 | ❌ | ✅ | ✅ |
| 市场教育成本低 | ✅ | — | — |
| 已有合作伙伴网络 | — | — | ✅ |

## 适用场景

- 新产品或新功能的市场进入规划
- 从 PLG 转向 Sales-led 或混合模式的决策
- 进入新地域市场（国际化）
- 产品发布前的 Go-to-Market 准备

## 限制

- 聚焦 B2B SaaS 场景，B2C 商品 GTM 不在覆盖范围
- 不涉及品牌营销（品牌定位/广告投放/公关）
- 定价覆盖策略层面，不深入财务建模细节
- 假设产品已有 MVP，不涉及从 0 到 1 的产品定义
