# Sales Professional — 销售技能库

> 面向独立开发者、创业者和小型 B2B 团队的专业销售技能集合。从策略到执行，覆盖销售全流程。

## 技能清单

| 技能 | 描述 | 安装量 | 来源 |
|------|------|--------|------|
| cold-email | 冷启动邮件：高打开率标题、个性化策略、序列编排 | 87.2K | [skills.sh](https://skills.sh/coreyhaines31/marketingskills/cold-email) |
| crm-automation | CRM 自动化：数据质量治理、工作流设计、报表 | 4.4K | [skills.sh](https://skills.sh/claude-office-skills/skills/crm-automation) |
| lead-generation | 潜客挖掘：信号识别、列表建设、评分模型 | 2.8K | [skills.sh](https://skills.sh/apify/agent-skills/apify-lead-generation) |
| gtm-strategy | GTM 策略：市场进入路线图、定位、定价、渠道 | 2.1K | [skills.sh](https://skills.sh/phuryn/pm-skills/gtm-strategy) |

## 工作流

```
GTM 策略 ──→ 潜客挖掘 ──→ 冷邮件外联 ──→ CRM 管理
 (规划)       (找谁)        (接触)         (追踪)
```

## 安装

```bash
# 安装全部销售技能
npx skills add skills-repo/sales-professional -g -y

# 或按需安装单个技能
npx skills add skills-repo/sales-professional@cold-email -g -y
npx skills add skills-repo/sales-professional@crm-automation -g -y
npx skills add skills-repo/sales-professional@lead-generation -g -y
npx skills add skills-repo/sales-professional@gtm-strategy -g -y
```

## 与本组织其他仓库的关系

- **marketing-master** — 入站营销（SEO、文案、着陆页），与销售互补
- **startup-founder** — 创始人销售属于早期阶段，销售技能库覆盖日常执行
- **trader** — 金融交易，完全不同领域
