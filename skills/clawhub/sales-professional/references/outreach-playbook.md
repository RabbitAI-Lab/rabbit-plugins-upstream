# 外联与跟进 playbook

> 冷外联的核心是"被回复"，不是"被看到"。本 playbook 给冷邮件结构、回复率杠杆与跟进节奏。

## 1. 冷邮件结构（高回复率）

```
主题行   — 具体 + 利益点，避免"合作洽谈"这类空话
开场     — 一句 relevance（为什么是你/为什么现在）
价值     — 一个具体能帮对方解决的问题或数据
轻 CTA  — 一个低门槛动作（"周二还是周四方便 15 分钟？"）
签名     — 真实姓名与身份
```

**铁律**：正文 ≤ 120 词；价值前置，不写公司自嗨史。

## 2. 回复率杠杆（按影响排序）

1. **精准 ICP**：发给真正有痛点的人，比优化文案更重要。
2. **个性化开头**：提到对方具体业务/近期动作，打开率显著提升。
3. **单一 CTA**：给一个明确动作，不要"回复或约时间或看 demo"三选一。
4. **发送 timing**：目标市场周二至周四上午本地时间。

## 3. 跟进节奏（基线：4 次触达 = 首封 + 3 次跟进）

```
第 0 天  首封       ← 触达 1
第 3 天  轻跟进（换角度补一句价值）        ← 触达 2
第 7 天  提供样本/案例                    ← 触达 3
第 14 天 最后触达（"先不打扰，需要时找我"） ← 触达 4
```

- 多数正向回复来自第 2-4 次**触达**（即第 1-3 次跟进），放弃过早=放弃收入。
- 每条跟进带新增信息，不是单纯"再问一下"。

**计数口径（必须统一）**：本库一律按「触达」计数，首封算第 1 次触达。基线共 4 次触达，因此**不存在"第 4 次跟进"**——引用数字前先确认单位是「触达」还是「跟进」。

**扩展变体**：需要更长序列时用 5 次触达（基线 + 第 21 天再一次最后触达），见 [skills/cold-email/](../skills/cold-email/SKILL.md)。扩展只允许在尾部追加触达，**不改首封起算点（第 0 天）**，否则两套节奏无法对齐复盘数据。

## 4. 发送前检查清单

- [ ] 主题行具体且含利益点
- [ ] 开头 relevance 清晰
- [ ] 正文 ≤120 词、价值前置
- [ ] CTA 单一且低门槛
- [ ] 含可退订/真实发件人（合规）

## 5. 常见坑

- **群发感**：模板痕迹重，无人回应。加一句真实个性化。
- **CTA 过多**：让人不知从哪开始，干脆不回。
- **只发不跟**：发一封没回就放弃，错过绝大多数成交。
- **价值模糊**：只说"我们很棒"，没说"能帮你解决 X"。
- **混用计数口径**：一处按"触达"、一处按"跟进"，复盘时把第 2 次触达当成第 2 次跟进，回复率归因整体错位。

## 6. 相关子技能与层次边界

本 playbook 是 **L2 方法论**（冷邮件结构 / 回复率杠杆 / 跟进节奏 / 发送前清单），只解决"怎么写与怎么跟"的原则，不替你生成真实邮件或配置自动化。要产出具体资产，调对应 **L3 子技能**：

- 冷邮件正文与主题行写作 → [skills/cold-email/](../skills/cold-email/SKILL.md)（`cold-email` 子技能，覆盖开场 / 主题行 / 跟进）
- 跟进节奏自动化、CRM 打点 → [skills/crm-automation/](../skills/crm-automation/SKILL.md)（`crm-automation` 子技能，覆盖流程 / 漏斗 / 跟进自动化）
- 精准 ICP 与名单挖掘 → [skills/lead-generation/](../skills/lead-generation/SKILL.md)（`lead-generation` 子技能，覆盖线索 / ICP / 优先级 / 名单）

> 层次边界：本文档给"结构与原则"，不生成真实邮件或配置自动化——那是 `skills/` 的职责。按本 playbook 定稿结构后，用 `cold-email` 产出具体信件。
