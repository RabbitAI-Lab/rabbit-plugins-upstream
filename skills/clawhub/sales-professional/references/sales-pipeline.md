# 销售管道与 GTM 决策 playbook

> 管道不清，努力白费。本 playbook 给管道阶段定义、GTM 决策树与出海要点。

## 1. 管道阶段（通用 B2B）

```
认知 (Awareness) → 兴趣 (Interest) → 评估 (Eval) → 提案 (Proposal) → 成交 (Closed)
         ↑ 各阶段设转化率目标与停滞预警
```

- 每阶段定义"进入条件"与"退出条件"，避免商机卡在模糊状态。
- 停滞 > N 天的商机自动触发跟进任务（交给 CRM 自动化）。

## 2. GTM 决策树

```
Q1 产品形态？
├─ 自助 SaaS → PLG：免费试用 + 产品内引导
├─ 高客单 B2B → 销售驱动：外联 + DEMO + 提案
└─ 实体/本地 → 渠道 + 地推

Q2 目标市场？
├─ 国内 → 微信/抖音私域 + 内容获客
└─ 海外 → 邮箱冷外联 + LinkedIn + 独立站 SEO

Q3 定价锚点？
├─ 价值定价（节省/赚到的倍数）优于成本定价
└─ 先有锚点再谈折扣，避免一上来就降价
```

## 3. 出海（海外 GTM）要点

- **渠道**：冷邮件 + LinkedIn 仍是 B2B 最有效；独立站承接搜索流量。
- **时区与节奏**：按目标市场工作日发信，避开当地节假日。
- **合规**：GDPR/CAN-SPAM 对冷邮件有要求（可退订、真实发件人）。
- **本地化**：不是翻译，是重写价值主张贴合当地痛点。

## 4. 管道健康检查清单

- [ ] 每个阶段有量化转化目标
- [ ] 停滞商机有自动跟进触发
- [ ] 线索来源可归因（知道哪条渠道有效）
- [ ] 定价有锚点，折扣有审批

## 5. 常见坑

- **没有阶段定义**：所有商机都"进行中"，看不出堵在哪。
- **只追新不跟旧**：忽视跟进，大量近成交商机流失。
- **盲目出海**：没研究当地合规与渠道习惯，邮件进垃圾箱。
- **价格战**：一上来降价，损伤利润与定位。

## 6. 相关子技能与层次边界

本 playbook 是 **L2 方法论**（管道阶段定义 / GTM 决策树 / 出海要点 / 健康检查清单），只解决"怎么判断与决策"，不写具体产出的操作细节。要产出可落地资产，调对应 **L3 子技能**：

- 管道阶段定义与 GTM 策略落地 → [skills/gtm-strategy/](../skills/gtm-strategy/SKILL.md)（`gtm-strategy` 子技能，覆盖上市 / 渠道 / 定价 / 定位）
- 停滞商机自动跟进触发 → [skills/crm-automation/](../skills/crm-automation/SKILL.md)（`crm-automation` 子技能，覆盖流程 / 漏斗 / 跟进自动化）
- 线索来源可归因、ICP 挖掘 → [skills/lead-generation/](../skills/lead-generation/SKILL.md)（`lead-generation` 子技能，覆盖线索 / ICP / 优先级 / 名单）

> 层次边界：本文档不写"怎么写一封邮件"或"怎么配 CRM 字段"——那是 `skills/` 的职责。读完本 playbook 做判断后，把产出交给对应子技能执行。
