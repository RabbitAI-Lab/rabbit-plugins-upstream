## 产教融合校企合作职能群 — 任务清单与依赖拓扑（Catalog）

本文件是第一层结构：15 域 125 个能力单元的结构索引、依赖拓扑与 10 条行业管线。单元说明列为任务类型的一句话说明；完整执行口径（必选/可选组件、组装顺序、约束、格式）见 `VCO-requirements.md`。首次使用必须读取本文件。

### 域间逻辑流声明

```
X0 路由编排域（任务路由 → 双校准 → 信息卡展示 → 管线编排）
  → 条件路由到 14 个职能域之一或多个：
     ├── 行业天然通用层（组织运转）：N1 生源与驻厂 / N2 项目财务 / N3 交付行政 / N4 数据与系统
     └── 业务泛化通用层（经营闭环）：B1 感知 → B2 准入 → B3 表达 → B4 触达
                       → B5 成交留存 → B6 交付保障 → B7 度量 → B8 协同
                       → B9 风控 → B10 沉淀 → 回流 B1
  → 各域单元按依赖拓扑执行（域内依赖 + 跨域依赖）
  → X0-04 实习批次管线编排与执行通报 扇入整合交付
```
