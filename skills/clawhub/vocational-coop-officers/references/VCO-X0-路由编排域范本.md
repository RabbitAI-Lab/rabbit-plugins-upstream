## X0 路由编排域范本 —— B 校来访考察

### 案例背景卡

| 项 | 内容 |
|---|---|
| 主体 | B 校（某高职院校，拟开设无人机应用技术方向）／S 服务商（我方） |
| 时间 | 2026 年 1 月来访当日（B 校拟于 5 月启动共建） |
| 规模 | 拟合作专业 1 个；首期订单班 40 人（示例值） |
| 委托口径 | 校方：想共建专业并解决实习出口；企业方：需要装调与装配岗位人员；渠道方：希望承接招生 |
| 数据约定 | 政策与税率标「法定」；服务费标「行业常见区间」；人数、班额标「示例值」 |

> 本文件与其余 14 个域范本共用同一案例基线（主体、时间线、数字），见 `VCO-exemplars.md` §统一案例基线。

#### X0-01 校企任务路由与单元匹配 —— 任务路由报告

**路由报告（来访当日 09:20）**

| 项 | 内容 |
|---|---|
| 委托复述 | 校方希望共建无人机方向、建设实训室、并解决首届学生实习出口 |
| 委托人识别 | 校方（生源）为主委托人；企业方（岗位）与渠道方（招生）为关联方，费用立场需分别确认 |
| 匹配单元 | B5-01 客户建档、B5-03 院校拜访、B8-01 项目立项、B2-01 资质路径、N4-06 设备选型、B9-01 合规测绘 |
| 建议管线 | V1 院校开拓到签约（前段）＋ V2 专业共建落地（后段） |
| 红线初筛 | ①是否承诺「包就业」——校方口径中出现，须当场纠正；②是否由我方直接组织管理实习——须通过合规业务结构设计，不得以有偿代理方式介入；③合作专业与拟输送岗位是否对口——需专业目录对照 |
| 路由结论 | 可进入 V1；红线②未澄清前，不进入报价与协议 |

待澄清项：校方实习管理制度、专业教学计划、拟合作企业名单、收费项目与对象。

#### X0-02 产教融合行业校准与组织校准 —— 双校准报告

**一、行业校准（节选）**

| 项 | 结论 |
|---|---|
| 行业 | 职业教育产教融合服务 + 人力资源服务 |
| 院校层次 | 高职（三年制），实习安排受《职业学校学生岗位实习管理规定》约束 |
| 专业方向 | 无人机应用技术（装调检修方向优先） |
| 计价口径 | 元/人/月；行业常见区间，需按实际核定；打包价仅用于短周期项目 |
| 关键红线 | 14 条实习红线；费用只能来自企业（口径 C） |
| 时效标注 | 法规以最新有效版本为准；补贴标准按当地当年口径复核 |

**二、组织校准（节选）**

| 项 | 结论 |
|---|---|
| 组织形态 | 一级服务商 + 下游渠道（二级代理、招生机构） |
| 决策链 | 市场委员会定价 → 业务副总 → 事业部执行；协议用章需两级签批 |
| 管理颗粒度 | 批次制：按批次立项、按批次核算、按批次复盘 |
| 数据纪律 | 数字三档；台账唯一入口 |

校准结论：本次任务按「高职 + 专业共建 + 一级服务商」口径执行；补贴与地方细则标「待复核」。

签批：校准师 ______ 业务副总 ______
