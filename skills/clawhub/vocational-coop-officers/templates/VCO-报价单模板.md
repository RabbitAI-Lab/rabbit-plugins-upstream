# VCO-报价单模板（对外报价结构＋精算留痕）

> 用法：按〔〕替换；价格一律标档（D1 法定／D2 行业区间／D3 示例值）。报价前必须完成 B7-04 精算并确认未低于保本线。

## 一、基本信息

| 项 | 内容 |
|---|---|
| 报价编号 | BJ-〔年〕-〔序号〕 |
| 客户 | 〔某制造企业（A 厂）〕 |
| 服务项目 | 〔实习安置＋驻厂管理＋月度对账〕 |
| 批次规模 | 〔N〕人（示例） |
| 报价有效期 | 〔30〕天 |
| 编制／审核 | 〔姓名〕／〔姓名〕 |

## 二、报价结构

| 项 | 内容 |
|---|---|
| 计价单位 | 〔元/人/月〕（三选一：元/人/月、元/小时、元/人/期） |
| 单价（含税） | 〔区间下限–上限〕元/人/月（D2，需按实际核定） |
| 计费月数 | 〔6〕个月（示例） |
| 计费人数 | 按实际在岗；不满〔10〕天不计费；满〔10〕天不满整月按出勤折算 |
| 结算节奏 | 月结〔T+30〕天；对账后〔5〕个工作日内开票 |
| 调价机制 | 每〔6〕个月复核；或当地最低工资调整超〔5〕%时触发 |
| 不含项 | 〔住宿、体检、保险、交通〕等（逐项列明） |

## 三、服务内容（SOW）

| # | 服务项 | 交付标准 | 频次 |
|---|---|---|---|
| 1 | 生源组织与甄选 | 专业对口核验、健康与年龄合规 | 每批次 |
| 2 | 入场与手续 | 三方协议、知情书、保险齐备 | 每批次 |
| 3 | 驻厂管理 | 驻厂配比〔1:50〕；日报每日提交 | 每日 |
| 4 | 工资与权益核对 | 不接触学生报酬；协助核对差错 | 每月 |
| 5 | 异常处置 | 2 小时首报；24 小时内书面 | 事件驱动 |
| 6 | 月度对账 | 人数、月数、扣款逐项核对 | 每月 |
| 7 | 留存管理 | 留岗率目标〔≥85%〕（示例） | 每月 |

## 四、考核与奖惩

| 指标 | 目标 | 未达处理 |
|---|---|---|
| 到岗完成率 | 〔≥95%〕 | 按缺口比例调整服务费 |
| 留岗率 | 〔≥85%〕 | 低于阈值进入改进期，不罚不扣 |
| 结算差错率 | 〔0〕 | 差错当日更正 |

> **纪律**：不设「罚款式」条款；不以学生报酬作为任何结算基础。

## 五、报价三档（可选）

| 档 | 内容 | 适用 |
|---|---|---|
| 标准档 | 基础服务＋驻厂＋对账 | 常规批次 |
| 精简档 | 基础服务＋远程支持 | 成熟客户 |
| 保障档 | 标准档＋留存对赌 | 大客户 |
