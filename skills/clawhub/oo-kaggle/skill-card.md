## Description:

Kaggle connector for searching and reading Kaggle competitions, datasets, notebooks, scripts, and models through the OOMOL oo CLI.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and external users use this skill to query Kaggle resources through an OOMOL-connected account without handling raw Kaggle credentials directly.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Fallback setup directs users to execute remote installer scripts without verification.

Mitigation: Review before installing; prefer an official package manager, an inspectable downloaded installer, or a versioned installer with checksum or signature verification.
