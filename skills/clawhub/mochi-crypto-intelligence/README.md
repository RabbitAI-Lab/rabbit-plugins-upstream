Research crypto developments from free public sources, verify primary evidence, deduplicate events and track a local watchlist.

```text

```

```text
Verify whether this announced upgrade actually executed or remains a proposal.
```

```text
Preview new and changed verified events for my local watchlist.
```

Published by MochiPay. This page distributes the unchanged 1.0.0 package under MIT-0. Uses the host’s browsing/search tools and optional standard-library Python helpers. No paid intelligence API or wallet access is required. Offline input analysis is labeled accordingly; it does not trade, transfer funds or start continuous monitoring.

## Requirements

AI client with browsing/search; optional helpers require Python 3.10+ standard library.

## Installation and first use

First [connect the MochiLab Skills assistant](https://mochilab.bz/Skills/Connect.aspx?lang=en), then send:

```text
Install mochi-crypto-intelligence
```

Or place the ZIP’s Skill folder in the target workspace’s skills/ directory and start a new conversation. Each BOT should connect its own MochiLab account.
