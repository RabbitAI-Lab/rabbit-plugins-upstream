## Description:

Research recent crypto-market developments from free public sources, verify original evidence, deduplicate stories, and track changes to a local watchlist. Use for crypto intelligence briefs, project updates, event calendars, narrative research and rumor verification; no paid data provider or API key required.

This skill is ready for commercial/non-commercial use.

## Use Case:

Crypto researchers, analysts, and users use this skill to build source-linked updates, verify claims and event stages, and track changes for selected projects or a local watchlist.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A separate MochiLab connection may involve permissions outside the bundled public-source research workflow.

Mitigation: Use the client's direct import option for the research workflow, and review any separate MochiLab connection permissions before choosing that route.

Risk: Local history and backups can retain research records.

Mitigation: Keep outputs in a dedicated folder and remove retained history and backups when no longer needed.
