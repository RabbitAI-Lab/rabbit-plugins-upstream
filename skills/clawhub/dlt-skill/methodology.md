# 大乐透诚实分析 · 方法论与数学依据

> 本文件供 skill 在需要时加载，提供核心结论的可核查依据。所有数字均来自本项目对真实 2906 期开奖数据的实测与回测。

## 1. 核心数学结论（不可动摇）

| 结论 | 数值/事实 | 含义 |
|------|-----------|------|
| 前区熵效率 | 99.91% | 开奖近似完全随机，仅 ~0.09% 偏离 |
| 任一 5+2 组合一等奖概率 | 恒 1/21,425,712 | 热冷组合无概率梯度 |
| 频率偏差 | ±15%（卡方 90.84） | 幅度不足转化为优势 |
| 所有选号法回测 | p > 0.05（组合 p=0.667） | 无统计显著预测力 |
| 凯利 f\* | < 0 | 不应下注 |
| 样本外 ROI | ≈ −67%（随机基线 −64.6%，无差异） | 不优于随机 |
| 蒙特卡洛年净亏 | ≈ ¥6275，正收益概率 0.01% | 长期必亏 |
| 前后区独立性 | r = 0.024 | 可分开建模 |
| 9 项过滤器 | 排除 88% 组合 | 仅过滤不提升中选可能 |

**结论**：数学上本系统不优于随机，任何选号法/胆拖均不提高单注一等奖概率。唯一真实信号（±15% 频率偏差）剥离离群值后仍为负期望。**不应投注，仅供娱乐参考、量力而行。**

## 2. 9 项过滤器（dlt_common.py 实现）

应用于前区 5 码，排除约 88% 组合（仅作缩水，不提升中选可能）：

1. **AC 值** ∈ [4, 6]
2. **和值** ∈ [80, 130]
3. **跨度** ∈ [15, 30]
4. **奇偶比** 2:3 或 3:2
5. **大小比**（小 01–17 / 大 18–35）2:3 或 3:2
6. **质数个数** 1–2（11 个质数：02,03,05,07,11,13,17,19,23,29,31）
7. **012 路** 每路 > 0
8. **连号组数** ≤ 1
9. **重号** ≤ 2（对上期）

后区 2 码独立筛选。

## 3. 方法发现 + 证伪引擎（dlt_method_explorer.py）

系统性提案候选选号法 → walk-forward 样本外回测 → 随机基线 + Bonferroni 校正 → **头条指标 = 一等奖命中**（全 0 即 no_edge 成立）→ 证伪归档。已覆盖 9 种主流法：

| 法 | 思路 |
|----|------|
| hot | 追热号 |
| cold | 博冷号 |
| avoid_last | 规避上期号码 |
| balanced | 均衡（奇偶/大小/质合均衡） |
| omission | 遗漏值（长期未出号） |
| interval | 区间分布（前区 1–35 分区间） |
| tail | 尾数/同尾 |
| kill | 杀号定胆公式 |
| back_refine | 后区细化 |

**所有法样本外一等奖命中 = 0 = 随机**。小额奖（≤六/七奖）存在可检测的 ±15% 偏差，但剥离离群值后 ROI 仍负，不有正收益可能。引擎输出 `dlt_method_explorer.json` 含 `no_edge_first_prize` 字段。

## 4. 开奖随机性检验电池（dlt_randomness_test.py）

对真实历史跑 10 项卡方（α=0.05），三种结论状态：

- **OK**：统计量 < 临界值，干净随机。
- **KNOWN_BIAS**：统计量 > 临界值，但属于已知 ±15% 频率偏差（与项目既有结论一致），非异常、已证伪有正收益可能性。
- **FAIL**：灾难性异常（频率/结构严重偏离），疑似数据损坏或过程失效——硬闸门失败。

实测（2906 期）：6 项 OK + 4 项 KNOWN_BIAS + 0 项 FAIL。硬闸门通过。

### 4.5 密码学级随机性灵敏度升级（NIST SP 800-22，dlt_nist_sts.py）

作为既有卡方电池的"灵敏度升级"，新增 NIST SP 800-22 标准套件（密码学级），
从"位级"进一步探测极微弱非随机结构（连号机 / 伪随机生成器瑕疵）：

- **编码方案**：每球取 1 个奇偶比特，先全部前区后全部后区（扁平化，去除"每期 5+2=7 位帧"的 1/7 频谱假象）。
- **六项检验**：Monobit / Block Frequency / Runs / Longest Run / Discrete Fourier(Spectral) / Approximate Entropy（纯标准库实现，含自实现 FFT 与不完全 Gamma Q）。
- **诚实定位**：NIST 为 i.i.d. Bernoulli(0.5) RNG 校准。彩票号码不是位流，其二进制展开天然携带两项"非随机"特征——
  (1) 号码轻微频率非均匀（χ² 已量化 KNOWN_BIAS）；(2) 位编码固有特性（前区奇偶边际≈0.514 / 无放回抽样 / 前-后区阶跃）。因此个别项"未通过"是预期且良性。
- **对照验证**：均匀随机开奖穿过同一编码也会同样未通过 → 证明是编码/偏差假象，非开奖机缺陷。
- **实质结论**（2906 期 → 20342 位）：2 项 PASS / 3 项 KNOWN_BIAS / 1 项 N/A（Runs 因 1 比例略偏离 0.5 按 NIST 预处理条件不适用） / **0 项 ANOMALY**。
- **完整性闸门**：位流 1 比例 0.5165 ∈ [0.45,0.57] ✅ 且 0 ANOMALY ✅ → 数据源一致，无可利用结构。
- **结论**：NIST 在本数据上仅扮演"压力测试"，确认大乐透无任何超出已知良性偏差的可利用模式；其"未通过"不纳入硬闸门。

> 自检（self_test）：用 random.getrandbits 生成真随机 i.i.d. 位流，验证 FFT 与朴素 DFT 一致、各检验通过率 0.992（落入 NIST 推荐置信区间 [0.90,1.06]），证明算法实现正确。

## 5. 胆拖优化（dlt_dantuo_optimizer.py）

胆拖**不提高单注一等奖概率**，只优化投入结构。优化器枚举形态（前区 1–3 胆 × 多拖数 + 后区 0–1 胆 × 多拖数，预算 ≤ 120 注），按三指标多目标权衡：

1. **号码最可靠**：模型 combined_score（评分排序）。
2. **成本最低**：按实际注数计费（前 N 选 5 × 后 M 选 2；胆拖按组合数实算，非按单张）。
3. **中奖概率最高**：加权蒙特卡洛估计"至少中任一奖"概率（固定种子确定性）。

候选池按评分排序后**洗牌**（固定种子）避免特征聚集。输出最优方案 + 候选列表 + 回退组合。
