## Description:

Routes open-source UI/UX work to suitable design systems, component-library guidelines, and design review practices.

This skill is ready for commercial/non-commercial use.

## Use Case:

Open-source contributors and developers use this skill to choose UI design guidance for component fixes, documentation sites, landing pages, and design reviews while respecting the target project's conventions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Apple-inspired tokens and component guidance could be mistaken for official Apple or Tencent specifications.

Mitigation: Treat them as community guidance and check the target project's official design and contribution documentation.

Risk: Linked skills and external UI resources are separate from this package.

Mitigation: Review those resources independently before installing or using them.
