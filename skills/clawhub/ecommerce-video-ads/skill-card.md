## Description:

Plans and creates short ecommerce video ads for TikTok, TikTok Shop, Instagram Reels, and Meta, with platform-aware scripts, shot plans, and AI or real footage.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

Ecommerce sellers and marketers use this skill to plan product video ads, write timed scripts and shot lists, and produce platform-aware creative variations using real or AI-generated footage.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Cloud generation sends selected images and voices to Varg and its model providers.

Mitigation: Use only media you are permitted to share, review provider data policies before submitting confidential material, and use planning workflows without cloud generation when appropriate.

Risk: Installing an unintended or unreviewed skill version can introduce unwanted behavior.

Mitigation: Install only the intended skill and prefer reviewed installer and repository versions.
