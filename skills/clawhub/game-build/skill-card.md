## Description:

Adapts to available tools to build a runnable game from an approved design, with deterministic self-checks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[worldwonderer](https://clawhub.ai/user/worldwonderer)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to prototype a game's highest-risk design question or implement an approved design as a runnable 2D, 2.5D, or 3D game. It guides tool selection, production checks, and handoff for independent playtesting.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Private or unreleased project artwork may be disclosed to hosted 3D or image generation services.

Mitigation: Before submitting artwork, check whether each service processes inputs locally or sends them to a provider, review its data handling, and submit only artwork approved for that use.
