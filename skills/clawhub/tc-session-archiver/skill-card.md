## Description:

Archive and organize completed OpenClaw session logs into structured markdown notes for long-term memory retention.

This skill is ready for commercial/non-commercial use.

## Publisher:

[terrycarter1985](https://clawhub.ai/user/terrycarter1985)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent users use this skill to turn completed session transcripts into concise, searchable markdown memory files with decisions, actions, blockers, and insights.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Session transcripts can contain secrets or private credentials that would be preserved in a local markdown archive.

Mitigation: Review and redact sensitive values before writing or appending archive files.
