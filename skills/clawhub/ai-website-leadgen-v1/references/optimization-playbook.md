# 优化动作目录与风险分级（Optimization Playbook）

本文件是「提出 5 个优化点」（第 5 步）与「执行低风险优化」（第 7 步）的弹药库。每个动作标注**风险等级**、**作用阶段**、**落地方式**与**示例**。Agent 据此归类、排序并生成建议。

## 1. 风险分级

- **low（B 级，用户同意后 MCP 自动执行）**：不破坏现有结构/数据流，仅追加区块或低风险改文案/字段属性。
- **high（逐条确认）**：删字段、改首屏结构、H1 重构、删联系方式、改漏斗路径、内容大改、改 noindex/HTTPS。

> 凡涉及 `save_ai_page` 改页面源码、`edit_custom_form` 改表单，均须遵守本技能 §2.1 红线与 `references/customform-democode-base.md` 的强制规则：保留 `{{}}`/`{%%}` 数据标签与表单校验/提交 JS，不破坏既有模板绑定。

## 5. 生成「5 个优化点」的排序规则

1. **先打最大漏点**：用 funnel-framework 第 4 节映射，定位得分最低的阶段/最痛漏点，对应的动作排第 1。
2. **投入产出比优先**：low 风险 + 高预期影响的动作（如 F1 减字段、P1 加 CTA、P2 信任区块）优先。
3. **覆盖多阶段**：5 点尽量横跨 页面/CTA/表单/信任/联系 不同面，避免 5 点全挤在一个面。
4. **低风险为主、高风险单列**：若最大漏点是高风险（如删字段 F10），仍把它列为优化点但明确标 `high` 需确认，另补一个 low 风险点垫底。
5. **每条含 5 要素**：`现状 → 漏点 → 建议动作(ID) → 风险等级 → 预期影响`。

### 示例 5 点（节选）

```
1. [表单/high] 联系页 9 字段过多 → 删"公司地址/公司全称"等高频空字段(F10) → 预期提交率 +20%~40%
2. [CTA/low] 全站无动作导向 CTA → 加"免费获取报价"主按钮(P1) → 预期点击 +15%
3. [信任/low] 无资质/客户证明 → 首页加"合作客户+资质"区块(P2) → 预期信任度提升
4. [联系/low] 电话仅在页脚 → 页头加点击拨打(P3) → 预期电话量 +10%
5. [产品/low] 产品页无询价入口 → 加一键询盘+相关推荐(R3) → 预期询盘 +12%
```
