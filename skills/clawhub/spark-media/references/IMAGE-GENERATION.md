# 图片生成详细说明

## 文生图请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `prompt` | string | 是 | 图片描述文本，最大 2000 字符 |
| `width` | integer | 否 | 宽度，需与支持的 2K 推荐尺寸组合一致 |
| `height` | integer | 否 | 高度，需与支持的 2K 推荐尺寸组合一致 |
| `style` | string | 否 | 附加到提示词中的风格描述，如"油画风格，厚涂笔触" |
| `image_count` | integer | 否 | 生成数量，1-4，默认 1 |

## 图生图请求参数

图生图使用 `POST /image/edit`，根据文字描述和一张参考图生成新图片。它与文生图一样同步返回 `data.images[]`，并按输出图片尺寸和张数计费。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `prompt` | string | 是 | 图片修改或生成目标，最大 2000 字符 |
| `reference_image` | file | 二选一 | multipart 上传的参考图文件 |
| `image_url` | string | 二选一 | 参考图 URL，需为可访问的 URL；不要同时上传 `reference_image` |
| `width` | integer | 否 | 输出宽度，默认 2048 |
| `height` | integer | 否 | 输出高度，默认 2048 |
| `style` | string | 否 | 附加风格描述，如"商业广告，清爽高级" |
| `image_count` | integer | 否 | 生成数量，1-4，默认 1 |

适合场景：

- 基于商品图生成广告图、海报图、社媒封面
- 保留参考图主体，替换背景、光影、构图或风格
- 根据用户上传的图片生成统一视觉风格的营销素材

## 推荐提示词技巧

- 运用连贯的自然语言描述画面内容（主体+行为+环境等）
- 用短词语描述画面美学（风格、色彩、光影、构图等）
- 写出图像用途和类型，例如：PPT封面背景图、广告海报设计
- 文字排版描述：将文字内容置于双引号内，通过指令描述文字的大小、字体、颜色、风格和位置
- 图生图时明确说明要保留什么、改变什么，例如“保留商品外观和比例，替换为夏季海边背景，增加促销标题区域”

| 尺寸 | 点数 | 约售价（元） |
|------|------|------|
| 2048x2048 | 56 | 0.56 |
| 2304x1728 | 54 | 0.54 |
| 1728x2304 | 54 | 0.54 |
| 2848x1600 | 61 | 0.61 |
| 1600x2848 | 61 | 0.61 |
| 2496x1664 | 56 | 0.56 |
| 1664x2496 | 56 | 0.56 |
| 3136x1344 | 57 | 0.57 |

**计费公式**：点数 × 单价（元/点），默认单价 0.01 元/点。

图生图按输出图片尺寸和张数使用同一计费规则。

## 图片格式

返回格式为 **PNG**，Base64 编码。需要时可在客户端解码保存为图片文件。

## 多图生成

`image_count` 参数支持 `1-4` 张图片。

- 系统会按张累计计费。
- 多图通常会比单图耗时更久。
- 为保证稳定性，多图请求可能按张生成后再聚合返回，因此结果可能是逐张完成的。
