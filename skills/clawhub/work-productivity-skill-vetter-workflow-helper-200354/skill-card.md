## Description: <br>
Helps AI-agent users, skill authors, maintainers, and teams create practical Skill Vetter-style workflows for bug fixes, setup hardening, reliability improvements, and adjacent skill development. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
AI-agent users, skill authors, maintainers, and teams use this skill to turn skill-vetting, security review, bug-fix, and reliability requests into concrete workflows, checklists, decision aids, code changes, or implementation support. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Overbroad trigger wording may invoke the skill for general security, GitHub, or bug-fix requests that are outside explicit skill-vetting or pre-installation review work. <br>
Mitigation: Prefer explicit skill-vetting, pre-installation review, workflow-hardening, or reliability-improvement requests before using the skill, and confirm scope when the user's request is ambiguous. <br>
