# 善起名 · 国学命名助手（WorkBuddy Skill）

一个基于《易经》、风水、八卦与国学经典的命名咨询技能，为 WorkBuddy / OpenClaw 设计。

## 能做什么

- **给新生儿/儿童起名**：结合孩子生辰八字，输出正式名 + 小名/昵称。
- **评析现有名字**：根据八字看名字五行成色，给出保留/调整建议。
- **家族五行合参**：把孩子八字与父亲、母亲命局一起排盘，找出全家共同喜用与忌神，形成整体调衡方案。

## 核心特点

- **精确排盘**：内置 `scripts/bazi.py`，采用儒略日（JDN）法计算四柱，1900–2100 年通用，已用 1949-10-01 = 甲子日 锚点验证。
- **父母命局合参**：不单凭孩子一方八字断喜忌，而是把父母八字一并纳入，判断"孩子所缺所喜，父母命局能否补益、名字当如何调衡"。
- **正式名 + 小名双交付**：每个方案都包含读音、字义出处、五行属性、补益逻辑、与父母呼应、卦象简评、谐音检查，以及 2–3 个小名备选。

## 安装方式

### 方式一：通过 WorkBuddy 技能市场安装

在 WorkBuddy / OpenClaw 的「技能市场」搜索 **"善起名"** 或 **"shanqiming"**，一键安装。

### 方式二：本地导入

1. 下载本仓库为 ZIP 压缩包。
2. 打开 WorkBuddy → 技能管理 → 添加技能 → 上传技能，选择 ZIP 文件即可。

### 方式三：ClawHub 一键安装

访问 [clawhub.ai](https://clawhub.ai) 搜索 **shanqiming**，点击安装。

## 使用示例

在 WorkBuddy 对话中输入：

```
@skill:shanqiming 给林姓男孩起名，孩子 2026-04-08 巳时，父亲林远航 1988-06-18 午时，母亲苏婉清 1990-09-22 酉时。
```

## 文件说明

- `SKILL.md`：技能主指令文件，包含完整工作流程与边界约束。
- `scripts/bazi.py`：精确四柱计算脚本，用法：`python bazi.py 年 月 日 [时]`。
- `references/wuxing_reference.md`：天干地支五行、五虎遁/五鼠遁、旺衰喜忌、起名常用字五行分类、康熙笔画姓名卦等参考。
- `icon.png`：技能图标（512×512 PNG）。

## 重要声明

本技能提供的八字、五行、卦象等内容仅供**传统文化参考与心理寄托**，不宣扬迷信决定论，不承诺任何现实效果。姓名学不决定人生走向，人生终究在己。

生辰信息仅用于本次分析，不留存、不外传。
