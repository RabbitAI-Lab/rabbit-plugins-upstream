# 五行 / 八字 命名参考手册

本文件供「善起名」技能在排盘、定喜忌、起名时按需查阅。所有四柱计算以 `scripts/bazi.py` 为准，本手册只提供判定规则与用字库。

## 一、天干地支五行

**十天干**
- 阳：甲(木) 丙(火) 戊(土) 庚(金) 壬(水)
- 阴：乙(木) 丁(火) 己(土) 辛(金) 癸(水)

**十二地支**
- 子(水) 丑(土·湿) 寅(木) 卯(木) 辰(土·湿) 巳(火)
- 午(火) 未(土·燥) 申(金) 酉(金) 戌(土·燥) 亥(水)

**地支藏干（起名/合参常用）**
- 子：癸水　丑：己土+癸水+辛金　寅：甲木+丙火+戊土
- 卯：乙木　辰：戊土+乙木+癸水　巳：丙火+庚金+戊土
- 午：丁火+己土　未：己土+丁火+乙木　申：庚金+壬水+戊土
- 酉：辛金　戌：戊土+辛金+丁火　亥：壬水+甲木

## 二、五虎遁（年干→月干）与五鼠遁（日干→时干）

**五虎遁（正月/寅月天干起算）**
- 甲己之年丙作首（寅月丙）→ 乙庚戊寅 → 丙辛庚寅 → 丁壬壬寅 → 戊癸甲寅
- 顺推：寅月天干定后，每月+1（天干循环）。

**五鼠遁（子时天干起算）**
- 甲己还加甲（子时甲）→ 乙庚丙子 → 丙辛戊子 → 丁壬庚子 → 戊癸壬子
- 顺推：子时天干定后，每时辰+1。

## 三、旺衰与喜忌判定通则

1. **得令**：日主五行与月支（月令）同气或受生为得令（旺）；被克/泄为失令（弱）。
2. **得地**：日主在地支有根（本气或中气藏干）为得地。
3. **得势**：天干有比劫/印星帮扶为得势。
4. **身旺**（得令+得地/得势）：喜克（官杀）、泄（食伤）、耗（财）；忌生（印）、助（比劫）。
5. **身弱**（失令+无根/无帮）：喜生（印）、助（比劫）；忌克、泄、耗。
6. **喜用神**=对日主有益的五行；**忌神**=有害的五行。起名/调衡即"补喜用、避忌神"。

- **金（补金/喜金用）**：锋、铭、钧、锐、锦、镇、铎、鑫、铠、铮、铄、锡、银、锋、钟

> 注意：字的五行以"字义+偏旁+姓名学常归类"综合判断，个别字有异说（如"丽"多归火、"冬"归水、"陆"归土），遇争议以主流姓名学归类为准并注明。

## 五、康熙笔画姓名卦（简法）

1. 取姓与名各字的**康熙笔画**数。
2. 上卦 = 姓笔画 % 8（余0作8）；下卦 = 名总笔画 % 8（余0作8）。
3. 八卦对应：1乾 2兑 3离 4震 5巽 6坎 7艮 8坤。

## 六、谐音与音律检查

- **谐音**：姓+名连读，逐字组词排查歧义/不良联想（如"马昊进"→"好进/浩进"皆正）。
- **音律（平仄）**：现代汉语声调 1/2 为平、3/4 为仄；避免三仄尾（如 3-4-4 收尾略重），尾字用平声更悠扬；姓与名避免同声母/韵母拗口。
