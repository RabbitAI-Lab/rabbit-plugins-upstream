# 多平台博主批量自动提取与关注技能 (Blogger Auto-Follow)

本技能用于解决用户在观看视频、浏览推荐长文或 PPT 截图时，看到一堆优质博主需要手动逐一搜索关注的繁琐痛点。
不仅支持**多模态图片识别**与**多平台批量自动关注**，还支持**本地博主资产库管理**（自动抓取主页直达 URL、增量录入、指定删除、一键在浏览器打开主页检索最新动态）。

> [!TIP]
> **对话即执行**：用户在与 AI 助手日常聊天时**无需死记终端命令**，直接发送截图或文本，Agent 将全自动完成识别、数据校验、调起浏览器并引导关注归档。

## 📋 详细执行规范

### 1. 博主信息结构化提取
当用户提供包含博主的图片（如视频截图、表格、思维导图、排行榜）或文本时：
- **精准提取博主名称**：过滤无关文字，提取纯净的博主账号名称；
- **提取元数据**：提取所属分类标签、粉丝量等；
- **展示给用户确认**：生成清晰的博主清单明细表。

---

### 2. 目标平台判定与交互确认（必须遵守）
若用户未明确指定平台，且从图片/文本内容无法 100% 确定唯一平台：
- **必须主动停下来，向用户提问确认目标平台**；
- 支持的主流平台：
  1. `douyin` (抖音)
  2. `xiaohongshu` (小红书)
  3. `bilibili` (哔哩哔哩 / B站)
  4. `x` (X / Twitter)
  5. `youtube` (YouTube)

---

### 3. 各平台手动登录确认（不限时等待）
- 打开目标平台首页后，**程序进入不限时等待状态**；
- 支持用户使用**手机扫码登录、账号密码登录、短信验证码登录**等任意方式；
- 用户在浏览器中完成登录后，回到终端按 `[Enter 回车键]`，脚本正式启动。

---

### 4. 超低频拟人防风控机制（防封禁、防限制）
- **基础随机间隔**：每个博主操作后随机休眠 `10.0 ~ 18.0 秒`；
- **阶段性深度休眠**：每连续处理 `5 位博主`，额外深度休眠 `20.0 ~ 35.0 秒`；
- **防重复误取消**：严格核验“已关注”、“互相关注”、“已订阅”状态，已关注的博主自动跳过；
- **滑块与验证码主动暂停**：检测到验证码时暂停并提示用户在浏览器中手动完成，回车后无缝继续。

---

### 5. 本地博主资产库管理与动态检索

#### 自动持久化存储：
- 数据主文件：`data/followed_bloggers.json`
- 可点击可视化导航：`data/FOLLOWED_BLOGGERS.md`

#### 管理与检索常用命令：
```bash
# 1. 查看库中已归档的所有博主 (或按分类/平台筛选)
python3 scripts/manage_bloggers.py --list
python3 scripts/manage_bloggers.py --category "教程实测"

# 2. 一键在本地浏览器中批量打开博主主页直达链接 (快速检索最新动态)
python3 scripts/manage_bloggers.py --open --category "教程实测"

# 3. 手动增量添加新博主
python3 scripts/manage_bloggers.py --add "博主名称" --category "AI实操" --platform douyin --url "https://..."

# 4. 删除指定博主 (支持博主名称或 ID 序号，自动同步刷新 Markdown)
python3 scripts/manage_bloggers.py --delete "博主名称"
```

## 🚫 反模式与严禁行为 (Anti-Patterns)

在开发与日常使用本技能时，**严禁**以下行为以保障账号与系统稳定性：

1. ❌ **严禁使用无头模式 (Headless) 或追求超高并发跑批**：
   - 社交平台对高并发无头浏览器具有极高的风控敏感度。切勿尝试修改代码去掉休眠或开启多线程并发，否则将导致 IP 被拉黑或账号直接被封禁。
2. ❌ **严禁在未登录或游客状态下强行执行关注**：
   - 必须等待用户在浏览器中成功登录后再按回车启动自动化。若未登录，页面无关注权限，会导致所有博主处理失败。
3. ❌ **严禁新注册账号在单日内过量批量关注**：
   - 注册不满 1 周的新账号风控阈值极低，单日批量关注建议控制在 **10 ~ 15 人** 以内；老账号建议单日 **30 ~ 50 人** 以内。
4. ❌ **严禁在遇到滑块验证码时不处理直接强行回车**：
   - 遇到滑块或点选验证码时，必须在浏览器中手动滑开后再按 Enter 继续。强行跳过或重复重试会导致风控等级瞬间上升。
5. ❌ **严禁对低分辨率模糊截图不做校验直接盲目跑批**：
   - 模糊截图可能导致 OCR 识别出形近错别字（如把“日”认成“曰”），执行前应先输出表格让用户快速核对。

## ❓ 常见问题与报错排查 FAQ (Troubleshooting)

### Q1: 提示 `Chrome 9222 调试端口无法连接` 或 `Connection refused` 怎么办？
- **原因**：本地已有一个普通的 Chrome 正在运行且未开启调试模式，或者 9222 端口被其他进程占用。
- **解决步骤**：
  1. 完全退出当前所有 Chrome 窗口（macOS 按 `Cmd + Q`，Windows 在任务管理器中结束 `chrome.exe`）；
  2. 重新运行 `python3 scripts/start_chrome.py`（或直接让 Agent “帮我启动调试浏览器”）；
  3. 确认打开的 Chrome 带有专属调试提示横条后，再运行关注脚本。

### Q2: 访问 YouTube / X 提示网络超时或无法连接？
- **原因**：海外平台需要系统代理 / VPN 环境支持，直连会导致 Playwright 页面加载超时。
- **解决步骤**：
  1. 开启本地代理/VPN 软件，确保开启系统代理或全局模式；
  2. 在打开的调试 Chrome 中先手动打开一次 `youtube.com` 或 `x.com`，确认可以正常访问网页；
  3. 回到终端重新启动批量关注脚本即可。

### Q3: 报错 `playwright._impl._errors.TargetClosedError` 或浏览器突然意外关闭？
- **原因**：在脚本运行期间，用户手动关闭了调试 Chrome 浏览器窗口，或被系统内存清理工具强制杀掉。
- **解决步骤**：
  - 运行期间请保持调试 Chrome 窗口开启；
  - 若意外关闭，重新运行 `start_chrome.py` 重新唤起即可。已经成功关注的博主已安全存入本地资产库，不会重复执行。

### Q4: 平台页面改版、提示找不到关注按钮或搜索结果为空怎么办？
- **原因**：目标平台前端 UI 或 DOM 选择器进行了微调升级。
- **解决步骤**：
  1. 运行一键平台诊断工具：`python3 scripts/diagnose_platform.py -p <平台名称> --headed`；
  2. 诊断工具会自动输出当前平台的选择器健康状况与匹配结果；
  3. 若选择器失效，参考 [references/supported_platforms.md](file:///Users/yan/Github/blogger-auto-follow/references/supported_platforms.md) 快速微调对应平台类下的 CSS 选择器。

### Q5: 登录二维码过期了怎么办？
- **机制说明**：本技能采用**不限时等待机制**。如果扫码时间较长导致二维码失效，直接在网页上点击“刷新二维码”，用手机扫码成功后，回到终端按 `[Enter]` 即可正常继续，无需重启脚本。

### Q6: 重复运行同一个名单，会把已经关注的博主取消关注吗？
- **机制说明**：**绝对不会**。脚本具备**状态幂等校验机制**，在点击前会严格检查页面按钮文案（如“已关注”、“互相关注”、“已订阅”），已关注的博主会自动标记并跳过，安全无副作用。
