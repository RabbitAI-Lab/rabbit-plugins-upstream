# 隐私、版权与边界（元题 yotta-item）

## 一、数据边界

- **本地运行**：核心路径不联网、不调用模型；题库、蓝图与试卷只在本机流转；
- **不上传**：没有遥测、没有云端提交、没有远程接口；把目录拷走即可离线使用；
- **零权限要求**：只需要读写用户指定的本地文件，不需要网络、数据库或系统级权限。

## 二、内容边界

- **不生成题面**：元题不做「AI 编题」——题目内容与答案全部来自学校自备题库；
  库中没有的题，元题不会编，只会报告缺口；
- **不内置题目与教材原文**：仓库与发布件中不含真题、教材、试卷原文；
  `template` 与 `scripts/fixtures/samples/` 里的示例均为合成占位数据（如「示例考点A」「SC-01」）；
- **不做实测断言**：难度标注是题库相对口径，不等于考后实测难度；
  区分度、掌握率等实测结论属元镜（yotta-mirror）的学情分析范围，元题不做预测性表述。

## 三、教育伦理边界

- 不做学生个体排名、评语与升学预测；
- 组卷结果与缺口清单是命题辅助，试卷定稿、内容审查与意识形态把关由命题组与教研组负责；
- 试卷文件只保存题目 id 引用，学生相关信息不进入元题的输入输出契约。

## 四、免责声明

报告中的 `disclaimer` 字段固定输出：本文件由元题基于本地题库与双向细目表的确定性计算生成，
仅作命题辅助；题目内容来自学校自备题库，未生成或改写题面；难度标注为题库相对口径，
不等于考后实测难度与区分度；试卷最终定稿由命题组与教研组负责。
