## Description: <br>
Senior Staff Engineer skill for AI coding agents that enforces simplicity, reuse-first, minimal-diff changes, testability, and Clean Code discipline for coding, refactoring, debugging, and code-review tasks. <br>

This skill is ready for commercial/non-commercial use. <br>

### License/Terms of Use: <br>

## Use Case: <br>
Developers and engineering teams use this skill to guide AI coding agents toward simple, maintainable, minimally scoped, and verifiable code changes. It is intended for coding, refactoring, debugging, review, and architecture discussions. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may make an agent more conservative about implementation changes and testing requirements. <br>
Mitigation: Set task-specific priorities clearly when speed or exploratory work is more important than strict minimal-diff discipline. <br>
Risk: Coding-style guidance can shape agent behavior across broad coding, refactoring, debugging, and review tasks. <br>
Mitigation: Review proposed plans and code changes before applying them, especially in repositories with different engineering conventions. <br>
