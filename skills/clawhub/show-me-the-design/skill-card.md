## Description:

Use only when the user explicitly requests this skill. Help beginners understand and examine software concepts and their collaboration through visuals grounded in source code, from overview to detail.

This skill is ready for commercial/non-commercial use.

## Publisher:

[agenticweb4](https://clawhub.ai/user/agenticweb4)

### License/Terms of Use:

MIT-0

## Use Case:

External users and beginner software learners use the skill to understand how a software project is designed and how its parts work together. It creates source-grounded visual explanations, diagrams, and offline lessons for an explicitly requested topic.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated lessons can contain project source snippets and file references that may be sensitive when shared outside the project.

Mitigation: Review source excerpts and file references before sharing generated materials outside the project.
