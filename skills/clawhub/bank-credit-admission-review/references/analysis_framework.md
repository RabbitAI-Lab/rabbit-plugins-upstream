# 四维分析框架明细

本文件为授信准入审查四维分析的指标、阈值与红旗信号清单。阈值仅为通用参考，行业有显著差异时以 `rules_library.md` 中的行业专项规则为准。

## 维度一：经营情况
### 1.1 行业景气度
- 指标：行业生命周期（导入 / 成长 / 成熟 / 衰退）、近 3 年行业增速、产能利用率、政策导向（鼓励 / 中性 / 限制 / 禁止）。
- 红旗：行业被列入"两高一剩"/限制类；近 3 年负增长且无明显拐点；突发强监管（如教培、平台经济、房地产）。
- 数据缺口：无行业基准时，结论限"中"以下并标注缺口。

### 1.2 市场地位
- 指标：市占率 / 排名、品牌力、技术壁垒 / 牌照、客户粘性。
- 红旗：市场份额持续下滑；排名靠后且无差异化；核心客户流失。

### 1.3 主营业务
- 指标：收入结构（前三大产品 / 客户占比）、盈利模式、产能 / 产量、订单能见度。
- 红旗：单一客户 / 产品占比 >50%；收入靠非主营（如投资收益、处置资产）支撑；产销量与收入背离。

### 1.4 上下游
- 指标：前五大供应商 / 客户集中度、应付账款 / 应收账款周转天数、议价能力、产业链位置。
- 红旗：供应商高度集中且替代难；应收账款周转大幅恶化；对下游议价弱、大量赊销。

## 维度二：财务情况
### 2.1 偿债能力
- 指标：资产负债率、流动比率、速动比率、现金短债比、利息保障倍数（EBIT / 利息费用）、有息负债 / EBITDA。
- 通用警戒线：资产负债率 >70%（制造业）、现金短债比 <1、利息保障倍数 <2、有息负债 / EBITDA >6。
- 红旗：短期债务占比过高且现金短债比 <1；利息保障倍数为负（亏损付息）；频繁借新还旧。

### 2.2 盈利能力
- 指标：毛利率、净利率、ROE、ROA、近 3 年趋势。
- 红旗：毛利率显著低于同业且持续下滑；连续 2 年亏损；非经常性损益占利润 >50%。

### 2.3 现金流
- 指标：经营活动现金流净额、自由现金流、现金流 / 净利润（盈利质量）、收现比（销售收现 / 营收）。
- 红旗：经营现金流长期为负或远小于净利润（利润"虚"）；收现比 <0.8；靠筹资现金流维持运转。

### 2.4 或有负债
- 指标：对外担保余额及 / 净资产、被担保方集中度、未决诉讼标的额、明股实债、表外负债（如并表基金、回购义务）。
- 红旗：对外担保余额 >净资产 50%；为关联方 / 民企互保；存在大额未决诉讼或被执行。

### 2.5 财务真实性疑点
- 指标：收入 / 利润与现金流背离度、应收账款增速 vs 营收增速、存货跌价计提充分性、毛利率异常高于同业、关联交易占比。
- 红旗：应收增速远超营收；存货高企且跌价准备低；毛利率畸高且无合理解释；大量关联交易输送利润。

## 维度三：管理层与股权
### 3.1 实控人背景
- 指标：实控人性质（国资 / 自然人 / 无实控）、履历与资信、是否限高 / 失信 / 被执行。
- 红旗：实控人为自然人且有多条失信 / 限高；实控人变更频繁；股权代持嫌疑。

### 3.2 股权结构
- 指标：股权集中度、质押比例、冻结情况、一致行动人。
- 红旗：控股股东高比例质押（>80%）；股权被冻结 / 司法拍卖；股权结构复杂存在代持。

### 3.3 管理层
- 指标：核心团队稳定性、激励机制、重大变动（董事长 / 财务总监离职）。
- 红旗：一年内核心高管频繁变动；财务负责人频繁更换（财务造假前兆）。

### 3.4 涉诉涉执
- 指标：作为被告案件数及金额、被执行记录、限高令、失信人。
- 红旗：作为被告且涉案金额大；被列入失信被执行人；有多地法院冻结。

### 3.5 关联方与担保圈
- 指标：关联担保、互保网络、资金占用、同一实控人下企业群。
- 红旗：陷入互保圈 / 担保链（区域性民企常见）；资金被关联方占用；同一控制下多家企业同时出险。

## 维度四：外部风险
### 4.1 政策风险
- 指标：行业监管趋势、环保 / 安监 / 反垄断处罚史、贸易壁垒。
- 红旗：所在行业面临收紧性政策；近期重大处罚；出口依赖且遇贸易摩擦。

### 4.2 征信
- 指标：征信报告贷款笔数 / 余额、逾期记录、查询次数、对外担保代偿。
- 红旗：存在当前逾期；近半年硬查询次数暴增；对外担保已代偿。

### 4.3 司法
- 指标：裁判文书数量、作为被告比例、破产重整 / 清算、股权冻结。
- 红旗：进入破产程序；大量作为被告的金融借款 / 买卖合同纠纷；核心资产被查封。

### 4.4 舆情
- 指标：负面新闻、债务违约 / 展期、评级下调、监管处罚、裁员 / 停产。
- 红旗：公开市场债券违约或展期；评级被下调至投机级以下；实控人 / 核心资产被查封传闻属实。

## 附：嵇氏「八大主线逻辑实证 + 交叉验证」（可选增强层，中小企业客群推荐启用）

> 来源：用户上传本地文献 嵇少峰《重构中国银行业信贷风控体系——2026 信贷技术从本质到实践的思考》（91 页）。完整框架、判语与页码见 `references/ref_jishaofeng_credit_risk_critique.md`。
> **引用格式**：`〔引·嵇少峰《信贷风控批判》P85〕`（转述加后缀 `，wb转述`）。
> **定位**：本层用于**交叉校验与逻辑穿透**，是对上述四维框架的补强，不替代四维框架；方法论观点不得当作客户事实数据来源。

### A. 八大主线（决定调查的全面性）
| 主线 | 关键实证动作 | 评估目标 |
|---|---|---|
| 一 经营者 | 品行与意愿（信用记录/法院执行/同业口碑/家庭稳定性）；能力与经验（从业年限/重大决策成败/团队互补）；战略与眼光（3～5年规划） | 发展驱动力与还款意愿根源 |
| 二 资产 | 真实性（现场盘点+权属发票）、有效性（设备利用率/厂房空置率/存货周转）、增值性（技术先进性/区位/知产） | 家底厚度与质量、第二还款来源 |
| 三 现金流 | **重建"准利润表"**（银行流水/主要合同核收入，供应商/水电费核成本）；应收账龄与集中度；投融资现金流 | 第一还款来源的可靠性 |
| 四 负债 | 显性（征信全量）、**隐性**（表外借款/对外担保/民间融资/股东往来款）、或有（担保/未决诉讼/环保处罚） | 真实杠杆与安全边际 |
| 五 生产与供应链 | 工艺效率（良品率/能耗 vs 标杆）、供应商依赖度与结算、客户依赖度与回款模式 | 商业模式脆弱性与核心竞争力 |
| 六 行业趋势 | 生命周期、政策与监管、技术变革与替代风险 | 外部环境方向与冲击力（社会建构） |
| 七 发展 | 历史投资成败、研发投入与新产品、**本次融资需求合理性** | 未来走向与授信合理性 |
| 八 信用履约 | 税务/工商历史记录；还款意愿（合主线一+七）；**违约成本**（合主线二+六） | 最终综合评判 |

### B. 交叉验证关系表（精髓：结论相互矛盾 = 风险隐藏信号，须查至疑点消除）
| 验证类型 | 交叉的两条主线 | 验证点 | 风险信号 |
|---|---|---|---|
| 一致性 | 三 现金流 × 四 负债 | 声称利润能否覆盖利息与债务 | 高利润却称无力付息；低负债却称现金流紧张 |
| 真实性 | 二 资产 × 三 现金流 | 资产规模与产出收入/利润是否匹配 | 巨额资产低产出（大马拉小车）；高收入但资产不匹配（疑虚增） |
| 合理性 | 七 发展 × 三 现金流 | 扩张投资额 vs 自身造血能力 | 造血不足却依赖贷款激进扩张 |
| 持续性 | 六 行业 × 七 发展 | 发展战略是否顺应行业趋势 | 下行期逆势重资产投入；技术路线落后仍投入 |
| 意愿性 | 一 经营者 × 八 信用履约 | 经营者口碑 vs 历史信用记录 | 夸夸其谈但名下企业有不良记录 |
| 压力测试 | 四 负债 × 六 行业 | 行业下行时现有负债是否致资金链断裂 | **高负债 + 强周期行业 + 行业已现拐点** |

### C. 启用条件与降级
- **数据越差、校验越严**：中国中小企业数据信息失真严重，不做校验则取数不能成为依据；随数据源真实性上升，校验要求可逐步弱化 〔引·嵇少峰《信贷风控批判》P86〕。
- 因此本层与「**零数据降级**」规则联动：财务为空/数据保真度低时，**必须**启用八大主线与交叉验证，并在报告中显式列出"矛盾点清单"；数据来源可靠（审计财报+征信齐全）时可简化为抽样验证。
- 若交叉验证发现矛盾且无法消除，结论不得优于"不予准入 / 暂缓"，并列入补充尽调清单。
