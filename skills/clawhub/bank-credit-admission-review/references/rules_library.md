## 有效规则

### 行内准入政策类（用户提供，优先级最高）
- 〔2026-08-11〕**「一般负面情况」认定**：满足以下任一条的企事业单位构成一般负面情况——
  ① 过去连续三年亏损；② 连续三年年度报表资产负债率超过 85%；③ 当期年报净资产为负。
  命中者原则上不予准入；确有业务必要须上提审批权限 + 特别理由说明 + 足额缓释措施。
  ｜用户提供·行内制度｜高
  **执行方式**：本 Skill **第 0 步**，先读 `references/negative_criteria.md` 校准口径，
  再跑 `scripts/negative_screen.py` 做确定性判定，禁止人工心算认定。该判定为四维分析的
  一票否决前置步骤，结论并入报告第九章"一票否决速查"。
  〔2026-08-11 融合说明：原独立 Skill `bank-negative-list-screening` 已整体并入本 Skill，
  不再单独存在。〕

- 〔2026-08-11〕**三条红线口径确认**（业务口径确认，脚本与文档已同步生效，
  未经再次确认不得调整）｜用户确认·行内口径｜高
  1. **「超过 85%」= 严格大于**：85.00% 不构成命中，仅列临界提示。
  2. **「净资产为负」看当期年报**：最近一期为负即构成，**不要求连续三年**；
     因此 C3 与 C1/C2 年度窗口不同，成立不足三年的主体 C3 仍须独立判定。
  3. **亏损口径归母与合计分别计算、不区分主次**：两口径平权各判一次，任一口径连亏三年
     即命中；结论不一致时仍认定命中并出具少数股东损益调节核查提示；仅有单一口径数据时
     须在信息缺口中声明待补数复筛。
  **其余口径要点**：扣非作实质性连亏辅助提示；年度须为完整会计年度且以年报审计数为准；
  C1/C2 不足三年输出"数据不足"而非推断。

- 〔2026-08-11〕**「零数据 / 非上市主体」自动降级处理规则**（数据可得性类，脚本已固化）：
  被比对企业**无任何公开财务数据**（财汇MCP 及公开渠道财务/评级/担保/司法均为零记录、
  `metrics` 全空）时，定量分位比对失效，须自动转入**四段式定性处理**（脚本 `emit_qualitative`，
  `compare` 输出 JSON 带 `qualitative_mode=true`）：
  ① **定性规模定位**——以行业基准中位营收为锚，用注册资本做数量级对比（如"低约 N 个数量级、
  属微型主体，与上市公司基准不具直接可比性"）；
  ② **行业名实校验**——`industry_match=false` 时打 ⚠ 强提示，建议改以**实际主业**对应行业基准复核；
     （该提示在数值路径同样触发，由 `emit_industry_divergence` 用 `declared_industry` 区分
     "仍以国标基准"与"已切换实际主业基准"两种措辞，避免误判）；
  ③ **能力边界声明**——明示非上市/数据稀缺、置信度 **LOW**、上市公司基准对非上市主体**系统性偏乐观**、
     结论不替代现场尽调与审计财报；
  ④ **「缺口即风险」默认授信建议**——暂不予信用授信；确需介入须同时满足：借款人提供**审计财报** +
     **足额强担保/抵质押** + 严格 KYC（凭统一社会信用代码 USCC 排除同名/关联失信主体）+ 现场尽调。
  信息缺口段在零数据下须追加"全部财务指标缺失、缺口即风险、须补财报复评"声明（修正了误报"无缺口"）。
  ｜富长翔艺（批发业，零数据）案例沉淀｜高
  **执行方式**：调用 `scripts/benchmark_db.py compare -i <企业指标.json>`，当输入 `metrics` 为空或
  仅含 `null` 时脚本自动走该分支，无需人工临时拼写；行业名实背离由 Agent 在 `profile.industry_match`
  与 `profile.actual_business` 显式标注（脚本不自判背离）。
  **设计取舍**：有数但稀疏者仍走原有 `gaps` 披露路径，仅当 `metrics` 全空才触发本分支。

- 〔2026-08-11〕**「上市集团全资子公司 / 并表主体」数据补位规则**（数据可得性类，本次调查沉淀）：
  当被查主体为**已上市母公司的 100% 全资子公司**（如中兴通讯 000063.SZ/0763.HK 之北京中兴数字星云），
  其**独立公开财务数据常为荒漠**（财汇MCP 及第三方工商对子公司主体多为零记录），但**母公司经审计
  年报会并表披露该子公司资产/负债/净资产/资产负债率**，且母公司自身有主体评级与公开经营数据——
  此时须以**母公司并表披露 + 母公司评级 + 第三方工商**三方交叉补位，置信度可由"数据荒漠 LOW"
  提升至"母公司支撑可核验"，**不机械触发"缺口即风险→拒贷"**。处理要点：
  ① 缺失的子公司自身营收/利润/流动比率仍按**缺口**披露，须补经审计财报；
  ② 高杠杆（如数字星云 ALR 93.05%，行业第100分位）须结合"新设爬坡期 + 母公司担保可用"解读，
     **不直接构成拒贷**，转为"强担保结构"准入；
  ③ 风险锚点由子公司转为**母公司信用**（本案母公司中诚信 AAA/稳定，连续十年）；
  ④ 授信须以**母公司连带责任保证或纳入其已公告子公司担保额度**为硬前提（无担保且不抵质押→拒贷）；
  ⑤ 须每年跟踪母公司年报更新并表数据，建立"母公司—子公司"数据台账。
  ｜北京中兴数字星云（中兴通讯全资子公司，数据靠母公司并表披露补位）案例沉淀｜高
  **执行方式**：先 `get_corporate_credit_ratings` 拉母公司评级；WebSearch 母公司最新年报取子公司并表段；
  再用 `benchmark_db.py compare` 以子公司可取得指标（如 ALR）做分位定位，并在报告中显式标注"母公司补位"来源。

- 〔2026-08-11〕**「流动资金贷款需求测算」规则**（授信额度约束类，脚本 `loan_demand.py` 固化）：
  采用银保监会《流动资金贷款管理暂行办法》"营运资金量法"测算**新增流动资金贷款额度 A**
  （A = 营运资金量 R − 借款人自有资金 F − 现有流贷 L − 其他渠道营运资金 O；
  R = 上年度营收 ×(1−销售利润率)×(1+增长率 g)÷ 营运资金周转次数）。
  处置纪律：① 拟授信流动资金贷款 **≤ A**：需求合理，按常规条件放行；
  ② 拟授信 **> A**：超额须说明真实用途（扩产/并购等）并配套**足额抵质押或强担保**，否则审慎或不超 A；
  ③ **数据缺口**（营收/周转科目不全致 A 不可得）：转"补数后复核"的准入前提条件，
     呼应「零数据 / 非上市主体」降级规则，补经审计财报与周转数据前不得核定信用流贷额度；
  ④ 参数（g / f / L / O）缺失时脚本取保守默认（g=0、f=30%、O=0）并显式标注假设。
  ｜流贷办法口径 + 脚本验证（示例企业测算通过）｜高
  **执行方式**：`python scripts/loan_demand.py -i <财务.json>`，将输出「一、流动资金贷款需求测算」
  直接嵌入报告 §五；A 值作为 §十一 / §十三 准入结论的额度约束依据。

- 〔2026-08-11〕**「刚性负债情况」分析规则**（偿债安全性类，脚本 `loan_demand.py` 固化）：
  刚性负债 = 短期借款 + 一年内到期非流动负债 + 长期借款 + 应付债券 + 长期应付款
  + 融资性应付票据（经营性占款如正常应付账款 / 预收不计入）。五项核心指标与红旗阈值：
  ① 刚性负债占比 ≥70%（负债高度刚性、再融资依赖高）→ 强审慎；
  ② 短期刚性÷货币资金 <1.0（即期偿付缺口，类比现金短债比<1）→ 红旗；
  ③ 利息保障倍数 <1.0（息前利润不抵利息）→ 重大红旗；
  ④ 刚性负债÷EBITDA >6（经营现金流覆盖薄弱）→ 高杠杆预警；
  ⑤ 刚性负债÷净资产 ≥1.5（净资产缓冲薄）→ 红旗。
  处置纪律：任一红旗触发 → 综合评级**不得高于「中高」**并专章说明缓释；
  利息保障 <1 且叠加第 0 步红线 → 直接不予介入；数据缺口转补数前提（补征信 / 财报后复核）。
  阈值可按行内口径调整；房地产 / 基建等天然高刚性行业须结合周期位置解读，避免机械套用。
  ｜银行授信实务口径 + 脚本验证（多红旗示例触发四项红旗）｜高
  **执行方式**：同 `loan_demand.py`，输出「二、刚性负债情况分析」嵌入报告 §六；
  红旗结论联动 §十 风险评级与 §十三 准入结论。

- 〔2026-08-19〕**「ST / *ST 风险警示」识别规则**（外部风险类，2025 退市新规口径）：
  上市公司客户须先查 ST/*ST 状态再定级——
  ① **ST（其他风险警示）**：分红不达标（近3年累计分红<年均净利30%且<5000万，创业板3000万）、
     控股股东资金占用≥2亿或>净资产30%、违规担保≥1000万或占净资产5%、内控审计非标未整改、
     银行账户冻结、失信被执行人等 → 风险定价上调、强担保、缩短期限；
  ② ***ST（退市风险警示）**：财务类（利润总额/净利润/扣非孰低为负 + 扣除后营收<3亿〔主板，
     创业板/科创板1亿、北交所5000万〕；净资产为负；审计非标）、交易类（连续20日市值<5亿或
     股价<1元）、规范类（占款≥2亿或>30%且6个月未归还、内控非标连续两年、控制权争夺致信披失效）、
     重大违法类（造假：1年≥2亿且占比≥30%/连续2年≥3亿且≥20%/连续3年）→ **一票否决级**，
     原则上不得新增信用敞口，已有敞口压降/退出；
  ③ **摘帽判定**：ST 消除全部触发情形可摘帽；*ST 摘星须次年利润/营收/净资产/审计意见**全部达标**，
     且新规"交叉适用"——次年任一指标不达标直接终止上市，无宽限期；
  ④ **壳价值陷阱**：*ST 保壳期常见突击交易/关联输血/债务重组，授信须甄别真实性，防止被保壳动作误导。
  ｜2025 退市新规 + 公开案例（*ST摩登/*ST西发/ST华西/安奈儿对照）｜高
  **执行方式**：完整阈值与案例见 `references/st_risk_guide.md`；对上市公司客户在"外部风险"章
  输出 ST/*ST 状态、触发类型、次年达标概率、对存量债权影响四问。

- 〔2026-08-19〕**「同业对比强制原则」**（数据可得性类，用户指令 · 最高优先级执行纪律）：
  审查任何客户（**无论是否上市公司、无论数据多寡**），**只要有条件取得同业可比数据，即须做同业对比**，
  判断其关键指标是否**低于同业水平**，并以此作为评级与准入的重要依据——
  ① 上市公司/发债企业：用 `benchmark_db.py compare` 做**行业分位比对**（P10/P25/P50/P75/P90 + 百分位排名）；
  ② 非上市但有数据：以其可取得指标（营收/净利/ALR/周转等）对照行业基准分位，输出"高于/接近/低于同业"定位；
  ③ 零数据非上市主体：按「零数据降级规则」做**定性规模定位**（注册资本 vs 行业基准中位营收的数量级对比），
     仍须给出"与同业相比处于何种水平"的定性结论，不得省略同业视角；
  ④ 同业对比结论须落入报告（§八 行业基准比对 / 准入标准建议），并标注对比基准口径（行业/样本数/年度）。
  ｜用户指令（2026-08-19 确认）+ 既有 benchmark_db 能力｜高
  **执行方式**：先 `query` 确认基准库是否已覆盖该行业，未覆盖则按需采集建基准（见 `industry_benchmark.md`）；
  再 `compare` 输出分位/定性定位；结论逐条带基准口径标签。

- 〔2026-08-19〕**「同业对比·门当户对（规模匹配）」补充规则**（用户指令追加 · 对比尺度纪律）：
  同业对比**必须先看规模是否匹配**——轻量级 vs 重量级直接比优劣，本身就是不合理结论的源头。
  **规模分层先行，同层对比优先**：
  ① **分层标准**（按最近年报营收，可结合总资产/注册资本复核）：大型 ≥100 亿 ｜ 中型 20–100 亿 ｜
     中小型 5–20 亿 ｜ 小型微 <5 亿（阈值可按行内口径调整，分层目的在"同量级比较"，不在绝对划分）；
  ② **同层优先**：基准样本充足时优先与**同规模层**样本对比；基准库当前未按规模分层时，
     `compare` 须在结论中**显式标注客户规模位置**（如"客户营收 3 亿，处于基准样本营收分布 P25 以下，
     属小型微层，分位结论仅供方向参考"），不得输出裸分位排名充当定论；
  ③ **量级悬殊降级**：客户营收 < 基准中位营收 **1/10**（或 > 基准中位 10 倍）时，定量分位对比**降级**
     为"规模校正解读"或转入定性定位（呼应零数据降级），防止以数量级失真误导评级；
  ④ **规模本身是维度**：规模层差异须计入"经营情况"维度评分——同等指标下，规模越小的客户抗风险缓冲
     越薄（供应链议价/融资渠道/平滑亏损能力均弱），不因"与同层持平"而豁免规模风险；
  ⑤ 报告呈现：同业对比表须带"客户规模层 + 对比样本规模范围"两列，审核时先看规模匹配再看分位。
  ｜用户指令（2026-08-19 追加确认，源自"轻量级对重量级不合理"的对比尺度要求）｜高
  **执行方式**：`compare` 已内置规模分层——读入 `metrics["营业总收入"]` 自动判定客户规模层，
  筛同规模层同业样本输出「同层分位」列与「规模校正提示」；量级悬殊（客户营收<基准中位营收1/10
  或>10倍）自动降级警告；同层样本<5家自动跳过并提示代表性不足。无营收数据时由 Agent 手工
  标注规模位置并落两列。

- 〔2026-08-19〕**「控制权变更 / 易主观察」规则**（治理类，安奈儿易主案例沉淀）：
  上市公司客户发生控股股东/实控人变更后——
  ① **观察期 ≥1 年**：观察期内不因易主上调评级，评级以经营基本面为准；
  ② **新实控人担保须落纸面**：口头/表态不作数，须实际提供连带责任保证或支持函并核验；
  ③ **三维评估新实控人**：实控人实力（资产/现金流）× 历史操盘记录（既往控股标的是否扭亏）× 输血意愿（定增/担保动作）；
     **操盘手 ≠ 白衣骑士**——有"买壳-输血-重组"流水线记录的资本方，须按皖通科技类实证检验其产业赋能能力；
  ④ **控制权基础核查**：新实控人及其一致行动人合计持股比例是否偏低（<20% 为薄弱）、原实控人剩余股权及其减持/质押扰动；
  ⑤ **题材与传闻隔离**：新实控人体系内资产注入/跨界转型的**预期不得作为当期授信依据**，仅记入贷后监测。
  ｜安奈儿（黄涛/世纪金源 4.22 亿易主 + 皖通科技实证 2025 巨亏 3.26 亿）案例沉淀｜高
  **执行方式**：易主类客户按此五条核查，输出"新实控人三维评估表 + 观察期结论"。

- 〔2026-08-19〕**「跨界转型 / 第二曲线」甄别规则**（题材类，安奈儿算力传闻案例沉淀）：
  客户（或其新实控人体系）宣布跨界新业务（算力/AI/医药/新能源等题材）——
  ① **两级证据分级**：已落地业务（公告+收入/投资实缴）为一级证据，可计入分析；传闻/预期/股吧帖为二级，
     **不得作为授信依据**，仅记入贷后监测关键词；
  ② **跨界失败前科记险**：既往收购告吹、监管罚单、跨界应收被拖欠等，记为跨界执行力与风控能力减分项；
  ③ **亏损企业重资产跨界 = 风险信号**：主业失血+货币资金有限却布局重资产新业务（如 AIDC/数据中心），
     触发重估而非利好，须评估资金缺口与流动性传导；
  ④ **"第二曲线"与"资产注入预期"区分**：上市公司客户还须区分"自身做新业务"与"实控人体系资产注入预期"，
     后者属远期期权，不构成当期信用基础。
  ｜安奈儿（2024 收购算力告吹+罚单、2026 新增经营范围后传闻转型）案例沉淀｜高
  **执行方式**：出现跨界题材时按此四步甄别，报告"外部风险/经营情况"章输出证据分级结论。

- 〔2026-08-19〕**「现金流质量」规则**（财务质量类）：
  ① 连续 2 年经营现金流为负 + 连续 2 年自由现金流为负 → 综合评级上限"中"；
  ② 净利润为正但经营现金流持续为负 → 利润质量存疑，须排查应收/存货/提前确认收入；
  ③ 收现比（经营现金流÷净利润）<0.5 连续两年 → 红旗，评级不高于"中高"；
  ④ 经营现金流为负但靠短期借款维持运营（短借激增+财务费用上升）→ 流动性依赖信号，并入刚性负债分析。
  ｜安奈儿"增收减利/经营现金流为负/短借+149%"案例 + 通用财务分析口径｜高
  **执行方式**：现金流指标取自财报/财汇MCP，结合 `loan_demand.py` 刚性负债输出交叉印证。

- 〔2026-08-19〕**「审计质量联动」规则**（财务真实性类）：
  ① 审计意见分级联动：标准无保留→正常；保留/带强调事项→评级不高于"中"；否定/无法表示→一票否决（呼应评分卡）；
  ② **审计机构连续 2 年更换** → 财务质量红旗，须穿透核查更换原因；
  ③ **"年报前会计差错更正 + 计提大额减值 + 未弥补亏损达股本 1/3"组合拳** → 财务质量红灯，须核查是否存在
     "洗大澡"/调节利润，评级下调并加强贷后（安奈儿 2026-04-29 同日三公告即典型案例）；
  ④ 财报数据与公告原文冲突时**以公告原文为准**并记录分歧（呼应数据审核协议）。
  ｜安奈儿 2026-04-29 三公告（差错更正/减值/未弥补亏损）+ 审计实务口径｜高
  **执行方式**：读取审计报告/公告正文核实意见类型与变动，输出"审计质量核查结论"。

- 〔2026-08-19〕**「股票 / 股权质押情况」必查规则**（或有负债与股权质量类，用户指令 · 固定必查项）：
  对**上市公司客户（及发债主体）**，股权质押调查是**必查项**，纳入「管理层与股权」维度，
  用财汇MCP `get_stock_pledge_details`（工具：股票质押明细）拉取质押明细，**列表展示**以下字段：
  ① **质押权人（质权人）** ② **质押数量 / 剩余质押数量**（万股） ③ **质押状态**（未解押 / 已解押）
  ④ **质押起始日 / 截止日** ⑤ **质押成本价 / 预警价 / 平仓价（估算）** ⑥ **公告日期**。
  分析要点（结合十大股东/十大流通股东持股数）：
  1. **质押率**：股东已质押份额 ÷ 其持有份额（质押股数 / 该股东持股数）；整体质押率 = 质押总数 / 总股本；
  2. **股东剩余份额**：持股数 − 质押数（可自由支配的股份）；质押率 >50% 即列重点关注；
  3. **预警 / 平仓价安全边际**：现价 vs 预警价 / 平仓价——现价低于预警价触发追加质押/补保证金，
     低于平仓价且未补充则质权人可强平，股价下跌会引发**质押强平螺旋**（质押→跌→强平→更跌）；
  4. **质权人结构**：银行/信托/券商占比，信托占比高说明融资渠道下沉、财务弹性弱；
  5. **实控人/控股股东质押**：比例高（≥50%）或接近平仓价 → 控制权转移风险（质权人可能被动接盘），
     评级下调并列入贷后监测；
  6. **联动**：质押率与「控制权变更/易主观察」规则联动——高质押易触发被动减持/易主；
     非上市公司查**股权出质**（工商登记，财汇MCP 企业筛选 `filter_companies_by_basic_info`
     股权出质维度或工商变更记录）。
  ｜隆基绿能质押明细（MCP 字段验证：质权人/剩余质押/预警平仓价齐全）+ 用户指令｜高
  **执行方式**：`get_stock_pledge_details` 参数 `target_stock`（股票名称/代码，数组）；返回 0 条时
  在报告质押小节注明"公开质押记录为空（或无存续质押）"而非省略该维度；输出统一用表格
  列示：出质人/质权人/质押数量/剩余质押/状态/起始日/截止日/成本价/预警价/平仓价/公告日，
  并在表后附质押率与平仓安全边际结论。
