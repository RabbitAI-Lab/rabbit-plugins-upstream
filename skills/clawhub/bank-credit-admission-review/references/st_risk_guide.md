# ST / *ST 风险警示规则速查（2025 退市新规口径）

> 生效依据：2024-04-30 沪深交易所修订《股票上市规则》，2025-01-01 正式实施（"退市新规"）。
> 适用：授信审查中判断上市公司客户是否处于风险警示状态、壳价值与退市风险。
> 口径来源：证监会/交易所公开规则 + 2025 年公开案例（已按 2026-08 可查信息核对）。

## 一、概念区分

| | ST（其他风险警示） | *ST（退市风险警示） |
|---|---|---|
| 性质 | 提示经营/规范风险，**不直接退市** | 已处退市边缘，**次年不达标即退市** |
| 涨跌幅 | 5%（创业板/科创板 20%、北交所 30%） | 5%（同上） |
| 触发 | 单一条件触发 | 单一条件触发，四类情形 |
| 对授信含义 | 风险定价上调、强担保要求 | 一票否决级风险，原则上不得新增信用敞口 |

## 二、触发 ST（其他风险警示）的情形

**规范类（新规重点新增）：**
1. **分红不达标**（主板新增）：最近 3 年累计现金分红 < 年均净利润 30% 且总额 < 5000 万（创业板 3000 万）——仅连续 3 年盈利的公司才可能触发，与亏损公司无关
2. **控股股东资金占用**：非经营性占用余额 ≥ 2 亿 或 > 净资产 30%
3. **违规担保**：≥ 1000 万 或 占净资产 5%
4. **内控非标**：内控审计报告被出具无法表示意见 / 否定意见，且未整改

**经营异常类：**
5. 主要银行账户被冻结
6. 被列为失信被执行人
7. 生产经营受严重影响，预计 3 个月内不能恢复
8. 董事会无法正常运作等交易所认定的重大风险情形

## 三、触发 *ST（退市风险警示）的情形（四类）

### ① 财务类（主板口径；创业板/科创板/北交所门槛见括号）
- 利润总额、净利润、扣非净利润 **三者孰低为负** + 扣除后营收 **< 3 亿元**（创业板/科创板 1 亿、北交所 5000 万；原主板 1 亿已上调）
- 期末**净资产为负**
- 年报被出具**无法表示意见 / 否定意见**
- 连续两年财报非标（审计意见）

### ② 交易类
- 连续 20 日**总市值 < 5 亿元**（主板，原 3 亿）
- 连续 20 日**收盘价 < 1 元**（面值退市）

### ③ 规范类
- 控股股东资金占用 ≥ 2 亿 或 > 净资产 30%，**6 个月内未归还**（→ 直接启动规范类退市程序）
- 内控非标 **连续两年**且未整改（第一年 ST → 第二年 *ST → 第三年退市）
- 控制权无序争夺导致信息披露失效
- 未按期披露年报/半年报，责令改正期内未改正

### ④ 重大违法类（多数直接退市，无 *ST 过渡）
- **财务造假**：1 年造假 ≥ 2 亿且占比 ≥ 30%；或连续 2 年造假 ≥ 3 亿且占比 ≥ 20%；或连续 3 年及以上造假
- 欺诈发行、重大信息披露违法、其他严重损害证券市场秩序

## 四、摘帽（撤销风险警示）条件

### ST → 摘帽
触发情形全部消除：占款清收完毕 + 会计师专项核查意见、内控整改合格、账户解冻、失信解除等 → 交易所审核后撤销。

### *ST → 摘星（以财务类为例）
**次年须全部达标**：
- 利润总额、净利润、扣非净利润孰低均为正
- 扣除后营收 ≥ 3 亿（对应板块门槛）
- 期末净资产为正
- 审计意见为标准无保留
- 不触及其他退市情形

> ⚠️ **交叉适用收紧**：财务类 *ST 后，次年任一财务指标（营收/净资产/审计意见）仍不达标 → **直接终止上市，无宽限期**。突击营收、卖资产、债务重组一次性收益等"保壳"财技在新规下基本失效。

## 五、授信审查应用要点

1. **上市公司客户**：授信前查 ST/*ST 状态（行情软件、公告标题即含标识；财汇MCP 公告检索可筛"风险警示"）。
2. **状态含义**：
   - ST：风险定价上调、强担保、缩短期限；
   - *ST：**一票否决级**，原则上不得新增信用敞口；已有敞口启动压降/退出预案；
   - 重大违法类（造假退市）：立即核查是否存在违规担保/占款，评估债权申报与追偿路径。
3. **壳价值判断**：*ST 公司"保壳"期间可能出现突击交易、关联输血、债务重组——授信须甄别其**真实性**，防止被"保壳动作"误导。
4. **与第 0 步红线的关系**：*ST 公司多数同时命中"连续三年亏损/净资产为负"红线，两者互为印证；ST（非*ST）公司不必然命中红线，仍按常规四维流程，但风险评级上调。
5. **对照检查模板**（用于报告"外部风险"章）：
   - 是否 ST/*ST？触发类型（财务/交易/规范/重大违法）？
   - 若 *ST：次年达标概率？有无退市风险？对存量债权影响？
   - 若 ST：触发原因是否消除？摘帽进度？

## 六、案例参照

- *ST 摩登：财务类（利润为负+营收<3亿）+ 规范类（占款未清收）双触发，占款由第三方代偿后申请摘星，须会计师专项核查。→ 规范类摘帽的典型路径。
- *ST 西发：营收利润达标仍被 ST，因法院受理重整申请。→ 重整 ≠ 摘帽，须重整完成并消除风险。
- ST 华西：2024 年内控审计无法表示意见（连续两年非标且未整改）→ 规范类 ST 典型。
- 安奈儿（002875，2026-08）：连续 6 年亏损但 2025 营收 5.43 亿 > 3 亿，净资产为正、无审计非标、无占款/违规担保 → **当前不触发 ST**；需盯"营收跌破 3 亿"或"净资产转负"两个触发点，另"未弥补亏损达实收股本 1/3"是《公司法》层面警示（须股东会说明），不直接触发交易所 ST。
