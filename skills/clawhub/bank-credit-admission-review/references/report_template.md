## 五、流动资金贷款需求测算
### 5.1 测算参数与结果 〔来源标签〕
（引用 `scripts/loan_demand.py` 输出；参数 g=预计销售收入年增长率、f=借款人自有资金比例、
L=现有流贷、O=其他渠道营运资金，均须标注来源与保守假设）
> 参数与结果表（上年度营收、销售利润率、各周转天数、营运资金周转次数、营运资金量 R、
> 借款人自有资金 F、现有流贷 L、其他渠道 O、**新增流贷额度 A**）
### 5.2 授信金额合理性结论
- 拟授信流贷 **≤ A**：需求合理，可按常规条件放行；
- 拟授信流贷 **> A**：超额须说明真实用途（扩产/并购等）并配套**足额抵质押或强担保**，否则审慎 / 不超 A；
- **数据缺口**（营收/周转科目不全）：A 不可得，转"补数后复核"的准入前提条件（呼应零数据降级规则），不得据此核定信用流贷额度。

（引用 `scripts/loan_demand.py` 输出：短期借款 / 一年内到期非流动负债 / 长期借款 / 应付债券
/ 长期应付款 / 融资性应付票据 + **刚性负债合计** + 短期刚性占比；经营性占款不计入）
### 6.2 核心指标与红旗
> 指标表：刚性负债占比 / 短期刚性÷货币资金 / 利息保障倍数 / 刚性负债÷EBITDA / 刚性负债÷净资产，
> 各列判定（健康 / 关注 / 红旗）。红旗阈值：占比 ≥70%、短期覆盖 <1.0、利息保障 <1.0、
> 刚性-EBITDA >6、刚性-净资产 ≥1.5（可按行内口径调整）。
### 6.3 期限结构与偿债安全性结论
（短刚 vs 长刚结构、即期偿付压力；任一红旗触发时综合评级**不得高于「中高」**并须专章说明缓释；
利息保障 <1 且叠加第 0 步红线 → 不予介入；数据缺口项转补数前提）
