# 流动资金贷款需求测算 与 刚性负债情况分析 — 方法论

> 用途：在授信准入初审报告（模式 B）与「一般负面情况」快筛报告（模式 A）中，固化两块**授信额度与负债结构**分析——
> ① **流动资金贷款需求测算**（回答"这家企业该给多少流贷才合理"）；
> ② **刚性负债情况分析**（回答"它的债务里有多少是硬约束、即期能不能还上"）。
> 两块共同服务于第 6 步的**准入结论**：流贷测算约束"授信金额合理性"，刚性负债约束"偿债安全性"。
> 计算由 `scripts/loan_demand.py` 确定性产出，**禁止人工心算**（与第 0 步红线脚本同一纪律）。
> 与其他文件的衔接：`analysis_framework.md`（财务下钻）→ 本方法论（额度与负债结构）→ `admission_standards_control.md`（尺度与抓手）→ `risk_rating.md`（评级）→ `rules_library.md`（规则沉淀）。

## 一、流动资金贷款需求测算（银保监会流贷办法口径）

依据《流动资金贷款管理暂行办法》及补充通知的"营运资金量法"。

### 1.1 公式链

```
销售利润率        p  = 净利润 ÷ 上年度营业收入
存货周转天数      Dinv = 360 × 存货 ÷ 营业成本
应收账款周转天数  Drec = 360 × 应收账款 ÷ 营业收入
应付账款周转天数  Dpay = 360 × 应付账款 ÷ 营业成本
预付账款周转天数  Dpre = 360 × 预付账款 ÷ 营业成本
预收账款周转天数  Dadv = 360 × 预收账款 ÷ 营业收入

营运资金周转次数  W  = 360 ÷ (Dinv + Drec − Dpay + Dpre − Dadv)
营运资金量        R  = 上年度营业收入 × (1 − p) × (1 + g) ÷ W
借款人自有资金    F  = R × f            （f = 自有资金比例，默认 0.30）
新增流动资金贷款额度  A = R − F − L − O
                      （L = 现有流动资金贷款；O = 其他渠道提供的营运资金）
```

- **折算说明**：银监会原文以"存货（平均余额）"列示，实务允许取**期末余额**近似（标注假设）。
- `g`（预计销售收入年增长率）：优先取企业申报/经营计划，无则取**行业近三年营收 CAGR**或保守取 0；激进假设（g>20%）须标红复核。
- `f`（自有资金比例）：保守默认 **0.30**；若可取得所有者权益中可投入营运的明细，可上浮，但须标注来源。
- `L`（现有流贷）：优先取"短期借款"中流贷部分；无明细时以**短期借款**近似，标注假设。
- `O`（其他渠道营运资金）：含应付票据（融资性）、股东借款、发行债券等已锁定来源；缺失默认 0 并标注。

### 1.2 输出与判定

| 输出项 | 含义 | 判定 / 处置 |
|---|---|---|
| 营运资金量 R | 维持经营所需营运资金增量 | 规模锚 |
| 新增流贷额度 A | 理论可新增流贷上限 | **拟授信流贷 ≤ A 视为需求合理** |
| A < 0 | 自有资金与存量已覆盖，无需新增流贷 | 不应新增信用流贷；确有用途须以抵质押/强担保覆盖 |

**与授信结论联动**（详见 `rules_library.md`「流贷需求测算规则」）：
- 拟授信流贷 **≤ A**：需求合理，可按常规条件放行。
- 拟授信流贷 **> A**：超额部分须说明真实用途（扩产/并购等）并配套**足额抵质押或强担保**，否则审慎/不超 A；
- **数据缺失**（营收/周转科目不全）：A 不可得，该测算转为"补数后复核"的**准入前提条件**（呼应零数据降级规则），不得据此核定信用流贷额度。

### 1.3 数据来源

主源财汇MCP `get_company_financial_metrics`（营收/净利/存货/应收/应付/预付/预收/短借）；营业成本、增长率、自有资金比例可由公开年报/问询函补位。字段映射见 `data_mapping.md` §五。

## 二、刚性负债情况分析（银行内部口径）

"刚性负债"= 企业**必须按约偿付本息的硬债务**，区别于经营性无息负债（如正常应付账款属于经营占款、通常不含息、可滚动，不计入刚性）。

### 2.1 刚性负债构成（取数口径）

```
刚性负债 = 短期借款
         + 一年内到期的非流动负债
         + 长期借款
         + 应付债券
         + 长期应付款（融资租赁款等，剔除经营性）
         + 应付票据（融资性部分，如已贴现/质押的银行承兑汇票）  〔可选，按需计入〕
```

> 口径取舍：正常**应付账款、预收账款、合同负债**属经营性占款，默认**不计入**刚性负债；若将"带息应付票据"并入，须在报告中声明口径。银行内部口径不一，本 Skill 以"带息 + 一年内须偿付本金"为纳入原则。

### 2.2 核心指标与红旗阈值

| 指标 | 公式 | 健康 | 关注 | 红旗（强审慎） |
|---|---|---|---|---|
| 刚性负债占比 | 刚性负债 ÷ 总负债 | < 50% | 50%–70% | **≥ 70%**（负债高度刚性，再融资依赖度高） |
| 短期刚性覆盖 | (短期借款 + 一年内到期) ÷ 货币资金 | ≥ 1.0 | 0.7–1.0 | **< 1.0**（即期偿付缺口，类比现金短债比<1） |
| 利息保障倍数 | EBIT ÷ 利息费用 | ≥ 3.0 | 1.0–3.0 | **< 1.0**（息前利润不抵利息，经营难覆盖财务成本） |
| 刚性负债 / EBITDA | 刚性负债 ÷ EBITDA | < 3 | 3–6 | **> 6**（经营现金流对刚性债务覆盖薄弱） |
| 刚性负债 / 净资产 | 刚性负债 ÷ 所有者权益 | < 1.0 | 1.0–1.5 | **≥ 1.5**（杠杆高，净资产对刚性债务缓冲薄） |

> 阈值可按行内口径在 `rules_library.md` 调整；阈值为**参考值**，须结合行业（如房地产/基建天然高刚性）与周期位置解读，不得机械套用。

### 2.3 期限结构

拆分**短期刚性**（短期借款 + 一年内到期）与**长期刚性**（长期借款 + 应付债券 + 长期应付款），计算短刚占比。短刚占比越高，即期流动性压力越大，对授信期限结构（优先中短期、绑定回款）与担保要求越高。

### 2.4 与结论联动（详见 `rules_library.md`「刚性负债情况规则」）

- 任一红旗触发 → 综合风险评级**不得高于"中高"**，须专章说明缓释（抵质押、强担保、期限错配修正）。
- 利息保障倍数 < 1 **且** 触发第 0 步红线 → 直接**不予准入**。
- 刚性负债占比 ≥ 70% 或 短期刚性/货币资金 < 1 → 授信须以**足额抵质押或实控人无限连带**为硬前提。
- 数据缺失：刚性负债不可得时，按"缺口即风险"转为准入前提条件（补征信/财报后复核），不机械放行。

## 四、质量校验清单（Agent 自检）

- [ ] 流贷测算是否由 `loan_demand.py` 产出，参数（g / f / L / O）是否标注来源与假设？
- [ ] 拟授信流贷是否 ≤ 测算新增额度 A；超额是否配套抵质押/强担保说明？
- [ ] 数据缺失时，流贷测算是否转为"补数后复核"前提条件（而非默认可信）？
- [ ] 刚性负债口径是否声明（经营性占款不计入、融资性票据是否并入）？
- [ ] 五个刚性指标是否逐项计算，红旗是否触发并联动评级与结论？
- [ ] 零数据/数据荒漠主体是否走定性降级，未机械套用公式？
- [ ] 行业特性（如房地产高刚性）是否在解读中被考虑，避免误判？
