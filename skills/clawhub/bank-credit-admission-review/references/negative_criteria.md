# 「一般负面情况」认定标准细则

> 行内口径原文：一般的负面情况，指过去连续三年亏损，或连续三年年度报表资产负债率超过 85%，或净资产为负的企事业单位。
> 本文件是对该口径的可执行化拆解。每次判定前通读，不得凭记忆套用。

## 〇、口径确认记录（2026-08-11 生效）

原表述存在三处歧义，已经业务口径确认如下，脚本与本文件均按此实现。**未经再次确认不得擅自调整**：

| 争议点 | 确认结论 | 对应实现 |
|---|---|---|
| 「超过 85%」是否含等于 | **超过 = 严格大于**，85.00% 不命中 | `ALR_RED_LINE = 85.0`，判定符为 `>` |
| 「净资产为负」是否同样要求连续三年 | **看当期年报**，最近一期为负即构成，不要求连续三年 | C3 仅取窗口内最近年度判定 |
| 亏损取归母还是合并 | **分别计算、不区分主次**，两口径平权 | C1 拆 C1·归母 / C1·合计，任一命中即 C1 命中 |

## 一、三条红线

| 编号 | 红线 | 判定条件 | 关系 |
|---|---|---|---|
| C1 | 连续三年亏损 | 归母净利润、净利润合计**分别判定**，任一口径最近三个完整会计年度均 < 0 | 三条为**或**关系，命中任意一条即构成 |
| C2 | 连续三年资产负债率超标 | 最近三个年度报表资产负债率均 **> 85%** | 同上 |
| C3 | 当期年报净资产为负 | **最近一个**年度报表净资产 < 0（不要求连续三年） | 同上 |

**"超过 85%" 取严格大于**：恰好等于 85.00% 不构成命中，但须在报告中列为临界项提示。

**C1 与 C3 的年度窗口不同**：C1、C2 看最近三个完整会计年度；C3 只看最近一期年报。因此成立不足三年的主体，C1/C2 判"数据不足"时，C3 仍可独立成立并直接构成红线。

## 二、指标口径

### C1 净利润口径

**归母净利润与净利润合计（含少数股东损益）两个口径平权，分别计算，不设优先级与回退关系。**

- 两个口径各判一次，**任一口径构成连续三年亏损即 C1 命中**
- 两口径结论不一致时（如归母连亏而合计未连亏），仍认定 C1 命中，同时在报告中出具**差异提示**：差额源于少数股东损益，须核查是否存在通过并表结构调节归母利润的情形
- 仅取得单一口径数据时，凭已有口径出结论，但须在「信息缺口」章节声明另一口径缺失、结论待补数复筛（财汇MCP 常仅返回归母，属高频情形）
- **扣非归母净利润**不作为直接判定口径，但作为「实质性连亏」的辅助判断：
  - 若扣非连续三年为负、而归母因非经常性损益（政府补助、资产处置、债务重组收益等）某年转正 → 按实质重于形式原则，在报告中出具「实质性连亏」提示，建议从严认定并上提审批
  - 该情形属**提示**而非自动命中，最终认定由审查人结合行内政策把握

### C2 资产负债率口径

- 计算式：负债合计 ÷ 资产总计 × 100%
- 以**合并报表年度数**为准（母公司报表仅作参考）
- 以年度报告直接披露值优先；披露值缺失时由资产/负债科目反算，反算值须在报告中标注为派生数据
- 剔除永续债、少数股东权益等特殊科目的口径调整**不做**，一律按报表原始科目计算，避免主观调节

### C3 净资产口径

**判定窗口为当期，即最近一个已出具的年度报表；该年度净资产为负即命中，不要求连续三年。**

- 默认采用**所有者权益合计**（含少数股东权益）
- 同时核对**归母净资产**：若合计为正而归母为负，须在报告中单列提示——该情形常见于合并了高权益少数股东项目的集团，母公司层面已资不抵债
- 净资产 = 资产总计 − 负债合计，可由科目反算，反算值同样标注为派生数据
- 净资产金额完全缺失时，可由资产负债率是否低于 100% 推定其正负（ALR<100% ⇔ 净资产为正）；推定值仅决定正负、不代表金额，须在报告中标注
- **历史年度曾为负而当期转正**：C3 判未命中，但须出具提示，核查转正来源（增资、债转股、资产重估或利润实现）及其可持续性——账面增资转正而经营未改善的，实质风险未消除

## 三、年度范围规则

- "连续三年"指**最近三个完整会计年度**，非滚动十二个月，仅适用于 C1、C2
- **C3 不适用"连续三年"**，只取最近一个年度报表
- 判定基准：以最近一个**已出具年度报告**的年度为末年，向前推三年
- 当年年报尚未披露时，不得用中报、季报或未审数替代年报参与判定；可作为趋势提示单列
- 存在**会计政策变更或财务重述**时，采用最新披露的重述后数据，并在报告中说明重述事项及影响

## 四、边界情形处理

| 情形 | 处理方式 |
|---|---|
| 成立不足三年 | C1、C2 判**数据不足**；但 **C3 仍须照常判定**——最近一期净资产为负即直接构成一般负面情况。仅当 C3 也无法判定时，整体才为"无法认定"。报告中说明成立时间与可得年度数，提示历史数据不足属固有风险 |
| 三年中有年度未出年报 / 未审计 | 该年度视为数据缺口，对应红线判定为「数据缺口」，整体结论为「暂不构成（存在数据缺口）」，出具补充资料清单 |
| 事业单位、无标准资产负债率口径 | C2 改按「负债总额 ÷ 资产总额」测算，或在无该口径时标注 C2 不适用；C1 改按「年度收支结余」判断，C3 按「净资产（事业基金）」判断 |
| 政策性亏损主体（公用事业、政策性城投等） | 仍按红线**如实认定命中**，不得因政策属性豁免；可在"例外说明"章节陈述亏损性质、财政补贴与偿债保障，供审批权衡 |
| 集团合并口径与授信主体口径不一致 | 以**授信申请主体**自身报表判定；同时提示集团层面情况，避免母子公司风险穿透遗漏 |
| 重组 / 破产重整后主体 | 重整完成前的历史年度仍计入判定；重整完成后可另附"重整后经营表现"作为补充说明，但不改变红线命中事实 |
| 币种或单位不一致 | 统一折算为人民币同一单位后再判定，折算汇率与来源须标注 |

## 五、常见误判风险

1. **把"三年中有三年亏损"与"连续三年亏损"混淆**——非连续年度亏损不构成 C1
2. **用未审数或管理层报表替代年报数**——数据可靠性不足，易被推翻
3. **恰好 85% 判为命中**——须严格大于才命中
4. **把 C3 也按"连续三年"判**——C3 是当期口径，最近一期为负即构成，误按三年会大量漏筛
5. **C1 只算一个口径就下结论**——两口径平权，只算归母会漏掉合计连亏的主体，反之亦然
6. **成立不足三年就直接判"无法认定"**——C3 不受年数限制，须先单独判 C3
7. **只看归母净利润忽略扣非**——遗漏实质性连亏客户
8. **只看合计净资产忽略归母净资产为负**——遗漏母公司资不抵债情形
9. **对政策性主体主动放宽**——红线判定与审批权衡应分离，判定阶段不做主观豁免
10. **数据缺口下强行结论**——两年数据推断三年属越权判定，C1/C2 必须输出"数据不足"

## 六、判定与决策的边界

本红线判定回答的是「**是否构成一般负面情况**」这一事实性问题，不回答「是否给予授信」。

- 构成 ≠ 一律拒绝：确有业务必要的，走上提审批 + 特别理由说明 + 缓释措施落实路径
- 不构成 ≠ 无风险：仅说明未触发该三条红线，其余风险须由完整授信审查覆盖

任何情况下，本判定结论均为辅助参考，不替代正式审批决策。
