## 一、边界情形案例

### 〔2026-08-11〕万科企业股份有限公司 — 红线校验样本
- **情形**：近五年归母净利润 2021–2023 为正（225.24 / 226.18 / 121.63 亿），
  2024–2025 连续巨亏（−494.78 / −885.56 亿）；资产负债率五年区间 73.22%–79.74%，
  始终低于 85%；净资产未转负。
- **判定**：以 2023–2025 为窗口，C1 仅两年亏损未构成连续三年，C2、C3 均未命中
  → **不构成一般负面情况**。
- **沉淀结论**：巨额亏损与红线命中不划等号。本例说明三条红线是**机械化事实判定**，
  不能替代风险实质判断——万科同期已出现债券展期、境内外评级下调至违约级、
  境内评级终止，实质风险远高于红线所反映。**未命中红线的客户仍须完整授信审查。**
- **衍生提示**：若 2026 年度继续亏损，C1 将于 2026 年报披露后命中，属"预计命中"客户，
  建议对此类主体建立提前预警名单。
- **数据来源**：MCP·预警通（近五年年报）

## 二、口径争议登记

> **三处争议已于 2026-08-11 经业务口径确认并落地，脚本与全部文档同步生效。**
> 本节保留争议原文与确认过程，供后续追溯；未经再次确认不得擅自调整判定逻辑。

### 〔2026-08-11 已确认〕"超过 85%" 的边界取值
- **争议**：恰好 85.00% 是否命中。
- **确认结论**：**「超过」即严格大于**，85.00% 不命中。
- **实现**：`ALR_RED_LINE = 85.0`，判定符维持 `>`；同时新增临界提示——
  任一年度 ALR 与 85% 差异不足 0.5 个百分点时，提醒回原始报表复核小数位
  （避免四舍五入导致 84.996% 与 85.004% 结论翻转）。

### 〔2026-08-11 已确认〕"净资产为负"是否同样要求连续三年
- **争议**：原表述"连续三年年度报表资产负债率超过 85% 或净资产为负"，
  "连续三年"是否同时修饰净资产。
- **确认结论**：**看当期年报**，最近一期净资产为负即构成，**不要求连续三年**。
- **实现**：C3 由三年连续判定改为仅取窗口内最近年度判定，标签同步改为
  「C3 当期年报净资产为负」。连带影响两处：
  1. **C3 不再受"数据不足三年"限制**——成立不足三年的主体，C1/C2 判"数据不足"时
     C3 仍独立判定，可直接构成红线（已加用例覆盖）。
  2. 原"最近年度净资产已为负但未满三年"的预警提示失去意义（现已直接命中），
     替换为反向提示——**当期为正但历史年度曾为负**时，核查转正来源与可持续性。
- **风险提示**：本口径显著**扩大**了 C3 的命中面。当期一次性大额减值、
  商誉暴雷或亏损导致净资产短暂转负的主体将直接构成红线，须在报告中说明成因，
  由审批环节权衡，判定阶段不作主观豁免。

### 〔2026-08-11 已确认〕净利润采用归母还是合计
- **确认结论**：**分别计算，不区分主次**——两口径平权。
- **实现**：C1 拆为 `C1·归母净利润口径` 与 `C1·净利润合计口径` 两个子判定，
  任一口径连亏三年即 C1 命中；扣非仍作实质性连亏辅助提示。配套两条规则：
  1. **两口径结论不一致**（如归母连亏而合计未连亏）→ 仍认定命中，并输出提示：
     差额源于少数股东损益，须核查是否存在通过并表结构调节归母利润的情形。
  2. **仅取得单一口径数据**（财汇MCP 常仅返回归母，属高频情形）→ 凭已有口径出结论，
     但在「信息缺口」章节声明另一口径缺失、待补数复筛，不得默认视为已完整判定。

## 三、脚本实测缺陷与修复记录

### 〔2026-08-11〕「标准无保留」被误判为非标审计意见
- **现象**：审计意见关键词匹配用 `"保留" in op`，导致「标准无保留意见」命中预警。
- **修复**：改为 `is_non_standard_opinion()`，先排除含「无保留」的表述，再分层识别
  否定意见 / 无法表示意见 / 持续经营重大不确定性 / 强调事项段 / 保留意见。
- **教训**：中文财务术语存在「无X」式否定前缀，关键词匹配必须先处理否定语义。

### 〔2026-08-11〕净资产缺失导致 C3 误报数据缺口
- **现象**：仅有资产负债率、无净资产金额时，C3 判为「数据缺口」，整体结论被降级为
  「暂不构成（存在数据缺口）」，实际上资产负债率 76.89% < 100% 已可确定净资产为正。
- **修复**：新增逻辑推定——资产负债率 < 100% ⇔ 资产 > 负债 ⇔ 净资产为正，
  据此完成 C3 正负判定，报表中标注「正（推定）」并输出推定说明。
- **教训**：判定所需的是**正负号**而非绝对金额，能由已有指标逻辑推出的不应报缺口；
  但推定结论必须显式标注，不得冒充实测值。

### 〔2026-08-11〕口径变更后的回归验证
六个用例全部通过，覆盖三处口径变更的边界：

| 用例 | 场景 | 预期 | 实测 |
|---|---|---|---|
| 1 | 万科真实数据（2023 盈利、24/25 亏损，ALR 73%–77%） | 不构成 | ✓ 不构成 |
| 2 | 三年连亏 + ALR 88%/91.3%/96.5% | 构成 C1+C2 | ✓ 一致 |
| 3 | **C3 新口径**：仅当期净资产为负，未连亏、ALR 未连续超标 | 构成（仅 C3） | ✓ 一致 |
| 4 | **C1 双口径**：归母连亏、合计未连亏 | 构成 + 不一致提示 | ✓ 一致 |
| 5 | **C3 不受年数限制**：仅两年数据 + 当期净资产为负 | 构成（C1/C2 数据不足） | ✓ 一致 |
| 6 | **85% 边界**：三年恰好 85.00% | C2 未命中 + 临界提示 | ✓ 一致 |

用例 3 与用例 5 是本次口径变更后**新增的命中路径**——旧逻辑下两者均判"不构成"或
"无法认定"，属于此前会被漏筛的客户类型。

## 四、误判风险清单

- 非连续年度亏损被误判为 C1 命中
- 使用未审数或中报数参与"连续三年"判定
- **C3 仍按连续三年判定**（口径已改为当期，误用旧逻辑会大量漏筛）
- **C1 只算归母或只算合计一个口径就下结论**（两口径平权，须各判一次）
- **成立不足三年即整体判"无法认定"**（C3 不受年数限制，须先单独判 C3）
- 合计净资产为正而归母净资产为负的集团被漏筛
- 账面盈利依赖非经常性损益、扣非连亏的客户被漏筛
- 政策性主体被主观豁免，判定与审批权衡未分离
