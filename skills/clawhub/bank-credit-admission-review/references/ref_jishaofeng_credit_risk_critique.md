## 一、对中国银行业信贷风控的六大批判（P3–P4）

| # | 批判主题 | 核心命题（wb 概括） |
|---|---|---|
| 一 | 对金融科技的迷信 | 把信贷决策简化为"数据进—模型出"的黑箱，忽视社会资本、行业生态、企业家精神等非结构化因素，也忽视经济周期、共债极限、监管政策等**社会建构因素**，导致系统性风险集聚 |
| 二 | 信贷产品简单化 | 追求标准化规模效应而推"一刀切"产品，忽视行业差异与真实资产负债率，**已形成批量不良** |
| 三 | 风险治理滞后 | 对"灰犀牛"反应迟缓；监管与政府导向对风险表现影响重大，但多数智能风控与专家决策系统未做科学调整 |
| 四 | 对"线上+线下"的简单理解 | 线上只是把传统方法搬到线上、线下只是机械填表，两头优势都没拿到 |
| 五 | 行业整体认知缺失 | 忽视信贷技术研究，倾向于僵化复制既有成功模式 |
| 六 | 银行社会角色被重新定义 | 社会性、功能性、安全性共同重塑风控逻辑，须在保持安全性与盈利性前提下实现前两者 |

## 二、信贷风险辩证认识论（P6–P7 / P89）

- **三重属性**：客观确定性、社会建构不确定性、价值负载性
- **五大核心观点**：三重属性不可分割、灰度认知定律、层展性风险原理、社会建构颠覆力法则、价值理性优先
- **范式变革五大特征**：风险本体重构、认知范式升维、方法论革命、价值理性回归、复杂性直面
- **方法论后记要义（P89）**：以动态、系统、辩证视角看待风险，反对机械化的静态评估；主张行业知识、因果推理与数据建模深度融合，通过人机协同实现风险"可解释、可干预、可演化"。

## 三、对传统专家策略法（5C / LAPP）的批判（P82–P84）

三大流派定位：概率派（定量）/ 因果派（定性）/ 不确定派。

5C、LAPP 的**五大局限**：

1. **框架简单**——一级维度有限，二三级维度及权重缺科学安排，易受区域/产业/经济环境变化影响
2. **基础不牢**——未解决数据保真问题，以及数据如何科学转化为各级评价标准
3. **难以落地**——缺乏把专家策略转为全流程执行标准并有效监督分支机构的机制
4. **社会建构变量缺位**——难以适配中国广大区域与经济/文化/产业的个性化特征
5. **人才培养无体系**——缺乏体系化的信贷分析能力培养机制

> **嵇氏判语（P84）**：5C/LAPP 提供了分析维度，但作为一套风控体系是不完整、不精确、难以规模化执行的；中小企业信贷风控的成功依赖总行构建的精细化专家策略框架与配套管理体系，而非某个"神奇模型"。

## 四、【核心·最实用】嵇氏逻辑实证中小企业信贷分析技术——八大主线（P85–P86）

> 原题为《嵇氏逻辑实证中小企业信贷分析技术》，属专家策略法的深度改造版本。设计逻辑：**八大主线决定调查的全面性，逻辑实证决定每条主线的穿透深度与自我验证，主线之间形成更高维的交叉验证关系。**

| 主线 | 调查焦点（wb 概括） | 核心评估目标 |
|---|---|---|
| **一、经营者逻辑** | 品行与意愿、能力与经验、战略与眼光 | 评估企业的"大脑和心脏"，判断发展驱动力与还款意愿根源 |
| **二、资产逻辑** | 真实性（现场盘点与权属核实）、有效性（利用率与周转）、增值性 | 评估"家底"的厚度、真实性与质量，判断抗风险能力与第二还款来源 |
| **三、现金流逻辑** | 盈利性（重建"准利润表"）、运营性、筹资与投资 | 评估"血液"的造血能力与循环效率，判断第一还款来源可靠性 |
| **四、负债逻辑** | 显性负债（全面征信）、隐性负债、或有负债，并对资产做真实性价值评价 | 评估"负重"真实水平，判断财务杠杆安全边际与债务可持续性 |
| **五、生产与供应链逻辑** | 技术工艺与效率、供应链稳定性、客户与销售模式 | 评估"机体"运行效率与健康度，判断商业模式脆弱性与核心竞争力 |
| **六、行业趋势逻辑** | 行业生命周期、政策与监管环境、技术变革与替代风险 | 评估外部环境的方向与冲击力（社会建构因素） |
| **七、发展逻辑** | 投资与扩张、研发与创新、融资需求合理性 | 评估企业未来走向与**本次授信的合理性** |
| **八、信用与履约逻辑** | 税务工商历史合作记录、还款意愿、违约成本 | **最终综合评判** |

## 五、【精髓】八大主线交叉验证关系（P86）

> **核心思想**：当不同主线得出的结论**相互矛盾**时，即为**风险隐藏的信号**，须深入调查至疑点消除。这是本方法论最具操作性的部分。

| 验证类型 | 参与主线 | 验证问句 | 典型风险信号 |
|---|---|---|---|
| **一致性验证** | 现金流 ↔ 负债 | 声称的利润是否足以覆盖利息与债务？ | 利润高却称无力付息；负债率低却总说现金流紧 |
| **真实性验证** | 资产 ↔ 现金流 | 资产规模与其产生的收入利润是否匹配？ | 巨额资产但产出极低；收入高但资产不匹配 |
| **合理性验证** | 发展 ↔ 现金流 | 扩张所需投资额与自身造血能力是否匹配？ | 造血不足却依赖贷款激进扩张 |
| **持续性验证** | 行业趋势 ↔ 发展 | 投资方向是否顺应行业趋势？ | 行业下行期逆势重资产投入；技术路线落后仍加码 |
| **意愿性验证** | 经营者 ↔ 信用履约 | 经营者品行口碑与历史信用记录是否一致？ | 口头承诺强但名下企业有不良记录 |
| **压力测试验证** | 负债 ↔ 行业趋势 | 行业下行时现有负债是否会导致资金链断裂？ | **高负债 + 强周期行业 + 行业已现拐点** |

> **为何要如此复杂校验（P86）**：中国中小企业数据与信息严重失真，不做校验则取数不能成为依据；**随着数据源真实性上升，校验要求可逐步弱化**——此句可直接作为"零数据降级"的依据（数据越差，校验越严）。

## 六、四大客群技术路径主张（P75–P89）

| 客群 | 风控内核 | 专家推演要求 |
|---|---|---|
| 消费信贷 | 客户行为数据挖掘，**以概率模型为核心** | 低 |
| 中小微标准化场景经营贷 | 数据模型 + 行业通用规则，强调**可解释性**以满足监管 | 中低 |
| 中小微**非标准化**经营贷 | **专家经验与主观判断为主**，靠逻辑链与社会建构互动提升适应性 | **最高（风控难度最高）** |
| **大公司信贷** | 财务与经营信息相对标准透明，专家推演要求相对下降；重点转向**政策导向、行业地位、经济发展趋势、国内国际环境**等社会建构因素 | 中（但社会建构要求最高） |

- **微贷（P75–P80）**：基础画像 8 维 + 经营 8 维（含 POS/微信/支付宝流水、水电费单、物流单据等**非财务验证**）；指出常熟农商、台州银行、泰隆银行的微贷模式**普遍复制失败**。
- **中小企业信贷（P81–P86）**：专家策略法为**绝对风控底座**，概率模型用于验证、因果模型用于辅助，充分考量经济/政策/区域/产业等社会建构因素；走"**专家经验 → 专家策略 → 专家模型**"进化路径，通过场景定制与客群定制降低设计复杂度。
- **大公司信贷（P87–P89）**：问题根源是资源驱动/关系驱动；方案包括机器学习整合上下游数据、风险仪表盘动态预警、图计算挖掘关联网络、总行开发分行业专家模板、把社会建构分析设为贷前贷中贷后强制环节；目标是由"资源驱动"转向"风控驱动/知识驱动"。

## 六之补充、【大型企业专用】嵇氏三维平衡体系（P71–P72 + P87–P89）

> **补录说明（2026-09-04）**：初版引用卡把"大公司信贷"压缩为一句话，**丢失了原书专为大型企业设计的四层架构**。经回查原书 P71–P72 补全框架骨架。**这是回答"嵇氏方法论能否用于大型企业"的直接依据。**

### 6B.1 核心边界判语（最关键）

> **大公司信贷不是"大号中小企业贷"**——其风险本质是国家意志、产业规律、资本博弈的**建构性产物**；用中小微那套方法评估航母级企业是不合适的。（P72）

即：**八大主线（中小企业）与三维平衡体系（大公司）是两套并行架构，不可互相套用。**

### 6B.2 四层架构骨架（P71–P72）

| 层级 | 权重 | 定位 |
|---|---|---|
| **一、社会建构主导层** | **40%** | 政策导向、行业地位、营商环境、政商网络；输出《社会建构评估报告》**并作为决策主线** |
| **二、专家因果推演层** | **40%** | 财务深度分析、跨周期韧性、"灰犀牛"预判；**专家持"一票通过权/一票否决权"特权** |
| **三、概率模型验证层** | **20%** | 财务与非财务数据量化、创新指标；核心作用是**验证**与识别"**建构－数据背离**"异常 |
| **四、动态调谐与决策层** | 动态权重 | 按触发条件实时调权重；**最终决策 = 三层加权整合**，审贷会合议裁决 |

> 各层的**具体监测指标、实施工具与权重调整示例请回原书 P71–P72 表核对**；本卡不复现该表细节。

> **权重表述提示**：原书 P71 表列"概率模型验证层 20%"，P87 处提"30%"，属作者自述"框架仍在优化中"的内部差异——**引用时取区间 20%–30% 并注明**。

### 6B.3 适用边界与分流规则（P72）

- **适用对象**：管理规范的大型集团、上市公司、行业影响力大的企业。
- **分流规则（重要）**：国内大公司数据环境、治理水平、经营规模差异很大，须把**一部分「数据不可靠 + 不具备行业影响力 + 规模相对较小」的"大公司"划入类似中小企业的非标准经营贷范围**管理——即**改用八大主线 + 强交叉验证**。
- **原则声明（P72）**：三大要素的权重设计是主干，具体方法工具是枝叶。

### 6B.4 大公司信贷现有体系的"三维缺失"批判（P87–P88）

| 缺失维度 | 现状 | 后果 |
|---|---|---|
| **量化智能模型维度**（应占 20%–30%） | 近乎空白，模型多为简单统计与监控，缺预测性与动态调整能力 | 难以从海量数据识别细微风险信号 |
| **社会建构维度** | 分析薄弱且非强制，依赖个人经验 | 行业狂热期难抵业务压力集体涌入，形成"**合成谬误**" |
| **专家因果推演维度** | 多停留于明面财报与单一企业报表判读，缺可靠专家策略法 | 标准财报齐备仍出现大量大型企业信贷损失（技术性原因） |

### 6B.5 落地路径要点（P88–P89）

1. **量化模型**：整合供应链、舆情、专利、ESG 数据，建企业健康度综合评分模型
2. **动态预警**：建风险仪表盘，实时监控关键指标异常并自动推送
3. **关系挖掘**：用图计算绘制企业—股东—担保方关联网络，识别关联交易与担保圈风险
4. **专家权重上浮**：企业面临重大战略决策（如并购）时提升专家推演权重
5. **总行职责**：开发分行业专家分析模板；把社会建构分析设为贷前贷中贷后强制环节
6. **终极目标**：由"资源驱动/关系驱动"转为"风控驱动/知识驱动"——看得更远、做得更稳、管得更精，实现"穿越周期"
