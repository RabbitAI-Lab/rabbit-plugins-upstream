## 一、对中国银行业信贷风控的六大批判（P3–P4）

| # | 批判要点 | 原文要点 |
|---|---|---|
| 一 | **对金融科技的迷信与系统性风险** | 过度依赖智能风控模型，把信贷决策简化为"数据输入—模型输出"黑箱，忽视社会资本、行业生态、企业家精神等非结构化因素；部分机构忽视经济周期、共债极限、监管政策、社会约束等**社会建构因素**，使系统性风险迅速集聚 |
| 二 | **信贷产品的"简单化"与结构性错配** | 为追求标准化和规模效应推出"一刀切"产品（纯税务贷、流水贷），忽视行业差异、经营模式、管理能力、真实资产负债率等核心变量，**已形成批量不良** |
| 三 | **风险治理滞后性与监管适应性不足** | 对"灰犀牛"事件（行业周期、政策调整）反应迟缓；政府/监管导向对客户信贷风险表现产生重大影响，但多数智能风控与专家决策系统未做科学调整——"**要么过分保守，要么过分纵容，要么置之不理**" |
| 四 | **简单理解"线上+线下"** | 线上可能只是传统方法线上化，线下可能是机械化填表；不严谨的组合**既失去纯线上量化风控的完整性，又失去线下专家经验的缜密性** |
| 五 | **整个银行业缺乏对信贷风险体系的认知** | 忽视信贷技术研究与应用，注意力集中在成功模式的僵化复制上，"**幻想只依靠管理模式的改变就能在信贷业绩上得到迅速提升**" |
| 六 | **银行业社会角色被重新定义但认知不足** | 社会性、功能性和安全性重塑了风控逻辑，银行必须考虑**在实现社会性、功能性的同时保持安全性和盈利性** |

## 二、信贷风险辩证认识论（P6–P7）

**三重属性**（3.2）：① 客观确定性 ② 社会建构不确定性 ③ 价值负载性

**五大核心观点**（3.5）：三重属性不可分割 / **灰度认知定律** / **层展性风险原理** / **社会建构颠覆力法则** / **价值理性优先**

**范式变革五大特征**（3.6）：风险本体的重构 / 认知范式的升维 / 方法论的革命 / 价值理性的回归 / 复杂性的直面

**方法论后记要义**（P89）：以动态、系统、辩证视角看待风险，**反对机械化的静态评估**；打破传统风控中"**因果孤立**"与"**数据依赖**"的局限；主张行业知识、因果推理与数据建模深度融合，通过人机协同实现风险可解释、可干预、可演化；最终路径是"**算法发现风险根源、人类设计调控策略**"。

## 三、对传统专家策略法（5C / LAPP）的批判（P82–P83）

三大流派定位：**概率派（定量派）/ 因果派（定性派）/ 不确定派**。

对 5C、LAPP 的**五大局限**：
1. **框架简单**：一级维度有限（5C 五个、LAPP 四个），不足以完整分析企业风险；二三级维度及权重无科学制度安排，区域/产业/经济环境变化会影响评价结果
2. **基础不牢**：**未解决数据保真问题**，以及数据信息如何科学转化为各级维度评价标准
3. **难以落地**：缺乏把专家策略转化为全流程执行标准、并有效监督分支机构的机制
4. **社会建构变量缺位**：难以适配中国广大区域、不同经济/文化/产业的个性化特征
5. **人才培养无体系**：缺乏体系化的信贷人员分析能力培养

> **嵇氏判语**：5C/LAPP 提供了分析维度，但**作为一套风控体系是不完整、不精确、难以规模化执行的**；中小企业信贷风控的成功"**不依赖于某个神奇模型，而依赖于银行总行构建的精细化专家策略框架 + 强大的配套管理体系**"（P84）

## 四、【核心·最实用】嵇氏逻辑实证中小企业信贷分析技术——八大主线框架（P85–P86）

> 原名为《嵇氏逻辑实证中小企业信贷分析技术》，是专家策略法的深度改造版本。**八大主线决定调查的全面性，逻辑实证决定每条主线的完整穿透与自我验证，主线之间形成更高维的交叉验证关系。**

| 主线 | 核心调查与分析线索（实证安排） | 核心评估目标 |
|---|---|---|
| **一、经营者逻辑** | 1. 品行与意愿：历史信用记录、法院执行信息、同业口碑、家庭稳定性、对事业专注度<br>2. 能力与经验：行业从业年限、重大决策成败案例、市场趋势判断力、管理团队能力互补性<br>3. 战略与眼光：是否有清晰 3～5 年规划？如何应对当前行业主要挑战？ | 评估企业的"**大脑和心脏**"，判断发展首要驱动力与还款意愿根源 → **经营现状的合理性** |
| **二、资产逻辑** | 1. 资产真实性：核心资产（设备、房产、存货）现场盘点与权属核实（购买合同、发票）<br>2. 资产有效性：设备利用率、厂房空置率、存货周转率（无效资产就是负担）<br>3. 资产增值性：技术设备先进性、土地区位价值、知识产权潜在价值 | 评估企业"**家底**"的厚度、真实性与质量，判断抗风险能力与第二还款来源 → **资产积累的合理性** |
| **三、现金流逻辑** | 1. 盈利性现金流：**重建"准利润表"**，核实主营收入真实性（核对银行流水、主要合同）与成本结构合理性（核对主要供应商、水电费支出）<br>2. 运营性现金流：应收账款账龄与集中度、预付账款合理性、应付账款谈判能力<br>3. 筹资与投资现金流：历史投资来源与回报、现有融资渠道与成本 | 评估企业"**血液**"的造血能力（盈利）与循环效率（运营），判断第一还款来源可靠性 → **现金流的合理性验证** |
| **四、负债逻辑** | 1. 显性负债：全面征信查询，核实银行借款、民间借贷、上下游应付款的总额/期限/成本<br>2. 隐性负债：挖掘不计入报表的借款、对外担保、民间融资成本、股东往来款<br>3. 或有负债：对外担保、未决诉讼、环保等行政处罚风险<br>4. 对资产进行真实性价值评价 | 评估企业"**负重**"的真实水平，判断财务杠杆安全边际与债务可持续性 → **负债的合理性及融资的逻辑** |
| **五、生产与供应链逻辑** | 1. 技术工艺与效率：生产流程、技术来源、良品率、能耗水平，与行业标杆对比<br>2. 供应链稳定性：主要供应商依赖度、原材料价格波动风险、采购结算方式<br>3. 客户与销售模式：主要客户依赖度、产品定价能力、销售回款模式、市场竞争力 | 评估企业"**机体**"的运行效率与健康度，判断商业模式脆弱性与核心竞争力 |
| **六、行业趋势逻辑** | 1. 行业生命周期：朝阳/成熟/衰退<br>2. 政策与监管环境：国家产业政策、环保、税收等法规影响<br>3. 技术变革与替代风险：是否面临技术路线颠覆 | 评估外部环境的方向与冲击力（社会建构因素） |
| **七、发展逻辑** | 1. 投资与扩张：过往重大投资项目成败分析、当前扩张计划<br>2. 研发与创新：研发投入强度、新产品储备、技术路线<br>3. 融资需求合理性：本次贷款需求是否与切实的发展计划匹配 | 评估企业未来走向与**本次授信的合理性** |
| **八、信用与履约逻辑** | 1. 税务、工商的历史合作记录<br>2. 还款意愿评估：综合主线一（经营者）与主线七（发展）判断主动履约意愿<br>3. 违约成本评估：综合主线二（资产）、主线六（行业）评估违约的声誉/社会/商业代价 | **最终的综合评判** |

## 五、【精髓】八大主线交叉验证关系表（P86）

> **该表精髓**：当从不同主线得到的结论**相互矛盾**时，就是**风险隐藏的信号**，必须深入调查直至疑点消除。

| 验证类型 | 主线 A | 主线 B | 交叉验证点 | 风险信号 |
|---|---|---|---|---|
| **一致性验证** | 现金流（三） | 负债（四） | 企业声称的利润是否足以覆盖利息和债务？ | 利润很高但声称无力付息；或负债率很低却一直声称现金流紧张 |
| **真实性验证** | 资产（二） | 现金流（三） | 报表资产规模与其产生的收入和利润是否匹配？ | 巨额资产但产出效益极低（"大马拉小车"）；或收入很高但资产规模不匹配（可能虚增收入） |
| **合理性验证** | 发展（七） | 现金流（三） | 扩张计划所需投资额是否与其自身现金流生成能力匹配？ | 自身造血能力严重不足，却依赖贷款激进扩张 |
| **持续性验证** | 行业趋势（六） | 发展（七） | 发展战略和投资方向是否顺应行业发展趋势？ | 行业下行期逆势重资产投入；技术路线明显落后仍坚持投入 |
| **意愿性验证** | 经营者（一） | 信用履约（八） | 经营者品行和历史口碑是否与其历史信用记录一致？ | 经营者夸夸其谈但名下企业有不良信用记录 |
| **压力测试验证** | 负债（四） | 行业趋势（六） | 若行业下行，现有负债水平是否会导致资金链断裂？ | **高负债经营于强周期行业，且行业已现拐点迹象** |

> **为何要如此复杂校验**：中国中小企业数据、信息严重失真，不做校验则信贷人员取数不能成为依据。随着数据源真实性上升，校验要求可逐步弱化（P86）。

## 六、对不同客群的技术路径主张（P75–P89）

- **微型企业经营贷（微贷，P75–P80）**：基础画像 8 维（年龄/户籍/婚姻/教育/健康、家庭结构、社会声誉、行业经验、经营能力、还款意愿、社会资本、关联人）+ 经营 8 维（经营基本面、产品与服务、采购环节、销售环节、库存生产、行业趋势、竞争格局、**非财务验证**：POS/微信/支付宝流水、水电费单、物流单据）。指出常熟农商、台州银行、泰隆银行的微贷模式**普遍复制失败**。
- **中小企业信贷（P81–P86）**：**专家策略法为绝对风控底座**，结合概率模型（验证）、因果模型（辅助），充分考量经济、政策、区域、产业等社会建构因素，构成辩证、动态的信贷分析框架。走"**专家经验 → 专家策略 → 专家模型**"进化路径，同时清醒认识 AI 局限；通过**场景定制和客群定制**降低策略与模型设计复杂度。
- **大公司信贷（P87–P89）**：问题=资源驱动/关系驱动；方案=引入机器学习整合上下游数据、建立风险仪表盘动态预警、图计算挖掘关联网络、总行开发分行业专家分析模板、**把社会建构分析设为贷前贷中贷后强制性环节**、建立动态权重调节机制；目标是从"**资源驱动**"转向"**风控驱动/知识驱动**"，做到"看得更远、做得更稳、管得更精"。

4. "**中小企业信贷风控的成功，不依赖于某个'神奇模型'，而依赖于银行总行构建的'精细化专家策略框架 + 强大的配套管理体系'。**"（P84）
5. "**当从不同主线得到的结论相互矛盾时，就是风险隐藏的信号，必须深入调查直至疑点消除。**"（P86）
6. "**高负债经营于强周期行业，且行业已现拐点迹象。**"（P86，压力测试风险信号）
7. "**晴天送伞，雨天收伞。**"（P89，批评大公司业务盲从）
8. "**算法发现风险根源、人类设计调控策略。**"（P89，后记）

## 八、与 bank-credit-admission-review 的结合方式

| 现有 skill 环节 | 嵇氏框架补强 |
|---|---|
| 6C 模型 / 8 维度加权评分卡 | 用**八大主线**替代或并行 6C 做定性穿透（尤其主线三现金流"重建准利润表"、主线四隐性负债挖掘） |
| 财务定量分析 | 补"**非财务验证**"（POS/微信/支付宝流水、水电费单、物流单据）与"**重建准利润表**"思路 |
| 行业对标（门当户对） | 补主线六"行业趋势逻辑"与**社会建构因素**（政策/监管/区域/产业） |
| 风险交叉校验 | 直接引入**八大主线交叉验证关系表**（6 类验证 + 风险信号）作为报告必备校验环节 |
| 零数据降级 | 可引用"**随着数据源真实性上升，校验要求可逐步弱化**"（P86）作为降级依据；反之数据越差校验越严 |
| 授信方案设计 | 补主线七"**融资需求合理性**"——本次贷款需求是否与切实发展计划匹配 |
