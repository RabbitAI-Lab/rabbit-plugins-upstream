# 风险评级矩阵与评分卡

## 一、评分卡（通用，权重可按行业在 rules_library 中调整）
| 维度 | 权重 | 评分 1-5（5 最优） | 关键依据 |
|---|---|---|---|
| 经营情况 | 25% | | 景气度 / 地位 / 主业 / 上下游 |
| 财务情况 | 35% | | 偿债 / 盈利 / 现金流 / 或有 / 真实性 |
| 管理层与股权 | 20% | | 实控 / 股权 / 管理层 / 涉诉 / 担保圈 |
| 外部风险 | 20% | | 政策 / 征信 / 司法 / 舆情 |

综合得分 = Σ(维度得分 × 权重)，满分 5 分。

## 二、等级映射
| 综合得分 | 风险等级 | 准入建议 |
|---|---|---|
| ≥4.5 | 低风险 | 准入 |
| 3.8–4.49 | 中低 | 准入（常规条件） |
| 3.0–3.79 | 中 | 有条件准入 |
| 2.0–2.99 | 中高 | 有条件准入（强约束）或审慎 |
| <2.0 | 高风险 | 不予准入 |

## 三、一票否决（直接"不予准入"或"有条件准入-强约束"）
出现以下任一，综合等级不得高于"中高"，且须专项说明：
- 公开市场债券违约 / 展期未解决；
- 被列入失信被执行人且未履行；
- 核心资产被查封 / 实控人限高且影响偿债能力；
- 财务存在重大真实性疑点（如审计否定意见 / 无法表示意见）；
- 行业属监管明确禁止授信类。

## 四、评级纪律
- 任一维度信息缺口 >50%，该维度最高给 3 分（中性），并标注缺口。
- 外部来源仅为网络传闻且无法交叉验证的结论，不得作为定级主依据。
- 定级须有证据链；"不予准入"须列足至少 3 条硬性理由。
