# 授信准入审查检查清单（种子版，逐步补全）

> 每次审查前通读；复盘新增项追加于"待补充"区并定期合并。

## A. 资料完整性
- [ ] 近 3 年财报（含审计意见）
- [ ] 征信报告（企业 + 实控人）
- [ ] 工商信息（股权 / 出质 / 冻结）
- [ ] 评级报告（如有）
- [ ] 拟授信方案（品种 / 金额 / 期限 / 担保）
- [ ] 重大诉讼 / 被执行查询
- [ ] 舆情扫描

## B. 四维必查项（对照 analysis_framework.md）
- [ ] 经营：行业周期、市占率、客户集中度
- [ ] 财务：现金短债比、利息保障倍数、经营现金流 / 净利润、对外担保
- [ ] 股权：实控人资信、股权质押 / 冻结、高管变动
- [ ] 外部：征信逾期、司法被执行、评级下调、负面舆情

## C. 一票否决速查

### C0. 行内「一般负面情况」红线（第 0 步前置必查）
> 执行方式：先读 `references/negative_criteria.md` 校准口径，再跑本 Skill 的
> `scripts/negative_screen.py` 做确定性判定，禁止人工心算。
- [ ] C1 过去连续三年亏损？**归母、合计两口径分别各判一次**，任一口径连亏三年即命中
- [ ] C1 两口径结论不一致？→ 仍认定命中，并核查少数股东损益是否被用于调节归母利润
- [ ] C1 仅取得单一口径数据？→ 在信息缺口章节声明另一口径缺失、待补数复筛
- [ ] C2 连续三年年度报表资产负债率 **> 85%**？（严格大于，恰好 85.00% 不命中但须列临界提示）
- [ ] C3 **最近一期年报**净资产为负？（当期口径，**不要求连续三年**）
- [ ] C3 当期为正但历史年度曾为负？→ 核查转正来源（增资 / 债转股 / 资产重估）及可持续性
- [ ] 上述任一命中 → 认定构成一般负面情况，原则上不予准入；如继续须上提审批 + 特别理由 + 缓释措施
- [ ] 扣非净利润连续三年为负（账面盈利依赖非经常性损益）→ 实质性连亏提示
- [ ] 数据不足三年 → C1/C2 输出"数据不足"，但 **C3 仍须单独判定**，不得直接整体判"无法认定"

### C1. 其他一票否决项
- [ ] 债券违约 / 展期未决？
- [ ] 失信被执行人未履？
- [ ] 核心资产查封 / 实控人限高？
- [ ] 审计否定 / 无法表示意见？
- [ ] 监管禁止授信类？
