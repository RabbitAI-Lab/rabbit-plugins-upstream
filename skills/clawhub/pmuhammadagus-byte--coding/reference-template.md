# Coding Convention Reference Template

This is a template for a user-owned reference file. The user fills it with their own coding conventions. The agent reads it only when the user explicitly asks.

Example structure:

```
# My Coding Conventions
- Indentation: 2 spaces
- Naming: snake_case for files
- Tests: colocated with source
- Comments: minimal
```

The agent does not create or edit this file. It only reads what the user provides.
