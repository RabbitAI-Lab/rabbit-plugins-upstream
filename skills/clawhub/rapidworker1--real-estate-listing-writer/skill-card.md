## Description:

Writes MLS-ready listing descriptions from the seller's fact sheet, with the fair housing and accuracy limits the copy has to clear before it ships.

This skill is ready for commercial/non-commercial use.

## Publisher:

[rapidworker1](https://clawhub.ai/user/rapidworker1)

### License/Terms of Use:

MIT-0

## Use Case:

For U.S. listing agents, team leaders, and brokerages to prepare buyer-first property listing outlines from seller-provided facts, track unverified claims, and review fair-housing and MLS wording before publication.

### Deployment Geography for Use:

United States

## Known Risks and Mitigations:

Risk: A preliminary outline may contain inaccurate or misleading facts or wording if treated as finished listing copy.

Mitigation: Independently verify facts and wording against source documents and applicable fair-housing and MLS requirements before publication.

Risk: Running the helper again overwrites outline.md in the selected output folder.

Mitigation: Use a dedicated output folder and preserve any drafts you need.

Risk: The optional Windows app is unnecessary for this workflow and requires a separate security review.

Mitigation: Use the bundled Python workflow instead, or review the optional app separately before downloading or running it.
