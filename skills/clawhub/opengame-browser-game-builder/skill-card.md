## Description: <br>
Design and build small, original, playable browser-game prototypes for 2D Canvas, DOM, WebGL, or Three.js experiences. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[opengameapp](https://clawhub.ai/user/opengameapp) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, designers, and game makers use this skill to scope, build, improve, and verify focused browser-game prototypes with playable loops, controls, feedback, and clear handoff notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated game code or suggested dependency commands may behave differently in the target project or introduce unwanted dependencies. <br>
Mitigation: Review generated code and commands before running them, then test the playable loop, browser console, resize behavior, and promised input modes. <br>
