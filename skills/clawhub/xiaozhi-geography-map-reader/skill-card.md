## Description:

帮助初中和高中学生按图名、图例、比例尺、方向与关键数据读懂地图和地理图表，并分析地理错因。

This skill is ready for commercial/non-commercial use.

## Publisher:

[qizhitang](https://clawhub.ai/user/qizhitang)

### License/Terms of Use:

MIT-0

## Use Case:

面向初中和高中学生，帮助他们读懂当前题目中的地图与地理图表，并按具体证据定位读图、计算或表达方面的错因。

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Learning records, cross-skill sharing and reminders can expose student information if enabled without informed consent.

Mitigation: Keep these features off by default; enable each only when wanted and with the required student or guardian consent.

Risk: The supplied files do not establish how the platform or companion skills enforce storage and consent controls.

Mitigation: Before enabling memory, sharing or reminders, confirm that the platform and connected skills apply the stated consent controls.

Risk: Asking for a student's home address or live location would expose unnecessary personal information.

Mitigation: Use textbook locations or public landmarks for map exercises; do not request a home address or live location.
