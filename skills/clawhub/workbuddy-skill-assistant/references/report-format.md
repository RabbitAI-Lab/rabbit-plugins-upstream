# 报告格式模板（reports/YYYY-MM-DD.md）

> 本文件从 `SKILL.md` 的「报告格式」段下沉而来，作为报告的单一事实源模板。
> 由 `scripts/report_builder.py` 渲染；agent 审阅后发布。
> 修改报告样式请改这里，不要在 `SKILL.md` 内联维护（保持主文件"纯路由器"）。

## 固定包含字段

时间 / 模式 / 推送状态 / 版本自检 / 用户阶段 / 环境健康分 / **最佳实践达标明细** / 建议动作（≤3）/ 上轮采纳情况 / 待确认项 / 采纳闭环战绩 / 健康分趋势 / 下一步。

## 模板示例

```markdown
# WorkBuddy skill 使用管理指南 · 建议报告（主动态）
- 时间：YYYY-MM-DD HH:MM
- 模式：每日检查
- 推送状态：已推送(<通道>) / 未推送(<原因>) / 未开启
- 版本自检：运行副本 vX = 发布 vY ✓ / 不一致 ⚠️
- 用户阶段：新用户 / 进阶用户
- 环境健康分：88/100
- 最佳实践达标：8/12 项（上轮 7/12 → 8/12 ↑）
- 发现：
  1. [P1] qq-mail 连接器 disconnected → 建议重连（交互态确认后执行）
  2. [P2] 近 7 天未使用自动化 → 可建"每日晨报"自动化
- 最佳实践达标明细：
  | 领域 | 检查项 | 状态 |
  |------|--------|------|
  | 记忆 | 记忆画像完整 | ✅ 达标 |
  | skill | skill 精简 | ❌ 未达标（23 个全开） |
  | ... | ... | ... |
- 上轮采纳情况：采纳 a1 / 搁置 a2
- 战绩：本轮第 24 次检查 · 累计发现 8 项 · 已修复 5 项 · 连续 3 天
- 待确认项（pending_actions）：a1, a2
- 下一步：打开对话说"看看建议"确认执行
```

> 推送失败横幅（仅 `push_status="failed"` 时出现，置于报告顶部）：
> `⚠️ 本次推送未送达（原因：<reason>），完整报告已存本文件，建议检查 agent-mail/企微连接器或下轮自动重试。`
