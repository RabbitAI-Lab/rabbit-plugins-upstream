# WorkBuddy skill 使用管理指南 · 3分钟快速上手

> 这份速览就是为你写的——3 分钟让你**会用、会养** skill，不怕踩坑。下面从"我能帮你做什么"到"skill 到底怎么用"一步步来，跟着做就行～

---

## 我能帮你做什么

一个自动关注你 WorkBuddy 使用状态的"使用顾问"：
- **主动扫描**系统配置（连接器/自动化/Skill/记忆/日志/模型），发现问题给分级修复建议
- **判定你的阶段（三级）**——初级先带你完成初始化引导打地基；进阶直接给效率建议与达标检查（核心服务）；高级获得全量 12 条核心检查
- **主动达标检查**——把最佳实践收敛成 12 条分级 checklist 逐条判达标，未达标就给出可执行改进动作（调 skill / 装 skill / 修配置），而非停在建议
- **记采纳闭环**——把"建议→改善"记成可见战绩，进步看得见

## 我能做什么 / 我不做什么（先看这个）

| ✅ 我会做 | ❌ 我不做 |
|-----------|----------|
| 扫描系统、判定阶段、给出分级建议（P0/P1/P2） | **不擅自修改**你的配置、文件、自动化 |
| 定期主动扫描，有问题才提醒，没事不打扰 | 不刷屏、不重复打扰 |
| 把待办项排队等你确认 | 不绕过你直接执行 |
| 你确认后，才执行：写记忆、装 skill、重连连接器等 | 不碰你个人文件以外的任何东西 |

> 一句话总结：**我只给建议和方案，动手前一定先问你。** 所有自动化任务都在你的本机沙箱内运行，安全合规。

## 用起来只有一条路

不用记"该说哪个关键词"。你只要打开对话说"**使用助理**"，我就会：

1. **扫描系统** → 自动判断你是初级、进阶还是高级用户
2. 初级 → 先带你做**初始化引导**（2 分钟让 AI 记住你是谁），再给检查建议
3. 进阶 → 直接给**系统检查 + 效率建议 + 达标检查**（L1+L2 核心项，逐条判达标，未达标给改进动作）
4. 高级 → 同上，但达标检查为**全量 12 条核心项**
5. 你有任何问题，直接问 → 我**优先从最佳实践知识库**里找答案，找不到再查通用知识

## 🧩 skill 到底怎么用（安装 → 使用 → 维护，附可视化）

这是本 skill 的核心招牌功能——不止"帮你管 skill"，更要让你**自己会用、会养** skill。完整图文指引（含一张可交互的「Skill 生命周期图」）在 **[`skill-usage-guide.md`](skill-usage-guide.md)**，命中"怎么用 skill / skill 速览"时我会直接打开它并渲染那张图。

三句话先给你个底：
- **安装**：SkillHub 托管的 4 个核心技能（`skill-map` / `skill-check-pro` / `skll-auto-upgrade` / `high-quality-skill-guidance`）→ 直接复制安装 prompt 执行，**别走市场搜索**（必 0 结果）；其他技能走 `find-skills`。
- **使用**：`@技能名` 或自然语言说"推荐 skill""效率诊断"即可触发。
- **维护**：`skillhub upgrade --check-only` 一次批量查升级，或装 `skll-auto-upgrade` 收口自动维护链。

> 想连好"让 AI 替你取数"的连接器？看 [`config-templates/connector-quick-ref.md`](config-templates/connector-quick-ref.md) 的「新手上路」节（3 分钟配好第一个连接器，含授权流程可视化）。

## 四个模块，一眼看懂（不用记细节）

| 模块 | 干什么 | 谁需要 |
|------|--------|--------|
| **① 系统扫描及效率提升** | 判定你的阶段 + 系统检查 + 效率建议 | 所有人（地基） |
| **② 最佳实践达标检查** | 12 条核心 checklist 逐条判达标 | 进阶 / 高级 |
| **③ skill 生态管理** | 查看 / 检查 / 升级 / 精选推荐 skill | 进阶 / 高级（重点） |
| **④ 采纳闭环 + 自我迭代** | 记录采纳、越用越准 | 所有人 |

> 关系：① 打底 → ② 审计 → ③ 精选 → ④ 进化。初级用户只走 ①，升级后逐步解锁 ②③④。

## 第一次使用建议（2 步）

1. **说"使用助理"** → 我会自动扫描并判定你的阶段，带你走完初始化引导（让 AI 记住你是谁）
2. **说"启用主动监护"** → 一键建好"每日主动检查"自动化，让顾问真正主动跑起来

> 之后就不用管了——每天 11:00 自动检查，有问题才提醒你。
