# profile-theme-map · 用户画像 → 主题倾斜映射

> 积木哲学落地：**主题 skill 是小积木，用户适配是搭小积木组合（大积木）。**
> 本文件只做「岗位/兴趣 → 主题集合」的轻量映射，不再写任何 skill 条目。
> 新增岗位 = 加一行；新增主题 = 加一个文件；两者互不牵连。

## 推荐输出公式

```
用户技能组合（大积木）= 通用核心（core.md · 人人必备）
                        + 倾斜主题（下方映射命中主题 · 每主题取 top N 未装项）
```

## 映射表（岗位 / 兴趣 → 主题倾斜）

| 岗位 / 兴趣 | 倾斜主题（小积木组合） |
|---|---|
| 设计岗 | 可视化, HTML前端, PPT演示 |
| 投资 / 金融岗 | 投资分析, 财务管理, 文档管理 |
| 前端 / 开发岗 | HTML前端, 可视化, 文档管理 |
| 内容 / 运营岗 | 可视化, 文档管理, PPT演示 |
| 知识 / 研究岗 | 知识管理, 文档管理, 投资分析 |
| 通用默认 | 文档管理, PPT演示 |

## 使用方式（模块 ③-4）

1. 读 `USER.md` 画像 → 匹配上表最贴近的岗位/兴趣标签（可多选）。
2. 取命中主题的 `themes/<theme>.md`，与已装做差集，只推缺失积木。
3. 每主题内按 `usability` → `composable` 排序，取 top N（默认 3）入队 `install_skill`。
4. 人工管理员可直接增删上表映射或调整主题文件，无需改任何 skill 条目。

## 扩展

- 新增主题：在 `themes/` 下建 `<theme>.md`（≤10 条），在本表加引用即可。
- 新增岗位：在上表加一行映射，不动任何主题文件。
