## Description: <br>
Deprecated Auth0 React guidance that directs users to install the consolidated `auth0` skill for React SPA login, logout, protected routes, and user-session work. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and external users encounter this retired skill when working on Auth0 authentication in React SPAs. Its only current use is to redirect them to the maintained consolidated `auth0` skill before making authentication changes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Users may follow a retired skill and miss updates in the maintained Auth0 guidance. <br>
Mitigation: Install and use the consolidated `auth0` skill before making Auth0 authentication changes. <br>
Risk: Auth0 work can involve credentials, authentication settings, and user-session behavior. <br>
Mitigation: Review the replacement skill separately and verify any authentication configuration before applying changes. <br>
