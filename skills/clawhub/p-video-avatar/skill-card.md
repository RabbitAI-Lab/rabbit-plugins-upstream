## Description:

Use when someone wants a person on camera speaking a script — lip-synced host, spokesperson, or narrated avatar from a portrait photo.

This skill is ready for commercial/non-commercial use.

## Use Case:

Creators and developers use this skill to plan and generate a single lip-synced talking-head video from a portrait and an approved script or narration audio using Pruna.

## Known Risks and Mitigations:

Risk: Automatic installation of unpinned prerequisite skills may run unreviewed third-party instructions.

Mitigation: Review the skill source and pin or verify prerequisite versions before approving installation; do not automatically run install commands.

Risk: Portraits, narration, scripts, prompts, and an API credential are sent to Pruna during generation.

Mitigation: Obtain permission for the person's likeness and submitted content, avoid sensitive inputs, and protect the API credential.
