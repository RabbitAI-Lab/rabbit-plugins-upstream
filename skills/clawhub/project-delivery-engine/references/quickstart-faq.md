# 5 分钟上手、常见问题与错误翻译

本文件只在第一次使用、用户询问具体用法或 `project-gov`（项目治理工具）报错时读取。正常接续项目不需要反复读取。

## 一个完整例子

假设用户要做一项持续一个月的行业调研，资料会不断增加，也会换窗口和调用多个 AI。

1. 用户说：**“帮我把这个项目立起来，以后换窗口也要能接着做。”**
   - AI 检查当前文件夹，只补齐缺少的五件套和三个索引，记录当前目标、下一步、风险和交接入口。
2. 几天后用户说：**“接着上次继续。”**
   - AI 先读取当前快照，再沿索引按需查历史和材料，不要求用户重新解释整个项目。
3. 工作量变大时用户说：**“一个 AI 忙不过来，多找几个一起做。”**
   - 主线程划分任务范围、验收条件和停止条件；子智能体带证据回来，主线程统一采纳。
4. 阶段成果完成后用户说：**“找另一个 AI 独立检查一遍。”**
   - 独立复审者不继承主线程结论，只依据任务、成果、验收条件和证据挑错。
5. 用户准备换窗口时说：**“整理交接文件，我要换个窗口。”**
   - AI 对账当前状态、下一步和未决事项，验证通过后留下可直接接续的入口。

用户不需要记住文件名或命令。只要说清楚要立项、接续、整理、并行、复审或交接即可。

## 什么时候会触发

| 用户说的话 | 是否使用本 Skill | 原因 |
| --- | --- | --- |
| “看看这个项目现在做到哪了” | 是 | 依赖当前项目状态 |
| “接着昨天的继续做” | 是 | 需要跨会话接续 |
| “把这个项目的资料整理好” | 是 | 需要文件分层和索引 |
| “解释一下这段代码” | 否 | 普通临时任务 |
| “并行查三个网页，用完就结束” | 否 | 不依赖长期项目状态 |
| “帮我改一句话” | 否 | 一次性轻任务 |

## 常见问题

### 必须输入 Skill 名称吗？

不必。任务明显依赖长期项目状态时可以自动触发；手动选中本 Skill 更稳妥。

### 它会替代 Git（源码版本管理）吗？

不会。它管理项目状态、文件入口、协作和交接；Git 继续管理源码版本。

### 已经做了很久的旧项目还能用吗？

可以。先运行 `migrate-check（迁移检查）`，缺什么补什么，坏什么修什么，不覆盖仍然有效的项目内容。

### 它会每次读取全部历史吗？

不会。默认只读取当前快照和必要索引，历史、证据和物料按当前任务需要再展开。

### 它会创建很多空目录吗？

不会。新项目只创建必要入口；没有实际文件需要存放时，不预建完整空目录树。

### AI 说“完成了”就算完成吗？

不算。主线程必须核对成果和证据；重要结果可以再交给独立上下文复审。

## 出错时怎么处理

看到错误时先停止当前写入，不要绕过 `propose → apply（预演→执行）`。下面是常见提示的人话解释：

| 提示关键词 | 它在说什么 | 怎么处理 |
| --- | --- | --- |
| `missing_five_piece_file` / `missing_index_file` | 项目入口或索引缺失 | 先运行迁移检查，再只补缺少的文件 |
| `unresolved_references` | 文件里引用了找不到的编号 | 核对对应索引和引用，不要随手删除记录 |
| `template_placeholder_found` | 模板占位文字还没换成真实内容 | 填入真实状态后重新验证 |
| `handoff_last_semantic_checkpoint_invalid` / `handoff_change_status_missing_or_invalid` | 交接检查点的时间或核对状态格式不正确 | 按交接模板修正两项声明 |
| `five_piece_over_45kb` | 当前入口文件过大 | 把详细过程放入历史或证据层，并保留索引 |
| `before_hash_missing` | 编译计划缺少目标文件的写前指纹 | 放弃旧计划，重新运行 `propose（预演）` |
| `Hash precondition failed` | 预演后目标文件真的发生了变化 | 先核对新内容，再重新运行 `propose（预演）` |
| `Compiled plan version incompatible` | 预演计划来自旧版或不同版本的 Skill | 放弃旧计划，用当前版本重新运行 `propose（预演）` |
| `path_not_allowed` | 写入位置不属于治理范围 | 停止并说明目标路径，不要绕过限制 |
| `Unsupported option(s)` | 命令参数不属于当前版本 | 运行 `--help` 查看当前用法；`prune` 现在只读盘点 |

如果提示不在表里，主线程应先用 `inspect（检查）` 或 `validate（验证）` 获取最小错误信息，再说明具体文件、原因和下一步；不得把机械校验通过说成业务语义已经正确。
