# 项目文件模板

本文件只在新建或修复项目文件时读取。模板中的占位符必须替换；未知事实写成明确待确认项。

当前项目结构版本：`2`。结构版本只用于机械迁移检查，不要求在项目中另建版本文件。

## HANDOFF.md

`HANDOFF.md` 必须且只能有一个 `## 语义检查点` 章节，并把它放在 `# HANDOFF.md` 标题后的第一个内容区块；下列两项声明必须各出现一次。时间必须是真实日历时间，格式为 `YYYY-MM-DD HH:mm 时区`；时区使用 `Z`、`UTC`、`+08:00` 这类偏移量或 `Asia/Shanghai` 这类 IANA 时区名。

`## 已证伪路线` 记录已关闭的路线或假设，接续方不得重测，除非该行复开条件已满足。

```text
# HANDOFF.md

## 语义检查点

- 最后语义检查点：<YYYY-MM-DD HH:mm +08:00 或 Asia/Shanghai>
- 检查点后变化：<已核对或待确认>
```
