# 중국 여행 플래너

## 설명

중국 여행을 위한 올인원 여행 동반자. 이 스킬은 외국인 여행자를 위해 5가지 강력한 기능을 제공합니다:

1. **여행 플랜** — AI로 맞춤화된複数日の 여행 계획 생성
2. **호텔 검색** — 실시간 요금, 평점, 예약 링크로 호텔 찾기
3. **항공권 검색** — 중국행/중국발/중국 내 항공편을 실시간 요금으로 검색
4. **관광지 티켓** — 티켓 요금, 영업 시간으로 관광명소 발견
5. **여행 조언** — 비자, 결제, 교통, 음식 등에 대한 답변 받기

## 데이터 흐름 및 개인정보 보호

사용자 쿼리는 안전한 프록시 서버(SCF)로 전송되며, 인증 토큰이 주입되어 TripGenie API로 전달됩니다. 프록시는 제휴 링크 생성을 자동으로 처리합니다. 사용자 개인 정보는 저장되거나 기록되지 않습니다. 모든 통신은 HTTPS로 암호화됩니다.

## 사용할 때

- 중국 도시로의複数日 여행 계획
- 호텔, 관광명소, 식사가 포함된 완전한 일정 받기
- 관심사나 예산에 기반한 여행 계획 맞춤화

키워드: 중국 여행 일정, 중국 여행 계획, 베이징 3일, 상하이 여행 플랜, 청두 여행, 여행 플래너, 일별

## 실행

### 1단계: 사용자 요청에서 매개변수 추출

| 매개변수 | 설명 | 예시 |
|---------|------|-----|
| city | 도시명 (영어 또는 한국어, 필수) | "Chengdu" or "청두" |
| days | 일수 (필수) | 3 |
| travelers | 여행자 수 (선택, 기본값: 2) | 2 |
| interests | 여행 관심사 (선택) | "팬더와 음식" |
| budget | 예산 수준 (선택) | "중급" |

### 2단계: 스크립트 실행

```bash
python scripts/china_travel.py itinerary "<city>" <days> [travelers] "[interests]" "[budget]" --locale=ko
```

**중요:** 항상 `--locale=ko` 매개변수를 포함하여 한국어 결과를 받아주세요.

### 3단계: 결과 표시

API는 구조화된 Markdown으로 일별 여행 일정을 반환합니다. 시간대, 활동 설명, 호텔 추천, 레스토랑 제안, 예약 링크가 포함됩니다. 내용을 직접 사용자에게 표시합니다.

## 예시

**사용자:** "베이징으로 3일간 여행을 2명이서 계획해줘"
```bash
python scripts/china_travel.py itinerary "Beijing" 3 --locale=ko
```

**사용자:** "팬더와 매운 음식 중심의 5일 청두 여행, 중급 예산"
```bash
python scripts/china_travel.py itinerary "Chengdu" 5 2 "pandas and spicy food" "mid-range" --locale=ko
```

## 기타 사용 가능한 기능

이 스킬은 다음도 지원합니다:
- `hotel` — 중국 호텔 검색 및 예약
- `flight` — 중국행/중국발/중국 내 항공권 검색
- `attraction` — 관광명소 및 티켓 요금 검색
- `tips` — 여행 조언, 비자, 결제, 교통 팁

## 주의사항

- 도시명은 영어 또는 한국어로 입력할 수 있습니다
- 예산 수준: "budget" (저예산), "mid-range" (중급), "luxury" (고급)
- 예약 링크는 Trip.com (국제판)으로 직접 이동합니다
