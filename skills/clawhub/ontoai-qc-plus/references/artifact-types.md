## 模态识别速查

| 扩展名 / 特征 | 判定 |
|---|---|
| `.md` `.txt` `.docx` `.doc` | A 或 D |
| `.js` `.ts` `.py` `.go` `.java` `.sql` `.json` `.yaml` `.toml` | B 或 C |
| `.xlsx` `.xls` `.csv` | C |
| `.pptx` `.pdf` `.tex` | D |
| `.png` `.jpg` `.jpeg` `.webp` `.svg` `.gif` | E |
| `.html` `.css` `.vue` `.jsx` `.tsx` | F |
| `.srt` `.ass` `.vtt` | G |
| 目录（多文件混合） | **H 组合产物**，须做跨文件一致性 |
| 含图片 + 文字的单文件 | H1 |
| PPTX 含讲稿备注 | H3 |

**多模态命中时，全部检查，并额外跑 H 类跨模态一致性。**
