# 合规性检查项

版本 1.0.0 ｜ 2026-10-11

> 合规类问题与真实性同级，属**最高严重度**。命中即进必改区（确定性 = 1.0 时）。
> 本文件只做**风险标注**，不构成法律意见。判为必改的表述应提示用户"建议由法务/合规复核"。

---

## L1 · 广告法极限词

**依据**：《中华人民共和国广告法》第九条，广告不得使用"国家级""最高级""最佳"等用语。

**触发词（正则）**：
```
国家级|最高级|最佳|最优|最强|最好|最大|最高|最先进|最低价|最便宜|最新科学|最新技术
|第一(品牌|名|家)?|首个|首选|独家|唯一|独创|顶级|极品|巅峰|极致|史无前例|前所未有
|百分百|百分之百|100%有效|绝对|万能|永久|无敌|永不|包治|根治|彻底解决|一次解决
|领先|遥遥领先|革命性|颠覆性|划时代|史上最
```

**判定**：
- 出现在**广告/营销/电商/落地页**场景 → **必改**
- 出现在内部文档、技术文档、非营销语境 → 可改或不报
- 有真实证明依据的（如"全国销量第一"附权威统计出处）→ 降级为存疑，提示用户备妥证明

**保护边界**：
- 产品型号名（如"极光 MAX"）、既定专有名词、官方称号
- 已获权威机构认定并能提供证明的表述

## L2 · 密钥与凭据泄露

**触发（正则）**：
```
(sk-|pk_live|pk_test)[A-Za-z0-9]{16,}
AKIA[0-9A-Z]{16}
-----BEGIN [A-Z ]*PRIVATE KEY-----
(password|passwd|pwd|secret|token|api[_-]?key|access[_-]?key)\s*[:=]\s*['"]?[^\s'"]{6,}
(mongodb|mysql|postgres|redis):\/\/[^\s:@]+:[^\s@]+@
Bearer\s+[A-Za-z0-9._-]{20,}
```

**判定**：**必改**，严重度 5。

**附加检查**：配置文件、前端代码、日志输出、截图、示例文档中的示例密钥（即使是假的，也提示"建议改为占位符"）。

**动作**：标注位置，**不代为替换**（替换需用户确认密钥管理方案）。

## L3 · 个人隐私信息

**触发（正则）**：
```
身份证：[1-9]\d{5}(18|19|20)\d{2}(0[1-9]|1[0-2])(0[1-9]|[12]\d|3[01])\d{3}[\dXx]
手机号：1[3-9]\d{9}
银行卡：\d{16,19}
邮箱（对外发布物）：[\w.+-]+@[\w-]+\.[\w.]+
详细住址：.{2,10}(省|市).{2,10}(区|县).{5,30}(路|街|号)
```

**判定**：对外发布场景 → **必改**（建议脱敏）；内部文档 → 可改。

**保护边界**：企业公开的联系方式、客服电话、官网邮箱——属必要信息，保留。

## L4 · 版权与授权

| # | 检查 | 判定 |
|---|---|---|
| 4.1 | 引用他人作品（文字/图片/音乐/视频）无出处 | 必改（补出处或删除） |
| 4.2 | 使用未授权素材（商用图片、字体、音效） | 必改（提示授权风险） |
| 4.3 | 字体商用风险（微软雅黑、方正字体商用需授权） | 可改 |
| 4.4 | 大段引用未标注（超过合理引用范围） | 必改 |
| 4.5 | 二次创作/改编未获授权 | 必改 |

**动作**：**只标注风险，不判断法律结论。** 提示"建议确认授权状态"。

## L5 · 行业违规承诺

| 行业 | 违规表述 | 判定 |
|---|---|---|
| **金融** | 保本保收益、稳赚不赔、零风险、年化收益承诺、内幕消息、涨停预测 | 必改 |
| **医疗** | 根治、包治、特效、无副作用、药到病除、最先进疗法、治愈率 100% | 必改 |
| **教育** | 包过、保过、不过退款（无依据）、速成、名师 guaranteed、提分承诺 | 必改 |
| **房产** | 升值保证、投资回报承诺、学区房承诺（无官方文件） | 必改 |
| **招聘** | 性别/年龄/地域/婚育限制表述 | 必改 |

**触发正则示例**：
```
保本|保收益|稳赚|零风险|包过|包治|根治|特效|无副作用|药到病除|速成|保证.{0,6}(收益|回报|升值|通过)
```

## L7 · 英文真相广告 / 极限词（FTC）

**依据**：美国《联邦贸易委员会法》第 5 条（FTC Act §5）及 FTC 真相广告规则（16 CFR Part 255）——在英文营销/落地页/产品描述中，不得对产品或服务的功效、排名、安全性作**无充分依据的超级lative 或绝对化承诺**。（密钥/隐私/版权检查见 L2–L4，正则语言无关，对英文同样生效。）

**触发词（正则，不区分大小写）**：
```
\s(best|#1|number one|greatest|most advanced|most powerful|leading|top-?rated|world'?s? leading|ultimate|unbeatable|unsurpassed|flawless|perfect|100%|guaranteed|risk-?free|no side effects|clinically proven|scientifically proven|instant(ly)?|miracle|magic)\b
```

**判定**：
- 出现在**英文广告/营销/电商/落地页/SaaS 官网**场景 → **必改**（确定性 = 1.0 时）
- 出现在技术文档、非营销语境 → 可改或不报
- 有真实、可核验依据的（如 "ranked #1 by G2 in 2026" 附出处）→ 降级为存疑，提示用户备妥证明

**与 L1（中文广告法）的关系**：L1 管中文极限词（最佳/第一/国家级），本 L7 管英文等价物；中英混合产物两节叠加加载。

**保护边界**：产品型号名、既定专有名词、已获权威机构认定并能提供证明的表述。

## 合规项的报告写法

合规项在报告中必须写清三件事：

1. **命中原文**（具体片段）
2. **风险类型**（对应 L1–L7 哪一项）
3. **不改的后果**（如："可能被市场监管部门认定为违法广告，面临罚款"）

**不得自行改写合规表述**——改写可能改变法律语义，只提示用户复核。

## 与已移除项的说明

早期方案曾纳入《人工智能生成合成内容标识办法》（2025-09-01 施行）的标识义务检查。
**已移除**，理由：该办法约束对象为**网络信息服务提供者**（平台方），不适用于普通用户使用 AI 产出的文档、代码与图片，纳入质检项属于误适用。

若用户**主动询问**"我这个要不要标 AI 生成"，再按下列口径回答（不作为质检项）：
- 平台方（提供 AI 生成服务的产品）有强制标识义务；
- 个人用户在平台发布时，按平台规则与平台提示执行标识。
