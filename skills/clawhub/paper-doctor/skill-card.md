## Description: <br>
Paper Doctor provides automated peer-review style critique and polishing guidance for academic paper drafts. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[wen-i-love](https://clawhub.ai/user/wen-i-love) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Academic authors, researchers, and students use this skill to diagnose draft papers across structure, methodology, experiments, writing quality, references, figures, formatting, and venue fit. It supports PDF, LaTeX, and Markdown drafts and can produce targeted follow-up analysis for specific sections. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The security review reports that the skill grants shell execution without explaining why that authority is needed for the paper-review workflow. <br>
Mitigation: Review before installation, remove or disable shell execution when it is not required, and require explicit user consent before any command is run. <br>
Risk: The skill can use optional internet-assisted reference checking when enabled by the user. <br>
Mitigation: Use internet-assisted checks only with user approval and avoid sending confidential or unpublished manuscript content to external search tools. <br>
