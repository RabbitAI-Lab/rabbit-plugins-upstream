# WorkBuddy 每日签到 · 使用说明

> 适用版本：v3.1.0

## 先看这里：你在哪台设备上？

凭据只存在于浏览器的登录会话里，**只能从电脑上取一次**，取到之后在哪台设备用都行。

| 你的情况 | 怎么做 |
|---|---|
| 主要在**电脑**上用 | 按下面「三分钟上手」走一遍，全程在一台机器上完成 |
| 主要在**手机**上用 | 先借一次电脑取凭据（约 2 分钟），把内容发到手机，再在手机上录入。详见文末「在手机上使用」 |
| 两边都用 | 各录一次即可，同一个凭据可以同时用，互不干扰 |

## 三分钟上手

### 第 1 步：拿到自己的登录凭据

1. 用浏览器打开 WorkBuddy 网页端，正常登录
2. 按 `F12` 打开开发者工具，切到 **Network（网络）** 面板
3. 随便点一个页面操作，找到任意一个发往 `copilot.tencent.com` 的请求
4. 在 **Headers** 里找到 `Authorization`，复制 `Bearer ` 后面那一长串（不含 `Bearer ` 本身）

> 这串东西就是你本人账号的通行证，等同于登录状态。**不要发给任何人**，包括贴到群里、提交到代码仓库。

### 第 2 步：录入

```bash
cd 本技能目录
python3 scripts/setup.py --token '你复制的那串'
```

或者不带参数运行 `python3 scripts/setup.py`，它会提示你粘贴，回车即录入。

**粘贴不用清洗。** 下面这些都能自动识别，不用手动删前缀：

- `Bearer eyJhbGci...`
- `Authorization: Bearer eyJhbGci...`
- 带引号、带首尾空格、末尾带分号
- 连同一整条 `curl -H '...'` 命令一起复制
- 一整段 JSON 片段

看到 `[已写入] .../config.json（权限 0600）` 就成了。

### 第 3 步：验证

```bash
python3 scripts/checkin.py --dry-run
```

这一步只查状态、不领取。返回「今日未签到」或「今日已签到」都说明凭据可用。

### 第 4 步：签到

```bash
python3 scripts/checkin.py
```

成功会输出类似：

```
✅ 签到成功，本次 +20，连续 6 天，累计 320
```

## 想每天自动签？

技能本身不注册任何后台任务。要每天自动跑，你自己在系统里加一条计划任务即可：

**macOS / Linux**

打开系统自带的计划任务工具，添加一条每天执行的任务，执行内容填：

```
cd /你的/技能目录 && /usr/bin/python3 scripts/checkin.py
```

执行时间按你自己的作息设置，建议放在每天固定上班之后。

**Windows**

打开「任务计划程序」，新建一个基本任务，触发器选「每天」，操作选「启动程序」，
程序填 `pythonw.exe`，参数填 `scripts\checkin.py`，「起始于」填技能目录。

注意：任务由你的系统负责调度，本技能不注册任何自启项，卸载技能后请自行删除这条任务。

## 常见问题

**问：这东西会不会偷偷读我的登录信息？**
答：不会。脚本只读它自己目录下的 `config.json`，不遍历目录、不碰浏览器数据、不碰客户端文件。你可以直接打开 `scripts/setup.py` 和 `scripts/wbcfg.py` 逐行检查，全文不到 300 行。

**问：token 存哪儿？安全吗？**
答：存在本技能目录的 `config.json`，文件权限 600（只有你自己能读）。不想留了就跑 `python3 scripts/setup.py --purge`，文件立刻删除。

**问：token 会过期吗？**
答：会，一般 28 天。过期后签到会报「凭据已过期」，按第 1 步重新复制一次就行。技能不会替你自动续期——那意味着要长期保存刷新凭据，风险更大，所以没做。

**问：会不会重复领取、把账号搞异常？**
答：不会。脚本每次先查当天状态，已签到就直接返回，不重复请求领取接口。重复运行是安全的。

**问：能同时签多个号吗？**
答：不能，也不打算支持。技能只服务你自己的一个账号。

**问：会不会绕过什么验证？**
答：不会。凭据失效就停下，要求你重新提供，不尝试任何自动恢复、不模拟登录、不发验证码。

## 在手机上使用

手机上没有开发者工具，**取不到凭据，这一步必须借一次电脑**。取到之后手机就能独立用，不需要一直连着电脑。

### 三步搞定

**① 电脑上取**

按上面「第 1 步」复制那串内容。

**② 传到手机**

发给自己就行：微信「文件传输助手」、备忘录、隔空投送、邮件，随便哪种。别发到群聊或朋友圈。

**③ 手机上录入**

在手机的 WorkBuddy 里把内容粘给助手，说「这是我的凭据，帮我录入」；或者在技能目录里执行：

```bash
python3 scripts/setup.py --token '粘贴内容'
```

粘完就完事，后面每天签到在手机上直接说「签到」即可。

### 为什么不能在手机上自动取

三个原因，都不是本技能故意为难你：

1. **凭据在客户端里是加密存的**，即使读到文件也解不开，拿不出可用的值
2. **手机浏览器没有开发者工具**，也没有别的入口能看到请求头
3. **用手机重新登录一次再抓取，等于代替你完成登录**，这属于操作他人账号的范畴，平台不允许技能这么做，也不该做

所以「从电脑取一次」是唯一的正经路径。好在只需要做一次，之后 28 天内都不用再碰。

### 手机上的几个实际问题

**问：手机上技能目录在哪？**
答：不用管。你只要把内容粘给助手，助手会自己找到位置并执行。

**问：换手机了或者重装了怎么办？**
答：重新走一次上面三步，把同一串内容再录一遍就行。

**问：电脑和手机能同时用吗？**
答：能。同一个凭据在两边各存一份，互不影响，签到是幂等的，哪边先签另一边会自动跳过。

## 它主动不做的事

| 事项 | 说明 |
|---|---|
| 读本机登录态 | 不扫描、不读取、不解密任何客户端或浏览器数据 |
| 自动续期 | 不保存刷新凭据，过期即让用户重新提供 |
| 跨域转发 | 只请求官方地址，不做备用域名兜底 |
| 批量操作 | 只服务一个账号，无多账号逻辑 |
| 常驻后台 | 不注册自启、不留进程，只在被调用时跑一次 |
| 打印凭据 | 任何输出都不含凭据内容或片段 |
