## Description:

Guides agents through creating women's fashion marketing videos by transferring actions from an authorized reference video to a supplied model image using Qinghu AI.

This skill is ready for commercial/non-commercial use.

## Publisher:

[autoagc](https://clawhub.ai/user/autoagc)

### License/Terms of Use:

MIT-0

## Use Case:

Fashion merchants and creators use this skill to make women's clothing promotional videos with a different real or virtual model while retaining the movements in a reference clip.

### Deployment Geography for Use:

China (domestic iqinghu.com service)

## Known Risks and Mitigations:

Risk: Reference videos and model images are uploaded to an external service.

Mitigation: Use only authorized media and confirm the uploader is comfortable sharing it with Qinghu AI.

Risk: The workflow requires an API token and incurs usage-based credits.

Mitigation: Keep the token private, review the credit estimate, and obtain approval before generation.

Risk: Installing or running a new package introduces dependency risk.

Mitigation: Prefer an existing trusted installation or a trusted package-manager install over ad hoc execution.
