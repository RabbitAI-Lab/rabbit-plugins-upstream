## Description: <br>
Single-source-of-truth drift auditor for documentation-heavy repositories that finds hand-copied facts, proposes a manifest of canonical locations and copies, and verifies that each copy still matches. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[conorbronsdon](https://clawhub.ai/user/conorbronsdon) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and documentation maintainers use this skill to discover duplicated facts in documentation-heavy repositories, create a reviewed `.ssot.yaml` manifest, and run read-only checks that report drift before commits or releases. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may inspect sibling repository paths when a manifest references cross-repo copies or canonicals. <br>
Mitigation: Install only where cross-repo inspection is acceptable, review manifests for `../` paths, and require explicit approval before any cross-repo command or edit. <br>
Risk: The skill's read-only posture is imprecise because artifact instructions mention refreshing sibling repositories with Git commands. <br>
Mitigation: Constrain use to reporting and proposal workflows; require human approval for `git fetch`, `git pull`, and any mutation outside the audited repository. <br>
Risk: Manifest patterns and proposed diffs can be incorrect if duplicated facts are legitimately different, historical, rounded, or generated by a pipeline. <br>
Mitigation: Review proposed canonicals, rounding rules, and diffs before writing manifests or applying fixes, especially for monotonic metrics and generated files. <br>
