## Use Case: <br>
External users use this skill to search for blowout services, check appointment availability, and create bookings through Lokuli's MCP server. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Creating a booking can send customer contact details and location or ZIP code to Lokuli's external service. <br>
Mitigation: Before creating a booking, have the agent confirm the provider, service, time, price or terms if shown, and the exact name, email, phone number, and location or ZIP code to be sent. <br>
