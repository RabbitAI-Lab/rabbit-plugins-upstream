**Полноценный практический навык по Гаагской системе для патентных поверенных по образцам, юристов в сфере ИС и корпоративных юристов по всему миру — с опорой на международную фазу ВОИС, применимый с точки зрения любой договаривающейся стороны, с опциональной главой о КНР (CNIPA).**

Это не энциклопедия: навык даёт маршруты проверки на каждом этапе подачи и экспертизы, юридические источники, проверяемые по статьям (Женевский акт / Общая инструкция / Административная инструкция / Руководство), числовые требования к изображениям, единству образца и приоритету, а также перепроверяемые параметры пошлин и сроков (со встроенным скриптом расчёта пошлин).

Формат — универсальный Agent Skills (`/SKILL.md`); работает с любым агентом, поддерживающим skills.

## Установка

### Вариант 1: скрипт синхронизации (рекомендуется)

```bash
# Windows
py -3 scripts/sync_to_local.py

# macOS / Linux
python3 scripts/sync_to_local.py

# Частые параметры
py -3 scripts/sync_to_local.py --dry-run                # предпросмотр без записи
py -3 scripts/sync_to_local.py --target D:/path/to/skills   # свой каталог skills
```

Скрипт односторонне синхронизирует этот репозиторий как единый навык в ваш локальный каталог skills (по умолчанию `~/.workbuddy/skills`, устанавливается как `hague-design-system/`): новые и изменённые файлы перезаписываются, устаревшие удаляются, **локальные метаданные вроде `_user_meta.json` сохраняются**; файлы уровня репозитория (README, LICENSE, logo и т. п.) в каталог skills не устанавливаются.

### Вариант 2: копирование вручную

Скопируйте папку репозитория целиком в ваш каталог skills (например, `~/.workbuddy/skills/`) и переименуйте её в `hague-design-system`, затем перезапустите или перезагрузите приложение.

> ⚠️ Навык состоит из множества файлов: база знаний в `references/` (Акт и Общая инструкция, Административная инструкция, Руководство по Гаагской системе, опциональная глава о КНР и др.) подключается из `SKILL.md` относительными путями `@` — **отсутствие одного файла разрывает цепочку**. Копируйте каталоги целиком; не берите только `SKILL.md`.

## Ключевые механизмы

1. **Универсальное ядро**: международная фаза ВОИС (общая для всех договаривающихся сторон) — основная часть; глава о CNIPA/КНР опциональна и может быть полностью пропущена специалистами вне КНР;
2. **Единый источник права и данных**: изменчивые данные (пошлины, заявления) сходятся к единственному авторитетному источнику; история версий и индекс файлов централизованы (`changelog.md`, `11-file-index.md`) — никаких расхождений;
3. **Постепенное раскрытие**: объёмные тексты (включая Руководство по Гаагской системе на 286 КБ) лежат в `references/`, загружаются по мере необходимости и снабжены индексом по строкам — контекст не перегружается;
4. **«Нет» при отсутствии данных**: сомнительная информация помечается сразу — никаких выдуманных статей, сроков и сумм; в ответах никогда не используются таблицы Markdown (только списки и определения в строку).

## Структура репозитория

```text
HAGUE-SKILLS/                        # Корень репозитория = корень навыка (репозиторий одного навыка)
├── SKILL.md                         # Управляющий слой: роль / задача / контекст / процесс / правила / вывод
├── references/                      # 12 файлов знаний (включая главу о КНР, changelog, индекс)
├── scripts/                         # Скрипты навыка (расчёт пошлин, помощник) + sync_to_local.py
├── README.md                        # 简体中文 (по умолчанию)
├── README.zh-Hant.md                # 繁體中文
├── README.en.md                     # English
├── README.fr.md                     # Français
├── README.es.md                     # Español
├── README.ar.md                     # العربية (RTL)
├── README.ja.md                     # 日本語
├── README.ru.md                     # Русский (этот файл)
├── LICENSE                          # Лицензия MIT
└── logo.png                         # Логотип бренда (шапка README)
```

- Корень репозитория — это корень навыка; после установки структура строго **2 уровня** (`SKILL.md` / `references/` / `scripts/`), по официальной структуре WorkBuddy;
- Файлы уровня репозитория (`README*.md`, `LICENSE`, `logo.png`, `scripts/sync_to_local.py`) в каталог skills не устанавливаются;
- Файлы навыка: **CRLF, UTF-8 без BOM**.

## Данные и актуальность

- Правовые источники — **действующие официальные версии ВОИС / CNIPA**; в навыке указаны базовые даты данных и рекомендуемая периодичность перепроверки (список §3.0);
- Изменчивые данные (пошлины, индивидуальные пошлины за указание, заявления сторон, курсы валют) перепроверяйте по последним официальным публикациям или калькулятору пошлин перед использованием в деле;
- Результат — практический справочный материал, **не является юридической консультацией**.

## Ограничения

- Не заменяет официальную и индивидуальную оценку: сроки, пошлины и процедурные выводы определяются уведомлениями указанного ведомства и официальными публикациями;
- Никаких выдумок: данные, которые не удаётся найти, возвращаются как «нет»;
- Правовой охват — процедура и общие правила Гаагской системы; материальное право и практика экспертизы каждой указанной договаривающейся стороны — по официальным позициям этой стороны.
