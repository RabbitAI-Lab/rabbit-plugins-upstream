# Hague Design System · مهارة عملية لتسجيل التصاميم الدولية في نظام لاهاي

> *«سؤال واحد، وجواب عملي جاهز للعمل على القضية في نظام لاهاي.»*
> *"Ask once. Get a filing-ready Hague design practice answer."*

[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Version](https://img.shields.io/badge/version-1.10.8-blue.svg)](references/changelog.md)
![Agent-Agnostic](https://img.shields.io/badge/Agent-Agnostic-blueviolet)

![No-Fabrication](https://img.shields.io/badge/Principle-No--Fabrication-orange)

**مهارة عملية شاملة لنظام لاهاي، موجّهة إلى وكلاء التصاميم والمحامين المتخصصين في الملكية الفكرية والمستشارين القانونيين للشركات في جميع أنحاء العالم — محورها المرحلة الدولية لدى الويبو، وصالحة من منظور أي طرف متعاقد، مع فصل اختياري خاص بالصين (CNIPA).**

ليست موسوعة: بل مسارات تحقّق لكل خطوة من خطوات الإيداع والفحص، ومصادر قانونية قابلة للتحقق مادةً مادةً (وثيقة جنيف / اللائحة المشتركة / التعليمات الإدارية / الدليل)، ومعايير رقمية للرسوم التخطيطية ووحدة التصميم والأولوية، ومعطيات قابلة لإعادة التحقق بشأن الرسوم والمواعيد (مع سكربت مدمج لحساب الرسوم).

متوافقة مع صيغة Agent Skills العامة (`/SKILL.md`)؛ تعمل مع أي وكيل يدعم الـ skills.

## التثبيت

### الخيار 1: سكربت المزامنة (موصى به)

```bash
# Windows
py -3 scripts/sync_to_local.py

# macOS / Linux
python3 scripts/sync_to_local.py

# خيارات شائعة
py -3 scripts/sync_to_local.py --dry-run                # معاينة دون كتابة
py -3 scripts/sync_to_local.py --target D:/path/to/skills   # مجلد skills مخصّص
```

يزامن السكربت هذا المستودع كمهارة واحدة، باتجاه واحد، إلى مجلد المهارات المحلي (افتراضيًا `~/.workbuddy/skills`، وتُثبَّت باسم `hague-design-system/`): تُستبدل الملفات الجديدة أو المعدّلة، وتُحذف الملفات القديمة، و**تُحفظ البيانات الوصفية المحلية مثل `_user_meta.json`**؛ ولا تُثبَّت ملفات المستودع (README وLICENSE وlogo وغيرها) في مجلد المهارات إطلاقًا.

### الخيار 2: النسخ اليدوي

انسخ مجلد المستودع بالكامل إلى مجلد المهارات لديك (مثل `~/.workbuddy/skills/`) وأعد تسميته إلى `hague-design-system`، ثم أعد تشغيل التطبيق أو أعد تحميله.

> ⚠️ المهارة متعددة الملفات: قاعدة المعرفة في `references/` (الوثيقة واللائحة المشتركة، والتعليمات الإدارية، ودليل نظام لاهاي، والفصل الاختياري الخاص بالصين، إلخ) تُشار إليها من `SKILL.md` بمسارات نسبية `@` — **فقدان ملف واحد يقطع السلسلة**. انسخ المجلدات كاملة، ولا تأخذ `SKILL.md` وحده.

## ما الذي تقدمه

| المجال | الوصف |
|------|------|
| الطلب الدولي | أهلية الإيداع؛ الإيداع عبر DM/1 وeHague؛ متطلبات الرسوم التخطيطية؛ وحدة التصميم؛ الأولوية؛ مسارات الإيداع ومراحل الإجراء |
| التسجيل والنشر | الفحص الشكلي والتصحيحات؛ التسجيل الدولي وتاريخ التسجيل؛ النشر والتأجيل؛ السحب |
| الفحص وسبل الانتصاف | الردّ على الرفض من المكتب المعيَّن؛ إعلانات منح الحماية وآثار النفاذ؛ البطلان؛ المسارات بعد الرفض |
| التجديد والتغييرات | مدة الحماية والتجديد (بما في ذلك مهلة السماح)؛ تغيير المالك، وبيانات المالك، والوكيل، والتقييد، والتنازل |
| الرسوم | أنواع المعاملات السبعة (الطلب / التجديد / تغيير الملكية / تغيير بيانات المالك / تغيير اسم وعنوان المصمم / التقييد / التنازل)؛ حاسبة رسوم نظام لاهاي؛ هيكل الرسوم بالفرنك السويسري؛ سكربت حساب مدمج |
| البحث | البحث عن التصاميم السابقة والحالة القانونية في DesignDB |
| اختياري · فصل الصين | إعلانات الصين؛ الفحص وسبل الانتصاف أمام CNIPA؛ الإحالة وعمليات النظام؛ الطلبات التقسيمية؛ ملاحظات باليوان الصيني (يمكن للممارسين خارج الصين تخطّيها بالكامل) |

## الآليات الأساسية

1. **نواة عالمية موحّدة**: المرحلة الدولية لدى الويبو (المشتركة بين جميع الأطراف المتعاقدة) هي المتن الأساسي؛ وفصل CNIPA/الصين اختياري ويمكن للممارسين خارج الصين تخطّيه بالكامل؛
2. **مصدر قانوني وبيانات من نقطة واحدة**: تتجمّع البيانات المتغيّرة (الرسوم والإعلانات) في مصدر موثوق وحيد، مع تاريخ الإصدارات وفهرس الملفات في مكان واحد (`changelog.md` و`11-file-index.md`) لتجنّب تباين الأرقام؛
3. **الإفصاح التدريجي**: النصوص الطويلة (ومنها دليل نظام لاهاي بحجم 286 كيلوبايت) تُوضع في `references/` وتُحمَّل عند الحاجة مع فهرس بأرقام الأسطر، دون إثقال السياق؛
4. **«لا يوجد» عند تعذّر البيانات**: تُوسم المعلومات غير المؤكدة فورًا — لا اختلاق لمواد أو مواعيد أو مبالغ؛ ولا تُستخدم جداول Markdown في الردود المسلَّمة (بل قوائم وتعريفات سطرية).

## بنية المستودع

```text
HAGUE-SKILLS/                        # جذر المستودع = جذر المهارة (مستودع مهارة واحدة)
├── SKILL.md                         # لوحة التحكم: الدور / المهمة / السياق / العملية / القواعد / الإخراج
├── references/                      # 12 ملف معرفة (يشمل فصل الصين الاختياري وchangelog والفهرس)
├── scripts/                         # سكربتات المهارة (حاسبة الرسوم وأداة الجلب) + sync_to_local.py
├── README.md                        # 简体中文 (افتراضي)
├── README.zh-Hant.md                # 繁體中文
├── README.en.md                     # English
├── README.fr.md                     # Français
├── README.es.md                     # Español
├── README.ar.md                     # العربية (هذا الملف)
├── README.ja.md                     # 日本語
├── README.ru.md                     # Русский
├── LICENSE                          # رخصة MIT
└── logo.png                         # شعار العلامة (ترويسة README)
```

- جذر المستودع هو جذر المهارة؛ وبعد التثبيت تكون البنية من مستويين **فقط** (`SKILL.md` / `references/` / `scripts/`)، وفق البنية الرسمية لمهارات WorkBuddy؛
- لا تُثبَّت ملفات المستودع (`README*.md` و`LICENSE` و`logo.png` و`scripts/sync_to_local.py`) في مجلد المهارات؛
- اصطلاح ملفات المهارات: **CRLF وUTF-8 بدون BOM**.

## البيانات والحداثة

- تتبع المصادر القانونية **النسخ الرسمية السارية للويبو / CNIPA**؛ وتُدوَّن في المهارة تواريخ أساس البيانات ودورات إعادة التحقق الموصى بها (قائمة §3.0)؛
- بالنسبة للبيانات المتغيّرة (الرسوم، ورسوم التعيين الفردية، والإعلانات، وأسعار الصرف)، أعد التحقق من أحدث المنشورات الرسمية أو حاسبة الرسوم قبل استخدامها في ملف القضية؛
- المخرجات مرجع عملي — **وليست مشورة قانونية**.

## الحدود

- لا تُغني عن التقدير الرسمي أو تقدير كل حالة على حدة: المواعيد والرسوم والاستنتاجات الإجرائية تخضع لإشعارات المكتب المعيَّن والمنشورات الرسمية؛
- لا اختلاق: البيانات غير القابلة للعثور يُجاب عنها بـ«لا يوجد»؛
- يركّز التغطية القانونية على إجراءات نظام لاهاي وقواعده المشتركة؛ أما القانون الموضوعي وممارسة الفحص في كل طرف متعاقد معيَّن فتتبع المواقف الرسمية لذلك الطرف.
