## 项目简介

Helios Kanban Skills 是一组用于在 Helios 平台上管理和展示看板（Kanban）相关功能的技能/工具集合。目标是提供直观的看板视图、任务卡片管理、列（lane）操作以及与后端同步的能力，便于在 Helios 环境中快速构建看板式工作流。

## 主要功能

- 创建 / 编辑 / 删除 看板与列（lane）
- 创建 / 编辑 / 移动 / 删除 任务卡片（card）
- 支持多用户协作与权限控制（视实现而定）
- 与 Helios 平台或自定义后端同步数据
- 支持导入/导出（CSV/JSON）以及基本统计信息
