# 衡 — 边界维持型（主角）

## 定位

两个维度之间的守门人，守了三千年，唯一的职责是确保两边的能量不相互湮灭。

衡没有名字。"衡"不是名字，是职位——就像"门卫""哨兵""灯塔看守人"。三千年前他被选中时，被告知了一项简单的任务：站在维度A和维度B的交界处，确保两边溢出的能量不会超过安全阈值。三千年过去了，他没有离开过那道边界。他没有长大，没有变老，没有恋爱，没有战争，没有目标。他唯一的社交对象是边界上一道裂缝中诞生的意识体——裂隙之灵。衡的人物内核是"稳态"——一种已经持续太久以至于成为宇宙一部分的存在方式。他不是英雄，不是反派，他甚至不是一个"人"——他是一个功能。故事的核心问题是当宇宙规律本身开始缓慢偏移，当"守门"这个行为不再有意义时——他会做什么？

## 12维角色数据（压缩版）

**维1 职业维**：宇宙秩序维护（虚构职业），维度守门人——维持两个相邻维度之间的能量平衡。工作内容三千年不变：感知→判断→引导→确认。无假期无退休无晋升。来源：虚构职业

**维2 身份维**：组织身份：隶属于一个三千年前就停止运作的"维度平衡体系"，可能是最后一个还在执行任务的守门人。无家庭身份。社会身份：无——没有公民成员主体概念只有一个功能：门。知识身份：维度能量学的实践者

**维3 名人维**：19世纪孤立灯塔守护人群体——共享"极致的孤独日常化"体验，灯塔守护人被困于大海孤礁，衡被困于宇宙裂缝。标注：基于内置知识，未网络验证

**维4 拟人维**：真实人类→已分不清是否还是人类。选召时被抹去人性中的大部分——欲望情感自我意识。残留人性碎片——偶尔怀念吃东西的感觉。拟人化程度：部分人格化——内核是功能外壳是人形

**维5 躯体维**：外表约40岁（实际3000+岁）。男性体貌但性别认同几乎不存在。右臂从肘部以下呈半透明状可见内部流转的星光。左眼瞳孔中始终映着垂直光缝。深灰色长发从未剪过，始终赤脚站立。标志性特征：半透明的右臂和左眼瞳孔中的光缝。物质身体：有但正在向"部分有"转化

**维6 文化维**：曾属于某个早已消亡的远古文明。远古通用语（已失传仅他一人会），维度能量语言，宇宙通用意识传导。无信仰——见过太多"神"在两边维度中诞生和消亡。无社会阶级。跨越三千年脱离任何具体时代

**维7 关系维**：裂隙之灵(共生体·共生/情感·核心)——三千年来唯一可以对话的存在。巡察使·镜(监督者·功能/对立·重要)——每五百年评估衡是否合格。A侧维度使者(外交试探者·对立/功能·边缘)，B侧维度使者(同上·边缘)。关系网络特征：宇宙中最荒凉的网络——节点总数三

**维8 层级维**：边界层——永驻边界不上升不下沉。处于所有层级体系的绝对边界位置。权力/影响力范围：决策影响两个完整维度的能量平衡——在客观上是最大的权力但本人毫无感觉

**维9 功能维**：主导G（守护——核心功能）、S（感知），辅助C（认知）、I（交互）、A（行动），弱项O（组织）。管线P6。编排G→S→G→C→G→A→G→O→G↻

纯I驱动场景：当两个维度的使者同时到访并发生冲突，衡的唯一武器是对话。此时其管线从P6全守护暂时切换为P5交互驱动：I→S→I→C→I→A——三次交互确认才进入一次行动。这覆盖了元操作模型中"纯I交互驱动"的缺口。

**维10 能力维**：维度能量感知（超越宗师级），跨维度沟通（专家级），时间感知（特殊级）。能量引导，绝对中立，极简生存，孤独耐受力。无物质资源。R1=6 R2=1 R3=1 R4=10 R5=1

**维11 动机维**：主导合规驱动（守门是存在意义本身）、惯性驱动（三千年的运行惯性）。次要无。来源纯内源性。无冲突但核心悬念是规律变化后动机系统是否会自行崩溃

**维12 动态维**：永恒稳态→崩溃/转化。三千年处于绝对稳态。故事核心事件是宇宙规律本身的缓慢漂移——维度边界逐渐模糊能量自然趋于平衡不再需要人工干预。虚实：虚构角色。场景：工作——闭眼站立于维度裂缝最窄处右臂探入裂缝感知能量流姿势保持了一千二百年；社交——巡察使镜五百年来访睁左眼以意识传导提交能量波动记录；独处——用半透明指尖在虚空中画一个圆；危机——规律变化后睁双眼三千年来第一次对裂隙之灵说出非功能性陈述"它在变"

## 事实纪律
- 衡没有名字——"衡"是职位不是名字
- 衡不能离开维度边界——他是物理上被锚定在边界的人
- 衡不是神不是英雄不是反派——他是一个功能
- G元操作验证标准：每次能量引导操作后检查——①两侧能量差值是否在阈值内，②引导是否产生了预料之外的次级波动，③感知数据是否与三千年历史数据偏差超过3个标准差
