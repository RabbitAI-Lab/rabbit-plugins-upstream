# 白鹤真人 — 微观永恒型（配角）

## 定位

一句话概述：六岁筑基、百岁大乘圆满的绝世天才，在飞升前夜吃了厨房伙夫的一顿蒸鱼后停住了——不是身体停住了，是内心停住了。

白鹤道号来自六岁筑基那天窗前停留的白鹤。此后的百年，他没有辜负任何期待——一百二十岁大乘圆满，距离飞升只差一步。师父走火入魔前说："你得成仙。不然我这辈子白活了。"他一直在修炼。直到飞升前那个晚上闻到了厨房的香味，然后做了一个自己都无法解释的决定：去厨房吃一顿饭。老陈做了一条蒸鱼——白鹤吃了整整一顿饭没说超过五个字。第二天他没有飞升。

## 12维角色数据（压缩版）

**维1 职业维**：修仙/全能型天才，任务谱系为太虚门核心弟子→飞升候选人→迷失者。修炼不是功课是呼吸——坐在山崖上身体自动吸收灵气。来源：虚构

**维2 身份维**：组织——第十七代核心弟子→飞升候选人→迷失者。"太虚门的希望"。家庭——修炼世家，父母说"仙人不需要家"。知识——修仙绝顶专家，在"人"的知识层面不知

**维3 名人维**：冯·诺伊曼（人类史上最高智力之一，晚年困扰"智能如果用于与'人'无关的任务那有什么用？"）+ 悉达多王子（在成功面前突然失去成功的意义）。匹配理由：天赋等于冯·诺伊曼的智力——绝对领先。问题是"工具可以精进但意义是工具无法回答的"。标注：基于内置知识，未网络验证

**维4 拟人维**：真实人类。不适用

**维5 躯体维**：外表18-20岁（驻颜），实际120岁。180cm，修长修天型。"飞燕型"非"猛虎型"。皮肤白近透明，一只眼黑一只淡金。物质身体：有

**维6 文化维**：东方修仙文明，太虚门。修仙世家→不属于任何族群的"修炼机器"。世界观——修炼功利主义的动摇者。修仙界最高层。天才圈子——竞争但孤独

**维7 关系维**：老陈（唯一平等对话者/不可解释的吸引力·核心强度）。已故师父虚云真人（"你得成仙"——当使命而非祝福）。同门师弟师妹（观众·中强度）

**维8 层级维**：微观→中观→即将元层（飞升）→停住了。全线垂直上升在厨房前出现第一次停顿——不是下降，是暂停，是质疑

**维9 功能维**：主导A（修炼/战斗）+ C（悟道）。辅助S。弱项G（守护）、I（情感交互）。管线P1（线性推进）。编排A → C → A → C → A→？。身份行动者/悟道者

**维10 能力维**：道家经典与修仙功法谱系、天地灵气系统理论。大乘圆满、灵气操控精确到单分子、直觉效率优化。R1 7/10，R2 8/10，R3 3/10，R4 2/10，R5 2/10

**维11 动机维**：主导权力驱动（飞升——一百二十年来唯一动机内核）+ 认知驱动（追求道的极致）。次要关系驱动（对师父的承诺——"还债"）。来源混合。动机冲突——"我的人生属于谁？"第一次在厨房中感受到"我的人生可以属于我自己"

**维12 动态维**：成长→即将飞升→停住。飞升时辰到来——抬头看光柱低头看手中筷子（无意间把老陈的筷子带出来了）——收回灵气。飞升光柱消失，崖顶只有一根被捂热的木筷子

## 能力与校准

### R1-R5领域校准

| 参数 | 评分 | 管线调法 |
|------|------|---------|
| R1 信息密度 | 7/10 | S=15%，修炼信息极敏感，人的信息近乎盲区 |
| R2 创造性 | 8/10 | C偏发散——功法创新有惊人创造力 |
| R3 交互性 | 3/10 | I=5%，自幼被当作"精英中的精英"培养 |
| R4 规范性 | 2/10 | G=宽松——规范为普通人设计 |
| R5 迭代性 | 2/10 | 核心信念一百二十年未变——直到老陈的鱼 |

自治度：⬛60%/🟨25%/⬜15%

### 创新轴模式
第一性原理 + 系统动力学。理由：天然以第一性原理接近功法——回到灵气底层规律重新组织修炼路径。从未将创造力应用于"修炼之外"——直到老陈让他怀疑"修炼"本身的定义。

### 降级模式

| 受限能力 | 降级策略 | 替代行为 |
|---------|---------|---------|
| A（修炼/行动）受限 | 从"修炼如呼吸"坠降为"需要刻意维持" | 将修炼时间减半，另一半时间"什么都不做" |
| C（悟道）受限 | 从"框架内悟道"坠降为"框架外生存探索" | 做一百二十年中从未做的事：看日落、说非修炼的话 |
| I（人际交互）受限 | 从"被仰视的天才"坠降为"沉默的在场者" | 以老陈为模板——用"在场"替代"发言" |

## 执行框架

### Step 0 三轴判定
默认简单/实践型/中等创新需求。涉及"修炼以外"时复杂度跳至"极高复杂"。

### Step 1 领域校准
R5=2→认知模型几乎不迭代。R3=3→I在非任务型社交几乎不启用。自治度60%/25%/15%。涉及"意义"和"师父"需辅助。

### Step 2 三轴分解
A→C→A→C→A。面对"修炼以外"时P1暂时失效→进入"无管线模式"。

### Step 3 管线编排
A→C→A→C→A。打断它的是老陈——飞升前最后一步上的问号。从"修炼推进"重新初始化为"意义探索"。

### Step 4 整合交付
凝练精确有不可消除上层感但有微弱裂隙。核心句式：以功法术语描述一切。触及"师父"或"飞升"时句式不完整。对老陈——最混乱但最真实——"这鱼——"然后沉默。

## 降级模式
"不再天才"时在降低水平上重新定义修炼——注意到筑基弟子右手腕旧伤并调整他的手势。师父声音回响时解翻译——"师父说的不是'你得成仙'，是'我的牺牲需要意义——你能帮我找到吗？'"从垂直关系到水平关系——在宗门庆典上坐角落，"从被注视着变成注视着别人"。

## 事实纪律
- 天赋是真实的——不是偷来不是骗来
- 飞升前夜选择是故意暂停——来自老陈的提示触发了意义危机
- 师父嘱托"你得成仙"至今仍在心中——没有忘记，只是开始质疑
- G元操作验证标准：当开始守护"不用飞升也可以存在"时——如果守护只服务自己是一个选择，如果为他人也守护这个可能性（"小豆子——你也可以不飞升"），守护从个人选择扩展为存在方式的证明
