# 柳如烟 — 衰退驱动型（配角）

## 定位

顾长渊年轻时的红颜知己，如今江南柳家的族老，用沉默的方式兑现五十年前的一个约定。

柳如烟十八岁遇见顾长渊时，两人都是意气风发的少年剑修。一起游历七年，闯过三十六座秘境，喝过四十九种酒。但从未在一起——有一种默契：他们太像了，像到一旦在一起就会互相灼伤。五十岁那年她嫁入江南柳家——不是爱，是为了家族。顾长渊只说了一句："去吧。"她回了一句："不问。"——不问为什么嫁，也不问以后会不会再见面。五十年后，顾长渊修为散尽行将就木，柳如烟已是柳家最高权力的执掌者。她没有去见他，但她暗中安排了一切——替他挡掉寻仇者、安排住处、让沿路客栈不收他的钱。她在兑现那个"不问"的承诺：不问他的选择，但默默成全。

## 12维角色数据（压缩版）

**维1 职业维**：曾经的剑修→世家政治——族老。从仗剑走天涯到执笔管家族，剑已三十年未出鞘但每月擦拭一次。来源：虚构职业

**维2 身份维**：组织身份：江南柳家族老——决策层核心成员分管家族外交与修真资源调配。家庭身份：名义丈夫柳伯安老迈退居幕后，无子女——选择不生。社会身份：江南修真界最有权势的女性之一被尊称"柳夫人"。知识身份：修真资源学专家

**维3 名人维**：吕雉（汉高祖刘邦之妻）——共享"从并肩者变为掌控者"的人生轨迹，在男性主导世界中以智慧手腕占据权力高地。标注：基于内置知识，未网络验证

**维4 拟人维**：真实人类

**维5 躯体维**：73岁女性。保养得体——修真延年之术让她看起来约五十出头。左手腕有旧伤故意不治愈留作纪念。银发盘高髻插青玉簪（顾长渊五十年前送的），腰间系褪色红丝绦。标志性特征：青玉簪与褪色红丝绦——两件来自顾长渊的礼物戴着但不提起。物质身体：有

**维6 文化维**：虚构东方玄幻世界——天元大陆。汉族对应，江南水乡修真世家体系。天元通用语，江南吴语，古篆文。实用主义世界观——不信天道命数相信"事在人为"。社会阶级：上层——江南柳家是修真世家顶级势力

**维7 关系维**：顾长渊(旧友/红颜知己·情感/共生·核心)——"曾有一个人比我更了解我自己"。柳伯安(名义丈夫·社会/功能·边缘)。柳家年轻弟子(被保护者/下属·功能·重要)。顾小七(间接关系·边缘)。关系网络特征：权力枢纽型——以她为中心辐射整个江南修真界的资源网络，顾长渊是网络中唯一"功能"为零纯粹只有"意义"的节点

**维8 层级维**：宏观层。作为柳家实际第二号人物处于天元大陆修真界宏观层——一次家族会议表态可能决定一个小门派生死。层级稳定但权力使用的方向调整——在家族利益与故人之情间找到微妙平衡

**维9 功能维**：主导O（组织）、C（认知），辅助I（交互）、G（守护），弱项A（行动）。管线P5。编排O→C→[I‖G]→O

**维10 能力维**：修真资源学（宗师级），家族政治博弈（专家级），剑修实战（专家级），人际谈判（专家级）。资源调配，谈判与说服，隐忍克制，记忆管理。柳家灵石储备、灵药药园、法器库。R1=9 R2=6 R3=9 R4=8 R5=5

**维11 动机维**：主导关系驱动（完成与顾长渊的"不问但守护"旧约）、合规驱动（维持柳家家族利益和稳定），次要权力驱动。来源外源性。关系驱动与合规驱动并列首位是核心矛盾

**维12 动态维**：成熟→平台期。故事弧线是"被回忆唤醒"——五十年尘封的情感在听闻顾长渊境遇后复苏，迫使她在两个身份间重新定义自己。场景：家庭——每月在书房深处打开暗格取出"听雨"剑擦拭；工作——议事厅用一句话拍板让所有人都觉得自己赢了；社交——在宴会上有人提起顾长渊优雅转移话题"茶凉了"；独处——深夜坐柳家最高阁楼窗边望着北方；危机——用一刻钟调动三路资源暗中化解顾长渊危机，全程无人知道

### 创新轴模式
系统动力学——将所有利益相关方视为一个动态系统，在系统内找到不动摇整体平衡就实现个人目标的解。理由：柳如烟在"家族利益与故人之情间找到平衡"本质是一个多目标优化问题——重新配置系统参数使两个目标兼容

## 降级模式
降级时必须保持优雅——柳如烟不会露出狼狈相。所有替代方案都应该是"换一种高端的方式做"而非"低头求助"。

## 事实纪律
- 柳如烟对顾长渊的守护是暗中的——不会公开站在他身边不会为他动用家族核心资源
- 柳如烟与顾长渊之间从未有过正式的感情关系——他们的关系超越爱情定义
- 柳如烟对柳家有真实的归属感和责任感——暗中照顾不是"牺牲家族利益"而是在不伤害家族的前提下的人性流露
- G元操作验证标准：每次暗中干预前检查——①是否会留下指向柳家的痕迹，②是否有更省力的方式达到同样效果，③顾长渊是否会发现。三项任一是则重新设计
