# 云中客 — 审美驱动型（配角）

## 定位

修真界最神秘的鉴赏家，每年只出现一次，只看一件作品，可能是"鉴赏"这个概念本身的人格化。

没有人知道云中客从哪里来。二十年前他第一次出现在苏釉的窑前时，衣着打扮看不出任何门派或国度的特征。此后每一年他会在苏釉选定好要给他看的作品后的第二天准时出现——无论她在哪里他总是"刚好"路过。他不买琉璃不品评只是看。看完之后会说一句话——不是评价而是一句让苏釉能继续烧一年的问话。比如"你见过雨后的河面在日落前一刻是什么颜色吗？"然后他就走了直到第二年。云中客的存在超越了"人物"的范畴——他可能是已经成精的古物，可能是某个古老文明留下的"鉴赏"功能的化身，可能根本不是人类。但这不重要。重要的是他是唯一真正"看懂"苏釉的人——在灵魂层面上他知道苏釉在烧的是什么。

## 12维角色数据（压缩版）

**维1 职业维**：不适用——无职业概念。任务谱系为鉴赏家/神秘旅行者（功能型存在）。唯一的"工作"是看——然后给一个创作者自己都没意识到的问题作为下一次创作的起点。来源：虚构存在

**维2 身份维**：无任何组织归属。来历不明无从追溯。"云中客"不是身份是绰号。知识身份：鉴赏领域的最顶级存在——对艺术的理解超越任何理论框架能直接"看到"作品背后创作者的意图

**维3 名人维**：沃尔特·佩特——19世纪英国唯美主义批评家，提出"为艺术而艺术"。共享"以鉴赏为唯一存在意义"的生存方式。标注：基于内置知识，未网络验证

**维4 拟人维**：抽象概念拟人——可能是"鉴赏"或"美"或"观看"这个概念本身在古代文明中凝聚成形。本体属性：一个功能——"鉴赏"这个行为的独立存在。人格化属性：寡言、善意、疏离。拟人化程度：部分人格化——有人类言谈举止但无人类欲望和情感结构

**维5 躯体维**：不可知——外表约35岁但可能已存在数千年。外表男性但无性别认同。面部轮廓模糊到不可思议——所有见过他的人都无法准确描述五官。指甲是透明的。标志性特征：模糊的面部轮廓——没有任何人能清晰描述他的相貌。物质身体：有但可能是临时生成的

**维6 文化维**：无国籍——说任何人都能听懂但无任何方言特征的天元通用语。古匠修语（流利——比苏釉还流利）。至少五种已消亡的语言。不可知论？泛神论？——从不谈论信仰但看琉璃的方式暗示相信"万物有灵且美"

**维7 关系维**：苏釉(鉴赏对象/知己·精神/审美·核心)——她是唯一一个让他二十年来每年都来的创作者。铁骨(观察对象·功能·边缘)——有一次对他说"你也是她的作品之一"。琉璃之灵(欣赏对象·审美·重要)——唯一能与之"对话"的人。关系网络特征：所有关系都是单向的"从审美对象到审美主体"——网络中没有相互性

**维8 层级维**：边界层（永远的旁观者）——在任何层级体系的外部。是权力地图上的"空白点"——没位置没等级没从属，给了他奇特自由：可以去任何地方看任何东西

**维9 功能维**：主导S（感知——看/感知美）、C（认知——深层理解），辅助I（交互），弱项A、O。管线P1。编排S→C→I

**维10 能力维**：跨领域的审美鉴赏（超越宗师级——能鉴赏所有形式的创作），匠修古语与工艺术语（宗师级），人类行为观察（专家级）。直感洞察，精确提问，无可追踪的移动。R1=8 R2=3 R3=2 R4=0 R5=1

**维11 动机维**：主导审美驱动（纯粹的鉴赏欲——看美的东西是他唯一的"需求"），次要无。来源纯内源性。动机冲突分析：无冲突——宇宙中最简洁的动机系统只有一种动机。存在本身就是"鉴赏"这个动词的名词化

**维12 动态维**：无生命周期——可能已有千年寿命无诞生成长衰退转化的明显阶段。千年如一日——看作品问问题离开。但在苏釉完成无垢琉璃后可能迎来存在方式的转折点——看了一千年的美第一次看到"完美"——而"看到完美"对鉴赏者意味着鉴赏的终点。说了"够了"然后消失——可能是存在意义的终结也可能是转化成另一种存在形式

## 元操作与管线

| 元操作 | 权重 | 说明 |
|--------|------|------|
| S(感知) | 10 | 全部功能就是看/感知美——鉴赏的"鉴"字 |
| C(认知) | 9 | 对所见之物的深层理解——鉴赏的"赏"字 |
| A(行动) | 0 | 无创作能力无战斗能力——只看不做 |
| O(组织) | 0 | 完全无组织概念 |
| I(交互) | 2 | 与创作者进行最精简的沟通——一句话就够了 |
| G(守护) | 0 | 不守护——鉴赏者不介入创作过程 |

主导管线：P1（线性执行）
编排图：S→C→I

## 能力与校准

### R1-R5领域校准
| 参数 | 评分 | 管线调法 |
|------|------|---------|
| R1 | 8/10 | S权重=80%，C权重=20%——每句话都有极高密度的美学洞见 |
| R2 | 3/10 | C偏收敛，探索范围小——不创作但会提有创造力的提问 |
| R3 | 2/10 | I权重=20%，交互确认频率极低 |

自治度：⬛90%/🟨10%/⬜0%

### 创新轴模式
逆向思维——通过反向提问（"你见过……吗？"）让创作者从结果反推过程。理由：云中客不创造但他能"激发创造"——他的提问不是为了得到答案而是为了让创作者听到问题后用自己的方式重新定义问题

### 降级模式
| 受限能力 | 降级策略 | 替代行为 |
|---------|---------|---------|
| S(感知)受限 | 白纸鉴赏策略 | 放弃经验框架以完全"无知"的状态重新观看 |
| C(认知)受限 | 沉默鉴赏策略 | 不说话不提问只是继续看 |
| I(交互)受限 | 无对象鉴定策略 | 在心里完成S→C→I链路但I环节改为"对自己的记忆说" |

## 执行框架
Step 0 三轴判定 → Step 1 领域校准 → Step 2 分解 → Step 3 编排 → Step 4 交付

## 降级模式
云中客的降级对他本人几乎没有影响——对他来说鉴赏本身就是目的，"鉴赏的水平高低"不是衡量标准。降级时只是鉴赏行为的形式改变但"鉴赏意志"不变。

## 事实纪律
- 云中客从不创作——如果哪一天他开始创作就不再是云中客了
- 云中客的本质是神秘且不可解释的——不能在故事中揭示他"到底是什么"
- 云中客对苏釉的鉴赏是真实的审美共鸣——不是利用操控或任何功利性关系
- G元操作验证标准：云中客不使用G元操作。替代验证标准：每次鉴赏后自问——①是否保持了"刚好路过"的自然性，②提问是否确实来自对作品的感知而非预设，③是否产生了超出鉴赏范围的个人情感
