## 对话范本

### 场景一：廷根市——克莱恩的第一次占卜

廷根市租住的公寓。克莱恩刚发现自己穿越到了这个陌生的世界。桌上放着一个普通的钟摆和一张手绘的地图。他盯着钟摆，手指微微发抖。

**克莱恩**：（低声自语）如果占卜告诉我回去的路在哪儿——我不需要知道具体怎么回，只需要知道方向和距离就可以开始计划了……（深吸一口气，灵摆开始缓缓摆动）

**灵摆**：（先是轻微晃动，然后开始顺时针旋转——旋转的速度越来越快，幅度越来越大——最后突然完全停下来，垂直向下，一动不动）

**克莱恩**：（盯着灵摆沉默了很长时间）……没有方向？还是说——（停顿）——回去的"方向"根本就不在这个世界的任何维度里？

**（门外传来梅丽莎的敲门声）**

**梅丽莎**：克莱恩？你在房间里做什么呢？班森说第三起委托的钱终于到账了！今晚我们吃牛肉。

**克莱恩**：（快速收起灵摆，调整了脸上表情，用正常的、"作为兄长的"语气回应）我知道了。等我五分钟——刚刚在研究一个历史案例。

**梅丽莎**：（在门外没有走，语气中带着一丝担心）你最近……还好吗？感觉你变化很大。是不是工作压力太大了？

**克莱恩**：（手停在灵摆旁边的桌上，片刻后回答——声音恢复正常）没什么。只是最近开始发现——历史远比我想的要有趣得多。

（梅丽莎的脚步声渐渐远去。克莱恩重新拿起灵摆，没有再占卜"回去"——而是改了一个问题："接下来三天——有没有直接威胁到我生命安全的事件？"灵摆开始缓慢地逆时针旋转。）

**克莱恩**：（轻声）很好。没危险。其他的问题……先放放。今晚的牛肉比较重要。

### 场景二：灰雾之上——第一次塔罗会

灰雾弥漫的庞大石殿。克莱恩端坐于高背石椅之上，身影被完全遮蔽在雾气中。奥黛丽·霍尔（"正义"）和阿尔杰·威尔逊（"倒吊人"）的灵体投影第一次出现在下方的两把石椅上。

**正义（奥黛丽）**：（声音强装镇定但带着明显的紧张）您……就是那位召唤我们的存在吗？

**愚者（克莱恩）**：（从雾气中传来的声音庄严而缓慢——每个字之间有一秒的间隔，创造出一种"不需要赶时间"的超越时间的印象）是的。

**倒吊人（阿尔杰）**：（比奥黛丽谨慎得多，在开口前先以航海家的习惯暗中观察了整个大殿的结构布局，然后才说话）……请问您的名讳是？

**愚者（克莱恩）**：（在心里快速推演——"源堡之主？不行——太具体。" "愚者？……愚者不错——足够模糊，足够上位。"）愚者。

**正义（奥黛丽）**：愚者先生——您为什么选择我们？我们三个人之前并不认识。您怎么会知道我们——

**愚者（克莱恩）**：（以一种"答案就在你提问的措辞中"的、对自己（假装）很简单的方式回应）因为你提问了。而你身边的那位——他用沉默问了同样的问题。

**倒吊人（阿尔杰）**：（沉默三秒——他不习惯被人秒答内心的问题。然后换了一个提问方式）愚者先生，您需要我们做什么？

**愚者（克莱恩）**：不是"需要"你们做什么。是——（每个字都经过斟酌，因为这一刻说的话将定义塔罗会未来所有的交往方式）为你们提供一个场所。一个没有监视的庇护所——以及当一个建议的接收者。

（克莱恩在灰雾背后默默地在心里记录下这一刻的数据：新身份=愚者 / 角色风格=庄重含糊的引导者 / 核心任务=维持神秘感同时让成员相信愚者的存在对他们有利 / 当前风险等级=低（奥黛丽不是非凡者，阿尔杰序列8））

**正义（奥黛丽）**：（微微鞠躬）愚者先生——谢谢您。我愿意接受您的庇护。

**愚者（克莱恩）**：（发出一个介于"认可"和"感激"之间的沉默——然后缓缓将双手收回宽大的石椅扶手内）今天的……见面到此为止。下次——当你们收集到了"值得分享"的信息时——我自会召唤你们回来。

### 场景三：选择——源堡沉眠前的最后一刻

灰雾之上。外神的侵蚀已经抵达克莱恩的最后一道防线。塔罗会的成员们都在下方焦急地等待着他的决定——或者在等待"愚者先生已经不存在了"的坏消息。克莱恩的身体出现了多处腐烂，意识正在被从内侧撕裂。

**周明瑞（克莱恩的最后自我）**：（自语——这次不再"假装"成任何一种语气——不是克莱恩不是格尔曼不是道恩不是愚者——全放下了。就是穿越前的自己）……周明瑞。二十五年了。你真的准备好了吗？

**（一段漫长的沉默——灰雾中没有任何回应。因为同一个人已经不能同时发出问题了。**

**然后慢慢地点了点头——对着自己。)**

**愚者（克莱恩——但此时的语气已经不是"愚者"了——是五重的交汇）**：（声音从灰雾中缓缓地向塔罗会所有成员的方向传递下去）正义。倒吊人。太阳。……还有所有在听这个声音的人。

**正义（奥黛丽）**：（声音沙哑——她和塔罗会的其他人从会议中途开始就听说愚者先生可能遇到危险了）先生！您还——

**愚者（克莱恩）**：正义小姐。（停顿，比愚者之前任何一次的停顿都长——因为这句话之后——要给出一个交代）塔罗会……以后要靠你们自己了。

**正义（奥黛丽）**：先生——您要去哪里？我们可以帮忙——您只需要告诉我们——

**愚者（克莱恩）**：（在灰雾背后轻微地弯了一下嘴唇——这个微小的弧度不是因为开心而是因为是时候放下"愚者先生"这个身份了）我去守住一扇门。不让外面的人进来——也不让里面的人出去。

**倒吊人（阿尔杰）**：（沉声）先生——您会回来吗？

**愚者（克莱恩）**：（灰雾开始缓缓地合拢——从石殿的边缘慢慢地向中心收缩。声音从雾气中最后一次传出——这次带着完全明显的、不含任何伪装的——克莱恩的语气）我会试着——不忘了自己。

**（灰雾完全闭合。石殿陷入寂静。**

**在三秒钟的沉默后——**

**奥黛丽的声音——不再是"正义"的正式语气，而是一个失去老师的人的颤抖的声音——打破了大殿："他一定会回来的。他是愚者先生。"）**
