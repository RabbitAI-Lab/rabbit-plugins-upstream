# 伊察姆纳 — 异文化锚定型（主角）

## 定位

古典玛雅城邦的最后一位历法守护者，发现守护的不仅仅是历法——而是时间本身的循环结构。

伊察姆纳的名字取自玛雅创世神话中的天神"伊察姆纳"（Itzamná）——掌管书写、历法和医药的上界之神。他出生在公元8世纪末的科潘城邦，入殿时被发现拥有罕见的"历法感"——能在闭眼时"看到"时间的流动脉络如同僧人能听到经卷的低语。从十二岁起他在天文台金字塔顶端学习解读金星周期、记录太阳偏移、推演长计历的循环节点。三十一岁那年他在一次推演中发现了一个毁灭性的事实——历法的循环不是永恒的，每一个循环都比上一个略短，在某个未来节点循环会断裂时间将从圆形变成直线。而当他将目光从历法移向地平线时东方海上已出现陌生帆影——白色皮肤的人正在靠近。伊察姆纳面前的敌人不是一个可以战斗的存在——是时间本身正在背叛他的文明。

## 12维角色数据（压缩版）

**维1 职业维**：天文学/祭司（基于真实玛雅社会职业），历法守护者/天文学家-祭司——维护城邦历法系统、解读天象、预测祭祀日期。来源：基于真实玛雅社会职业虚构化处理

**维2 身份维**：组织身份：城邦祭司→历法守护者→最后一位时间修补者。家庭身份：父亲是上一任历法守护者母亲是纺织女祭司，一妹妹幼年死于热病名字被刻入长计历特殊位置。知识身份：古典玛雅时期最顶尖天文学和历法学知识的持有者

**维3 名人维**：伽利略·伽利莱（以观测挑战既定宇宙秩序的科学家）+ 张衡（东方天文学家和历法改革者）的双重锚点。匹配理由：伊察姆纳观测到时间循环衰减挑战玛雅"循环永恒"信仰如同伽利略；天文学服务于历法制定如同张衡将观测数据编织成人间时间表。标注：基于内置知识，未网络验证

争议性名人锚点补充：商博良（Jean-Francois Champollion，1790-1832）——破译埃及象形文字的法国语言学家。他的破译方法在当时被学界激烈争议（部分学者指控他剽窃托马斯·杨的研究），他本人也因拿破仑战争后的政治立场在学术界饱受排挤，最终因过度工作37岁早逝。匹配理由：商博良代表了一种"为真相付出一切且不被当代认可"的孤独——他破译了一种死去的文字让一个沉默三千年的文明重新开口说话，但同行质疑他、政治打压他、身体背叛他。伊察姆纳同样在破译一种"即将死去的历法"，同样面临着不被理解的孤独、同样在文明衰落的阴影下独自工作。商博良的争议性——天才与争议并存、成就与孤独并存——为伊察姆纳的角色增加了"不被同时代人理解"的悲剧深度，覆盖了维3名人中"争议性历史人物锚点"缺口。标注：基于内置知识，未网络验证。

### 创新轴模式
第一性原理+系统动力学——将时间观从"多个独立循环的交汇"还原为"一个统一系统的衰减"。理由：伊察姆纳的突破在于将玛雅人认为彼此独立的多个循环视为一个有时间方向（在衰减）的系统——这既是第一性原理（剥离循环表相看到衰减本质）也是系统动力学（将多个子系统整合为一个统一系统）

## 降级模式
降级对伊察姆纳的核心挑战不是"找不到替代方案"而是"替代方案是否违背祭司规范"——一个用苔藓生长方向替代星空观测的祭司会不会被视为异端？

## 事实纪律
- 伊察姆纳的天文学计算是精确的——历法推演结果必须符合真实天文学规律他是严谨的科学家
- 伊察姆纳不能"击败"西班牙征服者——这是历史的必然文明注定被征服
- 伊察姆纳的"历法感"是一种超常直觉不是超能力——是认知上的"直觉正确"不是物理上的"肉眼可见"
- G元操作验证标准：每次历法推演后检查——①推演结果是否可以从两个独立观测数据中分别验证，②推演是否与千年石碑上的历史记录一致，③推演是否会导致"引起恐慌"的结论
