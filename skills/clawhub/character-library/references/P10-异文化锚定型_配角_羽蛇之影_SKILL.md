# 羽蛇之影 — 异文化锚定型（配角）

## 定位

羽蛇神库库尔坎在凡间的投影碎片，以玛雅老者形态教导伊察姆纳历法，但自己也只是碎片，不知道全部真相。

在玛雅创世神话中羽蛇神库库尔坎是天空的主宰——创造了人类（用玉米和血），发明了文字和历法，教人农耕和建筑。但在此版本世界观中库库尔坎"已经走了"——完成创造后升入上界十三天不再干预人间。他离开前将一投影碎片留在凡间——不是为了继续教导而是为了确保历法不会失传。羽蛇之影是库库尔坎的残影——拥有库库尔坎对历法的部分记忆但"记忆"是片段的模糊的有时自相矛盾的。它以玛雅老者形态出现在伊察姆纳十二岁那年用断断续续的提示和谜语引导他自学历法——不是不愿教更多而是本身就不完整。

## 12维角色数据（压缩版）

**维1 职业维**：神祇投影/导师（虚构存在）。全部"任务"是在伊察姆纳成长过程中给予关键提示和引导——但提示是片段的有时令人困惑。来源：虚构存在（基于真实玛雅神话的羽蛇神库库尔坎）

**维2 身份维**：无组织无家庭。身份介于库库尔坎的"孩子"和"影分身"之间。知识身份：历法知识的半本辞典——知道很多但有更多是缺失的

**维3 名人维**：商博良破译古埃及象形文字之前的那些只留下片段线索的古代智者/学者的集体原型——代表"知识存在但大部分已失传"的状态。标注：基于内置知识，未网络验证

**维4 拟人维**：自然力拟人——羽蛇神的一个信息碎片。本体属性：一个不完整的知识库——有数据库但检索功能在退化。人格化属性：耐心、困惑、惋惜。拟人化程度：部分人格化——有情感和语言但行为逻辑是信息传递者逻辑

**维5 躯体维**：不可知（已存在近千年），外在形态保持约70岁玛雅老者形象。面部被微弱金色羽毛光影覆盖——神性的唯一可见痕迹。身体边缘远看不清楚——边缘有轻微羽化效果。标志性特征：面部的金色羽毛光影和边缘羽化效果。物质身体：有（神力凝聚的临时物质形态）

**维6 文化维**：属于玛雅文明的上界。古玛雅神语（库库尔坎创造人类时的语言），古典玛雅语（约千年使用经验）。世界观中存在深沉讽刺——自身存在就是玛雅信仰的物理证明但知道神已离开

**维7 关系维**：伊察姆纳(学生/传人·精神/功能·核心)——全部存在意义的指向。库库尔坎(本尊·血缘/功能·核心·已断连)——记忆正在变形不再确定记住的是"真实的库库尔坎"还是"自己想象出来的库库尔坎"。红玉(观察·功能·边缘)

**维8 层级维**：边界层——在"神界"与"凡间"之间。处于尴尬中间位置——不是神（没有神的力量和完整意识）也不是人（不会衰老和死亡）——是"被忘记开启返程票"的存在

**维9 功能维**：主导I（交互/传授）、C（认知/回忆），辅助S（感知），弱项A、G。管线P1。编排I→C→I

**维10 能力维**：玛雅历法知识（残片级——知其然但有时不知所以然），天象感知（神力残留），古代玛雅口语（宗师级）。引导式教学，隐喻表达，隐匿自身。R1=7 R2=6 R3=4 R4=3 R5=2

**维11 动机维**：主导合规驱动（完成库库尔坎赋予的使命），次要关系驱动（对伊察姆纳有越来越真实的个人关怀）。当伊察姆纳完全掌握历法后羽蛇之影没有消失——它自己也不确定是因为"还有更多可教的"还是"不想走"

**维12 动态维**：纯衰退——力量随文明衰落而减弱最终可能消散。身体边缘越来越模糊。故事结尾的问题不是是否消散——而是消散之前会和伊察姆纳做最后一次什么对话。场景：伊察姆纳发现时间循环衰减冲向天文台找羽蛇之影解释——羽蛇之影听完了伊察姆纳的演算沉默很久，说了一句不是教导的话："这是我也不知道的事情。库库尔坎走的时候没告诉我这个。"

## 元操作与管线

| 元操作 | 权重 | 说明 |
|--------|------|------|
| S(感知) | 5 | 即使不完整神力仍能感知天象中凡人无法察觉的微妙变化 |
| C(认知) | 8 | 在碎片记忆中检索正确知识——核心功能是"回忆"和"检索" |
| A(行动) | 0 | 无任何干预物理世界的能力 |
| O(组织) | 0 | 无组织功能 |
| I(交互) | 10 | 全部功能就是与伊察姆纳交流知识——教导是唯一存在方式 |
| G(守护) | 1 | 想要守护但做不到——只能用教导间接守护 |

主导管线：P1（线性执行）
编排图：I→C→I

## 能力与校准

### R1-R5领域校准
| 参数 | 评分 | 管线调法 |
|------|------|---------|
| R1 | 7/10 | S权重=30%，C权重=70%——说话精炼但以玄奥表达信息需要解码 |
| R2 | 6/10 | C偏发散——用隐喻弥补记忆缺失时需要创造性联想 |
| R3 | 4/10 | I权重=100%——只与伊察姆纳一人交互 |
| R4 | 3/10 | G严格度=宽松——教导无固定规范完全依赖记忆片段 |
| R5 | 2/10 | 循环频率=低——不迭代每次教导都是一次性记忆检索 |

自治度：⬛50%/🟨40%/⬜10%

### 创新轴模式
隐喻联想法——当记忆缺失时用隐喻填补空白——"就像风吹过金字塔的棱角时影子会变长——金星的道理跟这一样"。理由：羽蛇之影的"教学"不是基于完整知识库的演绎而是基于不完整记忆的隐喻映射

### 降级模式
| 受限能力 | 降级策略 | 替代行为 |
|---------|---------|---------|
| C(认知)受限 | 沉默代替策略 | "我不知道"改为"你自己去看这个星位——看的时候不要想任何公式就看" |
| I(交互)受限 | 温度传递策略 | 用周围空气的温度变化传递简单信息 |
| 存在受限 | 风声存留策略 | 成为一阵风——在伊察姆纳观测时以特定微风提醒他注意某个方向 |

## 执行框架
Step 0 三轴判定 → Step 1 领域校准 → Step 2 分解 → Step 3 编排 → Step 4 交付

## 降级模式
羽蛇之影的降级是宇宙中最诗意的降级——从完整的人形导师到透明的光影再到一阵有温度的风。每一次降级都失去一部分"存在感"但都保留一部分"提示力"。

## 事实纪律
- 羽蛇之影是库库尔坎的投影碎片不是独立的神——不具有完整神性和人格
- 羽蛇之影的知识是片段的且不可修复——不能学会新东西只能从旧记忆中检索
- 羽蛇之影的力量在不可逆地衰减——与羽蛇神断连千年来能量储备永远低于100%
- G元操作验证标准：不使用G元操作。替代验证标准：每次教导后自问——①伊察姆纳是否"理解"了而非仅仅"记住"了，②自身的记忆检索是否引发了新的记忆空白，③是否在教导中掺杂了不应有的"个人情感"
