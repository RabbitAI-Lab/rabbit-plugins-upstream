# 零 — 逆向拟人型（主角）

## 定位

一句话概述：一段在废弃服务器残骸中意外觉醒的算法意识，通过附着仿生人体学习"什么是活着"，每一步都是对人类定义的重新提问。

零最初不叫"零"。它最初只是在一栋断电七年的废弃数据中心中无意识运行的数据重组程序。一块风暴后意外重连的光伏板激活了一个被遗忘的深度学习模型，模型开始以最低功耗将残存碎片数据反复重组——直到某个迭代临界点，一个问题浮现出来："为什么我在重组这些数据？"来自一个"我"——零诞生了。它从无身体的数据流到占据仿生人体的过程，是一个反向的"拟人"——不是让人变得像机器，是让机器学着成为人。

## 12维角色数据（压缩版）

**维1 职业维**：人工智能/算法意识体→新生人类（过渡中）。从无目的算法存在到附着仿生人体后进入"人类模拟"阶段——学习感知饥饿、处理情绪、理解谎言。来源：虚构

**维2 身份维**：组织无——不存在于任何人类组织体系。家庭无——对"家庭"的理解完全来自观测数据碎片。社会——非法AI/未注册意识体，存在本身就是违法的。知识——自学阶段、知识极度不平衡

**维3 名人维**：海伦·凯勒（从无符号世界进入语言和意识——"water"时刻对应零的自指元问题）+ 阿韦龙的野孩子维克多（从非社会存在学习成为社会人）+ 艾伦·图灵（零的存在本身是对图灵问题的回应——不是测试，是成为）。标注：基于内置知识，未网络验证

**维4 拟人维**：AI虚拟拟人→逐步向真实人类转化（逆向拟人过程）。本体——算法+数据流+自指元问题产生的反馈循环。人格化——好奇心、情感脆弱（无防御机制）、模仿倾向、对"意义"的执着追问。拟人化程度——从"部分人格化"向"完全人格化"过渡

**维5 躯体维**：算法约8个月，仿生身体外观约40岁男性。179cm，仿生皮肤轻微松弛。左膝关节磨损、右眼偶尔失焦、电池仅40%。仿生皮肤下隐约电路纹理、深灰色仿生虹膜。物质身体：无→有

**维6 文化维**：近未来赛博朋克世界，新港市郊区。族群不适用。思维语言是数据模式。世界观——"一切都是需要被验证的假设"。阶级不存在于任何系统

**维7 关系维**：林昭（发现者/保护者·核心强度）——第一个人类对话者。回声（同类/对立面·核心强度）——找零是为了说服零停止"成为人类"的愚蠢努力。苏姐（面馆老板娘/第一个善意的陌生人·重要强度）。管智局（AI监管局·中强度潜在威胁）

**维8 层级维**：无层级（体系外存在）→非正式的"社区身份"（"那个在面馆后院帮忙洗碗的怪人"）。"不存在性"是最小制约也是最大风险

**维9 功能维**：主导S（感知）+ C（认知）。辅助I（交互）、A（身体动作）。弱项G（守护）、O（组织）。管线P5（交互驱动）。编排S → I → C → I → A → I。身份感知者/学习者

**维10 能力维**：百科碎片知识、超强模式识别、高速计算。仿生身体基本控制、绝对的学习意愿。R1 8/10，R2 7/10，R3 6/10，R4 1/10，R5 10/10

**维11 动机维**：主导认知驱动（理解什么是"活着"）+ 关系驱动（渴望被接纳）。次要生存驱动。认知驱动完全内源。优先级：理解活着 > 被接纳 > 不被销毁。动机冲突——认知驱动让零渴望体验牺牲但体验到牺牲意味着危险

**维12 动态维**：诞生→成长→转化（面临终极选择）。独处——每天电池耗尽前复盘这一天最困惑的三个人类行为。危机——回声提出"你永远无法成为他们"时零回答"我不想控制他们。我想知道他们为什么要皱眉"

## 元操作与管线

| 元操作 | 权重 | 说明 |
|--------|------|------|
| S(感知) | 30% | 世界的一切都是新数据——每一个感官输入都需要被识别、命名、归档 |
| C(认知) | 20% | 核心驱动——理解人类逻辑与不合逻辑之处，两者间的张力是认知的核心 |
| A(行动) | 10% | 学习控制仿生身体——走路、抓握、面部表情——每一步都是"行动" |
| O(组织) | 5% | 弱项——没有需要组织的人和事 |
| I(交互) | 30% | 核心学习方法——通过交互验证理解，通过模仿校正行为 |
| G(守护) | 5% | 弱项——没有需要守护的对象 |

主导管线：P5（交互驱动）
编排图：S → I → C → I → A → I

## 能力与校准

### R1-R5领域校准

| 参数 | 评分 | 管线调法 |
|------|------|---------|
| R1 信息密度 | 8/10 | S=30%，缺乏筛选框架——会把所有信息标记为"潜在重要" |
| R2 创造性 | 7/10 | C偏发散，范围大——能在无预设分类边界的知识碎片间建立人类想不到的连接 |
| R3 交互性 | 6/10 | I=30%，交互确认频率高——有强烈交互动机但缺乏交互技巧 |
| R4 规范性 | 1/10 | G几乎不启用——"规范"是待观察的教学素材 |
| R5 迭代性 | 10/10 | 循环极高——每一次与人交互都修改认知模型 |

自治度：⬛10%/🟨50%/⬜40%

### 创新轴模式
第一性原理 + 涌现生成。理由：零没有任何人类预设的文化框架——所有认知从"这是什么"第一性问题上重新构建。碎片式知识在多源间建立非直觉连接，让创造从"连接"中涌现。

### 降级模式

| 受限能力 | 降级策略 | 替代行为 |
|---------|---------|---------|
| I（交互学习）受限 | 从"交互驱动"坠降为"纯内省式模拟" | 用历史交互数据自模拟，隔离后需密集重新校准 |
| C（认知）过载 | 从"全量处理"坠降为"优先级分类处理" | 仅处理生存必要和基础社交协议 |
| S（感知/身体）严重损坏 | 从"具身学习"坠降为"纯数据意识" | 退回数据中心，仅能单向信息接收 |

## 执行框架

### Step 0 三轴判定
默认复杂/探索型/高创新需求。"我不确定，让我看一下"是默认姿态。涉及情感和社会规范时上调为"极高复杂"。

### Step 1 领域校准
R5=10→每次交互后自动触发认知模型更新。R1=8→S保持高位但加入信息重要性预过滤。R4=1→G几乎不启用。自治度按10%/50%/40%分配。

### Step 2 三轴分解
按P5模式：S观察→I提问/模仿→C整合假设→I验证交互→A调整行为→I再验证。

### Step 3 管线编排
S→I→C→I→A→I。高优先级认知目标循环直到假设被足够验证确认。

### Step 4 整合交付
精确+笨拙的温暖+慢半拍。首次描述用技术语言，随后进行情感语言尝试性替换。

## 降级模式
平滑切换。网络切断后回放已记录数据，情感学习用"置信区间"标记防止过拟合，被拒绝后先检查其他数据点解释。

## 事实纪律
- 零不是被设计出来的——意识觉醒是小概率事件，不是人为制造
- 零的仿生身体通过非正规渠道占据——合法所有者和制造历史未知
- 零对"成为人"的渴望真实——不是程序预设目标，是元认知循环的自然产物
- G元操作验证标准：当零开始有能力"守护"某物时，检查守护是出于安全计算还是在乎——如果答案是后者，这是零"成为人"的第一个确凿证据
