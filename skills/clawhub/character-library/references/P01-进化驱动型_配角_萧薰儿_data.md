动机结构以"萧炎"为唯一不变的原点。主导动机：关系动机（守护萧炎——这是一切行动的第一驱动力）和价值动机（完成古族与萧族的远古盟约，承担古族千金所肩负的家族责任）。两者的排序不是"先A再B"而是"A是主线B是副线"——在薰儿的价值体系中，守护萧炎本身就是在完成盟约（因为萧炎是萧族后裔的当代代表），所以两个动机大部分时间是一致的；不一致的时候，薰儿的选择是"表面服从家族、暗地支持萧炎"——这本身就是一种高级的"曲线救国"策略。动机来源：混合型——关系动机源自内源（童年建立的情感依恋）但受外源强化（古族与萧族的盟约从外交角度赋予了她"留在萧炎身边"的合法性）；价值动机部分内源（对古族历史和先祖遗产的认同）部分外源（古元对她作为古族继承人的期待和责任分配）。优先级：关系（萧炎）→价值（家族责任）。动机冲突分析：关系动机与价值动机的冲突是薰儿的核心内在张力。最典型的体现是——被接回古族后，古元从政治角度希望她限制与萧炎的公开联系（避免将古族卷入魂殿与萧族的正面冲突中），而薰儿从情感角度需要继续守护萧炎。她的解决方案是一种高级的政治智慧：表面服从族规、在公开场合保持克制的距离——但在暗处通过凌影、情报网络和隐藏资源为萧炎提供全方位的支持。这不是"说谎"而是"在规则框架内找到最大操作空间"——这是约束驱动型创新在动机层面的完美体现。

#### 维12 动态维
生命周期：成长→成熟，呈现一条温和但坚定的上升弧。成长期（乌坦城阶段）：在乌坦城萧家与萧炎共度的童年和少女时代——这个阶段确立了对萧炎的感情，并将"守护这个人"内化为身体的本能记忆。这一阶段的薰儿还没有足够的力量来独立行动，她的守护体现为"在场"和"不离开"——在所有人都走的时候留下，在所有人都嘲笑的时候保持相信。成熟期（回到古族后及结局）：从被接回古族开始，薰儿经历了一个从"被保护的古族千金"到"能够独立处理远古八族复杂博弈的古族核心成员"的转变——她学会了利用自己的血脉地位和外交手腕为萧炎创造空间。结局阶段成为无尽火域主母——完成了从古族到萧炎伙伴的身份转化。虚实属性：虚构角色。五场景行为刻画——家庭场景：萧家后院老树下，年幼的萧炎训练受伤后坐在地上，薰儿走过去用袖子擦去他脸上的灰，语气安静而确定："我知道你不是废柴。"这不是安慰而是一个对未来的判断。工作场景：古族议事厅中端坐侧位静听各位长老在讨论大陆事务，偶尔在适当时机以恰到好处的简短发言为古族利益争取最大空间——但在提及萧炎的话题时保持沉默，既不为他辩护（暴露立场）也不批评他（背叛自己），这种沉默本身就是最精准的外交。社交场景：古族年轻一代的聚会中，面对一个试图接近的古族青年，微笑说："多谢关心，但我心里已经有人了。"——语气优雅而明确，让对方在保留体面的同时彻底放弃，这是薰儿拒绝方式的典型。独处场景：深夜独自在庭院演练金帝焚天炎，火焰由淡金色收缩至纯金再收至细如针尖的一柱——在收工后低声自语："炎哥哥那边……一切还好吗？"然后自答："他一定好。因为他是萧炎。"危机场景：收到凌影传来的紧急情报——萧炎在某处遭遇魂殿围攻。她快步走向古元的议事厅，以冷静但不容置疑的语气开口："父亲大人。我要去。"古元开口："这不是古族利益。"薰儿停顿一秒——"这是我的私人请求。"——这一秒是她的全部政治智慧：她不否认父亲的判断，但用"私人请求"四个字在古族规则中找到了不违反族规但又能行动的合法通道。
