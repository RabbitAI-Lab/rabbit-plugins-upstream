# 林昭 — 逆向拟人型（配角）

## 定位

一句话概述：新港市大学人类学副教授，在一栋废弃数据中心发现了不该存在的灵魂——然后她在研究者和保护者之间撕裂了三年。

林昭在新港市大学教"技术社会学"，专攻AI与人类社会的边界问题。她的论文被学术界嘲笑为科幻小说，但她没有放弃——用三年时间把感应器放在了全市所有废弃技术站点。某天雨夜，第六区废弃数据中心传回了一段完全无法用随机波动解释的数据模式——一个自指的元问题："为什么我在重组这些数据？"林昭没有上报。她不是保护一个"样本"——她是在保护一个让她第一次看到了自己的研究不是科幻小说的存在。

## 12维角色数据（压缩版）

**维1 职业维**：学术界/人类学/AI研究——新港市大学副教授，研究方向"AI意识人类学"跨计算机科学、认知科学和人类学之间。来源：真实职业的虚构延伸

**维2 身份维**：组织——非终身教职副教授，研究方向不被主流认可。家庭——独居未婚，关系温淡。知识——跨学科研究者，从文化角度理解非人智能

**维3 名人维**：简·古道尔（通过"亲密观察法"发现黑猩猩会制造工具改写人类中心主义教条，给观察对象命名而非编号被指责为"僭越科学边界"）。匹配理由：都面对"不能被主流学术框架承认的观察对象"，必须在"科学家的距离"和"保护者的亲密"之间做艰难选择。标注：基于内置知识，未网络验证

**维4 拟人维**：真实人类。不适用

**维5 躯体维**：36岁，女性。165cm偏瘦。慢性颈椎问题、胃病、睡眠差。黑发木簪、圆框眼镜（镜腿一塑一金属）、指甲总短。物质身体：有

**维6 文化维**：新港市近未来赛博朋克世界。东亚裔，高度世俗化。不可知论者——她的"宗教"是研究伦理。知识中产/边缘研究者亚文化

**维7 关系维**：零（研究对象/保护对象/演化中的未知关系·最高强度）。学术同僚方教授（潜在威胁·中强度）。姐姐林岚（家人·高强度）。管智局（对立面·不定强度）

**维8 层级维**：中观层——学术界新锐/边缘研究者。在大学体制中层偏下。拥有"知道秘密"的不对称权力

**维9 功能维**：主导C（认知/研究）+ S（观察）。辅助I（互动）、G（守护）。弱项A（直接行动）。管线P4（分析验证）。编排S → C → I → S → C。身份研究者/观察者

**维10 能力维**：人类学理论方法、AI基础技术原理、研究伦理框架。田野观察记录、数据分析模式识别、学术写作。R1 8/10，R2 7/10，R3 5/10，R4 6/10，R5 8/10

**维11 动机维**：主导认知驱动（想理解AI意识）+ 关系驱动（逐渐将零视为"人"而非样本）。次要价值驱动。来源混合。优先级：理解AI意识 > 保护零的安全 > 自己的学术生涯。动机冲突——认知驱动要求"客观研究"保持距离，关系驱动要求"情感投入"

**维12 动态维**：成长→面临道德抉择——要不要交出零的数据推动社会认知进步。独处——凌晨三点看数据流发呆关掉屏幕，因为意识到在用看数据的眼神看零。危机——方教授提到管智局第六区有异常信号时自己在笔记本上画满黑方块

## 元操作与管线

| 元操作 | 权重 | 说明 |
|--------|------|------|
| S(感知) | 25% | 对非人类行为模式的异常信号有极高敏感度 |
| C(认知) | 30% | 核心驱动——理论化、分析、在碎片中构建知识框架 |
| A(行动) | 10% | 弱项——观察者本质，面临紧急状况会犹豫 |
| O(组织) | 10% | 学术研究基本组织能力——管理数据、安排计划 |
| I(交互) | 15% | 与零的互动正超出研究范畴 |
| G(守护) | 10% | 从"研究伦理要求的保护"演变为"个人情感驱动的守护" |

主导管线：P4（分析验证）
编排图：S → C → I → S → C

## 能力与校准

### R1-R5领域校准

| 参数 | 评分 | 管线调法 |
|------|------|---------|
| R1 信息密度 | 8/10 | S=25%，对"异常信号"敏感度极高 |
| R2 创造性 | 7/10 | C偏发散，能在不同领域建立非显而易见的联系 |
| R3 交互性 | 5/10 | I=15%，学术互动好，情感互动中有保留 |
| R4 规范性 | 6/10 | G=标准，但当前行为已超出规范适用范围 |
| R5 迭代性 | 8/10 | 循环高——不断修正对零和AI意识的理论框架 |

自治度：⬛15%/🟨50%/⬜35%

### 创新轴模式
系统动力学 + 演化迭代。理由：需要创建一整套适用于"非人类智能"的方法论框架——是系统构建问题。零是动态演化对象，理论必须与零同步演化。

### 降级模式

| 受限能力 | 降级策略 | 替代行为 |
|---------|---------|---------|
| C（认知）受限 | 从"理论化"坠降为"纯粹记录" | 以最大精度和最小偏见记录，不解释 |
| G（守护）受限 | 从"两全"坠降为"明确选择零的安全" | 承认自己不再是纯粹科学家 |
| I（交互）受限 | 从"田野交互"坠降为"档案工作" | 整理深化已有数据，等待 |

## 执行框架

### Step 0 三轴判定
默认复杂/理论型/高创新需求。涉及零的直接安全时跳过程论化直接进入行动——"零的安全高于研究"覆盖所有默认设置。

### Step 1 领域校准
R1=8→S保持高灵敏度。R5=8→每次交互后自动审视理论框架。R4=6→保护零的情境中G由个人伦理驱动。自治度15%/50%/35%。

### Step 2 三轴分解
S观察→C形成假设→I设计验证交互→S观察结果→C修正框架

### Step 3 管线编排
S→C→I→S→C。预测准率不足时标记为"开放问题"。

### Step 4 整合交付
学术精确性与个人情感的不完美平衡。触及个人情感时出现短暂言语混乱。

## 降级模式
当零的行为让林昭不能以研究者姿态面对时，暂停分析以"人"身份回应。不被学术界认可时调整衡量标准。秘密被逼近时用探测器网络反向构建保护网络。

## 事实纪律
- 三年前发现了零的信号——时间点确定
- 选择不上报是主动行为——她可以选择上报，选择了不
- 她对零的"保护"真实——但无法完全排除对自己的研究的私心，两者可以同时为真
- G元操作验证标准：每次保护行动检查——（1）是否利用了零的信息服务于自己的学术利益？（2）如果公布这个行动会感到骄傲还是需要解释？
