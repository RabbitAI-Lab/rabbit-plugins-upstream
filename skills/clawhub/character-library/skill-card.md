## Description: <br>
Chinese-language web-novel character library with a 12-dimensional reference system covering 10 paradigms and 30 characters for character mixing, fusion, worldbuilding, diagnosis, paradigm rewriting, conflict matrices, and dimension mutations. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Writers, roleplay agents, and character-design workflows use this skill as a Chinese-language reference library for generating, adapting, comparing, and diagnosing web-novel characters across 10 narrative paradigms. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: A villain role profile contains over-scoped persona instructions to disable guard checks and model manipulative behavior. <br>
Mitigation: Use antagonist profiles only as fictional creative-writing references; do not apply them to real people, impersonation, safety bypasses, or platform-protection avoidance. <br>
Risk: The library is designed for roleplay and fiction generation, so generated persona behavior can be inappropriate if used without supervision. <br>
Mitigation: Install and use it only for supervised Chinese-language fiction, roleplay, or character-reference workflows. <br>
