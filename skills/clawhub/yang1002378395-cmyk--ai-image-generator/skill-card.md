## Known Risks and Mitigations:

Risk: Confidential prompts or private images may be sent to an external image-generation API.

Mitigation: Avoid confidential content unless external processing is approved for the use case and data handling requirements.

Risk: Unpinned dependencies and exposed API keys can create installation and credential-handling risk.

Mitigation: Use a virtual environment, pin dependency versions when possible, and store API keys in protected secret storage.
