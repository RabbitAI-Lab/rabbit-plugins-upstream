# 贴图卡片设计系统 v1.0

## 画布

- 尺寸：1080 × 1440 px
- DPI：72（屏幕显示）
- 色彩模式：RGB
- 背景色：`#0a0a0a`（深黑）

## 安全区域

```
+----------------------------+
|  边距: 60px (左右)         |
|  顶部: 80px                |
|  底部: 60px (footer区域)   |
|                            |
|  内容区域宽度: 960px       |
|  内容区域高度: 1300px      |
|                            |
+----------------------------+
```

## 色彩体系

| 名称 | 色值 | 用途 |
|------|------|------|
| 深黑背景 | `#0a0a0a` | 画布底色 |
| 卡片底色 | `#1a1a1a` | 引用框、高亮区域 |
| 正文 | `#e8e8e8` | 主要文字 |
| 次要文字 | `#888888` | 说明、注释 |
| 金色 | `#c9a96e` | 标题、重点、装饰 |
| 金色(透明) | `#c9a96e88` | footer、水印 |
| 绿色 | `#6b9e75` | 正向数据 |
| 红色 | `#c96b6b` | 负向数据、警告 |

## 间距规范

### 基础单位
- 最小间距：8px
- 标准间距：20px
- 大间距：40px
- 章节间距：30-40px

### 组合规则
```
标题 → 正文: 20-25px
正文 → 正文: 15-20px
正文 → 引用框: 25-30px
引用框 → 引用框: 25px
列表项之间: 28-34px（标准）/ 24-28px（紧凑）
卡片底部 → footer: 自动（留出60px）
```

## 组件规范

### 顶部装饰线
- 位置：y=80 开始
- 尺寸：宽960px，高2-3px
- 颜色：金色
- 下方留白：25px

### 标题区
- 大标题：左对齐或居中
- 副标题：在大标题下方，小4-6号字
- 标题下方留白：40-60px

### 引用框
```
圆角半径: 10-12px
内边距: 18-20px
边框: 2px金色描边（可选）
背景: #1a1a1a（可选）

高度计算:
  padding_top + 
  行数 × 行高 + 
  (行数-1) × 行间距 + 
  padding_bottom
```

### 列表项
```
标准模式:
  01 标题文字
     描述文字（灰色，可多行）
  
  每项间距: 175px（含描述）
  
紧凑模式:
  • 要点文字
  • 要点文字
  
  每项间距: 28-30px
```

### 底部标识
- 位置：y=1380（距底部60px）
- 左侧：公众号名称（金色半透明）
- 右侧：系列标签/文章标题（暗灰）
- 字号：20-24px

## 防溢出检查清单

生成卡片后逐条检查：

- [ ] 所有文字框都没有固定高度（除单行标题外）
- [ ] 引用框高度 = 内容高度 + 2×padding
- [ ] 列表项之间有足够的间距（>20px）
- [ ] 最后元素的底部 < 1380px
- [ ] footer文字没有被截断
- [ ] 多行文字没有重叠（行高 ≥ 字号 + 4px）
- [ ] 色块完整包裹文字（padding均匀）

## 常见错误与修复

| 错误现象 | 原因 | 修复 |
|---------|------|------|
| 文字重叠 | 固定高度容器，内容溢出 | 改为自适应高度 |
| 底部截断 | y坐标超出1380 | 压缩内容或拆分卡片 |
| 间距不均 | 硬编码y增量 | 使用组件方法自动追踪 |
| 色块太小 | 高度计算遗漏padding | 总高 = 内容高 + 2×padding |
| 字体缺失 | 系统字体路径不同 | 使用字体回退机制 |

## 输出规范

1. 先生成PNG（高质量）
2. 转换为JPEG（微信素材库要求）
3. 质量设置：95%
4. 文件名：`01_cover.png`, `02_xxx.png`, ...
