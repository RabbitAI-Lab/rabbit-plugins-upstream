## Use Case: <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill adds a persistent remote MCP server for a personal public site. <br>
Mitigation: Install it only if you are comfortable with that connection, and remove the MCP client entry when access is no longer needed. <br>
Risk: Returned resume, portfolio, and blog content is served by an external personal site and may change over time. <br>
Mitigation: Treat responses as current public site content and review important details before relying on them. <br>
