## Description:

Guides controlled photoreal image generation with readable in-image text and structured layouts through Pruna's P-Image-Ideogram model.

This skill is ready for commercial/non-commercial use.

## Publisher:

[pruna-ai](https://clawhub.ai/user/pruna-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators, marketers, and developers use this skill to plan and generate photoreal images, branded visuals, and layouts with readable text or precise placement.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Image prompts and generation settings are sent to Pruna's API using a Pruna API key.

Mitigation: Avoid including sensitive content in prompts and use a securely managed API key.

Risk: Example install commands use floating package references.

Mitigation: Pin reviewed versions or verify the source before installing dependencies.
