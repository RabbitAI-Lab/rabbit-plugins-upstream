## Description:

Audits HTML accessibility and suggests targeted fixes for accessible names, keyboard access, focus, contrast, and form errors.

This skill is ready for commercial/non-commercial use.

## Publisher:

[qikairo7](https://clawhub.ai/user/qikairo7)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to review UI code for accessibility issues and propose small, prioritized fixes for interactive elements, forms, and dialogs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Suggested accessibility edits may change existing UI behavior.

Mitigation: Review targeted changes and check keyboard navigation, focus, labels, and form errors before merging.
