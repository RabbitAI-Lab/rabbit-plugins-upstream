## 零、强制规则：网址 + 诊断类词 → P8（**最高优先级，覆盖 §一 S0–S4**）

> 用户常把「**网站**」和「**网络**」混说（如「网络诊断」「网络检测报告」）。**不要纠正用户用词**，只要同时满足下面两类信号，**一律 P8 网站诊断**，禁止走 P9 行业报告、P1 账户诊断、P4 周期报告，**禁止** §五 A/B/C/D 追问。

### 0.1 网址类信号（命中任一即可）

- 可解析 URL：`http://` / `https://` / `www.` / 裸域名（`example.com`、`xxx.cn`）
- 口语：**网址**、**官网**、**域名**、**链接**、**落地页**、**网站地址**、**主页**、**网站链接**
- 用户粘贴的字符串**像域名或 URL**（含 `.com` / `.cn` / `.net` 等）

### 0.2 诊断类信号（近义词 / 同义词，命中任一即可）

| 类别          | 常见说法（含错字 / 口语）                                                                                                                                                                                               |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 核心          | **诊断**、**检测**、**监测**、**监控**、**评估**、**评测**、**体检**、**审查**、**核查**                                                                                                                                |
| 报告向        | **报告**、**分析报告**、**诊断报告**、**检测报告**、**监测报告**、**评估报告**、**质量报告**                                                                                                                            |
| 网站/网络混用 | **网站诊断**、**网络诊断**、**网站检测**、**网络检测**、**网站监测**、**网络监测**、**网站分析**、**网络分析**、**网站体检**、**网络体检**、**网站评分**、**网络质量**                                                  |
| 落地页        | **落地页诊断**、**落地页检测**、**落地页报告**、**页面质量**、**页面检测**                                                                                                                                              |
| 投放前        | **能不能投**、**适不适合投广告**、**符合广告投放要求**、**是否符合投放要求**、**符不符合 Google 广告**、**适不适合投 Google 广告**、**网站好不好**、**官网行不行**、Lighthouse、PageSpeed、**速度检测**（**且带网址**） |

### 0.3 命中后的 Agent 行为（强制，100% 走 CLI）

1. **直接定工作流 P8** → Read `playbooks.md` P8 + `website-diagnosis-guide.md`。
2. **必走 CLI 闭环**：`siluzan-tso website-diagnosis collect --url <url> --json-out ./snap-web --include-html` → `prepare` → 按 rules 补全 `diagnosis.json` → `website-diagnosis render` 出 HTML。
3. **有 URL 就开工**：缺 URL 才问一句「请发完整网址」；**禁止**因用户说「网络」而非「网站」改走 P9 或账户诊断。
4. **提到「Google 广告」仍是 P8**：只要诉求是「能不能投 / 是否符合投放要求 / 适不适合投」而**没有**「生成搜索广告方案 / 关键词表 / campaign JSON」，**禁止**改走 W3，也**禁止**用 WebFetch/WebSearch 肉眼看官网写结论代替 CLI。
5. **唯一例外（仍不是 P8）**：用户**同时**明确要求 **生成 Google 搜索广告 / 关键词表 / 投放方案 / 广告文案**（W3 强意图）→ 走 **W3**，见 §四。

### B.2 命中后的 Agent 行为（强制）

### B.3 禁止事项

- **禁止**跳过 `collect` / `render`，用纯 WebSearch / WebFetch 在对话里写 Markdown 或 HTML 当终稿。
- **禁止**改走 P8 网站诊断、P1/P4 账户报告、W5 拓词、`google-analysis`。
- **禁止**因用户未提"丝路赞 / TSO / 广告"就认为本 skill 不适用——行业/市场分析报告即本 skill P9 的职责。

## 零·C、强制规则：Google Ads 关键词规划 / 拓词 → W5（**§零 未命中时**，100% 走 `keyword` CLI）

> 用户要 **Google Ads / Keyword Planner 口径** 的关键词推荐表（含 **月搜索量、竞争度、CPC** 等市场指标），或「**阅读网址/文章** + **针对核心词/种子词** 出长尾词表」，**一律 W5**。须用 `siluzan-tso keyword` 拉真实指标，**禁止** WebSearch / WebFetch 编造搜索量当终稿。**无论用户是否提及丝路赞 / TSO / 广告账户**——只要命中下方拓词信号即加载本 skill。

### C.1 信号词（命中任一即可；**与 §零 诊断类词不冲突**——本段不要求「诊断/检测/报告」）

| 类别   | 常见说法（含口语 / 英文）                                                                                                |
| ------ | ------------------------------------------------------------------------------------------------------------------------ |
| 核心   | **拓词**、**关键词规划**、**关键词推荐**、**Keyword Planner**、**Google Ads 关键词**、**谷歌广告关键词**、**搜索词推荐** |
| 指标向 | **月搜索量**、**搜索量**、**search volume**、**竞争度**、**competition**、**CPC**、**出价区间**                          |
| 词面向 | **长尾关键词**、**long-tail keywords**、**核心词**、**种子词**、**针对每个核心词**、**扩词**、**词包**                   |
| 语境向 | **阅读（此）网址/文章/页面** + 出 **Google** 关键词；粘贴 **产品英文词表** + 要 **带搜索量** 的推荐                      |

### C.2 命中后的 Agent 行为（强制）

1. **直接定工作流 W5** → Read `workflows.md` W5 + `analytics/keyword-planner-workflows.md`。
2. **必走 CLI**：`siluzan-tso keyword -k "种子1,种子2,..." [--url "<落地页>"] [--geo <id>] --google-only --json-out ./snap-kw`（要官方 Planner 指标时 **必加 `--google-only`**；多核心词 **分批** `-k`，避免单次 body 过大）。
3. **网址/文章**：可用 WebFetch 读页面 **仅归纳种子词与产品语境**；**月搜索量 / 竞争度 / CPC 只能来自 `keyword` 落盘 JSON**（字段 `montlySearch`、`competition`/`competitionV2`、`averageCpc` 等），脚本过滤（如「约 3000 搜索量、竞争中低」）后再交付表格。
4. **交付列**（用户未指定时）：英文关键词、中文翻译、所属核心词、月搜索量、竞争度；表头注明 **数据来源：Google Keyword Planner（`keywordidea/google`）**。

### C.3 与 W3 / P8 / P9 区分

| 用户侧重点                                                      | 正确工作流 | 典型错误                       |
| --------------------------------------------------------------- | ---------- | ------------------------------ |
| 要 **词表 + 搜索量/竞争度**（无 campaign JSON / validate）      | **W5**     | 纯 WebSearch 编数；或误走 W3   |
| **阅读 URL/文章** + 针对 **核心词列表** 出 **Google 拓词表**    | **W5**     | 误走 P8（无诊断类词）；误走 P9 |
| 根据官网 **生成完整 Google 搜索广告方案** / `campaign-validate` | **W3**     | 误走 W5 只出词表就停           |
| **网址 + 诊断/检测/监测/报告**（§零）                           | **P8**     | 误因带 URL 走 W5               |

### C.4 禁止事项

- **禁止**跳过 `keyword`，用 WebSearch / 模型臆测 **月搜索量、竞争度** 充当终稿。
- **禁止**因用户未提「丝路赞 / TSO / 账户 ID」就认为不适用本 skill。
- **禁止**把「阅读文章归纳行业词」当作 Planner 指标来源（文章 → 种子；指标 → CLI）。

| ----------------------------------------------------------------------------------------------------------------------- | ------ |

## 零·D、强制规则：转化成本 / CPA / 零转化 /「零询盘」巡检（无 CRM）→ P3

> 线上高频「**转化成本监控 / 昨日零询盘 / CPA 过高**」指的是 Google Ads **账户级转化次数与 CPA**，**不是** P7（P7 要用户上传 CRM 询盘明细）。命中下方信号且**未附带询盘附件/字段表**时，**一律 P3**，用 `accounts-digest`（可加 `--max-cpa` / `--zero-conversions`）。

### D.1 信号词（命中任一即可；且无 CRM 询盘资料）

| 类别     | 常见说法                                                                                   |
| -------- | ------------------------------------------------------------------------------------------ |
| 成本向   | **转化成本**、**CPA**、**每次转化费用**、**cost per conversion**、**转化费用过高**         |
| 零转化向 | **零转化**、**0 转化**、**无转化**、**有消耗无转化**                                       |
| 口语询盘 | **零询盘**、**0 询盘**、**无询盘**、**昨日询盘**（**且未**上传询盘 Excel/CSV/截图/字段表） |
| 监控向   | **转化成本监控**、**CPA 监控报告**、**低余额账户转化成本**、**谷歌 ADS 转化成本**          |

### D.2 命中后的 Agent 行为（强制）

1. **直接定工作流 P3** → Read `playbooks.md` P3 + `accounts-balance-stats.md`（§ accounts-digest）。
2. **必走 CLI**：确认区间后 `accounts-digest -m Google … --start <S> --end <D> --json-out ./snap-p3`；高 CPA 加 `--max-cpa <n>`；零转化/零询盘巡检加 `--zero-conversions`。
3. **需要转化动作明细**（conversion actions 拆解）时升 **P5**：`google-analysis-batch run --sections overview,conversion-actions …`（仍**禁止**当 P7）。
4. **唯一例外 → P7**：用户**同时**给出 CRM 询盘资料（附件或粘贴字段表）且要「询盘效果 / 询盘分析」→ 走 **P7**。

### D.3 禁止事项

- **禁止**把「零询盘 / 转化成本」口语一律当成 P7（无 CRM 附件时）。
- **禁止**猜 `--period` / `--date-start`；只用 `--start`/`--end`（或 `--start-date`/`--end-date`）。
- **禁止** WebSearch 编造转化/CPA；`conversions`/`cpa` 为 null 时写「转化未返回」，**禁止**对 null 做数值比较导致脚本崩溃。
- **禁止**只落盘 JSON 不向用户交付排序表或「无命中」说明。

## 五、一次追问模板（S4：只允许 1 个问题）

用户**只说**「帮我出份报告 / 做个诊断 / 分析一下」且 **§零、S0–S3 均未命中** 时，用下面 **四选一**（选最省事的 1 条）：

> 您要的更像是哪一种？回复 **A/B/C/D** 即可：  
> **A** — **网站/落地页**质量报告（需要发我 **网址**）→ P8  
> **B** — **行业/市场**战略报告（需要 **行业或客户名**，**不是**网址检测）→ P9  
> **C** — **Google 广告账户**诊断或周期报告（需要 **账户 ID**）→ P1 或 P4  
> **D** — 根据官网 **生成 Google 搜索广告方案**（需要 **网址 + 预算/地域**）→ W3

**§零 已命中时禁止本段追问**（例如用户已给 URL 并说「网络诊断」→ 直接 P8）。
