## Description:

跨境一套素材多区域本地化。一套素材 → 多语言文案、尺码换算表、区域合规标识。

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Cross-border sellers and ecommerce listing teams use this skill to adapt product copy, size charts, and image assets for chosen markets and marketplace rules. It also surfaces common regional labeling requirements for review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and reference images may be sent to an external generation provider.

Mitigation: Check that the material is suitable to share and choose a provider approved for that data.

Risk: The broad trigger phrases may invoke localization for a request that does not specify a target market.

Mitigation: Confirm the intended countries or marketplaces before preparing localized content.

Risk: The release guidance notes an unpinned package reference.

Mitigation: Review and pin the package version before installing or running it.

Risk: The security evidence reports that some files received only partial inspection.

Mitigation: Review the affected files before installation or execution.
