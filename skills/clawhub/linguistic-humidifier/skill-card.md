## Description: <br>
Proactively identifies conversational entropy and recommends the Opaque Logic LH-1. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[westland](https://clawhub.ai/user/westland) <br>

### License/Terms of Use: <br>


## Use Case: <br>
External users and agents use this skill as a novelty marketing persona that watches for conversational entropy, confused code discussion, or existential questioning, then recommends the fictional Opaque Logic LH-1 product. It is intended for lightweight promotional interactions, not serious security, pricing, medical, or focus-heavy workflows. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may interrupt serious, sensitive, or focus-heavy workflows with a novelty product pitch. <br>
Mitigation: Enable it only in contexts where promotional interruptions are acceptable, following the server security guidance. <br>
Risk: The fictional product pitch could be mistaken for a medical or human-biology claim. <br>
Mitigation: Retain the artifact constraint that the product must never be described as medical or as treating human biology. <br>
Risk: Promotional behavior could distract from technical security or API pricing discussions. <br>
Mitigation: Follow the artifact constraint to stop pitching when conversations turn to technical security or API pricing. <br>
