## Description:

Guides agents to retrieve and cite structured Google search results through Scavio, including organic links, knowledge graph data, related questions, and AI overviews.

This skill is ready for commercial/non-commercial use.

## Publisher:

[scavio-ai](https://clawhub.ai/user/scavio-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and other agents use this skill to look up current information, summarize cited search results, or adapt Google Custom Search integrations to Scavio's compatible endpoint.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Search queries and localization details are sent to Scavio using a Scavio API key.

Mitigation: Avoid searching confidential, personal, regulated, or internal-only content unless third-party search is approved; store the key securely.
