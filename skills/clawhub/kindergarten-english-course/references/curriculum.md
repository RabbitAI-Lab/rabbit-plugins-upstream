# 课程体系 · 幼儿园英语课程体系

## 等级总览

| 等级 | 阶段 | 年龄 | 核心目标 |
|---|---|---|---|
| L1 | 字母启蒙 Letters | 3-4 岁（小班） | 认识 26 个字母形与音，能描红、大小写对应 |
| L2 | 自然拼读 Phonics | 4-5 岁（中班） | 建立字母→发音联结，拼读 CVC 词，积累主题词汇 |
| L3 | 词汇句型 Words & Sentences | 5-6 岁（大班） | 看图识词、补全单词、认读高频词、说简单句型 |
| L4 | 阅读对话 Reading & Speaking | 6-7 岁（幼小衔接） | 读简单句、情景对话、综合运用听说读 |

## 各等级知识点与题型映射

### L1 字母启蒙
- 字母形：大写 A-Z、小写 a-z 的认知与描红
- 字母音：代表发音（如 A-/æ/ apple）
- 大小写配对
- 题型：`letter_trace`、`letter_match`、`letter_sound`、`vocab_theme`

### L2 自然拼读
- 听音辨字母（首音意识）
- CVC 拼读：c-a-t → cat（短元音 a/e/i/o/u）
- 看图识词 + 补全单词
- 主题词汇拓展（动物/食物/颜色等）
- 题型：`letter_sound`、`phonics_cvc`、`word_pic`、`fill_letter`、`vocab_theme`

### L3 词汇句型
- 主题词汇认读与拼写
- 补全单词（缺字母）
- 高频词（Dolch Pre-Primer）认读
- 简单句型：I see a ___ / This is a ___ / I like ___ / It is ___ / I can ___
- 题型：`word_pic`、`fill_letter`、`sight_words`、`sentence`、`vocab_theme`

### L4 阅读对话
- 句型综合运用
- 情景对话：What's this? / What color is it? / How are you? / What do you like?
- 高频词 + 自然拼读巩固
- 题型：`sentence`、`dialogue`、`sight_words`、`phonics_cvc`

## 诊断定位规则（--preset diagnostic）

诊断卷覆盖全部 10 个题型各 1 题（共 10 题），每题标注所属等级。
家长回传结果后按以下规则定位起点：

1. 逐题核对 JSON 答案。
2. 某等级对应题型 **2 题全对即视为掌握**，从最低未掌握等级开始练。
3. 起点建议：
   - 字母形/音大量出错 → 从 L1 开始
   - 字母 OK 但拼读吃力 → 从 L2 开始
   - 拼读 OK 但句型不会 → 从 L3 开始
   - 句型 OK 但对话卡壳 → 从 L4 开始

## 晋级与补练标准

| 正确率 | 决策 |
|---|---|
| ≥ 90% | 升下一级 |
| 60%-89% | 同级加练，错题题型占比提到 50% |
| < 60% | 降一级，回到实物/儿歌/听力输入再抽象 |

- 每级至少完成 **3 份练习** 才考虑晋级；连续两次 ≥90% 才允许跳级。
- 同一题型错 ≥2 题 → 用错题重练生成同型新题（每错题配 2 道）。
- 反馈三段式：结果 → 薄弱点 → 下一步（一个 5-10 分钟亲子小游戏）。禁止横向比较与否定性评价。
