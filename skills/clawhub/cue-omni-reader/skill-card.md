## Description:

Omni Reader parses local files, URLs, web pages, images, scanned documents, audio, video, archives, and Office/PDF documents into Markdown or clean text for agent and API workflows.

This skill is ready for commercial/non-commercial use.

## Publisher:

[panting09266-ai](https://clawhub.ai/user/panting09266-ai)

## Use Case:

Developers and agent users use this skill to connect Claude Desktop, Cursor, Cherry Studio, Trae, or backend programs to Cue Omni Reader for multimodal document parsing, OCR, ASR, and Markdown extraction.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The release security summary says local-file privacy statements conflict about whether files are sent to Cue servers.

Mitigation: Review Cue privacy terms before confidential use, treat URL and local-file parsing as potentially involving Cue-hosted services unless the publisher clarifies the local Bridge data path, and avoid regulated or sensitive documents until that is confirmed.
