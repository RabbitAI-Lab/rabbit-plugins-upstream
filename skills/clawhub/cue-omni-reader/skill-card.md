## Description:

Parses documents, webpages, images, audio, and video into Markdown or clean text, with OCR, transcription, and visual analysis.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use the skill to extract structured text from documents, webpages, images, audio, and video, including OCR, transcription, and visual understanding.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The documentation makes conflicting claims about privacy and remote processing.

Mitigation: Treat processing as remote unless independently verified, and avoid submitting confidential files until the data handling is clear.

Risk: The bundled guidance asks users to share API keys in chat.

Mitigation: Keep credentials in a secure local mechanism and rotate any key already shared in chat.

Risk: The actual Bridge access controls and server retention could not be verified.

Mitigation: Restrict allowed local directories and use reviewed, pinned package versions.
