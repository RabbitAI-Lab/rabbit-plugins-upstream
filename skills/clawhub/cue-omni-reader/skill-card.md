## Description:

Converts user-provided documents, images, audio, video, and web pages into Markdown or clean text using OCR, transcription, and visual analysis.

This skill is ready for commercial/non-commercial use.

## Publisher:

[panting09266-ai](https://clawhub.ai/user/panting09266-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and other external users can extract searchable text, tables, transcripts, and visual context from documents and media for downstream analysis.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill's privacy and local-file/API-key handling instructions are contradictory, leaving document processing and retention unclear.

Mitigation: Before use, confirm where documents are processed and retained; keep API keys out of chat and agent-visible output, authorize only necessary directories, and approve exact-version installation or configuration changes. Avoid confidential documents until the privacy guidance is resolved.
