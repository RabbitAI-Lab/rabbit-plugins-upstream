# 金融理论大师 Skill

金融理论知识框架与理论选型 skill。系统整理资产定价、投资组合、有效市场假说、行为金融、公司金融、货币与宏观金融、风险管理七大板块的核心命题、关键模型、前提假设、适用场景与已知局限，并提供跨理论对比矩阵、假设强度排序与理论关系图。

**核心信条：没有一个金融理论在所有场景下成立。判断一个理论用得对不对，先看它的假设在当前场景里成不成立。**

## 五个核心设计

### 1. 用一条统一线索串起七个板块

所有资产定价理论都是同一个恒等式的不同填法：`p = E(mx)`。CAPM、CCAPM、多因子模型、期权定价的差别，只在于如何指定那个随机贴现因子 m。这条线索把看上去分散的板块变成一个有骨架的体系。

### 2. 用五条元判断约束所有理论的使用

| # | 元判断 | 作用 |
|---|--------|------|
| 1 | 联合假说问题 | 检验市场有效性必须先假定资产定价模型，两者不可分离检验 |
| 2 | 假设强度与结论锐利度成反比 | 理论选型的第一把尺子 |
| 3 | 收益差异只有三种解释 | 风险补偿 / 错误定价 / 数据挖掘，先分类再讨论 |
| 4 | 宏观金融的经验证据远多于共识模型 | 这一板块没有教科书答案 |
| 5 | 模型是坐标系不是真值 | Black-Scholes 假设全错但仍是行业报价标准 |

### 3. 用实证地位标签强制标注争议

每个理论都带一个状态标签。有实质性分歧的（CAPM、EMH 半强式、明斯基、MMT、泰勒规则、VaR、UIP）必须写出分歧双方，不允许挑一边说。

### 4. 用历史模块给理论定坐标

**制度先于理论出现。** 汇票早于国际贸易理论九百年，英格兰银行早于货币政策理论两百多年，金本位早于国际收支调节理论。把理论当成制度的原因，是金融写作最常见的错误之一。

历史模块提供三件理论模块给不了的东西：

| 工具 | 作用 |
|------|------|
| 理论-历史对照表（32 组） | 每个理论回应的具体历史困境是什么，从而知道它的边界在哪里 |
| 12 条常见误传的纠错清单 | 郁金香泡沫的真实规模、1929 与萧条的因果关系、布雷顿森林不是纯粹固定汇率等 |
| 人物与机构索引 | 44 位人物、28 个机构，按领域与时期定位 |

历史部分的证据标准与理论部分不同：**理论看统计显著性，历史看史料可靠性。** 两者不能混用，SKILL.md 第七节给出了四级标准。

### 5. 把政策判断与投资判断分开，并强制标注幸存者偏差

政策分析最容易犯的错是把**目标**当成**效果**。所以政策工具箱对每项工具都要求写清目标、机制、时滞、失效条件四项，缺一项就视为不完整。

案例部分则有一条硬约束：**每个案例必须标注幸存者偏差。** 每一个成功案例背后都有大量做同样判断但没成功的人。不标注偏差的案例集，会把运气包装成能力。数据集的 `survivorship` 字段是必填项（≥8 字符），测试会检查。

同时明确一条边界：**本模块只判断方向与机制，不给幅度与时点预测。** 方向判断的正确率显著高于幅度与时点的判断正确率，把前者当后者用是最常见的误用。

## 快速上手

```bash
cd finance-theory-master

# 检索理论（关键词大小写不敏感，命中 0 条会显式失败并返回退出码 2）
python scripts/theory_lookup.py -k 波动率
python scripts/theory_lookup.py -m 货币宏观
python scripts/theory_lookup.py -t 极强
python scripts/theory_lookup.py -s 有争议
python scripts/theory_lookup.py --id capm
python scripts/theory_lookup.py --list

# 重新生成索引并校验
python scripts/gen_data.py
python scripts/gen_data.py --check
python scripts/validate_data.py

# 测试
python -m pytest tests/ -q
```

## 素材来源与已知局限

| 素材来源 | 本次采集结果 | 影响 |
|---------|------------|------|
| 历史对话记录 | 检索未命中（检索工具本次仅覆盖 2026-10-01 至 10-08，返回 0 条） | 未纳入个人历史观点 |
| ima 个人知识库 | 仅 1 个个人库且内容为空 | 未纳入知识库素材 |
| 网络公开资料 | 已采集，覆盖因子动物园、复制研究、VaR 局限、明斯基、泰勒规则、三元悖论、A 股有效性等 | 作为主要来源 |
| 金融学标准文献 | 作为框架与核心命题的主要依据 | 作为主要来源 |

**三点须知：**

1. **本框架的骨架来自金融学主流文献体系，不是个人原创观点。** 引用时溯源到原始文献，不要溯源到本 skill。
2. **实证数字有采集时点。** 因子复制研究、VaR 危机表现、A 股投资者结构等数据会更新，给出具体数字时应说明时点。
3. **文献的卷期页码未逐条核录。** 正式引用前请核对原文；出处记不清的一律标注「待核」，不使用看似合理的假信息填充。
4. **历史部分的年份与数字存在学界争议。** 《汉谟拉比法典》的绝对年代、铸币发明的具体时间、复式记账的最早使用地点、16 世纪通胀幅度、古代利率水平，均有不同估计。本 skill 给出的是常用区间，并已标注「学界存在不同估计」。非西方金融史（伊斯兰金融技术、中国货币史、印度与东南亚信用制度）只做了要点性覆盖，未展开。
5. **投资案例的收益数字为广泛报道口径。** 案例中的获利规模来自公开报道，可能存在出入，已在 `references/14-*` 与 `data/investor_cases.csv` 中标注。案例仅用于展示推理方式，**不构成任何投资建议**。
6. **政策工具的效果受制度条件制约。** 同一工具在成熟市场与非西方市场的效果差异可能极大。非西方场景需额外检查外储覆盖、货币错配、央行独立性、管制程度四项约束（见 `references/15-*`）。
7. **争议性政策案例无学术共识。** 马来西亚资本管制、国际货币基金组织条件的评价等，学界存在实质分歧，引用时必须写出双方论点。

## 不适用场景

| 场景 | 处理 |
|------|------|
| 要求用理论推导收益预测 | 拒绝 |
| 要求预测危机时点 | 拒绝。明斯基框架的事前预测力弱是其已知性质 |
| 需要具体行情与财务数据 | 转 `finance-master` 或数据类 skill |
| 期货开平仓决策 | 转 `futures-master` |
| 基金筛选与组合诊断 | 转 `fund-master` |
| 代写论文并伪造文献 | 拒绝 |
