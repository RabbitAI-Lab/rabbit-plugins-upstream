# 01 资产定价理论

## 一、这一板块回答什么问题

同一个市场上，为什么有些资产的长期平均收益更高？高出多少算「合理」？价格是怎么被定出来的？

资产定价理论的全部内容，可以归结为一个恒等式和围绕它的填空。

---

## 二、统一框架：所有资产定价理论都是同一个式子的不同填法

### 2.1 现值恒等式

任何资产的价格都等于其未来所有支付的现值之和：

```
P = Σ E(CF_t) / (1 + r_t)^t
```

对股票若假设现金流按固定增长率 g 永续增长，得到**戈登增长模型**：

```
P = D_1 / (r - g)
```

这个式子不是理论，是定义。所有争论都集中在一点：**贴现率 r 该取多少，它的经济学含义是什么。**

### 2.2 随机贴现因子（SDF）框架

Cochrane 在《Asset Pricing》里把这个式子改写成更一般的形式：

```
p = E(m · x)
```

其中 x 是未来支付，m 是随机贴现因子（又称定价核、状态价格密度）。这一写法把资产定价的全部内容压缩成一句话：**给 m 指定一个经济学含义。**

| 理论 | 对 m 的指定 |
|------|-----------|
| CAPM | m 是市场组合收益的线性函数 |
| CCAPM | m 是消费增长率的函数，m 与边际效用成正比 |
| 多因子模型 | m 是若干因子收益的线性组合 |
| 期权定价 | 不走 m 的路线，改走无套利 + 动态复制 |

**使用方法：** 讨论任何资产定价理论时，先问「它把 m 设成了什么」，再看这个设定是否合理。这比记住一堆公式有效率得多。

## 三、资本资产定价模型（CAPM）

### 3.1 核心命题

```
E(R_i) = R_f + β_i · [E(R_m) - R_f]
β_i = Cov(R_i, R_m) / Var(R_m)
```

含义：**只有系统性风险被定价。** 可分散掉的风险不该拿到补偿，因为投资者可以免费消除它。

### 3.2 前提假设

| # | 假设 | 现实情况 |
|---|------|---------|
| 1 | 投资者只关心单期收益的均值与方差 | 长期投资者关心多期，也关心偏度和尾部 |
| 2 | 投资者同质预期，对参数看法一致 | 分歧是市场存在的前提 |
| 3 | 可按同一无风险利率无限借贷 | 借入利率普遍高于借出利率 |
| 4 | 市场无摩擦（无税、无交易成本） | 两者都存在且显著 |
| 5 | 资产可无限分割 | 多数资产有最小交易单位 |
| 6 | 存在无风险资产 | 长期看不存在真正的无风险资产（通胀风险、再投资风险） |
| 7 | 单期模型 | 投资者的期限结构差异被忽略 |

### 3.3 关键推论

1. 市场组合（所有风险资产按市值加权的组合）是均值方差有效的
2. 所有投资者持有同一个风险资产组合，只在无风险资产与它之间的比例上不同（**两基金分离**）
3. beta 是唯一被定价的风险维度

### 3.4 局限（分三层）

**假设层**

- 同质预期与无摩擦市场是极端假设，且这两条不是「近似成立」而是「近似不成立」
- 单期设定与真实的长期投资行为不匹配

**实证层**

- 横截面上，低 beta 组合的长期收益高于 CAPM 预测（低波动率异象、BAB 因子）
- 规模、价值、动量、盈利、投资等维度的收益差异，CAPM 无法解释
- Fama-French 1992 的研究表明规模和账面市值比在横截面上有解释力，而 beta 没有

**方法论层（最严重）**

**Roll 批判（1977）：** CAPM 要求用「市场组合」，即所有风险资产的市值加权组合，包括未上市公司、房地产、人力资本、艺术品等。这个组合**不可观测**，任何用股票指数代替它的检验，检验的都不是 CAPM 本身。

后果是：CAPM 严格意义上**不可检验**。所有实证都是在检验「股票指数作为市场组合代理的 CAPM」。

### 3.5 那它还能不能用

能。但要分清目的：

| 使用目的 | 是否可用 | 说明 |
|---------|---------|------|
| 估算资本成本（WACC 的权益成本） | 可用 | 行业标准做法，虽不精确但可比较 |
| 绩效归因（分解 alpha 与 beta） | 可用 | 作为基准仍有信息量 |
| 风险分解（区分系统性/非系统性） | 可用 | 概念框架清晰 |
| 精确预测个股收益 | 不可用 | 横截面解释力弱 |
| 唯一真理式的定价 | 不可用 | Roll 批判未解决 |

**实证地位：有争议（横截面表现被实质削弱，但作为基准与语言仍被广泛使用）。**

## 四、套利定价理论（APT）

### 4.1 核心命题

Ross（1976）提出。收益率与一组系统性因子线性相关：

```
R_i = a_i + b_i1 F_1 + b_i2 F_2 + ... + b_ik F_k + ε_i
```

构造无套利组合后推出：

```
E(R_i) = R_f + Σ_j β_ij · λ_j
```

其中 λ_j 是因子 j 的风险溢价。

### 4.2 与 CAPM 的关键差别

| 维度 | CAPM | APT |
|------|------|-----|
| 理论基础 | 一般均衡 | 无套利 |
| 前提假设 | 强（均值方差偏好、同质预期等） | 弱（不要求同质预期，不要求市场组合） |
| 因子数量 | 单一（市场组合） | 多个，但不指定是哪些 |
| 因子内容 | 明确指定为市场组合 | **不指定，需使用者自行选择** |
| 可检验性 | 受 Roll 批判困扰 | 因子未指定前难以证伪 |

### 4.3 局限

**因子未指定是 APT 最大的问题，也是它最大的用途。**

- 问题：APT 只说「有若干因子」，不说是什么因子。这使得它难以被证伪，也使得实证研究有极大自由度去构造「显著」的因子
- 用途：它提供了**多因子框架的合法性**。Fama-French 模型、Q 因子模型在方法论上都可以看成 APT 的具体实现
- 严格推导需要「资产数量足够多」和「不存在近似套利机会」，这两条在实践中都不精确成立

**从 APT 到「因子动物园」只有一步：** 既然因子没被指定，只要肯试，总能找到统计上显著的因子。这正是 2016 年之后「因子动物园」问题的直接源头。

**实证地位：作为框架稳健（多因子结构本身成立），作为具体模型需配合因子选择，有争议。**

## 五、多因子实证模型

### 5.1 模型演进

| 模型 | 年份 | 因子构成 | 解决的问题 |
|------|------|---------|-----------|
| CAPM | 1964–66 | 市场 | 基础 |
| Fama-French 三因子 | 1993 | 市场、规模（SMB）、价值（HML） | 解释规模与价值异象 |
| Carhart 四因子 | 1997 | 加动量（UMD） | 解释动量异象 |
| Fama-French 五因子 | 2015 | 加盈利（RMW）、投资（CMA） | 用盈利与投资统一解释多个异象 |
| Fama-French 六因子 | 2018 | 加动量 | 补齐 |
| Q 因子模型 | 2015 | 市场、规模、投资、ROE（Hou-Xue-Zhang） | 用 neoclassical q 理论重构因子 |

**FF5 的自我修正意义：** 三因子模型在 1993 年提出后，二十多年里发现了大量它解释不了的异象。FF5 把盈利和投资加进来，等于承认原模型遗漏了系统性模式。这是多因子研究「不断打补丁」的典型路径。

### 5.2 因子动物园与复制危机（本板块最重要的实证事实）

| 研究 | 方法 | 结论 |
|------|------|------|
| Harvey、Liu、Zhu（2016） | 清点已发表因子，做多重检验校正 | 316 个因子；主张新因子 t 门槛从 2.0 提到约 3.0 |
| McLean、Pontiff（2016） | 97 个预测变量的三段收益对比 | 样本外低 26%（数据挖掘上界），发表后低 58%；差值 32 个百分点归因于发表后知情交易 |
| Linnainmaa、Roberts（2018） | 用发表前数据做样本外检验 | 多数异象在原始样本期之前并不存在 |
| Hou、Xue、Zhang（2020） | 统一方法复制 452 个异象 | 65% 过不了 t > 1.96；82% 过不了多重检验门槛 2.78 |
| Chordia、Goyal、Saretto（2020） | 另一套统计工具 | 大量「显著」实为假阳性 |
| Jensen、Kelly、Pedersen（2023） | 贝叶斯框架，93 个国家 | 多数因子方向可复现，但幅度小于原报告 |
| Swade、Hanauer、Lohre、Blitz（2024） | 因子张成分析 | 约 15 个因子足以张成整个因子空间，其余多为冗余 |

**McLean-Pontiff 的解读是三分的：**

- 样本外下降 26% → 数据挖掘成分的上界估计
- 发表后进一步下降 32 个百分点 → 知情交易的作用，说明投资者从学术发表中学习
- 剩余部分未消失 → 说明存在真实的风险补偿或未被消除的错误定价

**这一组研究改变了什么：** 在 2000 年代，「某因子有 t 值大于 2 的实证支持」足以支撑一个产品。现在不够了。**必须过三道关：多重检验校正、跨市场复现、扣除交易成本后仍存在。**

### 5.3 面对大量候选因子时的筛选标准

综合 Ang（2014）、Kozak-Nagel-Santosh（2018）等提出的标准：

| 标准 | 含义 | 检验方法 |
|------|------|---------|
| 经济理由 | 溢价存在要有讲得通的机制 | 是风险补偿还是行为偏差？机制能否被独立验证 |
| 统计稳健 | 过得了多重检验校正 | t > 3.0 而非 2.0；查看 deflated Sharpe ratio |
| 跨样本存活 | 不同时期、地域、资产类别都存在 | 至少在美股、欧股、日股、新兴市场都验证 |
| 成本后可交易 | 扣除交易成本与冲击成本后仍存在 | 注意换手率高的因子（如动量）成本敏感 |
| 独立信息 | 不是已有因子的重新包装 | 与已知因子做正交化后是否还有 alpha |

**注意：等权多因子组合比优化权重更稳健。** 优化权重会放大估计误差，这一结论与投资组合理论中的 1/N 之谜同源（见 `02-投资组合理论.md`）。

## 六、期权定价

### 6.1 Black-Scholes-Merton 框架

Black、Scholes（1973）与 Merton（1973）通过**动态复制**证明：如果能用标的资产和无风险资产连续复刻期权的支付，那么期权价格由无套利条件唯一确定，与投资者风险偏好无关。

**关键洞察：期权定价不需要知道标的资产的预期收益率。** 这是与 CAPM 一系（必须知道期望收益）的根本方法论差别。

### 6.2 假设与偏离

| 假设 | 现实 |
|------|------|
| 标的服从几何布朗运动，波动率常数 | 波动率显著随时间变化，且与价格水平相关 |
| 收益对数正态 | 股权指数收益超额峰度约 5 至 10，偏度约 -0.5 至 -1.0（Cont、Tankov 2004） |
| 可连续交易、无交易成本 | 离散再平衡带来跟踪误差（Boyle、Emanuel 1980） |
| 无跳跃 | 价格会跳跃，尤其是事件驱动时 |
| 可无限制卖空 | 多数市场有卖空约束 |

### 6.3 波动率微笑与偏斜

1987 年以前，标普 500 指数期权的隐含波动率呈微笑形（价内与价外都高于平值）。1987 年崩盘之后转为**偏斜**（smirk）：隐含波动率随行权价单调下降，低行权价期权的隐含波动率显著更高。

**这不是模型的失败，而是市场在告诉你模型在哪里失效。** 偏斜意味着市场隐含的收益分布比对数正态更负偏、峰度更高。做波动率交易的人读微笑曲线，就是在读市场对尾部风险的定价。

### 6.4 扩展路径

| 模型 | 年份 | 核心创新 | 能生成微笑 | 主要用途 |
|------|------|---------|-----------|---------|
| Black-Scholes | 1973 | 风险中性定价、闭式解 | 否（常数波动率） | 报价惯例、基础对冲 |
| Merton 跳跃扩散 | 1976 | 泊松跳跃过程 | 短期微笑 | 有事件风险的股票期权 |
| Heston 随机波动率 | 1993 | 均值回复的波动率过程 | 内生微笑 | 股票期权（含奇异） |
| Dupire 局部波动率 | 1994 | 波动率是价格与时间的确定函数 | 可完美拟合当日微笑 | 奇异期权定价 |
| SABR | 2002 | 随机远期与随机波动率 | 可捕捉微笑动态 | 利率、外汇期权 |
| 粗糙波动率 | 2018 起 | 分数布朗运动刻画波动率 | 更真实的期限结构 | 研究前沿 |

**跳跃扩散的特殊问题：** 跳跃风险无法完美对冲，这直接打破了 BS 赖以成立的**完全市场假设**。这是扩展模型里最本质的一步退让。

**实证地位：无套利定价原理稳健；BS 的具体分布假设已被明确证伪，但其报价与对冲功能仍在被使用。**

## 七、利率期限结构

同一发行人、不同期限的债券收益率构成收益率曲线。解释其形状的三种经典假说：

| 假说 | 核心论点 | 推论 |
|------|---------|------|
| 预期假说 | 长期利率等于未来短期利率的预期均值 | 曲线形状反映市场对利率路径的预期 |
| 流动性溢价理论 | 长期债券有流动性溢价 | 曲线通常向上倾斜，即使预期利率不变 |
| 市场分割理论 | 不同期限市场由不同投资者群体主导，供需独立 | 曲线形状由各期限的供需决定 |

无套利建模路线（不走均衡，只要求内部一致）：

| 类型 | 代表模型 | 特点 |
|------|---------|------|
| 短期利率模型 | Vasicek、CIR、Hull-White | 描述短期利率的随机过程 |
| 整条曲线模型 | HJM（Heath-Jarrow-Morton） | 直接对整条曲线建模，维度高但更契合抵押贷款支持证券等定价 |

**实践中的关键点：** 收益率曲线是宏观预期、风险溢价与供需摩擦的混合结果，三种假说各自解释一部分，没有哪一种单独成立。用曲线做预测时，必须先说明假定哪种机制占主导。

## 八、消费资本资产定价与股权溢价之谜

### 8.1 CCAPM

Lucas（1978）、Breeden（1979）把资产定价建立在消费上：随机贴现因子与边际效用成正比。

```
m_{t+1} = δ · u'(C_{t+1}) / u'(C_t)
```

在幂效用下，这直接给出「预期收益与消费增长协方差成正比」的结论。理论上更根本，因为 CAPM 可以视为它在特定条件下的近似。

### 8.2 三个谜题

| 谜题 | 内容 | 提出者 |
|------|------|-------|
| 股权溢价之谜 | 美国历史股权溢价远高于标准模型能解释的水平 | Mehra、Prescott（1985） |
| 无风险利率之谜 | 要为高股权溢价找到解释，需要极高的风险厌恶，但那会推出无风险利率远高于实际值 | Weil（1989） |
| 股权波动之谜 | 股价波动远大于股利波动 | Shiller（1981） |

### 8.3 主要修补方向

| 方向 | 代表文献 | 核心思路 |
|------|---------|---------|
| 习惯形成 | Constantinides（1990）、Campbell-Cochrane（1999） | 效用取决于消费相对习惯水平，而非绝对水平 |
| 长期风险 | Bansal、Yaron（2004） | 消费增长中很小的可预测成分被大幅定价 |
| 罕见灾难 | Rietz（1988）、Barro（2006） | 小概率巨大下跌抬高了要求的溢价 |
| 异质性与有限参与 | 多篇 | 只有部分家庭持股，代表性消费者假设不成立 |
| 行为解释 | 前景理论与损失厌恶 | 损失厌恶本身即可解释高溢价 |

**这一块的状态：** 谜题已被确认存在三十多年，修补方案众多，**没有一个取得共识**。这是宏观金融缺少共识模型（见元判断 4）最典型的例子。

**实证地位：CCAPM 的逻辑稳健，标准幂效用版本被实证明确击败，替代方案均有争议。**

## 九、与其他板块的接口

| 接口 | 说明 |
|------|------|
| 与投资组合理论 | CAPM 是 MPT 加上均衡条件的产物；MPT 给「有效前沿」，CAPM 给「切点组合就是市场组合」 |
| 与有效市场假说 | 联合假说问题：检验 EMH 必须先假定一个资产定价模型，两者不可分离检验 |
| 与行为金融 | 因子溢价是风险补偿还是错误定价，是两派的核心战场。动量尤其难用风险解释（它在市场反弹后会崩溃） |
| 与公司金融 | CAPM 用于估算权益成本，进而算 WACC，进入资本预算 |
| 与风险管理 | 期权定价的希腊字母是风险对冲的基础；VaR 的参数法依赖这里的分布假设 |
| 与货币宏观 | 无风险利率的期限结构是货币政策传导的核心环节 |

## 十、使用本板块时的三条提醒

1. **先问「m 是什么」。** 拿到任何资产定价结论，先确认它背后对随机贴现因子的指定。指定不同，适用场景就不同。
2. **讨论实证发现时必须带模型口径。** 「发现了某异象」严格说是「相对于某模型存在异常」，这是联合假说问题的直接后果。
3. **因子类结论必须带四项信息：** 多重检验校正后的显著性、跨市场复现情况、扣除成本后的收益、与已知因子的独立性。缺任何一项，结论都不完整。
