# 14 投资案例与判断逻辑

## 一、这一份回答什么问题

`13` 讲了政策怎么作用于行情。这一份讲：**在特定行情与政策环境中，具体的钱是怎么赚到的、怎么亏掉的，以及背后的判断链条能不能复用。**

每个案例按同一套框架拆解：识别信号 → 推理链条 → 决策要点 → 执行 → 结果与教训。

**先说清三条总的纪律：**

1. **本模块只分析已发生的历史案例，不构成任何投资建议。** 历史案例的价值在于展示推理方式，不在于提供可套用的模式
2. **「判断正确」与「赚到钱」之间隔着时点、仓位与资金期限。** 案例里失败的类型里，相当一部分是「判断对但死在中途」
3. **幸存者偏差必须主动标注。** 每一个成功的案例背后，都有大量做同样判断但没成功的人。本模块会在每个案例后说明这一点

## 二、案例分析框架

### 2.1 七项拆解

| # | 项目 | 要回答什么 |
|---|------|-----------|
| 1 | 行情类型 | 牛市 / 熊市 / 震荡市 / 危机 |
| 2 | 政策环境 | 当时政策处在哪一阶段（收紧 / 宽松 / 中性 / 救助） |
| 3 | **识别信号** | 具体看到什么数据、文件、表态。必须是可观察、可验证的 |
| 4 | **推理链条** | 从信号到结论的完整逻辑，每一步不能跳 |
| 5 | **决策要点** | 具体做什么、用什么工具、仓位多大、什么条件下退出 |
| 6 | 执行难点 | 实际做的时候会在哪里卡住（资金期限、投资者压力、流动性） |
| 7 | 结果与教训 | 结果如何，可复用的部分是什么，不可复用的部分是什么 |

### 2.2 第 3 项和第 4 项是最容易作假的地方

事后叙事会把「我早就觉得不对劲」包装成「识别信号」。**真正的识别信号必须是当时就能指出来的具体对象**：某份招股说明书第几页的条款、某个可查询的比率、某次会议的措辞。

判断一个案例叙述是否可靠，只需问一句：**这个信号在当时是可得的吗，还是在事后才变得显眼？**

## 三、危机型机会：做空与抄底

### 3.1 案例一：1992 年做空英镑（政策不可持续模式）

| 项目 | 内容 |
|------|------|
| 行情类型 | 危机（政策危机，非市场崩盘） |
| 政策环境 | 德国统一后为抑制通胀维持高利率；英国处于衰退需要降息 |

**识别信号**

- 英国加入欧洲汇率机制（ERM），英镑需维持在约 2.95 德国马克的中央平价附近
- 德国统一（1990）后，德国联邦银行面对通胀压力保持高利率，且明确不愿为其他成员国降息
- 英国经济处于衰退，失业上升，需要低利率刺激
- 英国的通胀水平高于德国，实际需要贬值
- 市场已多次试探区间下限，英国央行持续干预，外汇储备承压

**推理链条**

```
固定汇率 + 资本自由流动（三元悖论中已选两项）
→ 英国必须放弃货币政策独立性
→ 但英国的经济状况要求独立降息
→ 两个目标互斥，必有一方让步
→ 让汇率目标让步，比让经济目标让步的政治成本更低
→ 因此英镑最终会贬值或退出 ERM
→ 方向确定，剩下的是时点
```

**决策要点**

- **不预测汇率水平，只判断政策组合的可持续性。** 这是整个案例最关键的认知转换
- 做空工具选择：远期外汇合约，成本低、杠杆高、可续期
- 仓位规模：以能承受央行短期干预造成的浮亏为限
- 触发条件：英国央行干预规模与频率上升、官员表态出现松动

**执行难点**

- 央行可以短期大幅加息把空头逼出场（1992 年 9 月 16 日英国一天内两次加息，从 10% 到 12% 再到 15%）
- 空头需要足够厚的资金承受短期浮亏
- 「什么时候崩」无法预测，只能等

**结果与教训**

1992 年 9 月 16 日「黑色星期三」，英国宣布退出 ERM，当日两次加息均未能维持平价。广泛报道口径下，该笔交易的获利约为 10 亿美元。

**可复用的部分：** 当两个政策目标互斥且其中一个有硬约束时，判断哪一方会让步，比预测价格更可靠。

**幸存者偏差提示：** 当时做同样判断的人不少。差别在于能否承受央行干预期的浮亏、以及能否等到事件发生。**判断正确但资金期限不够的人，同样出局。**

### 3.2 案例二：1997 年亚洲金融危机（资产负债表错配模式）

| 项目 | 内容 |
|------|------|
| 行情类型 | 危机 |
| 政策环境 | 固定（或准固定）汇率 + 资本账户开放 + 国内信用扩张 |

**识别信号**

- **短期外债 / 外汇储备** 比率超过 1，是核心指标
- 经常项目逆差占 GDP 比重高（泰国在危机前约 8%）
- 银行体系大量投向房地产，抵押品集中于不动产
- 本币债务以外币计价（货币错配）
- 企业盈利为本币，债务为外币（期限错配叠加货币错配）
- 本地利率远高于外币利率，吸引套利资金持续流入

**推理链条**

```
外币短期借款 + 本币收入（货币错配）
+ 短期负债 + 长期资产（期限错配）
→ 只要资本流入持续，结构稳定
→ 一旦资本流入逆转，必须先偿还短期外债
→ 外储不足以覆盖 → 汇率被迫贬值
→ 贬值使外币债务本币值暴增 → 企业与银行同时资不抵债
→ 抵押品被迫抛售 → 价格下跌 → 更多违约
→ 自我强化
```

**决策要点**

- 盯住两个比率：**短期外债 / 外储**、**经常项目逆差 / GDP**
- 关注银行体系对不动产的敞口集中度
- 判断触发点：外储开始下降、离岸与在岸利差扩大、远期汇率溢价上升

**执行难点**

- 做空本币需要离岸市场，部分国家限制
- 危机传染顺序难判断（泰国 → 菲律宾 → 马来西亚 → 印尼 → 韩国）
- 部分市场（如马来西亚）会突然实施资本管制，空头无法平仓

**结果与教训**

- 泰国 1997 年 7 月放弃钉住汇率，危机扩散至东亚多国
- 韩国 1997 年 11 月接受 IMF 约 580 亿美元救助，为当时最大规模
- **中国香港 1998 年 8 月政府入市**：买入恒生指数成分股，动用约 1,180 亿港元，占当时市值约 7%，并成立外汇基金投资公司，后以盈富基金形式逐步退出。这是「以平准基金击退空头」的正面案例，也是政府直接入市的争议样本
- **马来西亚 1998 年 9 月实施资本管制**并固定汇率。恢复速度在当时快于接受 IMF 方案的国家，但起点条件不同，不能直接对比。这是「逆华盛顿共识」的代表案例

**可复用的部分：** 危机不是从汇率开始的，是从**资产负债表结构**开始的。先看结构，再看价格。

### 3.3 案例三：2005 至 2007 年做空次贷（错误定价的保险模式）

| 项目 | 内容 |
|------|------|
| 行情类型 | 牛市末期至危机 |
| 政策环境 | 长期低利率 + 证券化扩张 + 监管真空 |

**识别信号**

- 次贷在新增住房贷款中的占比快速上升
- 浮动利率贷款的**利率重置时间表**集中在 2007 至 2008 年
- 贷款审核标准弱化：借款人信用评分下降、贷款价值比上升、收入证明缺失
- 房价在 2006 年开始环比转弱
- CDO 分层结构：同一批贷款被打包成不同优先级的证券，优先级获得高评级
- **评级模型依赖历史房价数据，而历史样本中没有全国性房价下跌的情形**

**推理链条**

```
利率重置集中到期 → 月供跳升 → 违约率上升
→ MBS 现金流受损 → CDO 分层自下而上被击穿
→ 评级下调 → 触发合同中的强制出售条款
→ 抛售 → 价格下跌 → 更多评级下调
→ 自我强化
```

**关键在第二步之后：** 不是预测「会不会危机」，而是**计算在给定违约率下，哪一层会被击穿，以及当前该层的定价是否合理**。

**决策要点**

- **读原始文件。** 有做空者逐份阅读贷款池的说明文件，而非依赖评级与二手分析
- 用信用违约互换（CDS）而非直接做空证券：**成本有限（保费），收益不对称（标的归零时收益巨大）**
- 计算不同违约率假设下的分层损失
- 关键判断：如果违约率假设正确，损失规模是否远超保费总额

**执行难点**

- 保费需要连续支付，做空者要能承受长期支出
- 投资者的压力：在结果出现前，会质疑「为什么一直亏钱交保费」
- 需要对冲机构对手方风险（危机中交易对手可能倒闭）

**结果与教训**

2007 年相关交易获得巨大收益，广泛报道口径下，单只基金年收益超过五倍，整个机构当年利润约 150 亿美元；另一位做空者个人的收益达数十亿美元。

**可复用的部分：** 危机中最难的不是发现风险，而是**找到把判断转换成有限成本、无限收益的工具**。这是「期权思维」的本质。

**幸存者偏差提示：** 大量做空者在 2006 年就进场，被保费消耗与投资者赎回淘汰，未能等到 2007 年。**方向正确、工具正确、时点错一年，结果完全不同。**

### 3.4 案例四：2008 年抄底（资本结构上层模式）

| 项目 | 内容 |
|------|------|
| 行情类型 | 危机 |
| 政策环境 | 救助阶段（注资、担保、零利率、QE） |

**识别信号**

- 系统性风险已经确定：政府明确表态不会放任系统重要性机构倒闭
- 财政救助方案规模与覆盖面（TARP 7,000 亿美元）
- 央行推出针对性的流动性工具（商业票据融资、资产支持证券贷款等）
- 信用利差达到历史极值，高收益债利差峰值接近 2,000 个基点

**推理链条**

```
系统性机构不会全部倒闭（政策已明确）
→ 但普通股股东可能被大幅稀释
→ 优先股与债券的受偿顺序在前，且有政策托底
→ 因此在危机中，资本结构上层是风险收益比更优的位置
→ 若同时获得认股权证，则在下行有保护的同时保留上行
```

**决策要点**

- **买资本结构的上层，不买底层。** 优先股、债券优先于普通股
- 用结构化条款而非直接持有：优先股股息 + 认股权证，构建不对称收益
- 判断依据不是「股价便宜」，而是「受偿顺序 + 政府背书」
- 高收益债：在利差极值时买入，收益来源是利差收敛而非基本面改善

**执行难点**

- 危机中「便宜」可以变得更便宜，估值不是买入理由
- 需要判断政府救助的边界：哪些机构会被救，哪些不会
- 时间点极难把握，分批建仓是必要手段

**结果与教训**

2008 年 10 月的此类投资在此后数年取得显著回报。更重要的是方法论：**危机中先问「受偿顺序」，再问「价格」。**

**反例：** 同期大量买入濒临倒闭机构普通股的资金大幅亏损。同样的判断（危机可控），因为选了资本结构底层，结果相反。

### 3.5 案例五：2020 年疫情崩盘（央行承诺模式）

| 项目 | 内容 |
|------|------|
| 行情类型 | 危机（外生冲击型） |
| 政策环境 | 无限量宽松 + 财政直达 |

**识别信号**

- 央行的措辞从「有限规模」变为「无上限」（2020 年 3 月的表述）
- 同时启用多个流动性工具，且首次涉及公司债的二级市场购买
- 财政方案规模达到 GDP 的两位数百分比
- 政策出台速度以天计，而非以月计

**推理链条**

```
外生冲击（疫情）而非内生失衡
→ 央行「无上限」承诺意味着流动性风险被消除
→ 财政直达意味着需求不会长期塌陷
→ 因此这是流动性危机而非偿付能力危机
→ 流动性危机在流动性注入后结束，恢复速度快于偿付能力危机
→ 2008 年是偿付能力危机，2020 年是流动性危机，这是关键区别
```

**决策要点**

- 区分**流动性危机**与**偿付能力危机**。前者注入流动性即可解决，后者需要资本重建，时间以年计
- 关注央行措辞的变化：从「规模有限」到「不限量」是质变
- 政策出台的速度是重要信号：速度快说明决策层判断严重

**结果与教训**

市场在央行宣布无上限措施的当日见底。**政策底与市场底在同一时间出现，这在历史上罕见，原因是政策的「无上限」性质消除了不确定性，而非仅仅降低了利率。**

**可复用的部分：** 判断危机的性质（流动性还是偿付能力）决定了对恢复速度的预期。

## 四、牛市型机会：识别泡沫与参与

### 4.1 泡沫的识别信号清单

这是本节最实用的部分。泡沫无法精确定义，但信号可以观察。

| 类别 | 信号 | 说明 |
|------|------|------|
| 估值 | 用「市销率」「点击量」「用户数」等替代现金流指标 | 定价锚从盈利转向叙事 |
| 供给 | 新股发行首日大幅上涨；无盈利公司密集上市 | 供给方在利用高价 |
| 需求 | 新开户数激增；融资余额快速上升；场外配资出现 | 杠杆与散户同时入场 |
| 行为 | 卖方分析师目标价频繁上调；「这次不一样」的论述盛行 | 叙事替代分析 |
| 结构 | 抵押品集中于单一资产；融资期限短于资产期限 | 结构脆弱性累积 |
| 政策 | 监管开始提示风险，但尚未采取实质措施 | 政策转向的前兆 |

### 4.2 案例：1999 至 2000 年互联网泡沫

**识别信号**

- 大量无盈利公司上市，估值以「眼球数」「页面浏览量」为基础
- 新股首日涨幅动辄翻倍
- 传统估值方法被公开宣称「过时」
- 融资成本在上升（美联储 1999 年 6 月起连续加息）但市场忽视

**可选的应对方式与各自后果**

| 应对 | 案例 | 结果 |
|------|------|------|
| 做空 | 部分对冲基金在 1999 年做空科技股 | **判断正确但时点错误，多数在做空浮亏与投资者赎回中出局**。有一只著名的价值型基金在 2000 年 3 月关闭（恰在顶部附近），此前连续大幅亏损 |
| 拒绝参与、持有传统价值资产 | 部分价值投资者 | 1999 年大幅跑输（有知名投资者当年跑输大盘超过 40 个百分点），2000 至 2002 年大幅跑赢 |
| 参与并在顶部前退出 | 极少数 | 事后叙事中存在，实际可验证的案例稀少 |

**这个案例最重要的教训不是「如何做空泡沫」，而是：**

> **在泡沫中，「不参与」本身就需要承受巨大的职业与心理压力。** 判断正确不等于能持有到判断被验证。**资金期限与心理承受力，与判断能力同等重要。**

**幸存者偏差提示：** 「我在 2000 年做空了科技股」这类叙述中，绝大多数省略了此前的浮亏与仓位变化。真正可验证的是：那一年关闭的那只基金，判断方向完全正确。

### 4.3 案例：1986 至 1989 年日本泡沫

**识别信号**

- 地价与股价同时快速上涨，且以土地为抵押的信贷快速扩张
- 「东京地价可以买下整个美国」这类论述的流行
- 央行从 1989 年 5 月起连续加息，并引入**房地产贷款总量管制**（直接限制银行对不动产的贷款增速）
- 货币政策在 1989 至 1990 年快速转向

**机制链条**

```
低利率 + 金融自由化 → 信贷扩张 → 资产价格上涨
→ 抵押品升值 → 可贷额度进一步扩大 → 自我强化
→ 央行加息 + 贷款总量管制 → 信贷收缩
→ 抵押品价格下跌 → 强制去杠杆 → 长期下行
```

**关键判断依据：** 政策工具从「价格型」（加息）升级到「数量型」（贷款总量管制），说明价格工具已被判断为无效。**监管工具升级是比加息更强的信号。**

**结果与教训**

1990 年泡沫破裂，此后进入长期低迷。这个案例的核心教学点是**资产负债表衰退**：资产价格下跌后，企业与家庭优先偿还债务而非借贷，货币政策传导中断。这解释了为什么之后近二十年的零利率与量化宽松未能重启增长。

## 五、熊市与政策转向型机会

### 5.1 案例：1981 至 1982 年利率见顶与长期债券牛市

**识别信号**

- 美国 10 年期国债收益率在 1981 年达到约 15% 以上的历史高位
- 通胀率开始从两位数回落
- 货币政策维持极度紧缩（联邦基金利率一度超过 20%）
- 经济进入双底衰退（1980 与 1981 至 1982）

**推理链条**

```
名义利率 = 实际利率 + 通胀预期
→ 当名义利率处于历史极值且通胀开始回落
→ 实际利率被推至极高水平
→ 极高实际利率不可持续（会压垮经济）
→ 因此名义利率必降
→ 长久期债券在利率下行中涨幅最大
→ 这是一个"极端估值隐含极端回报"的判断
```

**决策要点**

- 判断依据是**实际利率的极端值**，不是「债券便宜」
- 工具选择：长久期债券，久期越长对利率下行越敏感
- 时点判断依靠通胀数据的连续回落，而非单月数据

**结果与教训**

此后数十年债券市场经历长期上行（收益率长期下行）。这是「制度与政策体制转变带来的长期趋势」的典型案例。

**可复用的部分：** **政策体制（regime）的改变，比单次政策动作重要得多。** 从「通胀容忍」转向「通胀目标制」，是一次体制转换，其影响持续数十年。

### 5.2 案例：2012 年欧债危机（央行可信承诺模式）

**识别信号**

- 西班牙、意大利 10 年期国债收益率升至 7% 以上，进入不可持续区间
- 欧洲央行此前表态模糊，市场对「是否救助」存在分歧
- 欧洲央行行长在 2012 年 7 月发表明确表态：在职责范围内，准备采取一切必要措施维护欧元，并强调「相信我，这就够了」
- 随后推出有条件的主权债购买计划（该计划最终未被实际使用）

**推理链条**

```
央行的可信承诺 + 主权债收益率处于不可持续水平
→ 若承诺可信，债券持有人不必再担心违约
→ 收益率应回落至与该国基本面相符的水平
→ 关键点：计划未被使用却生效，说明"承诺"本身即是政策
→ 因此这是一个重定价事件，而非基本面改善事件
```

**决策要点**

- 判断核心是**央行承诺的可信度**，而不是债务国的基本面
- 可信度来源：央行有无法律授权、有没有明确规模、历史信誉如何
- 关键区别：无上限承诺与有条件承诺的效果差异巨大

**结果与教训**

西班牙 10 年期国债收益率在此后一年内从约 7.5% 降至约 4% 附近。

**可复用的部分：** **央行的可信承诺本身就是资产价格的重定价事件。** 判断承诺可信度的三个要素：法律授权、规模是否明确、历史信誉。

## 六、震荡市与制度变革型机会

### 6.1 案例：2005 年股权分置改革

**识别信号**

- 上市公司非流通股与流通股长期分割，两类股东利益不一致
- 改革方案明确：非流通股东向流通股东支付对价以换取流通权
- 改革分批推进，方案需股东大会通过

**推理链条**

```
股权分置 → 大股东不关心股价 → 治理折价
→ 改革后大股东利益与股价绑定 → 治理改善
→ 治理改善提升估值中枢
→ 同时改革释放的流动性预期吸引增量资金
→ 制度变革带来的估值重估，幅度大于短期政策
```

**决策要点**

- 判断依据是**激励结构的变化**，不是短期刺激
- 关注改革方案的推进节奏与通过率
- 时点：改革启动初期，预期差最大

**结果与教训**

改革自 2005 年启动后，市场经历了一轮大幅上涨，至 2007 年见顶。

**可复用的部分：** **制度变革改变参与者的激励结构，其效果远超短期政策。** 这类机会的识别依据是「制度文本」，不是「政策表态」。

### 6.2 案例：2014 至 2015 年杠杆牛与随后的危机

**识别信号（上涨阶段）**

- 融资余额从数千亿元快速升至超过 2 万亿元
- 场外配资（非场内融资）大量出现，杠杆倍数高于场内
- 新开户数激增，散户资金集中入场
- 估值分位快速上行

**识别信号（转折阶段）**

- 监管开始清查场外配资（2015 年中）
- 融资余额见顶回落
- 成交量在价格见顶前先见顶

**推理链条（下跌阶段）**

```
杠杆资金 + 平仓线规则
→ 价格下跌触发强制平仓
→ 平仓抛售加剧下跌
→ 触发更多平仓
→ 流动性最差的标的先崩，随后传导至流动性好的标的
→ 政策入市可以阻断螺旋，但不能修复杠杆受损的资产负债表
```

**政策应对与效果**

- 入市买入、限制减持与做空、暂停新股发行
- 政策成功阻断连续性螺旋，但市场信心修复缓慢
- **关键教训：政策底不等于市场底。** 入市承接卖盘解决的是流动性，不解决杠杆资金的退出压力与估值回归

**决策要点**

- 判断杠杆行情的顶部，关键是**政策对杠杆的态度**，不是估值
- 判断崩盘的深度，关键是**杠杆资金规模与平仓线分布**，不是基本面

## 七、失败案例：判断对但结果错

这一节比成功案例更重要。

### 7.1 失败类型一览

| 失败类型 | 案例 | 机制 |
|---------|------|------|
| **方向对、时点错** | 1999 年做空科技股 | 浮亏与赎回压力迫使在正确结果出现前出局 |
| **方向对、工具错** | 危机中买普通股而非优先股 | 受偿顺序在后，被稀释归零 |
| **方向对、仓位错** | 有商品基金在天然气上的方向判断基本正确，但仓位过大导致基金清盘 | 波动率超出保证金承受能力 |
| **模型对、假设错** | 1998 年某大型对冲基金的收敛交易 | 历史相关性在危机中失效，趋近于 1；杠杆放大损失 |
| **判断对、环境变** | 2008 年做空者在政策救助后未及时调整 | 政策改变了游戏规则，原判断的前提消失 |
| **方向对、流动性错** | 买入低流动性资产等待价值修复 | 需要卖出时无法退出 |

### 7.2 1998 年那次基金崩溃的完整拆解

这是「模型正确但假设失效」最标准的案例。

| 项目 | 内容 |
|------|------|
| 策略 | 收敛交易：买入相对便宜的债券，卖空相对昂贵的债券，等待价差收敛 |
| 前提 | 历史价差关系最终会回归；不同市场的相关性可用于分散风险 |
| 杠杆 | 资产规模相对自有资本约 25 倍 |
| 崩溃机制 | 俄罗斯违约 → 全球避险 → 所有价差同时反向扩大 → 相关性趋近于 1 → 分散假设失效 → 保证金追缴 → 被迫平仓 |
| 结果 | 由监管机构组织主要银行注资重组，避免连锁清算 |

**三条可复用的教训：**

1. **相关性在危机中趋近于 1。** 分散化在最需要的时候最不可靠
2. **杠杆把「时间」变成敌人。** 若没有杠杆，同样的判断只需等待；有杠杆，则可能在等待中出局
3. **流动性与仓位规模必须匹配。** 仓位大到无法在不影响价格的情况下退出时，定价权已不在自己手上

## 八、可复用的七种推理模式

把所有案例的判断逻辑抽象出来，得到七个模式。**这是本模块最有价值的产出。**

### 模式 1：政策不可持续模式

**适用：** 政策目标互斥、其中一方有硬约束

**判断步骤：**

1. 列出政策的所有目标
2. 找出哪两个目标互斥
3. 判断哪个目标有硬约束（外汇储备、法律授权、政治成本）
4. 硬约束更强的目标会被优先，另一方让步

**案例：** 1992 年英镑、1997 年泰铢、2018 年土耳其里拉

### 模式 2：资产负债表错配模式

**适用：** 判断货币危机与债务危机

**判断步骤：**

1. 检查三个错配：货币错配（借外币、赚本币）、期限错配（借短、用长）、抵押品错配（抵押品集中于单一资产）
2. 计算关键比率：短期外债 / 外储、经常项目逆差 / GDP
3. 若抛售发生，机制是否自我强化？

**案例：** 1997 年亚洲、1982 年拉美、1994 年墨西哥

### 模式 3：融资结构模式

**适用：** 判断杠杆驱动的市场崩塌

**判断步骤：**

1. 融资来源：场内还是场外？受监管还是不受监管？
2. 平仓规则：抵押品折扣、保证金要求、平仓线
3. 规模估算：杠杆总规模与价格下跌多少会触发集中平仓
4. 传染路径：哪些标的流动性最差，会先崩？

**案例：** 2015 年 A 股、2008 年批发融资挤兑、2022 年英国养老金

### 模式 4：极端估值模式

**适用：** 判断长期趋势转折

**判断步骤：**

1. 寻找**实际变量**的极值（实际利率、实际汇率、股权风险溢价），而非名义价格
2. 问：当前水平隐含的假设是什么？
3. 该假设有多大可能持续？
4. 若假设改变，重估幅度有多大？

**案例：** 1981 至 1982 年利率见顶、2000 年科技股、2020 年负实际利率

### 模式 5：央行承诺模式

**适用：** 危机与政策转向

**判断步骤：**

1. 区分「有条件承诺」与「无上限承诺」
2. 判断可信度：法律授权、规模明确性、历史信誉
3. 若承诺可信，则相关风险资产的重定价幅度由承诺覆盖范围决定
4. 关注措辞变化，而非行动

**案例：** 2012 年欧债、2020 年疫情、2008 年 TARP 的拖延与恶化

### 模式 6：制度变革模式

**适用：** 结构性机会

**判断步骤：**

1. 找到改变参与者**激励结构**的制度文本（不是政策表态）
2. 推断激励改变后的行为变化
3. 行为变化 → 现金流变化 → 估值变化
4. 制度变更的效果持续期远长于短期政策

**案例：** 2005 年股权分置改革、1990 年代私有化、1970 年代通胀目标制

### 模式 7：催化剂与时点模式

**适用：** 所有需要判断时点的场景

**判断步骤：**

1. 承认一个事实：**判断方向容易，判断时点极难**
2. 寻找**强制触发器**：资金到期日、利率重置日、财报披露日、央行会议日、法律生效日
3. 用期权而非线性工具表达判断（成本有限）
4. 用催化剂的临近程度决定仓位

**案例：** 2005 至 2007 年做空次贷（利率重置时间表是催化剂）、1992 年英镑（外储消耗速度是催化剂）

## 九、使用本模块的纪律

| 纪律 | 说明 |
|------|------|
| 只分析已发生的案例 | 不做前瞻预测，不给具体标的建议 |
| 必须标注幸存者偏差 | 每个成功案例都要说明「同样判断但失败的人有多少」 |
| 区分判断与执行 | 判断能力、资金期限、心理承受力是三个独立变量，缺一个都不成 |
| 失败案例同等重要 | 第七节的价值不低于第三至六节 |
| 不把历史类比当预测 | 历史类比必须指出当时的制度条件与当下的差异 |
| 盈利数据标注口径 | 广泛报道的数字可能有出入，须标注「常见报道口径」 |
| 决策要点必须可操作 | 不写「保持警惕」这类等于没说的话，要写具体动作与触发条件 |
