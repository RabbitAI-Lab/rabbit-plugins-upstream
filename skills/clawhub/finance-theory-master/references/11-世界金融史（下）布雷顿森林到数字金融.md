# 11 世界金融史（下）：布雷顿森林到数字金融

## 一、这一份回答什么问题

1944 年确立的美元体系怎么运转、为什么崩、崩了之后世界靠什么维持；金融全球化的三次浪潮怎么起怎么落；2008 年危机的传导链条具体是什么；数字货币是全新的东西，还是老问题的新形态。

**这一份的核心判断：** 布雷顿森林体系崩溃后，世界并没有进入「无体系」状态，而是进入了一个**没有正式规则但有实际层级**的美元本位。理解这个层级，是理解此后所有国际金融事件的前提。

配套阅读：`10-世界金融史（上）：从古代起源到金本位.md`、`12-金融史脉络对照与索引.md`。

## 二、布雷顿森林体系的运行与崩溃（1945 — 1973）

### 2.1 制度设计

| 要素 | 内容 |
|------|------|
| 汇率安排 | 美元与黄金挂钩（每盎司 35 美元），其他货币与美元挂钩，波动幅度允许上下各 1% |
| 储备资产 | 黄金 + 美元（美元被当作「与黄金同等」） |
| 调节机制 | 短期的国际收支失衡由 IMF 提供融资，长期的根本性失衡允许调整平价 |
| 资本流动 | 明确允许并鼓励资本管制，认为投机性资本流动是战间期不稳定的根源 |
| 治理 | IMF 与 IBRD，投票权加权的份额制 |

**与金本位的根本差别：** 金本位要求国内调整（工资物价下跌），布雷顿森林允许汇率调整与 IMF 融资。**设计者的意图是给国内就业政策留出空间。**

### 2.2 从短缺到过剩（1945 — 1958）

| 年份 | 事件 |
|------|------|
| 1947 | 欧洲出现「美元荒」，IMF 开始贷款；《关税与贸易总协定》签署 |
| 1948 — 1952 | 马歇尔计划提供约 130 亿美元援助，同时缓解美元荒与政治风险 |
| 1949 | 英镑贬值，欧洲多国跟随 |
| 1958 | 欧洲主要货币恢复可兑换，资本管制开始放松 |

**马歇尔计划的金融意义常被低估：** 它不只是援助，还是让欧洲重建储备、恢复可兑换的前提。**没有它，布雷顿森林的可兑换目标无法在十年内实现。**

### 2.3 特里芬难题

**罗伯特·特里芬（1960）** 指出体系的内在矛盾：

```
世界需要美元作为储备货币 → 美国必须持续输出美元（逆差）
美国持续逆差 → 美元对黄金的可兑换性受质疑
→ 信心与流动性不可兼得
```

**这个矛盾无法在体系内解决。** 唯一的出路是创造一种不依赖单一国家逆差的储备资产。这就是特别提款权（SDR）的由来。

### 2.4 七次危机的累积

| 年份 | 事件 |
|------|------|
| 1960 | 伦敦金价突破 35 美元，特里芬难题公开化 |
| 1961 | 「伦敦黄金池」成立，多国央行联合干预金价 |
| 1962 | 美联储与主要央行建立货币互换网络 |
| 1967 | 英镑贬值；对美元的信心进一步削弱 |
| 1968 | 黄金双价制（官方市场与私人市场分离）；黄金池解散 |
| 1969 | **特别提款权（SDR）创设** |
| 1971 | 8 月 15 日尼克松宣布关闭黄金窗口，同时冻结工资物价 90 天 |

**1960 年代的每一次危机，都是同一矛盾的重复发作。** 黄金池、互换网络、双价制、SDR，全部是在不改变根本结构的前提下做的补丁。

### 2.5 终结

| 年份 | 事件 |
|------|------|
| 1971.12 | 《史密森协定》：美元贬值至每盎司 38 美元，波动幅度放宽 |
| 1972 — 1973 | 英镑、里拉等相继浮动；美元再度承压 |
| 1973.3 | 主要货币普遍浮动，布雷顿森林体系终结 |
| 1976 | 《牙买加协定》在法律上确认浮动汇率、黄金非货币化 |

**注意一个常被忽略的事实：布雷顿森林体系的正式终结不是一次事件，而是从 1960 年延续到 1976 年的十六年过程。** 制度很少在某一天死掉。

## 三、美元本位的实际运转（1973 至今）

### 3.1 没有规则的体系靠什么维持

布雷顿森林崩溃后，国际货币体系依赖四个非正式支柱：

| 支柱 | 内容 |
|------|------|
| 美元的网络效应 | 贸易计价、外汇交易、国际债券、大宗商品定价都以美元为主，转换成本极高 |
| 美国国债市场 | 全球最深最流动的安全资产市场，为各国储备提供停泊处 |
| 美联储的准全球央行角色 | 危机时通过货币互换向全球提供美元流动性（2008、2020 年规模空前） |
| 制度与产权的声誉 | 美债被视为无风险资产，本质是对美国制度可信度的定价 |

**这就是所谓「过度特权」（exorbitant privilege）：** 美国能以本币借外债，且融资成本低于其他国家。**代价是必须持续供给安全资产，形成贸易逆差。**

### 3.2 石油美元与资本循环（1973 之后）

1973 年石油危机后油价暴涨，产油国积累巨额美元。这些美元通过伦敦等离岸市场回流到拉美、非洲等发展中国家，形成主权贷款潮。

**1970 年代的循环链条：**

```
油价上涨 → 产油国美元收入 → 流入西方银行 →
银行放贷给发展中国家 → 借款国逆差扩大 → 油价继续上涨 → 循环强化
```

**这个循环在 1982 年断裂。**

## 四、金融自由化与全球化的三次浪潮

### 4.1 第一次浪潮：放松管制（1970s — 1980s）

| 年份 | 事件 |
|------|------|
| 1971 | 布雷顿森林终结，汇率波动催生外汇衍生品需求 |
| 1973 | 芝加哥期权交易所（CBOE）成立；Black-Scholes 模型发表 |
| 1974 | 德国赫斯塔特银行倒闭（「赫斯塔特风险」的由来） |
| 1979 | 美联储「沃尔克冲击」，激进加息至 20% 以上 |
| 1979 | 欧洲货币体系（EMS）成立 |
| 1980 — 1982 | 高利率引发全球衰退，拉美债务危机爆发 |
| 1985 | 《广场协议》：美元对日元、马克有序贬值 |
| 1987 | 《卢浮宫协议》；同年 10 月 19 日「黑色星期一」 |
| 1988 | 巴塞尔协议 I：首次统一资本充足率标准（8%） |

**衍生品市场的爆发与 Black-Scholes 的关系值得注意：** 定价公式让期权可以被连续报价与对冲，从而把一个难以交易的品种变成标准化产品。**这是理论直接创造市场的罕见案例。**

### 4.2 第二次浪潮：新兴市场危机（1990s）

| 年份 | 事件 | 特征 |
|------|------|------|
| 1994 | 墨西哥「龙舌兰危机」 | 固定汇率 + 短期外币债务 + 政治冲击 |
| 1997 | 亚洲金融危机（7 月泰铢，波及韩国、印尼、马来西亚） | 固定汇率 + 短期外债 + 银行体系脆弱 + 资本流动逆转 |
| 1998 | 俄罗斯违约 | 主权违约引发全球风险重定价 |
| 1998 | 长期资本管理公司（LTCM）崩溃 | 高杠杆 + 相关性假设失效 + 流动性枯竭 |
| 1999 | 巴西贬值；欧元启动（记账） | 区域货币一体化与新兴市场调整 |
| 2001 | 阿根廷违约 | 货币局制度崩溃 |

**这几次危机的共同结构：**

1. 本币或固定汇率承诺吸引大量外币短期借款
2. 资产负债表存在货币错配
3. 外部冲击触发资本外流
4. 汇率贬值使外币债务本币值暴增，企业与银行同时资不抵债
5. 危机自我强化

**LTCM 的教训尤其重要：** 它的模型基于历史相关性，认为分散的套利头寸风险很低。1998 年 8 月俄罗斯违约后，所有头寸同时反向，相关性趋近于 1，杠杆放大损失，最终需要纽约联储组织救助。**这是「相关性在危机中失效」最著名的一次实证，与 2008 年、2022 年重复出现的现象同一结构。**

### 4.3 第三次浪潮：全球失衡与金融深化（2000s）

| 年份 | 事件 |
|------|------|
| 1989 | 「华盛顿共识」提出，推动资本账户开放与私有化 |
| 1999 | 美国《金融服务现代化法》废止 1933 年分业经营限制 |
| 2004 | 巴塞尔协议 II（内部评级法） |
| 2005 | 美联储理事伯南克提出「全球储蓄过剩」假说解释美国逆差 |
| 2000s | 全球失衡扩大：美国逆差、东亚与产油国顺差、储备积累 |
| 2000s | 影子银行体系快速扩张：货币市场基金、资产支持商业票据、回购市场 |

**「全球储蓄过剩」与「美元特权」是两种解释，立场不同：**

- 储蓄过剩论：问题在顺差国的储蓄过多，压低了全球利率
- 美元特权论：问题在储备货币国可以无成本融资，导致过度消费

**这两种解释至今没有定论，但它们共同指向同一事实：失衡不可持续。**

## 五、2008 年全球金融危机

### 5.1 背景与触发

| 因素 | 内容 |
|------|------|
| 低利率环境 | 2001 年后美联储长期低利率，推动寻求收益 |
| 证券化 | 住房抵押贷款被打包为 MBS、CDO，分层出售 |
| 评级机制 | 结构化产品大量获得 AAA 评级，风险被系统性低估 |
| 影子银行 | 批发融资（回购、ABCP）取代存款，但不受存款保险与监管约束 |
| 杠杆 | 投行杠杆普遍在 20 至 30 倍 |
| 顺周期机制 | 以市价计量 + 抵押品折扣，价格上涨时放大信贷，下跌时强制去杠杆 |

### 5.2 时间线

| 时间 | 事件 |
|------|------|
| 2007.2 | 汇丰银行为次贷损失计提拨备，市场首次警觉 |
| 2007.8 | 法国巴黎银行冻结三只基金，同业市场冻结 |
| 2007.9 | 英国北岩银行挤兑，出现百年来首次英国银行挤兑 |
| 2008.3 | 贝尔斯登被摩根大通收购，美联储提供融资 |
| 2008.9.7 | 房利美与房地美被接管 |
| 2008.9.15 | **雷曼兄弟申请破产保护** |
| 2008.9.16 | 美国国际集团（AIG）获 850 亿美元救助 |
| 2008.10.3 | 《紧急经济稳定法案》（TARP，7,000 亿美元）通过 |
| 2008.10 | 全球央行协同降息，美联储大幅扩张货币互换 |
| 2009.3 | 美联储启动第一轮量化宽松（QE1） |
| 2010.7 | 《多德-弗兰克法案》签署，含「沃尔克规则」 |
| 2010.11 / 2012.9 | QE2、QE3 |
| 2010 — 2017 | 巴塞尔协议 III 分阶段实施（提高资本与流动性要求） |

### 5.3 传导机制：这是批发融资的挤兑

**2008 年危机的本质不是「银行挤兑」，而是「批发融资挤兑」。**

```
次贷违约上升 → MBS 价格下跌 → 回购市场抵押品折扣上升 →
融资成本骤升或无法滚动 → 持有大量结构化产品的机构被迫抛售 →
价格进一步下跌 → 更多机构被迫抛售
```

**关键区别：** 传统挤兑发生在存款端，有存款保险与央行最后贷款人机制。批发融资没有保险、没有明确的最后贷款人，因此挤兑速度更快、范围更广。**这是「影子银行」概念进入主流政策讨论的原因。**

### 5.4 欧债危机（2010 — 2015）

| 年份 | 事件 |
|------|------|
| 2010 | 希腊获首轮救助；爱尔兰接受救助 |
| 2011 | 葡萄牙、西班牙、意大利承压；希腊债务减记谈判 |
| 2012 | 希腊债务重组（PSI，私营部门参与）；德拉吉「不惜一切代价」表态 |
| 2015 | 希腊公投否决救助条件后又接受第三轮救助 |

**欧债危机的核心结构性问题：** 货币联盟有统一货币政策，却没有统一财政与银行联盟。**成员国用本币计价的债务消失后，政府失去了通过贬值调整的通道，只能内部贬值（削减工资与支出），社会成本极高。**

**银行与主权债的「末日循环」：** 银行持有大量本国国债，国债下跌使银行资本受损，银行需要救助又加重政府债务。**这与 1340 年代佛罗伦萨银行因英王违约而破产的结构完全相同。**

### 5.5 危机改变了什么

| 领域 | 变化 |
|------|------|
| 央行职能 | 量化宽松与前瞻指引常规化；央行资产负债表规模扩张到空前水平 |
| 监管框架 | 巴塞尔 III 提高资本与流动性要求；引入逆周期资本缓冲 |
| 宏观审慎 | 从微观监管转向系统性风险监测 |
| 影子银行 | 被纳入监管视野，但跨境与非银领域仍在扩张 |
| 学术 | 金融摩擦重新进入宏观模型；明斯基与金融周期研究复兴 |

**一个未被解决的问题：** 危机后各国债务水平不但没有下降，反而上升了。**去杠杆没有发生，杠杆只是从私人部门转移到了公共部门。**

## 六、数字货币与金融科技

### 6.1 比特币与区块链

| 时间 | 事件 |
|------|------|
| 2008.10 | 「中本聪」发布比特币白皮书 |
| 2009.1 | 创世区块生成 |
| 2010.5 | 首次实物交易：一万枚比特币换两张披萨 |
| 2011 | 早期泡沫；丝绸之路暗网交易 |
| 2013 | 价格首次突破 1,000 美元；中国禁止银行涉足比特币业务 |
| 2015 | 以太坊上线，引入智能合约与可编程资产 |
| 2016 | The DAO 被攻击，暴露智能合约风险 |
| 2017 | ICO 热潮；12 月价格接近 20,000 美元 |
| 2018 | ICO 泡沫破裂，价格大幅回落 |
| 2019 | Facebook 提出 Libra（后改名 Diem，最终搁置） |

**比特币要解决的问题是什么：** 在没有可信第三方的情况下实现价值转移。**它把「信任」从机构转移到了算法与算力，代价是吞吐量与能耗。**

**与历史上所有货币创新的比较：** 比特币不是第一种私人货币（银行券本来就是私人货币），也不是第一种非金属货币（纸币早了九百年）。**它真正的新意在于：不由任何主权发行、没有中心发行者、发行规则不可变更。** 这三条在历史上没有先例。

### 6.2 稳定币、央行数字货币与 DeFi

| 类别 | 内容 | 安排主体 |
|------|------|---------|
| 加密资产（比特币、以太坊） | 无锚定，价格剧烈波动 | 无 |
| 稳定币 | 锚定法币或资产，用作交易媒介与结算 | 私人发行，储备是关键争议 |
| 央行数字货币（CBDC） | 央行直接对公众或机构发行的数字法币 | 央行 |
| DeFi | 用智能合约替代中介完成借贷、交易、清算 | 无中心运营者 |

**关键事件：**

| 时间 | 事件 |
|------|------|
| 2020 | DeFi 爆发式增长；巴哈马发行 Sand Dollar（首个 CBDC） |
| 2020 | 中国数字人民币（e-CNY）开始试点 |
| 2021.9 | 萨尔瓦多将比特币列为法定货币 |
| 2021 | 加密资产总市值创历史新高；NFT 热潮 |
| 2022.5 | Terra/Luna 与算法稳定币 UST 崩盘 |
| 2022.11 | FTX 交易所破产，客户资产被挪用 |
| 2023.3 | 美国硅谷银行、Signature、第一共和银行相继倒闭；瑞士信贷被瑞银收购 |
| 2024.1 | 美国批准现货比特币 ETF |
| 2025 | 美国通过稳定币监管立法 |

**稳定币的核心争议与历史先例：** 稳定币承诺按面值赎回，但储备资产的透明度与质量受质疑。**这与 19 世纪美国自由银行时代的「银行券折价交易」是同一问题：私人发行、承诺兑付、市场怀疑。** 差别在于稳定币可以跨国流通、赎回速度更快，因此挤兑也更难阻止。

**CBDC 的动机：** 支付效率、货币主权（对抗私人稳定币）、货币政策传导、以及对跨境支付体系的替代设想。**反对意见集中在隐私与政府权力的边界。**

### 6.3 金融科技的其余脉络

| 领域 | 关键节点 |
|------|---------|
| 在线支付 | PayPal（1998）；支付宝（2004）；M-Pesa 肯尼亚移动支付（2007）；微信支付（2013） |
| P2P 借贷 | Zopa（2005）、LendingClub（2006）；中国在 2013 至 2015 年爆发增长，2018 至 2020 年集中爆雷并全面清退 |
| 众筹 | Kickstarter（2009）；股权众筹受各国证券法约束 |
| 机器人投顾 | Betterment（2008）、Wealthfront；把资产配置流程自动化 |
| 开放银行 | 欧盟 PSD2（2015 通过、2018 生效），强制银行开放账户接口 |
| 量化与算法交易 | 从 1980 年代的程序化交易到 2010 年代的高频交易与机器学习 |

**一条值得注意的规律：** 金融科技的每一次热潮，都在重演「技术降低了门槛，但风险特征没变」的剧本。P2P 借贷重演了无监管信贷的周期；稳定币重演了私人货币的兑付问题；算法交易重演了流动性的顺周期收缩。**技术改变的是速度与覆盖面，不是风险的本质结构。**

## 七、2020 年代至今

| 时间 | 事件 | 意义 |
|------|------|------|
| 2020 | 疫情冲击；美联储无限量 QE，与多国扩大货币互换；大规模财政刺激 | 央行准全球最后贷款人角色达到顶峰 |
| 2021 | 通胀回归，多国 CPI 创数十年新高 | 长期低通胀共识被打破 |
| 2022 | 美联储为抑制通胀快速加息；英国养老金 LDI 策略引发国债市场危机；日本维持收益率曲线控制 | 「政策转向引发的市场事故」成为新风险类型 |
| 2023 | 硅谷银行倒闭（利率风险 + 负债集中 + 社交媒体加速挤兑）；瑞士信贷被收购 | 银行危机的新形态：数字化加速的挤兑 |
| 2024 | 主要央行转向降息；美国批准现货比特币 ETF | 加密资产被纳入传统资管框架 |
| 2025 | 稳定币立法落地；多国推进 CBDC；全球债务水平继续上升；去美元化讨论升温 | 货币体系的多极化议题重新进入政策议程 |

**关于「去美元化」的诚实判断：** 讨论很多，但美元在网络效应、市场深度、制度信誉上的优势依然显著。**历史上储备货币的更替都以数十年计，且通常伴随发行国的重大失败。** 把趋势判断等同于时点判断，是这一议题上最常见的错误。

## 八、本期的六条主线

| 主线 | 内容 |
|------|------|
| **储备货币的两难没有解** | 特里芬难题在布雷顿森林体系内无解，在美元本位下也只是被转移，没有被消除 |
| **杠杆从私人转向公共** | 2008 年后家庭与企业去杠杆，政府加杠杆；总债务水平未降。**危机被延后，没有被消除** |
| **相关性在危机中失效** | 1998 年 LTCM、2008 年结构化产品、2022 年 LDI 与股债同跌，同一机制反复发作 |
| **挤兑的形式在变，本质不变** | 从存款挤兑到批发融资挤兑，再到社交媒体加速的数字挤兑。触发更慢或更快，结构一致 |
| **理论创造市场** | Black-Scholes 创造期权市场的报价体系；现代组合理论创造指数化产品。理论不只是解释 |
| **监管套利持续存在** | 分业经营催生影子银行，资本管制催生离岸市场，加密监管催生跨链与匿名工具 |
