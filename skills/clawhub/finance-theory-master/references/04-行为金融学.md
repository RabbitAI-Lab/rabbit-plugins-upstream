# 04 行为金融学

## 一、这一板块回答什么问题

人并不按理性预期与效用最大化行事，偏差是系统性的、不会相互抵消。那么价格会怎样？套利为什么没能纠正它？

行为金融不只是一堆「投资者很傻」的案例合集。它要回答的是一个更硬的问题：**如果偏差是系统性的但套利是有限的，市场价格的偏离会呈现什么规律。**

---

## 二、理论基础：前景理论

### 2.1 核心内容

Kahneman、Tversky（1979）通过实验发现，大多数人的实际决策不符合期望效用理论，并提出替代框架。三个关键成分：

| 成分 | 内容 | 与期望效用的差别 |
|------|------|----------------|
| 参考点依赖 | 效用取决于相对于某个参考点的变化，而非绝对财富水平 | 期望效用以绝对财富为自变量 |
| 损失厌恶 | 同样幅度下，损失的痛苦大于等额收益的愉悦，系数约 2 至 2.5 倍 | 期望效用对盈亏对称 |
| 概率权重 | 小概率被高估，中高概率被低估 | 期望效用使用客观概率 |
| 价值函数形状 | 收益区间为凹（风险厌恶），损失区间为凸（风险寻求） | 期望效用全局风险厌恶 |

### 2.2 关键推论

**损失区间是凸的，意味着亏损时人会转向风险寻求。** 这一条解释了大量行为：

- 亏损后不肯止损，反而加仓摊薄
- 深度虚值期权的系统性高估（相当于买彩票）
- 处置效应（见下）

### 2.3 能解释的现象

前景理论被用来解释阿莱悖论、股权溢价之谜、期权微笑等。**但有一个重要局限：** Kahneman 与 Tversky 没有给出参考点如何确定、价值函数具体形式如何，这极大限制了它的可操作性。这是前景理论从「解释工具」到「可计算模型」之间的主要障碍。

## 三、系统性偏差清单

| 偏差 | 内容 | 市场表现 |
|------|------|---------|
| 过度自信 | 高估自己判断的准确性，低估误差范围 | 交易过度、换手率高、预测区间过窄 |
| 代表性偏差 | 过度重视近期数据的模式，忽略总体特征 | 外推近期增长，造成对消息反应不足后再过度反应 |
| 保守性偏差 | 不能及时根据变化修正预测模型 | 公告后漂移（PEAD） |
| 锚定效应 | 判断被无关数值牵引 | 对历史高点的执念，价格锚定 |
| 可得性偏差 | 容易想起的事件被认为更可能发生 | 近期危机后长期过度悲观 |
| 处置效应 | 倾向过早卖出盈利、过久持有亏损 | 盈利股后续表现优于亏损股（Shefrin-Statman 1985） |
| 心理账户 | 把钱按来源或用途分账，与整体财富效用不一致（Thaler 1985） | 分红与资本利得区别对待；组合分层管理 |
| 后见之明 | 事后认为结果本可预见 | 复盘失效，无法从错误中学习 |
| 羊群效应 | 跟随群体行为 | 题材炒作、抱团、踩踏 |
| 赌徒谬误 | 认为独立事件的概率会自我平衡 | 连跌后过度看涨 |
| 本土偏差 | 过度配置本国资产 | 全球分散不足 |
| 熟悉度偏差 / 控制幻觉 | 偏好自己熟悉的标的，认为更可控 | 集中持仓，分散不足 |
| 减少后悔与推卸责任 | 决策目标包含避免后悔 | 拖延、跟随共识、选择不必负责的选项 |

**关键性质：这些偏差是系统性的。** 它们不会因为人数多而相互抵消，这是行为金融挑战 EMH 第二条论证的核心。

## 四、有限套利

Shleifer、Vishny（1997）提出的这一概念，是行为金融从「描述偏差」走向「解释价格」的关键一步。

### 4.1 核心论点

即使你确信价格错了，也不一定能安全地套利。原因有四个：

| 限制 | 说明 |
|------|------|
| 噪音交易者风险 | 错误定价可能在短期内进一步加剧，套利者可能在正确方向上先亏钱 |
| 代理问题 | 管理他人资金的套利者受业绩考核约束，可能在回撤中被迫平仓 |
| 资金期限错配 | 错误定价的纠正时间不确定，而资金的期限是确定的 |
| 替代品不完美 | 做空需要找到真正可替代的标的，往往找不到 |

**经典例子：** 即使你知道某个资产被高估，做空它的成本（借券费、逼空风险）可能吃掉全部理论收益。在 2000 年互联网泡沫中，很多正确的空头在最终赚钱前已经清盘。

### 4.2 为什么这一条重要

它回应了 EMH 的第三条论证（理性套利者会纠正价格）。**有限套利说明：价格偏离可以长期存在，不是因为没人发现，而是因为发现的人没法安全地兑现。**

**在 A 股的适用性尤其突出。** 做空机制不完善（融券成本高、券源少），意味着套利限制是硬的制度约束而非软的资金约束。这是 A 股高估值纠正缓慢的机制性原因（见 `03-有效市场假说与市场异象.md` 第七节）。

## 五、行为资产定价模型

这是行为金融试图从「批判」走向「建模」的努力。各模型的共同思路是：把投资者分成不同类型，让类型之间的互动决定价格。

| 模型 | 提出者与年份 | 核心结构 |
|------|------------|---------|
| 噪音交易者模型（DSSW） | DeLong、Shleifer、Summers、Waldmann（1990、1991） | 理性套利者与噪音交易者共存；引入噪音交易者风险，证明噪音交易者在某些情况下可获得更高收益 |
| BSV 模型 | Barberis、Shleifer、Vishny（1998） | 两类偏差解释反应模式：选择性偏差导致对消息反应不足，保守性偏差导致过度反应 |
| DHS 模型 | Daniel、Hirshleifer、Subramanyam（1998） | 有信息者存在过度自信与有偏自我归因；金融资产价格对私人信息过度反应、对公开信息反应不足 |
| HS 统一理论模型 | Hong、Stein（1999） | 重点不在认知偏差而在作用机制：把交易者分为「消息观察者」与「动量交易者」，两者的互动同时产生反应不足与过度反应 |
| 行为组合理论（BPT） | Shefrin、Statman | 投资者实际构建的是按目标与风险态度分层的金字塔，而非有效前沿上的点；各层之间的相关性被忽略 |
| 行为资产定价模型（BAPM） | Shefrin、Statman | 把投资者分为「信息交易者」（按 CAPM 行事）与「噪音交易者」（犯各类偏差），两类共同定价 |

**BSV 与 DHS 的关系：** 两者基于不同的行为前提，但结论相似，Fama（1998）就指出过这一点。这说明行为偏差的解释力强，但**从不同偏差出发能推出相近结论，也意味着模型对偏差的选择不够敏感**，这本身是个弱点。

**HS 模型的独特价值：** 它把反应不足和过度反应统一归因于「关于基本价值信息的逐渐扩散」，不需要假设特定的情感刺激或流动性需求。这个「统一」的尝试在方法论上更经济。

## 六、行为金融自身的局限

这一节是本板块最需要被认真对待的部分。行为金融的批评者提出的问题，很多至今没有解决。

### 6.1 四项结构性局限

| 局限 | 内容 | 后果 |
|------|------|------|
| 事后解释倾向 | 大多数行为解释是在观察到异象之后提出的，而非事前预测 | 解释力强，预测力弱；难以区分「解释」与「事后附会」 |
| 偏差参数不稳定 | 偏差的强度随时间、人群、情境变化，没有稳定参数 | 难以做样本外预测，模型难以校准 |
| 缺乏统一模型 | 偏差清单越来越长，但没有一个模型能把它们组织起来 | 可以解释任何现象，反而削弱了可证伪性 |
| 偏差可能相互抵消 | 若不同投资者犯不同方向的偏差，净效应可能为零 | 与 EMH 第二条论证的争论回到原点 |

### 6.2 与 EMH 的争论现状

**这场争论没有胜负。** 更准确的描述是：

- 双方都同意存在系统性偏差
- 分歧在**错误定价的规模与持续性是否足以支撑可获利的策略**
- 复制危机（见 `03-*` 第五节）对这一争论的影响是双向的：它削弱了行为金融用来攻击 EMH 的证据，同时也没有证明市场完全有效

### 6.3 一个常被忽略的自我否定机制

行为金融发现的部分错误定价，会随着被认识和被利用而衰减。这意味着：

> **行为金融的成功本身，部分地削弱了它所描述的现象。**

McLean、Pontiff（2016）发现的「发表后收益下降 58%」，直接印证了这一点。这个自我否定机制使得行为金融的结论天然具有时效性。

## 七、理论定位：与理性框架的关系

### 7.1 不是替代关系

一个常见误解是「行为金融推翻了现代金融理论」。实际情况更接近层次分工：

| 层次 | 理性框架 | 行为框架 |
|------|---------|---------|
| 基准 | 提供可计算的基准（CAPM、有效前沿） | 解释偏离基准的机制 |
| 语言 | 「风险补偿」 | 「错误定价 + 有限套利」 |
| 预测 | 事前的结构性预测 | 主要是事后的机制解释 |

### 7.2 一个实用的分工方式

**用理性框架做基准，用行为框架做偏离分析。**

具体步骤：

1. 先用理性模型算出「若市场有效，应该是什么样」
2. 观察实际与基准的偏离
3. 用偏差清单与有限套利去解释偏离的方向与持续性
4. 判断偏离属于哪一类（风险补偿 / 错误定价 / 数据挖掘）

这个顺序比单用任一派更有产出，因为它天然包含了交叉验证。

### 7.3 无风险偏好与行为角度的共同结论

有一个值得注意的收敛：价值投资与行为金融在若干结论上趋于一致。两者都认为市场会系统性高估成长预期、低估困境反转的可能，且都认为纠正需要时间。

巴曙松对价值投资的评价中有一个观察值得引用：**价值投资是可以训练、积累、学习的，而技术分析和行为金融应用到投资上，更多是一种艺术。** 这句话点出了行为金融在可操作性上的现实位置。

## 八、与其他板块的接口

| 接口 | 说明 |
|------|------|
| 与有效市场假说 | 直接对手方。EMH 的四条论证是被攻击靶子，PEAD 等异象是行为金融的弹药 |
| 与资产定价 | 因子溢价是风险补偿还是错误定价，是两派战场；动量尤其难以用风险解释 |
| 与投资组合理论 | 分散不足（本土偏差、熟悉度、控制幻觉）是反复记录的偏差；BPT 提出实际组合是分层金字塔而非有效前沿上的点 |
| 与公司金融 | 市场择时假说、CEO 风险偏好、同伴效应对资本结构的解释力；管理层过度自信与并购决策 |
| 与风险管理 | 处置效应导致亏损累积、过度自信导致仓位过重、羊群效应放大尾部风险 |
| 与宏观金融 | 凯恩斯的「动物精神」与选美竞赛是最早的行为金融思想；明斯基的代际遗忘机制是行为层面的解释 |

## 九、使用本板块时的三条提醒

1. **区分「解释」和「预测」。** 行为金融擅长解释已发生的现象，不擅长预测未发生的。用行为理论做预测时，必须明确标注这一步是推断而非理论结论。
2. **偏差清单要挑着用。** 有十几个偏差可用时，事后总能找到「一个」符合的。挑之前先想清楚：这个偏差在本场景下有可验证的表现吗？没有就换一个更好的框架。
3. **注意自我否定机制。** 一个错误定价一旦被广泛认识，就会开始衰减。引用行为金融结论时，要说明这个结论在当前是否还成立。
