# 07 风险管理

## 一、这一板块回答什么问题

风险怎么度量？度量本身的失效边界在哪？为什么 2008 年那么多机构带着「安全」的组合出事？

风险管理理论的核心矛盾是：**度量的目的是为了管理风险，但度量本身会制造新的风险。** 一个显示低风险的模型，会让人加大敞口，从而使实际的损失潜力更大。这是这一板块与资产定价、公司金融最不同的地方。

---

## 二、风险的定义与层次

### 2.1 从波动率到不确定性

| 概念 | 内容 |
|------|------|
| 波动率 | 收益的离散程度，方向无关。最简单也最常用的度量 |
| 下行风险 | 只关注负向偏离（下行标准差、最大回撤） |
| 尾部风险 | 极端损失的概率与幅度 |
| 风险 vs 不确定性 | Knight（1921）：风险是可概率化的，不确定性是不可概率化的。多数真正致命的冲击属于后者 |

**关键区分：** 大部分风险模型处理的是「风险」，而危机中真正造成损失的往往是「不确定性」。这是模型与现实的根本错配，而不是参数没调好。

### 2.2 为什么波动率是不够的

两个组合可以有相同的波动率而尾部风险完全不同。波动率只用了分布的二阶矩，对偏度与峰度不敏感。而股权类资产的收益恰恰是**负偏、厚尾**的。

## 三、VaR：主流度量及其问题

### 3.1 定义

VaR 回答的是：**在给定置信水平与持有期内，损失不会超过多少。**

```
P(ΔP ≤ −VaR) = 1 − α
```

由 J.P. 摩根与 G30 集团在 1993 至 1994 年间提出并推广，1994 年通过 RiskMetrics 模型普及，1996 年被巴塞尔委员会用于确定资本充足率。

**三个关键参数：**

| 参数 | 巴塞尔要求 | 说明 |
|------|-----------|------|
| 持有期 | 10 个营业日 | 决定度量的时间尺度 |
| 置信水平 | 99% | 反映风险偏好 |
| 观察期间 | 1 年 | 决定历史数据的窗口 |

### 3.2 三种算法

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| 参数法（方差-协方差） | 假设收益服从正态分布，用均值与协方差算分位数 | 计算简便快速，可解析求解 | 分布假设严格；金融数据厚尾，会低估尾部风险 |
| 历史模拟法 | 用历史收益序列的经验分位数 | 不需要分布假设，直观 | 严重依赖历史数据；假设未来重复过去；对极端情况预测不足 |
| 蒙特卡洛模拟 | 生成大量价格路径，从模拟分布取分位数 | 可处理非线性资产、非正态分布、路径依赖产品 | 计算量大；结果准确性依赖模型与参数假设 |

巴塞尔委员会也认可基于 GARCH、EWMA、TGARCH 等波动率模型的改进方法。

### 3.3 六项结构性局限

| 局限 | 说明 | 后果 |
|------|------|------|
| 尾部盲区 | 只给出阈值，不说明超过阈值后会亏多少 | 同样 VaR 的 200 万美元，尾部损失可能是 200 万也可能是 2000 万，VaR 无法区分 |
| 非次可加性 | VaR 在非正态分布下不满足次可加性，组合 VaR 可能大于各部分 VaR 之和 | 会**惩罚分散化**，不利于识别集中风险。这是 VaR 不满足一致风险度量公理的核心问题 |
| 正态假设低估厚尾 | 参数法假设正态，金融收益实际厚尾 | 极端损失的概率被系统性低估 |
| 顺周期性 | 波动市场里 VaR 升高（迫使减仓），平静市场里 VaR 降低（鼓励加仓） | 在流动性最紧张时迫使抛售，放大压力。这是内生的放大器 |
| 虚假精确 | 输出一个单一数字，掩盖了估计区间之宽 | 让人以为精度很高，实际置信区间可能很宽 |
| 忽略流动性 | 经典 VaR 不考虑市场深度、清算成本、保证金动态 | 危机中流动性消失，实际损失远超 VaR |

### 3.4 2008 年的检验

**银行持有的组合按模型计算出的 VaR 在 2% 至 3% 量级，而 2008 年 9 至 10 月的实际损失超过 VaR 的 5 至 10 倍。**

这是 VaR 局限最有力的实证。它直接推动了监管从 VaR 转向 ES。

**但要注意一个细节：** 后来的研究显示，即使在危机中，VaR 对实际损失的覆盖率也只有约 26% 至 66%（视资产与情景而定），ES 约 53% 至 87%。**ES 更好，但在极端情景下也不够。** 这一点很重要：不要把 ES 当作解决方案，它只是改善。

## 四、ES / CVaR

### 4.1 定义

预期损失（Expected Shortfall，ES），又称条件风险价值（CVaR），度量的是**损失超过 VaR 之后的平均损失**。

```
ES_α = E[L | L > VaR_α]
```

### 4.2 优势

| 优势 | 说明 |
|------|------|
| 度量尾部严重程度 | 直接回答「超过阈值后有多惨」 |
| 满足次可加性 | 是一致风险度量（Acerbi、Tasche 2001），正确奖励分散化 |
| 监管认可 | 巴塞尔的 FRTB（交易账户基本审查）正在把资本计量从 VaR 转向 ES |

### 4.3 局限

| 局限 | 说明 |
|------|------|
| 不易沟通 | 比 VaR 抽象，对非技术受众解释成本高 |
| 数据需求更大 | 尾部数据稀疏，估计更困难 |
| 对极端离群值敏感 | 越靠尾部的估计越不稳定 |
| 在危机中仍不够 | 见 3.4 的覆盖率数据 |

**关键提醒：VaR 与 ES 的关系是「阈值」与「阈值之后的均值」。** 用 ES 不等于抛弃 VaR，实务中两者配合使用。

## 五、波动率建模

| 模型 | 特点 | 使用场景 |
|------|------|---------|
| EWMA（RiskMetrics） | 指数加权移动平均，近期数据权重更高 | 简单快速的波动率估计 |
| GARCH（Bollerslev 1986） | 波动率有聚集性，当期波动依赖过去波动与过去冲击 | 最常用的条件波动率模型 |
| EGARCH | 允许正负冲击对波动率有非对称影响 | 捕捉杠杆效应（跌时波动上升更多） |
| 随机波动率 | 波动率本身是随机过程 | 期权定价与复杂衍生品 |

**波动率聚集性是这一块的经验基础：** 高波动之后往往还是高波动，低波动之后往往还是低波动。这违反了独立同分布假设，是 VaR 参数法的直接问题来源。

## 六、极值理论（EVT）

**目标：** 只对分布的尾部建模，把尾部外推到样本稀疏的高分位数。

| 方法 | 分布 | 说明 |
|------|------|------|
| 超阈值法（POT） | 广义帕累托分布（GPD） | 对超过高阈值的部分建模 |
| 区块最大值法 | 广义极值分布（GEV） | 对分块最大值建模 |

**实践问题：**

- 阈值选择需要靠平均超额图等方法判断，存在主观性
- 需要处理序列相关（去聚集）
- 参数不确定性高，稳定性检验是必需的

**价值：** 它让「99.9% 分位数」这类历史数据几乎不覆盖的估计成为可能。但代价是引入了更强的模型假设。**这是用模型风险换取尾部精度，交易是否划算取决于用途。**

## 七、压力测试与情景分析

| 类型 | 内容 |
|------|------|
| 历史情景 | 重演 2008 信用紧缩、2013 缩减恐慌、2020 疫情抛售等已发生事件 |
| 假设情景 | 构造未发生但合理的宏观与市场冲击 |
| 反向压力测试 | 先问「什么情景会让组合触及风险底线或资本限额」，再倒推该情景的可能性 |

**实施要点：**

1. 在关键风险因子上定义冲击，然后完整重估组合，不要用近似
2. 必须包含流动性、基差、融资压力的冲击，不能只做价格冲击
3. 报告 P&L、盈亏平衡点与脆弱环节，不只报一个损失数字

**压力测试在方法论上优于 VaR 的地方：** 它不假设未来像过去，因此可以处理 Knight 意义上的不确定性。**它的弱点则相反：情景是人选的，会系统性地遗漏没想到的事情。**

## 八、VaR 模型的回测

模型必须被验证，这是风险管理中最容易被跳过的一步。

| 方法 | 检验什么 |
|------|---------|
| 突破计数 | 实际盈亏超过 VaR 的频率应接近 1 − α（99% VaR 约 1%） |
| Kupiec POF 检验 | 无条件覆盖率是否达标 |
| Christoffersen 检验 | 突破是否独立（不能聚集） |
| 交通灯框架 | 监管用的分级处置机制 |

**如果突破聚集或超出容忍度：** 需要重新校准窗口与参数、增强因子映射、或改用更丰富的方法论，并记录模型变更与治理过程。

**回测的核心价值：** 它把「模型说风险很低」这个断言变成一个可检验的命题。没有回测的风险模型，本质上是一个未经检验的假设。

## 九、其他风险类别

### 9.1 信用风险

| 模型类型 | 代表 | 思路 |
|---------|------|------|
| 结构化模型 | Merton（1974） | 把股权看作对公司资产的看涨期权；违约发生在资产价值低于负债时 |
| 约化模型 | Jarrow-Turnbull 一系 | 不解释违约原因，直接对违约强度建模 |
| 组合信用模型 | CreditMetrics、KMV | 从单一债务人扩展到组合的相关违约 |

**结构化模型的理论价值：** 它把公司金融（资本结构）与风险管理连接起来，违约概率直接取决于杠杆水平。这是本板块与 `05-公司金融.md` 最直接的接口。

### 9.2 流动性风险

**2008 年最重要的教训之一是：流动性风险与市场风险不可分离。**

在市场压力下，买卖价差扩大、做市商承接意愿下降，导致所有资产同时下跌。传统的流动性调整 VaR 或附加项可以部分处理这个问题，但无法在平静期预测压力期的流动性塌陷。

### 9.3 操作风险与模型风险

| 类别 | 说明 |
|------|------|
| 操作风险 | 流程、人员、系统、外部事件导致的损失 |
| 模型风险 | 模型本身成为损失来源：假设错误、参数不稳、误用、治理缺失 |

**模型风险的计算意义：** 所有风险度量的输出都是模型输出。模型误差不会被其他模型自动抵消，反而可能相互叠加。

### 9.4 相关性失效

与 `02-投资组合理论.md` 第六节同源，但在风险管理场景下后果更严重：

| 现象 | 数据 |
|------|------|
| 主要股票市场间相关性在 2008 年飙升至 0.90 以上 | 几乎消除国际分散化 |
| 股债相关性在 2022 年由负转正（约 +0.55） | 打破 2000 至 2021 年的结构性假设 |
| 黄金在四个危机区间均保持接近零或负相关 | 唯一稳定的分散化工具 |

**对风险管理的直接含义：** 用平静期相关性计算的风险预算，在最需要保护的时期会严重不足。压力测试必须使用危机期相关性。

## 十、本板块的元问题

### 10.1 度量的悖论

**风险度量会改变行为，从而改变被度量的风险。**

一个显示低风险的模型会鼓励加仓，加仓会提高实际风险，而模型在下一次更新时才会反映出来。这个滞后正是顺周期性的来源。

**这不是可以通过改进模型解决的问题，而是度量这件事本身的性质。** 任何被用作决策依据的风险指标，都会产生这个效应。

### 10.2 一致风险度量公理

一个「好的」风险度量应满足四条公理：单调性、正齐次性、平移不变性、次可加性。VaR 满足前三条但在非正态下不满足次可加性，ES 满足全部四条。这是为什么学术与监管都倾向于 ES。

**但要注意：** 满足公理不等于适用于所有目的。**VaR 作为限额语言仍然有效**（交易台说「日 VaR 上限 1000 万」是清晰可执行的），而 ES 在沟通上更难。实务中两者配合。

### 10.3 一个诚实的现状

风险管理领域的技术工具已经相当精细，但它没有也不可能消除风险。**风险管理的实际功能是让损失可承受、可预期、可归因，而不是让损失不发生。**

对风险的错误认知（以为风险已被消除）比风险本身更危险。

| 接口 | 说明 |
|------|------|
| 与资产定价 | 期权定价的希腊字母是风险对冲的基础；BS 的分布假设直接进入参数法 VaR |

| 与货币宏观金融 | 危机机制的理解决定压力测试情景的设计；明斯基的融资结构三分法可用于识别系统性风险积累 |
| 与行为金融 | 处置效应导致亏损累积、过度自信导致超配、羊群效应放大尾部 |

## 十二、使用本板块时的三条提醒

1. **先问「用来干什么」。** 用于沟通限额，VaR 可用；用于资本计量，ES 更合适；用于极端情景，必须用压力测试。同一个风险，用途不同工具不同。
2. **任何风险指标都要配回测。** 没有回测的风险数字是未经检验的假设，不能作为决策依据。
3. **把顺周期性写进方案。** 使用 VaR 类指标时，必须同时说明它在压力期会迫使减仓，并预先规定反周期的处理方式（如使用固定高波动期的压力 VaR、不把 VaR 作为唯一减仓触发条件）。
