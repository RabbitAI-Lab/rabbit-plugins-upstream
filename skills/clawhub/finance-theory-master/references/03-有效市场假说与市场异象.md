# 03 有效市场假说与市场异象

## 一、这一板块回答什么问题

价格里到底反映了多少信息？公开信息能不能用来赚钱？如果发现某种能赚钱的模式，那是风险补偿、是错误定价，还是统计幻觉？

这一板块是金融学争论最激烈的地方，也是最重要的地方。因为「市场是否有效」这个问题的答案，决定了主动管理、基本面研究、量化策略、被动指数化各自的生存空间。

---

## 二、有效市场假说（EMH）

### 2.1 三种形式

Fama 在 1965 年提出初步表述，1970 年的综述给出经典的三分：

| 形式 | 价格反映了什么信息 | 推论 | 如何检验 |
|------|------------------|------|---------|
| 弱式 | 所有历史价格与成交量 | 技术分析无效 | 收益序列相关性、游程检验 |
| 半强式 | 所有公开信息 | 基本面分析无效 | 事件研究（看公告后的异常收益） |
| 强式 | 所有信息，包括未公开的 | 内幕交易也无效 | 内幕交易者收益、专业机构业绩 |

**三种形式是嵌套的：** 强式成立则半强式成立，半强式成立则弱式成立。反过来不成立。所以现实中通常观察到的是「弱式基本成立、半强式部分成立、强式不成立」。

### 2.2 理论支撑

EMH 不是单靠一条论证支撑，而是三条独立论证的叠加，Fama 的表述是层层递进的：

1. 如果投资者理性，会理性评估资产价值，市场有效
2. 即使部分投资者非理性，只要交易是**随机**产生的，错误会相互抵消，价格仍然有效
3. 即使非理性不是随机的，理性套利者会纠正价格
4. 即使套利不能完全纠正，非理性投资者的财富会逐渐减少，长期无法存活

**这四条论证是行为金融的主要攻击对象。** 尤其是第 2 条和第 3 条，行为金融用「系统性偏差」反驳第 2 条，用「有限套利」反驳第 3 条。

### 2.3 联合假说问题（最重要的方法论限制）

Fama（1970）本人就明确指出：**要检验市场有效性，必须先假定某个资产定价模型是正确的。**

原因：所谓的「异常收益」，是实际收益减去模型预测的正常收益。你无法区分下面两种情况：

- 市场无效，价格偏离了基本面
- 市场有效，但你的模型错了

**这就是「联合假说问题」，也有文献称为「坏模型问题」。**

**直接后果：**

1. 「发现了异象」严格说只是「相对于某模型存在异常」。任何异象讨论必须写明用的是哪个模型
2. EMH 严格意义上**不可单独检验**
3. 这个困局是「实证金融」与「行为金融」长期争论不下的技术根源

## 三、主要市场异象

### 3.1 清单

| 异象 | 内容 | 关键文献 |
|------|------|---------|
| 规模效应 | 小市值股票收益高于大市值 | Banz（1981） |
| 价值效应 | 高账面市值比（低估值）股票收益更高 | Basu（1977）、Fama-French（1992） |
| 动量 | 过去 3 至 12 个月表现好的股票继续跑赢 | Jegadeesh、Titman（1993） |
| 长期反转 | 过去 3 至 5 年表现差的股票后来跑赢 | DeBondt、Thaler（1985） |
| 低波动率异象 | 低波动率、低 beta 股票的风险调整后收益更高 | 后续多篇；BAB 因子（Frazzini-Pedersen 2014） |
| 盈利与投资 | 高盈利、低投资的公司收益更高 | Fama-French（2015） |
| 盈利公告后漂移（PEAD） | 财报超预期后价格在数周内继续同向移动 | Ball、Brown（1968） |
| 动量崩溃 | 动量策略在市场反弹后出现剧烈回撤 | Daniel、Moskowitz（2016） |
| 一月效应 | 小盘股效应大部分集中在 1 月 | 多篇 |

### 3.2 PEAD 为什么特别重要

PEAD 是行为金融最有力的证据之一。逻辑很简单：

- 如果市场半强式有效，财报公布的那一刻价格就该调整到位
- 实际上，价格会在之后数周内继续朝同一方向移动
- 这意味着公开信息**没有**被立即完全反映

**注意：** 动量与长期反转是一对看似矛盾的现象。短中期动量、长期反转，两者同时存在。行为金融用「反应不足」与「反应过度」的组合来解释（见第四节）。

### 3.3 异象的三种解释

这是元判断 3 的具体展开。

| 解释 | 逻辑 | 预测 | 如何区分 |
|------|------|------|---------|
| 风险补偿（理性） | 这些资产承担了投资者厌恶的风险，高收益是公平补偿 | **发表后不衰减**，套利无法消除风险溢价 | 找独立于已知因子的风险暴露 |
| 错误定价（行为） | 投资者系统性偏差造成偏离，套利力量不足以纠正 | **发表后衰减**，资金入场纠正 | 看发表前后收益变化 |
| 数据挖掘（统计） | 多重检验下的偶然显著 | **样本外即消失** | 看样本外与跨市场复现 |

**分因子的判断（文献中的一般看法）：**

| 因子 | 风险解释是否讲得通 | 行为解释是否讲得通 |
|------|-----------------|-----------------|
| 价值 | 讲得通（困境企业在衰退中表现差） | 讲得通（投资者外推过去增长） |
| 动量 | 难（它在市场反弹后崩溃，且对显而易见的风险因子是负暴露） | 讲得通（反应不足 + 处置效应） |
| 低波动率 | 主要是约束故事（杠杆限制、基准约束） | 弱 |
| 规模 | 讲得通（小企业在信贷紧缩中难再融资） | 讲得通 |

**这个区别有直接的操作含义：** 如果是风险补偿，溢价在套利下应该存活；如果是错误定价，应随更多资金入场而衰减。判断一个因子的未来，就是判断它属于哪一类。

## 四、行为金融对 EMH 的挑战（交叉视角）

本节只列与 EMH 争论直接相关的部分，完整内容见 `04-行为金融学.md`。

| EMH 的论证 | 行为金融的反驳 | 关键概念 |
|-----------|--------------|---------|
| 非理性交易随机产生，相互抵消 | 偏差是**系统性的**，不会因为平均而消失 | 前景理论、过度自信、代表性偏差 |
| 理性套利者会纠正价格 | **有限套利**：即使知道定价错误，也无法安全套利 | 噪音交易者风险、代理问题、资金期限 |
| 非理性者财富减少后被淘汰 | 某些情形下非理性者收益更高，可以长期存续 | 噪音交易者模型（DSSW 1990） |
| 价格反映所有公开信息 | PEAD 等证据显示公开信息反应不足 | 反应不足与过度反应 |

**核心分歧的实质：** 不是「理性」对「非理性」，而是**「错误定价的规模与持续性是否足以支撑可获利的策略」**。两派都承认存在偏差，分歧在量级与经济意义。

## 五、复制危机：异象本身的可靠性问题

这是 2015 年之后这一板块最重要的进展。它把争论从「EMH 对不对」转向了一个更基本的问题：**那些用来质疑 EMH 的异象，自己站得住吗？**

### 5.1 核心研究

| 研究 | 结论 |
|------|------|
| Harvey、Liu、Zhu（2016） | 已发表因子 316 个；多重检验下标准 t 门槛过低，主张提到约 3.0 |
| McLean、Pontiff（2016） | 97 个预测变量：样本外低 26%，发表后低 58%；32 个百分点的差值归因于发表后的知情交易 |
| Linnainmaa、Roberts（2018） | 用发表前的历史数据检验，多数异象在原始样本期之前并不存在 |
| Hou、Xue、Zhang（2020） | 统一方法复制 452 个异象：65% 过不了 t > 1.96，82% 过不了门槛 2.78 |
| Chordia、Goyal、Saretto（2020） | 另一套统计工具得出「大量显著为假阳性」 |
| Jensen、Kelly、Pedersen（2023） | 贝叶斯视角：93 个国家的多数因子方向可复现，但幅度小于原报告 |
| Swade、Hanauer、Lohre、Blitz（2024） | 约 15 个因子足以张成整个因子空间 |

### 5.2 对两边都是打击

这一批研究的结果对争论双方都不利，这是它最有意思的地方：

- **对行为金融派：** 用来质疑 EMH 的异象，绝大多数是统计幻觉。样本外的衰减恰恰是数据挖掘的典型特征
- **对 EMH 派：** 但异象并没有完全消失。发表后收益下降 58%，剩下 42%。如果市场完全有效，应该归零

**McLean-Pontiff 自己的解读是三分的：** 样本外下降 26% 是数据挖掘的上界；额外 32 个百分点是知情交易的作用，说明投资者从学术发表中学习；剩余部分说明存在真实的风险补偿或未被消除的错误定价。

### 5.3 方法论的教训

这批研究给出的操作规则，适用于所有金融实证结论：

1. **t 值 2.0 不是门槛。** 在已测试数百个假设的领域，门槛应显著提高
2. **样本外是必需的，不是可选的。** 样本内显著几乎没有信息量
3. **发表后衰减是常态。** McLean-Pontiff 之前，多数研究默认异象会持续
4. **看回测要问搜索过程。** 报出来的回测是「一次搜索中的最好结果」，不是「策略的期望结果」。Deflated Sharpe Ratio（López de Prado、Bailey 2014）就是为此设计的校正工具
5. **谨慎对待自动化因子挖掘。** 参数越多，越可能拟合噪音，且这个问题在遇到研究者没见过的数据前不可见

## 六、其他效率视角的证据

| 视角 | 发现 | 含义 |
|------|------|------|
| 主动管理业绩 | Fama、French（2010）发现扣除费用后主动基金整体为负的 alpha | 支持半强式有效 |
| 个股整体表现 | Bessembinder（2018）：多数个股长期跑不赢国库券，全部净财富创造集中在少数股票 | 指数化的理论依据 |
| 事件研究 | 大多数事件（并购、分红、拆股）的公告效应快速且方向明确 | 支持半强式 |
| 内幕交易 | 内幕交易者有显著超额收益 | 强式不成立 |
| 专业机构业绩 | 少数机构持续跑赢，但样本小、难以区分技能与运气 | 争议状态 |

**Bessembinder 的发现值得单独说。** 它解释了为什么「分散持有」在长期如此重要：个股收益分布极度右偏，少数股票贡献了全部净财富。这意味着**挑选个股的期望结果远比直觉差**。这一发现与投资组合理论中分散化的结论互相印证。

## 七、中国市场有效性专章

以下内容是本板块的落地部分，也是使用时最需要标注不确定性的地方。

### 7.1 现状判断

学术与业界的普遍共识是：**A 股尚未达到标准的半强式有效，整体处于从弱式有效向半强式有效过渡的阶段。**

需要提醒的是，这个判断具有时效性。注册制改革、退市新规、机构占比提升、量化资金普及都在改变这个状态。

### 7.2 结构性与制度性因素

| 类别 | 因素 | 对有效性的影响 |
|------|------|--------------|
| 参与者结构 | 散户持股市值占比约 30%，但贡献 70% 以上的交易量 | 噪音交易多，价格更多围绕情绪而非价值波动 |
| 换手率 | 长期位居全球主要市场前列，部分年份超 200% 至 300% | 高换手本身不创造价值，是无效性的直接度量 |
| 波动率 | 显著高于成熟市场，科创板块年化波动率可达 40% 以上 | 相当部分来自噪音而非基本面 |
| 交易制度 | 涨跌停板 + T+1 | 截断价格发现（好消息不能一天到位），限制日内纠错 |
| 做空机制 | 融券成本高、券源少 | 缺少价格发现的「反向力量」，高估值的纠正只能靠多头换手和时间 |
| 政策权重 | 宏观与产业政策对定价的影响权重高于成熟市场 | 政策预期的多轮博弈拉长了价格发现过程 |
| 机构行为 | 短期排名压力导致抱团追热点、换手率高 | 机构未能有效充当稳定器和纠错力量 |
| 信息披露 | 及时性与完整性仍在完善 | 阻碍向半强式迈进 |

### 7.3 哪些理论在 A 股更适用，哪些更不适用

| 理论 | 在 A 股的适用性 | 原因 |
|------|--------------|------|
| 弱式有效 | 部分成立，但反转与动量异象长期显著 | 制度限制下信息反映速度慢 |
| 半强式有效 | 明显不成立 | 公开信息反应滞后，存在数天至数周的消化期 |
| CAPM | 横截面解释力弱，与成熟市场同样差甚至更差 | 单因子结构无法容纳 A 股的规模、反转等系统性差异 |
| 多因子模型 | 需谨慎，因子定义需本土化 | 因子在 A 股的显著性排序与美股不同，且样本期短、制度变更频繁 |
| 行为金融 | **适用性较高** | 散户交易占比高、偏差表现更为集中且稳定 |
| 有限套利 | **适用性突出** | 做空机制不完善，套利限制比成熟市场更真实、更硬 |
| 均值方差组合 | 参数估计问题更严重 | 样本期短，波动结构不稳定 |
| 相关性分散 | 危机期相关性上升的现象同样存在 | 无本质差别 |
| 复制危机的方法论 | **必须应用** | A 股样本期更短、制度变更更多，数据挖掘风险高于成熟市场 |

### 7.4 在 A 股场景下讨论有效性的三条纪律

1. **先说明检验时点。** A 股制度变更频繁，任何有效性判断都带有时间戳
2. **区分制度性无效与行为性无效。** 涨跌停和 T+1 造成的是制度性摩擦，散户偏差造成的是行为性偏离，两者的政策含义不同
3. **不要用成熟市场的因子清单直接套用。** 因子的显著性排序、样本期长度、交易成本结构都不同

## 九、使用本板块时的三条提醒

1. **谈有效性别忘模型口径。** 这是联合假说问题，也是本板块最容易犯的错误。说「A 股无效」时必须说明相对于什么模型。
2. **异象结论必须过三道关。** 多重检验校正、跨市场与样本外复现、扣除成本后存在。缺一道都不完整。
3. **区分三种解释再谈未来。** 风险补偿会存活，错误定价会衰减，数据挖掘会消失。不分类就讨论「这个因子还行不行」，讨论是无效的。
