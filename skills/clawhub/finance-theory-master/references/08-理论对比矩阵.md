# 08 理论对比矩阵

## 一、这一份解决什么问题

前面七个文件是分板块的纵向整理。这一份做两件事：

1. **横向对比**：把全部理论放到同一组坐标上比较，包括假设强度、数据要求、实证地位
2. **关系梳理**：说清哪些理论互补、哪些冲突、哪些是不同层次的东西

需要理论选型、判断争议状态、找文献出处时，先看这一份。

## 二、主对比表（一）：定位与状态

| 理论 | 提出者（年份） | 核心命题 | 假设强度 | 实证地位 |
|------|--------------|---------|---------|---------|
| 现值/戈登增长 | 传统框架 | 价格 = 未来现金流贴现 | 低（是恒等式） | 稳健（作为框架） |
| 随机贴现因子框架 | Cochrane 系统化（2001） | 所有资产定价都是对 m 的指定 | 低（是框架） | 稳健（作为统一语言） |
| 现代投资组合理论 | Markowitz（1952） | 分散化在给定收益下降风险 | 中 | 稳健（数学结论） |
| 分离定理 | Tobin（1958） | 最优风险组合与偏好无关 | 中 | 稳健 |
| CAPM | Sharpe（1964）、Lintner（1965）、Mossin（1966） | 只有系统性风险被定价 | 强 | 有争议（横截面被削弱） |
| APT | Ross（1976） | 无套利推出多因子线性结构 | 中 | 有争议（因子未指定） |
| 三因子模型 | Fama-French（1993） | 规模与价值解释横截面 | 中 | 有争议 |
| 五因子/六因子 | Fama-French（2015、2018） | 增加盈利与投资 | 中 | 有争议 |
| Q 因子模型 | Hou-Xue-Zhang（2015） | 用 q 理论重构因子 | 中 | 有争议 |
| 期权定价 | Black-Scholes（1973）、Merton（1973） | 无套利 + 动态复制 | 强 | 无套利原理稳健；分布假设已削弱 |
| 期限结构三假说 | 传统 | 解释收益率曲线形状 | 中 | 各有部分解释力 |
| CCAPM | Lucas（1978）、Breeden（1979） | 贴现因子源于消费边际效用 | 中 | 逻辑稳健，标准版本被击败 |
| 有效市场假说 | Fama（1965、1970） | 价格反映可得信息 | 强 | 有争议。弱式基本成立，半强式部分成立，强式不成立 |
| 前景理论 | Kahneman-Tversky（1979） | 参考点依赖、损失厌恶、概率权重 | 低 | 稳健（作为心理学事实） |
| 有限套利 | Shleifer-Vishny（1997） | 错误定价无法被安全套利 | 低 | 稳健 |
| 行为资产定价模型 | DSSW（1990）、BSV（1998）、DHS（1998）、Hong-Stein（1999） | 不同投资者类型互动决定价格 | 低 | 解释力强，预测力弱 |
| MM 定理 | Modigliani-Miller（1958、1963） | 完美市场下资本结构无关 | 极强 | 套利逻辑稳健 |
| 权衡理论 | 后继发展 | 税盾与困境成本权衡出最优杠杆 | 中 | 有争议（部分支持） |
| 代理理论 | Jensen-Meckling（1976） | 代理成本影响资本结构 | 中 | 有支持 |
| 信号理论 | Ross（1977） | 融资选择传递内部信息 | 中 | 有支持 |
| 啄食顺序 | Myers-Majluf（1984） | 内源 > 债务 > 权益 | 中 | 有争议（部分支持） |
| 货币数量论 | Fisher（1911）、Friedman（1956） | 货币供给通过价格反映 | 中 | 长期稳健，短期有争议，货币需求稳定性已削弱 |
| 泰勒规则 | Taylor（1993） | 利率对通胀与产出缺口系统性反应 | 中 | 有争议（描述力下降） |
| 明斯基金融不稳定假说 | Minsky（1963、1986、1991） | 稳定内生地产生脆弱性 | 低 | 有争议（事后解释强，事前预测弱） |
| 金融加速器 | Bernanke-Gertler-Gilchrist（1999） | 信息不对称放大冲击 | 中 | 有支持（已成共识机制） |
| 利率平价 | 传统 | 利差决定汇率变动 | 中 | CIP 2008 后出现持续偏离；UIP 已显著削弱 |
| 三元悖论 / 二元悖论 | Mundell-Fleming；Rey（2015） | 政策目标不可兼得 | 中 | 有争议（需结合资本管制等现实条件） |
| VaR | J.P.摩根、G30（1993–94） | 给定置信度下的最大损失阈值 | 中 | 已削弱（作为唯一度量；2008 检验失败） |
| ES / CVaR | Acerbi-Tasche（2001） | 尾部平均损失，一致风险度量 | 中 | 稳健（理论上更优），但危机中仍不足 |
| Merton 结构化信用模型 | Merton（1974） | 股权是对公司资产的看涨期权 | 中 | 稳健（作为框架） |

## 三、主对比表（二）：适用与局限

| 理论 | 适用场景 | 主要局限 | 互补理论 | 冲突理论 |
|------|---------|---------|---------|---------|
| 现值/戈登增长 | 现金流可预测的成熟资产估值 | 终值假设主导结果；对贴现率极敏感 | 全部资产定价模型 | 无（是共同基础） |
| 随机贴现因子 | 组织与统一资产定价讨论 | 不指定 m 就无法计算 | 全部资产定价模型 | 无 |
| MPT | 组合构建的概念框架 | 期望收益估不准；单期；忽略尾部 | CAPM、风险平价 | 1/N 之谜在实务层面挑战其价值 |
| CAPM | 资本成本估算、绩效归因、风险分解 | Roll 批判（市场组合不可观测）；横截面表现差 | MPT、WACC | 多因子模型、行为金融 |
| APT | 多因子框架的理论合法性 | 因子未指定，难以证伪 | 多因子模型 | 无（是多因子模型的方法论源头） |
| 多因子模型 | 横截面收益解释、因子投资 | 因子不稳健；样本外衰减；多重检验问题 | APT、行为金融（提供机制解释） | CAPM（单因子结构） |
| 期权定价 | 衍生品定价、对冲、波动率交易 | 常数波动率与对数正态已被证伪；跳跃风险不可对冲 | 随机波动率、跳跃扩散、局部波动率 | 无（扩展而非替代） |
| CCAPM | 资产定价的理论根基 | 标准幂效用版本被实证击败；三个谜题未解 | 习惯形成、长期风险、罕见灾难 | CAPM 是一般均衡下的一种近似，两者关系是层次而非对立 |
| EMH | 判断主动管理的价值空间 | 联合假说问题（严格不可单独检验） | 资产定价模型（必须配对使用） | 行为金融 |
| 前景理论 | 解释个人决策偏离期望效用 | 参考点与价值函数形式未确定，难计算 | 行为资产定价模型 | 期望效用理论 |
| 有限套利 | 解释错误定价为何持续 | 难以量化套利限制的强度 | 行为资产定价模型 | EMH 的第三条论证 |
| 行为资产定价模型 | 解释市场层面的偏离机制 | 事后解释倾向；缺乏统一模型；参数不稳 | 有限套利、前景理论 | CAPM、EMH |
| MM 定理 | 分析资本结构的基准框架 | 假设极端；静态；无实证支撑其结论本身 | 权衡理论、代理理论、啄食顺序 | 三者都以它为基准作出修正，不是简单对立 |
| 权衡理论 | 解释行业间杠杆差异 | 困境成本难量化；不解释高盈利低杠杆 | MM、代理理论 | 啄食顺序（在负债率决定因素上） |
| 代理理论 | 治理与资本结构、并购与自由现金流 | 代理成本难量化 | MM、权衡理论 | 无直接对手 |
| 信号理论 | 融资公告的价格效应 | 检验困难（信号与基本面混淆） | 啄食顺序、代理理论 | 无直接对手 |
| 啄食顺序 | 解释融资顺序偏好 | 不解释目标杠杆；不解释部分企业行为 | 信号理论 | 权衡理论 |
| 货币数量论 | 长期通胀与货币关系 | 货币需求稳定性已削弱 | 货币政策框架 | 明斯基等后凯恩斯视角 |
| 泰勒规则 | 政策基准、政策路径讨论 | 依赖不可观测的 r* 与潜在产出；忽略金融变量 | 预期锚定框架 | 危机期与供给冲击期的实际政策 |
| 明斯基 | 解释危机机制与风险积累 | 微观不必然推广到宏观；难形式化；事前预测弱 | 金融加速器、债务通缩 | 主流宏观（认为波动源于外部冲击） |
| 金融加速器 | 解释金融如何放大冲击 | 参数校准难；对金融部门的刻画仍简化 | 明斯基（提供动因） | 无（已被主流接受） |
| 利率平价 | 长期汇率锚、套息交易分析 | UIP 失效；CIP 2008 后偏离 | 三元悖论 | 现实中的汇率行为 |
| 三元悖论 | 开放经济的政策约束分析 | 二元悖论指出汇率浮动换取独立的空间被削弱 | 二元悖论 | 无（是被修正而非取代） |
| VaR | 限额沟通、日常风险监控 | 尾部盲区、非次可加、顺周期、忽略流动性 | ES、压力测试 | 一致风险度量要求（ES） |
| ES / CVaR | 资本计量、尾部风险度量 | 沟通难；数据需求大；危机中仍不足 | VaR、极值理论 | 无（是改进而非替代） |

## 四、假设强度排序

这是理论选型的第一把尺子。假设越强，结论越锐利，也越容易被证伪。

| 强度 | 理论 | 结论特征 | 使用建议 |
|------|------|---------|---------|
| 极强 | MM 无税定理、EMH 强式 | 干净、反直觉、可解析 | 作为基准使用，不作为现实描述 |
| 强 | CAPM、Black-Scholes、EMH 半强式 | 有闭式解、可计算 | 可用，但必须核验假设 |
| 中 | APT、多因子模型、权衡理论、啄食顺序、泰勒规则、VaR、利率平价 | 结构灵活、参数增多 | 可用，需说明参数选择 |
| 低 | 行为金融、有限套利、前景理论、明斯基 | 解释力强、预测力弱、可证伪性低 | 用于机制解释，不用于定量预测 |
| 框架级 | SDF、现值恒等式、MPT 的数学结构 | 是组织方式而非可证伪命题 | 作为统一语言使用 |

**一个反直觉的规律：** 假设强度与实证表现**不是**正相关的。假设越强的理论（如 CAPM）实证表现越差；假设越弱的理论（如行为金融）能解释的现象越多。原因在元判断 2：强假设换来锐利结论，代价是更容易被现实推翻。

## 五、数据要求排序

| 数据要求 | 理论 | 说明 |
|---------|------|------|
| 无 | 有限套利、前景理论、明斯基框架 | 概念性框架，不需数据即可讨论 |
| 低 | 1/N 等权、等风险预算 | 只需资产的波动信息 |
| 中 | CAPM（需 beta）、多因子模型（需因子收益）、泰勒规则（需通胀与产出缺口） | 需估计少量参数 |
| 高 | 均值方差优化（需期望收益、方差、协方差）、DCF（需现金流预测与贴现率）、CCAPM（需消费数据） | 参数数量随资产数平方增长 |
| 极高 | VaR（参数法需完整协方差矩阵）、极值理论（需大量尾部样本）、结构化信用模型（需资产价值与波动率） | 参数多且尾部数据稀疏 |

**规律：数据要求越高的理论，实务表现越不理想。** 因为参数越多，估计误差越大。这是 1/N 之谜的根源，也是「简单方法常常更好」在金融里的具体体现。

## 六、六大流派分野

金融理论的争论不是散点式的，它沿几条清晰的流派线展开。

| 流派 | 核心立场 | 代表理论与人物 | 学术阵地 |
|------|---------|--------------|---------|
| 芝加哥学派 / 新古典 | 市场有效、理性预期、均衡分析 | EMH、CAPM、多因子模型；Fama、Miller、Sharpe | 芝加哥大学 |
| 行为学派 | 偏差是系统性的，套利是有限的 | 前景理论、有限套利、行为资产定价；Kahneman、Tversky、Thaler、Shiller | 耶鲁、加州伯克利 |
| 新凯恩斯 | 价格黏性、市场不完全、政策有效 | 泰勒规则、DSGE、金融加速器；Bernanke、Taylor | 美联储体系、MIT |
| 后凯恩斯 / 货币学派 | 金融内生地产生不稳定，不确定性不可概率化 | 明斯基、债务通缩；Minsky、Fisher | 非主流，危机后获得关注 |
| 制度 / 法金融 | 制度与法律决定金融发展与企业行为 | LLSV 一系 | 世界银行体系 |
| 实证复制派 | 先问证据站不站得住，再谈理论 | 因子动物园批判、复制研究；Harvey、Hou、Xue、Zhang | 横跨各校 |

**两个值得注意的地方：**

1. **芝加哥学派的内部也发生了分歧。** Fama 是 EMH 的代表，但他同时是因子研究的开创者。他的三因子模型本身就承认了单因子结构无法解释横截面。而在 EMH 与行为金融的争论中，Fama（1998）对行为金融的攻击主要集中在「异象本身不稳健」，这个立场后来被复制危机以另一种方式证实了一半。
2. **复制派的立场不属于任何一派。** 它们的结论对双方都不利：削弱了行为金融的异象弹药，也没有证明市场完全有效。

## 七、十组核心争论

| # | 争论 | 甲方立场 | 乙方立场 | 现状 |
|---|------|---------|---------|------|
| 1 | 市场是否有效 | 价格反映信息，主动管理难有价值 | 存在系统性错误定价，套利受限 | 无定论。弱式基本成立，强式明确不成立，争议集中在半强式 |
| 2 | 因子溢价的性质 | 风险补偿，应存活于套利 | 错误定价，应随资金入场衰减 | 分因子而异。价值与规模两者都讲得通；动量难用风险解释；低波动率主要是约束故事 |
| 3 | 异象的真伪 | 大部分是数据挖掘 | 样本外衰减说明存在学习效应，但未归零 | 复制研究提供了有力证据：多数不稳健，但未全部消失 |
| 4 | 资本结构有最优解吗 | 权衡理论：存在目标杠杆 | 啄食顺序：负债率由累积融资缺口决定 | Graham-Harvey 调查中 81% 的 CFO 认为存在目标杠杆，但两种理论各解释一部分 |
| 5 | 金融是波动的传播者还是来源 | 主流：金融传播外部冲击 | 明斯基：金融内生地产生波动 | 无定论。金融加速器已被主流接受，是中间的妥协 |
| 6 | 通胀该用规则还是相机抉择 | 泰勒规则：系统性规则提升可信度 | 预期锚定可替代激进加息；规则描述力下降 | 近年偏向后者（2025 年 Jackson Hole 的 Beyond the Taylor Rule） |
| 7 | 货币政策独立性靠什么 | 三元悖论：汇率浮动可换取独立 | 二元悖论：全球金融周期限制独立 | 无定论。中国案例显示资本管制与汇率容忍度是现实变量 |
| 8 | 汇率由什么决定 | 利差（利率平价） | 财政、资本流动、地缘政治、央行信誉等多因素 | 传统框架的解释力明显下降 |
| 9 | 风险该怎么度量 | VaR：直观、可沟通、可设限额 | ES：满足一致性公理，覆盖尾部 | 监管转向 ES（Basel FRTB），实务中两者配合 |
| 10 | 估值/测度能用多少参数 | 更多参数带来更精确 | 1/N 之谜：估计误差吃掉了优化的收益 | 实务共识偏向简洁。等权多因子组合比优化权重更稳健 |

## 八、理论之间的关系类型

分清关系类型，是判断「用哪个」的前提。

### 8.1 层次关系（非对立）

| 上层 | 下层 | 关系 |
|------|------|------|
| SDF 框架 | CAPM、CCAPM、多因子模型 | 它们是同一个式子的不同填法 |
| 期望效用理论 | 前景理论 | 前者是基准，后者是修正 |
| MPT | CAPM | CAPM 是 MPT 加均衡条件 |
| 无套利原理 | 期权定价、APT、MM 定理 | 三者都建立在无套利上 |
| 货币理论 | 泰勒规则、非常规货币政策 | 规则与工具是理论的应用层 |

### 8.2 互补关系

| 组合 | 互补方式 |
|------|---------|
| EMH + 资产定价模型 | 联合假说问题使两者必须配对使用 |
| 理性框架 + 行为框架 | 前者做基准，后者做偏离分析 |
| 明斯基 + 金融加速器 | 前者讲动因，后者讲机制 |
| 三元悖论 + 二元悖论 | 后者指出前者在金融全球化下的漏洞 |
| VaR + ES + 压力测试 | 阈值、尾部均值、极端情景的三层配合 |
| 权衡理论 + 啄食顺序 + 代理理论 + 择时 | 各解释资本结构的一部分，必须并用 |

### 8.3 替代关系

| 被替代 | 替代者 | 原因 |
|--------|-------|------|
| 货币数量论（作为政策框架） | 价格型货币政策 | 货币需求稳定性削弱 |
| VaR（作为资本计量唯一指标） | ES | 一致风险度量要求 |
| Black-Scholes（作为定价模型） | 随机波动率、跳跃扩散、局部波动率 | 常数波动率与对数正态被证伪 |
| 单因子 CAPM（作为横截面模型） | 多因子模型 | 无法解释规模、价值、动量等系统性差异 |

### 8.4 表面冲突但实际共存

| 现象 | 说明 |
|------|------|
| 动量与长期反转 | 短中期动量、长期反转同时存在。行为金融用反应不足加过度反应解释 |
| EMH 与因子研究 | 同一位学者可以既是 EMH 代表又是因子研究开创者。因子研究的立场是「横截面存在可预测差异」，不必然推翻「价格大体反映信息」 |
| 有效市场与主动管理 | 半强式有效不排斥少数人有技能，只是说明整体上扣除费用后难有超额收益 |

## 十、快速选型指引

| 你的问题 | 先用哪个框架 | 再补什么 |
|---------|------------|---------|
| 这类资产该要求多高收益 | SDF → CAPM 或对应因子模型 | 检查该市场是否为因子显著性的适用场景 |
| 这笔钱怎么分配 | MPT 框架（概念）→ 等权或风险平价（实施） | 相关性压力测试 |
| 这个策略的收益来源是什么 | 三分法（风险补偿 / 错误定价 / 数据挖掘） | 样本外与跨市场复现检验 |
| 这个异象是真的吗 | 复制研究方法论 | 多重检验校正、成本后表现 |
| 该发债还是发股 | MM 定理作基准 | 权衡理论 + 啄食顺序 + 代理理论并用 |
| 这个项目该不该投 | NPV | 检查贴现率是否与项目风险匹配 |
| 货币政策往哪走 | 泰勒规则（基准） | 预期锚定框架 + 金融变量 |
| 金融风险积累到哪一步了 | 明斯基的融资结构三分法 | 金融加速器机制 + 资产负债表数据 |
| 组合的风险有多大 | VaR（限额）+ ES（尾部） | 压力测试（极端情景） |
| 这些数据说明什么 | 先做联合假说检查（用的是哪个模型） | 至少两个流派的交叉验证 |
