# 12 金融史脉络对照与索引

## 一、这一份解决什么问题

`10` 与 `11` 是按时间顺序的叙述。这一份做四件事：

1. **理论-历史对照**：每个金融理论回应的具体历史困境是什么
2. **人物与机构索引**：按领域和时期快速定位
3. **时间线速查**：压缩到一张表，用于快速定位
4. **纠错清单**：金融史里被广泛误传的说法，以及实际情况

需要判断「这个理论当年是为了解决什么问题」、或者「这个人／机构在哪个位置」时，先看这一份。

## 二、理论-历史对照表（本模块的核心）

**读法：** 金融理论几乎都是对某个具体历史困境的回应。知道困境是什么，就知道理论的边界在哪里。

| 理论 | 提出年份 | 回应的历史困境 | 对应的制度变迁 |
|------|---------|--------------|--------------|
| 亚里士多德的反利息论 | 约前 340 | 城邦内部债务与社会稳定 | 债务免除、反高利贷立法 |
| 阿奎那的高利贷论 | 13 世纪 | 商业扩张与教会伦理的冲突 | 汇票、干兑换等变通工具 |
| 价格-铸币流动机制 | 休谟 1752 | 重商主义下对贸易顺差的执念 | 金本位自动调节的理论基础 |
| 货币数量论 | 博丹 1568、洛克、休谟 | 16 世纪美洲白银流入与价格革命 | 央行对货币发行的控制 |
| 劳动价值论与比较优势 | 李嘉图 1817 | 拿破仑战争后的谷物法之争 | 自由贸易立法（1846 年废谷物法） |
| 萨伊定律 | 萨伊 1803 | 后革命时代对生产过剩的否认 | 主张不干预；后被凯恩斯推翻 |
| 金本位调节理论 | 19 世纪 | 各国如何维持汇率平价 | 1870 至 1914 年古典金本位 |
| 通货学派与银行学派之争 | 1840 年代 | 银行券发行是否需要百分之百黄金准备 | **1844 年皮尔银行法** |
| 马克思的金融资本批判 | 1867 | 产业资本与金融资本的分离 | 对金融危机内生性的早期论述 |
| 边际效用革命 | 杰文斯、门格尔、瓦尔拉斯 1870s | 古典价值论无法解释价格形成 | 经济学从政治经济学中分化 |
| 洛桑学派一般均衡 | 瓦尔拉斯 1874 | 价格体系如何同时出清所有市场 | 数理经济学的范式 |
| 马歇尔的局部均衡 | 1890 | 供求分析的工程化 | 教科书体系的确立 |
| 费雪的货币数量论与债务通缩 | 1911、1933 | 美元化、通胀与大萧条 | 美联储的货币管理依据 |
| 魏克赛尔的自然利率 | 1898 | 利率与物价的关系 | 后来影响瑞典学派与凯恩斯 |
| 熊彼特的创新理论 | 1911、1942 | 经济发展的动力来源 | 创造性破坏与信用创造 |
| 凯恩斯的有效需求理论 | 1936 | 大萧条中的长期失业 | **布雷顿森林体系的设计、财政政策合法化** |
| 凯恩斯方案的班柯 | 1943 | 国际清算与顺差国责任 | 败给怀特方案；影响后世 SDR 讨论 |
| 特里芬难题 | 1960 | 美元作为储备货币的内在矛盾 | SDR 创设、布雷顿森林崩溃 |
| 哈耶克与奥地利学派的周期论 | 1931 | 信贷扩张导致的虚假繁荣 | 与凯恩斯之争延续至今 |
| 货币主义 | 弗里德曼 1956、1963 | 大萧条的货币解释与滞胀 | 1979 年沃尔克转向货币目标 |
| 明斯基的金融不稳定假说 | 1963、1986 | 金融体系为何周期性脆弱 | 2008 年后成为主流参照 |
| 有效市场假说 | 法马 1965、1970 | 主动管理能否创造价值 | 指数化投资的兴起 |
| 期权定价理论 | Black-Scholes-Merton 1973 | 衍生品如何定价与对冲 | **CBOE 成立与衍生品市场爆发** |
| 套利定价理论与多因子模型 | 罗斯 1976、Fama-French 1993 | 单因子模型解释力不足 | 因子投资与 smart beta |
| 前景理论与行为金融 | Kahneman-Tversky 1979 | 理性人假设与实证偏离 | 行为投资产品、监管的行为转向 |
| 真实经济周期与 DSGE | 1980s | 宏观模型的微观基础问题 | 央行预测与政策评估工具 |
| 影子银行与批发融资挤兑 | 2008 后 | 危机为何发生在非银行体系 | 多德-弗兰克、巴塞尔 III |
| 金融周期理论 | BIS 一系 | 金融变量周期长于商业周期 | 逆周期资本缓冲 |
| 现代货币理论 | 1990s 至今 | 主权货币下的财政空间 | 争议极大，政策含义未定 |

**从这张表能看出两件事：**

1. **制度先于理论。** 汇票、央行、金本位、衍生品市场都在对应理论出现之前就已经存在。理论往往是事后解释与规范化。
2. **危机催生理论。** 大萧条催生凯恩斯与货币主义，1970 年代滞胀催生规则化货币政策，2008 年催生金融摩擦宏观模型与明斯基复兴。

## 六、纠错清单

金融史是被误传最多的领域之一。下面这些说法流传很广，但都不准确。

| 常见说法 | 实际情况 |
|---------|---------|
| 「1929 年股灾导致了大萧条」 | 股灾是触发因素之一。深度与长度主要来自**货币供给收缩、金本位约束、以及银行体系的连锁倒闭**。弗里德曼与施瓦茨、艾肯格林的研究是主要依据。把它简化成「崩盘导致萧条」会掩盖真正的政策失误 |
| 「郁金香狂热是一次全国性经济灾难」 | 现代研究（Goldgar 等）指出，参与者主要是少数商人，规模有限，**对荷兰整体经济的影响远小于流传的说法**。它作为「泡沫」的象征意义大于实际经济冲击 |
| 「金本位天然稳定、信用可靠」 | 金本位稳定的是汇率与长期物价，代价是**调整成本全部落在就业与工资上**。它在有普选权的社会里不可持续，1931 年英国的退出证明了这一点 |
| 「布雷顿森林体系是固定汇率制」 | 它是**可调整的钉住汇率制**，允许上下各 1% 波动，并允许在「根本性失衡」时调整平价。与真正的固定汇率不同 |
| 「银行的英文 bank 来自意大利语的『长凳』」 | bank 与 banca 同源，确实与兑换商的桌子有关，但**「破产」（bankrupt）来自 banca rotta 的说法缺乏可靠文献依据**。这类词源故事多属后人附会 |
| 「罗斯柴尔德家族靠滑铁卢消息一战暴富」 | 广为流传，但**缺乏可靠史料支持**。罗斯柴尔德家族的实力来自跨国债券承销网络与信息优势，不是某一次投机 |
| 「2008 年危机就是次贷危机」 | 次贷是触发点。**危机的主体是批发融资市场的挤兑与影子银行体系的脆弱性**。把它简化为「穷人借了还不起的房贷」会完全错失传导机制 |
| 「1933 年分业经营导致了 2008 年危机，废止它就带来了危机」 | 相关性存在，**因果关系无法确立**。1999 年废止后危机发生在投资银行与影子银行，不是商业银行的证券业务 |
| 「明斯基的理论能预测危机时点」 | 明斯基提供的是**危机机制**，不是时点判断。他本人在世时并未预言 2008 年。把它当作择时工具会误用 |
| 「数字货币是全新的东西」 | 私人发行货币（银行券）、非金属货币（纸币）、无中心发行（部分地方性货币）都有先例。**比特币真正的新意在于：不由主权发行、没有中心发行者、发行规则不可变更** |
| 「去美元化正在快速发生」 | 趋势讨论多，实际进展慢。**储备货币更替以数十年计**，且通常伴随发行国的重大失败。把趋势判断当时点判断是常见错误 |
| 「西班牙因美洲白银而富有」 | 白银大量流入，但**西班牙王室在 1557 至 1650 年代反复破产**。财富被战争、抵押与通胀消耗。这是资源诅咒在金融层面的经典案例 |

## 七、本模块的已知局限

| 局限 | 说明 |
|------|------|
| 数据多为区间估计 | 古代利率、中世纪物价、16 世纪通胀幅度等，学界存在不同估计，本模块给出的是常用区间 |
| 年份存在学术分歧 | 如《汉谟拉比法典》的绝对年代、铸币发明的具体时间、复式记账的最早使用地点，均有争议 |
| 非西方金融史覆盖偏薄 | 伊斯兰金融技术、中国货币史、印度与东南亚的信用制度，本模块只做了要点性覆盖，未展开 |
| 机构与人物索引非穷尽 | 只收录了具有结构性影响的对象，遗漏是必然的 |
| 理论归因有简化 | 把理论对应到单一历史困境，方便记忆但损失了复杂性。多数理论的产生是多个因素叠加 |
| 当代部分缺乏时间检验 | 数字货币、稳定币、去美元化的历史地位，需要更长的时间才能判断 |

**引用本模块时的纪律：** 涉及具体数字与年份，标注「学界存在不同估计」或核实原始文献。涉及当代事件的性质判断，说明这是当前的主流解读而非定论。
