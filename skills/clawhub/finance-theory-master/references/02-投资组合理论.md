# 02 投资组合理论

## 一、这一板块回答什么问题

给定一笔钱和一定的风险承受能力，怎么分配到不同资产上？「分散」在数学上到底是什么，它的边界在哪？

资产定价回答「价格应该是多少」，投资组合理论回答「我该怎么持有」。两者的连接点是均值方差框架：资产定价里的 CAPM 就是这个框架加上均衡条件后的产物。

---

## 二、现代投资组合理论（MPT）

### 2.1 核心命题

Markowitz（1952）的贡献是把风险第一次写成可计算的量（方差），并把注意力从单个资产转移到整个组合上。

```
min  w'Σw
s.t. w'μ = μ_target,  w'1 = 1
```

对每个目标收益率求解，得到一组最优权重，这些点连成**有效前沿**。理性的投资者只在有效前沿上选择。

### 2.2 分散化的数学

关键洞察只有一句：**只要资产间不完全相关，组合的风险就低于各资产风险的加权平均。**

以两个各 20% 波动率的资产为例，等权持有：

| 相关系数 | 组合波动率 | 分散化收益 |
|---------|-----------|-----------|
| +1.0 | 20.0% | 无 |
| +0.5 | 17.3% | 中等 |
| 0.0 | 14.1% | 显著 |
| -1.0 | 0.0% | 完全 |

Markowitz 称分散化是「金融中唯一的免费午餐」。**这句话有个前提没被强调：免费的前提是相关性稳定。**

### 2.3 分离定理

Tobin（1958）指出，引入无风险资产后，最优风险资产组合与投资者的风险偏好**无关**。所有投资者持有同一个风险资产组合，区别只在无风险资产与它的比例上。

这条推论是后来指数化投资的理论基础，也是 CAPM 的直接前置。

### 2.4 输入参数的规模问题

对 N 个资产，均值方差优化需要：

- N 个期望收益估计
- N 个方差估计
- N(N-1)/2 个协方差估计

N=100 时需要 100 + 100 + 4950 = **5150 个参数**。参数数量的增长速度远快于可用数据量的增长速度。

## 三、估计误差问题（本板块的核心难题）

### 3.1 问题性质

均值方差优化对**期望收益**的估计误差极度敏感。原因：

1. Merton（1980）证明，要以合理精度估计期望收益，需要极长的数据历史，远长于实际可得的样本
2. 优化器会主动利用估计误差：超配期望收益被高估的资产，低配被低估的
3. 期望收益的小误差会导致权重的大幅变化，产生极端、反直觉的配置

**Michaud（1989）的著名说法：均值方差优化在实务中是一个「误差最大化器」。**

### 3.2 补偿方法

| 方法 | 原理 | 局限 |
|------|------|------|
| 权重约束 | 限制单个资产权重的上下界 | 掩盖弱输入，不修正它 |
| 收缩估计 | 把样本协方差矩阵向结构化目标压缩（Ledoit-Wolf 2004） | 需要选定目标和收缩强度 |
| 重采样 | 用蒙特卡洛从不确定输入生成多条有效前沿，取平均（Michaud 1998） | 依赖模拟模型设定 |
| Black-Litterman | 以市场均衡权重为起点，叠加主观观点（1992） | 观点与参数仍需自行选择 |
| 最小方差组合 | 完全不用期望收益 | 仍依赖协方差 |
| 风险预算 | 控制各资产对组合风险的贡献 | 不自动优化收益 |
| 换手惩罚 | 显式加入交易成本 | 需要真实的成本模型 |

### 3.3 1/N 之谜

DeMiguel、Garlappi、Uppal（2009）在 7 个数据集上，把 14 种优化策略与简单等权（1/N）组合做样本外对比，**没有任何一种优化策略能一致地跑赢等权**。

**解释是偏差与方差的权衡：**

| 方法 | 偏差 | 方差 | 净效果 |
|------|------|------|-------|
| 优化组合 | 低（用了更多信息） | 高（对样本期敏感） | 估计误差大时表现差 |
| 1/N | 高（忽略所有信息） | 低（无需估计） | 估计误差大时表现好 |

**正确解读：** 这不是说 1/N 普遍最优。它说明的是：**「怎么分配」的重要性低于「分散到多广」。** 持有跨行业、跨地区的 20 只股票等权组合，即使权重定得粗糙，也已经充分分散。

**实践顺序建议：** 先确保分散广度（跨资产类别、行业、地域），再考虑用优化方法微调权重。顺序反了，等于在一个不确定的基础上做精算。

## 四、风险平价

### 4.1 核心思路

不按资金比例分配，而按**各资产对组合风险的贡献**分配，使每类资产贡献相等的风险。

由 Qian（2005）形式化，由桥水全天候基金推广。Asness、Frazzini、Pedersen（2012）记录杠杆化风险平价组合 1926 至 2010 年的夏普比率约 0.5 至 0.6，同期纯股票约 0.4。

### 4.2 优势

- **不需要预测期望收益。** 直接绕开了 MPT 最脆弱的输入
- 天然给出比市值权重更分散的配置（股票的波动率远高于债券，风险平价下债券的权重会被放大）

### 4.3 局限

| 局限 | 说明 |
|------|------|
| 依赖债券风险溢价 | 债券长期正收益是这个策略的基础。若债券进入长期熊市，策略承压 |
| 依赖低利率杠杆 | 要获得接近股票的收益，需对低波动资产加杠杆。融资成本上升则策略失效 |
| 相关性假设 | 与 MPT 同样依赖协方差矩阵的稳定性 |
| 2022 年的检验 | 股债相关性由负转正，平衡型与风险平价组合同时遭遇数十年来最严重回撤 |

**2022 年的教训很直接：** 风险平价的核心假设是「债券能对冲股票风险」。这个假设在 2000 至 2021 年间成立，2022 年不成立。任何建立在这条相关性上的策略，都建立在一个可能随时反转的前提上。

**实证地位：有争议（历史表现稳健，但高度依赖特定利率与相关性环境）。**

## 五、凯利准则

### 5.1 核心命题

Kelly（1956）从信息论出发，给出在对数效用（最大化长期复合增长率）下的最优下注比例。

以赔率为 b、胜率为 p 的简单情形：

```
f* = (b·p - q) / b,  其中 q = 1 - p
```

### 5.2 为什么重要

- 最大化长期复合增长率，而不是单期期望收益
- 数学上，算术收益与几何收益的关系是「几何 ≈ 算术 − 方差/2」。降低方差能提高复利效率

### 5.3 实践中的问题

| 问题 | 说明 |
|------|------|
| 参数敏感 | 对胜率估计的误差极度敏感，高估胜率会导致过度下注 |
| 波动巨大 | 满凯利下注的净值波动在实践中难以忍受 |
| 回撤深 | 即使长期最优，中途的深度回撤也可能导致中途被迫离场 |

**实践共识是使用「分数凯利」**，通常取 1/4 至 1/2。代价是放弃了部分长期增长率，换取了可承受的回撤路径。

## 六、相关性失效

### 6.1 现象

**相关性不是常数。它在市场下跌时上升。**

Longin、Solnik（2001）用极值理论证明，国际股票市场在大幅负收益期间的相关性显著高于正常时期。这意味着平静市场里测出的分散化收益是**被高估的**。

### 6.2 实证记录

| 资产对 | 正常市场（2012–2019） | 2008 金融危机 | 2020 疫情 | 2022 利率冲击 |
|-------|---------------------|-------------|----------|-------------|
| 美股 — 发达市场股票 | 0.65 | 0.92 | 0.88 | 0.82 |
| 美股 — 新兴市场股票 | 0.52 | 0.85 | 0.82 | 0.70 |
| 美股 — 美国国债 | -0.15 | -0.40 | -0.35 | **+0.55** |
| 美股 — 黄金 | 0.00 | -0.10 | -0.20 | -0.15 |
| 美股 — REITs | 0.70 | 0.88 | 0.80 | 0.75 |

（数据为文献中引用的估计区间，使用时需核对原始来源与时点）

### 6.3 三个关键观察

1. **危机期间股票市场间相关性飙升到 0.9 附近**，国际股票配置的分散化收益几乎消失
2. **2022 年股债相关性转正**，打破了 2000 至 2021 年间的负相关结构，是 60/40 与风险平价模型数十年来最严重的压力测试
3. **黄金是四个危机区间里唯一保持接近零或负相关的资产**，更接近「对冲工具」而非「安全港」（Baur-Lucey 2010）

### 6.4 成因

| 机制 | 说明 |
|------|------|
| 共同因子暴露 | 严重衰退中几乎所有公司同时面临收入下降、违约上升、融资收紧 |
| 传染 | 保证金追缴、强制平仓、羊群行为传导冲击 |
| 流动性撤出 | 做市商扩大价差、收缩承接意愿，导致所有资产同时下跌 |

### 6.5 对组合构建的含义

1. **用危机期相关性做压力测试**，不要用长期均值。用长期均值会得到一个「正常时分散良好、最需要保护时保护不足」的组合
2. **按风险因子分散，而不是按资产类别分散。** 两个看似无关的资产可能共享同一个底层风险因子（增长、利率、流动性），在压力时同时失效
3. **明确以低相关为目标的策略**（管理期货、尾部风险对冲、做多波动率）比传统资产类别分散更可靠

## 七、本板块的元问题

### 7.1 单期模型的根本错配

均值方差框架是单期的。真实投资者有多期目标、有负债、有流动性需求、有阶梯式的风险承受能力。这些在框架里都没有位置。

**后果：** 优化出来的「最优组合」可能因为与负债期限不匹配、或在最差时点被迫变现，而在实践中变成最差组合。

### 7.2 均值方差忽略了尾部与偏度

框架只用了前两阶矩。若收益分布负偏且厚尾（股权收益正是如此），两个方差相同的组合可能有完全不同的尾部风险。

**后果：** 「方差最小」不等于「最安全」。这是为什么风险管理领域后来发展出 ES、CVaR 等只关注尾部的度量（见 `07-风险管理.md`）。

### 7.3 一个诚实的现状总结

投资组合理论是金融学中数学化程度最高、也最容易被误用的板块。它的形式化程度让人以为精确，而它的核心输入（期望收益）恰恰是最难估准的量。

**使用本板块的正确姿势：** 把它当成「思考分散化结构的框架」，而不是「求出最优权重的计算器」。求出的权重精度远低于数字显示的小数位所暗示的水平。

## 八、与其他板块的接口

| 接口 | 说明 |
|------|------|
| 与资产定价 | CAPM 是 MPT 的均衡版本；MPT 给前沿，CAPM 指定切点为市场组合 |
| 与有效市场假说 | 如果市场有效，就不存在超越市场组合的风险收益改善空间，只需持有市场组合 |
| 与行为金融 | 分散不足（本土偏差、熟悉度偏差、控制幻觉）是行为金融反复记录的偏差；BPT 提出投资者实际构建的是分层金字塔而非有效前沿上的点 |
| 与风险管理 | 组合层面的风险度量（VaR、ES）建立在本板块的协方差结构上，因此继承其相关性失效问题 |
| 与公司金融 | 项目资本预算中的 WACC 是组合思想的微观应用；企业多元化是否创造价值与组合分散化是同一逻辑 |

## 九、使用本板块时的三条提醒

1. **先看参数规模。** 资产数量一多，优化所需的参数数量就失控。这时优先考虑降维（因子模型、最小方差、等权），而不是硬上完整优化。
2. **相关性必须做压力测试。** 用正常期相关性得出的分散效果，在危机中大概率不成立。这一条几乎每次危机都会被重新验证一遍。
3. **分母决定仓位。** 在组合层面，「能承受多大回撤」决定风险预算，而不是先决定仓位再算回撤。
