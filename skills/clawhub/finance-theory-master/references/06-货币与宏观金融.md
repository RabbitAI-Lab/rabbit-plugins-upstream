# 06 货币与宏观金融

## 一、这一板块回答什么问题

货币、利率、汇率、金融体系与实体经济之间是怎么互相作用的？货币政策能做什么、做不到什么？金融危机为什么会周期性发生？

这是七个板块里**共识最少的一块**。资产定价有 SDF 作为统一语言，公司金融有 MM 定理作为基准，而宏观金融到目前为止没有形成被广泛接受的统一模型。使用这一块的内容时，必须比使用其他板块更谨慎。

---

## 二、这一板块的根本状态：经验多于共识

中国社科院金融所在评估金融周期研究时给出了一个很直白的判断：**目前对金融周期运行与作用机制，还没有建立起有说服力的模型。** 经验实证文献多，理论模型少。

BIS（国际清算银行）长期坚持的立场与此一致：金融因素不只是经济波动的传播渠道，本身就是波动的来源之一，但现有主流模型难以容纳这一点。

**实践含义有两层：**

1. 谈论宏观金融问题时，不要给出比资产定价问题更确定的结论
2. 这一板块的理论，多数价值在于**机制解释**而非**定量预测**

## 三、货币理论

### 3.1 货币数量论

Fisher（1911）的交易方程式：

```
M · V = P · T
```

剑桥学派改写为货币需求形式，Friedman（1956）发展为现代货币主义：货币需求是稳定的函数，因此货币供给的变化会主要反映在价格上。

| 论点 | 状态 |
|------|------|
| 长期货币与价格的关系 | 稳健。长期看货币增速与通胀高度相关 |
| 短期货币与产出的关系 | 有争议。短期货币冲击会先影响产出而非价格 |
| 货币需求的稳定性 | **已显著削弱。** 20 世纪 80 年代后金融创新与金融脱媒使货币数量很难即时精确管理，货币数量与政策目标的关联明显减弱 |

**这个「已削弱」的后果很实际：** 主要央行早已从数量型货币政策转向价格型（利率）调控。中国人民银行也经历了这个过程：1996 年确定 M1 为中介目标，1998 年取消信贷规模管理，2018 年后不再公布 M2 与社融的数量目标，2019 年 LPR 改革后逐步形成价格型调控体系。

### 3.2 货币需求理论

| 理论 | 提出者 | 核心 |
|------|-------|------|
| 流动性偏好 | 凯恩斯 | 货币需求来自交易、预防、投机三种动机 |
| 资产选择理论 | 托宾 | 把货币需求放进风险与收益的权衡框架 |
| 平方根定律 | 鲍莫尔、托宾 | 交易性货币需求与收入、利率的关系可形式化 |

### 3.3 现代货币理论（MMT）

核心主张：主权货币发行国的政府，其财政约束不等于家庭或企业的预算约束，因为政府可以发行货币。因此财政政策的空间比传统认知更大。

**这是争议极大的理论。** 支持者认为它揭示了主权货币的制度现实；批评者认为它低估了通胀约束、汇率约束与制度约束，且其政策主张在通胀环境下风险极高。**引用时必须把这个争议状态写出来，不能当作已确立的结论使用。**

## 四、IS-LM 及其局限

Hicks（1937）把凯恩斯的论述整理为 IS-LM 框架：IS 曲线表示产品市场均衡，LM 曲线表示货币市场均衡，交点决定利率与产出。

**局限（这是理解宏观模型演进的入口）：**

| 局限 | 说明 |
|------|------|
| 静态框架 | 比较静态分析，不处理动态调整路径 |
| 忽略预期 | 预期不进模型，而预期在现代宏观中处于核心位置 |
| 微观基础缺失 | 曲线来自加总关系，不是从个体最优行为推导出来的 |
| 价格与工资刚性处理粗糙 | 对短期与长期的区别处理不够细致 |

**后续演进：** 新凯恩斯的 DSGE 模型补上了微观基础与预期，但也带来了新的问题：模型对金融摩擦的处理长期薄弱，2008 年危机暴露了这个缺口。伯南克等人的金融加速器理论正是对这一缺口的回应。

## 五、货币政策规则

### 5.1 泰勒规则

Taylor（1993）提出的简单规则：

```
i = r* + π + 0.5(π − π*) + 0.5(y − y*)
```

其中 r* 是长期中性利率，π 是当前通胀，π* 是目标通胀，y − y* 是产出缺口。

**泰勒原理：** 通胀上升 1 个百分点时，名义利率必须上升超过 1 个百分点，否则实际利率下降，会进一步刺激需求并推高通胀，形成自我强化的螺旋。

**泰勒规则的双重身份：**

- 描述性：它最初是对美联储实际行为的近似描述
- 规范性：后来被广泛用作央行「应该怎么做」的基准

### 5.2 局限

| 局限 | 说明 |
|------|------|
| 依赖不可观测量 | 中性利率 r* 与潜在产出 y* 都不可观测，只能估计。美联储对中性利率的中位估计本身就有一个较宽的区间 |
| 只含两个变量 | 无法容纳金融稳定、资产价格、信用条件等变量 |
| 描述力下降 | 2008 年后与 2022 年后的实际政策路径与规则推算值的偏离显著扩大 |
| 忽略预期 | 用当期通胀而非预期通胀，可能给出误导性的建议 |

### 5.3 规则之外：预期锚定的替代作用

Nakamura、Riblier、Steinsson 在 2025 年 Jackson Hole 会议上提出的「Beyond the Taylor Rule」给出了一个有影响的解释：**如果公众相信通胀最终会回到目标，央行就不需要用极高的实际利率去压制需求，可以「看穿」暂时性的价格冲击。锚定的预期替代了部分激进加息的功能。**

他们的实证发现是：疫情前通胀经历更稳定的国家，在 2021 至 2022 年通胀上行期间加息的幅度更小。

**这一结论的重要含义：** 央行信誉本身就是一种政策工具。信誉弱的央行即使激进加息也换不来较低的通胀，反而可能陷入「通胀更高、政策更紧」的循环；而长期积累信誉的央行有更大的操作空间。

**但要看到这一结论的另一面：** 如果预期开始漂移，央行必须果断行动。预期锚定是「可用的空间」，不是「必然成立的前提」。把预期锚定当作理所当然，然后长期宽松，是这一框架下最大的风险。

## 六、非常规货币政策

| 工具 | 机制 | 已识别的副作用 |
|------|------|--------------|
| 量化宽松（QE） | 央行购买长期资产，压低长期利率与期限溢价 | 资产价格效应加剧分配不均；退出困难；对实体经济传导效率存争议 |
| 前瞻指引 | 通过承诺未来政策路径影响当前预期 | 承诺的可信度依赖央行信誉；条件变化后调整会损害信誉 |
| 负利率 | 突破零下限 | 对银行盈利与货币市场基金的冲击；现金替代风险 |
| 收益率曲线控制 | 直接盯住特定期限的利率 | 退出机制复杂，资产负债表规模风险 |

**2008 年的核心教训之一：** 央行资产负债表成为常规政策工具后，「利率政策」与「资产负债表政策」的边界变得模糊，这对泰勒规则这类只含单一政策利率的框架构成了根本性挑战。

## 七、金融危机理论

### 7.1 明斯基金融不稳定假说

Minsky 于 1963 年提出雏形，1986 年与 1991 年形成完整框架。

**两条定理：**

1. 经济在某些融资结构下是稳定的，在另一些融资结构下是不稳定的
2. 经过一段长时间的繁荣，经济会从有助于稳定的金融关系转向有助于不稳定的金融关系

**融资结构的三个层次：**

| 类型 | 现金流状况 | 风险 |
|------|-----------|------|
| 对冲型融资 | 经营现金流足以覆盖本息 | 最安全 |
| 投机型融资 | 经营现金流只够付息，本金需滚动再融资 | 依赖再融资环境 |
| 庞氏融资 | 经营现金流不足付息，靠借新还旧 | 依赖资产价格持续上涨 |

**核心命题「稳定孕育不稳定」：** 长期稳定会降低风险感知、放松监管、鼓励加杠杆，使融资结构从对冲型向投机型、庞氏型迁移。当关键资产价格转向下跌时，脆弱性会发生跃迁，从可控损失变成系统性断裂，即「明斯基时刻」。

**明斯基定理的一个推论：** 一个经济体无法同时实现高杠杆、金融稳定与持续增长。

**局限（必须写出来）：**

| 局限 | 说明 |
|------|------|
| 微观不必然推广到宏观 | 后凯恩斯主义内部的「合成谬误」质疑：投资企业的支出就是资本品企业的收入，企业部门的总债务与总收入是平衡的，因此微观层面的杠杆上升不必然导致宏观层面的不稳定 |
| 依赖较强的假设 | 假定债务主要为生产投资融资、利润率为固定值，这两条与经验现实不符 |
| 难以形式化 | 完整框架难以写成可估计的模型，导致实证研究多为诠释性而非检验性 |
| 事前预测力弱 | 理论在事后解释危机方面很强，但无法给出时点判断。这正是本 skill 明确拒绝回答「明斯基时刻什么时候来」的原因 |
| 对金融与实体关系的处理 | 与马克思的实体资本和虚拟资本区分不同，明斯基的双价投资体系中资产既可以是生产资料也可以是金融债权，模糊了金融与实体经济的联系 |

**明斯基与主流的根本分歧：** 主流经济学认为金融体系**传播**经济波动（波动来自外部冲击）；明斯基认为金融体系不仅传播波动，**而且产生**波动。这个分歧决定了政策主张的差异：主流强调货币政策的独立操作，明斯基提出「大政府」（财政干预）与「大银行」（央行最后贷款人）。

**2008 年后明斯基受到广泛关注。** 《经济学人》2016 年专文评述，2023 年欧美局部银行破产事件再次引发对金融不稳定性的讨论。但也要注意另一面的批评：Palley（2009）认为把危机完全解释为「明斯基危机」是误导性的，明斯基机制起了作用，但那是一出更大戏的一部分（涉及新自由主义增长模式下工资停滞与债务驱动的需求替代）。

### 7.2 金融加速器

Bernanke、Gertler、Gilchrist（1999）提出 BGG 模型，把金融摩擦加入动态一般均衡框架。

**传导链条：**

```
信息不对称 → 金融摩擦 → 金融加速器 → 实际产出波动
```

**同时作用于借贷双方：**

| 方向 | 衰退期的表现 |
|------|------------|
| 贷方（银行） | 贷款损失增加，放贷更谨慎 |
| 借方（企业、家庭） | 收入与财富下降，抵押物价值下跌，信誉度降低 → 可获得的信贷减少 → 采购与投资计划受阻 → 衰退加剧 |

上行期机制方向相反：抵押物升值、信贷扩张、投资增加、增长加速。

**金融加速器的意义：** 它解释了为什么金融因素会**放大**冲击而非仅仅传导它。这是主流框架内部对金融作用的重要修正，也是金融周期理论的核心。它比明斯基的框架更容易形式化，因此更容易被纳入主流模型与政策讨论。

**与明斯基的分工：** 金融加速器讲「金融如何放大冲击」，明斯基讲「金融如何内生地产生脆弱性」。前者是机制，后者是动因。两者互补，不冲突。

### 7.3 债务通缩

Fisher（1933）提出的机制：债务积压下的被迫抛售压低资产价格，资产价格下跌提高实际债务负担，进一步迫使抛售。

**这个机制与明斯基的框架同源。** 明斯基在一定程度上结合了凯恩斯与费雪的思想：对金融不稳定性的见解接近费雪的债务通缩理论，政策建议则与凯恩斯类似，主张逆周期干预。

## 八、国际金融

### 8.1 利率平价

| 类型 | 内容 | 实证状态 |
|------|------|---------|
| 抵补利率平价（CIP） | 远期汇率与即期汇率之差等于利差 | 长期近似成立，但 2008 年后出现持续偏离（基差扩大），成为持续的异常现象 |
| 非抵补利率平价（UIP） | 预期汇率变动等于利差 | **已显著削弱。** Fama（1984）记录的远期溢价之谜与长期存在的套息交易收益，都表明高利率货币倾向于升值而非贬值 |

**UIP 失效的实践含义：** 套息交易（借低息货币、买高息货币）长期存在正向收益，这不是免费的午餐，它对应的是承担尾部风险（套息交易在危机中会出现剧烈崩溃）。

### 8.2 三元悖论与二元悖论

**三元悖论（Mundell-Fleming）：** 货币政策独立、汇率稳定、资本自由流动，三者只能同时实现两个。

**二元悖论（Rey 2015）：** 在金融全球化程度足够高时，即使允许汇率自由浮动，也无法保证货币政策独立。全球金融周期会传导至所有开放经济体。这意味着三元悖论中「汇率浮动换取独立」的那条出路被削弱了。

**中国的适用性（据《经济理论与经济管理》2025 年的研究）：**

| 观察 | 内容 |
|------|------|
| 现实表现 | 疫情以来中国货币政策方向与美联储显著不同，同时人民币贬幅小于欧元，说明具备一定程度的独立性 |
| 两个条件 | 提高对汇率贬值的容忍度 + 适度的资本账户管制 |
| 数量型渠道 | 2005 年汇改前后、2009 年危机初期、2012 年、2018 至 2019 年、2022 至 2024 年间，数量型货币政策独立性较弱，与外汇储备变化、资本流动冲击相关 |
| 价格型渠道 | 大部分时期保持独立；下降主要出现在危机期与汇改前的窗口 |
| 汇改的作用 | 2005 年「721」、2010 年「619」、2015 年「811」三次汇改通过释放汇率波动性，提升了货币政策独立性水平 |

**一个方法论提醒：** 该研究特别指出，仅从利率层面度量中国的货币政策独立性是不完整的。中国正在经历从数量型向价格型的转型，必须同时从数量与价格两个维度度量，否则会得出偏差的结论。这个提醒对其他转型经济体同样适用。

### 8.3 汇率决定理论

| 理论 | 核心 | 局限 |
|------|------|------|
| 购买力平价 | 长期汇率由相对物价水平决定 | 短期偏离巨大且持续，交易品与非交易品的区分使检验困难 |
| 货币模型 | 汇率由两国货币供求决定 | 假设价格灵活，短期不成立 |
| 超调模型（Dornbusch 1976） | 价格黏性下，汇率短期会过度调整后再回归 | 对预期形成机制的假设较强 |
| 资产组合模型 | 汇率由两国资产的供求均衡决定 | 参数多，实证表现不稳 |

**关于汇率问题的一个诚实结论：** 汇率是宏观金融中预测表现最差的领域之一。把利率作为汇率主要驱动力的传统框架，在近年受到的挑战尤其明显。讨论汇率时应避免给出高置信度的方向判断。

## 九、宏观金融整合的现状

| 方向 | 内容 | 状态 |
|------|------|------|
| 金融周期 | 金融变量的周期远长于商业周期，且与商业周期不完全同步 | 经验证据较多，机制模型未达成共识 |
| 债务与去杠杆 | 债务积压对增长的影响、去杠杆的路径 | 讨论活跃，结论分歧大 |
| 通胀预期与货币政策信誉 | 预期锚定作为政策的替代性工具 | 近年有重要进展（见 5.3） |
| 宏观审慎政策 | 用逆周期资本缓冲、贷款价值比等工具管理系统性风险 | 已成政策实践，理论框架仍在建设中 |
| 货币政策与金融稳定的边界 | 是否应当「逆风而行」（主动刺破资产泡沫） | 长期争论，无共识 |

**一句话总结这一板块的状态：** 有大量可靠的机制性认识（金融加速器、债务通缩、明斯基的融资结构迁移），但缺少能同时容纳这些机制并有良好预测性的统一模型。

## 十、与其他板块的接口

| 接口 | 说明 |
|------|------|
| 与资产定价 | 无风险利率与期限结构是资产定价的输入；股权溢价之谜是宏观金融与资产定价的交界问题 |
| 与风险管理 | 金融危机的机制性理解直接影响压力测试情景的设计；明斯基的融资结构三分法可用于识别系统性风险积累 |
| 与有效市场假说 | 若市场有效，资产价格应已反映货币政策预期，问题变成「预期误差」而非「政策效果」 |
| 与公司金融 | 货币政策通过信贷渠道影响企业融资条件；金融加速器的传导依赖企业资产负债表状况 |
| 与投资组合理论 | 宏观情景是资产配置的顶层输入；但自上而下的宏观择时实证表现普遍不佳 |

## 十一、使用本板块时的三条提醒

1. **不要给宏观问题时点判断。** 这一板块的理论（尤其明斯基框架）在事前预测上表现弱。这不是能力限制，而是理论的已知性质。
2. **区分机制与预测。** 金融加速器、债务通缩、融资结构迁移这些都是可靠的**机制**描述。把它们转换成定量预测，是超出了理论能力范围的一步。
3. **引用 MMT 与明斯基必须带争议标注。** 两者的学术地位与政策含义都存在实质分歧，不能当作已确立的结论使用。
