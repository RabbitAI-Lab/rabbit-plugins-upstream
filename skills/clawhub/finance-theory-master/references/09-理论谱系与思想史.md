## 二、思想史时间轴

| 时期 | 事件 | 意义 |
|------|------|------|
| 1900 | Bachelier 的博士论文用布朗运动刻画股价 | 最早把随机过程引入金融，长期被忽视 |
| 1933 | Fisher 提出债务通缩理论 | 解释了大萧条的核心机制 |
| 1934 | Graham、Dodd《证券分析》 | 基本面分析的奠基，早于任何学术定价模型 |
| 1936 | 凯恩斯《通论》：动物精神、选美竞赛 | 最早的对投资者心理的系统论述 |
| 1937 | Hicks 整理出 IS-LM | 凯恩斯论述的形式化 |
| 1952 | **Markowitz 提出组合选择** | 第一次把风险写成可计算的量 |
| 1958 | **Modigliani、Miller 提出 MM 定理** | 开创公司金融 |
| 1964–66 | **Sharpe、Lintner、Mossin 建立 CAPM** | 把组合理论均衡化 |
| 1965 | Fama 提出 EMH 初步表述 | —
| 1970 | **Fama 的 EMH 综述** | 三种形式，成为现代金融的基石 |
| 1973 | **Black-Scholes 与 Merton 的期权定价** | 无套利定价的巅峰；理论领先于市场 |
| 1974 | Merton 的结构化信用模型 | 把违约与资本结构连接 |
| 1976 | **Ross 提出 APT**；Jensen、Meckling 的代理理论 | 多因子框架的合法性；公司金融转入治理视角 |
| 1977 | Ross 的信号理论；Roll 对 CAPM 的批判 | 融资的信息含义；CAPM 的方法论危机 |
| 1978–79 | **Lucas、Breeden 建立 CCAPM**；**Kahneman、Tversky 提出前景理论** | 两条新路线同时起步：更根本的理性框架，和第一个严肃的非理性框架 |
| 1980s | 异象大量涌现：规模、价值、反转、一月效应 | 开始动摇 CAPM 与 EMH |
| 1985 | **Mehra、Prescott 提出股权溢价之谜** | 标准模型的定量失败被正式确认 |
| 1986 | Bollerslev 提出 GARCH | 波动率建模的基础 |
| 1987 | 美股崩盘 | 波动率微笑由「微笑」变为「偏斜」，期权定价假设被市场明确否定 |
| 1990 | DSSW 噪音交易者模型 | 第一次把非理性者建进均衡模型 |
| 1992–93 | **Fama-French 三因子**；Jegadeesh-Titman 动量；Taylor 规则；Heston 随机波动率 | 多因子范式成型同时，政策与衍生品两条线各自突破 |
| 1993–94 | **VaR 被提出并推广** | 风险度量走向标准化，局限也在此埋下 |
| 1997 | **Shleifer、Vishny 提出有限套利**；Carhart 四因子 | 行为金融从描述偏差走向解释价格 |
| 1998 | BSV、DHS 模型 | 行为资产定价的建模尝试 |
| 1999 | Hong-Stein 统一理论模型；BGG 金融加速器 | 行为与主流两条线各自推进 |
| 2001 | Cochrane 的《Asset Pricing》系统化 SDF 框架 | 资产定价获得统一语言 |
| 2008 | **全球金融危机** | 同时打击 VaR、DSGE 的金融摩擦处理、EMH 的强式主张 |
| 2010s | 行为金融进入主流（Thaler 2017 年获诺奖，Shiller 2013 年获奖） | 从异端变成教科书内容 |
| 2015–16 | **Harvey-Liu-Zhu 的因子动物园批判**；**McLean-Pontiff 的发表效应**；Fama-French 五因子 | 多因子范式开始自我修正 |
| 2018 | FF 六因子；Linnainmaa-Roberts 的历史检验；Bessembinder 的个股表现研究 | 复制问题被系统化 |
| 2020 | **Hou-Xue-Zhang 复制 452 个异象** | 复制危机成为领域共识 |
| 2022 | 股债相关性转正 | 打破 60/40 与风险平价的二十年基础 |
| 2023 | Jensen-Kelly-Pedersen 的贝叶斯反驳 | 争论进入「方向可复现、幅度更小」的中间地带 |
| 2024–25 | Swade 等估计约 15 个因子足以张成；Beyond the Taylor Rule | 因子收敛；货币政策框架转向预期锚定 |

## 三、三次范式转折

### 3.1 第一次转折：从经验到科学（1952–1973）

**转折内容：** 投资从「挑选好公司」变成「在风险与收益的权衡中优化组合」。

**推动问题：** 在 Markowitz 之前，投资分析几乎完全集中在单个证券的估值上（Graham-Dodd 路线），没有可计算的组合层面理论。

**完成的标志：** Markowitz（组合理论）、MM（公司金融）、CAPM（均衡定价）、EMH（信息效率）、Black-Scholes（衍生品）五块拼图在二十年内全部就位，形成一套逻辑严密的统一框架。

**这一时期的共同特征：** 假设强、结论锐利、数学化程度高。金融学由此获得了「社会科学王冠上的宝石」的地位。

### 3.2 第二次转折：从理想到现实（1980s–2010s）

**转折内容：** 实证发现大量无法解释的现象，理论开始修补与分化。

**推动问题：** 规模、价值、反转、一月效应、股权溢价之谜、波动率微笑。这些现象不是噪音，它们有稳定的模式。

**两条修补路线：**

| 路线 | 做法 | 代表 |
|------|------|------|
| 在理性框架内补丁 | 加因子、加摩擦、改偏好 | 多因子模型、金融加速器、习惯形成、长期风险、罕见灾难 |
| 换假设 | 引入心理学，放松理性人假设 | 行为金融、有限套利、前景理论 |

**完成的标志：** 没有明确标志，因为这条转折还在进行中。可以确认的是：**到 2010 年代，行为金融已从异端进入主流**（2002、2013、2017 年三次诺贝尔奖与此领域相关）。

### 3.3 第三次转折：从数量到质量（2015 至今）

**转折内容：** 不再问「又发现了什么」，而是问「已发现的还站得住吗」。

**推动问题：** 已发表因子超过 300 个，其中大多数不可能都是真的。多重检验问题被正式提出。

**核心成果与影响：**

| 成果 | 影响 |
|------|------|
| Harvey-Liu-Zhu（2016） | 把 t 门槛从 2.0 提到约 3.0，成为实证研究的新规范 |
| McLean-Pontiff（2016） | 证明发表本身会显著削弱收益预测性，确立「发表后衰减是常态」 |
| Hou-Xue-Zhang（2020） | 452 个异象的复制，65% 与 82% 的两级失败率 |
| Swade 等（2024） | 约 15 个因子足以张成，其余冗余 |

**这一次转折与前两次性质不同：** 前两次是提出新理论，这一次是**对已有证据的质量审计**。它没有产生新理论，但改变了整个领域的证据标准。

**对写作与研究的直接含义：** 2015 年之后，任何引用实证发现而不提多重检验校正、样本外复现、成本后表现的做法，都已经过时。

## 四、几条思想线索的走向

| 线索 | 起点 | 中间 | 现在 |
|------|------|------|------|
| 组合理论 | Markowitz 均值方差 | CAPM、Black-Litterman、风险平价 | 简洁方法回归（1/N 之谜、等权多因子） |
| 资产定价 | CAPM 单因子 | APT、多因子、SDF 统一 | 因子收敛（约 15 个）与复制审计 |
| 市场效率 | EMH 三形式 | 异象累积、行为挑战 | 无定论，转向「异象本身是否稳健」 |
| 投资者理性 | 理性预期 | 前景理论、有限套利 | 行为金融主流化，但预测力仍弱 |
| 公司金融 | MM 定理 | 权衡、代理、信号、啄食顺序 | 多理论并用，无统一理论 |
| 风险度量 | 波动率 | VaR | ES + 压力测试三层配合 |
| 金融与宏观 | 货币数量论 | IS-LM、泰勒规则、金融加速器 | 金融周期理论，模型未达共识 |
| 证据标准 | 单篇论文的显著性 | 样本外检验 | 多重检验校正 + 复制研究 + 发表后衰减 |

**一条总的趋势：从「更强的假设推出更锐利的结论」，转向「对已有结论做更严格的审计」。**

## 五、中国市场适用性专章

这一章是本 skill 最需要标注不确定性的部分。**A 股制度变更频繁（注册制、退市新规、做空机制、投资者结构），因任何有效性判断都带有时间戳。**

### 5.1 判断中国市场时的三个结构性差异

| 差异 | 内容 | 受影响的理论 |
|------|------|------------|
| 参与者结构 | 散户持股市值约 30%，贡献 70% 以上交易量 | 行为金融的适用性上升；EMH 半强式不成立 |
| 套利限制更硬 | 做空机制不完善（融券成本高、券源少），是制度性而非资金性约束 | 有限套利理论的解释力突出 |
| 制度摩擦显著 | 涨跌停 + T+1 截断价格发现；政策对定价权重高 | 信息反应速度慢，价格发现过程被拉长 |
| 样本期短、制度变更多 | 可用历史短，期间规则多次变化 | 数据挖掘风险高于成熟市场；因子结论更不可靠 |
| 国企预算软约束 | 财务困境成本的市场约束被削弱 | 权衡理论在中国的适用性下降 |

### 5.2 逐理论适用性对照

| 理论 | 中国适用性 | 需要调整的地方 |
|------|-----------|--------------|
| 现值/DCF | 适用 | 贴现率中的国家风险溢价如何设定缺乏共识；终值假设对中国成长型企业尤其脆弱 |
| MPT | 框架适用 | 参数估计问题更严重（样本期短、波动结构不稳） |
| CAPM | 横截面解释力弱 | 与成熟市场同样差。用于资本成本时需额外考虑制度溢价 |
| APT / 多因子 | 需本土化 | 因子的显著性排序与美股不同；需重新检验而非直接套用 |
| 期权定价框架 | 适用 | 无套利原理不受市场成熟度影响；但参数校准需用本市场数据 |
| EMH 弱式 | 部分成立 | 反转与动量异象长期显著，与弱式有效不完全一致 |
| EMH 半强式 | **明显不成立** | 公开信息反应滞后，存在数天至数周的消化期 |
| 前景理论 | 适用 | 散户占比高，偏差表现更集中 |
| 有限套利 | **适用性突出** | 套利限制是硬的制度约束 |
| 行为资产定价模型 | 适用性较高 | 但要注意模型本身预测力弱的问题同样存在 |
| MM 定理 | 套利逻辑适用 | 作为基准使用 |
| 权衡理论 | 国企场景适用性下降 | 预算软约束削弱财务困境成本的约束力 |
| 啄食顺序 | 适用性受限 | A 股权益融资的历史约束（审批制）与理论假设的「自由选择融资方式」不符 |
| 代理理论 | 适用 | 需补充国有股东的特殊性（控制权偏好、行政任命） |
| 泰勒规则 | 需改造 | 中国的货币政策调控仍在从数量型向价格型转型，仅看利率不完整；需同时看数量维度 |
| 三元悖论 | 需调整 | 适度资本管制 + 汇率容忍度是获得独立性的两个现实条件；二元悖论指出汇率浮动的作用有限 |
| 明斯基框架 | 适用 | 机制解释有效，但事前预测力弱的特点同样存在 |
| 金融加速器 | 适用 | 国企的软约束会削弱借贷双方的双向传导 |
| VaR / ES | 方法适用 | 厚尾特征可能更明显；需用本地数据重新校准 |
| 相关性失效 | 同样存在 | 危机期相关性上升的现象无本质差别 |

### 5.3 在中国场景下使用金融理论的五条纪律

1. **每一条结论都要标时点。** A 股的制度与结构变革速度快，2015 年的结论在 2025 年可能已经不成立
2. **区分制度性无效与行为性无效。** 涨跌停与 T+1 造成的是制度摩擦，散户偏差造成的是行为偏离。两者的政策含义与持续性不同
3. **不要直接套用海外因子清单。** 因子的显著性排序、样本期长度、交易成本结构都不同，需要独立检验
4. **数据挖掘风险要按更高标准处理。** 样本期更短、制度变更更多，同样的 t 值在 A 股的证据强度更低
5. **国企场景单独处理。** 预算软约束改变了财务困境成本的作用，这会影响依赖该机制的多个理论（权衡理论、金融加速器）

## 六、理论使用的元规则

这一节是全书的收口。无论用哪个理论，这七条都成立。

### 规则 1：先说清用的是哪个模型

这是联合假说问题的直接要求。讨论「市场是否有效」「收益是否可预测」时，必须说明相对于哪个资产定价模型。

### 规则 2：假设核验先于结论引用

拿到一个理论结论，先问它在什么条件下成立，再对当前场景逐条核验。**不核验就直接引用，是误用理论最常见的方式。**

### 规则 3：只说能说的

理论能回答「结构关系」，不能回答「时点」。用理论给出时点判断，是超出了它的能力范围。明斯基框架在这方面尤其容易被误用。

### 规则 4：争议必须标注

有实质性分歧的理论（CAPM、EMH 半强式、明斯基、MMT、泰勒规则、VaR、UIP），引用时必须写出分歧双方与各自的依据。

### 规则 5：证据要过审计

2015 年之后，引用实证发现必须带上：多重检验校正后的显著性、样本外与跨市场复现情况、扣除成本后的收益、与已知因子的独立性。

### 规则 6：数据要求越高，越要警惕

参数越多，估计误差越大。高数据要求的理论（均值方差优化、DCF、VaR 参数法）在实务中表现普遍不如直觉预期。简洁方法常常更好。

### 规则 7：分清用途再谈优劣

同一个理论在不同用途下评价不同：

| 用途 | 评价标准 |
|------|---------|
| 精确预测 | 样本外表现 |
| 基准参照 | 是否可计算、是否被广泛认可 |
| 教学框架 | 是否清晰、是否能建立直觉 |
| 沟通语言 | 是否可被非技术受众理解 |
| 政策讨论 | 是否能承载机制解释 |

**CAPM 在「精确预测」上评价很低，在「基准参照」和「沟通语言」上评价很高。** 不区分用途就讨论「CAPM 好不好」，讨论是没有意义的。
