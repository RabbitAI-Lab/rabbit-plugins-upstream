# 15 非西方金融史与政策实践

## 一、这一份回答什么问题

`13` 与 `14` 的政策工具与投资案例主要来自成熟市场。**非西方市场的制度条件不同，同样的政策会产生不同的效果，同样的信号含义也不同。**

这一份按区域梳理：金融史脉络 → 各类行情下的政策应对 → 代表性机会 → 判断依据。覆盖伊斯兰世界、印度、日本、韩国、东南亚、中国（含中国香港与中国台湾）、拉美、俄罗斯与东欧、中东与海湾、非洲、土耳其。

配套阅读：`13-行情类型与政策工具箱.md`、`14-投资案例与判断逻辑.md`。

## 二、为什么必须单独处理

### 2.1 制度条件差异导致的六个偏移

| 偏移 | 内容 | 后果 |
|------|------|------|
| **外储约束更硬** | 本币非国际货币，外债必须用外币偿还 | 政策空间受外储规模直接约束，宽松不能随意 |
| **货币错配普遍** | 借外币、赚本币 | 贬值即危机，这是新兴市场危机的核心机制 |
| **央行独立性较弱** | 财政主导、政治干预 | 政策可信度低，同样的政策效果打折 |
| **通胀记忆更长** | 历史上多次经历高通胀 | 通胀预期锚定差，公众不信「暂时性通胀」 |
| **政策工具受管制** | 资本管制、利率管制、信贷额度 | 政策传导路径与成熟市场不同 |
| **银行体系更集中** | 国有银行主导或财阀关联 | 货币政策通过行政渠道传导，而非利率渠道 |

### 2.2 由此得出的三条判断调整

1. **在非西方市场，先看外储与外部融资能力，再看货币政策。** 外储是硬约束，利率不是
2. **在非西方市场，政策可信度折价更大。** 同样幅度的承诺，市场反应弱于成熟市场
3. **在非西方市场，制度性套利（管制差异）常比基本面更决定收益。** 一价定律的偏离幅度更大、持续时间更长

## 三、伊斯兰世界：利息禁令下的金融体系

### 3.1 脉络

| 时期 | 制度 |
|------|------|
| 7 至 8 世纪 | 金币第纳尔确立，重量成色稳定，成为跨区域结算货币 |
| 9 至 10 世纪 | suftaja（异地支付指令）、hawala（汇款）、sakk（支付凭证）成熟 |
| 中世纪 | mudaraba（一方出资一方经营）、musharaka（共同出资共担盈亏）、murabaha（成本加成销售）成为合规融资结构 |
| 1963 | 埃及出现现代伊斯兰银行的早期试验机构 |
| 1975 | 伊斯兰开发银行、迪拜伊斯兰银行成立，现代伊斯兰金融业成形 |
| 1983 | 马来西亚颁布伊斯兰银行法；此后成为全球伊斯兰金融枢纽 |
| 2002 | 马来西亚发行首只主权伊斯兰债券（sukuk） |
| 2000 年代 | 全球 sukuk 市场快速扩张，海湾基建与马来西亚为主要发行方 |

### 3.2 政策工具的特殊性

| 常规工具 | 伊斯兰金融中的对应安排 | 机制差异 |
|---------|---------------------|---------|
| 利率政策 | 以利润率（profit rate）替代 | 传导依赖利润分享合同，对资金价格的敏感度低于利率 |
| 央行流动性支持 | 需使用符合教义的抵押品与结构 | 可用的抵押品种类受限 |
| 公开市场操作 | 需使用 sukuk 或商品 Murabaha | 市场规模与深度不及国债市场 |
| 存款准备金 | 同样适用 | 但对伊斯兰银行与常规银行需分别设定 |
| 财政融资 | 发行 sukuk 而非付息国债 | 需以实物资产或项目收益为支撑 |

### 3.3 行情与政策应对

| 行情 | 政策应对 | 特点 |
|------|---------|------|
| 1970 年代石油繁荣 | 石油美元流入，伊斯兰银行业复兴 | 资金充裕推动制度化 |
| 2000 年代扩张 | 马来西亚与海湾竞争伊斯兰金融中心；sukuk 快速扩容 | 制度套利与监管竞争 |
| 2008 年危机 | 伊斯兰银行受次贷直接冲击较小（不持有传统结构化产品） | 合规约束意外提供了风险隔离 |
| 2014 至 2016 油价下跌 | 海湾国家动用储备，发行主权 sukuk | 财政压力推动伊斯兰债券扩容 |
| 2017 年 | 出现 sukuk 的结构性争议案例（发行人主张不按传统路径赎回） | 暴露了「合规结构」与「合同法实质」之间的张力 |

### 3.4 判断依据

- **看合规结构的实质而非形式。** 同一个名称下的合同安排可能差异极大，需看资产是否真实转移、风险由谁承担
- **看监管辖区的选择。** 马来西亚与海湾的伊斯兰金融监管标准不同，会影响同一结构的风险
- **看油价。** 海湾国家的财政状况与油价高度相关，主权 sukuk 的信用质量随之变化

## 四、印度：从管制经济到自由化

### 4.1 脉络

| 时期 | 制度与事件 |
|------|-----------|
| 1850 年代 | 殖民政府发行铁路债券，形成早期资本市场 |
| 1913 | 卢比纳入金汇兑体系 |
| 1947 后 | 五年计划，国有化与许可证制度（License Raj） |
| 1969 | 14 家主要银行国有化 |
| **1991** | **国际收支危机 → 自由化改革**（详见 4.2） |
| 2003 至 2007 | 股市长期上行 |
| 2008 | 全球危机冲击 |
| 2013 | 美联储退出预期引发资本外流，卢比承压 |
| 2016 | 废钞令（取消高面值纸币流通） |
| 2017 | 商品与服务税改革，统一全国税制 |

### 4.2 案例：1991 年国际收支危机与改革

| 项目 | 内容 |
|------|------|
| 行情类型 | 危机（国际收支危机） |
| 触发 | 海湾战争推高油价 + 海外侨汇下降 + 政治不稳定 + 长期双赤字 |

**识别信号**

- 外汇储备降至仅能覆盖约两周进口
- 政府以黄金作为抵押向外国央行取得短期融资
- 经常项目逆差持续扩大
- 财政赤字与货币化融资并存

**推理链条**

```
外部冲击（油价、侨汇） + 内部失衡（双赤字）
→ 外储耗尽
→ 无法维持汇率与进口支付
→ 必须贬值 + 接受外部融资条件
→ 外部融资条件要求结构性改革
→ 改革改变资源配置机制（取消许可证、开放外资）
→ 释放被抑制的增长潜力
```

**决策要点**

- 判断依据是**外储覆盖进口的月数**，这个指标最直接
- 政策转向的信号是「改革方案的具体文本」（取消许可证、汇率并轨、外资准入），不是官员表态
- 机会窗口在改革启动后的早期，此时市场对改革效果存在分歧

**结果与教训**

1991 年 7 月卢比大幅贬值，随后推行结构性改革。改革启动后印度股市进入长期上行通道。

**可复用的部分：** **国际收支危机常成为结构性改革的强制触发器。** 外储耗尽时，改革的政治阻力最小。

### 4.3 判断依据汇总

| 行情 | 关注点 |
|------|-------|
| 上行期 | 外资流入规模、经常项目逆差、卢比汇率、油价（印度是石油净进口国） |
| 下行期 | 外储覆盖月数、央行外汇干预、加息幅度、财政赤字 |
| 政策转向 | 改革文本的具体条款、外资准入清单、税制改革进度 |

## 五、日本：从泡沫到资产负债表衰退

### 5.1 脉络

| 时期 | 制度与事件 |
|------|-----------|
| 1872 | 国立银行条例，建立近代银行体系 |
| 1882 | 日本银行成立 |
| 1897 | 加入金本位 |
| 1949 | 道奇路线，固定汇率 360 日元兑 1 美元 |
| 1973 | 石油危机冲击 |
| **1985** | **广场协议 → 日元升值 → 宽松 → 泡沫** |
| 1989 至 1990 | 央行连续加息 + 房地产贷款总量管制 → 泡沫破裂 |
| 1997 至 1998 | 金融机构连续倒闭，金融危机 |
| 1999 | 零利率政策 |
| 2001 | 量化宽松（早于欧美） |
| 2003 | 银行不良资产处置方案推进 |
| 2013 | 量化与质化宽松（QQE） |
| 2016 | 收益率曲线控制 |

### 5.2 三类行情的政策与机会

**牛市与泡沫（1986 至 1989）**

| 项目 | 内容 |
|------|------|
| 政策链条 | 广场协议后日元升值 → 出口承压 → 央行降息 → 信贷扩张 → 土地与股票价格上涨 |
| 识别信号 | 以土地为抵押的信贷增速远超名义 GDP；地价与股价同步急升；「东京地价买下美国」类论述流行 |
| 关键信号 | **1989 年 5 月起央行加息，并引入房地产贷款总量管制** |
| 判断依据 | 政策工具从价格型（加息）升级到数量型（贷款总量管制），说明价格工具已被判断为无效。**工具升级比加息本身强得多** |
| 结果 | 1990 年泡沫破裂，日经指数此后长期下行 |

**熊市与资产负债表衰退（1990 至 2012）**

| 项目 | 内容 |
|------|------|
| 政策组合 | 零利率（1999）、量化宽松（2001）、多轮财政刺激 |
| 为什么无效 | **资产负债表衰退**：企业与家庭优先偿还债务而非借贷，利率再低也无人借款。货币政策传导中断 |
| 识别信号 | 企业部门净储蓄为正；信贷需求对利率不敏感；货币乘数持续下降 |
| 政策教训 | 在资产负债表衰退中，货币政策不是有效工具，需要财政直接填补需求缺口 |

**政策转向型机会（2012 至 2013）**

| 项目 | 内容 |
|------|------|
| 识别信号 | ① 2012 年 11 月，政治人物在竞选中明确承诺货币宽松与通胀目标；② 12 月选举结果确认；③ 2013 年 1 月，央行与政府共同设定 2% 通胀目标；④ 4 月，新任央行行长推出大规模量化与质化宽松 |
| 推理链条 | 人事更替 + 制度目标变更 + 工具规模质变 → 政策体制（regime）转换 → 本币贬值与权益资产重估 |
| 关键判断 | **信号不在单次政策动作，而在体制转换。** 央行行长更替、通胀目标写入官方文件、工具规模量级变化，三者叠加构成体制转换 |
| 结果 | 权益指数与汇率在两年内出现大幅同向变动（股升、汇贬） |
| 可复用部分 | 判断体制转换，看人事、目标、工具规模三项，而不是看单次会议 |

### 5.3 判断依据汇总

| 观察对象 | 为什么重要 |
|---------|-----------|
| 央行行长与政策委员会的人事变动 | 体制转换的前兆 |
| 是否设定明确通胀目标 | 目标制是体制标志，不是技术细节 |
| 资产购买规模相对 GDP 的比例 | 量级变化才是质变 |
| 企业部门净储蓄 | 判断是否存在资产负债表衰退 |
| 收益率曲线形态 | 日本长期采用收益率曲线控制，曲线形态直接反映政策意图 |

## 六、韩国：政策性金融与危机应对

### 6.1 脉络

| 时期 | 制度与事件 |
|------|-----------|
| 1960 至 1970 年代 | 出口导向 + 政策性贷款（优惠利率定向支持出口与重化工业） |
| 1980 年代 | 逐步自由化 |
| **1997** | **亚洲金融危机，接受 IMF 大规模救助** |
| 1998 至 1999 | 财阀重组、劳动力市场改革、外资准入放开 |
| 2008 | 韩元大幅贬值，与美联储建立货币互换 |
| 2020 年代 | 半导体周期主导经济波动 |

### 6.2 案例：1997 年危机

| 项目 | 内容 |
|------|------|
| 行情类型 | 危机（货币与银行双重危机） |

**识别信号**

- 短期外债对外汇储备的比率超过 1
- 财阀负债率极高（债务对权益比率普遍在数倍以上）
- 商业银行通过海外分行大量借入短期外币，形成货币与期限双重错配
- 经常项目逆差扩大
- 区域性传染已经发生（泰铢、印尼盾）

**推理链条**

```
财阀高杠杆 + 银行短借长贷 + 外币负债
→ 外币融资渠道一旦关闭，企业无法滚动短期债务
→ 银行为偿还外债必须抢购美元 → 本币急贬
→ 贬值使外币债务本币值暴增 → 企业违约 → 银行不良激增
→ 政府外储不足以同时支持汇率与银行体系
→ 必须接受外部救助并接受结构调整条件
```

**政策应对**

| 措施 | 目标 |
|------|------|
| 大幅提高利率 | 阻止资本外流、稳定汇率 |
| 接受 IMF 条件性贷款 | 补充外储 |
| 财阀债务重组与交叉担保解除 | 降低系统性杠杆 |
| 开放外资并购 | 引入外部资本与治理 |
| 劳动力市场改革 | 提升调整弹性 |

**判断依据**

- 危机后的机会窗口出现在**外储开始回升、汇率稳定、企业债务重组方案明确**之后
- 关键信号：外储连续数月回升、汇率波动率下降、外资开始净流入
- 时机判断：不是危机最深时，而是**稳定机制已经建立、但市场信心尚未恢复**的时段

**结果与教训**

危机后韩国经历了结构调整，企业治理与外资准入显著改善。1998 至 1999 年市场出现显著反弹。

**可复用的部分：** 接受外部救助并执行结构调整的国家，其中期恢复通常好于拒绝调整的国家。**代价是短期的深度衰退与社会成本。**

## 七、东南亚：分化最明显的危机应对

### 7.1 同一次危机的四种应对

1997 年危机中，东南亚各国采取了差异极大的政策路径，构成了一组天然对照实验。

| 国家 | 汇率政策 | 资本管制 | 结果与争议 |
|------|---------|---------|-----------|
| **泰国** | 放弃钉住，汇率自由浮动 | 无 | 危机起点。此前通过国际银行便利大量借入短期外币 |
| **印尼** | 浮动 | 无 | 危机最深，伴随社会动荡与政权更替。IMF 条件中的部分措施（如取消补贴）加剧了社会冲击 |
| **马来西亚** | 1998 年 9 月固定汇率并实施资本管制 | 有 | 1999 至 2000 年恢复速度在当时快于接受 IMF 方案的国家。**但起点条件不同，不能直接归因于管制本身** |
| **中国香港** | 维持联系汇率制 | 无 | 1998 年 8 月政府直接入市买入成分股，动用约 1,180 亿港元（约占市值 7%），后以交易所交易基金形式逐步退出 |

### 7.2 判断依据

| 观察对象 | 含义 |
|---------|------|
| 短期外债 / 外储 | 核心脆弱性指标 |
| 银行对不动产的敞口 | 抵押品集中于单一资产的风险 |
| 国际银行便利的规模与期限 | 泰国危机前的关键渠道 |
| 政策反应的类型 | 加息保汇率，还是浮动汇率换取降息空间，决定衰退深度与恢复速度 |

### 7.3 马来西亚 1998 年的争议

这是「逆华盛顿共识」最常被引用的案例。

**支持方论点：** 资本管制阻断了资本外逃，固定汇率稳定了预期，为结构性改革争取了时间；恢复速度快于接受 IMF 方案的国家。

**批评方论点：** 起点条件不同（马来西亚的短期外债比率低于泰国与印尼）；管制的成本体现在长期（外资信心、市场效率、行政成本）；若管制未被解除，长期成本会显现。

**本模块的立场：** 学术上未形成共识，引用时必须写出双方论点，不能只引一方。

**可复用的部分：** **同类危机的不同应对方式，是最好的对照实验。** 分析时要注意起点条件的差异，避免把「结果差异」直接归因为「政策差异」。

## 八、中国：从白银到现代金融体系

### 8.1 脉络

| 时期 | 制度与事件 |
|------|-----------|
| 明清 | 白银货币化，一条鞭法以白银计税 |
| 1935 | 法币改革，放弃银本位 |
| 1949 至 1978 | 计划经济，金融体系单一化 |
| 1990 | 上海与深圳证券交易所设立 |
| 1994 | 汇率并轨，人民币大幅调整 |
| 1997 至 1998 | 亚洲金融危机中维持汇率稳定、加强资本管制 |
| 1998 至 2002 | 国有银行不良资产剥离至资产管理公司 |
| 2001 | 加入世界贸易组织 |
| 2005 | 汇率形成机制改革，人民币进入渐进升值通道 |
| 2005 至 2007 | 股权分置改革推动市场大幅上行 |
| 2008 | 大规模财政刺激 |
| 2015 | 杠杆行情与随后的市场危机 |
| 2017 | 金融去杠杆 |
| 2020 | 房地产融资管理规则（「三道红线」） |
| 2021 后 | 房地产信用收缩与风险处置 |

### 8.2 三类关键案例

**牛市与制度变革（2005 至 2007）**

| 项目 | 内容 |
|------|------|
| 识别信号 | 股权分置改革方案明确：非流通股东向流通股东支付对价换取流通权；方案需股东大会表决通过 |
| 推理链条 | 股权分割 → 大股东不关心股价 → 治理折价；改革后利益绑定 → 治理改善 → 估值中枢上移 |
| 关键判断 | **依据是制度文本（对价方案），不是政策表态。** 制度改变激励结构，效果持续期远长于短期政策 |

**杠杆行情崩塌（2015）**

| 项目 | 内容 |
|------|------|
| 识别信号（上行） | 融资余额从数千亿元升至超过 2 万亿元；场外配资出现且杠杆高于场内；新开户数激增 |
| 识别信号（转折） | 监管开始清查场外配资（2015 年中）；融资余额见顶回落；成交量先于价格见顶 |
| 推理链条 | 杠杆资金 + 强制平仓线 → 下跌触发平仓 → 平仓加剧下跌 → 更多平仓触发 |
| 政策应对 | 入市买入、限制减持与做空、暂停新股发行 |
| 关键教训 | **政策底不等于市场底。** 入市解决流动性，不解决杠杆资金退出与估值回归 |

**房地产信用收缩（2020 后）**

| 项目 | 内容 |
|------|------|
| 识别信号 | 针对房企融资的量化约束规则出台（2020 年 8 月）；房企融资渠道同时收紧 |
| 推理链条 | 高杠杆房企依赖滚动融资 → 融资渠道收紧 → 现金流断裂 → 项目停工 → 销售下滑 → 进一步恶化 |
| 判断依据 | 看房企的**短期债务到期结构与现金短债比**，而不是看销售数据 |
| 政策应对 | 后续的融资支持、保交楼措施、需求端放松 |

### 8.3 中国台湾与中国香港

| 地区 | 关键事件 | 政策与判断依据 |
|------|---------|--------------|
| 中国台湾 | 1990 年资产泡沫破裂（指数从约 12,000 点跌至约 2,500 点） | 央行紧缩与信用管制；此后设立稳定基金机制 |
| 中国台湾 | 1997 至 1998 年亚洲危机中相对稳健 | 外债规模小、经常项目顺差，脆弱性低于东南亚 |
| 中国香港 | 1998 年政府入市击退空头 | 买入成分股 + 后续以交易所交易基金退出。判断依据是「联系汇率制不可放弃」的政治承诺 |
| 中国香港 | 离岸人民币中心地位 | 离岸与在岸利差是重要的政策信号，反映资本流动压力 |

### 8.4 判断依据汇总

| 行情 | 关注点 |
|------|-------|
| 上行 | 融资余额与场外杠杆、新开户数、成交量与价格是否背离、政策对杠杆的态度 |
| 下行 | 强制平仓线的分布、政策入市的规模与持续性、杠杆资金退出进度 |
| 政策转向 | 制度文本的条款、工具箱的升级（从价格型到数量型）、人事与目标变化 |
| 房地产相关 | 房企短期债务到期结构、现金短债比、融资渠道是否多渠道同时收紧 |

## 九、拉美：债务危机与货币局制度的教训

### 9.1 脉络

| 时期 | 制度与事件 |
|------|-----------|
| 1970 年代 | 石油美元回流，拉美国家大量借入美元债务 |
| **1982** | **墨西哥违约，拉美债务危机爆发** |
| 1985 | 贝克计划（增加贷款换取改革） |
| 1989 | 布雷迪计划（债务减记并转为可交易债券） |
| 1990 年代 | 私有化，外资流入，布雷迪债券市场形成 |
| 1994 | 墨西哥「龙舌兰危机」，美国主导的国际救助 |
| 1998 至 2002 | 阿根廷货币局制度崩溃与主权违约 |
| 2003 至 2011 | 大宗商品超级周期，巴西、智利受益 |
| 2009 至 2014 | 巴西对资本流入征税（金融交易税） |
| 2018 | 阿根廷再度寻求大规模 IMF 融资 |

### 9.2 案例：阿根廷货币局制度的崩溃（1998 至 2002）

| 项目 | 内容 |
|------|------|
| 行情类型 | 危机（汇率制度与主权债务双重危机） |
| 制度背景 | 1991 年建立货币局制度，比索与美元 1:1 并可自由兑换，货币发行以外储为限 |

**识别信号**

- 货币局制度放弃了货币政策独立性，而阿根廷的主要贸易伙伴（巴西）在 1999 年贬值，竞争力严重受损
- 美元在 1990 年代后期持续走强，阿根廷的出口竞争力进一步削弱
- 财政赤字持续，只能通过借外债弥补
- 债务以外币计价，而税收为本币
- 银行体系大量持有本国政府债券（银行与主权债的绑定）

**推理链条**

```
货币局制度 + 财政赤字 + 外币债务
→ 需要持续的资本流入维持
→ 外部条件变化（巴西贬值、美元走强、国际融资收紧）
→ 资本流入停止 → 外储下降
→ 维持 1:1 比价需要极高利率与财政紧缩 → 经济深度衰退
→ 衰退削弱偿债能力 → 违约风险上升 → 利差扩大 → 融资成本更高
→ 制度与债务同时不可持续
```

**政策应对与顺序**

| 顺序 | 措施 |
|------|------|
| 1 | 存款冻结（限制提取存款） |
| 2 | 主权债务违约 |
| 3 | 放弃固定比价，比索大幅贬值 |
| 4 | 债务重组，大幅减记 |
| 5 | 经济在深度衰退后开始反弹 |

**判断依据**

- 核心指标：**外储 / 基础货币**（货币局制度下决定维持能力）、**外币债务 / 出口收入**
- 制度不可持续的判据是「维持成本高于放弃成本」，而非外储水平本身
- 机会窗口在**制度放弃与债务重组方案明确之后**，不在危机最深处

**结果与教训**

主权违约与货币贬值后，阿根廷资产在以硬通货计价的口径下在此后数年出现显著回升。

**可复用的部分：** **放弃固定汇率制度不是失败，而是把不可持续的东西变成可持续的。** 判断机会的时点是制度调整完成，而非危机最深处。

### 9.3 判断依据汇总

| 观察对象 | 含义 |
|---------|------|
| 外币债务 / 出口收入 | 偿债能力的直接约束 |
| 外储 / 基础货币 | 固定汇率制度的维持能力 |
| 银行持有的主权债比例 | 银行与主权的绑定程度，决定危机的传染速度 |
| 主要贸易伙伴的汇率变化 | 相对竞争力，固定汇率下的隐性压力 |
| 大宗商品价格 | 拉美多数国家的财政与出口基础 |

## 十、俄罗斯与东欧：转轨的两种路径

### 10.1 俄罗斯

| 时期 | 制度与事件 |
|------|-----------|
| 1991 | 苏联解体 |
| 1992 | 「休克疗法」：价格自由化、私有化、财政货币紧缩 |
| 1995 | 贷款换股权式私有化 |
| **1998** | **短期国债违约、卢布贬值、债务延期偿付** |
| 1999 至 2008 | 油价上行推动权益市场大幅上行 |
| 2008 | 市场暴跌，外储大量消耗 |
| 2014 | 克里米亚事件后制裁，卢布危机，转向浮动汇率 |
| 2022 | 制裁升级，实施资本管制与市场限制 |

**1998 年危机的识别信号**

- 短期国债收益率极高（年化三位数），表明市场已定价极高违约风险
- 债务高度依赖滚动发行，短期债务占比高
- 亚洲金融危机后国际资本撤离新兴市场
- 油价下跌冲击财政收入
- 财政赤字与债务货币化压力

**推理链条**

```
高短期债务比重 + 只能滚动发行 + 外部融资关闭
→ 无法再融资 → 违约
→ 违约触发本币贬值与资本外逃 → 需要债务延期偿付与资本管制
→ 代价：信用长期受损，但终止了失血
```

**政策应对：** 违约、贬值、延期偿付、资本管制，然后逐步恢复。

**机会窗口：** 1998 年危机之后，随着油价回升与财政纪律恢复，权益市场在随后多年大幅上行。**判断依据是油价与财政收支的同步改善，不是违约事件本身。**

### 10.2 东欧与转轨路径对照

| 国家 | 路径 | 结果 |
|------|------|------|
| 波兰 | 1990 年激进稳定计划（价格自由化、货币紧缩、汇率锚定） | 短期深度衰退，但较早恢复增长，后加入欧盟 |
| 匈牙利 | 渐进改革，较早引入外资 | 外资占银行体系比重高，2008 年危机中受冲击大 |
| 捷克 | 快速私有化 | 初期成效有限，后调整 |

**转轨的核心判断依据：**

1. **稳定化的速度。** 越早把通胀压下来，恢复越早
2. **外部锚的选择。** 汇率锚定能快速稳定预期，但丧失货币政策独立性
3. **外资进入银行体系的比例。** 比例高可提升治理，但在全球冲击中成为波动输入渠道
4. **制度建设的质量。** 产权保护与司法效率决定长期资本流入

## 十一、中东与海湾：资源财政与主权基金

### 11.1 脉络

| 时期 | 制度与事件 |
|------|-----------|
| 1950 至 1970 年代 | 石油收入国有化；最早的主权财富基金设立 |
| 1973 | 石油禁运，石油美元大规模回流 |
| 1980 年代 | 油价暴跌，海湾国家转为财政赤字 |
| 1990 年代 | 主权基金规模扩张，全球资产配置 |
| 2003 至 2008 | 油价上行，地区房地产与基建扩张 |
| 2009 | 迪拜债务危机，邻近酋长国提供支持 |
| 2014 至 2016 | 油价暴跌，财政承压；推出经济转型规划 |
| 2019 | 国家石油公司上市 |

### 11.2 制度特点

| 特点 | 含义 |
|------|------|
| 货币钉住美元 | 货币政策跟随美联储，无法独立应对本地周期 |
| 主权财富基金 | 把不可再生资源收入转为可跨代持有的金融资产 |
| 石油收入主导财政 | 财政政策与油价高度同步，缺乏逆周期能力 |
| 家族与王室关联企业密集 | 治理结构与信息披露水平与成熟市场差异大 |

### 11.3 判断依据

- **油价是财政与流动性的第一驱动。** 分析海湾资产先看油价与财政收支平衡油价
- **主权基金的资产配置变化是重要信号。** 基金从海外回流国内，说明财政压力上升
- **钉住美元的代价在利率周期错配时暴露。** 美联储大幅加息而本地区需要宽松时，矛盾最突出
- **治理折价长期存在。** 同一资产在治理改善前后估值差异显著，这是制度套利的来源

## 十三、土耳其：政治干预央行的代价

### 13.1 脉络

| 时期 | 制度与事件 |
|------|-----------|
| 2001 | 银行危机与货币危机，接受 IMF 方案，重建银行体系与央行独立性 |
| 2002 至 2013 | 信用扩张与增长，通胀温和 |
| 2018 | 里拉危机，与主要经济体的外交摩擦叠加 |
| 2019 至 2023 | 非正统政策：在通胀高企时降息 |
| 2021 至 2023 | 里拉大幅贬值，通胀升至数十年高位 |
| 2023 后 | 政策转向，大幅加息 |

### 13.2 案例：非正统政策与货币崩溃

**识别信号**

- 央行行长在短时间内多次更替
- 官方表述从「以通胀为目标」转为「以利率为目标」（即把降息本身当作目标）
- **外汇存款与黄金存款在居民资产中的比例上升**，说明本币信心在流失
- 官方通胀与独立机构估算的通胀存在显著差距
- 央行动用外储干预汇率，外储净额下降

**推理链条**

```
政治压力要求降息 + 通胀高企
→ 实际利率为负 → 本币资产吸引力下降
→ 居民与企业转向外汇存款 → 本币进一步贬值
→ 进口价格上涨 → 通胀更高
→ 需要更高名义利率才能稳定 → 但政策要求降息
→ 循环强化
```

**关键判断依据：** **央行独立性的丧失是可以观察的（人事、目标表述、独立估算的差距），而不是需要预测的。**

**结果与教训**

在非正统政策期间，本币大幅贬值，通胀升至数十年高位。政策转向后大幅加息。

**可复用的部分：** **政治干预央行是货币危机最可靠的先行信号之一。** 观察点是人事与目标表述，不是汇率本身。

## 十四、跨区域的六条共同模式

把上述区域的经验抽象出来。

### 模式 1：外储是硬约束，利率不是

在非西方市场，判断政策空间的第一指标是**外储对外债的覆盖能力**，而不是政策利率水平。外储耗尽时，任何汇率承诺都不可信。

### 模式 2：货币错配是危机的标准配置

借外币、赚本币。贬值直接导致资不抵债。**检查短期外债 / 外储与外币债务 / 出口收入两个比率。**

### 模式 3：政策转换常由危机强制触发

1991 年印度的自由化、1997 年后韩国的结构调整、2001 年后土耳其的银行改革，都由外储耗尽或危机强制推动。**危机时政治阻力最小，这既是规律也是机会窗口。**

### 模式 4：放弃不可持续的固定汇率不是失败

阿根廷、泰国、英国的案例都说明：**放弃固定汇率是把不可持续的东西变成可持续的。** 判断机会的时点是制度调整完成后，不是危机最深处。

### 模式 5：央行独立性的丧失可以观察

人事变动、目标表述变化、官方与独立估算的差距、外储净额下降。这些都是可观察信号，不需要预测。

### 模式 6：制度套利空间大于基本面差异

管制差异（资本账户、行业准入、税制、治理标准）造成的一价定律偏离，幅度更大、持续时间更长。**这是非西方市场超额收益的主要来源，也是主要风险来源。**

## 十五、使用本模块的纪律

| 纪律 | 说明 |
|------|------|
| 不整体化处理「非西方」 | 区域间差异极大。任何关于「新兴市场整体」的结论都不成立，必须落到具体国家 |
| 案例争议要写出双方 | 马来西亚资本管制、IMF 条件的评价等均无共识，只引一方是误导 |
| 起点条件必须说明 | 对照实验的价值取决于起点是否可比。不同起点的结果差异不能直接归因于政策差异 |
| 数据口径要标注 | 新兴市场的官方数据质量差异大，通胀、外储、失业数据需说明来源口径 |
| 不做时点判断 | 与 `13`、`14` 同一纪律。方向与机制可判断，时点不可判断 |
| 中国香港、中国台湾、中国澳门按规范表述 | 涉及其金融机构与法规时，一律使用规范名称 |
