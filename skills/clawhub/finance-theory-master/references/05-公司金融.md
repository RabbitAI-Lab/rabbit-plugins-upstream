# 05 公司金融

## 一、这一板块回答什么问题

企业该投什么项目、钱从哪里来、赚到之后怎么分配。三个问题分别对应投资决策、融资决策、股利决策。

公司金融是金融学里理论最密集、也最「多理论并存」的板块。原因是：**没有任何一个资本结构理论能完整解释观测到的企业行为。** 实务中必须同时用多个框架。

---

## 二、投资决策：资本预算

### 2.1 基本方法

| 方法 | 判据 | 优点 | 问题 |
|------|------|------|------|
| 净现值（NPV） | NPV > 0 则接受 | 理论最正确，与价值最大化一致 | 依赖贴现率与现金流预测的准确性 |
| 内部收益率（IRR） | IRR > 要求收益率 | 直观，不依赖贴现率估计 | 非常规现金流有多个解；规模不可比；隐含再投资假设不合理 |
| 回收期 | 短于阈值则接受 | 简单，反映流动性 | 忽略回收期后的现金流，无时间价值概念 |
| 盈利指数 | PI > 1 则接受 | 资本限额下可用于排序 | 同样依赖贴现率 |
| 实物期权 | 含期权价值则可能接受 | 处理延迟、扩张、放弃的灵活性 | 参数难估，易被滥用为「什么项目都能过」的理由 |

**NPV 的理论地位最高，但实务中最容易被误用的是实物期权。** 把不确定性说成「期权价值」从而给负 NPV 项目背书，是资本预算里最常见的自欺方式。使用实物期权法必须明确写出：期权的类型、行权条件、估值参数来源。

### 2.2 贴现率：WACC 及其问题

```
WACC = (E/V) · R_e + (D/V) · R_d · (1 - T)
```

权益成本 R_e 通常用 CAPM 估算，因此 **CAPM 的局限会直接传导到资本预算**（见 `01-资产定价理论.md` 第三节）。

WACC 的三个常见误用：

1. **用公司整体 WACC 评估所有项目。** 不同业务的风险不同，应使用与项目风险匹配的贴现率
2. **用账面权重代替市场权重。** 理论要求市场价值权重
3. **循环依赖。** 权益成本依赖 beta，beta 依赖杠杆，杠杆又依赖融资决策

## 三、资本结构：MM 定理与后继理论

### 3.1 MM 定理

Modigliani、Miller（1958）提出，1963 年加入公司所得税修正。

| 版本 | 命题 | 公式 |
|------|------|------|
| 无税 | 企业价值与资本结构无关 | V_L = V_U |
| 无税 | 权益成本随杠杆线性上升 | R_E = R_U + (D/E)(R_U − R_D) |
| 有税 | 负债带来税盾，负债越多价值越高 | V_L = V_U + T × D |

**核心论证是套利：** 如果两个只有资本结构不同的公司价值不等，投资者可以用「自制杠杆」复制另一方的风险收益结构并套利，套利会消除价差。

**这条套利逻辑本身是稳健的。** 它是 MM 定理最经得起检验的部分。

### 3.2 假设与偏离

| 假设 | 现实 |
|------|------|
| 无税 | 公司税与个人所得税都存在，且税盾价值受个人税影响（米勒 1977 修正） |
| 无交易成本 | 存在 |
| 无破产成本 | 存在，且随杠杆非线性上升 |
| 无代理成本 | 存在，且是资本结构的核心决定因素之一 |
| 信息完全对称 | 存在显著不对称 |
| 同质预期 | 分歧普遍 |
| 分析与个人可按同一利率借贷 | 个人借款利率更高 |

**MM 定理的定位：** 它不是一个描述现实的模型，而是一个**基准**。它告诉你「在什么条件下融资决策无关」，从而把研究聚焦到「现实中的哪些摩擦让融资决策变得有关」。

### 3.3 权衡理论

在 MM 基础上引入两边的成本：

```
V_L = V_U + PV(税盾) − PV(财务困境成本) − PV(债务代理成本) + PV(债务代理收益)
```

**最优资本结构出现在税盾的边际收益等于财务困境成本的边际成本处。**

| 债务的好处 | 债务的成本 |
|-----------|-----------|
| 利息税盾 | 财务困境的直接成本（法律与管理费用） |
| 减少自由现金流，约束浪费性投资（Jensen 1986） | 财务困境的间接成本（客户、供应商、员工流失，融资成本上升） |
| 债权人的额外监督 | 资产替代与投资不足（见 3.4） |

**局限：**

- 无法精确量化财务困境成本，它随企业与宏观环境差异极大
- 难以解释为什么很多高盈利企业保持低杠杆（它们有充足的应税收入可以抵税）
- 假设企业有明确的目标杠杆并能无成本地连续调整，实际是动态且有黏性的

**权衡理论预测的最优杠杆因行业而异。** 文献中常引的经验值：公用事业约 60% 至 70%，科技企业约 5% 至 20%。这个差异本身就是权衡理论的最有力证据：现金流越稳定、有形资产占比越高，能承受的杠杆越高。

### 3.4 代理理论

Jensen、Meckling（1976）把资本结构放进代理框架。

**股东与债权人的冲突：**

| 问题 | 机制 |
|------|------|
| 资产替代 / 过度投资 | 高杠杆时股东有动机投资高风险项目：成功归股东，失败主要由债权人承担 |
| 投资不足 / 债务积压 | 存在大量未偿债务时，股东可能拒绝正 NPV 项目，因为收益主要归债权人 |

**股东与经理的冲突：**

| 问题 | 机制 |
|------|------|
| 帝国构建 | 自由现金流充裕时，经理可能投资负 NPV 项目以扩大规模 |
| 自由现金流假说（Jensen 1986） | 负债的强制付息可约束经理浪费现金，这是债务的代理收益 |

**代理理论的价值：** 它把资本结构从「纯财务问题」变成「治理问题」。资本结构不仅是融资方式的选择，也是控制权与激励结构的安排。

### 3.5 信号理论

Ross（1977）：融资选择会向市场传递内部信息。

- 发债 → 管理层对未来现金流有信心（因为承诺了固定支付）
- 发股 → 管理层可能认为股价被高估

**推论：** 融资公告本身就有价格效应。这是资本结构研究中少有的可检验推论，且得到较一致的实证支持。

### 3.6 啄食顺序理论

Myers、Majluf（1984）从信息不对称与逆向选择出发，得出融资的优先顺序：

```
内部融资（留存收益） > 债务融资 > 股权融资
```

**逻辑链条：**

1. 管理层比外部投资者更了解企业价值
2. 若股价被低估，管理层会避免增发新股（不愿让新股东分享低估的价值）
3. 投资者知道这一点，因此把增发视为「股价被高估」的信号
4. 为避免这一嫌疑，管理层优先用内部资金
5. 内部资金不足时，债务对信息不对称的敏感度低于权益，所以优先债务
6. 权益融资是最后手段

**核心预测：企业的负债率由其累积的融资缺口决定，而不是由目标负债率决定。**

### 3.7 市场择时假说

企业根据市场条件择时发行：股价被高估时发股，被低估时回购。放松了啄食顺序关于市场半强式有效的假定。

实证结果混杂：部分企业确实在择时，但持续预测估值水平很困难。

### 3.8 资本结构理论的实证状态

| 理论 | 支持的证据 | 未解释的问题 |
|------|-----------|------------|
| 权衡理论 | 行业间杠杆差异与税盾价值正相关；Graham-Harvey（2001）调查 392 位 CFO，81% 认为存在目标资本结构 | 高盈利企业为何低杠杆；困境成本难量化 |
| 啄食顺序 | 多数企业偏好内部资金；盈利能力与负债率负相关 | 为何有些企业在能借款时发股；为何有些企业维持目标负债率 |
| 代理理论 | 治理结构与杠杆相关 | 代理成本难量化 |
| 市场择时 | 存在择时行为 | 难以持续预测估值；结果混杂 |

**Fama、French（2002）估算的调整速度约为每年 7% 至 18%。** 这个速度既不是「瞬时调整」（支持权衡理论需要的最快情形），也不是「完全不调整」（支持啄食顺序），所以两种理论各有一部分解释力。

**关于中国市场的实证发现：**

| 发现 | 来源 | 含义 |
|------|------|------|
| 资本结构调整存在非对称性：负债率提高时，经营绩效对调整速度的影响逐步减弱 | 段军山、宋贺 | 「棘轮效应」——上调容易下调难 |
| 国有控股公司调整速度较慢 | 同上 | 预算软约束与监管缺失是主因 |
| 调整速度约 0.311 | 连玉君等（2007） | 低于成熟市场水平 |
| 市场化进程快的地区调整速度快约 7 个百分点 | 姜付秀等（2011） | 制度成本是调整速度的重要决定因素 |

**中国场景下的关键特殊性：国有企业的预算软约束使「财务困境成本」的市场约束被削弱。** 这意味着权衡理论在中国国企场景下的适用性下降，因为该理论依赖财务困境成本作为杠杆的制衡力量。

## 四、股利政策

### 4.1 基本框架

| 理论 | 核心观点 |
|------|---------|
| MM 股利无关论 | 在无税、无摩擦条件下，股利政策不影响企业价值（投资者可自制股利） |
| 信号理论 | 股利变化传递管理层对未来的信心；股利增加是正面信号，削减是负面信号 |
| 代理成本 | 分红减少自由现金流，约束管理层浪费（与自由现金流假说同源） |
| 税收客户效应 | 股利与资本利得的税率不同，吸引不同税负的投资者群体 |
| Lintner 模型 | 企业倾向于平滑股利，只对持久性的盈利变化做出调整 |

### 4.2 现实中的关键约束

| 约束 | 影响 |
|------|------|
| 股利的黏性 | 管理层极不愿意削减股利，因此股利水平一旦确定就具有下行刚性 |
| 回购的替代性 | 回购比股利更灵活（无黏性），且在不同税制下有税收优势，因此成为越来越主要的分配方式 |
| 监管与制度 | 不同市场对分红有不同要求与惯例 |

**实践中的观察：** 由于股利的黏性，**股利变化所传递的信号强度高于股利水平本身**。这一条比「高股利好还是不好」更有信息量。

## 五、企业估值

| 方法 | 逻辑 | 适用 | 主要陷阱 |
|------|------|------|---------|
| DCF（自由现金流折现） | 预测未来自由现金流并折现 | 现金流可预测的成熟企业 | 终值占比重过大；贴现率与增长率不匹配 |
| APV（调整现值法） | 无杠杆价值 + 融资副作用现值 | 杠杆结构会显著变化时 | 融资副作用的估算 |
| WACC 法 | 用加权平均资本成本折现 | 杠杆结构稳定时 | 承接 CAPM 的全部问题 |
| 相对估值（可比公司/倍数） | 用可比标的的倍数 | 有活跃可比标的时 | 可比性假设；市场整体高估或低估会传导 |
| 实物期权 | 加入灵活性价值 | 高不确定性、可分阶段决策 | 参数难估，易被滥用 |

**一块重要的实务经验：估值结果的精度远低于数字显示的小数位。** DCF 的输入误差在 10% 至 20% 量级时，输出可以相差数倍。因此估值应给出区间与情景，而不是单点数值。

## 六、公司治理与制度

| 视角 | 核心论点 |
|------|---------|
| 代理视角 | 治理机制（董事会、激励、控制权市场）用于降低代理成本 |
| 法与金融（LLSV 一系） | 法律对投资者保护的程度是金融发展与企业价值的重要决定因素 |
| 控制权视角 | 资本结构同时是控制权安排；控制权偏好会影响融资选择 |

**在 A 股场景下的特殊性：**

| 因素 | 影响 |
|------|------|
| 国有控股 | 预算软约束、行政任命、政治关联影响调整行为 |
| 控制权偏好 | 国有股东难以放弃控制权，使杠杆调整阻力更大 |
| 减持与回购制度 | 影响分配政策的实际执行方式 |
| 信息披露质量 | 影响信息不对称的程度，进而影响啄食顺序与信号理论的解释力 |

## 七、本板块的根本局限

| 局限 | 说明 |
|------|------|
| 无统一理论 | 权衡理论、啄食顺序、代理理论、择时假说各解释一部分，没有一个完整解释观测到的资本结构 |
| 静态为主 | 真实决策是动态的；市场条件、成长机会、竞争格局都在变，静态模型只拍到快照 |
| 困境成本难量化 | 这是权衡理论最大的操作障碍，直接导致「最优资本结构」在实践中无法精确计算 |
| 行为因素不可忽略 | CEO 风险偏好、董事会构成、同伴效应对杠杆的解释力可观，研究显示 CEO 个人特征能解释的杠杆变异与公司层面因素相当 |
| 制度差异未充分纳入 | 不同国家的税制、破产法、股权结构差异显著，跨国实证的结论可比性差 |

**实践中的正确姿势：多框架并用。** 不要试图判定哪个理论「对」。针对具体决策，用不同框架各看一遍，列出它们指向的杠杆水平或分配方式，再看分歧在哪，分歧往往就是决策的关键变量。

## 八、与其他板块的接口

| 接口 | 说明 |
|------|------|
| 与资产定价 | CAPM 决定权益成本，进入 WACC，进入资本预算；MM 定理的套利逻辑与无套利定价框架同源 |
| 与有效市场假说 | 若 EMH 成立，公司只能发行公允定价证券，融资决策无关（与 MM 结论相通）；若定价错误，则存在择时与发行窗口 |
| 与行为金融 | 市场择时假说、CEO 过度自信与并购决策、同伴效应 |
| 与投资组合理论 | 企业多元化与组合分散化是同一逻辑；股东可在组合层面自行分散，因此企业的多元化未必增值 |
| 与风险管理 | 财务困境成本是信用风险的核心；资本结构决定信用风险敞口的起点 |
| 与货币宏观金融 | 货币政策通过信贷渠道影响企业融资条件；金融加速器的传导依赖企业的资产负债表状况 |

## 九、使用本板块时的三条提醒

1. **不要问「哪个理论对」。** 资本结构领域没有统一理论，这个判断本身就是结论的一部分。用多个框架交叉看，把分歧列出来。
2. **国企业场景要调整假设。** 预算软约束削弱了财务困境成本的约束力，这会让权衡理论的结论失效，需要单独说明。
3. **估值必须给区间。** 单点估值的精度是假象。给出情景与区间，比给出精确数字更专业，也更诚实。
