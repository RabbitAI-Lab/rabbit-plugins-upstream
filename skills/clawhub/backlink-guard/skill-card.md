## Description:

Checks backlink sources before submission, verifies live listings, and audits a site's backlink profile for spam-like patterns.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zhuyansen](https://clawhub.ai/user/zhuyansen)

### License/Terms of Use:

MIT-0

## Use Case:

SEO practitioners and site owners use it to find backlink opportunities, assess source quality, verify listings, audit link profiles, and inspect competitor and AI search citations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Selected domains, keywords, and questions may be sent to external providers, and records are retained locally.

Mitigation: Review inputs and provider choices before running; do not submit sensitive information.

Risk: Optional checks can incur provider charges.

Mitigation: Review the stated USD cost and obtain explicit approval before any paid run.

Risk: The reviewed artifact does not include the pinned package's executable code.

Mitigation: Verify the pinned release before supplying API keys.
