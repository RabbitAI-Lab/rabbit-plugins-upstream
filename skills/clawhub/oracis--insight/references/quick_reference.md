# Insight 技能 - 快速速查表

## 一句话说明

用AI在10分钟内完成传统方法需要数周的用户洞察分析，直接输出可用于产品设计和营销文案的具体洞察。可选阶段四进一步把洞察转化为《小而美》一人公司/小团队创业方案。

## 三个关键维度

### 痛点 Pain Point
用户最担心/恐惧的是什么？
- 关键：找到"被背叛"的情绪触发点
- 竞争对手往往不是同类产品，而是记忆/习惯

### 痒点 Itch Point
用户想表达什么样的身份？
- 关键：理解"理想中的自己"这种心理投射
- 用户希望别人如何看待他的选择

### 爽点 Pleasure Point
那个"啊~"的满足瞬间是什么？
- 关键：具体的生理/心理细节
- 温度、口感、节奏、情感释放

## 快速启动流程

```
用户输入产品/服务
        ↓
【阶段一】生成4类用户画像 + 核心用户推荐
        ↓
用户选择要分析的用户群
        ↓
【阶段二】输出痛点/痒点/爽点 + 可用文案
        ↓
【阶段三】输出P0/P1/P2产品机会清单
        ↓
（可选）【阶段四】输出小而美创业6步落地路线图
        ↓
得到：明天就能验证的具体方向 / 90天创业行动手册
```

## 输出质量检查清单

- [ ] 用户描述有画面感（能看到具体的人）
- [ ] 核心用户选择有商业逻辑支撑
- [ ] 痛点/痒点/爽点有情绪共鸣
- [ ] 文案表达可直接用于营销
- [ ] 产品机会具体可执行
- [ ] 优先级排序有理由说明

### 阶段四附加检查清单（启用小而美创业落地时）

- [ ] 社区定位通过四问自检（热爱/盈利/自传播/技能）
- [ ] MVP功能不超过3个，且全部通过四问自检
- [ ] 定价方案从第一天就收费（无免费模式）
- [ ] 100客户冷启动有三阶段拓展计划
- [ ] 营销方案含双账号+三层内容+私域沉淀
- [ ] 财务模型含12个月成本预算与runway
- [ ] 反模式警示明确（避免传统创业陷阱）

## 阶段四：小而美创业落地速查

### 6步法核心

| 步骤 | 关键问题 | 反模式 |
|------|----------|--------|
| 4.1 社区反向定位 | 你的核心用户聚集在哪里？你是否属于这个社群？ | 凭空脑补痛点、追大众市场 |
| 4.2 极简MVP | 能否先人工跑通流程？功能能否砍到3个以内？ | 完美主义打磨、功能堆砌 |
| 4.3 100客户冷启动 | 亲友→社群→陌生人三阶段如何展开？第一天定价多少？ | 盛大发布会、免费获客 |
| 4.4 原生营销 | 个人号+品牌号如何分工？30天内容如何排？ | 重金投放、忽视私域 |
| 4.5 盈利护城河 | 12个月成本预算？LTV/CAC是否大于3？ | 营收涨但利润跌、过早融资 |
| 4.6 文化与价值观 | 价值观5条以内？一人公司SOP能否离开你运转？ | 价值观沦为口号、为扩张招人 |

### 极简主义创业者四准则

1. **盈利优先于规模** — 靠营收造血，不依赖融资
2. **先做创作者，再做创业者** — 从输出价值开始
3. **立足社区，服务精准人群** — 聚焦细分社群
4. **掌控大于体量** — 自主决策，按自己节奏经营

## 常见问题

**Q: AI生成的洞察能直接用吗？**
A: 不是"最终答案"，而是"快速可验证的方向"。需要结合真实业务场景测试迭代。

**Q: 适合什么行业？**
A: 通用框架，可适配餐饮、SaaS、电商、教育等行业。

**Q: 需要什么输入？**
A: 产品/服务描述，以及希望分析的侧重点（可选）。

**Q: 输出格式是什么？**
A: 结构化Markdown报告，可导出为文档或演示文稿。
