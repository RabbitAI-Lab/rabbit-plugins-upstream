## Documentation Use Rules

- Verify exact import names, constructors, method names, streaming APIs, tool-call formats, and structured-output APIs against official docs before writing code.
- If docs conflict with local package versions, inspect the installed package version and its local types.
- Cite or mention the official docs consulted in the final report when they materially affected implementation choices.
- Do not paste long documentation excerpts into generated project files.
