# 投标文件分册结构与撰写口径

> 本文件说明 `scripts/engine/bid-lexicon.js` 里那套结构的**来源与口径**，
> 方便你判断生成的骨架是否适用于你的项目，以及该往哪里改。
>
> 本文件是行业通行做法的归纳，**不是法规原文，也不能替代招标文件**。
> 当招标文件与本文件冲突时，**永远以招标文件为准**。

## 一、为什么是"三册"

国内投标文件的主流组织方式是按**评审口径**分册，而不是按部门或按时间：

| 分册 | 评审对应 | 缺项的后果 |
|---|---|---|
| 第一册 资格文件 | 资格审查（符合性检查） | **直接否决**，通常不给补正机会 |
| 第二册 商务文件 | 商务评审 / 报价评审 | 影响商务得分，严重时按无效投标处理 |
| 第三册 技术文件 | 技术评审 | 影响技术得分，负偏离未声明可能被认定虚假响应 |

把资格文件单独成册的实际价值：**资格项是"有无"问题，商务技术是"好坏"问题**。
分开装订能让评委快速完成符合性检查，也让投标人自查时不容易漏项。

> 部分项目采用"一册到底"或"正本/副本分装"，此时仍建议在册内按同样顺序编排，
> 自查逻辑不变。

## 二、四类项目的结构差异

### 货物类（`goods`）

评审重心在**技术参数逐条响应**与**供货进度**。

- 技术文件必须包含"技术参数逐条响应表"，逐条列明响应值，并明确标注优于 / 等于 / 低于
- 负偏离（低于要求）必须如实写明，隐瞒即构成虚假响应
- 分项报价明细表的**分项之和必须等于总价**，且与开标一览表一致

### 工程类（`works`）

评审重心在**施工组织设计的针对性**与**人员资格**。

- 拟派项目经理的建造师注册证书、安全考核合格证、社保缴纳证明三件套缺一不可
- 若招标文件要求"无在建项目"，须出具无在建承诺
- 施工组织设计**不能是通用模板** —— 评委能一眼看出，技术分会大幅扣减
- 工程量清单报价不得缺项漏项，缺项通常被认定未实质响应

### 服务类（`service`）

评审重心在**服务方案的针对性与可交付性**。

- 服务需求必须逐条响应，SLA（响应时限、到场时限）须与招标文件一致
- 服务方案要给出可考核的指标，而不是"我们保证优质服务"这类表述
- 项目团队人员的职称 / 执业资格与劳动关系证明须齐全

### 政府采购类（`gov-procurement`）

评审重心在**资格合规与预算约束**。

- **报价超过采购预算或最高限价 → 直接无效**，这是政府采购最常见的废标原因
- 需提供信用记录查询结果（信用中国 / 中国政府采购网），且查询日期须在采购文件要求的期限内
- 涉及中小企业的，中小企业声明函填写必须与事实一致
- 资格声明须按采购文件**给定格式**出具，自行改格式常被认定为无效

## 三、条款类型与响应结论的判定口径

引擎把条款归为五类（`reject` / `qualification` / `commercial` / `technical` / `other`），
归类依据是 `bid-lexicon.js` 里的 `CLAUSE_TYPE_KEYWORDS` 关键词表 —— **可逐条核对**。

响应结论只有三种：

| 结论 | 含义 | 你要做什么 |
|---|---|---|
| 响应 | 条款文本命中了你已提供的资质 / 业绩，或报价未超限额 | 在投标文件对应章节标注响应页码 |
| 需补充 | 条款要求提供材料，但没命中你提供的任何材料；或报价超限额 | **投标截止前必须补齐或调整**，否则有否决风险 |
| 待确认 | 条款未命中任何材料，且不属于明确的材料要求 | 人工确认该条款是否适用于本项目 |

### 匹配是怎么做的（可复核）

引擎用**最长公共子串**比对条款文本与你的资质/业绩条目，命中长度 ≥ 4 个汉字才算命中，
并把命中的那一段原文报出来。

为什么不用整串包含：你写"计算机信息系统集成资质二级"，招标文件写"须具备计算机信息系统集成资质"，
整串包含会**全部落空**，把每一行都判成"需补充"——那样这份表就没有任何信息量。
报出命中的公共片段，你才能一眼确认"它凭什么说这条响应了"。

### 超预算判定

当条款文本形如"不得超过 / 不得高于 / 不得超出 X 万元"，且你填了 `price` 时，
引擎会直接算出限额与报价的差额并给出结论。**超预算通常直接废标，值得单独判。**

## 四、本文件不覆盖的内容

- 具体项目的评标办法与分值构成（各项目差异极大，必须读招标文件）
- 地方性规定与行业特殊要求（如涉密项目、进口产品论证）
- 电子招投标平台的操作流程（各平台不同）

以上三项请以招标文件与招标代理的答复为准。
