## Description:

Build self-contained HTML slides with bilingual text, navigation, speaker notes, print styles and a Markdown outline. Use for HTML Slide Storyboard.

This skill is ready for commercial/non-commercial use.

## Publisher:

[hznetnewpower](https://clawhub.ai/user/hznetnewpower)

### License/Terms of Use:

MIT No Attribution

## Use Case:

External users can turn selected talking points or project material into self-contained HTML presentations and Markdown outlines, including bilingual slides and speaker notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated presentations, speaker notes, reports, and local state remain in the selected workspace until removed.

Mitigation: Use a selected workspace within the host sandbox and remove generated files and local state when they are no longer needed.

Risk: Browser or print layout may need review before a presentation is shared.

Mitigation: Review the generated HTML in a browser and check its print layout before sharing.
