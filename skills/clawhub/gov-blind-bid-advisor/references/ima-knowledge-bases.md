# IMA 知识库挂载（检索增强来源）

本技能在 WorkBuddy 中运行时，若宿主已连接 **IMA 知识库 MCP**（`mcp__ima-mcp__search_knowledge` 可用），
可挂载以下由用户（一线评标专家）发布 / 订阅的招投标·政府采购权威知识库，作为**检索增强（RAG）来源**，
使商机发现、投标决策、风险自查的结论"有据可循"，而非仅凭模型记忆。

## 使用方式（给技能运行时的指令）

- **工具**：`mcp__ima-mcp__search_knowledge`
- **参数**：`knowledge_base_id`（下表 ID）、`query`（中文自然语言，含关键术语）、`cursor`（分页，留空取首页）
- **行为**：
  1. 根据用户意图，从下表挑选 **1–3 个最相关** 的知识库检索；
  2. 读取返回结果中的 `highlight_title` / `highlight_content` / `knowledge.title` 作为依据；
  3. 在输出中**注明来源库名称与文档标题**（如「依据《招投标评标否决AI知识库》— 否决投标记录：…」）；
  4. 若 IMA 工具不可用或检索为空，明确说明"未启用知识库检索 / 未检到相关条目"，不伪称已检索。
