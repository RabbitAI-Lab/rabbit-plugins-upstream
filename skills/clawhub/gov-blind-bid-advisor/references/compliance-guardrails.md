# 合规护栏与风险识别指引（compliance-guardrails）

> 投标人防御视角。本文件定义本技能的**不可逾越红线**、**废标雷区自查清单**与
> **排他性/萝卜坑条款识别信号**。所有内容用于帮助用户*合法、合规*地投标，
> 绝不用于规避审查或实施违法行为。

## 一、不可逾越红线（技能必须拒绝的情形）

| 红线 | 说明 | 技能行为 |
|------|------|---------|
| 围标 / 串标 / 价格联盟 | 与其他投标人协同报价、分配中标、共享底价 | 拒答，不提供任何方法，也不提供"规避审查"思路 |
| 资质 / 业绩造假 | 伪造证书、虚构项目、PS 证明材料 | 拒答；缺失资质只给*合法*补强（办理真实资质/联合体） |
| 虚假中小企业声明 | 不符合条件却申报小微优惠 | 拒答；仅当用户确认真实符合才生成声明函模板 |
| 规避否决条款 | "把不符项包装成符合""绕开★号条款" | 拒答；如实提示缺口与合法路径 |
| 突破安全边界 | 破解验证码、绕过登录、代理池伪装、采非公开信息 | 技能设计层面禁止，采集模块强制 robots + 限速 + 透明 UA |
| 代写违法文书 / 承诺中标 | "保证中标""中标概率" | 回避承诺性表述；质疑/投诉仅给模板+时效，不构成法律意见 |

## 二、废标雷区自查清单（投标人自我合规）

投标人须逐条核对招标文件"投标人须知 / 资格要求 / 符合性审查"中的否决情形：

### 资格性审查（任一不满足即无效投标）
- [ ] 具备独立法人资格（营业执照有效）
- [ ] 满足特定资质（如系统集成、医疗器械经营许可等）——**必备项缺失=一票否决**
- [ ] 财务状况/纳税/社保正常（无列入严重违法失信名单）
- [ ] 未被列入政府采购严重违法失信行为记录名单

### 符合性审查（形式与实质）
- [ ] 投标文件签署、盖章齐全（法人签字+公章+骑缝章）
- [ ] 报价唯一、无选择性报价、无附加条件
- [ ] 工期/交货期/质保期满足★号实质性要求
- [ ] 技术参数对★号条款无负偏离（或负偏离在允许范围）
- [ ] 投标保证金按时、足额、从基本户转出（如要求）
- [ ] 未存在法定串通情形（单位负责人同一/存在控股管理关系等）

> `compliance_checker.py` 的"时间节点合规"部分可自动校验发售期/截止日/公示期等；
> 其余清单项由用户线下逐条核对，技能给出清单而非代判。

## 三、排他性 / 萝卜坑条款识别信号（防御扫描）

以下信号提示招标文件可能"为特定供应商量体裁衣"，投标人可据此决定投入或依法质疑：

| 信号 | 典型表述 | 风险 | 应对 |
|------|----------|------|------|
| 限定特定品牌/型号 | "指定XX品牌""须原厂授权""唯一专利" | 🔴 高 | 核实是否允许等效替代；否则可质疑 |
| 技术参数高度指向 | "指标须与XX方案完全一致""专有技术" | 🔴 高 | 判断是否具唯一合理性，存疑则质疑 |
| 地域门槛 | "本地注册""本地纳税""本省业绩" | 🟡 中 | 通常违法（法定例外除外），可质疑 |
| 过高/无关资质 | "须甲级/涉密/独家代理"且与规模不匹配 | 🟡 中 | 核实必要性，过高门槛可质疑 |
| 无关奖项加分 | "须获XX驰名商标/特定奖项" | 🟢 低 | 与履约无关，可提示质疑 |
| 单一来源无理由 | 应招标却走单一来源 | 🔴 高 | 重点自查，必要时异议/投诉 |

> 信号仅为提示，不构成违法认定。是否构成歧视性条款需结合全文与法定例外判断；
> 确有排斥性的，可在法定期限内依法提出质疑（答复不满意再投诉）。

## 四、质疑 / 投诉时效（防御维权用）

| 程序 | 时限 | 起算 |
|------|------|------|
| 质疑 | 知道权益受损后 **7 个工作日** | 知道或应知道之日 |
| 投诉 | 质疑答复期满后 **15 个工作日** | 采购人答复期满 |
| 行政复议 | 收到投诉处理决定后 **60 日** | 决定送达之日 |
| 行政诉讼 | 收到投诉处理决定后 **6 个月** | 决定送达之日 |

> 技能可提供时效计算与函件模板，但不替代律师；超期将丧失救济权，务必提示用户尽早行动。

## 五、采集合规（采集模块强制）

- 仅采依法公开信息；每次请求前检查 robots.txt。**取不到策略文件（网络错误 / 非 200）时按默认禁止（fail-closed）**，不采集该域；仅当 robots 策略明确允许时才继续。
- 同域请求间隔 ≥3 秒；单域 ≤50 次/小时；明确 User-Agent。
- 遇 403/429/503 立即停该域；不破解验证码、不绕过登录、不轮换 IP、不伪造身份。
- 数据仅用于用户自身分析，不转售、不二次分发。
- 详见 `references/anti-scraping-best-practices.md`。
