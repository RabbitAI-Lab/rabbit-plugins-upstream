# 认知卡 few-shot 示例

> 供录入助手参考的标准产出样例。均满足判定阈值(N≥3 且有核心卖点/关键事实)。

## 例1:皇氏水牛奶(保健营养/乳品)
```
商品名称：皇氏水牛奶
定位：高钙营养早餐奶
类目：乳品；牛奶
核心卖点：高钙高蛋白；营养早餐
关键事实：每100ml含钙约120mg(营养成分表)；生水牛乳为原料(配料表)
能力：营养早餐<-高钙高蛋白；便于准备
适用人群：儿童；成人
适用场景：早餐；加餐
功效：高钙；高蛋白
推荐关键词：牛奶；早餐；高钙
禁用表达：增强免疫；促进长高
允许表达：适合早餐与家庭日常
需求：早上没时间做早餐；想给孩子补钙
用户会问：有没有适合小孩喝的牛奶；高钙牛奶推荐
不适合：乳糖不耐受
差异化：水牛奶乳固体含量高于普通牛奶
契合理由：儿童<-高钙助力成长发育；早餐<-开盒即饮省时间
```

> 例1 含 v3 意图/推荐增强字段(需求/用户会问/不适合/差异化/契合理由);例2、例3 未加，仅示意这些字段为**选填**、老格式仍有效。

## 例2:土鸡蛋(食品生鲜)
```
商品名称：山林散养土鸡蛋
定位：家庭日常蛋类与早餐食材
类目：生鲜食品；蛋类
核心卖点：山林散养；营养早餐食材
关键事实：支持水煮、煎蛋、蒸蛋(商品说明)；五谷喂养[推断]
能力：快速准备早餐<-支持水煮煎蛋蒸蛋
适用人群：儿童；成人；中老年
适用场景：工作日早餐；家庭日常烹饪
推荐关键词：土鸡蛋；早餐；蛋
禁用表达：一定比普通鸡蛋营养更高；养生治病
允许表达：适合作为家庭日常蛋类选择；适合早餐和家庭烹饪
```

## 例3:5号电池(数码3C/日用)
```
商品名称：碱性5号电池
定位：日常小家电通用电池
类目：数码配件；电池
核心卖点：大容量耐用；即装即用
关键事实：LR6 碱性电池(标称)；单节1.5V(标称)
能力：驱动遥控器/玩具/鼠标<-LR6标准兼容
适用场景：遥控器；无线鼠标；儿童玩具
推荐关键词：5号电池；碱性电池；AA
禁用表达：续航当事实断言
允许表达：适合日常小电器使用
```

## 反例(不该这么写)
```
核心卖点：最好的牛奶；国家级品质          ← 违规:绝对化用语,应拒绝
关键事实：喝了增强免疫、能长高            ← 违规:超范围功效,应改写/进禁用表达
适用人群：上班族                        ← 不在受控集,应换"成人"或删
```
> 上面只有 2 个有效标签且卖点违规,**不满足 N≥3**,系统会降级 LLM 或跳过。
