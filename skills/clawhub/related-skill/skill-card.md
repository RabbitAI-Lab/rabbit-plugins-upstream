## Description: <br>
Discover and install related skills from the inference.sh skill registry to help expand an AI workflow with complementary capabilities. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[okaris](https://clawhub.ai/user/okaris) <br>

### License/Terms of Use: <br>


## Use Case: <br>
Developers and agent users use this skill to discover, install, update, and remove complementary inference.sh skills for media generation, research, automation, and workflow expansion. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can guide an agent to install, update, or remove other skills, changing the local skill environment. <br>
Mitigation: Approve only specific npx skills commands that were requested, and avoid broad updates or removals unless those changes are intended. <br>
Risk: Newly installed skills may introduce behavior or publishers the user has not reviewed. <br>
Mitigation: Review each target skill and publisher before installation. <br>
