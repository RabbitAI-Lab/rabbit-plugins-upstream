# 双平台申诉规则摘录与时限对照

> 以下为规则要点整理，用于快速判断。**具体条款以平台后台与官方规则中心为准**，规则会按季度调整。

## 一、时限总表

| 项目 | 抖店 | 微信小店 |
|---|---|---|
| 发起时限 | 收到单据后 **7 个自然日** | 异常评价投诉限 **180 天内**的用户评价 |
| 审核周期 | **1-5 个工作日** | **7 个工作日** |
| 补件窗口 | **72 小时**，超时未补视为申诉失败 | 平台要求补充时另行通知 |
| 申诉次数 | 异常评价仅 **1 次** | 按投诉类型分别计算 |
| 文字限制 | 描述 **≤100 字** | 按投诉类型要求 |
| 图片限制 | 最多 **6 张**，单张 ≤5MB | 按申诉类型要求举证 |

## 二、抖店

### 差行为处置异议申诉
- 入口：店铺 → 商家体验分 → 差行为扣分详情 → 违规单/判责明细
- 时限：收到单据后 7 个自然日内发起
- 审核：平台 1-5 个工作日给出结果
- 补件：申诉被退回时，补充材料时限为 72 小时，超时未补充则申诉失败

### 异常评价（差评）申诉
- 适用：评价本身涉嫌违规时
- 时限：仅支持发表时间不超过 **30 天** 的评价
- 次数：**只能申请一次**
- 内容限制：描述不超过 100 字，最多上传 6 张图，单张 ≤5MB
- 审核周期：3-7 个工作日（以后台实际提示为准）

### 评价可否删除
- 评价与追评**均不支持删除**
- 合规申诉是唯一合法途径
- 商家**不得付费删差评**，不得找第三方违规处理差评，恶意回复差评亦属违规

### 体验分口径
- 2025 版改为**商品体验 / 物流体验 / 服务体验**三维度加权
- 不再单列商品差评率作为考核项
- **"4.6 分"不是官方规则中的固定阈值**，商品是否被降权或清退由类目规则与清退规则单独判定

### 清退相关红线
- 品退差评显著高于同行
- 体验分不达标
- 状态异常、信息质量差、违规

## 三、微信小店

### 店铺体验分管理规则
- 修订 2025-05-29，生效 2025-06-24；2026-02-16 再次修订
- 5 分制，**最低 3 分**
- 分**服务体验 / 商品体验 / 物流体验**三维度
- 有效支付订单量 **≥10 单**才计分
- 近 30 天滚动统计，每日 12:00 更新
- 商家对商责判罚**申诉成功**的订单不计入商责纠纷单；异常售后整笔订单不计入

### 投诉与申诉
- 入口：店铺管理 → 投诉中心
- 类型：异常下单 / 异常售后 / **异常评价** / 异常带货者
- 异常评价投诉数据范围：限 **180 天内**的用户评价
- 平台 **7 个工作日**内审核完毕

### 评价规则
- 评价与追评**不可修改删除**

## 四、两平台差异要点（最容易踩的坑）

| 坑 | 说明 |
|---|---|
| 走错入口 | 微信小店四个投诉类型要分流，选错类型会白跑 |
| 字数超限 | 抖店 100 字硬限制，微信小店可放宽 → 抖店必须准备短版 |
| 图数超限 | 抖店 6 张上限，通用模板放 8 张图直接失败 |
| 补件超时 | 抖店 72 小时窗口容易被忽略，被退回后要立刻补 |
| 重复提交 | 微信小店审核期 7 个工作日，期间重复提交可能被视为干扰 |
| 申诉机会已用 | 抖店异常评价仅 1 次，提交前务必核对 |
| 评价过 30 天 | 抖店不再受理 |

## 五、给商家的话术（讲清规则，不制造恐慌）

```
判定结果：
· 可申诉 —— 剩余时间 X 天 X 小时，建议今天提交
· 时间紧 —— 剩余不足 24 小时，先提交现有材料，被退回再补
· 已超期 —— 该条评价无法申诉，建议把精力放在改进履约与后续同类差评的预防上
```
