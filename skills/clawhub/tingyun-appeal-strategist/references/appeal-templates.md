# 申诉单模板库（8 类场景）

> 使用说明：抖店异常评价申诉描述限 100 字、最多 6 张图 → 用【短版】。微信小店可适当放宽 → 用【完整版】。
> 所有模板中的 `{订单号}` `{差评原文}` `{日期}` 必须替换为真实信息。
> **不得承诺通过率**，不得写"必过""保证""100%"。

---

## 1. 卖家未开发票

**【短版 · ≤100字】**
```
订单{订单号}已于{日期}完成开票，发票信息已同步买家确认（见凭证{图号}）。
买家评价与事实不符，申请复核判责。
订单号：{订单号}，日期：{日期}
```

**【完整版】**
```
一、基本情况
订单号：{订单号}，下单时间：{日期}，交易已完成。
二、判责事项
平台就"卖家未开发票"作出判责。
三、事实与凭证
1. 该订单已于{日期}开具发票，发票记录见凭证{图号}；
2. 开票后已通过旺旺/飞鸽告知买家，见凭证{图号}；
3. 买家确认信息见凭证{图号}。
四、诉求
买家评价内容与上述事实不符，申请依据完整凭证复核本次判责。
订单号：{订单号}
```

**必备凭证**：发票记录截图、开票告知聊天、买家确认记录

---

## 2. 虚假交易刷评价

**【短版 · ≤100字】**
```
订单{订单号}为真实交易，物流已签收（凭证{图号}），买家已确认收货（凭证{图号}）。
订单时间线完整，无异常刷单特征，申请复核。
订单号：{订单号}
```

**【完整版】**
```
一、订单真实性
订单号：{订单号}，下单 {日期}，发货 {日期}，签收 {日期}，物流轨迹见凭证{图号}。
二、买家确认收货
买家确认收货时间与物流签收时间一致，见凭证{图号}。
三、无刷单特征
收货地址、联系方式、聊天记录相互印证，见凭证{图号}；本单与该买家历史交易连续，见凭证{图号}。
四、诉求
本单具备完整真实交易链路，申请复核"虚假交易"判责。
订单号：{订单号}
```

**必备凭证**：物流签收记录、确认收货截图、买家聊天、订单时间线、历史订单连续性

---

## 3. 异常售后地址

**【短版 · ≤100字】**
```
订单{订单号}的收件地址为买家下单时填写，与平台订单信息一致（凭证{图号}），
买家确认地址无误（凭证{图号}），不存在异常地址。申请复核。
订单号：{订单号}
```

**必备凭证**：订单地址截图（含时间戳）、买家确认记录

---

## 4. 无故拒绝售后

**【短版 · ≤100字】**
```
订单{订单号}售后已按平台规则处理，退款已于{日期}到账买家账户（凭证{图号}），
服务记录完整（凭证{图号}），不存在拒绝售后。申请复核。
订单号：{订单号}
```

**必备凭证**：售后处理记录、退款到账截图、客服工单、沟通记录

---

## 5. 恶意差评

**【短版 · ≤100字】**
```
订单{订单号}履约完整，评价内容与事实不符。订单、聊天、发货记录一致（凭证{图号}），
双方沟通记录见凭证{图号}。申请复核。
订单号：{订单号}
```

**必备凭证**：完整聊天记录、订单履约记录、发货实物图、既往好评

**注意**：恶意差评类举证要谨慎。只陈述事实与凭证，不评价买家动机，"恶意"二字非必要不写。

---

## 6. 平台活动导致差评

**【短版 · ≤100字】**
```
订单{订单号}差评源于平台{活动名称}活动规则（规则见凭证{图号}），
买家参与记录见凭证{图号}，非服务质量问题。申请复核。
订单号：{订单号}
```

**必备凭证**：活动规则页截图（带活动标识）、买家活动参与记录

---

## 7. 商品描述不符

**【短版 · ≤100字】**
```
订单{订单号}所购商品规格与详情页描述一致（详情存档见凭证{图号}，
发货实物见凭证{图号}，规格表见凭证{图号}），不存在描述不符。申请复核。
订单号：{订单号}
```

**必备凭证**：详情页存档、发货实物图、规格表、买家选规格记录

---

## 8. 服务态度类差评

**【短版 · ≤100字】**
```
订单{订单号}服务过程有完整记录（工单见凭证{图号}，会话见凭证{图号}），
客服按平台规范处理（质检记录见凭证{图号}），请依据记录复核。
订单号：{订单号}
```

**必备凭证**：客服工单、飞鸽会话、质检记录

---

## 通用写作红线（8 类模板都适用）

| 不要写 | 为什么 | 改成 |
|---|---|---|
| 请平台主持公道 | 无信息量 | 直接写事实与订单号 |
| 必过 / 保证通过 / 100% | 无法承诺，且可能构成虚假承诺 | 只陈述事实与诉求 |
| 该买家是恶意差评 | 主观定性，容易被驳回 | 只陈述履约完整、评价与事实不符 |
| 4.6 分以下会被下架 | 官方规则中查不到此固定阈值 | 引用官方规则原文与具体判责条款 |
| 我是新商家求照顾 | 与判责无关 | 删除 |
| 附带无关截图 | 图数有限，浪费额度 | 只留与判责直接相关的凭证 |
