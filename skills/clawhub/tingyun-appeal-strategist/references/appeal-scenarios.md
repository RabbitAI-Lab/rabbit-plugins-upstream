# 举证清单速查（单页版 · 可打印）

> 用法：判责类型 → 找到对应行 → 逐条打勾 → 全勾再提交
> 截图统一要求：**完整、不裁边、带时间戳、带订单号**

## A. 通用四件套（每单先备齐）

- [ ] 订单详情页截图（含订单号、下单时间、金额、状态）
- [ ] 完整聊天记录截图（从头到尾，不跳段、不裁切）
- [ ] 物流/发货记录截图（发货时间、签收时间）
- [ ] 买家确认收货或确认沟通的截图

## B. 按判责类型补充

| 判责类型 | 需额外准备 |
|---|---|
| 卖家未开发票 | 发票记录 / 开票截图 / 开票后告知买家的聊天 |
| 虚假交易刷评价 | 订单时间线 / 历史交易连续性 / 买家收货地址与联系方式印证 |
| 异常售后地址 | 订单地址截图 / 买家确认地址无误的记录 |
| 无故拒绝售后 | 售后处理记录 / 退款到账截图 / 客服工单号 |
| 恶意差评（评价与事实不符） | 发货实物图 / 规格表 / 买家选规格记录 / 既往正常评价 |
| 平台活动导致差评 | 活动规则页截图（带活动标识）/ 买家参与记录 |
| 商品描述不符 | 详情页存档 / 发货实物图 / 规格参数表 |
| 服务态度类 | 客服工单 / 飞鸽会话 / 质检或服务记录 |

## C. 提交前 30 秒自检

- [ ] 还在时限内？（抖店发起 7 日 / 微信小店异常评价 180 日内）
- [ ] 申诉机会还没用过？（抖店异常评价仅 1 次）
- [ ] 字数符合规格？（抖店 ≤100 字）
- [ ] 图数符合规格？（抖店 ≤6 张，单张 ≤5MB）
- [ ] 每张图都有订单号或时间戳？
- [ ] 有没有一句话带着"必过/保证/100%"？（有就删）
- [ ] 有没有写"4.6 分"？（有就删，改引官方原文）
- [ ] 文案是自己逐句核对过的？（不是 AI 生成后直接提交）

## D. 提交后

- [ ] 抖店：72 小时内盯着是否被退回补件
- [ ] 微信小店：7 个工作日等待，期间不重复提交
- [ ] 被驳回：对照 6 条驳回原因表定位问题，修正后重新提交（次数有限，先改对再交）

## E. 三个不要

1. 不要碰"删评"——评价与追评平台均不支持删除，合规申诉是唯一合法途径
2. 不要找第三方违规处理差评——抖店明确禁止，属违规行为
3. 不要在旺旺里给多个人批量发同一段申诉话术——批量发送同类信息是平台风控信号
