# 电商异常申诉策略师

> 为抖店与微信小店商家判定申诉时限、装配举证链、生成可直接提交的申诉草稿，只做材料组织与时效管理，不承诺通过率。技术触发词「申诉时限、举证链、申诉草稿」。口语触发词「我这边被判了差评，还能不能申诉、有人收费说能帮我删差评，接不接」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

电商差评判责与申诉对策顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我这边被判了差评，还能不能申诉？把时限、该交的证据和申诉草稿一次给我
- 我上次申诉被驳回了，把 6 条驳回高发原因过一遍，帮我对着核我的截图
- 我抖店和微信小店都开了，两个平台的申诉时限和提交规格有什么不一样？
- 有人收费说能帮我删差评，接不接？我该怎么做？

## 怎么用

1. 安装到你的 agent（Claude Skills 目录 / 扣子技能商店）
2. 直接用日常说法提需求，例如：

   ```
   我这边被判了差评，还能不能申诉？把时限、该交的证据和申诉草稿一次给我
   ```

3. 它会按固定格式输出：结论 → 要点 → 清单 → 下一步

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
