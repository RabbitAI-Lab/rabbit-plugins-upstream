## Description:

Guides the creation of Amazon product listing images and A+ content modules with dLazy image generation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Sellers and creative teams use this skill to plan and generate Amazon listing main images, secondary product visuals, and A+ page modules.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Using the skill requires a dLazy API key and sends prompts and referenced product media to dLazy's cloud service.

Mitigation: Review the service's terms and data handling before sharing sensitive product material; protect the API key.

Risk: The artifact contains inconsistent CLI version references.

Mitigation: Confirm the intended CLI version before installing or running it.

Risk: Generated product imagery or text may misrepresent the product or fail marketplace requirements.

Mitigation: Review images and claims against the actual product and applicable listing requirements before publishing.
