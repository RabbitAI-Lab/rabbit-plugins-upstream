## Description:

Query Khánh Hòa Provincial Library SRU catalog via CQL and output structured JSON records.

This skill is ready for commercial/non-commercial use.

## Publisher:

[baolinhtv](https://clawhub.ai/user/baolinhtv)

### License/Terms of Use:

MIT-0

## Use Case:

Library patrons, researchers, and developers use this skill to search Khánh Hòa Provincial Library holdings by keyword, title, or author and retrieve structured catalog records.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Search terms are sent to the Khánh Hòa Provincial Library SRU service.

Mitigation: Avoid entering sensitive or confidential terms in catalog searches.
