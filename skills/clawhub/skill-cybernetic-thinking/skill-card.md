## Description:

Cybernetic Thinking helps AI coding agents reason about architecture, debugging, refactoring, and robust code changes through a control-theory and systems-theory workflow.

This skill is ready for commercial/non-commercial use.

## Publisher:

[shrimpleon](https://clawhub.ai/user/shrimpleon)

### License/Terms of Use:

MIT

## Use Case:

Developers and engineers use this skill to guide AI coding agents through complex software work where correctness, observability, stability, bounds, and convergence matter. It is most relevant for architecture design, non-deterministic debugging, legacy-code changes, and cross-module refactoring.

### Deployment Geography for Use:

Global
