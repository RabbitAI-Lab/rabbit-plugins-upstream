# 极鲸云 AliExpress 店铺研究 Skill

按站点和店铺 ID 查询 AliExpress 店铺详情，并结合店铺商品样本分析销量、销售额、粉丝、商品规模和类目。

当前不支持按店铺名称搜索，也不提供订单、广告、佣金、履约指标或卖家中心操作。

## 安装 / 更新

```text
安装这个Skill: https://github.com/geekbi/geekbi-aliexpress-shop-search-skill
```

分析这个 AliExpress 美国站店铺的销售表现和商品结构。
