## Known Risks and Mitigations:

Risk: The skill requests command and file authority even though its normal creative-planning use is text generation.

Mitigation: Install with text-generation-only permissions where possible; avoid command execution, broad file write access, and external API access unless the publisher narrows and explains those capabilities.

Risk: Creative direction can be generic, misaligned, or impractical when the brief lacks brand, audience, budget, or execution constraints.

Mitigation: Provide concrete brief details and have the creative or brand team review outputs before using them for campaign or visual direction decisions.
