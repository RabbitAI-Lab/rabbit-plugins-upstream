# gzh-comment-export · 公众号留言/评论导出

把自己公众号后台收到的读者留言（评论）**批量导出成本地 Markdown**，按文章分组，方便留言归档、精选整理、读者反馈分析。

一句话：以前得在后台一篇文章一篇文章点开、一条条复制留言，现在 AI 批量干完——不用装插件、不用填 token/cookie、全程只读。

## 能干什么

- 打开公众号后台「互动管理 → 留言」（官方留言管理页），按文章分组全量读取
- 每条留言带作者昵称、内容、留言时间、地区
- 文章列表自动翻页到底，0 条留言的文章也照常记录
- **全程只读**：屏蔽/删除/置顶/回复等管理按钮一律不碰
- **纯本地运行**：留言只落到你自己电脑上，不上传任何内容

## 前提（必须装）

- **必须装 webclaw3**：本 skill 靠 webclaw3 打开你已登录的公众号后台，不装跑不了。
  - 装好后先检查一遍通道：`node <webclaw3安装路径>/scripts/webclaw3.mjs doctor`
  - 路径一般在 `~/.claude/skills/webclaw3` 或 `~/.workbuddy/skills/webclaw3`
- 浏览器里先登录好公众号后台（`mp.weixin.qq.com`）——登录的是哪个号，就导出哪个号的留言。

## 怎么用

```bash
node skill.mjs <input.json>
```

`input.json` 只有一个参数：

| 参数 | 说明 | 默认 |
|---|---|---|
| `output_dir` | 导出目录（自动创建） | 当前目录下 `gzh-comment-export/` |

```json
{ "output_dir": "/abs/path/to/out" }
```

## 输出

- `comments.md`：按文章分组的留言明细（标题 + 发表时间 + 留言表格：作者/内容/时间/地区）
- `index.json`：统计（账号、文章总数、留言总数、每篇留言数、partial 状态）

## 边界

- 只导出**自己公众号**（后台当前登录的号）的留言，不抓别人公众号文章的评论
- 只读不写：不做精选、回复、删除等任何后台操作
