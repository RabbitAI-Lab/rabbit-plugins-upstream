## Description:

Researches public LinkedIn company, product, and showcase pages by ID and discovers public products by keyword or category through Crawlora.

This skill is ready for commercial/non-commercial use.

## Publisher:

[crawlora-org](https://clawhub.ai/user/crawlora-org)

### License/Terms of Use:

MIT-0

## Use Case:

Researchers, sales teams, and developers use this skill to profile public LinkedIn company, product, and showcase pages or discover products for competitive research and company enrichment.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: API requests send the Crawlora API key and requested public LinkedIn IDs or searches to Crawlora.

Mitigation: Use only if this data sharing is acceptable; keep CRAWLORA_API_KEY out of source control.

Risk: Public LinkedIn data use may be subject to provider terms, and successful API requests can consume credits.

Mitigation: Review Crawlora and LinkedIn terms before use and request only the data needed.
