# 五类客户交付型咨询报告排版规范要点

> **word-formatter v1.0.0「黑灰白」** — 2026-07-29 build
> 上次完整校验：5/5 通过，26 项自动检查 + 11 项人工复核

本文件是 word-formatter 技能的详细规范参考。脚本自动处理"版式层"要求（页面、字体、颜色、表格、页眉页脚、图件）；"结构层"与"签署层"要求依赖人工复核（已列入各配置的 manual_checks）。

**统一设计语言（五类完全一致）**：仅黑/白/灰三色，不使用任何彩色（深蓝、深红等均禁用）；强调一律用加粗或灰度层次表达。宋体正文、黑体分级标题、三线表（无竖线/无填色/无斑马纹）、统一页眉（报告标题）+ 页脚页码（第 N 页 共 M 页）。

## 一、财务尽职调查报告（`dd_report_financial.json`）

规范依据：证监会《保荐人尽职调查工作准则》(2022)「财务会计调查」章节 + 江苏省注协「详式财务尽调框架」。

- 骨架：封面/声明/摘要 → 一、公司基本情况 → 二、业务与技术 → 三、财务会计（会计政策/比率/损益/资产/现金流/纳税）→ 四、同业竞争与关联交易 → 五、公司治理与独立性 → 六、重大风险揭示 → 七、结论与建议。
- 常见图件：财务尽调程序框架（流程图）。
- 特色表格："风险点—证据—结论"三栏表、股权结构表。

## 二、法律/综合尽职调查报告（`dd_report_legal.json`）

规范依据：证监会尽调准则法律合规章节 + 《律师事务所从事证券法律业务管理办法》。

- 骨架：主体资格与历史沿革 → 股东与股权结构（**含股权架构图**）→ 业务与资质 → 重大资产与知识产权 → 重大合同与债权债务 → 劳动人事与社保 → 税务与财务合规 → 诉讼仲裁与行政处罚 → 法律意见与整改建议。
- 常见图件：股权架构图（层级树）。

## 三、综合风险评估报告（`risk_assessment.json`）

规范依据：COSO ERM(2017) 五要素 + 《企业内部控制基本规范》(五部委2008)。

- 骨架：评估范围与依据 → 评估说明 → 一、风险治理与环境 → 二、风险识别 → 三、风险评估（**可能性×影响 风险矩阵**）→ 四、关键风险排序 → 五、风险应对 → 六、剩余风险与监控 → 七、结论与建议。
- 常见图件：风险评估流程(COSO) 流程图、风险矩阵表。风险矩阵以三线表二维呈现，**严禁彩色色块**，高/中/低仅用深灰/中灰/浅灰（黑灰层次）标识。

## 四、财税风险评估报告（`risk_assessment_tax.json`）

规范依据：税务风险管理指引 + 财税合规体检逻辑（增值税/企业所得税/个税/发票/社保/税收优惠）。

- 骨架沿"税种风险识别 → 财税风险评估（矩阵）→ 重大风险分析 → 风险应对与整改 → 剩余风险监控"展开。
- 常见图件：财税风险评估流程、税种风险矩阵表（同样灰阶，无彩色）。

## 五、财务分析报告（`financial_analysis.json`）

规范依据：财政部《管理会计应用指引第801号——企业管理会计报告》+ 通用分析框架。

- 骨架：封面 → 摘要与重要提示 → 一、财务概况 → 二、财务指标分析（偿债/营运/盈利/成长四类，三线表）→ 三、趋势分析（3–5 年）→ 四、结构分析 → 五、行业对标 → 六、问题诊断（差异—原因—影响）→ 七、建议与展望。
- 常见图件：财务分析框架流程图；趋势图、结构图优先以三线表 + 文字呈现，更利于审计追溯。指标按四类三线表列示并标注行业参考值。

> **图件约定**：流程图/股权架构图/风险矩阵用 structured 引擎离线渲染（黑体中文标签、浅灰节点 `#F2F2F2`、深灰边框 `#404040`，符合极度克制的黑/白/灰配色，无任何彩色）；优先以三线表 + 文字呈现数据类图件，利于审计追溯。各配置 `common_diagrams` 字段列明了该类常用图件。

## 统一页眉页脚标准（五类一致）

- 页眉：报告标题（宋体 9pt、灰色 `#595959`、居中）+ 下方细线分隔；无机构 Logo 占位（如需由客户 VI 定制）。
- 页脚：页码"第 N 页 共 M 页"（宋体 9pt、灰色、居中），由 Word 页码域自动生成。
- 校验脚本 `validate_docx.py` 的 `check_header_footer` 会确认页眉文字与页码域均存在。

## 通用基础标准（所有类别适用）

| 标准 | 用途 |
|---|---|
| GB/T 9704-2012《党政机关公文格式》 | 中文正式文书版心、字号、行距的事实基准 |
| GB/T 7714-2015《信息与文献 参考文献著录规则》 | 引用与参考文献格式 |
| GB/T 15835-2011《出版物上数字用法》 | 数字、日期、百分比写法 |
| GB/T 15834-2011《标点符号用法》 | 中英文标点混排 |
| GB 3100~3102《量和单位》 | 计量单位与财务数据单位 |

## 常见陷阱（脚本相关）

- 中文字体必须写入 `w:rFonts/@w:eastAsia`，仅设置 `font.name` 中文不生效。
- "仿宋_GB2312 / 楷体_GB2312" 在部分机器缺失，可替换为 "仿宋 / 楷体"（配置中改 font_cn 即可）。
- 目录页码是域（TOC field），python-docx 不能刷新；交付前在 Word 中 Ctrl+A → F9。
- 行距"固定值 28 磅"用 exact 规则；"1.5 倍"用 multiple 规则，两者在配置中通过 line_spacing_rule 区分。
- 任何直接格式（direct formatting）里的 stray 彩色都会被 `enforce_color=true` 强制覆盖为黑/深灰，确保全篇只有黑/白/灰。
