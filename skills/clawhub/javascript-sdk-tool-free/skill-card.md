## Known Risks and Mitigations: <br>
Risk: File-upload examples could lead users to send sensitive files to an AI service without reviewing privacy or retention terms. <br>
Mitigation: Confirm each selected file is intended for the AI service before upload and review the provider's privacy and retention terms for sensitive data. <br>
Risk: API keys could be exposed if hard-coded or used directly in browser code. <br>
Mitigation: Store API keys in environment variables for server-side code and use a proxy pattern for browser applications. <br>
