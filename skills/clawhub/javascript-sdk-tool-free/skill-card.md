## Known Risks and Mitigations:

Risk: File upload examples can send local files to an external service and may mark uploads public.

Mitigation: Confirm the exact local file before upload, avoid secrets or private project files, and use public sharing only when intended.

Risk: API keys can be exposed if copied into source code or used directly in browser clients.

Mitigation: Store API keys in environment variables for server-side use and use a proxy pattern for browser applications.
