# 自定义质检规则编写指南

在技能目录（或与会话数据一起上传）放置 `rules-custom.md`，即可覆盖默认规则。写法要求：

## 基本结构

沿用 rules-default.md 的结构：按维度分节，每个维度写清「判定条件 → 扣分值 → 上限」。判定条件尽量写成可核对的表述（关键词清单、时间阈值、行为描述），避免只写"态度要好"这类无法执行的要求。

## 可以自定义的内容

1. **调整阈值**：如把首响超时从 3 分钟改成 1 分钟（电商大促场景）。
2. **增删禁语**：加入你公司的禁语清单；行业敏感词（如医疗器械不得承诺疗效、金融不得承诺收益）。
3. **新增维度**：如"营销合规"（是否按规范推荐会员/加购）、"信息安全"（是否引导客户离开平台交易——很多平台明令禁止）。
4. **行业化判定**：
   - 奢侈品/珠宝：产品推荐是否得体、线下门店引流话术是否合规
   - 家用电器：故障排查步骤是否标准、是否规范创建上门维修工单
   - 软件售后（群聊场景）：技术答复是否准确、承诺事项是否闭环跟进
5. **权重与总分**：可改各维度上限，总分仍建议保持 100 便于横向比较。

## 示例片段

```markdown
## 营销合规（上限 -10）
- 客户咨询 A 商品时坐席推荐无关高价商品且客户明确拒绝后仍继续推销 — 每次 -5
- 引导客户添加微信/线下交易 — -10（平台红线）
```

## 建议

- 每个判定条件问自己：质检员拿着这句话能否对一条会话做出一致判断？不能则细化。
- 语义类条件（态度、专业度）建议标注"倾向待复核"，让技能把拿不准的交给人判断。
- 规则改动后先用小批量数据试跑一次，确认没有大面积误判再全量使用。
