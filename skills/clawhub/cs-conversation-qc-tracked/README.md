# 客服会话质检 (cs-conversation-qc)

批量分析客服会话导出文件，按可配置规则逐条评分，输出**带扣分证据的质检报告 + 待人工复核清单**。让主管从每周逐条翻聊天记录的抽检苦活中解放出来，把时间花在复核和辅导上。

## 它能做什么

- 输入：客服系统导出的会话记录（CSV/Excel/文本均可，自动识别列结构）
- 输出：三部分质检报告——质检明细（每会话总分）、扣分证据（每笔扣分附脱敏原句和时间点）、待人工复核清单（AI 拿不准的交给人判断）
- 五个默认质检维度：响应及时性、服务禁语、情绪安抚、流程合规、专业性

已在以下系统的导出格式上验证列识别：企业微信、千牛、美洽（其他系统的导出通常也能自动识别，识别不了会向你确认列含义）。

## 快速体验（1 分钟）

没有现成数据？直接对 Agent 说：

> 用 examples 里的示例数据跑一次质检给我看看

即可看到完整报告效果（示例输出见 `examples/sample-report.md`）。

## 使用自己的数据

1. 从客服系统后台导出会话记录（各系统一般在「聊天记录/会话管理 → 导出」）。
2. 把文件交给 Agent，说"帮我质检这批客服会话"。
3. 收到报告后重点看 Sheet3 待复核清单——这些是需要人工判断的条目。

## 自定义质检规则

默认规则见 `references/rules-default.md`。要按你公司的 SOP 定制（改超时阈值、加禁语清单、加行业维度如奢侈品导购合规/家电报修流程），参考 `references/rules-guide.md`，放一个 `rules-custom.md` 即可覆盖。

## 数据与隐私

- 数据全程在你的本地 Agent 环境处理，本技能不上传任何数据。
- 报告中的手机号、身份证、地址等个人信息自动脱敏。
- 质检结果供人工复核参考，不建议未经复核直接用于坐席考核。
