# 种子影库（影愈）

按 22 类困扰组织推荐片目。每部标注：`《片名》（年份）｜型别｜适配强度｜治愈点`。

- **型别**：方法（看完有可借鉴的做法/态度）、信息（帮助理解/看见自己/他人）、希望（共鸣/陪伴/力量）
- **强度**：轻 / 中 / 重（指适合的困扰强度段；「轻-重」表示全段适用）

命中困扰后，优先从对应分组选片；若候选不足 3 部，可结合「通用希望区」补充。所有片目均为真实作品；实时扩展时须核验片名与年份。
