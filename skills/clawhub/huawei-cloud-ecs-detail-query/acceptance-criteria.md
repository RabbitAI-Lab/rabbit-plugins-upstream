# 验收标准

## 功能验收

- [ ] `list` 子命令能成功列出 ECS 实例，输出包含名称、状态、规格、IP、实例 ID
- [ ] `show` 子命令能成功查询单个 ECS 实例详情，输出包含实例名称、ID、状态、规格、vCPU、内存、创建时间、可用区、网络信息、云硬盘
- [ ] `capability-list` 子命令能正确列出所有能力
- [ ] 支持 `--region` 参数指定区域
- [ ] 支持 `--limit`、`--offset`、`--name`、`--ip` 等筛选参数

## 错误处理验收

- [ ] AK/SK 未配置时退出码 3 并给出明确提示
- [ ] 实例不存在时退出码 4 并给出明确提示
- [ ] limit 超出范围时退出码 5 并给出明确提示
- [ ] CLI 执行失败时退出码 6 并给出错误详情
- [ ] 无效 server_id 格式时退出码 7 并给出明确提示

## 安全验收

- [ ] 无硬编码 AK/SK（从环境变量读取）
- [ ] 所有 API 调用有 30s 超时
- [ ] 纯只读操作，不涉及任何写操作
