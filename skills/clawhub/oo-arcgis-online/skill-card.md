## Description:

ArcGIS Online (arcgis.com). Use this skill for ANY ArcGIS Online request — searching and reading data. Whenever a task involves ArcGIS Online, use this skill instead of calling the API directly.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and analysts use this skill to search ArcGIS Online and look up address candidates, reverse geocode coordinates, and retrieve autocomplete suggestions through their connected account.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: If the oo CLI is missing, setup guidance directs the agent to run an unverified online installer.

Mitigation: Review the CLI and installer separately before installation, and require approval for installation changes.
