## Description:

Reviews resumes locally, identifies supporting evidence and job description keyword gaps, asks for missing facts, suggests factual edits, and exports confirmed content to DOCX, HTML, or PDF.

This skill is ready for commercial/non-commercial use.

## Publisher:

[yottameta](https://clawhub.ai/user/yottameta)

### License/Terms of Use:

MIT-0

## Use Case:

Job seekers use the skill to review resume structure and supporting evidence, compare a resume with a target job description, prepare follow-up questions, and export a confirmed resume.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installation examples use an unpinned npm package with automatic confirmation, and security coverage is partial.

Mitigation: Review the installation command, pin an explicitly reviewed package version, and verify its source and integrity before installing.
