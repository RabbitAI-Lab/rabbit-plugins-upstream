## Description:

Analyzes resumes locally, identifies experience evidence and job description gaps, supports evidence-based mock interviews, and exports confirmed content to DOCX, HTML, or PDF.

This skill is ready for commercial/non-commercial use.

## Publisher:

[yottameta](https://clawhub.ai/user/yottameta)

### License/Terms of Use:

MIT

## Use Case:

Job seekers use this skill to review resume structure and evidence, compare a resume with a target job description, prepare for a focused mock interview, and export a fact-checked resume in common document formats.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The documented npm install command does not pin a version, so a later package release may differ from the version reviewed.

Mitigation: Pin the package version when installing and review the selected release before use.
