## Description: <br>
Design data models for construction projects. Create entity-relationship diagrams, define schemas, and generate database structures. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[datadrivenconstruction](https://clawhub.ai/user/datadrivenconstruction) <br>

### License/Terms of Use: <br>
MIT <br>


## Use Case: <br>
Developers, data engineers, and construction analytics teams use this skill to model construction project entities, relationships, schemas, and validation checks. It helps produce SQL DDL, JSON Schema, Mermaid ER diagrams, structured tables, and export-ready guidance from user-provided project data. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may need filesystem access for user-selected project files or export locations. <br>
Mitigation: Install and run it only where access to those project files and export paths is acceptable. <br>
Risk: Generated SQL DDL or identifiers may be incorrect or unsafe if based on untrusted names or unvalidated user input. <br>
Mitigation: Review and validate generated schemas, table names, fields, relationships, and constraints before applying DDL to a real database. <br>
