## Use Case:

Content creators and marketing teams use this skill to build and refine advertising media across linked workflows, such as creating product videos, adapting reference videos, and producing supporting images or voiceovers.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Uploaded media is exposed through publicly accessible URLs, and retention and link expiry are unspecified.

Mitigation: Upload only media authorized for processing, avoid sensitive material, and confirm link access and retention before sharing assets.

Risk: Digital-human and voice features may use a person's likeness or voice.

Mitigation: Obtain permission before using anyone's likeness or voice.

Risk: API credentials, endpoint changes, and generation charges can affect account security and costs.

Mitigation: Keep the API key private, retain the default endpoint unless a replacement is trusted, and agree on credit spending before generation.
