## Known Risks and Mitigations:

Risk: Identity cloning can create a person-like spokesperson from photos, voices, or video.

Mitigation: Use only media and likenesses the user owns or is authorized to modify, and avoid creating personas without clear consent.

Risk: Uploaded assets may become accessible through public URLs.

Mitigation: Send only media suitable for public URL handling and delete custom personas or uploaded assets when they are no longer needed.

Risk: Watermark or object removal can be used on media the user does not have rights to alter.

Mitigation: Apply removal and enhancement features only to content the user owns or has permission to edit.
