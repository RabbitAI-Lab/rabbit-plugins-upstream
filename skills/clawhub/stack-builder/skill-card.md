## Description: <br>
Design, audit, and evolve a personalized AI skill stack for a user by observing available context, interviewing for gaps, recruiting existing skills, and generating installable role-specific SKILL.md files. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[jjliu6](https://clawhub.ai/user/jjliu6) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Individuals, developers, consultants, creators, and other knowledge workers use this skill to design a personalized agent-role stack around their observed strengths, workflow gaps, existing skills, and success criteria. It produces a blueprint and, after confirmation, auditable prompt-only SKILL.md files for new roles. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill works best when it can inspect relevant project and conversation context, which may include sensitive user work patterns or artifacts. <br>
Mitigation: Use it only when comfortable with read-only context review in the active environment, and limit available context to what is relevant for stack design. <br>
Risk: Generated skills may encode incorrect, over-personalized, or misleading workflow guidance if the observed context is incomplete. <br>
Mitigation: Review the blueprint and generated SKILL.md files before install or versioning, and require explicit user confirmation before any installation, publishing, or external action. <br>
