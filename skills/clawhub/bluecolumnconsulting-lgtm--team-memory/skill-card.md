## Description: <br>
Team Memory helps an agent store and recall team roles, strengths, working agreements, and routing context through BlueColumn, requiring a BlueColumn API key. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[bluecolumnconsulting-lgtm](https://clawhub.ai/user/bluecolumnconsulting-lgtm) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Employees and team-support agents use this skill to map team roles, communication preferences, workload signals, and working agreements so requests can be routed to the right owner and onboarding context can be replayed. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Team-member profile details, workload signals, and working preferences may be sensitive. <br>
Mitigation: Confirm organizational approval before use, minimize stored descriptions, and avoid private HR, performance, health, or confidential workload details unless authorized. <br>
