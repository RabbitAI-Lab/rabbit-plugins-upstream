## Description:

Find the connected site's striking-distance queries (page-2 rankings, positions 11-20, where one edit reaches page 1) from real Search Console data, quantify the click upside, and stage the specific fixes for approval. Use when the user wants quick SEO wins, more traffic without new content, or asks what to optimize first. Runs on SEOmatic, the SEO agent that works from the site's real Google Search Console data; nothing goes live until the user approves it.

This skill is ready for commercial/non-commercial use.
