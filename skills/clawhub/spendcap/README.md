# SpendCap 1.0.0

SpendCap is the separate Receipt skill for setting daily and maximum-per-purchase limits on a
connected app. Current enforcement covers purchases made through Receipt.

```bash
openclaw skills install @receiptprotocol/spendcap
```

The source candidate is private and must not be published until release approval. It reuses the
canonical Receipt connection and its exact eight universal tools. Setup never makes a purchase.
