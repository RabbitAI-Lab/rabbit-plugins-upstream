# 聊天分析框架

## 一、基础数据提取

用 `wechat-cli export` 导出后，提取以下数据：

### 消息计数
- 统计总消息数（不含系统消息）
- 分别统计 A（用户）、B（对方）的消息数量
- 计算比例（正常 40%-60%，差距过大说明一方主动）

### 时间维度
- 首条消息时间 → 判断认识时长
- 最后消息时间 → 判断关系活跃度（24h内/3天内/7天+/已读不回）
- 消息时间分布 → 判断聊天节奏（白天/深夜/工作日/周末）
- 平均每天消息数 → 判断亲密度

### 消息类型
- 纯文字 vs 图片/表情 vs 语音 vs 红包/转账 → 投入程度指标

## 二、人格画像维度

### 主动性（谁先发起聊天）
- **高主动型**：经常主动发起话题、找对方
- **被动回应型**：主要在对方找时才回复
- **平衡型**：双方都有主动

### 话题深度
- **浅层交流**：只聊日常（吃了吗、在干嘛）
- **中层交流**：分享感受、观点、经历
- **深层交流**：谈价值观、未来规划、情感话题

### 情感表达方式
- **直接表达**："想你""喜欢你""想见你"
- **间接表达**：通过关心、问候暗示
- **隐晦表达**：用玩笑、调侃掩饰真实情感
- **冷淡型**：很少主动表达情感

### 回应风格
- **秒回型**：经常立即回复，显示关注
- **延迟回应**：有时不回或很久才回
- **敷衍型**：回复简短（嗯/哦/好）
- **认真型**：回复有内容、有延伸

### 沟通习惯
- 爱用表情包？爱发长消息？爱问问题？爱开玩笑？
- 是否有固定的聊天仪式（比如睡前必道晚安）

## 三、关系阶段判定

| 阶段 | 特征 |
|------|------|
| 陌生 | 刚加好友，几乎没聊 |
| 认识 | 偶尔寒暄，话题限于日常 |
| 熟悉 | 有来有往，开始分享生活 |
| 暧昧 | 有情感暗示，互相关心，有调情 |
| 交往 | 明确关系称呼，深度话题频繁 |

## 四、问题诊断 Checklist

### 常见问题模式

**消息比例失衡**
- 一方 70%+ 消息 → 主动方可能用力过猛，被动方可能兴趣不足
- 对策：主动方适当降频，被动方主动找话题

**话题停留在表面**
- 永远在聊吃了吗、在干嘛、加班
- 对策：引入更私人的话题（过去的经历、对某事的看法）

**回应质量下降**
- 早期消息长而热情，后期越来越短
- 对策：换话题重新引起兴趣，或直接推进关系

**一方推进太快**
- 关系早期频繁表白/追问/要求见面
- 对策：放慢节奏，增加日常陪伴感

**一方推进太慢**
- 聊了很久（3个月+）但从不推进
- 对策：找时机明确表达意图

**晚安文化陷阱**
- 只有早安晚安，聊天浮于表面
- 对策：引入电话或线下见面

**读消息不回**
- 对方发消息后很久不回（>4小时）
- 对策：降低期待，或主动结束这种模式

## 五、亲密度指标

### 高亲密度信号
- 主动分享私人事（工作压力、家庭情况）
- 主动关心对方身体/情绪
- 有专属称呼/表情
- 愿意视频/语音聊天
- 主动约见面
- 聊到未来计划（假期、旅行）

### 低亲密度信号
- 消息频率低（<3条/天）
- 话题不深入
- 不主动关心
- 没有线下接触
- 称呼客气

## 七、实时模式分析（正在聊天时）

适用于用户正在微信上和某人实时聊天，切过来问"看看现在怎么样""下一步怎么回"。

### 分析维度

#### ① 会话节奏

| 指标 | 看什么 | 怎么判断 |
|------|--------|----------|
| **回复速度** | 两人每条消息间的间隔 | 秒回=高兴趣；5min+短回复=降温；忽快忽慢=心情波动 |
| **字数趋势** | 最近3轮消息字数的变化 | 越写越少=兴趣降；越写越多=热了；突然暴增=有故事 |
| **谁在驱动** | 最近3个话题是谁起的 | 全是你在起=单向；她会延伸/追问=双向 |
| **消息数比例** | 最近20条中双方占比 | 你70%+=用力过猛，对方可能敷衍 |

#### ② 情绪温度

**判定当前氛围：**
- 🔥 **热**：双方调侃/撒娇/吐槽/快速互回 → 适合推进
- 🌤 **温**：正常互动，有来有往 → 正常维持
- ❄️ **冷**：单字/单表情/拖延回复 → 该换话题或收手
- ⛔ **卡住**：同一话题来回绕无进展 → 需要破局

**信号检测：**

✅ 绿灯（可推进）：
- 她主动问关于你的事
- 用"表情包/图片+文字"多重回复
- 接你的梗/吐槽你/怼你
- 主动分享生活细节（照片、见闻、心情）
- 回复了你但话没说完，等她继续

🔴 红灯（该刹车）：
- 连续3轮以上单字/单表情
- 回避你明确推进的问题（约饭、见面）
- 已读但很久不回（>30min）
- 明显简化语气（"嗯""好"/"哦"替代之前的"好的呀""好嘞"）

🟡 黄灯（换策略）：
- 接但不过分热情
- 聊得下去但没火花
- 可能对方在忙/心情不好/没兴趣 -> 简短收尾比较体面

#### ③ 窗口判断

根据时间判断当前适合什么节奏：
- **深夜(22:00-2:00)**：情绪窗口，适合走心/暧昧/回忆话题，不适合闲聊
- **午休(12:00-14:00)**：适合轻松话题，可聊 5-10 轮
- **工作时间(9:00-18:00)**：简短一点，对方可能忙，表现活跃反而奇怪
- **周末/节假日**：适合约见面，适合聊未来安排

#### ④ 好停点识别

这轮结束了吗？
- 对方回了表情/单字 → 该停了，不要再追一句
- 对话自然停顿 >5min → 可以收尾
- 刚聊到一个高潮（互怼/互撩）→ **在这里停住**，留悬念
- 约饭/见面已确认 → 不要继续聊，直接结束

#### ⑤ 水温变化检测

对比**最近20条**和**这20条之前的20条**：
- 字数平均增加了？→ 升温
- 字数平均减少了？→ 降温
- 表情/图片变多了？→ 氛围变轻松
- 她开始跟你说负能量的事了？→ 信任增加
- 回复速度变慢了？→ 新鲜感在降

```

```

## 九、实时模式 vs 历史模式对比

| 维度 | 历史模式 | 实时模式 |
|------|----------|----------|
| 数据量 | 500条+（全量） | 30条（最近） |
| 分析重心 | 性格画像、关系阶段 | 会话节奏、温度信号 |
| 时间跨度 | 整个关系周期 | 最近几分钟到几小时 |
| 输出风格 | 长报告、系统性 | 短平快、可执行 |
| 主要用途 | 复盘反思 | 临场决策 |
| 脚本辅助 | `analyze_chat.py` 输出统计 | 直接AI读原文 |
