# 回复建议框架

## 核心原则

**不要给套路话术**，要：
1. 基于上下文具体分析
2. 给出有个人风格的信息（你自己的说话方式）
3. 明确说明适用场景和风险

---

## 三种策略类型

### 进攻型（适合关系已到暧昧期）
- 大胆表达情感、推进关系
- 风险：对方可能退缩
- 适用：对方近期回应积极，有情感暗示

### 稳妥型（适合刚进入熟悉期）
- 保持热情但不过度，不给对方压力
- 风险：进展较慢
- 适用：关系还在磨合，节奏还没稳定

### 保守型（适合关系早期或对方冷淡）
- 保持联系感，不主动推进
- 风险：关系可能停滞
- 适用：对方回应冷淡，或自己处于不确定状态

---

## 常见场景的回复策略

### 场景1：对方问"在干嘛？"
- **稳妥**：分享一个有趣的当前状态 + 反问
  "刚在XXX（一个具体的事），你呢，今天忙吗？"
- **进攻**：加一句情绪表达
  "刚在XXX，忙完啦～有点想找人聊天的感觉，你呢？"
- **保守**：简短回答
  "在工作/学习中，你呢？"

### 场景2：对方说"今天好累"
- **稳妥型**：关心 + 倾听 + 不追问
  "辛苦啦...是工作上的事还是？有啥能帮的尽管说"
- **进攻型**：关心 + 提供陪伴
  "辛苦啦，抱抱 🤗 晚上要不要语音聊聊，放松一下？"
- **保守型**：简单关心
  "累就早点休息，注意身体"

### 场景3：对方主动分享（图片/事情）
- 核心原则：给出具体回应，不要只说"哈哈"或"嗯嗯"
- **回应公式**：确认看到 + 具体评论 + 相关延伸 + 反问

### 场景4：对方很久没回消息后再回
- 不要表现出等待和焦虑
- **稳妥**：轻松化解，不提等待
  "哈哈没关系～那个事情后来怎么样了？"
- **进攻**：加一点调侃
  "消息都沉海底了哈哈哈哈，终于浮上来啦～"

### 场景5：对方发出暧昧信号（撒娇、试探）
- **进攻**：接住信号，正面回应，推进关系
  "你这是在撒娇吗？"
- **稳妥**：接住信号，但不完全接住，留空间
  "哈哈好可爱～这样我会更想见你哦"

### 场景6：对方不主动，需要你开场
- **稳妥**：分享一个具体的生活片段 + 问对方
  "今天吃到一家超好吃的店！你最近有没有发现什么好吃的？"
- **进攻**：带一点情感暗示
  "今天发生了一件XX的事，突然想到你～"
- **保守**：以问句开场，看对方反应
  "最近怎么样？好久没聊了"

### 场景7：深夜聊天
- 深夜是情感升温的好时机，但也要判断对方状态
- **进攻**：深夜话题可以更私人
  "这么晚还没睡，在想什么？"
- **稳妥**：关心对方休息
  "怎么这么晚？明天不用上班吗？"

## 禁忌清单

1. **连续发3条以上对方没回的消息** → 对方感到压力
2. **用质问语气** → "你怎么不回我？""你不喜欢我了吗？"
3. **给关系下定义太早** → 对方还没准备好会跑
4. **只关心不分享** → 变成单方面的情绪垃圾桶
5. **用太明显的套路** → "我想你了"说完立刻撤回是扣分项
6. **贬低竞争者** → 对方可能会觉得你不够自信
7. **过度解读对方消息** → 有时嗯就是嗯，没别的意思

---

## 判断对方兴趣度的信号

### 高兴趣（进攻时机）
- 主动找话题
- 回复很快（<5分钟）
- 消息长、有内容
- 主动关心你
- 主动约见面
- 有情感表达（撒娇、调侃、暧昧）

### 中等兴趣（稳妥时机）
- 有问有答，但不延伸
- 回复时间不固定
- 话题限于日常

### 低兴趣（保守时机）
- 回复极慢（>2小时）或经常不回
- 回复简短（1-2字）
- 不问问题
- 不主动找你
- 很少发表情/emoji

---

## 分析下一句回复的步骤

1. 读取最新几条消息，确认对话语境
2. 判断对方当前的情绪状态（开心/疲惫/试探/冷淡）
3. 判断当前关系阶段（认识/熟悉/暧昧/交往）
4. 判断对方的兴趣度（参考上面信号）
5. 结合你的性格（消息风格），选择策略类型
6. 给出的回复要符合你自己的说话习惯，不要生硬模仿

### 给出的格式：
```
建议回复（3条）

1. [策略类型] [策略名]
   回复内容："..."
   理由：...
   适用场景：...

2. ...

3. ...
```
