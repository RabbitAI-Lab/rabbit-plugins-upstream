# Logic Checklist — Discussion 逻辑推理逐条检查清单

## 使用方法
按顺序检查每一项，✓ 通过，✗ 缺失，⚠ 弱。

---

## Section 1: Causal Chain Completeness（因果链完整性）

- [ ] Mechanism → Evidence → Conclusion 三层都有
- [ ] 每个 claim 都有 mechanism 说明
- [ ] Mechanism 有具体 evidence 支持
- [ ] 不是 data 直接跳到 conclusion

## Section 2: Evidence Specificity（证据具体性）

- [ ] 每个 claim 都有具体 evidence（i.e., 数据 / 文献 / 例子）
- [ ] 不是纯抽象 claim（"X is similar to Y" 但无具体相似之处）
- [ ] Evidence 与 claim 有 logical connection
- [ ] Evidence 不只是 citation 堆叠

## Section 3: Data-Interpretation-Speculation Layering（三层结构）

- [ ] Data 层有标志词（"I found" / "The data show"）
- [ ] Interpretation 层有标志词（"suggest" / "indicate"）
- [ ] Speculation 层有标志词（"may" / "might" / "could"）
- [ ] 三层不混合（data 与 speculation 不分）

## Section 4: Causal vs Correlational Boundary（因果vs相关边界）

- [ ] Correlational study 不 claim 因果
- [ ] Cross-sectional 不 claim intervention effect
- [ ] 用 "associated with" / "related to" / "may lead to"
- [ ] 没有过度推论

## Section 5: Alternative Explanations Coverage（替代解释覆盖度）

- [ ] 主要 claim 有 1+ alternative explanation
- [ ] Alternative 有具体内容（不是 generic）
- [ ] Alternative 有反驳证据或承认
- [ ] 不是单一解释（one-sided argument）

## Section 6: Claim-Limitation Balance（Claim 与 Limitation 平衡）

- [ ] Limitation 后立即有 claim balance
- [ ] 不用纯自我贬低语言
- [ ] Limitation 与 claim 对冲
- [ ] 没有 "Our study cannot prove..." 削弱 claim

## Section 7: Anti-Pattern Check（反模式）

- [ ] ❌ Correlational study claim 因果
- [ ] ❌ Data 直接跳到 conclusion（无 mechanism）
- [ ] ❌ 单一解释（无 alternative）
- [ ] ❌ Pure self-flagellation（纯自我贬低）
- [ ] ❌ Speculation 包装成 data（无标志词）

---

## 严重度判定

| 缺失项数 | 严重度 |
|---|---|
| 0-2 | Minor |
| 3-5 | Major |
| 6+ | Critical |
