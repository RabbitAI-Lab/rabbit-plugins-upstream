# 步骤 S1：并行拉取 4 源原始数据

- **输入**：`asin`（目标 ASIN）、`marketplace`（站点代码，默认 US）、`days`（Keepa 回看天数，默认 365）
- **依赖**：无（仅依赖运行时入参）
- **用途**：为 S2/S3/S4 提供四大数据源的原始 JSON——Keepa 历史曲线、Sorftime 日销趋势、SIF 流量关键词、SIF 流量结构总览

## 站点参数映射表

不同数据源使用不同的站点参数格式，调用前必须按下表转换：

| marketplace | Keepa domain | Sorftime marketplace | SIF country |
|-------------|-------------|---------------------|-------------|
| US | 1 | us | US |
| UK | 2 | gb | UK |
| DE | 3 | de | DE |
| FR | 4 | fr | FR |
| JP | 5 | jp | JP |
| CA | 6 | ca | CA |
| IT | 8 | it | IT |
| ES | 9 | es | ES |
| IN | 10 | in | IN |
| MX | 11 | mx | MX |
| BR | 12 | br | BR |
| AU | — | au | AU |
| AE | — | ae | AE |
| SA | — | sa | SA |

> **Keepa 不支持 AU/AE/SA**（domain 表无此三站）。对这三个站点，S1.1 Keepa Series 跳过，仅拉 Sorftime + SIF 两路，S2 也不调用 Keepa Product Request。

## S1.1 Keepa 历史时序数据

调用 `linkfox-keepa-product-series`，脚本路径 `<ce-skills>/linkfox-keepa-product-series/scripts/keepa_product_history.py`：

```json
{"asin": "<ASIN>", "domain": <数字>, "days": 365}
```

```bash
python <ce-skills>/linkfox-keepa-product-series/scripts/keepa_product_history.py \
  '{"asin":"<ASIN>","domain":1,"days":365}'
```

关键返回字段（时间序列数组 `{time, value}`）：
- `buyBoxPrice` / `amazonPrice` — 价格历史
- `salesRank` — BSR 排名历史（含子类目）
- `ratingCount` — 评论数历史
- `rating` — 评分历史
- `sellerCount` — 卖家数历史
- `monthlySales` — 月销量历史

**成本**：动态，`0.045 × Keepa tokens`。24h 本地缓存。

**限流降级**：若返回 429 或超时，跳过 S1.1，在 stderr 标注 `[⚠️ Keepa 限流]`，S3 分析时用 Sorftime 数据兜底。

→ 得到：`keepa_series.json`

## S1.2 Sorftime 日销趋势

调用 `linkfox-sorftime-amazon-product-detail`，脚本路径 `<ce-skills>/linkfox-sorftime-amazon-product-detail/scripts/sorftime_product_detail.py`：

```json
{"asin": "<ASIN>", "marketplace": "<小写>", "includeTrend": 1}
```

```bash
python <ce-skills>/linkfox-sorftime-amazon-product-detail/scripts/sorftime_product_detail.py \
  '{"asin":"<ASIN>","marketplace":"us","includeTrend":1}'
```

关键返回字段：
- `salesTrend` — 日销量趋势数组（交错 `[date, value, ...]`，-1 = 无法预估）
- `revenueTrend` — 日销售额趋势（单位：美分）
- `dealTrend` — Deal 促销历史
- `priceTrend` — 价格趋势
- `bsrRankTrend` — BSR 排名趋势 `[{NodeId, Rank: [...]}]`
- `ratingCountTrend` — 评论数趋势
- 快照字段：`currentPrice`, `currentBsr`, `fbaFee`, `rating`, `reviewCount` 等

**成本**：动态，`internal_query_count × 12`。24h 本地缓存。

→ 得到：`sorftime_detail.json`

## S1.3 SIF 流量关键词反查

调用 `linkfox-sif-asin-keywords`，脚本路径 `<ce-skills>/linkfox-sif-asin-keywords/scripts/sif_asin_keywords.py`：

```json
{"asin": "<ASIN>", "country": "<大写>", "timePieceType": "latelyDay", "pageSize": 100}
```

```bash
python <ce-skills>/linkfox-sif-asin-keywords/scripts/sif_asin_keywords.py \
  '{"asin":"<ASIN>","country":"US","timePieceType":"latelyDay","pageSize":100}'
```

关键返回字段（每条关键词记录）：
- `keyword` — 关键词文本
- `productNaturalRank` — 自然排名
- `productAdRank` — 广告排名
- `weeklySearchVolume` — 周搜索量
- `trafficShare` — 流量占比
- `naturalTrafficShare` / `paidTrafficShare` — 自然/付费流量得分
- `clickConcentrationShare` — 点击集中度
- `clickToPurchaseConversionRate` — 点击转化率
- `displayPositionTypes` — 展示位类型
- `isMainKw` / `isAccurateKw` — 主词/精准词标记

**成本**：固定 9 积分。24h 本地缓存。

→ 得到：`sif_keywords.json`

## S1.4 SIF 流量结构总览

调用 `linkfox-sif-asin-summary`，脚本路径 `<ce-skills>/linkfox-sif-asin-summary/scripts/sif_asin_summary.py`：

```json
{"searchValue": "<ASIN>", "country": "<大写>", "last7d": true}
```

```bash
python <ce-skills>/linkfox-sif-asin-summary/scripts/sif_asin_summary.py \
  '{"searchValue":"<ASIN>","country":"US","last7d":true}'
```

关键返回字段：
- `totalExposureScore` / `Prev` — 总曝光得分（及上期）
- `naturalSearchExposureScore` / `Ratio` — 自然搜索曝光（及占比）
- `sponsoredProductsExposureScore` / `Ratio` — SP 广告曝光（及占比）
- `amazonsChoiceExposureScore` / `Ratio` — AC 曝光
- `editorialRecommendationsExposureScore` / `Ratio` — 编辑推荐曝光
- `topRatedExposureScore` / `Ratio` — Top Rated 曝光
- `totalTrafficKeywordCount` / `Prev` / `In` / `Out` — 总流量词数（及上期、新进、退出）
- `naturalSearchKeywordCount` / `Prev` / `In` / `Out` — 自然搜索词数
- `sponsoredProductsKeywordCount` — SP 广告词数
- `amazonsChoiceKeywordCount` / `In` / `Out` — AC 词数

**成本**：固定 9 积分。24h 本地缓存。

→ 得到：`sif_summary.json`

## 执行方式

四路并行发起（互不依赖），同一轮并行调用。使用 Bash 工具在单条消息中发起 4 个并行调用。

> **⚠️ 路径约定**：`<ce-skills>` = `/root/.linkfox/.ce/skills`。所有脚本会自动将完整响应落盘到会话目录 `<cwd>/linkfox/<YYYY-MM-DD>/<session>/data/`。脚本 stdout 对 > 8KB 响应只输出摘要，需要具体字段时从落盘 JSON 用 `jq` 按需读取。

## 自检

- [ ] 至少 3 个数据源返回了非空数据（Keepa 限流降级时至少 Sorftime + SIF 可用）
- [ ] Keepa 限流时已在 stderr 标注 `[⚠️ Keepa 限流]`
- [ ] AU/AE/SA 站点未调用 Keepa（domain 表无此三站）

## 输出

| 输出文件 | 来源 | 下游消费者 |
|---------|------|-----------|
| `keepa_series.json` | S1.1 Keepa Series | S2（确认 ASIN 有效）、S3（价格/BSR/评论/生命周期分析） |
| `sorftime_detail.json` | S1.2 Sorftime | S3（销量/Deal/季节性分析，Keepa 限流时兜底） |
| `sif_keywords.json` | S1.3 SIF Keywords | S3（流量结构分析） |
| `sif_summary.json` | S1.4 SIF Summary | S3（流量结构分析） |
