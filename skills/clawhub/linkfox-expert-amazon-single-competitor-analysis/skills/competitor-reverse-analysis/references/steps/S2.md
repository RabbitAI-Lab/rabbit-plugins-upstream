# 步骤 S2：补充 Keepa 商品详情快照

- **输入**：`asin`、`marketplace`（来自运行时入参）、S1 各源返回状态（确认 ASIN 有效）
- **依赖**：S1 完成（需确认 ASIN 在 Keepa/Sorftime 中有数据，非空壳 ASIN）
- **用途**：为 S3 补充 FBA 费用、材质、重量、尺寸、13 月月销历史、30/90/180 天 BSR 均值等快照字段

## 调用

调用 `linkfox-keepa-product-request`，脚本路径 `<ce-skills>/linkfox-keepa-product-request/scripts/keepa_product_detail.py`：

```json
{"asin": "<ASIN>", "domain": <数字>, "history": 1}
```

```bash
python <ce-skills>/linkfox-keepa-product-request/scripts/keepa_product_detail.py \
  '{"asin":"<ASIN>","domain":1,"history":1}'
```

`domain` 映射同 S1 站点参数映射表。`history: 1` 表示包含 12 个月月销历史 + 30/90/180 天平均排名。

关键返回字段：
- `title` / `brand` / `imageUrl` — 商品基础信息
- `fbaFee` / `referralFee` — FBA 费用和佣金
- `material` / `weight` / `dimensions` — 材质、重量（g）、尺寸（mm）
- `salesRank` — 当前 BSR + 类目树
- `monthlySales` — 当前月销 + 最多 12 个月历史
- `avg30` / `avg90` / `avg180` — 30/90/180 天 BSR 均值
- `rating` / `reviewCount` — 当前评分和评论数
- `sellerCount` — 当前卖家数
- `listedSince` — 上架时间
- `variations` — 变体信息

**成本**：动态，`0.045 × Keepa tokens`。24h 本地缓存。

## 限流降级

- 若 S1.1 Keepa Series 已限流（429），S2 大概率也会限流 → **直接跳过 S2**
- 跳过时在 stderr 标注 `[⚠️ S2 跳过] Keepa 限流，S3 用 Sorftime 快照兜底`
- S3 降级方案：用 Sorftime 的 `currentPrice`, `fbaFee`, `rating`, `reviewCount` 等快照字段替代

## AU/AE/SA 站点

Keepa 不支持此三站（domain 表无对应值），S2 直接跳过。

→ 得到：`keepa_product.json`（或 `null` 表示跳过）

## 输出

| 输出文件 | 来源 | 下游消费者 |
|---------|------|-----------|
| `keepa_product.json` | S2 Keepa Product Request | S3（KPI 总览、关键时间线、利润率计算） |
