# 步骤 S4：生成 HTML 报告

- **输入**：S3 的分析 JSON（`s3_analysis.json`）
- **依赖**：S3 完成
- **用途**：生成 11 章节的 HTML 深度报告，落盘到会话目录 `reports/`

## 前置：读取报告组件库

先 Read `linkfox-report-generator` 的 `references/analysis-layouts.md` 获取可用组件库：

```
/root/.linkfox/workspaces/.claude/skills/linkfox-report-generator/references/analysis-layouts.md
```

## 报告章节设计

按 S3 分析 JSON 的 10 个维度 + 行动建议，设计 11 个章节的 HTML 片段：

| 章节 | 数据源（S3 字段） | 推荐组件 |
|------|------------------|---------|
| 1. KPI 总览 | `kpi_overview` | stat-card 网格 |
| 2. 关键时间线 | `timeline` | timeline 线性图 |
| 3. BSR 深度解析 | `bsr_volatility` | 数据表 + 趋势描述 |
| 4. 评论曲线与异常检测 | `review_anomaly` | 柱状图（月增量）+ 异常标记表 |
| 5. 价格策略量化分析 | `price_strategy` | 三阶段对比表 + 弹性系数 |
| 6. Deal 效果评估 | `deal_effectiveness` | Deal 前后对比表 |
| 7. 销量趋势与季节性 | `sales_seasonality` | 月度汇总表 + 高峰/低谷标注 |
| 8. 流量结构分析 | `traffic_structure` | 饼图（自然/付费占比）+ Top 词表 |
| 9. 生命周期判断 | `lifecycle` | 阶段表 + 交叉验证 |
| 10. SWOT 综合研判 | `swot` | 四象限 |
| 11. 行动建议 | 综合 all | insight-list |

## HTML 编写规则

1. **无 `<!DOCTYPE>` / `<html>` / `<head>` / `<style>` / `<body>` 标签**——由 `inject_report.py` 注入模板
2. 每个统计章节必须包含 `<div class="data-source">数据源：xxx</div>`
3. 派生计算章节加 `.ds-computed` 子块
4. 数字使用千位分隔符，百分比保留 1 位小数
5. 所有统计数据来自 S3 JSON，**禁止 LLM 心算**
6. 分节写入 HTML 片段，追加到 `.fragment.html` 文件

## 报告元信息

报告头部必须包含：
- 生成时间（ISO 8601）
- 参数快照（ASIN、marketplace、days）
- 数据来源清单（S1 各源是否成功 + S2 是否跳过）
- 局限性说明（Keepa 限流降级、SIF 延迟、覆盖空白）
