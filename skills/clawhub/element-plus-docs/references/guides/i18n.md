Element Plus 组件默认使用英文。 如果你想使用其他语言，请继续阅读以了解具体方法。

Element Plus 提供了全局配置选项。

Element Plus还提供一个 Vue 组件 ConfigProvider 用于全局配置本地化设置和其他设置。

我们使用 Day.js 库来管理组件的日期和时间，例如 DatePicker。 在 Day.js 中设置合适的语言也非常重要，这样才能确保国际化功能正常工作。 您必须分开导入Day.js的区域设置。

完整文档请参阅：ConfigProvider 让我们以 unpkg 为例：

关于完整文档，请参阅： ConfigProvider

如果你需要其他语言，欢迎提交 PR。 你只需要在 这里 添加一个语言文件即可。

**Examples:**

Example 1 (sql):
```sql
import ElementPlus from 'element-plus'
import zhCn from 'element-plus/es/locale/lang/zh-cn'

app.use(ElementPlus, {
  locale: zhCn,
})
```

Example 2 (jsx):
```jsx
<template>
  <el-config-provider :locale="zhCn">
    <app />
  </el-config-provider>
</template>

<script setup lang="ts">
import { ElConfigProvider } from 'element-plus'
import zhCn from 'element-plus/es/locale/lang/zh-cn'
</script>
```

Example 3 (unknown):
```unknown
import 'dayjs/locale/zh-cn'
```

Example 4 (jsx):
```jsx
<script src="//unpkg.com/element-plus/dist/locale/zh-cn"></script>
<script>
  app.use(ElementPlus, {
    locale: ElementPlusLocaleZhCn,
  })
</script>
```
