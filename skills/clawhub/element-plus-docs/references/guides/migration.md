此指南 将帮助您从 Element Ui 2.x 升级到 Element Plus。

使用 Element Plus 与 Vue 3 迁移构建时可能遇到一些问题。 有些组件依赖于 Vue 3 内部 API。 尝试将全局组件或将你项目中每个组件的版本调整为3 。

我们已经为您提供了一个迁移工具，可以将您的项目从 Element UI 迁移到 Element Plus。 您可以在 这里 找到 gogo code 迁移工具。
