Element Plus 为了避免视觉传达差异，使用一套特定的调色板来规定颜色，为你所搭建的产品提供一致的外观视觉感受。

Element Plus 默认的主题色是明亮、友好的蓝色。

除了主颜色外，您需要在不同的场景中使用不同的场景颜色 (例如，危险的颜色表示危险的操作)

中性色用于文本、背景和边框颜色。 通过运用不同的中性色，来表现层次结构。
