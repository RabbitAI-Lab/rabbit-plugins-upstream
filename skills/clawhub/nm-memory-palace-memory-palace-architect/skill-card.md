## Use Case: <br>
Developers, writers, and knowledge workers use this skill to design spatial knowledge structures, encode concepts with memorable sensory cues, and validate memory-palace navigation and recall. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill has broad triggers around memory, organization, knowledge, spatial topics, and architecture, so it may activate in conversations where memory-palace design is only adjacent to the user's intent. <br>
Mitigation: Confirm that the user wants memory-palace architecture guidance before applying the workflow. <br>
Risk: Example palace_manager.py commands depend on external plugin files not included in this artifact. <br>
Mitigation: Treat those commands as integration examples and verify the required plugin files and Python environment before running them. <br>
