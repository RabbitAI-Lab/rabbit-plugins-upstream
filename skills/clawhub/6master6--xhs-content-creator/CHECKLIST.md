# xhs-content-creator 内容创作速查清单

> **用前 30 秒过一遍**。违反任何 error 项都先改正再调 `generate_and_publish.py`。
> 完整规则见 `SKILL.md §1.5`；本文件是 1 页速查版。

## 标题
- [ ] ≤20 字（emoji 与全角符号按 2 字算；`｜` U+FF5C 算 2 字，`·` U+00B7 算 1 字 — 用 `·` 避免超长）
- [ ] 核心关键词在前 8 字
- [ ] 无极限词（最 / 第一 / 必 / 100% / 唯一 / 独家 / 全网最低 / 史上最强 / 神药 / 神器 / 神级 / 永不）
- [ ] 无站外导流（私信 / 微信 / +V / vx / 公众号 / 小红书号 / 看主页）
- [ ] 无夸张承诺（包 X / 保证 X / 立省 / 错过等 N 年）

## 正文
- [ ] 300-800 字
- [ ] 3-5 个短段（按 `\n\n` 分段）
- [ ] **主题 + 位置前置**：开头 1-2 句讲清「主题」和「位置」（不要用「另一面 / 被遗忘的远方 / 不为人知的秘密」等抽象概念开头）
- [ ] 每个场景必带地名（湖 / 塔 / 亭子 / 绿道 / 水库 / 街道 / 区 / 镇 等）
- [ ] 标题关键词在正文出现 1-2 次
- [ ] emoji ≤5 个

## 话题
- [ ] 2-5 个精准话题
- [ ] 每个以 `#` 开头
- [ ] 组合：地点类（强）+ 氛围类（中）+ 季节/时令类（中）+ 品类类（弱）
- [ ] 避免泛词（日常 / 分享 / 生活 / 记录 / vlog / 好物 / 推荐 / 种草 / 测评 / 合集）

## 图片
- [ ] 1-9 张
- [ ] 首图承担点击理由（最强氛围）
- [ ] 推荐竖图 3:4（横图会被裁切）
- [ ] 清晰无水印（无平台水印 / 日期水印 / 二维码）
- [ ] 多图色调 / 风格 / 主体协调

## 合规（红线）
- [ ] 不侵权搬运（小红书有图片指纹 + 文本查重）
- [ ] 不站外导流（再次确认）
- [ ] 不虚假夸大（神药 / 神器 / 神级 / 永不 X / 一用就 X）
- [ ] 不伪科学（不挂靠无出处的「专家说 / 研究表明」）
- [ ] 不收益 / 疗效承诺（X 天赚 X / 保证收益 / 吃 X 治 X / 用 X 瘦 X）
- [ ] 不涉敏感（政治 / 宗教 / 时政 / 医疗诊断 / 炫富）
- [ ] 不违规品类（医美 / 医疗 / 金融 / K12 / 二类电商 / 烟酒 — 需资质）

## 自动化
- [ ] 跑前先 `python3 scripts/validate_content.py` 验证（exit 0 = 通过）
- [ ] QR 由 watcher cron 自动发 DM（无需手动 poll）
- [ ] 失败保留：`actions.jsonl` / `result.json` / `content.normalized.json` / `screenshots/` / `dom/`

## 发布前最后一问
- [ ] 用户确认了地点（image 工具不可信，必须显式确认）
- [ ] 标题字数按 `·` 算法算过 ≤20
- [ ] 6 条红线在脑子里过一遍（合规 > 出片）
