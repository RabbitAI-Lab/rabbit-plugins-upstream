## Description:

Guides users through Nitrosend onboarding, including the remote MCP connection, Brand Kit, sending domain, sender defaults, and optional recurring analytics.

This skill is ready for commercial/non-commercial use.

## Publisher:

[nitrosend](https://clawhub.ai/user/nitrosend)

### License/Terms of Use:

MIT-0

## Use Case:

External users use this skill to complete Nitrosend onboarding: connect their agent through MCP, configure brand identity and an authorized sending domain, and set sender defaults. They can also opt into recurring analytics when their agent host supports scheduling.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup can change account and brand settings, upload a logo, configure sending domains, and enable recurring reports.

Mitigation: Confirm the intended account and brand, use only a logo the user approves, and review sender defaults and report schedules before enabling them.
