## Description:

Generates post-lesson reinforcement materials, exercises, and reference answers for Agent Skill courses covering SKILL.md, frontmatter, progressive disclosure, storage, safety review, and skill triggering.

This skill is ready for commercial/non-commercial use.

## Publisher:

[yinnxinn](https://clawhub.ai/user/yinnxinn)

### License/Terms of Use:

MIT-0

## Use Case:

Educators and training facilitators use this skill to generate Agent Skill course review notes, layered homework exercises, separated answer keys, grading points, and optional extension topics.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill creates two Markdown files in the active workspace, which could conflict with similarly named homework documents.

Mitigation: Review the planned output filenames and existing workspace files before accepting or keeping generated materials.

Risk: Broad course-review triggers may activate when the user discusses nearby Agent Skill teaching topics.

Mitigation: Use the skill when the request is specifically about Agent Skill course reinforcement, homework, exercises, or reference answers.
