# 库存进销存与补货管理

[English](README.md)

管理商品和多仓库出入库流水，计算库存、移动加权成本及补货建议，按币种输出报表。

## 功能

管理商品和多仓库出入库流水，计算库存、移动加权成本及补货建议，按币种输出报表。

在当前助手的工作区运行，输出处理结果和报告，原文件保留。

安装后，把任意一条发给 AI，并附上相关文件或网址。

```text

```


```text

```
