# 五级评级判定门槛

> 本版本（v4）精简版。原 multi-agent pipeline 用的"评级输入维度"等已删除，默认模式直接用这套阈值。

## 评级体系

| 等级 | 评级 | 判定门槛 | 操作含义 |
|---|---|---|---|
| ⭐⭐⭐⭐⭐ | 强烈买入 | 多重利好共振、风险可控、预期显著跑赢大盘（>15%/年化超额） | 重仓介入，逢低加仓 |
| ⭐⭐⭐⭐ | 买入 | 正面因素占优、风险可接受、预期跑赢大盘（5-15%） | 建仓或加仓，逢低介入 |
| ⭐⭐⭐ | 持有 | 多空均衡或不确定性高、预期接近大盘（±5%） | 维持现仓位，不动 |
| ⭐⭐ | 卖出 | 负面因素占优、预期跑输大盘（-5% 至 -15%） | 减仓，不再加仓 |
| ⭐ | 强烈卖出 | 系统性风险或基本面恶化、预期显著跑输（<-15%） | 清仓或做空 |

## 🛡️ 监管事件叠加规则

**这是 v4 新增的强制规则**——发现罚款 / 处罚 / 立案时，评级必须额外调整：

| 事件类型 | 评级影响 |
|---|---|
| 罚款 ≤ 净利润 5% | 不下调，列入风险段 |
| 罚款 5-15% | **降一档** |
| 罚款 > 15% 或平台经济首例效应 | **降至「持有」或以下** + 等中报定调 |
| 立案调查未落地 | 保守一档 + 注明可能罚款区间 |

## 操作建议规范

除评级外，主 agent 必须给出：

- **仓位比例**：占总资产的百分比（强烈买入 20%+，买入 10-20%，持有 0-10%，卖出 0-5%，强烈卖出 0%）
- **入场区间**：1-3 个价格区间（结合支撑位与估值）
- **止损位**：基于 ATR 或关键支撑位（一般 ATR×2 或支撑位下方 3-5%）
- **目标价区间**：1-3 个目标价（结合压力位、估值中枢、可比公司）
- **时间框架**：达到目标价或止损的预期时间（1-3 月 / 6-12 月）

## 置信度说明（建议附）

- **数据完整度**：高（财报 + 行情 + 资讯齐全）/ 中（缺 1-2 维）/ 低（>2 维缺失）
- **判断置信度**：高（多维共振）/ 中（部分维度矛盾）/ 低（数据缺失或事件不明朗）
- **评级翻转触发条件**：列出 2-3 个若发生变化将改变评级的具体条件
