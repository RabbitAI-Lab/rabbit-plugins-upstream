## Description:

输入受访者公开资料、采访主题与可用时长，产出一份可直接执行的中文采访提纲：按叙事主线编排核心问题、每题的追问方向及素材核对点。

This skill is ready for commercial/non-commercial use.

## Publisher:

[xxjrq](https://clawhub.ai/user/xxjrq)

### License/Terms of Use:

MIT-0

## Use Case:

媒体编辑、自媒体创作者和采访者可用它根据用户提供的公开资料、主题与时长，整理中性、有时间安排的中文采访问题、条件式追问和录制前核对清单。

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: 提纲可能把用户提供的资料误写成已核实事实，或使用未获许可的内容。

Mitigation: 保留资料原有归属；使用前核实事实，并确认发布所需的授权。

Risk: README 安装命令未固定 CLI 版本或仓库修订，安装内容可能随时间变化。

Mitigation: 安装前检查 CLI 版本和仓库修订。
