# 投标澄清智能助手

> 不止代写答复：先审"专家这要求合不合法"，再审"我怎样答才不作废"，量清"澄清·补正"与"实质性修改"那条红线。

## 这是什么

投标人在"被要求澄清 / 说明 / 补正"的高压、限时、信息弱势场景下的合规顾问。它**不止代写答复**，而是先反向审查专家要求是否合法，再判定自己怎样答才不越界变成"实质性修改"而废标，并识别违法澄清、攥住事后救济后手。

## 核心能力

- **反向审查**（审专家）：识别"四类违法澄清"（变相二次报价 / 补实质内容 / 要求改方案或额外承诺 / 差别对待），标红并给法条依据。
- **应答边界判定**（审自己）：把每条事项判为 可答 / 须补正 / 禁实质修改，给出不越界口径。
- **行动包**：答复函草稿 + 留痕清单 + 后手清单（质疑→投诉）。
- **项目属性路由**：政采（87号令第51条）/ 工程招标（实施条例第52条）/ 国企采购，自动切换法条集。
- **主动澄清预检**：用户想主动发函说明时，直接拦截并提示实施条例第52条。

## 工作流

步骤0 属性路由 → 步骤1 解析澄清函 → 步骤2 反向审查 → 步骤3 应答边界判定 → 步骤4 合成行动包。

## 使用方式

把收到的澄清函（或专家来函原文）粘贴给助手，它会按四段式输出：解析 → 反向审查 → 应答边界 → 行动包。
