## Description:

Provides AI coding assistants with WCAG 2.2 guidance, semantic HTML and ARIA patterns, keyboard and screen-reader workflows, and deterministic accessibility audit tools for web interfaces.

This skill is ready for commercial/non-commercial use.

## Publisher:

[skills-repo](https://clawhub.ai/user/skills-repo)

## Use Case:

Developers use this skill to build and review accessible web interfaces, improve keyboard and screen-reader support, and produce prioritized audit findings. It provides technical guidance and checks, while legal compliance decisions remain with the user's team.
