## Description:

Provides accessibility engineering guidance for web interfaces, including WCAG alignment, semantic HTML and ARIA, keyboard access, screen reader testing, and repeatable static checks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[skills-repo](https://clawhub.ai/user/skills-repo)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to design and review accessible web interfaces, improve semantic markup and keyboard behavior, and produce static audit findings and remediation guidance. It also helps teams plan manual screen reader checks alongside automated checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Static checks may miss keyboard and screen reader usability problems.

Mitigation: Supplement automated checks with manual keyboard and screen reader testing.

Risk: The README's global install commands skip prompts, and external installer code was not reviewed in the supplied evidence.

Mitigation: Prefer project-scoped installation from a reviewed source revision and installer version.
