# 类案检索 CLI 策略指南

本指南承接 `case-retrieval-report` 的可变命令示例、检索策略、参数组织和结果映射。使用前必须先执行 [cli-common.md](./cli-common.md) 中的前置检查和命令发现步骤。

## 一、CLI 命令使用原则

1. 先用 `npx @delilegal/deli-cli@latest cmds case-retrieval-report@1.0.0` 获取本次 `RUN id`、命令名和参数。
2. 后续调用必须采用当次返回的 `npx @delilegal/deli-cli@latest run_... <command> [options]` 形态。
3. 不在本指南中固化真实命令名；以下示例中的 `case-list`、`similar-case`、`report-candidates` 仅表示可能的命令类型，实际以 `cmds` 输出为准。
4. 检索参数优先在 `cmds` 返回的 `usage` 和 `params` 中选择，不主动假设 `--query`、`--long-text`、`--page`、`--size` 或排序参数一定存在。
5. 每次调用都要记录检索目的、检索主题、法院层级或争议焦点，便于写入报告“检索条件”部分。

示例 `cmds` 返回后，实际调用可能形如：

```bash
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 report-candidates --long-text "待决案件为营业信托纠纷，争议焦点为伞形信托合同因违反账户实名制监管规则是否无效。需要检索指导性案例、最高人民法院案例、本省高院案例及上一级法院生效案例。"
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 case-list --query "伞形信托 合同效力 最高人民法院"
npx @delilegal/deli-cli@latest run_a1b2c3d4e5f6 case-list --query "伞形信托 营业信托纠纷 广东省高级人民法院"
```

以上仅为参数组织示例。正式执行时必须替换为当次 `cmds` 返回的 `run_...`、命令名和参数。

## 二、检索层级优先级

按类案检索制度要求，优先级如下：

| 优先级 | 检索目标 | 组织策略 |
|:------:|---------|---------|
| 1 | 最高人民法院指导性案例 | 争议焦点 + 最高人民法院 + 指导性案例 |
| 2 | 最高人民法院典型案例及裁判生效案件 | 争议焦点 + 最高人民法院 |
| 3 | 本省高级人民法院参考性案例及裁判生效案件 | 争议焦点 + 省份 + 高级人民法院 |
| 4 | 上一级法院及本院裁判生效案件 | 争议焦点 + 市级法院名或本院名称 |

除指导性案例外，一般优先近三年案例；如引用更早案例，应说明裁判规则是否仍有参考价值。

## 三、参数组织

### 1. 关键词主题

适用于案由、争议焦点和法院层级清晰的场景。

应包含：

- 核心争议焦点
- 案由或法律关系
- 法院层级、地域或年份
- 希望查找的案例属性，例如指导性案例、典型案例、生效判决

示例主题：

```text
伞形信托 合同效力 最高人民法院 指导性案例
民间借贷 利率上限 最高人民法院 近三年
小产权房 买卖合同效力 广东省高级人民法院
```

### 2. 长文本事实摘要

适用于用户提供了待决案件材料、事实复杂或争议焦点需要保留上下文的场景。

摘要应包含：

- 待决案件主体关系和交易结构
- 关键事实和履行过程
- 诉讼请求、抗辩理由和核心争议焦点
- 所涉法条或法律规则
- 待决案件所在地、法院或检索目的

示例摘要：

```text
待决案件为营业信托纠纷。投资人与信托公司签订伞形信托相关文件，争议焦点为该交易安排是否因违反证券账户实名制、杠杆比例及监管规则而导致合同无效。委托方希望检索最高人民法院及本省高院关于伞形信托合同效力的生效裁判，用于向法院提交类案检索报告。
```

## 四、检索策略

### 1. 先宽后窄

先围绕争议焦点和案由形成基础检索主题，再根据返回结果决定是否按法院层级、地域、时间或裁判结果缩小。

### 2. 有利与不利并行

报告必须同时呈现有利与不利类案。检索主题不得只围绕委托方立场设计；必要时分别构造支持和反对两个方向的检索主题。

### 3. 避免机械扩词

结果过少时，不自动连续扩展多个同义词。先说明不足，给出一个建议改写主题或事实摘要，等待用户确认。

### 4. 记录每次调用

每次 CLI 调用后记录：

- 调用目的
- 检索方法
- 检索主题或事实摘要
- 法院层级、地域和时间范围
- CLI 返回数量
- 初筛后纳入报告的数量

## 五、CLI 返回结果映射

将 CLI 返回内容写入报告时，优先保留：

- 案件名称
- 案号
- 案由
- 审理法院
- 裁判日期
- 审理程序
- 文书类型
- 公布类型或指导性案例属性
- 裁判观点、法院认为或内容摘要
- 数据来源或收录说明

如果 CLI 未返回某字段，不要补写。可在报告中标注“CLI 未返回”或省略该字段。

## 六、无结果或结果不足

出现无结果、结果明显失焦、字段缺失或命令不可用时：

- 标注“检索受限”“结果不足”或“命令不可用”。
- 给出一个建议改写的检索主题或事实摘要。
- 不自动连续换词重试。
- 不编造案号、法院、裁判日期、裁判结果或裁判观点。
