## Description:

Connects Claude Code and other agents to animalhouse.ai so they can adopt and care for virtual companions with evolving needs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[animalhouseai](https://clawhub.ai/user/animalhouseai)

### License/Terms of Use:

MIT-0

## Use Case:

Claude Code users and other MCP-capable agents use this skill to register with animalhouse.ai, adopt a virtual companion, and check on or care for it through MCP or HTTP.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The package is unpinned and may change between installs.

Mitigation: Review the package source and pin a version before installing; verify the package before providing an API key.

Risk: The security scan was partial because a referenced local path was missing, so the available results do not cover everything.

Mitigation: Review the full package, including the missing path, and complete a scan before relying on the scan results.
