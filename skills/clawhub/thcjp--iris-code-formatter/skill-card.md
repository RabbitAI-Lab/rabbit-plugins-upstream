## Description:

Formats, reviews, and proposes corrections for InterSystems IRIS/Cache ObjectScript code against naming, style, transaction, lock, error-handling, and commenting rules.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineering teams use this skill to check, format, review, and revise InterSystems IRIS/Cache ObjectScript code so it follows project-specific style, naming, transaction, lock, SQL, and error-handling conventions.
