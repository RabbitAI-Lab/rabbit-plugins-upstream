## AOM2 主体资产生成域范本

> 承载三必备主体要素（头像/服装/动作）的资产生成，特征剥离法锁定分离性，产出可独立交付的资产。

### 域任务要求

| 任务ID | 任务类型 | 必选组件 | 可选组件 | 组装顺序 | 约束 | 格式 |
|--------|---------|---------|---------|---------|------|------|
| AOM2-01 | 头像生成 | 头像图（随机生成或指定图处理）、风格参数 | 种子值、参考图 | 风格确定→生成或处理→清晰度校验 | 正面清晰、光线良好、固定种子、与服装分离 | PNG 头像图（可独立交付） |
| AOM2-02 | 服装生成 | 服装图（随机生成或指定图处理）、款式参数 | 多套循环换装 | 款式确定→生成→干净背景校验 | 平铺或干净背景、避免遮挡、与头像分离 | PNG 服装图（可独立交付） |
| AOM2-03 | 动作提取 | 动作模板视频、模型权重、推理脚本 | encoder（vitb）、帧数限制（max_frames） | 视频加载→逐帧深度推理→深度视频输出 | ≤15 秒、单人、≥720p、每帧独立归一化、全随机跳过 | MP4 深度视频（可独立交付） |

### AOM2-01 头像生成范本

**任务要求**：
- 必选组件：头像图（随机生成或指定图处理）、风格参数
- 可选组件：种子值、参考图
- 组装顺序：风格确定 → 生成或处理 → 清晰度校验
- 约束：正面、清晰、光线良好；固定种子保证跨图一致；与服装分离（特征剥离法）
- 格式：PNG 头像图（可独立交付）

**范本内容**：

```
portrait of a [角色描述], [发色] [发型], [五官特征], facing camera,
clean background, high detail, realistic photography style, studio lighting.
```

**样本特征摘要**：
- 结构：角色外观 → 发型 → 五官 → 机位 → 风格 → 打光
- 风格：写实影棚人像
- 逻辑：只生成脸，不涉及服装，与服装生成分离（特征剥离法）
- 格式：英文提示词，逗号分隔短语

> 要点：固定种子 + 相同角色描述是保证跨图一致性的硬约束；只出脸，禁带服装元素。

### AOM2-02 服装生成范本

**任务要求**：
- 必选组件：服装图（随机生成或指定图处理）、款式参数
- 可选组件：多套循环换装
- 组装顺序：款式确定 → 生成 → 干净背景校验
- 约束：平铺或干净背景，避免遮挡；与头像分离（特征剥离法）
- 格式：PNG 服装图（可独立交付）

**范本内容**：

```
[服装款式描述], flat lay on clean background, full garment visible,
no model, no watermark, high detail, studio lighting.
```

**样本特征摘要**：
- 结构：款式 → 平铺/干净背景 → 完整展示 → 无模特
- 风格：电商平铺图
- 逻辑：强调「无模特、完整展示」避免遮挡，与头像生成分离（可并行）
- 格式：英文提示词短语

> 要点：与头像生成（AOM2-01）并行执行，互不依赖；多套换装时循环生成。

### AOM2-03 动作提取范本

**任务要求**：
- 必选组件：动作模板视频、模型权重、推理脚本（`scripts/infer_depth.py`、`scripts/video_to_depth.py`）
- 可选组件：encoder 选择（vitb 默认）、帧数限制（max_frames）
- 脚本调用：
  - 单图→深度图（分步验证用）：`python scripts/infer_depth.py <model.pth> <in.png> <out.png> [vitb]`
  - 视频→深度视频（完整提取）：`python scripts/video_to_depth.py <model.pth> <in.mp4> <out.mp4> [vitb] [max_frames]`
  - 关键参数：encoder=vitb（Base 版，精度与速度均衡）；max_frames 限帧测试（0 或省略为全部帧）；视频输出灰度深度视频、帧率与原视频一致、每帧独立归一化；单图验证额外输出彩色深度图（`<stem>_color.png`，COLORMAP_INFERNO 热力图，可视化辅助）
- 组装顺序：视频加载（分步1）→ 逐帧深度推理（分步2）→ 深度视频输出（分步3）
- 约束：输入 ≤15 秒、单人、动作清晰、≥720p；每帧独立归一化；CPU 可跑（Base 版约 30–40 秒/帧）；全随机/无原视频时本任务跳过
- 环境依赖：模型权重 Depth Anything V2 Base（约 372MB，从 hf-mirror 下载）；Python 依赖 `torch torchvision opencv-python numpy`（CPU 版即可）
- 格式：MP4 深度视频（灰度，帧率与原视频一致，可独立交付）；单图验证附彩色深度图（`_color.png` 热力图，可视化辅助）

**范本内容**：

```bash
# 单图 → 深度图（分步验证用）
python scripts/infer_depth.py <model.pth> <in.png> <out.png> [vitb]

# 视频 → 深度视频（完整提取）
python scripts/video_to_depth.py <model.pth> <in.mp4> <out.mp4> [vitb] [max_frames]
```

关键参数：
- encoder：vitb（Base 版，精度与速度均衡）
- max_frames：限帧测试（如 10），0 或省略表示全部帧
- 输出：灰度深度视频（帧率与原视频一致，每帧独立归一化）；单图验证额外生成彩色深度图 `<stem>_color.png`（热力图可视化）

**环境依赖**（首次使用）：模型权重 Depth Anything V2 Base（约 372MB）从 hf-mirror 下载；Python 依赖 torch/torchvision/opencv/numpy（CPU 版）。

**样本特征摘要**：
- 结构：单图命令 → 视频命令 → 参数说明 → 环境依赖
- 风格：命令行接口
- 逻辑：加载→推理→输出三阶段合并为单任务，内部分步 S→C→O
- 格式：bash 命令 + 参数说明

> 要点：全随机/无原视频时跳过本任务，直接进 AOM4 内置 VideoGen 路径（动作自由发挥）。
