### AOM3-01 背景生成范本

**任务要求**：
- 必选组件：背景图（随机生成或指定图处理）、场景描述参数
- 可选组件：固定种子、风格描述、参考图（图生图替换）
- 组装顺序：场景确定 → 背景生成/指定 → 分辨率与构图校验
- 约束：与角色风格协调、无遮挡主体（主体由角色层生成）、分辨率匹配成片（≥720p）；固定种子保证跨镜头一致
- 格式：PNG 背景图（可独立交付）

**范本内容**：

```
[场景描述], empty scene without people, [光线/氛围描述],
wide shot, no foreground subject, clean composition, high detail,
realistic photography style, 16:9 aspect ratio.
```

图生图背景替换（参考图驱动）：

```
将参考图背景替换为[目标场景描述]，保留主体不变，
match lighting and perspective, seamless blending, high detail.
```

**样本特征摘要**：
- 结构：场景描述 → 无人物 → 光线 → 机位 → 构图 → 风格 → 画幅
- 风格：空镜场景图
- 逻辑：强调「无人物、无前景主体」，避免与角色层冲突；独立场景层，直接汇入组合、不进入三视图
- 格式：英文提示词 + 图生图替换指令

> 要点：背景是独立场景层，不进入三视图，直接汇入 AOM4 组合（生成式融合或成片后抠像替换）。

### AOM3-02 物品生成范本

**任务要求**：
- 必选组件：物品图（随机生成或按指定产品图处理）、品类参数
- 可选组件：固定种子、产品三视图（品牌植入须多角度）、产品脱底处理
- 组装顺序：品类确定 → 物品生成/指定 → 干净背景与轮廓校验
- 约束：平铺或干净背景、轮廓清晰；广告产品须与真实产品一致；固定种子
- 格式：PNG 物品图（白底/透明底，可独立交付）

**范本内容**：

```
[物品品类描述], single object on white background, no hand, no person,
full object visible, clear silhouette, high detail, studio lighting.
```

指定产品脱底（品牌植入）：

```
将指定产品图去除背景，保留产品完整轮廓，输出白底或透明底 PNG。
```

**样本特征摘要**：
- 结构：品类 → 白底 → 无手无人 → 完整可见 → 轮廓 → 风格
- 风格：电商产品白底图
- 逻辑：强调「无手、无人物」，轮廓清晰便于回流 AOM4-01 三视图锁定手持；广告产品须与真实产品一致
- 格式：英文提示词 + 产品脱底指令

> 要点：物品是唯一跨域回流要素——产出后须回流 AOM4-01 三视图锁定手持（条件依赖）。

### AOM3-03 音频准备范本

**任务要求**：
- 必选组件：配音口播音频（用户提供 / TTS 生成 / 随机）、台词文本
- 可选组件：音色参数、语速/情绪、TTS 模型选择
- 组装顺序：台词确定 → 音频来源选择（提供/TTS/随机）→ 音频生成或采集 → 清晰度校验
- 约束：音频清晰、无背景噪音、单人语音；台词与口型驱动时长匹配；随机模式由 TTS 按角色风格生成
- 格式：音频文件（mp3/wav，与成片时长匹配，可独立交付）

**范本内容**：

```
输入：
- 台词：[口播台词文本]
- 来源：[用户提供音频 / TTS 生成 / 随机]
- 音色：[音色参数，如 年轻女声 / 成熟男声]

TTS 生成提示（随机或指定音色时）：
用[音色描述]朗读以下台词，语速[快/中/慢]，情绪[自然/热情/沉稳]：
[台词文本]

输出：[音频文件路径]（mp3/wav，时长与成片匹配）
```

**样本特征摘要**：
- 结构：台词 → 来源选择 → 音色参数 → 生成/采集
- 风格：口播音频
- 逻辑：音频驱动口型（AOM4-03），缺省无时成片为静默视频
- 格式：输入清单 + TTS 提示词

> 要点：配音口播为可选次要要素，缺省「无」时跳过本任务，AOM4-03 也不激活。
