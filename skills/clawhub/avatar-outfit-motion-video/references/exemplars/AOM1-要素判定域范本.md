## AOM1 要素判定域范本

> 唯一入口。六要素正交判定 + 成片合成方式预判 + 主动索要素材，是后续所有域的校准锚点。

### 域任务要求

| 任务ID | 任务类型 | 必选组件 | 可选组件 | 组装顺序 | 约束 | 格式 |
|--------|---------|---------|---------|---------|------|------|
| AOM1-01 | 六要素判定 | 用户需求文本、六要素判定结果、使用模式识别、成片合成方式预判 | 素材采集（指定要素）、素材来源说明 | 需求读取→六要素逐一判定→模式识别→成片合成方式预判→主动提示素材采集→指定要素采集→输出判定方案 | 判定基于明确表述；六要素皆可指定/随机；主体缺省随机、次要缺省无；指定素材须清晰可用 | 判定方案表 + 待提供素材清单 |

### AOM1-01 六要素判定范本

**任务要求**：
- 必选组件：用户需求文本、六要素（头像/服装/动作/配音口播/背景/物品）判定结果、使用模式识别、成片合成方式预判（动作迁移/配音口播）
- 可选组件：素材采集（被判定为「指定」的要素，如音频/台词）、素材来源说明
- 组装顺序：需求读取 → 六要素逐一判定（必备主体先判、可选次要后判）→ 模式识别（全随机/半自动/全定制）→ 成片合成方式预判（动作迁移/配音口播）→ 主动提示素材采集 → 指定要素采集 → 输出判定方案
- 约束：判定基于用户明确表述；六要素皆可「指定」或「随机」；头像/服装/动作缺省默认随机；配音口播/背景/物品缺省默认「无」，启用时同样可指定/随机；指定素材须清晰可用
- 交互提示：判定完成后须主动列出待用户提供的素材清单——凡「指定」要素逐项索要对应素材（头像图/服装图/动作模板视频/配音音频或台词/背景图或场景描述/产品图），并明确说明「随机」要素无需提供、「无」要素直接跳过
- 格式：六要素判定方案（Markdown 表格：要素/主体·次要/指定·随机·无/依据/素材路径）+ 待提供素材清单

**范本内容**：

六要素判定方案：

```
| 要素 | 主体/次要 | 指定/随机/无 | 依据 |
|------|-----------|-------------|------|
| 头像 | 必备主体 | [指定/随机] | [用户明确提供 / 缺省默认随机] |
| 服装 | 必备主体 | [指定/随机] | [用户明确提供 / 缺省默认随机] |
| 动作 | 必备主体 | [指定/随机] | [用户明确提供 / 缺省默认随机] |
| 配音口播 | 可选次要 | [指定/随机/无] | [用户提供音频/台词 / 缺省默认无] |
| 背景 | 可选次要 | [指定/随机/无] | [用户提及场景 / 缺省默认无] |
| 物品 | 可选次要 | [指定/随机/无] | [用户提及手持产品 / 缺省默认无] |

使用模式：[全随机 / 半自动 / 全定制]
成片合成方式预判：[动作迁移 / 配音口播 / 两者结合]
扩展维度：配音口播 [指定/随机/无] + 背景 [指定/随机/无] + 物品 [指定/随机/无]
```

素材采集提示（判定后主动索要）：

```
待提供素材清单：
| 要素 | 判定 | 需用户提供 |
|------|------|-----------|
| 头像 | [指定] | 头像图（正面清晰照） |
| 服装 | [随机] | 无需提供（自动生成） |
| 动作 | [指定] | 动作模板视频（≤15 秒） |
| 配音口播 | [指定] | 音频文件或台词文本 |
| 背景 | [无] | 直接跳过 |
| 物品 | [指定] | 产品图（正面清晰照） |

「随机」要素无需提供；「无」要素直接跳过；「指定」要素须等素材到位后再进入生成域。
```

**样本特征摘要**：
- 结构：要素 × 主体·次要 × 指定或随机或无 × 依据（六行表）+ 模式结论 + 成片合成方式预判 + 扩展维度 + 素材采集提示
- 风格：客观判定表 + 交互提示清单
- 逻辑：六要素皆可指定/随机；主体缺省默认随机、次要缺省默认无，不臆测用户意图；判定后先预判成片合成方式，再主动索要「指定」要素素材
- 格式：Markdown 表格

> 要点：全随机模式 = 三主体皆随机、三次要皆无；半自动 = 只给动作（原视频）；全定制 = 三主体皆指定。成片合成方式预判（动作迁移/配音口播）决定后续素材采集重点——配音口播需音频、动作迁移需动作视频。判定完成后务必先输出素材采集提示，再进入生成域。
