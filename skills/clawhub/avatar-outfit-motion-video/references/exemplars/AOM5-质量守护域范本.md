## AOM5 质量守护域范本

### 域任务要求

| 任务ID | 任务类型 | 必选组件 | 组装顺序 | 约束 | 格式 |
|--------|---------|---------|---------|------|------|

### AOM5-01 成片校验审查范本

**适用场景**：对成片做一致性校验与合规审查，交付。

**输入**：成片、三视图锚点。

**输出**：成片 + 校验审查结论。

**范本内容**：

```
## 一致性校验
- 身份（脸型/发型）：[一致 / 漂移]
- 服装（款式/颜色/材质）：[一致 / 漂移]
- 结论：[通过 / 需回退重生成]

## 合规审查
- 肖像：原视频长相已深度剥离 [是 / 否]
- 版权：素材来源合规 [是 / 否]
- 结论：[通过 / 需处理]

## 交付
- 成片：[路径]
- 审查结论：[通过 / 驳回]
```

**样本特征摘要**：
- 结构：一致性校验 → 合规审查 → 交付
- 风格：检查清单
- 逻辑：先一致性（质量守恒）后合规（硬约束），分步进行
- 格式：Markdown 检查表

> 要点：一致性漂移须回退 AOM4 重生成；合规是硬约束，不可跳过。
