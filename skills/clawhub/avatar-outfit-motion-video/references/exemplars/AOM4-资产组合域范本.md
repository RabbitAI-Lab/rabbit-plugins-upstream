## AOM4 资产组合域范本

### 域任务要求

| 任务ID | 任务类型 | 必选组件 | 可选组件 | 组装顺序 | 约束 | 格式 |
|--------|---------|---------|---------|---------|------|------|
| AOM4-01 | 三视图合成 | 头像（图或描述）、服装（图或描述）、三视图提示词、正面单图提示词 | 手持物品（图或描述）、固定种子、风格描述、手持姿势描述 | 垫图或描述融合→特征剥离→三视图生成→正面单图派生 | 三视角一致、手-物不穿模、固定种子 | PNG 三视图 + PNG 正面单图 |
| AOM4-02 | 动作迁移成片 | 三视图/正面单图、深度视频（或跳过）、动作描述 | 背景图、手持物品图、模型选择、时长、分辨率 | 路径判定→背景融合→动作迁移 | 云端优先、内置非 1:1、背景物品不漂移 | MP4 成片 |

### AOM4-01 三视图合成范本

**任务要求**：
- 必选组件：头像（图或描述，图来自 AOM2-01）、服装（图或描述，图来自 AOM2-02）、三视图提示词、正面单图提示词
- 可选组件：手持物品（图或描述，有物品时，图来自 AOM3-02）、固定种子、风格描述、手持姿势描述
- 组装顺序：头像+服装（+物品）垫图或描述融合 → 特征剥离指令 → 三视图（正/侧/背）生成（校准点）→ 派生正面单图（校准点）
- 约束：三视角身份/服装/比例一致；手持物品形态/握姿三视角一致、不穿模；正面单图与三视图角色完全一致；固定种子；物品缺失时跳过手持锁定
- 格式：PNG 三视图（1 张）+ PNG 正面单图（1 张，均可独立交付）

**适用场景**：一级组合——特征剥离法合成三视图（可含手持物品），并派生正面单图作首帧。

**输入**：头像（图1/描述，来自 AOM2-01）、服装（图2/描述，来自 AOM2-02）、可选手持物品（图3/描述，来自 AOM3-02）。

**输出**：正面/侧面/背面三视图 + 正面全身单图（均可独立交付）。

**范本内容**：

三视图合成（校准点）：

```
character turnaround sheet, three views of the same person standing side by side in a row:
front view, side view, back view, orthographic projection, full body, white background.
consistent face, hairstyle and outfit across all three views, same height and posture,
[手持物品描述，如 holding a [物品] in one hand, same grip in all views],
high detail, realistic photography style, studio lighting.
```

特征剥离指令（垫图通道解绑）：

```
主体1的面部特征与身份严格参考图片1。
主体1的服装款式与材质严格参考图片2。
主体1的手持物品形态与握姿严格参考图片3（有物品时）。
```

正面单图派生（校准点）：

```
full body portrait of a single [角色描述] standing front view, [发色] [发型],
[服装描述], [手持物品描述], neutral relaxed standing pose,
facing camera, white studio background,
realistic photography, high detail, consistent with the turnaround sheet character.
```

**样本特征摘要**：
- 结构：三视图合成（校准）→ 特征剥离指令 → 正面单图派生（校准）
- 风格：角色设定图（character sheet）
- 逻辑：头像/服装/物品三图垫入，锁定身份与手-物一致性，三视图是身份 ID 卡
- 格式：英文提示词 + 中文解绑指令

> 要点：三视图合成既「组合」头像/服装/物品，又「产出」新资产三视图，三视图再参与 AOM4-02/03/04 的下一级组合（递归嵌套）。

### AOM4-02 动作迁移成片范本

**任务要求**：
- 必选组件：三视图/正面单图（图或描述，图来自 AOM4-01）、深度视频（产物，来自 AOM2-03，或跳过）、动作描述
- 可选组件：背景图（来自 AOM3-01，生成式融合或后处理替换）、手持物品图（已在三视图锁定）、模型选择、时长、分辨率
- 组装顺序：分步1 路径判定（校准点：按三路径决策表判定）→ 分步2 背景融合（提示词指定或抠像替换）→ 分步3 动作迁移 → 成片
- 约束：路径依据三路径决策表（云端优先、无则降级内置）；本地需 NVIDIA 显卡 16GB+；内置动作自由发挥非 1:1；背景与物品保持与首帧一致、不漂移
- 交互提示：组合前主动询问用户「是否指定执行路径？」——用户指定则按指定路径，未指定则按三路径决策表自动选择并告知选择依据
- 格式：MP4 成片

**适用场景**：二级组合——按路径做动作迁移，融合背景与手持物品，合成成片。

**输入**：三视图/正面单图（来自 AOM4-01）、深度视频（来自 AOM2-03，或跳过）、动作描述、可选背景图、可选手持物品图。

**输出**：复刻或自由发挥动作、背景与手持物品稳定的成片。

**范本内容**：

路径判定（分步1，基元内校准点，规则见上方「三路径决策表」）：

```
| 路径 | 条件 | 选择 |
|------|------|------|
| 云端连接器（AI-HIVE/可灵/Picset） | 已连接任一 | 优先 |
| 本地 ComfyUI | 有 NVIDIA 显卡 16GB+ | 次选 |
| 内置 VideoGen | 以上皆无 | 兜底 |
```

主动提示：「是否指定执行路径？」——用户指定则按指定，未指定则按上表自动选择并告知依据。

云端动作迁移（1:1 复刻，含背景/物品）：

```
一位[角色描述]，保持[服装描述]，[手持物品描述]，
站在[背景描述]中，跟随参考深度视频做出[动作描述]的动作，动作流畅，
正面机位，写实摄影风格，影棚打光，背景与手持物品保持稳定，画面连贯。
```

内置 VideoGen 降级（动作自由发挥，含背景/物品）：

```
A [角色描述] wearing [服装描述], [holding a [物品]], in [背景描述], [动作描述],
natural full body motion, front view, realistic photography, studio lighting,
stable background and prop, smooth continuous motion.
```

背景替换两通道（`[背景描述]` 的两种实现）：
1. **生成式融合**：合成提示词中直接描述背景，一次成片。
2. **后处理替换**：成片抠像→叠加 AOM3-01 背景图→合成，适合指定/参考图背景。

**样本特征摘要**：
- 结构：路径判定（基元内分步）→ 云端模板 → 降级模板 → 背景替换两通道
- 风格：影视镜头 + 短视频
- 逻辑：路径判定降为基元内分步校准点；云端 1:1 复刻、降级自由发挥
- 格式：决策表 + 中文/英文提示词

### AOM4-03 配音口播对口型范本

**任务要求**：
- 必选组件：正面单图（图或描述，图来自 AOM4-01）、音频文件（产物，来自 AOM3-03）、音频对口型模型（SadTalker / Wan2.2 对口型等）
- 可选组件：背景图（来自 AOM3-01，生成式融合或后处理替换）、手持物品图（已在正面单图锁定）、口型强度、表情参数、时长
- 组装顺序：分步1 路径判定（校准点：按三路径决策表判定）→ 分步2 背景融合 → 分步3 口型驱动 → 成片
- 约束：音频清晰、单人正面；模型须支持音频对口型；无需深度视频（跳过 AOM2-03）；背景与物品保持与首帧一致、不漂移
- 交互提示：组合前主动询问用户「是否指定执行路径？」——用户指定则按指定路径，未指定则按三路径决策表自动选择并告知选择依据
- 格式：MP4 成片（口型与音频同步）

**适用场景**：二级组合——数字人口播，音频驱动口型，融合背景与手持物品。

**输入**：正面单图（来自 AOM4-01）、音频（来自 AOM3-03）、背景图（可选）、对口型模型。

**输出**：口型与音频同步、背景与手持物品稳定的成片。

**范本内容**：

```
路径判定（分步1，基元内校准点）：云端连接器 / 本地对口型模型 / 内置（规则同 AOM4-02 决策表）

主动提示：「是否指定执行路径？」——用户指定则按指定，未指定则按决策表自动选择并告知依据。

输入：
- 角色图：[正面单图路径]（来自 AOM4-01，可含手持物品）
- 背景图：[背景图路径]（来自 AOM3-01，可选）
- 音频：[配音口播音频路径]（来自 AOM3-03）
- 模型：SadTalker / Wan2.2 对口型 等

输出：口型同步、背景与手持物品稳定的数字人口播视频
```

**样本特征摘要**：
- 结构：路径判定 → 角色图 + 背景图 + 音频 → 口型驱动 → 成片
- 风格：数字人口播
- 逻辑：音频驱动（无需深度视频，跳过 AOM2-03），背景/物品随首帧锁定
- 格式：决策表 + 输入清单

> 要点：三视图合成是一级组合（角色），动作迁移与配音口播是二级组合（成片），二选一；口播带货常在正面单图锁定手持产品 + 背景替换实现品牌植入。

### AOM4-04 自由组合范本

**任务要求**：
- 必选组件：任意要素资产（头像图/服装图/三视图/深度视频/背景图/物品图/音频，来自 AOM2/AOM3/AOM4-01）或要素描述（提示词）、组合目标描述
- 可选组件：组合方式（提示词组合 / 产物组合）、风格参数、固定种子
- 组装顺序：组合目标确定 → 要素选择（资产或描述）→ 组合方式判定（提示词组合 / 产物组合）→ 组合执行 → 产物校验
- 约束：提示词组合融合要素描述为单一提示词、一次生成、无需中间产物；产物组合先生成要素中间产物、再垫图合成；两种方式产物一致；静态产物可直接交付、无需成片质检
- 组合建议：单要素（头像=角色头像图、服装=服装平铺图、三视图=角色设定图/身份 ID 卡、深度视频=动作控制信号、背景=场景背景图、物品=产品白底图、音频=口播音频素材）；双要素（头像+服装=换装图、服装+背景=服装场景展示图、物品+背景=产品场景图、头像+背景=头像场景图、服装+物品=穿搭配饰图、头像+物品=代言人持产品图、头像+音频=音频头像）；三要素及以上（头像+服装+背景=角色场景图、头像+服装+物品=模特手持产品图、服装+背景+物品=场景道具展示图、头像+服装+背景+物品=完整角色场景图）；各产物均有丰富变体应用
- 交互提示：主动提示用户「要组合哪些要素、产出什么、用提示词组合还是产物组合」——列举可用要素（资产或描述），并给出上述组合建议供选择
- 格式：静态产物（PNG，可独立交付）

**适用场景**：把任意要素自由组合为静态产物，是固定组合之外的通用通道。支持「提示词组合」与「产物组合」两种方式。

**输入**：任意要素资产（头像图/服装图/三视图/深度视频/背景图/物品图/音频）或要素描述（提示词）+ 组合目标。

**输出**：静态产物（PNG，可独立交付）。

**范本内容**：

```
主动提示：「要组合哪些要素、产出什么、用提示词组合还是产物组合？」——列举可用要素（资产或描述），支持任意子集组合。

自由组合建议（要素 → 产物 → 变体应用，按要素数分组）：

单要素（独立交付）：
| 组合 | 产物 | 变体应用建议 |
|------|------|-------------|
| 头像 | 角色头像图 | 社交头像、虚拟形象、游戏角色脸、直播封面 |
| 服装 | 服装平铺图 | 电商商品图、服装设计稿、穿搭素材库 |
| 三视图 | 角色设定图 / 身份 ID 卡 | 游戏原画、动漫角色设定、虚拟主播形象 |
| 深度视频 | 动作控制信号 | 跨角色动作迁移、动画动作参考、游戏动作库 |
| 背景 | 场景背景图 | 电商场景、影视背景、虚拟空间、壁纸 |
| 物品 | 产品白底图 | 电商主图、产品目录、设计素材库 |
| 音频 | 口播音频素材 | 视频配音、播客内容、有声书朗读 |

双要素：
| 组合 | 产物 | 变体应用建议 |
|------|------|-------------|
| 头像 + 服装 | 换装图 / 穿搭图 | 电商模特试穿、虚拟试衣间、OOTD 分享、设计预览 |
| 服装 + 背景 | 服装场景展示图 | 详情页场景图、品牌宣传大片、社媒内容 |
| 物品 + 背景 | 产品场景图 | 电商主图、广告海报、详情页使用场景 |
| 头像 + 背景 | 头像场景图 | 社交封面、虚拟形象场景、个人品牌页 |
| 服装 + 物品 | 穿搭配饰图 | 穿搭推荐、配饰展示、种草图 |
| 头像 + 物品 | 代言人持产品图 | 直播封面、代言海报、小红书种草图 |
| 头像 + 音频 | 音频头像 / 静态口播 | 语音社交、数字人、口播配图 |

三要素及以上：
| 组合 | 产物 | 变体应用建议 |
|------|------|-------------|
| 头像 + 服装 + 背景 | 角色场景图 | 游戏角色立绘、动漫插画、虚拟代言人 |
| 头像 + 服装 + 物品 | 模特手持产品图 | 直播带货封面、商品代言、种草内容 |
| 服装 + 背景 + 物品 | 场景道具展示图 | 场景化陈列、道具展示、门店物料 |
| 头像 + 服装 + 背景 + 物品 | 完整角色场景图 | 营销大片、品牌代言、沉浸式场景 |

提示词组合（描述融合，一次生成，无需中间产物）：
一位[角色描述]穿着[服装描述]站在[背景描述]中，
[姿势/光线描述], realistic photography, high detail.
（直接融合头像/服装/背景的「描述」为单一提示词，不先各自生成图）

产物组合（垫图合成，先有中间产物）：
将[要素A图]与[要素B图]合成为[目标描述]，
保持各要素形态一致，光线与透视统一，seamless blending, high detail.
```

**样本特征摘要**：
- 结构：主动提示 → 组合建议表（要素/产物/变体应用）→ 提示词组合 → 产物组合
- 风格：图像合成
- 逻辑：提示词组合融合描述一次生成（轻量快速、无中间产物），产物组合先产要素再合成（精确可复用），任意子集自由组合、可直接交付
- 格式：组合建议表（含变体应用）+ 两种组合提示词

> 要点：自由组合是固定组合之外的通用通道，有提示词组合（描述融合、无中间产物）与产物组合（垫图合成）两条路径；产物为静态图、独立交付，不走 AOM5 成片质检。
