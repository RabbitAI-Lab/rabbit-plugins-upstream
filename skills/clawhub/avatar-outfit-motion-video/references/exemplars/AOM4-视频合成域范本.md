## AOM4 视频合成域范本

### 域任务要求

| 任务ID | 任务类型 | 必选组件 | 组装顺序 | 约束 | 格式 |
|--------|---------|---------|---------|------|------|
| AOM4-01 | 路径判定 | 可用资源清单、需求类型 | 合成方式判定→三路径评估→决策 | 优先云端、无则降级 | 路径决策结果 |
| AOM4-02 | 动作迁移成片 | 三视图/正面单图、深度视频、路径、动作描述 | 按路径分支→动作迁移→成片 | 云端 AI-HIVE 优先、内置非 1:1 | MP4 成片 |
| AOM4-03 | 音频对口型 | 正面单图、音频、对口型模型 | 单图→音频→口型驱动→成片 | 音频清晰、单人正面 | MP4 成片 |

### AOM4-01 路径判定范本

**适用场景**：判定合成方式（动作迁移 / 音频对口型）与执行路径（云端 / 本地 / 内置）。

**输入**：可用资源清单（连接器状态、显卡、内置能力）、需求类型。

**输出**：合成方式 + 路径决策结果。

**范本内容**：

```
第一步：判定合成方式
| 需求 | 合成方式 |
|------|---------|
| 复刻动作 / 舞蹈 / 走秀 | 动作迁移（需深度视频） |
| 说话 / 口播 / 对口型 | 音频对口型（需音频） |

第二步：判定执行路径
| 路径 | 条件 | 选择 |
|------|------|------|
| 云端连接器（AI-HIVE/可灵/Picset） | 已连接任一 | 优先 |
| 本地 ComfyUI / 对口型模型 | 有 NVIDIA 显卡 16GB+ | 次选 |
| 内置 VideoGen | 以上皆无 | 兜底 |

决策：合成方式 [动作迁移/音频对口型]，路径 [所选路径]，依据 [资源情况]。
```

**样本特征摘要**：
- 结构：合成方式判定 → 执行路径判定 → 决策结论
- 风格：两级决策表
- 逻辑：先按需求定合成方式，再按资源定执行路径
- 格式：Markdown 表格

### AOM4-02 动作迁移成片范本

**适用场景**：按判定路径做动作迁移，合成成片。

**输入**：三视图/正面单图、深度视频（或跳过）、动作描述。

**输出**：复刻或自由发挥动作的成片。

**范本内容**：

云端动作迁移（1:1 复刻，深度视频 + 三视图锁身份）：

```
一位[角色描述]，保持[服装描述]，跟随参考深度视频做出[动作描述]的动作，动作流畅，
正面机位，写实摄影风格，影棚打光，画面连贯。
```

内置 VideoGen 降级（动作自由发挥，正面单图为首帧）：

```
A [角色描述] wearing [服装描述], [动作描述], natural full body motion,
front view, realistic photography, studio lighting, smooth continuous motion.
```

动作描述词库（`[动作描述]` 占位符可填）：

| 中文 | 英文 |
|------|------|
| 跳舞 / 跟着节奏摆动 | dancing / swaying to a rhythm |
| 走秀 / 台步 | catwalk / runway walk |
| 口播 / 说话 | speaking / lip-sync |
| 摆姿势 / 转身 | posing / turning around |
| 运动 / 健身 | working out / exercising |

**样本特征摘要**：
- 结构：云端模板 → 降级模板 → 动作词库
- 风格：影视镜头 + 短视频
- 逻辑：云端用深度视频提供动作、prompt 只描述外观；降级用首帧锁身份、文字描述动作
- 格式：中文提示词 + 英文提示词 + 词库表

> 要点：云端与降级的关键差异——云端 1:1 复刻动作，降级动作自由发挥。

### AOM4-03 音频对口型范本

**适用场景**：数字人口播，音频驱动的口型同步，让角色"开口说话"。

**输入**：正面单图、音频文件（语音/台词）、对口型模型。

**输出**：口型与音频同步的成片。

**范本内容**：

```
输入：
- 角色图：[正面单图路径]（来自 AOM2-03）
- 音频：[语音/台词音频路径]
- 模型：SadTalker / Wan2.2 对口型 等

输出：口型同步的数字人口播视频
```

**样本特征摘要**：
- 结构：角色图 + 音频 → 口型驱动 → 成片
- 风格：数字人口播
- 逻辑：无需深度视频（跳过 AOM3），音频直接驱动口型
- 格式：输入清单 + 输出说明

> 要点：音频对口型与动作迁移是两种并列的合成方式——前者音频驱动（说话），后者视频驱动（动作）；两者在 AOM4-01 路径判定时二选一。
