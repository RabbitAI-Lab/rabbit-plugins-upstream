## 🎯 为什么选择这个 Skill？

| 痛点 | 解决方案 |
|------|---------|
| 🧩 B 端产品复杂度高，缺少系统方法论 | **11 阶段完整生命周期**：从战略洞察到运营迭代，覆盖产品全链路 |
| 🔐 权限/审批/多租户设计门槛高 | **B 端核心深度**：RBAC/ABAC/ReBAC · BPMN 2.0 审批流 · 多租户架构 · 数据字典 |
| 🤖 AI 产品设计缺乏范式 | **AI 产品全栈**：LLM 能力边界 · RAG 7 大模式 · Agent 6 大架构 · Prompt Engineering |
| 📄 文档产出慢，模板不专业 | **10+ 专业模板**：PRD · BRD · MRD · FRD · 竞品分析 · 用户研究……填内容即用 |
| 💰 定价和商业化缺乏方法论 | **SaaS 定价两大维度 + 七步定价法 · PLG 产品驱动增长 · 2026 中国 SaaS 趋势** |

## 📦 快速开始

```bash
cp -r b2b-pm-workbench ~/.claude/skills/
```

**触发方式**：直接描述需求，自动匹配阶段和方法论：
- "帮我写一份企业 CRM 的 PRD"
- "设计一个审批流引擎"
- "做 B 端竞品分析"
- "设计 AI 客服 Agent 的产品方案"
- "做 SaaS 产品定价方案"
