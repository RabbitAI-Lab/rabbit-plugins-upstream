## 5. 审批流与工作流设计

### 5.1 审批流程

```
[发起申请] → [部门负责人审批] → [财务审批(金额>5000)] → [总经理审批(金额>50000)] → [完成]
                                     ↓(驳回)                  ↓(驳回)
                                  [返回发起人修改]          [返回发起人修改]
```

### 5.2 审批节点配置

| 节点 | 审批人确定方式 | 审批规则 | 超时处理 |
|------|--------------|---------|---------|
| 部门负责人 | 申请人的直属上级 | 默认通过 | 48h超时自动提醒 |
| 财务审批 | 指定角色：财务审批岗 | 金额≤5000自动跳过 | 24h超时升级到财务总监 |
| 总经理审批 | 指定岗位：总经理 | 金额≤50000自动跳过 | 72h超时自动提醒 |

### 5.3 审批操作

| 操作 | 说明 | 权限 |
|------|------|------|
| 通过 | 流转到下一节点 | 当前节点审批人 |
| 驳回 | 返回发起人，可指定驳回到哪个节点 | 当前节点审批人 |
| 转审 | 转给其他人审批 | 当前节点审批人 |
| 加签 | 增加额外审批人（前加签/后加签） | 当前节点审批人 |
| 撤回 | 发起人撤回申请 | 发起人（仅审批中） |
| 催办 | 发送催办通知 | 发起人 |

## v1.1.0 新增: SaaS定价模型与PLG要素

### 定价模型设计（七步定价流程）
| 步骤 | 内容 | 输出 |
|------|------|------|
| 1. 价值量化 | 客户使用产品能省多少钱/赚多少钱？ | 价值量化表 |
| 2. 定价维度 | 按用量(API调用/存储/用户数)还是按功能复杂度？ | 定价维度矩阵 |
| 3. 竞品对标 | 竞品怎么定价？价格锚点在哪？ | 竞品价格对比 |
| 4. 套餐设计 | Free/Starter/Pro/Enterprise 各包含什么？ | 套餐对比表 |
| 5. 价格锚定 | 哪个套餐是"锚"？哪个是"利润中心"？ | 价格心理学策略 |
| 6. 试用转化 | 免费试用→付费的转化路径设计 | 转化漏斗设计 |
| 7. 定价测试 | A/B测试不同价格点的转化率 | 定价实验计划 |

### PLG产品驱动增长要素
| 要素 | 设计要点 | 指标 |
|------|---------|------|
| 免-体验 | 注册后5分钟内体验核心价值 | Time-to-Value <5min |
| 病毒传播 | 协作/分享功能自然带来新用户 | 病毒系数>1.0 |
| 自助升级 | 使用量到达阈值自动提示升级 | 升级转化率>5% |
| 产品内教育 | 引导式Onboarding替代培训视频 | 激活率>60% |
| 数据驱动 | 基于使用行为数据优化产品 | 留存率>40%(M1) |
