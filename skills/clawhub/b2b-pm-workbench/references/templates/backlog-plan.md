# B端产品需求池与版本规划模板

## 一、需求池管理

### 1.1 需求池Excel字段标准

使用 `xlsx` skill 生成需求池Excel，包含以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| 需求ID | REQ-YYYY-序号 | 唯一标识，如 REQ-2026-0001 |
| 需求标题 | 文本 | 一句话描述需求 |
| 需求来源 | 枚举 | 客户反馈/销售反馈/内部规划/竞品对标/用户调研/战略要求 |
| 来源详情 | 文本 | 来源的具体客户/人/场景 |
| 客户重要度 | 枚举 | KA战略/高价值/中等/普通 |
| 涉及角色 | 多选 | 使用该功能的目标角色 |
| 需求类型 | 枚举 | 新功能/功能优化/Bug修复/技术优化/体验优化 |
| 需求阶段 | 枚举 | 原始需求/已澄清/方案设计中/待评审/已排期/开发中/已上线 |
| KANO分类 | 枚举 | 基础型/期望型/兴奋型/无差异型 |
| 优先级 | P0/P1/P2/P3 | P0=必须做(本版本), P1=应该做(下版本), P2=可以做(远期), P3=不做 |
| 优先级评分 | 0-100 | 基于加权评分法自动计算 |
| 关联功能模块 | 枚举 | 如：采购管理/审批流/权限管理等 |
| 预估工作量 | 人天 | 粗略估计 |
| 需求提出时间 | 日期 | |
| 期望上线时间 | 日期 | 客户期望（如有） |
| 承诺客户 | 文本 | 已承诺交付的客户（如有），空白=未承诺 |
| 评审结论 | 文本 | 通过/驳回/待确认 |
| 备注 | 文本 | 补充信息 |

### 1.2 需求池维护规则

```
1. 需求提出后24小时内录入需求池
2. 每周一同步需求池状态到产品和开发
3. 每月清理一次长期无进展的需求（标记为P3或关闭）
4. 客户承诺的需求必须标注，不能丢
5. 需求ID一旦分配，不重复使用
```

## 三、优先级评分计算器

### 加权评分法

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 客户付费意愿 | 25% | 10=客户明确愿意额外付费；5=间接影响成单；0=无付费关联 |
| 战略匹配度 | 20% | 10=直接支撑战略目标；5=间接相关；0=无关 |
| 对NRR贡献 | 15% | 10=显著提升NRR；5=有一定贡献；0=无贡献 |
| 技术可行性 | 15% | 10=技术成熟，工作量小；5=需技术验证；0=技术风险极高 |
| 竞争覆盖 | 10% | 10=竞品都有且客户必比；5=竞品有但不关键；0=竞品没有 |
| 实施复杂度 | 10% | 10=极易实施(1人周)；5=中等(2-4人周)；0=高复杂度(>8人周) |
| 对NDR贡献 | 5% | 10=直接防止流失；5=有留存效果；0=无留存影响 |

### 快速优先级（MoSCoW法）

- **Must Have**：没有这个产品不可用（基础型需求）
- **Should Have**：重要但可通过变通方案暂时解决（期望型需求）
- **Could Have**：有更好，没有也能接受（兴奋型需求）
- **Won't Have**：明确不做（本期不做的都放这里）

## 四、版本发布检查清单

```
上线前必须完成：
□ PRD已评审通过
□ 技术方案已评审

□ 测试用例已评审
□ P0用例全部通过
□ P0 Bug全部修复
□ 数据迁移脚本已准备（如有）
□ 回滚方案已准备
□ 帮助文档已更新
□ 发布公告已准备
□ 客户通知已发出（如涉及已有客户）
□ 监控告警已配置
□ 灰度方案已确定（如有）
```

## v1.1.0 新增: PLG优先级排序

### PLG Backlog优先级矩阵
| 优先级 | 类型 | 示例 | 预期影响 |
|--------|------|------|---------|
| P0 | 激活阻断 | 注册流程卡住、核心功能不可用 | 直接影响激活率 |
| P0 | 付费阻断 | 无法升级、支付失败 | 直接影响收入 |
| P1 | 激活优化 | Onboarding引导、首次体验 | 提升激活率20% |
| P1 | 病毒传播 | 分享功能、协作邀请 | 提升病毒系数 |
| P2 | 留存提升 | 使用提醒、周报 | 提升留存率 |
| P2 | 转化优化 | 定价页优化、PQL评分 | 提升转化率 |
| P3 | 体验优化 | UI美化、性能优化 | 长期竞争力 |

### PLG Sprint规划
| Sprint | 主题 | 核心目标 | 关键指标 |
|--------|------|---------|---------|
| Sprint 1-2 | 激活优化 | 注册→首次体验<5分钟 | 激活率>40% |
| Sprint 3-4 | 病毒传播 | 分享功能上线 | 病毒系数>0.5 |
| Sprint 5-6 | 付费转化 | 自助升级流程 | 免费→付费>3% |
| Sprint 7-8 | 留存提升 | 使用提醒+周报 | M1留存>40% |
