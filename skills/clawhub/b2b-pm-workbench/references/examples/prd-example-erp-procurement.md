## 1. 背景与目标

### 1.1 需求背景

公司在为XX集团做私有化部署时，客户明确提出缺少采购管理功能。经调研，现有30+家付费客户中，有12家直接提到了采购管理需求，8家在用竞品的情况下因无采购模块而流失。

内部产品委员会决策：将采购管理作为Q3重点模块上线。

### 1.2 商业目标

| 目标维度 | 指标 | 当前值 | 目标值(Q4) |
|---------|------|--------|----------|
| 客户数 | 使用采购模块的付费客户 | 0 | 15家 |
| 收入 | 采购模块增值收入 | ¥0 | ¥120万/年 |
| 留存 | 存量客户增购率 | 0% | 30% |

### 1.3 产品一句话

> 企业采购人员可以在一个平台完成从采购申请→询价比价→采购订单→收货入库→对账结算的全流程管理，将采购周期从平均15天缩短至3天，并确保每一次采购都合规可控。

## 3. 核心业务流程

### 3.1 采购全流程（泳道图描述）

```
采购申请员 → 采购员 → 采购主管 → 供应商 → 仓管 → 财务
    │          │         │         │       │      │
    ├─发起申请─┤         │         │       │      │
    │          ├─审批────→         │       │      │
    │          │   ←────通过/驳回──        │       │      │
    │          ├─询价比价─→       │       │      │
    │          │   ←────报价────          │       │      │
    │          ├─生成采购单──→             │       │      │
    │          │   ←────确认订单──────────→│       │      │
    │          │         │         ├─发货─→       │      │
    │          │         │         │       ├─收货入库─┤
    │          │         │         │       │   质检  │
    │          ├─对账─────────────────────────────→│
    │          │         │         │       │   ├─结算─┤
    │          │         │         │       │   │ 付款 │
```

### 3.2 关键业务规则

| 规则ID | 描述 |
|--------|------|
| BR-001 | 采购金额>5000元，必须3家以上比价 |
| BR-002 | 单笔金额>50000元，需要总经理加签 |
| BR-003 | 收货时数量偏差>5%，系统预警并阻塞入库 |
| BR-004 | 供应商黑名单中的供应商不可参与询价 |
| BR-005 | 合同付款比例和金额不得超过合同总额 |

## 4. 功能详细说明

### 4.1 功能架构

```
采购管理模块
├── 采购申请
│   ├── 我的申请（列表/新增/查看/撤回）
│   ├── 申请审批（待审/已审）
│   └── 申请模板（常用采购项模板）
├── 采购执行
│   ├── 采购单管理（待处理/执行中/已完成）
│   ├── 询价比价（发起询价/报价对比/比价报告）
│   └── 订单跟踪（发货/物流/预计到货）
├── 供应商管理
│   ├── 供应商库（列表/详情/评价/黑名单）
│   ├── 供应商准入（注册/审核/资质管理）
│   └── 供应商绩效（评分/交易记录/不良记录）
├── 收货入库
│   ├── 收货单（待收货/已收货）
│   ├── 质检（合格/不合格/让步接收）
│   └── 入库确认（自动生成库存记录）
└── 对账结算
    ├── 对账单（生成/确认/差异处理）
    ├── 付款计划（按合同/按进度）
    └── 发票管理（登记/核验/抵扣）
```

### 4.2 核心页面：采购申请列表

**页面布局：**
```
┌──────────────────────────────────────────────────────┐
│ 采购申请                                                │
│                                                        │
│ [搜索申请编号/名称...]  [状态▼] [日期范围▼]  [搜索]         │
│                                                        │
│ [新建申请] [批量提交]                                    │
│                                                        │
│ ☐ |申请编号     |标题          |金额    |状态  |申请人|时间 │
│ ☐ |PR20260607001|办公电脑采购   |¥50,000|审批中|李四  |06-07│
│ ☐ |PR20260607002|打印纸采购     |¥500   |已通过|王五  |06-07│
│ ☐ |PR20260606001|服务器扩容     |¥80,000|已驳回|赵六  |06-06│
│                                                        │
│ 已选2项 [批量提交]       共128条  < 1 2 3 ... 7 >        │
└──────────────────────────────────────────────────────┘
```

**字段说明：**

| 字段 | 类型 | 必填 | 校验 | 说明 |
|------|------|------|------|------|
| 申请标题 | 文本 | 是 | 2-100字符 | 采购事项简述 |
| 采购类型 | 下拉 | 是 | 枚举值 | 办公用品/IT设备/服务/原材料/其他 |
| 采购金额 | 数字 | 是 | 0.01-99999999.99 | 预估金额，提交审批用 |
| 申请部门 | 下拉 | 是 | 关联组织架构 | 默认当前用户部门 |
| 期望交付日期 | 日期 | 否 | ≥今天 | |
| 采购明细 | 表格 | 是 | 至少1行 | 名称/规格/数量/单价/总价 |
| 申请理由 | 文本域 | 是 | 10-500字符 | 说明采购必要性 |
| 附件 | 文件 | 否 | ≤10MB×3 | 报价单/合同/审批文件 |

**交互规则：**
- 新建表单：弹出全屏/侧边表单，分"基本信息"和"采购明细"两步
- 保存草稿：所有字段均可为空，跳过校验
- 提交：执行全量校验，通过后生成申请编号，进入审批流
- 撤回：仅"审批中"状态可撤回，撤回后回到"草稿"

### 4.3 核心页面：询价比价

**功能描述：**
采购员向多家供应商发起询价，收集报价后进行比价分析，选择最优供应商。

**询价单字段：**

| 字段 | 说明 |
|------|------|
| 询价物料 | 从采购申请自动带入，可增删 |
| 询价供应商 | 从供应商库选择，最少2家，必须满足"非黑名单" |
| 询价截止时间 | 供应商需在此时间前提交报价 |
| 报价说明 | 对供应商的补充要求 |

**比价报告：**

| 维度 | 供应商A | 供应商B | 供应商C |
|------|--------|--------|--------|
| 报价总额 | ¥48,500 | ¥51,000 | ¥47,200 |
| 交货周期 | 7天 | 5天 | 10天 |
| 付款方式 | 货到付款 | 预付30% | 月结 |
| 历史评分 | 4.5/5 | 4.2/5 | 4.8/5 |
| 综合推荐 | ⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐ |

**选择后流程：** 选中供应商 → 系统自动生成采购订单 → 采购主管审批 → 发送给供应商确认

## 5. 审批流设计

### 采购申请审批流

```
[发起申请] 
    → [部门负责人审批] (必过)
        → [采购主管审批] (必过)  
            → [财务审批] (金额>5000触发)
                → [总经理审批] (金额>50000触发)
                    → [完成，生成采购单]
```

### 审批规则

| 节点 | 审批人 | 超时 | 可执行操作 |
|------|--------|------|-----------|
| 部门负责人 | 申请人的直属上级 | 48h提醒 | 通过/驳回/转审 |
| 采购主管 | 采购主管角色 | 24h提醒 | 通过/驳回/转审/加签 |
| 财务审批 | 财务审批角色 | 24h升级 | 通过/驳回 |
| 总经理 | 总经理角色 | 72h提醒 | 通过/驳回 |

## 8. 验收标准（节选）

| 编号 | 验收项 | 验收标准 |
|------|--------|---------|
| AC-001 | 采购申请提交 | 所有必填项填写后，提交成功，审批流启动 |
| AC-002 | 比价报告 | 至少选择2家供应商，自动生成比价表格 |
| AC-003 | 金额>5000触发财务审批 | 财务收到审批通知，可以审批 |
| AC-004 | 金额≤5000跳过财务审批 | 采购主管通过后直接完成，不经过财务节点 |
| AC-005 | 供应商黑名单 | 黑名单中的供应商不在询价列表可选范围 |
| AC-006 | 收货数量偏差 | 偏差>5%时系统预警，阻止入库确认 |
| AC-007 | 审计日志 | 所有CUD操作可在审计日志中查询，不可删除 |
