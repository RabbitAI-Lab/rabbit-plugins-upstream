# Listing Optimizer Lite — 深度 FAQ

本文档覆盖边缘场景、工具兼容、安全合规等深度问题。

## 基础类

**Q1：Lite 版有没有每天/每月的使用次数限制？**
完全没有。Lite 版不设调用次数上限，也不收取任何费用。你可以一天优化 100 个产品，每次一个。唯一的限制是 AI 模型的上下文窗口——单轮对话不要塞太多产品信息即可。

**Q2：中文产品名优化成英文 Listing 时，品牌名要翻译吗？**
品牌名一般不翻译，保留原文。产品名中的描述性部分需要翻译。如果你有标准英文产品名，可以提供；没有的话 AI 会做合理翻译。

**Q3：可以优化多个变体（如不同颜色/尺寸）吗？**
Lite 版单次只支持一个产品变体。如果你有红/蓝/黑三个颜色，可以分别跑三次，或描述为"三色可选"让 AI 在卖点中体现。

**Q4：生成的卖点超过了平台限制怎么办？**
亚马逊单条 bullet 限制 500 字符，Lite 版默认每条在 80-150 字符内。如果超了，你可以说"第一条卖点太长，帮我缩短到 100 字符以内"。

## 平台专项类

**Q5：亚马逊加拿大站、墨西哥站有什么特殊规则？**
加拿大站同美国站规则，但关键词应考虑中性和法裔加拿大人的搜索习惯。墨西哥站标题用西班牙语为佳。Lite 版目前不支持小语种深度优化。

**Q6：Shopee 泰国/印尼站的标题可以用英文吗？**
建议使用当地语言以获得最佳搜索排名。Lite 版当前不支持泰语/印尼语的本地化优化。如果你有英文标题，AI 可以帮你优化英文版本，但建议找本地化团队翻译。

**Q7：亚马逊的「商品描述」和「A+ 内容」有什么区别？为什么 Lite 版不支持 A+？**
商品描述是纯文本段落，A+ 内容是带图片排版的增强型描述。A+ 需要图片设计和模板搭建，超出 Lite 版的文字优化范围。Pro 版规划中会支持 A+ 文案。

**Q8：Lazada 和 Shopee 的后端关键词在哪里填？**
Lazada 和 Shopee 没有独立的"后端关键词"字段。关键词主要通过标题和描述自然融入。Lite 版生成的"后端搜索词"仅适用于亚马逊，其他平台会将关键词分配建议放在优化说明中。

## 内容质量类

**Q9：同一产品让 AI 优化两次，结果不同怎么办？**
AI 生成有随机性，两次结果可能不完全一样。如果你喜欢第一次的版本，直接告诉 AI"用刚才第一版的写法，把尺寸改一下"。

**Q10：AI 生成的描述和竞品太像了怎么办？**
因为 AI 基于行业最佳实践和通用表达方式，相似度无法完全避免。建议做以下调整：
- 加入你的品牌特有故事或卖点
- 换一种表达逻辑顺序
- 使用同义词替换部分高频词

**Q11：关键词里包含品牌词（如 Nike / Apple）可以吗？**
❌ 不可以。标题、描述、后端关键词中都不要加入与你无关的品牌词，这违反了平台规则，可能导致 Listing 下架或账号受限。

## 技术/兼容类

**Q12：这个 Skill 跟哪些 AI 平台兼容？**
这是 OpenClaw 生态的 Skill，理论上兼容所有支持 Markdown 格式 SKILL.md 的 AI 代理平台。具体表现为 LLM 阅读 SKILL.md 后按规则执行，不依赖任何特定后端。

**Q13：有没有 API 可以批量调用？**
Lite 版没有 API 接口。如果你需要批量处理，可以：
- 自行编写脚本调用 LLM API 并传入本 SKILL.md 作为 system prompt
- 或等待 Pro 版推出

**Q14：优化结果可以导出为 Excel/CSV 吗？**
目前不直接支持导出。你可以复制结果粘贴到自己的文档或表格中。每次输出采用固定结构，便于批量手动粘贴。

**Q15：我用的模型不支持中文怎么办？**
SKILL.md 是中英双语。如果你用的模型只支持英文，请用英文触发短语（"Optimize this listing: ..."），AI 会根据输入语言自动调整输出语言。

## 安全合规类

**Q16：AI 生成的 Listing 被举报侵权怎么办？**
AI 按行业通用规则生成，没有侵权意图。但以下情况需要注意：
- 如果输入中包含竞品的独特卖点表达，AI 可能借鉴了类似句式
- 建议在上架前用查重/侵权检测工具跑一遍
- 最终内容的法律责任由使用者承担

**Q17：输入的产品信息会被用来训练 AI 模型吗？**
在当前会话中处理的信息不会被持久化存储，也不会用于模型训练。但建议不要在输入中包含：
- 真实客户数据（姓名、电话、地址）
- 账号密码或 API Key
- 商业机密级别的独家产品配方

**Q18：使用了这个 Skill 后想停用，数据怎么处理？**
本 Skill 不做任何持久化存储。关闭对话即完成"数据删除"。你不需要执行任何额外操作。
