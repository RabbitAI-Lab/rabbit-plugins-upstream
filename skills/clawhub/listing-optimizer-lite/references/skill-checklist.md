# Listing Optimizer Lite — 快速自检清单

用这张清单检查你的 Listing 优化是否够专业。

## 输入阶段

- [ ] 产品名称是否已提供？
- [ ] 目标平台是否指定？（默认：Amazon）
- [ ] 目标市场是否指定？（默认：US）
- [ ] 核心卖点是否列出？（越详细越好）
- [ ] 品牌名是否提供？（可选但推荐）

## 标题检查

- [ ] ≤ 平台字符限制（Amazon 200 / Shopee 60 / Lazada 80）
- [ ] 核心搜索词位于前 80 字符内
- [ ] 无价格/促销语/emoji（对应平台规则）
- [ ] 首字母大写（介词/连词除外）
- [ ] 可读性：读起来像人工写的，不是关键词堆砌

## 卖点检查

- [ ] 每句以核心利益开头
- [ ] 使用主动语态和动词开头
- [ ] 每条 ≤ 150 字符
- [ ] 覆盖：功能→痛点→场景→差异化→保障
- [ ] 自然融入了目标关键词（不堆砌）

## 描述检查

- [ ] 三段式结构：品牌故事→优势展开→场景+保障
- [ ] 语气专业热情，不过度夸张
- [ ] 自然融入 3-5 个 LSI 关键词
- [ ] 无虚假承诺或未经证实的数据

## 关键词检查

- [ ] 覆盖不同词根（核心/属性/场景/用途）
- [ ] 无重复词根
- [ ] 无竞品品牌名
- [ ] Amazon US ≤ 250 字节
- [ ] 排除不相关的词

## 最终确认

- [ ] [Brand] 占位符已替换为真实品牌名
- [ ] 参数信息（尺寸/颜色/数量）准确无误
- [ ] 不同产品做了差异化措辞
- [ ] 核对过平台最新政策（AI 可能有滞后）
