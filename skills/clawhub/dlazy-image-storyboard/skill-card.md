## Description:

Guides creators from a brief through approved character designs and scripts to cinematic or narrative storyboards and generated images.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creative teams and individual creators use this skill to plan film, advertising, short-video, comic, or educational storyboards, approve characters and scripts, and generate visual panels.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installing a global third-party CLI may affect the local environment.

Mitigation: Review the CLI before installing, or use the documented npx alternative instead.

Risk: Prompts and selected media files are sent to dLazy's cloud service.

Mitigation: Avoid submitting confidential prompts or media unless cloud processing is approved.

Risk: Saving an API key in local CLI configuration leaves persistent credentials on disk.

Mitigation: Use the documented environment-variable option when a persistent key is undesirable.
