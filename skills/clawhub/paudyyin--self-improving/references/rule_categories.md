# 规则分类说明

## 规则类别

### avoid（避免操作）
从失败/错误中提取的规则，标识应该避免的操作模式。

**来源**：
- 追踪记录中 status=error 的操作
- .learnings/ 中标题包含"错误/失败/避免"的记录

**示例**：
- 避免在 file_write 中出现编码错误（置信度: 85%）
- 避免在 api_call 中出现超时错误（置信度: 72%）

### prefer（推荐做法）
从成功模式中提取的规则，标识值得推荐的操作模式。

**来源**：
- 追踪记录中 status=success 的操作
- .learnings/ 中不包含错误关键词的记录

**示例**：
- 优先使用 async/await 处理异步操作（置信度: 90%）
- 优先使用 pathlib 处理文件路径（置信度: 78%）

## 置信度计算

### 从追踪记录提取
- **avoid 规则置信度** = 该操作错误次数 / 总错误次数
- **prefer 规则置信度** = 该操作成功次数 / 总成功次数

### 从学习记录提取
- 默认置信度: 0.8（80%）
- 学习记录是人工确认的经验，置信度较高

## 阈值设置

| 规则类型 | 最低置信度 | 说明 |
|---------|-----------|------|
| avoid | 10% | 至少占总错误的10%才提取 |
| prefer | 20% | 至少占总成功的20%才提取 |
| learning | 80% | 固定值，人工确认 |

## 输出格式

### System Prompt 格式
用于注入到后续会话的 system prompt，直接指导 AI 行为。

### JSON 格式
用于程序间数据交换和存储。

### Markdown 格式
用于文档化和人工审阅。
