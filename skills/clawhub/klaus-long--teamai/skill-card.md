## Description:

Klaus Team is a Chinese-language WinClaw workflow for assembling ordered AI development roles to produce product requirements, design guidance, code, previews, tests, and packaged project outputs.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and product builders use this skill in WinClaw to coordinate selected AI roles for rapid prototypes, full-stack project scaffolds, backend APIs, design prototypes, code review, integration, and QA workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated project files, code, or shell commands may be incorrect or unsafe to run unchanged.

Mitigation: Review generated code and commands before execution, packaging, or release.

Risk: Preview recovery may stop an existing preview service.

Mitigation: Use preview recovery only in the intended workspace and confirm no important local preview process depends on that service.

Risk: Some backend outputs are described as in-memory mock data without a database.

Mitigation: Treat those outputs as prototypes unless persistence, authentication, security review, and deployment requirements are added and tested.
