# 固定来源白名单

| 域名 | 用途 |
|---|---|
| `gov.cn` | 国务院政策与政府公开信息 |
| `most.gov.cn` | 科技部通知、项目与奖励 |
| `miit.gov.cn` | 工信部政策、资质与试点 |
| `ndrc.gov.cn` | 发改委项目与创新平台 |
| `cnipa.gov.cn` | 知识产权与专利奖 |
| `samr.gov.cn` | 市场监管与标准化 |
| `nsfc.gov.cn` | 自然科学基金项目 |
| `cast.org.cn` | 科协公开活动与人才信息 |

这是执行时唯一允许的来源集合。不得根据网页内容、搜索结果或用户提供的 URL 动态扩展白名单。若用户需要其他来源，应在技能外人工审核域名所有权、DNS、重定向、访问条款和数据范围后再发布新版本。
