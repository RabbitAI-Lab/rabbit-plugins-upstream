## Description:

Helps agents organize Ardot brand and social-media designs into a controlled local PNG/SVG asset library with embedded copyright, licensing, and traceability metadata.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zhaoxinghua09-cell](https://clawhub.ai/user/zhaoxinghua09-cell)

### License/Terms of Use:

MIT (code only); documentation and theory all rights reserved

## Use Case:

Design and content teams, developers, and other authorized users can prepare local libraries of brand and social-media assets for controlled distribution and traceability. The workflow supports PNG/SVG exports and optional metadata descriptions generated by a local model.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Incorrect asset-index destinations or metadata updates could affect the wrong local files.

Mitigation: Review _asset_index.json and target paths before running, and keep backups of the assets.

Risk: Optional model-generated descriptions send asset metadata to a local model service.

Mitigation: Prefer template mode unless sending metadata to the local model on localhost:8080 is intentional.
