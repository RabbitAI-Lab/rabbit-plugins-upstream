## Description:

Guides the export of Ardot brand and social-media designs into a controlled local PNG/SVG asset library with copyright and provenance metadata.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zhaoxinghua09-cell](https://clawhub.ai/user/zhaoxinghua09-cell)

### License/Terms of Use:

MIT (.py code only); all rights reserved (documentation and theory)

## Use Case:

Brand teams and asset managers use this skill to export design assets, record attribution and licensing metadata, and prepare a traceable local library for controlled distribution.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Asset downloads and metadata injection can overwrite local PNG/SVG files.

Mitigation: Use a dedicated asset library with backups; review the URL map and asset index before running scripts.

Risk: The optional local model service can receive asset metadata.

Mitigation: Use template mode if metadata should not be sent to the localhost model service.
