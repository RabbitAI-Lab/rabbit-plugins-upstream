# 模拟评标方法论（魔鬼评委视角）

本文件是 SKILL.md 第 4 节的展开，定义逐项模拟打分的判定规则。核心原则：**客观项看证据、主观项给估算、总分仅参考**。

## 1. 评分项分类

| 类型 | 判定特征 | 打分方式 | 置信度 |
|---|---|---|---|
| 客观项 | 标准含「提供/具备/具有/证书/复印件/承诺/须…否则不得分/每…得…分」等可证伪判据 | 证据齐→给对应分；缺失→0；部分符合→按标准比例 | 高 |
| 主观项 | 标准含「优/良/中/差/合理/较合理/完善/0–N分/酌情/横向比较」等区间或比较判据 | 基于响应内容质量给估算区间分 | 低 |
| 未知 | 脚本未识别清楚 | 先核定类型再打 | 核定后定 |

## 2. 客观项铁律

1. **证据缺失 = 0 分**，不仁慈、不凑分、不四舍五入补。
2. 标准写「须提供 X 否则不得分」→ 响应无 X 即 0，无论其他多好。
3. 标准写「每高于 1% 扣 0.5」等量化规则 → 按规则精确计算，不估。
4. 部分符合（如「具备 3 项中的 2 项得 2/3 分」）→ 按标准比例给分，并在理由写明比例依据。

## 3. 主观项诚实法则

1. 只给**估算分 + 估算区间**（如「估 7/10，区间 5–8」），不得伪装确定性。
2. 理由必须写清「为什么是这个档」——对照标准里的档位描述（优/良/中）给依据。
3. 明确提示：真实评委主观差异大，该项实际得分可能 ±区间浮动。
4. 若响应对应内容缺失或极薄弱 → 给低分（甚至 0）并标注「响应中未体现」。

## 4. 价格分处理（开标前策略 + 开标后算分）

价格分常占 30–60%，是最大单项，但**开标前无法精确计算**（不知其他投标人报价）。分两段处理：

**开标前（策略参考）**：
- **公式解读**：用大白话解释本项目价格分怎么算（低价优先 / 基准价 / 区间）。
- **敏感度分析（明确计算边界，禁止数字幻觉）**：
  - **低价优先法**：我方只需与「最低价」比较，可精确计算极限情形——假设「我方报价 = 全场最低价」时价格分满分、或「我方报价 = 基准价」时的标准得分；其余情形按公示公式推演相对低价的得分区间（标注为估算）。
  - **基准价法 / 综合评分法**：**禁止编造具体分值**——基准价由「全部报价」算出，未知对手报价则无法定基准价。改为提供**趋势推演**：如「若基准价整体下浮，您每降价 1%，价格分相对优势约扩大 X 个身位（定性）」，帮助用户理解降价方向的边际收益；并明确建议开标后用 `price_score.py` 复盘精确分值。
- **报价策略**：激进 / 稳健 / 保守三档建议（结合得分点与竞争格局，不替用户决定最终报价）。

**开标后（精确算分）**：
- 同时具备「全部报价列表 + 价格分规则（method/full_score/base…）」→ 调用 `price_score.py` 按既定规则客观算分。
- 仅具备规则无报价 → 标「无法计算（缺报价）」。
- 既无规则也无报价 → 标「无法计算」，不臆造评标基准价。

## 5. 最弱评分项排序（多维补强优先级矩阵）

旧式 `(满分−模拟)×可行性权重` 过于简化（可行性权重无定义、忽略时限/成本/连锁效应）。升级为**多因子矩阵**：

先请用户提供（未给则按「未知」处理并标注）：
- **距封标剩余天数**：≤3天 紧迫度高 / 4–10天 中 / >10天 低
- **可投入补强预算范围**：低 / 中 / 高

对每个评分项评估：
```
可提分空间 = 满分 − 模拟得分
补强可行性 = 易(补证书/盖章)=高 / 中(改表述)=中 / 难(需真实业绩且暂无)=低
时间适配   = 可行性是否赶得上剩余天数（难项在≤3天→降权）
经济适配   = 补强成本是否在预算内（超预算→降权）
连锁覆盖度 = 补此项能否同时覆盖其他缺失项（能→加权）
```

**补强优先级 = 可提分空间大 × 可行性高 × 时间适配 × 经济适配 × 连锁覆盖度高** → 按综合分降序取 TOP3。

- 报告对每项写：优先级、预估提分、建议动作、时限/成本提示。
- 比单纯「得分最低」更能指导补强——既看空间大小，也看当下能否真补得上。

## 6. 报告置信声明

报告开头固定声明：

> ⚠️ 本结果为 AI 基于既定评标表对我方响应的**模拟自检**，非真实评标结论，仅供参考。主观项得分为估算，实际评委打分存在偏差。

## 7. 两法分轨提示

- **政府采购法**体系：价格分占比有法定下限（货物/服务类价格分一般不得低于 30%），服务类可更高；加分项不得设置地域/规模歧视。
- **招标投标法**体系：综合评估法下主观分权重、否决条款须在招标文件中明示。
- 涉及法定红线或口径不确定时，联动 IMA 知识库核实，不在无依据下臆断。
