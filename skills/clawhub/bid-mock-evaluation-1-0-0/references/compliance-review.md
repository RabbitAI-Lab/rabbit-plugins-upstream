# 评标表合规审查方法论（模式 C · 质疑弹药库）

本文件是 SKILL.md「模式 C」的展开。核心：审查**评标表本身**的合法性，把歧视性/违规条款挖出来，做成「可质疑点清单」+ 法条依据，供投标人质疑/投诉使用。

> ⚠️ **时效性**：本文件法条整理截止 **2026-07**，法规可能修订。每条输出须附核验声明，结论以现行有效法 + IMA 知识库核实为准，重大质疑建议咨询专业律师。本技能**不保证法条最新**。

## 1. 高频法条速查表（内置，硬法条优先引用）

引用时优先从此表取**硬法条**（法律/行政法规/部门规章，带精确条号）；**软依据**（规范性文件/指导意见/行业惯例）仅作辅助，不单独作为质疑支点。

| 违规类型 | 硬法条（精确条号） | 软依据（辅助） |
|---|---|---|
| 歧视性/定向（限定品牌、产地、特定供应商、特定业绩奖项） | 招标投标法第18条（不得以不合理条件限制排斥）、第20条（招标文件不得要求特定生产供应者）；政府采购法第22条第2款；招标投标法实施条例第32条（以不合理条件限制排斥的具体情形） | 财政部涉企违规专项整治要求 |
| 价格分占比违规 | 政府采购货物和服务招标投标管理办法（87号令第55条）：**货物≥30%、服务≥10%**（须分档判断，不可笼统以30%卡所有项目）；工程类价格分按招投标法实施条例及项目所在地规定 | 财库〔2007〕2号 |
| 主观不可量化（"优/良/中"无档位描述） | 87号令第55条（评审标准须细化量化） | — |
| 否决条款越界 | 招标投标法第42条；招标投标法实施条例第51条（法定否决情形） | — |
| 违规加分/门槛（地域、规模、所有制歧视性加分） | 政府采购法第22条；招标投标法实施条例第32条 | 中小企业促进法（扶持例外合法） |
| 资质门槛无关（与履约无关的证书/人员资格） | 87号令第17条（不得设与履约无关条件） | — |

> 引用纪律：硬法条须写全「法/条例/令 + 条号」；软依据只写方向，不伪造文号。两法分轨——政府采购法体系 vs 招标投标法体系口径不同，按项目所属法律体系适用。

## 2. 审查维度与判定

| 维度 | 违规表现 | 识别线索 |
|---|---|---|
| 歧视性/定向 | 限定特定品牌、产地、供应商、代理商授权；设定与项目无关的特定业绩/奖项 | "须提供XX品牌原厂授权""须具有XX地业绩" |
| 价格分占比违规 | 货物<30%、服务<10%（分档判断） | 价格分=20% 且为货物类 → 高危 |
| 主观不可量化 | 综合评分法下标准未细化量化，自由裁量过大 | "方案优者得满分"无档位 |
| 否决条款越界 | 法定情形外设否决；未明示即否决；一票否决过宽 | "未提供某承诺函即否决"（非法定） |
| 违规加分/门槛 | 地域/规模/所有制歧视性加分；业绩门槛过高变相排斥 | "本地企业加X分" |
| 资质门槛无关 | 要求与履约无关资质/证书/人员资格 | 软件项目要求机电类资质 |

## 3. 审查流程

1. 通读评标表全部评分项 + 否决/废标条款 + 资格门槛。
2. 逐项对照上表 6 维度，命中即记一条。
3. 每条给出：**条款原文摘录** + **违规类型** + **法条依据（方向，优先引用 §1 硬法条）** + **质疑/投诉建议**。
4. 标注风险等级：🔴 高危（明显违规，可质疑）/ 🟡 中（表述模糊，建议澄清）/ ⚪ 低（提示注意）。
5. 每条附 ⚠️ 法条核验提示（见文件头时效性声明）。

## 4. 护栏

- **只识别、不捏造**：质疑点必须基于评标表中**真实存在**的条款；不得替用户编造不存在的违规。
- **法条给方向不给定论**：以现行有效法 + IMA 知识库核实为准；重大质疑建议咨询专业律师。
- **两法分轨**：政府采购法体系 vs 招标投标法体系口径不同，按项目所属法律体系适用对应条款。
- **不教唆滥用**：质疑/投诉须基于真实合法权益，不得指导「缠诉」「恶意异议」。
- `is_knockout` 标记项（★/否决/一票）重点核查是否超越法定情形。
