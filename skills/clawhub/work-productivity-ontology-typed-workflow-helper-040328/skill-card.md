## Description: <br>
Helps agent users, skill authors, maintainers, and teams turn ontology-style work-productivity needs into practical workflows, checklists, artifacts, analysis, code changes, and verification notes. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

## Use Case: <br>
AI-agent users, skill authors, maintainers, and teams use this skill to plan and produce ontology-style workflow support for structured knowledge graph, typed workflow, productivity, reliability, and adjacent skill-authoring tasks. It is intended to produce practical local-hardware-friendly plans, templates, checklists, automation outlines, code changes, or decision aids that can be checked against stated success criteria. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad activation wording may cause the skill to run for loosely related ontology, typed-workflow, or knowledge-graph prompts. <br>
Mitigation: Narrow the trigger wording or disable implicit invocation when the skill should run only for explicit ontology or typed-workflow requests. <br>
Risk: Generated workflow artifacts can reflect incomplete user constraints or unchecked planning assumptions. <br>
Mitigation: Review the output against the stated success criteria, visible assumptions, limits, and required inputs before applying it. <br>
