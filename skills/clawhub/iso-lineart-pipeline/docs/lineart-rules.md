# 线稿规矩

这份文档只写**踩过的坑和量化过的结论**，不写教程。

---

## 1. 为什么不能用「二维拼多边形」出等距线稿

看起来最省事的做法是：在二维画布上算好每个面的四个角，按顺序画多边形。
这个做法有三处结构性的失败，而且**加细节只会让它更烂**：

| 现象 | 实测 | 根因 |
|---|---|---|
| 屋顶悬空 | 檐板底面与墙顶之间最大空隙 ≈45px（1920 画布），全片无接合线 | 屋面与墙体各自算坐标，没有共享的三维位置 |
| 剪影被吃掉 | 某一面加排线后，排线覆盖该面 62% 面积，外轮廓与内部线同宽 | 排线被当成"质感"，实际是遮住剪影 |
| 构件读成脚手架 | 6 根本意是斜撑的竖杆与墙面无任何连接关系 | 构件位置靠目测换算，没有依附关系 |

**根本原因：「墙顶在哪」和「檐口在哪」这两个问题，二维拼贴法回答不了。**
它们不是精度问题，是表达能力问题。所以一旦要走这条路，就必然会飘。

正解：**先建三维体块，再做隐藏线消隐**。几何自洽之后，你想让它飘都飘不起来。

## 2. 五条铁律

### 2.1 墙顶必须跟着屋面斜

单坡屋里，垂直于坡向的两面墙（山墙）顶是**斜的**，平行于坡向的两面墙顶是**平的但高度不同**。

如果图省事把四面墙顶都做成同一水平面，屋面又按坡度斜着放，
那么山墙顶上必然留出一条三角缝——整栋建筑读成"顶着个盖子"。

实现：`wquad()` 用 `(a,h)` 平面上的梯形沿 `b` 挤出，顶边由 `htop(a)` 给出。

### 2.2 线宽由「离剪影多少像素」决定，不由面贴标签

给每个面手贴 `sil / str / det` 权重是错的：
同一块屋面，在轮廓上是重线，在内部是轻线，**一条边在不同位置需要不同粗细**。

做法：把 z-buffer 里等于 `inf` 的像素（没被任何面覆盖 = 纸）二值化，
膨胀 3px 得到「剪影带」。逐条边采样时，落在剪影带内的样本段用重线，其余用所属面的线宽。

结果就是插画的层级：**外轮廓重、内部细节轻**，而且是自动的。

### 2.3 装饰件必须做薄板，不能做厚盒子

封檐板 / 窗台 / 门框 / 招牌——这些做成厚盒子（三面可见）时，
三个面都是纸白色，堆在一起就读成**一堆木块**。

同一构件改成薄板（0.004–0.014 厚）之后，只露一个面加一条厚度边，才读成"板"。

### 2.4 构件有尺寸下限：0.03 场景单位

场景单位 ≈ 882px（1920 画布）。

| 场景单位 | @1920 | @240（游戏尺寸） | 结论 |
|---|---|---|---|
| 0.010 | 9px | 1.1px | 只剩噪点 |
| 0.020 | 18px | 2.2px | 糊 |
| **0.030** | **26px** | **3.3px** | **下限** |
| 0.050 | 44px | 5.5px | 读得清 |

据此删掉过的东西：排线、0.03 宽斜撑（读成划痕）、74×124px 挑出招牌
（和角柱、过梁叠在同一片像素上，糊成一个黑块）、6 根横档的梯子。

**判据不是"画得对不对"，是"在 240px 那一档还看不看得见"。**
看不见的元素不是细节，是噪点。

### 2.5 消隐容差要跟共面几何一起想

可见性判据是 `d ≤ zbuf + EPS`（`EPS = 0.0022`）。

- 用「面 ID 相等」判定会**丢线**：两块共面的墙皮谁后画谁拥有像素，先画的那些边全部消失。
- 用「深度比较 + 小容差」才对：共面的边 `d == zbuf`，容差内通过；被挡住的边深度差远大于容差，正确消失。

容差不能大：设成 0.02 就会让藏在表面后 1px 的几何漏出来。

## 3. 体量比例会决定它读成什么

同一套线宽和细节，改比例就换了一个物种：

| 进深 : 面宽 | 读成 |
|---|---|
| 0.52 : 0.48（进深大） | 岗楼 / 塔 |
| **0.50 : 0.56（面宽大）** | **铺子 / 棚屋** |

定案：面宽 0.56 / 进深 0.50 / 檐高 0.47 / 屋面坡度 0.28。

另外，**「墙上的洞」读不出营业感**。
把售卖台挑出墙外 0.046、再用两根柱子撑住檐口之后，前脸才有纵深——
近处的柱子、中间的台面、后面的墙，三层一叠，这个开间才成立。

## 4. 什么该由代码做，什么该由模型做

`线稿锁剪影与构造，模型补材质与设计。`

实测：把一张线稿喂给图生图模型，模型自己加了檐梁、三处斜撑、
屋面上两块方向不同的补板、挑出的招牌臂、柜台的拼板缝——**线稿上一笔都没有**。

所以：

- ✅ 代码该保证的：**轮廓正确、构件不飘、开洞真穿透、比例对**
- ❌ 代码不必承担的：材质质感、笔触、冷暖、每个铆钉
- ⚠️ 代码做不到的：**手绘压感**。亚像素抖动（0.55–0.75px 幅值）只能让线不绝对直，
  达不到真实手绘的起收笔变化。这是能力边界，不要拿抖动冒充笔触。

---

## 5. 成本

全部本地计算，**0 积分**。1920×1920 单张 ≈3 秒（SS=2 超采样，3840² 深度缓冲）。

造型迭代的代价只有时间，所以**判据应该是"改一次能不能肉眼看出差别"**，
而不是"判据指标有没有变绿"。指标全绿但成片没变，等于没做。
