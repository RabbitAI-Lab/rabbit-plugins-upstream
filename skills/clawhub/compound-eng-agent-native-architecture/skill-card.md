## Description:

Design agent-native applications where agents replace UI users as the primary actor. Use when designing MCP tools, agent-loop architectures, system prompt design, hooks policy, shared-workspace file patterns, or self-modifying agent systems.

This skill is ready for commercial/non-commercial use.

## Publisher:

MIT-0

## Use Case:

Developers and engineers use this skill to design, review, and refactor agent-native systems, including MCP tools, agent loops, system prompts, hooks policy, shared workspaces, mobile execution, testing, and self-modifying agent patterns.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill includes copyable guidance for broad file, network, persistent-memory, deployment, and self-modifying-agent capabilities.

Mitigation: Apply workspace containment, network allowlists, sensitive-data minimization, approval gates, audit logs, rollback, and user-visible controls before using these patterns.

Risk: Architecture examples may be mistaken for secure drop-in code.

Mitigation: Treat examples as design sketches and review them against the target application's threat model before implementation.
