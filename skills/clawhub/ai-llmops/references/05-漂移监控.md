# 05 漂移监控

> 适用：发现"AI 效果悄悄变差"——生产运行的雷达
> 核对基准日：2026-08

## 1. 三类漂移

| 漂移类型 | 定义 | 示例 |
|---|---|---|
| 数据漂移（Input Drift） | 输入分布变化 | 用户提问方式/主题变化 |
| 概念漂移（Concept Drift） | 输入输出映射变化 | 业务规则/政策变了 |
| 模型漂移（Model Drift） | 模型自身行为变化 | 供应商更新、上下文污染 |

## 2. 监控指标体系（三层）

### 2.1 业务指标（结果层）
- 满意度、转化率、投诉率、错误率
- 人工介入率（AI 转人工比例上升 = 预警信号）

### 2.2 质量指标（评测层）
- 定期跑评测集：忠实度/准确率/幻觉率 vs 基线
- 频率：发布前全量，运行中每周采样

### 2.3 技术指标（输入/输出层）
- 输入分布统计（主题/长度/语言变化）
- 输出特征（长度/格式/拒答率变化）
- 延迟/成本异常

## 3. 告警阈值（经验值）

| 指标 | 告警阈值（示例） |
|---|---|
| 核心质量指标 | 周环比下跌 >5% |
| 拒绝率 | 环比上涨 >30% |
| 转人工率 | 上涨 >20% |
| 输入分布漂移 | PSI/JS 距离超阈值 |
| 成本 | 月预算超 80% 预警 / 超 100% 告警 |

> 阈值需按业务校准：高合规场景更敏感（医疗/金融收紧）

## 4. 漂移响应流程

```
① 检测：指标告警触发
② 诊断：是数据漂移/概念漂移/模型漂移？（对比输入分布/评测结果/模型日志）
③ 定位：哪个资产变了（模型版本/知识库/Prompt/业务规则）
④ 处置：回滚 or 更新（如业务规则变了→更新知识库/Prompt）
⑤ 复盘：记录根因与防复发
```

## 5. 常见误区
1. "只看业务指标"——业务指标滞后（用户已经开始不满），质量/技术指标前置
2. "漂移就是模型问题"——先排查是否数据/概念变化
3. "告警太多狼来了"——阈值要校准，分级告警（预警/告警/严重）
