# 06 成本治理

> 适用：LLM 调用成本核算与控制——AI 的 FinOps
> 核对基准日：2026-08

## 1. 为什么成本会失控

- Token 计费随调用量线性增长
- 输入输出 Token 双计费（输出更贵）
- 多模型多场景缺乏预算管理
- Prompt 膨胀/上下文塞满推高成本

## 2. 成本核算口径

```
单次成本 = 输入 Token × 输入单价 + 输出 Token × 输出单价
月成本   = Σ(各场景调用量 × 单次成本)
成本构成 = 模型调用 + 向量库/存储 + 基础设施 + 人工维护
```

### 核算要点
- **分场景核算**：每业务场景单列（找成本大头）
- **分模型核算**：各模型单列（找贵模型）
- **趋势跟踪**：月环比（发现异常增长）

## 3. 降本策略（按性价比排序）

| 策略 | 做法 | 效果 |
|---|---|---|
| **路由分层** | 简单任务用轻量模型，复杂任务用强模型 | 显著（可省 30-60%） |
| **Prompt 瘦身** | 精简上下文、去除冗余指令 | 中（省输入 Token） |
| **缓存复用** | 相似请求缓存（前缀缓存/结果缓存） | 中（高频场景有效） |
| **蒸馏部署** | 高频固定任务用蒸馏小模型 | 高（但需质量验证） |
| **批量处理** | 非实时任务批量/非高峰调用 | 低-中（视 API 定价） |
| **预算控制** | 设置预算上限 + 超预算熔断 | 保命（防失控） |

## 4. 预算控制机制

```
预算分配：按场景/部门设月度预算
预警线：达 70% 预警，80% 告警，100% 熔断（停止调用/降级）
异常检测：单日成本突增 >50% 告警（查是否配置错误/流量异常）
```

## 5. 成本治理流程
1. 月度成本报告（分场景/分模型/趋势）
2. 成本 Top 场景优化（路由/缓存/蒸馏）
3. 预算复盘（超支原因分析）
4. 季度成本策略更新

## 6. 常见误区
1. "只看单价不看用量"——用量才是大头，先找高频场景
2. "所有场景都用最强模型"——大炮打蚊子，路由分层最省钱
3. "成本是财务的事"——工程师的 Prompt/上下文设计直接影响成本
