## Description:

Affinity (affinity.co). Use this skill for ANY Affinity request — searching and reading data. Whenever a task involves Affinity, use this skill instead of calling the API directly.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and teams use this skill to search and read people, companies, lists, opportunities, and related records in their connected Affinity account.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup may run downloaded code whose contents and live behavior have not been verified, and may change skills installed for other agents.

Mitigation: Review and approve a verified, version-pinned CLI installation separately, including any changes to other agents' installed skills.

Risk: Using the skill involves access brokered by OOMOL to the connected Affinity account.

Mitigation: Use it only with an Affinity connection you intend OOMOL to access, and review the action and returned data.
