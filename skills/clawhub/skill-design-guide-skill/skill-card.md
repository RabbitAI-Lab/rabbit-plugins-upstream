## Description:

Skill Design Guide helps agents design and review AI skills by choosing workflow or agent architecture, selecting workflow patterns, writing SKILL.md files, and applying a governance-aware quality checklist.

This skill is ready for commercial/non-commercial use.

## Publisher:

[haiyangchenbj](https://clawhub.ai/user/haiyangchenbj)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, skill authors, and reviewers use this guide to design new AI skills, choose an appropriate workflow pattern, or review an existing skill for structure, guardrails, and governance readiness.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: External-source summaries may be incomplete, outdated, or misapplied to a specific skill design.

Mitigation: Use the guide as design advice and validate important architecture, governance, and publishing decisions against current authoritative sources.

Risk: Publishing or creation actions could be triggered unintentionally if the guide is treated as an action tool instead of reference material.

Mitigation: Use separate publishing or creation tools only when those actions are intentional and confirm external actions before execution.
