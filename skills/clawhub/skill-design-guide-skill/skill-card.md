## Description:

Skill Design Guide helps agents design better AI skills by choosing Workflow versus Agent, selecting workflow patterns, writing SKILL.md files, and applying a governance-aware quality checklist.

This skill is ready for commercial/non-commercial use.

## Publisher:

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent builders use this skill to design, review, and improve agent skills by selecting an appropriate architecture pattern, structuring SKILL.md content, and checking quality and governance concerns before release.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Publishing-related wording could be mistaken for permission to push or update a skill directly.

Mitigation: Use this skill for design and review guidance only; review separate skill-publish behavior and require confirmation before any external publishing action.

Risk: Architecture recommendations can be incomplete or misleading if applied without reviewing the target skill and its operating context.

Mitigation: Apply the included quality checklist and human review before deploying or releasing generated skill changes.
