# Job Screener Engine — 岗位深度评估引擎

[![ClawHub](https://img.shields.io/badge/ClawHub-发布-4B44C0)](https://clawhub.ai/CalmDownTR/job-screener-engine)

在用户拿到面试邀请或 Offer 后，对岗位机会做深度评估：六个维度 A–H 等级 + 全局 1–5 分，输出行动建议、面试练手价值与风险提示。

---

## 这是什么

一个通用 AI Agent 技能（Skill），帮助求职者理性评估工作机会。适用于支持 `npx skills` 标准的各类 AI 编程助手。通过 6 个维度的 A–H 等级与全局 1–5 分进行结构化评估，并给出投递建议。

**核心设计理念：**
- **粗粒度分级代替假精确**：每维 A–H 等级 + 全局 1–5 分，可解释、可复现，避免 0-100 制的确定性幻觉
- **一票否决**：不满足底线的岗位直接标记，节省精力
- **面试/入职解耦**：即使不建议入职，也可能值得面试练手
- **信息透明**：信息不足的维度诚实标注，不猜测不编造

> **为什么用等级而不用百分制？** 0-100 制（如「薪资匹配度 13/18」）是假精确：13 与 14 的差别无法解释、每次运行会漂移、总分无法复核。A–H 等级 + 全局 1–5 分可解释、可复现、诚实标注信息不足。

**三个核心差异：**

- **面试/入职解耦**：不建议入职 ≠ 不值得面试。每个机会独立评估「面试练手价值」，把「去不去」和「面不面」拆成两个问题；
- **资金来源 > 账面盈利**：稳定性按「国家信用 > 全球调配 > 资本市场 > 主营业务」判断，而非看账面数字；
- **你的底线是评分的一部分**：一票否决、薪资 trade-off、核心维度优先级都来自你的本地画像，不是通用模板。

## 何时使用

初期筛选阶段建议依赖个人快速判断，以保持投递效率；获得面试邀请或 Offer 后再用本引擎进行深度评估，此时投入的每一分钟都对应一个真实推进中的机会，投入产出比更高。

## 安装

```bash
npx skills add CalmDownTR/job-screener-engine
```

安装后自动配置为 AI 可用技能。

## 首次使用（渐进式配置）

不必先填完配置。第一次评估时，AI 只会问 3 个核心问题（Base 底线、技术方向、公司类型偏好），答完立刻出第一份报告（标注「部分个人化」），之后随时可以补全。

### 方式一：AI 引导补全（推荐）

告诉 AI：

> "帮我补全求职画像"

AI 会按向导逐项提问（可随时说"够了"），完成后更新 `user_profile.md`。

### 方式二：自行填写

```bash
cp references/user_profile.TEMPLATE.md references/user_profile.md
# 然后编辑所有 [占位符]
```

> **隐私：** `user_profile.md` 只保存在你的本地仓库（已加入 .gitignore），不会上传到任何地方。

## 使用

配置完成后，直接告诉 AI：

| 你说 | AI 会做 |
|------|---------|
| "拿到 offer 了，帮我看看" + 公司/岗位信息 | 搜索信息 → 六维等级 + 全局评分 → 报告 |
| "这个面试机会值不值得去" + JD 链接 | 解析 JD → 搜索补充 → 一票否决 → 评分 |
| "帮我对比这两个 offer" + 岗位信息 | 分别评估 → 同分排序 → 对比输出 |

### 输出示例

```
## 📋 岗位评估 | XX科技有限公司 - 后端开发工程师

### 基本信息
- 薪资：20K-30K
- 公司规模：C轮 / 500人
- 地点：上海
- 信息来源：用户提供 + 搜索补充

### 评分明细
| 维度 | 等级 | 说明 |
|------|------|------|
| 薪资匹配度 | B | 20K-30K，在期望范围内 |
| 公司规模与规范度 | A | C轮融资，500人，制度相对完善 |
| 技术成长空间 | C | 后端技术栈匹配，但方向偏业务 |
| 工作节奏与心理适配度 | B | 弹性工作，偶有加班 |
| 稳定性 | B | C轮融资，收入来源清晰 |
| 区域居住可行性 | B | 通勤和配套均属合理水平 |
| **全局评分** | **4/5** | 核心维度（薪资、稳定性）达标，无否决项 |

### 判定：✅ 推荐投递
### 重要程度：A
### 面试练手建议：中等价值

岗位与自身技术方向部分相关，可投递并了解市场行情。
```

## 自定义配置

所有评估参数通过 `references/user_profile.md` 配置：

| 配置项 | 说明 |
|--------|------|
| Base 底线/期望 | 最低接受与理想薪资 |
| 技术方向 | 核心赛道（Agent/LLM / 后端等） |
| 公司偏好 | 目标公司类型 |
| 工作节奏 | 能接受的强度 |
| 核心维度优先级 | 全局评分时优先保证的维度 |
| 一票否决 | 直接跳过的条件 |
| 同分排序 | 分数相同时的优先级 |
