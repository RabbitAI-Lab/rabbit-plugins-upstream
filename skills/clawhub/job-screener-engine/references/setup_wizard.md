# 首次配置向导（渐进式）

本向导用于收集用户求职偏好并生成 `user_profile.md`。分两段：**核心 3 问** + **可选补全**。用户可随时说"够了"结束补全。

---

## 流程概述

```
核心 3 问（一次问完） → 生成基础画像 → 出第一份报告 → 可选补全（逐项，可随时停）
```

---

## 第一部分：核心 3 问（必问，一次问完）

在一次回复中同时提出以下 3 个问题：

1. **Base 薪资底线**：你能接受的最低 Base 月薪是多少？（如 20K）
2. **核心技术方向**：你的主要技术方向是什么？（如 Agent/LLM / 前端 / 后端 / 嵌入式）
3. **公司类型偏好**：你优先考虑什么类型的公司？（大厂 / 外企 / 国企/央企 / 创业公司 / 中型科技公司 / 不拘）

规则：
- 未回答的项按默认值处理（底线：不设限；方向：不限；公司类型：不拘），不追问
- 收集到答案（或用户确认跳过）后，立即生成 `user_profile.md` 并开始评估
- 在报告的「画像状态」栏标注「部分个人化」

---

## 第二部分：可选补全（逐项提问，可随时停）

第一份报告输出后，用一句话引导："想更准？花 2 分钟补齐以下配置。" 用户同意后逐项提问，**每次只问 1 个问题**；用户说"够了"立即停止，已收集的信息立即写入 `user_profile.md`。

1. **期望薪资**：理想的 Base 月薪是多少？（如 30K）
2. **薪资 trade-off**：如果公司非常稳定（央企/国企/外企大厂），可以接受低多少？
3. **技术栈**：主要用什么技术栈？（如 Python+PyTorch / React+Node / Go+K8s）
4. **成长方向**：希望在哪个方向持续成长？（如 AI 架构 / 全栈 / 高并发 / 产品化）
5. **期望城市**：想在哪个城市工作？
6. **工作节奏**：能接受什么节奏？（必须双休 / 偶尔加班可接受 / 大小周可接受 / 不拘）
7. **管理风格**：偏好什么管理风格？（结果导向 / 尊重个体差异 / 避免微观管理 / 不拘）
8. **稳定性要求**：希望在一家公司待多久？（2年+ / 3年+ / 不拘）
9. **区域要求**：对居住区域的要求？（租房合理 / 通勤可接受 / 不拘）
10. **求职状态**：在职 / 离职 / 刚毕业？（含可到岗时间）
11. **基本信息**：怎么称呼你？几年经验？（可选）

---

## 错误处理

- **用户跳过核心问题**：该项按默认值处理，报告标注「部分个人化」
- **用户提供模糊信息**：如"薪资差不多就行" → 追问一次具体数字，仍模糊则按默认值
- **用户中途退出补全**：已收集的信息立即写入 `user_profile.md`，未收集的保持占位符
- **已存在 user_profile.md**：跳过向导直接读取；如需调整，请用户自行修改或说"帮我补全求职画像"

---

## 示例对话

```
AI: 先问 3 个核心问题：① Base 底线多少？② 技术方向？③ 偏好的公司类型？不确定的可以先不答。
用户: 20K 吧，Agent/LLM 方向，外企优先
AI: 好，用「部分个人化」画像先跑评估……
    （输出第一份报告，画像状态标注「部分个人化」）
AI: 想更准？花 2 分钟补齐期望薪资、工作节奏、管理风格等配置。
```
