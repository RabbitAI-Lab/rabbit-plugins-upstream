# Changelog

## 2.1.0 (2026-08-26)

### 定位收敛（产品）
- 定位从「初筛+深度评估并存」收敛为「拿到面试/Offer 后的深度评估」：触发词、标题、README 文案全部对齐
- 首次使用从 14 问完整配置改为「3 个核心问题 + 渐进式补全」，第一份报告不再被配置墙拦住

### 报告增强
- 报告模板新增「信息完整度」「📎 信息来源与引用」区块；「面试练手建议」前移至判定之后
- README 首页新增「核心差异」（面试/入职解耦、资金来源判断、本地画像）与隐私声明
- 反馈闭环（结果校准）降级为 README「未来方向」

## 2.0.0 (2026-08-26)

### 重大变更（Breaking）
- 评分制重构：6 维 0-100 加权总分 → 每维 A–H 等级 + 全局 1–5 分（可解释、可复现，消除假精确）
- 移除数值权重与「中间值兜底」，改用「核心维度优先级」与「?」+ 区间处理信息不足
- 判定档位由全局分直接映射（5→⭐ … 1→❌），同分排序阈值改为「全局分相同或相差 1 分」
- 统一维度命名（公司规模与规范度 / 技术成长空间 / 工作节奏与心理适配度 / 区域居住可行性）

## 1.0.1 (2026-05-12)

### 修复
- SKILL.md 补全 frontmatter 字段（version, homepage），满足 ClawHub 发布要求
- README.md 发布指引更新为 ClawHub 流程

## 1.0.0 (2026-05-12)

初始版本发布。

### 新增
- 6 维评分框架：薪资匹配度、公司规模、技术成长、工作节奏、稳定性、区域可行性
- 7 步评估工作流：解析 → 搜索 → 一票否决 → 评分 → 补缺 → 报告 → 对比
- 一票否决机制：不满足底线的岗位直接标记，跳过评分
- 面试练手独立评估：与"是否入职"解耦，独立判断面试价值
- 信息不足降级策略：最多 3 问 + 中间值兜底 + 诚实标注
- 资金来源稳定性判断：账面盈利 ≠ 资金稳定
- 多岗位对比排序：同分时按用户优先级排序
- 首次配置向导 `references/setup_wizard.md`
- 用户画像模板 `references/user_profile.TEMPLATE.md`
- 版本元数据 `_meta.json`
- 最小权限设置 `allowed-tools: Read, WebSearch`
