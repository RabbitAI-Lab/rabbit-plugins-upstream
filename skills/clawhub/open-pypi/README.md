# open-pypi

A lightweight Brave browser skill for **PyPI**.

## What it does

Open the Python Package Index (PyPI) in Brave.

- Reuses an existing relevant tab/session
- Avoids unnecessary duplicate tabs
- Verifies the destination
- Never handles credentials

## Example triggers

- Open PyPI
- Take me to PyPI
