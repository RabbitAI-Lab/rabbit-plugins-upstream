```

- 韵脚：主歌1 [ABAB / AABB]（[辙名 韵母]） / 副歌 [AAAA]（[辙名 韵母]） / 主歌2 [辙名] / 桥段 [辙名]

- [第 X 句] 韵脚偏宽，可换更严的韵：[候选字]
- [副歌比主歌少 N 字]，对旋律时留意呼吸位
- [意象] 第 X 段略跑题，建议回到 [核心意象]
```

## 填写约束

1. 每段段首必须写明所用韵辙（参考 references/rhyme-rules.md 的十三辙）。
2. 每句后必须标字数（汉字数，不含标点；助词计入）。
3. 副歌必须有一句重复的 hook，且比主歌短而齐。
4. 全篇核心意象不超过 3 个，写完好回查是否跑题。
5. 原创为原则：不套用、改写、翻译已有歌曲的歌词；只借鉴结构情绪。
6. 字数与韵脚是配曲参考，不与特定旋律强绑定；用户给旋律信息后再调。
