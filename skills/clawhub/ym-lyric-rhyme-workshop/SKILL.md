# 歌词押韵工坊 (ym-lyric-rhyme-workshop)

按主题、情绪与曲风写原创歌词，给出押韵方案与每句字数标注，可逐句打磨换韵。把"帮我写首歌"变成一份能拿去配曲的成稿，而不是一段灵感碎片。

## 何时使用

- 用户说「写段歌词」「帮我押韵」「写首歌」「这段词怎么改更顺」时
- 用户给了一段主题或情绪，想做成完整歌词时
- 用户希望歌词有明确韵脚、能数出每句字数以便对旋律时

## 运行前提

- 依赖：无第三方依赖，纯文本处理
- 不读取任何本地文件，除非用户明确给出路径
- 不联网、不上传任何数据

## 输入契约

| 项 | 必需 | 说明 |
|---|---|---|
| 主题与情绪 | 必需 | 如"毕业告别，不舍但向前""深夜加班想放弃又坚持" |
| 曲风 | 可选 | 民谣 / 说唱 / 流行 / 古风；默认流行抒情 |
| 结构 | 可选 | 主歌+副歌 / 只有一段 / 含桥段；默认标准流行结构 |
| 参考字数 | 可选 | 主歌每句大致字数、副歌是否要短 |
| 是否要押韵方案 | 可选 | 默认给出 |

**缺失处理：**

- 缺曲风 → 按流行抒情写，并在开头注明"未指定曲风，按流行抒情处理"
- 要求"像某首歌那样" → 只借鉴结构与情绪，**不模仿其旋律与歌词**，并明确告知不套用已有作品
- 要求填词到已有旋律但不给旋律信息 → 说明无法保证格数对上，给通用字数方案，待用户补充旋律字数与节奏后再调
- **主题与情绪都为空 → 直接说明无法动笔，列出需要什么，绝不编造歌词**

## 执行步骤

1. **定结构** — 先给结构表（主歌1 / 预副歌可选 / 副歌 / 主歌2 / 副歌 / 桥段可选 / 尾段），结构确定后再写词，不边写边改结构。

2. **定押韵方案** — 标注每段韵脚（如 AABB / ABAB / AAAA），中文按韵母押韵、兼顾十三辙（规则见 `references/rhyme-rules.md`）。给出本段所用韵辙（如"发花辙 a/ia/ua"）。换韵时明确标出新韵辙。

3. **写词并标格数** — 每句后标字数，如 `风把旧照片吹到了脚边(10)`。字数便于对旋律时调整；同一段内相邻句字数建议有节奏变化而非全一样（说唱可故意齐整）。

4. **副歌必须有记忆点** — 一句重复的 hook，且比主歌更短更整齐，便于传唱。若用户没要求，默认给一个 hook 方案。

5. **意象一致性** — 全篇围绕 2~3 个核心意象展开，避免意象乱跳；开头列出所选意象，写完后回查是否跑题。

6. **逐句打磨模式** — 用户指出某句别扭时，给 3 个改法（换韵 / 换字数 / 换意象），并说明各自代价（如换韵会带动整段韵脚、换字数可能影响节奏），让用户选。

7. **硬性约束** — 不套用、不翻译、不改写已有歌曲的歌词；不生成旋律与音频；不保证能直接配曲（需按实际旋律调格数）；每句字数标注是"参考字数"，不是绝对节拍。

## 输出格式

Markdown，套用 `templates/lyric-template.md`：

```
## 一、结构与押韵方案
- 结构：主歌1 → 副歌 → 主歌2 → 副歌 → 桥段 → 尾段
- 韵脚：主歌1 ABAB（江阳辙 ang/iang/uang）/ 副歌 AAAA（发花辙 a/ia/ua）

## 二、核心意象
- 意象1 / 意象2 / 意象3

## 三、歌词全文
【主歌1】（江阳辙）
路灯把影子拉得很长(9)
你说以后要去远方(8)
…

【副歌】（发花辙）
别怕(2) 路还长(3)
…

## 四、可打磨点提示
- 第 X 句韵脚偏宽，可换更严的韵
- 副歌比主歌少 2 字，对旋律时留意呼吸位
```

## 能力边界

- 不生成旋律、不生成音频、不做编曲（只给文字与字数标注）
- 不保证与特定旋律严丝合缝（需用户按格数自行调整或提供旋律信息）
- 不套用、改写、翻译已有歌曲的歌词（原创为原则，引用结构情绪除外）
- 不读取本地音频文件；不自动发布

## 常见坑

1. **只给灵感不给结构** — 用户说"写首关于离别的歌"，模型容易吐一段散文诗。规避：先定结构与韵脚再写词，结构表是第一步产出。
2. **字数标注漏标或标错** — 标了字数但数和实际不符，用户拿去对旋律会错位。规避：每句写完当场数字数，标点不计入字数（以汉字+必要助词计）。
3. **为了押韵硬凑意思** — "为了押 an 韵硬塞一个不相关的词"。规避：先保证句意通顺，韵脚在可选同韵字里选最贴句意的；实在凑不上就换韵并标出。
4. **副歌没有 hook** — 主歌副歌一个调，整首没记忆点。规避：副歌必须有一句重复的短 hook，且比主歌更短更齐。
5. **套用已有歌** — 用户说"像 XX 那样"，模型可能直接改写那首歌的歌词。规避：只借鉴结构情绪，原创填词；明确告知不套用。
6. **意象乱跳** — 一段写"海"，下句突然"雪山"，情绪断裂。规避：开头锁定 2~3 个核心意象，写完好回查。

## 验收用例

- 正常：「毕业，不舍但向前，流行」→ 完整结构歌词 + 押韵方案 + 每句字数标注
- 边界 1：用户说"副歌这句不顺" → 给 3 个改法（换韵/换字数/换意象）与各自代价
- 边界 2：要求照抄某首歌的歌词 → 拒绝，给同主题原创替代
- 失败：要求填词但不给旋律信息 → 说明无法保证格数匹配，给通用字数方案

## 目录说明

- `references/` — 中文押韵规则（十三辙与韵母）、常见曲风结构表
- `templates/` — 歌词输出模板（段标注 + 韵脚 + 每句字数）
