# 中文押韵规则（十三辙与韵母要点）

写词时判断"哪两句算押韵"的硬知识。中文押韵看**韵腹（主要元音）与韵尾**是否相同或相近，不要求声母、声调一致。

## 一、十三辙（按韵辙归类）

十三辙是北方戏曲/民歌对普通话韵母的传统归并，写流行、民谣、说唱都够用。每辙给代表韵母与示例字。

| 辙名 | 韵母（含韵头） | 示例字 | 常见感觉 |
|---|---|---|---|
| 发花 | a, ia, ua | 家、话、画、花 | 开口、明亮 |
| 梭波 | o, e, uo | 河、歌、过、火 | 柔和 |
| 乜斜 | ê, ie, üe | 夜、月、借、写 | 细腻、略收 |
| 一七 | i, ü, er, -i(舌尖) | 你、雨、诗、意 | 收敛、叙事感 |
| 姑苏 | u | 路、苦、故、步 | 低沉 |
| 怀来 | ai, uai | 来、爱、海、代 | 舒展 |
| 灰堆 | ei, uei(ui) | 飞、泪、对、归 | 轻柔 |
| 遥条 | ao, iao | 笑、跑、调、好 | 明亮上扬 |
| 由求 | ou, iou(iu) | 走、愁、留、手 | 悠远 |
| 言前 | an, ian, uan, üan | 天、念、远、年 | 开阔 |
| 人辰 | en, in, un, ün | 心、问、春、引 | 温厚 |
| 江阳 | ang, iang, uang | 光、唱、想、方 | 洪亮 |
| 中东 | eng, ing, ueng, ong, iong | 风、梦、拥、灯 | 饱满收束 |

## 二、押韵判定要点

1. **同辙即押**：只要落在同一辙内，就算押韵。如"家(jia)"与"花(hua)"同属发花辙，可押。
2. **宽韵与严韵**：严韵要求韵腹韵尾完全相同（同韵母）；宽韵允许同辙不同韵母（如言前的 an 与 ian 通押）。流行歌常用宽韵，古风偏向严韵。
3. **声调不要求一致**：平仄不同也能押（"风 fēng"与"梦 mèng"同中东辙，可押），但连续同声调易显单调，可刻意错开。
4. **轻声字可作韵脚但弱**：如"的、了、吗"作尾字押韵感弱，副歌可用，主歌慎用。
5. **-ng 与 -n 不相通**：江阳(ang)与人辰(en)不可通押，中东(eng)与言前(an)不可通押，这是最常犯的错。

## 三、常见可通押情况

- 言前(an/ian/uan/üan) 四韵母互押
- 人辰(en/in/un/ün) 四韵母互押
- 江阳(ang/iang/uang) 三韵母互押
- 中东(eng/ing/ong/iong) 互押，但 ing/ong 与 eng 通押时略宽，古风慎用
- 遥条(ao/iao)、由求(ou/iu) 各自内部通押

## 四、换韵的写法

- 主歌换韵：主歌1用甲辙，主歌2可换乙辙，制造推进感
- 副歌固定一辙：副歌通常从头到尾一辙，强化记忆
- 桥段可离调：桥段换一个反差大的辙（如主歌江阳、桥段一七），制造情绪转折
- 换韵时在歌词里明确标出新韵辙名，方便核对

## 五、字数标注约定

- 每句后标 `(N)`，N 为汉字字数，**不含标点**
- 助词"的、了、着、吗"计入字数（它们占音节）
- 英文/数字按音节或字符数另注，如 `say goodbye(3英)`
- 字数只作对旋律的参考，不是绝对节拍；同一段相邻句字数建议有变化避免呆板
