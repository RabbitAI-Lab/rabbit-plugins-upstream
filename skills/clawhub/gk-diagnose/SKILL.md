# 工控故障预检（免费版）

现场设备停了，先别急着动手。**这一步告诉你"该查哪一段"**——判断故障落在电源、控制器、通讯、执行器还是机械，再给你几项能立刻做的检查。

**永久免费**，不需要付费、不需要授权、不需要提供任何设备信息。

## 功能说明

本技能只做一件事：**故障大类预检**。

1. 根据你给的「品牌 + 现象」，判断故障落在哪一段：
   **电源 / 控制器 / 通讯 / 执行器 / 机械 / 数据解释**
2. 给出 3-5 项**立刻能做的现场检查动作**，每项都写清"做完应该看到什么"
3. 提示该场景的**安全红线**（带电作业、高压直流母线、旋转机械）
4. 告诉你下一步该往哪个方向深入

## 适用场景

- 现场设备停了，想先快速缩小范围
- 变频器报故障码，想知道大概是哪一类问题
- PLC 指示灯异常（SF / BF / ERR），想判断是硬件还是程序
- 通讯中断，想确认是接线、参数还是数据解释问题
- 想知道某个报警"值不值得马上停机处理"

## 不适用场景

- **需要具体处置方案**：本技能只给方向，不给完整的排查步骤、参数检查项和预防建议（那是深度案例库的内容）。
- **需要精确码值含义的最终裁决**：不同固件版本的故障码含义可能有差异，请以设备随机手册的《故障代码表》和铭牌参数为准。
- **安全相关功能的最终确认**：涉及安全回路、STO、SIL 等级的功能，必须由具备资质的工程师按规范验收。
- **非工控领域**：家用电器维修、汽车电路、IT 网络故障不在覆盖范围内。
- **需要现场测量的结论**：本技能不做远程测量，只告诉你"该测哪里、测到什么值说明什么"。

## 使用方法

直接说设备品牌 + 故障现象即可：

- `g120 报 F30001`
- `S7-1200 的 BF 灯红了`
- `三菱 FX5U ERR 灯亮`
- `Modbus RTU 从站没响应`
- `变频器给了运行命令但电机不转`

也可以只描述现象不报品牌：`变频器一启动就跳过流`。

## 参数说明

| 参数 | 必填 | 说明 | 示例 |
|---|---|---|---|
| `brand` | 否 | 设备品牌/系列 | `g120`、`s7-1200`、`fx5u`、`hmi`、`modbus`、`mm4` |
| `symptom` | 是 | 故障现象或报警码 | `F30001`、`通讯不通`、`启动不转`、`BF灯红` |

- 未给 `brand` 时，按通用工控排查路径处理，并提示可能的品牌差异。
- `symptom` 支持中文现象描述，也支持原始报警码。

**示例 1**
> 用户：`G120 报 F30001 怎么排查？`
> 输出：故障大类＝执行器/机械（过流类）→ 5 项现场检查（脱线点动 / 盘车检查 / 延长斜坡 / 核对铭牌参数 / 兆欧表测绝缘）→ 安全红线（直流母线余电）→ 提示深入方向

**示例 3**

| 本技能给什么 | 本技能不给什么 |
|---|---|
| 故障落在哪一段 | 具体的根因判断 |

## 注意事项

- 现象描述越具体，预检越准（带上品牌型号 + 报警码 + 什么时候出现）。
- 涉及带电、高压、旋转机械时，**先断电验电再动手**，安全红线优先级高于排查速度。
- 如果预检后你觉得方向对了、需要具体怎么修，再考虑用付费版取详细方案。
