## Description:

Personal astrology companion for calculating and interpreting natal charts, with first-use birth-profile onboarding and conversational feedback. Use for personal natal readings or astrology questions involving the user's chart.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users can use Astron for private, reflective astrology conversations, including natal chart readings, general sky events, transit windows, secondary progressions, and natal chart SVG exports. Interpretations are symbolic reflection, not scientific assessments or guarantees.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security assessment is benign but incomplete, and the skill's file and shell capabilities have undeclared tool scope.

Mitigation: Review whether its file and shell access fits your needs; keep birth profiles and exports private, and get permission before sending birth details to an external geocoding service.
