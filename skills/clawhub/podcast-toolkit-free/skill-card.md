## Description: <br>
Podcast Toolkit Free helps individual creators plan a podcast, outline episodes, prepare interview questions, generate show notes, and organize local Markdown project files. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External creators and agents use this skill to structure a personal podcast workflow, including show positioning, episode outlines, interview preparation, recording checklists, and show notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Example shell commands using file redirection can overwrite existing local podcast files. <br>
Mitigation: Review command paths before execution and run examples in a new project directory or with backups. <br>
Risk: Guest planning templates can store personal contact details in local Markdown files. <br>
Mitigation: Avoid adding sensitive guest information unless the local storage location is appropriate for that data. <br>
Risk: Podcast planning guidance may be generic and may not fit a creator's audience or production constraints. <br>
Mitigation: Review outlines, questions, and show notes against the creator's editorial goals before publishing. <br>
