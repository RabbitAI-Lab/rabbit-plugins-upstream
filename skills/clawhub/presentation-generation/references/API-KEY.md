# API 密钥配置与价格

默认 API 根地址为 `https://ai-skills.open-idea.net/api/v1`；密钥环境变量为 `PRESENTATION_GENERATION_API_KEY`，可选覆盖 `AI_SKILLS_API_URL`。从 ClawHub 安装免费；无需购买或配置 OpenAI、Anthropic、Google、Replicate 等第三方付费凭据。

- `presentation.inspect`：免费
- `presentation.outline`：输入 ¥0.006、输出 ¥0.012/千 tokens
- `presentation.generate`：¥0.50/份

实际价格以[演示文稿生成产品页面](https://ai-skills.open-idea.net/skills/presentation-generation)和响应头为准。不要记录、回显或提交完整 API Key。
