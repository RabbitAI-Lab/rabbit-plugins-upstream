<br>

「マドリッドとは何か」の解説ではなく、**そのまま事件簿に入る成果物**を返します。正確な手数料の積算、二種類の期限の計算、そのまま記入できるチェックリストと回答メモ、一字一句照合できる条約全文。

WIPO の国際段階の手続はどの締約国から見ても共通です。本スキルは**締約国中立（office-neutral）の視点**で書かれており、CNIPA／中国の接続は任意の一章にすぎません。USPTO からでも EUIPO からでも JPO からでも CNIPA からでも、同じように使えます。

本スキルに組み込まれた手数料の数字・期限・宣言には、いずれも**データ基準日と公式の確認先**が付いています。見つからないものは「なし」と答えます — でっち上げません。

```
git clone https://github.com/huiningip/madrid-trademark ~/.workbuddy/skills/madrid-trademark
```

エージェント非依存 — skills に対応した任意のエージェントに導入できます。

> 📣 **変動データは決め打ちしません。** 手数料・個別手数料・締約国の宣言・加盟数・法令は、いずれも「基準日 + 推奨確認周期 + 公式の確認先」を備えます。周期を過ぎればオンライン確認を要求し、検索エンジンのキャッシュ値は採用しません。

## 詳細な適用範囲

### 手数料：二つの経路は互いに代替できません

`scripts/madrid_fee.py` は**オフラインのスナップショット**による計算です。ネットワークもブラウザも不要で、76 の締約国の個別手数料を内蔵し、`--date` に従って**公示済みの料率改定**を適用します。

`scripts/madrid_feecalc_live.py` は**公式の実測**です。実ブラウザで WIPO の Fee Calculator を操作し、締約国ごとの正式な金額を返します。金額に争いがある場合の判定手段となります。

> 公式計算機は JSF アプリケーションで、締約国の一覧も結果も JavaScript が描画するため、**HTTP で取得することはできません**。チェックを入れるたびに AJAX で再描画され、単発のクリックが取りこぼされることがあるため、スクリプトは「チェック → 実際に選択された集合を読み戻す → 未反映分を再チェック」を最大 4 巡まで繰り返します。末尾が「選択済み N / M」で M に達していなければ、その結果は仕様上使えません。

```bash
# オフライン：見積書の初回算定に
py madrid_fee.py --countries ID,IL --classes 2 --date 2026/11/01

# 実測：金額に争いがあるときの判定に
py madrid_feecalc_live.py --origin US --classes 1 --countries JP,ID,IL
```

**`--date` が決定的なパラメータです。** WIPO の個別手数料ページは*現在*の金額しか表示しませんが、計算機は「出願予定日」に有効な料率を適用します。料率の発効日（多くは 11 月 1 日、1 月 1 日）をまたぐ場合は、出願予定日ごとに分けて算定しなければなりません — 同じ出願が発効日の前後で二つの価格になり得ます。実測済みの記録：**2026-11-01 発効、インドネシア 91 → 125、イスラエル 471 → 503**。

### 期限：二種類の期限があり、実務が最も取り違えるところ

**拒絶通報期間**は「官庁が通知を発する期限」で、月単位です。基準は **12 か月**、プロトコル第 5 条(2)(b) の宣言をした締約国は **18 か月**、さらに第 5 条(2)(c) の宣言があり異議が生じた場合は最長で約 **25 か月**。事後指定では**登録日**から起算します。

**回答期限**は「名義人が暫定拒絶に回答する期限」で、日／月単位、実施細則第 17 条(7) に基づき国ごとに通報されます。

- 中国（CN）：職権拒絶 **15 日** / 異議に基づく拒絶 **30 日**。WIPO の送達を受領した日から起算
- フランス（FR）：1 か月 / 2 か月 · 英国（GB）：2 か月 · ドイツ（DE）：4 か月 · 日本（JP）：3 か月
- 米国（US）：6 か月（職権）/ 40 日（異議。TTAB の命令の日から起算）· タイ（TH）：90 日

> **網羅性に関する警告。** WIPO のこの表が収録するのは **38 加盟国**（全 117 のうち）にすぎず、起算基準は **6 通り**あります（名義人の受領 / WIPO の送達 / 官庁の発出 / WIPO の受領 / 発出後 14 日目 / TTAB の命令）。**一覧に無い ＝ 回答期限が無い、ではありません。** 公式の起算基準が「受領日」でない場合、`madrid_deadline.py` は受領日からのカウントダウンを**拒否**します（受領日から数えると残り時間を過大に見積もるため）。その場合は公式の起算日の提示を求めます。

**15 / 30 日と 12 / 18 / 25 か月を混同しないでください。** 前者は名義人の回答期限、後者は官庁が通知を発する期限です。

### セントラル・アタック：3 か月、しかも宛先を間違えないこと

国際登録は登録日から **5 年**のあいだ基礎出願／基礎登録に依存し、基礎が取り消されれば連動して失効します。救済はプロトコル第 9 条の五により、取り消しの日から **3 か月以内に各指定官庁へ直接**変形登録を提出することです。変形後の国内出願は**元の国際登録日と優先日**を保持します。

> 頻出する誤り：変形登録を WIPO に提出してしまう。変形登録の宛先は**各指定官庁**であり、国際事務局ではありません。

### 宣言の確認：まず宣言を確認し、それから方針を決める

締約国は 17 類の宣言・通報を行うことができ、効力・手数料・期限に直接影響します。指定締約国を選ぶ際は、次の順に確認します。個別手数料を取るか → 拒絶通報期間はどの段階か → 特別な要件があるか（使用意思の宣言など）→ 分割・統合が使えるか → ライセンスの記録が国際的な効力を持つか。

> **セーフガード条項の注意。** 指定締約国と本国の締約国が**ともに協定とプロトコルの二重締約国**である場合、その国の第 8 条(7) および第 5 条(2)(b)/(c) に基づく宣言は、両者の関係では**効力を生じません**（プロトコル第 9 条の六(1)(b)、手数料表 2.4 / 5.3 / 6.4）。中国の出願人がフランス、ドイツ、イタリア、スペイン、スイスなどの二重締約国を指定するときは、この点を事案ごとに確認する必要があります。

### 条約全文：一字一句照合でき、コマンド一発で再取得

協定（18 条）、プロトコル（16 条 + 10 の細則）、実施細則（41 規則 + 手数料表）、行政上の指示（7 部 19 条 + 第 11 条の二）を、**中国語の逐語全文**（WIPO Lex の正式翻訳）と**英語の公式全文**の対で収録しています。公式テキストが更新されたら、`wipo_lex_fetch.py` で再取得するだけです。

```bash
# まず構造を下見し、冒頭・末尾の条文と条数の勘定を照合する
py -B wipo_lex_fetch.py --url https://www.wipo.int/wipolex/en/text/384637 --inspect
```

## 中核メカニズム

### 変動データの鮮度ゲート

本スキルで最も硬い規則です。手数料・個別手数料・締約国の宣言・加盟数・為替・条約の版は、変わり得るものすべてが §3.0 の一覧に「基準日 + 推奨確認周期 + 公式の確認先」を登録していなければなりません。

| データ項目 | 基準日 | 確認周期 | 確認先 |
|-----------|--------|---------|--------|
| 加盟数 | 2026-09-23 | 毎月 | WIPO 加盟国ページ |
| WIPO 手数料 | 手数料表 2023-02-01 版 | 四半期ごと | WIPO 手数料表 |
| 締約国ごとの個別手数料 | 2026-08-23 | 毎月 | WIPO 個別手数料ページ |
| 締約国の宣言 | 2026-03-15 | 毎月 | WIPO 宣言ページ |
| 回答期限の表 | 2026-08-28 | 毎月 | WIPO 回答期限ページ |
| CHF 為替 | **内蔵しない** | 支払いのたびに | リアルタイム為替 / Fee Calculator |

確認周期を過ぎた場合、または利用者から明示の求めがあった場合、**必ずオンラインで確認してから回答します**。見つからないものは「なし」と答えます。

### データの一点管理

同じデータを二か所に置かず、二つの口径が併存することを避けます。

- 手数料の数値 → `references/madrid-fees.md`（機械可読の写し：`scripts/madrid_fee_data.json`）
- FAQ と反例 → `references/madrid-faq.md`
- 締約国の宣言 → `references/madrid-declarations.md`（17 類の番号付き）

「人が読む版 ↔ 機械が読む版」の整合は、`selftest.py` の専用ケースが締約国ごとに照合します — 文書だけ直してデータを同期しなければ、自己テストが赤くなります。

### 二種類の期限を分離して計算

`madrid_deadline.py` は一つのコマンドで両方を扱いますが、論理は厳格に分離しています。

- 既定モードは**拒絶通報期間**（12 / 18 / 25 か月）— 12 か月を既定とし、宣言の確認を要求します。**18 か月には明示的な `--declared-18` が必要**で、12 か月を前提に異議による延長を主張すると即座に遮断されます（第 5 条(2)(c) は 18 か月の宣言を前提とするため）
- `--respond` は**回答期限**を計算 — 実施細則 17(7) の全 38 加盟国のデータを内蔵し、6 種の起算基準を判定します

### 出力形式の鉄則

スキル自身の参照内容には Markdown の知識表を使えます。しかし**呼び出し後に利用者へ渡すテキストでは Markdown の表を禁じます** — 代わりに「項目：金額（根拠条文）」の行、締約国ごとの `·` の要点、字下げによる整列で示します。金額と期限は単位と根拠を省けません。変動データを含む場合は、再確認が必要かどうかを必ず添えます。

### 反例ライブラリ

`references/madrid-faq.md` は 16 の頻出反例を収録し、本スキル自身の過去の口径の誤りの訂正も含みます。とくに頻度が高く被害の大きいもの：拒絶通報期間を 18 か月と決め打ちする、補充手数料と個別手数料を区別しない、猶予期間の割増を「納付総額の 50%」で計算する、猶予期間の最終日に支払う、更新のついでに商品を直す、セントラル・アタック後に WIPO へ変形登録を出す。

> 底線となる原則：マドリッドの実務では、**期限と方式の適合が、主張の巧拙よりも重い**。期限を逃せば、権利は原則として回復できません。

## 汎用 AI との違い

汎用モデルに「マドリッドの手数料はいくらか」と聞けば、**基準日が無く、出所を辿れず、期限切れかもしれない**数字が返ってきます。本スキルの違いは三点です。

| | 汎用 AI | madrid-trademark |
|---|---|---|
| 手数料の数字 | 学習データのスナップショット。基準日なし | 基準日 + 公式の確認先 + 実測による再確認 |
| 拒絶通報期間 | 「18 か月」と答えがち | 12 か月を基準とし宣言で決まる。25 か月には厳格な前提 |
| データが無いとき | もっともらしい答えを作りがち | 「なし」と答える |
| 期限の計算 | 暗算。誤りやすい | `madrid_deadline.py` が 6 種の起算基準を判定 |
| 条文の引用 | 言い換え。照合できない | 協定／プロトコル／実施細則／行政上の指示の逐語全文。grep で照合可能 |
| 成果物 | 一段落の文章 | チェックリスト + 回答メモ + 締約国ごとの費用明細 |

汎用の対話は**より良い会話**です。本スキルは**「見つからない／正確でない」という不確かさを消す**ためのものです。

## データと出所

- **捏造ゼロ。** 見つからないデータは「なし」と答えます。見積もらず、プレースホルダで埋めません。
- **テレメトリなし。** 本スキルは純粋にローカルのファイル群です。外部へ何も送信せず、鍵も含みません。
- **条文は照合可能。** 条約全文はすべて WIPO Lex の公式ページから取得し、取得スクリプト `wipo_lex_fetch.py` も同梱しているので、自ら再取得して照合できます。文末の「要点と正誤表」はスキルが整理した内容で公式テキストではありません。**条文の引用は常に正文によります。**
- **再現可能。** 日付計算のスクリプトはすべて `--today` による再現に対応し、期限の結果を遡って検証できます。
- **免責。** スクリプトの出力は見積もりと注意喚起です。最終的には WIPO / CNIPA の公式通知および公式請求額によります。

## 適用範囲と限界

できないことを正直に述べます。

- **指定締約国の実体商標法の逐条解釈や訴訟戦略は扱いません。** 各国国内法（米国ランハム法の個別規定、EU 商標規則、各国の拒絶不服審査の実務細目）は、その国の法または現地の弁護士にご確認ください。
- **単一国家・地域の商標出願は扱いません。** USPTO、EUIPO、JPO への直接の国内出願は本線の外で、マドリッドとの接続の比較としてのみ触れます。
- **類否の主観的判断や勝訴率の予測はしません。** 拒絶への対応の枠組みとテンプレートは提供しますが、特定の商標の登録可能性、類否リスク、事件の帰趨は予測しません。
- **為替のリアルタイム取得は内蔵していません。** CHF の為替は変動データで、支払いのたびに自ら確認する必要があります。
- **実務家の判断を代替しません。** これは実務の補助具であり、法的効力を持つ意見書ではありません。
- **事件簿が無ければ個別の方針は出せません。** まず拒絶通知、登録番号、指定締約国などの資料をご提示ください。

**最良の回答を得るための聞き方：** 事務の類型（出願 / 更新 / 拒絶への対応 / 変更・譲渡 / 変形登録 / 手数料 / 期限）+ 重要な事実（指定締約国、類の数、基礎の状態、登録日または登録番号、拒絶の有無と国）+ 期待する成果物（費用の見積もり / 期限のカウントダウン / 回答のひな形 / 手続のステップ / リスク一覧）。

## いきさつ

マドリッドの案件の苦労はきわめて具体的です。**同じことが、協定に一度、実施細則に一度、手数料表に一度、さらに各締約国の宣言に一度ずつ書かれている**——そしてそのどれか一つの改定が、先週まで正しかった口径を一瞬で無効にする。手数料の改定、宣言する国の増加、加盟数の +1。実務では、そのたびに全部を確認し直すことになります。

そこで四層の法的テキスト（協定 / プロトコル / 実施細則 / 行政上の指示）を、手数料表・宣言ページ・公式ガイドとともに逐語全文として取り込み、変わり得るデータにはすべて鮮度の刻印を打ち、計算できるもの — 期限と手数料 — は再現可能なスクリプトにしました。「確認」という作業そのものを、一つの呼び出しにするために。丸半日ではなく。
