**一套面向全球商標代理人、智慧財產權律師與企業法務的馬德里體系實務技能。**

<br>

不是「馬德里是什麼」的科普問答，而是**能落在案頭上用的東西**：算得準的規費清單、算得清的兩類期限、可直接填寫的檢查清單與答辯要點備忘錄、逐字可核的條約全文。

WIPO 國際階段程序對任一締約方通用——本技能以**締約方中立（office-neutral）視角**撰寫，中國（CNIPA）銜接僅作可選專章。你從 USPTO、EUIPO、JPO 還是 CNIPA 出發，都一樣能用。

技能內建的每一個規費數字、每一條期限、每一份聲明，都標註了**資料基準日與官方核驗入口**。查不到的，它直接回你「無」——不編。

```
git clone https://github.com/huiningip/madrid-trademark ~/.workbuddy/skills/madrid-trademark
```

跨 agent 通用——只要支援 skills 的 agent 都能裝。

> 📣 **易變資料不寫死。** 規費、單獨規費、締約方聲明、成員數、法條均設「基準日 + 建議複核週期 + 官方核驗入口」，到點即提示聯網核驗，禁止採信搜尋引擎快取值。

## 裝上就能用

```bash
# 方式一：skills CLI
npx skills add huiningip/madrid-trademark

# 方式二：git clone（CLI 同步異常時兜底）
git clone https://github.com/huiningip/madrid-trademark ~/.workbuddy/skills/madrid-trademark
```

> **裝完先自檢**：這不是一個只有 `SKILL.md` 的技能。`references/`（13 份 Markdown + 2 份官方 PDF）、`scripts/`（7 個 Python 腳本 + 2 份 JSON 資料）、`templates/`（2 份範本）都是被正文以 `@` 相對路徑引用的實體，缺一即會斷鏈。
>
> 裝完看一眼安裝目錄：若只有 `SKILL.md`、沒有那幾個子目錄，說明同步工具只抓了單一檔案——改用上面的 `git clone` 重新裝一次即可。
>
> 腳本自檢（Python 3.10+，離線腳本僅用標準庫）：
>
> ```bash
> py -B scripts/selftest.py     # 9 組用例，全綠即為完整部署
> ```

然後在任意支援 skills 的 agent 裡直接說話：

```
「馬德里 指定日本 單獨規費 現在多少，幫我算一下 3 類」
「馬德里 臨時駁回 中國 15 日還是 30 日，從哪天起算」
「客戶基礎註冊 2021 年註冊的，今年被撤了，還能轉化嗎」
「馬德里續展 2016-07-01 註冊 10 年期，現在辦還來得及嗎」
「算一下指定 US/JP/ID/IL 的駁回期，哪些國要按 18 個月盯」
```

沒有表單、沒有精靈、沒有註冊門檻。問一句，拿一份能直接進案卷的東西。

## 涵蓋情境

### 規費：兩條路徑，不得互相替代

`scripts/madrid_fee.py` 是**離線快照**計算——無網路、無瀏覽器即可用，內建 76 個締約方單獨規費，並按 `--date` 套用**已公告的費率調整**。

`scripts/madrid_feecalc_live.py` 是**官方實測**——用真實瀏覽器驅動 WIPO Fee Calculator，輸出逐國權威金額，是金額爭議的裁決依據。

> 官方計算器是 JSF 應用，締約方清單與結果均由 JS 觸發渲染，**無法用 HTTP 抓取**。腳本內建「勾選 → 回讀 → 補勾」最多 4 輪重試，因為每次勾選都會觸發 AJAX 重繪、單次點擊可能被吞；結尾若顯示「已勾選 N / M」未達 M，結果即判為不可用。

```bash
# 離線：給報價單做初算
py madrid_fee.py --countries ID,IL --classes 2 --date 2026/11/01

# 實測：金額有爭議時用它裁決
py madrid_feecalc_live.py --origin US --classes 1 --countries JP,ID,IL
```

**`--date` 是決定性參數。** WIPO 單獨規費頁只顯示**當前**金額，而計算器按「預計提交日」適用當期費率。跨費率生效日（常見 11 月 1 日、1 月 1 日）必須按預計提交日分別核算——同一份申請在生效日前後可能是兩個價。已實測記錄：**2026-11-01 生效，印尼 91 → 125、以色列 471 → 503**。

### 期限：兩類期限，實務最易混淆

**駁回期**是「主管局發出通知的期限」，按月計：基準 **12 個月**，已依議定書第 5 條(2)(b) 聲明者 **18 個月**，兼具第 5 條(2)(c) 聲明且發生異議最長約 **25 個月**。後期指定自**登記日**起算。

**答辯期**是「註冊人答辯臨時駁回的期限」，按日／月計，逐國依實施細則第 17 條(7) 通報：

- 中國（CN）：依職權駁回 **15 日** / 異議類駁回 **30 日**，自收到 WIPO 轉交通知之日起算
- 法國（FR）：1 個月 / 2 個月 · 英國（GB）：2 個月 · 德國（DE）：4 個月 · 日本（JP）：3 個月
- 美國（US）：6 個月（依職權）/ 40 日（異議，自 TTAB 命令之日起算）· 泰國（TH）：90 日

> **涵蓋度警示**：WIPO 該表僅收錄 **38 個成員**（共 117 個），起算基準有 **6 種**（註冊人收到 / WIPO 轉交 / 局發出 / WIPO 收到 / 局發出後第 14 日 / TTAB 命令）。**未列名 ≠ 無答辯期限。** 官方基準非「收到之日」類時，`madrid_deadline.py` 會**拒絕**按收件日倒數（按收件日算會高估剩餘時間），並要求提供官方起算日。

**不得把 15 / 30 日與 12 / 18 / 25 個月混為一談**——前者是註冊人答辯的期限，後者是主管局發通知的期限。

### 中心攻擊：3 個月，且方向不能錯

國際註冊自註冊日起 **5 年**內依賴基礎申請／註冊；基礎被撤銷則隨之失效。救濟是依議定書第 9 條之五，在撤銷之日起 **3 個月內直接向各指定局**提交轉化申請，轉化後享有**原國際註冊日與優先權日**。

> 高頻錯誤：向 WIPO 提交轉化申請。轉化是向**各指定局**提的，不是向國際局提的。

### 聲明核查：先核聲明，再定策略

締約方可作出 17 類聲明與通知，直接影響效力、規費與期限。選指定締約方時按序核查：是否收單獨規費 → 駁回期幾檔 → 是否有特殊要求（如使用意圖聲明）→ 分割／合併是否適用 → 授權備案是否有國際效力。

> **保全條款提醒**：被指定締約方與原屬締約方**均為協定 + 議定書雙參加國**時，該國依第 8 條(7)、第 5 條(2)(b)/(c) 所作聲明在雙方關係中**不生效力**（議定書第 9 條之六(1)(b)、費用表第 2.4/5.3/6.4 項）。中國申請人指定法國、德國、義大利、西班牙、瑞士等雙參加國時，須逐案核驗此項。

### 條約全文：逐字可核，一鍵重抓

協定（18 條）、議定書（16 條 + 10 分條）、實施細則（41 條 + 費用表）、行政規程（7 部分 19 條 + 第 11 條之二）均收錄**中文逐字全文**（WIPO Lex 中文正式翻譯）與**英文官方全文**配對。官方文本更新後，用 `wipo_lex_fetch.py` 重跑即可：

```bash
# 先勘察結構，核對首尾與條號計數
py -B wipo_lex_fetch.py --url https://www.wipo.int/wipolex/en/text/384637 --inspect
```

## 核心機制

### 易變資料時效閘門

技能裡最硬的一段規則。規費、單獨規費、締約方聲明、成員數、匯率、條約版本——凡會變的資料，都必須在 §3.0 的時效清單裡登記「基準日 + 建議複核週期 + 官方核驗入口」：

| 資料項 | 基準日 | 複核週期 | 核驗入口 |
|--------|--------|----------|----------|
| 成員數 | 2026-09-23 | 每月 | WIPO 成員頁 |
| WIPO 官費 | 費用表 2023-02-01 版 | 每季 | WIPO 費用表 |
| 各締約方單獨規費 | 2026-08-23 | 每月 | WIPO 單獨規費頁 |
| 締約方聲明 | 2026-03-15 | 每月 | WIPO 聲明頁 |
| 答辯駁回期限表 | 2026-08-28 | 每月 | WIPO 應答期限頁 |
| CHF 匯率 | **不內建** | 每次繳費前 | 即時匯率 / Fee Calculator |

超過複核週期或使用者明確要求時，**必須聯網核驗後再作答**。查不到的直接答覆「無」。

### 資料單點維護

同一份資料不存兩處，避免兩套口徑並存：

- 規費數值唯一權威源 → `references/madrid-fees.md`（機器可讀鏡像 `scripts/madrid_fee_data.json`）
- FAQ 與反例唯一權威源 → `references/madrid-faq.md`
- 締約方聲明唯一權威源 → `references/madrid-declarations.md`（17 類編號）

兩份「人類可讀版 ↔ 機器可讀版」的一致性，由 `selftest.py` 的專用用例逐國比對把關——文件改了、資料沒同步，自檢會紅。

### 兩類期限分離計算

`madrid_deadline.py` 一條命令涵蓋兩類期限，但邏輯嚴格隔離：

- 預設模式算**駁回期**（12 / 18 / 25 個月）——預設 12 個月並要求核驗聲明，**18 個月須顯式 `--declared-18`**；在 12 個月基礎上主張異議延長會被直接攔截（第 5 條(2)(c) 以 18 個月聲明為前提）
- `--respond` 算**答辯期**——內建 WIPO Rule 17(7) 全 38 成員資料與 6 種起算基準判定

### 輸出格式鐵律

技能自身的參考內容允許 Markdown 知識表；但**呼叫後向使用者交付的文字嚴禁使用 Markdown 表格**——改用逐行「項目：數值（依據條款）」、分締約方 `·` 要點、縮排對齊呈現。金額與期限不得省略單位與依據；涉及易變資料須一併說明是否需重新核驗。

### 反例庫

`references/madrid-faq.md` 收錄 16 條高頻反例，含本技能歷史口徑錯誤的更正說明。最高頻、後果最重的幾條：預設 18 個月駁回期、補充費與單獨規費不分、寬限期附加費按「應繳總額 50%」計、寬限期最後一天才繳費、續展時順手改商品、中心攻擊後向 WIPO 提轉化。

> 底線原則：馬德里實務中，**時效與形式合規比爭辯能力更重要**。錯過期限 = 權利通常不可回復。

## 和通用 AI 問答的關係

直接問大模型「馬德里規費多少」，你會拿到一個**沒有基準日、無法追溯來源、可能過期**的數字。本技能的差異在三個地方：

| | 通用 AI 問答 | madrid-trademark |
|---|---|---|
| 規費數字 | 訓練語料裡的快照，無基準日 | 標註基準日 + 官方核驗入口 + 可實測複核 |
| 駁回期 | 常答「18 個月」 | 預設 12 個月基準，須核聲明；25 個月有嚴格前提 |
| 資料缺失 | 傾向於編一個像樣的答案 | 直接回覆「無」 |
| 期限計算 | 心算，易錯 | `madrid_deadline.py` 按 6 種起算基準判定 |
| 法條引用 | 轉述，不可核 | 協定／議定書／細則／行政規程逐字全文，可 grep 核對 |
| 交付物 | 一段文字 | 檢查清單 + 答辯備忘錄 + 逐國費用明細 |

通用問答是**更好的聊天**，本技能是**讓「查不到 / 查不準」這層不確定性消失**。

## 資料與時效

- **零編造**：查不到的資料直接回覆「無」，不估算、不佔位填充。
- **無遙測**：技能為純本機檔案包，不向外傳送任何資料、不含任何金鑰。
- **條文可核**：條約全文均來自 WIPO Lex 官方頁面，抓取腳本 `wipo_lex_fetch.py` 一併開源，可自行重抓複核。文末「要點與勘誤」為技能整理內容，非官方文本，**引用條文一律以正文為準**。
- **可重現**：所有日期計算腳本支援 `--today` 重現，期限結果可回溯。
- **免責**：腳本輸出為估算與提示，最終以 WIPO / CNIPA 官方通知與官方帳單為準。

## 能力邊界

誠實說明它做不到什麼：

- **不涵蓋締約方實體商標法逐條解讀與訴訟攻防**。指定國國內法（美國《蘭哈姆法》具體條款、歐盟商標條例、各國駁回復審實務細節）須另詢該國法律或當地律師。
- **不處理單一國家 / 區域性商標申請**。直接向 USPTO、EUIPO、JPO 遞交的純國內申請不在主流程內，僅作與馬德里的銜接對比說明。
- **不做近似性主觀判斷與勝訴率預測**。提供駁回應對框架與範本，不對具體商標的可註冊性、近似風險或案件勝負作預測。
- **不內建即時匯率抓取**。CHF 匯率為易變資料，每次繳費前須自行核驗。
- **不替代執業判斷**。這是實務輔助工具，不是具法律效力的意見書。
- **缺少案卷時給不出針對性方案**。請先提供駁回通知、註冊號、指定締約方等材料。

## 緣起

做馬德里案子的痛點很具體：**同一件事，條約裡寫一遍、實施細則裡寫一遍、費用表裡寫一遍、各締約方聲明裡各寫一遍**，而其中任何一處改版，都可能讓上週還算對的口徑突然作廢。規費改一次價、駁回期多一個國家聲明、成員數 +1，實務上就得重新核一遍。

於是把四層法律文本（協定 / 議定書 / 實施細則 / 行政規程）連同費用表、聲明頁、官方指南拉下來做成逐字全文，把會變的資料全部打上時效戳，把能算的期限和費用寫成可重現的腳本——讓「查證」這件事本身變成一次呼叫，而不是一個下午。
