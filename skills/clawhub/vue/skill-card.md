## Description: <br>
Builds, debugs, and reviews Vue 3 apps, covering reactivity, components, composables, Pinia state, Vue Router, forms, performance, migration, testing, TypeScript, and common runtime failures. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineers use this skill to build, debug, review, and migrate Vue 3 applications. It helps diagnose reactivity, component communication, routing, state, SSR hydration, forms, performance, security, testing, and TypeScript issues. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may read and update Vue-specific preference files under ~/Clawic/data/vue/, which can retain project conventions or sensitive details for future assistance. <br>
Mitigation: Avoid storing secrets or sensitive project details in those preference files, and review or remove stored Vue preferences when working across projects with different confidentiality needs. <br>
