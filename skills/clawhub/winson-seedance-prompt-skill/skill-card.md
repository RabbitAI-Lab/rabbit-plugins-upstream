## Description:

Transforms a creator's video idea into copy-ready Jimeng Seedance 2.5 prompts using structured scene formulas, transition techniques, and prompt quality checks.

This skill is ready for commercial/non-commercial use.

## Use Case:

External creators and prompt-writing agents use this skill to turn short creative briefs, reference-media plans, edit requests, or narrative concepts into complete Seedance 2.5 video prompts. It is intended for text guidance and prompt generation, not code execution.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated prompts may include copyrighted characters, marks, or platform-unsuitable IP references if the user's idea asks for them.

Mitigation: Review prompts for copyright and IP handling before platform use; convert known IP references into original descriptions and add explicit exclusion language.

Risk: Generated video prompts can still lead to unwanted subtitles, audio, visual drift, inconsistent characters, or malformed scenes.

Mitigation: Apply the skill's quality checklist before use, including negative constraints, character consistency checks, material references, and continuous timing.
