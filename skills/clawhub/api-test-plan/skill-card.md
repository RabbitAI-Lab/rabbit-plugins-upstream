## Description: <br>
Plan API endpoint or service tests that cover functional, negative, contract, auth, validation, error, and non-functional cases. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and QA engineers use this skill to draft API test plans for REST or GraphQL endpoints. It helps cover functional behavior, validation, authorization, contract conformance, error handling, setup, and non-functional checks. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated plans can be inaccurate when API contracts, status codes, authorization rules, or dependencies are incomplete. <br>
Mitigation: Review the plan against the actual API contract, schemas, auth configuration, and service behavior before using it as test coverage. <br>
Risk: Users could expose sensitive production tokens, payloads, or customer data while asking for a test plan. <br>
Mitigation: Use sanitized API specifications, redacted examples, and non-production credentials when prompting the skill. <br>
