## Description:

Live SEO data via DataForSEO MCP server: SERP analysis, keyword research, backlink profiles, on-page analysis, competitor and content analysis, business listings, AI visibility, and domain analytics.

This skill is ready for commercial/non-commercial use.

## Use Case:

SEO practitioners, marketers, and developers use this skill to request live DataForSEO-backed SERP, keyword, backlink, on-page, competitor, local listing, and AI visibility analysis from an agent.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill sends keywords, domains, URLs, and SEO queries to DataForSEO for live research.

Mitigation: Install and use it only when DataForSEO processing is intended, and avoid submitting sensitive or confidential queries unless that use is approved.

Risk: Paid DataForSEO API calls, scraper operations, backlink analysis, and large result sets can incur costs.

Mitigation: Review DataForSEO budget settings, run the documented cost check before calls, request confirmation for expensive operations, and stop when a daily budget would be exceeded.

Risk: Default US English location and language settings can produce misleading results for other markets.

Mitigation: Specify the intended location and language when the analysis is not for US English.
