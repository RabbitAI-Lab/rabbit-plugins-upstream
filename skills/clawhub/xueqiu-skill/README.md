# xueqiu-skill

雪球数据 API 的 OpenClaw Skill，用于在对话中直接查询雪球组合、用户、行情和调仓数据。

## 功能

- 搜索雪球用户、投资组合和帖子
- 按收益过滤并排行组合
- 获取组合实时行情与历史净值
- 查看组合详情、持仓和调仓历史
- 查看用户创建的组合与原创发帖

详细接口规范见 [SKILL.md](./SKILL.md)，参数说明和返回字段见 [接口调用说明.md](./接口调用说明.md)。

## 安装

按 OpenClaw 加载技能的方式引入本目录即可，具体步骤请参考 OpenClaw 文档。

## 准备凭证

1. 前往 https://wxpub.aibana.art 注册账号
2. 在「Skill 技能」页面创建 `app_id` 和 `secure_key`
3. 账户充值（每次成功调用扣 0.2 元，失败自动退款）

将凭证告知 Claude，例如：

> 我的 app_id 是 `ak_xxx`，secure_key 是 `yyy`

## 使用示例

直接用自然语言提问，Claude 会自动调用相应接口：

- 「帮我搜索关键词为"实盘"的组合，按总收益排前 5」
- 「搜一下"散户老牛"相关的帖子」
- 「ZH349701 的当前净值是多少？」
- 「拉一下组合 12363 最近 10 次调仓」
- 「天地侠影最近发了哪些帖子？」

## 接口端点

| 环境 | Base URL |
|---|---|
| 线上 | `https://wxpub.aibana.art` |
| 本地 | `http://localhost:8080/wxpublic_fetch` |

所有接口走 `POST /xueqiu/{method}`，请求体为 JSON。

## 计费与限速

- 每次成功调用扣 0.2 元，失败自动退款
- 全局限速：60 秒内最多 10 次上游请求（所有用户共享）
- 建议客户端节奏：每 6 秒一次请求最稳定
- 队列超 20 个返回 429，等待超 120 秒返回 503

## 常见错误

| 状态码 | 含义 |
|---|---|
| 401 | 凭证无效，检查 app_id / secure_key |
| 402 | 余额不足，前往后台充值 |
| 429 | 请求过多，稍后重试 |
| 502 | 上游雪球调用失败，已自动退款 |

完整错误码见 [SKILL.md](./SKILL.md#错误处理)。
