## Description:

Discover and call ScraperSocial endpoints for public social media and web data across 33 sources, excluding personal-contact endpoints.

This skill is ready for commercial/non-commercial use.

## Publisher:

[nikhonit](https://clawhub.ai/user/nikhonit)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agents use this skill to find supported public-data endpoints and retrieve social media or web data through ScraperSocial without choosing a platform-specific skill first.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: API calls can consume ScraperSocial credits, especially when retrieving large volumes of data.

Mitigation: Review endpoint costs and scope requests before calling; use free endpoint discovery first.

Risk: Collected social and web data may be subject to access or use restrictions.

Mitigation: Collect only data you are authorized to use; personal-contact endpoints are not callable through this skill.
