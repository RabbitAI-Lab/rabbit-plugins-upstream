## Description:

Checks author-approved world rules against short scene excerpts and returns evidence-linked findings with revision options requiring author approval.

This skill is ready for commercial/non-commercial use.

## Publisher:

[xxjrq](https://clawhub.ai/user/xxjrq)

### License/Terms of Use:

MIT-0

## Use Case:

Authors and editors use it to check chapter scenes against approved rules for triggers, costs, and exceptions. It requests missing rule details and presents evidence-linked findings and revision choices for author approval.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Suggested revisions may not match the author's intent or approved canon.

Mitigation: Review the cited scene evidence and approve each suggested change before applying it.

Risk: The documented install command does not pin an installer version or repository revision, which can reduce reproducibility.

Mitigation: Use a reviewed installer version and repository revision for reproducible installation.
