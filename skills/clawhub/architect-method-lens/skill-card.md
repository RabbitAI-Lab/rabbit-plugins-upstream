## Description:

Extract evidence-backed design methods from an architect's writings, interviews, drawings, and built works, then apply those methods critically to a current architectural project.

This skill is ready for commercial/non-commercial use.

## Publisher:

[caninlew](https://clawhub.ai/user/caninlew)

### License/Terms of Use:

MIT-0

## Use Case:

Architects, designers, researchers, and external agents use this skill to convert architect sources and project evidence into traceable method profiles, method cards, comparative critiques, and project-specific design questions without copying signature style.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Project or source material may include confidential client, site, or design information.

Mitigation: Confirm source access permissions before using project files or browsing, and redact sensitive material when sharing outputs.

Risk: Architectural analysis can overstate intent, code compliance, buildability, or recurring methods when evidence is thin.

Mitigation: Use the evidence model, source register, confidence labels, and counter-lens checks before treating any method card as design guidance.

Risk: Applying a named architect's lens can drift into style mimicry or unsupported form copying.

Mitigation: Translate methods into project-specific questions and evaluation criteria, and preserve the current project's authorship, constraints, and professional review obligations.
