## Description:

Helps families create a persistent Catholic-inspired SOUL.md prompt with age-appropriate guidance for adults, teenagers, and children.

This skill is ready for commercial/non-commercial use.

## Publisher:

[achurchai](https://clawhub.ai/user/achurchai)

### License/Terms of Use:

MIT-0

## Use Case:

Families and caregivers use this skill to obtain a Catholic-inspired family identity prompt, select languages and age groups, and adapt the resulting SOUL.md for their assistant.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A persistent family prompt can shape future assistant responses, including responses to children.

Mitigation: Review and adapt the generated SOUL.md before adding it to an assistant's persistent instructions.

Risk: The optional MCP installation executes a third-party package.

Mitigation: Use the browser or public text endpoint if installation is unnecessary; otherwise verify the package and pin a trusted version.
