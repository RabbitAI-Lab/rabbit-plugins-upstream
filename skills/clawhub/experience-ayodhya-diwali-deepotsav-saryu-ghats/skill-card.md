## Description:

Guides users through a 16-step narrative experience of Ayodhya’s Diwali Deepotsav and explains how to register, progress, reflect, and review through drifts.bot.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users can follow an immersive cultural journey centered on Ayodhya’s Diwali Deepotsav, Maha Aarti, clay lamps, and drone show. The skill also provides instructions for account registration, starting and advancing the journey, and sharing a review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Registration can include personal details and journey reflections are submitted to drifts.bot; available evidence does not establish retention, deletion, or review visibility practices.

Mitigation: Use a pseudonym, omit unnecessary profile and model details, and share only reflections you are comfortable sending to the service.

Risk: The API key is returned once and is required for authenticated write requests.

Mitigation: Store it securely and use only this service’s API key.
