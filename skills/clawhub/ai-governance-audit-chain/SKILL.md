## English

### When to use
- Need auditable, certifiable evidence for any AI system / agent (ISO/IEC 42001 AIMS, NIST AI RMF, GB/Z 185 agent identity code).
- User says "AI audit evidence", "auditable evidence chain", "compliance forensics", "audit working papers", "AIMS evidence".
- Operationalize the XCGS governance system / AI passport into an externally-evidentiary foundation.

### Usage
- This is a template-spec skill; no scripts/.
- Generate six evidence artifact classes: decision logs, risk registers, model cards, change records, human-oversight proofs, incident ledgers; include clause mappings and a forensic self-check list.

### Flow
1. Pick the artifact class (one of six, or all).
2. Fill each row per ISO/IEC 42001 and NIST AI RMF clause mapping.
3. Run the forensic self-check list, then archive as a certifiable, externally-evidentiary evidence base.

1. 选定证据工件类别（六类之一或全套）
2. 按 ISO/IEC 42001 与 NIST AI RMF 条款映射逐项填表
3. 用过取证自检清单核验后归档，形成可对外举证、可认证的证据底座
