## Description: <br>
Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
API developers, backend teams, developer-experience teams, and maintainers use this skill to create or improve practical OpenAPI and Swagger documentation for REST APIs. It helps turn API documentation requests into tailored artifacts, reusable checklists, implementation support, and verification notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may trigger on broad API-related wording. <br>
Mitigation: Use it when the request explicitly concerns generating, validating, reviewing, or improving OpenAPI or Swagger documentation for REST APIs. <br>
Risk: Generated API documentation guidance can be incomplete or misaligned with the actual service behavior if the available API details are stale or partial. <br>
Mitigation: Validate outputs against the service implementation, route definitions, schemas, examples, and any available OpenAPI or Swagger tooling before relying on them. <br>
