# 基础技术指标信号引擎（三维技术面分析）

## 一句话简介

融合趋势（EMA + ADX）、均值回归（布林带）、量价（OBV + 量比）三个维度的纯 pandas 信号引擎，通过三维投票输出买入 / 卖出 / 观望结论。

## 触发口令

```
分析 XXXX        （XXXX = 个股名称或代码，如：分析 贵州茅台 / 分析 600519）
```

## 三维框架

| 维度 | 指标 | 信号作用 |
|------|------|----------|
| 趋势 | EMA(13/55) + ADX(14，阈值 25) | 方向 + 趋势强度 |
| 均值回归 | 布林带(20, ±2) | 超买 / 超卖 |
| 量价 | OBV + 量比 | 量能配合确认 |

- 买入：趋势看多（或价格跌破布林下轨超卖）且 OBV 上行且未破上轨。
- 卖出：趋势看空（或价格突破布林上轨超买）且 OBV 下行且未破下轨。
- 观望：三维度信号分裂。
