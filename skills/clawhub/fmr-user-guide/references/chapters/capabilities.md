# 能力发现（FMR 能干什么）

## 进入条件

- 状态前置：任意状态（本章自带降级分支，各状态都能回答）。
- 意图话术："FMR 能干什么""有哪些功能""有什么用""能组合出什么玩法""值不值得装/升级""给我一份功能速览"。

## 主流程

1. 按状态分通道（主流程 P1–P3 探针结论沿用，不重跑）：

| 状态 | 通道 | 动作 |
|---|---|---|
| 未安装 | 降级 | 输出定位叙述（见能力词典）+ 提示安装（install 章）。不拼功能清单 |
| 接口面不符（SKILL.md 判定表后注） | 降级 | 视同版本低：定位叙述 + 提示升级，版本走版本证据链（SKILL.md P4 落地细则） |
| 装了未启动 | 降级 | 读版本走版本证据链（`current/package.json` → `install-info.json` 的 `nodePath` 目录 → 未知；P4 同款读取法）+ `data/router-config.json` 已配置线索字段（`routing.strategy`、`autoUpdate.mode` 等；只读，**不回显任何 key**）作"已配置线索" → 定位叙述 + 线索 + 提示启动 |
| 正常 | 探测 `GET http://127.0.0.1:5678/api/features` | 200 → 主通道；404 / "API not found" → 先取版本证据链版本号，与**技能已知最新版本**（能力词典头注记）比对：不高于已知最新 → **版本低**：定位叙述 + 提示升级（等于已知最新时附注"接口待 FMR 新版提供"）；高于已知最新 → **技能知识面可能落后**：降级速览 + 提议勘误回写（须用户确认），不建议升级；其他异常（超时/5xx）→ 报告异常，建议重试或转 troubleshoot 章，不拼清单 |

2. 主通道组装（深解一律查 `${CLAUDE_SKILL_DIR}/references/data/capability-dictionary.md`；接口自带 `name`/`summary` 是第一事实，词典与接口冲突时以接口为准）：

- **L1 定位层**：词典"定位叙述"，永远先给，版本无关，不列功能清单；
- **L2 能力层**：接口 `builtin` / `gated` 两张列表按词典归组装入五组（基础接入 / 渠道与 key / 模型路由 / 进阶玩法 / 运维保障），每条标注【开箱】（builtin）或【配置解锁】（gated）；`gated.enabled=false` 加标【支持，未启用】；`endpoints` 单列"虚拟端点入口"小节（B 表说明）；
- **L3 用法层**：接口 `combos` 逐条按 `requires` 核对——引用的 gated 特性 `enabled=false` 时标注"需先配置 X，暂不可用"；全部满足才作为可用组合呈现，并附词典深解（解决什么问题、步骤入口）。

3. `lifecycle` 字段 = `"outdated"` → 输出顶部加一句"建议升级"（跳 upgrade 章）；能力速览照常给，不拦截、不说教。

## 交付形态

| 形态 | 触发 | 内容 |
|---|---|---|
| 一屏速览 | 装/升级/迁移章收尾主动附；用户随口一问 | L1 一段 + 开箱列表 + 解锁列表 + 2 条可用组合（+过时提示） |
| 现场问答 | 用户明确问功能/用法 | L1 + L2 五组全量 + L3 全部可用组合 |
| 速览文档 | 用户要"整理一份/发我/存档" | 三层全量 + 全部组合写成 markdown 文件；文首注明生成时间与接口版本（P3 实测） |

## 未知 id 处理

接口返回词典未收录的 id：直接以接口 `name`/`summary` 呈现，归入"其他"，如实说明词典暂无深解；用户想深挖 → 只读试调（GET 只读端点、`/admin` 面板查看），不代改配置；随后**提议回写词典，用户确认才改本仓库**（回写规则见词典头部）。

## 禁则

- 特性/端点/组合清单只来自运行时 `/api/features`；任何"版本 → 功能清单"的映射不得写进本技能任何文件。
- 降级显示不拼凑功能清单；未收录 id 不猜测语义。
- 版本时效判定只信 `lifecycle` 字段；技能不内置"某版本算旧"的知识。
- 面向用户的产出物遵守界面词纪律（Free Model Router（FMR））。

## 完成判据

1. 输出逐条可溯源：主通道条目能对应到本次 `/api/features` 返回字段；降级输出能对应到机读事实（版本号/已配置线索字段）；
2. 未收录 id 已按接口文案呈现且未虚构语义；涉及回写的，用户确认前本仓库无改动；
3. `lifecycle=outdated` 时升级提示已给出；
4. 交付形态与触发匹配；文档形态文首含生成时间与版本号。
