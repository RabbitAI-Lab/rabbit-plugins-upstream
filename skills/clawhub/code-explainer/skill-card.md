## Description: <br>
Explain what a piece of code does in plain English, at the depth the reader needs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[mohitagw15856](https://clawhub.ai/user/mohitagw15856) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, engineers, and code reviewers use this skill to understand unfamiliar snippets or files, get a one-line summary, walk through logic step by step, and identify non-obvious behavior, bugs, edge cases, or code smells. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Users may provide sensitive proprietary code for explanation. <br>
Mitigation: Only submit code that the user is comfortable having the agent process, and avoid sharing confidential snippets unless the environment is approved for that material. <br>
Risk: Code explanations and bug notes can be incomplete or misleading when context is partial. <br>
Mitigation: Treat the output as review guidance and confirm important findings against the full codebase, tests, and runtime behavior before making changes. <br>
