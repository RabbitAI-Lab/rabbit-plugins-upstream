## Description: <br>
顺序阅读工具-免费版 helps an agent guide users through long documents in order, generate structured reflection notes, track reading progress, extract key concepts, and save local Markdown notes. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[thcjp](https://clawhub.ai/user/thcjp) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
External users and developers use this skill to read long-form text or Markdown documents sequentially, produce structured reflections, extract concepts, and preserve progress in local Markdown notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: User-selected documents may be read into the agent context during long-form reading. <br>
Mitigation: Use the skill only with documents the user intends to share with the agent, and avoid sensitive files unless that disclosure is acceptable. <br>
Risk: The skill may write Markdown notes or progress files to the provided output path or documented default. <br>
Mitigation: Review the output path before execution and inspect generated notes before relying on or sharing them. <br>
