## Description:

Learn how to identify search intent behind a query and match content format to it. Covers the four intent types, SERP analysis, mixed intent, and a worked example.

This skill is ready for commercial/non-commercial use.

## Publisher:

[uzairseo](https://clawhub.ai/user/uzairseo)

### License/Terms of Use:

MIT-0

## Use Case:

Writers, editors, and content planners use this skill to identify what searchers want and plan a matching page format. It guides query wording and search-results analysis, intent classification, and content outlining.
