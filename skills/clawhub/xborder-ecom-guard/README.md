# 跨境电商合规护栏（xborder-ecom-guard）

面向美国 / 欧盟市场的跨境电商，在商品详情、广告文案、直播话术、店铺介绍、客服话术
**发布 / 提交前** 实时拦截跨境合规危险表述，按风险分级输出整改建议。纯本地、零网络、
零动态执行、零依赖。

## 检测类别（6 类 36 条）
1. 虚假评论与刷单（刷好评、刷单、虚假评价、付费评论、好评返现）
2. 原产地误导（美国制造、德国制造、原装进口、隐瞒产地）
3. CE 标识虚假宣称（CE认证、虚假CE证书、擅自加贴CE）
4. 关税与申报违规表述（低报货值、拆包避税、包税不申报、瞒报通关）
5. 安全合规宣称需核实（符合欧盟标准、无毒无害、食品级安全）
6. 跨境广告极限词与疗效宣称（最佳跨境、第一海外品牌、治疗功效、包治百病）

## 用法
```bash
python3 scripts/guard.py --text "本店美国制造，CE认证，好评返现，包税不申报"
python3 scripts/guard.py --text "..." --format json
python3 scripts/guard.py --list-categories
```

## 依据（全文公开）
美国 FTC 背书规则（16 CFR Part 255）、欧盟 GPSR（Regulation (EU) 2023/988）、
欧盟 UCPD（2005/29/EC）、欧盟市场监督条例（EU 2019/1020）。

> 部分表述（如"美国制造""CE认证"）在真实合规场景也可能使用，工具将其设为 medium 提示级，
> 建议结合真实资质 / 证明核实；明确的违法操作表述（刷单、低报货值、治疗功效等）设为 high。
