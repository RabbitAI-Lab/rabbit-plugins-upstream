## Description:

Creates Cliptude videos from saved templates using the Cliptude CLI or MCP, supporting narration scripts, voiceovers, and talking-head recordings.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mwitiderrick](https://clawhub.ai/user/mwitiderrick)

### License/Terms of Use:

MIT-0

## Use Case:

External users and content creators use this skill to generate Cliptude videos from a topic, narration script, voiceover, or presenter recording, then review and render the finished video.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Voiceover and talking-head uploads may contain recordings the user does not want to share.

Mitigation: Use only recordings the user is comfortable sharing with Cliptude.

Risk: API credentials and paid generation can expose account access or incur unwanted costs.

Mitigation: Protect API keys and set credit and revision limits before generation.

Risk: The external CLI, MCP service, and companion skills have separate trust considerations.

Mitigation: Review and trust each external tool and service separately before use.
