## Description:

Generate images from text prompts and edit or synthesize images using reference images with GPT Image 2.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to create images from prompts or edit and synthesize images using up to five reference images through GPT Image 2.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and reference images may be sent to dLazy, and API use may incur account charges; the CLI also stores an API key locally.

Mitigation: Send only prompts and images you are comfortable sharing, monitor account charges, protect the stored key, and review the pinned CLI before installation.
