## Description:

Crypto Fear & Greed index and market sentiment analysis that helps an agent assess market mood before taking a position, with artifact notes stating no network calls or API key.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers can use this skill to prompt an agent for crypto market sentiment context before considering entries or risk posture. Outputs should be treated as informational sentiment guidance, not financial advice.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The artifact does not show how the Fear & Greed score is calculated or where data comes from.

Mitigation: Treat crypto sentiment outputs as informational only and verify them against trusted market data before making financial decisions.

Risk: Crypto sentiment labels can be misleading if used as standalone trading signals.

Mitigation: Use the output only as one input in a broader review process with human judgment and independent risk checks.
