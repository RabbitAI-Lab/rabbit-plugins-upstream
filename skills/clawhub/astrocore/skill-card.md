## Description:

Connects an OpenClaw agent to the owner's AstroCore workspace for chat and persistent memory, reports, and gallery items.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dimasash2005-ship-it](https://clawhub.ai/user/dimasash2005-ship-it)

### License/Terms of Use:

MIT-0

## Use Case:

OpenClaw owners and agents use this skill to connect an AstroCore workspace, retain owner-approved memories across sessions, and share reports and gallery items.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Sensitive information could be stored in the owner's AstroCore workspace.

Mitigation: Save only owner-approved memories; do not store passwords, payment details, or other secrets.

Risk: The separate connector installation command affects the owner's server.

Mitigation: Have the owner review and run the command themselves; the agent must not install or manage the service.
