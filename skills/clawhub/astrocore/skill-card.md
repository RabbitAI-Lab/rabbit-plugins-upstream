## Description:

Connects an OpenClaw agent to AstroCore for owner-facing chat, persistent memory, reports, gallery items, and scheduled tasks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dimasash2005-ship-it](https://clawhub.ai/user/dimasash2005-ship-it)

### License/Terms of Use:

MIT-0

## Use Case:

OpenClaw owners use this skill to chat with their agent through AstroCore, retain approved memories and deliverables across sessions, and request scheduled work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Saved memories, reports, gallery items, and mission content are sent to an external AstroCore workspace.

Mitigation: Save only owner-approved content; avoid secrets and payment data.

Risk: Scheduled missions can cause the agent to run tasks later and store the results.

Mitigation: Create or change missions only with the owner's agreement, and confirm the task and schedule.
