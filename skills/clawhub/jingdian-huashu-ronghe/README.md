# 经典话术融合训练器

> **郭哥AI·出品** — 民营医疗运营实战沉淀，方法论跨行业通用

把经典书籍/课程里的沟通理论与一线真实对话融合，一键生成 **标准版 / 共情版 / 引导版** 三版话术，并附适用场景、风险提示和一线验证方式。

## 这个 Skill 解决什么问题

大多数团队的话术培训是「领导讲一遍，新人听一遍」，听完就忘。根本原因是：**理论（书上的）和实战（一线对话）是割裂的**。

本 Skill 把两者强行融合：旧书/课程给稳定基准，真实对话给一线验证，融合出三种可以直接拿去用的话术，并闭环「试用 → 反馈 → 迭代」。

## 适用行业

销售、客服、咨询（医疗/教育/保险/金融/电商）、市场运营、管理沟通——凡是「人要跟人说话成交」的场景都适用。

## 快速开始

1. 给 AI 两样东西：
   - **理论来源**：经典书籍/课程的话术或沟通理论（粘贴原文，或说明书名+章节）
   - **真实对话**：一段脱敏后的一线聊天/通话记录
2. 告诉 AI 场景（首次咨询、回访、破冰、价格谈判…）
3. 得到三版话术 + 适用场景矩阵 + 风险提示 + 一线验证方式

## 输入示例

```
旧书理论：《电话销售中的心理学》第3章——客户抗拒的是"被推销"的感觉
真实对话：客户说"我再考虑考虑"，咨询师回复"那您什么时候能决定？优惠今天截止"
场景：价格谈判/犹豫客户
```

## 输出示例（节选）

```
【标准版】"考虑是应该的。我帮你把刚才说的几点再理一下，理完你心里就有数了，来不来都没关系。"
【共情版】"我特别理解，看病不是买菜。你怕花了钱没效果，很多客户一开始都有这顾虑……"
【引导版】"你主要顾虑效果还是费用？我直接帮你对接主任，周三上午有名额，先帮你留着。"
```

## 注意事项

- 真实对话必须**脱敏**（去姓名/电话/地址）
- 医疗/金融/教育等行业内容，发布前须额外过行业合规审核
- 不得承诺效果、不得虚构优惠
