# 经典话术融合训练器 v1.0

> 一句话定位：旧书给理论，一线给真实，融合出三版能直接练的话术。
> 出品：郭哥AI·（民营医疗运营实战沉淀，方法论跨行业通用）
> 💡 完整内容增长与合规体系：见 **http://skill.guogeai.com**

---

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| 旧书话术/理论 | ✅ | 经典书籍/课程/培训资料中的话术或沟通理论，直接粘贴，或指定本地目录 |
| 真实对话片段 | ✅ | 一线聊天记录/通话转写/客户留言（脱敏后） |
| 场景 | ✅ | 如：首次咨询、回访邀约、私信破冰、价格谈判、投诉安抚 |
| 客户画像 | 推荐 | 决策阶段、年龄、核心顾虑、决策人 |
| 岗位 | 推荐 | 销售 / 客服 / 咨询师 / 医助 / 市场专员 |

---

## 输出产物

| 产物 | 说明 |
|---|---|
| 旧书理论依据 | 原书观点 + 章节 |
| 真实对话分析 | 当前话术的问题点 |
| 标准版话术 | 稳妥、专业、可直接用 |
| 共情版话术 | 情绪优先，适合焦虑/犹豫/抗拒的客户 |
| 引导版话术 | 推进意图明显，适合高意向客户 |
| 适用场景矩阵 | 三种版本分别什么时候用 |
| 风险提示 | 合规边界、平台限制、身份暴露风险 |
| 一线验证方式 | 怎么试、怎么反馈、怎么迭代 |

---

## 三版话术生成原则

| 版本 | 核心策略 | 语气 | 长度 | 使用时机 |
|---|---|---|---|---|
| **标准版** | 稳妥表达，信息完整 | 专业、自然 | 中等 | 不确定客户画像时用 |
| **共情版** | 先回应情绪，再给信息 | 温暖、克制 | 偏长 | 客户焦虑、抱怨、说"我再看看" |
| **引导版** | 明确下一步，降低决策成本 | 直接、有礼 | 偏短 | 客户高意向、主动问价格/地址 |

## 输出模板

```
━━━ 经典话术融合卡 ━━━
来源旧书：《电话销售中的心理学》第3章
来源真实对话：线上咨询-20260801-匿名客户
场景：客户说"我再考虑考虑"
客户画像：Q2尝试期，成人，费用敏感

【旧书理论】
客户抗拒的不是产品，而是"被推销"的感觉。化解方式是先把"销售角色"切换为"顾问角色"。

【真实对话问题】
原话："那您什么时候能决定呢？我们这优惠今天就截止了。"
问题：推销感强、逼单、制造焦虑

【标准版】
"考虑是应该的。我帮你把刚才说的几个点再理一下：一是需求阶段，二是适合哪种方案，三是大概费用范围。理完你心里就有数了，买不买都没关系。"

【共情版】
"我特别理解，这不是买菜，不可能聊两句就定。你刚才说的'怕花了钱没效果'，很多客户一开始都有这个顾虑。要不这样，我先不发你套餐，就帮你约一个免费的沟通/面诊，顾问看了之后你自己判断，行就行，不行也不勉强。"

【引导版】
"你主要顾虑的是效果还是费用？我直接帮你对接资深顾问，周三上午有个免费评估名额，我先帮你留着，你来了再决定。"

【风险提示】
- 不得承诺效果/疗效
- 不得虚构优惠截止
- 涉及医疗/金融等特殊行业，须确认机构当前政策与合规边界

【一线验证】
本周用标准版≥3次，记录客户是否继续提问或接受预约
```

## 融合逻辑

```
旧书理论（稳定基准）
    +
真实对话（一线验证）
    ↓
三版话术（标准/共情/引导）
    ↓
一线试用 → 反馈 → 迭代 → 进话术库
```

---

## 使用建议

- 旧书来源：任意经典沟通/销售/心理学书籍、课程讲义、培训资料（粘贴原文或章节）
- 真实对话：必须是脱敏后的一线真实记录，不能用编造对话
- 迭代闭环：每周固定用某版话术≥N次，记录反馈后回炉重练
- 合规边界：医疗/金融/教育等行业内容须额外过行业合规审核
