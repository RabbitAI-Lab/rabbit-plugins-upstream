## [v2.4.5] - 2026-10-22

### ✅ 新增：多格式扩展

- `format_router.py`：统一入口，自动路由 PDF / XML / OFD / ZIP / RAR
- XML 数电票解析（恢复 xml_parser.py）
- OFD 国标 GB/T 33190 解析（恢复 ofd_parser.py）
- ZIP 混合打包支持（内含 PDF/XML/OFD 自动识别）
- RAR 支持（依赖 unar：brew install unar）

### 🛡️ 保证

- PDF 主路径**零改动**（invoice_extractor.py md5 全程一致）
- 表头与样式**完全沿用 v2.4.0 原版 create_excel()**：
  - 15 列表头（发票号码 / 开票日期 / 购买方信息-名称 / ...）
  - 表头填色 D9D9D9 + 加粗 + 居中换行
  - 冻结首行 A2
  - 数字格式（@ / YYYY-MM-DD / #,##0.00 / 0.00%）
- 税率留空 = 多税率（设计规范，PDF/XML/OFD 一致）

### 📊 测试结果

| 格式 | 文件 | 张数 | 价税合计 |
|------|------|------|---------|
| PDF | 20261022 优格上海 | 10 | ¥4,300.45 |
| XML | 26312000006362802556 | 1 | ¥88.00 |
| OFD | 26312000006362802556 | 1 | ¥88.00 |
| ZIP | PDF+XML 混合 | 11 | ¥4,388.45 |
| RAR | unar 解包后就绪 | — | — |

### 📌 使用方式

```python
from format_router import extract_invoices, create_excel_any

invoices = extract_invoices("invoice.pdf")   # 格式自动识别
create_excel_any(invoices, "output.xlsx")       # v2.4.0 原版样式
```

**或命令行**：
```bash
python3 format_router.py <文件或目录> [输出.xlsx]
```


## [v2.4.6] - 2026-10-23

### 🐛 修复：OFD 解析器 4 个 bug

- **购方名取成标签行**：国际发票 OFD 排版是「销售方在前、购买方在后」，`_is_company_name` 把「统一社会信用代码/纳税人识别号：」当公司名 → 增加 12 个标签行排除词
- **购方税号取成发票号**：`_is_tax_id` 接受 20 位纯数字（增值税发票号码）→ 排除纯数字 + 限定 15/18 位
- **销方判定失效**：`_is_likely_seller` 关键词表没有「旅行社/航空/出行」→ 扩充 20+ 关键词
- **税额取成金额**：`_split_amounts` 用 min/middle/max 三分法，被「单价干扰值」打乱 → 改用**勾稽关系（total = amount + tax）+ 税率双重校验**

### ✅ 验证

- OFD vs XML 交叉比对：**50/50 字段 100% 一致**
- 真实数据：70 张发票 100% 识别，价税合计 ¥102,906.87
- PDF 主代码 md5 全程零改动（`788f0384d9e242b496132003ae5a9398`）

### 🆕 新增
