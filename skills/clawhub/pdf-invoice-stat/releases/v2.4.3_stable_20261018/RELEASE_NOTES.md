## 🔄 升级指南（v2.4.0 → v2.4.3）

1. **直接覆盖 `invoice_extractor.py`**（无破坏性变更）
2. **新增 `config.py`**（可选，缺失时自动 fallback）
3. **运行测试验证**：
   ```bash
   bash run_tests.sh
   ```
4. **回滚方法**：
   ```bash
   cp releases/v2.4.3_stable_20261018/invoice_extractor.py ./
   ```
