# 升级迁移指南

## v2.4.0 → v2.4.3（推荐升级）

### 步骤

1. **备份当前代码**（推荐）
   ```bash
   cp invoice_extractor.py _backups/invoice_extractor_v240.bak
   ```

2. **升级主代码**
   - 直接覆盖 `invoice_extractor.py`（无破坏性变更）
   - 新增 `config.py`（配置化，**可选**——删除它主代码会走 fallback 默认值）

3. **跑测试验证**
   ```bash
   bash run_tests.sh
   # 或单跑单元测试
   python3 tests/test_extract_v243.py
   ```

4. **如果发现行为差异**
   - 检查 `config.py` 是否与内置默认值冲突
   - 临时回滚：
     ```bash
     cp _backups/invoice_extractor_v240.bak invoice_extractor.py
     ```

### 不兼容点

- ✅ **完全向后兼容**——主代码无破坏性 API 变更
- ✅ 输出 Excel 列数不变（15 列）
- ✅ 不传 `config.py` 时使用内置默认值（行为与 v2.4.0 一致）
