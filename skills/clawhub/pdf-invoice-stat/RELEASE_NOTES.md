## 🐛 v2.4.4 修复的紧急 bug

### 1. PDF 损坏直接崩 → graceful error

**问题**：损坏/加密/格式异常的 PDF 文件导致程序直接崩溃  
**根因**：`pdfplumber.open()` 调用没有 try/except 包装  
**修复**：
- `pdfplumber.open()` 加 try/except 包装
- 单页文本提取失败不中断
- 单页解析失败不中断
- 损坏文件优雅返回空列表（不崩）

### 2. 跨页发票合并

**问题**：同一发票号多页时，只取第一页信息，丢失后续页  
**根因**：原版每张发票只取第一页，跨页发票信息不完整  
**修复**：
- 同发票号多页时合并各页信息
- 取字段最完整的页 + 最后一页的金额
- 日期取第一个非空
