## Description:

Resolves a public Linktree page to its published links and profile details through ScraperSocial.

This skill is ready for commercial/non-commercial use.

## Publisher:

[nikhonit](https://clawhub.ai/user/nikhonit)

### License/Terms of Use:

MIT-0

## Use Case:

Creators, researchers, and developers use this skill to look up public Linktree profiles and identify their published destination links.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The API key and request metadata pass through ScraperSocial's service.

Mitigation: Keep the API key private and request only public Linktree pages you are comfortable sharing with ScraperSocial.

Risk: Fetching pages spends ScraperSocial API credits.

Mitigation: Confirm the handle and intended lookup before calling the service; avoid unnecessary repeat requests.
