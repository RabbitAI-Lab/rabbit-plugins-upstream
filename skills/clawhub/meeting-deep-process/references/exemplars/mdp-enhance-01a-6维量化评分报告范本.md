### 样本来源
- **来源类型**：生成样本
- **脱敏状态**：已脱敏
- **场景类型**：协作型

### 四维分析

#### 结构
逐维展开的6维质量评分表，每维度包含原始指标值、标准化评分（0-10）、计算依据、场景权重。最后汇总为加权综合评分和综合质量评级。评分表之后附加评分汇总雷达图描述和维度间相关性说明。不包含根因分析、12维诊断信号或"差点成为亮点"片段——这些由01b和01c分别负责。

#### 风格
数据驱动、量化精确。每个评分必须展示从原始指标到最终分数的完整计算链路，杜绝直觉性评分。使用表格呈现核心数据，文字段落用于解释评分依据和维度含义。综合评级的判定标准透明可查、可复现。

#### 逻辑
6维权重按场景类型强制调整（协作型→参与均衡度×1.5权重），不得使用统一权重。各维度评分基于可观测的客观指标（发言时长分布、决策信号密度、新观点计数等），通过标准化公式映射到0-10区间。综合评级采用双判定：加权综合分+低分维度计数（≥3维低于阈值→降级）。评分体系设计原则：区分度优先——避免所有会议集中在5-7分的"平庸区"。

#### 格式
固定模板：会议元数据 → 6维逐一评分表（每维含原始指标→评分→依据→权重）→ 加权综合计算 → 综合质量评级（含判定依据）→ 评分雷达图描述。

## 一、6维逐项评分

### 维度1：信息密度

| 指标 | 数值 |
|------|------|
| 发言总字数 | 8,247 字 |
| 决策信号数（明确决策+条件判断+选项排除+行动承诺） | 43 个 |
| 信息密度原始值 | 5.21 决策信号/千字 |
| 标准化评分 | **5.2 / 10** |
| 场景权重 | 1.0（协作型-中权重） |

**计算依据**：信息密度 = 决策信号数 / 发言总字数 × 1000 / 10 = 43 / 8247 × 100 = 5.21，映射至 0-10 区间取 5.2。发言中存在大量状态汇报型内容（"本周做了XX""下周计划做XX"），占比约 47%，拉低了有效信号密度。6 次提到"可能""大概"等不确定措辞，对应的 8 个决策信号因模糊性扣除 0.4 分。

**定性评价**：信息密度处于中等偏低水平。有效决策信号被大量例行状态更新稀释，部分关键信息（孙磊运营端的数据准备进度）在日常顺序汇报中被一带而过，直到会议末尾才被李明追问出阻塞风险。

### 维度2：新颖性

| 指标 | 数值 |
|------|------|
| 新观点/新信息/新连接出现次数 | 6 次（3 新观点 + 2 新信息 + 1 新连接） |
| 历史重复内容占比 | 68%（与上两周周会高度重复） |
| 标准化评分 | **3.5 / 10** |
| 场景权重 | 0.5（协作型-低权重） |

**计算依据**：新颖性基准为协作型周会预期（≥12 个新颖信号为满分）。实际新颖信号 6 个，其中"赵雪提出的组件化设计对前后端协作流程的改造方案"（第 38 分钟）为本次唯一具有跨职能新连接的信号。其余 5 个信号为增量式更新（如"接口文档已更新至 v2.4"），新颖度有限。历史重复内容占比 68%（主要集中在前 20 分钟的例行进度汇报），拉低了整体新颖性评分。

**定性评价**：会议内容以惯性推进为主，缺乏"上次会议后发生了新变化"的信息增量。唯一的亮点信号（赵雪的组件化提议）未被充分展开讨论——该片段后续被 mdp-enhance-01c 标记为"差点成为亮点"。

### 维度3：冲突深度

| 指标 | 数值 |
|------|------|
| 实质性分歧出现次数 | 2 次 |
| 分歧中被展开讨论的回合数 | 3 回合（分歧 A：1 回合 / 分歧 B：2 回合） |
| 分歧平均追问深度 | 1.5 层 |
| 标准化评分 | **3.0 / 10** |
| 场景权重 | 1.0（协作型-中权重） |

**计算依据**：协作型会议预期冲突深度为"多数分歧被追问≥3 回合"。本次 2 次实质分歧——分歧 A（第 27 分钟，王芳前端进度 vs 陈刚后端接口依赖）仅 1 回合即被李明以"先按计划走"中止；分歧 B（第 45 分钟，赵雪与陈刚的组件颗粒度争议）展开 2 回合后因时间不足被搁置至"下次再聊"。平均追问深度 1.5 层，远低于 3 层的基准线。分歧被"搁置"而非"深度展开"是评分偏低的根本原因。

**定性评价**：会议中存在真实的意见分歧，但这些分歧没有被当作"建设性张力"深入挖掘。主持人对冲突信号的态度偏向于快速消解而非引导展开，导致分歧停留在了"被承认"而非"被分析"的层面。

### 维度4：决策清晰度

| 指标 | 数值 |
|------|------|
| 会议中形成的明确决策 | 4 项 |
| 含责任人+DDL 的决策 | 3 项 |
| 被二次确认的决策 | 2 项 |
| 标准化评分 | **6.0 / 10** |
| 场景权重 | 1.0（协作型-中权重） |

**计算依据**：决策清晰度评分 = (含责任人+DDL决策数 / 总决策数 × 7) + (被二次确认决策数 / 总决策数 × 3) = (3/4 × 7) + (2/4 × 3) = 5.25 + 1.5 = 6.75，经冗余修正（1 项决策被后续发言部分推翻→扣 0.75）后为 6.0。第 4 项决策"孙磊负责协调外部数据供应商的时间"仅指定了责任人但无具体 DDL，判定为不完整决策。

**定性评价**：决策层面的表现优于其他维度，多数决策有明确的责任人和时间节点。但决策的二义性风险仍在——孙磊的数据协调时间未定，在会议结束后可能导致跟进链断裂。该问题在 mdp-enhance-01b 中关联到议程结构的"行动项确认环节过于仓促"根因。

### 维度5：参与均衡度

| 指标 | 数值 |
|------|------|
| 发言时长分布 | 李明 35.2% / 陈刚 27.8% / 王芳 15.1% / 赵雪 9.3% / 刘洋 7.6% / 孙磊 5.0% |
| 发言频次分布 | 李明 31 次 / 陈刚 24 次 / 王芳 14 次 / 赵雪 8 次 / 刘洋 6 次 / 孙磊 4 次 |
| 话语权基尼系数 | 0.42 |
| 被他人点名/提问次数 | 李明 0 次 / 孙磊 0 次 / 赵雪 3 次 / 刘洋 1 次 |
| 标准化评分 | **2.8 / 10** |
| 场景权重 | 1.5（协作型-高权重） |

**计算依据**：协作型会议参与均衡度基准为"最高发言者不超过 25%，最低发言者不低于 10%"。话语权基尼系数 0.42，映射至 2.8/10（0.10→10 分，0.50→0 分，线性插值）。李明与陈刚合计占据 63% 话语权，形成"总监+后端"双中心话语结构。孙磊作为运营代表（负责外部数据协调这一关键路径）全场仅主动发言 4 次，且 0 次被主动点名征求意见——这表明会议的信息流动存在系统性盲区。赵雪的被点名次数（3 次）均来自李明追问设计进度，而非跨职能主动询问。

**定性评价**：此次会议最显著的质量短板。话语权高度集中在技术和管理角色，运营和测试角色边缘化。值得注意的是，刘洋和孙磊的低参与度并非"无话可说"——在会议末尾简单提及测试资源紧张和数据供应商延期风险时，均显示出重要阻塞信息——但这些问题未被安排在议程中充分讨论的时间窗口。

### 维度6：洞察产出率

| 指标 | 数值 |
|------|------|
| 可行动认知数 | 4 项 |
| 高价值认知（跨职能/跨项目/方法改进） | 1 项 |
| 认知被纳入行动项的比例 | 2/4 = 50% |
| 标准化评分 | **4.5 / 10** |
| 场景权重 | 1.0（协作型-中权重） |

**计算依据**：洞察产出率 = (可行动认知数 / 参会人数 × 10) × 认知纳入行动项比例 = (4/6 × 10) × 0.50 = 6.67 × 0.50 = 3.33，经高价值认知加权（唯一的高价值认知"组件化设计对协作流程的改造"附加 1.17 分）后为 4.50。

**定性评价**：会议产出了 4 项可行动认知，但其中 2 项（"前后端联调需要更频繁""测试用例应该更早介入"）属于通用性建议，缺乏本次会议特有的洞察力。唯一的高价值认知来自赵雪的组件化设计提议，但其执行路径（由谁牵头/C端组件库与后端API的映射方式）未被明确——这一"洞察机会的浪费"在 mdp-enhance-01c 中被进一步分析。

## 三、综合质量评级

| 评级维度 | 数值 | 判定 |
|----------|------|:--:|
| 加权综合分 | 4.11 / 10 | — |
| 低分维度计数（< 5.0）| 信息密度(5.2✓) / 新颖性(3.5✗) / 冲突深度(3.0✗) / 决策清晰度(6.0✓) / 参与均衡度(2.8✗) / 洞察产出率(4.5✗) | **4 维低于阈值** |
| **综合质量评级** | | **低（接近平淡）** |

**评级判定逻辑**：
1. 加权综合分 4.11，处于"低"评级区间（0-4.9→低，5.0-6.9→中，7.0-8.4→高，8.5-10→优秀）
2. 低分维度双重验证：4 维低于 5.0 阈值（≥3→确认降级），排除偶然性
3. 评级结论：**低（接近平淡）**——会议在决策清晰度上表现尚可，但参与均衡度和冲突深度严重拖分，呈现出"两人主导、信息单向流动、分歧被压制"的协作型会议典型低质量模式

**高权重维度单独预警**：
- **参与均衡度（权重 1.5）**：评分 2.8，是最严重的质量问题，对综合评分的拖累权重最大
- 如果将李明和陈刚以外的 4 人参与度提升至 12% 以上，综合评分预计可提升至 5.5-6.0 区间
