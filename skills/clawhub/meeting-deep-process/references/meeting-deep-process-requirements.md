## 会议深度加工与质量增强引擎任务要求清单

会议深度加工与质量增强引擎每种任务类型的"零件清单"——必选/可选组件、组装顺序、领域约束。按清单逐项产出。

---

### D01 智能交互执行域

#### mdp-exec-01 交互上下文装配
- **必选组件**: 历史交互摘要、关联决策记录、涉及人员累积12维剖面（来自D04）、未闭合行动项列表、会议元数据（议程/参会人/历史会议模式）、场景识别结果（8场景之一+判定依据）、数据充分度判定结果（冷启动/浅积累/深积累）、场景参数下发映射表
- **可选组件**: 数据源可用性检测结果、实时转写流可用性标记
- **组装顺序**: 历史数据聚合→会议元数据采集→场景判定→数据充分度判定→场景参数映射→参数下发
- **约束**: 场景识别必须基于元数据客观特征，不得凭直觉判定；数据充分度影响下游任务激活范围，不得在冷启动阶段激活深积累任务；场景参数必须下发至所有下游任务
- **格式**: 上下文装配报告（Markdown含场景判定依据+激活配置表）

#### mdp-exec-02 原生交互编排
- **必选组件**: 交互上下文摘要（来自exec-01）、议题推导路径、实时捕获的决策记录、决策→行动项映射表、结构化交互产出（决策记录/行动清单/上下文摘要）
- **可选组件**: 未澄清假设列表、逻辑漏洞提示、交互原始记录快照（完整对话记录+决策捕获日志——格式化纯文本归档，供下游D02/D03/D05任务消费或人工回溯）
- **组装顺序**: 交互上下文加载→议题路径生成→实时捕获→行动项映射→产出组装→自动分发
- **约束**: 不引入"会议"形式——无会前/会中/会后分段；行动项必须含责任人+DDL；产出在交互结束时已就绪，无人工整理步骤
- **格式**: 原生交互产出（Markdown + 行动项结构化清单）

#### mdp-exec-03 外部会议兼容执行
- **必选组件**: 参会前洞察（议程解析/参会人累积剖面/历史关联交互/参会策略建议）、参会中记录（转录文本/关键决策标记/场景适配的焦点提醒）、参会后产出（会议摘要/待办提取清单/分发记录/剖面更新触发）、外部加工隐私边界声明
- **可选组件**: 多语种润色、AI代理发言建议、会后原始数据快照（格式化转写全文归档+参会人出勤统计+录制文件元数据清单——多格式导出Markdown/JSON/TXT，供下游任务消费或人工回溯，与深度加工产出并行不互斥）
- **组装顺序**: 会前数据加载→参会洞察生成→会中旁听捕获→焦点检测→会后摘要→待办提取→分发归档→触发D04快照
- **约束**: 参会中实时分析依赖数据源提供实时转写流，离线数据源下相关能力降级为会后分析；他人12维剖面仅基于公开会议发言推断；焦点提醒仅在议题与自身利益相关时触发
- **格式**: 外部会议执行报告（Markdown三段式 + 产出清单）

#### D01参考：数据源抽象接口

D01三个任务通过以下6个抽象接口从会议数据源获取原始数据，不直接调用平台命令：

| 接口 | 数据 | 说明 | tmeet CLI 命令映射 |
|------|------|------|------|
| 获取会议列表 | 会议ID、主题、时间、参会人 | 支持时间范围、会议码等多维度查询 | `meeting list` / `meeting list-ended` |
| 获取会议详情 | 议程、时长、参会人完整信息 | 单次会议的结构化元数据 | `meeting get` |
| 获取录制列表 | 录制ID、时长、文件状态 | 关联到具体会议 | `record list` → `record address` |
| 获取转写原文 | 逐句文本 + speaker标注 + timestamp | 深度分析的核心输入 | `record transcript-get` / `transcript-paragraphs` / `transcript-search` |
| 获取智能纪要 | AI摘要 + 议题列表 | 快速概览和议题识别 | `record smart-minutes` |
| 获取参会人数据 | 姓名、身份、入离会时间 | 关联发言者与身份 | `report participants` |

若未加载任何会议数据源技能，回退使用 `references/tmeet-cli-reference.md` 中的 `tmeet` CLI 直接获取数据。典型数据获取工作流见该文件末尾。部分实时能力依赖实时转写流，离线数据源下降级为会后分析模式。

### D02 交互效能分析域

#### mdp-analyze-01 跨录制议题聚类
- **必选组件**: 多场会议议题列表、议题聚类结果（聚类标签+每个聚类的议题成员+聚类置信度）、主题热力图（时间×议题频率矩阵）、沉默议题预警列表、场景参数调整后的聚类权重说明
- **可选组件**: 议题趋势预测、议题演化路径图
- **组装顺序**: 议题提取→权重设定（场景参数）→聚类计算→热力图生成→沉默检测→预警输出
- **约束**: 单场会议数据下降级为单场内议题识别；沉默议题的"应讨论但未出现"判断必须基于历史议题频率的统计显著性
- **格式**: 议题聚类报告（Markdown含热力图描述+聚类详情表+预警清单）

#### mdp-analyze-02 决策溯源关联
- **必选组件**: 决策ID、决策内容、原始发言片段引用（speaker+timestamp+转写原文）、决策上下文（当时已知信息/排除选项）、上下游决策关联链（前序决策→本决策→后续决策）、决策者12维剖面关联
- **可选组件**: 决策质量评估（基于后续结果的回测评估）
- **组装顺序**: 决策识别→发言锚定→上下文提取→关联链构建→剖面关联标注
- **约束**: 每个决策必须可追溯到具体发言片段，不得模糊引用"会议中讨论了"；决策关联链必须基于明确的因果或时间关系，不得强行关联
- **格式**: 决策溯源图谱（Markdown含决策链表格+发言引用+因果路径描述）

#### mdp-analyze-03 群体动力分析
- **必选组件**: 发言立场提取结果（每人/每次发言的赞同/反对/补充/沉默信号标注）、立场聚类结果（阵营标签+每个阵营的成员+支持强度）、权力流向图谱（提问者→回答者→决策者→执行者有向图）、剖面-立场分歧检测结果（12维预期vs实际站队+异常信号列表）、阵营稳定性评分（跨会议追踪）、桥接者识别结果（连接对立阵营的节点+特征描述）
- **可选组件**: 阵营漂移动态（同一人在连续会议中的立场变化轨迹）
- **组装顺序**: 发言立场提取→阵营聚类→权力流向分析→剖面-立场比对→分歧检测→稳定性评分→桥接者识别
- **约束**: 阵营划分必须基于可追溯的发言证据（赞同/反对/补充/沉默信号）；剖面-立场分歧必须展示12维预期推导过程；桥接者识别必须基于跨阵营互动频率量化指标
- **格式**: 群体动力分析报告（Markdown含阵营图描述+权力流向描述+分歧检测表+桥接者清单）

#### mdp-analyze-04 发言者参与度分析
- **必选组件**: 发言统计数据（每人发言次数/总字数/平均发言长度）、发言时长分布表（每人+占比）、话语权集中度指数、交互网络有向图谱（谁对谁说话+频率权重）、主导者与沉默者标注
- **可选组件**: 发言打断模式分析、发言质量评分（信息密度/决策贡献度/冗余度）
- **组装顺序**: 发言统计→时长分布→集中度计算→交互网络构建→角色标注
- **约束**: 发言时长的统计不能简单等同于"参与度"——需区分信息性发言和程序性发言；交互网络的方向判断基于明确的对话信号
- **格式**: 参与度分析报告（Markdown含统计表格+网络图描述+角色分类）

#### mdp-analyze-05 行动闭环验证
- **必选组件**: 决策存活率（已执行/已推翻/已遗忘，每项含具体实例）、行动项闭合率（及时完成/延期/未开始的比例和时间分布）、重复决策检测结果（同一议题多场会议出现但从未落地+预警）
- **可选组件**: 闭合周期统计（从决策到执行的平均时间）、延迟原因分类
- **组装顺序**: 行动项收集→状态验证→存活率计算→闭合率统计→重复检测→预警生成
- **约束**: 单场会议数据下仅能提取当前行动项，无法验证闭合状态——标注"需后续会议数据验证"；重复决策的判断阈值：同一议题≥3场会议且决策内容相似度≥70%
- **格式**: 闭环验证报告（Markdown含存活率/闭合率统计表+重复决策预警清单+验证局限声明）

#### mdp-analyze-06 录制价值评估
- **必选组件**: 信息密度评分（0-10，基于决策数/发言冗余比）、决策产出率（决策数/会议时长）、场景ROI评估（谈判型=让步vs收益；调解型=冲突降级幅度；信息型=知识传递有效率；协作型=行动项生成率）、值得参加判断（是/否+理由）
- **可选组件**: 录制保留建议（永久归档/定期归档/可丢弃）
- **组装顺序**: 信息密度计算→决策产出率统计→场景ROI评估→综合判断
- **约束**: ROI评估必须基于场景分类调整指标权重；值得参加判断必须综合考虑信息获取收益和认知消耗成本；不得仅凭时长判断价值
- **格式**: 录制价值评估报告（Markdown含评分表+ROI计算+参加建议）

#### mdp-analyze-07 效率趋势分析
- **必选组件**: 周期性体检报告（周/月/季）、会议时长趋势图、决策密度变化曲线、议程偏离率趋势、可异步替代率变化、改进建议列表
- **可选组件**: 与行业基准对比、异常预警（特定指标突变超过阈值）
- **组装顺序**: 历史数据聚合→指标计算→趋势拟合→异常检测→改进建议推导
- **约束**: ≥2场会议数据后激活；趋势拟合需标注数据点数量和置信区间；改进建议必须可操作（避免"提升效率"等空洞建议）
- **格式**: 效率趋势报告（Markdown含趋势描述+指标统计表+改进建议清单+数据充分度声明）

### D03 知识资产沉淀域

#### mdp-knowledge-01 报告自动起草
- **必选组件**: 场景匹配的报告模板、会议数据填充内容、报告草稿（事实摘要→人工审核→润色稿的生成链）
- **可选组件**: 多语种翻译、格式适配（PDF/Word/Markdown）
- **组装顺序**: 模板选择（场景参数）→数据映射填充→事实摘要生成→（人工审核节点）→润色稿生成→格式导出
- **约束**: 区分两种生成模式：事实摘要可无人工干预自动生成，润色稿必须经人工审核；报告内容的事实性声明必须可追溯到原始会议数据
- **格式**: 报告文档（Markdown或用户指定格式，含事实来源标注）

#### mdp-knowledge-02 复盘材料生成
- **必选组件**: 项目全生命周期交互时间线、关键决策点标注（含决策者12维剖面）、转折事件描述+前后对比、经验教训结构化条目、改进行动建议
- **可选组件**: 定量指标对比（预期vs实际）、复盘方法论模板选择
- **组装顺序**: 生命周期交互收集→时间线构建→关键决策提取→转折点识别→经验条目化→建议推导
- **约束**: 复盘材料的"经验教训"必须对应到具体决策和事件，不得生成模糊的通用建议；转折事件须标注触发条件和影响范围
- **格式**: 项目复盘报告（Markdown含时间线+决策关联+经验条目+改进清单）

#### mdp-knowledge-03 知识库条目提取
- **必选组件**: 结构化知识点列表（每条含标题/核心内容/来源会议ID+发言片段/置信度/关联议题标签）、跨会议验证状态、去重合并记录
- **可选组件**: 知识条目间的依赖和引用关系、知识图谱节点
- **组装顺序**: 知识点识别→来源标注→置信度评估→去重检测→权重调整→知识条目输出
- **约束**: 每条知识条目标注事实来源和置信度；禁止将未验证或存在争议的陈述沉淀为"知识"；同一结论被≥2场会议独立验证→权重提升；关键知识条目须设人工审核节点
- **格式**: 知识库条目清单（Markdown含知识条目表+来源追溯+验证状态+审核标记）

#### mdp-knowledge-04 结构化画像抽取
- **必选组件**: 场景特定的抽取结果（面试→候选人12维剖面/培训→教学内容结构化/外部沟通→话术库条目）、画像关联到原始交互数据
- **可选组件**: 画像版本管理、候选/人才对比矩阵
- **组装顺序**: 场景判断→抽取规则加载→内容提取→结构化组装→画像归档
- **约束**: 面试场景的候选人剖面必须标注"基于N场面试推断"，区分自我陈述的能力和实际表现的能力；培训内容的抽取必须保持知识结构的完整性
- **格式**: 结构化画像报告（Markdown，格式随场景自适应）

### D04 发言者12维剖面分析域

#### mdp-profile-01 单次剖面快照
- **必选组件**: 每个发言者的12维推断表格（实体层维1/维2/维3/维6 + 社会层维7/维8 + 抽象层维9/维10/维11）、每个推断维度标注推断信号来源（引用的具体发言片段）、置信度等级标注（✅高/⚠️中/❓低）、不可推断维度清单（含维5躯体维全部子维度🚫）
- **可选组件**: 各维度的替代推断方向（如果不确定性高，列出备选）
- **组装顺序**: 发言者识别→逐维信号采集→实体层推断→社会层推断→抽象层推断→置信度标注→不可推断维度标记
- **约束**: 基于本技能内置的12维角色模型框架（详见SKILL.md"12维角色模型定义"章节）；躯体维（维5）从文本不可推断，必须标注🚫；每个维度推断必须有对应的发言片段作为信号来源；置信度低（❓）的维度必须标注不确定性
- **格式**: 12维剖面快照表（Markdown含12维推断详情表+信号来源清单+置信度标注+不可推断声明）

#### mdp-profile-02 累积剖面画像
- **必选组件**: 跨会议聚合的个人完整12维画像、每维度的数据充分度（N场会议/N次独立发言支持）、新旧数据冲突时的更新记录（贝叶斯更新+更新原因）、≥2场会议数据激活（冷启动阶段降质为仅当前场数据）
- **可选组件**: 剖面稳定性评分（各维度在更新中的波动程度）、更新频率建议
- **组装顺序**: 历史剖面加载→新快照比对→冲突检测→贝叶斯更新→充分度重算→剖面稳定性评估
- **约束**: 新旧数据冲突时使用贝叶斯更新，不得简单覆盖或取平均；数据充分度标注必须量化（N次独立发言），不得凭感觉填写；冷启动阶段标注"数据充分度不足，基于单场推断"
- **格式**: 累积剖面画像报告（Markdown含12维累积画像表+数据充分度统计+更新日志+稳定性评分）

#### mdp-profile-03 本人剖面对比
- **必选组件**: 发言者累积画像 vs 用户自身12维剖面的差异矩阵（每个维度的差值+方向+影响评估）、维度对齐清单（利益一致/认知互补/价值共识）、维度张力清单（利益冲突/认知差异/层级不对等）、综合协作兼容性评分。用户自身剖面作为输入参数提供，使用与本技能内置模型相同的12维格式填充
- **可选组件**: 张力缓解建议、协作价值最大化策略
- **组装顺序**: 双方剖面加载→逐维对比→差异度计算→对齐检测→张力识别→综合评分
- **约束**: 对比时双方12维的数据充分度必须对等标注（如本人剖面完整填充vs对方剖面仅3场会议推断→标注不对等可能影响对比可靠性）；张力识别不能仅基于单一维度差异，需多维度综合分析
- **格式**: 剖面差异矩阵报告（Markdown含12维对比表+对齐/张力清单+兼容性评分+数据充分度不对称声明）

#### mdp-profile-04 剖面演化追踪
- **必选组件**: 同一人跨时期12维变化轨迹表（每维度变化方向+幅度+时间跨度）、变化信号分类（晋升信号/离职倾向/认知升级/立场漂移/策略性波动）、场景上下文校验结果（识别策略性变化vs真实人格变化）、≥3场会议数据激活
- **可选组件**: 变化预测（基于当前趋势推断未来3-6个月的变化方向）、干预建议
- **组装顺序**: 历史剖面序列加载→逐维变化检测→变化量计算→信号分类→场景校验→预测推导
- **约束**: 谈判型场景下维11动机的剧烈变化标记为"策略性波动可能"，不直接判定为人格变化；变化信号须标注统计显著性（变化幅度/数据支持场次）；冷启动和浅积累阶段休眠

#### mdp-enhance-03a 实时话语深度干预
- **必选组件**: 深度监测结果（讨论深度等级+触发阈值依据）、干预建议卡片（含目标对象12维剖面标注+12维适配措辞+干预时机）、每场干预频次≤3次
- **可选组件**: 干预紧迫度分级、备份干预措辞
- **组装顺序**: 转写流加载→深度监测→阈值判定（场景参数）→目标对象12维匹配→干预风格选择→措辞生成→时机确定
- **约束**: 阈值和风格双重调整——场景决定"何时干预"（详见catalog.md场景适配表），12维决定"如何干预"（维8↑+C型→苏格拉底追问、维11关系→邀请式、维11权力→匿名挑战、维12低→渐进式等，详见catalog.md 12维适配表）；措辞引导性非评判性；不干预寒暄和程序性发言；无实时流转发时本任务休眠
- **格式**: 干预建议卡片（简洁措辞+12维依据+干预时机）

阈值和风格随场景调整：

| 场景 | 干预阈值 | 干预风格 | 典型干预时机 |
|------|:--:|------|------|
| 协作型 | 低——允许更多日常交流，只在关键障碍被回避时干预 | 引导式："这里是否可以具体说说当前最大的阻碍是什么？" | 连续3人汇报后无人追问时 |
| 决策型 | 中——在选项被模糊处理或决策悬置时干预 | 苏格拉底式："如果我们选择A，代价是什么？如果选B呢？" | 选项罗列完毕但无人明确表态时 |
| 创意型 | 高——只在出现高价值信号但未被展开时干预 | 启发式："如果把这两个看似无关的点连起来，会怎样？" | 有人提出反常观点但被跳过时 |
| 谈判型 | 高——只在核心分歧被回避时干预 | 中立式："双方的核心诉求是否有可以交换的空间？" | 讨论在次要问题上打转时 |
| 调解型 | 中——情绪升级或叙事僵持时干预 | 共情式："从各方的视角，现在最关键的未被回应的问题是什么？" | 各方各自重复已有立场超过2轮时 |
| 评估型 | 低——缺乏行为证据或标准不一时干预 | 追问式："关于这个评分的具体行为依据是什么？" | 评分缺乏具体事例支撑时 |
| 信息型 | 中——在单向灌输超过阈值时干预 | 激活式："如果让你用一句话讲给没参加的人，你会怎么说？" | 连续10分钟无人提问时 |
| 仪式型 | 低——形式走完但缺乏情感连接时干预 | 唤起式："这个项目里有没有一个瞬间让你觉得'值了'？" | 流程走完但氛围冷淡时 |

干预措辞按目标对象12维特征匹配：

| 目标对象12维特征 | 干预风格 | 措辞框架 | 注意事项 |
|------|------|------|------|
| 维8层级↑ + 维9功能A型 | 直接质询式 | "这个决策的代价是什么？如果数据不支持这个方向呢？" | 高层级A型通常能承受直接挑战 |
| 维8层级↑ + 维9功能C型 | 苏格拉底追问式 | "按照这个逻辑往下推，当X发生时，我们如何应对？" | C型偏好逻辑链的完整性 |
| 维8层级中/低 + 维11动机(关系) | 邀请式 | "刚才X提到一个很有意思的点，[名字]你怎么看？" | 关系驱动者需要感到被邀请而非被拷问 |
| 维11动机(权力) + 维10能力↑ | 挑战式 | "有没有人觉得这个结论下得太快了？" | 权力驱动者享受智力博弈，匿名化挑战降低防御 |
| 维11动机(价值) + 维6文化 | 共鸣式 | "这个方向跟你之前提到的XX理念，好像有一个张力，你怎么调和？" | 诉诸其内在价值体系 |
| 维12动态↓（一致性高） | 渐进式 | "我们先不考虑推翻，就假设有一个参数变了，输出会怎样？" | 低灵活性者需要渐进引导 |
| 全体沉默（无人应和） | 匿名化激活 | "如果每个人匿名写下此刻最大的一个担忧，可能会是什么？" | 打破层级压迫或群体思维 |

#### mdp-enhance-03b 离线追问清单生成
- **必选组件**: 追问清单（每个追问项含：节点定位speaker+timestamp+目标对象12维剖面+12维适配追问方向+预期深化路径+可能揭示的信息）、六维覆盖度分析（统计追问项覆盖的维10能力域和维9功能类型分布）
- **可选组件**: 追问项按优先级排序、追问项的情景化措辞模板
- **组装顺序**: 转写全文加载→节点识别→目标对象12维匹配→追问方向推导→预期路径推演→覆盖度统计
- **约束**: 每个追问项必须标注目标对象的12维剖面依据；追问方向必须定向激活目标对象的维10能力核心域；覆盖度分析须确保各维10域和各维9类型均有代表性覆盖
- **格式**: 追问清单（Markdown含节点定位表+追问方向+预期路径+覆盖度统计）

#### mdp-enhance-04 会议模式优化
- **必选组件**: 跨会议重复平淡模式（议程/参与/权力/时间四类，每种≥2场独立证据）、12维人-会匹配分析（功能完备性/权力梯度/动机对齐度/能力覆盖度/关系安全度/文化兼容度——6项中至少分析3项）、模式影响量化（每种模式的平均质量损失评分）、改进方案（每项标注优先改进的12维维度）、效果追踪框架（改进前后对比指标）
- **可选组件**: 行业最佳实践对标、渐进式改进路线图
- **组装顺序**: 01b+01c历史数据聚合→四类模式检测→12维人-会匹配分析→影响量化→改进方案推导→优先级排序→追踪框架建立
- **约束**: ≥3场激活；模式检测按场景隔离（不同场景模式不混合检测）；人-会匹配基于D04累积剖面；改进方案必须可操作且标注12维维度；涉及权力结构或人际关系的建议标注敏感性
- **格式**: 会议模式优化报告（Markdown含模式识别清单+12维匹配分析+量化影响+改进方案+追踪框架）

模式发现与改进按场景差异化：

| 场景 | 重点检测的平淡模式 | 改进方向示例 |
|------|-------------------|-------------|
| 协作型 | 轮流汇报→无人追问→草草结束 | 压缩汇报时间至30%，增加"障碍讨论"和"资源协商"环节 |
| 决策型 | 选项罗列→模糊表态→决策悬置或权威拍板 | 引入"预承诺"机制（会前提交书面立场），匿名投票后再辩论 |
| 创意型 | 发散无序/过早收敛/集体思维 | 设"发散阶段"（只产出不评判）和"收敛阶段"（投票+组合）分界线 |
| 谈判型 | 立场僵持/回避核心分歧/无交换框架 | 引入"利益互换清单"（双方各自列出可交换项和核心底线） |
| 调解型 | 各说各话/情绪升级/缺乏第三方框架 | 引入"共同叙事"环节（双方合写事件经过），结构化表达训练 |
| 评估型 | 问答题化/评分趋中/缺乏证据锚定 | 强制行为锚定评估法（每项评分必须有具体行为描述支撑） |
| 信息型 | 单向灌输/无理解验证/被动接收 | 改为"翻转会议"（会前异步阅读材料，会中只做讨论和答疑） |
| 仪式型 | 流程走完/缺乏情感连接/叙事空洞 | 设计"个人叙事"环节（每个参与者分享一个项目中的触动时刻） |

12维驱动的"人-会匹配"分析：

| 分析维度 | 关联12维 | 检测内容 | 改进方向 |
|---------|:--:|------|------|
| 功能完备性 | 维9功能 | 会议的元操作需求与实际参会人的维9功能分布是否匹配 | 决策型会议缺少A型→引入有决策权的人；创意型缺少C型→引入分析型思维者 |
| 权力梯度 | 维8层级差异 | 层级梯度是否过大导致沉默，或过小导致无法决策 | 梯度过大→部分议题改为无高层参与的预讨论；梯度过小→明确指定本轮决策人 |
| 动机对齐度 | 维11动机 | 参会人的驱动力类型与会议目的的一致性 | 利益驱动的参会人参加价值讨论→议程中加入"利益相关性"环节建立连接 |
| 能力覆盖度 | 维10能力 + 维1职业 | 会议所需领域知识是否被参会人覆盖 | 关键领域无人覆盖→邀请对应专家或改为异步征集意见 |
| 关系安全度 | 维7关系 | 参会人之间的已有关系是否支持建设性冲突 | 维7关系中已有对抗的两人被安排在同一辩论环节→可能升级 |
| 文化兼容度 | 维6文化 | 不同文化背景者在同一会议中的沟通兼容度 | 技术vs商业文化冲突→增加"术语对齐"环节；代际差异→调整表达方式 |

#### D05 场景适配的亮点设计策略

| 场景 | 会议常见平淡模式 | D05亮点设计策略 | D05质量诊断关键指标 |
|------|----------------|---------------|:--:|
| 协作型 | 轮流汇报→无人追问→草草结束 | 设计"障碍墙"环节：每人必须抛出一个当前最大阻碍；指定魔鬼代言人对每个里程碑提出质疑 | 追问密度、阻碍信号产出率 |
| 决策型 | 选项罗列→无人明确表态→决策悬置 | 设计"预承诺→辩论→再投票"三步决策法；强制每人必须在讨论前提交书面立场 | 立场明确度、反对理由充分性 |
| 创意型 | 发散无收敛/过早收敛/集体思维 | 设计"最蠢方案"环节降低防御心理；使用反事实推演（"如果我们有无限预算/零预算会怎样"）；强制轮换视角 | 新颖信号密度、假设挑战频次 |
| 谈判型 | 立场僵持/回避核心分歧 | 设计"利益互换矩阵"预填；引入"如果对方条件全满足，我们额外能获得什么"的换位问题 | 让步合理性、底线探索深度 |
| 调解型 | 各说各话/情绪升级/缺乏第三方视角 | 设计"共同叙事"环节（双方合写事件经过）；引入结构化的"感受→事实→需求"三段表达框架 | 情绪降温速度、共识信号出现频次 |
| 评估型 | 问答题化/评分趋中/缺乏行为证据 | 设计STAR追问模板（情境→任务→行动→结果→反思）；强制每项评分必须有≥2个行为证据锚定 | 行为证据密度、评估区分度 |
| 信息型 | 单向灌输/无理解验证/被动接收 | 设计"教给别人"环节（听完后每人用自己话讲给旁边人）；插入"最难理解的点"匿名投票 | 知识传递有效率、提问质量 |
| 仪式型 | 形式走完/缺乏情感连接/叙事空洞 | 设计"关键时刻"回顾（每人分享一个最触动自己的项目瞬间）；设计"项目墓志铭"共创（如果项目是一本书，封底写什么） | 叙事覆盖度、情感共鸣强度 |
