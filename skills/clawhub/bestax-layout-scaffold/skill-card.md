## Description:

Scaffolds complete, responsive pages with @allxsmith/bestax-bulma for dashboards, landing pages, focused forms, and card-grid catalogs.

This skill is ready for commercial/non-commercial use.

## Publisher:

### License/Terms of Use:

## Use Case:

Developers use this skill to build responsive application and website layouts from bestax-bulma components, selecting an app shell, landing page, centered page, or card grid to match the request.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A fixed navbar may obscure page content if the required HTML class is omitted.

Mitigation: Review generated fixed-navbar markup and add has-navbar-fixed-top to the HTML element when needed.

Risk: Generated layouts may include external placeholder images or CSS changes unsuitable for the project.

Mitigation: Review image sources and new CSS classes before using the generated page.
