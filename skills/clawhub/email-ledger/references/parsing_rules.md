# 解析规则参考文档

本文档记录邮件解析中各类信息的提取规则，便于后续维护和扩展。

## 报备类型分类规则

`CATEGORY_PATTERNS` 列表按优先级排序，越具体的模式越靠前。匹配时取第一个命中的类型。

| 模式 | 报备类型 | 示例主题 |
|------|----------|----------|
| `商务结果\|中标结果\|采购结果` | 商务结果报备 | 【商务结果】工信部项目数据采购方式申请 |
| `阳光承诺书.*免签\|免签署.*阳光承诺书` | 阳光承诺书免签申请 | 【请章总审批】供应商入库-阳光承诺书免签申请 |
| `指定供应商\|指定.*供应商` | 指定供应商申请 | 【审批类】《2024年中国互联网学习发展报告》发布会物料指定供应商申请 |
| `新增简易供应商\|简易供应商.*特批` | 新增简易供应商/阳光承诺书特批 | 【新增简易供应商】广东雷曦文化有限公司-申请特批 |
| `白名单` | 白名单申请 | 【特殊审批】白名单申请-禾赛科技 |
| `授权自采\|自购申请\|申请授权自采` | 授权自采申请 | 【申请授权自采】关于...场地...申请授权自采 |
| `费用变更\|变更申请\|视频制作费用变更` | 费用变更报备 | 【视频制作费用变更申请】回复_... |
| `特殊入库\|特殊.*入库` | 特殊入库报备 | 【请余总审批】供应商嘉立创特殊入库报备申请 |
| `审批申请.*供应商新增\|供应商新增` | 供应商新增审批 | 【审批申请】供应商新增 免签署"合作伙伴阳光承诺书" |
| `审批类\|审批申请` | 审批类报备 | 通用审批类 |
| `采购方式申请` | 采购方式报备 | 采购方式相关 |
| `申请.*外采\|外采.*申请\|采购申请` | 采购申请 | 【申请】AI陪伴外采视频制作服务需求申请 |
| `报备` | 一般报备 | 含"报备"但无更具体分类 |
| （默认） | 其他报备 | 无法匹配任何模式 |

## 供应商名称提取规则

按优先级从高到低：

### 从主题提取
1. `【新增简易供应商】XXX有限公司-申请特批` → 提取方括号后的公司名
2. `【新增简易供应商】XXX、XXX-申请特批` → 提取方括号后、"-申请"前的多供应商
3. `白名单申请-XXX` → 提取连字符后的名称
4. `供应商XXX特殊入库` → 提取"供应商"后、关键词前的名称

### 从正文提取
1. `对方（XXX）无法签署` → 提取括号内公司名
2. `拟新增 XXX 为我司供应商` → 提取"新增"到"为"之间的名称
3. `供应商（XXX）制作` → 提取括号内公司名
4. `供应商名称：XXX` → 提取冒号后的名称
5. `预中标供应商为：XXX` → 提取冒号后的名称
6. `与XXX有限公司合作` → 提取公司名
7. 渠道类：场地名称提取（举办场地为/使用XXX作为场地/场地为XXX基地）

### 回退策略
- 正文中第一个非"科大讯飞"的公司名（含"有限公司"等后缀）
- 外文公司名（含 LTD/INC/CORP/GMBH）

## 审批人提取规则

1. 主题中 `请XXX总审批/审阅` → 提取称谓
2. 主题中 `XXX总审批` → 提取称谓
3. 正文 `请XXX审批` → 提取（排除"您"、"领导"、"烦"）
4. 正文开头称呼 `XXX总：/XXX总好` → 提取称谓
5. 正文中间 `XXX总好` → 提取称谓
6. 收件人姓名推断

## 新增规则

如需新增报备类型或提取规则：
1. 在 `CATEGORY_PATTERNS` 列表中添加模式，放在合适的优先级位置
2. 在 `extract_vendor_name` 函数中添加新的正则匹配
3. 用实际邮件测试验证
