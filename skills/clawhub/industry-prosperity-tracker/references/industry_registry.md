# 行业注册表

本文件记录所有支持的行业配置。v2.0 起采用通用引擎架构，内置行业直接注册在
`scripts/fetch_indicators.py` 的 `BUILTIN_SECTORS` 字典中，自定义行业通过
`--stocks` 参数动态传入。

## 通用指标框架（所有行业共用）

| 层级 | 指标 | 数据源 | AKShare函数 | 权重 |
|------|------|--------|------------|------|
| 领先 | 官方制造业PMI | 国家统计局 | macro_china_pmi_yearly() | 15% |
| 领先 | 财新制造业PMI | 财新/Markit | macro_china_cx_pmi_yearly() | 15% |
| 领先 | PPI年率 | 国家统计局 | macro_china_ppi_yearly() | 10% |
| 同步 | 出口同比 | 海关总署 | macro_china_exports_yoy() | 15% |
| 同步 | 进口同比 | 海关总署 | macro_china_imports_yoy() | 10% |
| 同步 | 龙头股营收QoQ | 交易所披露 | stock_financial_abstract() | 15%/N |
| 滞后 | 龙头股毛利率QoQ | 交易所披露 | stock_financial_abstract() | 20%/N |

N = 龙头股数量，权重自动均分。

## 自定义行业使用方式

用户输入任意行业名称时，AI根据行业知识选择2-5只龙头股，通过命令行参数传入：

```bash
python scripts/fetch_indicators.py \
    --sector custom_military \
    --sector-name "军工" \
    --stocks "600760:中航沈飞,002179:中航光电,000768:中航西飞"
```

AI选股原则：
1. 各细分领域的龙头（市值/营收最大）
2. 覆盖产业链关键环节（不只一个子行业）
3. A股上市，代码6位（6开头沪市，0/3开头深市）
4. 至少4个季度财报数据（保证QoQ计算）
5. 主业占比高（避免综合企业干扰）

## 添加内置行业

在 `scripts/fetch_indicators.py` 的 `BUILTIN_SECTORS` 字典中添加一行：

```python
"military": {
    "name": "军工",
    "stocks": [
        ("600760", "中航沈飞"),
        ("002179", "中航光电"),
        ("000768", "中航西飞"),
    ],
},
```

添加后无需修改其他文件，评分和报告脚本自动适配。
