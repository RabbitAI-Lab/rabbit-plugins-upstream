# 景气度评分方法论

## 总体思路

将多个异质指标（产量、销售额、存货等）统一转换为一个 0-100 的综合景气评分，并判断当前处于上行/下行/拐点区间。

评分方法刻意保持简单可解释——每个指标只有 +1/0/-1 三种状态，加权求和后映射到0-100。这确保结果可审计、可解释，避免黑箱。

---

## Step 1: 计算单指标方向

对每个指标 i，根据最新一期的环比(MoM)或季环比(QoQ)变化判断方向：

```
direction_i = +1    if change_i > +threshold_i    (改善)
direction_i =  0    if -threshold_i <= change_i <= +threshold_i  (持平)
direction_i = -1    if change_i < -threshold_i    (恶化)
```

默认阈值 threshold = 2%（MoM）或 0.5个百分点（毛利率等比率指标）。

**反向指标特殊处理**：
- 存货周转天数：天数下降 = +1（去库存利好），天数上升 = -1
- 其他反向指标在指标定义中标注 `inverted: true`

---

## Step 2: 加权求和

每个指标有预设权重 weight_i（见行业指标文件），所有权重之和为1.0。

```
raw_score = sum(direction_i * weight_i)    for all indicators i
```

raw_score 取值范围为 [-1.0, +1.0]。

---

## Step 3: 映射到 0-100 量表

```
prosperity_score = (raw_score + 1.0) * 50
```

- raw_score = +1.0（全部上行）→ score = 100
- raw_score = 0.0（全部持平）→ score = 50
- raw_score = -1.0（全部下行）→ score = 0

---

## Step 4: 趋势平滑

对最近3期的 prosperity_score 计算移动平均，得到 smoothed_score：

```
smoothed_score = average(prosperity_score[t], prosperity_score[t-1], prosperity_score[t-2])
```

报告中同时展示当期 score 和 smoothed_score。

---

## Step 5: 方向判断

| smoothed_score | 方向判断 | 含义 |
|---------------|---------|------|
| > 60 | 景气上行 | 多数指标改善，处于周期上升阶段 |
| 40 - 60 | 景气平稳/拐点 | 多空交织，可能处于周期转折 |
| < 40 | 景气下行 | 多数指标恶化，处于周期下降阶段 |

---

## Step 6: 关键信号提取

从所有指标中提取：
- **Top 3 正向信号**：direction = +1 且权重最大的3个指标
- **Top 3 负向信号**：direction = -1 且权重最大的3个指标

在报告中突出展示，帮助用户快速理解景气的核心驱动力。

---

## Step 7: 历史分位数（参考信息）

对每个指标，计算当前值在过去12个月中的百分位排名：

```
percentile_i = rank(current_value_i, historical_12m_values_i) / 12 * 100
```

- >70 → 高位
- 30-70 → 中性
- <30 → 低位

分位数仅作为参考展示，不参与评分计算。这帮助用户判断指标的绝对水平，而不仅是环比方向。

---

## 计算示例

假设半导体行业当前9个指标方向如下：

| 指标 | 权重 | 方向 | 加权贡献 |
|------|------|------|---------|
| L1 北美设备出货 | 15% | +1 | +0.15 |
| L2 日本设备出货 | 10% | +1 | +0.10 |
| L3 台湾半导体PMI | 15% | 0 | 0.00 |
| C1 IC产量 | 15% | +1 | +0.15 |
| C2 全球销售额 | 10% | +1 | +0.10 |
| C3 芯片进口额 | 10% | 0 | 0.00 |
| C4 头部公司营收 | 5% | -1 | -0.05 |
| T1 存货周转天数 | 10% | +1 | +0.10 |
| T2 综合毛利率 | 10% | 0 | 0.00 |

```
raw_score = 0.15 + 0.10 + 0 + 0.15 + 0.10 + 0 - 0.05 + 0.10 + 0 = 0.55
prosperity_score = (0.55 + 1.0) * 50 = 77.5
```

方向判断：smoothed_score > 60 → **景气上行**

---

## 局限性说明

1. 评分基于环比方向（+1/0/-1），不反映变化幅度。大幅改善和小幅改善同等对待。
2. 滞后指标按季度更新，在季度间使用上一期数据。
3. 评分不预测未来，仅描述当前状态。
4. 部分指标有数据延迟（如SIA全球销售额延迟3个月），评分反映的是"已知最新数据"时的景气状态。
