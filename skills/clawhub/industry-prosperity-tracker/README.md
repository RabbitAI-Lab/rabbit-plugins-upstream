# 板块景气度查询 (Industry Prosperity Tracker)

跟踪任意行业景气度的通用引擎，用 A 股龙头股财务数据 + 宏观指标计算综合景气评分（0-100）。

## 核心功能

- **通用框架**：适用于任意行业，不限于特定板块
- **双数据层**：宏观层（PMI/PPI/进出口 40%）+ 企业层（龙头股营收/毛利率 60%）
- **自动权重分配**：根据用户提供的股票数量自动均分企业端权重
- **动态选股**：支持内置行业（半导体、医药、新能源、消费品）和自定义行业
- **一键报告**：HTML 仪表盘报告，含评分仪表盘、指标明细表、关键信号

## 自定义行业示例

```bash
# 黄金行业
python scripts/fetch_indicators.py --sector gold --sector-name "黄金" \
    --stocks "601899:紫金矿业,600547:山东黄金,600489:中金黄金"

# 化工行业
python scripts/fetch_indicators.py --sector chemical --sector-name "化工" \
    --stocks "600309:万华化学,600426:华鲁恒升,002493:荣盛石化"
```
