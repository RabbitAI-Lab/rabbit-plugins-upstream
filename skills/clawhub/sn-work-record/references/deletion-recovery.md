# 删除与恢复暂禁（1.15.1）

服务端无可靠恢复契约。完整 JSON 备份不等于可恢复机制，不能根据字段名推定 `isDeleted=0` 可以恢复记录、审批关系或历史状态。

- 生产 CLI 的 `--delete` / `--restore-deleted` 始终在读取凭据、认证和任何 OA 网络请求前拒绝，即使已确认目标或获得显式授权。
- 公共 `oa_utils.update_time_entry()` 对任何非 `None` 的 `is_deleted` 在任何网络请求前拒绝；不会进入 `deletion_guard`。没有启用删除/恢复的布尔绕过开关。
- `scripts/deletion_guard.py` 仅保留内部离线 fake 回归流程，不接入生产入口。fake 中的备份、持久意图、同 ID 标记反转和读回成功，不是服务端恢复证据，不得把真实 OA 回调传入实验流程。
- 本地锁不是服务端 CAS，不能阻止其他客户端并发，不提供事务隔离或可逆保证。保留现有 submission/amendment guard、备份和 pending 日志，不清 guard，不另增记录冒充恢复。
- 待取得可靠服务端契约或隔离环境证据并单独评审后，才能设计后续实现；本版不执行真实删除/恢复验证。

## 运行时与密钥兼容

环境白名单只约束派生子进程/替换解释器：依赖探测子进程仅获 PATH/HOME、语言、时区、TMPDIR，不继承 OA 密钥、代理凭据或其他环境秘密。实际解释器切换仅额外保留 OA_ENC_KEY、指定解释器、既有 guard 目录、代理和 CA 环境白名单；不继承 PYTHONPATH/PYTHONHOME/LD_PRELOAD 或无关 token。当前解释器已满足依赖时直接返回，不净化现有进程，也不能撤销 Python 启动前的路径注入；不构成宿主权限隔离。额外运行环境定制先提出兼容需求，不回退到完整环境复制。

OpenSSL 保持 AES-256-CBC + base64 + PBKDF2 旧文件格式；密钥从匿名管道的独立 fd 输入，数据仍走 stdin。子进程参数与环境均无 OA 密钥。单行密钥超过1022 UTF-8字节或含换行/NUL 时在启动子进程前封闭拒绝，不静默截断、不改写原密钥。凭据、个人设置与现有提交保护均不迁移、不轮换。
