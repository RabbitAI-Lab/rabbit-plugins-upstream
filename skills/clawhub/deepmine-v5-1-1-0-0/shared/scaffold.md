# 四级认知支架

用户答不出、原地打转或推回决策权时，按当前 SCAFFOLD 等级降低回答难度。等级由 [orchestrator.md](../orchestrator.md) 的 Step 7 维护。

原则：**让用户选，比让用户想容易；让用户纠错，比让用户描述容易。**

---

## L1 · 换角度开放问

正常开放提问。换一个切入角度，而不是把同一个问题换个说法重问。

```
「如果给一个完全不懂这块的人讲，你会从哪儿开始说？」
「这件事最近一次发生是什么时候？」
```

## L2 · 给类比

用一个日常场景做类比，把抽象问题落到具体经验上。

```
「有点像整理衣柜——先清空、再分类、最后归位。
 你这套流程有类似的顺序吗？」
```

## L3 · 给选项锚点

给出不超过 3 个方向让用户选。**选项必须来自用户此前说过的词，不造他没提过的内容。**

```
「我列三个方向，看哪个最接近：
 1. 降低人工成本
 2. 提升响应速度
 3. 减少操作出错」
```

## L4 · 给具体场景判断

不再问「你要什么」，改成「我理解的是……对吗」。让用户纠错。

```
「我理解下来是：先把重复工单自动处理掉，人力压下来，
 响应速度要比现在快，满意度不能降——这个方向对吗？」
```

L4 回答里「但是」后面跟的内容通常是最关键的补充，留意并在下一轮展开。

---

## 支架失效处理

连续 3 轮在 L4 仍无进展（STALL 达到 3）：

1. 停止追问当前维度，标记为「未明确」
2. 输出已收集内容的阶段摘要
3. 询问用户是继续换维度、还是直接收口

```
「这块先放一放。我把前面聊到的整理一下你看看——
 [阶段摘要]
 接着往下聊，还是就到这儿直接出结果？」
```

## 禁止

- 在同一支架等级上重复问同一个问题
- L3 给出超过 3 个选项
- L3 的选项里出现用户从未提及的内容
- 支架升级时向用户说明「我换个简单的问法」
