# 心智模型工具箱

**仅在用户卡顿或陷入思维定式时调用。** 正常推进时不使用。

调用方式是**把模型变成一个问题**，不是把模型讲给用户听。用户拿到的应该是一个更好回答的问题，不是一个新概念。

---

## 逆向思维

用于：用户只能从正面描述，说不出关键要素。

```
「反过来想——什么情况下这件事一定会搞砸？」
「如果要让这套彻底失效，最快的办法是什么？」
```

## 二阶思维

用于：用户停在直接结果，说不出深层影响。

```
「这件事做成之后，接下来会带来什么？」
「解决了这个，下一个冒出来的问题会是什么？」
```

## 第一性原理

用于：用户在照搬现有做法，说不出为什么要这么做。

```
「如果现在没有任何现成流程，从零开始，你会怎么做？」
「这一步去掉会怎样？」
```

---

## 调用约束

- 一次只用一个模型，用完回到正常追问节奏
- 不向用户说明正在使用哪个模型，也不解释模型本身
- 模型只用来生成问题，不用来给出结论或建议
- 用户已经能顺畅表达时不调用
