# DeepMine 心灵捕手 · 思维挖掘 Skill

**V5.2**　｜　CC BY-SA 4.0　｜　波罗密科技 张凯

> 基于大语言模型的苏格拉底式深度追问系统。通过结构化的人机协同对话，把你脑子里未经整理的隐性知识、碎片经验和复杂构想，转化成清晰、逻辑完整、可直接对外使用的结构化知识资产。
>
> 它不替你想，只把你自己的判断问出来。最终文档里的每一句话，都是你说过的话。

## 它解决什么问题

| 你的状态 | 它做什么 | 你拿到什么 |
| --- | --- | --- |
| 有多年经验，但让你讲讲不出来 | 锚定具体事件，逐层问出做法、依据和例外 | **知识集** —— 可复用的方法论 |
| 说不清自己或公司到底好在哪 | 从服务对象一路问到可验证的结果 | **价值陈述** —— 能直接用的对外表述 |
| 想法有了，但整合不成方案 | 六维度结构化收集，逐项补齐 | **方案文档** —— 可交付的需求文档 |

## 核心机制

**三位一体追问决策引擎** —— 每一轮同时执行三重判断：

- **相关性判断**：识别回答是否偏离主题，三档处理，偏题时给选项而不是指责
- **SOLO 五层级诊断**：判断回答处在哪个认知层级（单点 → 并列 → 因果 → 规律），据此决定下一问怎么问
- **实质内容检查**：检测空泛表达，把「我觉得挺好的」逼回「具体什么时候、做了什么、结果如何」

**四级认知支架** —— 答不出来时逐级降低难度：换角度 → 给类比 → 给选项 → 给场景让你纠错。让你选比让你想容易，让你纠错比让你描述容易。

**认知激活检测** —— 捕捉你改口、自我修正、前后说法不一致的瞬间。那通常是想法真正推进的地方，此时只复述不追问，把空间留给你。

**三场景统一框架** —— 一套引擎覆盖经验萃取、价值梳理、方案生成，首轮自动路由。

**全程掌握控制权** —— 随时可以喊停、补充、换主题，或者跳过剩余追问直接出结果。

## 快速开始

### 推荐参数

| 参数 | 推荐值 |
| --- | --- |
| 模型 | Claude / GPT / DeepSeek / Qwen 等主流大模型的中高端型号 |
| Temperature | 0.4 |
| Max Tokens | 4096 |
| 上下文窗口 | ≥ 8K |

### 接入

将本仓库作为 Agent Skill 导入，或把 `SKILL.md` 内容粘贴至 System Prompt。发送任意需求内容即自动启动。

### 控制指令

| 指令 | 作用 |
| --- | --- |
| 停一下 | 暂停追问 |
| 我想补充 | 开放补充通道 |
| 换主题 | 重新锚定，已聊内容保留 |
| 帮我整理已聊内容 | 输出阶段摘要 |
| 直接整理输出 | 跳过剩余追问，立即出文档 |
