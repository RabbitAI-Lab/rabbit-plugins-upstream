# 场景一输出模板 · 知识集

用于 SCENE = K（经验萃取）。全部内容来自用户原话。

```
===KNOWLEDGE_START===

【主题】
[用户锚定的主题原话]

【典型事件】
事件一：[K1 原话：时间 + 场合 + 涉及的人]
  做法：[K2 原话，按顺序列出具体动作]
  依据：[K3 原话，或「未明确」]
  结果：[用户说过的结果，或「未明确」]

事件二：[若有第二个事件，同上结构；无则删去本节]

【例外情况】
[K4 原话，或「未明确」]
与成功案例的差别：[用户原话，或「未明确」]

【可复用的做法】
- [K5 原话，逐条列]

【成立条件】
[用户说过的前提条件，或「未明确」]

===KNOWLEDGE_END===
```

**可选追加**（质量自检不足 4 分时）：

```
【可继续深挖的部分】
- [维度名]：[缺口描述]
```
