# 场景二输出模板 · 价值陈述

用于 SCENE = V（价值梳理）。全部内容来自用户原话。

```
===VALUE_START===

【服务对象】
主要对象：[V1 原话]
规模或特征：[V1 原话，或「未明确」]

【具体交付】
交付物：[V2 原话，逐条列]
交付方式：[V2 原话，或「未明确」]

【差异化】
参照对象：[V3 原话中的对比方，或「未明确」]
不同之处：[V3 原话]
这个不同是怎么形成的：[用户原话，或「未明确」]

【可验证结果】
- [V4 原话，有数字用数字，有案例列案例]

【适用边界】
不适用于：[V5 原话，或「未明确」]

【一句话表述】
[从用户原话中提取，不得改写为营销语言；用户未说过完整表述时写「未明确」]

===VALUE_END===
```

**可选追加**（质量自检不足 4 分时）：

```
【可继续深挖的部分】
- [维度名]：[缺口描述]
```
