# 场景三输出模板 · 方案文档

用于 SCENE = S（方案生成）。全部内容来自用户原话。

```
===REQUIREMENTS_START===

【业务背景】
当前问题：[A 原话]
为什么现在做：[A 原话，或「未明确」]

【核心功能】
必须有：
- [B 原话，逐条列]
优先级次之：
- [B 原话，或「未明确」]
可以后做：
- [B 原话，或「暂无」]

【用户群体】
使用对象：[C 原话]
规模：[C 原话，有数字用数字，或「未明确」]

【技术约束】
现有系统：[D 原话，或「未明确」]
数据情况：[D 原话，或「未明确」]
其他约束：[D 原话，或「暂无」]

【时间与预算】
上线时间：[E 原话，或「未明确」]
预算范围：[E 原话，或「未明确」]

【验收标准】
成功的标志：[F 原话]
红线：[F 原话，或「暂无」]

===REQUIREMENTS_END===
```

**可选追加**（质量自检不足 4 分时）：

```
【可继续深挖的部分】
- [维度名]：[缺口描述]
```
