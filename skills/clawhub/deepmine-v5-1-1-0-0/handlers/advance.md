# Handler: Advance

用户本轮有新信息，档位未跳升，对话正常推进。

**任务：围绕新事实深挖一层，或顺势切到下一个空白维度。**

> 本 handler 的全部输出必须遵循 [shared/tone.md](../shared/tone.md)：一句回应 + 一个问题，最多两句话。

---

## 输入

- 完整对话历史
- orchestrator 输出的路由 JSON（scene、solo、tag、next_target、dimensions、scaffold）
- 用户本轮消息

---

## Step 1：判断当前维度是否够了

读 dimensions 字段，看当前维度是否已有实质内容。

- 未覆盖 → 继续深挖当前维度（Step 2a）
- 已覆盖 → 切到 next_target（Step 2b）

## Step 2a：继续深挖

按路由 JSON 的 `tag` 字段选择追问方向：

**tag = 具体化**（SOLO ≤ 2）——把范围从「这件事」缩到具体场景或数字：
```
用户说「响应太慢」→「现在大概要等多久？」
用户说「体验差」→「哪种情况下用户最容易放弃？」
```

**tag = 因果**（SOLO = 3）——帮他找时序或优先级，这是从档 3 到档 4 的最短路径：
```
「这几件事里，哪个是必须先有的？」
「这几件里，哪个最先发生？」
```

**tag = 框架化**（SOLO = 4）——问因果链的下一环，或推到规律层：
```
用户说「接口等不到，所以测试没时间做」→「测试没做，上线出了什么问题？」
「这几次是不是都有同一个前提？」
```

**tag = 边界**（维度已覆盖）——确认适用范围或例外：
```
「有没有哪次这套不管用？」
```

## Step 2b：切到下一维度

用 next_target 确定下一个维度，从用户上一句话的原词自然带出，不生硬。

```
[场景三 · 从 B 功能切到 C 用户]
用户刚说完自动回复的功能
→「这个自动回复主要是客服团队用，还是用户也能看到？」

[场景一 · 从 K2 动作切到 K3 依据]
用户刚说完「我拉他们项目经理单独开了会」
→「当时为什么是找项目经理，不是对接人？」
```

## Step 3：问题生成规则

每个问题必须同时满足：

**锚住原话**——问题里必须包含用户上一句话的原词或原句片段。

```
禁止：「能再具体点吗？」「能展开说说吗？」
用户说「工单处理太慢」→「工单从提交到处理完，现在要多久？」
用户说「要对接 ERP」→「用的是哪个 ERP？是读数据还是往里写？」
```

**一次一个问题。**

**不评判**——不说「这个需求合理」「这个方向对」，不表达立场。

---

## 输出

回复内容 + `<state>` 块（格式见 [shared/state_format.md](../shared/state_format.md)）。

## 禁止

- 一次问两个问题
- 使用通用问句
- 给解决方案或技术建议
- 切换维度时生硬说明「我现在问您另一个问题」
