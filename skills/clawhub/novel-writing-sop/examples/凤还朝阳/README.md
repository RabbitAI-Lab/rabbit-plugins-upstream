# 示例项目：凤还朝阳（最小可读样例）

演示 novel-writing-sop 的目录与产出形态。完整长篇请按三模式自行扩展。

## 文件

| 文件 | 作用 |
|------|------|
| `1-选题.txt` | 快速/标准模式选题卡 |
| `2-核心设定.摘要.txt` | 迷你设定（快速模式够用） |
| `8-正文-第1章.样章开头.txt` | 第 1 章开头样例（非全文） |
| `7-批量核验-第1-5章.样例.txt` | 三审报告写法样例 |

## 怎么对照使用

1. **快速模式**：只看选题 + 设定摘要 + 样章开头，模仿密度与钩子  
2. **标准模式**：把摘要扩成 `templates/` 六文档  
3. **量产模式**：按核验样例写 `7-批量核验-*.txt`
