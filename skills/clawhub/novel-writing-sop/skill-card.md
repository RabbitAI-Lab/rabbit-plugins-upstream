## Use Case:

External writers and agents use this skill to plan, draft, continue, revise, and batch-review Chinese web-novel projects. It supports quick first-chapter drafting, structured long-form outlining, five-chapter production batches, and quality checks for continuity, reader appeal, and prose style.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill includes guidance for lowering AI-detection rates in generated prose.

Mitigation: Use the style-editing guidance for readability and voice; do not use it to hide AI authorship or evade platform, school, workplace, or publisher disclosure rules.

Risk: The skill can activate broadly on fiction-writing and continuation requests.

Mitigation: Install it only when a structured Chinese web-novel workflow is desired, and confirm the intended mode before long-form drafting.

Risk: Included scripts create or inspect files in local project directories.

Mitigation: Run the scripts only on project directories you choose and review generated files before using them in a release workflow.

Risk: The workflow asks users to learn from references and platform conventions, which can create plagiarism risk if used carelessly.

Mitigation: Keep reference works as structure or style inspiration only, and review generated plots, settings, and passages for originality before publication.
