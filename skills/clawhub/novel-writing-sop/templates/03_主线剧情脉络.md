# 03_主线剧情脉络（5000 字）

> **用途**：规划故事整体框架，按卷划分，明确每卷的核心主题和剧情走向

---

## 分卷规划（五大卷结构）

### 第一卷：启程（0-20 万字）

**卷名含义**：主角从平凡走向非凡的起点

**核心主题**：成长与觉醒

**剧情要点**：
- [ ] 建立日常：展示主角的初始状态和生活环境
- [ ] 遭遇变故：突发事件打破平静（退婚/灭门/穿越/觉醒）
- [ ] 被迫踏上征途：没有退路的选择
- [ ] 获得金手指/导师：关键转折点
- [ ] 初战告捷：建立读者信心
- [ ] 第一卷结尾：小高潮 + 引出更大世界

**关键人物**：引路人、初期伙伴、第一个小 BOSS

**结尾悬念**：发现更大的阴谋/接到新任务/身世线索

---

### 第二卷：初露锋芒（20-40 万字）

**卷名含义**：主角在新环境中证明自己

**核心主题**：冒险与历练

**剧情要点**：
- [ ] 换地图：进入更大舞台（宗门/学院/帝都）
- [ ] 建立团队：结识核心伙伴
- [ ] 区域反派：地方势力的冲突
- [ ] 击败区域 BOSS：证明实力
- [ ] 接触世界秘密：发现更大的阴谋/真相的一角
- [ ] 能力突破：达到新境界

**关键人物**：新伙伴、区域 BOSS、神秘引路人

**结尾悬念**：发现自身与大局的关联/被迫卷入更大纷争

---

### 第三卷：风云激荡（40-60 万字）

**卷名含义**：矛盾激化，主角遭遇重大挫折

**核心主题**：挫折与蜕变

**剧情要点**：
- [ ] 卷入更大势力纷争：派系斗争/宗门大战
- [ ] 遭遇重大挫折：失败/背叛/失去重要的人
- [ ] 跌入低谷：身心受创，信念动摇
- [ ] 沉淀与领悟：在低谷中获得新力量/新认知
- [ ] 重整旗鼓：以更成熟的姿态回归

**关键人物**：背叛者、精神导师、生死之交

**结尾悬念**：发现真正的敌人/做出重大抉择

---

### 第四卷：强者之路（60-80 万字）

**卷名含义**：主角成长为真正的强者

**核心主题**：责任与抉择

**剧情要点**：
- [ ] 揭露世界真相：背后的阴谋浮出水面
- [ ] 与主要反派正面交锋：理念/利益的终极冲突
- [ ] 做出影响世界的重大决策：牺牲小我/拯救苍生
- [ ] 实力跃升：达到顶尖层次
- [ ] 集结力量：联合盟友，准备决战

**关键人物**：核心反派、关键盟友、牺牲者

**结尾悬念**：决战前夕的平静/最终 BOSS 现身

---

### 第五卷：巅峰对决（80-100 万字）

**卷名含义**：所有矛盾的总爆发和解决

**核心主题**：决战与新生

**剧情要点**：
- [ ] 集结力量：整合所有资源和盟友
- [ ] 与最终 BOSS 决战：多阶段战斗/智斗 + 武斗
- [ ] 解决所有伏笔：回收所有悬念
- [ ] 交代战后世界：新的秩序建立
- [ ] 主角归宿：归隐/继续前行/新的开始

**关键人物**：最终 BOSS、所有重要角色

**结尾**：圆满收官或开放式结局

---

## 创作要点

- [ ] 每卷要有明确的主题和核心冲突
- [ ] 卷与卷之间要有承接和递进
- [ ] 每卷结尾要有悬念引出下卷
- [ ] 高潮要分布在每卷的中后段
- [ ] 节奏要有张有弛，不要一直紧绷
