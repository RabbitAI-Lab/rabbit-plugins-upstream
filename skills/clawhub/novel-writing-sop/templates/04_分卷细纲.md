# 04_分卷细纲（10000-15000 字）

> **用途**：这是大纲的主体部分，按卷分章规划，明确每章的核心内容
> **粒度**：不必细化到每一章，但每 10-20 章要有关键节点

---

## 分卷细纲模板

### 第 X 卷：[卷名]

**本卷核心目标**：
- 主角要达成的具体目标
- 需要解决的核心冲突
- 能力/心智成长点

**预计章节**：第 X 章 - 第 X 章（共 X 章）

**主要出场人物**：
- 主角
- 核心伙伴
- 本卷反派
- 功能性 NPC

---

### 情节点规划（10-20 个核心节点）

```\n第 1 章：日常打破 → 第 2 章：被迫选择 → 第 3 章：初遇伙伴\n   ↓\n第 4-5 章：小试牛刀 → 第 6-8 章：遭遇挫折 → 第 9-10 章：反杀\n   ↓\n第 11-15 章：高潮战斗 → 第 16-18 章：收尾 + 新悬念\n```\n\n**详细节点列表**：\n\n| 章节 | 核心事件 | 出场人物 | 情绪曲线 | 爽点/冲突点 |\n|------|----------|----------|----------|-------------|\n| 第 1 章 | | | 平静→波动 | |\n| 第 2 章 | | | 波动→上升 | |\n| 第 3 章 | | | 上升→小高潮 | |\n| ... | | | | |\n\n---

## 分卷细纲示例（以第一卷为例）

### 第一卷：启程（第 1 章 - 第 20 章）

**本卷核心目标**：
- 主角从废柴到觉醒，完成初次成长
- 建立基础人脉圈
- 引出世界观和更大的舞台

**情节点规划**：

```\n第 1 章：测试受辱 → 第 2 章：获得金手指 → 第 3 章：初次尝试\n   ↓\n第 4-6 章：家族小比 → 第 7-10 章：外出历练 → 第 11-15 章：遭遇强敌\n   ↓\n第 16-18 章：绝地反杀 → 第 19 章：家族大比 → 第 20 章：踏上征途\n```\n\n**关键章节设计**：\n\n| 章节范围 | 核心事件 | 情绪曲线 | 爽点密度 |\n|----------|----------|----------|----------|\n| 1-3 章 | 受辱→觉醒→初试 | 屈辱→惊喜→期待 | 1 个爽点 |\n| 4-6 章 | 小比打脸 | 压抑→爆发 | 2-3 个爽点 |\n| 7-10 章 | 外出历练 | 紧张→收获 | 1 个爽点 + 1 个温情 |\n| 11-15 章 | 遭遇强敌 | 危机→苦战 | 持续紧张 |\n| 16-18 章 | 绝地反杀 | 压抑→爆发 | 高潮爽点 |\n| 19-20 章 | 大比夺冠→踏上征途 | 荣耀→期待 | 圆满 + 悬念 |\n\n**结尾悬念**：
- 主角发现身世线索
- 收到大宗门邀请函
- 暗示更大的阴谋

---

## 创作要点

- [ ] 每章要有明确的目标和冲突
- [ ] 10-20 章形成一个中等高潮
- [ ] 每卷结尾必须有大高潮和悬念
- [ ] 情节点之间要有因果关系，不能断层
- [ ] 爽点分布要均匀，不要过度集中或过度稀疏
- [ ] 留出调整空间，允许根据创作情况微调
