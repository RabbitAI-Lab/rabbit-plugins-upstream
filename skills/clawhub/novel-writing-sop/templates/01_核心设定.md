# 01_核心设定（2000 字）

> **用途**：定义小说的世界观、力量体系和核心悬念，为后续创作奠定基础

---

## 一、世界观

### 1.1 时代背景
- **类型定位**：玄幻/仙侠/都市/科幻等
- **时间设定**：古代/现代/未来/架空
- **地理分布**：
  - 主要大陆/国家/城市
  - 势力分布图
  - 重要地点标记

### 1.2 地理势力
- **主要势力**：宗门/家族/集团/组织
- **势力关系**：盟友、敌对、中立
- **资源分布**：灵脉/矿产/技术/财富集中地

---

## 二、力量体系

### 2.1 等级划分
```
等级 1 → 等级 2 → 等级 3 → ... → 等级 N
```
- 每个等级的名称和特征
- 升级条件和难度
- 各等级的能力边界

### 2.2 能力设定
- **能力类型**：法术/武技/科技/异能
- **能力获取方式**：修炼/遗传/学习/觉醒
- **能力使用代价**：灵力消耗/寿命损耗/副作用

### 2.3 限制规则
- **不可逾越的红线**：越级挑战的代价、禁忌之术
- **平衡机制**：相生相克、此消彼长
- **特殊例外**：主角的金手指如何绕过限制

---

## 三、核心悬念

### 3.1 主线概括
用一句话说清故事核心：
> 例如："废柴少年意外获得上古传承，踏上逆天改命之路"

### 3.2 三大钩子（至少）
1. **身世之谜**：主角的真实身份/血统/来历
2. **未解之谜**：某个重大事件背后的真相
3. **情感悬念**：关键人物的命运走向

### 3.3 悬念释放节奏
- 第 X 章：首次暗示
- 第 X 章：部分揭露
- 第 X 章：重大反转
- 第 X 章：真相大白

---

## 四、创作要点

- [ ] 世界观要能自洽，不要前后矛盾
- [ ] 力量体系要有明确上限，避免后期崩坏
- [ ] 悬念要足够吸引人，但不能故弄玄虚
- [ ] 核心设定一旦确定，后续不要随意更改
