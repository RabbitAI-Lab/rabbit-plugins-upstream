# 03_章节创作阶段

> **阶段目标**：按大纲批量创作章节正文，经过双视角审核后定稿
> **产出物**：`8-正文-第N章.txt` + `7-批量核验-第{N}-{M}章.txt`
> **完成标准**：每章通过编剧审+读者审+去AI腔过滤，字数≥2500
> **核心模式**：**5章一批，批量写作，批量核验**

---

## 📚 核心模式：5章一批迭代写作

### 为什么5章一批？

- 5章 = 1个完整剧情单元，上下文连贯
- 批量写比逐章写效率高，节奏不中断
- 批量核验能发现跨章的连贯性问题
- 防止逐章写作导致的情节漂移

### 批量写作循环

```
确认批次位置 → 加载上下文 → 写5章正文 → 双视角审核 → 去AI腔过滤 → 修改或继续
```

---

## 📖 Part A：分章大纲生成（如未完成）

写正文前，确认本批5章的分章大纲已存在（`5-第{N}-{M}章-分章大纲.txt`）。

如果没有，先生成：

### A1 确定批次位置

问"为第几章开始？"，计算批次范围 N~N+4。

### A2 加载上下文

加载选题、设定、分卷大纲、剧情单元、上一批结尾钩子。

### A3 生成5章大纲

每章模板：标题、核心目标、单元出处、场景、人物、关键情节(3-4节点)、爽点、结尾钩子。

**约束**：
- 5章范围锁定，不超出剧情单元
- 不新增角色（除非大纲已规划）
- 钩子链必须连续

### A4 批量核验

| 核验维度 | 标准 | 
|----------|------|
| 剧情单元覆盖率 | ≥85% |
| 角色合规 | 不超出设定 |
| 爽点分布 | 每章≥1个 |
| 钩子链 | 章章衔接，末章钩子引下批 |
| 与前文一致性 | 不与前文矛盾 |

覆盖率<85或任一章有遗漏→退回修改。

### A5 保存

通过后保存到 `5-第{N}-{N+4}章-分章大纲.txt`。

---

## 📖 Part B：正文批量写作

### B1 确定正文批次位置

确认对应分章大纲文件存在。

### B2 逐章写正文

按分章大纲逐章写作，每章强制 **2500字以上**（不含标题和【本章完】标记）。

**写作要点**：
- [ ] 按照 `5-第{N}-{M}章-分章大纲.txt` 中的章节规划写作
- [ ] 遵循 `写作风格分析报告.md` 的文风要求
- [ ] 章节开头要有钩子，结尾要有悬念
- [ ] 爽点密度：每 1000 字至少 1 个爽点
- [ ] 心理活动外化为动作/神态/对话
- [ ] 对话标签多样化，避免单调的"XX 道"

**写作禁忌**：
- ❌ 禁用 Markdown 标题符号（#）
- ❌ 禁用间隔符号（——、--）
- ❌ 禁用"不是...而是..."句式
- ❌ 禁用 AI 高频词（仿佛、猛地、忽然、竟然...）

### B3 字数核验

每章写完后**立即核验字数**（不含标题和【本章完】标记）。
不足2500必须返回扩充，不得跳过，不得累积到批末补。

---

## 📖 Part C：双视角审核（5章全部写完后执行）

### C1 编剧审核（novel-review）

**审核四大维度**（100分制）：

| 维度 | 权重 | 检查内容 |
|------|------|----------|
| 剧情连贯性 | 30分 | 与大纲一致性、前后文衔接、情节逻辑 |
| 内容质量 | 30分 | 人物行为合理性、对话自然度、描写到位度 |
| 字数要求 | 20分 | 每章≥2500字、无注水 |
| 节奏可读性 | 20分 | 爽点分布、钩子设置、节奏张弛 |

**评分标准**：
- 优秀 90-100
- 良好 80-89
- 合格 70-79
- 不合格 <70（必须修改）

### C2 读者审核（novel-reader-review）

**模拟挑剔读者视角**（100分制）：

| 维度 | 权重 | 检查内容 |
|------|------|----------|
| 故事连贯性 | 25分 | 5章是否构成完整小故事、衔接是否自然 |
| 吸引力与可读性 | 25分 | 节奏、悬念、钩子设置 |
| 爽点密度 | 25分 | 爽点数量(≥5个)、类型多样化、分布节奏 |
| 剧情Bug检测 | 25分 | 设定矛盾、人设崩坏、情节漏洞、时间线错误 |

**评分标准**：同上

### C3 去AI腔过滤（stop-slop-cn）

加载 [去AI腔过滤指南.md](去AI腔过滤指南.md)，执行：

**十大禁用语扫描**：
- [ ] 清嗓式开场白（值得注意的是、不得不说...）
- [ ] 二元对比（不是...而是...）
- [ ] 时间转场废话（就在此时、突然、忽然...）
- [ ] 心理口癖（不禁想到、心中暗想...）
- [ ] 情绪套路（心中一凛、倒吸一口凉气...）
- [ ] 战斗套路（身形一闪、快如闪电...）
- [ ] 副词泛滥（非常、十分、极其...）
- [ ] 系统流特供（一排数据流、半透明面板...）
- [ ] 废话过渡（此刻他心中只有一个念头...）

**六大禁用结构扫描**：
- [ ] 二元对立结构
- [ ] 否定列举
- [ ] 设问自答
- [ ] 排比堆砌
- [ ] 流水账转场
- [ ] 段落结尾金句综合征

**评分卡**（每章50分制，低于38分必须改）：

| 维度 | 问题 | /10 |
|------|------|-----|
| 直接性 | 有"不是…而是…"类二元结构吗？ | |
| 干净度 | 能找到"值得注意的是""不得不说"吗？ | |
| 真实感 | 读者会觉得这是人写的吗？ | |
| 动作化 | 心理描写多还是动作/对话多？ | |
| 具体性 | 抽象形容词多还是具体细节多？ | |

## 📖 Part D：修正与推进

### D1 判定结果

- 编剧审 + 读者审 均≥80，且去AI腔≥38 → ✅ 通过
- 任一审核 <80 或去AI腔 <38 → ❌ 进入修改模式

### D2 修改模式

参考 [去AI腔过滤指南.md](去AI腔过滤指南.md) 的改写方向：

| ❌ AI腔 | ✅ 更好 |
|---------|---------|
| 他心中十分惊讶 | 他嘴里的烟掉在地上 |
| 他感到一股寒意 | 他不自觉地缩了缩脖子 |
| 他意识到情况不妙 | "操。"他骂了一声 |
| 眼前是极其壮观的景象 | 眼前五米高的机甲把半边天都遮了 |

修改后重新执行 C1-C3 核验，直到通过。

### D3 保存核验报告

保存到 `7-批量核验-第{N}-{N+4}章.txt`，包含：
- 编剧审评分 + 关键问题
- 读者审评分 + 关键问题
- 去AI腔评分 + 违规词清单
- 修改记录

### D4 更新摘要库

每章通过审核后，更新章节摘要：

```markdown
## 第 N 章：标题
**核心事件**：
- 事件 1
- 事件 2
**埋下的伏笔**：
- 伏笔 1
**钩子**：→ 下章衔接点
**关键人物变化**：
- 人物 A：变化描述
```

同步更新 `6-执行附录.txt` 中的伏笔状态和进度追踪。

## 📝 文风要求

**严格遵循**：[写作风格分析报告.md](写作风格分析报告.md)

**核心要点**：
- 心理活动外化为动作/神态/对话
- 对话标签多样化，避免单调的"XX 道"
- 句式长短结合，形成节奏感
- 章节结尾必须有钩子（悬念/冲突预告/反转）
- 禁用 AI 高频词

**人工修改特征**（降低AI检测率）：
1. 删除间隔符号（——）
2. 增加语气词（甚是、颇有些、半晌）
3. 简化对话标签
4. 调整句式节奏，让句子更紧凑
5. 心理外化：用动作/眼神/表情代替心理描写
6. 结尾加钩子，留悬念
7. 口语化称呼
8. 极简主义：能删则删
9. 删除 AI 规律：去除规律性表述

---

## 🔄 批量延续模式

当用户说"继续直到结束"时：

- 跳过批次间确认，自动进入下一批
- 核验仍须执行（可精简为摘要格式），**不可跳过**
- 每5章保存一次核验报告

---

## ⚠️ 常见陷阱

| 陷阱 | 说明 | 正确做法 |
|------|------|----------|
| 多章合并写再拆分 | 导致每章字数不足 | 逐章写，逐章核验字数 |
| 字数核验延迟 | 积累到批末才查 | 写一章核验一章，不累积债务 |
| 大纲文件范围重叠 | 批次间章节编号冲突 | 每批独立范围文件 |
| 跳过核验 | 追求速度跳过审核 | 核验不可跳过 |
| 逐章循环 | 写1章→审1章→改1章 | 5章一批写完再统一审 |
