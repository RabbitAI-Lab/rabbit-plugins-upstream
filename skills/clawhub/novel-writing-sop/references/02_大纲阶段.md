# 02_大纲阶段

> **阶段目标**：完成详细的小说大纲，为批量章节创作奠定基础
> **产出物**：6 个大纲文档（`2-核心设定.txt` `4-分卷大纲.txt` `5-剧情单元.txt` `5-分章大纲.txt` `6-节奏控制.txt` `6-执行附录.txt`）
> **完成标准**：6 个文档全部完成并通过审核，才能开始章节创作
> **重要性**：⭐⭐⭐⭐⭐ **这是全书质量的关键！**

---

## 📋 核心原则

**大纲不是走过场，而是创作的地图！**

- ✅ **详细优先**：大纲越详细，创作越顺畅
- ✅ **逻辑自洽**：世界观、人物动机、剧情发展要能自圆其说
- ✅ **单元化拆分**：5章一个剧情单元，便于批量写作和核验
- ✅ **预留空间**：大纲不是铁律，允许创作中微调
- ✅ **审核通过**：大纲必须通过审核才能开始写正文

---

## 📚 大纲六文档结构

大纲阶段需要完成 **6 个独立的文档**，每个文档都有详细模板：

| 序号 | 文件编号 | 文档名 | 字数要求 | 核心内容 | 关键点 |
|------|----------|--------|----------|----------|--------|
| 1 | `2` | [核心设定](大纲模板/01_核心设定.md) | 2000 字 | 世界观、力量体系、核心悬念 | 世界能自洽，悬念够吸引人 |
| 2 | `2` | [人物群像](大纲模板/02_人物群像.md) | 3000 字 | 主角、配角、反派档案 | 人物有动机，关系有演变 |
| 3 | `4` | [主线剧情脉络](大纲模板/03_主线剧情脉络.md) | 5000 字 | 五大卷剧情框架 | 每卷有主题，卷卷有悬念 |
| 4 | `4`+`5` | [分卷细纲 + 剧情单元](大纲模板/04_分卷细纲.md) | 10000-15000 字 | 每卷→剧情单元→5章分章大纲 | **重点中的重点** |
| 5 | `6` | [系统与节奏控制](大纲模板/05_系统与节奏控制.md) | 3000 字 | 升级、情绪、爽点节奏 | 节奏有张弛，爽点分布匀 |
| 6 | `6` | [执行附录](大纲模板/06_执行附录.md) | 2000 字 | 伏笔、道具、进度追踪 | 伏笔有回收，设定不矛盾 |

**总计**：约 25000-30000 字大纲

## 🚀 执行步骤

### 步骤 1：核心设定

从 `大纲模板/01_核心设定.md` 和 `大纲模板/02_人物群像.md` 完成：

- 世界观、力量体系、核心悬念
- 主角、配角、反派档案
- 保存到 `2-核心设定.txt`

### 步骤 2：分卷大纲

从 `大纲模板/03_主线剧情脉络.md` 完成五卷框架：

- 每卷核心主题、剧情走向、结尾悬念
- 保存到 `4-分卷大纲.txt`

### 步骤 3：剧情单元拆分（⭐新增）

**全书结构**：300章 / 5卷 / 每卷60章

将每卷60章拆为 **12个剧情单元**，每个单元 = **5章**：

```
第1卷（60章）
├── 剧情单元1：第1-5章
├── 剧情单元2：第6-10章
├── ...
└── 剧情单元12：第56-60章
```

每个剧情单元包含：

| 项目 | 说明 |
|------|------|
| 单元主题 | 这5章讲什么 |
| 核心冲突 | 驱动本单元的矛盾 |
| 爽点安排 | 至少3个爽点 + 类型标注 |
| 情绪曲线 | 起→承→转→合 |
| 钩子链 | 每章结尾钩子→下章开头衔接 |
| 角色出场 | 本单元涉及的人物 |

保存到 `5-第X卷-剧情单元.txt`

### 步骤 4：分章大纲（5章一批）

基于剧情单元，逐批生成 **5章一组** 的分章大纲：

每章使用模板：

| 项目 | 说明 |
|------|------|
| 标题 | 章节名 |
| 核心目标 | 本章要达成什么 |
| 场景 | 发生地点 |
| 登场人物 | 出场角色 |
| 关键情节 | 3-4个节点 |
| 爽点 | 类型 + 位置 |
| 结尾钩子 | 引向下章的悬念 |

保存到 `5-第{N}-{N+4}章-分章大纲.txt`

> **注意**：分章大纲可以在大纲阶段全部完成，也可以在创作阶段按需生成（每批写之前生成对应5章大纲），但**写之前必须有大纲**。

### 步骤 5：节奏控制与执行附录

- 从 `大纲模板/05_系统与节奏控制.md` 完成节奏设计，保存到 `6-节奏控制.txt`
- 从 `大纲模板/06_执行附录.md` 完成伏笔/道具/设定追踪，保存到 `6-执行附录.txt`

### 步骤 6：审核大纲

- [ ] 世界观是否自洽？
- [ ] 人物动机是否合理？
- [ ] 剧情发展是否有逻辑？
- [ ] 每个剧情单元是否有完整起承转合？
- [ ] 爽点分布是否均匀？
- [ ] 伏笔是否有回收计划？
- [ ] 钩子链是否连续（章→章、单元→单元）？

### 步骤 7：确认通过

- [ ] 大纲通过审核
- [ ] 进入下一阶段：[03_章节创作阶段.md](03_章节创作阶段.md)

## ⚠️ 常见错误

❌ **错误 1**：大纲太简单，只有几百字
✅ **正确**：按 6 个模板详细填写，总计 25000-30000 字

❌ **错误 2**：边写边想，没有大纲
✅ **正确**：大纲完成前不写正文

❌ **错误 3**：大纲写完就扔一边
✅ **正确**：创作时对照大纲，定期回顾

❌ **错误 4**：大纲过于僵化，不允许调整
✅ **正确**：大纲是地图，可以微调但不能乱改

❌ **错误 5**：剧情单元没有钩子链
✅ **正确**：每章结尾必须有钩子，衔接下章开头

## 📝 大纲审核清单

- [ ] 世界观能自洽，没有明显漏洞
- [ ] 力量体系有明确上限，不会后期崩坏
- [ ] 主角有清晰的成长弧线
- [ ] 反派有合理动机，不是纯工具人
- [ ] 每卷有明确主题和高潮
- [ ] 每个剧情单元有完整起承转合
- [ ] 伏笔有回收计划
- [ ] 爽点分布均匀，节奏有张弛
- [ ] 钩子链连续，章章衔接自然
- [ ] 分章大纲足够详细，每章目标清晰
