# 01_选题与素材阶段

> **阶段目标**：从灵感出发，策划选题方案，搜集充足素材，确定小说类型和受众
> **产出物**：`1-选题.txt` + `3-标签简介.txt` + 素材包
> **完成标准**：选题锁定、标签简介就绪、素材充足，可以开始写大纲
> **核心原则**：⭐⭐⭐⭐⭐ **参考可以，模仿学习，但绝不抄袭！要有自己的节奏和故事！**

---

## ⚠️ 重要提醒（必读）

### 🚫 关于抄袭的红线

**素材的正确用法**：
- ✅ 学习优秀作品的结构和节奏
- ✅ 分析爽点设计和情绪调动
- ✅ 借鉴世界观搭建的方法论
- ✅ 吸收人物塑造的技巧
- ✅ 避免前人踩过的坑

**绝对禁止**：
- ❌ 直接照搬他人作品的情节、人物设定、世界观
- ❌ 把别人的核心创意包装后当成自己的
- ❌ 洗稿（换皮不换骨）
- ❌ 过度借鉴导致读者既视感太强

**记住**：
> 参考是为了学习技巧，抄袭是扼杀创意。
> 素材是燃料，但火要是你自己的。
> 可以站在巨人肩膀上，但别把巨人当成自己。

---

## 一、选题策划

### 1.1 需求摸底

先聊清楚以下问题，再动手策划：

- [ ] 偏好的类型/题材（玄幻/仙侠/都市/科幻/历史...）
- [ ] 想用的金手指/核心梗（系统/签到/重生/穿越...）
- [ ] 目标平台（番茄/起点/晋江...）
- [ ] 参考案例（喜欢哪些书的感觉）

### 1.2 生成选题方案

一次性生成 **3 个选题方案**，每个方案包含：

| 项目 | 要求 |
|------|------|
| 书名 | 正好15字符（含标点），吸睛，包含核心梗/反差感 |
| 简介 | 150字内，黄金三句开头 |
| 核心卖点 | 一句话说清这本的吸引力 |
| 目标受众 | 男频/女频 + 年龄层 |
| 差异化 | 和同类书比，我们的特色 |

### 1.3 选定与定稿

- [ ] 用户选定一个方案
- [ ] 保存到 `1-选题.txt`（书名 + 简介 + 核心卖点 + 目标受众）

### 1.4 标签与简介

选定后立即生成平台发布所需的材料：

- [ ] **作品标签**：6-8个（匹配目标平台的热门标签）
- [ ] **黄金简介**：500字，含黄金三句式（第一句抓眼球、第二句抛悬念、第三句亮卖点）
- [ ] 保存到 `3-标签简介.txt`

---

## 二、素材搜集

选题确定后，围绕选定方向深入搜集：

### 2.1 世界观素材
- [ ] 参考的历史背景/地理环境
- [ ] 参考的力量体系（修炼等级/魔法体系/科技树）
- [ ] 特殊设定（特殊职业/组织/规则）

### 2.2 人物素材
- [ ] 主角原型或性格参考
- [ ] 重要配角灵感
- [ ] 反派设定参考

### 2.3 剧情素材
- [ ] 想写的经典桥段（退婚/废柴逆袭/复仇...）
- [ ] 想写的爽点类型（打脸/升级/感情...）
- [ ] 想写的感情线类型

### 2.4 参考作品
- [ ] 同类优秀作品（学习优点）
- [ ] 想超越的作品
- [ ] 想避免的套路

## 三、素材整理

### 3.1 建立项目文件夹

```
[小说名]/
├── 1-选题.txt
├── 3-标签简介.txt
├── 素材/
│   ├── 灵感笔记.md
│   ├── 世界观参考.md
│   ├── 人物参考.md
│   ├── 剧情脑洞.md
│   ├── 写作风格分析报告.md
│   └── 参考资料/
├── 大纲/          ← 02阶段产出
└── 正文/          ← 03阶段产出
```

### 3.2 风格分析参考

- [ ] 阅读并理解 `写作风格分析报告.md`
- [ ] 明确原作者的写作特征和禁忌
- [ ] 后续创作严格遵循风格报告中的要求

### 3.3 素材筛选

- [ ] 删除重复或冲突的设定
- [ ] 合并相似的灵感
- [ ] 标记优先级（核心/次要/可选）
