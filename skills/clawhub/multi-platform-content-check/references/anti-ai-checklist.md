# 去AI化写作检查清单

> 基于 Wikipedia "Signs of AI writing" 完整模式清单（30+种AI写作特征），适配中文写作场景。覆盖词汇、句式、结构、灵魂四维度。任何内容在交付前必须逐条对照检查。

---

## 一、词汇维度

### 1.1 开头套话（严禁出现在首段）

- 随着……的发展/进步/普及
- 在当今/现代社会/数字化时代……
- 众所周知
- 不可否认/不可否认的是
- 毋庸置疑/毋庸讳言
- 近年来，……引起了广泛关注
- ……正成为越来越多企业的选择
- 在这个……的时代
- 如今，……已经成为……
- 当我们谈论……时

### 1.2 过渡词（禁止或严格限制）

- 值得一提的是
- 不仅仅是……更是……
- 首先……其次……最后……
- 一方面……另一方面……
- 与此同时
- 在这个过程中
- 在此基础上
- 除此之外
- 更为重要的是
- 换句话说
- 从另一个角度来看
- 从某种程度上来说
- 事实上
- 客观来说/严格来说
- 归根结底
- 总而言之/综上所述/综合来看
- 由此可见
- 此外/同时
- 需要注意的是/需要指出的是
- 重要的是

### 1.3 结尾套话（严禁出现在末段）

- 总而言之/综上所述/综合来看
- 未来的路还很长
- 让我们拭目以待
- 相信在不久的将来
- ……任重道远
- 为行业注入新的活力
- 开启……新篇章
- 赋能……新发展
- 助力……迈上新台阶
- 为……提供了新的思路/方向
- 期待……带来更多可能
- ……的未来值得期待
- 让我们共同期待
- ……将继续引领/推动
- 展望未来，……

### 1.4 意义膨胀词（禁止）

AI写作喜欢给事物赋予不恰当的重大意义：

- 见证了……
- 标志着……的转折点/里程碑
- 是……的缩影/写照/体现
- 彰显了……
- 体现了……的深远意义
- 为……奠定了坚实基础
- 开启了……的新篇章/新阶段
- 推动了……的进程
- 对……产生了深远影响
- 在……中发挥着举足轻重的作用
- 成为……的重要力量/关键一环
- 引领……迈入新阶段
- 代表着……的方向/趋势
- 具有里程碑式的意义

### 1.5 形容词与修饰语（禁止）

- 深入的/深度的（探讨/分析/解读）
- 全面的/全方位的/多维度/多角度
- 淋漓尽致
- 不可或缺/至关重要/举足轻重
- 日益增长
- 蓬勃发展/方兴未艾/应运而生
- 潜移默化/焕然一新
- 层出不穷/日新月异/瞬息万变
- 令人瞩目/值得深思/引发思考
- 意义深远/影响广泛
- 行之有效/切实可行
- 丰富多彩/博大精深/源远流长
- 与时俱进/充满活力/生机勃勃

### 1.6 动词套话（禁止）

- 深入探讨/全面解析/深度解读
- 一文读懂/全面剖析
- 系统梳理/深入浅出
- 纵深推进/持续赋能/全面赋能
- 携手共进/共创未来
- 砥砺前行/锐意进取
- 助力企业/行业……
- 赋能……/赋能千行百业
- 打造……生态/构建……格局
- 擘画……蓝图

### 1.7 伪权威表达（严禁）

- 与XX多年经验……
- 据我从XX那得知……
- 据业内人士透露……
- 据研究表明……（无具体来源时）
- 根据调查/数据显示……（无具体来源时）
- 业内专家表示……（无具体人名时）
- 有观点认为……
- 不少企业表示……
- 业界普遍认为……
- 多项研究表明……（无具体引用时）
- 据相关统计……（无具体来源时）

### 1.8 结构性标记词（禁止用于段落开头）

- 第一/第二/第三
- 其一/其二/其三
- 一方面/另一方面
- 首先/其次/再次/最后
- 接下来/那么
- 下面我们来看看/让我们来看看

### 1.9 推销式语言（禁止）

- 坐落于/位于……核心区域
- 拥有/坐拥/荟萃
- 丰富的/深厚的（文化/底蕴/积淀）
- 令人叹为观止/美不胜收
- 独树一帜/引人入胜
- 堪称……/不容错过
- 备受瞩目/广受好评
- 深受……青睐
- 赢得了……的一致好评
- 树立了……标杆

### 1.10 模糊归因词（禁止，除非有具体来源）

- 业内报告显示
- 观察人士指出
- 有批评者认为
- 多方消息源
- 业界人士
- 相关数据显示
- 据多方了解

### 1.11 物化客户词汇（严禁）

把客户当作实验对象、小白鼠或观察样本的词汇，一律禁止：

- 实践（如"在实践中""实践证明"）
- 观察（如"通过观察""观察发现"）
- 试验/实验（如"经过试验""实验表明"）
- 测试（如"在客户中测试"）
- 试错（如"试错成本"）
- 验证（如"验证了可行性"——除非指具体技术验证）
- 样本（如"客户样本"）
- 标杆/示范
- 摸索/探路
- 跑通/落地验证

**替代原则**：用"合作""服务""项目""实际使用"等平等视角词汇。

### 1.12 高频AI词汇（英文对照）

以下英文词在中文语境中对应使用也需警惕：

- Additionally → 此外/另外
- Align with → 与……保持一致
- Crucial → 至关重要
- Delve → 深入探讨
- Emphasize → 强调
- Enduring → 持久的
- Enhance → 增强
- Foster → 培养/促进
- Garner → 获得
- Highlight → 突出
- Interplay → 相互作用
- Intricate → 复杂
- Landscape → 格局
- Pivotal → 关键的
- Showcase → 展示
- Tapestry → 织锦
- Testament → 证明
- Underscore → 强调
- Vibrant → 充满活力的

### 1.13 深度伪权威短语（禁止）

- The real question is / 真正的问题是
- At its core / 本质上
- In reality / 实际上（用作伪深度时）
- What really matters / 真正重要的是
- Fundamentally / 从根本上说
- The deeper issue / 更深层的问题
- The heart of the matter / 问题的核心

### 1.14 信号词/预告式短语（禁止）

- Let's dive in / 让我们深入看看
- Let's explore / 让我们探索
- Here's what you need to know / 这是你需要知道的
- Now let's look at / 现在让我们看看
- Without further ado / 废话不多说

## 二、句式维度

### 2.1 系动词回避（Copula Avoidance）

AI倾向用复杂动词替代简单的"是""有"。

**禁止：** "作为……的重要组成部分""扮演着……的角色""发挥着……的作用"
**改用：** 直接说"是……的一部分""有……的作用"

**错误：** 这个平台扮演着企业数字化转型的关键角色
**正确：** 这个平台是企业数字化的工具之一

### 2.2 否定并列句式（Negative Parallelism）

禁止"不仅……而且""不只是……更是""既……又……还"的连续堆砌。

**错误：** 它不仅是工具，更是方法；不只是方法，更是理念
**正确：** 这个工具改变了工作方式

### 2.3 三元组滥用（Rule of Three）

AI喜欢把事物凑成三个来显得全面。禁止强行凑三。两项优于三项。

**错误：** 提升了效率、降低了成本、优化了体验
**正确：** 如果只有两个就说两个

### 2.4 虚假范围（False Range）

禁止"从X到Y"句式，除非X和Y确实在同一条有意义的尺度上。

**错误：** 从初创企业到世界500强，从北京到纽约
**正确：** 只说相关的那个范围

### 2.5 伴随状语堆砌（对应英文 -ing superficial analysis）

禁止在句尾堆砌"……着……"的伴随状语来制造假深度。

**错误：** 这一举措体现了公司对合规的重视，彰显了行业引领者的担当，预示着未来发展的方向
**正确：** 这项举措把合规要求落到了流程里

### 2.6 同义词循环（Elegant Variation）

AI因重复惩罚机制会用不同词指代同一事物。人类写作允许重复。

**错误：** 该平台……这一系统……此项工具……该方案……
**正确：** 平台……平台……平台……（重复没关系，清晰优先）

### 2.7 过度修饰与限定（Excessive Hedging）

禁止层层叠叠的限定词。

**错误：** 在某种程度上，这可能或许大概会对部分企业的某些环节产生一定影响
**正确：** 这会影响企业的采购环节

### 2.8 填充短语（Filler Phrases）

| 禁止 | 改用 |
|------|------|
| 为了实现这一目标 | 为了 |
| 由于……的原因 | 因为 |
| 在目前这个时间节点 | 现在 |
| 在……的情况下 | 如果 |
| 该系统具有处理……的能力 | 该系统能处理 |
| 需要指出的是，数据显示 | 数据显示 |
| 就……而言 | （删除，直接说） |

### 2.9 被动语态隐藏主体

AI常隐藏动作主体或完全省略主语。

**错误：** 配置文件不需要。结果会自动保存。
**正确：** 你不需要配置文件。系统会自动保存结果。

### 2.10 连字符复合词滥用

英文中AI过度使用 hyphenated pair（data-driven, cross-functional, real-time等）。中文语境中对应"数据驱动的""跨职能的"等过度使用。保留定语位置的，删除谓语位置的。

### 2.11 尾随否定片段

禁止在句尾附加否定片段替代完整从句。

**错误：** 选项来自所选项目，无需猜测。
**正确：** 选项来自所选项目，用户不需要猜测。

## 三、结构维度

### 3.1 开头直接用小标题

**错误：** 首段就是"## 什么是XX"
**正确：** 开头必须是一段完整的引导性段落，自然引入主题。小标题最早在第二段之后出现。

### 3.2 每段都以主题句开头

AI倾向于每段第一句就是概括。人类写作中，段落开头可以是：一个具体场景、一组数据、一个反问、一个转折、一个细节。

### 3.3 段落长度过于均匀

AI生成的段落往往字数相近、结构平行。人类写作段落有长有短，有的段落只有一句话。

### 3.4 机械的排比结构

**错误：** "它不仅是工具，更是方法；不仅是方法，更是理念；不仅是理念，更是行动。"

### 3.5 "是什么-为什么-怎么做"三段论

人类写作的行文逻辑更多变：可以从一个案例切入，从一个问题出发，从一个对比展开。

### 3.6 结尾总结升华

AI几乎总是在结尾做"总结+展望"。禁止。人类文章可以：戛然而止、以一个具体建议结尾、以一个问题收尾、以一个细节画面收尾。

### 3.7 "挑战与展望"式公式段落

禁止"尽管……面临挑战，但……""虽然……存在不足，但前景依然广阔"这类公式化转折段落。

**错误：** 尽管数字化转型面临诸多挑战，但随着技术不断成熟，未来前景可期
**正确：** 如果有挑战就具体说是什么挑战，有什么应对；没有就不写

### 3.8 内联标题列表（Inline-Header Vertical Lists）

禁止用加粗标题+冒号的列表项来组织段落。

**错误：**
- **用户体验：** 用户体验得到显著提升……
- **性能优化：** 性能通过算法优化得到增强……

**正确：** 用正常段落叙述

### 3.9 过度使用加粗

禁止机械地加粗关键词。一篇正文中加粗不超过3-5处。

### 3.10 破折号滥用

AI使用破折号（——）的频率远高于人类。硬性约束：最终版本不含破折号（—或–）。能用逗号、句号、括号替代的就替代。

### 3.11 emoji装饰

禁止在正文标题、小标题、列表项中使用emoji。正式内容中不出现任何emoji。

### 3.12 标题后接重复阐述段落

AI常在小标题后加一句泛泛的复述再进入正题。禁止。标题后直接进入实质内容。

### 3.13 变更叙事式写作

文档不应写成"这个函数被添加来替代之前的方法"这种描述变更的口吻，除非是changelog。应描述事物本身的样子。

## 四、灵魂维度

避免AI模式只是底线。无菌、没有声音的写作和机器生成的内容一样明显。好的写作背后有一个真实的人。

### 4.1 要有观点

不只是陈述事实，要对事实有反应。有明确立场，不骑墙。可以承认局限和困难，可以提出质疑。

**无灵魂：** 数字化有一定优势，同时也面临一些挑战。
**有灵魂：** 数字化喊了三年，真正用起来的没几家。问题不在技术，在流程。

### 4.2 节奏变化

短句制造节奏感。然后来一个长句，把信息密度提上去。再来一个短句收尾。连续三个句子长度相同必须打断。

### 4.3 承认复杂性

真实的人有混合感受。"这事做得不错，但成本确实高"比"这事做得不错"更真实。

### 4.4 具体而非空泛

不是"这很令人担忧"，而是"3个月跑了20家企业，只有2家真正用起来了"。

### 4.5 允许不完美

完美结构感觉算法化。跑题一下、插入一个细节、留一个未完全展开的想法——这些都是人类的痕迹。

## 五、沟通痕迹维度

### 5.1 对话式残留（禁止）

- 希望对您有帮助
- 当然/好的
- 接下来我们来看
- 让我们一起了解
- 下面为您介绍
- 以上就是

### 5.2 知识截止声明（禁止）

- 截至目前
- 根据已有信息
- 虽然具体细节有限
- 基于现有资料

### 5.3 谄媚语气（禁止）

- 好问题
- 您说得很对
- 这是一个非常关键/重要/好的问题
- 确实如此

### 5.4 通用积极结论（禁止）

**错误：** 公司的未来看起来光明。激动人心的时代即将到来，他们继续追求卓越的旅程。这代表了向正确方向迈出的重要一步。
**正确：** 公司计划明年再开设两个地点。

## 六、检测指导

### 不要误报的项（false positives）

以下单独出现不是AI痕迹的可靠指标：
- 完美的语法和一致的风格（许多专业作者或经过编辑的文章）
- 混合正式和随意的语域
- "平淡"或"机械"的文字（AI有具体的特征，一般性的干涩不等于AI）
- 正式或学术词汇
- 评论中的信件式开头或结尾
- 孤立的常见过渡词
- 弯引号（macOS、Word等默认自动弯引）
- 破折号单独出现
- 未引用的声明
- 正确、复杂的格式

**关键原则**：寻找AI特征的**集群**，而非孤立特征。一个破折号不算什么；破折号+三元组+充满活力的织锦+"结论"部分就是AI的铁证。

### 人类写作的迹象（保留这些）

- 具体、不寻常、难以伪造的细节
- 混合感受和未解决的张力
- 有年代感的引用（俚语、梗、圈内笑话）
- 可解释的第一人称编辑选择
- 句子长度的变化
- 真正的旁白、插入语或自我纠正

## 七、质量评分体系

对改写后的文本进行 1-10 分评估（总分 50）：

| 维度 | 评估标准 |
|------|----------|
| **直接性** | 直接陈述事实还是绕圈宣告？10分：直截了当；1分：充满铺垫 |
| **节奏** | 句子长度是否变化？10分：长短交错；1分：机械重复 |
| **信任度** | 是否尊重读者智慧？10分：简洁明了；1分：过度解释 |
| **真实性** | 听起来像真人说话吗？10分：自然流畅；1分：机械生硬 |
| **精炼度** | 还有可删减的内容吗？10分：无冗余；1分：大量废话 |

**标准：**
- 45-50分：优秀，已去除AI痕迹
- 35-44分：良好，仍有改进空间
- 低于35分：需要重新修订

## 八、自检清单

每篇内容交付前，逐项检查：

### 词汇检查
- [ ] 是否包含第一节中任何禁用词汇？
- [ ] 是否有意义膨胀词（见证了/标志着/彰显了等）？
- [ ] 是否有推销式语言（坐拥/备受瞩目/深受青睐等）？
- [ ] 是否有模糊归因（业内报告显示/观察人士指出等，无具体来源）？
- [ ] 是否有填充短语（为了实现/在目前这个时间节点等）？
- [ ] 是否有物化客户词汇（实践/观察/试验/测试/试错/样本/标杆/示范/跑通等）？
- [ ] 是否有伪深度短语（真正的问题是/从根本上说/更深层的问题等）？
- [ ] 是否有预告式短语（让我们深入看看/这是你需要知道的等）？

### 句式检查
- [ ] 是否有系动词回避（扮演着……角色/发挥着……作用）？
- [ ] 是否有否定并列（不仅……更是/不只是……更是）？
- [ ] 是否有强行凑三元组？
- [ ] 是否有虚假范围（从X到Y）？
- [ ] 是否有同义词循环（用不同词指代同一事物）？
- [ ] 是否有过度限定（可能或许大概）？
- [ ] 是否有被动语态隐藏主体？
- [ ] 是否有尾随否定片段？

### 结构检查
- [ ] 首段是否为完整段落（非小标题）？
- [ ] 是否有"首先/其次/最后"等结构性标记？
- [ ] 段落长度是否有变化（非全部均匀）？
- [ ] 结尾是否在"总结升华"？
- [ ] 是否有"挑战与展望"公式段落？
- [ ] 是否有内联标题列表（加粗标题+冒号的列表项）？
- [ ] 加粗是否过度（超过5处）？
- [ ] 破折号是否过多？（最终版本应不含破折号）
- [ ] 是否有emoji？
- [ ] 标题后是否有重复阐述段落？
- [ ] 是否有变更叙事式写作？

### 灵魂检查
- [ ] 内容是否有观点和立场（不骑墙）？
- [ ] 句式是否有节奏变化（长短交替）？
- [ ] 是否承认了复杂性和局限？
- [ ] 是否用了具体数据和案例而非空泛描述？
- [ ] 是否有对话式残留（希望对您有帮助/下面为您介绍等）？
- [ ] 是否有谄媚语气（好问题/您说得很对等）？
- [ ] 是否有知识截止声明？
- [ ] 是否有通用积极结论？
