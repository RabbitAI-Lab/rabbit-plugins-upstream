# PRODUCT_SELECTION() 市场选品与机会评估

- Skill：`zayn-product-selection`
- 用途：结合市场证据和我方能力评估候选产品。
- 不适用：热门榜单、无资金和供应约束的泛推荐。
- 输入：市场、客户、业务、供应、资金、库存、风险、时间。
- 最低条件：市场信号、我方能力、资金与风险约束可比较。
- 流程：候选集→需求→能力→经济性→风险→验证优先级。
- 输出：产品比较表、分类、证据、缺口、验证动作和停止条件。
- 证据：共享规则；仅在明确要求且数据充分时评分。
- 协作：market/competitor/profile 上游，opportunity/plan 下游。
- 示例：比较三类服务器 SSD 是否适合德国市场小范围试销。
- 版本：v1.0.0
