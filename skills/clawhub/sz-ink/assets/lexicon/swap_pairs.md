# swap_pairs.md — L1 口语↔书面替换对表（84组）

> 用法：S4 改写的词级弹药——AI 腔词 → 中性/口语词。与 cliche 词表（查病）配套，本表是换药。
> 来源规范：编对依据黄廖版《现代汉语》词汇章原则（同义词的语体色彩/语义轻重/搭配差别，ima 库：《现代汉语》知识点大全、词汇章PPT、修辞章"词语的锤炼"）+ 课堂转写实词频观察。**ima 检索摘要未提供成规模词对原文，本表词对为本 skill 按上述原则编写[新拟·黄廖原则]**——用前过语体门卫（公文体替换来源是政务规范用词，不是口语）。
> 格式：`AI常用/书面 → 改写方向`，括号内是语体限制。

## 使用规则
1. 改写后过体检脚本回测——替换对是弹药不是自动枪，LLM 按语境选；
2. 公文体：本表仅第一组（名词化还原部分保留规范表述）+ 黑话组适用，二/四组多不适用（语体档案 official_doc 优先）；
3. 同一替换方向在同篇别用超过 2 次（替换对本身用成套路=新的机械感）；
4. 新增词对必须带语体标注和原则出处，改表后重跑体检脚本。
