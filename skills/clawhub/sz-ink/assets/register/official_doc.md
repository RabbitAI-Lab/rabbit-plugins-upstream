# 语体档案 · 公文体（official_doc）

> L4 资产。**主要资产继承自 sz-writer-enjoy**（rules/deai_blacklist.md + audit_rules.md R1~R7），
> 本文件是其语体化封装 + sz-ink 接口适配。单源声明：词表内容以 sz-writer-enjoy 为源，此处不抄正文，改写动作按本档案路由。

## 1. 文体特征指纹

- 场景：通知、请示、报告、方案、纪要；
- 读者关系：机关行文，对象感、行文方向（上行/下行/平行）决定称谓与语气；
- 句式：规整是**语体要求**，不是 AI 味——句长 CV、句式混用率在公文体**降权或不启用**；
- "AI 味"在公文中的表现：黑话混入（第一层硬禁词）、词频轰炸、空转段、万能结尾、排比无事实承接。

## 2. 与通用九指标的关系（重要：语体降权）

| 指标 | 公文体处理 |
|---|---|
| 1 句长节奏 CV | **降权为参考**——公文句式本就规整，不作为干预触发器 |
| 2 短气群 | **禁用**——公文无短气群要求 |
| 3 套话密度 | **主指标**，词表 = cliche_common + cliche_official_doc（三层词表映射） |
| 4 句式混用 | **降权**——陈述句主导是语体要求 |
| 5 语气温度 | **禁用**——公文语气词判据走白名单机制（语气对错≠语气浓度） |
| 6 留白度 | **禁用**——公文不留白 |
| 7 词汇轮换 | 保留——同一概念公文也讲指称规范 |
| 8 段落呼吸 | 降权——公文段落功能模块化 |
| 9 结构规整度 | **改造启用**：检测"一是二是三是"同构连用 ≥3 段、每段总分总——这些在公文里也是 AI 味信号（R4/R5 对应） |

**放行规则（公文体专用）**：指标 3 为主判 + 指标 7/9 辅判；其余指标只报告不判分。

## 3. 禁区与白名单（全文以 sz-writer-enjoy 为源）

- 第一层硬禁：网感黑话（赋能/抓手/闭环/颗粒度…）正式公文出现即阻断；
- 第二层监控：此外/同时（句首）/值得注意的是…同词全文 >2 次警告；
- 第三层空转：万能结尾、空转开头、"一是二是三是"≥3 段同构；
- **白名单（不误伤）**：国标套语（妥否，请批示/特此通知/此复）、政务常规动词（进一步/切实/加强/推动/落实…仅查词频轰炸）、政策原文引用；
- **真数据铁律**：数字/文号/日期/人名职务——只许改表达，绝不改/删数据本体。

## 4. 改写动作特点

- 替换来源：政务规范用词表（不向口语降级——**公文体去AI味≠口语化**）；
- 空转段：删除或改写为有信息内容（有数据/有具体对象/有实际措施）；
- 结尾：替换为与内容绑定的事实性收束（依据素材回链）。
