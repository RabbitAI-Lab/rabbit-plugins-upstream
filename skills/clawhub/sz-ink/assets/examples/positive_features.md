# positive_features.md — L3 正向特征例（"人味"特征-例证对）

> 用法：与 paragraph_pairs.md（改前→改后）互补——本库是"人写原文特征→机制→应用点"的正向参照，供 S8 风格判断和风格档案（L6）提取用。
> 来源规范：特征描述均出自 ima 库课件；例证若课件未给原文引文，则标[转述]并写机制，不伪造引文。

## 一、汪曾祺系（ima：《汪曾祺小说语言与文体分析_课堂笔记.pdf》《散文化风格解析.docx》《特点解析.docx》）

### 特征1 简单句的排列组合产生表现力
- 课件：**"即使句子简单直接，通过精心的排列组合，也能产生富有表现力的叙述效果"**。
- 机制：表现力在语序不在词藻——AI 靠修饰词堆表现力，真靠短句排布。
- 应用点：改写时删修饰词后重排句序，别急着补形容词。

### 特征2 文白相间
- 课件：**"追求简洁性与文白相间的美感"**。
- 机制：白话铺陈里点一个文言词（"岁寒，然后知松柏"式），比全程白话有骨。
- 应用点：节奏长句里允许保留一个雅词，但每段至多一个。

### 特征3 少用修饰词
- 课件：**"少用修饰词而多反应"**。
- 机制：写反应不写形容——不写"他很紧张"，写"他把手里的烟捏灭了"。
- 应用点：形容词→动作/反应替换（配处方卡05/08）。

### 特征4 过滤与留白（"平淡"的来源）
- 课件：**"过滤掉故事中的负面元素，留给读者美好而回味无穷的阅读体验"**。
- 机制：不写满，删掉评判，只留事实——回味空间来自读者。
- 应用点：结尾收在事实上（配卡28/30）。

### 特征5 情节弱化、结构松散
- 课件：**"结构松散，情节因素较弱，常先写环境背景再出现人物"**。
- 机制：不追求叙事效率，允许"没用"的环境笔——AI 是效率怪兽，每句都"有用"。
- 应用点：结构干预时允许一处无功能的环境/闲笔（配卡34）。

## 二、杨绛系（ima：《我们仨》艺术特色笔记）

### 特征6 朴素语言
- 课件：**"朴素的语言风格"**。
- 机制：大悲大喜用小词说——"梦见他回来了"比"我陷入了深深的思念"重十倍。
- 应用点：情感浓度高时反而降词格（配卡07/08）。

### 特征7 哀而不伤（克制抒情）
- 课件：**"哀而不伤的抒情"**。
- 机制：情绪只给七分，留三分读者自己疼。
- 应用点：删情绪强化词（"无比悲痛"→删，让事实说话）。

## 三、老舍系（ima：《老舍.doc》）

### 特征8 方言口语入文
- 课件：**"老舍小说的语言在北京口语基础上"**。
- 机制：地域/人群口语特征是身份指纹——AI 文本无籍贯。
- 应用点：口语体改写允许北京话/北方话层级的口语词，不限于普通话中性词。

## 四、课堂转写系（85篇实测）

### 特征9 节奏大幅参差
- 实测：**rhythm_cv 中位 0.726（AI 常见 0.3-0.4）**。
- 机制：真人一句话里长短气群混着来，讲到兴头上气群变长，收尾砸短句。
- 应用点：句长 CV 是最强单一信号（红线指标）。

### 特征10 语气词条件性出现
- 实测：**语气温度中位 0 但 P75=3.26**——真人不是每句都"呗/嘛"，情绪到了才用。
- 机制：语气词是情绪标记不是装饰。
- 应用点：语气词补在情绪节点，禁均匀撒（防"演人"）。

### 特征11 自我修正与跳步
- 实测：转写里大量"哦不对，我重说""这个不展开"。
- 机制：真人允许思维痕迹留在文本里，AI 永远圆滑。
- 应用点：允许一处自我修正/跳步（配卡32/34）。

### 特征12 重复即强调（教学法重复）
- 实测：真人讲解同义反复（"很简单，真很简单"）。
- 机制：有意的重复是强调，无意识的重复（一词到底）是病——两者判据不同（前者紧邻、后者全文分布）。
- 应用点：与卡09的区分——紧邻重复可保留。

## 使用规则
1. 本库是正向参照系：S8 阶段"像不像人"的终审依据之一；
2. 特征不许堆叠使用（全文文白相间+方言+跳步=另一种表演）——单篇取 2-3 个特征方向即可；
3. 例证一律不伪造引文：课件没给原文的，写机制不写"原文"。
