## 编卡规则（写卡时必读）
1. 症状用具体语言现象描述，不写"显得AI"这类主观话；
2. 判据必须可判定（正则/计数/上下文条件），且注明"单处不算，成簇才判"或"单处即判"；
3. 动作写具体步骤（删/换/拆/重排），一条卡一个动作主题；
4. 对照例必须含"改前"和"改后"，改后须比改前短或等长（去AI味通常做减法）；
5. 禁区：什么情况不许用此卡（如公文体白名单词、法定套语）；
6. 出处：市面来源或 ima 库课件名。

**体检总则（v0.4.2 定稿）：判据即体检项，全量不抽样；文体只是先验。**

输入是任意文体乃至片段，AI 可能随机命中任何病灶——45 张卡的判据在 S3 **逐条全量过**，
下表只回答"命中了先治谁"（S4 分级排序用）和"卡45检索开不开"（成本分级用），不回答"查不查"：

| 卡 | 判据特征（可观测） | 高危先验（只提优先级/检索级别） |
|---|---|---|
| 41 | 零第一人称体验句 且 零偶发细节、按卖点组织 | 种草/探店/推广文 |
| 42 | S1 职能序列与语体标准模板完全一致 | 营销文案/官方介绍 |
| 43 | 缺点全落"场景/价格/偏好"安全位 | 种草/测评文 |
| 44 | 列举位 ≥3 条同句法骨架 | 任何含列举的文体 |
| 45 | 细节密集且可公开检索同款 | 种草/探店/攻略 |

- **豁免才是文体键**：法定文本/电商详情页等"用途不需要"的白名单豁免，在各卡禁区节；
- **卡45 是唯一分级项**：细节密集 或 高危先验命中 → 必检索；其余抽查关键细节位（检索成本高，不默认全量）；
- **片段模式**（<300字或<4句）：篇层/结构卡（25–40）停用，41–45 照常全量体检（列举/缺点/视角特征在片段里同样可观测）；
- 治疗分级在 S4：按偏差取 ≤3 处开刀，其余命中进"观察清单"——体检全量，治疗有配额。
**教训单源**：语言层全绿 ≠ 像人。视角层（有没有人在场）是第五层病灶。
