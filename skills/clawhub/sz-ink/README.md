# 研墨 sz-ink — 中文去 AI 味改写器

> 体检看整体，开刀只定点，锚点不可侵犯，达标就收手。

**为什么叫"研墨"**：AI 吐的字是墨块，得磨出人味才能落笔。"研"字双关——这个技能的鉴别力全部来自**汉语言文学研究**（语体学/词汇学/修辞学/语篇学），不是一张禁词表。

sz-ink 是一个面向中文文本的**事后改写器**：输入一段"AI 腔"明显的文本，输出改写后的文本 + 指标报告 + 改动日志 + 漂移报告。它不做生成，不做检测器绕过承诺，验收以"读起来像人"为准。

## 与市面做法的差别

市面上去 AI 味的方案大多走三条老路：同义词替换拉困惑度、一张禁词表让模型"别说这几个词"、或以骗过检测器为目标。共同的缺陷是**只做减法不重构、没有语言学根据、换一个模型词表就失效**。

sz-ink 的鉴别力来自汉语本身的知识体系——语体学、词汇学、修辞学、语篇研究中的成熟结论被逐条转化为可判定的规则：

| 知识来源 | 转化成的鉴别能力 |
|---|---|
| 语体学：语体是语境的产物，形式与场合错配即失当 | **语体档案 + 条件阈值**。不存在全局阈值：公文体去 AI 味 ≠ 口语化，讲解体有术语豁免与语气词"允许不强制" |
| 词汇学：书面语/口语对立、同义词的语体色彩差别 | **84 组带语体标注的替换对**——换词必须换对语体，而不是机械同义替换产出病句 |
| 修辞学：句式选择（整句/散句）、辞格的运用条件 | **排比失控、条目同壳、对仗收尾**的判据——AI 的"整"与人的"散"是规则差异，不是审美偏好 |
| 语法：句类（陈述/疑问/感叹）、语气词的情态义 | **语气温度、留白度指标**——啊/吧/呢/嘛/呗各有明确情态义，人味指纹有语义依据 |
| 语篇与信息结构 | **空转段"删后无损"判定、结构规整度、视角层卡**——篇层病灶删词治不好，病在信息组织 |

由此能区分三种形态不同的 AI 味：**黑话型**（赋能/闭环/综上所述）、**文案腔型**（诗意套壳+排比失控+零事实锚点）、**洗稿型**（细节与公开素材同款、列举顺序保真）。词表法对后两种是瞎的。

## 工作方式（S0–S8 状态机）

```
S0 语体判定 → S1 建档 → S2 体检 → S3 达标判定
                     未达标 ↓              ↓ 达标
        S4 定点干预(≤3处/轮) → S5 回测 → S6 还原审核 → S7 回滚(如有漂移)
                                              ↓
                                            S8 交付
```

- **体检**：九项统计指标（句长节奏、套话密度、语气温度、留白度、句类熵、结构规整度等），Python 标准库实现，零依赖；`--self-test` 自带回归验证；
- **判定**：红线不过必须干预；总分 ≥6/9 即放行——**不追求全绿，全绿是过度干预的信号**；设"过度优化"上限，像人过了头就是"演人"；
- **干预**：每轮只动偏差最大的 ≤3 处，按处方卡（症状→判据→动作→对照例）执行；配额 ≤5 处/篇，超限说明该重新生成而非改写；
- **语义保真**：动刀前建《文章档案》（结构图+语义锚点+论点清单），锚点零改动；改后独立审核三查，漂移即回滚；
- **诚实边界**：改表达治不了"缺事实"。缺体验细节的稿子只能交付《补事实清单》由作者补——真实不是能生成的属性，只能由作者供给。

## 目录结构

```
sz-ink/
├── SKILL.md              # 入口：流程状态机 + 路由表 + 硬约束
├── rules/
│   ├── metrics.yaml      # 九项指标定义与三语体阈值（单一事实源）
│   └── boundaries.md     # 锚点边界 / 体验位与编造边界 / 白名单
├── tools/
│   ├── check_metrics.py  # 体检脚本（九项指标 + --self-test 回归）
│   ├── build_profile.py  # 风格档案提取（"像谁"的目标层）
│   └── audit_semantic.py # 语义锚点机械核查（数字/专名/否定词守恒）
├── assets/
│   ├── lexicon/          # 套话/语气/留白词表 + 84 组替换对
│   ├── prescription/     # 45 张处方卡（词/句/篇/结构/视角五层）
│   ├── examples/         # 63 组改前改后对照例 + "人味"正向特征
│   ├── register/         # 三语体档案（新媒体/公文/讲解）
│   └── structure/        # 7 个人写结构骨架样板
└── manifest/asset_manifest.json
```

## 快速上手

```bash
# 体检一段文本（先判语体再选阈值组）
python tools/check_metrics.py 文本.txt --register colloquial_media

# 回归验证
python tools/check_metrics.py --self-test
```

改写由智能体按 `SKILL.md` 的 S0–S8 流程执行，人读最终判定，指标只是哨兵。

## 定位声明

sz-ink 管"去腔"，不管"伪造真实"：它能让统计指纹与文风落进真人区间，但无法替作者过一遍人生——私人细节、真实价格、当天的意外，只能由作者补。
