# 中国航空券予約

## 説明

中国旅行のためのオールインワン旅行コンパニオン。このスキルは外国人旅行者向けに5つの強力な機能を提供します：

1. **フライト検索** — 中国への/中国発/中国内のフライトをリアルタイムの料金とスケジュールで検索
2. **ホテル検索** — リアルタイムの料金、評価、予約リンクでホテルを探す
3. **観光地チケット** — チケット料金と営業時間で観光スポットを発見
4. **旅行プラン** — パーソナライズされた複数日の旅行プランを生成
5. **旅行アドバイス** — ビザ、支払い、交通、食事などに関する回答を取得

## データフローとプライバシー

ユーザーのクエリは安全なプロキシサーバー（SCF）に送信され、認証トークンが注入されてTripGenie APIに転送されます。プロキシはアフィリエイトリンクの生成を自動的に処理します。ユーザーの個人データは保存または記録されません。すべての通信はHTTPSで暗号化されています。

## 使用する場面

- 自国から中国の都市へのフライトを探す
- 中国の都市間の国内線を検索
- 日付、キャビンクラス、旅行タイプでフライトオプションを比較

キーワード：中国 フライト、北京 飛行機、上海 フライト、中国 国内線、中国 航空券、ビジネスクラス、エコノミー

## 実行

### ステップ 1：ユーザーのリクエストからパラメータを抽出

| パラメータ | 説明 | 例 |
|-----------|------|-----|
| origin | 出発都市/空港（必須） | "Tokyo" |
| destination | 到着都市/空港（必須） | "Beijing" |
| date | 旅行日 YYYY-MM-DD（必須） | "2026-08-15" |
| trip_type | "one way"または"round trip"（任意） | "round trip" |
| cabin | キャビンクラス（任意、デフォルト：エコノミー） | "business" |

### ステップ 2：スクリプトを実行

```bash
python scripts/china_travel.py flight "<origin>" "<destination>" "<date>" "[trip_type]" "[cabin]" --locale=ja
```

**重要：** 常に `--locale=ja` パラメータを含めて、日本語での結果を取得してください。

### ステップ 3：結果を表示

API は構造化された Markdown で航空会社名、フライト番号、出発/到着時刻、料金、予約リンクを返します。内容を直接ユーザーに表示します。

## 例

**ユーザー：** "8月15日にロンドンから北京へのフライトを探して"
```bash
python scripts/china_travel.py flight "London" "Beijing" "2026-08-15" --locale=ja
```

**ユーザー：** "ニューヨークから上海への往復ビジネスクラス"
```bash
python scripts/china_travel.py flight "New York" "Shanghai" "2026-09-01" "round trip" "business" --locale=ja
```

## その他の利用可能な機能

このスキルは以下もサポート：
- `hotel` — 中国のホテルを検索して予約
- `attraction` — 観光スポットとチケット料金を検索
- `itinerary` — 複数日の旅行プランを生成
- `tips` — 旅行アドバイス、ビザ、支払い、交通のヒント

## 注意

- 都市名と空港コードの両方がサポートされています
- 予約リンクは Trip.com（国際版）に直接遷移します
