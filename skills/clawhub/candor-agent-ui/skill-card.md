## Description:

Provides practical design guidance for agent interfaces, including tool calls, approvals, run status, progress, AI disclosure, accessibility, and review checklists.

This skill is ready for commercial/non-commercial use.

## Publisher:

[arunk3](https://clawhub.ai/user/arunk3)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and product teams use this skill when designing or reviewing interfaces where an AI agent can communicate, request approval, use tools, or change something. It provides guidance and a checklist for making the agent's actions, state, and impact clear to people.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Agent screens can present an unconfirmed status or misleading account of an action if guidance is applied without checking the live behavior and underlying evidence.

Mitigation: Run the review checklist against the screen and keep status, timing, counts, and outcomes tied to what the service actually reports.
