# 4 种产物形态详细说明

> 本文档详细说明 one-paper-company 技能的 4 种产物形态。SKILL.md 仅保留简表。

## 形态 1：周期复盘（重型，默认，v1.0 已实现）

**输入**：公司名 + 季度
**产物**：`{公司简称}_周期复盘_{季度}_自包含.html`（2-3 MB）
**结构**：10 步滚动联动（scrollytelling）+ 15 类数据可视化

| Step | 内容 | vp 联动面板 |
|---|---|---|
| 1 | 财务季图（营收/净利/毛利率）| vp-fin |
| 2 | 分部结构（5 分部堆叠柱）| vp-seg |
| 3 | 行业格局墙（2 波 × 10-15 家）| vp-wall |
| 4 | K 线全周期（含稀疏史前点）| vp-kline |
| 5 | K 线 focus 模式（近 6 年）| vp-kline |
| 6 | 高频需求（capex/dcrev/租金）| vp-hf |
| 7 | 库存天数（领先毛利率）| vp-inv |
| 8 | 类比打分卡 + 负对照 | vp-score |
| 9 | 子板块时钟（8 扇区 × 4 子板块）| vp-clock |
| 10 | 监测信号卡（8 信号 × 阈值/证伪）| vp-signal |

**视觉规范**：暖米中性色 + 公司品牌色（仅替换 `--green`/`--green-d`）+ ECharts 5.5.0 内联 + 像素风品牌动画

## 形态 2：速览卡（轻型，待实现 v2.1）

**输入**：公司名 + 季度
**产物**：`{公司简称}_速览卡_{季度}_自包含.html`（200-500 KB）
**结构**：单页 KPI 网格 + 关键事件时间线 + 趋势小图

```
┌─────────────────────────────────────────┐
│  公司 Logo + 名称 + 季度 + 品牌色条       │
├─────────────────────────────────────────┤
│  4 大 KPI（营收/净利/毛利率/库存天数）    │
├─────────────────────────────────────────┤
│  趋势小图：3 个月 K 线 + 营收柱状 + 估值  │
├─────────────────────────────────────────┤
│  关键事件时间线（最近 6 个事件）          │
├─────────────────────────────────────────┤
│  风险信号（3 个最关键）+ 信源             │
└─────────────────────────────────────────┘
```

## 形态 3：估值地图（中型，待实现 v2.2）

**输入**：公司名 + 季度
**产物**：`{公司简称}_估值地图_{季度}_自包含.html`（500 KB-1 MB）
**结构**：估值历史 + 同业对比 + DCF 散点

```
┌─────────────────────────────────────────┐
│  Hero: 公司当前估值 + 历史分位数           │
├─────────────────────────────────────────┤
│  Section 1: PE/PB/PS 历史走势（10 年）   │
├─────────────────────────────────────────┤
│  Section 2: 同业对比散点图（PE vs 增速）  │
├─────────────────────────────────────────┤
│  Section 3: DCF 敏感性散点                │
├─────────────────────────────────────────┤
│  Section 4: 估值结论 + 风险点             │
└─────────────────────────────────────────┘
```

├─────────────────────────────────────────┤

├─────────────────────────────────────────┤
│  Section 3: 份额变化堆叠图                │
├─────────────────────────────────────────┤
│  Section 4: 进入/退出者列表 + 结局分布    │
