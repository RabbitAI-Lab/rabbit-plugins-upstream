# 老孟中文编程（ZHC）

ZHC 是一门**全中文语法的编程语言**：关键字、内置函数、类型名、错误提示全部是中文，源码扩展名 `.zc`，编译器产出 x86-64 原生程序。操作符（`+ - * / % == < > 且 或 非`）、函数调用括号与字符串引号沿用通用符号，其余全部中文。

## 何时使用

- 用户要求"用中文编程""写个中文代码""老孟中文编程""ZHC"。
- 需要编译/运行 `.zc` 源码，或解释一段中文源码的语义。
- 需要中文报错定位（E 码）与修复建议。
- 需要把程序内表格数据导出成 Excel / Word / HTML / CSV。
- 需要核对关键字、内置函数、类型名与契约版本。

不适用：需要 Python 生态第三方库的重度任务，直接用 Python。

## 快速上手

```zc
定义 合计 为 整数 0
循环 序 从 1 到 100 步 1
    设 合计 为 合计 + 序
结束
输出 "1 到 100 之和是 ", 合计
```

编译执行：

```bash
python -X utf8 scripts/zhc.py 示例.zc --run
```

只做词法语法检查（JSON 诊断，供编辑器使用）：

```bash
python -X utf8 scripts/zhc.py 示例.zc --诊断
```

打印类型与内置函数手册：

```bash
python -X utf8 scripts/zhc.py --api
```

## 语言速览（照此写，勿自创）

| 概念 | 写法 | 要点 |

| 赋值 | `设 合计 为 合计 + 序` | 已有变量用 `设`，禁止重复 `定义` |

| 前测循环 | `当 条件 则 … 结束` | 语言**无 break / continue**，靠条件或标志位退出 |

| 函数 | `函数 平方(甲:整数) 返回 整数 … 结束` | 参数必须写 `名:类型`，多个用逗号分隔；无返回值省略 `返回 类型` |

| 空值 | `空` | 指针/引用空值 |

## 表与记录

```zc
定义 t 为 表
造列(t, "名称", 文本)
造列(t, "数量", 整数)
定义 r 为 记录
置元素(r, "名称", "螺丝")
置元素(r, "数量", 1200)
追加(t, r)
输出 转JSON(t)
```

## Office 导出（OFFICE-WEB 2.4）

桥按「对象 + 动作 + JSON 参数」三段调用，参数路径字段名为 `路径`，格式由桥按动作决定：

```zc
定义 t 为 表
造列(t, "名称", 文本)
造列(t, "数量", 整数)
定义 r 为 记录
置元素(r, "名称", "螺丝")
置元素(r, "数量", 1200)
追加(t, r)

定义 p 为 记录
置元素(p, "表", t)
置元素(p, "路径", "库存.xlsx")
定义 报 为 文本 桥调用("表", "导出xlsx", 转JSON(p))
输出 报
```

动作清单：`导出csv` `导出xlsx` `导出docx` `导出html`。导出 HTML 页面用 `桥调用("页面", "导出html", …)`，可附 `标题` 字段。

运行前置：桥脚本必须位于 `scripts/桥/zhc_bridge.py`（编译器按「与 zhc.py 同级的 `桥` 目录」查找，路径编译期烧入产物）。若位移了桥目录，用环境变量覆盖：

```bash
set ZHC_BRIDGE_HOME=<桥所在目录>
set ZHC_PY=<python.exe 绝对路径>
```

`桥可用()` 返回 `真` 表示桥已起好；返回 `假` 时导出会**自动降级为 CSV**（报文中 `降级: true` 并给 `B001`），此时应修好桥再重跑以拿到 xlsx/docx。写盘失败返回 `-1` 并报 `B005`；桥应答超 30 秒记 `B006`。

## 错误处理

错误一律形如 `[Exxx] 中文说明`。码位 38 个，区间：

| 区间 | 类别 |
|---|---|
| E001–E014 | 词法与字符（非法字符、未闭合引号、数字格式） |
| E201–E214 | 语法结构（缺 `则`／`结束`、语句不完整） |
| E301–E313 | 名称与类型（未定义引用、类型不匹配、重复定义） |
| E401 / E901 | 运行期与内部（除零、越界、编译内部异常） |
| B0xx | 桥协议与导出 |

逐条成因与修法见 `references/错误码表_E_1.0.md`。对外答复全程中文，不得把错误码翻成英文。

## 智能体工作流程

1. **判类型**：新建 / 修错 / 解释 / 导出，四选一。
2. **查契约**：要精确语义读 `references/契约_1.0.md`；不确定的关键字一律先查表，禁止臆造。
3. **小步验证**：改一次跑一次 `--诊断`，再 `--run`；只看首条错误，修完复跑。
4. **导出前自检**：`桥可用()` → 导出 → 读回报文确认。
5. **交付口径**：给完整可复制的 `.zc` 代码块；报错引用原文中文；不输出伪代码。

## 禁止事项

- 不得使用英文关键字（`if`/`while`/`def`）或 Python 式缩进块。
- 不得把 `当` 写成 `while` 语义之外的变体，不得自创 `结束如果` 之类不存在的收尾词——统一用 `结束`。
- 不得声称支持契约外的语法或库。
- 不得写错版本号：本技能对应语言面 `ZHC-LANG-1.0`，桥面 `OFFICE-WEB 2.4`。
