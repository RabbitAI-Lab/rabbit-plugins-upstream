## Description:

Apply ASD-STE100 Simplified Technical English to written instructions: one action per sentence, imperative mood, condition first, one name per item, short sentences, no semicolons. Use before writing or when auditing prompts, AGENTS.md, SKILL.md, READMEs, runbooks, checklists, and the technical steps of an article. For articles, enforce structure only and keep the essay voice; never flatten narrative prose. Report contradictions between rule files instead of silently choosing one.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and technical writers use this skill to write or audit agent instructions, runbooks, checklists, and procedural sections of articles. It helps make procedural text concise and consistent while preserving narrative voice and surfacing conflicts between rule files.

Mitigation: Select documents intentionally and review excerpts and proposed rewrites before approving edits.
