# ASD-STE100 Issue 9 — Condensed Rule Summary

Independent summary for practical writing and review. Rule numbers match the standard. Wording is paraphrased, not reproduced. The [Issue 9 PDF](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf) is authoritative and free to download. The 875-word dictionary is not included, by design.

## Section 1 — Words

| Rule | Summary |
|---|---|
| 1.1 | Use approved dictionary words, technical nouns, and technical verbs. |
| 1.2 | Use an approved word only as its approved part of speech. |
| 1.3 | Use an approved word only with its approved meaning. |
| 1.4 | Use only the approved forms of verbs and adjectives. |
| 1.5 | A technical noun must fit an approved technical-noun category. |
| 1.6 | A non-approved word is permitted only as a technical noun or part of one. |
| 1.7 | Do not use a technical noun as a verb. |
| 1.8 | Use technical nouns approved in your company, industry, or subject field. |
| 1.9 | Choose short, easy technical nouns. |
| 1.10 | Do not use regional, slang, or jargon words as technical nouns. |
| 1.11 | Use one technical noun for one item; never switch names. |
| 1.12 | Technical verbs must fit an approved technical-verb category. |
| 1.13 | Do not use a technical verb as a noun. |
| 1.14 | Use American spelling unless told otherwise. |

## Section 2 — Multi-word nouns

| Rule | Summary |
|---|---|
| 2.1 | A multi-word noun has at most three words. |
| 2.2 | If a technical noun is longer, write it in full first, then define a shorter form or hyphenate the parts. |

## Section 3 — Verbs

| Rule | Summary |
|---|---|
| 3.1 | Use only the verb forms given in the dictionary. |
| 3.2 | Allowed forms: infinitive, imperative, simple present, simple past, simple future, past participle as adjective. |
| 3.3 | Use the past participle only as an adjective. |
| 3.4 | Do not build complex verb constructions with auxiliary verbs. |
| 3.5 | Use the `-ing` form only as a technical noun or as a modifier inside one. |
| 3.6 | Use the active voice. Passive is allowed in descriptions only when the agent is unknown. |
| 3.7 | Describe an action with an approved verb, not with a noun or another part of speech. |

## Section 4 — Sentences

| Rule | Summary |
|---|---|
| 4.1 | Write short, clear sentences. |
| 4.2 | Do not omit words or use contractions to shorten a sentence. |
| 4.3 | Use a vertical list for complex text. |
| 4.4 | Use connecting words and phrases for related topics. |
| 4.5 | Use an article or demonstrative adjective before a noun when grammar needs it. |

## Section 5 — Procedures

| Rule | Summary |
|---|---|
| 5.1 | Maximum 20 words per sentence, including warnings and cautions. |
| 5.2 | One instruction per sentence, unless two actions occur at the same time. |
| 5.3 | Write instructions in the imperative. |
| 5.4 | Put a condition first, then a comma, then the command. |
| 5.5 | Notes give information only, never instructions. |

## Section 6 — Descriptions

| Rule | Summary |
|---|---|
| 6.1 | Give information gradually. |
| 6.2 | Use key words and phrases to show structure. |
| 6.3 | Maximum 25 words per sentence. |
| 6.4 | Use paragraphs to group related information. |
| 6.5 | One topic per paragraph. |
| 6.6 | Maximum six sentences per paragraph. |

## Section 7 — Safety instructions

| Rule | Summary |
|---|---|
| 7.1 | Use the applicable word for the risk level: warning = injury or death; caution = damage to objects. |
| 7.2 | Start with a clear command or condition. |
| 7.3 | Explain the risk or the possible result. |

## Section 8 — Punctuation and word count

| Rule | Summary |
|---|---|
| 8.1 | Use standard punctuation but not the semicolon. |
| 8.2 | Use hyphens to connect directly related words. |
| 8.3 | Parentheses are for references, item identifiers, step labels, abbreviations, singular/plural pairs, explanations, and alternatives. |
| 8.4 | In a vertical list, a colon ends the sentence for word-count purposes. |
| 8.5 | Text in parentheses counts as one word. |
| 8.6 | Count each of these as one word: numbers, numbers with units, abbreviations, alphanumeric identifiers, quoted text, titles, headings, placards, labels. |
| 8.7 | A hyphenated word counts as one word. |

## Section 9 — Writing practices

| Rule | Summary |
|---|---|
| 9.1 | If a word-for-word replacement does not work, change the sentence construction. |
| 9.2 | Use each approved word correctly. |
| 9.3 | Do not form phrasal verbs from two words. |
| 9.4 | Keep terminology and wording consistent. |

## Common substitutions

Not the official dictionary. This is a short list of frequent offenders with plain replacements.

| Avoid | Use |
|---|---|
| ensure | make sure |
| verify | make sure |
| utilize, utilise, leverage | use |
| facilitate | help, make easy |
| commence, initiate | start |
| terminate | stop |
| prior to | before |
| in order to | to |
| perform, conduct, execute | do |
| demonstrate | show |
| additionally, furthermore | also |
| assist | help |
| attempt | try |
| sufficient | enough |
| purchase | buy |
| obtain | get |
| provide | give |
| require | need |

Technical nouns and verbs are exempt: `deploy`, `commit`, `lint`, `mount`, and similar domain terms are allowed when they name a real technical concept. The rule is one meaning, one name, used consistently.

## Local adaptations for agent instructions

These are ours, not the standard's:

- A code span, path, URL, or identifier counts as one word.
- A table row or checklist item is one sentence.
- Structure-only mode applies to article prose: the 20/25-word caps apply to instructions and technical claims, not to narrative.
- English only. For Chinese text, structural advice is allowed. Vocabulary enforcement is not.
