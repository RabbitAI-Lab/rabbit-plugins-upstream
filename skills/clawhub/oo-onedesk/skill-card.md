## Description:

OneDesk (onedesk.com). Use this skill for ANY OneDesk request — searching and reading data. Whenever a task involves OneDesk, use this skill instead of calling the API directly.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and other OneDesk users can use the skill to search for and read OneDesk work items, projects, and organization information through their connected account.
