# Manifest Schema

Generated by `extract.py`, optionally refined by `apply_verified.py`.

## Top-level

```json
[
  { /* entry */ },
  ...
]
```

## Entry Fields

### Stage 1 fields (extract.py — always present)

| Field | Type | Description |
|-------|------|-------------|
| `filename` | string | Original filename (exact, as in folder) |
| `filepath` | string | Absolute path to the file |
| `year_hint` | string\|null | Year from filename prefix (most reliable; use as fallback) |
| `status` | string | `needs_llm_review` (initial state after extract) |
| `raw_text` | string | First 3 pages of PDF text concatenated (for LLM/human parsing) |
| `is_duplicate` | bool | True if another entry has a similar filename (dup detection) |
| `duplicate_group` | string\|null | Indices of duplicate group, e.g. `"[3,7]"` |
| `title` | null | Populated by Stage 2 (LLM or VERIFIED_DATA) |
| `title_source` | null | `llm`, `verified`, or `filename` |
| `year` | string\|null | Year (from year_hint or overridden by Stage 2) |
| `year_source` | string\|null | `filename`, `llm`, or `verified` |
| `venue` | string\|null | Conference/journal abbreviation |
| `venue_source` | string\|null | `llm` or `verified` |
| `notes` | string | Human-readable notes |

### Stage 2 fields (apply_verified.py — added when verified)

| Field | Type | Description |
|-------|------|-------------|
| `title` | string | Paper title |
| `authors` | string[] | List of author names (optional) |
| `year` | string | Publication year |
| `venue` | string | Conference/journal abbreviation |
| `llm_confidence` | string | `high` / `medium` / `low` (if LLM-parsed) |
| `abstract` | string | First ~300 chars of abstract |

## Status Rules

| Status | Meaning | Will rename? |
|--------|---------|-------------|
| `ready` | Metadata confirmed (via VERIFIED_DATA with `confirmed: True`) | ✅ Yes |
| `needs_llm_review` | Initial state; no verified data injected yet | ❌ No |
| `needs_verification` | Legacy; same as `needs_llm_review` | ❌ No |
| `manual_review` | Extraction failed; no title found | ❌ No |
| `llm_failed` | LLM parsing returned no usable title | ❌ No |
| `llm_error` | LLM API call failed | ❌ No |

## Output Filename Format

```
[Year] [Venue] Title.pdf
[Year] [Venue] Title (1).pdf   ← duplicate
[Year] [Venue] Title (2).pdf   ← duplicate
```
