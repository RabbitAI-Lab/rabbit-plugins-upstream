## Description:

Route a task to the right EveryInfra product and use its MCP or REST contract safely. One API key covers structured data from 90 platforms (TikTok, Instagram, X, YouTube, LinkedIn, Reddit, Amazon, RedNote, Douyin), web search, AI, CAPTCHA, phone numbers, email and proxies. Use when the user mentions EveryInfra or is unsure which product fits.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers can use this skill to choose an EveryInfra data, search, AI, or other API product and interact with it through MCP or REST. It guides setup, capability discovery, and authorization of potentially paid operations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Service calls can share task inputs with EveryInfra and paid operations can spend the account wallet balance.

Mitigation: Use a key scoped to the needed products, confirm the provider for ambiguous requests, and authorize paid calls deliberately after checking current requirements and pricing.
