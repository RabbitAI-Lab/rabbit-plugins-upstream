## Description: <br>
Parameter-efficient fine-tuning for LLMs using LoRA, QLoRA, and 25+ methods for memory-constrained training, adapter workflows, and multi-adapter serving. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and ML engineers use this skill to plan and execute PEFT, LoRA, and QLoRA fine-tuning workflows for large language models with limited GPU memory. It provides installation commands, training code, adapter configuration guidance, merge and serving patterns, and troubleshooting advice. <br>
