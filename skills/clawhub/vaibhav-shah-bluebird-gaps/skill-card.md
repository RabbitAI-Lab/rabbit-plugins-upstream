## Description:

Find schedule conflicts and focus-time gaps in synthetic calendar events.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vaibhavmighty](https://clawhub.ai/user/vaibhavmighty)

### License/Terms of Use:

MIT

## Use Case:

People planning focused work can use this skill to identify overlapping events and find open intervals long enough for a task in a synthetic or user-approved calendar export. The skill is intended for class-only calendars and should not be connected to a personal calendar.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security review notes that calendar file-reading is not listed in the declared tool scope.

Mitigation: Use only the synthetic fixture or a user-approved export, and review the file and command before running the planner.
