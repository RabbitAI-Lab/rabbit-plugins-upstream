## Description:

Creates 15–25-second vertical social videos with voiceover and burned-in subtitles from prompts and optional reference files.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and marketing teams use this skill to make short vertical videos for social platforms from a prompt and optional reference media.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and optional attachments are sent to dLazy, and project context may persist on the hosted service.

Mitigation: Only share content intended for upload and review dLazy service terms before using sensitive data.

Risk: An API key may be stored in local CLI configuration.

Mitigation: Protect local credentials and rotate or revoke the key if exposed.

Risk: Using the skill requires installing or running a third-party CLI package.

Mitigation: Review the pinned CLI package before installing or running it.
