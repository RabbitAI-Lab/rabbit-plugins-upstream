## Description:

Helps create 15–25-second vertical social videos with storyboards, generated clips, voiceover, and burned-in subtitles.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and social media teams use this skill to request finished vertical shorts for TikTok, YouTube Shorts, Reels, and similar platforms rather than a script alone.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and files attached with --files are sent to dLazy services.

Mitigation: Review prompts and attachments for sensitive content before sending; attach only files approved for upload.

Risk: Using the CLI requires a dLazy API key.

Mitigation: Keep the key private, use the provided authentication flow, and revoke or rotate it if exposed.
