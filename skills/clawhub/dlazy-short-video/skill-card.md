## Description:

Creates finished 15–25-second vertical videos for social platforms using a hook-first storyboard, per-shot imagery and video clips, voiceover, and burned-in subtitles.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and social-media teams use this skill to generate complete vertical short videos for TikTok, YouTube Shorts, Instagram Reels, and Douyin from prompts and optional reference media.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected attachments are sent to dLazy, and attached media is uploaded to its storage service.

Mitigation: Submit only prompts and media appropriate for the intended cloud service; avoid uploading sensitive material unless authorized.

Risk: Video generation may consume paid credits, while project sessions and an API key are associated with the organization.

Mitigation: Choose the intended organization project, monitor credit use, and protect, rotate, or revoke the saved API key as needed.

Risk: The release security review does not establish the security of the external CLI or hosted service.

Mitigation: Review the provider's terms and security practices before sharing sensitive prompts or media.
