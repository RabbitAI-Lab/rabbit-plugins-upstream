## Description:

Creates finished 15–25 second vertical social videos from a hook-first storyboard, generated shots, voiceover, and subtitles.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and social media teams use the skill to turn a prompt and optional reference media into a finished short vertical video for social platforms.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected media are sent to dLazy, and attached files are uploaded to its media storage.

Mitigation: Choose the intended project and attachments, and send only content you are comfortable sharing with the service.

Risk: The service uses credits, and the CLI stores an API key in the local user configuration.

Mitigation: Monitor service-credit use, protect the saved API key, and revoke it when it is no longer needed.
