## Description:

Creates 15–25-second vertical social videos with storyboards, generated clips, voiceover, and burned-in subtitles.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and marketing teams use this skill to produce finished vertical videos for TikTok, YouTube Shorts, Reels, and similar social platforms.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and attached files are sent to dLazy's cloud service.

Mitigation: Only submit prompts and files that you intend to share with dLazy.

Risk: The CLI stores an API key locally and a global install remains on the device.

Mitigation: Protect the local API key and use the pinned npx invocation if a persistent global install is unwanted.
