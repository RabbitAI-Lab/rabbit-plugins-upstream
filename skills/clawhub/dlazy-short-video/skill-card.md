## Description:

Creates finished 15–25-second vertical social videos with a hook-first storyboard, voiceover, and burned-in subtitles through dLazy.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and marketing teams use this skill to make short vertical videos for social platforms such as TikTok, YouTube Shorts, and Reels.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and options are sent to the dLazy service.

Mitigation: Avoid including confidential information in prompts unless approved for that service.

Risk: Attached local files are uploaded to dLazy storage.

Mitigation: Attach only files you are comfortable uploading.

Risk: The CLI can save an API key locally.

Mitigation: Protect the local key and rotate or revoke it through the dLazy dashboard if needed.

Risk: A global CLI installation persists on the system.

Mitigation: Use the skill's pinned npx command if a global installation is not wanted.
