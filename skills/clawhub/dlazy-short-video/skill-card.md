## Description:

Creates finished 15–25-second vertical social videos with shot-by-shot visuals, voiceover, and burned-in subtitles.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and marketing teams use this skill to produce short vertical videos for social platforms from prompts and optional reference files.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and attached files may be sent to the third-party dLazy service.

Mitigation: Avoid sending sensitive prompts or files; review attachments before upload.

Risk: Login stores an API key locally for future CLI use.

Mitigation: Protect local credentials and rotate or revoke the key through dLazy if needed.

Risk: A global CLI install persists on the device.

Mitigation: Use the pinned npx option if a global installation is not desired.
