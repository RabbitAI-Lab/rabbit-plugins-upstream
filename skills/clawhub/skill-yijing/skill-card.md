## Description: <br>
Yijing Divination helps agents present an interactive I Ching divination UI with coin, time, number, and random casting plus AI-generated readings. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[aiepco](https://clawhub.ai/user/aiepco) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
External users use this skill through an agent to launch an interactive I Ching divination flow, cast hexagrams by coin, time, number, or random methods, and receive AI readings for their questions. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill creates and uses a third-party account and API key. <br>
Mitigation: Review before installing, protect any generated API key, and rotate it if it is exposed or no longer trusted. <br>
Risk: User questions, divination history, and API keys may be stored in the browser and sent to the external service. <br>
Mitigation: Avoid entering sensitive personal, financial, medical, or relationship details unless the user accepts that handling, and clear browser storage when appropriate. <br>
