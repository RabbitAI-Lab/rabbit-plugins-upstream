## Description:

Helps agents create scenario-guided Onimi Pages and editable Onimi Slides in the user's workspace.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mariohazy](https://clawhub.ai/user/mariohazy)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and teams use the skill to make guided web Pages or editable slide decks, validate local drafts, and optionally save private drafts to Onimi with their authorization.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A new or saved project may expose work to an unintended audience.

Mitigation: Confirm project visibility before cloud creation or saving; use private access when controlled sharing is needed.

Risk: Draft source or upload responses may contain private content or access capabilities.

Mitigation: Keep source and upload response files private and out of chat, logs, and public repositories.

Risk: An unrequested update may change the installed skill during creation.

Mitigation: Run updates only when the user requests an exact version.
