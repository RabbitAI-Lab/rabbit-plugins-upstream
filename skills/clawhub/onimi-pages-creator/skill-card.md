## Description:

Create, refine, validate, and preview a polished standalone HTML page when the user wants a website, interactive artifact, report, poster, dashboard, or demo that can be shared through Onimi Pages.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, designers, and content teams use this skill to create self-contained, validated HTML pages for websites, reports, posters, dashboards, interactive artifacts, and Onimi Pages handoff.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Mutable installation commands such as npm @latest can install a different package version over time.

Mitigation: Prefer ClawHub or a verified direct-download flow; when using npm, pin or review the resolved version before installation.

Risk: The skill creates local HTML files and can continue to publishing or update workflows only when authorized.

Mitigation: Validate the local HTML first, and require explicit user approval before publishing, changing visibility, or updating the installed skill.
