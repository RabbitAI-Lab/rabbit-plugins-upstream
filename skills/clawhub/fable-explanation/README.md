# Fable Explanation · 寓言讲概念

越复杂的知识，越需要绕着弯讲。

用寓言故事理解新概念，接近结尾才揭晓，故事后再解释概念、隐喻和容易误解的地方。

Explain complex concepts through short fables, storytelling, analogies, and metaphors. Reveal the concepts near the ending, then explain their meaning, story mappings, and limitations. Useful for learning, teaching, and concept explanation.

## 适合什么时候用

- 第一次接触一个抽象概念，想先建立具体的印象。
- 看过定义，但仍分不清概念中的人物、条件和因果关系。
- 需要向不熟悉专业术语的人解释一个概念。

输入是一个或多个具体概念。只知道领域时，可以先选出想学的概念，再使用本技能。故事帮助建立直觉，正式解释负责说明含义；阅读时把两部分连起来看。

## 完整示例：机会成本

以下展示故事、概念和隐喻之间的关系。实际使用时重新创作适合所给概念的故事。

> 木匠只剩半天工夫。修桥能换两袋米，修门能换一袋，做桌子能换三袋。他把三张邀约摆在工作台上，拿起了做桌子的刨子。
>
> 傍晚，他扛着三袋米回家。孩子问：“今天什么也没花吧？”
>
> 路过桥头时，木匠停了一下。修桥的人正把两袋米递给另一位匠人。
>
> 他看了看自己空着的另一只手，继续往家走。

这个故事讲的是**机会成本**：做出选择时，所放弃的其他可行选择中，价值最高的那一个。

| 故事里的元素 | 对应含义 |
| --- | --- |
| 只剩半天 | 时间有限，三件事无法同时完成 |
| 选择做桌子 | 实际采取的行动 |
| 修桥的两袋米 | 放弃的最佳替代选择，是这次选择的机会成本 |
| 修门的一袋米 | 另一个被放弃的选择，不与两袋米相加 |

隐喻的边界：故事假设三项工作都能在半天完成，材料和其他成本相同，报酬也能确定拿到。现实中的时间、风险和非金钱收益也可能影响替代选择的价值。故事里的“空着的手”表示放弃的机会，不是实际支付了两袋米。

## 阅读时可以留意什么

先看故事中的选择、限制和结果，再对照解释，检查关键情节能否对应概念的核心机制。多个概念一起出现时，留意各自的含义和关系，避免只记住一个模糊的道理。

隐喻难免有所简化，因此输出最后会说明容易误解的地方。涉及具体学科的严格定义、推导或计算时，可以在读完故事后继续查阅相应资料。
