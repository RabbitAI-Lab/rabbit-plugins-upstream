# Reclaim Protocol Builder skill for ClawHub

Instructions for using the existing Reclaim Builder MCP in OpenClaw. The skill connects developers to `@reclaimprotocol/agent` over local stdio; it does not include a Gateway plugin or a hosted MCP endpoint.

The npm server was initialized and its tool catalog checked in the public repository CI. The OpenClaw setup follows the official MCP documentation; an end-to-end OpenClaw verification session has not been tested here.

Source: https://github.com/reclaimprotocol/developer-tools/tree/main/integrations/clawhub/reclaim-protocol-builder

Product: https://build.reclaimprotocol.org
