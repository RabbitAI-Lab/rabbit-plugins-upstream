## 概念理解类问题

### Q1: PPAP和APQP有什么区别？
**A:** 
| 项目 | APQP | PPAP |
|------|------|------|
| 全称 | Advanced Product Quality Planning | Production Part Approval Process |
| 阶段 | 产品开发全过程 | 零件批准阶段 |
| 目的 | 产品质量策划 | 零件批准确认 |
| 关系 | APQP包含PPAP | PPAP是APQP输出之一 |

APQP是项目开发流程，PPAP是其中的批准环节。

### Q2: 哪些情况下必须提交PPAP？
**A:** 必须提交的情况：
1. 新零件首次提交
2. 产品设计发生变更
3. 原材料或供应商变更
4. 生产工艺变更
5. 停产超过12个月恢复生产
6. 客户要求重新批准

### Q3: PPAP的5个提交等级如何选择？
**A:** 
- **默认等级**: Level 3（大多数客户要求）
- **选择依据**: 以客户合同或采购文件要求为准
- **供应商权限**: 供应商不可自行降低提交等级
- **升级情况**: 质量问题时可被要求提高等级

### Q4: Cpk和Ppk有什么区别？
**A:**
| 项目 | Cpk | Ppk |
|------|-----|-----|
| 计算方式 | 基于过程固有变异 | 基于样本变异 |
| 用途 | 长期过程能力 | 初始过程能力 |
| 公式 | min(Cpu, Cpl) | min(Ppu, Ppl) |
| 标准差 | σ (过程标准差) | s (样本标准差) |

**简单理解**: Ppk是"短期能力"，Cpk是"长期能力"

## 流程执行类问题

### Q5: PPAP样品数量如何确定？
**A:** 
1. **首选**: 按客户要求确定
2. **无特殊要求**: 一般3-5件
3. **大型零件**: 可协商减少数量
4. **重要零件**: 可能要求更多

### Q6: 提交PPAP的时间节点是什么？
**A:** 
通常在以下时机提交：
1. 小批量试生产完成后
2. 首批量产件发货前
3. 客户要求的特定节点

**注意**: 必须使用正式工装生产样品

### Q7: PPAP批准需要多长时间？
**A:**
- **标准周期**: 收到完整文件后5-10个工作日
- **影响周期因素**:
  - 文件完整性
  - 问题反馈次数
  - 客户内部审批流程
- **加快方法**: 首次提交完整、准确

### Q8: PPAP批准后还需要做什么？
**A:**
1. **持续保持**: 确保过程能力持续满足要求
2. **变更管理**: 任何变更需重新评估PPAP
3. **定期审查**: 配合客户年度审核
4. **问题响应**: 及时响应市场反馈

## 文件准备类问题

### Q9: PSW签名有什么具体要求？
**A:**
1. **必须原件签名**: 不能电子签名或打印
2. **授权人签字**: 供应商质量经理或授权人
3. **日期一致**: 与提交日期一致
4. **清晰可辨**: 签名清晰，便于识别

**常见问题**: 
- 使用电子签名 → 不合格
- 签名模糊 → 不合格
- 日期涂改 → 不合格

### Q10: 过程能力数据如何收集？
**A:**
1. **样本量**: 至少50件连续生产件
2. **采样方式**: 随机抽样，避免选择性抽样
3. **测量设备**: 已完成MSA验证
4. **数据记录**: 记录所有原始数据
5. **计算方法**: 使用统计软件计算

### Q11: GR&R不合格怎么办？
**A:**
1. **分析原因**: 设备问题/操作问题/零件变异
2. **改进措施**:
   - 设备问题: 维修、校准、更换设备
   - 操作问题: 标准化操作、培训
   - 零件变异: 改进零件一致性
3. **重新分析**: 改进后重新做MSA
4. **记录归档**: 保存所有分析和改进记录

### Q12: 客户特殊要求(CSR)如何处理？
**A:**
1. **识别**: 从客户合同、规范中识别CSR
2. **清单化**: 编制CSR清单
3. **满足证明**: 提供满足CSR的证据
4. **差异说明**: 无法满足的CSR需申请偏差

## 审核反馈类问题

### Q13: PPAP被退回如何处理？
**A:**
1. **分析原因**: 仔细阅读客户反馈
2. **制定对策**: 针对问题制定改进措施
3. **整改文件**: 修改或补充文件
4. **重新提交**: 按要求重新提交
5. **跟踪确认**: 确认客户收到并审核

### Q14: 收到PPAP需要整改的反馈怎么办？
**A:**
1. **理解问题**: 明确整改要求
2. **原因分析**: 找出根本原因
3. **对策实施**: 实施改进措施
4. **效果验证**: 确认整改有效
5. **重新提交**: 按要求重新提交

### Q15: 能否边生产边等PPAP批准？
**A:**
- **原则**: 不建议，可能承担风险
- **分批交货**: 与客户协商分批交付
- **风险承担**: 未批准前交付可能面临:
  - 客户拒收
  - 质量问题责任
  - 追溯困难

## 典型案例分析

### 案例1: 过程能力不足导致PPAP延迟

**背景**: 
某冲压件供应商提交PPAP，提交等级Level 3，Cpk数据0.98。

**问题**:
1. Cpk=0.98 < 1.33（不满足要求）
2. 客户要求整改后重新提交

**分析**:
- 原因分析发现: 模具磨损导致尺寸漂移
- 根本原因: 模具维护周期过长

**改进措施**:
1. 修模并调整模具参数
2. 缩短模具维护周期
3. 增加过程监控频次
4. 重新收集数据

**结果**: 
整改后Cpk=1.45，PPAP获得批准

**教训**:
- 初始过程能力研究必须认真对待
- 发现问题要分析根本原因
- 改进措施要有针对性

---

### 案例2: PSW签名不规范被退回

**背景**:
某供应商提交PPAP文件包，所有内容完整。

**问题**:
PSW使用电子签名，且日期有明显涂改痕迹。

**客户反馈**:
1. PSW必须原件签名
2. 日期不能涂改
3. 要求重新提交

**整改**:
1. 重新打印PSW表格
2. 授权人现场签字
3. 重新提交完整文件包

**结果**:
重新提交后获得批准

**教训**:
- PSW签名要求必须严格执行
- 不能抱有侥幸心理
- 细节问题也会导致失败

---

### 案例3: 遗漏客户特殊要求

**背景**:
某汽车电子供应商提交PPAP，客户要求满足CSR清单。

**问题**:
提交的PPAP文件包未包含CSR满足证明。

**客户反馈**:
1. 缺少CSR满足情况说明
2. 要求补充所有CSR的满足证据

**整改**:
1. 对照CSR清单逐项检查
2. 补充每项CSR的满足证据
3. 对无法满足的项申请偏差批准

**结果**:
补充完整后获得批准

**教训**:
- 必须仔细阅读客户要求
- CSR清单必须逐项核对
- 遗漏会导致重复工作

---

### 案例4: 外观批准报告适用性判断

**背景**:
某金属件供应商提交PPAP，零件无外观要求但提交了外观批准报告。

**问题**:
客户认为不需要该文件，要求删除。

**分析**:
- 外观批准报告仅适用于有外观要求的零件
- 该零件为内部件，无外观要求
- 属于"条件必需"项，不需要提交

**结果**:
删除该文件后提交，PPAP获得批准

**教训**:
- 准确判断各项要求的适用性
- 不是越多越好，要按要求提供
- "条件必需"项要根据实际情况判断

---

### 案例5: 供应商变更未及时提交PPAP

**背景**:
某供应商将原材料供应商从A公司变更为B公司，未重新提交PPAP。

**问题**:
客户审核时发现原材料来源变更。

**客户反馈**:
1. 材料供应商变更属于PPAP重新提交条件
2. 要求重新提交PPAP
3. 期间停止供货

**整改**:
1. 确认新材料性能符合要求
2. 重新进行过程能力研究
3. 准备完整PPAP文件包
4. 重新提交并获得批准

**结果**:
重新批准后恢复供货

**教训**:
- 了解PPAP重新提交的触发条件
- 变更管理必须及时评估PPAP影响
- 不要等到客户发现才处理

## 快速参考表

### PPAP重新提交触发条件

| 触发条件 | 是否需要重新提交 |
|----------|-----------------|
| 设计变更 | 是 |
| 材料变更 | 是 |
| 供应商变更 | 是 |
| 工艺变更 | 是 |
| 停产12个月以上 | 是 |
| 质量问题被要求 | 是 |
| 检验方法变更 | 视情况 |
| 次要供应商变更 | 视情况 |

### PPAP常见不合格项

| 不合格项 | 占比 | 预防措施 |
|----------|------|----------|
| 过程能力不足 | 25% | 充分验证工艺 |
| 文件不完整 | 20% | 清单核对 |
| PSW签名问题 | 15% | 严格执行要求 |
| CSR遗漏 | 15% | 仔细阅读要求 |
| MSA不合格 | 10% | 提前验证测量系统 |
| 其他 | 15% | - |

### PPAP成功要点

1. **充分准备**: 正式生产前完成内部验证
2. **一次准确**: 减少重复提交
3. **沟通及时**: 主动与客户沟通
4. **持续改进**: 获得批准后保持能力
