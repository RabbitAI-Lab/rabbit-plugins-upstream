## 设计记录阶段

### 填写内容
- 工程图纸（已批准版本）
- CAD/CAM数据
- 技术规范
- 材料规格书

### 填写要求
1. **版本确认**: 确保是最新批准版本
2. **完整性**: 包含所有相关图纸和规格
3. **清晰度**: 图纸清晰，尺寸标注完整
4. **可追溯性**: 有明确的版本号和批准日期

### 常见问题
- 图纸版本过旧
- 缺少变更标记
- 尺寸标注不完整

## 工程变更文件阶段

### 填写内容
- 工程变更通知单(ECN)
- 偏差申请单
- 临时变更批准
- 设计变更记录

### 填写要求
1. **变更编号**: 唯一标识的变更编号
2. **变更内容**: 清楚描述变更内容
3. **批准状态**: 变更已获批准
4. **实施状态**: 明确变更实施阶段

### 填写示例
```
ECN编号: ECN-2024-001
变更零件: 12345678
变更内容: 倒角尺寸由R1.0改为R1.5
变更原因: 消除毛刺问题
批准日期: 2024-01-15
实施状态: 已实施
```

## 工程批准阶段

### 填写内容
- 设计验证计划(DVP)
- 设计验证报告
- 型式试验报告
- 设计计算书

### 填写要求
1. **DVP完整性**: 覆盖所有设计要求
2. **试验结果**: 如实记录试验数据
3. **判定结论**: 基于数据的客观判定
4. **签名认可**: 设计工程师签字

### 判定标准
| 项目 | 判定标准 |
|------|----------|
| 尺寸符合性 | 100%符合图纸 |
| 功能试验 | 满足性能指标 |
| 耐久性 | 满足寿命要求 |
| 材料性能 | 符合规格要求 |

## DFMEA阶段

### 适用范围
- 供应商负责产品设计时
- 客户要求提供时

### 填写内容
| 列项 | 填写说明 |
|------|----------|
| 项目 | 产品/系统名称 |
| 功能 | 产品功能描述 |
| 潜在失效模式 | 可能发生的失效形式 |
| 潜在失效后果 | 失效对顾客的影响 |
| 严重度(S) | 后果严重程度(1-10) |
| 潜在失效原因 | 失效发生的根本原因 |
| 频度(O) | 原因发生的频率(1-10) |
| 现行控制 | 现有预防/探测措施 |
| 探测度(D) | 探测难度(1-10) |
| RPN | S×O×D，风险优先数 |

### 评分标准

**严重度S评分**
| 分数 | 说明 |
|------|------|
| 10 | 无预警的安全问题 |
| 9 | 有预警的安全问题 |
| 8 | 严重功能丧失 |
| 7 | 主要功能丧失 |
| 6 | 次要功能丧失 |
| 5 | 舒适性问题 |
| 4 | 轻微问题 |
| 3 | 轻微干扰 |
| 2 | 无明显问题 |
| 1 | 无影响 |

**频度O评分**
| 分数 | 说明 |
|------|------|
| 10 | 非常高(≥100ppm) |
| 9 | 高(50-99ppm) |
| 8 | 中高(20-49ppm) |
| 7 | 中等(10-19ppm) |
| 6 | 中低(2-9ppm) |
| 5 | 低(1-2ppm) |
| 4 | 很低(<1ppm) |
| 3 | 极少 |
| 2 | 极低 |
| 1 | 不可能(失效几乎不可能) |

**探测度D评分**
| 分数 | 说明 |
|------|------|
| 10 | 绝对无法探测 |
| 9 | 很小的机会探测 |
| 8 | 很小的机会 |
| 7 | 小机会 |
| 6 | 中等机会 |
| 5 | 中高机会 |
| 4 | 高机会 |
| 3 | 很高机会 |
| 2 | 几乎肯定能探测 |
| 1 | 肯定能探测 |

### RPN处置原则
- RPN > 100: 必须采取改进措施
- RPN 50-100: 建议采取改进措施
- RPN < 50: 监控并持续改进

## 控制计划阶段

### 填写内容
| 列项 | 填写说明 |
|------|----------|
| 工序名称 | 过程流程图中的工序 |
| 产品特性 | 需要控制的产品特性 |
| 过程特性 | 影响产品特性的过程参数 |
| 控制方法 | 具体控制手段 |
| 反应计划 | 异常时的处置措施 |

### 产品特性 vs 过程特性
- **产品特性**: 顾客要求的特性（如尺寸、硬度、外观）
- **过程特性**: 影响产品特性的过程参数（如温度、压力、时间）

### 填写示例

| 工序 | 产品特性 | 公差 | 过程特性 | 控制方法 | 检测频率 | 反应计划 |
|------|----------|------|----------|----------|----------|----------|
| 冲压 | 孔径φ10 | ±0.1 | 模具精度 | 模具点检 | 每班1次 | 停机调整 |
| 热处理 | 硬度HRC45-50 | - | 温度、时间 | 自动记录 | 连续 | 隔离评审 |

## 初始过程能力研究阶段

### 填写内容
- 数据收集记录表
- 测量值记录
- 统计计算结果
- 能力分析图表

### 数据要求
1. **样本量**: 至少连续50件
2. **采样方式**: 随机抽样或系统抽样
3. **测量设备**: 已完成MSA
4. **数据完整性**: 无缺失值

### 能力指标计算

**过程能力指数 Cp/Pp**
```
Cp = (USL - LSL) / 6σ
Pp = (USL - LSL) / 6s
```

**过程能力指数 Cpk/Ppk**
```
Cpu = (USL - X̄) / 3σ
Cpl = (X̄ - LSL) / 3σ
Cpk = min(Cpu, Cpl)
```

### 判定标准
| 指标 | 要求 | 判定 |
|------|------|------|
| Ppk | ≥1.67 | 理想 |
| Ppk | ≥1.33 | 最低要求 |
| Ppk | 1.0-1.33 | 需要改进 |
| Ppk | <1.0 | 能力不足 |

### 填写示例
```
零件号: 12345678
特性: 孔径φ10±0.1mm
USL: 10.1mm  LSL: 9.9mm
样本量: 50件
X̄: 10.02mm
σ: 0.025mm
Ppk: 1.33
判定: 合格
```

## 测量系统分析阶段

### 填写内容
- MSA计划
- 测量系统数据
- GR&R分析结果
- 校准记录

### 分析方法

**量具重复性和再现性研究(GR&R)**

1. **选取样本**: 选取10件代表性零件
2. **选择人员**: 选取2-3名测量员
3. **重复测量**: 每件零件测量2-3次
4. **数据记录**: 记录所有测量值
5. **计算分析**: 计算%GR&R

### GR&R判定标准
| %GR&R | 判定 | 行动 |
|-------|------|------|
| ≤10% | 优秀 | 接受 |
| 10-30% | 可接受 | 基于重要性决定 |
| >30% | 不可接受 | 必须改进 |

### %GR&R计算
```
%GR&R = (GR&R / TV) × 100%
其中:
- GR&R = √(EV² + AV²)
- EV = 重复性 (Equipment Variation)
- AV = 再现性 (Appraiser Variation)
- TV = 总体变异 (Total Variation)
```

### 填写示例
```
测量设备: 卡尺0-150mm，分辨率0.01mm
测量员: A、B
零件数: 10件
重复次数: 2次
EV: 0.008mm
AV: 0.005mm
GR&R: 0.009mm
TV: 0.102mm
%GR&R: 8.8%
判定: 优秀
```

## 外观批准报告阶段

### 适用范围
- 零件有外观要求时
- 客户要求提交外观批准时

### 填写内容
- 外观标准
- 标准样品
- 外观检查报告
- 颜色标准（适用时）

### 外观标准要素
1. **外观检查条件**: 光源、角度、距离
2. **接受标准**: 缺陷类型、允许程度
3. **标准样品**: 批准的外观样品
4. **检查方法**: 目视/放大镜/仪器

## PSW零件提交保证书阶段

### 填写要点

| 字段 | 填写要求 | 常见错误 |
|------|----------|----------|
| 零件号 | 必须与图纸一致 | 填写错误 |
| 零件名称 | 标准名称 | 简写或不完整 |
| 提交原因 | 选择一项主要原因 | 选择多项 |
| 提交等级 | 按客户要求 | 自行降低等级 |
| 样品数量 | 实际数量 | 虚报 |
| 偏差说明 | 如实说明偏差情况 | 隐瞒或夸大 |
| Ppk/Cpk | 实际测量值 | 造假 |
| 签名 | 原件签名 | 打印或电子签名 |

### 提交等级说明
- **Level 1**: 仅PSW
- **Level 2**: PSW+样品+有限数据
- **Level 3**: PSW+样品+完整数据
- **Level 4**: 按客户要求
- **Level 5**: PSW+全部数据+现场审核

### 签署要求
1. 必须供应商授权人签字
2. 不得使用电子签名或打印签名
3. 日期必须填写
4. 签字人须对内容负责

### 典型问题
- 使用电子签名代替原件签名
- 日期与文件日期不一致
- 零件信息与实际不符
- Ppk/Cpk数据造假
