## 模板生成原则

### 通用要求
1. **结构清晰**: 采用分层标题，层次分明
2. **内容完整**: 覆盖所有必需信息项
3. **格式规范**: 符合客户和行业标准
4. **可追溯**: 包含版本、日期、编号等追溯信息

### 文件命名规范
```
[零件号]_[文件类型]_[版本]_[日期]
示例: 12345678_PSW_RevA_20240115.pdf
```

### PSW填写说明

| 字段 | 填写要求 | 注意事项 |
|------|----------|----------|
| 零件名称 | 与图纸一致 | 使用正式名称 |
| 零件号 | 客户零件号 | 必须准确 |
| 提交原因 | 选择适用项 | 只能选一项主要 |
| 提交等级 | 按客户要求 | 不得自行降低 |
| 样品数量 | 按客户要求 | 注明单位 |
| Ppk/Cpk | 实测数据 | 必须≥1.33 |
| 签名 | 原件签名 | 不得电子签名 |

- 所有"必需"项必须提供文件
- "条件必需"项根据实际情况判断
- "状态"列如实填写实际状态
- 版本号必须是最新的批准版本

## 过程流程图模板

### 流程图符号说明

| 符号 | 名称 | 用途 |
|------|------|------|
| ○ | 工序圆 | 表示加工工序 |
| □ | 操作方框 | 表示操作步骤 |
| ◇ | 判断框 | 表示决策点 |
| → | 箭头 | 表示流程方向 |

## 模板生成示例

### 示例场景
客户要求提交一款冲压件的PPAP，提交等级Level 3。

### 生成文件清单

1. **零件提交保证书(PSW)**
   - 填写完整零件信息
   - 声明提交原因和等级
   - 供应商签字盖章

2. **PPAP文件目录**
   - 按18项要求逐项核对
   - 标注实际状态
   - 记录文件版本

3. **过程流程图**
   - 冲压工艺流程
   - 关键工序标注
   - 控制点说明

4. **检查记录表**
   - 首件检验记录
   - 过程能力数据
   - MSA分析记录

### 智能体生成提示

当用户请求生成PPAP文件时，应：
1. 确认零件信息和提交要求
2. 选择合适的模板
3. 按实际数据填充模板
4. 标注需要用户补充的信息
5. 输出符合客户格式要求的文档
