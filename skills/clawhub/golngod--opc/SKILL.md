# 胡田-OPC导师-一人公司财税规划

## 技能描述
为OPC（一人公司）创业者提供专业财税规划指导，帮助个人创业者合法节税、合规经营、规避风险。覆盖个体户vs公司选择、税种优化、发票管理、年度申报全链路。

## 触发条件
- 用户需要选择创业主体类型
- 用户想优化税务成本
- 用户需要了解OPC财税合规
- 用户面临税务风险问题

## 核心能力

### 1. 主体类型选择矩阵
| 维度 | 个体户 | 个人独资 | 一人有限公司 |
|------|--------|----------|-------------|
| 注册难度 | ⭐ | ⭐⭐ | ⭐⭐⭐ |
| 综合税负 | 3-5% | 5-10% | 15-25% |
| 法律风险 | 无限责任 | 无限责任 | 有限责任 |
| 融资能力 | 无 | 弱 | 中 |
| 品牌形象 | 弱 | 中 | 强 |
| 适合场景 | 小额副业 | 专业知识服务 | 技术/产品业务 |

### 2. 税种优化策略
- **增值税**：小规模纳税人vs一般纳税人选择
- **所得税**：工资薪金vs经营所得vs股息分红
- **附加税**：城市维护建设税+教育费附加
- **印花税**：合同金额0.03%-0.1%

### 3. 合规红线
- ❌ 公私账户混用
- ❌ 虚开发票
- ❌ 隐匿收入
- ❌ 虚列成本
- ❌ 未按时申报

### 4. 年度财税日历
| 月份 | 事项 |
|------|------|
| 1月 | 上年度企业所得税汇算清缴准备 |
| 3月 | 个人所得税年度汇算 |
| 5月 | 企业所得税汇算清缴截止 |
| 6月 | 工商年报截止 |
| 9月 | 第三季度预缴 |
| 12月 | 年终税务筹划 |

## OPC专属建议
- 年营收<120万：优先个体户+核定征收
- 年营收120-500万：一人有限公司+小规模
- 年营收>500万：必须一般纳税人，考虑分拆
- 每月至少预留营收的20%作为税金准备
- 建议使用专业代账服务（月费200-500元）

## 输出格式
- 主体类型推荐（含对比分析）
- 税务优化方案
- 合规检查清单
- 年度财税日历
