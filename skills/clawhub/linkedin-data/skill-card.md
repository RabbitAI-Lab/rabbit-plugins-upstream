## Description:

LinkedIn API integration with a single superagnt API key (Bearer token). Fetch company profiles, jobs, people, posts, and professional network insights.

This skill is ready for commercial/non-commercial use.

## Publisher:

[superagnt](https://clawhub.ai/user/superagnt)

## Use Case:

Sales, recruiting, and research agents can use the LinkedIn Data API to retrieve professional profiles, company details, job listings, posts, and related insights for enrichment and analysis.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Requests use an external API and an API key, so the service receives the submitted queries and credentials.

Mitigation: Use an authorized API key and confirm the data in each request is appropriate to share with the service; keep the key private.
