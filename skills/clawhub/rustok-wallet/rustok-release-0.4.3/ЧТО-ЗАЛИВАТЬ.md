# Заливка на ClawHub — скилл 0.4.9

## Что заливать

`clawhub-skill-0.4.9.zip` — либо папку `clawhub-skill-0.4.9/` целиком, смотря
что попросит форма.

Внутри три файла: `SKILL.md`, `claw.json`, `scripts/health-check.sh`.

## Куда

https://clawhub.ai/temrjan/skills/rustok-wallet → загрузка новой версии.

## Проверено перед упаковкой

- Версия **0.4.9** в `claw.json` и в шапке `SKILL.md` — синхронны между собой.
  Прежний листинг — 0.4.8, то есть номер строго выше, как требует площадка.
- В пакете **ноль** упоминаний «24 слова» — они заменены на 12 там, где речь о
  создании кошелька.
- Образ, на который ссылается скилл, **уже опубликован**: `rustok-wallet:latest`
  = дайджест `d120b41d2617` = версия 0.4.3. Заливать скилл раньше образа было
  нельзя — листинг ссылался бы на несуществующее.

## Что изменилось в тексте скилла

Одна правка по смыслу: онбординг теперь говорит «back up the 12-word recovery
phrase» и «prints the address and the 12 words». Всё остальное не тронуто.

## Отдельно, после заливки

Поставить git-тег на репозитории — по конвенции линии:

```
cd ~/Dev/projects/rustok/mcp-wallet-0.4.x
git tag skill-v0.4.9 && git push origin skill-v0.4.9
```

Скажите — сделаю сам, это одна команда.
