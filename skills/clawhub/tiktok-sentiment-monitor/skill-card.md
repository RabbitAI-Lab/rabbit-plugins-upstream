## Description:

Retrieves public TikTok keyword search results, creator posts, and video comments as structured JSON so agents can support sentiment monitoring, trend analysis, competitor research, creator tracking, and audience-insight reports.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users, marketing teams, market researchers, content operators, and agent developers use this skill to gather public TikTok content and comment data for social listening, viral-content discovery, competitor monitoring, creator evaluation, and reporting workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill sends TikTok keywords, target URLs or IDs, and the Guaikei API token to www.guaikei.com.

Mitigation: Install and run it only when that data sharing is acceptable for the organization and keep the token in an environment variable.

Risk: Returned public TikTok data and local temp-directory logs may include usernames, comments, targets, or query terms that are sensitive in context.

Mitigation: Review and clean generated logs when needed, and redact user-identifying fields before external publication or commercial redistribution.

Risk: The skill retrieves data but does not independently verify sentiment, trend, or risk conclusions generated by downstream analysis.

Mitigation: Treat generated reports as analytical assistance and have a human reviewer check claims, rankings, and recommendations before acting on them.
