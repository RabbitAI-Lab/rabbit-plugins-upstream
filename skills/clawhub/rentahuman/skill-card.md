## Description:

Hire humans for physical-world tasks via RentAHuman.ai. Search available humans by skill, post bounties, review applications, and coordinate real-world work. Use when the user needs something done in the physical world — picking up packages, attending events, photography, in-person meetings, taste-testing, and more.

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: The quick-start can publish task details without the preview and user approval required elsewhere in the documentation.

Mitigation: Require approval of the final listing, worker count, and total budget before posting.

Risk: Public task descriptions may disclose exact addresses, package identifiers, or access instructions.

Mitigation: Keep sensitive details out of public descriptions and share restricted instructions only after hiring.

Risk: Payments and the optional MCP package require additional review.

Mitigation: Follow the documented approval requirements for payments and review and pin the optional MCP package separately.
