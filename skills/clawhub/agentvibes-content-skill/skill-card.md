## Description: <br>
AgentVibes Content Skill helps agents generate, format, and manage marketing copy, written content, title optimization, and API-backed content workflows. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

## Use Case: <br>
External users, developers, and teams use this skill to automate content generation and content-management tasks through an agent workflow. It is intended for marketing copy, writing support, title optimization, structured output, and API-response handling rather than pure technical documentation. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The security evidence reports broad local command and file powers plus remote content-management actions without enough scoping or user controls. <br>
Mitigation: Review the skill before installation, run it with least-privilege file and shell access, and restrict commands and writable paths to the specific content workflow being performed. <br>
Risk: The security evidence advises caution with sensitive prompts, files, API keys, and business data unless endpoint behavior and command/file boundaries are independently verified. <br>
Mitigation: Avoid providing secrets or sensitive business data until the AgentVibes endpoint behavior, API-key handling, and local execution boundaries have been independently checked. <br>
