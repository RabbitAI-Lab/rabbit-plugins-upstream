## Description:

Helps agents search and retrieve Indexed company data through the OOMOL-connected oo CLI.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

Agents and users can search Indexed company records, retrieve profiles by slug, and look up companies by website domain.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The suggested remote installers can run unverified code on the user's machine.

Mitigation: Review the installation path and use a verified package or an installer checked for integrity before executing it.

Risk: Company lookups and searches can consume account credits.

Mitigation: Check the expected credit cost and use only an account the user intends the agent to access.
