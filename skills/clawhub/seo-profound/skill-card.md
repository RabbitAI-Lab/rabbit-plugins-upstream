## Known Risks and Mitigations:

Risk: The skill depends on a Profound API key and a referenced install script, so an agent could expose credentials or run setup from an unverified source if deployed carelessly.

Mitigation: Verify the Profound install script from its actual source before use and provide PROFOUND_API_KEY only in the intended agent environment.
