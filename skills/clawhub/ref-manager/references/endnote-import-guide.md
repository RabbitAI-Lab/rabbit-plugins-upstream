# EndNote Import Guide

The skill produces `references.ris` (primary) and `references.xml` (secondary). Both import into EndNote with one action each.

## Why import is manual

EndNote's desktop library (`.enl`) is a proprietary binary format with no public API, so no program can write references directly into it. The standard, reliable path is to generate an exchange file (RIS or XML) and import it.

## Import RIS into EndNote

1. Open your EndNote library (or create one: File → New).
2. `File → Import → File…`
3. Click `Choose…` and select `references.ris`.
4. In the `Import Option` dropdown, choose **Reference Manager (RIS)**.
5. Leave `Duplicates` as `Import All` (or choose your preference).
6. Click `Import`.

All references in the file are imported at once — no per-item work.

## Import EndNote XML into EndNote

1. `File → Import → File…`
2. Select `references.xml`.
3. Set `Import Option` to **EndNote generated XML** (or **EndNote Import** depending on version).
4. Click `Import`.

RIS is recommended as the primary format because its `Import Option` name is consistent across EndNote versions. XML offers richer field mapping but the option name varies by version.

## Troubleshooting

- **"Import option not recognized"** — make sure the option exactly matches the file type (RIS vs XML). If XML fails, use the RIS file.
- **Chinese characters show as ???** — ensure the file is UTF-8. Both files generated by this skill are UTF-8; if EndNote misreads them, check EndNote's encoding setting or import the RIS file.
- **Fields look incomplete** — the source likely had no DOI and was not in Crossref; re-check the record in `refs.json` and fill the missing fields, then re-run.

## Verification after import

After importing, spot-check a few records against the `文献对账表.xlsx` sheet — especially the `核对结果` column — to confirm the corrected fields carried over.
