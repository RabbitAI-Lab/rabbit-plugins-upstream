## Description:

Frontend UI design guidance for creating webpages, landing pages, dashboards, React/Vue components, and other frontend pages that output HTML/CSS/JS code.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and frontend engineers use this skill to steer agents toward distinctive, high-polish UI implementations for web pages, dashboards, landing pages, and component work. It is intended for frontend code generation, not static image or social media graphic design.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill strongly steers typography, color, motion, and layout choices that may conflict with a product's brand system or accessibility requirements.

Mitigation: Review generated UI against the target design system, contrast requirements, responsive behavior, and accessibility standards before release.

Risk: Generated frontend code may load fonts from Google Fonts, which can be unsuitable for offline, privacy-sensitive, or restricted-network deployments.

Mitigation: Replace external font links with approved local or self-hosted fonts when the deployment environment requires it.

Risk: The source skill is written in Chinese, which may make review harder for teams that do not read Chinese.

Mitigation: Have a reviewer verify the source guidance and intended design constraints before adopting the skill in a production workflow.
