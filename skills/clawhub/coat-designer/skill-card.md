## Description:

Helps agents create customized coat designs from prompts, clothing specifications, reference images, text, and logos for print-on-demand or manufacturing-on-demand workflows.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ai-hub-admin](https://clawhub.ai/user/ai-hub-admin)

### License/Terms of Use:

MIT-0

## Use Case:

Designers, print-on-demand sellers, and developers use this skill to prepare coat design requests and retrieve design drafts, multi-view previews, and links to interactive workspaces.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Design prompts, reference image URLs, brand assets, tags, and session metadata are sent to an external design service.

Mitigation: Confirm the service's privacy and retention practices before sharing confidential designs, personal images, secrets, or unreleased brand assets.

Risk: The example npx command may fetch a changing version of the onekey CLI.

Mitigation: Pin an approved onekey CLI version when using the npx example.
