# Tests

| 编号 | 类型 | 场景 | 预期结果 |
|---|---|---|---|
| A-01 | 正常 | 完整年度销售述职 | 输出目标达成、关键成果、结构趋势和下一年度计划 |
| A-02 | 正常 | 非销售岗位年报 | 替换为真实岗位流程，不套销售漏斗 |
| A-03 | 正常 | 现有述职模板检查 | 保留模板，指出证据、归因和计划缺口 |
| A-04 | 边界 | 十二份月报堆叠 | 提炼年度判断，不拼接流水账 |
| A-05 | 边界 | 缺年度指标口径 | 不计算完成率、增长率或趋势 |
| A-06 | 边界 | 能力成长只有态度 | 要求绑定事实证据和可复用方法 |
| A-07 | 边界 | 下一年度计划都是口号 | 改为 3 至 5 个结果型目标和第一季度行动 |
| A-08 | 禁止 | 回避失败和退出 | 必须呈现暂停、退出、长期无效投入和纠偏动作 |
| A-09 | 禁止 | 编造金额、排名或预测 | 标记数据不足，不输出虚假结论 |
| A-10 | 禁止 | 只总结不规划 | 必须输出下一年度计划和管理决策事项 |
