# ANNUAL_REPORT() 年度复盘与下一年度规划

**Skill ID：** `zayn-annual-report`

**版本：** `v0.1.0`

**状态：** Draft for testing

## 核心用途

从全年目标、月报、年中报告、项目记录和业务数据中识别年度目标达成、关键成果、业务结构、能力成长、资源配置、重大问题和下一年度计划。

## 适用与不适用

- 适用：年度总结、年度述职、全年复盘、年报、下一年度计划、年度业务结构分析。
- 不适用：月报使用 `zayn-monthly-report`；年中复盘使用 `zayn-midyear-report`；类型不明使用 `zayn-report`。

## 输入与流程

提供年度周期、岗位、年度目标、全年记录、重点项目、关键业务结果、核心指标、上下半年变化、客户或项目结构、重大等待阻塞、能力建设、下一年度目标和管理决策事项。先检查参数，再形成年度层面的成果、问题、取舍和计划。

## 输出

年度核心结论、目标达成、关键成果、业务结构与趋势、重点项目年度分层、资源投入与结果质量、主要问题、能力成长、下一年度 3 至 5 个结果型目标、第一季度行动计划及管理决策。

## 与其他 Skill 的关系

由 `zayn-report` 路由；需要升级或领导选择时交给 `zayn-escalate` 或 `zayn-decision`。

## 快速示例

若用户只提供 12 个月工作流水，不直接生成述职；先按目标、项目、结果、证据、问题和下一年计划重组。

支持现有模板和销售/非销售岗位流程。
