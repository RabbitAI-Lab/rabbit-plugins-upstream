## Description:

Design craft for Orshot studio templates: one focal point, a 2-font type system, 60-30-10 color, copy that still fits when the data changes, restrained motion, the brand kit when the design should be on-brand, layouts that do not repeat, and a create-then-critique loop over the hosted Orshot MCP server. The shared craft base that every Orshot use-case skill loads when it creates or refines a template (posts, stories, carousels, ads, banners, thumbnails, video). Use when: "design a template for this", "make this template look less generic", "refine this design", "build an on-brand post template", "why does this look AI-made". NOT for rendering, batches or posting (use orshot) or for a whole job end to end (use its use-case skill, for example orshot-blog-images or orshot-ad-creative).

This skill is ready for commercial/non-commercial use.

## Use Case:

Designers, marketers, and developers use this skill to create or refine on-brand Orshot templates for social posts, ads, banners, thumbnails, and video. It guides visual hierarchy, typography, color, copy fit, layout variety, and motion before a template is rendered.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Shared or edited content may not be appropriate for the selected Orshot workspace, and validation renders can consume credits.

Mitigation: Use the intended workspace, upload only content you are permitted to share, preserve a copy before refining an existing template, and account for render costs when validating.
