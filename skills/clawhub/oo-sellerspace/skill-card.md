## Description:

SellerSpace helps agents search and read SellerSpace data through an OOMOL-connected SellerSpace connector.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External users and developers use this skill to inspect SellerSpace account data, including stores, marketplaces, products, advertising metrics, store performance, and FBA shipments through the OOMOL CLI connector.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: First-time setup includes remote installer commands that execute downloaded code directly.

Mitigation: Use a verified, signed, or manually reviewed oo CLI installation path before running SellerSpace connector commands.
