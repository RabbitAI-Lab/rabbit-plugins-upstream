## Description:

This skill helps agents spot and refine generic AI styling in UI, images, and game art.

This skill is ready for commercial/non-commercial use.

## Publisher:

[yysws5566](https://clawhub.ai/user/yysws5566)

### License/Terms of Use:

MIT-0

## Use Case:

Designers and developers use this skill to choose a distinctive visual direction, refine UI pages, and review visual work for generic AI styling. It provides practical guidance on typography, color, layout, accessibility, interaction states, and final polish.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Changes to existing styles or design files could overwrite user work.

Mitigation: Back up the original file to the workspace and get the user's agreement before replacing existing styles or design files.
