## Description:

Generate natural-sounding speech from text with Gemini 2.5 TTS through dLazy.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill to turn Mandarin or English text into spoken audio with selectable voices.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected file inputs are sent to dLazy's hosted service.

Mitigation: Avoid supplying sensitive text or files unless the service's data handling is acceptable.

Risk: Using the CLI requires an API key and may consume account credits.

Mitigation: Protect the API key, check available credits, and review costs before generation.

Risk: The documented output example shows an image despite this being an audio skill.

Mitigation: Confirm the actual result is audio rather than relying on the example's media type.
