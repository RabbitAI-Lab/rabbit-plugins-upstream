# Kandinsky — картинки, видео, говорящие аватары

Генерация и редактирование медиа через **Kandinsky API**: изображения по
описанию, правка готовых картинок, увеличение качества, короткие видео по тексту
или из фотографии, оживление изображений и говорящие аватары из фото и аудио.

Один Python-скрипт, только стандартная библиотека. Ни зависимостей, ни установки.

---

## Быстрый старт

**1. Задайте адрес и ключ.** Обе переменные обязательные, выдаёт их владелец
сервера Kandinsky API. Нет доступа — запросите его на **kandinsky@kandinskylab.ai**:

```bash
export KANDINSKY_API_BASE="http://ваш-сервер:5051"
export KANDINSKY_API_KEY="ваш-ключ"
```

Необязательно: `KANDINSKY_OUT_DIR` — каталог для готовых файлов. Без неё файлы
пишутся в текущий каталог, а под управлением агента — в служебный каталог
навыка. Никуда за пределы разрешённого каталога скрипт не пишет.

**2. Проверьте связь:**

```bash
python3 scripts/kandinsky.py health
```

**3. Рисуйте:**

```bash
python3 scripts/kandinsky.py t2i "закат в горах, кинематографично" -o out.png
```

Если навык стоит в агенте — то же самое обычными словами: «нарисуй закат в
горах».

> **Адрес обязателен:** без `KANDINSKY_API_BASE` навык не сделает ни одного
> запроса. Значения по умолчанию у него нет.

## Команды

| Команда | Что делает |
|---|---|
| `t2i "описание"` | текст → картинка |
| `i2i файл "что изменить"` | картинка + текст → изменённая картинка |
| `superres файл --upscale 2\|4` | увеличение качества |
| `t2v "описание" [--pro]` | текст → короткое видео |
| `i2v файл "движение"` | оживить картинку → видео |
| `avatar фото аудио` | говорящий аватар |
| `health` | проверка связи и настроек |
| `status` / `result <номер>` | долгие задачи: состояние и получение файла |

Результат сохраняется в файл из `-o`. Полный список флагов —
`python3 scripts/kandinsky.py --help`.

**Разрешения.** Картинка: `1024x1024` (по умолчанию), `768x768`, `768x1280`,
`1280x768`, `auto`. Видео: `512x512`, `512x768`, `768x512`, а с `--pro` —
`768x1280`, `1280x768`. У `i2v` вместо разрешения `--quality lite|sd|hd`.

## Как библиотека

```python
from kandinsky import Kandinsky

k = Kandinsky()                                  # адрес и ключ — из окружения
k.generate_image("кот в скафандре", out="cat.png")
k.animate_image("cat.png", "кот машет лапой", out="cat.mp4")
```

## Безопасность

- **Ключ уходит открытым текстом** в заголовке `Authorization: Bearer …`,
  поэтому обычный `http` на публичный адрес запрещён. Разрешены `https`,
  loopback и адреса внутри частных сетей.
- **Фильтр содержимого включён** и проверяет запрос, исходное фото и результат.
- **Скрипт читает только указанные файлы** и пишет только в файл из `-o`.
  Ничего не сканирует и никакой статистики не отправляет.
- **Ответ больше 200 МБ обрывается** — защита памяти от сбойного сервера.

## Частые сообщения

| Сообщение | Что означает |
|---|---|
| «Нет ключа» / «Не задан адрес API» | не заданы переменные окружения |
| «Ошибка авторизации» | ключ не подходит к этому серверу |
| «Небезопасный транспорт» | `http` на публичный адрес; нужен `https` |
| «Запрос отклонён цензурой» | сработал фильтр — переформулируйте запрос |
| «Задача застряла в очереди» | сервер не взял задачу; номер задачи есть в выводе |
| «В ответе результата нет медиа-данных» | задача завершилась пустой, повтор не поможет |

Долгую задачу можно забрать позже:

```bash
python3 scripts/kandinsky.py result <номер> -o out.mp4
```
