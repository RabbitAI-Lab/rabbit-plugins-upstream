# CLARIFY() 需求澄清

**Skill ID:** `zayn-clarify`
- 所属分类：客户沟通
- 一句话用途：识别客户需求中缺失、模糊、冲突或容易误解的信息，并生成最少但关键的澄清问题

CLARIFY() 用于识别客户需求中缺失、模糊、冲突或容易误解的信息，并生成最少但关键的澄清问题。它不负责直接报价，也不负责替客户补全需求。
