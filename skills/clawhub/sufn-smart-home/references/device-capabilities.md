# 设备类型与能力

以下内容仅用于内部意图映射，不向用户展示 model 或属性名称。

| 设备类型 | model | 可查询/控制能力 |
| --- | --- | --- |
| 开关、插座 | `kg` | 查询开关；开、关 |
| 单色灯 | `lamp_1` | 开关、亮度 |
| 色温灯 | `lamp_2` | 开关、亮度、色温 |
| RGB 灯 | `lamp_3` | 开关、亮度、HSL 颜色 |
| 单色 + RGB 灯 | `lamp_4` | 开关、亮度、HSL 颜色 |
| 全功能灯 | `lamp_5` | 开关、亮度、色温、HSL 颜色 |
| 窗帘 | `curtain` | 查询状态和开合度；全开、全关、停止、设置开合度 |
| 遮光窗帘 | `curtain_shade` | 窗帘全部能力，加查询/设置遮光度 |
| 空调 | `air_conditioner` | 查询开关、当前温度、设定温度、模式、风速；开关、设温、模式、风速及增量调节 |
| 已有场景 | `scene` | 列出和执行；禁止创建、修改或删除 |

灯具只有在 `deviceModels` 明确返回 `adjust` 时才允许微调；不要仅依据文档或设备名称假定支持。
