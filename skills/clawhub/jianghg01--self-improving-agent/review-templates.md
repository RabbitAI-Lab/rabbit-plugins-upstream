# Review Templates — 复盘与经验提取模板

## 失败复盘完整模板

每次触发复盘时，复制以下模板填写：

```markdown
## [失败复盘] YYYY-MM-DD HH:MM

### 基本信息
- **任务**: {任务描述}
- **错误类型**: {ENV|API|LOGIC|DATA|PERM|UX|PERF|FORMAT}
- **严重度**: {P0-阻断|P1-严重|P2-一般|P3-轻微}
- **影响范围**: {当前任务|同类任务|全局}

### 错误描述
{一段话描述发生了什么错误，包括错误信息原文}

### 5 Whys 根因分析
1. **为什么出现这个错误?** {直接原因}
2. **为什么会有这个直接原因?** {间接原因}
3. **为什么会遗漏这个环节?** {流程原因}
4. **为什么流程中没有检查点?** {系统原因}
5. **根本原因是什么?** {根因}

### 修正方案
- **治标**（立即修复）: {具体步骤}
- **治本**（防止再发）: {具体措施}

### 预防规则
{用一句话总结未来如何避免，格式："当{条件}时，必须{动作}"}

### 记忆写入
- [ ] L1: 已记入当前会话上下文
- [ ] L2: 已写入 memory/YYYY-MM-DD.md
- [ ] L3: 已晋升为永久规则（满足晋升条件时勾选）
```

## 批量复盘模板（Pro）

当需要一次性分析多个失败案例时使用：

```markdown
## [批量复盘] YYYY-MM-DD

### 案例汇总

| # | 日期 | 错误类型 | 场景 | 严重度 | 状态 |
|---|------|----------|------|--------|------|
| 1 | MM-DD | [TAG] | 简述 | P0-P3 | 已修复/待修复 |
| 2 | MM-DD | [TAG] | 简述 | P0-P3 | 已修复/待修复 |
| ... | | | | | |

### 交叉分析
- **共性根因**: {多个案例的共同根本原因}
- **模式识别**: {是否存在系统性的薄弱环节}
- **影响链**: {错误之间是否存在因果关系}

### 统一修正方案
{针对共性问题制定的一套修正方案}

### 预防规则（批量）
1. {规则1}
2. {规则2}
3. {规则3}

### 记忆写入
- [ ] L3 新增规则: {N} 条
- [ ] L3 更新规则: {N} 条
- [ ] 子Skill提取: {是/否} → {skill-name}
```

## 经验提取模板

当从复盘中提炼出可复用经验时：

```markdown
## [经验提取] YYYY-MM-DD

### 来源
- **复盘记录**: [链接或日期]
- **提取类型**: {错误预防|最佳实践|效率优化|用户偏好}

### 经验规则
**标题**: {一句话概括}
**适用场景**: {什么时候适用}
**具体规则**: {应该怎么做}
**反例**: {不应该怎么做}

### 验证状态
- **已验证场景**: {列出已验证的使用场景}
- **未验证场景**: {列出推测适用但未验证的场景}
- **置信度**: {★数量}/5

### 关联
- **相关规则**: {其他相关经验规则的引用}
- **相关Skill**: {是否已有相关Skill}
```

## 复盘质量检查清单

每次完成复盘后，对照检查：

```
复盘质量自检:
- [ ] 错误类型标签准确
- [ ] 5 Whys 触及了真正的根因（不是表面原因）
- [ ] 修正方案可立即执行（不是空洞建议）
- [ ] 预防规则已规则化表述（"当X时，必须Y"）
- [ ] 已写入对应层级的记忆
- [ ] 治本方案已评估可行性
```

## 错误类型速查表

| 标签 | 含义 | 典型场景 | 常见根因 |
|------|------|----------|----------|
| `ENV` | 环境配置 | 路径不存在、版本不兼容、依赖缺失 | 环境差异未检查 |
| `API` | 接口变更 | 端点404、参数变化、认证失败 | 未做版本兼容 |
| `LOGIC` | 逻辑缺陷 | 死循环、条件遗漏、边界错误 | 边界条件未覆盖 |
| `DATA` | 数据异常 | 空值、格式错误、编码乱码 | 输入校验缺失 |
| `PERM` | 权限不足 | 文件只读、API scope不够 | 权限预检缺失 |
| `UX` | 期望偏差 | 输出格式不符、内容方向错误 | 需求理解不充分 |
| `PERF` | 性能瓶颈 | 超时、内存溢出、响应慢 | 未做性能预估 |
| `FORMAT` | 格式/编码 | 中文乱码、日期格式、换行符 | 编码假设不一致 |
