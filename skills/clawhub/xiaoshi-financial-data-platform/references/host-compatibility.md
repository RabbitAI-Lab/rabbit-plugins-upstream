# 宿主平台兼容与降级

## 最低能力

完整运行需要宿主具备：

- 向 `https://api.shizixi.com` 发起 HTTPS GET/POST 请求；
- 让用户本人输入邮箱验证码并确认条款；
- 将认证响应中的 Key 作为敏感信息处理；
- 读取 JSON、下载文件并校验 SHA-256（历史下载任务需要）。

宿主若没有安全 Secret 存储，仍可完成当前会话的登录和查询，但不得把 Key 写入普通文件、聊天长期记忆、Skill 或系统提示词；下次重新走邮箱验证码登录。

## 推荐凭据入口

OpenClaw、QClaw 或兼容运行时可将已有 Key 放在受保护环境变量 `XIAOSHI_API_KEY`。该变量是可选的：未配置时走邮箱验证码登录。不得要求用户在公开聊天中粘贴 Key，也不得把 Key 写入仓库、`.env.example` 或安装包。

其他平台优先使用其原生 Secret、凭据或连接器存储。平台只提供普通文件存储时，不做跨会话保存。

## 网络与工具降级

- 只能 GET、不能 POST：可以读取公开 Manifest 与部分公开元数据，但不能完成登录、注册或认证查询；明确说明限制后停止认证流程。
- 无法限制凭据目标域：不要发起认证调用。
- 无法安全处理认证响应：不要请求验证码；提示用户换用支持 Secret/受保护凭据的平台。
- 无法直接下载限时对象：报告可用下载入口和限制，不把 API Key 附加到对象 URL。
- 宿主不支持远程 Skill 更新：继续使用已安装版本和当前公开 API 合约；让用户通过原商店或 Git 仓库升级。

## 平台适配原则

平台专属元数据只是增强项，不改变核心工作流。忽略不认识的 `agents/openai.yaml` 或 `metadata.openclaw` 字段是安全的。所有平台都必须保留用户确认、凭据不回显、域名白名单、限流停止条件和不执行交易的边界。
