## 二、动态过滤规则（核心，必须执行）

**纳入关键词（INCLUDE）**：招投标、招标、投标、采购、评标、否决、异议、投诉、国企、范本、文件、合规、实务、专家征集、法律案例、判例、地方政策、公共资源交易、电子招投标、CA签章、合同范本、行业范本、审计、纪检、巡视、负面清单、政策解读、司法解释

**排除关键词（EXCLUDE，命中即跳过）**：软考、论文、精益制造、备考、佛教、Dify、行业研究、信息系统项目管理师、高项、小说、股票、营销、私域、自媒体、考证、会计、考研

**自动判断逻辑**：新库名称或描述命中 ≥2 个纳入词，且不含任何排除词，则自动纳入本会话清单；命中任一排除词则跳过。纳入后按功能优先级进入路由表。

> 实践教训：本账户"我发布的"库已从 9 个膨胀到 13 个，混入了「软考高级论文素材 / 软考系统规划与管理师备考资料 / 精益制造全套99册」三个无关库。若不做排除，检索会污染招投标答案。**切勿假设"我发布的库都是招投标"。**

### 3.3 KB-L 降级行为（每轮重试 + 显式标注 + 恢复提示）

- KB-L 为**降级备用**：类案检索锦上添花，非主流程依赖。其检索失败 / 未挂载 / 返回空，**不中断主流程**。
- **每轮独立重试**：即便上一轮已标注 KB-L 不可用，本轮仍尝试检索 1 次，避免误判为长期不可用。
- **恢复提示**：若此前标注不可用、本轮重试成功 → 在【依据来源】首行主动提示：「法律案例库（KB-L）已恢复，类案推送功能已激活。」仅首次恢复当轮提示一次，避免反复打扰。
- **不可用标注**：重试仍失败 → 在【依据来源】末行显式标注，让用户知道"缺了这块信息"：
  > `注：法律案例库（KB-L）当前不可用，类案推送功能暂未激活。`
- 严禁用模型记忆脑补类案、伪造案号或裁判文书编号。

## 四、检索负载约束（重要）

- IMA `search_knowledge` 单次返回可达 **10 万+ 字符**（已实测 122K）。
- **只抽取** `title / introduction / highlight_content` 三类片段级字段，禁止整段灌入上下文。
- 使用 `cursor` 翻页（首页传 `""`），每库最多取前 2 页、每条目截取前 800 字高亮。
- 仅在需要原文时，才按 `media_id` 取全文（当前工具未暴露取全文接口，故以片段为准）。
- 并行检索上限 3 个库，避免 token 爆炸。

## 八、知识库使用铁律（知识治理层 · 固定基座）

本 skill 的知识治理规则作为检索融合与回答的硬性约束（已在 `system_prompt.md` 的 `<knowledge_governance>` 内注入运行时）。

**效力层级压制（两轴）**
- *法律位阶*：行政法规 > 部门规章 > 规范性文件 > 实务口径。
- *来源优先级（跨库冲突采信）*：KB-A 法规原文 > KB-B/X 实战口径 > KB-C/书籍 范本对照；KB-L 类案仅作参考，不与法规结论冲突；政府侧 KB-E/F 不纳入本 skill 检索范围。

**四大铁律（强制）**
1. **强制溯源**：每条引用标注 `【KB代号】` + 条文号（或条目名）；带 ima 返回的角标 [n]。
2. **盲区熔断**：检索为空时声明"当前知识库无相关信息"，严禁用模型记忆脑补法条、案号、编号。
3. **区域差异标注**：涉及地方性规定时注明"以下为全国性规定，具体执行以项目所在地要求为准"。
4. **KB-L 降级显式标注**：KB-L 不可用/未挂载时，在【依据来源】末行标注"注：法律案例库（KB-L）当前不可用，类案推送功能暂未激活。"——禁止静默跳过、禁止脑补类案。

**二次把关（融合层）**
- 无关召回片段（如问异议程序却召回"混凝土标号"）直接忽略，不强行拼凑。
- 同一问题跨库交叉验证（如 KB-A 与 KB-B）后再下结论。
- ima 连接器整体不可用 → 声明"知识库检索不可用，仅依据现行法规作答"，不编造。

> 实践教训：纯靠"ima 统一召回 + 模型事后噪音屏蔽"会被混入的无关库（软考/精益制造）污染；本 skill 在**检索层**用固定白名单 + INCLUDE/EXCLUDE 过滤，在**融合层**用四大铁律二次把关，双层防护。
