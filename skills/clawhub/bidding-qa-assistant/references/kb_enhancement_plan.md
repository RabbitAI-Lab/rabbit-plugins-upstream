## 二、建议额外挂载的库（按优先级）

### P0 — 立刻补强
1. **法律案例 / 裁判文书库**（IMA 广场搜索："招投标 案例"、"招标投标 判例"）
   - 用途：异议投诉、异常预警、综合法规引用真实案例。
   - 已有一个可选库：`7312638744735564 法律-法律案例`（6394 条），但需筛选出招投标相关片段。若发现更聚焦的"招投标/政府采购案例库"优先订阅。
2. **各地公共资源交易 / 招投标地方法规库**（搜索："北京 公共资源交易"、"广东 招标投标管理办法"）
   - 用途：操作引导、异常预警中给出地方具体规定。
3. **行业招标文件范本库**（搜索："信息化 招标文件范本"、"医院 招标 范本"）
   - 用途：范本推荐按行业细分，提升实用性。

### P1 — 中期完善
4. **合同范本库**（搜索："施工合同 范本"、"政府采购 合同 范本"）
   - 用途：合同条款、履约、变更、索赔问答。
5. **电子招投标 / CA 签章操作指南库**（搜索："电子招投标 操作"、"CA 签章"）
   - 用途：操作引导高频问题（解密失败、上传错误等）。
6. **审计 / 纪检 / 巡视问题清单库**（搜索："招投标 审计 常见问题"、"围串标 审计"）
   - 用途：异常预警，识别高风险操作。

### P2 — 可选增强
7. **最新政策解读 / 法规更新库**（搜索："招标投标法 修订"、"最新政策解读"）

## 三、挂载后的 skill 更新步骤

1. 在 IMA 中订阅/加入新库。
2. 重新触发本 skill，Step 0 会动态拉取新库；若新库名称命中 INCLUDE 关键词，会自动纳入清单。
3. 将新库按功能补充到 `ima_kb_catalog.md` 的"核验快照"与"路由表"中。
4. 更新 `system_prompt.md` 的 `<kb_routing>`（仅当新库成为某功能首选时）。
5. 在 `test_cases.md` 中新增 1-2 条用例覆盖新库。
6. 用 `package_skill.py` 重新打包。

## 四、动态发现扩展规则（未来库自动识别）

除当前 INCLUDE 关键词外，建议把以下词也作为纳入信号：
`法律案例、判例、裁判文书、地方政策、公共资源交易、电子招投标、CA签章、合同范本、行业范本、审计、纪检、巡视、负面清单、评标专家、政策解读、司法解释`

同时新增排除信号：
`小说、股票、营销、私域、自媒体、考证、会计、考研`

> 判断逻辑：新库名称或描述命中 ≥2 个纳入词，且不含排除词，则自动纳入本会话可用清单；命中任一排除词则跳过。

## 五、运营 SOP：新增纳入库人工复核（应对 INCLUDE 漂移风险）

INCLUDE 词表较宽（"采购 / 国企 / 合规 / 审计 / 纪检 / 巡视"等具多义性），存在"误纳入"可能——例如某《国企合规审计手册》因命中"国企+合规+审计"三词被自动纳入，但内容可能是企业内控而非招投标法规。

缓解原则：本 skill 以**固定白名单为基座**、新增库仅作"补充项"，核心检索不受污染；但建议在运营中增加一节：
1. 每周巡检 `session.kb_whitelist` 中的"动态补充项"，人工确认其确属招投标问答范畴。
2. 对误纳入库：加入 EXCLUDE 列表或从清单剔除，并同步更新 ima_kb_catalog.md 第二节。
3. 重大库变更 / 新增挂载后，跑 test_cases.md 全量回归（重点 T09 排除准确率、T13 动态发现、T15 KB-L 恢复）。
