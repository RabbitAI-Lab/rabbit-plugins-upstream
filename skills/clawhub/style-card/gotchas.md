# Gotchas · 生图实战坑清单（跨卡通用）

> 来源：style-card 三次闭环验证的实战积累。生成任何图前过一遍；
> 发现新坑（Phase B/D 中）随手回写到这里。

## 文字类

1. **中文/英文拼写错误高发**——生图模型写长词必错（实测 generate→gencate）。
   对策：槽位文字 ≤12 字；专有名词用引号包裹；生成后逐词检查拼写，
   错了就改 prompt 重生成，不要手动 P 图。
2. **主标题越长越容易崩**——像素/手绘类风格的主标题控制在 8 字符内（中文≤6字）。
3. **装饰性英文比正文英文稳**——窗口标题、品牌行用英文更有味道且不易错，
   正文说明用中文没问题，但别把长句塞进图形元素里。

## 结构类

4. **模型会幻觉加区块**——不写死数量，它就自作主张补内容（实测多出一格
   「Google Analytics」）。对策：prompt 明确"共 N 个区块，布局如下，不要增加"。
5. **槽位没填满的位置会被模型发明内容填充**——所有槽位必须显式给值，
   不留"类似即可"的模糊指令。

## 风格纪律类

6. **风格卡的「禁止出现」段必须写进生成 prompt**——只写在卡里不投喂，
   模型不知道（实测噪点纹理就是漏投喂导致）。
7. **强调色纪律靠数量约束**——"唯一强调色"类风格要写明"最多出现 N 处"，
   否则模型会到处撒高亮。
8. **风格迁移优先保"配色+构图"**——文字内容和参考图完全无关才是好验证；
   复现度评估看四项：配色还原 / 构图还原 / 元素还原 / 文字准确率。
