# 反推 Prompt：任意图 → 风格卡（Skill 核心引擎）

> 用法：把下面的 prompt 连同参考图一起发给视觉模型（Claude/GPT-4V/Gemini 均可），
> 得到一张结构化风格卡；风格卡里的「生成 Prompt」可直接填槽复用。

---

## 反推 Meta-Prompt

```
请分析这张图片的视觉风格，输出一张「风格卡」，严格按以下结构：

## 1. 一句话风格描述
用一句话概括这个风格，让人不看图也能想象出来。

## 2. 基础参数
画幅比例 / 适用场景 / 信息容量

## 3. 配色系统
列出背景色、主色、强调色的具体色值（估算 hex），以及整体质感
（如：做旧噪点 / 光滑渐变 / 纸张纹理）。

## 4. 构图布局
用 ASCII 线框图画出布局结构，标注每个区域的功能
（如：通栏标题带 / 2x2 网格 / 黑色强调块），并说明视觉动线和黄金位放什么。

## 5. 字体排印
标题字体特征 / 数据强调方式 / 正文排版 / 特殊符号用法。

## 6. 图形元素
插画风格、图标类型、描边、装饰元素。

## 7. 内容槽位
列出这张图里「可替换的文字位」，用 {槽位名} 标注，说明每个槽位的字数限制。

## 8. 生成 Prompt
综合以上所有分析，写一段可直接投喂给生图模型的完整 prompt，
内容槽位用 {} 保留，风格描述写死。要求：不参考原图的具体内容，
只保留风格，使填入任意新文本都能复现同风格作品。

注意：只分析风格，不要复述图片的具体内容含义。
```

---

## 封装成 Skill 的设计草案

**名称建议**：`style-card`（图生风格卡）

**输入**：参考图 1 张（可选：要套用的目标文本）

**流程**：
1. **反推**：视觉模型按 Meta-Prompt 输出结构化风格卡
2. **验证**（可选闭环）：用风格卡 + 测试文本生成一张图，对比参考图，差异点回写进卡片
3. **入库**：风格卡存为 `style-cards/风格卡_{名称}.md`，参考图一并存放，维护一份 `INDEX.md` 目录（名称/一句话风格/画幅/适用场景）
4. **复用**：用户给文本 → 按场景检索风格卡 → 填槽 → ImageGen 生成

**依赖能力**：读图（模型自带）+ 写文件 + ImageGen，全部现成，无需外部 API。

**和市面产品的差异**：
- 即梦/Liblib/CLIP Interrogator 的反推 = 输出一坨 prompt 文本，不可复用、无结构
- 本 skill = 结构化卡片 + 槽位模板 + 可积累的风格库，越用越厚
