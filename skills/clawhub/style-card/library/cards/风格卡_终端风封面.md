# 风格卡 · 终端风封面（Retro Terminal）

> 来源：WaytoAGI《CLI是什么》飞书文档封面海报
> 参考图：`../../assets/原图_WAYTOAGI终端风封面.jpg`
> 状态：已验证——换内容实测「POETRY/诗遇」，复现度 ~95%，噪点负面清单生效

---

## 1. 一句话风格描述

一张假装是终端截图的海报：macOS 终端窗口框里，像素彩虹大字母压阵，等宽字体排满元信息和一段 CLI 对话，极客味扑面而来。

## 2. 基础参数

| 项 | 值 |
|---|---|
| 画幅 | 16:9 横版 |
| 适用场景 | 技术文章封面、单观点海报、CLI/编程主题 |
| 信息容量 | 1 个大标题 + 3 行元信息 + 1 段对话 |

## 3. 配色系统

- 窗口底：深炭黑 `#1E1E1E`
- 标题栏：中灰 `#9E9E9E`，左起 macOS 三色圆点（红 `#FF5F57` / 黄 `#FEBC2E` / 绿 `#28C840`）
- 主标题：8 色霓虹彩虹轮换——红 `#FF4D4D`、橙 `#FF9F1C`、黄 `#FFD60A`、绿 `#3DDC84`、青 `#4CC9F0`、蓝 `#4361EE`、紫 `#9B5DE5`、粉 `#F15BB5`
- 正文文字：灰阶 `#8A8A8A` / 白 `#E8E8E8`

## 4. 构图布局

```
┌──────────────────────────────────────┐
│ ● ● ●   * {窗口标题，英文等宽}           │ ← 标题栏
├──────────────────────────────────────┤
│         ✨ {品牌行} ✨  （灰色小字居中）    │
│                                      │
│         {主标题·像素彩虹大字母}           │ ← 黄金位
│                                      │
│    {元信息1} / {元信息2} / {元信息3}      │
│                                      │
│  > {指令原文，可中文}                     │
│  ● {AI回复摘要行1}                      │
│  ● {AI回复摘要行2}                      │ ← 对话区
└──────────────────────────────────────┘
```

- 窗口居中占满画面，标题栏三圆点是不可省的身份元素
- 主标题在中轴线上，占画面高度约 1/4
- 对话区压在下半部，制造"真实截图"的叙事感

## 5. 字体排印

- 全图唯一字体族：等宽 monospace（JetBrains Mono / SF Mono 质感）
- 主标题：8-bit 像素粗体，字母间距紧，**每字母一色**按彩虹顺序轮换
- 像素字母带错位双重描边（同色 offset，复古 glitch 感）
- 元信息与对话：小号等宽，`>` 提示符、`●` 项目符号增强终端语法感

## 6. 图形元素

- 仅有的图形 = 终端窗口 chrome（标题栏 + 圆点），无任何插画
- 可选彩蛋：光标闪烁块 `▊`、`$` / `>` 提示符
- 拒绝一切装饰性图标——内容本身就是图形

## 7. 内容槽位

- `{窗口标题}`：英文等宽，格式 `* create xxx with xxx`（≤40字符）
- `{品牌行}`：如 `✨ WaytoAGI CLI ✨`（≤20字符）
- `{主标题}`：**≤8 个字母**的单词/缩写（如 WAYTOAGI），太长像素字母会挤
- `{元信息1-3}`：模型名/工具名/路径/日期，每项≤12字符
- `{指令原文}`：`>` 开头，可中文，≤40字
- `{AI回复}`：1-2 行摘要，每行≤30字

## 8. 生成 Prompt（可直接复制）

```
生成一张复古终端（Retro Terminal）风格的海报，16:9 横版：

1. 整体是一个 macOS 终端窗口，深炭黑色背景（#1e1e1e），
   顶部有灰色标题栏，左侧红黄绿三个圆形按钮，
   标题栏写等宽字体文字："{窗口标题}"
2. 窗口内居中偏上是主标题："{主标题}"，
   超大像素风（8-bit pixel）粗体字母，每个字母使用不同的
   霓虹彩虹色（红、橙、黄、绿、青、蓝、紫、粉依次排列），
   字母带错位双重描边，呈现复古 glitch 效果。
   字母必须是干净纯色块像素，无噪点、无雪花纹理
3. 主标题上方有一行居中的灰色等宽小字："{品牌行}"；
   主标题下方用灰色等宽小字排成**一行**（用 " / " 分隔，不换行）：
   "{元信息1}" / "{元信息2}" / "{元信息3}"
4. 画面下半部分模拟终端对话输出：
   一行以 ">" 开头的指令："> {指令原文}"
   下方一行 AI 回复式灰色等宽文字："● {AI回复}"
5. 所有文字使用等宽字体（monospace），英文单词拼写必须准确，
   整体像一张真实的终端截图，极客复古风，无其他装饰元素
```

## 9. 禁止出现（负面清单）

- ❌ 像素字母内混入 RGB 噪点/雪花纹理（实测首次生成就犯，已写入 prompt 规避）
- ❌ 主标题超过 8 个字母
- ❌ 圆角现代卡片、渐变、插画元素——窗口 chrome 之外不许有任何图形
- ❌ 非等宽字体出现
- ❌ 中文放进主标题（像素字体对中文支持差），中文只出现在对话区
