# 风格卡 · 杂志编辑风 Editorial

> 来源：2026 设计趋势自主挖掘（高端杂志排版）
> 状态：待验证（demo 随卡产出）

## 1. 一句话风格描述
衬线大标题 + 细网格 + 大留白 + 栏式排版，高端杂志封面/内页质感，克制、有分量。

## 2. 基础参数
| 项 | 值 |
|---|---|
| 画幅 | 3:4 竖 / 16:9 横 |
| 适用场景 | 深度长文配图、书评、个人 IP 调性、专栏 |
| 信息容量 | 刊名 + 大标题 + 引文 + 2-3 段正文 + 落款 |

## 3. 配色系统
- 底：暖米白 `#FAF6F0`；文字：炭黑 `#1A1A1A`
- 单一强调色：赤陶 `#C05B3D`（与 Bonnie 作品集一致）
- 细线分隔 `#E5DFD5`；全图 ≤2 色

## 4. 构图布局
```
┌──────────────────┐
│ 刊名 · 期号（小字）   │
│                  │
│   大标题（衬线，      │
│   居中或左对齐）      │
│   副标题/引文        │
│   ———— 细线 ————   │
│ 正文1 | 正文2（两栏） │
│   首字下沉可选       │
│   页脚：作者 · 日期    │
└──────────────────┘
```

## 5. 字体排印
- 标题：衬线（Noto Serif SC 900），大字；正文：无衬线 400
- 首字下沉、引文斜体、细线分隔是签名元素

## 6. 图形元素
- 细线、页脚横线、首字下沉字母；无 emoji、无插画

## 7. 内容槽位
- `{刊名/栏目}`、`{期号}`、`{大标题}`、`{副标题/引文}`、`{正文2-3段}`、`{作者/日期}`

## 8. 生成方式（engine: html）
html-base.css + html-template.md；Noto Serif SC（标题）+ Noto Sans SC（正文）；CSS Grid 两栏正文。

## 9. 禁止出现
- ❌ 超过 2 种颜色、❌ emoji/插画、❌ 圆角卡片、❌ 花哨装饰
