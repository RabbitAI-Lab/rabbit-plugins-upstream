# 风格卡 · 极简大字报 Bold Minimal

> 来源：2026 设计趋势自主挖掘（bold minimalism）
> 状态：已验证——首样「完成大于完美」复现度~98%，留白克制、强调色精准

## 1. 一句话风格描述
超大一句金句 + 巨量留白 + 单一强调色，字即图形，安静但有冲击力。

## 2. 基础参数
| 项 | 值 |
|---|---|
| 画幅 | 1:1 / 4:5 竖 |
| 适用场景 | 金句卡片、封面、单观点输出、引言分享 |
| 信息容量 | 1 句金句 + 1 个强调词 + 顶部标签 + 底部来源 |

## 3. 配色系统
- 底：纯白 `#FFFFFF` 或米白 `#FAFAF7`
- 文字：近黑 `#111111`；唯一强调色（高亮词/色块）任选一：赤陶 `#C05B3D` / 蓝 `#3B82F6`
- 无其他颜色

## 4. 构图布局
```
┌────────────────┐
│ [顶部小标签]     │
│                │
│  超大金句（占     │
│  60-70% 面积，    │
│  关键词换强调色）  │
│                │
│        [底部来源小字]│
└────────────────┘
```
- 大留白是核心：文字之外的区域保持干净

## 5. 字体排印
- 超粗黑体 900，字距紧；强调词换色或加下划粗线
- 顶部标签、底部来源用小号字

## 6. 图形元素
- 一条色块/下划线高亮、一个小标签；无插画、无图标堆砌

## 7. 内容槽位
- `{金句}`（≤18字）、`{强调词}`（≤6字）、`{顶部标签}`、`{底部来源}`

## 8. 生成 Prompt
```
极简大字报 Bold Minimal 风格海报，1:1 方形：纯白背景，巨量
留白。画面中央一句超大超粗黑体金句「{金句}」，占画面 60%
以上，其中关键词「{强调词}」用单一强调色（赤陶色）显示，
其余近黑色。左上角一个小号标签「{顶部标签}」，右下角一行
小字来源「{底部来源}」。无插画、无图标、无渐变、无阴影，
除了金句和一个强调色之外什么都不要，安静克制。
```

## 9. 禁止出现
- ❌ 多种颜色、❌ 装饰图标、❌ 渐变阴影、❌ 正文堆砌
