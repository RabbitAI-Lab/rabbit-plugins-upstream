# 风格卡 · 轻国风新中式

> 来源：2026 设计趋势自主挖掘（轻量化新中式 / 宋式美学）
> 状态：已验证（HTML demo 随卡产出）

## 1. 一句话风格描述
宣纸米白底 + 淡墨晕染 + 篆刻小章 + 大留白，简化传统纹样配现代细网格，清雅、克制、有书卷气，告别满版刺绣的老国潮。

## 2. 基础参数
| 项 | 值 |
|---|---|
| 画幅 | 3:4 竖 / 1:1 |
| 适用场景 | 文化科普、读书书评、节日节气、茶/香/非遗、个人 IP 调性、知识卡片 |
| 信息容量 | 大标题 1 + 副题 1 + 正文 2-3 段 + 落款/印章 |

## 3. 配色系统
- 底：宣纸米白 `#F5EFE0`；墨：炭黑 `#2B2B28`
- 主色（淡墨）：`#4A4A44`（正文灰墨）；次墨 `#6B6B62`
- 单一强调色：朱砂红 `#B54A35`（印章 / 关键点，全图 ≤3 处）
- 晕染：CSS 径向渐变模拟淡墨，透明度 0.06-0.12；无高饱和撞色

## 4. 构图布局
```
┌──────────────────────┐
│  竖排小字 / 栏目名（右上）   │
│                      │
│   主标题（衬线大字，      │
│   左对齐或居中，        │
│   可竖排）             │
│   ── 细线分隔 ──       │
│   正文1（一段）         │
│   正文2（一段）         │
│   关键词（小印章式点缀）   │
│         [朱砂印章/落款] │
└──────────────────────┘
```
- 大留白是灵魂：四周留白 ≥ 10%，核心信息集中在中上黄金位
- 印章落款放右下角，压住画面收尾

## 5. 字体排印
- 标题：衬线 `Noto Serif SC` 900，大字 72-96px，可竖排（writing-mode:vertical-rl）
- 正文：`Noto Serif SC` 400/600，行高 2.0-2.2，字距略松
- 栏目小字：`Noto Sans SC` 300，全角空格或竖排点缀

## 6. 图形元素
- 淡墨晕染（径向渐变圆斑）、细线分隔、篆刻印章（方形朱砂块 + 白字）
- 可选：简化山水/竹枝/月相等极简线性元素（CSS 形状，不堆砌）
- 无 emoji、无插画、无照片

## 7. 内容槽位
- `{栏目名}`、`{主标题}`（≤10 字，可换行）、`{副题/引文}`（≤20 字）
- `{正文1-2段}`（每段 30-80 字）、`{关键词1-3}`（各 ≤4 字，印章式）
- `{落款}`（作者/日期）、`{印章文字}`（1-2 字，白字朱底）

## 8. 生成方式（engine: html）
html-base.css + html-template.md；Noto Serif SC（标题/正文）+ Noto Sans SC（小字）；宣纸底 `#F5EFE0`，径向渐变做淡墨晕染；印章用方形朱砂块 + 白字居中；可选竖排标题。

## 9. 禁止出现
- ❌ 高饱和撞色 / 荧光色、❌ emoji、❌ 满版大花纹刺绣
- ❌ 直角粗边框卡片、❌ 噪点颗粒（保持宣纸素净）
- ❌ 超过 3 处朱砂强调色、❌ 竖排正文（正文保持横排可读）
