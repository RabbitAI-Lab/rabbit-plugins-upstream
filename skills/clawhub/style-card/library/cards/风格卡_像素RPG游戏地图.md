# 风格卡 · 像素 RPG 游戏地图

> 来源：用户剪贴板图「从 Coding 到 Builder：学习路径反过来了」
> 参考图：`../../assets/原图_像素RPG游戏地图.jpg`
> 状态：已验证——换内容实测「先发出去再说」，复现度 ~95%，文字基本零错

---

## 1. 一句话风格描述

把知识卡片画成一张 16-bit 像素 RPG 游戏地图：知识点是游戏窗口，学习路径是闯关路线，弹窗、进度条、存盘按钮全是叙事道具——道理变成了一场游戏。

## 2. 基础参数

| 项 | 值 |
|---|---|
| 画幅 | 4:3 横版 |
| 适用场景 | 路径对比、学习路线、方法论证、流程闯关 |
| 信息容量 | 1 个大标题 + 左右两条路径(各3-4步) + 中央弹窗 + 对比表 + 底部结论带 |

## 3. 配色系统

- 底色：奶油米白 `#F5EFDC`，四周留白边
- 地图层：草绿 `#7BB661`、土黄路径 `#E0C568`、湖蓝 `#5B9BD5`、深绿树丛
- 窗口 chrome：复古系统蓝标题栏 `#3B6EA5` + 白色 __ □ × 按钮、米白窗口底 `#F8F4E8`
- 强调块：粉红标题块 `#E8607A`、黑色警告框（红字红边）、绿色奖励框、黄星 ★
- 方向箭头：红箭头（旧路径）vs 绿箭头（新路径），颜色即立场

## 4. 构图布局

```
┌────────────────────────────────────────┐
│ 窗口大标题(文件名.EXE)  │  右上角色块口号      │ ← 顶部带
├──────────────┬──────────┬──────────────┤
│ 左：旧路径窗口链  │ 中央弹窗    │ 右：新路径窗口链    │
│ (标题黑框+3-4步) │ SYSTEM.   │ (标题黑框+3-4步)  │
│ 从"新手村"出发   │ MESSAGE   │ 通向"城堡"终点     │
│ ↓虚线箭头串联    │ 大字+OK钮  │ ↓虚线箭头串联      │
│ 骷髅警告框       │ +奖励进度条 │ 笑脸奖励框        │
├──────────────┴──────────┴──────────────┤
│ 对比总结窗口(左列VS右列+闪电)               │
├────────────────────────────────────────┤
│ ⚠ 核心思路一句话  │ LOADING ▓▓▓ 100%     │ ← 底部状态栏
└────────────────────────────────────────┘
```

- 黄金位：右上角色块口号、中央弹窗大字、底部核心思路
- 左右路径各带情绪锚点：旧路径挂骷髅头警告（红），新路径挂笑脸奖励（绿）
- 空隙用像素地图元素填充：树、河流、城堡、洞穴、小人、路牌

## 5. 字体排印

- 全图像素字体（中文像素黑体 + 英文像素体）
- 窗口标题一律用**文件名梗**：内容主题.后缀（CODE.PY / REWARD.EXE / 对比总结.TXT）
- 步骤编号 01 02 03 前缀；按钮文字全大写（OK / PLAY / SAVE）

## 6. 图形元素

- 复古系统窗口（蓝标题栏 + __ □ ×）是一切内容的容器，连大标题都装在窗口里
- 游戏道具：进度条（100% 绿块）、PLAY/SAVE 按钮、★ 星星、⚠ 警告、手型光标 ▲
- 地图物件：像素树、湖、城堡、洞穴、步道、背包小人、木路牌
- 虚线箭头串联步骤，实线大箭头标路径方向

## 7. 内容槽位

- `{顶部窗口标题}`：主题缩写.EXE（≤20字符）
- `{大标题}`：核心转变句（≤18字）
- `{右上口号}`：时代/主张名（≤8字）
- `{左路径名}`：旧方式 + 一句注释（≤14字）
- `{左步骤1-3}`：每步 `01 文件名.后缀` + 2行说明
- `{右路径名}` / `{右步骤1-3}`：同上
- `{中央弹窗}`：转折句大字（≤8字）
- `{左警告}` / `{右奖励}`：各≤12字
- `{对比表}`：左3条 VS 右3条，每条≤6字
- `{核心思路}`：≤20字

## 9. 禁止出现（负面清单）

- ❌ 禁止高清写实元素混入——一切物件必须像素化（锯齿边缘是身份）
- ❌ 禁止现代扁平设计窗口（圆角、阴影、毛玻璃）——只用 90 年代系统窗口 chrome
- ❌ 窗口标题必须用文件名梗，禁止用普通短句当窗口标题
- ❌ 步骤窗口数量写死（每侧 3 个），防止模型幻觉增删关卡
- ❌ 红绿立场不能反：红=旧路径/警告，绿=新路径/奖励
- ❌ REWARD.EXE 窗口只放进度条，奖励文案只出现在右侧绿色框——
   实测两处重复展示同一句文案（已验证发现的唯一结构偏差）
- ❌ 文字量大，生成后必查拼写（参考 gotchas：中文≤12字/槽位）
