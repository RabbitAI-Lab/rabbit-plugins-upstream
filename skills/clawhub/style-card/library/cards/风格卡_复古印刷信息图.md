**engine: html（双轨）**

---

## 1. 一句话风格描述

复古印刷 + 孟菲斯色块的信息图：奶油底上铺高饱和色块卡片，黑色粗描边扁平插画，大黑体标题，一图装 7-9 个知识点。

## 2. 基础参数

| 项 | 值 |
|---|---|
| 画幅 | 3:4 竖版（955×1280，小红书标准） |
| 适用场景 | 知识点合集、活动复盘、课程笔记、多要点总结 |
| 信息容量 | 7-9 个知识点区块 |

## 3. 配色系统

- 底色：奶油米白 `#F5EFE0`
- 通栏标题带：芥末黄 `#F2C230`（主标题底）、天蓝 `#9BD4E4`（副标题底）
- 区块色板（轮换）：珊瑚粉 `#F08A7E` / 天蓝 `#A8D8EA` / 芥末黄 `#F5D547` / 薄荷绿 `#A8E6CF` / 黑色 `#1A1A1A`
- 全图统一黑色粗描边（约 3-4px），复古印刷质感，轻微做旧噪点

## 4. 构图布局

```
┌─────────────────────────────┐
│  通栏主标题带（黄底黑字，特大号）      │
│  通栏副标题带（蓝底黑字，中号）        │
├──────────────┬──────────────┤
│  区块1（粉）   │  区块2（蓝）    │
├──────────────┴──────────────┤
│  区块3（黄，可横向大区块放数据）       │
├────────┬─────────┬──────────┤
│ 区块4    │ 区块5（黑底）│ 区块6      │
│（米白）   │ 强调/避坑  │（米白）     │
└────────┴─────────┴──────────┘
```

- 首行黄金位放「数据/意外发现」类最抓眼内容
- 黑底块固定放「避坑/警告」，形成视觉锚点
- 每个区块 = 小标题 + 图标插画 + 2-3 行要点

## 5. 字体排印

- 标题：超粗黑体（无衬线），通栏，字距紧
- 数据强调：超大号数字/符号（如「≤10人」占半格）
- 要点：中黑体，可配 ★ 列表、✓/✗ 对比
- 引用：引号 + 斜体英文原文 + 小字注释

## 6. 图形元素

- 扁平简笔插画：人物半身像、电脑/手机、奖杯、皇冠、笑脸、警告三角
- 图标统一黑色描边卡通风，可加 ✦ ✧ 星形装饰点缀
- 区块之间用色块天然分隔，无额外分割线

## 7. 内容槽位（换内容只改这里）

- `{主标题}`：活动/主题名（≤12字）
- `{副标题}`：亮点数 + 来源（如「N大核心洞察 | XX现场一手资料」）
- `{区块1-6}`：每个区块的小标题 + 图标主体 + 2-3 条要点

## 8. 生成 Prompt（可直接复制）

```
生成一张复古印刷风信息图海报，3:4 竖版：

1. 背景：奶油米白色（#F5EFE0），轻微做旧噪点质感，整体是复古印刷+孟菲斯色块风格，所有元素带黑色粗描边
2. 顶部通栏两条标题带：第一条芥末黄底（#F2C230）黑色超粗黑体大标题「{主标题}」；第二条天蓝底（#9BD4E4）黑色中号字体副标题「{副标题}」
3. 标题带下方 2x2 色块卡片网格（珊瑚粉/天蓝/芥末黄/薄荷绿底），每格一个知识点：
   - 区块1：「{区块1标题}」+ {图标描述} + 要点：{区块1要点}
   - 区块2：「{区块2标题}」+ {图标描述} + ★ 列表：{区块2要点}
   - 区块3 横向大区块：放最抓眼的数据「{核心数据}」超大号显示 + 简短说明
4. 底部三列：左列米白底「{要点A}」+ 奖杯图标；中列黑底白字「避坑提醒 WARNING ZONE」，用红叉✗和绿勾✓对比错误与正确做法；右列米白底「{要点B}」+ 黄色笑脸图标 + 一句引言
5. 所有插画为扁平简笔卡通风、黑色描边；文字全部用超粗黑体，层级分明；高信息密度但排版整齐
```

## 9. 禁止出现（负面清单）

- ❌ 不得自行增加区块数量——prompt 里写死区块数（"共N个区块，不要增加"），否则模型会幻觉出多余的格（实测多出过一格「Google Analytics」）
- ❌ 禁止照片级写实插画，只允许扁平简笔卡通
- ❌ 禁止细描边（<2px）和无描边——粗黑描边是本风格的身份
- ❌ 禁止渐变、玻璃拟态、阴影堆叠
- ❌ 区块底色不得重复相邻格（色板轮换是节奏感的来源）
