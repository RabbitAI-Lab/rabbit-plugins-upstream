# 风格卡 · 暗色霓虹 Dark Neon

> 来源：2026 设计趋势自主挖掘（dark mode / neon tech）
> 状态：已验证——首样「RAG外挂资料库」复现度~95%
> ⚠️ 实测坑：多张数据卡注释重复（三卡都写"答案有出处"）

## 1. 一句话风格描述
深空底色 + 霓虹光晕 + 细网格光点，科技海报质感，赛博但不浮夸。

## 2. 基础参数
| 项 | 值 |
|---|---|
| 画幅 | 16:9 横 / 1:1 |
| 适用场景 | 硬核技术科普、AI 概念、开发者向内容 |
| 信息容量 | 1 个大标题 + 1 句副标题 + 1-3 个关键数据/流程 |

## 3. 配色系统
- 底：深空蓝黑 `#0A0E1A`
- 霓虹主色：青 `#00FFE0`；辅色：品红 `#FF2E88`、紫 `#7B5CFF`
- 文字：白 `#E8F0FF`，关键数据霓虹发光
- 背景细网格线 + 光点

## 4. 构图布局
```
┌────────────────────┐
│  大标题（霓虹发光字）   │
│  副标题一行           │
│  ┌────┐ ┌────┐      │
│  │数据卡│ │数据卡│     │
│  └────┘ └────┘      │
│  流程/列表（细光边）    │
└────────────────────┘
```
- 标题居上，数据卡半透明黑底 + 霓虹描边，背景网格线增加纵深

## 5. 字体排印
- 科技感黑体/等宽（Space Grotesk / JetBrains Mono），标题发光
- 数据大数字 + 小注释

## 6. 图形元素
- 网格线、光点、霓虹描边、半透明卡片、发光分隔线

## 7. 内容槽位
- `{主标题}`、`{副标题}`、`{关键数据1-3}`、`{流程/列表}`

## 8. 生成 Prompt
```
暗色霓虹科技海报，16:9 横版：深空蓝黑背景（#0A0E1A），背景
有细网格线和稀疏光点。上方霓虹青色（#00FFE0）发光大字标题
「{主标题}」，一行白色副标题「{副标题}」。中间 2-3 个半透明
黑色数据卡，霓虹描边，卡片里是大数字「{数据}」发光 + 小字
注释。下方一条流程/列表，用霓虹紫（#7B5CFF）细光边分隔。
整体高质感科技感，光晕克制不刺眼，无噪点堆砌、无彩虹渐变。
```

## 9. 禁止出现
- ❌ 过亮渐变、❌ 彩虹堆砌、❌ 噪点过度、❌ 拟物写实
- ❌ 多张数据卡的注释必须各不相同——实测三卡副注释重复同一句，prompt 里逐卡写明注释内容
