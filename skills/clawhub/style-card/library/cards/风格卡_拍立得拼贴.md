# 风格卡 · 拍立得拼贴 Scrapbook

> 来源：2026 设计趋势自主挖掘（mixed-media / collage）
> 状态：已验证——首样「种一棵树」复现度~95%，胶带/别针/手写批注到位

## 1. 一句话风格描述
照片 + 和纸胶带 + 便签 + 手写批注 + 别针拼贴，温暖手工笔记本感，有"人的指纹"。

## 2. 基础参数
| 项 | 值 |
|---|---|
| 画幅 | 3:4 竖 |
| 适用场景 | 个人故事、生活感悟、书评、复盘、温暖向内容 |
| 信息容量 | 1 个手写标题 + 1-2 张拍立得 + 2 张便签 + 批注箭头 |

## 3. 配色系统
- 底：奶油纸 `#FBF7EF`（带轻微纸张纹理）
- 拍立得：白框照片；文字：手写黑/棕 `#2B2620`
- 胶带/便签马卡龙色：粉 `#F4B8C5`、黄 `#F5D547`、蓝 `#A8D8EA` 轮换

## 4. 构图布局
```
┌────────────────┐
│  [手写大标题]    │
│  ┌────┐ 便签    │
│  │拍立得│ [便签] │
│  │(斜放)│       │
│  └────┘  箭头批注 │
│  [胶带贴角] [别针] │
└────────────────┘
```
- 元素倾斜、重叠、错落，胶带固定照片四角，别针钉便签

## 5. 字体排印
- 手写体（ZCOOL KuaiLe），大小不一、轻微倾斜
- 批注用手写箭头 + 短句

## 6. 图形元素
- 拍立得照片（带白边框）、和纸胶带、便签纸、别针、手绘箭头、笑脸涂鸦

## 7. 内容槽位
- `{手写标题}`、`{照片1-2描述}`、`{便签1-2}`、`{批注箭头文字}`

## 8. 生成 Prompt
```
拍立得拼贴 Scrapbook 风格海报，3:4 竖版：奶油色纸张背景带
轻微纹理。一张拍立得照片（白边框）斜着贴在左上，四角用
马卡龙色和纸胶带固定，另 1-2 张便签纸用别针钉在右下，便签
上写手写小字「{便签}」。画面中央手写体大标题「{手写标题}」，
旁边画手绘箭头和批注「{批注}」。整体温暖手工笔记本拼贴感，
元素错落倾斜、有真实纸张和胶带质感，不要过度整洁。
```

## 9. 禁止出现
- ❌ 过度整洁/直角排列、❌ 电脑印刷字体、❌ 冷色调、❌ 照片写实过度
