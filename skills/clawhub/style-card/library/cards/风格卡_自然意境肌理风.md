# 风格卡 · 自然意境肌理风

> 来源：2026 设计趋势自主挖掘（自然意境肌理 / Japandi 静奢 / 松弛治愈）
> 状态：已验证——首样「每天 15 分钟」复现度~95%
> ⚠️ 实测坑：正文小字长句会错字（「积累」→「积果」）；小字在手机上偏糊，本卡定位收敛为「语录/金句卡」，去小字正文

## 1. 一句话风格描述
暖米白纸纹底 + 低饱和莫兰迪灰调 + 朦胧虚化的植物光影，大量留白、克制柔和，专为「一句语录/金句」打造的走心文案卡。

## 2. 基础参数
| 项 | 值 |
|---|---|
| 画幅 | 3:4 竖（实测最佳）/ 1:1 |
| 适用场景 | 语录文案、金句、书摘、生活感悟、朋友圈/小红书文案、个人 IP 调性 |
| 信息容量 | 1 句金句（可换行）+ 1 个作者落款，克制，别塞小字正文 |

## 3. 配色系统
- 底：暖米白纸纹 `#F2EFE9`（带细微纸张肌理）
- 主文字：深灰墨 `#4A4A44`
- 次文字：浅灰 `#9A978F`
- 氛围色：灰调植物绿 `#B5BFA8`（只出现在虚化剪影/光影里，不抢戏）
- 全图 ≤3 色，无高饱和

## 4. 构图布局
```
┌──────────────────────┐
│                      │
│   金句（墨灰大字，     │
│   居中偏上黄金位，     │
│   可换 2-3 行）       │
│                      │
│   落款（浅灰小字，     │
│   居中，作者/出处）    │
│                      │
│         （大留白）      │
│              🌿右侧     │
│         朦胧植物/光影    │
└──────────────────────┘
```
- 留白占 65% 以上，植物/光影只出现在画面一侧作氛围，不居中
- 视觉动线：金句 → 落款 → 氛围光影收尾；金句是唯一主角

## 5. 字体排印
- 金句：细腻衬线或极简无衬线（宋体感优先），墨灰色 `#4A4A44` 偏深，字号大、字距略松，保证手机上清晰可读
- 落款：浅灰小字，行距宽，克制不抢
- 无粗黑体、无发光字

## 6. 图形元素
- 朦胧虚化的植物剪影（绿植/枝叶）、柔和自然光影（窗光/斜阳感）、纸张纹理
- 仅此三类，无插画、无卡通、无 emoji、无图标

## 7. 内容槽位
- `{金句}`（≤16 字，可换 2 行，实测短句零错）
- `{落款}`（作者名/出处，≤8 字，浅灰小字）
- **不再设正文小字槽位**——小字糊且易错，语录卡不需要

## 8. 生成 Prompt（imagegen，中文版实测有效）
```
一张自然意境肌理风的语录卡片海报，竖版 3:4。低饱和莫兰迪灰调，
整体安静松弛、克制柔和。大面积留白，背景是暖米白纸纹底，画面
一侧有一株朦胧虚化的绿植剪影和柔和光影，营造淡雅氛围。画面
中上部是一句金句「{金句}」，用细腻的衬线或无衬线字，深灰墨色、
字号较大、字距略松、清晰可读、拼写正确，可换行但不要缩太小。
下方居中是浅灰小字落款「{落款}」。整体像一张有质感的日系走心
文案海报；无噪点堆砌、无高饱和撞色、无emoji、无插画、无卡通、
无大段小字正文。文字清晰、不糊、不拼错。
```
**槽位纪律**：金句 ≤16 字、逐字给定；落款 ≤8 字；明确"不要大段小字正文"。

## 9. 禁止出现
- ❌ 高饱和色、❌ emoji、❌ 插画/卡通、❌ 粗黑体、❌ 发光字
- ❌ 噪点堆砌、❌ 强视觉冲击构图、❌ 元素塞满
- ❌ **大段小字正文**——本卡只放一句金句 + 落款，小字正文易糊且错字
- ❌ 拼写错误——生成后逐词检查
