# 风格卡 · 液态玻璃质感

> 来源：2026 设计趋势自主挖掘（液态玻璃 / Liquid Glass / 软质 3D）
> 状态：已验证——首样「每天 15 分钟」复现度~95%，文字零错（含 3 个小字模块）
> ⚠️ 实测亮点：玻璃内部会折射出有机液态纹理，是本风格的意外加分项，prompt 里保留"果冻般软质 3D 感"可稳定触发

## 1. 一句话风格描述
半透明磨砂玻璃层 + 流动高光 + 彩色渐变折射，果冻黏土般的软质立体，通透、高级、有"摸得到"的质感。

## 2. 基础参数
| 项 | 值 |
|---|---|
| 画幅 | 3:4 竖（实测最佳）/ 1:1 / 16:9 横 |
| 适用场景 | 数码 3C、科技概念、AI 主题封面、金融科技、护肤美妆、高端知识卡 |
| 信息容量 | 主标题 1 + 副题 1 + 3-5 个玻璃信息模块 |

## 3. 配色系统
- 底：深空蓝紫渐变 `#0A0E1F → #1A1F3D`（或品牌深色）
- 玻璃层：半透明白 `rgba(255,255,255,0.10-0.18)` + 磨砂 backdrop-blur
- 流动高光：青 `#4FD1C5`、紫 `#A78BFA`、品红 `#F472B6` 渐变折射（作为光斑，非大面积）
- 整体质感：通透磨砂 + 柔和光泽，无噪点、无硬阴影

## 4. 构图布局
```
┌──────────────────────┐
│      主标题（大玻璃字）   │
│     [玻璃模块A] [玻璃模块B]│
│     [玻璃模块C] [玻璃模块D]│
│  底部：流动光斑 / 渐变折射 │
└──────────────────────┘
```
- 玻璃层只叠一层，不堆叠多层；背景渐变要够艳、对比要够
- 每个玻璃模块 = 圆角卡片 + 图标 + 一句说明，光斑点缀在模块角落

## 5. 字体排印
- 标题：无衬线粗体（Space Grotesk / Noto Sans SC 900），可做轻微膨胀/软质感
- 数据/关键词：大数字加粗，配柔和发光
- 正文：Noto Sans SC 400，浅色高对比（深底浅字）

## 6. 图形元素
- 半透明圆角玻璃卡片、流动高光条、彩色渐变折射光斑、柔和发光
- 可选：泡泡/软质 3D 物件点缀（果冻质感）
- 无锐利直角、无噪点、无重阴影

## 7. 内容槽位
- `{主标题}`（≤8 字）、`{副标题}`（≤20 字）
- `{玻璃模块1-N：图标+标题+一句说明}`（每模块标题 ≤6 字，说明 ≤15 字）
- `{关键词/大数字}`（1-2 个，发光强调）

## 8. 生成 Prompt（imagegen，中文版实测有效）
```
一张液态玻璃质感的知识卡片海报，竖版 3:4。深空蓝紫渐变背景
（#0A0E1F 过渡到 #1A1F3D）。画面主体是一块大面积的磨砂玻璃面板，
半透明白色表面、柔和模糊、边缘圆润膨胀，表面有流动的高光，折射出
青色（#4FD1C5）、紫色（#A78BFA）、品红（#F472B6）的光斑。主标题
「{主标题}」用粗圆体无衬线字，柔和发光，字形完整清晰、拼写正确。
下方 {N} 个圆角玻璃模块排成一行，每个模块内是图标加一句短说明：
{模块1：图标+说明}、{模块2：图标+说明}、{模块3：图标+说明}。
整体有果冻般软质 3D 感，通透、高级、有触感；无锐利直角、无噪点
颗粒、无硬阴影、无插画、无照片；玻璃层只叠一层；光斑色不超过三种。
文字清晰、不糊、不拼错。
```
**槽位纪律**：主标题 ≤8 字；每个模块说明 ≤8 字（实测 8 字内零错）；
模块数量写死「共 N 个，不要增加」。
英文版 prompt（备用）：见 git 历史 / 按 reverse-meta-prompt.md 反推。

## 9. 禁止出现
- ❌ 锐利直角 / 硬阴影、❌ 噪点颗粒、❌ 玻璃层堆叠多层
- ❌ 大面积荧光铺底、❌ 插画 / 照片、❌ 文字拼写错误（生成后逐词检查）
- ❌ 超过 3 种折射光斑色
- ✅ 实测通过项：中文小字 8 字内准确率高；「果冻软质 3D」关键词是质感稳定器
