# 风格卡 · 手绘白板涂鸦风（概念科普图）

> 来源：用户剪贴板图「软件行业的集体转向：AI Agent 时代的 CLI 复兴」
> 参考图：`../../assets/原图_手绘白板涂鸦风CLI复兴.jpg`

---

## 1. 一句话风格描述

像聪明人在白板上边讲边画：黑墨线稿涂鸦 + 荧光黄高亮笔一个强调色，简笔小人和机器人出演，箭头串起逻辑流，一眼看完一个概念。

## 2. 基础参数

| 项 | 值 |
|---|---|
| 画幅 | 4:3 横版 |
| 适用场景 | 概念解释、前后对比、公式化表达、流程推演 |
| 信息容量 | 1 个大标题 + 1 组对比 + 1 个公式 + 1 条逻辑链 + 1 句结论 |

## 3. 配色系统（极简双色）

- 底色：纸白/米白 `#FAFAF5`
- 线稿：黑墨 `#1A1A1A`（线条粗细随性，像马克笔手绘）
- 唯一强调色：荧光黄高亮 `#E8F04A`（只用在关键词涂抹、高亮条、箭头描边上）
- 无渐变无阴影，最多一层浅灰 `#D9D9D0` 辅助

## 4. 构图布局

```
┌─────────────────────────────────┐
│  大标题（黑手写体，关键词带荧光黄涂抹块）│
├───────────────┬─────────────────┤
│ 左：过去/旧世界   │  右：现在/新世界    │
│ 场景插画+要点文字  →  大空心箭头  →  场景插画+要点 │
├─────────────────────────────────┤
│ 「关键公式」高亮条（整行荧光黄底）      │
│ 公式图示：A图标 + B图标 = C图标        │
├─────────────────────────────────┤
│ 逻辑流程带：角色A --气泡--> 中枢图标 --手绘弯箭头--> 多个去向 │
├─────────────────────────────────┤
│  结论带（荧光黄高亮）：一句话本质总结      │
└─────────────────────────────────┘
```

- 黄金位：大标题关键词、关键公式、结论——三处都必须有荧光黄
- 对比区左右各配一个"主角"插画（如：工程师小人 vs 圆头小机器人）
- 箭头承担叙事：直箭头=转变，弯箭头=流向，气泡=台词

## 5. 字体排印

- 全图手写体气质：标题特大、正文中小号，像快速板书
- 强调方式不是加粗变大，而是**荧光黄涂抹块垫底**
- 台词放对话气泡里，口语化短句（如「你动嘴」「它动手」）

## 6. 图形元素

- 简笔火柴人（圆头、线条身体）+ 圆头小机器人（天线、方块身体）
- 手绘图标：终端窗口 `[>_]`、齿轮、工具箱、日历、放大镜、桥梁
- 一切线条微微歪斜、不闭合，保留手绘涂鸦感，拒绝工程制图的精确

## 7. 内容槽位

- `{大标题}`：主题句，含一个可高亮的关键词（≤16字）
- `{左标题}` / `{左要点}`：旧世界
- `{右标题}` / `{右要点}`：新世界
- `{转变箭头文字}`：一句话点破变化（如「软件用户变了」）
- `{公式}`：A + B = C 形式，每项≤8字
- `{角色台词}`：2-4 个气泡短句
- `{结论}`：本质总结一句话

## 8. 生成 Prompt（可直接复制）

```
生成一张手绘白板涂鸦风格的科普信息图，4:3 横版：

1. 背景：纸白色（#FAFAF5），全部元素为黑色墨水手绘线稿，
   线条粗细随性、微微歪斜，像聪明人在白板上边讲边画；
   全图唯一强调色是荧光黄高亮笔（#E8F04A）
2. 顶部大标题：黑色手写体「{大标题}」，其中关键词用荧光黄
   涂抹高亮块垫底
3. 中部左右对比：左侧标题「{左标题}」+ 简笔工程师小人 +
   场景涂鸦（{左要点}）；右侧标题「{右标题}」+ 圆头小机器人 +
   场景涂鸦（{右要点}）；中间一个大空心手绘箭头，箭头上写
   「{转变箭头文字}」
4. 下方一条通栏荧光黄高亮条写「关键公式：{公式}」，
   公式下方配手绘图标图示：A图标 + B图标 = C图标
5. 再下方是逻辑流程带：{角色A}小人带对话气泡「{台词1}」，
   手绘弯曲箭头流向中央的终端窗口图标「[>_]」（下方标注
   {中枢标注}），再用手绘弯箭头分发到 2-3 个去向，每个去向
   配小图标和气泡「{台词2}」
6. 底部结论带：荧光黄高亮「{结论}」，旁边配一个手绘桥梁
   或连接类小图标
7. 无渐变无阴影，拒绝精确制图感，保持涂鸦笔记的松弛感
```

## 9. 禁止出现（负面清单）

- ❌ 禁止精确制图感：直尺般笔直的线、完美闭合的圆、工程 CAD 质感——一切线条要歪、要松弛
- ❌ 除荧光黄外禁止出现任何彩色（实测该卡色彩纪律极好，勿破坏）
- ❌ 禁止渐变、阴影、纹理填充
- ❌ 禁止写实人物，只允许火柴人和圆头机器人
- ❌ 荧光黄不得大面积铺底超过 3 处（标题关键词/公式/结论），滥用会失去强调作用
