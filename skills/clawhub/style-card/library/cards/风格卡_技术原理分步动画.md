# 风格卡 · 技术原理分步动画图

> 来源：公众号「赛博禅心」《DeepSeek 开源推理框架》文内动图
> 参考图：原图版权归原作者，未随仓库分发；风格特征见下方各段
> 状态：待验证（demo 已随卡产出，见 examples/）

---

## 1. 一句话风格描述

让技术原理"动起来"的极简流程动画：灰白节点图上，一个 token 小药丸沿着箭头逐站流动，走到哪亮到哪，底部步骤条同步讲解放到第几步——一篇长文的核心机制被压缩成 10 秒动图。

## 2. 基础参数

| 项 | 值 |
|---|---|
| 画幅 | 16:9 或 1:1（正方形也常见，适配公众号/小红书） |
| 适用场景 | 技术原理讲解、系统流程、机制对比、公众号配图 |
| 信息容量 | 4-8 个节点 + 3-6 个步骤 + 每步一句说明 |

## 3. 配色系统

- 底色：纯白 `#FFFFFF`（外框米白 `#FAFAF7`）
- 正文：近黑 `#1A1A1A`
- 唯一强调色：蓝紫 `#4B5BDC`（当前节点描边、token 药丸、关键数字、命中高亮）
- 高亮容器：极浅紫 `#EEF0FF`；次级卡片：浅灰 `#F5F5F7`
- 语义色（少量）：浅绿 `#E8F5EE` 正确/命中、浅红 `#FDEBEC` 错误/未命中
- token 元素：小药丸/小方块徽章，黑底白字或蓝紫底白字

## 4. 构图布局

```
┌─────────────────────────────┐
│  标题（黑粗体，居中或左上）        │
├─────────────────────────────┤
│                             │
│   节点流程图（横向或纵向）：        │
│   [用户] → [服务A] → [核心节点]   │
│              ↓               │
│   [辅助节点]  [核心节点B]         │
│              ↓               │
│   [存储/输出节点]                │
│                             │
├─────────────────────────────┤
│ 第 N 步 / 共 M 步（蓝紫小字）      │
│ 该步骤的一句说明（灰底条）         │
└─────────────────────────────┘
```

- 节点 = 白底圆角框 + 细灰边 + 主标题 + 灰色小注释（如「Prefill·读取输入·8 卡服务器」）
- 箭头上可挂小字标签（如「KV」「写入缓存」）
- 数据卡变体：2x2 大数字网格（大数字蓝紫 + 黑色小注释）

## 5. 动画语言（本卡的灵魂，静态图没有的部分）

1. **token 流动**：一个小药丸沿箭头路径逐节点移动，每站停顿 ~1.5s
2. **当前节点高亮**：正在工作的节点边框变蓝紫 + 微发光，其余保持灰白
3. **步骤推进**：底部「第 N 步 / 共 M 步」+ 说明文字随流动同步切换
4. **渐次浮现**（对比类变体）：多张堆叠卡片从灰到亮逐块淡入，token 方块逐个弹入
5. 循环播放，节奏克制——每步 1.5-2s，整轮 8-12s，无弹跳夸张动效

## 6. 字体排印

- 标题：黑体 900，24-32px
- 节点主标题：700，16-20px；节点注释：400 灰色 12-14px
- token 徽章：等宽字体（JetBrains Mono），键盘键帽样式
- 步骤条：等宽小字「STEP N / M」或中文「第 N 步 / 共 M 步」

## 7. 内容槽位

- `{标题}`：机制名（≤16字）
- `{节点1-N}`：每个节点 = 名称 + 一行注释（名称≤6字，注释≤14字）
- `{路径}`：token 流动的节点顺序
- `{步骤1-M}`：每步 = 当前节点 + 一句说明（≤20字）
- `{对比组}`（可选变体）：普通方案 vs 优化方案两卡堆叠

## 8. 生成方式（engine: html-anim）

本卡不用 ImageGen——动画必须手写 CSS。用 `references/html-base.css` 底座 +
`references/html-template.md` 的「动画模式」节，产出自循环播放的单文件 HTML。

**动画实现要点**：CSS `@keyframes` 按总时长编排所有动作（如 10s 一轮）；
token 移动用 `offset-path: path('M...')` 或逐段 translate 过渡；
节点高亮和步骤文字切换用同一时间轴的 keyframes 百分比控制，保证严格同步。

导出：① HTML 直接交付（微信里录屏/另存为 GIF）；
② 或 Playwright 逐帧截图 + ffmpeg 合成 GIF（后续可加脚本）。

## 9. 禁止出现（负面清单）

- ❌ 禁止插画、照片、渐变彩块——全部用「白底圆角框 + 细边 + 灰字」的语言
- ❌ 强调色只有蓝紫一种，语义绿/红只用于命中/失败，不得装饰用
- ❌ 动效禁止弹跳、旋转、缩放夸张——只用位移、透明度、描边色变化
- ❌ 节点超过 8 个就得拆图——一图只讲一条链路
- ❌ 步骤说明每步 ≤20 字，动画节奏每步 ≥1.5s，不许快闪
