# 风格卡 · 便当盒 Bento Grid

> 来源：2026 设计趋势自主挖掘（Apple 式模块布局）
> 状态：待验证（demo 随卡产出）

## 1. 一句话风格描述
大小不一的圆角模块拼成网格，每个模块是一张独立小卡（标题 + 一句说明 + 图标），Apple 发布会式的清爽现代感。

## 2. 基础参数
| 项 | 值 |
|---|---|
| 画幅 | 1:1 / 4:3 |
| 适用场景 | 作品集、技能清单、资源汇总、个人 IP 站、多模块导航 |
| 信息容量 | 1 个标题卡 + 4-8 个模块 |

## 3. 配色系统
- 底：米白 `#F7F7F7`；卡片：纯白 `#FFFFFF`
- 圆角 18-24px，细描边 `#E5E5E5`
- 单一强调色：蓝 `#3B82F6`（或按品牌换赤陶 `#C05B3D`），大数字/重点用它
- 极浅阴影 `0 4px 16px rgba(0,0,0,.05)`

## 4. 构图布局
```
┌──────────────┬───────────┐
│ 标题卡（横跨）             │
├──────┬───────┼───────────┤
│ 大卡  │ 小卡   │ 小卡      │
│(2x2) │       │           │
│      ├───────┼───────────┤
│      │ 小卡   │ 小卡      │
└──────┴───────┴───────────┘
```
- 一块大卡（2x2）放核心/成果，其余 1x1 小卡
- 每卡 = 图标(emoji) + 标题 + 一行说明，重点卡可加大数字

## 5. 字体排印
- 圆体/中黑体（Noto Sans SC 700），卡片标题 18-22px，说明 14px 灰
- 大数字用 900 粗体

## 6. 图形元素
- emoji 图标（每卡一个）、大数字、小进度条可选
- 无插画、无照片

## 7. 内容槽位
- `{主标题}`、`{副标题}`、`{模块1-N：图标+标题+一行说明}`、`{核心大卡：大数字+说明}`

## 8. 生成方式（engine: html）
用 html-base.css + html-template.md，CSS Grid 实现模块网格；圆角/描边/阴影按第 3 段。导出 PNG。

## 9. 禁止出现
- ❌ 直角、❌ 阴影过重、❌ 单卡塞 3 行以上文字、❌ 超过 2 种强调色
