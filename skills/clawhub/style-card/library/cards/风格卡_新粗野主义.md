# 风格卡 · 新粗野主义 Neo-Brutalism

> 来源：2026 设计趋势自主挖掘（manypixels / strate 等）
> 状态：已验证——首样「每天15分钟」复现度~95%，硬阴影/星爆/胶囊全部到位

## 1. 一句话风格描述
粗黑描边 + 硬实心阴影 + 高饱和撞色 + 超大无衬线粗字，像一张"故意没打磨"的宣言海报，反 AI 味、一眼抓人。

## 2. 基础参数
| 项 | 值 |
|---|---|
| 画幅 | 3:4 竖 / 1:1 |
| 适用场景 | 观点输出、避坑警告、必知内容、强立场单页 |
| 信息容量 | 1 个大标题 + 1 句副句 + 2-4 个标签/数据 |

## 3. 配色系统
- 底：白 `#FFFFFF` 或单一撞色底（亮黄 `#FFE600`、亮粉 `#FF5FA2`、天蓝 `#4CC9F0` 选一）
- 描边：纯黑 `#000000`（3-4px 粗）
- 硬阴影：纯黑，`offset 6-8px`，**无模糊**
- 强调块：草绿 `#7CE38B`、橙 `#FF8A3D` 轮换

## 4. 构图布局
```
┌──────────────────┐
│ [胶囊标签]         │
│ 超大标题（占上半，     │
│  可斜置/叠字）        │
│ 副句一行            │
│ [色块按钮] [胶囊标签]  │
│ ★ 星爆/箭头 点缀      │
└──────────────────┘
```
- 元素允许重叠、越界、斜置——秩序来自"冲突感"
- 标题占画面 50% 以上

## 5. 字体排印
- 超粗无衬线黑体（900），全大写或超大中文字，字距紧
- 强调词用反白（黑底白字块）或下划线粗条

## 6. 图形元素
- 胶囊标签、色块按钮、★星爆、加粗箭头、手绘下划线高亮条
- 无插画、无照片、无渐变

## 7. 内容槽位
- `{主标题大字}`（≤12字）、`{副句}`（≤20字）、`{标签1-3}`、`{数据/对比}`

## 8. 生成 Prompt
```
新粗野主义 Neo-Brutalism 风格海报，3:4 竖版：纯白背景，一个
撞色色块（亮黄/亮粉/天蓝任选）做点缀。超大超粗无衬线黑体
主标题「{主标题}」占画面上半，黑色粗描边（4px）+ 纯黑硬实心
阴影（offset 8px，无模糊）。下方一句副句「{副句}」。底部放
2-3 个胶囊标签「{标签}」和一个色块按钮，配 1-2 颗 ★ 星爆和
粗箭头点缀。元素允许轻微重叠和斜置，冲突感即秩序。无渐变、
无模糊阴影、无插画照片，反 AI 模板味。
```

## 9. 禁止出现
- ❌ 圆角（只许小圆角或直角）、❌ 渐变、❌ 模糊/柔和阴影、❌ 细字
- ❌ 居中对称的模板脸、❌ 插画照片
