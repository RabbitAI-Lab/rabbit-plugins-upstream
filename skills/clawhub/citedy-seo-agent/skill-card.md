## Description: <br>
Citedy SEO Agent connects an agent to Citedy for trend research, competitor analysis, content-gap discovery, SEO article generation, social adaptations, lead magnets, URL ingestion, search performance reports, and automated publishing. <br>

This skill is ready for commercial/non-commercial use. <br>

External users, marketers, and developers use this skill to connect an agent to Citedy for SEO research, article generation, social-media adaptation, publishing workflows, and recurring content automation. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can publish publicly and create recurring automation without consistently requiring explicit confirmation. <br>
Mitigation: Require confirmation of destinations, visibility, schedule, and expected credit impact before publishing, creating sessions, deleting content, changing settings or webhooks, rotating keys, or running expensive generation. <br>
Risk: The skill requires a Citedy API key and can operate against connected marketing, social, search, and content accounts. <br>
Mitigation: Install only when Citedy account access is intended, keep the API key out of chats and logs, and revoke the key from the Citedy dashboard when access is no longer needed. <br>
Risk: Content generation, trend scouting, and publishing workflows can spend Citedy credits. <br>
Mitigation: Review credit costs before expensive operations and keep spend and cadence limits configured in the Citedy dashboard. <br>
