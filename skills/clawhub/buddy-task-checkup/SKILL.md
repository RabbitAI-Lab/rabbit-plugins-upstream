# 你的Buddy定时任务体检了吗？

## 这是什么

你给 AI 助手定了一堆定时任务：每天播报、每周总结、定时提醒……定完之后呢？**没人检查**。空跑的、重复的、产出没人看的任务在悄悄烧时间和注意力。这套**定时任务体检法**像体检一样照见现状：哪里健康、哪里带病、哪里缺位，一次看清。

## 五步体检

1. **盘点列清单**：把所有定时任务列成一张表——名称、干什么、多久跑一次、上次跑出什么。列不全，体检就没做。
2. **三类逐条判**：
   - **空跑**：任务在跑，但没产出、产出没变化、或者跑了等于没跑——白烧。
   - **重复**：两条以上任务盖着同一件事——留一条、合并其余，别让两个闹钟叫同一件事。
   - **没人看**：产出正常，但没人消费——报告没人读、播报没人点。产出没人看，等于没产出。
3. **出三色报告**：红（该停）、黄（该改）、绿（健康），每条一句话理由。报告一眼扫完，不写论文。
4. **空白清单**：这段时间反复出现、却没有任何任务在接的活——这是需求信号。逐条列出建议新建的任务：干什么、多久一次、给谁看。
5. **处置落地**：红的关停或降频，黄的合并改写，空白按优先级补位。**体检不做处置，等于白检。**

## 数据怎么处理（四道闸门）

1. **本地处理**：盘点与判定全程在你机器上做，原始任务内容不出机器。
2. **统计回流**：默认关。要开必须专门弹窗、单独同意；只留「哪类任务多少件」的计数，不留任何原文；随时可撤回。
3. **一键反馈**：只有你主动点反馈才外发，内容是你自己选定的那一条。
4. **内测自愿**：内测邀请自愿报名、按模板交，绝不自动收。

平台官方本来就给聚合统计（对话次数、使用人数、收藏、调用），先用足官方的；自建回流只补内容型信号，能不收就不收。

## 看板字段

体检结果建议按六列看板呈现：**名称 / 序号 / 干什么 / 开关 / 何时开关 / 触发条件**——精美简洁，一眼扫完。

## 一句话节奏

盘点 → 三类判 → 三色报 → 空白列 → 处置落地。

## 止损线

体检报告出完没人处置，报告本身就变成了「没人看」型任务——给自己也定一条处置提醒，出报告当天就动手。
