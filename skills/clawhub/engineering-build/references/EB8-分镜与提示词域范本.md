## EB8 分镜与提示词域范本

### 一、领域知识要点

- 分镜要素：镜号、景别（远/全/中/近/特）、运镜（推/拉/摇/移/跟/升降）、时长、画面内容、台词/字幕、音效
- 镜头语言：景别表意（特写=情绪、全景=环境）、轴线规则、越轴、正反打
- 蒙太奇：叙事剪辑、表现剪辑、交叉剪辑
- AI 图像提示词结构：主体 + 属性 + 环境 + 构图/镜头 + 光线 + 风格 + 画质词 + 负向提示
- AI 视频提示词：镜头运动 + 主体动作 + 场景变化 + 时长，需描述变化而非静态
- 工具差异：Midjourney（参数化 --ar/--style）、Stable Diffusion（权重/采样器）、即梦/Seedance（中文语义）

### 二、判定标准

- 每个镜头须给景别、运镜与时长
- 画面描述须可拍摄，禁止抽象情绪词
- 提示词须结构化，不得堆砌形容词
- 分镜须与脚本节奏对齐

### 三、范本结构

1. 脚本拆解
2. 分镜表（镜号/景别/运镜/时长/画面/台词）
3. 视觉风格定义
4. 提示词清单
5. 生成参数
6. 一致性控制

### 四、常见失范

- 只写文案不写画面
- 提示词全是形容词无具体元素
- 镜头无逻辑跳接
- 忽略时长与节奏

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 镜头序列、景别规划、节奏曲线、时长分配 |
| 本域产出 | 镜头规划表；分镜表；提示词清单；视频提示词集；风格锚定规范 |
| 下游可用 | 风格锚定规范 |

### 七、执行卡（以「脚本拆解与镜头规划」为例）

**开工前备齐**：镜头序列、景别规划、节奏曲线、时长分配

**可选补充**：脚本、参考片

**按序执行**：

1. 读脚本
2. 分场
3. 拆镜
4. 定景别
5. 排节奏

**交付前核对**：镜头须服务叙事；不得无意义切换

**成品须符合**：镜头规划表

按「镜头规划表」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
## 4. 提示词清单
## 5. 生成参数
## 6. 一致性控制
```

**齐备要求**：必选组件「镜头序列、景别规划、节奏曲线、时长分配」须全部落位；约束「镜头须服务叙事；不得无意义切换」须逐条成立；可选「脚本、参考片」按需补充。
