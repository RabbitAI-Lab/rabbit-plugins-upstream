## EB9 视频剪辑域范本

### 一、领域知识要点

- 剪辑语法：剪辑点（动作、视线、声音）、J-cut/L-cut、节奏与呼吸
- 结构：钩子（前3秒）→ 铺陈 → 高潮 → 收束 → CTA
- FFmpeg 核心：-i 输入、-ss/-t 截取、-vf 滤镜（scale/crop/fps/subtitles）、-c:v libx264 -crf 码控、concat 拼接
- 字幕：SRT/ASS 格式、时间轴对齐、烧字幕 vs 外挂
- 自动剪辑：静音检测切分、场景检测、关键帧抽取、精彩片段打分
- 程序化视频：Remotion（React 组件即视频）、帧驱动渲染
- 导出规范：分辨率、帧率、码率、色彩空间、平台适配（竖屏 9:16 / 横屏 16:9）

### 二、判定标准

- 成片须匹配目标平台的分辨率与时长
- 剪辑点须服务节奏，不得机械等长
- 字幕时间轴误差须在 ±0.2s 内
- 导出参数须与平台推荐一致

### 三、范本结构

1. 剪辑脚本与结构
2. 素材清单与时间轴
3. 剪辑点说明
4. 字幕文件
5. 导出参数
6. 成片与工程文件

### 四、常见失范

- 前3秒无钩子导致流失
- 字幕与语音错位
- 导出码率过低导致糊
- 音画不同步

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 结构表（段落/时长/内容）、节奏曲线、剪辑点说明 |
| 本域产出 | 剪辑脚本；FFmpeg 命令集；切片集+字幕；程序化视频工程；成片+导出说明 |
| 下游可用 | 成片+导出说明 |

- [ ] 字幕时间轴误差须在 ±0.2s 内

### 七、执行卡（以「剪辑脚本与结构设计」为例）

**开工前备齐**：结构表（段落/时长/内容）、节奏曲线、剪辑点说明

**可选补充**：素材、目标平台

**按序执行**：

1. 定结构
2. 排节奏
3. 标剪辑点
4. 配字幕要点

**交付前核对**：前3秒须有钩子；节奏须有起伏

**成品须符合**：剪辑脚本

### 八、成品骨架

按「剪辑脚本」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 剪辑脚本

## 1. 剪辑脚本与结构
## 2. 素材清单与时间轴
## 3. 剪辑点说明
## 4. 字幕文件
## 5. 导出参数
## 6. 成片与工程文件
```

**齐备要求**：必选组件「结构表（段落/时长/内容）、节奏曲线、剪辑点说明」须全部落位；约束「前3秒须有钩子；节奏须有起伏」须逐条成立；可选「素材、目标平台」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
