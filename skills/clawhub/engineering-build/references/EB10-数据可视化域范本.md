## EB10 数据可视化域范本

### 一、领域知识要点

- 图型与关系对应：趋势-折线、对比-柱、构成-饼/堆叠、分布-直方/散点、关系-网络、地理-地图
- 坐标轴规范：纵轴不得截断、量纲须标注、零基线原则
- 配色：分类用色相、连续用明度、注意色盲友好与对比度
- 标注：数据来源、时点、单位、样本量缺一不可
- 看板设计：一屏一个决策问题、层级不超过三级、支持下钻
- 误导识别：双轴混用、面积夸大、3D 效果、选择性区间

### 二、判定标准

- 图型须匹配数据关系
- 纵轴不得截断以夸大差异
- 须标数据来源与时点
- 须校验色盲可读性

### 三、范本结构

1. 图表清单（问题/图型/字段）
2. 配色与标注规范
3. 看板布局
4. 交互与下钻说明
5. 可读性校验

### 四、常见失范

- 用饼图展示超过 5 个分类
- 截断纵轴制造增长假象
- 双轴图让人误读相关性
- 无标注导致无法核对

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 图表清单（类型/字段/交互）、配色、标注、看板布局 |
| 本域产出 | 可视化看板；数据看板；可读性检查报告 |
| 下游可用 | 可读性检查报告 |

### 七、执行卡（以「数据可视化实现」为例）

**开工前备齐**：图表清单（类型/字段/交互）、配色、标注、看板布局

**可选补充**：数据源、品牌规范

**按序执行**：

1. 判关系
2. 选图型
3. 定配色
4. 实现
5. 校验可读性

**交付前核对**：纵轴不得截断；须标数据来源与时点

**成品须符合**：可视化看板

```markdown
## 2. 配色与标注规范
## 3. 看板布局
## 4. 交互与下钻说明
## 5. 可读性校验
```

**齐备要求**：必选组件「图表清单（类型/字段/交互）、配色、标注、看板布局」须全部落位；约束「纵轴不得截断；须标数据来源与时点」须逐条成立；可选「数据源、品牌规范」按需补充。
