## 工程构建任务清单与依赖拓扑

工程构建按"域 → 任务"组织的任务清单，附价值链、场景管线与依赖关系。

**价值链**：需求澄清 → 现状读通 → 方案取舍 → 增量实现 → 回归验证 → 交付（每个域即一类产物在此链上的一次完整实例）

**域划分判据**：域 = 一类**产物的完整构建链**。代码、设计稿、分镜、成片的构建与验收方式不同构，故各自成域，域内任务即该链的阶段。

**互斥约束**：一个任务只属于一个域；同一工作不会在两个域中同时出现。

**域间逻辑流**：EB1 代码重构 → EB2 测试工程 → EB3 云与部署 → EB4 应用开发 → EB5 交互设计 → EB6 原型与线框 → EB7 视觉设计 → EB8 分镜与提示词 → EB9 视频剪辑 → EB10 数据可视化 → EB11 数据与自动化 → EB12 安全与可观测性

**域内基线规则**：每个域的首个任务为该域基线任务，同域其余任务一律以其产出为参照，不得跳步执行。

## 知识图谱

将依赖拓扑扩展为知识图谱，支持跨任务的关系推理。

**实体节点类型**

| 类型 | 数量 | 说明 |
|------|------|------|
| 任务节点 | 57 | 形如 `EB1-01`、`EB12-05` 的可执行单元 |
| 域节点 | 12 | 任务的分组边界 |
| 元操作节点 | 9 | S/C/A/O/I/G 及组合 |
| 产出物节点 | 57 | 各任务声明的交付格式；与任务近 1:1，故不单独建模归并 |
| 场景节点 | 27 | 场景管线中的入口场景 |

**关系边类型**

| 边 | 方向 | 含义 |
|----|------|------|
| 包含边 | 域 → 任务 | 域包含其下所有任务 |
| 依赖边 | 任务 → 任务 | 前置产出是后继输入，见各域链路 |
| 产出边 | 任务 → 产出物 | 任务声明的 `格式` 即其产出节点 |
| 路由边 | 场景 → 任务 | 场景管线的链首即入口任务 |
| 反向边 | 产出物 → 任务 | 由交付格式反查产出它的任务 |

**推理能力**

- **路径推导**：给定起止任务，沿依赖边求最短可行链
- **任务推荐**：给定已完成任务，取其后继中依赖已满足者
- **依赖分析**：给定任务，回溯全部前置与受影响的下游
- **并行识别**：同域内无依赖边的任务可并行执行
- **产出反查**：给定交付格式，定位产出它的任务
- **形态归并**：本负载物全部产出物归入「可运行产物」这一产物形态，跨负载物可再归并

更多组合根据具体任务动态推导。
