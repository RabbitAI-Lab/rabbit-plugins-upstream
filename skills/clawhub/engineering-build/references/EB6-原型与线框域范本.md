## EB6 原型与线框域范本

### 一、领域知识要点

- 保真度阶梯：纸面草图 → 低保真线框 → 中保真交互 → 高保真视觉
- 线框要素：布局栅格、区块、占位内容、标注（间距/字号/交互）
- 用户流：任务路径、分支、返回、异常
- 可交互原型：热区跳转、状态切换、动效过渡
- 设计系统：色彩、字体、间距、圆角、阴影、组件状态（默认/悬停/激活/禁用/加载/错误/空）
- 原型验收：任务完成率、路径是否可达、标注是否可执行

### 二、判定标准

- 线框须标尺寸与间距，不得只画框
- 每个组件须给全状态
- 原型须覆盖关键任务完整路径
- 标注须可被开发直接执行

### 三、范本结构

1. 设计目标与约束
2. 信息架构
3. 页面清单与线框
4. 组件与状态
5. 交互说明
6. 标注与交付清单

### 四、常见失范

- 只画静态页无交互
- 组件缺状态导致开发猜测
- 标注缺失只能靠目测
- 原型无法走通完整任务

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 页面清单、线框稿、栅格与间距标注 |

| 下游可用 | 交付包+评审记录 |

### 七、执行卡（以「线框与信息架构」为例）

**开工前备齐**：页面清单、线框稿、栅格与间距标注

**可选补充**：信息架构、需求

**按序执行**：

1. 定页面
2. 画骨架
3. 标栅格
4. 填占位
5. 标注

**交付前核对**：须标尺寸间距；占位内容须真实语义

**成品须符合**：线框稿

```markdown
## 3. 页面清单与线框

```
