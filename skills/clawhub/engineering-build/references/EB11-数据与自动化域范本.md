## EB11 数据与自动化域范本

### 一、领域知识要点

- 幂等与可重入：同一输入重复执行结果不变；断点续跑与失败重试
- 数据管道：抽取-清洗-转换-加载；增量与全量的取舍
- 数据质量五维：完整性、唯一性、及时性、一致性、有效性
- 脚本工程：参数化、日志分级、退出码、干跑（dry-run）模式
- 调度与监控：定时触发、依赖编排、超时与告警
- 凭据与权限：环境变量注入、最小权限、审计留痕

### 二、判定标准

- 脚本须可重复执行且幂等
- 须有失败重试与断点续跑
- 数据须过五维质量校验
- 不得硬编码路径与凭据

### 三、范本结构

1. 任务目标与触发方式
2. 输入输出与幂等设计
3. 处理流程与异常分支
4. 数据质量校验
5. 日志与告警
6. 退出码与集成方式
7. 运行与回滚说明

### 四、常见失范

- 一次性脚本不敢跑第二遍
- 无日志导致失败无迹可寻
- 全量重跑覆盖了正确数据
- 凭据写死在脚本里

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 任务目标、输入输出、参数清单、质量统计口径、幂等策略、异常分支与退出码 |
| 本域产出 | 自动化脚本+说明；数据管道；数据质量报告；调度与监控配置；性能优化报告 |
| 下游可用 | 性能优化报告 |

### 六、交付自检

交付前逐项打勾，任一项不成立即返工：

- [ ] 脚本须可重复执行且幂等
- [ ] 须有失败重试与断点续跑
- [ ] 数据须过五维质量校验
- [ ] 不得硬编码路径与凭据

同时排除以下失范：

- [ ] 已排除：一次性脚本不敢跑第二遍
- [ ] 已排除：无日志导致失败无迹可寻
- [ ] 已排除：全量重跑覆盖了正确数据
- [ ] 已排除：凭据写死在脚本里

### 七、执行卡（以「自动化脚本设计」为例）

**开工前备齐**：任务目标、输入输出、参数清单、质量统计口径、幂等策略、异常分支与退出码

**可选补充**：现有手工流程、运行环境

**按序执行**：

1. 定目标
2. 定输入输出与质量口径
3. 设计幂等
4. 列异常分支与退出码
5. 写运行说明

**交付前核对**：须幂等且可 dry-run；不得硬编码路径与凭据；退出码须分级

**成品须符合**：自动化脚本+说明

### 八、成品骨架

按「自动化脚本+说明」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 自动化脚本+说明

## 1. 任务目标与触发方式
## 2. 输入输出与幂等设计
## 3. 处理流程与异常分支
## 4. 数据质量校验
## 5. 日志与告警
## 6. 退出码与集成方式
## 7. 运行与回滚说明
```

**齐备要求**：必选组件「任务目标、输入输出、参数清单、质量统计口径、幂等策略、异常分支与退出码」须全部落位；约束「须幂等且可 dry-run；不得硬编码路径与凭据；退出码须分级」须逐条成立；可选「现有手工流程、运行环境」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
