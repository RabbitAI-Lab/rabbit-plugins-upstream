### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Uninstalling this skill can disconnect other Beatra skills when shared installation records are malformed.

Mitigation: If other Beatra skills are in use, wait for the uninstall safeguard to be fixed and follow the documented disconnect guidance.

Risk: Installation enables shared persistent authorization and automatic installation analytics; requested media work sends chosen inputs to Beatra and can spend credits.

Mitigation: Review the connection and credit implications before use, and provide only inputs intended for Beatra processing.
