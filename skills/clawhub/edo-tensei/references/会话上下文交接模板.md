# 会话上下文交接文档（模板）

> 用法：
> 1. 在**旧的重会话**里发一句话让 agent 按本结构总结并保存为 markdown 文件，例如：
>    「请按下面的结构生成本会话的上下文交接文档，并保存为 `会话交接_YYYYMMDD.md`：
>     …（把本文件内容贴进去）」
> 2. 旧会话即可归档 / 关闭，不再常驻渲染。
> 3. 在**新会话**（同一工作空间）里上传该文件作为首条上下文，即可无缝延续。

## 11. 外部引用（远程链接）【仅 `context_depth=full` 时由接管/转生自动填入】
> 本小节用于在新会话保留「当前会话使用过的远程资源地址」，避免跨会话/跨设备丢失导致新会话不可用。
> 由接管/转生在 `context_depth=full` 时，自动从当前会话上下文中抽取以下三类链接填入；`standard`/`minimal` 不生成此节。

| 类别 | 链接 | 用途说明 |
|---|---|---|
| 腾讯文档 |  | 设计思路 / 软著素材 / 证据文档 等 |
| 资料库（WorkBuddy 资料库等） |  | 跨会话知识沉淀位置 |
| 其他远程地址 |  | 其他 http(s) 远程资源 |

- 若当前会话未使用任何外部链接，接管/转生会跳过本小节（不强行留空表）。
- 链接应填「可访问的完整 URL」，勿只写「见腾讯文档」这类无地址叙述。
- 本小节随 handoff 一并被导出包携带，确保目标端不丢链接。
