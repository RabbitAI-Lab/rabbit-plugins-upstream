## 一、免费公开上架路径

| 渠道 | 费用 | 做法 |
|---|---|---|
| **ClawHub** (clawhub.ai) | 免费 | 写 `manifest.yaml`(slug/version/分类/触发词/标签/author) + `package_skill.py` 打包 zip → 网页端 GitHub 登录提交 → 审核约 1–3 工作日 → 出现在客户端「技能市场」 |

> 市场以免费技能为主流；存在个别付费技能但不影响你选择免费发布。免费发布**不转移版权**，作者仍保留全部权利。

## 二、上架时保留署名与可迭代

1. **署名与权利声明**（固化时一并写入技能包）：
   - **必带 · `LICENSE`**：这是真正对外生效的权利声明文件（如 MIT-署名 或自定义「保留署名」协议），随包发布即可主张权利；`manifest.yaml` 的 `author` 字段填你的署名（可用笔名/邮箱，**无需真实姓名**）。
   - **可选 · `软著与创意保护说明.md`**：这是完整「原创证据链」文档（版本演变 v1→vN），**不要求随包原文投放**——作为补充证据可一并打包进 `docs/`，但市场审核通常只看 LICENSE + author。
   - `SKILL.md` 顶部注明创意来源（见软著说明第五节模板）。
2. **迭代更新**：
   - 本地改完 → 把 `manifest.yaml` 的 `version` 递增（1.0.0 → 1.0.1）→ 重新提交；
   - 市场自动提示用户更新，已发布内容照样可改，**发完不锁死**。
3. **两层模型不变**：用户只看到「转生 / 接管 / 导出 / 导入 / 设置」五个指令；内部原语（建塔/依赖检查/路由/启动包/导出包/导入包/配置读写…）随版本增删，用户指令面不变，迭代零负担。

## 三、腾讯文档归档流程（独立于 AI 资料库）

### 3.1 为什么单独建目录
- AI 资料库（腾讯文档空间 `<你的AI资料库空间ID>` 下的「AI资料库」）用于**与 AI 协作的经验沉淀**，已有既定管理规范；
- 本技能的**产品文档 / 证据 / 发布物**属于「作品资产」，不应混进 AI 资料库，避免与经验库规范冲突、也便于单独授权与归档。

### 3.2 归档目录结构（建议）
在**你的腾讯文档个人空间根目录**（非 AI 资料库内）新建文件夹：

```
秽土转生·技能与证据/
├─ 产品说明_秽土转生_v5.html
├─ README_控制塔机制.md
├─ PROJECT_INDEX模板.md
├─ 依赖图谱与行动看板.md
├─ 会话交接模板/
│   ├─ 新会话启动提示词.md
│   ├─ 子任务拆分交接清单.md
│   └─ 路由投送清单.md
├─ 发布包/
│   ├─ 跨平台移植工具包.md
│   ├─ 软著与创意保护说明.md
│   ├─ 发布与上架指南.md
│   └─ LICENSE
```

### 3.3 上传方式
- **方式 A（推荐，结构化保留）**：用 WorkBuddy 的 `tencent-docs` 能力 → 在个人空间根目录新建「秽土转生·技能与证据」文件夹 → 将上述文件逐一上传为该目录下的文档/文件。
- **方式 B（快速）**：本地整理成压缩包，在腾讯文档网页端「新建 → 上传」整体拖入该文件夹。
- 上传后**不要**移入「AI资料库」节点；该文件夹独立于经验库，便于作为软著/原创证据单独留存与分享。

### 3.4 权限与备份
- 个人空间内设为「仅自己可见」或按需生成分享链接；
- 建议同步在本地某处保留一份副本（即当前这份），双份留存防丢失。

## 四、著作权归属与跨平台迭代（provenance）

1. **著作权归人（你），不归 AI / 平台**：WorkBuddy（及任何 AI）是创作工具，不是法律意义上的作者；依著作权法，由人类用户作为作者享有著作权。免费发布也不转移版权——市场通常仅获「托管/展示」授权，所有权仍在你。
2. **跨平台再生成仍是你的**：把本技能的创意/产品文档拿到 DeepSeek、豆包等其他平台，按其格式「移植」成该平台的技能并上传，新作品的著作权同样归你（你仍是作者，对方平台只是另一工具）。各平台互不为版权转移。
3. **建议保留「首版出处」溯源（非法律强制，但强烈建议）**：在技能包 `SKILL.md`/说明里注明「最初于 WorkBuddy 创作，迭代记录见…」。这不构成版权转移，但能在多平台同款技能间建立原创证据链、避免「谁先做出来的」争议，也方便你用腾讯文档发布视图统一跟踪。
4. **各平台上架前读其条款**：ClawHub/SkillHub/企业模板及他平台对上传内容均有各自条款，一般你保留版权、授予平台托管许可；留意是否有「独家/排他」勾选项，按需不勾。
