# 独孤九剑 · 股票短线抓涨技法

## 核心理念

> **千种形态，不过涨跌。如同阴阳，极致必反。**

所有技术分析的本质只有四个维度：**方向 + 能量 + 时间 + 位置**。九式是这四个维度在不同市场场景下的具体战术展开。

---

## 九式详解

### 总诀式 —— 精准布局，超级心法

**定位**：系统的顶层框架，九式的元规则。

**核心逻辑**：
- 多维度信号互证（量能、形态、周期、心态）
- 当四个独立维度的信号收敛于同一点 → 一剑封喉的时刻
- 格栅模型（Latticework of Mental Models）：每式是一个心智模型

**触发条件（量化版）**：
- 至少有 2 个招式同时触发
- 信号之间不矛盾
- 综合置信度 >= 60

---

### 破剑式 —— 一击即中，把握起爆

**定位**：突破买入，抓趋势启动的第一时间

**市场逻辑**：
- 系统从"盘整态"切换到"趋势态"的相变临界
- 振幅收窄 = 多空达成暂时平衡 = 即将打破
- 放量突破 = 新方向获得能量确认

**量化条件**：
1. 前 3 日振幅持续收窄（蓄势形态）
2. 当日成交量 ≥ 5日均量的 1.5 倍（能量确认）
3. 价格突破 20 日内最高价（趋势信号）
4. 当日收阳线（方向确认）
5. 【加分】在斐波那契时间窗口（5/8/13天）

**失败模式**：
- 假突破：突破但无放量配合
- 突破后立即回落收阴（诱多）

---

### 破刀式 —— 空中加油，时间窗口

**定位**：趋势中途的加仓/入场点

**市场逻辑**：
- 趋势是自增强循环（反身性）：价格上涨 → 吸引买盘 → 进一步上涨
- 空中加油 = 确认自增强循环未被切断
- 回调到均线 = 对"均值"的健康回归测试

**量化条件**：
1. 处于上升趋势（MA21 斜率向上）
2. 价格回踩 5/8 日均线但未有效跌破
3. 回调过程缩量（筹码锁定良好的信号）
4. 近 3 日内再度放量上攻
5. 当日收阳确认

**失败模式**：
- 回调跌破 MA21 → 趋势可能逆转
- 回调放量 → 可能是出货而非洗盘

---

### 破枪式 —— 主力思路，量能跟踪

**定位**：追踪主力资金，借力打力

**市场逻辑**：
- 主力是市场系统的关键影响节点
- 资金流向数据是主力行为的直接痕迹
- 主力连续流入 + 价格未大涨 = 蓄力阶段

**量化条件**：
1. 连续 3 日主力资金净流入
2. 同期价格涨幅 < 3%（主力仍在吃货）
3. 成交量温和放大（非脉冲式对倒）
4. 价格站在 MA5 之上

**失败模式**：
- 主力对倒（左右手互倒）制造假放量
- 主力流入但价格开始下跌（托单出货）

---

### 破鞭式 —— 可攻可守，上下画线

**定位**：震荡市策略，利用支撑/阻力边界

**市场逻辑**：
- 震荡区间 = 系统的约束边界
- 在边界做反向操作：下沿买、上沿卖
- 支撑/阻力 = 大量参与者的心理锚定

**量化条件**：
1. 价格在明确的箱体内运行（振幅 < 15%）
2. 布林带宽度适中（3-20%）
3. RSI 在 30-70 之间
4. 当前靠近下沿（位置 < 35%）→ 买点
5. 当前靠近上沿（位置 > 65%）→ 卖点

**失败模式**：
- 假突破 → 止损
- 箱体被有效突破 → 停止打墙，转为趋势策略

---

### 破索式 —— 低价吃货，形态底部

**定位**：左侧交易，在底部区域建仓

**市场逻辑**：
- 跌幅足够大 → 悲观共识已达极致
- 地量出现 → 想卖的人都卖了（卖盘枯竭）
- 均线走平 → 下跌趋势动能耗尽
- "利空出尽，尚可一等"的量化版

**量化条件**：
1. 累计跌幅 ≥ 30%
2. 底部横盘 ≥ 8 天，振幅 < 10%
3. 出现地量（20日成交量分位 < 20%）
4. 均线走平收敛（MA5-MA21 差距 < 5%）
5. 不再创新低

**失败模式**：
- 接飞刀：股票在均线下持续下跌
- 基本面结构性断裂（公司破产、行业消亡）
- 底部还有地下室（中概股常见）

---

### 破掌式 —— 左右逢源，短线打墙

**定位**：在清晰箱体内高抛低吸

**市场逻辑**：
- 这是破鞭式的"快进快出版"
- 要求换手率适中（有流动性但无过度投机）
- 箱体下沿缩量买入 → 箱体上沿卖出

**量化条件**：
1. 存在清晰的短期箱体（15天内，振幅 2-15%）
2. 换手率 3-15%
3. 当前在箱体下沿（位置 < 35%）
4. 下沿处缩量
5. RSI < 40（辅助确认）

**与破鞭式的区别**：
| 维度 | 破鞭式 | 破掌式 |
|------|--------|--------|
| 时间框架 | 中期（20-60天） | 短期（5-15天） |
| 箱体大小 | 较大（5-15%） | 较小（2-10%） |
| 操作频率 | 低频 | 高频 |
| 换手率要求 | 不强调 | 必须满足 |

---

### 破箭式 —— 从容不迫，应对缺口

**定位**：缺口交易，利用价格跳跃信号

**市场逻辑**：
- 跳空 = 价格连续性被打破 = 强烈的供需失衡
- 缺口不回补 = 原方向的能量极强
- 缺口在斐波那契时间窗口不回补 = 更高级别的确认

**量化条件**：
1. 存在 3 日内未回补的缺口
2. 缺口幅度 ≥ 1%
3. 缺口当日放量配合
4. 向上缺口 + 价格稳在缺口上方 → 做多
5. 向下缺口 + 价格持续在缺口下方 → 规避/做空

**缺口类型**：
- 突破缺口（趋势启动）
- 持续缺口（趋势中继，可测量目标位）
- 衰竭缺口（趋势末端，即将反转）

---

### 破气式 —— 再不盲目，消息作用

**定位**：消息面的博弈论分析

**市场逻辑（核心口诀）**：
- **利好曝光，谨防风险**：利好消息已被公开 → 所有买家已入场 → 没有新增买盘 → 只剩卖盘余地 → 下跌概率 > 上涨概率
- **利空出尽，尚可一等**：利空消息已经出尽 → 所有卖家已离场 → 没有新增抛压 → 只剩买盘余地 → 上涨概率 > 下跌概率

**量化条件**：
1. 存在近期公告/新闻
2. 判断消息方向（利好/利空）
3. 判断市场是否已提前定价
4. 利好 + 已公开 + 已上涨 → 卖出/不追
5. 利空 + 已公开 + 已大跌 → 等待底部信号

**多层思维**：
- 第一层：利好 → 买（散户思维）
- 第二层：利好已预期 → 卖（老手思维）
- 第三层：利好改变基本面范式 → 可能驱动新趋势（专家思维）

## 辅助概念

### 五十买点

50 种买入模式可分为两大类：
1. **趋势追随型**（右侧）：破剑式、破刀式、破箭式
2. **均值回归型**（左侧）：破索式、破掌式、破鞭式

多样性降低系统崩溃风险，每种模式有独立的期望值。

### 周期波动，五八一三

斐波那契数列在时间维度上的应用：
- 3/5/8/13/21/34 天是重要的变盘窗口
- 从最近的重要高点或低点开始计数
- 窗口期 ±1 天都有效

### 分时黄线

分时均线 = 日内 VWAP = 市场平均成本
- 价格在黄线上方 → 日内强势，你的买入价高于市场平均
- 价格在黄线下方 → 日内弱势
- 突破黄线 → 日内趋势转变信号

### 盘口大单

- 大单占比 > 30% → 主力在活动
- 大单持续买入 + 价格不涨 → 主力压盘吸筹
- 大单持续卖出 + 价格不跌 → 主力托单出货

### 阻速线

Speed Resistance Lines：连接起点到不同比例（1/3, 2/3）位置
- 用于判断反弹是否演变为反转
- 突破上方阻速线 → 反转概率大
- 未能突破 → 只是反弹

## 风险控制框架

### 核心原则

1. **任何单一招式都不能作为满仓依据**
2. **多招式共鸣（≥2）才能加仓**
3. **止损永远在入场前设定**
4. **流动性不足时（换手率 < 1%），所有信号打折**
5. **基本面结构断裂（ST/*ST/退市风险），所有信号无效**

### 止损规则

| 招式 | 止损位 | 逻辑 |
|:---|:---|:---|
| 破剑式 | 突破日最低价下方 1% | 突破失败 = 假突破 |
| 破刀式 | 最近回调低点下方 1% | 回调加深 = 趋势破坏 |
| 破鞭式 | 箱体下沿下方 2% | 破箱体 = 策略失效 |
| 破索式 | 最近低点下方 3% | 创新低 = 底部判断错误 |
| 破掌式 | 箱体下沿下方 1% | 窄止损，快进快出 |
| 破箭式 | 缺口上沿下方 1%（向上缺口） | 回补缺口 = 缺口失效 |

## 未覆盖的场景（已知局限性）

1. **一字板（涨跌停）**：无法交易，所有招式失效
2. **流动性枯竭**：对手盘消失，形态分析无意义
3. **系统性风险**：大盘暴跌/金融危机，个股招式难以对抗
4. **T+1 限制**：A股当日买入次日才能卖出，破掌式的高频打墙受限
