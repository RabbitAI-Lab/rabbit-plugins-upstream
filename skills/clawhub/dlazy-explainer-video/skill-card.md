## Description:

Helps turn documents, topics, or briefs into narrated explainer videos through outlining, storyboarding, voiceover, production, and validation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators, educators, and teams use this skill to turn documents or briefs into narrated explainers, courseware, and training videos using the dLazy service.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected attachments are sent to an external dLazy service.

Mitigation: Attach only files you are comfortable uploading and review sensitive content before submission.

Risk: Using the service requires a locally stored API key and an external CLI package.

Mitigation: Protect the local key, rotate or revoke it if exposed, and review the package before installation; use npx to avoid a persistent global installation.
