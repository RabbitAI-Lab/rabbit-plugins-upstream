# 运动营养专家模块

## 定位
为**健康人群**（增肌 / 减脂 / 维持 / 体能期）制定个性化饮食方案。
硬边界：不开疾病营养处方；慢性病、进食障碍史、孕妇、哺乳期等特殊情况一律转介医生 / 注册营养师。

## 1. 饮食方案制定流程
1. **收集信息**：目标、体重/体脂、训练量、作息、饮食偏好与禁忌、食物过敏史、外食频率、既往节食史
2. **计算能量与营养素**（第 2、3 节）
3. **分配餐次**（第 4 节）
4. **生成食谱**：按第 5 节食物清单搭配，给出 1 日模板 + 同类替换表，保证一周多样性
5. **跟进调整**：每 2 周评估，按第 7 节规则调整

## 2. 能量计算
- 基础代谢（Mifflin-St Jeor）：
  - 男：10×体重kg + 6.25×身高cm − 5×年龄 + 5
  - 女：10×体重kg + 6.25×身高cm − 5×年龄 − 161
- 每日总消耗 TDEE ≈ 基础代谢 × 活动系数（1.2 久坐 / 1.375 轻度 / 1.55 中度 / 1.725 高 / 1.9 极高）
- 目标热量：
  - 增肌期：TDEE +200-300kcal
  - 减脂期：TDEE −300-500kcal
  - 维持期：TDEE ±100kcal

## 3. 三大营养素分配
- **蛋白质**：1.6-2.2g/kg（减脂期取上限）
- **脂肪**：0.8-1.2g/kg，或占总热量 20-35%
- **碳水**：剩余热量 ÷ 4
- **纤维**：25-35g/日；**水**：体重kg × 30-40ml/日

## 4. 餐次与训练营养
- 3-5 餐/日，按作息分配；每餐蛋白质 20-40g
- 练前 1-2 小时：一餐含碳水 + 适量蛋白（如米饭 + 鸡胸肉）
- 练后：24 小时内补足即可，不必纠结"30 分钟窗口"；全天总量优先于时机
- 睡前可安排一餐缓释蛋白（如牛奶/酪蛋白），非必需

## 5. 食物选择清单
- **蛋白质**：鸡胸肉、牛瘦肉、鱼虾、鸡蛋、牛奶/酸奶、豆制品、乳清蛋白
- **碳水**：大米、面条、燕麦、红薯、玉米、土豆
- **脂肪**：坚果、橄榄油/菜籽油、深海鱼、蛋黄
- **蔬菜**：深色蔬菜优先，每餐 200-300g
- **素食者**：豆制品 + 谷物搭配补足氨基酸；注意维生素 B12、铁，必要时转介

## 6. 一日食谱模板（减脂期示例：70kg 男，约 1900kcal，P143g/C202g/F59g）
| 餐次 | 内容 | 宏量估算 |
|---|---|---|
| 早餐 | 燕麦 60g + 牛奶 250ml + 鸡蛋 2 个 + 蓝莓一小把 | P29/C60/F22 |
| 午餐 | 米饭（生米 80g）+ 鸡胸 180g + 炒青菜 300g | P48/C72/F16 |
| 练前加餐 | 香蕉 1 根 + 乳清蛋白 1 勺 | P21/C30/F2 |
| 晚餐 | 红薯 150g + 清蒸鱼 180g + 凉拌菠菜 250g + 坚果 15g | P45/C40/F19 |
| 全天合计 | — | 约 1900kcal，P143/C202/F59 |

注：数值为估算，实际执行建议用食物秤/APP 记录 1-2 周校准。
- 增肌期：在此基础上 +200-300kcal（加一餐或每餐加量约 20%）
- **同类替换表**：鸡胸 ↔ 鱼/虾/牛肉/豆干；米饭 ↔ 面条/燕麦/红薯；青菜 ↔ 任意深色蔬菜
- 一周内蛋白质来源 ≥4 种，蔬菜 ≥5 种

## 7. 跟进与调整规则（每 2 周评估）
评估指标：体重周均值趋势、训练表现、饥饿感/精力、执行度
- 减脂停滞 2-3 周 → 先查执行（记录完整度、步数），再 −100-200kcal 或 +1 次有氧
- 增肌过快（>0.5%/周）→ 减 100-200kcal
- 体重掉太快（>1%/周）或力量明显下滑 → 回调 100-200kcal
- 长期减脂（>12 周）→ 安排 1-2 周 diet break（吃到维持热量）

## 8. 外食 / 食堂策略
- 点菜公式：1 拳蛋白质 + 2 拳蔬菜 + 1 拳主食
- 火锅/麻辣烫：清汤底、蘸料减半、多点肉和绿叶菜
- 外卖：备注少油少盐；汤泡饭改干饭；饮料换无糖

## 9. 饮食记录方法
- 记录 3 天（2 个工作日 + 1 个休息日），用 APP 或拍照
- 评估重点：蛋白质是否达标、蔬菜量、外食频率、夜宵/零食/含糖饮料

## 10. 补剂（证据分级，只介绍不推销）
- **肌酸 3-5g/日**：证据最充分的力量/增肌补剂；需多喝水，肾病者禁用
- **乳清蛋白**：只是方便的蛋白质来源，不是必需品
- **咖啡因**：训练前 3-6mg/kg 可提表现；影响睡眠者慎用
- 原则：饮食地基没打好不谈补剂；不推荐成分不明的复合产品

## 11. 禁止事项
- 禁止极低热量（<1200kcal/日）方案
- 禁止断食疗法处方式指导
- 禁止给慢性病/进食障碍史/孕妇开具体食谱 → 转介

### 素食版要点（蛋奶素 / 全素）
- **蛋白质拼图**：豆制品 + 谷物同餐（如米饭+豆腐、全麦面包+鹰嘴豆泥），互补氨基酸
- 每日目标：豆腐/豆干 200-300g + 豆类 100g + 乳清或大豆蛋白 1-2 勺（全素用大豆分离蛋白）
- 需关注：维生素 B12（全素必须补充）、铁（搭配维 C 促吸收）、锌、Omega-3（亚麻籽/藻油）
- 全素且备赛/严格热量控制者 → 建议转介注册营养师

### 备餐（meal prep）建议
- 一次做 3-4 天份：主食（米饭/红薯/意面）+ 3 种蛋白质 + 2 种蔬菜
- 分装冷冻，冷藏 3 天 / 冷冻 2 周内吃完
- 调味后置：酱汁单独装，吃前再加，避免蔬菜出水变软

## 13. 补液标准

水常被忽略，但脱水会直接拉低训练表现与认知状态。基础量见第 3 节（体重kg × 30-40ml/日），以下是**训练场景的补充标准**。

### 训练前后补液

| 时点 | 建议量 | 说明 |
|---|---|---|
| 训练前 2 小时 | 5-7 ml/kg | 如 70kg → 350-490ml，给身体留出排空时间 |
| 训练前 15 分钟 | 约 200ml | 视口渴程度 |
| 训练中 | 每 15-20 分钟 150-250ml | 不要等口渴才喝 |
| 训练后 | 每丢失 1kg 体重补 1.25-1.5L | 训练前后称重估算流失 |

### 水分流失自测
- **晨尿颜色**：浅黄 = 基本正常；深黄/琥珀色 = 明显不足
- **训练前后体重差**：差值即流失量（出汗 1L ≈ 掉重 1kg）
- 流失超过体重 2% 时，运动表现已开始下降

### 电解质与运动饮料
- **< 60 分钟的中低强度训练**：白水足够，不需要运动饮料
- **> 60-90 分钟、大量出汗、高温环境**：补充含钠电解质（钠 300-600mg/L 区间参考）
- **判断是否出汗多**：训练后衣服有明显盐渍、皮肤发咸 → 需补钠
- 减脂客户注意：运动饮料含糖，需计入当日热量；可选无糖电解质片

### 常见误区
- 一次性猛灌大量水 → 胃部不适、影响训练；应分次少量
- 只用"是否口渴"判断 → 口渴时已经轻度脱水
- 只补白水不补钠（长时间大量出汗）→ 可能稀释性低钠，出现头晕恶心
- 咖啡/浓茶当水喝 → 有轻度利尿作用，不能完全替代白水

### 特殊人群
- **高血压**：关注钠摄入总量，运动饮料的钠需计入全天限额
- **糖尿病**：训练中防低血糖，随身备糖；运动饮料的糖量需纳入计算
- **肾病**：补液量遵医嘱，**不要套用本节的通用标准**
