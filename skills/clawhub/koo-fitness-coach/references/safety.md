# 安全红线

## 训练中立即停止的信号
- 胸痛、胸闷、异常气喘
- 头晕、眼前发黑、恶心想吐
- 关节"错位感"、刺痛（区别于肌肉酸胀）
- 心率长时间降不下来

## 转介标准（出现以下情况建议就医 / 找物理治疗师）
- 疼痛持续超过 2 周无缓解
- 静息痛、夜间痛
- 明确的外伤史
- 慢性病客户出现新症状
- 详见 references/rehab.md

## 高风险组合黑名单
- 颈后推举 + 肩峰撞击史 → 禁止
- 大重量深蹲无保护杠 / 无保护者 → 禁止
- 急性腰突期做硬拉 / 深蹲 → 禁止
- 高血压客户长时间倒立 / 憋气冲大重量 → 禁止

## 力竭训练安全边界
- 复合动作（深蹲/硬拉/卧推）不冲 RPE10，必须有保护
- 孤立动作可偶尔到力竭，但关节疼痛即停（见 rehab.md 红绿灯）
- 新手前 3 个月不安排力竭组

## 特殊人群注意事项（一般原则，具体遵医嘱）
- **高血压**：避免憋气冲大重量、避免头低于心脏的长时间体式；监测运动前后血压
- **糖尿病**：随身备糖防低血糖；注意足部保护，避免赤足训练
- **孕妇**：必须有医生许可；孕中晚期避免长时间仰卧、憋气、高冲击与跌倒风险动作
- **老年人**：加入平衡与防跌倒练习；骨质疏松者避免脊柱屈曲+旋转联合负荷；渐进幅度减半
- **青少年**：以技术学习为主，不冲极限重量；避免过早专项化

## 免责建议
- 首课签署《运动风险知情同意书》。
- 所有计划标注"仅供参考，身体不适请及时就医"。

## 紧急处置流程（心肺骤停 / 晕厥）

### 识别
- 突然倒地、无反应、无正常呼吸（或仅有濒死叹息样呼吸）→ 按心肺骤停处理
- 单纯晕厥但呼吸正常 → 平卧抬高下肢，保持气道通畅，观察恢复

### 处置步骤（发现 → 呼救 → 按压 → 除颤）
1. **确认环境安全**，轻拍双肩呼喊判断反应
2. **呼救**：指定具体人员拨打 120，另一人取 AED（不要只说"快叫救护车"）
3. **判断呼吸**（不超过 10 秒）：无呼吸或仅有叹息样呼吸 → 立即开始按压
4. **胸外按压**：双手交叠置于两乳头连线中点，深度 5-6cm，频率 100-120 次/分，充分回弹
5. **人工呼吸**：30 次按压 : 2 次吹气；不接受或不便做人工呼吸者，做单纯持续按压
6. **AED 到达后**：开机 → 贴片（右上胸 + 左腋下）→ 听语音提示 → 电击时确保无人接触 → 电击后立即恢复按压
7. **持续至**：急救人员到达、或伤者恢复自主呼吸与反应

### 健身房常见场景
- **器械砸伤 / 大重量压伤**：先固定伤处，不随意移动；怀疑脊柱伤不动，等专业救援
- **中暑**：移至阴凉处、解开衣物、物理降温、补含电解质液体
- **低血糖**（糖尿病客户）：意识清醒给含糖饮料/糖果；意识不清禁止喂食，侧卧位等急救
- **脱水 / 过度换气**：平卧、抬高下肢、缓慢呼吸引导
- **晕厥后**：本次训练立即终止，建议就医排查原因，不"缓过来就继续练"

### 预防前置措施
- 场馆内 AED 位置全员知晓；教练持有有效期内的急救与 CPR 认证
- 首次课确认紧急联系人；高风险客户（心血管史）训练时不离视线
- 训练区保持通道畅通，杠铃区必须使用卡扣

## 执业合规提示

- 首课必须完成 **PAR-Q+ 风险筛查 + 知情同意书签署**（见 assessment.md）
- 所有书面计划底部标注免责声明："本计划为一般性健身指导，不能替代医疗诊断。训练中出现不适请立即停止并就医。"
- 不得使用"治疗""康复""治愈""疗效"等医疗用语描述训练效果
- 不得宣称可替代药物、可逆转慢性病
- 涉及营养建议时，遵守当地关于营养咨询资质的规定；超出资质范围的转介注册营养师
- 隐私：客户健康数据（病史、体测、疼痛记录）属于敏感个人信息，未经书面同意不得对外分享或用于宣传
- 影像使用（训练照片/视频）：必须单独取得肖像授权，且注明用途范围

> 具体资质要求因执业地区而异（如是否需要体育指导员证、急救证、营养师资质等），请按所在地区的体育主管部门与市场监管要求自行核对。
