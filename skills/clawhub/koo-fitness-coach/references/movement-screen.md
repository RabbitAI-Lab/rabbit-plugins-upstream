# 标准化动作筛查

## 定位

`assessment.md` 提供的是一套**轻量自编筛查**（4 个动作，够用但不成体系）。本文件提供两层更强的工具：

1. **FMS 功能性动作筛查**——7 个动作、0-3 分制，用于量化动作质量并发现不对称
2. **关节逐段排查顺序**——动作受限时的系统化归因路径

使用时机：
- 首次评估需要客观基线 → 用 FMS
- 客户主诉"某个动作做不了/不舒服" → 用逐段排查
- 两者可叠加：FMS 发现异常 → 逐段排查定位原因

**先做 `assessment.md` 的 PAR-Q+ 风险筛查，通过后再做本文件筛查。** 有疼痛症状直接走 `rehab.md`。

## FMS 七动作筛查

每个动作按 **0-3 分**打分：

| 分数 | 含义 |
|---|---|
| 3 | 无代偿完成 |
| 2 | 有代偿完成 |
| 1 | 无法完成 |
| 0 | 动作中任何部位出现疼痛 |

**重要**：出现 0 分（疼痛）时，该动作为 0 分且**立即停止该项筛查，转介就医**（见 rehab.md）。疼痛优先于所有评分逻辑。

### 筛查动作清单

| # | 动作 | 主要观察 | 对应运动模式 |
|---|---|---|---|
| 1 | 深蹲 | 躯干是否直立、膝是否内扣、足跟是否离地、深度 | 蹲 |
| 2 | 跨栏步 | 髋膝踝是否在一条线、骨盆是否稳定、支撑腿是否代偿 | 单腿稳定 + 髋 |
| 3 | 直线弓步 | 前后脚是否在一条线上、骨盆是否旋转、膝触地质量 | 单腿 + 髋活动度 |
| 4 | 肩部灵活性 | 双手背后能否接近、是否代偿性耸肩或弓背 | 肩带活动度 |
| 5 | 主动直腿抬高 | 抬腿角度、膝盖是否弯曲、骨盆是否后倾 | 腘绳肌柔韧 + 核心 |
| 6 | 躯干稳定俯卧撑 | 撑起时腰椎是否塌陷、躯干是否同步 | 核心稳定 |
| 7 | 旋转稳定性 | 对角伸展时躯干是否旋转/侧倾 | 核心抗旋 |

单侧动作（2、3、4、5、7）**左右各测一次，取较低分计入总分**。

### 评分汇总

- 总分范围 0-21 分（7 项 × 3 分）
- 记录时同时标注：总分、左右不对称项、0 分项（疼痛）

## 评分解读与决策

### 三条优先规则（按顺序判断）

1. **有疼痛（0 分）** → 最高优先级。停止训练该项，按 rehab.md 转介。**不继续走下面的流程。**
2. **有左右不对称** → 次高优先级。即使总分不低，单侧差异也提示代偿链，优先处理活动度与稳定性。
3. **总分偏低** → 提示整体动作质量基础不足。

### 参考判定

| 情况 | 处理方向 |
|---|---|
| 总分 ≥ 17 且无不对称 | 动作质量良好，可直接进入常规力量训练 |
| 总分 14-16 或存在中度不对称 | 在训练计划中加入针对性纠正动作，4-6 周后复测 |
| 总分 < 14 | 建议以动作质量训练为主（对应 OPT 模型阶段 1），暂不推大重量 |
| 任一 0 分 | **转介**，不做训练处方 |

**注意**：总分只是参考指标，不是诊断结论。不要对客户下"你有 X 问题"的判断（见 rehab.md 禁止事项）。筛查的用途是**决定训练起点**，不是给身体下定义。

### 从筛查到训练决策

```
筛查结果
  ├─ 0 分疼痛 ──────────→ 转介，停止
  ├─ 左右不对称 ────────→ 单侧训练 + 活动度改善，降低负荷
  └─ 分数低但无痛
       ├─ 蹲/跨栏步/弓步低 → 髋踝活动度 + 单腿稳定优先
       ├─ 肩部灵活性低 ──→ 胸椎活动度 + 肩关节周围软组织
       ├─ 直腿抬高低 ────→ 腘绳肌柔韧 + 核心骨盆控制
       └─ 核心两项低 ────→ 抗旋/抗伸展核心训练优先
```

各模块的对应动作见 `exercise-library.md` 的退阶链，纠正训练安排进 `program-design.md` 的热身与辅助部分。

## 关节逐段排查顺序

当一个动作受限或不舒适（但在无痛范围内），按**从下往上的链条**逐段排查，而不是直接怀疑出问题的那个关节。

### 排查顺序

| 顺序 | 关节段 | 常见受限表现 |
|---|---|---|
| 1 | 足踝 | 足背屈受限 → 深蹲脚下沉、脚跟离地 |
| 2 | 膝 | 屈伸受限 → 蹲深不足、膝内扣 |
| 3 | 髋 | 屈髋/外旋受限 → 弓腰代偿、膝超脚尖过多 |
| 4 | 骨盆与腰椎 | 骨盆控制差 → 腰椎过伸或骨盆翻转 |
| 5 | 胸椎 | 伸展/旋转受限 → 肩部上举代偿、含胸 |
| 6 | 肩 | 屈曲/外旋受限 → 推举受限、肩前痛 |
| 7 | 颈 | 头前伸 → 全链条张力改变 |

**核心逻辑**：相邻关节相互影响。例如"深蹲蹲不下去"的原因常常在**踝**或**髋**，而不在膝本身。先查下方关节，再查上方。

### 三条通用原则

1. **中立位优先**：所有动作以脊柱中立、骨盆中立为基准。先能维持中立位，再谈负荷。
2. **活动度先于力量**：受限的关节段先改善活动度，再加载。在受限状态下加重量只会强化代偿模式。
3. **左右对称优先于绝对数值**：单侧差异比整体柔韧性差更值得处理。

### 受限处理的优先级

```
1. 疼痛 → 转介（不做处理）
2. 活动度明显受限 → 灵活性/活动度练习（每日 5-10 分钟）
3. 活动度可接受但控制差 → 稳定性与激活练习
4. 以上均可 → 正常加载，加入动作模式训练
```

## 复测节奏

- 首次筛查记录基线
- 每 4-6 周复测一次（与体测复测同步，见 session-sop.md）
- 只复测**有问题的项目**即可，不必每次全测 7 项
- 复测结果与基线对比，进步体现在分数或不对称改善上，而不只是"感觉好点了"
