## 一、蹲模式（Knee-dominant）

### 杠铃深蹲
- **目标肌群**：股四头肌、臀大肌、核心
- **标准步骤**：（1）杠置于斜方肌上部，双脚与肩同宽、脚尖微外展；（2）吸气，屈髋屈膝同步下蹲，膝盖沿脚尖方向；（3）蹲至大腿与地面平行（活动度允许可更低）；（4）呼气，脚跟发力站起。
- **呼吸**：下蹲吸气，站起呼气（大重量可用瓦式呼吸）。
- **常见错误 Top3**：1. 膝盖内扣 2. 脚跟离地 3. 弓腰（骨盆翻转）
- **纠错口令**："膝盖找脚尖方向""脚像树根扎进地里""胸口挺起来看前方"
- **退阶 → 进阶**：箱式深蹲 → 自重深蹲 → 高脚杯深蹲 → 杠铃深蹲 → 前蹲
- **禁忌 / 慎用人群**：急性腰椎间盘突出、膝关节急性炎症期

### 高脚杯深蹲
- **目标肌群**：股四头肌、臀大肌、核心
- **标准步骤**：（1）双手抱哑铃/壶铃于胸前，双脚略宽于肩；（2）吸气，垂直下蹲，肘部沿膝盖内侧下行；（3）蹲至最低点保持躯干直立；（4）呼气，脚掌踩实站起。
- **呼吸**：下蹲吸气，站起呼气。
- **常见错误 Top3**：1. 肘部不下行导致含胸 2. 脚跟离地 3. 膝盖内扣
- **纠错口令**："肘尖找膝盖内侧""屁股坐向地板"
- **退阶 → 进阶**：靠墙深蹲 → 高脚杯深蹲 → 双哑铃深蹲 → 杠铃深蹲
- **禁忌 / 慎用人群**：膝关节急性疼痛期

### 保加利亚分腿蹲
- **目标肌群**：股四头肌、臀大肌、单侧稳定肌群
- **标准步骤**：（1）后脚搭于凳上，前脚置于身前约一大步；（2）吸气，垂直下蹲，后膝趋近地面；（3）下蹲至前腿大腿接近水平；（4）呼气，前脚发力站起。
- **呼吸**：下蹲吸气，站起呼气。
- **常见错误 Top3**：1. 前脚过近导致膝超脚尖过多 2. 重心不稳左右晃 3. 躯干过度前倾
- **纠错口令**："前脚踩穿地板""上身像坐电梯直上直下"
- **退阶 → 进阶**：分腿蹲（后脚不抬起）→ 扶墙保加利亚蹲 → 负重保加利亚蹲
- **禁忌 / 慎用人群**：膝关节不稳、平衡能力差者需扶墙

## 二、铰链模式（Hip-dominant）

### 罗马尼亚硬拉
- **目标肌群**：腘绳肌、臀大肌、下背
- **标准步骤**：（1）双脚与髋同宽站立，杠贴大腿；（2）吸气，屈髋将臀部往后推，杠沿腿前侧下滑；（3）至腘绳肌有明显拉伸感时停；（4）呼气，臀部发力顶髋站直。
- **呼吸**：下放吸气，拉起呼气。
- **常见错误 Top3**：1. 弓腰 2. 杠铃远离身体 3. 膝盖过度弯曲（做成深蹲）
- **纠错口令**："屁股往后找墙""杠铃刮着小腿上""腿后侧像皮筋拉长"
- **退阶 → 进阶**：臀桥 → 早安式体前屈（徒手）→ 哑铃罗马尼亚硬拉 → 杠铃罗马尼亚硬拉 → 传统硬拉
- **禁忌 / 慎用人群**：急性腰椎间盘突出、腘绳肌急性拉伤

### 传统硬拉
- **目标肌群**：臀大肌、腘绳肌、竖脊肌、斜方肌、前臂
- **标准步骤**：（1）双脚与髋同宽，杠位于脚掌中部上方；（2）屈髋下蹲握杠，小腿贴近杠；（3）吸气憋气绷紧，腿推地面、杠贴腿垂直上升；（4）站直锁髋（不后仰）；（5）屈髋下放回起点。
- **呼吸**：起杠前吸气憋住，锁髋后呼气换气。
- **常见错误 Top3**：1. 起始臀位过低（做成深蹲）2. 弓腰起杠 3. 杠远离身体
- **纠错口令**："把地板推开""杠贴着腿走""背像一块钢板"
- **退阶 → 进阶**：架上硬拉 → 六角杠硬拉 → 传统硬拉 → 相扑硬拉
- **禁忌 / 慎用人群**：急性腰椎间盘突出、未经评估的高血压者（憋气升压）

### 臀推
- **目标肌群**：臀大肌、腘绳肌
- **标准步骤**：（1）上背靠于凳缘，杠铃置于髋部（垫护垫），双脚与髋同宽；（2）呼气，臀部发力顶髋至躯干与大腿成一条线；（3）顶峰收缩 1-2 秒；（4）吸气，缓慢下放。
- **呼吸**：顶髋呼气，下放吸气。
- **常见错误 Top3**：1. 用腰发力过度顶（腰椎过伸）2. 顶髋高度不足 3. 双脚位置过远变腘绳肌主导
- **纠错口令**："下巴收住看膝盖""肋骨下沉别翻胸"
- **退阶 → 进阶**：臀桥（地面）→ 单腿臀桥 → 杠铃臀推 → 单腿杠铃臀推
- **禁忌 / 慎用人群**：髋关节急性疼痛期

## 三、水平推模式

### 杠铃卧推
- **目标肌群**：胸大肌、三角肌前束、肱三头肌
- **标准步骤**：（1）仰卧，五点接触（头、肩胛、臀贴凳，双脚踩地）；（2）肩胛后缩下沉，握距略宽于肩；（3）吸气，杠下放至胸骨中下部（约乳线）；（4）呼气，推起至手臂伸直（肘不锁死）。
- **呼吸**：下放吸气，推起呼气。
- **常见错误 Top3**：1. 肩胛未收紧导致肩前痛 2. 手肘过度外展（90°）3. 臀部离凳起桥过度
- **纠错口令**："肩胛装进口袋""手肘与身体约 75 度""把杠掰弯"
- **退阶 → 进阶**：上斜俯卧撑 → 哑铃卧推 → 杠铃卧推 → 窄距卧推
- **禁忌 / 慎用人群**：肩袖损伤急性期、胸大肌拉伤史

### 俯卧撑
- **目标肌群**：胸大肌、三角肌前束、肱三头肌、核心
- **标准步骤**：（1）双手撑地略宽于肩，身体呈一条直线；（2）吸气，屈肘身体整体下放至胸接近地面；（3）呼气，推起至手臂伸直（肘不锁死）。
- **呼吸**：下放吸气，推起呼气。
- **常见错误 Top3**：1. 塌腰 2. 耸肩 3. 手肘过度外展
- **纠错口令**："屁股夹紧像一块平板""肩膀装进口袋""手肘与身体呈 45 度"
- **退阶 → 进阶**：上斜俯卧撑 → 跪姿俯卧撑 → 标准俯卧撑 → 下斜俯卧撑 → 负重俯卧撑
- **禁忌 / 慎用人群**：腕关节急性损伤、肩袖急性损伤

## 四、垂直推模式

### 站姿杠铃推举
- **目标肌群**：三角肌前束/中束、肱三头肌、核心
- **标准步骤**：（1）杠置于锁骨前，握距略宽于肩，前臂垂直；（2）吸气绷紧核心与臀部；（3）呼气，垂直向上推起，头部略微后让；（4）杠过头后头回到中立位；（5）吸气，控制下放至锁骨。
- **呼吸**：上推呼气，下放吸气。
- **常见错误 Top3**：1. 腰椎过伸代偿（挺肚子）2. 推举轨迹向前绕 3. 手腕后折
- **纠错口令**："屁股夹紧肋骨下沉""杠走直线贴着脸上""手腕立起来"
- **退阶 → 进阶**：坐姿哑铃肩上推举 → 站姿哑铃推举 → 杠铃推举 → 借力推举
- **禁忌 / 慎用人群**：肩峰撞击史（禁颈后推举）、腰椎不稳

## 五、水平拉模式

### 杠铃划船
- **目标肌群**：背阔肌、斜方肌中下部、菱形肌、肱二头肌
- **标准步骤**：（1）屈髋前倾约 45°，膝盖微屈，背部挺直；（2）握距略宽于肩，自然下垂；（3）呼气，手肘沿身体两侧后拉至腹部；（4）挤紧肩胛 1 秒；（5）吸气，控制下放。
- **呼吸**：后拉呼气，下放吸气。
- **常见错误 Top3**：1. 弓腰 2. 用惯性甩起 3. 耸肩（斜方肌上部代偿）
- **纠错口令**："手肘找裤兜""肩胛夹住一支笔""把杠拉向肚脐"
- **退阶 → 进阶**：坐姿绳索划船 → 哑铃单臂划船 → 杠铃划船 → 潘德雷划船
- **禁忌 / 慎用人群**：急性下背痛、腰椎间盘突出急性期

### 坐姿绳索划船
- **目标肌群**：背阔肌、菱形肌、斜方肌中下部、肱二头肌
- **标准步骤**：（1）坐姿，膝盖微屈，躯干直立；（2）双手握把，肩胛前伸放松；（3）呼气，手肘后拉至躯干两侧，挺胸挤肩胛；（4）吸气，控制还原至肩胛前伸。
- **呼吸**：后拉呼气，还原吸气。
- **常见错误 Top3**：1. 躯干前后大幅摆动借力 2. 耸肩 3. 只用肱二头肌拉、不挤肩胛
- **纠错口令**："胸口挺向把手""先动肩胛再动手肘"
- **退阶 → 进阶**：弹力带划船 → 坐姿绳索划船 → 单臂绳索划船 → 杠铃划船
- **禁忌 / 慎用人群**：急性下背痛

## 六、垂直拉模式

### 引体向上
- **目标肌群**：背阔肌、肱二头肌、斜方肌下部、核心
- **标准步骤**：（1）正握（掌心向前）略宽于肩悬垂，身体绷直；（2）沉肩，肩胛下沉收紧启动；（3）呼气，挺胸将下巴拉过单杠；（4）吸气，缓慢下放至手臂接近伸直（保持肩部张力不松）。
- **呼吸**：拉起呼气，下放吸气。
- **常见错误 Top3**：1. 耸肩启动 2. 借力甩动（kipping）凑次数 3. 下放自由落体
- **纠错口令**："肩膀装进口袋""胸口找杠""手肘找肋骨"
- **退阶 → 进阶**：悬垂 → 悬垂耸肩 → 弹力带辅助引体 → 跳跃离心引体 → 标准引体向上 → 负重引体
- **禁忌 / 慎用人群**：肩袖损伤急性期、肘关节急性炎症期

### 高位下拉
- **目标肌群**：背阔肌、大圆肌、肱二头肌
- **标准步骤**：（1）坐姿固定大腿，正握宽于肩；（2）沉肩，躯干微后倾（约 15°）；（3）呼气，将横杠拉至上胸；（4）挤紧肩胛 1 秒；（5）吸气，控制还原至手臂伸直、肩胛上提。
- **呼吸**：下拉呼气，还原吸气。
- **常见错误 Top3**：1. 拉到颈后（伤肩）2. 躯干大幅后仰借力 3. 耸肩
- **纠错口令**："杠拉向锁骨""胸口迎向杠""肩胛先下沉"
- **退阶 → 进阶**：直臂下压 → 高位下拉 → 反握下拉 → 引体向上
- **禁忌 / 慎用人群**：肩峰撞击史、颈椎问题（禁颈后下拉）

## 七、核心与孤立动作

### 平板支撑
- **目标肌群**：腹横肌、腹直肌、竖脊肌、臀肌
- **标准步骤**：（1）前臂撑地，肘在肩正下方，双脚与髋同宽；（2）收紧臀腹，身体呈一条直线；（3）保持均匀呼吸，坚持目标时长；（4）结束时先落膝再起身。
- **呼吸**：全程自然均匀呼吸，不憋气。
- **常见错误 Top3**：1. 塌腰（腰椎过伸）2. 撅臀过高 3. 憋气
- **纠错口令**："肚脐找脊柱""屁股夹紧像一块板""肋骨往下沉"
- **退阶 → 进阶**：跪姿平板支撑 → 标准平板支撑 → 单腿平板支撑 → 负重平板支撑
- **禁忌 / 慎用人群**：腕肘急性损伤、严重腰椎问题

### 哑铃侧平举
- **目标肌群**：三角肌中束
- **标准步骤**：（1）站姿，双手持哑铃垂于体侧，肘微屈；（2）呼气，沿身体两侧抬起至与肩平行；（3）小指略高于拇指；（4）吸气，控制下放。
- **呼吸**：抬起呼气，下放吸气。
- **常见错误 Top3**：1. 耸肩代偿 2. 用惯性甩起 3. 抬过肩高致肩峰撞击
- **纠错口令**："肩膀下沉""想象倒水出去""手肘带手"
- **退阶 → 进阶**：弹力带侧平举 → 坐姿哑铃侧平举 → 站姿哑铃侧平举 → 侧平举递减组
- **禁忌 / 慎用人群**：肩袖损伤急性期、肩峰撞击史（控制在肩以下）

### 哑铃弯举
- **目标肌群**：肱二头肌、肱肌
- **标准步骤**：（1）站姿，双手持哑铃垂于体侧；（2）大臂贴紧躯干固定；（3）呼气，屈肘弯举至前臂接近垂直；（4）顶峰收缩 1 秒；（5）吸气，控制下放至手臂伸直。
- **呼吸**：弯举呼气，下放吸气。
- **常见错误 Top3**：1. 大臂前后摆动借力 2. 用腰部后仰甩起 3. 下放不做离心控制
- **纠错口令**："大臂夹住肋骨""手肘钉在原位""慢放两秒"
- **退阶 → 进阶**：弹力带弯举 → 哑铃交替弯举 → 杠铃弯举 → 集中弯举
- **禁忌 / 慎用人群**：肘关节急性炎症期、肱二头肌长头腱炎急性期
