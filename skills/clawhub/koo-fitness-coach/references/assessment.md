# 会员评估与分级

## 1. PAR-Q+ 风险筛查（首课必做）
以下任一回答"是"，先建议就医评估，暂缓高强度训练：
1. 医生是否曾说你有心脏问题，只能在医生建议下运动？
2. 运动时是否曾胸痛？
3. 近一个月内未运动时是否曾胸痛？
4. 运动时是否曾因头晕失去平衡或失去意识？
5. 是否有因运动加重的骨骼 / 关节问题？
6. 是否正在服用心脏 / 血压相关药物？
7. 是否有其他不适合运动的理由？

## 2. 基础体测（记录基线，每 4-12 周复测）
- 身体成分：体重、腰围（条件允许加体脂率）
- 心肺（二选一）：3 分钟台阶测试 / 12 分钟跑
- 力量基线：俯卧撑最大次数、自重深蹲质量、平板支撑时长；有基础者可用 5RM 估算 1RM（Epley 公式：1RM ≈ 重量×(1+次数/30)）
- 柔韧：坐位体前屈、肩关节活动度

## 3. 静态姿态观察（记录，不诊断）
- 头前伸、圆肩、骨盆前倾 / 后倾、足弓塌陷
- 发现明显异常 → 在计划中加入对应灵活性/激活练习，严重者转介

## 4. 简易动作筛查（每个动作观察 5 次）
| 筛查动作 | 观察点 | 不通过 → 退阶 |
|---|---|---|
| 自重深蹲 | 膝盖是否内扣、脚跟是否离地、躯干是否过度前倾 | → 箱式深蹲 / 靠墙深蹲 |
| 俯卧撑（可跪姿） | 腰是否塌陷、肩胛是否稳定 | → 上斜俯卧撑 |
| 单腿站立 30 秒 | 是否大幅晃动 | → 加强单侧与核心训练 |
| 手臂上举贴墙 | 腰是否反弓代偿 | → 胸椎灵活性练习优先 |

## 5. 分级决策树
- **新手**：系统训练 < 6 个月，或任一筛查不通过 → 自重 / 固定器械为主，全身训练，RPE 6-7
- **中级**：系统训练 6-24 个月，筛查通过 → 自由重量为主，可分化训练，RPE 7-8
- **进阶**：系统训练 > 24 个月，有明确力量数据 → 周期化训练，RPE 8-9

## 6. 专项体测补充

### 跑步 / 跑者
- 单腿提踵次数（小腿耐力）、单腿下蹲质量（髋稳定）
- 5 分钟步频计数（目标 170-180 步/分）、近期最长距离与配速
- 既往损伤史重点问：胫骨疲劳性骨膜炎、足底筋膜炎、髂胫束

### 产后（必须已获医生许可）
- 先问：分娩方式、产后时长、是否已做腹直肌分离评估
- 腹直肌分离自测（仰卧抬头，2 指以上分离 → 禁止卷腹类动作）
- 盆底肌：不评估内部，只问"咳嗽/跳跃是否漏尿"，有症状 → 转介
- 早期只做呼吸、骨盆控制、臀桥、行走；避免高冲击与腹压骤增

### 中老年
- 增加：坐立起立测试（30 秒椅子起坐次数，评估下肢功能）
- 增加：单腿站立时间（闭眼更难）、起立-行走计时（TUG）
- 重点关注：平衡、防跌倒、骨密度（有骨质疏松史者避免脊柱屈曲+旋转负荷）

### 器械受限场景（居家 / 出差）
- 记录可用条件：徒手 / 弹力带 / 一对哑铃 / 单杠 / 瑜伽垫
- 徒手方案以动作难度递进替代负荷递进（见 exercise-library.md 的退阶→进阶链）

## 7. 与标准化筛查 / OPT 阶段的分工

上面的第 4 节是**轻量自编筛查**（4 个动作），适合快速定级与日常快速复核。以下情况改用 `movement-screen.md` 的 **FMS 标准化筛查**：

- 客户目标是增肌 / 力量，需要更可靠的起点判定
- 出现左右不对称、动作别扭但无痛
- 需要与 4-6 周后的复测做量化对比
- 客户有运动表现需求（跑跳、球类、体测）

分工原则：
- **日常定级** → 用本文件第 4 节，快
- **正式评估 / 复测 / 有疑虑** → 用 `movement-screen.md`，准
- **任何一项出现疼痛** → 两个都不用，直接走 `rehab.md`

### 分级结果 → OPT 阶段映射

定级完成后，用 `opt-model.md` 决定训练起点：

| 本文件分级 | 建议 OPT 起始阶段 | 说明 |
|---|---|---|
| 新手（或任一筛查不通过） | 阶段 1 稳定性耐力 | 先解决动作质量，不推大重量 |
| 中级（筛查通过） | 阶段 3 肌肥大 | 大部分客户长期停留在此 |
| 进阶（有明确力量数据） | 阶段 4 最大力量 | 需先有阶段 3 的容量基础 |

注意：分级只决定**起点**，之后按 `opt-model.md` 的升降级规则动态调整。减脂客户通常不需要进入阶段 4-5。
