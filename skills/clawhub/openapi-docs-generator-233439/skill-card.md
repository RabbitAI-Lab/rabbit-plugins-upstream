## Description: <br>
Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to turn REST API context into actionable OpenAPI or Swagger documentation plans, artifacts, checklists, code changes, and validation steps. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may be invoked for general API or developer-experience wording beyond explicit OpenAPI or Swagger tasks. <br>
Mitigation: Review deployment routing and tighten triggers if precise invocation matters. <br>
Risk: Generated documentation guidance may be incomplete or inconsistent with a service's actual API behavior. <br>
Mitigation: Review outputs against source routes, schemas, authentication behavior, and run relevant OpenAPI validation before release. <br>
