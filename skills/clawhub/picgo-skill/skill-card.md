## Description: <br>
Uploads local image files through a locally running PicGo service when an agent needs image hosting. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[naratsuna](https://clawhub.ai/user/naratsuna) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and agents use this skill to upload one or more local image files through a local PicGo server. It supports configuring the PicGo service URL and is useful when image files need to be moved from local storage to the image host configured in PicGo. <br>
