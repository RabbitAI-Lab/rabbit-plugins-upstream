# econ-lens · 曼昆透镜

把曼昆《经济学原理》的概念当成一副「透镜」，戴在真实决策和现象上看。不输出教科书定义的堆砌，而是输出能改变下一步行动的诊断。

## 它做什么

你描述一个决策/现象/新闻/选择，它输出「透镜卡片」：

- 一句话定义（大白话，不抄书）
- 曼昆视角：这个概念真正想纠正的直觉错误
- 贴到你的账上：挂到你的真实情境
- 常见误用：这个概念最容易被用歪的方式
- 下一步：一个具体可执行的小动作

内置场景路由：说「都投入这么多了放弃太亏」唤醒沉没成本谬误，说「要不要现在做」唤醒边际思考，以此类推。

## 概念卡随你生长

skill 自带陪读沉淀模式：每读完一章《经济学原理》，把「挂上过真实账单」的概念写成卡片，概念库越读越厚。

## 安装

```bash
clawhub install econ-lens
```

或把本仓库放进 `~/.workbuddy/skills/`。
