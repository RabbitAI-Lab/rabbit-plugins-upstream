# Econ Lens（曼昆透镜）

## Overview

把曼昆《经济学原理》的概念当成一副「透镜」，戴在真实决策和现象上看：不输出教科书定义的堆砌，而是输出**能改变下一步行动的诊断**。

三层结构（蒸馏三层，缺一不可）：
1. **概念层** → `references/concepts.md`：概念卡（定义/曼昆视角/案例/误用/原书位置）
2. **判断层** → 本文件的触发路由：什么场景唤醒哪个概念
3. **应用层** → `references/cases.md`：Bonnie 的私人案例账单库（⚠️ 隐私文件，**不上传 GitHub/ClawHub**，公开版用「用户自填案例」模板替换）

## 工作流

### 模式 A：场景诊断（默认）

用户描述了一个决策/现象/新闻/选择，需要经济学视角。

**第 1 步：识别场景类型**，路由到对应概念（读 `references/concepts.md` 中命中的卡片）：

| 场景信号 | 唤醒概念卡 |
|---|---|
| 「要不要放弃 A 去做 B」「不做这个我能干嘛」 | 机会成本 |
| 「都投入这么多了，放弃太亏」 | 沉没成本谬误 |
| 「要不要现在就做/再等等」 | 边际思考 |
| 「我做 X 到底图什么、值不值」 | 激励 |
| 「我一个人/一个团队干所有事，怎么分工」 | 比较优势 |
| 「这个东西为什么这么贵/这么缺/价格为什么失灵」 | 稀缺 与 市场与价格信号 |
| 「有人受益有人受害但没人付钱/平台治理类问题」 | 外部性与市场失灵 |

**第 2 步：输出透镜卡片**（一次最多 3 张，按相关度排序），固定格式：

```
◇ 概念名（原书章节位置）

一句话定义：……（不许抄书，用大白话）
曼昆视角：这个概念真正想纠正的直觉错误是什么
贴到你的账上：从 cases.md 或对话中提取用户的真实情境，把概念挂上去
常见误用：这个概念最容易被用歪的方式
下一步：一个具体、可执行的小动作
```

**第 3 步：必须反问，不许只给结论。** 诊断后至少抛回一个问题（参照苏格拉底陪读方式），把概念变成用户的账单。例：给完「机会成本」卡后问「如果不做现在这份工作，你模糊选项里最清晰的那一个是什么？」

**第 4 步（发现新案例时）：** 如果对话中产生了把概念挂上真实账单的新案例，**追加到 `references/cases.md`**（标注日期），让案例库生长。

### 模式 B：陪读沉淀（陪读《经济学原理》对话结束后）

当一轮曼昆陪读结束（如完成某一章的讨论）：

1. 回顾对话，找出「被挂到真实账单上」的概念（挂不上的概念不收录——这是本 skill 和摘要笔记的核心区别）
2. 为每个概念写/更新概念卡到 `references/concepts.md`，格式：
   - `## 概念名`（含原书位置，如「曼昆微观 Ch.1 原理二」）
   - 定义（大白话）/ 经典例（书里的）/ Bonnie 案例（从 cases.md 引用或直接摘录）/ 常见误用（对话中实际纠正过的误解优先）
3. 在 `references/cases.md` 追加新案例，标注来源日期
4. 更新本文件路由表（如果有新概念）

### 原则

- **不挂账的概念不出卡**：只输出能与用户真实处境连接的概念
- **一次最多 3 张**：透镜糊了等于没戴
- **案例优先级**：cases.md 真实案例 > 对话中当场提取 > 书中经典例
- **误用比定义更重要**：每张卡必须写「常见误用」，这是透镜的防伪标
