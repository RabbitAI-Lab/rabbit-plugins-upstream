## Description:

用曼昆经济学概念分析真实决策与现象，并将陪读讨论沉淀为可应用的概念卡。

This skill is ready for commercial/non-commercial use.

[bonniegeng-max](https://clawhub.ai/user/bonniegeng-max)

### License/Terms of Use:

## Use Case:

面临工作、商业、新闻或生活决策的用户，可用它从经济学角度梳理取舍、激励与市场影响。陪读《经济学原理》时，也可将讨论沉淀为概念卡，并用反思问题连接到实际情境。

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A broad conversational trigger may activate the skill during ordinary discussion.

Mitigation: Review whether the everyday-phrase trigger suits your workflow, and narrow it if it causes unwanted activations.

Risk: The referenced local cases.md file was unavailable during scanning, so behavior involving those entries was not fully reviewed.

Mitigation: Keep personal case entries local and use the bundled cases-template.md for shared releases; review any local cases before using them.
