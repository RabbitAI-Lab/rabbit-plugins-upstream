## Description:

Connects agents to Kimi K3 for text generation and analysis of supplied text, images, and video.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and other agents use this skill to request complex analysis, writing, and coding help from Kimi K3, including questions about supplied images or videos.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected media files are sent to dLazy's hosted service.

Mitigation: Review prompts and files before submission; do not send sensitive material unless intended.

Risk: Using the dLazy service requires an API key stored or supplied to the CLI.

Mitigation: Protect the key and rotate or revoke it when no longer needed.
