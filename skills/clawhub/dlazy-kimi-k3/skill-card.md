## Description:

Uses the hosted Kimi K3 model to generate text for analysis, coding, and writing, with optional image and video understanding.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and other users can ask Kimi K3 to analyze information, help with code, and draft text using prompts and optional images or videos.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected local media may be sent to dLazy cloud services.

Mitigation: Review prompts and files for sensitive information before submitting them.

Risk: Logging in stores an API key locally.

Mitigation: Use DLAZY_API_KEY per invocation if local key storage is unsuitable.
