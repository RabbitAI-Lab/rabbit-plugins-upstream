# 产品解读模板

## 结构

```
1. 标题（含产品名+核心升级/认证/能力）

2. 开头（1段）
   - 一句话说清"什么产品出了什么变化"
   - 立即说明这个变化对用户意味着什么

3. 背景与趋势（1-2段）
   - 行业背景：为什么需要这个能力/认证
   - 不要写太长的行业铺垫，读者关心的是产品变化

4. 核心内容（主体）
   - 新能力/新版本：具体是什么、怎么用、有什么数据
   - 认证解读：认证标准考什么、通过意味着什么、对选型的参考价值
   - 不罗列全部功能，选最有差异化的2-3个展开

5. 对用户的影响
   - 现有用户怎么用（升级路径/兼容性）
   - 潜在用户怎么看（选型参考）

6. 结尾
   - **{品牌名}，帮助xxx企业xxx。**
```

## 字数：1500-2200字

## 要点
- 不写成"我们发布了好厉害"的自夸体
- 读者关心的是"这对我有什么用"
- 认证类文章重点解读标准本身的价值，而非通过考试的荣耀感
