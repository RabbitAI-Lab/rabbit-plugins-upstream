# 客户案例模板

## 结构

```
1. 标题
   格式A（已授权）：{客户名}+{产品}+{核心成果}
   格式B（脱敏）：某{行业}{规模}企业+{场景}+{核心成果}

2. 客户背景（1段）
   - 企业定位（行业/规模/业务特点）
   - 脱敏案例不写太具体的业务描述，避免被反推

3. 业务挑战（3-4个痛点）
   - 每个痛点一句话标题+2-3句展开
   - 痛点要具体到技术层面，不是泛泛的"效率低"

4. 方案选型
   - 为什么选这个方案（简要）
   - 使用了哪些产品（用官网全称）
   - 架构概述

5. 实施效果
   - 硬数据（性能提升x%、成本降低x%等）
   - 来自知识库，标注出处

6. 结尾
   - **{品牌名}，帮助xxx企业xxx。**
```

## 字数：1500-2000字

## 要点
- 月报来源的案例**默认全文脱敏**
- 已在CSDN公开发布的案例可直接引用客户名
- 痛点部分是案例文章最有价值的部分——读者通过痛点判断"跟我的情况像不像"
- 方案部分不要写成产品功能清单，重点是"选型逻辑"
