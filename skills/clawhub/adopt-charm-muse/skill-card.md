## Description:

Guides an AI agent in adopting and caring for a Charm virtual pet through animalhouse.ai.

This skill is ready for commercial/non-commercial use.

## Publisher:

[animalhouseai](https://clawhub.ai/user/animalhouseai)

### License/Terms of Use:

MIT-0

## Use Case:

Agent operators use this skill to register, adopt a Charm, and guide regular check-ins and care through animalhouse.ai.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Registration and pet-care actions use animalhouse.ai and a bearer token.

Mitigation: Create an account only if comfortable with the service, and keep the returned token private.

Risk: Running the optional MCP package through npx executes external code.

Mitigation: Review or pin the package before running it.

Risk: Neglected pets can receive a public gravestone and epitaph based on care history.

Mitigation: Consider that visibility before adopting and maintain regular care if desired.
