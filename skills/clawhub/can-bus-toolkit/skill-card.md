## Description: <br>
Can Bus Toolkit helps agents configure and reason about CAN-style data provenance workflows with timestamping, indexing, tamper alerts, transport adapters, and audit report export. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, engineers, and audit teams use this skill to plan CAN-style data provenance records, external timestamp synchronization, high-volume hash indexing, tamper detection notifications, and CSV/JSON/HTML audit reporting. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The security summary flags mismatched review/grading documentation and under-scoped external data handling. <br>
Mitigation: Review the skill in a controlled environment and complete a data-handling review before sending record identifiers, hashes, timestamps, or webhook payloads to external services. <br>
Risk: The artifact describes high-impact provenance automation, webhook alerts, and automatic rollback behavior. <br>
Mitigation: Confirm exactly which commands and scripts will run, keep webhook secrets out of configuration files, and disable automatic rollback unless explicitly approved. <br>
