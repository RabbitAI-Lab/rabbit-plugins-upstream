# 古文活过来 — AI古文动画短视频创作 Skill

> 融合 8 个对标账号创作手法：第二课堂（课堂式）/ 古人来敲门（情景剧）/ 拾文予童的一堂课（亲子教育×AI语文）/ 银河第一课（AI+古文+历史）/ 孔孟道（先贤智慧育儿）/ 苏先生的答案（先贤×穿越）/ 斯文的灰鸽子（国学解读）/ 小满的一堂课（课文考点）
> 数据来源：抖音作品接口 + 蝉妈妈 + 用户投喂（游客态抓取，赞/评/转/藏/时长为实时值）

## 核心理念

> 古文不是用来背的，是活过一遍又活过来的。

四条原则：
1. **一句话破题** — 用学生听得懂的现代生活语言讲出核心矛盾
2. **情境拉满** — 把古代场景"搬"到今天，让学生代入角色
3. **人物有血有肉** — 不扁平化古人，呈现情绪、动机与微妙之处
4. **落脚在当下的道理** — 讲完古文，让学生带走一个用得上的思考

新增原则（v3.0.0，来自 8 账号验证）：
5. **替用户提问** — 钩子不是"讲知识"，是"替目标用户问出心里话"
6. **为转发设计金句** — 内容本质是社交货币，第4幕必须有"值得转给孩子/学生"的金句
7. **转赞比是北极星** — 爆款信号 = 转发+收藏双高，评论低是常态

## 触发条件

当用户表达以下任一意图时触发：
- 想做一个 AI 教育/古文/语文类的短视频账号
- 想参考某个账号（如第二课堂、古人来敲门、孔孟道、苏先生）做同类型账号
- 为已有账号生成一条古文动画视频的完整脚本
- 需要 AI 提示词（文生图、文生视频、配音等）
- 需要账号内容日历/运营规划
- 提到"四幕法""古文IP""穿越见古人"等核心手法

## 工作流

### Step 0：选题定位（v3.0.0 新增）

**按爆款潜力排序的四大选题方向**（来自 6 账号横向分析）：

| 优先级 | 方向 | 公式 | 爆款证据 | 目标人群 |
|--------|------|------|---------|---------|
| 🥇 P0 | 家长/学生痛点×先贤故事 | 孩子XX怎么办？→先贤故事→金句 | 孔孟道 174.5万/114.8万 | 家长（转给孩子） |
| 🥈 P0 | 课文/寓言×反常识提问 | 重读XX才懂XX / XX里最可悲的是什么 | 拾文 64.2万/银河 60.5万 | 学生+家长 |
| 🥉 P1 | 经典解读×国学智慧 | 逐章解读（无痛点） | 灰鸽子 5.3万封顶 | 收藏型 |
| P2 | 节日/应景 | 金榜题名/端午等 | 千级（低） | — |

**选题红线**：
- ❌ 纯知识选题是流量陷阱（灰鸽子反证）——必须叠加痛点/情绪
- ❌ 节日应景不作主赛道（各账号千级）
- ❌ 卷李白/杜甫/苏轼内卷 → 选冷门角度差异化

**首发选题矩阵**（验证过的高潜力组合）：
- 读书好累学习没用（劝学）— 拾文64.2万/银河5.1万双验证
- 网络烂梗/表达丢失 — 孔孟道114.8万
- 隐形霸凌/被孤立 — 孔孟道174.5万
- 伤仲永（天赋vs努力）— 小满2.97万（新号空间大）
- 桃花源记（找不到的不是路是人心）— 银河9094

### Step 1：竞品分析（参考账号解构）

当用户提供一个抖音链接或账号名时：

1. **链接解析**：用浏览器打开链接，获取 snapshot
2. **数据提取**：从页面提取以下关键字段
   - 作者/账号名 + 粉丝数 + 获赞数
   - 视频标题 + 发布时间 + 播放/点赞/分享/收藏数据
   - 作者声明（是否 AI 生成：检查 `作者声明：内容由 AI 生成`）
   - 视频时长
   - 话题标签
   - 评论区互动关键词
3. **风格分析**：AI 画风 / 色调倾向 / 视频结构 / 角色呈现 / BGM 风格
4. **成功要素提炼**：用户画像 / 内容价值 / 分享动力 + **转赞比/藏赞比/评赞比信号**（爆款共性：转发+收藏双高）

### Step 2：差异化定位

基于竞品分析，定位新账号的独特位置：

| 维度 | 分析要素 |
|------|---------|
| **赛道** | 课本同步（刚需） / 人生哲理（情绪） / 考点提分（焦虑） |
| **画风** | 水墨国风 / 写实CG / 皮影剪纸 / 3D卡通 / 手绘 |
| **结构** | 纯讲解 / 剧情演绎 / 古人第一人称 / 考点拆解 / 穿越见证 |
| **时长** | 1-2min（轻量）/ 3-6min（标准，v3.0 拉宽）/ 深度 |
| **目标人群** | 初中生 / 小学生 / 家长 / 全体 |

**差异化工具：** 在竞品分析表中标注「竞品做什么，我做什么不同」

#### 4.2 先写故事（Story First）

**核心原则：先写故事，再写脚本。** 故事写作规则：

| 规则 | 说明 |
|------|------|
| 🎯 有主角 | 确定故事的主角（通常是一个古人） |
| 🎭 有冲突 | 找出原文中的矛盾/张力 |
| 💬 有对话 | 把文言文直接变成角色之间的对话 |
| 🔥 有情绪 | 让读者感受到古人的情绪 |
| 🌉 有现代关联 | 在结尾把古代困境拉到今天 |

#### 4.3 故事转脚本 + 四幕法结构（v2.9 骨架，8 账号验证）

```
第1幕 冲突开局（0-15s）：替学生/家长提问 or 反常识颠覆 or 情绪冲击（铁律：前3秒必须有钩子，≤15s）
第2幕 历史处境（15-60s）：还原作者真实人生处境，让观众"进入"（差异化护城河，无人做深）
第3幕 原文演绎（60-150s）：古文原句在情绪高点砸下，名句=情绪落点，考点自然嵌入
第4幕 克制和解（150-210s）：价值观金句收尾 + 现代学生与古人和解 + 转发设计（金句=值得转给孩子的话）
```

**钩子库（前3秒，8条）**：
1. 替用户提问「读书好累，学习没用？」
2. 身份反差「两千年前的人，给我上了一课」
3. 反常识金句「他是从鬼门关回来才写'轻舟已过万重山'的」
4. 场景悬念「如果苏轼有朋友圈…」
5. 情绪冲击（孩子摔门而出+字幕「我讨厌背古文」）
6. 家长痛点提问「孩子总把烂梗挂嘴边」
7. 痛点具象化（霸凌画面+「被孤立的那天，没人帮他」）
8. 第一人称手记「我写了这个故事——给所有考砸了的孩子」

**v3.0 关键升级**：
- 时长拉宽到 **3-6 分钟**（原 3:40 定式）
- 第4幕金句 = **转发设计**（必须是一句"值得转给孩子/学生"的话）
- 转赞比检查点：写完自查——"观众会转发吗？会收藏吗？"

#### 4.4 去 AI 化（双层质检）

**文案去 AI 腔（7 类黑名单）**：万能套话开头 / 过度工整排比 / 句句金句化（金句≤2句）/ 情绪贴标签 / 书面腔混口语 / 完美闭环 / 评论腔结尾

**人味改写五法**：加废话 / 留半句 / 动作代替形容词 / 数字细节 / 打破节奏

**画面去 AI 味**：不完美细节埋点 + 禁止词（精致/唯美/梦幻/华丽/完美/无瑕/闪耀）

**v3.0 新增人味手法（学苏先生）**：第一人称创作手记「我写了这个故事…」+ 避免播音腔，用自然带情绪颗粒感的声音

#### 5.3 数据复盘（v3.0 新增）

**北极星 = 转赞比**（爆款 34-90%）+ **藏赞比**（19-86%）；评论低（1.5-3%）是常态

| 指标 | 健康线 | 不达标 → 动作 |
|------|--------|--------------|
| 5秒完播率 | ≥40% | 换开场钩子逻辑 |
| 2秒跳出率 | 低 | 钩子三通道检查 |
| 赞粉比 | >2:1 | 警惕投流/低质量流量（典里有戏 1.04:1 案例） |

**评论区三层运营**：置顶情感话题 / 回复中嵌入考点 / 号召收藏（"考前再看一遍"）

## 使用约束

- ✅ 可以修改风格以适应不同年级
- ✅ 可以自由扩展延申思考（保持原文原意）
- ✅ 可以选「课堂讲解 / 穿越见证 / 情景演绎」三种类型
- ❌ 不能歪曲原文含义为趣味而趣味
- ❌ 不能为了"好理解"而省略关键考点
- ❌ 不能编造不存在的历史背景或人物关系
- ❌ 不能做纯知识选题（无痛点/情绪）——流量陷阱
- ❌ 不交付未过质检脚本（去AI化双层检查）

## 注意事项

- **⚠️ 事实核查**：文言文原文必须与教材完全一致，不可 AI 随意修改
- **⚠️ 版权**：生成新故事时用"同风格再创作"，不是照抄原账号
- **⚠️ 人物一致性**：同一个人物保持面部一致，用 seed/参考图/角色资产库
- **⚠️ 画面上限**：写实古风易陷入诡异谷，多用暖光、虚化背景规避
- **⚠️ 多角色配音**：区分叙事旁白和角色配音，不要让 AI 用同一个声音读所有人台词
- **⚠️ 封面文字**：AI 直出中文易乱码，生图不带字，后期剪映叠字
