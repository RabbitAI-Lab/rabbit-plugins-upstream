# 古文活过来 — AI古文动画短视频创作 Skill

## 概述

本 Skill 提供一套从「竞品分析→账号设计→内容生产→发布运营」的全流程方法论，用于在抖音等短视频平台创建以 AI 动画演绎古文/文言文为内容的账号。核心是让「古人自己说话」，融合第二课堂的知识科普与古人来敲门的情感共鸣。

## 触发条件

当用户表达以下任一意图时触发：
- 想做一个 AI 教育/古文/语文类的短视频账号
- 想参考某个账号（如第二课堂、古人来敲门）做同类型账号
- 为已有账号生成一条古文动画视频的完整脚本
- 需要 AI 提示词（文生图、文生视频、配音等）
- 需要账号内容日历/运营规划

## 工作流

### Step 1：竞品分析（参考账号解构）

当用户提供一个抖音链接或账号名时：

1. **链接解析**：用浏览器打开链接，获取 snapshot
2. **数据提取**：从页面提取以下关键字段
   - 作者/账号名 + 粉丝数 + 获赞数
   - 视频标题 + 发布时间 + 播放/点赞/分享/收藏数据
   - 作者声明（是否 AI 生成：检查 `作者声明：内容由 AI 生成`）
   - 视频时长（从 `statictext "00:00 / XX:XX"` 提取）
   - 话题标签（`#` 开头的文字）
   - 评论区互动关键词（提取热门评论的前 3 条）
3. **风格分析**：从页面结构和推荐视频推断
   - AI 画风（水墨国风 / 写实CG / 3D卡通 / 扁平插画）
   - 色调倾向（暖棕古书/冷蓝科技/金红古风）
   - 视频结构（纯旁白 / 多角色对话 / 分镜讲解）
   - 角色呈现（人物出镜 / 插画 + 字幕 / 纯动画）
   - BGM 风格（古琴/轻音乐/钢琴/电子）
4. **成功要素提炼**：分析其爆款逻辑
   - 用户画像（学生？家长？泛人群？）
   - 内容价值（知识刚需 vs 情绪共鸣）
   - 分享动力（实用收藏 vs 情感转发）

### Step 2：差异化定位

基于竞品分析，定位新账号的独特位置：

| 维度 | 分析要素 |
|------|---------|
| **赛道** | 课本同步（刚需） / 人生哲理（情绪） / 考点提分（焦虑） |
| **画风** | 水墨国风 / 写实CG / 皮影剪纸 / 3D卡通 / 手绘 |
| **结构** | 纯讲解 / 剧情演绎 / 古人第一人称 / 考点拆解 |
| **时长** | 1-2min（轻量）/ 2-4min（标准）/ 4-6min（深度） |
| **目标人群** | 初中生 / 小学生 / 家长 / 全体 |

**差异化工具：** 在竞品分析表中标注「竞品做什么，我做什么不同」

### Step 3：账号设计

输出完整的账号配置：

```
## 账号身份卡
- 账号名：_____
- 简介（≤100字）：_____
- 头像描述（AI生图提示词）：_____
- 背景图描述：_____
- 视觉主色调：_____
- AI画风标签：_____

## 内容产品线（通常3条线）
1. 主产品线（80%）：引流款 → _______
2. 爆款产品线（15%）：冲量款 → _______
3. 互动产品线（5%）：互动款 → _______

## 发布节奏
- 频率：每周___条
- 时段：_______
- 最佳时长：_______
```

### Step 4：单条视频生产（核心模块）

#### 4.1 选题与脚本

**选题公式：** `课文/古文名称 + 现代痛点钩子`

示例：
- 陈太丘与友期行 → "朋友迟到该不该等？"
- 咏雪 → "两个比喻，哪个更好？"
- 论语 → "如果孔子是你同桌"
- 次北固山下 → "一个唐朝人在船上想什么"

**核心原则：全故事演绎，零旁白。** 所有信息通过角色台词+动作+字幕传达，不出现讲解式的叙事旁白，严格避免第三人称解说。

**脚本结构（标准模板）：**

```
┌───────── 剧本格式（纯故事演绎）─────────────────┐
│                                                  │
│  【场景1】现代钩子（画面驱动，无台词）          │
│    · 画面：现代场景，人物动作叙事                │
│    · 字幕：钩子文字                              │
│    · 音效：环境音                                │
│                                                  │
│  【场景2】穿越转场（纯视觉，无台词）             │
│    · 画面：现代→古代转场动画                     │
│    · 音效：转场音效+BGM起                        │
│                                                  │
│  【场景3-N】古人故事演绎（角色台词驱动）        │
│    · 角色A（语气）：[台词]                       │
│    · 角色B（语气）：[台词]                       │
│    · 动作描述：[人物做什么]                      │
│    · 字幕：文言原文弹出 + 考点词高亮             │
│                                                  │
│  【结尾场景】角色面对镜头（打破第四面墙）       │
│    · 角色（语气）：[互动提问]                    │
│    · 字幕：关注引导                              │
└──────────────────────────────────────────────────┘
```

**剧本编写规则：**

| 规则 | 说明 |
|------|------|
| 🚫 禁止旁白 | 背景信息通过角色对话或画面自然透露，不出现叙事旁白 |
| 💬 角色台词 | 角色名（语气）：[台词]，如：友人（怒喝）：非人哉！ |
| 🎬 动作描写 | 用[方括号]描述，如：[友人骑马来到门前，翻身下马] |
| 🎥 运镜标注 | 每个场景标注镜头运动方式：推/Push In、拉/Pull Out、摇/Pan、移/Track、跟/Follow、升降/Boom Up/Down、固定/Static、手持/Handheld |
| 🖼️ **画面用中文展示** | 聊天预览中画面描述写中文，说清楚画面内容和氛围。**英文 AI prompt 放在下方或折叠区作为技术参考**，不占据主展示位 |
| 📜 文言原文 | 作为字幕弹出，关键考点词黄色高亮标注 |
| 🎯 结尾互动 | 角色直接对镜头说话，抛出讨论问题 |

**剧本模板（完整结构）：**
```
# 《标题》— 完整拍摄脚本

## 📇 统一提示词参考卡（AI生成时使用）

### 角色提示词
- [角色A]：[外貌+服装+年龄+表情基调]
- [角色B]：[外貌+服装+年龄+表情基调]

### 场景基调提示词
[统一的时间、光色、风格、构图，所有场景共用]

### 画面风格提示词
[画风描述：写实古风CG/水墨等]

---

## 分镜表

### 场景X｜时间

🎨 **画面**
（中文描述）

🎥 **运镜**
（中文描述）

💬 **台词**
角色名（语气）：台词

📝 **字幕**
弹出的文字内容

🔊 **音效**
音效说明
```

**常用运镜速查表：**

| 运镜 | 英文 | 用法场景 |
|------|------|---------|
| 推 | Push In | 强调情绪、揭示细节、进入角色内心 |
| 拉 | Pull Out | 揭示环境、制造距离感、落幕 |
| 横摇 | Pan | 展示场景全貌、连接两个空间 |
| 横移 | Track/Truck | 平行跟随人物运动，有沉浸感 |
| 跟 | Follow | 跟随角色移动（背面跟/侧面跟） |
| 升降 | Boom Up/Down | 展示高度落差、气势/卑微反差 |
| 固定 | Static | 对话场景、角色直视镜头 |
| 手持微晃 | Handheld | 紧张、冲突、不安定情绪 |
| 变焦 | Zoom | 快速聚焦/拉开，制造冲击 |
| 环绕 | Orbit | 围绕角色360度，高潮情绪渲染 |

**运镜标注格式：**
每个场景在 `动画：` 行中，`【运镜】` 后标明运镜类型，如：
```
动画：[友人骑马赶来，下马敲门]
【运镜】推：从全景推到友人愤怒的面部特写
```
或：
```
动画：【运镜】固定→推。门缓缓打开，元方站在门内。镜头从全景慢慢推到元方面部
```

**可选结尾彩蛋：考点速记卡**

生产者在主故事之后可增加考点速记彩蛋，格式如下：
```
【彩蛋】考点速记卡（15秒）
· 画面：古书卷毛笔书写方式弹出重点词
· 配音：无（纯画面+字幕+轻音效）
· 字幕：期→约定 ▪ 去→离开 ▪ 委→丢下 ▪ 引→拉 ▪ 顾→回头看
```
彩蛋与主故事用标题卡隔开，不影响沉浸感。

#### 4.2 AI 文生图提示词生成

**核心原则：人物提示词与场景提示词分开书写**，确保同一人物在不同场景中相貌、服装一致性。

**写实古风CG 人物提示词模板：**
```
【人物】[角色名]，[年龄]岁，[性别]，[外貌特征：发型/面容/气质]，
[服装]（[颜色][形制]汉服/衣着），
[动作/表情]，[视角]（正面/侧面/全身/半身），
写实古风CG，电影质感，9:16竖屏
```

**写实古风CG 场景提示词模板：**
```
【场景】[时代]（东汉/唐代/宋代），[地点]（庭院/街道/书院），
[环境细节]（建筑/摆设/植被），[天气/时间]，
[色调]（暖金/琥珀/青绿），[风格]写实CG，电影质感，9:16竖屏
```

**场景中展示格式：**
```
🤖 **人物提示词**
[角色名]：____

🤖 **场景提示词**
____
```

**提示词模板（水墨国风版）：**

```

传统水墨画风格，淡彩渲染，松散笔触，诗意留白，
```

#### 4.4 配音设置

根据不同角色场景选用：

| 角色类型 | 声音特征 | 推荐工具 |

| 古人（长者） | 低沉男声，语速0.9 | ElevenLabs / Azure Yunxi |

| 愤怒角色 | 粗犷男声，语速1.2 | 剪映TTS大龙（提高音调） |
| 儿童角色 | 童声，语速1.0 | 剪映TTS童声系列 |

### Step 5：发布策略

#### 5.1 标题公式

```
[数字/情绪钩子] + [内容亮点] + [身份词/标签]
```

示例：
- "同学迟到你会等吗？看1800年前的7岁少年怎么回答 🏮"
- "如果谢道韫有朋友圈，她会发什么？3分钟看完"
- "孔子要是你同桌，第一句话会说什么？"

#### 5.2 标签矩阵

```
#精准学科标签  #关联流量赛马   #平台扶持标签   #人群情绪标签
```

示例：
```
#七年级语文 #陈太丘与友期行 #用AI打开100部人文经典 #文脉里的中国 #AI创作浪潮计划 #亲子教育 #古文
```

#### 5.3 发布节奏

- **冷启动期（前2周）**：每周3-4条，测试不同选题方向
- **成长期（第3-4周）**：聚焦数据最好的方向，系列化
- **爆发期（第5周+）**：固定栏目+互动话题+评论区运营

- [ ] 考点词汇是否已做标注
- [ ] 是否包含互动引导

## 注意事项

- **⚠️ 事实核查**：文言文原文必须与教材完全一致，不可 AI 随意修改
- **⚠️ 版权**：生成新故事时用"同风格再创作"，不是照抄原账号
- **⚠️ 人物一致性**：同一个账号内，同一个人物（如孔子、元方）要保持面部一致，通过 seed 值或固定参考图实现
- **⚠️ 画面上限**：写实古风易陷入诡异谷，多用暖光、虚化背景规避
- **⚠️ 多角色配音**：需区分叙事旁白和角色配音，不要让 AI 用同一个声音读所有人台词
