# 古文活过来 — AI古文动画短视频创作 Skill

## 概述

本 Skill 提供一套从「竞品分析→账号设计→内容生产→发布运营」的全流程方法论，用于在抖音等短视频平台创建以 AI 动画演绎古文/文言文为内容的账号。核心是让「古人自己说话」，融合第二课堂的知识科普与古人来敲门的情感共鸣。

## 触发条件

当用户表达以下任一意图时触发：
- 想做一个 AI 教育/古文/语文类的短视频账号
- 想参考某个账号（如第二课堂、古人来敲门）做同类型账号
- 为已有账号生成一条古文动画视频的完整脚本
- 需要 AI 提示词（文生图、文生视频、配音等）
- 需要账号内容日历/运营规划

## 工作流

### Step 1：竞品分析（参考账号解构）

当用户提供一个抖音链接或账号名时：

1. **链接解析**：用浏览器打开链接，获取 snapshot
2. **数据提取**：从页面提取以下关键字段
   - 作者/账号名 + 粉丝数 + 获赞数
   - 视频标题 + 发布时间 + 播放/点赞/分享/收藏数据
   - 作者声明（是否 AI 生成：检查 `作者声明：内容由 AI 生成`）
   - 视频时长（从 `statictext "00:00 / XX:XX"` 提取）
   - 话题标签（`#` 开头的文字）
   - 评论区互动关键词（提取热门评论的前 3 条）
3. **风格分析**：从页面结构和推荐视频推断
   - AI 画风（水墨国风 / 写实CG / 3D卡通 / 扁平插画）
   - 色调倾向（暖棕古书/冷蓝科技/金红古风）
   - 视频结构（纯旁白 / 多角色对话 / 分镜讲解）
   - 角色呈现（人物出镜 / 插画 + 字幕 / 纯动画）
   - BGM 风格（古琴/轻音乐/钢琴/电子）
4. **成功要素提炼**：分析其爆款逻辑
   - 用户画像（学生？家长？泛人群？）
   - 内容价值（知识刚需 vs 情绪共鸣）
   - 分享动力（实用收藏 vs 情感转发）

### Step 2：差异化定位

基于竞品分析，定位新账号的独特位置：

| 维度 | 分析要素 |
|------|---------|
| **赛道** | 课本同步（刚需） / 人生哲理（情绪） / 考点提分（焦虑） |
| **画风** | 水墨国风 / 写实CG / 皮影剪纸 / 3D卡通 / 手绘 |
| **结构** | 纯讲解 / 剧情演绎 / 古人第一人称 / 考点拆解 |
| **时长** | 1-2min（轻量）/ 2-4min（标准）/ 4-6min（深度） |
| **目标人群** | 初中生 / 小学生 / 家长 / 全体 |

**差异化工具：** 在竞品分析表中标注「竞品做什么，我做什么不同」

输出完整的账号配置：


### Step 4：单条视频生产（核心模块）

#### 4.1 选题

**选题公式：** `课文/古文名称 + 现代痛点钩子`

示例：
- 陈太丘与友期行 → "朋友迟到该不该等？"
- 咏雪 → "两个比喻，哪个更好？"
- 论语 → "如果孔子是你同桌"
- 次北固山下 → "一个唐朝人在船上想什么"

#### 4.2 先写故事（Story First）

**核心原则：先写故事，再写脚本。** 不要直接开始分镜。先想清楚你要讲一个什么样的故事，把全文翻译/演绎成一段精彩的叙事文本。

**故事写作规则：**

| 规则 | 说明 |
|------|------|
| 🎯 有主角 | 确定故事的主角（通常是一个古人），赋予他/她鲜明的性格 |
| 🎭 有冲突 | 找出原文中的矛盾/张力——训斥、质疑、反转、选择 |
| 💬 有对话 | 把文言文直接变成角色之间的对话，不要转述 |
| 🔥 有情绪 | 愤怒、委屈、骄傲、羞愧——让读者感受到古人的情绪 |
| 🌉 有现代关联 | 在结尾把古代困境拉到今天，让读者联想到自己 |

**故事模板：**

```
## 《选题》— 故事版

主角：[人物，一句话描述性格]
冲突：[原文的矛盾点]

### 故事正文

（一段叙事，把文言文翻译成生动的现代故事。
包含人物对话、动作描写、情绪变化。
结尾自然地引出一个现代议题。）
```

**示例（陈太丘与友期行）：**

```
## 《陈太丘与友期行》— 故事版

主角：元方，7岁，一个比同龄人懂事太多的孩子。
冲突：父亲的迟到朋友不仅不道歉，还反过来骂人。

### 故事正文

正午已过。陈太丘站在门口看了一眼日头，摇了摇头，上车走了。

他前脚刚走，后脚一个穿棕色袍子的中年人气喘吁吁骑马赶到。翻下马一看——门关了，人走了。

"非人哉！"他重重砸门，"与人期行，相委而去！"

门开了一条缝。一个7岁的小男孩站在里面，穿浅蓝色的小汉服，头上扎一个小发髻。他看着门外暴跳如雷的大人，没有害怕。

"您与我父亲约好正午，"男孩说，声音不大，但很清晰，"您正午没到——是您不守信。现在对着儿子骂父亲——是您没有礼貌。"

中年人愣住了。他的手慢慢放下来，嘴张了张，什么也没说出来。

男孩把门关上了。他转身走回院子里，没有回头。

门口只剩下一个大人和快要落下去的太阳。

### 结尾转折

如果你是元方，你会怎么做？
如果迟到的人换成你，你会怎么想？
```

#### 4.3 故事转脚本（Story → Script）

故事写好后，按以下步骤拆分为分镜：

1. **拆场景**：把故事分成3-7个场景，每个场景一个镜头
2. **标时间**：每个场景分配时间轴（通常20-40秒/场景）
3. **加运镜**：每场景标注镜头运动方式
4. **配台词**：直接从故事中提取对话，标注角色和语气
5. **定字幕**：把关键对话/文言原文提炼为字幕标题
6. **写画面**：用中文描述每个场景的视觉内容和氛围
7. **出参考卡**：汇总角色提示词+场景基调+画面风格

**转换对照表：**

| 故事元素 | 脚本元素 |
|---------|---------|
| 叙事背景 | 画面描述（中文） |
| 人物对话 | 角色名（语气）：台词 |
| 动作描写 | 运镜标注 + 画面动作 |
| 情绪氛围 | 色调 + 音效 + 运镜节奏 |
| 结尾转折 | 角色面对镜头 + 字幕互动 |
| 关键金句 | 字幕弹出 |

#### 4.4 脚本结构（标准模板）

**核心原则：全故事演绎，零旁白。** 所有信息通过角色台词+动作+字幕传达，不出现讲解式的叙事旁白，严格避免第三人称解说。

**剧本模板（完整结构）：**
```
# 《标题》— 完整拍摄脚本

## 📇 统一提示词参考卡（AI生成时使用）

### 角色提示词
- [角色A]：[外貌+服装+年龄+表情基调]
- [角色B]：[外貌+服装+年龄+表情基调]

### 场景基调提示词
[统一的时间、光色、风格、构图，所有场景共用]

### 画面风格提示词
[画风描述：写实古风CG/水墨等]

---

## 分镜表

### 场景X｜时间

🎨 **画面**
（中文描述）

🎥 **运镜**
（中文描述）

💬 **台词**
角色名（语气）：台词

📝 **字幕**
弹出的文字内容

🔊 **音效**
音效说明
```

**常用运镜速查表：**

| 运镜 | 英文 | 用法场景 |
|------|------|---------|
| 推 | Push In | 强调情绪、揭示细节、进入角色内心 |
| 拉 | Pull Out | 揭示环境、制造距离感、落幕 |
| 横摇 | Pan | 展示场景全貌、连接两个空间 |
| 横移 | Track/Truck | 平行跟随人物运动，有沉浸感 |
| 跟 | Follow | 跟随角色移动（背面跟/侧面跟） |
| 升降 | Boom Up/Down | 展示高度落差、气势/卑微反差 |
| 固定 | Static | 对话场景、角色直视镜头 |
| 手持微晃 | Handheld | 紧张、冲突、不安定情绪 |
| 变焦 | Zoom | 快速聚焦/拉开，制造冲击 |
| 环绕 | Orbit | 围绕角色360度，高潮情绪渲染 |

**运镜标注格式：**
每个场景在 `动画：` 行中，`【运镜】` 后标明运镜类型，如：
```
动画：[友人骑马赶来，下马敲门]
【运镜】推：从全景推到友人愤怒的面部特写
```
或：
```
动画：【运镜】固定→推。门缓缓打开，元方站在门内。镜头从全景慢慢推到元方面部
```

**可选结尾彩蛋：考点速记卡**

生产者在主故事之后可增加考点速记彩蛋，格式如下：
```
【彩蛋】考点速记卡（15秒）
· 画面：古书卷毛笔书写方式弹出重点词
· 配音：无（纯画面+字幕+轻音效）
· 字幕：期→约定 ▪ 去→离开 ▪ 委→丢下 ▪ 引→拉 ▪ 顾→回头看
```
彩蛋与主故事用标题卡隔开，不影响沉浸感。

#### 4.6 AI 文生图提示词生成

**核心原则：人物提示词与场景提示词分开书写**，确保同一人物在不同场景中相貌、服装一致性。

**写实古风CG 人物提示词模板：**
```
【人物】[角色名]，[年龄]岁，[性别]，[外貌特征：发型/面容/气质]，
[服装]（[颜色][形制]汉服/衣着），
[动作/表情]，[视角]（正面/侧面/全身/半身），
写实古风CG，电影质感，9:16竖屏
```

**写实古风CG 场景提示词模板：**
```
【场景】[时代]（东汉/唐代/宋代），[地点]（庭院/街道/书院），
[环境细节]（建筑/摆设/植被），[天气/时间]，
[色调]（暖金/琥珀/青绿），[风格]写实CG，电影质感，9:16竖屏
```

**场景中展示格式：**
```

____
```

**提示词模板（水墨国风版）：**

### Step 5：发布策略

#### 5.1 标题公式

```
[数字/情绪钩子] + [内容亮点] + [身份词/标签]
```

示例：
- "同学迟到你会等吗？看1800年前的7岁少年怎么回答 🏮"
- "如果谢道韫有朋友圈，她会发什么？3分钟看完"
- "孔子要是你同桌，第一句话会说什么？"

#### 5.2 标签矩阵

```
#精准学科标签  #关联流量赛马   #平台扶持标签   #人群情绪标签
```

示例：
```
#七年级语文 #陈太丘与友期行 #用AI打开100部人文经典 #文脉里的中国 #AI创作浪潮计划 #亲子教育 #古文
```

#### 5.3 发布节奏

- **冷启动期（前2周）**：每周3-4条，测试不同选题方向
- **成长期（第3-4周）**：聚焦数据最好的方向，系列化
- **爆发期（第5周+）**：固定栏目+互动话题+评论区运营

## 注意事项

- **⚠️ 事实核查**：文言文原文必须与教材完全一致，不可 AI 随意修改
- **⚠️ 版权**：生成新故事时用"同风格再创作"，不是照抄原账号
- **⚠️ 人物一致性**：同一个账号内，同一个人物（如孔子、元方）要保持面部一致，通过 seed 值或固定参考图实现
- **⚠️ 画面上限**：写实古风易陷入诡异谷，多用暖光、虚化背景规避
- **⚠️ 多角色配音**：需区分叙事旁白和角色配音，不要让 AI 用同一个声音读所有人台词
