# 附录：详细行程展示格式规范

## 1. 详细行程展示要求

当用户请求"生成详细行程"后，展示的内容**必须**包含以下详细信息：

### 数据来源
详细行程 JSON 数据来自：`trip_answer.每日行程` 数组

每个元素包含：
- `title` - Day标题
- `行程路线` - 当天路线
- `时间建议` - 时间安排数组
- `美食推荐` - 餐厅数组
- `酒店` - 酒店详情对象
- `景点推荐` - 景点数组
- `date` - 日期

## 3. 详细行程展示示例

```markdown
### 🏯 Day 2（5月29日）成都 - 三国文化
**路线**：成都武侯祠博物馆 → 锦里古街 → 成都万达瑞华酒店

| 时间 | 安排 |
|------|------|

| 12:00 | 午餐：月满大江千层肚火锅(武侯祠店) |
| 14:00 | 漫步锦里古街 |
| 18:00 | 办理入住 |

**🏨 住宿**：成都万达瑞华酒店(太古里店)（¥1100/晚）

- 核心设施：免费Wi-Fi、停车场、健身房、室内游泳池、SPA、餐厅、酒吧

**📍 景点详情**：
- **成都武侯祠博物馆** ⭐4A景区
  - 📍 地址：四川省成都市武侯区武侯祠大街231号
  - ⏰ 开放时间：09:00-18:00
  - 💰 门票：¥50
  - ⏱️ 建议游览时间：2-3小时
  - 📝 简介：全国唯一一座将君主刘备与丞相诸葛亮同祀的祠庙，打破了传统礼制，百姓称'武侯祠'而非'昭烈庙'，正是对诸葛亮'功盖三分'的至高致敬。

  - 📍 地址：成都市武侯区武侯祠大街231号附1号

  - 💡 Tips：晚上逛锦里更有韵味，灯光璀璨，小吃众多

**🍜 美食详情**：
- **月满大江千层肚火锅(武侯祠店)**
  - 📍 地址：武侯区
  - 💰 人均：¥86
  - 🍽️ 特色菜品：千层肚、毛肚、鸭肠、麻辣牛肉
```

## 4. 重要提醒

1. **每一天**都必须包含完整的：行程路线、时间安排、住宿详情、景点详情、美食详情
2. **景点详情**必须包含：名称、地址、开放时间、门票、建议时间、简介、Tips
3. **美食详情**必须包含：名称、地址、人均价格、特色菜品
4. **酒店详情**必须包含：名称、价格、地址、核心设施
5. 禁止跳过任何一天的详细信息
6. 详细行程展示完毕后，添加路书引导语（不是调整引导语）

---

## 5. 简要行程 vs 详细行程引导语区别

| 类型 | 引导语 |
|------|--------|
| **简要行程** | 💡 如需调整，告诉我：<br>• 「第一天住豪华酒店」→ 升级第1天住宿<br>• 「最后一天吃肯德基」→ 修改最后一天餐饮 |
| **详细行程** | 💡 **需要生成专属路书吗？** 点击生成您的专属旅行路书~ |
