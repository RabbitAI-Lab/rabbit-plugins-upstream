# 机会发现与选品评分
<!-- version: 1.1.0 | last_updated: 2026-08-10 -->

## 选品核心思维

不要问"什么东西好卖"。

应该问：

> **"什么需求已经存在，但当前商品供给没有很好地满足？"**

寻找的是"有人买，但同行卖得很烂"的机会。

---

## 合规前置检查（选品第0步）

任何选品分析之前，先做合规排除。命中即直接淘汰，不进入后续评估。

```
Step 0a: 该商品是否属于13类禁售品？
  -> 是 → 直接淘汰（REJECT）
  -> 否 → 继续

Step 0b: 该商品是否属于限售品类（出版物/食品/演出门票/二手车/摩托车）？
  -> 是且无资质 → 直接淘汰
  -> 是且有资质 → 标注合规要求，继续
  -> 否 → 继续

Step 0c: 该商品是否涉及他人知识产权/品牌授权？
  -> 是且无授权 → 直接淘汰
  -> 否 → 进入机会评估
```

> 完整禁售/限售清单见 `references/00-platform-rules.md`。此步骤对应决策引擎 P0 层硬性淘汰。

## 7种适合闲鱼的商品类型

### 1. 强搜索型
用户已知道自己要什么（MacBook Air M2、罗杰MX Master 3S、佳能R6）。
优势：购买意图明确。

### 2. 长尾型
"Mac mini M2 双屏支架" 而非 "电脑支架"。
搜索量小但购买意图强，竞争少。

### 3. 信息差型
用户不知道去哪里买的特殊工具、小众配件、行业用品、特定型号零件。

### 4. 解决问题型
不卖"收纳盒"，卖"出租屋衣柜空间不够的收纳方案"。
从商品思维 → 问题思维。

### 5. 有明显价格差
货源¥35，闲鱼成交¥79，扣掉所有成本仍有 ≥30% 毛利。

### 6. 非标品
二手/小众/非标/个性化/长尾，淘宝不擅长覆盖的商品。

### 7. 服务型产品
AI PPT制作、AI内容生成、Skill开发、Prompt优化。
优势：几乎没有库存成本，毛利可以非常高。

## 机会来源

- 闲鱼搜索（看搜索建议词、热门关键词）
- 淘宝/天猫/拼多多/京东（看销量 + 评价差的产品）
- 小红书/抖音（看种草内容下的需求评论）
- 1688/Amazon（看货源价格差）
- Google/Reddit/海外社区（看信息差机会）
- 行业论坛/用户评论（看高频抱怨）
- 自己的客户需求（已有客户的复购请求）

重点捕捉5种需求信号：
1. 高频问题（"有没有办法……"）
2. 高频搜索（"XX怎么选"）
3. 高频抱怨（"为什么这个这么贵"）
4. 高频替代（"有没有便宜一点的"）
5. 高频专业需求（"XX型号配什么"）

## 5种商品模型

| 模型 | 典型商品 | 毛利 | 难度 | 推荐 |
|------|---------|------|------|------|
| 闲置转卖 | 手机、电脑、相机、家具 | 中 | ★★ | ★★★★ |
| 低价标品 | 配件、收纳、家居小物 | 低~中 | ★★ | ★★★★★ |
| 信息差商品 | 小众工具、特殊用品 | 中~高 | ★★★ | ★★★★★ |
| 服务型 | PPT、设计、AI、咨询 | 高 | ★★★ | ★★★★★ |
| 高客单商品 | 数码、设备、收藏品 | 高 | ★★★★ | ★★★ |

账号定位原则：一个账号 = 一个明确的人群 + 2~5个相关品类。

## 不可比性评估

最好的闲鱼商品应具备"不可比性"——用户无法直接找到完全一样的竞品。

| 商品类型 | 被复制风险 |
|---------|----------|
| 普通数据线 | 10/10 |
| 手机壳 | 10/10 |
| 普通收纳盒 | 9/10 |
| 小众配件 | 6/10 |
| 专业设备 | 4/10 |
| 专业服务 | 3/10 |
| 解决方案 | 2/10 |
| 专业知识产品 | 1~3/10 |

**原则：越容易被淘宝搜索到同款，越不应作为长期核心 SKU。**

提升不可比性的方法：
- 组合商品（支架 + 理线器 + 收纳 = "桌面效率套装"）
- 增加服务（商品 + 安装指导 + 售后）
- 改变定义（从"卖商品"到"卖解决方案"）

## 利润来源分析

判断商品利润来自哪里：

```
利润 = 信息差 + 供应链差 + 服务差 + 信任差 + 流量差 + 效率差
```

如果利润 90% 来自"别人还不知道这个货源"，很脆弱。
如果利润来自独特供应链 + 专业服务 + 内容能力 + 客户关系，才可能持续。

## 账号权重与流量基线

> **合规边界**：账号权重是平台基于真实交易行为给出的信任评价，只能通过真实、合规的经营逐步积累。任何通过虚假交易、刷量、批量注册账号等方式提升权重或规避平台限制的行为均属违规，本系统明确禁止。

闲鱼的流量分配高度依赖账号权重。同样的商品，新账号和老账号的初始曝光可能相差 5-10 倍。选品分析时必须将账号权重作为前置条件。

### 影响账号权重的因素

| 因素 | 影响 | 说明 |
|------|------|------|
| 芝麻信用 | 高 | 信用分越高，初始流量越好 |
| 账号活跃度 | 中 | 经常浏览/搜索/互动的账号更活跃 |
| 历史交易量 | 高 | 成交越多，平台信任度越高 |
| 好评率 | 高 | 差评会显著降权 |
| 违规记录 | 致命 | 违规会导致限流甚至封号 |
| 账号垂直度 | 中 | 同一类目持续发布，平台会打标签给精准流量 |
| 实名认证 | 基础 | 未实名几乎无流量 |
| 闲气值 | 致命 | <80分即被限制发布和互动，<60分商品全部下架 |

### 算法分发机制对选品的影响

选品时必须理解流量从何而来。闲鱼的流量来自两条通道，它们的分发逻辑不同：

**搜索流量（主动需求）**：
- 召回机制：倒排索引（文本匹配）+ 神经网络向量匹配（语义相似）
- 排序权重：搜索词与标题/描述的相关性、商品特征、卖家活跃度
- 运营启示：标题关键词覆盖决定召回命中率。选品时要确认目标用户实际搜索哪些词，将这些词编入标题。长尾词竞争小、意图精准，优先覆盖。

**推荐流量（被动曝光）**：
- 算法收集用户浏览/搜索/设备/服务日志，预测偏好特征匹配商品
- 新品有扶持期，需在扶持期内通过真实合规经营积累正向反馈（点击/咨询/收藏）才能获得持续推荐
- 多样性打散机制：同类商品不会全部展示给同一用户
- 运营启示：推荐流量因人而异，不能仅凭自己搜索验证排名。新品上架后的前3-5天数据（CTR、咨询率）对后续推荐分配影响极大。

**内容安全审核对选品的约束**：
- 所有发布内容经深度学习/知识图谱自动风险识别，高置信度直接审核
- 标题/图片中的敏感词可能触发审核导致延迟上架或被删
- 运营启示：选品阶段就应排查商品是否容易触发安全审核（如含敏感关键词、擦边描述），避免上架后反复被删浪费扶持期。

### 账号阶段与流量基线

| 账号阶段 | 典型特征 | 初始曝光预期 | 建议 |
|---------|---------|------------|------|
| 新账号 | <10 笔交易，无评价积累 | 低（50-200/天） | 先通过真实合规交易积累 3-5 个好评（低价标品更易起步） |
| 成长账号 | 10-50 笔交易，好评率 >95% | 中（200-1000/天） | 聚焦 1-2 个类目建立垂直度 |
| 成熟账号 | >50 笔交易，好评率 >95%，无违规 | 高（1000+/天） | 可以测试多品类，流量分配较稳定 |

> **重要**：新账号不要直接测试高客单商品。先用低价标品（¥20-50）快速积累 3-5 个好评，再逐步测试目标商品。07-data-diagnosis.md 中的曝光阈值对新账号不适用--新账号的"正常"曝光可能只有成熟账号的 1/5。
