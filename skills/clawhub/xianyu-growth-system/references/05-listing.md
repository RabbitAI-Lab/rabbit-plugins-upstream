# 商品页生成（标题 + 图片 + 文案 + 定价）
<!-- version: 1.1.0 | last_updated: 2026-08-10 -->

## 约束生成原则

不要直接写商品页。先检查必要信息：

```yaml
required_info:
  product_name: ""        # 商品名称
  brand: ""               # 品牌
  model: ""               # 型号
  condition: ""           # 成色
  cost: ""                # 成本
  price: ""               # 售价
  key_selling_point: ""   # 核心卖点
  target_user: ""         # 适用人群
  inventory: ""           # 库存
  shipping: ""            # 发货方式
  after_sales: ""         # 售后承诺
```

已有：直接生成。
缺失：根据重要程度询问，不猜测。

**禁止编造：** 参数、品牌、材质、成色、认证、购买渠道、售后承诺。
缺失信息标记 UNKNOWN。

> **信息发布规范约束**：所有标题、图片、描述必须符合闲鱼信息发布规范。禁止发布含第三方联系方式/二维码/外部链接的内容，禁止使用与商品不符的网图或盗图，禁止堆砌无关关键词。违规内容会被内容安全算法自动识别并下架/降权。详见 `references/00-platform-rules.md`。

## 标题 SOP

标题不是广告语，是搜索关键词集合。

闲鱼搜索通过倒排索引（文本分词匹配）+ 神经网络向量匹配（语义相似）双路召回商品。标题中的关键词直接决定能否被召回——买家搜索词必须出现在标题分词结果中。因此标题的核心任务是覆盖买家实际搜索词，而非吸引眼球。

### 结构

> **核心关键词 + 品牌/型号 + 核心属性 + 使用场景**

### 关键词三级

| 级别 | 类型 | 示例 |
|------|------|------|
| 一级词 | 大词 | PPT、电脑支架、相机、投影仪 |
| 二级词 | 属性词 | MacBook、铝合金、便携、4K |
| 三级词 | 场景词 | 办公、租房、桌搭、出差 |

最终组合：核心词 + 属性词 + 场景词

### 示例

错误：`超级好用的电脑支架推荐！！！`
正确：`MacBook电脑支架｜铝合金｜桌面显示器支架｜Mac桌搭`

### 禁止

- "全网最低""老板疯了""绝对正品"（无搜索价值）
- 感叹号堆砌
- 与商品无关的流量词

## 图片 SOP

### 7图结构

| 图序 | 用途 | 内容 |
|------|------|------|
| 图1 | 点击图 | 商品 + 一个核心卖点，0.5秒内知道你卖什么 |
| 图2 | 核心卖点 | 适配型号/尺寸/材质/承重 |
| 图3 | 使用场景 | 真实桌面使用效果，不要只拍商品 |
| 图4 | 细节 | 接口/材质/结构/做工 |
| 图5 | 尺寸 | 视觉化标注尺寸 |
| 图6 | 真实状态 | 划痕/磕碰/使用痕迹（二手必须，不藏瑕疵） |
| 图7 | 交易说明 | 发货/售后/购买注意事项 |

### 主图原则

> 商品占70% + 卖点占20% + 环境10%

主图任务：让用户在0.5秒内知道你卖什么，以及为什么值得点。

### 图片禁止项（平台红线）

以下内容会被内容安全算法识别并处罚（下架/扣分/降权）：

- 禁止包含微信号/QQ号/手机号等联系方式
- 禁止包含二维码/条形码
- 禁止包含第三方平台链接或名称
- 禁止添加水印（尤其是导流水印）
- 禁止使用盗图/网图/与商品不符的图片
- 禁止含虚假宣传或夸大功效的内容

> **内容安全自动审核机制**：闲鱼对所有发布的文本/图片/音频/视频进行自动风险识别（深度学习+知识图谱+融合模型）。高置信度违规内容由算法直接审核处理（下架/删除），低置信度内容转入人工审核。审核覆盖商品、评价、留言等所有发布场景。发布时应避免敏感词、擦边描述和任何可能触发审核的内容，因为审核延迟或被删会浪费新品扶持期。

### 图片策略输出

```yaml
cover_strategy:
  objective: CTR
  target_user: "MacBook用户"
  message: "释放桌面空间"
  composition:
    product_ratio: 70%
    text_ratio: 20%
    context_ratio: 10%
image_set:
  - cover       # 点击图
  - scenario    # 场景图
  - feature     # 卖点图
  - spec        # 参数图
  - detail      # 细节图
  - trust       # 信任图（实拍/状态）
  - transaction # 交易图
```

### 二手商品图片特殊规则

优先级：真实 > 美观

必须展示：瑕疵、使用痕迹、序列号（隐私部分遮挡）、配件、包装、实际状态。

> 主动暴露缺陷，比买家收货后发现缺陷更便宜。

## 文案 SOP

### 5段式结构

```
① 第一行：核心利益（一句话说清楚为什么值得买）
② 商品是什么（基本描述）
③ 适合谁/为什么卖（目标人群 + 转手原因）
④ 商品状态（成色/功能/配件）
⑤ 交易信息（发货/售后/注意事项）
```

### 示例

```
【Mac用户桌面效率神器】

MacBook桌面支架，铝合金材质，稳固不晃，可调高度和角度。

适合：MacBook/iPad、居家办公、外接显示器、桌面桌搭

商品：95新
状态：功能正常，无明显磕碰
配件：原装配件齐全

因为换设备所以闲置，非长期商家库存。
支持平台担保交易，发货前会拍照确认商品状态。
想要可以直接拍，有具体型号/尺寸问题也可以先问我。
```

### 文案原则

- 让用户快速判断"是不是我想要的"
- 降低买家决策成本
- 不写"全网最低""100%最好"（除非能证明）
- 简洁，不写成淘宝详情页

## 定价 SOP

### 三价格策略

假设目标成交价 ¥99：

```
展示价：¥129    → 价格锚点
心理成交价：¥109 → 议价空间
最终优惠：¥99    → 买家觉得谈到了好价格
```

不要虚构原价、虚假优惠。

### 不同品类的定价权重

| 品类 | 核心权重 | 定价策略 |
|------|---------|---------|
| 二手数码 | 信任 > 价格 | 价格略高于最低价，用真实状态 justify |
| 标准商品 | 价格敏感 | 略低于淘宝同款 |
| 服务型 | 结果 > 价格 | 按结果定价，不按工时 |
| 高客单 | 风险降低 > 价格 | 价格可以高，但要降低买家风险 |
| 收藏品 | 专业度 > 价格 | 价格反映专业评估 |
