# 风险管理
<!-- version: 1.1.0 | last_updated: 2026-08-10 -->

## 五类风险

| 风险类型 | 预警信号 | 影响 |
|---------|---------|------|
| 平台风险 | 流量骤降、规则变更、账号限制 | 系统性，不可控 |
| 供应链风险 | 缺货、涨价、质量下降 | 直接影响履约 |
| 合规风险 | 投诉、违规、封号 | 可能丧失经营资格 |
| 商品风险 | 退款、差评、售后纠纷 | 利润侵蚀 |
| 人力风险 | 工作量失控、客服占用过多时间 | 不可规模化 |

## 停止规则

每个 SKU 必须有明确的停止规则，触发即执行：

### 流量停止规则

```
IF 7天有效曝光后咨询率 < 2%
  -> STOP（需求不足或商品页有严重问题）
```

### 经济停止规则

```
IF 贡献利润 <= 0
  -> STOP（亏损）

IF 每小时贡献利润 < ¥50 且持续2周
  -> STOP（低于机会成本）
```

### 风险停止规则

```
IF 退款率 > 15%
  -> STOP扩张，排查产品质量

IF 售后率 > 20%
  -> STOP，产品体验有严重问题

IF 供应商断货且无法在3天内找到替代
  -> STOP，避免已有投入浪费
```

### 竞争停止规则

```
IF 同行数量从<5增至>20 且价格下降>20%
  -> 降低资源投入，启动差异化

IF 商品被大量复制且无差异化优势
  -> 淘汰，释放资源给新SKU
```

## 反同质化策略

当竞争者快速增加时，不要第一反应降价。

优先执行：

1. **增加服务** - 安装指导、使用教程、售后保障
2. **增加组合** - 从单品升级为套装/方案
3. **增加专业知识** - 更专业的描述、选购建议
4. **增加售后** - 更长的保障期、更灵活的退换
5. **增加交付速度** - 24小时发货、同城自提
6. **改变目标人群** - 从大众市场转向细分人群
7. **改变商品定义** - 从"卖商品"到"卖解决方案"

核心：从商品竞争 -> 方案竞争 -> 价值组合竞争。

## 不可比性建设

提升商品不可比性的方法：

| 方法 | 示例 |
|------|------|
| 组合商品 | 支架+理线器+收纳 = "桌面效率套装" |
| 增加服务 | 商品 + 安装 + 教程 + 售后 |
| 改变定义 | 从"收纳盒"到"出租屋空间解决方案" |
| 专业知识 | 从"卖收藏品"到"专业收藏顾问" |
| 客户关系 | 从一次性交易到长期服务关系 |

## 平台风险应对

不把所有风险押在平台流量上。

一旦验证出需求，开始沉淀：

```
闲鱼（获客入口）
  -> 合规客户关系维护（复购/口碑）
  -> 小红书/抖音（内容获客）
  -> 独立站/小程序（品牌和交易）
  -> 社群（客户关系）
```

闲鱼是获客入口，不是唯一资产。

> **合规警告**：闲鱼平台禁止站内导流行为（如在聊天/商品描述中留微信号、二维码等）。渠道迁移应通过合规方式实现--例如买家主动询问购买渠道时，在平台规则允许范围内沟通。不要在商品页或自动回复中直接放置外部联系方式。具体规则以闲鱼最新平台政策为准。

## 过早自动化的风险

最警惕的事：过早自动化。

未验证 PMF（Product-Market Fit）就自动化，只是自动化地制造垃圾。

正确的顺序：

```
人工发现 -> 人工验证 -> 找到可重复模式 -> 标准化 -> 半自动 -> 自动化
```

而不是：

```
AI -> 自动铺1000个商品 -> 等待奇迹
```

## 平台合规红线

以下行为可能导致商品下架、账号限流或封号。完整违规类型及扣分表详见 `references/00-platform-rules.md` 闲气值与违规处罚部分。

> **关键提醒**：
> - 站内导流（留微信号/二维码/外部链接）：扣1-100分
> - 刷单刷评（虚假交易/刷收藏/点赞）：扣40-100分
> - 隐瞒瑕疵（不披露真实状态/缺陷）：扣20-100分
> - 出售假冒商品：扣20-100分，同年累计3次投诉=永久封禁
> - 诱导定金/虚假发货：直接扣100分
>
> 闲气值<80分即下架所有商品并限制7天。保持高闲气值和低纠纷率本身就是最好的风险策略。

> **三价格策略合规提示**：`references/05-listing.md` 中的三价格策略要求展示价必须是真实标价，不得虚构原价制造虚假折扣。闲鱼对价格操纵有检测机制，违规可能导致商品下架。

## 交易争议与举证风险

### 卖方举证义务
卖方在争议处理中承担信息披露举证责任。必须能够证明已如实披露：
- 商品基本属性、使用时长、成色
- 具体瑕疵、维修记录、质量问题及质保期

未如实披露上述信息的，争议处理将直接判定退货退款，运费由卖方承担。

### 平台介入条件
争议在确认收货前或超时打款时限内受理。平台基于双方举证判定。个人闲置物品不支持无理由退货（另有约定除外），但描述不符/质量问题的退货退款不受此限。

### 大数据快速裁决风险
闲鱼可基于卖方历史处罚记录综合评估，对买方退款申请直接快速处理。**卖方历史违规越多，被快速裁决支持退款的可能性越大**——即使本次交易卖方占理，历史污点也可能导致判罚倾斜。

> 运营启示：保持高闲气值和低纠纷率，本身就是降低争议处理风险的最好策略。发货前拍照留证、聊天中确认商品状态，是卖方最有力的举证手段。

### 服务费成本风险
确认收货后发起的退款，已划扣的平台服务费不退还。高退款率不仅侵蚀利润，还会叠加服务费损失。月成交突破门槛（>10件且>10000元）后费率升至1.6%，利润空间进一步压缩。定价时必须按实际费率核算，而非仅用基础0.6%估算。

## 税务与工商合规

当运营规模扩大时，需关注以下合规要求：

### 个体经营 thresholds

| 阶段 | 可能触发 | 建议动作 |
|------|---------|---------|
| 月成交 <10 单 | 个人闲置转让，通常无需登记 | 正常运营 |
| 月成交 10-50 单 | 可能被认定为经营行为 | 关注平台通知，保留交易记录 |
| 月成交 >50 单或月收入 >5000 元 | 大概率被认定为经营行为 | 考虑办理个体工商户营业执照 |
| 月收入持续 >2 万元 | 税务申报义务可能触发 | 咨询当地税务部门，依法纳税 |

> **免责声明**：以上阈值为一般性参考，具体标准因地区和政策而异。请以当地市场监管和税务部门的最新规定为准。本系统不提供法律或税务建议，规模化运营前请咨询专业机构。

## 风险评估模板

```yaml
risk_assessment:
  sku_id: "SKU-001"
  risks:
    platform:
      level: low
      note: "不依赖单一流量来源"
    supply:
      level: medium
      note: "1688一件代发，有2个备选供应商"
    compliance:
      level: low
      note: "正规商品，无违规风险"
    product:
      level: low
      note: "退款率5%，售后率3%"
    labor:
      level: medium
      note: "每单客服0.3h，发货0.1h"
  overall_risk: medium
  mitigations:
    - "确认第二供应商报价"
    - "准备3套客服话术模板降低回复时间"
  stop_rules:
    - "退款率>10%暂停"
    - "供应商断货3天停止"
```
