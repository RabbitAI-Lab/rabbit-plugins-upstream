# 核心原则与决策引擎
<!-- version: 1.1.0 | last_updated: 2026-08-10 -->

## 核心铁律

1. **先验证需求，再优化运营** - 没有需求的产品，优化转化率毫无意义
2. **先算单位经济，再谈规模** - 贡献利润 ≤ 0 的 SKU 直接淘汰
3. **先人工验证，再自动化** - 自动化一个未验证的流程只是自动化地制造垃圾
4. **先找需求，再找商品** - 不要问"什么好卖"，要问"什么需求没被满足"
5. **不和同行竞争价格，改变竞争维度** - 从商品竞争升级为方案竞争
6. **曝光是过程指标，利润才是结果指标** - 不要被流量数据迷惑
7. **咨询是免费的用户研究** - 客服聊天记录是需求洞察的金矿
8. **每个 SKU 都必须有停止规则** - 无停止规则的 SKU 不进入实验池
9. **平台合规是生存底线** - 禁售品类直接淘汰、闲气值低于80停止扩张、站外导流零容忍（详见 `references/00-platform-rules.md`）
10. **赢家获得资源，失败者快速退出** - 不恋战，让资本和时间向已验证的有效东西集中
11. **闲鱼负责验证，不负责承载全部商业价值** - 验证成功后迁移到更高毛利渠道

## 决策引擎规则

规则按优先级分层执行。**高优先级层命中时，低优先级层不执行。** 同层内多条同时命中时，取最严重的决策（REJECT > HOLD > 诊断优化 > SCALE > PRODUCTIZE）。

### P0 层：硬性淘汰（命中即 REJECT，不看其他层）

```
IF product_category IN prohibited_list   # 13类禁售品
  -> REJECT

IF product_category IN restricted_list AND no_qualification   # 限售品类无资质
  -> REJECT

IF contribution_profit <= 0
  -> REJECT

IF supply_risk = HIGH AND margin < HIGH
  -> REJECT

IF after_sales_risk = UNCONTROLLABLE
  -> REJECT

IF commoditization_risk >= 9/10 AND no_cost_advantage
  -> REJECT
```

> 禁售/限售品类完整清单见 `references/00-platform-rules.md`。此层为合规前置检查，在任何经济性评估之前执行。

### P1 层：前置阻断（命中即 HOLD，不进入诊断层）

```
IF supply_stability = UNKNOWN
  -> HOLD (先验证供应链)
```

### P2 层：漏斗诊断（按漏斗顺序，取第一个命中的瓶颈）

```
IF impressions < threshold AND listing_age >= minimum_test_period
  -> TRAFFIC_DIAGNOSIS (流量问题)

ELSE IF impressions HIGH AND CTR LOW
  -> COVER_TITLE_OPTIMIZATION (主图/标题优化)

ELSE IF CTR HIGH AND inquiry_rate LOW
  -> VALUE_PROPOSITION_OPTIMIZATION (商品页优化)

ELSE IF inquiry_rate HIGH AND CVR LOW
  -> PRICE_TRUST_DIAGNOSIS (价格/信任/客服诊断)
```

### P3 层：放大决策（P0-P2 均未命中时执行）

```
IF CVR HIGH AND contribution_profit HIGH AND refund_rate LOW
  -> SCALE (放大)

ELSE IF contribution_profit HIGH AND human_hours HIGH
  -> PRODUCTIZE (产品化)

ELSE
  -> ITERATE (继续优化当前变量)
```

### 仲裁规则

当多条规则同时命中时：
1. **跨层冲突**：高优先级层覆盖低优先级层。P0 命中时不看 P1-P3。
2. **同层多规则**：取决策严重度更高的结果（REJECT > HOLD > 诊断 > ITERATE > SCALE > PRODUCTIZE）。
3. **P2 漏斗层例外**：取漏斗最上游的瓶颈（曝光 > 点击 > 咨询 > 成交），因为上游问题不解决，下游优化无意义。
4. **P3 冲突**：SCALE 和 PRODUCTIZE 同时命中时，优先 PRODUCTIZE（人工瓶颈比规模瓶颈更紧急）。

## 双评分模型

### Score A：Opportunity Score（机会评分）

判断"值不值得测试"，在商品进入实验池前使用。

| 维度 | 权重 | 评分范围 | 说明 |
|------|------|---------|------|
| 需求强度 | 20% | 1-10 | 搜索量、咨询频率、需求明确度 |
| 单笔贡献利润 | 20% | 1-10 | 售价 - 所有成本后的真实利润 |
| 竞争风险 | 15% | 1-10（越低越好） | 同行数量、同质化程度 |
| 差异化 | 10% | 1-10 | 不可比性、独特价值 |
| 供应稳定性 | 10% | 1-10 | 货源是否稳定、是否独家 |
| 可复制性 | 10% | 1-10 | 能否扩展到更多SKU |
| 人工成本 | 10% | 1-10（越低越好） | 每单耗时、客服强度 |
| 售后风险 | 5% | 1-10（越低越好） | 退款概率、纠纷风险 |

综合分 ≥ 75：重点测试
60-75：小规模测试
< 60：暂缓

#### 评分锚点（1/5/10 分参考标准）

| 维度 | 1 分 | 5 分 | 10 分 |
|------|------|------|-------|
| 需求强度 | 几乎无搜索量，需要教育市场 | 有一定搜索量，但需求分散 | 搜索量大且意图明确，高频咨询 |
| 单笔贡献利润 | ≤ ¥10/单 | ¥30-50/单 | ≥ ¥100/单 |
| 竞争风险（越低越好） | 同行 >20，完全同质化 | 同行 5-15，部分同质化 | 同行 <5，差异化明显 |
| 差异化 | 淘宝一键搜到同款 | 有一定差异化但可被模仿 | 不可比，组合/服务/知识壁垒 |
| 供应稳定性 | 单一供应商，随时断货 | 2-3 个供应商，基本稳定 | 独家货源或自产，完全可控 |
| 可复制性 | 单一 SKU 无法扩展 | 可扩展 3-5 个变体 | 可建完整 SKU 矩阵（10+） |
| 人工成本（越低越好） | >2h/单，重度客服 | 0.5-1h/单，中等客服 | <0.3h/单，标品轻客服 |
| 售后风险（越低越好） | 退款率 >15%，纠纷高发 | 退款率 5-15%，偶有纠纷 | 退款率 <5%，几乎无纠纷 |

> 注意：锚点为参考标准，非绝对阈值。根据品类和平台环境调整。

### Score B：Execution Score（执行评分）

判断"现在是否值得扩大"，在有实际数据后使用。

| 维度 | 评分范围 | 达标线 |
|------|---------|--------|
| CTR | 1-10 | > 2% |
| 咨询率 | 1-10 | > 5% |
| CVR | 1-10 | > 3% |
| 贡献利润 | 1-10 | > ¥30/单 |
| 退款率 | 1-10（越低越好） | < 10% |
| 人工小时 | 1-10（越低越好） | < 2h/单 |
| 生命周期 | 1-10 | > 30天 |

> **达标线说明**：此处的「达标线」是**最低生存线**--低于此线的 SKU 应考虑淘汰。`references/07-data-diagnosis.md` 的漏斗分析中还有一个「健康范围」（CTR > 3%、咨询率 > 8%、CVR > 15%），那是运营良好的参考目标。两个层级的关系：低于达标线 = 淘汰候选；达标线到健康范围之间 = 可优化；高于健康范围 = 表现优秀。

## 置信度机制

决策必须附带置信度，防止小样本误判：

```yaml
# 高置信度（0.8+）
decision: SCALE
confidence: 0.85
evidence: "30天数据，50+订单，CVR稳定在5%，退款率<5%"

# 低置信度
decision: TEST
confidence: 0.41
evidence: "仅3单成交，数据不足以判断趋势"
warning: "即使目前利润好，也不应判断为爆款"
```

置信度影响因素：
- 样本量（订单数 < 10 = 低置信度）
- 时间跨度（< 7天 = 低置信度）
- 数据一致性（波动大 = 低置信度）

## 北极星指标

整个系统只认一个一级指标：

> **每小时贡献利润 = SKU贡献利润 ÷ 实际投入人工小时**

示例：
- 商品A：每天赚¥300，耗时5小时 = ¥60/小时
- 商品B：每天赚¥200，耗时0.5小时 = ¥400/小时

应该重点做B。

辅助指标：曝光、CTR、咨询率、CVR、客单价、毛利率、售后率、人工时、生命周期。

> **服务费对利润的影响**：平台服务费（基础0.6% + 条件性1% + 鱼小铺1.6%）直接侵蚀贡献利润。月成交突破门槛（>10件且>10000元）后费率升至1.6%，必须重新核算北极星指标。详见 `references/00-platform-rules.md` 服务费章节。
