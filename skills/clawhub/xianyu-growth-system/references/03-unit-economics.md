# 单位经济模型
<!-- version: 1.1.0 | last_updated: 2026-08-10 -->

## 核心公式

```
真实贡献利润
= 售价
  - 采购成本
  - 物流
  - 包材
  - 平台服务费（基础0.6% + 条件性1%）
  - 退款损失（预估）
  - 售后损失（预估）
  - 人工成本（时间 × 时薪）
  - 内容生产成本（分摊）
```

最终除以投入时间：

> **每小时贡献利润 = 真实贡献利润 ÷ 投入人工小时**

## 成本计算明细

### 固定成本（每单必发生）

| 项目 | 说明 | 计算 |
|------|------|------|
| 采购成本 | 进货价 | 实际采购价 |
| 物流 | 快递费 | 按实际承运商报价 |
| 包材 | 包装材料 | 快递盒 + 填充物 + 胶带 |
| 平台服务费 | 交易手续费 | 见下方服务费计算规则 |

### 可变成本（按概率发生）

| 项目 | 说明 | 计算 |
|------|------|------|
| 退款损失 | 退款时的物流+折损 | 退款率 × (往返物流 + 商品折损) |
| 售后损失 | 纠纷补偿/部分退款 | 售后率 × 平均补偿金额 |
| 退货损耗 | 二手商品退货贬值 | 退货率 × 贬值金额 |

### 人工成本

| 项目 | 说明 | 计算 |
|------|------|------|
| 选品时间 | 找商品、比价、评估 | 分摊到每个SKU |
| 内容生产 | 拍照、写文案、做图 | 分摊到每个商品 |
| 客服时间 | 咨询回复、议价 | 每单平均客服时长 × 时薪 |
| 发货时间 | 打包、寄出 | 每单平均发货时长 × 时薪 |
| 售后时间 | 处理问题、退款 | 售后率 × 平均处理时长 × 时薪 |

建议时薪基准：¥50-100/小时（根据个人机会成本调整）

### 平台服务费计算规则

| 费项 | 费率 | 触发条件 |
|------|------|---------|
| 基础软件服务费 | 0.6% | 所有成交订单，从买家付款中实时划扣 |
| 软件服务费（基础门槛） | 额外1% | 当月成交>10件且>10000元，超出部分 |
| 软件服务费（手机品类） | 额外1% | 自然年手机品类>6笔，超出部分 |
| 鱼小铺 | 每笔1.6% | 开通鱼小铺的卖方（0.6%+1%），不享受门槛优惠 |

关键规则：确认收货后退款，已划扣服务费不退还。

```
示例1：普通卖家，月8单总额¥6000
  -> 仅基础0.6%，服务费 = 6000 × 0.6% = ¥36

示例2：普通卖家，月15单总额¥15000
  -> 前10000元：10000 × 0.6% = ¥60
  -> 超出5000元：5000 × 1.6% = ¥80
  -> 总服务费 = ¥140（有效费率约0.93%）

示例3：鱼小铺卖家，月15单总额¥15000
  -> 每笔1.6%，服务费 = 15000 × 1.6% = ¥240
```

## 利润计算模板

```yaml
unit_economics:
  selling_price: 99
  costs:
    product_cost: 35
    logistics: 8
    packaging: 3
    platform_fee: 0.59          # 基础0.6%: 99 × 0.6% = ¥0.59（月成交未达门槛时）
    estimated_refund_loss: 4    # 退款率8% × 往返物流+折损50
    estimated_after_sales: 3     # 售后率5% × 平均补偿60
    labor_cost: 15               # 0.3h × 50/h
    content_amortized: 2         # 内容生产成本分摊
  total_cost: 71
  contribution_profit: 28
  margin_rate: 28.3%
  labor_hours: 0.3
  contribution_per_hour: 93
```

## 强制停止条件

出现以下任意情况，SKU 不进入实验或停止扩张：

| 条件 | 动作 | 原因 |
|------|------|------|
| 贡献利润 ≤ 0 | REJECT | 亏损生意没有优化价值 |
| 每小时贡献利润 < ¥50 | OPTIMIZE/REJECT | 低于机会成本，不如做其他事 |
| 单笔人工时间 > 2小时 | STOP扩张 | 不可规模化，本质是低时薪工作 |
| 售后风险不可控 | REJECT | 利润会被售后吞噬 |
| 供应商无法稳定供货 | HOLD | 断货会导致已有投入浪费 |
| 极度同质化且无成本优势 | REJECT | 价格战不可避免 |

## 增长可能是假的

警惕单位经济模型恶化：

```
第一月：10单 × ¥100利润 = ¥1,000
第二月：30单 × ¥80利润 = ¥2,400
第三月：80单 × ¥40利润 = ¥3,200
```

表面爆发增长，实际单位利润在下降。原因：竞争者进入 → 售价下降 → 投诉增加 → 客服时间增加 → 售后增加。

**必须监控趋势，不是只看绝对值。**

## 三价格策略

定价不应使用"成本 + 20%"的简单加价。三价格策略（展示价 > 心理成交价 > 最终优惠）通过留出议价空间来提升成交概率。

> 三价格策略的完整定义、示例和合规提示详见 `references/05-listing.md` 定价 SOP 部分。此处不重复。

**服务费对定价的影响**：月成交突破门槛（>10件且>10000元）后，超出部分费率从0.6%升至1.6%，到手价减少约1%。鱼小铺卖家每笔固定1.6%。定价时需按当前实际费率核算到手利润。

## 成本收益分析原则

任何运营动作都必须有"预期增量利润 / 时间成本"：

| 动作 | 耗时 | 预期提升 | 值不值 |
|------|------|---------|--------|
| 优化主图 | 30min | +20%成交 | 值 |
| 研究发布时间 | 2h | +2% | 不值 |
| 做10套详情图 | 5h | +3% | 不值 |
| 找一个高利润SKU | 4h | ¥4000/周 | 非常值 |

低于阈值的动作不做。
