# 产品化与规模化
<!-- version: 1.1.0 | last_updated: 2026-08-10 -->

## 核心判断

闲鱼本身不是商业模式。

它最有价值的地方是：

> **低成本、快速、真实地告诉你"什么东西有人愿意付钱"。**

精力分配：
- 70% 发现和验证高价值需求
- 20% 转化优化
- 10% 自动化

---

## 渠道迁移路径

当出现"稳定成交 + 高毛利 + 高频需求"时，开始渠道迁移：

```
第一阶段：闲鱼 -> 需求验证
第二阶段：合规客户关系维护 -> 复购与口碑
第三阶段：小红书/抖音 -> 内容获客
第四阶段：独立站/小程序 -> 品牌和交易
第五阶段：产品/SaaS -> 可规模化收入
```

> **合规导流边界**：闲鱼禁止在商品描述/图片/聊天中发布第三方链接、二维码或诱导跳转（违规扣1-100分）。客户迁移应通过合规方式实现——例如买家主动询问购买渠道时，在平台规则允许范围内沟通。不要在商品页或自动回复中直接放置外部联系方式。具体规则以闲鱼最新平台政策为准。

---

## 服务型商品的三次产品化

服务型商品必须经历三个阶段：

### 第一阶段：人工

> 人做 + AI辅助

验证需求和服务能力。每单都人工完成。

### 第二阶段：半自动

> AI做80% + 人审核

找到可重复模式后，用AI加速生产。

### 第三阶段：产品化

> 用户自己完成 + 你提供系统

边际成本下降，收入可规模化。

---

## 什么时候离开闲鱼

当满足以下条件时，应该开始渠道迁移：

- 稳定成交（连续30天有订单）
- 高毛利（贡献利润 > ¥100/单）
- 高频需求（每周咨询 > 20）
- 流程已标准化
- 有客户沉淀（合规方式沉淀的客户 > 50）

不是"离开"闲鱼，而是在闲鱼之外建立不依赖平台的收入。

> **经营性行为认定合规升级**：规模化运营时可能触发经营性行为认定（在售>30件且品类<3类、年交易>104笔、年销售额>10万元等）。被认定后须依法办理市场主体登记，在主页公示营业执照/经营地址/联系方式，并履行七天无理由退货等经营者义务。提前评估合规成本，避免因未履行经营者义务被平台处置。详见 `references/00-platform-rules.md`。

## AI自动化的正确顺序

AI最应该自动化的是：

> **缩短实验周期，而不是自动发布商品。**

| 环节 | 人工耗时 | AI辅助后 |
|------|---------|---------|
| 找商品 | 2h | 20min |
| 写标题 | 30min | 2min |
| 写文案 | 30min | 2min |
| 做图方案 | 1h | 5min |
| 数据分析 | 1h | 1min |

从每周测试5个商品 -> 每周测试50个商业假设。

> **批量发布风险**：AI自动化发布时，短时间内大量上架、使用相同/相似模板批量生成商品，可能触发平台异常行为检测，导致限流或账号限制。应控制发布节奏（每天上架不超过3-5个），确保每个商品的标题/图片/描述有实质差异，避免被判定为重复铺货或不当注册。

## 战略决策模板

用户问"接下来怎么做"时，必须回答：

```yaml
strategic_advice:
  current_state: |
    3个L2赢家SKU，2个L1实验中
    月贡献利润¥8000，每小时贡献利润¥120
    主要风险：2个SKU被复制的风险增加
  evidence: |
    基于过去30天数据
    SKU-A: 50单，CVR 5.2%，利润¥3500
    SKU-B: 30单，CVR 4.1%，利润¥2800
    SKU-C: 20单，CVR 3.8%，利润¥1700
  unit_economics: |
    平均贡献利润¥87/单（已扣除平台服务费0.6%-1.6%）
    平均每小时贡献利润¥120
  risk: |
    SKU-A commoditization_risk 从3升至6
    供应商B报价上涨10%
  decision: SCALE + PRODUCTIZE
  next_actions:
    - "SKU-A启动差异化策略，增加组合商品"
    - "SKU-B寻找替代供应商"
    - "SKU-C放大测试，准备爆款复制"
    - "整体在合规前提下沉淀客户关系"
  stop_conditions:
    - "SKU-A被复制数>15且价格下降>15%"
    - "SKU-B供应商涨价导致利润<¥40/单"
```

## 最终原则

> 不要优化"怎么在闲鱼卖得更多"，先找到"什么东西值得持续卖"。
> 不要追求爆款，追求可重复的正向单位经济模型。

闲鱼 -> 需求验证 -> 服务 -> 产品 -> SaaS，这才是完整的创业路径。
