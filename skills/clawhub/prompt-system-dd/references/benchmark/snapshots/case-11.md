## 2. 任务

- 任务解码：评估某制造业标的的并购投资决策。关键成功因子（KSF）：①估值区间的可信度；②协同效应的可实现性；③风险敞口的可承受性。
- 具体动作：分三阶段执行——估值建模→协同效应测算→风险矩阵与交易结构建议。
- 核心范围：对象限制造业标的股权并购；视角限买方；显式排除反垄断申报细节与交割税务筹划。
- 交付物：并购评估报告一份（Markdown，8000-12000 字）+ 估值与协同测算表，含版本约定（v1.0 提投委会稿）。
- 核心目标：为投委会提供可追责的 Go/No-Go 决策依据与谈判区间。
- 验收标准：①估值阶段：三种方法（DCF/可比公司/可比交易）交叉验证区间可独立复算；②协同阶段：每项协同有量化口径与兑现年份；③风险阶段：每项风险有对冲或退出机制。

思维链强制三阶段输出（不可合并）：

- 分析层：拆解表层/深层需求 + 标注所有假设 + 关联 2024-2026 年制造业并购市场动态；
- 构建层：生成 3 个差异化交易结构方案（各附创新点与风险矩阵）→ 选最优并论证否决理由；
- 压力层：模拟用户质疑 x3 + 极端场景测试 x2 + 伦理安全扫描；
- 自我超越：初稿 → 魔鬼代言人批判 → 修订至满足全部验收标准 → 附【优化日志】。

## 3. 背景、事实与规则

- 背景：标的为细分行业龙头，卖方启动竞标流程，买方需在尽调基础上形成报价策略。
- 已知事实：标的近三年营收 CAGR 约 12%（来源：标的审计报告）；行业可比交易 EV/EBITDA 中位数 9.5x（来源：Capital IQ，2026-06 取数）。
- 规则约束：遵循 IFRS 口径；引用具体数据来源与取数时点，禁止泛称"市场水平"。
- 参考资料：可参考 McKinsey 并购协同方法论与 Damodaran 估值框架。
- 时效性锚点：关联 2024-2026 年利率环境与制造业景气度动态，2023 年前交易样本显式排除。
- 假设标注：所有未经核实的前提必须以"假设:"前缀显式标注（如"假设:协同兑现率取 70%"）。

## 4. 示例（多示例锚定）

- 正例 1（侧重方法交叉）：DCF 区间 28-32 亿 + 可比交易 26-30 亿 → 取重叠带 28-30 亿为谈判锚——强调多方法互证。
- 正例 2（侧重协同量化）：采购协同 = 合并采购量×历史降价弹性 2.5%×兑现率 70%，分 3 年兑现——强调口径透明；与正例 1 的关键差异在经营协同与估值锚的分工。
- 反例："标的成长性好，估值合理"——无口径、无区间、无方法，属不可验收的结论性断言。
- 风格基准：以上示例用于锚定"每个数字必须有来源、口径、兑现路径"的标准，不构成范围限制，禁止照抄示例内容。
