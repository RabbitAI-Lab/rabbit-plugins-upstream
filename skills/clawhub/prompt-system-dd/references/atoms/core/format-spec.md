> 唯一真相源:本文件是格式规范模块的唯一权威定义。
> 自包含:不依赖其他原子内容;深度语义遵循全局锚(D1极简/D2标准/D3增强/D4专家)。

## D1 极简

- 输出形式:[一句话,如"500字以内的纯文本"]。
- 填充要求:形式 + 体量一句话说清,不含结构细节。
- 填充要求:输出形式与字数上限至少明确其一,缺失则产出规模易失控。
## D2 标准

- 输出形式:[Markdown/纯文本/表格];
- 结构框架:[核心章节顺序,用→连接]。
- 填充要求:章节顺序完整覆盖交付物;禁止出现未定义的"等"字。

## D3 增强

- 输出形式:Markdown,标题层级规范(一级=章节,二级=小节);
- 结构框架:[完整章节序列];
- 颗粒度标准:[每章要点数下限 / 字数区间 / 数据精度];
- 图表标注:数据图表需标注 [来源 + 时间范围]。
- 填充要求:颗粒度必须量化到数字;标注规则覆盖所有出现的图表。

## D4 专家

- 输出契约:Markdown 分层,层级规则显式(H1=主题/H2=章节/H3=要点);
- 结构框架:[完整章节序列 + 各章节体量占比];
- 颗粒度标准:[量化到数字:要点数/字数区间/小数位/样本量];
- 图表契约:[类型 + 数据字段 + 来源标注 + 时间范围的完整标注模板];
- 硬约束:超出字数上限 10% 视为违反契约;关键结论必须加粗;
- 收尾要求:以 [指定元素,如行动清单/参考链接] 结尾。
- 填充要求:输出契约必须可机械检验;体量占比之和为 100%。

## 质量检查清单

- [ ] 无"等""相关"类开放表述
- [ ] 深度档位与 DEPTH 指纹第 5 位一致
- [ ] D3+ 颗粒度量化到数字;D4 含可机械检验的硬约束
