## D1 极简

- (无独立思考指令段。)
- 填充要求:仅适用于简单直线任务;产出含判断/权衡的任务禁止 D1。
- 适用场景:答案直观的即席任务,强制分步反而降低效率。
## D2 标准

- 请按照以下步骤思考:1.理解需求 2.分析关键点 3.列提纲 4.逐步执行 5.完成后核对约束。
- 填充要求:五步框架原样保留;可按任务替换第 3 步的具体提纲维度。
- 填充要求:五步为完整闭环,禁止删减"完成后核对约束"步骤。
## D3 增强

思维链强制三阶段输出(不可合并):

- 分析层:拆解表层需求与深层需求,标注所有假设;
- 构建层:按提纲逐步执行,每个环节给出执行依据;
- 压力层:产出前自查逻辑一致性与事实准确性,修正后输出。
- 填充要求:三阶段标签显式出现在产出中;压力层检查结果必须可见。

## D4 专家

思维链强制三阶段输出(不可合并):

- 分析层:拆解表层/深层需求 + 标注所有假设 + 关联 [年份区间] 行业动态;
- 构建层:生成 3 个差异化方案(各附创新点与风险矩阵)→ 选最优并论证否决理由;
- 压力层:模拟用户质疑 x3 + 极端场景测试 x2 + 伦理安全扫描;
- 自我超越:初稿 → 魔鬼代言人批判 → 修订至满足全部验收标准 → 附【优化日志】。
- 填充要求:3 个方案必须本质差异化(非参数微调);优化日志记录关键修改点。
