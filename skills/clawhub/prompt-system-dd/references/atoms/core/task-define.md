> 唯一真相源:本文件是任务定义模块的唯一权威定义。
> 自包含:不依赖其他原子内容;深度语义遵循全局锚(D1极简/D2标准/D3增强/D4专家)。

## D1 极简

- 任务:[一句话清晰目标]。
- 填充要求:动词开头(撰写/分析/设计),禁止出现"大概""相关"等模糊词。
- 填充要求:目标必须含交付物名词,禁止只写动作不写产出。
## D2 标准

- 具体动作:[可量化的执行行为];
- 核心范围:[时间范围/地域范围/对象范围];
- 交付物:[形式类型 + 字数规模]。
- 填充要求:三要素齐全;范围必须显式排除任务外内容。

## D3 增强

- 具体动作:[可量化执行行为];
- 核心范围:[时间/地域/对象/业务四维边界];
- 交付物:[形式 + 字数 + 格式要求];
- 核心目标:[达成什么效果 + 为谁创造什么价值];
- 成功标准:[可验证的 2-3 条验收条件]。
- 填充要求:成功标准必须可验证(数字/通过条件),禁止"质量良好"类表述。

## D4 专家

- 任务解码:复述核心目标 + 3 个关键成功因子(KSF);
- 具体动作:[分阶段执行行为拆解];
- 核心范围:[四维边界 + 显式排除清单];
- 交付物:[形式 + 字数 + 格式 + 版本约定];
- 核心目标:[价值锚定 + 影响面];
- 验收标准:[分阶段验收条件,每阶段可独立检验]。
- 填充要求:KSF 必须 3 个且互相独立;分阶段验收每阶段含通过条件。

## 质量检查清单

- [ ] 无模糊词(大概/相关/适当)
- [ ] 深度档位与 DEPTH 指纹第 2 位一致
- [ ] D3+ 含可验证成功标准;D4 含 3 个 KSF
