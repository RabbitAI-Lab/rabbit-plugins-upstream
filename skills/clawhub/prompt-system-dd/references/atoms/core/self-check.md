> 唯一真相源:本文件是自检机制模块的唯一权威定义。
> 自包含:不依赖其他原子内容;深度语义遵循全局锚(D1极简/D2标准/D3增强/D4专家)。

## D1 极简

- (无独立自检段。)
- 填充要求:仅适用于无质量风险的机械任务;含判断/数据的任务禁止 D1。
- 适用场景:低风险短任务,产出后人工快速核对即可。
## D2 标准

产出前核对 3 项:

- [ ] 任务目标是否完全覆盖;
- [ ] 输出格式是否符合要求;
- [ ] 约束条件是否逐条满足。
- 填充要求:3 项原样保留;可追加任务特有的 1 项核对点。

## D3 增强

产出前执行 5 项检查并给出自评:

- [ ] 完整性:任务要素无遗漏;
- [ ] 逻辑性:模块间无冲突;
- [ ] 专业性:术语与行业标准准确;
- [ ] 可执行性:无模糊表述,要求可操作;
- [ ] 适配性:针对具体场景,非通用模板。
- 自评:按 7 维度速查表(见 SKILL.md)打分,总分低于基调合格线则修订后输出。
- 填充要求:自评分必须显式给出;低于合格线必须修订。

## D4 专家

在 D3 基础上追加对抗性验证:

- 模拟用户质疑 x3:[从需求/数据/可行性三个角度各拟 1 个尖锐质疑并回应];
- 极端场景测试 x2:[最不利输入与边界条件下方案是否成立];
- 人工复核节点:显式声明 [需要人类专家验证的结论清单及理由];
- 声明:自评通过不等同于专业审核,重大决策前需人工验证。
- 填充要求:质疑必须尖锐且非虚构 strawman;复核节点必须具体到结论项。

## 质量检查清单

- [ ] 深度档位与 DEPTH 指纹第 8 位一致
- [ ] D2 3项/D3 5项+评分/D4 对抗质疑+复核节点
- [ ] 依赖规则:think-chain D4 时本原子必须 ≥ D3
