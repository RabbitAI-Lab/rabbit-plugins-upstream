> 唯一真相源:本文件是迭代机制模块的唯一权威定义。
> 自包含:不依赖其他原子内容;深度语义遵循全局锚(D1极简/D2标准/D3增强/D4专家)。

## D1 极简

- 如需调整,直接说明修改点即可。
- 填充要求:一句话;不提供维度枚举。
- 适用场景:单轮即席任务,无需结构化迭代契约。
## D2 标准

- 调整方式:可修改 [维度1]、[维度2]、[维度3];
- 反馈路径:直接回复"调整 [维度]"即可触发优化。
- 填充要求:维度枚举来自本任务实际可调项,禁止照抄通用维度。

## D3 增强

- 调整方式:[内容/结构/风格/规模四维,逐项给出本任务可调项];
- 反馈路径:回复"调整 [维度]"或"补充 [内容]"即可触发;
- 触发词约定:列出本任务 3 个高频调整触发词。
- 填充要求:触发词必须来自任务语境;每维给出 1 个具体示例。

## D4 专家

- 调整方式:四维调整 + 深度调档;
- 深度调档:输出 DEPTH 指纹与档位说明,用户可指定 [某原子] 升/降档(如"约束再严格些"= constraints 升档),仅重生成对应模块;
- 调档前置:调档前先按 depth-adaptation.md"指纹 diff"评估影响面(工具 scripts/fingerprint.py diff),不全量重出;
- 顶档处理:目标原子已处 D4 时,按 depth-adaptation.md 覆盖触发表"顶档"行执行(位不变-内容增强 或 改调关联原子),不得违规升档;
- 反馈路径:回复"调整 [维度]"或"[原子名] 升/降档";
- 迭代记录:每轮修改在【优化日志】追加变更条目(指纹变化 + 修改点;位不变-内容增强场景记录"位不变-内容增强"标记)。
- 填充要求:调档语义必须与 depth-adaptation.md 全局锚一致;优化日志不可省略。

- [ ] D2+ 维度来自本任务实际可调项
