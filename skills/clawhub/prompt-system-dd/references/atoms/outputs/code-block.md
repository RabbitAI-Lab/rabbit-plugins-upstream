> 唯一真相源:本文件是代码块类输出的唯一权威定义。
> 自包含:不依赖其他原子内容,可独立注入组装。

## 输出规范

- 命中信号:代码、脚本、程序、接口实现、伪代码。
- 格式要求:标准 Markdown 代码围栏(```语言名),语言标注必填,禁止无语言围栏。
- 结构要求:每个代码块前必须有 1 句用途说明,复杂逻辑逐段注释;接口实现附调用示例。
- 粒度要求:单文件不超过 200 行,超出时拆分模块并给出文件组织说明;关键分支必须有错误处理。
- 填充要求:可直接复制运行的完整代码,禁止伪代码与真实代码混排,占位符用尖括号标注(如 <API_KEY>)。
