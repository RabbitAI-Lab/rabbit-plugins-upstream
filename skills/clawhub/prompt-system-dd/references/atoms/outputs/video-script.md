## 输出类型注入内容

- 适用场景:短视频脚本(抖音/快手/视频号)、宣传视频(企业宣传/产品推广)、教学视频(课程/教程/培训)
- 格式要求:分镜头脚本格式,含时间码、画面、台词、音效,时间/画面/声音明确
- 特殊要求:
  - 时间码精确到秒
  - 画面描述需包含镜头运动
  - 音效需明确背景音乐和转场音效

## 提示词注入模块

```markdown
## 3. 输出要求细则
- 格式规范:标准分镜头脚本格式(时间码 | 画面描述 | 文案/台词 | 音效/音乐 | 备注)
- 结构框架:黄金3秒吸睛→产品展示→使用场景→核心卖点→行动引导
- 颗粒度标准:
  1. 时间码精确到秒(如:00:03-00:08)
  2. 画面描述需包含镜头运动(推/拉/摇/移)、人物动作、场景细节
  3. 文案需标注字幕、旁白、台词区分
  4. 音效需明确背景音乐风格、转场音效、重点音效
- 关键要点:必须包含"黄金3秒钩子"、"产品3个核心卖点"、"明确的购买链接引导"
```
