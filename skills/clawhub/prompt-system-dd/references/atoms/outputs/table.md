## 输出类型注入内容

- 适用场景:数据对比(产品/方案/价格)、清单(任务/检查/物料)、明细(预算/人员/物料)
- 格式要求:Markdown 表格或 CSV,表头明确,数据准确,含必要说明与备注
- 特殊要求:
  - 列名清晰(如"项目、数量、单价、小计")
  - 数据准确,标明单位和精度
  - 必要时添加汇总行与计算公式

## 提示词注入模块

```markdown
## 3. 输出要求细则
- 格式规范:Markdown表格格式,包含表头、数据行、汇总行
- 结构框架:表格+必要的数据说明和备注
- 颗粒度标准:
  1. 至少包含5列数据(项目、数量、单价、小计、备注)
  2. 金额精确到元,百分比精确到小数点后1位
  3. 表格底部需包含总金额汇总
- 关键要点:必须包含每项数据的计算方式和来源
```
