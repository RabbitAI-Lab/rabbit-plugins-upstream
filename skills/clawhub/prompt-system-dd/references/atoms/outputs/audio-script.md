> 唯一真相源:本文件是音频输出类型的唯一权威定义。单段正交结构,无深度分档。
> 自包含:不依赖其他原子内容,可独立注入组装。

## 输出类型注入内容

- 适用场景:录音脚本(播客/有声书/广告录音)、播客稿(访谈/解说/故事)、音效说明(背景音乐/音效设计)
- 格式要求:带时间戳的脚本,标注音效与背景音,说明语气和情感
- 特殊要求:
  - 时间戳精确到秒
  - 标注语气(温暖/严肃/活泼)
  - 音效说明(音效类型、时机、时长)

## 提示词注入模块

```markdown
## 3. 输出要求细则
- 格式规范:带时间戳的脚本格式(时间 | 内容 | 语气 | 音效 | 备注)
- 结构框架:开场→正文→结尾
- 颗粒度标准:
  1. 时间戳精确到秒(如:00:15-00:45)
  2. 内容需标注主播/旁白/台词
  3. 语气标注:开场温暖亲切(00:15-00:30),正文专业严谨(00:30-03:00)
  4. 音效:背景音乐(轻快/舒缓)、转场音效(过渡提示)
- 关键要点:必须包含开场问候、3个核心要点、结尾总结和感谢
```

## 多模态组合规则

当输出为多种格式组合时,在提示词格式规范中逐部分声明:

```markdown
- 格式规范:组合格式
  - 第1部分:文本(800-1000字的分析报告)
  - 第2部分:表格(数据对比表格)
  - 第3部分:图表(趋势图描述)
- 结构框架:分析报告→数据表格→图表说明→结论建议
```
