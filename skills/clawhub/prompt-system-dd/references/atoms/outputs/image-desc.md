> 唯一真相源:本文件是图片输出类型的唯一权威定义。单段正交结构,无深度分档。
> 自包含:不依赖其他原子内容,可独立注入组装。

## 输出类型注入内容

- 适用场景:设计图(Logo/海报/界面)、示意图(流程/架构/关系)、视觉素材(插图/背景/素材)
- 格式要求:描述图片内容与风格,提供详细视觉元素说明,标注尺寸与比例
- 特殊要求:
  - 描述清晰具体(颜色、构图、元素)
  - 风格明确(简约/复杂/现代/传统)
  - 尺寸和用途说明(打印/网页/社交媒体)

## 提示词注入模块

```markdown
## 3. 输出要求细则
- 格式规范:详细描述图片内容+视觉元素+风格要求
- 结构框架:图片概述→视觉元素说明→风格描述→尺寸要求
- 颗粒度标准:
  1. 主色调:蓝色系(#3B82F6为主色,辅以白色和浅灰)
  2. 构图:居中对称,主体占画面60%,留白40%
  3. 元素:必须包含标题、副标题、背景装饰图案
  4. 风格:现代简约,扁平化设计
- 关键要点:必须明确标注尺寸(1920x1080像素)、用途(网页Banner)
```
