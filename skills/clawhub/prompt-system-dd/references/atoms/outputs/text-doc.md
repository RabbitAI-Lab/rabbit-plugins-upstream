> 唯一真相源:本文件是文本输出类型的唯一权威定义。单段正交结构,无深度分档。
> 自包含:不依赖其他原子内容,可独立注入组装。

## 输出类型注入内容

- 适用场景:报告(市场分析/项目进度/总结)、邮件(欢迎/通知/商务)、文案(营销/产品/广告)、方案(培训/活动/实施)
- 格式要求:Markdown 或纯文本,标准文档格式(标题、段落、列表),结构清晰逻辑连贯
- 特殊要求:
  - 字数范围明确(如"500-600字"、"10000字左右")
  - 段落分明,使用标题和列表
  - 语言风格符合场景(正式/活泼/简洁)

## 提示词注入模块

```markdown
## 3. 输出要求细则
- 格式规范:Markdown格式,正文分章节(一级标题+二级标题)
- 结构框架:背景介绍→核心分析→结论建议
- 颗粒度标准:每个章节至少包含3个要点,总字数800-1000字
- 关键要点:必须包含数据支撑和具体建议
```
