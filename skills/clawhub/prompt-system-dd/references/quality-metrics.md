# 质量可检验指标(Quality Metrics)

> 唯一真相源:本文件定义七维质量表中**可机械计算**的子集及其档位阈值。
> 主观项(专业性 / 场景适配性 / 语气一致性)不在此列,保留人工核对,禁止强行量化。
> 实现:`scripts/score_prompt.py`;门禁一致性校验:`validate_skill.py` QL001-QL008(QL001/002/004-007 为 error,QL003/QL008 为 warning)。

## 目录

- 设计原则
- 可计算指标阈值表
- 主观项清单(人工核对)
- 计分方式
- 阈值标定状态

## 设计原则

1. **只量化能算的**。七维表曾给出"质量可评估"的错觉,实际全靠人工。本文件把其中可机械判定的部分抽出来,交给人看的只剩真正需要判断的部分。
2. **阈值是草案**。下表数值为初版估算,需在实际产出样本上标定后才能作为硬门禁;标定前一律按 warning 处理,不阻断交付。
3. **D1 豁免大部分指标**。D1 是极简档(一句话产出),强行套用结构化指标会逼出冗余内容,表中 "-" 表示不校验。

补充说明:

- **QL003** 的"数据项"指产出中出现的具体数值、年份、统计口径、引用条款;"来源标记"指 `来源:`、`(来源...)`、`据 XX`、`[引用]` 等显式标注。无法可靠识别数据项时,本项降级为 info 不参与计分。
- **QL004** 的"约束段"指含"约束/必须/禁止/要求/边界"标题或首句的区块;不在约束段内的列表项不计入。
- **QL006** 接受等价表述(如"第一步分析 / 第二步构建 / 第三步压力测试"),由脚本做模糊匹配。
- **QL008** 的"通用词表"指 内容/结构/风格/规模 四个通用维度名;只有超出这四个词的、来自任务语境的触发词才计数。

## 主观项清单(人工核对)

以下三项不设阈值、不参与自动计分,产出后由人确认:

1. **专业性** —— 术语使用是否符合行业标准,是否有外行表述。
2. **场景适配性** —— 是否针对具体场景定制,而非套通用模板(重点看域原子是否真正落地)。
3. **语气一致性** —— 风格定义是否在全文贯彻,是否存在前后语气断裂。

## 计分方式

- 逐维判定 `pass / fail / skip`("-" 为 skip)。
- 通过率 = pass 数 / (pass 数 + fail 数),skip 不计入分母。
- **通过率 < 100% 时输出失败项明细,由人决定是否返工**;脚本不代替人做返工判断。
- 主观项单独输出为 `manual_checklist`,供人逐项勾选。

## 变更规则

- 修改本表阈值后,必须同步 `scripts/score_prompt.py` 中的 `METRICS` 常量;
