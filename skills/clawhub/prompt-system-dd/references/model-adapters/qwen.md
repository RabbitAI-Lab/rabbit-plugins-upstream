> 唯一真相源:本文件定义通义千问系列目标模型的提示词结构改写规则。
> 正交性:适配器只改写**表达形态**,不改变 DEPTH 指纹的 9 位档位语义。

## 适用判定信号

- 用户显式指定通义千问 / Qwen / 阿里;
- 指纹后缀为 `@model=qwen`;
- 国内部署环境 + 中文业务语境。

## 结构偏好

中文 Markdown 分层 + 明确角色设定。Qwen 对"角色 + 分步要求 + 输出格式"三段式的响应最稳定。

| 通用段 | Qwen 写法 |
|--------|-----------|
| 角色 | `# 角色` |
| 任务 | `# 任务` |
| 上下文 | `# 背景` |
| 示例 | `# 示例` |
| 输出格式 | `# 输出格式` |
| 思考指令 | `# 执行步骤`(有序列表) |
| 约束 | `# 约束` |
| 自检 | `# 自检` |
| 迭代 | `# 调整方式` |

## 必用写法

- 角色段必须写满:身份 + 经验年限 + 能力维度,泛化角色会显著降质;
- 执行步骤用有序列表逐步列出;
- 中文标点统一(与 SKILL.md 注意事项一致);
- 需要结构化输出时同时给出字段名清单与一个最小示例(示例对 Qwen 的格式遵循度提升明显)。

## 禁用写法

- 禁止角色段只写"你是一个 AI 助手"这类泛化表述;
- 禁止超长 system prompt(>2000 字)—— 长指令下中段遵循度下降;
- 禁止混用中英文标点。

## 注入模块

组装产出尾部追加:

```
请按上述步骤依次执行,完成后对照自检清单逐条确认,再输出最终结果。
```

## 与档位的交互

- D1/D2:角色 + 任务 + 约束三段即可;
- D3:补齐背景、执行步骤、自检;
- D4:追加对抗审查与合规复核节点,并要求在输出末尾单列"需人工确认事项"。

## 质量检查清单

- [ ] 角色段含身份 + 年限 + 能力三维
- [ ] 执行步骤为有序列表
- [ ] 标点全中文,无中英混排
- [ ] 结构化输出场景给出了最小示例
- [ ] DEPTH 头部指纹未被本适配器改写(仅尾部追加执行要求)
