## Description: <br>
ExpertLens adds a platform-agnostic expert reasoning framework that helps an agent diagnose the real problem, adapt reasoning to the domain, self-audit responses, and optionally coordinate multi-model review for harder tasks. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and external users use ExpertLens to add structured expert-style reasoning, domain adaptation, calibrated uncertainty, and self-review behavior to an AI assistant for complex or high-quality deliverables. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad auto-activation may apply the reasoning framework to more tasks than expected. <br>
Mitigation: Install only if broad expert-style reasoning behavior is desired, and review activation behavior before using it in sensitive workflows. <br>
Risk: Autonomous Swarm, email feedback, and persistent memory instructions can involve third-party AI services or stored information. <br>
Mitigation: Disable or avoid those features for confidential work unless the agent shows exactly what will be shared or stored and the user explicitly approves it. <br>
