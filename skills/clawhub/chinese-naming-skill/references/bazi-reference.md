# 八字五行参考

> 本参考文档提供八字分析的基础知识。**AI 在使用时应向用户呈现不同观点，让用户选择。**

## 基础概念

### 四柱八字

用出生年月日时推算的四组天干地支：

```
年柱    月柱    日柱    时柱
丙午    甲午    癸丑    戊午
```

- 日主（日柱天干）代表命主
- 月令（月柱地支）决定五行旺衰基准

### 五行生克

```
相生：木 → 火 → 土 → 金 → 水 → 木
相克：木 → 土 → 水 → 火 → 金 → 木
```

### 用神与忌神

- 用神：命局中最需要的五行，起名时优先补益
- 忌神：命局中过旺或有害的五行，起名时避免

## 流派简介

八字命理存在流派分歧，以下为主要流派及其特点：

### 《渊海子平》《子平真诠》系（正统派）

- **来源**：宋元明子平主流体系
- **特点**：重格局、重定式，判断标准严格
- **从格判定**：日主需在天干地支中无任何同党根（包括地支藏根的中气、余气），印星不透不藏，从神得令透干，无实质性逆顺。只要有一点藏根，即判身弱，不走从格
- **适用**：判断保守，宁可走守势，适合避免误判

### 《滴天髓》《滴天髓阐微》系（变通派）

- **来源**：清·任铁樵阐微
- **特点**：叠加了取象/灵活变通一层，边界上可能破例
- **从格判定**：有时会说"似从不从亦可从"之类的变通表述
- **风险**：变通表述在实际操作中容易导致误判，从格一旦误判则用神集反转

> ⚠️ **使用方式**：当两派判断不同时，向用户说明分歧点、各自依据和后果差异，**让用户选择**采用哪个流派的判断。

## 真太阳时 vs 时区时间

### 区别

- **时区时间**：标准时间，如北京时间（东八区统一时间）
- **真太阳时**：出生地实际太阳时，根据经度计算

### 计算方法

```
时差 = (出生地经度 - 120) × 4 分钟
东边加、西边减
北京时间 ± 时差 = 真太阳时
```

示例：
- 杭州东经 120.2° → 时差约 +0.8 分钟 → 几乎无影响
- 成都东经 104° → 时差约 -64 分钟 → 可能影响时柱

### 选择建议

- 时差较小时（几分钟内）：通常不影响时柱，用哪个都行
- 时差较大时（尤其接近时辰交界点）：两套排盘可能不同，需向用户说明差异，让用户选择
- 有些家庭重视真太阳时（更"精确"），有些觉得时区时间就够了——这是用户的选择

## 日柱推算注意事项

手算日柱容易出错：
- 不要轻信"某年某日是甲子日"的民间说法
- 如手算，需用两个以上独立基准日交叉验证
  - 常用基准：1900-01-01 甲戌日、1949-10-01 甲子日
- 最可靠方式：用专业排盘软件/网站

## 父母八字的作用与局限

### 作用（参考层，非硬约束）

- 看父母喜神方向是否与宝宝一致
- 看亲子间的天干合（如戊癸合 = 父女紧密）
- 可作为意象上的加分参考

### 局限

- 不能从父母喜好类推宝宝用神——父母喜神可能恰好是宝宝忌神
- 父母八字只看"方向是否冲突"，不作决定因素
- 亲子合应的表现是多方面的（心理亲密、物理陪伴等），不要简单等化为"亲密度"

### 命理推断的边界

以下类型的推断不可靠，应避免：
- 「刑冲合害 → 亲疏/距离/聚少离多」——动能关系不等于物理/心理距离
- 「财透 → 理财能力强」——需多要素同看
- 「身弱用财 → 为妻子让步」——命局结构不直接翻译为现代行为
- 「八字看健康」——与现代医学实证相关性低，只可作"五行偏趋"参考
