## Use Case:

Agent users, skill authors, maintainers, and teams use this skill to adapt proven Humanizer-style workflow demand into scoped workflow plans, reusable checklists, artifacts, analysis, code changes, and validation notes. It supports practical productivity and reliability work for adjacent skills and related agent workflows.
