## Description:

Guides theming of @allxsmith/bestax-bulma apps through brand colors, CSS variables, dark mode, and app-wide configuration.

This skill is ready for commercial/non-commercial use.

## Publisher:

[allxsmith](https://clawhub.ai/user/allxsmith)

### License/Terms of Use:

MIT-0

## Use Case:

Frontend developers use this skill to customize branding, component colors, typography, spacing, dark mode, icon libraries, and class prefixes in @allxsmith/bestax-bulma apps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Root-level themes, dark mode, and class prefix changes can alter the appearance of the entire app.

Mitigation: Review changes at the app root and check affected components in light and dark modes before deployment.
