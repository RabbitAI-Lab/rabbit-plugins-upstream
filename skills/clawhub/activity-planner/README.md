# Activity Planner 活动策划方案生成器

一款为 WorkBuddy / QClaw 设计的活动策划专家技能，根据活动类型、预算、目标人群、场景等信息，自动生成结构完整、可直接落地执行的活动策划方案。

---

## 一句话介绍

> 输入活动信息，输出一份可直接交付执行的 HTML 活动策划报告。

覆盖：新品发布、年会、快闪店、促销活动、社群活动、展会参展等主流活动类型。

---

## 适用场景

- 品牌活动 / 新品发布会策划
- 公司年会 / 团建 / 客户答谢
- 商场 / 门店快闪店活动策划
- 社群裂变 / 私域活动
- 展会参展 / 路演策划
- 促销 / 节日营销活动

---

## 核心能力

| 模块 | 输出内容 |
|------|---------|
| 活动定位 | 目标拆解、受众洞察、竞品差异化 |
| 创意主题 | 2-3 个主题方向 + 阐释 + 适合理由 |
| 流程设计 | 完整时间线、环节内容、负责人分工 |
| 预算分配 | 按场地、物料、推广、人员等维度拆解 |
| 宣传推广 | 预热、爆发、收尾三阶段推广节奏 |
| 沟通话术 | 邀请、提醒、现场主持、转化引导话术 |
| 物料文案 | 海报、推文、短视频、社群文案模板 |
| 风险预案 | 天气、设备、人流、舆情等风险与备选 |
| 效果评估 | KPI 指标、数据采集方式、复盘框架 |
| 推广监控 | 关键节点检查清单、实时数据监控表 |

最终输出为**结构化 HTML 报告**，可直接复制、打印或分享给团队。

---

## 安装方式

在 WorkBuddy / QClaw 中加载本技能：

1. 将本仓库克隆到本地
2. 在技能管理中选择 **从本地导入**，选择 `SKILL.md`
3. 或等待 ClawHub 市场审核通过后直接安装

---

## 使用方法

触发关键词：
- “帮我策划一个活动”
- “年会方案”
- “新品发布会策划”
- “活动策划”
- “活动方案”

触发后，按引导提供以下信息：
1. 活动类型
2. 活动目标
3. 目标人群
4. 预算范围
5. 活动时间
6. 活动地点
7. 参与人数（可选）
8. 品牌调性（可选）
9. 特殊要求（可选）

填写完成后，自动生成完整 HTML 策划报告。

---

## 输出示例

生成报告包含：
- 活动主题建议
- 详细流程表（时间 / 环节 / 负责人 / 备注）
- 预算分配表
- 推广节奏图
- 话术脚本库
- 物料文案模板
- 风险预案清单
- 效果评估指标
- 推广监控表
