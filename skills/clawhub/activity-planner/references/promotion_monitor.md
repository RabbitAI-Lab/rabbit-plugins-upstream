# 推广过程监控指南

## 监控指标体系

### 指标分层

| 层级 | 指标 | 说明 | 计算方式 |
|------|------|------|---------|
| 曝光层 | 展示量 | 广告/内容被展示的次数 | 平台后台直接读取 |
| 曝光层 | 触达人数 | 独立用户看到广告的次数 | 平台去重统计 |
| 曝光层 | CPM | 千次展示成本 | 总花费 / 展示量 × 1000 |
| 互动层 | 点击量 | 广告/链接被点击的次数 | 平台后台直接读取 |
| 互动层 | CTR | 点击率 | 点击量 / 展示量 |
| 互动层 | CPE | 单次互动成本 | 总花费 / 互动次数 |
| 互动层 | 转发量 | 内容被转发/分享的次数 | 平台后台直接读取 |
| 转化层 | 报名人数 | 完成报名表单的人数 | 报名系统统计 |
| 转化层 | 留资数 | 留下联系方式的人数 | 表单/CRM统计 |
| 转化层 | 到店/到场数 | 实际到场参与的人数 | 现场签到统计 |
| 转化层 | CPL | 单个留资成本 | 总花费 / 留资数 |
| 转化层 | CPA | 单个到店成本 | 总花费 / 到店数 |
| 转化层 | 转化率 | 报名→到场的转化率 | 到场数 / 报名数 |

### 不同渠道的核心监控指标

| 渠道 | 核心指标 | 辅助指标 |
|------|---------|---------|
| 朋友圈广告 | CTR、CPL | 展示量、点击量 |
| 公众号推文 | 阅读量、报名转化率 | 转发量、收藏量 |
| 小红书 | 互动率、种草→报名转化 | 笔记曝光、涨粉数 |
| 抖音/视频号 | 完播率、点击率 | 点赞量、评论量 |
| 微信社群 | 报名转化率、裂变系数 | 活跃度、分享次数 |
| KOL合作 | 专属链接点击量、CPL | 互动量、曝光量 |
| 线下地推 | 留资数、CPA | 扫码率、到店率 |

## 目标值设定参考

### 按渠道的基准CTR/CPL参考

| 渠道 | 基准CTR | 基准CPL | 备注 |
|------|---------|---------|------|
| 朋友圈广告 | 1.5%-3% | 15-40元 | 行业差异大，仅供参考 |
| 公众号推文 | 3%-8%（阅读→报名） | 5-20元 | 取决于粉丝质量 |
| 小红书 | 2%-5% | 10-30元 | 品牌号略低 |
| 抖音/视频号 | 1%-3% | 20-50元 | 视频质量决定性强 |
| 微信社群 | 5%-15% | 3-10元 | 最便宜但规模有限 |
| KOL合作 | 2%-8% | 20-80元 | 取决于KOL匹配度 |

### 预警阈值设定规则

| 指标 | 正常 | 预警 | 严重 |
|------|------|------|------|
| CTR | 高于基准值 | 低于基准值30% | 低于基准值60% |
| CPL | 低于基准值 | 高于基准值30% | 高于基准值60% |
| 报名进度 | 达到时间进度对应目标 | 落后目标20% | 落后目标40% |
| 到场率 | 70%以上 | 50%-70% | 低于50% |

## 数据回收频率与流程

### 预热期（活动前7-14天）

**每日数据回收（固定时间：每日10:00前回收前一日数据）**

回收数据：
- 各渠道展示量、点击量、CTR
- 各渠道报名人数、CPL
- 总报名进度 vs 时间进度
- 社群活跃度（日活、讨论量）
- KOL内容数据（曝光、互动、专属链接点击）

输出：**每日推广日报**

### 活动当天

**每2小时数据快报**

回收数据：
- 签到人数 vs 报名人数（到场率）
- 现场互动数据（拍照打卡数、话题讨论量）
- 直播数据（在线人数、互动量）
- 实时转化数据（如有现场销售）

输出：**每2小时快报**（发送至工作群）

### 延续期（活动后1-7天）

**每日数据回收**

回收数据：
- 活动相关内容传播数据（阅读、转发、讨论）
- 现场转化跟进数据（回访成功率、二次转化率）
- UGC内容数量和传播量
- 满意度调查回收率和评分

## 动态优化策略

### 预算调拨规则

| 触发条件 | 动作 | 执行时限 |
|---------|------|---------|
| 某渠道CPA低于均值30% | 追加该渠道20%预算 | 24小时内 |
| 某渠道CPA高于均值50% | 暂停该渠道投放 | 12小时内 |
| 某渠道连续2天无转化 | 暂停并排查原因 | 即时 |
| 总预算消耗过快（超时间进度20%） | 降低非核心渠道预算 | 即时 |
| 总预算消耗过慢（落后时间进度20%） | 追加高效渠道预算 | 24小时内 |

### 内容优化规则

| 触发条件 | 动作 | 执行时限 |
|---------|------|---------|
| 某素材CTR低于1% | 24小时内替换素材 | 24小时 |
| 某素材CTR高于3% | 追加该素材投放量 | 12小时 |
| 报名转化率低于2% | 优化落地页/报名表单 | 24小时 |
| 社群讨论量下降50% | 发起话题/活动激活 | 即时 |

### 节奏调整规则

| 时间节点 | 检查项 | 预警动作 |
|---------|--------|---------|
| 预热第3天 | 报名进度 vs 目标 | 不足40%：启动KOL追投+社群裂变 |
| 预热第5天 | 报名进度 vs 目标 | 不足60%：启动应急推广+电话邀约 |
| 预热第7天（前1天） | 到场预估 vs 目标 | 不足80%：启动最后冲刺+朋友圈定投 |
| 活动当天开场前2h | 签到人数 vs 报名人数 | 到场率不足50%：电话提醒未到场人员 |
