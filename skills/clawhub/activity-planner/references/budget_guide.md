## 预算规模参考

| 预算区间 | 策略侧重 | 注意事项 |
|---------|---------|---------|
| 5000元以下 | 线上为主，创意驱动 | 优先社群和自媒体传播，场地选免费/低成本 |
| 5000-2万 | 小型线下+线上结合 | 控制人数，重体验轻排场 |
| 2-5万 | 中型线下活动 | 可请专业摄影，注意物料品质 |
| 5-10万 | 正式品牌活动 | 可考虑KOL合作，需专业搭建 |
| 10-30万 | 大型品牌活动 | 媒体投放占比提升，需专业团队执行 |
| 30万以上 | 大型发布会/盛典 | 需活动公司全案执行，增设公关模块 |

## 预算编制原则

1. **机动资金不少于5%**：应对突发情况
2. **大头锁定优先**：场地、搭建等大额支出先确认再分配剩余
3. **留痕原则**：每笔预算标注预计实际支出，便于复盘
4. **ROI意识**：转化类活动算清获客成本，品牌类活动算清CPM
