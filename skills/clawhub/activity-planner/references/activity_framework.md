# 活动策划框架 - 按活动类型

## 1. 新品发布会

### 核心目标
品牌曝光 + 产品认知 + 媒体传播

### 策划要点
- **前7-14天**：媒体预热，悬念海报，KOL预告
- **前3天**：确认到场名单，发送提醒
- **活动当天**：
  - 签到体验（30min）：产品展示区、互动打卡
  - 正式发布（60-90min）：品牌叙事 → 产品亮相 → 核心卖点讲解 → 嘉宾分享
  - 体验交流（60min）：自由体验、媒体专访、社交
- **后3-7天**：PR稿件发布，KOL内容铺发，数据回收

### 关键成功因素
- 产品亮相环节的"Wow Moment"设计
- 媒体到场率和发稿率
- 现场体验区的完成度

### 常见坑
- 流程冗长导致注意力涣散（控制在2.5小时内）
- 媒体群访安排混乱（提前排好时间表）
- 体验区排队过长（控制人数节奏）

## 2. 公司年会

### 核心目标
团队凝聚 + 年度回顾 + 激励展望

### 策划要点
- **前2周**：节目征集、抽奖规则公布、座位安排
- **活动当天**：
  - 入场签到（30min）：拍照墙、签到互动
  - 年度回顾（20min）：视频+数据回顾
  - 颁奖环节（30min）：年度优秀、特别贡献
  - 文艺节目（60min）：员工节目+专业演出
  - 抽奖互动（30min）：穿插多轮抽奖
  - 晚宴社交（90min）：自由交流
- **后1周**：照片视频分发，满意度收集

### 关键成功因素
- 节目质量和节奏把控
- 抽奖环节的惊喜感
- 年度回顾的感染力

### 常见坑
- 领导讲话过长（每人控制在5分钟内）
- 节目冷场（备好串场互动）
- 抽奖公平性质疑（提前公示规则）

## 3. 快闪店活动

### 核心目标
体验转化 + 社交传播 + 品牌植入

### 策划要点
- **选址**：人流密集商圈/目标人群聚集地
- **周期**：3-7天为宜，首日引爆，持续引流
- **设计**：打卡点至少2个，体验区1-2个，商品/服务区1个
- **每日运营**：
  - 开店引流：KOL/达人探店时段
  - 高峰互动：限时活动、整点惊喜
  - 闭店整理：数据记录、物料复位
- **传播设计**：
  - 专属话题标签
  - 打卡分享机制（分享得福利）
  - 每日内容输出（照片/短视频）

### 关键成功因素
- 视觉冲击力（让人忍不住拍照）
- 体验设计闭环（吸引→体验→分享→转化）
- 每日人流稳定性（持续引流策略）

### 常见坑
- 选址人流不匹配目标人群
- 打卡点过于单一导致传播疲劳
- 现场转化路径缺失（光打卡不消费）

## 4. 促销活动

### 核心目标
短期销售增长 + 库存清理 + 用户激活

### 策划要点
- **活动周期**：3-7天，不宜过长
- **促销机制设计**：
  - 满减/折扣/赠品三选一为主，避免叠加混乱
  - 设置阶梯激励（如满100减20，满200减50）
  - 限时限量制造紧迫感
- **宣传节奏**：
  - 前3天：预告+蓄水
  - 活动期：每日推播+社群催单
  - 最后1天：倒计时冲刺
- **现场/页面设计**：
  - 核心优惠信息一目了然
  - 购买路径最短化
  - 营造热销氛围（库存倒计时、已购人数）

### 关键成功因素
- 优惠力度的吸引力（对比日常价格）
- 传播触达的精准度
- 购买转化路径的顺畅度

### 常见坑
- 优惠规则复杂导致用户放弃
- 库存准备不足断货
- 活动后价格回调策略缺失

## 5. 社群/线下沙龙活动

### 核心目标
用户深度连接 + 知识分享 + 社群活跃

### 策划要点
- **规模**：15-40人最佳，保证互动质量
- **时长**：2-3小时
- **流程设计**：
  - 签到破冰（20min）：自我介绍+破冰游戏
  - 主题分享（45-60min）：嘉宾分享或圆桌讨论
  - 互动讨论（30-45min）：分组讨论或Q&A
  - 自由交流（30min）：茶歇社交
- **内容沉淀**：
  - 活动前：收集参与者关心的问题
  - 活动中：专人记录要点、拍照
  - 活动后：整理纪要分发，引导后续讨论

### 关键成功因素
- 嘉宾/话题的吸引力
- 互动环节的设计质量
- 参与者画像的匹配度

### 常见坑
- 人数过多导致互动质量下降
- 嘉宾分享单向输出缺乏互动
- 活动后无跟进导致一次性关系

---

## 6. 展会参展

### 核心目标
品牌展示 + 获客引流 + 商务对接

### 策划要点
- **展前1个月**：展位设计确认、物料制作、人员培训
- **展前2周**：邀约目标客户到展位、预约商务洽谈
- **展会期间**：
  - 展位设计：视觉吸引力+产品展示+洽谈区+互动区
  - 每日获客：扫码留资机制、互动小游戏
  - 现场活动：展位限时活动（每天1-2场，每场15-30min）
  - 商务对接：提前排好洽谈时间表
- **展后1周**：客户跟进分级、线索转化、参展复盘

### 关键成功因素
- 展位的视觉差异化
- 留资机制的高效性
- 展后跟进的及时性

### 常见坑
- 展位同质化无吸引力
- 只收集名片无后续跟进
- 人员轮换混乱导致接待断档
