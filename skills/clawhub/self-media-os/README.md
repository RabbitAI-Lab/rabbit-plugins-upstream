# 自媒体操盘系统 · self-media-os

一个 Agent Skill（AI 技能）。装进支持 [Agent Skills](https://www.anthropic.com/news/skills) 格式的工具（Claude Code、Trae 等）后，当你在做自媒体内容决策时，AI 会自动启用一套经过大量爆款验证的**内容判断标准**，帮你判断和修改：选题、开头钩子、结尾、涨粉策略、账号定位、变现路径、数据诊断。

它的核心主张是一句话：**视频火不火，主要不取决于选题，取决于结构。** 好内容有可拆解的规律——在观众心里设置一个清晰的问题、尽可能晚地揭晓答案、结尾留下让人回味的东西。这套系统把这个过程拆成了 AI 可执行的判断工具。

## 它解决什么问题

做内容的人几乎都陷在这个循环里：数据差 → 归因错误（怪账号、怪运气、怪平台算法）→ 去抄下一个爆款 → 还是差。

差的往往不是执行力，是判断内容好坏的标准从来没换过。而市面上的方法论大多给模板："10 个爆款钩子公式""万能开头三件套"。模板的问题是：套对了是运气，套错了不知道为什么错——并且 AI 时代，套模板这件事 AI 比人快一百倍。

这个 Skill 反着来：**不替你写，帮你换判断标准。** 它内部的信条是：你的终极形态是决策者，而不是会用高级工具的工具人。

## 它的判断标准长什么样

装上后，AI 会用这样的判断回应你。举几个例子感受一下风格：

> **"你越讲干货，越不涨粉。"**
> 干货吸来的只是"正好在搜资料的人"——他们记住的是信息，不是你。所以很多账号点赞收藏都不差，粉丝却一动不动。

> **"90% 的钩子都是废的。"**
> "你知道吗？""5000 万人不知道的真相"只是形式。真正有效的开头，要在观众心里制造一个具体、清晰、观众自己意识到"我想知道答案"的问题。

> **"垂直赛道是个伪命题。"**
> 该问的不是"我的赛道垂不垂直"，而是这个选题能戳到多少人的共同好奇心。一个只有同行在乎的选题，做得再好，天花板就是同行的数量。

> **"结尾别总结、别把话说死、别求关注。"**
> 回想你收藏过的干货视频，你记住的从来是中间那几句干货，不是结尾的"以上就是三点"。

## 它内置的判断速查表

这张表是 `SKILL.md` 里的速查表：

| 工具 | 一行版 |
|---|---|
| 选题三查 | 除你之外有人想看吗？/ 别人听完记得住、酒局上愿意讲吗？/ 能一句话写出精准缺口吗？ |
| 钩子三自检 | 挖的洞清晰吗？/ 填洞时长和答案匹配吗？/ 遮住标题封面能站住吗？ |
| 洞察五问 | 换一群人还成立吗？/ 能被搜到吗？/ 竞品能说同样的话吗？/ 想得起具体时刻吗？/ 观众做决定时能想起吗？ |
| 对标五问 | 他的变现方式你能用吗？/ 他会的你会吗？/ 别人凭什么信你？/ 这条道还有你的位置吗？/ 别人能抄你吗？ |
| 结尾三禁令 | 别总结内容 / 别把话说死 / 别求关注 |
| 利他类型 | 信息型说"是什么"= 有没有你都行，不涨粉；判断型说"我认为/我见过/我发现"= 认知长在身上才涨粉 |
| 好内容定义 | 看完觉得"有人终于说出了我想说的话" |

## 这个 Skill 的四个设计决策

它不是"一堆方法论的堆放"，有四个刻意的工程决策：

1. **教 AI 理解机制，而不是背规则。** 每个判断标准都附带"为什么成立"（比如：为什么悬念能留人——大脑对没完成的事记忆更强，心理学上叫蔡根尼克效应）。理解了机制，AI 就能应对你没覆盖到的新场景，而不是机械填表。
2. **按需加载。** `SKILL.md` 只是入口，八个分域文件（选题、钩子、涨粉、定位、变现、诊断、灵感、工作流）按问题类型加载——问钩子只读钩子文件，不浪费上下文。
3. **触发克制。** 只在你明确寻求内容建议时激活；随口聊到某个视频、某个博主不会触发，不硬套框架。
4. **防"说得漂亮"的坑。** 所有框架都能把一个没道理的观点包装得头头是道，所以每个判断都附带可验证的机制解释，教程类内容不硬套内容框架——最终判断权留给人。

## 安装

**方式一：一句话安装（最省事）**

打开你正在用的 AI Agent，直接发这句话：

> 帮我安装这个 Skill：https://github.com/SupereeeYunjiu/self-media-os

有文件操作权限的 Agent 会自己下载并放到正确位置。

**方式二：命令行一键安装**（需要 [Node.js](https://nodejs.org/) 22+）

```bash
npx skills add SupereeeYunjiu/self-media-os
```

用开源的 [skills CLI](https://github.com/vercel-labs/skills) 安装——它会自动检测你装了哪些 Agent 让你选，默认装到当前项目，加 `-g` 全局可用。[支持 80+ Agent，完整列表见这里](https://github.com/vercel-labs/skills/blob/main/docs/agents.md)。

**方式三：手动安装**

仓库页面右上角 **Code → Download ZIP**，解压后把整个 `self-media-os` 文件夹复制到技能目录：

| Agent | 技能目录 |
|---|---|
| Claude Code | `~/.claude/skills/`（全局）或项目内 `.claude/skills/` |
| Trae | `~/.trae-cn/skills/` |
| Codex | `~/.agents/skills/` |
| 其他 Agent | 同理，放进该 Agent 的技能/rules 目录 |

**哪些 AI 能用？**

- **原生支持 Agent Skills 格式**（自动发现、自动触发）：Claude Code、Trae、Codex、Cursor、OpenCode 等
- **其他任何 AI**——通义灵码、文心快码、Kimi、DeepSeek、豆包、CodeBuddy 等：把 `SKILL.md` 和 `references/` 里的文件发给它，说一句"按这套标准帮我判断"，一样成立。仓库全部是纯 Markdown，没有读不了 Markdown 的 AI。
