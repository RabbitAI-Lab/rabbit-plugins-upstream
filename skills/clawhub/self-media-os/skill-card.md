## Description:

Provides content decision guidance for creators on topic selection, hooks, audience growth, account positioning, monetization, performance diagnosis, and publishing review.

This skill is ready for commercial/non-commercial use.

## Use Case:

External creators use this skill to assess and improve social media content decisions, from topic selection and script structure to audience growth, monetization, and pre-publication checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The installation guidance uses an unpinned CLI command.

Mitigation: Check the CLI package and version before running the install command, and pin a version when reproducibility matters.

Risk: Some account troubleshooting suggestions could lead to deleting content or removing followers.

Mitigation: Review and verify the diagnosis before taking account actions; back up content before deleting anything.
