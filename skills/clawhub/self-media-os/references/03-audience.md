# 03 涨粉与洞察：涨粉三诀 / 痛点与洞察

涨粉的迷思先破掉：点赞高、收藏高、评论区和谐，都不等于涨粉。涨粉是另一个机制——本文件三诀都围绕它。

## 一、涨粉的底层逻辑：关注是将来时

观众为什么关注你？关注这个动作的心理本质：**他相信你以后还能持续交付让他满意的东西**。

- 关注一个做饭的 = 想看他之后还能教你怎么在家复刻米其林级别美食
- 关注一个好看的明星 = 颜值本身就在持续向你输出

推论：观众关注你不是**奖励你这条视频**，是**预付对下一条的期待**。想清楚这个，下面三诀就好理解了。

## 二、第一诀：越讲干货，越不涨粉

听起来反直觉，但机制很硬：

- 案例：一个做 HR 的朋友，毕业季做"求职懒人包"——简历模板、面试技巧、怎么筛选岗位，高强度更新。评论区一片和谐："学到了，谢谢""收藏了，谢谢"。但涨粉量特别少。
- 为什么：互联网上那么多教找工作的账号，作为求职者，闭着眼搜"毕业生求职"都能搞到这些资料。**你吸来的只是正好在平台搜面试攻略的人——他们冲资料来的，不是冲你这个人来的。** 下次再有面试需要，他搜"面试资料"又是一大把，完全不需要你这个账号。
- 这就是"信息型利他不涨粉"的机制（完整诊断 → 06 工具人号一节）。
- "评论区扣一轰炸 5000 人"式的涨粉套路没用——扣一的人是冲福利来的，不是冲你来的。千万别试。

## 三、第二诀：替观众说话——人不会为信息关注一个人，会因为"被看见"关注一个人

**被看见 = 你说出了一个他心里早有感觉、但还没组织成语言的东西。你提前说出来了，就到位了。**

- 财务公司案例："老板娘买奢侈品包能不能入公司账"——这种问题答案一搜一大把，而且都差不多。怎么做才能拉开差距？客户表面问的是包，**最深层的东西是公司存在公私不分的问题**：之后再有的话怎么办？现在已经有的怎么解决？把这个问题分析清楚，绝对让人觉得你有点东西。
- "想做好自媒体"这四个字的拆法：里面其实包括选题、流量、变现、涨粉——有人追求流量，有人追求变现；追求流量的背后又分"想要既省事又有流量的方法"还是"不计成本只要有流量就行"。
- **能看透这些藏在观众心里的分层，才能涨有质量的粉。** 涨粉类请求先做这个拆解，比直接给"涨粉技巧"有用得多。

## 四、第三诀：痛点不是洞察——别把两个东西搞混了

### 区别
- **痛点 = 观众自己早就知道的东西。** 为什么叫痛点？一个人哪里痛，他自己比别人更清楚。"我缺钱""我学习不好"——你做视频只能指出这些，别人当然不会觉得你牛逼。
- **洞察 = 问题背后的东西。** "我缺钱"的背后是：我想要一个轻松的赚钱方法，你得给我一个。"我学习不好"的背后是：我需要一个不用背就能考高分的方法，你得给我一个。

### 洞察五问（判断你的洞察够不够精准）
拍视频之前问自己五个问题：

1. **换一群人，这个洞察还成立吗？** 一个睡眠建议给想提升分数的学生也成立——那就不行，说明它太通用。
2. **这句话能被搜到吗？** 能被搜到，说明不是你先说的。
3. **你的竞品能说同样的话吗？** 能——那它或许精准，但并不难想，已经有人讲过，你再讲流量可能就不好。
4. **你能回忆起这个洞察是从哪个具体时刻来的吗？** 想不起来，可能是你编的。编的就不是真洞察，大家听了不会触动。
5. **观众下次做相关决定的时候，你确定他能想起你的洞察吗？** 不会，说明你找的不够精准。

五问过完，你就知道自己是真的洞察了观众内心，还是又拍了个没用的工具视频。

## 接到涨粉请求的思考顺序

1. 先看账号的利他类型：输出的是信息（是什么）还是判断（我认为/我见过/我发现）？信息型 → 06 工具人号诊断。
2. 再拿"关注是将来时"拷问：看完这条，观众有理由期待你的下一条吗？期待的理由是什么？
3. 然后跑洞察五问：用户以为的"洞察"是不是只是痛点（观众自己早知道的东西）？
4. 最后指向元概念"替人翻译"（→ 05 洞察翻译法）：用户有没有说出观众心里有但嘴上没有的那句话？好内容的定义就是——看完觉得"有人终于说出了我想说的话"。
