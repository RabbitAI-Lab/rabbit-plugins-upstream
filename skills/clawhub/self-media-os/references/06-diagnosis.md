# 06 诊断与起号：工具人号 / vlog三型 / 起号真相 / 运维附录

## 一、工具人号诊断（点赞高收藏高，就是不涨粉的元凶）

### 两个同病相怜的案例
- 留学规划号：留学有什么坑、签证要准备什么材料、哪个学校排名掉了——每条都做得特别详细。但每当升学季视频起来一波，升学季一过瞬间没流量。作者不想做了。
- 旅游避坑号：北京五个地方千万别去、什么时候来北京玩攻略——做得很好，但除了旅游高峰，流量基本没变化。
- 共同点：内容做得很好，但**把这个号完全交给另一个人、或者换成 AI 做，结果没区别**。

### 机制：为什么信息型利他不涨粉
- 你和观众的壁垒无非是**信息差**，而这种信息属于**公共财产**。你讲了，观众记住的是信息，不是你；你不讲，有的是人讲，甚至观众问 AI 都行——不差你一个。
- 数据表现：点赞高、收藏可能高，但**不涨粉**。因为在观众眼里你不是个人，是工具。**工具要粉丝没有用。**
- 工具的特征就是可代替：扳手坏了扔了换个新的，锤子坏了扔了换个新的。

### 破局：判断型利他
- 不是"留学 5 个坑"，是"**我见过**一个学生误选了个专业，全是中国人，读了两年英语还没进步"——前者任何中介都能发，后者是只有你才经历过的案例经验。
- 不是"北京这五个地方千万别去"，是"**我带**我爸妈去北京，最让我意外的不是景点，是他们在故宫走了 20 分钟就走不动了"。
- 区别信号词：信息型说"是什么"；判断型说"**我认为 / 我见过 / 我发现**"。
- 区别不在谁的知识多，在**谁的认知长在自己身上**——认知是别人偷不走的东西。
- 做出判断型内容的出发点不止几个，掌握一个，剩下的会自己长出来。

### 补充判断：纯讲故事号
- 好的故事自带巨大流量——讲出去的瞬间就有被故事本身吸引而来的人贡献流量。注意措辞：是被故事吸引来的，不是被你这个人。
- 但精彩的故事是有限的。纯讲故事的号每天都焦头烂额：这个故事不错观众喜欢吗？那个也不错但被人讲过了——永远为下一个选题发愁，永远高强度搜下一个选题会不会撞车。这也是另一种可代替。破局同样是判断型利他。

## 二、vlog 三型诊断（"我拍的 vlog 没人看"）

先破误解：不是你的生活无聊，是把 vlog 理解错了。对照三型看用户能拍哪种：

### 1. 判断性 vlog（普通人最省钱、最取巧的入口）
- 参照系：从好到拉锐评类视频——把某个东西做排序（游戏/明星/电影），流量都不低。这类视频卖的是**判断**。
- 把判断放进 vlog：选题/标题的格式是"我做了什么什么，但**我最后悔的是 / 我发现 / 我感受 / 我觉得**……"——例："今天去吃麦当劳，但我发现了个恐怖的事。"
- 机制：这些标题隐词就是人的判断，就是钩子——在你脑子里轻松挖了个清晰的洞（为什么后悔？吃个普通麦当劳能有什么恐怖的事？）。整条视频都在解释观众心里的疑问。
- 不用先追求特立独行的生活、不用租豪车豪宅——**今天做了一个特别的决定，把它拍出来**就够了。比日记流水账强太多。

### 2. 向往性 vlog（情绪 > 剪辑）
- 定位：带观众过上他想过但还没过的那十分钟。
- 案例：满世界钓鱼老哥——"随时想飞去哪钓鱼就去钓"的生活就是钓鱼佬牛马想要的，大家多羡慕你知道吗？这种情况下**完全不要考虑剪辑**，脖子挂个 go pro 不停记录：准备、风景、打窝、等待、发呆、上钩，全程拍进去。重剑无锋，大巧不工。
- 机制：观众看的重点不是你能不能钓上鱼，是"我有一天是不是也能像你一样过一天"。浓烈的情绪已经大过了剪辑和文案。

### 3. 身份型 vlog（最简单也最难）
- 简单：什么都不用做，不用拍断不用审美。难：需要一个观众天然对你有信息差的身份——海员的船上日常、摇奶茶的忙不过来的日常、酒厂老板的一天。
- 卡点判断：**你的身份是普遍的还是特殊的？** 拍"牛马打工一天"没人看——太多人打过工。拍"酒厂老板的一天"有人看——大多数人一辈子进不去那个场景。
- 活人感：老板身上最值钱的是他每天划过去没留意的小事（酒厂什么样、真假酒怎么分辨）——他觉得理所当然，观众想看的就是这些小事。
- 观众点进来不是因为内容，是因为**这个人活在大多数人一辈子进不去的场景里**。

## 三、起号真相（流量层的现实视角）

> 这一节讲的是"流量从哪来"的运作现实，和内容判断层不冲突——内容层解决"东西对不对"，这一节解决"火起来之后流量怎么放大"。

- 真正的起号就是**一条视频做起来的**，不存在复杂流程：某条视频火了，一宿涨了七八千粉 → 投 100 块验证（100 块涨 150 粉）→ 把这条视频追加 5000 块 → 1.5 万粉 → 再投 → 3 万粉。所有账号都是这么起来的。
- 素人火也是一样：某一条视频火，其他视频没那么火——你刷到的突然火起来的素人，主页往往就那一条。
- 选题配合的分工：
  - **想破流量 → 猎奇选题**："第一个吃螃蟹的人为什么说螃蟹吃完会死""这种长得像海胆的东西真的是水果吗，能吃吗"——不知道做什么猎奇的，可以直接问 AI："我这个行业有什么猎奇的、一般人不知道的事？"
  - **想涨粉 → 知识性系列**：芒果蘸辣椒面（海南人吃法，巨好吃）→ 预告下一期葡萄能配什么 → 做成 12 期奇怪水果吃法。系列 = 给观众"以后还能交付"的期待（呼应 03：关注是将来时）。
- **火了一条之后：沿着火的选题接着拍。** 芒果蘸辣椒面火了，明天研究荔枝配酱油（能吃出三文鱼的口感）——已经被验证过有流量的事，重复做。

## 四、技术运维附录（账号本身的排查）

> 运维层方法，与内容判断层不同层面。内容判断解决"东西对不对"，运维层排查"账号本身有没有问题"。两派观点并存（一派讲起号流程，一派说起号流程都是骗子）——账号数据异常且内容自查无果时，才参考本层。

- 不推流的常见技术原因：账号被降权、死粉过多、搬运或抄袭被识别、画面不清晰。
- 排查思路：用最新作品数据（不超三天）看推荐来源占比，异常低说明被限流；低质粉丝占比过高可清理；标签混乱时删除旧作品等标签重置。
- 打标签的常识：平台根据抽帧、文案、封面元素、话题综合分析出内容标签——画面里关键元素越多越聚焦（画面只有一辆车，标签就是车；一辆车加一个美女，标签可能是车也可能是美女），在内容里**频繁出现关键元素、弱化非关键元素**。
- 优质视频的运维标准：流量转化效率——观众在你这里消费的是时间、行为、货币、社交四种成本，能让人支付越多成本的视频越优质。
- 用法提醒：这些是运维视角的参考，先做内容判断层的自查（钩子/选题/利他类型），确认内容没问题时才查运维层。反过来"内容不行怪账号"是常见误区。

## 接到诊断请求的思考顺序（数据差倒查链）

用户说"数据差 / 不涨粉 / 没人看"，按这条链倒查，从内容到账号：

1. **钩子**：遮住标题封面看开头，跑钩子三自检（→ 02）——洞挖了没？清晰吗？
2. **选题**：跑选题三查（→ 01）——素材本身有没有需求、写不写得出缺口？
3. **利他类型**：本文件第一节——是不是信息型工具人号？（点赞高收藏高不涨粉的，八九不离十在这里）
4. **账号运维**：内容自查全过了数据还异常，才查附录层（限流/标签/死粉）。
5. 判决：定位到哪一环，就开哪一环的方子。不把"内容问题"误诊为"账号问题"（反之亦然）。
