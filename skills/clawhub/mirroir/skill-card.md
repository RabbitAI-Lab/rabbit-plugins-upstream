## Description:

Drive a real iPhone through macOS iPhone Mirroring with the mirroir MCP tools: read the screen, tap, type, swipe, open apps, and replay skills. Use whenever a task needs the user's phone.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agents use mirroir to inspect and operate the user's iPhone through macOS iPhone Mirroring, completing phone tasks in checked steps and replaying saved workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can read screen content and act on a real iPhone containing the user's accounts and data.

Mitigation: Grant Screen Recording and Accessibility only to the intended host, and review consequential actions and saved replays.

Risk: The submitted instructions do not verify the external server's implementation or enforcement.

Mitigation: Use a reviewed package version, remove the server registration, and revoke permissions when it is no longer needed.
