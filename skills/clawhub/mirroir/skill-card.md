## Description:

Drive a real iPhone through macOS iPhone Mirroring with the mirroir MCP tools: read the screen, tap, type, swipe, open apps, and replay skills. Use whenever a task needs the user's phone.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agents use Mirroir to inspect and operate a user's iPhone through macOS iPhone Mirroring when a task requires the phone. Actions that send, post, buy, delete, or change settings require the user's explicit consent.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:
