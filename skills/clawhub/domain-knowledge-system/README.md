# Domain Knowledge System · 陌生领域知识系统搭建器

**输入任意领域名称，自动执行四大步骤，输出一套完整的知识系统。**

一个通用的 Trae Skill，帮你快速入门任何陌生领域。已用 Kpop、跑步、摄影三个完全不同类型的领域验证通过。

## 它能干什么

你只需要说一句话：

> "帮我搭建 Kpop 知识体系"
> "我想了解红酒，从哪开始"
> "帮我系统学习手机摄影"

然后它会自动执行：

1. **信息源清场** — 扫描小红书、B站、YouTube 等平台，输出该领域的信息源清单
2. **锚点聚焦 + 认知地图** — 选 2-3 个最有代表性的锚点，生成结构化认知地图（HTML 可视化）
3. **入门路径规划** — 输出必看必读清单，按"先感性再理性"的顺序排列
4. **定时追踪配置** — 设置周报/月度扫描/进度回顾，让 Agent 帮你坚持

## 覆盖的领域类型

| 类型 | 示例 | 验证状态 |
|------|------|---------|
| 有基础但想精进 | 跑步（脚踝受伤后重新开始） | ✅ 已验证 |
| 完全知识盲区 | Kpop（零基础入门） | ✅ 已验证 |
| 有工具但没方法 | 手机摄影（介于之间） | ✅ 已验证 |
| 其他领域 | 红酒、咖啡、滑雪、投资、AI 编程 | 可迁移 |

## 使用方式

将 `SKILL.md` 放置到 Trae 项目的 `.trae/skills/domain-knowledge-system/` 目录下，即可通过自然语言指令调用。

## 方法论

**信息源先行 → 锚点策略 → 先感性再理性 → 定时追踪**

这不是通用的方法论，是经过三个完全不同的领域验证过的可执行流程。
