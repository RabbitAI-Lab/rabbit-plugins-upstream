## Use Case:

External users and agent operators use this skill to build a structured learning system for an unfamiliar domain, including source discovery, anchor topics, a cognitive map, an entry path, and recurring follow-up tasks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may create recurring tracking tasks from broad learning prompts without enough user-control details.

Mitigation: Use it only for explicit domain-learning workflows and confirm weekly reports, monthly scans, progress reminders, or generated files before enabling them.

Risk: Broad trigger phrases can activate the skill when the user only wants general learning advice.

Mitigation: Confirm the target domain, current level, goal, and time commitment before generating a full tracking system.
