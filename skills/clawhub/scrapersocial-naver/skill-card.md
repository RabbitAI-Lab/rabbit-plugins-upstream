### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Search queries and the ScraperSocial API key are sent to ScraperSocial.

Mitigation: Use only approved queries and a dedicated API key; review ScraperSocial's data-handling terms before use.

Risk: API searches may consume credits.

Mitigation: Check credit costs and limit or page requests to control usage.
