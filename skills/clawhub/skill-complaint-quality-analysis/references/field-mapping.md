# 客诉台账字段映射参考

## 标准字段映射表

| 中文名称 | 英文字段名 | 数据类型 | 是否必需 | 说明 |
|---------|-----------|---------|---------|------|
| 客户名称 | customer | 字符串 | 是 | 投诉客户的公司或个人名称 |
| 产品型号 | product | 字符串 | 是 | 涉及投诉的产品型号或编号 |
| 投诉日期 | date | 日期 | 是 | 客诉登记或发生的日期 |
| 问题类型 | issue_type | 字符串 | 是 | 投诉问题分类（如：质量缺陷、功能失效、外观不良等） |
| 异常描述 | description | 文本 | 否 | 详细的异常现象描述 |
| 处理状态 | status | 字符串 | 否 | 处理进度（如：待处理、处理中、已关闭） |
| 投诉来源 | source | 字符串 | 否 | 投诉渠道（电话/邮件/系统/现场） |
| 严重程度 | severity | 字符串 | 否 | 问题严重等级（一般/严重/紧急） |
| 响应时效 | response_time | 数值 | 否 | 从投诉登记到首次响应的时间（小时） |

## 数据校验规则

### 日期格式
- 支持格式：YYYY-MM-DD、YYYY/MM/DD、YYYYMMDD
- 异常处理：无法解析的日期会被标记为NaN，在分析时过滤

### 空值处理
- 必需字段（客户名称、产品型号、投诉日期、问题类型）空值超过20%时提示数据质量问题
- 可选字段空值不强制要求

### 重复数据
- 识别标准：同一客户 + 同一产品 + 同一日期 + 同一问题描述
- 提示重复数据数量，但不自动删除

### 异常值
- 日期范围：早于2000年或晚于当前日期+30天的数据会被标记为异常
- 负数值：数值字段出现负值时提示

## 字段关联分析要点

### 多工作表关联
- 如果Excel文件包含多个工作表，需要确认各表之间的关系
- 常见关联方式：通过"投诉单号"或"序列号"关联
- 如无法自动识别，需向用户确认

### 关联字段建议
- 如果存在多个工作表，建议检查以下关联字段：
  - 投诉单号/序列号
  - 客户编码
  - 产品编码
  - 时间范围重叠

## 使用建议

### 字段确认流程
1. 展示脚本识别到的所有字段列表
2. 对照标准字段映射表，询问不明确字段的具体含义
3. 确认关键字段的实际列名
4. 生成字段映射关系

### 数据质量提示
- 如果发现以下情况，需要向用户提示：
  - 必需字段缺失率高（>20%）
  - 日期格式异常（无法解析的日期超过10%）
  - 重复数据占比高（>5%）
  - 明显的异常值（如未来日期）

### 特殊情况处理
- 如果用户提供的是CSV文件，只有单一工作表
- 如果用户提供的是文本粘贴数据，需要先结构化处理
- 如果字段命名不规范，需要用户提供映射说明
