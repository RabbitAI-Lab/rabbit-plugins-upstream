# 六阶段详细操作规范

> 用途：律师使用本技能六个阶段时的SOP（标准操作流程）
> 配套使用：每个阶段配合对应的模板文件

## 阶段总览

| 阶段 | 核心问题 | 关键产出 | 关键模板 | 准入 |
|---|---|---|---|---|

| Phase 1 | 怎么告/怎么应？ | 请求权基础分析报告 | 02-请求权基础分析报告模板.md | 决定接案 |

## Phase 0 详细规范：案件初筛

### 目标
15-30分钟内判断"接/不接/有条件接"

### 输入
- 客户口头陈述
- 基础证据材料
- 客户身份信息

### 操作步骤
1. **5min**：客户背景与诉求确认
2. **5min**：案由识别（用排除法缩小范围）
3. **5min**：时效核查（关键）
4. **5min**：证据初评（核心证据是否在己方）
5. **5min**：利益冲突检索
6. **5min**：形成决策建议

### 输出
- 接案评估卡（完整填写）
- 决策：接 / 有条件接 / 不接

### 关键技巧
- 时效核查不容商量，先看时效
- 证据初评看"核心证据三性"：是否在我方、是否真实、是否充分
- 利益冲突必须先做，不可事后补救

## Phase 1 详细规范：诉请构建

### 目标
1-2小时内完成请求权基础和抗辩权基础的双向检索

### 输入
- 案件事实
- 合同文本
- 法律关系

### 操作步骤
1. **固定权利请求**（10min）：明确己方主张的核心权利
2. **检索请求权基础**（20min）：从合同法、民法典、建工解释中找支持法条
3. **识别抗辩权基础**（20min）：站在对方立场推演抗辩空间
4. **拆分构成要件**（20min）：对每一基础规范逐项拆要件
5. **分配举证责任**（10min）：按要件分类说分配
6. **识别请求权竞合**（10min）：评估是否需要选择性合并
7. **风险标注**（10min）：标注主张责任未履行风险、举证不能风险

### 输出
- 请求权基础分析报告（完整填写）
- 请求权/抗辩权基础规范清单（含条文号、要件、举证责任分配）

### 关键技巧
- 检索条文时同时检索"司法解释"和"指导案例"
- 不要忽略"备选请求权"——主请求权失守时备用
- 抗辩检索要做"魔鬼代言人"练习

## Phase 2 详细规范：攻防推演

### 目标
半天到1天完成九步法递进分析

### 输入
- Phase 1产出物
- 全部证据材料
- 案件事实

### 操作步骤（九步递进）
1. **固定权利请求**（30min）：从Phase 1带入并细化
2. **确定请求权基础**（30min）：从Phase 1带入并细化
3. **确定抗辩权基础**（30min）：从Phase 1带入并细化
4. **构成要件分析**（1-2h）：对每一基础规范详细拆要件
5. **诉讼主张检索**（1h）：穷尽己方所有主张
6. **争点整理**（1-2h）：核心环节，需反复推敲
7. **要件事实证明**（2-3h）：最耗时的环节
8. **事实认定**（1-2h）：预判证据三性
9. **要件归入裁判**（1h）：得出裁判走向预判

### 输出
- 九步法攻防全景图（完整填写）
- 关键攻击/防御节点识别
- 备选攻击/防御路径

### 关键技巧
- 每步独立成段，写清楚本步结论
- 第四步到第七步是核心，耗时最多
- 争点整理要区分"真假争点"——假争点不需要花时间

## Phase 3 详细规范：文书核验

### 目标
30min-1h完成起诉状/答辩状/代理词的八个一致审计

### 输入
- 文书初稿
- Phase 1、Phase 2产出物

### 操作步骤
1. **一致性①**：诉讼请求 vs 诉讼主张
2. **一致性②**：诉讼请求 vs 事实理由
3. **一致性③**：诉讼请求 vs 法律依据
4. **一致性④**：诉讼请求 vs 举证质证
5. **一致性⑤**：事实认定 vs 证据采信
6. **一致性⑥**：事实认定 vs 裁判说理
7. **一致性⑦**：裁判说理 vs 裁判主文
8. **一致性⑧**：裁判主文 vs 诉讼请求
9. **四个不固定诊断**：从根源找问题
10. **改进建议**

### 输出
- 八个一致核验清单
- 一致项数 / 8
- 关键风险列表
- 改进建议

### 关键技巧
- 八个一致是底线，缺一不可
- "四个不固定"诊断帮助找到根源
- 任何一个不一致都可能在二审/再审被抓住

## Phase 4 详细规范：庭审预演

### 目标
半天完成庭审预演手册

### 输入
- Phase 1-3全部产出
- 庭审通知（法官、对方律师信息）

### 操作步骤
1. **争点表整理**（30min）：与Phase 2第六步衔接
2. **证据三性预判**（1h）：对己方和对方证据逐项评估
3. **质证提纲**（1-2h）：按对方证据逐项准备
4. **法庭发问预演**（1-2h）：双向准备
5. **释明信号识别**（30min）：详见专门参考文件
6. **辩论提纲**（1-2h）：按争点分组
7. **风险预案**（1h）：列出所有可能突发情况

### 输出
- 庭审应对手册
- 风险预案

### 关键技巧
- 法官释明信号是关键情报
- 质证意见要具体到"为什么三性不成立"
- 风险预案要列出"如果……则……"

## Phase 5 详细规范：策略复盘

### 目标
1-2小时完成裁判预判

### 输入
- Phase 1-4全部产出
- 庭审情况（如已开庭）

### 操作步骤
1. **裁判结果三档分析**（30min）
2. **关键变量识别**（30min）
3. **敏感性分析**（30min）：乐观/基准/悲观三档
4. **备选方案设计**（1h）：Plan A/B/C
5. **调解空间评估**（15min）
6. **上诉/再审预案**（30min）
7. **执行预案**（15min）
8. **给客户最终建议**（15min）

### 输出
- 裁判预判与备选方案
- 给客户的决策建议

### 关键技巧
- 裁判预判要给出概率区间，不要给单一答案
- 备选方案要穷尽，避免"全押一注"
- 调解时机把握非常重要

## 跨阶段通用技巧

### 1. 文档管理
- 每阶段产出物独立成文
- 文件命名：阶段序号 + 模板名 + 案件简称
- 归档到统一案件文件夹

### 2. 复盘机制
- 每案结束后做"事后诸葛亮"分析
- 哪些预判准确、哪些失误
- 沉淀为方法论资产

### 3. 团队协作
- Phase 0可由初级律师完成
- Phase 1-2由主办律师主导
- Phase 3-5由主办律师审核

### 4. 时间管理
- 紧急案件：Phase 0-1优先，其他并行
- 重大案件：完整六阶段
- 简单案件：Phase 1+Phase 3+Phase 5

## 常见误区

- **跳过Phase 0**：直接进入分析，错过接案决策窗口
- **Phase 1只做请求权不做抗辩**：防御不足
- **Phase 2争点不分真假**：浪费时间在假争点上
- **Phase 3流于形式**：未真正审查一致性
- **Phase 4忽略法官视角**：错过释明信号
- **Phase 5只给单一方案**：缺少备选
