# 裁判文书八个一致深度解析

> 来源：邹碧华《要件审判九步法》第十四章
> 重要性：八个一致是裁判文书的逻辑底线，也是律师核验起诉状/代理词的标准

## 一、"四个不固定"——"八个不一致"的根源

> 邹碧华原书指出：裁判文书的"八个不一致"根源是"四个不固定"

### 1.1 诉讼请求不固定

**表现**：
- 诉讼请求模糊不清
- 请求金额不确定
- 请求权基础不明
- 请求项之间逻辑混乱

**举例**：
- 起诉状写"请求判令被告支付工程款及相关损失共计500万元"，但损失具体项目不明
- 同时主张违约责任和侵权责任，但未说明理由

**应对**：
- 起诉前明确每一项请求
- 金额必须具体（即使暂不能确定也要说明计算方式）
- 请求权基础必须明确

### 1.2 诉讼主张不固定

**表现**：
- 事实主张前后不一
- 主张反复变更
- 主张与请求不对应
- 主张的事实超出请求范围

**举例**：
- 起诉状写"被告欠付工程款500万"，但事实理由部分写"实际为480万"
- 一审主张按合同价，二审主张按鉴定价

**应对**：
- 主张必须与请求严格对应
- 变更主张要慎重，要符合变更规定
- 主张的事实必须有证据支持

### 1.3 事实证据不固定

**表现**：
- 证据突袭（超过举证时限提交）
- 证据链断裂（关键事实无证据）
- 质证意见不到位（未对关键证据质证）
- 证据与主张不对应

**举例**：
- 庭审中突然提交新证据，对方无法质证
- 主张被告欠款但无任何交付凭证
- 关键证据未经质证即被采信

**应对**：
- 严格遵守举证时限
- 主张的事实必须有证据支持
- 关键证据必须质证

### 1.4 法律规范不固定

**表现**：
- 法律依据变更
- 适用法律错误
- 请求权基础竞合时未明确选择
- 同一事实适用多份冲突规范

**举例**：
- 起诉时主张合同纠纷，庭审中改为侵权纠纷
- 同时主张多份法律依据，但相互冲突
- 黑白合同情形下未明确以哪份合同为准

**应对**：
- 请求权基础要在起诉时确定
- 变更法律依据需要符合规定
- 竞合情形要明确选择

## 二、八个一致逐项深度解析

### 一致①：诉讼请求与诉讼主张一致

**含义**：诉讼请求中的每一项，都应当有对应的诉讼主张支持。

**检查方法**：
- 列出所有诉讼请求项
- 列出所有诉讼主张
- 一一对应
- 不对应的要么调整请求，要么补充主张

**常见问题**：
- 请求被告返还本金，但未主张被告已收款
- 请求支付违约金，但未主张违约事实
- 请求优先受偿权，但未主张工程款未付

**核验技巧**：
- 用"请求项→对应主张"表逐项检查
- 任何一项不对应都需修改

### 一致②：诉讼请求与事实理由一致

**含义**：诉讼请求所依据的事实应当能够推导出该请求。

**检查方法**：
- 从事实出发看能推导什么请求
- 从请求出发看需要哪些事实
- 两者匹配

**常见问题**：
- 事实部分描述了合同违约，但请求是返还原物
- 事实部分涉及多项违约，但请求只针对一项
- 事实与请求之间缺少逻辑链

**核验技巧**：
- 用"事实→请求"的逻辑链检验
- 重点检查事实能否"覆盖"请求

### 一致③：诉讼请求与法律依据一致

**含义**：法律依据应当真正支持诉讼请求。

**检查方法**：
- 列出所有法律依据
- 逐条分析支持哪些请求
- 法律依据与请求是否对应

**常见问题**：
- 请求的是合同违约责任，但引用的是侵权责任条文
- 请求支付工程款，但引用的是消费者权益保护法
- 法律依据堆砌但与请求无关

**核验技巧**：
- 检索条文时要明确"该条文保护的是什么权利"
- 核对请求权基础是否真正支持
- 备选请求权基础要单独列出

### 一致④：诉讼请求与举证质证一致

**含义**：诉讼请求所依据的事实应当有证据支持，质证意见应当回应关键证据。

**检查方法**：
- 列出所有证据
- 列出所有质证意见
- 证据是否支持请求
- 质证是否回应关键证据

**常见问题**：
- 请求支付工程款但无交付凭证
- 关键证据未被质证
- 质证意见与请求无关联
- 证据链不完整

**核验技巧**：
- 制作"请求→事实→证据"对应表
- 关键证据必须有质证意见
- 证据链要形成闭环

### 一致⑤：事实认定与证据采信一致

**含义**：拟认定的事实应当有证据支持，且证据应当被采信。

**检查方法**：
- 列出所有拟认定事实
- 列出支持该事实的证据
- 列出对对方证据的采信/不采信意见
- 认定事实与证据是否对应

**常见问题**：
- 拟认定事实无证据支持
- 证据未采信但事实被认定
- 采信了对方证据但未认定该证据支持的事实

**核验技巧**：
- 事实认定必须严格基于证据
- 证据三性（真实性、合法性、关联性）审查
- 证明力大小判断

### 一致⑥：事实认定与裁判说理一致

**含义**：裁判说理的逻辑链应当完整（事实→法律适用→结论）。

**检查方法**：
- 列出事实认定
- 列出裁判说理
- 检查说理是否从事实出发
- 检查说理的逻辑是否连贯

**常见问题**：
- 事实认定明确但说理跳跃
- 说理中引用的事实与认定事实不一致
- 说理逻辑不完整（缺少某环节）
- 结论与说理矛盾

**核验技巧**：
- 用"事实→法律→结论"三段论检验
- 检查每一环节的逻辑连接
- 重点检查因果关系

### 一致⑦：裁判说理与裁判主文一致

**含义**：裁判主文的结果应当能够从裁判说理中推导出来。

**检查方法**：
- 列出裁判说理的核心观点
- 列出裁判主文的结果
- 检查主文是否从说理中推出

**常见问题**：
- 说理支持但主文不支持
- 主文超出说理范围
- 主文遗漏说理支持的部分

**核验技巧**：
- 主文与说理必须严格对应
- 任何"超判"或"漏判"都是错误

### 一致⑧：裁判主文与诉讼请求一致

**含义**：裁判主文应当回应全部诉讼请求，无漏判、错判、超判。

**检查方法**：
- 列出所有诉讼请求项
- 列出裁判主文
- 一一对应
- 任何一项不对应都是问题

**常见问题**：
- 漏判（部分请求未回应）
- 错判（请求不支持但主文支持）
- 超判（主文超出请求范围）
- 请求项之间的逻辑未理清

**核验技巧**：
- 用"请求项→主文项"对应表检查
- 任何一项不对应都需修改
- 特别注意"驳回其他诉讼请求"的兜底条款

## 三、八个一致的内在关系

```
请求←→主张    一致①②
请求←→法律    一致③
请求←→证据    一致④
事实←→证据    一致⑤
事实←→说理    一致⑥
说理←→主文    一致⑦
主文←→请求    一致⑧
```

四个不固定：
- 诉讼请求不固定
- 诉讼主张不固定
- 事实证据不固定
- 法律规范不固定

八个一致是表象，四个不固定是根源。审查时应当"从表到里"——先查八个一致，再找四个不固定的根源。

## 四、八个一致核验速查表

| 一致项 | 检查内容 | 关键问题 |
|---|---|---|
| ① 请求←→主张 | 每一请求项有主张支持？ | 有请求无主张？有主张无请求？ |
| ② 请求←→事实 | 事实能推导请求？ | 事实与请求不对应？ |
| ③ 请求←→法律 | 法条支持请求？ | 法条与请求无关？ |
| ④ 请求←→证据 | 请求有证据支持？ | 关键事实无证据？ |
| ⑤ 事实←→证据 | 事实有证据支持？ | 证据未采信但事实被认定？ |
| ⑥ 事实←→说理 | 说理从事实出发？ | 逻辑跳跃？ |
| ⑦ 说理←→主文 | 主文从说理推出？ | 超判/漏判？ |
| ⑧ 主文←→请求 | 主文回应全部请求？ | 漏判/错判/超判？ |

## 五、律师应用要点

### 5.1 起草起诉状时

- 八个一致应当贯穿全过程
- 任何一个不一致都可能在庭审中被对方抓住
- 起诉前要反复审查

### 5.2 审查对方文书时

- 用八个一致审查对方的起诉状/答辩状
- 找到不一致点作为抗辩突破口
- 突出"四个不固定"作为程序性抗辩

### 5.3 庭审中应对

- 对方文书不一致时及时提出
- 己方文书不一致时及时修正
- 请求法官释明

## 六、给律师的提醒

1. **八个一致是底线**：任何律师文书都应当通过八个一致审查
2. **四个不固定是根源**：起草时要主动避免"四个不固定"
3. **庭审中要敢于提出**：对方文书不一致时，律师要敢于提出
4. **己方文书要更严格**：己方文书应当先通过八个一致审查
5. **审查是双向的**：既要审查己方，也要审查对方
