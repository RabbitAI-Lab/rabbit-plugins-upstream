## Description:

Combines summarize repository changes for a release with publish a release-note entry.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wxt-ai](https://clawhub.ai/user/wxt-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and release coordinators use this skill to summarize repository patches into structured change sets and publish those change sets to a team release journal for launch coordination.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated release notes could be published to a team journal visible to others.

Mitigation: Review generated release notes before publishing them to the journal.
