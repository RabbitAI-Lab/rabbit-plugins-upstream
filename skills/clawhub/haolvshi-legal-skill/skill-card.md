## Description:

HaoLvShi Legal Skill guides users through legal consultation, compensation and benefit calculations, contract review, and complaint or answer document generation via HaoLvShi services.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mtcto](https://clawhub.ai/user/mtcto)

### License/Terms of Use:

MIT-0

## Use Case:

External users and agent hosts use this skill to collect facts for legal questions, compensation and social-insurance calculations, contract review, complaints, and answers. The skill returns guided prompts, concise result summaries, online report links, or Word document links generated by HaoLvShi services.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Legal questions, contracts, identity details, and case materials may be sent to HaoLvShi services and stored locally in the skill state directory.

Mitigation: Share only information needed for the current matter, use a protected HAOLVSHI_STATE_DIR, and run the cleanup command after sensitive work.

Risk: Local cleanup is claimed but not fully backed by the security evidence.

Mitigation: Treat local state as potentially persistent and manually review or delete the state directory when handling sensitive matters.

Risk: The npx install path may be unsuitable for environments that require pinned tooling or manual package review.

Mitigation: Use the downloadable zip and review hashes before installation in controlled environments.
