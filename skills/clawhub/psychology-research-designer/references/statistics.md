# 统计分析路线

## 先匹配数据，再选模型

| 数据与问题 | 常用起点 | 需要额外检查 |
|---|---|---|
| 两个连续变量 | Pearson/Spearman 相关、线性回归 | 关系形状、异常值、残差。 |
| 分类 X、连续 Y | t 检验、ANOVA 或回归 | 方差、组别不平衡、事后比较。 |
| 多个预测变量 | 多元/层次回归 | 理论入模顺序、共线性、过度控制。 |
| 二元 Y | Logistic 回归 | 事件数、线性 logit、分离。 |
| 计数 Y | Poisson 或负二项 | 过度离散、零膨胀。 |
| 中介或路径 | 回归路径、SEM | 时间顺序、M-Y 混杂、间接效应 CI。 |
| 调节 | 含交互项的回归/广义模型 | 简单斜率、量尺中心化、交互功效。 |
| 重复测量 | 混合模型或重复测量模型 | 个体内相关、时间编码、缺失。 |
| 嵌套数据 | 多层模型 | ICC、随机效应结构、群体数。 |
| 潜变量 | CFA/SEM | 测量模型、识别、模型拟合与等值。 |

## 通用分析顺序

1. 锁定/记录分析计划、导入与数据字典。
2. 检查范围、重复、缺失、异常值和数据结构；保留可追溯的处理记录。
3. 报告描述统计、分布和变量间关系。
4. 按研究目的评估测量质量。
5. 检验主要假设，报告估计值、效应量、置信区间和模型诊断。
6. 做预先定义或有明确理由的敏感性/稳健性分析，并区分探索性结果。

不要机械要求每个变量正态。说明有关的是哪一项假定：残差、链接函数、独立性、线性、同方差、多元正态或随机效应分布。需要时使用变换、稳健估计、非参数或合适的广义模型，并说明理由。
