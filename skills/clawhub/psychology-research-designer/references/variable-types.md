# 构念、变量与层级

## 四层区分

| 层次 | 要回答的问题 | 示例 |
|---|---|---|
| Construct（构念） | 理论上讨论的心理属性或过程是什么？ | 认知卸载。 |
| Variable（变量） | 数据中可变、可作为预测或结果的表示是什么？ | 认知卸载行为指数。 |
| Operationalization（操作化） | 如何把构念映射为观察指标？ | 外包给 AI 的解题步骤比例。 |
| Measurement（测量） | 使用什么任务、量表、观察、日志或编码？ | 任务日志加盲评编码。 |

不要因一个量表名称相似就认定它测量目标构念。先描述理论定义，再选择指标，并说明指标遗漏或混入了什么。

## 变量角色

- **Predictor / IV（X）**：先行因素、暴露或被操纵因素。
- **Outcome / DV（Y）**：待解释的结果。
- **Mediator（M）**：理论上位于 X 与 Y 之间的过程；须有合理时间顺序。
- **Moderator（W）**：改变路径强度或方向的边界条件，通常用交互项检验。
- **Confounder（C）**：在目标暴露之前、同时影响 X 与 Y 的共同原因。
- **Covariate（Z）**：为了精度或已说明理由而纳入的变量；不因方便而自动加入。

每个变量写：中文/英文名称、缩写、角色、理论定义、操作化、变量类型（连续/分类/计数/二元）、测量时间、数据来源及分析层级。

## 层级检查

先问“这个变量的变异主要发生在哪里？”：

| 现象 | 可能层级 | 常见错误 |
|---|---|---|
| 学生对班级气氛的感知 | 个体 | 将个人感知直接说成班级气氛。 |
| 班级共享的欺凌规范 | 班级 | 不检查组内一致性就聚合。 |
| 学生每天的压力 | 时间点嵌套个体 | 当作独立横断面记录。 |
| 团队领导风格 | 团队/组织 | 只在个体层解释团队效应。 |

当单位嵌套、重复或双人/网络互依时，先在设计里反映此结构，再选择统计模型。
