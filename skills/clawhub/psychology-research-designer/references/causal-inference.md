# 因果推断与结论边界

## 用设计限定语言

因果解释至少涉及：明确处理/暴露、时间顺序、可比的反事实、混杂处理、无严重选择偏差和可解释的测量。统计显著、控制很多变量或发现“中介”都不会自动满足这些条件。

| 设计 | 主要可支持的表述 |
|---|---|
| 一次横断面调查 | 关联、预测、理论一致的路径模式。 |
| 多波观察 | 时间顺序与后续关联；未测混杂仍可能存在。 |
| 随机实验 | 在操纵、随机化、依从与分析集定义下的处理效应。 |
| 准实验 | 在明确识别假设和诊断支持下的近似因果效应。 |

## 中介的额外条件

即使 X 被随机化，M 通常没有被随机化。若想把 X → M → Y 称为因果机制，仍需处理或论证 M-Y 的未测混杂、处理后混杂、时间顺序和测量误差。否则称为“间接效应模式”或“机制证据”，不要称为机制证明。

## 控制变量审查

对每个候选控制变量问：

1. 它是否在 X 之前发生？
2. 它是否可能同时影响 X 与 Y？
3. 它是否可能是中介、碰撞变量或处理后变量？
4. 不控制与控制时结论是否都应透明报告？

无法回答时，保守地不把它作为主要调整变量，并在限制中说明。
