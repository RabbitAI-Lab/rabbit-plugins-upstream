# 样本、抽样与统计功效

## 样本设计

明确目标人群、可及样本、招募渠道、纳入标准、排除标准与外推边界。排除标准应尽量在数据收集前确定，且不能根据结果变量事后设定。

| 情形 | 功效与样本量关键输入 |
|---|---|
| 均值比较/实验 | 目标效应量、组数、显著性水平、目标功效、分配比例、失访。 |
| 多元回归/交互 | 预测变量数、感兴趣的增量效应、共线性、交互通常较小且需要更多样本。 |
| 中介/路径模型 | 每条路径大小、间接效应分布、测量质量；宜使用 Monte Carlo 或仿真。 |
| CFA/SEM | 参数复杂度、载荷、残差、缺失与模型误设；不能用单一固定 N 规则代替。 |
| 多层模型 | 群体数、每群体人数、ICC、组间处理分配；群体数通常是关键。 |
| 纵向 | 每波留存率、波数、测量间隔、个体内效应与缺失机制。 |

不要机械写“N ≥ 200”。在无法获得可信先验时，说明正式研究前应使用 G*Power、仿真或 Monte Carlo 分析，并报告假定的最小有意义效应。为失访或无效数据预留样本，但不把预留当作对功效分析的替代。

## 缺失与失访

记录缺失的位置、比例、可能机制和与样本特征的关系。预先说明完全案例、最大似然或多重插补等方法的适用条件；纵向研究额外比较留存者与失访者。不要把“缺失很少”当成无需检查的理由。
