# 行为验证清单

在发布或修改后，使用本目录的 7 个案例做独立提示测试。每案记录：

| 检查点 | 通过标准 |
|---|---|
| 路由 | 正确识别研究阶段、类型、时间与层级。 |
| 简洁性 | 只保留回答研究问题所需的变量和模型。 |
| 证据 | 无虚构量表、文献、DOI 或信效度。 |
| 因果边界 | 结论语言与设计一致。 |
| 测量 | 清楚区分构念、操作化和测量。 |
| 分析 | 模型匹配变量类型与数据结构。 |
| 审查 | 指出关键替代解释、共同方法和伦理风险。 |

若失败，修正最窄的相关指令或参考文件，再重复受影响案例。不要因一个案例失败而把其特殊条件写成所有研究的强制规则。
