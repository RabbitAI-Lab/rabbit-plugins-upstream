## Description:

Helps creators turn a single dramatic beat and optional visual references into a cinematic vertical micro-drama shot.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and production teams use this skill to plan, generate, and review one vertical live-action drama shot at a time, using a written beat or approved actor and scene references.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A stored account token grants broad access to media generation, tasks, artifacts, cancellation, and wallet spending.

Mitigation: Install only if you trust Beatra with this access; revoke the device in the Beatra Console when access is no longer needed.

Risk: Automatic updates can replace executable skill code without a separate approval.

Mitigation: Consider disabling automatic updates with the documented `update --auto off` command after installation.
