## Description:

Encoding Toolkit helps agents encode, decode, hash, and identify common text formats including Base64, Base64URL, Base32, Hex, URL encoding, HTML entities, ROT13, Binary, and ASCII85.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and technical users use this skill to transform text between common encodings, decode received encoded strings, compute hashes for strings or files, and identify likely encoding formats.
