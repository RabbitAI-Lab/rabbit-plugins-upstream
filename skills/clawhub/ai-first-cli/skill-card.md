## Description:

This skill should be used when designing, building, or reviewing a command-line tool that AI agents will call, not just humans. Use it when deciding output format (JSON vs text), error handling, exit codes, flags, discoverability, dependencies and packaging, or autonomous-operation safety for a CLI. Also use it when asked how to make an existing CLI agent-friendly, or to evaluate a tool against the agent-first design philosophy. Grounded in Vercel's cloud-for-agents methodology.

This skill is ready for commercial/non-commercial use.

Developers use this skill to design or review command-line tools for agent use, including structured output, actionable errors, discoverability, packaging, and safeguards for autonomous operation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Agent-oriented CLI guidance could lead to unsafe noninteractive behavior or insufficient validation when applied to tools with side effects.

Mitigation: Preserve user authorization for destructive actions and use input validation and dry-run safeguards when adding noninteractive operation.
