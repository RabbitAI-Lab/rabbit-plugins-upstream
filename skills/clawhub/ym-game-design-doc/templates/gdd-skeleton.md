# 游戏策划案模板 (GDD Skeleton)

按以下顺序产出，每一节先读「填写说明」再填「示例」参考。示例基于原创小游戏概念「苔原牌局」（Tundra Hand）：一款 solo 向肉鸽卡牌游戏，玩家每局从随机卡池组一套流派，打通一片冰原地牢后死亡结算、跨局继承少量资源。

---

## 1. 电梯陈述

**填写说明：** 一句话说清三件事——玩家是谁、在做什么、爽点在哪。不要写世界观背景，不要写功能列表。这节是整份文档的锚，后面所有章节都要回扣它。

**示例（苔原牌局）：**
> 给喜欢动脑的卡牌玩家：每局从随机卡池组出一套新流派，打通一片冰原地牢，爽点在「这局又凑出了从没见过的 combo」。

---

## 2. 核心循环

**填写说明：** 必须能一句话说清「玩家每 1~3 分钟在做什么」。把动作画成文字环（箭头连接）。环里出现的动作 = MVP 必需；环外的动作 = 后期候选。写不出这句话，就回到第 1 节重想概念。

**示例（苔原牌局）：**
> 每 2 分钟：组牌 → 进地牢 → 战斗掉卡 → 强化卡组 → 死亡结算 → 组牌

文字环：
```
组牌 → 进入地牢 → 战斗掉落 → 强化卡组 → 死亡结算 ↺
```

---

## 3. 系统清单

**填写说明：** 逐个系统标注【MVP】或【后期】。判定规则只有一条——该系统是否在核心循环闭环里。MVP 合计必须能在给定产能内做完（见 `references/scope-control.md`）。标注【后期】的系统不要写进前 6 个月排期。

**示例（苔原牌局）：**

| 系统 | 标注 | 理由 |
|---|---|---|
| 卡组构筑 | MVP | 核心循环「组牌」必需 |
| 局内战斗 | MVP | 核心循环「战斗」必需 |
| 地牢程序生成 | MVP | 核心循环「进入地牢」必需 |
| 死亡跨局继承 | MVP | 核心循环「死亡结算」必需 |
| 卡牌稀有度/升级 | MVP | 核心循环「强化卡组」必需 |
| 剧情章节 | 后期 | 环外，首作用随机事件替代 |
| 联机对战 | 后期 | 环外，首作不做 |
| 模组编辑器 | 后期 | 环外，社区起量后做 |

---

## 4. 数值框架

**填写说明：** 只定框架不定死值。列出三样东西——成长维度（玩家沿哪几条线变强）、货币种类（几种钱、各自用途）、产出/消耗节点（资源从哪来、到哪去）。具体数值留给试玩调参，本表标注「数值待调」。

**示例（苔原牌局）：**

- 成长维度：角色等级（局内）、卡牌稀有度（跨局解锁）
- 货币种类：金币（局内消耗，买卡/复活）、寒铁（跨局货币，解锁卡池）
- 产出节点：战斗掉落金币、事件给寒铁、Boss 掉稀有卡
- 消耗节点：商店买卡（金币）、复活（金币）、卡池扩容（寒铁）
- 数值待调：攻击/血量基数、掉落率、寒铁产出曲线均在试玩迭代中定

---

## 5. 美术风格

**填写说明：** 给 2~3 个参考作品（说清借哪点），再给资产量估算——角色立绘、地图、特效各自的数量级。工时按 `references/scope-control.md` 资产基准折算，不写「风格简单」这类空话。

**示例（苔原牌局）：**

- 参考作品：杀戮尖塔（卡面信息密度）、月圆之夜（暗色奇幻氛围）、盗贼之海（冰原冷色调）
- 资产量估算：40 张卡面、10 个敌人立绘、3 张地牢底图、8 个特效
- 折算工时（solo）：卡面 40×6h=240h、立绘 10×12h=120h、底图 3×15h=45h，合计约 405h

---

## 6. 开发里程碑

**填写说明：** 把 MVP 系统按团队规模折算成周表。solo 每周有效开发约 15 小时；小团队按 人数×15h 再扣协作损耗（2-3 人扣 20%、5 人以上扣 35%）。每里程碑写「可玩判定」——到那周能不能跑出一段可玩内容。

**示例（苔原牌局，solo）：**

| 周 | 交付 | 可玩判定 |
|---|---|---|
| 1-4 | 核心战斗 + 组牌 | 能打一局、卡能出 |
| 5-9 | 地牢生成 + 掉落 | 有随机性、能重开 |
| 10-13 | 死亡继承 + 卡升级 | 跨局有积累 |
| 14-16 | 美术接入 + 平衡一轮 | 像能玩的游戏 |

MVP 总工时约 280h（系统）+ 405h（美术）≈ 685h，solo 折算约 45 周——超 6 个月，需把美术降到占位级（先灰模）压到约 400h，即约 27 周（不超 6 个月）。

---

## 7. 风险清单

**填写说明：** 每条风险配一个「砍法」。砍法的合格标准：砍掉该风险对应功能后，核心循环文字环仍然成立。砍法不成立 → 升级为「必须解决」并写应对。不要在风险表里留空砍法。

**示例（苔原牌局）：**

| 风险 | 砍法 | 砍后核心循环 |
|---|---|---|
| 内容量不足，玩家很快通关 | 砍到 3 章地牢 + 复用卡池 | 组牌→战斗→结算 仍成立 |
| 程序生成产出垃圾地牢 | 砍随机，改手工 12 张模板轮换 | 进入地牢 仍成立 |
| 美术延期拖垮排期 | 先灰模占位，上线后换皮 | 全部动作不依赖美术 |
| 平衡崩坏（某卡无敌） | 砍该卡出池，禁超 3 张同名 | 组牌仍成立，只是窄 |
