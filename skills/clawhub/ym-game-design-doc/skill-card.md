## Description:

Produces indie game design documents covering the core loop, MVP systems, numbers framework, art scope, development milestones, and concrete scope-cutting risks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[liuyuming0823](https://clawhub.ai/user/liuyuming0823)

### License/Terms of Use:

MIT-0

## Use Case:

External game creators and developers use this Chinese-language skill to turn an indie game concept, target platform, and team size into a scoped game design document. It is especially suited to defining an MVP, estimating milestone effort, and documenting risks with feature cutdown options.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad gameplay-design wording may trigger a full GDD-style response when the user only wanted lightweight brainstorming.

Mitigation: Ask whether the user wants brainstorming or a full GDD before applying the complete template.

Risk: Generated milestone estimates depend on user-provided platform and team-size assumptions.

Mitigation: State any defaults used, especially PC platform and solo 15 hours per week, and include capacity calculations for review.
