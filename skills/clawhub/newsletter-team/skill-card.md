## Description:

Researches, drafts, edits, and schedules newsletters using web and file tools across multiple channels with team role coordination.

This skill is ready for commercial/non-commercial use.

## Use Case:

Marketing, editorial, and developer teams use this agent configuration bundle to coordinate recurring newsletter research, drafting, review, and approval-gated scheduling across web, file, memory, and channel-planning workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Newsletter workflows may use web research, local files, and memory that include sensitive editorial plans or source material.

Mitigation: Confirm the intended file, memory, and research scope before installation and keep work limited to newsletter-related sources.

Risk: Externally visible newsletter scheduling or channel actions could publish or calendar incorrect activity.

Mitigation: Keep approval-gated scheduling enabled and require human approval before any newsletter distribution or calendar mutation.
