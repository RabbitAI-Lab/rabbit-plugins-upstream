# 经营异常判定表

本文件定义 15 条异常检测规则。每条规则给出：规则编号、检测条件、严重级、说明。硬闸脚本 `earnings_lint.py` 检查报告中是否包含对每条规则的判定结果（触发或未触发），不检查判定是否正确（那是分析者的职责）。

## 规则表

| 编号 | 规则名 | 检测条件 | 严重级 | 说明 |
|------|--------|----------|--------|------|
| A01 | 应收增速远超收入 | 应收账款同比增速 > 收入同比增速 × 1.5 | 高 | 放宽信用冲收入，收入质量存疑 |
| A02 | 存货积压 | 存货同比增速 > 收入同比增速 × 1.5 | 高 | 产品滞销，下期可能减值 |
| A03 | 纸面利润 | 经营现金流净额 < 净利润 × 0.3，连续2季 | 高 | 利润无现金支撑 |
| A04 | 毛利率大幅下降 | 毛利率同比下降 > 5个百分点 | 高 | 成本失控或产品降价 |
| A05 | 期间费用率大幅上升 | 期间费用率同比上升 > 5个百分点 | 高 | 费用失控或大额一次性支出 |
| A06 | 销售费用增但收入降 | 销售费用同比增 + 收入同比降 | 中 | 投入无效，获客效率恶化 |
| A07 | 研发费用率连续上升 | 研发费用率连续3季上升且无新产品/新业务产出 | 中 | 研发投入低效 |
| A08 | 财务费用率大幅上升 | 财务费用率同比上升 > 2个百分点 | 中 | 有息负债增加或汇率大幅波动 |
| A09 | 合同负债大幅下降 | 合同负债环比下降 > 20% | 中 | 下期收入可能承压 |
| A10 | 自由现金流持续为负 | 自由现金流连续3季为负 | 中 | 持续烧钱，需关注融资需求 |
| A11 | 非经常损益占比高 | 非经常性损益 / 净利润 > 30% | 中 | 盈利质量低，主业利润弱 |
| A12 | 资产负债率大幅上升 | 资产负债率同比上升 > 10个百分点 | 中 | 杠杆快速上升 |
| A13 | 商誉占净资产比高 | 商誉 / 净资产 > 30% | 低 | 存在减值风险，需持续关注 |
| A14 | 应收周转天数大幅增加 | 应收周转天数同比增加 > 30天 | 中 | 回款变慢，信用风险上升 |
| A15 | 存货周转天数大幅增加 | 存货周转天数同比增加 > 30天 | 中 | 周转变慢，积压风险 |

## 使用方法

1. 对每条规则，检查报告中是否有对应的判定（「触发」或「未触发」）。
2. 触发的规则，报告中必须写明：异常现象、数据依据（具体数字）、严重级。
3. 未触发的规则，报告中标注「未触发」即可（一句话）。
4. 如果材料缺少计算某条规则所需的数据，标注「数据不足，无法判定」。

## 严重级含义

| 严重级 | 含义 | 报告中的处理 |
|--------|------|-------------|
| 高 | 直接影响业绩质量判断，必须在核心结论中提及 | 单独段落 + 数据依据 + 原因分析 |
| 中 | 值得关注但不一定是问题，需结合趋势判断 | 列入异常清单 + 简要说明 |
| 低 | 长期风险提示，不影响本期判断 | 风险节提及即可 |

## 报告中异常节的写法

每条触发的异常按以下格式写：

```
### 异常 A01：应收增速远超收入
- 异常现象：应收账款同比增速 45%，收入同比增速 20%，应收增速为收入增速的 2.25 倍。
- 数据依据：应收账款 12.3 亿（上年同期 8.5 亿），收入 50.2 亿（上年同期 41.8 亿）。
- 严重级：高
- 可能原因：公司可能放宽信用政策以冲刺收入，或下游客户回款能力下降。
```

未触发的规则汇总写一句话：

```
以下规则未触发：A04、A05、A10、A11、A12、A13、A14、A15。
```

数据不足的规则汇总写：

```
以下规则因数据不足无法判定：A07（研发费用分季数据未给出）。
```
