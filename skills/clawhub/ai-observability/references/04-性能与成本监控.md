# 04 性能与成本监控

> 适用：AI 应用的响应效率与 Token 成本实时追踪
> 核对基准日：2026-08

## 1. 性能指标（AI 特有）

| 指标 | 口径 | 说明 |
|---|---|---|
| TTFT | 首 Token 延迟 | 用户感知"开始回答"的速度 |
| TPS | 每秒输出 Token 数 | 生成速度 |
| 端到端延迟 | 请求到完成 | P50/P95/P99 分布 |
| 超时率 | 超时调用占比 | 含模型 API 超时与自身超时 |
| 限流率 | 被供应商限流占比 | 配额/并发问题信号 |

## 2. 成本监控指标

| 指标 | 口径 |
|---|---|
| 单次成本 | 输入+输出 Token × 单价 |
| 日/月成本 | 汇总 + 环比趋势 |
| 分场景成本 | 按业务场景拆分 |
| 分模型成本 | 按模型拆分 |
| Token 结构 | 输入/输出占比、上下文复用率 |

## 3. 监控节奏

| 频率 | 动作 |
|---|---|
| 实时 | 延迟/错误率/限流（告警） |
| 每小时 | 成本聚合、Token 结构 |
| 每日 | 成本日报（分场景/模型） |
| 每周 | 性能与成本周报（趋势+异常） |

## 4. 告警阈值（经验值）

| 指标 | 预警 | 告警 |
|---|---|---|
| P95 延迟 | 超过 SLO 80% | 超过 SLO 100% |
| 错误率 | >1% | >3% |
| 限流率 | >1% | >5% |
| 日成本 | 预算 70% | 预算 90% |
| 单日成本突增 | >30% | >50% |

## 5. 常见误区
1. "只看平均延迟"——P95/P99 才能暴露尾部延迟问题
2. "成本月底看"——成本要实时/日报盯，月底发现就晚了
3. "性能问题全怪模型"——先查 Prompt 长度/上下文策略/缓存是否生效
