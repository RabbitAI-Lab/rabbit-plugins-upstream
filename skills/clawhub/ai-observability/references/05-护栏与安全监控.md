# 05 护栏与安全监控

> 适用：AI 应用安全防护的线上监控——护栏效果与攻击感知
> 核对基准日：2026-08

## 1. 监控对象

| 对象 | 监控内容 |
|---|---|
| 护栏命中 | 注入拦截率、敏感词拦截、内容审核命中 |
| 攻击感知 | 注入攻击尝试数、越狱尝试数、批量探测 |
| 数据泄漏 | 输出中个人信息泄漏、日志脱敏失效 |
| 越权行为 | Agent 越权调用、异常工具调用（衔接 Agent 治理） |
| 模型安全 | 有害内容输出率（衔接红队） |

## 2. 关键指标

| 指标 | 口径 | 告警建议 |
|---|---|---|
| 护栏命中率 | 命中护栏 / 总调用 | 命中率突降（护栏失效）→ 告警 |
| 注入检测数 | 疑似注入请求数 | 突增 >50% → 告警 |
| 越狱成功率 | 越狱成功 / 尝试 | >0 需严重告警 |
| 敏感泄漏数 | 输出含个人信息数 | >0 即告警（红线） |
| 有害输出率 | 有害输出 / 总输出 | 超阈值 → 严重告警 |

## 3. 响应流程

```
检测（护栏/检测器命中） → 分类（攻击/误伤/泄漏）
→ 处置（拦截/降级/下线） → 溯源（追踪到会话与版本）
→ 加固（护栏规则/检测器更新） → 复盘
```

## 4. 护栏有效性评估
- **误伤率**：护栏误拦截正常请求的比例（过高影响体验）
- **漏放率**：应拦截未拦截的比例（过高风险失控）
- 平衡：低风险场景宽松，高风险场景严格（医疗/金融从严）

## 5. 常见误区
1. "护栏命中率高就是安全"——命中率要看分母，攻击少时命中率意义有限
2. "只拦不测"——要定期用对抗样本测护栏（衔接红队 skill）
3. "泄漏监控是事后"——输出实时检测 + 日志脱敏双层防线
