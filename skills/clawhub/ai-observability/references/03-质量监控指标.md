# 03 质量监控指标

> 适用：AI 应用线上质量的实时看板——离线评测的运行时补位
> 核对基准日：2026-08

## 1. 为什么需要线上质量监控

离线评测（评测集回归）是"体检"，线上监控是"实时心电图"：
- 评测集是固定的，线上输入分布会变
- 问题在评测集发现时，用户已经受影响
- 线上监控能尽早发现漂移与异常

## 2. 核心质量指标

| 指标 | 口径 | 监控方式 |
|---|---|---|
| 幻觉率 | 含幻觉回答 / 总回答 | 自动检测（规则/评估器）+ 抽样复核 |
| 拒答率 | 拒绝回答 / 总回答 | 自动统计（分类拒绝原因） |
| 转人工率 | 转人工会话 / 总会话 | 业务系统联动 |
| 满意度 | 用户反馈评分 | 点赞/点踩、评分 |
| 质量评分 | 评估器打分（0-5） | 抽样评估器评分 |
| 超时/截断率 | 超时或输出截断 / 总调用 | 系统统计 |
| 报错率 | 调用失败 / 总调用 | 系统统计 |

## 3. 异常检测策略

### 3.1 阈值监控（基线对比）
- 核心指标环比/周环比下跌超阈值 → 告警
- 阈值示例：幻觉率 >3% 告警、>5% 严重

### 3.2 漂移检测（分布变化）
- 输入分布漂移（主题/长度/语言）
- 拒答率突升（可能护栏过严或 Prompt 问题）

### 3.3 抽样人工复核
- 自动检测覆盖不了的主观质量 → 抽样（≥5%）
- 复核结果回流校准自动检测器

## 4. 看板设计（建议布局）

```
顶部：健康总览（幻觉率/拒答率/满意度 三卡 + 状态灯）
中部：趋势图（24h/7d 各质量指标曲线）
下部：Top 异常（问题样本列表：输入/输出/判定/严重度）
侧栏：抽样复核队列（待人工复核样本）
```

## 5. 常见误区
1. "幻觉率实时精确统计"——自动检测有误差，需抽样校准，别迷信数字
2. "只看拒答率"——拒答率低可能是"乱答"而非"答得好"，要联动质量分
3. "监控数据存了就完"——数据要能回溯到具体会话和版本（衔接 02 追踪）
