# Геометрия и проверяемые данные

## Разметка кадра

Координаты в пикселях исходного изображения: x вправо, y вниз. `image_size` должна совпадать с размером файла. Границы — кусочно-линейные функции y(x), заданные видимыми якорями. Точки идут строго слева направо и покрывают весь `x_range`. Не продолжай линию за последнюю наблюдаемую точку. Если сетка искривлена, добавь якоря, пока линия наложения не совпадёт с ней.

`left` и `right` ячейки задают x(v), где v=0 на верхней границе строки, v=1 на нижней. Это позволяет учитывать наклон вертикальных линий. Для перспективы или движения камеры допускаются собственные `columns` у конкретной строки вместо общего набора. Каждая ячейка ограничена **той же парой** верхней и нижней границ, что и строка. Повторная независимая нарезка колонок горизонтальными полосами недопустима.

Ниже искусственный пример схемы; его координаты нельзя переносить на другие изображения.

```json
{
  "image_size": [1200, 400],
  "frame_id": "frame_0001",
  "source_video": "example.mp4",
  "time_seconds": 0.5,
  "x_range": [30, 1160],
  "boundaries": [
    {"id": "b0", "points": [[30,40],[600,62],[1160,88]]},
    {"id": "b1", "points": [[30,110],[600,132],[1160,158]]},
    {"id": "b2", "points": [[30,180],[600,202],[1160,228]]}
  ],
  "columns": [
    {"name":"time","left":[[0,30],[1,30]],"right":[[0,330],[1,330]],"psm":7},
    {"name":"message","left":[[0,330],[1,330]],"right":[[0,1160],[1,1160]],"psm":7}
  ],
  "rows": [
    {"id":"R001","top":"b0","bottom":"b1"},
    {"id":"R002","top":"b1","bottom":"b2"}
  ]
}
```

`--inset` у `split` убирает часть сетки сверху и снизу (по умолчанию 2 исходных пикселя). Столбцы задай внутри вертикальных линий, сохранив весь текст. Проверяй, что отступы не режут диакритику, цифры и нижние выносные элементы. Вырезки создаются билинейной интерполяцией без генерации новых деталей. Сильный поворот, неоднозначная сетка или границы, не представимые как y(x), требуют предварительного поворота с документированной связью с исходным кадром либо другого кадра. Полностью скрытый текст не восстанавливается.

## Файлы результата

- `frames/frames.json`: исходный видеофайл, SHA-256, метаданные FFprobe, запрошенное время и фактический PTS выбранного кадра на временной шкале декодирования. PTS не является временем события. Извлечение идёт от начала видео: надёжно для коротких роликов, но затратно для длинных.
- `overlay.png`: проверка границ на исходном изображении; голубые линии строк, жёлтые — столбцов.
- `rows/*.png`: выпрямленные строки; `cells/*.png`: ячейки из тех же исходных полос.
- `manifest.json`: размеры, координаты, строки и ячейки, ссылки и SHA-256 источника/вырезок. Храни исходный кадр вместе с результатом; путь к нему разрешается относительно файла манифеста, если не абсолютный. Не редактируй манифест после проверки без повторной проверки.
- `ledger.json`: черновик ручной расшифровки; `ocr-draft.json`: необязательный черновик OCR. Оба содержат ту же последовательность ID и полей, что и манифест.

Объект поля в реестре:

```json
{
  "ocr_text": "optional draft",
  "text": null,
  "status": "unreviewed",
  "reviewer": "",
  "note": ""
}
```

`verified`: непустой буквальный текст и имя/роль проверяющего. `blank`: визуально подтверждённое пустое поле, `text` равен пустой строке. `clipped` и `unreadable`: имя/роль, пояснение и видимая часть текста (либо null); эти поля остаются ограничением точности. Дополнительные ссылки на другие кадры записывай в `note` или собственное поле `evidence`, не заменяя первичный источник.

Имена файлов и ID создаваемых строк/полей должны содержать только ASCII-буквы, цифры, дефис и подчёркивание. Это ограничение относится к идентификаторам, а не к распознаваемому русскому тексту.

## Проверка принадлежности

Для каждой строки проведи взглядом верхнюю и нижнюю линии от времени через объект к сообщению. Убедись, что исходный ряд не потерян и не добавлен повторно. Затем проверь наложение, целую выпрямленную строку и отдельные ячейки. Хеш подтверждает неизменность файла после создания реестра, но не подлинность исходного журнала и не правильность разметки или прочтения.
