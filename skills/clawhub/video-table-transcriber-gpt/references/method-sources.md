# Методические источники

- Tesseract, ImproveQuality: https://tesseract-ocr.github.io/tessdoc/ImproveQuality.html — влияние перекоса, сегментация страницы и ограничения чтения таблиц без специальной разметки. PSM выбирается под уже выделенный блок/строку, а не для угадывания связей в таблице.
- OpenCV, Extract horizontal and vertical lines by using morphological operations: https://docs.opencv.org/4.x/dd/dd7/tutorial_morph_lines_detection.html — морфологическое выделение сетки можно использовать как подсказку для якорей. Это необязательное расширение; комплектный скрипт OpenCV не требует. При наклоне, изгибе и бликах результат нужно проверять визуально.
- FFmpeg documentation: https://ffmpeg.org/ffmpeg.html — извлечение кадров. Комплектный скрипт сохраняет фактический PTS из showinfo наряду с запрошенным временем.

Комплектный метод сочетает разметку реальных границ строк, геометрическую нарезку, чтение ячеек и сверку по нескольким кадрам. Эти источники не являются сертификатом точности данного навыка.
