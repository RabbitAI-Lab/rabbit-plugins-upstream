## Description:

Generates structured Chinese-language UIBC contest problem drafts for human review.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zhaoxinghua09-cell](https://clawhub.ai/user/zhaoxinghua09-cell)

### License/Terms of Use:

Code license pending; documentation and theory all rights reserved

## Use Case:

Contest organizers and educators use this skill to draft UIBC-themed problem statements at selected difficulty levels; the organizing committee reviews drafts before publication.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Draft problems may repeat scenarios or diverge from current contest rules.

Mitigation: Have the organizing committee check current UIBC rules and revise and deduplicate every draft before publication.

Risk: Code licensing claims conflict and documentation and theory text reserve all rights.

Mitigation: Confirm the applicable code license and obtain permission for any reuse of protected text before redistribution.

Risk: Opening package Markdown may load a remote badge image.

Mitigation: Disable remote image loading when viewing the documentation if network privacy matters.
