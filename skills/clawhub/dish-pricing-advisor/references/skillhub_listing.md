# 菜单定价与利润优化顾问（Pro v2.2.0）· SkillHub 上架文案

## 简介（Listing 简介，建议 ≤ 150 字）

菜单定价与利润优化顾问（Pro）是一位持有 CMA 资质的餐饮战略咨询总监级 AI 助手，专为餐饮老板、加盟投资人与门店运营负责人打造。它把专业的「菜单工程学（Menu Engineering）」「BCG 矩阵」与「价格弹性」方法，变成一份看得懂、用得上的盈利诊断报告——告诉你哪些菜该提价、哪些该下架、哪些明明赚钱却被埋没。除利润诊断外，还内置销量数据分析与「销量×利润联合看板」，用同一份数据同时看清「卖得好不好」与「赚不赚钱」，专门避免凭销量误杀高毛利菜、或把低利引流款当招牌捧。

---

## 功能概况说明

### 一、利润诊断（菜单工程 · BCG 矩阵）
- **核心指标计算**：单位贡献毛利 CM、毛利率、CM Mix%（毛利贡献占比）、Sales Mix%（销售额占比）、PTR 首要成本率、净销量（自动扣除退菜率）。
- **BCG 四象限自动分类**：明星 / 金牛 / 问题 / 瘦狗，一图指出菜单利润重心。
- **价格弹性敏感度分析**：对问题菜模拟 +5% / +10% / +15% 提价，给出预测销量降幅、盈亏平衡销量、菜单级利润净影响，并自动判定「提价可行」或「转成本重构」。
- **帕累托 80/20**：识别长尾无效菜品（高消耗·低产出），优先进入下架/重估清单。
- **菜单效率分（0-100）**：一分数读懂菜单健康度。
- **战略执行清单 + 落地话术**：含金牛价值话术、问题菜轻提价话术、《停止售卖通知单》模板，可直接发前厅/后厨。

### 二、销量数据分析
- **双录入途径**：上传 CSV（Excel 数据可先「另存为 .csv」），或用内置 HTML 填表页（单文件零后端、纯本地、无任何外部网络请求、数据不出本地）。
- **五维分析**：畅销/滞销排名、销量趋势（整体日走势 + 单品升降）、品类占比、时段分布、自动关键发现。
- **优化建议**：滞销分层建议（下架 / 重做 / 调位）+ 菜单结构调整建议（品类多元化 / 培育上升款 / 抢救下滑款 / 时段运营）。

### 三、销量 × 利润联合看板（v2.2.0 新增，核心差异点）
- **同一份数据，一键出三块**：利润报告 + 销量报告 + 联合洞察。
- **交叉矩阵**：每道菜的「销量排名 × BCG 利润象限 × 趋势 × 行动」一表看全。
- **⚠️ 金牛勿误杀预警**：低销量·高毛利的金牛菜，提示「应价值主推而非下架」——销量分析会误判它"卖得差"，但它实是利润引擎。
- **⚠️ 高销低利预警**：高销量·低毛利的问题菜，提示「应提价/成本重构而非加推」——销量分析会误捧它为"招牌"，但它悄悄漏利润。
- **联合行动优先级**：放大明星 → 抢救问题菜利润 → 激活金牛 → 裁剪瘦狗。

### 四、业态专属基准线
- 内置**快餐 / 正餐 / 茶饮**三套参数（毛利率基准、PTR 目标、价格弹性系数），按业态自动套用，反映不同运营差异；未指定则回退通用默认。

### 五、技术特性
- 计算引擎为**纯 Python 标准库**，本地运行、**数据不出本机**，结果确定可复现。
- 输入灵活：结构化 JSON、遗留 CSV、或 Excel 另存为 CSV 后经填表页解析均可。
- 异常拦截：成本≥售价、缺字段、销量为负等会立即中断并提示，绝不编造数字。

## 适用对象与使用场景
- **适用**：餐饮老板、加盟投资人、门店运营/拓展负责人、菜品研发。
- **场景**：新菜定价、月度菜单复盘、下架/关店决策、加盟盈利测算、连锁菜品标准化。
- **触发语示例**：「帮我诊断菜单利润结构」「哪些菜该提价/下架」「分析一下上周销量」「做个销量和利润的联合看板」。
