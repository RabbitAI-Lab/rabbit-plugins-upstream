## Description:

PartnerStack Partner (partnerstack.com). Use this skill for ANY PartnerStack Partner request — searching and reading data. Whenever a task involves PartnerStack Partner, use this skill instead of calling the API directly.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

Partner managers use the agent to retrieve marketplace program, partnership, payout, and reward data from their connected PartnerStack Partner account. It can also look up an individual marketplace program by company key.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Mitigation: Review the setup and use a pinned oo release; require approval before setup changes other agent skills.
