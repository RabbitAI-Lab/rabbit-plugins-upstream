## 找信息的方法（教给用户，比给答案更有用）

| 想找什么 | 去哪儿 |
|---|---|
| 校历、选课通知、转专业通知、学籍管理规定、教材征订、期末考试安排 | **教务处** https://jwc.qfnu.edu.cn → "重要通知" / "规章制度" |
| 推免办法、研究生招生 | **研究生处** https://yjs.qfnu.edu.cn |
| 奖助学金评选通知、资助政策、公寓管理、心理健康 | **学工处** https://xg.qfnu.edu.cn |
| 校园网、一卡通、统一身份认证、WebVPN | **网络信息中心** https://net.qfnu.edu.cn |
| 座位预约、馆藏、开馆时间 | **图书馆** https://lib.qfnu.edu.cn 与公众号 qfnulib |
| 招聘信息、宣讲会、签约手续 | **就业管理系统** https://jyqfnu.sdbys.com/ |
| 本学院的推免细则、转专业方案、奖学金细则 | **本学院官网**（各学院均有独立站点，域名形如 `xxx.qfnu.edu.cn`） |
| 历年分数、招生计划 | **本科招生网** https://zsb.qfnu.edu.cn |

> **提示**：学院层面的细则（推免、转专业、奖学金）每年都在变，且**只发在学院官网上**。学会自己盯学院网站，是大学里最值得养成的第一个习惯。
