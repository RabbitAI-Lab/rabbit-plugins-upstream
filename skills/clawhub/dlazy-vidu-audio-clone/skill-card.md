## Description:

Clones a voice from reference audio and generates speech reading new text through Vidu Audio Clone.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to produce spoken audio in a permitted reference voice from new text.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Cloned speech could impersonate someone without consent.

Mitigation: Use only voices you own or have clear permission to clone, and avoid deceptive impersonation.

Risk: Reference audio, prompts, generated speech, and credentials are sensitive when using a hosted service.

Mitigation: Install only if you trust the dLazy CLI and service; share only audio and text you are authorized to send.
