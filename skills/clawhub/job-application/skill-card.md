## Description:

Creates tailored job-application materials from structured profile and job data, including a focused CV, cover letter, plain-text application, and optional local PDF rendering.

This skill is ready for commercial/non-commercial use.

## Publisher:

[clawjames1](https://clawhub.ai/user/clawjames1)

### License/Terms of Use:

MIT-0

## Use Case:

Job seekers use the skill to draft truthful, role-specific CVs, cover letters, and plain-text applications from structured profile and job data. PDF rendering is optional; sending an application requires separate authorization.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Personal profile information and generated applications may contain sensitive data.

Mitigation: Keep real profiles and outputs outside the installed skill directory in private locations.

Risk: Unvalidated PDFs or untrusted application files may produce incorrect or unsafe output.

Mitigation: Keep validation enabled for real applications and render PDFs only from application folders you created or trust.

Risk: An application could be sent without the job seeker's approval.

Mitigation: Obtain explicit authorization for the specific destination before submitting or sharing application documents.
