## Description:

This skill runs a local free checker for software outsourcing milestone acceptance and payment tables, recalculating row totals, aggregate totals, duplicates, blanks, and negative amounts with source-cited findings.

This skill is ready for commercial/non-commercial use.

## Use Case:

Finance, cashier, project accounting, and operations users can use the skill during monthly settlement or payment review to check software outsourcing milestone acceptance and payment records before continuing payment workflows. The free package performs local deterministic checks and reports missing material instead of producing unsupported conclusions.
