# 花材档案

价格为一线城市花市零售参考区间（元），单位按「枝」或「扎」（1 扎 ≈ 5–10 枝，视品种）。
**所有价格随季节、产地、地区波动 30–50%，输出时必须标注「以当地为准」。**

## 常见替换关系

替换三原则：**同角色、同色系、体量接近**。体量差超过 30% 时要同步调整枝数。

| 缺货 | 可换 | 价差 | 说明 |
|---|---|---|---|
| 洋桔梗 | 香雪兰 | 持平 | 形态更柔，枝数可不变 |
| 洋桔梗 | 康乃馨 | -2/枝 | 花瓣较硬，观感略逊 |
| 白玫瑰 | 白洋牡丹 | -14/枝 | 体量更小，需增 1–2 枝 |
| 玫瑰 | 洋桔梗 | -3/枝 | 需增 1–2 枝补体量 |
| 芍药 | 洋牡丹 | -10/枝 | 体量接近，最接近的替代 |
| 郁金香 | 马蹄莲 | +4/枝 | 都属线条型，观感差异大 |
| 尤加利 | 银叶菊 | +6/扎 | 色更灰，适合冷调 |
| 尤加利 | 雪柳 | +8/扎 | 线条更硬，风格更东方 |
| 满天星 | 蕾丝花 | +8/扎 | 更高级，用量减半 |
| 绣球 | 康乃馨（大朵） | -20/枝 | 体量差大，需 3–4 枝替代 1 枝 |

## 使用方式

1. 先按角色筛出候选花材
2. 按季节过滤（当季优先）
3. 按禁忌排除（宠物 / 过敏 / 场合）
4. 按预算选具体品种和枝数
5. 为每种花材至少配一个替代项
