# 配方转图像描述

图像的作用是**帮助用户预判做出来的样子**，不是做一张海报。

因此图像描述必须被配方锁死：花材种类、数量、疏密、配色、器型，全部来自配方，不允许自由发挥。

## 受限模板

按固定顺序填写，空缺的槽位就删掉，不要补形容词。

```
[构图] 一束[风格]风格的花，插在[器型]中，[视角]，[背景]
[主花] [数量] 枝[主花名]，[颜色]，[状态]，[位置关系]
[配花] [数量] 枝[配花名]，[颜色]，分布在[位置]
[叶材] [数量] 扎[叶材名]，朝[方向]外扩，形成[轮廓描述]
[点缀] 少量[点缀名]，仅[数量]处
[质感] [光线]，[背景材质]，[真实感要求]
[禁止] 不要出现配方之外的花材；不要改变枝数；不要加文字和装饰
```

## 示例

配方：洋桔梗 7、白玫瑰 5、小雏菊 6、尤加利 2 扎、满天星 4，圆形玻璃瓶 18cm，粉白，自然野趣。

```
一束自然野趣风格的瓶插花，插在透明圆形玻璃瓶中，正面平视，深色木质桌面背景。

主花：7 枝粉色洋桔梗，花瓣半开，高低错落分布在中心偏左上；5 枝白色玫瑰，开至半放，集中在右侧，其中一枝略高。
配花：6 枝白色小雏菊，成 3 簇分布在空隙处，不散布。
叶材：2 扎尤加利叶，向左右斜外延伸，轮廓宽度约为瓶口的 1.7 倍，有自然的松散空隙。
点缀：4 处白色满天星，仅出现在边缘。

质感：单侧柔和顶光，玻璃瓶透出水的厚度，花瓣有细微绒感，写实摄影风格，浅景深。
禁止：不要出现配方之外的花材；不要增加枝数；不要添加文字、丝带或装饰物。
```

## 关键控制点

**1. 用数量词，不用程度词**

| 不要写 | 要写 |
|---|---|
| 很多花 | 7 枝 |
| 点缀一些 | 4 处 |
| 丰满 | 冠幅约为瓶口的 1.7 倍 |
| 自然一些 | 高低错落，留有 2–3 处空隙 |

**2. 疏密必须与枝数对应**

枝数少却描述成「丰满茂密」，图就会比实际能做出来的好看，用户做完会失望。这是最伤信任的失真。

**3. 器型必须写形状和高度**

只写「花瓶」会得到完全不同的比例。要写「透明圆形玻璃瓶，高 18cm，口径 9cm」。

**4. 视角固定为正面平视**

俯拍和侧拍都会掩盖比例问题。正面平视最接近用户站在桌前的真实观感。

**5. 禁止项必须有**

不写禁止项，模型会自动加丝带、卡片、花瓶纹样、背景装饰，这些都不在清单里，用户买不到。

## 一致性检查

出图后对照配方逐条核对：

- [ ] 数得出来的花材种类 = 配方种类数
- [ ] 主花数量目测在配方数量 ±1 范围内
- [ ] 叶材有明显外扩轮廓（不是紧贴花球）
- [ ] 器型与配方一致
- [ ] 画面里没有任何配方之外的元素

任一条不符，改配方描述里的槽位后重出，不要在文案里解释「图片仅供参考」。那句话等于承认产品不可信。

## 多方案时

同一需求出三套方案时，让三套在**结构维度**上区分，而不是只换颜色：

| 方案 | 区分维度 | 例 |
|---|---|---|
| A | 风格最贴近用户描述 | 自然野趣，松散 |
| B | 预算更省 / 更易做 | 三种花材的极简版 |
| C | 体量或气质更进阶 | 加入线条花材，更正式 |

只换颜色会让用户觉得是同一个方案抽了三次卡。
