# 硬约束规则

这些规则的作用是让配方「合法」。任何一条不通过，都必须回退重算，不能靠文案圆过去。

## 一、预算分配

给定花材预算 `B`，按以下比例拆分（经验值，允许 ±5% 浮动）：

| 角色 | 占比 | 说明 |
|---|---|---|
| 主花 | 45–55% | 低于 45% 会显得单薄，高于 55% 就没钱买叶材 |
| 配花 | 20–25% | 用来填缝和过渡 |
| 叶材 | 12–18% | 决定轮廓，不能省 |
| 点缀 | 5–8% | 满天星、勿忘我这类，超了显廉价 |
| 辅材 | 5–8% | 花泥、铁丝、包装纸 |

**花器单独计价**，不占花材预算，通常占总支出 20–25%。报总价时必须写清「含/不含花器」。

### 快速验算

预算 ¥200 时的合理构成：
- 主花 ¥90–110
- 配花 ¥40–50
- 叶材 ¥24–36
- 点缀 ¥10–16
- 辅材 ¥10–16
- 花器 ¥40–50（另计）

合计约 ¥174–228。落在区间外就重算。

## 二、尺寸与枝数

### 由花器推成品尺寸

- 成品冠幅 ≈ 瓶口直径 × **1.5–1.8**
- 成品总高 ≈ 瓶身高度 × **1.6–2.0**

例：瓶口 9cm、瓶高 18cm → 冠幅 14–16cm（单边），总高 29–36cm。

### 由冠幅推主花枝数

| 成品冠幅 | 主花枝数 | 适用场景 |
|---|---|---|
| < 25cm | 3–5 | 办公桌、床头 |
| 25–40cm | 5–9 | 餐桌、玄关 |
| > 40cm | 9–15 | 落地、活动布置 |

### 角色枝数配比

**主花 : 配花 : 叶材 ≈ 1 : 0.8 : 1.2**

叶材的枝数要比主花多，这是新手最容易搞反的地方。叶材不够，做出来就是一个球，没有外扩的轮廓。

### 主花排布密度

相邻主花间距 ≈ 一个花头直径。排成一圈等距是最常见的新手错误，会显得机械。

## 三、色彩

### 色相数量

**不超过 3 个色相。** 第 4 个色相必然让画面失控。

### 比例

**60 / 30 / 10**：主色 60%、辅色 30%、点缀 10%。

### 安全策略

| 策略 | 适合谁 | 做法 |
|---|---|---|
| 同色系深浅过渡 | 新手、不确定时 | 同一色相取 3 个明度，最稳、最不容易翻车 |
| 邻近色 | 有经验者 | 色环相邻 30–60 度 |
| 对比色 | 仅点缀 | 对比色面积不超过 10%，超过就俗 |

### 常见配色组合

- 粉白：洋桔梗 + 白玫瑰 + 尤加利（最安全）
- 奶油米黄：洋牡丹 + 香雪兰 + 银叶菊
- 秋日：大丽花 + 菊花 + 南天竹
- 东方：白菊 + 松枝 + 枯枝（克制，枝材为主）

## 四、硬性禁忌

### 宠物家庭（猫狗）

**必须排除**：
- 百合 —— 对猫剧毒，花粉、叶片、花瓶水全部有毒，舔一口就可能急性肾衰
- 杜鹃、绣球、郁金香、绿萝、龟背竹、万年青

**相对安全**：玫瑰、洋桔梗、向日葵、康乃馨、小雏菊、洋牡丹

### 花粉过敏

**排除**：百合、向日葵、菊花类、紫罗兰
**可选**：重瓣品种（花粉退化）、洋桔梗、郁金香、玫瑰（去雄蕊）

### 场合禁忌

| 场合 | 禁忌 | 原因 |
|---|---|---|
| 探病 | 白菊、黄菊、浓香花 | 花语与气味都不合适 |
| 送恋人 | 黄玫瑰、菊花 | 部分文化里代表分离或悼念 |
| 商务 | 过于随意的小碎花 | 缺体量感 |
| 卧室 | 百合、夜来香等浓香 | 影响睡眠 |
| 佛堂/祭祀 | 鲜艳喜庆色 | 场合不符 |

### 气味强度

浓香花材（百合、夜来香、风信子、栀子）**一个方案里最多一种**，且不放在餐桌或卧室。

## 五、季节适配

按当前季节优先选当季花材。当季花材价格低 30–50%，状态也更好。

反季花材不是不能用，但必须在输出里标明「反季，价格偏高且花期偏短」。

## 六、可执行性

配方要能被一个没插过花的人做出来。判断标准：

- 步骤 ≤ 8 步
- 不需要特殊工具（花泥刀、剑山除外，需在清单里列出）
- 不需要「感觉」类判断（如「插到好看为止」）
- 每一步都有可验证的结果

超过这个范围，降低规格（缩小尺寸、减少花材种类），而不是增加说明文字。
