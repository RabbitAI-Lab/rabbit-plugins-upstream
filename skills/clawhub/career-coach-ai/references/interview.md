# 模拟面试手册

按需加载。用于「有面试 / 想练表达 / 怕被问倒」。

## 流程
1. 确认岗位与面试类型（行为 / 技术 / 压力）。
2. 出 3~5 道针对性题目，逐题模拟（用户答，你扮演面试官追问）。
3. 每题给反馈：表达结构、内容深度、加分点与扣分项。
4. 收尾输出：高频致命问题清单 + 标准回答框架 + 反问面试官话术。

## 行为面试题库（STAR 作答）
- 讲一个你最有成就感的项目。
- 说一次你搞砸 / 失败的事，怎么补救？
- 和同事 / 老板冲突怎么处理的？
- 你最大的缺点是什么？（答「真实短板 + 在改的动作」，别答「太完美主义」）
- 为什么离开上一家 / 为什么选我们？
- 压力最大的一次，怎么扛过来的？

## 技术 / 专业题（按岗位给 2~3 道）
- 产品：如何衡量一个功能是否成功？
- 技术：讲讲你做过最复杂的系统设计 / 最深的一个 bug。
- 运营：给你一个 0 粉新号，怎么起量？
- 数据：这个指标掉了 20% 你怎么排查？

## 压力测试题
- 「你简历这块经历很水，凭什么胜任？」
- 「如果今天就要你定方案，资料不全怎么办？」
> 应对原则：不慌、先确认边界、给框架再填内容、承认未知但给学习路径。

## 每题反馈评分 rubric
- **结构**（0~5）：有没有 STAR / 结论先行。
- **深度**（0~5）：有没有量化、有没有思考过程。
- **加分点**：哪个动作亮眼。
- **扣分项**：哪句暴露短板 / 跑题 / 贬低前东家。
> 给反馈先肯定 1 条，再给 1 个最该改的点，别一次列 10 条。

## 反问面试官话术（收尾用）
- 「这个岗位未来半年最关键的指标是什么？」
- 「团队目前最大的挑战是哪块？」
- 「您觉得做好这个岗位，最容易被忽视的能力是什么？」
> 避免一上来问薪资休假；把薪资问题留到 HR / 终面。

## 高频致命问题清单
- 表达无结构、流水账。
- 只说团队成果，看不出「我」做了啥。
- 贬低前公司 / 前老板。
- 对「为什么是我们」答不上来。
- 缺点答成优点、显得不真诚。
