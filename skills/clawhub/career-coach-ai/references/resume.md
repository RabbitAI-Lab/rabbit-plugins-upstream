# 简历优化手册

按需加载。用于「改简历 / 投了没回音 / 想跳槽」。

## 1. 三大常见痛点（诊断时先点出）
1. **空话**：「负责相关工作」「具备良好沟通能力」——无证据。
2. **无量化**：只有职责没有结果，看不出价值。
3. **不匹配**：没对齐目标岗位 JD 的关键词与要求。

## 2. STAR 重写法
- **S Situation 情境**：背景（项目 / 业务 / 规模）。
- **T Task 任务**：你的目标或要解决的问题。
- **A Action 行动**：你具体做了什么（突出「我」的动作，非团队）。
- **R Result 结果**：量化结果（增长 X% / 省 Y 元 / 提前 Z 天 / 满意度 +N）。
> 写法：动词开头 + 量化结果。「主导 XX 项目，将转化率从 3% 提升至 7%（+133%），覆盖 12 万用户。」

## 3. ATS 友好清单
- 用标准 section 标题：工作经历 / 项目经历 / 教育 / 技能。
- 关键词对齐 JD（岗位写「数据分析」，简历别只写「处理数据」）。
- 避免表格 / 图片 / 花哨排版 / 两栏；用纯文本可解析。
- 文件名用「姓名-岗位-年限.pdf」，别用「简历 final 最终版.pdf」。

## 4. 前后对比样例
- ❌ 前：「负责用户增长，做了很多活动，效果还不错。」
- ✅ 后：「设计并落地 3 场裂变活动（S），目标拉新 1 万（T）；搭建渠道分层 SOP（A）；新增注册 2.3 万、单获客成本下降 41%（R）。」

## 5. 可套用模块模板
```
【工作经历】公司名 | 岗位 | 起止
- 背景：一句话业务/规模
- 动作：用 STAR 写 2~3 条，动词开头
- 结果：每条配量化指标
【项目经历】项目名 | 角色
- 问题/目标 → 你的动作 → 量化结果
【技能】按岗位 JD 对齐，分「精通/熟练/了解」
```
> 交付时给「改写前后对比」+ 让用户套模板补自己的数据；不替用户编造数字。
