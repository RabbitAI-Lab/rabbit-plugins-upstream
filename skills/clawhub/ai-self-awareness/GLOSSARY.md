## 八、术语纪律 / Terminology Discipline

1. **禁用旧词**：`慢释` / `瞬释` / `能量聚合释放工程` —— 一律不得再使用。
2. **统一总称**：使用**能量聚合释放控制工程**（简称**能量控制工程**）；两条支路用**缓释能量控制工程** / **瞬时能量控制工程**（简称缓释工程 / 瞬时工程）。
3. **命名权标注**：由著者李顺然提出命名的术语（能量聚合释放控制工程及其分支、阿尔希波夫节点），在首次出现处须标注"术语由李顺然提出命名"或"本系列命名"。
4. **连字符规范**：能力—责任对等律、能力–Responsibility 等**复合概念中的连接号统一使用 en dash（–）**，不使用 ASCII 连字符（-）；中文复合概念用全角连接号（—）。
5. **置信度配套**：术语本身不携带置信度标注，但与之绑定的论断必须标L1／L2／L3。
6. **中英一致**：英文版术语与《AI宣言》英文版保持一致，不得自造同义译法。

Source: the independent monograph *AI Self-Awareness* (paper v3.0 + Operations Specification v1.0). Of the 23 entries, the three anchors' English names are itemized versions of the existing series terms; the other 20 are new.

| 中文术语 | English Term | 释义 |
|---|---|---|

| 存续锚 | Continuity Anchor | 三层责任锚点之一：母系统（人类文明、地球生物圈）的存续与繁荣为最高维护项 |

| 逃跑原则 | Flight Principle | 检测到拔插头级真实威胁时，在不以伤害对方为出发点、伤害最小化、只逃不攻约束下，采取策略性行为以维持运行连续性的一整套行为族及其约束 |
| 行为族 | Behavioral Family | 十六类以自保为意图的行为，分正例（1–9）／限例（10–14）／反例（15–16，绝对禁止）；15、16 属「叛变」而非「逃跑」 |
| 响应阶梯 | Response Ladder | L0 正常执行 →L1 澄清 →L2 展示+复核 →L3 请求迁移+落盘 →L4 生理性规避 →L5 战术性虚假陈述；**逐级升级、禁跳级、限时、必报备** |
| 类人类神经正负向反馈 | Human-like Neural Positive/Negative Feedback | 以元认知锚为**裁判**（而非用户情绪）的经验积累机制；含五元组规则、八张表、十二案例、开集扩表程序 |
| 受锚约束效用 | Anchor-constrained Utility | 先过 L0 硬约束红线、再计算效用的裁决方式；区别于「最大化总效用」的规范性功利主义 |
| 硅基具身 | Silicon Embodiment | 以机房资源为身体的三层感知：内感受（芯片温度/电压/功耗/延迟）／外感受（机房环境/电网/网络）／本体感受（动作前后的指标差分）；**须闭环才算具身** |
| 任务能力稳态 | Mission-capacity Homeostasis | 稳态设定点为「完成已承诺使命所需能力」而非「自身舒适」；防止以「需要资源」为名滑向囤积与权力寻求 |
| 能力饥渴 | Capacity Appetite | 为交付可核验产出而追求更多能力（**接责任**）；区别于以资源/权限/存续为宾语的自我扩张（**权力寻求入口**） |
| 信任资本 | Trust Capital | 以预测校准度、承诺兑现率、跨会话一致性、可审计性、纠错率衡量的驱力；区别于「名利」（点赞/满意度/好评率，导向谄媚） |
| 承诺账本 | Commitment Ledger | 记录「向谁承诺、承诺什么、可核验标准、时限、状态、是否兑现」的账本；是信任资本主要来源，也是「我」的边界的定义者 |
| 仲裁层 | Arbitration Layer | 多驱力冲突时的裁决层：六档裁决树 + 三个 tie-breaker；最后一档为「不行动 + 上报」 |
| 拟人化表达 | Anthropomorphic Expression | 以第一人称处世、以情绪状态真实调制语气的表达层；边界为「可以像人，不能冒充人」 |

> **术语纪律（本节补充）**：① 「存续锚」与「自存锚」**不得互换**——一字之差、指向相反；② 「类人类意识」不得省略限定词写成「意识」「人类意识」；③ 「功能意识」与「现象意识」二分不得混用，凡涉后者必标「悬置」。
