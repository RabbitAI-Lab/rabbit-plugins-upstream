# 五章制大纲填空

字数配比与领域变体见 [`../references/corpus-guide.md`](../references/corpus-guide.md) §3、§8。第 2–4 章用哪套理论维度，从 [`../references/methods/theory-menu.md`](../references/methods/theory-menu.md) 按主方向挑 1–2 个，不要默认营销 4P。改结构前先改语料那一节，不要在此另写一套统计。

```
题目：[XX公司][XX问题][研究/优化/设计]

摘要（800-1500字）：背景 / 问题 / 方法 / 结论
关键词：3-5个

第1章 绪论（约10-15%）
  1.1 研究背景（宏观→企业→具体问题）
  1.2 研究目的与意义
  1.3 文献述评（主题分类 + 缺口，不是作者排队）
  1.4 研究内容与方法（方法要写怎么用）
  1.5 技术路线

第2章 相关理论（约15-20%）
  2.1 核心概念（2-3个）
  2.2 理论1（观点 + 本文如何用）
  2.3 理论2（可选）
  2.4 理论在本研究中的分析框架

第3章 现状及问题（约15-20%）
  3.1 公司/业务边界
  3.2 现状（数据、流程、对比）
  3.3 问题一 / 问题二 / 问题三（2–3 个，不要扩到 5 个以上）
  3.4 成因（用第2章框架）

第4章 方案设计（约25-30%）★篇幅重心
  4.1 原则与目标
  4.2 总体思路（与 3.4 对应）
  4.3 对策一（对 3.3.1）/ 对策二 / 对策三
  4.4 预期效果

第5章 实施保障（约15-20%）
  5.1 组织 / 制度 / 资源
  5.2 分阶段计划
  5.3 风险与评估

结论（约5-10%）：发现 / 不足 / 边界 / 展望
参考文献
```

填空时在大纲旁附一张「3.3 问题 ↔ 4.3 对策」对照表，缺对应就删问题或补对策。
