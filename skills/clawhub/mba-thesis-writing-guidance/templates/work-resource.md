# 工作资源盘点

选题不是从外面捡一个「高级题」，是从你每天的现场盘出来的。由 Agent 用提问填写并保存到论文项目根目录，不必让用户打开本模板手填。每类至少三条。

## 五类入口

| 类别 | 你现在能写下来的 |
|---|---|
| 人（能访谈或观察的同事、上级、客户、供应商） |  |
| 流程（审批、交付、排班、客诉、报销……卡在哪） |  |
| 记录（纪要、台账、复盘、绩效、培训记录；是否有权使用） |  |
| 客户（沟通、评价、回访、流失；能否脱敏） |  |
| 反复看到却没人解释的现象 |  |

## 三步转成候选问题

1. 挑一个具体现象（不要写「客户服务」，要写「售后工单响应比去年明显变慢」）
2. 补对象和情境（谁、哪个组织边界、哪段时间）
3. 用「为什么」或「如何」写成疑问句
