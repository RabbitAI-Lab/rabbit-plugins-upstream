# 选题可行性自检清单

没方向先盘 [`../templates/work-resource.md`](../templates/work-resource.md)；一句话版本填 [`../templates/topic-statement.md`](../templates/topic-statement.md)。闸门与三级收窄见 [`../workflows/01-topic.md`](../workflows/01-topic.md)。

## 先说结论

题目不是越大越好。一个可推进的题目，至少要同时满足：有真实问题、范围可控、资料可得、方法匹配、时间够用。

请用下面的项目检查一个暂定题目。每一项都可标为“已确认 / 尚未确认 / 不适用”；“尚未确认”就是下一步要补的地方。

## 一、真实问题

- [ ] 我能用一句话说明这个研究对象正在面对什么管理问题。
- [ ] 这个问题能在实际组织、行业或工作场景中观察到。
- [ ] 我知道这个问题会影响谁，例如员工、客户、团队或管理者。

## 二、范围是否可控

- [ ] 题目写清楚了研究对象，而不是泛称“企业”或“消费者”。
- [ ] 题目限定了一个主要场景、行业或组织类型。
- [ ] 题目没有同时研究太多对象、因素和结果。
- [ ] 我能说明资料覆盖的时间范围。

## 三、资料能否取得

- [ ] 我知道可能的资料来源：问卷、访谈、公开材料、工作记录或案例资料。
- [ ] 我能接触到足以支撑研究的样本或信息。
- [ ] 资料获取不依赖无法确认的授权。
- [ ] 我知道如何匿名或去敏处理可能涉及的信息。

## 四、方法是否匹配

- [ ] 我知道自己更想回答“是否存在关系/差异”，还是“为什么/如何发生”。
- [ ] 我能初步说明采用问卷、访谈或案例的理由（写法见 [`../references/methods/method-guide.md`](../references/methods/method-guide.md)）。
- [ ] 方法复杂度与我的时间、资料和能力相匹配。
- [ ] 主方向已定，理论候选来自 [`../references/methods/theory-menu.md`](../references/methods/theory-menu.md)，不是默认 4P。

## 五、时间是否允许

- [ ] 我能把题目拆为开题、资料收集、分析和写作四个阶段。
- [ ] 每个阶段都有明确的小产出。
- [ ] 我至少为修改留出一轮时间。

## 先看阻断项，再看其他条件

以下三项任一项尚未确认时，不要用其余勾选项抵消：

- [ ] 我能接触到足以支撑研究的样本或信息。
- [ ] 资料获取不依赖无法确认的授权。
- [ ] 我至少为修改留出一轮时间。

三项均确认后，再回看其余项目：

- 其余项目大多确认：可以进入研究问题和研究设计。
- 其余项目仍有多项不确定：保留方向，优先缩小对象、场景或问题。
- 阻断项未确认：先解决资料、授权或时间条件，不急于写开题正文。

## 最小行动

今天只做一件事：用一句话写清“研究谁、在哪个场景、面对什么问题、准备靠什么资料回答”。写不清，题目就还没有收拢。
