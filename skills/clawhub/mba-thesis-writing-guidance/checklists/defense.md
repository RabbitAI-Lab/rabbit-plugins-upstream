# 答辩前七天准备清单

## 目标不是讲完，而是讲清

答辩准备的核心，是在有限时间里讲清一条主线：你研究了什么问题、为什么这样设计、发现了什么、结论的边界在哪里。下方以 10 分钟为示例；请按你所在项目的实际陈述时长等比例调整。

## 10 分钟陈述结构

| 时间 | 要讲什么 | 目标 |
|---|---|---|
| 0–1 分钟 | 问题与背景 | 让听者知道你研究什么 |
| 1–2 分钟 | 研究问题与价值 | 说明为什么值得回答 |
| 2–4 分钟 | 研究设计 | 说明资料和方法为何匹配 |
| 4–7 分钟 | 关键发现 | 只讲最能回答问题的证据 |
| 7–9 分钟 | 结论与建议 | 回答研究问题，不扩大结论 |
| 9–10 分钟 | 局限与结束 | 展示边界意识 |

## 第 7–5 天：锁定主线

- [ ] 我能用一句话说清论文的核心问题。
- [ ] 我能用一句话说清研究对象、资料和方法。
- [ ] 我只保留最能支撑结论的图表和证据。
- [ ] 题目、摘要、PPT 和结论的核心表述一致。

## 第 4–3 天：搭 PPT 与问题卡

- [ ] PPT 每页只有一个要点，标题本身能表达结论。
- [ ] 每张图表都能回答“这说明什么”。
- [ ] 我准备了研究问题、方法、样本/资料、结果、建议和局限六类问题卡。
- [ ] 每张问题卡都写了证据、边界和回答顺序。

## 第 2 天：第一次模拟

- [ ] 完整讲一遍并计时。
- [ ] 记录超时、停顿、跳页和解释不清的位置。
- [ ] 请一位旁听者只指出“听不懂的地方”。
- [ ] 根据反馈删减内容，而不是只加文字或动画。

## 第 1 天：第二次模拟与物料检查

- [ ] 第二次完整计时演练在目标时长内完成。
- [ ] 备份 PPT、论文、数据表和必要附件。
- [ ] 检查字体、图片和图表在另一设备上的显示。
- [ ] 留出答辩当天的准备时间。

演练表：[`../templates/defense-rehearsal.md`](../templates/defense-rehearsal.md)。

## 答辩当天

- [ ] 开场第一分钟直接说问题与对象，不铺陈复杂背景。
- [ ] 听清问题后再回答；不确定时说明可确认的范围。
- [ ] 回答始终回到论文已有资料和分析，不临场扩展未经核实的结论。
