# 研究方法选择清单

## 先从问题出发

方法不是先选工具，而是先看你要回答什么问题、能取得什么资料。先把研究问题写清楚，再判断更适合问卷、访谈还是案例。

| 你更想回答的问题 | 更可能匹配的方法 | 先确认什么 |
|---|---|---|
| 是否存在关系、差异或影响 | 问卷与定量分析 | 样本、变量、题项来源 |
| 为什么发生、如何形成 | 半结构访谈 | 受访者、提纲、整理时间 |
| 一个组织或项目如何推进 | 案例研究 | 案例边界、证据来源、过程资料 |
| 既需要看关系，也需要解释过程 | 混合方法 | 两类资料如何相互补充、时间是否足够 |

## 一、研究问题

- [ ] 我能写出一个主要研究问题，不用“全面分析”“系统研究”这类空泛词。
- [ ] 我知道它更偏向关系/差异，还是过程/原因。
- [ ] 子问题不超过两个，并且都服务于主问题。

## 二、选择问卷前

- [ ] 关键概念能转成受访者能够理解和回答的题项。
- [ ] 我知道目标样本是谁，以及怎样接触他们。
- [ ] 我能找到可信的量表来源，或说明自编题项的依据。
- [ ] 我写下了预计样本数、核心变量或维度数，以及准备采用的分析方式。
- [ ] 样本规模与后续分析方式相匹配。
- [ ] 我不会把相关关系直接写成因果结论。

## 三、选择访谈前

- [ ] 我需要理解的是经验、过程、动机或决策逻辑。
- [ ] 我能接触到有直接经验的受访者。
- [ ] 我有一份围绕研究问题的半结构访谈提纲。
- [ ] 我写下了预计访谈人数、每次访谈时长和初步编码方式。
- [ ] 我预留了整理、编码和回看材料的时间。
- [ ] 我知道如何匿名处理受访者信息。

## 四、选择案例前

- [ ] 案例对象有清楚的组织、项目或时间边界。
- [ ] 我能获得不止一种证据，例如访谈、公开材料或内部记录。
- [ ] 我写下了案例的起止时间、关键事件和准备使用的证据类型。
- [ ] 我能说明这个案例为什么值得研究。
- [ ] 我会按事件或决策过程组织材料，而不是只写背景介绍。

怎么选、怎么写进第 1 章、如何调整：[`../references/methods/method-guide.md`](../references/methods/method-guide.md)。SEM、案例个数、实验法、公开数据源的刹车线见 [`../references/methods/research-design.md`](../references/methods/research-design.md)，不要在本页另写一套阈值。

## 最终确认

- [ ] 我能用一句话说明“这个方法如何回答我的主问题”。
- [ ] 我能列出当前最大的资料风险，以及一个替代方案。
- [ ] 若考虑混合方法，我能说明两类资料各回答什么，而不是把两种方法简单叠加。
- [ ] 当时间、资料或分析能力不足以支撑两套流程时，我会先选一个主方法。
