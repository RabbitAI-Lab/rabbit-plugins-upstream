# 初稿修改优先级清单

## 修改顺序比修改速度更重要

收到意见后，不要从第一句话开始逐句润色。先修会影响全文的问题，再修局部表达。建议按“主线—结构—证据—表达”推进。

| 优先级 | 先检查什么 | 常见表现 |
|---|---|---|
| P1 主线 | 题目、问题、方法、结论是否一致 | 写了很多，仍回答不了主问题 |
| P2 结构 | 章节是否各有任务、逻辑是否衔接 | 前后重复、章节像拼接 |
| P3 证据 | 论据与分析是否支撑判断 | 只有观点，没有资料或解释 |
| P4 表达 | 术语、句子、格式、引用 | 语言不顺、格式不统一 |

## P1：主线一致性

- [ ] 题目、研究问题、研究方法和结论指向同一个核心问题。
- [ ] 每个研究问题在正文中都有资料或分析回应。
- [ ] 结论没有超出资料能够支持的范围。
- [ ] 摘要、目录、引言和结论对研究对象的表述一致。

## P2：章节结构

- [ ] 每一章开头能说明“本章解决什么”。
- [ ] 章节之间有自然承接，不重复讲同一段背景。
- [ ] 综述、方法、分析和结论各自承担不同任务。
- [ ] 图表、附录和正文的编号、引用一致。

## P3：证据与分析

- [ ] 关键判断后有资料、文献、访谈片段、数据或案例支撑。
- [ ] 我解释了证据为什么能支持这个判断。
- [ ] 数据表不只呈现结果，也写明结果与问题的关系。
- [ ] 引用来源可追溯，转述没有改变原意。

## P4：表达与格式

- [ ] 一段只推进一个中心意思。
- [ ] 概念首次出现时有清楚界定，后续用词统一。
- [ ] 删除空泛副词、重复句和没有依据的结论词。
- [ ] 标题层级、格式和参考文献统一。

## 盲审纸面（送审前再过一遍）

对照 [`../workflows/05-revision.md`](../workflows/05-revision.md) 的五查：选题是否具体、综述是否对话、理论是否贯穿、对策是否可执行、格式是否过硬。导师批注先翻译再改，追踪表见 [`../templates/advisor-tracker.md`](../templates/advisor-tracker.md)。

## 完成前回看

- [ ] 本轮修改后，我重新检查了题目、目录和结论。
- [ ] 我能用三句话说清这一轮改了什么。
