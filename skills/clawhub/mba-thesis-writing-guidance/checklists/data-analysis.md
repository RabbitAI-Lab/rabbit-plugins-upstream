# 资料与结果检查清单

- [ ] 每个关键数字都能回到原始表、问卷、访谈记录或公开源。
- [ ] 样本/访谈对象的范围与第 1 章声明一致。
- [ ] 问卷若使用，报告了回收、有效、信效度或至少说明为何不做。
- [ ] 访谈若使用，说明了人数、角色、是否按饱和停止，而不是凑到某个教科书数字。
- [ ] 图表有编号、标题、正文引用和来源。
- [ ] 没有把相关关系写成因果，除非设计支撑。
- [ ] 统计结果写成「方向 + 显著性 + 对问题意味着什么」，不是只贴软件输出。
- [ ] 回归或信效度不理想时，先查测量、样本、模型，不改数据、不编数字。
- [ ] 第 3 章问题都能在结果中找到对应证据，而不是只出现在标题里。
