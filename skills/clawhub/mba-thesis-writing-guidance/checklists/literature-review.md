# 文献综述“对话式”写作清单

笔记卡：[`../templates/literature-notes.md`](../templates/literature-notes.md)。

## 核心原则

文献综述不是“谁说了什么”的资料清单，而是回答三个问题：已有研究形成了什么共识？分歧在哪里？这些研究还无法解释什么？

## 一、阅读记录是否能比较

- [ ] 我先写清了检索主题、资料来源和筛选范围，不是只收集顺手看到的文献。
- [ ] 我知道哪些文献是核心必读，哪些只是补充背景。
- [ ] 每篇核心文献都记录了研究对象、问题、方法和主要结论。
- [ ] 我知道这篇文献与我的问题有什么关系，而不只保存了摘要。
- [ ] 我区分了理论观点、实证发现和案例描述。

## 二、分类是否围绕问题

- [ ] 我按主题、机制、变量或研究情境分类，而不是按作者或年份排队。
- [ ] 每一类文献都能用一个简短标题概括。
- [ ] 分类之间没有明显重复，合起来能服务我的研究问题。

## 三、每一段是否形成“对话”

- [ ] 段首先写自己的归纳句，而不是直接抛出作者名字。
- [ ] 段中至少比较两篇研究的相同点或不同点。
- [ ] 我说明差异可能来自对象、情境、方法或时间。
- [ ] 段尾写出这一类研究的启发或限制。

## 四、研究缺口是否具体

- [ ] 我写的是“现有解释在哪个对象、情境或机制上还不够”，不是简单说“研究不多”。
- [ ] 这个缺口能自然连接到我的研究问题。
- [ ] 我没有把资料不足或个人兴趣误写成学术缺口。

## 五、段落收束模板

> 围绕【主题】，已有研究普遍认为【共识】。其中，【研究 A】在【对象或方法】中发现【发现】，而【研究 B】在【对象或方法】中指出【差异】。这意味着，现有解释在【具体情境】下仍需要讨论【限制或问题】。因此，本文聚焦【自己的研究问题】。

## 六、理论是否已从菜单选定

- [ ] 主方向明确，候选来自 [`../references/methods/theory-menu.md`](../references/methods/theory-menu.md) 对应表。
- [ ] 用户已删并到 1–2 个，且能说清第 3、4 章怎么用。
- [ ] 没有把 AHP / SWOT / 鱼骨图当成核心理论。

## 最小行动

挑出你已经写好的一段综述，先把第一句改成自己的归纳判断，再补一处比较和一处限制。不要急着加新文献。
