# 领域候选题目（小题深做）

用来对照题目是否已经收到「一家对象 + 一个可观察的落差」。结构与篇幅通例见 [`../references/corpus-guide.md`](../references/corpus-guide.md)。**本仓库不收录 PDF。**

这些是**题型示例**，不是参考文献。Agent 给候选题时按这个粒度写；不要输出「某公司人力资源研究」「数字化转型策略研究」这类筐。引用任何既有论文的观点，须回溯原文。

## 怎么判断够不够「小题」

一条合格题目，应能同时回答三问：

1. **研究谁**：部门、产品线、客户群或一条流程，而不是「中国企业 / 某行业」。
2. **出了什么状况**：有落差（投入了但没用上、考核了但行为反着走、覆盖了但流失集中在某一段）。
3. **打算怎么证明**：访谈、问卷、工单/台账、公开年报之一，现在就能说清入口。

口诀：对象可触达，问题有落差，证据有路径。下面按领域各列约 25–30 条；匿名对象可换成作者自己的企业。营销不是默认方向——主方向按现场落差认，见 [`../references/methods/theory-menu.md`](../references/methods/theory-menu.md)。

## Agent 使用约定

给用户出候选题目时：

- 每条都要能改写成：「我计划在【场景】中，围绕【对象】的【落差】，通过【资料】回答【问题】。」写不出来就再收一刀。  
- 不要用「全面优化」「体系构建」「数字化转型策略」当题目的核心词。  
- 对象优先用作者能触达的现场；作者坚持写进不去的明星公司时，先过材料闸门。  
- 8 个方向（营销、人力、运营、质量、财务、战略、数字化、经营管理）都按同一粒度出题；不要因为模板像营销就默认给 4P 题目。
