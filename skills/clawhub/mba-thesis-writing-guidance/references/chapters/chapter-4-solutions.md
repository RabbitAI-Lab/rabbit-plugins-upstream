# 第4章 方案设计：怎么写

这是全文篇幅重心（约 25–30%）。任务是：针对第 3 章每一个核心问题，给出本案例能执行的方案。读者看完应知道谁在何时用什么资源做什么，以及如何验收。落笔习惯见 [`../prose.md`](../prose.md)。

## 本章要回答的问题

1. 方案遵循什么原则、要达到什么可检查的目标  
2. 总体思路如何对应 3.4 的成因（不是另起一套框架）  
3. 每条对策如何一一对应 3.3 的问题  
4. 预期效果用什么指标、相对什么基准  

## 4.1 原则与目标

原则从第 2 章理论和本对象约束里来，写 3 条左右即可（例如：先治理冲突再扩覆盖；不新增编制前提下调整流程）。目标写成可验收的状态：时间窗口 + 指标 + 相对现状的变化。

不要把原则写成口号。每一条原则应能在 4.3 里找到对应取舍。

## 4.2 总体思路

一张框架图 + 一段说明。图的结构必须能映射回第 2 章理论维度，并与 3.4 成因同构。近期 / 中期任务在图上能分清优先级。

SWOT、PEST、五力若在第 2–3 章用过，到本章停止当主框架。主框架跟主方向走，不要把人力/运营/财务/经营管理写成营销 4P 四段。

## 4.3 具体对策

每一个 3.3 的问题对应一条对策。缺对应：删问题或补对策。每条对策按同一套字段写：

| 字段 | 内容 |
|---|---|
| 针对 | 对应 3.3 哪一条、3.4 哪一条成因 |
| 谁来做 | 责任部门 / 岗位，可写到委员会或项目角色 |
| 做什么 | 动作、制度、流程或工具，具体到步骤 |
| 何时 | 阶段和里程碑 |
| 用什么资源 | 编制、预算来源、系统、外部支持 |
| 验收 | 指标、数据从哪来、看到什么算做成 |
| 风险 | 本条主要阻力与预案 |

小节标题用论断（营销如「先统一价盘再扩三四线」，人力如「先把质检隐瞒从计件工资里拆出去」，运营如「先保护瓶颈工序再加班次」），不用「优化方案」。论断—证据—机制—对本企业意味着什么，见 [`../diagnosis/style-a-vs-b.md`](../diagnosis/style-a-vs-b.md)。

数字必须能回溯。写不出出处就标「待补材料」并停在该条，不编预算和效果。

## 4.4 预期效果

把 4.3 各条的验收指标收成一张表：指标、现状、目标、时间、数据来源。效果只承诺本案例、本时间窗口能观察的变化。

## 与第 5 章的分工

有的学校把实施保障放在第 4 章末，有的单列第 5 章。无论放哪：组织、制度、资源、分阶段计划和风险，按 [`chapter-5-implementation.md`](chapter-5-implementation.md) 写，不要和 4.3 的对策正文重复粘贴。结论见 [`chapter-conclusion.md`](chapter-conclusion.md)。

## 本章小结

300–600 字：重申问题—对策对应关系，点明第 5 章（或本章末）如何保障落地。

## 写完验收

- [ ] 第 4 章仍是全文最重的一章  
- [ ] 主框架不是 SWOT / PEST / 五力  
- [ ] 3.3 与 4.3 一一对应  
- [ ] 每条对策具备：谁、做什么、何时、资源、指标  
- [ ] 重要论断至少有一种可展示证据
