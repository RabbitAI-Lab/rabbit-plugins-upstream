## 1. 导言

### 1.1 报告用途

本页给应用型 MBA 学生提供：
- 论文结构的清晰范式
- 各章节篇幅的量化参考
- 写作风格与行文规范
- 理论选用的实践指南
- 可直接套用的大纲模板

### 1.2 通行规模

| 维度 | 通例 |
|------|------|
| 结构 | 五章制为主（部分学校六章） |
| 正文 | 常见 3万–4.5万字，多数学校要求 ≥3万 |
| 篇幅重心 | 第4章方案设计，约 25–30% |
| 常见领域 | 营销、人力资源、运营、质量、财务、战略、数字化、经营管理 |

### 1.3 如何使用本报告

- **开题阶段**：重点阅读第 2、4、8 章，确定论文骨架
- **正文写作**：重点阅读第 3、5、6 章，把握篇幅与行文
- **修改答辩**：重点阅读第 9 章，对照自查清单

## 2. 总体结构范式

### 2.1 标准五章制结构

应用型 MBA 论文**绝大多数采用五章制**（部分学校为六章），标准结构如下：

```
封面 → 中/英文摘要 → 目录 → 
第1章 绪论 → 
第2章 理论综述/文献综述 → 
第3章 现状分析/问题诊断 → 
第4章 方案设计/策略制定 → 
第5章 实施保障/效果评价 → 
结论 → 参考文献 → 致谢
```

### 2.2 各章功能定位

| 章节 | 核心功能 | 典型标题模式 |
|------|----------|--------------|
| 第1章 绪论 | 交代背景、意义、方法、技术路线 | 研究背景、研究目的、研究意义、研究方法 |
| 第2章 理论综述 | 梳理相关理论、文献回顾 | 相关理论概述、文献综述、理论基础 |
| 第3章 现状/问题 | 描述企业现状、诊断问题 | XX公司现状、存在的问题及原因分析 |
| 第4章 方案设计 | 提出解决方案/策略/体系 | XX体系设计、优化方案、策略制定（跟主方向，不默认营销） |
| 第5章 实施保障 | 保障措施、实施计划、效果评价 | 实施保障、推进步骤、预期效果 |
| 结论 | 总结全文、指出不足、展望未来 | 结论与展望、研究结论 |

### 2.3 结构变体

- **六章制**：部分论文将"现状分析"与"问题诊断"拆分为两章（第3章现状、第4章问题），或将"方案设计"与"实施保障"拆分
- **案例研究型**：少数论文采用"案例描述→案例分析→解决方案"结构
- **实证研究型**：涉及问卷调查的论文会增加"问卷设计与数据分析"章节

## 3. 章节字数与篇幅统计

### 3.1 正文规模

建议先按学校下限写，再按下列区间自我检查：常见 30,000–45,000 字。低于学校下限或第 4 章明显偏薄，都要停下来补材料，不要靠第 1 章背景凑字。

### 3.2 各章字数与占比

学校另有规定的以学校为准。没有规定时，用这张配比表：

| 章节 | 常见字数 | 建议配比 |
|------|----------|----------|
| 第1章 绪论 | 4,000–6,000 | 10-15% |
| 第2章 理论综述 | 5,000–7,000 | 15-20% |
| 第3章 现状/问题 | 6,000–8,000 | 15-20% |
| 第4章 方案设计 | 9,000–12,000 | 25-30% |
| 第5章 实施保障 | 5,000–7,000 | 15-20% |
| 结论 | 1,500–3,000 | 5-10% |

**核心发现**：第4章（方案设计）是篇幅最重的章节，建议约占全文 25–30%，体现 MBA 论文「解决问题」的导向。

### 3.3 摘要字数

- 中文摘要：800-1500字（平均约1000字）
- 英文摘要：与中文摘要对应，略短

### 3.4 三级标题数量

| 层级 | 建议 |
|------|------|
| 二级标题（X.Y） | 15–25 个 |
| 三级标题（X.Y.Z） | 20–35 个 |

## 4. 三级标题结构规律

### 4.1 第1章 绪论 —— 标准结构

```
第1章 绪论
  1.1 研究背景
  1.2 研究目的与意义
    1.2.1 研究目的
    1.2.2 研究意义
  1.3 文献述评（按主题/机制）
    1.3.1 主题一：共识与分歧
    1.3.2 主题二：共识与分歧
    1.3.3 研究缺口（接到本题目）
  1.4 研究内容与方法
    1.4.1 研究内容
    1.4.2 研究方法
  1.5 技术路线/论文框架
```

**写作要点**：
- 1.1 研究背景：从宏观（行业/国家）→ 中观（企业）→ 微观（具体问题）三层递进
- 1.3 文献综述：优先按主题/机制组织（共识→分歧→缺口），不要默认写成「国外一段 + 国内一段」
- 1.4 研究方法：常见方法包括文献研究法、案例分析法、问卷调查法、访谈法、定量分析法

### 4.2 第2章 理论综述 —— 标准结构

```
第2章 相关理论概述
  2.1 核心概念界定
    2.1.1 XX的定义
    2.1.2 XX的内涵/特征
  2.2 相关理论
    2.2.1 XX理论
    2.2.2 YY理论（可选）
  2.3 理论在本研究中的应用框架
```

**写作要点**：
- 理论选择要与第4章方案设计直接对应
- 每个理论需说明"核心观点→适用场景→本研究如何应用"
- 避免堆砌理论，核心理论 1–2 个（外加最多一个工具），见 `methods/theory-selection.md`

### 4.3 第3章 现状/问题 —— 标准结构

```
第3章 XX公司现状及问题分析
  3.1 公司概况
    3.1.1 公司简介
    3.1.2 组织架构
  3.2 XX管理现状
    3.2.1 现状描述（流程/制度/数据）
    3.2.2 已有成效
  3.3 存在的问题
    3.3.1 问题一：XXX
    3.3.2 问题二：XXX
    3.3.3 问题三：XXX
  3.4 问题原因分析
    3.4.1 原因一：XXX
    3.4.2 原因二：XXX
```

**写作要点**：
- 3.1 公司简介：500-800字，配组织架构图
- 3.2 现状描述：用数据、图表、流程说话，避免空泛
- 3.3 问题诊断：问题要与第4章方案一一对应
- 3.4 原因分析：可从"制度/人员/技术/环境"等维度展开

### 4.4 第4章 方案设计 —— 标准结构

```
第4章 XX方案/策略设计
  4.1 设计原则与目标
    4.1.1 设计原则
    4.1.2 设计目标
  4.2 设计思路/框架
  4.3 具体方案/策略
    4.3.1 策略一：XXX
    4.3.2 策略二：XXX
    4.3.3 策略三：XXX
  4.4 方案评价/预期效果
```

**写作要点**：
- 这是论文**最核心章节**，篇幅应占25-30%
- 4.3 具体方案要与3.3问题一一对应
- 方案要具体、可操作，避免空泛口号
- 配流程图、框架图、表格增强可读性

### 4.5 第5章 实施保障 —— 标准结构

```
第5章 实施保障/推进计划
  5.1 组织保障
  5.2 制度保障
  5.3 资源保障（人力/财力/技术）
  5.4 实施计划/推进步骤
    5.4.1 第一阶段：XXX
    5.4.2 第二阶段：XXX
  5.5 预期效果/风险评估
```

### 4.6 结论 —— 标准结构

```
结论
  一、主要研究结论（3-5条）
  二、研究不足/局限性
  三、未来展望
```

## 5. 写作方式与行文特点

### 5.1 摘要写法

**中文摘要四要素**：
1. **研究背景**（1-2句）：行业背景+企业背景
2. **研究问题**（1句）：本文针对XX问题
3. **研究方法/过程**（2-3句）：运用XX理论，从XX角度分析
4. **研究结论/建议**（2-3句）：提出XX方案，达到XX效果

**示例**（摘自《A公司绩效考核方案研究》）：
> 本文结合A公司在绩效考核方案上存在的一些主要问题，运用绩效考核的相关理论知识，结合A公司绩效考核的现状从公司部门、员工绩效考核两个层次进行了全面、系统的分析，找出了A公司在绩效管方面的根本问题是把绩效考核作为是整个绩效管理体系……针对A公司绩效管理方面存在的主要问题，本文分析了其主要原因，并结合A公司的战略目标进一步引进平衡计分卡和KPI的绩效考核方法……

**英文摘要**：与中文摘要对应，注意时态（背景用现在时，方法用过去时，结论用现在时）

### 5.2 句式与语气

**常用句式**（连接词省着用，详见 `prose.md`）：
- "本文针对XX问题，运用XX理论，从XX角度进行分析……"
- "研究表明/分析发现/结果显示……"

**语气规范**：
- 使用**第三人称**（"本文""本研究"），避免"我""笔者"
- 使用**书面语**，避免口语化表达
- 使用**肯定语气**，避免"可能""也许"等模糊词（除非确实不确定）
- 使用**现在时**描述理论，**过去时**描述研究过程

### 5.3 理论—案例结合方式

**标准链路**：
```
第2章 理论介绍 → 第3章 用理论框架分析现状 → 第4章 用理论指导方案设计
```

**示例**（平衡计分卡BSC）：
- 第2章：介绍BSC的四个维度（财务、客户、内部流程、学习与成长）
- 第3章：用四个维度分析A公司绩效考核现状
- 第4章：按四个维度设计A公司绩效考核指标体系

### 5.4 图表使用规范

**常见图表类型**：
| 类型 | 用途 | 示例 |
|------|------|------|
| 组织架构图 | 展示企业结构 | 第3章公司简介 |
| 流程图 | 展示业务流程 | 第3章现状描述、第4章方案设计 |
| 框架图 | 展示理论模型/方案框架 | 第2章理论、第4章方案框架 |
| 表格 | 对比数据/指标体系 | 第3章问题、第4章指标设计 |
| 柱状图/饼图 | 展示调研数据 | 问卷调查结果 |

**图表规范**：
- 图要有**图号+图题**（如"图3-1 A公司组织架构图"）
- 表要有**表号+表题**（如"表4-1 KPI指标体系"）
- 图表要在正文中**被引用**（如"如图3-1所示"）
- 图表来源要注明（自制/改编自XX）

### 5.5 过渡与论证套路

**章节过渡句**：
- "上一章分析了……本章将……"
- "在……的基础上，进一步……"
- "针对上述问题，本章提出……"

**论证逻辑**：
- **问题→原因→对策**：第3章问题→3.4原因→第4章对策
- **理论→现状→方案**：第2章理论→第3章用理论分析→第4章用理论设计
- **宏观→中观→微观**：行业背景→企业现状→具体问题

### 5.6 书面表达规范

句长、连接词、现场词以 [`prose.md`](prose.md) 为准，不要用「具有重要意义」撑段，也不要靠「首先 / 其次 / 最后」推进每一节。

## 6. 理论选用与应用特点

完整可选目录、何时不要选、Agent 给用户的挑选格式：[`methods/theory-menu.md`](methods/theory-menu.md)。下面短表只作速查，**不要当第 2 章必写清单**。执行时 1–2 个核心理论。

### 6.1 高频理论/模型清单

使用频率最高的理论/模型（按领域常见程度，不是排名竞赛）：

| 理论/模型 | 常见程度 | 适用领域 |
|-----------|----------|----------|
| SWOT分析 | 高频（仅作环境铺垫） | 战略、营销、通用 |
| PEST分析 | 高频（仅作环境铺垫） | 战略、营销、环境分析 |
| 品牌理论 / 营销组合 | 营销高频 | 营销、品牌 |
| STP战略 | 营销高频 | 营销 |
| 供应链 / 质量管理 | 运营高频 | 运营、质量 |
| 绩效管理 / 激励机制 | 人力高频 | 人力资源 |
| 360度考评 | 人力较常见 | 人力资源、绩效 |
| KPI关键绩效指标 | 人力较常见 | 人力资源、绩效 |
| BSC平衡计分卡 | 人力较常见 | 人力资源、绩效 |
| 成本控制 / 全面预算 | 财务较常见 | 财务 |
| 敏捷 / Scrum | 项目类较常见 | 运营、项目管理 |
| 竞争战略 | 战略高频 | 战略 |
| PDCA循环 | 质量较常见 | 运营、质量 |
| AHP-模糊综合评价 | 评价类可见 | 财务、评价 |
| SICAS模型 | 数字营销可见 | 营销、直播 |

### 6.2 理论落地链路

**标准链路**："理论综述→现状分析→方案设计"

**示例1：平衡计分卡（BSC）**
```
第2章：介绍BSC四维度（财务、客户、内部流程、学习与成长）
  ↓
第3章：用四维度分析A公司绩效考核现状（各维度存在的问题）
  ↓
第4章：按四维度设计A公司绩效考核指标体系
```

**示例2：SWOT+STP（营销类）**
```
第2章：介绍SWOT、STP理论
  ↓
第3章：用SWOT分析企业营销环境（优势/劣势/机会/威胁）
  ↓
第4章：用STP进行市场细分→目标市场→市场定位→营销组合策略
```

**示例3：PDCA循环（质量类）**
```
第2章：介绍PDCA（计划-执行-检查-处理）
  ↓
第3章：分析质量管理现状（P/D/C/A各环节的问题）
  ↓
第4章：按PDCA设计质量改进方案
```

### 6.3 按领域的理论偏好

| 领域 | 核心理论（第 4 章主框架从这里挑） | 铺垫 / 辅助 |
|------|----------|----------|
| 营销 | STP、4P/4C/7P、品牌资产、服务差距、CRM | SICAS、SWOT、PEST |
| 人力资源 | 期望/公平/双因素（择一）、BSC 或 KPI（择一）、胜任力 | 360、柯氏、心理契约 |
| 战略 | 竞争战略类型、资源基础观、安索夫 | SWOT、PEST、五力、价值链 |
| 财务 | 全面预算、作业成本/责任会计、COSO、营运资本 | 杜邦拆解；AHP 是方法不是理论 |
| 运营 | TOC、精益浪费、价值流、库存策略、SCOR | 流程图、对标 |
| 质量 | PDCA、DMAIC、质量成本、供应商质量 | 鱼骨/控制图（工具） |
| 数字化 | TAM/UTAUT、TOE、信息系统成功、数据治理 | 成熟度尺子（不对方案本身） |
| 经营管理 | 管控三模式、委托代理、权变/结构、交易成本 | COSO、组织变革（常放第 5 章） |

### 6.4 理论选用原则

1. **相关性**：理论要与研究问题直接相关
2. **适用性**：理论要能指导方案设计
3. **精简性**：1–2 个核心理论（外加最多一个工具），见 `methods/theory-selection.md`
4. **能操作**：能变成第 3、4 章的维度；经典框架（PDCA、期望理论、竞争战略类型）可以用，不要求追新词
5. **不要把方法当理论**：AHP、回归、鱼骨图写进第 1 章方法，不占第 2 章理论名额

---

## 7. 分领域深度剖析

### 7.1 营销类

**典型结构**：
```
第1章 绪论
第2章 营销相关理论（STP、4P、品牌理论、SWOT）
第3章 企业营销环境分析（PEST+SWOT）+ 营销现状与问题
第4章 营销策略制定（STP+4P/4C组合策略）
第5章 营销策略实施保障
结论
```

**核心章节**：第4章营销策略制定（占比30-35%）

**常用理论**：STP、4P/4C、SWOT、PEST、品牌理论、SICAS（直播营销）

**写作要点**：
- 第3章环境分析（PEST / SWOT）止于铺垫，不要写成第4章
- 第4章只展开第3章真正出血的维度（某一个 P 或某一段旅程），不要四段 4P 凑齐
- 需要定位时用 STP 收到目标市场；与问题无关的细分删掉
- 证据用问卷、访谈或渠道台账，有哪条用哪条

---

### 7.2 人力资源类

**典型结构**：
```
第1章 绪论
第2章 绩效管理/激励理论（BSC、KPI、360度、双因素理论）
第3章 企业人力资源现状与问题分析
第4章 绩效/激励体系设计（指标体系/激励方案）
第5章 实施保障与效果评价
结论
```

**核心章节**：第4章体系设计（占比30-35%）

**常用理论**：BSC平衡计分卡、KPI关键绩效指标、360度考评、激励机制理论

**写作要点**：
- 第4章要设计**具体的指标体系**（配表格，列出指标/权重/评分标准）
- 指标要分层级（公司级→部门级→员工级）
- 要有**实施保障措施**（组织/制度/文化/技术）

---

### 7.3 战略类

**典型结构**：
```
第1章 绪论
第2章 战略管理理论（竞争战略、SWOT、PEST、波特五力）
第3章 企业内外部环境分析（外部PEST+五力，内部资源能力）
第4章 战略制定与选择（SWOT矩阵→战略定位→战略方案）
第5章 战略实施与控制
结论
```

**核心章节**：第3章环境分析+第4章战略制定（合计占比50-55%）

**常用理论**：SWOT、PEST、波特五力、价值链、竞争战略（成本领先/差异化/聚焦）

**写作要点**：
- 第3章环境分析（PEST / 五力 / 资源能力）止于铺垫
- 第4章主框架用竞争战略类型或能指导方案的理论，不用 SWOT 矩阵当方案本身
- 战略要具体到**业务层面**（产品/市场/区域）

---

### 7.4 财务类

**典型结构**：
```
第1章 绪论
第2章 财务/成本/风险理论
第3章 企业财务现状与问题分析
第4章 评价体系构建/优化方案（AHP-模糊评价/预算体系/风控模型）
第5章 方案实施与保障
结论
```

**核心章节**：第4章模型构建/方案设计（占比30-35%）

**常用理论**：全面预算、作业成本/责任会计、COSO、营运资本（AHP 是赋权方法，不是理论，见 `methods/method-guide.md`）

**写作要点**：
- 第4章落到科目、流程、控制点或资金计划，不要只做完比率分析
- 若学校要求评价体系：理论用风险/预算/质量成本，AHP 放进方法并交代专家与一致性
- 每个数字能回到报表或台账口径

---

### 7.5 运营/质量类

**典型结构**：
```
第1章 绪论
第2章 质量管理/项目管理理论（PDCA、敏捷、供应链、精益）
第3章 企业运营/质量现状与问题分析
第4章 优化方案设计（流程优化/体系构建/敏捷实施）
第5章 方案实施与效果评价
结论
```

**核心章节**：第4章方案设计（占比30-35%）

**常用理论**：PDCA循环、敏捷/Scrum、供应链管理、精益生产、质量管理

**写作要点**：
- 第3章要有**流程图/现状图**
- 第4章要有**优化后流程图**（前后对比）
- 要有**实施计划**（甘特图/里程碑）

---

### 7.6 经营管理类

**典型结构**：第 2 章用管控/代理/结构/交易成本之一；第 3 章写授权清单、议事规则或加盟/集团界面上的落差；第 4 章给可执行的授权、检查与退出规则，不要改写成 4P。

**常用理论**：见理论菜单「经营管理」。组织变革框架若主要解决「推不动」，放到第 5 章保障，不要占第 4 章业务方案。

---

### 7.7 数字化类

**典型结构**：第 2 章用 TAM/TOE/信息系统成功/数据治理之一；第 3 章必须有采用、双轨、数据质量或决策不用数的证据；第 4 章写并轨、责任人、界面或考核，不写「提升数字化水平」。

**常用理论**：见理论菜单「数字化」。成熟度五级可以当第 3 章对标尺子，不能当第 4 章方案。

---

## 9. 全流程写作指引

### 9.1 开题阶段

#### 9.1.1 选题原则

**好选题的标准**（粒度见 `examples/corpus-index.md`）：
- ✅ **具体**：一家能触达的对象 + 一个可观察的落差
- ✅ **可操作**：现在就有证据路径
- ✅ **有理论支撑**：1–2 个理论能贯穿第 3、4 章
- ✅ **有实践价值**：做完能帮这个对象做决策

**选题公式**：
```
[XX公司/部门] + [XX管理领域] + [可观察的落差/问题] + 研究
```

**示例**：
- ✅ 《某制造企业生产部门新系统上线后一线抵触的关键影响因素研究》
- ❌ 《A公司绩效考核方案研究》（有对象，没有落差）
- ❌ 《蔚来新能源汽车营销策略研究》（对象过大，问题是筐）
- ❌ 《中国企业绩效管理研究》（行业筐）

#### 9.1.2 研究背景与意义

**研究背景写法**（三层递进）：
1. **宏观背景**：行业/国家/时代背景（2-3句）
2. **中观背景**：企业所在市场/竞争环境（2-3句）
3. **微观背景**：企业具体问题/痛点（2-3句）

**研究意义写法**：
- **理论意义**：哪个理论在哪个情境下被怎样用（1-2句），不要写「丰富了相关研究」
- **实践意义**：对这个对象、这类岗位或这条流程，做完能帮谁做哪类决策（2-3句）

#### 9.1.3 研究方法设计

选用、第 1 章四项写法、学校/导师/材料变了怎么调整：[`methods/method-guide.md`](methods/method-guide.md)。刹车：[`methods/research-design.md`](methods/research-design.md)。不要默认「文献+案例+问卷」三件套。

**技术路线图**：展示"提出问题→分析问题→解决问题"；图上要能看到取证与分析，不要只在图例堆方法名。

### 9.2 正文写作阶段

#### 9.2.1 各章展开要点

**第1章 绪论**（5000字）：
- 1.1 研究背景：从大到小，层层聚焦
- 1.3 文献综述：按主题/时间组织，最后要有"研究述评"指出研究空白
- 1.4 研究方法：说明为什么选这些方法

**第2章 理论综述**（6000字）：
- 理论选择要与第4章方案直接对应
- 每个理论：核心观点（200字）+ 适用场景（100字）+ 本研究如何应用（100字）
- 最后要有"理论应用框架"图

**第3章 现状/问题**（7000字）：
- 3.1 公司简介：500-800字，配组织架构图
- 3.2 现状：用数据、图表、流程说话
- 3.3 问题：2–3 个核心问题，要与第4章方案一一对应
- 3.4 原因：从制度/人员/技术/环境等维度分析

**第4章 方案设计**（10000字）★：
- 4.1 原则与目标：明确、可衡量
- 4.2 设计思路：配框架图
- 4.3 具体方案：与3.3问题一一对应，要具体可操作
- 4.4 预期效果：定性+定量描述

**第5章 实施保障**（6000字）：
- 组织/制度/资源/技术四维保障
- 实施计划：分阶段，配甘特图
- 风险评估：识别风险+应对措施

**结论**（2000字）：
- 主要结论：3-5条，每条1-2句
- 研究不足：2-3条
- 未来展望：1-2条

#### 9.2.2 理论与案例结合

**标准链路**：
```
第2章 理论介绍 → 第3章 用理论框架分析现状 → 第4章 用理论指导方案设计
```

**示例**：
- 第2章介绍BSC四维度 → 第3章用四维度分析现状问题 → 第4章按四维度设计指标体系

#### 9.2.3 图表规范

**图表数量建议**：
- 全文：15-25个图表
- 第3章：5-8个（现状图、流程图、数据表）
- 第4章：8-12个（框架图、流程图、指标表、方案图）
- 第5章：2-4个（甘特图、实施计划表）

**图表规范**：
- 图：图号+图题（如"图3-1 A公司组织架构图"）
- 表：表号+表题（如"表4-1 KPI指标体系"）
- 正文中要引用（如"如图3-1所示""见表4-1"）
- 来源注明（自制/改编自XX）

#### 9.2.4 参考文献规范

数量、外文比例、近五年占比、著录格式：**先问学校**，写入 `templates/school-format.yaml`。学校没写时，用 [`format-standards.md`](format-standards.md) 的通用底线。不要用本小节的旧数字卡用户。

### 9.3 修改/答辩阶段

#### 9.3.1 常见问题自查清单

**结构检查**：
- [ ] 五章结构完整（绪论→理论→现状→方案→保障→结论）

**内容检查**：

- [ ] 第2章理论与第4章方案直接相关
- [ ] 方案具体可操作（不是空泛口号）
- [ ] 有足够的数据/图表支撑

**格式检查**：
- [ ] 图表有编号+标题

- [ ] 摘要四要素完整（背景/问题/方法/结论）

**语言检查**：
- [ ] 使用第三人称（"本文""本研究"）
- [ ] 使用书面语（无口语化表达）
- [ ] 无错别字/语法错误
- [ ] 句子长度适中（每句不超过40字）

#### 9.3.2 查重

查重率以学校为准，写入 `school-format.yaml`。理论与综述用自己的话转述并标注出处。腔调、句长的加强检测不在本文件，见 `prose.md` 与 humanize-mba-text。

#### 9.3.3 答辩准备

陈述时长、PPT 页数以学校通知为准。结构与问题卡见 [`../workflows/06-defense.md`](../workflows/06-defense.md)。下面页数仅供参考，按实际时长缩放。

**PPT结构**（示例）：
1. 封面（题目+姓名+导师）
2. 研究背景与意义（2页）
3. 研究内容与方法（1页）
4. 理论框架（1页）

8. 结论与展望（1页）
9. 致谢（1页）

**答辩时间**：以学校为准；清单里的 10 分钟结构可等比缩放

## 结语

1. **理解范式**：掌握五章制标准结构
2. **把握篇幅**：各章字数合理分配，第 4 章做重心
3. **精选理论**：1–2 个核心理论（外加最多一个工具），与方案直接对应
4. **具体方案**：第 4 章要具体可操作，与问题一一对应
5. **规范写作**：书面语、第三人称、图表规范；学校规定优先
