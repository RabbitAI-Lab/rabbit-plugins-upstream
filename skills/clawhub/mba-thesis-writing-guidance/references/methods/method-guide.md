# 方法：选用、写法与调整

理论回答「用什么概念拆问题和出方案」；方法回答「用什么证据、怎么收集、怎么分析」。两件事不要混在第 2 章里。

- 理论目录与挑选：[`theory-menu.md`](theory-menu.md)  
- 理论条数与死理论：[`theory-selection.md`](theory-selection.md)  
- 方法刹车（SEM、案例个数、实验、没内部数据）：[`research-design.md`](research-design.md)  
- 勾选清单：[`../../checklists/research-method.md`](../../checklists/research-method.md)  
- 一页映射表：[`../../templates/method-mapping.md`](../../templates/method-mapping.md)

本页只写：常见方法用哪一种、第 1 章怎么写规范、材料或学校要求变了怎么调整。

## 三件套不要混

| | 管什么 | 写在哪 | 例子 |
|---|---|---|---|
| 理论 | 解释现象、约束方案结构 | 第 2 章，贯穿第 3、4 章 | 期望理论、PDCA、竞争战略类型 |
| 方法 | 取证与分析路径 | 第 1 章写清，第 3 章执行 | 案例、访谈、问卷、财务分析 |
| 工具 | 辅助整理 | 第 3 章图表或附录 | SWOT、鱼骨、AHP、甘特图、控制图 |

AHP、模糊综合评价、SPSS 回归、NVivo 编码都是方法或工具。它们可以出现在第 1 章「研究方法」，**不要占第 2 章核心理论的名额**。

## 先问题后方法

方法复杂度不是质量。先写主问题，再选能干净回答它、且你拿得到材料的路径。

| 主问题在问什么 | 主方法 | 常配的辅方法 | 最低材料 |
|---|---|---|---|
| 这家对象的这个问题是怎么形成的、方案怎么落地 | 单案例 + 文档 | 访谈 | 可脱敏的制度、流程、关键事件 |
| 是否存在差异、相关或影响（要分布） | 问卷 + 描述/回归 | 访谈解释异常 | 样本框、量表来源、发放路径 |
| 当事人如何理解、为何这样做 | 半结构访谈 | 文档对照 | 角色清单、提纲、整理时间 |
| 过程与分布都要 | 混合：案例/访谈 + 问卷 | — | 两类材料如何互相限制结论；时间够不够 |
| 账上数字如何变化、驱动在哪 | 财务/运营数据分析 | 访谈核对口径 | 报表、台账、口径说明 |
| 相对同行或历史差在哪 | 比较 / 对标 | 案例深挖机制 | 可核对的公开或内部对照数据 |
| 现场实际怎么干（与制度不一致） | 观察 / 流程走查 | 访谈 | 能进现场或拿到操作日志 |

文献研究法几乎每篇都会用，用来读理论和综述，**单独不能支撑第 3 章**。不要把「文献法、案例法、问卷法」三件套当默认配置——用不上的删。

## 按方向的常见组合（可改，不要当必修）

| 主方向 | 更稳的组合 | 常被多余加上的 | 调整提示 |
|---|---|---|---|
| 营销 | 案例 + 客户/渠道访谈；要分布时加问卷 | 无样本路径的「市场调研」 | 渠道冲突往往访谈+台账比问卷有用 |
| 人力资源 | 案例 + 员工/管理者访谈；考核题目可加问卷 | 照搬成熟量表但不改情境 | 样本量不够就不要承诺回归 |
| 运营 | 案例 + 流程数据（交期、在制、工单）+ 岗位访谈 | 与问题无关的员工满意度问卷 | 没有流程数据就先走查，不编节拍 |
| 质量 | 案例 + 缺陷/客诉/检验数据 + 相关岗位访谈 | 空 DMAIC（无测量） | 先确认缺陷可计数 |
| 财务 | 案例 + 报表/台账分析；内控题加制度走查与访谈 | 无专家样本的 AHP「赋权」 | 内部明细拿不到就改公开数据撑得住的问题 |
| 战略 | 案例 + 公开信息 + 对标；内部访谈补决策过程 | 五力写满却无一条内部证据 | 纯公开信息只能做定位级问题，做不了成本明细 |
| 数字化 | 案例 + 使用日志/工单 + 一线访谈 | 成熟度打分自嗨 | 日志没有就用访谈+屏幕/表单证据 |
| 经营管理 | 案例 + 制度/授权清单 + 多方访谈 | 硬加消费者问卷 | 多方（总部/分子/一线）角色缺一类就补，不凑人数 |

Agent 给方法建议时，先按用户主方向看这张表，再按材料闸门加减，不要一律「案例+问卷+访谈」。

## 各方法：规范写法与走样

每一种方法在第 1 章用**四项**写完：回答主问题的哪一部分；数据从哪来；样本或对象怎么来；分析怎么做。下面是规范与调整。

### 文献研究

- **规范**：写检索范围（主题词、中英文、时间）、纳入标准、如何按主题/机制归类。  
- **走样**：只写「查阅了大量文献」；用百度百科当理论来源。  
- **调整**：学校要求「国内外综述」分段时，仍按主题组织，国外/国内放在同一主题内部比较，不要先国外一大段再国内一大段。

### 案例研究

- **规范**：案例边界（哪家企业/哪块业务、起止时间）、为何单案例（或为何要对照）、证据类型不少于两种（制度/数据/访谈/观察）、关键事件如何串起来。  
- **走样**：写成公司简介；多案例却每家一段宣传。  
- **调整**：对照论证需要第二家又进不去 → 改为「本案例 + 公开对标」，并在局限性里承认机制外推受限。不要虚构第二家。案例个数的判断见 `research-design.md`。

### 访谈

- **规范**：角色类别（不是只写「管理人员」）、每类为何必要、提纲如何对应研究问题、预计场次与时长、录音/笔记与匿名、编码或整理规则、饱和或停止规则。  
- **走样**：人数写成「15–30 人」却说不清角色；还没做就写「管理层普遍认为」。  
- **调整**：某类关键人访谈不到 → 降级为文档证据，并写明缺口；不要用同级同事的传言替代。人数用饱和判断，公式见 `research-design.md`。

### 问卷

- **规范**：总体与抽样、发放渠道、预计有效回收、量表来源或自编依据、核心变量、分析计划（描述 / 差异 / 回归）、信效度打算报告什么。MBA 常见有效问卷下限约 150（学校另有规定的听学校）。  
- **走样**：相关写成因果；自编题无依据；样本是「转发到同学群」。  
- **调整**：  
  - 总体很小（如一个 80 人车间）→ 改为普查或访谈，不要硬冲 150。  
  - 学校要问卷但你接触不到客户 → 改员工/经销商等你够得着的总体，并改研究问题；或申请不做问卷，用访谈+台账。  
  - 导师要 SEM → 先过 `research-design.md` 五问，过不了就降级回归/分层回归+访谈。

### 财务或运营数据分析

- **规范**：指标定义、口径、时间窗口、数据来源文件、比较基准（同期、预算、对标）、缺失值怎么处理。  
- **走样**：把年报里的大数贴进正文，没有接到本问题；口径中途更换不说明。  
- **调整**：内部明细授权不到 → 改用法定披露/政府统计/行业协会公开数，题目收到公开数据撑得住的粒度。禁止借用同类企业数字填本案例。

### 比较 / 对标

- **规范**：对标对象为何可比（规模、业务、阶段）、比哪些指标、数据出处、差异如何解释（不是「人家做得好」）。  
- **走样**：对标世界一流或行业龙头，机制完全不同。  
- **调整**：找不到可比对标 → 改为自身跨期比较（政策/系统上线前后）。

### 观察 / 流程走查

- **规范**：观察时段与岗位、记录表、与制度文本如何对照、是否影响现场（霍桑效应要承认）。  
- **走样**：逛了一圈写成「实地调研发现管理落后」。  
- **调整**：进不了车间 → 改用操作日志、工单时间戳、监控抽帧等留下痕迹的材料，并写局限。

### 层次分析 AHP / 模糊综合评价

- **规范**：它是赋权或评价**方法**。写清准则层如何来自第 2 章理论维度、专家是谁、如何避免全是作者自己打分、一致性比率阈值、评价对象是什么。  
- **走样**：第 2 章把 AHP 当理论；专家全是同学；CR 不合格仍用权重。  
- **调整**：请不到合格专家 → 不要上 AHP，改成基于业务数据的指标对比，或访谈排序。学校点名要「评价体系」时，理论用风险管理/预算/质量成本，AHP 只当赋权步骤。

### 混合方法

- **规范**：写清两类材料各回答什么、时间顺序（先访谈后问卷，或相反）、如何互相限制结论（问卷里的异常用访谈解释；访谈判断用数据核对）。  
- **走样**：两种方法各写一段，结论各说各的。  
- **调整**：时间 <3 个月或一类材料路径不通 → 砍成一个主方法，在开题里主动收缩，不要承诺混合。

## 第 1 章方法节：段落规格

不要只列名称。每种方法一段，建议按此顺序：

1. **用途**：这句话回答主问题的哪一块（现状 / 成因 / 关系 / 方案约束）。  
2. **材料**：文件名类型、访谈角色、问卷总体，现在是否已有路径。  
3. **步骤**：怎么抽样或选案例、怎么收集、怎么整理。  
4. **分析**：编码、描述统计、对比逻辑、信效度；不准备做的也写清「为何不做」。  
5. **限度**：这种方法回答不了什么，后面结论不得越这条线。

技术路线图里，方法应出现在「取证 → 分析」两格，不要只在图例里写「文献+案例+问卷」。

第 3 章落地时：方法节承诺过的材料必须出现（表、引语、流程、出处）。承诺了问卷却只在第 3 章讲故事，属于方法空转，改第 1 章或补材料。

## 怎样调整（学校、导师、材料、时间）

按下面顺序处理冲突，不要同时改题目、理论和方法去「全都迁就」。

### 1. 材料路径变了

| 变化 | 先改什么 | 不要改什么 |
|---|---|---|
| 内部明细批不下来 | 题目收到公开/可脱敏材料撑得住的问题，或加一手访谈 | 不编数字、不借用同行数 |
| 问卷发不出去 | 主方法改访谈+文档；研究问题从「是否相关」改为「如何形成」 | 不降低有效问卷门槛却仍写回归分析 |
| 关键访谈对象拒绝 | 用文档/日志替代该类角色，局限性里写缺口 | 不拿传言补「普遍认为」 |

### 2. 学校模板点名要某些方法

先读学校文件：是「建议具备」、还是「必须问卷」。

- 必须问卷：把研究问题改到你够得着的总体（员工、经销商、住院患者等），量表能对应理论维度。总体不够大就书面申请普查或混合，并保留学校批示。  
- 建议问卷：材料更适合案例时，在开题写清为何案例更能回答主问题，问卷降为辅或不做。  
- 必须「定量分析」：财务/运营指标的描述、对比、趋势也是定量；不必上 SEM。

### 3. 导师要求「再加一个高级方法」

回到刹车线。加码前必须能同时回答：这个方法多回答了主问题的哪一句、样本和权限是否撑得住、你能否用普通话解释异常结果。任一答不上，建议降级，并给导师看 `research-design.md` 对应节。

常见降级：

- SEM → 回归 / 分层回归 + 访谈  
- 多案例 → 单案例深挖 + 公开对标  
- 真实验 → 不要自称实验；问卷或准实验（若有自然分组且能说明不可比性）  
- AHP → 业务数据对比或访谈排序

### 4. 时间不够（距交稿 <3 个月）

只保一条链：一种主方法 + 现有材料能写完第 3 章。砍掉尚未启动的问卷或第二案例。已经发出的问卷：能收回多少算多少，按实际样本改分析承诺（描述为主，推断降级），在局限性写清。

### 5. 理论换了，方法要不要换

理论换了只改第 2–4 章的维度，方法不一定换。只有当新理论要求的证据类型变了（例如从「旅程流失」改成「员工公平感知」）才改抽样对象。先改理论菜单里的主理论，再回头改本页的对象与题项。

### 6. 主方向认错了

方法组合跟着方向走。从营销改到运营：问卷客户可能变得不必要，流程数据变得必要。改 `thesis-config.yaml` 的 `main_discipline`，再重填方法映射表，不要只改标题里的「策略」两字。

## 第 1 章写完即查

- [ ] 每种列出的方法都能用一句话说清「它回答主问题的哪一块」  
- [ ] 用不上的方法已删，没有默认三件套  
- [ ] 样本、角色或数据文件现在有路径，或已标明待补且暂停对策  
- [ ] 分析承诺与样本规模匹配（没 150 份有效问卷就不承诺 SEM）  
- [ ] AHP / SWOT / 鱼骨没有被写成第 2 章核心理论  
- [ ] 混合方法写了如何互相限制结论  
- [ ] 刹车线（SEM / 多案例 / 实验 / 无内部数据）已按 `research-design.md` 过一遍  

过不了就停在选题或开题，不要先写第 4 章再补方法。
