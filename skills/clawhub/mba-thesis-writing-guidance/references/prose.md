# 落笔时的行文

写每一段就按这个习惯走，不要等整章写完再「去 AI」。腔调、句长、连接词首先是**写法**，不是事后检测项。

[`humanize-mba-text`](https://github.com/stephenlzc/humanize-mba-text-skill) 是成节之后的**加强**：把仍整齐、仍像模板的地方定位出来，改说法。本页不维护检测词表，也不跑检测脚本。

## 习惯

1. **一段一个推进**  
   先写判断，再给证据，再写对这个对象意味着什么。不要一段里既做背景又做文献又做对策。

2. **句长有长短**  
   短句钉事实和数字，稍长的句子解释机制。念出来应能换气。不要连续十几句长度差不多，也不要靠超长句一次塞完因果。

3. **连接词省着用**  
   节内靠句子本身衔接。「首先 / 其次 / 最后」「综上所述」「由此可见」「与此同时」不是每节标配；真要分步，用事情本身的顺序（谁先做、数据哪年来）。

4. **用现场词**  
   写岗位、流程节点、指标、工单、考核口径。咨询黑话（赋能、抓手、闭环、痛点、赛道）换成这件事在现场怎么说。

5. **从对象落到问题**  
   背景从本案例近两年的落差写起，不从「随着……的发展」起笔。宏观材料只保留能解释这个落差的那几句。

6. **综述先归纳再比较**  
   段首是你的判断（这类研究普遍认为什么），中间比较两篇以上，段尾接到本题目。不要「张三认为、李四指出」排队。

## 写完一节先扫一遍

用半分钟问三句：

- 这一段念给同事，他能不能听懂你在主张什么？  
- 句子是不是齐刷刷一样长？  
- 有没有连续三处靠「首先 / 同时 / 因此」往下推？

过不了这三问，当场改说法，再往下写。仍改不顺、或整章已经写成了再交给 humanize 加强，然后回到改稿清单核数字和主线。
