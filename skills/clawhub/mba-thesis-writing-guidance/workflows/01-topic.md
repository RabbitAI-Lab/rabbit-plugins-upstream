# 阶段 01：选题闸门

清单：[`../checklists/topic-feasibility.md`](../checklists/topic-feasibility.md)。一句话版本：[`../templates/topic-statement.md`](../templates/topic-statement.md)。没方向时按 `00-intake` 用提问盘工作资源，写入项目根目录 `work-resource.md`，不要丢模板让用户手填。

`00-intake` 已经写入的 `thesis-config.yaml` 直接用，只问还空着的项。有 AskQuestion 就用选项卡。

优先选你熟悉、能触达证据的现场。别人要申请调研许可，你推开办公室门就是现场——这是在职 MBA 的优势，不要丢掉去写一家进不去的明星公司。

## 最小输入

让用户按条回答（可多选的已标明）：

1. 论文类型：专题 / 企业诊断 / 案例 / 调研报告 / 学校指定 / 不确定  
2. 研究对象：现职 / 前雇主 / 实践项目公司 / 公开信息公司 / 还没有  
3. 行业  
4. 管理问题方向（多选，但最后只留一个主问题）  
5. 主学科方向（只能一个）：营销 / 人力 / 运营 / 质量 / 财务 / 战略 / 数字化 / 经营管理  
   认方向用现场落差，不要默认营销。对照 [`../references/methods/theory-menu.md`](../references/methods/theory-menu.md)「方向怎么认」。  
6. 材料：已有 / 能拿到 / 只能脱敏摘要 / 尚无合法路径  

## 三秒判断（太大 / 太小 / 没数据）

候选题目先过三刀，命中就划掉，不要靠改词藻救命：

| 刀 | 命中信号 | 处理 |
|---|---|---|
| 太大 | 对象是「中国企业 / 某行业」，或同时研究一堆因素 | 收到一家企业、一条流程、一个问题 |
| 太小 | 找不到文献、没有可观察现象、写不满三万字 | 略放一层（仍保持可取证） |
| 没数据 | 核心证据依赖未授权内部明细，又没有公开替代 | 换对象、改成公开材料撑得住的问题，或停 |

## 三级收窄

被导师反复打回，多半是否定边界，不是否定方向。从上往下砍：

1. 行业话题 → 管理问题：这句话里有没有「出了什么状况」  
2. 管理问题 → 具体对象与情境：谁、哪个部门、哪段时间，你能不能触达  
3. 对象 → 可验证的研究问题：影响因素 / 机制 / 比较 / 原因，且至少有一条现在就走得通的证据路径  

例：`企业数字化转型策略研究` → `数字化投入不小但一线抵触新系统` → `某制造企业生产部门` → `员工抵触的关键影响因素（访谈 + 使用记录）`。

## 负面清单（触发即停，不推荐题目）

| 触发 | 对用户说 |
|---|---|
| 论文类型「不确定」 | 类型会改题目写法、方法和开题结构，先问学校 |
| 还没有研究对象 | MBA 通常需要边界清楚的组织或对象 |
| 没有主学科方向 | 可以有辅方向，必须有一个主方向管逻辑 |
| 没有管理问题 | 先写出现场里谁在痛、痛在哪 |
| 没有任何合法证据路径 | 不能靠编材料往下走 |
| 公开信息公司 + 题目依赖内部成本/考核明细 | 改对象或改成公开材料撑得住的问题 |
| 主方向与核心材料严重错配 | 先改方向或改材料，不改词藻 |
| 剩余时间 <3 个月却要新开 SEM / 多案例 / 实验 | 砍方法、砍题目，保一条能做完的链 |

停写时只输出：触发项、为什么拦、最少还要补什么。

## 没有内部数据

先核对是真拿不到，还是没找对地方。公开年报、法定披露、政府统计、高校订阅库，往往够撑一部分题目。真拿不到（法律/合同保护、未上市且不披露、样本极小）就换对象或换问题，不要「估算」「借用」「参考同类企业填数」。细则见 [`../references/methods/research-design.md`](../references/methods/research-design.md)。

## 通过后

给 3–5 个**候选**题目。粒度对齐 [`../examples/corpus-index.md`](../examples/corpus-index.md)：对象可触达、问题有落差、证据有路径。不要输出「某公司人力资源研究」「数字化转型策略研究」这类筐。

公式仍是：`[对象]+[领域]+[问题/优化/设计]+研究`，但「问题」必须写成可观察的落差，而不是「优化/体系」本身。每个候选附：核心问题、核心材料、主要风险、建议主方向。标成候选，等用户删并。3–5 个候选不要全挤在营销；用户主方向已明确时，候选跟该方向走。

可行性可按 1–5 分粗评：合规、聚焦、对象清楚、材料、理论匹配、可行动、与作者背景匹配。总分过低或「材料」低于 3 分的删掉。

## 检查点

- [ ] 题目能用一句话说清对象和问题  
- [ ] 有可展示的证据路径  
- [ ] 用户确认后再进 `02-literature` 或 `03-outline`
