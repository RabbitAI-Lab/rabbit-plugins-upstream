# 阶段 02：文献与理论

清单：[`../checklists/literature-review.md`](../checklists/literature-review.md)。笔记卡：[`../templates/literature-notes.md`](../templates/literature-notes.md)。理论规则：[`../references/methods/theory-selection.md`](../references/methods/theory-selection.md)。按方向挑选：[`../references/methods/theory-menu.md`](../references/methods/theory-menu.md)。方法怎么写、怎么改：[`../references/methods/method-guide.md`](../references/methods/method-guide.md)。

文献综述是对话，不是「谁说了什么」的清单。每一类要能回答：共识是什么、分歧在哪、还解释不了什么、如何接到本题目。

## 步骤

1. 用题目里的对象类型 + 管理问题 + 候选理论做检索词；中英文都要。  
2. 核心文献按**主题 / 机制**归类，不按作者年代排队，也不默认写成「国外一段 + 国内一段」。  
3. 每一类写清：共识、分歧、还解释不了什么。  
4. 研究缺口写到对象 / 情境 / 机制，并接到本题目；不要写「研究较少」。  
5. 打开理论菜单对应方向，给 3 个候选让用户删并到 1–2 个；选定后再画将用于第 3–4 章的分析框架。不要替用户宣布「本文采用 4P」。  
6. 参考文献数量与结构底线见 [`../references/format-standards.md`](../references/format-standards.md)；学校另有规定的以学校为准。

Agent 可以帮整理你已读笔记、检查段落是否有比较句。不可以编造文献，也不可以让模型「总结这个领域」后直接当综述。

## 禁止

- 编造文献、年份、期刊、DOI  
- 用百度百科、无署名网页当理论来源  
- 第 2 章写学科史，后面章节不再使用该理论  

## 检查点

- [ ] 研究缺口具体到对象/情境/机制，不是「研究较少」  
- [ ] 理论能映射到第 3、4 章小节  
- [ ] 用户确认理论后再搭大纲
