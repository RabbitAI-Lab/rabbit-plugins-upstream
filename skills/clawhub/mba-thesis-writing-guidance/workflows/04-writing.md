# 阶段 04：分章写作

落笔习惯（句长、连接词、现场词）见 [`../references/prose.md`](../references/prose.md)，写每一节就用，不要等整章写完。建议顺序：第 3 章 → 第 4 章 → 第 2 章 → 第 1 章 → 第 5 章 → 结论 → 摘要。先有问题和方案，再倒装绪论。

论文不是一次写出来的。在职读者没有整块时间：把节拆到 15–25 分钟能推进的颗粒（一张表、一段成因、一条对策），先完成再完美。写不下去通常是标题太大，不是「懒」。

## 每章开始前

- 重读该章检查清单  
- 确认本章要回答的问题、要用的证据、与邻章的接口  
- 图表编号按 [`../references/format-standards.md`](../references/format-standards.md)

## 第 3 章

按第 3 章文件写：边界、现状、**2–3 个**问题、用第 2 章框架拆成因。概况只留与问题有关的信息。数据结果清单见 [`../checklists/data-analysis.md`](../checklists/data-analysis.md)。

## 第 4 章

- 标题用论断；主框架不得只剩 SWOT / PEST / 五力  
- 对策必须可执行（谁、做什么、何时、资源、指标）  
- 与第 3 章问题一一对应，缺对应就删问题或补对策  

## 红线

- 不编数字和访谈原话；缺证据就标注「待补材料」并停在该节  
- 统计结果写成「方向 + 显著性 + 对问题意味着什么」，不把相关写成因果  
- 每一节写完先按 `prose.md` 扫三问（主张是否听得懂、句长是否过齐、连接词是否连推）  

AI 可以整理提纲、对照缺口、改病句。成段正文必须由用户基于自己的材料写或改；分区见 [`../references/ai-use.md`](../references/ai-use.md)。
