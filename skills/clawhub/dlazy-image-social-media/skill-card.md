## Description:

Plans platform-specific social media visuals and captions, and guides image generation for Instagram, TikTok, YouTube, LinkedIn, and Xiaohongshu.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and marketing teams use this skill to plan social media imagery, platform-appropriate layouts, short in-image text, and separate captions, with optional image generation through dLazy.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and referenced local media may be shared with dLazy cloud services.

Mitigation: Share only content you are comfortable sending to dLazy and review media before upload.

Risk: Login may store an API key locally, and a global CLI install persists on the system.

Mitigation: Protect the local key and use the documented npx option when a persistent installation is unwanted.
