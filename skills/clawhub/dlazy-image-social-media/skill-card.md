## Description:

Plans platform-specific social media visuals, layouts, and layered copy for channels including Instagram, TikTok, YouTube, LinkedIn, and Xiaohongshu.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Social media creators and marketing teams use this skill to plan platform-specific visuals, concise in-image headlines, and separate captions, then adapt a design across platforms or prepare image-generation requests.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security scan is incomplete, so installation details and some referenced content were not fully inspected.

Mitigation: Review the pinned @dlazy/cli@1.2.3 package and any unresolved referenced content before installing or running it.

Risk: The skill documentation says prompts and supplied media files are sent to dLazy-hosted services for generation.

Mitigation: Avoid sending sensitive prompts or media unless that transfer is approved for the intended use.

Risk: Image generation may incur an external action if a confirmation step is misunderstood or skipped.

Mitigation: Obtain clear user confirmation before each image-generation request and stop when confirmation is not given.
