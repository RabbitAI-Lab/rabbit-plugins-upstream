## Description:

Helps create platform-adapted social media visuals, image prompts, and captions for Instagram, TikTok, YouTube, LinkedIn, and Xiaohongshu.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and marketing teams use this skill to plan and generate social media images and accompanying copy tailored to each platform's format and audience.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected media files are sent to dLazy services for generation.

Mitigation: Only submit content you are comfortable sharing with dLazy; review selected files before generation.

Risk: Installing and authenticating the third-party CLI may leave a global package or locally stored API key.

Mitigation: Review the CLI source and package before use; consider npx and DLAZY_API_KEY to avoid a persistent global install or saved key.
