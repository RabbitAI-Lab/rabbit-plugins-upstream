## Description:

Helps plan and create platform-specific social-media visuals, in-image headlines, and captions for Instagram, TikTok, YouTube, LinkedIn, and Xiaohongshu.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Creators and marketing teams use this skill to plan and generate platform-adapted social-media graphics, carousel layouts, headlines, and captions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and user-provided media may be sent to dLazy's cloud service, where generated outputs are hosted.

Mitigation: Use only content approved for third-party processing; avoid uploading sensitive or confidential media.

Risk: Login may store an API key locally, and global CLI installation persists on the device.

Mitigation: Use a per-invocation DLAZY_API_KEY and npx when a saved key or long-lived global CLI is undesirable.
