# 政策翻译官

> 官话 → 人话 → 行动

## 这是什么

新政策出来看不懂、不知道对自己有没有用？一句话告诉你能不能、省多少、该怎么做。支持企业政策和个人政策，双输出：可视化 HTML + 可转发文本总览。

## 快速开始

在 AI 助手中导入 `skill.md`，然后发送：

```
帮我解读政策 [政策名称]，我是 [企业/个人]，[行业]，[资质]
```

技能自动走六步流程，产出 HTML 报告 + 文本总览。

## 案例

| # | 案例 | 类型 |
|:--|:--|:--|
| 1 | 2026 年个税退税 | 个人政策 |
| 2 | 2026 企业税收减免 | 企业政策（无评分体系） |

## 技术栈

纯 HTML + CSS，零外部依赖，零 CDN。暖橙主题色，纵向时间轴，卡片式布局。
