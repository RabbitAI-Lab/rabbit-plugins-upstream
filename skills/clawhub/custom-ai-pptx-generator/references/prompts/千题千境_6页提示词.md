# 千题千境 PPT skill — 6 页提示词包

> 用途：用户拿这份提示词去 Midjourney / DALL·E / 即梦 / 文心一格 /
> Stable Diffusion 等工具出更精致的样图，**避免在 image_gen 上反复打补丁**。
> 拿回图后，**我**用 python-pptx 出最终可编辑 PPTX。

## 通用参数（每页都套）

| 项 | 值 |
|---|---|
| 比例 | 横版 16:9，1280×720（也可用 1920×1080，最后我用哪个都行） |
| 风格 | cute children's picture book style, flat cartoon vector, very rounded shapes, picture-book illustration, soft drop shadows |
| 背景 | 奶白 `#FFFCF7` |
| 主色板 | 橙 `#FF9F45` / 黄 `#FFCD3C` / 绿 `#88D8B0` / 蓝 `#6FC2E8` / 紫 `#B39DDB` |
| 文字 | 深灰 `#2C3E50` |
| 装饰 | 四角散布 星/心/气球/糖果/云朵 等扁平小图标 |

> 通用修饰短句（粘贴到每条 prompt 末尾）：
> `Flat cartoon vector, very rounded shapes, candy colors, picture-book illustration feel, soft drop shadows, generous whitespace, child-friendly, professional presentation slide.`

## 拿图回来时的标准

- **尺寸**：横版 16:9，建议 1920×1080 或 1280×720
- **命名**：`p1_cover.png` / `p2_what.png` / `p3_capability.png` / `p4_you.png` / `p5_flow.png` / `p6_start.png`
- **存放位置**：建议放 `c:\Users\kenzj\WorkBuddy\20260912200310\sample3\`
- **不需要抠图**，留原图即可，PPT 用法二选一后我再处理

## 我拿图后会做什么（两种用法，倾向 B）

- **A. 直接嵌入**：把图作为整页背景或大图贴入。文字不灵活，改起来麻烦。
- **B. 原生重建（推荐）**：参照图的视觉走向，用 python-pptx 原生形状（圆角卡片、彩色药丸、流程圆、CTA 按钮、文本框）重建 6 页。**文字可改、颜色可调、卡片可增删**——这正是"可编辑 PPT"的目标。
