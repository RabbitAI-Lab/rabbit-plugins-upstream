## Description:

Adapts user-provided web novels into Chinese webtoon plot breakdowns, episode tags, and panel-oriented scripts.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

External creators and developers can use the skill to turn Chinese web-novel material into structured plot breakdowns, episode tags, and visually oriented webtoon scripts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected media may be sent to dLazy for cloud generation, which may incur charges.

Mitigation: Review each prompt and media selection before confirming generation, avoid sending sensitive content, and check applicable charges.

Risk: Logging in saves the dLazy API key in the local CLI configuration.

Mitigation: Protect the local configuration, avoid sharing it, and rotate or revoke the key if it is exposed.

Risk: The artifact contains conflicting workflow descriptions and stale CLI version references.

Mitigation: Clarify whether image generation is intended and verify current CLI installation details before installing or running it.
