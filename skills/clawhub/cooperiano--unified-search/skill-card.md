## Description: <br>
Unified Search helps an agent search across Chinese, English, academic, and skill-discovery sources with fallback retries, result deduplication, source labels, freshness labels, and optional Brave or Tavily API keys. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[cooperiano](https://clawhub.ai/user/cooperiano) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and agents use this skill to request unified search coverage across general web, Chinese-language, English-language, academic, and ClawHub skill-discovery sources. It is useful when a single query may need fallback handling, source marking, deduplication, freshness filtering, or optional Brave and Tavily integrations. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Optional Brave and Tavily integrations may use API keys or service tokens. <br>
Mitigation: Use least-privilege keys, keep secrets out of generated notes or shared knowledge files, and confirm that configured integrations are acceptable before installation. <br>
