# 板块异动指标体系

> 免责声明：本文档中的"操作含义"为数据统计结果的研究参考，不构成投资建议，不承诺收益。实际交易请独立判断并自负风险。

## 一、价格类

| 指标 | 计算 | 阈值 | 含义 |
| :--- | :--- | :--- | :--- |
| 板块平均涨幅 | 成分股涨幅等权平均 | >1% 活跃，>3% 强异动 | 板块整体强度 |
| 超额收益 | 板块涨幅 - 全市场平均涨幅 | >+1% 显著跑赢 | 相对强弱 |
| 上涨家数占比 | 上涨家数 / 成分股数 | >80% 普涨，<50% 分化 | 板块广度 |
| 涨停家数 | 主板>=9.5%，双创>=19.5% | >=2 有赚钱效应 | 情绪强度 |

## 二、量能类

项目库历史 `volume/amount` 大多为 0，脚本自动降级：

| 指标 | 计算 | 说明 |
| :--- | :--- | :--- |
| 成交占比 | 板块当日成交额 / 全池成交额 | >5% 资金聚集，>10% 高度聚焦 |
| 龙头成交 | 板块内成交额前3 | 确认是否大票主导 |

若未来历史量能补齐，可恢复量比（板块当日成交额 / 20日均额，>1.5 放量，>2 显著放量）。

## 三、资金类（fundflow_cache JSON）

| 指标 | 字段/计算 | 含义 |
| :--- | :--- | :--- |
| 主力净流入 | `mainForce` 板块加总 | >0 资金进场 |
| 资金为正个股占比 | `mainForce>0` 家数 / 成分股数 | >60% 资金普流 |
| 5日累计净流入 | `history` 最近5日 `mainForce` 加总 | 趋势性 |
| 正流入天数占比 | 板块个股5日中正流入天数 / (成员*5) | >60% 持续性好 |
| 净流入强度 | `mainForce / 当日成交额` | >5% 资金主导 |

注意：盘前/盘中运行时，`fetch_date` 是当天但数据 `date` 可能滞后一日，报告中会标注资金流基准日。

## 四、结构类

| 指标 | 含义 |
| :--- | :--- |
| 龙头梯队 | 涨幅前3且成交额>3000万：龙头/中军/跟风是否完整 |
| 涨停梯队 | 龙头封板 + 二板/三板高度 |
| 板块内联动 | 龙头异动后跟风股是否跟随 |

## 五、情绪/消息类（可选增强）

- `news_cache` JSON：新闻热度变化
- `longhubang_daily`：游资/机构席位，机构净买入>0 为加分
- 公告催化剂：中标、订单、预增等（项目 `announce_cache`）

## 六、异动分类

按"涨幅方向 × 资金方向 × 广度"组合：

| 类型 | 特征 | 操作含义 |
| :--- | :--- | :--- |
| 强势异动 | 涨幅>0 + 资金流入 + 广度>60% | 关注龙头（研究参考，非买入指令） |
| 资金进场 | 涨幅小/平 + 资金大幅流入 | 潜伏信号，观察是否启动 |
| 冲高出货 | 涨幅>0 + 资金净流出 | 反弹减仓（研究参考，非卖出指令） |
| 放量下跌 | 跌幅+放量 | 破位信号，回避 |
| 弱修复 | 涨幅>0 + 无量 + 资金平平 | 超跌反弹，持续性差 |
