# 某省级人民医院 — 全品类膳食纤维主食营养食堂合作方案

## 一、背景与问题
贵院日均住院糖尿病患者约200人，营养食堂主食供应的核心难题：
- 普通米饭/馒头→糖尿病患者餐后血糖飙升
- 全麦馒头→纤维含量低（<6%）、口感差、患者拒食
- 现有方案无法兼顾"控糖"和"好吃"——患者血糖管理和用餐体验的矛盾无解

## 二、解决方案
全品类膳食纤维主食（20+种可溶+不可溶纤维，含量≥20%）嵌入营养食堂：
- **不改变患者主食习惯**——口感接近普通馒头/米饭，患者接受度高
- **真实控糖**——20人验证数据显示，14天空腹↓34%、餐后↓39%
- **可验证**——每批患者可配CGM，数据透明可见

## 三、验证数据（同级别医院参照）
某市级医院（20人，14天）：双重达标率45%，0例低血糖
某大学附属医院（20人，Day3）：空腹已下降0.8 mmol/L（趋势向好）
某医药流通企业某市试点（50人，14天）：双重达标率48%

## 四、合作模式
- 验证期：免费提供20人×7天验证包（主食+CGM），数据说话
- 供应期：月供高纤白面__吨（按日均200人×三餐估算），嵌入营养食堂主食管线
- 支持：配营养科培训 + AI监测后台接入 + 季度数据报告

## 五、下一步
建议安排一次营养科现场演示：
- 现场烹饪品鉴（5分钟）
- 展示CGM实时血糖监控（15分钟）
- 讨论合作方案（30分钟）
```

### 三、信号分析与问题归类

#### 问题1：价格敏感（40%，高优先级）
```
识别：8条拒绝中，"价格太贵"占比最高
根因：¥XXX体验版后用户的下一步成本是¥XXX，心理落差大
影响：如不解决，C端体验→标准转化率将持续偏低

触发动作：→ P2-02
  行动：评估增加 ¥XXX 极简体验版（3天CGM+1天主食，成本¥XX，售价¥XXX）
  观察期：1个月后看"价格太贵"拒绝比例变化
  成功标准：价格拒绝率从 40% → <25%
```

#### 问题2：品牌认知低（25%，中优先级）
```
识别：5条"没听过你们"——品牌冷启动困难
根因：新品牌无知名度，B端客户不敢冒险推荐
影响：影响"意向→验证"转化

触发动作：→ P3-01
  行动：包装"某公众人物/某网红医生"级别KOL合作内容 + "已合作医院案例墙"
  观察期：2个月后看"没听过"拒绝比例变化
```

#### 问题3：竞品给更好条件（15%，中优先级）
```
识别：3次提到 DGI 给出更好的渠道条件
根因：DGI 有先发优势和规模效应，渠道政策更灵活
影响：可能被挤出药房渠道

触发动作：→ P1-01（增量扫描 DGI）+ → P2-01（评估渠道策略是否需要差异化）
  行动：P1-01 增加 DGI 渠道政策专门监控；P2-01 评估"不跟 DGI 在药房硬刚，转攻医院+体检中心"
```
