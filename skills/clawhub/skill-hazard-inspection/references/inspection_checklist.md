## 一、电气安全

### 检查项目

| 序号 | 检查内容 | 标准要求 | 检查方法 | 判定 |
|------|----------|----------|----------|------|
| 1.1 | 配电箱/柜 | 箱门完好、接地可靠、有安全警示标识 | 目视+工具检测 | |
| 1.2 | 临时用电 | 线路敷设规范、无私拉乱接、配电箱有漏电保护 | 现场查看 | |
| 1.3 | 电气设备 | 外壳接地、无破损漏电、绝缘良好 | 摇表测试 | |
| 1.4 | 防雷接地 | 接地装置完整、接地电阻符合要求 | 专用仪器检测 | |
| 1.5 | 电动机 | 运行无异常振动和声响、温度正常 | 温度计+听诊 | |

### 隐患描述参考

- 配电箱门损坏，无法正常关闭
- 临时用电线路未穿管保护
- 设备接地线松动或缺失
- 电动机接线盒盖缺失

## 使用说明

1. **检查前准备**: 熟悉检查区域的工艺流程和设备分布
2. **逐项检查**: 对照清单逐项检查，客观记录实际情况
3. **发现隐患**: 使用"隐患描述参考"中的格式规范记录
4. **分类录入**: 按隐患类别调用 `create_inspection.py` 录入系统
5. **严重等级判断**:
   - **critical (特大)**: 可能造成群死群伤的重大隐患
   - **high (重大)**: 可能造成人员伤亡或重大财产损失
   - **medium (较大)**: 可能造成人员伤害或较大财产损失
   - **low (一般)**: 影响较小，有整改价值的隐患
