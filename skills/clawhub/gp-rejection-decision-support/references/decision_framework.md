## 1. 五步决策流程

### 第一步：体系与法律适用判定
- 政府采购法体系（公开招标/邀请招标/竞争性谈判/竞争性磋商/询价/单一来源）／招投标法体系／国企非招标采购。
- 体系不同 → 术语与红线不同（政采："无效投标""废标""质疑"；招："否决投标""异议"）。
- **信息不足立即追问**，不假设。

### 第二步：条款性质归类（用矩阵对号入座）
将该条款归入三类之一：**应当认定无效** / **可澄清补正** / **裁量空间**。

### 第三步：事实匹配
- 投标人响应是否落入该条款的无效情形？
- 区分 **重大偏差** vs **细微偏差**：
  - 重大偏差：对采购文件实质内容（报价、工期、质量、技术规格、★号条款）的偏离/保留，导致实质上影响合同履行、限制评委会裁量权、或不公正影响其他投标人。
  - 细微偏差：不影响实质响应、不影响公平竞争。

### 第四步：可澄清性判定（关键分叉）
依据 **87号令第五十一条、第五十二条**：
- **可澄清、不得直接认定无效**：含义不明确的内容、同类问题表述不一致、明显文字错误、明显计算错误。澄清不得超出投标文件范围或改变实质性内容。
- **不得澄清、不满足即无效**：实质性内容（投标报价、工期、质量、主要技术参数、★号条款）不得通过澄清补正。
- **形式瑕疵**（签字盖章遗漏、装订、份数、电子签章格式）：通常按前附表要求补正或认定；若前附表明定为无效情形则从其规定，谨慎认定。
- **报价前后不一致**：按 87号令第52条修正（大小写不一致以大写金额为准；总价与单价不一致以单价为准；不同文字表述以中文文本为准）；修正后经投标人确认生效。

### 第五步：结论 + 依据 + 措辞 + 质疑投诉复核研判
输出决策意见书（SKILL 第七节模板），并调用政采投诉库（7450416392468005）研判同类被质疑投诉情形走向。

## 2. 应当无效 vs 可澄清补正 判定矩阵（核心）

> 用法：按"争议性质"行定位，再用"处理"列定类，最后核"依据/边界"。政采法源以 87号令 / 94号令 / 政府采购法为主。

| 争议性质 | 典型表现 | 处理 | 依据与边界 |
|---|---|---|---|
| **资格性不符** | 资质类别/等级/有效期不满足；财务/业绩/信誉硬门槛未达；联合体组成不符 | **应当认定无效（不可澄清）** | 资格后不得借澄清补充；87号令第60条（一）；资格项非"可补正" |
| **法定禁止/串通** | 串通投标、弄虚作假、行贿、重大违法记录未满年限、列入失信/黑名单、关联投标（同一负责人/控股） | **应当认定无效 + 书面报告财政** | 87号令第37条（视为串通）、第63条；政府采购法第77条；指明后果并建议书面报告财政部门 |
| **签署盖章缺失** | 未加盖单位公章、无法定效力签署、联合体无共同投标协议 | **应当认定无效**（若前附表明定为无效情形） | 87号令第60条（五）；非"含义不明确/计算错误"类 |
| **实质性响应偏差** | 技术★号条款负偏离、工期超期、质量不达标、主要参数不满足 | **应当认定无效（不可澄清）** | 实质性内容不得澄清；87号令第60条（六）"不满足招标文件★号条款" |
| **报价超限价** | 投标报价高于采购文件设定的最高限价 | **应当认定无效** | 超限价即无效，显式检查；87号令第60条（二） |
| **多项负偏离累积** | 非★号条款多项负偏离，按评标办法可认定为不响应 | **应当认定无效**（依办法判定） | 须引用评标办法具体条款，非必然 |
| **串通/弄虚作假痕迹** | 异常一致报价、相同错误、混装证书、虚假业绩 | **应当认定无效 + 报告财政** | 87号令第37、63条；建议书面报告财政部门 |
| **报价明显低于其他且无法证明** | 报价明显低于其他通过符合性审查投标人的报价，先要求说明 | **可澄清补正（先澄清）** | 87号令第60条（四）；经书面说明+证明仍不成立才认定无效；非直接否 |
| **含义不明确/表述不一致** | 表述歧义、同类问题表述不一致 | **可澄清补正（不得否）** | 87号令第51条；澄清不超范围不改实质 |
| **明显文字/计算错误** | 大写小写不一致、分项汇总误差 | **可澄清补正（修正）** | 87号令第52条；按采购文件修正约定 |
| **形式瑕疵（非明定无效）** | 装订、份数、电子签章格式轻微不符，前附表未明定无效 | **可补正 / 谨慎认定无效** | 优先补正；前附表明定无效则从其规定 |
| **细微偏差** | 不影响实质响应与公平竞争的轻微偏离 | **可补正（不无效）** | 不影响中标结果，要求补正即可 |

**关键分叉判别口诀**：
- 实质内容（报价/工期/质量/主要技术/★号条款）出问题 → **认定无效**，不可澄清。
- 含义/文字/计算出问题 → **澄清**，不可直接认定无效。
- 资格硬门槛出问题 → **认定无效**，资格后不可补。
- 形式小瑕疵 → 看前附表是否明定无效；未明定则**补正优先**。

## 3. 法条依据层级映射（政府采购法体系）

| 层级 | 依据 | 适用 |
|---|---|---|
| 法律 | 《政府采购法》 | 基本制度、废标原则（第36条）、违法责任（第77条） |
| 行政法规 | 《政府采购法实施条例》 | 细化资格、串通、质疑投诉衔接 |
| 部门规章 | 87号令《政府采购货物和服务招标投标管理办法》 | 第37/51/52/60/63条为核心无效与澄清条款（适用于公开/邀请招标） |
| 部门规章 | 94号令《政府采购质疑和投诉办法》 | 质疑（第10-13条）、投诉（第17-19条）程序与时效 |
| 采购文件 | 投标人须知前附表、评标办法 | 具体★号条款、修正约定、无效投标清单（效力通常最高） |

**效力压制**：采购文件具体条款（尤以前附表）> 部门规章 > 行政法规 > 法律原则；但条款本身不得违反上位法，冲突时提示向代理机构书面澄清。

> **准确性护栏**：本技能给出的条款号（如 87号令第60条、第52条）为常见锚点。撰写评标报告前，**须以政采实务与合规库（7463496212028405）内 87号令 / 94号令原文为最终准据**，核对子项编号，避免记错或张冠李戴。
