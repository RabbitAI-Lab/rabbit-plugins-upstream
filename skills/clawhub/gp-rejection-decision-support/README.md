# 否决/废标决策支持·政采专家版

> 政府采购评审中评标委员会（专家）侧的无效投标/废标决策引擎。输入「具体投标人响应 + 采购文件对应条款」，输出：① 是否构成无效投标及法条/条款依据；② 应当无效与可澄清补正的区分判定；③ 可直接写入评标报告的规范化无效投标理由措辞。

## 它能做什么

- **评得准**：基于判定矩阵对号入座，区分「应当认定无效 / 可澄清补正 / 裁量空间」。
- **无效得有依据**：每条结论绑定采购文件条款 + 法定依据（87号令/94号令/政府采购法），引号引用并标注来源库。
- **经得起质疑投诉复核**：调用政采投诉知识库研判同类被质疑投诉情形的处理走向与抗推翻要点。
- **不踩纪律红线**：客观中立、全程留痕溯源、回避人情与领导干预。

## 适用边界

- 体系：以《政府采购法》体系（公开招标/邀请招标/竞争性谈判/磋商/询价/单一来源）为主；招投标、国企采购为可扩展体系（挂载对应库并切换术语）。
- 角色：评标委员会决策支持，**不替代**评委会法定职权。
- 不越界：不做报价策略、不帮投标人规避、不代写质疑/投诉文书。
