# SOP 正文模板 (sop-template.md)

本模板用于把补全后的流程落成标准作业程序（SOP）。复制本模板，按【】提示逐项填写，删除提示注释后交付。

## 一、填写字段清单（访谈补全时逐条核对）

- 流程名称：【】
- 适用范围：适用谁 / 什么场景 / 不适用谁【】
- 触发条件：什么情况下启动本流程【】
- 输入材料：开始执行前需要准备好的东西【】
- 角色与职责：谁执行 / 谁审核 / 谁知会，具体到岗位【】
- 步骤与判断点：每一步做什么、满足什么继续、不满足怎么办【】
- 异常处理：每一步出错的应对【】
- 交付物：每一步产出什么【】
- 附件清单：用到的表单 / 系统 / 模板【】
- 修订记录：版本、日期、修改人、变更说明【】

## 三、填好的示例（周报表提交，原创流程）

# 周报表提交标准作业程序 (SOP)

### 1. 适用范围
- 适用：各业务线周报负责人
- 场景：每周五 18:00 前完成并提交
- 不适用：法定节假日按行政通知顺延，不在此流程

### 2. 角色职责表 (RACI)
| 角色(岗位) | 执行(R) | 审核(A) | 知会(I) | 备注 |
|---|---|---|---|---|
| 周报负责人 | 是 | | 是 | 由各组组长担任 |
| 部门主管 | | 是 | | 仅做内容确认，不代填 |
| 行政助理 | | | 是 | 接收并归档 |

### 3. 步骤表
| 步骤 | 操作 | 判断条件 | 异常时怎么办 | 交付物 |
|---|---|---|---|---|
| S1 | 从系统导出本周工作清单，按模板填入完成情况 | 系统可登录且本周数据已同步 | 系统无法登录：联系 IT 报障并在群里报备，顺延不超过 1 小时；仍不行则先交文字版，次日补系统导出 | 填好的周报草稿 |
| S2 | 将草稿发给部门主管确认内容 | 主管在 30 分钟内回复 | 主管超时未回：电话提醒一次；仍无回复按「主管已知会」提交，并存档提醒记录 | 经主管确认的周报 |
| S3 | 在规定时间前提交至行政助理并归档 | 周五 18:00 前送达 | 临近截止仍未确认：升级至部门主管电话确认，优先保证按时提交 | 已归档周报 |

区分要点：S1 产出的是「草稿」不对外，S2 的产出才是「经确认可提交版」，两者不能混为一谈；漏掉 S2 直接提交视为未审核。

- 周报模板（公司知识库「周报」分类）
- 工作系统导出入口（内网地址，权限由 IT 开通）
