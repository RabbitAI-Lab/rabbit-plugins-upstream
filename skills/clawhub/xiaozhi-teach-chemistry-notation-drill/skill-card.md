## Description:

帮化学老师设计班级的化学用语过关体系：元素符号、化合价、化学式、化学方程式分级过关，贯穿全年分段推进，配合间隔回看与分层任务；高中延伸到必修与选择性必修（第 5～8 级）。触发语示例："全班化学式总写错，怎么设计过关""化合价默写怎么安排才不突击""方程式配平怎么分层训练""过关卡怎么设计""过关没通过的学生怎么跟进"。不处理：整节课的教案（含复习课、讲评课，转化学教案设计）、实验教学（转化学实验教学指导）、单元练习、试卷与试卷分析（分别转测评设计师、学情分析师）。

## Use Case:

Chemistry teachers use this skill to plan a year-long, level-based practice and review system for chemical notation, create short checkpoint cards, and follow up on class-level learning gaps. It is designed for teacher review and classroom adaptation.

## Known Risks and Mitigations:

Risk: Generated chemistry questions or answer keys may contain errors.

Mitigation: The teacher should verify each formula and balancing result before using generated questions in class or assignments.

Risk: Class records could expose student personal information.

Mitigation: Use pseudonyms or seat numbers, omit contact and family details, and have the teacher confirm proposed record changes before saving.

Risk: The security review has medium confidence and incomplete reference checks, with a Unicode concern noted in its guidance.

Mitigation: Review the unresolved references and flagged Unicode content before installing, as the security guidance recommends.
