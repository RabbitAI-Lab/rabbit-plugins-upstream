## Description:

Generates cinematic videos from text or images using Google Veo 3.1 through dLazy.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to generate videos from prompts or reference images and to extend existing clips.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and supplied media may be sent to dLazy, and generated media is hosted by dLazy.

Mitigation: Share only media and prompts you are comfortable sending to and storing with dLazy.

Risk: The CLI may store an API key in local configuration.

Mitigation: Use a per-invocation API key environment variable if you do not want the key saved locally.
