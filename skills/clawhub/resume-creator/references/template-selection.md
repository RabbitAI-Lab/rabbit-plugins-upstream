# Presentation Selection

Read this reference before asking for any resume presentation choice. Use the
user's current interaction language for the entire explanation, table labels,
recommendations, and selection question. Keep template names unchanged.

Present both paths below, then wait for one exact selection. The entries under
"adaptation direction" are instructions for a newly authored, self-contained
HTML rendition guided by that Reactive Resume visual direction. They do not
claim an app export or pixel-exact equivalence.

Show all 15 entries. For each, state its adaptation direction and best-fit

### Five recommendations

Recommend exactly five entries from the table, in priority order, and give a
one-sentence reason for each. Derive the recommendations from the supplied
facts, target role, target reader, language, content density, and whether the
resume needs to foreground projects, credibility, or personal brand. Do not
recommend a template merely because its name is memorable.

If those inputs are not available, use this neutral fallback order:
`Ditto`, `Bronzor`, `Rhyhorn`, `Lapras`, `Glalie`. Explain that it favors
readability and broad professional use, not a judgement about the candidate.

## Path B: Native HTML styles

Show all three entries. These are original HTML presentations, not Reactive
Resume template adaptations. Read [html-styles.md](html-styles.md) after the
user selects one.

| Style | Distinguishing visual characteristics | Suitable scenarios |
| --- | --- | --- |
| `Classic` | One-column hierarchy, restrained accent color, conventional section order, generous spacing | Recruiter review, ATS-adjacent handoff, corporate and broad professional applications |
| `Editorial` | Typographic narrative, measured rules, strong headline and summary, quieter project treatment | Research, strategy, product, senior individual-contributor and writing-led profiles |
| `Studio` | Modular project emphasis, confident accessible color, compact metadata, stronger visual rhythm | Design, creative technology, independent work, founders, builders, portfolio-led applications |

## Selection prompt

Ask for one exact name after showing the full comparison. Do not generate a
file until the user selects a name or explicitly delegates the decision.

- Chinese: `请直接选择一个名称，例如：Bronzor、Lapras 或 Studio。`
- English: `Choose one exact name, for example: Bronzor, Lapras, or Studio.`
