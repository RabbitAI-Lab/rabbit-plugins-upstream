## Description: <br>
Creates reusable paged HTML tutorial guides from workflows, screenshots, videos, links, reference images, and step-by-step documentation. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[mmgongzhu](https://clawhub.ai/user/mmgongzhu) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, technical writers, and workflow owners use this skill to turn procedural material and media into a local paged HTML tutorial, or to extract reusable UI style prompts from reference images. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Referenced support files may be missing, which can make style extraction or HTML generation incomplete. <br>
Mitigation: Confirm the required style and production reference files exist, or provide equivalent instructions before relying on generated output. <br>
Risk: Generated labels or prompts may default to Chinese-language wording. <br>
Mitigation: Ask the agent to localize visible labels, captions, and prompts for the intended audience before publishing. <br>
