## Description:

A local DRT/ICT trading journal agent that records trades, analyzes win/loss patterns, and maintains a personal trade memory for future review.

This skill is ready for commercial/non-commercial use.

## Publisher:

[northcap-group](https://clawhub.ai/user/northcap-group)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers can use this skill to journal DRT/ICT trades locally, review setup performance, and surface simple learning points from accumulated trade history.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill stores trade journal entries locally in its own data file.

Mitigation: Install only if local storage of trade journal history in the skill workspace is acceptable.

Risk: The analysis may be mistaken for financial advice or automated trading behavior.

Mitigation: Use the output as journaling support and review guidance manually before making trading decisions.
