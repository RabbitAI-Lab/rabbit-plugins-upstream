## Description:

ppt to video, word to video, excel to video, pdf to video, document to video — parse, outline, storyboard, voiceover, build, validate. Use when the user gives a document and wants an explainer, report broadcast, courseware, or training video.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users can turn PowerPoint, Word, Excel, or PDF documents into explainer, report, courseware, or training videos through dLazy's hosted workflow.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Documents attached for video generation are uploaded to dLazy media storage and processed through its hosted service.

Mitigation: Send only documents you are comfortable sharing with dLazy, and review its privacy terms and credit costs before use.

Risk: Logging in saves an organization API key in the local CLI configuration.

Mitigation: Use a trusted device and revoke the key when it is no longer needed.

Risk: Resuming a project with the wrong project ID could use unintended conversation context.

Mitigation: Confirm the intended project before continuing work.
