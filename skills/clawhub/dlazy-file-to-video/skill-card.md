## Description:

Helps turn PPT, Word, Excel, and PDF documents into narrated explainer, courseware, report, or training videos through the dLazy hosted service.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Employees, educators, and developers use this skill to create narrated videos from documents for presentations, reports, lessons, and training.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Attached documents and prompts are sent to the dLazy hosted service.

Mitigation: Use only documents approved for external processing, and review the content before uploading.

Risk: Use of the service requires an API key stored by the CLI or passed through an environment variable.

Mitigation: Protect the key and rotate or revoke it through the dLazy dashboard when needed.
