## Description:

Helps turn PPT, Word, Excel, and PDF documents into explainer, training, and report videos through a project-based dLazy agent.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators, educators, and teams use this skill to turn documents into narrated explainer, courseware, or training videos with a project-based assistant.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and explicitly attached files are sent to dLazy's service.

Mitigation: Share only documents and prompts you are comfortable sending to dLazy; review files before attaching them.

Risk: Login may save an API key in the user's local configuration.

Mitigation: Protect the local key and revoke or rotate it from the dLazy dashboard if needed.

Risk: A global CLI installation persists on the user's system.

Mitigation: Use the pinned npx command for one-off runs when a persistent installation is unwanted.
