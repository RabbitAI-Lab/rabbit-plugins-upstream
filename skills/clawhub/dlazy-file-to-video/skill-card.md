## Description:

Turns presentations, Word documents, spreadsheets, and PDFs into explainer, report, course, or training videos.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

External users can turn presentations, reports, spreadsheets, and PDFs into explainer, report, course, or training videos.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Attached documents are uploaded to dLazy media storage for processing.

Mitigation: Only upload documents you are comfortable sharing with dLazy.

Risk: Authentication saves an organization API key in local CLI configuration by default.

Mitigation: Protect the local configuration and revoke unused keys; use the documented environment-variable option when appropriate.

Risk: Requests use organization projects and may consume service credits.

Mitigation: Select the intended organization project and consider credit costs before starting.
