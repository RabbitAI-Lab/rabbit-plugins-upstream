# P6 新手商品创建

## 约束生成原则

不直接写商品页。先检查必要信息：

```yaml
required_info:
  product_name: ""        # 商品名称
  brand: ""               # 品牌（无品牌标"无品牌"）
  model: ""               # 型号
  condition: ""           # 成色（全新/95新/9成新）
  cost: ""                # 成本
  price: ""               # 售价
  key_selling_point: ""   # 核心卖点（一句话）
  target_user: ""         # 适合谁
  inventory: ""           # 库存数量
  shipping: ""            # 发货方式
  after_sales: ""         # 售后承诺
```

已有：直接生成。缺失：询问，不猜测。

**禁止编造：** 参数、品牌、材质、成色、认证、购买渠道。

## 定价 SOP

### 新手简化定价

```
售价 = 进货价 + 运费 + 包材 + 目标利润（≥¥20）
```

### 三价格策略

假设目标成交价 ¥89：

```
展示价：¥109    -> 价格锚点
心理成交价：¥95  -> 议价空间
最终优惠：¥89    -> 买家觉得"谈到了好价格"
```

注意：不虚构原价、不虚假优惠。展示价必须是真实标价，不能先抬高再假装打折。闲鱼平台可能对虚假标价进行处罚。三价格策略的核心是**留出议价空间**，而非制造虚假折扣。

### 新手定价防错

```
IF 售价 - 所有成本 < ¥20
  -> 警告：利润太低，不值得做

IF 新手想定最低价打价格战
  -> 阻止：计算最低盈利价格，不打价格战
```

## 标题 SOP

### 结构

> **核心关键词 + 品牌/型号 + 核心属性 + 使用场景**

### 关键词三级

| 级别 | 类型 | 示例 |
|------|------|------|
| 一级词 | 大词 | 电脑支架、PPT、收纳 |
| 二级词 | 属性 | MacBook、铝合金、便携 |
| 三级词 | 场景 | 办公、租房、桌搭 |

组合：核心词 + 属性词 + 场景词

### 三种标题类型

| 类型 | 模板 | 示例 |
|------|------|------|
| 搜索型 | 关键词+关键词+关键词 | MacBook支架｜铝合金｜桌面支架 |
| 场景型 | 给XX使用的XX | 给MacBook用户的桌面效率支架 |
| 痛点型 | 解决XX问题的XX | 解决桌面空间不够的MacBook支架 |

**至少准备3个标题版本。**

### 禁止

- "全网最低""老板疯了""绝对正品"等夸大宣传词
- 感叹号堆砌
- 与商品无关的流量词
- 虚构原价/虚假优惠描述
- 关键词堆砌（同义词反复排列）
- 留微信号/手机号/外部链接（引导站外交易，扣1-100分）

## 图片 SOP

### 核心原则

> 一张图只解决一个问题。

新手最大的坑：图片做得很漂亮，但不知道卖点是什么。

### 7图结构

| 图序 | 解决的问题 | 内容 |
|------|----------|------|
| 图1 | 我卖什么？ | 商品 + 一个核心卖点 |
| 图2 | 为什么买？ | 核心卖点/适配型号/材质 |
| 图3 | 怎么用？ | 真实使用场景 |
| 图4 | 有什么细节？ | 材质/接口/做工 |
| 图5 | 具体多大？ | 尺寸视觉化 |
| 图6 | 为什么信你？ | 实拍/状态/包装 |
| 图7 | 怎么交易？ | 发货/售后说明 |

### 主图原则

> 商品占70% + 卖点占20% + 环境10%

主图任务：0.5秒内知道你卖什么 + 为什么值得点。

### 新手图片防错

**图片硬性禁止项**（违反会被AI审核下架/降权）：
- 禁止二维码、微信号、手机号等联系方式
- 禁止外部链接
- 禁止水印（闲鱼官方水印除外）
- 禁止纯文字图（无实物图片）
- 禁止盗用他人图片

```
IF 新手想做"淘宝风"大字报
  -> 阻止：闲鱼需要真实感，不是淘宝详情页

IF 二手商品不展示瑕疵
  -> 警告：主动暴露缺陷比收货后被发现更便宜
```

## 文案 SOP

### 新手5段式

```
① 核心利益（一句话说清楚为什么值得买）
② 商品是什么（基本描述）
③ 适合谁/为什么卖
④ 商品状态（成色/功能/配件）
⑤ 交易信息（发货/售后/注意事项）
```

### 示例

```
【Mac用户桌面效率神器】

MacBook桌面支架，铝合金材质，稳固不晃，可调高度和角度。

适合：MacBook/iPad用户、居家办公、外接显示器、桌面桌搭。

95新，功能正常，无明显磕碰，原装配件齐全。

因为换设备所以闲置，非长期商家库存。
支持平台担保交易，发货前会拍照确认商品状态。
想要可以直接拍，有具体型号/尺寸问题也可以先问我。
```

### 文案原则

- 让用户快速判断"是不是我想要的"
- 降低买家决策成本
- 不写"全网最低""100%最好"（除非能证明）
- 简洁，不写成淘宝详情页

## 算法原理对发布策略的影响

> 闲鱼的算法决定你的商品能不能被搜到和推荐。了解原理才能配合算法而不是被算法惩罚。详见 `references/00-platform-rules.md`。

### 搜索排序

闲鱼通过关键词匹配 + 向量匹配召回商品，再根据相关性排序。

**发布策略**：
- 标题关键词准确比数量堆砌重要——选对核心词，让算法精准匹配
- 选对类目——类目错误会直接影响搜索排序
- 标题、描述、图片信息要一致——相关性模型会交叉验证

### 个性化推荐

系统根据买家浏览行为预测偏好，匹配推荐商品。

**发布策略**：
- 准确的标题和类目让系统知道把你的商品推荐给谁
- 不要频繁修改商品——每次修改会重置推荐权重
- 新品发布后系统会测试推荐，给点耐心

### 内容安全审核

发布的文本/图片会被AI自动审核（深度学习+知识图谱），高置信度直接处理。

**发布策略**：
- 不打擦边球，AI审核能识别违禁内容
- 避免敏感词、违规图——一旦被识别会降权甚至下架
- 不盗图、不搬运——系统能识别重复内容

## 发布后等待期指南

> 商品发布后到收到第一个咨询之间的"空窗期"（通常 1-7 天）是新手最容易焦虑和放弃的阶段。

### 发布后 24 小时

- **检查曝光** - 在闲鱼"我的"->"我发布的"里看商品浏览量。0 浏览说明标题关键词可能有问题
- **搜索验证** - 用你的关键词搜索，看能不能搜到自己的商品。搜不到说明标题需要优化
- **如果 0 浏览** - 换标题关键词组合，在平台规则允许范围内优化后重新发布

### 发布后 48 小时

- **如果浏览 >50 但无咨询** - 问题在主图或价格。主图不够吸引或价格偏高
- **如果浏览 <10** - 问题在标题/关键词。尝试换更具体的长尾词（如"MacBook Air M2支架"而非"电脑支架"）
- **操作** - 优化主图（让商品更突出）或微调价格（降 5-10 元测试）

### 发布后 72 小时

- **如果仍无咨询** - 尝试"擦亮"功能（闲鱼每天可以免费擦亮一次，增加曝光）
- **换标题版本** - 用之前准备的 3 个标题版本中的一个替换
- **如果 3 天后仍无任何咨询** - 不要继续等。回到 P4 检查是不是选品问题

### 等待期不要做的事

- 不要为了曝光一次性上很多商品（质量 > 数量）
- 不要频繁修改商品（每次修改会重置推荐）
- 不要刷浏览量（会被平台降权）
- 不要因为焦虑就降价到亏本

### 等待期心态

```
发了没人问 ≠ 失败
发了没人问 = 需要诊断问题在哪
```

诊断顺序：标题能搜到吗？-> 曝光够吗？-> 主图能吸引点击吗？-> 价格合理吗？-> 逐项排查，一次只改一个变量。
