# P10 复盘放大与收入阶段

## 第一笔利润复盘

第一单完成后，Skill 不问"感觉怎么样？"。

而是 structured 复盘：

```yaml
first_sale_report:
  product:
    name: "MacBook铝合金支架"
    category: "桌面配件"
  result:
    views: 1320
    inquiries: 23
    orders: 3
    conversion_rate: 13%
  economics:
    revenue: 267
    product_cost: 105
    logistics: 24
    packaging: 9
    platform_fee: 1.6    # 0.6%基础服务费（月销售额超10000元后超出部分另加1%）
    profit: 127.4
    labor_hours: 3
    profit_per_hour: 43
  learning:
    strongest_signal: "用户非常关注适配型号"
    biggest_objection: "价格"

    improvement: "在商品页增加适配型号列表"
    surprise: "晚上10点后咨询量最高"
```

## 从第一单到可重复模型

```yaml

  pricing_insight:

    price_99: { conversion: null, inquiries: null }  # 未测试

    top_concern: "适配型号"
```

下一次做相似商品时，AI 参考这些经验。这就是复利。

## 收入阶段

### Stage 1：完成第一笔利润（示例参考：¥0-¥100）

目标：完成第一笔利润。

不要追求快速赚大钱。

核心任务：
- 跑通完整流程（选品->发布->咨询->成交->发货->售后）
- 建立信心
- 积累第一手经验

### Stage 2：找到可重复成交的商品（示例参考：¥100-¥1,000）

目标：找到一个可重复成交的商品。

核心任务：
- 复制第一个成功商品的方法
- 测试 2~3 个变体（不同标题/价格/图片）
- 找到"能稳定卖"的组合

### Stage 3：建立 SKU 组合（示例参考：收入逐步提升）

目标：建立 SKU 组合。

核心任务：
- 横向复制（同需求的不同价位）
- 纵向复制（同人群的不同产品）
- 优化效率（减少每单人工时间）

**经营性行为预警**：到这个阶段，你的在售物品可能超过30件、年交易可能超104笔——闲鱼会认定你为经营性卖家，需办理营业执照并公示。详见 `references/00-platform-rules.md`。

### Stage 4：产品化与多渠道

目标：产品化、自动化、多渠道。

核心任务：
- 半自动化流程
- 在合规前提下沉淀客户关系（遵守平台导流规则）
- 探索小红书/抖音等渠道

> 以上金额均为教学示例，不代表实际收益，也不构成任何收益承诺。

> ⚠️ **导流违规风险**：在闲鱼聊天或商品页中引导买家加微信/扫码/跳转外部平台，属于引导站外交易，一般扣1分，严重扣20分，特别严重扣100分。沉淀客户应在合规前提下进行（如买家主动询问联系方式、交易完成后自然添加等），绝不能群发微信号或在商品描述中留联系方式。

**经营性行为预警**：这个阶段几乎必然触发经营性行为认定。务必提前办理营业执照，在主页公示经营信息，履行七天无理由退货等经营者义务。详见 `references/00-platform-rules.md`。

**此时建议切换到 xianyu-growth-system Skill。**

## 放大决策

当达到 REPEATABLE 状态时，评估是否放大：

```yaml
scale_assessment:
  current_state: "REPEATABLE"
  evidence:
    repeatable_orders: true
    stable_profit: true
    proven_model: true
  decision: SCALE
  conditions_met:
    - "连续3周有稳定成交"
    - "找到1个可重复成交的商品"
    - "每单贡献利润 > ¥20"
    - "售后率 < 10%"
    - "闲气值 > 81分（无违规限制）"
    - "未触发经营性行为认定，或已完成经营者登记"
  compliance_check:
    - "商品均不属禁售/限售品类"
    - "无引导站外交易记录"
    - "无虚假描述/隐瞒瑕疵投诉"
    - "服务费成本已纳入利润计算"
  next_actions:
    - "扩大测试到5-10个SKU"
    - "横向复制成功商品"
    - "开始记录单位经济数据"
  handoff: "建议切换到 xianyu-growth-system 进行规模化增长"
```

## 每周复盘7问

1. 哪个商品最赚钱？
2. 哪个商品最浪费时间？
3. 哪个商品咨询最多但成交最低？
4. 哪个商品毛利最高？
5. 哪个商品最容易被复制？
6. 哪个用户需求最近出现频率增加？
7. 下周应该停止什么？

第7个最重要：优秀运营不是每周增加10件事，而是每周删掉5件无效事。

## 商品四象限

每周做一次商品淘汰：

| | 高转化 | 低转化 |
|---|---|---|
| **高曝光** | 爆款：补货/扩标题/增相似商品 | 优化：优先改主图->价格->文案 |
| **低曝光** | 隐藏爆款：优化标题/关键词 | 淘汰：直接淘汰，不恋战 |

---

## 停止清单

新手必须记住：

- 不为了上新而上新
- 不为了曝光追求低价
- 不迷信所谓闲鱼算法秘籍
- 不没算利润就扩张
- 不没验证就囤货
- 不一开始就自动化铺货
- 不追逐所有热门商品
- 不和别人无限价格战
- 不隐瞒商品缺陷
- 不把 GMV 当利润
- 不把订单量当商业价值
- 不把自己变成客服机器人

---

## 最终交接

当用户达到以下条件时，建议切换到 `xianyu-growth-system`：

- 连续3周有稳定成交
- 找到至少1个可重复成交的商品
- 每单贡献利润 > ¥20
- 有基本的数据记录习惯
- 闲气值 > 81分（无违规限制）

> 以上条件与上方"放大决策"中的 `conditions_met` 保持一致。达到这些条件意味着已验证了可重复模型，可以进入规模化增长阶段。

```
xianyu-side-hustle（0 -> 1）已完成使命
        ↓
xianyu-growth-system（1 -> N）接棒
```
