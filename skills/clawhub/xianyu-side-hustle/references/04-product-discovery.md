# P3 从赛道到具体商品

## 目标

从已选赛道中，找到具体的、可执行的商品。

不是"卖宠物用品"，而是"猫砂垫防带出硅胶垫"。

---

## 商品发现流程

```
赛道（如"Mac桌面配件"）
  ↓
品类拆解
  ↓
具体商品
  ↓
购买场景
  ↓
候选清单
```

---

## 品类拆解方法

以"Mac桌面配件"为例：

```
Mac桌面配件
├── 支架类（笔记本支架/显示器支架/平板支架）
├── 收纳类（桌面收纳/线材收纳/键盘收纳）
├── 理线类（理线器/理线带/理线盒）
├── 保护类（键盘膜/屏幕保护/外壳）
├── 扩展类（扩展坞/转接头/集线器）
├── 照明类（桌面灯/屏幕挂灯）
├── 输入类（鼠标/触控板/键盘）
└── 散热类（散热架/散热垫）
```

每个子品类继续拆到具体商品。

## 7种适合新手的商品类型

### 1. 强搜索型
用户已知道要什么（"罗技MX Master 3S"）。
优势：购买意图明确。

### 2. 长尾型
"Mac mini M2 双屏支架" 而非 "电脑支架"。
搜索量小但竞争少。

### 3. 信息差型
用户不知道去哪里买的特殊配件。

### 4. 解决问题型
不卖"收纳盒"，卖"出租屋衣柜空间不够的收纳方案"。

### 5. 有明显价格差
货源¥35，闲鱼成交¥79，扣成本后仍有 ≥30% 毛利。

### 6. 非标品
二手/小众/个性化，淘宝不好找同款。

### 7. 服务型
AI PPT / 设计 / 咨询，零库存高毛利。

## 禁售品类快速排除清单

确定候选商品后，先快速过一遍排除：

| 检查项 | 如果是 -> 直接淘汰 |
|--------|-------------------|
| 属于13类禁售品？ | 是 -> 淘汰 |
| 需要资质但没有？ | 是 -> 淘汰 |
| 涉及品牌但没有授权？ | 是 -> 淘汰 |
| 品牌空瓶/化妆品空瓶？ | 是 -> 淘汰（制假高风险品） |
| 假冒/山寨/仿品？ | 是 -> 淘汰 |

> 完整禁售品类速查表和限售品类资质要求详见 `references/00-platform-rules.md`。拿不准能不能卖的，默认不能卖。

## 商品筛选标准

新手版简化筛选（回答5个问题）：

| 问题 | 通过标准 | 不通过 |
|------|---------|--------|
| 有人买吗？ | 闲鱼有同类商品在卖 | 搜不到同类 |
| 一单能赚多少？ | ≥ ¥20/单 | < ¥20 |
| 需要投入多少？ | ≤ ¥200首批 | > ¥500首批 |
| 会不会大量退货？ | 低售后风险 | 服装/食品/易碎 |
| 别人是不是已经卷死了？ | 同行<20个 | 同行>50个且价格战 |

通过5项 -> A：立即测试
通过3-4项 -> B：观察
通过<3项 -> C：不要做

---

## 新手第一轮策略

**不允许新手一开始发布100个商品。**

第一轮只测试 5~10 个 SKU。

原因：现在的目标不是赚钱最大化，而是找到第一个"能成交"的模型。

```
10个候选 -> 筛5个 -> 上架测试 -> 留2-3个 -> 放大
```
