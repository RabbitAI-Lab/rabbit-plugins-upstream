# P4 新手简化验证

## 目标

用最简单的方式验证商品值不值得做。

新手不需要复杂的评分公式，只需要回答6个问题。

---

## 6问验证法

### Q1：有人买吗？

检查方式：
- 闲鱼搜索关键词，看有没有同行在卖
- 看同行的"想要"数量
- 看同行最近成交记录

**具体操作步骤**：
1. 打开闲鱼 App，在顶部搜索框输入你的商品关键词（如"MacBook支架"）
2. 搜索结果页面上方有"筛选"，按"最新发布"排序，看近期有没有新同行上架
3. 浏览前 3 页结果，数一数有多少个在卖同类商品的卖家
4. 点进几个同行的商品页，看"想要"人数（≥3 人想要说明有需求信号）
5. 如果能看到"已售"或"评价"记录，说明有成交

通过：有3个以上同行在卖，且有成交信号
不通过：搜不到同类商品（可能是真没需求，也可能是机会--需进一步判断）

### Q2：一单能赚多少钱？

简化计算：

```
售价 - 进货价 - 运费 - 包材 - 服务费(成交价×0.6%) = 粗略利润
```

通过：粗略利润 ≥ ¥20/单
不通过：< ¥20/单（新手不值得做，时间成本太高）

### Q3：需要投入多少钱？

通过：首批测试 ≤ ¥200
不通过：> ¥500（新手不应冒这个险）

### Q4：会不会大量退货？

通过：不易碎、不易坏、不易争议
不通过：服装（尺码）、食品（保质期）、易碎品、电子品（功能争议）

### Q5：别人是不是已经卷死了？

通过：同行 < 20个，或同行商品页质量差
不通过：同行 > 50个且价格已降到最低

**具体操作步骤**：
1. 在闲鱼搜索你的商品关键词
2. 浏览前 5 页结果，大致数一下同行数量（每页约 20 个结果）
3. 如果前 5 页超过 100 个结果且价格区间很窄（最高价不超过最低价的 1.5 倍），说明已经卷死了
4. 点进 3-5 个同行的商品页，看图片质量和文案水平。如果大多拍得粗糙、文案简单，说明同行质量不高，你有差异化空间

### Q6：这个商品在闲鱼能不能卖？

检查方式：
- 确认不在13类违禁品中（详见 `references/00-platform-rules.md`）
- 如果需要资质（出版物/食品/门票等），确认你有
- 涉及品牌的，确认不是假冒/侵权商品

通过：商品合规，可以发布
不通过：属禁售/限售/侵权 -> 换商品

## 新手防错

### 常见错误1：未验证就囤货

```
新手："这个商品利润50%，我要进100件。"
Skill：NO。先测试5件。
原因：你还没验证需求，100件的库存风险太大。
```

### 常见错误2：盲目跟风

```
新手："别人卖得很好，我也卖。"
Skill：先检查5个问题。
- 有没有人买？
- 你能赚多少？
- 你的货源在哪？
- 会不会退货？
- 同行是不是已经卷死了？
```

### 常见错误3：只看利润不看风险

```
新手："这个利润200%，肯定能赚。"
Skill：检查售后风险和供应稳定性。
高利润往往伴随高风险。
```

## 验证通过后的行动

验证通过 -> 进入 P5 找货源
验证不通过 -> 回到 P3 重新选商品
部分通过 -> 记录问题，观察或调整后重试
