# 闲鱼平台规则与算法原理

> 本文件是所有阶段的底层约束。任何选品、发布、客服、履约决策都必须先通过本文件的合规检查。

---

## 闲鱼社区三大底线

闲鱼是个闲置交易社区，规则都围绕三句话：

| 底线 | 大白话 | 对新手意味着什么 |
|------|--------|-----------------|
| **真实** | 你得是真人在做真交易 | 实名认证是必须的。发布信息、和买家聊天、成交发货都要真实。答应的事就得做到 |
| **安全** | 不卖违法东西，不骗钱，不泄露隐私 | 钱走平台担保交易，别私下转账。买家电话地址别到处发 |
| **平等** | 买卖双方地位平等，公平自愿 | 不强买强卖，不欺负买家，遇到纠纷讲道理别动手动脚 |

## 账号安全红线

| 要求 | 说明 |
|------|------|
| 实名认证 | 必须完成实名/实人认证，这是交易基础 |
| 支付宝绑定 | 绑定支付宝用于收款和担保交易 |
| 芝麻信用 | 建议授权芝麻信用，提升买家信任度 |
| 一人一号 | 禁止大量注册账号，违规扣100分 |

> **对新手意味着什么**：开店前先把实名认证和芝麻信用搞定，这是交易信任的根基。千万别借号、买号、开一堆小号——一个号出事，你名下其他号也可能被连带处置。

## 限售品类（需资质）

| 品类 | 资质要求 | 限制 |
|------|---------|------|
| 出版物（图书等） | 需扫描ISBN编码发布；经营性卖家需出版物经营许可证 | 无许可证不得经营性销售 |

> **对新手意味着什么**：上面这些品类要么需要办证、要么有数量限制，新手阶段一律跳过。先做不需要资质的品类，等有经验了再考虑。

## 信息发布规范

### 标题规则

- 禁止关键词堆砌（同义词反复排列影响搜索体验）
- 禁止与商品无关的流量词（如"全网最低""老板疯了"）
- 禁止夸大宣传词汇（如"绝对正品""100%最好"）
- 禁止感叹号堆砌
- 标题须与商品实际信息一致

### 图片规则

- 禁止二维码、联系方式、外部链接
- 禁止水印（闲鱼官方水印除外）
- 禁止纯文字图（无实物图片）
- 禁止盗用他人图片
- 禁止使用与商品无关的网图

### 描述规则

- **如实描述义务**：必须如实披露商品品牌、型号、现状、维修记录、瑕疵
- 禁止导流信息（第三方链接、二维码、微信号、手机号）
- 禁止虚假宣传（夸大功效、虚构参数、伪造认证）
- 禁止诱导站外交易

### 类目规则

- 必须选择正确类目，错放类目会被降权
- 类目与商品实际属性不匹配将影响搜索排序

## 交易规则

### 发货时效

- 卖方应在约定时间内发货
- 未征得买方同意不得合并包裹
- 不得包含物流禁运品

### 退货退款规则

- **签收后不支持无理由退货**（双方另有约定的除外）
- 收件人应场检视表面是否一致，发现问题可拍照拒签
- 卖方未如实披露瑕疵/维修记录/质量问题的，交易作退货退款处理
- 质量问题支持退货退款；致使交易目的不能实现的，退货风险由卖方承担

### 争议处理

- **受理期限**：订单确认收货前或超时打款时限内提出
- 举证责任：卖方需证明已如实描述、按约定发货
- 平台介入：双方协商不成可申请平台介入裁定
- 运费：争议责任归属买方则买方承担退货运费，归属卖方则卖方承担

### 虚拟商品/服务类交易特殊规则

- 虚拟商品：交付前风险由卖方承担，交付后根据举证判定
- 服务类交易：卖方已产生实质服务行为的，买方要求退款需协商一致
- 定制物品：买方无理由退款需赔偿卖方损失（最高不超过订单金额）
- 当面交易：买卖双方自行承担风险

> **对新手意味着什么**：闲鱼个人闲置不支持无理由退货，所以描述必须写清楚所有瑕疵。发货前拍照留证是保护自己的关键。虚拟商品/服务类交易，买家一旦确认收到/验收，你的风险就小很多，所以一定要让买家确认。

## 卖方软件服务费

### 费率表

| 费种 | 费率 | 触发条件 |
|------|------|---------|
| 基础软件服务费 | 0.6% | 所有成交订单 |
| 软件服务费（基础门槛） | +1% | 当月累计成交>10件且累计金额>10000元，超出部分收取 |
| 软件服务费（手机品类门槛） | +1% | 当年手机品类累计成交>6笔，超出部分收取 |
| 鱼小铺 | 1.6% | 开通鱼小铺的卖方每笔订单（0.6%基础+1%软件），不享受门槛优惠 |

### 关键规则

- 成交额 = 确认收货时交易订单的交易额（含买家实付款、运费、平台红包/补贴；不含闲鱼币、卖方出资红包/补贴）
- 同一笔订单最多收取1.6%（基础0.6% + 软件1%）
- 确认收货前退款：不收取服务费
- 确认收货后退款：已划扣的服务费不退还
- 由支付服务商从买家支付的订单款项中实时划扣

### 对利润的影响

> 新手定价时必须将0.6%基础服务费纳入成本计算。月销售额超过10000元后需额外预留1%费用。

## 经营性行为界定

### 认定标准（满足任一即被认定为经营行为）

1. 已取得营业执照/许可证等经营主体资格，或公示自我经营声明
2. 使用一手货源/固定货源/有售后/七天无理由退货/多库存/多规格等经营性描述，且符合以下任一：
   - 在售物品>30件且品类<3类
   - 同一型号/款式频繁反复售出5次以上
   - 年交易笔数>104笔且每月至少3笔
   - 年销售额>10万元
3. 特殊场景（收藏品/潮玩/数码/搬家/明星闲置等）不直接认定，平台综合判定

### 经营者额外义务

- 依法办理市场主体登记（豁免情形除外）
- 如实登记身份/经营地址/联系方式/行政许可
- 在个人主页公示营业执照/经营地址/联系方式
- 如实全面披露商品品牌/型号/现状/维修记录/瑕疵
- 履行七日无理由退货等经营者义务

> **对新手意味着什么**：如果你越做越大，在售超过30件且品类集中、同款反复卖出、年交易超104笔——闲鱼会认定你是"经营者"，要求你办营业执照。到这一步前，先评估自己是否准备好了承担经营者义务。详见 `references/10-review-scale.md` 中的经营性行为预警。

## 闲气值与违规处罚

### 闲气值体系

- 满分100分，当前闲气值 = 100分 - 近90天违规扣分总和

### 处罚阶梯

| 闲气值 | 处罚 |
|--------|------|
| 81-100分 | 无限制 |
| 61-80分 | 下架所有商品、7天内无法发布/互动、限制主页展示7天 |
| 31-60分 | 下架所有商品、14天内无法发布/互动/购买、限制展示14天 |
| 1-30分 | 删除所有商品、21天内无法发布/互动/购买、限制展示21天 |
| 0分 | 删除所有商品、永久限制发布/互动/购买、永久限制展示 |

### 关键违规类型及扣分

| 违规类型 | 扣分 |
|---------|------|
| 危及交易安全（虚假发货/诱导定金/诈骗） | 扣100分 |
| 不当注册（大量注册） | 扣100分 |
| 不当使用账号（租借/盗取/转让/囤积） | 扣100分 |
| 扰乱平台秩序（刷单/刷赞/刷粉/数据造假） | 严重扣40分，特别严重扣100分 |
| 出售假冒盗版商品 | 严重扣20分，特别严重扣100分 |
| 规避准入要求（无资质发布） | 严重扣20分，特别严重扣100分 |
| 描述不当（商品与描述不符/未披露瑕疵） | 严重扣20分，特别严重扣100分 |
| 违背承诺（未按约定提供服务） | 扣20分，严重扣40分 |
| 引导站外交易（第三方链接/二维码/诱导跳转） | 一般扣1分，严重扣20分，特别严重扣100分 |
| 骚扰他人（恐吓/辱骂/人身攻击） | 一般扣1分，严重扣20分，特别严重扣100分 |
| 泄露用户信息 | 严重扣20分，特别严重扣100分 |

> **对新手意味着什么**：闲气值满分100，低于81分你的商品就会被下架、无法发布。最容易被扣分的操作：刷单（扣40-100分）、引导站外交易（扣1-100分）、隐瞒瑕疵被投诉（扣20-100分）。守住这三条底线，你的闲气值就不会出问题。一个号被处罚，你名下其他号也可能被连带处置。

## 算法原理（新手版）

> **合规边界**：以下内容仅用于帮助新手理解平台公开规则，提供真实、合规的商品与服务。任何通过虚假数据、刷量、账号操控等方式影响平台算法的行为均属违规，本系统明确禁止。

### 搜索排序

闲鱼搜索结果排序基于以下因素：

- **关键词匹配**：使用倒排索引 + 神经网络向量匹配召回商品
- **商品特征**：标题/描述/类目与搜索关键词的相关性
- **用户行为**：用户搜索关键词特征、使用习惯影响个性化结果
- **相关性模型**：保障结果与搜索关键词相关
- **多样性打散**：避免同类型内容过度集中
- 用户可手动选择按"信用"/"价格"/"最近活跃"/"离我最近"排序

> 新手启示：标题关键词准确 > 关键词数量堆砌。选对类目很重要。

### 个性化推荐

- 收集用户浏览、搜索记录、设备信息、服务日志
- 通过算法模型预测人群偏好特征
- 基于偏好特征匹配商品并排序
- 根据用户浏览行为实时反馈调整推荐
- 引入多样性打散机制，避免同类型内容过度集中
- 用户可在"设置-隐私-个性化内容推荐"中管理

> 新手启示：新品发布后，系统会根据标题和类目匹配潜在买家。准确的标题和类目比铺量更重要。

### 内容安全审核

- 对文本/图片/音频/视频进行安全风险识别
- 使用深度学习/知识图谱推理/时序模型/融合模型
- 高置信度信息算法直接审核处理，低置信度引入人工审核
- 覆盖商品/评价/留言/圈子等所有信息发布场景

> 新手启示：不要尝试打擦边球。AI审核会自动识别违规内容并降权或下架。
