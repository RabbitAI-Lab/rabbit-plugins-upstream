# P1 五种副业模型与路线选择

## 五种副业模型

| 模型 | 启动成本 | 风险 | 适合人群 | 推荐度 |
|------|---------|------|---------|--------|
| M1 二手闲置 | 0元 | 极低 | 所有新手 | ★★★★★ |
| M2 低库存 | 100-500元 | 低 | 有少量启动资金 | ★★★★ |
| M3 一件代发 | 0-100元 | 中 | 有货源渠道 | ★★★ |
| M4 数字产品 | 0元 | 低 | 有创作能力 | ★★★★ |
| M5 技能服务 | 0元 | 低 | 有专业技能 | ★★★★★ |

---

## M1 二手闲置

**特点：** 0成本启动，先跑通流程。

来源：
- 自己闲置
- 家庭闲置
- 朋友闲置（帮别人代卖）
- 二手平台低买高卖（需专业知识）

适合：新手第一桶金。

关键：不要想着靠这个赚大钱，目标是 **完成一次完整交易**。

---

## M2 低库存

**特点：** 先买 3~10 件测试，验证需求后再补货。

适合：有一点启动资金（500元以上）的人。

关键：**严格控制首批采购量**，即使利润看起来很好，也先测 5 件。

防错规则：
```
IF 新手 AND 首次采购 > 10件
  -> 阻止，建议先测3-5件
```

**经营性行为预警**：如果同一款商品反复卖出5次以上，或在售超过30件且品类集中，闲鱼可能认定你为经营性卖家，需办理营业执照。详见 `references/00-platform-rules.md`。

> **服务费提醒**：每笔成交订单扣除0.6%基础服务费，月销售额超10000元且超10件的部分额外扣1%。定价时需预留这部分成本。

---

## M3 一件代发

**特点：** 不需要囤货，客户下单后从供应商发货。

风险：中等。核心问题是供应商稳定性。

常见货源：1688、拼多多、义乌购。

关键风险：
- 供应商断货 -> 你的闲鱼已有咨询
- 供应商涨价 -> 利润消失
- 发货慢 -> 买家退款
- 质量不可控 -> 差评

**必须先验证供应商，再上架。**

**经营性行为预警**：一件代发容易被认定为经营性卖家（一手货源/多库存/固定货源），如果交易量达到经营性标准，需办理营业执照并公示。详见 `references/00-platform-rules.md`。

---

## M4 数字产品

**特点：** 边际成本几乎为零，一次制作多次出售。

类型：
- 模板（PPT/Notion/Excel）
- 素材（设计素材/摄影预设）
- 教程（技能教程/行业指南）
- 工具（小工具/脚本）
- 资料整理（行业报告/学习资料）

风险：合规、版权、同质化。

关键：确保你有权出售，不侵权。

**虚拟商品交易争议规则**：虚拟商品交付买家前风险由卖方承担，交付后按举证判定。买家一旦确认收到并能使用，你的风险大幅降低。务必在聊天中让买家确认"收到了，能用"。详见 `references/00-platform-rules.md`。

---

## M5 技能服务

**特点：** 不需要库存，毛利可以非常高。

类型：
- PPT制作 / PS设计 / 视频剪辑
- AI工作流 / Prompt优化 / Skill开发
- 文案写作 / 简历优化 / 翻译

优点：零库存，高毛利。

缺点：容易变成人肉外包，时间换钱。

关键：**卖结果，不卖工具。**

错误定位：`AI写作服务`
正确定位：`30分钟帮你生成一篇可直接发布的公众号文章`

## 副业路线规划

根据用户画像，生成阶段性路线：

### 路线 A：零成本起步

```
闲置代卖（验证流程）
  ↓
二手商品（学习选品）
  ↓
低库存（验证需求）
  ↓
长尾商品（建立优势）
```

### 路线 B：有资金起步

```
低库存（验证需求）
  ↓
长尾商品（建立优势）
  ↓
SKU矩阵（规模化）
```

### 路线 C：技能起步

```
技能服务（验证付费意愿）
  ↓
标准化服务（提高效率）
  ↓
数字产品（边际成本下降）
```

### 路线 D：有供应链

```
一件代发（验证需求）
  ↓
低库存（控制质量）
  ↓
规模化（扩大品类）
```
