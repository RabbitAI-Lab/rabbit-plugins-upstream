# P2 赛道选择模型

## 核心原则

不要让 AI 直接说"卖手机壳"。

要先建立 **赛道选择模型**，从需求、利润、竞争等维度评分，产出 Top 10 候选方向。

---

## 赛道评分维度

| 维度 | 权重 | 说明 |
|------|------|------|
| 需求 | 20% | 有多少人搜索/需要 |
| 利润 | 20% | 一单能赚多少 |
| 竞争 | 15% | 同行多不多（越少越好） |
| 供应 | 10% | 货源好不好找 |
| 售后 | 10% | 退货/纠纷风险（越低越好） |
| 客单价 | 10% | 单笔金额大小 |
| 复购 | 5% | 会不会重复购买 |
| 内容难度 | 5% | 图片/文案好不好做 |
| 物流难度 | 5% | 好不好发货 |

---

## 新手友好赛道特征

优先推荐具备以下特征的赛道：

1. **强搜索型** - 用户知道自己要什么（如具体型号配件）
2. **长尾型** - 搜索量小但竞争少，购买意图强
3. **信息差型** - 用户不知道去哪里买
4. **低售后** - 不容易退货/纠纷
5. **轻物流** - 体积小、不易碎、好发货

---

## 新手应避免的赛道

| 赛道 | 原因 |
|------|------|
| 服装 | 尺码/色差/面料问题多，退货率高 |
| 美妆 | 真假争议、保质期、皮肤过敏风险 |
| 食品 | 保质期、食品安全、合规风险 |
| 大件家具 | 物流成本高、运输损坏风险 |
| 热门标品 | 竞争激烈，价格战 |
| 假货风险高的品牌 | 法律风险 |
| 药品/医疗器械/保健品 | 需资质，无资质发布属违规 |
| 出版物（批量经营） | 需出版物经营许可证 |
| 演出门票 | 需合法来源，黄牛票违规 |
| 品牌仿品/山寨货 | 假冒侵权，扣20-100分 |
| 账号/外挂/破解软件 | 属禁售品，扣分甚至封号 |

## 平台合规红线品类

> 以下品类在闲鱼禁止销售或需特殊资质，新手一律不碰。完整禁售品类速查表和限售品类资质要求详见 `references/00-platform-rules.md`。

**新手快速判断**：拿不准能不能卖的，默认不能卖。特别注意品牌空瓶/化妆品空瓶属制假高风险品，也在禁售范围内。

---

## 品类合规检查步骤

选好赛道后，发布前必须走一遍合规检查：

```
Step 1：查禁售表 -> 你的品类在不在13类违禁品里？
Step 2：查限售表 -> 需不需要资质？你有吗？
Step 3：查品牌侵权 -> 涉及品牌商品，你有授权吗？
Step 4：查经营性风险 -> 这个品类会不会让你快速触发经营性行为认定？
```

任何一步不通过 -> 换赛道，不冒险。

---

## 赛道拆解方法

从大市场找到小需求：

```
大市场（如"宠物"）
  ↓ 太大，竞争激烈
细分市场（如"猫"）
  ↓ 还是太大
具体场景（如"养猫"）
  ↓ 继续拆
具体需求（如"猫砂周边"）
  ↓ 继续
具体商品（如"猫砂垫防带出"）
```

**目标：找到一个具体购买场景。**
