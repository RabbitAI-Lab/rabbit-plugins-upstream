# P0 副业启动与用户画像

## 目标

建立用户画像，判断适合哪种副业模式。

不急着找商品，先搞清楚"你是谁"。

---

## 账号合规前置检查

在开始之前，确认账号基础条件已满足：

| 检查项 | 说明 | 未通过怎么办 |
|--------|------|-------------|
| 实名认证 | 必须完成实名/实人认证，否则无法正常发布和交易 | 立即在闲鱼设置中完成认证 |
| 芝麻信用授权 | 建议授权，提升买家信任度 | 在闲鱼设置-账号与安全中授权 |
| 支付宝绑定 | 绑定支付宝用于收款和担保交易 | 确保支付宝实名与闲鱼一致 |
| 新号熟悉期 | 新注册账号先花时间熟悉平台功能、社区公约和交易流程，再开始发布商品 | 新手先了解规则再交易，避免因不熟悉平台规则产生违规；新号无需特殊操作，正常合规使用即可 |

> **新手提示**：如果账号还没完成实名认证，先停下来去搞定。没有认证的号什么都做不了。

## 用户画像采集

询问以下问题（可分批问，不要一次全部抛出）。

**用口语化方式提问，不要直接抛出专业术语**：

| 内部字段 | 问用户的口语 | 选项 |
|---------|------------|------|
| budget | "你准备花多少钱开始做？" | 0元 / 500元 / 1000元 / 5000元 |
| daily_hours | "你每天能腾出多少时间？" | 半小时 / 1小时 / 2小时 / 全职 |
| willing_inventory | "你愿意先买一些货放着卖吗？" | 愿意 / 不愿意 |
| willing_face | "你愿意拍照露脸吗？" | 愿意 / 不愿意 |
| has_supply_chain | "你有没有认识的货源或渠道？" | 有 / 没有 |
| has_skills | "你有什么拿手的技能吗？比如做PPT、修图、写文章" | PPT / PS / 视频 / 写作 / AI / 设计 / 没有 |
| has_resources | "你手边有没有可以卖的东西？比如闲置、渠道、人脉" | 闲置物品 / 渠道 / 人脉 / 没有 |
| risk_tolerance | "如果亏了一点钱你能接受吗？" | 完全不能 / 亏个几十可以 / 亏几百也行 |
| target_income | "你期望通过副业每月增加多少收入？（仅作规划参考，不代表收益承诺）" | 少量补贴 / 覆盖日常开支 / 更多 |

**建议分 2-3 轮问完**：
- 第 1 轮：预算 + 时间 + 有没有技能/资源（3 个问题）
- 第 2 轮：根据第 1 轮回答，追问相关项（如"有技能"->问具体什么技能）
- 第 3 轮：补齐剩余项（风险偏好、目标收入等）

## 画像判断逻辑

根据用户画像自动判断推荐路线：

### 预算 0 元 + 时间少

```
推荐：闲置代卖 -> 二手商品 -> 低库存
理由：零成本启动，先验证能卖东西
```

### 预算 1000+ + 每天 2 小时

```
推荐：低库存 -> 长尾商品 -> SKU矩阵
理由：有启动资金，可以小规模测试
```

### 有设计/写作/AI 技能

```
推荐：技能服务 -> 标准化服务 -> 数字产品
理由：零库存，高毛利，技能可复用
```

### 有供应链资源

```
推荐：一件代发 -> 低库存 -> 规模化
理由：货源优势，可以跳过找货阶段
```

### 什么都不懂 + 什么都没有

```
推荐：二手闲置 -> 闲鱼熟悉流程 -> 再选模型
理由：先跑通一次完整交易，建立信心
```

```yaml
  1. 家里闲置的数码/家居/书籍

what_next: "我会帮你筛掉7个，留3个最优的"
```

## 新手心理建设

第一次做闲鱼的人通常有三种心态，Skill 需要识别并引导：

| 心态 | 表现 | 引导 |
|------|------|------|
| 急于赚钱 | "怎么快速月入过万" | 降温：先完成第一笔利润再说 |
| 害怕亏钱 | "万一卖不出去怎么办" | 安心：从零成本闲置开始 |
| 完美主义 | "图片还没做好不敢发" | 推进：先发布再优化，完成 > 完美 |
