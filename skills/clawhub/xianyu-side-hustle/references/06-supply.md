# P5 货源与供应商验证

## 核心原则

不只是告诉用户"去1688找"。

要教用户 **怎么验证供应商**。

> 先测试，不囤货。

---

## 货源渠道

| 渠道 | 适合 | 特点 |
|------|------|------|
| 1688 | 实物商品 | 批发价低，但需要验证质量 |
| 拼多多 | 实物商品 | 可一件代发，价格透明 |
| 闲鱼 | 二手/信息差 | 低买高卖，需要专业知识 |
| 自有闲置 | M1模型 | 零成本 |
| 自己制作 | 数字产品/服务 | 零成本，高毛利 |
| 线下批发 | 本地商品 | 可看货，但需要跑市场 |

---

## 供应商验证清单

找货源时，必须检查：

```yaml
supplier_check:
  price: ""              # 价格是否合理？对比3家以上
  moq: ""                # 最小起订量是多少？新手能否接受？
  shipping_speed: ""     # 发货速度？24h/48h/72h？
  stock: ""              # 库存充足吗？会不会断货？
  reviews: ""            # 评价如何？有没有差评？
  repeat_rate: ""        # 回头率？高回头率=靠谱
  after_sales: ""        # 售后政策？支持退换吗？
  real_photos: ""        # 能提供实拍图吗？
  packaging: ""          # 包装怎么样？会影响评价吗？
  logistics: ""          # 物流方式/费用？
  authorization_check: "" # 品牌商品：供应商是否有品牌授权？能否提供授权证明？
```

---

## 供应商验证流程

### Step 1：找3家以上供应商对比

不要只找一家。至少对比3家，选择综合最优。

### Step 2：小批量试单

先下 3~5 件的试单，验证：
- 发货速度
- 商品质量
- 包装质量
- 实物与描述是否一致

### Step 3：确认稳定性

试单通过后，不要马上大批采购。先确认：
- 库存是否稳定
- 价格是否稳定
- 能否持续供货

### Step 4：建立备选

始终准备 1~2 个备选供应商，防止断货。

---

## 新手防错

### 错误1：只看价格不看质量

```
新手："这家最便宜，就选这家。"
Skill：检查评价和回头率。最便宜的可能是质量最差的。
```

### 错误2：大批量采购

```
新手："这家便宜，我直接进50件。"
Skill：NO。先试3件，验证质量和服务。
```

### 错误3：不确认库存就上架

```
新手："我已经上架了，但供应商说没货了。"
Skill：上架前必须确认供应商有库存。
```
