## TC3 法律文书域范本

### 一、领域知识要点

- 合同八要素：主体、标的、数量质量、价款、履行期限地点方式、违约责任、争议解决、生效条件
- 条款起草原则：定义前置、权利义务对称、违约后果可计算、争议解决唯一
- 常见合同类型要点：劳动（试用期/竞业/补偿）、买卖（风险转移/验收）、租赁（转租/维修）、服务（交付标准/验收）、NDA（保密范围/期限/例外）
- 诉讼文书结构：当事人信息、诉讼请求、事实与理由、证据清单、落款
- 法律意见书结构：委托事项、事实摘要、法律分析、结论意见、风险提示、免责声明
- 条款效力：违反法律强制性规定无效；格式条款须提示说明

### 二、判定标准

- 主体信息须完整可核验
- 权利义务须对称，单方权利须有对价
- 违约与争议解决条款须可执行
- 金额、期限、比例须具体，禁止"另行协商"占位

### 三、范本结构

1. 首部（主体/鉴于）
2. 定义条款
3. 权利义务条款
4. 价款与支付
5. 违约责任
6. 争议解决
7. 附则与签署

### 四、常见失范

- 关键条款留空待议
- 违约责任无计算方式
- 争议解决条款同时约定诉讼与仲裁
- 定义术语前后不一致

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 合同全文、条款清单、风险提示、待确认项 |
| 本域产出 | 合同文本；协议模板+填写说明；法律意见书；诉讼文书；律师函/催告函；条款修订建议书 |
| 下游可用 | 条款修订建议书 |

### 六、交付自检

交付前逐项打勾，任一项不成立即返工：

- [ ] 主体信息须完整可核验
- [ ] 权利义务须对称，单方权利须有对价
- [ ] 违约与争议解决条款须可执行
- [ ] 金额、期限、比例须具体，禁止"另行协商"占位

同时排除以下失范：

- [ ] 已排除：关键条款留空待议
- [ ] 已排除：违约责任无计算方式
- [ ] 已排除：争议解决条款同时约定诉讼与仲裁
- [ ] 已排除：定义术语前后不一致

### 七、执行卡（以「合同起草」为例）

**开工前备齐**：合同全文、条款清单、风险提示、待确认项

**可选补充**：交易背景、双方主体信息、商务条款

**按序执行**：

1. 定合同类型
2. 搭条款框架
3. 填商务条款
4. 写通用条款
5. 复核

**交付前核对**：条款须可执行；空白项须标 [待确认]；须给风险提示

**成品须符合**：合同文本

### 八、成品骨架

按「合同文本」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 合同文本

## 1. 首部（主体/鉴于）
## 2. 定义条款
## 3. 权利义务条款
## 4. 价款与支付
## 5. 违约责任
## 6. 争议解决
## 7. 附则与签署
```

**齐备要求**：必选组件「合同全文、条款清单、风险提示、待确认项」须全部落位；约束「条款须可执行；空白项须标 [待确认]；须给风险提示」须逐条成立；可选「交易背景、双方主体信息、商务条款」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
