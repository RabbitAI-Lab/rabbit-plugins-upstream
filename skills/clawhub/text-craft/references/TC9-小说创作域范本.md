## TC9 小说创作域范本

### 一、领域知识要点

- 三幕式结构：建置（25%）、对抗（50%）、解决（25%）；关键节点：激励事件、第一转折、中点、第二转折、高潮
- 网文节奏：黄金三章（开局冲突/金手指/悬念）、每章钩子、爽点密度、章节字数（2000-3000）
- 人物弧光：起始信念 → 压力测试 → 信念动摇 → 转变/坚守
- 世界观构建：规则体系、势力版图、力量层级、经济与语言一致性
- 叙事视角：第一人称/第三人称限知/全知；视角切换规则
- 伏笔管理：埋设章节、回收章节、未回收清单

### 二、判定标准

- 角色行动须符合其动机与已知信息，不得为推进剧情而降智
- 世界观规则一旦设定不得随意打破
- 每章须有进展与钩子，不得纯过渡
- 伏笔须有回收计划

### 三、范本结构

1. 故事梗概
2. 人物小传与关系图
3. 世界观设定
4. 分卷分章大纲
5. 章节正文
6. 伏笔台账

### 四、常见失范

- 金手指无限制导致失去张力
- 角色动机前后不一致
- 中段塌陷（无冲突推进）
- 设定堆砌打断叙事

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 核心设定、规则体系、势力/层级、冲突源、禁忌项 |
| 本域产出 | 设定集；分卷分章大纲；章节正文；角色档案+关系图；节奏规划表；伏笔台账+一致性报告 |
| 下游可用 | 伏笔台账+一致性报告 |

### 六、交付自检

交付前逐项打勾，任一项不成立即返工：

- [ ] 角色行动须符合其动机与已知信息，不得为推进剧情而降智
- [ ] 世界观规则一旦设定不得随意打破
- [ ] 每章须有进展与钩子，不得纯过渡
- [ ] 伏笔须有回收计划

同时排除以下失范：

- [ ] 已排除：金手指无限制导致失去张力
- [ ] 已排除：角色动机前后不一致
- [ ] 已排除：中段塌陷（无冲突推进）
- [ ] 已排除：设定堆砌打断叙事

### 七、执行卡（以「故事设定与世界观」为例）

**开工前备齐**：核心设定、规则体系、势力/层级、冲突源、禁忌项

**可选补充**：题材定位、读者画像

**按序执行**：

1. 定题材
2. 设核心冲突
3. 建规则
4. 画势力
5. 列禁忌

**交付前核对**：规则须自洽且可被打破以产生张力

**成品须符合**：设定集

### 八、成品骨架

按「设定集」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 设定集

## 1. 故事梗概
## 2. 人物小传与关系图
## 3. 世界观设定
## 4. 分卷分章大纲
## 5. 章节正文
## 6. 伏笔台账
```

**齐备要求**：必选组件「核心设定、规则体系、势力/层级、冲突源、禁忌项」须全部落位；约束「规则须自洽且可被打破以产生张力」须逐条成立；可选「题材定位、读者画像」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
