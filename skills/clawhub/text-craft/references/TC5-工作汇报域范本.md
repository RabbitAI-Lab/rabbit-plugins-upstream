## TC5 工作汇报域范本

### 一、领域知识要点

- 周报结构：本周产出（可量化）、问题与阻塞、下周计划、需协调事项
- 工作总结结构：目标-行动-结果-复盘-下一步
- 成果量化三法：绝对数（完成 8 项）、对比数（较上周 +30%）、占比（覆盖 90%）
- 阻塞分级：需上级决策 / 需跨部门协调 / 自行可解
- 汇报语气：陈述事实 + 给出判断 + 提出请求，不铺陈过程

### 二、判定标准

- 每条产出须有结果或进展证据，禁止"推进中"
- 阻塞须标明需要谁做什么
- 总结须含未达成项与原因
- 计划须有时限

### 三、范本结构

1. 本期产出（量化）
2. 问题与阻塞（含请求）
3. 下期计划
4. 需协调事项
5. 数据附件

### 四、常见失范

- 只列动作不列结果
- 只报喜不报忧
- 阻塞不指明需要谁支持
- 计划全是"继续推进"

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 产出清单（含量化）、问题与阻塞、下周计划 |
| 本域产出 | 周报/日报；工作总结；工作台账 + 量化汇总 |
| 下游可用 | 工作台账 + 量化汇总 |

### 六、交付自检

交付前逐项打勾，任一项不成立即返工：

- [ ] 每条产出须有结果或进展证据，禁止"推进中"
- [ ] 阻塞须标明需要谁做什么
- [ ] 总结须含未达成项与原因
- [ ] 计划须有时限

同时排除以下失范：

- [ ] 已排除：只列动作不列结果
- [ ] 已排除：只报喜不报忧
- [ ] 已排除：阻塞不指明需要谁支持
- [ ] 已排除：计划全是"继续推进"

### 七、执行卡（以「周报日报生成」为例）

**开工前备齐**：产出清单（含量化）、问题与阻塞、下周计划

**可选补充**：工作台账、任务系统记录

**按序执行**：

1. 提取产出
2. 量化
3. 归纳问题
4. 排下周计划
5. 成文

**交付前核对**：每条产出须有结果或进展证据；禁止空话

**成品须符合**：周报/日报

### 八、成品骨架

按「周报/日报」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 周报/日报

## 1. 本期产出（量化）
## 2. 问题与阻塞（含请求）
## 3. 下期计划
## 4. 需协调事项
## 5. 数据附件
```

**齐备要求**：必选组件「产出清单（含量化）、问题与阻塞、下周计划」须全部落位；约束「每条产出须有结果或进展证据；禁止空话」须逐条成立；可选「工作台账、任务系统记录」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
