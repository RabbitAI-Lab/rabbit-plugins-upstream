## TC16 融资与招投标文书域范本

### 一、领域知识要点

- BP 结构：问题-方案-市场-竞争-模式-数据-团队-融资用途
- 投资人关注序列：赛道天花板 → 差异化 → 单位经济 → 团队 → 风险；顺序不能倒
- 标书结构：资格文件、技术标、商务标、报价；废标雷区（缺章漏签、超经营范围、格式不符、未逐条响应）
- 尽调回复原则：只答所问、给证据、不粉饰；不确定的写"待确认"而非含糊
- 数据口径：同一指标全文一致，注明统计周期与口径来源

### 二、判定标准

- 每个论断须有数据或证据支撑
- 标书须逐条响应招标要求并留响应索引
- 不得夸大、隐瞒或使用无法证伪的表述
- 财务数据须注明口径与周期

### 三、范本结构

1. 一句话定位
2. 问题与方案
3. 市场与竞争
4. 商业模式与数据
5. 团队
6. 融资用途或报价
7. 附录与索引

### 四、常见失范

- BP 只讲愿景不讲单位经济
- 标书漏响应项导致废标
- 尽调回复含糊其辞
- 同一指标前后口径不一

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 一句话定位、问题、方案、市场规模、竞争格局、单位经济、团队、融资用途 |
| 本域产出 | 商业计划书；投标文件+响应索引；尽调回复包 |
| 下游可用 | 尽调回复包 |

- [ ] 每个论断须有数据或证据支撑
- [ ] 标书须逐条响应招标要求并留响应索引
- [ ] 不得夸大、隐瞒或使用无法证伪的表述
- [ ] 财务数据须注明口径与周期

同时排除以下失范：

- [ ] 已排除：BP 只讲愿景不讲单位经济
- [ ] 已排除：标书漏响应项导致废标
- [ ] 已排除：尽调回复含糊其辞
- [ ] 已排除：同一指标前后口径不一

### 七、执行卡（以「商业计划书撰写」为例）

**开工前备齐**：一句话定位、问题、方案、市场规模、竞争格局、单位经济、团队、融资用途

**可选补充**：经营数据、行业数据、竞品资料

**按序执行**：

1. 写定位
2. 述问题
3. 给方案
4. 算市场
5. 比竞争
6. 列数据
7. 写团队
8. 说用途

**交付前核对**：须给单位经济；市场测算须给方法与假设

**成品须符合**：商业计划书

### 八、成品骨架

按「商业计划书」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 商业计划书

## 1. 一句话定位
## 2. 问题与方案
## 3. 市场与竞争
## 4. 商业模式与数据
## 5. 团队
## 6. 融资用途或报价
## 7. 附录与索引
```

**齐备要求**：必选组件「一句话定位、问题、方案、市场规模、竞争格局、单位经济、团队、融资用途」须全部落位；约束「须给单位经济；市场测算须给方法与假设」须逐条成立；可选「经营数据、行业数据、竞品资料」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
