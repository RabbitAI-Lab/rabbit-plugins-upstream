## TC6 演示与宣讲域范本

### 一、领域知识要点

- 金字塔结构：结论先行、以上统下、归类分组、逻辑递进
- 一页一观点原则；页标题即为该页结论
- 图表优先于文字：能用图不用表，能用表不用段
- 讲稿与幻灯分离：幻灯给关键词，讲稿给完整句与过渡
- 时间预算：每页 60-90 秒，预留答疑

### 二、判定标准

- 每页须有一个可被复述的结论句
- 图表须标数据来源与时点
- 讲稿须口语可读，不得照念幻灯
- 页数须匹配汇报时长

### 三、范本结构

1. 核心结论页
2. 分论点页（页标题=结论）
3. 支撑图表
4. 讲稿（含过渡与时间标记）
5. 答疑预案

### 四、常见失范

- 一页多个观点
- 幻灯堆字
- 讲稿写成书面语
- 超时且无删减预案

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 核心结论、分论点、支撑图表、页级观点 |
| 本域产出 | 演示文稿；讲稿；评审报告 + 删改清单 |
| 下游可用 | 评审报告 + 删改清单 |

### 六、交付自检

交付前逐项打勾，任一项不成立即返工：

- [ ] 每页须有一个可被复述的结论句
- [ ] 图表须标数据来源与时点
- [ ] 讲稿须口语可读，不得照念幻灯
- [ ] 页数须匹配汇报时长

同时排除以下失范：

- [ ] 已排除：一页多个观点
- [ ] 已排除：幻灯堆字
- [ ] 已排除：讲稿写成书面语
- [ ] 已排除：超时且无删减预案

### 七、执行卡（以「汇报演示稿制作」为例）

**开工前备齐**：核心结论、分论点、支撑图表、页级观点

**可选补充**：数据材料、品牌模板

**按序执行**：

1. 定结论
2. 拆分论点
3. 配图表
4. 排页序
5. 成稿

**交付前核对**：一页一观点；图表须标注来源；不得超过汇报时长

**成品须符合**：演示文稿

### 八、成品骨架

按「演示文稿」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 演示文稿

## 1. 核心结论页
## 2. 分论点页（页标题=结论）
## 3. 支撑图表
## 4. 讲稿（含过渡与时间标记）
## 5. 答疑预案
```

**齐备要求**：必选组件「核心结论、分论点、支撑图表、页级观点」须全部落位；约束「一页一观点；图表须标注来源；不得超过汇报时长」须逐条成立；可选「数据材料、品牌模板」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
