## TC7 商业文案域范本

### 一、领域知识要点

- 转化文案四段式：钩子（痛点/利益）→ 证据（卖点/参数/背书）→ 消除顾虑（保障/对比）→ 行动指令（CTA）
- 卖点三层：功能（有什么）→ 利益（带来什么）→ 意义（成为什么）
- 平台规格：淘宝标题 60 字符、京东卖点、抖音口播前 3 秒、亚马逊 listing（标题/五点/描述/A+）
- 合规红线：绝对化用语（最/第一/国家级）、虚假承诺、医疗功效、价格欺诈
- A/B 测试要素：单一变量、样本量、显著性
- 去 AI 味：删套话、去排比堆砌、具体化数字、恢复口语节奏

### 二、判定标准

- 每个卖点须有可验证的证据或参数
- CTA 必须唯一且动作明确
- 禁用绝对化用语与未证实功效
- 跨境 listing 须符合目标平台规则与当地法规

### 三、范本结构

1. 钩子句
2. 核心卖点（利益化表述）
3. 证据与参数
4. 顾虑消除
5. 行动指令
6. 合规检查

### 四、常见失范

- 形容词堆砌无具体证据
- 卖点与用户痛点无关
- CTA 过多导致注意力分散
- 跨境直接机翻不做本地化

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 钩子、主文案、标题、CTA、投放场景 |
| 本域产出 | 广告文案组；落地页文案；商品文案；本地化 listing；活动文案包；改写稿+对照说明 |
| 下游可用 | 改写稿+对照说明 |

### 六、交付自检

交付前逐项打勾，任一项不成立即返工：

- [ ] 每个卖点须有可验证的证据或参数
- [ ] CTA 必须唯一且动作明确
- [ ] 禁用绝对化用语与未证实功效
- [ ] 跨境 listing 须符合目标平台规则与当地法规

同时排除以下失范：

- [ ] 已排除：形容词堆砌无具体证据
- [ ] 已排除：卖点与用户痛点无关
- [ ] 已排除：CTA 过多导致注意力分散
- [ ] 已排除：跨境直接机翻不做本地化

### 七、执行卡（以「广告文案撰写」为例）

**开工前备齐**：钩子、主文案、标题、CTA、投放场景

**可选补充**：产品卖点、目标人群、竞品文案

**按序执行**：

1. 定媒体
2. 定人群
3. 写钩子
4. 写正文
5. 写CTA
6. 合规检查

**交付前核对**：须给多版本供 A/B；禁用绝对化用语

**成品须符合**：广告文案组

### 八、成品骨架

按「广告文案组」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 广告文案组

## 1. 钩子句
## 2. 核心卖点（利益化表述）
## 3. 证据与参数
## 4. 顾虑消除
## 5. 行动指令
## 6. 合规检查
```

**齐备要求**：必选组件「钩子、主文案、标题、CTA、投放场景」须全部落位；约束「须给多版本供 A/B；禁用绝对化用语」须逐条成立；可选「产品卖点、目标人群、竞品文案」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
