## TC11 剧本创作域范本

### 一、领域知识要点

- 剧本格式：场景标题（内/外景、地点、时间）、动作描述、角色名、对白、转场
- 短剧结构：前 6 秒钩子、每集 1 个反转、集末悬念、单集 1-2 分钟
- 三幕与节拍表：Save the Cat 15 拍（开场画面、主题陈述、催化剂、争辩、第一幕转折等）
- 人物小传：欲望、缺陷、秘密、前史伤口
- 广播剧：纯听觉叙事，需靠台词与环境音交代空间与动作
- 对白原则：潜台词优先、每句有目的、避免信息直给

### 二、判定标准

- 每个场景须推进剧情或揭示人物，否则删
- 对白须承担潜台词，不得纯解释
- 短剧集末必须有钩子
- 动作描述须可拍摄，禁止写心理活动

### 三、范本结构

1. 一句话故事
2. 人物小传
3. 分集大纲
4. 节拍表
5. 剧本正文
6. 悬念清单

### 四、常见失范

- 对白解释过多无潜台词
- 场景无冲突纯过渡
- 短剧节奏拖沓错过前6秒
- 广播剧写成视觉剧本

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 一句话故事、人物小传、分集大纲、剧本正文 |
| 本域产出 | 短剧剧本；分集大纲+节拍表；广播剧脚本；影视剧本；人物小传+关系网 |
| 下游可用 | 人物小传+关系网 |

### 六、交付自检

交付前逐项打勾，任一项不成立即返工：

- [ ] 每个场景须推进剧情或揭示人物，否则删
- [ ] 对白须承担潜台词，不得纯解释
- [ ] 短剧集末必须有钩子
- [ ] 动作描述须可拍摄，禁止写心理活动

同时排除以下失范：

- [ ] 已排除：对白解释过多无潜台词
- [ ] 已排除：场景无冲突纯过渡
- [ ] 已排除：短剧节奏拖沓错过前6秒
- [ ] 已排除：广播剧写成视觉剧本

### 七、执行卡（以「短剧剧本创作」为例）

**开工前备齐**：一句话故事、人物小传、分集大纲、剧本正文

**可选补充**：平台调性、单集时长

**按序执行**：

1. 定钩子
2. 设反转
3. 写分集
4. 写正文
5. 查节奏

**交付前核对**：前6秒须有钩子；每集须有反转；集末须留悬念

**成品须符合**：短剧剧本

### 八、成品骨架

按「短剧剧本」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 短剧剧本

## 1. 一句话故事
## 2. 人物小传
## 3. 分集大纲
## 4. 节拍表
## 5. 剧本正文
## 6. 悬念清单
```

**齐备要求**：必选组件「一句话故事、人物小传、分集大纲、剧本正文」须全部落位；约束「前6秒须有钩子；每集须有反转；集末须留悬念」须逐条成立；可选「平台调性、单集时长」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
