## 写作翻译任务清单与依赖拓扑

写作翻译按"域 → 任务"组织的任务清单，附价值链、场景管线与依赖关系。

**价值链**：委托澄清 → 体裁判定 → 素材整备 → 骨架设计 → 成文 → 修订 → 格式落地 → 交付核验（每个域即一种文种在此链上的一次完整实例）

**域划分判据**：域 = 一种**文种的完整生产链**。十二种文种的链互不同构（论文有评审、公文有行文关系、小说有伏笔台账），故每种文种独立成域，域内任务即该链的阶段。

**互斥约束**：一个任务只属于一个域；同一工作不会在两个域中同时出现。

**域间逻辑流**：TC1 学术文稿 → TC2 公文与告知文书 → TC3 法律文书 → TC4 会议纪要 → TC5 工作汇报 → TC6 演示与宣讲 → TC7 商业文案 → TC8 新媒体内容 → TC9 小说创作 → TC10 诗词歌词 → TC11 剧本创作 → TC12 技术文档与报告 → TC13 商务沟通 → TC14 翻译与本地化 → TC15 销售与客户沟通 → TC16 融资与招投标文书

**域内基线规则**：每个域的首个任务为该域基线任务，同域其余任务一律以其产出为参照，不得跳步执行。

## 知识图谱

将依赖拓扑扩展为知识图谱，支持跨任务的关系推理。

**实体节点类型**

| 类型 | 数量 | 说明 |
|------|------|------|
| 任务节点 | 78 | 形如 `TC1-01`、`TC16-03` 的可执行单元 |
| 域节点 | 16 | 任务的分组边界 |
| 元操作节点 | 12 | S/C/A/O/I/G 及组合 |
| 产出物节点 | 76 | 各任务声明的交付格式；与任务近 1:1，故不单独建模归并 |
| 场景节点 | 36 | 场景管线中的入口场景 |

**关系边类型**

| 边 | 方向 | 含义 |
|----|------|------|
| 包含边 | 域 → 任务 | 域包含其下所有任务 |
| 依赖边 | 任务 → 任务 | 前置产出是后继输入，见各域链路 |
| 产出边 | 任务 → 产出物 | 任务声明的 `格式` 即其产出节点 |
| 路由边 | 场景 → 任务 | 场景管线的链首即入口任务 |
| 反向边 | 产出物 → 任务 | 由交付格式反查产出它的任务 |

**推理能力**

- **路径推导**：给定起止任务，沿依赖边求最短可行链
- **任务推荐**：给定已完成任务，取其后继中依赖已满足者
- **依赖分析**：给定任务，回溯全部前置与受影响的下游
- **并行识别**：同域内无依赖边的任务可并行执行
- **产出反查**：给定交付格式，定位产出它的任务
- **形态归并**：本负载物全部产出物归入「成稿文本」这一产物形态，跨负载物可再归并

更多组合根据具体任务动态推导。
