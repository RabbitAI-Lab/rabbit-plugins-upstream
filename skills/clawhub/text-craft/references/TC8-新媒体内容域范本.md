## TC8 新媒体内容域范本

### 一、领域知识要点

- 长图文（公众号类）：标题-摘要-正文-引导，长文需小标题分段与金句锚点
- 图文笔记（小红书类）：封面标题（痛点/数字/身份）、正文短句换行、标签组合、评论区引导
- 短视频脚本：前 3 秒钩子、15 秒一个信息点、结尾引导，口播与画面分离标注
- 标题公式：数字、疑问、对比、身份代入、结果承诺（不得虚假）
- 平台算法偏好：完播率、互动率、收藏率、关注转化
- 多平台改写：同一选题按平台语域重写，而非复制粘贴

### 二、判定标准

- 标题须与正文一致，不得标题党
- 前 3 秒须给出继续观看的理由
- 平台语域须匹配（图文社区口语、长图文书面、短视频年轻化）
- 标签须精准不得堆砌

### 三、范本结构

1. 标题与封面文案
2. 钩子（前3秒）
3. 正文分段/分镜
4. 互动引导
5. 标签
6. 发布检查

### 四、常见失范

- 一稿多平台直接分发
- 标题承诺正文不兑现
- 脚本只有文案没有画面提示
- 标签与内容无关

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 标题、摘要、正文分段、金句锚点、引导语 |
| 本域产出 | 长图文稿；图文笔记；短视频脚本；标题候选集；多平台内容包；选题库+内容日历 |
| 下游可用 | 选题库+内容日历 |

### 六、交付自检

交付前逐项打勾，任一项不成立即返工：

- [ ] 标题须与正文一致，不得标题党
- [ ] 前 3 秒须给出继续观看的理由
- [ ] 平台语域须匹配（图文社区口语、长图文书面、短视频年轻化）
- [ ] 标签须精准不得堆砌

同时排除以下失范：

- [ ] 已排除：一稿多平台直接分发
- [ ] 已排除：标题承诺正文不兑现
- [ ] 已排除：脚本只有文案没有画面提示
- [ ] 已排除：标签与内容无关

### 七、执行卡（以「长图文撰写」为例）

**开工前备齐**：标题、摘要、正文分段、金句锚点、引导语

**可选补充**：选题素材、品牌调性

**按序执行**：

1. 定选题
2. 写标题
3. 搭结构
4. 填内容
5. 加锚点
6. 写引导

**交付前核对**：每段一个信息点；标题须与内容一致

**成品须符合**：长图文稿

### 八、成品骨架

按「长图文稿」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 长图文稿

## 1. 标题与封面文案
## 2. 钩子（前3秒）
## 3. 正文分段/分镜
## 4. 互动引导
## 5. 标签
## 6. 发布检查
```

**齐备要求**：必选组件「标题、摘要、正文分段、金句锚点、引导语」须全部落位；约束「每段一个信息点；标题须与内容一致」须逐条成立；可选「选题素材、品牌调性」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
