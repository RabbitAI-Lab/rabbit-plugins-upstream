## TC15 销售与客户沟通域范本

### 一、领域知识要点

- 销售沟通四段：建立信任（相关性）→ 挖掘需求（提问）→ 呈现价值（对应痛点）→ 推进承诺（下一步）
- 异议三分类：价格异议多为价值不清、时机异议多为优先级不足、信任异议多为证据缺失
- 话术原则：先认同再重构，不用"但是"转折；把"我理解"换成对具体处境的复述
- 客户成功沟通：里程碑通报、价值复盘、续约前置（到期前 90 天启动）
- 书面与口头分工：书面留证据、口头探真实；关键承诺必须落书面

### 二、判定标准

- 每次沟通须给出明确的下一步与时间
- 异议须归因到具体类型后再应对
- 不得承诺未确认的价格、交付或效果
- 客户处境须先于产品介绍

### 三、范本结构

1. 客户处境复述
2. 价值主张
3. 证据与案例
4. 异议类型与应对
5. 下一步与时限

### 四、常见失范

- 一上来讲产品，不问客户处境
- 用"但是"否定客户刚说的话
- 异议不归因直接降价
- 沟通结束没有下一步

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 客户处境、触达理由、相关性证据、开场话术、下一步请求 |
| 本域产出 | 触达文案；方案呈现文案；异议应对脚本；续约沟通材料 |
| 下游可用 | 续约沟通材料 |

### 六、交付自检

交付前逐项打勾，任一项不成立即返工：

- [ ] 每次沟通须给出明确的下一步与时间
- [ ] 异议须归因到具体类型后再应对
- [ ] 不得承诺未确认的价格、交付或效果
- [ ] 客户处境须先于产品介绍

同时排除以下失范：

- [ ] 已排除：一上来讲产品，不问客户处境
- [ ] 已排除：用"但是"否定客户刚说的话
- [ ] 已排除：异议不归因直接降价
- [ ] 已排除：沟通结束没有下一步

### 七、执行卡（以「客户触达与开场」为例）

**开工前备齐**：客户处境、触达理由、相关性证据、开场话术、下一步请求

**可选补充**：客户背景、共同联系人、触发事件

**按序执行**：

1. 找相关性
2. 一句话说清为什么找他
3. 给价值预告
4. 提轻量下一步

**交付前核对**：开场须有相关性理由；不得自夸开场

**成品须符合**：触达文案

### 八、成品骨架

按「触达文案」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 触达文案

## 1. 客户处境复述
## 2. 价值主张
## 3. 证据与案例
## 4. 异议类型与应对
## 5. 下一步与时限
```

**齐备要求**：必选组件「客户处境、触达理由、相关性证据、开场话术、下一步请求」须全部落位；约束「开场须有相关性理由；不得自夸开场」须逐条成立；可选「客户背景、共同联系人、触发事件」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
