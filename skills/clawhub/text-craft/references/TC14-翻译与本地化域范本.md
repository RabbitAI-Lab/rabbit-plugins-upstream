## TC14 翻译与本地化域范本

### 一、领域知识要点

- 翻译三标准：信（意义等值）、达（目标语言通顺）、雅（语域相称）；三者冲突时先保信息，再调语域
- 术语管理：术语表先行、全文一致、缩写首次出现给全称
- 本地化维度：日期与数字格式、度量衡、货币、姓名称谓、色彩与图标的文化含义
- 译腔来源：被动语态直搬、长定语前置、连接词冗余、代词照译
- 审校流程：初译 → 对照审校（原文并排）→ 语言审校（只看译文）→ 终审
- 不可译项处理：音译 + 释义、功能对等替换、保留原文加注

### 二、判定标准

- 术语须全文一致，并与术语表对齐
- 数字、日期、单位须按目标语言习惯转换
- 不得保留源语言语序造成的译腔
- 文化敏感项须做适配或加注说明

### 三、范本结构

1. 翻译任务书（语向/受众/用途/术语表）
2. 术语表与专名对照
3. 初译稿
4. 对照审校记录
5. 本地化适配说明
6. 终稿

### 四、常见失范

- 逐字直译导致句子读不通
- 同一术语前后多种译法
- 日期与单位照搬不转换
- 忽略目标文化的禁忌与惯例

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 源文本、语向、目标受众、用途场景、文体要求、术语表 |
| 本域产出 | 翻译任务书；术语表；初译稿；审校记录+修订稿；本地化终稿 |
| 下游可用 | 本地化终稿 |

- [ ] 不得保留源语言语序造成的译腔

### 七、执行卡（以「翻译任务界定」为例）

**开工前备齐**：源文本、语向、目标受众、用途场景、文体要求、术语表

**可选补充**：参考平行文本、历史译法

**按序执行**：

1. 定语向
2. 定受众
3. 定用途
4. 定文体
5. 收术语

**交付前核对**：用途决定策略（发表/内部/界面）须先确认；术语表缺失须先建

**成品须符合**：翻译任务书

### 八、成品骨架

按「翻译任务书」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 翻译任务书

## 1. 翻译任务书（语向/受众/用途/术语表）
## 2. 术语表与专名对照
## 3. 初译稿
## 4. 对照审校记录
## 5. 本地化适配说明
## 6. 终稿
```

**齐备要求**：必选组件「源文本、语向、目标受众、用途场景、文体要求、术语表」须全部落位；约束「用途决定策略（发表/内部/界面）须先确认；术语表缺失须先建」须逐条成立；可选「参考平行文本、历史译法」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
