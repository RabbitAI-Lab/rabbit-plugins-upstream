# 科研福音-小红书、抖音、b站数据抓取神器

## 这是什么

一款通过 CDP（Chrome DevTools Protocol）连接用户已打开浏览器、直接读取页面 DOM 数据的网页数据抓取工具。

- **不走爬虫、不调平台接口**——登录态天然在浏览器里，绕过签名与风控
- **所见即所得**——用户在浏览器里打开什么、滚动展开到什么，就抓什么
- **多平台**——内置小红书、抖音、B站适配，其他网页可用通用模式
- **双形态**——图形界面版 + 命令行版

## 使用步骤

1. 浏览器以调试模式启动：`chrome.exe --remote-debugging-port=9222`
2. 在浏览器中打开目标页面（小红书笔记/抖音视频/B站视频等），**滚动展开全部内容**（评论区滑到底、折叠回复点"展开"）
3. 获取并启动本工具（图形界面版）
4. 勾选要抓取的页面（可多选）和字段，选择保存位置（默认桌面\网页抓取数据），点击"开始抓取"
5. 自动导出 Excel：概览 Sheet（每个页面一行）+ 评论 Sheet（每条评论一行，折叠回复单独一列）

## 抓取内容

- 页面级：标题、作者、发布时间、正文、点赞数、收藏数、评论数、URL
- 评论级：用户名、评论内容、点赞数、时间；折叠回复归组挂到父评论下
- 点赞归一化：显示"赞"=0，1.2w=12000，1.2k=1200

## 平台注意点

- **小红书**：子评论平行结构，工具自动挂载到父评论
- **抖音**：评论区虚拟滚动，抓取前先在浏览器中滚动评论区加载数据
- **B站**：评论区懒加载，抓取前先滚动页面使评论区渲染

## 常见问题

| 问题 | 解决 |
|------|------|
| 连不上 9222 | 浏览器未以调试模式启动 |
| 页面列表为空 | 先在浏览器打开目标页面 |
| 评论抓不全 | 回到浏览器滚动加载后再抓 |
| 无折叠回复 | 在浏览器点开"展开N条回复" |
