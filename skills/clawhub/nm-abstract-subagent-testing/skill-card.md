## Description: <br>
Test skills via TDD in fresh subagents. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[athola](https://clawhub.ai/user/athola) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and skill authors use this skill to plan TDD-style validation of agent skills in fresh conversations. It helps compare baseline, with-skill, and rationalization-test results so teams can measure whether a skill improves behavior without priming bias. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate on broad testing or validation requests and influence how the agent plans skill tests. <br>
Mitigation: Before installing, confirm that this testing methodology should apply to generic testing and validation prompts in the target agent environment. <br>
