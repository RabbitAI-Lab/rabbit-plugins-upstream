# S4 · W-ABCD 真假 Web3 识别器

> 帮普通用户一眼识破"打着 Web3 旗号的伪项目 / 资金盘"，降低受骗风险。

## R — 原文 (Reading)

> 基于人工智能（AI）、区块链（Blockchain）、共建社区（Collaborative Community）与数据要素（Data）为有机构成的新技术范式（W-ABCD）；其中"共建社区"是区别于传统 ABCD（AI/Blockchain/Cloud/Data）的组织变量。

— 蓝皮书编写组，导言 / 第一章（二）

> **署名**：本 skill 的方法论（W-ABCD 范式）源自《价值互联网产业应用蓝皮书（2025）》编写组（导言 / 第一章·W-ABCD 范式）。上引 R 段为原著要义引述并已署名；本 skill 的结构与改写为二次创作，Apache-2.0 仅覆盖改写部分，**不覆盖蓝皮书原著内容**。

## I — 方法论骨架 (Interpretation)

W-ABCD 不是技术堆叠清单，而是一套"技术+组织"复合范式。五个要素各管一件事：

- **W（Web3 价值互联网网络）**：内核是否是"传递价值、计量贡献并分配"，而非仅传递信息。
- **A（AI / AIoT）**：是否作为新质生产工具，提升多元要素贡献的可度量性。
- **B（Blockchain）**：是否用区块链做可信底座——存证、不可篡改、可溯源、自动执行。
- **C（Collaborative Community 共建社区）**：是否有真实的社会型组织——成员"消费即投资、行动贡献即投资"，通证是计量分配工具而非单纯积分。这是区别于普通 ABCD 的**关键变量**。
- **D（Data 数据要素）**：是否把实体运营数据变成可信、可定价的生产要素闭环。

判别逻辑一句话：一个项目若只是把 AI/区块链/云/数据当技术栈堆砌，**没有真实的"共建社区"组织变量**，那它只是信息化/数字化升级，不是真 Web3。C 是试金石——没有真实共治、共担、共享的社区，再多的技术堆叠也只是"区块链+"噱头。

**对普通用户的防骗提示**：很多诈骗盘会刻意堆砌"AI/区块链/大数据"字眼并宣称"共建社区"，但 C 必须是**真实的组织变量**，不是一句宣传口号。本 skill 第 2 步专门用来戳破"宣称有社区 ≠ 真有共建社区"。

## A1 — 书中的应用 (Past Application)

### 案例 1：OORT 是否满足五要素（书中第四章原生型判别）
- **问题**：AI 训练算力分散、成本高（AWS/Google Cloud 学生难负担），传统中心化云无法激励全球闲置算力协同。
- **方法论的使用**：用 W-ABCD 逐项核对——W（去中心化数据云价值网络）、A（聚合全球 AI 算力）、B（区块链作激励层可信结算）、**C（130+国家、35 万成员共建社区，PoH 算力证明共治）**、D（全球分散算力数据上链）。
- **结论**：五要素齐备，判定为真·Web3 原生型。
- **结果**：2021 年商业化，助云天励飞计算时间缩短约 35%、成本降约 50%。

### 案例 2：新能源换电网络积分商城（verified f01 V2 预测力示范）
- **问题**：某新能源换电网络想用积分激励用户共享电池，宣称"产业 Web3"。
- **方法论的使用**：逐核五要素——若无"共建社区"组织变量、仅中心化积分商城（用户行为不上链、无通证计量贡献、无社区共治），则**缺 C**。
- **结论**：属伪 Web3，仅为中心化会员激励。
- **结果**：反例示范——若改为"用户行为上链 + 通证计量贡献 + 社区共治"，方可升格为真 Web3。华润隆地充电桩（物联网充电数据上链 + 智能合约自动分配 + 穿透式监管下投资人共建）即含社区要素、判为真的产业应用。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 投资人/用户看到"XX 项目用 AI+区块链+大数据打造产业 Web3"宣传，想判断真伪。
2. 普通用户被拉进某个"Web3 交易所/跟单盘/共建社区"，担心是不是骗局。
3. 内容创作者写 Web3 科普/测评，需给项目贴"真/伪 Web3"标签。
4. 创业者评估自己或友商项目是否真·Web3，以适配合规与叙事。
5. 用户被"美式 RWA 普惠叙事"吸引，想对照中国式"非金融"路径辨真伪。

### 语言信号（用户的话里出现这些就应激活）

- "这个项目到底算不算真 Web3？"
- "是不是只是套了区块链壳 / 伪概念 / 资金盘？"
- "它说有共建社区，但真的吗？"
- "美式 RWA 和中国式 Web3 有啥区别？"
- "区块链+大数据就是 Web3 吗？"
- "这个交易所 / 平台靠谱吗？"

### 与相邻 skill 的区分

- 与 `S3 三类主导模式判别器` 的区别：S4 解决"是不是真 Web3"（真伪、有没有 C），S3 解决"已是 Web3 后属于原生型/产业变革型/链改型哪一类"（选型）。**先 S4 定真伪，再 S3 定模式**。
- 与 `S1 通证/代币化概念辨析器` 的区别：S1 解决概念层级混淆（通证化 vs 代币化 vs RWA 族），S4 解决整体范式真伪（是否齐备 W-ABCD 五要素尤其是 C）。S1 偏术语边界，S4 偏项目识别。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **逐项核对 W / A / B / C / D 五要素**
   - 完成标准：列出五项各自的证据——W 是否价值网络内核、A 是否 AI 生产工具、B 是否区块链可信底座、C 是否有共建社区、D 是否有数据要素闭环；任一项缺失须在结论中标注。

2. **重点判断"共建社区 C"是否真实存在**
   - 完成标准：能回答三问——①成员是否"消费即投资/行动贡献即投资"；②通证是否用于计量分配而非纯积分；③治理是否多方共治而非中心化分发。
   - 判停条件：若 C 不成立（仅为中心化积分商城/粉丝群/拉人头话术），**直接判定"伪 Web3 / 仅信息化升级 / 疑似资金盘"**，跳过第 3 步细节，只补风险点。

3. **给出真伪结论与风险点**
   - 完成标准：输出"真·Web3（类型）+ 缺项清单 + 风险点"；风险点引用 ce 反例（伪 RWA、慢资产快金融、美式叙事遮蔽）标注。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只是想搞清楚"通证化/代币化/RWA"概念区别 → 用 `S1 概念辨析器`。
- 已确认是真 Web3，需要选主导模式/落地路径 → 用 `S3 模式判别器` / `S8 RWA 路径设计器`。
- 纯政策条文查询（如某法条原文）→ 不在本 skill 范围。

### 作者在书中警告的失败模式

- **ce18 伪 RWA**：以"赋能实体/贡献分配"为名，实为变相融资盘或代币炒作；"贡献即确权"被操作为新型集资工具，普通参与者风险极高。
- **ce02 风险上链爆雷**：底层非标、信用依赖高、信息不透明的资产包装上链，借 DeFi 杠杆放大，风险瞬时传导（如 2025.11 美国 SME 应收账款 RWA 爆雷，损失超 30 亿美元）。
- **ce17 美式叙事遮蔽**：用美式"资产代币化、碎片化融资"模板套中国场景，忽略"非金融"合规导向，误判可行性。
- **ce06 慢资产快金融错配**：资产回款周期长却承诺高流动性、通证属性模糊游走监管空白。

### 合规红线与使用须知（依据《价值互联网产业应用蓝皮书（2025）》第三篇·第五章）

本 skill 在**境内合规框架**下做真伪识别，采用蓝皮书"中国式非金融赋能"视角：境内 Web3 产业应用应聚焦"非金融"的数字化赋能（溯源、贡献计量、RDA 真实数据资产），**不得涉及通证代币化等加密金融行为**。

> "中国境内开展价值互联网与通证经济产业应用创新活动，不能涉及通证代币化等加密金融行为，而应聚焦探索'非金融'的数字化赋能产业提效方向。"
> "包括稳定币在内的虚拟货币无法满足 KYC、AML 等要求，在中国境内发行与交易虚拟货币属于非法金融活动。"
> — 价值互联网产业应用蓝皮书编写组，第三篇·第五章（合规边界）／ p02、ce03

**境内绝对禁止（🔴）**——命中任一项即判为"禁区 / 伪 Web3 资金盘"，普通用户切勿参与：
- 境内代币化、虚拟货币（含稳定币）发行与交易；
- 面向境内居民募资、提供交易或合约带单；
- 以"Web3/区块链"为名要求充值 USDT、拉人头返利、承诺升值；
- 为境外违规 RWA / 虚拟货币项目提供账户、资金划转或技术支持（连带追责，"只是帮忙"不免责）。

**高危（🟡）**：功能型通证 / 积分一旦叠加升值叙事、开通二级流转，可能被重新定性为金融属性——判定时按"是否产生金融化流通预期"而非"叫什么名字"为准。

**特别提示普通用户**：任何要求充值、带单、拉人头的"交易所 / 跟单盘 / 共建社区"，极可能是资金盘，**请勿参与、勿投资**。境外交易所向中国居民展业同样属非法。"境外合规 ≠ 境内合规"。

**免责声明**：本 skill 仅用于项目真伪识别与科普参考，**不构成任何投资建议或投资邀约**。涉及中国大陆境内虚拟货币交易、交易所相关业务属非法金融活动，请遵守《关于进一步防范和处置虚拟货币交易炒作活动的通知》（央行等十部门，2021.9）及最新监管规定，**以最新监管公告为准，宁可保守**。

### 作者的盲点 / 时代局限

- 编写组含项目方/服务商，天然带推广立场，对"通证激励是否真能持续激活贡献（而非沦为拉新噱头）"实证不足，**对概念包装识别偏乐观**——容易把"宣称有社区"直接当作"真有共建社区"。本 skill 第 2 步"验证 C 真实性"正是针对此盲点的补强。
- 对监管不确定性着墨偏乐观（以"合规化路径"收束，但境内红线仍刚性）。

### 容易混淆的邻近方法论

- 与 `S3 模式判别`、`S1 概念辨析` 的区别见 A2。
- 与 `f09 六构件评估模型`：六构件偏投资评估清单，本 skill 偏范式真伪五要素（尤其 C），可互补使用。
