# 示例 3 — "宣称有社区" vs "真有共建社区"

**用户提问**
> 它说自己有共建社区，但真的吗？我们公司说要建共建社区，但其实就一个粉丝群发积分。

---

**skill 被激活**（"共建社区""真的吗"验真信号）→ 加载 S4，重点执行第 2 步 C 验真。

**agent 按 E 段执行（聚焦 C 三问）：**

### C 验真三问核对

| 三问 | 宣称"有社区"的项目（如某积分商城 / 粉丝群） | 真·共建社区（如华润隆地充电桩 / OORT） |
|------|--------------------------------------------|----------------------------------------|
| ① 成员是否"消费即投资 / 行动贡献即投资"？ | 否——只是消费拿积分，无"投资/贡献"性质 | 是——行为上链即贡献，通证计量权益 |
| ② 通证是否用于**计量分配**而非纯积分？ | 否——中心化积分，规则平台单方定 | 是——智能合约按贡献自动分配 |
| ③ 治理是否**多方共治**而非中心化分发？ | 否——决策中心化公司做出 | 是——社区共治（如 PoH 算力证明） |

### 判停条件触发
该项目的三问**全不成立**（粉丝群发积分、中心化决策）→ 按 E 第 2 步判停条件：**直接判定"伪 Web3 / 仅信息化升级"**，跳过细节，补风险点。

> **结论**：缺真实共建社区 C，不是真 Web3。若改为"用户行为上链 + 通证计量贡献 + 社区共治"，方可升格为真产业应用。

---

**给用户的一句话**
