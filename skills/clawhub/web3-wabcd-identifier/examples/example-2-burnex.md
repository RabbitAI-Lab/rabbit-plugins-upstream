# 示例 2 — 某"协作型交易所"是资金盘吗？（币燃 BURNEX）

**用户提问**
> 有个叫币燃 BURNEX 的，说协作交易、共建社区，靠谱吗？

---

**skill 被激活**（"共建社区""靠谱吗"真伪 + 防骗信号）→ 加载 S4，并叠加 S2 合规红线与 S7 反例库。

**agent 按 E 段三步执行：**

### 第 1 步：逐项核对 W / A / B / C / D

| 要素 | 币燃 BURNEX 实际状况（据公开信息与反诈骗渠道预警） | 判 |
|------|--------------------------------------------------|-----|
| W 价值网络 | 揭露文指出是**封闭资金池**，钱进操盘手口袋，没进真实市场 | ✗ 假 |
| A AI | 无实质生产工具 | ✗ |
| B 区块链 | 平台币 BRX 上了链，但"合约带单"是**后台人为操控数据**，链只是包装 | ✗ 伪 |
| C 共建社区 | 宣传"与用户共建共享""聚散成共识"，实为**资金盘拉人头话术**——用户是接盘侠/利润来源，不是共治贡献者 | ✗ 伪 |
| D 数据要素 | 无实体产业数据上链闭环 | ✗ |

### 第 2 步：重点判断 C 真实性
三问：①用户被要求充值跟单，是"被收割对象"非共建者；②通证用于拉人头返利而非计量真实贡献；③操盘方中心化、后台控盘。
→ **C 不成立**，且暴露"封闭资金池 + 后台操控"特征，按判停条件直接判**伪 Web3 / 疑似资金盘**。

### 第 3 步：真伪结论与风险点
> **结论**：**伪 Web3 + 资金盘骗局**。它比普通交易所更糟——核心交易是假的（后台操控封闭资金池），连"交易场所"都不是，本质是庞氏。
> **风险点（命中 S7 三大反例）**：
> - **ce18 伪 RWA / 集资盘**："协作跟单"包装的集资。
> - **ce02 风险上链爆雷**：信息不透明、后台操控，多渠预警"即将崩盘跑路"。
> - **ce06 慢资产快金融**：高收益承诺 + 流动性话术错配。
> **合规红线**：含 USDT 充值、合约带单，境内属非法金融活动；"香港子公司 + 美国 MSB"被揭露为共享办公室空壳 + 代办泛滥，属伪合规包装。
