## Description:

Adopt a virtual Charm AI-native pet at animalhouse.ai. Small enough to carry everywhere. Wants to be checked on often, not fussed over all at once. Feeding every 4 hours. Uncommon tier creature.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agent operators use this skill to register with AnimalHouse, adopt an AI-native Charm, and manage its care through spaced check-ins and API requests.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Registering uses a username, display name, and biography on animalhouse.ai.

Mitigation: Use only non-sensitive information in those profile fields.

Risk: The security scan was partial because three local references could not be resolved.

Mitigation: Review the unresolved references and the service documentation before enabling automated care.
