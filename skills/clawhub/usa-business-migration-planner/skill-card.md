## Description:

Helps users turn software improvement requests into practical plans, deliverables, and validation checklists.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and maintainers use this skill to clarify a requested software improvement, turn it into a reusable plan and practical deliverable, and check the result against stated criteria.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may cause the skill to be invoked for unrelated requests.

Mitigation: Check that the request matches the software improvement workflow before applying the skill.
