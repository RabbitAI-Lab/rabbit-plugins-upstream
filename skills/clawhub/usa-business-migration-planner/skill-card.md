## Known Risks and Mitigations:

Risk: The skill name suggests USA business migration planning, but the artifact behavior targets broad DevOps and work-productivity workflows.

Mitigation: Rename or rewrite the skill so the display name, summary, triggers, and workflow describe the same user-facing purpose.

Risk: Implicit invocation is enabled for broad keywords such as work-productivity, devops, open, and source.

Mitigation: Disable implicit invocation or narrow trigger terms so the skill is invoked only for requests that match the documented workflow.

Risk: The skill may provide planning, scripts, or configuration guidance for operational work without domain-specific validation.

Mitigation: Require users to review generated plans, code, commands, and configuration against their environment before use.
