## Description:

HTML Designer helps agents create visually polished, accessible, responsive HTML/CSS pages and templates using design principles for typography, color, layout, and visual hierarchy.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jhauga](https://clawhub.ai/user/jhauga)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, designers, and content teams use this skill to generate or refine landing pages, portfolios, marketing pages, HTML prototypes, and reusable web templates with strong visual hierarchy, accessibility, and responsive structure.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Bundled static templates may contain placeholder links, images, social URLs, mailto addresses, or script/style references that are unsuitable for a real site if copied unchanged.

Mitigation: Review and replace template placeholders and references before publishing generated or adapted HTML.
