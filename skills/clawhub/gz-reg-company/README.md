# 开公司 · 新手老板注册全流程技能

**出品：鼎信财税 + 雄韬 联合开发（tax.xtocn.com） · 广州专精 · 仅有限责任公司**

面向三入口的一套知识与口径统一的开公司顾问：**客户自助**（问答 + 建议摘要 + 引导联系顾问）、**顾问出书**（正式 Word《注册全流程方案书》）、**内部自用**（口径查询 / 新人培训）。

## 维护要点

1. **政策变** → 只改 `guangzhou-params.md`（含末尾"口径红线"），记得同步更新时间戳。
2. **报价变** → 只改 `config/pricing.yaml`，改完把 `status` 置"已生效"；技能不自行编价。
3. **新增许可行业** → 在 `permit-map.md` 表格加一行（证照名 + 发证部门 + 是否可集群）。
4. **口径统一**：所有文件以"先结论后理由、区间 + 以官方最新核定为准、不教红线"为准绳；改一处要扫一遍 evals 是否有牵连。
5. **发布/注册**：将本目录镜像一份到运行环境的 `.claude/skills/开公司/`（TheRenSkill/CompanyHeadlines 同款做法）后即可被识别；镜像时确认客户可见内容不含内部批注与精确报价（报价只在顾问流程按 pricing.yaml 输出）。
