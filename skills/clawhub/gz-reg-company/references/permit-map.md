# 行业许可映射（permit-map）

> 作用：判断客户行业是否需要额外资质，并在方案书/客户问答里给出**资质提醒**。
> 铁律：**"先照后证"**——执照先办，许可证后办；未取得许可证前不得开展该项业务。
> 下表为方向性口径，审批部门与具体要求随时可能调整；涉许可的客户，正式办理前务必由顾问按最新要求专项核一遍，**拿不准就明确说"需专项确认"，绝不硬编**。

## 一、判断流程

1. 从客户"主营业务 + 经营范围"反推是否命中下表许可项。
2. 命中 → 必须给资质提醒：许可证名称、发证部门、以及"执照先办、证照后办、未拿证不做该项"的时序。
3. 未命中 → 普通行业，走常规注册即可，但要提示：**若经营范围勾了许可项，领照后仍要去办证**。

> **地址与许可的联动**：凡需"现场经营 + 现场核查"的许可行业（餐饮/食品加工、住宿旅馆、诊所/医疗、办学培训等），注册地址必须是真实可用的经营场地，**集群/托管地址通常不适用**——给这类客户出地址方案时要提醒走"实地注册"，别推荐只收信的挂靠地址。

## 二、常见行业映射表

| 客户主营（关键词） | 是否需要资质 | 证照 / 审批要点 | 提示 |
|---|---|---|---|
| 餐饮 / 外卖 / 食堂 / 食品加工 | 需 | **食品经营许可证**（市场监督部门）；仅售**预包装食品**的网店多为"备案" | 办照后可先申请；无证不得开餐 |
| 食品销售（超市/便利店/网售） | 需/备案 | 食品经营许可证，或仅预包装食品销售备案 | 按售卖的品类区分 |
| 电商零售 / 直播带货（卖普通商品） | 一般不需专门许可 | 以营业执照主体经营即可 | 若卖食品/药品/化妆品等另按品类办证 |
| 直播 / MCN / 内容制作 | 视情 | 平台合规 + 涉经营资质按品类；不涉及就不需专门证 | 区分"帮别人卖"与"自己卖" |
| 进出口贸易 | 需后续备案 | 经营范围含"货物/技术进出口"后，办**海关进出口收发货人备案**、电子口岸等（对外贸易经营者备案登记已取消） | 出口退税另有条件 |
| 图书 / 报纸 / 音像网售 | 需 | **出版物经营许可证**（新闻出版部门） | 书店/网店适用 |
| 药品 / 医疗器械 | 需 | 药品经营许可（药监）；医疗器械二类备案、三类经营许可 | 门槛与仓储要求高 |
| 职业技能培训（成人/非学历） | 视情 | 多需人社部门**民办职业培训学校**审批 | 场地/师资有要求 |
| 面向中小学生的培训（学科/艺术体育） | 需 | 教育/文旅/体育等部门**办学许可**；学科类目前从严 | 谨慎，建议专项咨询 |
| 医美 / 诊所 / 医疗 | 需 | **医疗机构执业许可**（卫健部门），门槛高 | 不建议按普通公司办理 |
| 劳务派遣 | 需 | **劳务派遣经营许可**（人社）+ 注册资本门槛（见 capital 文件） | 实缴/验资要求 |
| 人力资源服务（招聘中介） | 需 | **人力资源服务许可**（人社） | 部分地区备案即可，按当地 |
| 建筑 / 装修施工 | 需资质 | 建筑业相关资质（住建部门）；纯室内设计/咨询一般不需要 | 施工与设计分开看 |
| 酒店 / 住宿 / 洗浴 | 需 | 公共场所卫生许可 + 特种行业许可（公安）+ 消防 | 多证齐备才可营业 |
| 酒吧 / 娱乐 / 演出场所 | 需 | 娱乐经营许可（文旅）+ 消防等 | 审批链条长 |
| 道路运输 / 货运 / 网约车 | 需 | **道路运输经营许可**（交通部门）等 | 网约车另涉平台准入 |
| 卷烟零售 | 需 | **烟草专卖零售许可**（烟草部门） | 范围与选址有限制 |

## 三、给客户的话术模板

> "你提到会做 **餐饮堂食**。这部分属于**许可经营**：营业执照先办，随后还要申请 **《食品经营许可证》**（市场监督管理部门核发）才能实际营业。我们把这项写进经营范围，但方案里会单列'办照后要办的证'，你拿到执照后我们接着帮你把证办下来，中间不耽误。"

## 四、口径边界（别越界）

- 本表只做"是否需要证"的方向判断，**不指导如何钻空子、不教无证经营**。
- 遇到上表没覆盖、或需要跨省、或涉金融/证券/彩票等强监管行业的，一律回答"该行业需专项资质与审批，建议由顾问对接办理"，不要现场下结论。
