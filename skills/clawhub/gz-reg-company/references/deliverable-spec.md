# 顾问版《公司注册全流程方案书》逐节模板（deliverable-spec）

> 目的：把「采集到的事实 + 各 reference 的建议值」**组装成一份可直接发给客户、可被 docx 渲染的正式方案书**。
> 客户 = 新手老板，语言 = 平实，术语带解释；所有"建议"都带理由；所有费用/时限给区间或标"以官方最新核定为准"。
> 文中 `{{占位}}` 表示按客户实情填充；涉及未确认事项用"待核"标注，不编造。

**整体规格**：约 8–12 页；主标题、封面抬头与页脚署名按鼎信财税 + 雄韬 联合品牌（tax.xtocn.com）；用清晰的 Heading 结构（docx 渲染时映射标题层级与表格）。

| … | | | |

- 统一说明命名结构、为什么"以申报核名为准、多备字号"（引 naming-capital-scope）。

### 3.2 注册资本建议

- 给区间 + 建议值，附 3 行理由（责任隔离 / 行业门槛 / 增资易减资难）。
- **必写提醒**：现在认缴即可，但按现行《公司法》须自成立起 **5 年内缴足**；不是永远不用缴。
- 若客户行业涉实缴门槛（劳务派遣等）：单列"该行业另有实缴要求，需专项确认"。

### 3.3 股东与股权结构

- 一人 or 多人、各自持股比例建议 + 理由；多人必提醒避免 50/50、把分工/分红/退出写进股东协议。
- 客户没想好的：给一套"最简单省事"的默认（如全部本人持股或按出资比例）。

### 3.4 经营范围建议

- 主营条目（照着规范库的语言给客户可看懂的表述方向）+ 适度兼营。
- 涉许可项 → 单列并标注"领照后须办证方能经营"，具体证照引 permit-map。
- 附注"以登记机关规范条目库核定为准，不照抄他司长文"。

### 3.5 注册地址方案

| | 方案A：实地注册 | 方案B：集群/托管注册 |
|---|---|---|
| 适用 | 已租/已购商用地址 | 尚无办公室 |
| 材料 | 产权证明或租赁合同等 | 集群托管机构出具的住所证明 |
| 费用 | {{区间/以报价为准}} | {{区间/以报价为准}} |
| 提示 | 商用性质 | 地址须真实可收信，防失联异常 |

给明确推荐：没有办公地址的客户，推荐方案 B 起步，同时提醒将来有办公室可迁址。

> **硬规则**：凡涉"现场经营 + 现场核查"的许可行业（餐饮/住宿/诊所/培训等，见 permit-map），**只能走方案 A 实地注册，不提供方案 B 集群**——别让顾问把挂靠地址推给餐饮客户。

## 七、注册完成后七件事（合规运营全貌）

每件用统一小节，客户可看懂"是什么/怎么办/费用/时长/不办的风险"：

1. **刻章备案**（公章/财务章/发票章/法人章；公安备案）
2. **银行对公开户**（基本户，法人面签；用于收付款与税务代扣）
3. **税务登记与核定**（新办纳税人套餐、实名、核定税种与票种，才能开票）
4. **记账与报税**（无业务零申报、有业务如实申报；小规模/一般纳税人怎么选——初期默认小规模）
5. **社保与公积金登记**（有员工后办理缴费登记，别漏）
6. **工商年报**（每年按时限报送，逾期列异常）
7. **章程与证照保管**（执照、公章、章程别乱放；信息变更及时办）

每件 "不办的风险" 一句带过（引 risk-zero），语气平和不吓唬。

## 八、记账报税年度服务（增值推荐页）

- 为什么新手老板建议委托代账：申报节点多、口径易变、漏报成本高；代账把"按期申报+发票+账本+年报"管起来，老板专注生意。
- 服务内容清单（示意）：每月记账、按季申报增值税与个税、企业所得税预缴与汇算、发票管理、工商年报、税务事项提醒。
- **年度服务费报价**：读 config/pricing.yaml，给区间与套餐。
- 话术诚实："托管不是不管，重大经营决策仍建议先问财务/税务意见。"

## 九、零申报与避坑提示

- 讲清：没业务也要零申报、也要年报；有业务还零申报=虚假申报。
- 红线提示（不教操作）：虚开专票、私户收经营款不入账、抽逃出资、无证经营许可项目。逐条给后果口径（引 risk-zero）。
