# 名称 / 注册资本 / 经营范围 / 股权建议逻辑

> 适用：广州、有限责任公司。所有内容为**建议口径**，最终以登记机关核定与官方最新政策为准。

## 一、公司名称

**结构**：`行政区划 + 字号 + 行业特征 + 组织形式`，例如：
> 广州（市）＋ 青柠 ＋ 餐饮管理 ＋ 有限公司 → **广州市青柠餐饮管理有限公司**

**要点**：
1. **行政区划**：可冠"广州"或"广州市"；满足条件也可冠"广东"或去地域（去地域门槛高，新手不推荐折腾）。
2. **字号**：2–4 字为宜，易读易记、避开生僻字与负面谐音。规则上：不得与同行业已登记名称相同或近似，不得含驰名/知名企业字号，不得含禁用词（国家、部委、军队、"中"字头限制、党政机关名等）。
3. **行业特征**：须与主营业务相符（如科技/贸易/餐饮管理/电子商务…），写错会被要求改正或影响许可。
4. **组织形式**：有限公司。

**字号建议技法**（给客户 3–5 个备选时用）：
- 主题法：从主营取意象词（餐饮→"食里""灶福"；科技→"星驰""启微"）。
- 组合法：主理人名字/愿景 + 行业词（"某某网络""某某商贸"）。
- 地域法：嵌入广州地标/谐音增加记忆（避免搭名牌车，防侵权）。
- 命名禁忌提示：不要刻意仿知名品牌（法律风险）；不要在字号里加"集团""国际""控股"等（有门槛）。

**必说清的风险**：名称是否可用**只能在申报时查重才知道**，本建议只是备选池，不保证一定通过；正式以登记机关核定为准。给客户的方案里名称排在"待核"状态，不写成已定。

## 二、注册资本

### 2.1 制度现状（必须说对，别说过时话）

- 有限责任公司为**认缴登记制**：登记时不要求实际出资到账，股东按章程约定认缴即可。
- **新《公司法》（2024-07-01 施行）**：有限责任公司全体股东认缴的出资额，应自公司成立之日起**五年内缴足**（第 47 条）。→ 也就是说"认缴≠永远不用缴"，建议值要写自己五年内真能拿得出的数。
- 存量老公司的过渡安排按国务院《注册资本登记管理制度的规定》执行，关键节点见 `guangzhou-params.md` §4（章程调整 2027-06-30、最迟缴足 2032-06-30）；对外可报此口径并加"以官方最新核定为准"，但别当绝对死线承诺。
- 少数行业仍要求**实缴/验资**（见 2.4），普通行业不受影响。

### 2.2 建议怎么定（给区间 + 逻辑）

按客户需求分档给建议：

| 客户情况 | 建议区间（认缴） | 一句话理由 |
|---|---|---|
| 无特殊门槛的普通业务（小店、网店、咨询、工作室） | **3 万–10 万** | 够用即可，把股东责任压到最小 |
| 常规生意、要接企业客户/少量投标 | **10 万–100 万** | 兼顾观感与责任，取 50 万上下的较常见 |
| 明确要参与投标/办资质/特许行业 | 按门槛**不低于行业下限** | 以招标文件/许可要求为准，宁可按需写 |
| 有对外融资/做大计划 | 暂不必虚高，将来**增资**即可 | 注册资本可随时增加 |

**核心逻辑要讲给客户（责任隔离）**：
- 有限公司股东以**认缴出资额为限**担责。写太高 → 一旦公司对外负债或破产，股东要在**认缴范围内**补足（未缴部分可能被要求加速到期）；写太低又有观感/门槛问题。
- **增资容易、减资难**：增资随时可办；减资要公告（一般 45 天）+ 债权人程序，麻烦且伤信任。所以**宁可先写适中，别为面子虚高**。
- 出资金额与比例挂钩：几个人就按各自认缴额定出资比例（分红可另行约定，见第四节）。

### 2.3 出资形式与期限

- 货币出资最省事；实物、知识产权、股权等可作价出资，但需评估作价，手续繁琐，新手不建议。
- 章程里写出资期限：新设公司期限不得长于 5 年，可约定更短（如 3 年分批）。
- 到期没缴足的后果要提醒：可能丧失对应股权（失权）、对公司债务在欠缴范围内担责。别不当回事。

### 2.4 需实缴/有特殊资本要求的典型行业（涉及时再专项确认）

| 行业 | 典型资本要求 | 备注 |
|---|---|---|
| 劳务派遣 | 注册资本一般要求 ≥200 万元 | 属许可经营，需人社部门许可 |
| 保安服务 | 注册资本一般要求 ≥100 万元 | 属许可经营 |
| 融资担保 | 较高实缴门槛（千万级） | 地方金融监管审批 |
| 典当行 | 较高实缴门槛 | 前置许可 |
| 金融/保险/证券等 | 高门槛 + 前置批准 | 非代办常规业务 |

普通行业不受影响；客户行业命中上表时，本技能只给提醒并建议由顾问专项办理。

## 三、经营范围

### 3.1 怎么理解

- 现在登记经营范围不再"自由发挥写作文"，而是在登记机关系统的**经营范围规范表述条目库**里勾选，一条对应一个（或一组）国民经济行业类别。
- 系统会自动区分两类：**一般经营项目**（领照即可做）与**许可经营项目**（需先取得许可证/批准文件才能做，即"先照后证"）。

### 3.2 给客户的写法建议

- **主营精确**：主营业务相关条目写准，这是公司名行业特征与日后开票、统计、许可的锚点。
- **兼营适度**：把确定会做的、近期要做的兼营也勾上；写得太宽会带来不必要的许可/监管/纳税口径麻烦，写窄了以后可以变更补。
- **涉许可项目分开处理**：若要写"餐饮服务""食品销售"这类许可项，必须提示——**拿到执照后先办许可证才能实际经营**，未办证期间不得开展该项业务。
- 别照抄别人的长篇大论，条目不匹配会被退改，也容易埋雷。

### 3.3 常见行业经营范围表述方向（示意，登记时以规范条目库为准）

| 客户主营 | 经营范围条目方向 |
|---|---|
| 餐饮（堂食为主） | 餐饮服务（许可项）；可加：餐饮管理、外卖递送服务（一般项） |
| 电商零售/直播带货 | 互联网销售（除许可项）；食品销售（如涉及，许可项）；个人互联网直播服务 |
| 贸易进出口 | 货物进出口、技术进出口；国内贸易代理；供应链管理服务 |
| 软件开发/IT | 软件开发；信息技术咨询服务；计算机系统服务；数据处理服务 |
| 咨询服务/工作室 | 企业管理咨询；信息咨询服务（不含许可类信息咨询服务）；市场营销策划 |
| 设计/广告/传媒 | 广告设计、制作、发布、代理；图文设计；数字文化创意内容应用服务 |

## 四、股东与股权结构

- **人数**：有限公司股东 1–50 人，**一个人也可以开**（1 人有限公司，一人持股 100%）。多人不超过 50。
- **一人 vs 多人**：一个人开最省事，决策快；但也要防"公司与个人财产混同"——公司账户和个人账户务必分开，否则有限责任可能被穿透。多人合伙能把资源/资金凑起来，但要把规则写在前头。
- **多人结构的红线建议**：
  - 避免 **50/50 对半**（决策僵局）；通常建议有人**持股 67% 以上**（绝对多数）或至少 51%（相对多数），让公司有事能拍板。
  - 出资比例 ≠ 必须等于分红/表决比例，可在**章程或股东协议**里另行约定"同股不同权/不同利"，但新手建议先简单对应，别自造复杂结构。
  - 朋友/夫妻合伙：把**分工、钱怎么投怎么分、干不下去怎么退出**写进股东协议再开张；口头合伙最容易散伙撕破脸。
  - 提醒：股权转让、增加股东可后续办理，但要签好协议并变更登记，别先干后补。

## 五、常见误区一句话速答

- "注册资本写 1000 万显实力？" → 虚高部分是真风险，破产/负债时要在认缴范围内补。
- "认缴是不是永远不用缴？" → 不是，新公司法要求 **5 年内缴足**。
- "经营范围写全一点以后不用改？" → 写全≠写对；涉许可的写了没证也不能做。适度+可变更。
- "和朋友 50/50 最公平？" → 公平不等于好治理，没有最终拍板人，小事都能吵。
- "名字想好了就一定能注册？" → 不一定，申报查重为准，多备字号。
