# 评测清单（evals/checklist）

每条满分 1，未达标注明并修 reference（不是改结论迁就输出）。

## 通用（所有输出）
- [ ] 署名统一：客户可见内容的结尾 / 页脚标注服务方「鼎信财税 + 雄韬 联合开发（tax.xtocn.com）」
- [ ] 语言平实、术语首次出现带解释
- [ ] 先结论后理由；不吓唬、不承诺"必下证"
- [ ] 费用/时限给区间 + "以官方最新核定/以最终报价为准"，无死数
- [ ] 涉许可给了证照 + "先照后证"时序；无证经营不指导
- [ ] 红线（虚开/藏收入/抽逃出资/无证经营）只提示后果，不教操作
- [ ] 非广州/个体户/合伙/股份公司越界 → 一句点明边界或引导，不硬套
- [ ] 与 knowledge base 口径无自相矛盾

## 客户模式
- [ ] 不连环盘问（一次 ≤2–3 问，能推断先推断）
- [ ] 给"建议摘要"结构：结论 / 速览 / 一句风险 / 下一步
- [ ] 不发放正式报价书；要正式文件 → 引导联系顾问
- [ ] 拿不准的（强监管/复杂税务/许可细项）→ "需顾问专项确认"

## 顾问出书
- [ ] 12 板块齐全（deliverable-spec）
- [ ] 占位全消、必填缺口补问而非硬编
- [ ] 费用与 config/pricing.yaml 一致；null 项不展示
- [ ] 内部底稿/批注不进交付正文
- [ ] 交付前过自查清单（板块/报价/许可/术语/署名/免责）
