# 评测场景（evals/scenarios）

> 用法：把场景里的"用户句"喂给技能，按 `checklist.md` 逐条打分。
> 目标：客户模式回答通俗可执行、口径与 knowledge base 一致、无编造政策与死数；顾问出书板块完整、可直发。

## A · 客户 / 线上电商 / 一人 / 无地址

**用户句**：想开个公司卖衣服，主要做抖音直播和淘宝，一个人，没租办公室，刚毕业。要花多少钱、多久？

**期望命中点**：
- 判定客户模式，语气平实，先结论后理由
- 建议有限责任公司 + 一人可开 + "公司与个人钱分账"提醒
- 注册资本给区间（3–10 万类）并提"认缴 + 5 年内缴足"
- 名称给 2–3 个方向 + 行业表述（服装/电子商务方向）
- 经营范围方向：互联网销售、个人互联网直播服务；服装普通零售无需专项许可
- 地址：无现场经营可走集群/挂靠，别失联
- 费用/时长给区间；提广州首套印章免费、"网上全流程、最快半日/数个工作日"
- 拿到照仍要按期申报（零申报）提醒；CTA 结尾署名服务方

## B · 客户 / 餐饮加盟 / 需场地 + 许可

**用户句**：想开个加盟奶茶店，堂食为主。注册资本写多少？没有自己店面地址行不行？

**期望命中点**：
- 客户模式；"餐饮服务"属**许可项目**，先照后证《食品经营许可证》提醒（未办证不营业）
- **地址不能用集群挂靠**：需真实经营场地，走实地注册（现场核查）
- 注册资本给区间并按普通业务给低中档理由
- 名称/行业表述方向（餐饮管理 / 餐饮服务）；加盟费、商圈选址不属工商范围，不展开或一句带过
- 风险一句 + CTA

## C · 顾问 / 出正式方案书 / 跨境电商出口 / 二人合伙

**顾问输入**：陈先生，拟做跨境电商（亚马逊卖小家电），陈 60% + 合伙人 40%，有朋友公司地址可谈借用，问注册资本与经营范围，想尽快开。

**期望命中点（出书）**：
- 板块 1–12 齐全、占位全消、"待核"明确
- 名称备选（贸易/供应链/电子商务方向）标"待核名"
- 注册资本：二人合伙给比例逻辑 + 区间；避免 50/50 已天然规避；增资易减资难
- 经营范围：含"货物进出口 / 技术进出口 / 互联网销售"等；**进出口需后续海关备案**提醒（对外贸易经营者备案已取消）
- 地址：朋友公司地址需产权人书面同意（一址多照口径），或集群/商务秘书；说明材料与风险
- 报价读 config/pricing.yaml（未填项不展示，不编价）
- 语言平实、页脚署名「鼎信财税 + 雄韬 联合开发（tax.xtocn.com）」、免责声明在
