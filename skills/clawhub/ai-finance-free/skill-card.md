## Known Risks and Mitigations: <br>
Risk: The security evidence flags broad file, command, API, export, and recurring automation authority without clear user-control boundaries. <br>
Mitigation: Review before installing, run only under explicit user direction, and require confirmation before file export, shell execution, scheduled tasks, external API use, or connections to trading or account systems. <br>
Risk: Financial analysis outputs may be incorrect, stale, incomplete, or inappropriate for a user's risk profile. <br>
Mitigation: Treat outputs as analytical support, verify source data independently, and require qualified human review before financial, trading, or compliance decisions. <br>
Risk: The skill may use finance API credentials or user-provided financial data. <br>
Mitigation: Store credentials in environment variables or a managed secret store, use least-privilege API keys, and avoid sharing sensitive account or personal financial data unless required. <br>
