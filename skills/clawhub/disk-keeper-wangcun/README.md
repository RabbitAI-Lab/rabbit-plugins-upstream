# 净盘师 DiskKeeper

> 一个真正**免费、纯本地、零上传**的 Windows 磁盘清理工具。
> 自动体检 → 分级 → 安全清理 → 账实对账。
> **不装全家桶、不弹广告、不上传你的任何文件。**

---

## 一、这是什么

C 盘红了，不知道该删什么？清理软件越清越乱，还越装越卡？

净盘师不是又一个 `rm -rf` 脚本。它的做法是：**先体检、再分级、最后才清理**，每一步可追溯、可回看，**极低误删**。

**它解决四个真实痛点**

| 痛点 | 净盘师怎么解 |
|---|---|
| C 盘红了不知道删啥 | `doctor` 一键体检，告诉你空间卡在哪 |
| 清理软件越清越乱 | 正向白名单，**只动可重建的缓存和 Temp**，其余一律不碰 |
| "我释放了 10G"是假的 | 以系统实测为准，**强制账实对账**，不虚报 |
| 清完没记录、查不清 | 删除台账**边删边写**，崩溃不丢账 |

```
disk-keeper/
├── SKILL.md                    # Skill 说明
├── README.md                   # 本文件
├── _meta.json                  # 发布元数据
└── scripts/
    └── disk_butler.py          # 自包含核心（零第三方依赖，纯标准库）
```

> 首次运行时，脚本会在 `scripts/disk_keeper_state/` 下**自动创建**本机运行数据（体检台账、清理历史等）。该目录**不随包分发**，每个人的数据只存在自己电脑上。

## 三、安装与使用

**环境要求：** Python 3.8+（Windows）

**三步上手：**

```bash
python scripts/disk_butler.py doctor       # ① 体检：先看看空间卡在哪
python scripts/disk_butler.py plan         # ② 预览：列出可清理项（不删）
python scripts/disk_butler.py clean --yes  # ③ 清理：确认后执行安全清理
```

> **`clean` 不加 `--yes` 时只列清单、不删除。** 默认就是安全的。

| 命令 | 作用 | 风险 |
|---|---|---|
| `doctor` | 快速体检（空间 / 回收站账本 / 缓存点 / 健康判定） | 只读 |
| `doctor --deep` | 深度盘点（顶层目录 + 大文件） | 只读 |
| `scan` | 同 `doctor --deep` | 只读 |
| `plan [--with-r2]` | 清理计划预览（列清单 + 大小，不删） | 只读 |

| `clean --yes` | 执行安全项清理 | 低 |
| `clean --yes --with-r2` | 加上需确认项 | 中 |
| `recycle` | 回收站真实账本（只读） | 只读 |
| `recycle --ghost --yes` | 清理"幽灵收据"（不占空间，只清账本） | 低 |
| `recycle --purge --yes` | 清空回收站（**不可逆**） | **高·手动专用** |

## 五、安全模型（这是它敢给你用的原因）

1. **正向白名单**：只动系统 Temp、浏览器缓存、包管理缓存、IM/工具纯缓存子目录，**其余一律不碰**。
2. **绝对禁区**：系统目录、桌面、文档、下载、图片、视频、音乐等个人资料目录——**永不进入清理清单**。
3. **默认 dry-run**：`clean` 不加 `--yes` 只列清单不删；删除前每个目标二次校验，命中禁区立即拦截。
4. **不删联接/符号链接**：避免误伤迁移过的目录。
5. **账实对账**：每个动作「声称释放 vs 系统实测」强制核对，不符自动记录。
6. **零上传**：**纯本地运行，不读取、不上传任何你的文件。** 没有网络请求，没有云端。
7. **不自动清空回收站**：清空回收站是唯一高危操作，**永远需要你手动执行并二次确认**。

## 七、为什么可以放心用

- **零上传**：不像某些清理软件那样偷偷收集数据
- **账实透明**：动了哪些、没动哪些、为什么，全都告诉你
- **边删边写**：删除台账实时记录，中途崩溃也不丢
- **禁区二次校验**：关键目录永远拦得住
- **作者自己在用**：这是从真实踩坑中长出来的工具，不是拼凑出来的

## 八、注意事项

- 首次建议先 `doctor` / `plan` 看清单，再 `clean --yes`
- `recycle --purge` 不可逆，请谨慎（会清空全部回收站）
- 换电脑自动适配盘符与用户目录，不写死任何路径
- 不触碰你的个人资料与聊天数据本体
