# 净盘师 DiskSage · 发布包说明

> 一个基于真实踩坑经验、可上架 WorkBuddy Skill Pay 的 Windows 智能净盘师工具。
> 自动体检 → 分级 → 安全清理 → 账实对账 → 自进化（三基因）。
> **免费版全功能、零上传、账实相符；省心版买"不操心"。**

---

## 一、这是什么

净盘师 DiskSage 把"科学清理磁盘"做成可复用、可上架、可分成的能力。它不是又一个 `rm -rf` 脚本——**先体检、再分级、最后才清理**，每一步可追溯、可回看、极低误删。

**三基因（实战长出来的，不是口号）**
- **反省**：动手前先读血泪史正本；每个动作做「声称释放 vs df 实测」对账，对不上自动记偏差。
- **进化**：偏差与新坑自动追加进 lessons.md；learn 命令人工落教训；规则随教训演进，绝不重犯。
- **超越（实践中自我迭代）**：`evolve` 命令分析运行指纹，自动调优规则库并推进 `RULES_VERSION`；省心版还能接收云端规则库演进推送——越用越懂你的机器。

**它解决什么痛点**
- C 盘红了不知道删啥 → `doctor` 一键体检，告诉你空间卡在哪。
- "清理软件"反而越清越乱 → 正向白名单，只动可重建缓存/Temp，其余不碰。
- "释放 10G"是假的 → 回收站 $I 是"收据"不是"数据"，以 df 实测为准，强制对账。
- 清完没记录查不清 → 删除台账边删边写，崩溃不丢账。

## 五、安全模型（铁律）

1. **正向白名单**：只动系统 Temp / 浏览器缓存 / 包管理缓存 / IM·工具纯缓存子目录（cache/temp/gpucache…），其余一律不碰。
2. **R3 绝对禁区**：系统区（Windows/Program Files/ProgramData）、用户个人资料（Desktop/Documents/Downloads/Pictures/Videos/Music/.workbuddy）、AppData\Roaming 整体——永不进入清理清单。
3. **dry-run 默认**：`clean` 不加 `--yes` 只列清单不删；删除前每个目标二次校验 R3，命中即拦截。
4. **不删联接/符号链接**：避免误伤迁移目录（如剪映迁到别的盘）。
5. **账实对账**：每个动作「声称释放 vs df 实测」强制核对，不符自动记偏差进教训库。
6. **回收站净化**：删除后自动提示回收站精确净化，避免"删了但空间没涨"。
7. **零上传红线**：纯本地运行，**不读取、不上传任何用户隐私文件**——与 CCleaner（2017 供应链投毒事件后信任受损）最根本的区别，也是信任基石。

## 九、自我迭代机制（三基因在实践中的硬落地）

净盘师是**越用越懂你机器的活系统**，不是交付即终点的脚本：
- **反省**：每次运行先读 `lessons.md` 血泪史正本，动手前规避已知坑。
- **进化**：账实不符、误判、新坑自动落教训进正本；`learn` 支持人工沉淀经验。
- **超越（实践中自我迭代）**：`evolve` 读取 `history.jsonl` + `clean_manifest.jsonl` 的运行指纹（释放量、账实相符度趋势、最常清理类型、拦截次数），自动判定规则库是否需调优并推进 `RULES_VERSION`。省心版 PRO 用户额外接收**云端规则库演进推送**——把海量机器的踩坑经验汇成持续进化的专家判断，这是脚本类工具抄不走的护城河。

## 十、信任与推荐（让人用了想推荐）

- **信任来源**：零上传 + 账实对账透明（声称 vs 实测，差异自动说明）+ 删除台账边删边写（崩溃不丢账）+ R3 禁区二次校验。每次清理给你"安全凭证"：动了哪些、没动哪些、为什么。
- **推荐载体**：`report` 命令生成"省心报告"——累计释放空间、账实相符度、零误删、拦截次数，配一行可一键复制的分享文案（带 #磁盘清理 #C盘爆满 话题），让用户把"看得见的价值感"发朋友圈/小红书。**看得见的效果，才是最好的广告。**

## 十一、注意事项

- 首次请先 `doctor` / `plan` 看清单，再 `clean --yes`。
- `recycle --purge` 不可逆，慎用（会清空全部回收站）。
- 跨用户：自动探测盘符（固定盘）与用户目录，换机自动适配，不写死任何路径。
- 不触碰用户个人资料与聊天数据本体；删除仅限可重建缓存。
