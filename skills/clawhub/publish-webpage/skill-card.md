## Description:

Publishes a user's simple webpage by generating a self-contained static site, packaging it, deploying it to goclawgo, and returning a shareable URL.

This skill is ready for commercial/non-commercial use.

## Publisher:

[nerkn](https://clawhub.ai/user/nerkn)

### License/Terms of Use:

MIT-0

## Use Case:

External users and assisting agents use this skill to turn a non-technical user's idea into a live one-page website. It is intended for simple pages such as landing pages, portfolios, personal sites, and shareable idea pages deployed through a goclawgo Agent URL.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill publishes content to a live hosting service.

Mitigation: Confirm the page does not include private, confidential, regulated, or proprietary information before deployment.

Risk: The goclawgo Agent URL functions as a project-specific deployment URL.

Mitigation: Treat the Agent URL as sensitive project access information and avoid sharing it unnecessarily.
