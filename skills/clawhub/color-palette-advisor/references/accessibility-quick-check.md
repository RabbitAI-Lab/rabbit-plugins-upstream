# 无障碍对比度速查

## WCAG 2.1 标准

| 级别 | 正文文字 (<18pt/24px) | 大文字 (≥18pt/24px 或 ≥14pt 粗体) | UI 组件 |
|------|----------------------|-----------------------------------|---------|
| AA | ≥ 4.5:1 | ≥ 3:1 | ≥ 3:1 |
| AAA | ≥ 7:1 | ≥ 4.5:1 | - |

## 快速判断规则

1. **白字 + 主色按钮**: 如果主色 lightness > 50%，白字大概率不达标 → 用 600/700
2. **深色文字 + 浅色背景**: #333 以下（含）基本都达标
3. #999 是分水岭：#999 在白底上只有 2.8:1（不达标），#888 约 3.5:1（大字达标）
4. **语义色文字**: 尽量配浅色背景使用；深色背景上需调亮
