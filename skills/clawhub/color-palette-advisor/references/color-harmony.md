# 色彩搭配规则

## 常见搭配方式

### 1. 互补色 (Complementary)

色环上 180° 相对的两个色相。

```
主色 ──→ 色环 180° ──→ 辅助色
示例: 蓝 #3B82F6  ↔  橙 #F97316
```

- **特点**: 对比强烈，视觉冲击大
- **适用**: 促销、需要强调差异的场景
- **注意**: 避免两个高饱和互补色等面积使用，建议 70:30

### 2. 类似色 (Analogous)

色环上相邻 30°-60° 的色相。

```
主色 ──→ ±30°-60° ──→ 辅助色
示例: 蓝 #3B82F6  →  青蓝 #0EA5E9  →  靛紫 #6366F1
```

- **特点**: 和谐统一，视觉舒适
- **适用**: 大多数 App/Web 界面
- **注意**: 需通过明度/饱和度区分层级

### 3. 三角色 (Triadic)

色环上等距 120° 的三个色相。

```
主色 ──→ +120° ──→ 辅助1 ──→ +120° ──→ 辅助2
示例: 蓝 #3B82F6  /  黄 #EAB308  /  红粉 #EC4899
```

- **特点**: 丰富活泼，平衡感好
- **适用**: 儿童产品、创意类应用
- **注意**: 选一个主色，另两个做点缀

### 4. 分裂互补 (Split-Complementary)

互补色两侧各 30°。

```
主色 ──→ 180° ± 30° ──→ 两个辅助色
示例: 蓝 #3B82F6  ↔  橙黄 #F59E0B + 橙红 #EF4444
```

- **特点**: 比互补色柔和，但有足够对比
- **适用**: 需要辅助色区分但又不要太冲
- **推荐**: 大多数商业项目首选

### 5. 单色系 (Monochromatic)

同一色相，通过明度/饱和度变化。

```
主色 500 → 100 (浅) → 900 (深)
```

- **特点**: 极致统一，高级感
- **适用**: 高端品牌、极简设计
- **注意**: 需通过明度差区分层级，建议 ≥20%

## 辅助色选择建议

| 主色 | 推荐辅助色搭配方式 | 辅助色示例 |
|------|-------------------|-----------|
| 蓝 | 分裂互补 | 橙黄 + 橙红 |
| 绿 | 类似色 | 青蓝 + 黄绿 |
| 红 | 类似色 | 橙 + 粉 |
| 紫 | 互补色 | 黄绿 |
| 橙 | 类似色 | 红 + 黄 |
| 青 | 分裂互补 | 红橙 + 紫红 |

## 深色模式调色原则

1. **主色调亮 1-2 档**: 500 → 400/300 用于按钮和强调
2. **背景非纯黑**: 用 #0D0D0D / #111827 而非 #000000
3. **文字非纯白**: 用 #E5E7EB / #F3F4F6 而非 #FFFFFF（减少眩光）
4. **降低饱和度**: 深色模式下高饱和色刺眼，适当降饱和
5. **阴影反向**: 深色模式用更深的黑做"凹陷"效果，不用阴影做层级
