## Description:

Plan or re-plan the work in the TODO.md task tree using /todo-plan [<goal>] [--revise [<reason>]].

This skill is ready for commercial/non-commercial use.

## Publisher:

[bassemzohdy](https://clawhub.ai/user/bassemzohdy)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to turn a goal into a proposed plan document and TODO tree, or to revise an existing plan. It presents the full proposal and waits for confirmation before writing plan changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Some referenced local planning materials were unavailable to the security scan, so their contents were not assessed.

Mitigation: Review the referenced todo core, todo-add, and verification materials, and review the proposed plan and TODO tree before confirming changes.
