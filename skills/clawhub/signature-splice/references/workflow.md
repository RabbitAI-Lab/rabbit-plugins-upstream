# signature-splice — 工作流与实现细节

本文件是 `SKILL.md` 的展开，解释"为什么这么做"与"怎么调参"。抽象工作流固定 4 步，具体参数全部外置。

## 1. 归一化模型：一个公式吃掉四种底子

签名图常见四种来源，肉眼看着不一样，但都可以用**合成到白底后的亮度**统一表达：

```
alpha   = A / 255
lum     = 0.299R + 0.587G + 0.114B            # 原始亮度
lum_eff = 255 - (255 - lum) * alpha           # 合成到白纸后的亮度（0=黑，255=白）
```

| 来源 | 表现 | lum_eff 表现 |
|------|------|--------------|
| 白底 JPG/PNG | 不透明、白底黑字 | = lum，字黑底白 |
| 透明 PNG（墨=黑+α） | RGB 全黑，形状在 α | α 处≈0（黑），其余=255（白） |
| 深底浅字 | 背景暗、笔画亮 | 背景低、笔画高 |
| 截图 | 带边框/灰底 | 边框/灰底为中间值 |

**墨迹度**（越大越像墨）：

```
浅底深字（light）： ink = 255 - lum_eff
深底浅字（dark） ： ink = lum_eff
```

极性（light/dark）默认 `auto`：取**边带**（外 12%）像素 `lum_eff` 的**中位数**当背景亮度，≥128 视为浅底。
"墨迹只在 alpha 通道"的 PNG 在合成后边带=纯白，会被正确判成 light。

## 2. 去截图边框（`trim_frame`）

在**外侧边带**（`--margin-frac`，默认 6%）里，把"几乎整行/整列都非背景"的行/列当作边框线：

- 逐边找：`col[x] > --frame-span`（默认 0.85）→ 记为该边最内侧的边框线；
- 从页面边缘**裁到该线（含）**；
- 注意最外 1~2 像素可能是白缝、黑线在其内侧 → 因此在**边带内扫描**而不是只看最外一圈。

对普通签名（边框区近乎空白）不会误裁；对长竖笔画（覆盖率通常 < 0.85）也不会误裁。

## 3. 阈值与去噪

- 基础阈值 `--ink-threshold`（默认 35）。
- **自适应**：`threshold = max(基础, P25(ink) + --adaptive-delta)`。
  用 25 分位估计"背景墨迹"（背景占多数时 P25≈背景），避免把灰底/阴影整片当成墨。`--adaptive-delta=0` 关闭。
- `--min-blob`：`scipy.ndimage.label` 去连通域，删掉像素数小于阈值的孤立点（JPG 噪点）。
- 按掩码取包围盒，四周加 `--pad-frac` 透明边距。
- 输出：RGBA，`α = ink`，`RGB = 0`（或 `--keep-color` 且为浅底时保留原色）。

**产物形态**：紧裁、透明底、纯黑墨 → 合成到白纸上"像是直接签上去的"，不带方块底、不带灰边。

## 4. 区域定位的几何

```
region.x0 = frame.x0 + inset
region.x1 = frame.x1 - inset
region.y0 = anchor_line.y1 + gap
region.y1 = frame.y1 - inset
```

- `frame` = 包含锚点行、面积最小的已合并矢量框；
- `anchor_line` = 含锚点文本的整行 bbox；
- `inset`（默认 2.5）、`gap`（默认 3.0）单位 pt。

**取框的合并规则**：把 `page.get_drawings()` 的每条线（多为 0.75pt 的细矩形）按"相交或间距 ≤ tol
（默认 0.5pt）"迭代合并成 bbox。表格的众多单元格会合并成整张表的大框；独立的签字栏方框自成一框。
因为只接受"高度 ≥ 2×行高且包含锚点行"的框，表格大框会把锚点行也圈进去吗？不会——锚点行在签字栏里、
不在表格里，所以最小包含框就是签字栏那个框。

**回退**：若无框（纯扫描件）→ 报 `error`，请改用 `--box`/`--rect`。

---

## 5. 均匀排版

区域被切成 `rows × cols` 个**等大格子**（`cols` 缺省 = ⌈N / rows⌉）；每格再按 `--cell-fill`
（默认 0.94）向中心收边，得到 target；签名按**等比缩放**放进 target（`keep_proportion=True`）并居中。
→ 结果：每个签名**高度一致、水平等距**，互不重叠、不越框。

- 一行放 N 个（默认 `--rows 1`）最常见；
- 人多 / 区域矮时可 `--rows 2 --cols 2` 之类；
- 想更大/更小：调 `--cell-fill`（0.9 更松、0.99 更满）或 `--inset/--gap` 改区域。

## 6. 一个完整实例（匿名）

- 场景：某单页报名表，法律声明栏是一个矢量方框，内含一行 `参加人员（签名）：`。
- 锚点：`（签名）` → `--anchor "（签名）"` 自动命中该行所在的框。
- 自动框 / 自动区域：由 `locate_anchor.py` 输出（= 锚点行下方、框内留边距），无需手填坐标。
- 4 张签名来源各异：白底 JPG ×2、透明 PNG ×1、"墨迹只在 alpha 通道"的 PNG ×1、
  **截图（带灰框 + 黑竖线）** ×1 → 经预处理统一为透明底·紧裁·纯黑。
- 顺序：`--order "甲,乙,丙,丁"`（= 名单自上而下）。
- 校验：页数不变、正文逐页文本一致、嵌入 N 张带 alpha 的 PNG。
- 结论：跑通一次后，换 PDF / 换签名 / 换顺序都只是改参数重跑。

## 7. 调参速查

| 想要 | 调 |
|------|----|
| 去更多灰底/阴影 | ↑ `--adaptive-delta`、↑ `--ink-threshold` |
| 去更多截图边框 | ↑ `--margin-frac`、↓ `--frame-span` |
| 保留更细的笔画（别裁太狠） | ↓ `--ink-threshold`、↑ `--pad-frac` |
| 去更多噪点 | ↑ `--min-blob` |
| 保留墨色 | `--keep-color` |
| 极性反了 | `--polarity light` 或 `dark` |
| 签名更大/更小 | ↑/↓ `--cell-fill`，或改 `--inset`/`--gap`/`--rect` |
| 多行排布 | `--rows 2`（默认 `--cols` 自动） |
| 加姓名标注 | `--labels`（建议单行时用） |
