## Use Case:

Project managers, commercial teams, and finance reviewers use this skill before monthly construction output-value confirmation to recalculate table values, check totals, find duplicate or incomplete rows, and identify negative amounts. It reports source-backed findings and lists missing materials when the input is insufficient.
