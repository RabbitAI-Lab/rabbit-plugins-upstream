## Description: <br>
Obsidian Tasks helps agents set up and manage task boards in Obsidian vaults using Kanban boards, Dataview dashboards, and structured Markdown task notes. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[larsderidder](https://clawhub.ai/user/larsderidder) <br>

### License/Terms of Use: <br>
MIT <br>


## Use Case: <br>
Developers, knowledge workers, and teams using agent-assisted Obsidian workflows use this skill to initialize and maintain a task pipeline, update task notes and board cards, and link tasks to supporting notes or research. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can create and edit task Markdown files inside the Obsidian vault and folder selected by the user. <br>
Mitigation: Confirm the vault path before setup, and use backups or version control when the vault contains important notes. <br>
