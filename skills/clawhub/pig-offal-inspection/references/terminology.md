## 2. 非食用猪副产品

指生猪屠宰加工后，所得毛皮、毛、蹄壳、三腺等不可食用的产品。

### 2.1 完整列表

| 序号 | 名称 | 不可食用原因 |
|------|------|-------------|
| 1 | 毛皮 | 可能携带病原体 |
| 2 | 毛 | 非食用部分 |
| 3 | 蹄壳 | 非食用部分 |
| 4 | 胆囊 | 含有有毒成分 |
| 5 | 胆汁 | 含有有毒成分 |
| 6 | 甲状腺 | 含有激素类物质 |
| 7 | 肾上腺 | 含有激素类物质 |
| 8 | 病变淋巴结 | 可能携带病原体 |

### 2.2 三腺定义

- **甲状腺**：位于喉部，气管两侧，能分泌甲状腺激素
- **肾上腺**：位于肾脏上方，能分泌肾上腺素等激素
- **病变淋巴结**：发生病变的淋巴结组织

## 3. 部位详细定义

### 3.1 猪头类

| 名称 | 定义 |
|------|------|
| **猪三角头**（猪瘦头） | 从颈部寰骨处下刀，左右各划割至露出关节（颈寰关节）和咬肌，露出左右咬肌约3cm~4cm，然后将颈肉在离下巴痣6cm~7cm处割开，不露脑顶骨，呈三角形状的完整猪头 |
| **猪平头** | 从齐耳根进刀，直线划至下颌骨，将颈肉在离下巴痣6cm~7cm处割开，不露脑顶骨的完整猪头 |

### 3.2 内脏类

| 名称 | 定义 |
|------|------|
| **猪天堂**（猪天梯、猪牙卡） | 生猪屠宰加工后获得的上腭 |
| **猪舌根肉** | 生猪屠宰加工后获得的舌咽肌 |
| **猪腰** | 生猪屠宰加工后获得的肾 |
| **猪肚** | 生猪屠宰加工后获得的胃 |
| **猪小肚** | 生猪屠宰加工后获得的膀胱 |
| **猪小肚系**（猪尿管、猪膀胱系） | 生猪屠宰加工后获得的尿道管 |
| **猪沙肝** | 生猪屠宰加工后获得的脾脏 |
| **猪脏** | 泛指可食用的内脏器官 |

### 3.3 肠类

| 名称 | 定义 |
|------|------|
| **猪大肠** | 生猪屠宰加工后获得的直肠、盲肠和结肠 |
| **猪小肠** | 生猪屠宰加工后获得的十二指肠、空肠、回肠，包括肠黏膜 |
| **猪小肠头** | 生猪屠宰加工后获得的十二指肠 |
| **猪花肠**（猪生肠） | 生猪屠宰加工后获得的子宫 |

### 3.4 油脂类

| 名称 | 定义 |
|------|------|
| **猪花油** | 生猪屠宰加工后获得的肠外侧呈鸡冠状的油脂 |
| **猪网油** | 生猪屠宰加工后获得的胃外侧呈网状的油脂 |
| **猪板油** | 猪腹腔内的脂肪组织 |
