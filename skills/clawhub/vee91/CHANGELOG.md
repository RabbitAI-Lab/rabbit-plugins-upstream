# V90 Changelog

V90 is the architecture-level expansion of V80.

Major additions:
- Heterogeneous Model Fabric
- Provider-neutral adapters
- Agent Swarm + reputation
- MCP/A2A-ready tool/agent mesh
- Evidence graph and layered memory
- Genetic capability evolution
- Environment and challenge factories
- Pareto evaluation and independent verification
- Durable mission/workflow compiler
- Sovereign control plane
- Hardware-aware compute routing
- Security/supply-chain boundaries
- Explicit autonomy levels
- Human-attention optimization
- Capability/mission registries

V90 is not an assertion of unlimited capability. It is a design for continuously measuring and extending capability under explicit constraints.
