# Memory Layers

1. Working memory: current task.
2. Episodic memory: prior task traces.
3. Semantic memory: verified facts and concepts.
4. Procedural memory: successful workflows/skills.
5. Failure memory: known failure modes.
6. Provenance memory: source and transformation history.
7. Capability memory: model/tool/agent benchmarks.

Each layer has retention and invalidation rules.
