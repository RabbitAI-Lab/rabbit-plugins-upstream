# Genetic Evolution Engine

A capability genome is:
model + prompt/policy + tool set + routing policy + memory policy + workflow + evaluator + resource budget.

Operators:
- mutation: alter one component
- recombination: combine successful components
- ablation: remove unnecessary components
- compression: reduce cost/latency
- specialization: optimize for a task family
- diversification: maintain genuinely different candidates

Selection must use independent benchmarks and safety gates.
