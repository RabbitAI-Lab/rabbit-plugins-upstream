# Autonomy Levels

L0: advise only.
L1: execute reversible local actions.
L2: execute bounded multi-step workflows.
L3: operate durable missions with checkpoints.
L4: self-optimize inside sandbox with automatic regression gates.
L5: propose production changes but require explicit approval for irreversible/high-impact actions.

Do not grant autonomy based only on confidence. Increase autonomy based on verified reliability and bounded permissions.
