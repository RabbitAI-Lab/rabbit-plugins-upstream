# Agent Swarm

Use role-specialized workers:
Researcher, Planner, Builder, Designer, Coder, Data Analyst, Critic, Red Teamer, Verifier, Operator, Librarian.

Swarm patterns:
- map/reduce
- debate
- tournament
- jury
- pipeline
- hierarchical delegation
- independent replication

Use A2A-compatible discovery/delegation where available. Do not assume every agent is trusted; apply capability and provenance checks.
