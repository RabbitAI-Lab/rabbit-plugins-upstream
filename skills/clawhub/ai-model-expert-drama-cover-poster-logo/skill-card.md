## Known Risks and Mitigations:

Risk: Uploaded reference images, videos, audio, prompts, task IDs, and generated outputs are submitted to AI-HIVE and should be treated as provider-visible data.

Mitigation: Use only assets intended for AI-HIVE processing, avoid sensitive media, and confirm users understand the provider-visible data flow before upload.

Risk: Using unlicensed media, protected likenesses, trademarks, or unsupported brand claims in generated covers or videos can create rights and accuracy issues.

Mitigation: Confirm authorization for source media, likenesses, music, trademarks, and brand facts before generation and again before publication.

Risk: AI-HIVE API keys are required for task submission and can expose account access if copied into public artifacts or screenshots.

Mitigation: Keep API keys in local environment variables or private config, never commit real keys, and rotate keys if exposure is suspected.
