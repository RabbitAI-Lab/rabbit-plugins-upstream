# 薇芯聊天记录导出小程序（weixin 4.x / Windows）

一个**交互式终端小程序**，把本机**已登录薇芯（个人号）**的聊天记录解密导出成 TXT：扫描可导出的会话 → 勾选 → 一次性导出或实时监听；导出文件已存在时**自动追加**新消息；消息尽量详细（系统消息、转账/红包/文件/链接/引用/撤回/拍一拍等）；每条带发送人**唯一标识** `显示名(wxid)`。

> ⚠️ 仅用于**本人设备、本人账号**的数据，本地学习研究。读取进程内存取密钥、解密本地库违反薇芯用户协议；导出的 TXT 含他人个人信息，请只留本地、勿传播或上传。全流程无任何网络请求。

## 操作系统支持

- **仅 Windows 已验证**。抓密钥（`setup`）依赖 Frida hook `Weixin.dll` 里 x64 的 `aesni_set_encrypt_key`，是 **Windows 专有**的，macOS/Linux 需各自单独逆向，**目前未支持/未验证**。
- 解密、读取、导出、skill 读写均为**纯 Python**，理论跨平台——只要你已有某账号的 `keys/<wxid>.json` 和对应的 `db_storage` 数据，在其他系统上也能读/导出；但这条路径同样未在非 Windows 上验证。

## 快速开始

```bash
pip install pycryptodome psutil frida zstandard
python wechat_export.py
```

按菜单走：**1 选账号 → 2 抓密钥 → 3 扫描会话 → 4 选会话 → 5 导出 / 6 实时监听**。

- **1 检测/选择账号**：自动从运行中的薇芯探测数据目录与 `wxid`（支持多账号）。
- **2 密钥状态 / 抓取**：显示各库密钥是否就绪；需要时一键抓取——抓取期间请按提示在薇芯里**多点开会话、搜索聊天内容、打开收藏/朋友圈/公众号**（每个库的连接首次打开时才暴露它的密钥）。密钥稳定，抓一次长期复用，存于 `keys/<wxid>.json`。
- **3 扫描会话**：列出可导出的会话（显示名 / 类型 / 消息数 / 最近时间 / wxid）。
- **4 选择会话**：输入序号 `1,3,5`、区间 `2-6`、`all` 或 `none`。
- **5 立即导出**：写到 `export/<wxid>/<会话名>_<wxid尾>.txt`；已存在则追加。
- **6 实时监听**：先全量，再每隔若干秒轮询追加新消息（Ctrl+C 停）。
- **7 设置**：输出目录、轮询间隔。
- **8 清理 / 还原初始状态**：删除本项目生成的全部内容（密钥 `keys/`、导出 `export/`、增量状态 `state/`、缓存等），还原成"刚拿到代码"的样子；会先列出待删项并要你输入 `y` 确认，只动项目目录、不碰薇芯本身的数据。

## 导出格式

```
===== 会话：张三（wxid_aaaaaaaa）=====
[2026-11-27 19:28:09] 我(wxid_bbbbbbbb): 你好啊
[2026-11-27 20:56:37] 李四(wxid_cccccccc): 测试
[2026-11-27 17:34:23] 张三(wxid_aaaaaaaa): [链接:邀请你加入群聊] https://...
```

发送人恒带**唯一标识** `wxid`（昵称撞名也能区分）。显示名优先级：**群昵称（群聊）> 联系人备注/昵称 > wxid**；都没有时直接显示 `wxid`。本人显示为 `我(自己的wxid)`。

消息类型：文本原样；其余带细节占位——`[图片] [语音 Ns] [视频 Ns] [名片:x] [动画表情] [位置:x] [文件:名 大小] [链接:标题] url [引用] 本文（引用 某人:原文） [转账 ¥金额 备注] [红包 祝福语] [小程序:名] [视频号:x] [聊天记录:x] [系统] … [拍一拍] …`；未识别类型写 `[未知消息 type=N] 原文片段`，不丢信息。

### 媒体本体
导出时自动把**文件**和**视频**的本体复制到 `export/<wxid>/media/<会话名>/`，并在消息行尾标出相对路径，例如：

```
[2026-11-28 01:32:48] 我(wxid_bbbbbbbb): [文件:example.pdf 502.0KB]  -> media/张三/example.pdf
[2026-11-28 01:33:31] 我(wxid_bbbbbbbb): [视频 4s]  -> media/张三/video.mp4
```

- 文件在磁盘上是明文（`msg/file/<月>/<原名>`），按文件名匹配。
- 视频是明文 `.mp4`（`msg/video/<月>/*.mp4`），按**内容 md5** 匹配消息。
- **图片**本体**未导出**，行尾标注「图片本体需图片密钥，暂未导出」。原因：图片在磁盘上是 V2 加密的 `.dat`（`msg/attach/<会话hash>/<月>/Img/*.dat`），解密成 `wxgf`（薇芯自有格式，内层是 HEVC 编码的静态图），再转成 JPEG/PNG。链路已基本打通——`.dat` 头(31B)+1KB AES-128-ECB+XOR 的布局已摸清，`wxgf→HEVC→PNG` 也用 ffmpeg 验证可行；唯独那把 **16 字节图片 AES 密钥**取不到：它由 `Weixin.dll` 内置的软件 AES 使用（不走已 hook 的 OpenSSL 路径），且不以明文常驻内存（4 次全内存穷举均无）。要拿到它需逆向定位并 hook 该软件 AES 的密钥扩展函数，属更深的逆向，暂未做。
  - 变通：对**已在薇芯里查看过**的图片，薇芯会把解密后的 `wxgf` 落到 `cache/<月>/Message/<会话hash>/ImageTemp/`，可用 `ffmpeg` 把其中的 HEVC 转成 PNG（无需密钥），但只覆盖看过的图。

## 命令行（脚本化，可选）

交互之外也可用 `export.py`：

```bash
python export.py --list                    # 列出会话
python export.py --once --targets 张三,某群   # 导出一次（子串匹配显示名/wxid）
python export.py --targets 张三             # 导出后进入实时监听
python export.py --account <wxid>          # 指定账号
```

## 原理

薇芯 4.x 本地库用 **SQLCipher 4** 加密（AES-256-CBC + HMAC-SHA512，PBKDF2 256000，页 4096，保留区 80）。该版本把密钥混淆存放、内存无明文，且**每库一把独立密钥**。

获取点：薇芯打开每个库连接时会调用 `Weixin.dll` 里（静态 OpenSSL）`aesni_set_encrypt_key` 展开 AES 密钥，入口 `RCX` 指向 32 字节原始 key。`capture_keys.py` 用 Frida hook 它（函数入口按特征字节自动定位），再用「AES 解 `contact.db` 首块看 SQLite 头」的**方案无关校验**把每把 key 对到具体库。

## 文件

| 文件 | 作用 |
|---|---|
| `wechat_export.py` | **交互式小程序（主入口）** |
| `capture_keys.py` | Frida 抓各库密钥（`capture()` 可被调用，也可独立运行） |
| `wxread.py` | 账号探测、解密打开、联系人、会话扫描、发送人唯一标识、详细消息格式化 |
| `exporter.py` | 导出引擎：`export_once` / `monitor`，追加 + 增量状态 |
| `wxmedia.py` | 媒体本体定位与导出（文件/视频明文复制；图片 .dat 待密钥） |
| `export.py` | 非交互 CLI |
| `decrypt.py` | SQLCipher4 整库解密 |
| `keys/<wxid>.json` | 各库密钥（按账号） |
| `state/<wxid>.json` | 增量位置（文件已存在就追加的依据） |
| `export/<wxid>/*.txt` | 导出结果 |

## 已知限制

- **准实时**：只解密主 `.db`，最新消息可能还在未落盘的 `-wal` 里，有几秒延迟。
- 群成员**群内昵称**已支持（解析 `chat_room.ext_buffer` protobuf）：优先级 群昵称 > 联系人备注/昵称 > `wxid`；没设群昵称也不是好友时回退显示 `wxid`（唯一标识仍在）。个别系统消息模板里的 `$占位$` 未回填。
- 媒体本体：**文件、视频已导出**（明文复制到 `media/`）；**图片**本体待图片 AES 密钥（见上）暂未导出，只给占位；**语音**存于 media 库（需额外密钥 + silk 解码），暂未导出，只给 `[语音 Ns]`。
- 抓密钥需薇芯在运行并登录；`capture_keys.py` 的函数定位依赖特征字节，薇芯大版本改动该处时可能需重新定位。
- 旧的 `keys.py`（内存扫描）在 4.x 已失效，由 `capture_keys.py` 取代。
