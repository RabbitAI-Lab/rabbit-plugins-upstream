## 📌 为什么做这个 Skill？(Why We Built This)

在准备科技大厂（Google, Meta, 字节跳动, 腾讯, 美团）的产品经理（PM）面试，或者日常提升 **Product Sense（产品感官）** 时，绝大多数求职者与 PM 都会陷入以下三个顽固的困境：

1. **纸上谈兵与伪收敛**：背了很多框架（CIRCLES、STAR、RICE），但在实际面对开放性问题或真实项目追问时，往往逻辑散乱、无法落地，自己却浑然不知。
2. **真人 Mock 成本极高**：找大厂 PM 导师或同行进行模拟面试，时间难对齐、金钱成本高，且无法做到随时随地的高频训练。
3. **通用 AI 的“伪模拟”陷阱**：
   - **太温柔**：通用 AI 聊天默认倾向于顺着用户说，缺乏真实面试中对逻辑死角、假定前提和数据归因漏洞的**高强度追问（Grill）**。
   - **只问不教**：即使使用某些追问 Prompt，AI 往往也只是把你问到哑口无言，却无法指出具体扣分点，更无法示范顶级 PM 在该场景下如何结构化解答。

**`PM Interview Grill Me` 正是为了打破这一绝症而生。** 它的定位不是又一个静态的提示词词库，而是一套**具有大厂 PM 总监主权意识的“高强度拷问 + 即时框架教练”原生 Agent Skill**。

## 💎 核心价值与差异化定位 (Core Value Proposition)

| 维度 | 自主看书/背框架 | 通用 AI 对话 (裸 Prompt) | 真人 PM 模拟面试 | **PM Interview Grill Me** |
|---|---|---|---|---|
| **反应强度** | 零（无反馈） | 温和顺从，缺乏质疑 | 高（视面试官水平而定） | **高（深度刨根问底，直击逻辑假定漏洞）** |
| **即时教学** | 静态知识 | 极少，多为泛泛而谈 | 取决于导师意愿 | **每轮必给：优点拆解 + 扣分点 + 金牌示范回答** |
| **使用成本** | 低 | 低，但效果差 | 极高（时间+金钱） | **零门槛（随时随地在 Agent CLI 中触发）** |
| **复盘闭环** | 无 | 无结构 | 依赖人工笔记 | **结构化评级卡（Rubric）与示范对比** |

### 核心使命
> **“在挨打中学会思考，在示范中建立标准。”**  
> 让你在真正踏入大厂面试场之前，已经经历过上百次高强度的思维碰撞，并熟练掌握顶级 PM 的结构化表达习惯。

## 🎯 考核模式 (Interview Modes)

### 模式 A：四大经典题型抽考
针对 PM 面试最核心的四大能力板块进行标准化测试：
1. **Product Design & Sense（产品设计与感官）**：考察需求定义、用户画像与解决方案选型（CIRCLES 框架）。
2. **Metrics & Data Analytics（数据指标与分析）**：考察指标体系搭建（AARM/GAME）与数据异常下跌排查（5 步归因法）。
3. **Product Strategy & Monetization（商业策略与变现）**：考察 TAM 市场估算、商业化定价与商业模式 Fit（BUS 框架）。
4. **Behavioral & Execution（行为面试与执行力）**：考察团队冲突、需求优先级拒绝与危机处理（STAR 框架）。

### 模式 B：简历与真实项目“深度烤问”
- 输入你的真实 PM 项目经历或简历段落。
- 面试官将化身严苛的高管，对你的**项目 ROI、数据真实归因、方案推导逻辑、反向指标风险**进行连续 3-5 轮深挖。

## 🚀 原生 Skill 一键安装与使用 (Direct Skill Installation)

本项目遵循标准的 **Agent Skill 规范 (`SKILL.md`)**。安装后即可在你的 AI Agent CLI 中直接通过自然语言触发，**无需手动复制任何提示词**！

### 1. Codex & 通用 Agent CLI 安装

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/isdou/pm-interview-grill.git ~/.agents/skills/pm-interview-grill
```

### 2. Antigravity Agent 安装

```bash
mkdir -p ~/.gemini/config/skills
git clone https://github.com/isdou/pm-interview-grill.git ~/.gemini/config/skills/pm-interview-grill
```

### 3. Claude Code 安装

```bash
mkdir -p ~/.claude/skills
git clone https://github.com/isdou/pm-interview-grill.git ~/.claude/skills/pm-interview-grill
```
