External users and agents use this skill to research Binance cryptocurrency markets, gather market data, calculate technical indicators, plan DCA schedules, size positions, scan USDT pairs, and summarize whale activity for informational trading research. <br>

Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill contacts Binance public market APIs and may fail or be unavailable in some regions. <br>
Mitigation: Use it only where Binance API access is permitted, respect rate limits, and do not use VPN guidance to bypass regional restrictions. <br>
Risk: Reference material includes examples for authenticated account access and order placement. <br>
Mitigation: Do not provide live Binance API keys or run order-placement examples without separate review, testnet or dry-run safeguards, least-privilege keys, and explicit human confirmation. <br>
Risk: Trading analysis can be mistaken for personalized financial advice. <br>
Mitigation: Treat outputs as informational research, include risk caveats, and require the user to make and validate any trading decision. <br>
