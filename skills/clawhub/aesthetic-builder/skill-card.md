## Description: <br>
Aesthetic Builder helps an agent create complete aesthetic style-system skills from a visual concept or extract a shared aesthetic layer from multiple Character Builder roles using a three-layer, nine-dimension interaction model. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[wavegeometry](https://clawhub.ai/user/wavegeometry) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Designers, creative technologists, and agent builders use this skill to turn aesthetic concepts, visual style goals, or groups of character roles into reusable aesthetic system Skill files. It is suited for brand systems, UI visual guidance, art direction, spatial design guidance, and IP visual consistency work. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad design-related trigger terms may invoke the skill during general design conversations. <br>
Mitigation: Install it only when a Chinese-language aesthetic style-system workflow is desired, and confirm that its scope matches the active task. <br>
Risk: Generated Skill files may contain aesthetic judgments, cultural references, or style guidance that need review before reuse. <br>
Mitigation: Review generated Skill files before installing or relying on them, especially cultural references, color claims, and design constraints. <br>
