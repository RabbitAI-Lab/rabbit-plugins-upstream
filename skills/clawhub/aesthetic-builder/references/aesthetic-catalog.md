## 审美技能清单与依赖拓扑

审美建造器按审美生成流程组织的方法论执行任务清单，附任务间关系和元操作映射提示。

**域间逻辑流**：A0（ab-04模式检测→路由） → A1/A2/A3（三层可并行启动，共享交互上下文） → A4（跨维交互映射） → A5

**双模式路由**: Mode A（独立审美生成）→ 标准A0→A5流程 / Mode B（角色风格提取）→ ab-04提取角色数据→标准流程 / Mode C（混合）→ 角色数据作为审美参数约束，其余按标准流程

**关键差异**：不同于Character Builder的严格逐层串行（实体层→社会层→抽象层），Aesthetic Builder的三层(A1/A2/A3)可以并行启动——因为感知层的一个色彩选择不依赖文化层的完成，但各层间的交互效应需在A4阶段集中映射处理。

### 依赖拓扑摘要

#### 一、域内链路

**审美需求解析链路**: ab-04 → ab-00 → ab-01 → ab-02

**感知层链路**: ab-10 → ab-11 → ab-12 → ab-13 → ab-14
（串行但需共享交互上下文——后序任务需读取前序任务的输出作为交互检查依据）

**情感层链路**: ab-20 → ab-21 → ab-22

**文化层链路**: ab-30 → ab-31 → ab-32 → ab-33

**跨维交互链路**: ab-40 → ab-41 → ab-42

**整合输出链路**: ab-50 → ab-51 → ab-52

#### 二、跨域协同链路

**完整审美生成链路**: ab-04 → ab-00 → ab-01 → ab-02 → ab-10/ab-20/ab-30（三层并行启动点）→ ab-11/ab-12/ab-13/ab-14/ab-21/ab-22/ab-31/ab-32/ab-33（各层内串行）→ ab-40 → ab-41 → ab-42 → ab-50 → ab-51 → ab-52

**三层并行启动链路**: ab-02 ⇉ [ab-10, ab-20, ab-30]

**层内串行+交互检查**:
- A1感知层: ab-10 → [ab-11(读ab-10)] → [ab-12(读ab-10,ab-11)] → [ab-13(读ab-11,ab-12)] → [ab-14(读ab-10,ab-11,ab-12,ab-13)]
- A2情感层: ab-20(读ab-10,ab-11) → [ab-21(读ab-13,ab-20)] → [ab-22(读ab-20,ab-21,ab-10,ab-11,ab-13)]
- A3文化层: ab-30(读ab-10,ab-11,ab-20) → [ab-31(读ab-30)] → [ab-32(读A1/A2/A3所有已完成)] → [ab-33(读ab-30,ab-31,ab-32,ab-10,ab-11)]

**交互汇聚链路**: [ab-14, ab-22, ab-33] ⇇ ab-40

**校验汇聚链路**: [ab-40, ab-41, ab-42] ⇇ ab-50

#### 三、三轴协同链路

**执行轴+内容轴**: ab-02 → 清单法填充9维组件（含交互对） → ab-40 → ab-41 → ab-42 → ab-50 → ab-51

**执行轴+创新轴**: ab-02 → 审美创新模式（M6模式直用/M7模式改进可嵌入ab-10/ab-20/ab-30/ab-40等） → ab-50

#### 四、交互对处理追踪链路

不同于Character Builder的"逐维填充→组合验证"模式，Aesthetic Builder新增交互对追踪：

```
ab-10(色彩) ──→ ab-11(形态) ──→ ab-12(材质) ──→ ab-13(空间) ──→ ab-14(感知层校验)
    │              │    │          │    │    │          │
    │   交互上下文共享（颜色上下文传递给形态）  │    │    │   交互上下文共享（形态+材质上下文传递给空间）
    │              │    │───────────────────────→│    │
    │              │        交互上下文共享（形态上下文传递给空间）│
    │              │                              │
    ▼              ▼                              ▼
ab-20(情感基调, 读色彩+形态) → ab-21(节奏, 读空间+情感) → ab-22(情感层校验)
    │
    ▼
ab-30(文化引用, 读色彩+形态+情感) → ab-31(符号) → ab-32(语境) → ab-33(文化层校验)
                                                                    │
                                              ┌─────────────────────┘
                                              ▼
                                    ab-40(跨维交互映射, 读全部9维)
                                              │
                                              ▼
                                    ab-41(协同增强) → ab-42(张力设计)
                                                          │
                                                          ▼
                                                    ab-50(完整性校验)
```

关键原则：每个感知层任务完成后，其输出作为交互上下文供后续任务（同层和跨层）读取。这不是严格串行依赖——而是"信息可用性"的窗口。情感层可以在感知层的首批输出（色彩）完成后即启动，不需要等整个感知层完成。
