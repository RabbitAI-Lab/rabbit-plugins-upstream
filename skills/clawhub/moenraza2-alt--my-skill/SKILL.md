# My First ClawHub Skill

This is my first skill published to the ClawHub registry. I created this skill to learn the publishing workflow and understand how OpenClaw skills work.

## What This Skill Does

This skill serves as a learning project for:
- Understanding the ClawHub skill format
- Learning how to structure `SKILL.md` with proper YAML frontmatter
- Practicing the publish workflow with the ClawHub CLI

## How to Use

1. Install the skill:
   ```bash
   clawhub install my-skill
   ```

2. Use it in your OpenClaw agent configuration

3. Customize based on your needs
