## Description: <br>
Helps agent users, skill authors, maintainers, and teams create practical Skill Vetter-style workflows for bug fixing, setup hardening, reliability improvement, and adjacent skill creation. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
External users, developers, skill authors, and maintainers use this skill to turn skill-vetting requests into action plans, checklists, templates, analyses, code changes, or decision support with explicit validation. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger words and implicit invocation may cause the skill to activate for unrelated requests. <br>
Mitigation: Narrow triggers to explicit skill-vetting phrases and confirm the user's intent before applying the workflow. <br>
