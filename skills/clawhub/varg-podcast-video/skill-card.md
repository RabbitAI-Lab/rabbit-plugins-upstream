## Description:

Creates short podcast-style dialogue videos with consistent AI characters, generated shots, native audio, an HTML storyboard, and a stitched MP4.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

External creators and developers use the skill to turn a short two-character script and reference images into a podcast, interview, debate, or myth-versus-truth video.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Character reference photos and dialogue may be sent to Varg for cloud processing.

Mitigation: Avoid sensitive material and confirm the user is comfortable with cloud processing before submitting references or dialogue.

Risk: Video generation can consume substantial credits.

Mitigation: Estimate the cost and get the user's approval before generating video clips.

Risk: The release guidance flags an unpinned installer and broader installation options.

Mitigation: Review the selected installation source, version, and scope before running its installation command.
