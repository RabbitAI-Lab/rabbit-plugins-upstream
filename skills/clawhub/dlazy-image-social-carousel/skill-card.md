## Description:

Guides social-media carousel design through direction approval, reference-image analysis, and cover-first image generation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and marketing teams use this skill to plan platform-specific social carousels and generate a cover before producing visually consistent follow-up slides.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and supplied media may be sent to dLazy, and generated images are hosted there.

Mitigation: Share only content approved for the hosted service; review sensitive media before upload.

Risk: Logging in may save an API key locally.

Mitigation: Protect the local credential and rotate or revoke the key if exposed.

Risk: The documentation mentions CLI versions 1.0.9 and 1.2.3 inconsistently.

Mitigation: Verify the intended CLI version before installation; use the documented npx path if a global install is undesirable.
