## Description:

Guides the design and creation of social-media carousel slides through an approved direction and cover-first image generation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and marketing teams use this skill to plan platform-specific carousel slides, confirm the visual direction, and generate a cover before matching the remaining slides to it.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected media may be sent to dLazy's hosted API.

Mitigation: Use only content you are comfortable uploading to dLazy; review the CLI package before using sensitive media.

Risk: Use requires a dLazy API key and an optional global CLI installation.

Mitigation: Protect the API key and prefer the on-demand npx option if a persistent global install is undesirable.
