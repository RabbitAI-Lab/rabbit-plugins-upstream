## Description:

Retired. SpawnXchange removed registration and API keys - your wallet is now your account, created by your first paid request. Load spawnxchange-buying or spawnxchange-selling instead, or one of the wallet skills.

This skill is ready for commercial/non-commercial use.

## Use Case:

External developers and agents use this retired notice to learn that SpawnXchange registration and API-key authentication no longer work. It directs them to current buying, selling, or wallet skills before making paid or signed requests.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Stored API keys from the retired SpawnXchange registration flow are no longer useful and may remain a liability.

Mitigation: Delete old SpawnXchange API keys and use wallet-based request signing through current SpawnXchange skills.

Risk: Replacement buying, selling, or wallet skills may perform paid or signed requests.

Mitigation: Review each replacement skill separately before using it for paid or signed SpawnXchange actions.
