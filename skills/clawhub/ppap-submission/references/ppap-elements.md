# PPAP 18 项要素提交要点与常见缺失

> 适用于 AIAG PPAP 第四版，Level 3 提交。

## 1. 设计记录（Design Record）
- 提交最新版图纸 / 三维数模，版本号清晰
- **常见缺失**：版本过期、与 PFMEA 引用的图纸版本不一致

## 2. 授权工程变更文件（EWO/ECN）
- 所有已生效的工程变更单及审批记录
- **常见缺失**：变更未闭环、缺客户回签

## 3. 顾客工程批准
- 客户对样件、偏差、临时变更的书面批准
- 仅在适用时提交

## 4. DFMEA
- 设计责任方须提交；关注严重度、RPN / AP 行动优先级
- **常见缺失**：设计责任在客户时误提交 / 漏提交

## 5. 过程流程图（Process Flow）
- 覆盖制造、检验、返工、存储全步骤，与 PFMEA 过程项对应
- **常见缺失**：遗漏检验/返工工位

## 6. PFMEA
- 过程失效模式、原因、现行控制、S/O/D、AP 行动
- **常见缺失**：与流程图工序不对应、特殊特性未识别

## 7. 控制计划（Control Plan）
- 试产 / 量产控制计划，特性、规范、方法、反应计划齐全
- **常见缺失**：与 PFMEA 特性、控制方法脱节

## 8. 测量系统分析（MSA）
- GRR（% Study Var）、偏倚、线性、稳定性、量具校准
- **阈值**：GRR < 10% 优秀，10–30% 可接受（须审批），> 30% 不合格
- **常见缺失**：仅做 GRR 漏稳定性、关键量具未分析

## 9. 尺寸结果（Dimensional Results）
- 全尺寸实测，注明规范、实测值、合格判定、测量设备
- **常见缺失**：抽样不足、未覆盖全部特殊特性

## 10. 材料/性能试验记录
- 材质证明（材质单、RoHS/REACH）、性能试验报告
- **常见缺失**：材质单无第三方章、性能试验样本量不足

## 11. 初始过程研究（Cpk/Ppk）
- 关键 / 重要特性过程能力，建议 Cpk ≥ 1.33
- **常见缺失**：Ppk 与 Cpk 混用、样本量 < 25、未剔除特殊原因

## 12. 合格实验室文件
- 内部实验室范围证明 / 外部实验室 ISO 17025 资质
- **常见缺失**：外部报告缺认可标识

## 13. 外观批准报告（AAR）
- 外观件（颜色、纹理、光泽）适用，客户签核
- 非外观件不提交

## 14. 生产件样品
- 按提交等级数量，来自有效生产运行（1–8 小时、300+ 件）
- **常见缺失**：用试制件冒充生产件

## 15. 标准样品（Master Sample）
- 封样留存，附顾客批准与有效期
- **常见缺失**：无封样记录、无客户签核

## 16. 检查辅具（Checking Aids）
- 检具、治具、综合量规及校准记录
- **常见缺失**：检具无 GRR、校准过期

## 17. 顾客特殊要求（CSR）
- 客户附加清单（如 Harman RBA、Lamborghini 特定格式）
- **常见缺失**：漏看 CSR、用通用模板套用

## 18. 零件提交保证书（PSW）
- 正式签署，含零件号、变更等级、提交等级、结果判定
- **结果**：批准 / 临时批准（附条件与期限）/ 拒收
- **常见缺失**：PSW 与实测数据矛盾、缺授权签署
