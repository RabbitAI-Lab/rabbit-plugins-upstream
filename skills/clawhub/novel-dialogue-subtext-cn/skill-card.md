## Description:

输入单个章节、场景或短文中的对白片段，并提供人物目标、关系与已知事实；产出不改写事实的新版对白、逐句潜台词和人物差异核对，适用于小说修订。资料不足时先列明缺失项，不臆测人物动机；超过单次场景或表格一百行时要求分批处理。

This skill is ready for commercial/non-commercial use.

## Use Case:

小说作者和编辑可用此技能修订单个场景或短文中的对白：在保留已知事实与情节走向的前提下增强人物声音差异，并逐句说明表层意思、潜台词策略和事实保留情况。

## Known Risks and Mitigations:

Risk: A revised line could imply a fact or character motive that the source material does not establish.

Mitigation: Provide known facts, goals, and relationships, then review each line against them; ask for clarification where the source is ambiguous.

Risk: The README installer command does not pin the CLI or repository version.

Mitigation: Verify the CLI and repository version before installing.
