# 投标否决经验问答

> 投标否决/废标经验问答技能 · 已关联公开知识库「招标投标专家否决汇集」，即装即用。

## 技能简介

本技能聚焦**投标被否决 / 废标**这一垂直场景，帮助投标人理解真实被否原因、规避风险。基于已关联的公开知识库（真实中标候选人公示中提取的否决投标信息）与互联网补充，输出带案例与法规支撑的问答。

**本技能为纯问答技能，不提供数据采集 / 知识库写入能力。**

## 触发场景

- 询问否决 / 废标原因、案例分析、风险预警
- “什么情况会被废标” / “否决投标常见问题” / “投标被拒怎么办”
- “帮我看看这个项目有没有废标风险”

**不适用（移交对应技能）：**

- 一般性招标文件逐条解读 → `bid-doc-interpreter`
- 投标文件编制、报价策略、标书排版 → 投标文件编制技能
- 数据采集 / 知识库写入 → 其他采集工具

## 知识库

- 名称：招标投标专家否决汇集
- 内容：按省份 / 地市组织的否决投标信息
- 权限：公开查询可用；写入仅知识库创建者持有

## 输出示例

```markdown
## 核心结论
[1-2 句话概括最关键发现]

## 常见否决原因及案例
### 1. [否决类别标题]
**风险等级**: 🔴高 / 🟡中 / 🟢低
**具体说明**: ...
**操作建议**: ...
**典型案例**: > [项目名称 + 否决理由]
**参考依据**: > [法规 / 互联网补充]

## 风险预警清单
| 检查项 | 风险等级 | 关键提示 |
|--------|----------|----------|

## 其他建议
## 数据来源说明
```

## 使用技巧

- 提问尽量带项目类型 / 省份 / 行业关键词，命中率更高。
- 可主动要求“给出 XX 地区的实际废标案例”触发精确检索。
