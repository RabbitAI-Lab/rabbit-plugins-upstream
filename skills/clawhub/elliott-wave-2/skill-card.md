## Description: <br>
Provides Elliott Wave analysis guidance for counting waves, identifying extensions, applying Fibonacci retracement and target ratios, and checking core wave-counting constraints. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External users and agents use this skill to structure educational technical-analysis discussions about Elliott Wave counts, extension waves, corrective waves, and Fibonacci price zones. It supports chart-analysis workflows and should not be treated as investment advice. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Users may mistake educational wave-count guidance for investment advice. <br>
Mitigation: State conclusions as analysis support, require independent verification, and avoid relying on wave counts alone for trades. <br>
Risk: Ambiguous charts can support multiple plausible Elliott Wave counts. <br>
Mitigation: Use Fibonacci ratios, the five-wave/three-wave structure, wave-four non-overlap, alternation, and at least one independent signal before presenting a count as useful. <br>
Risk: Thinly traded or unclear markets can distort wave structures. <br>
Mitigation: Apply the skill mainly to liquid markets with clear trends and call out uncertainty when the pattern is not clean. <br>
