# 9 题自检 · 分类矩阵 · 资产卡模板（与 zengzhi.life 首页自检同源）

> 口径：T1–T8 是资产类，P 是"付费验证"放大器（不占编号）。答案只存用户本机，不上传。

## 9 道原题（逐字使用，不要改写）

| # | 类 | 题目 |
|---|---|---|
| 1 | T1 | 你在现在的行业/岗位待了几年？有没有人隔三差五来找你请教？ |
| 2 | T2 | 你有没有自己整理过一套"顺手的东西"——表格、流程、清单、SOP——别人见过后说"发我一份"？ |
| 3 | T3 | 你手里有没有一份别人没有的名单、名录、资料、存档——网上搜不到现成的？ |
| 4 | T4 | 你为自己或团队写过脚本、小工具、自动化流程，甚至内部系统吗？ |
| 5 | T5 | 你公开写过的文章、讲过的课、录过的视频，有被大量收藏转发，或被搬运抄袭过吗？ |
| 6 | T6 | 你做过的 PPT、表格模板、海报、设计稿、拍摄作品，有人说过"这个好，借用一下"吗？ |
| 7 | T7 | 有没有人因为你的账号、口碑、社群，专程找你请教、谈合作、介绍生意？ |
| 8 | T8 | 你用 AI 工具（写 Prompt、搭自动化工作流、定制智能体/Bot）做出过让同事或朋友惊叹"你怎么做到的"的东西吗？ |
| 9 | P | 过去一年，有没有人为"你的东西"付过钱？咨询费、买资料、定制、打赏都算。 |

每题三档：0 = 没有 · 1 = 有一点 · 2 = 常有人专门来找。**对话时一次问 1–2 题，把选项念给用户听。**

## 评分与置信

- 各类基础分 = 该题得分（0–2）
- **P 是乘数**：`最终分 = 基础分 × (1 + 0.5 × P得分)`——付过钱的经验，置信度整体上调
- 命中类（基础分 > 0 的 T）按分数排序输出；全 0 时如实说"暂时没发现现成资产，但这不代表没有——很多资产缺的是'被问对问题'"，然后从第 1 题的行业经验切入继续挖

## 分类矩阵（形态 / 渠道 / 诚实缺口）

| 类 | 名称 | 商品化形态 | 渠道举例 | 最常见的"诚实缺口" |
|---|---|---|---|---|
| T1 | 经验诀窍 | 付费咨询 / 专栏 / 避坑手册 | 知识星球、Gumroad | 缺"从零到一"的成文步骤——口口相传卖不上价，写成手册才卖得动 |
| T2 | 模板清单 | 模板商品（单份或合集） | Gumroad、知识店铺、小红书 | 缺脱敏通用版——去掉你的私货，别人才拿得动 |
| T3 | 数据语料 | 数据产品 / API / 授权 | 数据交易所、API 市场、B 端 | 缺来源与授权链说明——说不清来源的数据没人敢买 |
| T4 | 软件工具 | API / 一次性授权 / 订阅 | RapidAPI、AppSumo、自营 | 缺独立部署说明——别人拿走跑不起来就是废品 |
| T5 | 内容作品 | 付费专栏 / 电子书 / 小课 / 播客 | 公众号付费、知乎、小宇宙 | 缺"从浅到深"的重组——散篇打包不值钱，结构化才行 |
| T6 | 视觉设计 | 成套模板 / 素材 | 素材平台、Gumroad | 缺成套化——单张没量，按行业打包成套才卖得动 |
| T7 | 垂直影响 | 商单 / 带货 / 付费社群门票（不可转让） | 品牌方、联盟分销、知识星球 | 缺自有产品——影响力是放大器，先有 1–2 件货让它放大 |
| T8 | AI 资产 | Prompt 包 / 工作流模板 / Bot 配置 | Coze 商店、GPTs Store、Gumroad | 缺适用场景说明——离开你的私有数据还能跑，才算资产 |

## 资产卡模板（每件资产一张；字段与平台展示页一致）

```markdown
# 资产卡：<资产名>（分类）
- 证据回显：<原样引用用户给的事实/数字/文件名/截图描述；无证据 → 「待补证据：<缺什么>」>
- 商品化示例：<按上表"形态"具体化到这一件>
- 谁愿意付钱：<买方画像，越具体越好>
- 怎么卖：<上表"渠道"里挑 1–2 个，说清第一步>
- 诚实缺口：<上表"缺口"具体化；这是下一步要补的，不是缺点批判>
- 自报价意向：<心理价数字，或"面议/未标价"——上平台时填进"自报价">
- 主体性质：<个人/工作室/公司——以谁的名义对外，平台简介三要素之一>
- 置信：★×<0-2>（P 题结果 0/1/2；解释：付过钱的经验整体上调）
```

## 素材清单模板（进平台前给用户的"带什么"）

```
1. 身份证明：这套东西是你的——创作时间线、交付记录、聊天记录截图
2. 内容本体：模板文件 / 脱敏数据样例 / 工具截图 / 文章链接
3. 有效信号：下载量、点赞收藏、客户反馈、付费截图（有就带，没有标注"待补"）
4. 边界声明：不涉密、不涉职务成果、不侵权（这三句要能自己签）
```

> 引导语：**"能证明的才叫资产，说不清来源的叫风险。"** 缺的证据逐条列出，补齐一件划掉一件。
