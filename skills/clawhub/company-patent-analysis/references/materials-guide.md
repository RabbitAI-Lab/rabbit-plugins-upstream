# 两项必填怎么写好

报告分析的是**一家企业在一个技术方向上的专利**。决定报告好坏的就是这两项：企业对不对得上专利登记名，方向写得准不准。

## 一、目标企业（`--company`）

**写专利上登记的全称。** 一般是「地名＋字号＋行业＋有限公司」。

| 写法 | 结果 |
| --- | --- |
| `宁德时代新能源科技股份有限公司` | ✅ 和专利登记一致 |
| `宁德时代` | ⚠️ 简称。系统会尝试用字号回溯登记名，多数能对上，但不保证 |
| 名称里错了一两个字 | ⚠️ 回溯不到时会直接报「没有找到名为……的申请人」，不扣费 |
| `企业A`、`某某公司` | ❌ 占位名，一定找不到 |

用户只说了简称时，先用专利检索按申请人搜一下，把登记全称拿给用户确认再提交。

**集团企业**：集团母公司往往很少以自己名义申请专利，实际申请人是下属子公司。用户关心的是某个业务线，就填那个业务线的子公司全称。

## 二、技术方向（`--subject`）

**只写技术名称**，3-255 字。

| 写法 | 结果 |
| --- | --- |
| `钠离子电池正极材料` | ✅ 具体，结论锋利 |
| `电池` | ⚠️ 太宽，报告会很散 |
| `宁德时代在钠离子电池方向的专利布局` | ❌ 混进了企业名和「专利布局」，检索会跑偏 |

## 三、其余参数都可不填

分析目标、市场、时间范围、来源、排除方向、背景素材都有默认值。用户主动提了再带上，不要为了填全反复追问。

背景素材（`--materials` / `--materials-file`）会记在任务里备查，用户有现成的企业介绍可以带上，没有就跳过，不要编。
