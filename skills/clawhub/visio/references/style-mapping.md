# 固定风格 → Visio 映射

> 用户固定视觉体系在 Visio 产物中的落地规则。对话内 SVG/HTML 可视化沿用同一套色值，保证产出系列一致。

## 1. 配色（固定）

| 角色 | 色值 | Visio 填充 | 语义 |
|---|---|---|---|
| 主色蓝 | #185FA5 | `RGB(24,95,165)` | 主链路/主架构 |
| 绿 | #3B6D11 | `RGB(59,109,17)` | 智能化/改造后能力/达标 |
| 琥珀 | #854F0B | `RGB(133,79,11)` | 风险点/部分满足/待确认 |
| 红 | #A32D2D | `RGB(163,45,45)` | 对抗方/关键风险/缺失 |
| 灰 | #5F5E5A | `RGB(95,94,90)` | 背景层/辅助信息/连线 |

- 文字反白：蓝/绿/红底上用白色 `RGB(255,255,255)`；灰底或浅底用深灰 `RGB(51,51,51)`。
- 连线默认灰、线宽 1pt（`LineWeight` 0.0139）；强调主链路用蓝、1.5pt。
- 虚线（`LinePattern=2`）只用于监督支线、反馈回流、待确认关系。

## 2. 字体与字号

- 字体：微软雅黑（Microsoft YaHei）；西文/数字较多时可用 Segoe UI。
- 字号：节点标题 12pt、正文标注 10pt、连线标签 10pt；标题区 18–20pt。
- 节点内文字水平居中（HorzAlign=1），多行时行距默认。

## 3. 图类映射

| 图类 | 页面建议 | Visio 实现要点 |
|---|---|---|
| 层级/阶梯图 | 横向 A4（11.69×8.27） | 层块用矩形、自下而上堆叠；层间向上箭头 |
| 三栏式（左原态→中改造→右技术） | 横向 A4 | 三列等宽泳道，列标题色块：灰→蓝→绿 |
| 流程/链路图 | 横向 A4 | 圆角矩形节点 + 直线箭头连线 |
| 矩阵图（如 22 域） | 纵向 A4 或横向 | 表格化矩形阵列，缩写入格 |
| 决策环 | 正方形页 | 四段扇形（可用 EllipticalArcTo 或四块弧形模具）+ 中心圆 |

## 4. 生成脚本参数约定（build_vsdx.py）

- 坐标单位为英寸，原点左下角；A4 横向页 11.69 × 8.27。
- 节点：`fill` 用上表 hex；`corner: "round"` 得圆角矩形。
- 连线：`arrow: true` 加实心箭头；`dash: true` 虚线；`label` 写关系名。
- 生成后用 `export_via_com.ps1` 导出 SVG 复核视觉效果，再交付。
