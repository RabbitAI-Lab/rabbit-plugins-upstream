## Description: <br>
Helps AI-agent users, skill authors, maintainers, and teams create self-improving, proactive workflows for bug fixing, setup hardening, reliability improvements, and adjacent skill design. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External developers, skill authors, maintainers, teams, and AI-agent users use this skill to turn demand for self-improving and proactive agent workflows into practical plans, checklists, analyses, code changes, or decision support. It emphasizes local-hardware-friendly outputs and visible validation notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad activation wording may route generic productivity or self-improvement requests to this skill when the user intended a different workflow. <br>
Mitigation: Use explicit invocation or narrower trigger terms when installing or configuring the skill. <br>
