## Description:

A Chinese-language quick reference for preparing digital resources with TaskFlow, publishing them to ClawHub, and verifying the result.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and resource publishers use this quick reference to coordinate TaskFlow preprocessing, publish a digital resource to ClawHub, and check its listing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Incorrect publish arguments could publish the wrong resource or metadata.

Mitigation: Review the resource path, slug, name, version, and changelog before running the publish command.

Risk: Publishing a resource containing sensitive information.

Mitigation: Use the pre-publication checklist to check the resource for sensitive information before publishing.
