## 平面图（俯视图）

```
        ↑
        N
        
   ┌─────────────────┐
   │                 │
   │   [墙/家具]     │
   │                 │
   │       A         │   ← A = 演员位置
   │     /   \       │
   │    /     \      │   ← ← = 演员视线/动作
   │   B       C     │   ← B, C = 其他演员
   │   |       |     │
   │   ●→     ←●     │   ← → = 机位
   │   1       2     │   ← 1, 2 = 机位编号
   │                 │
   │   - - - - - - - │   ← - - - = 180 度轴线
   │                 │
   └─────────────────┘
        
        ↓
        S
```

## 调度模式选择

| 人数 | 模式 | 说明 |
|------|------|------|
| 2 | I 模式 | 两人面对面，轴线在中间 |
| 3 | A 模式 | 一人对两人，A 字形 |
| 3 | L 模式 | 一人孤立，其他人在 L 形长臂上 |
| 4+ | I/A/L 组合 | 限制到少数关键机位 |

## 身体语言 / 站位选择

| 关系 | 站位 |
|------|------|
| 盟友/合作 | 并肩、纵深 |
| 对手/紧张 | 面对面、背对背 |
| 不对称权力 | 90度角、交叉手臂、分离 |
| 喜剧 | 背对背（语境反差） |
| 惊悚 | 背对背、无眼神接触 |
| 亲密 | 纵深、并肩 |
| 正式 | 90度角、直角后景不看 |

## 反思检查

- [ ] 调度是否清晰表达关系？
- [ ] 演员空间是否足够活动？
- [ ] 机位是否违反 180 度？
- [ ] 是否还有更有趣的站位？
- [ ] 镜头流是否服务故事？
