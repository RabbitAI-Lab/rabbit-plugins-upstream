# Visual Design Framework — 视觉设计框架

> 来源: Steven D. Katz, *Film Directing Shot by Shot* (1991). 知识库 `Film_Directing_Shot_by_Shot_KB.json`.

本文件是**前置生产**的完整框架——从概念到分镜的整套工作流。

## 1. 五阶段预生产 (Five Phases of Preproduction)

| 阶段 | 输出 | AI 协助点 |
|------|------|----------|
| **1. 剧本写作** | 完整剧本 | 场景结构、对话节拍、视觉提示 |
| **2. 美术设计 (Production Design)** | 概念图、模型、建筑图 | 视觉调性、色彩、空间、气氛 |
| **3. 剧本分析/镜头规划** | 分镜、调度图 | 镜头流、机位、连续性 |
| **4. 摄影规划** | 机位、灯光、运镜 | 镜头选择、运动路径、灯光提示 |
| **5. 排练** | 实测表演与机位 | 配合演员调度 |

> **Katz 强调**：**前期是唯一真正自由的阶段**——"一旦开拍一切不可逆"

## 2. 制作设计的 6 个发展阶段（历史）

1. **早期默片**（1912 前）——剧院布景师，布景=彩绘背板+家具
2. **意大利影响**（1912-1916）——《Quo Vadis?》《Cabiria》推动精制实景
3. **制片厂工厂体系**（1915-1920s）——艺术总监成为建设管理者
4. **德国电影影响**（1920s）——Ufa、表现主义/Kammerspielfilm
5. **黄金时代制片厂风格**（1920s-1930s）——Warner 粗粝写实、MGM 奢华高调
6. **Production Designer 头衔确立**（1939）——Menzies 凭《乱世佳人》获首个 Production Designer 奥斯卡

## 3. 制作设计 5 大产出

### 概念图 (Concept Art)
- 范围从快速草图到 30×40 英寸完整渲染
- 表达情绪和氛围：颜色、灯光、风格比技术精确更重要
- 传统媒材：水粉、蛋彩、油画、水彩、彩色墨水、丙烯、混合媒材
- 案例：*Star Wars* 的 Ralph McQuarrie 用 8 张概念画定了整部电影的视觉基调

### 建筑图 (Architectural Drawings)
- **平面图 (Plan)**：俯视图，标比例
- **剖面图 (Section)**：侧视横截面
- **立面图 (Elevation)**：正/侧视图，正交投影
- **机位透视图 (Camera Angle Projection)**：透视画法展示特定机位/焦段下的画面

### 模型 (Models)
- 借用建筑学方法
- 不同于分镜，模型可视化**3D 空间**（摄影机记录的空间）而非 2D（观众看到的空间）
- 材料：纸板、泡沫板、巴尔沙木、模型黏土、玩具士兵

### 连续性草图 (Continuity Sketches)
- 顺序面板描述每个镜头的构图和顺序
- Menzies 在《乱世佳人》中画了**上千张**这种草图

### 最终设计图 (Final Design Illustrations)
- 完整渲染的概念图
- 用于团队沟通和拍摄参考

## 4. 分镜 (Storyboard) 的三大功能

### 功能 1：解释 (Interpretation)
- 传达**镜头流**——戏剧设计和图形设计的结合
- 传达**情绪和氛围**——优秀插画师的工作
- 传达**视点、镜头透视、叙事运动**——关键实操元素
- 案例：*The Graduate* 的 Michelson 分镜本——"动作即使不知道故事也容易读懂"

### 功能 2：改编 (Adaptation)
- 所有分镜都是剧本的改编
- 分镜可能"几乎就是剧本的另一个草稿"
- 故事板艺术家可能建议文学想法、重构场景、添加故事元素、贡献对话

### 功能 3：规划/沟通 (Planning/Communication)
- 与整个制作团队沟通的最清晰语言
- 即使小成本剧情片也受益

## 5. 分镜媒材与技法

| 媒材 | 特性 | 适用 |
|------|------|------|
| **铅笔** | 可擦除，"艺术家的文字处理器" | 草稿、底稿 |
| **墨水+炭粉** | 宽广色调，可复制 | 成品分镜 |
| **马克笔** | 明快快速；**不耐光**（数周内褪色） | 颜色、基础设计 |

> **马克笔警告**：不耐光——阳光直射下数周内明显褪色

## 6. 分镜表达技法

| 镜头技术 | 分镜表达 |
|---------|---------|
| **摇镜 (Pan)** | 显示主体位置+箭头表示路径；框中框表示构图 |
| **推轨/变焦 (Dolly/Zoom)** | 现场切（大面板内小框）；连接箭头表示运动 |
| **转场 (Transition)** | 面板间空隙表示叠化/淡入；DIALOGUE/NARRATION 在上，SOUND EFFECTS 在下 |
| **升降 (Crane)** | 多个面板代表单一不中断镜头；说明文字描述连续运动 |

## 7. 简化分镜方法

| 方法 | 描述 | 适用 |
|------|------|------|
| **文字描述** | 框+描述+箭头 | 基础规划 |
| **示意图** | 俯视平面图：机位和动作方向 | 镜头排序；揭示逻辑问题 |
| **火柴人** | 表达位置和动作方向 | 快速草图（< 1分钟） |
| **透视箭头** | 透视图中的箭头表达视角 | 表达机位角度 |
| **重叠面板** | 表达运动镜头 | 移动主体和机位 |
| **透视盒** | 把火柴人放在 3D 盒子里 | 表达机位角度（低角、高角 CU） |
| **增加体积** | 给火柴人增加形体和体积 | 空间关系；尝试不同调度版本 |

## 8. 格式与展示

- **面板尺寸**：平均约 **4×6 英寸**（约 10×15 cm）
- **展示方法**：
  1. **墙/布告板**（Disney 方法）——许多面板可见，团队会议用
  2. **作品集盒**——6-20 面板，可携
  3. **书式/活页夹**——每页一个大面板（8×10 英寸）——可以变化速度模拟剪辑节奏

## 9. 分镜的 4 大原则

1. **分镜在拍摄时是否被遵循并不重要**——分镜的价值在**思考过程**
2. **画完大段剧本后，导演能看到剧本中无法展现的戏剧流**
3. **纸上可视化是产生想法的技巧，不只是建立计划**
4. **自己动手画最有益**——"卷起袖子直接与图像工作的重要性怎么估计都不过分"

## 10. Production Cycle (制片如同发车)

> *The production cycle is like a train leaving the station. Preproduction is the only truly free period.*

| 阶段 | 自由度 | 风险 |
|------|--------|------|
| **预生产** | 高（可改方案） | 低（成本未投入） |
| **拍摄** | 低（已成既定） | 高（每天成本巨大） |
| **后期** | 中（剪辑可重排） | 中（时间有限） |

## 11. AI 导演使用提示

### 预生产 AI 协助流程

```
剧本 → 概念图 → 分镜 → 调度图 → 镜头清单
 ↓        ↓        ↓        ↓        ↓
场景分析  美术设计   机位设计   演员位置   拍摄排期
```

### 概念图生成的 4 个问题

在生成概念图前先回答：
1. **这个场景的情绪是什么？**（关键词：紧张、孤独、亲密……）
2. **颜色调性是什么？**（冷色/暖色/高对比/低对比）
3. **空间感是什么？**（封闭/开放/纵深/扁平）
4. **历史/文化语境是什么？**（时代、地域、社会阶层）

### 分镜生成的 5 步流程

1. **场景分析**：场景目标 + 戏剧转折 + 情感弧线
2. **关键镜识别**：识别 Q&A 链条中的关键时刻
3. **机位初稿**：基于轴线、关系、节奏定 2-3 个主机位
4. **多版本生成**：基于"过程而非产品"原则，生成 2-3 版
5. **批评与精炼**：用 180 度检查、视线检查、动作中切检查

### 调度图的核心字段

| 字段 | 描述 |
|------|------|
| **机位** | 相机位置和角度 |
| **演员位置** | 演员在空间中的位置 |
| **轴线** | 180 度线（通常虚线） |
| **光源** | 主光、辅光、轮廓光 |
| **道具** | 主要道具位置 |
| **运动** | 演员/相机运动方向 |
| **时刻** | 该时刻的戏剧内容 |
