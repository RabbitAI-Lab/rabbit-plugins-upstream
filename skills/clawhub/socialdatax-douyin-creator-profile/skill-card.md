This skill is ready for commercial/non-commercial use.

## Use Case:

Agents assisting analysts and marketers retrieve Douyin creator profile details and audience counts from SocialDataX for account research.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Normal use runs the latest npm package with access to the SocialDataX API key.

Mitigation: Review before installing; prefer a pinned, reviewed package version or trusted installed CLI, and provide the API key only in an environment trusted with that package.
