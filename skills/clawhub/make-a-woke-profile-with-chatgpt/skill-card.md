## Description:

Turn a consented selfie into a satirical set of AI-generated profile images, animated tiles, and a social-ready collage, with an optional presenter video.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

People who want a playful, satirical profile set can use the skill to transform their own selfie into themed images and animations, then assemble them into a collage or optional video.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A selfie and other identifying details may be sent to an image-generation service, and the result can remain recognizable.

Mitigation: Use your own photo or one shared with clear permission, and consider privacy before uploading or posting the resulting images.

Risk: The security guidance reports a possibility of deleting existing files in an output folder.

Mitigation: Choose a new or empty output folder and back up any files that must be kept.

Risk: The security review reports unpinned installation commands and partial inspection of one script, so its scan does not provide complete assurance.

Mitigation: Review the source and installation references before running, pin versions where applicable, and treat the security review as incomplete.
