## Description:

Turns seller-selected Douyin comment objections and authorized still images into short spoken demo clips, one clip per still.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Sellers and their agents use public Douyin comment objections and authorized product or presenter stills to plan replies and create individual talking demo clips. The skill does not post replies to Douyin.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Shared Beatra device authorization grants broad account access, including paid generation and task management.

Mitigation: Review the requested account authority before connecting and confirm the live price and each paid stage before approving it.

Risk: Automatic client updates can replace local package files without separate approval.

Mitigation: Review the skill before installation and disable automatic updates with the documented update command where change control requires manual approval.
