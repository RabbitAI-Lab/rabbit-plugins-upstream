# 飞书可选集成

飞书仅用于用户明确选择的持久化与推送。默认的课表生成、调整和复盘不需要飞书。

## 启用条件

同时满足以下条件后才可执行外部操作：

1. 用户明确选择飞书。
2. 飞书已通过平台 Connector、OpenClaw 集成或本地密钥存储安全连接。
3. 不需要用户在聊天中提供 App Secret、访问令牌或其他凭据。
4. 用户已确认本次操作的空间、表、记录范围、时间范围和接收方。

若条件不满足，继续在会话内生成内容，并说明尚未执行任何飞书读写或推送。

## 最小数据模型

优先从以下最小表开始：

| 表 | 最小字段 |
|---|---|
| `profiles` | 昵称/代号、年龄段、培养重点、更新时间 |
| `schedules` | 版本号、生效日期、状态、课表、变更摘要 |
| `daily_logs` | 日期、任务完成情况、可选备注 |
| `weekly_reviews` | 周次、节奏判断、下周重点、调整建议 |

默认不要创建情绪、健康、学校、住址、联系方式等字段。用户明确需要某字段时，先说明用途、保存位置和风险，再决定是否增加。

提醒或临时活动可按需增加独立表。不要为了“以后可能用到”预先创建大量长期记录表。

## 读取确认

每次读取前展示：

```text
准备从飞书读取：
- 空间：<用户可识别名称>
- 表：<表名>
- 范围：<记录/日期范围>
- 用途：<生成课表/复盘/趋势>

确认读取以上范围吗？
```

不要在每次对话开始时自动读取。只在当前请求确实需要历史数据时提出。

## 写入确认

写入前先展示摘要或预览：

```text
准备写入飞书：
- 空间与表：<目标>
- 操作：新增 / 更新 / 覆盖
- 内容：<字段和记录数量摘要>
- 保留：<用户选择的期限，未选择则长期保留>

确认执行这次写入吗？
```

用户说“记录今天”只表示希望形成一条记录草稿。先展示解析结果，获得确认后再写入。

更新课表时先生成新版预览。只有确认后，才将旧版标记为历史版本并写入新版。

## 推送确认

推送前展示接收方、内容摘要和发送时点。首次推送、变更接收方或批量推送必须单独确认。

定时提醒由外部调度器负责。本 Skill 不自行创建后台任务。若用户要求配置，明确说明：

- 推送频率和时区；
- 接收方；
- 将读取的数据范围；
- 暂停和删除方法。

## 保留、删除与撤销

- 未指定保留期限时，明确提示外部平台会持续保存，询问是否接受。
- 支持按日期、表或全部范围准备删除计划；删除前展示范围并确认。
- 停止使用时，引导用户移除飞书应用/Connector 权限并删除本地密钥。
- 不回显凭据，不把凭据写入文档、日志或示例。

## 安全失败

遇到以下情况停止外部操作并改为会话内输出：

- 无法确认目标空间或接收方；
- 连接权限超过当前任务所需范围；
- 返回内容包含未预期的敏感字段；
- 用户未确认覆盖、删除或批量操作；
- 需要通过聊天传递凭据。
