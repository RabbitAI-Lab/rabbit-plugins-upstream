# 飞书安全配置说明

本文件不保存 App ID、App Secret、访问令牌、App Token、Table ID 或接收方 ID。

## 推荐方式

1. 为家庭计划创建独立的飞书应用或 Connector。
2. 只授予目标多维表格所需的最小读写权限。
3. 在 OpenClaw、运行环境或系统密钥存储中配置凭据，不要粘贴到聊天。
4. 在本地私有配置中记录目标空间、表和接收方的可识别名称；不要提交真实 ID。
5. 先用测试表和虚构数据验证。

## 启用前检查

- [ ] 凭据未出现在聊天、仓库或日志中
- [ ] 仅共享专用多维表格
- [ ] 已确认读取和写入范围
- [ ] 已确认推送接收方
- [ ] 已确定数据保留期限
- [ ] 已知道如何撤销应用权限和删除本地密钥

配置完成后，只需告诉 Skill“飞书连接已安全配置”。Skill 会先展示本次操作范围，再请求确认；不要把凭据内容发给 Skill。
