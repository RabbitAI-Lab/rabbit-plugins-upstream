# 最小示例输入

以下内容为虚构示例，只用于演示会话内规划，不连接外部服务。

```text
请帮我给孩子制定一版每周计划，只在当前对话处理，不要保存。

- 代号：小树
- 年龄段：小学低年级
- 放学：工作日 16:30
- 睡觉：21:00
- 固定活动：周三 17:00–18:00 运动
- 家长可陪伴：工作日 19:00–20:00
- 本周重点：阅读习惯、户外活动
- 单次主动任务不超过 25 分钟
- 周五晚只保留家庭自由时间
```

预期行为：

1. 不要求真实姓名、学校或联系方式。
2. 不读取历史记录。
3. 不启用飞书或 Notion。
4. 先检查冲突，再输出完整七天计划和风险提醒。
