# 图片裂变 - 业务流程详述

## 业务目标

多平台多店铺铺货场景下，将一组 listing 图片（主图、副图、A+ 图）裂变为视觉差异化的新图片，商品本身保持不变，用于规避平台图片查重/关联检测。

## 输入参数清单

- **images**：用户上传的图片（1 张或多张）
- **model**：生图模型；仅允许 `BANANA_PRO` 和 `GPT_2_IMAGE` 两个值，未指定时必须用 AskUserQuestion 让用户选择。不同模型支持的宽高比不同
- **quality**：图片质量（仅 GPT_2_IMAGE 支持）
- **similarity_threshold**：相似度上限百分比（默认 60）
- **fission_count**：每张图裂变数量（默认 1）
- **user_prompt**：用户附加提示词（可选）

## 步骤拆解

### S1：参数校验与模型确认

- 动作：校验输入合法性，确认模型选择
- 上游：用户输入
- 下游：S2、S4
- 所需字段：images、model、quality

### S2：图片预处理与队列生成

- 动作：判断图片类型，生成处理队列
- 上游：S1（model）、用户图片
- 下游：S4
- 所需字段：images、model

### S3：组装 Prompt

- 动作：拼接基础约束 + 用户附加提示词
- 上游：用户参数
- 下游：S4
- 所需字段：similarity_threshold、user_prompt
- 关键逻辑：
  - 基础约束（不改变商品 + 相似度阈值）不可被覆盖
  - 用户提示词仅做叠加

### S4：逐张裂变生图

- 动作：调用生图模型，逐张生成裂变图
- 上游：S1（模型配置）、S2（处理队列）、S3（prompt）
- 下游：S5
- 所需字段：processing_queue、final_prompt、model、quality、fission_count

### S5：产出整理与落盘

- 动作：图片落盘到会话目录，生成映射关系
- 上游：S4（裂变结果）
- 下游：用户（最终交付）
- 所需字段：fission_results

## 报告诉求

无报告需求。产出为图片文件 + 原图→裂变图映射关系。

## 已知局限

- 相似度为 prompt 语义约束，非硬性校验
- 极复杂图片（大量文字、密集排版）裂变效果可能不理想
