# 版式蓝图（四类场景）

按用户意图先判定原型，再取对应蓝图。多原型混用时取并集，页签顺序按「先结论、后明细、
再异常」排列——看表的人第一眼要看到结论。

所有蓝图共用 `design_system.md` 的令牌，本文只规定**结构与字段**，不重复颜色字号。

---

## 通用构表约定

- **页签顺序**：概览 → 明细 → 分析 → 异常 / 附录。超过 5 个页签就要合并。
- **页签命名**：中文、≤ 8 字、语义完整。不要「Sheet1」「分析2」。
- **每张表三个区**：标题区（1–2 行）→ 表头 → 数据区 → 脚注（可选）。
- **每个数字都带口径**：表头写单位或口径，脚注写公式定义。
- **一张表一个粒度**：不要在同一个表里混「订单行」和「客户汇总」两种粒度。

---

## P1 · 生产 / 库存运营

**典型触发**：排产计划、工单执行、在制品、出入库明细、库存周转、齐套率。

### 页签结构

| 页签 | 内容 | 粒度 |
|---|---|---|
| `概览` | 6 个 KPI 卡片 | 汇总 |
| `工单明细` | 工单执行主表 | 工单 |
| `异常` | 达成率 < 90% 或延期 > 3 天 | 工单 |
| `趋势`（可选） | 近 8 周产出与达成率 | 周 |

### `工单明细` 字段

| 列 | 字段 | 类型 | 说明 |
|---|---|---|---|
| A | 工单号 | 文本 | 冻结列 |
| B | 产品名称 | 文本 | 长文本，> 34 宽时换行 |
| C | 车间 / 产线 | 文本 | |
| D | 计划数量 | 整数 | |
| E | 完成数量 | 整数 | |
| F | 达成率 | 百分比 | `=IFERROR(E/D,0)` |
| G | 计划完成 | 日期 | |
| H | 实际完成 | 日期 | 未完成留空 |
| I | 延期天数 | 整数 | `=IF(H="",TODAY()-G,H-G)` |
| J | 单位成本 | 货币 | |
| K | 工单金额 | 货币 | `=E*J` |
| L | 状态 | 文本 | 未开工 / 在制 / 完工 / 延期 |

### 公式锚点

```
F{r} = IFERROR(E{r}/D{r},0)          达成率：分母为零返回 0，不要返回空（会破坏汇总）
I{r} = IF(H{r}="",TODAY()-G{r},H{r}-G{r})
K{r} = E{r}*J{r}
合计行 D/E/K 用 SUM，F 用 IFERROR(SUM(E)/SUM(D),0) —— 不要对达成率列求平均
```

### 概览 KPI 卡片

2 行 × 3 列的卡片区，用 `theme_engine.kpi_card()` 画。六个指标建议：计划量、完成量、
达成率、延期工单数、在制金额、齐套率。卡片规范见 `design_system.md` §10。

### 图表

- `概览` 右下：近 8 周达成率折线（单系列，不要图例）。
- `趋势`：产出量柱状 + 达成率次坐标轴折线（双系列，图例放底部）。

## P2 · 销售订单 / 客户分析

### 页签结构

| 页签 | 内容 | 粒度 |
|---|---|---|
| `经营概览` | KPI 卡片 + 月度趋势 | 汇总 |
| `订单明细` | 订单主表 | 订单行 |
| `客户排行` | 帕累托：客户 × 金额 × 累计占比 | 客户 |
| `账龄`（可选） | 应收账龄分布 | 客户 |

### `订单明细` 字段

| 列 | 字段 | 类型 | 说明 |
|---|---|---|---|
| A | 订单编号 | 文本 | 冻结列 |
| B | 客户名称 | 文本 | |
| C | 下单日期 | 日期 | |
| D | 交付日期 | 日期 | |
| E | 产品 / 规格 | 文本 | |
| F | 数量 | 整数 | |
| G | 单价 | 货币 | |
| H | 金额 | 货币 | `=F*G` |
| I | 折扣率 | 百分比 | |
| J | 净额 | 货币 | `=H*(1-I)` |
| K | 审核状态 | 文本 | 待审 / 已审 / 驳回 |
| L | 业务员 | 文本 | |

### 公式锚点

```
H{r} = F{r}*G{r}
J{r} = H{r}*(1-IF(I{r}="",0,I{r}))    折扣率为空按 0 处理，避免 #VALUE!
客户排行 C{r}/SUM($C$2:$C$n) 要用绝对引用，否则排序后全乱
```

### 客户排行（帕累托）

按金额降序排，加「累计占比」列（`=SUM($C$2:C{r})/SUM($C$2:$C$n)`），
对累计占比列加色阶帮助识别 80% 分界。不要加数据条，占比已有强弱含义。

### 图表

- `经营概览`：本月订单额（卡片）+ 近 12 月订单额柱状图（单系列）。
- `客户排行`：Top 10 横向条形图，类别多时横向才不会挤。

## P3 · 财务分析与预算

### 页签结构

| 页签 | 内容 | 粒度 |
|---|---|---|
| `利润表` | 分层损益，本期 / 上期 / 变动 | 科目 |
| `费用明细` | 费用发生明细 | 单据 |
| `预算执行` | 预算 vs 实际 vs 差异 | 科目 × 期间 |

### `利润表` 结构

分层排列，层次用小计行隔开（小计行用 `surface` 底色 + bold）：

```
营业收入
  主营业务收入
  其他业务收入
  营业收入小计          ← 小计行
营业成本
  营业成本小计          ← 小计行
毛利                    ← 小计行，= 收入小计 - 成本小计
期间费用
  销售费用 / 管理费用 / 研发费用 / 财务费用
  期间费用小计          ← 小计行
营业利润                ← 小计行
利润总额 / 净利润       ← 小计行
```

列：`项目 | 本期 | 上期 | 变动额 | 变动率`。
变动率用 `=IFERROR(D/C,"")`；C 为空或 0 时留空，**不要显示 #DIV/0!**。
变动额与变动率按「涨红跌绿」着色——注意这里的「涨」指利润增加。

### `预算执行` 字段

`科目 | 期间 | 预算 | 实际 | 差异 | 执行率 | 状态`

```
差异   = 实际 - 预算        （超支为正）
执行率 = IFERROR(实际/预算,"")
执行率 > 100% 的行：状态列写「超支」，用条件格式把该行执行率标为 fall 色
```

不要给整行上色，只标执行率单元格，否则整张表失去重点。

### 图表

- `利润表` 右侧：收入 / 成本 / 毛利 三项本期 vs 上期的簇状条形图。
- `预算执行`：执行率横向条形图，按执行率降序，Top 10。

## P4 · 项目计划 / KPI 看板

### 页签结构

| 页签 | 内容 | 粒度 |
|---|---|---|
| `看板` | KPI 卡片 + 状态分布 + 本月里程碑 | 汇总 |
| `任务清单` | 任务主表 | 任务 |
| `里程碑` | 关键节点 | 节点 |

### `任务清单` 字段

| 列 | 字段 | 类型 | 说明 |
|---|---|---|---|
| A | 任务编号 | 文本 | 冻结列 |
| B | 任务名称 | 文本 | |
| C | 负责人 | 文本 | |
| D | 开始日期 | 日期 | |
| E | 截止日期 | 日期 | |
| F | 工期（天） | 整数 | `=E-D+1` |
| G | 进度 | 百分比 | 0–1 |
| H | 状态 | 文本 | 未开始 / 进行中 / 已完成 / 阻塞 |
| I | 阻塞原因 | 文本 | 非阻塞留空 |
| J | 逾期天数 | 整数 | `=IF(H="已完成",0,MAX(0,TODAY()-E))` |

### 进度列的处理

进度是 0–1 的小数，用百分比格式即可，**不要**用 `REPT("█",...)` 拼字符画进度条——
字符画在换字体、换列宽、复制到别处时全都会散架。

### 看板布局

```
A1:D3     KPI 卡片 1        F1:I3  KPI 卡片 2
A5:D5     状态分布（标题）
A6:D16    环形图
F5:I16    本月里程碑（小表格，自带表头行）
```

**看板页没有统一的表头行，必须显式跳过表格样式**，否则引擎会把第一行当表头刷成色块：

```python
apply_theme(wb, theme="amber", skip_sheets=["看板"])
```

跳过的页自己用 `kpi_card()` 和 `style_sheet(..., header_row=...)` 单独处理，
或干脆手写少量样式——看板页元素少，手写反而更快。`style_sheet` 接受显式传入的
`layout`，可以精确指定 `header_row`，用于「小表格嵌在看板里」的情况。

### 图表

- 状态分布用环形图（类别 ≤ 5）。
- 里程碑用表格，不用图。

## 场景判定速查

| 用户说的是 | 原型 |
|---|---|
| 工单、排产、在制、出入库、库存、齐套、产线 | P1 |
| 订单、客户、销售、回款、应收、账龄、业务员 | P2 |
| 利润、费用、预算、成本、损益、同比环比 | P3 |
| 任务、进度、里程碑、负责人、排期、绩效、KPI | P4 |
| 说不上来 / 通用明细 | 按 P2 的明细表结构，只保留一页 |
