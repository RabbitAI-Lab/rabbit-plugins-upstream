## Description:

Helps agents create and edit ecommerce images and videos, prepare marketing content, and query Qinghu ecommerce data.

This skill is ready for commercial/non-commercial use.

## Use Case:

Creators, marketers, and ecommerce teams use this skill to generate product imagery and promotional videos, edit or translate media, draft storyboards, and retrieve product and market data through Qinghu tools.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Provided media is uploaded to an external service.

Mitigation: Upload only material approved for processing by Qinghu.

Risk: The integration uses a Qinghu API key and paid operations can consume credits.

Mitigation: Protect the API key, check estimated credits, and obtain explicit confirmation before paid submissions.

Risk: Face replacement, watermark removal, and video translation can affect others' content or likenesses.

Mitigation: Use these features only on content and likenesses you are authorized to edit.

Risk: Unpinned npm installs or latest-version invocations can change the code executed.

Mitigation: For stronger supply-chain control, pin and review the qhkit version before installation.
