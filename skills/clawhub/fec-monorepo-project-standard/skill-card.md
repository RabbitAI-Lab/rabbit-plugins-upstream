## Description:

Guides developers in creating, reviewing, and restructuring frontend monorepos using pnpm workspaces, Turborepo, or Nx.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers and engineers use this skill to organize frontend monorepos, manage workspace dependencies, configure build and test tasks, and review package boundaries and release checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger terms such as workspace may activate the skill during unrelated repository discussions.

Mitigation: Confirm the repository uses relevant monorepo tooling and that this guidance fits the task before applying it.

Risk: Remote build caches could expose sensitive outputs if configured without care.

Mitigation: Separate trusted CI from local caching and review cached outputs and environment settings for sensitive data.
