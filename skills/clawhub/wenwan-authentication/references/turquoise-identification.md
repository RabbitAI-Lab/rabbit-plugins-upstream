# 绿松石真伪鉴别完整指南

## 一、常见造假与优化手段

| 类型 | 做法 | 特征 |
|------|------|------|
| **沁胶** | 将低瓷度松石浸泡在无色胶体中 | 表面孔隙被封，光泽偏"胶感" |
| **注胶** | 真空加压将胶打进石头内部 | 颜色呆板、光泽弱，裂隙处有胶残留 |
| **灌胶** | 使用有色胶体，同时改变颜色与密度 | 颜色深、手感重 |
| **染色** | 用白松石或菱镁矿染色冒充 | 颜色集中在缝隙，过于均匀，氨水擦拭会掉色 |
| **注蜡/过蜡** | 浸蜡处理 | 放久后会褪色，统一色泽 |
| **合成/压制** | 人工材料合成 | 蓝色微小颗粒，表面人工铁线 |
| **玻璃仿制** | 玻璃、塑料冒充 | 硬度低，手感轻，有贼光 |
| **菱镁矿染色** | 菱镁矿染色仿绿松石 | 密度轻（~2.1-2.3 g/cm³），颜色浮于表面 |

## 二、11 种实用鉴别方法

### 2.1 看颜色
- **天然**：色泽温润，颜色分布不均匀，有自然杂色。铜离子多→偏蓝，铁离子多→偏绿
- **假货**：颜色过分均匀，人工染色痕迹明显
- 高蓝料、军绿料、菜籽黄各有价值，但菜籽黄/军绿克价低于高蓝

### 2.2 看铁线
- **天然铁线**：往内凹、纹理随机、粗细变化自然，放大可见深入内部
- **假货铁线**：仅附着表面，纹路呆板、方向一致
- 无铁线"净肉"料存在但稀少，完全无铁线需警惕人工去除或仿品

### 2.3 浸水测试
- 天然松石有细小气孔，浸水1小时左右出现细密小气泡
- 瓷度越高，气泡出现越慢（高瓷甚至不出现）
- 注胶品表面气孔被封 → 无气泡
- ⚠️ 高瓷高蓝松石泡水变色极慢甚至不变，不能以"不变色=假"判定

### 2.4 听声音
- 天然原矿碰撞发出清脆"瓷声"
- 注胶品碰撞声音沉闷

### 2.5 擦拭法
- 蘸氨水布擦拭 → 天然不变色，染色品会掉色

### 2.6 热针法
- 烧红针刺隐蔽处：天然松石无味或轻微松香味；注胶品有刺激性塑料焦味
- ⚠️ 有损测试，谨慎使用

### 2.7 刀刮法
- 天然高瓷松石莫氏硬度5-6，锋利刀具划过不留痕
- 注胶品易出刮痕，厚胶处轻刮会起皮

### 2.8 划玻璃
- 天然松石硬度足以在玻璃上留痕
- 仿制品划后出现明显划痕

### 2.9 火烧法
- 天然松石轻烧后变黑，擦除不留痕，冷水清洗光洁如新
- 注胶品遇火 → 火焰加大发蓝 + 刺鼻气味 + 表面发黄发黑
- ⚠️ 过火会损伤松石，仅适合轻微测试

### 2.10 紫光灯（365nm）检测
- 天然松石荧光反应微弱或无荧光
- 灌胶/沁胶品出现明显蓝白色荧光
- ⚠️ 最新注胶技术处理后也可能无荧光

### 2.11 仪器检测
- 放大镜观察裂隙处有无胶残留、气泡
- 红外光谱仪检测是最权威方法
- CMA认证珠宝检测机构出具鉴定证书是最终依据

## 三、品质评判四维度

### 瓷度（最核心指标）
| 等级 | 特征 | 克价参考 |
|------|------|----------|
| 泡松/面松 | 无光泽，指甲可刮粉，入水立即变色 | <50/克 |
| 硬松 | 有蜡状光泽，中低致密度 | 50-150/克 |
| 瓷松 | 玻璃-蜡状光泽，高致密度，指甲划不动 | 150-500/克 |
| 玉化 | 强玻璃光泽，半透明，可镜面反光 | 500-2000+/克 |

### 颜色（价值排序从高到低）
1. 高蓝（天蓝）→ 最高价值
2. 蓝绿/果冻绿 → 高价值
3. 军绿 → 中价值
4. 菜籽黄/黄绿 → 中低价值
5. 浅绿/白蓝 → 低价值

### 铁线
- 天然随机分布、有凹陷感、深入内部
- 铁线美（蛛网纹、水草纹）可提升观赏价值
- 净肉无铁线在特定品种中为加分项

### 净度
- 少裂隙、少杂色矿物斑块为佳
- 完全无瑕极为稀少

## 四、品类价值参考

### 圆珠/老型珠
- 高瓷高蓝 10mm+：500-1500/克
- 高瓷蓝绿 10mm+：200-600/克
- 高瓷军绿/菜籽黄：100-300/克

### 雕件（貔貅/兽珠等）
- 含雕工溢价约20-50%
- 高蓝瓷松 18mm 兽珠：1500-3000+
- 军绿/菜籽黄 18mm 兽珠：200-600
- 菱镁矿仿品：20-80

## 五、快速鉴别决策树

```
拿到绿松石
├── 重量明显轻？→ 菱镁矿/塑料（仿品）
├── 表面有贼光（塑料感反光）？→ 玻璃/塑料（仿品）
├── 颜色极其均匀无任何纹理？→ 染色/合成
├── 365nm紫光灯有蓝白荧光？→ 注胶（处理）
├── 热针测试有刺鼻味？→ 注胶/塑料
├── 刀刮起皮？→ 注胶
├── 入水不吸水不变色？→ 高瓷原矿 或 注胶
│   └── 同时满足：光泽好+铁线自然+孔道正常 → 高瓷原矿
├── 入水立即吸水变色？→ 低瓷原矿（泡松）
└── 各项测试通过 → 天然原矿，看瓷度和颜色定品质
```

## 六、密度快速判断表
