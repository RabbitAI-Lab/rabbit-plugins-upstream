## Description:

Use when converting medical text between academic and patient-friendly tones, translating medical jargon for patients, adapting research papers for public audiences, or rewriting clinical notes for patient handouts.

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: Medical tone conversion can oversimplify, omit nuance, or introduce clinically misleading wording.

Mitigation: Review generated patient-facing or clinical text for medical accuracy before relying on it.

Risk: Some documented API examples reference interfaces or files that are not present in the packaged artifact.

Mitigation: Use the packaged scripts/main.py interface and verify commands before depending on example code.
