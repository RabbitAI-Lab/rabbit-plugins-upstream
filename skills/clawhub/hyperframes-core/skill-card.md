## Description:

Guides agents in building renderable HyperFrames video compositions with timed clips, sub-compositions, media, and deterministic animation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[heygen-com](https://clawhub.ai/user/heygen-com)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and creative teams use this skill to structure, validate, and render HTML-based HyperFrames video compositions with predictable timing and media playback.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Unpinned npx examples may run an unreviewed HyperFrames CLI version.

Mitigation: Use a trusted, lockfile-pinned project dependency or an exact reviewed CLI version.

Risk: A background preview server may keep running after review.

Mitigation: Stop the preview server when finished.
