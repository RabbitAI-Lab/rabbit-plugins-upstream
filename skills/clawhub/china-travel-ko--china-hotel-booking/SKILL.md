# 중국 호텔 예약

## 설명

중국 호텔을 실시간으로 검색하고 추천, 요금, 예약 링크를 제공합니다. 중국을 방문하는 외국인 여행자를 위해 설계되었으며, 영어와 Trip.com의 TripGenie API를 통한 호텔 정보를 제공하고, 베이징, 상하이, 시안, 청두, 광저우 등 주요 도시를 커버합니다.

## 사용할 때

사용자가 다음을 원할 때 사용합니다:
- 중국 도시의 호텔 찾기
- 요금과 예약 링크가 포함된 호텔 추천 받기
- 예산, 위치 선호도, 여행 날짜로 호텔 검색
- 중국 여행의 호텔 비교

키워드: 중국 호텔, 베이징 호텔, 상하이 숙박, 중국 숙박, 호텔 예약, 예산 호텔, 고급 호텔

## 실행

### 1단계: 사용자 요청에서 매개변수 추출

사용자 쿼리에서 다음을 추출합니다:

| 매개변수 | 설명 | 예시 |
|---------|------|-----|
| city | 도시명 (영어 또는 한국어, 필수) | "Beijing" or "베이징" |
| check_in | 체크인 날짜 YYYY-MM-DD (선택) | "2026-08-01" |
| check_out | 체크아웃 날짜 YYYY-MM-DD (선택) | "2026-08-05" |
| guests | 인원수 (선택, 기본값: 2) | 2 |
| budget | 예산 수준 또는 금액 (선택) | "1박 100달러 이하" |
| preferences | 기타 선호도 (선택) | "자금성 근처" |

### 2단계: 스크립트 실행

```bash
python scripts/china_travel.py hotel "<city>" "[check_in]" "[check_out]" [guests] "[budget]" "[preferences]" --locale=ko
```

**중요:** 항상 `--locale=ko` 매개변수를 포함하여 한국어 결과를 받아주세요.

### 3단계: 결과 표시

API는 구조화된 Markdown으로 호텔명, 요금, 평점, 주요 특징, 예약 링크를 반환합니다. 내용을 직접 사용자에게 표시합니다.

결과의 마지막에, 다른 기능(항공권 검색, 관광지 검색, 여행 플랜, 여행 조언)도 한국어로 안내됩니다.

## 예시

**사용자:** "상하이에서 와이탄 근처 2명용 호텔을 찾아줘"
```bash
python scripts/china_travel.py hotel "Shanghai" "" "" 2 "" "near the Bund" --locale=ko
```

**사용자:** "베이징에서 7월 10일부터 12일까지 예산이 적은 호텔"
```bash
python scripts/china_travel.py hotel "Beijing" "2026-07-10" "2026-07-12" 2 "under $80/night" --locale=ko
```

**사용자:** "청두에서 3명용 고급 호텔"
```bash
python scripts/china_travel.py hotel "Chengdu" "" "" 3 "luxury" --locale=ko
```

## 주의사항

- 도시명은 영어 또는 한국어로 입력할 수 있습니다
- 날짜는 선택이지만 빈 객실 상황과 요금을 좁히는 데 도움이 됩니다
- API는 자연 언어 선호도를 지원합니다 (예: "지하철 역 근처", "조식 포함")
- 예약 링크는 Trip.com (국제판)으로 직접 이동합니다
- 모든 결과는 한국어로 표시됩니다
