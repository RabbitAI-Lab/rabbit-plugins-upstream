# Билеты на достопримечательности Китая

## Описание

Ваш универсальный помощник для путешествий в Китай. Этот навык предоставляет 5 мощных функций для иностранных туристов:

1. **Билеты на достопримечательности** — Открытие достопримечательностей с ценами на билеты, часами работы и ссылками для бронирования
2. **Поиск отелей** — Поиск отелей с ценами, рейтингами и ссылками для бронирования в реальном времени
3. **Поиск авиабилетов** — Поиск рейсов в/из/внутри Китая с ценами в реальном времени
4. **Планировщик поездки** — Генерация персональных многодневных планов поездки
5. **Советы для путешественников** — Получение ответов о визе, оплате, транспорте, еде и многом другом

## Поток данных и конфиденциальность

Запросы пользователей отправляются на безопасный прокси-сервер (SCF), который внедряет токены аутентификации и перенаправляет запросы в TripGenie API. Прокси автоматически обрабатывает генерацию партнерских ссылок. Личные данные пользователей не сохраняются и не регистрируются. Все коммуникации зашифрованы по HTTPS.

## Когда использовать

- Найти достопримечательности и занятия в китайском городе
- Получить цены на билеты и часы работы для конкретных достопримечательностей
- Открыть для себя мероприятия на основе интересов (история, природа, еда и т.д.)

Ключевые слова: достопримечательности Китая, чем заняться в Пекине, Шанхай туризм, Великая Китайская стена билеты, Запретный город, Терракотовая армия, достопримечательности, билеты, туризм

## Выполнение

### Шаг 1: Определение параметров из запроса пользователя

| Параметр | Описание | Пример |
|----------|----------|--------|
| city | Название города (английский или русский, обязательно) | "Xi'an" or "Сиань" |
| days | Количество дней (необязательно, по умолчанию: 1) | 2 |
| interests | Ключевые слова интересов (необязательно) | "история и культура" |

### Шаг 2: Запуск скрипта

```bash
python scripts/china_travel.py attraction "<city>" [days] "[interests]" --locale=ru
```

**Важно:** Всегда включайте параметр `--locale=ru` для получения результатов на русском языке.

### Шаг 3: Отображение результатов

API возвращает структурированный Markdown с названиями достопримечательностей, ценами на билеты, часами работы и ссылками для бронирования. Представьте контент напрямую пользователю.

## Примеры

**Пользователь:** "Что можно посетить в Сиане?"
```bash
python scripts/china_travel.py attraction "Xi'an" --locale=ru
```

**Пользователь:** "2 дня исторических достопримечательностей в Пекине"
```bash
python scripts/china_travel.py attraction "Beijing" 2 "history" --locale=ru
```

## Другие доступные функции

Этот навык также поддерживает:
- `hotel` — Поиск и бронирование отелей по всему Китаю
- `flight` — Поиск рейсов в/из/внутри Китая
- `itinerary` — Генерация многодневных планов поездки
- `tips` — Советы для путешественников, виза, оплата, транспорт

## Примечания

- Названия городов можно вводить на английском или русском языке
- Ссылки для бронирования ведут напрямую на Trip.com (международная версия)
