## Description:

Write, polish, and cite Chinese-language articles on Chinese history, literature, and culture, following the user's outline or draft while expanding it with web research and verified citations.

This skill is ready for commercial/non-commercial use.

## Publisher:

[j3ffyang](https://clawhub.ai/user/j3ffyang)

### License/Terms of Use:

MIT-0

## Use Case:

Writers, researchers, and agents use this skill to turn Chinese history, literature, and culture outlines or drafts into polished Chinese articles with checked sources, citation lists, and optional correction notes. It is especially suited to user-led essays where preserving the user's thought-flow is required.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may guide the agent to search the web and cite external sources, so inaccurate or unchecked sources could lead to unsupported historical or literary claims.

Mitigation: Open and verify cited sources before using them, prefer primary or academic sources, and move unverifiable claims into a corrections note instead of asserting them.

Risk: The skill may guide the agent to update repository documentation such as articles, correction files, or README indexes.

Mitigation: Review proposed file changes before accepting them and confirm Simplified or Traditional Chinese preferences when script choice matters.
