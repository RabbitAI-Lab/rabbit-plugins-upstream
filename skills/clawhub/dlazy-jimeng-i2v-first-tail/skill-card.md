## Description:

Generate coherent transition videos from supplied first and last frames using Jimeng.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to request a Jimeng transition video from a prompt and first and last frame images, then receive the generated asset and task or result details.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and supplied media are sent to dLazy, and generation may incur charges.

Mitigation: Only upload media you are comfortable sharing and review the estimated cost before generation.

Risk: The saved dLazy API key could be exposed.

Mitigation: Protect the saved key and rotate or revoke it if needed.

Risk: The examples contain inconsistent first- and last-frame flags.

Mitigation: Check the command's help for the supported options before use.
