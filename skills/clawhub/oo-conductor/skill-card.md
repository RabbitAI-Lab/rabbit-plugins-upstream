## Description:

Conductor helps agents query Conductor Monitoring websites, pages, segments, issues, statistics, and affected pages through an OOMOL-connected account.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers and external users use this skill to retrieve Conductor Monitoring data from an authenticated OOMOL connector without handling raw Conductor tokens.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup instructions include unverified remote installer scripts that may execute local code.

Mitigation: Prefer installing the oo CLI from a verified package or release with checksum or signature verification, and avoid remote installer pipes unless the OOMOL endpoint is trusted.
