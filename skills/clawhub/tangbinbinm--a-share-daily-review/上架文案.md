# 上架文案 — A股每日复盘日报

## 基本信息
- **技能名称**:A股每日复盘日报(免API Key·装完即用)
- **一句话简介**:一句"今日复盘",30秒生成A股当日全景日报——指数、情绪、板块、涨停梯队、龙虎榜,无需任何API Key。
- **分类**:效率办公 / 金融数据(以平台实际类目为准)
- **标签**:A股、复盘、日报、行情、免Key

## 详细介绍(发布表单粘贴)

**为什么是它?**
市面上的股票类 Skill 几乎都要你先去注册账号、申请 API Key、往配置里贴密钥——
本技能基于 akshare 公开数据接口,**零注册、零配置、零费用**,安装即可用。

**说一句话,得到一份完整复盘:**
- 📊 六大指数收盘全景(上证/深证/创业板/科创50/北证50/沪深300)
- 🌡 市场情绪温度计:涨跌家数、涨停/跌停、炸板情况、市场活跃度
- 🏭 行业板块领涨领跌 TOP5(双数据源自动切换,东财挂了走同花顺)
- 🚀 涨停梯队:连板高度、梯队结构、所属行业
- 💰 龙虎榜净买额 TOP5

**设计原则:**
- 只陈述市场事实,不荐股、不预测、不构成投资建议
- 各数据段独立容错:某个数据源抽风不影响其他段落
- 全程本地运行,不上传任何数据,无隐私风险
- 周末/节假日自动回退最近交易日

**使用示例:**
- "今日复盘" / "A股复盘"
- "生成 7月17日 的复盘日报"
- "今天股市怎么样"

> ⚠️ 免责声明:本技能输出仅为公开市场数据整理,不构成投资建议。股市有风险,投资需谨慎。
