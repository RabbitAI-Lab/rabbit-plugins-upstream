# A-Share Daily Review (China Stock Market)

Zero-config A-share market daily review generator. Uses public akshare data — no API keys needed.

## Features

- 📊 6 major Chinese indices (SSE, SZSE, ChiNext, STAR 50, BSE 50, CSI 300)
- 🌡 Market sentiment: advance/decline, limit-up/down, market activity
- 🏭 Sector leaders & laggards TOP 5 (dual data source with auto-failover)
- 🚀 Limit-up tier analysis: streak height, tier structure, industry
- 💰 Dragon-Tiger Board TOP 5 net buyers
- 🔒 All data stays local, zero telemetry

## Quick Start

1. Install: `pip install akshare pandas`
2. Say "今日复盘" or "A-share daily review"
3. Get a structured Markdown report in 30 seconds

## Requirements

- Python 3.8+
- `pip install akshare pandas`

## Disclaimer

This skill presents market facts only. It does NOT provide investment advice.
