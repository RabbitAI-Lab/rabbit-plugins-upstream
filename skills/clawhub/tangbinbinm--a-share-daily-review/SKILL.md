# A股每日复盘日报 (A-Share Daily Review)

免 API Key 的 A股复盘日报生成器。数据来自 akshare 公开行情接口,全程本地运行,
不上传任何数据,不需要注册任何账号。

## 环境准备(首次使用)

运行前确认依赖已安装;缺失时执行:

```bash
pip install --quiet akshare pandas
```

若 pip 报 externally-managed 错误,改用 `pip install --user --quiet akshare pandas`
或在虚拟环境中安装。akshare 版本建议 >= 1.14。

## 使用步骤

1. 运行数据脚本(位于本技能目录 `scripts/daily_review.py`):

```bash
python3 {baseDir}/scripts/daily_review.py
```

   - 可选参数 `--date YYYYMMDD` 指定交易日;默认自动取最近一个交易日
   - 脚本输出一个 JSON 对象;各数据段独立容错,个别段失败会记录在 `errors` 中,
     不影响其余段落

2. 读取 JSON,按下方模板渲染 Markdown 日报。

3. 渲染铁律(必须遵守):
   - **只陈述数据事实**,禁止给出买卖建议、荐股、点评个股"值得关注"之类的话术
   - 每份日报末尾必须附免责声明(见模板)
   - 某段数据缺失时写"该数据源今日不可用",不要编造数字
   - 数字保留两位小数;涨跌幅带 % 与正负号

## 日报模板

```markdown
# 📈 A股复盘日报 · {date}

## 一、指数概览
| 指数 | 收盘 | 涨跌幅 |
|---|---|---|
(逐行填入 indices)

## 二、市场情绪
上涨 {up} 家 / 下跌 {down} 家,涨停 {limit_up} 家,跌停 {limit_down} 家。
(如有炸板率、封板率等字段则补充一句)

## 三、行业板块
**领涨**:(boards_top 前5,名称+涨跌幅+领涨股)
**领跌**:(boards_bottom 前5)

## 四、涨停梯队
今日涨停 {count} 家;最高连板 {max_streak}。
(top 列表:名称/连板数/所属行业)

## 五、龙虎榜
(lhb 前5:名称/涨跌幅/净买额,单位换算为亿元)

## 六、数据说明
数据来源:akshare 公开接口 · 生成时间 {generated_at}
缺失段:(errors 内容,无则写"无")

> ⚠️ 免责声明:本日报仅为公开市场数据的整理与事实陈述,不构成任何投资建议。
> 股市有风险,投资需谨慎。
```

## 故障排查

- 脚本整体失败:多为 akshare 需要升级,执行 `pip install -U akshare` 后重试
- 网络超时:重试一次;仍失败则告知用户数据源暂不可用,不要伪造数据
- 周末/节假日运行:脚本自动回退到最近交易日,属正常行为

## 隐私说明

本技能不采集、不上传任何用户数据;所有请求仅为拉取公开行情,全部在本机完成。
