# 🧙‍♂️ 九维雷达V3.0终极选股系统

## 系统概述

老法师九维雷达V3.0是一套基于行为金融学、量化因子投资和网络分析的综合选股系统。专为寻找"未来一年翻倍潜力股"设计，整合三大高级引擎和九大分析维度。

## 核心特色

✅ **三大高级引擎全内置**
- 📰 NLP情绪引擎 - 基于200+关键词词典的行业情绪量化
- 🕸️ 网络结构引擎 - 基于浙财大2024论文的错杀股识别模型  
- 🎯 预期差引擎 - 基于芝加哥大学PEAD效应的五大预期差维度

✅ **九大分析维度全覆盖**
1. 估值维度（0-25分）
2. 超跌维度（0-20分）
3. 质量维度（0-15分）
4. 景气度维度（0-15分）
5. NLP情绪维度（0-20分）
6. 网络结构维度（0-20分）
7. 预期差维度（0-25分）
8. 动量择时维度（0-10分）
9. 市值弹性维度（0-6分）

✅ **总分158分，翻倍概率=总分×0.7**
- 🔴 S级：100分+，翻倍概率70%+
- 🔴 A级：90-99分，翻倍概率63-70%
- 🟡 B级：80-89分，翻倍概率56-63%

## 核心选股公式

```python
综合评分 = 
  估值得分 + 超跌得分 + 质量得分 + 
  景气度得分 + NLP情绪得分 + 网络结构得分 + 
  预期差得分 + 动量择时得分 + 市值弹性得分

翻倍概率 = min(95, 综合评分 × 0.7)
```

## 择时与风控体系

### 买入三档法
1. 第一档：现价 ±5% - 试探性建仓（30%仓位）
2. 第二档：下跌10-15% - 主力建仓区（50%仓位）
3. 第三档：下跌20-25% - 黄金坑，重仓出击（100%仓位）

### 止损铁律
- 单票回撤>20%：无条件重新评估基本面
- 组合最大回撤控制线：25%
- 单一标的最大仓位：15%

### 卖出信号
1. 翻倍目标达成：减半仓，剩下的设移动止盈
2. 基本面恶化：不计成本卖出
3. 市场情绪过热：当人人都在讨论这个股票时
