# 九维雷达V3.0评分标准细则

## 维度1：估值评分（0-25分）

| PE区间 | 得分 | 说明 |
|-------|------|------|
| <15倍 | 25分 | 极度低估，价值投资最佳区间 |
| 15-25倍 | 20分 | 低估，安全边际充足 |
| 25-35倍 | 15分 | 合理估值区间 |
| 35-50倍 | 8分 | 估值偏高，需高成长匹配 |
| >50倍 | 3分 | 估值过高，谨慎 |
| 亏损/PE缺失 | 10分 | 中性处理 |

## 综合评级标准

| 总分区间 | 评级 | 翻倍概率 | 操作建议 |
|---------|------|---------|---------|
| 110分+ | S+级 | >77% | 重仓出击，第一优先级 |
| 100-109分 | S级 | 70-77% | 核心配置，建议10-15%仓位 |
| 90-99分 | A级 | 63-70% | 积极配置，建议8-12%仓位 |
| 80-89分 | B级 | 56-63% | 可参与，建议5-8%仓位 |
| 70-79分 | C级 | 49-56% | 小仓试探，观察跟进 |
| <70分 | 观察级 | <49% | 仅跟踪，不操作 |
