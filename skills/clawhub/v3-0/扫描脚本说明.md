### 3. 综合评分计算
```python
def calculate_9d_score(row):
    """九维综合评分
    返回：综合评分 + 各维度明细 + 翻倍概率
    """
    total = sum([
        calc_value_score(row),
        calc_drawdown_score(row),
        calc_quality_score(row),
        calc_industry_score(row),
        calc_sentiment_score(row),
        calc_network_score(row),
        calc_expectation_gap_score(row),
        calc_momentum_score(row),
        calc_size_score(row)
    ])
    
    doubling_prob = min(95, total * 0.7)
    return total, doubling_prob
```

### 4. 批量扫描函数
```python
def scan_stock_pool(stock_codes):
    """批量扫描股票池
    返回：按综合评分排序的DataFrame
    """
    results = []
    for code in stock_codes:
        data = get_stock_basic_data(code)
        score, prob = calculate_9d_score(data)
        results.append({**data, 'score': score, 'prob': prob})
    
    return pd.DataFrame(results).sort_values('score', ascending=False)
```

## 注意事项

1. **数据更新频率**：每日收盘后扫描，T+1日生效
2. **行情数据延迟**：Tushare数据通常晚1-2小时，建议收盘2小时后扫描
3. **限流处理**：API调用间隔0.15秒，避免触发限流
4. **断点续传**：大量扫描建议保存中间结果，支持断点续扫

## 结果验证建议

1. **交叉验证**：用两个不同数据源分别扫描，对比结果
2. **人工复核**：TOP 10标的必须人工复核基本面逻辑
3. **历史回测**：验证过去1年S级标的的实际表现，持续优化模型
4. **模拟盘跟踪**：实盘前先做3个月模拟盘，验证系统有效性
