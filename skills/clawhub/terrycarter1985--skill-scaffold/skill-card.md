## Description:

Scaffold a new ClawHub-ready skill folder with the required SKILL.md frontmatter, references/ dir, and skill-card.md in one step.

This skill is ready for commercial/non-commercial use.

## Publisher:

[terrycarter1985](https://clawhub.ai/user/terrycarter1985)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and ClawHub publishers use this skill to create a minimal, publishable skill skeleton without manually writing frontmatter and starter reference files.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Running the generated commands creates local files and can publish under the authenticated ClawHub account.

Mitigation: Choose the slug deliberately, inspect the generated files, and run a dry-run publish before publishing for real.
