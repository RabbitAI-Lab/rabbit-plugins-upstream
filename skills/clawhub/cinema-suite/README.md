# Cinema Suite

Cinema Suite 1.0.0 contains 62 redacted production cinema entries and 9 mode mappings. Install this Skill as the catalog layer, then install each referenced mode Skill for executable capture, replay, coupon, failure, or page-world capabilities.

The host remains business-neutral: it supplies routing, scheduling, capture transport, and event APIs. Mode Skills own business encryption, binding, replay logic, and failure semantics.

Source: prod /api/chupiaoChannel/list?appType=App (system-catalog-fallback). This package intentionally excludes passwords, tokens, cookies, uuids, authorization headers, and raw private backend responses.
