## Description:

Helps remote workers, gamers, home-office users, and small teams create local diagnostic workflows for consumer-network issues such as bufferbloat, router problems, modem problems, and latency.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

External users use this skill to turn home or small-office network troubleshooting requests into practical diagnostic workflows, checklists, analysis, code, or decision support. It focuses on local-hardware-friendly approaches for issues such as bufferbloat, router behavior, modem behavior, and latency.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill name suggests error-message improvement, but the instructions route users into home-network troubleshooting workflows.

Mitigation: Review the skill before installing and rename display metadata or narrow invocation triggers so users understand that it is a network-diagnostics helper.
