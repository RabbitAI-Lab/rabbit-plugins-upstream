## Description:

Generates 2K, 3K, and 4K images from text prompts and reference images for posters, key visuals, and large-format print.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to generate high-resolution images from prompts or reference images for visual design and print projects.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected reference files are sent to dLazy, and generated images are hosted there.

Mitigation: Avoid submitting sensitive content without authorization and review the service's data-handling terms.

Risk: Authentication may store a dLazy API key locally.

Mitigation: Protect local credentials and rotate or revoke the key in the dLazy dashboard if needed.
