## Description:

Full version of the Doubao image model, generating 2K/3K/4K images from prompts and reference images, suited to key visuals, posters, and large-format print.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

## Use Case:

External users and developers can provide a text prompt and optional reference images to generate high-resolution Seedream visuals for key art, posters, and large-format print.
