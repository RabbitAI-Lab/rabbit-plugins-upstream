## Description:

Underwrites buy-and-hold rental properties with realistic expenses, investment metrics, stress tests, and a DEAL, THIN, or OVERPRICED verdict.

This skill is ready for commercial/non-commercial use.

## Publisher:

[voronindenis5](https://clawhub.ai/user/voronindenis5)

### License/Terms of Use:

MIT

## Use Case:

Rental investors and agents use the skill to screen buy-and-hold properties, compare financing and stress scenarios, and see which assumptions drive the result. It provides educational underwriting estimates, not investment, tax, or lending advice.

### Deployment Geography for Use:

Global
