## Description:

Conquer a keyword: rewrite the connected WordPress site's best-matching page for it and propose the change as a reviewable diff with a before/after summary.

This skill is ready for commercial/non-commercial use.

## Publisher:

[conqueror](https://clawhub.ai/user/conqueror)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, marketers, and site operators use this skill to turn a target keyword into a reviewable WordPress page revision. It helps select the best-matching post, compare search results, draft improved title, excerpt, structure, and content, and submit the proposal for human review in Conqueror.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can read WordPress post content, including drafts.

Mitigation: Install it only for projects where that content access is intended and authorized.

Risk: A proposed revision could introduce inaccurate, misleading, or unwanted page changes if applied without review.

Mitigation: Review the Conqueror diff carefully before applying any revision to the live site.
