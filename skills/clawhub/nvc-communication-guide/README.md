# DCA Decision Calculator

左侧定投决策计算器。输入当前指数点位、近一年最高点、持仓成本、汇率，输出是否触发定投、加仓倍数、换汇建议、风险提示。

## 主要功能

- **决策计算模式**：提供数据 → 计算跌幅 → 判断触发 → 计算加仓倍数 → 输出结构化报告
- **换汇计算模式**：提供汇率 → 对比历史成本 → 换汇判断 → 分批方案
- **持仓诊断模式**：分析持仓浮盀、估值偏离、健康度评级

## 触发词

定投、基金、纳斯达克、指数、加仓、换汇、人民币、汇率、投资、持仓、成本
