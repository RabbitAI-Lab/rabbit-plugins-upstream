## Description: <br>
AI-assisted short video creation where the user selects topic, aspect ratio, and duration, then receives guided video generation using their own Kling, Doubao, or similar video API key. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External users use this skill to create short videos through a paid guided workflow after configuring their own third-party video generation API key. The skill creates a local order record, verifies clawtip payment, and then guides topic, aspect ratio, duration, and generation steps in conversation. <br>
