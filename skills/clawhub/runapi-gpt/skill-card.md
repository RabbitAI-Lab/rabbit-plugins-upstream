## Description:

Guides developers in using GPT generation and text embedding models through RunAPI with OpenAI-compatible clients.

This skill is ready for commercial/non-commercial use.

## Publisher:

[runapi-ai](https://clawhub.ai/user/runapi-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to configure RunAPI clients and make chat, Responses, embedding, streaming, and supported compatibility-protocol requests.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Requests can send sensitive data to RunAPI.

Mitigation: Send only data authorized for sharing with RunAPI.

Risk: An unintended provider or exposed API key can result from misconfiguration.

Mitigation: Use a RunAPI API key and deliberately set the RunAPI base URL; keep the key private.
