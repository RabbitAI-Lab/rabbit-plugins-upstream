## Description:

This skill provides a standardized, reproducible AI-assisted programming workflow that turns vague ideas into production-ready code through three ordered steps: requirements to complex feature descriptions, descriptions plus technology stack to method-call structure, and structure to complete project code.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to turn an initial software idea into a structured requirements document, a cross-layer method-call blueprint, and then complete project code and configuration. It is especially suited to Chinese-language AI-assisted app development workflows where the user wants staged review and control before code generation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill uses opinionated defaults and examples that may steer a project toward an unsuitable client, server, database, language, or architecture.

Mitigation: Confirm the desired language, client/server stack, database, deployment target, and security requirements before generating implementation code.

Risk: Generated production-style code may contain incorrect assumptions or incomplete security controls for the target application.

Mitigation: Review and test generated requirements, method-call blueprints, code, configuration, and deployment files before using them in a real project.
