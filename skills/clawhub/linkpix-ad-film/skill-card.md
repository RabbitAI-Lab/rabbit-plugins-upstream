## Description:

帮助创作者使用 LinkPix 生成适合品牌宣传和商品展示的电影感广告视频。

This skill is ready for commercial/non-commercial use.

## Use Case:

Creators and brand teams use this skill to turn product images and a detailed visual brief into short cinematic advertisements or brand videos.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installing Node or the qhkit npm package may change the local software environment.

Mitigation: Review installation commands and package trust before approving global installs or PATH changes.

Risk: The CLI uses a LinkPix API token and uploads local image or video inputs for generation.

Mitigation: Use a trusted token and confirm that input media is appropriate to upload before submission.
