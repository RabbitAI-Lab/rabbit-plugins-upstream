## Description:

Generate visually unified image-based PPT/PPTX decks from articles, reports, papers, notes, or outlines, using dLazy for every slide image.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to turn articles, reports, papers, notes, or outlines into visually unified, image-based PowerPoint decks. Each slide is a generated full-slide image, so individual text and shapes are not separately editable.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:
