## Description:

Creates visually unified, image-based PowerPoint decks from articles, reports, papers, notes, or outlines using dLazy-generated slide images.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

External users and presentation creators use this skill to turn source material into a visually consistent, image-based PowerPoint deck with optional speaker notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Slide prompts and attached source images are sent to dLazy.

Mitigation: Review the service's privacy expectations and obtain approval before sending confidential material.

Risk: A shared local runtime stores a dLazy API key for agents to use.

Mitigation: Protect the key and review account access and credit usage before running the skill.
