## Description:

Draft a pull request description from the current branch's diff. Use when the user asks for a PR description, a merge request summary, or "what does this change do".

This skill is ready for commercial/non-commercial use.

## Publisher:

[widoxm](https://clawhub.ai/user/widoxm)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and reviewers use this skill to turn a branch diff and commit list into a concise pull request or merge request description.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may require the agent to read repository diffs and commit messages that contain sensitive or unreleased work.

Mitigation: Install and use it only in repositories where sharing the current branch diff and commit history with the agent is acceptable.
