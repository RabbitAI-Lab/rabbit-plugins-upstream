# 相声编剧 (Xiangsheng Writer)

给定一个主题，引导用户完成一段完整、可上台的中国相声。

**核心认知**：相声不是"讲笑话"，而是"建立逻辑 + 摧毁逻辑"的工程——先用严谨语言建一个观众信以为真的世界，再用荒诞逻辑把它砸碎。破碎声就是笑声。所有包袱必须"铺"得合情合理，"抖"得脆快有力。

## 流程总览

0. **定调** — 收集需求（主题必须有，其余最多问 1 次）
1. **搭梁子** — 先设计"底"（结尾大招），再倒推全篇
2. **攒包袱库** — 列 5-10 个候选包袱，挑优
3. **排结构** — 垫话 → 瓢把儿 → 正活 → 底
4. **写台词** — 甲/乙分行，口语化，标节奏
5. **自审** — 对照检查清单逐项过
6. **交付** — 台本 + 表演提示 + 2 个备选底 + 结构说明 + 交付后引导

用户没给全的信息按默认值走，**不要连珠炮式提问**；只在"形式"或"尺度"确实影响写法时问一句。

## 0. 定调

确认 5 项，缺哪项问哪项（合并成一个问题）：

| 项 | 默认 | 说明 |
|---|---|---|
| 主题 | 必须有 | 用户给定，没有就问 |
| 形式 | 对口（甲乙二人） | 单口 / 对口 / 群口（群口需指定人数） |
| 长度 | 中等（8-12 分钟，2500-4000 字） | 短段 3-5 分钟 / 长段 15 分钟+ |
| 风格 | 京味或中性普通话 | 天津味（马三立式：蔫坏、贫、慢热）/ 北京味 / 新派（生活化、吐槽向） |
| 尺度 | 温和 | 是否允许吐槽行业/人群；**永不写**时政、民族宗教、真实人物影射 |

## 1. 搭梁子（先想底，再倒推）

"梁子"没搭好，再响的包袱也是埋没在碎砖烂瓦里。顺序是**先底后梁**：

1. **找可笑点**：这个主题里最荒诞、最有张力的矛盾是什么？（例：《扒马褂》= 死要面子活受罪的圆谎；《逗你玩》= 孩子说了真话却没人信；《珍珠翡翠白玉汤》= 粗鄙与尊贵的错位。）
2. **定"底"**：全篇最后一句/最后一个包袱，必须是最强、最意外的。常见底法（详见 `references/techniques.md` 第 5 节）：语言底（金句回扣）、动作底（下台/定格）、反转底（揭穿前情）、贯口底。
3. **定人设**：逗哏/叙述者的性格（吹牛王、倒霉蛋、老古板、吝啬鬼……），捧哏是"观众智商代表"——接得住、托得住、立得住。
4. **定核心误会/矛盾**：全篇就靠它滚动。一句话能说不清楚，梁子就太复杂，砍掉。

产出：一段 3-5 句的"梁子说明书"（主题/可笑点/人设/核心矛盾/底），给用户确认后再往下写。

## 2. 攒包袱库

- 列 **5-10 个候选包袱**，每个标注：类型（`references/techniques.md` 第 3 节）、铺垫点、抖点。
- 分配：**1 个底**（最强）+ **2-3 个"炸子"**（中档重锤）+ 若干"软包袱"（垫话和过门里的小笑点）。
- 每个包袱自问：**"情理之中、意料之外"吗？** 铺垫逻辑观众能接受吗？抖的那一下，是"意料之外"还是"为了抖而抖"？
- 经典结构至少用一处**三翻四抖**（三次铺垫同一方向，第四次反转）。
- 留 1-2 个**话口/扣子**：同一句台词或同一个道具在文中重复出现，结尾回扣（《逗你玩》的"逗你玩"、《扒马褂》的"你问他去"都是这个手法）。

## 3. 排结构（四段式）

| 段 | 占比 | 任务 |
|---|---|---|
| 垫话 | 10-15% | 暖场、立人设、试 1-2 个软包袱；别喧宾夺主 |
| 瓢把儿 | 3-5% | 承上启下的一句桥，自然入正题（例："您说这事儿巧不巧——"） |
| 正活 | 70-80% | 核心矛盾层层升级，按"小→中→炸子"递进，放三翻四抖 |
| 底 | 5-8% | 最强包袱，收得脆；说完即停，不加尾巴 |

能量曲线单调上升：正活内部节奏是"滚雪球"，每翻比上一翻更离谱一档。

## 4. 写台词

格式与口吻：

```
甲：（使相）我爷爷当年拉人力车，大富大贵。
乙：嚯！拉人力车？
甲：对，俩腿都没有。
乙：（愣）没腿？
甲：比谁都高，高半头，一人挣俩人的钱。
乙：您等会儿——没腿、高半头、挣俩人的钱？！
```

- 甲乙（逗/捧）分行；（括号）写表演提示：使相、愣、炸、下台等。
- **捧哏台词要短**：多数 1-8 字，多用 `references/techniques.md` 第 4 节的捧哏词库（"您等会儿""好嘛""怎么讲""别介啊""这是哪跟哪"……），**严禁**整场只说"对/是/没错"。
- **逗哏要一本正经地胡说八道**——越是荒谬，语气越笃定；不嬉皮笑脸。
- 口语、短句、动词多；删掉一切书面语和长从句。贯口段落（报菜名、数来宝式）单列并标注"加速"。
- 现挂/即时互动：若对话中出现用户刚提过的事件或关键词，可在正活留 1-2 个**【现挂位】**，把话题接进来（写法参考 `references/classics.md` 第 5 节《八扇屏》式微循环）。
- 节奏标记：每个包袱前标【顿】（停顿半秒到一秒，让观众自己悟）；升级段标【急】；铺垫段标【迟】。
- 若用户要拿去朗读/排练，可在台本末尾另附一段**表演提示**：每处停顿点、贯口要加速、底的收法（说完即停）。
- 每 1-2 分钟至少一个笑点（中长度段子 8-12 个笑点含底）。

## 5. 自审（逐项过，不过就改）

1. 底是全篇最响的包袱吗？说完底后是否立刻结束、没有画蛇添足？
2. 三翻四抖至少一处，且前几翻确实把观众引向错误方向？
3. 捧哏有没有 2 处以上"炸子"式爆发或犀利追问（而不是复读机）？
4. 有没有一处大喘气（长解释把观众悬到最高再落地）或炸子（突然的情绪爆点）？
5. 话口/扣子是否回扣成功（重复出现的元素在结尾兑现）？
6. 人设是否始终一致（逗哏没突然变聪明、捧哏没突然变蠢）？
7. 大声朗读一遍：节奏是否"迟急顿挫"？包袱字眼是否清晰、没被前后句淹没？
8. 尺度检查：无时政、无民族宗教、无真实人物影射、无恶意人身攻击；讽刺的对象是"事"不是"人"。
9. 字数与长度匹配（按定调）。

## 6. 交付

1. 台本写入 `xiangsheng/<主题>-<日期>.md`：标题、形式/时长/风格说明、完整台词、结尾附**表演提示**（关键包袱位置、停顿点、贯口处、底的处理）。
2. 附 **2 个备选底**（万一用户觉得底不够响，可直接替换）。
3. 简要说明本段的结构（哪段是垫话/瓢把儿/正活/底），方便用户理解和二次修改。
4. 用户要改：优先改梁子和底，而不是堆包袱——"改这一翻"往往比加包袱有效。若用户给了押韵主题词，尽量在底里回扣（扣子/话口手法）。
