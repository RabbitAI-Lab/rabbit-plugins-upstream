# 相声技法手册

写稿前的工具箱。第 3、4、5 节是核心，写每个包袱前对照一遍。

## 1. 四段式结构（骨架）

一段相声 = 垫话 → 瓢把儿 → 正活 → 底。

| 段 | 功能 | 写法要点 | 禁忌 |
|---|---|---|---|
| 垫话 | 暖场、立人设、拉近距离 | 聊场合、聊天气、聊"今天要说个啥"；试 1-2 个小包袱探观众 | 过长（喧宾夺主）；一上来就讲正题 |
| 瓢把儿 | 入活的桥 | 一句自然过渡："您说这事儿巧不巧""我有一朋友""话说那天……" | 硬切（"下面我讲个故事"） |
| 正活 | 核心矛盾层层升级 | 剥洋葱/滚雪球：人设→矛盾→阻碍升级→三翻四抖 | 平铺直叙、"记叙文式"流水账 |
| 底 | 全篇最强一击 | 详见第 5 节；说完即停 | 底后加解释、加"谢谢大家"式的尾巴 |

**层次铁律**：观众读完/听完应该能说出"这段是讲什么的、从哪几个层面笑的"。说不出 = 梁子没搭好，先改结构再改包袱。

## 2. 捧逗关系（对口/群口）

- 逗哏：发散、荒谬、自我中心。负责"系包袱"（把死结系紧、制造悬念）。一本正经地胡说八道。
- 捧哏：收敛、逻辑、客观。负责"解包袱"（关键时刻一拉绳头）。代表观众智商基线——逗哏说傻话捧哏不反驳，俩人就都成了傻子，不可乐。
- 群口（三人以上）：一人逗、多人捧，另设一人"腻缝"（专打岔、提破、搅局）。《扒马褂》就是典型：甲被乙丙轮番"扒"。
- 捧哏的"顶、刨、撞、盖"（赵佩茹四法）：顶（顶回去不让顺）、刨（刨根问底）、撞（迎面撞翻）、盖（盖住逗哏的话头）。

## 3. 包袱类型（笑点发动机）

常用七类，写稿时给每个包袱标类型：

1. **误会型**：双方信息不对称，各说各话还都"有理"。（《逗你玩》：孩子说了真话，妈妈当是犯贫。）
2. **三翻四抖型**：三次铺垫同一方向，第四次反转。见第 6 节。
3. **吹牛/夸张型**：一本正经地吹，越吹越离谱，捧哏不断拆台，最后自己圆不上。（《扒马褂》爷爷没腿拉洋车。）
4. **谐音/双关型**：字面歧义、谐音梗。（"敢情是二位汤老爷呀？"）
5. **逻辑悖谬型**：故意违反常识、曲解对方话语，但每步推得"严丝合缝"。（《珍珠翡翠白玉汤》：糊饭嘎巴=珍珠、白菜帮=翡翠、馊豆腐=白玉。）
6. **身份错位型**：高低颠倒——皇帝认要饭的、县官变小伙计、孙子指挥爷爷。
7. **现挂/意外型**：利用现场突发（高阶，台本里留空位即可，标注【现挂位】）。

**好包袱三问**：铺垫逻辑观众能接受吗？抖的那一下是"意料之外"还是硬拐？观众笑完能复述给旁人吗（能复述的包袱才是响包袱）？

## 4. 捧哏词库（防止"复读机捧哏"）

捧哏禁整场只说"对/是/没错"。按功能备货：

- **垫话/接话**：嗯、是嘛、好嘛、嚯、哎哟、得。
- **质疑/找漏洞**：您等会儿、怎么讲、这是哪跟哪、没听说过、怎么着呢、啊？
- **翻包袱/炸**：不对！去你的吧、您快找地儿拉去吧、您这是吃饱了撑的、满嘴放炮、胡说八道！
- **替观众发问**：那这怎么回事、您说怎么办、那您猜怎么着。
- **盖/收**：行了行了、得得得、甭说了。

捧哏的"炸子"（突然爆发，音量/情绪骤变）一段戏至少 1-2 处，是全篇节奏的爆点。

## 5. 底的六种法（结尾大招）

1. **语言底**：一句金句回扣全篇主题。（"这马褂啊，我不要了。"——《扒马褂》式收尾，前情全废，一句带过。）
2. **反转底**：揭穿前情——观众以为的真相被最后一句推翻。（朱元璋找"汤"，其实是找做杂和菜汤子的那俩人。）
3. **动作底**：动作收尾——下台、定格、追打、扒衣服。
4. **贯口底**：一段加速贯口收住，戛然而止。
5. **自嘲底**：主角自曝"我就是个傻子/我就是来蹭的"。
6. **现挂底**：留空位，现场收。

**底的原则**：全篇最好的包袱必须留给底；底说完立刻停（"底不响，全白讲"）；铺垫太长导致观众忘了初衷的，先砍铺垫而不是加长铺垫。

## 6. 三翻四抖（核心技法）

利用模式识别与惯性思维：第一句建立模型 → 第二句确认 → 第三句强化（观众放松警惕）→ 第四句切换轨道（预测失败 = 笑声）。

**模板**：

```
逗：我这人特别爱护动物。（一翻，建立）
捧：有爱心。
逗：路边看见流浪猫，我肯定抱回家。（二翻，确认）
捧：真善良。
逗：看见受伤的小鸟，我得给它包扎。（三翻，强化）
捧：大善人啊！
逗：就是蚊子咬我，我都舍不得打，只能用扇子扇。（推向极端）
捧：这就有点过了吧？
逗：怕给它拍死在我脸上，血把我也弄脏了。（抖：动机曝光——不是爱护动物，是嫌脏）
```

**要诀**：
- "三"是泛指，实际可两翻到六翻（《如此照相》六翻一抖）；名字永远叫三翻四抖。
- 前三翻必须**同方向**且**每翻加码**，抖的那下必须是"方向突变"而非"程度升级"。
- 两种用法：①单个包袱内部（上面模板）；②全篇结构（三个平行段落 = 三翻，结尾 = 抖），如《八扇屏》三个贯口段 + 底、《改行》卖粥/卖黄瓜/卖西瓜三段 + 底。初学写整段建议用结构版。
- 有的段子只需三翻不用抖（观众自己悟到，笑在"会心"）——马三立式蔫坏幽默常用。

## 7. 节奏：迟急顿挫

- **迟**：铺垫要慢，让观众听清每个字、建立画面。
- **急**：贯口、吵架、升级段加速。
- **顿**：包袱响之前的那一秒停顿值千金，让观众自己"悟"。台本标【顿】。
- **挫**：观众狂笑时不接话，等笑声"稍落未落"时立刻接（接后劲）。

## 8. 话口与扣子（重复即结构）

- **话口**：一句口头禅/固定句式反复出现（"你问他去""好嘛""得"），结尾用它收。
- **扣子**：道具或事件先埋后爆（《扒马褂》的马褂、《逗你玩》的"逗你玩"三字）。
- 原则：重复的元素必须**兑现**——埋了就要爆，爆了要有回音。

## 9. 常见坑（自审清单来源）

| 坑 | 表现 | 修正 |
|---|---|---|
| 掉底 | 底不响，铺垫不足或包袱太绕 | 换底或砍铺垫 |
| 复读机捧哏 | 捧哏只有"对/是" | 换词库（第 4 节），加炸子 |
| 画蛇添足 | 底后加解释/加词 | 说完即停 |
| 洒狗血 | 逗哏自己先笑、过犹不及 | 一本正经；把笑变成表演 |
| 吃了吐 | 包袱字眼含糊 | 标【顿】，重音定位 |
| 匀速背课文 | 节奏平 | 迟急顿挫 |
| 记叙文相声 | 流水账没层次 | 回到梁子：先底后梁，砍掉不服务的场景 |
| 为抖而抖 | 包袱与主题无关 | 所有包袱必须服务核心矛盾 |

## 10. 安全与尺度

- 永不写：时政人物、民族宗教、真实可识别人物影射（活人）、歧视性刻板印象。
- 讽刺的对象是"事/现象"，不是"人"；丑角可以丑，但丑要"有来由"（性格缺陷导致），不是生理/出身缺陷。
- 涉及行当（医生、律师、交警等）时，丑化限于"行业通病+自嘲"，且让捧哏（正常人）负责吐槽平衡。
- 低俗梗（性、屎尿）可用但限一处，且必须是"意料之外的正经"，不能是"为低俗而低俗"。
