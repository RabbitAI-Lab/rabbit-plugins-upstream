# xiangsheng-writer 相声编剧 Skill

给定一个主题，引导完成一段完整、可上台的中国相声：从定调、搭梁子、攒包袱到成稿自审，产出带节奏标记和表演提示的甲乙台词本。

## 它是什么

一个 Agent Skill（SKILL.md 驱动的流程型技能），不是自动出稿器——它把"经典相声的结构方法论"变成一套可执行的创作流程，让模型按相声行规写段子，而不是把笑话串起来。

**核心认知**：相声是"建立逻辑 + 摧毁逻辑"的工程——先用严谨语言建一个观众信以为真的世界，再用荒诞逻辑把它砸碎。所有包袱必须铺得合情合理、抖得脆快有力。

## 功能

- **主题驱动**：客户只给一个主题（如"外卖""相亲""AI算命"），skill 引导完成全流程
- **最少提问**：缺信息才问，且最多合并问一次；其余按默认值走（对口、中长度、温和尺度）
- **先底后梁**：先设计结尾大招（底），再倒推全篇，避免"记叙文相声"
- **包袱库**：写稿前列 5-10 个候选包袱并标类型，保证响包袱密度
- **四段结构**：垫话 → 瓢把儿 → 正活 → 底，能量曲线单调上升
- **自审清单**：9 项逐项过（底是否最响、捧哏是否复读机、有无三翻四抖、尺度检查等）
- **交付物**：完整台词本（含节奏标记【顿】【急】、表演提示）+ 2 个备选底 + 结构说明

## 使用方法

### 作为 Skill（推荐）

在支持 AgentSkills 的环境（OpenClaw 等）中，将本目录放入 skills 路径即可。当用户说"写段相声""编个段子""把 XX 写成相声"时自动触发。

典型对话：

```
用户：来个"外卖"主题的相声
Skill：[定调确认] → [梁子说明书] → 用户确认 → [包袱库] → [结构] → 完整台词本
```

### 作为参考文档

`references/techniques.md` 和 `references/classics.md` 本身也是独立的相声创作教程，可直接阅读学习：

- 第 3 节：包袱七大类型（误会、三翻四抖、吹牛、谐音、逻辑悖谬、身份错位、现挂）
- 第 6 节：三翻四抖模板与要诀
- 第 5 节：底的六种法
- classics.md 末尾："主题类型 → 推荐骨架"速查表

## 创作流程速览

| 步骤 | 产出 |
|---|---|
| 0. 定调 | 形式/长度/风格/尺度（默认值可跑，最多问 1 次） |
| 1. 搭梁子 | 3-5 句"梁子说明书"：可笑点、人设、核心矛盾、底 |
| 2. 攒包袱库 | 5-10 个候选包袱，1 底 + 2-3 炸子 + 软包袱 |
| 3. 排结构 | 四段式分配，能量曲线检查 |
| 4. 写台词 | 甲乙分行、口语化、节奏标记、捧哏词库 |
| 5. 自审 | 9 项清单逐项过 |
| 6. 交付 | 台本 + 表演提示 + 2 备选底 + 结构说明 |

## 尺度红线

- 永不写：时政人物、民族宗教、真实可识别人物影射、歧视性刻板印象
- 讽刺"事/现象"，不讽刺"人"
- 低俗梗限一处，且必须是"意料之外的正经"

## 关于经典文本

`references/classics.md` 中的经典段子（马三立《逗你玩》、刘宝瑞《珍珠翡翠白玉汤》、传统《扒马褂》、《八扇屏》等）仅用于**结构研究**。台本中不得整段抄写原文；引用名句不超过一两句并注明出处。
