## Description:

Chinese crosstalk (xiangsheng) writing skill. Given a topic, it guides through a six-step workflow (briefing, story-arc design with the ending first, punchline bank, four-part structure, script writing, self-review) to produce a stage-ready script with pacing marks and performance notes, plus two alternative endings.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users can use this skill to write, revise, polish, or diagnose Chinese crosstalk scripts. It guides the work from premise and joke structure through a performable two-person script with pacing and performance cues.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A generic request to write a joke may activate the xiangsheng format unexpectedly.

Mitigation: State the preferred style or explicitly ask for a different format when needed.
