# 黄金白银行情日报 — 数据源与口径说明

## 一、国际现货（XAU / XAG）

- 实时价、涨跌幅、昨收、日内高/低、盘面：金投网、金十数据、财联社、同花顺、cngold、tradingeconomics。
- 口径：现货（spot）与期货（COMEX）不同，注明"亚盘盘中 / COMEX 收盘"。
- 人民币折算仅作参考：`美元价 × USD/CNY ÷ 31.1035`，与国内 T+D 不等价，两者并列。

## 二、国内 T+D 与期货

- 黄金 T+D、白银 T+D、沪金主力、沪银主力：上海黄金交易所（SGE）延时行情、金投网、cngold。
- 单位差异：沪金/黄金 T+D 为元/克；沪银/白银 T+D 为元/千克。

## 三、宏观指标

- DXY、USD/CNY：Wind、新浪财经、tradingeconomics。
- 10Y 美债收益率、10Y TIPS 实际收益率：FRED（美联储圣路易斯）、金十数据。**TIPS 是金价核心压制变量，必查必列。**
- WTI / Brent：tradingeconomics、金十数据、财经媒体。
- CME FedWatch：CME 官网 FedWatch 工具，取 7 月 / 9 月 / 12 月加息概率。

## 四、央行购金

- 中国央行黄金储备：央行官网月度数据、WGC（世界黄金协会）月报。
- WGC 年度央行黄金储备调研：连续增持比例、计划增持比例。

## 五、机构目标价

- 高盛 / 小摩 / 花旗 / 瑞银 / 大摩 / 德银：各机构研报、财经媒体转述。
- **必标注是否已下调及幅度**；瑞银若维持看多须显式标"未下调"。补充：美银、ANZ、BMO 等可作备注。

## 六、近 90 天黄金双向价格（仪表盘①②）

- 人民币单价：沪金主力连续 AU0，新浪财经期货历史接口 `InnerFuturesNewService.getDailyKLine?symbol=AU0`（元/克，交易日历）。
- 美元单价：COMEX 黄金，westock `data_kline` code=`fuGC`（USD/oz）。stooq / yfinance 常被反爬或限流，勿强行依赖。
- 窗口 = 近 90 个交易日（约三个月）；两图分别取各自交易日序列，不强行按同一日期对齐。
- 沪金与国际金存在 ~0.3% 国内溢价属正常，无需抹平。
- 输出：注入 `assets/report_template.html` 脚本区的 `gold90` 对象（含 `usd`/`rmb` 各自的 `dates`、`values`、`min`、`max`）。

## 七、金银比（GSR）近半年序列（仪表盘③）

真实半年序列（约 1/21–当日，60+ 点），重建方法：

- **早期（1 月–6 月中）**：基于真实月度均值（T-GolDream / IndexMundi）与关键极值周度重建。
  - 关键极值：1/29 低点 ≈45（格林大华期货半年报）、5 月低点 ≈54、6/21 低点 64.05、7/17 高点 72.05。
- **6/18–7/17**：尽量用 T-GolDream 真实日度值。
- **末尾（当日）**：接当日 GSR（现货金 ÷ 现货银）。
- **均值线**：随序列重算（2026-07-21 实测 ≈64.4），图表均值线与该值一致。
- **半年最低/最高**：取真实极值（如 45.0 / 72.05）。
- 由 `scripts/build_gsr_series.py` 生成 `<script>` 片段（含 `dates`、`values`、`mean`），直接注入 `#gsrChart` 脚本区。
- 正文「四、金银比」的大数字、半年低/均/高与图表同源，避免两处数值不一致。

## 八、交叉验证与异常剔除

- 多源一致优先；遇单源异常（价格跳变、时间戳在未来、与多源冲突）一律剔除，并在表下 note 注明采用口径。
- 不同时点（亚盘 vs 纽盘）报价不强行拼接，注明盘面即可。
