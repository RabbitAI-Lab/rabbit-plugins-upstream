## 报告结构（统一一份）

1. **标题 + 日期 + 数据截止时间**
   - 标题：`<h1>黄金白银行情日报</h1>`
   - 副信息：`2026年7月21日（周二）　|　数据截止：亚盘盘中 14:20（北京时间）`
   - 顶部 tag：现货金 USD/oz · 金银比 · 白银涨跌（如 `现货金 4,069.76 USD/oz · 金银比 69.6 · 白银领涨 +3.75%`）

2. **简明结论与风险提示（速览）置于最前**
   - 该 `<section>` 加金色高亮边框：`border:2px solid var(--gold);box-shadow:0 4px 16px rgba(232,197,71,.18)`
   - 内容：一段"结论："综述（金银当日表现 + 主导逻辑 + 关键观察锚点）+ 固定 5 条风险（`<ul class="risk">`）+ 免责声明（`.disclaimer`）。
   - 风险固定 5 条措辞：政策超预期 / 地缘反复 / 白银高波动 / 国内流动性 / 数据噪声（允许按当日事实微调描述，但 5 条主题不变）。

3. **核心图表仪表盘（紧跟结论）**

## 数据铁律

- 必须联网搜索当日真实行情，不得捏造；不同时点报价注明盘面（亚盘盘中 / COMEX 收盘）。
- 人民币折算价 ≠ 国内 T+D，两者并列、不强行统一（公式：美元价 × 汇率 ÷ 31.1035）。
- 10Y TIPS 实际收益率是金价「核心压制变量」，每次必查、必在宏观表体现。
- 「地缘冲突→油价→通胀→加息→金银跌」反向传导链优先解释行情。
- 机构目标价近期密集下调，必须标注是否已下调及幅度。
- 白银分析必讲「光伏去银化」工业逻辑（银包铜/电镀铜使单瓦耗银 −30~50%，2026 光伏用银预计 −10~19%）。
- 风险提示固定 5 条：政策超预期 / 地缘反复 / 白银高波动 / 国内流动性 / 数据噪声。
