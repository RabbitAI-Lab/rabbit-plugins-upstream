# AI Agent 安全检查清单

## 1. 敏感信息保护
- [ ] 代码中无硬编码的API密钥、密码、Token
- [ ] 敏感配置通过环境变量传入
- [ ] .env文件已加入.gitignore
- [ ] 日志中不打印敏感信息
- [ ] 错误信息不泄露系统内部细节

## 2. 输入验证
- [ ] 所有用户输入都进行验证和过滤
- [ ] 防止提示注入攻击
- [ ] SQL查询使用参数化查询
- [ ] 文件操作验证路径，防止目录遍历
- [ ] 输出内容进行适当转义

## 3. 权限控制
- [ ] 工具调用有权限校验
- [ ] 用户数据隔离
- [ ] 管理员接口有认证保护
- [ ] 最小权限原则

## 4. 数据安全
- [ ] 用户数据加密存储
- [ ] 敏感数据传输使用HTTPS
- [ ] 数据备份和删除策略
- [ ] 符合隐私法规要求

## 5. 依赖安全
- [ ] 第三方依赖定期更新
- [ ] 检查已知漏洞（CVE）
- [ ] 不使用来源不明的代码

## 6. 日志与监控
- [ ] 关键操作有审计日志
- [ ] 异常行为检测和告警
- [ ] 安全事件响应流程

## 7. AI特有风险
- [ ] 提示注入防护
- [ ] 输出内容审核
- [ ] 工具调用白名单
- [ ] 速率限制防止滥用
- [ ] 对话历史安全存储
