## Description:

Helps agents research YouTube videos, comments, channels, and Shorts through read-only SocialDataX data access.

This skill is ready for commercial/non-commercial use.

## Publisher:

[devinchen2014](https://clawhub.ai/user/devinchen2014)

### License/Terms of Use:

MIT-0

## Use Case:

External users and researchers use this skill to find YouTube videos, inspect video details and comments, and review channel profiles and video or Shorts lists.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Running the latest npm package at runtime can introduce unreviewed changes with access to the SocialDataX API key.

Mitigation: Pin and review the package version or use a controlled preinstalled copy, especially in sensitive environments.
