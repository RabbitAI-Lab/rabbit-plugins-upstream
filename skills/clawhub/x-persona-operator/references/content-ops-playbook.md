# 内容生产工作流与互动 SOP Playbook

> 把"今天发什么、怎么发、回什么"变成可复用的流程，而不是每次临场发挥。本 playbook 给内容生产工作流、跨平台改编矩阵与互动运营 SOP。偏方法论；具体执行见 [skills/content-engine/SKILL.md](../skills/content-engine/SKILL.md) 与 [skills/engagement-ops/SKILL.md](../skills/engagement-ops/SKILL.md)。

## 1. 内容生产工作流（4 步）

```
选题(人设+增益) ──▶ 创作(钩子+结构) ──▶ 审核(声音标尺) ──▶ 发布+首波互动
   │                    │                    │
   └─ 见 growth 日历    └─ 见 content-engine └─ 见 persona-playbook §4
```

1. **选题**：从人设半径 + 信息增益出发，优先"受众真问题 / 行业真争议 / 可验证结论"。
2. **创作**：Hook 前置（首句就给价值或冲突），结构清晰（清单体 / 故事体 / 逻辑链）。
3. **审核**：过 [persona-playbook.md](persona-playbook.md) 的"一致性检查清单"，确认声音命中、未越界。
4. **发布 + 首波互动**：发后 1–2 小时内主动在相关线程互动，撬动早期信号。

## 2. 跨平台改编矩阵

同一条核心观点，按平台形态改写（X 是主阵地，其它平台复用）：

| 源形态 | X 主帖 | 长线程 | 改编到 |
|--------|--------|--------|--------|
| 一篇长文 | 提炼金句 + 链接 | 拆成 5–8 条逻辑链 | 博客 / writer-studio |
| 一次教程 | 步骤清单体 | 逐步展开 + 代码块 | 短视频脚本（content-creator） |
| 一个观点 | 反共识单条 | 论据 + 案例 | LinkedIn / 公众号 |
| 一组资源 | 资源清单 | "收藏向"线程 | 简报（newsletter） |

**原则**：X 上先验证哪类内容互动高，再把高互动内容改编到其它平台，而不是反过来。

## 3. 互动运营 SOP

| 场景 | 动作 | 红线 |
|------|------|------|
| 有人 @ 或回复 | 24h 内回应，真人语气，不模板化 | 不冷嘲、不删异见（除非违规） |
| 高质量问题 | 展开答或转为下一条内容选题 | 不敷衍"已读乱回" |
| 负面 / 争议 | 按 persona-playbook §3 边界 SOP 处理 | 不情绪对线、不删改事实 |
| 大 V 相关线程 | 贡献有价值回复，借流反哺 | 不刷屏、不硬广 |
| DM | 按账号主设定的口径回应 | 不泄露隐私、不代做承诺 |

## 4. 发布前审核清单（总）

- [ ] 命中人设声音标尺（persona-playbook §2/§4）
- [ ] 首句有 Hook，结构可扫读
- [ ] 数据 / 链接可溯源，无未声明广告
- [ ] 未越界到"本账号不碰"话题
- [ ] 发布时段对齐受众活跃（growth 日历）
- [ ] 已备好首波互动动作

## 5. 常见坑

- **临场发挥无流程**：质量忽高忽低，人设不稳。
- **改编变抄袭**：跨平台改写了别人的观点不署名，损信誉。
- **互动模板化**：每条回复像机器人，社区感知差。
- **只发不维护**：内容发出即结束，错过早期互动窗口。
