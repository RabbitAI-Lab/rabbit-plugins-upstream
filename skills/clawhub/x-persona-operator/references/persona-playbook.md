# 人设定位与声音校准 Playbook

> 在写第一条推文前，先回答：这个账号是"谁"？它代表什么立场、用什么声音说话、绝不碰什么。本 playbook 给一套决策树 + 声音校准表 + 边界清单 + 常见坑。

本篇是「人设层」方法论（L2），负责把"账号是谁"定清楚；具体的人设落地动作下沉到 L3 子技能 [skills/persona-design/SKILL.md](../skills/persona-design/SKILL.md)。

## 1. 决策树：从 0 定人设

```
Q1 这个账号代表谁？
├─ 真实个人（创始人 / 专家 / 求职者）→ 走「真人放大」：放大既有观点，不虚构
├─ 品牌官方号 → 走「品牌人格」：抽象出品牌调性（专业/亲和/犀利）
└─ 虚构 IP / 角色号 → 走「角色设定」：写角色卡（背景/动机/口头禅）

Q2 核心受众是谁？（决定语气与话题）
├─ 开发者 / 技术人 → 直给、带代码、少修饰
├─ 创业者 / 投资人 → 强调杠杆、趋势、可行动结论
└─ 大众 / 消费者 → 类比、故事、情绪钩子

Q3 你提供什么"信息增益"？
├─ 观点（vs 共识搬运）→ 人设偏"犀利 / 有立场"
├─ 实操（教程 / 模板）→ 人设偏"实用 / 可靠"
└─ 资源（聚合 / 情报）→ 人设偏"策展 / 信息源"

Q4  Topic 半径多大？
├─ 单一垂直（如只聊 Rust）→ 人设极锐、易记忆，但天花板低
└─ 相关多主题（AI + 创业 + 职场）→ 人设偏"跨界观察者"，半径需有主线串联
```

**经验法则**：先在一个垂直里把人设打透（可识别），再向外辐射；不要一开始就做"什么都聊"的杂货铺。

## 3. 边界清单（Boundary Checklist）

人设的"不做什么"和"做什么"同样重要——边界缺失是账号翻车的主因。

- [ ] 不冒充真人 / 机构；虚构 IP 须明确是角色号
- [ ] 敏感话题（政治 / 宗教 / 族群 / 争议社会事件）立场已与账号主确认，或明确回避
- [ ] 不荐股 / 不承诺收益 / 不提供未经证实的医疗或法律建议
- [ ] 负面互动处理 SOP 已定：删 / 回 / 静音 / 拉黑 的触发条件
- [ ] 不实信息零容忍：引用数据必须可溯源，不确定标注"据 X 报道"
- [ ] 商业合作 / 推广必须标注，不夹带未声明广告

## 4. 一致性检查清单（每条发布前）

- [ ] 这句话换成别人发，能认出是本账号吗？（声音标尺命中）
- [ ] 是否越界到"本账号不碰"的话题？
- [ ] 是否兑现了账号的"信息增益"承诺（不是又一篇共识搬运）？
- [ ] 是否可被断章取义曲解？（高危句先改或加限定）
- [ ] 链接 / 数据是否可溯源？

## 5. 常见坑

- **人设漂移**：今天犀利明天亲和，算法和受众都记不住你是谁。
- **为蹭热点抛弃调性**：热点不对受众，流量来了也留不住，还稀释人设。
- **把角色号当真人说**：虚构 IP 未声明，被扒后信任归零。
- **过度人设化**：每句都端着，失去真实感；人设是底色，不是表演。
- **忽视负面 SOP**：第一次被怼就慌乱回应，放大冲突。
