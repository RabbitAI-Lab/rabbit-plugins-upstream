# X 算法增长与内容日历 Playbook

> 增长不是"多发"，是"让算法把你的声音推给对的人"。本 playbook 给 X 推荐逻辑的实操解读、增长循环设计、内容日历模板与复盘方法。偏方法论；具体执行见 [skills/growth-tactics/SKILL.md](../skills/growth-tactics/SKILL.md)。

## 1. X 推荐逻辑（实操解读，非官方黑盒）

X 的曝光主要由以下信号驱动（行业共识，非精确公式）：

| 信号 | 含义 | 运营动作 |
|------|------|---------|
| 早期互动率 | 发后 1–2 小时内的点赞 / 转推 / 回复 / 停留 | 发后主动在相关线程互动、引导首波评论 |
| 停留时长 | 线程被读完 / 展开的比例 | 用"钩子 + 渐进展开"结构，别一上来给结论 |
| 转发价值 | 被转推带来二跳曝光 | 内容要"可转述"：金句、清单、争议观点 |
| 关注转化 | 看完后点进主页关注 | 主页要有清晰人设与连续内容，别只靠单条 |
| 复访 | 用户反复回来看你 | 固定栏目 / 固定时间，培养习惯 |

**核心结论**：算法奖励"被真实互动的内容"，而非"高频刷屏"。一条高互动 > 十条无人理。

## 2. 增长循环设计（Growth Loop）

```
                     ┌──────────────┐
   关注者/路人 ──▶ 看到推文 ──▶ 早期互动(赞/转/回)
        ▲                                     │
        │                                     ▼
   关注转化 ←── 主页人设清晰 ←── 进入主页 ←── 二跳曝光(被转推)
        │
        └── 新关注者成为下一轮"看到推文"的基数
```

三类可主动设计的循环：

1. **钩子循环**：用"反共识观点 / 强清单 / 争议问题"拉早期互动 → 触发二跳。
2. **价值循环**：固定栏目（如每日一题 / 每周复盘）培养复访与期待。
3. **网络循环**：在相关大 V 线程里**高质量回复**（非刷屏），借其流量反哺本号。

## 3. 内容日历模板

| 时段 | 内容类型 | 目标 | 频率 |
|------|----------|------|------|
| 周一 | 观点 / 反共识 | 拉互动、立人设 | 1–2 条 |
| 周二–周四 | 实操 / 教程 / 资源 | 提供信息增益、促转发 | 2–3 条 |
| 周五 | 复盘 / 互动提问 | 促评论、养社区 | 1 条 |
| 周末 | 轻量 / 个人向 | 拉近距离、防断更 | 1 条 |

- [ ] 每周至少 1 条"旗舰内容"（长线程 / 深度观点），其余为辅助
- [ ] 固定栏目占 30%，即兴占 70%，避免全计划失灵活
- [ ] 发布时间对齐受众活跃时段（看 analytics 的高峰）

## 4. 复盘方法（每周 30 分钟）

用 X Analytics（或第三方）拉下列指标，按"假设—结果"对照：

- [ ] 曝光最高 3 条 vs 最低 3 条：差异在 Hook / 话题 / 形式？
- [ ] 互动率（互动 / 曝光）趋势：升 or 降，对应哪类内容？
- [ ] 关注净增：哪条带来最多关注转化（主页入口设计是否到位）？
- [ ] 下一周改什么：把一条"假设"写进下周计划（如"周二教程类互动更高 → 增到 3 条"）

**闭环原则**：每条内容都承载一个可验证假设，复盘用数据修正，而非凭感觉。

## 5. 常见坑

- **刷屏式更新**：一天 20 条低质，互动率被稀释，算法降权。
- **只发不互动**：早期互动靠自己主动，发完就走必无人理。
- **追所有热点**：热点不对人设，流量不转化关注。
- **忽视主页**：单条火了但主页空白，关注转化归零。
- **买粉 / 互刷**：虚假信号误导算法，真实互动率反而下降。
