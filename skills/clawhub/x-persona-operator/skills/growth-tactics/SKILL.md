# Growth Tactics — 增长策略（算法 / 循环 / 复盘）

> 增长不是"多发"，是"让算法把你的声音推给对的人"。本技能把推荐信号翻译成可执行的循环与日历，并用每周复盘闭环迭代。

**来源说明**：改编自社区技能 `coreyhaines31/marketingskills@social`（skills.sh 73.8K 安装，社交增长方法论），按本组织 superpower 架构重组；算法逻辑详见 [../../references/growth-algorithm-playbook.md](../../references/growth-algorithm-playbook.md)。

## 能力

- **信号解读**：早期互动率 / 停留时长 / 转发价值 / 关注转化 / 复访——五类信号对应动作
- **循环设计**：钩子循环（拉早期互动）、价值循环（固定栏目养复访）、网络循环（大 V 线程借流）
- **内容日历**：按受众活跃时段排布旗舰内容 + 辅助内容 + 固定栏目
- **复盘闭环**：每周拉曝光 / 互动率 / 净增，按"假设—结果"修正下周计划

## 使用方式

```
/growth-tactics 给我一份下周的 X 内容日历，受众是开发者，每周 3 条旗舰
/growth-tactics 我这周曝光跌了，帮我做个复盘，数据在 analytics 里
/growth-tactics 设计一个借大 V 流量的网络循环，不刷屏
```

## 工作流

1. **读信号**：明确当前阶段缺哪类信号（互动 / 关注 / 复访）
2. **选循环**：按目标选 1–2 个增长循环重点做
3. **排日历**：套 growth-algorithm-playbook §3 模板，旗舰占 30%、即兴 70%
4. **埋假设**：每条内容承载一个可验证假设
5. **周复盘**：用 §4 清单对照数据，写进下周修正项

## 适用场景

- 账号从 0 到 1 冷启动增长
- 增长瓶颈期诊断（互动率低 / 关注转化差 / 断更）
- 用数据而非感觉驱动内容节奏

## 限制

- 不买粉、不互刷、不刷屏；虚假信号会反伤真实互动率
- 增长动作须与人设一致，不为涨粉抛弃调性
- 具体推文怎么写交给 content-engine；具体回复话术交给 engagement-ops
- X 算法非公开，本技能给的是行业共识级实操，非精确公式
