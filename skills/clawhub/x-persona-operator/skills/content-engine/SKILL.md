# Content Engine — 内容引擎（选题 / 创作 / 改编）

> 有了人设，内容才能"像一个人持续在说"。本技能把长文、教程、观点改写成符合 X 形态与人设调性的推文与线程，并沉淀可复用的选题库。

**来源说明**：改编自社区技能 `coreyhaines31/marketingskills@social`（skills.sh 73.8K 安装，2026-10-08 更新），按本组织 superpower 架构重组为子技能，并叠加 persona-playbook 的人设约束。

## 能力

- **选题**：从人设半径 + 信息增益出发，优先受众真问题 / 行业真争议 / 可验证结论
- **Hook 设计**：首句即给价值或冲突，避免铺垫；清单体 / 故事体 / 逻辑链三选一
- **长线程结构**：逐条递进、可扫读、末条收口（CTA / 总结 / 钩子）
- **跨形态改编**：长文→金句+链接、教程→步骤清单、观点→反共识单条（见 [../../references/content-ops-playbook.md](../../references/content-ops-playbook.md) §2 矩阵）
- **人设对齐**：每条落稿前对照 persona-design 的声音标尺

## 使用方式

```
/content-engine 把这篇关于 RAG 的长文改成一条 X 线程，人设偏实用犀利
/content-engine 给"独立开发者如何冷启动"想 5 个选题，受众是程序员
/content-engine 这条观点写成反共识单条，不超过 280 字
```

## 工作流

1. **定输入**：长文 / 教程 / 观点 / 空白选题——明确源形态
2. **选结构**：按内容类型选 Hook + 线程/单条结构
3. **写稿**：首句 Hook 前置，正文可扫读，末条收口
4. **审标尺**：过 persona-playbook §4 一致性清单，确认声音命中、未越界
5. **排期**：按 growth 日历放入合适时段（见 [../../references/growth-algorithm-playbook.md](../../references/growth-algorithm-playbook.md) §3）

## 适用场景

- 每天稳定产出符合人设的推文与线程
- 把 blog / 文档 / 播客内容改编为 X 形态复用
- 冷启动期快速搭建选题库

## 限制

- 不编造数据 / 不夹带未声明广告；引用须可溯源
- 改编他人观点须署名，不洗稿
- 具体增长节奏与互动话术交给 growth-tactics / engagement-ops
