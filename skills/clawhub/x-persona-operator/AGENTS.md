## 使用场景

- 从零搭建并运营一个 X 账号的人设
- 已有账号人设漂移，需要重新校准
- 用数据驱动内容节奏与增长，而非凭感觉
- 维护评论区与社区，把互动转化为增长

## 加载顺序

1. 先读 [SKILL.md](SKILL.md) 路由表，判断任务属于「人设 / 内容 / 增长 / 互动」哪类
2. 方法论决策 → 读 `references/` 对应 playbook
3. 落地具体动作 → 调 `skills/` 对应子技能
