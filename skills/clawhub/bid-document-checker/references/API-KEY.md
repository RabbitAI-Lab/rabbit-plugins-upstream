# API 密钥配置

在平台开通产品后创建或复用账号通用 Key；产品生产默认关闭，尚未验收时不能调用。原有专用 Key 仍受对应产品与 Ability 范围限制。

```sh
: "${BID_DOCUMENT_CHECKER_API_KEY:=${AI_SKILLS_API_KEY:?请先配置平台密钥}}"
```

请求使用 `Authorization: Bearer ${BID_DOCUMENT_CHECKER_API_KEY:-$AI_SKILLS_API_KEY}`。仅访问 `https://ai-skills.open-idea.net`。不要输出、记录或在对话中粘贴完整 Key；上游模型 Key 由平台管理。401检查密钥；403检查开通、账户和 Ability；503检查产品启用与运行依赖，不能改用其他服务上传私有文件。

## 获取价格、确认费用与无法报价时的处理

目前没有对 OpenClaw 开放的独立产品报价、余额查询或预占试算 API。不要为了读取计费响应头提交收费任务，也不要编造 `/prices`、`/quote` 或 `/balance` 路径。让用户在已登录的产品工作台查看当前价格/最高预留和余额，确认对应操作、输入版本及人民币预算；无法获得当前费用依据时停在免费预检/复核步骤。

分析需要模型传输授权及按当前上限计费的同意；核验和组包分别按当前配置计费，草稿组包另须用户确认。一次授权仅覆盖用户明确约定的范围。任务实际收费以终态响应头为准，不能把受理时0元当成免费。平台通用操作 API 没有本包可提交的最高费用字段；Agent 记录的预算不是服务端强制限额，不能承诺超额绝不发生。需要服务端页面费用确认时让用户使用工作台；不要把网页 `/run` 私有会话端点当成 Bearer API。
