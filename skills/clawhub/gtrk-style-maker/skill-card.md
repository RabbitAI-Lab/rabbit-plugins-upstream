## Description:

通过启发式访谈帮助视频创作者提炼自己的视觉语法，并生成可执行的风格 skill、共享词表和栏目配置。

This skill is ready for commercial/non-commercial use.

## Publisher:

[gitruck](https://clawhub.ai/user/gitruck)

### License/Terms of Use:

MIT-0

## Use Case:

Video creators use this skill to clarify the visual language of a channel through an evidence-led interview, then turn it into reusable production skills and a channel style configuration.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Default installation can persistently make generated skills available to multiple assistants without first asking the user to select them.

Mitigation: Review generated skills before installation, choose which assistants may receive them, and consider project-only installation. Use a reviewed installer version.
