# Paper Reading Skill（论文精读 · 八要素法）

基于清华《科研学术表达》博导读论文方法的精读 Skill。核心理念：读论文不是吸收知识，而是**像研究者一样思考**——读思路不读结论，与作者对话，不成为文献的粉丝。

## ✨ 功能特色

- **八要素笔记表** — 作者 / 单位 / 时间 / 题目 / 研究目的 / 方法 / 结果 / 即时感想，一篇一行
- **对话式批注** — ❓疑问 / ⚡反驳 / 🔗补充 / 💡联想，逐段与作者过招
- **批判性四问** — 解决了什么 / 方法好在哪 / 不足 / 下一步
- **领域定位** — 时间轴进化史 + 学术人际网络 + 文献地图
- **手搓原则** — AI 负责引导提问和整理，即时感想与判断由你本人产出

## 🔑 使用方式

直接把论文（全文文本 / PDF 路径 / 标题 / DOI / 链接）发给我，说"精读这篇"即可。

- 想先找文献？先用 `psych-literature-search` 检索，再逐篇精读
- 读了几篇后，说"帮我看看我读过的文献之间有什么关系"生成文献地图
