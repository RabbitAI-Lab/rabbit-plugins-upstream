## 概览
本文档定义质量成本分析中图表类型的选择规则。系统将根据数据特征和分析目的自动选择最合适的图表类型，确保数据可视化的有效性和可读性。

## 图表类型与适用场景

### 1. 饼图（Pie Chart）
**用途**：展示部分与整体的关系，强调各部分在整体中的占比

**适用场景**：
- 展示质量成本四大分类的占比
- 展示损失成本的构成（内部 vs 外部）
- 展示预防鉴定成本的构成（预防 vs 鉴定）

**使用条件**：
- 数据类别较少（≤ 6个）
- 所有类别的总和代表整体（100%）
- 重点是比例而非绝对值

**不适合的场景**：
- 类别过多时（> 6个）
- 需要比较不同时期的占比
- 需要精确比较各部分大小

**示例**：质量成本分类占比（预防成本 20%、鉴定成本 30%、内部损失 35%、外部损失 15%）

### 2. 柱状图（Bar Chart）
**用途**：比较不同类别的数值大小

**适用场景**：
- 比较四大分类的金额
- 比较不同项目的成本
- 比较不同部门的成本

**使用条件**：
- 需要比较各类别的绝对值
- 类别标签较长时使用横向柱状图
- 需要精确比较数值大小时

**变体**：
- **分组柱状图**：比较多个维度的数据（如不同时期、不同部门的对比）
- **堆叠柱状图**：展示总体构成的同时比较各部分大小

**示例**：四大分类金额对比（预防成本 ¥100万、鉴定成本 ¥150万、内部损失 ¥175万、外部损失 ¥75万）

### 3. 折线图（Line Chart）
**用途**：展示数据随时间的变化趋势

**适用场景**：
- 展示质量成本总额的趋势变化
- 展示各分类成本的趋势变化
- 展示指标（如损失成本占比）的趋势变化
- 对比多个指标的趋势

**使用条件**：
- 数据具有时间序列特征
- 需要展示变化趋势和规律
- 数据点较多（≥ 5个时期）

**变体**：
- **多线图**：同时展示多个指标的趋势
- **面积图**：强调累积效果和总量变化

**示例**：2023年Q1-Q4质量成本趋势（Q1: ¥400万 → Q2: ¥450万 → Q3: ¥420万 → Q4: ¥380万）

### 4. 雷达图（Radar Chart）
**用途**：多维度对比分析

**适用场景**：
- 评估不同时期的质量管理成熟度
- 对比不同部门的质量成本结构
- 评估质量改进效果

**使用条件**：
- 需要同时比较多个维度（≥ 3个）
- 维度之间有可比性
- 数据已经标准化

**不适合的场景**：
- 维度过多（> 8个）
- 需要精确比较数值大小

**示例**：2023年 vs 2024年质量成本结构对比（预防、鉴定、内损、外损四个维度）

### 5. 热力图（Heatmap）
**用途**：展示二维数据的分布和关联

**适用场景**：
- 展示不同部门在不同时期的成本
- 展示成本项目的关联分析
- 识别成本热点

**使用条件**：
- 数据具有二维结构
- 需要快速识别异常值或热点

**示例**：各部门各季度质量成本热力图

### 6. 指标卡片（Indicator Card）
**用途**：突出展示关键指标的数值和状态

**适用场景**：
- 展示质量成本总额
- 展示损失成本占比
- 展示预警指标

**使用条件**：
- 需要强调关键数字
- 需要快速获取核心信息

**示例**：质量成本总额 ¥500万、损失成本占比 50%

### 7. 仪表盘（Gauge）
**用途**：展示指标在预设范围内的位置

**适用场景**：
- 展示损失成本占比是否达标
- 展示质量改进目标完成度

**使用条件**：
- 指标有明确的阈值或目标值
- 需要直观展示指标状态

**示例**：损失成本占比 50%（目标：< 40%）

## 自动选择规则

### 规则1：分类占比分析
**触发条件**：
- 数据按分类汇总
- 需要展示各分类在整体中的占比

**选择逻辑**：
```
IF 分类数量 ≤ 6:
    生成饼图
ELSE:
    生成柱状图 + 饼图（饼图仅展示前6个+其他）
```

### 规则2：分类金额对比
**触发条件**：
- 数据按分类汇总
- 需要比较各类别的绝对金额

**选择逻辑**：
```
生成柱状图
```

### 规则3：趋势分析
**触发条件**：
- 数据包含时间维度（日期列）
- 时期数量 ≥ 3

**选择逻辑**：
```
IF 时期数量 ≥ 5:
    生成折线图
ELSE:
    生成柱状图（时间序列）
```

### 规则4：关键指标展示
**触发条件**：
- 需要突出展示核心指标

**选择逻辑**：
```
生成指标卡片 + 仪表盘（如果指标有目标值）
```

### 规则5：多维度对比
**触发条件**：
- 需要同时比较多个维度
- 维度数量 ≥ 3

**选择逻辑**：
```
IF 维度数量 ≤ 8:
    生成雷达图
ELSE:
    生成分组柱状图
```

### 规则6：综合报告
**触发条件**：
- 生成完整的质量成本分析报告

**选择逻辑**：
```
默认生成以下图表组合：
1. 饼图（分类占比）
2. 柱状图（分类金额对比）
3. 折线图（如果有趋势数据）
4. 指标卡片（关键指标）
5. 仪表盘（如果有目标值）
```

## 图表设计原则

### 颜色使用
- **一致性**：同一分类在不同图表中使用相同颜色
- **可读性**：避免使用过于相似的颜色
- **语义化**：
  - 预防成本：蓝色（代表稳定、理性）
  - 鉴定成本：绿色（代表检查、验证）
  - 内部损失成本：橙色（代表警告）
  - 外部损失成本：红色（代表危险）

### 标签与标题
- 图表标题应清晰说明图表内容
- 坐标轴标签应包含单位
- 数据标签应显示关键数值
- 图例应放置在合适位置（右侧或底部）

### 交互性
- 支持鼠标悬停显示详细数据
- 支持点击图例显示/隐藏数据系列
- 支持缩放和拖动（针对折线图）

### 响应式设计
- 图表应适应不同屏幕尺寸
- 在移动端自动调整布局
- 支持横向滚动（针对宽表格）

### 可访问性
- 提供图表的文本描述
- 使用高对比度颜色
- 避免仅用颜色区分数据

## 特殊场景处理

### 场景1：数据量过大
**问题**：当数据点过多时，图表会变得拥挤不堪

**解决方案**：
- 折线图：使用采样或聚合
- 柱状图：仅显示Top N，其余归为"其他"
- 饼图：仅显示前6个，其余归为"其他"

### 场景2：数据差异过大
**问题**：当数据量级差异过大时，小数值难以识别

**解决方案**：
- 使用对数刻度
- 使用双Y轴
- 拆分为多个图表

### 场景3：空值或缺失数据
**问题**：数据中存在空值或缺失时期

**解决方案**：
- 在折线图中断开连接（显示空缺）
- 在柱状图中留出空白位置
- 在图例中标注数据缺失

### 场景4：异常值
**问题**：数据中存在异常值，影响整体可视化效果

**解决方案**：
- 在数据清洗阶段处理异常值
- 在图表中标注异常值
- 提供过滤选项，允许用户排除异常值
