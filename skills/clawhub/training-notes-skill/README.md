# 培训纪要结构化（training-notes-skill）

> **参赛作品 · SkillHub 线上挑战赛（第 1 期）**
> 主题：**让开会更简单** ｜ 基于官方「腾讯会议 Skill（tmeet）」二创

把一小时培训会议的冗长转写稿，重构成**可速读的章节手册 + 可自测的题库**，让一次培训沉淀为可复用的知识资产。

---

## 为什么做这个（差异化）

赛事介绍明确点名「培训」场景，但当前参赛作品中**几乎没有专门的培训结构化工具**——多数聚焦通用会议。培训是高频、强复用、且最易被感知"会后价值"的场景，契合度天然高，是本期值得冲奖的空旷赛道。

---

## 特性

- ✅ 转写 → 章节手册 + 自测题，一键产出
- ✅ 对接 tmeet：拉取培训会议录制/智能纪要/转写
- ✅ 本地兜底：无 tmeet 时用本地素材，附 `training_minutes.py`
- ✅ 输出带目录、要点、自测题，新人可直接自学
- ✅ 可独立运行：纯标准库 Python 脚本，零依赖

---

## 环境要求

- 已安装并授权 **腾讯会议 Skill（tmeet）**（在线模式）。
- 本地模式：Python 3.8+，无需任何第三方包。

---

## 安装

下载 `training-notes-skill.zip` → SkillHub/WorkBuddy 导入 → 同时安装官方 tmeet。

---

## 快速开始

**在线模式**
> 用户：把这场后端规范培训转写做成手册，附自测题。
> 助手：tmeet 拉取转写 → 切章 → 每章要点+2题 → 输出《后端规范培训手册》。

**本地模式**
```bash
python scripts/training_minutes.py --input examples/培训转写.md --output 培训手册.md
```

---

## 辅助脚本 `scripts/training_minutes.py`

| 参数 | 说明 |
|------|------|
| `--input` | 培训转写/纪要素材（.md/.txt） |
| `--output` | 输出培训手册路径 |
| `--title` | 手册标题 |

脚本按标题/段落切分章节，抽取要点，并基于要点生成自测题（启发式），是「完成度 / 可独立运行」评分的支撑。

---

## 与比赛主题的契合

- **让开会更简单**：培训会议「会后复用」长期是空白，本 Skill 让培训产出可检索、可自测的知识资产，降低重复培训成本。
- **基于 tmeet 二创**：单向依赖官方腾讯会议 Skill 的录制/转写能力，属赛事鼓励的「场景组合」二创，专家评审阶段可获额外加分。
- **可独立运行 + README 完整**：满足海选 TRACE 自动评测要求。
