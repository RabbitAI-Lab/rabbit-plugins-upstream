# 培训手册模板（training_template）

> training-notes-skill 输出的培训手册骨架。

```markdown
# {培训主题} 培训手册

## 目录
1. {章节一}
2. {章节二}

## 第1章 {章节一}
### 要点
- {关键概念/操作步骤/易错点}
### 自测题
（简答）本章提到的「X」具体指什么？

## 第2章 {章节二}
...
```

## 生成规则

- **章节切分**：优先按原文 `#` 标题；无标题时按空行段落近似切分。
- **要点抽取**：列表项、加粗句、含冒号的短句。
- **自测题**：每章基于首条要点生成 1-2 道简答题，用于培训后自测。

> 自测题为复习引导，非标准考卷；正式考核请人工审校题库。
