## 第1章 第一章 代码提交规范
### 要点
- 提交信息格式：type(scope): subject，例如 feat(order): 支持分期付款
- 禁止大杂烩提交，单次只做一件事，便于回滚与 review
- 提交必须关联需求单号，方便追溯
- 不要在提交里混改格式与逻辑

## 第2章 第二章 分支管理
### 要点

- 合并前必须至少一人 Code Review 并通过 CI

## 第3章 第三章 异常处理
### 要点
- 禁止吞异常（空 catch），必须记录日志或向上抛出
- 对外接口必须返回统一错误码，不暴露内部堆栈
- 关键路径打 INFO 日志，异常打 ERROR 并带上下文
- 第三方调用必须设置超时与降级
