## Known Risks and Mitigations: <br>
Risk: Refactoring advice can introduce behavior changes if applied without tests or review. <br>
Mitigation: Review proposed diffs and run the project test suite before accepting changes, especially for production or business-critical code. <br>
Risk: Example refactorings may not match the target codebase's architecture or domain constraints. <br>
Mitigation: Apply patterns in small, focused changes and adapt them to local conventions during code review. <br>
