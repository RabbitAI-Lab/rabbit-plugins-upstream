## Description:

Make an instrumental track or a song with lyrics with a Wiro AI music model. Use when the user wants music, a song or a jingle made with Wiro AI or through the Wiro MCP server.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Users who want an original instrumental track, song, or jingle use this skill to turn a style description and optional lyrics into generated music through Wiro's hosted models.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Request text and supplied lyrics, including lyrics read from a local project file, may be sent to Wiro and its selected hosted model.

Mitigation: Only include request text and lyrics that you are comfortable sharing with Wiro and its selected hosted model.

Risk: The security scan was partial because a local path-like reference could not be resolved, leaving the evidence incomplete.

Mitigation: Review the unresolved path reference and the related skill behavior before use.
