**核心设计**：
VAD 不再用 `duration_s >= 30*60` 硬编码，而是 `workload > estimated_capacity * safety_margin`。
- 冷启动默认容量 60 min·base，safety_margin=0.8 → VAD 触发线为 48 min·base
- 随着 `record_task()` 执行更多任务，`estimated_capacity` 自动校准
- 公式自动适应：服务器容量大 → VAD 触发线自动抬高

**变更逻辑对比**：
```
之前: ≥30min → VAD（固定死线）
现在: workload > C×0.8 → VAD（动态自适应）
```

## v1.7.1 (Hotfix) — _guess_domain 增加 uploader 参数

### 问题
`_guess_domain(video_title)` 只看标题，合集分集标题如"20210908 院长专栏"不含交易关键词，
返回 `general`。但UP主名"张聚贤说交易"含"交易"关键词。

### 改动
| 文件 | 改了什么 |
|------|---------|
| `transcription_enhancer.py` | `_guess_domain(video_title) → (video_title, uploader)`，同时检查标题和UP主名 |
| `pipeline.py` (2处) | 调用加 `uploader` 参数 |
| `transcriber_bilibili.py` | 调用加 `owner_name` 参数 |
| `speaker_knowledge.py` | `_guess_domain` 增加 `uploader` 参数，调用处传 `speaker` |

### 验证
```
_guess_domain("20210908 院长专栏", "")             → general  (无uploader)
_guess_domain("20210908 院长专栏", "张聚贤说交易")  → trading  ✅
_guess_domain("Anthropic Managed Agent", "AI研究")  → tech     ✅
```
