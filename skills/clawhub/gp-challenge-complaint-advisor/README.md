# 政府采购质疑投诉参谋（GP Challenge & Complaint Advisor）

基于 IMA 可用知识库（政府采购投诉AI知识库 等）的政府采购质疑/投诉参谋工具，面向供应商与潜在供应商，提供**参谋（查案例）**、**质检（审草稿）**、**填空（轻起草）** 三大能力。

## 功能

- **参谋模式**：输入案情，检索相似投诉处理案例，输出《投诉参谋报告》（相似案例、官方驳回/支持理由、风险提示），每条案例可溯源到知识库 `media_id`。
- **质检模式**：粘贴投诉书草稿，按结构要素 + 深度逻辑层（事项-依据对应、时间链、请求可执行性、语言规范、证据充分性）分级标记风险。
- **填空模式**：按争议类型输出投诉书骨架模板，并依上下文动态预填、附高频法条与填写提示。

## 触发词

投诉参谋、投诉书助手、政府采购投诉、质疑、审投诉书、查投诉案例、写投诉书、投诉质检、投诉书模板、类似案例、被驳回理由、投诉有用吗、财政局会支持我吗、质疑被驳了怎么办、投诉能赢吗；退出/异常：不想投诉了、投诉撤回。

## 知识库（IMA 可用）

- 主库：政府采购投诉AI知识库（id `7450416392468005`）
- 补充：招投标异议投诉处理（`7480160395744474`）、政府采购实务与合规（`7463496212028405`）
- 可选：法律-法律案例（`7312638744735564`，仅作广义法律先例交叉印证）

## 使用说明

1. 描述案情或粘贴草稿，技能自动路由到对应模式。
2. 所有案例引用均来自知识库真实检索，禁止编造；报告附来源 `media_id` 与法条条文号。
3. 本报告基于历史案例数据，不构成法律意见，建议咨询执业律师。
