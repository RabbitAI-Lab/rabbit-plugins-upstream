## Description:

Helps authors plan and write long-form Chinese web fiction, from story structure and outlines to requested chapters and revisions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[worldwonderer](https://clawhub.ai/user/worldwonderer)

### License/Terms of Use:

MIT-0

## Use Case:

Authors and other external users use this skill to plan a serialized novel, develop outlines, draft requested chapters, and revise existing chapters while maintaining story continuity.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Planning and writing workflows may create or modify story files and continuity records in the selected project.

Mitigation: Use a dedicated writing workspace and review the project path before running a workflow that changes files.

Risk: Explicit author-preference memory may persist beyond an individual drafting session.

Mitigation: Review what preferences will be saved and request memory updates only when intended.
