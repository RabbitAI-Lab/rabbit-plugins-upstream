## Description:

Assists with long-form web novel writing from outline to draft, including worldbuilding, character design, plot-line management, daily continuation, revision, and prose checks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[worldwonderer](https://clawhub.ai/user/worldwonderer)

### License/Terms of Use:

MIT-0

## Use Case:

External writers and writing agents use this skill to plan, draft, continue, revise, and quality-check long-form web fiction projects while maintaining story state, reader expectations, character relationships, and chapter continuity.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security review says part of the guidance encourages adapting existing works beat by beat and calling the result original.

Mitigation: Use the skill for original outlining, continuity management, drafting, and style cleanup; do not map a copyrighted source's scenes or beats into a new work.

Risk: The security review says the skill may create and modify many project files and run local Node/Python scripts for tracking and prose checks.

Mitigation: Review planned file changes and scripts before execution, and run the skill inside a project workspace with version control.
