## Description:

Story Long Write helps agents plan, draft, revise, and quality-check long-form Chinese web fiction with structured outlines, character and worldbuilding files, continuity tracking, and local prose-quality tools.

This skill is ready for commercial/non-commercial use.

## Publisher:

[worldwonderer](https://clawhub.ai/user/worldwonderer)

### License/Terms of Use:

MIT-0

## Use Case:

Writers, editors, and agent operators use this skill to create and maintain long-form Chinese web-fiction projects, including premise selection, setting and character design, chapter outlines, drafting, revision, continuity tracking, and quality checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may create or modify fiction project files, including outlines, chapters, character notes, tracking JSON, and derived Markdown views.

Mitigation: Use it in a dedicated writing folder and review generated edits before publication or reuse.

Risk: Comparator and adaptation workflows can encourage outputs that are too close to copyrighted works.

Mitigation: Use comparator material for high-level craft analysis only and check drafts for original plot, character, and prose expression.

Risk: Bundled Node and Python tools inspect and update local project files as part of quality and tracking workflows.

Mitigation: Run the tools only on intended project paths and keep backups or version control for writing projects.
