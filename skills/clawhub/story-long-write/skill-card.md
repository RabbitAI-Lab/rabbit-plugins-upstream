## Description:

Helps authors plan, draft, and revise long-form Chinese web fiction, from story structure and outlines through individual chapters.

This skill is ready for commercial/non-commercial use.

## Publisher:

[worldwonderer](https://clawhub.ai/user/worldwonderer)

### License/Terms of Use:

MIT-0

## Use Case:

Fiction authors and writing assistants use this skill to develop a long-form web novel, plan volumes and chapters, write requested chapters, and revise drafts while maintaining story continuity.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Story planning and drafting can create or change multiple files in the selected workspace.

Mitigation: Run it in a dedicated fiction-project directory and review changes before accepting them.

Risk: Optional author preference memory and story tracking persist locally.

Mitigation: Keep sensitive material out of the writing workspace and review stored preferences and tracking files.
