# Source and release identity

Hype Shorts Remix 0.1.1 contains independently implemented Node.js scripts and original workflow
instructions. The scripts use Node built-ins and invoke the user's installed FFmpeg/FFprobe.
Project data is ordinary JSON and local media files. Source code and instructions are included
in this archive under the accompanying MIT-0 license for this ClawHub distribution.

The included rain clip was generated for this release's owner through APIsRouter using Seedance
2.0 Mini on 3 October 2026. Its measured dimensions are 1280×720. It supplies local example media;
rendering the example makes no model request. API-generated media and local edited compositions
have separate verification records.

FFmpeg, Node.js and any separately selected model or media services are installed or accessed
independently and retain their own licenses and terms. This package contains no account keys or
prepaid generation credits.
