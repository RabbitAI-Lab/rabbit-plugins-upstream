## Description:

Checks and helps fix Open Graph and Twitter card metadata so shared pages display the intended link previews.

This skill is ready for commercial/non-commercial use.

## Publisher:

[egorshar](https://clawhub.ai/user/egorshar)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and site owners use this skill to check page or site link previews, correct social metadata and image tags, and verify the result after deployment.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Link-preview checks share page URLs with getwowlink.

Mitigation: Check only public pages or staging pages safe to share.

Risk: Incorrect or duplicate meta-tag changes can degrade shared previews.

Mitigation: Review generated edits before deployment and re-check the live pages afterward.
