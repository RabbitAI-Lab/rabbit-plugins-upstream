## Description:

Minimalist Design System guides agents in applying a modern minimalist UI design system, including design tokens, component styling, Tailwind customization, responsive layouts, motion, and accessibility practices.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and frontend-focused agents use this skill to apply a consistent minimalist visual system to UI implementation, component libraries, Tailwind tokens, responsive layouts, motion, and accessibility refinements.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can steer frontend work toward a specific minimalist visual style even when a project needs a different design language.

Mitigation: Apply the skill only when minimalist design-system, UI styling, Tailwind token, component library, or visual consistency work is explicitly desired.

Risk: Some source guidance is written in Chinese, which may create ambiguity in non-Chinese workflows.

Mitigation: Ask the agent to respond in the user's preferred language and confirm design choices before applying broad UI changes.
