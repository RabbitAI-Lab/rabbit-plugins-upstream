## WB01-技能生成域范本

### 范本概述

D1 技能生成域全任务范本，覆盖 D1-01/D1-02/D1-03/D1-04 全部任务的产物样式：目录结构 → SKILL.md → 子资源 → 打包自检。

### 范本正文

**【D1-01 技能目录结构生成】目录树**（含空目录占位说明）：

```
skills/weekly-report/
├── SKILL.md              # ★ 必须存在，最先创建
├── references/           # 本技能需要：周报章节结构规范（1 个文件，平铺）
└── templates/            # 本技能需要：报告输出模板（1 个文件，平铺）
# 无脚本需求 → 不建 scripts/，不为凑数建空目录；目录名与 name 一致（kebab-case）
```

**【D1-02 SKILL.md 生成】完整 SKILL.md**（frontmatter 12 字段全展示）：

````markdown
---
name: weekly-report
display_name: 周报生成器
display_name_en: Weekly Report Generator
description: 从工作记录、Git 提交与任务列表生成结构化周报。触发词：周报、本周总结、weekly report
description_zh: 从工作记录与任务列表生成结构化周报
description_en: Generate structured weekly reports from work logs and task lists
category: productivity
allowed-tools: Read, Grep, Glob
version: 1.0.0
author: Your-Company-Name
---

# 周报生成器

当用户需要生成周报时，按以下步骤执行：

1. 收集输入：向用户确认时间范围（默认本周），读取 @references/report-rules.md 中的章节结构要求
2. 汇总素材：从用户提供的记录、任务列表中提取本周期完成项、进行中项、风险项
3. 生成周报：按 references/report-rules.md 的章节结构输出，数字保留原始精度，不确定的标注"待确认"
4. 输出：Markdown 格式落盘为 weekly-report-{YYYY-WW}.md，并向用户展示摘要
````

**【D1-03 子资源生成】子资源内容示例**（references/ 知识文档样例节选）：

````markdown
# report-rules.md（references/report-rules.md）
## 周报章节结构（AI 按此组装）
1. 本周概要（≤3 行）
2. 完成事项（表格：事项/进度/佐证）
3. 进行中（表格：事项/进度/风险）
4. 下周计划（列表）
## 措辞规范
- 客观陈述，不使用形容词堆砌；数据保留原始精度；无佐证的条目标注"待确认"
````

**【D1-04 技能打包】打包自检清单 + 打包记录**：

```markdown
## 打包自检清单
- [x] SKILL.md 位于包根，frontmatter 必填字段（description/description_zh/description_en/version/author）齐全
- [x] 目录层级 ≤ 2（根目录/二级目录/文件），references/ 与 templates/ 内文件直接平铺
- [x] @references/ 引用的文件全部真实存在
- [x] 包内无真实凭证，占位符均为 ${VAR} 形式
- [x] 全部文件 UTF-8 编码
## 打包记录
- 命令：压缩 skills/weekly-report/ 为 weekly-report.zip，zip 根层为 weekly-report/ 目录
- 包名：weekly-report.zip；版本：1.0.0
```

### 结构要点标注

1. description 必填且含触发词；description_zh/description_en 成对必填；version/author 必填
2. 可选字段按需保留、省略即默认：category 取平台分类之一（以创建页为准）；allowed-tools 逗号分隔；disable-model-invocation/user-invocable 仅接受 true/false，仅在需改变默认行为时添加
3. 正文为可直接执行的步骤指令，引用子资源用 @references/ 路径且文件真实存在
4. 目录名与 name 一致（kebab-case）；zip 根层为 weekly-report/ 目录
5. 无外部调用的技能不放 scripts/，避免无用目录
6. 两级目录硬约束：references/ 内文件直接平铺，禁止嵌套子目录（平台实测超限即解析失败）

### 替换清单

name/display_name/三个 description/author 替换为用户技能信息；category/allowed-tools 按技能实际取值替换或整行删除；正文步骤改写为用户技能的真实执行流程；references/ 与 templates/ 内容替换为用户的领域知识与输出模板；自检清单按实际勾选结果更新。
