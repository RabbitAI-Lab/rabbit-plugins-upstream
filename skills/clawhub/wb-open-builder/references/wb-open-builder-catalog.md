### 依赖拓扑摘要

#### 一、域内链路

**需求路由链路**：D0-01 → D0-02 → D0-03
**技能生成链路**：D1-01 → D1-02 → D1-03 → D1-04
**连接器生成链路**：D2-01 → D2-02/D2-03（D2-02 与 D2-03 可并行）→ D2-04
**专家生成链路**：D3-01 → D3-02 → D3-03 → D3-04
**专家团生成链路**：D4-01 → D4-02 → D4-03 ‖ D4-04
**Buddy应用链路**：D5-01 → D5-02 → D5-03
**校验交付链路**：D6-01 → D6-02（校验 FAIL 时 ↻ 回对应生成任务修正后复检）

#### 二、跨域协同链路

**主生成管线**（P4 条件分支）：D0-01 → D0-02 → D0-03 ?(类型)→ D1/D2/D3/D4/D5 对应域 → D6-01 ⇇ 五域终任务扇入 → D6-02
**校验迭代链路**（P2 迭代精炼）：D6-01 ↻(FAIL → 对应 Dx 任务修正 → 复检) → D6-02
**组合生成**：多类型组合（如专家团内置共享技能）按 D4 主链 + D1 子链（skills/ 目录）编排，共享技能目录挂载于团队包 skills/ 下
**Buddy应用引用**：D5 市场配置可引用 D1/D2/D3/D4 产出的资产或平台已有资产，引用 ID 须与资产 source/name 一致

#### 三、入口说明

标准入口为 D0-01。校验已有资产包场景下，D6-01 可作为临时入口（此时其依赖视为已满足，校验后按需回写修正建议）；该双入口约定仅在执行层生效，catalog 依赖字段保持生成链路定义。

#### 四、知识图谱

**实体节点类型**：任务节点 D0-01~D6-02（24 个）；域节点 D0~D6（7 个）；元操作节点 S/C/A/O/I/G；资产类型节点（技能/连接器/专家/专家团/Buddy应用）。

**关系边类型**：依赖边（→）、并行边（‖）、扇入边（⇇）、条件边（?）、迭代边（↻）、产出边（任务→资产文件）。

**推理能力**：由资产类型反推所需任务路径；由校验 FAIL 字段定位所属任务并给出修正路径；由依赖边识别可并行任务组合。
