## 范本清单

按域分组的范本索引。范本来源为 WorkBuddy 开放平台官方文档示例（已含占位符，无敏感信息），结构可直接模仿，业务内容须替换为用户自己的。

### 范本标准格式模板

每个范本子文件统一使用以下结构：

```
## WB{编号}-{域名}范本
### 范本概述
（一段话：该范本对应的资产类型与适用场景）
### 范本正文
（完整可复制的配置/文件内容，占位符保持 {{VAR}} 形式或官方示例原样）
### 结构要点标注
（3~6 条：该范本体现的关键规范点，对照 requirements 字段表）
### 替换清单
（模仿产出时必须替换的元素列表）
```

### 使用规则

1. 结构类组件（目录、JSON 字段）优先用 templates/ 模板填充；范本用于理解"填成什么样算对"
2. 文案类组件（描述、示例、提示词）用样本法模仿范本结构与风格，业务内容全部替换
3. 范本中的占位符（example.com、${VAR}、you@example.com 等）禁止原样提交，生成时全部替换为真实值或保留 ${VAR} 待用户填写
4. 官方示例与 requirements 字段表冲突时（如 displayDescription 字数、defaultInitPrompt 一致性在个别官方示例中未满足），以 requirements 字段表为准并复检
