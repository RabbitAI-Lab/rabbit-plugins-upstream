## WB02-连接器生成域范本

### 范本概述

D2 连接器生成域全任务范本，覆盖 D2-01/D2-02/D2-03/D2-04 全部任务的产物样式：接入方式判定 → 元信息与图标 → 连接配置 → 配套 Skill。以 MCP+Skill 方案为主线（官方任务管理示例改写），CLI 方案差异在要点中标注。

### 范本正文

**【D2-01 接入方式判定】判定报告**：

```markdown
## 接入方式判定报告
- 判定结果：MCP + Skill
- 判定依据：服务方提供网络 API 且可封装为 MCP Server（远程 streamableHttp 接入）；非"已有稳定跨平台 CLI"场景（否则应选 CLI + Skill）
- Server 能力清单：create_task（创建任务）、list_tasks（查询任务）、update_task（更新任务）——逐工具列入 D2-04 说明范围
- 认证方式初判：Server 自带 OAuth → connector-meta.json 省略 auth_mode
```

**【D2-02 元信息与图标生成】connector-meta.json**：

```json
{
  "name": "任务管理",
  "name_zh": "任务管理",
  "name_en": "Task Manager",
  "description": "Create and manage tasks in WorkBuddy.",
  "description_zh": "通过自然语言创建、查询和更新任务。",
  "description_en": "Create, query, and update tasks with natural language.",
  "source": "task-manager",
  "type": "mcp",
  "version": "1.0.0",
  "examples_zh": [
    "创建一个明天下午到期的评审任务",
    "列出本周尚未完成的任务"
  ],
  "examples_en": [
    "Create a review task due tomorrow afternoon",
    "List unfinished tasks for this week"
  ]

```

icon.svg：平台图标（SVG 推荐/PNG/JPG，PNG·JPG 建议 64×64、背景透明、小尺寸可辨识），文件名 icon.svg 置于包根。

**【D2-03 连接配置生成】mcp.json**（远程 MCP，HTTPS + 占位符凭证）：

```json
{
  "mcpServers": {
    "your-service": {
      "type": "streamableHttp",
      "url": "https://mcp.example.com/mcp",
      "headers": {
        "Authorization": "Bearer ${SERVICE_TOKEN}"
      },
      "timeout": 30000
    }
  }
}
```

mcp.json 本地 stdio 备选形态：

```json
{
  "mcpServers": {
    "your-service": {
      "command": "npx",
      "args": ["your-mcp-package"],
      "runtime": { "type": "node", "version": "20" }
    }
  }
}
```

**【D2-04 配套 Skill 生成】skills/task-usage/SKILL.md**（逐工具说明范式，节选）：

````markdown
---
name: task-usage
description: Instruct the AI to correctly call the Task Manager connector tools (create/list/update tasks)
---

# 任务管理连接器使用说明

## 前置条件
用户已连接 task-manager 连接器并完成授权；授权失效时提示"请在 WorkBuddy 连接器设置中重新连接"。

## 工具说明
### create_task
- 用途：创建新任务
- 参数：title（string，必填）、due_date（string，选填，ISO 8601）、priority（enum: high/normal/low，默认 normal）
- 调用示例：用户说"创建一个明天下午到期的评审任务" → create_task(title="评审任务", due_date="2026-09-03T14:00:00+08:00")
- 错误恢复：due_date 格式错误时向用户确认具体时间后重试，不猜测

### list_tasks / update_task
（同格式逐工具补全：用途/参数表/调用示例/错误恢复）

## 高风险操作确认
删除任务、批量更新前必须向用户复述影响范围并获确认。
````

**目录结构**：

```
your-connector/
├── connector-meta.json
├── mcp.json
├── icon.svg
└── skills/
    └── task-usage/
        └── SKILL.md
```

### 结构要点标注

1. mcpServers 下仅一个 Server；远程必须 HTTPS；凭证一律 ${VAR} 占位
2. source 为 kebab-case 全局唯一；examples_zh/en 各 2~5 条用户真实口语
3. 配套 Skill 的参数名/类型/必填/默认值必须与实际工具一致；MCP 有标准工具描述时 skills/ 可选，CLI 方案强烈推荐必须提供
4. type=cli 时必须改用 cli.json 并将 type 设为 "cli"（cli.json 三平台 init/auth/status/unAuth 命令与 statusMatch 规则见 requirements D2-03）
5. auth_mode 取值：省略（自带 OAuth/无认证）/ server-side / gateway / token（token 需配 token-schema.json）

### 替换清单

source/name/description/examples 替换为用户服务信息；url 替换为真实 MCP 地址；${SERVICE_TOKEN} 换成用户服务的实际变量名；D2-01 判定报告按用户服务形态重写；skills/ 内 SKILL.md 按用户真实工具清单逐工具重写。
