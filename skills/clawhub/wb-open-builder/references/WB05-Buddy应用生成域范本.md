## WB05-Buddy应用生成域范本

### 范本概述

D5 Buddy 应用生成域全任务范本，覆盖 D5-01/D5-02/D5-03 全部任务的产物样式：应用基础配置 → 首页与市场配置 → 其他配置与预览。Buddy 应用在开放平台网页端配置（非 zip 上传），本范本产出"填写内容清单"供用户逐项粘贴。

### 范本正文

**【D5-01 应用基础配置】模块 1 填写内容清单**：

```markdown

```

### 结构要点标注

1. 本域不走 zip 上传：三个产物均为"配置内容清单"，由用户在开放平台网页端逐模块粘贴
2. 工作模式 2~4 个（各可预绑定 Skill）；场景胶囊 2~5 条且用用户真实口语；引用的专家/技能/连接器必须已上架或同批生成；内置连接器须为支持 OAuth 认证的 MCP
3. icon/背景图设计规格按官方数值转述不得改动（icon 16px×16px 线宽 1.2px；背景图 1000×910px 日夜间 2 套）
4. Client Secret 仅展示一次的提醒必须出现在清单中；每次退出配置前提醒导出配置 JSON
5. 发布流程七节点：创建应用→基础信息→创建审核→分模块配置→预览调试→提交审核→发布上线
6. 配置 OAuth 内置连接器时，授权回调 URL 需伙伴侧实现接收授权码的 HTTPS 端点（服务端自实现，非平台配置项）；应用不使用绑定能力时，模块 4 可开启"跳过首次绑定应用授权"

### 替换清单

{{}} 占位全部替换为用户应用的真实内容；授权回调与可信 Origin 用用户真实域名；模型清单按开放平台模型池实际可选值填写；市场资产引用已上架或同批生成的真实 ID。
