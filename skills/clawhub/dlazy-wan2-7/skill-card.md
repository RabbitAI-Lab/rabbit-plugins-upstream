## Description:

Guides agents in generating videos from text prompts, reference media, or first and last frames using Tongyi Wanxiang 2.7 through dLazy.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to request short videos from text, reference images or videos, and first and last frames through the dLazy service.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Private reference media may be uploaded to dLazy's service.

Mitigation: Only provide media you are comfortable sharing with dLazy.

Risk: The CLI requires an API key and makes network requests.

Mitigation: Confirm you trust the dLazy CLI and service before installing, and use an API key you can rotate or revoke.
