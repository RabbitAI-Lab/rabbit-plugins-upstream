# Final proofread after author decisions

Proofread **the assembled revision**, not the initial suggestions in isolation.

- Run a line-level pass for spelling, articles, punctuation, agreement, idiom, sentence boundaries, referent clarity and terminology. For writers using English as an additional language, explain only material idiom/collocation changes; never erase deliberate voice or international style automatically.
- Run a structural pass for new neighbors created by moves and insertions: information already introduced? evidence near claim? pronouns still point to the same antecedent? example attached to a usable generalization? conclusion still supported by the available source?
- Run an integrity pass: dates, numbers, names, product commands and linked claims agree with source materials. A source quote validates wording, not the external truth. Keep unverified items as requests to confirm rather than invented fixes.
- Separate **required** corrections from **optional** stylistic alternatives. A clean result does not need edits.
- Show exactly what changed in the final draft, preserving every accepted/rejected choice. If full rerun was not performed, say “Revision assembled; independent final proofread not yet completed.”
