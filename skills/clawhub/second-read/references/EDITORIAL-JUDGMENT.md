# Editorial judgment: meaning, sequence, restraint

Load before substantive proposed edits. Internally compare the author's intended statement with the likely first reading *at that exact point* and with the proposed revision. A revision must beat **leave unchanged** on reader benefit **without** adding facts or losing voice.

## Semantic invariants

| Check | Failure to catch | Safe decision |
|---|---|---|
| Scope | some → all; single pilot → every customer | Preserve population, qualifier and comparison class |
| Modality | may → will; possible → confirmed; recommendation → commitment | Retain epistemic/normative force |
| Status/time | proposed trial → approved launch; next month → now | Retain dates, approval and conditions |
| Evidence | vivid illustration → proof of prevalence; correlation → cause | Keep evidence type and uncertainty visible |
| Attribution | company's estimate → established fact; unnamed experts → consensus | Name source; request external verification if needed |
| Agency | user can export → platform exports automatically | Preserve who acts and where |
| Meaningful symbols | metaphor/fictional ambiguity → literal explanation | Preserve the expressive effect |
| Sequence | conclusion requires something introduced later | Add a bridge, move an existing fact or qualify the conclusion |

## Reader state

At each passage, silently ask: What does the reader **know**? What is only **claimed or inferred**? What do they **expect next**? Which antecedents and terms are available now? What emotional first impression is plausible rather than certain? Then judge later passages against those expectations. Use the same reasoning for argument threads and optional inline self-questions.

A generalization without an illustrative instance and an example without any purpose are both useful diagnostic prompts, **not automatic error categories**. A single vivid example can carry sufficient meaning; a technical reference may rightly omit narrative examples.

## Paired judgments

**Edit, meaning is reversed.** The brief says "pilot reliability before fare decision"; opening says "make fares free immediately." Suggest a bounded opening and matching conclusion. If the brief is absent and either position is defensible, ask which thesis is intended before committing to one.

**Leave, image is doing the work.** "A timetable is a promise." A replacement that explains service-level expectations kills a precise metaphor. Preserve.

**Leave, hypothetical already identified.** "Imagine a nurse finishing a shift after midnight." Adding "this is merely hypothetical" weakens it. Intervene only if later language treats this imagined case as a measured frequency.

**Edit, unsupported quantifier.** "Eight of ten pilot users succeeded, so everybody can onboard in seconds." Retain the pilot scope and request timing evidence; do not invent it.

**Leave, legitimate qualification.** "The early results suggest an improvement, although the sample is small." Do not upgrade to definitive success.

**Leave, deliberate literary silence.** "Neither of them touched the key." Resist adding explicit motives without the author's invitation.

**Edit, cross-asset mismatch.** A supplied campaign brief approves a six-week trial, but the current email offers six months. Correct the specific duration, citing the approved brief.

## Source and decision rule

Before surfacing any proposal, show internally: exact quote → demonstrated reader cost → smallest fix → semantic diff → why leaving it alone is worse. If that chain is incomplete, suppress the proposal or mark the ambiguity as a targeted question. Style preferences remain optional; factual contradictions against supplied authoritative records are required.
