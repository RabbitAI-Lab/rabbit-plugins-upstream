## Description:

Guides an agent through multi-scenario stock research and prepares source-attributed Markdown and self-contained HTML reports using the skill's stated data-quality rules.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Investors and research analysts can request company, industry, policy, market, or review analyses and receive reports that distinguish sourced facts from analysis. The skill documentation excludes trade execution and buy, position-size, or stop-loss recommendations.
