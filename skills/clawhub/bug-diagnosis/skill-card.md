## Description: <br>
Diagnose bugs systematically by reproducing failures, isolating scope, ranking and testing hypotheses, and documenting the proven root cause with a fix and regression guard. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

## Use Case: <br>
Developers and engineers use this skill when debugging defects or intermittent failures to structure the diagnostic loop from reliable reproduction through root-cause proof and fix validation. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Debugging guidance may propose code changes or shell commands that affect a repository. <br>
Mitigation: Review proposed changes and commands before applying them, especially in sensitive repositories. <br>
Risk: A diagnosis can be misleading if reproduction, isolation, or hypothesis testing is skipped. <br>
Mitigation: Require a reliable reproduction, narrowed location, tested hypothesis, and regression test before accepting the fix. <br>
