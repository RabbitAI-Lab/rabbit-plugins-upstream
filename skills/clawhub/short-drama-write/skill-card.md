## Description:

Writes and revises shootable Chinese short-drama episodes as Markdown screenplays while preserving the author's existing text where possible.

This skill is ready for commercial/non-commercial use.

## Publisher:

[worldwonderer](https://clawhub.ai/user/worldwonderer)

### License/Terms of Use:

MIT

## Use Case:

Writers and production teams use this skill to draft, revise, or normalize Chinese short-drama episode scripts with playable action, dialogue, and continuity.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Revisions may alter the author's intended story or overwrite unrelated passages.

Mitigation: Limit edits to the requested scope, preserve original wording, and ask before changing plot direction.

Risk: Timing estimates may not reflect actual delivery, pauses, or action pacing.

Mitigation: Treat calculated duration as a reference and check target runtime by reading and performing the script.

Risk: Optional timing and VO-share checks create a local temporary index of screenplay text.

Mitigation: Use the system temporary directory for the index and remove it when no longer needed.
