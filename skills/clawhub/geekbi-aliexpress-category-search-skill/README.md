# 极鲸云 AliExpress 类目研究 Skill

查询 AliExpress 类目树、类目父链和可信类目 ID，并结合类目商品样本研究销量、销售额、价格带、店铺分布和品类机会。

当前不提供类目官方 GMV、搜索量、广告或评论正文。

## 安装 / 更新

```text
安装这个Skill: https://github.com/geekbi/geekbi-aliexpress-category-search-skill
```

## 示例

```text
从 AliExpress 美国站类目树找到厨房小家电细分类目，并分析商品价格带和销量结构。
```

```text
比较两个同级类目的热销商品、新品和店铺集中度。
```
