# AliExpress 类目研究

## 流程

1. 从根类目逐层下钻，确认目标类目 ID、层级和是否叶子类目。
2. 查询类目商品，按销量、销售额、上架时间或价格建立多个样本视角。
3. 计算样本价格带、销量/销售额集中度、店铺数量、头部店铺占比和新品表现。
4. 对比相邻或同级类目时统一站点、币种、筛选和时间窗口。
5. 把供货、跨境准入、履约、退货和合规作为二次验证，不从商品样本直接推断。

## 边界

- `data.total` 最大显示 200，不能称为平台类目全量规模。
- 热销、高增长或高销售额不等于低竞争；还需看店铺分布、头部集中、上新密度和内容供给。
- 当前没有类目官方 GMV、搜索量、流量、广告和评论正文。
- 限售或需资质类目必须在 AliExpress 卖家中心和目标市场最新官方政策中复核。
