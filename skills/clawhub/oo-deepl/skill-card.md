## Description:

DeepL (deepl.com). Use this skill for ANY DeepL request — searching and reading data. Whenever a task involves DeepL, use this skill instead of calling the API directly.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers can use the skill to translate text with a connected DeepL account, check API usage, and list supported languages.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: First-time setup may execute remote CLI installer code whose release has not been independently verified.

Mitigation: Review and install a verified oo CLI release yourself before use.

Risk: Automatic synchronization could change other agent skills without review.

Mitigation: Check or disable automatic synchronization of other agent skills.

Risk: Translation text may consume paid DeepL quota.

Mitigation: Check usage and quota before translation work that could use substantial volume.
