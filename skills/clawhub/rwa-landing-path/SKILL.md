# S8 · RWA 落地流程与路径设计器

## R — 原文 (Reading)

> 经典 RWA 流程包括 10 个核心环节（A 项目/资产识别与体检 → J 市值管理与投资者关系）；中国真实世界通证实践多以"境内资产上链、境外价值释放"为核心：境内阶段对应经典流程 A-G（产业资产数字化与合规流通），境外阶段对应 H-J（全球化流动与市值管理）。
>
> — 价值互联网产业应用蓝皮书编写组，第四章 二（一）RWA 经典业务流程 / 第四章 二（二）境内—境外双层实践路径

## I — 方法论骨架 (Interpretation)

本技能把"把一个真实资产做成 RWA"拆成一条可排程的作业链路，并在中国制造了一个关键的"合规断点"。

- **十环节（A–J）是骨架**：从资产识别体检（A）、方案与 SPV 设计（B、D）、共建社区与经济模型（C）、链改技术集成（E）、登记确权（F）、一级发行（G），到境外的权益兑现（H）、二级发行做市（I）、市值管理（J）。它把"上链"从一句口号变成了一份带负责人与合规节点的工程排期表。
- **境内外双层是边界**：常识以为境内外同做、或"直接去海外发币"。蓝皮书的独特结构是——**境内只做价值生成的前半段（A–G：标识、存证、一级发行），价值流通的后半段（H–J：权益兑现、二级、市值）留到境外合规区**。这一步断裂，正是中国式 RWA 不踩红线的命门。
- **四阶递进定节奏**：要素通证化→资产通证化（价值生成）→代币化→资本化（价值流通）。境内止于前两阶，境外才走后两阶，避免"上链即融资一步到位"的错觉。
- **六构件评估定资格**：开工前先用"优质资产/共建社区/通证经济/技术架构/数据与算法/信用与审计"打勾，缺项即风险点——它回答"这个资产到底值不值得、能不能做 RWA"。

一句话：先评估资格（六构件），再按十环节排程，同时把境内止步点（G 之后）和境外衔接点（H 之前）钉死。

## A1 — 书中的应用 (Past Application)

### 案例 1: 朗新集团充电桩收益权 RWA（香港沙盒）
- **问题**：境内新能源充电桩存量大、流动性不足，传统融资依赖主体信用、门槛高，且境内严禁代币化融资。
- **方法论的使用**：按十环节排程，境内（A–G）用蚂蚁链完成资产标识、IoT 数据存证与一级登记；把价值流通（H–J）整体移到香港监管沙盒，发行锚定"收益权而非所有权"的证券型代币。
- **结论**：以"两链一桥"兼顾境内合规与跨境融资，境内止于一级发行、境外做二级与市值，形成清晰断点。
- **结果**：2024 年率先于香港监管沙盒发行，为"境内资产境外合规发行"积累可复制范式。

### 案例 2: 协鑫能科光伏电站收益权 RWA（香港沙盒）
- **问题**：光伏电站投资规模大、回收周期长，资产流动性与融资成本制约规模化。
- **方法论的使用**：同样沿 A–G（境内）/ H–J（境外）双层结构，锚定光伏电站收益权，蚂蚁链 + IoT + 隐私计算搭"两链一桥"，跨境发行。
- **结论**：与朗新并列"资产数字化与资产支持证券代币融合"路径典型，绿色低碳资产上链标杆。
- **结果**：与朗新共同验证新能源资产境外合规代币化可行性。

### 案例 3: 马陆葡萄 RDA（境内实数融合早期标杆）
- **问题**：农产品流通溯源难、信息不对称，优质难优价，品牌信任度低。
- **方法论的使用**：仅走十环节前段（产品资产化 / A–G 的数化、确权、合规流通），把全流程数据上链形成不可篡改资产凭证，不上二级、不融资。
- **结论**：作为"实物商品数字消费"路径典型，证明境内可只做价值生成、不做价值流通。
- **结果**：成为农产品溯源与品牌溢价模式的早期探索样本，与红糖链品、长白数参形成农产品数字资产矩阵。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 实操团队手里有一项实体资产（充电桩、光伏、农产品、数据资产），被要求"出一份 RWA 落地方案 / 排期表"，但不知道从哪一步下手。
2. 项目方想融资，但分不清"境内能做到哪一步、必须停在哪一步、剩下怎么通过境外合规区完成"。
3. 地方产业 / 地方平台想做"数字资产 / 数据资产"上链，需要判断是做 RDA（非金融）还是 RWA（金融），以及合规边界在哪。
4. 企业已有境内联盟链存证，想进一步"出海发币 / 跨境融资"，需要补上境外衔接点（H–J）与备案前置。
5. 投资人 / 审计方拿到一份 RWA 方案，想快速核查它是否漏了境内止步点、或越界做了境内禁做的环节。

### 语言信号 (用户的话里出现这些就应激活)

- "我们想做一个 RWA / 资产上链融资，第一步该怎么走？"
- "境内资产怎么合规出海？香港沙盒怎么接？"
- "这个充电桩 / 光伏 / 农产品能不能代币化？流程是什么？"
- "境内做到哪一步必须停，境外从哪一步开始？"
- "帮我排一份从资产识别到发行的十环节落地路线图"

### 与相邻 skill 的区分

- 与 **S2 · 合规边界红线检查** 的区别：S2 只判"某说法/某动作是否触犯境内金融红线"（是/否），本技能是在红线已知的前提下，画出端到端落地排期与境内外断裂点；需要先过 S2 再进本技能。
- 与 **S3 · 三类主导模式判别器** 的区别：S3 只回答"这个项目属于原生型 / 产业变革型 / 链改-资产支持型哪一种、组织形态怎么选"，本技能在前者的模式结论之上，给出具体作业步骤与跨境衔接。
- 与 **S10 · 监管范式与香港沙盒路径** 的区别：S10 聚焦"全球三范式 + 香港 Ensemble 沙盒 / SPV / QFLP 通道"的合规桥接细节；本技能用十环节把 S10 的"境外后半段（H–J）"作为衔接点嵌回整体路线图，不深入沙盒申报细则。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **六构件评估资产可代币化资格**
   - 动作：用「优质资产（现金流自偿）/ 共建社区（正和博弈）/ 通证经济（计量行为价值）/ 技术架构（可信）/ 数据与算法（最小可信闭环）/ 信用与审计（差异化管控）」六构件逐条打勾+标风险。
   - 完成标准：输出一张六构件清单，每一项标注"齐备 / 部分 / 缺失"及缺失项的风险说明；自偿性弱的资产须显式标记"不宜做链改-资产支持型"。
   - 判停条件：若"优质资产"或"信用与审计"任一为缺失且无法补，则跳到步骤结论并建议改走 RDA / 非金融数字化路径（转 S2 复核），不进入十环节设计。

2. **按十环节（A–J）逐步设计落地排期**
   - 动作：从 A 资产识别体检 → B 方案与 SPV → C 社区与经济模型 → D 运营/SPV 架构 → E 链改 → F 登记确权 → G 一级发行，逐环节填负责人、合规节点、链上/链下动作；H–J 先占位待境外阶段。
   - 完成标准：产出一张 A–J 排期表，每个环节有"做什么 + 谁负责 + 合规依据"；四阶递进节奏清晰（前两阶价值生成、后两阶价值流通）。

3. **标注境内止步点与境外衔接点**
   - 动作：在排期表上钉死——境内止于 G（一级发行），H–J 整体移至境外合规区；标出境外衔接需的前置动作（证监会备案、外汇与数据跨境申报、香港 SPV/QFLP 通道）。
   - 完成标准：路线图明确写出"境内止步点 = G 之后"，且 H–J 标注对应的境外法域（港/新沙盒）与备案前置；给出"未备案不得跨境发行"的红线提醒。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 仅想判断"某句话/某个设计是否踩境内金融红线"——这是 S2 的职责，本技能假定红线已确认。
- 仅想给项目定性"属于哪类主导模式"——这是 S3 的职责，模式未定前本技能的十环节无法精准排程。
- 仅想规划香港沙盒 / SPV / QFLP 申报细节——这是 S10 的职责，本技能只在路线图中把 H–J 作为衔接点。
- 资产完全无稳定现金流、权属不清、且无法补六构件——此时不应强行做 RWA，应先做 RDA / 溯源（非金融）。

### 作者在书中警告的失败模式

- **伪 RWA 资金盘（ce02）**：把高风险的链下非标信用资产包装上链，借 DeFi 杠杆把缓慢信用风险瞬时引爆（如 2025.11 美国 SME 应收账款 RWA 爆雷、损失超 30 亿美元）。本技能步骤 1 的六构件评估正是为拦截此类"无真实产业场景、仅靠升值叙事"的项目。
- **慢资产快金融错配（ce06）**：真实资产回款慢（数年）却用链上 7×24 快金融逻辑包装、承诺高流动性，监管真空期套利、事后被追责。排期表必须显式标注资产回款周期与流动性承诺的匹配性。
- **无备案跨境发行（ce13）**：标榜"香港/海外合规"却未履境内证监会备案即把境内资产出境发币，属明确违规。步骤 3 必须把"备案前置"列为 H–J 衔接的硬门槛。

### 作者的盲点 / 时代局限

- 编写组含 RWA 产业链服务商（道衍数科等），对失败案例与落地难度的披露可能选择性弱化；六构件"齐备"不应被当成"必然成功"——成败关键在商业可持续而非是否上链（见 f19）。
- 成稿于 2025 年，香港沙盒与稳定币/代币化全球规则仍在快速演化，部分"前沿通道"可能已被新规覆盖，步骤 3 的境外衔接点需以最新监管口径复核。

### 容易混淆的邻近方法论

- 把"通证化（广义/产业向）"误当"代币化（狭义/金融向）"——前者境内可做（RDA/溯源），后者境内严禁（ce01/ce16）。本技能步骤 1 已用六构件区分，但仍须与 S1 概念辨析器交叉确认。


### 合规红线与使用须知（普通用户必读）

本技能提炼自《价值互联网产业应用蓝皮书（2025）》（蓝皮书编写组，主编：梁超杰）第三篇·第五章「合规边界」，仅供风险识别与科普参考，**不构成任何投资建议、法律意见或投资邀约**。

- 中国境内开展价值互联网与通证经济产业应用，**不得涉及通证代币化等加密金融行为**，应聚焦"非金融"的数字化赋能（溯源、贡献计量、RDA 真实数据资产等）。
- 包括稳定币在内的虚拟货币，**在中国境内发行与交易属于非法金融活动**（央行等十部门 2021 年《关于进一步防范和处置虚拟货币交易炒作风险的通知》）。境外交易所、项目向中国境内居民提供服务同样属非法。
- **连带责任无死角**：不仅直接参与违法，为境外违规项目提供账户、资金划转、技术支持也依法追责——"只是帮忙做技术"不能免责。
- 任何以"Web3/区块链"为名、要求充值、拉人头返利、承诺升值预期的，极可能是资金盘，**请勿参与、勿投资、勿转发**。

> 引用原文："不能涉及通证代币化等加密金融行为，而应聚焦探索'非金融'的数字化赋能产业提效方向。""包括稳定币在内的虚拟货币无法满足 KYC、AML 等要求，在中国境内发行与交易虚拟货币属于非法金融活动。" —— 第三编·第五章（合规边界）／ p02、ce03
