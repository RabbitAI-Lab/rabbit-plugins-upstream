## Description: <br>
每日收集全球股市资讯（A股/港股/美股/欧股/亚太），覆盖各行业板块，国内国外各至少5条共至少10条，生成标题为「每日动荡+日期」的Markdown报告。 <br>

## Use Case: <br>
External users and market researchers use this skill to produce a concise Simplified Chinese daily Markdown report on global equity-market news, key market drivers, sector moves, and near-term risks. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Market news and prices are time-sensitive, and stale search results can make the daily report misleading. <br>
Mitigation: Use date-specific searches, verify source dates and years, and review the report before relying on it for financial decisions. <br>
Risk: The skill may create or overwrite a dated Markdown report in the user's Documents folder. <br>
Mitigation: Confirm the output path before use and adjust the save location if persistent local file creation is not desired. <br>
