# 搜索维度指南

执行每日动荡报告时，使用 WebSearch 搜索以下方向。**每个搜索词务必带上具体日期**，确保时效性。目标：国内国外各至少5条，总计至少10条有效资讯。

## 国内方面（至少5条）

- A股主要指数（上证、深证、创业板）前一交易日收盘数据 + 当天开盘/盘中走势
- 政策面重大消息（证监会、央行、国务院等在前一交易日收盘后或当天开盘前发布的内容）
- 各行业板块涨跌分化：科技、新能源、医药、消费、金融、地产、半导体、AI、汽车、油气等
- 北向资金流向、主力资金动向（前一交易日数据 + 当天预估）
- 港股/恒生指数前一交易日表现 + 当天走势

## 国际方面（至少5条）

- 美股（道指、纳指、标普500）前一交易日收盘 + 当天盘前期货
- 美联储政策表态、美国经济数据发布（前一交易日及当天）
- 亚太市场（日经、韩国KOSPI等）当天开盘情况
- 欧洲市场（德指、法指、英国富时）前一交易日
- 国际大宗商品（原油、黄金、汇率）变动
- 地缘政治事件及贸易动态

## 特别注意搜索

- 休息期间发布的重大消息（周末、假期后的首个交易日，需搜索前两日）
- 前一交易日盘后公告、业绩预告、重大资产重组等
- 当天开盘前的重大新闻（公司公告、行业政策、外部事件）

## 质量要求

- 🎯 每条资讯必须包含：**数据/事件 + 驱动原因简析**（"因为什么消息导致了什么变动"）
- 使用真实的搜索数据，不要编造新闻
- 报告语言使用简体中文
- 如果当日是周末（周六/周日），只生成简版周报（汇总本周重要动态 + 下周关注焦点）
