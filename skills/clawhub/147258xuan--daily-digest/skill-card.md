## Known Risks and Mitigations:

Risk: The digest can include previews of workspace memory notes and details from evolution state, which may contain sensitive information.

Mitigation: Run it only where those workspace files are appropriate to include, and review the generated digest before sharing it.

Risk: The security assessment reports partial scan coverage, an undeclared tool scope, and content that was not fully inspected.

Mitigation: Review the full release contents and intended access before installing or running the skill.
