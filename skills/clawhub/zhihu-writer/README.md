```

```

## 核心功能

1. **🔥 热点发现** — 自动抓取知乎热榜（tophub.today）
2. **🎯 智能选题** — 根据你的专业领域推荐 ROI 最高的话题
3. **✍️ 爆款写作** — 内置知乎高赞公式，最大化互动转化
4. **📈 发布优化** — 时间建议、标签推荐、冷启动策略
