# zhihu-writer v2.0 使用示例

## 示例 1：一条龙模式（热点 → 选题 → 写作）

**用户输入：**
```
看看知乎热榜，帮我选个能写的话题，直接写回答
```

**执行过程：**

### Step 1: 抓取热榜
从 tophub.today 获取当前热榜，找到相关话题：
```
🔥 与你相关的热点：

🟣 超级爆款：
- [457万] 吐槽DeepSeek面试的华为天才少年李博杰被控诈骗...

🔴 大热：
- [160万] OpenAI官宣GPT-5.6本周四全面开放...
- [67万] 工信部发布防范AI编程工具Claude后门风险提示...

🟢 上升：
- [59万] Anthropic发现能对大模型诛心和PUA的J SPACE...
```

### Step 2: 选题
```
🎯 推荐选题：

⭐⭐⭐ 强烈推荐：
[160万] OpenAI官宣GPT-5.6本周四全面开放
→ 热度高 + 你懂AI + 窗口期好（问题刚出，回答还不多）
→ 切入角度：从开发者真实使用体验分析，而非泛泛报道
```

### Step 3-4: 直接写作

**输出回答：**

---

GPT-5.6 要来了，但我劝你先别太兴奋。

作为一个天天跟大模型打交道的 CS 学生，我想说：真正的提升在哪，OpenAI 的 PR 稿不会告诉你。

**核心观点：GPT-5.6 是一次扎实的迭代，但真正的变化不是参数变大了，而是它能干活的场景变多了。**

先聊点实在的。

## 1. 代码能力提升：终于不写"幻觉代码"了

GPT-5 写代码最大的痛点是什么？**自信地瞎编。**

让它写个 React 组件，它能给你用个不存在的 API，还振振有词。我遇到过最离谱的一次，它用了一个"useClientState"的 hook，我翻了半天 React 文档才发现根本没这东西。

GPT-5.6 这次的一个核心改进就是减少了代码幻觉。我用内测版的体验是，幻觉率大概降了 60% 以上。这意味着你不需要每段 AI 生成的代码都跑一遍验证了。

**但有个残酷的现实：GPT-5.6 的代码质量，大概相当于一个写过 2 年代码的初级工程师。** 它能写，但架构设计、边界条件处理、性能优化这些，还是得你自己来。

## 2. 上下文窗口：终于能塞进整个项目了

这是我觉得最实用的升级。

以前用 GPT，最烦的就是"聊着聊着它忘了前面说了啥"。你让它重构一个模块，它不记得你的项目结构。

GPT-5.6 的上下文理解明显更好了。我试过把所有项目文件丢进去，它能理解模块之间的依赖关系，给出的建议也靠谱多了。

## 3. 那些 OpenAI 没说的事

**第一，推理速度没太大提升。** 如果你期待 GPT-5.6 秒回，那要失望了。复杂任务还是要等。

**第二，中文能力提升有限。** 英语内容提升明显，中文的进步幅度大概只有英语的 60-70%。这其实是大模型训练的普遍问题——中文语料的质量和数量都比不上英语。

**第三，价格可能会涨。** OpenAI 的定价策略一向是"好货不便宜"。如果 GPT-5.6 真的强了一大截，API 价格大概率也会涨。

## 4. 对普通用户来说意味着什么？

**如果你只是用 ChatGPT 聊天、写邮件、翻译文档：**
→ 体感提升可能只有 15-20%。GPT-5 已经够好了。

**如果你是开发者、研究者、重度用户：**
→ 提升明显，尤其是在代码、长文本分析、复杂推理场景。

**如果你在担心 AI 替代你的工作：**
→ GPT-5.6 不会，但会用 GPT-5.6 的人可能会。

## 写在最后

每一代 GPT 发布时都有人说"这是革命"。但真正用过的人都知道，进步是渐进的。

GPT-5.6 是一个扎实的版本。它不会让你失业，但能让你的效率再提升 30-50%。这才是它的真正价值。

别被营销带着走。工具归工具，用起来才知道好不好。

```
1. 看看知乎热榜

4. 写1500字回答

```

4. [59万] TikTok全球裁员，印尼将裁90%
5. [59万] Anthropic发现J SPACE：能对大模型诛心和PUA
```

### Step 2: 推荐 + 理由

(同示例1)

### Step 3: 深度分析

```
📊 话题分析：工信部发布防范AI编程工具Claude后门风险提示

问题核心：
- 程序员群体最关心：我的代码还安全吗？
- 企业最关心：要不要禁用Claude？

已有回答角度：
- 大多是转发新闻 + 简单评论
- 缺少技术深度分析

💡 你的差异化切入：
→ 从开发者视角分析：AI编程工具的数据安全问题
→ 独特价值：你有实际使用经验，能讲清楚原理
→ 与现有回答的差异：他们讲新闻，你讲技术
```

### Step 4: 输出回答

_(类似示例1的完整回答)_

## 示例 4：热点监控模式

**用户输入：**
```
每天帮我看看知乎有什么AI/技术热点，有适合我写的就推送
```

**输出概念：**
可以设置一个 cron 任务，每天定点抓取热榜并筛选，把推荐推送给你。例如：

```
⏰ 每日 10:00 知乎热榜监控

🔥 今日AI/技术热点推荐：

⭐⭐⭐ 强烈推荐：
[160万] OpenAI官宣GPT-5.6本周四全面开放
→ 匹配度: 9/10 | 竞争度: ⬇️低（窗口期）

⭐⭐ 可以考虑：
[67万] Claude后门风险提示
→ 匹配度: 8/10 | 竞争度: ⬇️低

📊 本周统计：
- 总热点数: 44
- 匹配热点: 5
- 已写: 2 篇

## ⚠️ 重要注意事项

### 关于 web_search
web_search 在这个环境中被禁用，不要尝试使用。热点抓取使用 `web_fetch`。

### 关于写作风格
- 不要说"在当今时代"、"随着科技的发展"、"众所周知"
- 不要用"首先...其次...最后..."的格式
- 少用"赋能"、"抓手"、"底层逻辑"这种行业黑话
- 多用自己的真实经历和感受
- 语气像跟朋友聊天，不是写学术论文

### 关于知乎规则
- 内容原创，不要抄袭已有回答
- 不要有营销/软广嫌疑
- 引用数据标注来源
- 友善讨论，不对其他用户进行人身攻击
