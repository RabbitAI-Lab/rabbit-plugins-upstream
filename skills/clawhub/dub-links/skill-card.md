## Known Risks and Mitigations:

Risk: The connected Dub account may allow access to customer data, destructive changes, partner restrictions, bounty rewards, or commission changes that affect payout totals.

Mitigation: Use the narrowest available account permissions and explicitly approve consequential changes.

Risk: The bundled shell example has quoting that may need correction before it runs.

Mitigation: Correct the shell quoting before running the example.

Risk: Live API permissions and remote MCP behavior were not verified.

Mitigation: Review the connected account's available permissions and confirm the intended action before relying on live behavior.
