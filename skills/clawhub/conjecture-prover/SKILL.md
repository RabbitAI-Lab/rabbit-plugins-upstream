# 数学猜想证明技能 (Conjecture Prover)

## 定位

本技能是一个**领域负载物技能**，提供数学猜想的系统化证明能力。通过标准化管线将任意猜想转化为可验证的证明或精确归约为开放问题。

**核心理念变革**：

1. **证明 ≠ 闭解**：将猜想精确归约为单一可验证的不等式，其价值不亚于完全证明。
2. **几何直觉优先**：非数学家的几何直觉（三平面、升维、碗）可以引导出精确的数学公式，比传统分析路线更高效。
3. **数值验证是校准点**：数值证据不是证明本身，但是证明方向正确性的关键校准锚点。
4. **诚实标注 > 虚假声称**：明确区分已证、已验证、待证，将开放问题清晰地留给后续工作。

## 核心能力

### 猜想拆解能力

进行知识点原子化拆解和依赖关系梳理。将任意数学猜想拆解为原子概念和核心瓶颈：

- **原子化拆解**：分解为不可再分的最小概念单元，标注依赖关系链
- **断层识别**：对照 `references/conjecture-prover-catalog.md` D1 域任务，定位核心卡点
- **等价转化**：将原问题转化为更易攻击的等价命题（如 RH → |ξ|² 单调性）

### 证明生成能力

运用全部创新方法（38 种）：

- **M7-08 约束驱动**：归约为单一不等式（近零点项绝对值 < 远零点项总和）——核心方法
- **M9-02 维度矩阵**：三平面框架（素数平面 × 零点平面 × K-hat 曲面）——几何直觉驱动
- **M6-05 基元重组**：K-hat 桥接 + |ξ|² 单调性 + 导数公式组合
- **M8-03 方法迁移**：投票/对决比喻迁移为符号分析

详见 `references/conjecture-prover-requirements.md` 创新方法完整映射。

### 严格化与验证能力

- **数值验证**：网格扫描确认单调性/凸性在全部测试点成立（1225/1225）
- **公式匹配验证**：导数求和公式与数值差分结果对比，验证推导正确性
- **安全性标注**：已证 vs 已验证 vs 待证 三层明确区分

### 论文产出能力

产出完整的学术论文集合：

- 正式论文（RH_PAPER.md）：学术发表格式
- 精简证明（RH_PROOF.md）：核心论证
- 通俗版（RH_POPULAR.md）：零基础可读
- 论证骨架（RH_ARGUMENT_SKELETON.md）：章→节→论点结构
- 推导过程（RH_PROOF_PROCESS.md）
- 验证脚本（scripts/rh_proof_verify.py）：可运行的数值证据
- 五维复核（RH_AUTO_REVIEW.md）：跨文件一致性检查

## 使用规则

### 执行流程

1. **猜想接收**：接收用户提供的猜想陈述，形式化重述
2. **类型判定**：识别猜想所属领域（解析数论/代数/组合/几何）
3. **拆解攻击**：原子化拆解 → 断层识别 → 38 种创新方法生成攻击向量
4. **路线选择**：从攻击向量中筛选最可行路线，结合数值验证校准方向
5. **归约或证明**：将猜想归约为更简单的等价问题，或在可行时完成证明
6. **诚实交付**：明确标注已完成和待完成部分，产出完整论文集合

### 核心纪律

1. **永远不声称已证未证之事**：数值证据 ≠ 解析证明，诚实标注每一步的状态
2. **几何直觉引导数学推导**：先找到直觉模型（碗、投票、桥），再转化为精确公式
3. **先验证再声称**：任何声称必须有数值或解析支撑
4. **远零点自动对 ≠ 全自动**：类分明确标注「自动」与「待控制」
5. **开放问题就是开放问题**：不粉饰、不隐瞒、不假装已解决
6. **安全边际（gap）必须显式计算**
7. **引用真实存在的文献**
8. **样本法模仿时不直接复制内容**，仅借鉴结构和风格

| D1 拆解 | 5 | 猜想陈述解析、原子概念拆解、断层识别、工具评估、拆解验证 |
| D2 证明 | 9 | 创新方法矩阵、引理设计、管线编排、等价转化、桥接构造、死路排除、归约、数值校准、证明验证 |
| D3 验证 | 5 | 解析界推导、数值扫描、公式匹配验证、安全边际计算、严格性确认 |

## 事实纪律

1. 所有引理必须可独立验证，不得跳过逻辑步骤
2. 数值验证必须明确标注为「数值验证」而非「证明」
3. 已证、已验证、待证 三层严格区分
4. 不确定的部分标注为「条件性结论」或「开放问题」
5. 安全边际（gap）必须显式计算且 > 0
6. 引用真实存在的文献
7. 样本法模仿时不直接复制内容，仅借鉴结构和风格
几何直觉可引导精确公式，数值校准防止走错方向
