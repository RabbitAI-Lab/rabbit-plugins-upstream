## 证明路线概要

```
三平面框架（素数、零点、K-hat 曲面）
  ↓
|ξ(σ+iγ)|² 作为 σ 的函数 — 碗
  ↓
导数求和公式（从 Hadamard 乘积导出）
  ↓
项分类：远零点自动投对票 ✓  近零点可能投反票 ?
  ↓
归约：|近零点反票| < |远零点正票|
  ↓
若成立 → 碗底唯一在 σ=0.5 → 零点全在正中央 → RH
```
