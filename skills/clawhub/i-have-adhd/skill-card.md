## Description:

Shapes agent responses for readers with ADHD using action-first instructions, bounded steps, clear progress, and fewer tangents.

This skill is ready for commercial/non-commercial use.

## Publisher:

[tenequm](https://clawhub.ai/user/tenequm)

### License/Terms of Use:

Apache 2.0

## Use Case:

People who prefer ADHD-friendly communication use this skill to receive actionable next steps, numbered tasks, and visible progress throughout a conversation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: ADHD-focused formatting continues for the rest of the session even when the topic changes.

Mitigation: Review this preference for each task; say 'stop adhd mode' or 'normal mode' to return to the default style.
