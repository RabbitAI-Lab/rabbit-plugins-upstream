## Description:

Reviews submitted code snippets and diffs for correctness, security, performance, and maintainability, then suggests fixes and drafts review comments.

This skill is ready for commercial/non-commercial use.

## Publisher:

[gechengling](https://clawhub.ai/user/gechengling)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and reviewers use this skill to assess supplied code snippets or PR diffs, prioritize findings, and draft actionable fixes, quality scores, and review comments for human review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Submitted code may contain secrets or sensitive repository content.

Mitigation: Share only necessary snippets or diffs and redact credentials and sensitive data before review.

Risk: Suggested fixes and security findings may be incomplete or incorrect.

Mitigation: Review comments before posting, test suggested changes, and independently verify security or compliance conclusions.
