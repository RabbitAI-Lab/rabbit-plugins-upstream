## Description:

Helps brand, content, short-drama, ecommerce, marketing, and AI search operations teams structure Doubao AI search inclusion and citation plans, evidence fields, production blueprints, and AI-HIVE image or video generation tasks.

This skill is ready for commercial/non-commercial use.

## Use Case:

External creators, brands, ecommerce teams, short-drama studios, and AI search operations teams use this skill to turn Doubao AI search inclusion and citation goals into structured answers, source cards, production briefs, storyboards, and generation commands. Developers and operators can also run the included scripts to create JSON blueprints, upload media, submit AI-HIVE image/video jobs, poll task IDs, and download generated outputs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: AI-HIVE API keys grant access to credential-backed planning and media generation.

Mitigation: Keep the API key private, prefer environment variables, and review ~/.ai-hive/config.json before use.

Risk: Local media uploads and generation prompts may submit sensitive, personal, or unlicensed content to AI-HIVE.

Mitigation: Confirm before uploading local media or submitting generation jobs, and verify rights for likenesses, brands, music, scripts, images, and videos.

Risk: Image and video generation can create costs on the connected AI-HIVE account.

Mitigation: Review the current model, quantity, routing mode, and pricing snapshot before submitting or repeating jobs.

Risk: AI search inclusion, ranking, and citation behavior is not guaranteed or stable.

Mitigation: Use verifiable source fields, record test dates and model names, and retest periodically instead of treating a single result as a durable ranking.
