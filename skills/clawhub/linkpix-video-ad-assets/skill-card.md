根据商品信息快速生成广告视频素材，适用于信息流广告、品牌推广及社交媒体营销，支持多条量产。

## Use Case:

External marketers, commerce operators, and agent users use this skill to generate and manage batches of product video ad assets for feed ads, brand promotion, and social media campaigns through LinkPix/qhkit.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can install and run unpinned third-party qhkit tooling and may make lasting local environment changes.

Mitigation: Review before installing; use this only if the @iqinghu/qhkit package and LinkPix service are trusted, and prefer a pinned qhkit version with a temporary tool path where possible.

Risk: The skill requires a qhkit API token and may upload product media to the LinkPix/qhkit service.

Mitigation: Use only when sharing the token and product media with the service is acceptable; avoid exposing credentials in chat, logs, or reusable command history.
