# Lite autonomy and gates

Continue automatically through diagnosis, safe initialization, bounded scanning, derived Markdown generation, validation, offline HTML generation, and ephemeral loopback verification.

Pause for the user when the result requests a source choice, access to a new directory, software installation, resolution of unknown output files, source modification, login, upload, payment, submission, publication, or any external data transfer.

Lite has no watch or background command. A successful foreground run proves only that the current static dashboard was built and verified.
