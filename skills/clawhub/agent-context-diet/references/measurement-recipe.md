# Рецепт замера: как получить цифры, не меняя поведение системы

Замер должен быть **read-only по отношению к запросу**: он считает и пишет журнал, но ничего
не подменяет и не режет. Тогда его можно включить на живом трафике без риска.

## Что считать

| Метрика | Что означает | Зачем |
|---|---|---|
| `total` | символов во всех текстовых блоках запроса | размер запроса (÷3,5–4 = токены для русского) |
| `dup_in_req` | символов в блоках, которые повторились ВНУТРИ этого же запроса | прямой кандидат на ссылку/дедуп |
| `repeat_cross` | символов в блоках, которые уже приходили в прошлых запросах | доля пересылаемой истории |
| `big` | блоков ≥ порога (например 4 000 симв.) | сколько вообще есть кандидатов на сжатие |
| `roles` | то же по ролям (system / user / assistant / tool) | где именно лежит объём |
| `cache_hit` | входных токенов, взятых из кэша провайдера | платим ли мы полную цену за историю |

Важно: **не пишите в журнал текст и превью.** Только размеры, роли и короткие хэши —
иначе в файл утекут секреты из трафика.

## Куда врезаться

* **если есть свой прокси перед моделью** — в точку, где формируется тело запроса к апстриму
  (до сжатия, чтобы видеть исходный объём), и в точку, где приходит ответ (для `usage`);
* **если прокси нет** — оберните вызов модели в свою функцию: тело запроса у вас уже есть;
* **если и этого нет** — статический минимум: `wc -c` по всем SKILL.md и число загрузок
  скилла за сессию из журнала инструментов. Этого достаточно, чтобы найти монолиты.

## Код (вставляется в своё место, ничего не меняет)

```python
import hashlib, json, time
from pathlib import Path

_SEEN: dict[str, int] = {}       # хэш блока → длина, блоки из прошлых запросов
PROBE = Path("dedup_probe.jsonl")

def _texts(body: dict):
    for m in body.get("messages") or []:
        if not isinstance(m, dict):
            continue
        role, c = str(m.get("role") or ""), m.get("content")
        if isinstance(c, str):
            yield role, c
        elif isinstance(c, list):
            for part in c:
                if isinstance(part, dict) and isinstance(part.get("text"), str):
                    yield role, part["text"]

def probe(body: dict, min_chars: int = 4000) -> None:
    st = {"n": 0, "total": 0, "dup_in_req": 0, "repeat_cross": 0, "big": 0, "roles": {}}
    seen_here: dict[str, int] = {}
    for role, txt in _texts(body):
        n = len(txt)
        st["n"] += 1; st["total"] += n; st["big"] += n >= min_chars
        r = st["roles"].setdefault(role, [0, 0, 0]); r[0] += n
        h = hashlib.blake2b(txt.encode("utf-8", "replace"), digest_size=8).hexdigest()
        if h in seen_here:
            st["dup_in_req"] += n; r[1] += n
        elif h in _SEEN:
            st["repeat_cross"] += n; r[2] += n
        else:
            seen_here[h] = n
            _SEEN.setdefault(h, n)
    with PROBE.open("a", encoding="utf-8") as f:
        f.write(json.dumps(st, ensure_ascii=False) + "\n")
```

Кэш провайдера (если у апстрима это есть в `usage`):

```python
u = (resp or {}).get("usage") or {}
hit = int(u.get("prompt_cache_hit_tokens")
          or (u.get("prompt_tokens_details") or {}).get("cached_tokens") or 0)
# записать: prompt_tokens, completion_tokens, hit, prompt_tokens - hit
```

## Как читать результат

* `dup_in_req` ≈ 0 → дедуп внутри запроса бесполезен, рычаг только в размере дампа.
  (Именно так вышло у нас: 0,00 % на 1,86 млн символов.)
* `repeat_cross` большой (у нас 75 %) → история пересылается целиком; это не дедуп, а
  поле кэша префикса. Полезно проверить, что ваш компрессор **детерминирован**:
  один и тот же вход дважды → одинаковый выход (иначе кэш промахивается и вы платите полную цену).
* `roles[].tool` большой (у нас 87 %) → смотреть надо на инструменты: что именно они отдают
  в контекст. У нас это оказались дампы скиллов.

## Проверка «кэш не сломан» (2 минуты)

1. Возьмите большой блок и соберите запрос дважды с одинаковым префиксом.
2. Если апстрим отдаёт `prompt_cache_hit_tokens` — во втором запросе доля попаданий должна быть высокой.
3. Отдельно проверьте детерминизм своего сжатия: сжать один текст дважды и сравнить хэши выхода.
