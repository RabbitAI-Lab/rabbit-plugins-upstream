# 06 违规罚款与泄露通报

> 用途：回答「罚款多少」「72 小时通报怎么做」。
> 核对基准日：2026-08-27

## 1. 两档罚款（第 83 条，工具 `penalty` 命令）

| 档位 | 上限 | 典型违规 |
|---|---|---|
| **高档次** | 2000 万欧元 或 全球年营业额 4%（取高者） | 违反合法基础、数据主体权利、跨境传输、儿童同意 |
| **低档次** | 1000 万欧元 或 2%（取高者） | 记录义务、安全措施、DPO、认证 |

**罚款计算（EDPB 指引）**：按违规严重性、故意/过失、缓解措施、历史记录等加权。

## 2. 数据泄露通报义务

| 对象 | 时限 | 内容 |
|---|---|---|
| **监管机构（SA）** | **72 小时**内（有理由可延，须说明） | 泄露性质、范围、影响、措施 |
| **数据主体** | 高风险时"无不当延误" | 泄露影响与自我保护建议 |

**记录义务**：所有泄露（含无需通报的）须记录在案（事实/影响/措施）。

## 3. 泄露响应流程

```
发现泄露 → 评估（性质/范围/风险）→ 72 小时通报监管机构
   → 高风险通知数据主体 → 处置（止损/补救）→ 记录归档 → 复盘
```

## 4. 典型罚款案例参考（尺度）

- 数据泄露 + 措施不足：数百万欧元级；
- 非法跨境传输：千万欧元级；
- 非法处理（无合法基础）：数亿欧元级（巨型平台）。

## 5. 常见坑

1. **超 72 小时**：硬时限，超时本身违规；
2. **不评估风险**：漏报高风险泄露（该通知没通知）；
3. **低风险也大动作**：所有泄露通知数据主体反而制造恐慌（按风险评估）；
4. **无记录**：未记录的低风险泄露 = 审计违规。
