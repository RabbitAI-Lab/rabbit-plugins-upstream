# 05 跨境传输机制

> 用途：回答「数据传到欧盟外用什么机制」「SCC 怎么签」「例外情形」。
> 核对基准日：2026-08-27

## 1. 传输机制总览（工具 `transfer` 命令）

| 机制 | 适用 | 说明 |
|---|---|---|
| **充分性认定** | 目标国有充分保护水平 | 无需额外措施（日本、英国、韩国、加拿大等部分国家在列；**中国不在列**） |
| **SCC（标准合同条款）** | 无充分性认定 | 最常用；控制者-处理者/控制者-控制者模板 |
| **BCR（约束性公司规则）** | 跨国集团内部 | 须监管机构批准，长期方案 |
| **行为准则/认证** | 特定场景 | 配套 SCC 使用 |
| **例外情形** | 特定少数场景 | 明确同意、合同必要、法律主张等 |

## 2. SCC 实操要点

- 使用欧盟委员会最新 SCC 模板（2021 版）按角色选模块；
- 补充**传输影响评估（TIA）**：评估接收国法律环境（EDPB 建议）；
- 补充分措施：加密、传输最小化等；
- 合同义务：通知、漏洞、数据主体权利协助；
- 记录归档 + 定期复审。

## 3. 中国场景特别提示

- **中国无充分性认定** → 向中国传输必须 SCC（或 BCR/例外）；
- 中国个保法/数据出境规定与 GDPR 传输并存（两边都要满足，见 07 模块）；
- 医械健康数据：GDPR 特殊类别 + 中国敏感个人信息双重限制。

## 4. 例外情形（第 49 条，慎用）

- 数据主体**明确同意**（且已被告知无充分性保护的风险）；
- 合同履行/法律主张所必需；
- 重大利益保护；
- 小规模非频繁传输（公共利益等）。

## 5. 常见坑

1. **裸传**：没签 SCC 就传数据到中国 = 违规；
2. **SCC 模板过时**：用旧版模板（2010 版）不合规；
3. **不补 TIA**：只有 SCC 没有传输影响评估（EDPB 要求）；
4. **例外滥用**：把常规业务包装成"例外"。
