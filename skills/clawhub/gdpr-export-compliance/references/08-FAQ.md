# 08 FAQ

**Q：中国公司做欧洲电商，受 GDPR 管吗？**
大概率受管——只要向欧盟境内主体提供商品/服务（哪怕免费）或监控其行为。核心是"业务是否指向欧盟"（语言/货币/欧盟用户占比/交付欧盟）。用 `scope` 命令初判，重大判断咨询律师。

**Q：没在欧盟设机构也要指定代表吗？**
GDPR 第 27 条：向欧盟提供商品/服务或监控的**非欧盟机构**（无欧盟机构且非公共机构），处理大规模数据通常须指定**欧盟境内代表**。

**Q：营销邮件要同意吗？**
电子营销一般需要同意（ePrivacy Directive + GDPR）；B2B 营销部分国家允许正当利益，但需 LIA 且注意各国差异。

**Q：用户要求删除，能拒绝吗？**
能拒绝的情形：法律保留义务（如财务记录法定保存）、合同履行必要等——但须说明理由并告知投诉渠道；无合法保留理由必须删（含备份/下游）。

**Q：传到中国的数据还用中国出境申报吗？**
要——方向相反但都触发：GDPR 管"欧盟→中国"传输（SCC 等），中国个保法管"中国境内→境外"出境（三路径）。同一批数据两边合规都要做。

**Q：罚款是自动的吗？**
不是——监管机构按 EDPB 指引个案评估（严重性/故意/措施/历史等），配合调查、主动补救可减轻；但硬性义务（72 小时通报）超时本身违规。

**Q：工具命令报错？**
确认 Python 3.8+、skill 根目录运行 `python tools/gdpr_toolkit.py --help`。

**Q：和医械数据出海合规什么关系？**
互补——GDPR 管"欧洲侧"数据合规（本技能），医械数据出海管"中国侧"出境路径（medical-data-export-compliance）；医械企业出海两者都用。
