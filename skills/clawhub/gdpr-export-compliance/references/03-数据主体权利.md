# 03 数据主体权利

> 用途：回答「用户要求访问/删除/可携/反对怎么办」「响应时限」。
> 核对基准日：2026-08-27

## 1. 权利清单（工具 `rights` 命令速查）

| 权利 | 内容 | 响应时限 |
|---|---|---|
| **访问权** | 用户可获取其个人数据副本 + 处理信息 | 1 个月（可延 2 个月） |
| **更正权** | 更正不准确数据 | 1 个月 |
| **删除权（被遗忘权）** | 删除个人数据（无保留必要等情形） | 1 个月 |
| **限制处理权** | 特定情形下限制处理 | 1 个月 |
| **数据可携权** | 以结构化机器可读格式获取并转移 | 1 个月 |
| **反对权** | 反对基于正当利益/直接营销的处理 | 1 个月 |
| **自动化决策相关权利** | 不受仅自动化决策（含画像）重大影响 | 1 个月 |

## 2. 响应流程

```
收到请求 → 身份核实（不得过度收集）→ 评估（是否适用）→ 执行/说明拒绝理由
   → 记录（合规审计）→ 1 个月内完成（复杂可延至 3 个月并告知）
```

## 3. 实务要点

- **身份验证**：确认请求者身份（不得因此索要过多信息）；
- **拒绝权**：可拒绝（如法律保留义务），但须说明理由并告知投诉渠道；
- **时限**：默认 1 个月（自收到完整请求起）；可因复杂/请求多延至 3 个月（须告知）；
- **收费**：原则上免费；明显无据/过度请求可收合理费用；
- **通知义务**：执行更正/删除后通知已披露的接收方；
- **自动化决策**：重大影响的全自动决策须允许人工干预、表达意见、质疑。

## 4. 常见坑

1. **超时未响应**：1 个月是硬时限（违规可被罚）；
2. **身份核实过度**：要求过多信息 = 违反最小化；
3. **删除不彻底**：备份/下游系统未同步删除；
4. **无记录**：没留请求处理记录 = 审计出问题。
