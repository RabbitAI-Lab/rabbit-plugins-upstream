# S2 · 合规边界红线检查

## R — 原文 (Reading)

> "中国境内开展价值互联网与通证经济产业应用创新活动，不能涉及通证代币化等加密金融行为，而应聚焦探索'非金融'的数字化赋能产业提效方向。"
>
> "包括稳定币在内的虚拟货币无法满足 KYC、AML 等要求，在中国境内发行与交易虚拟货币属于非法金融活动。"
>
> — 价值互联网产业应用蓝皮书编写组，第三篇·第五章（合规边界）／ p02、ce03


上引 R 段引述自《价值互联网产业应用蓝皮书（2025）》（蓝皮书编写组），此处为原著要义引述并已署名；本 skill 的改写与编排以 Apache-2.0 授权发布。

## I — 方法论骨架 (Interpretation)

这条原则是中国境内做 Web3 产业应用的"生死线"，是硬约束而非建议。核心判断只有一句话：**你是否让"价值"在境内进入了金融化流通**——无论它叫通证、代币、积分还是收益权凭证。一旦涉及代币化、稳定币、虚拟货币交易，就落入非法金融活动范畴。

三个要点：

1. **唯一合规出路是"非金融"的数字化赋能**。把区块链当可信账本与计量工具——做溯源、贡献计量、RDA 真实数据资产，而不是做融资盘、不搞升值预期。
2. **境内外双轨断裂**。境内只做"价值生成"（上链、确权、一级发行）；"价值流通"（代币化、二级、市值管理）只能放到境外合规区（香港沙盒 + 证监会备案前置）。两者不可在境内并轨。
3. **连带责任无死角**。不仅直接参与违规违法，为境外违规项目提供账户、资金划转、技术支持也追责——"只是帮忙做技术"不能免责。

记住一句话：**"境外合规 ≠ 境内合规"**。

## A1 — 书中的应用 (Past Application)

### 案例 1：朗新集团 / 协鑫能科充电桩·光伏收益权 RWA（香港沙盒）
- **问题**：境内绿色基建存量大但流动性不足，想融资又受境内红线约束，不能境内发币。
- **方法论的使用**：严守 p02——境内用联盟链只做资产数字化与运营数据存证；把收益权代币化整体放到香港监管沙盒，且"不涉及所有权转让、不面向境内居民募资"。
- **结论**：形成"境内资产、境外价值释放"的双层结构，是境内资产境外合规发行的范本。
- **结果**：2024 年于香港沙盒发行；与协鑫共同验证了新能源资产境外合规代币化路径（详见 c23/c24）。

### 案例 2：华润隆地「充美好」充电桩 RWA（香港 Ensemble 沙盒）
- **问题**：香港车桩比仅 7%、融资缺口大，但必须合规且穿透监管。
- **方法论的使用**：以特定充电站未来 1–3 年经营收益权（非所有权）为底层，ERC-20 分割；接入金管局 Ensemble 沙盒、穿透式监管、物联网数据实时上链；全程不碰稳定币、不向零售无差别发售。
- **结论**：国企 RWA 合规试点范式，收益权通证化而非资产货币化。
- **结果**：入选金管局 Ensemble 沙盒，为绿色基建收益权通证化提供样板（c03）。

### 案例 3：虚拟货币交易被定性为非法金融活动（第五章开篇 / ce03）
- **问题**：境内能否做代币化融资、稳定币结算？
- **方法论的使用**：p02 划红线——虚拟货币发行与交易属非法金融活动，七协会联合定性境内 RWA 代币化为风险范畴；我国金融管理部门未批准任何 RWA 代币化活动。
- **结论**：一律禁止，严打伪 RWA 资金盘。
- **结果**：相关宣传、交易行为均被依法处置，多次出现大 V 炒作虚拟货币被判例处置。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 项目方在动手前不确定"我们发的到底是通证还是代币、会不会踩线"。
2. 想用"境外合规"给境内业务找出口，或准备帮境外 Web3 项目做技术/通道/账户。
3. 涉及稳定币结算、虚拟货币交易，或面向境内居民做代币募资、炒作升值预期。
4. 内容创作者在科普 / 带货 Web3 项目，需先判断内容是否会诱导非法金融。
5. 传统企业想"上链融资"，但分不清产业赋能与资产代币化的边界。

### 语言信号（用户的话里出现这些就应激活）

- "我们发个币 / 代币 / 积分，能不能升值、能不能上交易所"
- "境外合规，境内应该也能做吧"
- "我只是帮忙做技术 / 开个账户 / 接个服务器"
- "用稳定币结算跨境货款"
- "境内资产、香港 / 海外发币"
- "老师你说的这个项目我能投吗"

### 与相邻 skill 的区分

- **与 S1（通证/代币化概念辨析器）的区别**：S1 解决"通证/代币化/RWA 概念是什么、如何分层"，偏认知澄清；S2 在概念清楚之后做"我的项目到底踩不踩红线"的生死判读。问"什么是代币化"→S1；问"我这玩法境内能不能做"→S2。
- **与 S10（监管范式与香港沙盒路径）的区别**：S10 解决"境内资产如何经香港沙盒 / SPV 合规出海"，偏路径设计；S2 是**前置闸门**——先判断是否允许、哪些动作在境内绝对禁止。顺序上先 S2 判生死，再过 S10 设计出海通道。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **列出项目所有"价值分配 / 通证"动作**
   - 完成标准：穷举四类动作——①白皮书/宣传（发、募、升值叙事）②经济模型（通证分配、回购、分润）③资金（面向谁募、是否跨境）④技术（链选型、是否二级流转）。无遗漏地形成一张"动作清单"。

2. **逐项比对红线清单**
   - 完成标准：对清单每条动作标注 🟢安全 / 🟡高危 / 🔴禁止，对照以下红线：
     - 境内代币化 / 虚拟货币发行交易（🔴）
     - 稳定币发行或结算（🔴）
     - 面向境内居民募资或提供交易（🔴）
     - 为境外违规 RWA / 虚拟货币提供账户、资金、技术支持（🔴）
     - 境内资产境外发行未证监会备案（🔴）
     - 功能型通证叠加升值叙事、可二级流转（🟡）
   - 判停条件：若任一动作命中 🔴，直接跳到步骤 3 判为"禁止 / 需重做"，不再逐项美化。

3. **判定安全 / 高危 / 禁止，并给出处置建议**
   - 完成标准：输出三色结论——
     - 全 🟢：可推进，但保留"非金融定位声明 + 不面向境内募资 + 不碰稳定币"三项记录；
     - 含 🟡：建议剥离金融化表述，改为 RDA / 功能型通证 / 数字提货权，并移除二级流转；
     - 含 🔴：判定"禁止"，给出两条出路——（a）境内改为纯非金融数字化赋能；（b）价值流通动作整体移至境外合规区并经证监会备案（接 S10）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯境外持牌合规区项目**（香港持牌、美欧注册，无境内居民参与、无境内配套）：此时以 S10 做出海路径设计为主，S2 仅作"境内连带风险"轻扫描。
- **纯术语 / 概念澄清**（仅问"什么是代币化"）：转 S1 概念辨析器。
- **完全无上链 / 通证元素的纯传统业务**：本 skill 不适用，属误激活。

### 作者在书中警告的失败模式（来自 counter-examples）

- **ce03 境内红线**：在境内触碰代币化 / 虚拟货币金融属性，直接构成非法金融活动。
- **ce09 稳定币陷阱**：稳定币无法满足 KYC/AML，易被用于洗钱、集资诈骗、违规跨境转移资金；我国严禁包括稳定币在内的虚拟货币交易炒作。
- **ce10 空气币 + 传销**：无实质技术、无真实场景（如 π 币），靠拉人头层级返利，常与诈骗关联，任何宣传交易均属非法。
- **ce11 连带追责**：为境外违规 RWA / 虚拟货币提供账户、资金划转、技术支持也违法，"只是帮忙"不免责——科技公司、支付通道、技术外包是高发连带主体。
- **ce12 虚假资产 / 投机炒作**：未经批准的 RWA / 稳定币、底层资产清单模糊、强调币价升值而非产业收益，我国金融管理部门未批准任何 RWA 代币化活动。
- **ce16 译名联想风险**：功能型 / 产品型 / 治理型通证若对外混用"通证 / 代币"措辞，易被监管联想为金融工具，概念误用本身即带来合规风险。

### 作者的盲点 / 时代局限

- 编写组含道衍数科（项目方）及多家 RWA 产业链服务商，**天然带有推广 Web3 产业应用的立场**，对监管态度的**不确定性着墨偏乐观**，以"合规化路径"收束，但境内红线仍刚性且可能随政策收紧。
- 稳定币 / 代币化的全球合法化进程、香港沙盒规则仍在快速演化，书中部分"前沿实践"可能已被新规覆盖。**使用时必须以最新监管公告为准，宁可保守。**

### 容易混淆的邻近方法论

- "非金融数字化"与"金融化"边界模糊：功能型通证 / 积分一旦叠加升值叙事、开通二级流转，可能被重新定性为金融属性（参见 ce16）。判定时应按"是否产生金融化流通预期"而非"叫什么名字"为准。


### 合规红线与使用须知（普通用户必读）

本技能提炼自《价值互联网产业应用蓝皮书（2025）》（蓝皮书编写组，主编：梁超杰）第三篇·第五章「合规边界」，仅供风险识别与科普参考，**不构成任何投资建议、法律意见或投资邀约**。

- 中国境内开展价值互联网与通证经济产业应用，**不得涉及通证代币化等加密金融行为**，应聚焦"非金融"的数字化赋能（溯源、贡献计量、RDA 真实数据资产等）。
- 包括稳定币在内的虚拟货币，**在中国境内发行与交易属于非法金融活动**（央行等十部门 2021 年《关于进一步防范和处置虚拟货币交易炒作风险的通知》）。境外交易所、项目向中国境内居民提供服务同样属非法。
- **连带责任无死角**：不仅直接参与违法，为境外违规项目提供账户、资金划转、技术支持也依法追责——"只是帮忙做技术"不能免责。
- 任何以"Web3/区块链"为名、要求充值、拉人头返利、承诺升值预期的，极可能是资金盘，**请勿参与、勿投资、勿转发**。

> 引用原文："不能涉及通证代币化等加密金融行为，而应聚焦探索'非金融'的数字化赋能产业提效方向。""包括稳定币在内的虚拟货币无法满足 KYC、AML 等要求，在中国境内发行与交易虚拟货币属于非法金融活动。" —— 第三编·第五章（合规边界）／ p02、ce03
