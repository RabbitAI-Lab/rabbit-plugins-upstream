# 使用指南

## 这是什么？

基于 KSAO 框架的 JD 匹配优先级判定工具。通过双层漏斗（硬过滤 + 能力维度匹配），帮你从大量 JD 中筛选出最值得投递的岗位。

## 准备工作

你需要准备：
1. **简历**（文件路径 或 直接粘贴文本）
2. **求职偏好**（岗位方向、薪资、城市、排除项、福利底线）
3. **待筛选的 JD 列表**（≥10 份用于校准，之后可批量处理）

## 首次使用流程

### Step 1: 收集偏好

Agent 会逐个问你 5 个问题：
1. 期望岗位方向
2. 期望薪资范围
3. 期望工作城市
4. 排除的行业/岗位类型
5. 福利底线

### Step 2: 提供简历

提供简历文件路径，或直接粘贴简历内容。

### Step 3: 生成画像

Agent 会生成两个画像：
- **候选人画像**：你的 KSAO 能力结构（知识/技能/能力/特质）
- **求职 JD 画像**：你的理想岗位特征

### Step 4: 确认匹配标准

Agent 会展示拟定的硬过滤规则和能力维度权重，你可以调整。**能力维度会根据你的简历和目标岗位动态生成**，而非使用固定模板。

### Step 5: 校准测试

提供 ≥10 份 JD，Agent 执行匹配并展示结果。你审阅后：
- 有调整 → 修改标准 → 重新测试
- 无调整 → 正式启用

### Step 6: 批量匹配

校准通过后，可以批量处理大量 JD。

## 非首次使用

直接提供 JD 列表，使用上次确认的匹配标准。

## 输入格式

| 输入类型 | 说明 |
|---------|------|
| 飞书多维表格 | 提供表格链接 |
| 本地 CSV | 提供文件路径 |
| 本地 Excel | 提供文件路径 |
| 直接粘贴 | 粘贴 JD 文本 |

## 输出格式

| 输出 | 说明 |
|------|------|
| `优先级判断` | high / medium / low |
| `优先级判断理由` | 30 字以内，格式：[核心原因]，[辅助说明] |
| 命中维度 | 匹配到的能力维度列表 |
| 深度匹配 | 精准匹配 / 超配 / 不足 |

## 匹配结果含义

| 结果 | 含义 | 建议 |
|------|------|------|
| **high** | 高度匹配，值得投递 | 优先投递 |
| **medium** | 有一定匹配度 | 看具体情况决定 |
| **low** | 不匹配 | 不建议投递 |

## 注意事项

- 匹配结果是参考，不是绝对标准
- JD 信息越完整，匹配越准确
- 校准环节很重要，能显著提升后续批量匹配的准确度
- 匹配标准可以随时调整，不需要从头开始
- 能力维度是根据你的画像动态生成的，不同用户的维度可能不同
