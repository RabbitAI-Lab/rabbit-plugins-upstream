## Description:

Generates and edits images with GPT Image 2.5 Sunburst, supporting reference images, aspect ratios up to 21:9, and quality settings up to max.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers can generate images from prompts or edit images using reference images. They can choose an aspect ratio and image quality for detailed compositions and in-image text.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected reference files are sent to dLazy's cloud service, and the CLI stores an API key locally.

Mitigation: Review dLazy's privacy terms, upload only material you intend to share, and protect or revoke the saved API key when needed.
