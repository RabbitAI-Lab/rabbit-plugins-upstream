## APQP产品质量策划

### 概述

APQP（Advanced Product Quality Planning）是汽车行业通用的产品质量策划方法论，通过跨功能团队合作，确保产品满足顾客要求。

### APQP五阶段流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  计划和定义  │───▶│  产品设计   │───▶│  过程设计   │───▶│  产品过程   │───▶│  反馈评定   │
│             │    │  及验证     │    │  及验证     │    │  确认       │    │  和纠正措施 │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

### 各阶段关键活动

| 阶段 | 主要活动 | 输出文件 |
|------|---------|---------|
| 1.计划和定义 | 顾客需求收集、市场分析、项目立项 | 设计任务书、项目计划 |
| 2.产品设计及验证 | DFMEA、设计评审、样件制作 | DFMEA、设计验证报告 |
| 3.过程设计及验证 | PFMEA、过程流程图、控制计划 | PFMEA、控制计划、作业指导书 |
| 4.产品过程确认 | 试生产、MSA、SPC、PPAP提交 | 量产批准文件、PPAP |
| 5.反馈评定和纠正措施 | 持续改进、减少变异 | 经验教训库 |

### 与IATF16949的关联

APQP是IATF16949要求的产品实现策划的核心方法，确保：
- 过程策划与产品策划同步
- 关键特性得到识别和控制
- 样件、试生产、量产阶段有序过渡

## FMEA失效模式与影响分析

### 概述

FMEA（Failure Mode and Effects Analysis）是一种预防性的风险分析工具，用于识别潜在失效模式及其影响。

### FMEA类型

| 类型 | 全称 | 适用阶段 |
|------|------|---------|
| DFMEA | Design FMEA | 产品设计阶段 |
| PFMEA | Process FMEA | 过程设计阶段 |
| SFMEA | System FMEA | 系统架构设计 |

### PFMEA评分标准

**严重度（S）评分（1-10）**:

| 评分 | 影响描述 |
|------|---------|
| 10 | 危害：无警告的严重危害 |
| 9 | 危害：有警告的严重危害 |
| 8 | 产品功能丧失（非安全相关） |
| 7 | 产品功能下降 |
| 6 | 功能暂时丧失 |
| 5 | 功能暂时下降 |
| 4 | 装配后即可发现的外观缺陷 |
| 3 | 装配前即可发现的外观缺陷 |
| 2 | 轻微缺陷，大多数顾客未注意到 |
| 1 | 无可察觉的影响 |

**频度（O）评分（1-10）**:

| 评分 | 失效可能性 |
|------|-----------|
| 10 | 极高（每天发生） |
| 8 | 高（每周发生） |
| 6 | 中等（每月发生） |
| 4 | 低（每年发生） |
| 2 | 极低（失效可能性极低） |
| 1 | 几乎不可能 |

**探测度（D）评分（1-10）**:

| 评分 | 探测方法 |
|------|---------|
| 10 | 不能探测 |
| 8 | 探测方法可能性很低 |
| 6 | 中等探测可能性 |
| 4 | 高探测可能性 |
| 2 | 几乎肯定能探测 |
| 1 | 肯定能探测 |

### RPN计算与决策

**公式**: `RPN = S × O × D`

**RPN阈值参考**:
- RPN > 100：高风险，必须采取纠正措施
- RPN 50-100：中风险，考虑采取纠正措施
- RPN < 50：低风险，可接受但应监视

**改进优先级**:优先关注高严重度项目，即使RPN较低

### FMEA编制步骤

1. 确定分析范围和边界
2. 组建跨功能团队
3. 识别过程步骤
4. 分析潜在失效模式
5. 评估影响和原因
6. 确定当前控制措施
7. 计算RPN
8. 制定改进措施
9. 评审和更新

## MSA测量系统分析

### 概述

MSA（Measurement System Analysis）用于评估测量系统的变异，确保测量数据质量。

### 测量系统变异性来源

```
总变异 = 零件变异 + 测量系统变异
         (PV)         (GRR)
```

### GRR评价标准

| GRR% | 评价 | 建议 |
|------|------|------|
| < 10% | 优秀 | 可接受 |
| 10-30% | 可接受 | 基于应用场景判断 |
| > 30% | 不可接受 | 必须改进 |

### MSA分析类型

**计量型MSA（GRR研究）**:
- 评价人：2-3人
- 评价次数：每人每零件测量2-3次
- 零件数：10个（含正常变异范围）

**计数型MSA（属性一致性分析）**:
- 评价人：2-3人
- 评价次数：2次
- 零件数：至少50个

### MSA报告要素

```
1. 测量系统基本信息
2. 测量人员信息
3. 零件测量数据
4. GRR分析结果
5. 结论与建议
```

## SPC统计过程控制

### 概述

SPC（Statistical Process Control）通过统计方法监控过程稳定性，及时发现异常变异。

### 控制图类型选择

| 数据类型 | 控制图 | 适用场景 |
|---------|--------|---------|
| 计量数据 | X̄-R | 子组样本2-5个 |
| 计量数据 | X̄-S | 子组样本>5个 |
| 计量数据 | I-MR | 单件/小批量 |
| 计件数据 | np/p | 合格/不合格数 |
| 计点数据 | c/u | 缺陷数 |

### 控制图判异准则

**准则1**: 1个点落在控制限之外
**准则2**: 连续9点落在中心线同一侧
**准则3**: 连续6点递增或递减
**准则4**: 连续14点交替上下
**准则5**: 连续3点中有2点落在2σ区域
**准则6**: 连续5点中有4点落在1σ区域
**准则7**: 连续15点落在1σ区域
**准则8**: 连续8点落在1σ区域之外

### 控制图应用步骤

1. 确定控制对象（关键产品特性/过程参数）
2. 选择合适控制图类型
3. 收集数据，建立初始控制限
4. 绘制控制图，持续监控
5. 分析控制图，判断过程状态
6. 分析异常原因，采取措施
7. 更新控制限，保持控制图动态管理

### Cpk计算与过程能力

**过程能力指数**:
```
Cp = (USL - LSL) / 6σ
Cpk = min[(USL - μ) / 3σ, (μ - LSL) / 3σ]
```

**Cpk评价标准**:

| Cpk值 | 过程能力 | 建议 |
|-------|---------|------|
| Cpk > 1.67 | 优秀 | 理想状态 |
| 1.33 < Cpk ≤ 1.67 | 良好 | 可接受 |
| 1.0 < Cpk ≤ 1.33 | 勉强 | 需要改进 |
| Cpk ≤ 1.0 | 不足 | 必须改进 |

## VDA汽车行业过程审核

### 概述

VDA（Verband der Automobilindustrie）是德国汽车工业协会发布的审核标准，在汽车行业广泛应用。

### VDA 6.3审核要点

**过程审核七步骤**:
1. 审核策划
2. 审核准备
3. 审核实施
4. 审核记录
5. 审核报告
6. 跟踪验证
7. 审核关闭

### VDA过程审核评分

| 得分 | 等级 | 含义 |
|------|------|------|
| 90-100 | A级 | 零缺陷 |
| 80-89 | B级 | 轻微偏差 |
| 70-79 | C级 | 轻微缺陷 |
| < 70 | D级 | 严重缺陷 |

### VDA审核检查表结构

```
P1 - 项目管理
P2 - 产品/过程开发策划
P3 - 产品/过程开发实现
P4 - 供应商管理
P5 - 过程要素
P6 - 过程分析
P7 - 顾客支持/服务
```

### 与IATF16949审核的区别

| 对比项 | VDA 6.3 | IATF16949 |
|--------|---------|-----------|
| 适用范围 | 过程审核 | 体系审核 |
| 重点 | 过程有效性 | 体系符合性 |
| 方法 | 过程导向 | 条款导向 |
| 深度 | 更深入 | 更全面 |
