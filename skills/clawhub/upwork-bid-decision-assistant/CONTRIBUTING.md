# 贡献指南

感谢你帮助改进 Upwork 投标判断助手。

## 可以贡献什么

- 修正文案、术语或错误链接；
- 补充更清晰的输入说明；
- 改进风险识别和缺失信息处理；
- 提交已脱敏的边界案例；
- 提升不同大模型或 Agent 环境的兼容性。

## 提交前请注意

1. 不要提交真实客户姓名、邮箱、电话、聊天记录、合同号或付款资料。
2. 示例必须虚构或充分脱敏。
3. 不增加基于国籍、族裔、姓名、口音或头像的风险判断。
4. 不加入规避平台规则、伪造计时、刷评价或免费窃取方案的技巧。
5. 平台事实类修改应注明核对日期，并优先依据官方资料。
6. 经验阈值应明确标注为经验规则，而不是平台保证。

## Pull Request 建议格式

- 说明修改解决了什么问题；
- 列出修改的文件；
- 给出一个虚构测试案例；
- 说明是否改变既有结论或评分逻辑。

提交贡献即表示你同意该贡献按本仓库 `LICENSE` 进行分发。
