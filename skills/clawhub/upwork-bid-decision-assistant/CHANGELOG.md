# Changelog

## 1.2.1-public — 2026-07-29

- 增加公开 GitHub 仓库结构、项目首页、贡献指南和隐私安全说明；
- 增加虚构输入/输出示例与 GitHub 发布指南；
- 授权调整为 Non-Commercial Public License 1.0，允许非商业使用与修改，禁止转售；
- 不包含任何小红书卖家素材、价格或内部销售文件；
- 核心判断逻辑仍与 v1.2.1 一致。

## 1.2.1 — 2026-07-29

- 将客户安装包与卖家上架素材彻底分离；
- 客户包不再包含小红书上架文案、封面详情页文案、建议售价或内部测试案例；
- 精简客户 README，只保留安装、建档、调用和安全说明；
- Skill 判断逻辑与 v1.2.0 保持一致。

## 1.2.0 — 2026-07-29

- 增加 Upwork Freelancer 公开主页作为个人画像的首选输入；
- 支持从主页链接、整页复制、连续截图、文字描述和语音口述中自动提取画像；
- 增加“已确认 / 仍缺失 / 需要确认”的画像草稿输出；
- 链接无法读取时自动切换到复制或截图流程；
- 信息不足时每轮最多追问 3 个会改变结论的问题；
- 明确公开时薪不能自动等同于最低可接受报价；
- 同步更新通用粘贴版、用户说明、用户画像模板、测试案例和默认调用提示。

## 1.1.0 — 2026-07-29

- 增加首次使用强制用户画像建档流程；
- 增加独立用户画像模板与复用/更新规则；
- 未建档时禁止猜测个人匹配分；
- 未建档时不再输出伪完整的 100 分总分，可改为已知维度 75 分制；
- 明确一票否决案例可先给安全结论，再提醒建档；
- 同步更新通用粘贴版、用户说明、输出模板和测试案例。

## 1.0.0 — 2026-07-29

- 首次发布；
- 增加工作、客户、竞争三层输入结构；
- 增加五维评估与硬性风险覆盖；
- 增加 Boost、Invite、Cover Letter 决策；
- 增加平台合规与安全边界；
- 增加 Profile 准备附录；
- 增加通用大模型粘贴版、上架文案和测试案例。
