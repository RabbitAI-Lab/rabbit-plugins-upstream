# 隐私与安全

本项目主要处理职位、客户历史和自由职业者个人画像。请避免在公开仓库中泄露敏感信息。

## 不应公开提交的内容

- 身份证件、银行卡、支付账号或税务资料；
- Upwork 登录信息、Cookie、验证码或 API 密钥；
- 客户的私人邮箱、电话、聊天和未公开附件；
- 未经允许的商业机密、内部数据或完整付费交付物；
- 可识别个人身份的连续截图。

## 报告问题

- 普通规则错误：使用 GitHub Issue，并使用虚构或脱敏示例。
- 可能造成隐私或账号安全风险的问题：不要公开粘贴敏感细节；优先使用仓库的私密安全报告功能（若仓库启用）。

本项目不会要求用户提供密码、验证码、身份证件或银行信息来建立画像。
