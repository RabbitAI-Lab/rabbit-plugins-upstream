# Upwork 用户画像获取方式

首次使用“Upwork 工作投标判断助手”时，任选一种方式提供个人信息。**最推荐的是直接提供已经填写完整的 Upwork Freelancer 公开主页。**

## 方式一：发送 Upwork 主页

直接发送你的 Freelancer 主页链接，并说：

> 请读取我的 Upwork 主页，建立用户画像。先列出已确认信息，再问我缺少的关键问题。

Skill 会尝试提取 Profile、Skills、Portfolio、Work History、评价、证书、语言、平台表现和公开价格。若链接无法读取，会提醒你改用复制或截图。

注意：主页公开时薪不会自动等同于你的最低报价，Skill 会请你确认。

## 方式二：复制或截图

可以复制整页文字，或者上传以下区域的连续截图：

- Profile 顶部、标题与 Bio；
- Skills；
- Portfolio；
- Work History 与客户评价；
- Certifications、Languages、Education；
- 当前公开时薪。

## 方式三：文字或口头描述

不方便提供主页时，可以直接用文字或语音讲述。Skill 会先替你总结成画像草稿，再以问答方式补齐缺失项。

例如：

> 我主要做中国市场进入、数字营销和小红书内容，做过汽车和 SaaS 项目。最低希望每小时 30 美元，不接受全职低价项目。

## 方式四：填写模板

```text
【Upwork 用户画像】
1. 核心技能（必填，3–5 项）：
2. 同类项目与可验证成果（必填）：
3. 最低可接受报价（必填，时薪/固定价/最低净收入）：
4. Portfolio、评价、证书或作品链接：
5. 英语及其他目标语言水平：
6. 每周可投入时间、所在时区：
7. 是否接受 Time Tracker、视频面试、跨时区会议：
8. 当前目标：快速收入 / 长期客户 / 建立历史 / 提高单价 / 其他：
9. 不接受的行业、任务或合作方式：
```

用户不必一次提供完整。Skill 会使用已知信息，并且每轮最多追问 3 个会改变结论的问题。

不要填写身份证、银行卡、账号密码或精确住址等敏感信息。
