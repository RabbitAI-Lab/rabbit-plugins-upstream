# 用户使用说明

## 这个 Skill 是做什么的

它用于把 Upwork 页面中的零散信号组合起来，辅助判断：

- 这个工作值不值得投；
- 客户是否可靠；
- 竞争是否已经太晚；
- 要不要使用 Boost；
- Invite 是否值得接受；
- 报价和 Connects 成本是否合理；
- 是否存在诈骗、免费劳动或平台合规风险。

它不是“保证接单”的工具，也不替代用户对自身能力和合同条款的最终判断。

## 第一次使用：先建立个人画像

Skill 在发现当前对话或项目中没有用户画像时，会主动提醒建档。你不必只能填写表格，可以任选以下方式：

1. **发送已经填写完整的 Upwork Freelancer 公开主页链接**；
2. 复制 Profile、Skills、Portfolio、Work History 与评价；
3. 上传主页连续截图；
4. 用文字或语音口述技能、案例、报价和偏好；
5. 使用 `用户画像模板.md`。

Skill 会先从现有材料中形成画像草稿，再用问答补齐关键缺口。每轮最多询问 3 个会改变结论的问题，不会要求重复提供已经出现的信息。

至少需要最终确认：核心技能、同类项目或可验证成果、最低可接受报价。Upwork 主页公开时薪只作为参考，除非你明确确认，否则不会自动当成最低报价。

支持长期记忆或项目说明的平台，可以保存后复用；不支持的平台，新开对话时需重新提供主页或粘贴画像。

没有足够画像时，Skill 不会猜测个人匹配度，也不会给出虚假的个人匹配分。若职位本身已经存在明确诈骗或合规风险，它仍会先给安全结论。

## 最简单的使用方法

### 方法一：发链接

发送 Upwork 工作链接，并说：

> 帮我判断这个工作值不值得投。请同时看客户历史、proposal、interview、invite、last viewed 和预算。

若模型无法访问链接，改用方法二。

### 方法二：复制整页

复制以下区域：

1. 工作标题和完整描述；
2. Activity on this job；
3. About the client；
4. Client's recent history；
5. 投标页面上的 Connects、预算和 Boost 信息。

### 方法三：连续截图

截图不要只截职位描述。至少包括：

- 工作顶部；
- 完整 JD；
- Activity on this job；
- About the client；
- 历史评价与相似工作；
- Apply 页面。

## 建立画像的推荐方式

最省事的方式：

> 这是我的 Upwork Freelancer 主页：___。请建立用户画像，读不到的部分再告诉我用截图或问答补充。

也可以复制这段填写：

```text
我的核心技能：
相似项目：
可展示案例：
最低可接受报价：
每周可用时间：
是否接受 Time Tracker：
英语/目标语言水平：
本次目标：短单 / 长期客户 / 建立记录 / 高客单价
我对这个工作的主观意愿：低 / 中 / 高
```

## 推荐提问

### 判断工作

> 请分析这个 Upwork 工作。先提取工作、客户和竞争信息，再告诉我：投不投、是否 Boost、置信度、主要风险、缺失信息。

### 判断 Invite

> 这是客户发来的 Invite。请判断我应该接受、接受后先问问题，还是拒绝。不要把接受 Invite 等同于接受合同。

### 判断 Boost

> 我准备投这个工作。请结合发布时间、proposal、interview、invite、last viewed、预算和我的匹配度，给出不 Boost、轻度 Boost 或积极 Boost 的建议，并给止损原则。

### 写 Cover Letter

> 先判断工作是否值得投。如果值得，再根据我的真实经历写英文 Cover Letter。不要虚构，不要提供可被免费拿走的完整方案。

## 信息不全时

Skill 会：

- 能判断就先判断；
- 给出置信度；
- 只要求补充最关键的字段；
- 告诉你为什么该字段会改变结论。

## 安全提示

- 不先付款；
- 不换汇或代收代付；
- 合同前不站外付款；
- 不免费完成核心工作；
- 不出租账号或身份；
- Time Tracker 只记录真实工作；
- 个人资料和客户机密注意打码。
