# Upwork 资料准备附录

仅在用户要求检查 Profile、Portfolio、Skills、Project Catalog、证书或曝光设置时使用。

## 1. Profile 基础

- 使用清晰、职业化头像；
- 标题优先写最能带来目标岗位的能力，不堆无关技能；
- Bio 开头两三行先说明“做什么、为谁做、能解决什么”；
- 后文写具体交付物、工具、行业和可验证成果；
- 使用英文为主，术语与目标岗位中的真实用词一致；
- 工作经历、教育背景、语言水平如实填写；
- 及时回复消息，保持可沟通性。

## 2. 关键词研究

不要 100% 凭自己想象关键词。

建议：

1. 收集 10–20 个真正想接的工作；
2. 提取标题、Skills、交付物和行业词；
3. 收集 3–5 位完成过相似工作的 freelancer 主页；
4. 让 AI 汇总高频且与本人真实能力一致的词；
5. 约 80% 使用平台已有、常见、可搜索的标准词；
6. 约 20% 可保留有明确搜索意图的细分词，例如特定平台或区域渠道；
7. 不为了流量加入自己不会做的技能。

## 3. Portfolio

每项能力至少准备一个可视化项目：

- 网站或产品：截图、链接或界面流程；
- 设计：成品、前后对比、品牌应用；
- 营销：投放结构、指标、内容表现；
- 写作或翻译：公开发表内容、节选、阅读或互动数据；
- 报告和研究：打码后的页面、目录、图表；
- 视频或音频：片段、封面、字幕、结果；
- 开发：GitHub、代码样本、功能截图。

每个项目写：

- 背景
- 任务
- 自己负责的部分
- 方法
- 交付物
- 结果
- 使用的 Skills

不得泄露客户隐私或把团队成果全部归为个人。

## 4. Project Catalog / Consultations / Video

- 将主要能力拆成多个清晰服务；
- 经验建议可先做 4–6 个有差异的 Catalog 项目，不为凑数重复；
- 每个项目突出一个搜索意图；
- 套餐写清交付、周期、修改次数、加急费；
- 封面可用 AI 辅助制作，但不要放联系方式、二维码或站外交易提示；
- Consultations 即使订单不多，也可作为额外展示和关键词入口；
- 有条件时制作简洁的英文 Video Introduction。

## 5. Skills、证书与外部作品

- 优先填写与目标工作直接相关的 Skills；
- 证书应真实、可验证、与业务相关；
- 可使用 Credly 等可验证凭证；
- 开发者可关联 GitHub、Stack Overflow 等真实作品；
- 不放驾驶证等无关证明；
- 不虚构国际证书或机构认可。

## 6. 评价与工作历史

- 完成项目后礼貌邀请客户留下真实、具体评价；
- 评价越能描述“做了什么、结果如何”，越能帮助未来客户理解能力；
- 不以折扣换五星；
- 新账号需要一定数量的真实 Completed Jobs 建立记录；
- 长期客户的合同可保持进行中，但仅限真实仍有合作可能的合同；
- 不为了指标人为维持虚假合同。

## 7. Availability Badge 与 Boosted Profile

经验建议：

- 偶尔接单、目标岗位很少或客单价很低：先不持续付费；
- 已经有完整 Profile、明确关键词、较高单价并准备常态接单：可测试 Availability Badge；
- Boosted Profile 按点击或互动消耗 Connects，应设置明确上限；
- 用 My Stats 观察曝光、点击、邀请和成交，不凭感觉长期烧 Connects；
- 任何推广都不能弥补定位混乱、Portfolio 缺失或低匹配。

## 8. 语言和验证

- 语言等级要能经受真实面试；
- 能开视频时，准备稳定网络、摄像头、麦克风和简短英文介绍；
- 完成身份验证；
- 不把平台或 AI 自动生成的语言标识当作永久保证。
