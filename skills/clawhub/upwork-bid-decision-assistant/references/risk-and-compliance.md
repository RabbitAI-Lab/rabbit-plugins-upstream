# 风险与合规规则

## 一票否决

出现以下情况，直接建议避开：

- 要求 freelancer 先付款、交押金、保证金、培训费或购买指定商品；
- 要求换汇、兑换支付宝/银行卡资金、代收代付、转账给第三方；
- 资金只显示为 pending、in review、截图或“已打款”，却要求先把钱转出去；
- 要求租借、购买、出售或共享账号、身份、银行卡、支付工具；
- 要求制作虚假评价、虚假身份、伪造证件、刷量或欺骗性内容；
- 要求窃取、购买或未经授权收集个人数据、商业机密或受限制数据；
- 要求免费完成可直接使用的核心成果；
- 合同前要求站外付款，或明确要求绕过 Upwork 费用；
- 明显违法或可能带来重大法律、国家安全、隐私风险的调研与数据任务；
- 对方持续催促、制造紧迫感，并拒绝提供可验证信息。

## 合同前沟通

一般原则：

- 合同开始前，沟通尽量留在 Upwork；
- 不发送手机号、邮箱、微信、WhatsApp、Telegram、社交账号、二维码或地址；
- 不接受合同前站外付款；
- 平台可能对特定法律、系统访问或 Enterprise 场景有例外，但即便出现例外，也不要把项目沟通和付款迁出平台；
- 页面或聊天出现平台警告时，立即停止并检查内容，不要尝试绕过检测。

## 客户身份判断

可以使用：

- 公司名称、域名、历史项目、付款验证、评论和公开业务信息；
- 账号注册时间、hire rate、total spent、历史平均支付；
- 沟通内容是否与其公司和岗位一致；
- 是否愿意使用平台合同和付款保护。

禁止使用：

- 仅凭国籍、族裔、头像、名字“像不像某国人”来判断；
- 把某个国家或地区直接等同于诈骗；
- 基于口音或种族作贬损性结论。

风险必须来自行为和证据。

## Hourly 合同

- 使用 Time Tracker 时，只记录真实工作；
- 截图内容应与合同相关，避免显示私人银行、个人邮件和敏感信息；
- 记录清楚 memo；
- 不超过 weekly limit；
- 不通过移动鼠标、自动点击或无关操作伪造活跃度；
- 开工前确认是否允许 manual time，以及该时间是否受付款保护；
- 注意 Upwork 工作周和双方时区，避免把工时记入错误周期。

## Fixed-price / Milestone

- 开始工作前确认 milestone 已有资金；
- 交付后使用合同内的 Submit work 功能；
- 范围、交付物、修改次数和验收标准写清；
- 大任务拆分 milestone；
- 不因客户口头承诺而交付未资助的大量工作；
- 客户要求新增范围时，先修改 milestone 或新建 milestone。

## 评价与履历

- 可以在项目完成后礼貌请求真实评价；
- 不以折扣、退款、赠品或其他利益交换五星评价；
- 不要求客户隐瞒问题；
- 不伪造 Portfolio、证书、Employment History；
- 涉及客户机密的案例应打码或获得授权。

## 免费方案与测试

可接受：

- 很短的能力验证；
- 已有 Portfolio；
- 对方法的高层说明；
- 不可直接商用的小样。

高风险：

- 完整策略、完整文案、完整设计稿、完整代码模块；
- 多轮无偿修改；
- “先做完看看，满意再付款”；
- 要求把核心成果发到站外。

## 敏感数据和调研

当工作涉及：

- 关键基础设施、机场/航班、能源、疫情、社会事件、政治组织；
- 大规模定位数据、个人身份信息；
- 未公开政府、企业或安全数据；
- 绕过访问限制、爬取受保护系统；

不要仅凭“网上有公开数据”就判断安全。建议用户确认数据来源、使用目的、适用法律与授权；无法确认时不接。
