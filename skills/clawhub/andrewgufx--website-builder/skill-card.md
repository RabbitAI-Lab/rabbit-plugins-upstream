## Description:

ANDG is a website planning assistant that helps users turn website ideas into clear site structure, content hierarchy, UX direction, technology suggestions, and build plans.

This skill is ready for commercial/non-commercial use.

## Publisher:

[andrewgufx](https://clawhub.ai/user/andrewgufx)

### License/Terms of Use:


## Use Case:

External users and developers use this skill to convert a vague website goal into a practical first-version plan, including pages, sections, copy, visual direction, stack guidance, and implementation steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Website plans may rely on stated assumptions when the user's request is vague.

Mitigation: Review the assumptions, site structure, copy, and build plan before using them as implementation direction.

Risk: Generated starter code plans or stack suggestions may not match the user's production constraints.

Mitigation: Validate technical recommendations against project requirements before implementation.
