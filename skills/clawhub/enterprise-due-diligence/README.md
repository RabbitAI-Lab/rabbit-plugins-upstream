# 企业尽调（Enterprise Due Diligence）

> 一家公司的"深度背景调查"，交给 AI 一次跑完。
> 法律 / 财务 / 业务三维度尽调，自动采集公开数据，输出结构化 Word 尽调报告 + 风险分级检查清单。

---

## 一、这个技能做什么

对目标企业进行**投资/合作前的尽职调查**，覆盖法律、财务、业务三大维度：

- **法律维度**：工商信息核实、股权架构、实际控制人、历史沿革、司法诉讼、知识产权、合规资质
- **财务维度**：财务报表摘要、关键比率、税务合规、关联交易（数据可得时）
- **业务维度**：核心产品/服务、商业模式、市场与竞争、客户与供应商、核心团队画像

最终交付 **结构化 Word 尽调报告**，并可按需生成 **30 项检查清单**（P0/P1/P2 风险分级、四色状态标记）。

## 二、双模板：轻量版 / 基础版

| | 轻量版（默认） | 基础版 |
|---|---|---|
| 章节 | 5 章 + 附录（基本信息/团队/知产/融资/产品） | 7 章 + 附录（含财务、业务、风险评估独立章节） |
| 定位 | 公开信息初筛、快速背景调查 | 投资/并购级完整尽调 |
| 数据要求 | 纯公开渠道即可成稿 | 建议补充财报等一手材料 |
| 触发 | 说「**轻量版**」或默认 | 说「**基础版**」 |

两版均：六个板块自动分页、标题导航树（视图→导航窗格可直接跳转）、来源逐条可追溯。

## 三、数据可信保障

- **多源交叉校验**：企查查 / 爱企查 / 天眼查 / 启信宝等多平台轮询，关键字段至少 2 源
- **权威裁决**：上市公司公告 / NMPA 注册证 / 信用公示系统 > 商业平台 > 行业媒体
- **时间戳优先**：取最新变更记录并注明时点，多源差异并存标注不覆盖
- **用户截图兜底**：支持用户提供平台截图补数，标蓝 + 来源可追溯
- **无 API 也能跑**：不依赖任何开放平台付费接口，纯公开渠道 + 用户协作即可完成

## 四、使用方式

直接把公司名丢给 AI：

```
帮我做企业尽调：XX生物科技有限公司（极早期肿瘤筛查）
做个轻量版尽调：XX医疗科技有限公司
用基础版完整尽调：某公司
```

支持附加材料（财报、合同、工商资料、平台截图），AI 会整合进报告并标注来源。

## 五、适用场景

- 投资尽调 / 并购前评估
- 合作方、供应商、经销商背景调查
- IPO 前初步评估
- 行业研究中的企业深度分析

## 六、合规声明

报告基于公开可获取信息生成，不构成投资建议；所有「待核实」内容均明确标注，交易决策请以一手尽职调查与官方文件为准。
