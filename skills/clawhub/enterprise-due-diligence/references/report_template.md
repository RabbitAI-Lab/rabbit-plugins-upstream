# 尽调报告模板规范

## 概述

本报告模板基于两份参考报告设计：
1. 内部参考模板 A — 5章结构（基本信息→团队→知识产权→融资→产品）
2. 内部参考模板 B — 6章结构（增加风险清单 P0/P1/P2）

综合后采用 **7章 + 附录** 结构，覆盖法律、财务、业务三大维度。

## 报告结构

### 封面
- 企业名称（黑色大标题 24pt）
- "尽职调查报告"（#1A1A2E 深海军蓝 20pt）
- 报告日期、尽调类型、范围（黑色 11pt）

**目标**: 回答"这家公司是什么"

#### 1.1 公司基础信息
表格结构（2列）:
| 项目 | 内容 |
|------|------|
| 统一社会信用代码 | ... |
| 法定代表人 | ... |
| 成立日期 | ... |
| 注册资本 | ...万元 |
| 注册地址 | ... |
| 企业类型 | ... |
| 经营状态 | ... |
| 经营范围 | ... |

#### 1.2 股权架构分析
表格（4列）:
| 股东名称 | 持股比例 | 股东类型 | 认缴出资额 |

#### 1.3 实际控制人
- 明确实际控制人身份
- 如有代持、多层嵌套需说明

#### 1.4 历史沿革（可选）

### 第二章：核心团队画像
**目标**: 回答"谁在操盘"

- 团队完整度
- 核心人员背景质量

### 第三章：知识产权与专利
**目标**: 回答"技术壁垒在哪"

#### 3.1 专利分析

### 第四章：财务分析与税务情况
**目标**: 回答"账上怎么样"

#### 4.1 财务报表摘要
表格（2列）:
| 项目 | 期末余额（万元） |

#### 4.2 关键财务比率
表格（4列）:
| 比率名称 | 数值 | 参考值 | 评价 |

#### 4.3 税务情况
- 纳税状态
- 税收优惠

### 第五章：业务与市场分析
**目标**: 回答"这生意能赚钱吗"

#### 5.2 商业模式分析（AI自动生成）
- 收入来源

#### 5.3 市场与竞争分析（AI自动生成）

## 格式规范

### 字体
- 正文: 微软雅黑 11pt
- 标题H1（章节）: 微软雅黑 14pt 加粗
- 标题H2（小节）: 微软雅黑 13pt 加粗
- 表头: 微软雅黑 9.5pt 加粗
- 表格正文: 微软雅黑 9.5pt

### 颜色
- 章节标题(H1): #376092（深灰蓝）
- 小节标题(H2): #4F81BD（浅灰蓝）
- 正文: 黑色
- 表头背景: #0F3460（深蓝），文字白色
- 表格隔行: #F2F2F2（浅灰）

### 表格
- 表格宽度: 自适应
- 表头样式: 深色底色 + 白色文字
- 隔行变色: 偶数行浅灰背景

## Lite 模板（轻量版，5 章）

对应 `generate_dd_report.py --template lite`（**默认模板**）。定位：公开信息初筛 / 快速背景调查，纯公开渠道可成稿。与 7 章基础版的差异：无独立财务/业务/风险评估章节（风险以红色标注内嵌），无检查清单硬绑定。

### 报告结构

```
封面（公司名 42pt #1A1A2E 加粗居中 + "企业尽职调查报告" + 日期/类型/信息基准日）
目录（手写静态五章 + 附录）
一、公司基本信息与股权架构
    1.1 公司基础信息    两列「维度-信息」表（16+项：信用代码/法人/成立/注册/实缴/类型/地址/状态/期限/登记机关/行业/参保/资质/官网/联系方式）
    1.2 经营范围        正文说明段（10.5pt #444444）+ 来源注（9pt #888888）
    1.3 股权结构        股东明细表 + 实控人追溯 + 结构评述
    1.4 主要人员        人员表 + 人员变动风险（红色）
二、核心团队画像
    2.1-2.3 各成员      每成员一张「维度-信息」表（现任职务/教育背景/履历/与公司关系）
                        + 团队评估 + 口径差异提示（红色）
三、知识产权与专利
    3.1 知识产权总览    专利表（名称/类型/法律状态/时间）+ 数量口径说明 + 专利风险（红色）
    3.2 商标与资质      表（项目/内容/状态）+ 资质风险（红色）
四、融资历史与资本结构
    4.1 融资时间线      表（时间/事件/金额/来源）
    4.2 资本结构与融资要点  "融资要点" 14pt #0072C6 + 红色要点段
五、核心产品
    5.1 核心产品        产品分组多表（方向标题 13pt #0F3460）
    5.2 核心技术        正文说明段 + 技术限制注（红色）
    5.3 行业与市场      市场/竞争/规划正文 + 规划兑现【待验证】（红色）
附录：数据来源清单（9pt #4F81BD 编号列表）
免责声明（9pt #888888）
```

### 样式参数

| 元素 | 参数 |
|---|---|
| 封面公司名 | 42pt 加粗 #1A1A2E，居中 |
| 章/节标题 | 14/13pt 加粗 #1A1A2E，内置 Heading 1/2 样式（导航可用） |
| 正文 | 微软雅黑 11pt 黑色 |
| 表头 | 9.5pt 白字 #0F3460 底纹 |
| 融资要点标题 | 14pt 加粗 #0072C6 |
| 风险/待验证标注 | 10.5pt 加粗 #EE0000 |
| 正文说明 | 10.5pt #444444 |
| 产品方向标题 | 13pt 加粗 #0F3460 |
| 附录来源 | 9pt #4F81BD |
| 免责声明 | 9pt #888888 |
| 页面 | A4 21×29.7cm，四边距 2.5cm |
| 表格 | Table Grid，无隔行变色（zebra=false） |

### 板块分页
lite 版六个板块（一、二、三、四、五、附录）**各自从新页开始**：章节标题使用「段前分页」（pageBreakBefore，脚本 `_add_lite_chapter` 实现），不依赖显式分页符，内容增删后分页不漂移。封面→目录保留显式分页符（目录标题不设段前分页）。

### lite 数据结构约定（复用标准 schema + 以下扩展字段）

| 字段 | 说明 |
|---|---|
| `lite_basic_rows` | 可选，基础信息两列行 `[{维度, 信息}]`，缺省由 basic_info 自动构造 |
| `paid_in_capital` / `employee_count` / `company_qualifications` / `website` / `contact_phone` / `contact_email` | 基础信息补充项 |
| `lite_basic_note` / `lite_scope_note` | 9pt 灰色注释（口径说明等） |
| `lite_controller_note` / `lite_equity_comment` | 实控人追溯 / 股权评述段 |
| `lite_mgmt_note` | 人员变动风险（红色） |
| `team_profiles` | `[{title, dims:[[维度, 信息], ...]}]`，团队画像维度表 |
| `lite_team_note` | 团队口径差异提示（红色） |
| `lite_patents` / `lite_patent_note` / `lite_patent_risk` | 专利表 / 口径说明 / 专利风险（红色） |
| `lite_ip_rows` | 商标与资质表 `[[项目, 内容, 状态], ...]`；`lite_qual_risk` 资质风险（红色） |
| `financing`（复用） | `[{date, event, amount, source}]` 融资时间线 |
| `financing_notes` | 融资要点列表（红色） |
| `product_groups` | `[{title, headers, rows, widths}]` 产品分组表 |
| `core_tech` | 核心技术段落列表（10.5pt #444444）；`lite_tech_note` 技术限制注（红色） |
| `market_texts` | 行业与市场段落列表；`lite_plan_note` 规划兑现【待验证】（红色） |
| `data_sources`（复用） | 附录来源清单（9pt #4F81BD） |
