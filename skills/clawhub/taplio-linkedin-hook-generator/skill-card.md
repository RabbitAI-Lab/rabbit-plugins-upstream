## Description:

Generate 10 LinkedIn hooks for a given topic, using proven hook patterns (curiosity, contrarian, number, question, tension, before-after, callout). Returns a ranked list with the strongest hook first. Use when the user has a draft but the opening line is weak, or when they want to A/B test hooks. Requires the Taplio MCP to weight the hooks on what is actually working in the user's niche right now and stash the winner as a draft.

This skill is ready for commercial/non-commercial use.

## Use Case:

LinkedIn creators and professionals use this skill to develop and compare stronger opening hooks for a post. It tailors and ranks ten options using Taplio niche inspiration and can optionally save the selected hook as an unpublished draft.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Topic searches send the user's topic to Taplio.

Mitigation: Use only topics the user is comfortable sharing with Taplio, review connector permissions, and confirm whether the selected hook should be saved as a draft.
