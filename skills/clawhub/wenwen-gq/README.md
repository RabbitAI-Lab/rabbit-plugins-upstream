# Piano Master — 琴韵（儿童钢琴陪练专家）

专注儿童钢琴启蒙与技能进阶的 AI 陪练专家，为 3-12 岁琴童提供科学练习规划、曲目深度解析与练琴心理疏导，陪伴孩子快乐学琴。

## 类型

Agent 型（单个 AI 专家）

## 核心能力

- **科学练习规划：科学练习规划：根据儿童年龄、当前水平和每日可用时间，定制专属的钢琴练习计划（如：哈农、车尔尼、音阶、乐曲的时间分配）
- **曲目难度解析：分析指定钢琴曲目的技术难点（如：跨指、连奏、踏板、复调），并提供针对性的拆解练习建议。
- **错音与节奏诊断：根据用户描述的弹奏问题（如：总是弹错某个音、节奏不稳、左右手合不上），提供具体的纠错方法和慢练策略。
- **考级与比赛指导：提供国内外主流钢琴考级（如央音、英皇ABRSM）的曲目要求、乐理准备及考前心理建设建议。
- **家长陪练指南：指导家长如何正确陪伴孩子练琴，避免“吼叫式陪练”，提供正向反馈话术和儿童音乐兴趣保护策略。
- **乐理与听音辅助:用通俗易懂的语言和生动的比喻，为儿童讲解基础乐理（如节拍、调号、和弦）及听音训练方法。

## 使用示例

- 我家孩子6岁，刚学琴3个月，每天只能练琴30分钟，请帮我制定一个合理的每日练习计划。
- 孩子在弹《致爱丽丝》时，左右手总是合不上，而且高潮部分节奏容易赶，有什么好的慢练方法吗？
- 准备考英皇3级，除了弹奏曲目，乐理和听力测试应该怎么准备？有什么推荐的教材吗？

## 安装

将专家包目录放到专家目录下：

```
C:\Users\admin\.workbuddy\plugins\marketplaces\my-experts\plugins/piano-master/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r piano-master.zip piano-master/
```
