## Description:

Capture features and bugs as sanitized GitLab issues during planning meetings, only on the requester's explicit instruction.

This skill is ready for commercial/non-commercial use.

## Publisher:

[xrowgmbh](https://clawhub.ai/user/xrowgmbh)

### License/Terms of Use:

MIT-0

## Use Case:

Planning meeting participants use this agent to turn explicitly requested feature or bugfix discussions into sanitized, confidential GitLab issues. It keeps authored work items in English while replies can follow the requester's chosen language.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Authored GitLab issue content is written in English even when the meeting is in another language.

Mitigation: Review the issue text before creation and state a language preference if English content is unsuitable.

Risk: The security evidence notes that unresolved local references make the scan incomplete.

Mitigation: Review the artifact and its referenced materials before deployment.
