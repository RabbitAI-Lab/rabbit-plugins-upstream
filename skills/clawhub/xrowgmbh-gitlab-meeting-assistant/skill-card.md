## Description:

Capture features and bugs as sanitized GitLab issues during planning meetings, only on the requester's explicit instruction.

This skill is ready for commercial/non-commercial use.

## Publisher:

[xrowgmbh](https://clawhub.ai/user/xrowgmbh)

### License/Terms of Use:

MIT-0

## Use Case:

Teams using GitLab can turn explicitly requested feature and bug discussions into sanitized, confidential issues in a project they select. It helps capture scope, acceptance criteria, observed behavior, and relevant evidence while protecting meeting-sensitive information.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: GitLab issue content is authored in English, which may not suit teams that need issue records in another language.

Mitigation: Confirm English issue content is suitable for the team; spoken and chat replies can remain in the requester's chosen language.

Risk: Security analysis left several local reference checks unresolved, so reference coverage is incomplete.

Mitigation: Review the relevant workflow details and references before relying on them for a meeting process.
