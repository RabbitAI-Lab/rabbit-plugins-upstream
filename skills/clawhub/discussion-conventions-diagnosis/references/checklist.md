# Conventions Checklist — Discussion 学术规范逐条检查清单

## 使用方法
按顺序检查每一项，✓ 通过，✗ 缺失，⚠ 弱。

---

## Section 1: Contribution Type（贡献类型）

- [ ] 显式 claim 1+ 种 contribution type（method / results / impact / application）
- [ ] Contribution claim 具体（不是 generic "We contribute to..."）
- [ ] Contribution 与本研究内容匹配
- [ ] Happy words 与 claim 强度匹配

## Section 2: Happy Words（Happy Words 恰当性）

- [ ] Happy words 适度（每 Discussion 2-3 个）
- [ ] Happy words 不堆叠在同一段
- [ ] 没有 "groundbreaking" / "revolutionary" 等极端词
- [ ] "novel" / "first" / "unprecedented" 适度

## Section 3: Achievement-Contribution Distinction（成就与贡献区分）

- [ ] Achievement（做了什么）有描述
- [ ] Contribution（对 field 价值）有描述
- [ ] 两者清晰分工
- [ ] 不是混在一起

## Section 4: Limitations Completeness（局限性完整性）

- [ ] 至少有 1 个具体 limitation
- [ ] 多个 limitations 时有序组织
- [ ] Limitation 类型多样（sample / design / measure / generalisability）
- [ ] 部分 limitations 是否有反驳证据（如果有则更好）
- [ ] 不是 pure self-flagellation

## Section 5: Future Work Specificity（未来方向具体性）

- [ ] Future work 包含 what / where / method / variable
- [ ] Future work 与 limitations 对应
- [ ] 不是 "more research is needed" 单独成句
- [ ] Future work 是 directional

## Section 6: Operational Specificity（操作具体性）

- [ ] Recommendation 是 operational
- [ ] 不是 "researchers should be careful" 等 abstract
- [ ] Operational 包含具体 verb + object + method
- [ ] Conditional recommendation（"if you encounter X, do Y"）

## Section 7: Anti-Pattern Check（反模式）

- [ ] ❌ 完全无 limitations 段
- [ ] ❌ "Our study has limitations" 单独成段
- [ ] ❌ "We contribute to the field" 无具体内容
- [ ] ❌ "We hope this research will inspire..."（"hope" 非学术）
- [ ] ❌ "More research is needed" 单独成句
- [ ] ❌ Happy words 堆叠（"novel groundbreaking unprecedented"）

---

## 严重度判定

| 缺失项数 | 严重度 |
|---|---|
| 0-2 | Minor |
| 3-5 | Major |
| 6+ | Critical |
