# Demo: Rainy Day

用户：

```text
杭州明天下雨，我一个人，下午想出去但不想折腾。
```

输出：

```markdown
方向版：当前只有“明天下雨”这一条用户信息，先裁决室内单点，别赌户外景区。

主线：一个能坐下、无需多次转场的室内文化空间
为什么：一个人出门最怕雨天转场多；单点路线能坐下，也能随时撤；雨停再加一小段散步。
预计：2-3 小时 / 60-150 元 / 低体力
风险：营业时间、是否预约、雨势要出门前确认。

备胎 A：离家 20-30 分钟内的商场书店。
备胎 B：一家安静咖啡馆，坐满 80 分钟。

别去：西湖长线步行、山路、露天市集、需要打车转场的路线。

出门前检查：降雨雷达 / 营业时间 / 预约 / 回程打车或地铁。

证据缺口：没有当前日期、出发城市和网页能力，暂不落到具名地点。

截图句：下雨天想出门，核心动作只有一个：找个能坐下的地方。
```
