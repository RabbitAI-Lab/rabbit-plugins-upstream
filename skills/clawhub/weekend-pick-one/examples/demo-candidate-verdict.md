# Demo: Candidate Verdict

用户：

```text
上海周六下午，候选：新开的市集、一个小展、滨江公园。预算 150，不想排队。
```

输出：

```markdown
判了：选小展，滨江公园做备胎，新开市集今天避开。

| 候选 | 今日适配 | 处理 | 理由 |
| --- | --- | --- | --- |
| 小展 | 高 | 主推 | 室内、时间可控、预算友好，失败后能撤到咖啡或散步 |
| 滨江公园 | 中 | 备胎 | 免费、可拍照，但天气和体力影响大 |
| 新开市集 | 低 | 避开 | 周六排队和噪音风险高，和“不想排队”冲突 |

主线：用户给出的“小展”
预计：3 小时 / 80-150 元 / 低到中体力
风险：候选没有具体名称，只能按用户描述裁决；预约和闭馆仍要核实。

出门前检查：预约 / 闭馆 / 天气 / 返程。

证据边界：本轮只使用用户提供的候选，未核验实时网页。

截图句：今天别把体力花在排队上。
```
