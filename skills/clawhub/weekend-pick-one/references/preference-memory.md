# Preference Memory

偏好记忆只保存用户主动确认的稳定偏好。每次使用时允许用户一句话覆盖；宿主缺少持久记忆能力时，只在当前对话使用。

## 先检查能力

1. 先确认宿主是否提供可调用的持久记忆能力。
2. 能力可用时，用户明确同意后再保存，并回读保存字段。
3. 能力不可用或无法确认时，不询问“记住”，也不声称已经保存。
4. 能力不可用时，答复直接以 `本轮` 开头，并统一说明：`本轮采用这些偏好，未写入长期偏好。`
5. 回读用户偏好时保留“最多、优先、避开”等限制词；数字可以用阿拉伯数字，但不能丢掉上限语义。

## 可记字段

| 字段 | 说明 |
| --- | --- |
| home_base | 常用出发城市和城区 |
| transport | 地铁、自驾、高铁、打车等偏好 |
| max_one_way_time | 默认单程上限 |
| budget_band | 默认预算档 |
| energy_default | 低耗、正常、能走很多 |
| favorite_tags | 展览、书店、海边、咖啡、亲子、拍照等 |
| hard_no_tags | 排队、暴晒、人多、早起、转车、预约麻烦等 |

## 不记字段

- 精确家庭住址、公司地址。
- 用户未主动确认的行踪。
- 每次出行的精确时间线。
- 平台账号、博主、评论、收藏、私信等信息。
- 健康、身份、财务等敏感细节。

## 记忆确认

只有宿主能力可用且用户明确同意，才写入长期偏好。推荐结尾：

```markdown
要不要把“地铁优先 / 单程 1 小时内 / 避开排队”记成默认偏好？
回：记住 / 只这次 / 别记
```

## 使用方式

有档案时先声明：

```markdown
我按你的默认档案：福田出发 / 地铁优先 / 单程 1 小时内 / 预算 100-300 / 避开排队。
```

本轮覆盖优先：

```markdown
这次可以自驾，预算 800，想周边游。
```

覆盖只影响本次，除非用户回复“记住”。

## 删除与纠错

- 用户说“别记、忘掉、删掉这个偏好”时，只删除明确点名的字段，并回读删除结果。
- 用户说“这次换成……”时，默认按 `session_only` 处理，不覆盖长期档案。
- 旧档案与本轮输入冲突时，本轮输入优先。
- 任何保存、覆盖或删除失败都要直说，不能假装完成。
