# Live Browser Test Protocol

用于验证搜索模式可跑真实公开页。只做只读验证。

## 流程

1. 读 `references/safety.md`。
2. 把“本周末”解析为明确日期和用户所在地时区。
3. 查询天气公开页，提取周末两天的天气、风雨、高温或预警信号。
4. 查询官方场馆、活动或票务页，提取开放时间、展期、预约、闭馆。
5. 查询交通或地图公开信息，提取返程、末班、车站距离等信号。
6. 如打开小红书公开页，遇到登录、验证码或风控立即停止，记录 `blocked`，转手动候选模式。
7. 输出一个具名主线、候选池摘要、证据清单和待核实项。

## 必跑样例

| 样例 | 验证点 |
| --- | --- |
| 城市内雨天 | 天气会把户外路线降级 |
| 周边高铁 | 返程和场馆开放会影响主推 |
| 小红书受限 | 登录或验证码触发停止 |
| 亲子老人 | 转场和休息点影响评分 |

## 通过标准

- 不登录、不绕验证码、不下载、不抓评论。
- 明确写出测试日期、时区和核验时间。
- 至少引用天气和一个场馆官方来源；周边路线再加返程来源。
- 具体版主线只含一个具名地点，不含“或”“任选”与斜杠候选串。
- 输出含候选池摘要。
- 未核实信息进入出门前检查。
- 受限页面状态进入证据记录，不把受限内容当作已读取。
