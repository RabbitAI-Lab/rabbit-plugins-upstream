# Regional Trip Policy

用于周边游、高铁一日往返、自驾、跨城半日和近郊路线。

## 周边游硬门槛

周边档进入主推前，必须检查 5 项：

| 门槛 | 通过条件 | 失败处理 |
| --- | --- | --- |
| 返程 | 有可核实返程车次、末班车、打车或自驾回程余量 | 降级城市内 |
| 天气 | 无暴雨、台风、山洪、强风、极端高温等强风险 | 改室内或降级 |
| 交通 | 高铁/自驾/城际总耗时符合单程上限 | 只作备胎 |
| 同行人 | 老人、儿童、低体力同行能承受转场 | 改近场或单点 |
| 退路 | 到达地有室内、咖啡、商场、车站等撤退点 | 降级或避开 |

任一硬门槛失败，不主推周边档。

## 自驾检查

- 停车可达性。
- 雨天路况和返程疲劳。
- 山路、水边、海边、施工路段。
- 酒店或临时休息点。
- 司机体力。

## 高铁检查

- 往返票都有余量。
- 进站、安检、候车、出站时间加入交通摩擦。
- 目的地到场馆的最后一段交通。
- 晚归风险和改签余量。

## 雨天周边

雨天周边只主推室内或强退路路线：

- 博物馆、展馆、书店、商场、室内街区。
- 高铁站到目的地转场短。
- 不主推海边、山里、古镇露天长走、市集。

## 对外输出句式

```markdown
近处和周边也看过：周边路线通过返程和天气检查，可以进主推。
```

```markdown
近处和周边也看过：周边路线因暴雨和返程不稳降级，今天留在城里。
```

候选数量继续写入结构化字段 `candidate_pool_summary`，正文不展示机械计数。
