# Escape Fit Score

用 Escape Fit Score 判断“今天最适合”，不要按热度排序。

## 输入字段

| 字段 | 说明 |
| --- | --- |
| city | 城市或大致区域 |
| home_base | 出发城市和城区 |
| time_window | 可用时间，例如 3 小时、半天、周六下午 |
| radius | 最长单程交通时间 |
| budget | 总预算 |
| transport | 地铁 / 自驾 / 高铁 / 打车 |
| energy | 低 / 中 / 高 |
| weather | 晴 / 雨 / 热 / 冷 / 未知 |
| companion | 独处 / 朋友 / 伴侣 / 亲子 |
| desired_feel | 拍照 / 放空 / 安静 / 新鲜感 / 轻社交 |
| hard_no | 明确避开项，例如排队、暴晒、跨城、强社交 |
| decision_load | 用户愿意自己选择的程度；`随便` 代表低选择负担 |
| travel_scope | 距离胃口：近场 / 城市内 / 周边 / 开放 |

## 评分维度

每项 0-5 分，5 分代表适配度更高。所有维度都按“适配”正向计分，避免把“摩擦高”误写成高分。

| 维度 | 观察信号 | 低分触发 |
| --- | --- | --- |
| 时间适配 | 来回交通、排队、预约、闭馆 | 单程超半径、强预约、排队不确定 |
| 体力适配 | 噪音、社交、步行、转场 | 吵、久站、换乘多、活动密集 |
| 预算适配 | 门票、餐饮、打车、隐藏消费 | 预算被门票或打车吃掉 |
| 天气适配 | 室内外、暴晒、下雨、寒风 | 高温暴晒、雨天室外、湿滑路线 |
| 人流适配 | 网红度、周末高峰、热门活动 | 新开、市集、限时展、节假日 |
| 退路质量 | 附近咖啡、书店、公园、地铁 | 不好玩时难撤、周边空 |
| 记忆价值 | 照片、故事、轻微新鲜感 | 纯通勤、无可记点 |
| 用户适配 | 与独处/拍照/放空/同行需求匹配 | 与用户状态冲突 |

## 权重

默认权重：

```json
{
  "time_fit": 1.2,
  "energy_fit": 1.4,
  "budget_fit": 1.0,
  "weather_fit": 1.0,
  "crowd_fit": 1.3,
  "retreat_quality": 1.5,
  "memory_value": 0.8,
  "user_fit": 1.6
}
```

动态调整：

- 用户体力低：体力适配、退路质量权重 +0.4。
- 时间小于 4 小时：时间适配、退路质量权重 +0.3。
- 明确想拍照：记忆价值 +0.3，但拥挤风险同步检查。
- 下雨或高温：天气适配 +0.5，室内候选优先。
- 用户独处：安静、可撤退、低社交候选优先。
- 预算低：预算适配 +0.4，隐藏消费必须点明。
- 自驾：停车、雨天路况和返程疲劳进入时间适配。
- 高铁：班次、进出站时间和返程票进入时间适配。
- 地铁：步行换乘、雨天出站距离进入体力适配。
- decision_load 低：减少展示候选数量，不改变距离、预算、体力权重。
- travel_scope 周边：读取 `regional-trip-policy.md`，返程、天气、交通、同行人、退路任一硬门槛失败时降级。

## 裁决规则

- 热度高但适配低：列入别去或工作日再去。
- 分数接近时选退路质量更高的候选。
- 候选证据不足时不要编细节，标记“待核实”。
- 最高总分如存在硬风险，降级为备胎或避开。
- 最终答案说“今天适合什么”，不要展开十个选择。

## 分级

| 分数 | 结论 |
| --- | --- |
| 4.3-5.0 | 今天适合，直接主推 |
| 3.6-4.2 | 可去，但要核实关键风险 |
| 2.8-3.5 | 只适合顺路或备胎 |
| 0-2.7 | 今天避开 |
