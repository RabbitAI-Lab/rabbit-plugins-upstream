# XHS Web Safe Search

小红书只作灵感源。执行时严格限制在用户主动触发的一次性公开搜索。

## 可读信号

- 地点名或区域。
- 活动类型。
- 室内/室外。
- 时间成本、排队、预约、拥挤风险。
- 适合独处、拍照、放空、朋友、亲子等泛化场景。
- 避雷信号：排队久、周末人多、强消费、天气不友好。

## 不读不存

- 博主身份和账号信息。
- 评论区内容。
- 点赞、收藏、粉丝等互动数据。
- 图片、视频、封面。
- 原文长句。

## 查询策略

先用状态词找适配，再用反向词查风险：

1. `{城市} {明确日期} 半天 不累`
2. `{城市} 一个人 散步 放空`
3. `{城市} 室内 小众展 不排队`
4. `{城市} 周末 别去`
5. `{地点} 排队 预约`

## 输出限制

不要说“小红书上都说”。改成：

```text
公开灵感里反复出现的风险信号：周末拥挤、需要预约、排队不确定。
```

若无法访问或需要登录：

```text
这部分需要你手动给 3-5 个候选，我可以直接判哪个更适合今天。
```

同时把 `public_inspiration` 标为 `blocked`，记录核验时间；不要继续登录，也不要把搜索框或遮罩后的内容当作候选。
