# Manual Candidates

用户给 3-5 个地点名或链接时，直接进入候选裁决模式。

## 输入模板

```markdown
城市：
出发地：
时间：
预算：
交通：
单程上限：
体力：
同行：
候选：
1.
2.
3.
硬避开：
```

用户随口给材料时无需强制补全。城市或出发地缺失时优先补问；其余情况最多补问一个高价值字段。

## 快速裁决

对每个候选给 4 项：

| 字段 | 说明 |
| --- | --- |
| 今日适配 | 高 / 中 / 低 |
| 主要理由 | 与时间、体力、预算、天气、退路相关 |
| 风险 | 排队、预约、交通、天气、消费、安全 |
| 处理 | 主推 / 备胎 / 顺路 / 避开 |

## 输出

先给排名：

```markdown
判了：选 2，1 做备胎，3 今天避开。
```

再给简表，最后给出门前核实项。
