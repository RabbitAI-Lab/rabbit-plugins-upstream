# Generic Web Search Adapter

用于非小红书公开搜索，例如官方场馆页、地图、天气、票务、城市活动页。

## 优先级

1. 当地气象部门或权威天气服务。
2. 官方场馆、活动方或政府页面。
3. 交通运营方、铁路或地图信息。
4. 官方票务或预约页面。
5. 公开灵感页。

## 交叉核实

公开灵感页负责发现候选，官方和实用页面负责核实：

- 营业 / 闭馆。
- 票价 / 预约。
- 室内外。
- 交通和返程。
- 天气风险。

## 输出标签

| 标签 | 含义 |
| --- | --- |
| 已核实 | 已从官方、地图、票务或天气交叉确认 |
| 待核实 | 只来自灵感页或搜索摘要 |
| 能力受限 | 页面打不开、要求登录或当前没有浏览器能力 |

未核实信息不能写成确定事实。

所有“已核实”事实都要保存来源 URL、核验时间和支持的判断；搜索摘要只能帮助定位原始页面，不能单独支撑营业、票价、展期或返程结论。
