## Known Risks and Mitigations:

Risk: The skill requests broad command, file-write, and external-service authority without concrete boundaries.

Mitigation: Use it only in a constrained project workspace and require confirmation before shell commands, file writes, or outbound service calls.

Risk: The included WCAG checker examples do not prove full accessibility compliance.

Mitigation: Treat generated checks as guidance and validate accessibility with human review plus established tools such as axe, WAVE, or Lighthouse.
