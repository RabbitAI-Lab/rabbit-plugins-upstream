# 通道矩阵（Channel Matrix）

> 每条盲区/置信度标注均来自 2026-08 企业版 PR 监测实战，非推测。选择通道前先查此表。

## 通道总览

| 通道 | 工具/查询式 | 适用场景 | 已知盲区（实测） | 结论置信度 |
|---|---|---|---|---|
| **百度搜索** | `baidu_search.py`（媒体名+主题 / 媒体名+独特长句） | **中文站核验必备通道**，盲区站点以此为准 | 中转链接需解析；只解析首页结果 | 高 |
| Google News RSS | `gnews_query.py`（含 `--site` 定向 + `when` 窗口） | 新闻索引、通稿站定向 | donews/qianlong/prnews.techweb/chinadaily **不索引**；对通稿小站覆盖不全（实测 4/7） | 中 |
| WebSearch | 标题/关键词/独特片段多波查询 | 通用发现、海外内容 | **对中文通稿小站结构性失效**——site: 限定+点名媒体都捞不出（7 家实测全灭）；只重复返回头部站点 | 中低（发现环节） |
| 搜狗微信 | weixin.sogou.com 关键词检索 | 公众号生态（预热稿/参会稿/KOL 稿） | 验证码拦截风险（重试或降级）；官方大号可能未被收录 | 中 |
| 媒体池路线 B | curl/WebFetch 抓频道列表页 + 指纹 grep | 已知小站定向（GNews 不索引的） | 只覆盖近 1-2 页（时效窗约 1 周） | 中高 |
| 已知 URL 直抓 | WebFetch / curl+UA | **验证环节**（发现之后的确认） | 基本无障碍（7/7）；个别站需 curl+UA 绕 WebFetch 拦截 | 高 |
| GDELT + GNews EN + HN | API 查询 | 海外报道 | — | 高（零报道结论可信） |

## 通道选择决策

```
任务类型？
├─ 存在性核验（某内容发没发）
│   └→ 已知目标媒体：GNews site:（快）→ 0 条 → 百度（必备）→ 仍 0 → 待核验
│   └→ 未知渠道：WebSearch 多波 + 百度 + 搜狗微信（公众号）
├─ 全量转载追踪
│   └→ 以稿搜稿（独特片段×5-10）全通道 → 媒体池三路定向 → 逐条三要素验证
├─ 首发溯源
│   └→ 时间最早的验证条目 + 正文来源标注链（如"来源：东方网"）
└─ 提及扫描
    └→ 主体名+事件锚点查询，提及≠转载，单独分层
```

## 盲区实证档案（2026-08 campaign）

| 案例 | 通道表现 | 教训 |
|---|---|---|
| **中国日报网排期稿** | GNews site: 0 条、chinadaily 官方站内搜索 API 0 条、WebSearch×2 全灭、首页/频道 grep 0 命中——**百度第一条即中** | 通道盲区 ≠ 事实不存在；把"免费检索通道暂未收录"写成结论 = 搜索质量事故 |
| 7 家通稿转载站（飞象/DoNews/科技讯/千龙/Techweb/砍柴/品玩） | WebSearch 全灭；GNews 4/7；已知 URL 直抓 7/7 | 瓶颈在"发现"不在"验证"——媒体池定向扫描是解法 |
| 科技讯 / Techweb | WebFetch 失败，curl+UA 成功 | 抓取被拦截时换栈，不下环境结论 |
| 搜狗微信（点火三周参会稿） | 返回 VerifyCode 页面 | 验证码拦截置信度降级，不重试超过一次 |
| icloudnews 直链 | cookie 墙拦截 | GNews 索引页替代举证；后续百度通道解析出直链 |
| 自有渠道公众号通稿首发 | 全通道无证据 | 无三要素证据连自有渠道也不能写已发布（推断条目已删） |

## 各站抓取姿势备忘

| 站点 | 有效姿势 |
|---|---|
| chinadaily.com.cn | 站内搜索 API 无效，走百度 |
| kejixun.top / prnews.techweb.com.cn | WebFetch 失败，curl + 浏览器 UA |
| 163.com / sohu.com | WebFetch 直抓可验证；sohu 的 `og:release_date` meta 可取发布时间 |
| 搜狗微信 | 关键词检索页；中转链接为双层临时签名（搜狗签名 + 微信 src=11 签名），微信侧数小时过期——仅可用于核验期内的内容读取，**不得作为交付物链接**（永久链接只有微信客户端生成的短链 `/s/xxx` 或带 sn 长链；搜狗来源页 `var sn` 为空无法自动构造） |
| csdn / yesky / cctime / pingwest / ikanchai | WebFetch 直抓可验证 |
