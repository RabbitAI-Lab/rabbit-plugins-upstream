## Description: <br>
Helps software maintainers, QA engineers, open-source contributors, and product teams add useful unit tests, raise test coverage, and check regressions in existing codebases. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, QA engineers, maintainers, and product teams use this skill to plan, implement, and verify unit tests and coverage improvements for existing codebases. It produces practical local workflows, checklists, code-oriented guidance, and verification notes that help reduce regression risk. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate for broad testing, regression, or quality requests. <br>
Mitigation: Install it only when this behavior is desired, and confirm that the request is actually about unit testing or coverage before following its workflow. <br>
Risk: Generated test plans, code changes, or shell commands may not match the target repository's conventions or behavior. <br>
Mitigation: Review proposed changes, run the repository's normal test and coverage commands, and treat verification notes as required before merging. <br>
