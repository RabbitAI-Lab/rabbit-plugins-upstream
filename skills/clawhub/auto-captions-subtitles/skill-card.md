## Known Risks and Mitigations:

Risk: Media submitted for editing may contain content the user should not share with an external service.

Mitigation: Only submit media you are authorized to share with the Levea editing service.

Risk: Exposure of the required LEVEA_API_KEY could allow unauthorized use of the editing service.

Mitigation: Store the API key in plugin or MCP configuration or a secret store, and keep it out of prompts and shared content.
