Mitigation: Use only approved assets, confirm upload intent before generation, and avoid submitting private product or personal media unless the user accepts AI-HIVE processing.

Risk: The skill can use a stored AI-HIVE API key and potentially billable routes.

Mitigation: Keep API keys local, protect the configuration file, and confirm high-cost or batch generation tasks before submitting them.

Mitigation: Require confirmation before uploads, generation tasks, or other actions that use stored credentials or consume paid service credits.
