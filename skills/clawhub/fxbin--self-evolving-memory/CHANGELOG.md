### v8 设计方向（草案，未实施）

经多专家圆桌讨论（Skill Architect / Cognitive Science Researcher / Product Strategist / Software Architect / Agent Runtime Engineer / Maintenance Skeptic）沉淀的设计层面洞察，作为后续 major 版本方向，当前 v7.x 不实施：

1. **遗忘协议（最高优先级设计缺陷）**：当前可演化区仍以追加为主（growth-journal、日记持续新增，叶节点 30 天归档但不删；SOUL.md 自 v7.3 起在巩固中保持字节不变）。神经科学的巩固同时是强化与遗忘（突触修剪），本系统只实现了强化半边。半年后 recent_memory/ 会膨胀，索引与检索可能退化。v8 应新增"模块零：遗忘协议"，定义 30/90/180 天分级降级与删除规则。

2. **Framework 定位重新审视**：13 模块 + 20+ 状态文件 + SKILL.md 8KB+ 的体量，超出了 skill 的合理契约边界（同类 mentor skill 4-5KB）。self-evolving-memory 本质是 agent runtime layer / framework，当前打包成 skill 是分发需要。v8 应考虑：①核心 skill 只保留模块 1-5（存储+巩固+晋升+冷却+自我指涉），模块 6-13 作为"增强包"按需启用；或 ②显式标注为"framework 级 skill"单独治理。

3. **自指承诺过载**：系统名叫"self-evolving"但 Agent 不能改 SOUL.md、不能改模块定义、只能在预设字段填值——这是"填表格"不是"自进化"。v8 应：①诚实命名（候选：`layered-memory-engine` 或 `agent-memory-framework`）；②显式化可演化边界为三层（硬边界=核心身份与模块定义不可改 / 软边界=阈值与切片数可证据驱动调整 / 开放区=记忆内容完全自主）。

4. **模块平级是假象**：6 个模块（模块九十十一十二十三 + 微巩固）在实际 LLM 执行下会被跳过——Agent 上下文有限，会优先跑核心存储与巩固。"平级模块"的目录结构暗示"全部必须"，应改为"核心 + 可选增强"分层。

### v7 · 2026-07-16 · 回忆侧双引擎升级（证据账本 + 回忆规划器）

**新增模块十二：证据账本（Evidence Ledger）**

借鉴 HMS 全息记忆系统的 Evidence Ledger 机制，在回忆结果注入 LLM 之前增加结构化整理层。回忆侧的输出层，不改动存储架构。

**6 类证据标签**：
1. **时间锚定**：区分事件时间/记录时间/验证时间，相对日期转精确区间
2. **来源分级**：一手观察/工具返回/用户口述/逻辑推导，四级可信度
3. **数值校准**：标注精度、不确定度和缺失侧，防止瞎猜
4. **状态仲裁**：多版本冲突时标注版本、置信度和覆盖关系
5. **计数去重**：合并同一事件的多次提及，区分计划/已完成/已取消
6. **跨源交叉**：多源一致的信息标记为已验证，提升可信度

**输出格式**：结论 + 支撑证据列表（每条带标签） + 待验证项 + 冲突标记

**新增模块十三：回忆规划器（Recall Planner）**

借鉴 HMS 全息记忆系统的 Recall Planning 机制，在检索前增加问题拆解和检索规划步骤。检索前的解析层，替代"拿到问题直接搜"的模式。

**四维问题解析**：
1. **时间范围解析**："最近""上次""之前"等模糊表述转换为精确日期窗口
2. **实体识别**：识别人物/项目/事件/工具/概念五类关键实体
3. **问题类型判定**：事实查询/模式回顾/决策参考/创作灵感/复盘分析，五类匹配不同检索策略
4. **精度需求**：快速确认/详细复盘/完整追溯，三档控制检索深度

**自检闭环**：初步检索后判断是否需要二次检索——信息不足/有冲突/缺关键维度/精度不匹配/时间范围偏差时触发，最多2轮补救，防止无限循环。

**回忆侧双引擎协作**：回忆规划器（检索前拆解+规划）→ 执行检索 → 证据账本（检索后整理+标注）→ LLM 回答。一前一后，各司其职。

### v6 · 2026-07-15 · DPM 启发的动态分层记忆增强

**新增模块十一：DPM 启发的动态分层记忆增强**

参考 DeepTutor 论文的 Dynamic Personal Memory (DPM) 机制，将记忆系统从"静态分层+定时巩固"升级为动态自适应系统。

**5 大核心机制**：

1. **三层 Trace Forest 分层记忆**：事件记忆从扁平列表升级为三层森林结构——散点事件(叶节点)→主题线索(枝干)→认知跃迁(主干)，每层有不同的保留策略和检索权重
2. **三专门 memory agent 提炼**：在记忆巩固守卫中增加三个专门提炼角色——因果侦探（挖因果链）/模式猎手（找重复模式）/边界测绘员（标记已知与未知边界）
3. **证据门控状态转换**：为记忆晋升增加证据门槛——不是到时间就升，而是累积到足够交叉验证证据（权重≥3.0）后才晋升，证据不足的标记为"待验证"而非直接删除
4. **角色化记忆切片**：在 USER.md 之外新增角色化记忆切片机制——按"决策者/学习者/执行者/创作者"四大角色维度分别存储行为模式和偏好，检索时按当前任务角色激活对应切片
5. **事件驱动微巩固**：在原有每日凌晨大巩固基础上，增加事件驱动的轻量巩固——重大事件（连续打破/连续失败/认知跃迁等）发生后立即触发，不等凌晨批量处理
