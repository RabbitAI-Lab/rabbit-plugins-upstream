## 这套系统是什么

这是一套以本地文件为状态真相源的 Agent 记忆操作协议。Host 提供调度器时可定时巩固，提供 `memory_search` 时可做语义检索；能力缺失时使用手动调度与本地白名单检索，不声称后台自动运转。

**v1 → v7 迭代历程**：从基础三层存储起步 → 加入自我指涉 → 加固守卫与回滚 → 引入事件因果图谱与主题索引 → 加入检索校验回路与主动探索 → 落地 DeepTutor DPM 动态分层增强 → 引入 Shadoweave HMS 证据账本与回忆规划器。每一步都来自真实使用中的问题，详细记录见根目录 `CHANGELOG.md`。

## 为什么选它

| 维度 | 大多数记忆技能 | 自进化记忆系统 |
|------|--------------|--------------|
| 形态 | 单一提示词模板 | 带初始化、事务巩固、检索与恢复契约的 local-first skill |
| 验证 | 仅结构检查 | 路由 eval + 安全/事务契约回归；真实效果仍取决于 Host 能力与部署数据 |
| 架构 | 单层/简单分类 | 三层存储 + 两大索引 + 回忆侧双引擎，共 13 大模块 |
| 学术来源 | 通用概念 | 融合 DeepTutor DPM、Shadoweave HMS、神经科学分层记忆理论 |
| 安全性 | 无防护 | 记忆巩固守卫 + 快照回滚，防止自我改写失控 |
| 依赖 | 强绑定外部数据库 | 核心状态本地；Calendar 与 memory_search 为可选 Host 能力并有降级路径 |
