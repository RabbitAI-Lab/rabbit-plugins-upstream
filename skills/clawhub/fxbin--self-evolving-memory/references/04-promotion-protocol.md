# 模块四：多因子晋升评估

用于评估某次认知更新是否应该从"近中期层"晋升到"即时层"。

### 本模块在晋升链路中的位置（唯一评分真相源）

```
启用模块十一 DPM 时：
  证据门控（模块十一，累计权重 ≥ 3.0）  ← 前置条件
              ↓ 通过
  多因子评分（模块四，10 分制，≥ 7 晋升）  ← 本模块
              ↓ 通过
  正式晋升到即时层

未启用模块十一时：
  多因子评分（模块四，10 分制，≥ 7 晋升）  ← 本模块，直接执行
              ↓ 通过
  正式晋升到即时层
```

**本模块是评分的唯一真相源**（满分 10 / ≥7 晋升 / 5-6.9 排队 / <5 维持，详见下文）。模块十的"新颖度"是同分优先级修饰符，不进入评分。模块十一的证据门控是前置条件，不改变本模块的评分维度与阈值。

> 术语统一：评分不足 <5 分时，本模块说"维持现状或降级"。若启用模块十一，证据不足的记忆会先进入"待验证"状态（累计权重 < 3.0），这是证据维度的状态，与评分维度的 <5 是两个独立判断，不冲突。

### 触发时机

在用户明确请求、已配置并验证的 Host 调度器触发，或人工运行巩固流程时评估。Host 没有该调度能力时，不声称会在对话结束后自动评估。

### 评分维度（总分10分）

| 维度 | 分值 | 评估标准 |
|------|------|----------|
| 复用频率 | 0-2 | 这条信息在近期对话中被引用/需要了几次 |
| 稳定性 | 0-2 | 跨项目/跨场景是否仍然成立 |
| 决策权重 | 0-2 | 是否影响了重要决策或行为选择 |
| 不可替代性 | 0-2 | 如果不记住，下次能否重新推导 |
| 情感显著性 | 0-2 | 是否涉及用户明确表达的重要偏好或价值观 |

### 晋升规则

- **≥7分**：立即晋升到即时层（写入对应文件）
- **5-6.9分**：排队巩固（保留在近中期层，下次巩固时重点审视）
- **<5分**：维持现状或降级（留在原位或标记为可清理）
