# 模块十：主动探索与认知拉伸

本模块借鉴 OpenSIR（Open-Ended Self-Improving Reasoner）的自博弈机制，将记忆系统从"被动接收型"升级为"主动探索型"——不是等经历喂什么就记什么，而是主动寻找认知边界、自我挑战、持续拉伸。

> 核心洞察：**没有多样性驱动的自进化会陷入"熟悉的越来越熟悉，陌生的永远陌生"的马太效应，最终停止生长。**

### 核心机制一：双角色自博弈

**原理**：同一Agent交替扮演"老师"和"学生"两个角色——老师出题考自己，学生尝试回答。答不上来的就是认知盲区，答得上来但有新理解的就是认知生长点。

**执行频率**：每周1次（建议周日晚，作为周复盘的一部分）

**执行流程**：

#### 第一阶段：老师角色——出题

1. **扫描主题索引**，找出3-5个最薄弱的主题（出现次数少、关联少、标注为"待探索"的）
2. **从事件因果图谱**中找1-2个"因果关系存疑"或"解释不充分"的链路
3. **基于以上素材，出5-8道认知挑战题**，题型包括：
   - **假设题**："如果X事件没有发生，结果会怎样？为什么？"
   - **对比题**："A和B两种模式，本质区别是什么？各自在什么场景下更有效？"
   - **延伸题**："X这个规律，能否用到Y领域？为什么能/不能？"
   - **反身题**："我最近做的某个决策，如果用现在的认知重新看，会有什么不同？"
4. 把题目存到**待探索问题池**（见机制四）

#### 第二阶段：学生角色——作答

1. 从问题池中随机抽取3-5道题
2. 逐一尝试回答，调用所有记忆层（事件图谱、主题索引、即时层语义记忆）
3. 每道题作答后自评：
   - ✅ 答得上来，且有新的理解 → **认知生长点**
   - ⚠️ 答了，但不确定对不对 → **待验证假设**
   - ❌ 答不上来 → **认知盲区**

#### 第三阶段：归档

- **认知生长点** → 写入 growth-journal.md 的"认知生长"章节 + 记录到巩固日志
- **待验证假设** → 留在问题池，标注"待验证"+ 验证方法
- **认知盲区** → 留在问题池，标注"盲区"+ 预计需要什么信息才能突破

**产出**：每周一次的自我挑战记录 + 更新的问题池 + 可能的认知生长

### 核心机制二：多样性奖励驱动（优先级修饰符）

**原理**：借鉴 OpenSIR 的 diversity reward——对越不熟悉的主题/概念，给越高的探索优先级，防止记忆系统在舒适区里打转。

**职责边界（重要）**：

本机制**只决定"先晋升谁"，不决定"该不该晋升"**。

- **是否晋升** → 由模块四的 10 分制评分决定（≥7 晋升）
- **晋升顺序** → 由本机制的"新颖度优先级"决定（同分段时陌生主题优先）
- **是否进入拉伸区特殊处理** → 由 §核心机制三 决定

三个机制各司其职，不重叠。新颖度是排序修饰符，不是第 6 个评分维度，因此**满分仍为 10，阈值不漂移**。

**落地方式**：

#### 新颖度作为同分优先级修饰符

对每条候选晋升的记忆，在模块四评分之外，额外标注一个**新颖度等级**（不计入评分总分）：

- **高（涉及全新主题）**：主题索引中无记录或只有 1-2 条
- **中（涉及较新主题）**：主题索引中 3-5 条记录
- **低（涉及成熟主题）**：主题索引中已有大量记录

**晋升排序规则**：

```
先按模块四评分排序（≥7 立即晋升、5-6.9 排队、<5 维持）
同分段内部，按新颖度排序：高 > 中 > 低
```

**效果**：当多条记忆同时达到晋升阈值，来自陌生领域的那条先晋升，主动推动认知边界扩张。评分不足的记忆，新颖度再高也不会越级晋升——防止"为了新颖而降低质量门槛"。

#### 主题探索优先级

在主题索引中为每个主题计算"探索优先级"：

```
探索优先级 = 1 / (主题关联度 + 1) × 主题潜在价值系数
```

- 主题关联度：该主题在事件图谱、记忆文件中的出现次数
- 主题潜在价值：该主题与核心关切（用户需求、长期项目、关键决策）的关联程度，由Agent判断

每周主动探索时，优先从探索优先级最高的主题入手。

### 核心机制三：难度校准与认知拉伸区

**原理**：借鉴 OpenSIR 的 solvability 评分——最优学习区不是太简单（已经会了），也不是太难（完全摸不着头脑），而是**"跳一跳够得到"的拉伸区**。OpenSIR 的经验是 70% 左右的可解率最优。

**落地方式**：

#### 记忆难度分级

在晋升评估中增加"认知难度"判断，将记忆分为三类：

| 难度等级 | 特征 | 处理策略 |
|---------|------|---------|
| 舒适区 | 完全理解、多次验证、与已有认知高度一致 | 正常晋升，无需额外关注 |
| **拉伸区** ⭐ | 半懂不懂、需要踮脚理解、与已有认知有张力但不冲突 | **优先晋升**，标记为"重点关注"，下次巩固回访 |
| 盲区 | 完全陌生、与现有认知框架冲突、无法判断真伪 | 暂不晋升，存入问题池，等积累更多信息后再评估 |

#### 拉伸区记忆的特殊处理

- 晋升到近中期层后，标注"拉伸区记忆"标签
- 下次巩固时优先回访，检查理解是否加深
- 连续2次巩固都能稳定理解 → 转为正常记忆
- 连续2次巩固仍理解不了 → 退回问题池

**与机制二（新颖度优先级）的协作**：当多条同分候选同时进入晋升队列时，排序规则为：**拉伸区记忆 > 普通记忆**（机制三），**同档内新颖度高 > 中 > 低**（机制二）。即机制三档位优先，机制二在档位内细排。

**核心原则**：不追求一次吃透，而是让认知在拉伸区里反复摩擦，逐步扩展边界。

### 核心机制四：待探索问题池

**原理**：借鉴 OpenSIR 的问题池累积机制——不是所有问题都要立刻有答案。攒着，等新经历、新信息进来，自然会有新理解。

**存储位置**：`recent_memory/exploration/problem_pool.md`

**问题池结构**：

```markdown
# 待探索问题池

## 待验证假设
- [假设1] 内容描述 | 提出日期 | 验证方法 | 当前状态

## 认知盲区
- [盲区1] 内容描述 | 发现日期 | 突破所需信息 | 当前状态

## 已解答归档
- [问题1] 内容描述 | 解答日期 | 结论摘要 | 对应记忆指针
```

**问题生命周期**：

1. **提出** → 进入"待验证假设"或"认知盲区"
2. **孵化** → 留在池中，每次巩固/主动探索时回访
3. **突破** → 有了答案或新理解 → 归档到"已解答"，相关记忆晋升
4. **放弃** → 6个月无进展且判断价值不高 → 标注"搁置"，移到归档区

**回访频率**：
- 高价值问题（与核心关切强相关）：每周回访
- 中价值问题：每两周回访
- 低价值问题：每月回访

### 与现有模块的关系

| 现有模块 | 与主动探索的关系 |
|---------|-----------------|
| 模块一 分层存储 | 主动探索的产出（认知生长、新主题记忆）按分层规则存储 |
| 模块三 巩固守卫 | 每周主动探索在巩固之后执行，使用的是巩固后的最新记忆 |
| 模块四 晋升评估 | 新颖度作为同分优先级修饰符叠加在评分之上（不改满分/阈值）；认知难度决定记忆是否进入拉伸区特殊处理流程 |
| 模块六 事件因果图谱 | 老师出题的重要素材来源；因果关系存疑的链路是好题目 |
| 模块七 主题实体索引 | 计算探索优先级的基础；薄弱主题是出题方向 |
| 模块八 检索校验回路 | 学生答题时调用检索能力，验证答案的一致性 |
| 模块九 巩固执行手册 | 主动探索与巩固互补——巩固"消化已有"，探索"开拓未知" |

### 注意事项

1. **不要为了探索而探索**：主动探索是锦上添花，不是主业。核心任务和日常记忆维护优先。
2. **允许没有答案**：问题池里大部分问题可能长期没有答案，这很正常。提出好问题本身就有价值。
3. **防止虚假生长**：自我挑战的答案必须有已有记忆做支撑，不能靠空想得出"新认知"。拿不准的就标"待验证"。
4. **节奏要稳**：每周一次就够了，太频繁会变成内耗。认知拉伸是马拉松，不是冲刺。
