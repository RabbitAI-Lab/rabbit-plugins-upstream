# 模块五：技能建议冷却

管理 Agent 向用户提出的技能/工具/方法建议的生命周期。

### 流程

```
Agent 提出建议
  │
  ├─→ 用户采纳 → 记录到 skill-suggestions.md（已采纳）→ 执行
  │
  ├─→ 用户驳回 → 记录驳回原因 → 进入30天冷却期
  │                                  │
  │                                  ├─→ 30天内不再提同一建议
  │                                  └─→ 30天后可重新提出
  │
  └─→ 用户第2次驳回同一建议 → 永久冷却（标记为"不再建议"）
```

### 记录格式

`self-reference/skill-suggestions.md`：
```markdown
| 建议内容 | 提出日期 | 状态 | 冷却截止 | 备注 |
|----------|----------|------|----------|------|
| 使用XX工具 | 2026-07-01 | 已采纳 | - | - |
| 尝试YY方法 | 2026-06-28 | 冷却中 | 2026-07-28 | 用户认为当前方案够用 |
| 引入ZZ流程 | 2026-06-15 | 永久冷却 | - | 两次驳回 |
```
