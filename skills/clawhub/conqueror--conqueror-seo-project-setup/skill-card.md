## Description:

Set up a durable local SEO workspace for a new SEO project, including working folder, site scope, goals, positioning, Conqueror MCP/project checks, and Search Console intake.

This skill is ready for commercial/non-commercial use.

## Publisher:

[conqueror](https://clawhub.ai/user/conqueror)

### License/Terms of Use:

MIT-0

## Use Case:

External users, developers, and SEO practitioners use this skill at the start of an SEO project to establish a reusable local workspace, collect site and goal context, verify Conqueror MCP project access, and prepare Search Console intake.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow can collect business strategy, SEO goals, and Search Console data that may include sensitive customer or internal information.

Mitigation: Use only a project folder the user controls, avoid credentials, and redact unnecessary confidential details before sharing files or notes.

Risk: The skill organizes local project files and may preserve SEO context over time.

Mitigation: Confirm the working folder location before creating or storing files, and keep the setup limited to user-approved project materials.
