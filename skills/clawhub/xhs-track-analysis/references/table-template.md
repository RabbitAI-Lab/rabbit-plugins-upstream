# 赛道分析主表 · 字段定义与样例

> 配套 `scripts/scaffold_table.py` 可一键生成空表骨架。本表把研究任务、关键词、笔记来源、达人与评论、关键判断和下一步动作放进同一个文件。

## 表结构（建议分节）

### 一、研究任务与三问
- 这次最想看懂什么：
- 品牌最后要做出什么选择：
- 结论交给谁使用：
- 采集时间窗口（起止，距分析 > 90 天须标"需复核"）：

### 二、关键词四分组
| 分组 | 关键词 | 对应问题 |
| --- | --- | --- |
| 人群与阶段 |  | 谁有需求 |
| 问题与效果 |  | 哪里不满意 |
| 产品与选择 |  | 在找什么 |
| 达人关联 |  | 达人能否自然参与 |

### 三、采集记录（每轮一行）
| 轮次 | 关键词 | 排序角度 | 展示位置 | 去重后笔记 | 来源(搜索/达人主页) | 采集时间 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |

### 四、重点笔记与达人（合并去重，保留出处）
| 笔记/达人 | 出现关键词(保留全部) | 来源(本人/第三方) | 商业化浓度(自然/疑似投放/合作) | 正文要点 | 素材 | 评论要点 | 关键判断 |

### 六、关键判断与下一步
- 用户在问什么：
- 平台内容怎样回答：
- 谁来讲 / 谁最可信：
- 下一步建议：

### 七、证据边界（必填）
- 样本量 / 覆盖：
- 不能下结论的部分：
- 需品牌自有数据验证的：

### 八、决策结论（必填，分析须收敛到投决）
- 投决建议：GO / NO-GO / 条件GO（附条件）：

- 讲什么角度：状态 / 成分 / 实测 / 怎么选 / 值不值 / 进入日常生活：
- 证据边界内置信度：高 / 中 / 低：

## 字段填写规则
1. **出现关键词**列必须保留该笔记出现过的全部关键词与排序，不可只写一处。
2. **来源**列区分"达人本人"与"其他账号讲该达人"，这是判断可信度的关键。
3. **证据边界**为强制节；未填则视为分析不完整。
4. 合并后不同内容数 < 累计结果数是正常的（重复被合并），需在采集记录中可追溯。
5. **商业化浓度**列须逐篇标注；高浓度内容信号打折，不与其互动量等权。
6. **采集时间**距分析 > 90 天的内容，在证据边界或备注标"需复核"。
7. **决策结论**为强制节；未填视为分析未收敛到投决。
