# 方法论：小红书赛道深度分析

> 本文为该方法的稳定层（框架/定义/规则），案例与数据见 `case-study.md`。

## 0. 什么是"小红书赛道分析"

- **是**：品牌在进入一个品类、推出一款新品或重做内容策略之前，通过公开内容看清**用户问题、内容回答、达人角色和评论反馈**。
- **不是**：估算市场规模；研究平台算法。
- **最容易失真的环节**：不是最后怎么总结，而是前面**搜了什么、看了哪些结果、同一篇内容反复出现以后怎么处理**。

## 1. Step 0 —— 定义问题（先写三问）

开始搜索前，必须写清：

1. `这次最想看懂什么？`
2. `品牌最后要做出什么选择？`
3. `这份结论最后交给谁使用？`

三问决定关键词分组方式与采集范围，避免"搜完就总结"。

## 2. Step 1 —— 关键词四分组

把关键词分成四组，每组对应一个分析视角（不是为了把表格做大）：

| 分组 | 对应问题 | 示例 |
| --- | --- | --- |
| 人群与阶段 | 谁有需求 | 熟龄肌抗老、40+护肤 |
| 问题与效果 | 哪里不满意 | 垮脸怎么办、皮肤松弛 |
| 产品与选择 | 在找什么 | 抗老面霜、紧致面霜、抗老面霜推荐 |
| 达人关联 | 达人能否自然参与 | 董洁护肤、董洁抗老、董洁状态 |

## 3. Step 2 —— 多排序采集（换排序 = 换角度）

对每个关键词，至少切到四种排序各看足量样本：

| 排序角度 | 看什么 |
| --- | --- |
| 最新 | 近期新出现或重新活跃的说法 |
| 最多点赞 | 哪些表达获得较多认同 |
| 最多收藏 | 哪些内容让用户想留下以后再看 |
| 最多评论 | 哪些内容引发追问、比较和争议 |

> 一次搜索只告诉你"我这次看到了什么"。换关键词、换排序以后，才开始看见这个赛道里有哪些不同问题。
> 这些观察**不能用来反推平台算法**。

## 4. Step 3 —— 多轮合并去重（最易失真处）

确定关键词后最费时的工作：

- 逐个搜索、切换排序，记录每一批内容**是用什么词搜到的、当时排在哪里**。
- 重点内容继续整理正文、素材、公开数据和评论；达人主页单独看。
- 同一篇笔记会在不同关键词/排序里反复出现：全保留会堆满重复，简单删除会丢掉"为何被不同问题同时搜到"的信息。

**正确做法**：同一篇笔记只保留一份，但保留它出现过的**所有关键词与排序**。合并后仍须知道：

- 这篇笔记从哪些关键词和排序里出现过；
- 它来自达人本人，还是其他账号在讲这个达人；
- 对应的正文、素材和评论放在哪里；
- 哪些资料已拿到、哪些页面未提供、哪些确实保存失败。

> 真正难的，不是把 N 条记录变成 M 篇笔记，而是合并以后仍然知道每篇的来龙去脉。

## 5. Step 4 —— 内容 + 达人分析

关键词和排序让我们看到赛道里有哪些问题；接下来要看：平台内容怎样回答，谁回答得更自然，用户又真正听进去了什么。

### 看达人：本人讲什么，市场怎样理解她

- 看达人**本人主页**在讲什么（如董洁：生活、居家、饮食、穿搭、旅行、工作、好物选择，而非直接经营成"抗老知识账号"）。
- 看**搜索结果里其他账号**怎样给她加解释（第三方放大：年龄状态、选品信任、进一步解释成抗老理由）。
- 拼出理解路径：

  > **生活方式和审美选择 → 年龄状态 → 选品信任 → 抗老产品理由**

- 判断该达人**回答哪类问题最可信**，其余（成分原理、效果证明、竞品比较、适合谁、使用边界）交给测评达人、专家内容、真实用户内容和品牌官方。
- 一位达人不需要回答品牌的所有问题；更重要的是她回答哪个问题时最可信。

### 跨关键词重复笔记的处理

- 多篇笔记同时出现在多个关键词 = 它连接了多个用户问题，应优先研究。
- 例：《我的答案是黑曜石面霜～》同时出现在 抗老面霜 / 紧致面霜 / 抗老面霜推荐，对应 这是什么品类 / 它能带来什么结果 / 为什么值得考虑。它本身完成了一条选择过程（比较竞品→讲差异→区分肤质质地场景→谈价格怎么选）。

## 6. Step 5 —— 评论分析（四种用户行为）

同样是高互动，用户可能在完成完全不同的判断。把高互动内容按行为归类：

| 行为 | 含义 | 信号 |
| --- | --- | --- |
| 向往状态 | 记住的是人/生活状态 | 谈漂亮、真实、自然、年龄状态 |
| 追问选择 | 愿意跟随但仍要证据 | 问品牌、求链接、追问资质/质量/选品标准 |
| 确认效果/风险 | 收藏≠相信≠购买 | "有没有用""会不会有风险" |
| 比较产品 | 已开始公开做选择 | 进入品牌、竞品、替代方案比较 |

> 点赞、收藏和评论总量只能告诉你内容有没有获得反应；**评论具体在谈什么**，才开始告诉你用户记住了什么、又卡在了哪里。

## 7. Step 6 —— 形成品牌建议 + 证据边界

一份真正完成的赛道分析，最后不应只交付"最近什么火"。品牌需依次解决：

1. 用户在问什么；
2. 平台内容怎样回答；
3. 谁来讲 / 谁最可信；
4. 下一步建议（品牌应先进入哪个问题、还要补什么）。

**必须写进证据边界**：真实商业结果仍需品牌自有曝光、点击、进店、成交和退款数据。结论能说到哪一步，取决于资料覆盖到哪一步。

> 工具不会替品牌自动生成小红书策略，它只是先把最慢、最容易漏、也最容易被一次搜索结果带偏的资料整理清楚。

## 8. 商业化浓度校准（重投放品类需打折解读）

当目标品类处于**重投放 / 种草密集**阶段，公开内容会被品牌与达人的商业化创作显著污染：高赞高藏笔记可能是投放产物，而非自然需求信号。校准动作：

- 在采集与判断时标注每篇笔记的**商业化浓度**：自然内容 / 疑似投放 / 明确合作。
- 对高浓度内容，其"用户问题 / 评论反馈"信号要**打折**，不与其互动量等权。
- 关键判断以**自然内容 + 真实用户评论**为主锚，投放内容仅作"市场供给"侧参考。
- 浓度判定线索：评论区大量"已买/求链接/品牌方"、含明确优惠码或购买引导、达人在该品类笔记频率异常高。

## 9. 混合采集与决策收敛

### 9.1 混合采集（量化初筛 + 人工深读）
纯手动深读覆盖有限；纯量化易失真。推荐混合：
- **量化初筛**（第三方：千瓜 / 新红 / 蝉妈妈 / 灰豚，或官方聚光）：先拿搜索词量级、笔记榜单、达人粉丝画像，圈定高潜关键词与达人；
- **人工深读**（网页端插件 / 人工）：对初筛结果做四分组、四排序、四行为归类与达人解读。
- 两者共用同一张主表（见 `table-template.md`）：量化填"量级 / 趋势"，人工填"语义 / 行为 / 判断"。

### 9.2 决策收敛（分析必须落到投决）
分析不是终点。Step 6 强制产出**决策结论**，避免"rich document ≠ right call"：
- **GO / NO-GO / 条件GO**：基于证据边界给出明确投决建议；
- **找谁讲**：推荐达人类型与各自可信问题边界（谁答状态、谁答成分、谁答测评）；
- **讲什么角度**：推荐内容切入角度（状态 / 成分 / 实测 / 怎么选 / 值不值 / 进入日常生活）。
- 主表新增「八、决策结论」节（见 `table-template.md`），未填视为分析未收敛。
