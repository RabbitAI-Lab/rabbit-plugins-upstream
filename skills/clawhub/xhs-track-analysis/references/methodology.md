# 方法论：小红书赛道深度分析

> 本文为该方法的稳定层（框架/定义/规则），案例与数据见 `case-study.md`（匿名化演示数据）。
> 本方法为原创框架：四分组 / 意图标注 / 四排序 / 长尾信号 / 合并规则 / 达人生态位 / 四行为 / 供给结构 / 风险扫描，均由本 Skill 自行定义，不依赖任何外部文档。

## 0. 什么是"小红书赛道分析"

- **是**：品牌在进入一个品类、推出一款新品或重做内容策略之前，通过公开内容看清**用户问题、内容回答、达人角色、评论反馈与赛道供给**。
- **不是**：估算市场规模；研究平台算法。
- **最容易失真的环节**：不是最后怎么总结，而是前面**搜了什么、看了哪些结果、同一篇内容反复出现以后怎么处理**。
- **小红书与抖音的本质差异**：小红书是**搜索 + 推荐双入口**平台，笔记有长尾生命周期（发布数月后仍可能被搜索命中）；赛道分析必须同时看"当下热门"与"长尾沉淀"两层。

## 1. Step 0 —— 定义问题（先写三问）

开始搜索前，必须写清：

1. `这次最想看懂什么？`
2. `品牌最后要做出什么选择？`
3. `这份结论最后交给谁使用？`

三问决定关键词分组方式与采集范围，避免"搜完就总结"。

## 2. Step 1 —— 关键词四分组 + 搜索意图标注

### 2.1 关键词四分组

| 分组 | 对应问题 | 示例 |
| --- | --- | --- |
| 人群与阶段 | 谁有需求 | 熟龄肌抗老、40+护肤 |
| 问题与效果 | 哪里不满意 | 垮脸怎么办、皮肤松弛 |
| 产品与选择 | 在找什么 | 抗老面霜、紧致面霜、抗老面霜推荐 |
| 达人关联 | 达人能否自然参与 | 生活方式博主护肤、某博主状态 |

### 2.2 搜索意图标注（资深专家补充 v3.0，推断）

每个关键词额外标注**意图阶段**，对齐种草漏斗——同一品类词下，用户处在不同决策阶段，看到的笔记类型完全不同：

| 意图阶段 | 用户在想什么 | 典型关键词形态 |
| --- | --- | --- |
| 发现 | "这品类存在什么" | 品类词（抗老）、场景词（30岁护肤） |
| 了解 | "它怎么解决问题" | 问题+效果（垮脸怎么办）、方法（护肤流程） |
| 比较 | "哪个更适合我" | 推荐/对比/测评（抗老面霜推荐、A还是B） |
| 决策 | "我该买哪个" | 价格/成分/避雷（值不值、避雷、成分表） |

意图标注的价值：判断该赛道的用户**卡在哪个阶段**——大量"比较"意图但"决策"意图内容少，说明品牌的机会在提供决策依据，而不是再发一篇种草。

## 3. Step 2 —— 多排序采集 + 长尾检查（换排序 = 换角度）

### 3.1 四排序

对每个关键词，至少切到四种排序各看足量样本：

| 排序角度 | 看什么 |
| --- | --- |
| 最新 | 近期新出现或重新活跃的说法 |
| 最多点赞 | 哪些表达获得较多认同 |
| 最多收藏 | 哪些内容让用户想留下以后再看 |
| 最多评论 | 哪些内容引发追问、比较和争议 |

> 一次搜索只告诉你"我这次看到了什么"。换关键词、换排序以后，才开始看见这个赛道里有哪些不同问题。这些观察**不能用来反推平台算法**。

### 3.2 笔记长尾信号（资深专家补充 v3.0，推断）

小红书搜索长尾是区别于抖音的核心特征。采集时对每条笔记记录**发布时长**，并检查：

- **发布 > 90 天、互动仍在增长**的笔记 = 长尾流量信号，说明这条内容在持续被搜索命中，其回答的用户问题是**持续存在**的需求；
- 高赞高藏但**全部是新发布** → 可能是当下热点/投放脉冲，不是长尾需求。

长尾信号强的笔记，比新爆款更值得作为"用户真实持久需求"的证据（但仍要配合商业化浓度打折）。

## 4. Step 3 —— 多轮合并去重（最易失真处）

确定关键词后最费时的工作：

- 逐个搜索、切换排序，记录每一批内容**是用什么词搜到的、当时排在哪里**。
- 重点内容继续整理正文、素材、公开数据和评论；达人主页单独看。
- 同一篇笔记会在不同关键词/排序里反复出现：全保留会堆满重复，简单删除会丢掉"为何被不同问题同时搜到"的信息。

**正确做法**：同一篇笔记只保留一份，但保留它出现过的**所有关键词与排序**。合并后仍须知道：

- 这篇笔记从哪些关键词和排序里出现过（含意图阶段）；
- 它来自达人本人，还是其他账号在讲这个达人；
- 对应的正文、素材和评论放在哪里；
- 哪些资料已拿到、哪些页面未提供、哪些确实保存失败。

> 真正难的，不是把 N 条记录变成 M 篇笔记，而是合并以后仍然知道每篇的来龙去脉。

## 5. Step 4 —— 内容 + 达人分析

### 5.1 达人角色生态位（资深专家补充 v3.0，推断）

不要只分"本人 vs 第三方"。先判定达人在这个品类里的**角色生态位**——不同生态位回答不同问题、可信度来源不同：

| 生态位 | 内容特征 | 回答哪类问题最可信 | 局限 |
| --- | --- | --- | --- |
| 种草型 | 生活方式/审美引领，产品自然进入生活画面 | "我为什么向往这种状态、这个产品为什么值得进入日常" | 不解决成分/效果证明 |
| 测评型 | 实测/对比/参数，强调验证过程 | "它实际表现如何、和竞品差在哪" | 商业化浓度通常偏高 |
| 专家型 | 成分/原理/皮肤学解释 | "为什么有效、适合谁、边界在哪" | 强决策品类可信度高，但离生活场景远 |
| 官方型 | 品牌自营/授权发布 | 品牌背书、活动信息 | 天然高商业化，用户信任打折 |

**判断方法**：看达人本人主页的母题构成 + 第三方账号对他的解读路径（共现溯因，非因果）。

> 一位达人不需要回答品牌的所有问题；更重要的是她**回答哪个问题时最可信**。跨生态位组合（种草型讲场景 + 测评型给证据 + 专家型给原理）是成熟的赛道内容矩阵。

### 5.2 本人讲什么，市场怎样理解她

- 看达人**本人主页**在讲什么（生活、居家、穿搭、好物选择，而非把主页经营成垂直知识账号）。
- 看**搜索结果里其他账号**怎样给她加解释（第三方放大：年龄状态、选品信任、进一步解释成品类理由）。
- 判断该达人回答哪类问题最可信，其余（成分原理、效果证明、竞品比较、适合谁、使用边界）交给其他生态位达人、专家内容、真实用户内容和品牌官方。

### 5.3 跨关键词重复笔记的处理

- 多篇笔记同时出现在多个关键词 = 它连接了多个用户问题，应优先研究（枢纽内容）。
- 同时出现在多个**意图阶段** = 该笔记覆盖了从了解到决策的完整路径，是内容矩阵的参考样板。

## 6. Step 5 —— 评论分析（四行为 + 评论者类型 + 自来水 + 购买意图）

### 6.1 四行为归类

同样是高互动，用户可能在完成完全不同的判断。把高互动内容按行为归类：

| 行为 | 含义 | 信号 |
| --- | --- | --- |
| 向往状态 | 记住的是人/生活状态 | 谈漂亮、真实、自然、状态 |
| 追问选择 | 愿意跟随但仍要证据 | 问品牌、求链接、追问资质/质量/选品标准 |
| 确认效果/风险 | 收藏≠相信≠购买 | "有没有用""会不会有风险" |
| 比较产品 | 已开始公开做选择 | 进入品牌、竞品、替代方案比较 |

> 点赞、收藏和评论总量只能告诉你内容有没有获得反应；**评论具体在谈什么**，才开始告诉你用户记住了什么、又卡在了哪里。

### 6.2 评论者类型（资深专家补充 v3.0，推断）

同一句评论，来自真实用户和来自营销号的证据价值完全不同。按线索区分：

| 线索 | 真实用户 | 营销号 / 水军 |
| --- | --- | --- |
| 表达 | 具体、有细节、带自身情境 | 空泛、口号式、重复模板 |
| 时间 | 分散、随内容发布自然分布 | 集中、短时间批量出现 |
| 账号 | 有日常动态 | 无名/零动态/只评不写 |

营销号评论**不计入**用户需求信号，仅标注"疑似营销"供参考。

### 6.3 自来水推荐信号（资深专家补充 v3.0，推断）

无任务驱动、用户自发向他人推荐笔记或产品 = **最接近真实口碑的证据**。出现"已经买/复购/推荐给朋友"类评论时单独记录，作为用户信任的直接信号。数量极少但**不许抽样**，全量核查。

### 6.4 购买意图分层（资深专家补充 v3.0，推断）

行动类评论要分层，不能一刀切当购买意愿：

| 层级 | 评论形态 | 含义 |
| --- | --- | --- |
| 好奇 | "这是什么""哪里买" | 信息获取，未决策 |
| 考虑 | "多少钱""有没有平价替代" | 价格/方案比较 |
| 决策 | "已经下单""用了三个月回来反馈" | 完成购买或复购 |

结论中的"用户购买意愿"只能用**决策层**评论支撑，好奇/考虑层只能说明"存在兴趣"。

## 7. Step 6 —— 品牌建议 + 证据边界 + 供给结构 + 风险扫描

### 7.1 四问（品牌建议必须回答）

一份真正完成的赛道分析，最后不应只交付"最近什么火"。品牌需依次解决：

1. 用户在问什么；
2. 平台内容怎样回答；
3. 谁来讲 / 谁最可信；
4. 下一步建议（品牌应先进入哪个问题、还要补什么）。

### 7.2 供给结构判断（资深专家补充 v3.0，推断）

看"谁在讲这个品类"，判断赛道的**饱和/缺口**：

| 维度 | 观察 | 判断价值 |
| --- | --- | --- |
| 达人集中度 | 头部 N 个达人占多少内容量 | 集中度高 = 供给被少数人占据，新进入者溢价高 |
| 生态位分布 | 种草/测评/专家/官方各占多少 | 某一生态位空缺 = 差异化切入机会 |
| 内容形式占比 | 图文 vs 视频、清单 vs 深读 | 形式单一 = 反形式内容有空间 |
| 意图阶段覆盖 | 发现/了解/比较/决策各自覆盖 | 决策阶段内容少 = 用户卡在选择前 |

> 少不等于机会，但提示用户还缺哪类答案。供给结构判断必须基于合并去重后的真实样本，不能凭印象。

### 7.3 品类风险扫描（资深专家补充 v3.0，推断）

赛道级风险排查，在投决前完成：

| 风险项 | 观察 | 说明 |
| --- | --- | --- |
| 功效宣称违规密度 | "三天见效""医美级""根治"类内容占比 | 高密度 = 平台治理风险高，品牌合规表述受约束 |
| 政策/舆情敏感 | 品类是否处监管关注期（医美/保健/金融等） | 判断依据为公开信息，合规边界由品牌法务把关 |
| 商业化扭曲度 | 投放内容与自然内容的互动差距 | 差距过大 = 赛道信号被商业化污染，结论打折 |

### 7.4 决策收敛（分析必须落到投决）

分析不是终点。Step 6 强制产出**决策结论**：

- **GO / NO-GO / 条件GO**：基于证据边界给出明确投决建议；
- **找谁讲**：按角色生态位推荐达人类型与各自可信问题边界（种草型讲状态 / 测评型给证据 / 专家型讲原理 / 官方型背书）；
- **讲什么角度**：推荐内容切入角度（状态 / 成分 / 实测 / 怎么选 / 值不值 / 进入日常生活）；
- **进入策略**（v3.0 新增）：主攻意图阶段 + 主打人群 + 内容矩阵形态（如"用专家型内容补决策阶段缺口，种草型承接向往"）。

主表「八、决策结论」未填视为分析未收敛。

## 8. 商业化浓度校准（重投放品类需打折解读）

当目标品类处于**重投放 / 种草密集**阶段，公开内容会被品牌与达人的商业化创作显著污染：高赞高藏笔记可能是投放产物，而非自然需求信号。校准动作：

- 在采集与判断时标注每篇笔记的**商业化浓度**：自然内容 / 疑似投放 / 明确合作。
- 对高浓度内容，其"用户问题 / 评论反馈"信号要**打折**，不与其互动量等权。
- 关键判断以**自然内容 + 真实用户评论**为主锚，投放内容仅作"市场供给"侧参考。
- 浓度判定线索：评论区大量"已买/求链接/品牌方"、含明确优惠码或购买引导、达人在该品类笔记频率异常高。

## 9. 混合采集与决策收敛

### 9.1 混合采集（量化初筛 + 人工深读）

纯手动深读覆盖有限；纯量化易失真。推荐混合：

- **量化初筛**（第三方：千瓜 / 新红 / 蝉妈妈 / 灰豚，或官方聚光）：先拿搜索词量级、笔记榜单、达人粉丝画像，圈定高潜关键词与达人；
- **人工深读**（`scripts/collector/` 受监督采集或人工）：对初筛结果做四分组、意图标注、四排序、长尾检查、四行为归类与达人解读。
- 两者共用同一张主表（见 `table-template.md`）：量化填"量级 / 趋势"，人工填"语义 / 行为 / 判断"。

### 9.2 证据边界（强制）

真实商业结果仍需品牌自有曝光、点击、进店、成交和退款数据。结论能说到哪一步，取决于资料覆盖到哪一步。

> 工具不会替品牌自动生成小红书策略，它只是先把最慢、最容易漏、也最容易被一次搜索结果带偏的资料整理清楚。
