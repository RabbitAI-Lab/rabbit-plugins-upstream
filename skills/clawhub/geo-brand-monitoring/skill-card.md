## Description:

Checks how 18 AI platforms mention and rank a brand, which competitors appear, and which pages they cite, then creates a shareable report; it can also help developers write code for the MaxAEO Open API.

This skill is ready for commercial/non-commercial use.

## Publisher:

[hclscut](https://clawhub.ai/user/hclscut)

### License/Terms of Use:

MIT-0

## Use Case:

Brand owners and marketing teams use it to check how selected AI platforms answer real category questions about their brand, competitors, and cited sources. Developers use it to integrate with the MaxAEO Open API.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The setup guidance asks users to paste a live API key into the conversation.

Mitigation: Do not paste a live key into chat; use a safer local secret-entry method.

Risk: The API reference includes an unpinned package install example and was only partially analyzed.

Mitigation: Verify the package version and where data is sent, and review the API reference before installing or integrating.
