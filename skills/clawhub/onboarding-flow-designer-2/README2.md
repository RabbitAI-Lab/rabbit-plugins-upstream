## 📘 Skill 2：新手引导设计师 (Onboarding Flow Designer)

```markdown
# 新手引导设计师（Onboarding Flow Designer）

## 一句话简介
基于用户旅程地图，为新用户设计从注册到激活的系统化引导流程，提升留存与转化。

## 详细说明
新手引导设计师是一个为产品团队和设计初学者打造的 AI 技能。它帮助您快速构建一个完整的新手引导方案，涵盖欢迎语、快速获胜任务、渐进式功能解锁、空状态设计以及召回机制。技能会根据您提供的产品特征（复杂度、用户熟悉度、合规性等）自动匹配最合适的引导策略（可选式、渐进式、强制式或沉浸式），并输出包含激活指标基准线的详尽方案。

该技能降低了引导设计的学习门槛，让非专业设计师也能产出有理有据、可落地执行的方案。

## 功能特点
- 🧭 **四阶段流程**：严格按照“欢迎与价值传达 → 快速获胜 → 渐进式功能引导 → 空状态与持续激活”结构化输出。
- 🧠 **智能策略匹配**：根据产品类型和用户特征自动推荐引导方式（可选/渐进/强制/沉浸）。
- ⏱️ **量化目标设定**：提供激活率（≥60%）、TTV（≤3 分钟）、7 日留存（≥30%）等基准指标。
- 🧩 **功能解锁排序**：将功能分 3 批（核心/常用/高阶）逐步呈现，避免新手信息过载。
- 📱 **空状态与召回**：内置空状态引导文案和回访唤醒机制设计建议。
- 🧩 **零代码输出**：全部方案以 Markdown 格式呈现，可直接用于团队协作或文档沉淀。

## 使用方法
1. 在 ClawHub 中启动该技能（或直接对话触发）。
2. 当您说出“设计新手引导”、“新用户怎么上手”、“做Onboarding”等关键词时，技能会自动启动。
3. 按提示提供产品名称、核心功能（Aha 时刻）和目标用户画像。
4. 技能将自动匹配策略并生成完整的四阶段引导方案。

## 输出示例（节选）
```markdown
# 新手引导设计方案

## 四阶段引导流程
### 阶段一：欢迎与价值传达
- **核心文案**：“30 秒定制你的专属计划”
- **问卷设计**：是否需要？（若需要，最多 3 题）

### 阶段二：快速获胜（First Win）
- **核心任务**：创建第一个项目
- **操作路径**：点击“+” → 输入名称 → 保存（完成）
- **正向反馈**：显示“太棒了！”动画

### 阶段三：渐进式功能引导
- **解锁顺序**：首批（核心）：项目管理；第二批（常用）：协作、评论；第三批（高阶）：报表分析。
- **呈现方式**：上下文工具提示。

## 成功指标（基准线）
- **激活率目标**：≥ 60%
- **TTV目标**：≤ 3 分钟
- **7日留存目标**：≥ 30%
