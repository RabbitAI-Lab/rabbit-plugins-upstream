# 凭证获取指南（AK/SK）

使用本技能前，需先获取明日DMP OPEN API 凭证：Access Key（AK）与 Secret Key（SK）。

## 申请方式（二选一）

**方式一：邮件申请**
- 收件人：product@mingdata.com
- 邮件主题：【明日DMP API开通申请】
- 邮件内容：公司名称、联系人、联系方式、使用场景

**方式二：在线表单申请**
- https://doc.weixin.qq.com/forms/ANEAJwfLAAoADMAHwbhAPICNUE0vDRd8f#/fill

## 配置方式

获取到AK/SK后，运行配置脚本写入本地：

```bash
# 生产环境（默认）
python3 scripts/setup_credentials.py <你的AK> <你的SK>

# 测试环境
python3 scripts/setup_credentials.py <你的AK> <你的SK> https://dmp-dev.mingdata.com
```

配置完成后，运行 `python3 scripts/preflight_check.py` 验证凭证有效。

## 安全提示
- AK/SK 属于敏感信息，请勿泄露
- 凭证文件保存在 `~/.mingdata_dmp_credentials`，权限设置为600（仅本人可读写）
- 避免在公共对话/公共屏幕明文展示AK/SK
- 建议仅在受信环境中配置

## 凭证格式参考
- Access Key：通常为8位左右的字母数字字符串
- Secret Key：通常为32位字母数字字符串
- 凭证有效期以平台通知为准，过期后需重新配置
