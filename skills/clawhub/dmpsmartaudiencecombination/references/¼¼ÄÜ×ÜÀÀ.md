# TP圈人（组合人群）Skill：总览（用于落盘设计稿）

> 说明：本文档为后续“技能包”中的主入口文档等价物（正式打包时可重命名为 `SKILL.md`）。
> 
> 范围：仅【组合人群】（audienceType=2）。
> 
> 关键原则：
> - 不编造标签/ID/量级/Overlap。
> - 候选标签必须来自 `tag/list` 返回且 `isDirectory=1`。
> - 语义召回参考“向量/TF-IDF相似度检索”思路实现，但不依赖现成技能调用。
> - Overlap 口径：仅计算「可选标签 x 与 MUST 标签集合 M」的交集量级（M∩x）。

---

## 1. 输入字段规范（按截图要求）
- 必填：自然语言需求描述、目标人群定向需求、投放目标
- 非必填：结构化拆解维度（基础属性/地理/行业品类/行为兴趣/生活方式/活跃度/KOLKOC内容偏好）
- 可选：历史投放数据/历史人群包、投放媒体/媒体点位

详见：[`01_输入字段规范.md`](01_输入字段规范.md)

---

## 2. 端到端工作流（循序渐进）
1) 需求解析 → 2) 完整性判断与最小追问 → 3) Schema 固化（10维）
4) 拉取可用标签池（tag/list）→ 5) 本地语义召回（索引检索）→ 6) 标签画像补全（查画像表）
7) 工程质量过滤与排序 → 8) 用户选择（MUST/PREFERRED/OPTIONAL/EXCLUDE）
9) MUST基准量级 |M| → 10) Overlap（仅 M∩x）→ 11) 递进组合方案 → 12) 用户确认
13) 调用 DMP 创建最终组合人群 → 14) 状态查询与交付

详见：[`02_整体流程与分步处理.md`](02_整体流程与分步处理.md)

## 5. 前置规范（与“批量打通圈包”保持一致，已内嵌）
- **鉴权口径一致**：URL query 拼接 `ts/randStr/accessKey/sign`；`sign = MD5(ts + randStr + secret_key).upper()`；`ts` 时效 3 分钟。
- **环境一致**：测试/生产 Base URL 的选择与项目一致。
- **任务记录一致**：记录时间、环境、接口路径、关键输入（脱敏）、返回ID（audienceId/taskId）、状态、错误信息。
- **导出一致**：候选标签表、Overlap 报告、最终组合规则 JSON 使用统一命名与导出入口（按项目规范）。
