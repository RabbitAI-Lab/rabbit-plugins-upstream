# 需求→Schema 防漏检查表（圈人通用）

> 目的：把用户自然语言需求拆成“可执行字段”，避免遗漏导致召回/分组缺维度（如兴趣偏好未入schema）。

## 1. 必填结构（建议全部保留；无值可置空/空数组）
- `_raw_text`
- `goal` / `use_case` / `kpi_target`
- `audience`（身份/阶段/年龄）
- `geo`（城市级别/省市）
- `interest`（兴趣种子与可选分层）
- `behavior`（行为/渠道/时间窗/频次）
- `exclude`（排除项）
- `notes.acceptable_substitutes`（可接受替代口径：无直达标签时兜底）
- `extra.original_points`（任何落不到字段的新点先兜底收口，禁止丢失）

## 2. 需求点分类（逐条打勾）
- 目标/场景：拉新/召回/转化/复购
- 人群身份：如新手爸妈/宝妈/奶爸
- 生命周期/孩子年龄：备孕/孕期/0-3岁等
- 地域：一二线/省市
- 父母年龄：如25-29/30-34（可选）
- 兴趣偏好：母婴/育儿/奶粉/纸尿裤/早教/亲子等
- 行为/消费：购买/加购/浏览/活跃（含时间窗）
- 排除项：排老客/排已购/排竞品
- 渠道/终端（如有）：APP/媒体/OS（可选）

## 3. 强制自检口径（Step2确认前）
- 任何用户提到的“点”，必须：
  - 要么进入上述结构化字段；
  - 要么进入 `extra.original_points`（后续再迁移）。
- 若用户说了“兴趣/偏好/品类”，但 `interest.seeds` 为空 → 视为缺失，必须补齐或询问。
