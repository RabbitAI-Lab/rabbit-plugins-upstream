# 05 标签召回与语义匹配（不依赖外部技能调用）

> 对齐：`tag-mapping-rules_2.md`。
> 核心：候选标签必须来自 DMP `tag/list` 的真实标签；语义相似度仅用于“召回/重排”。

## 1. 输入输出
- 输入：Schema（10维）+ 可用标签池（tag/list，过滤isDirectory=1）
- 输出：候选标签池 candidate_tags（tagId/tagName/pathName/tagType + similarity_score + 维度归因）

## 2. 标签池获取与硬过滤
1) 调用 `tag/list` 拉取标签元数据。
2) 过滤：仅保留 `isDirectory=1`。
3) 本地构建层级路径 `pathName`（基于 parentId 回溯）。

## 3. 召回策略（循序渐进）
### 3.1 Query构造（多Query并行 + 同义词扩展）
- 从Schema有值字段抽取关键词/短语。
- constraints.exclude 只用于后置过滤，不进入召回query。
- **同义词/别称扩展（第一层）**：对用户输入中的口语化/黑话触发词，先用 `references/synonyms_map.json` 做 query 扩展（仅扩展查询词，不直接生成标签）。
- 建议生成 3~6 个query（例如：行业+兴趣、行业+人群属性、城市级别、活跃度等），并行检索取并集。

### 3.2 相似度检索实现（参考dmp-targeting方法，自建）
可选两种实现（选一即可上线，先轻量后增强）：
- 方案A（轻量）：TF-IDF字符n-gram（适合中文标签名）+ 余弦相似度 TopK
- 方案B（增强）：Embedding向量 + ANN索引 TopK

> 产出：每个候选标签带 similarity_score（0~1）。

### 3.3 辅助召回与扩展
- 精确/模糊关键词匹配：补充可能漏掉的精确命中。
- 层级扩展：命中子标签后，可补充同父兄弟标签（仍需isDirectory=1）。

## 4. 去重与合并
- 按 tagId 去重；若多路命中取最高 similarity_score。
- 按维度/类别聚合用于展示（不等于组合）。

## 5. 无匹配兜底
- 候选为空 → 回到完整性判断触发澄清追问或放宽条件。
- 禁止编造标签/tagId。
