# 技能安装与环境检查

## 1. 环境要求

- Python >= 3.8（仅使用标准库，**无需安装任何第三方包**）
- 明日DMP OPEN API 凭证（Access Key / Secret Key）

## 2. 首次使用前置校验

每次执行圈人流程前，运行前置校验脚本：

```bash
python3 scripts/preflight_check.py
```

如果所有检查项通过（status=ok），可以直接开始圈人。

## 3. 凭证缺失处理

若 preflight_check 返回"凭证文件不存在"或"凭证不完整"：

### 3.1 获取AK/SK
阅读 `references/凭证获取指南.md` 申请Access Key和Secret Key。

### 3.2 配置凭证
运行凭证配置脚本：
```bash
python3 scripts/setup_credentials.py <ACCESS_KEY> <SECRET_KEY> [BASE_URL]
```

- BASE_URL 默认为生产环境 `https://open.mingdata.com`
- 测试环境填 `https://dmp-dev.mingdata.com`
- 凭证保存在 `~/.mingdata_dmp_credentials`（权限600，仅当前用户可读写）
- **与批量打通圈包、批量圈包、人群投放等技能共用同一凭证文件**，配置一次即可

### 3.3 凭证加载优先级
脚本会按以下优先级自动查找凭证：
1. 命令行参数 `--ak/--sk/--base-url`
2. 环境变量 `DMP_AK/DMP_SK/DMP_BASE_URL`
3. 配置文件 `~/.mingdata_dmp_credentials`

## 4. 零依赖说明

本技能所有脚本均使用 Python 标准库实现，不依赖 sklearn、numpy、pandas、openpyxl、requests 等任何第三方包：
- HTTP 请求：urllib（替代 requests）
- TF-IDF 语义匹配：纯Python手写实现（与sklearn TfidfVectorizer算法一致）
- Excel读取：zipfile + xml.etree（替代 pandas/openpyxl）

**因此无需 pip install 任何包，只要有 Python 3.8+ 即可运行。**

## 5. 常见问题

- **"未找到DMP API凭证"**：运行 `setup_credentials.py` 配置凭证
- **"标签指标表不存在"**：确认 assets/标签指标表.xlsx 文件完整
- **"DMP API error: code=xxx"**：检查AK/SK是否正确，base_url是否对应正确环境
- **连接超时**：检查网络是否能访问DMP API地址，如有代理需配置环境变量
