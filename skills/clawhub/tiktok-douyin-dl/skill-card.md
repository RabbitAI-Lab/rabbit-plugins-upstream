## Description: <br>
Downloads TikTok and Douyin videos and photo posts without watermarks using Linux command-line binaries. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[francis-xavier-code](https://clawhub.ai/user/francis-xavier-code) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and users can use this skill to install, update, and run command-line downloaders for TikTok and Douyin videos or photo posts. It is intended for local, user-directed downloads to a chosen save directory. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill installs and runs external command-line binaries and a Playwright browser runtime locally. <br>
Mitigation: Install only if you trust the release publisher, verify the release source when appropriate, and expect the first run to download Chromium. <br>
Risk: Downloading TikTok or Douyin content may implicate platform terms, intellectual property rights, or local law. <br>
Mitigation: Use the tool only for content you are allowed to download under applicable platform rules and law. <br>
