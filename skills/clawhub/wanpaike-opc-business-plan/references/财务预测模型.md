# 动态财务预测模型

## 核心改进：从固定示例到动态估算

本模型提供**基于用户输入动态计算**的财务预测框架，而非固定示例数据。AI在执行时根据用户提供的少量关键参数，自动推算完整的3-5年财务预测表。

---

| 序号 | 参数 | 说明 | 示例 |
|-----|------|------|------|
| 1 | 目标市场规模 | TAM规模（亿元） | 100亿 |
| 2 | 可获得市场份额 | SOM占比（%） | 3% |
| 3 | 客单价 | 年均单客户收入（万元） | 5万 |

| 5 | 年增长率 | 预期年增长率（%） | 80% |
| 6 | 初始客户数 | Y1预计获客数 | 50 |
| 7 | 续费率 | 客户年续费率（%） | 85% |

## 二、动态计算引擎

### 收入预测模型

```python
# 动态收入计算公式
def calc_revenue(params):
    year1_customers = params['initial_customers']
    growth_rate = params['growth_rate'] / 100
    arpu = params['arpu']
    renewal_rate = params['renewal_rate'] / 100
    
    results = []
    active_customers = 0
    
    for year in range(1, 6):
        new_customers = year1_customers * (1 + growth_rate) ** (year - 1)
        churned = active_customers * (1 - renewal_rate)
        active_customers = active_customers + new_customers - churned
        revenue = active_customers * arpu
        results.append({
            'year': f'Y{year}',
            'new_customers': round(new_customers),
            'active_customers': round(active_customers),
            'churned': round(churned),
            'revenue': round(revenue, 0)
        })
    return results
```

### 成本预测模型

```python
def calc_costs(revenue_list, params):
    gross_margin = params['gross_margin'] / 100
    
    # 费用率随阶段变化
    # 早期（Y1-Y2）：研发高、营销高、管理低
    # 成长期（Y3-Y4）：研发降、营销降、管理升
    # 成熟期（Y5+）：趋于稳定
    
    stage_ratios = {
        'Y1': {'rd': 0.40, 'marketing': 0.30, 'admin': 0.15},
        'Y2': {'rd': 0.35, 'marketing': 0.28, 'admin': 0.14},
        'Y3': {'rd': 0.30, 'marketing': 0.25, 'admin': 0.13},
        'Y4': {'rd': 0.25, 'marketing': 0.22, 'admin': 0.12},
        'Y5': {'rd': 0.22, 'marketing': 0.20, 'admin': 0.12},
    }
    
    results = []
    for r in revenue_list:
        y = r['year']
        ratios = stage_ratios.get(y, stage_ratios['Y5'])
        gross_profit = r['revenue'] * gross_margin
        rd = r['revenue'] * ratios['rd']
        marketing = r['revenue'] * ratios['marketing']
        admin = r['revenue'] * ratios['admin']
        op_profit = gross_profit - rd - marketing - admin
        op_margin = op_profit / r['revenue'] * 100 if r['revenue'] > 0 else 0
        
        results.append({
            'year': y,
            'revenue': r['revenue'],
            'gross_profit': round(gross_profit, 0),
            'rd_expense': round(rd, 0),
            'marketing_expense': round(marketing, 0),
            'admin_expense': round(admin, 0),
            'operating_profit': round(op_profit, 0),
            'operating_margin': round(op_margin, 1)
        })
    return results
```

### 单位经济模型

```python
def calc_unit_economics(params, cost_results):
    arpu = params['arpu']
    gross_margin = params['gross_margin'] / 100
    renewal_rate = params['renewal_rate'] / 100
    
    # 平均客户生命周期（年）
    avg_lifetime = 1 / (1 - renewal_rate) if renewal_rate < 1 else 10
    
    # LTV
    ltv = arpu * gross_margin * avg_lifetime
    
    # CAC估算（基于Y1营销费用和新客户数）
    y1_marketing = cost_results[0]['marketing_expense']
    y1_new = params['initial_customers']
    cac = y1_marketing / y1_new if y1_new > 0 else 0
    
    # 回收周期（月）
    monthly_gross = arpu * gross_margin / 12
    payback_months = cac / monthly_gross if monthly_gross > 0 else 0
    
    return {
        'CAC': round(cac, 0),
        'LTV': round(ltv, 0),
        'LTV_CAC': round(ltv / cac, 1) if cac > 0 else 0,
        'payback_months': round(payback_months, 1),
        'avg_lifetime': round(avg_lifetime, 1)
    }
```

### 盈亏平衡分析

```python
def calc_breakeven(cost_results, params):
    """找出首次运营利润转正的年份"""
    for c in cost_results:
        if c['operating_profit'] > 0:
            return c['year']
    return 'Y5+'
```

### 现金流与融资规划

```python
def calc_cashflow(cost_results, params, financing_amount=0):
    """基于运营利润和融资额推算现金流和Runway"""
    monthly_burn = abs(min(c['operating_profit'] for c in cost_results)) / 12
    runway = financing_amount / monthly_burn if monthly_burn > 0 else 999
    return {
        'monthly_burn_rate': round(monthly_burn, 0),
        'runway_months': round(runway, 1),
        'financing_needed': financing_amount
    }
```

def calc_valuation_sensitivity(revenue_at_y3, industry_ps_range):
    """基于Y3收入和行业P/S倍数范围估算估值"""
    low_val = revenue_at_y3 * industry_ps_range[0]
    mid_val = revenue_at_y3 * industry_ps_range[1]
    high_val = revenue_at_y3 * industry_ps_range[2]

## 六、使用指南（AI执行时）

1. **收集7个必填参数**：通过精简问答获取（见SKILL.md信息收集清单）
2. **动态计算**：按上述公式计算收入、成本、单位经济、盈亏平衡
3. **生成预测表**：填入PPT财务预测页
4. **敏感性分析**：自动生成，展示关键变量变动影响
5. **行业对标**：与行业基准对比，标注红黄绿
6. **估值关联**：财务预测结果直接用于CIVM估值模型

**重要**：所有数值必须来自动态计算，绝不使用固定示例。如果用户只提供部分参数，AI使用行业基准补全，但必须明确标注"行业参考值"。
