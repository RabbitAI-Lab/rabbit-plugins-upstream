# Proposed change

## Independently adoptable item

**Proposal** — Name the change and who it affects.

**Where the rule would take effect** — Identify the L0 team rule, L1 topic or L2 feature rule. Link the current clause and quote the relevant text or version. For a new rule, describe existing coverage.

**Text after adoption** — Write the full usable clause with conditions and exceptions. For retirement, name the replacement or exit condition.

**Evidence** — Identify the authoritative decision, contract or accepted correction and what it establishes.

**Decision** — Ask the one question that changes the outcome. If already decided, cite the decision instead.
