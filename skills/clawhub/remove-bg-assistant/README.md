# 智能抠图助手 (Remove Background Assistant)

基于百度/腾讯 API 的 AI 智能抠图工具。

## 核心功能

1. **人像抠图** - 自动识别人物，去除背景
2. **商品抠图** - 电商产品图背景去除
3. **通用抠图** - 支持各类图片场景
4. **透明输出** - 生成 PNG 透明背景图
5. **API集成** - 提供网站集成示例代码
6. **批量处理** - 支持多张图片批量抠图

## 技术方案

- 百度图像分割 API（当前使用）
- 腾讯云数据万象 CI（规划中）
- Flask Web 界面
- 免费额度 + 付费扩展

## 适用人群

- 电商卖家

- 内容创作者
