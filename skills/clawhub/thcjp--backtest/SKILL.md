## 技术原理与算法验证
### 核心数学公式
```markdown
Sharpe Ratio = (Rp - Rf) / σp
其中：
Rp = 投资组合收益率
Rf = 无风险收益率
σp = 投资组合标准差
```
```markdown
Max Drawdown = (Pmax - Pmin) / Pmax
其中：
Pmax = 投资组合历史最高点
Pmin = 投资组合历史最低点
```
### 变量说明表格
| 变量名 | 含义 | 类型 | 取值范围/典型值 |
|--------|--------|--------|----------------|
| Rp | 投资组合收益率 | float | 0.01 - 0.1 |
| Rf | 无风险收益率 | float | 0.001 - 0.01 |
| σp | 投资组合标准差 | float | 0.01 - 0.1 |
| Pmax | 投资组合历史最高点 | float | 100 - 1000 |
| Pmin | 投资组合历史最低点 | float | 100 - 1000 |
### 数值计算示例
假设投资组合收益率为0.08，无风险收益率为0.02，标准差为0.05，计算夏普比率。
```python
Rp = 0.08
Rf = 0.02
σp = 0.05
Sharpe Ratio = (Rp - Rf) / σp
print("夏普比率：", Sharpe Ratio)
```
输出结果：夏普比率：1.2
### 公式适用条件和局限性说明
1. 适用条件：适用于投资组合收益率的计算，需要历史收益率和标准差数据。
2. 局限性：仅考虑历史数据，未考虑市场变化和未来风险。
