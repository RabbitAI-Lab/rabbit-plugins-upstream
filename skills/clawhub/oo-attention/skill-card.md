## Description:

Attention enables agents to operate Attention through an OOMOL-connected account for reading, creating, updating, and analyzing Attention data.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agents use this skill to retrieve Attention conversations, list teams and users, and ask Attention to analyze selected conversations or deals through OOMOL-managed credentials.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: First-time setup displays remote installer commands that pipe scripts directly into a shell.

Mitigation: Review the installer or use a trusted package method, and do not allow an agent to run installer commands automatically.
