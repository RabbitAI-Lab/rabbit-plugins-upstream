## Description:

Helps create menswear promotional videos by transferring motion from a reference video to a real or virtual model shown in a reference image.

This skill is ready for commercial/non-commercial use.

## Publisher:

[autoagc](https://clawhub.ai/user/autoagc)

### License/Terms of Use:

MIT-0

## Use Case:

Content creators and merchants use this skill to turn authorized reference footage and a model image into short menswear marketing videos through Qinghu AI.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Reference media is uploaded to the Qinghu service and may include third-party likenesses or protected content.

Mitigation: Use only media and likenesses you are authorized to upload and use commercially.

Risk: Generating videos may consume paid Qinghu credits.

Mitigation: Request a current estimate with the reference video and obtain approval before generating.

Risk: The workflow may install or update the qhkit Node CLI and requires an API token.

Mitigation: Prefer a vetted, pinned or already-installed CLI version and provide only an authorized token.
