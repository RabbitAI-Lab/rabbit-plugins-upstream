## Description:

Helps agents write, revise, and review Chinese-first interface copy in concise, natural language, with guidance for common UI text types.

This skill is ready for commercial/non-commercial use.

## Publisher:

[yzfly](https://clawhub.ai/user/yzfly)

### License/Terms of Use:

CC BY-NC 4.0

## Use Case:

Product writers, designers, and developers use this skill to draft or improve interface text such as buttons, forms, empty states, notifications, dialogs, and error messages. It can also review existing copy and help establish consistent terminology.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The documented installer uses global scope and automatic confirmation.

Mitigation: Review the installer and repository revision before installing.

Risk: Suggested wording may not match a product's locale conventions.

Mitigation: Review proposed copy and specify the product's locale conventions when they differ from the skill's defaults.

Risk: The artifact license and server evidence report different license identifiers.

Mitigation: Confirm the applicable license before redistribution or commercial use.
