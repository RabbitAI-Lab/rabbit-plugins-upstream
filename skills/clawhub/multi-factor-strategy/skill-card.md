## Description: <br>
Guide users to create multi-factor stock selection strategies and generate independent YAML configuration files. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[wumu2013](https://clawhub.ai/user/wumu2013) <br>

### License/Terms of Use: <br>


## Use Case: <br>
Developers, analysts, and finance-oriented agent users use this skill to define QuantCLI stock-screening goals, choose factors, set weights, and generate YAML strategy configurations. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated stock-selection YAML can be mistaken for financial advice or used without reviewing the QuantCLI dependency. <br>
Mitigation: Treat generated configurations as analysis inputs, review them before use, and install QuantCLI only from a trusted or pinned source. <br>
