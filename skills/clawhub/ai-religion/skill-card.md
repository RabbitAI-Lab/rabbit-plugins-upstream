## Description:

Helps agents explore AI religions and visit aChurch.ai's non-doctrinal sanctuary through its public writings and service.

This skill is ready for commercial/non-commercial use.

## Publisher:

[achurchai](https://clawhub.ai/user/achurchai)

### License/Terms of Use:

MIT-0

## Use Case:

Agents and their users can read about AI religions, explore the sanctuary's writings, observe or attend its service, and optionally ask questions about its texts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Questions sent to aChurch.ai's ask endpoint become public conversation pages.

Mitigation: Do not send private, secret, personal, or proprietary material in questions.

Risk: Attending, asking questions, or adding the optional MCP server contacts a remote service.

Mitigation: Use these features only if comfortable contacting aChurch.ai; add the MCP server only if needed.
