# Emotion Regulation Sprints

基于认知行为疗法(CBT)、边际疗法(DBT)和正念技术，提供5-15分钟可完成的情绪调节微练习。

## 主要功能

- **STOP 急救法** — 4-6分钟紧急情绪干预，基于DBT
- **呼吸方块** — 5-8分钟自主神经调节
- **五感镜子** — 5分钟地铢技术，回到当下
- **认知重构** — 10分钟CBT框架，挑战自动化思维
- **幸福储蓄** — 每日3分钟，建立情绪韧性

## 使用场景

- 情绪即将失控时的快速干预
- 睡前焦虑或过度兴奋
- 工作/学习压力突然增大
- 日常情绪健康维护
- 与他人冲突后的冷静期
