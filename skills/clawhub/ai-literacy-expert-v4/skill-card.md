## Description:

Generates AI-literacy courseware, p5.js interactive lessons and games, and guided lesson-prep document packages for teachers and students.

This skill is ready for commercial/non-commercial use.

## Publisher:

[gqliang2026](https://clawhub.ai/user/gqliang2026)

### License/Terms of Use:

MIT-0

## Use Case:

Teachers, instructional designers, and education-focused developers use this skill to create AI-literacy lessons, interactive p5.js courseware, learning games, quizzes, and multi-format lesson-prep packages for middle-school, university, and professional audiences.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated teaching HTML or server code may use CDNs, API submission, audit logging, localStorage drafts, and document downloads in ways that need review before classroom deployment.

Mitigation: Review generated HTML and server code before use in real school or training environments, especially CDN loading, API submission, logging, localStorage, and download behavior.

Risk: Lesson-prep workflows may involve student or teacher information if users enter it into generated tools.

Mitigation: Avoid entering student personal data, add privacy notices and retention limits for any logging, and keep API keys server-side.
