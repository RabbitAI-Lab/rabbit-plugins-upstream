# Rubric：统计报告规范维度评分标准（1—5 分）

适用于 results-statistics-convention-checker。评分对象为英文心理学论文 **Results 部分** 的统计报告规范性。评分时先在草稿中定位全部统计陈述，再结合 `references/examples/examples_memberB.md` 对照定级。

## 5 分：高度规范，几乎无需修改

表现包括：

- 描述统计完整：所有比较的组别均报告 M 与 SD（或 Mdn），格式全文一致；
- 推断统计完整：t、F、χ² 等均带自由度，如 t(59) = 7.10、F(1, 208) = 5.98（参照 B-01、B-02）；
- p 值报告规范：报告精确 p 值（如 p = .02、p = .52），或使用规范的阈值报告（p < .001），无 p = .000、无把 p < .1 当显著；
- 报告效应量：主要效应给出 Cohen's d、partial η²、r、β 等，并有大小解读（参照 B-13）；
- 关键比较给出 95% CI（正文或表格中，参照 B-11）；
- 文中数值与图表一致，文字结论与统计结果方向一致；
- 不显著结果同样完整报告（参照 B-02）。

## 4 分：整体规范，仅有少量格式问题

表现包括：

- 描述统计与推断统计基本完整，个别处缺 SD 或自由度；
- p 值报告基本规范，个别处只给 p < .05 而未给精确值；
- 主要结果报告了效应量，但缺少解读或个别遗漏；
- 存在少量格式瑕疵：斜体缺失、空格不统一（如 "p<0.05" 与 "p < 0.05" 混用）、小数位不一致；
- 不影响读者对结果的判断与复核。

## 3 分：基本可用，但有明显问题

表现包括：

- 部分统计检验只报 p 值，缺统计量或自由度（如只写 "p < .05"）；
- 效应量基本缺失，或只在部分结果中报告；
- "X ± Y" 未界定 ± 为 SD 还是 SEM（参照 B-03、B-07）；
- 存在 p = .000、前导零混用（0.05 与 .05 并存）等规范问题；
- 文中个别数值与图表不一致，或文字结论与统计方向不完全吻合；
- 需要中等程度修改才能达到 APA 规范。

## 2 分：问题较多，影响学术规范性

表现包括：

- 统计报告缺项普遍：多处只有 p 值或只有 "significant" 字样，无统计量、自由度（参照 B-08）；
- 完全未报告效应量与置信区间；
- 把 p < .1 当作显著结果陈述，未标注边缘显著（参照 B-04、B-08）；
- 声称组间差异（higher/lower）但无任何检验支撑（参照 B-10）；
- 文中数值与图表多处不一致；
- 需要大幅修改。

## 1 分：严重不符合统计报告要求

表现包括：

- Results 中几乎没有规范的统计报告：无 M/SD、无检验统计量、无 p 值，只有百分比或 "data analysis shows" 式模糊表述（参照 B-09）；
- 显著性结论完全无法从所给信息复核；
- 统计结果与文字描述严重脱节或互相矛盾；
- 需要重写 Results 的全部统计陈述。

## 单项问题对评分的影响速查

| 问题 | 对评分的影响 |
| --- | --- |
| F/t/χ² 缺自由度 | 每类出现即不高于 4 分；普遍出现不高于 3 分 |
| 只报 p 值、无统计量 | 不高于 3 分；普遍如此不高于 2 分 |
| 缺效应量 | 不高于 4 分；完全缺失不高于 3 分 |
| 缺 95% CI（期刊/APA 建议报告处） | 不高于 4 分 |
| p = .000 / 前导零混用 / 斜体缺失 | 格式瑕疵，单项不降级，多项叠加降 1 级 |
| p < .1 当显著、未标边缘显著 | 不高于 3 分 |
| ± 未界定 SD/SEM | 不高于 4 分 |
| 文中数值与图表不一致 | 每处不高于 3 分，多处不高于 2 分 |
| 无任何推断统计支撑差异结论 | 不高于 2 分 |
| 无任何 M/SD 与检验（纯描述） | 1—2 分 |
