# 独立真值获取与有限审核抽样

先解决“依据从哪里来”，再决定审核多少。真值独立于候选结论，不要求每轮必有第二人；同人依独立材料判定仍是建设者自评，不冒称独立人员审核。

## 1. 真值获取路径

| 要判断的内容 | 优先获取路径 | 防止循环 |
|---|---|---|
| T1状态检查 | 固定对象×检查项×时点；按事前规格，用允许输入手算/独立参考计算器建立期望，再看候选结果 | 不把候选输出另存为expected；测试预期也需检查依据 |
| T2漏跑/漏检 | 冻结调度配置或受理清单，展开应执行任务；独立工单/监控/值班记录建立已知事件集 | 只有结果库不能发现静默漏跑；只有被检告警不能建立全量事件真值 |
| T4原因定位 | 事故复盘、已确认修复与事后验证、实验注入及实际生效证据，核对粒度和版本 | 工单若只转抄被检结论仍是循环来源；注入意图不等于故障实际生效 |
| E4结论支持 | 将关键Claim逐条关联原始证据，按结论类型的最低要素审核，可用删唯一证据变体检查判定变化 | URL存在不等于充分支持；候选自己生成的解释不是新证据 |

能先隐藏候选判断时，先按输入与规则建立期望。来源标注合成/注入/自然事件；审核结论保存案例ID、判据、证据来源/版本、审核者身份和分歧。没有独立依据的项保留U或按自标规程另列，不用“已写audit_verdict”替代来源核验。

## 2. 有限审核的起步办法

1. 固定范围、任务类型、时间窗和清单。评精确率可从冻结去重规则下的发现组抽样；评检查正确性需应检清单（含正常、UNKNOWN、漏跑），评召回需独立事件清单。191条IR不是天然适用于所有指标的分母。
2. 将业务严重度、服务/检查项、时间/版本作为有理由的分层；缺失和未分类单列，不能按候选判定“容易正确”的标签择优。
3. 已知严重违规和漏检全部列为底线事实，不通过抽样稀释。需审核的高风险项可优先全核；预算不足时保留未核覆盖缺口，不能宣称整个高风险集通过。异常/UNKNOWN/漏跑路径安排诊断样本。
4. 对其余分层在审核预算内随机/系统抽取，保存方法、种子或抽取起点、名单、抽取时点；相关同事故或同任务的多条结果登记聚类，不当作多个独立样本。无法满足概率抽样时只作所选样本描述。
5. 不换失败样本、不反复加样直到结果变好。先导审核可用少量案例暴露字段/标注问题，之后另冻结扩大方案；报告每层N、n、未审核数及独立事故/任务数。定向诊断与代表性样本分开。

例如预算只够10个单元，可约定2个高风险诊断样本＋4个普通时段随机样本＋4个异常/缺失路径样本；这只是本轮操作方案，需与实际分层、预算相符，不是最低统计样本量，也不能把混合x/10当总体正确率。可先约定一个核材料时间盒（数值由使用者定），不保证10条必能在该时间内审核完。

不设通用“高100%/中30%/低10%”：可作为具名任务的预算方案，但需说明依据、覆盖与推断范围。若做分层总体推断，需要各层总体规模、抽取概率、权重和匹配的区间方法；本Skill不提供未经验证的分层/聚类置信区间计算，缺这些条件时保持分层描述。

## 3. 样本量与两类区间

- **未知标签界限**：T/F/U已定义且总数>0时即可给`[T/(T+F+U), (T+U)/(T+F+U)]`，无需凑30条。例如T=2、F=0、U=1为`[2/3,1]`，只描述这3条标签不确定性；总数0为N/A。
- **有限全集**：已覆盖目标清单全部单位，报告该清单x/n，不强加抽样置信区间；不能外推其他平台或时期。
- **抽样置信区间**：沿用源规范，只有完整标签、独立二项单位与适用抽样设计时，缺省双侧95% Wilson。小n仍可计算但显示宽度与假设；n≥30不自动使便利样本、聚类或缺失标签可外推。方法参考[NIST比例区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)。

因此先确定要支持的决策、允许不确定性和审核预算，再决定样本量；没有这些依据时给范围内描述和下一步，不发明“最小可统计样本量”。未知标签界限和统计置信区间分别报告，不互换。

**“够不够”的可操作判据——决策翻转检验**：把点估计 x/n 换成区间另一端，看你要支持的结论会不会翻转。会翻转 → 当前样本量不足以支持该决策，只给描述与区间；不会翻转 → 该决策在这个不确定性下站得住。例如 3/4=75%、区间[25%,50%]：若你的决策是“至少一半正确”，换成下端 25% 结论翻转 → 不支持，只能报区间。这给出一条不依赖魔法数字的操作线：**样本量是否足够，取决于区间宽度是否小于你的决策需要的分辨力**，而不是某个通用 n。
