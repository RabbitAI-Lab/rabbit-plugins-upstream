# 范围与指标口径（46 项原子指标）

> 提取自核心指标字典 v0.7。每项一行：口径 + 最关键规则。按任务入口只读取入选项；必需缺证据项逐项登记，其他任务/维度可合并说明未纳入。通常3～5项，组合任务可更多，不因数量上限删除必需责任。

## E1 业务有效性（14 项）

| ID | 指标 | 口径与关键规则 |
|---|---|---|
| E1-01a | 关键风险验证覆盖率 | 经场景验证通过的关键风险条目 / 应覆盖关键风险条目；不能靠拆分易例扩大分子 |
| E1-02a | 去重发现精确率 | 审核正确的唯一发现组 / 已审核唯一发现组；正常输出**不进**此分母；未知/争议单列，可报区间；组键（对象×检查项×固定聚合窗）与“发现/正常输出”分类判据**事前冻结**并在报告披露，不得事后调整；确定性规则触发与非确定性判定**分列**，确定性易例不得抬高后者的精确率 |
| E1-03a | 事件召回率 | 至少一个有效匹配的真实事件 / 应检真实事件总数；运行失败、输入失败造成的漏检**不移出分母** |
| E1-03b | 按时事件召回率 | 首个有效结果不晚于发现期限的事件 / 应检事件；有效时刻=内容+证据+交付均满足，不用首次文字输出替代 |
| E1-04a | 根因 Top-K 命中率 | 前 K 个去重根因含确认根因 / 具备确认根因的案例数；拒答、运行失败计未命中；合理推测不算命中；真值未知的案例排除并报告数量 |
| E1-04b | 影响对象精确率 | 正确的影响对象声明 / 已审核影响声明；不输出不能靠 n=0 通过 |
| E1-04c | 影响对象召回率 | 已正确声明的真实影响对象 / 应识别影响对象；缺失输出计未命中 |
| E1-05a | 应交付建议有效率 | 期限内交付且满足适用/具体/可验证/安全条件的建议任务 / 契约要求建议的任务；缺失建议计失败（契约允许的升级单列） |
| E1-06a | 预测命中率 | 已确认结果中窗口内发生且要素齐备的独立预测 / 结果已确认的合格独立预测；同报确认覆盖率与区间；不得剔除未知后单独达标；命中判定不要求证据支持，证据质量另按 E4-01a 评；窗口边界等于边界算满足（容差为自检前冻结的参数，容差外临近单列） |
| E1-06b | 预测有效提前量 | 事件发生时刻 − 预测发布有效时刻；仅限命中预测；不与发现时效混算 |
| E1-06c | 预测风险召回率 | 被命中预测覆盖的确认风险 / 观察成熟期内确认发生的目标风险；防只对易例发预测 |
| E1-06d | 预测响应延迟 | 发布有效时刻 − 最早可预测时刻；与提前量独立（信息早已充分而迟迟不发布，提前量长而延迟差） |
| E1-07a | 检查输出正确率 | 与独立期望一致的检查单元 / 全部应检查单元；正常、异常、UNKNOWN 都进分母；缺失/冲突/迟交计不正确；无独立期望时按证据规则§6做自标分析，不作独立检查正确率；被检系统原始输入的回放对照可作自评依据，但不作独立复核；抽样按证据规则§5.1披露设计与覆盖 |
| E1-08a | 处置行动有效恢复率 | 时限内目标恢复+副作用在预算内+独立证据源验证的授权行动 / 已执行授权行动；不以命令返回成功或故障暂时消失为准；行动后自愈单列 |

## E3-01a与in_progress的边界

先按已有契约确认计划/受理清单、纳入窗口、截止时刻与输出要求，再关联inspection_records等执行结果。表名不决定资格：若它是独立、完整的受理台账且在执行前登记，也可能承担受理清单；若只有已执行/已输出行，则不能识别静默漏跑。

| 情况 | 处理 |
|---|---|
| 应执行任务已过截止，仍in_progress或无结果行 | 保留分母，不能计期限内完成；终态状态不是纳入条件 |
| 尚未到截止 | 单列待完成及其截止，不提前判失败；只有原契约已规定到期队列时才按该队列取分母，否则保留原集合及未决，不事后改分母 |
| 截止或应执行清单缺失 | E3-01a尚不可测或未能最终判断；可另描述已观察记录，不能声称漏跑率 |
| completed/(completed+failed+budget_exhausted)且仅来自结果库 | 只说明该库已观察终态记录的完成占比；还需核对completed是否满足运行契约，不能直接映射为E3-01a |

跨报告比较固定同一纳入与截止规则；辅助终态比例、在途数量和静默漏跑覆盖分别标注，不能因改了名称就声称完成原指标。
