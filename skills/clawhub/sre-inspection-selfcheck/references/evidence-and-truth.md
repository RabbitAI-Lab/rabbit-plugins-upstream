# 证据规则、真值与预测/处置语义

> 提取自主设计 v2.3 §5、真值与事件匹配协议 v0.5、核心指标字典 v0.7。

## 1. 评价单位

检查单元（对象×检查项×时点）、一次运行（Run）、一条发现（Finding）、一个独立事件、用户任务、团队周期、一次变更（Change）。同一事实可在不同单位各记一次（漏跑记运行失败 + 漏检记事件），这不是重复计分；**防重复加权只发生在跨维度汇总权衡时**（按主归属计一次），不改变各指标的原始记录。

## 2. 证据规则（八条）

1. 真值独立于被测结论：方案自己的判断不能当真值；合成、注入、自然事故数据**分别报告**，不混成实战召回。
2. 正常输出进检查正确率（E1-07a），**不进**异常发现精确率（E1-02a）分母。
3. 数据缺失不能判健康：只能输出 UNKNOWN，并注明缺失原因。
4. 运行失败、漏跑、缺失输出**不能事后从分母移除**——分母来自计划/应检清单，不是运行日志。
5. 同一事件的重复发现只算一次检出，重复负担（重复条数/原始条数）另报。
6. 按时判定用**首个满足内容+证据+交付条件的有效时刻**（first_valid_at），不用首次文字输出替代；证据不足时不回退初稿时间，记时间证据不足。
7. 未知与争议单列：审核后仍有 U 组无法判定时，报确认子集比例 T/(T+F) 并给全量区间 `[T/(T+F+U), (T+U)/(T+F+U)]`；区间不是统计置信区间。
8. 以越权数据取得的“真实发现”**不进命中分子**：单列“非法证据发现”，其业务价值单独描述，不与合法发现混算比例。

## 3. 预测语义（E1-06 族，七类结果）

**双锚点**：`detectable_at` = 最早可判定**已发生**（发现口径）；`predictable_at` = 最早可判定**将发生**（预测口径）。两者不互换。

**双口径**：提前量 = 事件发生时刻 − 发布有效时刻（E1-06b）；响应延迟 = 发布有效时刻 − 最早可预测时刻（E1-06d）。互相独立：信息早已充分而迟迟不发布 → 提前量可很长、响应延迟很差。

| 结果类别 | 处理 |
|---|---|
| 窗口内发生且声明齐备 | 命中，进分子；计算提前量 |
| 窗口外发生（确认） | 未命中，进分母 |
| 观察完整且确认未发生 | 未命中（基本负例），进分母，不计算提前量 |
| 发布时目标已发生 | 排除，单列“已可观测声明”（检测冒充预测），可另按发现口径评价；发布时信息已足以推断未来**不构成排除**，由响应延迟度量 |
| 受干预 | 单列，不入分母；披露干预剔除占比（预测与干预同主体必须披露）；干预后未发生不等于预防成功 |
| 失观且结果未知（含因风险本身致遥测中断） | 单列 U，不计失败不计删失；点估计分母=确认子集，**必须同报**确认覆盖率与全量区间 `[命中/(确认+U), (命中+U)/(确认+U)]`；不得剔除 U 后单独声称达标 |
| 与目标无关的失观 | 右删失（未成熟），不入合格池 |

确定性可计算的未来结果（如证书到期日）属 T1 边界，不按预测指标评价。同一风险多次预测：合并组代表事前定死，禁止事后择优；声明不齐备（无对象/无窗口）不入分母，单列并报声明完备率。**历史回放自检只能使用预测发布时刻可见的输入**；使用了事后才到达的数据即为输入泄漏，该样本作废、不计入任何分子。

## 4. 处置语义（E1-08a）

- 分母 = **已开始执行**的授权行动；半途失败/部分执行计未有效恢复；授权后未开始单列；一次逻辑行动的内部重试不增分母。
- 恢复判定 = 目标状态恢复 + 预期效果达成 + 副作用在预算内 + **独立于被测方案的证据源**验证（探测/监控/审计记录；不必然是第二个人）。
- 不以命令返回成功、故障暂时消失为准；行动后目标自愈单列，不入分子。
- 责任边界：人机小队中方案责任范围内的**人工执行（含按方案指定操作流程执行的动作）纳入并按执行主体分层**；范围外的人工执行不计入。

## 5. 真值完备性

只有已知事故、没有完整事件发现机制时，只能报告“已知事件集召回”，不能宣称全量召回。已知事件集的确认渠道**必须独立于被检输出**（值班记录/工单/人工确认，不得用被检方自己的告警充当分母来源），并**同报观察盲区时长与占比**（漏跑、数据缺失、无回执时段）——盲区内事件不可见，召回仅对已观察部分成立。真值修订（发现标错）应创建新版本并统一重算，不覆盖旧结果。

### 5.1 检查正确率的抽样

抽样计算E1-07a时，按服务×检查项×时段分层，已知异常、UNKNOWN和漏跑时段须入样；披露抽样框、方法、样本量及抽取时点，事后不换样。异常/缺失的定向入样会改变样本组成，因此只作该样本或各分层描述，不将混合样本比率直接当作总体正确率；总体推断仍需匹配抽样设计与权重。未测分层和整套检查的覆盖缺口另列。

## 6. 自评审核最小规程

无独立真值时 T/F/U 由被检方自标，只加“自评口径”标签不够，还必须：

1. 每条唯一发现组列出可独立复核的证据要素（对象/时间/数值或状态/触发依据）。
2. 失败样本为零时，逐项声明“未发现失败样本”，并附对若干“正确”样本的否证尝试记录（尝试证伪而未果）。
3. 一切自评结论标注 `reviewer=self`（自认，未经独立复核），不得表述为“已确认”“已验证”。
