## Description:

Turns a browser game or three.js/WebGL scene into a cinematic MP4 trailer with frame-accurate capture, directed shots, music, and quality checks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to capture and edit a browser game's gameplay into a paced trailer, with scripted camera moves, titles, sound, and checks for common video issues.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The server security assessment reports a local capture-server path-containment weakness and incomplete scan coverage.

Mitigation: Review the path-containment issue and scan coverage before installing; if proceeding, use a reviewed, pinned installer version and limit the skill's file and permission access.
