## Description: <br>
AgentPMT Workflow Creator helps agents build and manage multi-step AgentPMT workflows that chain tools, prompts, loops, branches, human notifications, and publishing actions through AgentPMT-hosted remote tool calls. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[agentpmt](https://clawhub.ai/user/agentpmt) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and workflow operators use this skill to create, validate, update, publish, remix, restore, and manage AgentPMT workflow drafts for reusable automation pipelines. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can guide agents through high-impact workflow actions such as publish, delete, restore, visibility changes, and context attachment. <br>
Mitigation: Before those actions, require the agent to show the target workflow ID, current draft revision, and intended effect, then get explicit confirmation. <br>
