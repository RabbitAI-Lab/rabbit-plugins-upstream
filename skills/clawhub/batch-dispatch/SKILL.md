# 攒单批量派发·不再返工

## 这是什么

管人管岗最常见的内耗：**发现问题→立刻派单→又发现问题→再派一单→前面那单返工**。一天派八次，每次都不完整。这套**攒单批量派发法**来自真实参谋岗的派工磨合：问题先攒，聊透再发，一发到位。

## 五步逐条

1. **有问题先挂账，不急着派**：发现问题先记下来，接着把手头这轮聊完。立刻派出去的单，大概率下十分钟就要改。
2. **聊透为准，不数个数**：攒到什么时候发？不看凑够几个，看**工作量信号**——这个话题聊明白了、能一句话说清要求了，就算攒够。三个也行、一个也行、五个也行，判断权在你。几个话题交错着聊很正常，每条账各自盯着「聊透没有」。
3. **攒够主动问一句**：判断攒够了，主动确认：「现在攒了 N 个，还有没有？没有我就发一波。」**发之前必问**，这一问能拦住九成返工。
4. **一声令下，统一派发**：一次发齐，每单写清做什么、给谁、什么顺序，不留空、不写待定——挂起也是一种明确结论。
5. **派后不再追加**：发完又冒出问题？进下一波的账，**不许塞进已经发出去的波次**。已经派的单让它跑完，改话只会制造返工。

## 一句话节奏

诊断 → 攒单 → 确认 → 统一派 → 接着聊下一波。

## 止损线

单条账挂太久没聊透（比如过了一天），主动收口：要么发出去，要么明确挂起给结论——不许永远「攒着」。
