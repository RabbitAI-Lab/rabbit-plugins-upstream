## Description:

Plan and review image, video, and audio generation workflows, including creative briefs, prompt design, reference checks, and iteration plans.

This skill is ready for commercial/non-commercial use.

## Use Case:

Creators and teams use this skill to plan image, video, or audio projects, review prompts and reference-media rights, and prepare an actionable generation workflow.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Optional MCP setup can persist an unpinned GitHub-based server that may execute different local code later.

Mitigation: Review the referenced MCP repository, pin a reviewed commit or release, and configure it only if local execution is acceptable.

Risk: Using media references without permission or relying on outdated model capabilities and costs.

Mitigation: Confirm rights to source media and verify current settings and costs in the live studio before generation.
