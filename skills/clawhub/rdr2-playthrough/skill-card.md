## Description:

Use when maintaining RDR2 (Red Dead Redemption 2) playthrough notes — logging an acquisition ("acquired X", "got N gold bars", "finished X"), answering in-game location/crafting questions, or reviewing the notes for duplicate or stale info.

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: The skill can be triggered by generic terms such as horse or weapon outside an RDR2 context.

Mitigation: Confirm the request is about Red Dead Redemption 2 before applying the skill's note-maintenance workflow.

Risk: Suggested edits could add incorrect game facts or duplicate existing note content.

Mitigation: Verify game facts before writing, propose the exact edit, and wait for user approval before changing notes.
