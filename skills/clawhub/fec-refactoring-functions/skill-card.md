## Use Case:

Frontend developers use this skill to select and apply small, behavior-preserving changes to function structure, names, parameters, shared context, and phase boundaries, checking each step before proceeding.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Frontend refactoring may unintentionally change observable behavior.

Mitigation: Use only where code changes are acceptable; review each small diff and run relevant tests before continuing.
