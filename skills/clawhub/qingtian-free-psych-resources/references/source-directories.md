# 权威目录源与信源优先级

基线库不足或需要核验时，按以下优先级联网搜索。**每个结果必须保留来源 URL 与核验日期。**

## 信源优先级（从高到低）

1. **政府卫生部门 / 国家级热线官网**：如 nhc.gov.cn（中国卫健委）、988lifeline.org（美国）、nhs.uk（英国）、mhlw.go.jp（日本厚劳省）
2. **权威全球目录**：Find A Helpline（findahelpline.com，175+ 国 2000+ 热线）、Befrienders Worldwide（befrienders.org，Samaritans 全球网络）、IASP 危机中心名单
3. **国际健康信息站**：helpguide.org（免费/低价线上咨询汇总）、Mental Health America、NAMI
4. **NGO / 公益组织官网**：Samaritans、Mind、NAMI、MindForward Alliance、各国本地公益机构
5. **高校 / 机构官方页面**：大学心理咨询中心、医院官网
6. **主流媒体**：仅用于交叉验证（如号码变更新闻），不作主来源

## 核验流程

1. 找到资源 → 打开官方来源页确认号码/费用/时段/语言
2. 记录：来源 URL + 核验日期 + 与基线差异
3. 差异处理：基线过时 → 更新基线并标注新核验日期；来源冲突 → 以官方最新为准并标注
4. 危机号码变更（如韩国 1393→109）→ 只保留现行号码，并在输出注明变更
