# 跨国在线平台与免费通道

> 核验日期基准：2026-09-16。使用前复核官方页面；免费范围必须准确标注。

## 在线倾听 / 文字支持

### 1. 7 Cups
- **状态**：verified
- **类型**：text_chat / platform_free
- **免费范围**：志愿者倾听者免费 24/7（多语言）；持证治疗师为付费层（约 $159–$299/月）
- **注意**：免费层是志愿者倾听，非专业治疗；输出必须区分两层
- **来源**：https://www.7cups.com/

### 2. Crisis Text Line
- **状态**：verified
- **类型**：text_chat
- **覆盖**：美国、加拿大、英国、爱尔兰
- **方式**：短信（美/加发 HOME 至 741741；英发 SHOUT 至 85258）
- **免费范围**：服务本身免费；运营商短信费除外（AT&T/T-Mobile/Sprint/Verizon 免费）
- **时段**：24/7
- **危机能力**：是
- **来源**：https://www.crisistextline.org/about-us/faq/

### 3. 988 Suicide & Crisis Lifeline（美国）
- **状态**：verified
- **类型**：crisis_helpline
- **方式**：电话 / 短信 / 在线聊天
- **免费范围**：免费、保密、24/7；无需公民身份/保险
- **语言**：英语；西语专线（按 2）
- **来源**：https://988lifeline.org/

## 在线治疗平台免费/低价通道

### 4. BetterHelp（助学金）
- **状态**：verified
- **类型**：platform_free
- **免费范围**：**无免费层**；财务援助仅 10%–40% 减价
- **注意**：不得标注"免费"，只能说"可申请助学金"
- **来源**：BetterHelp 官网（使用前核验当前政策）

### 5. Open Path Collective
- **状态**：verified
- **类型**：platform_free
- **免费范围**：非免费；终身会员费 $65，咨询 $30–$70/次（低价非免费）
- **注意**：低价渠道，标注"低价而非免费"
- **来源**：openpathcollective.org

### 6. Wysa
- **状态**：verified
- **类型**：ai_tool
- **免费范围**：AI 对话免费层；Premium $74.99/年
- **标注**：AI 工具，非专业咨询替代
- **来源**：wysa.io

### 7. Woebot
- **状态**：expired（消费者端 App 已于 2025-06-30 关闭，转向 B2B；个人无法注册）
- **注意**：不再推荐；多家 2026 测评站仍误标"免费可用"，必须纠正

## 全球目录

### 8. Find A Helpline
- **状态**：verified
- **类型**：global directory
- **覆盖**：175+ 国 2000+ 热线
- **用法**：按国家/主题搜索，作为空结果兜底
- **来源**：findahelpline.com

### 9. The Trevor Project（LGBTQ+ 青年，美国）
- **状态**：verified（注意：988 内按 3 的 LGBTQ+ 专线已于 2025-07-17 终止，以 Trevor Project 独立服务为准）
- **方式**：电话 / 短信 / 在线聊天，24/7
- **适用**：25 岁以下 LGBTQ+ 青年
- **来源**：thetrevorproject.org

## 使用提示

1. "免费"标注必须与真实范围一致：区分 完全免费 / 低价 / 助学金 / 免费层（志愿者/AI）。
2. AI 工具（Wysa/Woebot 等）一律标注"非专业咨询替代"。
3. 平台免费层与付费层严格区分，不得用免费层信息冒充专业服务。
