## 2. 访问协议（按优先级尝试）

### ① 腾讯文档 MCP（首选，环境具备时）
1. 先按技能发现流程读取 `tencent-docs-operations` skill 的 `SKILL.md`（该 skill 管理腾讯文档读写 MCP 工具）。
2. 调用前先 `tool_search` 获取对应 MCP 工具的实时 schema（工具名以 `mcp__tencent_docs__` 开头）。
3. 读取全表文本：`mcp__tencent_docs__get_content`（file_id + sheet_id）。
4. 按区域/筛选读取单元格：`mcp__tencent_docs__get_cell_data`（file_id、sheet_id、start_row/end_row/start_col/end_col，0-based；`return_csv=true` 时返回 CSV）。
5. 读取表格元信息：`mcp__tencent_docs__get_sheet_info`（确认行数、列数、used_range）。
6. 写入/更新表格：`mcp__tencent_docs__set_range_value`（values 数组，每项 `{row, col, value_type, string_value}`，0-based）。

### ② 浏览器打开（无 MCP 权限时）
用浏览器自动化打开链接 `https://docs.qq.com/sheet/DTG5OU3Jad1dEeGNt?tab=BB08J2`，等待渲染完成后逐屏读取表格内容。腾讯文档需登录态；未登录时提示"需登录后查看"并退回基线库。

### ③ 静态基线库兜底（离线/无访问权限时）
使用 `references/china-resources.md`、`references/international-resources.md`、`references/online-platforms.md`、`references/ai-tools.md`，并在输出中注明"数据来自静态基线库（核验于 YYYY-MM-DD），未能访问在线总表"。

## 4. 使用规则

1. **总表优先**：回答用户关于免费心理资源的问题时，先读总表筛选匹配行；总表不可用时才用基线库。
2. **核验状态处理**：总表中「核验状态=已失效」的条目不推荐，给出替代；「待核验」条目标注"使用前请以官方为准"。
3. **类别过滤**：用户要咨询→类别=免费心理咨询；要倾诉→免费心理倾诉；要 AI→免费心理AI；测评→走测评模块（不查总表）。
4. **危机优先**：命中危机信号时先输出 T0/T1 危机资源（见主 SKILL.md 危机优先协议），仍可从总表取号码，但优先取核验状态=已核验 的危机类条目。
5. **时效性**：以总表行 0「最后更新时间」和每条「最新核验时间」为准；核验日期距今 >6 个月的条目输出时追加时效警示。
6. **更新约定**：技能运行中发现号码变更/失效时，可经用户确认后写回总表（set_range_value），并更新「最新核验时间」与「核验状态」。
