## Description:

Synchronizes README.md with a Simplified Chinese README-zh.md while keeping English as the primary source.

This skill is ready for commercial/non-commercial use.

## Publisher:

[j3ffyang](https://clawhub.ai/user/j3ffyang)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and maintainers use this skill to keep an English README and Simplified Chinese README aligned, with cross-language navigation links and documentation-only edits.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated translations or grammar corrections may change meaning in project documentation.

Mitigation: Review README-zh.md and any README.md edits before publishing or committing the changes.

Risk: The skill intentionally edits README.md and README-zh.md to add or update language navigation links.

Mitigation: Check the resulting navigation links and confirm no non-documentation files were modified.
