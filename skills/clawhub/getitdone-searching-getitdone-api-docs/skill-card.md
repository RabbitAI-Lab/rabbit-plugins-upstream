This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and integration builders use this skill to look up GetItDone API operations, authentication, and error codes in published documentation without changing tasks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Documentation snippets may omit details needed for an accurate API answer.

Mitigation: Read the full documentation page when needed, cite the pages used, and state when the documentation does not cover the question.

Risk: API keys or tokens could be exposed in examples.

Mitigation: Use placeholders instead of real credentials.
