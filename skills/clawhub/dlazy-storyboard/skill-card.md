## Description:

Helps create multi-shot animated shorts with consistent characters, from storyboards and character references through audio and rendered video.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and production teams use this skill to plan and generate multi-shot animated shorts with consistent characters, voice, music, subtitles, and video assembly.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and attached files are sent to dLazy's hosted service.

Mitigation: Share only prompts and files intended for that service; review attachments before uploading.

Risk: Logging in can save a dLazy API key locally, and global installation persists the CLI.

Mitigation: Protect local credentials, rotate or revoke the key if needed, and use the pinned npx option to avoid a persistent global installation.
