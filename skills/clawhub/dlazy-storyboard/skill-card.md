## Description:

Creates multi-shot animated shorts with consistent characters, from storyboards and character references through video clips, narration, sound, subtitles, and final assembly.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to plan and generate multi-shot animated videos with consistent characters, voice, music, sound effects, and subtitles.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installing the external CLI and using the hosted service involves third-party software and service terms.

Mitigation: Review the pinned @dlazy/cli package and dLazy service terms before installing or using the skill.

Risk: Prompts, options, and attached files are sent to dLazy for processing.

Mitigation: Avoid sharing sensitive information and review attachments before submitting them.

Risk: Login stores a dLazy API key locally for later use.

Mitigation: Protect the local credential and rotate or revoke the key if it is exposed.
