## Description:

Maintains a live, layered dependency map of development work, tracking design, implementation, verification, and regressions across project pages.

This skill is ready for commercial/non-commercial use.

## Publisher:

[qikairo7](https://clawhub.ai/user/qikairo7)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to plan and track multi-part implementation work as a layered dependency map, resume work across sessions, and show verified progress or regressions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Mapping creates or updates local .mellos project files and may save a user or project mapping preference.

Mitigation: Review mapping scope and saved preference; select on-request to avoid automatic map opening.

Risk: Opening a map may start a local viewer or terminal pane; registration commands can change the host setup.

Mitigation: Use viewer actions only on the chosen surface, and reserve registration commands for installation or repair.
