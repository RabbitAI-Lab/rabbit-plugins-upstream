## Use Case:

External users and developers use this skill to let an agent inspect and update Zola wedding-planning data, including vendors, budget items, guests, seating assignments, events, RSVPs, registry items, gifts, inquiries, and vendor discovery.

## Known Risks and Mitigations:

Risk: The skill can change sensitive wedding-planning data, including guests, addresses, invitations, budget items, vendors, seating, and event details.

Mitigation: Install only when the agent should manage Zola account data, and review requests carefully before allowing write actions.
