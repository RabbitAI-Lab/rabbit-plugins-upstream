## Description: <br>
This skill helps agents work with Zola wedding planning data, including vendors, guest lists, budgets, seating, events, RSVPs, registry, gifts, and inquiry management. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External users and wedding planners use this skill to ask an agent to inspect and manage Zola wedding planning records across vendors, guests, budgets, seating, events, RSVPs, registry, gifts, and marketplace inquiries. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can change sensitive Zola records, including guests, invitations, vendors, budget, seating, RSVPs, and events. <br>
Mitigation: Use it only with trusted agents and ask for previews plus explicit confirmation before removals, bulk invitation changes, address updates, vendor bookings, or event edits. <br>
Risk: Zola wedding data may include sensitive personal and event-planning information. <br>
Mitigation: Install only when the agent should have access to that Zola data and review requested actions before allowing changes. <br>
