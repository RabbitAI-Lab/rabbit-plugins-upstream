## Description: <br>
Write technical blog posts as a professional tech blogger, following a strict structure, conversational style, and Markdown formatting. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, technical writers, and content teams use this skill to draft reader-facing technical blog posts, tutorials, and developer explainers. It guides the agent to produce a styled, standalone HTML article with structured sections, runnable code examples, and a concise final file-location response. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill writes a local HTML file whose slug-based filename could overwrite an existing file. <br>
Mitigation: Review the generated filename before use in directories containing important files, and rename or move existing files when needed. <br>
