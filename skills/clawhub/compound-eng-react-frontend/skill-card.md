## Known Risks and Mitigations:

Risk: Test commands may run against untrusted projects.

Mitigation: Run command examples only inside trusted project repositories and review them before execution.

Risk: E2E example credentials or saved authentication state may be copied into live workflows.

Mitigation: Use disposable test credentials; replace sample passwords and auth-state paths with project-approved secret handling.
