## Description:

Provides React architecture, TypeScript, Next.js, hooks, testing, code review, and locale synchronization guidance for frontend work.

This skill is ready for commercial/non-commercial use.

## Publisher:

[iliaal](https://clawhub.ai/user/iliaal)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to build and review React and Next.js interfaces, manage component state and asynchronous behavior, configure Tailwind CSS, and select suitable tests.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Saved Playwright login state can contain cookies that allow account impersonation.

Mitigation: Use an isolated test account, add e2e/.auth/ to .gitignore, keep saved sessions out of shared artifacts, and delete them when finished.
