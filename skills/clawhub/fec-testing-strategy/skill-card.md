## Description:

Helps frontend developers plan risk-based testing across static checks, unit, component, integration, end-to-end, and specialist quality layers.

This skill is ready for commercial/non-commercial use.

## Publisher:

[bovinphang](https://clawhub.ai/user/bovinphang)

### License/Terms of Use:

MIT

## Use Case:

Frontend developers and reviewers use this skill to map project risks to appropriate test layers, prioritize coverage, and identify useful checks and failure evidence.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A generic test plan may overlook project-specific risks or be mistaken for completed validation.

Mitigation: Review recommendations against the project's existing tools, critical user journeys, and CI gates; run and assess the selected checks separately.
