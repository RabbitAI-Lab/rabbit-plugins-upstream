## 初衷

> **从交底书到专利，最难的是第一稿。**

方案是清楚的，可要写成专利的样子：背景怎么铺、技术方案写多细、权利要求怎么分层、附图画哪几张，每一步都要经验。代理人排期紧，研发等不起。

这个 Skill 做的是：**把你手上的材料写成一份像样的专利初稿**，代理人拿到直接往下改，而不是从零写起。缺的信息按行业通行做法补上；系统推导和待补充的地方在核对说明里逐条列出，交给代理人之前你能一条条核对。

## 初稿里有什么

| 节 | 内容 |
| --- | --- |
| 1 | 发明创造名称 |
| 2 | 背景技术及现有技术的缺陷和不足 |
| 3 | 具体的技术方案描述 |
| 4 | 本发明创造的优点 |
| 5 | 具体实施方式及附图 |
| 6 | **权利要求结构预览** |
| 7 | 说明书摘要（300 字以内） |
| 8 | 附图标号表 |

**权利要求表是按代理人的规矩排的**：独立项、从属项连续编号，引用关系标清；材料同时支持产品和方法时，各出一条独立项；**独立项只写必不可少的特征，宁少勿多**，按通行做法补出来的部件一律不进独立项，保护范围不会被无端收窄。

**附图自动画**：连接关系图、流程图、模块框图、结构图、电路图，按领域判断该画哪种。

**发明点逐条比对**：每个发明点都拿去全球专利库里比，撞上了哪篇、是完全公开还是相近，都写清楚。

另附一份**核对说明**：系统推断的内容、待补充的事实、附图绘图说明、发明点比对、可替换的实现方式。

### 只有一个想法也行

一两句话说不清具体怎么做？先出几个可申请的方向，每个方向带核心方案、创新点和新颖性、可行性、差异化评分。挑一个，接着写初稿。

## 怎么用

**不需要密钥，装上就能用。** 第一次运行时脚本自动领取一份免费试用：累计 ¥40 额度、30 天有效，存在本机 `~/.patentmax/`。

试用用完后，在 [api.ip930.com](https://api.ip930.com/features/api-platform) 注册（再送 ¥50 体验额度）并创建密钥，设成环境变量即可，设了就不再用试用：

```bash
export PATENTMAX_API_KEY="pm_live_你的密钥"
```

然后直接跟 AI 说「帮我把这份交底写成专利」，给它文件或目录就行。

想自己跑命令：

```bash
# 材料齐的
python scripts/patentmax_disclosure.py create \
  --file ./交底材料.docx --file ./实验记录.md --wait --yes

# 只有一个想法
python scripts/patentmax_disclosure.py ideas --idea "……" --wait --yes
python scripts/patentmax_disclosure.py create --from-ideas <report_id> --direction 2 --wait --yes

# 下载
python scripts/patentmax_disclosure.py download --report-id <report_id> --out 专利初稿.docx
python scripts/patentmax_disclosure.py download --report-id <report_id> --kind notes --out 核对说明.docx
```

**只用 Python 标准库**，不需要 `pip install`，不用装 Node、不用装 Office、不用转 PDF。`.docx` 直接读。

新用户注册即送 ¥50 体验额度。

## 材料怎么准备

**材料越全，初稿越好，要你确认的推断越少。** 最少讲清三件事：

| | 写什么 |
| --- | --- |
| **解决什么问题** | 现有做法卡在哪 |
| **具体怎么做** | **最关键**：结构、步骤、参数、控制逻辑 |
| **达到什么效果** | 最好有数字 |

❌ 「一种智能阀门控制装置」：200 字以下脚本直接拦下来

✅ 「转轴上装角度和扭矩传感器，闸前闸后各一个水位计；扭矩增量超 30% 且水位差异常判定卡滞；冰冻时低频大振幅振动 30 秒，异物时高频小振幅 15 秒，三次失败告警锁定」

提交前可以先 `preview`，**不花钱**，看看材料够不够。

详见 `references/materials-guide.md`。

## 它不做什么

**初稿不是可以直接递交的申请文件。** 权利要求给的是结构预览，最终的保护范围要专利代理师定稿后才能递交。

**不保证能授权。** 发明点比对说明的是「在专利库里撞没撞上」，要一个能不能申请的结论，初稿写完再做一次专利查新。

**不做外观设计。** 适合发明和实用新型这类技术方案。

**不编实验数据。** 化工、药品这类需要实测数据的，缺了就列进「待补充」，不会凭空写一个数出来。
