# 全屋定制不吃亏，这样做万无一失5.12

你得明白一分价钱一分货的道理，定制品切勿逼着商家低价切入。如果你长期关注本号，肯定听说过低价切入。这个做法在任何不是具象商品的交易中都存在，避免的办法只有一个，就是商家的人品以及你的火眼金睛的辨别。例如全屋定制、例如木门的定制，又例如整个装修、这个都是无法真实拿走的具象商品，都有定制属性。
1.低价只能从商品本身的质量上下手，难道商家会仁慈给你倒贴不成。定制的低价最大的坏处是板材的好坏，这个是常常动手的地方，例如报价100，你非得80定制，那就非常简单，原来一张100元换成一张80元的板材，还真的难以分辨，更何况做成安装全部封边处理，到你家偶尔有开孔露出的横截面你也是无法判断板材是否已经掉包的。那能怎么避免呢？真的没有办法，除非你会用到综合看人的办法，比如前面提到的这篇《有什么诀窍，可以找到好的全屋定制？》
2.同样的板材都有好坏，所以不要以为多层就是一种，在你选择板材的时候，可以让商家让你带走一块样品，安装到家的时候，可以和打孔的横截面进行对比，大概也能看出好坏来。板材的好坏对于业主来说，唯有把不同档次的板材放一起，一目了然。否则前期报价再低，后期不断加钱，一点意义都没有。就像好多人装修只图低价找套餐，装修开始了，就能发现小区群里骂娘的声音，你早干啥去了？你图的是低价，当然有投你所好的公司，人以群分而已。苍蝇不叮无缝蛋的，自身先反省，然后再埋怨，否则不止装修上，以后上当的地方多了去了。
3.细节。你有时间刷抖音，没有时间看装修？种豆得豆，种瓜得瓜。这是必然的结果。就比如全屋定制，只给你报个框架的价格，你以为非常低，交了定金各种费用就开始了。抽屉需要增加加钱，层板需要加厚加钱，需要见光板加钱，需要边线加钱，等等费用就来了。当然你也可以不加钱，做出来你和人家同样做定制的比一下，要档次没有档次，要颜值没有颜值，要功能没有功能，充其量就是做了个盒子而已。《全屋定制那么贵，怎么做更省钱？》这篇里头有谈过，大家可以看看。
4.全屋定制和装修一样，切记让前期低价，定金哄骗。像外面各种大品牌，什么都没有做，动不动就是几万的定金。等你明白真相就迟了。比如不看家人入住人口，全部最烂的颗粒板；比如什么细节都不知道，等你知道细节要修改的时候，才知道各种加钱。
5.好的定制是货真价实，多钱就是多钱，而且你做的什么层板多少和抽屉多少，压根不会有任何费用，并不会一门心思就想让你上套，然后不断加钱。这一点你也可以咨询一下其他做过的邻居，当然看上去细节问题很多，就不用看了，低价能做都不错了，咋可能照顾颜值呢
