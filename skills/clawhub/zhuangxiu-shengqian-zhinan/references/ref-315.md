# 客厅用挂机，就显得寒碜吗？

客厅用挂机，一点都不寒碜。恰恰相反，客厅必须柜机才是被过去的审美带沟里了。

先戳破"客厅必须柜机"的执念。 好多人没有根据面积选择相应的空调，而是认为卧室必须挂机，客厅必须柜机。这样的做法会导致后期不仅浪费空间，而且多花一部分费用了。一般家里不论大小，都会在客厅布置柜机空调，或在电视墙这边，或在沙发墙这边，不论在那边，都会占用部分空间，即使用现在的圆柱形空调，也是一样，视觉空间也变小了。重要的是柜机的价格要比挂机贵多了。

同样空间，挂机全都能做到。 如果做成挂机，不仅节省地方，而且功能也能达到，最重要的还能节省一笔费用，何乐不为呢？想省钱省空间的，建议刚需客厅就用挂机吧，至于能不能满足功能完全取决于你的使用习惯，你如果开空调永远都是25度和一直是16度，是没法比的。而且一年就用一两个月左右的时间。

谁说挂机不美观？ 有的人认为挂机不美观，不知道这个审美从何说起？过去年代大家都以家里有个电视为荣，而且是过去的大屁股电视，很有气派。空调不是体积越大越好，能小当然是最美观的。如果善于规划，甚至挂机也能隐藏起来，视觉上更美观，而且不占地方。

挂机到底够不够用，看面积说话。 只要面积和空调的制冷面积相符，尽量采用挂机，省钱省地方。对照空调制冷功率与房间对应的适用面积：2匹挂机制冷量5000W，适用客厅19-32平米；2.5匹6100W，适用客厅23-38平米。普通刚需客厅，大两匹挂机完全够用。

价格差距有多大？ 2.5匹柜机动辄一万出头，换成大两匹的挂机，价位要低很多了。而且换成挂机的话，不会占用下方的空间，同时视觉上要轻巧多了。从价格和美观程度上比，挂机能满足肯定比柜机要实惠而且务实多了。

非要美观怎么办？ 你如果想要美观的话千万不要用柜机，这个谈不上好看了，只不过还是骨子里过去的审美，电器越大越有面而已；要美观直接风管机或者中央空调了。看看普通的风管机一拖一的做法，其实大部分价位3匹的下来在七八千左右，比起来比有的柜机还要便宜，而且视觉上更好看。

所以结论很简单： 刚需房其实就两个选择，一个挂机，一个风管机，有钱风管机，省钱挂机。柜机，又贵又占地方，北方暖气房更别碰，属于严重不推荐的行列。客厅用挂机不寒碜，为了面子多花大几千还占地方，那才是真亏。
