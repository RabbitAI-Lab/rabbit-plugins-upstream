# 全屋智能/智能家居怎么提前规划？怎么避免"伪智能"？

95%的全屋智能需求都是伪需求。 奉劝刚需普通家庭不要做整屋全屋智能，否则光一个待机电费够刚需业主肉疼！还有一旦坏了维修费用非常高，普通工薪阶层普通小户型房子没有必要使用。智能家居到底有没有用，自己不体验，一股脑弄到家里，结果不仅费钱，不好用，而且有时候适得其反。

前期预埋规划最关键。 想做全屋智能，水电施工是基础，一旦前期没有规划好，后期改造更难，甚至只能砸墙，太多人栽在这一步。

开关只有火线最致命：北方新交毛坯房，几乎所有开发商原有开关都没有零线。单火智能开关价格还贵，后期会不断出现频闪、关灯微亮、失灵甚至影响寿命的弊端，后期想改有的必须重新开槽，返工成本非常高。一定要在水电改造的时候，穿上零线，或者重新布局回路，一定告诉电工后面用智能开关，必须零活线都有，能穿则穿，省钱还能达到目的。（你如果嫌水电改造费用高，放弃全屋智能吧）

电动窗帘、智能马桶、扫地机器人、电动晾衣架一定要在装修时候留好电源。电动窗帘插座位置，一定要确定好窗帘盒大小规格；智能马桶电源位置最好先看好马桶，按照马桶规格尺寸预留；全自动扫地机器人一定要隐藏预留水电位置，保证后面安装不会露出明线。

网线布局非常重要。 网线布局分三种：传统做法光猫到路由器无线覆盖全屋，刚需户型首选够用；AC+AP每个房间都有有线信号稳定前期改造成本高；Mesh组网有线无线都可以，有线连接最大化保证空间信号无死角是大户型最常见做法，无线连接子母路由之间无需网线成本低适合大部分刚需户型，混合组网重要房间书房工作区用有线其他非工作区用无线。

先抓刚需别被全智能忽悠。 盲目求全各种堆积，前期没用过压根不知道自己的需求，结果是家里所有都接智能导致预算翻倍，入住以后才发现大部分压根用不上。先选刚需鸡肋的绝对不要：必装刚需优先智能开关（零火版）、网关、人体存在传感器、窗帘电机、智能门锁、安防摄像头；可选按需添加空调伴侣、语音音箱、简易中控面板；不装纯鸡肋智能垃圾桶、智能香薰、全屋RGB灯带、几千元中控大屏。

不要迷信全智能手动备份一定保留。 完全依赖智能控制，结果入住除过断网还有可能断电，有可能你盲目选的设备成了一堆废铁。智能开关优先选离线可手动款，关键区域比如卧室客厅一定要留物理备份，断网断电也不慌。

智能生态统一避免各自为王。 米家的灯、华为的音箱、涂鸦的传感器，千万不要犯这种低级错误，否则后期不兼容，不断更换APP，语音无法全部唤醒，买了一堆智障。优先选同一生态：米家适合普通家庭、华为鸿蒙适合华为手机用户、苹果HomeKit适合苹果用户。混搭必选Matter协议。网关最好放置开阔地方以客厅空间为主，没有任何遮挡物以及密闭空间，网关不要放进金属盒子非常屏蔽信号。

记住。 全屋智能是解决生活麻烦不是装面子，先列好自己的需求再下手别被商家忽悠。水电费用高怕贵的不适合全屋智能；看自己需求不要跟风和模仿；智能生态统一；设备质量一定要过关；一定保留手动控制；专业机构以及售后保障。越简单达到目的才是真的智能化，否则越繁琐越容易误触或者出现各种错误。
