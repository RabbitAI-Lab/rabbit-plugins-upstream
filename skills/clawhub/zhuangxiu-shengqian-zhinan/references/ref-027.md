# 动线翻车毁厨房！致命错误让做饭变折磨！

厨房动线很好理解，基本遵循原则：洗→切→炒。这是厨房装修的基本原则，如果这个错了，做饭绕来绕去，这就是动线错误。网友@一瓢饮：不要自装是有原因的，连基本的常识都没有人把握，找的定制商只是定制盒子，压根不管你位置和使用空间，结果很大的厨房连个切菜的位置都没有，水槽左边浪费很大空间。后悔已经迟了，奉劝大家价值重要，不要老是盯着价格低了。一个空间，动线布局不合理，会大大影响实际操作，尤其是厨房空间，洗，切，炒不在一条动线上，在实际操作上会反反复复的重复操作，浪费体力，浪费时效。网友@撒花姑娘：不要信灶具不要离烟道太远的鬼话了，就是因为家属说灶具朝右离烟道远影响吸烟效果，结果导致屁大的厨房洗切吵全部混乱，每次做饭都感觉跑了好多冤枉路，关键是一点都不顺网友@麦田王子：不怪不得别人，自己装修什么都不懂，只是感觉自己没钱自装可以更省钱，结果是找的熟人定制人家也不管位置，导致水槽和灶具紧挨，而两边都有充足的空间，空间极度浪费且不合理网友@小满：如果自己不懂装修千万不要太自信，这么大厨房除过空间大，其他都感觉不满意，最难受的是空间这么大动线竟然做错了。
从上图对比就可以看出来，原有动线极其不合理，改造以后洗与炒之间刚好满足切菜空间，这才是合理的动线做法。装修房子如果仅仅停留在施工上，只有价格，没有任何价值了，钱如果和邻居花的一样多，结果自己连个动线都能做错，一切价值归零，因为日后天天烹饪都会心烦---水槽右边那么大空间，为啥非得靠近灶具？背多少避坑指南都没用，人找对才是正确方向。--同样是听信烟机要离烟道近的鬼话，入住进来才恍然大悟，被自己蠢笑了，这种低级错误咋能当时想不明白呢小厨房就不要跟风高低台了，把台面做一个中间高度，既可以满足不弯腰，也可以满足灶台不要太高，这样最起码台面能多放一点东西，不会影响切菜功能。因为小所以舍弃了高低台，水槽右移，统一按照洗碗机高低设计，满足基本的动线功能，台面还能有点拓展空间。厨房很小，此时统一按照洗碗机高度，水槽右移，满足基本的动线合理。定制商朋友圈的嘚瑟，但是好多人压根看不到致命错误，只看到价格和靓丽的外表了，结果动线都是翻车的做法，还是信了烟机必须离烟道近的鬼话了，烟机朝右移出来一个切菜空间，这才是基本厨房动线。这个动线才是合理的，把原有错误的动线纠正过来，不仅实现功能的满足，同时收纳整洁。这么大厨房，水槽左边还有空间，非得和灶具拥挤一处，导致连基本的动线都是错误的厨房小请忽略烟机和烟道的距离，又不是豪宅，按照合理动线做就可以，千万不要错误认为厨房很大的样子，结果是水槽和灶具挤一块，害怕灶具离烟道太远。后记：其实厨房动线真的很简单，只要有基本的生活经验即可，找一个好的装修人和定制商也可以搞定。
