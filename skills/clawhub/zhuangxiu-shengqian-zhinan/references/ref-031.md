# 橱柜转角翻车实录：找错定制商的代价是‘每天做饭都想砸厨房’！

全屋定制几乎是每一家的必须。有人会问：为什么必须做全屋定制？其实答案很简单也很务实：家里很大，入住人少，成品家具能满足收纳，当然不需要定制；能做全屋定制不外乎空间与收纳的矛盾而已。找全屋定制的前提一定是：商家愿意替你着想，在力所能及的范围尽可能让定制完美；当然你如果只看谁价格低，把全屋定制看成是定制盒子的价格，那百分百翻车。例如橱柜转角的设计，好的定制商不会让你多掏一分钱，而且把价值做到最大化，而你只看低价或者掏高价找个不靠谱的定制商，多半都得翻车。像这种做法，充其量连定制盒子都不如，纯粹就是外行做法而已，定制前不应该先有图纸吗？很明显找错人而已。网友@机灵鬼：自己不懂设计才找个定制商，结果设计师还不如自己，导致转角没有合理利用，后悔已经安装，让重新整改必须重新核算费用，而且总价高出将近一半的价格。网友@暴富：为了省钱找亲戚砖砌的橱柜，结果转角位置太深了，放东西压根没法使用。解决办法：实验室托盘➕自粘滚珠，里头放一些不常用的东西，托盘可以抽拉，就可以解决这种非常深的转角空间。网友@麻椒鸡：完了，忘记旁边的柱子了，结果把转角给了小空间，这样转角位置很难利用，因为把转角给水槽这边，做成层板或者抽拉板，最起码能利用上空间。且不说内部空间，柜门位置设计错误，明显很低级的常识性错误了。解决办法两种：联动门或者大角度铰链对开门，不用多花一分钱，定制都可以解决问题，这个才是价值。上图全屋定制是瓦工设计的？你们找定制难道不看设计，只看是个能定制盒子就行？自己给自己挖坑而已。网友@隔壁老贾：定制设计师完全没有经验，小门压大门，结果一个都用不成。网友@雨大了：大家做全屋定制一定要找有设计团队的，你以为你直接找厂家便宜，结果纯粹没有价值。解决办法1：吊柜转角大柜门，一定是大门压小门，统一采用大角度铰链即可。解决办法2：也可以直接采用联动门设计，也可以满足功能 网友@泡沫：一边是柜门，一边是抽屉，嫌边线难看没有留，结果抽屉与明拉手打架，防不胜防。解决办法：要不不用明拉手，要不抽屉左边加边线。网友@佳航：转角成了死角，定制商说都是这样做，图纸是确认过的，不给整改。解决办法：图纸确认过就没有办法了，找的就是定制盒子的商家，不带一点脑子和设计的，要不忍了，要不付钱重新做。橱柜地柜转角设计，是不需要独立花一分钱的，都在延米价格里头包含，除非有人让你花几千元买个转角拉篮，用钱能解决有什么价值？谁都能解决《装修别搞 “炫技式设计”！看着高级，入住全是坑》转角位置尽量不放嵌入式家电，如果要放，需要注意旁边门开启空间，否则刚好与电器把手冲突，导致翻车。翻车了得找原因，不是说翻车了发网上骂商家，你掏的钱就是这样做法，而且这种价格低的本身就是定制盒子，完全不具备任何设计能力。好多人很自信以为找厂家定制就便宜，殊不知你人为逃开了设计团队，你真以为厂家是便宜到哪了？不就是因为少了设计才翻车而已。常见翻车的还有转角高低台的做法，基本这种翻车原因都是因为躲开了设计团队，你找再好的定制厂家，没有一个设计团队在前方给你把关，你并没有便宜多少，只不过是定制盒子，翻车的代价最终得不偿失。后记：其实全屋定制和装修一样麻烦，并不是简单定制盒子。现实里头好多人找定制都想找厂家，没有设计的定制，你就是厂家也是白搭，大部分厂家设计师都是新手，要不就是学徒画图而已。想要找到好的全屋定制最好的办法其实就是装修设计师和全屋定制是一个设计师，只有这样才能协调更紧密，而且更有设计感。
