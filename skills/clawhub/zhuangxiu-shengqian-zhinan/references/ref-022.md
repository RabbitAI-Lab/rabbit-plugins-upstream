# 全屋定制别当甩手掌柜！装完电器全翻车，返工代价太大！

西安不少业主找全屋定制时，以为 “全包省心”，结果装完电器才发现：插座被定制柜挡住、尺寸不匹配，返工花钱还耽误工期。其实全屋定制的坑，全国都一样，西安业主踩过的雷，外地也能避！找全屋定制和找装修公司一样的，人才是最主要的考察对象。家里所有定制一定要找一家去做，千万不要衣柜一家，其他一家，这个完全是自己坑自己的行为。后期颜色以及售后都非常麻烦，风险更大。装修的可以做全屋定制更好，设计师是一个，更好协调，出错几率降低，同时也可以压低成本；但是全屋定制绝对作不了装修，千万不要找一家做全屋定制的做装修，相当于找了一个卖刀的给你家做厨师一个道理。一旦全屋定制找不对人，与电器协调不好，翻车几率很大。定制预留空间小了，洗碗机进不去。一定注意需要洗碗机先让设计师看是否满足空间，然后水电交底定制必须在场，这样才能保证后期满足功能。水电交底定制在场的原因是你单独找了定制，如果定制是装修一块做就不需要定制单独来，设计师统一就可以交底；一旦你单独找定制，现场交底目的就是为了后期不扯皮，否则很有可能装修的水电无法满足后期定制的要求。其次，定制规划设计的时候给洗碗机的详细尺寸，或者直接给洗碗机的网购链接，让定制去协调尺寸。一定记住不要文字性的尺寸，要有产品图片的尺寸，后期错了商家或者定制担责，一旦你抄写尺寸错误，后期就是自己担责了。最简单的办法就是直接给产品链接和型号，让定制设计师与电器商家沟通，后期错误定制商承担。零嵌冰箱，尺寸产品都给了定制，结果做成这样。关键是定制死不承认，就是不整改，宁愿不要尾款也不改。碰到这种烂人，除过自认倒霉几乎没有办法，因为定制就没有店面，就是小区搞活动的扎点的。所以找全屋定制千万别图优惠便宜，你要的优惠越多，只不过是离坑更近而已。承担责任这个是一个商家底线行为，连这个都做不到，只能是烂人行列了。定制预留的空间烤箱塞不进去，以为是定制做错了，结果更傻眼。电器销售人员给的尺寸失误，导致定制预留错误，结果翻车。只能裁割柜体背板塞进去了。这里一定注意，实体店购买电器，一定要有产品本身的图片尺寸以及线上链接尺寸，千万不要让销售人员随便给尺寸，人有三昏，一个错误就会导致不断返工。尺寸都对，但是忘记量取洗碗机的把手尺寸，其实这个也难免，因为详细图纸里头没有把手尺寸，肯定就忽略了。不是什么大问题，后期都可以调整，但是建议洗碗机不要带突出把手的，内嵌隐形把手才是最佳选择，视觉也好看，也不会出现与旁边抽屉柜门冲突的问题。见得少的话就不会有错误，也不会有价格和价值之分了。也就是装修说的自装，都认为自己很省钱而且很完美。但其实是忽略了标准和价值而已。因为不知道还有伸缩支架这回事，而且自装所有人都不会给你建议，多一事不如少一事，事不关己高高挂起，这就是自装的弊端，所有人都巴不得事情少，钱不少。等到看到邻居家的做法，才恍然大悟，自己家只有价格没有价值而已。烟机本来是要嵌入进去的，底面与吊柜底部平齐，结果留空小了，压根进不去。解决办法，第一重新改柜子成本高，第二烟机上方柜门重新做大一点，烟机不嵌入，完全在吊柜下方即可。业主千万不要直接给定制商纯数据，实体店购买一定要有标准的图片尺寸，网购直接给链接有详细尺寸。业主很自信报了数字，结果是自己看错型号了，这下返工成本都得业主自担了。这也和全屋定制不专业有很大关系，一般做全屋定制是不会看你纯数字的，必须有产品图片详细尺寸或者具体商品链接，而不是业主发个纯数字，这个风险太大了。降低标准或者没有见过更好的，当然上图没有毛病，这个其实就是价格和价值的区别而已。其实只要你注意细节，就发现，洗碗机上方的不同之处了，虽然不影响使用，但是细节决定价值和高级感，这就是花同样的钱，结果完全是不一样的，细节才能看出价值区别。同样是洗碗机加抽屉，功能都一样，但细节价值是天地之差。『有时候洗碗机不影响使用，但是颜值翻车了』隐藏扫地机器人，柜门关不住。其实这个错误就太低级了，装修前想要扫地机器人尺寸大小位置就得规划好，定制时候根据机器人大小定制，应该定制商家经验太欠缺了。自装的话一个不管一个，没人全盘操心，结果地漏挡住了机器人，定制没有问题，只能自己承担责任了。自装前一个比一个自信，结果你把上下水留到洗烘机背面，不考虑机器安装吗？定制按照墙体定制，至于你能放进去不，只能自己承担后果了。装修真没有那么简单，很多人认为找几个会干的工人就可以，这话一点问题没有，但是装修并不是单个干活，第一步就得预想最后一步的风险，否则单个看都没有错，放一起全部翻车。总结：其实想要不出错误，不翻车，不外乎有人全身心操心和有一颗愿意替业主着想的心，否则技术再高，经验再足是没有用的。💬 你在装修中遇到过哪些“定制翻车”瞬间？欢迎在评论区留言，我们帮你分析原因、出解决方案！更多西安装修定制翻车干货： 西安橱柜定制翻车实录：90%人已中招！
