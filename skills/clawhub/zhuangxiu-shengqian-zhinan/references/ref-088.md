# 阳台就做个储物柜，都能翻车不断7.1

装修翻车的专题有一个系列了，直接专辑里头查看《装修翻车错误专题》，翻车的专题不是让大家看个热闹，一定要在自己装修的时候避免重复同样的错误，这个才是翻车专辑的意义所在。上一篇有个阳台洗衣柜的翻车，大家可以翻阅《阳台定制又翻车了，看看有没有自己家》今天看一下，阳台收纳柜翻车的事故。这个就是定制的问题了，没有经验，吊顶做好了才测量尺寸，这个低级错误不该有，只能拉回去重新做了；不仅柜体需要改造，柜门全部报废。用假柜门包砸不掉的墙体，真没有必要，乳胶漆颜色与柜门相近即可；非得花这个钱就得做成真柜门，而不是一眼看出来就是假的，做成了护墙板就等于白做了，其实就是留出正常柜门的均匀缝隙而已阳台移门到顶与下放的晾衣架打架，其实不算问题；要不你晾衣服的时候不要开门，要不就不要做一门到顶；要不就实现不了这么长的晾衣架，都想霸占不翻车都难，但其实完全可以用，晾衣服不开门就行，自己规划问题如果是精装修两边加5公分条子，那是因为墙体误差太大，如果是毛坯房装修，这么窄的柜子，两边5公分，柜子10公分都报废不能用了，这个就是翻车了上方有管道，没有办法，但是石膏板贵还是定制贵总能分清吧；直接用定制包裹，不仅突兀而且贵，更好的做法是直接上头石膏板做盒子，颜色还可以统一，这样不会视觉突兀沟通是下方有挡板外露，上方一门到顶，结果上下都漏挡板了，咋办？要不柜门报废，要不就加个板子难看木板做窗帘盒又贵又丑，而且窗帘盒通过去了，窗帘没法拉过去，早知道直接石膏板吊顶留出窗帘盒了真为了省钱，分不清石膏板贵还是定制贵，用定制包盒子隐藏管道又丑又贵，图个啥？封闭阳台做了铝合金柜子，做完才发现好廉价，浓重的塑料感，后悔迟了看着是一个完整的收纳柜，但是怎么看怎么别扭，上下柜门对缝那么难吗？有吊顶还这么丑，不懂设计而已，上方浪费那么大，窗户边需要占哪个便宜？基本审美都没有了便宜自有便宜的道理，人家设计好做好的东西，你给了木工就能做出来？这个就是想多了，照猫画虎其实就是这个档次了；定制最大价值在于设计，然后是安装。如果定制盒子的话这个就行，如果看设计的话，完全翻车的做法，审美天地之差你如果找一个只管赚钱的商家，就是上图的后果，明明知道有窗户，直接给你挡住，你现在不要柜子了，钱已经付了。找一家省心的定制并不难，只是大部分业主太过于自信，当然你都懒得打听思考，随便找个人多半会买教训再比较一下人家有窗户咋做定制的，这就是价值和价格的区别为了省钱但是自己不独立思考，连石膏板和定制哪个贵都没有搞清楚，结果是钱不仅没有少花，效果直接翻车，显得更廉价，这就是多花钱反而廉价的地方《明明花了几十万，为什么装修如此廉价？》同样花钱，价值和价格压根不是一回事，但是好多人永远宁愿坐到井下，拉都拉不出来这种柜子定制充其量就是盒子，只学到别人的断开式设计和极简把手，你本身柜门边线都突兀到10年前了，做这些又有什么用呢？总感觉是一位浓妆艳抹的村妇之感这水平也能吃这碗饭，你就说业主有多好说话，要不这些人还能继续生存呢
