# open-docker-hub

A lightweight Brave browser skill for **Docker Hub**.

## What it does

Open Docker Hub in Brave.

- Reuses an existing relevant tab/session
- Avoids unnecessary duplicate tabs
- Verifies the destination
- Never handles credentials

## Example triggers

- Open Docker Hub
- Take me to Docker Hub
