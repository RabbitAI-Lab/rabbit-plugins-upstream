# 塔罗解读框架

解读 `scripts/tarot.cjs` 的输出前必读。塔罗的重心在**牌意串联与故事性**，
比八字六爻更强调叙事，判词更柔软。

## 输入收集清单

| 信息 | 必需性 | 说明 |
|--------|--------|------|
| 问题/困惑 | 必需 | 不必精确到是非题，情绪与处境描述反而更好（「最近工作很迷茫」） |
| 抽牌方式 | 二选一 | ①用户没抽 → `--draw` 代抽（3 张牌阵）；②用户报了牌名 → `--cards` 查义 |

牌阵默认「过去,现在,未来」三张。用户主动要求其他牌阵（如「圣三角」「时间之流」）
可用 `--spread` 自定义位置名；一次解牌 3–5 张为宜。

## 解读方法（串牌叙事）

像讲故事一样解读牌阵，把三张牌融入**连贯的叙事**，而不是逐张念牌义：

1. **单牌定位** — 每张牌先看：
   - `position` 牌阵位置（该牌回答哪个时间维度/哪个侧面）
   - `meaning_up` / `meaning_rev`（正逆位牌义，抽牌时 `reversed` 已定）
   - `element` 元素与 `suit`（若小阿卡纳）：风=思辨/冲突，火=行动/热情，
     水=情感/直觉，土=物质/稳定；宝剑偏困境、权杖偏行动、圣杯偏情感、
     五角星偏务实。
   - `up_summary`/`reverse_summary` 一词概括（如「痛苦终结」「短暂成功」），
     叙事里用作小标题非常出彩。
2. **牌与牌的互动** — 关注相邻牌的呼应与冲突：元素相生相克（如权杖火牌后接
   圣杯水牌=热情遇冷）、数字的递进（权杖三到权杖十=扩张到过载）、大小阿卡纳的
   转换（大阿卡纳多=命运主题，小阿卡纳多=日常事务）。
3. **叙事弧线** — 过去→现在→未来天然是一条故事线：「过去的 X 埋下了 Y，
   现在的你站在 Z 的路口，未来的 W 提示…」。
4. **落在问题上** — 收尾必须回扣用户的原始困惑，给出可参考的倾向与行动建议；
   逆位不是「坏」，是「该牌能量的受阻或内化」，从成长角度阐释。

## 判词风格

- 多用画面感语言（`detailed_desc` 提供了韦特牌画面，可直接借景）。
- 正逆位措辞软：正位「顺流」，逆位「需要调整/内省」，避免「大凶」。
- 塔罗不与八字混断（体系不同），但用户要求综合时可用一句话互相呼应。

## 报告结构

```
## 牌阵一览
位置1：牌名（正/逆位）— up/reverse_summary
…（紧凑列出，配 emoji 适量）

## 串牌叙事
2-3 段连贯故事，每段落到一张牌的画面与位置含义

## 回到你的问题
1 段直接回应：牌阵整体指向什么倾向

## 一点建议
1-3 条，具体可执行（心态/行动/时机）
```
