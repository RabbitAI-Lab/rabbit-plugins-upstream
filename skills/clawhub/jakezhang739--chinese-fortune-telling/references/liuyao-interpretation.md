# 六爻断卦框架

解读 `scripts/liuyao.cjs` 的输出前必读。

## 输入收集清单

| 信息 | 必需性 | 说明 |
|------|--------|------|
| 所问之事 | 必需 | 一事一卦；问题越具体（如「这次跳槽去 A 公司是否合适」）断得越准 |
| 起卦方式 | 二选一 | ①用户没摇过卦 → `--cast` 代摇；②用户自己摇过/报卦名 → `--original key` 或 `--name 卦名` |
| 起卦时间 | 可选 | 默认当前时刻；用户报了摇卦时间就传入 `--date`（日干支决定六神与旬空） |

传统上心诚则灵：代摇前可以让用户默念所问之事，营造专注（也是体验仪式感）。

## 脚本输出 → 断卦步骤

### 1. 定卦（originalHexagram / changedHexagram）

- `name` 卦名、`gua_ci` 卦辞、`xiang_ci` 象辞、`modern_description` 现代释义。
- 卦辞定总基调（吉/凶/悔/吝），变卦示事态走向。
- `cast.yaos` 里 `changing: true` 的是动爻（老阴/老阳）。**没有动爻时以卦辞断，
  不再看爻辞**。

### 2. 看动爻（changingYaoTexts + changedLines）

- 一个动爻：以该爻爻辞为主断。
- 多个动爻：取**位置最靠上的动爻**爻辞为主（古法「多动取上」），兼顾参考。
- 动爻的**化出信息**看 `changedLines`：`changedGanZhi/changedElement/changedRelative`
  是变卦纳甲中同位之爻（六亲仍以本卦宫论），`relation` 给出变爻对动爻的作用：
  - **回头生**（变爻生动爻）：事态得后续助力，吉;
  - **回头克**（变爻克动爻）：动爻受伤，好事多磨、后续有阻力，减分项;
  - **化进神**（寅化卯、巳化午之类）：气势递进，越走越强;
  - **化退神**：气势退缩，渐次转弱;
  - **比和/泄气/动爻克变爻**：中性偏缓。
  `changedXunKong` 为 true 表示化空（变化落空、雷声大雨点小）。
  用神化回头克或化空时，断语要相应收敛。

### 3. 定用神（问什么事看什么爻）

`paipan.lines[].relative` 六亲取用（相对**卦宫五行**而言）：

| 所问 | 用神 | 备注 |
|------|------|------|
| 财运/交易/妻子(男问) | 妻财 | 问得失成败皆看财爻旺衰 |
| 事业/官非/疾病(病鬼)/丈夫(女问) | 官鬼 | 问升迁、竞聘尤重 |
| 长辈/父母/文书/房屋/考试 | 父母 | 考试、签约、证件类问事 |
| 晚辈/下属/宠物/解忧/医药 | 子孙 | 子孙为福神，克官鬼 |
| 平辈/朋友/竞争者 | 兄弟 | 兄弟爻动多主竞争破财 |

### 4. 旺衰生克（用神的处境）

以用神爻的 `element` 五行为主体：

- **月建生扶/同气 → 旺**；月建克泄 → 衰。（月令即问事当月地支）
- **日辰**（`dayGanZhi` 的地支）是六爻中最重的变量：日生用神为吉，日克用神为困。
- 爻的生克遵循五行常理（金木水火土生克）。
- 用神**旬空**（`lines[].xunKong` 为 true 且恰是用神/原神）：力量暂时落空——
  若逢冲填则有「出空」应期之说，短线不利、长线待时。

### 5. 世应（`lines[].shiYing`）

- **世爻为自己**，**应爻为对方/所问之事**。世应相生相合主顺，相冲相克主阻。
- 问与人相关的事（合作/感情/谈判）必看世应互动；问事体本身以用神为主。

### 6. 六神（`lines[].spirit`，辅助色彩）

青龙(喜)/朱雀(口舌文书)/勾陈(田土迟滞)/螣蛇(怪异纠缠)/白虎(凶伤疾病)/玄武(暗昧欺诈)。
**只作性质点缀**（如「官鬼持世又临白虎，压力感更实」），不单独定吉凶。

### 7. 断语组装

```
## 卦象总览
本卦 X（卦辞白话）→ 变卦 Y，一事一断的总基调

## 爻象分析
动爻爻辞解读 + 用神旺衰（引日辰月建）+ 世应关系

## 断语
直接回答所问之事的倾向（成/败/迟速/利弊），给出依据

## 建议
可行动建议（时机、方向、注意事项）；不确定的应期用「约 X 时间段」模糊表达
```

断语要**直接回答问题**，避免「可能好也可能不好」的和稀泥；证据不足时说清
「卦象倾向 X，但 Y 因素未明」，并建议换问法重占（一事不二占，同一问题别反复起卦）。

## 卦 key 约定（脚本内部，用户无感）

6 位二进制 = 上卦组(四,五,上爻) + 下卦组(初,二,三爻)，1=阳 0=阴。
用户口头描述卦象时（如「上乾下巽」），用 `--name 天风姤` 查名，别手工拼 key。
