# 八字解读框架

解读 `scripts/bazi.cjs` 的输出前必读。输出 JSON 的字段含义与使用顺序如下。

## 输入收集清单

| 信息 | 必需性 | 说明 |
|------|--------|------|
| 出生日期 | 必需 | 公历年月日 |
| 出生时刻 | 必需（无时辰则降级） | 时辰决定时柱；用户只知道「早上/傍晚」时，可按时间段换算时辰后注明不确定性 |
| 性别 | 大运需要 | 男顺排女逆排；缺省按男命并注明 |
| 出生城市 | 推荐 | 换算经度做真太阳时校正（见下表）；跨时区出生要问清当地时间 |

常见城市经度（`--lon` 参数）：北京 116.4 / 上海 121.5 / 广州 113.3 / 深圳 114.1 /
成都 104.1 / 重庆 106.5 / 杭州 120.2 / 武汉 114.3 / 西安 108.9 / 沈阳 123.4 /
哈尔滨 126.6 / 昆明 102.7 / 乌鲁木齐 87.6 / 拉萨 91.1。其他城市可按「东经度数」
问用户或取邻近城市。

**真太阳时**：出生时间默认按北京时间输入。出生地经度偏离东经 120° 每度差 4 分钟
（成都约慢 64 分钟），足以改变时柱。用户能提供出生城市就应带上 `--lon`。

## 脚本输出字段 → 解读顺序

### 1. eightChar 四柱（先读全局）

每柱字段：`Gan/Zhi` 干支、`WuXing` [干五行, 支主气五行]、`ShiShenGan/Zhi` 十神、
`HideGan` 藏干、`NaYin` 纳音、`XunKong` 旬空、`DiShi` 地势(十二长生)、`Chong` 冲。

- **日柱天干是日主**（本人核心气质），`strength.dayElement` 已给出。
- `ShiShenGan` 十神是论命的骨架：正官/七杀=事业压力，正财/偏财=财富，
  食神/伤官=才华表达，正印/偏印=学识庇护，比肩/劫财=自我与竞争。
- 报告里点出 2–3 个最突出的十神组合即可，不必逐柱罗列。

### 2. wuxing 五行分布（论喜忌的底图）

`{金木水火土: 百分比}`。缺哪一行（0%）与过旺一行（≥50%）都是叙事重点。

### 3. strength 日主强弱（定格局基调）

- 判级：极强/偏强/中和/偏弱/过弱。**中和是佳境**，极强过弱都算偏枯。
- `advice` 字段是现成的喜忌建议文案（宜什么气、忌什么方位颜色），直接化用。
- 不要向用户暴露 `debug` 里的权重公式，只讲结论与依据（如「生于丑月土旺，金气受生但被埋，故偏弱」）。

### 4. shensha 神煞（点缀，不主导）

命中的神煞含 `type`（吉/凶）、`description`（古义）、`modern_description`（今译）、
`recommend_jobs`（适合职业）。使用原则：挑 3 个以内最知名的（天乙贵人/桃花/文昌/
华盖/驿马优先级最高）展开；凶煞要给出化解视角而非渲染灾祸。神煞只作色彩，
格局判断以五行强弱为准。

### 5. specialPillars + yun + tiaoHou（进阶内容，按需展开）

- `specialPillars`：胎元/命宫/身宫/胎息（性格与先天禀赋的补充视角）。
- `yun.daYun`：大运列表（index 1 起是第一步大运，含起止年龄与年份）。用户问
  「近几年运势」时，找到当前年龄/年份所在的大运步，结合该步干支与日主生克论顺逆。
- `tiaoHou.hint`：调候提示（季节性的补救方向），与 strength.advice 呼应使用。

### 6. chenggu 称骨（独立彩蛋模块）

袁天罡称骨：`weightText`（几两几钱）+ `lyric`（歌诀判词）+ `breakdown`（年月日时
各占重量）。称骨偏民俗趣味，**口吻可以更轻松**，且要说明「骨重轻≠命不好，只是
先贤的一种分类」。放在报告末尾或用户明确问称骨时才展开。

### 7. lifeScores 五维评分（现代化摘要）

事业/财运/姻缘/健康/性情五项 0–100 分 + `summary` 总评。这是给现代用户的直观摘要，
**不是命理判断本身**——报告里可作为开篇速览，但紧随其后的必须是命理依据
（如「事业分较高是因命带文昌且官星得位」）。健康分低只提示「注意作息与某五行
对应脏腑的保养」，不做诊断。

## 报告组装建议（问「帮我看看八字」通用场景）

```
## 命盘速览
四柱、日主、格局基调（1-2 句白话）+ 五维评分速览表

## 格局与五行
日主强弱判读 + 五行分布喜忌（引 strength.advice）

## 分维研判
按用户所问展开（事业/财运/姻缘/健康…）；没特指就各 2-3 句
（十神证据 + 神煞点缀 + 大运走势一句话）

## 建议
3 条以内可行动建议（方位/颜色/时机/心性），源自 advice 与调候

## 称骨小结（可选）
weightText + lyric 白话转译，轻松口吻收尾
```

用户只问一个具体问题（如「我适合什么方向的工作」）时，不要输出全量报告，
直接围绕该问题取相关字段作答。
