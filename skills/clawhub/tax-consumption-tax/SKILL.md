### 一、梯次税率与生效时点

- 🔋 **分步征收**：自2026年9月1日起，无汞原电池、镍氢蓄电池、锂原电池、锂离子蓄电池、全钒液流电池按**2%征收；2027年9月1日起转4%**。光伏电池2027年4月1日起2%、2028年4月1日起4%
- 🗓️ **时点提醒**：税率设明确生效时点，系统建立产品—税率—时点台账，避免过渡期错配
- ⚠️ **高风险**：2026.9.1后应征仍按免征、或错用税率档导致少缴

**典型问法：**

```
"电池消费税什么时候开始按2%？"
"锂离子蓄电池消费税税率2027年多少？"
"光伏电池消费税哪年起征？"
```

### 二、阶段性免征清单与CMA检测

- 🆓 **免征范围**：2026.9.1至2028.12.31，钠离子电池、固态电池、燃料电池及光伏电池中的钙钛矿/叠层/砷化镓电池免征
- 📑 **CMA前置**：享受免征须在首次申报前取得省级及以上CMA资质认定机构出具的符合国标检测报告；不符国标或无国标不得享受
- ⚠️ **高风险**：无检测报告或产品未达标仍按免征申报，被追缴并处罚

**典型问法：**

```
"哪些电池免征消费税？"
"固态电池要交消费税吗？"
"免征电池需要CMA检测报告吗？"
```

### 三、委托加工收回与进口扣除

- 🔗 **凭税扣除**：从生产企业购进、委托加工收回或进口已纳消费税的电池，用于连续生产应税电池的，按**当期生产领用数量**扣除已纳消费税
- 📋 **凭证核算**：凭已纳消费税完税凭证按领用数量计算，避免多抵或少抵
- ⚠️ **风险**：未按领用数量扣减或凭证缺失引发税务调整

**典型问法：**

```
"委托加工收回的电池能扣已纳消费税吗？"
"进口已税电池连续生产怎么扣税？"
```

### 四、自产自用与移送申报

- 🔄 **连续生产免税**：自产自用应税电池用于连续生产应税电池的，不纳消费税
- 📦 **移送申报**：用于连续生产应税电池以外或其他方面的，于移送使用时申报缴纳
- ⚠️ **风险**：移送用于非应税电池生产未申报，被追缴补税

**典型问法：**

```
"自产自用电池要交消费税吗？"
"自产自用移送使用怎么申报？"
```

## 重要提示与边界声明

**重要提示**

1. **时点刚性**：税率与免征均设明确生效时点，须建立台账与提醒，避免过渡期错配。
2. **CMA前置**：免征资格以检测报告为前提，首次申报前必须取得省级及以上CMA机构报告。
3. **扣除合规**：委托加工收回扣税须按领用数量、凭已纳消费税凭证，避免税务调整。
4. **以官方为准**：电池消费税具体品目注释与进口环节税目以公告附件及主管税务机关口径为准。

**边界（本技能不做的）**

- **不代办**：消费税申报、减免税备案等需登录系统操作的事项
- **不代理**：税务争议代理等需执业资质的事务
- **不担保**：消费税定性、稽查结论等最终以税务机关认定为准
