## Description:

Turns seller-selected Douyin hot-search topics and supplied stills into short, individual talking hook clips.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Sellers and content creators use this skill to plan hooks from public Douyin trends or supplied topics and create separate short talking clips from their authorized photos and narration.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The shared Beatra device token can spend credits and access media and task capabilities across skills.

Mitigation: Review the account connection before installation, monitor credit charges, and revoke the device in the Beatra Console when no longer trusted.

Risk: The installed package can update automatically without a separate confirmation.

Mitigation: Disable automatic updates if you need to review new releases before use.
