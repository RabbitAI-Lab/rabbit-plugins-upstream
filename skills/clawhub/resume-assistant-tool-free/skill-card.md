## Description: <br>
Resume Assistant Tool Free helps individual job seekers polish, score, and export Chinese or English resumes as Markdown. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[thcjp](https://clawhub.ai/user/thcjp) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Individual job seekers use this skill to review, score, polish, and export a single resume. It supports quick resume self-checks, Markdown resume drafts, and bilingual Chinese or English feedback. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Resume content can include personal data, and the server security summary says the skill under-discloses privacy implications. <br>
Mitigation: Use it only with resume content you are comfortable sharing with the agent's LLM provider, or redact personal details before use. <br>
Risk: The artifact requests write and exec capability beyond what a Markdown resume review workflow normally needs. <br>
Mitigation: Run with exec disabled where supported, and confirm before allowing the skill to write, save, modify, delete files, or run shell commands. <br>
Risk: Automated resume scoring and polishing can produce inaccurate or overly generic career guidance. <br>
Mitigation: Review generated claims, scores, and edits before using the resume in an application. <br>
