# 实战案例：复刻贝莱德智库《2026年中全球投资展望：破稀缺之困，赴富足之途》

> 本案例是 `brand-pdf-deck-replica` 技能的第一次完整实跑记录，2026-09-17。
> 记录重点不是"做出来了"，而是**交付前抓出并修掉的 5 个真实缺陷**——
> 这 5 个都不是目测发现的，而是硬门检查抓出来的。

## 输入

| 项目 | 值 |
|---|---|
| 页数 / 尺寸 | 19 页 / 792×594pt（16:9 横向） |
| 来源 | PowerPoint for Microsoft 365 导出 |
| 文本 | 中文缺 ToUnicode 映射（`pdftotext` 全为 `本本本本`），拉丁字符与数字正常 |
| 图形 | 每页 15–230 个 `<image>`（2×2 索引图 + smask 成对），但数据图表页为原生矢量 |

## 输出

| 产物 | 规格 |
|---|---|
| `*.pptx` | 20 页，11.00×8.25in（= 792×594pt 同尺寸），每页满幅铺底 + 演讲者备注 44,925 字 |
| `*.pdf` | 20 页，MediaBox `0 0 792 594`，4.35 MB |
| `*.html` | 20 个 `.slide`，纯 SVG 无 JS |
| `csv/` | 34 个 CSV（10 张图 / 34 系列 / 5,553 个数据点） |

**p10 是唯一残差到 0.344pt 的图**：该图为斜纹填充柱，柱体几何不在 `fill` 里而在
`clipPath` 矩形里，斜纹本身带约 1px 描边，采样点落在描边上有偏移。

## 交付前修掉的 5 个缺陷

| # | 缺陷 | 根因 | 修法 |
|---|---|---|---|
| 1 | **文件编号错字** | 原稿是 `MKTG0726-5754384-EXP0727`，被写成 `MKTGT0726-5754384-EXIP0727`（多一个 T、多一个 I） | `pdftotext \| grep -o 'MKTG[^ ]*' \| od -c` 逐字节核对 |
| 2 | **页码整体错位** | 原稿 p2+p3 被并成一页，却仍用 deck 序号当页码 | 拆回两页（p2 左黑黄面板+右双栏；p3 左双栏+右纯黑面板），页码精确对齐 1–19 |
| 3 | **文字溢出出血** | 合并页三栏文字一直排到 592pt（超过页脚 559pt） | 拆页后文字栏 545–558pt 区间墨量归零 |
| 4 | **黑底黑字隐形** | 「首席投资策略师致辞」标题为 `#000` 却落在黑色面板上（该区域实测 100% 纯黑） | 改品牌黄 `#FFCE00`；并给 `page_footer()` 加 `dark_left/dark_right`，深色侧改浅色字 |
| 5 | **附录计数不实** | 写成「11 张图 / 10 个文件 / 残差全 ≤0.07pt」，实际是 10 张图 / 37 个 CSV / 最大残差 0.344pt | 改为按数据实算，并删掉 3 个低精度重复 CSV 副本 |

## 关键认知

1. **「有位图」≠「不能反解」**。原稿每页都有几百个 `<image>`，但那是 PowerPoint 的
   着色调色蒙版（2×2 索引图 + smask）；数据图表页的折线/柱形仍是完整矢量。**必须逐页判定**。
2. **纯 SVG 版面出 PDF 要 `SKIP_VERIFY=1`**。`html-to-pdf-cdp` 自带的 `verify_charts.js`
   只认 `<canvas>`，会对正确的 SVG 版面误报「12 个 canvas 未绘出」，从而阻断 PDF 导出。
3. **PPTX 的取舍要主动讲**。自绘 SVG 图表无法用 python-pptx 表达，因此采用
   「满幅位图铺底 + 演讲者备注存全文」——保真 100%、文字可检索；
   若客户需要直接改字，需另出原生形状降级稿。
4. **受限项要如实声明**。模型读不了图，所以封面彩色线缆束、p2 黑黄图形、p3 纯黑面板
   均为**意象重构**而非像素级复制——原稿这些位置本身就是位图，无法矢量还原。
