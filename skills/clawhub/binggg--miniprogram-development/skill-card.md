## Description:

Helps developers build, debug, preview, publish, and optimize WeChat Mini Programs, including optional CloudBase integration.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to create and maintain WeChat Mini Programs, troubleshoot projects, prepare previews and releases, and integrate CloudBase when their project uses it.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Suggested package runners and developer tools may execute external code.

Mitigation: Review commands before running them, prefer official sources, and pin tool versions where possible.

Risk: Uploads, publishing, cloud deployments, message push, and automatic replies can affect a live account or its users.

Mitigation: Review the target account, environment, and changes; obtain explicit approval before account-impacting actions.
