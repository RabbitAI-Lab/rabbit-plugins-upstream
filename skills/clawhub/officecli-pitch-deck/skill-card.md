## Description: <br>
Use this skill when the user is building a fundraising or investor pitch deck for seed, Series A, Series B, Series C, convertible note, SAFE round, or strategic raise scenarios, producing a single PowerPoint deck through OfficeCLI guidance. <br>

This skill is ready for commercial/non-commercial use. <br>

Risk: The skill includes remote OfficeCLI installer commands. <br>
Mitigation: Inspect the installer script before running it, or use the linked GitHub releases/download channel where possible. <br>
Risk: The skill creates or edits local presentation files through OfficeCLI. <br>
