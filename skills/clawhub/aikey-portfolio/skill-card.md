## Use Case:

External business owners and operators use this skill with an agent to compare multiple active lines, identify the binding bottleneck resource, and make portfolio-level allocation decisions. It is intended for portfolio checkups across online tools, knowledge products, e-commerce, live selling, retail, restaurants, factories, and mixed businesses.

### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: The skill may process sensitive revenue, resource allocation, and business-line details.

Mitigation: Use the configured privacy mode and avoid sharing unnecessary absolute amounts, customer names, domains, repository names, or account identifiers.

Risk: The skill can read prior AIKEY memory and write follow-up notes when the user's environment is configured for that behavior.

Mitigation: Review the configured memory location before use and keep memory contents scoped to information suitable for future portfolio discussions.

Risk: Portfolio recommendations can affect business prioritization and line shutdown decisions.

Mitigation: Treat outputs as decision support, verify input metrics, and make final allocation or shutdown decisions through the responsible business owner.
