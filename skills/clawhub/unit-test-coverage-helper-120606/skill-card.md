## Description: <br>
Helps software teams plan, implement, and verify useful unit tests that raise test coverage for existing codebases. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, maintainers, QA engineers, open-source contributors, and product teams use this skill to add or improve unit tests, raise coverage, and document verification steps for existing codebases. <br>

### Deployment Geography for Use: <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger wording may select the skill for general testing or quality-related requests. <br>
Mitigation: Use explicit invocation or narrower trigger settings when tighter activation control is needed. <br>
Risk: Suggested tests or coverage steps may miss project-specific behavior or encode incorrect assumptions. <br>
Mitigation: Review generated tests against intended behavior and run the relevant project test and coverage commands before relying on the result. <br>
