## Description: <br>
Using Creed routes an agent to relevant Creed software-engineering judgment skills before creative, testing, debugging, or shipping work in a Creed-enabled workspace. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[gusen1453](https://clawhub.ai/user/gusen1453) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and coding agents use this skill at the start of work in Creed-enabled workspaces to decide which Creed process skill should guide software-engineering judgment, planning, testing, debugging, review, and shipping. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The workflow can slow lightweight tasks by requiring extra Creed skill checks before work proceeds. <br>
Mitigation: Install it only in workspaces where Creed's engineering workflow should influence most software-development conversations. <br>
Risk: Broad workflow-routing guidance can affect how an agent prioritizes process skills for software-engineering tasks. <br>
Mitigation: Keep user instructions and workspace policy as the final authority, and review the selected Creed skill before relying on its recommendations. <br>
