## Description: <br>
Leafer Js provides LeaferJS Canvas engine guidance for creating, developing, and debugging graphics editors, interactive canvas applications, visualizations, animations, and framework integrations. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[zhenyangze](https://clawhub.ai/user/zhenyangze) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to build or troubleshoot LeaferJS applications for canvas graphics, editors, interactive apps, visualizations, animations, plugins, and framework deployments. It supports Web, Web Worker, Node.js, WeChat Mini Program, Vue, React, Next.js, and Nuxt development workflows. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad routing language may cause the skill to be used for general canvas or visualization requests where LeaferJS is not intended. <br>
Mitigation: Constrain activation or reviewer guidance to explicit LeaferJS, Leafer, or LeaferJS Canvas engine tasks when narrower routing is required. <br>
Risk: Copyable autosave examples use browser local storage and may persist user content in production editors. <br>
Mitigation: Before using those examples in production, disclose what is stored locally and provide controls to disable, clear, or avoid local persistence. <br>
