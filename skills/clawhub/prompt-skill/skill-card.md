## Description: <br>
提示词美学 turns a short image idea into a polished GPT-image2 prompt using the Chuge AIGC aesthetic framework, built-in style templates, color-role guidance, and bilingual Chinese/English output. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Use this skill when a user wants a GPT-image2 image prompt for posters, portraits, product visuals, social cards, travel visuals, conceptual posters, or related visual-design requests. It selects from 32 style templates, fills prompt parameters, applies color and quality guidance, and returns a Chinese prompt, English prompt, and brief usage note. <br>

### Deployment Geography for Use: <br>
Global, subject to platform availability and local policy requirements. <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate on generic prompt-writing language when the user is not asking for image prompt help. <br>
Mitigation: Use explicit wording for non-image prompt work and confirm GPT-image2 image intent when the request is ambiguous. <br>
Risk: Prompts are specialized for GPT-image2 and may transfer poorly to other image, video, 3D, UI, or text-generation workflows. <br>
Mitigation: Use the output with GPT-image2 or review and adapt the prompt before using it with other tools. <br>
