#### 1.1 Minutes Quality Standard / 纪要质量标准

| 检查项 | 判定标准 | 常见缺陷 |
|-------|---------|---------|
| 决议可执行 | 每条决议含动作、责任人、时限 | 只写"原则同意" |
| 讨论与决议分离 | 讨论过程不混入决议段 | 决议里夹带讨论细节 |
| 保留意见记录 | 有异议的须标注并写明理由 | 只记主流意见 |
| 行动项可追踪 | 有编号、责任人、截止日、状态 | 无编号难以跟踪 |
| 涉密处理 | 敏感内容单独标注分发范围 | 全文群发 |
| 时限 | 会后 1 个工作日内成稿 | 拖延导致执行偏差 |

#### 2.1 Workflow Design Rules / 流程设计规则

| 规则 | 要求 | 说明 |
|-----|------|------|
| 节点从简 | 同一审批事项不超过 5 个节点 | 超出应重新评估必要性 |
| 关键双人 | 资金、用印、外发类设置复核岗 | 不得由同一人复核与审批 |
| 时限明确 | 每节点设定时限 | 超时触发提醒 |
| 不可跳过 | 关键节点不可越级或跳过 | 系统层面限制 |
| 全额留痕 | 审批意见、附件、时间戳完整 | 可回溯至发起人 |
| 分级授权 | 按金额与风险设置阈值 | 阈值调整须留审批记录 |

### 3. Meeting Efficiency / 会议效率管理

| 阶段 | 动作清单 | 输出物 |
|-----|---------|-------|
| 会前 | 明确议题与预期产出、提前分发材料、确认必要参与人 | 议程 + 材料包 |
| 会中 | 按议题计时、决议当场确认、行动项当场定责 | 决议草稿 |
| 会后 | 1 个工作日内成稿分发、行动项入台账、到期提醒 | 纪要 + 台账 |
| 复盘 | 统计到会率、超时率、行动项关闭率 | 月度复盘表 |

### 4. Writing Standards / 写作规范

| 文档类型 | 核心原则 | 篇幅建议 | 必备要素 |
|---------|---------|---------|---------|
| 请示 | 一事一请，方案不少于两个 | 1 页内 | 背景、事项、方案、建议、时限 |
| 汇报 | 结论先行 | 3 页内 | 结论、依据、风险、需支持事项 |
| 纪要 | 决议可执行 | 2 页内 | 决议、行动项、责任人、时限 |
| 通报 | 事实与结论分开 | 1-2 页 | 事实、影响、要求 |
| 报送材料 | 口径统一、数据可溯 | 按监管要求 | 数据来源、口径说明、签字 |

**通用要求**：文种选择准确；称谓与层级规范；数字与单位口径统一；附件清单完整；密级标识清晰。

### 5. Efficiency Metrics / 效率指标

| 指标 | 定义 | 参考目标 | 数据来源 |
|-----|------|---------|---------|
| 纪要当日成稿率 | 会后当日完成纪要的比例 | ≥90% | 会议记录 |
| 行动项关闭率 | 按期关闭的行动项占比 | ≥90% | 行动项台账 |
| 审批平均时长 | 发起至终审的平均用时 | 环比不上升 | 审批系统 |
| 一次通过率 | 无需退回修改的文档占比 | ≥85% | 文档记录 |
| 模板复用率 | 使用标准模板的文档占比 | ≥70% | 文档库 |
| 报送零差错 | 报送材料被退回次数 | 0 次 | 报送记录 |

### 6. Information Handling Discipline / 信息处理纪律

| 要求 | 具体做法 |
|-----|---------|
| 密级标注 | 文档按机构分级标准标注密级与分发范围 |
| 最小必要 | 对外提供信息前逐字段核对必要性 |
| 脱敏处理 | 证件号、手机号、账号等字段默认掩码 |
| 审批留痕 | 外发、用印、报送均保留审批与登记记录 |
| 工具合规 | 智能工具输入前先移除敏感客户信息 |
| 人工复核 | 智能生成的文字须经责任人核对后使用 |
