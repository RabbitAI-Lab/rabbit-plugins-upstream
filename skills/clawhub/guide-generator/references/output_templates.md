# 攻略模板库

每个模板包含：适用场景、必问参数、搜索维度（示例 query）、模板骨架、篇幅分配。
所有模板的通用规则见 SKILL.md（交叉验证、防软文、2000–3500 字正文、来源标注、信息截止日期）。

---

## §1 旅行攻略

### §1a 短途周末游（1–3 天）

**必问参数**：出发地、目的地、天数、同行人、预算、出行月份

**搜索维度**：
```
<目的地> 周末游 攻略 2026
<目的地> site:xiaohongshu.com 值得去
<目的地> 必去景点 避雷
<目的地> 住宿 推荐 区域 site:zhihu.com
<目的地> 本地人 吃什么
<目的地> 交通 怎么去 高铁
```

**模板骨架**：
```markdown
# <目的地> <N>天攻略（<月份>·<同行人>）

## 概览
- 最佳季节 / 交通到达（方式、耗时、费用） / 预算总览（表：交通|住宿|餐饮|门票）

## 行程安排
### Day 1：<主题>
- 上午：<景点/活动>（门票、耗时、避坑）
- 下午：<…>（交通衔接）
- 晚上：<…>
### Day 2：<主题> …

## 住宿建议
- 区域对比表：区域 | 优势 | 价位档 | 推荐理由

## 美食清单
| 店名 | 招牌 | 人均 | 排队建议 |
|---|---|---|---|

## 避坑与注意事项
（避雷帖要点 + 备选方案：人少版/省钱版）

## 信息来源
（平台 + 要点）
```

### §1b 长途旅行（4 天以上）

**搜索维度**（在 §1a 基础上增加）：
```
<目的地> <N>天 路线 怎么安排
<城市A> 到 <城市B> 交通 高铁/飞机 班次
<目的地> 行前准备 行李清单
<目的地> 电话卡 支付 签证 换汇
```

**模板骨架**（在 §1a 基础上调整）：
- 概览中增加「路线总览」：城市间交通表（方式|班次|耗时|价格）
- 行程按 Day 展开，每天控制 2–3 个点，预留机动时间
- 增加「行前准备」小节：证件/签证、网络、支付、天气穿衣

### §1c 自驾游

**必问参数**：路线起终点、天数、同行人、车辆（油/电）、驾驶经验

**搜索维度**：
```
<路线> 自驾 攻略 路线图
<路线> 自驾 路况 危险路段
<路线> 沿途 加油站/充电桩
<沿途地点> 住宿 停车方便
<目的地> 自驾 停车 攻略
<季节> 自驾 <路线> 注意事项
```

**模板骨架**：
```markdown
# <路线> 自驾攻略（<N>天 <里程>km）

## 路线总览
| Day | 起 → 讫 | 里程 | 预计驾驶时长 | 主要看点 |
|---|---|---|---|---|

## 每日行程
- 每日含：驾驶段 + 停留点 + 住宿地（是否方便停车）

## 车辆与补给
- 充电/加油计划（按续航里程标注）、备胎与应急工具

## 安全提示（必含）
- 路况与危险路段、天气窗口、夜间驾驶建议、保险
```

### §1d 徒步 / 登山

**必问参数**：线路（或体能水平+期望风景）、经验水平、装备情况、出行月份

**搜索维度**：
```
<线路/山> 徒步 攻略 2026
<线路/山> 难度 时长 爬升 里程
<线路/山> 门票 预约 封山
<线路/山> 避雷 危险 迷路
<月份> <线路> 天气 温度
<线路> 装备 必备 清单
```

**模板骨架**：
```markdown
# <线路> 徒步/登山攻略

## 线路信息
- 里程 / 累计爬升 / 耗时 / 难度分级（参照官方或权威平台分级）
- 最佳季节窗口 + 当日天气要求

## 体能要求
- 适合人群说明（不照搬"小白友好"的说法，按爬升和时长客观描述）

## 装备清单
| 类别 | 必备项 | 建议项 |
|---|---|---|
| 鞋服 / 补给 / 应急 / 导航 | … | … |

## 行程与下撤
- 关键节点时间表、信号盲区、下撤点

## 安全提示（必含，放显眼位置）
- 天气突变预案、结伴要求、保险与救援联系方式
```

### §1e 城市漫步 / 打卡

**搜索维度**：
```
<城市> citywalk 路线
<城市> 老街 步行 攻略
<城市> 拍照 打卡 机位
<街区> 值得去吗 避雷
```

**模板骨架**：概览 → 按街区串路线（各点间步行距离）→ 拍照机位与时间点（光线）→ 美食穿插 → 避坑。

## §2 运动攻略

### §2a 运动场地（羽毛球/游泳/攀岩/网球/健身房等）

**搜索维度**：
```
<城市> <运动> 场馆 推荐 2026
<城市> <运动> 场地 价格 预订
<运动> 场馆 避雷 site:zhihu.com
<城市> <运动> 新手 去哪
```

**模板骨架**：
```markdown
# <城市> <运动>场地攻略

## 场馆对比
| 场馆 | 位置/交通 | 价格 | 黄金时段 | 人流 | 预订方式 | 点评要点 |
|---|---|---|---|---|---|---|

## 按需求推荐
- 新手友好 / 性价比 / 高手聚集 / 就近选择

## 新手建议
- 第一次去要注意什么（自带装备、预约规则、教练费用）
```

### §2b 运动装备

**必问参数**：运动项目、水平、预算、使用频率

**搜索维度**：
```
<装备品类> 推荐 2026 测评
<装备品类> 新手 选购 避坑
<具体型号> 值得买吗 / 缺点
<装备品类> 平替 性价比
```

**模板骨架**：
```markdown
# <装备品类> 选购攻略（<水平>·预算 <N>元）

## 选购要点
- 核心参数怎么选（按水平给具体标准，如"每周跑量 >30km 再考虑 XX 级缓震"）

## 推荐清单
| 价位档 | 型号 | 参考价 | 适合人群 | 选购要点 |
|---|---|---|---|---|

## 避坑
- 溢价品牌、假货重灾区、营销噱头参数、入门不必一步到位
```

### §2c 运动入门 / 训练

**搜索维度**：
```
<运动> 入门 教程 步骤
<运动> 自学 常见错误
<运动> 受伤 预防
```

**模板骨架**：入门路径（阶段划分）→ 所需装备与花费 → 常见错误 → 安全与伤病预防 → 进阶方向。

## §3 美食攻略

### §3a 目的地美食（城市 / 街区）

**必问参数**：口味偏好、人均预算、偏好类型（本地传统 / 网红 / 小众）

**搜索维度**：
```
<城市> 必吃 美食 攻略
<城市> 本地人 吃什么 site:zhihu.com
<城市> 美食 避雷 网红店
<城市> 早茶/夜市/菜市场 攻略
<城市> <菜系> 老字号 人均
```

**模板骨架**：
```markdown
# <城市> 美食攻略（<天数>·人均 <N> 元）

## 必吃清单
| 类别 | 店名 | 招牌菜 | 人均 | 排队建议 | 备注 |
|---|---|---|---|---|---|
| 早餐 / 正餐 / 小吃 / 甜品 / 夜宵 | … | … | … | … | 本地人店/网红店标注 |

## 按街区组织
- 每街区：主推 1–2 家 + 顺路小吃，形成"食程动线"

## 避坑
- 网红店 vs 本地人店对比、宰客高发区、时令注意（如休渔期）
```

### §3b 单品探店测评（如"全城最好吃的 5 家面"）

**搜索维度**：
```
<城市> 最好吃 <单品>
<城市> <单品> 测评 对比
<城市> <单品> 老店 排队
```

**模板骨架**：横向对比表（口味特点|价格|环境|排队|适合人群）→ 分类结论（传统派/创新派/性价比）→ 回购推荐与避雷 → 探店动线建议。

## §4 购物攻略

### §4a 商圈 / 商场

**搜索维度**：
```
<城市> 商场 对比 哪个好逛
<商圈> 攻略 品牌 定位
<城市> 奥特莱斯 折扣 攻略
<商圈> 停车 交通
```

**模板骨架**：
```markdown
# <城市> 购物攻略

## 商圈/商场对比
| 商圈 | 定位 | 主力品牌 | 优惠活动 | 交通/停车 | 适合人群 |
|---|---|---|---|---|---|

## 动线建议
- 一天逛 2 个商圈怎么排（含交通时间）

## 避坑
- 导购话术、退换货政策、节假日人流高峰
```

### §4b 特产 / 伴手礼

**搜索维度**：
```
<目的地> 伴手礼 推荐 值得买
<目的地> 特产 避雷 智商税
<目的地> 本地人 买什么
<特产> 品牌 老字号 哪里买
```

**模板骨架**：
```markdown
# <目的地> 伴手礼攻略

## 必买清单
| 品类 | 推荐品牌/店 | 价格区间 | 去哪买（机场/老街/超市） | 避雷 |
|---|---|---|---|---|

## 购买建议
- 保质期与携带/邮寄、机场 vs 市区价格差、可试吃再买
```

### §4c 折扣季 / 免税 / 海淘

**搜索维度**：
```
<品牌/品类> <大促> 攻略 2026
<目的地> 免税店 攻略 价格对比
海淘 <品类> 渠道 对比 避坑
<大促> 预售 规则 避雷
```

**模板骨架**：时间窗口与节奏表 → 比价策略（历史价、渠道价差）→ 额度/退税流程 → 常见坑（预售价高于现货、赠品套路、临期品）。

## 篇幅分配参考（2000–3500 字正文）

| 部分 | 占比 |
|---|---|
| 概览/关键信息 | 10–15% |
| 行程/核心推荐 | 45–55% |
| 清单表格（不计字） | — |
| 避坑与备选 | 15–20% |
| 实用信息（交通/住宿/安全） | 10–20% |
| 信息来源 | 5% |
