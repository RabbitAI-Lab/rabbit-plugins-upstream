# ima 知识库打标规范（原料层三段式 + 资产层五维）

> 用途：md 文件上传 ima 知识库前的自动打标依据。ima 无原生标签 API，标签写在 md front-matter `tags:` 列表里（格式 `维度:值`），随文件入库，供 AI 检索与跨层连线。
> 原则：AI 自行打标，无需用户逐张确认；一卡 3–5 枚，宁缺毋滥——选错的标签比没有更糟。

## 一、原料层三段式（公众号/PDF/网页原文 → 资料收集类库）

| 标签 | 取值 | 说明 |
|---|---|---|
| `来源:` | `公众号(账号名)` / `PDF` / `网页(域名)` / `书籍(书名)` | 溯源锚点，必打 |
| `置信度:` | `事实记录` / `较可信` / `案例级` / `待校准(二手)` / `待校准(二手汇编)` | 二手转译一律标待校准，不照搬原文自称 |
| `蒸馏状态:` | `待评估` / `已蒸馏→X卡` / `暂缓(非品牌核心)` / `归案例库(非方法卡)` | 蒸馏后**必须回写**为「已蒸馏→卡名」，防止重复搬运；也是知识库瘦身的价值分层开关 |

示例（front-matter 写法）：
```yaml
tags: [来源:公众号(藏锋), 置信度:较可信, 蒸馏状态:已蒸馏→个人影响力打造法]
```

## 二、资产层五维（蒸馏出的方法卡/案例卡 → 个人主库/公司库）

### 维度1 学科域（必选 1–2 个，知识主干）
市场营销 / 数据分析 / 心理学 / 消费行为学 / 广告学 / 商业模式探究 / 品牌研究 / 品牌视觉研究

> 可按使用者自己的知识结构替换这组支柱值；单卡最多 2 个。

### 维度2 方法（必选 1 个，检索主力）
品类增长 / 定位 / 视觉一致性 / 品牌焕新 / 行业分析 / 全案策划 / 内容营销 / 包装策略 …（随积累扩充，新方法回写本规范）

### 维度3 阶段（必选 1 个，执业流程位置）
洞察 / 方法论提炼 / 方案 / 落地 / 复盘

### 维度4 类型（必选 1 个，卡片形状）
步骤卡 / 原理卡 / 工具箱卡 / 案例卡 / 模型卡

### 维度5 行业（可选）
食品滋补 / 美妆 / 3C数码 / 服饰 / 餐饮 / 通用 …

示例：
```yaml
tags: [学科域:品牌研究, 方法:品类增长, 阶段:方法论提炼, 类型:步骤卡, 行业:食品滋补]
```

## 三、打标原则

1. 学科域是骨架：至少 1 个、至多 2 个。
2. 方法 + 阶段是检索主力，务必准确。
3. 一卡 3–5 枚足够，禁「全打」。
4. 对 AI 提取内容保持质疑，标签按内容实际质量判定，不照搬来源自称。
5. 元数据卡（索引/清单/台账类）不打五维，只打 `类型:索引`。
6. 新学科/新方法值出现时回写本规范，保持取值收敛（同义词合并，不并存两写法）。
