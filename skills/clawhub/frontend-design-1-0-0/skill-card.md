### Deployment Geography for Use: <br>

## Known Risks and Mitigations: <br>
Risk: Generated frontend code may not fit the target project's accessibility, performance, framework, or dependency constraints. <br>
Mitigation: Review generated code against project standards, run local tests and audits, and adapt implementation choices before shipping. <br>
Risk: Suggested fonts, images, or other visual assets may have licensing obligations outside the skill itself. <br>
Mitigation: Confirm licenses and usage rights for any external fonts or assets before including them in a release. <br>
Risk: A strongly opinionated visual direction may be inconsistent with an existing product brand or design system. <br>
Mitigation: Compare outputs with the product design system and adjust typography, color, motion, and layout decisions for brand fit. <br>
