# router — skill reference

Pick **one** primary Mystilink theory skill. Do not run multiple systems by default.

| Need | Skill |
|------|--------|
| Birth → ten gods / long-term structure | `mystilink-bazi` |
| Birth → twelve palaces / Zi Wei | `mystilink-ziwei` |
| Birth place + time → planets/houses/aspects | `mystilink-horoscope` |
| One question, cards | `mystilink-tarot` |
| One question, hexagram / moving lines | `mystilink-liuyao` |
