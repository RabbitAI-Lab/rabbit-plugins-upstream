## 4. 核验规则（改内容前先读）

1. **改数字必须同时改三处**：知识库正文、本文件对应行、核验日期。`audit.py` 会检查。
2. **核验日期超过复核周期的项**，`audit.py` 报警。
3. **未核验的信息不许写成事实**。写法只有两种：
   - 给查找路径（"去教务处查《学生手册》第 X 章"）
   - 明确标注不确定（"这个各校差得很远，我不敢给你一个数"）
4. **禁止编造来源**。找不到来源就标"待核"，不允许写一个看起来像来源的东西。
5. 涉及**求助资源**的项（12356、96110、110、120）改动前必须重新走一遍官方渠道——这些是学生可能真的会打的号码。
