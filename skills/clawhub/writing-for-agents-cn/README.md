# 写给 Agent 看的文档：让 AI 一次就懂你的需求

**同样的提示词，Agent 有时做得对有时做偏——差别在文档怎么写。**

## 这是什么

一套可直接照着做的操作手册（Skill 形式）：包含流程、判据、踩过的坑与实测数据。

## 怎么用

1. 把本目录放到你的 Agent 技能的加载目录下（不同 Agent 位置不同，见各自文档）
2. 让你的 Agent 读 `SKILL.md`，按里面的触发条件使用
3. 需要参考细节时，Agent 会自动读 `references/` 下的文档

## 内容

    SKILL.md          主流程与触发条件
    references/       细节、判据、实测数据
    scripts/          配套脚本（如有）
    NOTICE            上游署名与本作品所做的修改声明

## 环境要求

见 `SKILL.md` 内的说明。多数内容不需要额外软件；涉及脚本的会写明依赖。
