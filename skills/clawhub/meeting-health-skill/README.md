# 会议健康度分析（meeting-health-skill）

> **参赛作品 · SkillHub 线上挑战赛（第 1 期）**
> 主题：**让开会更简单** ｜ 基于官方「腾讯会议 Skill（tmeet）」二创

把"会议开得好不好"从感觉变成指标：发言均衡度、沉默成员、决策产出率、议题覆盖率，并给出改进建议。

---

## 为什么做这个（差异化）

现有会议类作品聚焦"记要/行动项/决策"，**几乎没有量化会议效率**的工具。本 Skill 切入"会议质量度量"这一空白子场景，与 huiyi 等仅浅涉效率分析形成纵深差异，且高度契合"让开会更简单"（先度量、再优化）。

---

## 特性

- ✅ 四类指标：发言均衡度 / 沉默成员 / 决策产出率 / 议题覆盖率
- ✅ 对接 tmeet：会议报告（参会人/等候室）、智能纪要
- ✅ 本地兜底：无 tmeet 时读发言名册 CSV + 纪要，附 `meeting_health.py`
- ✅ 可解释：每项指标给出改进建议，非黑盒评分
- ✅ 可独立运行：纯标准库 Python 脚本，零依赖

---

## 环境要求

- 已安装并授权 **腾讯会议 Skill（tmeet）**（在线模式）。
- 本地模式：Python 3.8+，无需任何第三方包。

---

## 安装

下载 `meeting-health-skill.zip` → SkillHub/WorkBuddy 导入 → 同时安装官方 tmeet。

---

## 快速开始

**在线模式**
> 用户：分析这场评审会的健康度。
> 助手：tmeet 拉报告+纪要 → 算指标 → 输出报告与建议。

**本地模式**
```bash
python scripts/meeting_health.py \
  --roster examples/会议发言统计.csv \
  --minutes examples/评审会纪要.md \
  --output 健康度报告.md --name 评审会
```

---

## 辅助脚本 `scripts/meeting_health.py`

| 参数 | 说明 |
|------|------|
| `--roster` | 参会发言名册 CSV（列：成员,发言分钟,角色） |
| `--minutes` | 会议纪要素材（.md），用于统计决策产出率 |
| `--output` | 输出健康度报告路径 |
| `--name` | 会议名称（标题用） |
