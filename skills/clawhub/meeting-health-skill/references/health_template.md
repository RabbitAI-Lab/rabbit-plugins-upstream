# 会议健康度报告模板（health_template）

> meeting-health-skill 输出的健康度报告骨架。

```markdown
# 会议健康度报告 · {会议名}

- 参会人数：{n}
- 总发言时长：{total} 分钟，人均 {avg} 分钟
- 发言均衡度（最高/人均）：{balance}（>2 提示存在主导者）
- 沉默成员（<2分钟）：{名单}

## 改进建议
- 控制主导者发言占比，主动点名沉默成员
- 为沉默成员分配专属议题
```

## 四类指标释义

- **发言均衡度** = 最长发言时长 ÷ 人均发言时长；>2 表示存在明显主导者。
- **沉默成员** = 发言 < 2 分钟者；可能未参与，也可能承担记录/观察角色，需结合角色判断。
- **决策产出率** = 纪要中「决策/决定/拍板」出现次数 ÷ 会议时长；衡量会议是否产出结论。
- **议题覆盖率**（扩展）：有结论的议题数 ÷ 总议题数；衡量议程闭环程度。

> 指标为启发式统计，发言时长不等于贡献质量；报告用于提示改进方向，非绝对评价。
