## Description: <br>
Local Search lets an agent run web searches from the user's machine against public search engines with fallback and structured result output. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and agent users use this skill to retrieve current public web information, verify claims, and gather recent sources without relying on a hosted search API. <br>
