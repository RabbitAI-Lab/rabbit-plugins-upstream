# Hierarchy Rules — 主要/次要/探索性结果分层（D6）

## 判定目标

判断 Results 是否把结果按证据重要性分层，并使读者能区分主要、次要与探索性结果。

## 层级识别信号（来自 8 篇论文的真实标注）

- **主结果信号**：核心假设的直接检验；"Main analyses"（B1）；预注册分析（C2 "preregistered"）；独立主分析小节（A1 3.2/3.3 RI-CLPM）。
- **次结果信号**："Preliminary analyses"（B1）；"secondary analysis"（C2）；"for comparison"（A1 3.4 CPLM）；manipulation check / group differences（A3、B1）。
- **探索性信号**："exploratory analysis"（B2）；"second exploratory step"（A3）；"Supplementary Results/Models" 路由（B2、B3）；non-preregistered 分析（C2）。

## 分层判据

- **标注信号**：是否出现 exploratory / secondary / preliminary / for comparison / supplementary / post hoc 等分层标记。
- **排列顺序**：主要结果是否位于次要/探索性之前；探索性是否后置或放入补充材料。
- **篇幅权重**：主要结果的呈现篇幅是否 ≥ 次要/探索性；是否存在喧宾夺主。
- **回指假设**：主要结果是否与核心假设对应，次要/探索性是否与辅助目的对应。
- **预注册区分**：预注册分析与探索性分析是否混淆（C2 显式区分 preregistered / non-preregistered）。

## 典型结构问题

| 问题 | 表现 |
|---|---|
| 主次不分 | 核心结果与探索性分析同级并列，无层级信号 |
| 探索性前置 | 探索性/事后分析出现在主结果之前 |
| 层次缺失 | 大量结果无任何主次标注，读者无法判断重要性 |
| 喧宾夺主 | 次要/探索性结果篇幅或位置压倒主要结果 |
| 预注册混淆 | 预注册与探索性分析不区分，误导读者 |

## 信息不足时的处理

- 无法从输入确认预注册/主结局 → 对 D6 标注"信息不足"，不臆断层级。
- 单一分析无层次 → D6 标注 N/A。

## 判定输出

- 对每个结果块标注：primary / secondary / exploratory / 未标注。
- 记录主次顺序与篇幅权重，作为 D6 打分依据。
- 仅结构重排建议：移动结果块位置、补充分层标注句，不修改措辞。
