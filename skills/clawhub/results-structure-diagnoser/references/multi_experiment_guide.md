# Multi-Experiment Guide — 多实验/多研究/多分析组织（D7）

## 判定目标

判断包含多个实验、研究或分析时，Results 是否具备清晰的全局组织框架。

## 组织模式（来自 8 篇论文的真实范式）

| 模式 | 说明 | 真实范例 |
|---|---|---|
| 顺序式 | Experiment/Study 依次呈现，每个有独立角色 | B3（实验 1→2→3，"Next, we sought to generalize…"） |
| 平行式 | 多个平行研究/条件逐一报告，内部结构一致 | A1（3.2 use / 3.3 helpfulness 同构平行） |
| 层级式 | 主分析 → follow-up → robustness，按分析层级递进 | C1（行为→RSA→连接→控制） |
| 汇聚式 | 各实验报告后设合并/整合小节 | A2（what/why/who 三层汇聚） |
| 按 outcome 并排 | 两实验在每个 outcome 内并排报告 | C2（SCR/recall/recognition/liking，各含 Exp1+Exp2） |
| 复现声明式 | 显式声明多实验复现 | B2（"all findings replicate across the two studies"） |

## 判据

- **框架信号**：是否有统领性的实验/研究编号与小节标题。
- **角色交代**：每个实验/分析是否在开篇说明其目的（主检验/复现/拓展/稳健性）。
- **跨实验承接**：下一实验的目的是否由上一实验结果引出（B3 "Next, we sought to generalize…"）。
- **组织一致性**：各实验内部的结果呈现结构是否一致（A1 平行）。
- **跨实验总结**：是否存在跨实验总结或复现声明（B2）。

## 典型结构问题

| 问题 | 表现 |
|---|---|
| 无统领框架 | 多实验结果堆叠，无编号/标题/角色区分 |
| 承接断裂 | Experiment 2 的目的与前文结果无逻辑关联 |
| 组织不一致 | 各实验内部结构各异，读者需反复适应 |
| 分析层级混乱 | 主分析与稳健性/补充分析穿插，无递进 |

## 不适用条件

- 单研究且单分析 → D7 标注 N/A（如多数单实验论文）。
- 单研究但多分析（A1/A3/C1）→ 按"多分析组织"判定，仍适用。

## 判定输出

- 记录实验/研究边界与角色，标注组织模式。
- 标记承接断裂、组织不一致、层级混乱的位置。
- 仅结构重排建议：补统领句、重排实验/分析顺序、拆分或合并小节，不修改措辞。
