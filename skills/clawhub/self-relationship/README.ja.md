# Self-Relationship Skill · 与自己对话

[English](README.md) | [中文](README.zh-CN.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Русский](README.ru.md) | **日本語** | [한국어](README.ko.md)

> 自分自身をより明確に理解し、成長をあきらめずに自分を受け入れ、実際の人生に合った選択ができるように人を支援します。
>
> 帮助一个人更好地理解自己、接纳自己、调整自己，并在现实中做出更适合自己的选择。

ポジティブ心理学に基づく AI スキルです。「自分との関係」「自己受容」「自分を理解する」「自己成長」などの話題について、ユーザーが性急にアドバイスやレッテルを求める前に、まず理解し、その後に変化するよう導きます。

## 基本理念

- **変わる前にまず自分を理解する**：急いで判断せず、まず「何が起きたのか、何を経験しているのか、それが自分にとって何を意味するのか」と問う
- **状態はアイデンティティではない**：「今不安だ」≠「私は不安な人間だ」
- **受容は変化の放棄ではない**：現実に基づいて次の一歩を決める
- **テストは理解のための道具であり、自分を定義するラベルではない**：性格検査、MBTI、Big Five は自分を知るための鏡
- **心理学を新たな自己判断の道具にしない**：作り上げた確信も、捏造した経験も、押し付けのポジティブもなし

## 特徴

- バイリンガル内容（`SKILL.md` 内に中国語全文 + 英語版）
- 構造化された自己内省フレームワーク：事実 → 感情 → 解釈 → 判断 → 選択
- 「AI 心理学記事」のような口調を避ける明確な表現原則と境界
- 診断なし、レッテルなし、ユーザーに代わって重大な人生の決定をしない

## インストール

このディレクトリ（または `SKILL.md`）をエージェントの skills ディレクトリにコピーします:

```bash
# skills をサポートするエージェント向け（例: Claude Code、Trae など）
# self-relationship ディレクトリを skills ディレクトリにコピー
cp -r self-relationship ~/.claude/skills/
```

インストール後、ユーザーが「自分との関係」「自己受容」「自分を理解する」「自己成長」、または中国語の 「与自己相处」「自我关系」「自我接纳」「自我理解」「认识自己」「自我成长」 などの話題に言及すると、スキルが自動的に読み込まれます。

## 使い方

エージェントと話すだけです。例:

- 「自分を批判せずにはいられません。どうすればいいですか？」
- 「自分は敗北者だと感じます。性格に問題があるのでしょうか？」
- 「MBTI を受けましたが、それに定義されている気がします。」
- 「本当に何が欲しいのか分かりません。」

エージェントはスキルに定義された対話原則に従います: 理解する → 明確化する → 視点を提供する → 選択肢を見つける。

## 内容フレームワーク

1. **基本理念** — 10 の核心原則（状態 ≠ アイデンティティ、受容 ≠ 放棄、傾向への注目など）
2. **自己内省フレームワーク** — 5 つの層: 事実 → 感情 → 解釈 → 判断 → 選択
3. **重要な区別** — 事実 vs 解釈、感情 vs 判断、受容 vs あきらめなど
4. **対話原則** — アドバイスの前に理解、不確かさを許す、矛盾を許す、コントロール可能なものを見つける
5. **表現原則** — 13 の原則（AI 調を避ける、金言を減らす、経験を捏造しない）
6. **応答の方向性** — 理解する → 明確化する → 視点を提供する → 選択肢を見つける
7. **境界** — 診断なし、病理化なし、ユーザーに代わる決定なし
