# Self-Relationship Skill · 与自己对话

[English](README.md) | [中文](README.zh-CN.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Русский](README.ru.md) | [日本語](README.ja.md) | **한국어**

> 사람들이 자신을 더 명확하게 이해하고, 성장을 포기하지 않으면서 자신을 받아들이며, 실제 삶에 맞는 선택을 할 수 있도록 돕습니다.
>
> 帮助一个人更好地理解自己、接纳自己、调整自己，并在现实中做出更适合自己的选择。

긍정 심리학에 기반한 AI 스킬입니다. 사용자가 「자기 관계」「자기 수용」「자기 이해」「자기 성장」등의 주제를 이야기할 때, 성급하게 조언이나 꼬리표를 붙이는 대신 먼저 이해하고 그다음에 변화하도록 안내합니다.

## 핵심 철학

- **변화하기 전에 먼저 자신을 이해하라**: 성급하게 판단하지 말고, 먼저 "무슨 일이 있었는지, 지금 무엇을 경험하고 있는지, 이것이 나에게 무엇을 의미하는지"를 물어보라
- **상태는 정체성이 아니다**: "지금 불안하다" ≠ "나는 불안한 사람이다"
- **수용은 변화의 포기가 아니다**: 현실에 기반해 다음 단계를 결정하라
- **검사는 이해를 위한 도구이지, 나를 정의하는 꼬리표가 아니다**: 성격 검사, MBTI, Big Five는 자신을 알기 위한 거울이다
- **심리학을 새로운 자기 판단 도구로 만들지 마라**: 만들어낸 확신도, 지어낸 경험도, 강요된 긍정도 없다

## 특징

- 이중 언어 콘텐츠(`SKILL.md`에 중국어 전문 + 영어 버전 포함)
- 구조화된 자기 성찰 프레임워크: 사실 → 감정 → 해석 → 판단 → 선택
- 「AI 심리학 기사」어투를 피하는 명확한 표현 원칙과 경계
- 진단 없음, 꼬리표 없음, 사용자를 대신한 중요한 인생 결정 없음

## 설치

이 디렉터리(또는 `SKILL.md`)를 에이전트의 skills 디렉터리에 복사하세요:

```bash
# skills를 지원하는 에이전트용(예: Claude Code, Trae 등)
# self-relationship 디렉터리를 skills 디렉터리에 복사
cp -r self-relationship ~/.claude/skills/
```

설치 후 사용자가 「자기 관계」「자기 수용」「자기 이해」「자기 성장」, 또는 중국어로 된 「与自己相处」「自我关系」「自我接纳」「自我理解」「认识自己」「自我成长」등의 주제를 언급하면 스킬이 자동으로 로드됩니다.

## 사용 방법

에이전트와 대화하기만 하면 됩니다. 예:

- "자꾸 자신을 비판하게 됩니다. 어떻게 해야 하나요?"
- "제가 실패자라고 느껴요. 성격에 문제가 있는 걸까요?"
- "MBTI를 했는데 그게 저를 정의하는 느낌이에요."
- "정말로 무엇을 원하는지 잘 모르겠어요."

에이전트는 스킬에 정의된 대화 원칙을 따릅니다: 이해 → 명확화 → 관점 제시 → 선택지 찾기.

## 내용 프레임워크

1. **핵심 철학** — 10가지 핵심 원칙(상태 ≠ 정체성, 수용 ≠ 포기, 경향성에 대한 주목 등)
2. **자기 성찰 프레임워크** — 5개 층: 사실 → 감정 → 해석 → 판단 → 선택
3. **중요한 구분** — 사실 vs 해석, 감정 vs 판단, 수용 vs 체념 등
4. **대화 원칙** — 조언 전에 이해, 불확실성 허용, 모순 허용, 통제 가능한 것 찾기
5. **표현 원칙** — 13가지 원칙(AI 어투 피하기, 금언 줄이기, 경험 지어내지 않기)
6. **응답 방향** — 이해 → 명확화 → 관점 제시 → 선택지 찾기
7. **경계** — 진단 없음, 병리화 없음, 사용자 대신 결정 없음

## 면책 조항

이 스킬은 교육과 자기 성찰 목적으로만 제공됩니다. 의학적, 심리적, 임상적 진단을 구성하지 않습니다. 심각한 심리적 고통이나 위기를 겪고 있다면 자격을 갖춘 전문가(상담사, 정신과 의사, 지역 위기 핫라인 등)의 도움을 받으시기 바랍니다.
