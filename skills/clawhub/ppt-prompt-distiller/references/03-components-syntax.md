# 组件语法库: 底部通栏 + 图标范式 + 特殊组件 + 视觉语法

## 底部通栏完整分类 L12-B (9种类型 Type A-I)

底部通栏是每页"最后一句话"，决定读者带走的记忆。

### 选型决策树
```
有强金句? ──→ Type A引号金句
有公式/口诀? → Type B公式栏
需图标阵列? → Type C图标阵列
需核心判断? → Type D核心判断
一句话概括? → Type E一句话总结
量化价值? → Type F价值总结
行动召唤? → Type G CTA行动
编号结论? → Type H编号结论
安全合规? → Type I安全信任
```

### Type A - 引号金句通栏
- **格式**: `── 「[金句标语]」 ──`
- **风格**: 引号包裹, 居中, 楷体或斜体
- **适用**: 教育科普/概念解释/GOBE轨道默认首选
- **示例**: `「模型即产品，数据即资产」`
- **提示词写法**: 底部橙色细线分割, 居中引号金句, 楷体稍大

### Type B - 公式/口诀通栏
- **格式**: `── [公式/口诀/等式] ──`
- **风格**: 等宽字体或大号黑体, 可含箭头加减号
- **适用**: 方法论/工程实践/需要记忆锚的页面
- **示例**: `好提示词 = 角色设定 + 结构化指令 + 质量约束 + 少量示例`

### Type C - 图标阵列通栏
- **格式**: `[图标1]标签1  [图标2]标签2  [图标3]标签3 ...`
- **风格**: 3-6个图标横向均分排列, 每个图标下方简短标签
- **适用**: 多要点总结/能力概览/并列展示
- **示例**: `📊 数据采集 → 🔧 清洗加工 → 🤖 模型训练 → 📈 效果验证`

### Type D - 核心判断通栏
- **格式**: `★ [核心结论/判断/建议]`
- **风格**: 五角星开头, 断言式语句
- **适用**: 对比决策后给结论/分析页收尾/选型推荐
- **示例**: `★ 推荐方案A：在数据质量>90%场景下综合最优`

### Type E - 一句话总结通栏
- **格式**: `[一句话概括本页核心信息]`
- **风格**: 平实陈述句, 不用修辞
- **适用**: 信息密集页快速回顾/过渡页/辅助说明页

### Type F - 价值总结通栏
- **格式**: `📈 [关键数字]+[价值描述]`
- **风格**: 数字放大高亮(橙或绿), 配简短价值说明
- **适用**: 成果展示/效果验证/ROI展示
- **示例**: `📈 发卡量提升200万张 | 过件率提高30%`

### Type G - 行动召唤(CTA)通栏
- **格式**: `➤ [行动指令 / 下一步建议]`
- **风格**: 箭头或按钮感开头, 动词引导
- **适用**: 收尾页/教程末页/需要引导下一步操作
- **示例**: `➤ 立即在你的项目中尝试第一步：数据探查`

### Type H - 编号结论通栏
- **格式**: `①结论1  ②结论2  ③结论3`
- **风格**: 编号列表, 通常2-4条, 横向或纵向排列
- **适用**: 复杂分析页的多点结论/审计发现汇总

### Type I - 安全/信任通栏
- **格式**: `🔒 [安全声明/合规标注/信任标记]`
- **风格**: 锁/盾牌图标, 严肃但不恐怖
- **适用**: 安全合规/风控/隐私说明/收尾信任闭环
- **示例**: `🔒 以上规范均已通过平安集团安全评审`

## 图标描述范式 L5 (5种F系列)

图标是信息图的视觉词汇。每种范式决定如何在正向提示词中描述图标。

### F1 类比具象范式 (最常用, 默认)
- **模式**: `[具体实物图标]: [抽象概念]`
- **示例**: `🔑 密钥管理` / `⚙️ 参数调优` / `🎯 精准定位` / `🛡️ 安全防护`
- **类比物来源**:
  - 办公: 文件夹/剪贴板/印章/日历/便签
  - 交通: 指南针/路标/信号灯/引擎/方向盘
  - 生活: 钥匙/锁/灯泡/放大镜/天平/盾牌
  - 自然: 树/水滴/火焰/闪电/山/桥梁
- **适用**: 80%场景, 尤其面向非技术受众时

### F2 管道流转范式
- **模式**: `输入[图标] → 处理[图标] → 输出[图标]`
- **示例**: `📥 原始数据 → 🔧 特征工程 → 🤖 模型训练 → 📊 预测输出`
- **适用**: 流程图/数据管道/处理链路/架构图

### F3 升级进化范式
- **模式**: `旧版本❌ → 新版本✅ (升级说明)`
- **示例**: `手工统计 ❌ → 自动化报表 ✅ (效率提升10倍)`
- **适用**: 方案对比/升级展示/迁移指南/说服销售弧线

### F4 警示强调范式
- **模式**: `⚠️ [风险点]` 或 `🚨 [严重警告]`
- **规则**: 警示类图标必须配合橙色/红色语义, 不能单独使用
- **适用**: 安全合规/常见错误/踩坑提醒/风控要点

### F5 二级缩进范式
- **模式**: 一级图标(大) + 二级缩进(小图标+文字)
- **示例**:
```
📊 数据治理
    ├─ 📥 采集: 自动化接入
    ├─ 🔍 质量: 异常检测
    └─ 📇 标准: 元数据管理
```
- **适用**: 层级展开/目录结构/分层架构/详细分类页

## 视觉语法 L5-Conn (元素间连接规则)

### 连接符词汇表
| 含义 | 符号 | 提示词用法 |
|------|------|-----------|
| 顺序/流转 | → | "横向箭头连接, 橙色, 统一粗细" |
| 包含/归属 | └─┬─┴ | "树形分支线条, 细灰色" |
| 对比/对立 | vs / ❌⭕ | "左右分栏, 中间竖分割线" |
| 因果/推导 | ∵→∴ | "因果箭头链, 可折线" |
| 循环/迭代 | ↻ | "环形顺时针箭头, 闭合回路" |
| 并列/独立 | \| (竖线) | "竖向分隔, 等宽分栏" |
| 汇聚/整合 | ↓↘↓ | "多路汇聚箭头指向中心" |
| 分解/展开 | ↑↗↑ | "从中心向上辐射分解" |

### 排版节奏控制
- 大标题后必须空一行再开始正文
- 要点间保持一致间距(提示词中写"均匀间距")
- 同级元素使用相同尺寸(图标大小统一/文字字号统一)
- 重要程度通过: 字号 > 颜色(橙>黑>灰) > 位置(居中>左顶) > 图标大小 表达
- 避免四种以上强调方式同时出现(视觉噪音)

## 特殊组件模板 L-Special (10种可复用微组件)

以下组件可在多页重复使用，保持Deck视觉一致性。

### S1 数据标注条
- **用途**: 展示关键指标及变化
- **结构**: `[标签] [数值] [变化箭头+百分比]`
- **示例**: `📊 模型准确率 | 94.5% | ↑ 3.2% vs 上季度`
- **适用**: Layout 11/成果展示页/每页关键数据

### S2 进度/完成度条
- **结构**: `[名称] ████████░░ 80%`
- **适用**: 项目状态页/能力成熟度/阶段回顾

### S3 标签云/标签组
- **结构**: `[标签1] [标签2] [标签3] ...`
- **提示词**: 横向圆角矩形标签, 橙色边框白底黑字, 均匀间距
- **适用**: 技术栈展示/关键词提取/能力标签区

### S4 引用块
- **结构**: `┌─ 「引用内容」 ─┐  —— 作者/来源`
- **提示词**: 左侧粗橙色竖线(4px), 内部引号包裹, 右下角小字来源
- **适用**: 证据支撑/权威背书/弧线B说服销售类

### S5 公式展示框
- **提示词**: 浅灰底色圆角框, 内部等宽字体公式, 变量可斜体
- **适用**: 方法论页/算法说明页/Type B通栏

### S6 对比卡片(迷你版)
- **结构**: ⭕[简述] vs ❌[简述]
- **适用**: 页面内局部对比(非整页Layout 2)

### S7 人物/角色卡
- **结构**: [头像图标] + [角色名] + [核心诉求/特征] 3行
- **适用**: 受众分析页/用户体验页/角色说明

### S8 时间线节点
- **结构**: `●──── [时间] [事件描述]`
- **适用**: 发展历程/项目计划/版本迭代

### S9 层级标签
- **结构**: `基础 / 进阶 / 高级` (颜色由浅到深)
- **适用**: 教程分级别/学习路径/能力分层

### S10 二维矩阵格
- **结构**: 2x2四象限, 横纵轴标签, 每象限内可放图标+短标签
- **适用**: 战略分析/优先级决策/问题分类
