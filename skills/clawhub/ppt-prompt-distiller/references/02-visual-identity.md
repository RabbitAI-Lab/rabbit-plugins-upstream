## 风格前缀库 L12-A (7种变体)

每页正向提示词第一段必须以对应前缀开头，决定整页视觉身份。

| 编码 | 名称 | 适用场景 | 前缀模板 |
|------|------|---------|---------|
| G-GOBE卡 | GOBE标准知识卡片 | 科普/方法论/教程正文页 | "GOBE商务知识卡片信息长图，[概念名]主题，[副标题]，平安橙#FF6600主色纯白底色黑色正文思源黑体字体，极简扁平矢量风格无3D无渐变无阴影" |
| P-平安通用 | 平安橙企业PPT | 产品宣讲/企业汇报/案例展示 | "平安橙风格企业商务PPT单页，[标题]专题，专业价值导向，平安橙主色调白色背景商务简洁风" |
| P-Cover | 封面专用 | Deck首页/章节封面 | "平安橙风格品牌封面设计，[大标题]，[副标题/tagline]，品牌Logo区域，大气磅礴视觉冲击力，[具体意象描述]" |
| P-Tutorial | 教程步骤页 | 操作指引/流程说明/How-to | "GOBE操作教程信息长图，[主题]分步指南，Step-by-step教学式排版，步骤编号清晰箭头连接，实操导向" |

## 头部架构 L12-D (5种类型)

头部=标题区+标识区，是页面视觉锚点。

### H-A 教育解释型 (科普/教程默认)
- **触发**: 页面目标是"让读者理解一个概念"。标题含冒号分隔的定义句。
- **结构**: `[概念名称]: [一句话定义]` + 橙色分割线 + 右上GOBE角标X/N
```
┌──────────────────────────────────────────────┐
│ [概念名称]: [一句话解释定义]                    │  ← 标题行: 概念:解释 格式
│ ──────────────────────────────────────────    │  ← 橙色细分割线
│ [GOBE角标X/N                              ]   │  ← 右上角橙色圆角角标
│                                              │
│  (正文内容区)                                  │
```

### H-B 杂志吸引型 (金句钩子/痛点唤醒)
- **触发**: 页面需要先抓住注意力再展开论证。常见于弧线B说服销售类首页。
- **结构**: 大号引号金句「...」+ 分割线 + 小字证据标注
```
┌──────────────────────────────────────────────┐
│ 「[金句/痛点/反直觉事实]」                     │  ← 大号引号金句，情感钩子
│ ──────────────────────────────────────────    │  ← 分割线
│ [小字补充说明/数据来源标注]                      │  ← 金句的支撑证据
│                                              │
│  (正文内容区)                                  │
```

### H-C 企业标准型 (平安橙系默认)
- **触发**: 轨道=平安橙系时的默认头部。品牌露出优先。
- **结构**: 简洁有力标题(无冒号) + 右上品牌tagline + 平安橙粗分割线
```
┌──────────────────────────────────────────────┐
│ [简洁有力标题]                                │  ← 无冒号，短促有力
│ [平安橙品牌标识]                              │  ← 右上品牌tagline
│ ──────────────────────────────────────────    │  ← 平安橙粗分割线
│                                              │
│  (正文内容区)                                  │
```

### H-D 封面宣言型 (仅封面)
- **触发**: 仅P1封面页。视觉冲击力优先于信息密度。
- **结构**: 居中大标题(正文2.5-3倍) + 居中副标题(1.5-2倍) + 视觉主元素40-50% + Logo区
```
┌──────────────────────────────────────────────┐
│                                              │
│         [大标题 - 最大字号]                    │  ← 居中，字号=正文的2.5-3倍
│       [副标题 / tagline]                      │  ← 居中，字号=正文1.5-2倍
│                                              │
│    [视觉主元素: 抽象图形/插画/数据可视化]        │  ← 居中占画面40-50%
│                                              │
│ [品牌标识区域]                            │  ← 底部或右上Logo区
└──────────────────────────────────────────────┘
```

### H-E 极简手册型 (教程/参考卡)
- **触发**: 参考卡/速查表/Cheat Sheet类页面。信息检索效率优先。
- **结构**: 双栏 `[术语/命令] | [功能速查]` + 分割线
```
┌──────────────────────────────────────────────┐
│ [术语/命令]  |  [功能速查]                    │  ← 双栏: 左术语右释义
│ ──────────────────────────────────────────    │
│                                              │
│  (结构化速查内容)                              │
```

## 编号系统 L-NumSys

| 编码 | 样式 | 适用场景 | 示例 |
|------|------|---------|------|
| 01式 | 01 02 03 ... | 流程步骤/时间轴(等宽对齐首选) | 01数据接入 02特征工程 |
| 圈码式 | ① ② ③ ... | 并列要点/非流程性列表(最常用) | ①准确率 ②召回率 ③F1 |
| 点式 | 1. 2. 3. ... | 嵌套列表/长文本段落内编号 | 1. 数据来源 2. 清洗规则 |
| 裸数字 | 1 2 3 ... | 卡片角标/矩阵格内/空间极小时 | 卡片右上角小数字 |

**规则**:
- 同一页面只能使用一种编号样式(除非有意表达层级差异如 `1 → ① → a`)
- 编号后必须有空格再跟文字
- 编号最大不超过两位数(99), 超过则改用字母编号(a b c)
- 封面/收尾页通常不用编号
