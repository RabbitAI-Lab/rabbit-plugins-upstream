# 布局模板库 L3 (12种完整布局)

每种布局含适用场景 + 精度规格 + 密度评分 + 图标数范围。

---

## Layout 1: 总分总经典布局 (最常用, 密度★★★☆☆)

**适用**: 概念解释/方法论概述/体系介绍
**精度**: 三列等宽各占30%间距5% | **图标数**: 6-9
**结构**: 头部 -> 核心论点大号居中(焦点) -> 3x2要点网格(三列两行) -> 底部通栏

```
┌──────────────────────────────────────────────┐
│ [头部: 标题+定义/金句+标识]                      │
│ ──────────────────────────────────────────    │
│  ┌────────────────────────────────────────┐  │
│  │ [核心论点/中心概念] 大号加粗居中           │  │  ← 视觉焦点
│  └────────────────────────────────────────┘  │
│  ┌──────┐ ┌──────┐ ┌──────┐                  │
│  │ 要点1 │ │ 要点2 │ │ 要点3 │                  │  ← 三列均分
│  └──────┘ └──────┘ └──────┘                  │
│  ┌──────┐ ┌──────┐ ┌──────┐                  │
│  │ 要点4 │ │ 要点5 │ │ 要点6 │                  │
│  └──────┘ └──────┘ └──────┘                  │
│ ══════════════════════════════════════════    │
│ [底部通栏: 金句/公式栏/总结]                     │
└──────────────────────────────────────────────┘
```

## Layout 2: 左右分栏对比布局 (对比/优劣, 密度★★☆☆☆)

**适用**: 对比分析/A测试/正误对照/选型决策
**精度**: 50:50均分中间2px分割线, 左绿右红语义 | **图标数**: 4-8
**结构**: 头部 -> 左右分栏(方案A⭕ vs 方案B❌) -> 各3-4个对比点 -> 底部结论标签

```
┌──────────────────────────────────────────────┐
│ [头部]                                        │
│ ──────────────────────────────────────────    │
│ ┌─────────────────┬─────────────────┐        │
│ │ ⭕ 方案A/正确做法  │ ❌ 方案B/错误做法  │        │  ← 左绿右红语义
│ │                 │                 │        │
│ │ [A的优点1]      │ [B的问题1]      │        │
│ │ [A的优点2]      │ [B的问题2]      │        │
│ │ [A的优点3]      │ [B的问题3]      │        │
│ │                 │                 │        │
│ │ ✅ 推荐使用     │ ⚠️ 不推荐        │        │  ← 底部结论标签
│ └─────────────────┴─────────────────┘        │
│ ══════════════════════════════════════════    │
│ [底部通栏]                                     │
└──────────────────────────────────────────────┘
```

```
┌──────────────────────────────────────────────┐

## Layout 4: 中心辐射布局 (核心概念展开, 密度★★★☆☆)

│     ↓              ↓              ↓           │

## Layout 5: 矩阵/表格布局 (参数对比/规格, 密度★★★★☆)

**适用**: 多方案对比/技术选型/产品规格/竞品分析
**精度**: 列宽自适应, 表头橙底白字 | **图标数**: 3-5(行列交叉处)
**结构**: 头部 -> 表格(维度x方案矩阵) -> 数据/符号填充 -> 底部选型建议

```
┌──────────────────────────────────────────────┐
│ [头部]                                        │
│ ──────────────────────────────────────────    │
│ ┌────┬──────┬──────┬──────┬──────┐            │
│ │维度│ 方案A│ 方案B│ 方案C│ 推荐│            │  ← 表头橙底白字
│ ├────┼──────┼──────┼──────┼──────┤            │
│ │指标1│  ✓   │  ✗   │  △   │  A  │            │

│ │指标3│  中   │  高   │  低   │  B  │            │
│ │指标4│  ★   │  ☆   │  ○   │  A  │            │  ← 星级评分
│ └────┴──────┴──────┴──────┴──────┘            │
│ ══════════════════════════════════════════    │
│ [底部通栏: 选型建议/决策公式]                   │

```

## Layout 6: 卡片瀑布流布局 (多模块并列, 密度★★★★☆)

**适用**: 功能列表/能力展示/产品特性/多模块概览
**精度**: 全宽卡片给高优先级模块, 半宽双列给次要模块 | **图标数**: 6-12
**结构**: 头部 -> 全宽卡片1 -> 半宽卡片2x2 -> 全宽强调卡片 -> 半宽卡片2x2 -> 通栏

```
┌──────────────────────────────────────────────┐
│ [头部]                                        │
│ ──────────────────────────────────────────    │
│ ┌──────────────────────────────────────────┐  │
│ │ 📇 卡片1: [模块标题] + 图标 + 2-3行摘要    │  │  ← 全宽卡片

│ ┌─────────────┐ ┌─────────────┐              │
│ │📇卡片2:标题  │ │📇卡片3:标题  │              │  ← 半宽双列

## Layout 7: 时间轴/路线图布局 (演进/历程, 密度★★★☆☆)

**适用**: 技术演进/版本历史/项目里程碑/发展路径
**精度**: 横向或纵向时间轴, 节点等距 | **图标数**: 5-10
**结构**: 头部 -> 时间轴线(带箭头) -> 节点(年份/阶段+事件描述) -> 通栏

## Layout 8: 问题-解决方案布局 (痛点-方案, 密度★★★☆☆)

**适用**: 痛点唤醒->方案展示->价值证明的说服链条
**精度**: 上半问题区(红色调), 下半解决区(橙/绿色调) | **图标数**: 4-8
**结构**: 头部 -> 痛点陈述(❌) -> 过渡箭头 -> 解决方案(✅) -> 效果数据 -> 通栏

## Layout 9: 分层金字塔布局 (层级/优先级, 密度★★☆☆☆)

**适用**: 战略层分解/优先级排序/Maslow类层次
**精度**: 三层金字塔或倒金字塔 | **图标数**: 3-9
**结构**: 头部 -> 金字塔图形(三层) -> 每层标签+说明 -> 通栏

## Layout 10: 循环/闭环布局 (迭代/持续, 密度★★☆☆☆)

**适用**: PDCA/DevOps循环/持续优化/反馈回路
**精度**: 圆形环路, 4节点均布顺时针 | **图标数**: 4-8
**结构**: 头部 -> 环形流程图(↻) -> 各阶段说明(环绕) -> 中心核心理念 -> 通栏

## Layout 11: 数据可视化主导布局 (指标/仪表盘, 密度★★★★★)

**适用**: KPI dashboard/数据报告/量化结果展示/效果验证
**精度**: 大数字+趋势图为主文字为辅 | **图标数**: 3-6
**结构**: 头部 -> 核心大数字("+200%") -> 辅助图表 -> 关键洞察 -> 通栏

## Layout 12: 混合自由布局 (复杂综合页, 密度★★★★★)

**适用**: 信息密度极高的综合概述页/一图看全貌
**精度**: 自由组合多种子区域需严格对齐 | **图标数**: 10-20+
**结构**: 头部 -> 上半核心数据 -> 中左要点列表 -> 中右示例图示 -> 下半补充 -> 通栏
> ⚠️ 仅在密度确实极高时使用，**优先考虑拆分为两页**。
