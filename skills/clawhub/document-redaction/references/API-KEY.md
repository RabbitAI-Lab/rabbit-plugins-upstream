# 平台密钥与费用

用户只配置 DOCUMENT_REDACTION_API_KEY 或 AI_SKILLS_API_KEY，前者优先；两者均缺失时停止调用。不要让用户在聊天粘贴完整 Key，不输出密钥、S3 配置或模型供应商凭证。`AI_SKILLS_API_URL` 是站点根地址，例如 `https://ai-skills.open-idea.net`，不带 `/api/v1`；路径统一附加一次 `/api/v1/document-redaction`。

预检、规则分析、人工确认和导出免费；这里的“本地”指平台服务端解析，不是客户电脑离线处理。明确授权的原生 OCR 按有效交付的实际输入/输出 Token 收费，副本生成按本次成功交付的实际物理页数收费。图片按一页计，复检不另收一笔，无效定位或复检失败不当作成功。

OCR 前向用户列出所选页 ID/数量、传输对象百炼、当前输入/输出 Token 单价及最高预占。单页预留最多 50000 输入和 16384 输出 Token，页数乘各预算及对应单价计算最高金额；这不是实际消耗。生成前列出当前全部物理页数、每页单价与总额。分别取得用户明确收费授权后才 POST `redact.locate` / `redact.generate`，不得把接受候选或逐页复核视为同意收费。

当前没有公开报价 API，也没有上述公开任务的通用费用确认字段；不要发起收费任务探价，不自造 `fee`、`maximum_fee` 等字段。通过登录工作台当前价格信息确认单价和预占；无法取得价格或用户未确认时停止收费步骤，由用户在工作台确认执行。

任务响应头 `X-AI-Skills-Billing-Currency`、`X-AI-Skills-Billing-Charged`、`X-AI-Skills-Billing-Balance` 用于人民币 CNY 结算与余额核对，提交中的金额不是最终报价。原任务重放、状态查询和下载不重复计费。产品默认关闭，实际价格、地域、原生坐标、私有 S3 和授权样本验收后才能开放；依赖未就绪时如实说明，不改用其他服务绕过。
