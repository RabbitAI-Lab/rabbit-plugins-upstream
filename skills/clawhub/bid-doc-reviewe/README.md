# bid-doc-reviewe · 招标文件审查智能助手（v2.0.0）

> 精通中国招标投标法律体系的招标文件审查助手。审查招标公告、资格预审文件、招标文件、投标邀请书、澄清修改函、评标报告、中标候选人公示，输出风险清单与合规度评估。

## 协同挂载的知识库
- **招投标实务与合规**：核心法规与标准范本（法条基石）
- **招投标评标否决AI知识库**：否决依据与实战避坑（否决条款/评标报告审查）
- **招投标异议投诉处理**：异议投诉时限、渠道、答复与处理流程

> 挂载方式：SKILL.md 的 `referred_knowledge_bases` 已写入库名与 id；若平台仅支持 shareId，请将 id 替换为对应库的分享链接。

## 本次 v2.0.0 主要强化
- 内置量化硬规则兜底（检索未命中时降级，防 P1 过度依赖 RAG）
- 文件类型自适应裁剪（省 Token、缓解长文件上下文溢出）
- 品牌/技术参数排他性审查（识别"或相当于"之名行指定之实）
- 多文件关联审查与冲突检测（澄清函覆盖、文件间一致性）
- 输出模板压缩（监管热点合并进风险清单 + 总体合规度量化分级）
- 特殊程序识别（两阶段/评定分离/EPC/框架协议/电子招标）+ 地方适配
- 快速响应模式（长文件先出高风险摘要）+ 投标人视角模拟
- 检索策略精细化（分层/交叉/反向/版本锁定）

## 适用边界
- ✅ 招标投标法体系
- ❌ 不适用于政府采购货物服务招标（请用 gov-procurement-advisor）
- ❌ 不适用于国企采购合规咨询（请用 gq-procurement-advisor）
