# TokST Memory Skill changelog

## 0.9.0

- Cloud MCP is the primary interface for durable memory and knowledge.
- Cloud MCP is the supported interface for durable memory and governed knowledge.
- The Skill is scoped exclusively to Cloud MCP memory and knowledge operations.
- `tokst_memory_list` supports stable cursor pagination, type filtering, and archive-status filtering.
- `tokst_search` requires a query of at least two characters.
