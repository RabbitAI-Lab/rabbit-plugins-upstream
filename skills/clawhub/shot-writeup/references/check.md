# Check before posting

Ask all four subjects in one go, in this order. Confidentiality comes first: if the work can't be shared, the rest doesn't matter yet.

- **With a tabbed question tool** (such as AskUserQuestion in Claude Code): one call, one tab per subject, two to four options each, your recommended option first.
- **Without one:** a numbered list in one message, each question with your suggested answer, so the designer can reply "all yes" or correct one.

## The four subjects

1. **Confidentiality.** Is this OK to share? Options: it's public / it's under NDA, so blur client names and data / not sure yet, so check with the client first. Name anything in the screenshots that looks confidential: client logos, real names, real data.
2. **Problem and goal.** Is it clear what problem this solved and for whom? Suggest a one-line version from the draft.
3. **Role and credit.** What did the designer do themselves, and who else should be credited? For team work, suggest "we" and naming the collaborators.
4. **Outcome and evidence.** What changed, and can they show it? Options: a number / a quote from a user or client / a before and after / no evidence yet, so describe it plainly. Use only what they give you.

## Then

Revise the draft with their answers, keeping the format and rules from step 3. If they answered "not sure yet" on confidentiality, say once that it's worth checking with the client before posting.

Done when all four subjects are answered or skipped and the revised draft is shown. Then go to step 5, Hand over the final version.
