# 周报交付前自检清单

交付前逐项检查。任何一项不通过，先修复再交付。

## A. 口径与数据（7 项)

- [ ] 统计周期与上周一致，且在报告头标明
- [ ] 币种、含税口径、归因窗口与上周一致
- [ ] 六件套齐全：GMV、订单、AOV、花费、退款、毛利
- [ ] 缺失指标已显式标注"数据缺失"，未静默跳过
- [ ] 估算值带 `~` 前缀并注明估算方法
- [ ] 环比计算抽查 2 个数字无误
- [ ] 比率类指标环比用 pp 表述

## B. 结论质量（6 项)

- [ ] 有一句话结论，且包含增长性质判断
- [ ] 结论不与 KPI 表矛盾
- [ ] 区分了收入增长 / 效率改善 / 利润改善
- [ ] GMV 上涨但毛利率下滑时，已明确指出
- [ ] 没有"表现良好""整体平稳"式无信息结论
- [ ] 单周 ±5% 内波动未被写成"趋势"

## C. 归因质量（6 项)

- [ ] 主要异动至少拆了一层维度
- [ ] 拆分数字能解释 70%+ 的总变化量
- [ ] 每个假设标注了置信度（高/中/低）
- [ ] 低置信假设配了下周验证动作
- [ ] 检查过退款滞后和基数效应
- [ ] 没有"市场原因"式的空归因

## D. 亮点与风险（5 项)

- [ ] 亮点 ≤3 条且每条有数据
- [ ] 风险 ≤3 条且写明不处理的后果
- [ ] 单点依赖（Top1 渠道/达人/SKU 占比过高）已检查
- [ ] 库存风险（断货天数）已检查
- [ ] 退款率异常已定位到 SKU 或原因

## E. 动作清单（5 项)

- [ ] 每条动作有优先级（P0/P1/P2）
- [ ] 每条动作有影响指标和验证方式
- [ ] 无"继续观察""保持现状"类伪动作
- [ ] 上周 P0/P1 动作有回顾（做了/没做/效果）
- [ ] P0 不超过 2 条（超过说明优先级没想清楚）

## F. 呈现（4 项)

- [ ] 按 output-template.md 六大区块排列
- [ ] KPI 表格式完整，无空列
- [ ] 全文可在 3 分钟内读完核心判断
- [ ] 数据缺口声明放在文末

## 快速红线（任一命中即打回）

- 只有数字没有判断
- 口径变了没标注
- GMV 涨、毛利掉，但结论写"增长良好"
- 动作清单为空或全是"观察"
