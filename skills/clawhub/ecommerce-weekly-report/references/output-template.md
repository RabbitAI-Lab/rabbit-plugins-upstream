# 电商周报输出模板

按以下公大区块输出。区块顺序不可调换；无数据的区块保留标题并写明"数据缺失"。

## 0. 报告头

- 统计周期：YYYY-MM-DD ~ YYYY-MM-DD（自然周 / 滚动7天）
- 对比基准：上周同口径 / 4 周均值
- 口径说明：币种、含税与否、渠道归因规则
- 口径变化提示：（如无写"与上周一致"）

## 1. 一句话结论

一到两句话回答："这周生意到底怎么样，为什么。"
必须包含增长性质判断（自然增长 / 付费换量 / 活动脉冲 / 利润改善 / 恶化）。

## 3. 亮点与问题区

**亮点（≤3 条，每条带数据）**

- 亮点 1：现象 + 数据 + 为什么重要

**问题（≤3 条，每条带数据 + 不处理的后果）**

- 问题 1：现象 + 数据 + 若不处理下周会怎样

## 4. 驱动与归因

- 增长贡献项：谁贡献了多少（SKU / 渠道 / 活动 / 达人 / 地区）
- 拖累项：谁拖了多少
- 归因方式标注：数据拆分 / 假设推断（置信度 高/中/低）

## 5. 增长质量判断

- 收入增长：有 / 无，幅度
- 效率改善：ROI、转化率、退款率方向
- 利润改善：毛利额与毛利率方向
- 综合定性：这周的增长"值不值"
