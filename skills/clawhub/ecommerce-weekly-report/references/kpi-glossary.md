# 核心指标口径定义与计算公式

周报中的每个指标必须使用统一口径。本表为默认口径；若用户数据口径不同，以用户口径为准并在报告头标注。

## 交易类

| 指标 | 公式 | 口径要点 |
|---|---|---|
| GMV | Σ 订单支付金额 | 默认按支付口径，不扣退款；含税与否需标注 |
| 净销售额 | GMV − 退款金额 | 用于利润计算时优先用净销售额 |
| 订单数 | 去重订单编号计数 | 拆单/合单规则要与上周一致 |
| 客单价 AOV | GMV ÷ 订单数 | 折扣直接压 AOV，解读时结合活动 |
| 件单价 ASP | GMV ÷ 售出件数 | AOV 平稳但 ASP 下滑 = 靠凑单撑客单 |
| 连带率 | 售出件数 ÷ 订单数 | 上升通常来自捆绑/满减设计 |

## 流量与转化类

| 指标 | 公式 | 口径要点 |
|---|---|---|
| 访客数 UV | 平台后台去重访客 | 各平台去重规则不同，不跨平台直接加总 |
| 转化率 CVR | 订单数 ÷ UV | 活动期 CVR 上升多为折扣拉动，非页面优化 |
| 加购率 | 加购人数 ÷ UV | 加购升 CVR 平 = 犹豫成本高（价格/运费/信任） |

## 投放类

| 指标 | 公式 | 口径要点 |
|---|---|---|
| 广告花费 | Σ 各渠道消耗 | 注明是否含服务费、达人坑位费 |
| ROI / ROAS | 广告成交 GMV ÷ 花费 | 归因窗口（7d click 等）必须每周一致 |
| ACoS | 花费 ÷ 广告成交 GMV | 亚马逊语境常用，与 ROAS 互为倒数 |
| 边际 ROI | Δ成交 GMV ÷ Δ花费 | 判断加投是否值得的关键，比平均 ROI 更重要 |
| CPA | 花费 ÷ 广告订单数 | 与毛利/单对比得出单均盈亏 |

## 售后与利润类

| 指标 | 公式 | 口径要点 |
|---|---|---|
| 退款率 | 退款订单 ÷ 总订单 | 注明按订单数还是金额；周期内申请 vs 完成 |
| 毛利额 | 净销售额 − 商品成本 − 履约成本 | 是否扣广告费要标注（建议单列"营销后毛利"） |
| 毛利率 | 毛利额 ÷ 净销售额 | 环比看 pp（百分点）变化，不说"下降 10%" |
| 营销后毛利 | 毛利额 − 广告花费 | 判断"付费换量值不值"的最终指标 |

## 环比与对比

- WoW 环比：(本周 − 上周) ÷ 上周，保留 1 位小数
- vs 4 周均值：本周 ÷ 过去 4 周均值 − 1，用于过滤单周噪音
- 百分点 (pp)：比率类指标（毛利率、退款率、CVR）环比一律用 pp 表述
- 大促周对比：与上一次同类大促对比，不与普通周对比

## 常见口径坑

1. 支付口径 vs 下单口径混用——预售期差异巨大。
2. 广告归因窗口周中被平台调整——环比失真，需标注。
3. 退款滞后——本周退款多来自上周订单，高退款率先查订单归属周。
4. 含税/不含税混用——尤其多平台汇总时。
5. 汇率波动——跨境店铺环比先固定汇率再比较。
