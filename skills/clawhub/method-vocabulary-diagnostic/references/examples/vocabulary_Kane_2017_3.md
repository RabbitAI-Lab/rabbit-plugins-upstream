# 片段类型：词汇

## 原文片段

Prior to the real trials of the task, participants first practiced the memory portion alone (one trial each of set sizes two and three), then practiced the processing portion alone (two trials each of set sizes two through five), and then practiced two combined trials (one each of set size two and three). Processing-only practice was additionally used to establish the reaction time (RT) cut-off for processing stimuli in the real task: If any symmetry-decision display exceeded the processing-practice mean RT plus 2.5 standard deviations, it disappeared and counted as a processing error.

## 来源文献

Kane et al., 2017, Journal of Experimental Psychology: General

## 适配诊断点

"Prior to" 引出正式试次前的练习阶段，first / then / and then 精确串联多步练习流程，冒号后补充规则细节，是规范序列连接词与程序描述的范例。
