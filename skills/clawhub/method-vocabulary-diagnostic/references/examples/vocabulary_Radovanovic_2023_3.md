# 片段类型：词汇

## 原文片段

An utterance was classified as containing process praise if it positively evaluated the infant's effort, strategies, or actions. These included phrases such as "good job!" or "great stacking!" (see Table S1). ... For praise to be contingent, caregivers must observe infants performing desired behavior before they can use praise to reinforce it. Thus, we classified an utterance as overlapping with infant behavior if it directly overlapped with caregiver speech (i.e., occurring during the previously coded timestamps for process praise), but also if infant behavior occurred up to 5 seconds before process praise began.

## 来源文献

Radovanovic et al., 2023, Developmental Psychology

## 适配诊断点

"was classified as ... if it ..." 的操作定义句式 + "For praise to be contingent, ... must ..." 的逻辑前提表述 + "Thus, we classified ... if ... but also if ..." 的条件界定，是行为编码标准的精确词汇范本。
