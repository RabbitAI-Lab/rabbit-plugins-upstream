# 心理学实证论文 Method 部分「词汇与学术用语维度」检查清单

> 标准依据：《Science Research Writing》(2nd ed.) §2.4「Useful Words and Phrases」与 §2.4.2「Language for the Methods section」（基于 2,500+ 篇 STEMM 论文词频分析）；学术写作通则：精确动词、动词+介词搭配、术语层级一致、正式语体。

---

## 1. 学术动词准确性

### 1.1 材料/设备来源动词

- [ ] 描述材料/设备/样本来源时使用教材 §2.4.2 列举的动词之一：`was obtained from` / `was purchased from` / `was acquired from` / `was provided by` / `was supplied by` / `was a kind gift (from)` / `was generated` / `was found (in)` / `was used as received` / `was used as supplied` / `is commercially available`
- [ ] 来源主语-动词搭配正确（`was a kind gift from Dr X` 而非 `was gifted from Dr X`）
- [ ] 商业来源给出公司 + 地点（`purchased from Sigma Aldrich` / `provided by Gibco, UK`），非仅"commercially obtained"
- [ ] 个人赠予来源给出姓名 + 单位（`a kind gift from Dr David Louis, Massachusetts General Hospital, MA, USA`）
- [ ] 不混用 `obtained` 与 `acquired`：`obtained` 用于样本/材料；`acquired` 多用于数据/影像

### 1.2 通用学术研究动词

- [ ] 研究目的/总论描述使用教材 §2.4.2「第一类通用学术研究动词」：`attempt` / `conduct` / `consider` / `determine` / `investigate` / `report` / `verify`
- [ ] 不混用 study/research/investigation/examination 同义名词（保持术语一致）
- [ ] 不使用口语化动词（`look at` / `check out` / `find out`）替代正式研究动词（`examine` / `investigate` / `determine`）

### 1.3 跨学科技术动词（教材 §2.4.2 第三类）

- [ ] 描述具体技术操作时优先使用 80+ 跨学科技术动词：`was adapted` / `was added` / `was administered` / `was adjusted` / `was analysed` / `was applied` / `was assembled` / `was assessed` / `was calibrated` / `was calculated` / `was characterised` / `was collected` / `was combined` / `was compared` / `was computed` / `was conducted` / `was connected` / `was constructed` / `was controlled` / `was converted` / `was defined` / `was derived` / `was designed` / `was determined` / `was discarded` / `was distributed` / `was divided` / `was eliminated` / `was employed` / `was estimated` / `was evaluated` / `was examined` / `was excluded` / `was exposed` / `was extracted` / `was fabricated` / `was filtered` / `was formulated` / `was generated` / `was immersed` / `was implemented` / `was included` / `was incorporated` / `was initiated` / `was input` / `was inserted` / `was installed` / `was inverted` / `was isolated` / `was located` / `was maintained` / `was maximised` / `was measured` / `was minimised` / `was modelled` / `was modified` / `was monitored` / `was normalised` / `was operated` / `was optimised` / `was performed` / `was placed` / `was plotted` / `was positioned` / `was prepared` / `was processed` / `was produced` / `was quantified` / `was recorded` / `was recovered` / `was regulated` / `was removed` / `was repeated` / `was represented` / `was restricted` / `was retained` / `was retrieved` / `was sampled` / `was scored` / `was selected` / `was separated` / `was simulated` / `was solved` / `was stabilised` / `was substituted` / `was synthesised` / `was tracked` / `was transferred` / `was treated` / `was varied` / `was utilised`
- [ ] 操作动词选择与主语匹配（被动主语为材料/对象：`The film was placed in...`；主动主语为研究者：`We administered the survey`）
- [ ] 同一操作全篇使用同一动词（不 `measured` 与 `assessed` 混用描述同一测量）
- [ ] 不使用 -ize 类生造动词（`we analyzized` 应为 `we analysed`）

### 1.4 因果 / 结果动词（教材 §2.4.2「CAUSE and RESULT」）

- [ ] 因果链使用 §2.4.2 列举的因果动词：`achieve` / `allow` / `avoid` / `compensate (for)` / `confirm` / `determine` / `enable` / `enhance` / `ensure` / `establish` / `facilitate` / `guarantee` / `improve` / `include` / `increase` / `limit` / `minimise` / `obtain` / `overcome` / `permit` / `prevent` / `provide` / `reduce` / `remove` / `simplify` / `validate`
- [ ] 不使用 `made` / `gave` / `got` 替代（`We made it possible` 应为 `we enabled`）
- [ ] 避免动词堆砌（同一句中两个以上因果动词并列：`ensures... and facilitates... and allows...`）

### 1.5 材料位置 / 空间关系动词（教材 §2.4.2「Verbs」）

- [ ] 描述材料/设备位置使用：`align` / `arrange` / `assemble` / `attach to` / `bisect` / `connect` / `converge` / `couple` / `embed` / `encase` / `enclose` / `fasten` / `fit` / `fix` / `install` / `intersect` / `join` / `locate` / `mount` / `orient` / `place` / `position` / `situate` / `space` / `surround`
- [ ] 区分精确空间动词：`fit`（尺寸配合）vs `install`（安装到位）vs `mount`（固定于支架）vs `position`（调整到目标方位）
- [ ] 描述几何方位使用规范副词/介词：`above` / `below` / `underneath` / `beside` / `alongside` / `adjacent` / `opposite` / `in close proximity`
- [ ] 描述几何关系使用：`parallel (to/with)` / `perpendicular (to)` / `symmetrical` / `asymmetrical` / `equidistant` / `equally spaced`
- [ ] 描述流向/序列使用：`upstream (of)` / `downstream` / `in the vicinity` / `out of range` / `within range`

### 1.6 操纵 / 处理动词

- [ ] 隐蔽操纵使用 `disguised as`（`disguised as a measure of familiarity with songs`）
- [ ] 刻意操纵使用 `deliberately manipulated`（`the list of songs was deliberately manipulated`）
- [ ] 改编使用 `adapted from` / `a (modified) version of` / `slightly modified` / `based on`
- [ ] 排除使用 `excluded` / `eliminated` / `discarded` / `removed` / `restricted` / `retained`（而非 `we threw out` / `we kept`）
- [ ] 随机化使用 `randomly assigned` / `randomized` / `allocated` / `counterbalanced`（而非 `put into groups`）

### 1.7 测量 / 评分动词

- [ ] 测量动词三档：`measured`（客观量）/ `assessed`（含主观判断）/ `estimated`（统计估计）
- [ ] 评分动词按量尺类型选：`rated`（李克特）/ `scored`（量表计分）/ `coded`（行为编码）/ `categorized`（分类）/ `classified`（归类）
- [ ] 记忆/识别动词：`recognized` / `identified` / `recalled` / `detected`（不混用）
- [ ] 操纵检验动词：`checked` / `confirmed` / `verified` / `validated`（不混用）
- [ ] 行为观察动词：`observed` / `monitored` / `recorded` / `tracked`（不混用）

### 1.8 数据处理 / 统计动词

- [ ] 因子分析动词：`conducted` / `extracted` / `retained` / `rotated` / `replicated`（搭配 EFA/CFA）
- [ ] 模型拟合动词：`fitted` / `estimated` / `tested` / `compared`（搭配 SEM/LTA/IRT）
- [ ] 数据清洗动词：`cleaned` / `screened` / `excluded` / `winsorized` / `transformed` / `normalized`
- [ ] 不混用 `performed` 与 `conducted`：`performed` 用于具体操作（performed a t-test），`conducted` 用于整体研究/分析（conducted EFA）

### 1.9 严谨性副词（教材 §2.4.2「INDICATE CARE」）

- [ ] 操作严谨性使用：`accurately` / `appropriately` / `carefully` / `completely` / `constantly` / `correctly` / `directly` / `exactly` / `firmly` / `frequently` / `gently` / `immediately` / `independently` / `individually` / `precisely` / `randomly` / `rapidly` / `reliably` / `repeatedly` / `rigorously` / `separately` / `smoothly` / `strictly` / `successfully` / `thoroughly` / `tightly` / `uniformly` / `vigorously`
- [ ] 形容词形式与副词形式不混用（`careful` 修饰名词；`carefully` 修饰动词）
- [ ] 不使用模糊副词 `very` / `really` / `extremely` / `a lot` 替代精确副词（`very carefully` 应改为 `rigorously`）
- [ ] 「every / each / both / all」强调全部性使用规范（`each participant was tested individually`）

### 1.10 「happy words」积极修饰词（教材 §2.4.2）

- [ ] 方法/工具/材料优点描述使用：`accurate` / `consistent` / `direct` / `easy` / `excellent` / `important` / `precise` / `relevant` / `robust` / `satisfactory` / `simple` / `suitable` / `useful`
- [ ] 不使用口语积极词（`great` / `nice` / `good` / `awesome` / `cool`）替代
- [ ] 「happy words」与严谨性副词配套使用（`a reliable method based on...` / `a robust analytical method`）

### 1.11 局限 / 困难表达动词（教材 §2.4.2「INDICATE PROBLEMS」）

- [ ] 局限性表达使用规范动词：`limited by` / `minimised` / `prevent` / `impossible` / `impractical` / `inevitable` / `unavoidable` / `unworkable`
- [ ] 不使用责任推卸表达（`we couldn't` / `we failed to`）改为客观（`it was difficult to` / `limited by` / `not possible`）
- [ ] 不使用自我贬低表达（`our method was bad`）改为客观（`slightly problematic` / `less than ideal`）

## 2. 固定搭配规范性

### 2.1 借鉴 / 比较搭配（教材 §2.4.2「COMPARE WITH」三 Option）

- [ ] **Option 1 完全相同** 使用：`according to` / `as described by/in` / `as detailed by/in` / `as explained by/in` / `as in` / `as proposed by/in` / `as reported by/in` / `as suggested by/in` / `following X et al.` / `identical to` / `in accordance with` / `previously shown in/by` / `the same as that of/in` / `using the method of/in` / `described elsewhere` / `details are given in`
- [ ] **Option 2 相似** 使用：`adapted from` / `almost the same as` / `based on` / `essentially identical` / `essentially the same` / `except for/that` / `in essence` / `in line with` / `in principle` / `largely the same` / `more or less identical` / `partly based on` / `practically the same` / `similar (to)` / `slightly modified` / `virtually the same` / `with some adjustments` / `with some alterations` / `with some changes` / `with some modifications`
- [ ] **Option 3 显著不同** 使用：`a novel step was` / `although in many ways similar` / `although in some ways similar` / `although similar to` / `except for/that` / `instead (of)` / `loosely based on` / `partly based on` / `unlike` / `with the following modifications`
- [ ] Option 1 借 by / of / in 后接规则正确：`by` / `of` 后接研究者名（`as described by Ross`）；`in` 后接文献（`as described in Ross et al. [2020]`）
- [ ] Option 3 显著不同时**显式列出差异点**（`with the following modifications:` 后接项目列表）
- [ ] 借鉴标注紧贴所借鉴方法/材料，不误挂他人工作

### 2.2 对比 / 让步连词（教材 §2.4.2「CONTRAST」）

- [ ] 段内对比使用：`however` / `whereas` / `by contrast` / `while` / `although` / `on the other hand`
- [ ] 条件对比使用：`either ... or ...` / `both ... and ...` / `neither ... nor ...` / `not only ... but also ...`
- [ ] 让步对比使用：`although` / `even though` / `despite` / `in spite of` / `whereas` / `while`
- [ ] 不使用口语对比（`but` / `and` / `also`）替代规范连词

### 2.3 序列连接词（教材 §2.4.2「SEQUENCE LANGUAGE」8 组）

- [ ] **Group 1 实验前**：`beforehand` / `earlier` / `formerly` / `in advance` / `originally` / `previously` / `prior to` / `initially`
- [ ] **Group 2 开始 / 第一步**：`at first` / `at the beginning` / `at the start` / `firstly` / `in the beginning` / `initially` / `to begin with` / `to start with`
- [ ] **Group 3 步骤顺序**：`after` / `afterwards` / `followed by` / `following` / `next` / `secondly` / `subsequently` / `then`
- [ ] **Group 4 短间隔后**：`quickly` / `shortly after` / `soon`
- [ ] **Group 5 较晚 / 较长等待后**：`eventually` / `in due course` / `in time` / `later` / `later on` / `towards the end`
- [ ] **Group 6 同时发生**：`as` / `as soon as` / `at once` / `at that point` / `at the same time` / `directly` / `immediately` / `instantly` / `in the meantime` / `meanwhile` / `once` / `simultaneously` / `straight away` / `until` / `when` / `while`
- [ ] **Group 7 结尾 / 最后一步**：`at the end` / `eventually` / `finally` / `in the end` / `lastly`
- [ ] **Group 8 实验后**：`afterwards` / `eventually` / `later` / `later on` / `subsequently`
- [ ] **避免** 口语化连接词（`and then` / `after that` / `next thing`）单独使用
- [ ] 同一程序链中 Group 3 词不重复堆砌（`First... then... then... finally...`），用不同 Group 或序号替代
- [ ] 序列词与「时间状语」配合（`presented for 650 ms` / `every 5 s` / `5 s long`）

### 2.4 理由 / 目的搭配（教材 §2.4.2「JUSTIFY CHOICES」）

- [ ] 显式目的使用：`in order to` / `with the aim of` / `so as to` / `so that` / `such that` / `for the purpose of` / `to this end` / `to take advantage of` / `our aim was to` / `provide a way of/to` / `selected on the basis of` / `in an attempt to`
- [ ] 优势/正当性使用：`chosen for/to` / `designed for/to` / `for brevity` / `for convenience` / `for maximum effect` / `for (the sake of) simplicity` / `the advantage of` / `the reason for` / `thereby` / `thus` / `which/this allowed` / `which/this permitted` / `which meant that` / `by doing..., we were able to`
- [ ] **不省略目的**——每个操作环节附带理由（to ensure / to account for），非机械罗列
- [ ] `so as to` 与 `in order to` 不混用（前者更正式，Goal-emphasized）；`to` 不带 `in order`（短句直接 `to`）

### 2.5 因果信号连接词

- [ ] 因果显式化使用：`because` / `since` / `as` / `therefore` / `thus` / `hence` / `thereby` / `consequently` / `as a result` / `accordingly` / `so` / `so ... that` / `such ... that`
- [ ] 不使用 `so` 单独承担因果（句首/句中用 `therefore` / `thus` / `hence`）

### 2.6 介词决定动词 / 名词含义（教材 §2.5.2）

- [ ] `evidence of`（存在）vs `evidence for`（可能存在）按语义选择，不互换
- [ ] `X was substituted for Y`（X 替换 Y）vs `X was substituted with Y`（Y 替换 X）按方向选择
- [ ] `was hit by a metal bar`（无意）vs `was hit with a metal bar`（有意）按意图选择
- [ ] `with one eye` 歧义敏感（using / having），上下文能消歧或换用 `using` / `by doing`
- [ ] `was coated with Y`（Y 是涂层材料）vs `was coated by (doing) Y`（Y 是涂覆方式）按过程选择
- [ ] 介词搭配与名词/动词常见组合一致：`derived from` / `based on` / `consistent with` / `consistent across` / `applied across` / `calibrated against` / `mapped against` / `assessed using` / `calculated by dividing`

### 2.7 来源 / 引用搭配

- [ ] 引用紧贴被引用方法/结果（`using the Shapiro-Wilk test¹¹` 而非段末统一标注）
- [ ] 多文献引用格式一致（`Smith et al. (2010)` 或 `(Smith et al., 2010)`，全文统一）
- [ ] 改编引用与完全相同引用区分（`adapted from Smith (2010)` ≠ `as described by Smith (2010)`）
- [ ] 引用人名 + 年份 vs 仅年份 vs 仅编号（全文统一一种格式）

### 2.8 量表 / 测量方法搭配

- [ ] 量尺锚点格式：`1 (strongly disagree) to 7 (strongly agree)` 或 `1 = strongly disagree to 7 = strongly agree`，全文统一
- [ ] 「assessed via / measured by / evaluated using」三搭配按语义选（assessed 含主观，measured 含客观，evaluated 含判断）
- [ ] 量表来源：`X scale (Author, Year)` / `X scale (Author et al., Year)` / `the X scale developed by Author (Year)` 三选一
- [ ] 量表报告公式化：工具 → 改编 → 理由 → 保留条目 → 信度 → 量尺锚点
- [ ] 缩写使用：首次给全称（`Exploratory Factor Analysis (EFA)`），后续直接用缩写

### 2.9 数据呈现搭配

- [ ] 统计值报告：`M = 3.51 (SD = 1.35)` 或 `M = 3.51, SD = 1.35`，全文统一
- [ ] 范围表达：`ranging from 1 to 7` / `range = 1–7`，含端点
- [ ] 样本量绑定：`with N = 80` / `among the 1,002 respondents` / `leaving 906 participants`
- [ ] 排除量化：`12 excluded for being Roma, 84 for attention check`，原因一一对应

### 2.10 标点 / 缩写搭配

- [ ] 引号使用：操纵材料原文用双引号（`"Rate your gut reactions towards environmental protection"`）
- [ ] 嵌套引号：外双内单（`"She said 'hello' to me"`）
- [ ] 破折号用法：em-dash（—）插入语；en-dash（–）数值范围；hyphen（-）复合词
- [ ] 缩写首次给全称：structural equation modeling (SEM) / Full Information Maximum Likelihood (FIML)
- [ ] 单位空格：5 s, 650 ms, 250℃, 120 Hz, 0.5 visual angles（数值与单位间留空格）
- [ ] 百分号无空格：72.43%（非 72.43 %）

## 3. 专业术语一致性

### 3.1 核心概念术语全文统一

- [ ] **被试/参与者** 术语统一：`participants` / `subjects` / `respondents` / `individuals` 四选一，全文一致（`participants` 为心理学顶刊主流）
- [ ] **条件/组** 术语统一：`condition` / `group` / `level` 三选一，全文一致
- [ ] **刺激/材料** 术语统一：`stimulus` / `stimuli` / `material` / `item` 按对象类型选，全文一致
- [ ] **反应/回答** 术语统一：`response` / `answer` / `reply` / `rating` 按反应类型选，全文一致
- [ ] **任务/范式** 术语统一：`task` / `paradigm` / `procedure` / `trial` 按颗粒度选，全文一致
- [ ] **操纵/处理** 术语统一：`manipulation` / `condition` / `intervention` / `treatment` 按场景选，全文一致
- [ ] **测量/评估** 术语统一：`measure` / `measurement` / `assessment` / `instrument` / `scale` 按对象选，全文一致
- [ ] **样本** 术语统一：`sample` / `dataset` / `cohort` / `study population`，全文一致
- [ ] **目标/对象** 术语统一：`target` / `referent` / `object` / `referent category`，全文一致

### 3.2 构念名即小节标题

- [ ] Method 节小标题以构念名直接命名（`Dehumanization.` / `Prejudice.` / `Mortality Salience.` / `Pretreatment Variables.` / `Personality-Descriptive Adjectives.` / `Gut Reactions and Actual Feelings.`），无需 `Measures of X` 或 `X Scale` 赘述
- [ ] 子节标题以正式名为主，必要时冒号后接通俗名（`Main Dependent Variable: Who Said What?` / `Direct Measures: Gut Reactions and Actual Feelings`）
- [ ] 同名小标题全文一致（`Procedure.` 不混用 `Experimental Procedure.` / `Study Procedure.`）

### 3.3 操纵 / 测量命名体系

- [ ] 操纵条件标签全文一致（`caring / uncaring`；`high-quality / low-quality`；`MS / sadness`）
- [ ] 测量命名体系内部自洽（`A-Easy Sets / A-Hard Sets / P-Easy Sets / P-Hard Sets` 四类对应）
- [ ] 操纵材料命名可识别（`Selective Teacher video / Overpraise Teacher video`；`Warm-up Phase / Test Phase`）
- [ ] 量表/范式版本号一致（`HEXACO-60` vs `HEXACO-100`；`SDO7` vs `SDO7(S)`）
- [ ] 软件/工具版本号一致（`Mplus Version 7` / `R Version 4.2.1` / `Python 3.9`）

### 3.4 缩略词管理

- [ ] 缩略词首次出现给全称：`structural equation modeling (SEM)` / `Full Information Maximum Likelihood (FIML)` / `Event-contingent sampling (ECS)` / `Implicit Association Test (IAT)` / `Latent Transition Analysis (LTA)`
- [ ] 同名缩略词全文一致（`SEM` 不混用 `S.E.M.` / `sem`）
- [ ] 自创缩略词遵循「首字母」规则（`A-Easy Sets` 取形容词首字母 `A`；`P-Easy Sets` 取 Paraphrases 首字母 `P`）
- [ ] 缩略词定义一次后全文复用，不反复重新定义

### 3.5 构念定义 → 测量工具 → 评分 → 量尺 链条

- [ ] 每构念按 `构念定义 → 测量工具 → 条目/题项 → 计分 → 量尺锚点 → 信度` 顺序报告
- [ ] 构念定义在前，测量操作在后（`Dehumanization was assessed via... X scale consists of N items...`）
- [ ] 量尺锚点逐字给出（`1 (does not apply) to 5 (applies)`），无歧义
- [ ] 计分方向显式说明（`reversed such that higher scores indicate more dehumanization`）
- [ ] 信度报告规范：`Cronbach's α = .86` / `ω = .91` / `composite reliability = .92`
- [ ] 构念名 → 工具名 → 评分方向 全文对齐（不 `dehumanization` 量表又 `prejudice` 量表名混用）

### 3.6 题项 / 操纵材料原文引用

- [ ] 量表题项引用给出完整原文（带引号或斜体），确保可复现
- [ ] 操纵材料指令以「参与者视角」原文引用（`"Before the session begins, suppose you see the other person in the waiting room..."`）
- [ ] 多题项以 `(a) / (b)` 编号并保持全文一致
- [ ] 原文引用前给出位置/上下文（`presented in the upper portion of the screen`）

### 3.7 统计符号 / 量表符号

- [ ] 统计符号格式：`M` / `SD` / `α` / `ω` / `CR` / `AVE` / `CFI` / `RMSEA` / `SRMR` 全文一致（斜体或正体按期刊规范）
- [ ] 量表锚点格式全文一致（`1 = strongly disagree to 5 = strongly agree` 或 `1 (strongly disagree) to 5 (strongly agree)`，二选一）
- [ ] p 值格式：`p < .05` / `p < 0.05` / `p < .001` 全文一致
- [ ] 效应量格式：`η² = .06` / `partial η² = .06` / `Cohen's d = 0.45` 全文一致
- [ ] 置信区间格式：`95% CI [x.xx, x.xx]` / `95% CIs [x.xx, x.xx]` 全文一致

### 3.8 工具版本 / 数据集名

- [ ] 量表版本号一致（`HEXACO-60` / `HEXACO-100`；`SDO7` vs `SDO7(S)`）
- [ ] 数据集 / 样本来源名一致（`GLR data set` / `Lab-TAB procedure` / `Portrait Values Questionnaire`）

## 4. 正式语体恰当性

### 4.1 避免口语化连接词

- [ ] **不** 使用口语化序列词 `then` / `next` / `and then` / `after that` / `next thing` 单独承担步骤衔接
- [ ] **不** 使用口语化对比词 `but` / `also` / `and` 单独承担让步/递进（用 `however` / `whereas` / `moreover` / `furthermore`）
- [ ] **不** 使用 `so` 单独承担因果（句首用 `therefore` / `thus` / `hence`）
- [ ] 程序链中**优先**使用教材 §2.4.2 Group 1–8 序列词（`prior to` / `subsequently` / `at which point` / `simultaneously` / `upon completion`）

### 4.2 避免口语化动词

- [ ] **不** 使用 `do` / `did` 单独承担研究操作（`we did the test` 应为 `we conducted the test` / `we administered the test`）
- [ ] **不** 使用 `get` / `got` 替代 `obtain` / `receive` / `acquire`
- [ ] **不** 使用 `make` / `made` 替代 `perform` / `conduct` / `produce` / `create`（除固定搭配 `made up of`）
- [ ] **不** 使用 `have` / `had` 单独承担研究操作（`we had the participants do...` 应为 `we asked the participants to do...` / `participants were asked to do...`）
- [ ] **不** 使用 `give` / `gave` 替代 `provide` / `administer` / `deliver`
- [ ] **不** 使用 `go` / `went` 替代 `proceed` / `continue`
- [ ] **不** 使用 `look at` / `check out` / `find out` 替代 `examine` / `investigate` / `determine`
- [ ] **不** 使用 `figure out` 替代 `determine` / `ascertain` / `identify`

### 4.3 避免口语化语气

- [ ] **不** 使用第一人称 `I`（学术 Method 用 `we` 或被动语态）
- [ ] **不** 使用第二人称 `you`（避免在 Method 节指令读者如何做）
- [ ] **不** 使用反问句（`How could we...?` / `Why did we...?`）
- [ ] **不** 使用感叹句（`What a surprise!` / `Amazing!`）
- [ ] **不** 使用缩写形式（`don't` / `can't` / `won't`），用完整形式（`do not` / `cannot` / `will not`）
- [ ] **不** 使用俚语（`a bunch of` / `tons of` / `sort of` / `kind of`）
- [ ] **不** 使用夸张副词（`very` / `really` / `extremely` / `super` / `totally`）

### 4.4 避免口语化名词 / 量词

- [ ] **不** 使用模糊量词 `a lot of` / `lots of` / `many` / `much` / `some` / `a few`（除非刻意表达数量级）
- [ ] **不** 使用 `big` / `huge` / `tiny` 替代 `large` / `considerable` / `substantial` / `small` / `negligible`
- [ ] **不** 使用 `thing` / `stuff` 替代 `item` / `element` / `component` / `factor` / `variable`
- [ ] **不** 使用 `kind of` / `sort of` 替代 `type of` / `category of`
- [ ] **不** 使用口语集合名词 `a bunch of` / `a lot of`（用 `a set of` / `a battery of` / `a pool of` / `a series of`）

### 4.5 严谨性副词使用规范（教材 §2.4.2「INDICATE CARE」）

- [ ] 操作描述附严谨性副词：`carefully` / `precisely` / `gently` / `thoroughly` / `rigorously` / `smoothly` / `tightly` / `rapidly` / `constantly` / `uniformly` / `repeatedly` / `reliably`
- [ ] 严谨性副词与具体操作匹配：`tightly clamped` / `gently inverted` / `precisely measured` / `carefully condensed`
- [ ] 不滥用严谨性副词（每段 ≤ 3 处，避免堆砌削弱可信度）
- [ ] 「every / each / both / all」与严谨性副词配套（`each participant was tested individually`）

### 4.6 「happy words」积极修饰词使用规范

- [ ] 方法/工具/材料优点使用规范形容词：`accurate` / `consistent` / `direct` / `precise` / `robust` / `reliable` / `satisfactory` / `suitable`
- [ ] **不** 使用口语积极词 `great` / `nice` / `good` / `awesome` / `cool` / `amazing`
- [ ] 优势描述以方法效果为单位（`a reliable analytical method based on HPLC`），不以个人感受为单位

### 4.7 局限性表达规范（教材 §2.4.2「INDICATE PROBLEMS」）

- [ ] **程度副词 + 形容词** 模式：`slightly problematic` / `slightly disappointing` / `less than ideal` / `not perfect` / `only approximate`
- [ ] **否定副词 + 形容词** 模式：`negligible` / `immaterial` / `unimportant` / `minor deficit` / `not significant` / `not identical`
- [ ] **责任最小化** 模式：`as far as possible` / `inevitably` / `unavoidable` / `limited by` / `impossible` / `impractical`
- [ ] **客观归因** 模式：`it was difficult to` / `it was hard to` / `necessarily` / `problematic` / `unworkable`
- [ ] **承认困难 + 论证影响有限** 三段式（`Although X was difficult, Y was negligible`）
- [ ] 未来研究方向：`Future work should...`（建议方向，邀请社区）vs `Future work will...`（自己计划，区分使用）
- [ ] **不** 使用责任推卸（`we couldn't` / `we failed to` / `we didn't manage to`）
- [ ] **不** 使用自我贬低（`our method was bad` / `we were wrong`）
- [ ] **不** 隐瞒局限性（`no problem occurred` → 应 `minor problems were negligible`）

### 4.8 目的 / 理由表达规范

- [ ] 每个操作环节附目的或理由（`to ensure` / `in order to` / `to account for` / `so as to` / `with the aim of`）
- [ ] **不** 罗列操作而不给目的（`Participants were asked to fill out the survey. They were thanked.` → 应 `Participants were asked to fill out the survey to enable measurement of... They were debriefed to prevent...`）
- [ ] 目的状语开头使用 `To + 动词原形`（`To test our main hypotheses, we used...` / `To assess convergent validity, we...` / `To calculate the dependent measure, we...`）
- [ ] 多层释义递进界定（`deeper and more intimate than ... In other words ... For example ... These questions should require ...`）——操纵构念标准范式

### 4.9 操纵 / 测量描述的语体层级

- [ ] **抽象 → 具体** 两层结构：`We assessed gut reactions. Specifically, participants rated...`（先构念后操作）
- [ ] **目的 → 方法 → 结果** 三层结构：`Our intention was to obtain a global impression. Therefore, a global coding system adapted from... was used. Coders first watched...`
- [ ] **同行衔接**：`Similar to previous research (Das et al., 2009), participants were...` / `Following X et al., we...`
- [ ] **本题对比**：`Unlike previous studies, we...` / `In contrast to typical Lab-TAB coding, our approach...`

### 4.10 释义与术语解释

- [ ] 缩略语 / 术语首次出现用同位语解释（`paraphrases, that is, the definition for the 47 adjectives` / `event-contingent sampling (i.e., ...)`）
- [ ] 操纵构念用「in other words / that is / specifically / for example」三层递进解释
- [ ] 操作定义结构化（`核心 because ... + That is, ... + For example, ...`）
- [ ] 同位语解释（`Dehumanization, the blatant dehumanization of outgroup members, was assessed...`）

### 4.11 题项 / 操纵材料引用语体

- [ ] 题项原文引用使用引号（`"Rate your gut reactions towards environmental protection"`）
- [ ] 操纵材料引用使用第二人称（参与者视角）原文：`"Before the session begins, suppose you see the other person..."`
- [ ] 引用材料配上下文：`presented on the screen` / `displayed below the question` / `shown in Figure 1`
- [ ] 多题项以 `(a) / (b)` 编号并保持全文一致

### 4.12 「Specifically / In particular / In specific / Moreover / Furthermore / Additionally」等焦点信号词

- [ ] 「Specifically」先抽象后具体（`We measured X. Specifically, participants rated...`）
- [ ] 「In specific」同义但更正式（`In specific, we used per capita tax revenues...`）
- [ ] 「Moreover / Furthermore / Additionally」添加信息（`Moreover, the scale has been validated...`）
- [ ] 「In contrast / On the other hand」对比（`In contrast to typical X, our approach...`）

### 4.13 引用风格统一

- [ ] 引用紧贴被引用方法/结果（`using the Shapiro-Wilk test¹¹` 而非段末统一标注）
- [ ] 引用格式全文一致（`Smith et al. (2010)` vs `(Smith et al., 2010)`，全文统一）
- [ ] 自我引用位置规范（`we (Author, Year)` / `the present study` / `in this work` 三选一）
- [ ] 多文献引用顺序一致（按时间 / 按字母 / 按方法相关性，全文统一）

### 4.14 整体段落语气一致

- [ ] 全文语气为「研究者报告」第三人称客观（`Participants were asked...` / `We conducted...`），不混用「个人叙事」（`I think...` / `we felt...`）
- [ ] 段落开头避免悬念（`Interesting thing happened...` → 应 `Unexpectedly, ...` / `Notably, ...`）
- [ ] 句末避免弱化（`...kind of worked` → 应 `...produced the expected effect` / `...did not reach significance`）
- [ ] 全文不出现语气词（`well` / `actually` / `basically` / `essentially`（作语气词时））
