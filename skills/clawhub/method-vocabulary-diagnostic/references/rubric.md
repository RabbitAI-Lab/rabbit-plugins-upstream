# 心理学实证论文 Method 部分「词汇与学术用语维度」评分细则

> 配套清单：`checklist.md`（4 大部分 / 43 个子类 / 约 207 个具体检查点）
> 评分方式：**触发式扣分**——满分 100 分为起点，仅在论文中实际出现对应问题才扣分；所有扣分点与 `checklist.md` 的具体检查项一一对应，本细则**不新增任何独立于清单的扣分维度**。

---

## 评分总则

| 等级 | 单项扣分幅度 | 适用情形 |
|---|---|---|
| **严重（Major）** | **10–15 分** | 核心方法学术动词误用导致操作含义歧义；专业术语错误引发学术误解；介词/方向性搭配错误改变句子操作含义 |
| **中等（Moderate）** | **5–9 分** | 固定搭配不规范；用词口语化；术语前后不一致；引用/统计符号格式不统一 |
| **轻微（Minor）** | **1–4 分** | 个别用词可优化；词汇丰富度不足；引用/缩写/排版细节未达最佳实践 |

**触发原则**：
1. 同一条检查项在一篇 Method 中**多次出现**时，每出现一次独立扣分一次，但**同一段落内的同类型重复计入 1 次**。
2. **同一句子触犯多条扣分规则**时，按最高等级扣一次，不重复叠加。
3. 单个子类累计扣分达到该子类上限时封顶（见各子类末标注）。
4. **下限**：总分不得低于 0 分；若累计扣分超过 100 分，按 0 分计。
