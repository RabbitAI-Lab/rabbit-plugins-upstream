## Description:

Diagnoses vocabulary and academic-language issues in psychology Method sections, checking academic verbs, fixed expressions, terminology, and formal register while producing scores and top-journal examples.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wangjinhongmy-pixel](https://clawhub.ai/user/wangjinhongmy-pixel)

### License/Terms of Use:

MIT-0

## Use Case:

Researchers, students, editors, and academic-writing assistants use this skill to review psychology empirical-paper Method sections for vocabulary precision, fixed-expression usage, terminology consistency, and formal academic register.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill reviews user-provided Method-section text, which may contain unpublished research details or sensitive study information.

Mitigation: Review or redact sensitive study details before submitting text to an agent using this skill.

Risk: An optional Windows junction command references a local D:\method-skill-project directory that may not exist in a target environment.

Mitigation: Run that command only when intentionally maintaining the referenced local directory; otherwise use the packaged markdown references.
