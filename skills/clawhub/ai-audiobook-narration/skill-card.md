## Description:

Guides users from final manuscript or course text through narrator selection, a representative pilot, chapter-by-chapter narration, and ordered audio delivery.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Authors, course creators, and their agents use this skill to prepare and produce a consistent single-narrator audiobook from final text, starting with an approved sample before creating ordered chapter audio.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Persistent shared device authorization grants spending-capable and multimedia access beyond this audiobook workflow.

Mitigation: Approve only if comfortable with the granted scope, and review or revoke Beatra device authorization when finished.

Risk: Automatic updates are enabled by default and can replace local skill files without separate approval.

Mitigation: Disable automatic updates with the documented command if you prefer to review changes before installing them.

Risk: Narration requests and later corrections can consume credits.

Mitigation: Review current estimates and approve each paid segment or correction before submission.
