## Description:

Helps agents answer questions about Myers Park High School athletics schedules, teams, rosters, coaches, news, and broadcast links using public site information.

This skill is ready for commercial/non-commercial use.

## Use Case:

Students, families, and other interested users can ask an agent about Myers Park teams, fixtures, coaches, school sports news, and game broadcast links.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Public schedules and broadcast information may be stale or incomplete.

Mitigation: Check cancellation, postponement, and to-be-announced status; confirm time-sensitive details with the school or event source.

Risk: Missing scores or partial past-season coverage can be mistaken for losses or nonexistent games and teams.

Mitigation: Treat null scores as unknown, avoid inferring a result from partial scores, and state the coverage limits of historical searches.
