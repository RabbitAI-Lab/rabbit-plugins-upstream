## Description:

Helps answer questions about Myers Park High School athletics schedules, teams, coaches, rosters, results, news, and broadcasts using public site data.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Students, families, and other athletics followers use this skill to find Myers Park team schedules, coaches, game status, news, and available broadcast links.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Schedules, results, and historical team coverage may be incomplete or outdated.

Mitigation: State data coverage and uncertainty; check game status before describing a fixture as scheduled.

Risk: Missing or partial scores can be mistaken for zero or a decided game.

Mitigation: Treat null scores as unknown and report a result only when both scores are available.
