# 时空智能分析法 · 写作风格

> 4 种叙事节奏 + 严禁事项清单。

---

## 一、4 种叙事节奏

### 节奏 1：侦探型（Investigative）

**适用**：竞品分析、技术选型
**特征**：
- 开篇抛出一个悬念："X 真的比 Y 好吗？"
- 中间层层剥开证据
- 结尾给判断

**范例**：
```
"如果你只看官网，Cursor 看起来比 GitHub Copilot 强太多。
但我们拉了 12 个月的 commit 频率、issue 关闭率、社区活跃度，
发现了一个完全不同的故事——"
```

### 节奏 2：编年史型（Chronicle）

**适用**：公司史、技术演化史
**特征**：
- 时间线清晰
- 关键节点有"戏剧性转折"
- 决策逻辑有解释

**范例**：
```
"2023 年 1 月，Cursor 团队做了一个被外界认为'自杀'的决定：
砍掉免费版。
6 个月后，这个决定让他们的 ARR 从 $1M 涨到 $50M——"
```

### 节奏 3：生态位型（Ecosystem）

**适用**：横向对比、生态分析
**特征**：
- 把对象放在"地图"中
- 用位置而不是评分来评估
- 强调"它填补了什么空白"

**范例**：
```
"在 AI IDE 这个赛道上，
GitHub Copilot 是'补全派'，Cursor 是'对话派'，v0 是'原型派'——
它们不在同一个生态位，直接比没有意义——"
```

### 节奏 4：预言型（Prophetic）

**适用**：未来趋势预测
**特征**：
- 明确标注 confidence
- 给出关键转折点信号
- 不夸张、不悲观

**范例**：
```
"未来 3 年，AGI 时代的'人机协作语言'最可能是 X（60%，confidence 中）。
关键证据：[3 个独立来源]
触发条件：以下 2 个信号出现 → 概率升到 80%——"
```

## 二、5 大严禁事项

### 严禁 1：使用咨询公司套话

❌ "赋能""抓手""打造闭环""价值重构""底层逻辑""顶层设计"

✅ 改为具体名词和动词

### 严禁 2：写流水账

❌ "2020 年 A，2021 年 B，2022 年 C"

✅ 写成故事弧线（铺垫 → 转折 → 爆发 → 沉淀）

### 严禁 3：参数对照表的文字版

❌ "产品 A 价格 $9，功能 X；产品 B 价格 $19，功能 Y"

✅ 讲每个产品"活成了什么样"

### 严禁 4：用形容词代替细节

❌ "该产品非常成功，用户非常喜欢"

✅ 用具体数字："3 个月内从 0 到 50,000 付费用户，留存率 87%"

### 严禁 5：推测当成事实

❌ "该公司的护城河是 X"

✅ "我推测该公司的护城河可能是 X（confidence 中，依据：Y），但还需要更多数据验证"

## 三、3 类用户的阅读节奏

| 用户类型 | 阅读节奏 | 重点 |
|---------|---------|------|
| **决策者（老板/PM）** | 5 分钟扫读 | 结论 + 关键证据 |
| **研究者** | 30 分钟精读 | 数据 + 引用 + 方法论 |
| **写作者** | 2 小时深读 | 叙事节奏 + 故事弧线 |

时空智能分析法的标准报告需要**同时满足三类用户**：
- 开头 1 段：5 分钟可读懂结论
- 中间 4 段：30 分钟可读完关键论证
- 全文：2 小时可深读全部细节

---

## 四、5 个节奏转换技巧

1. **段落开头的"钩子"**：避免「首先」「其次」「最后」开头
2. **段尾的"悬念"**：每个段落结尾留一个"但..."或"问题是..."
3. **对话/引语**：插入具体的人说的话，让叙事更生动
4. **数字节奏**：避免一长串数字，分散在不同段落
5. **场景描写**：用具体场景代替抽象陈述

## 五、引用规范

| 来源类型 | 引用格式 |
|---------|---------|
| 学术论文 | 作者（年份），《标题》，期刊/会议 |
| 公司公告 | 公司名（日期），《标题》，URL |
| 媒体报道 | 记者（日期），《标题》，媒体名，URL |
| 用户口碑 | 平台名（日期），《帖子标题》，URL |

每个引用必须可点击、可验证。
