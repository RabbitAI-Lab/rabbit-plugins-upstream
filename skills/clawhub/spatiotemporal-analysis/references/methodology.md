# 时空智能分析法 · 方法论

> 时空智能分析法的 4 个核心约束 + 5 段叙事弧线模板。

---

## 一、4 个核心约束

### 1. 反快照谬误（Snapshot Fallacy）

**错误**：把研究对象当"现在的一个截面"。
**正确**：纵向要求至少 3-5 个历史节点；横向要求至少 3 个同期对比对象；交汇要求说明"现在"在"过去-未来"中的位置。

### 2. 反孤立谬误（Isolation Fallacy）

**错误**：把对象当孤立原子来分析。
**正确**：横向强制要求场景化（A 无竞品 / B 少量 / C 充分）；必须解释为什么没竞品（如果是 A）；必须解释替代方案是什么（如果是 A）。

### 3. 反罗列谬误（Enumeration Fallacy）

**错误**：把研究当成"列清单"。
**正确**：强制要求决策逻辑（为什么选 A 不选 B）；强制要求故事弧线（起承转合）；强制要求细节代替概括。

### 4. 反二元谬误（Dualism Fallacy）

**错误**：把判断分为好/坏、赢/输。
**正确**：交汇部分必须给"位置"而非"评价"；一个产品在某个生态位可能是赢家，换个生态位可能是输家。

## 二、5 段叙事弧线模板

每段必须包含：

### 段 1：起源追溯（Origin）

- **它诞生的背景是什么？** 基于什么技术/理念/需求而来？
- **创始团队或核心推动者是谁？** 当时的行业环境是什么样的？
- **叙事目的**：让读者知道"为什么会有这个东西"。

### 段 2：诞生节点（Birth）

- **明确的首次发布/成立/提出时间**
- **最初的形态和定位**
- **叙事目的**：给读者一个清晰的时间锚点。

### 段 3：演进历程（Evolution）

- 从诞生到现在，按时间顺序梳理所有关键节点
- 包括但不限于：重大版本更新、融资事件、团队变动、战略转型、技术架构变化、用户规模里程碑、重大合作或收购、公关危机或争议事件
- **叙事目的**：让读者看到"它是怎么走过来的"。

### 段 4：决策逻辑（Decisions）

- 在每个关键节点上，尽可能还原决策背后的原因
- 为什么选了 A 而不是 B？当时面对的约束条件是什么？
- **叙事目的**：让读者理解"为什么是这条路径，而不是另一条"。

### 段 5：叙事弧线（Arc）

- 不要写成干巴巴的年表
- 用故事的方式把发展史串起来，让读者能感受到因果关系和时代脉络
- **叙事目的**：让读者记住的不只是"它存在"，而是"它为什么走到今天"。

## 三、3 类对象的维度调整

| 对象类型 | 纵向重点 | 横向重点 |
|---------|---------|---------|
| **产品/工具** | 版本迭代 + 用户增长 + 商业化 | 同类工具对比 + 用户口碑 |
| **公司/组织** | 融资 + 团队 + 战略 | 竞品 + 替代方案 + 生态位 |
| **技术概念** | 学术演化 + 标准确立 + 工业落地 | 类似技术对比 + 协议栈位置 |
| **人物** | 职业轨迹 + 关键决策 | 同期人物对比 |

## 四、交汇分析 4 个子段

### 子段 1：纵向惯性（Longitudinal Inertia）

过去 5-10 年的演化路径揭示的"惯性"：
- 技术债务（locked-in 的技术栈）
- 组织惯性（路径依赖）
- 用户习惯（认知锁定）
- 资本惯性（投资人绑定的方向）

### 子段 2：横向位置（Cross-sectional Position）

当前在生态位中的相对位置：
- 是头部 / 中部 / 长尾？
- 填补了什么空白 / 在跟谁正面竞争？
- 议价能力如何？

### 子段 3：未来概率分布（Future Probability Distribution）

列出 3-5 个可能场景：

```
场景 1：[最可能发生]      概率 60%  confidence: 中
关键证据：...
触发条件：...

场景 2：[次可能]          概率 25%  confidence: 中
关键证据：...
触发条件：...

场景 3：[小概率]          概率 10%  confidence: 低
关键证据：...
触发条件：...
```

### 子段 4：关键转折点（Inflection Signals）

哪些信号出现，概率分布会变化：
- 监测指标 1：...
- 监测指标 2：...
- 监测指标 3：...

## 五、写作风格的 3 个反模式

### 反模式 1：流水账

```
2018 年发布 A 产品。
2019 年获得 B 轮融资。
2020 年收购 C 公司。
2021 年用户数突破 100 万。
```

**改为**：起承转合的故事。

### 反模式 2：参数对照表

```
| 特性 | 产品 A | 产品 B | 产品 C |
| ---- | ------ | ------ | ------ |
| 价格 | $9     | $19    | $29    |
```

**改为**：讲每个产品"活成了什么样"，用户选它的真实理由。

### 反模式 3：咨询公司式空话

```
"该产品通过深度赋能企业级用户，构建了完整的商业闭环，实现了全链路的价值重构。"
```

**改为**：具体细节和例子。

## 六、哲学根源（brief）

时空智能分析法不是"另一种报告模板"，它是任何严肃研究都必须满足的"三重约束合并"：

1. **像新闻特稿那样讲故事**（叙事驱动）
2. **像咨询报告那样做对比**（横向广度）
3. **像学术论文那样严格**（事实溯源、推测标注、时间锚点）

## 七、信息可靠性等级

| 等级 | 标准 | 例子 |
|------|------|------|
| **确认（confirmed）** | 2+ 独立一手来源 | 公司官网 + SEC 文件 |
| **报道（reported）** | 1 个一手 + 1 个二手 | 公司公告 + 主流媒体 |
| **推测（speculated）** | 仅二手或推论 | 行业分析 + LLM 推理 |

每个事实必须标注等级。推测段必须明确写「我推测」而非「事实是」。
