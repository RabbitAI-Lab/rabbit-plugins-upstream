# 常见问题

**没有题目，还能批改吗？**
可以先检查可读文字的字词、标点和表达；无法确认的切题与总体等级暂不判断。补充题目和要求后再完成整篇评价。

**粘贴文字，能生成原图批注吗？**
没有原图时只能给段落定位与原句订正，不能伪造批注照片。提供原图也需要可靠坐标与绘图能力。

**照片看得懂，为什么没有批注图？**
正文可读与坐标可靠是两件事。坐标不足或平台无法绘图时，AI 应说明原因并继续文字批改。严重模糊或缺页时需要补图，不能猜字或给整篇等级。

**孩子写得很朴素，会被换成很多成语吗？**
默认最小修改，保留合理口语、短句和个人表达；可选提升与明确错误分开，不把华丽词语当作评分指标，也不把整篇改成成人范文。

**老师帮孩子改了，能算已经掌握吗？**
只能说这份稿件的问题已改善。二稿复查会标明修改来源；是否能独立做到，需要孩子在不同情境中尝试。

**关闭档案，能导出本次报告吗？**
可以。本次批改报告是交付文件，成长档案是长期教学摘要，两者独立。关闭档案时不读历史、不写档案、不导入导出便携档案；仍可按要求导出本次报告。

**Word 生成失败怎么办？**
缺少 python-docx 时脚本自动生成 Markdown 并告诉你实际路径。其他生成错误会保留旧文件；没有执行能力则给可复制文本，不声称生成成功。A4 Word 可多页，不承诺把长作文的全部订正塞进一页。

**会自动记录孩子姓名或作文全文吗？**
不会自动建档。档案仅保存确认后的教学摘要，不存原图和全文。报告里引用原句是本次交付，不等于建立档案；使用平台本身如何保存上传内容须以该平台设置为准。

**能一次批改全班吗？**
本版以单篇为主。多人多页须拆分或先确认页面与学生的对应关系，再逐篇批改；尚未提供全班自动统计或讲评汇总功能。
