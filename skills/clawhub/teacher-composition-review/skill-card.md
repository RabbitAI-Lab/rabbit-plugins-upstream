## Description:

帮助小学三至六年级教师批改作文照片、文本或可读取的文档，提供批注、建议等级、学生评语、教师参考和订正练习。

This skill is ready for commercial/non-commercial use.

## Publisher:

[dm-kevin](https://clawhub.ai/user/dm-kevin)

### License/Terms of Use:

MIT-0

## Use Case:

小学三至六年级教师用它批改学生作文、复查订正稿，并按需制作可打印报告或管理学生成长档案。

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Student profiles contain sensitive educational information.

Mitigation: Enable profiles only with appropriate consent and a clear local storage location.

Risk: Deleting an individual review permanently removes that profile record.

Mitigation: Confirm the exact review ID before deletion.
