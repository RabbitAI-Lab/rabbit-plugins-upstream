# 常见作文类型及特有要求

先依据题目、写作要求和正文判断类型；类型不明确时请老师确认。所有类型仍按基础规范、语言、内容和结构四个维度评价，并加载对应年级锚点。

| 类型 | 识别重点 | 类型特有要求 | 常见提升方向 |
| --- | --- | --- | --- |
| 写人 | 以一个人物的特点、品质或关系为中心。 | 通过典型事例、语言、动作、神态或心理描写表现人物，避免只罗列评价词。 | 选择最能说明特点的事例，补足人物细节与真切感受。 |
| 记事 | 围绕一件或几件事情展开。 | 交代必要的时间、地点、人物和起因，写清经过与结果，突出重点情节。 | 按事情发展安排顺序，在关键处放慢笔墨，写出变化或感受。 |
| 写景 | 描写自然或生活场景。 | 明确观察顺序、景物特点和描写角度，避免只堆砌形容词。 | 选取有代表性的景物，调动感官，融入适当感受。 |
| 状物 | 介绍或描写具体物品、动植物等。 | 写清外形、习性、用途或特点，材料围绕主要特征组织。 | 由整体到局部或按观察顺序描写，补充与物的真实互动。 |
| 想象作文 | 基于题目、图画或设定展开合理想象。 | 想象要服务主题，人物、情节和规则应前后一致，不能脱离题目要求。 | 建立清楚设定，补足因果与细节，让想象有情感和逻辑。 |
| 读后感 | 以阅读内容引出个人理解。 | 简要概括原文，重点写“感”与联系实际，观点要由文本支撑。 | 减少复述，围绕一个感受选择文本依据和个人经历展开。 |
| 应用文 | 有明确交际对象和实际用途，如书信、日记、通知、倡议书、留言条。 | 格式、称谓、日期、署名、对象、事项和语气必须符合具体文种。 | 对照文种格式补全要素，做到信息准确、表达简明、语气得体。 |

## 应用文格式核查

- 书信：称呼、问候、正文、祝语、署名和日期齐全，语气符合对象。
- 日记：日期（必要时天气）、正文和真实记录要素清楚。
- 通知：标题、对象、事项、时间地点、发布者和日期完整明确。
- 倡议书：标题、称呼、倡议缘由、具体做法、号召、署名和日期齐全。
- 留言条：称呼、交代事项、署名和日期简洁完整。

若题目要求的文种与正文不一致，先指出类型偏差；等级判断时将其作为内容和结构的重要因素。
