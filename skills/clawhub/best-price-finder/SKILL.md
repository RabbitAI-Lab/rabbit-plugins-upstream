# Best Price Finder 全网最低价一键查询

一个命令完成「搜索 → 全平台比价 → 取优惠购买链接」，无需逐步调接口。

## 用法

在 skill 目录下执行（或用脚本的完整路径直接运行，无目录依赖）：

```bash
uv run scripts/best_price.py "商品关键词"                  # 默认输出最低价 Top 3
uv run scripts/best_price.py "关键词" --top 5             # 多看几名
uv run scripts/best_price.py "关键词" --json              # 机器可读的 JSON
uv run scripts/best_price.py "关键词" --source 2          # 限定平台：0全部 1淘宝/天猫 2京东 3拼多多 4苏宁 5唯品会 7抖音 8快手
uv run scripts/best_price.py "关键词" --must-contain 官方旗舰店   # 标题子串过滤杂音
```

- 依赖：`uv`（首次 `uv run` 自动装 aiohttp，稍慢属正常）。
- 脚本只读，不读写本地文件；无需 API key。

## 使用说明

- **关键词越具体越准**：品牌 + 型号 + 规格（如"米家前置过滤器Pro"而非"过滤器"）；结果含配件/相似款时用 `--must-contain` 过滤。
- **输出即结论**：表格已按券后价升序，第 1 行就是全平台最低价及其购买链接；回答用户时直接引用，并附平台/店铺。
- 接口限流：串行调用，短时间内不要对同一关键词反复查，建议间隔1秒。
- 取链失败时表格显示「（取链失败）」，重试一次即可。
- 由于使用了买手的查询接口，返回的链接可能包含返利红包的领取，如果介意可只作为价格参考。
