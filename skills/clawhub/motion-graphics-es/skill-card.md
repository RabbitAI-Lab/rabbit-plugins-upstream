## Description:

Skill de producción de motion graphics en español. Úsala cuando el usuario pida "hacer un motion graphic", "animar un logo", "tipografía cinética", "reel/short para redes", "explainer", "infografía animada", "lower third", "stinger", "cabecera", "video de producto", "presentación animada", o pregunte por brief, storyboard, animatic, ritmo, easing, safe areas, entregables o formatos (9:16, 16:9, 1:1, 4:5). Cubre el pipeline completo (brief → sistema → animatic → producción → sonido → QC → entrega), con valores por defecto de timing, escalas tipográficas, paletas y matrices de entrega por plataforma.

This skill is ready for commercial/non-commercial use.
