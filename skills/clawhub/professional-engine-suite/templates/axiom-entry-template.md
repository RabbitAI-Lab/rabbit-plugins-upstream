# 证据/定价/规则/公理/守护条目格式

## 医学·证据条目（附录F）
| 字段 | 内容 |
|------|------|
| 编号 | EV-{两位数字} |
| 证据类型 | {系统综述/RCT/队列/病例/指南} |
| 等级 | {I/II/III}（按 GRADE 核对） |
| 说明 | {来源与年份、偏倚要点} |

## 医学·公式条目（附录G）
| 字段 | 内容 |
|------|------|
| 编号 | MS-{两位数字} |
| 公式 | {表达式} |
| 前提/假设 | {模型假设、单位约定} |
| 来源 | {教材/指南} |

## 投资·定价与恒等式条目（附录H）
| 字段 | 内容 |
|------|------|
| 编号 | PR-{两位数字} / AC-{两位数字} |
| 关系 | {表达式} |
| 假设 | {无套利/无摩擦/计息约定等} |
| 置信级 | A |

## 法律·规则条目（附录I）
| 字段 | 内容 |
|------|------|
| 编号 | LR-{两位数字} |
| 规则 | {名称} |
| 内容 | {表述} |
| 适用边界 | {法域/情形；版本敏感须标注} |

## 工程·物理·普遍定律条目（附录B）
| 字段 | 内容 |
|------|------|
| 编号 | U{两位数字} |
| 定律名 | {名称} |
| 数学形式 | {核心式} |
| 适用边界 | {成立条件} |
| 置信级 | A |

## 工程·物理·领域本构条目（附录C）
| 字段 | 内容 |
|------|------|
| 编号 | L2-{领域}-{两位数字}（领域：力学/电学/热学/流体/材料/光学/化工/生物） |
| 关系式 | {式子} |
| 适用区间 | {实验/理论区间} |
| 置信级 | {B/C}（C 级必须标注"实验范围外不可外推"） |
| 来源 | {教材/实验/标准} |

## 工程·形式·推理规则条目（附录D）
| 字段 | 内容 |
|------|------|
| 编号 | F{两位数字} |
| 名称 | {规则/判据名} |
| 形式化表述 | {推导形式} |
| 适用边界 | {成立条件} |
| 置信级 | A |

## 工程·形式·本构与规约条目（附录E）
| 字段 | 内容 |
|------|------|
| 编号 | L2-{语言/结构/协议/实测}-{两位序号} |
| 内容 | {约定/不变量/经验} |
| 适用版本/区间 | {版本号或条件（版本敏感须标注）} |
| 置信级 | {B/C} |
| 来源 | {规范文档/实现/实测} |

## 守护清单条目
| 字段 | 内容 |
|------|------|
| 编号 | G-{系列代号}{序号}（医学：Med；投资：Inv；法律：Law；工程：M/E/T/O/B/F；共享：C） |
| 误区 | {错误做法} |
| 正确表述 | {正确做法} |
