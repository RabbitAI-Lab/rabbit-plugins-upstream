## PES8-医学·回验调度域范本

### 范本概述

对应 PES8 域全部任务（检验组织/打回修正/交付裁决）。适用场景：医学册交付前检验调度（状态：[草稿]，内容待专业复核）。

### 范本正文

**PES8-01 检验组织范本**

题目（接 PES5/PES7 范本）：证据评估交付前检验。

| 检验 | 结果 | 证据 |
|------|------|------|
| 统计与单位核验 | PASS | 敏感度/NNT 复算一致（脚本复算留痕） |
| 置信审计 | PASS（最终 II） | 最弱环节：间接性降级段 |
| 误区扫描（G-Med） | PASS | G-Med2/G-Med3 核对通过；G-Med5 验前概率来源已标注 |
| 双通道互证 | PASS（一致） | 公式通道×脚本通道结果一致 |

**PES8-02 打回修正范本**（示意）

- FAIL：G-Med2 核对时发现仅呈现 RR 未呈现 ARR
- 定位：PES5-01 效应量呈现（缺绝对效应）
- 修正：补 ARR 与 NNT；复检通过

**PES8-03 交付裁决范本**

- 终态：②低置信（证据等级 II，标注因间接性降级与人群边界）
- 交付物：按 templates/evidence-report-template.md 组装
- 声明：非诊疗建议随报告附上 ✓

### 结构要点标注

1. 五项检验缺一不可，证据可追溯
2. 打回定位"域+步骤"，不整体重来
3. 低置信态标证据等级与失效边界；声明随附
4. 【草稿】文件：内容待专业复核
