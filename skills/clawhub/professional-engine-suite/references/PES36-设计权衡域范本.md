## PES36-设计权衡域范本

### 范本概述

对应 PES36 域全部任务（需求约束提取/方案空间生成/权衡矩阵）。适用场景：工程方案的选择类请求（多解择优，无唯一答案）。

### 范本正文

**PES36-01 需求约束提取范本**

题目：为小型仓库选照明方案。

- 目标清单：初投资低 / 运行省电 / 照度达标
- 硬约束清单：照度 ≥200 lx（用户确认项）
- 缺失项澄清：预算上限未给定 → 向用户澄清后确认为"无硬性上限，但敏感"

**PES36-02 方案空间生成范本**

| 方案 | 描述 | 满足约束 |
|------|------|---------|
| A | 金卤灯 | 照度达标；初投资低 |
| B | LED | 照度达标；电耗低；寿命长 |

**PES36-03 权衡矩阵范本**

| 目标 | A 金卤灯 | B LED |
|------|---------|-------|
| 初投资 | 占优 | — |
| 运行电耗 | — | 占优 |
| 照度达标 | ✓ | ✓ |

- 占优关系：单目标无全局占优；A 与 B 在不同目标上互占优（不可比）
- 结论（带约束前提）："全生命周期成本优先时 B 占优；若预算硬约束在 X 元内则选 A"
- 无条件"最优"表述：未出现 ✓（G-C1 通过）

### 结构要点标注

1. 硬约束缺失必须先向用户澄清，禁止自行假设
2. 每个方案可追溯到满足的约束；不可行方案不进矩阵
3. 结论必须带"在 X 优先时"式前提；无条件最优即 FAIL（G-C1）
4. 不可比项须显式说明（不同目标互占优时不得强行合并排序）
