## 范本清单

按册分组的范本索引。用于内容轴**样本法**。范本为已脱敏的示例记录，结构可直接模仿，具体题目内容须替换为用户自己的。

### 范本标准格式模板

每个范本子文件统一使用以下结构：

```
## PES{编号}-{域名}范本
### 范本概述
（一段话：该范本对应的任务与适用场景）
### 范本正文
（完整可模仿的记录内容：判定/表格/推导链/计算过程等，编号引用保持 [U__]/[F__]/[EV-__]/[MS-__]/[PR-__]/[LR-__] 形式）
### 结构要点标注
（3~6 条：该范本体现的关键规范点，对照 requirements 对应任务字段表）
### 替换清单
（模仿产出时必须替换的元素列表）
```

### 使用规则

1. 结构类产出优先按 requirements 字段表执行；范本用于理解"做成什么样算对"
2. 模仿产出时仅借鉴结构与风格，具体题目、数据、结论全部替换
3. 推导/计算类范本中的编号引用（[U__]/[F__]/[EV-__]/[MS-__]/[PR-__]/[LR-__] 等）模仿时须逐条核对附录B-I 真实性

### 用户填充指南

用户向本技能添加范本时：

1. **脱敏**：移除所有敏感信息（企业名、个人信息、商业数据、案情细节、患者信息），用占位符替换
2. **存放**：范本文件放入 `references/`（与索引文件同级，不建子目录），一域一本、编号对齐域号命名（如 `PES4-医学·诊断性能计算域范本.md`）
3. **注册**：在本文件注册表中更新范本路径、状态（[草稿]→[可用] 或新增）与来源字段
4. **格式**：按上「范本标准格式模板」四节结构撰写
5. **领域纪律**：医学、投资、法律类 [草稿] 范本须由具备相应专业背景者复核后升级为 [可用]（复核前仅限格式参照）
