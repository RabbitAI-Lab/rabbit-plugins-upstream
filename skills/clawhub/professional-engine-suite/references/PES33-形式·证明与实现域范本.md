### 范本正文

**PES33-01 标注证明范本**

题目（接 PES32 范本）：二分查找正确性。

证明链（每步标注引用）：
1. 初始化：lo=0, hi=n−1 ⟹ 区间包含性成立（target∈arr ⟹ target∈arr[lo..hi+1]）　[F05 初始化]
2. 保持：若 arr[mid]<target，则 target∈arr[mid+1..hi+1]（升序）⟹ 新区间仍含 target　[F01+升序性质]
3. 循环退出：lo>hi 时不变量给出 target∉arr　[F05 退出]
4. 终止性：每轮 hi−lo 至少减 1 且下有界 ⟹ 有限轮终止　[F02 归纳]
5. 复杂度：T(n)=T(n/2)+O(1) ⟹ T(n)=O(log n)　[F08 主定理情形2]

**PES33-02 实现与测试范本**

实现（依规约，节选）：
```python
def bsearch(arr, target):
    lo, hi = 0, len(arr) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if arr[mid] == target: return mid
        if arr[mid] < target: lo = mid + 1
        else: hi = mid - 1
    return -1
```
测试用例集：空数组 / 单元素（命中与未命中）/ 重复元素 / 首尾元素 / 目标不存在——边界条件全覆盖 ✓
