## PES9-医学·质检守护域范本

### 范本概述

对应 PES9 域全部任务（统计单位核验/误区扫描/双通道互证）。适用场景：对已有证据评估做质检（状态：[草稿]，内容待专业复核）。

### 范本正文

**PES9-01 统计与单位核验范本**

- 敏感度复算：TP/(TP+FN) = 90/(90+10) = 90% ✓（与报告一致）
- 效应量复算：ARR = 12%−8% = 4%；NNT = 25 ✓
- 剂量复算：5 mg/kg × 80 kg = 400 mg，封顶核对通过 ✓（脚本 dose_calc 复算一致）
- 单位核对：mg→mcg 换算逐项通过（G-Med9）✓

**PES9-02 误区扫描范本**（逐条留痕）

| 误区项 | 核对 | 结论 |
|--------|------|------|
| G-Med1 敏感度≠PPV | PPV 表述未误用 | ✓ |
| G-Med2 相对≠绝对 | ARR+NNT 已呈现 | ✓ |
| G-Med3 唯 p 值 | CI 与临床意义已结合 | ✓ |
| G-Med4 生存中位数 | 本题无生存数据 | 不适用 |
| G-Med5 群体外推 | 验前概率来源已标注 | ✓ |
| G-Med10 超说明书 | 无相关表述 | ✓ |

**PES9-03 双通道互证范本**

- 公式通道：手算 ARR/NNT；数值通道：脚本复算
- 结果一致（偏差 0）✓；通道独立说明：脚本未复用报告中间值

### 结构要点标注

1. 逐项复算留痕；不符即 FAIL
2. 误区逐条扫描，命中即 FAIL 不豁免
3. 双通道独立，不一致即打回
4. 【草稿】文件：内容待专业复核
