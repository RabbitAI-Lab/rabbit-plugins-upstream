## PES34-形式·回验调度域范本

### 范本概述

对应 PES34 域全部任务（检验组织/打回修正/交付裁决）。适用场景：交付前的形式检验调度与终态裁定。

### 范本正文

**PES34-01 检验组织范本**

题目（接 PES33 范本）：二分查找正确性证明与实现的交付前检验。

| 检验 | 结果 | 证据 |
|------|------|------|
| 签名与引用校验 | PASS | signature_check：接口与规约一致；[F05]/[F02]/[F08] 引用合法 |
| 置信审计 | PASS（最终 A） | confidence_propagate：全链 A 段（无规约/启发式段） |
| 缺陷模式扫描 | PASS | G-F1 边界条件：测试含空数组/首尾/重复 ✓；G-F3 不变量已声明 ✓ |
| 反例搜索 | PASS | 穷举 3×10⁴ 组合无反例（范围有限声明已附） |
| 双通道互证 | PASS（一致） | 证明通道（归纳）与测试通道（代码+穷举）结论一致 |

**PES34-02 打回修正范本**（示意）

- FAIL 项：G-F1 边界扫描发现"空数组未覆盖"
- 定位：PES33-02 测试用例集（缺空数组用例）
- 修正：补空数组测试；复检：通过

**PES34-03 交付裁决范本**

- 终态裁定：①可证/可测（A 级——证明链完整）
- 交付物：按 templates/proof-record-template.md 组装（规约→不变量→证明链→实现与测试→双通道验证→终态）

### 结构要点标注

1. 五项检验缺一不可，证据可追溯
2. 打回定位到"域+步骤"；禁止整体重来
3. 终态三分明确；②态标注失效边界；③态走拒答模板
4. 禁止把"测试通过"表述为"已证明"（置信分级纪律）

### 替换清单

- 被检验的证明/实现
- FAIL 定位与修正（如适用）
- 终态裁定
