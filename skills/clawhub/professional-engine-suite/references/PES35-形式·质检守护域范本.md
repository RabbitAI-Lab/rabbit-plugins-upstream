## PES35-形式·质检守护域范本

### 范本概述

对应 PES35 域全部任务（签名与引用校验/置信审计与缺陷扫描/双通道互证）。适用场景：对已有证明记录做质检，或作为临时入口独立校验历史产物。

### 范本正文

**PES35-01 签名与引用校验范本**

- signature_check.py：接口签名与规约后条件逐条核对——`def bsearch(arr: list[int], target: int) -> int` 与规约一致 ✓
- 引用校验：`[F05] [F02] [F08]` 均在附录D 在册；规约条款引用均存在 ✓

**PES35-02 置信审计与缺陷扫描范本**

- confidence_propagate.py：输入 `A A A A` → `最终置信: A（定理级）`
- 缺陷模式扫描（逐条留痕）：
  - G-F1 边界条件 ✓（空/首尾/重复已覆盖）
  - G-F3 循环不变量已声明且被轨迹校验 ✓
  - G-F6 复杂度误判核对：T(n)=T(n/2)+O(1) 已计入比较与索引运算 ✓
  - 其余项：不适用/通过（逐条记录）

**PES35-03 双通道互证范本**

- 双通道定义：证明通道（归纳+[F05]）× 测试通道（实现+穷举反例搜索）
- 双通道结果：证明断言"任意有限升序数组成立"；测试覆盖 3×10⁴ 组合无反例 → 一致 ✓
- 独立性命明：测试通道未复用证明中间结论（独立执行实现）

### 结构要点标注

1. 工具优先；工具不可用时人工检验并标注"人工检验"
2. 缺陷扫描逐条留痕，命中即 FAIL 不得豁免
3. 双通道必须独立（同一实现重复运行不算）；不一致即打回
4. 置信结论与通道证据一致（测试不得越级宣称证明）
