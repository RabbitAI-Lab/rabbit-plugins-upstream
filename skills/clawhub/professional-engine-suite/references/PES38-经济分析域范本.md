## PES38-经济分析域范本

### 范本概述

对应 PES38 域全部任务（成本区间估算/敏感性分析/假设清单编制）。适用场景：工程经济性估算类请求（投资、回收期、造价量级）。

### 范本正文

**PES38-01 成本区间估算范本**

题目：B 方案（LED 改造）投资回收期估算。

- 初投资：区间 [2.8万, 3.6万]（估算方法：指标法，按同规模项目指标）
- 年节电收益：区间 [0.9万, 1.3万]
- 回收期：区间 [2.2, 4.0] 年

**PES38-02 敏感性分析范本**

| 排序 | 敏感变量 | 弹性（变量变动 10% → 结果变动） |
|------|---------|--------------------------------|
| 1 | 电价 | ±9% |
| 2 | 年使用时长 | ±6% |
| 3 | 灯具实际单价 | ±4% |

**PES38-03 假设清单范本**

1. 电价 0.8 元/度（某地工商业电价，基准时点：{年月}）
2. 每天使用 10 h
3. 无政府补贴
4. 灯具实际寿命按厂家标称值下线取值

- 三要素核对（G-C3）：区间 ✓ + 敏感性 ✓ + 假设清单 ✓ → 通过

### 结构要点标注

1. 输出必须为区间，禁止无区间点值（G-C3）
2. 估算方法必须标注（指标法/类比法/清单法）
3. 敏感性量化到弹性排序（前 3 项）；假设清单随结果交付，禁止隐藏
4. 假设须含价格基准时点、地区等时空锚点

### 替换清单

- 项目与成本科目
- 区间数值与估算方法
- 敏感变量与假设条目
