## 任务清单与依赖拓扑

按四册五引擎组织的专业推理任务清单，附任务间关系和元操作映射提示。册布局（按逻辑序）：PES1-PES9 医学册（护人身）、PES10-PES17 投资册（护财产）、PES18-PES22 法律册（裁断二者）、PES23-PES35 工程册（物理+形式两引擎，扛二者之群体长期风险）、PES36-PES38 共享决策域，PES0 总判定门。**册数为收敛终局（不增设新册）**：四册按内核判据互斥且穷尽，四个高代价对象已完整覆盖，结构保持稳定。

**域间逻辑流**：PES0（总判定门：先判册再判册内引擎/道）→ 医学册 PES1→PES9 / 投资册 PES10→PES17 / 法律册 PES18→PES22 / 工程册 PES23→PES35（各册内质检守护、打回迭代）；共享决策域 PES36/PES37/PES38 由 PES0 分流后各自闭环；跨册问题多册扇出→各册回验→汇总。

### 依赖拓扑摘要

以下为四册五引擎任务的主要依赖链路，执行框架可据此自动编排管线：

#### 一、域内链路

**册路由链路**：PES0-01 → PES0-02 / PES0-03
**医学链路**：PES1-01 → PES2-01 → PES2-02 → PES2-03 → PES3-01 → PES3-02 / PES3-03 → PES4 系列 / PES5 系列 / PES6 系列 → PES7-01 → PES7-02 → PES7-03 → PES8-01 → PES9-01 ‖ PES9-02 ‖ PES9-03
**投资链路**：PES10-01 → PES11-01 → PES11-03 → PES12 系列 → PES13 系列 / PES14 系列 / PES15 系列 → PES16-01 → PES17-01 ‖ PES17-02 ‖ PES17-03
**法律链路**：PES18-01 → PES18-02 → PES19-01 → PES19-02 / PES19-03 → PES20 系列 → PES21 系列 → PES22-01 → PES22-02 / PES22-03
**工程路由链路**：PES23-01 → PES23-02 / PES23-03
**物理链路**：PES24-01 → … → PES27-04 → PES28-01 → PES29-01 ‖ PES29-02 ‖ PES29-03（缺方程/打回 ↻ 对应域）
**形式链路**：PES30-01 → … → PES33-04 → PES34-01 → PES35-01 ‖ PES35-02 ‖ PES35-03（缺不变量/打回 ↻ 对应域）
**共享决策链路**：PES36 / PES37 / PES38 各自入口任务 → 末端任务

#### 二、跨域协同链路

**医学主管线**（P2 迭代精炼嵌套）：PES0-01 → PES1-01 → … → PES8-01 → PES9 三项 ⇇ 扇入 → PES8-02（FAIL ↻）→ PES8-03
**投资主管线**：PES0-01 → PES10-01 → … → PES16-01 → PES17 三项 ⇇ 扇入 → PES16-02（FAIL ↻）→ PES16-03
**法律主管线**：PES0-01 → PES18-01 → … → PES22-01 ⇇ 多项扇入 → PES22-02 / PES22-03
**工程主管线**：PES0-01 → PES23-01 → PES24-01 → … → PES28-01 → PES29 三项 ⇇ 扇入 → PES28-02（FAIL ↻）→ PES28-03；形式侧同理经 PES34/PES35
**跨册管线**（P3 并行汇聚）：PES0-01 → PES0-02 ⇉ 各册子管线 ‖ → 各册回验 → 交接量一致性核对（损害事实/责任比例/损失金额）→ 汇总交付
**决策域协同**：任一册任务可经 PES0 分流至 PES36/41/42；各册附录为决策域提供领域内容（医学 F/G、投资 H、法律 I、工程 C/E）
**质检互斥链路**：五组检验集（医学/投资/法律/物理/形式）互不套用（册级串道检测）

#### 三、入口说明

标准入口为 PES0-01。各册经 PES0-01 分流后以其入口任务进入（PES1-01 / PES10-01 / PES18-01 / PES23-01）；校验已有记录场景下，各册质检域可临时入口（PES9 / PES17 / PES22 / PES29 / PES35）；知识库条目核对场景下，PES3-01 / PES12-01 / PES19-01 / PES25-01 / PES31-01 等可临时入口。该多入口约定仅在执行层生效，catalog 依赖字段保持标准链路定义。

#### 四、知识图谱

**实体节点类型**：任务节点 PES0-01~PES38-03（122 个）；域节点 39 个；册节点（医学/投资/法律/工程/共享决策）；引擎节点（循证/定价/规则/物理/形式）；元操作节点 S/C/A/O/I/G；编号体系节点（EV-* / MS-* / PR-* / AC-* / LR-* / U01-U22 / L2-* / F01-F16）；守护项节点（G-Med、G-Inv、G-Law、G-M/E/T/O/B、G-F、G-C）；终态节点（①成功/②低置信/③拒答）。

**关系边类型**：依赖边（→）、并行边（‖）、扇入边（⇇）、条件边（?，册/引擎/道分流）、迭代边（↻，打回修正/回补）、产出边（任务→推导记录/证明记录/证据评估/估值报告/规则适用报告/拒答报告）、校验边（各册质检对链路的守护关系）、互证边（双通道独立验证）、跨册边（PES0-02 分解与交接量核对）。

**推理能力**：由问题特征判定册与域路径（如"诊断敏感度"→医学册 PES4 全链）；由检验 FAIL 项定位所属域并给出修正路径；由依赖边识别可并行组合（如 PES37 与各册主管线并行）；由守护项节点反查各册易错环节；由跨册边识别高代价场景的多册分解方案。

更多组合根据具体任务动态推导。
