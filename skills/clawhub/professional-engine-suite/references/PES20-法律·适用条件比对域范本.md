## PES20-法律·适用条件比对域范本

### 范本概述

对应 PES20 域全部任务（要件事实比对/管辖核对/时效计算）。适用场景：法条要件与事实的逐项比对，及管辖与时效的规则计算。

### 范本正文

**PES20-01 要件事实比对范本**

题目：用户主张对方逾期交货构成违约（管辖与时效另列）。
- 要件拆解（示例格式）：①有效合同存在 ②履行期限届满 ③未按期履行 ④无免责事由
- 比对表：

| 构成要件 | 对应事实（用户陈述） | 状态 |
|---------|-------------------|------|
| 有效合同 | 2025-03 签约（合同扫描件用户已提供） | 表面满足 |
| 期限届满 | 约定 2025-06 交货 | 满足 |
| 未按期履行 | 至今未交货 | 待证（对方可能主张部分履行） |
| 无免责事由 | 未提及不可抗力 | 待核 |

- 缺口标记：要件③④标注"待证/待核"；举证责任分配提示（[LR-04]：主张违约方对违约事实举证）

**PES20-02 管辖核对范本**

- 管辖规则定位：合同纠纷管辖条款（+协议管辖条款），均带版本标注
- 要素比对：约定管辖"合同签订地"；签订地证据缺失 → 标注"待核"；备选法定管辖分析已列
- 结论表述：管辖核对结果（规则层面），不含"哪个法院更有利"类判断 ✓

**PES20-03 时效计算范本**

- 起算点：权利人知道或应当知道权利受损及义务人之日（[LR-02]）；本案用户 2025-06-30 明确知悉未交货
- 期间：一般诉讼时效三年（**须核现行法版本——已标注待核**）
- 计算：2025-06-30 起算 → 2028-06-30 届满（工具脚本 limitation_calc.py 复算一致 ✓）
- 中断/中止核对：未提及催告/起诉情形 → 标注"如期间有催告请告知，将影响计算"
- 输出附"非法律意见"声明 ✓

### 结构要点标注

1. 要件逐项比对；"待证/待核"不得省略（G-Law6/7）
2. 举证责任分配引用 [LR-04]
3. 时效起算点基于条文明确；期间须核版本（G-Law1）；中断中止逐项核对（G-Law4）
4. 管辖与时效结论均为规则陈述，不含有利性判断（G-Law8）
