## PES14-投资·无套利推演域范本

### 范本概述

对应 PES14 域全部任务（远期定价/期权平价/Black-Scholes 推导链）。适用场景：无套利定价——投资册的公理级部分，推导链必须可复现。

### 范本正文

**PES14-01 远期定价范本**

题目：无分红股票现价 100 元，无风险利率 4%（连续复利），期限 1 年。求远期理论价。
- 推导：F = S·e^(rT) = 100×e^(0.04×1) = 104.08 元　[PR-04]
- 无套利论证：若 F>104.08，卖远期+借钱买现货套利；若 F<104.08，反向套利——两方向均排除
- 假设声明：无摩擦、可无限制借贷、无分红（已声明）

**PES14-02 期权平价范本**

题目：同标的、同期限（1 年）、行权价 100 元，看涨 8 元，求看跌理论价。
- 平价关系：C−P = S−K·e^(−rT)　[PR-05]
- 8−P = 100−100×e^(−0.04) → P = 8−100+96.08 = 4.08 元
- 套利组合显式：买入看涨+卖出看跌 = 合成远期多头（组合构造步骤已列）
- 与市场价偏差讨论：仅作关系校验，不含方向预测 ✓

**PES14-03 Black-Scholes 推导链范本**（分段摘要）

1. 假设声明：几何布朗运动、无摩擦、连续对冲、无分红（假设清单强制 ✓）
2. 组合构造：期权 + Δ 份标的（Δ 待定），使瞬时无风险　[PR-05 系]
3. 无套利 ⟹ 组合收益=无风险利率 ⟹ 导出 BS 偏微分方程：∂V/∂t + ½σ²S²∂²V/∂S² + rS∂V/∂S − rV = 0
4. 边界条件代入 → 解析解：C = S·N(d₁) − K·e^(−rT)·N(d₂)
5. 每段标注引用与假设编号；希腊值定义附注

### 结构要点标注

1. 无套利论证必须给出双向套利组合（可复现）
2. 推导链分段标注引用；假设清单强制（连续对冲等）
3. 与市场价讨论仅限关系校验，禁止预测性表述
4. 参数单位与复利约定与 PES11-02 一致
