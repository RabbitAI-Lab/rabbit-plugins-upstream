### 范本正文

**PES27-01 公理标注推导 + PES27-02 方程求解范本**

题目（接 PES25 范本）：求 a 与 T。

推导链（每步标注编号）：
1. T = m₁a　[U07]
2. m₂g − T = m₂a　[U07]
3. 两式相加消 T：m₂g = (m₁+m₂)a　[代数]
4. a = m₂g/(m₁+m₂) = 2×9.8/5 = 3.92 m/s²　[数值代入，单位 m/s²]
5. T = m₁a = 3×3.92 = 11.76 N　[步骤1回代]

**PES27-04 量纲自检范本**（逐量内嵌）

- 步骤3：两边 kg·m/s² → N ✓
- 步骤4：[kg·m/s²]/[kg] = m/s² ✓
- 步骤5：[kg]×[m/s²] = N ✓

**PES27-03 数值通道范本**（示意）

- 调用：scripts/numeric_solver.py（RK4，h=0.05）
- 误差来源：截断误差 O(h⁴)；控制参数：步长 0.05（对照 0.025）
- 步长减半对照：末态差值 <1e-6 → 通过
