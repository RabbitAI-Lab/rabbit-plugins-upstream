## Description:

Activates top-level agent control for goal understanding, hierarchical planning, state tracking, multi-plugin orchestration, verification, recovery, reflection, and completion control.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agent users use this skill to apply structured top-level control to complex OpenClaw tasks that need planning, state tracking, tool or plugin orchestration, verification, recovery, and completion checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill has broad agent-planning guidance that may influence top-level task behavior more often than intended.

Mitigation: Review the activation wording before deployment if narrower use is required.

Risk: Complex agent-control guidance can encourage multi-step execution where mistakes are harder to notice.

Mitigation: Keep milestone verification, recovery limits, and final completion checks active for complex or high-impact tasks.
