## Known Risks and Mitigations:

Risk: Generic trigger terms such as nano, banana, pro, generate, edit, images, gemini, and bug fix may cause the skill to activate too often.

Mitigation: Narrow the trigger set or disable implicit invocation in busy skill environments, then review activation behavior before publishing.

Risk: The skill may produce workflow, code, command, or configuration guidance that needs context-specific review before use.

Mitigation: Review outputs against the user's stated constraints and validate any commands, code changes, or configuration snippets before applying them.
