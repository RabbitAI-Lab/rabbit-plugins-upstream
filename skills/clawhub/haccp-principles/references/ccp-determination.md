| 问题 | 判断内容 | 是 | 否 |
|------|----------|----|----|

| Q4 | 本步骤能否专门预防/消除/将该危害降至可接受水平？ | 本步骤为CCP | 需调整工艺或产品 |

### 判断要点

#### Q1：前提方案能否控制？

**前提方案包括：**
- 良好卫生规范（操作人员卫生、清洁消毒、环境卫生）
- 良好生产规范（厂房设计、设备维护、原料管理）
- 培训、可追溯性等其他规范和程序

**判定标准：** 仅当通过前提方案就能将危害控制在可接受水平时，才回答"是"

#### Q2：本步骤是否有特定控制措施？

**特定控制措施特征：**
- 有明确的控制参数（温度、时间、pH等）
- 能够专门针对该危害进行控制
- 不是泛指的一般性操作

**示例：**
- 烘烤步骤的"加热至75℃以上"是特定控制措施
- 单纯的"按工艺要求操作"不是特定控制措施

#### Q3：后续步骤能否控制？

**评估后续步骤时考虑：**
- 该危害是否会在后续步骤中被消除或降低
- 后续步骤是否有明确的控制措施
- 消费者食用前是否还有加热等处理

#### Q4：本步骤能否专门控制？

**"专门控制"含义：**
- 该步骤的控制措施是针对该危害的主要控制手段
- 不是辅助性或补救性的控制
- 缺少该步骤控制，该危害将无法接受

## CCP编号规则

| 编号格式 | 含义 |
|----------|------|
| CCP1, CCP2... | 按流程顺序编号 |
| 或按危害类型编号 | 如 CCP-B1（生物性危害第1个CCP） |

## 填写示例

| 流程步骤 | 显著危害 | Q1 | Q2 | Q3 | Q4 | 结论 | CCP编号 |
|----------|----------|----|----|----|----|------|----------|
| 原料接收 | 微生物污染 | 否 | 是 | 是 | - | 后续为CCP | - |
| 原料储存 | 微生物繁殖 | 是 | - | - | - | 非CCP | - |
| 蒸煮 | 致病菌残留 | 否 | 是 | 否 | 是 | 本步骤为CCP | CCP1 |
| 冷却 | 致病菌繁殖 | 否 | 是 | 是 | - | 后续为CCP | - |
| 冷却后工序 | 二次污染 | 否 | 是 | 否 | 是 | 本步骤为CCP | CCP2 |

---

## 注意事项

- CCP确定仅针对显著危害，非显著危害由前提方案控制
- 一个CCP可控制多个显著危害
- 一个显著危害可能需要多个CCP控制
- 当无法找到合适的CCP时，需要调整产品或工艺
- CCP确定后应在流程图上标注位置
