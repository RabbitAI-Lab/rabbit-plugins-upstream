# 危害分析工作表模板

## 概述

危害分析工作表是HACCP计划的核心文档，用于系统识别和评估食品生产过程中各步骤的潜在危害，确定显著危害，并为每个显著危害制定控制措施。

## 模板结构

### 表头信息

| 项目 | 内容 |
|------|------|
| 企业名称 | （填写企业全称） |
| 产品名称 | （填写产品名称） |
| 版本号 | （如V1.0） |
| 编制日期 | （YYYY-MM-DD） |

### 危害分析表

| 序号 | 生产步骤 | 本步骤引入/控制的潜在危害 | 危害类型 | 是否为显著危害 | 判定依据 | 控制措施 |
|------|----------|---------------------------|----------|----------------|----------|----------|
|      |          |                           | B/C/P    | 是/否          |          |          |

**字段说明：**

| 字段 | 填写要求 |
|------|----------|
| 生产步骤 | 按工艺流程图顺序填写，从原料接收到最后成品 |
| 潜在危害 | 明确描述具体危害，如沙门氏菌、农药残留、金属碎片 |
| 危害类型 | B=生物性；C=化学性；P=物理性 |
| 显著危害判定 | 综合考虑：发生可能性、严重性、可接受水平、设备性能、预期用途 |
| 控制措施 | 针对显著危害的具体控制措施，可一项控多危害或多措施控一危害 |

## 危害分类参考

### 生物性危害（B）

| 类别 | 示例 |
|------|------|
| 细菌 | 沙门氏菌、大肠杆菌O157、金黄色葡萄球菌、单增李斯特菌、肉毒梭状芽孢杆菌 |
| 病毒 | 诺如病毒、甲型肝炎病毒 |
| 寄生虫 | 旋毛虫、广州管圆线虫、弓形虫 |

### 化学性危害（C）

| 类别 | 示例 |
|------|------|
| 天然毒素 | 黄曲霉毒素、麻痹性贝类毒素 |
| 农兽药残留 | 有机磷农药、氯霉素、瘦肉精 |
| 添加剂滥用 | 亚硝酸盐超标、甜蜜素超标 |
| 金属污染 | 铅、砷、汞、镉 |
| 清洁剂残留 | 消毒剂、清洗剂 |

### 物理性危害（P）

| 类别 | 示例 |
|------|------|
| 金属异物 | 铁屑、不锈钢碎片 |
| 非金属异物 | 玻璃碎片、塑料碎片、头发 |
| 其他 | 骨头碎片、石头、昆虫 |

## 显著危害判定考量因素

1. **发生可能性**：该危害在生产过程中出现的概率
2. **严重性**：对消费者健康造成的影响程度
3. **可接受水平**：法规标准或客户要求的最高允许水平
4. **设备性能**：现有设备能否有效控制该危害
5. **致病菌存活/繁殖**：加工条件是否适合致病菌存活或繁殖
6. **预期用途**：是否针对易感人群
7. **后续控制**：后续步骤能否消除或降低该危害

## 填写示例

| 序号 | 生产步骤 | 潜在危害 | 类型 | 显著危害 | 判定依据 | 控制措施 |
|------|----------|----------|------|----------|----------|----------|
| 1 | 原料接收 | 大肠杆菌超标 | B | 是 | 原料可能携带致病菌，高风险 | 供应商审核、原料检验、低温储存 |
| 2 | 原料储存 | 霉菌生长 | B | 否 | 低温储存可有效控制 | 前提方案（良好卫生规范） |
| 3 | 蒸煮 | 沙门氏菌残留 | B | 是 | 蒸煮不充分可导致致病菌存活 | 关键限值：中心温度≥75℃/1min |
| 4 | 金属探测 | 金属异物 | P | 是 | 金属异物可能造成消费者伤害 | 金属探测器检测 |

## 注意事项

- 每个生产步骤单独一行，便于追溯
- 潜在危害应具体到危害名称，不要笼统填写
- 显著危害判定需有明确理由
- 控制措施应与后续CCP确定相衔接
- 表格填写完成后需HACCP小组审核确认
