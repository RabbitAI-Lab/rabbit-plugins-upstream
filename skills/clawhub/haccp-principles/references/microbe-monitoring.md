# 食品生产过程微生物监控程序指南

## 概述

微生物监控程序是HACCP体系的补充工具，用于确保食品安全、验证控制程序有效性、改进质量体系。本指南依据GB 14881-2025附录B制定。

## 监控类型

### 环境监控

监控食品生产环境中可能存在的微生物污染源，评估卫生状况。

| 监控对象 | 监控项目 | 目的 |
|----------|----------|------|
| 食品接触表面 | 手部、工作服、传送带、工器具、设备表面 | 评估直接污染风险 |
| 邻近接触表面 | 设备外表面、支架、控制面板、零件车 | 评估环境污染风险 |
| 环境空气 | 靠近裸露产品位置 | 评估空气污染风险 |
| 非食品接触表面 | 墙壁、转运工具、地漏、洗手池、工具、鞋底 | 评估整体卫生状况 |

### 过程产品监控

监控生产过程中产品微生物水平变化，评估过程控制能力。

| 监控对象 | 示例 | 目的 |
|----------|------|------|
| 原料 | 接收的原料 | 评估原料初始污染水平 |
| 半成品 | 关键工序后的产品 | 评估工序控制效果 |
| 未包装成品 | 出厂前未包装产品 | 评估最终产品安全 |

---

## 监控指标

### 指示微生物

用于评估卫生状况和过程控制能力：

| 指标 | 意义 |
|------|------|
| 菌落总数 | 总体卫生状况 |
| 大肠菌群/肠杆菌科/大肠杆菌 | 粪便污染指示 |
| 酵母霉菌 | 霉菌污染状况 |

### 致病菌（必要时）

根据产品特性和风险评估确定：

- 金黄色葡萄球菌
- 单增李斯特菌
- 沙门氏菌
- 大肠杆菌O157
- 副溶血性弧菌

## 监控频率设定

### 风险分级

| 风险等级 | 描述 | 建议频率 |
|----------|------|----------|
| 高风险 | 高温产品、直接入口、即食产品 | 每周1-2次 |
| 中风险 | 低温保存、需加热食用 | 每两周1次 |
| 低风险 | 需彻底加热后食用 | 每月1次 |

### 动态调整

| 情况 | 调整方式 |
|------|----------|
| 监控结果偏高 | 加密监控频率 |
| 厂房施工或改造后 | 加密监控频率 |
| 清洁消毒效果下降 | 加密监控频率 |
| 连续多次合格 | 可适当放宽频率 |

## 取样方法

### 涂抹法（环境表面）

**标准涂抹面积：** 10cm x 10cm（100cm²）或使用标准涂抹棉签

**操作步骤：**
1. 佩戴无菌手套
2. 取无菌棉签，用采样液润湿
3. 均匀涂抹规定面积
4. 将棉签放入采样管
5. 标识送检

### 沉降法（空气监控）

**操作步骤：**
1. 打开平皿盖
2. 暴露于规定位置和时间（通常15-30分钟）
3. 盖上平皿盖
4. 标识送检

### 直接取样法（过程产品）

**操作步骤：**
1. 使用无菌取样器
2. 按规定量取样
3. 放入无菌容器
4. 标识送检

## 限值设定原则

### 依据来源

1. 国家标准（GB 29921、GB 2762、GB 2763等）
2. 行业标准或团体标准
3. 企业内控标准（严于国家标准）
4. 客户要求

### 警戒限与行动限

| 限值类型 | 含义 | 处理措施 |
|----------|------|----------|
| 警戒限 | 接近不合格水平 | 加强监控、排查原因 |
| 行动限（不合格） | 超过即判定不合格 | 隔离评估、纠正措施、根因分析 |

---

## 异常处理流程

### 轻微不符合

**情况：** 超出警戒限但未达到行动限

**处理措施：**
1. 加密监控频率
2. 检查清洁消毒程序
3. 排查潜在污染源
4. 记录并跟踪趋势

### 严重不符合

**情况：** 超出行动限或检出致病菌

**处理措施：**
1. 立即启动纠正措施
2. 隔离评估相关产品
3. 排查原因（设备、人员、原料、清洁等）
4. 采取预防措施
5. 必要时扩大取样范围
6. 记录并保存证据

## 记录与评审

### 记录内容

- 取样时间、点位、人员
- 检测方法与结果
- 判定结论
- 异常处理措施
- 评审意见

### 评审频率

| 类型 | 评审频率 |
|------|----------|
| 日常记录 | 每周评审 |
| 月度汇总 | 每月汇总分析 |
| 年度评审 | 每年全面评审 |

### 评审内容

- 监控结果趋势分析
- 限值合理性评估
- 监控方案优化建议
- 与HACCP计划的衔接情况

---

## 注意事项

- 监控方案应与HACCP计划相协调
- 取样应具有代表性，覆盖关键区域
- 检测方法应采用标准方法或等效方法
- 人员需经过培训并具备相应能力
- 记录应真实、完整、可追溯
