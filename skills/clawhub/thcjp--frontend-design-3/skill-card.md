## Known Risks and Mitigations: <br>
Risk: Generated shell commands, file writes, API calls, or callback URLs could affect the local workspace or external services if approved without review. <br>
Mitigation: Review each proposed command, file change, API call, and callback URL before allowing execution. <br>
Risk: API keys or credentials could be exposed if provided when they are not needed for the specific task. <br>
Mitigation: Provide credentials only when the task requires them, prefer environment variables, and avoid committing generated secrets or logs. <br>
Risk: Generated frontend code can introduce usability, accessibility, browser-compatibility, or performance issues. <br>
Mitigation: Test generated interfaces across target browsers and devices, with extra review for animations, custom cursors, font loading, and SVG/noise effects. <br>
