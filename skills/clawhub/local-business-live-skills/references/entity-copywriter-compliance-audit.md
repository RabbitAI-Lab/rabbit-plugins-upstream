# entity-copywriter.md 合规风险审计

> 审计时间：2026-07-25
> 来源：WorkBuddy 抖音2026审核合规优化后的遗漏项自查
> 状态：⚠️ 未修复，建议下一轮优化

## 已发现的问题

### 1. Hook 公式含违禁词

| 问题 | 位置 | 风险等级 |
|------|------|---------|
| 「天花板」属于绝对化用语（生活服务敏感） | Hook 模板库 | 🔴 高 |

具体模板：
```
「[区域]的[品类]天花板，开了[数字]年」
```
老板用了直接限流/关橱窗。

### 2. CTA 模板含站外导流风险

| 问题 | 位置 | 风险等级 |
|------|------|---------|
| 「私信领优惠」→ 私信引导不规范 | CTA 模板 | 🟡 中 |
| 「评论区扣[关键词]，我拉你进群」→ 站外导流 | CTA 模板 | 🔴 高 |

### 3. 对比型模板有点名风险

```
「4S店报价8000，我们只要3000」
```
需确认不点具体店名，否则有网暴/不正当竞争风险。

## 修复方向

- "天花板" → 改为具体可验证描述（"开了3年"）
- "私信领优惠" → 改为平台内动作（"左下角定位"、"主页领券"）
- "评论区扣XX我拉你进群" → 删掉，用直播间/主页引导替代
- 对比型模板 → 加限制条件：只能用行业均价，不能点名具体门店
