## Description:

Guides creators through validating, packaging, publishing, and verifying agent skills across registries, plugin directories, and paid marketplaces.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oxde](https://clawhub.ai/user/oxde)

### License/Terms of Use:

MIT-0

## Use Case:

Skill creators and developers use this guide to check a skill's readiness, choose distribution channels, prepare listings, and verify installations. Publishing requires the user's approval for each channel.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Publishing can make a skill public and some registries may not allow complete removal.

Mitigation: Review each publish command and obtain the user's approval for each channel before running it.

Risk: Licensing and marketplace terms may differ across distribution channels.

Mitigation: Confirm the skill's license and each marketplace's current terms before listing.

Risk: Local validation inspects a supplied skill folder.

Mitigation: Run the validator only on skill folders intended for publication.
