# Dryer Vent Fire Guard — Reference

## 1. The fire mechanism, precisely

1. **Lint bypasses the screen.** The removable screen catches roughly 80% of fibers; the rest rides the exhaust stream.
2. **Restriction slows the stream.** Every elbow, foot of flex duct, and smooth-wall foot deposits lint where velocity drops (elbows, transitions, hood damper).
3. **Deposited lint narrows the duct further** → less airflow → drum air stays humid → load needs more time.
4. **Longer cycles = longer burner/element-on time** with less cooling airflow. Exhaust temperatures climb.
5. **Lint pyrolyzes then ignites** (roughly 250–300 °C). It burns hot and fast, and the fire has a ready-made duct path into walls.

The reason dry-time creep matters: it is the *only* symptom visible to the occupant before the thermal fuse saves you (or doesn't).

## 2. Code model (IRC M1502 family, manufacturer manuals)

| Rule | Value |
|---|---|
| Max developed (equivalent) length, 4″ duct | 35 ft |
| 45° elbow | −2.5 ft allowance |
| 90° elbow | −5 ft allowance |
| Flex transition (semi-rigid), effective length | ≈1.35× actual |
| Foil/vinyl flex as the *run* | violation (metal only) |
| Termination | outdoors, damper hood, **no screen** |
| Indoor/attic/crawl termination | violation |

3-inch and 2.5-inch ducts (older installs) lose big capacity; treat as undersized and flag.

## 3. Dry-time verdict bands

Timed with a standard load: bath towels, high spin, straight from the washer, same dryer setting as always.

| Minutes | Verdict | Meaning |
|---|---|---|
| ≤50 | HEALTHY | vent + machine likely fine |
| 51–60 | WATCH | early restriction; inspect + clean |
| 61–90 | RESTRICTED | clean now; find the cause |
| >90 or 2+ cycles | SEVERE | clean today; fire risk elevated |

Caveat: an oversized load or a dying heating element also slow drying. The vent audit disambiguates: run the same load on air-only — if the drum exhaust at the hood is weak regardless of heat, it's airflow (vent). Weak heat = element/gas valve (repair topic, out of scope).

## 4. Inspection walkthrough (10 minutes, no tools beyond a phone light)

1. Pull the dryer. Photograph the transition duct: material? crushed? screws through it (lint snaggers — tape joints only)?
2. Trace the run visually as far as possible. Count elbows, estimate length, note diameter.
3. Outside: find the hood. Damper flapping in the exhaust while the dryer runs (helper holds phone at the hood)? Any screen? Lint fuzz at the flap = accumulation inside.
4. While the dryer runs on air-fluff: hold a tissue at the hood — it should snap against the grille. A lazy flutter = restriction.
5. Note vertical rise: basement dryers venting up 8+ ft accumulate faster (lint moves uphill poorly).

## 5. Cleaning ladder

| Level | When | How |
|---|---|---|
| DIY both-ends | accessible run ≤15 ft, few elbows | shop vac + flexible vent brush, both ends, vacuum last |
| Pro cleaning | in-wall, vertical, long, condo runs | $100–200, rotary brush + vacuum rig |
| Duct replacement | foil/vinyl, crushed, screwed joints | semi-rigid/rigid aluminum, foil tape (no screws) |
| Reroute | equivalent length >35 ft | remove elbows/shorten; upsize to 4″ if 3″ |

## 6. Failure signatures to know

- **Thermal fuse blown (dryer runs, no heat at all):** classic restriction outcome. Replace fuse AND clean vent, or the new fuse blows too.
- **Cycling thermostat wear:** repeated overtemp cycling ages it; symptoms = hot clothes, long times.
- **Burning smell, stop immediately:** unplug, keep door closed, outdoor air only — call fire department if smell persists. Lint fires inside the duct can smolder quietly.

## 7. Recurrence

- Baseline: 1×/year full-run clean (autumn is a good anchor: heavy bedding season).
- 2×/year: 5+ person household, pets (hair loads the stream), cloth diapers.
- After any dryer move/install: re-audit the transition (kinks at re-install are the #1 self-inflicted restriction).

## 8. What about vent boxes / heat savers?

Indoor venting boxes ("heat reclaimers") sell well and violate code in most jurisdictions: gallons of water per load into house air (condensation/mold in cold climates) plus fine lint. Reject unless the device has a real lint trap AND condensation path AND your jurisdiction allows — rare.
