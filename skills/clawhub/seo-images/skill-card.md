## Description:

Image optimization analysis for SEO and performance, including alt text, file size, modern formats, responsive images, lazy loading, CLS prevention, image SERP checks, and WebP/AVIF plus IPTC/XMP optimization guidance.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, SEO practitioners, and site operators use this skill to audit image SEO and performance issues, generate prioritized optimization recommendations, and prepare commands or snippets for image conversion, compression, metadata, responsive images, and lazy-loading fixes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Optimization workflows can create new image files or change metadata in existing images.

Mitigation: Confirm the target path before running optimization commands, keep originals or backups, and verify the output files before replacing production assets.

Risk: Copyright, creator, or AI-source metadata may be inaccurate if injected without user confirmation.

Mitigation: Only inject copyright, creator, or AI-source metadata after confirming that it accurately describes the image and its rights status.
