## Description:

Provides a typed Go client for managing Supabase organizations, projects, branches, and settings through the Supabase Management API.

This skill is ready for commercial/non-commercial use.

## Publisher:

[psyb0t](https://clawhub.ai/user/psyb0t)

### License/Terms of Use:

MIT-0

## Use Case:

Go developers use this client to list Supabase organizations and projects and to automate project and branch settings through the Supabase Management API. It does not cover project data operations such as PostgREST, end-user Auth, or Storage.

### Deployment Geography for Use:

Global
