## Description: <br>
Infernal free-expression image swarm with concrete 4-agent roles (Muse, Guardian, Critic, Composer), JSON prompt schema, safety validator regex, refinement loop draft→Guardian→Critic→Composer finalize, and example packs for journalism/protest/censorship themes. Lawful, consent-aware, no fake evidence. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External users and agents use this skill to produce lawful, consent-aware civic-expression image prompt packs for journalism, protest, censorship, debate, and civil-liberties themes. It structures the workflow through Muse, Guardian, Critic, and Composer roles with a safety review loop before final prompt guidance. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Symbolic civic-expression image prompts can still be misread as evidence or used in sensitive journalism, protest, censorship, or public-figure-adjacent contexts before review. <br>
Mitigation: Treat first drafts as unreviewed and wait for the Guardian PASS/final prompt pack before using them. <br>
Risk: The workflow permits local brief and prompt-draft reads and workspace writes for prompt packs and review notes. <br>
Mitigation: Install only for matching symbolic civic-expression image prompting tasks and review generated files before relying on them. <br>
