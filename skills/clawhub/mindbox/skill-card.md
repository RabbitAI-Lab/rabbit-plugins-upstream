## Description:

Generate and revise editable offline mindmap HTML from notes, documents, ideas or saved Mindbox HTML.

This skill is ready for commercial/non-commercial use.

## Publisher:

[markingyang](https://clawhub.ai/user/markingyang)

### License/Terms of Use:

MIT

## Use Case:

External users can turn notes, documents, and ideas into editable offline mindmaps, then revise or export maps from their saved HTML files.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated HTML and companion Markdown can contain supplied content, notes, or unfinished drafts.

Mitigation: Review exported files before sharing them.

Risk: Global install or update commands can affect Mindbox across selected assistants.

Mitigation: Prefer reviewed installer and source versions, and check the selected assistants before using global commands.
