# 中文公文 docx 生成

生成党政机关公文 docx：通知、报告、请示、批复、函、会议纪要等。
版式为本 skill 内置的机关通行规范（Word 默认页边距体系），**不是国标 GB/T 9704 红头
版式**——不要凭训练记忆套国标（3.7/3.5/2.8/2.6 页边距、国标字号层级一律不用）。

## 第 0 步：字体检查（必做，缺一不可）

公文对字体要求严格，**规定的字体不可用其他字体替代**。每次生成前先跑：

    python3 <本skill目录>/scripts/check_fonts.py

- 全部 `[OK]` → 继续生成。
- 有 `[缺失]` → 停下，把缺失字体的名称和用途报告给用户，请用户自行安装；
  用户同意时可协助搜索官方下载渠道（脚本输出里已给出各字体的获取渠道建议）。
  装好后重跑本脚本，通过后再生成。
- **绝不把字体文件打包进 skill、写入仓库或以任何方式再分发**——规范字体均为
  商业版权（方正/中易/长城），再分发侵权。下载来源的合规性由用户自行把握。

| 字体（docx 中引用名） | 用途 |
|---|---|
| 方正小标宋简体 | 大标题（二号 22pt） |
| 黑体（SimHei） | 一级标题、表头 |
| 楷体_GB2312 | 副标题、二级标题（不加粗） |
| 仿宋_GB2312 | 正文、三级标题（加粗）、落款 |

## 版式规范

| 元素 | 字体 | 字号 | 其他 |
|---|---|---|---|
| 大标题 | 方正小标宋简体 | 二号 22pt | 居中；行距固定 **33 磅**；**长标题必须手工分行** |
| 副标题 | 楷体_GB2312 | 三号 16pt | 居中 |
| 一级标题（一、二、…） | 黑体 | 三号 | 首行缩进 2 字 |
| 二级标题（（一）（二）…） | 楷体_GB2312 | 三号 | **不加粗** |
| 三级标题（1. 2. …） | 仿宋_GB2312 | 三号 | **加粗** |
| 正文 | 仿宋_GB2312 | 三号 16pt | 首行缩进 **32 磅（=2 汉字）**；行距固定值 **29 磅**；**两端对齐** |
| 主送机关抬头 | 仿宋_GB2312 | 三号 | **顶格不缩进**，全角冒号结尾 |
| 数字/西文 | Times New Roman | 随所在段落 | 与中文混排 |
| 页边距 | 上下 2.54cm、左右 3.17cm（Word 默认值） | | A4 |
| 标点 | 全角：双引号 \u201c\u201d、书名号《》、破折号—— | | |

表格惯例：Table Grid 边框、整体居中、表头黑体小四或五号、正文仿宋；单元格内 `\n` 可换行。

## 最容易做错的四处

1. **长标题孤字行**：标题超过一行宽度时，Word 自动换行会产生孤字行（读起来像乱码）。
   必须按词意单元手工拆成两三行，每行独立成段。例：
   `['关于召开年度重点工作', '推进会议的通知']`
2. **首行缩进是 32 磅**，不是 2 字符、不是 0.64cm——python-docx 里写 `Pt(32)`。
3. **中英混排要设两处字体**：`run.font.name = 'Times New Roman'` 管数字/西文，
   中文必须再设 `rFonts` 的 `w:eastAsia`，漏掉会兜底成宋体。
4. **WPS 不热重载**：外部工具重存 docx 后，已打开的 WPS 窗口仍显示旧内容（标题栏带 `*`）。
   让用户看新效果前提醒关闭重开；自己验证 WPS 渲染前也要重新打开文件。

## 生成流程

用本目录 `scripts/gongwen_builder.py`，全部版式已封装好，**不要每个会话重写排版代码**：

```python
import sys
sys.path.insert(0, '<本skill目录>/scripts')   # skill 加载时会给出基础目录
from gongwen_builder import GongwenDoc

g = GongwenDoc()
g.title(['关于召开年度重点工作', '推进会议的通知'])   # 长标题手工分行
g.recipient('各处室、各有关单位：')            # 主送机关顶格，勿用 para 缩进
g.para('为……，现将有关事项通知如下：')
g.h1('一、会议时间')
g.para('……')
g.h2('（一）参会单位')
g.para('……')
g.table(['处室', '年度预算\n（万元）', '执行率'],
        [['××处', '65.00', '45.9%'], ...])
g.signoff('××市××局', '2026年9月2日')
g.save('会议通知.docx')
```

依赖：`python-docx`（`pip3 install --user python-docx`）。

## 验收纪律（数字通道）

1. 生成后必须跑：
   `python3 <本skill目录>/scripts/verify_gongwen.py <文件.docx>`
   核对边距/字体/行距/缩进/居中，PASS 才算完成。
2. **文字内容核对走数字通道**（docx 解 XML、PDF 提文本层），禁止靠视觉模型逐字识读；
   LibreOffice 渲染：`soffice --headless --convert-to pdf <文件.docx>`。
3. 视觉模型只用于版式类判断（布局、对齐、有无大面积异常），结论需交叉确认；
   形近字（九/六、未/末、日/曰）永远不单独采信视觉结论。
