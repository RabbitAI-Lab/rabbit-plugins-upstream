# COMPLAINT() 客诉分析

**Skill ID:** `zayn-complaint`
- 所属分类：客诉与售后
- 一句话用途：整理客户售后反馈、事实、证据、订单和责任状态，再判断处理方向
- 当前版本：`v0.1`
- 当前状态：Draft for testing
- 规则是否完成：是，初版规则已建立
- 是否已有测试案例：否，等待真实脱敏案例
- 下一步待办：测试参数、证据、最低运行条件、责任边界和输出结构

COMPLAINT() 用于在客户反馈质量、功能、错发、缺件、混退、损坏或其他售后问题时，先整理事实、证据、订单信息和责任状态，再判断应该如何处理。它不默认认定我方产品存在问题，也不直接决定退款、换货或赔偿。

完整规则见 [SKILL.md](SKILL.md)，调用模板见 [examples.md](examples.md)，测试要求见 [tests.md](tests.md)。
