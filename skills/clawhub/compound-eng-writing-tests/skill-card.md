## Description:

Guides developers in writing behavioral tests that detect real regressions and avoid weak assertions, misleading mocks, and unreviewed expectation changes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[iliaal](https://clawhub.ai/user/iliaal)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to design, write, and verify meaningful tests when adding coverage or fixing failing behavior across languages and frameworks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad test runs or temporary control mutations may affect project state or consume significant time.

Mitigation: Review test commands and proposed mutations before running them; isolate stateful test infrastructure and restore any temporary changes.
