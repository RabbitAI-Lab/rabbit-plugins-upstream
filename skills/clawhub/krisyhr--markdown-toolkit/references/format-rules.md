# Markdown 中文排版规则

## 中英文混排

| 情况 | 正确 | 错误 |
|---|---|---|
| 中文后接英文 | 使用 `Python` 编程 | 使用`Python`编程 |
| 英文后接中文 | 推荐 VS Code 编辑器 | 推荐VS Code编辑器 |
| 中文后接数字 | 共 100 个用户 | 共100个用户 |
| 数字后接中文 | 版本 2.0 发布 | 版本2.0发布 |

## 标点

- **中文内容**用全角标点：`。，、；：？！“”‘’（）【】《》`
- **英文/数字**用半角标点：`.,;:?!()[]`
- **中文和英文混排时**，中文标点前后不加空格
- 英文单词前后用半角空格

## 标题

- 一级标题：文档标题（每篇1个）
- 二级标题：主要章节
- 三级标题：子章节
- 不要跳级别（h1 → h3 跳过了 h2）

## 段落

- 段落之间空一行
- 每段不超过 5 行（公众号阅读体验）
- 列表项之间不空行

## 引用

- 引用块前后各空一行
- 引用内的段落也遵守段落间距规则

## 代码

- 代码块必须标注语言：```python
- 行内代码使用单个反引号：`code`
