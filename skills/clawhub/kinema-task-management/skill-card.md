## Description: <br>
Kinema personal task tracking system where an AI agent maintains tasks as local Markdown files and can generate reports, snapshots, and archives. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Individuals and teams use this skill to let an agent create, update, archive, and report on personal or project tasks stored as Markdown files. It is intended for conversational task tracking across Codex, Claude Code, and OpenClaw workflows. <br>
