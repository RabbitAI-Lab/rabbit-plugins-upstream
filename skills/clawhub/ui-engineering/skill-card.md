## Description:

Expert system for creating high-quality, brand-aligned user interfaces. Use this skill when asked to design websites, create components, or implement specific visual styles. It contains specifications for major tech companies, design trends, and specific site types like blogs or presentations.

This skill is ready for commercial/non-commercial use.

## Publisher:

[yzfly](https://clawhub.ai/user/yzfly)

### License/Terms of Use:

MIT

## Use Case:

Developers and designers use this skill to choose a design specification for a requested interface and apply its design tokens, component patterns, and interaction guidance when creating websites or components.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated code and suggested dependencies may need adaptation to the project.

Mitigation: Review generated code and dependency suggestions before adding them to the project.

Risk: Imported project instructions keep the skill's design guidance active until removed.

Mitigation: Remove the imported instructions when the project no longer needs this guidance.
