## Description: <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and agent users use this skill to answer date or current-time questions and perform simple mathematical calculations during an agent workflow. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The calculator feature evaluates user-provided text as Python code. <br>
Mitigation: Install only if the publisher is trusted, review calculator expressions before execution, and prefer a version that uses a restricted arithmetic parser instead of eval. <br>
