## 核心内容

1. **域名注册** - 如何选择和注册域名（instantbg.cn 实例）
2. **免费主机** - ECS、Vercel、Netlify 等免费托管方案
3. **网站部署** - Flask/Python 网站部署全流程
4. **ICP备案** - 中国大陆网站备案指南
5. **变现设置** - Google AdSense 广告接入
6. **工具集成** - 免费 API 接入（抠图、AI等）
