## Description:

Find viral outlier posts on TikTok, Instagram and YouTube, pull creator stats, transcribe and analyse videos, build competitor watchlists, and crawl profiles on demand. Prepaid credits, MCP or REST.

This skill is ready for commercial/non-commercial use.

## Use Case:

Creators, marketers, and social-media researchers use this skill to find unusually successful public posts, compare creators, analyze video content, and manage competitor watchlists across TikTok, Instagram, and YouTube.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The API key grants access to paid account features.

Mitigation: Keep VIRAL_OUTLIERS_API_KEY private and provide it only through a trusted environment or MCP configuration.

Risk: Optional CLI installation and profile monitoring can introduce software and credit-use risks.

Mitigation: Review and pin the CLI version before using npm commands; agree on monitored profiles and refresh cadence, check credit costs, and stop unwanted tracking explicitly.
