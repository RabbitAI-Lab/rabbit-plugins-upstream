## 使用说明

1. 报告必须 7 节齐全（问题/数据/清洗/分析/可视化/洞察/局限）
2. 摘要必须 3-5 句话回答核心问题
3. 局限必须诚实披露
4. 附录引用前序交付物（不重复内容）
