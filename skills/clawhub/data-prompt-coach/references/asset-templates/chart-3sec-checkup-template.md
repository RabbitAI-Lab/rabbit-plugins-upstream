# 图表三秒体检清单模板（场景 8 Step 5）

> v3.3 新增。CRISP-DM Step 5 交付物，配合 M17 + M19 使用。

## 模板

```markdown
## 图表三秒体检清单

### 图表 [N]：[图表标题]

#### 基本信息
- **图表类型**：[散点图/条形图/折线图/直方图/箱线图/热力图/...]
- **数据来源**：[列名 + 行范围]
- **目的**：[回答什么问题]

#### 维度 1 · 轴标签体检
- [ ] X 轴是否标注：变量名 + 单位（如 "GDP (USD)"）
  - 当前：[实际值] —— [✅通过 / ⚠️修复]
- [ ] Y 轴是否标注：变量名 + 单位
  - 当前：[实际值] —— [✅通过 / ⚠️修复]
- [ ] 多子图是否每个都有轴标签
- [ ] 类别轴是否清晰可读（不重叠）
  - 当前：[评价] —— [✅通过 / ⚠️修复]

#### 维度 2 · 数据范围体检
- [ ] 范围是否合理
  - X 轴：[实际范围] —— [✅合理 / ❌有负数GDP/❌超界值]
  - Y 轴：[实际范围] —— [✅合理 / ❌异常]
- [ ] 是否被极值拉伸
  - 中位数是否可见：[是/否] —— [✅合理 / ⚠️建议对数轴]
- [ ] 颜色映射是否合理
  - 顺序数据用顺序色板：[✅/❌]
  - 类别数据用定性色板：[✅/❌]

#### 维度 3 · 图表类型体检
- [ ] 图表类型匹配数据特征
  - 数据特征：[两变量关系/分布/比较/趋势/多维]
  - 当前类型：[实际类型]
  - 匹配度：[✅匹配 / ❌应改为 X]
- [ ] 替代方案（如不匹配）
  - 推荐：[替代类型]

#### 体检结论

- 通过项数：[N/9]
- 未通过项：
  1. [问题1] → [修复方案]
  2. [问题2] → [修复方案]
- 修复后状态：[✅全部通过 / ❌仍需修复]

### 修复执行（如有未通过项）

[修复后的图表描述/代码]

### 二次体检

- 通过项数：[N/9]
- 状态：[✅通过 / ❌仍需修复]
```

## 使用说明

1. 每张图表生成后立即触发体检
2. 9 项中任一未通过 → 必须修复后重新体检
3. 体检通过才能进入 Step 6 洞察
