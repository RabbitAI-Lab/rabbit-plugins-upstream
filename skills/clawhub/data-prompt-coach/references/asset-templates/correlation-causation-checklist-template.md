# 相关≠因果验证清单模板（场景 8 Step 6）

> v3.3 新增。CRISP-DM Step 6 交付物，配合 M17 + M20 使用。

## 模板

```markdown
## 相关≠因果验证清单

### 待验证断言

- **断言 [N]**：[A 导致/影响/决定 B]
- **相关系数**：[r = 数值]
- **样本量**：[N]

### 6 项验证

#### V1 · 第三变量检查
- 是否存在同时影响 A 和 B 的第三变量 C？
  - 候选 C：[列出]
  - 控制 C 后 A-B 相关性：[数值变化]
- 结论：[✅无第三变量 / ⚠️发现第三变量 C，相关性降至 r=N]

#### V2 · 反向因果检查
- 是否可能 B → A？
  - 业务逻辑：[是否合理]
  - 时间序列：[B 是否领先 A]
- 结论：[✅方向正确 / ⚠️可能反向因果]

#### V3 · 混杂因素检查
- 在子群体中 A-B 关系是否一致？
  - 子群体 1（如发达国家）：r = [N]
  - 子群体 2（如发展中国家）：r = [N]
  - 差异：[是否显著]
- 结论：[✅一致 / ⚠️子群体差异显著，存在混杂]

#### V4 · 时间滞后检查
- A 的变化是否领先于 B？
  - 时间序列数据：[有/无]
  - 滞后分析：[N 期]
- 结论：[✅A 领先 B / ⚠️无时间序列，无法验证 / ❌B 领先 A]

#### V5 · 样本范围检查
- 剔除极端值后关系是否成立？
  - 剔除规则：[3σ/IQR]
  - 剔除后 r：[数值]
- 结论：[✅仍成立 / ⚠️关系弱化]

#### V6 · 业务逻辑检查
- 从业务角度，A→B 因果关系是否合理？
  - 机制解释：[因果链]
  - 反例检查：[是否有反例]
- 结论：[✅合理 / ⚠️机制不清晰]

### 综合结论

- **通过项数**：[N/6]
- **未通过项**：
  1. [项] - [原因]
  2. [项] - [原因]

### 措辞修正

- **原断言**：[A 导致 B]
- **修正为**：
  - [6/6 通过]：[A 因果 B]（可说因果）
  - [部分通过]：[A 与 B 强相关（r=N），但因果机制可能是 [机制]]
  - [多数不通过]：[A 与 B 统计相关，但不能推断因果]

### 因果机制说明（如改"相关"）

- 可能的因果链：[A → C → B 或 C → A,B]
- 建议进一步验证：[实验设计/工具变量/双重差分]
```

## 使用说明

1. 每个涉及"A 导致/影响 B"的断言必须执行
2. 6 项全部通过才能说"因果"
3. 部分通过必须改"相关"+ 说明机制
4. 验证清单作为洞察报告的附录
