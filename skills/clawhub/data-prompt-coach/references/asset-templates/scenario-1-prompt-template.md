## 使用说明

**AI 行为**：
- 用户进入场景 1 → 主动展示本模板让用户填写
- 用户填完后 → 基于模板生成完整 Prompt + 爬虫代码
- **v3.4.1 新增**：生成代码前必须完成"合规预检"和"脱敏预检"

**用户行为**：

## 🛡️ 合规预检清单（v3.4.1 新增，AI 生成代码前必查）

填完模板后，AI 必须先回答以下问题，任一为 ❌ 则拒绝生成爬虫代码：

| # | 检查项 | 通过条件 | 失败处理 |
|---|--------|---------|---------|
| 1 | robots.txt 允许抓取 | ✅ 目标路径未被 Disallow | ❌ 提示"目标站 robots.txt 禁止抓取该路径，请改用其他数据源或联系站长" |
| 2 | 服务条款允许自动化 | ✅ ToS 未明确禁止 web scraping | ❌ 提示"目标站服务条款禁止自动化采集，请改用官方 API 或人工录入" |
| 3 | 数据为公开数据 | ✅ 无需登录即可访问 | ❌ 提示"目标数据需登录访问，本技能不生成绕过登录的代码" |
| 4 | 用途合规 | ✅ 用于个人分析/研究 | ❌ 提示"本技能仅支持个人研究用途，不生成商业爬虫/数据转售代码" |
| 5 | 不绕过认证 | ✅ 不破解验证码、不伪造 CSRF Token | ❌ 提示"本技能禁止生成绕过认证/破解验证码的代码" |
| 6 | 礼貌限流 | ✅ 默认 time.sleep(1-3s) | ❌ 提示"本技能强制礼貌限流，不生成高速并发爬虫代码" |

**AI 输出格式**：
```
## 🛡️ 合规预检结果
- [✅/❌] robots.txt 检查：{说明}
- [✅/❌] 服务条款检查：{说明}
- [✅/❌] 公开数据检查：{说明}
- [✅/❌] 用途合规检查：{说明}
- [✅/❌] 不绕过认证检查：{说明}
- [✅/❌] 礼貌限流检查：{说明}

→ 全部 ✅，开始生成代码
→ 任一 ❌，提示用户调整需求或更换数据源
```

## 🔒 脱敏预检清单（v3.4.1 新增，存储前必查）

涉及云端存储（飞书双存储 M26）时，AI 必须先识别字段清单中的敏感字段并提示脱敏：

| 字段类型 | 是否敏感 | 脱敏方式 | 提示话术 |
|---------|---------|---------|---------|
| 姓名（个人） | ✅ 敏感 | 首字+`*`（如"张*"） | `⚠️ 检测到姓名字段，云端存储前请脱敏` |
| 手机号 | ✅ 敏感 | `138****1234` | `⚠️ 检测到手机号字段，云端存储前请脱敏` |
| 身份证号 | ✅ 敏感 | `110***********0011` | `⚠️ 检测到身份证号字段，云端存储前必须脱敏（法律要求）` |
| 银行卡号 | ✅ 敏感 | `6222************1234` | `⚠️ 检测到银行卡号字段，云端存储前必须脱敏（法律要求）` |
| 邮箱 | ⚠️ 半敏感 | `z***@example.com` | `⚠️ 检测到邮箱字段，建议云端存储前脱敏` |
| 地址（详细） | ⚠️ 半敏感 | 保留省市，详细地址脱敏 | `⚠️ 检测到详细地址字段，建议云端存储前脱敏` |
| 公司名 | ❌ 非敏感 | 无需脱敏 | — |
| 帖子标题 | ❌ 非敏感 | 无需脱敏 | — |
| 帖子链接 | ❌ 非敏感 | 无需脱敏 | — |

**AI 输出格式**：
```
## 🔒 脱敏预检结果（云端存储前）
- [✅ 非敏感] 字段 1：{字段名}（公司名）
- [⚠️ 半敏感] 字段 2：{字段名}（邮箱）→ 建议脱敏
- [✅ 敏感] 字段 3：{字段名}（手机号）→ 必须脱敏
- [✅ 敏感] 字段 4：{字段名}（身份证）→ 必须脱敏（法律要求）

→ 敏感字段已识别，将在生成代码时加入脱敏函数
→ 本地 CSV 保留完整版，飞书表只存脱敏版
```

## AI 生成 Prompt 的规则

### 必含要素（黄金五要素 M1）

1. **范围**：URL + 抓取范围（全量 / 增量 / 时间段）
2. **字段**：字段清单 + 类型 + 取值规则
3. **规则**：排序 / 单位 / 格式 / 过滤
4. **格式**：CSV / 飞书多维表格 / JSON
5. **异常**：缺失填什么 / 歧义怎么办 / 无法识别怎么办

### 防幻觉三招（M2）

1. **亮证据**：每个字段标注 API 字段路径
2. **给示弱**：不确定的字段标注"待验证"
3. **禁脑补**：不假设字段名，必须实际查看 API 响应

### 增量同步（M14+M24）

1. **唯一 ID**：明确用什么字段作为唯一 ID
2. **缓存策略**：JSON 文件 / SQLite / 飞书多维表格
3. **过滤逻辑**：抓新数据 → 对比缓存 → 过滤 → 写入 → 更新缓存
4. **频率控制**：每次请求间隔 1-2 秒

### 飞书存储（M26）

1. **字段类型映射**：业务字段 → 飞书类型
2. **数据格式转换**：日期 → Unix 毫秒，超链接 → dict
3. **批量写入**：每批 500 条
4. **错误处理**：401 Token 失效 / 429 QPS 限制 / 字段长度超限
