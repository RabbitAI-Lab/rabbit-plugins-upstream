# M8 目标导向 Prompt 模型（反常识）

> **核心定位**：分析型任务的 Prompt 反模式——多给目标少给指令。

## R (Reading) 原文引用

> "可以多给'分析目标'，少给具体的'绘图指令'。让 TRAE Work 利用它的推理能力自主选择分析角度，往往能发现你没想到的视角。"

## I (Interpretation) 重写方法论

**反常识原则**：分析型任务，Prompt 越"少"反而越"好"。

```
✅ 多给的：
  - 分析目标（"找出 ROI 最高的组合"）
  - 分析维度（"按渠道/创意/受众/地区交叉"）
  - 必含指标（"总消耗/CTR/CPC/CPA/ROI"）
  - 输出结构（"含执行摘要+Top5+维度分析+建议"）

❌ 少给的：
  - 具体绘图指令（"用柱状图画"——让 AI 自己选）
  - 过度约束的分析路径（"先算 X 再算 Y"——让 AI 自主推理）
  - 写死的字段计算（"ROI = 转化价值/消耗"——除非有歧义否则不必写死）
```

**关键认知**：AI 的推理能力是被低估的——给它目标，它能发现你没想到的视角。

## A1 (Past Application) 书中案例

小陆 1500 行广告投放报告（教程场景 7）：

```
【分析目标】1.效果复盘 2.寻找亮点 3.识别浪费 4.策略建议
【分析维度】渠道/创意/受众/地区/广告主交叉分析
【分析指标】总消耗/总转化/CTR/CPC/CPA/ROI
【输出要求】HTML+PDF + 执行摘要+Top5 Findings+维度分析+建议
【注意事项】所有数字必须来自数据本身，严禁编造
```

没写"用柱状图画 X 轴 Y 轴"——AI 自主选了热力图/散点图/漏斗图。

## A2 (Future Trigger) 何时会需要

- **用户说**："深度分析""洞察报告""找规律""多维交叉"
- **场景**：场景 7 深度洞察报告
- **与相邻 skill 的区分**：
  - vs M1 五要素：M1 是采集型（要什么给什么），M8 是分析型（多给目标少给指令）
  - vs M9 分步提问：M8 是单次 Prompt 的写法，M9 是多次迭代的策略

## E (Execution) 可执行步骤

1. **写分析目标**：3-5 个具体目标（"找出 ROI 最高的组合"）
2. **列分析维度**：3-7 个交叉维度
3. **列必含指标**：明确哪些指标必须覆盖
4. **不写绘图指令**：让 AI 自选图表类型
5. **加防编造约束**："所有数字必须来自数据本身，严禁编造"

## B (Boundary) 边界与盲点

**不适用于**：
- 采集/提取类任务（那是 M1：要什么给什么）
- 需要严格控制格式的合规报告（必须按监管要求画图）
- 重复性周报（第一次用 M8 探索，跑通后用 M1 固化模板）

**作者盲点**：教程说"让 AI 自主推理"很好，但没讨论"AI 自主推理出错怎么办"——对于高风险报告，建议第一次用 M8 探索，第二次开始用 M1 固化模板。

## v3.1 配套增强 — 分析产出持久化附录

> 来源：教程 4「只需 5 步用 SOLO 实现数据采集到可视化全流程」+ 教程 3「不止是写代码：如何用 TRAE 进行复杂数据分析」

**触发条件**：M8 探索性分析完成后，AI 产出的分析结论/中间结果有再次复用价值时启用。

**持久化四要素**：

```
要素 1 · 中间产物落盘
  → 把分析过程中的中间表/中间结果保存为 .csv/.json/.sqlite
  → 命名规则：{task}_{step}_{timestamp}.{ext}
  → 避免下次重跑时重新计算，节省 80% 时间

要素 2 · Prompt 模板沉淀
  → 第一次用 M8 探索性 Prompt 跑通后
  → 把成功的 Prompt 沉淀为模板，第二次开始用 M1 固化模板
  → 模板存到 docs/prompts/ 或 .claude/prompts/ 目录

要素 3 · 验真脚本独立化
  → 验真抽查逻辑独立成 .py 脚本，可重复执行
  → 每次重新生成结果后，跑一次验真脚本，输出 [PASS]/[FAIL]

要素 4 · 增量同步（若任务需定期跑）
  → 引入 M14 增量同步机制
  → 用 ai_cache.json 指纹缓存，只处理变更部分
  → 清空+批量写入优于逐行更新
```

**与 M14 增量同步的区别**：M14 是"定期采集"场景的效率优化（输入端），本附录是"分析产出"的持久化（输出端），二者常配合使用：M14 定期采集 + M8 探索分析 + 持久化附录存档。

**与 M1 固化模板的关系**：M8 探索跑通后，下一次起用 M1 固化模板，本附录是"M8 → M1"的过渡桥梁。
