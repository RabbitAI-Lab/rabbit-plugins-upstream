# M1 黄金五要素 Prompt 模型

> **核心定位**：所有采集/提取类 Prompt 的基础骨架。缺哪个要素 AI 就在哪"自由发挥"。

## R (Reading) 原文引用

> "一句话区分好坏 Prompt：差的 Prompt 让 AI 不停猜（抓哪些字段？几页？怎么排？存成啥？），好的 Prompt 让 AI 读完不用猜任何东西。缺了哪个要素，AI 就会在那里'自由发挥'，结果自然不可控。"

## I (Interpretation) 重写方法论

任何"采集 / 提取 / 输入→输出"类 Prompt 必须显式包含 5 个要素，构成 AI 无需猜测的最小完备契约：

```
【1. 明确范围】数据源 + 范围 + 排除规则
【2. 字段清单】要哪些字段 + 每个字段的取值规则
【3. 处理规则】排序 + 单位统一 + 格式标准化 + 过滤
【4. 输出格式】Excel/JSON/CSV + 列顺序 + 文件名 + 备注列
【5. 异常处理】缺失填什么 + 抓不到怎么办 + 歧义怎么标
```

**自检口诀**：读完 Prompt，AI 还需要猜任何东西吗？是→补；否→发送。

## A1 (Past Application) 书中案例

老王晨间基金采集 Prompt（教程场景 1）：

```
今日日期。访问 [URL]，提取基金排行榜中的所有基金数据。
需要的字段：排名、基金代码、基金简称、基金类型、最新净值、近1年收益率、
            近3年收益率、基金规模、基金经理。
处理规则：1.排除货币基金和短债基金 2.按近一年收益率从高到低排序 3.收益率保留两位小数
输出为 Excel 文件，文件名包含今日日期。
```

老王受益点：20 分钟手工活 → 全自动化定时任务。

## A2 (Future Trigger) 何时会需要

- **用户说**："抓数据""爬取""批量提取""从网页拿""从 PDF 抠字段"
- **场景**：场景 1 网页采集 / 场景 2 文档字段提取 / 场景 6 周报（合并部分用）
- **与相邻 skill 的区分**：
  - vs M8 目标导向：M1 是"采集型"（要什么给什么），M8 是"分析型"（多给目标少给指令）
  - vs M2 防幻觉：M1 是骨架，M2 是叠加在骨架上的护栏

## E (Execution) 可执行步骤

1. **列字段清单**：逐条写要哪些字段
2. **写取值规则**：每个字段加"优先取 X，无则取 Y"
3. **定输出格式**：Excel/JSON + 列顺序 + 文件名规则
4. **写异常回退**：缺失填"未填写"，歧义"取第一个其余放备注"
5. **自检**："AI 还需猜什么？"——是→补；否→发送

## B (Boundary) 边界与盲点

**不适用于**：
- 分析型任务（那是 M8 目标导向：多给目标少给指令）
- 需要 AI 推理创新的场景（五要素会过度约束）
- 纯文本摘要类任务

**作者盲点**：教程主要面向结构化数据采集，对半结构化（JSON API）和非结构化（自由文本）场景的五要素适配未充分展开。
