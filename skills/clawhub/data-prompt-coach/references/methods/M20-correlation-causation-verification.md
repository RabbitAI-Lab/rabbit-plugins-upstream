# M20 相关≠因果反复验证清单

> **核心定位**：防止把"统计相关"误说成"业务因果"——这是 AI 数据分析最常见的幻觉，必须用清单强制反复验证。
>
> **来源**：v3.3 教程蒸馏（D1 数据分析与可视化课程，2026-07）

## I (Interpretation) 重写方法论

**相关≠因果验证清单（6 项）**：

```
□ V1 · 第三变量检查
  → 找出可能同时影响 X 和 Y 的第三变量 Z
  → 验证：控制 Z 后，X 和 Y 的相关性是否消失
  → 例子：冰淇淋销量 vs 溺水数 —— 控制温度后相关性消失

□ V2 · 反向因果检查
  → 验证：是 X → Y 还是 Y → X？
  → 例子：GDP → 幸福感？还是 幸福感 → GDP（幸福感高的国家更努力工作）？

□ V3 · 混杂因素检查
  → 找出可能扭曲 X-Y 关系的混杂因素
  → 验证：在子群体中 X-Y 关系是否一致
  → 例子：GDP-幸福感关系可能在发达国家 vs 发展中国家不同

□ V4 · 时间滞后检查
  → 验证：X 的变化是否领先于 Y？
  → 例子：教育投入 → GDP 增长（滞后 5-10 年）

□ V5 · 样本范围检查
  → 验证：相关性是否只在特定样本中成立？
  → 例子：剔除极端国家后，相关性是否仍成立？

□ V6 · 业务逻辑检查
  → 验证：从业务角度，X-Y 因果关系是否合理？
  → 例子：鞋码 → 阅读能力（相关但因果是年龄混杂）
```

**关键原则**：
- 6 项全部通过才能说"因果"
- 任一项不通过 → 必须改说"相关" + 说明可能的因果机制
- AI 主动验证，不等用户追问

**反常识**：相关系数 0.99 也不能说因果——经典例子：鞋码与阅读能力相关 0.9+，但因果是年龄。

## A1 (Past Application) 书中案例

**D1 Demo · 世界幸福指数 Step 6**：
- AI 输出："GDP 与幸福感相关 0.78，因此 GDP 提升能提高幸福感"
- 老师打断："相关≠因果，请验证"
- AI 执行清单：
  - V1 第三变量：发现社会支持与幸福感相关 0.76 → 可能是第三变量
  - V2 反向因果：可能是幸福感高的社会更稳定 → GDP 高（部分合理）
  - V3 混杂因素：发达国家 GDP-幸福感关系更强（样本异质）
- 修正结论："GDP 与幸福感强相关，但因果机制可能是：GDP → 社会基础设施 → 主观幸福感。建议表达'相关'而非'因果'"

## A2 (Future Trigger) 何时会需要

- **用户说**："为什么这个结论""这个怎么算的""推导链""A 导致 B 吗"
- **场景**：8 完整数据分析全流程 Step 6，也可用于场景 7 深度洞察报告
- **信号**：AI 输出涉及"X 导致 Y""X 影响 Y""因为 X 所以 Y"等因果表述
- **与相邻 skill 的区分**：
  - vs M2 防幻觉三招：M2 是通用防幻觉，M20 是统计因果特化
  - vs M13 中间逻辑可追溯：M13 是逻辑链可追问，M20 是因果断言可验证

## E (Execution) 可执行步骤

1. **识别因果断言**：扫描 AI 输出，找出所有"X 导致/影响/决定 Y"的断言
2. **逐条执行 6 项验证**：V1-V6 各打勾或叉
3. **修正结论措辞**：
   - 6 项全通过 → 可说"因果"
   - 任一项不通过 → 改"相关"+ 说明机制
4. **输出验证清单**：作为洞察报告的附录

**Prompt 骨架**：
```
请对以下结论执行"相关≠因果"验证：

[粘贴 AI 输出的结论]

验证清单：
□ V1 第三变量：是否存在同时影响 X 和 Y 的第三变量？
□ V2 反向因果：是否可能 Y → X？
□ V3 混杂因素：在子群体中关系是否一致？
□ V4 时间滞后：X 是否领先 Y？
□ V5 样本范围：剔除极端值后关系是否成立？
□ V6 业务逻辑：从业务角度因果是否合理？

输出：
- 通过项数 / 6
- 未通过项 + 原因
- 修正后的结论措辞（"相关" vs "因果"）
```

## B (Boundary) 边界与盲点

**不适用于**：
- 描述性统计（"Top 10 国家"）—— 无因果断言
- 已知的物理因果（"温度升高 → 冰融化"）—— 物理定律无需验证

**与 M17 联动**：M17 Step 6 必须调用 M20
**与 M2 联动**：M2 防幻觉三招是通用框架，M20 是其统计因果特化版本

**作者盲点**：
- 6 项验证在数据量小时难以全部执行（V3 子群体分析需要足够样本）
- 教程没讨论"观察性数据 vs 实验数据"的因果推断差异
- V4 时间滞后需要时间序列数据，截面数据无法验证
