# M17 CRISP-DM 7 步操作 SOP

> **核心定位**：把抽象的 CRISP-DM 流程落地为 7 步可执行操作，每步有明确交付物和决策点。
>
> **来源**：v3.3 教程蒸馏（D1 数据分析与可视化课程，2026-07）

## R (Reading) 原文引用

> "CRISP-DM（跨行业数据挖掘标准流程）模型的七步流程：1. 问题定义与数据获取 → 2. 数据探索与理解 → 3. 数据清洗与预处理 → 4. 数据分析与建模 → 5. 结论与可视化 → 6. 洞察与行动建议 → 7. 报告打包"
> "每一步都要产出明确的交付物，下一步基于上一步的交付物继续推进"
> "Demo：世界幸福指数数据 - AI 端到端完成六步分析（问题定义→数据获取→清洗→分析→结论→可视化）"

## I (Interpretation) 重写方法论

**7 步流水线**：

```
Step 1 · 问题定义与数据获取
  → 输入：业务问题 + 数据源（CSV/Excel/URL）
  → 交付物：问题陈述卡（业务问题→数据问题→关键指标→成功标准）
  → 决策点：数据是否足够回答问题（否→回到数据源扩充）

Step 2 · 数据探索与理解
  → 输入：原始数据
  → 交付物：数据体检清单（shape/dtypes/缺失率/异常值/分布）
  → 决策点：数据质量是否达标（否→进入 Step 3 清洗）

Step 3 · 数据清洗与预处理
  → 输入：原始数据 + 体检清单
  → 交付物：清洗决策审查表（每条决策记录：问题→选择→理由→影响）
  → 决策点：清洗是否充分（否→追加清洗规则）

Step 4 · 数据分析与建模
  → 输入：清洗后数据 + 问题陈述卡
  → 交付物：分析结果集（按子问题拆解，每子问题一结论）
  → 决策点：分析是否回答了问题（否→回到 Step 1 调整问题定义）

Step 5 · 结论与可视化
  → 输入：分析结果集
  → 交付物：图表 + 三秒体检清单（轴标签/数据范围/图表类型）
  → 决策点：可视化是否准确反映结论（否→调整图表类型）

Step 6 · 洞察与行动建议
  → 输入：结论 + 图表
  → 交付物：洞察卡（发现→含义→建议→下一步）+ 相关≠因果验证清单
  → 决策点：洞察是否可执行（否→回到 Step 4 深化分析）

Step 7 · 报告打包
  → 输入：所有前序交付物
  → 交付物：结构化报告（7 节：问题/数据/清洗/分析/可视化/洞察/局限）
  → 决策点：报告是否可独立阅读（否→补充背景）
```

**关键原则**：
- 每步必须产出明确交付物（不能"做了但没产出"）
- 每步结束有决策点（决定下一步走向，可能回退）
- 步骤之间是"流水线"而非"独立任务"
- Step 4-6 可能需要多轮迭代（不是一遍走完）

**反常识**：CRISP-DM 不是线性流程，而是带反馈环的——教程明确说"分析未回答问题→回到 Step 1 调整问题定义"。

## A1 (Past Application) 书中案例

**D1 Demo · 世界幸福指数**：
- Step 1：问题"GDP 是否决定幸福感" + World Happiness Report CSV
- Step 2：AI 输出数据体检（156 行 × 9 列 + 缺失率 + GDP/Happiness 分布）
- Step 3：清洗决策（缺失值用中位数填充 → 记录理由"避免极值扭曲"）
- Step 4：分析（GDP vs Happiness 相关系数 0.78 + Top 10 国家对比）
- Step 5：可视化（散点图 + 回归线 + Top 10 条形图）
- Step 6：洞察（GDP 是重要因素但非唯一 → 社会 support 相关性 0.76 接近）
- Step 7：报告打包（7 节结构）

## A2 (Future Trigger) 何时会需要

- **用户说**："我有数据想分析""帮我分析这份数据""我想用 AI 做数据分析""我有个 CSV 想知道..."
- **场景**：8 完整数据分析全流程
- **信号**：用户提供数据文件 + 一个想回答的问题（非单一查询任务）
- **与相邻 skill 的区分**：
  - vs M4 任务拆解：M4 是 4 步粗粒度（提取→清洗→核对→分析），M17 是 7 步细粒度含决策点
  - vs M8 目标导向：M8 是单次 Prompt 写法，M17 是端到端流程
  - vs M12 下钻触发：M12 是分析深度的迭代，M17 是流程的骨架

## E (Execution) 可执行步骤

1. **Step 1**：要求用户提交数据源 + 描述业务问题 → 生成"问题陈述卡"
2. **Step 2**：调用数据体检 Prompt → 输出数据体检清单
3. **Step 3**：基于体检结果，生成清洗 Prompt → 要求 AI 输出"清洗决策审查表"
4. **Step 4**：按问题陈述卡拆解子问题 → 每子问题一条分析 Prompt
5. **Step 5**：基于分析结果生成可视化 Prompt → 附"三秒体检清单"
6. **Step 6**：生成洞察 Prompt → 强制要求"相关≠因果验证清单"
7. **Step 7**：生成报告打包 Prompt → 输出 7 节结构 .md 报告

**Prompt 骨架（Step 3 示例）**：
```
基于以下数据体检结果，请执行清洗并输出决策审查表：

[粘贴数据体检清单]

要求：
1. 每个清洗决策必须记录：问题→选择→理由→影响
2. 缺失值处理必须说明为何选择（中位数/均值/删除/插值）
3. 异常值处理必须说明为何选择（保留/删除/修正）
4. 输出"清洗决策审查表"作为下一步输入
```

## B (Boundary) 边界与盲点

**不适用于**：
- 单一查询任务（用场景 3 SQL 生成即可，无需 7 步流程）
- 数据采集类任务（场景 1/2 是采集，不是分析）
- 已经清洗好的数据 + 简单查询（直接用 M1+M2 即可）

**与 M18-M21 联动**：
- Step 3 必须调用 M18（清洗决策审查）
- Step 5 必须调用 M19（图表三秒体检）
- Step 6 必须调用 M20（相关≠因果验证）
- 全流程必须警惕 M21（AI 背答案）

**作者盲点**：
- 教程没讨论"步骤回退的触发条件"——什么情况下回退到上一步 vs 当前步重做
- 教程没讨论"多轮迭代的停止条件"——Step 4-6 何时算"足够"
