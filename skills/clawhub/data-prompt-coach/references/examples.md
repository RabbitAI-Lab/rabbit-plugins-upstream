# 示例库

> 从 SKILL.md 抽取的 2 个端到端示例，演示双入口工作流程。

## 示例 1：引导入口（场景 2 文档提取）

**用户输入**："我有一堆候选人简历 PDF，想提取姓名/电话/学历/期望薪资到 Excel"

**Skill 执行流程**：
1. L1 识别：场景 2（信号：简历 PDF + 抠字段）
2. L2+ 资料感知：
   - 主动要求"给我 1-3 份样表" → 用户传 3 份 PDF
   - 调用 [pdf-analyzer.md](material-analyzers/pdf-analyzer.md) 分析版式/字段位置/易错点
   - 资料分析回填 5 要素：字段已明确、格式已明确、剩余异常处理未明
3. L2 访谈（最少 3 轮）：
   - 第 1 轮：问"简历格式统一吗？缺失字段怎么处理？"
   - 第 2 轮：问"输出 Excel 还是 CSV？是否需要备注列？"
   - 第 3 轮：问"批量大于 100 份时分批策略？"
4. L3 路由：场景 2 + <100 份 → M1+M2
5. L4+ 多物交付：Prompt + Excel 模板 + 验真脚本

## 示例 2：蒸馏入口

**用户输入**："蒸馏这个教程：https://example.com/data-analysis-tutorial"

**Skill 执行流程**：
1. L0.1 整体理解：体裁=混合（案例+方法论），主题=数据分析 Prompt 引导
2. L0.2 5 维度提取：候选 8 个（3 方法论 + 2 陷阱 + 1 决策框架 + 2 触发条件）
3. L0.3 三重验证：通过 4 个，淘汰 4 个（其中 2 个捞回）
4. L0.4 RIA++ 挂载：
   - 创建 M{N+1}-{slug}.md（按候选内容命名）
   - 更新 INDEX.md（追加新节点）
   - 更新 method-composition.md（追加场景组合）
   - 追加 test-prompts.json（每个新方法论 ≥1 条 should_trigger）
   - 淘汰候选写入 rejected.md / candidates.md
5. 输出蒸馏报告

**注意**：实际挂载的方法论名称取决于教程内容，不预先指定。
