# 场景 4·数据核对（参考案例）

> 本文件仅作参考案例。Prompt 骨架由 SKILL.md 主控 + M2+M7（顶配）套用生成。**防幻觉三招在本场景必须强化到顶配**。

## 案例原型

老周（消费品公司财务专员）月末核对员工报销，报销申请表 vs 银行付款流水，过去用 VLOOKUP 一行行比对。

## 关键参数

- **表 A**：报销申请表（姓名/部门/申请金额/费用类型/申请日期）
- **表 B**：银行付款流水（付款日期/收款方姓名/付款金额/备注）
- **匹配键**：姓名（可能存在模糊匹配）
- **状态分类**：
  - ✅ 匹配：姓名对上 + 金额相等
  - ⚠️ 金额不一致：姓名对上 + 金额不等（写出差额）
  - 🔵 仅 B 有：流水有但申请没有（疑似漏录）
  - 🔴 仅 A 有：申请有但流水没有（未付款）
  - ❓ 待确认：模糊匹配，需人工复核
- **输出**：核对结果表 + 依据说明列 + 最后汇总

## 样例 Prompt 片段（关键三段·三招顶配）

```
【核对规则】
以"姓名"作为主要匹配键，把表A的每一条申请与表B的流水进行匹配，判断属于以下哪种情况：
1. ✅ 匹配：姓名能对上，且申请金额 = 付款金额
2. ⚠️ 金额不一致：姓名能对上，但申请金额 ≠ 付款金额（请写出差额）
3. 🔵 仅流水有：表B里有这条流水，但表A里找不到对应申请
4. 🔴 仅申请表有：表A里有这条申请，但表B里找不到对应流水

【输出要求】
- 每一条都要给出"依据说明"，写清楚你是凭哪条申请、哪条流水做出的判断 [亮证据]
- 重要：严格基于我给的数据判断，不要猜测 [禁脑补]
- 如果某条因姓名相近、金额接近等原因你无法确定如何匹配，请标为"❓待确认"
  并说明疑点，不要强行配对 [给示弱]

【汇总】
最后给出一个汇总：各类状态分别有几条
```

## 隐藏坑（场景 4 专属·三招顶配）

1. **AI 强行配对模糊匹配**：必须给"❓待确认"出口，让 AI 不硬配
2. **依据说明空白**：必须强制"每条都要依据说明"——空白 = AI 脑补
3. **金额差额算错**：明确"差额 = 申请金额 - 付款金额"
4. **重复匹配**：一对多（一个员工多笔报销）必须用姓名+金额+日期组合匹配
5. **状态分类不全**：必须列出 4-5 种状态及判断规则
6. **漏汇总**：最后必须给"各类状态分别有几条"

## 验真抽查（4 件事）

1. 抽查"❓待确认"行：看 AI 是真不能确定，还是偷懒
2. 抽查"✅ 匹配"行：随机抽 5-10 条人工核对
3. 看汇总数字：表 A 总数 = 匹配 + 仅 A + 待确认；表 B 总数 = 匹配 + 仅 B + 待确认
4. 检查"金额不一致"差额是否合理（小数点、币种）
