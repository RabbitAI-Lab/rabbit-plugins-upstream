# 场景 6·周报敏捷分析（参考案例）

> 本文件仅作参考案例。Prompt 骨架由 SKILL.md 主控 + M1+M7+M4 套用生成。

## 案例原型

某公司运营负责人每周汇总 3 个事业部数据采集进度表（每张 50 行），过去手工合并 + VLOOKUP + 透视表。

## 关键参数

- **数据源**：3 个 Excel 文件（事业部 1/2/3），字段相同
- **任务四件事**（M4 拆解心法）：
  1. 合并：3 文件 → 总表（加"所属事业部"列）
  2. 计算：按事业部汇总（渠道数/目标/已完成/缺口/完成率）
  3. 筛选：完成率 <60% 标"落后" → 单独输出风险预警列表
  4. 总结：一段话业务洞察
- **指标口径**：完成率 = 已完成 / 目标，保留 1 位小数
- **输出**：分事业部汇总表 → 风险预警列表 → 业务总结段

## 样例 Prompt 片段（关键三段）

```
附件的 3 个 Excel 文件，分别是事业部 1/2/3 的数据采集进度，
每个文件字段相同：[字段列表]。

请帮我做以下处理：
1. 把 3 个文件合并成一张总表，新增"所属事业部"列以区分来源
2. 按事业部汇总：渠道数、目标数据量、已完成、缺口、本周新增、
   整体完成率（已完成/目标），最后加一行全公司合计
3. 判断标准：完成率 < 60% 的渠道标记为"落后"，
   单独输出一张风险预警列表（按完成率从低到高排）
4. 最后用一段话总结整体进度和最需要关注的事

输出要求：先给分事业部汇总表，再给落后渠道风险预警列表，
最后一段话总结业务进展。完成率保留 1 位小数。
```

## 隐藏坑（场景 6 专属）

1. **文件没合并**：必须写"把 N 个文件合并成一张总表"——AI 默认逐文件分析
2. **缺来源标识**：必须加"新增'所属事业部'列"——合并后无法区分
3. **完成率算错**：必须明确"完成率 = 已完成 / 目标"——AI 可能用其他口径
4. **风险预警漏筛**：必须明确阈值"完成率 < 60% 标记为'落后'"
5. **总结空泛**：必须规定"整体进度 + 落后渠道 Top 3 + 重点盯谁"
6. **完成率小数位不统一**：必须规定"保留 1 位小数"
7. **数据缺失被填 0**：必须给"数据缺失"出口而非"完成率 0%"

## 验真抽查（4 件事）

1. 抽查总表行数：3 个文件 × 50 行 = 150 行，对得上吗
2. 抽查完成率计算：随机抽 3-5 条，人工算 (已完成/目标)
3. 检查风险预警列表：完成率 <60% 的渠道是否都被筛出
4. 业务总结里的数字是否在汇总表里找得到
