# 场景 7·深度洞察报告（参考案例）

> 本文件仅作参考案例。Prompt 骨架由 SKILL.md 主控 + M8+M9（>10 万行加 M11）套用生成。

## 案例原型

某广告投放团队季度复盘，1500 行广告投放数据，需要交互式 HTML 报告 + PDF 存档 + Top 5 Findings。

## 关键参数

- **数据源**：1500 行广告投放数据 Excel
- **分析目标**（M8 目标导向）：
  1. 效果复盘：整体评估本季度投放质量
  2. 寻找亮点：识别 ROI/转化率表现最突出的维度组合
  3. 识别浪费：找出消耗较高但 ROI < 1.0 的"资金黑洞"
  4. 策略建议：为下季度预算分配给至少 5 条具体建议
- **分析维度**：投放渠道、创意类型、目标受众、地区、广告主（交叉分析）
- **必含指标**：总消耗、总转化量、平均 CTR、平均 CPC、平均 CPA、整体 ROI
- **输出**：HTML 交互报告 + PDF 静态版本

## 样例 Prompt 片段（关键三段）

```
附件是季度广告投放数据，请帮我进行深度数据洞察分析，并产出专业报告。

【分析目标】
1. 效果复盘：整体评估本季度的投放质量
2. 寻找亮点：识别 ROI、转化率表现最突出的维度组合
3. 识别浪费：找出消耗较高但 ROI < 1.0 的"资金黑洞"
4. 策略建议：基于数据为下季度预算分配给出至少 5 条具体建议

【输出要求】
1. 生成 HTML 交互式报告 + PDF 静态版本
2. 必须含：执行摘要 / 关键发现 Top 5 / 详细维度分析 / 结论与下步建议
3. 图表：请根据数据特征自主选择最佳图表（不要默认柱状图）

【注意事项】
- 所有数字必须来自数据本身，严禁编造结论
- 对每个"关键发现"请标注具体的支撑数据及计算口径
- 报告中若有显著的异常值（Outliers），请单独指出
```

## 隐藏坑（场景 7 专属）

1. **大文件阈值**（M11）：
   - <1500 行：直接拖
   - 1500-5000 行：直接拖但 Prompt 要更聚焦
   - 5000-10000 行：先拆维度分批
   - >10 万行：先让 AI 写 Python 脚本预汇总，再做洞察
2. **目标导向 vs 绘图指令**（M8 核心）：多给"分析目标"，少给"绘图指令"——让 AI 自选图表角度
3. **分步提问法**（M9）：高报告要求场景用 `/plan` 先出大纲 → 确认 → 深挖
4. **报告数字与数据对不上**：强化"所有数字必须来自数据本身，严禁编造"
5. **关键发现无支撑数据**：必须要求"标注支撑数据 + 计算口径"
6. **图表中文乱码**：加"使用支持中文的字体库（如 SimHei）"
7. **报告结构不全**：必须明确"执行摘要 + Top 5 + 维度分析 + 建议"
8. **异常值被忽略**：必须要求"显著的异常值请单独指出"——异常值往往是洞察来源
9. **图表类型单一**：加"请根据数据特征自主选择最佳图表"

## 验真抽查（4 件事）

1. 抽查 3 条 Findings：引用的数字是否在原数据中能找到
2. 检查异常值：AI 标出的异常值是否真的异常
3. 验证计算口径：ROI = 转化价值 / 消耗，分母分子是否正确
4. 业务常识校验：报告中"整体 ROI 5.0"这种异常高的数字要警惕
