# 场景 2·文档字段提取（参考案例）

> 本文件仅作参考案例。Prompt 骨架由 SKILL.md 主控 + M1+M2（>100 份加 M6）套用生成。

## 案例原型

小林（HR）金三银四要处理 200 份候选人简历 PDF，过去 3-5 分钟/份。

## 关键参数

- **数据源**：200 份 PDF（格式不统一，中英文混排、字段缺失、薪资写法不统一）
- **字段**：姓名/联系方式/最高学历/毕业院校/工作年限/当前职位/期望薪资/所在城市
- **取值规则**（关键）：
  - 联系方式：优先手机号 → 退而取邮箱 → 都没填"缺失"
  - 最高学历：取最高的一项
  - 当前职位：取最近一份工作
  - 期望薪资：**原样保留**写法（"30-40k" 不转换）
  - 所在城市：多值取第一个，其余放备注
- **输出**：Excel + 备注列写判断依据
- **异常**：缺失填"未填写"/"缺失"；完全无法识别单独列行说明原因

## 样例 Prompt 片段（关键三段）

```
【需要提取的字段】
1. 姓名
2. 联系方式：优先取手机号；如果没有手机号，则取邮箱；都没有则填"缺失"
3. 最高学历：从博士/硕士/本科/大专/其他中选一个，取学历最高的一项
4. 期望薪资：原样保留简历里的写法（如"30-40k""10000/月"）；未填写则填"未填写"

【输出要求】
- 严格基于简历原文提取，不要猜测或编造
- 对于有歧义或需要推算的字段，在"备注"列简要说明你的判断依据
- 如果某份简历完全无法识别，也单独列一行并在备注里说明原因

【异常处理】
- 字段缺失 → 填"未填写"或"缺失"
- 字段歧义 → 取第一个值，其余放备注
- 推算字段 → 在备注列写明推算依据
```

## 隐藏坑（场景 2 专属）

1. **多段经历堆叠**：必须显式写"取最高学历""取最近一份工作"——AI 默认把所有经历都堆进去
2. **薪资被统一转换**：必须写"原样保留"——AI 默认把"30-40k"转成数字
3. **备注列空白**：必须要求"判断依据"——空白备注 = AI 脑补
4. **大批量分批**：>100 份分批投喂，每批 50-100 份，第一批当对齐基准
5. **中英混排**：明确"中英文都识别，最终输出中文"

## 验真抽查（4 件事）

1. 抽查 3 份格式最乱的简历（中英混排/字段缺失/多段经历）
2. 看备注列有没有判断依据
3. 检查推算字段（如工作年限）的推算逻辑
4. 检查"完全无法识别"的行：是文档真有问题，还是 AI 偷懒
