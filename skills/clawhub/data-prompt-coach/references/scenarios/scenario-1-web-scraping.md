# 场景 1·网页批量采集（参考案例）

> 本文件仅作参考案例。Prompt 骨架由 SKILL.md 主控 + M1+M2+M7 套用生成，不在此重复模板。

## 案例原型

老王（投资从业者）每个交易日抓基金排行榜，过去手动 20 分钟/天。

## 关键参数

- **数据源**：`https://fund.eastmoney.com/data/fundranking.html`（带分页的网页表格）
- **字段**：排名/基金代码/基金简称/基金类型/最新净值/近1年收益率/近3年收益率/基金规模/基金经理
- **处理规则**：排除货币基金和短债基金 / 按近1年收益率降序 / 收益率保留 2 位小数
- **输出**：Excel，文件名含今日日期
- **异常**：抓不到的字段填"未获取"，不要瞎编

## 样例 Prompt 片段（关键三段）

```
访问 https://fund.eastmoney.com/data/fundranking.html ，提取基金排行榜中的所有基金数据。
如有分页请翻页抓全，不要只抓第一页。

【处理规则】
1. 排除货币基金和短债基金
2. 按近一年收益率从高到低排序
3. 收益率保留两位小数
4. "2.3万" 转成数字 23000；"23.45亿" 转成数字 23.45（亿元单位）

【异常处理】
- 字段缺失：填"未获取"（不要编数字）
- 翻页失败：在最后一条记录的备注列标"翻页中断于第 N 页"
```

## 隐藏坑（场景 1 专属）

1. **JS 动态加载**：网页需要等待加载完成，Prompt 加"等待页面加载完成"
2. **礼貌限流**：分批抓或加间隔（如 1-2 秒/请求），减轻目标站点压力，遵守 `robots.txt`，避免高峰期密集请求
3. **定时自动化**（高阶，需用户明确授权）：调通后追加"每个交易日早上 9 点自动执行，结果推送给我"——⚠️ 执行前必须告知用户：① 会写入本地文件 ② 会消耗凭证（如邮件/IM token）③ 会占用系统资源 ④ 用户须审查 .bat 内容并确认路径权限
4. **单位转换**：必须显式写"2.3万转成 23000"——AI 默认保留单位字符串

## 合规边界（v3.2 审计整改新增）

⚠️ **本场景仅作为 Prompt 教练辅助，不授权以下行为**：
- ❌ 规避目标站点的反爬虫机制（如伪造 User-Agent、绕过验证码、IP 轮换代理池）
- ❌ 抓取明确禁止抓取的内容（robots.txt disallow 或付费墙后内容）
- ❌ 大规模分布式抓取（应使用合规的爬虫服务而非本技能辅助）
- ❌ 抓取涉及个人隐私/敏感数据的内容

**用户须知**：本技能生成的 Prompt 仅供学习/合法数据采集使用。用户须自行承担合规责任，遵守目标站点 ToS 和当地法律法规。

## 验真抽查（3 件事）

1. 抽 3-5 条人工打开网页核对
2. 看缺失值分布：某字段大面积"未获取" → 字段识别规则要调
3. 看排序：是否真的按指定字段排序
