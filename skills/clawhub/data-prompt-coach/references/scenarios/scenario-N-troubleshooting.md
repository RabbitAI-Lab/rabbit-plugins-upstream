# 通用故障排除（场景 N）

> Skill 触发异常 / 生成 Prompt 质量问题 / 与其他 Skill 协作。

## 触发异常

| 症状 | 原因 | 解决 |
|------|------|------|
| 用户想写 Prompt，AI 跑去做分析 | 触发到 /consulting-analysis | 重申 "Do NOT use for 直接执行" 边界 |
| 用户想要图表，触发了本 Skill | 应该用 /chart-visualization | 告知用图表类 Skill |
| 7 场景之外的需求被触发 | 描述与某场景信号词重叠 | 告知"超出范围"，建议用 /consulting-analysis |

## 生成 Prompt 质量问题

| 症状 | 原因 | 解决 |
|------|------|------|
| Prompt 缺五要素之一 | 用户描述太简略 | 主动追问"处理规则？输出格式？异常情况？" |
| Prompt 没有"防幻觉三招" | 场景识别错误 | 重新识别场景，套顶配版三招 |
| Prompt 太啰嗦 | 所有规则全堆 | 按"五要素 + 三招 + 场景化补充"分块 |
| Prompt 没有验真建议 | 漏了输出第 3 段 | 补"验真抽查建议"段 |

## 场景识别错误

| 误识别 | 应识别为 | 区分信号 |
|--------|---------|---------|
| 周报当深度报告 | 周报 | 中等规模+多文件合并+完成率 → 周报 |
| 深度报告当周报 | 深度报告 | 大体量+多维交叉+HTML 报告 → 深度报告 |
| 字段提取当标注 | 字段提取 | 输入是 PDF/图片 → 提取；任务是抠字段 → 提取 |
| 标注当字段提取 | 标注 | 输入是文本；任务是打标签 → 标注 |

## 超出范围（直接告知）

| 用户想要 | 本 Skill 不做 | 建议去向 |
|---------|--------------|---------|
| 机器学习建模 | ❌ | 找 ML 类 Skill |
| 实时数据流处理 | ❌ | 找流处理类 Skill |
| 只画图表不要分析 | ❌ | 用 /chart-visualization |
| 直接执行分析拿结果 | ❌ | 用 /consulting-analysis |
| 替用户定义业务口径 | ❌ | 用户自己定义，本 Skill 只提醒"请先定义口径" |

## 常见结果不理想症状

| 症状 | 原因 | 解决 |
|------|------|------|
| AI 编造数字/字段 | 防幻觉三招没强化 | 检查 Prompt 含"不要猜测"+ "标注依据"+ "待确认出口" |
| 字段大面积缺失 | 字段识别规则太严 | 放宽匹配 / 大白话描述 / 提供 1-2 条样本对齐 |
| AI 把所有经历都堆 | 没规定"取最高/最近" | 补"取最高学历""取最近一份工作" |
| 大批量跑一半断 | 单批太大 | 拆成 50-100 条/批，保留全局序号 |
| 图表中文乱码 | 字体不支持 | 加"使用 SimHei 或指定路径字体" |
| SQL 跑出来的数翻倍 | 多表 JOIN 没去重 | 检查 COUNT 是否要 DISTINCT |

## 与其他 Skill 协作

| 场景 | 配合 Skill | 协作方式 |
|------|-----------|---------|
| 场景 6 周报 + 可视化 | /chart-visualization | 先用本 Skill 出 Prompt，再追加"使用 /chart-visualization 绘图" |
| 场景 7 深度报告 | /consulting-analysis | 本 Skill 出 Prompt，consulting-analysis 执行 |
| 大批量文档处理 | /excel-batch-processor | 本 Skill 出 Prompt，excel-batch-processor 执行批处理 |
| 把工作流沉淀为 Skill | skill-creator | 跑顺畅后用 skill-creator 沉淀 |

## 升级与反馈

- 发现 Bug 或改进点 → 在 CHANGELOG.md 记录
- 想发布到三平台 → 用 skill-publisher
