# 场景 8：完整数据分析全流程（CRISP-DM 7 步）

> v3.3 新增场景。当用户提供数据文件 + 一个想回答的业务问题时触发。
> 默认挂载 M17 CRISP-DM 7 步 + M18 清洗决策审查 + M19 图表三秒体检 + M20 相关≠因果验证。

## 触发信号

- **强信号**：我有数据想分析 / 帮我分析这份数据 / CSV 想知道 / 端到端分析 / CRISP-DM / 从问题到报告
- **弱信号**：数据可视化 / 完整报告 / 数据清洗 / 建模
- **教学特化信号**（触发 M21）：教学 / 学习 / 挑战任务 / 测试 AI / 背答案 / 数据陷阱

## 与场景 6/7 的区分

| 维度 | 场景 6 周报 | 场景 7 深度报告 | 场景 8 完整分析全流程 |
|------|-----------|---------------|---------------------|
| 输入 | 多文件 + 周期任务 | 单数据集 + 深度问题 | 数据 + 业务问题（端到端） |
| 输出 | Excel + 业务总结 | HTML + Top 5 Findings | 7 节结构化报告 + 6 个清单 |
| 流程 | M1+M7+M4 | M8+M9 | M17（7 步 SOP）+M18+M19+M20 |
| 是否教学 | 否 | 否 | 可选（M21） |

## 7 步工作流

### Step 1 · 问题定义与数据获取

**Prompt 骨架**：
```
我有一份数据：[描述数据源]
我想回答的业务问题：[描述问题]

请生成"问题陈述卡"：
- 业务问题（用户视角）
- 数据问题（可量化的等价问题）
- 关键指标（回答问题需要的核心指标）
- 成功标准（什么样的答案算"回答了问题"）
```

**决策点**：数据是否足够回答问题？
- 是 → 进入 Step 2
- 否 → 反问用户补充数据源

### Step 2 · 数据探索与理解

**Prompt 骨架**：
```
请对以下数据执行体检，输出数据体检清单：

[粘贴数据 / 描述数据结构]

体检清单：
- shape：行数 × 列数
- dtypes：每列数据类型
- 缺失率：每列缺失值比例
- 异常值：基于 3σ/IQR 的异常值
- 分布：关键数值列的分布（均值/中位数/分位数）
```

**决策点**：数据质量是否达标？
- 是 → 跳过 Step 3，直接 Step 4
- 否 → 进入 Step 3 清洗

### Step 3 · 数据清洗与预处理（M18）

读取 [M18-cleaning-decision-review.md](../methods/M18-cleaning-decision-review.md)。

**Prompt 骨架**：
```
基于以下数据体检结果，请输出清洗决策审查表：

[粘贴数据体检清单]

要求：
1. 每个数据问题一行，按 | # | 问题 | 选择 | 理由 | 影响 | 输出
2. 缺失值处理必须说明为什么选这个方法（不是"通常这样做"）
3. 异常值处理必须说明基于什么标准识别
4. 影响必须可量化
```

**决策点**：清洗是否充分？
- 是 → 进入 Step 4
- 否 → 追加清洗规则

### Step 4 · 数据分析与建模

**Prompt 骨架**：
```
基于清洗后数据和问题陈述卡，请按子问题拆解分析：

问题陈述卡：
[粘贴问题陈述卡]

子问题拆解：
- 子问题 1：[具体子问题]
- 子问题 2：[具体子问题]
- ...

每个子问题输出：
- 分析方法
- 关键数值
- 结论（一句话）
```

**决策点**：分析是否回答了问题？
- 是 → 进入 Step 5
- 否 → 回到 Step 1 调整问题定义

### Step 5 · 结论与可视化（M19）

读取 [M19-chart-3sec-checkup.md](../methods/M19-chart-3sec-checkup.md)。

**Prompt 骨架**：
```
基于分析结果，请生成图表 + 三秒体检：

分析结果：
[粘贴分析结果集]

要求：
1. 每个关键结论配一张图表
2. 图表生成后必须自检：
   - 轴标签：变量名 + 单位
   - 数据范围：合理（无负数 GDP 等）
   - 图表类型：匹配数据特征
3. 不通过则立即修复
```

**决策点**：可视化是否准确反映结论？
- 是 → 进入 Step 6
- 否 → 调整图表类型

### Step 6 · 洞察与行动建议（M20）

读取 [M20-correlation-causation-verification.md](../methods/M20-correlation-causation-verification.md)。

**Prompt 骨架**：
```
基于结论和图表，请输出洞察 + 相关≠因果验证：

[粘贴结论 + 图表]

要求：
1. 每条洞察用"发现→含义→建议→下一步"格式
2. 涉及"A 导致 B"的断言必须执行 6 项验证：
   - V1 第三变量 / V2 反向因果 / V3 混杂因素
   - V4 时间滞后 / V5 样本范围 / V6 业务逻辑
3. 任一项不通过 → 改"相关"+ 说明机制
```

**决策点**：洞察是否可执行？
- 是 → 进入 Step 7
- 否 → 回到 Step 4 深化分析

### Step 7 · 报告打包

**Prompt 骨架**：
```
请把所有前序交付物打包成结构化报告：

[粘贴所有交付物]

报告结构（7 节）：
1. 问题（问题陈述卡）
2. 数据（数据体检清单）
3. 清洗（清洗决策审查表）
4. 分析（分析结果集）
5. 可视化（图表 + 三秒体检）
6. 洞察（洞察卡 + 因果验证）
7. 局限（数据局限 + 分析局限 + 因果局限）
```

## 教学场景特化（M21）

如果识别到教学信号（"教学/学习/挑战任务/测试 AI"），在 7 步流程开始前增加"AI 背答案提醒"：

```
⚠️ 教学场景提醒（M21）：

1. 完成分析后，建议做"数据手术"验证 AI 是否真分析
2. 数据手术 5 步：
   - 备份原数据
   - 设计手术（重命名 1 列 / 反转 1 列 / 加 1 干扰列）
   - 让 AI 重新分析
   - 对比结论
   - 输出诊断报告

3. 自我诊断三问：
   - AI 是否引用了具体数据（行号/数值）？
   - AI 的过程是否过于流畅，缺少试错？
   - AI 是否回避了你提供的具体数据？
```

## 交付物清单（场景 8）

1. Prompt 集（7 步各一条精确 Prompt）
2. 问题陈述卡（Step 1 产出）
3. 数据体检清单（Step 2 产出）
4. 清洗决策审查表（Step 3 产出）
5. 分析结果集（Step 4 产出）
6. 图表 + 三秒体检清单（Step 5 产出）
7. 洞察卡 + 相关≠因果验证清单（Step 6 产出）
8. 7 节结构化报告（Step 7 产出）
9. AI 背答案诊断报告（仅教学场景，M21 产出）

## 关键纪律

1. **不能跳步**：7 步必须依次走，每步有交付物
2. **不能合并**：不要把清洗和分析合并成一步
3. **决策点必答**：每个决策点必须明确回答是/否
4. **回退允许**：Step 4 未回答问题 → 回 Step 1 调整
5. **教学场景特化**：识别到教学信号才挂载 M21，否则不挂载
