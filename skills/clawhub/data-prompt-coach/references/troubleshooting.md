# 故障排除

> 从 SKILL.md 抽取的故障排除表，常见问题与解决方案。

| 症状 | 排查 | 解决 |
|------|------|------|
| 误触发为"直接执行分析" | 应写 Prompt 却跑去分析了 | 重申 Do NOT 边界，建议用 /consulting-analysis |
| 双入口误触发 | 引导入口被触发为蒸馏或反之 | 反问"你要做数据分析（引导）还是蒸馏教程（萃取方法论）？" |
| 场景识别错误 | 信号词重叠 | 反问"这是周报还是深度报告？" |
| 3 轮访谈后仍不完备 | 用户描述太简略 | 进入第 4 轮继续问，或用户主动说"差不多就行"用当前信息生成 |
| 用户想要 ML 建模 | 超出 8 场景 | 告知不在范围，建议找 ML 类 Skill |
| 用户想要生成图表 | 超出 8 场景 | 告知不在范围，建议用 /chart-visualization |
| 蒸馏入口教程无方法论 | 教程是纯叙事 | 输出"无可挂载方法论" + 终止 |
| 蒸馏入口输入太短 | 文本 < 500 字 | L0.1 预检失败，输出"内容太短" + 终止 |
| 蒸馏挂载超 5 个 | 单次挂载过多 | 警告 + 仅挂载前 5 个，其余留 candidates.md |
| v3.1 方法论误触发 | 信号词与场景不匹配 | 验证 M12↔M13/M15↔M16 是否成对，否则不追加 |
| M14 增量同步误用 | 一次性任务用了增量同步 | 检查是否真有"定期"信号词，否则降级为 M6 分批处理 |
| **场景 8 误判为场景 7**（v3.3） | "深度分析""报告"信号词重叠 | 检查是否有"端到端""CRISP-DM""从问题到报告"——有则锁定场景 8，否则场景 7 |
| **场景 8 跳步**（v3.3） | 用户跳过清洗直接分析 | 强制按 CRISP-DM 7 步走，每步有交付物，不能合并清洗和分析 |
| **M21 教学场景误挂载**（v3.3） | 非教学场景挂了 M21 | 检查是否有"教学""学习""挑战任务""测试 AI""背答案""数据陷阱"信号词，否则不挂载 M21 |
| **M17-M20 拆分挂载**（v3.3） | 场景 8 中只挂 M17 不挂 M18/M19/M20 | CRISP-DM 7 步骨架不可拆分，M17/M18/M19/M20 在场景 8 必须成套挂载 |
| **口语化输入无法识别**（v3.3） | 用户说"我有个表想看看"等弱信号 | 走"场景自检 3 问"：数据源是什么 / 要做什么 / 输出是什么 |
| **5 个 v3.1+v3.3 方法论超限**（v3.3） | 场景 8 含下钻 + 可视化 + 教学导致超 5 个 | 优先保留 M17/M18/M19/M20（骨架），其余按场景优先级裁剪 |
| **因果验证遗漏**（v3.3） | 场景 8 Step 6 未跑 M20 验证 | 任何"A 导致 B"断言必须跑 6 维度验证，否则改"相关" |
