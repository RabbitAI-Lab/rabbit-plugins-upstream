# 场景识别决策树（v3.1）

> 拿到用户需求先识别 7 场景中的哪一类，再决定访谈方向和方法论组合。
> v3.1 增强：识别到方法论触发信号（探索性/可视化/定期运行/AI 可信度）后追加 M12-M16。

## 决策流程

```
用户描述需求
    │
    ▼
┌─────────────────────────────────────┐
│ 1. 数据源是什么？                    │
└─────────────────────────────────────┘
    │
    ├─ 网页 URL ──────────────────────→ 【场景 1】网页批量采集
    │
    ├─ PDF / Word / 图片 / 简历/合同 ─→ 【场景 2】文档字段提取
    │
    ├─ Excel / CSV / 数据库表 ────────┤
    │   │                              │
    │   ▼                              │
    │   ┌─────────────────────────┐   │
    │   │ 2. 任务类型是什么？       │   │
    │   └─────────────────────────┘   │
    │       │                          │
    │       ├─ 写 SQL 查询 ─────────→ 【场景 3】SQL 生成
    │       │
    │       ├─ 两张表对账/核对 ────→ 【场景 4】数据核对
    │       │
    │       ├─ 文本分类/打标签 ────→ 【场景 5】批量分类标注
    │       │
    │       ├─ 多文件合并+周报 ────→ 【场景 6】周报敏捷分析
    │       │
    │       └─ 多维交叉+报告 ──────→ 【场景 7】深度洞察报告
    │
    └─ 无法判断 ──→ 反问："这是采集/提取/SQL/核对/标注/周报/深度报告哪一类？"
```

## 7 场景识别信号词速查

| 场景 | 强信号词 | 弱信号词 |
|------|---------|---------|
| 1 网页批量采集 | 抓数据、爬取、网页表格、基金排行榜、价格监控 | 自动化、定时任务 |
| 2 文档字段提取 | 简历、合同、发票、名片、抠字段、提取信息 | OCR、识别 |
| 3 SQL 生成 | 写 SQL、查询、JOIN、子查询、聚合 | 数据库、表结构 |
| 4 数据核对 | 对账、核对、两张表对得上、报销、流水 | 匹配、稽核 |
| 5 批量分类标注 | 打标签、分类、标注、工单、用户反馈 | 标签体系、置信度 |
| 6 周报敏捷分析 | 周报、合并、汇总、完成率、风险预警 | 多文件、事业部 |
| 7 深度洞察报告 | 深度分析、报告、洞察、1500 行、HTML 报告 | 多维、交叉、Top 5 |

## v3.1 方法论触发信号词（场景识别后追加）

> 在 7 场景识别完成后，扫描以下信号，匹配到则追加 M12-M16 到方法论组合。

| 方法论 | 触发信号词 | 追加到典型场景 |
|--------|----------|---------------|
| **M12 下钻触发** | "深入分析""下钻""为什么这个数据""有哪些有趣维度""涌现" | 场景 6/7 探索性 |
| **M13 中间逻辑可追溯** | "为什么这个结论""这个怎么算的""逻辑是什么""推导链""AI 自动算的" | 场景 4/6/7 含 AI 计算 |
| **M14 增量同步** | "定期采集""每天自动跑""增量更新""每小时同步""重复运行" | 场景 1 定期版 |
| **M15 迭代式可视化** | "画个图""可视化""图表优化""美化""交互图""plotly" | 场景 6/7 可视化版 |
| **M16 多维数据联动** | "多维关系""联动""多个图表组合""热力图+气泡图""矩阵式" | 场景 7 含 ≥5 维 |

**叠加规则**：
- M12/M13 通常成对出现（下钻必须可追溯）
- M15/M16 通常成对出现（可视化迭代+多维联动）
- M14 通常与 M6（分批）+ M7（验真）三件套
- 单场景最多叠加 3 个 v3.1 方法论，避免组合爆炸

## 边界情形处理

### 情形 A：用户需求跨多场景

例："帮我把网页上的基金数据抓下来，再核对一下跟我手头的 Excel 是否一致"

→ 拆成两个 Prompt：先场景 1 采集，再场景 4 核对。**不要混在一个 Prompt 里**（违背 M4 任务拆解心法）。

### 情形 B：场景 6 vs 场景 7 难分辨

| 信号 | 场景 6 周报 | 场景 7 深度报告 |
|------|-----------|---------------|
| 数据规模 | 中等（< 200 行） | 大（> 1000 行） |
| 输出 | Excel + 业务总结 | HTML + PDF + Top 5 Findings |
| 重点 | 完成率、风险预警 | 多维交叉、ROI、资金黑洞 |
| 是否含可视化 | 可选 | 必含 |
| Prompt 风格 | M1 采集型 | M8 目标导向 |

### 情形 C：场景 2 vs 场景 5 难分辨

| 信号 | 场景 2 字段提取 | 场景 5 分类标注 |
|------|---------------|---------------|
| 输入 | PDF/图片/简历等非结构化文档 | 文本反馈/工单等结构化文本 |
| 任务 | 抠字段（姓名/电话/学历） | 打标签（功能异常/服务差评） |
| 输出 | Excel 字段表 | 标签 + 置信度 + 理由 |
