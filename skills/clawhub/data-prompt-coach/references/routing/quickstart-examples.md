## 场景 1：网页采集

### 强信号原话（直接锁定）

- "帮我把基金排行榜抓下来" → M1+M2+M7

- "自动跟踪这个价格变化" → 推断场景 1+M14 → 反问"要定期采集吗？"

### v3.4.0 爬虫场景原话（M22-M26 触发）

- "我用 requests.get 抓基金排行榜，返回的 HTML 是空的，数据藏在哪里" → M1+M2+M7+**M22**（SPA 识别）

## 跨场景任务（拆分处理）

用户输入"抓数据+核对+出报告"——

**AI 行为**：
1. **不要混在一个 Prompt 里**（违背 M4 任务拆解）
2. **拆成 3 个 Prompt**：
   - 第一步：场景 1（抓数据）→ M1+M2+M7
   - 第二步：场景 4（核对）→ M2+M7
   - 第三步：场景 7 或 8（出报告）→ 询问用户要深度报告（场景 7）还是端到端（场景 8）
3. **每步独立走 5 层触发引导**

## 入口歧义处理

用户输入"分析下这个教程"——

**冲突关键词**：
- "分析" → 引导入口信号
- "教程" → 蒸馏入口信号

**AI 行为**：
1. **优先识别"教程"** → 走入口 B 蒸馏
2. **反问确认**："你是要萃取教程中的方法论（蒸馏入口），还是要做教程里的数据分析任务（引导入口）？"
3. **用户回应后再走对应入口**
