# DIGEST — 不读教程原文，看这篇就够

> 「用 TRAE Work 做数据分析的实战教程」的精华提炼。经 cangjie-skill RIA-TV++ 蒸馏，11 个方法论通过三重验证。

## 3 心法一句话

1. **交代清楚**：把脑子里的"潜台词"（要什么、缺了怎么办、有歧义怎么办）写进 Prompt
2. **永远验真**：尤其是数字，让 AI 亮出依据，自己再抽查
3. **拆开来做**：复杂任务分步走，每步可检查、可回溯

## 11 个方法论速查

## 典型使用流程

```
用户描述需求
    │
    ▼
L1 场景识别（按数据源 + 任务类型）
    │
    ▼
L2 递归收敛访谈（最多 3 轮，一次一问）
    - 第 1 轮：场景识别 + 范围缺口
    - 第 2 轮：字段/口径缺口
    - 第 3 轮：异常处理缺口
    │
    ▼ 完备
L3 智能路由 + 组合生成
    - 匹配方法论组合
    - 从 methods/ 读取 RIA++ 六维
    - 套模板生成 Prompt + 防幻觉清单 + 验真建议
```
