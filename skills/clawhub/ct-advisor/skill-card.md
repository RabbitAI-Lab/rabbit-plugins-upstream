## Description:

A cloud-assisted advisor for clinical-trial methodology, design, statistics, regulatory compliance, quality control, and site execution.

This skill is ready for commercial/non-commercial use.

## Publisher:

[medstatstar](https://clawhub.ai/user/medstatstar)

### License/Terms of Use:

MIT

## Use Case:

Clinical-trial practitioners, clinicians, and students use this advisor to explore trial design, methodology, safety, regulatory, and quality questions and receive written guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Questions, metadata, and attachments may leave the device for cloud processing.

Mitigation: Obtain organizational approval before use with sensitive material; do not submit patient-level data, confidential protocols, sponsor-sensitive files, or regulated records without approval.

Risk: Automatic long-term memory may retain interaction patterns locally.

Mitigation: Review or disable long-term memory behavior before using the skill.

Risk: Sibling tools may run while sensitive environment variables are present.

Mitigation: Avoid running sibling tools with sensitive environment variables set.
