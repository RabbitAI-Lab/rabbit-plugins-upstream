## Description:

Generates Seedream 5.0 Pro images with fine detail, typography, and complex composition for commercial key visuals and brand assets.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Designers, developers, and creative teams use this skill to generate polished marketing key visuals and brand assets from prompts, optionally guided by reference images.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security evidence reports no clear harmful behavior, but scan coverage is partial and the reported login/API-key setup does not clearly match the image-generation description.

Mitigation: Review the CLI and package before installation, and only provide an API key you control.

Risk: Prompts and supplied local reference images are sent to dLazy's hosted API and media storage for generation.

Mitigation: Avoid sending sensitive prompts or images unless you are comfortable with the provider's data handling.
