# 诉讼自动化工作流 SOP

## IRAC 渐进式推理链

```
Jurisdiction → Facts → Issues → Law → Application → Risk → Action
     ↓           ↓         ↓        ↓        ↓            ↓        ↓
Step1 初始写入 → Step3 类案δ → Step4 法条δ → Step5 策略δ → Step7 出庭δ → Step8 编译审计
```

## 三阶段分离

```
阶段一（Step1-2）：事实采集 + 文书生成 → 暂停等待律师审阅
阶段二（Step3-7）：检索 → 分析 → 策略 → 定稿 → 出庭 → 暂停等待律师审阅
阶段三（Step8）：自动推理审计报告（全自动，无暂停）
```

## 数据库中间层

```
Step1 → 案件数据.json（唯一数据源头）→ Step2-7 仅读取JSON
Step2 → 文书数据.json（文书关键字段提取）→ Step3-6 校验补填
```

## 质量控制闭环

```
每步完成 → QC检查 → 通过→下步 / 不通过→自动重试（最大3次）
```
