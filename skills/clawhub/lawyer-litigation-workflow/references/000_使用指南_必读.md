# 律师诉讼自动化工作流 — 使用指南

## 快速开始

### 安装

在 WorkBuddy 中搜索「lawyer-litigation-workflow」一键安装。

### 启动

说：**「处理案件 {案件名}，案由是 {案由}」**

例如：「处理案件 青岛和润达建材，案由是 买卖合同纠纷」

## 工作区结构

```
~/.lawyer_workflow/
├── templates/          模板文件 (.docx)
└── cases/              案件目录
    └── {案件名称}/
        ├── evidence/   证据材料放这里
        ├── data/       中间数据自动生成
        └── output/     最终文书输出到这里
```

## 全流程概览

| 步骤 | 名称 | 说明 | 暂停 |
|------|------|------|------|
| Step0 | 前置检查 | 许可验证 + 工作区初始化 + 模板检测 | 否 |
| Step1 | 案件访谈 | 生成谈话笔录 + 证据预扫描 | **是** |
| Step2 | 文书生成 | 起诉状/答辩状/授权委托书等全套文书 | 否 |
| Step3 | 类案检索 | 多渠道检索相似案例 | 否 |
| Step4 | 法条检索 | 穷尽相关法律条文 | 否 |
| Step5 | 策略分析 | IRAC对抗式分析 + 法官模拟 | 否 |
| Step6 | 审查定稿 | 全案一致性审计 + 批注处理 | **是** |
| Step7 | 出庭文书 | 证据目录 + 代理词生成 | 否 |
| Step8 | 推理审计 | 五维推理质量评分（自动） | 否 |

## 两次审阅暂停

1. **Step1 完成后**：确认谈话笔录内容准确，当事人信息完整
2. **Step6 完成后**：逐份审查定稿文书，可批注修改

## 故障排除

| 问题 | 解决方案 |
|------|----------|
| 许可校验失败 | 检查 `~/.lawyer_workflow/license.json` |
| 模板缺失 | 运行 `python scripts/template_setup.py --list` |
| QC 不通过 | 查看 `[FAIL]` 项，修正后重试 |
| 超过试用次数 | 联系马律购买专业版 |
