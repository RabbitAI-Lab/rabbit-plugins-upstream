# QC 质量门控说明

## 质量检查项

| 序号 | 检查项 | 说明 | 失败处理 |
|------|--------|------|----------|
| 1 | 模板来源 | 结构标记/段落数/旧关键词/占位符 | Hard fail |
| 2 | 字体一致性 | 段落内字体统一 | Hard fail |
| 3 | 占位符残留 | 未被替换的【】占位符 | Hard fail |
| 4 | 文本漂移 | 重复信息/异常长段落 | Hard fail |
| 5 | Run完整性 | 多Run文本截断 | Hard fail |
| 6 | 内容骨架 | 必需结构元素是否齐全 | Hard fail |
| 7 | 当事人覆盖 | 所有当事人是否在文书中出现 | Hard fail |

## 执行规则

- 每份文书生成后立即运行 `doc_quality_checker.py`
- exit code != 0 → 硬失败，禁止降级
- 最大重试 3 次
- 3 次后仍失败 → 暂停等待人工介入

## 关键门控节点

- **Step2 后**：全部文书 QC
- **Step6 后**：全案一致性审计（10项）
- **Step7 后**：证据目录 + 代理词 QC
