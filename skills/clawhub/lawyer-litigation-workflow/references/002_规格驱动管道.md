# 规格驱动管道说明

## 管道五阶段

```
read_spec → enforce_spec → generate → narrative_fill → quality_check
```

## 规格文件结构

每个 `{文书}_spec.json` 包含：

- `title`：文书标题
- `immutables`：不可修改元素（标题、法院名称、结尾等）
- `replacements`：占位符→数据源映射
- `narrative_fill`：叙事内容填充配置
- `sections`：章节结构（降级模式使用）

## 模板安全替换

使用 `template_safe_tool.py` 进行 Run 级安全替换：
1. 清空段落所有 Run
2. 写入全文到 Run[0]
3. 校验内容完整性
4. 检查占位符残留

## QC 质量检查

`doc_quality_checker.py` 执行 7 项检查：
1. 模板来源（结构标记/段落数/旧关键词/占位符）
2. 字体一致性
3. 占位符残留
4. 文本漂移
5. 多Run完整性
6. 内容骨架
7. 当事人覆盖

任何一项不通过 → exit 1，禁止降级。
