## Description:

商品精修、去褶皱。随手拍的商品图 → 可直接上架的精修图。当用户说「精修」「去褶皱」「修图」「拍得不好看」「整理一下」时使用。

This skill is ready for commercial/non-commercial use.

## Use Case:

External ecommerce sellers and product photography teams use the skill to retouch product photos for catalog listings. It guides image edits that reduce random wrinkles, improve alignment and lighting, and clean up backgrounds while preserving product details.

### Deployment Geography for Use:

Global

Mitigation: Review the selected provider's data handling before sending images or prompts, and inspect the package content that was not fully analyzed before installation.
