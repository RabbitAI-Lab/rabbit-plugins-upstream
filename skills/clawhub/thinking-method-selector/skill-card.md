## Description:

Selects and applies a fitting thinking method when a user describes a problem or decision without naming a method.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ysskrishna](https://clawhub.ai/user/ysskrishna)

### License/Terms of Use:

MIT-0

## Use Case:

People facing an open-ended decision or problem use this skill to choose and apply one structured thinking method without having to know framework names in advance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad requests to help think through a problem may trigger a structured method when a user prefers to choose a framework themselves.

Mitigation: Review the chosen method with the user and allow them to request a different or explicitly named method.
