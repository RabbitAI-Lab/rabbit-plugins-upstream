## Use Case:

External creators, social media operators, brand marketers, ecommerce teams, and developers use this skill to convert authorized meme references and brand facts into short-video briefs, shot lists, prompts, runnable helper commands, task records, and acceptance checks. It is intended for original brand expression rather than copying protected content or making unsupported product claims.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: AI-HIVE generation calls can upload selected media and create cost-incurring tasks.

Mitigation: Review the final prompt, mode, routing choice, price snapshot, media paths, and budget before approving API calls.

Risk: The helper can store an AI-HIVE API key under the user's home directory.

Mitigation: Use placeholders in examples, avoid committing credentials, and confirm local credential-file permissions before sharing logs or archives.

Risk: Downloaded or edited media may be mistaken for a completed compliant deliverable without review.

Mitigation: Run the acceptance checklist for authorization, platform fit, factual claims, subtitle safe zones, and generated output quality before publishing.
