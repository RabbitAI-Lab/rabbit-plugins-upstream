## Description:

Generate and edit images using Google's Nano Banana 2.1 via WaveSpeed AI. The latest Nano Banana model, with gains in visual design, subject consistency and prompt adherence. Supports text-to-image and editing with up to 14 reference images, 1k / 2k / 4k output, 14 aspect ratios (including 1:4, 4:1, 1:8 and 8:1) and optional web search and image search grounding. Use when the user wants to create images from a prompt or edit and combine existing images with Nano Banana 2.1.

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: Prompts and reference images are uploaded to WaveSpeed for generation or editing.

Mitigation: Use only prompts and images you are comfortable uploading to WaveSpeed.

Risk: Image generation and optional web or image search incur usage charges that vary with settings.

Mitigation: Review current prices and generation settings before submitting a request.

Risk: Account authentication relies on a stored login or an API key.

Mitigation: Keep API keys out of chat and protect the stored login.
