## Use Case: <br>
External users use this skill for Beijing trip planning, relocation, work, compliance, daily-life setup, and long-term residency questions. It helps an agent route requests by visitor, resident, worker, student, or founder context and provide Beijing-specific guidance. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may persist sensitive Beijing context such as family, school, visa, employer, and childcare details in local memory files. <br>
Mitigation: Review and manage ~/Clawic/data/beijing/ before and after use, and avoid storing sensitive details unless the user has clearly provided durable context that should be retained. <br>
