# 车辆过户信息输出格式

支付成功并拿到接口 JSON 后渲染。**仅使用接口返回字段，禁止编造内容。**

## 输出顺序（固定）

```markdown
{过户概要模板}   ← 有 result 时必渲染，排第一

{过户记录明细模板} ← result.data 数组逐条渲染

---
*以上数据来源于第三方数据服务，仅供参考，请以实际车辆登记信息为准。*
```

无过户记录（`result.data` 为空数组）时，输出概要 +「暂无过户记录」提示 + 页脚免责。

---

## 过户概要模板

接口返回 `result` 对象时使用，**固定排在全文最前**。

数据路径：`result.*`（外层 `reason`、`error_code` 不展示给用户）。

### 渲染结构

```markdown
# 🚗 车辆过户信息查询结果

> 🔑 VIN：{data[0].vin 或用户查询的 VIN}

| 项目 | 内容 |
| ---- | ---- |
| 查询单号 | {result.orderid} |
| 过户记录数 | {result.data 数组长度} 条 |
| 总过户次数 | {首条记录的 transTimeSum，若各条一致取该值；否则取最大值} |
```

### 字段映射

| 展示项 | JSON 字段 | 说明 |
| ------ | --------- | ---- |
| VIN 码 | `result.data[].vin` | 17 位车架号；数组为空时用用户输入的 VIN |
| 查询单号 | `result.orderid` | 聚合数据订单号 |
| 过户记录数 | `result.data` 长度 | 数组元素个数 |
| 总过户次数 | `result.data[].transTimeSum` | 数值型，表示总过户次数 |

---

## 过户记录明细模板

遍历 `result.data` 数组，**按 changeMonth 降序**（最新过户在前）逐条渲染。

### 单条记录渲染结构

```markdown
## 过户记录 #{序号}

| 项目 | 内容 |
| ---- | ---- |
| 过户年月 | {changeMonth 格式化} |
| 过户前城市 | {cityBefore，空值显示「—」} |
| 过户后城市 | {cityAfter} |
| 距上次过户 | {transYear} 年 {transMonth} 个月 |
| 累计过户次数 | {transTimeSum} 次 |
| 车架号 | {vin} |
```

### 字段映射

| 展示项 | JSON 字段 | 说明 |
| ------ | --------- | ---- |
| 过户年月 | `changeMonth` | 如 `201508`，格式化为「2015 年 08 月」 |
| 过户前城市 | `cityBefore` | 首次过户可能为空 |
| 过户后城市 | `cityAfter` | 如「荆州市」 |
| 距上次过户（年） | `transYear` | 字符串数字，如 `"6"` |
| 距上次过户（月） | `transMonth` | 字符串数字，如 `"74"` |
| 累计过户次数 | `transTimeSum` | 数值型，如 `1` |
| 车架号 | `vin` | 17 位 VIN |

### changeMonth 格式化规则

| 原始值 | 展示格式 |
| ------ | -------- |
| `201508` | 2015 年 08 月 |
| `202301` | 2023 年 01 月 |

## 渲染规则

1. **概要首位**：有 `result` 时，必须先渲染 [过户概要模板](#过户概要模板)，再渲染明细。
2. **数组遍历**：`result.data` 每条记录独立成节，序号从 1 递增。
3. **排序**：默认按 `changeMonth` 降序；字段缺失时不参与排序比较。
4. **空值处理**：`cityBefore` 等字段缺失、空字符串、`null` 时显示「—」，不填「暂无」；其他可选字段空值跳过该行。
5. **文本清洗**：去除 HTML/script 标签；保留中文标点与换行。
6. **禁止臆造**：不生成接口未返回的过户原因、车主姓名等内容。
7. **页脚免责**（固定追加）：

```markdown
---
*以上数据来源于第三方数据服务，仅供参考，请以实际车辆登记信息为准。*
```
