## Description:

Find pages on your own site competing for the same search with the same intent, and decide per conflict to merge, differentiate, canonicalize, de-optimize or leave it, with evidence. Use for "are my pages cannibalizing each other", "two pages ranking for the same keyword", or "Google keeps switching which page ranks".

This skill is ready for commercial/non-commercial use.

## Use Case:

SEO practitioners and site owners use this skill to identify genuine query and intent overlap between their pages, review Search Console and search-result evidence, and choose an appropriate action for each conflict.
