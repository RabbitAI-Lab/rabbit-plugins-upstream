## Description:

Create a new Claude Code skill by scaffolding a properly structured SKILL.md with YAML frontmatter, trigger-rich description, workflow, examples, and anti-patterns, placing it in the appropriate skill location, and updating the library README when applicable.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dennisrongo](https://clawhub.ai/user/dennisrongo)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent-skill authors use this skill to turn recurring workflows or explicit skill-authoring requests into Claude Code skill files with clear trigger rules, examples, and anti-patterns. It is useful when creating project-scoped, global, or library-published skills.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A globally installed generated skill can affect future Claude Code sessions beyond the current project.

Mitigation: Review generated SKILL.md content before broad use and prefer project-scoped targets unless the behavior is intended for every session.
