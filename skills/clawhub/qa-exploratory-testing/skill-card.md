## Description:

This skill guides QA practitioners through time-boxed, charter-based exploratory testing to find issues scripted test cases may miss and record session notes, findings, bug reports, and coverage notes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kokxi](https://clawhub.ai/user/kokxi)

### License/Terms of Use:

MIT-0

## Use Case:

QA testers, developers, and product teams use this skill to plan focused exploratory sessions for new or under-tested features, using SBTM charters, tours, role play, failure paths, and structured notes to turn discoveries into test cases and bug reports.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Exploratory testing inputs may include sensitive production, customer, identity, payment, or screenshot data.

Mitigation: Use scoped test inputs and sanitize or mask sensitive data before sharing it with the agent.

Risk: The referenced full-skill-set install command would add skills beyond this artifact.

Mitigation: Review the full-skill-set install command and included skills before running it.

Risk: Exploratory findings can be hard to reproduce if session context is incomplete.

Mitigation: Record the charter, environment, operation sequence, observations, and supporting screenshots or logs for each finding.
