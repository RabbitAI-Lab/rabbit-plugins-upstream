# 算法备案与合规实操指南

---

## 一、算法备案实操流程

### 1. 备案入口
- **官方平台**：互联网信息服务算法备案系统
- **网址**：https://beian.cac.gov.cn

### 2. 须备案的对象
具有舆论属性或者社会动员能力的以下服务提供者：
- 算法推荐服务提供者（个性化推送、排序精选、检索过滤、调度决策等）
- 深度合成服务提供者和技术支持者
- 生成式 AI 服务提供者
- 拟人化互动服务提供者

### 3. 备案时限
| 事项 | 时限要求 |
|------|----------|
| 首次备案 | 提供服务之日起10个工作日内 |
| 信息变更 | 变更之日起10个工作日内 |
| 注销备案 | 终止服务之日起20个工作日内 |

### 4. 备案所需材料
1. **服务提供者信息**：名称、统一社会信用代码、联系人等
2. **服务形式**：APP、网站、小程序等
3. **应用领域**：新闻资讯、电子商务、社交网络等
4. **算法类型**：生成合成类、个性化推送类、排序精选类、检索过滤类、调度决策类
5. **算法自评估报告**：包括算法基本原理、数据使用情况、安全评估情况、风险防控措施等
6. **拟公示内容**：算法基本原理、目的意图和主要运行机制等

### 5. 备案流程
```
准备材料 → 登录备案系统 → 填报信息 → 提交材料 → 等待审核
→ 审核通过（30个工作日内）→ 获取备案编号 → 公示备案编号
→ 完成备案
```

### 6. 备案后义务
- 在网站/APP显著位置标明备案编号并提供公示信息链接
- 信息变更须及时办理变更备案
- 终止服务须办理注销备案
- 配合网信部门的年度核验（拟人化互动服务）

## 二、安全评估实操指南

### 1. 须开展安全评估的情形

| 情形 | 法规依据 |
|------|----------|
| 上线具有舆论属性或社会动员能力的生成式 AI 服务 | 《生成式AI办法》第17条 |
| 上线具有舆论属性或社会动员能力的算法推荐服务 | 《算法推荐规定》第27条 |
| 提供人脸/人声生成编辑功能的深度合成服务 | 《深度合成规定》第15条 |
| 开发上线具有舆论属性或社会动员能力的新产品/新应用/新功能 | 《深度合成规定》第20条 |
| 上线拟人化互动服务或增设相关功能 | 《拟人化互动办法》第22条 |
| 注册用户100万以上或月活10万以上的拟人化互动服务 | 《拟人化互动办法》第22条 |
| 使用新技术导致拟人化互动服务发生重大变化 | 《拟人化互动办法》第22条 |

### 2. 安全评估内容

#### 生成式 AI 服务安全评估重点
- 训练数据来源合法性、规模、类型、标注规则
- 算法机制机理说明
- 内容安全措施（违法内容识别、处置能力）
- 用户权益保护措施
- 数据安全和个人信息保护措施
- 应急处置能力

#### 深度合成安全评估重点
- 生成合成类算法机制机理
- 训练数据安全管理
- 内容标识措施
- 人脸/人声等生物识别信息保护
- 违法和不良信息识别能力

#### 拟人化互动安全评估重点
- 安全保障措施建设情况
- 训练数据处理情况
- 用户极端情境识别、应急处置、干预管理
- 用户规模、使用时长、年龄结构
- 未成年人、老年人保护措施
- 投诉举报受理处置情况

### 3. 安全评估方式
- 自行开展安全评估
- 委托专业机构开展安全评估
- 评估报告须提交至所在地省级网信部门（拟人化互动服务）

## 三、AI 内容标识实操指南

### 1. 显式标识实施

#### 文本内容
- 在文本起始位置添加"以下内容由人工智能生成"等文字提示
- 或在文本末尾添加"本内容为AI生成"等标识
- 或在交互场景界面添加显著的提示标识

#### 图片内容
- 在图片角落或适当位置添加"AI生成"水印
- 水印须清晰可辨，不被轻易裁剪

#### 音频内容
- 在音频起始位置添加语音提示"以下内容为人工智能合成"
- 或添加音频节奏提示

#### 视频内容
- 在视频起始画面添加"AI生成"显著标识
- 在视频播放界面的周边添加提示标识

#### 虚拟场景
- 在进入虚拟场景时显示"本场景由AI生成"提示

### 2. 隐式标识实施
- 在文件元数据（如 EXIF、XMP 等）中嵌入以下信息：
  - 生成合成内容属性信息（标识为 AI 生成）
  - 服务提供者名称或编码
  - 内容编号
- 鼓励添加数字水印（可见水印和不可见水印结合）

### 3. 传播平台核验流程
```
用户上传内容 → 平台核验文件元数据
├── 检测到隐式标识 → 在内容周边添加"该内容为AI生成"提示标识
├── 未检测到隐式标识 + 用户声明为AI生成 → 添加"该内容可能为AI生成"提示标识
├── 未检测到隐式标识 + 用户未声明 + 检测到生成痕迹 → 添加"该内容疑似为AI生成"提示标识
└── 未检测到 + 用户未声明 + 无痕迹 → 正常发布
```

## 四、个人信息保护影响评估实操

### 1. 须进行评估的情形
- 处理敏感个人信息
- 利用 AI 进行自动化决策
- 向境外提供个人信息
- 其他对个人权益有重大影响的个人信息处理活动

### 2. 评估内容
1. 个人信息的处理目的、处理方式等是否合法、正当、必要
2. 对个人权益的影响及安全风险
3. 所采取的保护措施是否合法、有效并与风险程度相适应

### 3. 评估报告保存
- 评估报告和处理情况记录须至少保存3年
- 处理目的、方式变化或发生重大安全事件时须重新评估

## 五、伦理审查实操流程

### 1. 设立审查委员会
- 单位须设立科技伦理审查委员会
- 委员会成员须包括相关领域专家
- 制定伦理审查制度和操作规程

### 2. 审查流程
```
AI 项目立项 → 提交伦理审查申请 → 委员会审查
├── 通过 → 项目继续 → 持续跟踪管理
├── 修改后通过 → 修改后继续 → 持续跟踪管理
└── 不通过 → 终止/修改项目
```

### 3. 审查要点
- 数据来源合法性和合规性
- 算法公平性和非歧视性
- 隐私保护措施有效性
- 安全防护措施充分性
- 透明度和可解释性
- 用户权益保护机制
- 未成年人保护措施
- 应急处置预案完备性

## 六、人脸识别合规实操

### 1. 合规使用条件
- 具有特定的目的和充分的必要性
- 采取对个人权益影响最小的方式
- 取得个人单独同意
- 提供替代验证方式（不得作为唯一方式）

### 2. 禁止行为清单
- 不得在私密空间（宾馆客房、浴室、更衣室、卫生间）安装人脸识别设备
- 不得以办理业务等为由误导、欺诈、胁迫个人接受人脸识别
- 不得通过互联网对外传输人脸信息（除非取得单独同意）
- 不得将人脸识别作为唯一验证方式（存在替代方案时）

### 3. 备案要求
- 人脸信息存储达10万人之日起30个工作日内备案
- 备案材料：基本情况、处理目的和方式、存储数量和安全措施、处理规则、保护影响评估报告

### 4. 技术安全措施
- 数据加密
- 安全审计
- 访问控制
- 授权管理
- 入侵检测和防御
- 网络安全等级保护（如适用）
