## Description:

Helps plan multi-agent work by assigning roles and defining allowed and prohibited activities for each agent.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zhaoxinghua09-cell](https://clawhub.ai/user/zhaoxinghua09-cell)

### License/Terms of Use:

MIT (code only); documentation and theory: all rights reserved

## Use Case:

Developers and teams use this skill to divide larger tasks among agents, clarify responsibilities, and review proposed permission boundaries before delegating work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A proposed role boundary could be mistaken for an enforced permission restriction.

Mitigation: Review each role's actual permissions and keep agent spawning or delegation under explicit user control.

Risk: Readers may assume the code license also permits redistribution of the documentation and theory.

Mitigation: Review the bundled license and obtain appropriate rights before reusing documentation or theory text.
