## Description:

Helps plan multi-agent work by assigning roles and defining each agent's permitted and forbidden tasks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zhaoxinghua09-cell](https://clawhub.ai/user/zhaoxinghua09-cell)

### License/Terms of Use:

## Use Case:

Developers and teams use this skill to divide larger tasks among agents, assign roles, and define boundaries that reduce overlapping work and unauthorized actions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The listing and artifact state different code licenses, while documentation and theory reserve rights.

Mitigation: Review the applicable terms before redistributing documentation or code.

Risk: A suggested plan could be mistaken for permission to execute agent actions.

Mitigation: Treat the plan as advisory; obtain user approval before spawning agents, writing files, or using external sources.
