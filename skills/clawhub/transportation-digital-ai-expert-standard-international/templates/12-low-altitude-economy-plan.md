## 6. UTM Platform Design

### 6.1 Positioning

The UTM (UAS Traffic Management) platform is the "air-traffic-management system" of the low-altitude economy — safe, efficient multi-operator, multi-type, multi-mission operations.

### 6.2 Functional Architecture

| Domain | Module | Description |
|--------|--------|-------------|
| **Registration** | Drone / operator / pilot registration | Interface with national CAA UAS registry |
| **Airspace mgmt** | Airspace designate & publish, use apply/approve, dynamic adjust | Geo-fence publish |
| **Flight plan** | Plan file/approve, conflict detect, optimize | Multi-operator coordination |
| **Surveillance** | Real-time tracking, replay, breach/deviation alert | Remote ID + radar + ADS-B |
| **Conflict mgmt** | Predict & resolve conflicts, priority (emergency > passenger > delivery > inspection) | Separation keeping |
| **Flow mgmt** | Route capacity, peak throttling, delay mgmt | Like ATM flow management |
| **Info service** | Weather (low-altitude), geo (obstacle DB), NOTAM | Unified publish |
| **Emergency response** | Crash / lost-link / intrusion fast response, auto-lock no-fly | Link with police / emergency |
| **Ops statistics** | Flights / hours / distance, efficiency analysis | Data-driven mgmt |
