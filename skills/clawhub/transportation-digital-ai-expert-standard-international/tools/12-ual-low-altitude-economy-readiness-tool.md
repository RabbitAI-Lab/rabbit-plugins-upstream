# Low-Altitude Economy (UAM) Digital-Readiness Assessment Tool

> This tool assesses the digital-infrastructure readiness of a city / region for the low-altitude economy (urban air mobility, drone logistics, and related services). It covers five dimensions—policy & regulation, infrastructure, market demand, technology capability, and organizational support—with 30 indicators, plus a UTM platform functional checklist, vertiport siting standards, an investment-estimation model, and an implementation roadmap.

> Currency note: all investments below are in USD (illustrative conversion 1 RMB ≈ $0.14). Adjust to local currency and market conditions.

## 2. UTM Platform Functional Checklist (32 Items)

### 2.1 Airspace Management (8)
- [ ] 1. Airspace grid management (dynamic split / merge / release)
- [ ] 2. Geofence management (permanent / temporary / dynamic)
- [ ] 3. Route planning (auto-avoidance + multi-constraint optimization)
- [ ] 4. Route approval (online apply → auto-review → instant approve)
- [ ] 5. Airspace capacity management (real-time load + flow control)
- [ ] 6. Special-airspace coordination (interface with ATC systems)
- [ ] 7. Conflict detection & resolution (4D trajectory prediction + alert)
- [ ] 8. Temporary no-fly management (rapid setup for events / incidents)

### 2.2 Flight Monitoring (8)
- [ ] 9. Real-time position monitoring (GNSS + 4G/5G return)
- [ ] 10. Flight-status monitoring (alt / speed / heading / battery / signal)
- [ ] 11. Remote ID broadcast + query
- [ ] 12. Trajectory replay (history query + anomaly analysis)
- [ ] 13. Geofence alert (approach / breach instant alert)
- [ ] 14. Aircraft health monitoring (battery / motor / comms / sensors)
- [ ] 15. Live video return (optional, inspection / security)
- [ ] 16. Multi-aircraft coordinated monitoring

### 2.3 Dispatch & Coordination (8)
- [ ] 17. Flight-plan management (file → review → approve → fly → close)
- [ ] 18. Dynamic priority dispatch (medical / fire rescue first)
- [ ] 19. Multi-operator coordination (conflict avoidance across operators)
- [ ] 20. Vertiport scheduling (slot allocation + conflict resolution)
- [ ] 21. Ground-support dispatch (charge / load / maintain windows)
- [ ] 22. Adverse-weather response (auto-adjust for storm / high wind / low vis)
- [ ] 23. Emergency return / divert guidance (auto-plan on fault / low battery)
- [ ] 24. Mission efficiency analysis (completion / timeliness / cost)

### 2.4 Safety & Compliance (8)
- [ ] 25. Pre-flight safety risk scoring + decision support
- [ ] 26. Incident / event reporting (mandatory + auto-generated + closed loop)
- [ ] 27. Operator qualification mgmt (license / medical / training / log)
- [ ] 28. Aircraft airworthiness mgmt (cert / maintenance / mod records)
- [ ] 29. Insurance mgmt (third-party liability + hull + cargo)
- [ ] 30. Data security (encryption + privacy + data classification)
- [ ] 31. Audit & compliance reporting (ops log + safety report + regulator filings)
- [ ] 32. Cybersecurity (identity + access control + intrusion detection + ISO 27001 / NIS2)

## 5. 30-Item Regulatory & Compliance Checklist

### 5.1 Aviation Authority Compliance (e.g., CAAC / EASA / FAA)

- [ ] 1. UAS real-name registration (all aircraft registered on UOM platform)
- [ ] 2. Operating certification (operator holds air operator certificate)
- [ ] 3. Pilot qualifications (valid remote-pilot license / certificate)
- [ ] 4. Airworthiness (aircraft passes airworthiness check / cert)
- [ ] 5. Flight-plan filing (filed per regulations)
- [ ] 6. Flight-record retention (data / logs retained per rules)
- [ ] 7. Incident / event reporting (unsafe events reported within 24 h)
- [ ] 8. UTM platform filing (UTM filed with authority)

### 5.2 Airspace & Safety Management

- [ ] 9. Airspace-use approval (airspace used with approval)
- [ ] 10. No-fly-zone avoidance (avoid published no-fly zones)
- [ ] 11. Temporary no-fly compliance (obey during major events)
- [ ] 12. Altitude-limit compliance (respect altitude-layer limits)
- [ ] 13. VLOS / BVLOS rules (comply with visual / beyond-visual rules)
- [ ] 14. Night-flight permit (special approval for night ops)

### 5.3 Local-Authority Compliance

- [ ] 15. Project filing (filed with local investment authority)
- [ ] 16. Environmental assessment (EIA required for construction)
- [ ] 17. Land / planning permit (vertiport needs land-use permit)
- [ ] 18. Fire-safety approval (vertiport / hangar fire approval)
- [ ] 19. Special-equipment mgmt (chargers / storage reported)
- [ ] 20. Noise-emission compliance (meets local noise standards)
- [ ] 21. Public-safety protection (public-safety notice + safeguards)

### 5.4 Public-Safety Compliance

- [ ] 22. Mass-event security permit (security plan for public events)
- [ ] 23. Dangerous-goods transport (special approval if applicable)
- [ ] 24. Personal-data protection (GDPR / CCPA-style consent for face / location)
- [ ] 25. Video-surveillance mgmt (public-area video filed / registered)

### 5.5 Data & Cybersecurity

- [ ] 26. Data-security law compliance (classification + protection)
- [ ] 27. Personal-data protection (notice-consent + data minimization)
- [ ] 28. Cybersecurity graded protection (UTM via ISO 27001 / NIS2)
- [ ] 29. Critical-infrastructure protection (NIS2 if designated)
- [ ] 30. Data residency / localization (flight & location data stored locally)

## 6. Four-Phase Implementation Roadmap

| Phase | Time | Core Tasks | Milestone |
|:---:|:---:|------|------|
| **Phase 1** Pilot First | 0–12 mo | Strategy + 1–2 vertiports + UTM V1.0 + 2–3 trial routes + 1 operator | First route approved & operating |
| **Phase 2** Infrastructure Build | 12–24 mo | 5–10 vertiports + private comms + surveillance radar + UTM V2.0 + 3–5 operators | City low-altitude network taking shape |
| **Phase 3** Scale Operations | 24–36 mo | 20+ vertiports + full surveillance + city-level UTM + 10+ operators + 8+ routine routes | Daily flights >100 |
| **Phase 4** Ecosystem Flourish | 36–60 mo | 50+ vertiports + city-cluster coordination + "low-altitude brain" + 20+ operators + full chain | Low-altitude economy cluster formed |

---

> **Usage advice:** This assessment should be led by the low-altitude-economy authority, jointly completed with airspace management, aviation, industry & IT, transport, and traffic-management agencies. Re-assess every 12 months to track progress. Results can support benchmark-zone applications and public-investment decisions.
