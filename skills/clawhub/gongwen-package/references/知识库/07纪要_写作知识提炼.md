# 07纪要写作知识提炼

## 一、标题写法


**（一）常规式标题。** 这是最基础、最常用的形式，具体又分三种：一是“会议名称＋纪要”，如《全国农村工作会议纪要》；二是“召开机关＋内容＋纪要”，如《省经贸委关于企业扭亏会议纪要》；三是“会议名称＋纪要内容＋纪要”，如《××市人民政府关于安全生产工作的会议纪要》。这类标题直接点明会议性质和纪要类型，简洁规范，一目了然。


**（三）通知型会议纪要的标题处理。** 通知型会议纪要有特定版式，可不再另设标题；指示性会议纪要的标题则需显示会议名称或中心内容。


## 二、开头写法



**（二）固定起首语式开头。** 不做过多的背景铺垫，直接以“会议听取了”“会议讨论了”“会议审议了”等固定起首语进入议题，简洁明了，直奔主题。这种方式适用于议题明确、内容聚焦的会议。

**（三）会议记录式开头。** 逐项分行排列会议组织情况，包括时间、地点、出席人、缺席人、列席人、主持人、记录员、议题八项内容，须在会议开始前填好。这种方式适用于会议记录，而非严格意义上的纪要，但可作为纪要起草的基础素材。



## 三、主体结构




**（三）议题展开方式。** 按会议议题顺序展开，每个议题用“会议听取了”“会议讨论了”“会议审议了”等起首语引出，随后用“会议强调”“会议指出”“会议决定”等表述语引出具体内容，层次分明。每个议题需挖掘背景信息、决策依据和涉事要素，如拨款议题须写明谁拨款、拨给谁、何时拨、项目名称、款额度，确保纪要能丰满准确地重现历史，经得起检验。

**（四）会议记录式主体。** 按议题顺序记录，每个议题前加序号，每位发言人发言另起一行，先写姓名加冒号再记内容。决议分条列出，有表决程序的记录表决方式和结果，争议问题记录焦点及各方观点。尾部另起一行写散会及时间，由主持人和记录人签名。


## 四、写作技巧

**（一）会前准备。** 做到三个弄清：弄清会议目的、弄清与会各方最终达成什么共识、弄清会议相关材料的核心要义。会前熟悉议题、研读材料，防备汇报人脱稿，腾出精力记录和领会领导意见。




**（五）语言风格。** 多用祈使句，句子简短，“要”字句是常见句式，格式为“执行单位＋要＋执行内容”。可学习领导善用排比句式的风格，在基于处理问题前提下增强表达力度。注重规避敏感用语和风险话题，符合领导身份、会议角色站位和法律法规。


**（七）能力提升。** 起草后认真对比初稿与修改稿，分析修改原因，归纳写作规律，通过对比反思提升能力。起草后需对比反思、核实数据、逐级修改，确保不漏事项、不错数据、无病句。
