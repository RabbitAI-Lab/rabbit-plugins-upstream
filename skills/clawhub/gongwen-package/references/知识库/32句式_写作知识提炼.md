# 32句式写作知识提炼

## 一、标题写法

公文标题如同文章的眼睛，既要准确传神，又要简洁醒目。最常用的标题模式是"直述型"结构，即直接点明文章主题与适用范围，让读者一眼便知文章所讲何事、适用于何种场景。例如"公文写作语言词句运用要点"这一标题，即采用"主题词+适用范围+文体属性"的组合方式，既交代了论述对象（语言词句运用），又限定了讨论边界（公文写作），还明确了文体性质（要点），三者兼备，干净利落。此类标题的写作要领在于：主题词要精准，适用范围要清晰，文体属性要恰当，切忌含混笼统、大而无当。

## 二、开头写法


- **形美**：句式结构匀称和谐，长短搭配错落有致，读来朗朗上口。
- **情真**：情感表达真挚自然，既不矫揉造作，也不冷漠生硬。


## 三、主体结构


以短句选用为例，可按字数分为八字句、十字句等类别；以句式框架为例，可按功能分为收尾句、过渡句、排比句等类型。这种层层递进、逐类展开的结构方式，使文章脉络清晰、条理分明，读者既可通篇通读，也可按需查阅。各板块之间既相对独立，又彼此呼应，共同服务于"提升公文写作水平"这一总目标。

## 四、写作技巧

### 1. 短句的段位布局

短句置于段首，可奠定基调、统领全段，如旗帜般引导读者把握段落要旨；置于文末，可收束有力、余味悠长，如钟声般留下回响。无论置于何处，都须与上下文意脉贯通，切忌生硬嵌入、前后脱节。
