# 24倡议写作知识提炼

## 一、标题写法


1. **极简式**：直接以“倡议书”三字为题，适用于倡议对象明确、内容单一的场景，简洁庄重。
2. **内容嵌入式**：将倡议的核心事项或目标群体嵌入标题，如“文明上网倡议书”“全民阅读倡议书”，使读者一眼即知倡议主旨。
3. **主副结合式**：主标题以凝练有力的语句点明主题，副标题交代场合或对象，如“让壮丽青春在创业大潮中奔涌激荡——在全区庆‘五一’、迎‘五四’表彰大会上的讲话”。此式适用于规格较高、场合正式的倡议。

无论采用何种形式，标题都应做到准确、醒目、有感召力，避免冗长含糊。

2. **三段式**：开头说明背景，中间阐明理由（可分条列述，每条先讲道理再举实例），结尾提出倡议事项并以呼吁性语言收束。若涉及规则设计，还需从多个角度论证目的、明确约束措施，并坦诚回应可能的质疑。
3. **总分条陈式**：主体分条阐述，用“一、二、三”结构，每段设对仗工整的小标题。每条内部遵循“明确精神内涵→结合本地实际→提出具体要求→引用典型事例佐证”的逻辑链条，结尾发出号召、首尾呼应、升华主题。

## 四、写作技巧

- 按作者角度和传播角度对倡议书进行分类，根据场景选择最合适的写法。
- 规则执行要有约束措施，明确违规行为及处罚方式，让规则可落地。
- 大量使用四字短语和排比句，增强气势和节奏感。
- 联系本地发展定位，增强针对性；照顾各层面分头部署。
- 使用“以优质丰富的内容和喜闻乐见的形式”等对偶短语，增强节奏感。
- 把握分寸，不说过头话，不提过高要求，不用过激言词。
- 语言精炼，切忌拖泥带水、废话连篇、东拉西扯、不得要领。
- 突出主体作用，强调收信人或相关群体的主体地位，如“青年是未来和希望”。
