Developers and engineers use this skill to build and adapt shadcn/ui components with Radix primitives, Tailwind styling, CVA variants, compound component patterns, and related CLI commands. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Documented shadcn CLI commands can modify a project in the wrong location if run from an unintended working directory. <br>
Mitigation: Confirm the app root before running commands and use the documented cwd option when the shell is elsewhere. <br>
Risk: Using overwrite or broad component-add commands can replace or add many project files. <br>
Mitigation: Review version-control diffs before and after CLI execution, especially when using --overwrite or adding many components. <br>
