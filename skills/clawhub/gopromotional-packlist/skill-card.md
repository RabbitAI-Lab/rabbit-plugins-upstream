## Description:

Create packing checklists from templates (work day, travel, trade show, gym) with per-night quantities, save them as Markdown, tick items off and see what is left. Use when someone is packing for a trip, an exhibition or the gym, or asks what they have forgotten.

This skill is ready for commercial/non-commercial use.

## Use Case:

Travelers, event exhibitors, gym-goers, and other people preparing to pack use the skill to create checklist files from templates, adjust quantities by trip length, and track items packed.

Global

Mitigation: Review and pin the package version before running it, and use a folder containing only the intended checklists.
