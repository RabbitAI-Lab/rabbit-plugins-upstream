## Description:

Use when an OpenClaw, LobeHub, or Hermes assistant encounters user corrections, failed commands or tools, outdated knowledge, missing capabilities, recurring mistakes, or a verified better approach, and before tasks where past lessons may matter. Prefer this skill whenever durable, reusable rules can improve future performance.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and assistant users can use this skill with OpenClaw, LobeHub, or Hermes to find relevant lessons, turn verified experience into concise reusable rules, and apply and refine those rules across recurring tasks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may cause the skill to activate for a wide range of tasks.

Mitigation: Review the trigger wording before installation and narrow it if broad activation is not desired.
