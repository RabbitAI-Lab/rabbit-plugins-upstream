## 搜索工作流程详解

### 阶段一：平台搜索

1. 打开甘肃省公共资源交易网 → 交易公告 → 地区选张掖 → 时间选当月 → 关键词搜索
2. 打开张掖市公共资源交易中心 → 浏览近期公告 → 按标题筛选信息化项目
3. 打开甘肃政府采购网 → 地区选张掖 → 日期当月 → 关键词搜索
4. 打开中国政府采购网 → 地区选甘肃-张掖 → 日期当月 → 关键词搜索
5. 其他平台按需补充

### 阶段二：搜索引擎补充

使用在线搜索工具搜索关键词组合，逐一访问结果判断有效性。

### 阶段三：信息提取与去重

1. 对每条有效公告提取15个字段
2. 与Excel已有记录比对（按项目编号+项目名称去重），跳过已录入项目
3. 按招标公告发布日期排序

### 阶段四：逐条填入Excel

1. 用 openpyxl 打开目标文件
2. 找到已有数据末尾行（序号列最大值+1）
3. 逐行追加新记录
4. 保存文件
