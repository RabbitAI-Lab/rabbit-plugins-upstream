# 视频生成 Playbook

> 解决「文生视频 / 图生视频 / 视频生视频怎么选、用什么工具、怎么控参数、怎么后处理」的执行链路，子技能 `video-generation` / `video-editing` 的落地方法论。
> 增量信息：生成路线决策树 + 工具对比矩阵 + 参数速查 + 踩坑表 + 交付清单。

## 1. 生成路线决策树

```
要做视频？
├─ 只有文字描述 → 文生视频（text2video）
│   └─ 素材要求高/需要品牌一致性 → 先文生图，再图生视频（更可控）
├─ 已有图片/产品图 → 图生视频（image2video）
│   └─ 图片是静态产品 → 加运镜（pan/zoom/rotate）指令增强动感
├─ 已有视频 → 视频生视频（video2video，风格迁移/重绘）
├─ 需要角色口型说话 → 数字人口播（专属工具，见下）
└─ 需要精确镜头语言 → 分段生成 + 剪辑拼接（一次生成整段长视频质量不可控）
```

**核心原则**：视频生成的可控性远低于图像生成。**一次生成 3-8 秒短片，多段拼接**是质量最优解；一次文生 30 秒以上长视频，动作/逻辑一致性大概率崩。

## 2. 工具对比矩阵（2026-08 实测信号）

| 路线 | 工具 | 成本 | 强项 | 弱项 |
|------|------|------|------|------|
| ComfyUI 本地 | AnimateDiff / LTX-Video 节点 | 免费（吃显存） | 可控、可复现 | 环境门槛高、速度慢 |
| 云端 ComfyUI | RunComfy（runcomfy-agent-skills） | 按量 | 免部署、skills.sh 生态最大安装量 | 云端排队、API 依赖 |
| 商业 API | Google Veo 3.1（veo-tools） | 按量 | 画质/动作一致性顶尖 | 需 GCP 配置、成本高 |
| 商业 API | MiniMax H3（cablate） | 按量 | 中文友好、速度快 | 细节一致性一般 |
| 商业 API | LTX-2（cineclaw） | 按量 | 图生视频/音生视频全能 | 生态较新 |
| 数字人口播 | HeyGen（heygen video-edit） | 订阅 | 口型/表情成熟 | 偏营销场景 |

**选型原则**：个人/小团队按「成本敏感 → 本地 ComfyUI；速度敏感 → MiniMax；质量敏感且有预算 → Veo」排序。不要同时接 3 家 API——先固定一家跑通全链路再扩。

## 3. 参数速查（以 ComfyUI 视频节点 / 通用 API 为基线）

| 参数 | 典型值 | 说明 |
|------|--------|------|
| frames | 16-49 | 帧数越多时长越长，质量与显存压力同步上升 |
| fps | 8-16 | 生成端 fps 不必高，交付时插帧/补帧 |
| width/height | 与模型训练尺寸一致 | 视频模型对非训练尺寸更敏感，宁小勿大 |
| CFG | 4-7 | 视频模型 CFG 过高 → 闪烁/伪影 |
| motion scale | 按工具 | 控制运动强度；小运动 → 更稳定 |
| seed | 固定 | 视频生成不稳定，seed 复现尤其重要 |
| denoise（图生视频） | 0.6-0.85 | 太高 → 偏离原图；太低 → 几乎不动 |

**踩坑 1**：fps 与 frames 的关系——`时长 = frames / fps`。要 4 秒 @16fps = 64 帧，不要靠把 fps 拉到 60 来"提速"，那是误解。
**踩坑 2**：图生视频的输入图分辨率必须匹配模型要求；直接传大图会崩或裁切。

## 4. 后处理与交付链路

```
生成 3-8 秒片段 ──→ 片段质检（闪烁/崩坏/首尾帧）──→ 剪辑拼接 ──→ 配乐/字幕
                        │                          │
                        └── 坏片段重生成（修 prompt/seed，不硬救）
```

- 片段质检：首帧、中段、尾帧各抽 1 帧目检；循环素材检查首尾帧能否无缝
- 拼接：用 [scripts/media_batch.py](../scripts/media_batch.py) 或 ffmpeg concat；同参数片段可直接 concat
- 交付：B 站/抖音横竖屏比例在生成时定，别后裁（裁掉构图）

## 5. 常见踩坑表

| 现象 | 根因 | 处置 |
|------|------|------|
| 画面闪烁/抖动 | CFG 过高、fps 与模型不匹配 | CFG 降到 ≤7；检查模型建议 fps |
| 主体变形漂移 | 时长过长 | 拆 3-8 秒片段；固定 seed |
| 图生视频不动 | denoise 过低 | 提到 0.7+；或 motion 参数 |
| 首尾帧断裂 | 未做循环处理 | 加循环节点/工具或剪辑时做转场 |
| 人物崩脸 | 视频模型一致性格外差 | 图生视频优于文生视频；多试 seed |
| 云端排队久 | 高峰期 | 错峰；本地 ComfyUI 备用 |

## 6. 交付清单

- [ ] 路线选择有依据（文生/图生/视频生），非盲目尝试
- [ ] 片段 ≤8 秒，多段拼接而非一次长视频
- [ ] frames/fps 换算正确，分辨率匹配模型
- [ ] 每片段 seed 记录可复现
- [ ] 坏片段重生成而非硬救
- [ ] 输出比例（横/竖）在生成时定好，交付格式统一（MP4 H.264）
