## 范本清单

范本清单与索引。用于内容轴**样本法**。

内容轴样本法执行流程：
1. 获取样本（本文件索引指向的子文件或用户提供）
2. 分析样本四维度：结构、风格、逻辑、格式
3. 整理为「样本特征摘要」
4. 模仿产出（保持结构框架和风格，替换内容）

> **使用说明**：七个域范本文件均已实配（一域一本，覆盖域内全部任务），标注 `[可用]` 的条目可直接使用样本法。范本子文件与本索引文件同级平铺存放（不建子目录），命名 `CWC{域号}-{域名}范本.md`；范本内容已脱敏，使用时仅借鉴结构与风格，严禁复制内容。CWC1 范本中的连接器市场内容为任务示范样本（快照基线 139 个，采集自公开连接器市场），实际执行必须实时检索。

### 范本标准格式模板

用户补充范本或新生成范本时，按以下标准格式填写（占位符 `________` 为待填内容，不可编造）：

```
## CWC{域号} {域名}范本

### CWC{域号}-{序号} {任务类型}范本

**输入**：________

**步骤**：
1. ________
2. ________
3. ________

**输出**：________

**范本要点**：
- ________
- ________
```

### 用户填充指南

用户向本技能添加范本时：

1. **脱敏**：移除所有敏感信息（连接器私有配置、个人信息、商业机密），用占位符替换
2. **存放**：将范本文件放入 `references/` 目录（与范本索引文件同级存放，不建子目录），一域一本、编号对齐域号命名（如 `CWC5-守护校验域范本.md`）
3. **注册**：在本文件对应条目中更新范本路径和状态
4. **特征摘要**：为每个范本撰写四维分析（结构、风格、逻辑、格式）
