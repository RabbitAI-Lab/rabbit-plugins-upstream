## CWC5 守护校验域范本

> **素材声明**：本范本示范中的连接器均取自 CWC1 范本快照（139 个）中真实存在的连接器；示范对象为"每日销售日报"组合方案（L2 路由，基元链见 CWC3 范本），依次走三道门。仅作任务示范，实际执行以实时扫描结果为准。

### CWC5-01 组合方案可行性校验范本

**场景**：CWC3-02 基元链定型后，进入第一道门。

**输入**：定稿基元链；CWC1 市场扫描结果；CWC2-02 匹配映射表。

**执行过程**：
1. 连接器存在性核对：有赞、小裂变 SCRM 均在 CWC1-02 分类展示表内；
2. 能力覆盖核对：取数/处理/交付/产出四段各有归属；
3. 衔接核对：上游输出＝下游输入（订单明细→汇总数据→日报文本→执行摘要）；
4. 层次落地核对：L2 所需定时触发与固定数据源齐备；
5. 输出校验结果表。

**产出**（校验结果表示范）：

| 校验项 | 结果 | 说明 |
|--------|------|------|
| 连接器存在性 | PASS | 有赞、小裂变 SCRM 均在市场扫描清单中 |
| 能力覆盖 | PASS | 取数（有赞）、处理（会话内）、交付（小裂变 SCRM）、产出（对话内）各有归属 |
| 数据接口衔接 | PASS | 步骤 1 输出＝步骤 2 输入；步骤 2 输出＝步骤 3 输入；步骤 3 输出＝步骤 4 输入 |
| 层次可落地性 | PASS | L2：每日定时触发、数据源固定、无人值守 |

**FAIL 分支示范**：若交付段连接器不具备群发能力，则"能力覆盖"FAIL——方案退回 CWC3-02 更换交付段连接器（候选：3Chat 私域客户运营）后重新过门，不得带伤下传。

**校验点**：
- 任一项不通过即 FAIL，方案退回 CWC3 修改
- 修复后须重新过本道门

### CWC5-02 风险识别与确认守护范本

**场景**：第一道门 PASS 后，识别风险并取得写入确认。

**输入**：基元链逐步骤读写类型标注；CWC2-03 授权核对表。

**执行过程**：
1. 逐步骤扫描读写类型：步骤 3（小裂变 SCRM 群发）为写入；
2. 风险分级（写入/隐私/资金/不可逆）；
3. 写入类操作逐项向用户确认并留存记录；
4. 授权缺失项引导（本示范无缺失；缺失时按 CWC2-03 引导动作执行）。

**产出**（风险与确认报告示范）：

| 风险项 | 类型 | 等级 | 确认状态 |
|--------|------|------|---------|
| 企微客户群群发日报（小裂变 SCRM） | 写入 | 中 | 已确认（用户对话内明确回复"确认创建群发任务"，记录可追溯） |
| 示例店铺销售数据读取（有赞） | 隐私 | 低 | 只读，无需确认；数据仅用于本次汇总，不外传 |
| 资金类操作 | 资金 | — | 本方案无此类操作 |

**写入操作多样示范**（两阶段确认场景）：若交付段改用慧獭进销存"销售采购开单"类写入操作，则确认守护同样适用——先向用户展示开单内容明细，取得明确同意后再执行提交，确认记录可追溯；确认动作分"内容预览确认"与"执行同意"两步向用户呈现，避免误操作。

**授权前置提示**（转自 CWC2-03）：小裂变 SCRM 须先完成企微授权。

**校验点**：
- 写入类操作必须先经用户明确确认，确认记录可追溯
- 只读优先原则在替代方案能力等价时适用（本示范取数/处理均为只读）
- 授权缺失即引导，严禁虚构能力或绕过授权

### CWC5-03 方案定稿检查范本

**场景**：第二道门 PASS 后，定稿检查。

**输入**：按 templates/workflow-plan-template.md 填充的方案；CWC5-01/02 记录；CWC3-01 路由判定。

**执行过程**：
1. 模板字段完整性检查：对照模板 1~9 节逐节核对（L2 方案第 4 节调度配置必填）；
2. 确认记录检查：写入确认与创建确认记录齐备且可追溯；
3. 与 CWC3-01 路由判定一致性检查：方案落地层次与路由判定一致；
4. 依赖引用有效性检查：引用的连接器、模板路径均真实存在；
5. 全部通过即定稿。

**产出**（定稿检查单示范）：

| 检查项 | 结果 | 说明 |
|--------|------|------|
| 模板字段完整 | PASS | 模板 1~9 节逐节填充；第 4 节调度配置含循环规则 FREQ=DAILY;BYHOUR=9;BYMINUTE=0 |
| 确认记录齐备 | PASS | 写入确认（群发）与创建确认（自动化）记录可追溯 |
| 层次路由一致 | PASS | 方案落地层次 L2 与 CWC3-01 路由判定一致 |
| 依赖引用有效 | PASS | 有赞、小裂变 SCRM 均存在于市场扫描清单；模板路径真实存在 |

**定稿版本号**：1.0.0（首次定稿）。三道门全 PASS，允许进入 CWC3-04 落地执行。

**校验点**：
- 检查单全 PASS 才允许进入 CWC3-03/CWC3-04/CWC3-05 落地执行
- 任一 FAIL 退回对应任务修复后复检
