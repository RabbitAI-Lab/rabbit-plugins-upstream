## 任务清单与依赖拓扑

按执行链路组织的连接器工作流编排任务清单，附任务间关系和元操作映射提示。

**域间逻辑流**：CWC0（任务协调）→ CWC1 / CWC2 / CWC4（市场发现、需求解析、灵感生成三入口并列）→ CWC3（工作流组合）→ CWC5（守护校验）→ CWC6（深化）。三条典型全链路：①需求驱动——CWC0-01 → CWC1 → CWC2 → CWC3 → CWC5 → 落地；②灵感驱动——CWC0-01 → CWC4 → CWC3 → CWC5 → 落地（用户采纳灵感后）；③市场更新——CWC1（重扫）→ CWC6-02 → CWC6-03。守护三道门（CWC5-01/02/03）固定串联在组合与落地之间。

### 依赖拓扑摘要

以下为连接器工作流编排任务的主要依赖链路，执行框架可据此自动编排管线：

#### 一、域内链路

**任务协调链路**: CWC0-01 → CWC0-02 → CWC0-03
**市场发现链路**: CWC1-01 → CWC1-02 → CWC1-03
**需求解析链路**: CWC2-01 → CWC2-02 → CWC2-03
**工作流组合链路**: CWC3-01 → CWC3-02 → CWC3-03 / CWC3-04 / CWC3-05（三层落地互斥，由 CWC3-01 路由决定）
**灵感生成链路**: CWC4-01 → CWC4-02 → CWC4-03
**守护校验链路**: CWC5-01 → CWC5-02 → CWC5-03（三道门固定串联）
**深化链路**: CWC6-01；CWC6-02（市场触发，独立成线）；CWC6-03 ← CWC6-01 / CWC6-02

#### 二、跨域协同链路

**需求驱动主链路**: CWC0-01 → CWC2-01 → CWC2-02 → CWC3-01 → CWC3-02 → CWC5-01 → CWC5-02 → CWC5-03 → CWC3-03 / CWC3-04 → CWC0-03
**灵感驱动链路**: CWC0-01 → CWC4-01 → CWC4-02 → CWC4-03 → CWC3-01（用户采纳灵感后进入组合）→ CWC3-02 → CWC5 → 落地
**市场查询链路**: CWC0-01 → CWC1-01 → CWC1-02 → CWC1-03
**守护贯穿**: CWC5-01/02/03 固定位于 CWC3-02 与 CWC3-03/CWC3-04/CWC3-05 之间，任何组合方案不得绕过
**市场更新链路**: CWC1-01（重扫）→ CWC6-02 → CWC6-03

#### 三、路由链路

- CWC0-01 → CWC1-01（市场查询）
- CWC0-01 → CWC2-01（需求驱动组合）
- CWC0-01 → CWC4-01（灵感浏览）
- CWC0-01 → CWC6-01（方案迭代）
- CWC0-01 → CWC6-02（市场更新适配）
