# 发型知识参考

## 脸型分类与特征

### 圆脸
- **特征**: 脸长和脸宽接近，下巴圆润，脸颊饱满
- **目标**: 拉长脸型，增加线条感，避免让脸看起来更圆
- **适合**: 侧分、高颅顶、有层次感的长发/中长发、锁骨发、八字刘海、偏分长刘海
- **避免**: 齐刘海、贴头皮直发、耳上超短发、中分无层次

### 方脸
- **特征**: 下颌骨明显，额头、颧骨、下颌宽度接近，线条硬朗
- **目标**: 柔化下颌线条，增加顶部蓬松感
- **适合**: 波浪卷发、侧分长刘海、层次感中长发、八字刘海、S卷、蓬松短发
- **避免**: 齐下巴直线 Bob、贴脸直发、超短精灵头

### 长脸
- **特征**: 脸长明显大于脸宽，额头或下巴较长
- **目标**: 横向拉宽视觉效果，缩短脸长
- **适合**: 空气刘海、法式刘海、横向蓬松的卷发、齐肩发、中长发、波浪卷
- **避免**: 高马尾、长直发中分、顶部过高的发型、超短发

### 椭圆脸 (鹅蛋脸)
- **特征**: 额头略宽于下巴，脸长约为脸宽的1.5倍，线条柔和
- **目标**: 几乎百搭，可尝试多种风格
- **适合**: 几乎所有发型，Bob头、大波浪、空气刘海、中分、侧分均可
- **注意**: 根据五官特点微调，如额头高可加刘海

### 心形脸
- **特征**: 额头宽，颧骨高，下巴尖
- **目标**: 平衡额头宽度，柔和下巴线条
- **适合**: 侧分、长刘海、下巴附近长度的 Bob、波浪中长发、空气刘海
- **避免**: 顶部过高蓬松、眉上短刘海

### 菱形脸
- **特征**: 颧骨最宽，额头和下巴较窄
- **目标**: 柔和颧骨线条，增加额头和下巴的视觉宽度
- **适合**: 侧分、层次感长发、八字刘海、下巴附近的卷发
- **避免**: 贴脸直发、超短发、强调颧骨的发型

## 男性专属发型指南

### 男性脸型与发型速查

#### 圆脸（男性）
- **目标**: 拉长脸型，增加顶部高度，弱化圆润感
- **适合**: 侧分油头、Undercut、飞机头、短寸渐变、纹理烫（顶部蓬松）
- **避免**: 齐刘海、两侧过于蓬松、蘑菇头、圆寸（会让脸更圆）
- **关键**: 顶部要有高度和纹理，两侧收紧（Taper Fade / 渐变）

#### 方脸（男性）
- **目标**: 柔化硬朗线条，避免过于方正
- **适合**: 侧分短发、纹理刘海、微卷中短发、经典油头（Pompadour）、微长鬓角
- **避免**: 极短平头、两侧全剃光的 High Fade、过于整齐的几何线条
- **关键**: 用纹理和长度中和硬朗感，鬓角留一点长度更自然

#### 长脸（男性）
- **目标**: 横向拉宽，缩短脸长视觉
- **适合**: 法式纹理刘海、两侧保留厚度的短发、中分微卷、平刘海、碎盖头
- **避免**: 顶部过高的飞机头、大背头、两侧剃太光的 High Fade、露额发型
- **关键**: 额头需要遮挡（刘海），两侧不能太薄，避免一切"拉高"视觉的发型

#### 椭圆脸（男性）
- **目标**: 百搭，根据气质和职业选择
- **适合**: 几乎所有男士发型，从极短寸头到中长纹理发均可驾驭
- **推荐**: 经典侧分、纹理短发、韩式微卷、美式渐变

#### 心形脸（男性）
- **目标**: 平衡宽额头，柔和尖下巴
- **适合**: 侧分刘海、碎盖、两侧渐变 + 顶部纹理、中长发微卷
- **避免**: 全露额头的大背头、顶部过高造型
- **关键**: 额头需要部分遮挡，下巴附近留一点长度增加分量感

#### 菱形脸（男性）
- **目标**: 柔和颧骨线条，增加额头和下巴视觉宽度
- **适合**: 两侧保留厚度的中短发、碎发、纹理烫、微长刘海
- **避免**: 两侧剃光的极短发型、贴头皮直发、露额全背头
- **关键**: 两侧一定要有头发，不能剃太光；头顶蓬松增加额头宽度

| 发型名称 | 描述 | 适合场景 |

| **飞机头 / Quiff** | 顶部向上向前抓出纹理 | 年轻潮流、休闲、增加身高感 |

| ** Afro / 爆炸头** | 自然卷蓬松造型 | 黑人发质、个性鲜明 |
| **Dreadlocks / 脏辫** | 辫子造型 | 街头文化、音乐人风格 |

### 男性发际线与发量问题

| 问题 | 适合发型 | 避免 |
|------|---------|------|
| **M型脱发/发际线后移** | 侧分纹理、碎盖头、法式刘海、顶部蓬松转移注意力 | 全露额头的大背头、齐刘海（会暴露发际线） |
| **头顶稀疏** | 寸头（减少对比）、纹理烫增加蓬松、短发减少重量拉扯 | 长发梳背、中分长发、贴头皮造型 |
| **发量少/细软** | 纹理烫、韩式碎盖、短发造型 | 长发、厚重造型、贴头皮直发 |
| **发量多/粗硬** | 渐变短发、油头、背头、有重量的造型 | 蓬松爆炸头、不打理的自然状态 |
| **自然卷/沙发** | 利用卷度的中长纹理发、渐变短发、柔顺处理后造型 | 强行梳直、中分长直发 |

### 男性风格场景

| 场景 | 推荐发型 | 要点 |
|------|---------|------|
| **职场/商务** | 侧分短发、经典油头、圆寸、Taper Fade | 整洁、利落、不过于个性 |
| **约会/社交** | 纹理刘海、韩式微卷、碎盖头、Pompadour | 自然、有亲和力、显年轻 |
| **运动/户外** | 寸头、短碎发、Fade、Crew Cut | 低维护、出汗不粘 |
| **潮流/街头** | Undercut、狼尾、纹理烫、中长发 | 有个性、能打理 |
| **文艺/复古** | 中长发、油头、微卷、自然碎发 | 随性、有质感 |

### 与 Barber / Tony 的沟通要点（男性版）

1. **说长度不说"短一点"**:
   - 顶部：用厘米或手指宽度（"顶部留 5-8cm" / "大概三指宽"）
   - 两侧：用 Fade 等级或手指宽度（"两侧渐变到 0.5mm" / "两侧推短，不要露头皮"）

2. **明确渐变类型**:
   - **Low Fade**: 渐变从耳朵上方开始，最保守
   - **Mid Fade**: 渐变从太阳穴开始，最百搭
   - **High Fade**: 渐变从额头侧面开始，最潮最利落
   - **Taper**: 自然过渡，不想要明显渐变时说这个

3. **顶部纹理需求**:
   - "顶部剪出层次，方便抓纹理"
   - "顶部不要打薄太多，我要烫纹理"
   - "顶部稍微碎一点，自然垂落"

4. **刘海/额头处理**:
   - "刘海留到眉毛，碎一点"
   - "我要能盖住额头的刘海"（M型脱发适用）
   - "全部向后梳，露出额头"（发际线好适用）

5. **带参考图**: 找 2-3 张同发质/同脸型的参考图，比口头描述准得多

6. **问清维护**: 
   - 剪发周期（通常 2-4 周）
   - 是否需要发蜡/发泥/发油，以及怎么用
   - 是否需要烫发配合

### 发质
| 发质 | 适合发型 | 注意事项 |
|------|---------|---------|
| 细软发 | 短发、层次感、烫卷增加蓬松 | 避免过长过重，会贴头皮 |
| 粗硬发 | 直发、大卷、有重量的发型 | 注意毛躁管理，适合柔顺处理 |
| 自然卷 | 中长发、利用卷度做造型 | 需要定期护理，避免打薄过度 |
| 沙发 | 层次感、柔顺烫、锁骨发 | 重点在柔顺，避免无序膨胀 |

### 发量
| 发量 | 适合发型 | 注意事项 |
|------|---------|---------|
| 发量多 | 厚重感发型、大波浪、层次打薄 | 可驾驭长发，需要定期打薄 |
| 发量少 | 短发、蓬松烫、高颅顶造型 | 避免过长，善用烫发增加视觉发量 |
| 正常 | 灵活，按脸型和风格选择 | — |

## 发型术语与剪法

### 基础剪法
- **层次剪 (Layer Cut)**: 头发长度由短到长逐层过渡，增加蓬松感和动感
- **打薄 (Thinning/Texturizing)**: 减少发量，让发型更轻盈，适合发量多的人
- **滑剪 (Slide Cutting)**: 剪刀斜向滑动剪切，创造柔和边缘
- **点剪 (Point Cutting)**: 剪刀垂直发梢点剪，打造自然碎发效果

### 刘海类型
- **空气刘海**: 薄透、内卷，适合额头高或长脸
- **八字刘海**: 中间短两侧长，自然分开呈八字，百搭修脸型
- **法式刘海**: 厚重随意，带自然空隙，适合椭圆脸和方脸
- **齐刘海**: 平齐厚重，适合椭圆脸、长脸
- **侧分长刘海**: 从一侧分过来，长度到颧骨或下巴，修脸型效果最强
- **眉上刘海**: 短于眉毛，个性鲜明，适合五官立体的人

### 经典发型
- **Bob (波波头)**: 下巴到肩膀长度的直发或微卷发，经典百搭
- **Lob (长波波头)**: 肩膀到锁骨长度，比 Bob 更随性
- **Pixie Cut (精灵短发)**: 耳上超短发，利落个性，考验五官
- **Shag (层次碎发)**: 多层碎发，摇滚随性风格
- **Curtain Bangs + Layers**: 中分八字刘海配层次，近年流行
- **Undercut (侧削)**: 两侧或后脑勺剃短，顶部留长，个性鲜明

## 年龄与风格考量

- **职场/正式**: 整洁的中长发、Bob、低层次短发，颜色以自然色为主
- **休闲/随性**: 层次感长发、自然波浪、法式刘海
- **个性/前卫**: 短发、挑染、不对称设计、Undercut
- **减龄**: 空气刘海、锁骨发、微卷、浅色系挑染

## 与 Tony 老师的沟通要点

1. **带参考图**: 找到目标发型的清晰照片
2. **描述发质**: 告知自己的发质、发量、日常打理时间
3. **说明需求**: 强调想要修饰的部位（如"我想让脸看起来小一点"）
4. **询问维护**: 了解需要多久的修剪周期、是否需要烫发/染发配合
5. **确认长度**: 用具体位置描述（如"到锁骨""下巴下两指"），避免"短一点"的模糊表达
