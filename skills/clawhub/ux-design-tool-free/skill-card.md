## Description: <br>
Helps individual developers and small teams apply UX design principles for flow analysis, mental-model alignment, friction reduction, progressive disclosure, feedback design, error prevention, cognitive load, boundary states, and basic accessibility. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[thcjp](https://clawhub.ai/user/thcjp) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and small teams use this skill to review product flows, forms, empty states, error handling, feedback, and accessibility basics when they do not have dedicated UX design support. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The release requests command execution and file-write permissions that the security evidence says its Markdown guidance does not need. <br>
Mitigation: Review the skill before installation and ask the publisher to remove those permissions or clearly document when they are required. <br>
Risk: Callback URL values or network diagnostic commands could create unintended outbound behavior in the current workspace. <br>
Mitigation: Do not provide callback_url values or allow network diagnostic commands unless that behavior is explicitly intended. <br>
