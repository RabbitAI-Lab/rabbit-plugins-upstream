## Description:

ExhibitDay (exhibitday.com). Use this skill for ANY ExhibitDay request — reading, creating, updating, and deleting data. Whenever a task involves ExhibitDay, use this skill instead of calling the API directly.

This skill is ready for commercial/non-commercial use.

## Use Case:

People managing events and event tasks use the skill to read, create, update, and delete ExhibitDay records through their connected ExhibitDay account.

## Known Risks and Mitigations:

Risk: Setup may execute downloaded code that has not been verified.

Mitigation: Review and install a verified CLI release yourself before enabling automatic setup; the remote installers and hosted connector implementation have not been verified.

Risk: Create, update, and delete actions can change or permanently remove ExhibitDay data.

Mitigation: Keep the skill's confirmation requirements for changes and deletions, and confirm the target and exact effect before proceeding.
