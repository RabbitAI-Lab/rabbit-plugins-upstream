This skill is ready for commercial/non-commercial use.

## Use Case:

Creators and marketing teams use this skill to turn product sites, scripts, or briefs into branded launch videos, including feature reveals and site showcases.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Unpinned HyperFrames commands may fetch updated packages or registry components.

Mitigation: Trust the package and registry before installation, and prefer a pinned or locked HyperFrames version.

Risk: The workflow may update globally installed skills and start a background preview service.

Mitigation: Run it in a project-scoped sandbox and review updates and preview-service activity.

Risk: Media and voice tools may inherit local API credentials.

Mitigation: Expose only the media and API credentials needed for the project.
