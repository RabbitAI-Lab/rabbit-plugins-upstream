# 중국 여행 팁

## 설명

중국 여행을 위한 올인원 여행 동반자. 이 스킬은 외국인 여행자를 위해 5가지 강력한 기능을 제공합니다:

1. **여행 조언** — 비자, 결제, 교통, 음식, 안전, 문화에 대한 답변 받기
2. **호텔 검색** — 실시간 요금, 평점, 예약 링크로 호텔 찾기
3. **항공권 검색** — 중국행/중국발/중국 내 항공편을 실시간 요금으로 검색
4. **관광지 티켓** — 티켓 요금, 영업 시간으로 관광명소 발견
5. **여행 플랜** — 맞춤화된複数日の 여행 계획 생성

## 데이터 흐름 및 개인정보 보호

사용자 쿼리는 안전한 프록시 서버(SCF)로 전송되며, 인증 토큰이 주입되어 TripGenie API로 전달됩니다. 프록시는 제휴 링크 생성을 자동으로 처리합니다. 사용자 개인 정보는 저장되거나 기록되지 않습니다. 모든 통신은 HTTPS로 암호화됩니다.

## 사용할 때

- 중국 여행에 대한 일반적인 질문
- 모바일 결제 앱(Alipay, WeChat Pay) 설정 방법
- 비자 요건 및 입국 정책
- 교통 팁 (기차, 지하철, 택시)
- 언어 및 커뮤니케이션 조언
- 음식 및 식사 문화
- 날씨 및 짐 싸기 팁
- 안전 및 비상 정보
- 문화 매너 및 관습

키워드: 중국 여행 팁, 중국 방문, 중국 비자, Alipay 설정, 중국 교통, 중국 음식, 여행 조언, 중국 안전, 중국 매너

## 실행

### 1단계: 사용자의 질문 파악

사용자 쿼리에서 여행 질문을 추출합니다.

### 2단계: 스크립트 실행

```bash
python scripts/china_travel.py tips "<question>" --locale=ko
```

**중요:** 항상 `--locale=ko` 매개변수를 포함하여 한국어 결과를 받아주세요.

### 3단계: 결과 표시

API는 중국을 방문하는 외국인 여행자의 필요에 맞게 한국어로 상세하고 실용적인 답변을 반환합니다. 내용을 직접 사용자에게 표시합니다.

## 예시

**사용자:** "중국에서 Alipay를 어떻게 설정해?"
```bash
python scripts/china_travel.py tips "외국인 여행자로서 중국에서 Alipay를 어떻게 설정하면 되나요?" --locale=ko
```

**사용자:** "중국 방문에 비자가 필요해?"
```bash
python scripts/china_travel.py tips "중국 방문 시 비자 요건은 무엇인가요?" --locale=ko
```

**사용자:** "중국에서 신용카드를 사용할 수 있어?"
```bash
python scripts/china_travel.py tips "외국인 여행자가 중국에서 신용카드를 사용할 수 있나요? 사용 가능한 결제 방법은 무엇인가요?" --locale=ko
```

## 기타 사용 가능한 기능

이 스킬은 다음도 지원합니다:
- `hotel` — 중국 호텔 검색 및 예약
- `flight` — 중국행/중국발/중국 내 항공권 검색
- `attraction` — 관광명소 및 티켓 요금 검색
- `itinerary` —複数日の 여행 계획 생성

## 주의사항

- 모든 답변은 한국어로, 외국인 여행자에 맞게 조정됩니다
- 정보는 중국 방문을 위한 실용적이고 최신의 조언을 포함합니다
- 예약 링크는 Trip.com (국제판)으로 직접 이동합니다
