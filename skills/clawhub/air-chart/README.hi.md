## यह स्किल क्या करती है?

अपने AI चैट में एक वाक्य कहिए — और यह **स्टेशन खोजता है, डेटा लाता है और चार्ट लिंक थमा देता है** — [x-cmd Draw](https://x-cmd.com/draw) द्वारा, डेटा और चार्ट एक ही URL में:

> 💬 "बीजिंग के पिछले एक हफ्ते का PM2.5 रुझान दिखाओ"
> 💬 "टोक्यो और सियोल की पिछले 7 दिनों की एयर क्वालिटी की तुलना करो"
> 💬 "नई दिल्ली में 30 दिन का PM10, WHO मार्गदर्शन के साथ"
> 💬 "सिंगापुर में पिछले 48 घंटों का हर घंटे ओज़ोन"
> 💬 "बीजिंग में अभी कौन-सा स्टेशन सबसे खराब है?"

पर्दे के पीछे पूरी तरह स्वचालित पाइपलाइन: शहर को पहचानना → **OpenAQ** से **सचमुच सक्रिय** स्टेशन चुनना (100+ देशों का सरकारी रेफरेंस-ग्रेड डेटा) → आउटलायर और रिक्तियों की सफाई → प्रोफेशनल चार्ट रेंडर करना।

**यह क्यों पसंद आएगा:**

- **चार्ट एक URL है — URL ही डेटा है** — डिफ़ॉल्ट रूप से आपको एक `x-cmd.com/draw` लिंक मिलता है जो चार्ट रेंडर भी करता है और उसमें हर मान भी रखता है। उसे साझा करें, Markdown में इमेज की तरह डालें, या URL में कोई संख्या बदलें — चार्ट तुरंत अपडेट हो जाता है। फ़ाइल चाहिए? `--out chart.svg` (या `.png`) उसे डाउनलोड कर देता है।
- **x-cmd Draw द्वारा रेंडरिंग** — आपकी लोकल पाइपलाइन शुद्ध `bash`/`jq`/`awk`/`curl` रहती है; चार्ट इंजन [x-cmd Draw](https://x-cmd.com/draw) है, तो आपको चार्ट प्रकारों की बढ़ती लाइब्रेरी (लाइन, बार, एरिया, पाई, रडार, गेज, सैंकी, गैंट, माइंड मैप और अधिक), लाइट/डार्क थीम, बहुभाषी रेंडरिंग, ऑनलाइन एडिटर मिलते हैं — रखरखाव का कोई रेंडरर कोड शून्य।
- **डिज़ाइन से भरोसेमंद** — सरकारी रेफरेंस-ग्रेड स्टेशनों को प्राथमिकता; चार्ट भौतिक सांद्रता (µg/m³) दिखाते हैं और **WHO 24-घंटा मार्गदर्शन** को रेफरेंस श्रृंखला के रूप में ओवरले करते हैं — सीमा डेटा के साथ चलती है। यह कोई दिखावटी AQI संख्या नहीं — रिपोर्ट में डालने लायक डेटा।
- **वैश्विक कवरेज, लचीला इनपुट** — 250+ शहरों के अंतर्निर्मित निर्देशांक; फ़ज़ी नाम (`delhi`, `tOKyo`, `中山`) सीधे चल जाते हैं, और कच्चे `lat,lon` भी मान्य हैं।
- **असली डेटा, खिलौना नहीं** — चुप «ज़ॉम्बी» स्टेशन और सेंसर-खराबी के स्पाइक हटाए जाते हैं; गायब घंटे एक्सिस से छूट जाते हैं, कभी 0 से भरे नहीं जाते।

## विशेषताएं

- **शून्य भारी निर्भरताएं** — शुद्ध `bash` / `jq` / `awk` / `curl`; SVG रेंडरर awk में लिखा है।
- **वैश्विक कवरेज** — 200+ प्रमुख शहरों के अंतर्निर्मित निर्देशांक, या सीधे `lat,lon` पास करें।
- **स्मार्ट स्टेशन चयन** — 25 किमी त्रिज्या खोज → 24 घंटे से साइलेंट «ज़ॉम्बी» स्टेशन छाँट (72 घंटे फ़ॉलबैक) → सरकारी रेफरेंस-ग्रेड मॉनिटरों को प्राथमिकता।
- **प्रोफेशनल विज़ुअल** — भौतिक सांद्रता इकाइयाँ (µg/m³) साफ़ लेबल, डिफ़ॉल्ट में WHO 24-घंटा मार्गदर्शन रेखा (अनुपालन पर हरी, उल्लंघन पर लाल), लाइट/डार्क थीम।
- **वास्तविक उपयोग के लिए इंजीनियरिंग** — लोकल कैश (घंटावार डेटा 20 मिनट / दैनिक 2 घंटे), HTTP 429 पर घातांकीय बैकऑफ़, अंतर-सजग रेंडरिंग (रिक्ति लाइन तोड़ती है — कभी 0 नहीं), UTC → स्टेशन-स्थानीय समय संरेखण।

## शुरुआत

### 1. API कुंजी लें (मुफ़्त, ~1 मिनट)

1. [OpenAQ Explorer](https://explore.openaq.org/register) पर रजिस्टर करें या लॉग इन करें (मौजूदा खाता: [लॉग इन](https://explore.openaq.org/login))।
2. अपना [खाता पेज](https://explore.openaq.org/account) खोलें — नीचे आपकी API कुंजी दिखती है; उसे कॉपी करें।
3. इसे कॉन्फ़िगर करें — एक चुनें:

```bash
export OPENAQ_API_KEY="your_key"                             # ephemeral / CI
echo 'OPENAQ_API_KEY=your_key' > ~/.config/air-chart/config  # persistent
```

सिस्टम कीचेन ज़रूरी नहीं — मुफ़्त सार्वजनिक सेवा क्रेडेंशियल सादे टेक्स्ट कॉन्फ़िग फ़ाइल में रहता है। कुंजी के बिना भी `--demo` मोड नमूना डेटा से सब रेंडर करता है।

### 2. चलाएं

```bash
# एक शहर, 7-दिन PM2.5 रुझान
./scripts/air_chart.sh --city Beijing --param pm25 --period 7d

# बहु-शहर तुलना (अधिकतम 4 शहर)
./scripts/air_chart.sh --city Tokyo --city Seoul --param pm25 --period 7d

# एक शहर, बहु-पैरामीटर (PM2.5 + PM10)
./scripts/air_chart.sh --city Beijing --param pm25 --param pm10 --period 30d

# 48-घंटे की घंटावार कर्व (दिन/रात पैटर्न)
./scripts/air_chart.sh --city Singapore --param o3 --period 48h

# स्टेशनों का रियल-टाइम बार-चार्ट स्नैपशॉट
./scripts/air_chart.sh --city Delhi --param pm10 --snapshot

# डार्क थीम, कस्टम आउटपुट
./scripts/air_chart.sh --city London --param no2 --period 14d --theme dark -o london.svg
```

### 3. AI एजेंट स्किल के रूप में इंस्टॉल करें

```bash
git clone https://github.com/qiakai/air-chart.git ~/.claude/skills/air-chart
# or: npx skills add qiakai/air-chart
```

फिर अपने एजेंट से कहें: *«टोक्यो और सियोल के पिछले 7 दिनों का PM2.5 तुलना करो।»*

`SKILL.md` चौड़ी एजेंट/रजिस्ट्री संगतता के लिए अंग्रेज़ी में है; चीनी संस्करण `SKILL.zh.md` पर है। चार्ट आउटपुट `--lang en|zh|es|hi|ja|ko|fr` सपोर्ट करता है (डिफ़ॉल्ट: सिस्टम लोकेल से ऑटो-डिटेक्ट)।

## CLI संदर्भ

| Flag | Description | Values |
| --- | --- | --- |
| `--city, -c` | शहर का नाम (दोहराने योग्य, ≤4) या निर्देशांक `"lat,lon"` | `Beijing`, `New Delhi`, `39.9,116.4` |
| `--param, -p` | प्रदूषक (डिफ़ॉल्ट `pm25`) | `pm25` `pm10` `o3` `no2` `so2` `co` |
| `--period, -t` | समय सीमा (डिफ़ॉल्ट `7d`) | `24h` `48h` (घंटावार) · `7d` `14d` `30d` (दैनिक) |
| `--snapshot` | शहर के सक्रिय स्टेशनों का बार-चार्ट स्नैपशॉट | flag |
| `--theme` | रंग थीम | `light` / `dark` |
| `--lang` | आउटपुट भाषा (चार्ट + संदेश) | `en` `zh` `es` `hi` `ja` `ko` `fr` (डिफ़ॉल्ट: लोकेल से ऑटो-डिटेक्ट) |
| `--out, -o` | चार्ट को `.svg` या `.png` डाउनलोड करें | डिफ़ॉल्ट: सिर्फ़ x-cmd Draw URL प्रिंट करें |
| `--demo` | डेमो मोड, API कुंजी नहीं चाहिए | flag |

## आर्किटेक्चर

```text
[city / pollutant / time range]
   │
   ▼
geo_resolve.sh      city name → coordinates + timezone (built-in gazetteer / raw lat,lon)
   │
   ▼
openaq_client.sh    OpenAQ API v3: auth, User-Agent, md5 cache,
                    429 exponential backoff, liveness filter (24h/72h),
                    sensor match by fixed parameter ID, reference-grade first
   │
   ▼
data_transform.awk  cleaning (negatives / physically impossible spikes),
                    gap detection (breaks, never zero-filled), stats, local-time labels
   │
   ▼
render_draw.sh      x-cmd Draw URL builder (URL-as-Data; optional .svg/.png download)
```

`data/parameters.tsv` openaq-api के स्थिर प्रदूषक ID से संरेखित स्थिर पैरामीटर शब्दकोश है: slug / param_id / नाम / इकाई / WHO 24-घंटा मार्गदर्शन / भौतिक सीमा / प्रति-पैरामीटर रंग — बिना अतिरिक्त `/parameters` राउंड-ट्रिप। विज़ुअल openaq-explorer परिपाटी का पालन करते हैं: प्रति-पैरामीटर पैलेट (PM2.5 `#E65100`, PM10 `#6A1B9A`, O3 `#0277BD`, NO2 `#00838F`), कलाब्लाइंड-अनुकूल बहु-शहर पैलेट, और सुरक्षा-हरी `#10B981` / अलर्ट-लाल `#EF4444` WHO मार्गदर्शन रेखा। यदि कोई स्टेशन शब्दकोश की डिफ़ॉल्ट से भिन्न इकाइयाँ रिपोर्ट करे (जैसे ppm), Y-अक्ष वास्तविक इकाइयों का उपयोग करता है और WHO रेखा आयामी भ्रम से बचने के लिए दबा दी जाती है।
