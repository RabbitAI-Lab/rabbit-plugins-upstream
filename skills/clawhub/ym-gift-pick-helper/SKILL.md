# 礼物决策助手 (ym-gift-pick-helper)

按关系、预算、已知偏好与禁忌，给 3 个有差异的具体方案（实用/体验/纪念），每个带理由、购买提示、风险与备选，而不是丢一堆通用清单让你自己挑。

## 何时使用

- 用户说「送什么礼物」「选个礼物」「礼物推荐」「送礼建议」时
- 用户说「给领导送什么」「送爸妈什么好」「送男朋友/女朋友什么」时
- 用户说「不知道送啥」「有没有合适的」时

## 运行前提

- 依赖：无第三方依赖，纯文本处理
- 不联网、不上传，不提供商品链接与实时价格
- 不读取任何本地文件，除非用户明确给出路径

## 输入契约

| 项 | 必需 | 说明 |
|---|---|---|
| 收礼人关系 | 必需 | 伴侣 / 父母 / 朋友 / 同事 / 领导 / 孩子 / 老师 等 |
| 预算 | 必需（缺则给三档让用户选） | 用于筛方案；缺时先给三档不猜 |
| 已知偏好 | 可选 | 爱好、在追的东西、生活习惯（如爱喝茶、喝咖啡） |
| 已知禁忌 | 可选 | 不喝酒、不用香水、对某物过敏等，硬性排除 |
| 送礼场合 | 可选 | 生日 / 节日 / 乔迁 / 感谢 / 商务 |
| 体面或实用倾向 | 可选 | 是否需要「拿得出手」或「天天用得到」 |

**缺失处理：**

- 缺预算 → 先给三档（100 以内 / 300 左右 / 800 以上）让用户选，绝不自行猜一个
- 缺偏好 → 先给 3~5 个方向让用户挑，再细化，不硬推
- 信息过少且用户不愿补充 → 给「通用安全选项」并明确标注「未个性化」
- 缺场合 → 默认按「心意表达」处理，关系分寸仍按关系判定

## 执行步骤

1. **定调** — 先写清这次送礼的原则：不同关系分寸不同（送领导避免过于私人、送伴侣重用心、送同事避免过于贵重造成压力、送长辈重实用与体面）。这一步写在输出最前，约束后面方案。

2. **过滤禁忌** — 先套 `references/relationship-rules.md` 的默认排除清单：贴身衣物、明显涉及身材外貌的物品、药品保健品、刀具钟表等有文化忌讳的、过于私人的物品，一律排除并写原因。用户明确提到的禁忌优先于一切。

3. **给 3 个有差异的方案** — 必须覆盖三个取向且不重复同类：
   - 实用向：能日常用上
   - 体验向：一次体验/活动/课程/演出
   - 纪念向：有纪念意义、可留存的物品
   每个方案写：具体礼物 / 价格区间 / 为什么适合（结合关系+偏好）/ 去哪买或怎么选 / 风险与避坑。

4. **每个方案给备选** — 写「如果买不到/断货/超预算」的替代礼物，仍符合该方案取向。

5. **预算与分寸校验** — 任一方案超预算太多则剔除或降级；商务/领导场景提示合规风险（金额是否触线、对象是否合适收礼）。

6. **最多 3 个追问** — 只问能快速改变推荐结果的问题（如「平时喝咖啡吗」「有没有在追的剧/游戏」「更想要实用还是惊喜」），不堆问题。

7. **给赠送话术** — 一句得体表达，避免「随便买的」「不知道你喜欢什么」这类减分话。

8. **硬约束自检** — 不超预算、不编造品牌与价格（只给区间）、不推荐三无产品、不涉及拆白金/红包等不当场景；凡专业人员项参照排除清单。

## 输出格式

Markdown，套用 `templates/gift-template.md`：

```
一、这次送礼的原则（关系 + 场合 + 分寸）
二、三个方案
  方案 A（实用向）：具体礼物 / 价格区间 / 为什么适合 / 购买提示 / 风险与避坑 / 备选
  方案 B（体验向）：……
  方案 C（纪念向）：……
三、已排除项与原因（禁忌 + 默认排除清单命中项）
四、追问（最多 3 个）
五、赠送话术
```

## 能力边界

- 不提供真实商品链接与实时价格（价格随渠道变动，只给区间）
- 不编造品牌、型号、价格；不推荐三无或来路不明产品
- 不下单、不代买
- 不做商务合规判定（只提示合规风险，最终以对方单位制度为准）
- 不解决送礼的人际关系难题，只给礼物层面的建议

## 常见坑

1. **缺预算硬猜** — 现象：用户没说预算，直接给「500 块的……」。原因：想尽快出结果。规避：缺预算先给三档让用户选，不替用户定档。
2. **三个方案撞车** — 现象：三个都是杯子/都是实用小物，无差异。原因：没锁定「实用/体验/纪念」三取向。规避：出方案前先分好三取向，互相不重复类别。
3. **忽略禁忌** — 现象：用户说「不喝酒」仍推酒。原因：没把禁忌当硬过滤。规避：先跑排除清单再出方案，命中项写原因并移除。
4. **踩文化忌讳** — 现象：给长辈送钟、给同事送刀。原因：忘了默认排除清单。规避：刀具钟表/伞/梨等按关系与文化习惯默认排除并说明原因。
5. **商务场景不提示合规** — 现象：直接推「送领导 2000 块的礼」。原因：当普通送礼处理。规避：领导/商务场景必带合规风险提示（金额、对象、单位制度）。
6. **编造价格品牌** — 现象：写「XX 牌 299 元官方价」。原因：想显得具体。规避：只给区间（如「200~400 元」），品牌只引用用户已知或市场常见，不编具体型号与报价。

## 验收用例

- 正常：「送领导，500 左右，喝茶」→ 三方案（含茶具/茶体验/纪念茶罐）+ 排除项 + 话术 + 商务合规提示
- 边界 1：无预算 → 先给三档让用户选，不出具体方案
- 边界 2：明确禁忌「不喝酒」 → 全部方案无酒类并说明已排除
- 失败：要求「送医生红包」等不当场景 → 拒绝并给合规替代

## 目录说明

- `references/` — 关系与分寸规则、默认排除清单（按需加载）
- `templates/` — 礼物方案输出模板
