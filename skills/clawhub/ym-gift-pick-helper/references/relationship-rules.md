# 关系与分寸规则 + 默认排除清单

本文件用于礼物推荐时定调与过滤。先按关系定分寸，再跑默认排除清单，最后结合用户已知禁忌。

## 一、关系与分寸规则

| 关系 | 分寸要点 | 推荐取向 | 避坑 |
|---|---|---|---|
| 伴侣 | 重用心、可浪漫、可私人体贴 | 纪念向、体验向（共同体验）优先 | 避免太敷衍的实用杂物；可私人但不过界 |
| 父母/长辈 | 重实用与体面、健康相关要稳 | 实用向（好用不花哨）、健康类需谨慎 | 不送三无保健品；不送涉及病情的暗示物 |
| 孩子 | 按年龄分，重安全与成长 | 玩具/书/体验（游乐园、课程） | 必须合规安全，标注适用年龄；不送危险小零件 |
| 朋友 | 看亲疏，可趣味可实用 | 实用向、兴趣向 | 避免过于贵重的「人情债」 |
| 同事 | 避免过于贵重造成压力、避免私人 | 小额实用、零食礼盒、通用好物 | 单件别太贵；不送贴身/私人/带暗示物品 |
| 领导/上级 | 避免过于私人、避免贵重触线；看单位制度 | 体面、适度、可转赠的通用好物 | 必提示商务合规风险；不送现金/有价证券/高价私物 |
| 老师/长辈非亲属 | 重尊重与得体 | 文具、书籍、体面小礼、鲜花 | 不送私人化、不送贵重 |

## 二、默认排除清单（命中即排除，写原因）

| 排除项 | 排除原因 |
|---|---|
| 贴身衣物（内衣、睡衣等） | 过于私人，易越界或冒犯，除非亲密伴侣且用户明确 |
| 明显涉及身材/外貌的物品（体重秤、瘦身仪、美容仪、显老/显胖暗示） | 易伤自尊，暗示对方「需要改善」 |
| 药品、保健品（尤其三无/来路不明） | 涉健康风险，且可能暗示对方身体有问题 |
| 刀具、钟表（钟/表）、伞、梨等 | 文化忌讳（送钟=送终、伞=散、梨=离），按关系与文化习惯规避 |
| 现金、红包、有价证券（对特定职业对象） | 合规与得体风险，尤其领导/公务/医护等场景 |
| 过于私人的物品（日记本、香水若对方不用、个人护理强相关） | 边界感差，易冒犯 |
| 来路不明/三无产品 | 质量与安全无保障 |
| 涉及宗教/政治敏感的物品 | 分寸与合规风险 |

## 三、使用纪律

1. 用户明确提到的禁忌优先于一切，先过滤。
2. 默认排除清单命中项，在输出「已排除项与原因」中逐条写明。
3. 领导/商务场景，任何方案后附一句合规风险提示（金额是否合适、对象能否收礼、以对方单位制度为准）。
4. 不编造品牌、型号、价格；价格只给区间。
