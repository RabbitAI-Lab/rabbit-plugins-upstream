# 招标文件版本智能对比（招标人版）

> 上传两份招标文件（旧版 + 新版），自动比对所有变更，从招标人/采购人视角逐条评估质疑风险、合规阈值、称谓一致性，输出发布前自检报告。

**英文名称**：Bidding Doc Version Smart Compare (Tenderer)

---

## 功能特性

- **发补遗前自检**：自动扫描所有变更，识别可能引发质疑或投诉的高风险条款
- **合规阈值校验**：自动对照法定参数（保证金比例、时限、49 条金额上限等）
- **称谓一致性检测**：全文"甲方/乙方""采购人/中标供应商"等称谓混用问题一目了然
- **发布决策辅助**：每条变更给出处置建议（必须修正 / 补充说明 / 备口径 / 正常发布）
- **知识库驱动**：对接 IMA「招投标实务与合规」知识库，法规依据可溯源

---

## 适用场景

| 适合 | 不适合 |
|------|--------|
| ✅ 招标人 / 采购人 / 采购代理机构 | ❌ 投标人视角分析（请使用投标人版） |
| ✅ 发布更正/补遗公告前的内部自查 | ❌ 替代法律顾问的正式法律意见 |
| ✅ 评估多轮招标文件修订对投标活动的影响 | ❌ 替代正式审计（仅基于上传两份文件内容） |

**支持输入**：`docx` / `pdf` 标准电子文档（推荐）；扫描件、图片 PDF、超大文件、特殊排版的处理边界见 SKILL.md「使用边界」章节。

## 报告结构

1. 发布决策概览（全局风险等级 + 发布建议）
2. 数据质量说明（解析状态、条款编号识别率、是否有数据缺口）
3. 优先级分布（P0–P4 统计）
4. 发布前处置清单（可勾选 checklist）
5. 时限合规检查（是否需顺延截止时间）
6. 一致性扫描结果（7 维度逐一状态）
7. 逐条变更明细（自检项 / 质疑触发点 / 法定阈值检查 / 发布决策 / 处置建议）
8. 免责声明
