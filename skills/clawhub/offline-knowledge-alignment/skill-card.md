## Description:

Guides alignment of offline knowledge bases with online search through gap analysis, source checks, content updates, and answer-quality review.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and knowledge-base maintainers use this skill to identify gaps in local reference collections, check records against online sources, update local content, and assess offline answer quality.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Mitigation: Restrict file and repository access to an approved knowledge base and review proposed changes before applying them.
