## Description:

Guides Go developers in using an unofficial typed client for Vercel's REST API.

This skill is ready for commercial/non-commercial use.

## Publisher:

[psyb0t](https://clawhub.ai/user/psyb0t)

### License/Terms of Use:

MIT-0

## Use Case:

Go developers can use this skill to install and integrate a typed Vercel API client, configure bearer-token authentication, and look up endpoint methods and response types.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: API calls may change or delete live Vercel resources.

Mitigation: Use a narrowly scoped token, verify the target account and team, and make changes only when the user requested them for the relevant resources.
