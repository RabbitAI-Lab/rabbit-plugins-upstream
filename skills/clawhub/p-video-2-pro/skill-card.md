## Description:

Guides an agent to generate one cinematic video clip with generated audio from text or optional start and end frames using Pruna's API.

This skill is ready for commercial/non-commercial use.

## Publisher:

[pruna-ai](https://clawhub.ai/user/pruna-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators, marketers, and developers use this skill to make a single short cinematic clip for ads, documentary shots, or dialogue from a prompt and optional reference frames.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected frame images are sent to Pruna's API.

Mitigation: Confirm the content is appropriate to share with Pruna before submitting it.

Risk: The skill uses an API key and suggests unpinned related-skill installs.

Mitigation: Scope PRUNA_API_KEY appropriately and use pinned or reviewed versions of related skills.
