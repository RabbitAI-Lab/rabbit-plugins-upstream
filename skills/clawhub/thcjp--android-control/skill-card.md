## Description:

Android Control helps agents operate and understand Android devices through uiautomator2 and FastMCP workflows for multi-device management, UI hierarchy analysis, element interaction, touch input, app lifecycle control, messaging, WeChat-specific actions, and AutoGLM visual analysis.

This skill is ready for commercial/non-commercial use.

Developers, testers, and operations teams use this skill to guide Android device automation, screen understanding, app control, message workflows, WeChat operations, and multi-device task orchestration on devices and accounts they control.

## Known Risks and Mitigations:

Risk: The skill can enable sensitive Android device, app, screenshot, UI dump, message, and multi-account automation.

Mitigation: Install and use it only for devices, apps, and accounts the user controls, with explicit user approval and a clearly scoped device and account target.

Risk: Messaging and marketplace workflows can send messages, read conversations, or post content through connected app accounts.

Mitigation: Require review of the target app, recipient or listing, and final text or content before any send, read, or publish action is executed.
