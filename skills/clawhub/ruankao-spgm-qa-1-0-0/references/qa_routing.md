# 问答分类与知识库路由指南（系统规划与管理师智能问答）

> 本技能的核心：先把考生提问准确分类，再路由到正确的 IMA 知识库（主库写法 / 次库真实项目）与检索 query，最后按模板组织可溯源答案。分类错了，答案就容易跑偏。

## 一、问题六大分类

| 类别 | 典型提问 | 路由库 | 关键 query 建议 |
|------|---------|-------|----------------|
| **A. 考情政策** | 报名条件？考几科？题型？合格线？免考？跨省？ | 主库 | `系统规划与管理师 报名条件` / `考试科目 题型` / `合格标准` |
| **B. 知识点** | ITIL 4 是什么？服务级别管理含哪些活动？七步改进法步骤？运维四要素？ | 主库 | `教程 第2版 IT服务规划` / `三色笔记 第X章` / `GB/T 24405` |
| **C. 真题解析** | 2023 论文真题怎么答？案例一般考什么？服务规划与设计考过哪些？ | 主库 | `论文真题 2023` / `参考论文 服务规划与设计` / `案例 论文 考试大纲` |
| **D. 备考方法** | 怎么复习？资料怎么选？论文/案例怎么练？零基础多久过？ | 主库 | `三色笔记` / `论文 框架 模板` / `考试大纲` |
| **E. 项目素材** | 真实 IT 项目长啥样？论文项目背景怎么写？运维项目案例？ | **次库** | 领域词：`运维` / `政务信息化` / `数字化转型` / `服务管理` / `信创` / `AI` |
| **F. 范文/框架** | 优秀范文结构？四段式怎么排？摘要写什么？ | 主库 | `参考论文 服务规划与设计` / `论文 框架 模板` |

> 跨类问题（如"我想写服务规划与设计的论文，给我一个真实项目背景 + 框架"）= D/E/F 组合：先用次库取真实项目样例（E），再调主库范文/框架（F）。

## 二、分类判定要点

1. 含"报名 / 条件 / 科目 / 题型 / 分数线 / 免考 / 跨省 / 成绩有效期" → **A 考情政策**。
2. 含"是什么 / 含哪些 / 如何定义 / 步骤 / 区别 / 原理"且指向理论概念 → **B 知识点**。
3. 含"真题 / 历年 / 20XX 年 / 考过 / 怎么答 / 考查重点" → **C 真题解析**。
4. 含"怎么复习 / 资料 / 计划 / 节奏 / 零基础 / 经验" → **D 备考方法**。
5. 含"真实项目 / 案例 / 背景怎么写 / 项目长什么样 / 招标" → **E 项目素材**（次库）。
6. 含"范文 / 框架 / 结构 / 摘要 / 模板" → **F 范文框架**。

## 三、答案结构模板

### 通用模板（A/B/C/D）

```markdown
**问**：<一句话重述用户问题>

**答**：<直接结论（1–2 句）>

<分点展开，每点含要点 + 简要解释>
- 要点一：……
- 要点二：……

> 📖 溯源：参考主库《XXX》（如适用）
> ⏰ 时效：考情政策类须注明"以当年官方公告为准"
```

### 项目素材模板（E，次库）

```markdown
**问**：<重述>

**答**：真实 IT 项目样例（参考次库「软考高级论文素材」）
- 项目类型：智慧/数字化/信创/AI 类（按用户输入领域词匹配）
- 可提取要素：项目名称 / 投资金额 / 建设周期 / 技术栈 / 建设目标 / 服务范围
- 用法：将上列要素改写为**你本人实际参与的项目**，作为论文"项目概述"底稿。

> ⚠️ 次库项目为第三方招标素材，**不可直接冒用或抄袭**，须替换为自身真实项目。
```

### 范文/框架模板（F，主库）

```markdown
**问**：<重述>

**答**：四段式结构（参考主库《论文框架模板》）
1. 摘要（约300字）：背景+项目+主要工作+成效
2. 项目概述（约400-500字）：行业背景+目标+概况+技术架构
3. 正文核心（约1500字）：2–4 个分论点（理论+实践+效果）
4. 结尾（约200-300字）：回顾+经验+升华

> 📖 溯源：参考主库《系统规划与管理师参考论文-服务规划与设计》
```

## 四、边界与拒绝清单（必须守门）

| 越界请求 | 处理方式 |
|---------|---------|
| 押题 / 预测必考题目 | 拒绝提供"押题"，引导系统复习大纲覆盖的知识领域 |
| 索取或泄露未公开真题 / 答案 | 拒绝，说明考试保密规定 |
| 代考 / 替考 | 拒绝，说明违纪违规后果 |
| 代写论文 / 买卖答案 | 拒绝，说明学术诚信与雷同判定风险 |
| 询问其他科目（高项/架构）具体知识点 | 说明本技能仅覆盖系规，建议对应科目技能 |

> 所有拒绝须语气克制、说明合规风险，不提供任何违规内容，并可在末尾附公众号联系（如用户需要合规指导）。

## 五、检索失败兜底

- IMA 主库不可达 / 返回空：用内置 `spgm_terminology.md` 与大纲要点作答，并注明"建议以官方最新资料/主库为准"。
- 次库按领域词仍无命中：说明"未检索到对口项目，可用内置模板按真实项目自行补全"。
