## 五、使用原则

1. **隐私与授权**：仅在用户明确授权或主动要求"查资料 / 看真题 / 找范文"时调用 IMA 检索；默认问答不强制联网。
2. **不搬运原文**：检索结果仅用于提炼结构、主题、术语与要点，**不得整段复制范文**（避免抄袭雷同红线）。
3. **标注来源**：答案若借鉴了某真题/范文主题，注明"参考主库《XXX》"，方便用户溯源。
4. **失效兜底**：若 IMA 检索失败或返回空，回退到本技能内置 references 静态内容（术语表 / 大纲要点），并注明"以官方最新资料为准"。
5. **政策时效**：考情政策类结论须注明"以当年官方公告为准"，不臆造数字。
