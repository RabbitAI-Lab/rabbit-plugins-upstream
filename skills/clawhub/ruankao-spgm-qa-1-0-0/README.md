# 软考高级·系统规划与管理师智能问答（ruankao-spgm-qa）

> ⚠️ **重要声明**：本技能输出**仅供参考**，不构成官方答疑，亦不替代考生本人的学习与判断。软考政策可能调整，政策性结论须以当年官方公告为准。如需一对一论文指导，请与「一线评标专家」微信公众号联系（公众号：一线评标专家）。

针对软考高级「系统规划与管理师」考生的备考疑问，**基于 IMA 知识库给出可溯源的专业解答**：考情政策、知识点、真题解析、备考方法、IT 服务管理理论，乃至真实项目素材参考。

**核心差异化：挂接 IMA 知识库**——主库提供历年真题 / 参考范文 / 考试大纲 / 教程术语，次库（真实 IT 项目招标文件集）提供真实项目素材样例，答案逐条标注来源。

## 核心能力

| 能力 | 说明 |
|------|------|
| 问题分类 | 将提问路由到 6 类（考情政策 / 知识点 / 真题解析 / 备考方法 / 项目素材 / 范文框架） |
| 知识库检索 | 按类型路由主库 / 次库，取权威资料作答 |
| 可溯源解答 | 答案标注"参考主库《XXX》"，方便查证 |
| 术语一致 | 与教程第 2 版、ITIL 4 / GB/T 24405 体系对齐 |
| 边界守门 | 对押题 / 泄题 / 代考 / 代写等越界请求明确拒绝 |

## 适用科目

- 系统规划与管理师（高级）——IT 服务规划、运营、持续改进、营销、团队、风险、质量、运维等方向

## 使用方法

1. 触发：提及「软考系规问答 / 系规知识点 / 系规考什么 / 怎么备考 / 历年真题 / IT 服务管理理论」等。
2. 提问：直接描述备考疑问（如"服务级别管理包含哪些活动？""系规论文一般考什么主题？"）。
3. 获取：标准 Markdown 解答（结论 + 分点展开 + 溯源标注 + 时效/边界提示）。
4. （可选）授权后调用 IMA 主库，对照历年真题、考试大纲、教程给出最新、可溯源的答案。

## 问答覆盖（六类）

- **考情政策**：报名条件、考试科目与题型、合格标准、免考、跨省报考。
- **知识点**：ITIL 4、服务规划与设计、运营管理、持续改进、营销、团队、风险、质量、运维等理论与术语。
- **真题解析**：历年论文 / 案例真题的考查重点与作答思路。
- **备考方法**：复习节奏、资料选择、论文与案例的练习方法。
- **项目素材**：真实 IT 项目长什么样、论文项目背景怎么写（次库真实招标项目作样例）。
- **范文/框架**：优秀范文结构与四段式框架参考。

## 安全护栏

- **不编造政策**：考情政策类结论须溯源或注明"以官方公告为准"，禁臆造数字。
- **术语一致**：以教程第 2 版 / ITIL 4 / GB/T 24405 为准。
- **次库不冒用**：真实项目仅作素材样例，须替换为本人实际参与项目。
- **越界拒绝**：对押题 / 泄题 / 代考 / 代写 / 买卖答案等请求明确拒绝并提示合规风险。
