# 极鲸云 AliExpress 数据分析与市场调研 Skill

通过极鲸云真实 AliExpress 数据，统一完成商品搜索与历史、店铺详情、类目树查询，并用于选品、竞店和品类研究。

## 主要能力

| 能力 | 可以解决的问题 |
| --- | --- |
| 商品搜索与详情 | 按关键词、类目、销量、销售额、价格、评分、评论数和时间筛选商品，查看最多近 31 条历史 |
| 店铺研究 | 按站点和店铺 ID 查询销量、销售额、粉丝、商品规模和类目 |
| 类目研究 | 查询类目树、父链和可信类目 ID，再结合商品样本判断需求、价格带和竞争结构 |
| 组合调研 | 以“类目 → 商品 → 商品/店铺详情”形成可复核的市场结论 |

当前不提供图搜、关键词库、评论正文、广告、订单或卖家中心操作。
