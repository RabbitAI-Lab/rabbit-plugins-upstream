# AliExpress 接口总览

| 能力 | 脚本 | Agent 接口 |
| --- | --- | --- |
| 站点列表 | `scripts/aliexpress_site_list.py` | `GET /api/v1/aliexpress/site/ai-list` |
| 商品搜索 | `scripts/aliexpress_goods_search.py` | `GET /api/v1/aliexpress/goods/ai-search` |
| 商品详情与历史 | `scripts/aliexpress_goods_info.py` | `GET /api/v1/aliexpress/goods/ai-info` |
| 店铺详情 | `scripts/aliexpress_mall_info.py` | `GET /api/v1/aliexpress/mall/ai-info` |
| 子类目列表 | `scripts/aliexpress_category_list.py` | `GET /api/v1/aliexpress/category/ai-list` |
| 类目父链 | `scripts/aliexpress_category_info.py` | `GET /api/v1/aliexpress/category/ai-info` |

当前没有 AliExpress 图搜、关键词库查询、评论正文读取、店铺名称搜索、广告、订单或卖家中心写操作接口。图片上传不是 AliExpress 图搜能力。
