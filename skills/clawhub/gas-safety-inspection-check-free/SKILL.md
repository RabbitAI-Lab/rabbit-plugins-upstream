# 燃气设施安全检查与隐患整改核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：餐饮门店、物业、工厂与学校食堂的**安全管理员 / 门店店长**，
在**每个月**的燃气安全检查节点上（也是燃气安全法定义务），必须把这张巡检与整改记录核一遍才能交差：

- 这个月**每个点位（门店 / 厨房 / 锅炉房 / 用气设备）到底查了没有**？漏查的点位要点名；
- **软管、管件到期了没**？超期还在用就是查封项；
- **燃气报警器年检到期了没**？报警器失效期间不报警、不联动切断阀；
- 记录有没有**同一天同一点位重复登记**、**合计行与明细对不上**、**关键字段空着或写错**。

**为什么必须核**：软管超期、报警器失效、隐患未整改，都是**燃气公司与监管的查封项**；
台账对不上、隐患没闭环，一旦爆燃企业要担责。而这一步几乎全是**跨列日期算术与清单勾稽**，
人造表格最容易在「到期日、年检周期、整改期限」这三处算错。

**这张表要有的列（缺列只报「材料不足」，绝不给结论）**：
点位编号、点位名称、点位类型（厨房 / 锅炉房 / 用气设备）、检查日期、检查项数、规定检查项数、
检查结果、隐患描述、整改期限(天)、整改完成日期、软管更换到期日、上次年检日期、年检周期(月)、
下次年检日期、核对日期。

**每个点位每月至少检查 1 次**（频次口径）；「核对日期」就是这次核对的基准日，
所有超期天数都以它为准 —— 本工具**不读本机时钟**，同一张表任何时候跑出来的结果都一样。

## 这个免费版查什么（6 项）

1. **检查频次覆盖**：按点位核对「核对日期」所在月的实际检查次数，本月一条记录都没有的点位逐个点名；
   最新一条检查结果是「停用」的点位不报缺检。
2. **软管/管件有效期**：逐行复算 检查日期 ≤ 软管更换到期日，超期即报并给出超期天数。
3. **燃气报警器年检**：逐行复算 上次年检日期 + 年检周期(月) = 下次年检日期（不符即报），
   并与核对日期比出**年检超期天数**（超期天数按复算值算，不认表里手填的日期）。
4. **同一点位同一检查日期重复登记**：逐条点名重复行号。
5. **合计行逐列复核**：点位数按**去重计数**，检查项数 / 规定检查项数 / 隐患数按明细行求和。
6. **关键字段缺失与取值非法**：空白与占位符（`待填`/`无`/`--`）、日期格式、数值为负或无法解析、
   检查结果必须是 正常 / 隐患 / 停用 / 已整改。

每条结论都带**原文行号与出处**（第 N 行「点位名」+ 具体日期与数字），可被第三方用同一口径复算。

## 怎么用

```bash
node scripts/run.mjs --sample                 # 先看样例
node scripts/run.mjs --input 你的材料.json     # 跑自己的材料
node scripts/run.mjs --input 你的材料.json --json
```

入参就是一个字段的 JSON：`{"text": "（把表头和若干数据行从 Excel 一起复制成文本，Tab 分隔最稳）"}`。

## 常见错法（燃气巡检台账里真的会有人这么填）

1. **软管只写「已更换」、不写「软管更换到期日」**：到期日是复算超期的唯一依据，
   写「已换」等于没写 —— 这一列空着，超期就永远算不出来。
2. **「下次年检日期」照抄上一张表**：它必须由 `上次年检日期 + 年检周期(月)` 复算；
   抄来的日期一旦过期，报警器年检就静默漏做（本工具按**复算值**算超期）。
3. **隐患行只写「已通知燃气公司」、不填「整改完成日期」**：限期整改看的是「整改完成日期」；
   只写「已通知」既不算闭环，也不会有超期天数（完整档的整改闭环项直接点它的名）。
4. **「检查结果」写成「已通知」「整改中」「已报修」**：只认 正常 / 隐患 / 停用 / 已整改 四选一；
   非法取值会让整改闭环与「停用点位不报缺检」这两处判定整项失效。
5. **合计行的「点位数」按明细行数填**：同一点位一个月查了两次仍只算 **1 个点位**（去重计数），
   填成明细行数就会和逐列复算对不上；另外**停用点位当月也要留一条「停用」记录**，
   一条都不留会被当成「本月缺检」。

## 边界（请务必知道）

本工具**不做**引擎 `CHECKS_OUT_OF_SCOPE` 里列的那些判断 —— 不判定燃气设施是否真的安全、
不判定隐患是否已经实质消除、不判定是否达到燃气公司与监管的查封或停气标准、
核对过程不联网核验资质证书与年检报告真伪、不代替安全管理员签字；
材料不足时**不给结论**，也不会输出「未发现问题」。
「干净样例 0 命中」只说明这张表按上面写明的口径算得对、该填的都填了。
