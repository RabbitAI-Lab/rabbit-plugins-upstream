## Description: <br>
Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineering teams use this skill to produce practical API documentation artifacts, workflows, checklists, code changes, and validation guidance for OpenAPI or Swagger-based REST APIs. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad activation wording may route general API-documentation requests to this skill when a narrower skill would be more appropriate. <br>
Mitigation: Invoke it for explicit OpenAPI, Swagger, REST API specification generation, validation, or documentation work, and tighten trigger wording where precise routing matters. <br>
