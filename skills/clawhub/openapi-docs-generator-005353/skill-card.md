## Description: <br>
Helps API developers and backend teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
API developers, backend teams, developer-experience teams, and maintainers use this skill to turn REST API documentation needs into concrete OpenAPI or Swagger workflows, checklists, validation notes, code-oriented guidance, and next-step recommendations. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad implicit activation wording may trigger the skill for generic API or developer-experience requests outside an OpenAPI or Swagger documentation task. <br>
Mitigation: Invoke the skill explicitly for OpenAPI or Swagger work, or confirm the documentation scope before relying on its output. <br>
