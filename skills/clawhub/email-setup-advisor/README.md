# 邮箱配置参谋（Email Setup Advisor）

> 动手接邮箱前替你踩坑的参谋：问清你的需求，帮你选对路径、预判限制，接错了给回头路。不碰你的账号。

**适用平台**：SkillHub（skillhub.cn）｜**版本**：v1.0.0｜**语言**：中文（附英文版）

## 一句话简介

接邮箱之前，先帮你选对路、提前把会撞的限制摆出来；接坏了，给不超过两条带第一步动作的回头路。

## 解决什么痛点

- 平台把"怎么点"做简单了，但"**该不该点、点哪条**"没人管——接入前没人告诉你选了这条路的代价。
- 接口只告诉你"能配什么"，没人告诉你"**配完会怎样**"：附件多大、发信多少、授权怎么给、发出去的信去哪看。
- 接坏了以后，用户面对的是一堆文档，不是下一步动作。
- 很多人分不清个人邮箱、AI 专属邮箱、已接入的个人邮箱三个地址的分工，结果走错门。

## 你会得到什么

1. **明确首选**——三问倒推出该走哪条路，讲清理由和取舍，不给你一堆选项盲选。
2. **限制预判表**——动手前把会撞的限制逐条摆出来：会撞什么 / 撞了会怎样 / 怎么绕 / 来源是官方还是经验还是待验证。
3. **接错回头路**——最多两条，每条都带第一步动作，不让你在文档里翻。
4. **邮箱分工讲清**——一句话分清三个地址各自干什么。

## 怎么用

装上后直接说人话就行，例如：

- "我要接自己的邮箱，该怎么选方案"
- "邮箱接上了但收不到信，怎么回事"
- "AI 专属邮箱和我自己的邮箱有什么区别"
- "附件超过 1MB 还能发出去吗"

## 使用边界（重要）

- **不代你操作账号**：不代登录、不代配置、不代授权。要它"直接帮你配好"会拒绝，然后给你分步自查清单。
- **不读、不处理邮件内容**：它不会去读你的邮件正文。
- **平台能力以官网为准**：它会给"待验证"标注和自查入口，不会把不确定的说成确定。
- 不碰账号代充、账号买卖。
