## 测算流程（8 步，每步输出中间链，禁止跨步直断）

1. **输入审计**：历法/时区/出生地/节气边界/日界规则/真太阳时影响 8 字段全确认。
2. **排四柱+旬空**：年柱（立春）→ 月柱（节气+五虎遁）→ 日柱（交叉验证）→ 时柱（真太阳时+五鼠遁）→ 旬空：**格局用日柱旬空**（月空看年支）；同时按**分柱空亡**（年/月/日/时各本柱旬）标注四柱各柱空亡，供步骤 6/7 六亲/风水读象使用。
3. **定格局**：月令灌气 50% 定旺衰；反断两条件（年支参加+坐支帮扶）；四格分流：身旺/身弱/从旺/从弱；从格先月干、破格从日支；月令空亡看年支。
4. **取用忌**：理论用神/忌神、组合用神/忌神、阴阳神五种神；再标格用忌 × 日主用忌四组合。
5. **命局解读**：同柱通根、相邻作用、一个命式一个算式、四库土特例、同柱干支六类关系（受生泄/克耗/互助/助耗/互耗/生克泄）。
6. **大运流年**：排大运（顺逆/起运折算）→ 越组合作用（冲合会临）→ 失脱、发动、二次同向作用、应期到位（被冲合之字流年到位）、链条断法、各主各事。**应期精微须套两条已核验规律**：① `原子 — 天干坐支受伤流年到位应期`（大运天干被本运地支伤 + 流年本天干到位再被流年地支伤 → 用神凶 / 忌神吉；须"本天干到位 + 又被流年地支伤"双条件才出，一上运就冲合不等于立即出事）；② `原子 — 局外应事律`（岁运冲 / 合命局外之字，用神被冲合必凶、忌神必吉，原书秘法 / 风水）。
7. **体系融合断语**：八字/天星密派**主体**（格局用忌+七神+三角取象）→ 天星密派**母本补充**（能量流/应事律/发散律/十神运动双螺旋）→ 六亲应事十二诀（按问事主题）；取象开口说话须用 `原子 — 干支双向与三字取象法` 与 `取象字典 — 六十花甲子象意表` 沿作用路线取断语，四字以上联动取象一般不出口；**分柱空亡**在此步按需用于六亲/事业方位/风水读象（如空亡方慎往、某柱空亡对应六亲不得力），与日柱旬空（格局用）分开标注。
8. **输出命书**：按下方《命书输出模板》8 段结构。

## 计算铁律（王玉川原著母本校准 · 引擎与 AI 解释权均不得违反）

以下四条为原书反复锤定的方法论校正，是"数"层可复算的底线；vault 长文笔记与原子库速查层（[[17-七星九元命理]] 全书主线 + 原子库）已据原书逐条核验，2026-09-22 起为技能强制口径：

1. **无化格 · 化=受伤**：八字内部一切六合 / 三合 / 三会均为"绊 / 会聚"作用力，**不存在"合化变性"**。凡遇合一律按"绊伤"处理——被合之字力量被牵制、受损，而非变成另一种五行。严禁套用任何"合化出某五行"的教材逻辑（引擎形式化层无合化分支，AI 亦不得引入化气推理）。
2. **反克（耗）是实算法**：吉神（用神）受克 / 耗 / 泄 ≠ 出凶，要看该字在算式中所站的位置与受力方向；同一字在不同组合里可吉可凶。禁用"吉神受克必凶"的机械判据。
3. **一个八字就是一个算式**：命局只决定计算方法，吉凶由"大运 / 流年引发 + 作用路线"算出，不靠感觉取象。取象只是计算链的"开口说话"层——须先定格局、明用忌、熟六亲喜忌再取，否则双关语似是而非（见 `原子 — 干支双向与三字取象法` 的 boundary）。
4. **相邻直接作用 · 不相邻沿节点串走**：禁跨步直断；失脱（受伤字失去原力后反发动）、二次作用、各主各事（吉凶分组分开断，不混为同一结论）一律照此。

> 违反上述任一条即属"带病输出"；判定前先回查原子库速查层与母本长文，不得凭模型预训练命理知识补位。

## 断语硬规则

- 输出概率 / 观察点 / 行动建议；**禁用**"必然/一定/百分百/必死/必败"式确定性断语。
- 一事一链：财/婚/健康/官非不混为同一结论。
- 先写相反证据，再判断；不挑吻合事件。
- **判据不可反用（2026-09-06 教训，勿再犯）**：vault 笔记断语绝大多数是「某组合 → 某应事」的**充分示例**，不是必要条件，**严禁反推为「无此组合 → 无此应事」**。
  - 实例：笔记《六亲十神应事十二诀》「父母离婚：印星为忌无财制印 → 父母离婚」被误用成排除条件，据「本盘印为用神」推出「不指向离异」，当事人实际已离异。

  - 通例：凡想用"XX 判据不成立"排除某应事时，先自问"这是唯一路径吗"；不是唯一就必须改概率表述，或把多条路径都列出来。

## 工程架构（v2.0 四权分离）

本技能 2.0 在保留原 8 步命理流程基础上，工程化加固为「四权分离」：

- **知识权**：Obsidian Vault 是唯一命理知识来源。每个 Pipeline Step 经 `rules/loading_matrix.yaml` 以 canonical 名（统一口径「天星密派」）加载指定 vault 文件，引擎不得自由决定读取哪些笔记。
- **计算权**：`engine/` 下本地 Python 规则引擎（input_audit / solar_time / paipan / pattern / yongji / dayun / liunian / inference / conflict_detector / validator / main）。全确定性、离线、无网络。
- **解释权**：AI/WorkBuddy 只能翻译与组织 evidence_chain，按固定 8 段模板生成命书；不得创造新结论、不得修改计算输出、不得使用模型预训练命理知识、不得为讨好用户修改结论。
- **裁判权**：`validator.py` 检查每条结论可追溯（rule_id → input → 中间计算 → output），并离线扫描 engine 禁用网络能力（requests / urllib / socket / httpx / aiohttp / curl / wget）。

统一证据链：每个 Step 输出 `{step, input, rules_used, intermediate_reasoning, opposing_evidence, output, confidence, rule_version, vault_source, needs_formalization, conflict}`，最终结论可追溯至 规则ID → 输入 → 中间计算 → 输出。

命名唯一：vault 与技能统一使用「**天星密派**」（**王玉川**创立）作为唯一体系名；`loading_matrix.yaml` 的 `source_file` 与 vault 实体文件名严格一致，改名时须同步两侧，否则加载失败。

### 坐标系约定（2026-09-04 修复，勿再踩）

出生钟表时间一律视为**北京时间（UTC+8）**；`_solar_term_jd` / `_jd_to_dt` 返回的节气时刻是 **UTC**。两者比较或相减前**必须**先 `solar_time.to_utc(birth_dt)` 转 UTC，否则等于把节气提前 8 小时生效。真太阳时只用于**定时辰 / 定日界**，不可用于与节气时刻比较（2026-09-04 前 `dayun.py` 正是误用真太阳时当 UTC，起运少算约 0.11 年，如 8.53 → 正确 8.64）。

### 逆排取节规则（2026-09-06 修复，勿再踩）

`dayun.py` 逆排分支原取 `pj = (jie_idx - 1) % 12`，等于**跳过一个节**：出生在午月（芒种后）却拿立夏当"上一节令"，起运被多算约 10 年（实测 2019-07-06 盘：20.43 岁 → 正确 10.04 岁）。
正确口径：出生必在本月之节（`jie_idx`）之后（否则月支不会是本月支），故**逆排的上一节令＝本月之节本身**，即 `pj = jie_idx`。顺排仍取 `(jie_idx + 1) % 12`（下一月之节）。
> 影响面：所有逆排盘（阴年男 / 阳年女）此前起运普遍偏大约 10 年，历史命书若涉逆排需复核起运与大运起点。

### 日柱独立复核（排盘后强制）

不信任引擎单一结果，用 JDN 锚点法独立复算日柱：以 **1949-10-01 = 甲子** 为锚，交叉验证 **2000-01-01 = 戊午**、**2024-01-01 = 甲子**，三点自洽才采信。公转农历→公历用 Meeus 章 49 精确新月公式二分求解（勿凭记忆）。
2026-09-04 实测：脚本日期差符号写反会误判日柱（壬戌 vs 正确甲寅），靠锚点法纠正。

### 节气边界强制复核（硬要求）

出生日恰在节气当天时，引擎只回传「节令日」不给时刻，**必须独立验算交节时刻**再定月柱（月柱一错，大运全错）。做法：Meeus 低精度太阳视黄经（L0 / M / C，误差 <0.01°≈15 分钟），二分求 λ=240/255/270/285 的时刻，再 +8h 转北京时间，与出生钟表时间直接比较（真太阳时校正对出生时刻与交节时刻同向，可抵消）。

实测坑：JD→日历换算时，`timedelta(days=jd - 2451545.0 + 8/24)` 的 `8/24` 写成 `8.0` 会让结果偏后整 8 天；用 `datetime(2000,1,1,12) + timedelta(days=...)` 反推日期最稳。1990-12-07 大雪实测 = 北京时间 09:07（出生 20:00 在其后约 11 小时，安全）。

确定性：`tests/test_determinism.py` 同输入重复 20 次，四柱 / 旺衰 / 格局 / 用忌 / 大运 / 流年 / 规则ID / evidence_chain 必须一致。

### 从旺/从弱判定口径（PDF 133-164，已形式化进 `engine/pattern.py`）

四格分流里**从旺格四条硬门槛**（天星密派上册 PDF 153-159，见 vault《天星密派 — 定格·取用·运算规律》第 58 行）：
① 日元生印比月（或月空生印比年）→ 进旺分支；② **日支帮扶**；③ **月干/时干其一帮扶**；④ **时支不构成有力克泄耗**。四条全满足 → 从旺（再分从印/从比，细分未形式化）；任一条不满足 → 身旺。

**关键口径（2026-09-04 用户纠正后锁定）**：第④条「时支不克泄耗」不是看时支五行的字面生克，而是看**时支的实际作用**——依据二十律「同柱干支直接作用」：时支官杀（克我）若被**时干印（生我）化解**（官印相生：时支生时干、时干生扶日主），则官杀力量被泄，不构成有力克泄耗，算「不克泄耗」。
实测：壬申 壬寅 甲寅 癸酉，时支酉=正官（金克木），但时干癸=印（水）化之——酉生癸、癸生甲，官印相生，时支实际不克日主 → 四条全满足，判**从旺**（从比）。此前曾机械套「时支酉金克木」误判身旺，已纠正为从旺。

未形式化规则（标 `needs_formalization`，交人工或后续规则形式化，不臆造算法）：格局量化权重、阴阳局完整生成、从印/从比细分、组合用神 / 五种神、越组合作用（合 / 会 / 临 / 失脱 / 发动 / 二次同向）、六亲应事十二诀、应事律、发散律——vault 仅自然语言描述。
