# 银发助餐点查询 · govt-meal-finder v1.0.0

帮老人或子女快速找到附近政府认证养老助餐点。

## 安装

```
根据 https://clawhub.ai/han815757857-cmd/skills/govt-meal-finder 安装银发助餐点查询
```

## 快速开始

```bash
export GAODE_POI_KEY="xl_xxx"   # 向服务运营方申请
python3 govt_meal_skill.py --city 北京 --place 天安门
```

## 覆盖城市

北京 · 广州 · 深圳（共约 4,253 条政府认证助餐点）

其他城市暂不支持，查询时会明确告知。

## 数据说明

- 数据来源：各城市政府公开养老助餐点名录
- 包含商业餐厅（已加入政府补贴计划）和社区食堂
- 电话来自政府公开名录，可直接致电确认开放时间和资格要求

## 使用提醒

1. 距离为直线距离，实际步行路程可能更远
2. 开放时间、剩余名额请致电确认，部分节假日停餐
3. 部分助餐点仅限本街道户籍老人，请现场核实资格
