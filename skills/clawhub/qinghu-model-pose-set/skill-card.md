## Description:

根据一张服装模特图生成多种姿势与展示角度的套图，供服装商品展示和社交媒体营销使用。

This skill is ready for commercial/non-commercial use.

## Use Case:

服装电商运营者和营销创作者可用一张模特照片生成多姿势、多角度的商品展示图，用于商品详情页和社交媒体素材。

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Selected photos are uploaded to Qinghu AI for generation.

Mitigation: Use only photos you are authorized to share, and check Qinghu AI's privacy terms before uploading.

Risk: Downloaded CLI code and service-side handling were outside the security review.

Mitigation: Prefer a reviewed, fixed CLI version and make upgrades deliberately.
