## Description:

Converse and write in Emirati; Abu Dhabi on request.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binablan](https://clawhub.ai/user/binablan)

### License/Terms of Use:

MIT-0

## Use Case:

Users can use the skill to converse and write in Emirati Arabic, revise messages or dialogue, and request explanations of documented pronunciation. Abu Dhabi guidance is opt-in.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Dialect quality is experimental and has not received independent native-speaker certification.

Mitigation: Have a speaker of the intended variety review consequential or public-facing text.

Risk: Installing the skill can change the active agent profile.

Mitigation: When following the installation example, use a fixed version in a fresh profile.
