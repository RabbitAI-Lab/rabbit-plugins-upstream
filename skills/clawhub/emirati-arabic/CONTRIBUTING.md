# Contributing

Thank you for helping improve the skill.

## Report a wording issue

Provide a short original example, your suggested correction, and the intended context. If relevant, describe the regional variety or register. Distinguish personal preference from a wider linguistic claim.

## Add a source-backed rule

Include the source, edition, printed page, limited necessary examples, and the rule's boundaries. Verify exact diacritics or spelling from page images rather than assuming PDF extraction is correct. Do not upload books or page collections.

## Privacy and attribution

Do not submit credentials, local computer paths, private conversations, personal data, or identifying information about other people. Use invented examples where possible, and label them as original.

## Before submitting

Run `python -m unittest discover -s tests -v`. Keep `SKILL.md` concise, update the source notes when introducing a rule, and avoid claiming that structural tests prove native-level fluency. Contributions should be compatible with the project's MIT license; do not relicense third-party material.
