# 从问题地图到本周内容与同题复测

以下是交接方式示例，延续随包演示的问题地图；没有运行 aimeGeo 安装、真实平台发布或 AI 查询，也不是客户成效。

## 让已整理的问题继续产生内容

- 输入本技能交付的 `问题—主题—内容形式映射表.csv`、`本周优先选题.md`、原题 ID 与文章覆盖证据。
- 演示中“首次试用步骤”可成为优先内容；“免费权益限制”仍需核对事实；“添加第一个账号”已由 A1 覆盖，沿用原教程。
- 当前 Agent 读取这些资料，在 aimeGeo 中完成选中稿件与配图并保存到文章列表，不把问题地图本身当成文章。
- 用户要发布时再沿当前账号配置执行，分别记录实际回执；需要 GEO 时沿原代表问题检测并保留回答和原生来源。

## 可复制任务

> 请使用 aimeGeo 继续本周优先选题。先读问题地图和已有文章，只写资料齐备且尚未覆盖的内容，保留问题 ID。完成正文与封面后保存到原项目，给我文章 ID；已有答案直接复用，资料缺项单列。先不发布，之后按这组问题安排复测。

内容入口：[制作内容](https://geo.aimmme.com/docs/content-production/)。检测入口：[AI 引用检测](https://geo.aimmme.com/docs/ai-citations/)。
