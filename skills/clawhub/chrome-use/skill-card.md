## Description:

Automates browsing, web research, data extraction, and app testing in the user's logged-in Chrome browser.

This skill is ready for commercial/non-commercial use.

## Publisher:

[leeguooooo](https://clawhub.ai/user/leeguooooo)

### License/Terms of Use:

MIT-0

## Use Case:

People and developers use this skill to research the web, extract information, and test or operate sites through their existing Chrome sessions, including authenticated pages.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Access to logged-in Chrome sessions can expose sensitive accounts or allow unintended actions.

Mitigation: Use only with a trusted publisher; avoid sensitive accounts unless each browser action is explicitly user-directed.

Risk: Installation and upgrades can execute mutable external tooling from unverified remote scripts.

Mitigation: Inspect installers before running them and prefer pinned, verified releases.
