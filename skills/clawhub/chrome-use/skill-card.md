## Known Risks and Mitigations:

Risk: Access to a logged-in Chrome session can expose sensitive information and allow account-changing actions.

Mitigation: Use only when browser access is intended, and require explicit user confirmation before submissions, uploads, purchases, or account changes.

Risk: The supplied install and upgrade commands execute downloaded scripts directly.

Mitigation: Independently verify their source and contents before running them, or avoid those commands.
