# weixin-quote

**类型**：**纯指导型**设置技能。**不含补丁文件、不安装任何插件包**。agent 执行时按 `SKILL.md` 的规格，**直接修改你机器上已安装的微信渠道插件**，使其具备"引用即上下文"（引用 bot 回复时把被引用全文注入模型）。

## 它如何带来能力

agent 按 `SKILL.md` 执行：

1. 定位本机微信插件（`openclaw plugins inspect openclaw-weixin --json`）并记录版本；**已实现则只校验**（幂等）；
2. 按规格实现：发送成功后记录服务端 `message_id`（**精确字符串**）；引用时**按 id 邻近（≤1000）匹配**，未命中用正文子串兜底；命中注入**全文**；未命中**显式标记，禁止猜测**；
3. 处理三个硬坑——id 超过 `Number.MAX_SAFE_INTEGER`（必须 BigInt/字符串比较）、时间戳不可作主判据、索引必须**跨重启持久化**（如小型 SQLite 索引，建议每接收方 80 条 / 24h）；
4. 征得你的明确同意，并**先备份**每个被修改的文件；
5. 重启 gateway，用 `[send-resp]` / `[quote-hit]` 日志验证（并做一次重启后引用回归）。

官方插件升级会覆盖改动——重新运行本技能即可重打。回滚 = 用第 4 步备份覆盖回去（或重装官方同版本）。

文件：`SKILL.md`（规格 + 执行）、`README.md`/`README-zh.md`、`LICENSE`(MIT)。

## 新机用法

```bash
openclaw skills install @yechang1450/weixin-quote
# 然后对 ClawBot 说：启用引用 / 引用没生效
```

agent 修改插件文件前一定会先征得同意，并先做备份。

## 触发词（收窄，限渠道语境）

启用微信引用上下文 / 修复 openclaw-weixin 引用匹配

仅在用户明确要求为 `openclaw-weixin` 渠道启用或修复引用追问时执行；改动任何文件前先征得确认，**绝不以提权方式**写入或构建；本地引用索引**仅属主可读**，并有**强制过期与上限**。
