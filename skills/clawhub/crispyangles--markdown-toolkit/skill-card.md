## Description: <br>
Markdown utility skill for generating tables of contents, converting Markdown and HTML, fixing formatting, stripping HTML, merging files, validating YAML frontmatter, and finding orphan links. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and documentation authors use this skill to perform common Markdown maintenance tasks, including TOC generation, Markdown-to-HTML conversion, formatting cleanup, frontmatter validation, file merging, and link reference checks. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Suggested commands can modify local Markdown files if run against the wrong path or without review. <br>
Mitigation: Verify target paths and preview or back up files before running in-place edit commands. <br>
