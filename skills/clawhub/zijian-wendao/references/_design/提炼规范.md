# 「资鉴问道」抉择案例·提炼规范（子任务通用）

你要从指定的古籍文本中，提炼出结构化、可直接用于「人生抉择推演」的历史案例。

## 文本位置
- 《史记》简体全文：`/sandbox/workspace/library/史记_简体/`（130 篇，文件名形如 `013_十表-三代世表.md`）
- 《资治通鉴》简体全文：`/sandbox/workspace/library/资治通鉴_简体/`（294 卷，文件名形如 `001_资治通鉴第一卷(周纪).md`，为**文言原文＋白话译文对照**，原文段与译文段交替出现）

## 方法
1. 用 `match`（grep）在指定目录中定位与目标事件相关的篇/卷（可用人物名、地名、关键句检索）。
2. **精读**相关段落（原文段），弄清来龙去脉。
3. 按下方模板提炼。**读多少写多少——宁可少而准，绝不编。**

## 铁律（决定这个技能的"靠谱"程度）
- **原文引用必须逐字来自上述文件**，不得改写、拼凑或凭记忆写成文言。引文控制在 1–3 句、100 字以内。
- **不得杜撰**任何人物、对话、结局。若某事件在指定文本中确实找不到，写「（该案例在指定底本中未找到，留待补充）」，**不要编**。
- 结果/代价的判断要有据：优先依据文本本身（含"太史公曰""臣光曰"的评论），其次才是常识推断；推断处标注「（推断）」。

## 单条案例模板（严格遵守）

```
## 案例名（出处简称）
- **标签**：#标签1 #标签2
- **情境**：两三句讲清当时的局面、这个人的身份与处境（他手里有什么牌、怕什么）。
- **抉择点**：一句话点明他面临的核心选择。
- **可选路径**：A.… ；B.… ；C.…（当时其实存在哪几条路，尽量给全）
- **实际抉择**：他选了哪条，为什么。
- **结果**：结局（成/败、生/死、兴/亡、得/失）。
- **显性代价**：看得见的付出与损失（性命、官位、钱财、时间、部众……）。
- **隐性代价**：看不见的代价（信任、名声、人心、士气、后患、心理负担、后世评价……）。若无，写「无显著」。
- **原文**：「……逐字引文……」——《书名·篇/卷名》
- **决策要点**：1) … 2) …（1–3 条，能迁移到现代人生/事业的原则）
- **风险提醒**：这条经验用错了会怎样 / 什么条件下不适用。
```

## 输出要求
- 每个案例 350–650 字，深挖但不注水。
- 文件开头写 `# 案例库·<分组名>`，然后依次排列各案例，案例之间空一行。
- 文件名与路径见各自任务说明，**写入指定路径**。
- 完工后在最终回复里简要报告：共产出多少条案例、涉及的篇/卷、以及哪些目标事件未找到。
