# Japanese N1 Sprint Coach

N1 备考冲刺助手。输入日语句子/词汇/语法/阅读段落，输出 N1 考点标注、语法拆解、易混淆对比、备考策略及短时段学习计划。

## 主要功能

- **句子解析模式**：贴日语句子 → 结构分析 + 语法点标注 + 词汇解释 + 易混淆对比
- **语法深度模式**：问具体语法 → 形式分类 + 易混点对比 + N1 真题型挖掘 + 速成练习
- **冲刺规划模式**：说“给个计划” → 倒计时分解工作量 + 短时段任务拆分 + 周计划表格
- **题型攻略模式**：讨论听力/阅读/词汇 → 解题步骤 + 常见陷阱 + 练习建议

## 触发词

N1、日语学习、语法、词汇、阅读、听力、备考、JLPT、能力考、日文、翻译
