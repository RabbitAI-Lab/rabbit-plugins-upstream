# 参考文献批量处理

输入论文标题 / DOI / 作者信息 / 现有文献条目，批量识别文献类型并生成 **GB/T 7714、APA、MLA 等多格式**参考文献条目，输出可直接复制的参考文献列表。

## 何时启用

- 用户批量粘贴论文标题、作者、DOI、URL 或现有文献条目
- 用户要求：批量生成参考文献、转格式、GB/T 7714 / APA / MLA、DOI 转引用、按类型整理文献
- 匹配下方提示词模板任一意图

## 提示词模板（示例）

**示例 1：** 根据这 10 篇论文标题，批量生成 GB/T 7714 顺序编码格式参考文献列表。

**示例 2：** 输入这几篇外文会议论文 DOI，导出 APA 标准参考文献格式。

**示例 3：** 整理我标注的图书、期刊、学位论文，区分类型统一生成国标参考文献。

## 工作流

### 1. 识别输入与文献类型

| 输入形式 | 处理 |
|----------|------|
| 论文标题（中文/英文） | 据标题语义判类型；信息不全时按「待补」生成骨架并标注缺失字段 |
| DOI（如 10.1234/xxx） | 优先用 DOI 检索补全元数据；无法联网时按 DOI 字面信息生成并标注「请核对」 |
| 作者 + 年份 + 标题 | 据已有字段生成；缺字段标注「待补」 |
| 现有格式混乱的条目 | 解析现有字段，按目标格式重排 |
| .bib 文件 | 解析 entry 字段，转目标格式 |
| 截图 / 图片 | 先读图提取文字，再整理 |

**文献类型识别（决定类型标识与字段要求）：**

| 类型 | GB/T 7714 标识 | 关键字段 | 识别线索 |
|------|----------------|----------|----------|
| 期刊论文 | [J] | 作者. 题名[J]. 刊名, 年, 卷(期): 页. | 含卷期页、刊名 |
| 图书 / 专著 | [M] | 作者. 书名[M]. 版次. 出版地: 出版者, 年. | 含出版社、ISBN |
| 学位论文 | [D] | 作者. 题名[D]. 保存地: 保存单位, 年. | 含学校、学位级别 |
| 会议论文 | [C] | 作者. 题名[C]//论文集编者. 论文集名. 出版地: 出版者, 年: 页. | 含会议名、conference |
| 论文集章节 | [M] | 作者. 章节题名[M]//编者. 书名. 出版地: 出版者, 年: 页. | 含 // 主书名 |
| 标准 | [S] | 标准编号, 标准名称[S]. | 含标准号如 GB |
| 专利 | [P] | 专利所有者. 专利题名: 专利国别, 专利号[P]. 公告日期. | 含专利号 |
| 报告 | [R] | 作者. 题名[R]. 出版地: 出版者, 年. | 含 report / 报告字样 |
| 电子资源 | [EB/OL] | 作者. 题名[EB/OL]. (发布日期)[引用日期]. URL. | 含 URL |
| 报纸文章 | [N] | 作者. 题名[N]. 报名, 出版日期(版次). | 含报纸名、版次 |

### 2. 多格式输出规范

详细格式模板与示例见 [references/formats.md](references/formats.md)。核心格式如下。

#### GB/T 7714-2015 顺序编码制

```
[1] 作者. 题名[文献类型标识]. 出版项.
[2] …
```

- 三人以内全列，超过三人列前三后加「, 等」(中文) 或「, et al.」(英文)
- 作者间用「,」分隔；最后作者前不加「和/and」
- 英文作者姓在前、名缩写在后（如 Smith J K）
- 卷期写法：`46(3): 512-525`
- 顺序编码：按正文引用顺序编号；无引用顺序时按字母序或用户给定顺序

#### APA 第 7 版

```
Author, A. A., & Author, B. B. (Year). Title. Source, volume(issue), pages. DOI
```

- 姓全拼、名缩写；作者间用「&」
- 期刊名、书名斜体；卷号斜体，期号不斜体
- 文献列表按第一作者姓字母序排列
- DOI 写成 `https://doi.org/10.xxx`

#### MLA 第 9 版

```
Author. Title of Source. Title of Container, Contributor, Version, Number,
Publisher, Publication Date, Location.
```

- 作者姓在前名在后（Full last, First）
- 书名、期刊名斜体；文章题名加引号
- 含 DOI 或 URL；MLA 9 倾向含 DOI

### 4. 字段缺失处理原则

- **不编造**：缺字段标注「待补」，不臆测数据、页码、年份、DOI
- **可推断**：中文期刊标题能推断学科但推不出卷期，仍标「待补」
- **DOI 优先**：有 DOI 时优先据 DOI 补全；无法联网则按字面生成并标「请核对」
- **多作者**：严格按各格式的人数阈值截断（GB/T 7714 三人后「等」；APA 20 人内全列、超 20 列前 19 + … + 末位；MLA 三人后「et al.」）

### 5. 交付检查

- [ ] 文献类型识别正确（类型标识与字段对应）
- [ ] 目标格式全部生成（用户要几种就出几种）
- [ ] 作者、年份、标题、出版项四要素齐全或已标「待补」
- [ ] 多作者截断符合各格式规则
- [ ] 中英文作者姓名格式区分正确
- [ ] 顺序编码按正文引用顺序或字母序排列
- [ ] 列表可直接复制到论文末尾，无多余符号

## 边界

- 不编造未提供的字段值（页码、卷期、DOI、年份、出版社）
- 不替代用户核对原文；标注「待补」「请核对」处需用户确认
- 不自动联网抓取文献元数据（除非用户明确要求用搜索工具）；DOI 字面信息生成时标「请核对」
- 不改变用户给定的事实信息（如作者顺序、年份）；仅做格式重排
- 中文姓名按原顺序输出（GB/T 7714 中文作者不倒置）；英文姓名按各格式规则倒置
