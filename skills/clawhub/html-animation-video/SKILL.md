# HTML 动画技能（29 种视觉风格 → 1080p 成片）

目标：一个主题 + 一种风格 = 一份可复现源码 + 1920×1080 / 30fps / 8 秒动画，可选渲染成 MP4。

## 执行流程

1. **确认主题与风格**。用户给了主题但没选风格 → 按主题气质推荐 2–3 个并说明理由，等确认（风格差异巨大，不猜）。用户已明确风格 → 直接开做。
2. **读风格档案**。打开 `assets/README.md`，找到对应风格的条目：画面要点 + 注意事项 + 去雷清单。**注意事项是硬约束**，每条都要在代码里落实。
3. **写源码**。单文件 `index.html`（内联 CSS/JS，零外部依赖；确需 CDN 时在文件头注释注明）。固定画布 1920×1080，时长 8 秒，循环或首尾呼应。
4. **交付 HTML**。先用 present_files 打开 `index.html` 让用户过目，附一段"本片做了什么、避了哪些雷"的说明。
5. **渲染 MP4（仅当用户要）**。按 `assets/README.md` 末尾"渲染章节"操作；playwright/ffmpeg 缺哪个装哪个，装不了就给用户手动录屏方案。

## 通用硬规则

- 帧率玩法（降帧、抽帧、steps()）用"渲染 30fps 但按目标帧率更新状态"实现，绝不输出低帧率文件。
- 像素风：所有坐标/位移取整，`image-rendering: pixelated`，整数倍放大。
- 时长控制：写一个 `T = 8` 秒的时间轴系统（分段 + 各段缓动），不要散落一堆 setTimeout。
- 每个风格至少对照一遍它的"避雷点"，交付说明里列出"避了哪几条"。
