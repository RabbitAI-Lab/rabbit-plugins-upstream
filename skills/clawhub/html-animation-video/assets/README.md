# 29 种风格档案（画面要点 / 注意事项 / 避雷清单）

> 用法：写代码前通读对应条目。"画面要点"是必须出现的元素，"避雷"是硬约束。

---

## 01｜复古纸张拼贴
- **技术**：HTML + CSS/JS
- **画面要点**：报纸牛皮纸底；抠图素材加 2–4px 白色剪刀边 + 投影；halftone 网点层；正负 2px 手摆抖动；拍上来/翻页转场；红黑构成主义字；勒索信拼字（多字体混排）。
- **注意**：满帧顺滑就没有手作感。
- **实现**：运动降到 **12fps**（甚至 6fps）——状态每 83ms（或 167ms）才更新一次；每拍加 ±2px 随机抖动。
- **避雷**：① 满帧顺滑像 PPT → 12fps + 抖动；② 缺撕边和投影会退成扁平矢量 → 每个素材必须有白剪刀边+投影；③ 字体只用一种没有拼贴味 → 标题用 3 种以上字体混拼。

## 02｜产品界面2.5D运镜
- **技术**：Remotion，或 Three.js 把截图贴到倾斜平面
- **画面要点**：真实页面截图（用户提供）；3D 倾斜做 2.5D 运镜；页面分层（前景/界面/背景不同 z）；卡点剪辑；数字滚动；闪帧；**关键信息停留 ≥1 秒**。
- **避雷**：① 节奏太快、整屏一拍一抖很廉价 → 放慢一档；② 界面文字必须真实可读，糊成灰条像占位图；③ 透视角度不要来回变，一条运镜走到底。

## 03｜霓虹复古 Synthwave
- **技术**：Canvas 或 WebGL
- **画面要点**：一点透视网格**持续向前滚动**；地平线分层渐变落日（大圆+切缝）；线条双层辉光；扫描线 + RGB 色偏；镀铬字；棕榈剪影；局部抽到 15fps 的磁带卡顿。
- **避雷**：① 网格不滚就是静态壁纸 → 镜头全程往前冲；② 颜色控制在品红/青/紫的霓虹系，混入橙会发脏；③ 辉光别叠太多层，糊成一片。

## 04｜纸面手绘笔记
- **技术**：HTML（SVG path 描边动画 + 手写字体）
- **画面要点**：米白纸面纹理；手绘细线器物（线要带轻微抖动，不能太规整像图标库）；手写体标题与用量；步骤编号卡；从空到成品逐步画出；刻度线；**每一步：动作和标签文字同一拍出现**。
- **避雷**：① 字和动作不同步就没有讲解感 → 每步同一帧出现；② 线条太规整像图标库 → 路径加微扰；③ 颜色一多压掉手绘感 → 铅笔灰 + 1 个强调色。

## 05｜水彩手绘
- **技术**：Canvas 2D
- **画面要点**：暖色棉纸纤维底；透明 wash 多层叠加越叠越深（globalAlpha 0.05–0.15/层）；dry-brush 飞白（低 alpha 短促断续笔触）；**纸白留作高光，颜色不填满**；手写批注+引线；逐笔上色动画；薄雾擦除转场；赭石/灰蓝低饱和色板。
- **避雷**：① 矢量形状贴水彩纹理一眼假 → 用**变宽笔触 + 毛刷轨迹**（一条笔触由多个半径渐变的圆叠成）；② 亮部留纸白；③ 颜色别填满整块，边缘留水渍感。

## 06｜黑白木刻版画
- **技术**：Canvas 2D
- **画面要点**：整块黑版，亮部是刀刻掉的白线；光是"刻"出来的，**画面逐刀刻出，不用淡入**；粗刀在前细线在后；刀线顺形体走；**最多一种颜色**（如朱红）；纸边留白；反字印章转场。
- **避雷**：① 每个面都排线会像毛和雨 → **只在受光边刻 3–6 刀**；② 淡入出现就不像刻的 → 刀痕逐条出现；③ 颜色最多一种。

## 07｜软体充气 3D
- **技术**：Blender（Python 脚本）或 Three.js 软体近似（顶点形变模拟挤压）
- **画面要点**：SSS 次表面散射软胶材质；糖果色；三点光 + HDRI；克隆阵列；软体碰撞挤压（落地压扁再快速弹起）；长尾缓动（回弹快、收尾慢）；浅景深 + 运动模糊；24fps 电影感。
- **避雷**：① 回弹一慢就没重量 → 下落加速、触地压扁 1–2 帧、弹起要快；② 缺 SSS 像硬塑料；③ 光打平像网页插图 → 强主光 + 冷轮廓光。

## 08｜点云测绘／剥层
- **技术**：Three.js（Points + 自定义 shader 更佳）
- **画面要点**：黑底悬浮真实测量点（程序生成地形/建筑点云也可，但要按地面/植被/建筑分类着色）；扫描面或剖切面推进；点经过扫描线后凝成掠射光实体；**按地面→植被→建筑逐层剥开**；发丝线测量读数；**一条设计好的运镜：镜头贴低穿点云而过**。
- **避雷**：① 远看像平地毯 → 镜头贴低穿越；② 点太稀读不出地形 → 密度要够（≥10 万点）；③ 剥层必须按分类分层，不是随机消隐。

## 09｜蓝图工程制图
- **技术**：Canvas 2D
- **画面要点**：普鲁士蓝晒图纸底（#0d3b8c 系 + 纸纹噪点）；**白色细线**；逐层绘制顺序（先中心线→轮廓→细节→标注）；尺寸线与引线；编号气泡；title block 图框；剖面线（45° 细线）；整张图纸平移缩放运镜。
- **避雷**：① 做成 3D 或发光线框就不像 → **只用蓝白两色的纯 2D 线稿**；② 线条一次全出现丢绘制感 → 按绘图顺序 stroke-dash 逐段画出。

## 10｜贴纸科普
- **技术**：HTML + CSS/JS
- **画面要点**：照片抠图或图标加 10px 白描边做成贴纸 + 投影；蓝灰/米白底；**配色 ≤3 色 + 1 强调色**；扁平图标配精确图表；超大画布（2–3 屏宽）；镜头长缓动平移缩放；柱状生长 + 数字滚动。
- **避雷**：① 配色超过三种就散；② **柱高和数字比例必须准**（数据错就没有科普严肃感）；③ 贴纸缺白边和投影就是普通抠图。

## 11｜动画电影式 3D 角色
- **技术**：Three.js 或 Blender，放开做
- **画面要点**：one-shot 8 秒小故事（按镜头分：出场→互动→落幅）；电影级逆光/夕阳布光；浅景深；角色有表情有表演（眼睛眨、身体起伏呼吸、转头）；轮廓光；电影字幕条（上下黑边+字幕）。
- **避雷**：① 只说"做个角色"会退成简陋小人 → **明确往最复杂最精致做**；② 没有景深和轮廓光就不像动画电影；③ 别让角色静止，时刻有微动作。

## 12｜中国水墨
- **技术**：Canvas 2D
- **画面要点**：程序宣纸纹理（米白+纤维噪点）；**墨分五色**（焦/浓/重/淡/清 五档灰）；**带墨量的毛笔笔触**（一条笔触内墨量从湿到枯渐变、飞白）、**不画闭合描边轮廓**（没骨法）；**留白 60–80%**；墨晕转场；**只盖一枚朱红印章**。
- **避雷**：① 矢量描边+笔刷贴图很假 → 笔触用墨量渐变的椭圆压痕叠加；② 不画闭合轮廓；③ 留白一少就成彩色插画 → 全片只用墨 + 一点朱红。

## 13｜ASCII 字符视觉
- **技术**：Canvas 2D 渲染字符网格（或 DOM pre）
- **画面要点**：monospace 字符网格（如 240×66）；琥珀色（#ffb000）或绿色荧光单色；CRT 扫描线 + 桶形畸变；bloom 辉光；**字符密度梯度：` .:-=+*#%@` 按亮度映射**；光标闪烁；**推拉镜头靠改字号做**；打字机字幕。
- **避雷**：① **整图套 ASCII 滤镜露馅 → 每一处亮点必须是网格里的真字符**（先离屏渲染形状读像素亮度，再逐格选字符）；② 字符集太少画面糊 → 至少 10 级密度；③ 所有文字（包括标题）都用字符画。

## 14｜等轴 2.5D 世界
- **技术**：Canvas 2D 手绘等轴面，或 Three.js OrthographicCamera
- **画面要点**：**固定 30° true isometric 投影，全程不变**；每个面三色调平涂（顶/左/右面各一色阶）；悬浮底座带剖面；Isotype 小图标计数表达数量；标签引线；cutaway 剖开展示内部；建筑生长带过冲（overshoot）；镜头沿路线平移（不旋转）。
- **避雷**：① 夹带透视或描边就变低多边形 3D → **正交投影、不描边**；② 镜头乱转破坏等轴感 → 只平移，不旋转缩放透视。

## 15｜梵高厚涂油画
- **技术**：Canvas 2D
- **画面要点**：先平涂底色；**沿流场（noise field）铺短粗厚涂笔触**；天空沿透视绕漩涡（星月夜式）；**每块区域十几种色相**的邻近色板；短粗笔触；深蓝描边；**笔触每秒换向 8 次（8fps 沸腾）**；墙/地/人物**分三遍分别铺笔触**；小物件单独成层。
- **避雷**：① 只换颜色不铺笔触就是普通插画；② 墙/地/人物不分层铺会糊成地毯；③ 全屏笔触一起抖会晕 → 分区域错开沸腾相位。

## 16｜虹彩迷幻 Shader
- **技术**：WebGL fragment shader
- **画面要点**：同心线（极坐标 sin 环）；**万花筒镜像对称（写明几重对称，如 8 重）**；旋涡隧道；**虹彩薄膜色（iridescence：按角度/法线取干涉色板）沿边缘流动**；高饱和撞色；VJ 循环（首尾衔接）。
- **避雷**：① 只写"迷幻"会退成普通渐变 → 对称方式和运动方式必须明确实现；② 虹彩色用 HSL 干涉色板，不要随机彩虹；③ 黑场开头剪掉，直接进入画面。

## 17｜黏土定格
- **技术**：Blender 或 Three.js（关键：抽帧）
- **画面要点**：黏土材质（粗糙+指纹/压痕法线细节）；**on twos：12fps 播放**（每 2 渲染帧换一次姿势）；**每拍形状微变 boil**（顶点加低频噪声）；柔光棚拍；浅景深微距；手工跳切节奏。
- **避雷**：① 动作一顺滑就像 CG → **抽帧到 12fps + 每拍形状微变**；② 材质没有指纹压痕就是塑料 → 加噪点 bump；③ 光要像桌面实拍，别用 HDRI 棚拍平光。

## 18｜像素游戏
- **技术**：Canvas 2D
- **画面要点**：内部 320×180 分辨率；**最近邻整数放大 6 倍**（`image-rendering: pixelated` + `imageSmoothingEnabled=false`）；**16–32 色有限色板**；精灵 8–12fps 阶梯帧动画；背景多层视差卷轴；**steps() 阶梯时序**；dithering 抖动过渡；游戏 HUD 像素字。
- **避雷**：① 平滑缩放/缓动会糊 → **所有坐标和位移取整数**，禁用插值；② 色板限 16–32 色，别超；③ 帧动画用离散帧，不做补间。

## 19｜扁平矢量
- **技术**：SVG + GSAP（或原生 JS 缓动）
- **画面要点**：纯色无渐变大色块；**5–6 种高饱和色板**；overshoot 弹性缓动（back.out）；预备动作（先反向压缩再冲出）+ 回弹；约 10% 挤压拉伸；元素 stagger 2–4 帧入场；形状擦除转场；**同一时刻只动一个主角**。
- **避雷**：① 加渐变就散 → 纯色；② 几个主体同时动就散 → 排队依次动；③ 色板 ≤6 色。

## 20｜印象派油画／莫奈
- **技术**：Canvas 2D
- **画面要点**：不勾边；水面用横向短笔触；**受光侧叠暖黄、背光侧叠淡紫（色彩阴影）**；亮色短笔光斑一闪一闪；**只让水面和光斑以 6fps 沸腾，地板/桥/建筑大面保持不动**；睡莲/日本桥母题可选；补色并置，别调成灰。
- **避雷**：① 全屏笔触一起抖会晕 → 只动水面光斑；② 笔触太大人物糊掉 → 人物区用小笔触；③ 阴影用紫不用灰黑。

## 21｜粒子聚散造型
- **技术**：Canvas 2D（≥10 万粒子用 WebGL/离屏优化）
- **画面要点**：数十万发光粒子（`globalCompositeOperation='lighter'`）；聚拢成目标形状（文字/图形采样点位）→ 停留 → 散开 → 下一个形状；深蓝黑底；部分粒子连线成关系网络；大数字计数器；一句英文结论字幕。
- **避雷**：① **粒子太少（<3 万）或没给目标形状就读不出造型** → 形状点位必须预采样；② 聚和散要有节奏（聚 2s→停 2s→散 1s），别一直飘；③ 加 additive blending 才有发光感。

## 22｜实体白模投影
- **技术**：Three.js
- **画面要点**：纯白体块城市/模型（材质纯白，**不带任何颜色**）；暗房展台；**数据以投影光（SpotLight/投影纹理）一层层打上去**；只亮朝向投影仪的面；柔和光边、溢出底座；一层一个问题（交通→人口→能耗）；开灯关灯作开场收尾；真实数据。
- **避雷**：① **白模本身带颜色就不是投影了，颜色只能来自投影光** → 材质纯白 + 暖色环境光关掉（会把白模染黄就用中性光）；② 字要投在模型上，别浮在屏幕上；③ 投影光角度固定，别乱晃。

## 23｜古埃及壁画
- **技术**：Canvas 2D
- **画面要点**：**侧脸正眼程式**（头侧、眼正、肩正、腿侧）；分栏横带 register 构图；象形文字栏；赭红/土黄/青金/孔雀绿矿物色平涂；黑色描边；太阳光线末端小手；墙面石灰质感噪点。
- **避雷**：① **别加透视和阴影，壁画是平的**；② 人物必须遵守正身侧脸规范姿势；③ 颜色只用矿物色；可以让河水和光线微微动，免得太静。

## 24｜产品爆炸拆解
- **技术**：Blender 或 Three.js
- **画面要点**：零件沿一根装配轴**等距分层抬起**；棚拍主光 + 冷色轮廓光；HDRI 反射；引线标注真实参数（**只写图纸里有的数，不许估**）；镜头在层间穿行；最后零件合拢回一体。
- **避雷**：① 型号和数字瞎编会露馅 → 没有真实数据就不标数；② 沿装配轴拆，不乱飞；③ 材质分清金属/塑料/PCB。

## 25｜纸面编辑式数据叙事
- **技术**：Canvas 2D
- **画面要点**：米色点阵纸底；真实数据逐点绘制（红蓝铅笔笔触质感）；手写批注钉在数据点旁；**RdBu 发散色阶**；**图表本身当镜头**（转场只靠图表变化：柱变线、轴缩放）；按数据选图型。
- **避雷**：① 别做成仪表盘或幻灯片 → **一次只讲一个观点**；② 转场只用图表本身的变化，不用滑页；③ 数据必须真实（可引用公开来源并在角落标出处）。

## 26｜玻璃拟态 UI
- **技术**：HTML + CSS（backdrop-filter）
- **画面要点**：底层 3–5 个大色斑（blur 80–150px）sine 慢速漂移；磨砂玻璃卡片（backdrop-filter: blur）；白色 5–10% 填充 + **1px 半透明白描边**；**邻近色两三色**（不要对比色）；3–5% 噪点防色带；全程呼吸感慢缓动。
- **避雷**：① 对比色/撞色显廉价 → 只用邻近色；② 动作一快就廉价 → 全程慢呼吸（4–6s 周期）；③ 缺 1px 白边和背景模糊就像普通卡片。

## 27｜积木玩具
- **技术**：Blender 或 Three.js
- **画面要点**：真实木桌微距拍；亮面 ABS 塑料（矩形高光）+ **顶面凸点**；缝隙接触阴影；角色两帧一拍定格（on twos）；**镜头逐帧顺滑**（镜头不抽帧，只有角色抽帧）；中性棚拍 HDRI。
- **避雷**：① **别出现品牌字样和小人轮廓**（版权风险）→ 角色用积木拼出；② 凸点和塑料高光必须有；③ 景深要浅才像微距实拍。

## 28｜Risograph 孔版套印
- **技术**：Canvas 2D
- **画面要点**：两三种专色（spot ink）；**每块颜色来自独立分版，multiply 叠出第三色**；**套印错位**（各版偏移 2–4px、方向不同）；halftone 网点（三块版**网角错开**，如 15°/45°/75°）；颗粒针孔；暖白纸底；无轮廓色块；角色 12fps、镜头 24fps。
- **避雷**：① 矢量图加噪点不算 Riso → **必须分版叠印**；② 没有套印错位就不像；③ 三块版网角必须错开，不然出摩尔纹。

## 29｜科幻扫描 HUD
