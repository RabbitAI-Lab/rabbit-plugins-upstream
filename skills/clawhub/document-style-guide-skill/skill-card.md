## Description: <br>
Assists with drafting, reviewing, polishing, and rewriting Chinese technical documentation, including READMEs, API docs, product manuals, tutorials, changelogs, and UI copy. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[ares0x](https://clawhub.ai/user/ares0x) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, technical writers, and product teams use this skill to review or rewrite Chinese technical documentation for spacing, sentence length, tone, punctuation, terminology, Markdown structure, changelog style, and UI copy consistency. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad document-writing prompts may activate the skill when the user intended another language or a non-technical writing style. <br>
Mitigation: Use explicit prompts that specify Chinese technical documentation, or state the intended language and style when a different writing mode is needed. <br>
Risk: Rewrite mode may alter wording in ways that change meaning, omit nuance, or make unsupported content sound more polished. <br>
Mitigation: Review rewritten output against the source document and verify factual claims, data, product names, and user-facing instructions before publishing. <br>
