# 参考：术语一致性规范

> 补充规范，原始文档未涵盖。适用于所有技术文档的术语管理。

---

## 一、核心原则

**同一概念在全文只能有一个称呼。**

在开始写作前，为每个核心概念确定唯一的中文或英文名称，并在全文严格统一使用。

---

## 二、同义词统一

### 规则 1：确定术语首选项，全文统一

写作前建立术语表，明确每个概念的唯一称呼，避免同义词混用。

**❌ 常见混用示例**

| 概念 | 混用示例（不可接受） |
|------|---------------------|
| 配置文件 | "配置文件"、"配置"、"设置文件"、"设定文件" 混用 |
| 代码仓库 | "仓库"、"代码库"、"repo"、"repository" 混用 |
| 部署 | "部署"、"发布"、"上线"、"deploy" 混用 |
| 用户界面 | "UI"、"界面"、"用户界面"、"前端页面" 混用 |

**✅ 正确做法**：确定一个术语，全文统一使用。

---

### 规则 2：中英文术语选用原则

| 情形 | 建议 | 示例 |
|------|------|------|
| 有通用中文译名 | 使用中文 | 使用"数据库"，不用"database" |
| 中文译名存在歧义或不通用 | 保留英文 | 使用"hook"，不用"钩子"（若读者群体不熟悉） |
| 首次出现的英文缩写 | 中文全称 + 英文缩写 | `持续集成（CI，Continuous Integration）` |
| 已在圈内约定俗成的英文词 | 英文原词 | API、SDK、CLI、PR、README 等不必翻译 |

---

### 规则 3：中英文缩写首次出现必须展开

英文缩写首次出现时，必须给出中文全称。此后文章中可直接使用缩写。

```
持续集成（CI，Continuous Integration）是现代软件开发的核心实践。
CI 可以……（后文直接使用缩写）
```

同样适用于中文缩略语：

```
自然语言处理（NLP）是人工智能的重要分支。
NLP 的核心任务包括……
```

---

## 三、品牌名与专有名词

### 规则 1：品牌名称大小写必须准确

品牌名、产品名、技术名称的大小写必须与官方写法完全一致，不得随意更改。

| ❌ 错误写法 | ✅ 正确写法 |
|------------|------------|
| Github | GitHub |
| Javascript | JavaScript |
| Typescript | TypeScript |
| Nodejs | Node.js |
| Npm | npm |
| Ios | iOS |
| Macos | macOS |
| Vscode | VS Code |
| Chatgpt | ChatGPT |
| Openai | OpenAI |
| Mysql | MySQL |
| Mongodb | MongoDB |
| Postgresql | PostgreSQL |
| Vuejs | Vue.js |
| Reactjs | React |
| Nextjs | Next.js |

> **处理方法**：遇到不确定的品牌名，查阅其官网首页或官方文档中的标准写法。

---

### 规则 2：产品功能名称统一

同一产品的功能名称在文档中必须统一，不得中英文混用或简称混用。

**❌ 错误**
```
你可以在"工作流"里配置任务。
也可以在 Workflow 中添加步骤。
进入"流程"页面后……
```

**✅ 正确**（全文统一使用中文"工作流"）
```
你可以在"工作流"里配置任务。
也可以在工作流中添加步骤。
进入工作流页面后……
```

---

## 四、数量词与量词

### 规则 1：统一计量单位的称呼

| 概念 | ❌ 混用 | ✅ 统一 |
|------|---------|---------|
| 存储容量 | "GB"、"G"、"Gb" 混用 | 统一使用 `GB` |
| 时间 | "毫秒"、"ms" 混用 | 在正文中统一（如代码注释用 `ms`，文字用"毫秒"） |
| 百分比 | "50%"、"百分之五十" 混用 | 技术文档统一使用 `50%` |

---

## 五、建议：文档级术语表

对于较长的技术文档（>3000 字），建议在文档开头或附录中维护一份术语表：

```markdown
## 术语表

| 术语 | 含义 | 说明 |
|------|------|------|
| 工作流 | Workflow | 本文统一使用"工作流" |
| CI | 持续集成（Continuous Integration） | 首次出现已展开 |
| 节点 | Node | 指计算节点，非 Node.js |
```

---

## 快速自查

- [ ] 同一概念全文只使用一种称呼
- [ ] 品牌名大小写与官方写法一致（GitHub / JavaScript / Node.js 等）
- [ ] 英文缩写首次出现已给出中文全称
- [ ] 中英文术语选用原则一致（有成熟中文译名则用中文）
- [ ] 计量单位在全文中统一
- [ ] 长文档已建立或维护术语表
