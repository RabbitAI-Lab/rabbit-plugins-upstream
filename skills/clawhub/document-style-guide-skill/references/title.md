# 参考：标题规范

> 来源：阮一峰《中文技术文档写作规范 · 标题》

---

## 层级定义

标题分为四级：

| 级别 | Markdown | 用途 |
|------|----------|------|
| 一级标题 | `# 标题` | 文章的标题（全文仅一个） |
| 二级标题 | `## 标题` | 文章主要部分的大标题 |
| 三级标题 | `### 标题` | 二级标题下面一级的小标题 |
| 四级标题 | `#### 标题` | 三级标题下某一方面的小标题（谨慎使用） |

---

## 原则

### 原则 1：不得跳级

一级标题下，不能直接出现三级标题，必须经过二级标题过渡。

**❌ 错误示例**

```markdown
# 一级标题

### 三级标题（缺少二级标题，属于跳级）
```

**✅ 正确示例**

```markdown
# 一级标题

## 二级标题

### 三级标题
```

---

### 原则 2：避免孤立编号

同级标题只有一个时，应该省略该层级或改用其他结构。

**❌ 错误示例**

```markdown
## 二级标题 A

### 三级标题 A   ← 只有一个三级标题，孤立编号

## 二级标题 B
```

**✅ 正确示例**

```markdown
## 二级标题 A

（直接在二级标题下写内容，无需三级标题）

## 二级标题 B
```

---

### 原则 3：下级标题不重复上级名称

**❌ 错误示例**

```markdown
## 概述

### 概述   ← 与上级同名
```

**✅ 正确示例**

```markdown
## 概述

### 背景
### 适用范围
```

---

### 原则 4：谨慎使用四级标题

尽量避免出现四级标题，防止章节结构过于复杂。

如果三级标题下有并列性的内容，优先使用**加粗列表项**代替四级标题。

**结构一（较少使用场景，适合长篇内容）**

```markdown
### 三级标题

#### 四级标题 A

#### 四级标题 B

#### 四级标题 C
```

**结构二（推荐，适合大多数场景）**

```markdown
### 三级标题

**（1）A**

**（2）B**

**（3）C**
```

---

## 快速自查

- [ ] 全文只有一个一级标题（`#`）
- [ ] 没有跳过层级（如从 H1 直接到 H3）
- [ ] 没有孤立的单个同级标题
- [ ] 下级标题不与上级标题同名
- [ ] 四级标题出现次数极少或为零
