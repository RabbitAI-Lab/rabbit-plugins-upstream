# 参考：数值规范

> 来源：阮一峰《中文技术文档写作规范 · 数值》

---

## 一、半角数字

阿拉伯数字一律使用**半角**形式，不得使用全角形式。

| 类型 | ❌ 错误 | ✅ 正确 |
|------|---------|---------|
| 价格 | 这件商品的价格是１０００元。 | 这件商品的价格是 1000 元。 |
| 数量 | 共有５个文件。 | 共有 5 个文件。 |

> **提示**：全角数字（`１２３`）与半角数字（`123`）的区别在于字符宽度。技术文档中一律使用半角。

---

## 二、千分号

数值为千位以上时，应添加千分号（半角逗号 `,`）。

```
XXX 公司的实收资本为 ￥1,258,000 人民币。
```

### 4 位数值的处理

| 数值位数 | 千分号 | 说明 |
|----------|--------|------|
| 4 位 | 可选 | `1000` 和 `1,000` 均可接受 |
| 5 位及以上 | 必须加 | `12,345`、`1,234,567` |

---

## 三、货币

货币金额使用阿拉伯数字，格式选择其一：
- 数字前写货币符号：`$1,000`
- 数字后写货币中文名称：`1,000 美元`

```
✅ $1,000
✅ 1,000 美元
✅ ¥5,000
✅ 5,000 元人民币
```

> **参考标准**：英文货币名称建议参考 [ISO 4217](https://en.wikipedia.org/wiki/ISO_4217)。

---

## 四、数值范围

表示数值范围时，使用**波浪线**（`～`）或**一字线**（`—`）连接：

```
132 kg～234 kg
2009 年～2011 年
10:00—18:00
```

### 带单位或百分号的范围

两个数字**都**要加上单位或百分号：

| ❌ 错误 | ✅ 正确 |
|---------|---------|
| `132～234 kg` | `132 kg～234 kg` |
| `67～89%` | `67%～89%` |

---

## 五、变化程度的表示法

### 增加

| 用法 | 含义 | 示例 |
|------|------|------|
| 增加**到** X 倍 | 定量（现在的值） | 增加到过去的两倍（过去为 1，现在为 2） |
| 增加**了** X 倍 | 增量 | 增加了两倍（过去为 1，现在为 3） |

### 减少

| 用法 | 含义 | 示例 |
|------|------|------|
| 降低**到** X | 定量（降到此值） | 降低到百分之八十（原 100，现 80） |
| 降低**了** X | 减少量 | 降低了百分之八十（原 100，现 20） |

### 禁止用法

❌ **不能使用"降低 N 倍"或"减少 N 倍"的表示法。**

因为"减少一倍"意味着数值变为零，逻辑上不成立。应改用"降低百分之几"或"减少百分之几"。

```
❌ 降低了 2 倍
✅ 降低了 50%
```

## 快速自查

- [ ] 所有阿拉伯数字使用半角形式
- [ ] 5 位及以上数字已添加千分号
- [ ] 货币金额格式正确（符号在前或中文名称在后）
- [ ] 数值范围使用 `～` 或 `—` 连接
- [ ] 范围两端都带有单位或百分号
- [ ] 变化程度表述使用"了/到"区分增量/定量
- [ ] 未使用"减少 N 倍"等不当表示法
