> **使用方法**：根据文档类型选择对应场景的 Checklist，逐项标记 ✅ / ❌ / N/A。

## 场景一：精简版 · UI 文案

> 适用：按钮文案、提示文案（Toast）、错误信息、空状态、表单标签、加载状态等。

- [ ] **U1**：按钮文案使用动宾结构（"立即下载"而非"下载功能"）
- [ ] **U2**：按钮字数 ≤ 5 字；危险操作按钮包含操作对象（"删除账号"而非"删除"）
- [ ] **U3**：Toast/提示文案字数 ≤ 20 字
- [ ] **U4**：错误提示包含"发生了什么 + 用户能做什么"，且不暴露技术细节
- [ ] **U5**：空状态文案包含"原因 + 引导操作"两部分
- [ ] **U6**："你"与"您"全产品统一，未混用
- [ ] **U7**：未使用"我们"代指系统
- [ ] **U8**：中文与英文/数字之间有半角空格（如"上传 3 个文件"）

## 场景二：标准版 · README / 技术文档

> 适用：README、API 文档、教程、博客文章、技术规范（< 2000 字）。

### 标题结构

- [ ] **H1**：全文只有一个一级标题（`#`）
- [ ] **H2**：没有跳级（H1 → H3 缺少 H2）
- [ ] **H3**：没有孤立的单个同级标题
- [ ] **H4**：下级标题不与上级标题同名

### 文本与句子

- [ ] **T1**：中文与英文之间有半角空格
- [ ] **T2**：中文与数字间距风格全文统一（有空格或无空格，选一种）
- [ ] **T3**：英文/数字与全角标点之间无空格（`MacBook Air。` ✓）
- [ ] **T4**：没有超过 40 字的单句
- [ ] **T5**：使用主动语态，无被动语态
- [ ] **T6**：使用肯定句，无双重否定句
- [ ] **T7**："你"/"您"全文统一
- [ ] **T8**：未使用"我们"代指系统或产品
- [ ] **T9**：操作步骤使用直接命令句（动词开头）

### Markdown 格式

- [ ] **M1**：所有代码块已标注语言类型（````bash`、````json` 等）
- [ ] **M2**：步骤类内容使用有序列表；并列内容使用无序列表
- [ ] **M3**：列表项标点风格统一（同一列表全加或全不加句号）
- [ ] **M4**：链接文本具有描述性（无"点击这里"、"这里"）

### 标点符号

- [ ] **P1**：并列词使用顿号（`、`），非逗号（`，`）
- [ ] **P2**：省略号使用 `⋯⋯`（六点），非 `...`
- [ ] **P3**：引号使用弯引号（`" "`），非直引号

### 术语一致性

- [ ] **V1**：品牌名大小写正确（GitHub / JavaScript / Node.js / VS Code 等）
- [ ] **V2**：同一概念全文只用一种称呼
- [ ] **V3**：英文缩写首次出现已给出中文全称

## 场景三：完整版 · 产品手册 / 长篇文档

> 适用：完整产品手册、技术规范、长篇教程（> 2000 字）。包含标准版全部条目，并增加以下检查。

### 继承标准版全部 25 条，再加以下条目：

#### 标题扩展

- [ ] **H5**：四级标题使用极少（有并列内容时优先用加粗列表替代）
- [ ] **H6**：各章节标题能独立传达信息，不依赖上下文

#### 句子与段落（扩展）

- [ ] **T10**：整段逗号分隔的长句总长 ≤ 100 字
- [ ] **T11**：使用简单句和并列句为主，复合句极少
- [ ] **T12**：每个段落只有一个主题
- [ ] **T13**：段落第一句是中心句
- [ ] **T14**：段落长度 ≤ 7 行（最佳 ≤ 4 行）
- [ ] **T15**：段落之间用一个空行隔开
- [ ] **T16**：段落开头无缩进空白

#### 写作风格（扩展）

- [ ] **S1**："的""地""得"使用正确
- [ ] **S2**：代词指代明确，无歧义（"其""该""此"等）
- [ ] **S3**：名词前无过多堆叠的形容词（拆分表达）
- [ ] **S4**：无冷僻词、生造词或文言词
- [ ] **S5**：无感叹号，或无多个感叹号连用
- [ ] **S6**：无多余客套语

#### 英文处理（扩展）

- [ ] **E1**：翻译英文复数时已还原为单数
- [ ] **E2**：中文中的省略号为 `⋯⋯`，非 `...`
- [ ] **E3**：英文书名/电影名已改用书名号（`《》`）
- [ ] **E4**：专有名词首字母大写，非专有名词不大写

#### 数值（扩展）

- [ ] **N1**：所有阿拉伯数字使用半角形式
- [ ] **N2**：5 位及以上数字已添加千分号（`1,258,000`）
- [ ] **N3**：数值范围使用 `～` 或 `—`，两端都带单位
- [ ] **N4**：变化程度使用"了/到"区分增量/定量
- [ ] **N5**：未使用"减少 N 倍"等不当表示法

#### 标点符号（扩展）

- [ ] **P4**：中文语境全部使用全角标点
- [ ] **P5**：英文整句使用半角标点
- [ ] **P6**：无标点位于行首
- [ ] **P7**：标题末尾无点号（句号/逗号/分号等）
- [ ] **P8**：句末括号加注时，句号在括号之外
- [ ] **P9**：引号嵌套时外层双引号、内层单引号（`" "` 和 `' '`）
- [ ] **P10**：省略号与"等"字不同时出现

#### Markdown 格式（扩展）

- [ ] **M5**：图片 alt text 已填写且有描述性内容
- [ ] **M6**：表格有表头，列数 ≤ 5 列
- [ ] **M7**：加粗只用于真正需要强调的关键词，无装饰性加粗
- [ ] **M8**：列表嵌套不超过两层
- [ ] **M9**：标题前后有空行
- [ ] **M10**：引用内容已注明出处

#### 术语（扩展）

- [ ] **V4**：计量单位在全文中统一
- [ ] **V5**：中英文术语选用一致（有成熟中文译名则用中文）
- [ ] **V6**：长文档已建立或维护术语表

#### 文档体系（针对完整手册）

- [ ] **D1**：文件名无空格，只使用半角字符
- [ ] **D2**：文件名只使用小写字母（`README`、`LICENSE` 等特殊文件除外）
- [ ] **D3**：多单词文件名使用 `-` 连接（`advanced-usage.md`）
- [ ] **D4**：文档包含必备章节（简介、环境准备、配置）
- [ ] **D5**：文档结构层次合理，无冗余章节
