# 参考：标点符号规范

> 来源：阮一峰《中文技术文档写作规范 · 标点符号》

---

## 总体原则

| # | 原则 |
|---|------|
| 1 | 中文语句的标点符号，均应该采取**全角符号**，与全角文字保持视觉一致 |
| 2 | 如果整句为英文，则该句使用**英文/半角标点** |
| 3 | 句号、问号、叹号、逗号、顿号、分号和冒号**不得出现在行首** |
| 4 | 点号（句号、逗号、顿号、分号、冒号）**不得出现在标题末尾**；标号（引号、括号、破折号、省略号、书名号、着重号、间隔号、叹号、问号）可以 |

---

## 句号

**规则 1**：中文语句结尾使用全角句号（`。`）。

**规则 2**：句末括号加注时，句号应在括号之外。

| ❌ 错误 | ✅ 正确 |
|---------|---------|
| 请参照第 1.3 节（见第 26 页。） | 请参照第 1.3 节（见第 26 页）。 |

---

## 逗号

- 逗号（`，`）表示句子内部的一般性停顿。
- ⚠️ 注意避免**"一逗到底"**：整个段落除结尾外，所有停顿都用逗号，这是不规范的写法。

---

## 顿号

**规则 1**：句子内部的并列词，用全角顿号（`、`）分隔，不用逗号，即使并列词是英语也是如此。

| ❌ 错误 | ✅ 正确 |
|---------|---------|
| Google, Facebook, 腾讯, 阿里和百度 | Google、Facebook、腾讯、阿里和百度 |

**规则 2**：英文句子中，并列词之间使用半角逗号（`,`）分隔。

```
Microsoft Office includes Word, Excel, PowerPoint, Outlook and other components.
```

**规则 3**：中文句子的并列词，最后一个尽量用"和"连接（两种写法均可，第二种更优）：

```
✅ 可接受：Google、Facebook、腾讯、阿里，以及百度等。
✅ 更优：   Google、Facebook、腾讯、阿里和百度等。
```

---

## 分号

分号（`；`）表示复句内部并列分句之间的停顿，比逗号停顿更长、比句号停顿更短。

```
北京是中国的首都；上海是中国的经济中心。
```

---

## 引号

**规则 1**：引用时使用全角双引号（`" "`），注意前后引号形状不同。

```
许多人都认为客户服务的核心是"友好"和"专业"。
```

**规则 2**：引号嵌套时，外层用双引号，内层用单引号（`' '`）。

```
鲍勃解释道："我要放音乐，可萨利说，'不行！'。"
```

> ⚠️ **注意**：不要使用 ASCII 直引号（`"` 和 `'`），必须使用弯引号。

---

## 括号

**规则 1**：补充说明时使用全角圆括号（`（）`），括号前后**不加空格**。

```
请确认所有的连接（电缆和接插件）均安装牢固。
```

**规则 2**：各种括号的名称对照表。

| 符号 | 英文名 | 中文名 |
|------|--------|--------|
| `{ }` | braces 或 curly brackets | 大括号 |
| `[ ]` | square brackets 或 brackets | 方括号 |
| `< >` | angled brackets | 尖括号 |
| `( )` | parentheses | 圆括号 |

---

## 冒号

**规则 1**：全角冒号（`：`）用于需要解释的词语后边，引出解释和说明。

```
请确认以下几项内容：时间、地点、活动名称和来宾数量。
```

**规则 2**：表示时间时，使用半角冒号（`:`）。

```
早上 8:00
```

---

## 省略号

**规则 1**：省略号（`⋯⋯`）表示语句未完或语气不连续。

**规则 2**：省略号占两个汉字空间，包含六个省略点，**不要使用**以下非标准形式：

| ❌ 非标准 | ✅ 标准 |
|----------|---------|
| `...` | `⋯⋯` |
| `。。。` | `⋯⋯` |
| `….` | `⋯⋯` |

**规则 3**：省略号不应与"等"字一起使用。

| ❌ 错误 | ✅ 正确 |
|---------|---------|
| 有香蕉、苹果、梨…等各色水果 | 有香蕉、苹果、梨⋯⋯（去掉"等"） |
| 有香蕉、苹果、梨…等各色水果 | 有香蕉、苹果、梨等各色水果（去掉省略号） |

---

## 感叹号

**规则 1**：使用平静的语气叙述，**尽量避免**使用感叹号（`！`）。

**规则 2**：**不得**多个感叹号连用（如 `！！` 或 `!!!`）。

---

## 破折号

**规则 1**：破折号（`————`）一般用于进一步解释。

**规则 2**：破折号应占两个汉字的位置。

- 如果破折号本身占两个汉字位置（`————`），前后不留空格：
  ```
  直觉————尽管它并不总是可靠的————告诉我，这事可能出了些问题。
  ```
- 如果破折号只占一个汉字位置（`—`），前后各留一个半角空格：
  ```
  直觉 —— 尽管它并不总是可靠的 —— 告诉我，这事可能出了些问题。
  ```

---

## 连接号

**规则 1**：连接号用于连接两个类似的词。

**规则 2**：以下场合使用**直线连接号**（`-`），占一个半角字符：

| 场合 | 示例 |
|------|------|
| 两个名词的复合 | 氧化-还原反应 |
| 图表编号 | 图 1-1 |

**规则 3**：数值范围使用**波浪连接号**（`～`）或**一字号**（`—`），占一个全角字符：

```
2009 年～2011 年
```

波浪连接号前后两个值**都建议**加上单位。

**规则 4**：波浪连接号可以用汉字"至"代替：

```
周围温度：-20 °C 至 -10 °C
```

## 标点符号速查表

| 符号 | 名称 | 用途 | 形式 |
|------|------|------|------|
| `。` | 句号 | 中文语句结尾 | 全角 |
| `，` | 逗号 | 句内一般停顿 | 全角 |
| `、` | 顿号 | 并列词分隔 | 全角 |
| `；` | 分号 | 并列分句停顿 | 全角 |
| `：` | 冒号 | 引出解释说明 | 全角 |
| `:` | 冒号 | 表示时间 | 半角 |
| `" "` | 双引号 | 引用 | 全角弯引号 |
| `' '` | 单引号 | 嵌套引用 | 全角弯引号 |
| `（）` | 圆括号 | 补充说明 | 全角 |
| `⋯⋯` | 省略号 | 语句未完 | 六点两格 |
| `！` | 感叹号 | 尽量避免 | 全角 |
| `————` | 破折号 | 进一步解释 | 两格宽 |
| `～` | 波浪连接号 | 数值范围 | 全角 |
| `-` | 直线连接号 | 复合名词/图表编号 | 半角 |

## 快速自查

- [ ] 中文语境全部使用全角标点
- [ ] 英文整句使用半角标点
- [ ] 无句号/逗号/顿号/分号/冒号位于行首
- [ ] 标题末尾无点号
- [ ] 并列词使用顿号（`、`）而非逗号（`，`）
- [ ] 省略号使用 `⋯⋯`（六点），不用 `...`
- [ ] 省略号与"等"不同时出现
- [ ] 无感叹号或多个感叹号连用
- [ ] 引号使用弯引号（`" "`、`' '`），不用直引号
- [ ] 括号前后无多余空格
- [ ] 句号在括号之外
