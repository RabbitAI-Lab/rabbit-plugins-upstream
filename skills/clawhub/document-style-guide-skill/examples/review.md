# Few-shot 示例：Review（审校）模式

本文档展示 **Review 模式**的完整工作流程与输出格式。

---

## 输入文档

以下是一份待审校的技术 README 草稿：

---

```markdown
# 快速上手指南

### 环境要求

在开始之前，请确认你的电脑上安装了以下软件：Node.js(版本要求>=16)，npm或者yarn包管理器，Git版本控制工具。

## 安装步骤

**第一步**：首先你需要克隆仓库到本地。克隆命令如下所示，可以在终端中执行这个命令来获取代码，这个操作会把远程仓库的所有文件下载到你的本地电脑上。

    git clone https://github.com/example/project.git

**第二步**：安装依赖。

**第二步**：启动项目

这个项目可以被用下面的命令来启动！！

    npm run dev

如果一切正常，你会在浏览器中看到项目运行的界面等…

## 常见问题

Q：端口被占用了怎么办？

A：没有被占用端口的情况下，项目会自动选择3000端口。
```

## 说明

以上示例展示了 Review 模式的核心行为：

1. **发现所有违规点**，包含位置、原文、问题描述、严重程度
2. **给出具体修改建议**，而不是只说"有问题"
3. **对于复杂改写**，提供修改版供参考
4. **严重程度分级**帮助作者优先处理关键问题
