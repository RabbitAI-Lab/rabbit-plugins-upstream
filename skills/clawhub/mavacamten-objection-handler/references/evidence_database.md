## 二、药代动力学对比

| 参数 | 玛伐凯泰 | 阿夫凯泰 |
|------|----------|----------|
| 半衰期 | 6-9天 | 75-85小时 |
| 主要代谢酶 | CYP2C19（主要），CYP3A4、CYP2C9（次要） | 多种酶代谢，关键代谢酶存在基因多态性 |
| 基因多态性影响 | CYP2C19受基因多态性影响 | 多通路代谢 |
| IC50/IC10比值 | 2.8 | 9.9（理论值，需临床验证） |
| 起始剂量（中国） | 2.5mg qd | 5mg qd |
| 最大剂量 | 15mg qd | 20mg qd |
| 滴定间隔 | 前12周不上调，之后每12周评估 | 每2周可上调，每次递增5mg |
| 达稳态时间 | 较长（半衰期长） | 较短（半衰期短） |

### 药代动力学关键解读

1. **半衰期与稳态浓度**：专家共识指出"在给药间隔一致的情况下，半衰期越长，血药浓度越平稳，单次漏服或多服药物时，对血药浓度的影响越小"
2. **玛伐凯泰长半衰期优势**：稳态血药浓度更平稳，LVEF波动风险更低
3. **IC50/IC10值**：阿夫凯泰较高值提示更宽的治疗窗口，但这是理论计算值，仍需在中国人群临床实践中验证
4. **CYP2C19基因检测**：田庄教授明确"CYP2C19代谢型和药物反应不完全相关，临床实践中不需要常规进行CYP2C19检测调整剂量"

## 五、安全性数据

### 5.1 玛伐凯泰安全性

| 数据来源 | LVEF<50%发生率 | 停药率 | 其他 |
|----------|------|------|------|
| EXPLORER-CN（30周） | **0%（无患者）** | 0% | 无因TEAE停药 |
| EXPLORER-HCM（长期） | 8.7%一过性<50% | 停药后均恢复 | 14例重新启动 |
| REMS真实世界（N≈12,000，34月） | 5.59/100患者年 | — | 心衰住院1.33/100患者年；药物相互作用检查仅0.3% |

### 5.2 阿夫凯泰安全性

| 数据来源 | 关键发现 |
|----------|----------|
| SEQUOIA-HCM | 不良事件发生率与安慰剂相当 |
| 2026年荟萃分析 | 阿夫凯泰在LVEF降低幅度上可能表现出更大的效应 |
| 长期安全性 | FOREST-HCM数据仍在积累中 |

### 5.3 安全性关键解读

1. 2026年荟萃分析提示阿夫凯泰LVEF降低幅度可能更大，需头对头研究验证
2. 玛伐凯泰中国滴定方案（2.5mg起始）在EXPLORER-CN中实现零LVEF<50%事件
3. 玛伐凯泰拥有全球最大CMI真实世界安全性数据库（REMS，约12,000例）

## 七、共识与指南引用

### 《心肌肌球蛋白抑制剂药物治疗专家共识》（2026年）
- 我国药学领域首部CMI权威指导文件
- 玛伐凯泰：2.5mg起始，前12周不上调，每4周监测LVEF和LVOTG
- 阿夫凯泰：5mg起始，每2周可上调5mg，快速达最优剂量
- 半衰期越长，血药浓度越平稳
- LVEF<50%需立即停药

### 《中国心肌病综合管理指南2025》
- 玛伐凯泰称为"首个"CMI
- 阿夫凯泰称为"第二个"CMI

### CMI之父Spudich教授观点
- 阿夫凯泰在肌球蛋白头部的结合位点与玛伐凯泰**并不相同**
- 不是简单的迭代升级
