# 玛伐凯泰竞品异议处理助手 (Mavacamten Objection Handler)

## 简介

面向医药代表和医学 liaison 的竞品异议处理智能辅助工具。当面对竞品阿夫凯泰片（Aficamten / CK-274）的异议时，自动识别异议类型，调取循证数据，生成结构化的话术建议。

## 适用场景

- 学术拜访前的竞品异议预判和话术准备
- 科室会答疑环节的即时应对
- 圆桌讨论中的数据支撑
- 微信群快速答疑

## 核心能力

### 六大异议域覆盖

| 异议域 | 竞品常见攻击 | 核心回应策略 |
|--------|-------------|-------------|
| 药代动力学 | "半衰期短、滴定快" | 长半衰期 = 稳态平稳 = 安全可控 |
| 安全性 | "治疗窗口更宽" | 理论值 vs 万例真实世界数据 |
| 临床疗效 | "十项终点全达标" | 数据量级对比 + 独有纤维化改善 |
| 证据成熟度 | "第二代优化升级" | 首创定义范式，非简单迭代 |
| 适应症 | "还能治 nHCM" | 聚焦已获批 oHCM，nHCM 尚未获批 |
| 使用便利性 | "滴定更快更方便" | 谨慎滴定换零 LVEF 事件 |

### 玛伐凯泰八大差异化锚点

1. **中国独立 III 期研究**（EXPLORER-CN）
2. **真实世界生存获益**（全因死亡风险↓73%）
3. **心肌纤维化改善**（LGE 6SD 显著降低）
4. **逆转重构深度**（LVMI -30.8 g/m²）
5. **真实世界数据规模**（REMS N≈12,000，34 个月）
6. **医保覆盖**（已入国家医保）
7. **中国安全性方案**（2.5mg 起始，零 LVEF<50%）
8. **单药治疗证据**（四项 III 期汇总 + RWS）

## 使用方式

直接用自然语言描述竞品异议场景即可，例如：

```
客户说阿夫凯泰半衰期短、滴定快，比玛伐凯泰方便，怎么回应？
```

Skill 会自动识别异议类型并输出结构化话术建议。
