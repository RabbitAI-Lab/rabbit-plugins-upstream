# 运营资料生成模板库

> 本文件定义12类运营资料的生成模板与规范。生成时严格遵循对应模板结构，从 `company_profile.md` 提取素材填充。

---

## 1. 品牌介绍文案

### 用途
官网关于我们、宣传册首页、合作方案品牌介绍、平台机构简介

### 模板结构
```
【标题】一句话定位 + 机构全称
【开篇】成立背景 + 核心理念引出（1段）
【核心优势】3-5条要点，每条含数据支撑（列表）
【服务范围】诊疗方向枚举（列表）
【团队亮点】刘国忠主任 + 特聘专家 + 助理团队（1段）
【信任背书】关键数据汇总（2025门诊2万人次/3000余名新生儿/抱婴成功率90%+）
【结语】品牌愿景 + 联系引导
```
### 字数控制
- 短版：300-500字（平台简介用）
- 长版：800-1200字（宣传册/合作方案用）

## 2. 朋友圈文案集

### 用途
医生个人朋友圈、中心官方朋友圈、助理团队朋友圈日常运营

### 模板结构（每条）
```
【钩子开头】提问/数据/情感共鸣（1句，15字以内）
【核心内容】案例要点/科普知识/中心动态（2-3句）
【价值升华】科学保胎理念自然融入（1句）
【行动引导】咨询/预约/直播提醒（1句）
【Emoji】1-3个，克制使用
```
### 生成类型
| 类型 | 示例触发词 | 内容方向 |
|------|-----------|---------|
| 报喜分享型 | "写报喜朋友圈" | 案例库中选取，突出数据对比 |
| 科普知识型 | "写科普朋友圈" | 胎停原因/保胎时机/用药误区 |
| 日常温情型 | "写日常朋友圈" | 候诊环境/团队服务/患者反馈 |
| 直播预告型 | "写直播预告" | 直播主题+时间+平台+亮点 |
| 节日关怀型 | "写节日朋友圈" | 节日祝福+孕育鼓励 |

### 批量生成
一次生成5-10条，标注类型，便于排期使用。

## 3. 小红书种草文案

### 用途
小红书平台内容运营，吸引备孕/保胎目标用户

### 模板结构
```
【标题】痛点关键词 + 数字 + 情绪词（20字以内，含emoji）
【正文开头】第一人称/第二人称代入，引发共鸣
【核心内容】3-5个要点，每点配emoji小标题
【信任建立】数据/案例/资质自然植入
【互动引导】提问结尾，引导评论收藏
【话题标签】#保胎 #复发性流产 #刘国忠保胎 等8-12个
```
### 内容方向
- 保胎成功案例分享（化名，保护隐私）
- 科普类：反复胎停原因、保胎用药误区、宫颈机能不全
- 体验类：就诊流程、远程问诊体验、助理服务
- 对比类："大礼包"用药 vs 科学保胎

## 4. 公众号文章

### 用途
微信公众号深度内容，建立专业权威形象

### 模板结构
```
【标题】痛点/悬念 + 价值承诺（不超过30字）
【导语】场景代入或数据引入（100字以内）
【正文】
  - 小标题分段，每段300-500字
  - 穿插案例（从案例库选取，化名处理）
  - 穿插科普知识
  - 适当加粗关键数据/结论
【结语】理念升华 + 行动引导
【尾部】中心介绍卡 + 联系方式 + 二维码引导
```
### 字数控制
- 短文：1500-2000字
- 深度文：2500-4000字

### 选题方向
| 系列 | 示例选题 |
|------|---------|
| 案例系列 | 《41岁8次不良孕史，仅用4种药迎来龙凤胎》 |
| 科普系列 | 《反复胎停的6大原因，你中招了几个？》 |
| 理念系列 | 《保胎不是大礼包：为什么药不是饭？》 |
| 专家系列 | 《刘国忠：从武警医院到坤如玛丽，8年保胎路》 |
| 时令系列 | 《高龄备孕如何提高成功率？》 |

## 5. 短视频脚本

### 用途
抖音/快手/视频号短视频内容

### 模板结构（30秒-60秒）
```
【场景】诊室/候诊区/直播间（标注拍摄场景）
【0-3秒·钩子】提问/数据/反转，抓住注意力
【3-15秒·痛点】描述患者常见困境或误区
【15-40秒·方案】科学保胎理念 + 具体做法
【40-50秒·案例】简述一个成功案例（数据对比）
【50-60秒·引导】关注/咨询/预约
```
### 脚本格式
| 时间 | 画面/字幕 | 口播台词 | 备注 |
|------|----------|---------|------|
| 0-3s | 字幕大字 | "胎停3次，还能当妈妈吗？" | 配悬念音乐 |
| ... | ... | ... | ... |

### 内容方向
- 案例反转类（大方案→少用药→成功）
- 科普答疑类（直播切片/口播）
- 误区纠正类（"大礼包"用药危害）
- 日常记录类（门诊日常/患者报喜）

## 6. 客户案例包装

### 用途
官网案例展示、宣传册案例页、销售演示、社交媒体长图文

### 模板结构
```
【案例标题】年龄 + 不良孕史次数 + 结果亮点
【患者背景】年龄、既往病史（化名处理，保护隐私）
【就诊经过】
  - 来诊前困境
  - 中心诊断发现
  - 治疗方案（突出用药精简）
  - 关键节点（HCG翻倍/NT通过/环扎等）
【结果】分娩方式、孕周、宝宝体重性别
【核心启示】1-2句理念总结
【数据卡片】用药种类对比、孕周对比等
```
### 注意事项
- 所有案例化名处理，不出现真实姓名
- 用药信息保持准确但不构成处方建议
- 突出"科学保胎、精简用药"的差异化

## 7. 销售话术 / 客服话术

### 用途
前台接待、电话咨询、微信客服、社群答疑

### 模板结构
```
【场景】描述触发场景
【客户常见问题】列举2-3个典型问题
【标准回复】
  - 共情回应（先安抚情绪）
  - 专业解答（简洁清晰）
  - 信任建立（数据/案例/资质）
  - 行动引导（预约/到院/远程问诊）
【禁忌提醒】不可承诺的效果、不可使用的绝对化用语
```
### 话术分类
| 场景 | 典型问题 |
|------|---------|
| 初次咨询 | "保胎成功率多少？""费用大概多少？" |
| 远程问诊 | "外地怎么看病？""能线上开药吗？" |
| 用药疑虑 | "为什么药这么少？""别人开了一大堆" |
| 心理焦虑 | "又胎停了怎么办？""年纪大了还能保吗？" |
| 预约就诊 | "怎么预约？""需要带什么？" |
| 售后跟进 | "报告怎么看？""什么时候复诊？" |

## 9. 海报文案

### 用途
朋友圈海报、门诊海报、活动海报、节日海报

### 模板结构
```
【主标题】6-12字，核心信息
【副标题】补充说明，10-20字
【正文/要点】3条以内，每条8-15字
【数据亮点】1组关键数据
【行动引导】扫码/电话/到院
【底部信息】中心名称 + 地址 + 二维码位
```
### 海报类型
| 类型 | 设计方向 |
|------|---------|
| 品牌形象 | 深蓝渐变+白色卡片+专业感 |
| 案例报喜 | 温暖色调+婴儿元素+数据对比 |
| 科普知识 | 清爽配色+图标+要点列表 |
| 活动预告 | 醒目标题+时间地点+二维码 |
| 节日关怀 | 节日元素+祝福语+品牌植入 |

## 12. 新闻通稿 / 媒体稿件

### 用途
媒体发布、行业公关、学术活动宣传、品牌动态传播

### 模板结构
```
【标题】新闻性标题，含机构名 + 事件/观点
【导语】5W要素（何人何时何地何事何因）
【正文】
  - 事件详情/观点阐述
  - 数据支撑
  - 专家引言（刘国忠主任原话风格）
  - 背景补充
【结语】中心简介 + 联系方式
```
### 选题方向
- 学术论坛举办（如"海河之滨"生殖免疫论坛）
- 媒体受邀（如天津电视台《健康直播间》）
- 里程碑数据发布（年度门诊量/新生儿数）
- 社会公益（疫情期间线上诊疗、科普直播）
- 共识制定参与
