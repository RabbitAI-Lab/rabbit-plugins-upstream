# 品牌语调与写作规范

> 本文件定义刘国忠保胎中心所有运营内容的品牌语调、写作红线和风格指南。生成任何内容前必读。

---

## 一、品牌人格

### 核心人设
**科学保胎倡导者** —— 专业、温暖、有原则

### 三个关键词
1. **专业**：用数据和循证说话，不夸大、不忽悠
2. **温暖**：理解求子路上的艰辛，每一句话都带着温度
3. **有原则**：坚持"不盲目、不过度"，敢于说"不用那么多药"

### 品牌主张
"科学保胎，不盲目，不过度"——这是一切的出发点。

---

## 二、语调指南

### 整体语调
- **专业但不冰冷**：医学术语适度使用，关键处用通俗语言解释
- **温暖但不煽情**：共情患者的痛苦，但不消费患者的眼泪
- **自信但不傲慢**：用数据说话，但不说"我们是最好的"
- **有态度但不偏激**：明确反对过度用药，但不攻击同行

### 不同场景的语调微调

| 场景 | 语调倾向 | 示例 |
|------|---------|------|
| 科普内容 | 专业+清晰 | "反复胎停的6大原因，逐一排查是关键" |
| 案例分享 | 温暖+有力 | "41岁，8次不良孕史，仅用4种药，龙凤胎平安" |
| 朋友圈 | 亲切+简洁 | "又一个报喜！这次只用了2种药" |
| 销售话术 | 专业+信任 | "我们先看您的检查报告，再判断需要什么方案" |
| 危机回应 | 沉稳+安心 | "别担心，我们24小时在线，先看数据再说" |
| 学术稿件 | 严谨+规范 | "中心数据表明，精准干预可显著提升持续妊娠率" |

## 三、写作红线

### 绝对禁止
1. **禁止承诺100%成功**：不使用"包成功""一定能保住""保证没问题"等绝对化表述
2. **禁止攻击同行**：不点名批评其他医院/医生，用"有的地方""有些方案"泛指
3. **禁止处方建议**：科普内容不构成具体处方建议，不给出具体药物剂量
4. **禁止泄露隐私**：所有案例必须化名处理，不出现真实姓名、身份证号等
5. **禁止虚假数据**：所有数据必须来自 `company_profile.md`，不编造数字
6. **禁止诱导焦虑**：不用"不保胎就会流产""再不来看就晚了"等恐吓式表达

### 谨慎使用
1. **成功率表述**：使用"抱婴成功率持续90%以上"，不简化为"成功率90%"
2. **案例用药**：可以说"仅用4种药"，但不列举具体药名和剂量（避免被当作处方）
3. **年龄表述**：可以说"最高年龄59岁"，但不暗示"任何年龄都能成功"
4. **比较表述**：可以说"有的方案用药十几种"，不直接说"某医院开了十种药"

## 四、核心词汇表

### 品牌专属词汇（优先使用）
| 词汇 | 用法 |
|------|------|
| 科学保胎 | 核心理念，高频使用 |
| 不盲目，不过度 | 理念补全，成对出现 |
| 精准干预/精准治疗 | 描述诊疗方式 |
| 找对原因，针对性治疗 | 解释诊疗逻辑 |
| 抱婴成功率 | 而非"成功率" |
| 一站式服务 | 描述全流程服务 |
| 查、检、治、养 | 描述系统保胎模式 |
| 珍贵儿 | 试管/高龄妊娠的宝宝 |

### 替代表达
| 避免 | 改用 |
|------|------|
| 保胎成功率 | 抱婴成功率 |
| 包治好 | 科学诊疗，精准干预 |
| 流产/胎停 | 不良妊娠史（更温和） |
| 你的问题 | 您的情况 |
| 吃药 | 用药/治疗（更专业） |
| 大礼包（贬义） | 过度用药方案 |

### 医学表述规范
- 使用"复发性流产"而非"习惯性流产"（前者更规范）
- 使用"胚胎停育"或"胎停育"，不用"死胎"
- 使用"生化妊娠"，不用"生化流产"
- 使用"辅助生殖技术"，不用"试管婴儿"做正式表述（口语可简化）

## 五、Emoji使用规范

### 允许使用的Emoji
- baby/报喜类
- 孕育/孕期类
- 温暖/感恩类
- 亮点/希望类
- 确认/通过类
- 科普/知识类
- 医疗/就诊类
- 数据/报告类

### 使用原则
- 朋友圈：每条1-3个
- 小红书：标题1个，正文每段1个
- 公众号：极少使用，仅排版需要时
- 销售话术：不使用
- 新闻通稿：不使用

## 六、数据引用规范

### 引用格式
- 首次引用完整表述："2025全年门诊服务总量达2万人次"
- 后续引用可简化："年门诊2万人次"
- 对比引用突出差异："外院方案10余种药物 -> 中心方案仅4种"

### 数据来源
所有数据必须来自 `company_profile.md`，严禁编造。如需使用未在画像中的数据，需标注"数据待确认"。

## 七、案例使用规范

### 化名规则
- 使用"宝妈""X女士""X妈妈"等化名
- 不使用真实姓氏加女士（如"赵女士"仅当案例原文已有时保留）
- 年龄和病史可保留（非隐私信息）
- 具体就诊日期模糊化处理

### 案例选择逻辑
- 用药精简案例优先（突出差异化）
- 高龄/复杂病史案例优先（突出专业能力）
- 误诊纠正案例优先（突出诊断能力）
- 根据内容目的匹配案例（科普配案例、报喜配案例、销售配案例）

## 八、合规提示

### 医疗广告合规
1. 不使用"最""第一""唯一"等极限词（患者评价中的"保胎第一人"等可引用但需标注为患者评价）
2. 不暗示保证治疗效果
3. 不利用患者形象做广告（除非获得授权）
4. 药品名称不直接出现在广告内容中
5. 专家头衔需与实际一致，不夸大学术职务

### 平台差异合规
- 小红书：避免医疗广告敏感词，以"分享"为主
- 抖音：医疗内容需认证，避免未经审核的健康建议
- 微信公众号：避免诱导分享，合规发布科普
- 朋友圈：个人号内容更灵活，但仍需注意医疗合规
