## Description:

Convert Markdown files to standalone styled HTML with syntax highlighting, table of contents, and responsive design.

This skill is ready for commercial/non-commercial use.

## Publisher:

[terrycarter1985](https://clawhub.ai/user/terrycarter1985)

MIT-0

## Use Case:

Developers, technical writers, and documentation maintainers use this skill to convert local Markdown files into standalone HTML pages for web pages, blog posts, or documentation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated HTML can preserve unsafe or unreviewed content from untrusted Markdown input.

Mitigation: Use trusted Markdown or review the generated HTML before publishing.

Risk: The converter writes to the requested output path and may overwrite an existing destination file.

Mitigation: Choose the output path deliberately and keep backups of important files before conversion.
