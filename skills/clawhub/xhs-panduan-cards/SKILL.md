# 小红书「判断推理 · 每日5题」图文

把 5 道考公判断推理**真题**做成 10 张 1080×1440 竖版卡片（题 → 解析交替）+ 可直接发布的标题/正文/标签。

## 产出物

```
<项目目录>/
├── days/dayNN.json          # 题库，每期一份，永不覆盖（查重靠它）
├── dayNN/
│   ├── 01-第1题.png  02-第1题解析.png  …  10-第5题解析.png
│   └── 文案.md
├── preview.png              # 本期 10 张总览，只用于自检，不上传
├── README.md                # 出题台账（查重依据）
└── scripts/make_cards.py    # 项目内一份副本，方便单独改版式
```

## 工作流

### 1. 定位项目目录

找含 `days/day*.json` 的目录，习惯用 `xhs-panduan/`。没有就新建 `days/`、`scripts/`、`README.md`，把本技能 `scripts/make_cards.py` 复制进 `scripts/`，`assets/template.json` 复制成 `days/day01.json` 起头（模板只是格式样例，题目必须重写）。

版式基线看 `assets/style-reference.png`（本期 10 张的总览），出图后要和它一致：同一套纸色、朱红/墨绿、微软雅黑、页码与进度点。

### 2. 确认今天的 Day N

列出 `days/*.json`，**N = 最大天数 + 1**。不要覆盖已有题库，也不要问用户天数。

### 3. 选题与查重（本技能最容易翻车的一步）

先读 `references/playbook.md` 第一、二、三节。硬规则：

- 一期 5 题 = 定义判断 1 + 类比推理 1 + 逻辑判断 3（翻译 / 真假 / 加强削弱 / 分析推理里选三个不同子类）。
- 每题必须是**可核实的真题**：年份 + 考试 + 题号，来源页要能看到原卷页图或官方答案。查不到出处就换题，**不要自己编题干和答案**。
- 查重两层：同一题号永不复用（扫所有 `days/*.json` 的 `source`）；同一考点主类相邻两期不重复。
- **图形推理不要选**：题干本身是九宫格/折纸/立体图，PIL 画不出来，本技能只处理纯文字题。

### 4. 写 `days/dayNN.json`

```json
{
  "day": 2,
  "cover_hook": true,
  "hook": "这5道判断推理，第4题最容易绕晕",
  "items": [
    {"tag": "定义判断 · 2024国考",
     "source": "2024年国家公务员考试行测（地市级）第88题",
     "point": "附性法推理·全称/同义/同向",
     "q": "题干", "options": ["A项", "B项", "C项", "D项"], "answer": 0,
     "why": ["第一段", "第二段"], "tip": "记一句"}
  ]
}
```

| 字段 | 说明 |
|---|---|
| `day` | 期号，决定页眉 DAY NN 与输出目录 |
| `hook` | 首图红字钩子，≤20 字，制造悬念但别剧透答案 |
| `tag` | 题型 + 题源缩写，绿色胶囊，如 `真假推理 · 2023云南省考` |
| `source` | 完整出处，印在解析卡底部「真题出处」 |
| `point` | 考点标签，**只用于查重台账，不上图** |
| `q` / `options[4]` | 题干 / 四个选项（A–D 顺序） |
| `answer` | 正确项下标 0–3 |
| `why` | 解析，2 段，每段 ≤60 字 |
| `tip` | 「记一句」方法句，≤24 字 |

硬规则（按版面反推，超了图上会糊）：

- 单题内容要能塞进 1440 高。**题干 ≤200 字、每个选项 ≤30 字**是安全上限；再长脚本会把字号压到 30/27，手机上看就吃力了。
- 长材料可以压缩（删掉不影响选项的排比句），但**逻辑关系不能动**；四个选项尽量保留原题文字，OCR 错字可修。
- 解析两段：第一段说正确项为什么对（点出规则/翻译/矛盾对），第二段逐项排除。
- 5 题答案字母打散，不要出现三个连续相同。
- 卡片文字只用汉字 + 中文标点：PIL 没有 emoji 字形，`✓`、`🙋` 会渲染成方框。
- 不要在 `q/options/why/tip` 里写换行符，脚本统一按像素宽度折行；题干别以全角引号 `“` 或书名号 `《` 开头（字形左侧留白会让红色竖标看起来悬空）。

### 5. 出图

```powershell
$PY = "<带 Pillow 的 Python 解释器>"   # Windows 示例：C:\Users\<用户名>\AppData\Local\Programs\Python\Python312\python.exe
& $PY "<项目>/scripts/make_cards.py" "<项目>/days/dayNN.json"
```

脚本按 JSON 位置推断输出：`days/` 的上一层生成 `dayNN/` 和 `preview.png`。每题会打印实际用到的字号；**出现 `WARN` 必须回改 JSON 重出图**（题太长 / 记一句折行），不要手改 PNG——字号是整卡联动的。

### 6. 自检（必做）

用 read_image 看 `preview.png`，重点查：

- 文字有没有溢出卡片、D 选项有没有压到进度点；
- 折行有没有劈开词（真值表式的 `→`、`∶` 两侧尤其容易）；
- 解析卡「正确选项」是否在 3 行内、有没有把双字词拆开（断行只应出现在逗号/分号后）；
- 解析卡「记一句」有没有折行、真题出处有没有被挤掉；
- 10 张张数与页码顺序（01 题1 → 02 解析1 → … → 10 解析5）。

### 7. 写 `dayNN/文案.md`

**照抄 `references/playbook.md` 第六节的骨架**，只换内容：标题 3 选 1（第 1 个固定「判断推理DayN｜…」）+ 正文 ≤6 段 + 9 个标签 + 答案速查表 + 图片清单 + 发布建议。结构固定，不要自创章节。

### 8. 更新出题台账

往项目 `README.md` 的「出题台账」追加本期 5 行（题型 / 题源 / 答案 / 考点）。下一期查重就靠它。

### 9. 交付

用 present 交付 `文案.md` 和 `preview.png`；回复里给 5 题答案速查表，并用一句「错几道？评论区报个数」收尾。

## 版式规格

| 项 | 值 |
|---|---|
| 画布 | 1080×1440（3:4） |
| 纸色 / 墨色 | (250,246,239) / (32,36,46) |
| 主题色 | 题目朱红 (198,74,48)、解析墨绿 (14,110,101) |
| 字体 | 微软雅黑粗体（题干、正确答案、记一句）+ 常规（选项、解析） |
| 题干 / 选项字号 | 52→30 / 38→27 px 自适应，按内容高度挑最大可用组合 |
| 解析字号 | 34→27 px 自适应 |
| 解析卡正确选项 | 40px 起，超过 3 行自动降到 36/34/32（`fit_answer_option()`） |
| 选项卡片 | 白色圆角，高随行数伸缩，左侧 A–D 圆标 |
| 页眉 | 红色胶囊「判断推理 · 每日5题」+ 右侧 DAY NN / 页码 |
| 页脚 | 左「答案在下一张 →」（解析卡为「第 N 题解析」）/ 右「第 N 题 / 共 5 题」 |
| 解析卡结构 | 正确答案大字块 → 解析两段 → 绿框「记一句」→ 真题出处 → 互动提示 + 进度点 |

配色在脚本顶部 `PAPER / ACCENT / ACCENT_D`，字号阶梯在 `pick_question_layout()` / `pick_answer_layout()`，内容底线 `CONTENT_BOTTOM`。**改样式只改脚本，不要逐张手工修图。**

## 常见坑

- **图形推理做不了**：需要嵌图（九宫格、折纸、立体展开），本脚本只排纯文字。遇到就换题，或另做图形模板。
- 定义判断、类比推理天然偏文字，别为了「像逻辑」硬改题干。
- 脚本的 `units()` 负责「标点不出现在行首、数字与单位不拆、`→` 不孤立」，改脚本时别删。
- 素材页常附「原创迁移练习」，那是机构自编的，**不能当真题抄**。
- `preview.png` 只用于自检，不要混进待上传的 10 张。
- 首图就是「第 1 题」（hook 印在题干上方），不需要额外封面图；10 张正好 5 题 5 解析。
