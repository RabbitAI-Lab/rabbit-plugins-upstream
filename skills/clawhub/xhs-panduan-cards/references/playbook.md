# 出题与发布手册（判断推理）

## 一、题型结构与配比

行测判断推理四大类，国考固定 40 题，省考多在 35 题左右，结构近似：

| 大类 | 题量 | 细分 | 本系列 |
|---|---|---|---|
| 图形推理 | 10 | 九宫格、折纸、立体展开、截面 | **做不了**（要嵌图，PIL 排不了） |
| 定义判断 | 10 | 法学/经济学/心理学术语、效应类、原则类 | 每期 1 题 |
| 类比推理 | 10 | 成语古语、近反义、功能、组成、种属、语法关系 | 每期 1 题 |
| 逻辑判断 | 10 | 翻译推理、真假推理、加强削弱、分析推理、集合推理 | 每期 3 题，三个不同子类 |

一期 5 题的稳定配比：**定义 1 + 类比 1 + 逻辑 3**。

逻辑里 **加强削弱、翻译推理、真假推理** 提分最快、也最容易讲清楚，长期要占到 2 题以上；分析推理（排队/配对）题干长、上图像糊，少用；集合推理（所有/有的）适合偶尔穿插。

## 二、真题来源与核验

首选 **青云培训学校 qy.school 的「每日一练」逐题解析页**：一页一题，含完整题面 + 原卷页图 + 官方答案 + 逐项解析 + 常见误区，URL 形如
`https://www.qy.school/daily-practice/daily-practice-2023-85-<hash>`。

备选：粉笔/华图/中公题库页、省考真题 PDF、真题汇编书扫描页。

核验三步，缺一不可：

1. 页面上有**原卷页图或明确年份+题号**；
2. 页面给的答案与你**自己推一遍**的结果一致；
3. 四个选项能完整对上——对不上说明 OCR 缺字/串行，换来源。

其他红线：

- 不标未经证实的年份/考试名。查不到就只写「公务员行测真题 · 判断推理」。
- 素材页末尾常附「原创迁移练习」，那是机构自编的，**不能当真题抄**。
- 题干可压缩排比句，但**逻辑关系、条件、数量不能动**；选项尽量保留原题文字，OCR 错字（如「有购物」）可修顺。

## 三、查重（日更必做）

**题目级**：同一场考试同一年同一题号永不复用。
**考点级**：同一期 5 题考点不重复；相邻两期不得出现同一考点主类（如「真假推理-矛盾关系」连出两天）。

查已有题库：

```powershell
Get-ChildItem days\*.json | ForEach-Object {
  (Get-Content $_ -Raw -Encoding utf8 | ConvertFrom-Json).items |
    ForEach-Object { "{0,-16} {1}" -f $_.point, $_.source }
}
```

（必须带 `-Encoding utf8`，否则中文按 GBK 读成乱码、`ConvertFrom-Json` 直接报错。）

台账写在项目 `README.md` 的「出题台账」表：期号 / 题号 / 题型 / 题源 / 答案 / 考点。每期追加 5 行。

## 四、题目写作

**题干**：≤200 字最稳，超过就会压到 30px。

- 定义判断的 ①②③ 分条**必须保留**，那就是考点本身。
- 翻译推理的长材料可删排比句（如「要走进实践深处、观照人民生活」这类并列倡议），只留与选项直接相关的条件句。
- 别以全角引号 `“` 或书名号 `《` 开头：字形左侧留白会让朱红竖标看起来悬空，加个引导词即可。

**选项**：保留原题文字；四个选项长度尽量接近，干扰项要「像」，不能一眼假；选项内的「所以，」「如果……那么」照抄，别改写。

**答案**：自己推一遍再落笔；5 题字母打散（A/C/B/C/C 这种，不要连着三个相同）。

**解析**：两段，每段 **40–55 字**。

- 第一段：正确项为什么对。要点出关键结构——定义规则的哪一条、翻译成什么、哪两条互为矛盾。
- 第二段：逐项排除，紧凑句式「B 的“老”一指资历一指年龄；C 前提只是“有些”；D 把音乐天赋扩成全部天赋」。
- 发现图上把词劈开了，**改句子**（加减两个字把断点挪走），不要插换行符。

**记一句**：≤24 字，公式化、能背走，例如：

- 「只有P才Q：Q→P；否P则否Q」
- 「先找矛盾对，再让其余全假」
- 「全称、同义、同向，三条缺一不可」
- 「加强看落点，别被专业名词带跑」

## 五、标题公式

固定前缀，方便做系列、便于搜索：

```
判断推理Day{NN}｜{钩子}
```

钩子四选一（一次给 3 个备选，第 1 个最推荐）：

1. 押错率型：「第4题，一半人绕不出来」「这5题全对的不到三成」
2. 题型价值型：「定义判断，扣分全在这三个字」「逻辑判断就靠这一招」
3. 反常识型：「这题看着像语文题，其实是逻辑」
4. 场景型：「考场上这5道，8分钟够吗」

钩子不能剧透答案，也不要直接写题型名 + 答案。

## 七、标签池（每次取 9 个）

固定 6 个：`#判断推理 #行测 #考公 #国考 #省考 #事业单位考试`
轮换 3 个：`#考编 #每日一题 #备考日常 #刷题 #逻辑判断 #学习打卡`

第一个标签权重最高，固定放 `#判断推理`，方便做话题聚合。

## 八、发布建议

- 时段：7:30–8:30、12:00–13:00、20:00–22:00（这三个时段发「晨读刷题」「午休刷题」「睡前刷题」最稳）。
- 10 张按 01–10 顺序上传，保持「题 → 解析」的节奏，不要打乱。
- 评论区自己置顶答案表 + 一句「明天想先练哪一类？定义还是逻辑？」收集下期选题。
- `preview.png` 只给自己看，不要上传。

## 九、考点储备（选题时翻这一节）

- **定义判断**：法学（附性法、正当防卫、无因管理）、效应类（涟漪效应、破窗效应、鸟笼效应）、经济学（边际效用、机会成本、进入壁垒）、心理学（从众、习得性无助）。
- **类比推理**：成语/古语（手段→目的、并列、近义）、功能关系、组成关系、种属关系、三词层级（并列下位类 + 上位类）、词性语法、命名方式。
- **翻译推理**：只有…才、如果…那么、除非…否则、且/或、必要充分条件的逆否。
- **真假推理**：矛盾关系（A 与 A 且非 B）、反对关系、假设法、唯一真/唯一假。
- **分析推理**：一一对应（人员-任务/位置）、确定信息优先、逆否链、剩余项排除。
- **前提假设**：论据与结论之间搭桥（缺环补齐）、排除他因、必要条件取反检验。
- **加强削弱**：直接结果支持、机制解释、样本代表性、另有他因/替代原因、力度比较（落实事实 > 可能风险）。

同一考点族可以隔几期换个变体再出（如「只有…才」这次考创作源泉、下次考政策条件），但不能同题号、不能相邻两期撞主类。
