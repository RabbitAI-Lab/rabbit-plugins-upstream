## Description:

Creates original cartoon character model sheets and restyles supplied characters or photos using written descriptions of animation looks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

External creators use the skill to describe original cartoon characters or restyle consented reference images into animation-inspired looks and request model-sheet images from varg.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Personal images may be processed by an external service, and the data handling disclosure is unclear.

Mitigation: Avoid sending personal or sensitive images until the service's data handling is clear; use reference images only with consent.

Risk: The installation instructions use an unpinned installer.

Mitigation: Review the installer and confirm a trusted version before running it.

Risk: Some guidance may work around image model refusals.

Mitigation: Keep image requests within the model's safeguards and do not use the skill to evade refusals.
