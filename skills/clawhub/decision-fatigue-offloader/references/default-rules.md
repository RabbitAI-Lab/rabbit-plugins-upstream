# 默认规则
## 默认城市
北京。用户未提供城市时使用。若用户消息中出现“上海/杭州/成都/长沙”等城市名，优先采用。
## 城市消费乘数表（基准 = 新一线城市，乘数 1.0）
乘数依据2026年各城市快餐午餐价格、外卖客单价和人均消费支出梯度估算。**只乘价格阈值，不乘偏好。**
| 城市/等级 | 餐饮乘数 | 购物乘数 | 休闲乘数 |
|---|---|---|---|
| 上海、北京 | 1.5 | 1.3 | 1.2 |
| 深圳、广州 | 1.3 | 1.2 | 1.1 |
| 杭州、南京、苏州 | 1.1 | 1.1 | 1.0 |
| 成都、武汉、天津、西安、重庆 | 1.0（基准） | 1.0 | 1.0 |
| 长沙、郑州、济南、福州、佛山、无锡 | 0.75 | 0.8 | 0.85 |
| 三四线及以下（未列城市） | 0.65 | 0.7 | 0.8 |
参考锚点：上海普通午餐快餐约38–42元，北京约30–40元，成都约15–25元，长沙约14元，郑州约10–15元。外卖客单价上海/北京44–47元，深圳/杭州/南京/广州32–45元。
## 餐饮
**午餐基准预算 40 元，晚餐基准 60 元**。实际预算 = 基准 × 餐饮乘数，四舍五入到10元。忌口默认“无”；优先距离≤1km或外卖30分钟内可达；工作日不选需排队超过10分钟的店。
## 着装
**不受城市乘数影响。** 按体感温度分档：≤5°C厚外套+保暖内层；6–15°C外套+长袖；16–25°C单层长袖或薄外套；≥26°C短袖/透气材质。有雨默认带伞，有风默认避开裙装/阔腿裤。
## 购物
**日用品基准单价阈值 100 元**，实际阈值 = 100 × 购物乘数。低于阈值直接选“销量最高且评分≥4.5”的第一个；高于阈值才允许比较两个候选。礼物基准预算 100–300 元，乘以购物乘数，优先“可退换”。
## 休闲
**不受城市乘数影响体力分档，但影响花费预期。** 精力值≤2默认“低体力、可随时退出”；3–4可选“半结构化”；5才推荐“需要出门社交”。如果推荐活动涉及付费，按休闲乘数调整可接受价格描述（如“人均不超过100元”在一线变为“人均不超过120元”）。
## 通用
用户说“随便”=授权直接用默认规则和已识别城市拍板，不追问。同一类型当天已拍板过，直接复用上次主决策（除非用户说“换”）。
