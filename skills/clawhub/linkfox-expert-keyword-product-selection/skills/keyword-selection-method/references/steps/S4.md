# S4: 汇总输出

## 输入
- S1候选关键词列表
- S2a 代表ASIN数据（ASIN+标题+价格+图片）
- S2b 卖家精灵需供比+CPC+垄断率+购买量+购买率数据
- S2c 漏斗过滤结果+竞争度
- S3 代表商品详情（Keepa）
- 可配置参数：sortBy, scoreWeights, includeWatchlist, riskAppetite, topN

## 操作（内部逻辑，无需调用外部工具）
1. 合并所有步骤数据，按关键词聚合
2. **排序**（根据 sortBy 参数）：
   - `sdr`：按需供比降序（默认）
   - `score`：按综合评分降序，评分公式见 SKILL.md
   - `custom`：多键排序（需供比 DESC → 购买量 DESC → 垄断率 ASC）
3. **输出范围**（根据 riskAppetite 参数）：
   - `conservative`：仅输出"可进"词
   - `balanced`：输出"可进"+"观望"（默认）
   - `aggressive`：观望也当候选，纳入排序
4. 取前 topN 个关键词（从保留池中取）
5. 为每个关键词构建输出字段：
   - rank: 排名序号
   - platform: "Amazon <marketplace>"
   - keyword: 关键词
   - demandSignal: 需求信号等级
   - supplyDemandRatio: 需供比
   - searches: 月搜索量
   - products: 商品数
   - cpc: PPC竞价
   - monopolyClickRate: 垄断率
   - purchases: 月购买量
   - purchaseRate: 购买率
   - competition: 竞争度等级
   - priceBand: 价格带
   - funnelConclusion: 漏斗结论
   - suggestedAction: 建议动作
   - sortBasis: 排序依据（"需供比=X" 或 "综合评分=X"）
   - score: 综合评分（仅sortBy=score时有值，0-10分）
   - filterTrace: 过滤标注（如"价格$26.99 ✓ | 搜索量45,906 ✓ | 垄断率39.99% ✓ | 综合分8.4"）
   - representativeProduct: {asin, title, price, image, brand} 或 null（淘汰词无代表商品）
6. 淘汰的关键词保留在附录中，representativeProduct=null，funnelConclusion标注淘汰原因
7. 缺字段统一标注"未返回"

## 输出
- JSON 文件：完整候选清单，含保留+淘汰关键词
- stdout：摘要表格（排名/关键词/需供比/CPC/垄断率/购买率/竞争度/漏斗结论/代表ASIN）
- stdout 末尾输出：`Saved full response: <绝对路径> (<字节数> bytes)`

## 用途
最终交付物，供前端关键词列表组件渲染。

## 落盘注记
- 落盘：JSON 保存到会话目录 data/ 子目录
- 读取：无（本步是最终输出，不读取上游文件，由 agent 在内存中合并）
- 判定：输出 JSON 含 keywords 数组，每条字段数 ≥ 15
