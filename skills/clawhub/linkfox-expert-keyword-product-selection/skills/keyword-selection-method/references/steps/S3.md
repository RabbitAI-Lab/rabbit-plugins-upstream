# S3: 补代表商品

## 输入
- S2d保留的关键词列表
- 每个关键词对应的Top1 ASIN（来自S2b）
- marketplace

## 操作
1. 对每个保留关键词的Top1 ASIN调用 `linkfox-keepa-product-request`，参数：asin, domain=1（US站）
2. 从返回数据中提取：title（标题）、price（价格）、images（主图URL）、rating（评分）、reviewCount（评论数）、brand（品牌）
3. **关键**：Keepa价格可能为null，标注"未返回"；图片可能为null，标注"未返回"
4. 价格带分级：<$15=低价, $15-30=中低, $30-50=中高, >$50=高价, 未返回=未返回
5. 读取保存的JSON文件而非解析stdout

## 输出
- 每个保留关键词的代表商品信息：ASIN, title, price, image, rating, reviews, brand, priceBand

## 用途
为S4汇总输出提供"代表商品"字段（主图+ASIN+标题+价格）。

## 落盘注记
- 落盘：Keepa脚本自动保存JSON到会话目录
- 读取：从保存的JSON文件读取 products[0]；价格在 csv.price 数组最后一项（单位：美分，需/100）
- 判定：响应含products数组（1条），字段数≥65，需投影 title/price/images/rating/reviewCount/brand
