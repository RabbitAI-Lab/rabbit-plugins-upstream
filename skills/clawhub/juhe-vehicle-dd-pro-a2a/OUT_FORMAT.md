# 车辆尽调报告 Pro（标准版）输出格式

支付成功并拿到套餐 JSON 后渲染。**仅使用接口返回内容，禁止编造。**  
**面向用户的报告正文禁止出现：** 底层接口编号、`resourceId`、英文字段名、「同接口××字段」等技术话术。对用户只用中文栏目名。

数据根路径：`data`（外层 `error_code`、`reason` 不展示给用户）。

| 模块         | JSON 路径           | 类型                       |
| ------------ | ------------------- | -------------------------- |
| 车辆配置档案 | `data.vinInfo`      | object                     |
| 登记五项     | `data.vinFive`      | object                     |
| 过户流转     | `data.vehicleOwner` | object（内含 `data` 数组） |
| 车检估算     | `data.chejian`      | object（`date` + `msg`）   |

---

## 车牌脱敏规则（强制）

凡展示车牌（来自 `vinFive.plate`），**禁止明文完整车牌**。

| 原始长度（去空格后） | 规则 | 示例 |
| -------------------- | ---- | ---- |
| ≥ 7 | 保留前 2 位 + 后 2 位，中间全部用 `*` | `浙J9PY96` → `浙J***96`；`京AD12345` → `京A****45` |
| 5～6 | 保留前 2 位 + 后 1 位，中间用 `*` | `京A123` → `京A**3` |
| ＜ 5 或空 | 显示 `—`（不展示残缺明文） | |

- 新能源 8 位牌同样：前 2 + 后 2，中间 `*`
- 追问、摘要、专章、表格**全部**使用脱敏后的值
- 日志中禁止写入完整车牌

轮胎规格等字段若含转义 `\/`，展示为 `/`（如 `215/60 R16`）。

---

## 输出顺序（固定）

```markdown
{报告头 + 一页摘要}     ← vinInfo 含有效车型信息时必渲染

{车辆配置档案}         ← vinInfo

{登记信息}             ← vinFive；车牌脱敏；无数据写「未见登记信息」

{过户专章}             ← vehicleOwner；data 空也要「未见过户记录」

{车检估算}             ← chejian；有 date/msg 则渲染

---
*免责页脚*
```

`vinInfo` 缺失、为空，或仅有 `orderid` 而无品牌/销售车型等关键字段（查无）时：只输出 [查无记录模板](#查无记录模板) + 页脚，**不**渲染空登记/空过户装点。

过户年月字段兼容 `changeMonth` 与 `changeMoth`（缺 e），展示统一为「YYYY 年 MM 月」。

## 报告头 + 一页摘要

```markdown
# 车辆尽调报告 Pro（标准版）

> 🔑 查询 VIN：{用户查询的 VIN}  
> 🕒 报告时间：{当前日期时间}  
> 📦 版本：标准版（配置档案 + 登记五项 + 过户流转）

## 一页摘要

| 项目 | 内容 |
| ---- | ---- |
| 销售车型 | {vinInfo.amVehicleName} |
| 品牌 / 车系 | {amMainBrandName} / {amSeriesName} |
| 年款 | {amYear} |
| 初次登记 | {vinFive.recordDate；无则「—」} |
| 过户灯 | 🔴红 / 🟡黄 / 🟢绿（仅信号灯，非买卖建议） |
| 总过户次数 | {见下；无记录写「共 0 次」} |
| 车牌（脱敏） | {按脱敏规则；无则「—」} |

**关键发现：**

1. {3～5 条事实：车型一句话、登记年、过户次数与是否跨城；全无过户则写「公开数据未见过户记录」}
```

### 总过户次数取值

- 遍历 `vehicleOwner.data[]`，取各条 `transTimeSum` 的**最大值**（数值比较）
- 数组为空或不存在：按 **0** 计

### 过户灯判定（必须遵守）

| 灯 | 条件（满足任一即取最高严重级别） |
| -- | -------------------------------- |
| 🔴 红 | 总过户次数 ≥ 5；或存在单条记录：`transMonth`＜6（可解析为数字）且 `cityBefore`、`cityAfter` 均非空且不相同 |
| 🟡 黄 | 未触红，且总过户次数为 2～4 |
| 🟢 绿 | 总过户次数为 0 或 1，且未触红 |

禁止出现：「建议购买」「不建议购买」「车况良好」「可以放心入手」等句。  
`price` / `purchasePrice` 仅可表述为「厂商指导价 / 新车市场价（参考）」，禁止写成「估值」「行情价」。

## 过户专章

```markdown
## 过户流转

| 项目 | 内容 |
| ---- | ---- |
| 总过户次数 | {最大值 transTimeSum；无则 0} |
| 记录条数 | {vehicleOwner.data 长度} 条 |

### 过户明细
```

有记录时，按过户年月**降序**（最新在前）输出汇总表：

```markdown
| 过户年月 | 过户前城市 | 过户后城市 | 距上次过户 | 累计次数 |
| -------- | ---------- | ---------- | ---------- | -------- |
| 2016 年 08 月 | — | 荆州市 | 6 年 / 74 个月 | 1 |
```

- `cityBefore` / `cityAfter` 空值显示 `—`
- 距上次过户：`{transYear} 年 / {transMonth} 个月`（缺一则只写有的）

`vehicleOwner.data` 为空或不存在：

```markdown
## 过户流转

公开数据未见过户记录。
```

## 查无记录模板

当配置档案查无（`vinInfo` 无效）时使用：

```markdown
# 车辆尽调报告 Pro（标准版）

> 🔑 查询 VIN：{用户查询的 VIN}

未查询到该车架号对应的车辆配置档案，无法生成尽调报告。请核对 VIN 是否正确后重试。

---
*以上结果仅供参考，请以实际车辆登记及厂商官方信息为准。*
```

## 车检估算专章（`data.chejian`）

对用户展示中文，**禁止**写出 `type` / `hasSg` / `chejian` 等字段名，**禁止**提及任何接口编号或 resourceId。

有 `chejian.date` 或 `chejian.msg` 时渲染：

```markdown
## 车检估算（仅供参考）

| 项目 | 内容 |
| ---- | ---- |
| 注册登记日 | {vinFive.recordDate；无则「—」} |
| 车辆类型 | {用户确认的 type 对应中文} |
| 事故/非法改装处罚 | {hasSg=1 → 是；hasSg=0 → 否} |
| 检验有效期止 | {chejian.date} |

{chejian.msg}

> 计算结果仅供参考，请以「交管12123」及车管所为准。
```

### 字段映射

| 展示项 | JSON 字段 | 说明 |
| ------ | --------- | ---- |
| 检验有效期止 | `data.chejian.date` | 如 `2026年11月30日` |
| 说明文案 | `data.chejian.msg` | 检验周期提示全文 |

`chejian` 缺失、为空对象、或为空数组 `[]` 时跳过本专章。
