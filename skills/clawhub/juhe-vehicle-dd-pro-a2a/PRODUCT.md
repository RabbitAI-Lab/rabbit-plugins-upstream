# 产品锁定：车辆尽调报告 Pro · 标准版

> 状态：标准版已定稿；收单 `resourceId` 见 `SKILL.md` 请求模板；返回结构与字段见 `README.md`；渲染见 `OUT_FORMAT.md`。

## 定位

一次付费，输出「购前车辆公开信息快检报告」。
输入：车辆 **VIN 码（车架号，17 位）** + **车辆类型** + **是否事故/非法改装处罚（hasSg）**。
前置：须经「VIN 前置校验」与车型/`hasSg` 收齐（见 `SKILL.md` 4.1 第二步），未通过不发起付费。
不做：车辆估值、事故全量、盗抢/抵押查询、真实违章清单、保险报价、「建议买/不建议买」类结论。

## 标准版一次返回字段

| 返回字段 | 模块 | 说明 |
| -------- | ---- | ---- |
| `data.vinInfo` | 车辆配置档案 | **必有**；缺失或查无则整单视为无车型档案 |
| `data.vinFive` | 登记五项 | 登记日、发动机号、登记口径品牌型号；车牌须脱敏展示 |
| `data.vehicleOwner` | 过户流转 | `data[]` 过户明细；空数组也要展示「未见过户记录」 |
| `data.chejian` | 车检估算 | `date` 检验有效期止 + `msg` 说明；依请求中的车型与 `hasSg` 计算，仅供参考 |

**版式冻结**：严格按 `OUT_FORMAT.md` 渲染；禁止每次查询换版式。
面向用户禁止英文字段名、底层接口编号与 `resourceId` 话术。

## 请求附加参数：车型与 hasSg

本套餐请求须携带 **`type`（车型）** 与 **`hasSg`**；登记日由服务端优先使用 `vinFive.recordDate`。

| 请求字段 | 对用户称呼 | 必填 | 取值 | 说明 |
| -------- | ---------- | ---- | ---- | ---- |
| `type` | 车型 / 车辆类型 | **是** | 见枚举 | **禁止猜测/默认静默提交** |
| `hasSg` | 事故与改装情况 | **是** | `1` 或 `0` | 是否发生过致人伤亡事故或存在非法改装被依法处罚的交通违法：**是=1，否=0**；禁止缺省 |

`type` 枚举：

| 值 | 含义（对用户话术可简化） |
| -- | ---- |
| 3 | 9 座（含）以下非营运小微型载客汽车（面包车除外）← 家用轿车/SUV 常用 |
| 7 | 非营运大型轿车 |
| 6 | 面包车 |
| 1 | 营运车辆 |
| 2 | 货车、大中型客车 |
| 4 | 摩托车 |
| 5 | 其他机动车 |

未同时拿到可映射的车型中文与事故中文（再转为合法 `type` 与 `hasSg`）前，**禁止**发起套餐请求。
**对用户引导须用中文选项**（如「家用车」「没有」），禁止让用户回纯数字，避免「1」既像营运又像「有事故」的冲突。友好话术与映射表见 `SKILL.md`。

## 交付结构

1. 一页摘要（过户灯 + 车名 + 登记年）
2. 车辆配置档案
3. 登记信息（车牌脱敏）
4. 过户专章
5. 车检估算专章（`chejian`）
6. 免责声明

空过户必须展示「未见过户记录」（排除风险也是付费价值）。

## 过户灯规则（红黄绿）

以 `vehicleOwner.data` 明细中的总过户次数（取各条 `transTimeSum` 的最大值；无记录视为 0）为主：

| 灯 | 条件 |
| -- | ---- |
| 红 | 总过户次数 ≥ 5；或存在单次距上次过户不足 6 个月且伴随跨城（`cityBefore` 与 `cityAfter` 均非空且不同） |
| 黄 | 未触红，且总过户次数为 2～4 |
| 绿 | 总过户次数为 0 或 1，且未触红 |

禁止输出确定性买卖/贷款建议句。价格字段仅作「厂商指导价/新车市场价参考」，禁止写成估值。
