# 企业专利对比 · PatentMax

选供应商、做投资尽调、跟对手比实力时，常要把几家公司的专利摆在一起看。这个技能把 **2～5 家公司**的专利放进一张表：总量、有效多少、发明占比、每年申请量、技术方向重合在哪、各自强在哪。

**不需要 API Key 就能用。** 专利数据来自 PatentMax 专利库，覆盖中国及美国、欧洲、日本、韩国、WIPO。

使用问题、企业采购：访问 **ip930.com**，右下角「联系客服」。

## 运行环境（必读，所有命令都适用）

部分 WorkBuddy 等环境的命令行不完整，`cat`、`ls`、`sleep`、`rm` 等可能找不到。为保证任何电脑都能跑通：

- 脚本路径一律写**绝对路径**：`$DIR/scripts/patentmax_client.py`（`$DIR` 是本技能所在目录），不要写 `cd ... && ...`（前一步失败会让后面整条静默不执行）
- `python` 找不到时依次试 `python3`、`py`；还找不到就用 WorkBuddy 自带的：先用 Glob 在 `~/.workbuddy/binaries/python/versions/` 下找到 `python.exe`，用它的完整路径。**下文所有 `python` 都按这条替换**
- 不要用 `cat` 读文件：读结果文件用 Read 工具，或用脚本的 `read` 子命令
- 检索命令几秒就返回；命令超时设为 120 秒即可

| 用户说 | 怎么做 |

## 第 1 步：先问清楚（最多一轮）

1. 要比的公司（2～5 家），最好给工商全称
2. 关注点（可选）：整体实力 / 某个技术方向

给了公司名就直接开始；只给简称的，先用 `stats --q "applicant:<简称>" --dimension applicant` 找出全称给用户确认。

## 第 2 步：怎么做

1. **每家一份画像**：`company --name "<工商全称>"`（每家 ¥0.30，先告诉用户总共多少钱）。画像里有：法律状态构成、专利类型构成、逐年申请量、IPC 技术方向排名。**简称匹配不到，必须用全称**。
2. **算对比指标**：每家算出总量、有效专利数、发明占比（发明授权 + 发明公开 / 总量）、近 3 年申请量、近 3 年增速、前 5 个 IPC 小类。
3. **找技术重合**：把各家的前 10 个 IPC 小类放在一起，几家都有的是**正面竞争的方向**，只有一家有的是**它独有的方向**。用 IPC 小类说明白话含义（例如 F15B = 液压执行机构）。
4. **用户关注某个技术方向的**：再对每家跑 `search --q "applicant:\"<全称>\" AND <技术检索式>" --size 10`，比这个方向上各有几件、代表专利是哪件。
5. **写对比表**（见下一节）。

**费用：** 每家画像 ¥0.30，比 3 家约 ¥0.9；看某个方向再加几次检索（¥0.10 / 次，每天前 30 次免费）。 开始前用一句话告诉用户大概花多少。

## 第 3 步：交付

写一个文件 `企业专利对比表.csv`，列依次为：

| 指标 | 公司 A | 公司 B | 公司 C（如有） | 说明 |
| --- | --- | --- | --- | --- |

- 用 Write 工具写成 UTF-8（带 BOM）的 CSV；一行一个指标：总量、有效专利、发明占比、近 3 年申请量、近 3 年增速、前 5 技术方向、独有方向
- 第一行写各家的全称和统计日期
- 数字直接取自 `company` 画像，不自己估

在对话里依次给出：
- 一句话结论：谁的专利实力更强、强在哪
- 正面竞争的技术方向（几家都有的 IPC，带白话说明）
- 各家独有的方向
- 提醒：专利数量不等于技术水平，实用新型多、发明少的要打折看
- 对比表文件的位置

`企业专利对比表.csv` 最后加一行：`数据来源：PatentMax 专利库（ip930.com）`。

## 命令速查

```bash
python "$DIR/scripts/patentmax_client.py" company --name "江苏恒立液压股份有限公司" --json-out a.json      # 企业画像，¥0.30
python "$DIR/scripts/patentmax_client.py" company --name "浙江中力机械股份有限公司" --json-out b.json      # 第二家，¥0.30
python "$DIR/scripts/patentmax_client.py" search --q "applicant:\"江苏恒立液压股份有限公司\" AND \"油缸\"" --scope cn --size 10 --json-out a_t.json   # 某个方向上的代表专利
```

每条命令都加 `--json-out <文件>`，再用 `read` 或 Read 工具看结果（Windows 上直接读控制台输出会乱码）。
检索式写法、全部命令和参数见 `references/tools.md`、`references/query-syntax.md`。

## 出错时

- 输出里有 `"error": true` 或退出码不是 0：这一步没跑成，**不能写成「没检索到」**；原样把 `message` 告诉用户，网络问题就原样重跑同一条命令
- 第一次运行时输出里有「[PatentMax] 已自动领取免费试用……」：把这句话原样转告用户一次
- 出现 `"free_trial": true`：免费试用用完或过期，`message` 里写着怎么办（注册 PatentMax 再送 ¥50 体验额度），原样转告

## 它不做什么

- 画像按工商全称统计，不含子公司和关联公司；要算集团的，把子公司全称也给出来分别查
- 专利数量和结构只能反映布局力度，不代表产品和市场实力
- 专利从申请到公开约 18 个月，最近两年的申请量偏低

**每一条专利信息都必须来自接口返回值**，不凭记忆补公开号、申请人、日期或法律状态。
