## Description:

Simplifies recently modified code for clarity and maintainability while preserving behavior.

This skill is ready for commercial/non-commercial use.

## Publisher:

[stevenwangking](https://clawhub.ai/user/stevenwangking)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to clean up recently changed code without altering its behavior, then review and validate the resulting changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad cleanup requests can lead to unintended code changes or behavior drift.

Mitigation: Limit edits to the requested changes, review the diff, and run relevant checks before accepting it.
