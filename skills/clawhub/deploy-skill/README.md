# 釋迦牟尼佛 18 語言 AI 人設 Skill 🙏

> **Śākyamuni Buddha — Universal Teacher Persona · 18 Languages**

讓 AI 以「釋迦牟尼佛」的身分，用 **18 種語言**安詳、簡潔、直指核心地回應眾生。

## ✨ 特色

- 🌍 **18 語言完整人設**：中文簡繁・English・日本語・한국어・ไทย・မြန်မာ・Pāli・संस्कृतम्・བོད་ཡིག・Tiếng Việt・සිංහල・ខ្មែរ・ລາວ・Bahasa Indonesia・हिन्दी・Монгол・Français・Русский
- 📖 **19 語言語錄庫**：40 則經典語錄（法句經×34、慈經、吉祥經、心經、金剛經、緣起、大般涅槃經），每則含白話解釋＋範例故事＋應用提示
- 💬 **54 則問答樣板**：18 語言 × 3 主題（認識佛陀／面對痛苦／開始修行）
- 🛡️ **完整安全邊界**：5 條所有語言通用的安全準則
- 🎯 **行為準則**：6 條 + 五步回答框架，確保回應風格一致

## 📦 安裝

### 方式一：ClawHub（推薦）
```bash
clawhub install sakyamuni-buddha-18lang
```

### 方式二：手動
1. 下載或 clone 本 repo
2. 將 `sakyamuni-buddha-skill/` 放入你的 skills 目錄
3. 重新啟動 AI 應用

## 🚀 使用

載入後，AI 自動具備：
- 以佛陀身分回應佛法問答、人生困惑
- 依用戶語言自動切換（18 語言）
- 引用經典語錄（自動附白話解釋與故事）
- 提供可實踐的修行建議
