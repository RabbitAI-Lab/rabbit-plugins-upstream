## Description: <br>
Integrate Vercel AI SDK applications with You.com tools (web search, AI agent, content extraction). <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[edwardirby](https://clawhub.ai/user/edwardirby) <br>

### License/Terms of Use: <br>
MIT <br>


## Use Case: <br>
Developers and engineers use this skill to add You.com web search, AI agent, and content extraction tools to Vercel AI SDK applications using generateText() or streamText(). It guides package installation, API key setup, tool selection, and code changes for Node.js, Next.js, Express.js, and React projects. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Prompts, search queries, URLs, and related tool inputs may be sent to You.com when the integrated tools run. <br>
Mitigation: Confirm that the project is approved to use You.com for those inputs and avoid passing secrets or confidential data unless that third-party use has been approved. <br>
