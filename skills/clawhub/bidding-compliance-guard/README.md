# 招投标合规护栏（bidding-compliance-guard）

在**投标文书、招标公告、资格预审文件、中标公示、商务应答、企业宣传**发布 / 提交前，
实时拦截《招标投标法》《招标投标法实施条例》《反不正当竞争法》等法规下的
**高频违法违规表述**。纯本地运行，零网络请求、零动态执行、零依赖。

## 检测覆盖（6 类 · 36 条）

| 类别 | 风险 | 代表表述 |
|---|---|---|
| 串通投标与围标 | high | 围标、陪标、内定中标、保证中标 |
| 虚假资质与业绩 | high | 虚构业绩、伪造资质、挂靠投标 |
| 诋毁竞争对手 | low/medium | 贬低竞争对手、诋毁同行、唯一可靠 |
| 报价操纵 | high | 低于成本报价、哄抬标价、报价联盟 |
| 商业贿赂 | high | 给予回扣、好处费、打点评标专家 |
| 排斥性条款 | high | 限定特定品牌、指定品牌、排斥潜在投标人 |

## 快速使用

```bash
python scripts/guard.py --text "我方承诺保证中标，并可安排陪标单位" --format json
python scripts/guard.py --file bid_doc.txt
python scripts/guard.py --list-categories
```

- 命中：输出类别 / 风险 / 原文片段 / 整改建议 / 法规依据。
- 未命中：`decision=clean`。

## 依据（全文公开）

《招标投标法》（2017 修正）、《招标投标法实施条例》（2019 修订）、
《反不正当竞争法》（2019 修正）、《招标公告和公示信息发布管理办法》（发改委令第 10 号）。
