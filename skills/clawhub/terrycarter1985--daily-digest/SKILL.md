# Daily Digest

Fetch multiple URLs, extract readable content, and produce a consolidated markdown digest.

## When to Use

- Morning briefings from multiple feeds
- Weekly knowledge summaries
- Competing articles on one topic into one view

## Prerequisites

- OpenClaw runtime with `web_fetch` tool available
- No external API keys required

## Steps

1. **Collect URLs** — Gather 3-10 URLs the user wants digested. Put them in a numbered list.
2. **Fetch each URL** — Call `web_fetch` for each URL with `extractMode: "markdown"` and `maxChars: 8000`.
3. **Extract key points** — For each fetched page, identify:
   - Title and source domain
   - 3-5 key takeaways (bullet points)
   - One notable quote or statistic if available
4. **Compose digest** — Structure output as:
   ```
   # 📰 Daily Digest — YYYY-MM-DD

   ## Overview
   2-3 sentence executive summary across all sources.

   ## Source 1: <Title>
   *<domain>*
   - Key takeaway 1
   - Key takeaway 2
   - Key takeaway 3
   > Notable: ...

   ## Source 2: <Title>
   ...

   ---
   Generated by daily-digest skill
   ```
5. **Deliver** — Output the digest. If the user specified a channel (email, Slack, etc.), deliver there.

## Tips

- If a URL fails to fetch, skip it gracefully and note it in the digest footer.
- Prefer `maxChars: 8000` per source — enough for most articles without overload.
- Order sources by relevance or recency based on the user's request.
- If two sources cover the same story, merge them into one section with both domains listed.

## Example

```
# 📰 Daily Digest — 2026-08-25

## Overview
AI regulation advances in the EU while open-source tooling continues to mature. Cloud costs show signs of stabilization.

## Source 1: EU AI Act Enters Enforcement Phase
*euractiv.com*
- First compliance deadlines hit in Q2 2026
- High-risk AI systems face stricter auditing requirements
- SMEs get extended transition periods
> Notable: "82% of enterprises say they are partially compliant"

## Source 2: The State of Open Source LLMs in 2026
*thenewstack.io*
- Local models now rival mid-tier cloud API performance
- Tool-using agents drive new adoption patterns
- Hardware efficiency gains outpace scaling laws
```

## Known Limitations

- Cannot authenticate behind paywalled URLs
- Very large pages (>50K chars) may be truncated
- Paywalled or JS-heavy sites may return minimal content
