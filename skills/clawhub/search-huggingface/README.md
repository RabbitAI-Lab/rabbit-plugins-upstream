# search-huggingface

A lightweight Brave browser skill for **Hugging Face**.

## What it does

Search Hugging Face models matching the user's query.

- Reuses an existing relevant tab/session
- Avoids unnecessary duplicate tabs
- Verifies the destination
- Never handles credentials

## Example triggers

- Search Hugging Face for vision models
- Find LLMs for code
