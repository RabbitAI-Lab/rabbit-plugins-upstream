## Description: <br>
Helps agent users, skill authors, maintainers, and teams plan, fix, harden, and validate Agent Browser-style workflows with practical local-friendly guidance, checklists, and artifacts. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, agent users, skill authors, maintainers, and teams use this skill to turn Agent Browser-style automation needs into practical plans, checklists, implementation support, or workflow guidance for bug fixes, setup hardening, reliability improvements, and adjacent skill creation. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad browser, automation, and bug-fix triggers may activate the skill for requests where it is not the intended helper. <br>
Mitigation: Confirm that the user is asking for Agent Browser-style workflow planning, hardening, reliability, or adjacent skill support before applying the workflow. <br>
Risk: Guidance-only outputs can still introduce incorrect or misleading workflow, code, or configuration recommendations. <br>
Mitigation: Review proposed changes, scan generated artifacts, and validate results against the stated success criteria before deployment. <br>
