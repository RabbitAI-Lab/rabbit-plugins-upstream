# Public method sources

- [Atlassian Project Poster](https://www.atlassian.com/team-playbook/plays/project-poster): Align questions, assumptions, scope, target results, and use documentation as a continuously updated collaboration tool.
- [Atlassian Goals, Signals, Measures](https://www.atlassian.com/team-playbook/plays/goals-signals-measures): Derive observable signals and specific measures from goals to avoid tracking only outputs.
- [AWS: Designing Generative AI for Success POC](https://docs.aws.amazon.com/prescriptive-guidance/latest/gen-ai-lifecycle-operational-excellence/dev-architecting.html): Define the POC with business value, data readiness, technical feasibility, and risk mitigation, and set exit criteria.
- [GOV.UK: How the discovery phase ends](https://www.gov.uk/service-manual/agile-delivery/how-the-discovery-phase-works): Deciding whether to continue investing based on understood problems, constraints, opportunities and measures.
