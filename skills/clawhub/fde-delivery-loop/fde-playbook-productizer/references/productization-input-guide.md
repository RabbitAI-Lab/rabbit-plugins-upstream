# Product input guide

## What is needed for a single delivery record

| Category | Content |
|---|---|
| Problem | Users, tasks, impediments, frequency and business impact |
| Conditions | Industry, scale, system, data, authority, regulations and team capabilities |
| Scenarios | Workflows, architectures, skills, integrations and human collaboration |
| Evidence | POC results, adoption, value, costs, risks and failures |
| Variants | Customer-specific configurations, exceptions, workarounds and customizations |
| Learning | Which assumptions hold, are disproven, or remain unknown |

## Common evidence level

- P0 Observation: single project experience;
- P1 candidate: two projects are similar, but the conditions and values are not stable;
- P2 verified: two or more independent scenarios reproduce the core results;
- P3 mature: multi-team reuse, with standard assets, evaluation and maintenance;
- P4 standard: has stable interfaces, governance, support and retirement mechanisms.

Only P2 and above enter formal productization; P0–P1 remain in the candidate library.
