# Results Evaluation Checklist

- [ ] Evaluates all six diagnostic dimensions.
- [ ] Provides an overall score and six dimension scores.
- [ ] Identifies the most important reporting problems.
- [ ] Grounds criticisms in the user's supplied text, statistics, tables, or figures.
- [ ] Calibrates claims to the available evidence.
- [ ] Checks statistical reporting for method-appropriate completeness.
- [ ] Checks alignment between narrative statements and quantitative results.
- [ ] Provides concrete, actionable revision steps.
- [ ] Does not invent missing statistics, methods, findings, or citations.
- [ ] Maintains the Results/Discussion boundary.
