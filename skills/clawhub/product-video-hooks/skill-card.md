## Description:

Writes product video openings as aligned visuals, spoken lines, and text overlays, checks claims against platform rules, and can create short hook clips when footage is available.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

Ecommerce marketers and creators use the skill to draft and test opening seconds for product ads on TikTok, Reels, and Meta, using buyer language and substantiated claims.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Optional clip generation transfers product photos, reference footage, and spoken text to external services.

Mitigation: Use only materials approved for external processing, or choose written hooks and local editing.

Risk: The install example uses an unpinned CLI package.

Mitigation: Review the install source and version before running the command.

Risk: The security scan was partial because two path-like references could not be resolved.

Mitigation: Review the unresolved references and source files before relying on the scan as complete.
