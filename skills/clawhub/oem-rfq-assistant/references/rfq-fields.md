# Canonical RFQ field list

Map every inbound inquiry onto these fields. Mark each as **confirmed** (buyer or
an approved SKU/drawing supplied it) or **to confirm** (missing). Never guess a
value to fill a gap.

## Contact & company

| Field | Notes |
|---|---|
| Company | Legal or trading name |
| Contact name | Person to address the reply to |
| Email | Primary reply channel |
| WhatsApp / phone | Optional, common in SEA / MEA / LATAM sourcing |
| Country / target market | Destination market drives compliance & shipping |

## Product & project

| Field | Notes |
|---|---|
| Product type | See category list below |
| Product / model reference | e.g. an existing SKU, competitor model, or sample id |
| Project stage | Supplier sourcing / Concept-new model / Prototype-sample / Replacement supplier / Mass production |
| Estimated annual quantity | `<1,000` · `1,000–5,000` · `5,000–20,000` · `20,000–50,000` · `50,000+` |

## Technical spec (product-dependent)

For **seats / saddles**:

| Field | Notes |
|---|---|
| Cover material | e.g. PU, leather-look, waterproof exposure target |
| Foam | Density / comfort profile |
| Shell / base | Material and geometry — usually needs a drawing or sample |
| Rail / bracket / mounting interface | **Usually a blocker** — must match the vehicle |
| Dimensions | Length × width, or "custom per model" |
| Weight target | If specified |
| Color / logo customization | Private-label branding |
| Storage / accessory integration | For scooter/moped seats |

For **cranksets / drivetrain**: arm length, BCD, spindle interface, chainring
teeth, material (forged alloy / hollow), finish, chain guard/spider needs.

For **brake lines / cables** (only if you have verified data): vehicle type,
system type (mechanical/hydraulic), interface type, fluid (Mineral/DOT),
length, mounting hole distance, rotor size, motor cut-off switch requirement,
ID/OD, reinforcement, working/burst pressure, temperature range, bend radius.
**Do not quote pressure/temperature/safety numbers without real test evidence.**

## Commercial

| Field | Notes |
|---|---|
| Target price band | Ask; never volunteer a price first |
| Required certifications / test evidence | Only confirm what you can actually prove |
| Packaging / private-label requirements | Box, manual, barcode, branding |
| Timeline | Desired sample and production dates |

## Product categories (adapt to your catalog)

Example category list from a two-wheel mobility seat manufacturer:

- E-Bike Saddle
- Electric Scooter Seat
- Electric Moped Seat
- Cargo Bike Saddle
- City / Comfort Bike Saddle
- MTB Saddle
- Road / Racing Bike Saddle
- Junior / Kids Bike Saddle
- Bicycle Crankset (Hollow Integrated / MTB / Road / City / Junior / Forged arm)
- Chain Guard / Drivetrain Cover or Spider
- Scooter / Moped Brake Line (sample-review only unless verified)
- Other

## Blocker fields (cannot responsibly quote without these)

1. Mounting / rail / interface reference (or a drawing / physical sample).
2. Target vehicle or model the part must fit.
3. Estimated annual quantity (drives feasibility and MOQ discussion).
4. Destination market (drives compliance and logistics).
