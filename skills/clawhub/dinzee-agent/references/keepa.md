# Keepa API

共 3 个工具。使用 `@工具中文名` 语法在任务提示词中调用。

### @Keepa-亚马逊-商品搜索

逆向筛选、条件过滤

**Prompt 模板：**
> 亚马逊{{美国站}},搜索关键词 "{{Sports Water Bottles}}" 产品，配送方式{{FBA}}，按销量倒序的前{{50}}个

**参数约束：**
- **90天缺货百分比-最高**: `25`=缺货不超过25%的时间
- **当前评论数量-最高**: `10000`=不超过10000条评论
- **是否获取评分信息（默认 1 获取，0 不获取）**: `0`=不获取, `1`=获取
- **当前销售排名-最高（数值越小排名越好）**: `1000`=排名前1000
- **销量/月销量-最高**: `10000`=不超过10000件
- **标题关键词**: `Digital Camera Canon`=包含Digital、Camera和Canon
- **排序(最多3)**: 对象数组，每项包含 fieldName 与 sortDirection
- **Amazon域名ID**: 必填, `1`=Amazon.com (美国), `2`=Amazon.co.uk (英国), `3`=Amazon.de (德国), `4`=Amazon.fr (法国), `5`=Amazon.co.jp (日本), `6`=Amazon.ca (加拿大)
- **每页返回的最大结果数**: `50`=每页50条, `100`=每页100条, 范围 50~100
- **页码（从1开始）**: `1`=第一页
- **当前评分-最低**: `4.0`=至少4星
- **当前评分-最高**: `5.0`=5星以下
- **当前购买按钮含运费价格-最高**: `5000`=不超过$50.00
- **当前购买按钮含运费价格-最低**: `1000`=至少$10.00
- **购买按钮是否为FBA**: `true`=FBA, `false`=非FBA

### @Keepa-亚马逊-商品详情

商品详情，一键获取

**Prompt 模板：**
> 获取亚马逊{{美国站}}，asin为:{{B0CP9Z56SW}}、{{B0CP7P7WSQ}}、{{B0CGXBGM7K}}的数据

**参数约束：**
- **亚马逊域名ID**: 必填, `1`=Amazon.com (美国), `2`=Amazon.co.uk (英国), `3`=Amazon.de (德国), `4`=Amazon.fr (法国), `5`=Amazon.co.jp (日本), `6`=Amazon.ca (加拿大)
- **亚马逊标准识别号(ASIN)，多个ASIN，用英文逗号分隔，最多100个**: 必填, `B0088PUEPK`=单个ASIN, `B0088PUEPK,B00U26V4VQ`=多个ASIN
- **返回值是否包含历史数据**: `1`=包含价格历史、销售排名、历史销量, `0`=仅返回基本商品信息

### @Keepa-亚马逊价格历史

定价策略、价格历史记录

**Prompt 模板：**
> 在{{美国站}}查询 ASIN 为 {{B0D9QFRJMX}}的商品，并获取价格历史数据

**参数约束：**
- **是否返回大类BSR曲线**: `1`=返回
- **是否返回闪促价格曲线**: `1`=返回
- **是否返回划线价/标价曲线**: `1`=返回
- **是否返回市场最低新品价曲线**: `1`=返回
- **是否返回第三方FBM新品价曲线**: `1`=返回
- **亚马逊域名ID**: 必填, `1`=Amazon.com (美国), `2`=Amazon.co.uk (英国), `3`=Amazon.de (德国), `4`=Amazon.fr (法国), `5`=Amazon.co.jp (日本), `6`=Amazon.ca (加拿大)
- **限制历史数据天数，默认90天**: `30`=30天, `90`=90天, 最大 365
- **是否返回第三方FBA新品价曲线**: `1`=返回
- **亚马逊标准识别号(ASIN)**: 必填
- **是否返回Prime专属新品价曲线**: `1`=返回
- **是否返回卖家数曲线**: `1`=返回
- **是否返回优惠券后买盒价曲线**: `1`=返回
