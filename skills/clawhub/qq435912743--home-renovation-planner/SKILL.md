# 家装/装修规划助手

## 为什么需要本技能

装修是大部分人一生中**金额最大、流程最复杂、坑最多**的消费之一。
平均每户装修花费15-40万，90%的装修人都踩过坑。

**帮你省的钱**：合理的预算规划和避坑，平均省3-8万。

---

## 核心能力

### 1. 装修预算规划

输入户型面积和装修档次，自动生成详细预算表：

| 项目 | 简装(元/㎡) | 精装(元/㎡) | 豪装(元/㎡) |
|------|-----------|-----------|-----------|
| 设计费 | 30-50 | 80-150 | 200-500 |
| 拆除 | 30-50 | 30-50 | 30-50 |
| 水电改造 | 80-120 | 120-180 | 180-300 |
| 泥瓦工 | 100-150 | 150-250 | 250-400 |
| 木工 | 80-120 | 150-250 | 300-500 |
| 油漆 | 30-50 | 50-80 | 80-150 |
| 主材 | 300-500 | 600-1000 | 1200-2000 |
| 家电家具 | 200-400 | 500-1000 | 1500-3000 |
| **总计** | **850-1440** | **1680-2960** | **3740-6900** |

### 2. 装修流程管理

按施工顺序的阶段管理：

```
📅 装修全流程（标准60-90天）

第1-2周：设计阶段
  □ 量房
  □ 设计方案确定
  □ 施工报价对比（至少3家）
  □ 签订合同（注意付款节点）

第3-4周：拆改阶段
  □ 墙体拆改
  □ 铲墙皮
  □ 新建墙体
  ⚠️ 注意：承重墙不能动！

第5-6周：水电阶段
  □ 水电交底
  □ 开槽布管
  □ 水电验收（拍照留底）
  ⚠️ 注意：插座位置多想想未来需求

第7-8周：泥瓦阶段
  □ 防水工程（做48小时闭水试验）
  □ 贴瓷砖
  □ 美缝

第9-10周：木工阶段
  □ 吊顶
  □ 定制柜安装
  □ 门窗安装

第11-12周：油漆+安装
  □ 墙面处理
  □ 橱柜/洁具安装
  □ 开关灯具安装
  □ 开荒保洁

第13周：软装+验收
  □ 家具进场
  □ 通风去甲醛
  □ 竣工验收
```

### 3. 材料选购指南

按品类给出选购标准和推荐：

| 品类 | 选购要点 | 预算占比 | 推荐品牌 |
|------|---------|---------|---------|
| 瓷砖 | 看吸水率(≤0.5%)、平整度、防滑系数 | 8-12% | 马可波罗/东鹏/诺贝尔 |
| 地板 | 实木>实木多层>强化(按预算) | 5-10% | 圣象/大自然/德尔 |
| 涂料 | 看VOC含量、耐擦洗次数 | 3-5% | 多乐士/立邦/嘉宝莉 |
| 橱柜 | 板材(爱格>露水河>颗粒板)、五金(百隆>海蒂诗) | 10-15% | 欧派/索菲亚/尚品宅配 |
| 洁具 | 陶瓷看釉面、马桶看冲水方式 | 5-8% | TOTO/科勒/恒洁 |
| 开关插座 | 铜片厚度、阻燃材料 | 1-2% | 西门子/施耐德/公牛 |

### 4. 装修风格匹配

用户提供喜好描述（喜欢的颜色/材质/感觉），推荐匹配风格：

| 风格 | 特点 | 适合人群 | 参考造价 |
|------|------|---------|---------|
| 现代简约 | 线条简洁、黑白灰+跳色 | 年轻人 | 中等 |
| 北欧风 | 原木+白色、温馨自然 | 文艺青年 | 中低 |
| 新中式 | 实木+留白、禅意 | 中年/文化人 | 偏高 |
| 日式 | 原木+棉麻、收纳强大 | 极简主义者 | 中等 |
| 工业风 | 水泥+金属、粗犷 | 个性派 | 中低 |
| 轻法式 | 线条+拱门、奶油色 | 女性/浪漫派 | 偏高 |

### 5. 避坑清单（必读）

**合同坑**：
- ❌ 报价单没有品牌型号规格 → 后期加钱
- ❌ 水电按米算 → 绕线多花钱
- ❌ 付款比例3-3-3-1 → 建议3-3-3.5-0.5（尾款留到入住后）

**施工坑**：
- ❌ 防水只做一遍 → 必须2遍，48小时闭水
- ❌ 墙面没挂网 → 容易开裂
- ❌ 瓷砖没留缝 → 热胀冷缩崩瓷

**材料坑**：
- ❌ 报价用品牌最低端系列 → 问清楚具体型号
- ❌ 说"大品牌"不具体 → 要白纸黑字写型号

## 使用流程

### 快速预算估算

```
输入："我家套内90平，想在成都精装修，帮我做个预算"

输出：完整预算表（含各项明细和总价范围）
```

### 风格定位

```
输入："我喜欢温馨自然的风格，预算有限，
家里有小孩，推荐什么风格和注意事项？"

输出：风格推荐+儿童友好装修要点
```

### 材料对比

```
输入："实木地板和实木多层地板到底差在哪？
我家装地暖能不能用？"

输出：详细对比+地暖适配建议
```

### 验收清单

```
输入："装修马上完工了，帮我出一份详细的验收清单"
```

## 自进化学习系统（越用越好用、越用越高效）

本技能内置通用学习模块 `scripts/learner.py`。每次使用后自动复盘、积累经验，逐步提升输出质量与执行效率，无需人工维护。

### 记忆文件
`learned_patterns.json`（位于本技能目录）记录：操作总数、各能力使用频次、错误模式、用户偏好、改进建议。

### 使用后请调用（Bash）

```bash
# 记录一次成功使用（--capability 填本次主要能力名，如「简历优化」「比价」）
python scripts/learner.py record <本技能目录> --capability 简历优化
# 记录一次失败/异常
python scripts/learner.py record <本技能目录> --capability 简历优化 --fail --error 格式识别失败 --note "用户上传了非标准文件"
# 记录用户偏好（下次直接使用）
python scripts/learner.py prefer <本技能目录> --key 输出语言 --val 中文
# 查看累计洞察（高频能力 / 反复错误）
python scripts/learner.py insight <本技能目录>
# 自动复盘（错误≥3次 或 操作≥10次 时给出改进建议）
python scripts/learner.py reflect <本技能目录>
```

### 迭代规则
- **错误累计 ≥3 次** → 主动增加预检/兜底步骤，并将经验回写本 SKILL.md。
- **操作数 ≥10 次** → 分析高频能力优先打磨示例与质量，低频能力评估精简或合并。
- **重要用户偏好** → 写入 `learned_patterns.json`，下次调用直接采用，减少重复询问。

> 越用越懂你：第一次用是通用能力，第十次用已沉淀为你专属的最佳实践。
