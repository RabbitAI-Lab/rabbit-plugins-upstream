# ai-industry-infographic：AI 行业信息图素材包生成器

从选题到成图 Prompt 的全套流程：主题设计 → 并行搜索 → 三轮数据核实 → 结构化生图 Prompt → 小红书文案。一张信息图的所有素材，一次产出。

AI 行业信息图最怕数据错：一个数字印在图上不可撤回。这个 skill 内置 S/A/B/C 信源分级和三轮硬性核实（web-verify-protocol），保证上图的每个数字都能追溯到来源，同时给出 ChatGPT 生图 Prompt 和发帖文案，从选题到发布一条龙。

## 适合谁用

- AI 行业自媒体/内容创作者，常做产业链图谱、趋势信息图
- 需要"带核实数据+成图 Prompt"素材包的内容团队
- 关注 LLM 格局、具身智能、芯片产业链、算力成本的行业分析师

## 快速开始

零依赖，直接按 SKILL.md 执行。核心流程：

```text
选题设计 → 并行搜索(3-5路) → 三轮核实(web-verify-protocol) → 结构化输出 → 标题+文案变体
```

输出四件套：选题定位、核心数据表、ChatGPT 生图 Prompt、小红书发帖文案。

## 文件说明

| 文件 | 作用 |
|------|------|
| `SKILL.md` | 完整工作流：选题分类、并行搜索、三轮核实、Prompt 模板库、文案规则 |

## 核心能力

- **选题分类**：六种视觉类型（架构图/时间线/对比雷达/成本拆解/生态图/2×2矩阵）按数据形态自动匹配
- **三轮核实**：S/A/B/C 信源分级 + R1/R2/R3 硬性核实门槛，数据可追溯
- **Prompt 模板库**：五种图表类型的 ChatGPT 生图 Prompt 骨架，含配色和布局约束
- **文案规则**：小红书标题 5 公式（数据冲击/实用/稀缺/身份/知识）+ 口语化正文规则
- **数据复用**：多选题共享数据建单一真相源，更新一次全局同步

## 推荐流程

1. 选题设计：按数据形态匹配视觉类型
2. 并行搜索：官方/分析师/国际对比/小众/近48小时五路并行
3. 三轮核实：输出前打印核实报告
4. 结构化输出：选题定位+数据+Prompt+文案
5. 发布：信息图发小红书，素材包可存档或复用

# ai-industry-infographic: AI-industry infographic material pack generator

A complete pipeline from topic to image prompt: topic design → parallel search → three-round data verification → structured image-generation prompt → Xiaohongshu copy. Every asset for one infographic, produced in one pass.

Infographics fear wrong numbers most — a printed figure can't be unprinted. This skill embeds S/A/B/C source grading and three-round hard verification (web-verify-protocol), so every number on the graphic traces to a source. It also outputs a ChatGPT image prompt and post copy: topic to publish in one go.

## Who it's for

- AI-industry self-media / content creators who regularly make industry maps and trend infographics
- Content teams needing "verified data + image prompt" material packs
- Analysts following the LLM landscape, embodied AI, chip supply chains, compute costs

## Quick start

Zero dependencies — just follow SKILL.md. Core flow:

```text
Topic design → parallel search (3-5 tracks) → three-round verification (web-verify-protocol) → structured output → title + copy variants
```

Outputs a four-piece set: topic positioning, core data table, ChatGPT image prompt, Xiaohongshu post copy.

## Files

| File | Purpose |
|------|---------|
| `SKILL.md` | Full workflow: topic taxonomy, parallel search, three-round verification, prompt template library, copy rules |

## Core capabilities

- **Topic taxonomy**: six visual types (architecture map / timeline / comparison radar / cost breakdown / ecosystem map / 2x2 matrix) auto-matched to data shape
- **Three-round verification**: S/A/B/C source grading + R1/R2/R3 hard minimums, traceable data
- **Prompt template library**: ChatGPT image-prompt skeletons for five chart types, with color and layout constraints
- **Copy rules**: Xiaohongshu title formulas (data impact / utility / scarcity / identity / knowledge) + conversational body rules
- **Data reuse**: multi-topic shared data builds a single source of truth — update once, sync everywhere

## Recommended workflow

1. Topic design: match visual type to data shape
2. Parallel search: official / analyst / international comparison / niche / last-48h — five tracks
3. Three-round verification: print the report before output
4. Structured output: topic positioning + data + prompt + copy
5. Publish: infographic to Xiaohongshu, material pack archived or reused
