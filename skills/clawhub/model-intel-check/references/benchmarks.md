# 题库目录：有什么、去哪下、给谁用

**只登记，不囤积。** 本目录只记录各题库的存在、格式和获取入口；用到哪个再用
`make_data.py`（或按其 README 手工）拉取。格式一栏标记与本 skill 脚本的兼容性：

- `数值` = 数值/短答案，`\boxed{}` 判分 —— intel_check.py 直接支持
- `MCQ-4` = 四选一字母判分 —— 直接支持
- `MCQ-N` = 多选一（>4 选项）—— 需改脚本 LETTER 范围，暂作参考
- `parquet` = 需要 `pip install pandas pyarrow` 转换

## 按模型档位选套件（原则：选官方分落在 40–85% 的题，全对或全错都没有鉴别力）

| 被测模型档位 | 推荐套件 | 理由 |
|---|---|---|
| 旗舰 thinking（K3 / GPT-5 / Gemini 3 Pro / R1-0528 级） | **AIME 2026 全 30** + GPQA 50 | 新题防污染；两套都有官方分可对照 |
| 中端 thinking / 蒸馏版 | AIME 2026 前 15（`--aime-indices 0-14`）+ MATH-500 抽 50 | 旗舰套件会大面积零分，失去区分度 |
| 非 thinking 通用模型 | MATH-500 抽 50 + GPQA 50（`--no-thinking`） | 对照官方**非 thinking** 口径的分 |
| 复测/防背题加强轮 | MathArena 当季赛题 或 AIME 2026（若上次跑的 2025） | 换题不换协议 |

**换题库的代价**：新套件上该模型未必有官方分，判定只能锚定"同档模型在新题上的
相对表现"或官方相近套件的分数，报告中必须声明。
