## Description: <br>
Helps iOS developers and coding agents migrate CocoaPods projects to Swift Package Manager by auditing dependencies, mapping packages, translating build settings, and adapting CI/CD. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[changjiashuai](https://clawhub.ai/user/changjiashuai) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to plan and execute CocoaPods-to-SPM migrations for iOS projects, including dependency audits, migration mapping, build setting translation, verification, and CI/CD updates. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Migration guidance can lead to incorrect project, Package.swift, Xcode, or CI changes if applied without review. <br>
Mitigation: Review generated changes and validate builds, package resolution, resource loading, Objective-C bridging, and CI updates before release. <br>
