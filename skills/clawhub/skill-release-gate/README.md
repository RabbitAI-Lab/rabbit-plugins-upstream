# Skill Release Gate / 上架三铁律发布闸门

## English

The mandatory release gate every skill / MCP / expert must pass: (1) national+international compliance, (2) AI-friendly, (3) strong cultural/IP story, with A/B/C/D tiering and built-in offline PII/secret scanners.

- Entry: read `SKILL.md` frontmatter, then follow steps.
- Scripts: `scripts/desens_check.py`, `scripts/secret_scan.py`; run `python scripts/<file> --help`.

## 中文

所有 skill / MCP / 专家上架前必过的发布闸门：国家+国际合规、AI 友好、理念强 IP；A/B/C/D 分级加闸；内置离线 PII/密钥扫描与去敏复核。

- 入口：读 `SKILL.md` frontmatter 后按步骤执行。
- 脚本：`scripts/desens_check.py`、`scripts/secret_scan.py`；`python scripts/<file> --help` 看用法。
