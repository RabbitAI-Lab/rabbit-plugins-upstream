# 元器件选型避坑指南（1.0.0）

**下单前 5 分钟对照，省掉几周的"玄学调试"。**

买到翻新 Flash 演示时丢数据、买到打磨 IGBT 炸板、买到 HC-06 调不了 AT、买到假 LM2596 带不动载——这些坑全部有前人踩过。本技能把渠道分级、假芯片识别、高频模块坑、缺货替代链整理成下单前对照表，电子 DIY、创客、硬件工程师、毕设学生都用得上。

## 它解决什么问题

| 你遇到的 | 它给你的 |
|----------|----------|
| 不知道在哪买靠谱 | 渠道四级分级（只给类型不给店名）：核心件走自营/授权分销，练手件才拼低价 |
| 怕买到假芯片 | 四类假芯片特征 + 五步验真法（溶剂擦丝印/查日期码/微距看背面） |
| 传感器数据乱跳 | 高频模块坑速查：MQ 裸探头、SHT30 兼容料、USB 供电纹波…… |
| 关键件缺货要换方案 | 缺货替代链：F103→GD32、SHT30→AHT20，改动量标清 |
| 涉及 220V 不敢接 | 安全红线：断电接线+先低压调试，无例外 |

## 内置知识

- **渠道四级分级**：自营目录商城/授权分销（核心件）→ 开发板官方店 → 认证企业店 → 个人与二手渠道（仅练手件）
- **四类假芯片**：打磨改标（最危险）/ 翻新拆机 / 白盒假冒 / 克隆片——每类给识别特征
- **五步验真**：看包装 → 溶剂擦丝印 → 微距看背面 → 查日期码 → 测参数
- **高频模块坑**：SHT30 / MQ 系列 / HC-05/06 / W25Q64 / LM2596 / TP4056 / 18650 / ESP32 模组 / 电源 / 继电器——每条给"自己量什么"的判据
- **缺货替代链**：五条常用替代，改动量按实际标（哪些是换个驱动、哪些要重标定，写清楚）

## 真实输出样例

问：「我要买 SHT30 测湿度做毕设，有什么坑？」

> **SHT30 的坑就一条，但足够毁掉你的毕业数据：兼容替代芯片。**
> 市面上大量"SHT30 兼容"模块用的是国产仿制芯片，标称精度一样，实测温漂大、湿度偏差 5%RH 以上——短时间演示看不出来，**连续跑 48 小时记录数据时漂移就现形**，答辩前发现来不及了。
>
> **正确买法**：认准 Sensirion 原厂（丝印 `SHT30`， humidity 精度 ±2%RH），走自营/授权分销渠道。到手后用「五步验真法」第 4 步查日期码：同盘日期码一致且不晚于购买日期。
>
> 【需自查：价格与库存以商城实时为准】
