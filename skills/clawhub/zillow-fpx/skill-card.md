## Description:

Query zillow.com from a shell with the fpx CLI to search listings, retrieve property records, histories, photos, market reports, and signed-in saved Zillow data through a browser tab.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and real-estate analysts use this skill to generate shell-based Zillow lookup workflows when they need listing, property, market, or saved-account data without running the Zillow MCP server.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The browser bridge can access saved Zillow data when the Zillow tab is signed in.

Mitigation: Keep the Zillow tab signed out for ordinary listing lookups, use a dedicated browser profile when possible, and remove or revoke pairing when finished.

Risk: Zillow can return login redirects, captcha interstitials, or changed page structures while fetch commands still complete.

Mitigation: Check fetched HTML for sign-in or bot-wall markers before trusting empty results, and use the documented healthcheck when calls fail.
