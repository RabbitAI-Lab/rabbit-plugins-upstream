Developers and engineering teams use this skill to plan and automate deprecation, sunset, and migration workflows for systems, APIs, features, and user transitions.

### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: The skill requests broad read and command execution authority for loosely defined automation tasks.

Mitigation: Review before installing and avoid use with sensitive repositories, credentials, or production migration work unless the publisher narrows scope and documents command, file, and credential safeguards.

Risk: The documented behavior is broader than the deprecation-and-migration name suggests.

Mitigation: Confirm the intended scope with the publisher and limit agent permissions to the specific files, commands, and systems needed for the migration task.
