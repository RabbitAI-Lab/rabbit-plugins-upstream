## 使用方法

0. **检测 .code-spec/ 是否存在**：检查 `index.md` 是否存在
   - 存在 → 继续步骤 1
   - 不存在 → 执行首次分析流程
1. 根据任务关键词匹配上表中的模块
2. 读取对应模块文件（仅读取需要的，不全量加载）
3. 在代码生成/修改/修复中应用规范
4. 对话结束时检查是否有新规范需要增量更新

## 语言特有规范

当项目使用 Python/Java/Go/Node.js/PHP/Rust 时，分析完通用 `code-style.md` 后，
按 `analyze-<lang>.md` 指引追加语言特有条目到对应的 `<lang>-style.md` 文件。
日常使用时按需加载，不全量加载。
