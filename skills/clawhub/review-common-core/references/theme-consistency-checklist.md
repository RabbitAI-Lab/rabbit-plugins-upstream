# 主题一致性审稿清单（theme-consistency-checklist）

> 本清单是 holistic-review-framework.md 第0节"一句话定题"的配套工具。
> 提供可执行的 JSON 校验格式和详细检查条目。

---

## 使用流程

1. 通读全文
2. 用一句话回答"这篇文章在讲什么？"
3. 对照以下 JSON 清单逐项填写
4. 用 `scripts/validate_theme_consistency.py` 验证

---

## JSON 校验格式

```json
{
  "meta": {
    "文章标题": "",
    "审稿日期": "",
    "审稿人": "笔探"
  },

  "一句话定题": {
    "我的答案": "",
    "答案中是否出现'和/以及/同时/也'": false,
    "判定": "通过/双核心/立意不明/尾巴多余"
  },

  "核心主题拆解": {
    "核心1": {
      "主题": "",
      "起始段落": "",
      "结束段落": "",
      "所占篇幅比例": "",
      "情绪基调": ""
    },
    "核心2": {
      "主题": "",
      "起始段落": "",
      "结束段落": "",
      "所占篇幅比例": "",
      "情绪基调": ""
    }
  },

  "双核心诊断": {
    "是否存在双核心": false,
    "两个核心是否有因果关系": false,
    "如果有因果，读者是否能明显感知到": true,
    "结论": "单篇专注/可合并/必须拆分"
  },

  "偏离检查": {
    "标题与正文：标题是否准确预告了全文主题": true,
    "开头与结尾：结尾是否回扣了开头承诺的核心": true,
    "收尾段：是否存在与主题无关的尾巴": false,
    "偏离段描述": "",
    "建议行动": "删除偏离段/拆分新文/修改开头/修改结尾"
  },

  "读者预期管理": {
    "读者读完第一节后的预期": "",
    "实际后半篇的内容": "",
    "预期与实际是否一致": true,
    "如果不一致，读者是否感到'跑题'": false
  },

  "输出": {
    "一句话定题最终版": "",
    "主题一致性评分": "A/B/C/D",
    "需要作者确认的问题": []
  }
}
```

### 评分标准

| 等级 | 标准 | 行动 |
|------|------|------|
| A: 完美 | 一句话定题答案清晰，全文紧密围绕一个主题，无偏离段落 | 直接进入后续审稿 |
| B: 良好 | 主题清晰，但存在1-2句轻微偏离，不影响整体感受 | 标注偏离句，可选修改 |
| C: 需修 | 一句话定题答案需要"和"字连接两个主题，或结尾明显偏离 | 必须处理：删偏离段或拆分 |
| D: 不可 | 全文主题散乱，一句话说不出在讲什么 | 建议作者重新规划文章结构 |

---

## 常见双核心模式

| 模式 | 示例 | 判定 | 处理 |
|------|------|------|------|
| 因果延伸 | "我的系统" → "所以我花钱多了" | 🟡 逻辑上成立，但读者感觉跑题 | 要么删后来者，要么切断成两篇 |
| 并列双线 | "A体验" + "B体验"混在一起写 | 🔴 两条线互相抢戏 | 拆成两篇 |
| 收尾升华 | 前面讲故事，结尾拔高到行业趋势 | 🔴 结尾脱离叙事 | 删升华段，自然收 |
| 夹带的彩蛋 | 文章中段插入一个不相干的小故事 | 🟡 信息密度够可留，否则删 | 看篇幅，短可留，长则删 |
