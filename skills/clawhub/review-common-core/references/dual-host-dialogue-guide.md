# 双人对话稿审稿指南

与单人独白不同，双人对谈稿有特殊的节奏和 voice 要求。本节定义双人对话稿的专项审稿维度，与通用审稿框架搭配使用。

---

## 1. 对话切换频率

双人对话最忌讳"粘在一起"——A说完B立刻接、B说完A立刻接，没有给听众留消化时间。

### 判断标准

| 切换间隔 | 感觉 | 建议 |
|---------|------|------|
| <8秒 | 🔴 太密 | 听众来不及消化上一句，听起来像"抢话" |
| 8-15秒 | 🟡 略密 | 如果是干货密集段可接受，否则需要拉开 |
| 15-30秒 | ✅ 舒适 | 正常谈话节奏 |
| >30秒 | 🟡 太疏 | A或B独白过长，需要打断或轮换 |

### 特殊处理

- **反转/金句后必须留空白**：A说出一句有冲击力的话后，B不应立刻接话。应标注"(停顿)"或B给一个非语言反应（"嗯……"）
- **悬念后不宜追问太快**：A说"我自己也纠结过"——听众需要一个反应时间，B可以直接追问会冲淡悬念

---

## 2. B的标准角色禁区

B（提问方）在双人稿中最容易出现以下问题：

### ❌ 禁区1：替A做总结

```
A：三步——收集、编译、学习。
B：所以第一步是收集，第二步是编译，第三步是学习？
→ ❌ B复读了A刚说过的内容
→ ✅ 改为B的追问："那第二步和第三步之间有什么区别？"
```

### ❌ 禁区2：当"听众发言人"做点评

```
B：这个角度好一点。 ← narrator感太重
→ ✅ "嗯，这个至少没那么揪心。" ← 个人化反应
```

### ❌ 禁区3：复读金句指导听众

```
A：试错不重要，试了不回头才重要。
B："试错不重要，试了不回头才重要"——这句话值得记住。
→ ❌ B在替作者告诉听众该记住什么
→ ✅ 沉默 + "嗯……这个我要想想" 或直接推进
```

### ✅ B的合格角色

- **真实好奇的追问**："等一下——第三步具体什么意思？"
- **个人化反应**："这句话挺扎心的""我太有共鸣了"
- **推动话题的引导**："那你后来怎么办？""多少钱？"
- **适当的沉默**：当A说了关键观点时，(停顿)比追问答得更好

---

## 3. 独白段长度控制

双人稿中A的连续独白不应太长：

| 独白长度 | 建议 |
|---------|------|
| <30秒 | ✅ 正常 |
| 30-60秒 | 🟡 需要中间有B的反应或打断 |
| >60秒 | 🔴 必须插入打断——除非是故事高潮段落 |

### 独白过长时的处理方法

- B可以在段落间插入开放式问题："等一下——那XXX是怎么处理的？"
- B可以给出短反应："嗯""是这样""然后呢？"
- 允许A在故事高潮时有60-90秒的连续叙述（如翻车段）

---

## 4. 双人稿特殊检查清单

审双人对谈稿时，额外检查以下维度：

| # | 检查项 | 问题 |
|---|--------|------|
| 1 | 切换节奏 | B的下一句话是否需要暂停？能否加"(停顿)"？ |
| 2 | B是否有复读 | B的话是否是A刚才说过的内容？ |
| 3 | B是否有点评感 | B是否在替听众"评价"好或不好？ |
| 4 | 独白长度 | A的连续独白是否超过60秒？ |
| 5 | 追问自然度 | B的问题是否像预习过稿子的人会问的？ |
| 6 | 沉默利用 | 全篇是否有足够的沉默让听众消化？ |

---

## 5. 与通用审稿框架的关系

- **对话切换检查**在 Phase -1（概念热力图）之后、Phase 1（五维度）之前执行
- **检查结果**标注在审稿报告的"对话切换密度"专属板块
- 输出格式：

```
## 对话切换密度审查

| 幕 | 切换次数 | 平均间隔 | 判定 | 问题段落 |
|----|---------|---------|------|---------|
| 1 | 10次 | 18秒 | ✅ | B"怎么说？"接太快 |
| 2 | 8次 | 30秒 | ✅ | — |
| ...
```

- **B的角色禁区**标注在 Voice 一致性板块下，作为单独子节
