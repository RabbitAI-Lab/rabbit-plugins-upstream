## ③ 因子构造：从模板到强因子

> 本章目标：让你能**批量**造出同时满足三条硬门槛的 alpha——Sharpe ≥ 1.25、Fitness ≥ 1.0、对你已 ACTIVE 集合的自相关 < 0.7。核心心法一句话：**用少数几种结构骨架，去"广撒"大量字段**，让 AI 帮你把"字段 × 结构"这张网织满。

---

### 3.1 一个可复用的基础形态

绝大多数能过闸的因子，都能塞进这个骨架：

```
group_rank( ts_rank( SIGNAL , 窗口 ) , 分组 )
```

拆成三层理解，从里到外：

| 层 | 组件 | 作用 | 直觉 |
|---|---|---|---|
| ① 信号 | `SIGNAL` | 一个有经济含义的原始量或比率 | "我赌什么？"（如 ROE、盈利收益率） |
| ② 时序 | `ts_rank(SIGNAL, d)` | 把 SIGNAL 在**过去 d 天**里排名，输出 0~1 | "这只股票现在的信号，相对它自己的历史是高是低？"→ 去量纲、抗跳变、天然平滑 |
| ③ 截面 | `group_rank(..., 分组)` | 在**同组股票内**横向排名 | "在同行里它排第几？"→ 剔除组间差异，只赌组内相对强弱 |

为什么这个骨架高产：
- `ts_rank` 输出被压进 [0,1]，**天然限制换手**（不会因为原始值突然翻倍就大幅调仓）——这对后面过 Fitness 至关重要。
- `group_rank` 让因子**行业中性**，自动剔除"整个板块涨"的 beta，聚焦个股 alpha，也更容易和你已有因子**正交**（降低自相关）。
- 两层排名叠加，对异常值极其鲁棒，`SIGNAL` 里有几个脏数据也不至于毁掉整个因子。

> 小白提示：先跑通这一个骨架，再谈其它。它是你 80% 提交的地基。

---

### 3.2 SIGNAL 怎么来：分母杠杆的经济含义

`SIGNAL` 最高产的形态是**"某个规模量 / 某个分母"的比率**。分子通常是利润、现金流、分析师预期；**分母决定了你在赌哪一类逻辑**。记住这张表，你就能一个分子配五个分母，瞬间造出五个不同的因子：

| 分母 | 代表比率 | 经济含义 | 强度/备注 |
|---|---|---|---|
| `/ equity`（净资产） | ROE 类 | 每一元**股东权益**赚多少 → 盈利**质量** | 最强的一类，权益是"自己的钱"，回报率直接反映竞争力 |
| `/ close`（股价） | 盈利收益率 E/P、B/P | 每一元**市值**买到多少盈利/账面 → **估值/价值** | 经典价值因子，close 每天变 → 天然自带一点动量信息 |
| `/ assets`（总资产） | ROA 类 | 每一元**总资产**赚多少 → 资产**运营效率** | 不受资本结构（负债多少）影响，跨杠杆可比 |
| `/ cap`（市值） | 各种 yield | 每一元**总市值**对应多少 → 规模归一的估值 | 与 /close 相近，但用总市值更稳（受单日股价噪声小） |
| `/ sales`（营收） | 利润率、P/S | 每一元**收入**转化成多少利润 → **盈利能力/成长** | 亏损或利润不稳的成长股常用它替代 E/P |
| `/ enterprise_value` | EV yield | 计入**净负债**后的真实企业价值收益率 | 剔除现金和负债干扰，比 /cap 更"干净" |

用法就是"分子换着来 × 分母换着来"，让 AI 生成一批候选：

```
# 分子：net_income / operating_cash_flow / est_eps ...
# 分母：equity / close / assets / sales ...
SIGNAL = fundamental_净利润类 / fundamental_或pv_规模类
```

> 心法（把常量变成变量）：不要把"分母"当固定的。**把分母本身当成一个可搜索的旋钮**，一个分子能派生一整排因子。

### 3.3 ★换手与 Fitness 的反直觉关系（本章最重要）

很多小白第一次卡关都卡在这里：**Sharpe 明明达标了，Fitness 就是过不了 1.0，怎么办？**

先看公式：

```
Fitness = Sharpe × sqrt( |returns| / max(turnover, 0.125) )
```

关键点：**turnover（换手率）在根号里的分母**。turnover 越大，Fitness 越小。也就是说——

> **一个信号预测力再好（Sharpe 高），如果它每天疯狂调仓（turnover 高），Fitness 也会被拖垮。**

给你数字直觉（假设 Sharpe=1.5、|returns|=0.10 固定，只看 turnover 变化）：

| turnover | max(turnover, 0.125) | sqrt(0.10 / 分母) | Fitness | 能否过闸(≥1.0) |
|---|---|---|---|---|
| 0.60（短窗高频） | 0.60 | 0.41 | **0.61** | ❌ 挂 |
| 0.30 | 0.30 | 0.58 | **0.87** | ❌ 差一点 |
| 0.15 | 0.15 | 0.82 | **1.22** | ✅ 过 |
| 0.10 | 0.125（触底） | 0.89 | **1.34** | ✅ 稳过 |
| 0.05 | 0.125（触底） | 0.89 | **1.34** | ✅（低于 0.125 不再加分） |

看懂两件事：
1. **同样的预测力，把 turnover 从 0.60 降到 0.15，Fitness 直接翻倍**（0.61 → 1.22）。这就是"救 Fitness"的杠杆。
2. `max(turnover, 0.125)` 说明 **turnover 低于 0.125 就不再有额外收益**——不用把换手压到极致，压到 ~0.10 附近就够了，再低是浪费。

**怎么降换手？把时序窗口拉长。** 短窗（如 `ts_rank(x, 5)`）信号一天一变、换手爆炸；长窗把信号平滑住，调仓自然变慢：

| 窗口 d | 典型场景 | 换手倾向 |
|---|---|---|
| 5 / 10 | 短期反转、事件 | 高换手，常卡 Fitness |
| 22 / 63 | 月度/季度 | 中等 |
| **126 / 252 / 504** | 半年/一年/两年 | **低换手，救 Fitness 首选** |

实操套路（Fitness 不达标时按顺序试）：
1. **把窗口加长**：`ts_rank(SIGNAL, 22)` → `ts_rank(SIGNAL, 252)`。最直接。
2. **加平滑算子**：外面套 `ts_mean(x, N)` 或 `ts_decay_linear(x, N)`，进一步压换手。
3. **换低频信号源**：基本面（季报）本身就比高频 pv 换手低。

> 记住这条因果链：**短窗 → 高换手 → 卡 Fitness；长窗（126/252/504）→ 低换手 → 救 Fitness。** 当你 Sharpe 够但 Fitness 差，几乎总是换手问题，先拉窗口。

### 3.4 组合法五式：让因子更强、更正交

单信号过了闸，还想 Sharpe/Fitness 更高、且和你已有因子**自相关 < 0.7**？把多个信号组合起来。以下五式从易到难：

#### 第一式：跨角色相乘（质量 × 预期）
把两个**不同数据角色**的信号相乘，抓"既……又……"的股票：

```
group_rank( ts_rank(ROE, 252) , subindustry )
  * group_rank( ts_rank(est_eps_修正, 252) , subindustry )
```

经济含义：**盈利质量高（ROE）且分析师在上调预期（est_eps）**的股票——两个独立利好叠加，比单看一个更锐利，且天然和纯质量/纯预期因子正交。

#### 第二式：rank blend（等权融合）
最稳的融合方式，先各自 rank 再加权，避免量纲打架：

```
0.5 * rank(A) + 0.5 * rank(B)
```

A、B 是两个不同逻辑的信号。等权 blend 通常比任一单腿更平滑、Sharpe 更高。权重也可以试 0.3/0.7。

#### 第三式：深层嵌套 4 信号 blend（通用模板）
把两个 blend 再 blend，一次融合 4 个信号，正交性和稳健性都上一个台阶：

```
0.5 * ( 0.5*rank(A) + 0.5*rank(B) )
+ 0.5 * ( 0.5*rank(C) + 0.5*rank(D) )
```

建议 A/B/C/D 来自**不同角色**（如 A=价值、B=质量、C=分析师预期、D=动量/反转），角色越分散，越不容易和已有因子撞车。

#### 第四式：反转 × 质量 blend
用短期反转做一条腿、质量做另一条腿，两种完全不同的 alpha 来源拼在一起：

```
0.5 * rank( -(close/open - 1) )
+ 0.5 * rank( ts_rank(ROE, 252) )
```

`-(close/open - 1)` 是日内反转（今天涨太多的明天回落，故取负号）。它和慢速质量因子相关性极低，blend 后往往显著降自相关。

#### 第五式：另类数据正交通道（期权 IV）
用主流玩家较少碰的数据（如期权隐含波动率 `implied_volatility_*`）单独开一条通道，做出的因子天然和"人人都在用的基本面因子"正交：

```
group_rank( ts_rank( -implied_volatility_call, 63 ) , industry )
```

IV 反映市场对该股的**风险/情绪定价**，是独立于财报的信息源。即使单腿 Sharpe 一般，它对**降低整体自相关**贡献很大——正交本身就是价值（能挤进你的 ACTIVE 集合而不被 0.7 相关卡掉）。

> 通用心法：**正交 = 换信息源。** 撞相关时，别在同一堆基本面里换算子，去换一个**新角色的数据**（news / option / sentiment / analyst）。

### 3.5 中性化：industry 还是 subindustry？

中性化（neutralize / group_rank 的分组，或显式 `group_neutralize`）的作用是**剔除"组"这一层的共同波动，只保留组内的个股 alpha**。选哪一级分组，是在"剔除多少 beta"和"保留多少样本"之间权衡：

| 分组粒度 | 剔除的东西 | 组内股票数 | 适用 |
|---|---|---|---|
| `market` | 只剔全市场 beta | 最多 | 想保留行业配置逻辑时 |
| `sector` | 剔大板块 | 多 | 粗中性 |
| `industry` | 剔行业 beta | 中 | **默认首选**，平衡最好 |
| `subindustry` | 剔子行业 beta，最细 | 少 | 想做"纯个股 alpha"、且组内样本仍够时 |

经验：
- **默认从 `industry` 起步**，最稳。
- 若因子还带明显行业暴露（回测里某几个行业主导收益），**下沉到 `subindustry`** 做更彻底的中性化，通常能提 Sharpe、降自相关。
- 分组太细（subindustry）在小 universe 里可能每组只剩几只股，排名会不稳，此时退回 `industry`。

### 3.6 通用示例模板（公开常识级，拿去改造，别照抄）

以下都是量化教科书级的**公开逻辑**，给你当"种子"，真正要做的是**换字段、换窗口、换分组、做 blend** 去衍生一大批：

```
# 模板 1：质量（ROE）× 分析师上修 —— 好公司且被看好
group_rank(ts_rank(net_income/equity, 252), subindustry)
  * group_rank(ts_rank(est_eps, 252), subindustry)
# 释义：净资产回报率高 + 一致预期 EPS 在抬升，双重利好叠加。

# 模板 2：价值 + 质量 rank blend —— 便宜又赚钱
0.5*rank(net_income/close) + 0.5*rank(net_income/equity)
# 释义：盈利收益率(E/P)代表便宜，ROE代表赚钱能力，两条独立逻辑融合。

# 模板 3：反转 × 质量 —— 短期错杀的好公司
0.5*rank(-(close/open - 1)) + 0.5*rank(ts_rank(net_income/assets, 252))
# 释义：今天被过度卖出(日内反转) + 长期资产回报率高(ROA)，赌均值回归。

# 模板 4：4 信号深嵌 blend —— 多角色稳健组合
0.5*(0.5*rank(net_income/close) + 0.5*rank(net_income/equity))
+ 0.5*(0.5*rank(ts_rank(est_sales,252)) + 0.5*rank(-implied_volatility_call))
# 释义：价值+质量+营收预期+期权情绪，四个角色分散，正交性强。

# 模板 5：期权 IV 正交通道 —— 独立信息源
group_rank(ts_rank(-implied_volatility_put, 63), industry)
# 释义：看跌期权隐含波动率低=市场不慌，做多；与基本面因子几乎不相关。
```

> 注意：这些是**结构示范**，字段名请用 `GET /data-fields` 查你账号**实际能用**的名字（tier 会锁部分字段/算子，别猜），把 `net_income`、`est_eps` 等替换成平台真实字段 id。

### 3.7 本章工作流：让 AI 帮你"广撒 × 结构"

把上面的东西串成一条可自动化的流水线，这才是"高效攒分"的关键：

1. **拉字段**：`GET /data-fields` 列出该 universe 下所有可用字段，按角色（fundamental/analyst/option/pv…）分桶。
2. **广撒**：让 AI 用 3.1 的骨架，把"分子 × 分母（3.2）× 窗口（默认长窗 3.3）× 分组（3.5）"做**笛卡尔积**，一次生成几十上百个候选表达式。
3. **过闸筛选**：批量 `POST /simulations`（注意低等级 K=2 并发上限，排队跑），只留 Sharpe≥1.25 且 Fitness≥1.0 的。
4. **Fitness 抢救**：没过 Fitness 的，自动把窗口从短换长（22→252→504）、套 `ts_decay_linear` 重跑（3.3）。
5. **正交筛选**：对活下来的，检查与你已 ACTIVE 集合的自相关；≥0.7 的，用 3.4 第五式换个新数据角色重造，或做 blend 降相关。
6. **每天只提最好的 1~2 个**：当天质量分是当天提交的**平均值**，弱因子会拉低平均，宁缺毋滥。

> 覆盖率心法：当某个方向"挖空了"，先问自己——**我这张"字段×结构"的网，到底覆盖了多少组合？** 多半远没穷尽。换个分母、换个数据角色、加一层 blend，空间立刻又打开了。
