# ATTRIBUTION

## 本技能的核心工作流方法论源自：

**codex-stata-for-economists**
- 作者：陈铸 (Chen Zhu) / 中国农业大学
- 仓库：https://github.com/maxwell2732/codex-stata-for-economists
- 许可：MIT License
- 贡献内容：
  - Agent审查规则模板（domain-reviewer, econometric-reviewer, log-validator 等）
  - 工作流快速参考架构
  - 质量门禁与评分细则
  - 复现协议（Replication-First Protocol）
  - Stata编码规范
  - 日志校验协议（Log Verification Protocol）
  - 数据保护协议
  - MERGE协议与学习循环
  - 模板文件（master.do, did-analysis, ddml-analysis 等）
  - Stata语法参考目录结构与部分内容

## Stata执行工具层源自：

**Stata-MCP**
- 作者：Sepinetam (Tianchen)
- 仓库：https://github.com/sepinetam/stata-mcp
- 文档：https://docs.statamcp.com
- 贡献：Stata CLI执行接口（uvx stata-mcp tool do）

## 整合与适配

本技能将上方的 **Codex Agent规则系统** 与 **MCP/CLI执行工具** 适配为 OpenClaw 技能格式，
增加了 OpenClaw 系统集成说明、stata-skill 兼容层以及中文工作流文档。
