## Description:

This skill is ready for commercial/non-commercial use.

## Use Case:

Marketplace analysts and sellers use this skill to check whether Ozon product categories are trending up or down over selected periods.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installing or upgrading qhkit can change the local software environment.

Mitigation: Review the package before installing; prefer a preinstalled, pinned version of qhkit.

Risk: Qinghu access requires an API token and data calls can incur charges.

Mitigation: Configure credentials yourself; check current pricing and obtain user approval before paid calls.
