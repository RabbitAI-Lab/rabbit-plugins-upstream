# GB/T 9959.3-2019 猪肉分割部位术语相关要求摘编

> 来源：GB/T 9959.3-2019《鲜、冻猪肉及猪副产品 第3部分：分部位分割猪肉》。本文仅改写本技能使用的部位肉名称和对应分割位置。

## 部位名称

- **猪五花**：从第五、第六胸椎间至腰荐椎连接处切下，去除猪肋排后形成五层夹花的腹部肉。
- **猪带骨方肉**：从第五、第六胸椎间至腰荐椎连接部位，在距脊椎骨下4 cm～6 cm肋骨处平行切下大排后，保留肋骨并剔去奶脯的部位肉。
- **猪大排**：从第五、第六胸椎间至腰荐椎连接部位，在距脊椎骨下4 cm～6 cm处平行切下，略经修割脂肪层的带脊部位肉。
- **猪肋排**：取自猪方肉的肋骨部分，边缘腹肌不超过3 cm。
- **猪前排**：从第五、第六椎间至颈椎部位脊骨，去除颈背肌肉，保留胸骨和五根肋骨的部位肉。
- **猪前腿、猪后腿**：分别沿前腿与后腿的骨骼和相邻肌肉边界分割，保持相应部位形态完整。
