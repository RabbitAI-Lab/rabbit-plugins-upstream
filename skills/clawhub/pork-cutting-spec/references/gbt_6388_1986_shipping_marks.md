# GB/T 6388-1986 运输包装收发货标志相关要求摘编

> 来源：GB/T 6388-1986《运输包装收发货标志》。本文仅改写分割猪肉运输包装收发货标志所需条款。

- 商品分类图示标志为必备项目；其他项目按实际需要选用，包括供货号、货号、品名规格、数量、毛重与净重、生产日期、生产厂、有效期限、收发货单位、运输号码和发运件数等。
- 中文采用仿宋体，代号采用汉语拼音大写字母，数字采用阿拉伯数字，英文采用大写拉丁字母。
- 标志应清晰、醒目、不脱落、不褪色；食品类纸箱、纸袋和塑料袋使用绿色单色印刷。
- 纸箱、纸袋和塑料袋可直接印刷；木箱、桶和袋类可刷写；暂不能确定的信息可以粘贴方式补充。
- 六面体包装分类图示通常设在第5、6面的左上角，袋类设在两大面的左上角，桶类设在左上方。
