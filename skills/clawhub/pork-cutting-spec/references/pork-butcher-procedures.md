## 3. 原料要求

加工分割猪肉的原料应符合 [GB/T 9959.1-2019相关要求](gbt_9959_1_2019_raw_carcass.md)，包括：

- 带皮片猪肉
- 去皮片猪肉
- 以片猪肉为原料加工的分体

---

## 4. 分割车间基本要求

### 4.1 车间组成

分割车间应包括：

- 胴体预冷间
- 分割剔骨间
- 产品冷却间
- 包装间
- 包装材料间
- 磨刀清洗间
- 工器具间
- 更衣室
- 卫生间
- 空调设备间等

### 4.2 温度要求

| 区域    | 温度要求  |
| ----- | ----- |
| 胴体预冷间 | 0℃～4℃ |
| 产品冷却间 | 0℃～4℃ |
| 分割剔骨间 | 12℃以下 |

### 4.3 设备表面要求

肉品接触面应：

- 易于清洗，表面光滑、耐磨、防渗、无凹陷和裂缝
- 耐腐蚀、无毒、无异味
- 可经反复清洗和消毒

---

## 5. 分割方式

### 5.1 热分割

- **定义**：以屠宰后未经冷却处理的鲜片猪肉为原料进行分割
- **时间要求**：分割至入预冷库时间不应超过45min

### 5.2 冷分割

**冷却猪肉分割**：

- 原料：冷却猪肉
- 温度要求：中心温度应控制在7℃以下
- 时间要求：分割加工时间不应超过1h

**冷冻猪肉分割**：

- 原料：冷冻猪肉
- 温度要求：解冻至适宜的分割温度（如-2℃～4℃）
- 可选：也可根据需要进行冻切加工
- 时间要求：分割加工时间不应超过1h

## 6. 分割程序及要求

### 6.1 分割工序概述

片猪肉可按程序进行整体分割，分段加工为六分体、八分体。

也可对六分体产出的前段、中段和后段产品分别进行分割：

**前段**：

- 颈背肌肉（Ⅰ号肉）
- 前腿肌肉（Ⅱ号肉）
- 前肘、前排、前腿骨、扇骨、月牙骨（脆骨边）等

**中段**：

- 大排肌肉（Ⅲ号肉）
- 小里脊
- 带骨中方肉
- 五花肉
- 脊骨、肋排等

**后段**：

- 后腿肌肉（Ⅳ号肉）
- 后腿骨、尾骨、叉骨等

各工序完成后，可按工艺需要：

1. 对带皮肥膘产品进行皮膘分割
2. 对各产品进行修整

**质量把控**：由各工序操作人员对上道工序转入的产品进行把关，达不到分割加工要求的，不准许流入下道工序。

### 6.2 分段

#### 分段位置

| 部位  | 分段位置                                                 |
| --- | ---------------------------------------------------- |
| 前段  | 从第5～6肋骨间（含锁骨，前后可偏差1根肋骨）对应的胸椎处垂直片猪肉中线下锯（刀），锯（割）下的前腿部位 |
| 中段  | 第5～6肋骨间与腰椎荐椎连接处之间的中间部位                               |
| 后段  | 从腰椎与荐椎连接部下锯（刀），锯（割）下的后腿部位                            |

#### 分段方式

- **六分体**：前段 + 中段 + 后段
- **八分体**：六分体 + 沿中段脊椎骨下4cm～6cm肋骨处平行脊骨锯下的大排和带骨中方

### 6.3 前段分割

#### 6.3.1 分前排、颈背肌肉

**步骤一：修整**

- 修去胸腔内的淋巴结、大血管和肥膘

**步骤二：分割前排**

- 自前段排骨与前腿肌肉中间肌膜处下刀
- 刀锋靠肩胛骨底面向前分割
- 从前段部位分割下带颈背肌肉的前排

**步骤三：分离颈背肌肉（Ⅰ号肉）**

- 用刀紧贴前排表面剔开颈背肌肉
- 再沿腓脊骨剔下颈背肌肉
- 分割出前排和颈背肌肉（Ⅰ号肉）

**步骤四：分颈骨头（可选）**

- 前排可沿锁骨用刀或锯切割为颈骨头和无颈前排

**步骤五：分前肘（可选）**

- 带皮前段可根据工艺需要，在分前排之前从肘关节处锯（切）下前肘

#### 6.3.2 扒膘

- 在前段带肘一侧最下端下刀
- 沿肌膜分开部分肥膘
- 抠住分离的肥膘部分
- 从肥膘与肌膜、肥膘和肌肉连接处下刀
- 分割出带皮肥膘或不带皮肥膘

#### 6.3.3 剔前腿骨、肩胛骨（扇骨）

**6.3.3.1 剔前腿骨**

1. 臂骨头向外，沿前腿骨走向划开骨头上方肌肉
2. 从肘关节处下刀沿尺骨和桡骨割至腕关节处
3. 沿臂骨两侧割至肩关节处分开骨头与肌肉
4. 用刀从桡骨下方插入向外割至腕关节处
5. 向内沿肘关节、臂骨割至肩关节处
6. 在肩关节处下刀分割前腿骨和肩胛骨
7. 割开筋腱，剔下前腿骨
8. 前腿骨可按带肉或不带肉方式分割

**6.3.3.2 剔肩胛骨（扇骨）**

1. 从肩关节处下刀，沿肩胛骨两侧边缘分别下刀割至月牙骨（脆骨边）处
2. 划开肌肉
3. 在肩胛骨小头部位下刀割至肩胛骨凸起处
4. 在肩胛骨两侧边缘刀口处下刀向内割至肩胛骨凸起处
5. 用手提起肩胛骨小头部位，并用力撕下肩胛骨（连同脆骨）
6. 用刀割开脆骨与肌肉，取下肩胛骨（连同脆骨）
7. 剩余肌肉为前腿肌肉（Ⅱ号肉）

**可选分割**：

- 带脆骨的带肉肩胛骨，可用刀分割为带肉扇骨和月牙骨（脆骨边）

### 6.4 中段分割

#### 6.4.1 分大排

**6.4.1.1 锯大排**

- 从脊椎骨下约4cm～6cm肋骨处
- 平行脊骨方向
- 用手持式切割设备切断肋骨

**6.4.1.2 剔大排**

- 用刀紧贴脊椎骨
- 剔下大排肌肉（Ⅲ号肉）

#### 6.4.2 分小里脊

- 沿脊骨剔下带脂里脊
- 剩余为小里脊

#### 6.4.3 剔脊骨

- 从最后一根肋骨处下刀
- 沿脊椎骨两侧剔下脊骨

#### 6.4.4 分肋排

**步骤一：锯肋排**

- 沿肋骨走向，用手持式切割设备锯分肋排

**步骤二：剔肋排**

- 用刀深入3cm左右割开肋骨与腹肋部位肉
- 一手压按肋排，压开肋骨截面处刀口
- 一手下刀紧贴肋骨平行划至肋排2/3处
- 一手拿住肋排中部提起，一手继续下刀划下肋排腩肉部分
- 呈扇弧形扒下肋排，剩余部分为五花肉

### 6.5 后段分割

#### 6.5.1 扒膘

1. 割开腿筋
2. 从后腿内侧，沿膘肉结合部扒去内侧肥膘
3. 再反转后段
4. 抓起已扒开的肥膘
5. 用刀沿外腿肉、荐臀肉表面割下外侧剩余猪皮和肥膘

#### 6.5.2 剔尾骨、叉骨

**剔尾骨**：

1. 从髋关节处叉骨一端下刀
2. 沿叉骨与尾骨结合一侧下刀分开叉骨和肌肉
3. 露出荐髋关节
4. 从荐髋关节软骨结合处下刀
5. 撬开尾骨，剔下尾骨

**剔叉骨**：

1. 用刀剔开叉骨髋关节一面的肌肉
2. 剔开软骨上的肌肉及圆孔处的筋腱
3. 分开腿骨和叉骨
4. 再剥离叉骨表面肌肉
5. 用刀划开叉骨曲线
6. 划开髋关节周围的筋腱
7. 再刮开叉骨底部关节两侧骨膜
8. 顺势剔开叉骨头
9. 手握叉骨头，用力撕下，分下叉骨

#### 6.5.3 剔后腿骨

1. 从内腿肉和股四头肌（元宝肉）肌膜连接处下刀划开
2. 露出股骨
3. 沿股骨、膝关节和胫骨划开肌肉
4. 在胫骨下刀，沿肌肉走向剥离腿弧
5. 一手提起后腿骨跗关节处
6. 一手用刀沿腓骨和腿弧肌膜结合处分割至髋关节
7. 再用刀沿髋关节剔开股骨周围肌肉
8. 抓住胫骨，用刀沿股骨周围剥开肌肉
9. 剔下后腿骨，剩余部分为后腿肌肉（Ⅳ号肉）
10. 后腿骨可按带肉或不带肉方式分割

### 6.6 皮膘分割

1. 将带皮肥膘产品的猪皮和肥膘进行分离
2. 修去猪皮、肥膘上的淤血、淋巴结、猪毛及其他杂质

### 6.7 修整

各部位产品应：

1. 按膘厚、带脂或等级要求进行修整
2. 修去产品表面的淤血、碎肉、淋巴结、骨渣、猪毛及其他杂质

## 7. 标识、包装、贮存和运输

### 7.1 标识

- 标签和标识应符合 [NY/T 3383-2020相关要求](nyt_3383_2020_packaging_labeling.md)
- 包装储运图形符号和收发货标志应分别符合 [GB/T 191-2025](gbt_191_2025_handling_marks.md)、[GB/T 6388-1986](gbt_6388_1986_shipping_marks.md)的相关要求

### 7.2 包装

1. 按品种、级别等进行包装
2. 包装应符合 [NY/T 3383-2020相关要求](nyt_3383_2020_packaging_labeling.md)
3. **包装间温度**：10℃～12℃
4. **冷却肉包装滞留时间**：不宜超过30min
5. 分割后的产品入库前进行异物检查，剔除金属等异物

### 7.3 贮存

| 类别  | 温度要求  |
| --- | ----- |
| 冷却肉 | 0℃～4℃ |
| 冷冻肉 | ≤-18℃ |

- 避免与有毒、有害、易挥发的物品混合贮存

### 7.4 运输

产品运输应符合 [GB/T 20575-2019相关要求](gbt_20575_2019_transport.md)
