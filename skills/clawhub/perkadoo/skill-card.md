## Description:

Run a fair social media or website giveaway with Perkadoo. Use when the user wants to pick giveaway winners, draw from comments, run a giveaway for a milestone or launch, or publish proof that a giveaway was fair. Draws use public drand randomness and return a results page anyone can check.

This skill is ready for commercial/non-commercial use.

## Use Case:

Giveaway organizers and creators use this skill to select winners from existing entrant lists or manage hosted giveaways, then share a public results page that documents the outcome.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The cleaned entrant names or handles are sent to Perkadoo, and giveaway results are published.

Mitigation: Share only necessary entrant information and verify the cleaned list before confirming the final draw.
