## Known Risks and Mitigations:

Risk: User-selected files passed to upload, --image, --video, --audio, --first-frame, or --last-frame leave the local machine for AI-HIVE processing.

Mitigation: Upload only media you are authorized to send to AI-HIVE and avoid sensitive or unlicensed source material.

Risk: The AI-HIVE API key may be stored in ~/.ai-hive/config.json during setup.

Mitigation: Use this storage only on trusted devices, keep file permissions restricted, and rotate or revoke the key if exposure is suspected.

Risk: Generated character, brand, product, or media details can be inaccurate or infringe rights if source facts and permissions are not checked.

Mitigation: Confirm factual inputs, usage rights, platform requirements, and final outputs before publication or commercial delivery.
