# 中国经济进展跟踪 — 完整分析框架

## 背景：S总监的经济诊断模型

### 核心问题
中国当前到底什么状态？如果不做干预未来会进入什么状态？如果要做干预，干预手段是什么？哪些行业产业有潜力爆发？未来又会进入什么状态？

### 两种可能性

#### 经济见顶（日本1990路线）
- 能发展的产业都发展了
- 能被创造的消费都已被提出并大量消费
- 只能靠外国投资输血获得"繁荣"
- 跌30年，在合适价格吃利息勉强度日，或超跌反弹

#### 假性放缓（结构性错配）
- 还有产业发展空间
- 大量资金去了产能过剩的地方（结构性产业投资错配）
- 存在巨大的新兴消费空间待激发
- 居民偶有发展停顿恐惧——新冠23年底才结束，距今仅2年
- 受中美贸易摩擦、俄乌、中东局部热战等外部环境影响

### 政策目标
```
不降低收入 + 加大消费支出 → 商品动销↑ → 收入↑ → 更多支出
→ 通胀维持2% + 经济增速维持5%+
→ 人均GDP从1.3万→3万美元
→ 社会有弹性承受30%资产缩水回撤
→ 类似美国：强科技+强消费+3%经济增速
```

### 政策工具箱（一脉相承的连续策略）
1. 保交楼、城市改造
2. 搞基建
3. 发优惠券、以旧换新、设备更新
4. 降息
5. 国企改革
6. 限制过剩产能、禁止企业降价内卷、打击外卖大战
7. 大力发展新兴产业（AI、新能源、生物医药）
8. 企业和居民减税
9. 防止居民储蓄存款外流

### 最终目的
消费存量与新产业增量两手抓。不要因AI发展太快光芒太盛而独木难支。

## AI角色的理性评估

### AI无法替代房地产的原因

| 维度 | 房地产（成功路径） | AI（当前困境） |
|------|-------------------|---------------|
| 就业乘数 | 1个建筑工人带动5个上下游 | 1个AI工程师替代N个白领 |
| 财富效应 | 人人有房=人人感觉有钱 | 只有持股者受益 |
| 消费拉动 | 装修、家电、家具连锁消费 | Token消费几乎为零 |
| 产业链深度 | 钢铁、水泥、玻璃、物流等几十行业 | GPU、服务器、光模块等少数行业 |
| 居民参与度 | 全民参与，6个钱包 | 极少数人参与 |

### AI的真实角色：新基建，不是新房地产
- 类似于1990年代的互联网基础设施
- 真正的消费增量来自AI赋能后的传统行业效率提升（AI+制造、AI+医疗、AI+教育）
- AI本身不产生大规模就业和消费
- 虚拟侧AI更多是降成本减人力，被减的人消费能力也下降
- 物理侧AI（眼镜、机器人）更多是激情消费、新奇消费，尚未到"人手一辆车"的阶段

### 靠AI破局经济下行的风险
- 预期过高、过热
- 短期投资热、基础设施、硬件购买热
- 最终要看能否盘活大面积市场经济（如同房地产盘活上下游和居民基础生活）
- 新能源、生物医药更加专门，缺乏影响全局的性质

## 产业潜力矩阵

两个维度：X轴=**影响广度**（对就业+消费的拉动面），Y轴=**产业确定性/规模**。

| 确定性/规模 ↓ \ 影响广度 → | 窄（少数人受益） | 宽（广泛就业+消费） |
|------|------|------|
| **高（已落地/规模化）** | 半导体设备、存储芯片、CPO/PCB、算力租赁 | 新能源汽车、高端制造 |
| **中（放量中/趋势明确）** | 生物医药、AI大模型、新材料、人形机器人 | （暂缺——无产业同时满足高确定+宽影响） |
| **低（远期/不确定）** | 核聚变、太空光伏、商业航天 | — |

结论：目前没有任何新兴产业能达到房地产的乘数效应。新能源车最接近但已进入存量竞争。右上角（高确定+宽影响）仍是空白区——这正是经济破局的核心缺口。

## 924行情的启示

924政策组合拳同时触及了消费存量和新产业增量：
- 降准降息 → 流动性
- 房贷利率下调 → 居民减负 → 释放消费
- 资本市场提振 → 财富效应
- 产业政策 → 科技/新能源

教训：信心可以一把火点起来，但基本面修复需要漫长时间。

## 传导链断裂点

政策的传导链「资金→企业→就业→收入→消费」在中间环节断裂：
- AI/半导体的钱→少数高技能人群
- 基建的钱→短期就业难持续
- 中小企业的钱不足→最广大就业群体未受益

核心矛盾：AI热替代了消费热，投资拉动了GDP但没拉动就业。

## 干预路径推演

### 干预（当前路径）
消费存量盘活 + 新产业增量 → 软着陆至4-5%增速 → 通胀回到2% → 人均GDP 1.3万→3万 → 社会有弹性 → 类似美国状态

### 半干预（只投AI忽略消费）
K型分化加剧 → AI万亿 vs 普通人降薪 → 社会矛盾积累

### 不干预
通缩螺旋自我强化 → 日本化：失去的30年 → CPI持续低位/转负 → 年轻人躺平 → 消费持续萎缩
