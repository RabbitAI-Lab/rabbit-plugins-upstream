## Known Risks and Mitigations: <br>
Risk: The skill guides agents to install and use a third-party inference.sh CLI and service. <br>
Mitigation: Install only when the user trusts inference.sh, prefer manual installation or checksum verification, and use the intended account. <br>
Risk: Prompts, image URLs, uploaded images, and generated outputs may be sent to third-party model providers and may affect quotas or billing. <br>
Mitigation: Avoid confidential prompts, private images, secrets, internal URLs, or regulated data unless the user accepts the provider's data handling and cost impact. <br>
