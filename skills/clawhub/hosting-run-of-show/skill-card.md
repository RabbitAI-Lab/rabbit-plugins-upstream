## Description:

Produce practical hosting timelines, guest information and day-of run sheets for dinners, parties and holiday events. Use for whole-event coordination, not just recipes or gift shopping.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jjjhenriksen](https://clawhub.ai/user/jjjhenriksen)

### License/Terms of Use:

MIT

## Use Case:

Hosts and event organizers use this skill to turn an event brief into a practical timeline, budget forecast, guest information, or day-of run sheet. It helps coordinate logistics while keeping confirmed facts, open decisions, and approved guest details clear.
