## Known Risks and Mitigations: <br>
Risk: API keys, prompts, source image URLs, callback URLs, generated image URLs, and task IDs may be exposed if copied into browser code, logs, screenshots, public repositories, or chat output. <br>
Mitigation: Keep APIDOT_API_KEY and workflow data in a server-side environment or secret manager, avoid logging sensitive values, and make live API calls only from infrastructure the user controls. <br>
Risk: Model-specific request fields, availability, limits, and commercial terms can be incorrect if inferred from another model or stale documentation. <br>
Mitigation: Use the current APIDot model page, API docs, quickstart, webhook docs, and examples before preparing payloads or making production decisions. <br>
