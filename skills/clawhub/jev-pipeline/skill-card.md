## Description:

Helps developers identify decision-shaped LLM calls, design typed Jev questions, and calibrate thresholds and escalation paths.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vicfei](https://clawhub.ai/user/vicfei)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to find suitable Jev decision tasks in code, draft and lint typed questions, and plan thresholds and human or model escalation from logged responses.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Optional installation and tool synchronization fetch code from GitHub repositories that are not pinned to a commit.

Mitigation: Review the repositories and tool-sync behavior, pin a commit, and test in a project-local or isolated environment before using sensitive code.
