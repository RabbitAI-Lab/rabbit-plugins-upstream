## Description: <br>
Helps agent users, skill authors, maintainers, and teams produce GitHub-style workflows, checklists, analyses, code changes, and verification notes for bug fixing, setup hardening, reliability improvements, and adjacent skill creation. <br>

This skill is ready for commercial/non-commercial use. <br>
