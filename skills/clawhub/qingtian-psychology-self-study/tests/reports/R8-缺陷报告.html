D39 · 多维度量表计分失败P1 生产阻塞
位置：assessment/scripts/scoring_engine.py score() · 与 SKILL.md §6 文档约定冲突

现象：计分引擎按 item_id 匹配作答键，而 SKILL.md §6 与 score_and_report.py 文档均要求 LLM 产出 {"q1":0,"q2":1,…}（按 items 顺序的位置键）。两者仅在 PHQ-9（恰好用 q1..q9 作 item id）上巧合一致；PANAS(pa1/na1)、FFMQ(ob1…)、ECR、SCL-90 等按文档作答时全部题目缺失 → 退出码 2「作答不完整」→ 计分静默失败。R1–R7 的 e2e 仅测了 PHQ-9，此盲区从未暴露（占 19 个量表中 18 个）。

修复：新增 _normalize_answers()，把 q<n> 位置键映射到第 n 个 item 的 id，item_id 键原样透传。文档约定的 q1..qn 格式对所有量表均可计分；SKILL.md §6 无需改动即与引擎一致。实证：PANAS q1..q20 修复前 exit=2 / 0 分，修复后 exit=0、0 缺失。
