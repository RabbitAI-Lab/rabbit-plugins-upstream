# TPR 练习个案报告 · CBT（认知行为）
- 时间：2026-08-10
- 流派：CBT
- 用户角色：来访者（社交焦虑情境）
- 练习轮次：6 轮

## 逐轮要点
1. 共情反映："你刚才说在会议上发言会心跳加速，这听起来挺让人紧张的。"
2. 识别自动思维："在你准备发言的那一刻，脑子里闪过的是什么？"
3. 认知重构：引导区分『事实』与『推测』。
4. 行为实验布置：下次会前先写下一个可验证的小预测。

## 教练观察（给练习者）
- 亮点：共情反映自然，提问开放。
- 待改进：第 3 轮有点急着给建议，可多用『你怎么看』回抛。
