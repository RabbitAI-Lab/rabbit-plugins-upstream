# 新手引导（首次使用必读）

> 本文件是 TPR 心理咨询练习器的快速入门指南，供首次使用或不确定从哪个流派开始的学习者参考。由 `SKILL.md` 在首次使用/需要新手引导时按需加载。

如果你是第一次使用 TPR 心理咨询练习器，不知道从哪个流派开始，以下是快速入门指南。

## 1. 快速体验模式

如果你不想纠结选择，可以直接说"**帮我推荐**"，AI 将根据你的情况推荐1-2个适合的流派，你从中选择一个开始。体验结束后自动生成个案报告。你可以在体验过程中随时说"换一个流派"。

## 2. 按你的状态选择流派

| 你现在的状态 | 推荐流派 | 老师 | 为什么 |
|-------------|---------|------|--------|
| "我不知道选什么，先试试看" | 人本主义疗法 | 承和 | 最温和、最不具侵入性，适合初次体验 |
| "我想学习具体的咨询技术" | 认知行为疗法（CBT） | 明思 | 技术清晰、结构化，最容易理解和学习 |
| "我最近压力大、焦虑" | 森田疗法 / ACT | 随然 / 允恒 | 不跟焦虑对抗，学习带焦虑生活 |
| "我有些情绪问题想处理" | 情绪聚焦疗法（EFT） | 情绎 | 以情绪为切入点，深入理解情绪模式 |
| "我对人际关系有困扰" | 系统式家庭治疗 / 精神动力学 | 观局 / 溯宁 | 从关系视角理解问题 |
| "我想探索自我、理解自己" | 精神动力学 / 格式塔 | 溯宁 / 觉今 | 深度探索内在世界 |
| "我有明确的目标想达成" | 焦点解决短期疗法（SFBT） | 望舒 | 快速、聚焦、目标导向 |
| "我内心很矛盾，难以抉择" | 动机性访谈（MI） | 导心 | 帮你说出内心的矛盾，找到改变动力 |
| "我只是想有人听我说" | 倾听陪伴 | 知安 | 不分析、不建议，纯倾听和陪伴 |
| "我想体验不同流派对比" | 任意两种流派切换 | 任意 | 说"换XX流派"即可切换，对比体验 |

## 3. 按流派"难度"选择

| 难度 | 流派 | 特点 |
|------|------|------|
| 🟢 入门友好 | 人本主义、倾听陪伴、SFBT | 对话节奏自然，不需要专业知识也能体验 |
| 🟡 中等深度 | CBT、森田疗法、叙事疗法、MI、MBCT | 有清晰的技术框架，需要一定认知参与 |
| 🔴 深度探索 | 精神动力学、格式塔、EFT、IFS、ACT、DBT | 涉及深层情绪或内在系统，体验较深 |
| 🔴 专业视角 | 系统式、合作对话、开放对话 | 需要理解"关系"或"对话"的哲学视角 |

## 4. 流派学习建议

建议按以下顺序体验，逐步建立对各流派的理解：

1. **第一站**：人本主义（承和）—— 体验"无条件积极关注"是什么感觉
2. **第二站**：CBT（明思）—— 学习识别和检验自动化思维
3. **第三站**：精神动力学（溯宁）—— 体验深度探索和自由联想
4. **第四站**：自由探索 —— 选择你感兴趣的流派深入体验
