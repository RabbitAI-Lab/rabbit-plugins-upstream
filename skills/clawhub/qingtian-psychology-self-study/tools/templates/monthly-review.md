# 月度反思模板（monthly_review）

> 每月一次，回看这个月的成长、卡点与方向。照着填，5–10 分钟。

## 1. 这个月我做了什么
- 学了哪些理论 / 概念：___________
- 做了几次练习（TPR / 对话分析 / 量表）：___________
- 读了什么 / 写了多少反思：___________

## 2. 三个最有收获的瞬间
1. ___________
2. ___________
3. ___________

## 3. 最卡住的地方（1–3 个）
- ___________
- （提示：卡点往往是下一步该深挖的方向）

## 4. 数据快照（从「我的进度」抄）
- 累计学习小时：___ ｜ 练习次数：___ ｜ 阅读本数：___
- 点亮里程碑：___

## 5. 下个月的方向校准
- 想加强的方向：___________
- 想放缓 / 暂停的方向：___________
- 是否要调整配置（模式 / 水平 / 目标 / 时间）？→ 需要就说「改配置」

## 6. 重测量表（建议）
- 这个月做过的量表，建议重测一次看趋势（如 PHQ-9 / GAD-7）。
- 说「自测」即可，我会帮你出题与对比上次。
