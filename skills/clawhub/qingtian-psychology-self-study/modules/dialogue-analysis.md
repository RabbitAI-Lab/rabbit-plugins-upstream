# 模块二（附）· 对话分析框架

> 当用户粘贴一段对话（咨询练习/真实对话/日常对话）后，按此框架分析。完整提示词见 `resources/prompts/dialogue-analysis-prompt.md`。本文件是框架摘要，供 Skill 快速套用。

## 五步分析法
1. **通读感受**：整体感觉？哪里顺畅、哪里别扭？
2. **逐句标注**：每句话用了什么技术？意图？理论支撑？
3. **替代推演**：挑 3 处关键回应，给出「如果是我会怎么做」及理由。
4. **模式识别**：发现自己的语言模式/惯性（如总在给建议）。
5. **提炼原则**：1 条「下次练习要特别注意」的原则。

## 五维透镜（四维升级版，新增身体维度）
- **情绪维度**：双方情绪是什么？情绪有没有被接住？被忽视还是回避？
- **关系维度**：权力关系？谁在引导？有无阻抗/迎合？
- **认知维度**：暴露了什么自动思维/核心信念？是否识别并工作？
- **身体维度**：胸闷、心跳、紧绷——情绪的神经印记；是否注意到来访者的身体信号？
- **技术维度**：用了什么具体技术？用得对不对、时机合不合适？

## 多流派对比
同一段对话分别用 **CBT / 精神动力 / 人本** 视角各看一遍：
- CBT：聚焦自动思维与行为实验机会
- 精神动力：聚焦移情、防御、早年模式
- 人本：聚焦共情准确性与关系温度

## 分析记录模板（可让用户填）
```
来源：TPR练习 / 真实咨询 / 日常对话
主题：
转捩点（关键一句）：
做得好的 2 处：
可改进的 2 处：
最大收获：
```

## 输出结构（给用户的最终报告）
1. 先肯定做得好的 1-2 处（具体）
2. 五维透镜要点（每维 1-2 句）
3. 替代推演（3 处，含理由）
4. 一个可执行的改进练习建议
5. 提醒：分析是成长工具，不是打分

## 示例（CBT 视角简析）
> 来访者：「我总觉得同事在针对我。」
> 咨询师：「你具体注意到什么让你这么觉得？」（✅ 开放式+回到行为证据，避免共谋妄想）
> 替代：也可先做情感反映「这让你很不安全」再问证据。
> 原则：面对偏执性假设，先共情不安，再温和收集证据，不急着否定也不急着认同。

> 敏感内容（自伤/创伤）出现时，分析报告末尾附危机资源提示（见 SKILL.md 第二节）。
