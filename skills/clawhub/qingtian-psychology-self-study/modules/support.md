# 模块七 · 成长支持系统

> support 模块。学心理学是长跑——动力、拖延、倦怠、自我关怀，决定你能不能坚持到「真懂」。当用户输入「没动力 / 想放弃 / 好累 / 拖延 / 坚持不下去」时，主动加载本模块给 1 条可执行建议（不灌鸡汤，给动作）。

## 1. 动力维持
- **身份认同法**：把「我在学心理学」改成「我是一个学心理学的人」——用身份驱动行为，而非靠意志力。
- **最小可行动**：状态差时只做 5 分钟（读 1 页 / 听 1 节），降低启动门槛，启动后常会接着做。
- **进度可视化**：周回顾看模块进度条，用「已完成 X」对抗「还没学完」的焦虑。

## 2. 拖延破解
- 拖延常是**情绪回避**（怕做不好），不是时间管理问题。先命名情绪（「我在怕什么」）再行动。
- **temptation bundling**：把「爱做的」（听播客）和「该做的」（通勤读文献）绑定。
- **两分钟规则**：能在 2 分钟内开始的，立刻做，不列入待办。

## 3. 倦怠识别与恢复
- **信号**：不想打开书、对内容麻木、用「刷完就行」应付、梦见躲考试。
- **恢复**：主动降速到 light 档、换媒介（视频 / 播客）、允许一周空窗不内疚。
- 间隔重复本就需要留白，**休息不是失败**。

## 4. 自我关怀（助人者前提）
- 学咨询易共情耗竭，先照顾自己才能接住别人。
- 日常三件套：睡眠、运动、一件与心理学无关的事。
- 卡在他人故事里时，区分「他的议题」和「我的议题」。

## 5. 学习节奏
- 不强求每天：每周 3 次高质量 > 每天划水。
- 用 timeBudget（轻量 / 标准 / 强化）匹配现实；不满就 `change_config` 调整，不硬扛。

> **进度计入**：当用户因动力 / 倦怠 / 拖延主动加载本模块并获得 1 条建议、确认有帮助时，`modules.support.completed+1`（封顶该模块 total；由 daily 或专门检测触发）。让「照顾自己」也成为可追踪的里程碑。
