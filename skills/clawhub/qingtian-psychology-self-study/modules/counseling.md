# 模块二 · 咨询技能训练内容库

> 覆盖：基础咨询技术、伦理（详见 ethics.md）、TPR 调度、对话分析（详见 dialogue-analysis.md）。本文件聚焦「技术」与「如何调度练习」。

## 1. 基础咨询技术（入门必学）

### 建立咨访关系
- **共情（Empathy）**：准确感知并反馈对方的内心世界，「穿上他的鞋走一里路」。≠ 同情（怜悯）。
- **积极关注（Unconditional Positive Regard）**：不加评判地接纳来访者这个人。
- **真诚（Congruence）**：表里一致，不戴专业面具。
- **倾听**：不只听内容，听情绪、未说完的话、矛盾。

### 核心回应技术
- **开放式提问**：「那时候你是什么感受？」——拓展而非收窄。
- **封闭式提问**：「你是说从上周开始失眠？」——确认事实用。
- **情感反映**：「听起来你很失望，也有点委屈。」——把情绪命名出来。
- **释义/内容反映**：「你刚才说的是，工作压力大让你想逃避社交。」
- **复述**：简短重复关键词，表示在场。
- **面质（Confrontation）**：温和指出矛盾（「你说不在乎，但眼泪下来了」）。慎用，需关系稳固。
- **即时化（Here-and-now）**：处理当下咨访关系中的动力。

### 流派技术速查
- **CBT**：识别自动思维→检验证据→认知重构；行为实验；活动日程安排。
- **精神动力**：自由联想、移情工作、解释。
- **人本**：跟随、共情性倾听、不急于给建议。
- **叙事**：外化问题（「问题是问题，人不是问题」）、改写故事。
- **ACT**：认知解离、接纳、价值澄清、承诺行动。

## 2. TPR 调度（practice 处理器）

> **已内嵌**：TPR 心理咨询练习器已整份复制进本技能的 `practice/` 目录（17 流派疗法+人格+危机/合规/伦理文件），由 `practice/RUNBOOK.md` 统一指挥。`practice` 处理器直接读 RUNBOOK 原生运行，无需外部加载、无需用户贴回。

**流程**：
1. 读 `practice/RUNBOOK.md`；问用户想练哪个流派（默认 CBT），或展示 17 流派列表供选。
2. 读该流派的 `practice/references/therapies/<流派>.md` + `counselors/<人格>.md`，以咨询师身份逐轮回应（附 💡理论说明），每轮前做危机评估。
3. 用户说「结束练习/生成报告」→ 按 RUNBOOK 第七节生成 Markdown 个案报告，存 `<workspace>/reports/practice/`。
4. 报告生成后：`stats.practiceCount++`、`modules.counseling.completed+1`、`logs[]` 追加练习条；建议用户把对话贴回做**对话分析**（转 `analyze_dialogue`）。
5. 降级：若某流派文件缺失 → 回退通用流派知识并标注，不阻断。

> 练习次数计入 `stats.practiceCount`；后续「对话分析」篇数单独计入 `stats.analyses`。

## 3. 咨询技术的「做得好」信号
- 先接住情绪，再处理内容
- 提问服务于来访者探索，而非咨询师好奇
- 沉默被容纳，不被焦虑填满
- 关系中出现「被听懂」的瞬间

## 4. 易踩的坑（初学者）
- 过早给建议 / 说教
- 把共情变成「我理解你」（轻率）
- 用提问掩盖自己的不安
- 把流派技术当成「话术套路」生搬硬套
