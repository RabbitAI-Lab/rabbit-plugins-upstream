# 模块五 · 案例分析与实践应用内容库

> cases 模块。经典案例 + 影视分析 + 日常观察，三位一体。案例库见 `resources/case-library/`。

## 1. 案例分析框架（写报告用）
```
1. 来访者主诉与背景（去标识化）
2. 概念化：用 1-2 个流派解释维持问题的机制
3. 关键转捩点 / 治疗关系动力
4. 用了什么技术、为何有效/无效
5. 我的反思：如果是我会怎么做
```
写满 1 篇 → `modules.cases.completed+1`。

## 2. 经典案例类型（建议练的顺序）
- **焦虑个案**：社交焦虑 / 广泛性焦虑——CBT 暴露与认知重构。
- **抑郁个案**：习得性无助框架——行为激活 + 认知重构。
- **关系议题**：依恋模式——心理动力 / 情绪聚焦。
- **创伤个案**：创伤知情照护——稳定化优先，不急于暴露。
- **危机个案**：自杀风险评估——安全计划。

## 3. 影视分析指南（film-guide.md 详解）
选片原则：角色有清晰心理弧光、含可讨论的咨询/人际场景。
分析角度：
- 角色的行为是否符合某流派假设？
- 电影呈现的「治疗」是否真实（很多影视误导）？
- 哪些桥段可做「如果是真实咨询会怎样」的对照？
推荐片单：《心灵奇旅》《头脑特工队》《盗梦空间》（记忆/潜意识）、《海蒂和爷爷》（依恋/教养）、《完美音调》慎选（避免浪漫化双重关系）。

## 4. 日常观察（最低门槛的练习）
- 观察一次真实对话：谁在引导？情绪有没有被接住？
- 记录自己的自动思维并检验证据（CBT 日常版）。
- 用五维透镜看一条朋友圈争吵。
> 日常观察计入 cases 模块「日常观察」项。
