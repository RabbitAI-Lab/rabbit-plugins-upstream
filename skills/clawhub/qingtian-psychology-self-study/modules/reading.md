# 模块四 · 经典精读与学术素养内容库

> reading 模块。书单数据见 `resources/book-list.json`；此处讲「怎么读」「怎么写」。

## 1. 分级阅读路线（摘要，完整见 book-list.json）
- **兴趣探索者**：广度优先，启蒙→入门→进阶选读，重趣味性。
- **准咨询师**：理论+练习同步，重点读咨询/流派/伦理，配合 TPR。
- **考研学术**：四本教材精读（普心/发心/社心/实统）+ 论文写作训练。

## 2. 高效阅读方法
- **三层阅读法**：① 略读（目录/结论/小标题，建立骨架）② 精读（核心章，做闪卡）③ 关联读（联系已学概念画地图）。
- **主动阅读四问**：这本书回答什么问题？核心论点？证据强弱？和我已知如何关联？
- **穿插不同书**：不要一个月只啃一本，交叉读保持新鲜与联结。
- **输出倒逼输入**：每本书写 1 篇读书笔记 / 费曼讲给朋友。

## 3. 论文阅读（整合阶段起）
- **IMRaD 结构**：Introduction / Methods / Results / Discussion。
- **三步读论文**：摘要+结论 → 图表+讨论 → 全文细读方法与局限。
- **做文献笔记**：研究问题、样本、方法、关键发现、局限、可借鉴处。
- 推荐来源：PsycINFO、Google Scholar、Frontiers、Annual Review of Psychology。

## 4. 学术写作
- **APA 格式**：文内引用 (Author, Year)、参考文献悬挂缩进；中文环境可用 GB/T 7714。
- **写作即思考**：先列大纲（问题-方法-结果-意义），再填肉。
- **避免伪科学写作**：区分相关与因果、不夸大结论、注明局限。
- 费曼输出训练：把复杂概念写给「12 岁小孩」看，逻辑漏洞会暴露。

## 5. 书单与进度联动
- 读完一本书 → `stats.booksRead+1`；在 `readings[]` 记 {title, level, status, date, rating, takeaway}；
- 模块 reading.completed 随「分级书单通读 / 论文阅读 / 学术写作」三项推进。

## 6. 推荐「必读」种子书（详见 book-list.json）
- 启蒙：《蛤蟆先生去看心理医生》《也许你该找个人聊聊》《被讨厌的勇气》
- 入门：《心理学与生活》《社会性动物》《思考，快与慢》
- 进阶：《认知疗法：基础与应用》《存在主义心理治疗》《身体从未忘记》
- 学术：《这才是心理学》《改变心理学的40项研究》
- 原著：弗洛伊德《精神分析引论》、罗杰斯、弗兰克尔
