# 模块三 · 心理测评与自我探索内容库

> self_assess 处理器调用。心理量表测评系统已**整份内嵌**进本技能的 `assessment/` 目录（21 个标准量表 JSON，含 PHQ-2/GAD-2 快速筛查 + 通用计分引擎 + 报告生成器），由 `assessment/RUNBOOK.md` 统一指挥。`assess` 直接读 RUNBOOK 原生运行，无需外部加载。记录分数进 `assessments[]` 并对比趋势。

## 按阶段推荐量表
| 阶段 | 推荐量表 | 用途 |
|---|---|---|
| 启蒙 | PHQ-2/GAD-2（快速初筛）、PHQ-9（抑郁）、GAD-7（焦虑） | 建立情绪基线 |
| 流派/领域 | PSS-10（压力）、 Rosenberg 自尊 | 自我概念探索 |
| 整合 | MAAS（正念）、ECR（依恋） | 深化自我觉察 |
| 专项 | 依据方向选（如职业倦怠、睡眠质量） | 定向追踪 |

> **快速筛查约定**：用户状态模糊/时间紧张 → 先做 PHQ-2（抑郁）或 GAD-2（焦虑），各 30 秒；总分 ≥3 提示阳性 → 建议继续完成完整 PHQ-9/GAD-7。PHQ-2/GAD-2 阳性不直接判级，仅作初筛信号。

## 调度方式（见 assessment/RUNBOOK.md 完整流程）
1. 读 `assessment/RUNBOOK.md`，输出启动引导语（三要素：困扰询问+允许指定量表+非诊断声明）。
2. 按阶段推荐或确认量表（RUNBOOK 量表库共 21 个；快速筛查见上）。
3. 逐题/批量出题收集作答（选项序号 0 起），运行封装脚本：
   `python3 "<SKILL_ROOT>/assessment/scripts/score_and_report.py" <SCALE_ID> <answers.json> <workspace>/reports/assessment/`（`<SKILL_ROOT>` 为本 Skill 安装根目录，脚本内部自动定位 scales 与引擎，勿硬编码绝对路径）
4. 解析输出末行 `RESULT_JSON>>>...`，记录 `assessments[]`：{date, id, name, dimensionScores, bands, reportPath, note}。
5. 对比历史：文字描述趋势，如「PHQ-9 从 12 降到 8，下降趋势好」；crisis_flag 为真→先于分数播求助资源。
6. 测评后建议写一句「这次分数让我注意到 ______」，纳入 `stageSummary` 素材。

## 兜底题目（计分脚本或某量表缺失时）
> 当 `score_and_report.py` 运行失败、或目标量表不在 `assessment/scales/` 时，用本库题目做粗略自评，或 LLM 直接依 scale JSON 计分（正向取 `options.score`、反向按选项分值端点翻转、按 `interpretation.bands` 判级）。仍不替代专业测评。
> 仅作粗略自评，不替代专业测评。计分：0=完全不会 1=好几天 2=一半以上 3=几乎每天。

### PHQ-9（过去两周）
1. 做事时提不起劲或没有兴趣
2. 感到心情低落、沮丧或绝望
3. 入睡困难、睡不安稳或睡眠过多
4. 感觉疲倦或没有活力
5. 食欲不振或吃太多
6. 觉得自己很糟，或觉得自己很失败
7. 注意力不集中（如读报/看电视）
8. 行动/说话明显迟缓，或反之坐立不安
9. 有不如死掉或伤害自己的念头
> 计分：0-4 无/_minimal；5-9 轻度；10-14 中度；15-19 中重度；20-27 重度。**第9题>0 或总分偏高 → 触发危机提示，建议尽快就医。**

### GAD-7（过去两周，0-3 同上）
1. 感到紧张、焦虑或急切
2. 不能停止或控制担忧
3. 对各种各样的事情担忧过多
4. 很难放松下来
5. 坐立不安
6. 变得容易烦恼或急躁
7. 害怕将有可怕的事发生
> 计分：0-4 无；5-9 轻度；10-14 中度；15-21 重度。

### Rosenberg 自尊（10题，同意度 1-4）
如「我感到自己是一个有价值的人」「我对自己持肯定态度」等（5 题反向计分）。总分越高自尊越健康。

## 测评伦理提醒
- 量表是**自我探索工具**，不是诊断。
- 结果波动正常，单次分数不代表定性。
- 高分预警（尤其 PHQ-9 第9题、GAD 高分）→ 必附专业求助建议。
- 趋势比绝对值更有意义，鼓励月度复测。
