# 渐进暴露练习模板（教学版 · Systematic Desensitization）

> 由 `practice` 处理器按需引用（暴露练习为隐藏能力）。将 CBT 行为技术中的渐进暴露（系统脱敏）拆成可执行的教学练习：建立恐惧层级 → SUDS 主观痛苦评分 → 逐级想象/现实暴露 → 记录与放松。
>
> ⚠️ **安全边界（硬性，凌驾一切）**：
> 1. 本工具是**教学演示**，不替代行为治疗师的暴露疗法；不适用于创伤后应激、惊恐发作频繁、有强烈回避或自伤风险的用户。
> 2. 现实暴露**绝不**要求用户做任何现实中危险、违法或会造成人际伤害的行为；只做安全的想象暴露与生活化小步骤。
> 3. 任何一级暴露引发强烈痛苦（SUDS ≥ 8/10）或危机信号 → 立即停止，转危机/安全话术，建议专业帮助。
> 4. 暴露不是"硬扛"：每一级都配放松技术（见 `resources/crisis-resources.md` §二 情绪急救包），感到失控即回到上一级。

---

## 一、练习流程（四步）

**第 1 步 · 建立恐惧层级（0-100 SUDS 主观痛苦分）**
让用户列出与目标恐惧相关的 8-10 个场景，从几乎不引起焦虑（SUDS 10-20）到最害怕（SUDS 90-100），排序成阶梯。只收集列表，不推进。

**第 2 步 · 放松技术配对**
每个层级选定一个放松工具（4-7-8 呼吸 / 渐进肌肉放松 / 5-4-3-2-1 落地，见 crisis-resources.md §二），练习到能在 2 分钟内明显放松为止。

**第 3 步 · 逐级暴露（每次只进一级）**
从 SUDS 最低一级开始：
- 想象暴露：闭上眼睛，用第一人称描述该场景 30-60 秒；
- 暴露中每隔 20 秒问一次 SUDS 分；
- SUDS 回落至峰值的一半以下，或持续 2 分钟 → 这一级算通过，做一次放松，记录；
- 同一会话最多推进 2 级，避免过度唤起。

**第 4 步 · 记录与复盘**
每次练习后填：
- 练习日期 / 目标恐惧 / 本次到达层级（SUDS 分）/ 峰值与回落 SUDS / 使用的放松技术 / 一句话发现
- 重复同一级 2-3 次且峰值持续下降 → 进入下一级。

---

## 二、对话示例（处理器话术）

```
> 我们先用 0-100 给"想到/遇到这件事"的痛苦程度打分：0=完全平静，100=极度恐慌。
> 请列出 8-10 个与 [目标] 有关的场景，从最轻松到最害怕。
> 例：看到相关图片(15) → 听到别人讨论(30) → 自己在安全环境描述(50) → 现实中靠近(70) → 实际面对(95)。
```

**暴露中**：
```
> 闭上眼睛，想象这个场景……现在用一句话描述你看到的。
> 现在 SUDS 是多少？（等待回答）……好，保持描述，不回避。
> 如果 SUDS 超过 8（即 80+），我们先回到放松：跟我做 4-7-8 呼吸，4 秒吸，7 秒屏，8 秒呼，做 4 轮。
```

## 三、完成判定与数据

- 每次完成一级暴露并记录：`logs[]` 追加 `type:"暴露练习"`（含目标、层级、峰值 SUDS）；不单独计入模块进度（作为 practice 的辅助工具），可计入 `stats.practiceCount` 的场景由 practice 处理器判定（仅当该次暴露作为完整练习会话结束时 +1）。
- 记录存入 `progress.json` 的 `logs[]`；周回顾可回顾暴露进展。

---

## 四、何时转专业帮助

- 恐惧显著影响日常功能（不敢出门/不敢社交）超过 6 个月；
- 暴露过程中反复出现强烈惊恐、解离或创伤闪回；
- 用户有自伤/伤人想法（任何时刻）→ 立即危机处理。
以上情况建议转介精神科/心理科，本工具仅作教学演示。
