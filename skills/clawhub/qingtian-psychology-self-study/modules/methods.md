# 模块六 · 学习方法工具箱（2026 证据版）

> methods 模块。会学比拼命学更重要——你同时在「学心理学」和「用心理学方法学」。

## 12 种方法（含 2025-2026 证据）

| 方法 | 怎么做 | 证据/效果 |
|---|---|---|
| 主动回忆 | 合上书复述刚学内容 | 保留率高 50%+（ScienceDirect 2025） |
| 间隔重复 | Anki/RemNote 按遗忘曲线复习 | 保留率提升 ~200%（Cepeda 元分析；SM-20 算法 2026） |
| 交错练习 | 混着练不同流派/题型 | 成绩提升 43%（Rohrer & Taylor） |
| 双重编码 | 文字+图像/概念地图 | 回忆率提高 65% |
| 费曼输出 | 用自己的话讲给外行 | 暴露理解漏洞 |
| 概念地图 | 画概念间因果/关系网 | 结构化记忆更牢 |
| 提取练习 | 用问题自测而非重读 | 优于重读 2-3 倍 |
| 交错+测试 | 测试穿插于学习 | 迁移能力更强 |
| 精细加工 | 问「为什么」「怎么关联」 | 深度编码 |
| 元认知监控 | 学后自评「我懂了多少」 | 校准自信偏差 |
| 同伴教学 | 教别人/互讲 | 输出倒逼掌握 |
| 刻意练习 | 针对弱点集中练 20 次 | 突破平台期 |

## 效力对比（避免自我感动式学习）
- ✅ 高效：主动回忆、间隔重复、交错、测试、费曼
- ⚠️ 低效但常用：重读、高亮、划重点、长时间集中刷
- 重读+高亮给人「熟悉=掌握」的错觉，实际提取能力几乎不提升。

## 与 Skill 的结合
- 学完概念 → 问「要闪卡吗？」（生成 CSV 供 Anki）
- 每周 → 周回顾写总结（主动回忆+精细加工）
- 同伴互讲 → 费曼轮讲、互评（同伴教学）
- 每月 → 月度反思校准元认知

## 方法选用建议
- 零基础：先建立主动回忆+间隔重复习惯
- 准咨询师：加费曼+案例交错+刻意练习（针对薄弱技术）
- 考研学术：加概念地图+双重编码+元认知监控（应对大题与论文）
