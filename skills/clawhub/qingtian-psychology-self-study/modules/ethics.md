# 模块二（附）· 咨询伦理与法律（不可跳过的底线）

> 伦理不是学完技术后的附加课，而是第一天就要建立的红线。本库供 learn / 伦理问答调用。涉及诊断红线见 SKILL.md 第二节。

## 六大主题

### 1. 保密原则
- **默认保密**：来访者所说内容严格保密。
- **保密例外（必须打破保密）**：
  - 有明确自伤/自杀风险
  - 有明确伤人/危害他人风险
  - 涉及未成年的虐待/忽视
  - 法律规定的其他情形（如法庭命令）
- 教学/案例讨论中必须**去标识化**。

### 2. 知情同意
来访者有权知道：咨询目标、方法、时长、费用、保密界限、录音用途、退出权利。自学练习中也应在开始前说明「这是练习，不是真实咨询」。

### 3. 双重关系
- 避免与来访者发展治疗外的关系（朋友、商业、亲密）。
- **典型坑**：朋友请你免费做咨询 → 应拒绝并转介，因为双重关系损害客观性且边界模糊。
- 轻微双重关系难以完全避免时，需觉察、记录、必要时转介。

### 4. 胜任力边界
- 只在受训范围内工作；超出即**转介**。
- 「什么不该做」比「怎么做」更重要。
- 自学练习 ≠ 真实咨询，不可对外声称可提供帮助。

### 5. 记录保存
- 记录应客观、聚焦、去情绪化；包含日期、主题、风险评级、计划。
- 保存时长依法规/机构规定；谁有权查看需明确。
- 自学日志中敏感内容注意本地隐私。

### 6. 危机干预义务
- 识别自杀/自伤风险：直接、不回避地询问「你是否有伤害自己的念头？」
- 有风险 → 不单独处理，启动资源（热线/就医/联系人）。
- 不是「劝一劝」就结束。

## 必读法规（中国大陆）
- **《中国心理学会临床与咨询心理学工作伦理守则》**（2018 版）—— 行业核心伦理文本。
- **《精神卫生法》**：第 23 条（心理咨询人员不得从事心理治疗或精神障碍诊断治疗）、第 76 条（违规开展心理治疗的法律责任）。这两条划出「心理咨询」与「心理治疗」的法定边界。
- **《刑法》《未成年人保护法》**相关条款：虐待、伤害、未成年人保护。
- 涉及诊断的红线：详见 SKILL.md 第二节，绝不越界。

## 伦理困境思考练习（给用户）
- 「朋友哭着来找你，说想死，你怎么办？」→ 先稳定、评估风险、给资源、动员其支持系统，必要时陪其联系专业机构；同时反思双重关系。
- 「来访者送你贵重礼物」→ 通常婉拒，讨论礼物背后的关系含义。

> 任何伦理疑问，优先「保护来访者福祉 + 守住边界 + 必要时转介」。
