# 认知记录卡（Thought Diary · 认知行为练习工具）

> 由 `record` 处理器调用。把一次引发情绪的事件拆成「情境 → 自动思维 → 情绪 → 认知歪曲 → 理性回应」五栏，训练识别与修正自动化思维（源自 CBT 认知三角：想法-感受-行为）。**教学练习工具，不替代专业治疗。**

## 一、五栏模板

```
【1 情境】发生了什么事？（时间/地点/和谁/具体触发点，只写事实）
【2 自动思维】那一刻脑海里闪过的念头是什么？（原话，别修饰）
【3 情绪与强度】情绪名称 + 0-100 强度（可多个，如 愤怒 80 / 委屈 60）
【4 认知歪曲】对照下方清单，标出这属于哪种/哪些歪曲
【5 理性回应】更平衡的替代想法（证据是什么？有没有别的解释？最坏/最好/最可能？）
```

## 二、认知歪曲对照清单（ANTs）

| 歪曲 | 特征 | 例句 |
|---|---|---|
| 灾难化 | 把结果想成最坏 | "这次搞砸了，我这辈子完了" |
| 非黑即白 | 全有或全无 | "要么完美，要么一无是处" |
| 读心术 | 认定别人怎么想 | "他肯定觉得我很蠢" |
| 过度概括 | 一次失败推及全部 | "我总是搞不好这种事" |
| 贴标签 | 给自己/他人定性 | "我就是个没用的人" |
| 应该句式 | 用"应该/必须"压自己 | "我必须让所有人都满意" |
| 情绪化推理 | 感觉即事实 | "我觉得焦虑，所以一定有危险" |
| 放大/缩小 | 放大缺点缩小优点 | "我的错很大，我的对不算数" |
| 低估正性 | 把好事当巧合/不算数 | "这次成功只是运气" |
| 算命式预言 | 预判负面结果 | "下周肯定会搞砸" |

## 三、引导话术（处理器逐栏收集）

1. 先接住情绪，再问：「刚才那件事，你脑子里最先冒出的一句话是什么？」
2. 每栏只收一栏内容，收完再问下一栏；用户说"填完了/结束"即收尾。
3. **第 4 栏**：把用户的自动思维与清单比对，**让用户自己选**（脚手架而非灌输），不要替用户贴标签。
4. **第 5 栏**：用苏格拉底式提问引导：「支持这个想法的证据是什么？反对的证据呢？如果好朋友遇到同样的事，你会怎么说？」
5. 情绪强度在 1→5 栏之间重测一次（如愤怒 80 → 60），体现"想法变了，情绪会松动"。

## 四、示例（CBT 视角简析）

- 情境：给领导汇报，领导皱眉看了两次手机。
- 自动思维："他觉得我讲得一团糟，马上要否定我。"
- 情绪：焦虑 85 / 羞耻 60
- 歪曲：读心术 + 灾难化
- 理性回应："我没有证据他是不耐烦，可能是看时间或消息。就算他没听清，我也可以请他指正，汇报不等于审判。"

## 五、与进度系统联动

- 每次完成一张记录卡：`logs[]` 追加 `type:"认知记录"`（含一句话觉察）、`stats.feynmanOutputs` 不变、`modules.counseling.completed+1`（触发点「认知记录」，首次达标 +1，上限模块 total）。
- 周回顾时可建议把本周记录卡中反复出现的歪曲类型汇总，写入 `learnerProfile.recurringStuck`，用于 daily 个性化。
- 危机提醒：若第 2 栏自动思维出现自伤/自杀内容 → 立即转危机处理器（见 SKILL.md §2/§6），不继续收栏。
