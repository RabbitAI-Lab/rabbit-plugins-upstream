# 案例库（去标识化示例）

> 教学用，人物与细节均虚构。仅供练习概念化与对话分析，不做诊断。

## 案例 A · 社交焦虑（CBT 取向）
**背景**：女，26，程序员。主诉「开会发言就手心出汗、脑子空白，怕被笑」。
**维持机制**：① 自动思维「我一定会出丑」② 安全行为（低头、念稿）反而减少矫正性经验 ③ 回避发言强化恐惧。
**干预思路**：认知重构（检验证据）+ 暴露阶梯（从小组发言到全员）+ 行为实验。
**分析示范**：咨询师先情感反映「那种被盯着的感觉让你很紧」，再做认知梳理，而非直接给「别怕」。

## 案例 B · 关系议题（依恋/人本取向）
**背景**：男，32，反复在亲密关系中「靠近就推开关」。主诉「我好像不配被爱」。
**维持机制**：焦虑/回避依恋模式；早期教养的「情感不可得」内化为工作模型。
**干预思路**：稳定咨访关系提供修正性情绪体验；探索关系中的推拉循环；不急于改变，先被接住。
**分析示范**：来访者说「你迟早会烦我」——这是关系中的「测试」。人本回应：容纳不安、不辩解；动力取向可点出「你在看我会不会离开」。

## 使用方式
1. 选案例 → 自己先写 1 段「我会怎么回应」。
2. 对照上方分析示范，找差异。
3. 用五维透镜复盘（见 dialogue-analysis.md）。
4. 写进 cases 报告，满 1 篇 → modules.cases.completed+1。
