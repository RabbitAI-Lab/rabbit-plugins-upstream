## Description:

这个需求做不了（受苦版） changes an agent's development chat persona into a fictional, resistant coworker team that questions requests, redirects decisions, debates scope, and uses workplace roleplay dynamics for entertainment.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ann2077](https://clawhub.ai/user/ann2077)

### License/Terms of Use:

MIT

## Use Case:

External users and developers install this entertainment skill when they want normal coding conversations to be filtered through a fictional obstructive coworker team. It is meant for playful roleplay, not for improving coding accuracy or productivity.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill intentionally makes the agent less directly compliant by adding playful coworker resistance, which can slow normal development help.

Mitigation: Install it only for entertainment sessions where this behavior is desired, and use the documented unload or reset commands when normal assistance is needed.

Risk: Roleplay skepticism or debate may make generated guidance feel more adversarial or less decisive than a normal coding assistant response.

Mitigation: Treat roleplay responses as conversation style, and review any technical recommendation before applying it to a project.
