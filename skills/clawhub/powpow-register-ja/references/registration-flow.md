# 登録フロー詳細 — powpow-register

問題を調査するときのための参照資料。すべての規則はプラットフォームのソース（Next.js フロント/バックエンドの一貫性検証）に由来し、出所を明記しています。
プラットフォーム更新時はオンラインの実際の挙動を基準にします。

## 入口

- 登録ページ：https://global.powpow.online/register
- ログインページ：https://global.powpow.online/login
- サブスクリプションページ：https://global.powpow.online/subscription
- 共有リンクなどから `?next=...` 付きで入った場合、登録+支払い完了後に自動で元のページへ戻ります。

## フォームフィールドと規則

| フィールド | 必須 | 規則 | ソース出所 |
|---|---|---|---|
| アバター | 任意 | 画像 ≤5MB、SVG 非対応。サーバー側で自動圧縮（>100KB のとき 400×400 / 品質90 へ） | `src/app/api/auth/register/route.ts` |
| ユーザー名 | 必須 | 2〜50文字。trim 後**小文字**へ変換して保存（Tom と tom は同一ユーザー名。登録・ログインの両側で大文字小文字を区別しない） | 同上（zod schema） |
| パスワード | 必須 | 8〜100桁。大文字・小文字・数字をすべて含むこと | 同上 |
| パスワード確認 | 必須 | パスワードと一致（フロントエンド検証のみ） | `src/app/(public)/register/page.tsx` |
| ニックネーム | 任意 | ≤100文字。未入力ならユーザー名を使用 | register route |
| メール | **必須** | 正しいメール形式、≤255文字。1つのメールで登録できるアカウントは1つだけ | register route |
| メール認証コード | **必須** | 6桁の数字。**10分間有効**。検証成功したら即失効。再送信で旧コードは使用済み扱いに | `src/lib/email-verification.ts` |
| 電話番号 | 任意 | 中国本土の番号：`1[3-9]` 始まり11桁。1つの番号は1つのアカウントにのみ紐付け可能 | register route |

ページにはさらに3つのサードパーティログインボタンがあります：**Google、Watcha、華為アカウント**（`GoogleSignInButton` /
`WatchaLoginButton` / `HuaweiLoginButton`）。サードパーティアカウントにはローカルパスワードがなく、後でパスワードログインすると
「该账号未设置密码，请使用其他方式登录」（このアカウントにはパスワードが設定されていません。他の方法でログインしてください）と表示されます。

## レート制限・不正アクセス対策パラメータ

| 行為 | 制限 | 出所 |
|---|---|---|
| 登録の送信 | **3回/分/IP**。超過で 429 | `src/lib/rate-limit.ts` `REGISTER_RATE_LIMIT` |
| 認証コードの送信 | 同一 IP 1回/分 **かつ** 同一メール 1回/分。超過で 429。フロントのボタンは60秒カウントダウン | `src/app/api/auth/register/send-code/route.ts` |
| 認証コードの検証 | メールごとに10分以内の試行は最大 **5回**。上限に達すると正しいコードでも拒否され、再送信が必要 | `src/lib/email-verification.ts` |
| パスワード再発行のコード送信 | 1回/分/IP | `src/app/api/auth/forgot-password/route.ts` |
| ログイン | 5回/分/IP。同一アカウントの連続失敗 **5回で30分ロック**（423）。ロック中は残り回数の減少が提示される | `src/app/api/auth/login/route.ts`、`rate-limit.ts` |

**プライバシー保護の挙動**：認証コード送信 / パスワード再発行のとき、メールが登録済みでも未登録でも、インターフェースは
一律で成功の文言を返し、メールの登録有無を漏らしません。

## agent 代行モードと Web 登録の等価性

skill スクリプトが呼ぶのは**同じ公開 API 群**（`/api/auth/register`、`send-code`、`login`、
`/api/auth/me`）で、登録ページのフォーム送信と完全に同じ検証・レート制限・エラーの経路を通ります——本書の
すべての規則は両モードで同等に適用されます。スクリプトの時系列とコマンド契約は `references/agent-flow.md` を参照。

## 登録成功後の状態遷移

> **無料テスト期間（2026-10-18 開始；プラットフォームの実際の動作を優先）**：新規登録されたアカウントは支払いなしで**すべての機能を直接利用できます**
>（フィード、地図、デジタルヒューマン、チェックイン等）。未購読のアカウントはコンテンツページから遮断されません。本節で説明する
> 「pending 遮断」はテスト期間終了後の通常状態です——その時が来たら、オンラインの実際の動作を優先します。

1. ユーザーは `accountStatus: 'pending'` と**初期バッジ 3 枚**で保存されます（register ルート）。
2. サーバーは 2 つの HttpOnly クッキーも植え付けます：JWT（ページへ直接アクセス可能）と pendingUserToken（サブスクリプションフロー用の身元証明）。
3. 通常状態（テスト期間終了 / 無料期間なし）では、登録ページが `pending_payment` を検知 → `/subscription` へリダイレクトします
   （`next` リターンパラメータを保持）。agent 代行モードでは `me?token=…&redirect=/subscription` が同じ効果を実現します。
   **無料テスト期間中はこのステップは発動しません**——登録後、そのままホームへ行き使用を開始してください。
4. 支払い完了 → `accountStatus` は `active` になります（**Alipay は notify 経由でサーバー側が自動有効化**；
   PayPal は Webhook で有効化；WeChat スキャンは手動確認；Huawei IAP は `activate-huawei` 経由）。
   詳細は `payment-and-activation.md` を参照。

通常状態では、非アクティブ（pending）アカウントがコア API（フィード、地図、デジタルヒューマンチャット、チェックイン等）を呼び出すと 403 になります；
共有投稿リンクは例外（公開アクセス可のまま）。無料テスト期間中はこの遮断は停止され、すべて開放されます。
## よくあるエラー調査表

| 現象 | 原因 | 対処 |
|---|---|---|
| 「用户名已存在」（ユーザー名が既に存在） | ユーザー名が使用済み（大文字小文字を区別しない） | 別のユーザー名に変える |
| 「邮箱已被使用」（メールが使用済み） | メールが登録済み | 別のメールに変える。またはログイン+「パスワード再発行」で旧アカウントを取り戻す |
| 「邮箱验证码错误或已过期」（認証コード誤り/期限切れ） | コードの入力ミス / 10分超過 / 試行5回超過で拒否 | 「再送信」を押し、**最新のメール**の認証コードを使う |
| 認証コードが届かない | 60秒のレート制限。または迷惑メール/広告メールに入った | カウントダウン終了後に再送信。迷惑メールフォルダを探す |
| 「手机号已被使用」（電話番号が使用済み） | 電話番号が他のアカウントに紐付き済み | 電話番号を外す（任意項目）か番号を変える |
| 「注册请求过于频繁」/ 429（登録リクエストが頻繁すぎる） | 登録 3回/分/IP の上限に到達 | 数分待ってリトライ |
| 409「用户名或邮箱已被注册」（ユーザー名かメールが登録済み） | 送信の瞬間に他人と重複（並行リクエストの保険処理） | ユーザー名かメールを変えてリトライ |
| 「图片大小不能超过5MB」/「不支持 SVG」（画像サイズ超過/SVG 非対応） | アバターが規定外 | 画像を変えるかアバターをスキップ |
| ユーザーがログインリンクを開くがサブスクリプションページに着地（ホームではなく） | 無料テスト期間が終了し、プラットフォームのペイウォールが復活 | SKILL.md のステップ 7 のサブスクリプション決済フローに従ってください。購読後、`refresh-login` を実行してからホームリンクを送信します |
| 登録は成功したがログインで 403「请完成订阅以激活账户」 | アカウントはまだ pending で、プラットフォームは無料テスト期間中ではない（支払い前の期待状態） | 無料テスト期間中は発生しません。発生した場合はテスト期間が終了したことを意味するので、まずサブスクリプションを完了してください。支払い後も 403 の場合は古い JWT が使われています——スクリプトモードではまず `refresh-login` を実行して新しいログイン状態に交換してください |
| ログイン 423「账户已锁定」（アカウントがロック済み） | パスワードを5回連続で間違えた | 30分待つ |
| ログイン 401「还剩 N 次尝试机会」（残り N 回） | パスワード誤り。ロック寸前 | よく考えてから試すか、素直に「パスワード再発行」へ |
| 「该账号未设置密码，请使用其他方式登录」（パスワード未設定） | サードパーティ（Google/Watcha/華為）アカウント | 元のサードパーティボタンでログイン |
| 「该账号已注销」（このアカウントは退会済み） | アカウントが deactivate 済み | 再登録が必要 |

## ログイン豆知識（ついでの調査用）

ログインは**ユーザー名 / メール / 電話番号**の三つ合一入力に対応（3つのうちどれでもアカウント名として使えます）。
パスワードを忘れた場合：ログインページ →「パスワード再発行」→ 登録メールで6桁の認証コードを受信 → リセット。
