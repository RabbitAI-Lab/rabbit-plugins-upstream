# 製品画面スクリーンショット — powpow-register

実行時に必要に応じて使用します。ユーザーがバブルにイメージを持っていない、または完成品の見た目を「確認したい」という場合は、該当リンクを送ってください。

## リンクのルール

- メインリンク（raw）：`https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-0N.jpg`
- ミラー（raw が開けない場合に使用、`N` は1〜6）：`https://cdn.jsdelivr.net/gh/durenzidu/durenzidu@main/screenshots/powpow-0N.jpg`
- 画像は公開リポジトリ内にあり、そのまま送信可能です。スキルディレクトリに**ダウンロードせず**、ローカルパスも送らないこと。
- 毎回、現在の話題に関する1〜3枚だけを送ります。

## 一覧

### powpow-01.jpg — デジタルヒューマン詳細ページ

![デジタルヒューマン詳細ページ](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-01.jpg)

実在の人物 / 歴史上の人物をデジタルヒューマン化したカード：オンライン状態、所在地、人物紹介、「会話を始める」など。
**使う場面**：「登録後、地図上のデジタルヒューマンと会話できる」ことを紹介するとき。

### powpow-02.jpg — 投稿作成・編集ページ

![投稿エディターページ](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-02.jpg)

投稿 / 旅行記を書く編集画面。右下に浮かぶボタンの一群。
**使う場面**：「登録したら何ができる？」「どこで書くの？」と聞かれたとき。

### powpow-03.jpg — 地図ページ（バブル + デジタルヒューマン）

![マップページ](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-03.jpg)

公開地図の全景：場所付き投稿が「バブル」として地図上に集まり、デジタルヒューマンはアバターで実在の場所にピン留めされている。
**使う場面**：**冒頭の製品紹介で最優先する画像**——「投稿した旅行記は地図上の1つのバブルになる」。

### powpow-04.jpg — 個人ホームページ（デジタル資産）

![プロフィールページ](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-04.jpg)

ユーザー自身のページ：友達 / フォロー / フォロワー、そして「デジタル資産」——バッジ残高、マイバブル、マイデジタルヒューマン。
**使う場面**：「登録するとバッジが3つ」と言うときにバッジの表示場所を見せる。「自分の資産は？」と聞かれたとき。

### powpow-05.jpg — ストーリー進行ページ

![ストーリー進捗ページ](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-05.jpg)

プラットフォーム内のストーリー型ゲーム（例「永乐·1421」）：章の進行、バッジ獲得、ロールプレイ。
**使う場面**：「投稿以外に何ができる？」「バッジはどうやって稼ぐ？」と聞かれたとき。

### powpow-06.jpg — 投稿詳細ページ（完成例）

![投稿詳細ページ](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-06.jpg)

公開された旅行記1件：作者、場所タグ、本文、添付画像。下部にいいね / コメント / シェア / 保存。
**使う場面**：**冒頭2枚目**——「他の人が地図上であなたのバブルを開いたときに見えるのはこれ」。

## メンテナンス備考

現行の画像ライブラリに**登録ページ**と**購読ページ**のスクリーンショットはありません。今後 `durenzidu/durenzidu` リポジトリの `screenshots/` 配下に追加（例：`powpow-07.jpg` 登録ページ、`powpow-08.jpg` 購読ページ）する場合は、本ドキュメントに同形式でセクションを追加してください。SKILL.md の案内文も併せて参照できます。
