# 製品 UI スクリーンショット — powpow-register

実行時に必要に応じて使用します。ユーザーがバブルを知らない、または完成品がどんなものか「見たい」ときに、対応するスクリーンショットをそのまま送ります。

## 画像の所在

- 6枚のスクリーンショットは**スキルに同梱済み**で、`assets/screenshots/powpow-0N.jpg`（`N` は1〜6）にあります。ローカル画像ファイルとしてそのまま送るだけでOK——ネット接続不要、GitHub に届かない環境を含め、どんな環境でも使えます。
- パッケージ内のファイルが予期せず欠けた場合のみフォールバック：ホスティングコピー `https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-0N.jpg` またはミラー `https://cdn.jsdelivr.net/gh/durenzidu/durenzidu@main/screenshots/powpow-0N.jpg`（注意：中国本土からはどちらも開けないことがあります——パッケージ内ファイルを優先してください）。
- 毎回、現在の話題に関連する1〜3枚だけを送ります。

## 一覧

### powpow-01.jpg — デジタルヒューマン詳細ページ

![デジタルヒューマン詳細ページ](../assets/screenshots/powpow-01.jpg)

実在/歴史上の人物をデジタルヒューマンにした後のカード：オンライン状態、所属地点、人物紹介、「会話を始める」など。
**用途**：「登録したら地図上のデジタルヒューマンと話せる」を紹介するとき。

### powpow-02.jpg — 投稿エディタページ

![投稿エディタページ](../assets/screenshots/powpow-02.jpg)

投稿/旅行記を書く編集画面。右下にフローティングボタンのグループ。
**用途**：ユーザーが「登録したら何ができるの」「どこで書くの」と聞いたとき。

### powpow-03.jpg — 地図ページ（バブル + デジタルヒューマン）

![地図ページ](../assets/screenshots/powpow-03.jpg)

公開地図の全景：地点付きの投稿が「バブル」として地図上に集まり、デジタルヒューマンはアバターで現実の地点にピン留めされます。
**用途**：**製品を紹介するときの最初の一枚**——「あなたの書いた旅行記は地図上の一つのバブルになります」。

### powpow-04.jpg — マイページ（デジタル資産）

![マイページ](../assets/screenshots/powpow-04.jpg)

ユーザー自身のページ：フレンド/フォロー/フォロワー、そして「デジタル資産」——バッジ残高、私のバブル、私のデジタルヒューマン。
**用途**：「登録するだけでバッジ3個プレゼント」のときにバッジの居場所を見せる。ユーザーが「私の資産は何？」と聞いたとき。

### powpow-05.jpg — ストーリー進行ページ

![ストーリー進行ページ](../assets/screenshots/powpow-05.jpg)

プラットフォーム内のストーリー遊び（サンプル「永楽・1421」）：チャプター進行、バッジ獲得、ロールプレイ。
**用途**：ユーザーが「投稿の他に何が遊べるの」「バッジはどう稼ぐの」と聞いたとき。

### powpow-06.jpg — 投稿詳細ページ（完成品サンプル）

![投稿詳細ページ](../assets/screenshots/powpow-06.jpg)

投稿済みの一篇の旅行記：作者、地点タグ、本文、写真。下部でいいね/コメント/シェア/保存ができます。
**用途**：**開始時の2枚目**——「他の人が地図上であなたのバブルを開くと、これが見えます」。

## メンテナンス備考

- `assets/screenshots/` 内の画像が、パッケージとして配布される第一のコピーです。スクリーンショットを更新するときは、`assets/screenshots/` の同名ファイルを差し替えて（`powpow-0N.jpg` の命名を維持）新しいバージョンを公開します。
- 公開リポジトリ `durenzidu/durenzidu`（`screenshots/` ディレクトリ）のホスティングコピーはフォールバックのミラーとして残し、パッケージ内ファイルと同期して更新します。
- 現在のスクリーンショット一式には**登録ページ**と**サブスクページ**のスクリーンショットがありません。将来追加する場合（例：`powpow-07.jpg` 登録ページ、`powpow-08.jpg` サブスクページ）、ファイルを `assets/screenshots/` に入れて同じ書式で項を追加すればOK。SKILL.md の案内文にも併せて言及できます。
