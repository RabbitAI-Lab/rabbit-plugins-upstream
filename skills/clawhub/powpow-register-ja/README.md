# powpow-register

PowPow バブル登録アシスタント（OpenClaw 版）：新規ユーザーを「バブルって何？」から
「アカウントがアクティベーションされ、ワンクリックログインして遊び始める」まで導きます——
製品紹介（UI スクリーンショット付き）、agent による登録代行（アバターアップロード含む）、
Alipay / PayPal サブスクの発注と着金トラッキング、双リンクのワンクリックログイン、エラー調査。

**v2.0.0 以降は agent 代行モード、v2.2.0 以降はプラットフォームの無料テスト期間にも適応**：コアスクリプト `scripts/powpow-register.mjs` はゼロ依存
（Node ≥ 18）。ユーザーが会話を離れるのは一度だけ：メールで認証コードを確認するためです。現在の無料テスト期間中は、登録済みアカウントがすぐにすべての機能を利用でき——サブスクリプション決済は任意です。テスト期間が終了してユーザーがサブスクリプションページに着地した場合、フローは自動的に決済パスへ切り替わります。Node がない場合、またはユーザーが自分で行うことを望む場合は、自動的に純ガイドモードにフォールバックします。

## インストール

```
openclaw skills install @durenzidu/powpow-register
```

## 機能

1. **製品紹介**：約120字のオープニング + スキル同梱の UI スクリーンショット
   （`assets/screenshots/` に6枚：地図ページ、投稿詳細ページなど。シーンに応じて
   1〜3枚を選んで送信。外部画像ホスティング不要、オフラインで利用可能）。
2. **登録代行**：agent がユーザー名/ニックネームを積極提案、パスワードは二択
   （ユーザー提供 or agent 生成）、認証コードの送信と提出、アバター直送（≤5MB・SVG 以外）、
   よくあるエラーの自動処理（使用済み/期限切れ/レート制限）。
3. **ワンクリックログイン（デュアルリンク）**：登録成功直後に、ログインリンクでユーザーはそのままホームに着地します（無料テスト期間中はワンクリックで利用可能）；
   サブスクリプションページに着地した場合（テスト期間終了）やユーザーがアップグレードを望む場合は、サブスクリプションフローに従ってください——着金後、新しいログイン状態に交換し、完全会員リンクでホームに着地します
   （HttpOnly クッキーを自動的に植え付けるプラットフォーム公式の `me?token=` ブリッジ経由）。
   設定）。
4. **サブスク決済**：Alipay（月 ¥6.99 / 四半期 ¥19.99 /
   年 ¥69.99、一括購入で自動更新なし）も PayPal（Premium Monthly、約 $1/月、自動更新、いつでも解約可）も agent が発注と着金ポーリングを代行。
   WeChat スキャン/華為 IAP は道案内のみ。
5. **エラー調査**：認証コードが届かない、ユーザー名/メールが使用済み、403 未アクティ
   ベーション、アカウントロックなどよくある問題を、すべてプラットフォームのソースに
   基づき出所付きで解説。

## セキュリティ

- **パスワード**は環境変数経由でのみスクリプトプロセスに渡し、コマンドライン引数に書かず、
  ディスクに落とさず、状態ファイルにも入れません。agent が生成したパスワードは
  ユーザーが保存するために一度だけ表示します。
- **認証コード**は公式登録インターフェースにのみ使用し、使い捨て。状態ファイル
  （メール/ユーザー名/token/注文番号）はシステムの一時ディレクトリに保存し、フロー終了時に
  `cleanup` でワンクリック削除します。
- **決済**：agent は注文の作成、レジを開くこと、着金確認のみ。ユーザーの Alipay / PayPal アカウント
  や決済証憑には絶対に触れず、代行支払いも絶対にしません。支払いは常にユーザーと
  公式レジの間で完結します。
- すべてのリクエストは公式ドメイン `https://global.powpow.online` にのみ送信。いかなる
  鍵も含みません。
