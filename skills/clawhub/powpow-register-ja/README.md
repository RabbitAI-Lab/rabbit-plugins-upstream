# powpow-register

PowPow（バブル）登録アシスタント（OpenClaw 版）：新規ユーザーを「バブルって何？」から「アカウントがアクティベーションされて、普通に使える」まで導きます——製品紹介（画面スクリーンショット付き）、段階的な登録案内、エラー調査、購読アクティベーションの説明。

純粋なガイド型スキル：スクリプトなし、依存なし。登録の操作はすべてユーザーがブラウザ / アプリ内で行います。

## インストール

```
openclaw skills install @durenzidu/powpow-register
```

## 機能

1. **製品紹介**：約120文字のオープニング + GitHub 公開リポジトリにホストされた画面スクリーンショットのリンク（地図ページ、投稿詳細ページなど全6枚。シーンに応じて1〜3枚を選んで送信）。
2. **登録案内**：フィールドルール（ユーザー名 / パスワード / メール認証コード / 電話番号 / アバター）、サードパーティログイン（Google / Watcha / 華為）、レート制限パラメータ——すべてプラットフォームのソースコード由来で、出所を明記。
3. **エラー調査**：認証コードが届かない、ユーザー名・メールの使用済み、403 未アクティベーション、アカウントロックなど13種のよくある問題。
4. **購読アクティベーション**：PayPal（Web）/ WeChat スキャン（手動確認）/ 華為 IAP（HarmonyOS）の3チャネルの説明と調査方法。既存の決済経路をそのまま再利用でき、スキルは道案内のみ担当します。

## セキュリティ

- キーは一切含まず、スクリプトなし、ユーザーの資格情報に触れません。
- ユーザーのパスワード・認証コード・支払い情報を**決して求めません**。登録と支払いはすべてプラットフォームのページ上で完了します。
