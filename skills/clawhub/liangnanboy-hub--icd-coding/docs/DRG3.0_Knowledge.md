## 三、DRG 编码命名规则

```
DRG编码 = MDC字母 + ADRG序号 + 严重程度码
例如：BB21
       │ │ │
       │ │ └─ 严重程度：1=伴严重MCC, 3=伴一般CC, 5=不伴, 9=不适用/独立
       │ └─── ADRG 序号（在 MDC 内的顺序，从 1 开始）
       └───── MDC 字母（A-Z 标识 26 个 MDC）

ADRG 编码 = MDC字母 + ADRG序号
例如：AA1, BR2, GF4
```

### 严重程度码（最后一码）含义

| 末位码 | 含义 | 适用场景 |
|--------|------|---------|
| 1 | 伴严重合并症或并发症（MCC） | 主要诊断+严重 CC/MCC |
| 3 | 伴一般合并症或并发症（CC） | 主要诊断+一般 CC |
| 5 | 不伴合并症或并发症 | 无 CC/MCC |
| 9 | 不适用或独立分组 | 手术组、内科独立病 |

### 内外科识别

- **外科组**（含手术或操作）：以"包含以下主要手术或操作"为入组依据
- **内科组**（无手术或操作）：以"主要诊断"入组

## 四、入组流程

```
病例病案首页
    │
    ▼
1. 提取主要诊断 + 其他诊断 + 主要手术或操作 + 其他手术或操作
    │
    ▼
2. 用主要诊断查 MDC 主诊表 → 确定 MDC
    │
    ▼
3. 在该 MDC 内，按入组规则匹配 ADRG
    │
    ├─ 优先：主要手术或操作 → 外科 ADRG
    │
    ├─ 次选：主要诊断 → 内科 ADRG
    │
    └─ 兜底："诊断"或"其他诊断"匹配
    │
    ▼
4. 在 ADRG 内，根据合并症/并发症严重程度（MCC/CC/无）细分为 DRG
    │
    ▼
5. 输出 DRG 编码（如 BB21）
```

## 五、ADRG 分组明细规则的"条目类型"

`ADRG 分组明细` 表中，每个 ADRG 由以下条目类型组合：

| 条目类型 | 含义 | 组合方式 |
|---------|------|---------|
| 包含以下主要手术或操作 | 主要手术或操作编码列表 | 任一匹配即入组 |
| 包含以下主要诊断 | 主要诊断编码列表 | 任一匹配即入组 |
| 包含以下主要诊断或其他诊断 | 主诊或其他诊断任一 | 任一匹配即入组 |
| 包含以下主要手术或操作且全部手术或操作中有两个及以上 | 手术组+手术数量要求 | 组合条件 |
| 手术或操作 1/2/3 | 组合入组条件之一 | 需与对应序号的子列表组合 |
| 全部手术或操作 1-4 | 全部满足 | 全部手术或操作中需包含 |
| 主要手术或操作 1/2/3/4/5 | 主要手术或操作组合 | 组合条件 |
| 主要诊断 1/2 | 主要诊断组合 | 组合条件 |
| 其他诊断 1/2/3 | 其他诊断组合 | 组合条件 |
| 诊断 1/2 | 诊断组合 | 组合条件 |
| 主要手术或操作 | 主要手术或操作 | 主要手术或操作中匹配 |
| 其他诊断 | 其他诊断 | 其他诊断中匹配 |
| 入组条件 | 分组规则文字说明 | 用于复杂组合 |

> **实战提示**：DRG 入组是"先到先得"——主手术或操作优先于主诊断，主诊断优先于其他诊断。所以编码顺序非常关键，主要手术或操作的选择直接影响入组结果。

## 六、合并症与并发症（CC/MCC）体系

| 类别 | 数量 | 用途 |
|------|------|------|
| MCC（严重合并症） | 1,581 | 触发末位 1（伴严重） |
| CC（一般合并症） | 6,337 | 触发末位 3（伴一般） |
| CC 排除列表 | 21,043 | 排除与主诊同类/相关的诊断 |

### 排除规则

当合并症诊断与主要诊断属于同一系统/类别时，**不计入 CC**（避免重复计费）。例如：
- 主要诊断 "J18.9 肺炎" + 其他诊断 "J44.1 慢阻肺急性加重" → 不算 CC（均属呼吸）
- 主要诊断 "I63.4 脑梗死" + 其他诊断 "I10 高血压" → 算 CC

> 排除规则明细见 `data/drg3.0_excl_dx.json`

## 十、特殊 DRG（DRG9/DRG0）

- **DRG9（自身疾病）**：当主要诊断为非疾病诊断（如 Z 码健康查体）或与本次住院无关时，归入 DRG9（不计入分组），通常按项目付费。
- **DRG0（错误 DRG）**：病案信息不全、主要手术或操作缺失、主要诊断缺失等异常情况。

## 十一、查询指令（DRG 3.0 版）

```
DRG3.0查MDC <诊断编码>           → 所属 MDC（例：DRG3.0查MDC I63.4）
DRG3.0查ADRG <ICD编码>           → 可能的 ADRG 列表（例：DRG3.0查ADRG 33.5000）
DRG3.0查DRG <DRG编码>            → DRG 名称、CC/MCC 标识（例：DRG3.0查DRG BB21）
DRG3.0基层病组 <疾病名/编码>      → 是否为 31 基层病组之一
DRG3.0对比2.0 <ADRG编码>         → 2.0 ↔ 3.0 编码/名称变化
DRG3.0是MCC <诊断编码>            → 是否为严重合并症
DRG3.0是CC <诊断编码>             → 是否为一般合并症
DRG3.0高危妊娠 <诊断编码>         → 是否高危妊娠
```

> 命令前缀 `DRG3.0` 用于与 2.0 命令 `DRG` 区分。过渡期（2026-9 ~ 2027-3）建议同时支持两套命令。
