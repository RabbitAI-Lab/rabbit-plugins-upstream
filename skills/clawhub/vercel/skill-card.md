## Known Risks and Mitigations: <br>
Risk: Vercel CLI commands proposed by the skill can affect production deployments, projects, domains, aliases, logs, and environment variables. <br>
Mitigation: Before approving commands, verify the active Vercel account, team, project, environment, and exact command target. <br>
Risk: Commands using tokens or --yes can expose credentials or bypass interactive confirmation. <br>
Mitigation: Review token handling and avoid automatic confirmation unless the command scope and target are explicitly intended. <br>
