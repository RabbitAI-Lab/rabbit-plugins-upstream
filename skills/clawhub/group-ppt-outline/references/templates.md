# 小组汇报 PPT 大纲 · 详细模板

按场景复制填写。页码、成员名、时长按实际替换。

**默认流程：** 填完下列文字方案后，按 [pptx-generation.md](pptx-generation.md) **立刻生成 `.pptx`**，不要等用户再要文件。

---

## 通用完整清单（默认）

```markdown
# 〔主题〕PPT 大纲 · N 人 · X 分钟

## 分工总表
| 成员 | 板块 | 页码 | 时长 |
|------|------|------|------|
| 成员A | | P01–P0? | ~? min |
| 成员B | | | |
| 成员C | | | |

## 页面清单

### P01 封面
- **幻灯片：** 主题名；副标题（课程/小组名）；成员姓名；日期
- **配图建议：** 与主题相关的一张主视觉（避免杂乱拼贴）
- **负责人：** 成员A（开场）
- **讲稿要点（20–30s）：** 问候 → 主题一句话 → 介绍成员分工顺序

### P02 目录 / 汇报结构
- **幻灯片：** 3–5 个板块标题（可标负责人）
- **配图建议：** 横向流程或编号列表
- **负责人：** 成员A
- **讲稿要点：** 今天分几部分、各谁讲、总时长

### P03 …（内容页按场景展开）

### P最后 致谢 / Q&A
- **幻灯片：** Thanks / 欢迎提问；联系方式（可选）
- **配图建议：** 简洁留白
- **负责人：** 最后一位 或 组长
- **讲稿要点：** 总结一句 → 感谢 → 请老师提问
```

## 场景：课程汇报（如电商用户分析 · 10 分钟 · 3 人）

建议 **10–11 页**：

| 页 | 标题 | 建议负责人 |
|----|------|------------|
| P01 | 封面 | A |
| P02 | 目录与分工 | A |
| P03 | 背景与问题 | A |
| P04 | 数据/用户概况 | B |
| P05 | 分析方法 | B |
| P06 | 关键发现 1 | B |
| P07 | 关键发现 2 | C |
| P08 | 结论与建议 | C |
| P09 | 局限与展望（可选） | C |
| P10 | 致谢与提问 | C |

单页内容页写法示例：

```markdown
### P06 关键发现：用户分层与转化
- **幻灯片核心内容：**
  - 发现一：（待填：指标 + 结论短句）
  - 发现二：
  - 对业务的含义：一句话
- **配图建议：** 漏斗图 或 分组柱状图（转化率对比）
- **负责人：** 成员B
- **讲稿要点（45–50s）：**
  - 先指图说明比的是什么
  - 说出 1 个反直觉点
  - 用一句过渡交给下一部分
```

## 场景：毕设中期答辩（15 分钟 · 四大板块）

必须覆盖：**研究现状、实验、问题、计划**。建议结构：

| 页 | 标题 | 板块 |
|----|------|------|
| P01 | 封面（题目、姓名、导师、日期） | — |
| P02 | 汇报提纲 | — |
| P03 | 选题背景与研究目标 | 引入 |
| P04–P05 | 研究现状 / 相关工作 | **研究现状** |
| P06–P08 | 已完成工作、实验设计、阶段性结果 | **实验** |
| P09 | 当前问题、风险与不足 | **问题** |
| P10–P11 | 下一步计划、时间表、预期成果 | **计划** |
| P12 | 致谢 | — |

论述页讲稿要点偏「做了什么 → 证据 → 还缺什么」，避免空谈意义。

```markdown
### P09 当前问题与风险
- **幻灯片核心内容：**
  - 问题1（技术/数据/进度）
  - 问题2
  - 已尝试的应对（若有）
- **配图建议：** 风险矩阵（影响×可能性）或问题列表
- **讲稿要点：** 坦诚问题 → 不甩锅 → 立刻衔接到计划页
```

单人答辩：分工表改为「本人 · 全页」；若只要框架不写多人，省略成员列。

## 场景：市场调研 · 固定 8 页

```markdown
### P01 封面
### P02 调研目的与问题
### P03 对象、抽样与方法
### P04 样本概况（待填数据）
### P05 核心发现（一）
### P06 核心发现（二）/ 交叉分析
### P07 洞察与建议
### P08 分工说明 + 致谢
```

每页仍含：核心内容、配图建议、负责人、核心发言要点（可更短）。

## 讲稿要点写法对照

| 避免 | 推荐 |
|------|------|
| 把幻灯片句子再念一遍 | 补充「为什么重要 / 请看这张图」 |
| 超过 120 字的段落 | 3–6 条口语关键词 |
| 「然后我们看下一页」无信息 | 用结论句过渡：「因此下一步要解决的是…」 |

## 配图建议速查

| 内容类型 | 优先视觉 |
|----------|----------|
| 对比 | 柱状/条形图 |
| 流程 | 横向步骤图 |
| 结构占比 | 饼/环（类别≤5） |
| 关系 | 简单关系图 |
| 现状文献 | 表格或时间线 |
| 计划 | 甘特/里程碑 |
| 封面 | 单主视觉，少文字 |
