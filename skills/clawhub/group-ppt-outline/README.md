# group-ppt-outline · 小组汇报 PPT 大纲生成

输入汇报主题、时长、人数分工，自动生成完整 PPT 页面框架，分配每人汇报内容，每页配套核心讲稿要点；**默认在方案后直接导出可打开的 `.pptx`**。

## 使用效果

输入汇报主题、时长、人数，输出标准化 PPT 完整页面清单，明确每页标题、核心内容、配图建议；同步拆分每人负责板块，配套每页简短口述讲稿；并默认生成可复制打开的 PPT 文件（备注栏含讲稿）。

## 默认行为

1. 先出文字方案（分工 + 每页大纲）
2. 同一轮用 `python-pptx` 生成桌面 `.pptx`
3. 仅当用户说「只要大纲」时跳过文件

生成细则见 `references/pptx-generation.md`。

## 提示词示例

1. 小组课程汇报主题为电商用户分析，10 分钟 3 人分工，生成完整 PPT 每页大纲和对应讲稿。
2. 毕设中期答辩 PPT 框架，15 分钟汇报，拆分研究现状、实验、问题、计划四大板块。
3. 市场调研小组作业，生成 8 页 PPT 目录，分配每人负责板块，每页标注核心发言要点。
