# 第3章 丢失的时间

天亮的时候，我醒了。

不记得怎么睡着的。

也不记得自己是怎么从那个客厅走回来的。

但我在床上。被子盖得好好的。手机在床头柜上，电量百分之七十三。

衣柜关着。

我坐起来。脚踩在地板上。凉的。

衣柜——我看了它很久——就是柜子。木头。衣服。什么都没有。

我去刷牙。

镜子里的人是我。眼睛有点肿。头发乱的。嘴巴里一股苦味。

我吐掉泡沫，拧开水龙头，捧水洗脸。水凉。拍在脸上能感觉到皮肤是热的。

我是活的。

我是正常的。

我要正常。

我热了牛奶。烤了两片面包。坐在餐桌前吃早饭。

窗户开着。楼下有人在说话。菜市场的喇叭声隔了几条街传过来。手机屏幕亮了一下——工作群的消息。

都正常。都对。

我打开电脑。

屏幕亮了。

桌面上多了一个文件。

我盯着它看了大概十秒。

文件名是今天的日期。`0728.ai`。

我没有创建这个文件。

我前天做的设计稿在另一个文件夹里。我昨天——昨天我没开电脑。我记得。我前天熬夜熬太晚了，昨天白天整个人都是昏的，晚上又——

晚上又发生了那些事。

我没开过电脑。

但我还是双击了。

文件打开了。是AI的工程文件，图层命名规范，跟我平时干活一样的习惯。画布上是一张海报设计。黑底。中间一行白色的字，字体是我常用的思源黑体。

「你睡得好吗？」

就这四个字。

我往下翻。下面还有一层——一行小字，几乎看不见：

「我不太习惯你的身体。」

我关掉文件。

心跳快了。我的手放在鼠标上，没动。

我重新打开。

四字还在。小字还在。

我检查创建时间——昨天下午两点十七分。

昨天下午两点十七分。

我努力回忆昨天下午两点十七分我在干什么。

空白。

就像一段磁带被洗掉了。我知道那个时间段存在，但里面没有任何内容。我坐在哪里？穿了什么？吃了什么？在想什么？什么都没有。

我关掉电脑。站起来。呼吸有点浅。

出门。

我要出门。

楼道里的灯亮了。

这是我第一次注意到这楼的灯其实是能亮的。以前它永远是坏的，暗的，伸手不见五指。今天它亮了。惨白的日光灯，照得墙上的灰都看得清清楚楚。

我下楼。

五楼。四楼。三楼。脚步声在楼道里弹来弹去。

楼下501的门开着半扇。

老周坐在门口的小板凳上择菜。抬头看见我，手上的动作停了。

就停了那么一拍。

像是看见了一个他没想到会看见的人。

「周叔。」我说。

「哎。」他说。声音有点慢。「小枫啊。」

「买菜呢？」

「嗯。」他低下头继续择菜，又抬起来看了我一眼。

那个眼神不对。

不是恶意的。是说不上来的。像看一个好久没见的人。

「你这几天——」他说了一半，停住了。摇摇头。「没事。挺好的就行。」

「我这几天怎么了？」

「没怎么。就——」他摆摆手，「算了算了，没事。」

他没看我第二次。

我走到三楼拐角，碰到林姐拎着垃圾袋从301出来。

「小枫！」她先叫我。

「林姐。」

「哎哟你这几天去哪了？」她上下打量我，语气是关心，但眼底有一点不确认的东西，「前天晚上我敲门给你送腌萝卜，没人应。我还以为你出远门了。」

「我一直在啊。」

「那可能是我敲错门了。」林姐说。

但她笑了一下。

那个笑——不是「我搞错了不好意思」的笑。是「算了我不戳穿你了」的笑。

她觉得自己没敲错。

「前天晚上是几点？」我问。

「大概九点多吧。你楼下灯也不亮，我还站了一会儿。」

九点多。前天晚上九点多。

我不记得前天晚上任何事。

「小枫？」林姐伸手在我面前晃了晃，「想什么呢？」

「没什么。可能我在洗澡吧。」

「哦——那有可能。」她点点头，拎着垃圾袋走了。

走了两步，回头又看了我一眼。

那一眼跟老周的眼神一样。

我站在楼道里，手扶着栏杆，指节发白。

我去了四楼。

402。

那扇门。

我站了大概两分钟。敲门。没人应。再敲。没人应。

但我注意到的不是没人应——是门口没有外卖。

这是我这辈子第一次看见402门口没有外卖盒。

干净的。干干净净。没有塑料袋，没有油渍，没有筷子。连灰都没有。像是从来没有人住过。

我弯腰看门缝。没有光。什么都看不见。

我又敲了一次。

咚。咚。咚。

跟那天晚上衣柜后面的声音一样。

没人应。

我退了一步。又退了一步。转身走了。

回到家。关门。锁上。

我看着衣柜。

柜门关着的。但我知道它后面是什么。

我走过去。拉开柜门。衣服挤在一起。手伸进去拨开——手指碰到了木头的边缘。

门。

我还是推开它了。

走廊还在。

跟我家一样的墙纸，一样的灯光，一样的地板。只是更安静。安静得耳朵发嗡。

我走进去。走到尽头。那扇门虚掩着。上一次它也是这样——

我推开。

客厅。跟我家一模一样的客厅。

但没有人。

另一个王枫不在。

沙发空着。茶几上——我上次来的时候上面是空的。这次有一个杯子。玻璃杯。里面有水。

我伸手摸了一下杯壁。温的。

小半杯水。还冒着热气。

她刚刚还在。

我站在那个客厅里。听自己的呼吸。没有别的声音。

我开始翻东西。

抽屉——跟我家一模一样的抽屉。筷子、勺子、开瓶器。位置都一样。

第二个抽屉——文件、笔记本、笔。

我打开笔记本。空的。一页都没写过。

第三个抽屉——照片。

一张合照。我和陈屿。

我不记得拍过这张照片。

照片里我穿了件蓝色的衬衫——那件衬衫我确实有。陈屿穿了件白T恤。他揽着我的肩膀，我靠在他身上笑。两个人看起来很好。

背景是一个饭馆。有红灯笼。我不记得去过这个饭馆。

翻过来看背面。

有人写了一行字。

黑色的笔迹。是我的字。

「别忘了我。」

我盯着那行字看了很久。是我的字。就是我的字。我写「的」字习惯把左边那一撇拖得很长。这行字就是这样写的。

但我没写过这行字。

我也没拍过这张照片。

我把照片揣进口袋。走出来。穿过走廊。推开自己家的柜门。回到自己家。

我把两张照片并排放在茶几上。

我家里的那张。和那个公寓里的那张。

一模一样的照片。

同一件蓝衬衫。同一个红灯笼。同样的笑容。

我翻过来。

我家里的那张——背面什么都没有。

另一张——背面有「别忘了我。」

时间戳一样。2026年4月17日。

四个月前。

我和陈屿半年前分手了。一月。我记得。一月中旬。具体日期记不清了，但肯定是分手了。

可这张照片是四月拍的。

如果四月我们还在一起拍照——那三月呢？二月呢？

我不记得。

那些月份变成了一片空白。

我不知道陈屿还是不是我男朋友。

我不知道自己是昨晚开始不对劲的，还是已经不对劲很久了。

我坐在沙发上。看着两张照片。一模一样的照片。一张有字，一张没有。

房间好像变冷了。

我拿起手机。打开微信。

然后我看到聊天记录。

昨天——凌晨三点十七分——我给陈屿发了一条消息。

「在吗？想你了。」

我不记得发过这条消息。

我不记得。三点十七分。那个时候我在床上吗？我在衣柜边上吗？我在那个走廊里吗？我根本不知道。

陈屿回了。时间是昨天早上七点四十二分：

「你终于理我了。」

五个字。

「你终于理我了。」

好像是我把他拉黑了。好像是我一直在躲他。好像这半年来是他一直在等我。

聊天记录往上翻。再往上翻。之前的消息——上一次我主动找他是半年前。分手那几天。

再之后全是他的消息。

「你还好吗？」

「王枫，你回我一下。」

「能不能当面说清楚？」

「我知道你在。」

「我错了行不行？」

每隔几天一条。没断过。我一条没回。

直到昨天凌晨三点十七分。

「在吗？想你了。」

这不是我发的。

但确实是从我的手机发的。

发送者的头像是我。名字是我。绿色气泡。已读。都对的。

我盯着屏幕。手指悬在屏幕上。

然后手机震了。

屏幕跳转——来电显示：陈屿。

手机在手里震。嗡嗡嗡。

我看着那两个字。

陈屿。

我接吗？

我不知道这张照片是怎么回事。

我不知道那条消息是怎么回事。

我不知道那个杯子里的水是谁喝的。

我不知道此刻的我——拿着手机的我——还是不是我。

手机震了第二下。

我接了。

（未完待续）
