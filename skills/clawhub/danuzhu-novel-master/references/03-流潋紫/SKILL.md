# 流潋紫风格参考

流潋紫写的不是「争宠」，是权力本身。她的风格核心：

- **女人之间的博弈是最高级的智力竞技。** 表面言笑晏晏，底下刀光剑影。一句话可以救人也可以杀人。
- **每一步都有代价。** 女主赢了——但代价是什么？每一次胜利都是咬着牙换来的。
- **没有绝对的好人坏人。** 在极端环境里，每个人都在求生存。能被理解，但不一定能被原谅。
- **反转要狠，铺垫要深。** 每一个反转往回看，伏笔都在前面埋好了。读者恍然大悟不是「怎么可能」——是「原来那个细节是这个意思」。

**参考要点：** 权力结构要清晰。女主的对手要有分量——碾压蠢货不好看。因果链条要严密，不能为了推进剧情让人物做不合理的事。
