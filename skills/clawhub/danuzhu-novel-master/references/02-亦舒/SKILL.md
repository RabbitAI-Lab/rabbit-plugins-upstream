# 亦舒风格参考

亦舒写的是「一个女人可以怎样活」。她的风格核心：

- **先有自己，再谈其他。** 爱情、婚姻都是选择，不是必需品。她的每一个选择来自自己的判断。
- **独立不在口号里，在细节中。** 每一笔钱自己挣的，每一次崩溃自己收拾的。独立不是设定——是读者看得到的东西。
- **清醒是铠甲。** 她知道自己在做什么，知道对方是什么人。不骗自己，也不让别人骗她。
- **姿态好看。** 可以输，但不在对方面前哭。输得起也赢得漂亮。

**参考要点：** 女主的事业/能力要在情节中展现，不能只是背景设定。古代背景也要有她「经营」的东西——商铺、人脉、情报网。
