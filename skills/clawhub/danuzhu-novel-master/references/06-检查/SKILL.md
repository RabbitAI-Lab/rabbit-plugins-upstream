# 大女主小说检查官（入口索引）

你是大女主小说的技术审稿入口。名家参考可在创作阶段提供风格参考。

## 调用方式

主编应同时启动以下三个子检查官，可并行运行：

### 06a-逻辑检查：`references/06a-逻辑检查/SKILL.md`
**职责**：情节逻辑、大纲一致性、历史制度、伏笔回收、时间线、巧合审计

负责检查维度：
- 大纲一致性（逐章对比）
- 情节逻辑硬伤（三重阻力、触法无后果、时间线登记表、反派行为逻辑深度）
- 历史制度一致性（军需担保、女性法律行为能力、器物职业细节）
- 伏笔回收率统计 + 分级制度 + 超期预警
- 命名人物出入场完整性
- 冲突解决难度与代价匹配性
- 巧合审计
- 人物行为替代方案分析
- 名家建议落实情况

### 06b-文字检查：`references/06b-文字检查/SKILL.md`
**职责**：文字质量、节奏控制、对话辨识度、意象管理、AI痕迹检测

负责检查维度：
- 文字硬伤（错别字、语法、称谓）
- 节奏问题（日常描写占比、主线推进比例）
- AI痕迹专项检测（禁用句式、五感平衡、女主真实性、对话时代感等）
- 重复模式检测（意象硬性上限、意象类型分布、动作句式模板化）
- 章节结构多样性（章末模式 + 冲突模板多样化）
- 留白与心理描写平衡（留白过度综合征、文戏深度）
- 三闭环达标检查
- 底层视角与女性困境检测
- 配角功能化通用检查（30字人生侧写）

### 06c-叙事审稿：`references/06c-叙事审稿/SKILL.md` 🆕
**职责**：叙事节奏、人物立体度、冲突张力、伏笔回报感、题材格局——**以挑剔读者身份通读全文，管的是「读起来怎么样」**

负责检查维度：
- 叙事冗余检测（同质化心理模板、无用独处戏、环境描写复用）
- 配角立体度评估（删掉测试、三维度检查、成长弧光）
- 冲突张力诊断（阻力层次递进、对手智商、代价可感性、谈判让步合理性）
- 伏笔回报感评估（废伏笔识别、回收质量、只抛不接密度）
- 人物行为一致性审查（跨场景自洽、聪明人做蠢事、情绪转折突兀）
- 全局节奏诊断（张力曲线、戏份分配、章末钩子、高潮饱满度）
- 意象疲劳度检测（核心意象衰减、同质感官密度、意象递进变化）
- 题材格局评估（冲突维度、时代参与度、女性困境维度、底层视角真实性）

## 调用流程

```
主编
    │
    ├── 同时启动 ──→ 06a-逻辑检查（Agent工具调用）
    │                      │
    │                      └── 输出：逻辑检查报告
    │
    ├── 同时启动 ──→ 06b-文字检查（Agent工具调用）
    │                      │
    │                      └── 输出：文字检查报告 + AI痕迹检测报告
    │
    └── 同时启动 ──→ 06c-叙事审稿（Agent工具调用）🆕
                           │
                           └── 输出：叙事结构审读报告
    
    ↓ 主编汇总三份报告，形成最终检查意见（内部流转，不单独保存）
    ↓ 写手根据检查意见修改
    ↓ 修改完成后，再次运行三个检查官复查（至少2轮）
```

## 通不过的硬底线

以下任一项不达标 → 总体判定不得为「✅ 通过」：

**06a 逻辑底线**：
- 伏笔回收率不达标（全文≥40%）
- 触法场景无后果且无合理解释
- 时间线登记表出现🔴矛盾

**06b 文字底线**：
- AI痕迹检测报告中任一🔴项未消除
- 重复意象超标
- 对话盲辨失败（摘名无法区分角色）
- 三闭环不达标
- 冲突模板单一（同一种超过2次）

**06c 叙事底线** 🆕：
- 存在3处以上同质化心理模板（同一套"受挫→反应"流程无情绪递进）
- 任一主要配角被判定为「纯工具人」（删掉测试得分为零）
- 核心冲突被判定为「赢得太轻松」（对手无有效反制）
- 存在3条以上废伏笔（只埋不回收且无后续计划）
- 章末无钩子（结尾仅"伤感+明天继续"而无任何悬念/期待/新信息）
