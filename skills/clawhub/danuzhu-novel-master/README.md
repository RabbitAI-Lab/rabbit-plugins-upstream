一、我想看的画面
================================================================

深夜，祠堂。族中长辈全到齐了，黑压压跪了一片。烛火晃得人脸上一明一暗。

王枫进来的时候，没跪。

她从袖子里抽出一卷账册，走到供桌前。一页。一页。一页——放在桌上。每一页都是她亲自查出来的贪墨铁证。放完最后一页，她转过身，看着她二叔。

「二叔。这些年你贪了多少银子——你是自己说，还是我替你念？」

祠堂里安静了大概有十秒钟。二叔脸上的表情，我这辈子都忘不了。

================================================================
二、王枫说话是什么感觉
================================================================

王枫私下里说的一句话，你感受一下她的语气：

「我知道所有人都觉得我好欺负。没事，让他们觉得。我就喜欢他们这么想——因为你把一个人捧到最高处再放手，摔下去的时候才好听。」

性格关键词：能忍，但不是软——是攒着。下手的时候不犹豫。话不多，但开口就是刀子。

================================================================
三、绝对不能有
================================================================

1. 不要任何男人从天而降救她——她能自己解决的事，不需要别人插手
2. 不要写她「内心深处其实很脆弱」「卸下防备之后也是个需要人疼的小女孩」——她不脆弱，她就这样
3. 不要圣母桥段——伤害过她的人，不原谅就是不原谅，不需要和解
4. 不要CP线、不要感情戏——专心搞事业
5. 不要「女人为难女人」——女配可以是对手，但得有脑子、有她的立场和动机

================================================================
四、风格参考
================================================================

像《知否》的质感——有烟火气、有人情世故、有日常细节。但王枫比明兰更主动进攻：明兰是守，王枫是攻。
像《甄嬛传》的步步为营——但她比甄嬛少一点儿女情长，多一点杀伐果断。

================================================================
五、补充设定
================================================================

背景：架空古代，类似明清。侯门世家，王枫是嫡长女，母亲早逝，父亲续弦。继母表面贤惠，实则纵容娘家蚕食王府产业。

故事主线：父亲病重昏迷期间，王枫发现家中账目被二房和继母联手掏空。她要在父亲醒来之前——或者醒不来之前——把家业夺回来。

王枫的优势：会算账、记性好、从小跟在父亲身边学做生意。
王枫的弱点：太能忍，有时候忍到对方觉得她真的没脾气——然后她出手的时候谁都反应不过来。但这个"忍"也有代价：她身边的人会觉得她冷。
