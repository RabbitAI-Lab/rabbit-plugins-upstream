# powpow-register

PowPow بابل رجسٹریشن اسسٹنٹ (OpenClaw ایڈیشن): ایک نئے صارف کو "بابل کیا ہے، معلوم نہیں" والی حالت سے "اکاؤنٹ فعال، ون کلک لاگ اِن، کھیلنا شروع" تک لے جاتا ہے — پروڈکٹ تعارف (انٹرفیس اسکرین شاٹس سمیت)، ایجنٹ ہو کر رجسٹریشن (پروفائل تصویر اپلوڈ سمیت)، علی پے/PayPal سبسکرپشن آرڈر و رقم کی وصولی ٹریکنگ، ڈبل لنک ون کلک لاگ اِن، خرابیوں کا حل۔

**v2.0.0 سے یہ ایجنٹ کی طرف سے کام کرنے والا موڈ ہے، اور v2.2.0 سے پلیٹ فارم کے مفت تجرباتی دور سے بھی مطابقت اختیار کر لیتا ہے**: بنیادی سکرپٹ `scripts/powpow-register.mjs` بغیر انحصار کا ہے
(Node ≥ 18)؛ صارف بات چیت صرف ایک بار چھوڑتا ہے: ان باکس میں تصدیقی کوڈ دیکھنے کے لیے۔ موجودہ مفت تجرباتی دور میں رجسٹر شدہ اکاؤنٹ فوراً ہر خصوصیت استعمال کر سکتا ہے — سبسکرپشن ادائیگی اختیاری ہے؛ اگر تجرباتی دور ختم ہو کر صارف سبسکرپشن پیج پر اتر جائے تو بہاؤ خودکار طور پر ادائیگی کے راستے پر سوئچ ہو جاتا ہے۔ Node کے بغیر، یا جب صارف خود کرنا چاہے، خودکار طور پر خالص رہنمائی موڈ میں واپس۔

## انسٹال

```
openclaw skills install @durenzidu/powpow-register
```

## فیچرز

1. **پروڈکٹ تعارف**: ~۱۲۰ الفاظ کا آغاز + اس کل کے ساتھ پیک انٹرفیس اسکرین شاٹس (`assets/screenshots/` میں ۶ تصاویر:
   نقشہ پیج، پوسٹ تفصیل پیج وغیرہ؛ موقع کے مطابق ۱ تا ۳ بھیجیں؛ بیرونی امیج ہوسٹ کی ضرورت نہیں، آف لائن قابل استعمال)۔
2. **ایجنٹ ہو کر رجسٹریشن**: ایجنٹ خود یوزر نیم/نک نیم تجویز کرتا ہے، پاس ورڈ دو میں سے ایک چنواتا ہے (صارف فراہم کرے یا ایجنٹ بنائے)،
   تصدیقی کوڈ بھیجنا اور جمع کرانا، پروفائل تصویر براہ راست اپلوڈ (≤5MB، SVG نہیں)، عام خرابیوں کا خودکار حل (زیر استعمال/میعاد ختم/حد بندی)۔
3. **ون کلک لاگ ان (دو لنک)**: کامیاب رجسٹریشن کے فوراً بعد لاگ ان لنک صارف کو سیدھا ہوم پیج پر لے جاتا ہے (مفت تجرباتی دور میں ایک کلک اور قابل استعمال)؛
   اگر سبسکرپشن پیج پر اتر جائے (تجرباتی دور ختم) یا صارف اپ گریڈ چاہے تو سبسکرپشن کے بہاؤ پر عمل کریں — آمدنی کے بعد نئی لاگ ان حالت میں تبدیلی ہوتی ہے اور مکمل ممبرشپ والا لنک ہوم پیج پر لے جاتا ہے
   (پلیٹ فارم کے سرکاری `me?token=` پل کے ذریعے، جو خودکار طور پر HttpOnly کوکی لگا دیتا ہے)۔
   خود لگ جاتا ہے)۔
4. **سبسکرپشن پیمنٹ**: علی پے (ماہانہ ¥6.99 / سہ ماہی ¥19.99 / سالانہ ¥69.99،
   ایک بار ادائیگی پر مکمل مدت، خودکار تجدید نہیں) اور PayPal (Premium Monthly، تقریباً $1/ماہ،
   خودکار تجدید، کسی بھی وقت منسوخ) — دونوں پر ایجنٹ ہو کر آرڈر + رقم کی وصولی کی پولنگ؛
   وی چیٹ QR/ہواوی IAP کی رہنمائی۔
5. **خرابیوں کا حل**: تصدیقی کوڈ نہ آنا، یوزر نیم/ای میل زیر استعمال ہونا، 403 غیر فعال، اکاؤنٹ لاک ہونا جیسی
   عام مشکلات — سب پلیٹ فارم کے سورس کوڈ سے، حوالوں کے ساتھ۔

## سیکیورٹی

- **پاس ورڈ** صرف ماحولیاتی متغیر کے ذریعے اسکرپٹ پروسیس میں جاتا ہے، کمانڈ لائن آرگیومنٹ میں کبھی نہیں لکھا جاتا، ڈسک پر محفوظ نہیں ہوتا،
  اسٹیٹ فائل میں بھی داخل نہیں ہوتا؛ ایجنٹ کا بنایا پاس ورڈ صارف کو محفوظ کروانے کے لیے صرف ایک بار دکھایا جاتا ہے۔
- **تصدیقی کوڈ** صرف سرکاری رجسٹریشن انٹرفیس پر استعمال ہوتا ہے، کام مکمل ہوتے ہی پھینک دیا جاتا ہے؛ اسٹیٹ فائل (ای میل/یوزر نیم/token/آرڈر نمبر)
  سسٹم کی عارضی ڈائریکٹری میں رہتی ہے، عمل ختم ہونے پر `cleanup` ایک کمانڈ سے صاف ہو جاتی ہے۔
- **پیمنٹ**: ایجنٹ صرف آرڈر بناتا ہے، پیمنٹ پیج کھولتا ہے، رقم کی وصولی چیک کرتا ہے؛ صارف کا علی پے اکاؤنٹ
  یا پیمنٹ اسناد کبھی نہیں چھوتا، ادائیگی بھی خود نہیں کرتا۔ ادائیگی ہمیشہ صارف اور سرکاری پیمنٹ پیج کے درمیان ہی ہوتی ہے۔
- تمام درخواستیں صرف سرکاری ڈومین `https://global.powpow.online` پر جاتی ہیں؛ کوئی API کلید نہیں بھیجی جاتی۔
