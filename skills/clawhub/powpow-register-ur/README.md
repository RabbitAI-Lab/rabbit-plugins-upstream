# powpow-register

PowPow بابل رجسٹریشن اسسٹنٹ (OpenClaw ورژن): نئے صارف کو «بابل کیا ہے» نہ جاننے سے لے کر
«اکاؤنٹ ایکٹیویٹ اور استعمال کے لیے تیار» تک پہنچائیں — مصنوعات کا تعارف (انٹرفیس اسکرین شاٹس سمیت)،
مرحلہ وار رجسٹریشن گائیڈ، ایرر کی تحقیق، سبسکرپشن ایکٹیویشن کی تفصیل۔

خالص گائیڈ قسم کا skill، کوئی اسکرپٹ نہیں، کوئی ڈیپنڈنسی نہیں؛ تمام رجسٹریشن اعمال صارف براؤزر/ایپ میں
خود مکمل کرتا ہے۔

## انسٹالیشن

```
openclaw skills install @durenzidu/powpow-register
```

## خصوصیات

1. **مصنوعات کا تعارف**: تقریباً 120 الفاظ کا تعارف + GitHub عوامی ریپوزٹری میں ہوسٹڈ انٹرفیس اسکرین شاٹس کے لنک
   (نقشہ پیج، پوسٹ ڈیٹیل پیج وغیرہ 6 تصاویر، موقع کے مطابق 1–3 بھیجیں)۔
2. **رجسٹریشن گائیڈ**: فیلڈ قواعد (یوزر نیم/پاس ورڈ/ای میل تصدیقی کوڈ/موبائل نمبر/پروفائل تصویر)،
   تھرڈ پارٹی لاگ ان (Google/Watcha/ہواوے)، ریٹ-لمٹ پیرامیٹرز، سب پلیٹ فارم سورس کوڈ سے لیے گئے اور سورس درج۔
3. **ایرر کی تحقیق**: تصدیقی کوڈ نہ ملنا، یوزر نیم/ای میل پہلے سے مستعمل، 403 ایکٹیویٹ نہیں، اکاؤنٹ لاک
   وغیرہ 13 عام مسائل۔
4. **سبسکرپشن ایکٹیویشن**: PayPal (ویب) / WeChat اسکین (دستی تصدیق) / ہواوے IAP (HarmonyOS) تین
   ذرائع کی تفصیل اور حل؛ موجودہ ادائیگی چین براہ راست دوبارہ استعمال ہو سکتی ہے، skill صرف راستہ دکھاتا ہے۔

## سیکورٹی

- کسی بھی کلید (key) پر مشتمل نہیں؛ کوئی اسکرپٹ نہیں، صارف کی اسناد (credentials) کو چھوتا نہیں۔
- **کبھی نہیں مانگتا** صارف کا پاس ورڈ، تصدیقی کوڈ یا ادائیگی کا ثبوت؛ رجسٹریشن اور ادائیگی سب پلیٹ فارم
  پیجز پر ہوتی ہیں۔
