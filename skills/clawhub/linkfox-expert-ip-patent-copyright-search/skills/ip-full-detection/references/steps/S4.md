# 步骤 4：汇总检测结果与风险评估

- **输入**：S2 的 AIGC 预筛结果 + S3 的专业检测 JSON（仅模糊项）
- **依赖**：S3（全部模糊项检测返回或失败后）
- **操作**：合并 AIGC 预筛结论 + 专业检测结果，统一计算每项风险等级和总体风险等级
- **输出**：结构化 `data` 对象，包含产品信息 + AIGC 预筛概览 + 合并后的 6 项检测结果 + 总体风险评估
- **用途**：供 S5 报告生成作为 `data` 参数

## 合并逻辑

每项检测的最终风险等级来源：

| S2 预筛判定 | S3 专业检测 | 最终风险等级来源 |
|-------------|------------|----------------|
| `RISK` | 未执行 | 采用 AIGC 预筛结论，等级映射为 `HIGH` |
| `CLEAN` | 未执行 | 采用 AIGC 预筛结论，等级映射为 `CLEAN` |
| `AMBIGUOUS` | 成功返回 | 使用 S3 专业检测 JSON，按 S4 评级规则计算 |
| `AMBIGUOUS` | 检测失败 | 回退 AIGC 预筛结论，等级映射为 `LOW`（保守放行但标注不确定） |

## AIGC 预筛结论到风险等级映射

| AIGC verdict | 映射风险等级 | 说明 |
|--------------|-------------|------|
| `RISK` | `HIGH` | AIGC 明确判断有风险，直接标记高风险 |
| `CLEAN` | `CLEAN` | AIGC 明确判断无风险，直接放行 |
| `AMBIGUOUS`（检测失败回退） | `LOW` | 保守处理，标注"专业检测失败，AIGC 预筛不确定" |

## 专业检测关键指标提取

对 S3 返回的每份 JSON 用 `python3 -c` 或 jq 提取以下指标：

### 文字商标检测
| 指标 | 提取路径 | 说明 |
|------|---------|------|
| textTrademarkRadar | `textTrademarkRadar` | 0=低风险, 1=待核查, 2=高风险 |
| blacklistCount | `blacklistTrademarks` length | 黑名单商标数 |
| whitelistCount | `whitelistTrademarks` length | 白名单商标数 |
| highRiskCount | `data[*].highestModeScore > 0` count | 高风险匹配数 |
| famousOrAmazonBrand | `data[*].isFamous or isAmazonBrand` count | 知名/亚马逊品牌数 |

### 图形商标检测
| 指标 | 提取路径 | 说明 |
|------|---------|------|
| radarResult | `radarResult` | low_risk / medium_risk / high_risk |
| boundingBoxCount | `boundingBoxCount` | 检测到的 Logo 区域数 |
| maxSimilarity | `data[*].similarity` max | 最高相似度 |
| totalMatches | `total` | 匹配总数 |

### 实用新型专利检测
| 指标 | 提取路径 | 说明 |
|------|---------|------|
| totalMatches | `total` | 匹配总数 |
| activeHighSim | `data[*].patentValidity=="Active" and similarity>=0.7` count | 有效高相似专利数 |
| troFlagged | `data[*].troCase or troHolder` count | TRO 标记数 |
| maxSimilarity | `data[*].similarity` max | 最高相似度 |

### 外观设计专利检测
| 指标 | 提取路径 | 说明 |
|------|---------|------|
| radarSameCount | `data[*].radarResult.same == true` count | radar 判定疑似侵权数 |
| highSim | `data[*].similarity >= 0.7` count | 高相似度数 |
| troFlagged | `data[*].troCase or troHolder` count | TRO 标记数 |
| maxSimilarity | `data[*].similarity` max | 最高相似度 |

### 版权检测
| 指标 | 提取路径 | 说明 |
|------|---------|------|
| highSim | `data[*].similarity >= 0.7` count | 高相似度数 |
| radarPositive | `data[*].subRadarResult == 1` count | radar 判定侵权数 |
| troFlagged | `data[*].troCase or troHolder` count | TRO 标记数 |
| maxSimilarity | `data[*].similarity` max | 最高相似度 |

### 政策合规检测
| 指标 | 提取路径 | 说明 |
|------|---------|------|
| totalMatches | `data` length | 违规匹配数 |

## 风险评级规则

每项检测独立评级：

| 检测项 | CLEAN | LOW | MODERATE | HIGH |
|--------|-------|-----|----------|------|
| 文字商标 | - | radar in [0,"待人工核查"] 且 highRiskCount=0 且 blacklistCount=0 | radar=1 或 highRiskCount>0 | radar=2 或 blacklistCount>0 |
| 图形商标 | boundingBoxCount=0 且 total=0 | radar="low_risk" 且 maxSim<0.7 | radar="medium_risk" 或 maxSim>=0.7 | radar="high_risk" 或 maxSim>=0.8 |
| 实用新型专利 | total=0 | activeHighSim=0 | activeHighSim in [1,5] | activeHighSim>5 或 troFlagged>0 |
| 外观设计专利 | total=0 | radarSameCount=0 且 maxSim<0.6 | radarSameCount=0 且 maxSim in [0.6,0.7) | radarSameCount>0 或 maxSim>=0.7 |
| 版权 | total=0 | maxSim<0.6 且 radarPositive=0 | maxSim in [0.6,0.7) 且 radarPositive=0 | maxSim>=0.7 或 radarPositive>0 |
| 政策合规 | total=0 | - | - | total>0 |

总体风险等级 = 最高单项风险等级（CLEAN < LOW < MODERATE < HIGH）。

## 高风险项标注

以下情况需在汇总数据中标记为"重点关注"：

- 外观设计专利：`radarResult.same == true` 的专利（不论相似度数值）
- 实用新型专利：`similarity >= 0.7` 且 `patentValidity == "Active"` 的专利
- 版权：`similarity >= 0.7` 或 `subRadarResult == 1` 的记录
- 文字商标：`blacklistTrademarks` 非空的条目
- 任何检测：`troCase == true` 或 `troHolder == true` 的记录
- AIGC 预筛判定为 `RISK` 的项（标注"AIGC 预筛风险"）

## 输出数据结构

汇总后的 `data` 对象结构：

```json
{
  "product": { "asin", "title", "brand", "price", "rating", "imageUrl", "link" },
  "aigc_prescreen": {
    "summary": { "total": 6, "risk": 1, "clean": 3, "ambiguous": 2 },
    "credits_saved": 4,
    "results": {
      "design_patent": { "verdict": "AMBIGUOUS", "reasoning": "...", "confidence": 55 },
      "utility_patent": { "verdict": "CLEAN", "reasoning": "...", "confidence": 85 },
      "copyright": { "verdict": "CLEAN", "reasoning": "...", "confidence": 90 },
      "graphic_trademark": { "verdict": "AMBIGUOUS", "reasoning": "...", "confidence": 50 },
      "text_trademark": { "verdict": "RISK", "reasoning": "...", "confidence": 92 },
      "policy_compliance": { "verdict": "CLEAN", "reasoning": "...", "confidence": 88 }
    }
  },
  "detection_results": {
    "text_trademark": { "risk_level", "source": "aigc_prescreen|professional", "radar", "total_matches", "high_risk_count", "blacklist_count", "summary", "top_matches", "aigc_reasoning" },
    "graphic_trademark": { "risk_level", "source", "radar", "bounding_box_count", "total_matches", "max_similarity", "summary", "top_matches", "aigc_reasoning" },
    "utility_patent": { "risk_level", "source", "total_matches", "active_high_sim", "tro_flagged", "max_similarity", "summary", "top_active_patents", "aigc_reasoning" },
    "design_patent": { "risk_level", "source", "total_matches", "radar_same_count", "tro_flagged", "max_similarity", "critical_finding", "summary", "aigc_reasoning" },
    "copyright": { "risk_level", "source", "total_matches", "radar_positive", "tro_flagged", "max_similarity", "summary", "top_matches", "aigc_reasoning" },
    "policy_compliance": { "risk_level", "source", "total_matches", "summary", "aigc_reasoning" }
  },
  "overall_risk": { "level", "primary_risk", "secondary_risk", "clean_areas" }
}
```

每项 `detection_results` 中新增字段：
- `source`：标记该风险等级来源——`aigc_prescreen`（AIGC 预筛直接判定）或 `professional`（专业检测计算）
- `aigc_reasoning`：AIGC 预筛的推理摘要（即使用于最终判定的是专业检测，也保留 AIGC 预筛推理供报告展示）
