# 步骤 5：生成 HTML 报告

- **输入**：S4 输出的结构化 `data` 对象
- **依赖**：S4
- **操作**：调用 `linkfox-report-generator` 生成 HTML 报告
- **输出**：HTML 报告文件（落盘到 `reports/` 目录）
- **用途**：最终交付物

## 调用方式

由于 `data` 对象较大，通过 Python wrapper 从文件读取 JSON 传参：

```python
import json, subprocess, sys
with open('<汇总数据临时文件路径>', 'r') as f:
    params = json.load(f)
params_str = json.dumps(params, ensure_ascii=False)
result = subprocess.run(
    ['python3', '<report_generator_path>/scripts/generate_report.py', params_str],
    capture_output=False
)
```

## 参数构造

```json
{
  "format": "html",
  "title": "ASIN <asin> - IP Full Detection Report (AIGC Pre-screened)",
  "instruction": "基于以下 AIGC 预筛 + 专业检测结果，生成一份完整的 IP 全检测报告。报告需包含：1）AIGC 预筛概览（6 项三态判定一览，标注积分节省）；2）总体风险评级与风险矩阵概览；3）每项检测的详细结果与风险解读（区分 AIGC 预筛判定 vs 专业检测）；4）高风险项的重点标注与建议；5）综合行动建议。",
  "data": <S4 输出的 data 对象>,
  "userPrompts": [

    "开头加一个 AIGC 预筛概览表格，展示 6 项的 verdict(RISK/CLEAN/AMBIGUOUS) 和 confidence，并标注哪些项跳过了专业检测。",
    "展示积分节省统计：N 项由 AIGC 预筛直接判定，M 项进入专业检测。",

    "AIGC 预筛推理摘要以引用块形式展示在每个检测项章节开头。",

```

## 报告章节

| 章节 | 数据来源 |
|------|---------|
| 产品信息概览 | S1 product 对象 |
| AIGC 预筛概览 | S4 aigc_prescreen 对象 |
| 总体风险矩阵 | S4 overall_risk |
| 文字商标检测 | S4 detection_results.text_trademark |
| 图形商标检测 | S4 detection_results.graphic_trademark |
| 实用新型专利检测 | S4 detection_results.utility_patent |
| 外观设计专利检测 | S4 detection_results.design_patent（含 critical_finding） |
| 版权检测 | S4 detection_results.copyright |
| 政策合规检测 | S4 detection_results.policy_compliance |
| 综合行动建议 | S4 overall_risk + 各项 risk_level |

## 报告视觉规范

### AIGC 预筛概览表格

| 检测项 | AIGC 判定 | 置信度 | 专业检测 | 最终风险 |
|--------|----------|--------|---------|---------|
| 文字商标 | RISK (红色) | 92% | 跳过 (灰色) | HIGH (红色) |
| 实用新型专利 | CLEAN (绿色) | 85% | 跳过 (灰色) | CLEAN (绿色) |
| 外观设计专利 | AMBIGUOUS (黄色) | 55% | 已执行 (蓝色) | MODERATE (橙色) |
| ... | ... | ... | ... | ... |

### 每项检测章节结构

1. **章节标题 + 风险等级标签**（HIGH=红/MODERATE=橙/LOW=黄/CLEAN=绿）
2. **来源标记**：`[AIGC 预筛]` 或 `[专业检测]` 或 `[AIGC 预筛 + 专业检测]`
3. **AIGC 预筛推理**（引用块，灰色斜体）
4. **专业检测结果详情**（仅当执行了专业检测时展示）
5. **关键发现/高风险匹配项**

## 输出路径

报告落盘到：`<cwd>/linkfox/<YYYY-MM-DD>/<session>/reports/ip-full-detection-<timestamp>.html`

同时保留：
- 6 份原始 JSON 数据文件（仅模糊项）在 `<cwd>/linkfox/<YYYY-MM-DD>/<session>/data/` 目录
- AIGC 预筛结果 JSON 在 `<cwd>/linkfox/<YYYY-MM-DD>/<session>/data/aigc-prescreen-<timestamp>.json`
