# 步骤 1：拉取产品详情

- **输入**：`asin`（运行时入参）、`region`（运行时入参，默认 US）
- **依赖**：无
- **操作**：调用 `linkfox-amazon-product-detail`，传入 `asins=asin`、`amazonDomain` 根据 region 映射（US → amazon.com）。执行脚本：
  ```bash
  python <skill_path>/scripts/amazon_product_detail.py '{"asins":"<asin>","amazonDomain":"amazon.com"}' --inline
  ```
- **输出**：`productTitle`（产品标题）、`imageUrl`（主图 URL）、`aboutItemFivePoint`（五点描述数组）、`productDescription`（A+ 描述）、`brand`（品牌）、`price`、`rating`
- **用途**：`productTitle` 和 `imageUrl` 供 S2 的 6 项检测作为输入参数；`aboutItemFivePoint` 拼接后作为文字商标检测的 `productText` 和实用新型专利检测的 `productDescription`

## 字段提取要点

从返回 JSON 的 `products[0]` 中提取：

| 字段 | 路径 | 用途 |
|------|------|------|
| productTitle | `products[0].title` | S2 所有检测的标题参数 |
| imageUrl | `products[0].imageUrl` | S2 图形商标/外观专利/版权/政策合规的图片参数 |
| aboutItemFivePoint | `products[0].aboutItemFivePoint` | 拼接为 productText 和 productDescription |
| brand | `products[0].brand` | 报告中的产品信息 |
| price | `products[0].price` | 报告中的产品信息 |
| rating | `products[0].rating` | 报告中的产品信息 |

## 五点描述拼接逻辑

将 `aboutItemFivePoint` 数组用空格拼接为一个字符串，截断到 1000 字符以内（睿关 API 限制）：
- 文字商标检测：拼接结果作为 `productText`
- 实用新型专利检测：拼接结果作为 `productDescription`，如超出 1000 字符则截断
