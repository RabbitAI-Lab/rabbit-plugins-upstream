# Evidence-linked session maps
1. Choose an immutable snapshot and keep its SHA-256 plus source bounds. Do not summarize a moving source as if it were fixed.
2. Index first; review parse errors, unlinked tools and classification uncertainty. Human-origin metadata is evidence of origin; absent metadata is not proof a prompt came from a human.
3. Build a small top-level map of topics or decisions. Each node should have a concise takeaway, current state, source span and unresolved question. Choose nodes from the actual session, not a fixed taxonomy.
4. Keep a chronological delta record for decisions and corrections. Do not turn an attempted action into successful execution or a passing test into deployment evidence.
5. Verify consequential claims against their underlying artifacts when available. Mark source-only recollections and unavailable artifacts explicitly.
6. Keep reasoning text out of summaries and indexes. Keep all other private content private too; a coverage hash is not a publication review.

Use ../templates/atlas.md as a starting structure. This method is domain-neutral: it ships no private research invariants, campaign IDs or historical claims.
