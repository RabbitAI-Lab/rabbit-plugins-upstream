# 儿童科普短视频生产（children-science-video）

面向儿童/小学生（3-10岁受众）的科普动画短视频生产流水线。输入一份科普文案或一个主题，输出「文案 → 5组分镜表 → 封面 → 双平台文案 → 9:16配图 → 首帧图生视频」完整资产包，全部落在 `{文案标题}/` 一个文件夹内。

## 触发与主题原则（最重要，先于一切）

1. **任意科普文案即触发**：用户粘贴/提供任何科普、安全、知识类文案（哪怕只有一段文字、未说明要做成视频），即按本技能全流程执行，**以该文案为唯一主题**。
2. **示例仅示例**：`references/example-scooter-safety.md`（滑板车安全）只是标准产出的格式范例，**禁止**把滑板车的主题、人物设定、台词套用到其他文案上；每个新任务都从用户输入重新创作。
3. 用户只给主题词、没给文案时，走 Step 1 从零创作；给了文案则以 Step 1 的优化改写为准（不改变原意与知识点）。

## 核心铁律（每次执行前必读，违反即返工）

1. **合规红线（最高优先级）**：禁止生成任何违反法律法规的内容，禁止色情低俗、毒品、赌博相关内容；禁止暴力恐吓、校园霸凌美化、涉政敏感与歧视性内容。危险动作只能以"错误示范+被制止/后怕"温和呈现，禁止血腥、受伤流血特写、动物受虐；无真实品牌、无真人肖像、无版权卡通形象；危险画面必须配安全标志/警告信息。医疗类内容只做科普，不给诊断与治疗建议。**选题本身触碰红线时直接拒绝并说明原因，不做变通改写。**
2. **统一输出目录**：开工第一步就确定 `{文案标题}/`（文案标题 = Step 1 的主题名，做合法文件名字符清洗），本次任务**所有产物**（文案、分镜表、封面提示词、PDF、图片、视频、封面图）全部存入该文件夹内，方便用户查找。
3. **全角色形象一致性**：所有文生图提示词必须原样复用 `references/character-consistency.md` 的基准块——儿童主角用「人物形象基准块」，出场的动物/植物/拟人角色各自用对应的「动植物形象基准块」；每个选题只在分镜表顶部定义一次，之后所有分镜只引用不重写，只允许按规则替换情绪词、着装与动作姿态；物种、配色、五官、体型比例、随身特征、画风参数零改动。
4. **配音字数**：每个分镜配音文案满足 40 ≤ 总字符数 ≤ 50 且汉字数 ≥ 36（约8-10秒口播）。**不足40字视为内容单薄，必须丰富**——补动作要领、装备/物种/器官名称、原理类比、知识彩蛋或后果对照，不许只加语气词凑字。写完后必须用 `scripts/check_voiceover.py` 机检。
5. **序号即文件名**：图片文件名 = 分镜脚本序号（`01.png`~`05.png`，两位补零）；视频文件名 = 同一序号（`01.mp4`~`05.mp4`）。禁止加主题前缀、中文描述、版本号后缀；图片与视频同名即代表同一分镜，一一对应不得错位。
6. **视频必须以配图为第一帧**：每个分镜的视频用该分镜生成的图片作首帧（image-to-video / 首帧图模式），禁止纯文生视频、禁止跨镜借用别镜图片。
7. **首尾镜头**：第1个分镜前3秒为冲突/悬念钩子；最后1个分镜以评论区提问收尾。
8. **表情丰富 + 动作达意**：图生视频提示词必须写出面部表情的「起始→转折→收尾」三层变化（具体到眉眼嘴；非人类角色落到触角/复眼/翅膀/花盘/叶片），每个肢体动作写全「身体部位+方向+幅度+意图」四件套，并含互动元素与文字动效。
9. **图文并茂**：每张文生图都要包含文字描述/安全标志/警告信息等图形化元素。
10. **中文输出**：所有文件 UTF-8；PDF 必须走 `scripts/make_platform_pdf.py`（已注册 SimSun/SimHei/SimKai）。

## 工作流（7步，按顺序执行）

### Step 0 建目录与定角色
- 定出 `{文案标题}`，创建 `{文案标题}/`，并按需建 `images/`、`videos/`、`cover/` 子目录。
- 读 `references/character-consistency.md`，为本次选题写全**所有出场角色**的基准块（儿童主角 + 每个动植物/拟人角色各一段），记入分镜表顶部「角色设定」，全程锁定。

### Step 1 生成/打磨科普文案
- 用户给了文案：提炼主题、安全知识点、情绪基调，按标准结构优化（不改变原意）；用户只给主题：从零创作。
- 结构：提问开场（钩子）→ 简单原理解释（类比要儿童能懂）→ 知识彩蛋（历史/文化/科学小知识）→ 正确做法/安全守则 → 行动号召。
- 语气：亲切风趣、像大哥哥大姐姐聊天，口语化带语气词；正文 150-300 字；附 3-6 个话题标签。
- 先过合规红线自检，再产出 `{文案标题}/{文案标题}_视频文案.md`。

### Step 2 生成5组分镜头脚本表
- 先读 `references/storyboard-rules.md` 与 `assets/storyboard-table-template.md`。
- 5镜叙事结构：①冲突开场（错误示范+3秒钩子）②科学原理 ③危险演示（温和）④正确做法+护具/场地/看护 ⑤安全守则+评论提问。
- 表格列：分镜号/时长/剧情要点/运镜方式/景别/文生图提示词/图生视频提示词/配音文案。分镜号直接决定图片与视频文件名（1 → `01.png` / `01.mp4`）。
- 提示词写法：文生图 = 全角色基准块+场景+动作+情绪词+文字/安全标志元素+9:16；图生视频 = 首帧 `{序号}.png` 承接+表情三层+2-4个连贯动作（部位+方向+幅度+意图）+情绪变化+互动元素+镜头运动+全角色锁定句+10秒。细则见 `references/video-prompt-rules.md`。
- 配音文案逐镜写满 40-50 字，每镜至少一个具体信息点。
- 产出 `{文案标题}/{文案标题}_分镜头脚本表.md`，随后必须跑 `scripts/check_voiceover.py` 校验字数，不合格按铁律4丰富内容后重跑。

### Step 3 全表提示词优化
对照 `references/video-prompt-rules.md` 逐镜优化：面部表情三层变化（眉眼嘴/触角翅膀花盘）、肢体动作四件套（部位+方向+幅度+意图）与儿童年龄动作特征、文字/安全标志/警告信息呈现、危险事件温和表达、角色间互动元素；复核全部角色基准块与顶部定义零差异；配音文案再丰富（字数守 40-50，不足则补知识点）。

### Step 4 生成爆款封面（竖+横）
- 读 `references/cover-specs.md`：竖版 3:4（小红书）、横版 4:3（抖音/视频号），3D渲染风格，全部角色与文生图完全一致。
- 钩子文字大字号（问题/警告式），主角靠前占画面1/3以上，背景干净；另做一版"强点击感"（标题更大、人物更靠前、背景更干净，信息流1秒可识别）。
- 产出 `{文案标题}/{文案标题}_封面提示词.md`（含每版完整提示词+标题备选+排版说明）；封面图生成后存 `{文案标题}/cover/cover_3x4.png`、`cover_4x3.png`。
- 注意：生成模型对中文文字不稳定，封面大标题允许后期贴字（剪映），提示词中仍要写上目标文字。

### Step 5 双平台爆款文案（PDF）
- 读 `references/platform-copy.md`：抖音/小红书标题各≤20字，正文可直接粘贴发布，无占位符。
- 用 `scripts/make_platform_pdf.py {md} {pdf}` 生成 `{文案标题}/{文案标题}_双平台发布文案.pdf`（已注册中文字体；emoji 会被剔除并在文末给出提示）。

### Step 6 生成9:16配图（以分镜序号命名）
- 读 `references/image-gen-specs.md`：逐镜调用 ImageGen 工具，比例 9:16，输出目录 `{文案标题}/images/`。
- 生成前必须告知用户图片生成的积分消耗（每张约5-10 credits）并得到确认。
- 文件名严格为 `01.png`~`05.png`；重掷时覆盖同名文件，不产生副本。
- 生成后逐张目检**全部角色**一致性（儿童看脸/发型/服装；动物看物种/配色/部件数量；植物看花色/花瓣数/株高），不一致就重掷或把基准块放到提示词最前加重权重。
- 逐张确认可作视频首帧（构图完整、主体不贴边、留有动作空间）。

### Step 7 以配图为第一帧生成视频（以分镜序号命名）
- 读 `references/video-prompt-rules.md` 第一、二节：逐镜用 `images/{序号}.png` 作首帧调用图生视频能力，输出 `{文案标题}/videos/{序号}.mp4`。
- 提示词首句固定：`以 {序号}.png 为首帧，保持首帧构图、角色形象、服装配色与场景完全一致，` 之后接表情三层 + 动作四件套 + 互动 + 镜头 + 全角色锁定句 + 10秒。
- 生成前必须告知用户视频生成的积分消耗并得到确认。
- 逐条目检：首帧是否吻合、角色有无变形换脸/物种漂移、表情是否变化、动作是否达意、文字与警告标志是否出现；不合格用同提示词重生成，最多3次，仍不合格回 Step 3 修提示词。
- 完成后可衔接 agnes-video-flash（reference 模式锁角色）做拼接成片。

## 输出文件规范
全部写在 `{文案标题}/` 内：

```text
{文案标题}/
├── {文案标题}_视频文案.md
├── {文案标题}_分镜头脚本表.md
├── {文案标题}_封面提示词.md
├── {文案标题}_双平台发布文案.pdf
├── images/    01.png 02.png 03.png 04.png 05.png   （Step 6，文件名=分镜序号）
├── videos/    01.mp4 02.mp4 03.mp4 04.mp4 05.mp4   （Step 7，文件名=分镜序号，以同序号图片为首帧）
└── cover/     cover_3x4.png cover_4x3.png
```

`{文案标题}` 需做文件名字符清洗：去掉 `\ / : * ? " < > |` 等非法字符与首尾空格，长度控制在 30 字以内。

## 交付前检查清单
- [ ] 所有产物都在 `{文案标题}/` 文件夹内，无散落在外的文件
- [ ] 5个分镜齐全；配音文案全部通过 check_voiceover.py（40≤总字符≤50，汉字≥36），不足40字的已补具体知识点
- [ ] 首镜3秒冲突钩子；尾镜评论提问
- [ ] 全部角色基准块一致（儿童 + 每个动植物角色逐段 diff 检验），分镜表顶部角色设定齐全
- [ ] 每镜图生视频提示词含：首帧 `{序号}.png`、表情三层变化、动作四件套（部位+方向+幅度+意图）、互动元素、文字/安全标志、全角色锁定句
- [ ] 图片文件名为 `01.png`~`05.png`，视频为 `01.mp4`~`05.mp4`，序号一一对应无错位
- [ ] 每条视频确认以同序号图片为第一帧，角色无变形、无物种漂移
- [ ] 危险画面温和无血腥，配警告标志；动物无受虐画面
- [ ] 封面竖3:4+横4:3各一版，钩子文字大字号
- [ ] 双平台标题≤20字，PDF中文显示正常
- [ ] 全流程无违法违规、色情、毒品、赌博及侵权内容
