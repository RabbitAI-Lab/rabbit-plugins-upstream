# 图生视频提示词规则（Step 2/3 写提示词时读）

## 一、组装公式

```text
[首帧承接：以文生图首帧画面为起始] + [2-4个连贯肢体动作，带时间轴] + [情绪变化曲线] + [互动元素：文字弹出/安全标志闪烁/第二角色反应/手势指向] + [镜头运动] + [着装形象全程不变的锁定句] + 时长10秒
```

## 二、必含六要素（每镜缺一即返工）

1. **肢体动作**：具体到身体部位——手臂挥舞、腿部蹬地、身体倾斜、手指指向、点头、歪头、眨眼、拍胸口。避免"动起来"这类空话。
2. **面部表情**：写清表情变化过程（如"从得意变成紧张，眉毛皱起，嘴巴张成啊的口型"），不只写一个静态情绪。
3. **互动元素**（至少一种）：
   - 画面文字动效：文字气泡抖动/弹出/逐字出现
   - 安全标志/警告信息：标志牌闪烁、对勾亮起
   - 第二角色：家长点头、竖大拇指、挥手回应
   - 对观众互动：指向镜头、双手合十拜托状
4. **文字/安全标志/警告信息**：危险与安全提示必须可见，写清出现时机（"第3秒时警告牌闪烁一次"）。
5. **镜头运动**：推/拉/摇/移/跟/环绕/固定选一，与分镜表的运镜方式一致。
6. **一致性锁定句**：固定结尾"人物着装形象全程不变，Q版软乎乎质感，儿童绘本风格，柔和暖光"。

## 三、危险事件的温和表达

- 摔倒：坐倒在软垫/草地上 + 揉膝盖 + 眼泪打转 + 后怕松口气。**禁止**擦伤、流血、肿包、痛哭特写。
- 冲突：车头偏移、身体晃动、慌张挥手，配"危险"警告牌闪烁。
- 纠正：由家长角色或护具"救场"，传递"有防护就不可怕"的安抚感。

## 四、情绪曲线设计

每镜设计 2 拍情绪（主角），推荐组合：
- 镜1：得意 → 紧张
- 镜2：好奇 → 认真/恍然大悟
- 镜3：惊讶 → 后怕 → 安心（护具救命）
- 镜4：专注 → 开心
- 镜5：认真 → 俏皮/亲切

情绪要通过表情+动作双重表达，不能只写"他很开心"。

## 五、连贯性要点

- 动作之间用"随后/接着/然后"衔接，前一动作的结尾姿态即下一动作的起始姿态。
- 道具状态跨镜一致（滑板车始终同款同色；护具戴上了不中途消失）。
- 每镜开头写"以首帧画面为起始"，确保与文生图首帧无缝衔接。

## 六、常见翻车与规避

| 翻车 | 规避写法 |
|---|---|
| 人物换脸/换衣 | 结尾加锁定句；图生视频可改用 reference 模式锁角色（见 agnes-video-flash 技能） |
| 动作太少画面呆 | 补小动作：挥手、眨眼、指向、跺脚、歪头 |
| 文字乱码 | 把文字写成"文字气泡/标志牌"等图形元素描述，重要文字靠配音传达；允许后期贴字 |
| 情绪扁平 | 写2拍情绪转折，表情描述具体到眉眼嘴 |
| 危险画面过激 | 用"软垫/护具/后怕"三件套温和化 |
