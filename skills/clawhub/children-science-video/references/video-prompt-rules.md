# 图生视频提示词规则（Step 2/3 写提示词时读）

## 一、首帧与命名（硬性约定）

1. **首帧来源**：每个分镜的视频**必须**以该分镜 Step 6 生成的图片作为第一帧（image-to-video / 首帧图模式），禁止纯文生视频、禁止跨镜借用别镜图片。
2. **首帧对应关系**：分镜 N → 首帧图 `N.png` → 成片 `N.mp4`，一对一，不得错位。
3. **文件命名**：图片与视频文件名**只用分镜脚本序号**（`01`~`05`，两位数补零），不加主题前缀、不加中文描述、不加 `_v2` 等后缀。
4. **落盘位置**：统一放在 `{文案标题}/` 文件夹内（见 SKILL.md 输出文件规范），图片与视频可分别置于 `{文案标题}/images/` 与 `{文案标题}/videos/`，或同层平铺——两者同名即代表同一分镜。
5. **提示词首句固定**：`以 {序号}.png 为首帧，保持首帧构图、角色形象、服装配色与场景完全一致，` 之后再接动作与情绪描述。

## 二、组装公式

```text
[首帧承接：以 {序号}.png 为首帧，锁定构图/角色/配色/场景] + [面部表情三层变化：起始表情→转折表情→收尾表情，写到眉眼嘴] + [2-4个连贯肢体动作，带时间轴，每个动作写清身体部位+方向+幅度+意图] + [情绪变化曲线] + [互动元素：文字弹出/安全标志闪烁/第二角色反应/手势指向] + [镜头运动] + [全角色形象全程不变的锁定句] + 时长10秒
```

## 三、必含七要素（每镜缺一即返工）

### 1. 面部表情要「丰富」——三层写法

不要只写一个静态情绪，必须写清**表情的变化过程**，且落到眉眼嘴三个部位：

| 层次 | 内容 | 写法示例 |
|---|---|---|
| 起始 | 承接首帧的表情 | 眉毛上扬，眼睛睁圆发亮，嘴角上翘带笑 |
| 转折 | 剧情触发点（0.5-1秒内完成） | 眉头猛地皱紧，眼睛瞪大瞳孔收缩，嘴巴张成"啊"的口型 |
| 收尾 | 情绪落点 | 眉毛舒展，眼神放柔，嘴角重新扬起并轻轻点头 |

**加强技巧**：叠加辅助面部动作让表情更生动——眨眼（每2-3秒一次自然眨眼）、挑眉、眯眼、鼓腮、咬下唇、脸颊泛红、眼角反光湿润、头部随情绪微微歪斜。

**非人类角色**：动物/植物没有人类眉毛，表情落在其固定部件上（见 `character-consistency.md` 第三之二节）——触角颤动/竖立、复眼睁圆或眯起、翅膀张合频率、花盘抬低、花瓣张缩、叶片卷垂。同一角色同一情绪全片用同一套写法。

### 2. 肢体动作要「真实表达意图」——动作四件套

每个动作都必须写全四项，缺项即为无效动作描述：

```text
[身体部位] + [运动方向] + [幅度/力度] + [该动作想表达的意图]
```

对照示例（左为无效写法，右为有效写法）：

| ❌ 空泛 | ✅ 真实表达意图 |
|---|---|
| 他动起来 | 右手握拳举到胸前用力一挥，表达"我一定能行"的自信 |
| 他很开心 | 双臂向身体两侧大幅展开，原地小幅蹦跳两下，脚尖离地约10厘米，表达雀跃 |
| 他害怕 | 双肩猛地缩向耳朵，双手抱住头，身体后倾重心下压，膝盖微曲，表达本能防御 |
| 他指着 | 右臂伸直，食指指向画面左侧道具，头随之转向同侧，眼神锁定目标，引导观众注意 |
| 他明白了 | 右手食指轻点太阳穴两下，随后手掌向上摊开在胸前，头部轻轻一点，表达"原来如此" |
| 他道歉 | 双手在胸前合十，上身前倾约15度，头低垂，肩膀放松下沉，表达诚恳认错 |
| 他邀请 | 右手掌心向上从身前向镜头方向平缓推出，身体微前倾，表达邀请与亲近 |

**儿童动作真实性要点**：3-10岁孩子重心偏高、动作幅度大而控制力弱——跑步时手臂前后大幅摆动、转弯时身体明显内倾、高兴时原地蹦跳、紧张时会抓衣角或摸头、听讲解时身体前倾。写出这些年龄特征，视频才不会像"成人套了儿童模型"。

**动作衔接**：前一动作的结束姿态即后一动作的起始姿态，用「随后/接着/然后」串联；同一动作不要写两遍。

### 3. 互动元素（至少一种）
   - 画面文字动效：文字气泡抖动/弹出/逐字出现
   - 安全标志/警告信息：标志牌闪烁、对勾亮起
   - 第二角色：家长点头、竖大拇指、挥手回应；动物角色飞向主角、植物角色转头看向主角
   - 对观众互动：指向镜头、双手合十拜托状、凑近镜头眨眼、掌心向上邀请手势

### 4. 文字/安全标志/警告信息
危险与安全提示必须可见，写清出现时机（"第3秒时警告牌闪烁一次"）。

### 5. 镜头运动
推/拉/摇/移/跟/环绕/固定选一，与分镜表的运镜方式一致。

### 6. 全角色一致性锁定句（固定结尾）
```text
画面中所有角色的物种、脸型、发型、服装配色、体型比例、随身特征全程保持不变，不发生变形、换脸、换装或物种漂移；Q版软乎乎质感，儿童绘本风格，柔和暖光，低饱和清新色调。
```

### 7. 时长与节奏
时长10秒；按 `起步(0-2s) → 主动作(2-6s) → 反应/互动(6-9s) → 定格/文字弹出(9-10s)` 分配，表情转折放在主动作与反应之间。

## 四、危险事件的温和表达

- 摔倒：坐倒在软垫/草地上 + 揉膝盖 + 眼泪打转 + 后怕松口气。**禁止**擦伤、流血、肿包、痛哭特写。
- 冲突：车头偏移、身体晃动、慌张挥手，配"危险"警告牌闪烁。
- 纠正：由家长角色或护具"救场"，传递"有防护就不可怕"的安抚感。
- 动物相关风险：动物角色只能做温和互动（飞近、停在肩上、被观察），**禁止**叮咬、追逐、攻击、受伤、被捕捉虐待等画面。

## 五、情绪曲线设计

每镜设计 2-3 拍情绪（主角），推荐组合：
- 镜1：得意 → 紧张
- 镜2：好奇 → 认真/恍然大悟
- 镜3：惊讶 → 后怕 → 安心（护具救命）
- 镜4：专注 → 开心
- 镜5：认真 → 俏皮/亲切

情绪要通过**表情三层变化 + 肢体动作意图**双重表达，不能只写"他很开心"。同框的其他角色（家长、动物、植物）也要有一句表情/动作反应，避免背景角色僵硬如雕像。

## 六、连贯性要点

- 动作之间用"随后/接着/然后"衔接，前一动作的结尾姿态即下一动作的起始姿态。
- 道具状态跨镜一致（滑板车始终同款同色；护具戴上了不中途消失；花朵开放程度与镜间时间线吻合）。
- 每镜开头写"以 {序号}.png 为首帧"，确保与该分镜文生图成果无缝衔接。
- 跨镜角色状态连续：上一镜结尾的表情基调，是下一镜起始表情的自然延续（除非剧情要求突变）。

## 七、常见翻车与规避

| 翻车 | 规避写法 |
|---|---|
| 角色换脸/换衣/物种漂移 | 结尾加全角色锁定句；图生视频改用 reference 模式锁角色；首帧图必须是对应序号那张 |
| 表情扁平僵硬 | 写起始→转折→收尾三层表情，具体到眉眼嘴；补自然眨眼、挑眉、鼓腮、脸颊泛红 |
| 动作与意图脱节 | 每个动作写全「部位+方向+幅度+意图」四件套，禁止只写"动起来""很开心" |
| 动作太少画面呆 | 补小动作：挥手、眨眼、指向、跺脚、歪头、抓衣角、摸头、身体前倾 |
| 成人动作套儿童 | 写年龄特征：重心偏高、手臂大幅摆动、转弯身体内倾、高兴原地蹦跳 |
| 首帧与视频不接 | 首句明确"以 {序号}.png 为首帧，保持构图/角色/配色一致"，禁止跨镜借图 |
| 文字乱码 | 把文字写成"文字气泡/标志牌"等图形元素描述，重要文字靠配音传达；允许后期贴字 |
| 危险画面过激 | 用"软垫/护具/后怕"三件套温和化；动物只做温和互动 |
