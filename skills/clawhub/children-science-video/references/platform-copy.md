# 双平台爆款文案规范（Step 5 文案与PDF时读）

## 一、通用要求

- 标题：抖音/小红书各≤20字，带钩子（悬念/警告/反差），可含1个emoji。
- 正文：可直接粘贴发布，禁止出现占位符（如"XXX"）、禁止营销感过重的话术。
- 标签：每平台 5-8 个，大词+精准词组合（如 #儿童运动安全 + #滑板车安全）。

## 二、抖音版

- 标题：短促、带冲突感，如 `双手离开把手，会发生什么？`
- 正文：3-5行短句，第一行复述钩子，中间给知识点，结尾抛互动问题；适度emoji。
- 标签示例：#儿童运动安全 #滑板车安全 #户外玩耍规范 #儿童科普 #家长必看 #安全第一

## 三、小红书版

- 标题：可带emoji与身份感，如 `滑板车安全第一课🚨松手真的不行！`
- 正文：emoji分段（💡⚠️✅）、编号列表（1️⃣2️⃣3️⃣）讲正确做法，结尾互动提问；育儿干货口吻。
- 标签示例：#儿童运动安全 #滑板车 #儿童安全防护 #育儿知识 #儿童科普动画 #家长必看

## 四、PDF 生成（必须走技能自带脚本）

```bash
python scripts/make_platform_pdf.py "{文案标题}/{文案标题}_双平台发布文案.md" "{文案标题}/{文案标题}_双平台发布文案.pdf"
```

- Markdown 源稿同样写入 `{文案标题}/` 文件夹内，与 PDF 同级，方便一起归档。

- 输入 Markdown 结构约定：`# 文档标题`、`## 平台名`、`### 标题/正文/话题标签`、`- 列表项`、`标签：`开头的行渲染为楷体强调。
- 脚本已注册 SimSun（正文）/SimHei（标题）/SimKai（强调），A4 排版；emoji 会被自动剔除并在文末提示"emoji以平台编辑器为准"。
- 脚本报字体缺失时：确认系统存在 `C:\Windows\Fonts\simsun.ttc / simhei.ttf / simkai.ttf`，或在脚本 FONT_CANDIDATES 中补充本机字体路径。

## 五、发布小贴士（写进PDF末尾）

- 发布时间：工作日 12:00-13:00 / 18:00-20:00，周末 9:00-11:00（儿童受众家长活跃段）。
- 封面用 Step 4 的竖/横封面，抖音选横版、小红书选竖版。
- 前3秒口播对应分镜1的冲突钩子，完播率关键。
- 评论区置顶提问（分镜5的结尾问题），引导互动。
