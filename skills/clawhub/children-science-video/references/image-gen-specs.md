# 9:16 配图生成规范（Step 6 配图时读）

## 一、工具与参数

调用 ImageGen 工具（文生图），关键参数：

| 参数 | 值 | 说明 |
|---|---|---|
| prompt | 分镜表「文生图提示词」列全文 | 基准块必须在最前 |
| size | `720x1280` | 9:16 竖屏，与短视频画幅一致 |
| quality | `high` | 保证人物细节与文字元素 |
| style | `3D卡通 / 儿童绘本`（按工具当前支持填写） | 与画风串一致 |
| output_dir | `{主题}/` | 产物落盘目录 |

**积分提醒**：图片生成消耗积分（每张约5-10 credits），批量生成前必须告知用户并得到确认。

## 二、执行流程

1. 逐镜调用 ImageGen，产物命名 `分镜图_01.png` ~ `分镜图_05.png`。
2. 每镜生成后立即 Read 查看，按第三节清单目检。
3. 不合格重掷（同提示词再生成，最多3次）；仍不合格则微调提示词（删冲突元素、把基准块提前、情绪词具体化）。
4. 5张全部通过后汇总交付，并提醒可衔接 agnes-video-flash（reference 模式）出视频。

## 三、目检清单（每张）

- [ ] 人物一致：脸型/发型/服装/配色与其他镜一致
- [ ] 情绪正确：该镜主导情绪词有体现
- [ ] 场景道具：与剧情要点一致（滑板车同款、护具齐全等）
- [ ] 文字元素：安全标志/文字气泡存在且可辨（乱码可接受后期贴字，但标志牌位置要对）
- [ ] 无违规：无血腥、无真实品牌、无畸形手指/多肢体

## 四、中文文字稳定性处理

生成模型渲染长句中文容易乱码：
- 提示词中文字内容控制在 8 字以内（如"危险 请勿松手"）。
- 乱码不影响使用：文字信息主要由配音与后期贴字传达；封面大标题见 cover-specs.md 第六节。

## 五、人物一致性强化技巧

- 基准块置于 prompt 最前，场景描述在后，减少场景对人物的"带偏"。
- 可用 image-to-image 追一致：以最满意的一张为 image1、input_fidelity 调高，再生成其他镜（保持同一人物）。
- 极端不一致时，改用「先定妆图、后 reference 模式出视频」工作流（见 agnes-video-flash 技能）。
