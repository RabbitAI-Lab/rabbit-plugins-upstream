# 9:16 配图生成规范（Step 6 配图时读）

## 〇、目录与命名（硬性约定，先看这节）

1. **总目录**：开工第一步就创建 `{文案标题}/` 文件夹（文案标题即 Step 1 的主题名，做合法文件名字符清洗），本次任务的**全部产物**都放进这个文件夹，方便查找。
2. **图片子目录**：`{文案标题}/images/`。
3. **图片文件名只用分镜脚本序号**：`01.png`、`02.png`、`03.png`、`04.png`、`05.png`（两位数补零）。
   - ❌ 禁止：`分镜图_01.png`、`01_滑板车.png`、`主题_01_v2.png`、中文文件名。
   - ✅ 唯一例外：封面图另存 `{文案标题}/cover/`，命名 `cover_3x4.png` / `cover_4x3.png`。
4. **同名即同镜**：图片 `01.png` 与视频 `01.mp4` 必须来自同一个分镜，序号一一对应，不得错位或跳号。

目录结构总览：

```text
{文案标题}/
├── {文案标题}_视频文案.md
├── {文案标题}_分镜头脚本表.md
├── {文案标题}_封面提示词.md
├── {文案标题}_双平台发布文案.pdf
├── images/          01.png ~ 05.png
├── videos/          01.mp4 ~ 05.mp4
└── cover/           cover_3x4.png / cover_4x3.png
```

## 一、工具与参数

调用 ImageGen 工具（文生图），关键参数：

| 参数 | 值 | 说明 |
|---|---|---|
| prompt | 分镜表「文生图提示词」列全文 | 所有角色基准块必须在最前 |
| size | `720x1280` | 9:16 竖屏，与短视频画幅一致 |
| quality | `high` | 保证角色细节与文字元素 |
| style | `3D卡通 / 儿童绘本`（按工具当前支持填写） | 与画风串一致 |
| output_dir | `{文案标题}/images/` | 产物落盘目录 |
| 文件名 | `{序号}.png` | 序号 = 分镜脚本序号，两位补零 |

**积分提醒**：图片生成消耗积分（每张约5-10 credits），批量生成前必须告知用户并得到确认。

## 二、执行流程

1. 先创建 `{文案标题}/images/`，再逐镜调用 ImageGen，产物命名 `01.png` ~ `05.png`。
2. 每镜生成后立即 Read 查看，按第三节清单目检。
3. 不合格重掷（同提示词再生成，最多3次）；仍不合格则微调提示词（删冲突元素、把基准块提前、情绪词具体化）。重掷时**覆盖同名文件**，不要生成 `01_2.png` 这类副本。
4. 5张全部通过后，**逐张确认可作为图生视频首帧**：构图完整、主体不贴边、角色无畸形、画面留白足够容纳动作。首帧不合格直接返工，不要带到视频环节。
5. 汇总交付并继续 Step 7（用这5张图作首帧生成视频）。

## 三、目检清单（每张，全角色逐项过）

**儿童主角**
- [ ] 形象一致：脸型/发型/服装/配色/装备与其他镜一致
- [ ] 情绪正确：该镜主导情绪词有体现
- [ ] 身体正常：手指数量正确，无多肢体、无关节扭曲

**动物/植物/拟人角色（出场即检）**
- [ ] 物种一致：没有跨镜漂移（蜜蜂不会变成苍蝇，向日葵不会变成雏菊）
- [ ] 配色一致：主色与辅色位置、比例与其他镜相同
- [ ] 结构一致：肢体/翅/触角/腿的数量、花瓣数、叶形、株高比例与其他镜相同
- [ ] 五官一致：眼睛形状位置、嘴型风格不变，拟人化程度不忽高忽低
- [ ] 画风一致：与儿童主角共用同一套质感与色调，无写实化倾向

**通用**
- [ ] 场景道具：与剧情要点一致（滑板车同款、护具齐全等）
- [ ] 文字元素：安全标志/文字气泡存在且可辨（乱码可接受后期贴字，但标志牌位置要对）
- [ ] 首帧可用：构图完整、主体不贴边、留有动作空间，能直接作为该镜视频首帧
- [ ] 命名正确：文件名就是分镜序号（`01.png`~`05.png`），落在 `{文案标题}/images/` 内
- [ ] 无违规：无血腥、无真实品牌、无动物受虐、无畸形

## 四、中文文字稳定性处理

生成模型渲染长句中文容易乱码：
- 提示词中文字内容控制在 8 字以内（如"危险 请勿松手"）。
- 乱码不影响使用：文字信息主要由配音与后期贴字传达；封面大标题见 cover-specs.md 第六节。

## 五、全角色一致性强化技巧

- **所有角色基准块置于 prompt 最前**，场景描述在后，减少场景对形象的"带偏"。
- **先出定妆图**：正式逐镜生成前，先用一张图把所有出场角色（儿童 + 各动植物）放在一起定妆，确认形象满意后再作为一致性参考。
- 可用 image-to-image 追一致：以定妆图或最满意的一张为 image1、input_fidelity 调高，再生成其他镜（保持全部角色同一形象）。
- 动植物比人物更容易漂移：提示词里把物种名、配色、部件数量写成**具体数字**（"六条细腿""12片花瓣""黄黑相间绒毛"），不要写"可爱的小蜜蜂"这类模糊描述。
- 极端不一致时，改用「先定妆图、后 reference 模式出视频」工作流（见 agnes-video-flash 技能）。
