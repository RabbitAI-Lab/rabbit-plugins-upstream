# 人物形象一致性规范（最高优先级，写文生图提示词前必读）

## 一、人物形象基准块（模板）

所有文生图提示词必须**原样包含**以下基准块，只允许按第二节规则替换 `{情绪词}` 与 `{着装}` 两个变量，禁止改写、增删、调整语序：

```text
3D卡通渲染风格，一个中国小男孩，约3-6岁，中国儿童典型面孔，鹅蛋脸型，圆润大眼睛，双眼皮，睫毛清晰，眼神温柔安静，粉嫩圆脸，皮肤细腻白皙带健康红润，黑色柔顺短发，无多余发饰，嘴唇粉嫩，表情{情绪词}，简约可爱日常童装（{着装}），全身Q版比例，软乎乎毛绒质感，柔和暖光，无厚重阴影，符合当前科普文案背景，高细节，高清画质，儿童绘本风格，治愈温柔色调，童趣治愈氛围，简约卡通场景，低饱和度清新色调，动态流畅自然，立体通透，适合儿童科普动画人物
```

## 一之二、动植物形象基准块（凡分镜出现动物/植物/拟人角色，必须使用）

儿童科普常出现动物（蜜蜂、恐龙、小鸭子）、植物（向日葵、含羞草）、拟人器官（小胃、小肺）等 3D 形象。这类形象**同样要全分镜一致**：每个选题**只定义一次**基准块，此后所有分镜原样复用，只允许替换 `{情绪词}`、`{动作姿态}`。

### 动植物形象锁定铁律

1. **一个选题一套基准块**：在 `{文案标题}/{文案标题}_分镜头脚本表.md` 顶部「角色设定」处写全所有出场角色的完整基准块（主角儿童 + 每个动植物角色各一段），后续分镜**只引用、不重写**。
2. **禁止逐镜改设定**：物种、年龄/生长阶段、配色、五官描述、体型比例、随身特征六项零改动；跨镜只允许变 `{情绪词}` 与 `{动作姿态}`。
3. **多角色同框**：按出场顺序排列各自基准块，中间用「，画面中还有」衔接，禁止把两个角色的特征混写进同一段。
4. **画风参数串统一**：动植物与儿童主角必须共用第四节同一套画风参数串，保证全片质感一致。
5. **写实红线**：不做写实动物/植物（避免恐怖谷与解剖细节）；不出现真实品牌、其他 IP 卡通形象、危险物种攻击画面；动物不流血、不受虐。

## 二、变量区（每个选题只定义一次，全分镜锁定）

- `{着装}` 默认值：`亮橙色短袖T恤，胸前浅蓝色小火箭图案，卡其色休闲短裤，白色运动鞋，浅灰短袜`
- 安全教育类选题可叠加装备（头盔/护膝/护肘），叠加时描述同样全分镜统一，如 `戴红色头盔、护膝、护肘`
- 若用户指定了着装或形象，以用户为准，但同样全部分镜锁定，禁止逐镜变化
- 备用主色（用户想换人物时整体替换，不可混搭）：明黄 / 湖蓝 / 草绿

## 三、情绪词微调规则（唯一允许的变量）

基准块中 `表情{情绪词}` 按剧情从下表选一个主导情绪词，每个分镜只选一个：

| 情绪词 | 适用剧情 |
|---|---|
| 得意兴奋 | 错误示范、耍酷开场 |
| 好奇地睁大眼睛 | 提问、发现新知识 |
| 认真专注 | 讲解原理、示范正确动作 |
| 惊讶皱眉 | 危险发生瞬间 |
| 紧张后怕 | 摔倒后的反应 |
| 委屈要哭 | 摔疼了但温和不血腥 |
| 开心地笑 | 正确做法、快乐收尾 |
| 恍然大悟 | 明白道理 |
| 俏皮地眨眼 | 与观众互动、结尾提问 |

禁止改动五官描述、脸型、发型、年龄、着装、画风参数。

## 三之二、动植物角色的情绪表达（不能照搬人类的眉眼描述）

动物/植物没有人类的眉毛与发型，情绪要落到它们**真实拥有的身体部件**上，且全片同一情绪用同一套写法：

| 情绪 | 动物写法 | 植物写法 |
|---|---|---|
| 得意兴奋 | 昂首挺胸，翅膀/尾巴高高翘起，眼睛弯成月牙 | 花盘向上抬高，花瓣张开，叶片上翘 |
| 好奇 | 头部前倾，触角竖起微微颤动，复眼睁圆 | 花盘歪向一侧，叶片轻轻展开 |
| 认真专注 | 身体站直，目光紧盯前方，翅膀收拢 | 茎秆挺直，花盘正对目标不晃动 |
| 惊讶 | 全身一震，翅膀猛地张开，触角后仰 | 花瓣瞬间收紧，叶片向后微缩 |
| 紧张后怕 | 缩起脖子，翅膀贴在身侧抖动，腿微曲 | 叶片下垂，花盘略低，茎秆轻晃 |
| 委屈要哭 | 眼睛湿润反光，嘴角下撇，触角耷拉 | 花瓣边缘垂落，叶片向下卷 |
| 开心地笑 | 眯眼大笑，翅膀轻快扇动，尾巴摇摆 | 花盘舒展，花瓣层层张开，叶片轻摆 |
| 恍然大悟 | 头微微一点，触角亮起，眼睛放光 | 花盘轻轻抬起，叶尖向上 |
| 俏皮互动 | 单眼眨动，翅膀比出小手势，头歪向镜头 | 一片花瓣轻轻卷起，花盘朝镜头倾斜 |

拟人器官/微生物参照动物列，把「翅膀/触角」替换为其固定结构特征（叶瓣/纤毛/伪足）。

## 四、画风参数串（基准块尾部已内置，禁止改动）

`软乎乎毛绒质感，柔和暖光，无厚重阴影，儿童绘本风格，治愈温柔色调，童趣治愈氛围，高细节，高清画质，立体通透，低饱和度清新色调，动态流畅自然`

儿童、动物、植物、拟人角色**共用同一套画风参数串**，禁止为某个角色单独换质感或色调。

## 五、文生图提示词组装公式

```text
[主角人物形象基准块] + [同框动植物角色基准块（每个角色一段，按出场顺序）] + [当前场景：地点/道具/背景] + [各角色动作姿态] + [画面文字元素：文字气泡/安全标志/警告信息，写清文字内容与样式] + 9:16竖构图
```

- 只有单一角色出场时，省略其余基准块，但已出场角色的基准块**不得简写或省略关键特征**。
- 基准块一律置于 prompt 最前，场景与文字元素在后，减少场景对形象的"带偏"。

## 六、一致性自检

1. **Diff 检验（全角色）**：抽出所有提示词中从 `3D卡通渲染风格` 到基准块结尾（`适合儿童科普动画人物` / `适合儿童科普动画角色`）的整段，**逐个角色**比对；除 `{情绪词}`、`{着装}`（含装备叠加）、`{动作姿态}` 外必须完全相同。
2. **角色清单核对**：把分镜表顶部「角色设定」里列出的每个角色，在5个分镜提示词中逐一打勾，缺一个即返工。
3. **目检**：配图生成后比对5张图——儿童看脸型/发型/服装/配色；动物看物种/配色/五官/翅尾腿数量；植物看花色/花瓣数/叶形/株高比例。不一致的重掷，或把该角色基准块移到提示词最前并去掉与之冲突的场景描述。
4. 图生视频阶段同样以基准块描述锁定所有角色，防止视频生成时角色"长变形"或物种漂移（如蜜蜂变苍蝇、向日葵变雏菊）。
