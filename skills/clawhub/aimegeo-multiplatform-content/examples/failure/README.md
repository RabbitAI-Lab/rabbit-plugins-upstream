# 失败输入与预期处理

这些是故意无效的离线夹具，不是用户案例或可用文章。运行 `python3 scripts/self_test.py` 会在临时目录复制成功包并应用失败输入，不修改原样例。

| 输入 | 操作 | 业务结果 |
| --- | --- | --- |
| [容量冲突.md](容量冲突.md) | 在成功包副本中替换 `xiaohongshu.md` | `FACT_MISMATCH`，因为本稿容量与已登记来源不一致；不能交接成事实一致的稿件包 |
| [缺少来源列.csv](缺少来源列.csv) | 交给 CSDN 正文中的 `preflight.py` | 退出 2，报 `缺少必填列 title 或 source` |
| [空来源.csv](空来源.csv) | 交给同一预检代码 | 退出 2，指出第 1 条记录的必填值为空 |

自检还构造原稿保留/局部改稿、超出 200 条资料、错误编码、缺图冒充可用、目录外路径和查询失败却填 0 等情况。任何失败都保留具体状态，不用新造数字、重写整篇或自动发布来掩盖失败。
