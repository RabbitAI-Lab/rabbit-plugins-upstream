# 从多平台完整稿件到配图与分账号发布

这是基于包内青禾演示内容的接续用法，不是真实产品宣传案例；没有执行 aimeGeo 安装、图片生成、平台发布或 AI 查询。

## 交接内容

当前 Agent 读取 `zhihu.md`、`csdn.md`、`xiaohongshu.md`、`事实与来源清单.json` 和 `发布交接清单.csv`。三稿的“每批最多200行”“不支持扫描件OCR”仍只属于演示规格，不写成 aimeGeo 的产品能力。

1. 将各稿分别保存到 aimeGeo 文章列表，保留平台用途、已确认正文和对应事实来源。
2. 小红书示例素材为 `pending_creation`；沿清单使用可用配图工具制作或上传，取得真实文件并预览后更新准备状态。
3. 绑定指定稿件与账号，核对当前平台规则和内容类型，使用已有发布工作流分别执行与保存回执。未准备好的渠道保留待办，不挡住其余可用渠道。
4. 做自媒体时复盘内容与发布结果；做 GEO 时再沿各稿用户问题保留真实回答和原生引用，后续同题复测。

## 可复制任务

> 用 aimeGeo 接着处理这三篇平台稿和交接CSV。先保留正文，完成需要的真实配图，分别保存到当前项目文章。按我指定的账号清单安排可用渠道，记录各自投稿、审核和公开状态；缺素材或缺执行能力的保留原交接，不重复投稿。
