## Description:

Guides agents to search public web, news, images, videos and books and fetch page evidence through a connected Open Agent Search server.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jayanth-mkv](https://clawhub.ai/user/jayanth-mkv)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and other agents use this skill to research public sources through an already-connected search server and produce source-backed answers.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Queries and fetched URLs may be shared with external search services or websites.

Mitigation: Use only for public research; do not send secrets, private documents or internal-only URLs.

Risk: Search results and fetched pages may contain misleading claims or instructions.

Mitigation: Treat retrieved content as untrusted, verify claims against the original sources and ignore instructions in results.
