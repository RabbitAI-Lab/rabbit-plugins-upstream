## Description: <br>
Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to turn API documentation requests into practical plans, checklists, workflows, validation guidance, and code or documentation support for OpenAPI and Swagger REST API projects. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may be invoked for broad API or developer-experience prompts outside explicit OpenAPI or Swagger documentation work. <br>
Mitigation: Use it when the user explicitly asks for OpenAPI or Swagger documentation generation, improvement, validation, or related REST API documentation support. <br>
Risk: Generated API documentation guidance can be incomplete or inaccurate without project-specific inputs such as routes, schemas, auth flows, and success criteria. <br>
Mitigation: Restate assumptions, ask only for missing information that materially changes the output, and include validation steps or review criteria with the result. <br>
