# 产品参考绑定最佳实践

## 标准绑定模板（强制使用）

```
@Image1 仅定义产品正面外观、Logo 位置、颜色、材质和整体轮廓，忽略背景与任何人物。
@Image2 仅定义产品侧面 / 安装状态 / 使用中的样子，忽略背景。
@Image3 仅定义产品细节（控制面板、出水口、按键、纹理），忽略整体场景。
@Image4（如有）仅定义主播出镜外貌、发型、服装风格，忽略背景。
产品在整个视频中必须与参考图保持完全一致，无变形、无扭曲、Logo 清晰可读。
```

## 绑定原则
1. 一张图只负责一个明确属性
2. 必须写「忽略什么」（背景、人物、其他产品）
3. 多张产品图共同定义同一个产品，禁止出现第二个不同外观的产品
4. 人物参考与产品参考严格分离

## 推荐上传优先级
1. 产品正面高清图（必须）
2. 产品侧面 / 安装实拍图（强烈推荐）
3. 产品细节特写（强烈推荐）
4. 主播出镜参考图（可选）
5. 使用场景参考（可选）
