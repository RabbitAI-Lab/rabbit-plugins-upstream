# Seedance 2.5 导演级提示词结构专业参考

## 推荐完整结构（默认使用）

```
CAMERA: [详细相机物理与运动描述]
LOOK: [视觉质感、胶片感、曝光、颗粒]
STYLE: [整体风格与表演方式]
CHARACTER: [人物外貌、服装、气质]
SETTING: [场景环境细节]
SCENES: [连续动作 + 对白交织的时间线]
```

## CAMERA 必备元素
- 画幅：垂直 9:16
- 拍摄方式：手持手机自拍模式
- 三大真实感参数（必须默认包含）：
  - subtle natural micro-shake
  - slight exposure breathing
  - occasional autofocus hunting with brief soft focus moments
- 构图缺陷：imperfect framing, occasional head crop, drifting composition
- 相机不可见：camera itself is never visible

## SCENES 写作原则
1. 动作与对白深度交织，而不是先说完再做动作
2. 对白简短、口语、有停顿
3. 每段动作自然触发相机物理变化（抖动、曝光、对焦）
4. 产品露出要自然，不要硬塞

## 时间线建议（25秒口播）
- 0-4s：个人化钩子 + 痛点共鸣
- 4-12s：产品引入 + 核心卖点
- 12-20s：细节演示 / 结果展示
- 20-25s：软性 CTA + 收尾

## 负面约束模板
产品外观、Logo、颜色、材质始终与参考图完全一致，无变形、无扭曲；主播自然对镜头说话，口型同步；无随机字幕、无多余文字、无专业广告灯光；保持手机手持 UGC 真实感。
