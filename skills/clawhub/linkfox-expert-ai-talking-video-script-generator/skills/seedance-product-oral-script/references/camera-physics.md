# Seedance 2.5 镜头物理参数专业参考

## 1. 手持抖动（Handheld Shake）

### 强度分级
| 强度 | 推荐提示词 | 适用场景 |
|------|-----------|---------|
| 极轻 | `subtle handheld micro-shake` / `very subtle natural phone sway` | 产品特写、需要看清细节 |
| 轻度（默认推荐） | `subtle natural micro-shake` / `natural slight phone shake` | 大多数美式 UGC 口播 |
| 中度 | `natural handheld shake` / `mild camera shake with breathing motion` | 走动中的自拍 |
| 较强 | `noticeable handheld shake` / `real phone-style jitter` | 兴奋、紧急场景 |

### 高效果组合
```
subtle natural micro-shake, imperfect framing, occasional head crop, real phone-style movement
```

## 2. 曝光呼吸（Exposure Breathing）

### 推荐写法
- 极轻：`subtle exposure breathing`
- 轻度（推荐）：`slight exposure breathing` / `natural exposure fluctuations`
- 中度：`realistic exposure breathing with slight brightness shifts`

### 最佳实践
与手持抖动一起写效果最强：
```
subtle exposure breathing, slight brightness fluctuations from auto-exposure
```

## 3. 自动对焦（Auto Focus Hunting）

### 推荐写法
- 极轻：`occasional subtle autofocus hunting`
- 轻度（推荐）：`slight autofocus hunting` / `occasional autofocus search with brief soft focus moments`
- 中度：`noticeable autofocus hunting`

### 产品特写注意
产品需要看清时，降低强度：`minimal autofocus hunting, keep product sharp most of the time`

## 4. 三大真实感参数黄金组合（强制默认）

```
subtle natural micro-shake, slight exposure breathing, occasional autofocus hunting with brief soft focus moments, imperfect framing, real phone-style movement
```

## 5. 使用原则
1. 永远用 subtle / slight / occasional 修饰，避免过度
2. 三个参数建议同时出现，真实感叠加
3. 产品特写时适当降低自动对焦强度
4. 光线变化场景可主动触发曝光呼吸
