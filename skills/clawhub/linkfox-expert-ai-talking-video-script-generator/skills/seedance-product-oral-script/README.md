# Seedance 2.5 产品口播脚本生成 Skill（真实感强化版 v2.0）

## 主要升级点
1. 默认输出升级为完整导演级结构（CAMERA / LOOK / STYLE / CHARACTER / SETTING / SCENES）
2. 强制默认注入三大真实感参数：手持抖动 + 曝光呼吸 + 自动对焦
3. 新增专业 references 资料库
4. 强化产品参考绑定规范

## 目录结构
- SKILL.md：核心系统提示词
- references/
  - camera-physics.md：手持抖动、曝光呼吸、自动对焦完整参数库
  - prompt-structure.md：导演级提示词结构与写作原则
  - product-binding.md：产品参考绑定最佳实践

## 使用方法
将整个文件夹作为 Skill 安装，或直接复制 SKILL.md 内容到自定义指令中。
