# FactorLab 因子理论参考

> 本文档详细说明 FactorLab 多因子模型的因子定义、计算方法、评分规则和购买建议逻辑。
> 基于《开源证券·金融工程》系列研报整理。

---

## 一、因子切割论

### 核心三要素

| 要素 | 说明 | 示例 |
|------|------|------|
| **对象** | 具有可加性的变量 | 涨跌幅、振幅、Alpha收益 |
| **刀法** | 具有区分力的切割变量 | 平均单笔成交额、收盘价、振幅 |
| **产出** | 高组均值 - 低组均值 | M_high - M_low |

### 切割方法

1. 将"刀法"变量排序
2. 取前 `high_pct` 比例为高组，后 `high_pct` 比例为低组
3. 计算两组"对象"变量的均值
4. 产出 = high_val - low_val（或 low_val - high_val，视因子方向）

## 二、三大核心因子

### F1: 理想反转因子 (Ideal Reversal)

| 项目 | 内容 |
|------|------|
| **对象** | 20日涨跌幅 |
| **刀法** | 20日平均单笔成交金额 |
| **产出** | M_high - M_low (high_minus_low) |
| **high_pct** | 0.5 |
| **方向** | 值越负越好（反转效应越强） |

**解读**: 以成交活跃度为刀，切割涨跌幅。如果低成交额组的涨幅显著高于高成交额组（值为负），说明反转效应强——即前期被忽视的股票反而表现更好，这是经典反转策略的基础。

### F2: 理想振幅因子 (Ideal Amplitude)

| 项目 | 内容 |
|------|------|
| **对象** | 20日振幅 |
| **刀法** | 20日收盘价 |
| **产出** | M_high - M_low (high_minus_low) |
| **high_pct** | 0.25 |
| **方向** | 值越负越好 |

**解读**: 以价格为刀，切割振幅。如果高价股的振幅小于低价股（值为负），说明高价股波动更小、结构更健康，市场对高价股的定价更理性。

### F3: 长端动量因子 (Long Momentum)

| 项目 | 内容 |
|------|------|
| **对象** | 160日Alpha收益（日收益减均值） |
| **刀法** | 160日振幅 |
| **产出** | low_val - high_val (low_minus_high) |
| **high_pct** | 0.3 |
| **方向** | 值越大越好 |

**解读**: 以振幅为刀，切割Alpha收益。取低振幅组的Alpha减去高振幅组的Alpha。如果低振幅日的Alpha收益显著为正，说明股票在平稳期持续积累收益，动量持续性强。

## 三、因子的子分映射

### 理想反转因子 -> 子分 (0-100)

| 原始值范围 | 子分 | 含义 |
|------------|------|------|
| < -0.03 | 100 | 反转效应极强 |
| -0.03 ~ -0.02 | 85 | 反转效应强 |
| -0.02 ~ -0.01 | 70 | 反转效应较好 |
| -0.01 ~ 0 | 55 | 反转效应一般 |
| 0 ~ 0.01 | 40 | 反转效应弱 |
| ≥ 0.01 | 25 | 无反转效应 |

### 理想振幅因子 -> 子分 (0-100)

| 原始值范围 | 子分 | 含义 |
|------------|------|------|
| < -0.015 | 100 | 振幅结构极优 |
| -0.015 ~ -0.008 | 80 | 振幅结构良好 |
| -0.008 ~ -0.003 | 65 | 振幅结构尚可 |
| -0.003 ~ 0 | 50 | 振幅结构一般 |
| 0 ~ 0.005 | 35 | 振幅结构偏差 |
| ≥ 0.005 | 20 | 振幅结构差 |

### 长端动量因子 -> 子分 (0-100)

| 原始值范围 | 子分 | 含义 |
|------------|------|------|
| > 0.08 | 100 | 动量极强 |
| 0.05 ~ 0.08 | 85 | 动量强 |
| 0.02 ~ 0.05 | 70 | 动量较好 |
| 0 ~ 0.02 | 55 | 动量一般 |
| -0.02 ~ 0 | 40 | 动量弱 |
| ≤ -0.02 | 25 | 动量极弱 |

## 四、综合评分 (FactorLab Score)

```
FactorLab Score = 理想反转子分 × 35% + 理想振幅子分 × 30% + 长端动量子分 × 35%
```

| 评分范围 | 信号 | 图标 |
|----------|------|------|
| ≥ 85 | 强势买入 | 🔥 |
| 70 - 84 | 关注 | ✅ |
| 55 - 69 | 留意 | ⚡ |
| < 55 | 回避 | ❌ |

## 五、购买建议逻辑

### 建议等级

| FactorLab评分 | 建议 | 置信度 | 操作指引 |
|--------------|------|--------|----------|
| ≥ 80 | 强烈推荐买入 | ≥ 85% | 三因子共振，逢低布局 |
| ≥ 65 | 建议买入 | ≥ 65% | 小仓位试探，设好止损 |
| ≥ 50 | 观望 | ≥ 50% | 等待更明确信号 |
| < 50 | 不建议买入 | ≥ 80% | 风险大于收益，暂回避 |

### 看多理由触发条件

- 理想反转因子原始值 < -0.02 → 反转效应显著
- 理想振幅因子原始值 < -0.008 → 振幅结构良好
- 长端动量因子原始值 > 0.05 → 动量持续性强
- 三因子全部达标 → "三因子共振，多维度验证一致看多"

### 风险触发条件

- 各因子未达阈值
- 三因子均未达标 → "因子面全面偏空"
- 当日跌幅 > 3% → 短期承压
- 历史数据 < 160根K线 → 长端动量无法计算

## 六、数据源说明

| 模式 | 数据源 | 说明 |
|------|--------|------|
| 实时模式 (默认) | 通达信TDX行情服务器 | 通过pytdx连接，获取实时行情和历史K线 |
| 模拟模式 (--no-live) | 随机模拟数据 | 基于股票代码种子生成确定性模拟数据，用于测试 |

> ⚠️ 模拟数据仅用于测试因子计算逻辑，不反映真实市场情况。实际使用应确保TDX服务器连接正常。

---

## 七、注意事项

1. **数据要求**: 长端动量因子需要至少160根日K线数据，数据不足时该因子得分为0。
2. **因子方向**: 理想反转和理想振幅因子值越负越好；长端动量因子值越大越好。
3. **评分局限**: 因子模型基于历史数据，不保证未来收益。
4. **风险提示**: 本系统仅作为量化研究工具，不构成投资建议。投资有风险，入市需谨慎。
