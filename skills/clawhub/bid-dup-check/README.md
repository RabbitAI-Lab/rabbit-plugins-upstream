# 标书查重专家（bid-dup-check）

标书查重与围串标风险**初筛**助手：上传多份投标 / 招标文件，自动解析、语义比对、碰撞检测，输出含风险等级与定位的结构化检测报告（支持 Word / Markdown 导出）。适用于**投标人自检与招标人初步筛查**，**不替代评标委员会正式判定**，也不替代专业查重系统或法律判定。

## 功能特性

- **关键信息碰撞**：公司名称 / 公司简称、项目经理、造价师、联系电话、邮箱、开户行与账号、法人 / 授权代表、注册地址、统一社会信用代码。
- **文本语义相似度**：定性锚定定级（高 / 中 / 低），识别直接复制、同义改写、结构相似。
- **文档属性预警**：作者、最后作者、公司、创建 / 修改时间比对。
- **表格内容相似度**：报价表 / 清单表结构对比。
- **差异比对**：仅两份文档时触发段落级增 / 删 / 改。
- **基线剔除**：提供招标文件时剔除「大家都照抄招标书」造成的误报。
- **工程健壮性**：内联输出 Schema + 思维链 + 自检清单、错误处理与降级、上下文管理与长文档分流、隐私与脱敏、统一署名与反馈脚注。

## 使用方式

1. 上传 2–10 份 `.docx` / `.pdf`（含文本层）/ `.txt` 标书；
2. 技能自动解析 → 语义分析 → 渲染报告；
3. 查看三层递进结果（3 句话摘要 → 结构化报告 → 下载链接）。

## 文件结构

- `SKILL.md` — 技能指令（给 AI 智能体的行为准则）
- `manifest.yaml` — 技能元数据（名称 / 版本 / 作者 / 反馈渠道）
- `README.md` — 本说明文档
- `references/detection_rules.md` — 敏感字段、定级锚点、基线剔除、报告结构（Step 4 的补充参考，非独立权威）
- `scripts/extract_documents.py` — 文档结构化提取
- `scripts/build_report.py` — 报告渲染（含统一署名脚注）
