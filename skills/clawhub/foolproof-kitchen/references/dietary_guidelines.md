# 《中国居民膳食指南(2022)》核心数据与营养科学参考

> 本文件依据中国营养学会发布的《中国居民膳食指南(2022)》现行版编制。
> 截至 2026 年 8 月，2022 版仍为最新正式版（第五次修订工作会议已于 2026 年 1 月召开，新版尚未发布）。

## 一、每日推荐摄入量（18-64 岁成人）

### 1.1 食物类别推荐量（2022 版）

| 食物类别 | 每日推荐量 | 说明 |
|---------|-----------|------|
| 谷类 | 200-300g | 其中全谷物和杂豆 50-150g |
| 薯类 | 50-100g | 鲜重 |
| 蔬菜类 | 不少于 300g | 深色蔬菜应占 1/2 |
| 水果类 | 200-350g | 果汁不能代替鲜果 |
| 畜禽肉 | 300-500g/周（约 43-71g/天） | 优先选择禽肉，少吃肥肉、烟熏和腌制肉 |
| 水产品 | 300-500g/周（约 43-71g/天） | 每周最好吃鱼 2 次 |
| 蛋类 | 300-350g/周（约 43-50g/天） | 约 1 个鸡蛋/天，吃鸡蛋不弃蛋黄 |
| 奶及奶制品 | 相当于 300ml 以上液态奶 | 可选择酸奶、奶酪等多样化奶制品 |
| 大豆及坚果 | 25-35g | 大豆 25g ≈ 北豆腐 75g ≈ 豆浆 360ml |
| 烹调油 | 25-30g | 约 2-3 汤匙 |
| 食盐 | 不超过 5g | 约一个啤酒瓶盖的量 |
| 添加糖 | 不超过 50g，最好 25g 以下 | 反式脂肪酸每天不超过 2g |
| 饮水 | 男性 1700ml / 女性 1500ml | 少量多次，白水或茶水为主 |

> **鱼禽蛋瘦肉合计**：平均每天 120-200g（2022 版新提法，不再单独拆分每日量）

## 二、能量需求计算公式

### 2.1 Mifflin-St Jeor 公式

**基础代谢率 (BMR)**：

- 男性：BMR = (10 × 体重kg) + (6.25 × 身高cm) - (5 × 年龄) + 5
- 女性：BMR = (10 × 体重kg) + (6.25 × 身高cm) - (5 × 年龄) - 161

### 2.2 每日总能量消耗 (TDEE)

| 活动水平 | 系数 | 描述 |
|---------|------|------|
| 久坐不动 | 1.2 | 几乎不运动，办公室工作 |
| 轻度活动 | 1.375 | 每周轻运动 1-3 天 |
| 中度活动 | 1.55 | 每周中强度运动 3-5 天 |
| 高度活动 | 1.725 | 每周高强度运动 6-7 天 |
| 极度活跃 | 1.9 | 高强度体力劳动或专业运动员 |

**默认使用轻度活动系数 (1.375)**，除非用户明确说明运动量。

## 三、三餐热量分配建议

| 餐次 | 热量占比 | 说明 |
|------|---------|------|
| 早餐 | 30% | 保证优质蛋白+复合碳水 |
| 午餐 | 35% | 全天最丰盛的一餐 |
| 晚餐 | 25% | 相对清淡，易消化 |
| 加餐 | 10% | 水果/坚果/奶制品 |

## 四、特殊人群饮食调整

### 4.1 糖尿病/高血糖

- 控制总热量，维持理想体重
- 选择低 GI 主食：燕麦、荞麦、糙米、全麦面包
- 蔬菜每日 500g 以上，优先绿叶蔬菜
- 蛋白质来源：鱼、去皮禽肉、豆制品
- 严格限制添加糖、含糖饮料、甜点
- 定时定量，少食多餐

### 4.2 高血压

- 严格控盐，每日 < 5g（最好 < 3g）
- 增加钾摄入：香蕉、土豆、菠菜、豆类
- 增加钙摄入：低脂奶、豆制品
- 减少饱和脂肪，增加不饱和脂肪酸
- 限制酒精

### 4.3 高尿酸/痛风

- 限制高嘌呤食物：动物内脏、浓肉汤、沙丁鱼、贝类
- 中等嘌呤适量：畜禽肉、鱼类、豆制品（适量）
- 鼓励低嘌呤：蔬菜、水果、奶制品、蛋类、谷物
- 每日饮水 > 2000ml，促进尿酸排泄
- 限制酒精，尤其是啤酒

### 4.4 孕期

- 孕早期（1-3 月）：维持孕前热量，补充叶酸 400μg/天
- 孕中期（4-6 月）：+300 kcal/天，增加蛋白质 15g/天
- 孕晚期（7-9 月）：+450 kcal/天，增加蛋白质 30g/天
- 保证铁、钙、碘、DHA 摄入
- 避免生食、未煮熟肉类、含汞高的鱼类

### 4.5 减脂人群（详见第八章）

- 热量缺口 300-500 kcal/天（建议不超过 TDEE 的 20%）
- 蛋白质提高至 1.6-2.2g/kg 体重（防止肌肉流失）
- 碳水降至 2-4g/kg 体重，优先低 GI 主食
- 脂肪 0.8-1g/kg 体重（不可过低，维持激素水平）
- 增加膳食纤维：蔬菜每餐 150-200g
- 主食减量但不断碳：每餐 50-75g 生重
- 烹饪方式优先：蒸、煮、凉拌、少油快炒、空气炸锅

### 4.6 增肌人群（详见第八章）

- 热量盈余 200-500 kcal/天
- 蛋白质：1.6-2.2g/kg 体重
- 碳水：4-7g/kg 体重（保障训练能量和恢复）
- 脂肪：0.8-1.2g/kg 体重
- 少食多餐，增加进食频率
- 训练后 30 分钟内补充蛋白质 20-30g + 快碳 30-50g

## 六、烹饪方法热量影响

| 烹饪方法 | 额外热量 | 说明 |
|---------|---------|------|
| 蒸 | 极少 | 健康首选 |
| 煮 | 极少 | 适合汤类、面食 |
| 焯水凉拌 | 调料油 5-10g | 清爽低卡 |
| 快炒 | 油 10-15g | 高温短时，控制油量 |
| 空气炸锅 | 极少油 | 健康炸物替代 |
| 煎 | 油 15-20g | 热量较高，控制频率 |
| 红烧/焖 | 油 10g + 糖 5g | 注意控糖 |

## 七、10-15 分钟快手策略

1. **并行操作**：烧水同时切菜，煮面同时备浇头
2. **预处理食材**：冷冻肉提前解冻（放冷藏室过夜），蔬菜提前洗净
3. **一锅出策略**：电饭煲焖饭（饭菜一锅出）、汤面（面菜蛋一锅）
4. **微波炉辅助**：快速解冻、蒸蔬菜、热预制主食
5. **简化刀工**：切丝改用切片、切丁，甚至手撕
6. **高效热源**：电磁炉/燃气灶同时使用两个灶眼
7. **调味简化**：万能酱汁提前调配（生抽:醋:蚝油 = 2:1:1）

## 八、健身减脂/增肌人群营养科学（专项参考）

> 本章综合《中国居民膳食指南(2022)》、ISSN（国际运动营养学会）立场声明、ACSM（美国运动医学会）指南，

### 8.2 减脂人群营养策略

**核心原则**：适度热量缺口 + 高蛋白 + 控碳水 + 适量脂肪

1. **热量缺口**：
   - 初始建议 300 kcal/天，逐步增加至 500 kcal
   - 缺口不要超过 TDEE 的 20%，否则代谢适应、肌肉流失
   - 建议每 2 周重新计算 TDEE（体重下降后 BMR 也会下降）

2. **蛋白质摄入**：
   - 1.6-2.2g/kg 体重（越低热量越高蛋白）
   - 每餐分配 20-40g 蛋白质，刺激肌肉蛋白合成
   - 优先选择低脂蛋白源：鸡胸肉、虾仁、蛋白、豆腐、瘦牛肉

3. **碳水策略**：
   - 2-4g/kg 体重，优先低 GI 主食（燕麦、糙米、全麦、红薯）
   - 训练日可适当增加碳水，休息日减少
   - 晚餐碳水减量，以蛋白质+蔬菜为主

4. **脂肪策略**：
   - 0.8-1g/kg 体重，不可低于 0.6g/kg（影响激素）
   - 优先不饱和脂肪：坚果、橄榄油、鱼油
   - 减少饱和脂肪和反式脂肪

5. **进食时机**：
   - 训练前 1-2 小时：少量碳水 + 蛋白质（如全麦面包+鸡蛋）
   - 训练后 30 分钟内：蛋白质 20-30g（如鸡胸肉/蛋白 shake）
   - 睡前可选慢消化蛋白质（酪蛋白/牛奶）

6. **减脂期推荐食材**：
   - 优质蛋白：鸡胸肉、虾仁、鸡蛋蛋白、瘦牛肉、豆腐、希腊酸奶
   - 低 GI 主食：燕麦、糙米、红薯、全麦面包、荞麦面
   - 高纤维蔬菜：西兰花、菠菜、生菜、黄瓜、西红柿
   - 健康脂肪：坚果（每日 15g）、橄榄油

### 8.3 增肌人群营养策略

**核心原则**：适度热量盈余 + 高蛋白 + 高碳水 + 力量训练

1. **热量盈余**：
   - 200-500 kcal/天，建议从 250 kcal 开始
   - 体重增长速度：每月 1-2kg 为理想（增肌为主，少增脂）
   - 超过此速度说明热量过高，多余热量转为脂肪

2. **蛋白质摄入**：
   - 1.6-2.2g/kg 体重
   - 每 3-4 小时摄入 20-40g 蛋白质
   - 训练日和休息日保持一致

3. **碳水策略**：
   - 4-7g/kg 体重，是增肌的核心能量来源
   - 训练前后必须有碳水摄入
   - 训练后 30 分钟内：蛋白质 20-30g + 快碳 30-50g（白米饭、香蕉、蜂蜜）

4. **进食频率**：
   - 建议每日 4-6 餐（含加餐）
   - 训练后加餐尤为重要
   - 睡前补充慢消化蛋白质有助于夜间恢复

5. **增肌期推荐食材**：
   - 优质蛋白：鸡胸肉、牛肉、鸡蛋、鱼虾、牛奶、豆腐
   - 能量碳水：米饭、面条、土豆、全麦面包、香蕉
   - 蔬菜水果：多样化摄入，保证微量营养素
   - 健康脂肪：坚果、牛油果、橄榄油

### 8.4 训练前后的营养时机

| 时机 | 摄入建议 | 目的 |
|------|---------|------|
| 训练前 2-3 小时 | 正餐（碳水 60-80g + 蛋白质 20-30g） | 储备能量 |
| 训练前 30-60 分钟 | 少量快碳 + 蛋白质（如香蕉+鸡蛋） | 快速供能 |
| 训练中 | 补充水分（每 15 分钟 150-250ml） | 防脱水 |
| 训练后 30 分钟内 | 蛋白质 20-30g + 快碳 30-50g | 肌糖原恢复+蛋白合成 |
| 训练后 1-2 小时 | 正餐（碳水+蛋白质+蔬菜） | 全面恢复 |
| 睡前 30 分钟 | 慢消化蛋白质（酪蛋白/牛奶/希腊酸奶） | 夜间持续供氨 |

### 8.6 减脂/增肌常见误区

| 误区 | 事实 |
|------|------|
| 减脂不能吃碳水 | 适量优质碳水必需，断碳影响代谢和训练表现 |
| 蛋白质越多越好 | 超过 2.5g/kg 无额外收益，增加肾脏负担 |
| 减脂只做有氧 | 力量训练保肌肉、提代谢，比纯有氧更有效 |
| 增肌要吃很多蛋白粉 | 食物优先，蛋白粉只是补充 |
| 晚上不能吃碳水 | 关键看全天总热量，训练日晚餐碳水有助恢复 |
| 减脂越快越好 | 每周减 0.5-1kg 为宜，过快流失肌肉 |
