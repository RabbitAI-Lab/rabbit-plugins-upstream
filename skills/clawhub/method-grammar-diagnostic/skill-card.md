## Description:

Diagnoses grammar and syntax issues in psychology Method sections, checking tense, passive voice, sentence structure, and grammar while returning scores and journal-style examples.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wangjinhongmy-pixel](https://clawhub.ai/user/wangjinhongmy-pixel)

## Use Case:

Academic writers, reviewers, and research-support agents use this skill to evaluate grammar and syntax in psychology Method sections. It produces a scored diagnostic report with ranked issues, evidence-linked guidance, and positive examples from journal-style Method writing.
