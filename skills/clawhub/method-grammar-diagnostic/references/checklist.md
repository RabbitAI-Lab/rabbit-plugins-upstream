# 心理学实证论文 Method 部分「语法与句法维度」检查清单

> 标准依据：《Science Research Writing》(2nd ed.) §2.5.1「Verb tense and the agentless passive」的五种主-被动用法及其「make it impossible for the reader not to understand」原则；学术写作通则：时态分工、被动语态消歧、句法透明度；正例惯例采自 JPSP / JEP:G / Developmental Psychology / PSPB / JCCP 等顶刊实证论文 Method 节共 47 个片段（Abramson 2024、Altgassen 2025、Asaba 2025、Costin 2019、Kteily 2016、Margolis 2020、Olaru 2023、Petsko 2022、Phillips 2021、Schroer 2025、Urban 2024、vanScheppingen 2020、Zhou 2016 等）。

---

## 一、时态一致性

### 1.1 本研究操作：一般过去时

- [ ] 招募、施测、编码、统计分析等本研究亲手执行的动作统一使用一般过去时（recruited / completed / coded / estimated / fitted）
- [ ] 第一人称主动叙述用 "We + 过去时"（We recruited, We used, We measured, We fitted）
- [ ] 被动叙述用 "was/were + 过去分词"，主语明确（participants were asked / data were collected / responses were made）
- [ ] 排除规则、最终样本量等已发生事件用一般过去时（were excluded, leaving N = …）
- [ ] 多研究论文中 Study 1/2/3 的操作叙述统一用一般过去时，不混入现在时

### 1.2 标准程序、设备、软件：一般现在时

- [ ] 描述通用方法、设备工作原理、软件功能用一般现在时（the eye tracker records at 25 frames/sec, the MC code system uses…, DTA is assessed using…）
- [ ] 量表/任务的恒常属性用一般现在时（the 16-item SDO7 scale has…, the survey included…, DTA was assessed using… 当主语是任务/工具本身时为恒常属性表述）
- [ ] 软件版本、统计方法通则用一般现在时（Full Information Maximum Likelihood estimation in Mplus Version 7）
- [ ] 仪器类参数（采样率、分辨率、视距、像素、视觉角度）以现在时呈现其恒常规格

### 1.3 既有证据与既定事实：现在完成时 / 一般现在时

- [ ] 引用前人已发表的研究结论用现在完成时或一般现在时（have been shown to elicit, as shown in Table 2）
- [ ] 已建立的量表/范式的背景信息用一般现在时 + 引用（adapted from Redick et al., 2012; following prior research）
- [ ] 引用同一工具在其他研究的常模/已验证属性时，时态不强行改写为过去时

### 1.4 同段并列要素的时态一致

- [ ] 同一并列从句中动词时态一致（不是 vs. are 不可并排出现，除非代表不同时间维度）
- [ ] 程序叙述的时间链（First / Next / Then / Finally / Upon completion）一律使用同一时态（一般过去时），不混用现在时
- [ ] 同一条件下的多个子操作使用同一时态体系（条件材料描述 now reads 与具体操作 coded 不在同一段落错位）
- [ ] 排除规则并列项 (a)(b)(c)(d) 中各动词时态统一（failed / applied / were suspected / seemed 而非混合）

### 1.5 时态与所指对象的对齐

- [ ] **过去时 vs 现在时不混用导致主-谓错位**：例如描述本研究标准程序时，was collected 不应错为 is collected（反之亦然），避免读者误以为是他人工作或既定标准
- [ ] 同一句中描述「你做了什么」用 Past Simple，描述「标准流程是怎样的」用 Present Simple，两者不互相替换
- [ ] "A flexible section was inserted in the pipe"（本研究）与 "A flexible section is inserted in the pipe"（标准程序）形成规范对照的范本

### 1.6 写作完成后的强制核查

- [ ] 写完 Method 后逐句核查每个动词时态，确认其传达的功能/意义与意图一致
- [ ] 不假设读者能自行脑补时态含义，凡可能产生主语/责任歧义者一律改写

## 二、被动语态规范

### 2.1 主-被动静态选择与目标期刊对齐

- [ ] 上线前查阅目标期刊近年 Method 节，确定该刊主流是被动（agentless passive）还是主动（we investigated / we conclude）
- [ ] 在同一 Method 节内保持体例一致：要么以被动为骨架、要么以第一人称主动为骨架，不在段间无序切换
- [ ] 即使期刊偏好主动语态，对「操作接受方」（participants were asked / data were collected）仍可用被动以确保叙述客观

### 2.2 无施事被动（agentless passive）的歧义控制

教材 §2.5.1 列出五种主-被动用法，每种都对应一种「make meaning clear」的消歧策略。本节逐条核查：

#### 用法 1：「X was collected/modified by me」（本研究工作）

- [ ] 当主语是本研究产出时，避免裸露的 was/were + 过去分词（agentless passive）造成归属歧义
- [ ] 改写为第一人称主动：**We collected / We modified**
- [ ] 或加位置/范围限定词：**in this study / here / in this work / in our model**
- [ ] 或用「假主语」：**This experiment / The procedure described above / The model**

#### 用法 2：「X was collected/modified by the person whose procedure I am using」（借鉴他人工作）

- [ ] 当所描述的是他人既有的方法/材料/模型时，必须给出**完整文献引用**（Author, Year）
- [ ] 加所属短语：**in their work / in that model / in the original study**
- [ ] 用「假主语」：**That experiment / The probe used in their study**

#### 用法 3：「X is collected/modified normally」（标准程序）

- [ ] 描述业内公认的标准操作时，给出**代表文献引用**或行业惯例来源（即使是标准程序也建议引用）
- [ ] 加标准化标识语：**using standard procedures / as in Smith (2010) / following prior research**
- [ ] 使用现在时（is/was 形式视主语时态而定）

#### 用法 4：「Figure 内既有标准程序又有本研究贡献」

- [ ] 当一个 Figure 同时含「标准流程」与「本研究新增」时，必须**显式声明哪部分是自己的**（The experimental setup used here is shown in Fig. 3）
- [ ] 或整体改写为主动：**We collect / We modify X**

#### 用法 5：「本研究工作 + 期刊要求用 Present Simple」

- [ ] 当期刊惯用现在时描述方法（如材料与工程类期刊），本研究动作也用现在时时，必须加**位置/范围限定**避免误读为标准程序
- [ ] 改写为：**We collect / We modify**；或加 **here / in this work / in our model**；或用 **This equation / The model** 作主语

### 2.3 主动语态（active voice）的规范使用

- [ ] 当主语为「我们」（研究者）时，优先用主动语态直接陈述（We used, We measured, We estimated, We fitted）
- [ ] 主动语态常配目的状语开头：**To test our main hypotheses, we used…**
- [ ] 模型/范式/统计方法的实施主动化：**We fitted LTA models, We estimated RMSEA**
- [ ] 主动叙述时句子主干简洁，动词具体明确，避免 "We conducted a study in which…" 这种空洞表达

### 2.4 被动语态的合理使用场景

- [ ] 当执行者不重要、信息焦点在动作本身或接受者时，使用被动（participants were asked, responses were made, items were reverse-coded）
- [ ] 当研究步骤以「材料/对象」为主语推进时，使用被动（The film was placed in a sealed chamber; The solutions were placed in the refluxing bath）
- [ ] 数据/样本处理链条使用被动 + 介词短语表达顺序（was extracted from frozen samples; was fitted with a plastic tube）
- [ ] 避免无施事被动堆砌造成的"动作漂浮"（连续 5 句以上 was/were + 过去分词，无明确主体）

### 2.5 归属清晰（ownership）

- [ ] 用 **In this study / here / in our model / in this work** 标记本研究贡献，与既有方法分开
- [ ] 引用位置准确：citation 放在所归属的方法/语句处，不误挂他人工作
- [ ] 当本研究工作与既有方法相似时，明确三分关系：**as described by（完全相同）/ adapted from（相似）/ unlike / instead of（显著不同）**，并说明差异意义
- [ ] 改编既有量表时显式说明改编方式（We removed the third item because… / adapted version of the 12 scenarios used in Studies 2a and 2b）

## 三、句子结构合理性

### 3.1 句式模板的规范使用

- [ ] 目的状语开头：**To + 动词原形**（To test our main hypotheses, To evaluate the validity, To calculate the dependent measure）
- [ ] 「方法不适用 → 因此采用 → 稳健性处理」三段式论证（are inappropriate because… → Thus, we estimated… → robust standard errors to reduce biases…）
- [ ] 「测量工具 → 改编 → 理由 → 保留条目 → 信度 → 量尺锚点」量表报告公式化
- [ ] 关键比较结构句：**exceeded the recommended threshold of … / surpassed the benchmark of … / were greater than …**，阈值与比较对象都精确给出

### 3.2 时间顺序与序列标记

- [ ] 程序段使用规范时间连接词：**In a first step / First / Next / Then / Subsequently / Finally / Upon completion / Prior to / Following / At which point**
- [ ] 避免单一使用 then / next / and then 等口语化连接词
- [ ] 同一程序链中连接词不重复堆砌，每步使用不同表述或与序号（First / Second / Third）配合
- [ ] 时间状语精确化：刺激呈现毫秒数（presented for 650 ms）、间隔（every 5 s）、时长（5 s long）、练习/正式试验数量
- [ ] 步骤按时间顺序形成完整环节链，无跳步（招募 → 知情同意 → 施测 → 补偿 → debriefing）

### 3.3 条件、对照与平行结构

- [ ] 实验条件/对照叙述使用**平行句式**（条件 A: …; 条件 B: …），仅关键变量对位变化（sociable, caring, considerate vs. indifferent, not very caring）
- [ ] 反平衡设计的条件对照用 **either … or … / while … vs. …** 完整陈述
- [ ] 排除规则的并列项使用平行动词形式（failed / applied / were suspected / seemed）
- [ ] 多研究间同一要素叙述同构（Study 1 → Study 2 → Study 3 仅更换因素水平名称）

### 3.4 长句内部结构

- [ ] 长句使用**标点分层**（破折号 —、括号 ()、插入语 that is, …）防止阅读阻塞
- [ ] 避免一串介词短语堆砌造成的歧义句（…in the oven at 250℃ with protective gloves to avoid injury for one hour…）
- [ ] 主-谓-宾核心前置，附加信息（条件、范围、原因）后置或用括号分隔
- [ ] **定语从句 / 现在分词短语 / 过去分词短语**修饰时贴近被修饰名词，避免悬垂修饰（dangling modifier）
- [ ] 关键概念给出即时术语解释：**i.e., …** 或括号注释（strong measurement invariance constraints, i.e., equal loadings and equal intercepts）

### 3.5 复合句与从句类型分工

- [ ] 原因：**because / as / since / which are likely to be more accurate, as we accounted for measurement error**
- [ ] 目的：**in order to / to ensure / to account for**（不给目的则视为机械罗列）
- [ ] 条件：**when / if / in cases where / whether … or …**
- [ ] 让步：**although / while / whereas**（条件对照与差异说明）
- [ ] 时间：**after / before / until / when / while / as soon as / at which point**
- [ ] 每个操作环节附带理由（to ensure / in order to / to account for），非机械罗列

### 3.6 强调与总结句

- [ ] 数据-含义一一对应：**These results indicate that… / This result confirms that…**
- [ ] 多重检验后用 **Together, these … tests … validate the measurement model** 类总结句收束，语法平行
- [ ] 段末或关键比较后用 **Thus / Hence / Therefore** 等显式逻辑连接词引出推论
- [ ] 总结句与所总结内容保持**句法主语一致**（Together, these validity tests validate…, these tests 与 validate 主谓一致）

## 四、语法准确性

### 4.1 主谓一致

- [ ] 主语为单数可数名词时谓语用单数（The eye tracker records…, not record）
- [ ] 主语为复数（participants / data / responses / items / trials）时谓语用复数
- [ ] 集体名词（a battery of / a pool of / a series of）作主语时谓语配合 of 后的名词单复数
- [ ] 主语插入定语/从句较长时仍保持主谓核心一致（The residuals of the same item at different time points, which were correlated, were …）

### 4.2 名词与冠词

- [ ] 单数可数名词必须带冠词（a / the）或其它限定词（this / each / my），不可裸用
- [ ] 不区分 a / the 会改变含义的场合按含义选择（a 首次提及 / the 再次提及 / the 双方共识之物）
- [ ] 抽象/物质/学术概念名词用零冠词（research / information / evidence / equipment）当泛指时
- [ ] 缩略词首次出现给出全称：structural equation modeling (SEM)、Full Information Maximum Likelihood (FIML)
- [ ] 缩略词在文中前后一致，不混用 SEM / S.E.M. / sem

### 4.3 介词使用

- [ ] **介词决定动词/名词含义**时不互换：evidence of（存在）vs. evidence for（可能存在）；X was substituted for Y（X 替换 Y）vs. X was substituted with Y（Y 替换 X）
- [ ] 介词 with 的歧义敏感（with one eye = using / having），上下文能消歧或换用 by doing / using / through
- [ ] 过程描述常用动词+介词搭配：was applied across / was calibrated against / was mapped against / was assessed using / was calculated by dividing
- [ ] 介词 by 表达非意图（was hit by a metal bar 暗示无意），介词 with 可表达意图（was hit with a metal bar 暗示有意）
- [ ] 避免**介词短语链**（a string of 5+ prepositional phrases）造成阅读阻塞，重组为分句或断句

### 4.4 代词指代

- [ ] 代词（it / they / this / these / those / such）指代对象明确无歧义
- [ ] 跨句代词先行词不被插入的同名词短语抢指
- [ ] **this study / this work / here** 等指示语明确指代本研究，不被误读为引用文献
- [ ] **the other three / the other half / the remaining** 等对照表达指代的对象紧邻出现

### 4.5 比较与量化结构

- [ ] 比较级 than 前后比较对象平行（greater than the highest squared inter-construct correlations，非 greater than the highest squared inter-construct correlations' values）
- [ ] 倍数/百分比比较完整：**twice as likely to / 25% more than / M = 3.51 (SD = 1.35)**
- [ ] 范围表达精确：**ranging from 1 (totally disagree) to 7 (totally agree)** 含端点标注
- [ ] 数值与样本量绑定（with N = … / among the 1,002 respondents / leaving 906 participants）
- [ ] 排除数量与排除原因一一对应（12 excluded for being Roma, 84 for attention check）

### 4.6 数、量、单位、符号

- [ ] 单复数一致：number of participants (单数) vs. a number of participants (复数)；data 复数、datum 单数
- [ ] 数值与单位间留空格（5 s, 650 ms, 250℃, 120 Hz, 0.5 visual angles）
- [ ] 统计符号格式一致：M / SD / α / ω / CR / AVE / CFI / RMSEA / SRMR 全大写斜体或按期刊规范
- [ ] 量表锚点格式一致：1 = strongly disagree to 5 = strongly agree 或 1 (strongly disagree) to 5 (strongly agree)，全文统一
- [ ] 百分号与数字间不留空格（72.43%），数值范围用 en-dash（18–79）非连字符

### 4.7 标点、缩写与排版

- [ ] 学术缩写首次出现给全称，再次出现可直接用缩写
- [ ] 长破折号（—）周围不空格或按期刊规范；连字符（-）连接复合词；en-dash（–）用于数值范围；em-dash（—）用于插入语
- [ ] 列表 (a)/(b)/(c)/(d) 与正文衔接（…because they (a) failed…, (b) applied…, …）
- [ ] 引号内引用材料与外文引述正确嵌套（双引号在外、单引号在内）
- [ ] 圆括号内补充信息结尾无句号时，括号外根据整句决定；句末时句号在括号外

### 4.8 一致性（terminology & formatting consistency）

- [ ] 同一概念全文术语一致（participants / subjects / respondents / respondents 不混用；condition / group / level 不混用）
- [ ] 同一要素前后表述一致（不能用 first session vs. initial session 混用）
- [ ] 同一指标的人名/缩写/版本号前后一致（HEXACO-60 / D-70；Mplus Version 7；MTurk / Prolific）
- [ ] 同一统计量报告格式一致（M = 3.51, SD = 1.35 vs. M = 3.51 (SD = 1.35) 二选一，不混用）
