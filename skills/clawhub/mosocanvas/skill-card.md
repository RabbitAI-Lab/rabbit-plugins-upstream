## Description: <br>
MoSoCanvas provides evidence-based visual direction for campaign images, posters, social image series, and physical promotional collateral, from intent and shot design through production briefs, artifact review, bounded repair, and quality benchmarking. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, creative teams, and external users use MoSoCanvas to turn visual campaign intent into structured art direction, shot plans, generation briefs, review records, controlled repairs, and benchmark evidence. It is best suited to image work where composition, carrier fit, visual narrative, and artifact inspection matter. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Local helper scripts can process images, create masks, hash files, build review packets with local references, and package releases. <br>
Mitigation: Run helper scripts only on intended project files and review generated manifests, packets, and archives before sharing them. <br>
Risk: Trend and benchmark workflows may involve collecting source URLs or current visual references. <br>
Mitigation: Use authorized sources, keep source references instead of redistributing protected imagery, and document the dated source policy for evaluations. <br>
Risk: Visual claims can be misleading when they are made without inspecting the actual artifact. <br>
Mitigation: Require artifact-grounded review records and user acceptance before treating an output as release-ready. <br>
