# Creator Audit — Pre-Delivery Checklist

Fix any failed item before delivering.

## A. Data & attribution (7)

- [ ] Attribution method and window stated in the header
- [ ] Cost basis includes fee, product, shipping, rights, commissions
- [ ] Every efficiency metric uses full cost, not fee-only
- [ ] Estimates marked with `~` and method noted
- [ ] Mixed attribution levels across creators flagged for comparability
- [ ] Sample window stated per creator
- [ ] Spot-checked 2 computed numbers against source data

## B. Scoring quality (6)

- [ ] All four axes scored per creator
- [ ] ER compared to creator's own baseline, not just global norms
- [ ] Margin-adjusted RPD computed (not just raw RPD)
- [ ] Creator CAC compared to paid/blended CAC
- [ ] Platform-specific metrics kept as secondary evidence only
- [ ] Trimmed check done for creators with 6+ posts

## C. Authenticity (5)

- [ ] Follower growth curve reviewed for spikes
- [ ] 30+ comments sampled across 3+ posts
- [ ] ER-to-size sanity check done
- [ ] Audience geo/demo match to buyer profile checked
- [ ] Any authenticity fail overrides to DROP

## D. Verdicts (6)

- [ ] Every creator has exactly one verdict: keep/scale/renegotiate/drop
- [ ] Each verdict has 2-3 decisive numbers as evidence
- [ ] Each verdict has a concrete next action (rate, brief, rights, replacement)
- [ ] Weak conversion diagnosed (format/offer/timing/audience/frequency) before any DROP
- [ ] Thin samples capped at KEEP/RENEGOTIATE with mandated test
- [ ] Strategic-value bumps stated explicitly

## E. Portfolio & delivery (6)

- [ ] One-line portfolio verdict present
- [ ] Concentration risk computed (top creator share)
- [ ] Budget reallocation plan with expected impact
- [ ] Content library / usage-rights wins priced and listed
- [ ] Data gaps and tracking fixes listed for next cycle
- [ ] Output follows output-template.md

## Red lines (any hit = do not deliver)

- Verdict of "mixed, keep monitoring" with no action
- RPD computed on fee-only cost
- A creator judged on follower count or raw views
- Authenticity checks skipped entirely
