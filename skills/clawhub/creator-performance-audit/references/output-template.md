# Creator Audit Report Template

Deliver every audit in this structure.

## 0. Audit header

- Period covered / sample per creator (posts, campaigns, days)
- Attribution method (codes, links, platform, survey) and window
- Cost basis (what's included in "full cost")
- Data gaps and low-confidence flags

## 1. One-line portfolio verdict

Example: "Of 5 creators, scale 1, keep 2 with brief changes, renegotiate 1, drop 1; reallocating $14K improves projected blended RPD from 0.9 to 1.6."

## 2. Scorecard table

| Creator | Platform | Full cost | Eng-view CPM | ER vs own baseline | CTR | CVR | Rev / $ | Margin-adj / $ | Authenticity | Verdict |
|---|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | pass/flag | |

Mark estimates with `~` and note method.

## 3. Per-creator verdicts

### Creator X — VERDICT

- **Evidence:** 2-3 decisive numbers
- **What's driving it:** content format, audience, price, authenticity
- **Action:** the specific next step (rate, brief, rights, replacement)
- **Confidence:** high / medium / low (sample size, attribution quality)

## 4. Portfolio-level findings

- Concentration risk (top creator's share of creator-driven revenue)
- Budget reallocation plan with expected impact
- Content library wins worth licensing for paid
- Brief/format patterns that convert (feed back to creative team)

## 5. Data gaps & next audit

- Missing tracking to fix before next cycle
- Creators on thin samples needing one more test
- Date of next audit
