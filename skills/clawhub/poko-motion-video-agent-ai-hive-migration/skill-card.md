## Description:

Assesses a content-layer partial migration from Poko Motion to AI-HIVE MCP by verifying platform capabilities and producing role boundaries, agent handoffs, MCP work orders, cost and quality metrics, approval controls, and rollback criteria.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, media operations teams, and content workflow owners use this skill to plan a cautious partial migration from Poko Motion to AI-HIVE MCP. It helps preserve the original project workspace while testing independently reviewable image, video, or shot-generation nodes with approval, cost, quality, and rollback controls.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Paid media generation or publishing workflows can create cost overruns or external actions before review.

Mitigation: Keep human approval, budget limits, pilot rollout, and rollback controls active before any paid generation, publishing, or bulk external action.

Risk: Uploading unauthorized people, brand, product, music, image, video, or other reference assets can create rights and policy exposure.

Mitigation: Upload only owned or authorized assets, record source identifiers and file hashes, and stop the workflow when authorization is missing.

Risk: The migration plan can overstate replacement quality, price, reliability, or platform equivalence without same-day comparable tests.

Mitigation: Require same-input, same-duration, same-size acceptance testing and avoid claims such as full replacement, best quality, or lowest price without current evidence.
