## Description: <br>
Produces frontend UI code and design guidance with an explicit spacing, typography, color, radius, and state system for polished app, dashboard, landing page, and component work. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and product teams use this skill to build or restyle frontend UI with a deliberate design system, working code, and designed interaction states. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated UI code can miss project-specific accessibility, framework, or design-system requirements. <br>
Mitigation: Review generated code before adding it to a project, with particular attention to contrast, focus states, component conventions, and existing design constraints. <br>
Risk: When brand constraints are not supplied, the skill may choose visual tokens that do not match the product brand. <br>
Mitigation: Provide brand colors, fonts, product references, and the target framework before generation when those constraints matter. <br>
