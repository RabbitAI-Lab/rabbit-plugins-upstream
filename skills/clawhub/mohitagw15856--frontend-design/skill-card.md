## Description:

Produce frontend UI that actually looks designed — a working spacing/type system, deliberate color use, real states, and restraint — instead of the generic AI-generated interface.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and designers use this skill to build or restyle frontend UIs, landing pages, dashboards, and components with an explicit visual system, designed interaction states, and working UI code.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill influences how an agent designs and writes frontend UI code.

Mitigation: Review generated UI code and visual decisions before deployment, especially for accessibility, brand fit, and user-facing behavior.

Risk: The reviewed artifact is guidance-only and does not add executable behavior or special access by itself.

Mitigation: Treat any generated code as a proposal and apply normal code review, testing, and security scanning before use.
