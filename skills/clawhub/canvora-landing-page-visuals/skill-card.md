## Description:

Generate a complete visual kit for a landing page from its URL — hero, features, process, stats, testimonials, comparison, timeline and CTA imagery, matched to the page's own sections.

This skill is ready for commercial/non-commercial use.

## Publisher:

[canvora](https://clawhub.ai/user/canvora)

### License/Terms of Use:

MIT-0

## Use Case:

Website developers, designers, and site owners use this skill to create section-matched visual assets for a public landing page from its URL.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The landing-page URL is sent to Canvora for analysis and visual generation.

Mitigation: Use only URLs you are comfortable sharing with Canvora.

Risk: A complete visual kit can consume up to 100 credits without another confirmation.

Mitigation: State the intended sections and credit budget before starting generation.
