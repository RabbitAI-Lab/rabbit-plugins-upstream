# 가입 플로우 상세 — powpow-register

문제를 해결할 때 참고하는 자료입니다. 모든 규칙은 플랫폼 소스(Next.js 프런트/백엔드 일관성 검증)에서 나왔으며 출처를 명시했습니다.
플랫폼 업데이트 시에는 온라인 실제 동작을 기준으로 합니다.

## 진입

- 가입 페이지: https://global.powpow.online/register
- 로그인 페이지: https://global.powpow.online/login
- 구독 페이지: https://global.powpow.online/subscription
- 공유 링크 등에서 `?next=...`와 함께 들어온 경우, 가입+결제 완료 후 자동으로 원래 페이지로 돌아갑니다.

## 폼 필드와 규칙

| 필드 | 필수 | 규칙 | 소스 출처 |
|---|---|---|---|
| 아바타 | 선택 | 이미지 ≤5MB, SVG 미지원. 서버에서 자동 압축(>100KB일 때 400×400 / 품질 90으로) | `src/app/api/auth/register/route.ts` |
| 사용자 이름 | 필수 | 2~50자. trim 후 **소문자**로 변환해 저장(Tom과 tom은 같은 사용자 이름. 가입·로그인 양쪽 모두 대소문자 구분 없음) | 동일(zod schema) |
| 비밀번호 | 필수 | 8~100자. 대문자, 소문자, 숫자를 모두 포함해야 함 | 동일 |
| 비밀번호 확인 | 필수 | 비밀번호와 일치(프런트엔드 검증만) | `src/app/(public)/register/page.tsx` |
| 닉네임 | 선택 | ≤100자. 입력하지 않으면 사용자 이름이 기본값 | register route |
| 이메일 | **필수** | 올바른 이메일 형식, ≤255자. 한 이메일로 계정 1개만 가입 가능 | register route |
| 이메일 인증번호 | **필수** | 6자리 숫자. **10분간 유효**. 검증 성공 즉시 무효화. 재발송 시 이전 코드는 사용됨으로 표시 | `src/lib/email-verification.ts` |
| 휴대폰 번호 | 선택 | 중국 본토 번호: `1[3-9]` 시작 11자리. 한 번호는 한 계정에만 연결 가능 | register route |

페이지에는 추가로 서드파티 로그인 버튼 3개가 있습니다: **Google, Watcha, 화웨이 계정**(`GoogleSignInButton` /
`WatchaLoginButton` / `HuaweiLoginButton`). 서드파티 계정에는 로컬 비밀번호가 없어서, 나중에 비밀번호로 로그인하면
「该账号未设置密码，请使用其他方式登录」(이 계정에는 비밀번호가 설정되어 있지 않습니다. 다른 방법으로 로그인하세요)가 표시됩니다.

## 레이트 제한·무차별 대입 방지 파라미터

| 행위 | 제한 | 출처 |
|---|---|---|
| 가입 제출 | **3회/분/IP**, 초과 시 429 | `src/lib/rate-limit.ts` `REGISTER_RATE_LIMIT` |
| 인증번호 발송 | 같은 IP 1회/분 **그리고** 같은 이메일 1회/분, 초과 시 429. 프런트 버튼은 60초 카운트다운 | `src/app/api/auth/register/send-code/route.ts` |
| 인증번호 검증 | 이메일당 10분 이내 최대 **5회** 시도. 상한 도달 시 올바른 코드여도 거부되며 재발송 필요 | `src/lib/email-verification.ts` |
| 비밀번호 찾기 코드 발송 | 1회/분/IP | `src/app/api/auth/forgot-password/route.ts` |
| 로그인 | 5회/분/IP. 같은 계정 연속 실패 **5회 시 30분 잠금**(423), 잠금 중 남은 횟수 감소 표시 | `src/app/api/auth/login/route.ts`, `rate-limit.ts` |

**프라이버시 보호 동작**: 인증번호 발송 / 비밀번호 찾기 시, 이메일이 이미 등록되었든 아니든 인터페이스는
일률적으로 성공 문구를 반환하며 이메일 등록 여부를 유출하지 않습니다.

## agent 대행 모드와 웹 가입의 동등성

skill 스크립트가 호출하는 건 **동일한 공개 API군**(`/api/auth/register`, `send-code`, `login`,
`/api/auth/me`)으로, 가입 페이지 폼 제출과 완전히 같은 검증·레이트 제한·오류 경로를 통과합니다 — 이 파일의
모든 규칙은 두 모드에 동일하게 적용됩니다. 스크립트 시퀀스와 커맨드 계약은 `references/agent-flow.md`를 참고하세요.

## 가입 성공 후 상태 흐름

> **무료 테스트 기간(2026-10-18 시작; 플랫폼의 실제 동작이 우선합니다)**: 새로 가입한 계정은 결제 없이 **모든 기능을 바로 사용할 수 있습니다**
> (피드, 지도, 디지털 휴먼, 체크인 등). 구독하지 않은 계정은 더 이상 콘텐츠 페이지에서 차단되지 않습니다. 이 섹션에서 설명하는
> "pending 차단"은 테스트 기간이 끝난 뒤의 일반 상태입니다 — 그때가 되면 온라인의 실제 동작이 우선합니다.

1. 사용자는 `accountStatus: 'pending'`와 **시작 배지 3개**로 저장됩니다(register 경로).
2. 서버는 HttpOnly 쿠키 두 개도 심습니다: JWT(페이지에 바로 접근 가능)와 pendingUserToken(구독 플로우용 신원 증명).
3. 일반 상태(테스트 기간 종료 / 무료 기간 없음)에서는 가입 페이지가 `pending_payment`를 감지 → `/subscription`으로 리디렉트합니다
   (`next` 반환 파라미터를 유지하며). agent 대행 모드에서는 `me?token=…&redirect=/subscription`가 같은 효과를 냅니다.
   **무료 테스트 기간 중에는 이 단계가 발동하지 않습니다** — 가입 후 바로 홈으로 가서 사용을 시작하세요.
4. 결제 완료 → `accountStatus`가 `active`가 됩니다(**Alipay는 notify를 통해 서버 측에서 자동 활성화**;
   PayPal은 Webhook으로 활성화; WeChat QR 코드는 수동 확인; Huawei IAP는 `activate-huawei`를 통해 진행).
   자세한 내용은 `payment-and-activation.md`에 있습니다.

일반 상태에서 비활성(pending) 계정이 핵심 API(피드, 지도, 디지털 휴먼 채팅, 체크인 등)를 호출하면 403을 받습니다;
공유된 게시물 링크는 예외입니다(공개 접근을 유지함). 무료 테스트 기간 중에는 이 차단이 중단되고 모두 열려 있습니다.
## 자주 발생하는 오류 해결 표

| 현상 | 원인 | 해결 |
|---|---|---|
| 「用户名已存在」(사용자 이름이 이미 존재) | 사용자 이름 사용 중(대소문자 구분 없음) | 다른 사용자 이름으로 |
| 「邮箱已被使用」(이메일이 사용 중) | 이메일이 이미 등록됨 | 다른 이메일로. 또는 로그인 + '비밀번호 찾기'로 기존 계정 복구 |
| 「邮箱验证码错误或已过期」(인증번호 오류/만료) | 코드 오타 / 10분 초과 / 시도 5회 초과로 거부 | '다시 보내기' 클릭, **최신 메일**의 인증번호 사용 |
| 인증번호가 안 옴 | 60초 레이트 제한. 또는 스팸/광고 메일에 들어감 | 카운트다운 끝나고 재발송. 스팸 메일 폴더 확인 |
| 「手机号已被使用」(휴대폰 번호 사용 중) | 번호가 이미 다른 계정에 연결됨 | 전화번호 제거(선택 필드)하거나 번호 변경 |
| 「注册请求过于频繁」/ 429(가입 요청이 너무 잦음) | 가입 3회/분/IP 상한 도달 | 몇 분 기다렸다가 재시도 |
| 409 「用户名或邮箱已被注册」(사용자 이름 또는 이메일이 이미 등록됨) | 제출 순간 타인과 충돌(동시 요청 안전망) | 사용자 이름 또는 이메일 바꿔 재시도 |
| 「图片大小不能超过5MB」/「不支持 SVG」(이미지 크기 초과/SVG 미지원) | 아바타가 규정에 맞지 않음 | 이미지 교체 또는 아바타 건너뛰기 |
| 사용자가 로그인 링크를 클릭하지만 구독 페이지에 도착(홈이 아닌) | 무료 테스트 기간이 끝나고 플랫폼 페이월이 돌아왔습니다 | SKILL.md의 7단계 구독 결제 플로우를 따르세요. 구독 후 `refresh-login`를 실행한 뒤 홈 링크를 보냅니다 |
| 가입은 성공했지만 로그인 시 403 "请完成订阅以激活账户" 반환 | 계정이 아직 pending이고 플랫폼이 무료 테스트 기간 중이 아닙니다(결제 전 예상 상태) | 무료 테스트 기간 중에는 발생하지 않습니다. 발생하면 테스트 기간이 끝난 것이므로 먼저 구독을 완료하세요. 결제 후에도 403이면 오래된 JWT를 사용한 것입니다 — 스크립트 모드에서 먼저 `refresh-login`를 실행해 새 로그인 상태로 교환하세요 |
| 로그인 423 「账户已锁定」(계정 잠김) | 비밀번호 5회 연속 오류 | 30분 대기 |
| 로그인 401 「还剩 N 次尝试机会」(남은 시도 N회) | 비밀번호 오류, 잠금 직전 | 신중하게 시도하거나 그냥 '비밀번호 찾기'로 |
| 「该账号未设置密码，请使用其他方式登录」(비밀번호 미설정) | 서드파티(Google/Watcha/화웨이) 계정 | 원래 서드파티 버튼으로 로그인 |
| 「该账号已注销」(이 계정은 탈퇴됨) | 계정이 deactivate 상태 | 다시 가입해야 함 |

## 로그인 팁(덤으로 해결용)

로그인은 **사용자 이름 / 이메일 / 휴대폰 번호** 3합1 입력을 지원합니다(셋 중 무엇이든 계정명으로 사용 가능).
비밀번호 분실: 로그인 페이지 → '비밀번호 찾기' → 가입 이메일로 6자리 인증번호 수신 → 재설정.
