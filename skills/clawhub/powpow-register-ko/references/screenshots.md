# 제품 UI 스크린샷 — powpow-register

실행 시 필요에 따라 사용합니다. 사용자가 버블을 모르거나, 완성된 모습을 '보고 싶어' 할 때 해당 스크린샷을 그대로 보냅니다.

## 이미지 위치

- 6장의 스크린샷이 **스킬에 동봉**되어 있으며, `assets/screenshots/powpow-0N.jpg`(`N`은 1~6)에 있습니다. 로컬 이미지 파일로 그대로 보내면 됩니다 — 네트워크 연결 불필요, GitHub에 접근할 수 없는 환경을 포함해 어떤 환경에서도 사용할 수 있습니다.
- 패키지 내 파일이 예기치 않게 없을 때만 폴백: 호스팅 사본 `https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-0N.jpg` 또는 미러 `https://cdn.jsdelivr.net/gh/durenzidu/durenzidu@main/screenshots/powpow-0N.jpg`(주의: 둘 다 중국 본토에서는 열리지 않을 수 있습니다 — 패키지 내 파일을 우선하세요).
- 매번 현재 주제와 관련된 1~3장만 보냅니다.

## 목록

### powpow-01.jpg — 디지털 휴먼 상세 페이지

![디지털 휴먼 상세 페이지](../assets/screenshots/powpow-01.jpg)

실존/역사 인물을 디지털 휴먼으로 만든 후의 카드: 온라인 상태, 소속 장소, 인물 소개, '대화 시작' 등.
**용도**: '가입하면 지도 위의 디지털 휴먼과 대화할 수 있다'를 소개할 때.

### powpow-02.jpg — 게시글 작성 페이지

![게시글 작성 페이지](../assets/screenshots/powpow-02.jpg)

게시글/여행 일기를 쓰는 편집 화면. 오른쪽 아래에 플로팅 버튼 모음.
**용도**: 사용자가 '가입하면 뭘 할 수 있어요', '어디서 글을 써요'라고 물을 때.

### powpow-03.jpg — 지도 페이지(버블 + 디지털 휴먼)

![지도 페이지](../assets/screenshots/powpow-03.jpg)

공개 지도 전체 모습: 장소가 있는 게시글이 '버블'로 지도 위에 모이고, 디지털 휴먼은 아바타로 실제 장소에 고정되어 있습니다.
**용도**: **제품 소개의 첫 번째 이미지** — '당신이 쓴 여행 일기는 지도 위의 한 알갱이 버블이 됩니다'.

### powpow-04.jpg — 개인 홈(디지털 자산)

![개인 홈](../assets/screenshots/powpow-04.jpg)

사용자 자신의 페이지: 친구/팔로잉/팔로워, 그리고 '디지털 자산' — 배지 잔액, 내 버블, 내 디지털 휴먼.
**용도**: '가입하면 배지 3개를 즉시 준다'고 할 때 배지가 어디 붙어 있는지 보여줄 때. 사용자가 '내 자산은 뭔가요'라고 물을 때.

### powpow-05.jpg — 스토리 진행 페이지

![스토리 진행 페이지](../assets/screenshots/powpow-05.jpg)

플랫폼 안의 스토리 게임(예시 '영락·1421'): 챕터 진행, 배지 획득, 롤플레이.
**용도**: 사용자가 '게시글 말고 뭘 더 할 수 있어요', '배지는 어떻게 벌어요'라고 물을 때.

### powpow-06.jpg — 게시글 상세 페이지(완성 예시)

![게시글 상세 페이지](../assets/screenshots/powpow-06.jpg)

작성된 한 편의 여행 일기: 작성자, 장소 태그, 본문, 사진. 하단에서 좋아요/댓글/공유/저장 가능.
**용도**: **오프닝 두 번째 이미지** — '다른 사람이 지도에서 당신의 버블을 열면 이렇게 보입니다'.

## 유지 보수 참고

- `assets/screenshots/` 안의 이미지가 패키지로 배포되는 첫 번째 사본입니다. 스크린샷을 업데이트할 때는 `assets/screenshots/`의 동일 이름 파일을 교체하고(`powpow-0N.jpg` 명명 유지) 새 버전을 배포합니다.
- 공개 저장소 `durenzidu/durenzidu`(`screenshots/` 디렉터리)의 호스팅 사본은 폴백 미러로 유지하며, 패키지 내 파일과 동기화해 업데이트합니다.
- 현재 스크린샷 목록에는 **가입 페이지**와 **구독 페이지** 스크린샷이 없습니다. 추후 추가할 경우(예: `powpow-07.jpg` 가입 페이지, `powpow-08.jpg` 구독 페이지) 파일을 `assets/screenshots/`에 넣고 같은 형식으로 항목만 추가하면 됩니다. SKILL.md 안내 문구에도 함께 언급할 수 있습니다.
