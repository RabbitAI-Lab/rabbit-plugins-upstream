# 제품 화면 스크린샷 — powpow-register

실행 중 필요에 따라 사용합니다. 사용자가 버블에 대한 개념이 없거나 완성품의 모습을 '확인'할 필요가 있을 때 해당 링크를 보내면 됩니다.

## 링크 규칙

- 메인 링크(raw): `https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-0N.jpg`
- 미러(raw가 안 열릴 때 사용, `N`은 1~6): `https://cdn.jsdelivr.net/gh/durenzidu/durenzidu@main/screenshots/powpow-0N.jpg`
- 이미지는 공개 저장소에 있어 그대로 전송할 수 있습니다. 스킬 디렉터리에 **다운로드하지 말고**, 로컬 경로도 보내지 마세요.
- 매번 현재 주제와 관련된 1~3장만 보냅니다.

## 목록

### powpow-01.jpg — 디지털 휴먼 상세 페이지

![디지털 휴먼 상세 페이지](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-01.jpg)

실존 인물/역사 인물을 디지털 휴먼으로 만든 카드: 온라인 상태, 소속 장소, 인물 소개, 「대화 시작」 등.
**쓰이는 곳**: 「가입하면 지도 위 디지털 휴먼과 대화할 수 있다」를 소개할 때.

### powpow-02.jpg — 글쓰기·편집 페이지

![게시물 편집 페이지](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-02.jpg)

게시글/여행 일기를 쓰는 편집 화면. 오른쪽 아래에 떠 있는 버튼 모음.
**쓰이는 곳**: 「가입하고 나면 뭘 할 수 있나요」「어디서 글을 쓰나요」라고 물어볼 때.

### powpow-03.jpg — 지도 페이지(버블 + 디지털 휴먼)

![지도 페이지](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-03.jpg)

공개 지도 전체 모습: 위치가 있는 게시글이 '버블'로 지도에 모이고, 디지털 휴먼은 아바타로 실제 장소에 고정되어 있습니다.
**쓰이는 곳**: **제품 소개의 첫 번째 선택 이미지** — 「올린 여행 일기가 지도 위의 한 버블이 됩니다」.

### powpow-04.jpg — 개인 홈페이지(디지털 자산)

![프로필 페이지](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-04.jpg)

사용자 본인 페이지: 친구/팔로잉/팔로워, 그리고 '디지털 자산' — 배지 잔액, 내 버블, 내 디지털 휴먼.
**쓰이는 곳**: 「가입하면 배지 3개를 드려요」라고 말할 때 배지 위치를 보여줄 때. 「내 자산이 뭐예요」라고 물어볼 때.

### powpow-05.jpg — 스토리 진행 페이지

![스토리 진행 페이지](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-05.jpg)

플랫폼 내 스토리형 게임(예시 「永乐·1421」): 챕터 진행, 배지 획득, 롤플레잉.
**쓰이는 곳**: 「글 외에 또 뭐가 있나요」「배지는 어떻게 모아요」라고 물어볼 때.

### powpow-06.jpg — 게시글 상세 페이지(완성 예시)

![게시물 상세 페이지](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-06.jpg)

발행된 여행 일기 하나: 작성자, 장소 태그, 본문, 첨부 이미지. 하단에 좋아요/댓글/공유/저장.
**쓰이는 곳**: **오프닝 두 번째 이미지** — 「다른 사람이 지도에서 내 버블을 누르면 보이는 화면이에요」.
