## Description: <br>
Helps API and platform teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, backend teams, platform teams, and developer-experience maintainers use this skill to turn REST API requirements, implementation details, and existing Swagger or OpenAPI assets into practical documentation artifacts, checklists, validation steps, and implementation guidance. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger wording may invoke the skill for general REST API or developer-experience prompts outside OpenAPI and Swagger documentation tasks. <br>
Mitigation: Use this skill for OpenAPI or Swagger documentation work and choose a more specific skill for unrelated backend design, implementation, or API support. <br>
