# YH8.5 回测与实盘绩效数据

## 一、实盘绩效（390 笔平仓流水，约 2 个月）

- **净收益**：+86.97U
- **胜率**：50.8%
- **利润引擎定位**：
  - ST 趋势引擎：趋势市盈利、震荡市亏损；8-24 小时持仓周期贡献约 90% 利润
  - BB20 震荡引擎：唯一正期望引擎（胜率约 53%）

## 二、关键回测结论（因子验证）

| 因子 | 结论 |
|---|---|
| 量比 >1.2 放量过滤 | 稳定降回撤（50-67% → 20-25%），风控因子而非 alpha |
| ACF/PACF 自相关过滤 | 胜率 36-38% → 51%+，盈亏比 1.15 → 2.2，回撤 73-88% → 16-18% |
| BB20 收盘确认 | 盘中 386 笔 -1.5% → 收盘 312 笔 +106%（挡掉瞬时假突破） |
| 做空回落确认 | 做空累计 -9.5% → +2.0%（避免强势突破位逆势接刀） |
| 均线/长影线/资金费率/OI 等 | 均无稳定 alpha，胜率天花板系市场客观边界 |

## 三、核心工程纪律

1. **证伪即砍**：所有因子都走「回测验证 → 分半检验 → 上线或砍掉」闭环，无数因子证伪后删除。
2. **进化边界**：参数只能在回测验证范围内调，防过拟合。
3. **如实记录亏损**：SL 止损单平仓的记账 bug 也如实补记，数据完整性优先于账面美观。

## 四、双引擎终局

YH8.5 于 2026-10-07 正式收官（关闭实盘、空仓收官）。双引擎纯规则体系完成历史使命，沉淀为可复用、可回测的策略资产。
