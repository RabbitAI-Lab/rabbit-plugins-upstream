# YH8.5 策略规则详解

## 定位

纯规则化双引擎量化信号系统。核心思想：**趋势用 ST 抓、震荡用 BB20 抓**，由 Playbook 按市场波动状态自动路由，市场牛/基/熊三场景自适应参数。无黑箱 ML，全部规则可回测、可证伪。

## 双引擎

### ST 趋势引擎（st_pure_trend）

- 基于 SuperTrend 指标，转向即开仓（趋势跟随）
- 量比放量过滤：缩量信号不可信，降回撤
- 自相关过滤：ACF/PACF 检验，剔除随机噪声信号
- 适用高波动/趋势市

### BB20 震荡引擎（bb20_range）

- 基于布林带，价格触及上下轨触发均值回归信号
- RSI 极值确认：碰下轨 + 超卖才做多、碰上轨 + 超买才做空
- 长期趋势方向过滤：逆势半仓放行
- 做空回落确认：避免强势突破位逆势接刀
- 适用低波动/震荡市

## Playbook 路由

- ATR 百分位 > 阈值 → 趋势引擎
- ATR 百分位 ≤ 阈值 → 震荡引擎
- 牛/基/熊三场景：自动切换止盈止损幅度与仓位系数

## 市场状态分型

`market_regime.py` 基于 ADX + ATR 百分位 + 长期均线方向，输出五类行情（强趋势/趋势+高波/弱趋势/震荡高波/震荡低波），驱动策略与仓位自适应。

## 优先级与风控

- 信号直通：规则触发即产出信号，不做二次主观判断
- 币种禁用名单：0% 胜率的「慢性亏损币」永久剔除
- 进化边界：参数只能在回测验证过的范围内调整，防过拟合
