# powpow-register

ผู้ช่วยสมัคร PowPow ฟอง (รุ่น OpenClaw): พาผู้ใช้ใหม่จาก "ไม่รู้ว่าฟองคืออะไร" ไปถึง
"เปิดใช้บัญชีแล้ว ใช้งานได้ปกติ" — แนะนำผลิตภัณฑ์ (พร้อมภาพหน้าจอ) แนะนำการสมัครทีละขั้นตอน
ตรวจหาข้อผิดพลาด อธิบายการเปิดใช้สมาชิกภาพ

Skill แบบให้คำแนะนำล้วน ๆ ไม่มีสคริปต์ ไม่มี dependency ทุกขั้นตอนการสมัครผู้ใช้ทำในเบราว์เซอร์/แอปเอง

## การติดตั้ง

```
openclaw skills install @durenzidu/powpow-register
```

## ความสามารถ

1. **แนะนำผลิตภัณฑ์**: เปิดเรื่อง ~120 ตัวอักษร + ลิงก์ภาพหน้าจอโฮสต์ใน repo สาธารณะ GitHub
   (หน้าแผนที่ หน้าโพสต์ ฯลฯ 6 ภาพ เลือกส่ง 1–3 ภาพตามสถานการณ์)
2. **แนะนำการสมัคร**: กฎฟิลด์ (ชื่อผู้ใช้/รหัสผ่าน/รหัสยืนยันอีเมล/เบอร์โทร/รูปโปรไฟล์) เข้าสู่ระบบบุคคลที่สาม
   (Google/Watcha/Huawei) ตัวจำกัดอัตรา ทั้งหมดจากโค้ดแพลตฟอร์มและระบุที่มา
3. **ตรวจหาข้อผิดพลาด**: ไม่ได้รับรหัสยืนยัน ชื่อผู้ใช้/อีเมลถูกใช้ 403 ยังไม่เปิดใช้ บัญชีถูกล็อก ฯลฯ
   13 ปัญหาพบบ่อย
4. **เปิดใช้สมาชิกภาพ**: อธิบายและตรวจหาสามช่องทาง PayPal (เว็บ) / WeChat สแกน QR (ยืนยันด้วยคน) / Huawei IAP (HarmonyOS)
   สายการจ่ายที่มีอยู่ใช้ต่อได้เลย skill แค่ชี้ทาง

## ความปลอดภัย

- ไม่มีคีย์ใด ๆ; ไม่มีสคริปต์ ไม่แตะข้อมูลยืนยันตัวตนผู้ใช้
- **ห้ามขอ**รหัสผ่าน รหัสยืนยัน หรือหลักฐานการจ่ายของผู้ใช้; การสมัครและการจ่ายอยู่ที่หน้าแพลตฟอร์มทั้งหมด
