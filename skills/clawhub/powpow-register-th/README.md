# powpow-register

ผู้ช่วยสมัครสมาชิก PowPow ฟอง (เวอร์ชัน OpenClaw): พาผู้ใช้ใหม่จาก «ไม่รู้ว่าฟองคืออะไร» ไปถึง
«บัญชีเปิดใช้งาน ล็อกอินคลิกเดียว เริ่มเล่นได้» — แนะนำผลิตภัณฑ์ (พร้อมภาพหน้าจอ) สมัครแบบ agent ทำแทน
(รวมอัปโหลดรูปโปรไฟล์) สั่งจ่ายและติดตามแพ็กเกจสมาชิกผ่าน Alipay/PayPal ล็อกอินคลิกเดียวแบบสองลิงก์
และแก้ปัญหา error

**ตั้งแต่ v2.0.0 เป็นโหมด agent ทำแทน และตั้งแต่ v2.1.0 จัดการ PayPal ได้ด้วย**: สคริปต์หลัก `scripts/powpow-register.mjs` ไร้ dependencies
(Node ≥ 18) ผู้ใช้ไม่ต้องออกจากบทสนทนาเลยตลอดกระบวนการ มีแค่สองครั้งที่ต้องจากไปชั่วคราว: เข้าอีเมลดูรหัสยืนยัน
และจ่ายเงินที่หน้าชำระเงิน Alipay/PayPal ถ้าไม่มี Node หรือผู้ใช้อยากลงมือเอง จะถอยไปโหมดแนะนำล้วนอัตโนมัติ

## ติดตั้ง

```
openclaw skills install @durenzidu/powpow-register
```

## ความสามารถ

1. **แนะนำผลิตภัณฑ์**: เปิดด้วยความยาว ~120 ตัวอักษร + ภาพหน้าจอที่แพ็กมากับสกิล (`assets/screenshots/`
   มี 6 ภาพ: หน้าแผนที่ หน้ารายละเอียดโพสต์ ฯลฯ เลือกส่งตามสถานการณ์ 1–3 ภาพ ไม่ต้องใช้โฮสต์รูปภายนอก
   ใช้ได้แบบออฟไลน์)
2. **สมัครแทน**: agent เสนอชื่อผู้ใช้/ชื่อเล่นเอง รหัสผ่านเลือก 1 จาก 2 (ผู้ใช้ให้หรือ agent สร้าง) ส่งและกรอกรหัสยืนยัน
   อัปโหลดรูปโปรไฟล์ตรง ๆ (≤5MB ไม่ใช่ SVG) จัดการ error ที่พบบ่อยอัตโนมัติ (ชื่อถูกใช้/หมดอายุ/โดนลิมิต)
3. **ล็อกอินคลิกเดียว (สองลิงก์)**: สมัครสำเร็จมอบลิงก์ «ครึ่งเซสชัน» พาตรงถึงหน้าแพ็กเกจสมาชิก พอเงินเข้า
   เปลี่ยนสถานะล็อกอินใหม่แล้วมอบลิงก์สมาชิกเต็มรูปแบบพาตรงถึงหน้าแรก (ผ่านสะพานทางการ `me?token=`
   ของแพลตฟอร์ม ปลูก cookie HttpOnly ให้อัตโนมัติ)
4. **จ่ายค่าสมาชิก**: ทั้ง Alipay (รายเดือน ¥6.99 / ราย 3 เดือน ¥19.99 / รายปี
   ¥69.99 ซื้อขาดครั้งเดียวไม่ต่ออายุอัตโนมัติ) และ PayPal (Premium Monthly ประมาณ $1/เดือน
   ต่ออายุอัตโนมัติ ยกเลิกได้ทุกเมื่อ) ให้ agent สั่งจ่ายแทน + โพลเช็กเงินเข้า
   ส่วนสแกน WeChat/Huawei IAP ให้แค่ชี้ทาง
5. **แก้ปัญหา error**: รหัสยืนยันไม่เข้า ชื่อผู้ใช้/อีเมลถูกใช้ 403 ยังไม่เปิดใช้งาน บัญชีถูกล็อก และปัญหาที่พบบ่อยอื่น ๆ
   ทั้งหมดมาจากซอร์สโค้ดของแพลตฟอร์มและระบุที่มาไว้

## ความปลอดภัย

- **รหัสผ่าน** ส่งเข้าโพรเซสของสคริปต์ทางตัวแปรสภาพแวดล้อมเท่านั้น ห้ามใส่ในพารามิเตอร์บรรทัดคำสั่ง
  ห้ามเขียนลงดิสก์ ห้ามเข้าไฟล์สถานะ รหัสที่ agent สร้างแสดงครั้งเดียวให้ผู้ใช้บันทึก
- **รหัสยืนยัน** ใช้กับ API สมัครทางการเท่านั้น ทิ้งทันทีที่ใช้เสร็จ ไฟล์สถานะ (อีเมล/ชื่อผู้ใช้/token/เลขออเดอร์)
  เก็บในไดเรกทอรี temp ของระบบ จบกระบวนการแล้ว `cleanup` เคลียร์ในคำสั่งเดียว
- **การจ่ายเงิน**: agent แค่สร้างออเดอร์ เปิดหน้าชำระเงิน เช็กเงินเข้า ห้ามแตะบัญชี Alipay/PayPal หรือหลักฐานการจ่ายเงิน
  ของผู้ใช้ ห้ามจ่ายแทน การจ่ายเงินเกิดขึ้นระหว่างผู้ใช้กับหน้าชำระเงินทางการเสมอ
- request ทั้งหมดส่งไปยังโดเมนทางการ `https://global.powpow.online` เท่านั้น ไม่มีคีย์ใด ๆ
