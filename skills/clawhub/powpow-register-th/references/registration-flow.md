# รายละเอียดขั้นตอนการสมัคร — powpow-register

เปิดดูเมื่อต้องตรวจหาปัญหา กฎทั้งหมดมาจากโค้ดแพลตฟอร์ม (การตรวจสอบสอดคล้องหน้า/หลังของ Next.js) ระบุที่มาไว้
แพลตฟอร์มอัปเดตยึดพฤติกรรมจริงออนไลน์เป็นหลัก

## จุดเข้า

- หน้าสมัคร: https://global.powpow.online/register
- หน้าเข้าสู่ระบบ: https://global.powpow.online/login
- หน้าแพ็กเกจ: https://global.powpow.online/subscription
- ถ้าเข้าจากลิงก์แชร์ที่มี `?next=...` พอสมัคร+จ่ายเสร็จจะกระโดดกลับหน้าเดิมอัตโนมัติ

## ฟิลด์ฟอร์มกับกฎ

| ฟิลด์ | บังคับ | กฎ | ที่มาโค้ด |
|---|---|---|---|
| รูปโปรไฟล์ | ไม่บังคับ | รูป ≤5MB ไม่รองรับ SVG; เซิร์ฟเวอร์บีบอัดอัตโนมัติ (>100KB บีบเป็น 400×400 / คุณภาพ 90) | `src/app/api/auth/register/route.ts` |
| ชื่อผู้ใช้ | บังคับ | 2~50 ตัวอักษร หลัง trim แปลง**พิมพ์เล็ก**ก่อนเก็บ (Tom กับ tom ถือเป็นชื่อเดียวกัน ทั้งฝั่งสมัครและเข้าสู่ระบบไม่แบ่งพิมพ์ใหญ่/เล็ก) | เดียวกัน (zod schema) |
| รหัสผ่าน | บังคับ | 8~100 ตัว ต้องมีตัวพิมพ์ใหญ่ พิมพ์เล็ก ตัวเลขครบ | เดียวกัน |
| ยืนยันรหัสผ่าน | บังคับ | ตรงกับรหัสผ่าน (ตรวจฝั่งหน้าเท่านั้น) | `src/app/(public)/register/page.tsx` |
| ชื่อเล่น | ไม่บังคับ | ≤100 ตัวอักษร; ไม่กรอกใช้ชื่อผู้ใช้แทน | register route |
| อีเมล | **บังคับ** | รูปแบบอีเมลถูกต้อง ≤255 ตัวอักษร; หนึ่งอีเมลสมัครได้บัญชีเดียว | register route |
| รหัสยืนยันอีเมล | **บังคับ** | ตัวเลข 6 หลัก; **อายุ 10 นาที**; ยืนยันสำเร็จแล้วใช้ไม่ได้อีก; ส่งใหม่จะทำรหัสเก่าเป็นใช้แล้ว | `src/lib/email-verification.ts` |
| เบอร์โทร | ไม่บังคับ | เบอร์แผ่นดินใหญ่จีนขึ้นต้น `1[3-9]` รวม 11 หลัก; หนึ่งเบอร์ผูกบัญชีเดียว | register route |

หน้าอีกทั้งมีปุ่มเข้าสู่ระบบบุคคลที่สามสามปุ่ม: **Google, Watcha, บัญชี Huawei** (`GoogleSignInButton` /
`WatchaLoginButton` / `HuaweiLoginButton`) บัญชีบุคคลที่สามไม่มีรหัสผ่านในเครื่อง ต่อไปเข้าสู่ระบบด้วยรหัสผ่านจะได้
"该账号未设置密码，请使用其他方式登录" (บัญชีนี้ยังไม่ได้ตั้งรหัสผ่าน กรุณาใช้วิธีอื่นเข้าสู่ระบบ)

## ตัวจำกัดอัตราและกันโจมตี

| พฤติกรรม | ข้อจำกัด | ที่มา |
|---|---|---|
| ส่งแบบฟอร์มสมัคร | **3 ครั้ง/นาที/IP** เกินเป็น 429 | `src/lib/rate-limit.ts` `REGISTER_RATE_LIMIT` |
| ส่งรหัสยืนยัน | IP เดียวกัน 1 ครั้ง/นาที **และ** อีเมลเดียวกัน 1 ครั้ง/นาที เกินเป็น 429; ปุ่มหน้าปั๊มนับถอยหลัง 60 วินาที | `src/app/api/auth/register/send-code/route.ts` |
| ตรวจรหัสยืนยัน | ต่ออีเมล ใน 10 นาทีลองได้สูงสุด **5 ครั้ง** ถึงขีดแม้รหัสถูกก็ปฏิเสธ ต้องส่งใหม่ | `src/lib/email-verification.ts` |
| ส่งรหัสลืมรหัสผ่าน | 1 ครั้ง/นาที/IP | `src/app/api/auth/forgot-password/route.ts` |
| เข้าสู่ระบบ | 5 ครั้ง/นาที/IP; บัญชีเดียวกันลองผิดติดกัน **5 ครั้งล็อก 30 นาที** (423) ระหว่างนั้นแจ้งจำนวนครั้งเหลือลดลง | `src/app/api/auth/login/route.ts`、`rate-limit.ts` |

**พฤติกรรมปกป้องความเป็นส่วนตัว**: ตอนส่งรหัสยืนยัน/ลืมรหัสผ่าน ถ้าอีเมลสมัครแล้วหรือไม่มีอยู่ หน้า API ส่งกลับ
ข้อความสำเร็จเหมือนกันทั้งหมด ไม่เผยว่าอีเมลสมัครแล้วหรือยัง

## การเปลี่ยนสถานะหลังสมัครสำเร็จ

1. ผู้ใช้บันทึกด้วย `accountStatus: 'pending'` มี **3 ตรา** เริ่มต้น (register route)
2. เซิร์ฟเวอร์วาง cookie HttpOnly สองตัวพร้อมกัน: JWT (เข้าถึง `/subscription` ได้ตรง) กับ
   pendingUserToken (หลักฐานยืนยันตัวในขั้นตอนสมัครสมาชิก)
3. หน้าสมัครเจอ `pending_payment` → กระโดด `/subscription` (เก็บพารามิเตอร์กลับ `next`)
4. จ่ายเสร็จ → `accountStatus` เปลี่ยน `active` (PayPal ผ่าน Webhook เปิดใช้อัตโนมัติ; WeChat สแกน QR
   ยืนยันด้วยคน; Huawei IAP ผ่าน `activate-huawei`) รายละเอียดดู `payment-and-activation.md`

ผู้ใช้ยังไม่เปิดใช้ (pending) เรียก API หลัก (ฟีด แผนที่ คุยมนุษย์ดิจิทัล เช็คอิน ฯลฯ) ได้ 403 ทั้งหมด
ยกเว้นลิงก์โพสต์ที่แชร์ (เปิดสาธารณะได้อยู่)

## ตารางตรวจหาข้อผิดพลาดพบบ่อย

| อาการ (ข้อความแจ้งต้นฉบับภาษาจีน) | สาเหตุ | วิธีแก้ |
|---|---|---|
| 「用户名已存在」 (ชื่อผู้ใช้มีอยู่แล้ว) | ชื่อผู้ใช้ถูกใช้แล้ว (ไม่แบ่งพิมพ์ใหญ่/เล็ก) | เปลี่ยนชื่อผู้ใช้ |
| 「邮箱已被使用」 (อีเมลถูกใช้แล้ว) | อีเมลสมัครไปแล้ว | เปลี่ยนอีเมล; หรือเข้าสู่ระบบ + "ลืมรหัสผ่าน" กู้บัญชีเก่า |
| 「邮箱验证码错误或已过期」 (รหัสยืนยันอีเมลผิดหรือหมดอายุแล้ว) | พิมพ์รหัสผิด / เกิน 10 นาที / ลองผิดเกิน 5 ครั้งถูกปฏิเสธ | กด "ส่งใหม่" ใช้รหัสใน**อีเมลล่าสุด** |
| ไม่ได้รับรหัสยืนยัน | ถูกจำกัด 60 วินาที; หรือไปอยู่สแปม/โฆษณา | รอให้ครบเวลานับถอยหลังแล้วส่งใหม่; ลองเปิดโฟลเดอร์สแปม |
| 「手机号已被使用」 (เบอร์โทรถูกใช้แล้ว) | เบอร์ผูกบัญชีอื่นแล้ว | เอาเบอร์ออก (ไม่บังคับ) หรือเปลี่ยนเบอร์ |
| 「注册请求过于频繁」/ 429 (ส่งคำขอสมัครถี่เกินไป) | ถึงขีดสมัคร 3 ครั้ง/นาที/IP | รอสักสองสามนาทีแล้วลองใหม่ |
| 409「用户名或邮箱已被注册」 (ชื่อผู้ใช้หรืออีเมลถูกสมัครแล้ว) | ชนชื่อกับคนอื่นตอนส่งพอดี (กันชนพร้อมกัน) | เปลี่ยนชื่อผู้ใช้หรืออีเมลแล้วลองใหม่ |
| 「图片大小不能超过5MB」/「不支持 SVG」 (รูปใหญ่เกิน 5MB ไม่ได้ / ไม่รองรับ SVG) | รูปโปรไฟล์ไม่ตรงกฎ | เปลี่ยนรูปหรือข้ามรูปโปรไฟล์ |
| สมัครสำเร็จแต่เข้าสู่ระบบ 403「请完成订阅以激活账户」 (กรุณาทำการสมัครสมาชิกให้เสร็จเพื่อเปิดใช้บัญชี) | บัญชียังเป็น pending | หลังเข้าสู่ระบบทำตามคำแนะนำไป `/subscription` สมัครสมาชิกให้เสร็จ |
| เข้าสู่ระบบ 423「账户已锁定」 (บัญชีถูกล็อกแล้ว) | พิมพ์รหัสผิดติดกัน 5 ครั้ง | รอ 30 นาที |
| เข้าสู่ระบบ 401「还剩 N 次尝试机会」 (เหลือโอกาสลอง N ครั้ง) | รหัสผิด ใกล้ถูกล็อก | คิดให้ดีก่อนลอง หรือไป "ลืมรหัสผ่าน" เลย |
| 「该账号未设置密码，请使用其他方式登录」 (บัญชีนี้ยังไม่ได้ตั้งรหัสผ่าน กรุณาใช้วิธีอื่นเข้าสู่ระบบ) | บัญชีบุคคลที่สาม (Google/Watcha/华为) | ใช้ปุ่มบุคคลที่สามเดิมเข้าสู่ระบบ |
| 「该账号已注销」 (บัญชีนี้ถูกปิดแล้ว) | บัญชีถูก deactivate แล้ว | ต้องสมัครใหม่ |

## ความรู้เล็ก ๆ เรื่องเข้าสู่ระบบ (ใช้ตรวจได้ด้วย)
