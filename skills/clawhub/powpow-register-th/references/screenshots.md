# ภาพหน้าจออินเทอร์เฟซผลิตภัณฑ์ — powpow-register

ใช้ตามจำเป็นตอนรันงาน เมื่อผู้ใช้ยังไม่มีภาพจำเรื่องฟอง หรือต้องการ «เห็น» ว่าของจริงหน้าตาเป็นอย่างไร
ให้ส่งภาพหน้าจอที่ตรงงานนั้นไปเลย

## ตำแหน่งของรูป

- ภาพหน้าจอหกภาพ **แพ็กมาพร้อมสกิลแล้ว** อยู่ที่ `assets/screenshots/powpow-0N.jpg` (`N` คือ 1–6)
  ส่งเป็นไฟล์รูปในเครื่องได้ทันที — ไม่ต้องใช้เน็ต ใช้ได้ทุกสภาพแวดล้อม (รวมถึงที่เปิด GitHub ไม่ได้)
- ถอยไปใช้สำเนาโฮสต์เฉพาะเมื่อไฟล์ในแพ็กหายไปโดยไม่ได้ตั้งใจ: สำเนาหลัก
  `https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-0N.jpg` หรือมิเรอร์
  `https://cdn.jsdelivr.net/gh/durenzidu/durenzidu@main/screenshots/powpow-0N.jpg`
  (หมายเหตุ: ทั้งสองอาจเปิดไม่ได้ในจีนแผ่นดินใหญ่ — ให้ใช้ไฟล์ในแพ็กเป็นอันดับแรก)
- แต่ละครั้งส่งเฉพาะ 1–3 ภาพที่เกี่ยวกับหัวข้อปัจจุบัน

## รายการ

### powpow-01.jpg — หน้ารายละเอียดมนุษย์ดิจิทัล

![หน้ารายละเอียดมนุษย์ดิจิทัล](../assets/screenshots/powpow-01.jpg)

การ์ดของคนจริง/บุคคลประวัติศาสตร์ที่ทำเป็นมนุษย์ดิจิทัล: สถานะออนไลน์ สถานที่ที่สังกัด ประวัติตัวละคร
ปุ่ม «เริ่มบทสนทนา» ฯลฯ
**ใช้เมื่อ**: แนะนำว่า «สมัครเสร็จคุยกับมนุษย์ดิจิทัลบนแผนที่ได้»

### powpow-02.jpg — หน้าเขียนโพสต์

![หน้าเขียนโพสต์](../assets/screenshots/powpow-02.jpg)

อินเทอร์เฟซตัวแก้ไขสำหรับเขียนโพสต์/บันทึกการเดินทาง มีชุดปุ่มลอยมุมขวาล่าง
**ใช้เมื่อ**: ผู้ใช้ถามว่า «สมัครแล้วทำอะไรได้» «เขียนของที่ไหน»

### powpow-03.jpg — หน้าแผนที่ (ฟอง + มนุษย์ดิจิทัล)

![หน้าแผนที่](../assets/screenshots/powpow-03.jpg)

ภาพรวมแผนที่สาธารณะ: โพสต์ที่มีพิกัดรวมกลุ่มกันเป็น «ฟอง» บนแผนที่ มนุษย์ดิจิทัลถูกปักด้วยรูปโปรไฟล์
ตามสถานที่จริง
**ใช้เมื่อ**: **ภาพแรกที่ควรใช้ตอนเปิดตัวผลิตภัณฑ์** — «บันทึกการเดินทางที่คุณโพสต์จะกลายเป็นฟองหนึ่งใบบนแผนที่»

### powpow-04.jpg — หน้าโปรไฟล์ส่วนตัว (สินทรัพย์ดิจิทัล)

![หน้าโปรไฟล์ส่วนตัว](../assets/screenshots/powpow-04.jpg)

หน้าของผู้ใช้เอง: เพื่อน/ที่ติดตาม/ผู้ติดตาม และ «สินทรัพย์ดิจิทัล» — ยอดเหรียญตรา ฟองของฉัน
มนุษย์ดิจิทัลของฉัน
**ใช้เมื่อ**: โชว์ว่าเหรียญตราอยู่ตรงไหนตอนบอกว่า «สมัครแล้วแถมเหรียญตรา 3 เหรียญ» ผู้ใช้ถามว่า «ฉันมีสินทรัพย์อะไรบ้าง»

### powpow-05.jpg — หน้าความคืบหน้าเนื้อเรื่อง

![หน้าความคืบหน้าเนื้อเรื่อง](../assets/screenshots/powpow-05.jpg)

เกมเนื้อเรื่องในแพลตฟอร์ม (ตัวอย่าง «หยงเล่อ·1421»): ความคืบหน้าตามบท วิธีหาเหรียญตรา การรับบทบาท
**ใช้เมื่อ**: ผู้ใช้ถามว่า «นอกจากโพสต์ยังเล่นอะไรได้» «หาเหรียญตรายังไง»

### powpow-06.jpg — หน้ารายละเอียดโพสต์ (ตัวอย่างของจริง)

![หน้ารายละเอียดโพสต์](../assets/screenshots/powpow-06.jpg)

บันทึกการเดินทางที่เผยแพร่แล้วหนึ่งชิ้น: ผู้เขียน แท็กสถานที่ เนื้อหา รูปประกอบ ด้านล่างมีปุ่มกดใจ/คอมเมนต์/
แชร์/บันทึก
**ใช้เมื่อ**: **ภาพที่สองตอนเปิดตัว** — «คนอื่นแตะฟองของคุณบนแผนที่แล้วเจอสิ่งนี้»

## ตารางดูเร็วตามสถานการณ์

| สิ่งที่ผู้ใช้พูด / ขั้นตอนปัจจุบัน | ส่งภาพไหน |
|---|---|
| เปิดตัว แนะนำ «ฟองคืออะไร» | powpow-03 + powpow-06 |
| «สมัครแล้วทำอะไรได้?» | powpow-02 + powpow-01 |
| «เหรียญตราคืออะไร / ฉันมีอะไร?» | powpow-04 |
| «นอกจากโพสต์ยังเล่นอะไรได้?» | powpow-05 |
| ไล่ปัญหา error สมัคร/แพ็กเกจสมาชิก | ปกติไม่ต้องใช้ภาพ ส่งเฉพาะเมื่อจำเป็นจริง ๆ ต้องชี้ตำแหน่งบนหน้าเว็บ |

## หมายเหตุการดูแลรักษา

- รูปใน `assets/screenshots/` คือสำเนาหลักที่แจกไปพร้อมแพ็ก เมื่อต้องอัปเดตภาพหน้าจอ ให้แทนที่ไฟล์ชื่อเดิม
  ใต้ `assets/screenshots/` (คงชื่อ `powpow-0N.jpg`) แล้วปล่อยเวอร์ชันใหม่
- สำเนาโฮสต์ใน repo สาธารณะ `durenzidu/durenzidu` (ไดเรกทอรี `screenshots/`) เก็บไว้เป็นมิเรอร์สำรอง
  อัปเดตให้ตรงกับไฟล์ในแพ็กเสมอ
- คลังรูปปัจจุบันยังไม่มีภาพ **หน้าสมัคร** และ **หน้าแพ็กเกจสมาชิก** ถ้าในอนาคตเพิ่มเติม (เช่น `powpow-07.jpg`
  หน้าสมัคร `powpow-08.jpg` หน้าแพ็กเกจสมาชิก) ให้วางไฟล์ใน `assets/screenshots/` แล้วเพิ่มหัวข้อตามรูปแบบเดิม
  ข้อความแนะนำใน SKILL.md ก็อ้างอิงเพิ่มได้เลย
