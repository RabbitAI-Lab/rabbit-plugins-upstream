# ภาพหน้าจอผลิตภัณฑ์ — powpow-register

หยิบใช้ตามต้องการตอนรัน ผู้ใช้ไม่รู้จักฟอง หรือต้อง "เห็น" หน้าตาผลงาน เอาเลยส่งลิงก์ตรง ๆ

  `https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-0N.jpg`

- แต่ละครั้งส่งแค่ 1–3 ภาพที่เกี่ยวข้องกับเรื่องปัจจุบัน

## รายการ

### powpow-01.jpg — หน้ารายละเอียดมนุษย์ดิจิทัล

![หน้ารายละเอียดมนุษย์ดิจิทัล](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-01.jpg)

การ์ดหลังคนจริง/บุคคลประวัติศาสตร์ถูกทำเป็นมนุษย์ดิจิทัล: สถานะออนไลน์ สถานที่ตั้ง ประวัติบุคคล "เริ่มคุย" ฯลฯ
**ใช้ตอน**: แนะนำ "สมัครเสร็จคุยกับมนุษย์ดิจิทัลบนแผนที่ได้"

### powpow-02.jpg — หน้าแก้ไขโพสต์

![หน้าแก้ไขโพสต์](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-02.jpg)

หน้าจอเขียนโพสต์/บันทึกการเดินทาง มุมขวาล่างมีปุ่มลอยกลุ่มหนึ่ง
**ใช้ตอน**: ผู้ใช้ถาม "สมัครเสร็จทำอะไรได้บ้าง" "เขียนที่ไหน"

### powpow-03.jpg — หน้าแผนที่ (ฟอง + มนุษย์ดิจิทัล)

![หน้าแผนที่](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-03.jpg)

ภาพรวมแผนที่สาธารณะ: โพสต์ที่มีสถานที่รวมกันเป็น "ฟอง" บนแผนที่ มนุษย์ดิจิทัลปักหัวไว้ที่จุดจริง
**ใช้ตอน**: **ภาพแรกที่เปิดแนะนำผลิตภัณฑ์** — "บันทึกการเดินทางที่คุณโพสต์จะกลายเป็นฟองหนึ่งบนแผนที่"

### powpow-04.jpg — โปรไฟล์ส่วนตัว (ทรัพย์สินดิจิทัล)

![โปรไฟล์ส่วนตัว](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-04.jpg)

หน้าของผู้ใช้เอง: เพื่อน/กำลังติดตาม/ผู้ติดตาม และ "ทรัพย์สินดิจิทัล" — ยอดตรา ฟองของฉัน มนุษย์ดิจิทัลของฉัน
**ใช้ตอน**: "สมัครแถม 3 ตรา" โชว์ว่าตราอยู่ตรงไหน; ผู้ใช้ถาม "ฉันมีทรัพย์สินอะไร"

### powpow-05.jpg — หน้าความคืบหน้าเนื้อเรื่อง

![หน้าความคืบหน้าเนื้อเรื่อง](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-05.jpg)

โหมดเนื้อเรื่องในแพลตฟอร์ม (ตัวอย่าง「หย่งเล่อ · 1421」): ความคืบหน้าบทสะสมตรา เล่นบทบาท
**ใช้ตอน**: ผู้ใช้ถาม "นอกจากโพสต์แล้วเล่นอะไรได้อีก" "ตราหามาได้ยังไง"

### powpow-06.jpg — หน้าโพสต์ (ตัวอย่างผลงาน)

![หน้าโพสต์](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-06.jpg)

บันทึกการเดินทางที่โพสต์ไปแล้ว: ผู้เขียน แท็กสถานที่ เนื้อหา รูปประกอบ ล่างกดไลก์/คอมเมนต์/แชร์/บันทึกได้
**ใช้ตอน**: **ภาพที่สองตอนเปิดเรื่อง** — "คนอื่นกดฟองของคุณบนแผนที่ เห็นคือเจ้านี่"

## ตรวจเร็วตามสถานการณ์

| สิ่งที่ผู้ใช้พูด / ช่วงนั้น | ส่งภาพไหน |
|---|---|
| เปิดเรื่อง "ฟองคืออะไร" | powpow-03 + powpow-06 |
| "สมัครเสร็จทำอะไรได้บ้าง?" | powpow-02 + powpow-01 |
| "ตราคืออะไร / ฉันมีอะไร?" | powpow-04 |
| "นอกจากโพสต์เล่นอะไรได้อีก?" | powpow-05 |
| ตรวจหาข้อผิดพลาดสมัคร/สมาชิก | ปกติไม่ต้องรูป; จำเป็นต้องอธิบายตำแหน่งหน้าจริง ๆ ค่อยส่ง |
