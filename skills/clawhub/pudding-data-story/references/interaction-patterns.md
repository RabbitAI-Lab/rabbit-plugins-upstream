# Interaction and visual grammar

Choose a pattern because it expresses the argument. Combine patterns only when the transition between them has semantic meaning.

## Authored scrollytelling

Use when the order of discoveries matters.

- Keep the graphic sticky and the document scroll native.
- Give each step one claim and one visual state.
- Reveal, annotate, sort, zoom, or filter marks as the copy advances.
- Restore states when scrolling upward.
- Prefer discrete steps; use continuous progress only for a genuinely continuous phenomenon.

Avoid:

- intercepting wheel or touch gestures;
- using scroll distance as decoration;
- putting essential controls underneath a sticky layer;
- step copy that merely says what the animation does.

## Concrete-to-population reveal

Use when individual examples humanize a distribution.

1. Show one case with its own identity.
2. Introduce comparison cases.
3. preserve the original case as the field fills.
4. reveal distribution, clusters, or outliers.
5. return to the original case with new context.

Good marks: dots, cards, small multiples, trajectories, or image samples. Keep each mark semantically stable.

## Search-first exploration

Use when readers have a natural place, name, category, or identity to look up.

- Start with a strong curated example so the page is meaningful before input.
- Add search with typeahead and forgiving matching.
- Provide shareable state in the URL when practical.
- Keep global context visible after selection.
- Offer curated entry points for readers who do not know what to search.
- State data caveats next to results that depend on them.

## Synchronized media timeline

Use for conversations, performances, processes, or sequences.

- Synchronize visual events to audio/video time.
- Allow scrubbing and direct selection.
- Keep a readable transcript or textual equivalent.
- Make the timeline useful even when media cannot autoplay.
- Show how one sequence compares with the full corpus after the concrete example.

## Playable model

Use when friction, constraints, or causality are the thesis.

- Turn the real mechanism into the rules of the interaction.
- Keep the model legible: the reader should know what each obstacle or parameter represents.
- Avoid gamifying harm with rewards or jokey feedback.
- Provide a non-playable summary and direct navigation.
- Separate modeled assumptions from observed facts.

## Participatory experiment

Use when reader input genuinely creates evidence or reveals emergence.

- Explain what will be collected before input.
- Minimize personal data.
- Show consent, moderation, and accessibility constraints.
- Return immediate feedback without overstating what one contribution proves.
- Reveal the aggregate and methodology.
- Provide an observer mode for readers who do not participate.

## Simulation and uncertainty

Use when repeated possible outcomes are more truthful than one forecast.

- Keep assumptions editable and visible.
- Show distributions, intervals, or repeated trials.
- Explain randomness and seed/reproducibility where relevant.
- Never animate a single lucky run as the expected result.

## Small multiples

Use when the same question applies across many entities.

- Keep scales and encodings consistent.
- Provide sorting or meaningful grouping.
- Highlight selected cases without removing context.
- Use progressive loading or virtualization for large sets.
- On mobile, use a single-column reading order or a focused selector.

## Motion rules

Motion should:

- preserve identity;
- direct attention;
- expose change;
- show causality or sequence;
- complete quickly enough that the reader stays in control.

Motion should not:

- loop for ambiance;
- hide axis or denominator changes;
- transform unrelated quantities into identical marks;
- delay access to evidence;
- make reduced-motion users lose information.

## Copy rules

Interface copy should answer the reader's question:

- “Find your county,” not “Choose a lens.”
- “Compare with 2010,” not “Push the data.”
- “What changes if the threshold is 20%?” not “Try the simulator.”

Published narrative copy describes the world, not the designer's intent.
