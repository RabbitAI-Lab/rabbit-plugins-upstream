## Known Risks and Mitigations:

Risk: The skill can upload reference media and download generated assets through AI-HIVE workflows.

Mitigation: Use only media the user is authorized to upload, and confirm where generated assets will be stored before running commands.

Risk: AI-HIVE generation tasks may require an API key and can involve paid image or video generation.

Mitigation: Keep API keys out of logs and shared repositories, and review prompts, routing mode, model choices, and estimated costs before submitting tasks.

Risk: Ecommerce content can include unsupported claims, false testimonials, or platform-rule violations.

Mitigation: Ground claims in verified product facts, avoid fabricated endorsements or guaranteed outcomes, and perform human review before publishing.

Risk: Reference-based content planning can become too close to protected source material.

Mitigation: Use authorized references only and retain abstract structure, not protected wording, logos, watermarks, music, or distinctive scene composition.
