## 概览
本指南说明SPC分析中6种标准控制图的类型、数据格式要求和适用场景，帮助用户选择正确的控制图类型。

## 控制图类型

### 1. Xbar-R图（均值-极差图）
**适用数据类型：** 计量型数据（连续值）  
**适用场景：**
- 子组大小为2-10个观测值
- 数据以子组形式收集（每次采集多个样品）
- 监控过程均值和波动

**数据格式：**
- Excel表格，每行代表一个子组
- 每列代表该子组中的一个观测值
- 至少需要2列数据

**示例数据：**
```
样品1  样品2  样品3  样品4
25.1   25.3   25.0   25.2
24.8   25.1   25.2   24.9
25.0   25.0   25.1   25.1
...
```

**使用方法：**
```bash
python scripts/spc_analysis.py --input data.xlsx --chart-type xbarr --output report.html
```

---

### 2. Xbar-S图（均值-标准差图）
**适用数据类型：** 计量型数据（连续值）  
**适用场景：**
- 子组大小大于10个观测值
- 数据以子组形式收集
- 对过程波动更敏感（使用标准差而非极差）

**数据格式：**
- 与Xbar-R图相同
- 每行代表一个子组，每列代表一个观测值
- 至少需要2列数据

**示例数据：**
```
样品1  样品2  样品3  ...  样品12
25.1   25.3   25.0       25.2
24.8   25.1   25.2       24.9
...
```

**使用方法：**
```bash
python scripts/spc_analysis.py --input data.xlsx --chart-type xbars --output report.html
```

**与Xbar-R图的区别：**
- Xbar-S图使用标准差衡量子组内波动，对异常值更敏感
- 当子组大小>10时，推荐使用Xbar-S图

---

### 3. I-MR图（单值-移动极差图）
**适用数据类型：** 计量型数据（连续值）  
**适用场景：**
- 每次只能采集一个样品
- 数据采集周期较长
- 无法形成子组
- 检测缓慢的过程偏移

**数据格式：**
- 单列数据
- 每行代表一个时间点的观测值

**示例数据：**
```
测量值
25.1
25.3
25.0
24.8
...
```

**使用方法：**
```bash
python scripts/spc_analysis.py --input data.xlsx --chart-type imr --output report.html
```

---

### 4. P图（不合格品率图）
**适用数据类型：** 计数型数据（离散值）  
**适用场景：**
- 监控产品的不合格品率
- 每次检验的产品数量不同
- 关注"是否合格"而非"有多少缺陷"

**数据格式：**
- 两列数据：检验数量、不合格数量

**示例数据：**
```
检验数量  不合格数量
100      5
120      8
90       3
...
```

**使用方法：**
```bash
python scripts/spc_analysis.py --input data.xlsx --chart-type p --output report.html
```

---

### 5. C图（缺陷数图）
**适用数据类型：** 计数型数据（离散值）  
**适用场景：**
- 监控固定大小样本中的缺陷数
- 每次检验的样本大小相同
- 关注"有多少缺陷"而非"是否合格"

**数据格式：**
- 单列数据：缺陷数

**示例数据：**
```
缺陷数
5
8
3
6
...
```

**使用方法：**
```bash
python scripts/spc_analysis.py --input data.xlsx --chart-type c --output report.html
```

---

### 6. U图（单位缺陷数图）
**适用数据类型：** 计数型数据（离散值）  
**适用场景：**
- 监控单位产品或单位面积上的缺陷数
- 每次检验的样本大小不同
- 关注"每单位有多少缺陷"

**数据格式：**
- 两列数据：样本量、缺陷数

**示例数据：**
```
样本量  缺陷数
10     5
15     8
8      3
...
```

**使用方法：**
```bash
python scripts/spc_analysis.py --input data.xlsx --chart-type u --output report.html
```

## 数据格式要求

### Excel文件要求
- 格式：.xlsx 或 .xls
- 编码：推荐UTF-8
- 数据位置：默认读取第一个工作表，可通过 `--sheet-name` 参数指定

### 数据质量要求
1. **数值型数据**：必须是数值类型，不能包含文本
2. **无空值**：数据单元格不能为空，空行会被自动删除
3. **连续性**：数据应为连续的时间序列
4. **最小样本量**：
   - Xbar-R/Xbar-S图：至少5个子组
   - I-MR图：至少10个数据点
   - P/C/U图：至少10个样本

### 数据预处理建议
- 删除明显的异常值（除非是为了测试检测规则）
- 确保数据按时间顺序排列
- 检查是否有缺失值并填补

## 适用场景对照表

| 控制图类型 | 数据类型 | 子组大小 | 样本量变化 | 关注指标 |
|-----------|---------|---------|-----------|---------|
| Xbar-R | 计量型 | 2-10 | 固定 | 均值、极差 |
| Xbar-S | 计量型 | >10 | 固定 | 均值、标准差 |
| I-MR | 计量型 | 1 | N/A | 单值、移动极差 |
| P | 计数型 | N/A | 可变 | 不合格品率 |
| C | 计数型 | N/A | 固定 | 缺陷数 |
| U | 计数型 | N/A | 可变 | 单位缺陷数 |

## 常见问题

### Q1: 如何选择Xbar-R图和Xbar-S图？
**A:** 当子组大小≤10时使用Xbar-R图，当子组大小>10时使用Xbar-S图。Xbar-S图对异常值更敏感。

### Q2: 什么时候使用I-MR图？
**A:** 当每次只能采集一个样品，或者数据采集成本高、周期长时使用I-MR图。

### Q3: P图和U图有什么区别？
**A:** P图关注"是否合格"（不合格品率），U图关注"有多少缺陷"（单位缺陷数）。如果你的产品可能同时有多个缺陷，使用U图。

### Q4: 控制限是如何计算的？
**A:** 控制限基于历史数据计算，通常使用3σ原则（均值±3倍标准差）。不同控制图类型使用不同的常数和公式。

### Q5: 数据量太少怎么办？
**A:** 建议至少收集20-30个数据点后再进行分析。数据太少会导致控制限不准确，影响分析结果的可靠性。

---

## 注意事项
1. 确保数据类型与选择的控制图类型匹配
2. 数据应按照时间顺序排列
3. 避免在数据中混入不同特性的测量值
4. 定期检查控制限的有效性，必要时重新计算
5. 结合业务知识解释分析结果，不要仅依赖统计规则
