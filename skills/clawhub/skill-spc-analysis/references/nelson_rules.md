## 概览
Nelson规则是一套用于识别控制图中异常模式的统计规则，由Lloyd S. Nelson于1984年提出。这些规则帮助识别过程是否失去统计控制，而不仅仅是检测超出控制限的单点。

## 规则概述

Nelson 8条规则分为两类：
1. **点规则**：规则1 - 检测超出控制限的点
2. **模式规则**：规则2-8 - 检测数据序列中的异常模式

**目的：**
- 提高异常检测的敏感性
- 识别过程变化的早期信号
- 区分随机变异和特殊原因变异

---

## 详细说明

### 规则1：1个点超出3σ控制限

**描述：** 有1个数据点落在控制限之外（UCL之上或LCL之下）

**含义：** 过程出现特殊原因变异，需要立即调查

**严重程度：** ⭐⭐⭐⭐⭐（最高）

**示例：**
```
数据点 #15 = 28.5，而UCL = 27.0
→ 违反规则1
```

**可能原因：**
- 设备故障
- 操作错误
- 原材料异常
- 测量系统错误

**应对措施：**
- 立即停止生产
- 调查根本原因
- 采取纠正措施
- 验证措施有效性

---

### 规则2：连续9个点落在中心线同一侧

**描述：** 连续9个数据点都落在中心线（CL）的同一侧（全部在上方或全部在下方）

**含义：** 过程均值发生偏移

**严重程度：** ⭐⭐⭐⭐

**示例：**
```
数据点 #5-#13 全部 > CL
→ 违反规则2（连续9点在中心线上方）
```

**可能原因：**
- 设备磨损
- 工具设置改变
- 环境温度变化
- 操作员习惯变化

**应对措施：**
- 检查设备设置
- 校准测量系统
- 培训操作员
- 调整过程参数

---

### 规则3：连续6个点持续递增或递减

**描述：** 连续6个数据点呈现持续递增或持续递减的趋势

**含义：** 过程存在趋势性变化

**严重程度：** ⭐⭐⭐⭐

**示例：**
```
数据点 #7-#12: 24.1, 24.3, 24.5, 24.7, 24.9, 25.1
→ 违反规则3（连续6点持续递增）
```

**可能原因：**
- 工具磨损
- 化学试剂浓度变化
- 温度逐渐变化
- 设备老化

**应对措施：**
- 定期维护设备
- 监控关键参数
- 实施预防性维护
- 考虑工具更换周期

---

### 规则4：连续14个点交替上下

**描述：** 连续14个数据点交替出现在中心线上方和下方

**含义：** 可能存在分层化（Stratification）或混合问题

**严重程度：** ⭐⭐⭐

**示例：**
```
数据点序列: 上, 下, 上, 下, 上, 下, ...（14个点）
→ 违反规则4（连续14点交替上下）
```

**可能原因：**
- 数据来自多个不同来源混合
- 测量系统精度不足
- 两个不同的过程混合在一起
- 采样方式不当

**应对措施：**
- 检查数据来源是否一致
- 改进测量系统精度
- 分离不同来源的数据
- 优化采样方法

---

### 规则5：连续3个点中有2个点落在2σ区域之外（中心线同一侧）

**描述：** 连续3个数据点中，有2个点落在中心线同一侧的2σ区域之外（即中心线±2σ之外）

**含义：** 过程开始发生偏移的早期信号

**严重程度：** ⭐⭐⭐

**示例：**
```
CL = 25.0, σ = 1.0
2σ上限 = 27.0, 2σ下限 = 23.0
数据点 #8=27.2, #9=27.5, #10=25.3
→ 违反规则5（2个点在2σ上限之外）
```

**可能原因：**
- 过程参数调整
- 原材料批次变化
- 新操作员

**应对措施：**
- 检查最近的变更
- 验证原材料质量
- 观察后续数据点
- 准备调整计划

---

### 规则6：连续5个点中有4个点落在1σ区域之外（中心线同一侧）

**描述：** 连续5个数据点中，有4个点落在中心线同一侧的1σ区域之外（即中心线±1σ之外）

**含义：** 过程均值轻微偏移

**严重程度：** ⭐⭐⭐

**示例：**
```
CL = 25.0, σ = 1.0
1σ上限 = 26.0, 1σ下限 = 24.0
数据点 #11-#15中，4个点 > 26.0
→ 违反规则6
```

**可能原因：**
- 过程参数轻微漂移
- 环境条件变化
- 测量系统校准偏差

**应对措施：**
- 密切监控趋势
- 检查环境条件
- 重新校准设备
- 调整过程参数

---

### 规则7：连续15个点落在1σ区域之内

**描述：** 连续15个数据点都落在中心线±1σ的范围内

**含义：** 分层化（Stratification）- 数据过度集中在中心线附近

**严重程度：** ⭐⭐

**示例：**
```
所有数据点都在 CL ± 1σ 范围内
→ 违反规则7
```

**可能原因：**
- 数据来自多个不同来源的混合
- 控制限计算错误
- 测量系统分辨率不足
- 数据被不当调整

**应对措施：**
- 检查数据收集方法
- 验证控制限计算
- 改进测量系统精度
- 调查数据来源

---

### 规则8：连续8个点落在1σ区域之外（中心线同一侧）

**描述：** 连续8个数据点都落在中心线同一侧的1σ区域之外

**含义：** 混合（Mixture）- 存在多个不同分布的混合

**严重程度：** ⭐⭐⭐

**示例：**
```
连续8个点全部 > CL + 1σ
→ 违反规则8
```

**可能原因：**
- 两个不同的过程混合
- 设备或工具差异
- 不同班次或操作员差异
- 原材料批次差异

**应对措施：**
- 分层数据分析
- 按班次、设备等分组
- 检查原材料一致性
- 标准化操作流程

---

## 应用建议

### 规则使用策略

1. **规则1必须使用**
   - 规则1是基础，任何控制图都应检测

2. **规则2-6推荐使用**
   - 对于大多数制造业场景，使用规则1-6即可
   - 能够有效识别过程偏移和趋势

3. **规则7-8谨慎使用**
   - 这两条规则对数据分层和混合敏感
   - 在特定场景下才有意义

4. **自定义规则集**
   - 根据行业特点和过程特性选择规则
   - 可以增加更严格的规则（如连续8点在中心线同一侧）

### 严重程度分级

| 严重程度 | 规则 | 响应时间 |
|---------|------|---------|
| 最高 | 1 | 立即 |
| 高 | 2, 3 | 当班内 |
| 中 | 5, 6, 8 | 24小时内 |
| 低 | 4, 7 | 下次审核 |

### 多规则同时触发

当多个规则同时触发时：
1. 优先处理严重程度最高的规则
2. 调查是否存在共同的根本原因
3. 记录所有触发的规则
4. 分析规则之间的关联性

## 示例

### 示例1：规则1触发

**场景：** 某工厂测量产品厚度

**数据：**
```
时间点:  1    2    3    4    5    6    7    8
厚度:   10.1 10.2 10.0 10.1 10.2 10.1 12.5 10.2
                    ↑
                  异常点
```

**控制限：**
- UCL = 11.0
- CL = 10.1
- LCL = 9.2

**分析：**
- 时间点7的厚度=12.5，超出UCL=11.0
- 触发规则1

**应对：**
- 立即停止生产
- 检查设备状态
- 重新测量验证
- 排除测量错误

---

### 示例2：规则2和规则5同时触发

**场景：** 某化学反应器温度监控

**数据：**
```
时间点:  1    2    3    4    5    6    7    8    9
温度:   85.0 85.2 85.5 86.0 86.3 86.8 87.2 87.5 87.8
         → 连续9点在CL上方（规则2）
         → 点7-9在2σ之外（规则5）
```

**控制限：**
- UCL = 90.0
- CL = 85.0
- LCL = 80.0
- σ = 1.67

**分析：**
- 规则2：连续9个点（点1-9）都在CL上方
- 规则5：点7-9中，有2个点在2σ上限之外

**结论：** 过程均值向上偏移

**应对：**
- 检查加热系统
- 调整温度设定
- 监控后续数据
- 更新控制限（如必要）

---

### 示例3：规则3触发

**场景：** 刀具磨损监控

**数据：**
```
时间点:  1    2    3    4    5    6
尺寸:   25.0 25.1 25.2 25.3 25.4 25.5
         → 连续6点持续递增（规则3）
```

**分析：**
- 尺寸持续增大，表明刀具磨损

**应对：**
- 预测何时达到规格限
- 安排刀具更换
- 更换后重新计算控制限

## 常见误解

### 误解1：规则1就足够了
**纠正：** 规则1只能检测超出控制限的点，无法检测趋势、偏移等模式。建议使用规则1-6。

### 误解2：违反规则就说明过程失控
**纠正：** Nelson规则给出的是信号，需要结合业务知识和实际情况判断。有些违规可能是由于数据特性导致的假阳性。

### 误解3：规则越多越好
**纠正：** 过多的规则会增加假阳性率，导致过度调整。应根据过程特性选择合适的规则集。

### 误解4：所有规则都适用于所有控制图
**纠正：** 某些规则对特定控制图更敏感。例如，规则7和8在P图和U图中更常见。

---

## 注意事项
1. Nelson规则是基于3σ统计原理的，确保控制限计算正确
2. 对于过程刚开始，数据量较少时，谨慎使用模式规则
3. 记录所有触发的规则，便于后续分析和改进
4. 结合行业标准和客户要求调整规则严格程度
5. 定期回顾和更新规则集
