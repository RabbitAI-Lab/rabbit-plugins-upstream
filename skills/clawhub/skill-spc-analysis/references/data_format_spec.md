## 概览
本文档定义SPC分析脚本所需的数据格式规范，确保数据能够被正确读取和处理。

## 通用要求

### 文件格式
- **文件类型：** Excel文件（.xlsx 或 .xls）
- **编码：** 推荐UTF-8
- **工作表：** 默认读取第一个工作表，可通过参数指定工作表名称

### 数据质量
- **无空行：** 空行会被自动删除
- **无空值：** 关键数据列不能包含空值
- **数值类型：** 数值型数据必须是真正的数值，不能是文本
- **时间顺序：** 数据应按照时间顺序从上到下排列

### 最小样本量
- Xbar-R/Xbar-S图：至少5个子组
- I-MR图：至少10个数据点
- P/C/U图：至少10个样本

## 各控制图数据格式

### Xbar-R图 / Xbar-S图

**数据结构：**
- 多列数据
- 每行代表一个子组
- 每列代表该子组中的一个观测值
- 至少需要2列

**Excel示例：**

| A列 | B列 | C列 | D列 |
|-----|-----|-----|-----|
| 样品1 | 样品2 | 样品3 | 样品4 |
| 25.1 | 25.3 | 25.0 | 25.2 |
| 24.8 | 25.1 | 25.2 | 24.9 |
| 25.0 | 25.0 | 25.1 | 25.1 |
| 25.2 | 25.1 | 24.9 | 25.0 |

**格式验证：**
```python
# 验证条件
- len(data.columns) >= 2
- 所有列都是数值型
- 每个子组大小 >= 2
```

**常见错误：**
- ❌ 单列数据
- ❌ 包含文本列
- ❌ 子组大小不一致

---

### I-MR图

**数据结构：**
- 单列数据
- 每行代表一个时间点的观测值

**Excel示例：**

| A列 |
|-----|
| 测量值 |
| 25.1 |
| 25.3 |
| 25.0 |
| 24.8 |
| 25.2 |

**格式验证：**
```python
# 验证条件
- len(data.columns) == 1
- 数据列是数值型
- 数据点数量 >= 10
```

**常见错误：**
- ❌ 多列数据
- ❌ 包含文本
- ❌ 数据点太少（<10）

---

### P图

**数据结构：**
- 两列数据
- 第一列：检验数量（inspection）
- 第二列：不合格数量（defective）

**Excel示例：**

| A列 | B列 |
|-----|-----|
| 检验数量 | 不合格数量 |
| 100 | 5 |
| 120 | 8 |
| 90 | 3 |
| 110 | 6 |

**格式验证：**
```python
# 验证条件
- len(data.columns) == 2
- 两列都是数值型
- 不合格数量 <= 检验数量
- 所有检验数量 > 0
```

**数据约束：**
- 不合格率 = 不合格数量 / 检验数量
- 0 ≤ 不合格率 ≤ 1

**常见错误：**
- ❌ 不合格数量 > 检验数量
- ❌ 检验数量为0或负数
- ❌ 列顺序颠倒

---

### C图

**数据结构：**
- 单列数据
- 每行代表一个样本的缺陷数

**Excel示例：**

| A列 |
|-----|
| 缺陷数 |
| 5 |
| 8 |
| 3 |
| 6 |
| 4 |

**格式验证：**
```python
# 验证条件
- len(data.columns) == 1
- 数据列是数值型
- 所有缺陷数 >= 0
```

**数据约束：**
- 缺陷数 ≥ 0
- 通常适用于缺陷数服从泊松分布的情况

**常见错误：**
- ❌ 缺陷数为负数
- ❌ 包含非整数

---

### U图

**数据结构：**
- 两列数据
- 第一列：样本量（sample_size）
- 第二列：缺陷数（defects）

**Excel示例：**

| A列 | B列 |
|-----|-----|
| 样本量 | 缺陷数 |
| 10 | 5 |
| 15 | 8 |
| 8 | 3 |
| 12 | 6 |

**格式验证：**
```python
# 验证条件
- len(data.columns) == 2
- 两列都是数值型
- 样本量 > 0
- 缺陷数 >= 0
- 缺陷数 <= 样本量（对于单位产品）
```

**数据约束：**
- 单位缺陷数 = 缺陷数 / 样本量
- 样本量 > 0
- 缺陷数 ≥ 0

**常见错误：**
- ❌ 样本量为0或负数
- ❌ 缺陷数为负数
- ❌ 列顺序颠倒

## Excel文件规范

### 文件命名
- 推荐使用描述性名称：`product_diameter_2024.xlsx`
- 避免使用特殊字符和空格
- 使用下划线或驼峰命名法

### 工作表结构

**单工作表：**
```
Sheet1: 数据
```

**多工作表：**
```
Sheet1: 2024年1月数据
Sheet2: 2024年2月数据
...
```

使用 `--sheet-name` 参数指定工作表：
```bash
python scripts/spc_analysis.py --input data.xlsx --sheet-name "2024年1月数据" --chart-type xbarr --output report.html
```

### 表头处理

**有表头：**
- 脚本会自动跳过第一行（假定为表头）
- 表头可以是任何文本，不影响分析

**无表头：**
- 脚本会将第一行当作数据处理
- 建议添加表头以提高数据可读性

### 数据区域
- 数据应该从第一行或第二行开始
- 数据区域外不要有其他内容
- 避免合并单元格

## 格式验证

### 自动验证

脚本会自动验证以下内容：

1. **文件存在性**
   ```python
   if not os.path.exists(input_file):
       raise FileNotFoundError(f"文件不存在: {input_file}")
   ```

2. **数据类型**
   ```python
   if not pd.api.types.is_numeric_dtype(data[column]):
       raise ValueError(f"列 '{column}' 不是数值型")
   ```

3. **数据量**
   ```python
   if len(data) < min_samples:
       raise ValueError(f"数据量不足，至少需要 {min_samples} 个样本")
   ```

4. **业务逻辑**
   ```python
   # P图：不合格数不能超过检验数
   if any(defectives > inspections):
       raise ValueError("不合格数量不能超过检验数量")
   ```

### 验证错误示例

**错误1：文件不存在**
```
错误: 文件不存在: data.xlsx

```

**错误2：数据格式不正确**
```

解决: 检查数据是否包含多列
```

**错误3：数据类型错误**

**错误4：数据量不足**

## 常见问题

### Q1: 可以包含日期列吗？
**A:** 可以，但脚本会忽略非数值列。如果需要日期信息，建议在文件名或报告中说明。

### Q2: 数据有空值怎么办？
**A:** 脚本会自动删除包含空值的整行。建议在提交数据前清理空值。

### Q3: 可以有多余的列吗？
**A:** 可以，但只使用数值型列。建议只包含必要的列以避免混淆。

### Q4: 数据需要排序吗？
**A:** 强烈建议按照时间顺序排列。如果数据顺序混乱，会影响趋势分析。

### Q5: 可以分析历史数据吗？
**A:** 可以。历史数据可以用于建立控制限，但要注意过程是否稳定。

### Q6: 如何处理异常值？
**A:** 除非确定异常值是由于测量错误，否则不应删除。异常值可能包含重要信息。

### Q7: 控制限多久更新一次？
**A:** 建议定期（如每3-6个月）重新计算控制限，或在过程发生显著变化时更新。

### Q8: 可以混合不同规格的产品数据吗？
**A:** 不可以。不同规格的产品应在不同的工作表或文件中分别分析。

## 数据准备清单

在提交数据进行分析前，请检查：

- [ ] 文件格式正确（.xlsx 或 .xls）
- [ ] 数据按照时间顺序排列
- [ ] 删除所有空行和空值
- [ ] 确认数据类型正确（数值型）
- [ ] 确认列数符合控制图类型要求
- [ ] 确认数据量充足（≥最小样本量）
- [ ] 检查业务逻辑（如不合格数≤检验数）
- [ ] 添加有意义的表头
- [ ] 使用描述性的文件名
- [ ] 备份原始数据
