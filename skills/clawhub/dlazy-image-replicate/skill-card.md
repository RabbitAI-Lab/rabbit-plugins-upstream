## Description:

Analyzes a reference image's composition, colors, lighting, and style to guide generation of a similar image with Seedream 4.5.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and designers use this skill to generate an image inspired by a reference image's visual style.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Reference media and prompts are sent to dLazy's hosted service.

Mitigation: Only submit media and prompts you intend to share with the service.

Risk: The external CLI is required, and login can store an API key locally.

Mitigation: Review the pinned CLI package before installation; use the documented on-demand option if preferred and protect the local API key.
