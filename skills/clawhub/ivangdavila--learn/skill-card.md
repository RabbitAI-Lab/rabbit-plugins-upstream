## Description:

Runs self-directed learning as a durable system for curriculum planning, deliberate practice, spaced review, verification, and maintenance.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ivangdavila](https://clawhub.ai/user/ivangdavila)

### License/Terms of Use:

MIT-0

## Use Case:

Learners and agents use this skill to plan self-directed study, run retrieval practice and spaced review, diagnose learning failures, and record durable progress across sessions. It is intended for learning systems around skills and subjects, not for one-off concept teaching, exam planning, or flashcard authoring.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can maintain long-term local learning records and touch related project, contact, and finance files.

Mitigation: Use it only when this persistence is acceptable, keep backups of ~/Clawic/data/, and review proposed changes to shared project, contact, and subscription records.

Risk: Subscription cancellation, file migration, deletion, or finance/contact edits may have unwanted effects if performed without clear confirmation.

Mitigation: Require manual approval before any finance or contact edit, subscription cancellation, migration, or deletion.
