## Description:

Helps agents predict likely country associations for names through Nationalize using an OOMOL-connected account.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

Users and developers can request ranked country predictions with probabilities for an individual name or a batch of up to 100 names through their connected OOMOL account.

### Deployment Geography for Use:

Global
