# Cruise Product Skill Pack

A comprehensive skill pack for cruise enthusiasts, offering tools for searching, filtering, and exploring cruise products.

由 [CruiseSkillBridge](https://cruiseskillbridge.com) 发布到 [ClawHub](https://clawhub.ai)。

## 安装

```bash
openclaw skills install @OWNER/ola-cruise-skill-pack
```

> 将 `OWNER` 替换为 ClawHub 发布者 handle。
