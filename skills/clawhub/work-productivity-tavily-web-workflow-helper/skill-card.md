## Description: <br>
Helps agent users and skill authors plan, troubleshoot, harden, and adapt Tavily-style web search workflows into practical local-friendly deliverables. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
AI-agent users, skill authors, maintainers, and teams use this skill to turn Tavily-style web search workflow needs into action plans, checklists, analyses, code changes, or decision support. It emphasizes clarifying constraints, producing an actionable artifact, and checking the result against visible success criteria. <br>

### Deployment Geography for Use: <br>
Global <br>
