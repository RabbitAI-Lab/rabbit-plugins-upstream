# 机器人领域测试知识库（Robot Domain Knowledge）

> 本文件是 `robot-testcase-generator` 的领域知识底座。生成用例前通读一遍；
> 具体阶段二/三的**方法选择与质量属性表以内联在 SKILL.md 的为准**，本文件提供背景知识、标准依据与测试要点。

---

## 1. 知识体系总览

机器人测试 = **机器人系统构成认知 + 控制/总线 + 分层测试金字塔 + 性能/安全标准**。

```
机器人测试能力模型
├── ① 系统构成（机械本体、控制器、驱动器、传感器、末端执行器、控制柜）
├── ② 控制与总线（运动控制器、伺服驱动、现场总线、示教/离线编程）
├── ③ 测试分层（单元/组件/集成/系统/验收）
├── ④ 运动与末端感知（运动学/动力学、轨迹、视觉引导、力觉）
└── ⑤ 标准与安全（ISO 10218、ISO/TS 15066、GB/T 36008 等）
```

## 2. 系统构成与测试关注点

| 子系统 | 说明 | 测试关注点 |
|---|---|---|
| 机械本体/关节 | 电机、减速器、编码器、限位 | 关节精度、回差、限位保护 |
| 控制器 | 运动控制卡/嵌入式控制器 | 指令响应、插补精度 |
| 驱动器/伺服 | 电流环/速度环/位置环 | 跟随误差、过载保护 |
| 传感器 | 编码器、IMU、视觉、力/力矩 | 数据有效性、标定、漂移 |
| 末端执行器 | 夹爪、吸盘、焊枪 | 抓取成功率、重复定位 |
| 控制柜/软件 | 运动控制器、总线、示教/离线编程 | 指令响应、插补精度、程序管理 |

## 3. 运动控制测试要点

- **关节空间**：单关节正/反向运动、限位、软限位、回零（Home）精度
- **笛卡尔空间**：直线/圆弧插补精度、轨迹平滑度、速度/加速度规划
- **重复定位精度**：多次往返同一目标位姿的偏差（工业机器人 mm 级）
- **奇异点/边界**：工作空间边界、奇异位形、关节角越界
- **动态特性**：启动/停止冲击、加减速时间、过冲/振荡
- **抱闸/掉电**：掉电保持、紧急停止后位置保持与恢复

## 4. 末端感知测试要点（视觉引导/力觉）

| 功能 | 测试要点 |
|---|---|
| 视觉引导 | 识别率、误识别率、遮挡/光照/模糊鲁棒性、类别混淆、手眼标定精度 |
| 力/力矩感知 | 力控精度、碰撞力检测阈值、拖拽示教 |

## 5. 安全标准与规范体系（国标/行标/企标）

| 层级 | 示例 | 测试意义 |
|---|---|---|
| 国标 | GB 11291.1（等同 ISO 10218-1 工业机器人安全）、GB/T 36008 协作机器人、GB 5226.1 机械电气安全 | 准入底线 |
| 行标 | JB/T 机械行业标准（工业机器人通用技术条件等） | 行业统一要求 |
| 企标 | 厂商/集成商验收规范 | **通常严于国标，验收线** |
| 国际对应 | ISO 10218、ISO/TS 15066、ISO 9283 | 国标多等同采用 |

| 标准 | 内容 | 测试意义 |
|---|---|---|
| ISO 10218-1/-2 | 工业机器人安全 | 安全相关控制系统（SRCS）验证 |
| ISO/TS 15066 | 协作机器人安全 | 力/速度限制、人体接触风险 |
| GB 11291.1 | 等同 ISO 10218-1 | 国内工业机器人准入 |
| GB/T 36008 | 协作机器人（等同 ISO/TS 15066） | 力/速度限制、人机协作 |
| IEC 61508 / 62061 | 功能安全 | 安全回路 SIL 等级验证 |
| GB/T 5226.1 | 机械电气安全 | 急停、电气防护 |

**处理原则**：企标 > 国标 > 行标；冲突取更严值；安全类按 GB/ISO 底线执行。

**安全测试要点**：急停响应时间、急停后运动停止/抱闸、碰撞检测触发、限速生效、安全区域、联锁、防护罩打开停机、上电自检。

## 6. 测试类型全景图

| 测试类型 | 说明 | 常用手段 |
|---|---|---|
| 功能测试 | 按需求验证模块/整机功能 | 仿真 + 实物 |
| 运动控制测试 | 轨迹、精度、速度、加速度 | 激光跟踪仪、编码器采集 |
| 感知测试 | 视觉引导识别率、鲁棒性 | 数据集回放、场景注入 |
| 通信测试 | 总线报文、丢包、时序、断连重连 | 总线抓包、故障注入 |
| 性能测试 | 节拍/循环时间、负载、启动时间 | 打点统计 |
| 可靠性测试 | 长时间运行、疲劳、异常恢复 | 老化测试、压力测试 |
| 安全测试 | 急停、碰撞、限速、联锁 | 故障注入、实物验证 |
| 环境测试 | 高低温、湿度、振动、粉尘 | 环境箱 |
| 兼容性测试 | 控制器/驱动器/传感器型号、总线协议版本 | 组合矩阵 |

## 7. 分层测试金字塔

```
        验收测试（场景级：整机完成指定任务）
      系统测试（模块间集成：运动+感知+调度）
    集成测试（组件间：节点间通信、驱动）
  组件测试（单模块：控制算法、感知节点）
单元测试（函数/算法级）
```

- **仿真先行**：离线编程/物理仿真覆盖大部分功能与边界；实物用于精度、安全、可靠性验证。
- **数据集回放**：感知类用录制的数据集回放，保证可复现。
- **故障注入**：通信断连、传感器失效、急停、断电等必须在实物/半实物上验证。

## 9. 典型风险点（探索性用例灵感）

1. **急停响应**：急停按下后残余运动、抱闸时序、恢复流程
2. **通信断连**：控制指令丢失、重连后状态同步
3. **传感器失效**：视觉/力觉数据异常或丢失时的降级行为
4. **重复执行**：连续执行同一任务 1000 次的精度漂移
5. **负载边界**：超载、偏载、负载突变
6. **标定缺失**：缺失或损坏时的启动行为
7. **轨迹边界**：接近工作空间边界、奇异点附近
9. **多机并发**：多机器人同区域调度、避碰
10. **数据一致性**：示教器显示 vs 实际关节位置核对

## 12. 重复定位精度测量方法

- **测量步骤**：机械臂以同一目标位姿反复运动 N 次（N≥30），用激光跟踪仪/千分表记录末端实际位置
- **指标**：按 ISO 9283 计算位姿重复性（RP），取 3σ 或最大偏差与需求比对
- **用例要点**：固定负载、固定速度、固定轨迹（避免热漂移干扰）；对比空载/额定负载
- **注意**：区分「重复定位精度」与「绝对定位精度」；连续运行热漂移（关节温度上升影响精度）

## 13. 安全功能详表（ISO 10218 / ISO/TS 15066）

| 安全功能 | 测试要点 |
|---|---|
| 急停（类别 0/1/2） | 停机响应时间、抱闸时序、急停后状态恢复 |
| 碰撞检测 | 触发力阈值、检测时间、停机行为 |
| 速度/力限制 | 限速生效、人员靠近减速、力限制（协作场景按 ISO/TS 15066） |
| 安全区域/联锁 | 围栏/光栅触发停机、防护罩联锁 |
| 双通道监控 | 安全回路冗余、单通道失效可检出 |
| SRCS | 安全相关控制系统功能验证（ISO 10218-1） |

## 14. 总线/通信测试要点

- **连接管理**：上电建连、握手、地址/节点 ID 冲突
- **报文时序**：周期报文频率/抖动、事件报文触发时序
- **超时/重连**：断线检测时间、重连补偿、反复断连
- **错误报文**：校验错误、非法 ID、长度异常 → 拒收不崩溃
- **性能**：总线负载率、通信周期余量、抖动
