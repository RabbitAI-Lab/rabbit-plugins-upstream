# 机器人测试输入（真实案例演示）

## 需求：协作机械臂（6 轴）运动与安全功能

1. 支持点到点运动（PTP）与直线插补（LIN）两种运动模式
2. 重复定位精度 ≤ ±0.05mm
3. 额定负载 5kg，额定末端速度 1m/s，最大速度 2m/s
4. 碰撞检测：检测到碰撞力超过 150N 时，100ms 内停机并进入保护状态
5. 急停按钮按下后立即停机、抱闸，位置保持，支持手动解除后恢复
6. 支持拖拽示教（手动牵引机械臂记录轨迹点）
7. 关节 1 运动范围 ±170°，超过软限位时自动减速并报警
8. 连续运行 8 小时后关节温度不超过 70℃
