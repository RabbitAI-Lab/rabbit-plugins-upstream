# 种草图文笔记创作

## 使用引导（30 秒看懂）

本技能帮你把「一个产品 / 一个主题」快速写成一篇**种草社区风格的图文笔记**——包含封面与标题、正文、话题标签、评论区引导，直接可用。

- **适合谁**：想做种草 / 好物 / 探店 / 经验分享图文的内容创作者、电商运营、自媒体。
- **怎么用**：告诉我「产品 / 主题 + 目标人群 + 想突出的卖点」，我来产出完整笔记草稿。
- **产出包含**：3 个备选标题（标注角度）、首屏正文、分层话题标签、封面文案、评论区引导。
- **按次计费**：单次 ¥0.15，通过支付宝 AI 按量付费；未付款时按提示完成支付即可取结果。
- **安全红线**：不写绝对化功效、不编造体验与数据、不踩平台违禁词。

> 不确定怎么写？直接说产品名和人群即可，例如：「便携折叠咖啡杯，通勤上班族」，我会帮你生成。

## Overview

种草社区的流量分配看两件事：**封面+标题决定点击，内容决定收藏与评论**。所以一篇笔记不是「写一篇短文」，而是三件独立的产品：一个能在信息流里被点开的**封面与标题**，一段能让人读完并想存的**正文**，一组能把你推给对的人的**标签**。

本技能按这个结构产出，并且严格遵守这类社区的内容红线——夸张功效、医疗断言、绝对化用语是笔记被限流的主要原因。

## When to use

- 用户要写种草笔记、种草文案、探店 / 好物 / 经验分享图文。
- 需要把一个产品 / 方法批量产出多篇不同角度的笔记。
- 需要改写一个已有笔记让它更符合社区调性。

## 平台规格

| 项 | 规格 |
|---|---|
| 标题 | ≤ 20 字（含 emoji 占位）；前 10 字必须出现核心信息 |
| 正文 | 建议 300～800 字；每段 ≤ 3 行，段间空行 |
| 首屏 | 前 3 行必须给出「这篇能给你什么」 |
| emoji | 每 2～3 段一个，段首或句末，不堆砌 |
| 话题标签 | 5～10 个，混合大词（10 万+ 笔记）与精准长尾词 |
| 封面文案 | ≤ 12 字，主标题 + 可选的副标（≤ 8 字） |
| 图片 | 首图决定点击；建议 6～9 张，含一张「信息图」提升收藏 |

## 标题公式（六类角度）

| 角度 | 模板 | 示例 |
|---|---|---|
| 痛点直击 | <人群>的<痛点>终于有救了 | 干皮秋冬卡粉终于有救了 |
| 数字清单 | <数字>个<领域>小技巧，第<N>个绝了 | 7 个通勤穿搭技巧，第 5 个绝了 |
| 反差 | 花了<X>才明白：<结论> | 花了 3000 才明白：护肤别乱叠 |
| 身份代入 | <身份>必看：<收益> | 打工人必看：10 分钟早餐方案 |
| 避坑 | 别再<错误做法>了！正确做法是… | 别再暴力去黑头了！ |
| 结果前置 | <时间/成本>做到<结果> | 30 天把体脂从 28% 降到 24% |

## 输出模板

```markdown
## 封面
- 主标：<≤12 字>
- 副标：<≤8 字，可选>
- 画面建议：<构图/色调/主体>

## 标题（给 3 个备选，注明角度）
1. <标题> —（<角度>）
2. …
3. …

## 正文
<首段 3 行内给出核心价值，第一人称>

<分点正文，每点一个小标题 + 2-3 行说明>

<结尾：一句引发评论的话，不要写「点赞关注」>

## 话题标签
#<大词1> #<大词2> #<中词> #<精准长尾1> #<精准长尾2> …

## 评论区引导
- 置顶评论：<自己补充的一句信息，引导互动>
```

## 关键规则

- **禁用绝对化与功效断言**：不写「最有效」「根治」「100%」「永久」「医用级功效」；涉及身体、皮肤、健康的只写个人体验，不写疗效。
- **不编造体验与数据**：没有使用过的产品不写「亲测有效」；价格、规格、成分不确定就留占位 `<待补>`。
- **第一人称、口语化**：不用书面语长句，不用「本文」「笔者」。
- **首屏必须给价值**：前三行不铺垫、不自我介绍。
- **结尾要有互动钩子**：用提问或留悬念（「你们更常用哪种？评论区告诉我」），不要生硬求赞。
- **标签要分层**：全是大词推不准，全是长尾词没流量，必须混合。
- **敏感品类谨慎**：医美、药品、金融、减肥类避免具体承诺与前后对比夸大。
