# 工作流程

> 完整小说创作流程和单章写作循环

---

## 完整小说创作流程

```
灵感 → 梗概 → 世界观 → 角色 → 大纲+文风 → 逐章写作 → 统稿 → 成品
```

### 阶段一：创意孵化（串行）

```
赵构思 → 张世界 → 王角色
```

1. **赵构思**：灵感 → 故事梗概（500字）+ 目标平台 + 核心冲突
2. **张世界**：梗概 → 世界观设定（时代、地理、社会、特殊体系）
3. **王角色**：梗概 + 世界观 → 角色卡（主角 + 配角 + 关系网）

### 阶段二：结构+风格规划（并行 → 审核）

```
李大纲 ─┐
         ├→ 陈总管审核
刘风格 ─┘
```

4. **李大纲**：梗概 + 世界观 + 角色 → 全书大纲（章节规划 + 伏笔地图）
5. **刘风格**：目标平台 + 世界观 → 文风规范手册
6. **陈总管**：审核大纲 + 文风规范 → 通过/打回

### 阶段三：正文创作（逐章循环）

```
吴正文 ↔ 周编辑（每章循环）
```

7. **吴正文**：大纲 + 文风 + 角色 + 世界观 + 前几章 → 章节正文
8. **周编辑**：章节正文 + 审查标准 → 审稿报告（通过/打回）
9. 循环：通过→下一章，打回→修改→再审

### 阶段四：全书统稿（串行）

```
刘风格润色 → 周编辑终审 → 陈总管交付
```

10. **刘风格**：全书风格统一润色
11. **周编辑**：全书终审（一致性、伏笔回收、弧光完成）
12. **陈总管**：整理交付完整小说

## 单章写作循环

```
准备素材 → 吴正文写初稿 → 周编辑审稿
                              │
                    ┌─────────┴─────────┐
                    ▼                   ▼
                  通过                 打回
                    │                   │
                    ▼                   ▼
              进入下一章          吴正文修改 → 周编辑再审
```

### 写作前准备
- 当前章节大纲
- 文风规范
- 相关角色档案
- 相关世界观设定
- 前1-3章正文（保持连贯）

### 审查维度（7项）
1. 情节逻辑
2. 人物一致性
3. 节奏把控
4. 伏笔操作
5. 平台适配度
6. 章末钩子
7. 文字质量

### 循环规则
- 通过 → 存入chapters/ → 进入下一章
- 打回 → 详细流程如下：

**打回后的完整修改流程：**

1. **吴正文读取审稿报告**：仔细阅读修改清单中的每一条问题和建议，理解周编辑的修改意图
2. **吴正文逐条修改**：根据修改清单逐条修改章节正文，高优先级问题必须全部解决，中低优先级问题尽量处理
3. **吴正文自检**：修改完成后检查是否遗漏问题、是否引入新问题
4. **吴正文提交修改稿**：将修改后的章节重新提交给周编辑
5. **周编辑复审**：
   - 逐条检查上次修改清单中的问题是否已解决
   - 检查修改是否引入了新问题
   - 通过 → 存入chapters/ → 进入下一章
   - 仍有问题 → 再次打回（回到步骤1）
6. **循环上限**：最多3轮。第3轮仍不通过，陈总管介入评估，决定是继续修改还是标记问题章节后继续下一章

## 分步模式暂停点

### 暂停点1：创意孵化完成
展示：梗概 + 世界观 + 角色
用户确认后进入阶段二

### 暂停点2：规划完成
展示：大纲 + 文风规范
用户确认后进入正文写作

### 暂停点3：每5章一次
展示：已完成章节 + 进度
用户确认后继续写作
