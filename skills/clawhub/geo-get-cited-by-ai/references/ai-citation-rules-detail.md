## 一、AI到底怎么选内容？—— 6大评分规则

### 规则1：信源权威度（权重最高）

AI不是"谁的内容都引用"，它内部有一套信源等级体系：

| 等级 | 信源类型 | 例子 | 被引用概率 | 策略 |
|:----:|---------|------|:---------:|:----:|
| **S级** | 权威机构/政府/学术 | 百度百科、知网、政府网站 | 几乎必引 | 争取被这些信源链接或引用 |
| **A级** | 知名平台深度内容 | 知乎高赞、公众号大V、行业垂直媒体 | 大概率引用 | 主阵地，深耕2-3个 |
| **B级** | 一般自媒体 | 普通回答、百家号、个人博客 | 看质量 | 内容质量决定一切 |
| **C级** | 低质/营销号 | AI生成同质化文章 | 被忽略 | 不要做 |

**提升信源等级的方法**：
1. 在知乎做高赞回答——AI认"被社区验证过的内容"
2. 被正规媒体报道——AI认"被第三方验证过的信息"
3. 与行业机构挂钩（协会/认证/合作）——AI认机构背书
4. 坚持长期稳定更新——AI认"持续存在的信源"

### 规则2：时效性权重（硬门槛）

| 内容年龄 | 被引用概率 | 说明 |
|:---------|:----------:|:----:|
| 近180天 | **5倍**高于旧内容 | 时效性是AI最看重的指标之一 |
| 6-12个月 | 正常 | 仍有机会，尤其深度内容 |
| 1年以上 | 除非权威信源（百科等），否则几乎不被引用 | 旧内容需要更新 |
| 3年以上 | 被AI忽略 | 除非经典文献 |

**实操策略**：
- 每季度更新行业数据（改日期+加新案例）
- 每月更新FAQ（添加新问题）
- 持续输出新内容（频率>3篇/周更优）

### 规则3：内容结构"AI友好度"

AI读内容的方式和人类完全不同。结构清晰的内容引用率高3倍。

**AI最喜欢的结构（按优先级）**：
```
1. FAQ/问答格式 → AI可以直接提取答案
2. 结构化列表 → 要点+数据，信息密度高
3. 对比表格 → 数据可视化，AI好提取
4. 步骤指南 → 逻辑清晰，可被拆解
5. 案例分析 → 有背景-问题-方案-结果四段

AI最讨厌的：
- 大段文字找不到重点
- 模糊表述（"很多用户""行业领先""效果很好"）
- 营销话术（AI认为不可信）
```

**黄金模板（已验证引用率最高）**：
```
标题：含核心关键词
开头：一句话给结论（50字内）
正文：
  H2: 分3-5个模块
    每个模块：观点 → 数据支撑 → 案例/场景
  列表/表格替代大段文字
  专业术语跟通俗解释
结尾：FAQ（3-5个常见问题）
```

### 规则4：跨平台交叉验证

AI不是只看单一平台。它会在多个平台交叉验证：

> 举例：你在知乎发了篇"小企业劳动仲裁指南"
> AI会同时去查：这件事在公众号有没有人提？在小红书有没有讨论？在百度百科有没有收录？
> **越多平台同时出现你的品牌，AI越觉得你"可信"**

**策略**：
- 同一套核心内容，改写后发到3个以上平台
- 推荐组合：知乎 + 公众号 + 百家号（覆盖DeepSeek/文心/Kimi）
- 不同平台用不同风格（知乎=专业深度，公众号=故事化，小红书=口语化）

### 规则5：数据具体度（AI的"信任触发器"）

AI对模糊表述不信任。有具体数据的会优先推荐。

**对比测试**：

| 内容 | AI评价 |
|------|--------|
| "我们的服务效率很高，客户都很满意" | ❌ 跳过——无法验证 |
| "2025年服务300+客户，平均响应时间<5分钟，客户满意度92%" | ✅ 优先引用——有数据可验证 |

**平台差异**：
- DeepSeek：对数据最敏感，具体数字是强引用信号
- 文心一言：更看重要权威来源，其次是数据
- 豆包：短内容+数据组合最优
- Kimi：深度内容+数据=最高引用率

### 规则6：用户互动信号

AI会看平台的互动数据来判断内容质量：

| 平台 | 关键互动信号 | 说明 |
|------|:-----------:|:----:|
| 知乎 | 点赞数/收藏数 | 高赞内容AI更愿意引用 |
| 公众号 | 阅读量/在看数 | 高阅读量=质量信号 |
| 小红书 | 收藏率 | 收藏率高代表"有用" |
| 百家号 | 阅读量/互动 | 百度系AI优先考虑 |

**正循环机制**：
```
内容好 → 互动高 → AI更愿意引用 → 用户看到后去互动 → 互动更高 → AI更信任
```

## 二、各AI平台公开信源特点速查

| AI平台 | 开发者 | 主要引用源 | 内容偏好 | 对时效敏感度 | 对数据敏感度 |
|--------|-------|-----------|---------|:-----------:|:-----------:|
| **DeepSeek** | 幻方量化 | 知乎/公众号/CSDN | 深度长文+结构化 | 高 | 高 |
| **文心一言** | 百度 | 百度百科/百家号 | 百度优先+结构化 | 中 | 中 |
| **豆包** | 字节跳动 | 抖音/头条号 | 短平快+数据 | 中 | 高 |
| **Kimi** | 月之暗面 | 知乎/公众号/学术 | 长文+专业深度 | 中 | 中 |
| **通义千问** | 阿里巴巴 | 阿里系+知乎 | 电商/消费场景 | 低 | 中 |

**核心发现**：
1. **知乎是所有AI平台的"共同最爱"** → 知乎深耕是GEO最低成本最高回报策略
2. **公众号覆盖DeepSeek+Kimi**，但不被文心/豆包引用
3. **百家号是打开文心一言的唯一钥匙**（百度系封闭生态）
4. **字节系内容（抖音/头条）主要影响豆包**，对其他AI影响小

## 三、从竞争中胜出的6条策略总结

| 策略 | 具体怎么做 | 预期效果 |
|:----|:----------|:--------:|
| **1. 提升信源等级** | 不只发普通平台，争取被行业媒体/权威机构引用 | 引用率翻5倍 |
| **2. 走存量+增量** | 每季度更新旧数据（改日期+加新案例），持续发新内容 | 保持时效性优势 |
| **3. AI友好结构** | 标题=核心词，正文=结构化+FAQ+数据表格 | 引用率+60% |
| **4. 跨平台布局** | 同一内容发3个以上平台（知乎+公众号+百家号） | AI交叉验证后更信任 |
| **5. 每条塞数据** | 每篇至少2个具体数字，避免模糊表述 | 引用率翻3倍 |
| **6. 养互动=养权重** | 回复评论、引导点赞收藏、在知乎做高赞回答 | 互动信号正向循环 |
