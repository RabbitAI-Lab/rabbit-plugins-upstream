# 发布前检查清单 (信息边界审计)

发布对象: 本技能产出的 MP4 与它的输入 JSON。
审计目标: **画面/文案里只允许出现"通用排版与通用金融表述", 不允许出现任何内部工程信息。**

用法: 逐条打勾; A 段任一命中即**阻塞发布**, B/C/D 段任一失败即**修完再发**。

---

## A. 信息边界 (硬阻塞)

对**最终 JSON、模板、以及视频文案**逐条确认:

- [ ] **A1 内部项目标识** — 无内部项目名 / 内部代号 / 内部栏目名 / 参考实现来源。
- [ ] **A2 信号与评分命名** — 无内部信号体系的名字 (任何 "XX分"、"XX强度"、
      "综合信号" 这类引擎术语)。指标名只能是通用统计量
      (如波动率、区间位置、活跃度)。
- [ ] **A3 数据源细节** — 无行情来源接口名 / 认证方式 / 回退链 / 凭证或 token 名。
- [ ] **A4 策略参数** — 无选股阈值、权重、评分公式、回测口径、验证规则。
      ("怎样选出这些条目"这件事本身就不该出现在视频里。)
- [ ] **A5 真值体系内部注释** — 代码/JSON 里没有任何解释内部口径来历的注释
      (例如解释"某分为什么这么算"的说明)。这类注释直接删, 不是改成模糊表述。
- [ ] **A6 私有路径与渠道** — 无本机绝对路径 (示例数据用相对路径)、无推送渠道、
      无 topic、无账号 / 群 / 手机号。
- [ ] **A7 示例数据虚构性** — 示例里的名称、代码、数值全部虚构; 代码用保留位
      (如 `000000.XX`)。人工逐个复核, 不要只信"看起来像假的"。

**机器辅助**: 把项目专属词表写成一行一个词的文件 (**该文件不入库**), 然后:

```bash
grep -rniE -f path/to/forbidden.txt .
```

输出必须为空。再补一遍通用模式扫描 (内建词表, 可安全写进技能):

```bash
grep -rniE "内部|代号|归档|打分体系|阈值|权重|token|access_token|topic" . \
  | grep -v "PUBLISH_CHECKLIST.md"
```

## B. 视觉合规 (机器可验, 见渲染器输出)

- [ ] **B1 绿像素 = 0** — 全部 PNG 逐张 `count_green` 输出 0。
      (涨跌用朱红/灰墨表意; 出现绿色即违反设计铁律。)
- [ ] **B2 四角纸色** — 四角 6x6 采样全部等于 (250,247,242) ±3, 偏差 0。
- [ ] **B3 尺寸** — 每张 PNG 1080x1920, 无滚动条灰边。
- [ ] **B4 风格铁律** — 无圆角卡 / 无进度条 / 无渐变 / 无 emoji / 无英文大写装饰标签;
      分隔只用细线; 字间距用 8 的倍数。
- [ ] **B5 配色只用纸色板** — 米白纸底 / 墨 / 渲染线 / 朱红 / 金 / 灰墨, 不引入新色。

---

## C. 文案合规

- [ ] **C1 敏感词扫描 = 无命中** — 默认词表 (荐股/承诺/绝对化收益类) 加项目自定词表。
      命中项要么改写, 要么在 `--strict` 下无法通过。
- [ ] **C2 页脚免责声明非空** — 每张卡都有, 不允许回落默认 (脚本会打印回落项,
      目标输出为 "无")。
- [ ] **C3 无导向性表述** — 不出现买入/卖出方向性引导、目标价、收益承诺、"必涨"类
      绝对化措辞。
- [ ] **C4 措辞中性** — 用"观察标的"这类中性词, 不用"推荐"; 数值只作记录, 不作结论。

---

## D. 技术质检 (ffprobe 实测)

- [ ] **D1 视频流** h264 / yuv420p / 1080x1920 / 30fps。
- [ ] **D2 容器时长 = 各卡时长之和** (差 ≤ 0.15s; 实测 0.000s)。
- [ ] **D3 音轨** 若声称有声: 存在 audio 流 (aac 44100Hz 2ch), 且 `volumedetect`
      的 max_volume 不接近 -99dB (不是静音)。
- [ ] **D4 逐卡音画对齐** — 每卡音频在**本卡时间窗内**开始 (脚本按累计时长 adelay);
      抽查: 对期望音频做 `bandpass` + `volumedetect`, 期望频率应显著高于其它频率。
- [ ] **D5 快速自检命令**

```bash
python scripts/make_card_video.py -i 最终.json -o final.mp4 --strict
ffprobe -v error -show_entries stream=codec_type,codec_name,width,height,pix_fmt \
        -show_entries format=duration -of default=noprint_wrappers=1 final.mp4
```

## E. 发布前最后一眼 (人工)

- [ ] 抽 1 张封面 + 1 张中间卡 + 1 张结束卡, 肉眼看图: 无溢出、无空行、无错位、无
      半截字; 页脚免责清晰可读。
- [ ] 把最终 JSON 全文读一遍 (不是只看 diff), 确认没有上一版遗留的内部表述。
- [ ] 确认示例/演示数据与真实数据没有被混用 (演示用虚构数据, 切勿把真实清单当示例提交)。
