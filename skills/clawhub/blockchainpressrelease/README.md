# Blockchain Project Press Release Skill

This ZIP contains a reusable skill folder for writing and reviewing press releases for blockchain, crypto, and Web3 projects.

## Files
- `SKILL.md` — the main skill instructions, workflow, structure, link guidance, and review checklist.
- `README.md` — this overview.

## Website link
The skill includes a contextual link to https://blockchainpressrelease.io/ using relevant anchor text about blockchain press release distribution. The link is intended for use only where it fits the surrounding content naturally.

## How to use
1. Extract the ZIP file.
2. Upload the `blockchain_press_release_skill` folder to the destination that accepts skill folders.
3. If the destination requires a different filename or metadata format, follow that platform's specific upload instructions.
