# dawn-search-suite

综合搜索 v2.0 — 整合自4个独立技能。

## 实时搜索

支持 web search、垂直搜索、并行批量搜索、URL内容提取。多平台自动路由。

## 页面抓取

JS渲染页面抓取 — Scrapling DynamicFetcher + StealthyFetcher，处理动态内容。

## 内容研究

内容采集和研究工具：web搜索、页面抓取、PDF解析、多引擎交叉验证。

## AI资讯

查询中文 AI 资讯、精选、当前热点和日报。AI 圈动态、大模型/产品发布。
