## 能为你做什么（政府补助五大场景）
---

### 一、补助性质判定（不征税 vs 应税）
- 🔎 **性质区分**：符合条件的不征税收入 vs 应税收入，避免"不征税≠免"
- 📋 **三条件**：有专项用途拨付文件、专门管理办法、单独核算（财税〔2011〕70号）
- ⚠️ **高频风险**：不征税条件不满足仍按不征税，补税+滞纳金

**典型问法：**
```
"政府补助要交税吗？"
"不征税收入三个条件是什么？"
```

### 二、专项用途文件归集与专账核算
- 🗂️ **文件管理**：取得专项用途资金拨付文件与资金管理办法
- 💼 **单独建账**：资金及支出单独核算，留存可证明合规的证据链
- ⚠️ **风险点**：专账核算缺失导致无法证明合规、被补税

**典型问法：**
```
"财政性资金怎么核算？"
"专项用途文件要准备哪些？"
```

### 三、对应支出管理与进项税
- 🚫 **不得扣除**：不征税收入对应支出不得在税前扣除
- 🔌 **进项税**：专用于不征税收入项目的进项税不得抵扣
- ⚠️ **风险点**：对应支出违规扣除、专账进项税误抵扣

**典型问法：**
```
"政府补助对应支出能扣除吗？"
"专用于不征税项目的进项税能抵扣吗？"
```

### 四、5年（60个月）跟踪与转应税
- ⏳ **转应税跟踪**：60个月内未支出部分须计入应税收入
- 📊 **台账管理**：建立补助性质判定表与5年跟踪表
- ⚠️ **风险点**：超5年未使用未转应税被补税

**典型问法：**
```
"5年没花完的补助怎么处理？"
"做一下不征税收入专账"
```

### 五、与政府购买服务区分
- 🆚 **定性边界**：政府补助（不征税/应税）与政府购买服务（应税）严格区分
- ⚠️ **风险点**：与政府购买服务混淆导致定性错误、补税

**典型问法：**
```
"政府购买服务和政府补助有什么区别？"
"补助误作应税多缴税了怎么办？"
```

## 重要提示与边界声明

**重要提示**
1. **不征税须三条件**：须同时满足专项用途拨付文件、专门管理办法、单独核算，对应支出不得扣除。
2. **5年须转应税**：60个月内未使用的部分须计入应税收入，不得长期挂账。
3. **进项税须区分**：专用于不征税收入项目的进项税不得抵扣。
4. **以官方为准**：政府补助税务处理以财税〔2008〕151号、财税〔2011〕70号及主管税务机关口径为准。

**边界（本技能不做的）**
- **不代办**：补助申报、专项资金系统填报等需登录操作的事项
- **不代理**：财政性资金合规性鉴证等需执业资质的事务
- **不担保**：不征税收入认定、补助定性等最终以税务机关为准

**服务说明**
- 每次提问都能获得完整闭环：智能问答 → 结构化结果 → 政策依据溯源 → 真实案例关联 → 实操辅导 → 反馈评价 → 合规报告
