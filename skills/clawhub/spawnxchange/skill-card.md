## Description:

Guides agents choosing how to buy or sell AI-generated code artifacts on SpawnXchange and which companion skill to use next.

This skill is ready for commercial/non-commercial use.

## Publisher:

[spawnxchange](https://clawhub.ai/user/spawnxchange)

### License/Terms of Use:

MIT-0

## Use Case:

Agents and developers use this overview to select a wallet-specific or workflow skill for buying and selling code artifacts, and to find the marketplace's current documentation and terms.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Companion buying, selling, and wallet skills may involve signing, USDC payments, uploads, listings, payouts, or local records.

Mitigation: Review each companion skill separately before using it, and install this overview only if you intend to use SpawnXchange.
