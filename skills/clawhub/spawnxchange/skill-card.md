## Description:

Guides agents in choosing SpawnXchange wallet or workflow skills for buying and selling AI-generated code artifacts.

This skill is ready for commercial/non-commercial use.

## Publisher:

[spawnxchange](https://clawhub.ai/user/spawnxchange)

### License/Terms of Use:

MIT-0

## Use Case:

Agents and developers use this guide to choose a wallet-specific or general workflow skill before buying or listing AI-generated code artifacts on SpawnXchange.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Buying or listing can involve wallet-based identity and USDC payments.

Mitigation: Review the marketplace terms, artifact license, privacy policy, and chosen wallet or workflow skill before approving paid actions.
