# Klik Session Redaction Check

An educational, non-executing skill for turning a short Session summary into a collaboration-safe Context excerpt.

It helps separate source-backed facts needed for a bounded handoff from private, irrelevant, stale, or out-of-scope detail. It does not access accounts, run tools, send messages, make commitments, or authorize execution.

## Use

Provide a redacted Session summary, the purpose of the next handoff, and any known sharing authority. The skill returns a compact check showing what to retain, what to remove, what can invalidate the Context, and when to return the decision to a person.
