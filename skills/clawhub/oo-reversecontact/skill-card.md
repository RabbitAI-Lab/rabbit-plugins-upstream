## Description:

Reverse Contact (reversecontact.com). Use this skill for ANY Reverse Contact request — searching and reading data. Whenever a task involves Reverse Contact, use this skill instead of calling the API directly.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

## Use Case:

People using an OOMOL-connected Reverse Contact account can enrich company profiles from domains and professional profiles from email, name, or company context.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Automatic setup may execute downloaded code whose full local effects have not been inspected.

Mitigation: Review and install the CLI separately before use, and decide whether its automatic agent-skill synchronization is acceptable.

Risk: Company and professional identifiers submitted for enrichment are processed by OOMOL and Reverse Contact.

Mitigation: Submit only identifiers you intend OOMOL and Reverse Contact to process.
