# 提示词编写指南

## 概述

提示词是发送给 GLM-4.1V-thinking-flash 模型的文本指令，直接决定了模型输出的质量和格式。本指南提供了针对不同任务类型的提示词模板和最佳实践。

## 核心原则

### 1. 明确任务目标
- 清楚描述**要做什么**、**输出什么格式**、**关注什么细节**
- 避免模糊指令如"看看这张图"，改为"详细描述图片中的主要物体、场景、颜色和构图"

### 2. 结构化输出要求
- 指定输出格式：JSON、Markdown 表格、要点列表、自然语言段落等
- 定义字段名和数据类型（如需要结构化数据）

### 3. 分步骤引导复杂任务
- 将复杂分析拆解为多个步骤
- 例如："首先识别图表类型，然后提取坐标轴信息，接着读取数据点，最后总结趋势"

### 4. 提供示例（Few-shot）
- 在提示词中包含 1-2 个输入输出示例
- 示例应覆盖典型场景和边缘情况

## 通用分析提示词模板

### 基础版（适用于大多数场景）
```
请详细分析这张图片的内容，包括但不限于：
1. 画面主要包含什么物体、场景、人物
2. 文字内容（如有，请完整提取并保持原有格式）
3. 图表/数据信息（如有，请结构化描述：图表类型、坐标轴、数据点、趋势、图例）
4. 画面细节和值得注意的元素（颜色、构图、光影、特殊标记等）
5. 整体氛围/主题/用途判断

请用清晰的结构化方式输出，重要信息优先。
```

### 简洁版（快速概览）
```
请简要描述这张图片的核心内容：主要物体、场景、关键信息。不超过 200 字。
```

## 专用任务提示词

### OCR / 文字提取
```
请完整提取图片中的所有文字内容，要求：
1. 保持原有的段落结构、换行和排版
2. 表格内容请用 Markdown 表格格式输出
3. 如有手写文字，请标注 [手写]
4. 模糊不清的文字请标注 [模糊]
5. 仅输出提取的文字内容，不需要额外说明
```

### 发票/票据/表单信息提取
```
请从这张发票/票据/表单图片中提取关键字段信息，按以下 JSON 格式输出：

{
  "invoice_number": "发票号码",
  "date": "开票日期 (YYYY-MM-DD)",
  "seller": "销售方名称",
  "buyer": "购买方名称",
  "total_amount": "价税合计 (数字)",
  "tax_amount": "税额 (数字)",
  "items": [
    {"name": "商品/服务名", "quantity": "数量", "unit_price": "单价", "amount": "金额"}
  ],
  "remarks": "备注信息"
}

字段不存在或无法识别时设为 null。金额字段只输出数字，不含货币符号。
```

### 图表/数据可视化分析
```
请分析这张图表，提取以下信息并按 JSON 格式输出：

{
  "chart_type": "柱状图/折线图/饼图/散点图/雷达图/其他",
  "title": "图表标题",
  "x_axis": {"label": "X轴标签", "unit": "单位", "categories": ["分类1", "分类2"]},
  "y_axis": {"label": "Y轴标签", "unit": "单位", "range": [最小值, 最大值]},
  "series": [
    {"name": "系列名", "data": [数值1, 数值2, ...], "color": "颜色描述"}
  ],
  "legend": ["图例项1", "图例项2"],
  "key_insights": ["关键洞察1", "关键洞察2", "趋势描述", "异常值"],
  "data_table": [
    {"category": "分类", "series1": 值1, "series2": 值2}
  ]
}

注意：
- 数值请尽量精确读取，无法精确读取时标注"约"
- 如果是百分比图表，请在 unit 中标注 "%"
- 多系列图表请在 data_table 中列出所有系列
```

### 代码/公式识别
```
请识别图片中的代码或数学公式，要求：
1. 代码：还原为可编辑的文本格式，保持缩进和语法高亮结构
2. 公式：使用 LaTeX 格式输出 (包裹在 $$ 中)
3. 混合内容：代码和公式分块输出，标注类型
4. 如有行号、注释、字符串字面量请完整保留
```

### 文档/页面理解
```
请理解这张文档页面的结构和内容，输出：

1. 文档类型：(发票/合同/简历/论文/报告/幻灯片/网页截图/其他)
2. 页面结构：(页眉/页脚/正文/侧边栏/表格/图片区域等)
3. 关键字段提取：(根据文档类型提取核心字段)
4. 完整文本内容：(按阅读顺序提取所有文字)
5. 视觉元素：(表格、图表、签名、印章、水印、Logo 等)
```

### 物体/场景识别与描述
```
请识别图片中的所有主要物体和场景，输出：

{
  "scene": "场景分类 (室内/室外/办公/自然/都市/工业/医疗/其他)",
  "objects": [
    {"name": "物体名称", "bbox": "位置描述(如:左上/中央/右下)", "attributes": ["颜色", "形状", "材质", "状态"], "confidence": "高/中/低"}
  ],
  "people": [
    {"count": 数量, "activities": ["活动1", "活动2"], "attributes": ["服装", "姿态", "表情"]}
  ],
  "colors": ["主色调1", "主色调2", "强调色"],
  "composition": "构图描述 (特写/全景/对称/三分法/引导线等)",
  "mood": "氛围描述 (专业/温馨/紧张/轻松/正式/艺术等)"
}
```

### 对比/差异分析
```
请对比图片中的两个/多个区域/时刻/对象，重点分析：
1. 视觉差异：颜色、形状、大小、位置、数量变化
2. 内容差异：文字修改、数据更新、元素增减
3. 语义差异：状态变化、流程推进、异常出现
4. 影响评估：这些变化意味着什么

请结构化输出差异清单，每项包含：位置、变化类型、具体差异、可能含义。
```

## 提示词组合策略

### 链式思考
```
请逐步分析：
步骤1：首先识别图片类型和主要内容
步骤2：然后针对用户问题进行详细分析
步骤3：最后总结核心结论并按要求格式输出
```

### 角色设定
```
你是一位资深的[领域]专家，擅长[具体技能]。请用专业的视角分析这张图片，重点关注[专业维度]。
```

### 约束条件
```
限制条件：
- 输出长度不超过 500 字
- 必须使用中文回答
- 禁止输出除 JSON 以外的任何文本
- 置信度低于 80% 的内容标注 [不确定]
```

## 常见问题与对策

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 输出格式不符合要求 | 提示词未明确指定格式 | 增加格式示例、JSON Schema 或严格约束 |
| 遗漏关键信息 | 提示词不够具体 | 细化任务步骤、列出必须提取的字段 |
| 产生幻觉/错误信息 | 图片模糊或提示词过于开放 | 添加"不确定时标注"约束、降低 temperature(不可改) |
| 文字识别不准 | 图片分辨率低/字体特殊 | 提示模型标注模糊区域、分多次请求局部放大 |
| 图表数据读取偏差 | 坐标轴刻度密集/无网格线 | 要求模型输出"约"值、提供坐标轴范围辅助估算 |

## 调试技巧

1. **分步测试**：先用简单提示词测试基础识别能力，再逐步加入复杂要求
2. **对比实验**：同一图片测试多个提示词版本，对比输出质量
3. **错误分析**：收集失败案例，分析共性问题，针对性优化提示词
4. **版本管理**：为提示词建立版本记录，标注适用场景和效果评分
