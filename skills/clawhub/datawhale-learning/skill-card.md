## Known Risks and Mitigations:

Risk: Linked tutorials or copied commands may be outdated or unsafe to run unchanged.

Mitigation: Verify current product documentation and review commands or code from linked tutorials before execution.

Risk: Sensitive credentials could be exposed if a learner pastes API keys into an agent workflow.

Mitigation: Do not request, expose, or provide API keys unless a separate trusted workflow explicitly requires them.

Risk: Network access may be unavailable, limiting direct verification of linked lesson details.

Mitigation: Return matching source links and a provisional plan instead of inventing lesson details.
