## Description:

Explore a design or strategy decision through distinct straightforward, hybrid and creative approaches, with concrete tradeoffs and a reasoned recommendation.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External users and developers use this skill to compare viable design or strategy options before committing to an implementation, including tradeoffs, failure modes, and evidence that could change the recommendation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: An unpinned npx installation command can fetch changing package contents.

Mitigation: Prefer a pinned or manually inspected installation path before installing.

Risk: The skill frames options and recommendations, but it does not enforce tool permissions or guarantee model compliance.

Mitigation: Keep user approval and host tool permissions as the controlling authority, and test the skill in the target environment before consequential use.
