## Description:

Guides agents in producing Next.js full-stack application plans, project files, code examples, configuration guidance, and development commands for App Router, data fetching, authentication middleware, performance optimization, and deployment.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineering teams use this skill to ask an agent for Next.js full-stack implementation guidance, generated project files, example code, configuration steps, and troubleshooting support for production-oriented web applications.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can guide an agent to generate or modify Next.js project files and run development commands.

Mitigation: Review generated code before using it and confirm commands before running them in sensitive repositories.

Risk: Generated applications may require database credentials or third-party API keys.

Mitigation: Keep secrets in environment variables, avoid hardcoding keys, and review configuration files before deployment.
