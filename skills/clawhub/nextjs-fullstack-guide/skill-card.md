## Known Risks and Mitigations:

Risk: The skill may generate project files or suggest development commands that affect the current workspace.

Mitigation: Review proposed file changes and approve only normal setup, build, test, or deployment commands for the intended project.

Risk: Generated authentication, middleware, or environment-variable code can create production security issues if used without review.

Mitigation: Review auth, middleware, and environment-variable handling before production use, and keep secrets in environment variables rather than generated source files.
