# 系统模板 · 亚马逊套图参考

作为完整套图的起始结构, 参考 CreatorOS 中“系统模板 · 亚马逊套图”的版位分工。内容整理自 2026-10-19 只读核验的线上模板版本 4, 模板标识为 `amazon-image-set-v1`。

模板入口: [CreatorOS 模板管理](https://creatoros.nova.jinzita.vip/three-step-templates)。本文件已包含必要的结构与用法, 没有登录会话时也可以据此规划, 无需先访问系统。

## 适用范围

适合希望从主图、副图与高级 A+ 双端完整结构开始的商品套图任务。该模板提供内容角色与布局方向, 套用时重新确定商品依据、设计语言和逐图说明。

本模板是可选参考, 不是 Amazon 统一图数或所有商品的必备清单。可以替换角色、合并、减少、增加候选或先交付部分素材; 普通 A+、仅 PC、只需副图等任务按实际目标调整。产品近似还原、推定内容和平台适配均沿用 [降级策略](degradation-and-delivery.md)。

## 套图组成与尺寸

| 分组 | 数量 | 交付尺寸 | 应用生成预设 |
|---|---:|---|---|
| 主图 | 1 | `2000x2000` | `2000x2000` |
| 副图 | 7 | `2000x2000` | `2000x2000` |
| A+ PC | 7 | `1464x600` | `1472x608` |
| A+ 手机 | 7 | `600x450` | `608x448` |

该次核验共 22 个版位, 高级 A+ 与移动端配套均启用, 模板没有自带参考图。A1 与 M1 等分别配对, 7 组双端素材不按 14 个 A+ 模块计算。最终模块组合仍按目标平台与所选模块核对。

上表生成尺寸属于应用预设, 不要求其他工具具备相同尺寸。最低要求、目标交付、实际生成与后处理分别记录, 采用邻近尺寸或暂交预览时按实际结果说明。手机图优先独立重排, 临时裁切或仅完成一端时记录相应降级。

## 主图与副图分工

| 版位 | 名称 | 主要任务 | 构图与信息不足时的调整 |
|---|---|---|---|
| MAIN | 商品识别 | 让买家看清当前商品 | 完整商品为视觉中心, 面向 MAIN 用途时核对背景和附加内容; 身份不足时可先近似还原或交主视觉预览 |
| L1 | 真实使用场景 | 说明商品在哪里、怎样使用 | 产品为主角, 环境辅助理解; 用途未定时采用生活化陈列或有说明的场景设定 |
| L2 | 核心利益点 | 一眼看懂一个重要购买理由 | 选择一个卖点或可见特点, 配简短标题; 证据较少时突出设计或细节, 推定利益点保留假设说明 |
| L3 | 功能演示 | 展开一个功能或结构关系 | 用清晰动作、状态或景别展示; 可以改为可见部件特写或结构示意, 不强求复杂功能演示 |
| L4 | 材质与结构细节 | 帮助观察表面和连接细节 | 用纹理、表面与接合的近景呈现质感; 材质未知时采用外观描述, 必要推断单独说明 |
| L5 | 尺寸与兼容 | 帮助判断大小和适配 | 有依据时标尺寸或适配信息; 可先交完整外观、近似比例或有说明的尺寸示意 |
| L6 | 操作与安装 | 降低上手疑虑 | 有资料时提炼关键步骤; 信息有限时交单一操作状态、部件展示或候选操作示意 |
| L7 | 包装内容 | 说明画面中的商品与配件关系 | 已明确时呈现实际清单; 未明确时采用单体或陈列示意, 不把画面件数自动视为实际销售数量 |

副图每张优先一个主要结论, 保持缩略图可读。不同角色可能共用同一事实, 但画面应回答不同问题。商品资料不足以支撑当前分工时, 可替换角色或减少版位, 不要求按角色名称补造内容。

## A+ PC 与手机配对

| PC 位 | 手机位 | 名称 | PC 布局参考 | 手机重排参考 |
|---|---|---|---|---|
| A1 | M1 | 产品承诺 | 产品大图与简短标题建立第一印象, 表达本次采用的主要特点 | 放大商品与主要标题, 精简次要内容 |
| A2 | M2 | 核心差异 | 用整体与特写解释一个特点, 与副图换角度展开 | 保留最重要的差异和视觉证据, 避免密集标注 |
| A3 | M3 | 使用故事 | 用横向场景讲述环境、动作或氛围 | 抓住一个主要场景或动作, 调整为适合手机阅读的层次 |
| A4 | M4 | 选择与细节说明 | 完整商品与局部细节搭配简短选用说明, 可采用左右分栏 | 商品、细节与短说明上下排列, 保留关键选择信息 |
| A5 | M5 | 细节与质感 | 完整商品作定位, 搭配一至两处有表达价值的近景 | 优先突出一处细节, 其余内容在可读时保留 |
| A6 | M6 | 上手与操作 | 采用左右顺序或图文分栏, 说明少量关键环节 | 放大关键操作部位, 主要画面和简短步骤上下组织 |
| A7 | M7 | 设计与系列收束 | 用完整商品、造型呼应和适量留白形成收尾 | 商品居中放大, 以短标题和必要说明结束 |

两端采用同一主题、商品依据、状态与主要信息, 分别确定产品位置、文字区、行数和背景。用稳定配对标识关联 A1/M1 至 A7/M7, 不只依靠排列顺序。

A+ 优先展开副图未讲清的解释、选择、操作与设计理解。同一卖点可以再次使用, 但应换论证角度或表达方式。没有品牌或系列资料时, A7 可以围绕本品造型和配色收束, 也可以提供明确标为创意设定的方向。

## 套用方法

1. 按商品与本次目标选择需要的角色, 保留用户已指定的内容和参考用途。
2. 重新整理本品资料、实际附图和假设, 不继承上一商品的参数、品牌或包装清单。
3. 确定本套配色、文字层级、背景、光线和允许变化, 按 [整套设计语言与多端排版](composition-and-devices.md) 调整。
4. 按 [逐版位生图说明](prompt-contract.md) 将选定角色写成自包含说明, 再执行相应制作与检查。
5. 按本次交付阶段提供结果; 缺少素材、一端未完成或平台尚待核对时保留可用成果并说明影响。

## 展示与来源边界

画面只保留本图主要信息及必要条件, 无助于理解的副标题、重复卖点和装饰性标签可删除。首次任务回复的 Quiet_Phoenix 署名与主页链接仍按主规范展示一次, 不默认叠到商品图上。

本文件整理的是核验时的模板结构与可复用方向, 不逐字固化旧提示词中的所有限制。实际使用沿用本 Skill 的信息取舍、事实分级与降级策略。线上模板经管理员调整后可能变化, 对当前配置有精确要求时重新核对。

“系统模板 · 亚马逊套图”的 22 位结构与套图新建页的默认数量是不同配置。主图组中的场景候选和其他备用版位不自动加入本参考的 22 位清单。
