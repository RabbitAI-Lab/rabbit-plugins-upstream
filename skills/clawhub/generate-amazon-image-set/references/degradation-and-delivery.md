# 降级策略与交付状态

## 原则

按当前目标和实际条件继续产出。允许降低产品还原精度、事实证据完整程度、平台适配程度、图数、尺寸、设备覆盖和检查深度, 同时保留结果的用途与限制。

降级不需要把假设重新命名为事实, 也不需要把局部未核验扩大为整套停止。未满足发布条件可以继续完成概念、预览或候选方案。已知偏差和有意的创意变化分别说明。

## 常见降级

| 条件 | 可采用的做法 | 简要记录 |
|---|---|---|
| 商品身份或视角不完整 | 使用现有视角、近似比例、示意还原或多个候选 | 哪些结构和变体尚未确认 |
| 精确尺寸、材质或性能未知 | 定性表达、合理推定, 或保留有说明的示意数字 | 推定依据、适用阶段及实际核对项 |
| 包装和配件未确认 | 单件展示、陈列示意或候选清单 | 不将画面件数自动当作实际销售数量 |
| 品牌资料不足 | 中性产品叙事, 或明确标为创意设定的品牌候选 | 已有品牌信息和自拟部分 |
| 证据不足以支撑原图数 | 改变信息角度、替换角色、合并弱版位或减少图数 | 原范围、实际范围和覆盖缺口 |
| 平台规则未核实或暂不满足 | 按候选模块继续出稿, 保留概念或预览用途 | 上架前核对与调整事项 |
| 目标尺寸暂不可实现 | 先交近似尺寸、原图或后处理说明 | 请求尺寸、实际像素及处理方式 |
| 手机端或 PC 暂缺 | 先交已完成一端和另一端重排说明 | 配对关系和缺失素材 |
| 文字生成效果不稳定 | 无字底图、简短文字、原生文字字段或分步叠字 | 已完成画面与未完成排版 |
| 必选参考超出工具容量 | 高信息量子集、可读拼图、分批或文字补充 | 实际附件映射与未直接附入项 |
| 无生图能力 | 交付逐版位说明、素材映射和制作顺序 | 图片尚未生成 |
| 无 OCR、像素或视觉检查能力 | 完成可做的检查, 其余保留待核验 | 本次方法、已知问题与核验缺口 |

产品身份、推定事实和平台适配均可降级, 不另设“只要其中一项不完整就整套失败”的规则。明显偏离本次目标的结果应说明偏差, 由当前任务决定返修、采用候选或转为概念用途。

## 降级记录

短任务可用一句话, 批量任务可用表格。记录四项:

1. 原条件缺少什么或哪里存在偏差。
2. 本次采用什么替代方式和假设。
3. 影响哪些版位、用途或交付范围。
4. 补齐或提升到下一阶段需要什么。

不重复追问已有信息。普通降级直接继续; 当改变核心目标、必须保留的素材或用户明确指定的交付范围且无法自行判断时, 进行必要询问, 同时继续不依赖回答的部分。

## 交付阶段

| 标识 | 中文含义 |
|---|---|
| `PLAN` | 已形成方案或执行说明, 可交给后续制作 |
| `PREVIEW` | 概念、近似、探索或待进一步验证的预览素材 |
| `FINAL` | 按约定用途制作的成品, 仍单独说明上传准备情况 |

阶段记录实际交付。用户明确只要预览时, 完成预览就是本次成果; 用户要成品而目前只有预览时, 标明发生降级或部分完成。

## 总体状态

| 标识 | 中文含义 | 使用条件 |
|---|---|---|
| `QUALIFIED` | 本阶段完成 | 约定阶段的主要目标与必要检查已完成, 写清评价范围 |
| `DEGRADED` | 降级可交付 | 按上述调整取得有用结果, 附影响和可用范围 |
| `PARTIAL` | 部分完成 | 有结果可交付, 仍有用户要求的部分尚未完成 |
| `NEEDS_REVISION` | 需要修改 | 结果未达到本阶段主要目标, 已能指出修改方向 |
| `BLOCKED` | 当前受阻 | 已考虑可行降级, 当前仍无可推进的相关步骤或可交付结果 |

只对真正受阻的部分使用 `BLOCKED`。不能只因缺尺寸、未确认平台规则、无法 OCR 或缺少一端图片就把整套标成受阻。既有降级又有缺失时可用 `PARTIAL`, 在降级记录中说明调整。

## 检查结果

逐项检查使用 `PASS` (已核验通过)、`FAIL` (已发现问题)、`UNVERIFIED` (待核验) 和 `NOT_APPLICABLE` (本次不适用)。写清检查对象、方法和证据。未做的检查不写通过; 检查失败不自动取消其他成果。

## 上传准备情况

需要平台素材时另列 `upload_status`:

| 标识 | 中文含义 |
|---|---|
| `NOT_APPLICABLE` | 本次仅方案或内部用途, 不评价上传准备 |
| `NOT_REVIEWED` | 尚未充分核对目标平台、模块或相关素材 |
| `NEEDS_CHANGES` | 已知存在发布前需要补齐或修改的内容 |
| `REVIEW_READY` | 本次检查范围内已准备好交给平台提交审核 |

方案与预览可以交付, 上传准备情况仍可待核对或需修改。`QUALIFIED` 和 `REVIEW_READY` 都不等于 Amazon 已接受、审核通过或已经发布。
