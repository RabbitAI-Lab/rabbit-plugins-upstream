# hongshu-note-parser

小红书笔记解析 — 丢一条链接，还你一份品牌可复用的结构化分析报告。

## 适用场景

- 品牌方图文策划案竞品分析
- 小红书爆款笔记拆解
- 视觉策略复盘参考

## 快速开始

```bash
# 1. 采集：抓取笔记内容 + 下载图片
python scripts/parse.py "小红书分享链接"

# 2. AI 分析：读取 stdout JSON + 图片 → 写分析 JSON

# 3. 生成报告
python scripts/parse.py --generate-html output/_analysis.json
```

## 依赖

无。仅使用 Python 标准库（urllib / json / re / html / base64）。

## 输出

| 文件 | 说明 |
|------|------|
| `笔记数据.json` | 采集的结构化数据（标题/正文/图片/互动/标签） |
| `img/` | 下载的笔记配图 |
| `报告.html` | 交互式胶囊卡片分析报告（图片 base64 内嵌，自包含） |

## 报告布局

```
Hero（标题/作者/互动数据）
  ↓
笔记图片画廊（点击放大灯箱）
  ↓
一句话总结（核心策略高亮）
  ↓
视觉策略分析（独立区块，5 维度）
  封面策略 / 图片节奏 / 图文配合 / 视觉风格 / 品牌植入
  ↓
4 胶囊卡片（点击展开）
  内容拆解 / 金句摘录 / 数据标签 / 品牌可复用
```

## 示例

`examples/` 目录包含两个真实案例：

| 案例 | 笔记 | 亮点 |
|------|------|------|
| example1-猫粮笔记 | 「你以为没用，其实对猫咪巨健康的东西‼️」 | 科普种草型，5 图 |
| example2-阿那亚攻略 | 「阿那亚选房保姆级攻略｜1-9期全解析」 | 攻略工具型，7 图，收藏>点赞 |

每个案例包含分析 JSON（AI 产出）和最终 HTML 报告。

> 示例 HTML 为轻量版（图片以占位符代替 base64 内嵌数据），实际生成的报告会完整内嵌所有图片。

## 注意

- 链接须含 `xsec_token`：通过小红书 APP「分享→复制链接」获取
- 直接从浏览器地址栏复制的链接可能缺少 token，会导致笔记数据为空
- 图片下载使用多 Referer 降级策略（小红书 CDN / 腾讯文档图床均支持）
- HTML 报告图片全部 base64 内嵌，不依赖外部 URL
