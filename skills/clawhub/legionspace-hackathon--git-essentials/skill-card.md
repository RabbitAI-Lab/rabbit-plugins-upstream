Developers and engineers use this skill as a compact Git command reference for setup, branching, remotes, history inspection, undo workflows, stashing, rebasing, tags, cleanup, and common collaboration flows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Some referenced Git commands can discard local work, remove untracked files, rewrite history, alter remotes, or change global Git configuration.

Mitigation: Confirm the target repository, inspect git status and diffs, prefer reversible commands such as git revert, and use dry-run cleanup options before destructive operations.
