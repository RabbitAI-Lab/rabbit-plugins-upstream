# Public method sources

- [Anthropic Official Skills Repository](https://github.com/anthropics/skills): Skills are composed of `SKILL.md` plus optional resources, are self-contained and use clear trigger descriptions, examples and rules.
- [OpenAI: Build skills](https://developers.openai.com/codex/skills/): Description ChatGPT and Codex adopt open Agent Skills structure, explicit and implicit triggering,`.agents/skills`local discovery,`agents/openai.yaml` optional metadata and plug-in distribution methods.
- [Anthropic: Agent Skills overview](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview): Description of custom skill catalogs, installation or upload methods, sandbox limitations, and cross-surface desync boundaries for Claude Code, claude.ai, and the Claude API.
- [Microsoft Agent Skills Document](https://learn.microsoft.com/en-us/agent-framework/agents/skills): Describes the Open Agent Skills structure, progressive disclosure, and responsibilities ofreferences/assets/scripts.
- [OpenAI: A Practical Guide to Building Agents](https://openai.com/business/guides-and-resources/a-practical-guide-to-building-ai-agents/): Designing agents around models, tools, instructions, orchestration, and layered guardrails.
- [Anthropic: Building effective agents](https://www.anthropic.com/engineering/building-effective-agents): Prioritize simple, composable patterns, differentiate between fixed workflows and dynamic agents, and weigh cost versus latency.
- [Anthropic: Demystifying evals for AI agents](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents): Establish tasks, experiments, and scorers for agents with multiple rounds, tool usage, and state changes, and continuously add failure cases.
- [OWASP Excessive Agency](https://genai.owasp.org/llmrisk/llm062025-excessive-agency/): Limit tool functionality, permissions, and autonomy, and add manual approvals and limits for high-impact actions.
