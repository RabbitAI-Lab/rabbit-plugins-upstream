## Description: <br>
Plan user flows and screen states for a Figma design before any designing starts. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[mohitagw15856](https://clawhub.ai/user/mohitagw15856) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Designers, product managers, and developers use this skill to plan a feature's screens, states, decisions, entry points, exits, and Figma page structure before design work begins. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Users may expect the skill to connect to Figma or inspect existing files automatically. <br>
Mitigation: Provide the feature, user type, platform, starting point, edge cases, and any project context the planner should consider. <br>
Risk: Planning output can omit context-specific edge cases if the prompt lacks product details. <br>
Mitigation: Review the generated flow map, state matrix, and quality checklist against the product requirements before using it as design scope. <br>
