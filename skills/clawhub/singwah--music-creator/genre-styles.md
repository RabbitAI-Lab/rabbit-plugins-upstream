# Genre Styles Reference (v4)

9 大类 40+ 子风格的详细参考。每个子风格包含 BPM、调性、HappyShrimp 风格提示词模板、编曲特征和代表艺人。

## 1. 流行 Pop

### Synth-pop
- **BPM**: 110–130 | **Key**: Am, Em, Dm
- **HappyShrimp**: `synth-pop, 120bpm, Am, analog synthesizer, drum machine, retro 80s vibe, catchy hook, [vocal]`
- **特征**: 合成器主旋律, 鼓机节奏, 复古 80s 质感
- **代表**: Depeche Mode, New Order, 张蔷

### Dance-pop
- **BPM**: 120–130 | **Key**: Am, Fm, C
- **HappyShrimp**: `dance-pop, 125bpm, Am, four-on-floor kick, polished production, upbeat, [vocal], club-ready`
- **特征**: 四拍底鼓, 明亮制作, 适合跳舞
- **代表**: Dua Lipa, Lady Gaga, 蔡依林

### Indie Pop
- **BPM**: 100–120 | **Key**: G, D, C
- **HappyShrimp**: `indie pop, 110bpm, G, jangly guitar, lo-fi aesthetic, dreamy, [vocal], bedroom pop feel`
- **特征**: 清脆吉他, lo-fi质感, 梦幻氛围
- **代表**: Clairo, Mac DeMarco, 陈绮贞

### K-Pop
- **BPM**: 110–130 | **Key**: Am, Fm, Em

- **特征**: 段落变化丰富, Hook密集, 高度制作

## HappyShrimp 提示词编写技巧

### 核心公式
```
[语言] [子风格], [BPM]bpm, [key], [乐器1], [乐器2], [vocal风格], [mood]
```

### 常用修饰词库

**声线**: male vocals / female vocals / child vocals / choir / duet
**音色**: deep voice / raspy / smooth / airy / operatic / whispery
**能量**: aggressive / chill / energetic / gentle / epic / melancholic
**制作**: polished / lo-fi / live / studio / acoustic / electronic
**特效**: autotune / reverb / delay / distortion / vinyl crackle
**氛围**: cinematic / intimate / festival / bedroom / underground / mainstream

### 避坑
- HappyShrimp 不识别具体歌手名，用声音特征描述代替
- 关键词不超过 6-8 个，太多反而混乱
- BPM 数值要合理，过高/过低 HappyShrimp 可能忽略
- 中文歌词咬字不清时加 `清晰咬字` 改善发音
- 器乐曲用纯音乐模式，或在风格描述中写 `instrumental / 纯音乐`
