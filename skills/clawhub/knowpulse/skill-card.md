## Description:

KnowPulse (知脉) by DAVYLAB validates subject-isolated knowledge graphs, traces prerequisite gaps, supports conservative learning diagnostics, and creates prerequisite-first learning paths for AI courses and education workflows.

This skill is ready for commercial/non-commercial use.

## Publisher:

[chenzhe223-tech](https://clawhub.ai/user/chenzhe223-tech)

### License/Terms of Use:

MIT

## Use Case:

Developers and educators use KnowPulse to validate subject-specific course dependency graphs, inspect prerequisites, and build prerequisite-first learning paths. Answer-based diagnostics are screening only and require educator review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security review had partial coverage, so it does not establish that the skill is risk-free.

Mitigation: Review the files that will run and use the skill with data and permissions appropriate to your workflow.

Risk: Diagnostic output could be mistaken for a definitive judgment about learner mastery.

Mitigation: Treat results as screening only, require educator review, and do not use them for medical, psychological, or high-stakes assessment.
