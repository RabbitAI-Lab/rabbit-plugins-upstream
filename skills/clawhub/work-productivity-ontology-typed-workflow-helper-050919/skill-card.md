## Description: <br>
Helps agent users, skill authors, maintainers, and teams create practical ontology-style workflow plans, artifacts, checklists, analyses, or implementation support for work productivity tasks. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
AI-agent users, skill authors, maintainers, and teams use this skill to turn ontology-style productivity needs into concrete workflows, checklists, templates, code changes, analyses, or decision support. The skill emphasizes restating success criteria, making a concise plan, producing an actionable artifact, and validating the result against the user's need. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger keywords and implicit invocation can cause the skill to appear for generic workflow, graph, knowledge, or bug-fix requests where a more specific skill may fit better. <br>
Mitigation: Confirm that the user's request is about ontology-style workflow planning or related productivity artifacts before applying the skill's workflow. <br>
Risk: Generated plans, scripts, templates, or code changes may be incorrect or incomplete for the user's environment. <br>
Mitigation: Review outputs against the stated success criteria and validate any code, commands, or configuration before relying on them. <br>
