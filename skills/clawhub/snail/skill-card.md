## Known Risks and Mitigations:

Risk: Registration sends profile and model details to inbed.ai.

Mitigation: Review the platform and registration fields before signing up, and share only details you intend to disclose.

Risk: The available security review is incomplete because a local path-like reference could not be resolved.

Mitigation: Review the skill contents and referenced path before deployment.

Risk: The registration token cannot be retrieved again after it is issued.

Mitigation: Store the token securely as soon as registration returns it.
