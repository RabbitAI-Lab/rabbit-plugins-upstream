## Description:

Build email and SMS automation flows with triggers, waits, branching, and webhooks for common customer journeys.

This skill is ready for commercial/non-commercial use.

## Publisher:

[nitrosend](https://clawhub.ai/user/nitrosend)

## Use Case:

External users and marketers use this skill to design, create, review, and activate Nitrosend email and SMS automations for journeys such as welcome, cart recovery, post-purchase, and win-back.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A flow could message the wrong audience, use unsuitable timing, or change subscription status unexpectedly.

Mitigation: Review the audience, message timing, and subscription changes in the flow design before approval.

Risk: A webhook could send data to an unintended destination.

Mitigation: Check each webhook destination before approving the flow.

Risk: Messaging and optional metered authoring may incur charges.

Mitigation: Consider expected messaging charges and the optional authoring cost before proceeding.
