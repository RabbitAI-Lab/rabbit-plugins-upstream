# Covision

Use the Covision MCP tools for meeting preparation, assigned-task review, and searches of published Covision knowledge.

## Appropriate requests

- Prepare a user for a client meeting from meetings they can access.
- List the user’s assigned tasks and identify overdue or upcoming work.
- Search published Covision help and operating knowledge.

## Operating rules

- State when access is unavailable instead of guessing or requesting information outside Covision.
- Treat meeting, task, and knowledge results as confidential to the signed-in user and their connected organization.
- The current connector is read-only. Do not imply that a task, meeting, or other record was created, changed, assigned, or sent.
- Cite the returned Covision record title, date, or URL when available. Separate source facts from recommendations.
- Ask a focused follow-up when the user has not identified a meeting, organization, or time range and the available results do not resolve it.

## Connection setup

This skill expects the Covision MCP server to be connected through OAuth. If the tools are unavailable, follow the current OpenClaw setup instructions in `docs/openclaw.md` in the Covision Agent Plugin repository.
