## Description:

Creates validated, interactive diagrams for architectures, workflows, sequences, data flows, and state lifecycles as standalone HTML with inline SVG.

This skill is ready for commercial/non-commercial use.

## Publisher:

[qikairo7](https://clawhub.ai/user/qikairo7)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use Archify to turn requirements, Mermaid input, or repository evidence into checked diagrams of systems, processes, data movement, and state changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Local diagram commands execute with access to the requested repository evidence.

Mitigation: Review the commands and limit repository access to the material intended for the diagram.

Risk: Optional brand capture and update checks may contact external services.

Mitigation: Use these options only when appropriate and verify the sources before including captured material.
