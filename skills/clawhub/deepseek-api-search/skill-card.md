## Description:

Search the web and retrieve webpage content through DeepSeek Search and Fetch APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jhc888007](https://clawhub.ai/user/jhc888007)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and other agent users can find current sources, filter search results, and read selected webpages for research and sourcing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Search queries and fetch URLs are shared with DeepSeek using the user's API key.

Mitigation: Do not submit confidential queries, private intranet URLs, or secret-bearing URLs unless third-party sharing is acceptable.
