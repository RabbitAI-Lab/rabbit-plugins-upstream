# 道路几何校核与多视角审查

本文件对应 `site_layout/road_geometry.py` 与 `site_layout/review_panel.py`，由 `build_site_plan.py` / `generate_site_layout.py` 自动执行并输出；内容与 0.5.0 同步。

## 1. 道路四项几何校核

| 编号 | 项目 | 默认阈值 | 依据 | 状态 |
|---|---|---|---:|---|
| R1 | 单车道宽度 | ≥3.5 m | 施工道路经验值 | [经验] 待项目复核 |
| R1 | 双车道宽度 | ≥6.0 m | 施工道路经验值 | [经验] 待项目复核 |
| R1 | 消防车道净宽 | ≥4.0 m | GB 50720 | [规范] |
| R2 | 单车道会车点间距 | ≤100 m | 施工道路经验值 | [经验] 待项目复核 |
| R3 | 临时道路转弯半径 | ≥9 m | 施工道路经验值 | [经验] 待项目复核 |
| R3 | 消防车道转弯半径 | ≥12 m | 按消防车转弯要求，数值待项目复核 | [规范/待核] |
| R4 | 尽头式回车场 | ≥12 m×12 m；高层 ≥15 m×15 m | GB 50016 | [规范] 高层判定由项目确认 |

说明：

- 宽度按 `attrs.lanes` 区分单/双车道；未给车道数时，宽度 ≥6.0 m 视为双车道，否则按单车道。
- 会车点只对长度 >100 m 的单车道校核；`attrs.passing_bays` 未提供时给 `manual`，不猜位置。
- 转弯半径用折线顶点三点外接圆计算，是偏保守的近似；实际图应画圆弧或倒角，最终按车型/消防车参数复核。
- 尽头式判定：道路端点 2 m 内无其他道路端点相接，即视为尽头；`attrs.turnaround=true` 或 `attrs.turnaround_area_m` 达到要求可放行。
- **只对 `temporary_road`、`fire_access` 判尽头**；`permanent_road` 归市政管理，不误报，但它的端点可作为临时道路的接顺点。
- 消防车道尽头缺回车场判 `fail`；临时道路尽头缺回车条件判 `manual`。
- 共线临时主路与消防车道只计一次长度，`road_length_by_category_m` 不重复列 `fire_access`。

## 2. 道路 attrs 写法

```json
{
  "id": "R-01",
  "category": "temporary_road",
  "width_m": 4.0,
  "geometry": {"type": "line", "points": [[0,0],[120000,0],[120000,80000]]},
  "attrs": {
    "lanes": 1,
    "passing_bays": [
      {"station_m": 50, "width_m": 6.5, "length_m": 15},
      {"station_m": 100, "width_m": 6.5, "length_m": 15}
    ],
    "turnaround": true,
    "turnaround_area_m": 144
  }
}
```

`station_m` 是沿道路中心线从起点算起的里程，不是坐标。

## 3. 多视角审查

六个固定角色，同一份校核结果按关注点重排：

| 角色 | 关注点 | 主要检查 |
|---|---|---|
| 项目总工 | 总体可行性、骨架、阶段衔接 | 1/2/4/11/13/14 + R1~R4 |
| 安全总监 | 塔吊、临建、用电、交通冲突 | 6/7/14 + R2/R3 |
| 消防/临建 | 消防车道、消火栓、净空、回车 | 3/4/5/15 + R1/R3/R4 |
| 文明环保 | 加工区隔离、九牌一图、垃圾扬尘 | 8/9/10 + R1 |
| 商务成本 | 道路规模、永临结合、配电距离 | 3/7/11 + R1 |
| 甲方/报建 | 红线、出入口、阶段必备、公示 | 1/2/4/9/13 |

结论规则：

- 该角色范围内有 `fail` → `fail`
- 无 `fail` 但有 `manual` → `review`
- 全部 `pass` → `pass`

闸门：

- `hard_fail=true`：不可提交内部评审，先改硬伤。
- `manual_review=true`：可提交，但必须带待确认清单。
- `final_check` 恒为 `false`。

角色意见只做重排，不新增结论，不替代审批和签字。

## 4. 输出

每次 `build_site_plan.py` 每个阶段自动生成：

```text
road-check-<stage>.json      # R1~R4 明细，可复算
road-check-<stage>.md        # 人读版
review-panel-<stage>.json    # 六角色结论、findings、闸门
review-panel-<stage>.md      # 人读版
```

`stage-<stage>.json` 里增加 `road_summary` 与 `review_summary` 两个摘要字段。

## 5. 会车、转弯、回车场怎么画

- 单车道 3.5 m 是**下限**；有会车、卸货、消防要求时按双车道 6.0 m 或加宽段。
- 会车点建议沿单车道每 60~100 m 设一处，尺寸按车型和现场条件；`passing_bays` 写里程，不写坐标。
- 普通施工道路转弯半径 9 m、消防车道 12 m 均为 [经验] 起步值；实际按车型、消防车参数、转弯轨迹复核。
- 尽头式道路优先做环形或 T 形回车场；12 m×12 m 是普通多层下限，高层项目按 15 m×15 m 或当地消防要求复核。
- 道路与永久道路结合时，先确认市政接顺标高、排水、产权和开口许可，平面图只能表达“接得上”，不能表达“接得合法”。

## 6. 边界

- 不校核道路结构承载力、纵坡、横坡、视距、交叉口转角，这些需要纵断面和现场条件。
- 不判断道路走向是否最优。
- 不替代消防审查、施工组织设计审批和项目总工签字。
