# 本版能做什么（0.7.2）

- **多方案候选**：A/B/C 三套布置，含道路骨架、塔吊覆盖、钢筋/木工/砂浆加工区、变压器、消防泵房/水池、排水沟、堆场、办公生活、临水临电、消防、施工电梯、九牌一图、宣讲台、垃圾池、洗车台、地磅等；自动设施统一 `source=auto-layout`、`confidence=candidate`。
- **真实红线与主体提取**：从底图建筑外轮廓层提取多栋闭合环并取最大主体；无主体轮廓时默认拒绝 A/B/C，`--allow-assumed-building` 只能出功能草案。红线按真实多边形内缩，出图窗口只取红线外 50 m，并裁剪窗口外底图线段。
- **设施图元形象化**：塔吊和施工电梯按类型自绘格构塔身、起重臂、配重、吊钩、双导轨、吊笼、停靠层与附着；主图显示尺寸有下限，图内注明“类型示意、不按实际尺寸”。
- **总平面与周边研判**：高压线、住宅、河道、市政管线、敏感点、既有道路、产权边界；硬约束 fail，软约束 review，塔吊看回转外缘而不是只看中心。
- **三阶段**：`earthwork / structure / finish` 分别过滤设施、跑规则/道路/周边、出 DXF/PNG；塔吊默认只进主体阶段，土石方/装饰自动退场（跨阶段使用需显式声明）；三阶段汇总时任一阶段 fail 即硬伤，人工项取并集，分数取最不利阶段。
- **道路几何**：单/双车道宽度、消防车道净宽、单车道会车点、转弯半径、尽头式回车场；永久道路端点可作接顺点，共线消防车道不重复计长。
- **临建规则**：消火栓间距/保护半径、配电室/一级箱距离、钢筋/木工/砂浆三类加工区隔离、变压器安全距离、消防泵房与水池、排水沟连续与排放、九牌一图、垃圾池、永临道路结合、阶段必备、几何冲突、消防净空等 26 条（含 0.7.0 生活区专项：与作业面分离、道路/消防疏散、配套完整性、办公区靠近主出入口）。
- **生活区分设**：员工宿舍区与工人生活区分开建模，工人生活区内置食堂、卫生间/淋浴、晾晒区三个子块；子块必须完全位于父包络内并声明 `parent_id`。自动生成按三块尺寸整体组合搜索，优先保证最差一块的尺寸保持率，再比总面积；默认净距 0.8 m，必要时降到 0.6/0.5 m 并写入 assumption。场地夹逼导致降级时写 `size_degraded/size_note`，不能当成人数、床位数和消防疏散已确认。
- **六视角审查**：每个角色输出 `pass/review/fail`、待办与闸门；角色意见只重排结论，不替代审批。
- **确定性留痕**：每条规则给数值与证据；A/B/C 分数是内部比选，不是评标分；每张图带 `DRAFT`、版本、合同号和免责声明。
- **单位与同源闸门**：无单位不猜，单位冲突 exit 4；同源优先比源图 SHA-256，缺失时退回比 `cad-contract` 契约号，两者都缺标 `unverified` 并告警；不同源出图 exit 5。
