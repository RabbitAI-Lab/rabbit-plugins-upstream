# book-analyst · 图书智能解读系统

以专业图书分析专家的角色，对指定图书进行系统、深入且实用的解读分析，产出帮助读者快速把握核心内容、获取实践指导、并顺着「书脉」延伸阅读的解读报告。

本技能为 AI 智能体技能包，通过 SKILL.md（+ references/report-spec.md 输出规范）驱动，无需外部 API 与网络依赖。

## 功能特性（v1.1.0）

- **13 节结构化解读**：基础信息 → 内容框架 → 核心观点 → 关键概念 → 精彩片段 → 三层应用价值 → 思维导图 → 批判性思考 → 行动指南 → 阅读建议 → 核心问答 → 延伸思考 → 同类图书推荐
- **线头梳理**：报告末尾附 2–4 本同类图书推荐，逐本标注与本书的关联「线头」类型（同作者延续 / 同主题深化 / 观点交锋 / 方法论同源 / 跨界呼应）与建议阅读顺序
- **评分量规校准**：价值度📚 / 难度🎯 / 实用度⚡ 三档评分按可对照量规给出，并附一句理由
- **引文真实性**：所有引用带来源状态标注（[原文] / [大意] / [公认表述]），无原文材料时自动降级为转述，杜绝伪引文
- **mermaid 思维导图**：第 7 节以 mermaid mindmap 语法输出（附纯文本树兜底）
- **双格式交付**：Markdown 完整报告 + 单文件 HTML 可视化报告（自包含、深浅主题自适应、13 节锚点目录）
- **交付自查清单**：报告交付前逐项核对 8 项质量检查

## 安装方法

将 `book-analyst/` 目录（含 SKILL.md 与 references/）复制到智能体的用户级技能目录：

```bash
# 通用位置示例（不同智能体以各自技能目录为准）
cp -r book-analyst ~/.workbuddy/skills/
```

安装后无需配置，直接以自然语言触发。

## 使用方式

**触发说法**：`解读某本书`、`分析/拆解某本书`、`生成读书报告`、`这本书讲了什么`、`读完这本书还可以读什么`。

**输入形式**：可直接给书名，也可提供该书的章节文本、阅读笔记、摘录或 PDF 内容（提供材料时分析将以材料为唯一事实来源，精度更高）。

**输出**：`<书名>-解读报告.md` 与 `<书名>-解读报告.html` 双文件。

## 示例输出（节选）

输入《穷查理宝典》后，报告包含：4 类线头推荐（巴菲特致股东的信 · 同主题深化 /《思考，快与慢》· 方法论同源 /《投资最重要的事》· 同主题深化 /《漫步华尔街》· 观点交锋）；三评分附理由（📚9/🎯4/⚡8）；全部引文标注 [公认表述] 或 [大意]；HTML 版含 13 节卡片式目录。
