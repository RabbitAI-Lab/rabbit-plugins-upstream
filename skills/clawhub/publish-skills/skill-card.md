## Description:

Guides maintainers through publishing skills to ClawHub and diagnosing skipped or failed skill-sync runs across the named repositories.

This skill is ready for commercial/non-commercial use.

## Publisher:

[j3ffyang](https://clawhub.ai/user/j3ffyang)

### License/Terms of Use:

MIT-0

## Use Case:

Maintainers of the named skill repositories use this guidance to publish SKILL.md updates through their ClawHub sync workflows, check release status, and troubleshoot failures.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Following the publishing guidance can publish or update skills under the configured ClawHub account.

Mitigation: Use it only when managing the named workflow, and review skill edits before pushing to the publishing remote.

Risk: Publishing credentials could be exposed in logs or repository files.

Mitigation: Keep the ClawHub token in masked secrets or environment variables and avoid logging it.
