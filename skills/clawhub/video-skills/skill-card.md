## Description:

Finds and recommends agent skills for AI video, image, voice, and music tasks, presenting visual options before generation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to find suitable skills and how-to guidance for media creation tasks, such as video editing, captions, voice, music, and animation. It presents choices before generation and directs the user to the selected skill or service.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Search requests may include confidential project details.

Mitigation: Remove confidential information from search requests.

Risk: Recommended skills and installation commands may not suit the user's task or account permissions, and generation can incur costs.

Mitigation: Review recommendations and install commands before enabling a skill, and check account permissions and generation costs.
