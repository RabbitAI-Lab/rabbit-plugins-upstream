## Description:

Matches video, image, voice, and music requests to relevant varg how-to workflows and presents visual options before generation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

People planning AI video, image, voice, or music work use this skill to find a suitable workflow, review visual options, and get its installation and usage guidance. It helps select a workflow and does not perform media generation itself.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Full-video projects may use GitHub storage without clearly specifying which project files are uploaded.

Mitigation: Before proceeding, agree on the storage location, account, and exact files that may leave the device; remove confidential details from search requests and review downstream skills before installation.
