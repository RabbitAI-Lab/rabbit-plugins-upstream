## Description:

Finds a suitable agent workflow for video, image, voice, or music requests and presents options before generation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers can use this skill to match a video, image, voice, or music request to a suitable agent workflow. It helps them review visual options and workflow guidance before generation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The recommended install command may use an unpinned installer.

Mitigation: Review the install source and version before running the command.

Risk: Search text is sent to an external service.

Mitigation: Avoid including confidential details in search requests, or confirm external sharing is acceptable.

Risk: The broader workflow may store project material in a private GitHub repository.

Mitigation: Confirm repository privacy and the project files intended for storage before setup.
