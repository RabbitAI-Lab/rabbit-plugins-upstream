先说清楚：AI 助手会拿到什么权限

  • 能做：配置域名解析、网站加速和免费证书、管理你已有的服务器（开端口、部署网站、执行命令）
  • 做不了（腾讯云会直接拒绝）：花钱（买服务器、续费、买域名）、删除或重装服务器、删除或转让域名、查看余额、查看你的实名资料
  • 你填的密钥只保存在这台电脑上，不会发给 AI 对话，也不会发给龙虾学院
  • 随时可以收回：腾讯云控制台 → 访问管理 → 用户列表 → agent-ops → 禁用，立即生效
  • 它的每次操作都会记在腾讯云「操作审计」里
  • 需要说明：为了部署网站，它能在你的服务器上以管理员（root）身份执行命令。请只把要交给它管理的服务器放在这个账号里。

有腾讯云账号吗？

已经有、并且完成了实名认证 → 直接跳到第 2 步。还没有：

① 注册腾讯云 ② 实名认证

注册：可以用微信扫码，也可以用邮箱或 QQ，需要一个中国大陆手机号（+86）。
实名认证：个人选「微信扫码」或「人脸识别」，几分钟就能完成；需要开公司发票就选企业认证。不实名就买不了任何云服务。

2

创建权限策略（规定 AI 助手能做什么）

打开「策略」页面
  1. 在打开的页面上，点 「新建自定义策略」 → 「按策略语法创建」 → 选 「空白模板」 → 下一步
  2. 策略名称填：agent-ops-web
  3. 把「策略内容」框里原有的文字全部删掉，粘贴刚才复制的内容 → 点「完成」
查看策略内容（不需要看懂）
3

创建 AI 助手专用的子账号

打开「用户列表」页面
  1. 点 「新建用户」 → 选 「自定义创建」 → 选 「可访问资源并接收消息」 → 下一步
  2. 用户名填：agent-ops
  3. 访问方式：只勾「编程访问」，不要勾「腾讯云控制台访问」 → 下一步
  4. 设置权限：在搜索框输入 agent-ops-web，勾选它。不要勾 AdministratorAccess 或其他任何策略 → 下一步 → 完成
