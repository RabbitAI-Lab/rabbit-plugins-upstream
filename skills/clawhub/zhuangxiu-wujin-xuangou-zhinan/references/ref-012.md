# 全屋定制10种实用做法，设计师都自愧不如！

全屋定制并不是定制盒子那么简单，也远远不是只要隐藏杂物的功能，而是要提升整体入住的价值感。今天看看这些定制的做法，不仅是满足功能，而且做出更有价值的设计，让普通设计师也自愧不如。第一、阳台没有墙垛定制做法。网友@美学格：阳台交付的墙垛拆除，做了一个侧面展示柜 与阳台洗衣机柜融为一体，美观又实用 不影响客厅采光阳台柜与侧柜齐平，将洗衣机和烘干机嵌入，阳台柜底部镂空放置扫地机器人刚合适，侧面和上面收纳清洁用品和杂物都很实用阳台侧面展示柜，上柜超白玻璃门，通透感十足，摆放书籍、纪念品都很有意义，下柜收纳纸巾、零食也很方便。网友@杨慧：阳台垛子砸不掉还不想包套，这么整就对了。有没有谁特别讨厌包套，又贵，又不好看，怎么办？ 一张图，告诉你，就这么办，简单，好看，还实用，还能放娃娃喜欢的小玩具。 全屋定制，整起来。网友@猪猪侠：阳台柜延伸至垭口，1.05->1.4米，增加收纳空间，且更加大气。网友@一木：阳台没有墙垛，做了组薄柜➕洗衣机柜的结合，视觉上部侧面开放，刚好用来摆放喜爱的小手办，一是不浪费，二是侧面看过去不是光秃秃的一块板，过于单调，下方正面开放镂空，直接用来放活动置物架，用来放置洗衣清洁用品，刚刚好nice。第二、利用定制弱化柱子的突兀。家里的承重柱子不能敲，简单的板子和不锈钢完美组合就可以让它更具功能性，简洁又实用~最重要是视觉上弱化了柱子的突兀感拆不掉的承重墙别再头疼啊~利用一下 利用黑色悬浮柜将转角包起来， 既增加功能性，又缓和转角的突兀感 黑白灰配色的极简风搭配暖调灯带， 是温馨又舒适利用餐厅和客厅间的柱子，形成悬浮餐桌的设计，与半开放厨房结合，柱子上的洞洞板满足屋主放一些装饰以及平板电脑支架的需求。家里不能拆的柱子 秒变高颜值置物架。这里原本是有个承重柱的，在客厅和餐厅之间，男业主平时有燃香的习惯，就顺势利用这个敲不掉的柱子做个燃香壁龛，把柱子利用起来。
承重柱×岛台穿插， 厨房选用开放式结构，直接变靓丽风景线呀，露出部分与墙面同色，安排上置物架 放些调料的瓶瓶罐罐，拿取方便 也很美观！
第三、厨房随手放调料。厨房正好有一段墙面凹档，被利用上了。做了小移门，左划可以隐藏在旁边高柜后面， 不锈钢台面搭配木纹免漆板， 高级感满满。利用台面夹角空间，定制「抽拉调料柜」，炒菜时直接抽拉取物，一目了然，超好用！橱柜台面空间窄不够用，在台面下方安装一个「隐藏式抽拉操作台」，便捷又实用，不用时关上，严丝合缝！燃气管包好以后还能做个超薄调料柜，真的不要再用台面来包管道了。这样做遮丑超级完美！ 随拿随放，隐形收纳，台面干净整洁直接在右侧高柜向左延伸出25CM，做成侧面开放调料格，这样的设计不仅整体感好，在厨房空间上衔接了厨柜和电器高柜，在功能上操作动线顺畅，更易拿取调料，在视觉上隐蔽性好，就算是调料瓶没那么统一，也不会让厨房显得杂乱。利用烟道设计出来的薄高柜，这种犄角旮旯用来放调料正正好 能藏起来的也都藏进柜子，关上柜门岁月静好。第四、厨房烟道管道薄柜。花了很多心思设计的地方！ 用起来还算是比较顺手！ 最最重要的，烟道旁边的15cm厚薄柜！ 如果你家也有这么个地方！ 强烈建议做起来！ 真的瓶瓶罐罐都收纳进去！ 关上门！干干净净！清清爽爽！在烟道的前方做了26厘米深2.3米高40厘米宽的顶天立地的薄柜，用于放厨房的调料和瓶瓶罐罐；调料柜刚好在炒锅的右手边，炒菜时打开门一目了然拿取非常方便，平时关上门又可以保持整洁美观。不仅是烟道薄柜，也可以利用厨房下水管前方空间，满足一个薄柜的收纳，视觉空间也变得更美观，一举两得第五、橱柜转角柜门更实惠。用各种炫技的五金那不是设计，用钱解决的办法谁都会。
橱柜台面进深60cm，层板向内退了15-20cm，分别深40cm和45cm，更易于拿取靠里的物品。 使用了4个165度铰链，这样柜门就可以完全向两侧打开。便于双手拿取重物。 柜门采用双开门设计，右边门先开，再开左边门。也可以做联动门，但是这个柜门较大，做联动门今后会有门板下沉的风险。层板分层空间 错层设计上下两层，下高上低 下层高度41cm，上层高度37cm，可以满足各种高度物品的收纳需求减少空间浪费； 使用了4个铰链，联动开门设计， 这样柜门就可以完全向两侧打开 便于双手拿取总结：以上两种办法，是不用多花一分钱就可以解决的办法，如果采用各种五金炫技的话，要设计师干啥？这个不是设计师的功劳，是金钱的力量！第六、最简单最省钱的电视柜插座隐藏。隐藏电视柜插座不要那么复杂，也不需要多余花钱，如果为了炫技，做那么复杂的话还是算了。上图做个抽屉抽拉不显得多此一举吗？还得多掏个抽屉钱和轨道钱。这种做法纯属智商税，后期不论更换插座或者使用电源都得趴地上。最实用的往往就是不用花一分钱的，最原始的设计才是最高端的，如上图，板子直接可以拿掉，不论你储物或者维修，都是最方便的。第七、次净衣收纳体现品质。网友@嘟嘟：真心建议大家装修一定要留一个空间做次净衣区 真的太好用，家居服、只穿了一两次的外套和裤子都有家了～网友@吃肉睡：折叠挂衣架＋脏衣篮的组合！ 成功打造了次净衣区网友@梦想成长：侧边次净衣区高90厘米，宽51厘米，深度31厘米。大人、小朋友衣服都可以放下。网友@睡莲：侧边次净主卧门背后这块区域就非常合适，不占空间，开门就能隐藏，完美利用死角！网友@来了就亮：挂衣区＋换鞋凳＋置物台 胆大心细的玄关柜，咖＋黑的配色第八、干区隔断柜。网友@1318：做了卫生间干区隔断柜双面高柜之后收纳再也不用愁了网友@琪姐：公卫洗手盆没有做半墙，做了这个薄柜来做手办柜是装修觉得最棒得决定，上面可以放心爱的阿尼亚，下面可以收纳纸巾、牙膏等日用品，既美观又实用第九、洗衣柜突出墙体。网友@格桑花：阳台和客厅之间的墙太窄了，装洗衣机柜会突出墙面。加一个和墙一样厚的开放格，完美的解决了问题，侧边的开放格和吊柜下面的开放格均做了胡桃色的跳色。使得整个柜子更加灵活美观。洗衣机柜突出阳台墙体，采用矮柜延伸出来，不仅满足收纳，同时遮挡洗衣机第十、飘窗西厨柜。网友@王美瘦：餐厅既然飘窗不能砸，那就把飘窗上方的空间利用起来，飘窗加高40厘米做一组电器柜，做了一个台下盆，日常洗水果或者洗菜洗手都可以用这个水盆，非常方便；左边的抽屉我会收纳一些咖啡机用到的东西，还有一些咖啡杯，包括榨汁机和料理机都可以藏起来，要用的时候拿出来其实也很方便网友@李李子：在不影响开窗的情况下，可以在飘窗上增加一到两层的抽屉储物功能，这样就可以大大释放厨房台面空间网友@桃子：餐厅低矮的窗台加高做了6个抽屉，让原本堆放杂物的飘窗变成了额外的西厨区，在这里做做早餐偶尔做烘焙十分实用。网友@Jiu：一直觉得飘窗是个鸡肋空间，直到我把它改造成了一个中古风水吧台，瞬间变成了家里最治愈的角落！每天在这里喝咖啡、看书，简直不要太惬意～飘窗下方做了抽屉式收纳，用来放咖啡豆、茶叶、杯子等，同时嵌入蒸烤箱，好看又实用。总结：全屋定制贵在设计，绝对不是定制盒子，但是只看低价的话，仅仅满足的是盒子的定制，完全就没有了细节价值了。
