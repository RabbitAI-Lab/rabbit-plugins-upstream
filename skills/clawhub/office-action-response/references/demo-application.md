# 示例申请文件（虚构演示案例，仅用于体验本技能）

申请号：202410000000.0（虚构）
发明名称：一种水渠闸门自动除冰装置及其控制方法
申请人：示例水利科技有限公司（虚构）

## 权利要求书

1. 一种水渠闸门自动除冰装置，包括闸门、驱动所述闸门升降的启闭电机，以及控制器，其特征在于：所述闸门两侧与闸槽接触的止水区域设有加热膜；所述装置还包括检测环境温度的温度传感器和检测所述启闭电机工作电流的电流传感器；所述控制器在所述环境温度低于温度阈值、且启闭过程中所述工作电流高于电流阈值时，判定所述闸门结冰卡滞，先启动所述加热膜加热，再控制所述启闭电机驱动所述闸门进行小幅往复启闭。

2. 根据权利要求1所述的水渠闸门自动除冰装置，其特征在于：所述小幅往复启闭的行程为5～20毫米，往复3～5次。

3. 根据权利要求1所述的水渠闸门自动除冰装置，其特征在于：所述加热膜为嵌入止水橡胶内的碳纤维发热膜。

4. 根据权利要求1所述的水渠闸门自动除冰装置，其特征在于：所述控制器在所述工作电流恢复到所述电流阈值以下后停止所述加热膜加热，并恢复正常启闭。

5. 一种水渠闸门除冰控制方法，采用权利要求1所述的装置，其特征在于，包括以下步骤：S1，实时采集环境温度和启闭电机的工作电流；S2，当环境温度低于温度阈值且工作电流高于电流阈值时，判定闸门结冰卡滞；S3，启动加热膜加热预定时间；S4，控制闸门小幅往复启闭直至工作电流恢复正常。

## 说明书

### 技术领域

[0001] 本发明涉及水利工程设备技术领域，具体涉及一种水渠闸门自动除冰装置及其控制方法。

### 背景技术

[0002] 北方地区冬季气温低，水渠闸门与闸槽之间的止水区域容易结冰，导致闸门冻结卡死、无法启闭。现有做法多为人工破冰，或者对闸门整体持续加热，前者效率低、有安全风险，后者能耗大。现有带加热功能的防冻闸门大多按温度定时加热，不能判断闸门是否真的被冰卡住，经常在没有卡滞时空耗电能，卡滞严重时又加热不足。

### 发明内容

[0003] 本发明要解决的技术问题是：准确判断闸门是否结冰卡滞，并在卡滞时以较低能耗快速解除卡滞。

[0004] 为此，本发明在闸门两侧止水区域设置加热膜，同时用温度传感器检测环境温度、用电流传感器检测启闭电机的工作电流。闸门被冰卡住时，启闭电机负载增大、工作电流明显升高。控制器在低温且电流超限时判定为结冰卡滞，先局部加热止水区域使冰层与闸槽之间形成水膜，再驱动闸门小幅往复启闭，利用往复运动剪断冰层。

[0005] 有益效果：只在真正卡滞时加热，且只加热止水区域，能耗低；加热与小幅往复配合，比单纯加热更快解除卡滞；电流恢复正常后自动停止加热，避免过度加热。

### 具体实施方式

[0006] 如图1所示，闸门1沿闸槽2升降，由启闭电机3驱动。闸门1两侧止水橡胶4内嵌入碳纤维发热膜5。温度传感器6安装在闸槽顶部，电流传感器7串接在启闭电机3的供电回路中，二者均与控制器8连接。

[0007] 本实施例中，温度阈值取0℃，电流阈值取启闭电机额定电流的1.3倍。启闭时若检测到环境温度低于0℃且工作电流超过额定电流的1.3倍，控制器8判定闸门结冰卡滞，先停止启闭，启动发热膜5加热3～5分钟，再控制启闭电机3驱动闸门1上下往复移动，行程10毫米，往复4次。

[0008] 往复过程中持续检测工作电流，电流回落到阈值以下即判定卡滞解除，控制器8停止加热并恢复正常启闭；若往复后电流仍超限，重复加热和往复，累计3轮仍未解除则报警，提示人工处理。
