## Description:

Helps an agent generate 10–300-second music tracks from text prompts for background music, ads, and short videos through dLazy's hosted service.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to request original music for background tracks, advertisements, and short-form videos using natural-language prompts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and generation parameters are sent to dLazy's third-party API, and output is hosted by its file service.

Mitigation: Use the service only when sharing the prompt and hosting generated output with dLazy is acceptable.

Risk: Local files explicitly provided to the CLI may be uploaded to dLazy's file service.

Mitigation: Avoid passing private files unless the upload is intended.

Risk: A global CLI installation persists on the machine.

Mitigation: Use the pinned npx invocation if a persistent global installation is not desired.
