## Description: <br>
Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to turn REST API requirements, route behavior, and existing service details into practical OpenAPI or Swagger documentation, review checklists, validation steps, and implementation support. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate for generic REST API or developer-experience questions because its activation wording is broad. <br>
Mitigation: Use it when the request explicitly involves OpenAPI, Swagger, API specifications, or REST API documentation work. <br>
Risk: Generated API documentation can be incomplete or misleading when route behavior, schemas, authentication, or error responses are not supplied. <br>
Mitigation: Review outputs against service source, tests, and runtime behavior, then validate the resulting OpenAPI or Swagger content with an appropriate schema validator. <br>
