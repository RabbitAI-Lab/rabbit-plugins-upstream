## Description:

Drafts bilingual AI-content disclosures, suggested metadata labels, and platform placement tips for fully generated, AI-assisted, or mixed content.

This skill is ready for commercial/non-commercial use.

Creators, publishers, and developers use this skill to draft Chinese and English AI-content disclosures, suggested metadata labels, and placement guidance before publication.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Draft disclosures may not meet current requirements for a regulated publication.

Mitigation: Check current official requirements and obtain appropriate professional review before publishing.

Risk: Generated statements and metadata assert human review without checking that it occurred.

Mitigation: Confirm human review took place and edit the statements and metadata to match the actual process.

Risk: Suggested metadata is not written into the published content.

Mitigation: Apply and verify required labels in the destination platform or file metadata separately.

Risk: The code and documentation have different reuse terms.

Mitigation: Read the license scope before reusing or redistributing the documentation or theory text.
