## Description:

A text polishing and formatting skill for Chinese novels, articles, and copywriting that sends 300+ character drafts to a cloud service to reduce AI-like phrasing and improve paragraph flow.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and creators use this skill to polish or format Chinese long-form drafts, especially novels, self-media articles, and copywriting, while preserving the original meaning.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Draft text may be sent to a third-party cloud endpoint.

Mitigation: Avoid private drafts or regulated content unless the user accepts third-party cloud processing.

Risk: A personal API key can be saved locally until cleared.

Mitigation: Use a personal key only when comfortable with local storage, and clear it when it is no longer needed.

Risk: The release promotes detection-evasion uses.

Mitigation: Do not use the skill to evade AI, plagiarism, or platform detection checks.
