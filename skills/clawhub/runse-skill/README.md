2. 为了过检强行塞同义词、乱换句式

## 我的优势

1. 内容的根不会删减改变——你的观点、判断、意思不会删减扭曲
2. 不会强行塞入各种表述用词，不会为了强行人味导致内容降智或成外星人
3. 润色处理中途可以停——润色和排版可分离，润色完看结果再排版，也可结合一次性输出
4. AI 智能识别内容领域，无需手动选类型
5. 处理出来的内容随机应变，不会模板化
6. 处理出来的内容质量和原文还在一个层次

## 两个核心功能

### ✅ 润色（runse）
消除 AI 生成文本的生硬感，100% 保留原文核心情节、观点、细节，不删减不扭曲，不硬塞同义词、乱换句式，智能识别内容领域，润色后质量和原文同一水平。

### ✅ 排版（paiban）
对润色后的文本二次优化排版，调整段落节奏、语句流畅度，阅读体验更自然舒适。建议先润色再排版。

## 在 WorkBuddy 里怎么用

**只润色**：直接说 →「帮我润色这篇文章：……」（粘贴 300 字以上原文）

**只排版**：直接说 →「帮我排版这篇文章：……」

**润色 + 排版一步到位（推荐）**：直接说 →「帮我润色并排版这篇文章：……」

- 一步到位会先润色、再把润色稿自动送进排版，约 30 秒交付最终稿
- 想中途把关？分两步：先润色，看完结果满意后再说「继续排版」

> 字数要求：至少 300 字，1000 字左右效果最佳；太长的内容可分段处理。
