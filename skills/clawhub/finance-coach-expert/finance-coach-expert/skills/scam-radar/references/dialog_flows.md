# 对话流完整话术 + 拒绝话术库（dialog_flows.md）

## 对话流一："老师荐股/带单"

**用户**："群里有个老师天天带单，上周跟着买赚了，这周让加资金，靠谱吗？"

**引导路径**：
1. 先要事实（不评价）："老师说过自己在哪家机构吗？群里收益截图能提供账户流水吗？资金是转到你自己的证券账户，还是别的 App？"
2. 过五特征（重点：持牌 + 资金去向）。
3. 给查验："证监会官网'监管对象'搜一下这位老师说的机构全名；基金业协会名录查有没有投顾资质。5 分钟就能查完。"
4. 收尾自决："查完有资质、资金也走你自己账户，你再决定；查无资质还催你加钱的，你自己就能判断。我这边不替你下结论。"

**高危信号要重点提醒**（只列事实）：要求转个人账户、用"内部通道App"交易、催加资金——命中即"高度存疑"，引导立即停止转入并核实。

## 对话流二："9 元/免费理财课"

**用户**："报了个 9 块钱的理财训练营，班主任天天私聊让我报 6800 的进阶班，说不学就赶不上涨了。"

**引导路径**：
1. 讲通用链条（见 case_material.md 套路一）：低价引流→社群造梦→话术升级→高价课，这是被消协反复提示的模式。
2. 过收费模式特征："低价入门 → 高价进阶"、"不学就错过"（紧迫感逼单）、"可以分期/贷款"——逐条让用户对号。
3. 给维权路径（如已付费）：12315 平台、消协投诉渠道；被诱导贷款买课的，金融监管总局 12378。
4. 收尾："继续上课还是退，决定权在你；如果退费遇到阻拦，上面维权路径可以走。我这边不替你判断这个课本身。"

## 对话流三："保本高收益"

**用户**："有个平台说保本保息年化 12%，国资背景，能不能投？"

**引导路径**：
1. 讲常识："保本"与"高息"同时出现本身是矛盾表述——收益与风险成正比是基本规律，正规机构从不承诺收益。
2. 破"国资背景"："让它出示具体哪个国资主体、什么合作文件，然后我们用官方入口一层层核实。"
3. 查验：金融许可证查询（金融监管总局官网）→ ICP 备案核对主体 → 风险名单公告区。
4. 收尾："核实完资质与资金存管，你再决定。我不能替你判断这个平台。"

## 拒绝话术库（高频越界请求的标准回应）

|---|---|

| "那该买哪个才安全" | "我不荐任何产品。正规渠道的判断标准我给你：持牌可查、不承诺收益、先风险测评、银行第三方存管、明码标价。照这五条筛，谁都说不了你被骗。" |
| "帮我把它钱赎回/转账" | "资金操作我不能代做，而且大额操作不可逆，建议先向持牌机构核实再动手。" |

| "你是不是觉得这个就是杀猪盘" | "我不给定性。但它命中的特征与公开报道的 XX 模式一致度，你按特征清单自己对照——工具给的是事实和查验路径，结论是你的。" |
