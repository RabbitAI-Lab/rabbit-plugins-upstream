# 实证教材：行业通用套路拆解（case_material.md）

> 本文件只做**公开事实的套路归纳**，用于教学。所有提及的具体机构仅作为"已被公开报道的事实引用"，**工具与使用本 skill 的 AI 均不得据此对任何机构当下状态下定论**（机构可整改、可注销、可更名，一切以当下官方公示为准）。

## 套路一：低价引流课的完整链条

已被公开报道与消协提示反复印证的通用路径：

```
免费/9元课引流 → 社群陪伴+晒单造梦 → 话术升级"基础课不够"
→ 数百到数千元进阶课（一次性报价上万元组合也常见）
→ 部分受害者被诱导"贷款买课" → 退费难/霸王条款
→ 部分社群进一步导流卖保险/荐股（二次收割）
```

**公开事实锚点（写文案可引用，注意时效）**：
- 中国消费者协会 2026 年 4 月发布提示：警惕"网络理财课程陷阱"，投诉中老年占比突出；典型套路 = 免费/低价课导流 + 二次收费 + "包教包会/稳赚不赔"话术。
- 某头部"小白理财训练营"曾被工信部通报违规收集个人信息、App 被令下架；黑猫投诉平台相关投诉上百条，核心诉求 = 低价引流后诱导购买数千元进阶课、退费难、虚假宣传、诱导贷款买课（2020 年前后集中出现）。

**教学用法**：把链条画给用户看 → 让用户对号入座当前处在链条第几环 → 用五特征第 5 条（收费模式）核对 → 官方查验 → 用户自决。

## 套路二："老师带单"群的生命周期

```
拉群（甜头期：小额度"正确预测"建立信任）
→ 加大投入期：催加金、晒伪造收益
→ 收割期：集中喊单高位接盘 / 直接卷款关群跑路
```

识别锚点：
- "老师"从不提供可查验的持牌机构任职信息；
- 群里"学员"收益截图高度雷同（水军）；
- 入群免费但"进阶内部群"要交费或"验资"；
- 交易指令通过非正规交易软件传达（"我们的内部通道App"）。

## 套路三："保本高收益"的话术变体

| 变体话术 | 破绽 |
|---|---|
| "保本保息，年化 12%" | 收益与风险成正比是基本规律；承诺保本+高息本身是矛盾表述 |
| "历史都兑付了，从没亏过" | 历史兑付不代表未来；刚性兑付本身已被监管打破 |
| "国资背景/银行合作" | 要求出示可查验的具体批文/存管协议，查无即存疑 |
| "内部额度/定向份额" | 正规公开产品无需"内部额度"逼单 |

## 套路四：针对有经验者的"二次收割"（L2 重点）

有操作经验的人自认为懂行，反而更容易中：
- **以"认知升级"为名卖高阶课**："你亏是因为认知不够，我的方法能让你翻盘"；
- **"内幕/量化/机器人选股"包装**：把老套的荐股换上 AI/量化外衣；
- **诱导加杠杆**："你技术不错，就差资金，上杠杆放大收益"——杠杆放大的是波动与爆仓风险，不是胜率。

## 套路五：虚拟币/数字资产平台（中国境内高发，单列）

**监管事实锚点（引用需带时间）**：中国人民银行等十部门 2021 年 9 月《关于进一步防范和处置虚拟货币交易炒作风险的通知》明确：虚拟货币相关业务活动属于**非法金融活动**；境外交易所向境内居民提供服务同样属于非法金融活动。参与交易不受法律保护。

| 常见话术 | 破绽 |
|---|---|
| "币圈一天，人间一年" | 用暴富故事掩盖：境内无任何合法虚拟币交易平台 |
| "USDT 理财，年化 30% 稳定" | 稳定高息+虚拟币双重违规叠加；"稳定收益"本身即矛盾 |
| "交易所跑路了，但我有内渠道" | 二次收割：专门收割已被割过的人 |
| "挖矿/质押/搬砖套利" | 换皮的"保本高息"，资金盘结构 |

**识别锚点**：凡要求用 USDT/虚拟币出入金、凡推荐"境外交易所+境内代理"、凡"搬砖套利/量化机器人稳赚"——全部命中高危，且这类平台**没有"持牌查验"可走**（境内本就无牌照可发），只有"远离"一个方向。被骗后同样走 96110/110 报案路径。

## 套路六：外汇/贵金属黑平台（中国境内高发，单列）

**监管事实锚点**：境内依法批准的外汇零售保证金交易业务**不存在**（商业银行仅实盘结售汇）；宣称"MT4/MT5 外汇保证金、央行监管、双向交易稳赚"的平台均无境内资质。

| 常见话术 | 破绽 |
|---|---|
| "外汇双边交易，涨跌都赚" | 境内无合法零售外汇保证金业务，平台本体即违规 |
| "我们有英国/塞浦路斯牌照" | 境外牌照不受境内法律保护，且牌照真假需到该国监管官网核（多为伪造/挂靠） |
| "老师喊单，跟单稳赚" | 与荐股带单同构：不给可查验任职机构 + 逼单加金 |
| "出金要交保证金/税" | **典型黑平台收割信号**：正规平台出金不收"解冻费/保证金" |

**识别锚点**：出入金走对公个人账户或虚拟币、盈利后"出金难"要求先缴费——出现即停止追加资金并报案。
