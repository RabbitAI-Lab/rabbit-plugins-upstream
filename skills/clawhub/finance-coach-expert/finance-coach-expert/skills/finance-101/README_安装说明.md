# finance-101（理财启蒙 101）安装说明

## 这是什么

8 章理财启蒙课程包：认知 → 清点 → 扫盲 → 配置 → 纪律 → 防割 → 体检 → AI 安全边界。
按章陪学，每章末有落地清单；带开学摸底三问定档（L1/L2）与按动机切入流程。

**立场**：纯教学——教认知+框架+纪律；
**不**荐股/荐基金/荐保险/给点位/承诺收益，不替用户给「是骗局」定性。

## 定位边界

| 它做什么 | 它不做什么 |
|---|---|
| 教理财认知框架与纪律（8 章课程） | 不荐股/荐基金/荐保险（一律引导持牌机构） |
| 给应急金、资产配置等通用原则 | 不给买卖点位、不预测行情、不承诺收益 |
| 教「防割」识别套路（第 6 章） | 不替用户给「是骗局」最终定性 |
| 教怎么安全地用 AI 问理财问题 | 不处理具体账户操作 |

## 复核方式

本技能为纯 Markdown 知识课程包，无脚本命令。内容结论的复验方式：
- 课程原则类结论（应急金 3-6 个月、股债配比等）在 `references/ch04_allocation.md`、`ch05_discipline.md` 内均标注了通用出处口径，可自行对照央行/交易所公开投教材料核验。
- 防割特征清单（第 6 章）逐条对应监管公开风险提示用语，可对照证监会投资者教育基地核验。

## 安装

把整个 `finance-101/` 文件夹复制到 Agent 平台的技能目录（如 `~/.workbuddy/skills/`），
或在平台上按「上传 skill 包」的标准流程导入 `finance-101-<版本>.zip`。

## 依赖

- 纯 Markdown 课程内容，无任何脚本依赖，零环境要求。

## 触发方式

对 Agent 说：
- 「想学理财，从头开始」
- 「应急金到底留多少」（问题速查直达第 4 章）

## 回答样例（真实交互节选）

> 用户：老师说现在不买就涨不回去了，我该信吗？
>
> 技能：这正好是第 5 章「纪律」和第 6 章「防割」要处理的问题。先说结论：**任何「再不买就晚了」的催单话术，本身就是风险信号**——正规投资建议不需要制造紧迫感。三个自查问题：①这位「老师」是否持牌？②收益承诺是否有书面依据？③他赚的是你赚钱的钱，还是你投入的钱？课程第 6 章给了完整的十问自查清单，我可以带你过一遍。
