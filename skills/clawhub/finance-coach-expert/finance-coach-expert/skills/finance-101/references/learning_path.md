# 学习路径图（learning_path.md）

## 两条推荐路线

### L1 路线（0 基础）：从第 1 章顺学

```
第1章 财商启蒙（误区清理）
  → 第2章 清点家底（算出净资产原点）
  → 第3章 投资品五类（认全工具）
  → 第4章 四桶+应急金（搭框架）
  → 第5章 定投与纪律（建立习惯）
  → 第6章 防骗防割（装上雷达）
  → 第7章 体检实战（落到自己数据）
  → 第8章 AI安全边界（终身受用）
```

预计节奏：每周 1-2 章，每章落地清单**必须做完**再进下一章——课程的价值 70% 在清单不在正文。

### L2 路线（有经验理论不扎实）：从第 5 章切入，回读 1-4 章

```
第5章 纪律自查（先照行为清单找出自己的"亏损引擎"）
  → 第2章 清点家底（校准从看清现状开始）
  → 第4章 四桶框架（对照自己的持仓结构）
  → 第6章 防二次收割（重点：识破"以认知升级为名卖课"）
  → 第7章 体检实战 → 第8章 AI安全边界
  （第1/3章可作速查，按需回读）
```

## 速查索引（带着问题来，直接跳）

| 你的问题 | 去哪章 |

| 我到底有多少钱 / 怎么算净资产 | 第 2 章 |

| 应急金留多少、放哪 | 第 4 章 |

## 学完的标志（对照总自测）

- [ ] 能不看书写出自己家的净资产和四桶占比
- [ ] 能说出应急金该覆盖几个月、放什么工具
- [ ] 能讲清"权益占比"是什么、自己的比例和原因
- [ ] 拿到任何理财营销，会先过五特征 + 查持牌
- [ ] 清楚哪些问题该问 AI、哪些必须找持牌机构
- [ ] 手机里有反诈 App，家人听过你的防割分享
