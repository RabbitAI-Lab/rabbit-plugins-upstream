# 第 7 章 · 资产体检实战

> 本章不讲：对体检结果的"操作指令"。
> 本章讲：怎么把第 2-5 章的框架落到你的真实数据上，产出一张"家庭资产体检卡"。

## 体检是什么、不是什么

- **是**：诊断书——只读你已有的存量数据做静态分析，输出"事实 + 中性区间 + 信息缺口"。
- **不是**：模拟盘（不接行情）、投顾（不给"下一步买什么"）、代操盘（不碰账户）。
- 一句话：**体检 = 看出问题，不是动刀。**

## 体检指标一览（全部是"事实 + 经验区间"，工具不判"偏高/偏低"）

| 指标 | 怎么算 | 经验区间（只作对照） |
|---|---|---|
| 净资产 | Σ资产 − Σ负债 | 无区间，看趋势 |
| 四桶占比 | 各桶 ÷ 总资产 | 无标准答案，与目标结构对照 |
| 应急金月数 | 灵活桶 ÷ 月刚性支出 | 3–6 个月 |
| 权益占比 | 进取桶 ÷（进取桶+稳健桶） | 20%–80%，随风险承受而异 |
| 集中度 | 单一类别占总额 | >50% 列为事实，自行复核 |

## 怎么做一次体检

1. **准备脱敏数据**：只需要金额+类别+四桶归属。不需要账号、证件号、平台名。全程本地，不上传任何平台。
2. **跑体检工具**：使用配套的资产体检计算器（asset-health-check），输入手填的 `assets.json`，输出 `health_card.md` 体检卡。
3. **对照自查**：体检卡每项都带"经验区间 + 请对照第 N 章自查"，逐项对照——**判断权在你**，工具只负责把事实算清楚。

## 数据可信度铁律

- 手填数据 = 唯一进结论的来源；
- 从截图/PDF 识别的数据 = 仅辅助预览，必须逐项人工核对后才可并入，核对前不进结论（错读比没读更危险）；
- 缺数据的项目，体检卡标"信息不全，仅出框架不出结论"——不编数。

## 体检之后的三种典型"发现"与对应章节

| 体检发现 | 对应自查章节 |
|---|---|
| 应急金 < 3 个月（事实对照，非评价） | 第 4 章：先填灵活桶 |
| 权益占比说不清为什么是这个数 | 第 4 章三个自问 + 第 5 章纪律 |
| 存在"保本+高收益"备注的持仓 | 第 6 章：五特征 + 官方查验 |
| 保障栏空白 | 第 3 章保障类 + 咨询持牌渠道 |

## ✅ 落地清单

1. 把第 2 章的资产负债表整理成体检工具的输入格式（类别/金额/桶）。
2. 跑一次体检，拿到你的体检卡。
3. 对体检卡"信息缺口"逐项用官方入口补数，两周内重跑一次。
4. 把"每季度体检一次"写进月历。


## 📝 自测三问

1. 体检"是/不是"什么？（诊断书 vs 哪三个东西）
2. 体检结论可以用哪些数据？截图识别的数据怎么处理？
3. 体检卡里"偏高/偏低"的判断为什么不存在？
