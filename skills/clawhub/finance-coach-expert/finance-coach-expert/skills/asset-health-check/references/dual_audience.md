# 双人群分层逻辑（dual_audience.md）

## 为什么要分层

割韭菜收割的多半是"觉得自己会、其实没理论、情绪化操作"的人（L2）；纯 0 基础的人（L1）还没进场。同一份体检卡，两群人需要的东西完全不同。

## 分档方法（进入时必问）

问用户：**"你操作过股票/基金吗？多久？主要靠什么决定买卖？"**

| 回答特征 | 档位 |
|---|---|
| 没操作过 / 钱全放银行 / 随手买过但说不清 | **L1** |
| 操作过一段时间 / 看净值做决定 / 听朋友消息买卖 / 被理财课带过 | **L2** |

拿不准就按 L1 处理（启蒙向更安全）。分档结果写进 `assets.json` 的 `experience` 字段。

## L1（0 基础）→ 启蒙侧重

**要解决的**：启蒙认知 + 清点家底 + 基础框架。

体检卡侧重提示（脚本内置）：
- 三件事确认：家底清点了吗？应急金建立了吗？基础保障（重疾/医疗）有概念了吗？
- 补框架顺序：第 1 章（财商启蒙）→ 第 2 章（清点家底）→ 第 3 章（投资品五类）→ 第 4 章（配置框架）
- 防骗优先：任何"稳赚 / 保本高息 / 9 元课带你致富"先存疑，对照第 6 章五特征自查

## L2（有经验但理论不扎实）→ 校准侧重（★反割韭菜主战场）

**要解决的**：用框架校准已有操作 + 识别自己的误区 + 防二次收割。

体检卡侧重提示（脚本内置）：
1. **操作特征自检**（用户自填，工具不判行情）：追涨杀跌？重仓单一？频繁换仓？有"保本高收益"矛盾认知？
2. **认知误区提示**（只点"缺框架"，不评判对错、不荐股）：如"权益占比 X% 但说不清为何持有 = 可能凭感觉而非框架，请对照第 4 章补逻辑"
3. **防二次收割**：若参加过付费理财课 / 有"老师带单"→ 引导用防割五特征 + 持牌查验（证监会官网可查持牌机构名录）自行验证。**不替用户判断某课程/平台是不是骗局**（红线）。
4. 重点防"觉得自己懂了可以加仓/上杠杆"——遇到此类想法，提示"杠杆放大的是波动不是胜率，请先补第 5 章定投与纪律"。

## 共同红线（两档都一样）

- 只到"事实 + 中性区间 + 缺口 + 该去哪查"层。
- 不出现"该买/该卖/偏高/偏低/是骗局"判断。
- 不荐股/荐基/荐险，不给点位，不承诺收益。
- 用户要"帮我决定" → 拒绝 + 给自查路径 + 引导持牌机构。
