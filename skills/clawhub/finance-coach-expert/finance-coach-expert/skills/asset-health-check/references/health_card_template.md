## 结构（五段固定，逐段说明）

注意：**卡片末尾的 `<!-- metrics: {...} -->` 机器可读行是模板红线的一部分**——`--compare` 靠它做零耦合解析，正文文案怎么改都不影响季度对比；regex 文案解析只是旧版卡片的兜底。

```
【家庭资产体检卡】

> 非投资建议，仅供自查；数据基于你手填，判断权在你，具体以持牌机构为准。
> 本工具只做静态存量分析：不接行情、不买卖、不代操作、不下"偏高/偏低"判断。
> 覆盖口径：本卡仅统计本次录入的项目；未录入的资产（如房产、公积金）不计入——缺项会让净资产与负债率失真。

## 一、家底全景（事实）
- 总资产 / 总负债 / 净资产（各带「手填(可信)」标签）
### 四桶占比
- 灵活取用 __% / 稳健 __% / 进取 __% / 保障 __%

## 二、中性对照（只给事实与经验区间，不替你下结论）
- 应急金：现状约 N 个月（经验区间 3–6 个月）→ 请对照第 4 章自查
- 权益占比：现状 X%（你自填风险承受=…；该类型常见经验区间 …%–…%）→ 请对照第 4 章自查
- 集中度事实：「某类」占可信资产 N%（单类占比高建议自行复核分散，工具不点名换哪只）
- 保障：名下已持有保险 N 项（…；未提及的常见险种会列出）。是否覆盖重疾/医疗请对照第 3 章自查，工具不荐险种
> 注：以上均为"事实 + 经验区间"，工具不判"偏高/偏低"，判断权在你。
```

## 逐段红线（改版时不可破坏）

| 段 | 红线 |
|---|---|
| 抬头 | 「非投资建议」免责 + 覆盖口径声明必须保留在最顶部 |
| 一 | 每个数字必须带可信度标签；缺数据写"信息不全，仅出框架不出结论"，不编造 |
| 二 | 只报"现状值 + 经验区间"，**禁止出现"偏高/偏低/不足/超标"等判断词**；每条带"请对照第 N 章自查" |
| 三 | 官方入口表五行固定，不得替换成商业渠道 |
| 待核对清单 | AI 识别项必须隔离在此，混入结论即为事故 |
| 四 | 只许方法层动词（自查/补数据/对照章节），禁止指令层动词（买入/卖出/调整/赎回） |
| 五 | L2 侧重也不给标的，只到"认知缺口 + 自查"层 |

## 经验区间速查（脚本内置）

| 指标 | 中性区间 | 说明 |
|---|---|---|
| 应急金 | 3–6 个月生活费 | 全人群通用 |
| 权益占比 | 20%–80%（全人群）；保守 10–40% / 平衡 30–70% / 进取 50–90% | 随 `risk_tolerance` 切换，只对照不判断 |
| 集中度 | 单类 >50% 列为事实 | 不点名换哪只 |

## 合规自扫（脚本内置 `_COMPLIANCE_BLOCKLIST`）

输出渲染完成后自动扫描，普通黑名单词（荐股词/点位词/收益承诺/定性）在"拒绝/自查引导"语境行内豁免；**强判断词（偏高/偏低/不足/该退保类指令）只认词前紧邻否定句式（6 字窗口）**，不随行豁免——像「应急金不足（经验区间 3-6）」这种混在事实行里的真判断会被拦下。命中 → stderr 告警，`--output` 模式下退出码 1。**看到告警必须人工复核后再交付**。
