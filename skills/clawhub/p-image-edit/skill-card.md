## Description:

Guides agents in editing existing photos with Pruna, including background changes, outfit edits, and reference-guided compositions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[pruna-ai](https://clawhub.ai/user/pruna-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to direct precise edits to existing photos, preserving requested details while changing backgrounds, outfits, or elements sourced from reference images.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Photos and edit prompts are sent to Pruna's cloud API.

Mitigation: Use only images and prompts you have permission to share; avoid sensitive personal, biometric, confidential, or proprietary material unless you accept Pruna's data handling terms.

Risk: Companion-skill installation examples use unpinned npx commands.

Mitigation: Install companion skills from a trusted source and pin reviewed versions instead of running unpinned examples blindly.
