# NETWORKMAP() 公开关系研究

- Skill：`zayn-networkmap`
- 用途：用可追溯公开证据研究行业、展会、协会、活动与公司之间的关系。
- 模式：行业与展会、行业与协会、公司与近期活动。
- 输入：行业边界、地区、时间、目标实体、角色要求、结果数量和已有资料。
- 最低条件：主体可识别，行业范围明确，地区与时间足以限定研究。
- 证据：优先官方目录、议程和公告；搜索摘要只作待核验线索。
- 输出：简洁结论、证据表、角色、来源等级、名单完整度、限制与未确认事项。
- 边界：不把参展、会员或同场关系直接判断为客户价值、采购意愿或销售优先级。
- 协作：复杂业务任务可由 `zayn-route` 前置确认范围；关系结果可交客户筛选或开发策略继续判断。
- 版本：v1.0.0
