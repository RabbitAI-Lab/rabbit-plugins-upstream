# Investment Decision Framework.md — 投资判断层（V3.3）

> 这是「投资判断层」。SKILL.md 定义了"怎么研究"，本文件定义"研究完怎么给结论"。
> 解决的核心问题：文章质量高，但普通投资者读完不知道"这家公司什么级别、现在该干嘛"。
> 表达规则（V3.3）：文章正文不直呼"散户"，用"很多人/普通投资者/我们/你"或第二人称；本文件作为内部方法论可用画像描述。
> V3.3 更新（用户 2026-07-18 校准）：分级改用「产业价值梯队」语言，避免读者误读为买卖评级；新增未来增长曲线、估值三问、市场分歧点、统一退出条件；正文不直呼散户。

---

## 一、产业价值梯队（替代 S/A/B/C 评级语言）

> **为什么改**：S/A/B/C 容易被读成"S=买入 / C=卖出"，但本 Agent 不是评级机构，不给买卖指令。改用「产业价值梯队」描述公司在产业链利润兑现上的位置，回到价值投资语言。
> 内部仍可用 S/A/B/C 做速记，**对外文章一律用梯队表达**。

每篇文章、每个核心标的，最终必须落到一个梯队。

```
第一梯队（内部记 S）：利润已经兑现
   产业核心环节 + 竞争优势明显 + 盈利真实落地
   → 结论：长期看好，价格纪律下研究布局

第二梯队（内部记 A）：产业位置优秀，等待盈利验证
   卡位最硬 / 稀缺性最强，但利润尚未兑现
   → 结论：长期看好但盯业绩拐点，小仓位潜伏

第三梯队（内部记 B）：需求存在，但商业模式未验证
   产业逻辑成立，公司竞争力或盈利质量待观察
   → 结论：观察，不急下注

淘汰观察（内部记 C）：逻辑弱于估值
   主题炒作 / 净利下滑却高估 / 持续亏损
   → 结论：不参与
```

**判定顺序**：先看产业位置（是不是利润池），再看壁垒与盈利兑现，最后看价格。任一层掉档即降一梯队。

## 二、定性评级（不显示数字分）

不使用 87分 / 82分 这类量化分，读者会误读为精准。改用定性 + 星标。

### 五维定性

| 维度 | 评级 | 含义 |
|------|------|------|
| 产业位置 | 强 / 中 / 弱 | 是否处于利润最集中环节 |
| 竞争壁垒 | 强 / 中 / 弱 | 技术/客户/规模壁垒是否稳固 |
| 盈利兑现 | 兑现 / 未兑现 / 假增长 | 利润是否真实落地（警惕非经常性损益） |
| 成长空间 | 大 / 中 / 小 | 国产替代/份额/新客户空间（配合未来增长曲线） |
| 估值合理性 | 低估 / 合理 / 高估 | 用估值三问判断，不单拍 PE |

### 汇总为投资质量

```
投资质量：★★★★★
（五星= S，四星= A，三星= B，二星及以下= C）
```

星标只反映"产业+公司"质量，**不含价格状态**。价格单独用三状态表达（见下）。

## 三、价值投资价格纪律（替代"买入价/止损价/目标价"）

> V3.3 重命名：原"价格三状态"→"价值投资价格纪律"。避免"买点/建仓"交易语言，用研究/持有/等待。
> V3.4 微调（2026-07-26）：补「周期位锚定 + 拐点跟踪信号 + 安全边际语言」三处，见第三节、第七节、第八节。

不输出交易型价格。用三种状态告诉读者"现在处在什么位置"。

```
低估：产业逻辑成立 + 市场预期不足
   → 可以研究布局

合理：公司优秀 + 价格匹配
   → 长期持有

高估：产业正确 + 市场已提前交易
   → 等待业绩消化，不追高
```

禁用词：买入 / 建仓 / 买点 / 止损价 / 目标价。
允许词：长期看好 / 等待合理价格 / 价值未兑现 / 暂不参与 / 逻辑破坏退出。
> 价格三状态本质就是安全边际：低估区买的是容错率，高估区是安全边际耗尽。

### 估值判断三问（V3.3 新增，替代单纯 PE 对比）
半导体成长公司 PE 经常失真（亏损期 PE 为负、高速增长期 PE 虚高）。估值不直接拍 PE 高低，固定问三个问题：
```
1. 市场已经交易了多少未来？（当前价格隐含多少预期）
2. 未来利润增长能否覆盖当前估值？（成长能不能消化估值）
3. 如果未来两年业绩兑现，现在价格是否合理？（用未来回看现在）
```
PE / 历史分位仍可作参考数据，但结论语言用三问而非单一倍数。

### 价值投资退出条件（V3.3 新增，统一模板）
所有文章统一。退出不靠价格跌幅，靠逻辑：
```
退出条件：
1. 产业逻辑变化（技术路线变更 / 需求证伪）
2. 竞争优势下降（大客户流失 / 被重新渗透）
3. 盈利兑现不及预期（持续证伪盈利拐点）
4. 估值远超长期成长能力（成长无法覆盖估值且恶化）
```
出现即退出，不摊平。
跟踪信号（每篇按链填 2-3 条，证据出现即重新评估，不等逻辑破坏才动）：技术路线被绕开 / 核心客户流失 / 大厂 Capex 下修。

## 三乙、未来增长曲线（V3.3 新增，个股必答）

> 价值投资买的是未来不是过去。每个核心个股必须回答："三年后为什么它还能增长？"

固定用增长曲线表达（至少第一 + 第二曲线）：
```
第一增长曲线：当前主业的国产替代空间
第二增长曲线：新产品 / 新客户 / 价值量迁移
第三增长曲线：更远的场景（如有）
```
例（鼎龙）：CMP抛光垫 → CMP抛光液 → 先进封装材料。让读者知道买的是未来。

## 三丙、市场分歧点（V3.3 新增，雪球最有价值部分）

> "为什么市场可能错"是产业研究的深度所在。每个核心个股给一组对照：
```
市场担心：（市场主流的负面共识）
我的判断：（为什么这个担心可能错 / 真正的变量在哪）
```
例：
- 鼎龙。市场担心：材料国产替代空间是否已兑现？我的判断：真空间不是国产份额提升，而是从低端材料向高价值材料迁移。
- 华大。市场担心：EDA赚钱太慢。我的判断：EDA不是普通软件，是国产芯片设计基础设施，盈利慢但壁垒最高。

## 四、与文章模板的衔接

框架 A（产业链深度）结尾必须包含：
1. 利润池地图（需求→利润→流向哪家公司）
2. 产业价值梯队（对外梯队语言，内部记 S/A/B/C）
3. 给投资者的三个提醒（正文不直呼散户）

框架 B（个股）结尾必须包含：
1. 五维定性评级表
2. 未来增长曲线（三年后为什么还能长）
3. 市场分歧点（市场担心 vs 我的判断）
4. 投资质量（产业价值梯队）
5. 价值投资价格纪律 + 退出条件
6. 为什么不是别人（竞争格局比较）
