# 热点追踪器 (Hot Topic Tracker)

> 多平台热点榜单自动抓取 + AI 智能分析 + 选题库一键生成

## 功能特性

- **多平台热点抓取**：抖音 / 小红书 / 知乎 / B站 / 微博 / 微信，一站式覆盖
- **AI 智能分析**：热度排序、标签聚类、趋势预测、竞品拆解，全部由模型驱动
- **选题库自动生成**：每个选题含标题变体、内容角度、平台适配脚本、热度预测
- **腾讯文档直存**：一键生成结构化文档（封面 + 总览表 + 详情 + 趋势预测）
- **定时自动化**：配合 qclaw-cron-skill 实现每日早报 / 实时监控 / 周报自动生成

## 定时自动化

配合 `qclaw-cron-skill`（请先读取该 Skill 了解最新格式）：

| 方案 | 触发时间 | 说明 |
|------|---------|------|
| 每日早报 | 每天 9:00 | 抓取热点 + 生成选题，保存腾讯文档 |
| 实时监控 | 每小时 | 检测热度增长 > 50% 则推送预警 |
| 周报生成 | 每周日 20:00 | 汇总本周热点 + TOP10 + 趋势预测 |

> ⚠️ 每小时执行成本较高，建议仅在工作时段启用（如 8:00–22:00）

## 常见问题

**Q: 抓取不到数据怎么办？**

A: 依次排查：
1. 确认网络正常，尝试更换搜索关键词
2. 某些平台需要登录态，请改用 `xbrowser profile=user` 抓取
3. 平台页面结构可能变化，请确认 URL 是否正确

**Q: 选题数量太少或不符合预期？**

A: 明确指定领域和数量，例如："生成20个科技数码类选题"

**Q: 如何避免定时任务重复执行？**

A: 使用 `qclaw-cron-skill` 创建 `isolated` sessionTarget 的任务，每次独立执行，避免历史干扰

**Q: AI 分析结果不准确？**

A: 当前 session 模型由 model route 自动选择最优模型，无需手动指定。如需更强推理能力，可在更高级别模型下重试。
