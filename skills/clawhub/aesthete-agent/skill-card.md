## Description:

Helps agents create and evaluate frontend color palettes, then export checked color tokens and visual previews.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers and designers use it to choose color systems for web interfaces, charts, and visual assets, then check contrast, color-blind legibility, and palette quality before exporting tokens or previews.
