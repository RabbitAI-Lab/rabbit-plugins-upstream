## Description:

Helps designers and developers choose, validate, and apply color palettes for interfaces and visual content using contrast checks, color-vision simulations, and visual review.

This skill is ready for commercial/non-commercial use.

## Publisher:

[docsor1212](https://clawhub.ai/user/docsor1212)

### License/Terms of Use:

MIT-0

## Use Case:

Designers and frontend developers use this skill to develop and compare color palettes for UI pages, slides, charts, posters, and other visual assets, then review legibility and visual fit before delivery.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Accepted or rejected palette choices can persist in local preference and palette files.

Mitigation: Review and back up local preferences before using feedback or house-palette workflows.

Risk: Optional page-render reviews can include page URLs and small samples of text and color evidence in local output.

Mitigation: Run render reviews only on pages whose URLs and sampled content you are comfortable including in local review output.
