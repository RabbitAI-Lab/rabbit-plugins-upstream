## Description:

Helps designers and developers create and validate color palettes for frontend interfaces and visual assets using contrast checks, color-blind simulations, and visual review.

This skill is ready for commercial/non-commercial use.

## Publisher:

[docsor1212](https://clawhub.ai/user/docsor1212)

### License/Terms of Use:

MIT-0

## Use Case:

Designers and developers use this skill to choose, test, and export accessible color schemes for websites, charts, slides, and other visual deliverables.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The bundled harvesting guide describes bypassing Cloudflare to scrape a source site, despite the skill's offline positioning.

Mitigation: Do not follow the harvesting guide without permission to collect from the site; review it before use in sensitive environments.

Risk: Unpinned installation can retrieve a different release than the one reviewed.

Mitigation: Use a pinned install or verify the release before installation.

Risk: Accepted palette choices may change local skill data files.

Mitigation: Review local data changes before accepting or sharing the updated skill.
