## Known Risks and Mitigations: <br>
Risk: Generated guidance or code templates can still introduce incorrect architecture, stale API usage, or regressions if applied without review. <br>
Mitigation: Review the proposed changes against the skill references, run the project's type checks and tests, and verify version-sensitive Effector ecosystem APIs against primary documentation. <br>
Risk: Full audit mode may produce inferred findings from static data-flow reasoning rather than directly observed runtime failures. <br>
Mitigation: Require file/path evidence, validate each inferred chain in the target codebase, and confirm fixes with focused acceptance criteria. <br>
