# 报告下载、阅读与验真

## 下载

1. 先 status 确认订单已完成或服务端出现报告字段。
2. 调用 report-download-url 仅作本站页面的辅助地址；首选 /pwf/check?orderNo=... 的下载/预览按钮。
3. 只输出 HTTPS 下载地址；供应商 HTTP 临时地址、签名 query、对象存储 key 不输出。

## 阅读

报告可能出现总体相似、相似片段、来源文献、参考文献/自引识别或 AIGC 风险。只引用报告当期真实字段，不把相似率等同抄袭比例，不自创原创率，不把 AIGC 报告当文本查重。

## 验真字段

万方官方验真常见输入是：

- 分段报告编号：从报告首页左上或报告编号区域逐段复制；
- 文献名称/批次名称：按报告首页题名/批次原样填写；
- 验证码：用户本人识读后填写。

先进入 https://vpcs.cqccjy.cn/pwp/verify 选择万方报告验真；统一入口不可访问时，再进入 https://truth.wanfangdata.com.cn/。验真通过只说明官方找到对应记录，还要核对题名、作者、检测类型和时间。

## 失败排查

检查编号四段是否缺失、题名首尾空格、全角半角、0/O、1/I 等混淆。连续失败后停止试错，不猜验证码、不绕过验证码、不把截图中的示例编号当作真实编号。
