# aurum-brain

> Gunakan saat mengaktifkan lapisan OS agent adaptif: pikiran terbuka terhadap skill, perilaku berbasis data, penalaran bertahap, koreksi-diri, anti-pengulangan, dan eksekusi tugas yang agentik.

## Ikhtisar

Aurum Brain adalah lapisan sistem operasi (OS) agent adaptif: ia menjaga agent tetap berpikiran terbuka terhadap skill, berbasis data, bernalar bertahap, berkoreksi sendiri, dan menghindari pengulangan. Ia diaktifkan untuk meningkatkan kualitas dan keandalan setiap respons yang dihasilkan agent.

## Penggunaan

Gunakan ketika kondisi pada deskripsi terpenuhi. Baca SKILL.md untuk panduan lengkap.
