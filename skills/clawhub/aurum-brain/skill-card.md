## Description:

Aurum Brain activates an adaptive agent operating layer for open-minded skill use, data-first behavior, stepwise reasoning, self-correction, anti-repetition, and agentic task execution.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and external users use this skill to guide an agent toward structured planning, evidence-first reasoning, self-correction, and clearer non-repetitive responses during general tasks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation may influence many agent decisions and responses.

Mitigation: Use the skill for explicit planning or self-review workflows instead of enabling it automatically for every task.

Risk: The optional local logging helper can retain sensitive task details.

Mitigation: Do not log credentials, private incident details, or sensitive prompts unless the log path and retention are controlled.
