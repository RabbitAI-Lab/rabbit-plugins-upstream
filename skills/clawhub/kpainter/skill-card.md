## Description: <br>
KPainter helps agents turn PDFs, PPTs, web links, and other documents into structured explainer videos, narrated lessons, slides, images, videos, and interactive learning experiences. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External users, educators, creators, and developers use this skill to create and refine KPainter media outputs from topics, documents, URLs, and prompts while preserving product routing rules and setup guidance. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: User-provided documents, URLs, prompts, and generated content may be sent to KPainter and associated with the user's KPainter API key. <br>
Mitigation: Use an API key controlled by the user, avoid submitting sensitive material unless the service is trusted for that data, and follow the documented KPainter connection flow. <br>
Risk: Incorrect product routing or unsupported parameters can create failed or misleading generation requests. <br>
Mitigation: Read the current KPainter catalog before choosing type-specific parameters, ask only for missing information, and confirm before switching product types. <br>
