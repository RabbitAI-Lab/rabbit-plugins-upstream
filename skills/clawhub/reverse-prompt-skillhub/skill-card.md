## Description:

Reverse Prompt Skillhub helps agents analyze supplied creative outputs and draft platform-specific generation prompts with confidence notes.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and creators use this skill to reverse-engineer prompt strategies from user-supplied images, videos, audio, text, 3D materials, UI screenshots, and code requests. It supports prompt drafting, platform syntax adaptation, confidence labeling, and iterative refinement for common generative AI platforms.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated prompts may create copyright, likeness, trademark, or platform-policy issues if used directly with restricted reference material.

Mitigation: Review each prompt for copyright, likeness, trademark, and platform-policy compliance before using it, and replace restricted references with permitted material.

Risk: Reverse-engineered prompts are estimates and may mislead users if treated as exact recovery of the original prompt.

Mitigation: Keep confidence labels with the analysis and iterate against user-provided generation results before relying on the output.
