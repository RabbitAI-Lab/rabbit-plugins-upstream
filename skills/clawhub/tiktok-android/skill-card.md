External users and social media operators use this skill to configure and run Android-device TikTok engagement sessions that search topics, inspect videos, and post static or AI-generated comments from a logged-in account. <br>

## Known Risks and Mitigations: <br>
Risk: ADB control can operate a logged-in Android device and post public TikTok comments on the user's behalf. <br>
Mitigation: Install only for deliberate TikTok automation use, run small reviewed sessions, and require explicit approval before campaigns that post comments. <br>
Risk: Campaign-scale commenting can create account suspension, reputation, or platform-policy risk. <br>
Mitigation: Avoid unattended cron or large campaigns unless the user accepts those risks; start with low-volume sessions and monitor account health. <br>
Risk: AI comment mode can send TikTok screenshots to the selected AI provider and requires local API keys. <br>
Mitigation: Enable AI mode only when screenshot sharing is acceptable, keep API keys in local environment files, and delete local screenshots or configuration when no longer needed. <br>
