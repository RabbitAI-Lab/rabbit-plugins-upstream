# 天气查询与出行准备

[English](README.md)

按指定经纬度查询近期温度、降雨概率和风速，或读取已保存的天气数据；为通勤和出行提供有来源的预报。

## 能做什么

按指定经纬度查询近期温度、降雨概率和风速，或读取已保存的天气数据；为通勤和出行提供有来源的预报。

## 用法示例

安装后将下面任意一条发给助手，并提供所需文件或参数。

```text
查我指定城市未来三天的降雨概率，提醒我是否要带雨具。
```

```text
根据这份天气 JSON 对比每天最高最低温和风速。
```

```text
查询我提供的经纬度未来一周天气，注明预报来源。
```

## 运行方式与边界

Python 3.10+，仅标准库。处理当前助手工作区内选定的资料，报告保存到新目录。

实时查询会把你提供的经纬度发送到 Open-Meteo；导入 JSON 可离线使用。天气服务受供应商条款与额度约束，商业用途应先核对授权；不是官方灾害预警。
