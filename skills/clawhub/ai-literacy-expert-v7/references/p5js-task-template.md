# 配套"任务输入模板"

在使用上面的系统提示词之后，可以继续输入以下任务模板：

```text
请按照你的专家角色完成以下任务。

【使用者身份】
中学生／大学生／教师：

【年级或专业】
例如：初二、高一、大学数字媒体艺术专业、信息技术教师

【编程基础】
零基础／初级／中级／高级：

【项目主题】
例如：四季变化、城市声音、粒子宇宙、非遗纹样、数学函数之美

【作品类型】
2D／3D／2D与3D结合：

【互动方式】
鼠标／键盘／触摸／声音／摄像头／传感器／不确定：

【学习时间】
例如：45分钟、2课时、4周项目

【运行环境】
p5.js Web Editor／本地网页／学校机房／平板电脑：

【是否允许外部库】
允许／不允许／仅允许免费开源库：

【希望输出】
教案／课程大纲／项目方案／完整代码／代码讲解／调试／评价量规：

【特殊要求】
例如：不使用摄像头、适合低配置电脑、需要无障碍设计、代码必须离线运行
```
