# 模块 B：工具操作（参考）

> 模块 B 让学生真正"上手" AI 协作工具。按专业方向二选一：**计算机/软件工程方向选 B1（TRAE IDE）**，**其他专业选 B2（TRAE Work·SOLO）**。两者均可独立完成后续所有教学环节。

## B1 · TRAE IDE 操作（计算机 / 软件工程方向）

- **定位**：掌握 IDE 端的 AI 协作流程（代码补全、Chat、Agent、多文件编辑等）。
- **适用对象**：计算机、软件工程等需要写代码的专业。
- **官方知识库（权威、持续更新）**：https://lcnziv86vkx6.feishu.cn/wiki/GEEnwlfTQi8qZrkFsPycfkUKnul
- **教学建议**：以"需求讨论 → Agent 生成 → 预览验证 → 迭代"为主线，结合模块 C 的 Prompt/拆解/验证方法论实练；强调使用 `.trae/rules/` 沉淀项目规则（回扣 C5）。

## B2 · TRAE Work 操作（全专业通用，SOLO）

> SOLO 是面向全专业、无需编程基础的 AI 协作工作台（Web / 客户端 / 移动端）。本单元目标是让学生掌握 TRAE Work 的基础操作与核心功能，为模块 C（方法论）和模块 D（实练）打底。

### 0 · 新手入门篇
- What is TRAE Work｜全面认识
- 如何安装 TRAE Work
- 认识 TRAE Work｜Work 模式
- 认识 TRAE Work｜Code 模式
- 认识 TRAE Work｜Design 模式
- 认识 TRAE Work 移动端
- 快速完成你的第一个任务
- **配套素材**：`B2. TRAE Work 操作 新手入门篇.pdf` / `B2. TRAE Work 操作 新手入门篇.pptx`

### 核心功能指南
- TRAE Work 基础功能｜模型（选择/切换不同大模型）
- TRAE Work 基础功能｜自动化（When→Do→Output 触发规则，回扣 C5 第 4 章）
- TRAE Work 基础功能｜语音功能
- TRAE Work 基础功能｜技能（Skill，回扣 C5 第 3 章沉淀阶梯）
- TRAE Work 基础功能｜MCP 工具（连接外部能力，回扣 A2/A1 的 Agent 外部能力）
- TRAE Work 基础功能｜规则与记忆（Rules & Memory，回扣 C5 第 1 级 Rules）
- 更多个性化配置
- **配套素材**：`B2. TRAE Work 操作核心功能指南.pdf` / `B2. TRAE Work 操作核心功能指南.pptx`

### 教学衔接
- B2 的"技能/Skill、规则与记忆/Rules、MCP"正是模块 C5 沉淀阶梯的"产品落点"——讲 B2 时可预告 C5。
- B2 的 Work/Code/Design 三种模式对应不同任务形态：Work=通用对话协作，Code=写代码，Design=做设计；让学生知道"什么任务用哪个模式"。

## 工具模块备课提示
- 工具迭代极快，优先引用官方知识库/最新版 PPT，不要凭记忆写操作步骤。
- 非计算机专业一律走 B2（SOLO），避免被编程门槛劝退；计算机专业走 B1 但也可了解 SOLO。
- 工具操作要"即用即教"：在模块 C 的方法论讲解过程中，同步演示对应的 TRAE/SOLO 功能，而非孤立讲工具。
