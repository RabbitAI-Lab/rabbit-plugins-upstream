## Description:

Produce an English CI Tools digest for a complete calendar month, with release evidence, migration notes and clearly separated open work. Use for monthly reporting or an explicitly requested month.

This skill is ready for commercial/non-commercial use.

## Publisher:

[xrowgmbh](https://clawhub.ai/user/xrowgmbh)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and CI Tools maintainers use the skill to prepare an English digest for a complete UTC calendar month, including release and merged change evidence, migration notes, and separately dated open work. It supports submitting that report through a merge request for review.

Global
