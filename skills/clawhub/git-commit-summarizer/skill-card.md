## Description:

Generate structured summaries of recent git commit activity for commit summaries, changelog drafts, standup notes, and repository change reviews over a time range.

This skill is ready for commercial/non-commercial use.

## Publisher:

[terrycarter1985](https://clawhub.ai/user/terrycarter1985)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to summarize local git history for changelogs, release notes, standup updates, and reviews of repository activity filtered by date range, author, or output format.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Summaries can include commit messages, author names, and dates from the selected local repository.

Mitigation: Review generated text or JSON before sharing it externally, and choose the repository path intentionally.
