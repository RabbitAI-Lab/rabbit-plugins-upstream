# 公差与符号参考表（按需加载）

处理公差套用、符号识别、特性分类时加载本文件。不要在对话中复述整表，直接查用。

## 1. 最终公差优先级（每个尺寸必须落到一条）

1. 显式公差优先 → 用显式，来源"图纸标注"。
2. 配合代号/螺纹/齿轮专用标准 → 查专用表，来源"配合公差"/"螺纹标准"。
3. 未注尺寸 → 查一般公差 profile，来源"一般公差"。
4. 无 profile 或类型无法判断 → 标记"待确认"，来源"未声明"。

## 5. ISO 2768-1

与 GB/T 1804 等效，等级对应：f→f, m→m, c→c, v→v。

## 6. 边界处理

- 尺寸分段开闭区间必须正确。
- 角度公差查"短边长度"，不是角度值本身。
- 圆角、倒角是否适用一般公差需确认公司标准，默认标记"待确认"。
- 配合代号（H7、g6）查专用表，**不套一般公差**。
- 螺纹（M10-6g）查螺纹标准，**不套一般公差**。
- **英制图纸禁止套用 GB/T 1804 / ISO 2768**；改取原图 "UNLESS OTHERWISE SPECIFIED" 栏。

## 7. 尺寸公差文本模式库

| 模式 | 示例 | 提取字段 |
|------|------|----------|
| 基本尺寸 | `20` | 公称值=20 |
| 对称公差 | `20±0.1` | 公称=20，上=+0.1，下=-0.1 |
| 极限公差 | `20+0.2/0` | 公称=20，上=+0.2，下=0 |
| 上下偏差 | `20 +0.2 -0.1` | 公称=20，上=+0.2，下=-0.1 |
| 配合代号 | `⌀20H7` | 公称=20，类型=孔径，配合=H7 |
| 螺纹 | `M10-6g` | 螺纹=M10，公差带=6g |
| 直径 | `⌀20`、`∅20`、`D20` | 公称=20，类型=直径 |
| 半径 | `R5` | 公称=5，类型=半径 |
| 球径 | `S⌀20`、`SR5` | 类型=球径/球半径 |

## 8. GD&T 符号与修饰符

**符号**：⏤直线度、⏥平面度、○圆度、⌭圆柱度、⌒线轮廓度、⌓面轮廓度、∥平行度、⊥垂直度、∠倾斜度、⌖位置度、◎同轴度、⌯对称度、↗圆跳动、⌰全跳动。

## 11. 符号与一般公差声明的位置与检测

**一般公差声明常出现在 4 处**，逐处检查：
1. 标题栏：`未注公差按 GB/T 1804-m`
2. 技术要求：`1. 未注公差尺寸的极限偏差按 GB/T 1804-2000 m级；2. 未注形位公差按 GB/T 1184-K`
3. 明细栏备注：`未注公差按 ISO 2768-mK`
4. 修订栏/角落注释：`一般公差按公司标准 Q/XXX-2023`

**解析字段**：标准号（GB/T 1804、GB/T 1184、ISO 2768、ASME Y14.5、公司标准）、等级（f/m/c/v、H/K/L）、适用范围（线性、角度、形位）。

**特性符号声明常出现在 4 处**：
1. 技术要求：`标注★的尺寸为关键特性`
2. 尺寸旁符号标注：★、△、∇、◇、▲、◆
3. 独立特性清单（角落或单独页）
4. 明细栏备注：`关键特性见控制计划 CP-XXX`

**符号检测难点与策略**：符号小（3-5mm）、位置多变、可能被尺寸线遮挡、易与图形混淆。
策略＝尺寸文本周边 2 倍文本高度范围搜索 + 模板匹配 + 视觉模型双验证（需 600 DPI 裁剪）。
**技术要求声明的映射优先于视觉检测**；两者冲突时以声明为准并在输出中告警。
