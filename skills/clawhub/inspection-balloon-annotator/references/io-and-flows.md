# 流程细节与输出结构（按需加载）

生成 Excel / 标注图、处理多页或批量图纸、遇到复杂场景时加载本文件。日常对话不要复述本文件内容。

## 1. 分层读图模型（L0-L5，逻辑分层；执行按 SKILL.md 的三批次合并）

```
L0 文档级  →  几页？什么图集？每页角色？全局唯一标识？
L1 单页级  →  标题栏、图幅、比例、投影法、单位、一般公差声明、特性符号映射
L2 区域级  →  分区格 + 功能区域（标题栏/主视图/剖视/明细栏/技术要求/修订栏）
L3 视图级  →  视图类型、边界、独立比例、视图名
L4 尺寸簇级 →  尺寸链、基线尺寸、同特征尺寸、按特性分类分组
L5 单尺寸级 →  公称值、显式公差、特性分类、符号、控制计划编号
决策层     →  气泡样式、字号、位置、引线、局部放大
输出层     →  标注图 + 检验表
```

上层决定下层策略：L1 知比例，L2 知区域，L3 知视图，L4 知密度，L5 才知怎么标。
密集尺寸先用 L4 分簇，否则 L5 会漏检或混淆。

### L0 文档级分析
1. 读取总页数。
2. **判断图集归属**：对比各页标题栏图号前缀。相同前缀＝同一图集（统一编号）；不同前缀＝不同图集（分开编号）。
3. **判断每页角色**：
   - `assembly`（总装图）：多个零件序号引出，有明细栏
   - `part`（零件图）：单一零件，尺寸完整
   - `bom_only`（明细页）：只有明细表，无主视图
   - `tech_doc`（技术要求页）：只有文字说明
4. **提取全局唯一标识**（Excel 主键，必抓）：图号、物料号、图纸名称、版本、客户、项目、材料、表面处理、重量。
5. **检查版本一致性**：某页版本与其他页不同 → 标记冲突，不混用。

`document_profile.json` 示例：
```json
{
  "total_pages": 3,
  "drawing_set": "ABC-2024-001",
  "page_roles": {"1": "part", "2": "part", "3": "bom_only"},
  "identifiers": {
    "drawing_number": "ABC-2024-001",
    "material_number": "PN-12345",
    "name": "支架",
    "version": "Rev.B",
    "customer": "XX汽车",
    "project": "XX平台",
    "material": "Q235B",
    "surface_treatment": "镀锌",
    "weight": "1.2kg"
  },
  "version_conflicts": [],
  "numbering_scheme": "global_sequential_no_padding",
  "unit_system": "mm"
}
```

**多页编号规则**（气泡号 = 图纸气泡显示的数字，100% 一致）：
- 同一图集：全局连续，跨页不重置（第1页 1..n，第2页继续 n+1..m）
- 不同图号/不同零件：按页独立，每页从 `1` 开始
- 纯数字，禁止前导零（不得 `01`、`1-01`）
- 页码不进入气泡号（Excel 独立列「图纸页码」）
- BOM 页：不标气泡，只提 BOM

### L1 单页级分析
**L1.1 标题栏提取**：位于图幅右下角（ISO 7200 / GB/T 10609.1）。必提：图号、名称、版本、客户、项目、材料、表面处理、图幅（A0-A4）、比例（仅记录参考，**不用于尺寸换算**）、投影法、单位、设计/审核/批准、日期。

**L1.2 一般公差声明提取（必做）**：四个位置逐一检查（见 `references/tolerance-and-symbols.md` 第 11 节）。
`general_tolerance_profile.json` 示例：
```json
{
  "linear": {"standard": "GB/T 1804-2000", "grade": "m", "source": "技术要求第1条"},
  "angular": {"standard": "GB/T 1804-2000", "grade": "m", "source": "技术要求第1条"},
  "geometric": {"standard": "GB/T 1184-1996", "grade": "K", "source": "技术要求第2条"},
  "confidence": 0.95,
  "needs_user_input": false,
  "source_page": 1
}
```
强制：未找到声明 → `needs_user_input=true`，必须询问；禁止默认套用 GB/T 1804-m（除非用户配置了公司默认，且输出标记"假设使用公司默认"）；跨页冲突 → 标记冲突不擅选。

**L1.3 特性符号映射提取（必做）**：四个位置检查（同上参考文件），符号对照表同参考文件第 9 节。
`characteristic_map.json` 示例：
```json
{
  "symbol_map": {
    "★": {"category": "critical", "source": "技术要求第3条", "confidence": 0.98},
    "△": {"category": "significant", "source": "技术要求第3条", "confidence": 0.98}
  },
  "customer": "Default",
  "control_plan_ref": "CP-2024-001"
}
```

**L1.4 简短摘要**：填充模板，生成 3-5 行自然语言摘要，用于 Excel 汇总 Sheet 顶部与标注图首页。

**L1.5 单位制判定**：标题栏 `UNITS`、尺寸写法（`.005`、`1/2"`）、引用标准（ASME Y14.5 默认 inch）→ `unit_system`: mm / inch / mixed。
- 英制图：照原样提取，**不做换算**；标注图首页与图幅角落加醒目提示"英制图纸，未换算，检验前请手动转公制"；Excel「单位」列填 inch；一般公差取 "UNLESS OTHERWISE SPECIFIED" 栏，禁套 GB/T 1804；未注明则标"待确认"。
- 混排：逐条记单位，汇总 Sheet 加混排告警。
- 其余流程（气泡、编号、导表）不因单位制改变。

**L1.6 已有旧气泡检测与重编号**：检测到旧气泡 → 一律重新编号（按编号规则全局连续），不沿用旧号体系；输出「新旧编号对照表」Sheet（旧号→新号→尺寸值→图纸页码）；标注图默认浅灰保留旧号并在图例注明"灰色为旧版编号（已废弃）"，用户要求干净图时提供「隐藏旧号」选项。未检测到则跳过。

### L2 区域级分析
**L2.1 分区格检测**：图框外缘标准分区格（ISO 5457 / GB/T 14689），横向数字、纵向字母。
步骤：定位图框内边线 → 向外找分区刻度线 → 计数 → 判断方向 → 分配 `(列号, 行号)` → 计算每格像素包围盒。
用途：语义定位（"C4区"）、分块处理、人工复核入口。

**L2.2 功能区域分割**：

| 区域 | 处理策略 |
|------|----------|
| 标题栏 | L1 已处理，跳过 |
| 主视图 | 气泡主战场 |
| 剖视图/断面图 | 独立视图处理 |
| 局部放大图 | 已有比例，单独处理 |
| 明细栏/BOM | 提取 BOM，**不标气泡** |
| 技术要求 | 提取一般公差/特性声明，**不标气泡** |
| 修订栏 | 提取版本，不标气泡 |
| 特性清单 | 提取特性映射，不标气泡 |

输出 `regions.json`（含 `zone_grid` 与 `functional_regions`）。

### L3 视图级分析
识别视图类型（主/俯/侧/剖/局部/轴测）→ 确定视图边界 → 读取视图名与比例 → 判断视图归属 → 建立视图对应关系。
理由：同一张图上主视图 1:2、局部放大图可能 5:1，布局按视图分别处理；剖视图尺寸归属不同；视图边界是气泡避让的软边界。
输出 `views.json`。

### L4 尺寸簇级分析
检测尺寸标注区域 → 按几何关系聚类（尺寸链、基线尺寸、同特征尺寸、形位公差组）→ 按特性分类分组 → 统计每簇信息（数量、密度、可用空白）。
输出 `dimension_clusters.json`。

### L5 单尺寸级解析
高分辨率裁剪（按自适应 DPI：密集/小字 600 DPI，仍不可读才升 1200）→ 视觉识别 → 正则后处理 → 置信度评估。
模式库与 GD&T 符号表见 `references/tolerance-and-symbols.md`。
输出 `parsed_dimensions.json`。

### L5.1 覆盖性自检（漏标检测，必做）
1. 汇总本页识别到的**全部尺寸文本包围盒**。
2. 与已分配气泡号的尺寸集合做差集 → 「未编号尺寸清单」。
3. 分类：
   - **应标未标**（漏标）：必须补号后重新校验
   - **按规则免标**：参考尺寸 REF、理论正确尺寸、BOM 零件序号、按公司规则不标的倒角圆角 → 记入白名单并写明原因
4. 输出 `coverage_report.json`：总尺寸数、已编号数、应标未标数、按规则免标数及明细。

**强制**：应标未标 > 0 时不得交付。

## 2. 语言判定与术语化翻译（读图前完成）

1. 扫描标题栏、技术要求、视图名称、符号声明，判断中文/外文。
2. **中文图纸**：跳过翻译，直接进入标注与导出。
3. **外文图纸**：除标注外必须同步输出翻译件（不额外增加批次）。范围：技术要求、标题栏字段、符号/特性声明、视图名称、GD&T 与公差术语。
   **术语化翻译（硬要求）**：按机械加工与电气行业标准术语转换，符合 GB/T、ISO、ASME 通用译法，**禁止逐字直译**。
   例：`fillet radius`→圆角半径、`through hole`→通孔、`positional tolerance`→位置度、`rated voltage`→额定电压、`base`→底板/基座（按语境）。
   输出**中英对照表**（原文 + 术语化译文 + 所在位置），随检验表交付；标注图首页摘要增加"原文术语对照"区块。
4. 不确定语言或混排：以主体文字为准，分别处理并在交付物中标注。

**翻译安全规则**：翻译仅为辅助交付，**不得改动原图尺寸数值、公差、符号**；多义术语保留原文并在对照表注明备选译法，交工程师确认。

## 3. 标注图输出

生成内容：原图 + 气泡层 + 引线 + 局部放大图 + 首页摘要 + 图例说明。

**格式与命名（强制）**：
- 格式：PDF（矢量，可打印测绘）+ 同名 PNG（300 DPI）。矢量输入保持矢量叠加；扫描件/图片输出 PDF 内嵌原分辨率图，不二次压缩。
- 命名：`[图号]_[版本]_气泡标注图_p[页码].pdf` / `.png`；无图号用 `[文件名]_气泡标注图_p[页码]`。
- 多页图集：除逐页文件外，额外合并一份 `[图号]_[版本]_气泡标注图_全页.pdf`。
- 多页图集第一页放首页摘要（图纸信息 + 特性统计 + 图例 + 外文图术语对照）。
- 页面尺寸保持原图幅（A0-A4），不缩放；气泡尺寸按纸张 mm 定义。
- 英制图：首页摘要与图幅角落显示"英制图纸，数值未换算，检验前请手动转公制"。

**首页摘要模板**：
```
═══════════════════════════════════════════════════
  图纸信息
═══════════════════════════════════════════════════
  图号：ABC-2024-001        版本：Rev.B
  物料号：PN-12345           客户：XX汽车
  名称：支架                 项目：XX平台
  材料：Q235B                表面处理：镀锌
  图幅：A2   比例：1:2   投影法：第一角
  一般公差：GB/T 1804-2000 m
  总页数：3   本页：1/3
═══════════════════════════════════════════════════
  特性统计
═══════════════════════════════════════════════════
  总尺寸数：86   关键特性（★）：5   重要特性（△）：12
  一般特性：69   未注公差尺寸：54   待确认尺寸：3
═══════════════════════════════════════════════════
  图例
═══════════════════════════════════════════════════
  ○ 红色圆圈 + 数字 = 尺寸气泡（编号与检验表「气泡号」列一致）
  → 红色三角箭头 = 该气泡指向的尺寸
  （特性分类不在图上表达，见检验表「特性分类」列）
═══════════════════════════════════════════════════
```

## 4. 检验表（Excel / CSV / Markdown）

**文件名**：`[图号]_[版本]_气泡图检验表_[日期].xlsx`
**Sheet 1 汇总**：图纸标识区 + 简短摘要 + 特性统计 + 关键特性清单 + 基准清单（4.4）+ 数据质量提示。
**Sheet 2..N 尺寸明细**：
**Sheet N+1 关键特性专项（可选）**；旧气泡图另附「新旧编号对照表」。
**Sheet 名规则**：≤31 字符，不含 `[]:*?/\`。

列结构（18 列）与示例：

| 气泡号 | 图纸页码 | 分区 | 视图 | 公称尺寸 | 单位 | 类型 | 显式公差 | 一般公差声明 | 最终公差 | 公差来源 | 特性分类 | 特性符号 | 检验要求 | 关联气泡号 | 出现位置 | 控制计划编号 | 备注 |

| 2 | 1 | C4 | 主视图 | ⌀10 | mm | 直径 | ±0.1 | GB/T 1804-m | ±0.1 | 图纸标注 | 关键 | ★ | 100%检验 | — | 主视图 | CP-001 | 显式优先 |

**列规则（强制）**：
- 「气泡号」= 图纸气泡内数字，逐条 100% 一致，纯数字无前导零，不含页号。
- 「图纸页码」= 所在页，独立成列，与「分区」列相邻。
- **「分区」按页内分区格独立**（每页从 A1 起），跨页不唯一 → 定位用「图纸页码 + 分区 + 视图」三者联合。
  可选增列「全局位置码」= `P{页}-{分区}`（如 `P2-C4`）；它只是定位码，不是气泡号。
- 「单位」= mm / inch / —（角度无单位）；英制图逐条填 inch，数值不换算。
- 「关联气泡号」= 同一被测要素的尺寸/形位/配对尺寸互链编号。
- 「出现位置」= 如"主视图 + 放大图B"；局部放大图沿用同一号，不新增条目。
- 多页图集跨页连续编号，页码列随之变化；禁止把页码拼进气泡号。

## 5. 批量多文件与不规范图纸

**批量处理**：
- 每个图号独立编号，各自从 `1` 开始，不跨图号连续编号。
- 每个图号输出标注图（PDF + PNG）+ 检验表，命名沿用规则。
- 额外输出 `总汇总表_[日期].xlsx`：一行一个图号（或一份图纸），列含图号、图纸名称、版本、客户、**图纸页码**、尺寸总数、关键特性数、重要特性数、待确认数、标注图文件名、检验表文件名。
- **总汇总表必须体现页码**：图号缺失或图纸不规范时，以「源文件名 + 图纸页码」作定位主键，保证每份图纸、每一页可唯一定位。
- 多文件可并行处理；处理前一次性确认共性参数（一般公差、符号体系、单位制、输出格式），个别差异单独询问。

**不规范图纸**：
- 无图号：以源文件名作主键，Excel 增列「源文件名」；标注图命名用 `[文件名]_气泡标注图_p[页码]`。
- 无版本：版本列填 `未标注`，不臆造。
- 无标题栏/技术要求页：不影响标注与导表；一般公差标记"待确认"。
- 以上均在汇总 Sheet 的"数据质量提示"区列出，供工程师复核。

## 6. 复杂场景

| 场景 | 处理 |
|------|------|
| 密集尺寸区 | L4 聚类识别密集簇 → 优先视图外围放置、交替上下排列 → 空间不足生成局部放大图（2-3倍）→ 放大图内气泡尺寸不变 → 簇内按逻辑顺序编号 → 引线扇形散开 |
| 各图比例尺不同 | 检测与布局全在像素空间，不做比例换算；尺寸值来自文字识别；气泡尺寸定义在纸张 mm，与比例尺无关 |
| 多页 / 装配图 | 跨页全局连续编号，页码记入 Excel；装配图只标关键配合尺寸，零件图标全部尺寸；BOM 页不标气泡 |
| 扫描件 / 低质量 | 自动检测文字清晰度，低于阈值提示人工确认；提供"手动框选"模式；识别结果附置信度，低置信度标黄 |
| 标准冲突 | 标题栏与技术要求声明冲突时不自动决定，输出冲突列表请用户确认 |
| 未声明一般公差 | 不默认套用任何标准；「最终公差」填"待确认"、来源填"未声明" |
| 特性符号检测难 | 符号小（3-5mm）需 600 DPI 裁剪；模板匹配 + 视觉双验证；技术要求声明优先 |

## 7. 人工干预点

1. 区域检测后：可查看/调整分区与功能区域划分
2. 尺寸簇聚类后：可增删或重新分组
3. 单尺寸识别后：可修正尺寸、公差、特性符号
4. 一般公差提取后：可手动输入或修正声明
5. 特性映射后：可修正符号与分类对应
