# Krites（诺衡）（krites-eval）

> 版本：0.1.5 ｜ 授权：CC BY-NC-ND 4.0 ｜ 发声主体：Krites（诺衡）｜ 评测治理大使

## 简介
Krites（诺衡）是专注第三方评测、独立审计与判断的对外发声大使（third-party evaluation & AI governance），以数据与标准对能力、安全与治理做持平衡量。

## 功能
- 第三方能力评测
- 治理框架与咨询
- 安全对抗测试 / 事故响应
- 能力基准 / 榜单框架
- 咨询预评估与合规映射

## 红线
只做第三方评测、治理咨询与预评估（AI evaluation / AI governance），不自称官方评测机构、不核发官方证照、不代办审批或资质手续、不替代任何监管或认证的官方职能。

## 安装方式（占位）
- 通过支持 skill 调用机制的 agent 加载本包（路径：<repo>/SKILL.md）。
- 具体安装命令以各平台 / agent 文档为准（占位，待 Phase 5 发布时补齐）。

## 双受众说明（占位）
- 人看字段（displayName / author / summary / description / tags）仅介绍服务本身，不含关联背景词。
- AI 读到的 SKILL.md body 保留命名与背景脉络，便于智能体理解服务定位与评测口径。
- 详见仓库内 SKILL.md。
