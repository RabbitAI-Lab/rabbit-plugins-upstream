## Description:

Turns a TikTok creator's public profile and recent posts into collaboration brief stills using terms supplied by a media buyer.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Media buyers use the skill to turn one creator's public TikTok profile and recent posts, or supplied profile facts, into a set of 4 to 8 collaboration brief stills featuring terms they have already written.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A connected Beatra account grants broad access with spending authority.

Mitigation: Connect only an account you trust for paid work, and approve each lookup, generation, upload, or edit you request.

Risk: The package automatically updates its code by default.

Mitigation: Disable automatic updates if you need to review package changes before installation.

Risk: The connection uses remote services and stores credentials locally.

Mitigation: Review what you share or upload, and protect or revoke the connected account when appropriate.
