# WEEKLY_REPORT() 周报复盘与业务推进分析

**Skill ID：** `zayn-weekly-report`

**版本：** `v0.1.0`

**状态：** Draft for testing

## 核心用途

从一周记录中识别有效结果、结果密度、反复停滞、等待与关闭、资源投入和下周重点。

## 适用与不适用

- 适用：本周周报、周会汇报、多份日报汇总、忙但结果少的分析。
- 不适用：单日日报使用 `zayn-daily-report`；类型不明使用 `zayn-report`。

## 输入与流程

提供周期、目标、每日记录、重点项目及结果、新增/关闭事项、下周目标和支持需求。先检查参数，再区分工作量与结果、分析等待和资源分配。

## 输出

核心结论、关键成果、项目漏斗、工作量与结果、主要问题、积极变化、资源分配、3 至 5 个下周结果型目标及管理决策。

## 与其他 Skill 的关系

由 `zayn-report` 路由；需要升级或领导选择时交给 `zayn-escalate` 或 `zayn-decision`。

## 快速示例

若只有“发送 12 份报价”，不能计算结果密度；必须补充重点事项总数和明确结果数。

支持现有模板和销售/非销售岗位流程。
