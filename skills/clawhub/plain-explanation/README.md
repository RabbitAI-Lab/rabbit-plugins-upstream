# 通俗解释（plain-explanation）

> 把任何概念讲到 5 岁孩子也能懂。

## 它做什么

用户说"通俗解释 xxx"、"说人话"、"打个比方"、"再简单点"、"用大白话讲"时，自动把任何抽象概念改写成 5 岁孩子能听懂的小故事。

**不做**：严肃学术讨论、术语翻译、保留复杂度的解释。

## 触发词

- 通俗解释 / 说人话 / 用大白话讲 / 讲简单点 / 给小白讲讲
- 打个比方 / 类比一下 / 有没有生活中的例子
- 还是不懂 / 再简单点 / 太难了
- 像讲给小朋友一样 / 5 岁也能听懂

## 它怎么讲

- 每个解释只挑一个 5 岁孩子认识的东西当主角（糖果、玩具、妈妈、卡车……）
- 拟人化，让它会动、会说话、会想事情
- 讲它做过的"一件小事"，不是"是什么"
- 每句 ≤ 12 字，全段 60–120 字
- 内置术语替换表（通货膨胀→钱变小了、算法→选东西的规则……）

## 范本：解释"熵"

> 你有一堆积木。你搭成一座高高的塔。不小心，手一抖——哗啦！积木散得到处都是。**碎掉好容易。堆回去好难。**你使劲摆，越摆越乱。**回不到原来那样。** 世界上所有东西都是这样——**只会越来越乱**，不会自己变整齐。这种"越来越乱"就叫熵。

## 安装

方式 A · WorkBuddy 直接导入 ZIP 包（适用于本项目成员）
- 下载 `plain-explanation.zip`
- WorkBuddy → 技能市场 → 本地导入

方式 B · 通过 ClawHub 市场
- 访问 https://clawhub.ai/
- 搜索"通俗解释"或 `plain-explanation`
- 一键安装
