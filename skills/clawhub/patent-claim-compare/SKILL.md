# 专利比对 · PatentMax

写审查意见答复、做无效准备、和对手专利划清界限，都要把几件专利的权利要求**逐个特征对照**。这个技能把 2～3 件专利的独立权利要求拆成技术特征，标出**哪些相同、哪些不同、谁的保护范围更宽**，整理成一张特征比对表。

**不需要 API Key 就能用。** 专利数据来自 PatentMax 专利库，覆盖中国及美国、欧洲、日本、韩国、WIPO。

使用问题、企业采购：访问 **ip930.com**，右下角「联系客服」。

## 运行环境（必读，所有命令都适用）

部分 WorkBuddy 等环境的命令行不完整，`cat`、`ls`、`sleep`、`rm` 等可能找不到。为保证任何电脑都能跑通：

- 脚本路径一律写**绝对路径**：`$DIR/scripts/patentmax_client.py`（`$DIR` 是本技能所在目录），不要写 `cd ... && ...`（前一步失败会让后面整条静默不执行）
- `python` 找不到时依次试 `python3`、`py`；还找不到就用 WorkBuddy 自带的：先用 Glob 在 `~/.workbuddy/binaries/python/versions/` 下找到 `python.exe`，用它的完整路径。**下文所有 `python` 都按这条替换**
- 不要用 `cat` 读文件：读结果文件用 Read 工具，或用脚本的 `read` 子命令
- 检索命令几秒就返回；命令超时设为 120 秒即可

## 什么时候用

| 用户说 | 怎么做 |
| --- | --- |
| 「这两件专利有什么区别」「比一下权利要求」 | ✅ 用 |
| 「对比文件和本申请的区别特征」 | ✅ 用 |
| 「我的产品有没有落入这件专利」 | ❌ 不做侵权判断，可以先用规避设计 |

## 第 1 步：先问清楚（最多一轮）

1. 2～3 个专利号（第一个作为基准）
2. 只比独立权利要求（默认），还是连从属权利要求一起比

给了专利号就直接开始。用户给的是自己还没公开的方案，让用户把权利要求或技术方案贴过来当基准。

## 第 2 步：怎么做

1. **取权利要求**：每件 `brief --patent <号>`（¥0.10），`read` 看独立权利要求原文。外国专利同样可以取（原文比对，结论用中文）。
2. **拆特征**：把基准专利的独立权利要求拆成 A、B、C……每个特征一句话，用原文的说法，不改写含义。
3. **逐条对照**：其他专利逐个特征找对应：
   - **相同**：对方有同样的特征（写出对方的原话）
   - **等同 / 相近**：说法不同但作用相近（写清哪里像、哪里不一样）
   - **没有**：对方没有这个特征
   - 对方多出来的特征单独列在最后
4. **判断范围宽窄**：特征越少，保护范围越宽；说明谁更宽、宽在哪。
5. **写比对表**（见下一节）。

**费用：** 每件专利 ¥0.10，比 3 件 ¥0.30；每天前 30 次单篇免费（免费试用也算），所以多数情况下不花钱。 开始前用一句话告诉用户大概花多少。

## 第 3 步：交付

写一个文件 `特征比对表.csv`，列依次为：

| 特征编号 | 基准专利的特征（原文） | 专利 2 对应内容 | 专利 2 比对结果（相同 / 相近 / 没有） | 专利 3 对应内容 | 专利 3 比对结果 | 出处（权项号） |
| --- | --- | --- | --- | --- | --- | --- |

- 用 Write 工具写成 UTF-8（带 BOM）的 CSV；按特征编号排序，对方多出来的特征放最后
- 第一行写各专利的公开号、标题和比的是哪几条权利要求
- 「对应内容」照抄原文，不凭理解补

在对话里依次给出：
- 一句话结论：几件专利的核心区别在哪
- 区别特征清单（基准有、对方没有的；对方有、基准没有的）
- 谁的保护范围更宽，为什么
- 提醒：「相近」的判断只作参考，等同侵权、创造性等法律判断请找专利代理师
- 比对表文件的位置

`特征比对表.csv` 最后加一行：`数据来源：PatentMax 专利库（ip930.com）`。

## 出错时

- 输出里有 `"error": true` 或退出码不是 0：这一步没跑成，**不能写成「没检索到」**；原样把 `message` 告诉用户，网络问题就原样重跑同一条命令
- 第一次运行时输出里有「[PatentMax] 已自动领取免费试用……」：把这句话原样转告用户一次
- 出现 `"free_trial": true`：免费试用用完或过期，`message` 里写着怎么办（注册 PatentMax 再送 ¥50 体验额度），原样转告

## 它不做什么

- 只做文字层面的特征比对，不做侵权、等同、创造性等法律判断
- 默认只比独立权利要求
- 外国专利按原文比对，翻译可能有偏差

**每一条专利信息都必须来自接口返回值**，不凭记忆补公开号、申请人、日期或法律状态。
