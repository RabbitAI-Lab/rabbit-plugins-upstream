# 投标猎手 🎯

> 每天自动帮你盯着各大政府采购平台，发现匹配的招标机会就通知你。  
> 不用一个个网站去翻，不用怕错过截止日期——它帮你干这些重复活儿。

## 这是什么？

如果你或者你的公司需要经常找政府采购项目去投标，你一定经历过这些事：

- 每天打开好几个政府采购网站，一个一个搜关键词
- 搜出来的结果里混杂着中标公告、更正公告、废标公告，得人工过滤
- 记下项目名称、截止日期、预算金额，生怕漏了哪一个
- 不同省份的网站格式还不一样，换个省份又要重新适应

**投标猎手就是帮你干这些事的。** 它自动访问你关心的政府采购平台，按照你设置的关键词筛选招标公告，过滤掉无关信息，把结果整理好汇报给你。

### 它具体能做什么

1. **自动扫描** —— 定时访问北京、河北、辽宁、大连、全国等政府采购平台，不用你手动打开浏览器
2. **关键词匹配** —— 你告诉它关心什么业务（比如"建筑工程""信息系统"），它按重要程度分三级筛选
3. **过滤噪音** —— 自动跳过中标公告、废标公告、更正公告等跟你没关系的内容
4. **提取关键信息** —— 自动从公告详情页提取投标截止时间、开标时间、预算金额
5. **跟踪进度** —— 记录每个项目的状态（关注中 → 已投标 → 中标/未中标），全程可追溯
6. **到期提醒** —— 快截止的项目主动提醒你，不会因为忙忘了投
7. **通知推送** —— 扫描结果可以发到飞书、钉钉、企微，或者导出文件

## 谁适合用？

- 📋 **每天需要找投标机会的商务、销售、市场人员** —— 不用再手动翻网页

## 怎么装？

### 第一步：装 Node.js

投标猎手需要 Node.js 运行环境。如果你的电脑上已经有 Node.js（版本 ≥ 18），跳过这一步。

**没装过的话**，去 [nodejs.org](https://nodejs.org) 下载安装包，选 LTS 版本（左边的按钮），像装普通软件一样双击安装就行。

装好后打开终端（Windows 上是 PowerShell 或 CMD，Mac 上是终端），输入下面命令确认装好了：

```bash
node --version
# 应该显示类似 v18.x.x 或 v20.x.x
```

### 第二步：装投标猎手

在终端里输入：

```bash
npm install -g bidding-hunter
```

> 💡 `npm install -g` 的意思是"全局安装"，装一次就行，之后在任何目录都能用。

### 第三步：装浏览器驱动

投标猎手需要一个自动化浏览器来访问网页，运行下面命令：

```bash
npx playwright install chromium
```

> 💡 这个命令会下载一个 Chromium 浏览器（Chrome 的开源版本），大约 150MB。只需要运行一次。

### 第四步：创建配置文件

```bash
bidding-hunter init
```

这个命令会在你的电脑上创建 `~/.bidding-hunter/config.yaml` 配置文件。接下来你需要编辑它，告诉投标猎手你关心什么关键词。

## 配置你的关键词

配置文件是最重要的——你告诉投标猎手你要找什么，它就帮你找什么。

用任意文本编辑器打开 `~/.bidding-hunter/config.yaml`（Windows 上路径是 `C:\Users\你的用户名\.bidding-hunter\config.yaml`）：

```yaml
matching:
  # 搜索词：在每个平台搜索框里输入什么
  # 一个搜索词就是一次搜索，建议 2-4 个，太多反而慢
  search_queries:
    - "建筑工程"
    - "信息化"

  # 关键词分级：匹配标题时按优先级筛选
  tiers:
    high:                          # 第一优先级：核心业务
      label: "重点项目"
      keywords: ["建筑工程", "土建施工", "信息系统"]
    medium:                        # 第二优先级：相关业务
      label: "一般项目"
      keywords: ["系统集成", "运维服务", "弱电工程"]
    low:                           # 第三优先级：拓展业务
      label: "关注项目"
      keywords: ["市政工程", "园林绿化", "物业管理"]

  # 黑名单：标题里包含这些词的就跳过
  # 这些都是"已经结束/不相关"的信号
  blacklist:
    - "中标"
    - "成交"
    - "废标"
    - "更正"
    - "流标"
    - "终止"
    - "澄清"

# 要扫描哪些平台
platforms:
  enabled:
    - beijing        # 北京公共资源交易平台
    - hebei          # 河北省招标投标公共服务平台
    - liaoning       # 辽宁省公共资源交易平台
    - dalian         # 大连市公共资源交易平台
    - national       # 全国公共资源交易平台（覆盖最广）
```

> ⚠️ **关键词怎么选？** 建议用你的核心业务词汇，2-4 个字一组，不要太长。比如你是做弱电工程的，用"弱电""安防""智能化"就比"弱电系统工程设计与施工"效果好——搜索词越短，命中率越高。

## 日常使用

### 每天扫一次

```bash
bidding-hunter scan
```

运行后它会逐个打开你配置的平台，搜索关键词，筛选匹配的公告。扫描完会自动保存结果。

整个过程大概 2-5 分钟（取决于开了几个平台），你可以在终端看到实时进度。

### 看今天的报告

```bash
bidding-hunter report --today
```

输出类似这样：

### 查看和更新项目状态

```bash
# 列出所有跟踪中的项目
bidding-hunter list

# 把某个项目标记为"已投标"
bidding-hunter status --id 5 --status submitted

# 查看状态统计
bidding-hunter stats
```

状态可以设为：`watching`（关注中）、`submitted`（已投标）、`won`（中标）、`lost`（未中标）

### 查看即将到期的项目

```bash
bidding-hunter remind
```

会列出投标截止日期在 3 天内的项目，帮你防止漏投。

### 导出数据

```bash
bidding-hunter export --format csv --output ~/Desktop/投标记录.csv
```

## 常见问题

**Q: 扫描太慢怎么办？**
A: 可以在配置文件里减少 `platforms.enabled` 中的平台数量，或者减少 `search_queries` 的搜索词数量。

**Q: 搜出来太多不相关的结果？**
A: 检查你的关键词是否太宽泛。试试用更精确的词，或者增加黑名单关键词。

**Q: 某些平台扫不出结果？**
A: 政府采购网站可能会改版。如果某个平台突然失效，可以联系技术人员更新适配器。

**Q: 需要一直开着电脑吗？**
A: 不需要。只有运行 `bidding-hunter scan` 的时候才需要。扫完就可以关掉。
