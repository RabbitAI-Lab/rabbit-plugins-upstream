## Description:

Friendly SEO coach mode: explain what each Conqueror workflow does, recommend the next step, and teach when to use MCP data versus web search.

This skill is ready for commercial/non-commercial use.

## Publisher:

[conqueror](https://clawhub.ai/user/conqueror)

### License/Terms of Use:

MIT-0

## Use Case:

External users and SEO practitioners use this skill to get friendly coaching while working with Conqueror workflows, including choosing the next SEO action, understanding data sources, and deciding when to use Conqueror MCP data, Google Search Console, web search, browser tools, or local files.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may recommend using connected Conqueror, Google Search Console, web, browser, or local-file tools during SEO workflows.

Mitigation: Review connected account permissions separately before use.

Risk: SEO recommendations may rely on live data, user-provided project context, web evidence, or coaching judgment.

Mitigation: Confirm important recommendations against the relevant data source before applying changes to a live site.
