## Description:

Write content by interviewing the user instead of drafting - extract their material through questions, then assemble the piece from their own words. Use when the user needs to write something for an audience or mentions "ghostwriter".

This skill is ready for commercial/non-commercial use.

## Publisher:

MIT-0

## Use Case:

External users use this skill to produce audience-facing writing by answering interview questions, then receiving a tightened draft assembled from their own words.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can activate on broad writing requests.

Mitigation: Use it when an interview-style writing process is desired, and confirm that the user wants this workflow before continuing.

Risk: Optional context scouting can involve researching the subject or destination.

Mitigation: Ask before scouting and proceed only when the user is comfortable with the agent researching that context.

Risk: The final piece may need information the user has not supplied.

Mitigation: Ask for missing lines instead of inventing content.
