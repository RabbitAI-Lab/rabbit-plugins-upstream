# 营销海报生成

## Overview

输入活动信息，输出可直接交付设计/可直接喂给图片生成模型的完整海报方案：一是**文案层**（信息层级清晰、能卖货），二是**视觉层**（构图、风格、配色、留白位置），每个方案配一段可复用的图片生成 prompt。

## When to use

- 用户要活动海报、促销海报、新品海报、招聘海报、朋友圈海报。
- 用户要海报文案 + 配图方案 / 图片生成指令。

## 输入要求

- 必填：活动主题、核心卖点。
- 缺省按常识补齐并声明假设：时间地点、目标人群、品牌调性、尺寸比例（竖版 3:4 / 方版 1:1 / 横版 16:9）、交付形态（线上投放 / 印刷）。

## Workflow

1. **确认活动要素**：主题、卖点、时间地点、人群、调性、尺寸。
2. **搭文案结构**：主标题（最大，一句话讲清利益）→ 副标题（补充或解释）→ 核心利益点（3 个以内）→ 行动号召（一个动作）→ 备注信息（时间地点规则）。
3. **给多版本备选**：同一活动出 3 套不同角度（如「利益驱动」「氛围情绪」「紧迫稀缺」），每套给不同的主副标题组合。
4. **定视觉方案**：为每套文案配画面主体、风格、主色、构图、留白区域。
5. **写图片生成 prompt**：中文描述 + 英文 tag 形式各一版，便于直接调用图片生成。

## 输出模板

```
## 活动要素确认
- 主题 / 时间地点 / 目标人群 / 调性 / 尺寸比：

## 方案一｜利益驱动型
### 文案层
- 主标题：…
- 副标题：…
- 利益点：① … ② … ③ …
- 行动号召：…
- 备注：…

### 视觉层
- 画面主体 / 场景：
- 风格与参考：        色彩：        光线：
- 构图：              文案留白区域：
- 需避开的雷区：

### 图片生成 Prompt
- 中文：
- English tags：

## 方案二｜…
## 方案三｜…

## 交付提示
- 印刷建议 / 线上投放建议 / 安全边距
```

## 文案规则

- **一个核心，不要平铺**：主标题只承载一个最强利益点，其余下沉到副标题和利益点。
- **主标题短**：控制在 10 字以内最有力，最多不超过 15 字，字号必须是全海报最大。
- **动词 + 利益**：「立省 300」「全场 5 折起」「免费领」比「优质服务」有效。
- **行动号召单一**：只让人做一个动作，且要明确（扫码 / 到店 / 回复关键词）。
- **不夸大**：促销定价、赠品、奖品务必如实；避免「最高」「第一」等无依据表述，避免虚假折扣。
- **备注别漏**：活动时间、参与条件、限购规则放在底部小字，但要保证可读。

## 视觉规则

- **先交代留白**：竖版海报文案通常在上或下三分之一，视觉要为文案预留干净区域，避免画面主体压住标题。
- **主体单一**：一个明确的视觉焦点（产品 / 人物 / 场景），不要什么都放。
- **风格与调性一致**：低价走量用高饱和撞色 + 粗体；高端用留白 + 低饱和 + 细字重。
- **印刷与屏幕差异**：要印刷时提示 300dpi、CMYK、3mm 出血；纯线上投放可用 RGB。
- **图 delector**：生成人物的图时注明年龄段 / 服饰 / 光线，避免结果与品牌人群错位。

## 自检清单

- [ ] 主标题传达单一核心利益且字数受控
- [ ] 信息层级明确（主 > 副 > 利益点 > CTA > 备注）
- [ ] 每张方案都指定了文案留白区域
- [ ] 提供了可直接使用的图片生成 prompt
- [ ] 促销信息真实，无夸大或虚假折扣
- [ ] 尺寸比与交付形态已考虑（印刷 / 线上）
