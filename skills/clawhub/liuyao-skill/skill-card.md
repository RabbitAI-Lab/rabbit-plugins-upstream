## Description:

Provides Liuyao / Zhou Yi (I Ching) divination casting and interpretation using coin, yarrow-stalk, or manual hexagram input.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jinlio](https://clawhub.ai/user/jinlio)

### License/Terms of Use:

MIT-0

## Use Case:

External users and agents use this skill to cast Liuyao hexagrams, retrieve original Zhou Yi hexagram and line text, and produce reflective interpretations for a user's stated question.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may treat divination readings as deterministic or professional advice.

Mitigation: Present readings as entertainment or reflective guidance and avoid using them as a substitute for medical, legal, financial, or other professional advice.

Risk: The automatic casting command may fail because script packaging appears inconsistent.

Mitigation: Test the casting command in the target agent environment and correct package paths before operational use.
