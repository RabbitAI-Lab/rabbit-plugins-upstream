## Description:

Find keyword opportunities for a site by discovering seeds, scoring volume, difficulty and intent, checking SERPs, and saving selected winners through a connected Conqueror MCP server.

This skill is ready for commercial/non-commercial use.

## Publisher:

[samuelnoah45](https://clawhub.ai/user/samuelnoah45)

### License/Terms of Use:

MIT-0

## Use Case:

External users, SEO practitioners, and developers use this skill to turn seed topics, Search Console data, ranking signals, and local SEO signals into prioritized keyword targets for a site or project.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Connected Conqueror project data may include business-sensitive SEO, ranking, or Search Console information.

Mitigation: Install and use the skill only when the agent is intended to access connected Conqueror project data for SEO research.

Risk: Keyword recommendations or save actions could affect client or business SEO workflows.

Mitigation: Review suggested keywords before acting on them, and require explicit user confirmation before saving keywords.

Risk: Keyword metrics may be unavailable from the connected data source.

Mitigation: Do not invent missing metrics; label unavailable values as unknown.
