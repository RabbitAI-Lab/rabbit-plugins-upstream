## Description:

Manages project context and documentation files by checking their claims against the codebase before creating or updating them.

This skill is ready for commercial/non-commercial use.

## Publisher:

[iliaal](https://clawhub.ai/user/iliaal)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to initialize or maintain AGENTS.md and other project documentation, checking content against the repository before making changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Changes to AGENTS.md or CLAUDE.md can influence future agent behavior.

Mitigation: Review generated changes before accepting them, especially edits to agent context files.
