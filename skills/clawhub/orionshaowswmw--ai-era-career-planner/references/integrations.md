# 可选集成（v2.0.0）

> ⚠️ 以下所有集成为**可选项**，仅在用户**明确提出需求**时才激活，且每次操作需获得用户确认。
> （v1 的"多语言支持 → references/i18n/en.md"指向不存在的文件，已移除；
> 如用户需要英文报告，直接按同一 JSON 结构以英文撰写即可。）

## AgentMail 集成
如用户明确要求将报告发送到邮箱，按用户提供的地址发送。

## 资讯订阅
如用户明确要求订阅职业方向资讯，根据用户选择的方向提供订阅服务（可随时取消）。

## 记忆保存
如用户明确要求保存规划摘要，提供内容供用户自行保存，不主动写入。

## 实时数据接入
招聘平台实时数据：仅在用户明确需要且当前环境可用时接入；任何实时数据
引用必须保留原始 URL 与访问日期。

## 重要原则

- **不自动发送**：不自动发送任何报告、资讯或推送
- **不自动订阅**：不自动订阅任何内容
- **不自动记录**：不自动写入任何 memory 或追踪文件
- **用户授权**：每次外部操作均需用户明确授权
