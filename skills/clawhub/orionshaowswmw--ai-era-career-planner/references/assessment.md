## 测评二：职业价值观（v2 修正：5 选 2）

> v1 缺陷：文案写"以下三项"却列了 5 项。v2 明确：**从 5 项中选出最看重的 2 项**。

1. **成就感** — 工作能让我有成果、被认可
2. **人际关系** — 工作环境和谐，有人关心我
3. **自主性** — 我能自己安排时间，做自己想做的事
4. **稳定性** — 这份工作稳定，不会突然消失
5. **成长性** — 这份工作能让我学到东西，不断进步

## 测评三：个人优势识别

问用户："回想过去，让你感觉最自豪的一件事情是什么？用一句话描述你在这件事里扮演的角色。"

分析关键词：
- "我亲自做成了…" → 执行力/动手能力强（R型）
- "我帮到了…" → 同理心/助人能力强（S型）
- "我想到了一个新方法…" → 创新能力（I/A型）
- "我让一群人一起行动了…" → 领导力（E型）
- "我把复杂的事情整理清楚了…" → 分析/条理能力（C型）

## 测评四：抗压与工作风格

问用户："如果遇到一件很难的工作，你会怎么做？"

1. 先仔细分析，搞清楚再动手
2. 先做起来，边做边调整
3. 找人商量，请教别人

5. 按照规则和流程一步步处理

## 方向匹配打分规则（match 命令，确定性启发式）

`fit_index = round(5 × (0.4·holland + 0.3·values + 0.3·anchor))`，**这是启发式，不是预测**。

- 子分 **holland**：方向主代码命中 = 1.0，未命中 = 0.2（`I/A` 混合代码对 I 和 A 均算命中）
- 子分 **values**：用户 2 项与方向 2 项的交集数 / 2（0 / 0.5 / 1.0）
- 子分 **anchor**：主锚命中 = 1.0，次锚命中 = 0.5，其他 = 0.0
- **缺失维度**（如用户没做霍兰德）：按可用维度重新归一化权重，并在输出中标记 `not_assessed`
- **排序**：fit_index 降序 → 薪资中值降序 → 方向名称升序（完全确定性，无随机）

命令行用法：
```bash
python3 scripts/career_planner.py match \
  --answers '{"holland":"R","values":["成就感","自主性"],"anchor":"自主/独立型"}' \
  --city 北京 --industry 互联网/IT --level entry --top 5
```
