## Description:

Chooses and implements design patterns in Kotlin, Java, Swift and Dart mobile code: Repository, Factory, Strategy, Observer, Adapter, Decorator, Facade, State machine, Command, Coordinator, Result types and Delegation, with a selection table and over-engineering warnings. Use when picking a pattern, refactoring god classes or flag-driven state, wrapping an SDK, or when a design feels over-abstracted.

This skill is ready for commercial/non-commercial use.

## Use Case:

Mobile developers use this skill to choose and implement language-appropriate design patterns in Kotlin, Java, Swift, and Dart. It helps them structure features, refactor over-abstracted code, and decide when a simpler language feature is enough.
