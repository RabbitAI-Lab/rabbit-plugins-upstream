# 基础设施 Apply 前评审清单

> 每次 `terraform apply` 前逐项核对。脚本只标红，本清单补全人工判断维度。

## 计划审查
- [ ] 已用 `scripts/tf_plan_risk.py plan.json --strict` 扫描
- [ ] 所有 delete/replace 已写明影响范围与回滚路径
- [ ] 无权限扩张（无 `"Action":"*"` / `"Principal":"*"`）
- [ ] 仅 create/update 的常规变更也核对命名与标签

## 数据安全
- [ ] 持久数据资源（RDS/桶/磁盘/证书）变更前已备份/快照
- [ ] 无将生产数据资源 replace 的操作未演练

## 状态与并发
- [ ] state 后端开启锁（远程 backend）
- [ ] 无人正在并发改写同一 state
- [ ] state 已版本化（可回退到上一版）

## 版本与依赖
- [ ] provider 版本已锁定
- [ ] 重大 provider 升级已单独提交、单独 review
- [ ] 模块版本约束明确，无隐式 major 跳变

## 可观测与回滚
- [ ] 变更期间监控/告警在线
- [ ] 已准备回滚命令与时间窗口
- [ ] 灰度策略就位（分批/金丝雀）

## 上线后
- [ ] 变更后跑核心健康检查
- [ ] 记录实际影响，更新运行手册
