## Description: <br>
Converts TRPG markdown files, such as rulebooks, scenarios, and catalogs, into same-directory PDF files for player and GM use. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[ice26985850](https://clawhub.ai/user/ice26985850) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
External users and game creators use this skill to convert gameplay-facing TRPG markdown documents into printable and tablet-readable PDFs while leaving the source markdown files unchanged. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: In large projects, the agent may select Markdown files that are not gameplay-use documents. <br>
Mitigation: Confirm the intended file set before conversion and exclude requirements documents, drafts, notes, transition files, and briefing_package contents. <br>
