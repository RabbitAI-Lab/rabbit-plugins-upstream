# VBot Skills Framework

> Build, share, and discover AI agent skills like never before.

## Features

- 🎨 Template system for quick skill creation
- 📋 Standardized SKILL.md format
- 🔧 7 production-ready skills included
- 📚 Easy to extend and customize

## Included Skills

| Skill | Description |
|-------|-------------|
| commit-ai | AI-powered git commit message generator |
| readme-gen | One-click README.md generator |
| dep-check | npm dependency outdated checker |
| emoji-finder | Developer emoji lookup |
| github-stats | GitHub repository statistics |
| reminder | Scheduled reminders |
| web-search | Web search capability |

## Usage

```bash
# Browse skills
ls skills/

# Use a skill
# Activate when user triggers match the description
```
