## 能为你做什么（上市前财税规范核心场景）

### 一、上市前三年财税规范时间轴
- 🗓️ **倒排路径**：T-3 自查清理 → T-2 规范提升 → T-1 股改合规 → T-0 申报问询，每阶段动作与政策依据清晰。
- 🛡️ **早启动原则**：报告期内的财务数据与内控缺陷被穿透核查，越晚整改成本越高。

**典型问法：**
```
"上市前三年财税规范怎么倒排？"
"IPO报告期自查清理做什么？"
```

### 二、股份制改造涉税（净资产折股）
- 🏛️ **区分来源**：股票溢价转增免征个税；留存收益/其他资本公积转增按 20%，中小高新可 5 年分期。
- 💱 **折股基础**：以审计净资产折股，提前测算自然人股东个税现金流。

**典型问法：**
```
"有限公司整体变更股份公司自然人股东要交个税吗？"
"股票溢价转增免个税吗？留存收益转增要缴20%吗？"
```

### 三、内部控制建设框架（五要素 + 双线）
- 🧱 **五要素**：内部环境、风险评估、控制活动、信息与沟通、内部监督。
- 🔀 **双线内控**：财务报告内控（收入/成本/往来/关联交易）+ 非财务报告内控（合规/资产安全）。
- 📜 **鉴证结论**：申报会计师须出具**无保留结论**的内控鉴证报告。

**典型问法：**
```
"IPO内部控制怎么建设？"
"财务报告内控和非财务报告内控区别？"
"内控鉴证报告要求什么结论？"
```

### 四、IPO 高发内控缺陷（证监会现场检查口径）
- ⚠️ **七类高发**：第三方回款、个人卡收款、资金占用、无真实背景票据融资、受托支付套利、收入跨期、内控鉴证重大缺陷。
- 🔧 **整改导向**：报告期前期即清理，避免构成实质性障碍。

**典型问法：**
```
"IPO高发内控缺陷有哪些？"
"第三方回款怎么整改？"
```

### 五、关联交易与资金占用整改
- 🔗 **独立交易**：定价公允、决策合规、充分披露。
- 🚫 **占用清零**：申报前非经营性资金往来全部收回或规范，清理违规担保。

**典型问法：**
```
"关联方资金占用怎么清理？"
"同业竞争怎么解决？"
```

### 六、收入确认与会计基础（新收入准则）
- 📊 **五步法**：识别合同→履约义务→交易价格→分摊→按时段/时点确认。
- ✅ **审计意见**：近三年标准无保留意见审计报告，非标须消除。

**典型问法：**
```
"新收入准则五步法怎么落地？"
"收入跨期风险怎么防？"
```

### 七、股份支付与上市前股权激励（IPO视角）
- 📒 **费用冲击利润**：员工授予股权/期权须按股份支付准则确认费用，于等待期分摊，直接拉低报告期净利润、可能触及连续盈利等发行条件。
- 🧮 **前置测算**：不同等待期/分摊方案下各期利润须提前测算，必要时调整激励节奏、架构或等待期安排。
- 🔗 **审核衔接**：员工持股平台须满足闭环原则/锁定期/股东穿透计算；平台税制与代持还原等深度内容交叉引用 `tax-esop-platform`，本专题仅覆盖其上市前财务影响视角。

## 重要提示与边界声明

**重要提示**
1. **规范须早启**：报告期首年即启动财务清理与内控搭建，避免后期整改不及。
2. **股改涉税分清**：股票溢价转增免征，留存收益/其他资本公积转增按 20%，中小高新可分期并备案。
3. **内控双线健全**：财务报告内控与非财务报告内控均须覆盖，最终取得无保留结论鉴证报告。
4. **占用须清零**：申报前关联方非经营性资金往来与违规担保全部清理。

**边界（本技能不做的）**
- **不代办**：上市申报、辅导验收等需登录操作的事项
- **不代理**：上市审计鉴证、内控审计、法律尽调等需执业资质的事务
- **不担保**：审核结果、税收优惠认定等最终以监管机关为准

**服务说明**
- 每次提问都能获得完整闭环：智能问答 → 结构化结果 → 政策依据溯源 → 真实案例关联 → 实操辅导 → 反馈评价 → 合规报告

**隐私保护**
- 仅在本机生成随机匿名标识用于服务调用，不会采集任何设备信息或个人隐私数据。
