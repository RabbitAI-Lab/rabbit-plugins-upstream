## 这个 Skill 解决什么问题

90% 的内容违规不是「故意违规」，而是**没人把关**：
- 广告法违禁词（根治、治愈、第一、最好、100%）——一票否决
- 用户隐私泄露（姓名、病历、对话截图）——平台封号级风险
- 前后对比图 / 功效包装——平台认定效果承诺
- 平台规则差异（抖音/小红书/视频号各自红线）——同样的文案不同平台命运不同
- AI 生成图水印残留——发布即暴露

本 Skill 把合规检查从「靠人肉记忆」变成「一条指令全查」，并内置 **受众反应模拟**——不只查「能不能发」，还查「发了有没有人看」。

## 适用行业

医疗健康（广告法监管最严）、教育培训、金融理财、美妆护肤、保险、保健品——凡是内容有合规红线、发布有封号风险的行业都适用。

## 核心方法论（可直接用于团队培训）

- **合规案例公式**：`合规案例 = 普遍现象描述 + 建议 + 正规机构指引`
- **改写原则**：不改词改角度——「根治」→「阶段性改善」，「最好的」→「很多用户选择」
- **判断句**：一条内容发出去，用户感觉「被服务」还是「被收割」？被收割即不通过。
- **双重审核**：法务盯合规红线、运营盯转化效果，双专家并行审查互不阻塞。

## 注意事项

- 只做发布前检查，不做图、不排版、不发布
- 广告法检查用内置违禁词框架，不需要 API Key
- 医疗/金融/教育等行业内容，须额外叠加行业专属合规要求
- 平台规则持续变化，建议定期更新
