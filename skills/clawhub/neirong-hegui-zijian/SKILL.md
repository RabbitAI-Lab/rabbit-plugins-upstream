# 内容发布前全链路合规自检 v1.0（通用版）

> **郭哥AI·出品** — 民营医疗运营实战沉淀（医疗合规 + 广告法实战经验），方法论适用于所有需要内容合规审核的行业。
> 💡 完整内容增长与合规体系：见 **http://skill.guogeai.com**

**定位：** 内容出稿后的最后一道阀门。所有内容（公众号/小红书/抖音/视频号/培训课件/知识库入库）发布前必过此检查。

## 五步检查流程

### 第一步：广告法违禁词检测

**四类违禁词分类框架：**
1. **功效承诺类**：根治、治愈、快速见效、永不复发、保证见效、100%、特效
2. **极限词**：第一、最好、首选、最先进、国家级、唯一
3. **违规导流**：联系方式（手机号/微信号/电话）、二维码、扫码加
4. **虚假宣传**：无资质宣传疗效（如美白/瘦身）、虚构案例

**检测范围：**
- 疗效承诺词：根治、治愈、保证见效、永不复发、快速见效、100%
- 绝对化用语：第一、最好、首选、最先进、国家级、唯一
- 资质暗示：权威专家、三甲认证、官方排名
- 对比贬低：别家不行、XX药没用
- 违规导流：联系方式、手机号、电话、微信号（正文）、二维码
- 虚构案例暗示：治好了、彻底康复、已康复
- 平台敏感词：特定行业词（短视频需用委婉表达）、加微信（改「联系咨询」「了解更多」）

**命中后：** 按6类改写策略输出合规替代方案，**不改词改角度**。

### 第二步：用户隐私脱敏检查
- [ ] 真实姓名（含姓氏+特征）→ 改为「一位年轻用户」「治疗后该区域...」
- [ ] 面部照片/可辨识特征 → 打码或替换
- [ ] 病历原文/诊断报告截图 → 匿名化处理
- [ ] 对话截图含个人信息 → 去标识化
- [ ] 地理位置精确定位 → 模糊到城市级别

### 第三步：形象/配图核实
- [ ] 专家照片→ 只能使用真实素材照片，严禁 AI 生成真人形象
- [ ] 机构场景→ 只能使用真实场景图片，严禁 AI 生成
- [ ] AI 生成配图→ 确认无水印（「AI生成」「图片由AI生成」等字样），裁底部确认
- [ ] SVG/示意图→ 不含虚假前后对比（除非标注「示意图」）
- [ ] 配图数量→ 公众号 2-3 张以上，穿插不同位置

### 第四步：去水印完成确认
- [ ] 所有 AI 生成图片已用工具裁底部去水印
- [ ] 逐张肉眼检查：无水印残留（「AI生成」「由AI生成」「人工智能生成」等）
- [ ] 裁剪量：1024px高→裁 150px, 1216px高→裁 150px, 其他按比例 12-15%

### 第五步：平台规则适配
**按目标平台检查：**

| 平台 | 特殊限制 | 检查项 |
|------|---------|--------|
| 公众号 | 标题禁用「根治」「治愈」，正文可提及行业词 | 标题违禁词、封面图合规 |
| 抖音 | 敏感词→委婉表达，禁止留联系方式 | 违禁词替换、CTA合规 |
| 小红书 | 🔴 限流极严，需极度生活化：敏感词一律委婉表达、禁直接联系方式（走私信软转化）、图片审核比文案更严、评论区同受审核 | 敏感词替换+导流检查+图片审核+评论区合规 |
| 视频号 | 🔴 独立规则：评论区同正文受审、可挂公众号链接（合规）、认证号需资质对应、机构号禁虚构资质、不制造焦虑恐慌 | 正文+预设评论+导流方式+身份匹配 |
| 培训课件 | 对内无广告法限制，但避免对外泄密 | 内部数据脱敏 |

## 第六步：案例表述合规检查

**核心公式：**
```
合规案例 = 普遍现象描述 + 建议 + 正规机构指引
```

**检查项：**
- [ ] 无「治好了XX」「这个患者治愈了」「康复案例」等直接结果表述？
- [ ] 案例是否使用「遇到XX情况 → 采取了XX方案 → 坚持了XX时间」的**过程描述**？
- [ ] 案例结论是否为「建议到正规机构评估」「具体因人而异」而非疗效承诺？
- [ ] 无虚构案例？所有案例均有真实来源可追溯？

**对比示例：**
| ❌ 违规 | ✅ 合规 |
|--------|--------|
| 「张先生在我们这治好了」 | 「一位用户，坚持阶段性方案+日常维护后，情况出现了改善」 |
| 「这个孩子3个月就康复了」 | 「3-6个月是常见的观察周期，很多人在这个阶段能看到变化」 |
| 「我们的方案让200多人摆脱」 | 「我们接触过各种类型的情况，每个人不同，方案也因人而异」 |

## 第七步：画面与字幕合规检查

**画面禁忌：**
- [ ] 🔴 无前后对比图（使用前/使用后对比）？—— 平台认定为效果承诺
- [ ] 🔴 无功效包装（产品包装/瓶体特写）？—— 暗示产品功效
- [ ] 无二维码/联系方式/微信号水印？
- [ ] 背景无行业敏感元素（手术室/白大褂特写/病历本）？

**字幕规范（抖音/视频号）：**
- [ ] 字幕是否**嵌入画面**（硬字幕）而非浮于屏幕上方？—— 悬浮字幕限流风险高
- [ ] 字幕无违禁词（同第一步检测）？
- [ ] 字幕无联系方式/微信号？

## 第八步：内容形式分类自检

| 内容形式 | 允许 | 禁止 |
|---------|------|------|
| **避坑科普** | 揭露智商税、防骗知识、行业潜规则 | 借科普之名做效果暗示 |
| **经验分享** | 个人踩坑经历、服务流程展示 | 承诺效果、前后对比 |
| **专业展示** | 专家面诊过程、检查流程 | 治疗中画面、用户隐私 |

自检：本次内容属于[_]类 → 边界是否踩线？

## 第九步：营销伦理与反面案例检查

**检查项（🔴 任一命中即不通过）：**
- [ ] 🔴 内容是否「套近乎+强推大单」？（过度营销）→ 改为专业咨询 + 方案分层讲解
- [ ] 🔴 是否暗示不合理剂量/项目堆叠？（过度消费）→ 拒绝过度推荐，按规范
- [ ] 🔴 是否效果承诺 / 前后对比夸张？→ 过程记录 + 「需面诊评估」
- [ ] 🔴 是否骚扰式营销（群发轰炸、无差别推送）？→ 改为节点式关怀
- [ ] 🟡 服务类动作是否「催促成交」而非「提供价值」？→ 先给价值再谈预约

**判断句**：一条内容发出去，用户感觉「被服务」还是「被收割」？被收割即不通过。

---

## 第十步：受众视角反应模拟（受众模拟）

**模拟方法（三问审查）：**
- [ ] 开头3秒：想划走 / 想继续看？（钩子真实性，拒绝标题党/恐吓式留人）
- [ ] 中段：产生信任 / 产生反感？（有没有「被收割感」「制造焦虑」）
- [ ] 读完后：想咨询 / 想收藏 / 无感 / 反感举报？

**检查项：**
- [ ] 🔴 是否引发「被制造焦虑/被恐吓」感？→ 改为中性健康提示
- [ ] 🟡 是否有「想试试/已收藏」的正向触发点？→ 若无，提示补强价值钩子
- [ ] 🟡 表达是否像「真人说人话」而非机构官方腔？→ 去AI化
- [ ] 🔴 是否尊重受众（无歧视/不消费苦难）？→ 尊严检查，命中即不通过

```markdown
**检查对象：** {标题/文件名}

**检查时间：** {YYYY-MM-DD HH:mm}

  - 「最好的」→ 建议改为「很多用户选择」

### 4. 去水印确认

### 5. 平台规则适配
- ✅ 公众号标题合规
- ⚠️ 抖音版本需替换敏感词

- ✅ 案例使用过程描述，无效果承诺
- ⚠️ 发现「治好了」表述 → 已改写为「观察到改善」

### 7. 画面与字幕合规

- ⚠️ 接受度预判：中（缺价值钩子）

### 📋 最终结论
- ✅ 通过（可直接发布）
- ⚠️ 条件通过（修改 {N} 处后可发布）
- 🔴 不通过（需重写或放弃发布）

修改项：{逐条列出需修改的内容和替换方案}
```

## 边界
- 只在内容产出后、发布前使用
- 不做图、不排版、不发布
- 广告法检查用内置违禁词框架，不需要 API Key
- 平台规则以当前已知为准，规则变化时更新本 Skill
- 医疗/金融/教育等行业内容，须额外叠加行业专属合规要求

**接入方式**：所有内容生产类 Skill 在输出最终内容前，**必须**先调用本 Skill 做合规检查。在内容生产 Skill 中加入以下代码块：

```markdown

- 命中 🔴 项（广告法违禁词/隐私泄露/前后对比图）→ 自动回改后重新生成
- 命中 🟡 项（格式/配图数量/去水印）→ 标注后继续，但需在产出末尾附合规报告摘要
- 通过 ✅ → 输出末尾自动附带「✅ 合规自检通过」
```

| 用户隐私泄露 | 阻止发布，强制脱敏 | — | 通过 |
| 前后对比图 | 阻止发布，必须删除 | — | 通过 |

| 平台敏感词 | 阻止发布，强制替换 | 标注，建议替换 | 通过 |
| 违规导流 | 阻止发布，强制删除 | 标注，建议调整 | 通过 |
