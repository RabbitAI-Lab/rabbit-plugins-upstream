# 小程序选题共创 · Skill

> 从「一个模糊的点子」到「可落地的产品技术规格 SOP」——用三步共创工作流，帮你把微信小程序想法推进到能直接开工的程度。

这是一个面向 **ClawHub / WorkBuddy** 的 AI Skill（技能包），不是小程序源码。它由 AI 充当「共创搭档」，用一套固定流程引导你完成选题、过筛、出方案，并附带两个完整的产品技术规格范本。

---

## 这个 Skill 能帮你做什么

- **把模糊点子逼出轮廓**：用联网搜索 + 提问，帮你扩大选题池、判断可行性。
- **三步 SOP 不跳步**：搜一波 → 呈现选题池逼你定方向 → 按三标准过筛出可执行方案。
- **给的是能开工的规格**：输出八节产品技术规格（定位 / 信息架构 / 界面 / 流程 / 存储 / 关键技术 / 合规 / 任务分解）。
- **踩坑预警**：命名含「AI」被拒、个人主体类目卡点、头部垄断核实、MVP 克制等真实经验内置其中。

> 注意：本 Skill 负责「选题 → 技术规格」，不负责写代码、调试、纯技术问答。

---

## 三步固定工作流（顺序不可跳）

| 步骤 | 动作 | 产出 |
|---|---|---|
| 1 · 搜一波 | 联网搜趋势 / 竞品 / 类目合规信号，扩大选题池 | 真实信号，而非臆测 |
| 2 · 锁方向 | 呈现选题池表格 + 点子初步判断，用提问逼你定方向（不替你拍板） | 锁定的方向 |
| 3 · 出方案 | 按三标准逐条过筛、揪问题、给可执行方案 / 规格 | 八节技术规格 + 确认门 |

### 内置选题方法论
- **三标准（每个点子必过）**：① 功能要单一 ② 使用场景要清晰 ③ 无明显头部垄断
- **五个已验证方向**：线下社交工具 / 各类计算器 / 行业垂直工具 / 节日场景工具 / 心理测试类

## 安装与使用

### 方式一 · ClawHub（推荐，全网一键装）
```bash
clawhub login
clawhub install miniprogram-topic-cocreation
```

### 方式二 · WorkBuddy 桌面端导入
打开 WorkBuddy → 技能管理 → 导入本地文件夹 → 选择本仓库根目录。

### 方式三 · 手动放置
把整个 `miniprogram-topic-cocreation/` 文件夹放到你的 skills 目录下即可。
