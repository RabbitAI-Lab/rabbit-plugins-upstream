## Description:

Helps ecommerce merchants, creative teams, and scaled content producers turn authorized reference videos, product assets, brand rules, audiences, and channel constraints into remake analysis, differentiated creative direction, shot-by-shot prompts, generation tasks, and acceptance checklists.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill to plan authorized short-video remakes for ecommerce, advertising, marketing, social commerce, and short-drama workflows. It produces reviewable creative briefs, scripts, prompts, runnable commands, task records, and quality checks before potentially paid AI-HIVE generation is submitted.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may upload media they do not have rights to use.

Mitigation: Confirm authorization before using reference videos, images, audio, logos, or product assets; otherwise limit output to abstract structure advice and new creative concepts.

Risk: Generation calls may cost money.

Mitigation: Review prompts, routing mode, model choice, and pricing snapshot before submitting jobs; run small samples before batch generation.

Risk: The workflow uses an AI-HIVE API key and can store it locally.

Mitigation: Use placeholders in shared examples, avoid committing keys or logs, and protect the local configuration file.

Risk: Broad activation wording could apply the skill to inappropriate remake requests.

Mitigation: Apply the documented boundaries for copyright, trademarks, privacy, real people, platform rules, and unsupported performance claims before producing executable steps.
