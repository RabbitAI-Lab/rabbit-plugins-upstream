## Known Risks and Mitigations:

Risk: Setup instructions include remote installer commands that can execute local code.

Mitigation: Review before installing and prefer official, verifiable, signed, or package-manager based installation steps for the oo CLI.

Risk: Authentication, connection, and setup workflows can change account state or expose the user to unintended sign-in actions.

Mitigation: Use the skill for read and list Recruit CRM tasks, and require separate explicit approval before setup, sign-in, connection, or write-capable workflows.
