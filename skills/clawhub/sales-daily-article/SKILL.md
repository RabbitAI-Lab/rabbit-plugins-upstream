# 销售干货日更流水线

一句话跑完：选题 → 查重 → 成文 → 合规自检 → 存盘 → 进全文库。

> 首次使用：告诉 AI 你的文章存放目录（如 你的常用文章目录），AI 会记住后续直接用。

| 说法 | 动作 |
|---|---|

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--line` | `销售` | 内容线：`销售`（默认）或 `防骗`。**由用户指定，不要自作主张切换** |

## 流程

### Step 1 · 选题（必须查重）

先扫描已有文章拿选题清单：遍历文章目录下所有 `.md`，提取每个文件的 `# ` 标题，按候选主题关键词统计命中（标题命中 或 正文命中 ≥2 次 = 该角度已被写过）。

选题规则：
1. 优先挑**库里没有的空白主题**
2. 同一角度换汤不换药的，视为撞题，重选
3. 一个角度被写过 2 次以上的（如复盘、心态、时间管理这类"大路货"），默认已写烂，不再碰
4. 选完先报给用户一句：`选题：xxx（库内无重复）`，再动笔

> 免费版靠人工扫标题避重，**只看得见标题撞车**，看不见"换个说法其实同一角度"的隐性撞题。付费版配选题查重脚本（切词块算重合度），能揪出肉眼看不出的重复。

### Step 2 · 成文

严格套用下方对应内容线的模板，**1000 字左右**（900–1100 均可）。

### 🚨 合规红线（成文后必自检）

自媒体账号被平台判违规是最大风险，以下五类一条都不许碰：

| 项 | 禁止 |
|---|---|
| **严格脱敏** | ❌ 真实产品名、真实客户名、真实公司名、逐字话术剧本、电话/微信等联系方式。一律抽象成"老陈/老王""某快消品""一位做建材的读者" |
| **不承诺收益** | ❌ "照做一定月入X万""保证成交""百分百有效"。改成"我自己是这么做的""不少人反馈有用" |
| **不踩人群** | ❌ 地域歧视、性别对立、职业贬低、煽动对立情绪 |
| **不碰敏感** | ❌ 时政、医疗疗效承诺、金融荐股、夸大宣传 |
| **时令一致** | ❌ 与当天真实月份不符的表述（"年底了""过年"）——必查 |

**自检动作（每篇必做，双重保险）：**
1. 机器查：按下表逐项扫描全文（明文联系方式、变体写法如"VX/绿泡泡/薇❤"、诱导话术"加我/私我/扣1领"、跨平台引导、疗效承诺、极限词"全网第一/行业第一/第一品牌"、医疗编造、真实信息脱敏）
2. 人工通读：抓机器查不到的语境问题（隐含的真实信息、指代可认出的真人）

命中就改掉再存盘，**禁止带着违规内容入库或发布**，也**禁止为过检删整段干货**——改写原文直到合规。

> 免费版逐项人工过；付费版配一键脱敏自检脚本（七类扫描：明文联系方式、变体写法、诱导话术、收益承诺、极限词、敏感领域、时令词冲突），直接报出违规位置。

### Step 3 · 存盘

文件名 `{文章目录}/YYYY-MM/aNNN.md`，NNN = 当前最大编号 + 1。
文件头统一用 YAML frontmatter：

```markdown
---
title: a262
date: 2026-08-30 早间
---

# 真实标题写这里
```

> `title` 字段填**编号**，不是真标题（全文库靠编号定位）。

### Step 4 · 入本地全文库

```bash
python "$SKILL_PATH/scripts/add_to_library.py" <文章.md路径>
```

脚本自动完成：读取 frontmatter → 转 HTML → 按日期**倒序**插入全文库 `</body>` 前（最新在顶）→ 更新"共 N 篇"。
全文库路径默认 `{文章目录}/文章全文库.html`，不存在会自动创建。

> ⚠️ 转换器限制（写稿时心里有数）：
> - 并列要点写成"行内加粗 + 分号连接"的一句话，不要用段内 `- ` 列表项（会残留破折号）
> - 独立成行的 `**xxx**` 会被转成 `<h3>`（不是 `<strong>`）

## 内容线 A · 防骗防坑

### 标题公式

```
[一句对话或场景钩子]"？[后果]——这3种[套路名]，专挑/专坑[人群]
```

实测样本：
- `"您的快递丢了，双倍赔"？客服一通电话，卡里钱没了——这3种冒充退款套路，专挑网购多的人`
- `小区门口"免费体检送鸡蛋"，转头让你花三千买了盒保健品？这3种会销套路，专坑家里老人`
- `兼职刷单"日赚300"？这3个套路，专挑想赚快钱的人`

### 正文骨架

```
第 1 段：场景代入，带引号的原话开场
第 2 段：说明严重性/高发时机 + 预告"说3种"

## 套路一：xxx
    场景描述（骗子怎么做，2-3 句）
    **怎么识别**：一句话点破破绽
    **怎么躲**：具体可执行的动作
    **关键点**：一句结论，可复用

## 套路二：xxx   （同上四段）
## 套路三：xxx   （同上四段）

## 三句话保命
1. **结论句**——补充说明
2. **结论句**——补充说明
3. **结论句**——补充说明

收尾段：一句金句 + "转给家里人（点名具体谁）" + 应急处置指引（96110 / 12315 / 110）
```

### 语气

第三人称客观科普，不出现第一人称人设。

## 内容线 B · 销售干货

### 标题公式

```
销售[场景/困境]，3 个[招数|雷区|问题][结果]
```

实测样本：
- `销售想离职，3 个真问题问完再决定走不走`
- `销售陪客户吃饭，3 个雷区踩 1 个客户再也不签单`
- `销售被客户骂完还笑脸相迎——3 步把"委屈"变成"复购"`

### 正文骨架

```
第 1 段：我做销售 {填你自己的年限} 年，+ 一个反直觉的观察
第 2 段：抛出本篇要解决的 3 个问题（加粗列点）
第 3 段：一句破折号金句 ——**核心判断**
第 4 段：今天讲"xxx"，学完你也能从'xx'变成'xx'

---

小标题段落 × 3（口语、带人物、有对话）
案例配角用通用化名：小张 / 小吴 / 李哥，带具体示意数字（月薪、年限、单数）
对话体：我问他："…"  他："…"

---

收尾：落到可执行的动作
金句收尾：一句"做销售久了你会发现……"
**互动钩子（必写）**：最后一段必须抛一个问题把人引到评论区，不能金句完就收。
    句式："你{碰上过/经历过}{本篇场景}吗？你是怎么{动作}的？评论区聊聊，我给您支两招。"
```

### 人设（脱敏模板，按自己的情况填）

- 第一人称 **"我做销售 {年限} 年"**，中性自称，**不绑定真实姓名 / 公司 / 电话 / 微信**
- 案例配角一律化名（小张 / 小吴 / 李哥），数据一律示意——文章不泄露隐私，发到任何平台都安全
- **中文与数字之间加空格**（`3 个雷区`、`2 年换过几家公司`）

> 付费版另含「常青选题库（60 个）」与「互动钩子库」，不用每天想写什么、结尾怎么抛问题。

## 硬性规则

| 规则 | 说明 |
|---|---|
| 篇幅 | **1000 字左右**，上限 1100 |
| 时令词 | ⚠️ 必须与当前日期一致（8 月的文章不能写"年底了"） |
| 加粗 | 防骗线：**怎么识别 / 怎么躲 / 关键点 / 三句话保命** 全部加粗。销售线：关键判断句加粗 |
| 英文数字空格 | 销售线加空格，防骗线不加 |
| 结尾 | 防骗线必须落到"转给家人 + 官方热线"；销售线必须落到"金句 + 评论区互动钩子"，只写金句算没写完 |
| 查重 | 选题前必扫全库，撞角度就换题 |
| 合规 | 每篇过完合规自检（机器 + 人工）才算完成 |
