# 风水堪舆 · 环境布局

> 初五数智出品 | 命理系列

## 功能

风水是研究人与环境关系的学问：

1. **家居风水**：
   - 大门/客厅/卧室/厨房/卫生间布局
   - 财位定位与催财方法
   - 文昌位定位与学业布局
   - 桃花位定位与感情布局
2. **办公室风水**：
   - 办公桌朝向
   - 领导办公室位置
   - 公司大门朝向
3. **户型分析**：
   - 缺角判断与化解
   - 门冲/穿堂煞/横梁压顶等常见问题
4. **择日搬家**：搬家/入宅/安床择吉

## 使用方式

「我家大门朝南，客厅在北面，帮我看看风水」
「我办公室坐西朝东，摆什么植物好？」
「这个户型图帮我分析一下（附图）」

## 温馨提示

风水布局是环境优化建议，仅供参考。重大装修决策请结合实际情况。
