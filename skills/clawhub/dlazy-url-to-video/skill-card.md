## Description:

Turns a supplied website URL into a promotional, advertising, or product-demo video using dLazy's hosted service.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and marketers provide a website URL to produce a promotional video, social ad, or product demo with brand styling, storyboard, and voiceover.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts, URLs, project context, and attached files may be sent to dLazy's hosted service.

Mitigation: Share only necessary information and avoid attaching private files unless required for the video task.

Risk: Using the CLI involves installing a package and may store an API key locally.

Mitigation: Review the pinned CLI package before installation and protect the local API key.
