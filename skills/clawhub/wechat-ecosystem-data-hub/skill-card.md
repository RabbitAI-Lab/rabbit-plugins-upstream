## Known Risks and Mitigations:

Risk: The skill stores the 曼格云 API key in config.json as plaintext.

Mitigation: Use a dedicated, revocable API key and remove or rotate it when the skill no longer needs access.

Risk: Local file paths may be uploaded to the remote service for supported media workflows.

Mitigation: Pass local file paths only when the user explicitly wants those files uploaded, and review files for sensitive content first.

Risk: The documented endpoint list is broader than the current executable capability observed in the release evidence.

Mitigation: Verify the available endpoints with the script before promising data access beyond account balance lookup.

Risk: Bundled __pycache__ files are included in the artifact.

Mitigation: Review or remove generated bytecode files before deployment if source-only distribution is required.
