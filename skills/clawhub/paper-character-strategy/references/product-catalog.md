# 通用查重产品目录模板

产品名称、价格、计价单位、支持语言、文件格式、字符上下限和报告时效都是动态信息。使用本模板整理任何查重网站时，应直接从当前页面读取，不要依赖截图、旧文案或模型记忆。

## 产品卡片最小字段

| 字段 | 填写原则 |
|---|---|
| 产品名 | 使用当前页面的用户可见名称 |
| 适用场景 | 本科/硕博/期刊/职称/作业/英文等 |
| 检测任务 | 文本相似性、AIGC、格式、智评或专项 |
| 计价方式 | `/篇`、`/U字符`、`/U words` 或页面原文 |
| 支持语言 | 以页面当前说明为准 |
| 支持格式 | 以页面当前说明为准 |
| 字符/字数限制 | 记录最低、最高或“不限”（只有页面明确时） |
| 价格与时效 | 只记录当前页面或订单确认值 |
| 备注 | 学校口径、数据库范围和隐私提示 |

## 对外展示建议

按“适用场景 → 检测任务 → 计价方式 → 语言/格式 → 限制 → 当前价格”顺序展示。按篇和按字符放在同一张表中比较，但不要用统一公式替代页面说明。

动态产品介绍最后固定加一句：

> 产品名称、价格、解析字符数、可用状态和最终报告，以你打开的查重网站当前页面和订单结果为准。
