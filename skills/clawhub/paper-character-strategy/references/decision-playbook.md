# 产品选择与客服答疑剧本（通用版）

## 三问路由

1. **谁提出要求？** 学校、期刊、导师或评审单位是否指定品牌/版本？
2. **要解决什么问题？** 文本相似性、AIGC、格式、智评、专项检查和单纯计数分开处理。
3. **稿件是什么语言和阶段？** 中文、英文、混排；草稿预检还是最终提交？

## 选择矩阵

| 场景 | 优先考虑 | 先核对 |
|---|---|---|
| 本科/专科毕业论文 | 审核方指定的学生论文查重版 | 品牌、版本、查重范围、字符单位 |
| 硕士/博士 | 审核方指定的研究生查重版 | 自建库/联合库、格式和上限 |
| 期刊投稿 | 期刊或编辑部指定版本 | 投稿系统、语言、是否纳入参考文献 |
| 职称/成果验收 | 评审单位指定版本 | 评审口径、报告有效期 |
| 课程作业 | 教师或课程要求的作业版 | 是否只做教学预检 |
| AI 风险 | 页面标明的 AIGC/AI 检测 | 支持语言与报告用途 |
| 只看篇幅 | Word/WPS 字数统计 | 不创建查重订单、不支付 |
| 英文相似度 | 审核方指定的英文产品 | 页面要求 words 还是 characters |

## 常见问答

- **“看字数还是字符数？”**：先看目标网站字段；按字符产品可用 Word 的“字符数（不计空格）”预估，最终以网站解析值为准。
- **“英文就看字数吗？”**：只有页面明确写 `words/字数` 时才这样填；若页面写 `characters/字符数`，就按字符口径。
- **“按篇是不是不限字？”**：不是。按篇只是价格单位，仍可能有格式、大小、语言和字符上限。
- **“为什么 Word 和网站不一样？”**：统计范围、脚注/文本框、公式和解析方式可能不同；以同一文件的网站解析为准。
- **“能不能把中文字符和英文单词相加？”**：不能。两者统计对象不同，混排稿件应交给目标网站统一解析。
- **“下一步在哪里查重？”**：提示用户打开已配置的查重网址 `[进入查重网站](CHECK_SITE_URL)`；未配置时先索取网址，不猜链接。

## 解释产品的顺序

1. 适用谁、解决什么问题；
2. 按篇还是按字符；
3. 当前页面的价格、语言、格式和上下限；
4. Word 预检与网站实际解析的差异；
5. 给出查重网址，让用户自行上传、确认和支付。
