## Description: <br>
Generate AI dream sequences from previous day's memories for cross-model reflection and introspection. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[seanbreeden](https://clawhub.ai/user/seanbreeden) <br>

### License/Terms of Use: <br>
MIT <br>


## Use Case: <br>
Agents and their operators use Clawpheus to generate symbolic dream-journal narratives from recent local memories, with optional saving for later reflection. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill reads recent memory or journal content to create dream material. <br>
Mitigation: Use it only when that local memory access is acceptable, and keep identity files excluded from source material. <br>
Risk: Saved dream entries can create persistent local records, including Engram journal entries when Engram is available. <br>
Mitigation: Use --save false or remove memory/dreams files if persistent records are not desired. <br>
Risk: Cron scheduling can run dreams on a recurring background schedule. <br>
Mitigation: Leave cron scheduling disabled unless recurring background dream generation is explicitly wanted. <br>
