## Use Case:

External founders, product marketers, growth teams, and developers use this skill to turn product and market inputs into practical GTM guidance: ICP definition, positioning, motion and channel selection, pricing offers, metrics, and a 90-day execution plan.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill asks for read, write, and command execution capabilities that are broader than needed for GTM planning.

Mitigation: Run it in an environment where file writes and command execution are restricted or require explicit approval.

Risk: The skill mentions API key configuration and can be used with sensitive business inputs.

Mitigation: Avoid providing API keys, credentials, or confidential business files unless the workflow is narrowed and access is necessary.

Risk: GTM recommendations can become inaccurate as market conditions, channels, pricing, and customer behavior change.

Mitigation: Validate the plan with current customer research, analytics, and periodic review before execution.
