## Description:

Photorealistically refine wedding venue photos, including drapery, florals, crystal lighting and sculptural installations.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and creative production teams use this skill to refine wedding venue photos while preserving the original composition, decor, floral details, lighting direction, perspective, and material fidelity.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill uses image-editing tools on user-provided photos.

Mitigation: Confirm the user intends to edit the supplied wedding venue image and avoid loading unrelated photos or reference assets by default.

Risk: The optional close-up reference file mentioned by the artifact is not included.

Mitigation: Treat close-up or new-camera-angle guidance as unavailable unless the missing reference is supplied or the user gives explicit direction.
