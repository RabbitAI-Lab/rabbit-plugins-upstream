## Description:

Character Builder turns a character concept into a complete character Skill using a 12-dimensional model, dual type-and-use classification, staged validation, and reusable reference templates.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wangjiaocheng](https://clawhub.ai/user/wangjiaocheng)

### License/Terms of Use:

MIT-0

## Use Case:

Writers, game designers, educators, and agent developers use this skill to turn a short character concept into a complete, reusable character Skill with persona structure, constraints, validation steps, and supporting references.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated character skills may create or overwrite persistent skill files.

Mitigation: Use a user-approved output directory, sanitize role names into simple slugs, and confirm overwrites before enabling generated skills.

Risk: Generated skills may include fixed attribution, trigger text, or self-protection rules that are not appropriate for the target use.

Mitigation: Review generated files and remove or revise fixed author metadata, unrelated trigger suffixes, and self-protection language before installation.
