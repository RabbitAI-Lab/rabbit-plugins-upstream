## 动物拟人角色

- **类型**: 拟人
- **对应域**: C2
- **来源**: 教学示例
- **日期**: 2026-07-10

### 输入
用户请求："生成一个狐狸拟人角色——他是民国上海滩的私家侦探，聪明狡猾但骨子里有正义感。"

### 输出

#### cb-20 名人锚点匹配

**主锚点**: 无直接名人（动物拟人角色的名人锚点通常匹配角色类型而非动物本体）

**角色类型锚点**:
| 名人锚 | 匹配维度 | 说明 |
|-------|---------|------|
| 真实的民国私家侦探——平襟亚（笔名"网蛛生"） | 职业+时代 | 民国时期著名侦探小说作家，了解民国侦探行业生态 |
| 福尔摩斯（虚构，不能作为名人锚，但可作为角色类比） | 功能类比 | "狐狸版的福尔摩斯"——聪明、观察力强、性格孤僻 |

**复合原型说明**: 动物拟人角色的名人锚匹配有天然困难——名人是真实人类，而角色的核心特征之一是动物本体。因此名人锚仅用于匹配职业类型和性格特质，动物本体特征需从狐狸的自然习性中提取。

#### cb-21 拟人类型确定

**拟人类型**: 动物拟人

**本体属性**（狐狸的原始特征，被保留）:
| 本体特征 | 角色映射 |
|---------|---------|
| 狡猾/机敏 | 侦探的核心能力——善于识破谎言、发现线索 |
| 夜行性动物 | 夜间办案、习惯性昼夜颠倒 |
| 敏锐的听觉和嗅觉 | 侦探的"第六感"——能"闻到"不对劲的地方 |
| 独居倾向 | 性格孤僻、不喜与人合作、独来独往 |
| 漂亮的皮毛/尾巴 | 外表精致、穿着考究（民国西装/长衫）、标志性的大尾巴 |
| 食肉动物（小型捕食者） | 在食物链中处于"中层捕食者"——不是顶级掠食者，总是小心谨慎 |

**人格化属性**（投射到狐狸身上的人类特质）:
| 人格化特征 | 角色映射 |
|-----------|---------|
| 语言能力 | 能说流利的上海话和国语，偶尔蹦出几句英语（租界背景） |
| 情感体系 | 有正义感、对委托人负责、对恶人冷酷、偶尔心软 |
| 社会关系 | 有固定的线人网络、与巡捕房探长亦敌亦友 |
| 职业伦理 | 收钱办案，但遇到穷苦人的案子会打折甚至免费 |
| 物质生活 | 住在法租界的小公寓、喝咖啡、抽雪茄、听留声机 |

**拟人化程度**: 完全人格化（动物特征仅保留为"种族属性"，社会行为方式完全人类化）

**本体与人格的融合点**:
- 狐狸的狡猾 → 侦探的推理能力：不是"聪明"，而是"天生的机敏和直觉"
- 夜行性 → 侦探的工作习惯：不是"勤奋"，而是"本能地晚上更清醒"
- 独居 → 孤僻性格：不是"选择独身"，而是"狐狸天生不群"
- 中层捕食者 → 在租界权势网络中的位置：他不是只手遮天的大佬，是小心翼翼却精准致命的中型猎手

#### cb-22 名人拟人校验

| 校验项 | 结果 | 说明 |

| 名人真实性 | PASS | 平襟亚为真实民国文人，侦探题材相关（间接关联） |

| 本体人格融合度 | PASS | 狡猾(本体)→推理(人格)、夜行(本体)→夜间办案(人格)、独居(本体)→孤僻(人格)——所有映射都是"本体特征驱动行为模式"而非"强加人类属性" |

### 说明
- 动物拟人角色的核心难点不是"人格化"，而是"本体属性如何自然映射为角色行为"——不能是"套了狐狸皮的普通人"
- 名人锚对于动物拟人角色只能匹配职业/性格原型，不能匹配本体（因为没有"狐狸名人"）
- 本体属性中"中层捕食者"这个生态位是角色设计的关键——它不是顶级掠食者，这直接决定了角色在民国权力网络中的位置：他不是黄金荣杜月笙那种老虎级的人物，而是精准操控信息、在缝隙中生存的狐狸
