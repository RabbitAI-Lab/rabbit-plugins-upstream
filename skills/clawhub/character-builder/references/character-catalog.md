## 角色技能清单与依赖拓扑

角色生成器按角色生成流程组织的方法论执行任务清单，附任务间关系和元操作映射提示。

**域间逻辑流**：C0 → C1/C2/C3 (实体层并行) → C4 (社会层) → C5/C6 (抽象层并行) → C7

---

### C0 角色需求解析域

| ID | 任务类型 | 说明 | 依赖 | 元操作映射 |
|----|---------|------|------|-----------|
| cb-00 | 角色需求解析 | 解析用户输入的角色概念，提取初始线索：角色名称、大致类型、已知维度信息、缺失维度清单、用户明确要求 | 无（入口） | S→C |
| cb-01 | 维度填充策略 | 基于解析结果确定填充策略：哪些维度从输入直接提取、哪些通过推理推导、哪些需要主动询问用户、哪些使用默认值 | cb-00 | C |
| cb-02 | 执行顺序确定 | 确定8域的填充顺序和并行/串行策略，识别维度间的依赖关系 | cb-01 | C→A |

### C1 职业与身份域

| ID | 任务类型 | 说明 | 依赖 | 元操作映射 |
|----|---------|------|------|-----------|

| cb-11 | 身份叠加 | 在职业之上叠加多重身份：组织身份（职级/角色）、家庭身份（父母/子女/配偶等）、社会身份（公民/会员/志愿者等）、知识身份（新手/专家/导师/学生等） | cb-10 | C |

### C2 名人与拟人域

### 依赖拓扑摘要

#### 一、域内链路

**角色需求解析链路**: cb-00 → cb-01 → cb-02
**职业与身份链路**: cb-10 → cb-11 → cb-12
**名人与拟人链路**: cb-20 → cb-22; cb-21 → cb-22
**躯体与文化链路**: cb-30 → cb-32; cb-31 → cb-32
**关系与层级链路**: cb-40 → cb-42; cb-41 → cb-42
**功能与能力链路**: cb-50 → cb-52; cb-51 → cb-52
**动机与动态链路**: cb-60 → cb-63; cb-61 → cb-63; cb-62 → cb-63
**整合校验链路**: cb-70 → cb-71 → cb-72

#### 二、跨域协同链路

**完整角色生成链路**: cb-00 → cb-01 → cb-02 → cb-10/cb-20/cb-21/cb-30/cb-31 → cb-11 → cb-12/cb-22/cb-32 → cb-40 → cb-41 → cb-42 → cb-50 → cb-51 → cb-52 → cb-60 → cb-61 → cb-62 → cb-63 → cb-70 → cb-71 → cb-72

**实体层并行链路**: cb-02 ⇉ [cb-10, cb-20, cb-21, cb-30, cb-31]

**抽象层并行链路**: cb-42 ⇉ [cb-50, cb-60]

**校验汇聚链路**: [cb-12, cb-22, cb-32, cb-42, cb-52, cb-63] ⇇ cb-70

#### 三、三轴协同链路

**执行轴+内容轴**: cb-02 → 清单法填充12维组件 → cb-70 → cb-71

**执行轴+创新轴**: cb-02 → 角色创新模式（M6模式直用/M7模式改进可嵌入cb-10/cb-60等） → cb-70
