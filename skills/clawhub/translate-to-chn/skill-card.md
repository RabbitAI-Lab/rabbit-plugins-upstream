## Description:

Translate a specifically requested article from ai-thoughts/docs/ into Simplified Chinese and write a matching -chn.md Markdown file after user confirmation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[j3ffyang](https://clawhub.ai/user/j3ffyang)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, writers, and documentation maintainers use this skill to translate one explicitly selected Markdown article into Simplified Chinese while preserving source structure, links, code, commands, and technical terms.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can read a selected source article and write a translated Markdown file, so an incorrect source or destination path could produce an unintended file or overwrite request.

Mitigation: Confirm the exact source article and output path before writing, and require explicit user approval before overwriting any existing -chn.md file.
