# Xiaohongshu Copywriting Guide — 小红书文案写作指南

This file provides platform-compliant copywriting strategies for crystal-themed Xiaohongshu notes. Load this for every note to ensure compliance, readability, and engagement.

---

## Platform Compliance Rules (平台合规规范)

### Core Principle

小红书对玄学、占卜、算命类内容有严格的内容审核机制。水晶内容如果被判定为"封建迷信"或"夸大功效"，会被限流甚至下架。

**安全定位:** 将水晶内容定位为"生活美学 + 文化分享 + 个人体验"，而非"功效承诺"或"命运改变"。

### Compliant Framing Patterns

| ❌ Non-Compliant | ✅ Compliant Alternative |
|------------------|------------------------|
| 这条手串能转运 | 这条手串陪我调整状态 |
| 戴了招财 | 感觉气场都明亮了 |
| 辟邪挡灾 | 帮我建立气场的边界感 |
| 旺桃花 | 让气场更柔和开放 |
| 开光过的 | 净化养护过的 |
| 改变运势 | 调整能量状态 |
| 灵验/有效果 | 个人体验分享 |

### Safe Expression Framework

All content should be framed as:
- **个人体验** (personal experience) — "我觉得""我的感受是"
- **文化分享** (cultural appreciation) — "在水晶文化中""传统认为"
- **情绪陪伴** (emotional companion) — "陪伴""支持""状态调整"
- **美学欣赏** (aesthetic appreciation) — "好看""质感""搭配"

Never frame as:
- 功效承诺 (efficacy guarantee)
- 医疗效果 (medical effect)
- 命运改变 (destiny alteration)
- 超自然力量 (supernatural power)

### Mandatory Disclaimer Elements

Notes should naturally include soft disclaimers:
- "水晶更多是一种陪伴和自我提醒"
- "每个人感受不同，选自己有眼缘的就好"
- "个人体验分享，理性看待"

## Title Formulas (标题公式)

### Formula 1: Pain Point + Curiosity (痛点+悬念)
```
[常见错误/困惑]？[反转/悬念]
```
Examples:
- 水晶戴了3个月没感觉？可能从一开始方向就错了
- 粉晶不是越粉越好！新手第一个要知道的真相
- 手串戴左手还是右手？90%的人戴反了

### Formula 2: Value Front-loading (干货前置)
```
[N个知识点/避坑指南]｜[主题]
```
Examples:
- 新手必看｜紫水晶的5个真相和3个避坑
- 一篇讲透｜粉晶到底怎么选怎么戴
- 干货收藏｜6种常见水晶气场适配表

### Formula 3: Emotional Resonance (情绪共鸣)
```
[温柔感受]＋[水晶意象]
```
Examples:
- 那些温柔的日子，是紫水晶陪我走过的
- 当你觉得气场低沉，试试这颗小太阳
- 不是所有治愈都来自言语，有时是一颗粉晶

### Title Rules
- 理想长度：15-20个字
- 必须包含一个关键词（水晶名/品类名）
- 禁止使用限流词
- 善用｜、！？、等小红书风格标点
- 数字比文字更有吸引力（3个、90%、5种）

## Engagement Optimization (互动优化)

### Opening Hook Techniques

1. **痛点共鸣法** — 直接戳中读者的困惑
   - "是不是买了水晶戴几天就放抽屉了？"

2. **反常识法** — 打破读者固有认知
   - "越贵的水晶不一定越适合你"

3. **数字法** — 用数字制造确定性
   - "新手入坑前必须知道的5件事"

4. **场景代入法** — 描绘读者熟悉的场景
   - "加班到深夜，摘下手串那一刻突然很安心"

### Comment-Inducing Questions (引导评论的话术)

Place at the end of Part 4, choose one that fits:
- "你现在戴的是哪颗？评论区聊聊～"
- "姐妹们第一颗水晶是什么？还记得吗？"
- "你觉得哪颗水晶和你最同频？来评论区对暗号"
- "有踩过什么水晶坑吗？评论区互相避雷呀"

### Save-Inducing Structure (引导收藏的结构)

To make readers want to save the note:
- Include a "收藏备用" or "先码后看" cue
- Structure knowledge points as a clear list (①②③)
- Include a summary table or checklist if possible
- End Part 3 with "建议收藏慢慢看"

### Structure for Readability

- **短段落:** 每段不超过3行
- **留白:** 段落之间空一行
- **符号引导:** 用 ① ② ③ 或 emoji 增加视觉层次
- **加粗关键:** 核心概念用【】或加粗标注
- **总字数:** 400-600字为宜，太长掉完读率

## Tag Strategy (标签策略)

### Tag Selection Principles

1. **大词+小词搭配** — 大词引流，小词精准
2. **主题词+场景词** — 水晶名 + 使用场景
3. **合规词优先** — 所有标签必须不含限流词

### Standard Tag Pool (Compliant)

**品类大词:**
```
#水晶 #水晶手串 #天然水晶 #水晶入门 #水晶日常
```

**知识型小词:**
```
#水晶知识 #水晶避坑指南 #新手水晶 #水晶怎么选
```

**合规玄学词:**
```
#气场 #能量 #调频 #同频 #气场匹配 #能量补缺 #情绪稳定
```

**场景词:**
```
#水晶搭配 #日常穿搭 #OOTD #生活美学
```

**水晶专属词 (举例):**
```
#紫水晶 #粉晶 #黄水晶 #白水晶 #黑碧玺 #茶晶
```

### Tag Count

- 每篇8-15个标签
- 前5个放核心标签（品类+主题）
- 后面放场景和长尾标签
- 不要堆砌超过20个，会被判定刷标签

## Emoji Usage Guide (Emoji使用指南)

### Recommended Emojis (Safe & Warm)

🌿 ✨ 🌙 💧 🌸 🔮 🤍 🌰 🍃 💫 🕯️ ☁️

### Usage Rules
- 每段最多1-2个emoji
- Emoji在句末或段首，不要嵌入句中
- 选择与内容气质一致的（温柔系：🌿🌸🌙；能量系：✨💫）
- 避免过度使用，保持干净质感

## Formatting Best Practices (排版要点)

### Line Break Strategy
- 每个知识点之间空一行
- 每段2-3行就换段
- 列表项之间不空行，列表整体前后空行

### Emphasis Techniques
- 【关键词】— 用方括号标注核心概念
- **加粗** — 关结论加粗
- ① ② ③ — 用圆圈数字引导知识点
- — （破折号）— 用于解释说明

### Length Guidelines
- 总字数：400-600字
- Part 1 开篇：30-60字
- Part 2 认知：50-80字
- Part 3 干货：150-250字
- Part 4 结尾：40-70字
- Part 5 标签：8-15个

## Common Copywriting Mistakes to Avoid

1. **开头太平淡** — "今天来聊聊紫水晶" → 没有钩子，划走率极高
2. **知识太密集** — 一段塞5个知识点 → 读者消化不了，完读率低
3. **缺乏互动引导** — 结尾没有问题 → 评论少，笔记权重低
4. **标签太多太乱** — 堆20个不相关标签 → 被判定刷标签
5. **用词不合规** — 出现限流词 → 直接限流，前功尽弃
6. **没有个人体验** — 纯知识搬运 → 缺乏温度，不触发共鸣
7. **结尾太生硬** — "以上就是分享" → 没有情感落点
8. **忽略排版** — 密密麻麻一大段 → 手机端阅读体验差
