## Structure Pattern Summary

Notice how each example follows the same five-part flow:

1. **开篇** — Names a relatable beginner mistake about THAT specific crystal
2. **认知** — States the core matching principle specific to that crystal
3. **干货** — 5 knowledge points with crystal-specific details (五行, wearing logic, pitfalls)
4. **结尾** — Warm closing + a comment-inducing question
5. **标签** — Crystal-specific tags + standard compliant tags

The structure stays constant; the content adapts to the crystal. This is the pattern to follow for any crystal theme the user provides.
