# Crystal Knowledge Database — 水晶知识库

This file contains detailed, accurate information about common crystals for use in Xiaohongshu copywriting. All information is framed in compliant language (气场/能量/调频), avoiding any restricted terms.

---

## Five Elements (五行) Quick Reference

The Five Elements system (金木水火土) is used to match crystals to a person's energy state. This is the core of "气场匹配" (aura matching).

| Element (五行) | Character | Suitable For |
|----------------|-----------|--------------|
| 金 (Metal) | 收敛、凝聚 | 需要专注、决断、气场稳固的人 |
| 木 (Wood) | 生长、舒展 | 需要活力、行动力、状态焕新的人 |
| 水 (Water) | 流动、智慧 | 需要情绪流动、灵感、松弛感的人 |
| 火 (Fire) | 温热、活跃 | 需要热情、表达力、气场提亮的人 |
| 土 (Earth) | 稳定、承载 | 需要踏实、安全感、情绪稳定的人 |

## Crystal Database (20+ Crystals)

### 1. 紫水晶 (Amethyst)

- **五行:** 火
- **颜色:** 浅紫至深紫
- **气场特质:** 温润、内敛、助静心
- **适合状态:** 思绪过多、入睡困难、需要专注时
- **佩戴逻辑:** 左手佩戴（接收能量），睡前可放枕边
- **能量补缺方向:** 补"静"——帮助从浮躁回到沉静
- **新手避坑:** 紫水晶怕暴晒，颜色会变淡；不要和硬度更高的宝石混放

### 2. 粉晶 (Rose Quartz)

- **五行:** 火
- **颜色:** 淡粉至玫瑰粉
- **气场特质:** 柔和、温暖、开放
- **适合状态:** 心轮紧闭、不愿表达情感、气场需要柔和时
- **佩戴逻辑:** 左手佩戴，靠近心脏位置效果更明显
- **能量补缺方向:** 补"柔"——软化气场中过于坚硬的部分
- **新手避坑:** 市场染色粉晶很多，天然粉晶颜色偏淡，过艳要警惕

### 3. 黄水晶 (Citrine)

- **五行:** 土
- **颜色:** 浅黄至金黄
- **气场特质:** 温暖、明亮、丰盛感
- **适合状态:** 缺乏自信、状态低迷、需要气场提亮时
- **佩戴逻辑:** 左手佩戴，日常可常戴
- **能量补缺方向:** 补"暖"——提升气场的明亮度和信心感
- **新手避坑:** 天然黄水晶稀少，大部分是紫水晶加热处理或合成，价格过低要警惕

### 4. 白水晶 (Clear Quartz)

- **五行:** 金
- **颜色:** 透明无色
- **气场特质:** 纯净、通透、放大
- **适合状态:** 需要清晰思考、气场需要净化时
- **佩戴逻辑:** 可左右手佩戴；常作为"放大器"搭配其他水晶
- **能量补缺方向:** 补"净"——帮助清理杂乱气场
- **新手避坑:** 白水晶是入门首选，但要选通透少棉絮的；染色冒充其他水晶的情况多

### 5. 茶晶 / 烟晶 (Smoky Quartz)

- **五行:** 土
- **颜色:** 浅棕至深棕黑
- **气场特质:** 沉稳、厚重、扎根
- **适合状态:** 情绪波动大、感到漂浮不踏实、需要安全感时
- **佩戴逻辑:** 右手佩戴（释放负面状态）
- **能量补缺方向:** 补"稳"——增强气场的安全感和稳定性
- **新手避坑:** 茶晶颜色深浅天然有别，不要误以为越深越好

### 6. 黑碧玺 (Black Tourmaline)

- **五行:** 水
- **颜色:** 黑色
- **气场特质:** 屏蔽、吸收、净化
- **适合状态:** 气场容易被影响、人多场合不适、需要边界感时
- **佩戴逻辑:** 右手佩戴（排出浊气）
- **能量补缺方向:** 补"护"——帮助建立气场的边界
- **新手避坑:** 黑碧玺常和黑曜石混淆；碧玺有压电性，摩擦可吸灰尘

### 7. 黑曜石 (Obsidian)

- **五行:** 水
- **颜色:** 黑色，有时带彩虹眼
- **气场特质:** 强力吸收、净化、深沉
- **适合状态:** 气场需要大扫除、状态低谷、需要深度清理时
- **佩戴逻辑:** 右手佩戴；不建议长期不间断佩戴，需定期净化
- **能量补缺方向:** 补"清"——深度清理气场中的浑浊
- **新手避坑:** 黑曜石能量偏刚，敏感体质建议从短时间佩戴开始；彩虹眼黑曜石品质更高

### 8. 草莓晶 (Strawberry Quartz)

- **五行:** 木
- **颜色:** 透明带红色斑点
- **气场特质:** 清新、甜美、活力
- **适合状态:** 气场需要提亮、想要增加亲和力时
- **佩戴逻辑:** 左手佩戴
- **能量补缺方向:** 补"甜"——增加气场的亲和与愉悦感
- **新手避坑:** 天然草莓晶产量少，很多是红东陵冒充

### 9. 石榴石 (Garnet)

- **五行:** 火
- **颜色:** 深红至酒红
- **气场特质:** 温热、有力、补血气感
- **适合状态:** 气场偏冷、手脚冰凉、需要温暖能量时
- **佩戴逻辑:** 左手佩戴
- **能量补缺方向:** 补"热"——增强气场的温度和活力
- **新手避坑:** 石榴石颜色越红润越好，发暗的品质较差

### 10. 海蓝宝 (Aquamarine)

- **五行:** 水
- **颜色:** 浅蓝至海蓝
- **气场特质:** 清凉、流动、沟通
- **适合状态:** 表达不畅、沟通受阻、需要松弛感时
- **佩戴逻辑:** 喉轮附近佩戴（项链）或左手
- **能量补缺方向:** 补"流"——帮助气场恢复流动和表达
- **新手避坑:** 海蓝宝多棉裂，完全干净的可能不是天然

### 11. 月光石 (Moonstone)

- **五行:** 水
- **颜色:** 乳白带蓝光
- **气场特质:** 柔和、直觉、阴性能量
- **适合状态:** 过于理性僵硬、需要柔软和直觉力时
- **佩戴逻辑:** 左手佩戴
- **能量补缺方向:** 补"柔"——增加气场的包容和柔软度
- **新手避坑:** 月光石的蓝光效应是关键，无蓝光的品质较低

### 12. 太阳石 (Sunstone)

- **五行:** 火
- **颜色:** 橙红带金色闪光
- **气场特质:** 明亮、积极、阳性能量
- **适合状态:** 状态低迷、缺乏动力、需要气场提亮时
- **佩戴逻辑:** 左手佩戴
- **能量补缺方向:** 补"光"——增强气场的明亮和积极性
- **新手避坑:** 太阳石的金砂闪光越多越好，暗淡的品质差

### 13. 发晶 (Rutilated Quartz)

- **五行:** 金
- **颜色:** 透明带金/银/黑发丝
- **气场特质:** 聚焦、放大、财运感
- **适合状态:** 需要决断力、聚焦目标、气场需要加固时
- **佩戴逻辑:** 左手佩戴
- **能量补缺方向:** 补"聚"——增强气场的凝聚和聚焦力
- **新手避坑:** 发晶以发丝顺、密、亮为佳；发丝杂乱的品质低

### 14. 绿幽灵 (Green Phantom Quartz)

- **新手避坑:** 绿幽灵以内含物形态清晰、层次分明为佳

### 15. 紫黄晶 (Ametrine)

- **颜色:** 紫黄双色

### 16. 青金石 (Lapis Lazuli)

- **新手避坑:** 青金石以少白纹、金色分布均匀为佳

### 17. 红纹石 (Rhodochrosite)

## Wearing Logic Summary (佩戴逻辑总则)

### Left vs Right Hand

- **左手 = 接收 (Receive):** 佩戴吸收型水晶（紫水晶、粉晶、黄水晶、白水晶等），帮助接收和补充能量
- **右手 = 释放 (Release):** 佩戴释放型水晶（黑碧玺、黑曜石、茶晶等），帮助排出和净化浊气

### How Many at Once

- 新手建议一次只戴1-2条，感受清楚再叠加
- 多条叠加可能气场互相干扰，反而混乱
- 白水晶可作为"放大器"搭配其他水晶

### Crystal Care (净化养护)

- **月光净化:** 满月夜放窗台，柔和净化
- **晶簇净化:** 放白水晶簇上， overnight
- **清水冲洗:** 流水冲洗30秒（注意：有些水晶怕水，如青金石）
- **避免:** 暴晒、化学清洁剂、高温、硬物碰撞

### Cleansing Frequency

- 经常佩戴：每周净化1次
- 刚入手：先净化再佩戴
- 状态低谷期佩戴后：及时净化

## Common Beginner Pitfalls (新手常见误区)

1. **盲目追求贵和稀少** — 昂贵不代表适合，气场匹配才是关键
2. **一次戴太多** — 能量互相干扰，反而消耗气场
3. **不分左右手** — 接收和释放搞混，效果打折
4. **从不净化** — 水晶佩戴后吸附气场浊气，需要定期清理
5. **只看外观** — 颜色好看但五行不匹配，事倍功半
6. **跟风入坑** — 别人说好就买，不了解自己状态需求
7. **期待立竿见影** — 水晶是陪伴，不是速效药，需要时间同频
8. **混戴相克水晶** — 比如黑曜石和粉晶同戴，一收一放可能互相抵消
