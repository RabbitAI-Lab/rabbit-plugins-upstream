## Description:

Convert text to speech using MiniMax Speech 2.8 via WaveSpeed AI, in two versions with the same inputs - HD (minimax/speech-2.8-hd) and Turbo (minimax/speech-2.8-turbo, lower price). Supports up to 10,000 characters per request, hundreds of system voices across 40 languages plus trained voice-clone IDs, emotion, speed, volume and pitch control, pause markers, interjections such as (laughs), a pronunciation dictionary, and mp3 / wav / pcm / flac output. Use when the user wants to generate speech audio or a voiceover from text with MiniMax Speech 2.8.

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: Text sent for speech generation may include information the user is not authorized to share; service data-retention practices were not audited.

Mitigation: Submit only text authorized for sharing with WaveSpeed AI, and review applicable service terms for retention details.

Risk: Speech generation is billed by text length, so requests can incur costs.

Mitigation: Check generation costs or estimate the request price before submitting it.

Risk: Using the CLI or MCP package introduces local software and permission considerations.

Mitigation: Prefer reviewed, pinned package versions and restrict local package permissions.
