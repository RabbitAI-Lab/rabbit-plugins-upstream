## 初衷

> **真正干活的人，往往写不出交底书。**

方案是自己想的，代码是自己敲的，实验是自己做的。轮到交底书，却卡在格式、卡在附图、卡在「这个点到底算不算创新」。拖着拖着，项目结题了，专利也就没了。

这个 Skill 做的是：**把你手上已有的东西读一遍，写成一份代理人拿到就能用的交底书**。缺的信息按行业通行做法补上；系统推导和待补充的地方在核对说明里逐条列出，交给代理人之前你能一条条核对。

## 能做什么

### 材料齐的：直接出交底书

给设计文档、研发报告、实验记录，或者直接给项目目录，返回两份 Word：

- **交底书正文**：发明名称、背景技术、技术方案、优点、实施方式及附图、权利要求结构预览、说明书摘要、附图标号表
- **核对说明**：系统推断的内容、待补充的事实、附图绘图说明、发明点比对、替代方案

**附图自动画**：连接关系图、流程图、模块框图、结构图、电路图，按领域判断该画哪种。

**发明点逐条比对**：每个发明点都拿去全球专利库里比，撞上了哪篇、是完全公开还是相近，都写清楚。

**按领域写到位**：计算机、机械、电子、化工、生物、药品六个领域各有写法。化工要配比和点值，机械要连接关系，软件要流程和分支，不会一个模板套到底。

### 只有一个想法：先出方向

一两句话说不清具体怎么做？先出几个可申请的方向，每个方向带核心方案、创新点和新颖性、可行性、差异化评分。挑一个，接着写交底书。

## 怎么用

**不需要密钥，装上就能用。** 第一次运行时脚本自动领取一份免费试用：¥20 额度、30 天有效，存在本机 `~/.patentmax/`。

试用用完后，在 [api.ip930.com](https://api.ip930.com/features/api-platform) 注册（再送 ¥50 体验额度）并创建密钥，设成环境变量即可，设了就不再用试用：

```bash
export PATENTMAX_API_KEY="pm_live_你的密钥"
```

然后直接跟 AI 说「帮我把这个项目写成交底书」，给它文件或目录就行。

想自己跑命令：

```bash
# 材料齐的
python scripts/patentmax_disclosure.py create \
  --file ./设计方案.docx --file ./实验记录.md --yes

# 只有一个想法
python scripts/patentmax_disclosure.py ideas --idea "……" --yes
python scripts/patentmax_disclosure.py create --from-ideas <report_id> --direction 2 --yes

# 下载
python scripts/patentmax_disclosure.py download --report-id <report_id> --out 技术交底书.docx
python scripts/patentmax_disclosure.py download --report-id <report_id> --kind notes --out 核对说明.docx
```

**只用 Python 标准库**，不需要 `pip install`，不用装浏览器、不用装 Office。`.docx` 直接读。

新用户注册即送 ¥50 体验额度。

## 材料怎么准备

**材料越全，交底书越好，要你确认的推断越少。** 最少讲清三件事：

| | 写什么 |
| --- | --- |
| **解决什么问题** | 现有做法卡在哪 |
| **具体怎么做** | **最关键**：结构、步骤、参数、控制逻辑 |
| **达到什么效果** | 最好有数字 |

❌ 「一种智能阀门控制装置」：200 字以下脚本直接拦下来

✅ 「转轴上装角度和扭矩传感器，闸前闸后各一个水位计；扭矩增量超 30% 且水位差异常判定卡滞；冰冻时低频大振幅振动 30 秒，异物时高频小振幅 15 秒，三次失败告警锁定」

提交前可以先 `preview`，**不花钱**，看看材料够不够。

详见 `references/materials-guide.md`。

## 它不做什么

**不出具专利申请文件。** 交底书是给代理人的技术说明，正式的权利要求书和说明书由专利代理师撰写并递交。

**不保证能授权。** 发明点比对说明的是「在专利库里撞没撞上」，要一个能不能申请的结论，交底书写完再做一次专利查新。

**不做外观设计。** 适合发明和实用新型这类技术方案。

**不编实验数据。** 化工、药品这类需要实测数据的，缺了就列进「待补充」，不会凭空写一个数出来。
