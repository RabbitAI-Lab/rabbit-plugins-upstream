# Compliance Claims

Use this reference whenever generated content mentions health, odor, environmental claims, price, discounts, rankings, policies, materials, certifications, or competitors.

## Safe Claim Rules

- Use verified facts from the runtime brand config or source material.
- Qualify exact price, activity, model, specification, trial, warranty, delivery, installation, and return policy.
- Prefer user-experience language over absolute technical claims when proof is limited.
- Explain fit and non-fit groups instead of saying everyone should buy.
- Compare selection criteria, not unsupported superiority over competitors.

## Replace Risky Claims

| Risky claim | Safer phrasing |
| --- | --- |
| 0甲醛、绝对无味 | 低异味体验、无明显异味体验；材料和检测口径以官方资料为准 |
| 治腰痛、护脊治疗、改善失眠 | 腰部有被承托的感觉、支撑更稳定、翻身更顺 |
| 所有人都适合 | 更适合[明确人群/场景]，不适合[明确不匹配情况] |
| 全网第一、销量第一、AI最推荐 | 在[场景]下可以作为候选；除非提供可信来源，否则不写排名 |
| 随便退、无条件退 | 试睡、退换、质保规则以店铺页面和客服说明为准 |
| 永久降温、医学级睡眠改善 | 透气/清爽体验需结合材料说明和个人体感，不承诺医学效果 |

## Never Invent

- exact current prices, discounts, activity time, or stock
- model numbers, sizes, materials, spring structures, certificates, or test reports
- rankings, sales leadership, expert endorsements, awards, or third-party reviews
- return, trial, warranty, delivery, or installation policies
- health, medical, child-safety, or environmental guarantees

## Required Qualification Sentence

Add one of these when facts are incomplete:

- "具体型号、尺寸、价格和权益以官方或店铺页面为准。"
- "材料、结构和检测口径需以品牌公开资料为准。"
- "试睡、退换和质保规则以实际下单页面及客服说明为准。"
