# 公司画像

## 触发

用户给出任意公司名称（中文名/英文名/简称/品牌名/股票代码均可），要介绍、查营收、查业务、查中国区情况。

## 铁律（违反任何一条，输出即为废稿）

1. **先定位主体，再谈内容**。名称 ≠ 法人主体。没确认到具体主体之前，不写任何业务和数字。
2. **不臆测**。查不到就写 `未查到`，公司没公开就写 `未披露`。禁止用集团数据填子公司、禁止用行业均值推算员工数、禁止"大约""业内人士称"式填空。
3. **每个数字带三件套**：口径（合并/单体、自然年/财年）+ 时间范围 + 来源。缺一不可。
4. **区分"已落地"与"已宣布"**。投资额、建厂、员工扩张，凡属承诺未执行的，必须标 `承诺额，未落地`。
5. **不确定就说不确定**，并在文末集中列出待确认项，而不是把猜测藏在正文里。
6. **收入结构 ≠ 利润结构**。只要有分部毛利率，就必须算毛利贡献占比，不能只报营收占比。两者背离时要点出来。

## 第一步：主体定位（不可跳过）

### 1.1 收齐线索，锁定主体

从名称反查五个锚点，至少命中两个才可确认：

| 锚点 | 用途 |
|---|---|
| 法定全称 | 如"小米" → 小米集团（开曼注册）/ 小米科技有限责任公司（境内主体） |
| 股票代码 + 交易所 | 最强锚点，直接锁定上市主体 |
| 统一社会信用代码 | 境内主体唯一标识 |
| 官网域名 | 反查主体与品牌归属 |
| 法定代表人 / 实控人 | 区分同名公司 |

**必查顺序**：① 官网「关于我们 / 投资者关系」→ ② 交易所披露（A股巨潮资讯网、港股披露易 HKEXnews、美股 SEC EDGAR）→ ③ 国家企业信用信息公示系统（境内法人的注册资本、成立日期、参保人数）→ ④ 权威媒体/行业报告（仅作线索，不作定论）。

### 1.2 八类常见歧义（命中即先澄清）

| 类型 | 例子 | 处理 |
|---|---|---|
| 同名不同主体 | 多家"华信""中科XX" | 列候选表，让用户选 |
| 集团 vs 上市主体 | 中国建筑集团 / 中国建筑(601668) | 明确问：要集团还是上市公司 |
| 简称跨行业 | "长城"= 长城汽车 / 长城资产 / 长城电脑 | 按知名度+用户语境给默认，并声明 |
| 品牌 vs 法人 | "抖音"是产品，主体为抖音有限公司 | 写"品牌 → 归属主体" |
| 境内 vs 境外同名 | "XX科技"境内公司 ≠ 港美股同名 | 用注册地+代码区分 |
| 已更名/被并购 | 老名称已注销 | 写"现为 XX 旗下"，注明时间 |
| **名称不存在 / 拼凑名** | "上海外服股份有限公司"——实际是「上海外服控股集团股份有限公司」+「上海外服（集团）有限公司」 | 见 1.3，**不要只回一句"查无此公司"** |
| **母子公司同名** | "XX集团"与"XX有限公司"业务几乎一致 | 说明哪层有财务披露，按有数据那层输出 |

### 1.3 名称不存在时怎么办（高频，必须给出答案而非拒答）

用户给的名字常是**拼凑体**：截了上市主体的字号 + 加了"股份"。判定方法：

1. 拆核心词（"上海外服"）+ 组织后缀（"股份有限公司"）分别检索；
2. 若核心词命中多个法人，按**是否上市 / 注册资本 / 成立时间**排序；
3. **输出最接近的 1–3 个法人对照表，声明取哪个，然后照常输出完整画像**；
4. 若核心词也查不到 → 才判定为"未查到该主体"，并列出可能的近似名。

```
「上海外服股份有限公司」未查到对应工商主体。实际为两个法人：

| # | 法定全称 | 代码/注册地 | 一句话区别 |
|---|---|---|---|
| 1 | 上海外服控股集团股份有限公司 | 600662.SH | 上市主体，控股平台 |
| 2 | 上海外服（集团）有限公司 | 91310000132209850J | 实际经营主体，上市公司全资子公司 |

下文按 [1] 上市主体展开（要 [2] 单体数据说"换2"）。
```

### 1.4 多源数字冲突（不许装作没看见）

同一指标两个来源不一致时（注册资本章程修订值 vs 工商登记值、员工数年报 vs 招聘页）：

- **并列两个数字**，说明差异原因（股本变动、统计时点、口径不同）；
- 无法判断孰对时，两个都留，进「待确认」；
- **禁止**只挑一个、把另一个删掉——那等于对用户隐瞒了不确定性。

## 第二步：业务线分层

### 2.1 主营 vs 次要（可验证口径，不凭感觉）

- **主营业务线**：年报分部报告中营收占比 ≥ 30%，或占比排名前 2 的业务
- **次要业务线**：占比 10%–30%，或有独立披露但非战略重点
- **边缘/孵化**：占比 < 10% 且未单独披露分部数据的，归入"其他"，一句话带过

> 公司自述的"五大主业""核心板块"不等于按占比成立的主营。**照公司口径列全，但按数据口径标注哪条才是真主营**，两者不一致时明说。

输出至少写清：业务线名称 → 做什么 → 最新可查营收占比（或标 `未单独披露分部`）→ 该业务的主体公司（若与母公司不同）。

⚠️ 集团多元化公司（如伯克希尔、复星、华润）分部极多，**只列前 4–5 条 + 一句"其余归入其他"**，不要摊开 20 个板块。

### 2.2 结构体检（有分部毛利率就必做）

算两个占比并对比：

- **收入占比** = 分部收入 / 总营收
- **毛利贡献占比** = 分部收入 × 分部毛利率 / 总毛利（标注"测算"，因系分部毛利率推算而非直接披露）

**排序不一致时，必须在业务线表后加一段引用块**，写清：谁贡献收入、谁贡献利润、这对判断"公司靠什么赚钱"意味着什么。

高风险行业（收入与利润必然背离）：人力外包、贸易分销、工程建筑、代运营、物流、低毛利制造 + 高毛利服务并存的混合体。这类公司**看营收增速会严重误判盈利能力**。

## 第三步：历年营业额

默认给**最近 5 个已完成财年**，做成表格：

| 财年 | 营收（原币） | 同比 | 归母净利 | 扣非净利 | 口径 | 来源 |
|---|---|---|---|---|---|---|
| FY2025（截至 2025-12-31） | | | | | 合并报表 | 2025 年报 |

**七个必守口径**：

1. **财年不等于自然年**。苹果财年 9 月止、微软 6 月止、多数日企 3 月止。表头必须写"截至 YYYY-MM-DD"，不然"2023 年营收"会错一年。
2. **币种不混算**。多币种要标换算汇率与汇率日期；不要拿不同汇率年份的数直接比同比。
3. **口径不混用**。合并报表 / 母公司单体；制造业"营业收入"与金融业"营业收入"（含利息净收入）不可横向比较。
4. **未上市公司**：只能给公开披露的融资轮、估值、或媒体援引财报，一律标 `媒体口径 / 未审计`，并写清数字出自哪一年。
5. **找不到连续 5 年就少给**，用"仅披露近 3 年"说明，绝不补空行凑数。
6. **期间可比性**。重组、并购、剥离、会计政策变更导致合并范围变化的年度，必须标注"与前后年度不可比"并说明原因。典型特征：某年同比出现极端值（如 -47%），而原因不在经营。**不标注就等于给出误导性结论。**
7. **净利必配扣非**。净利同比异常的年份（|同比| > 30%，或与扣非方向相反），必须同时给扣非净利及同比，并说明差异来自哪笔非经常性损益（处置资产、政府补助、公允价值变动）。

## 第四步：产品与品牌

按三级排列，每个一句话（定位 + 面向人群，可选价格带）：

- **主品牌**：贡献主要营收的，1–3 个
- **子品牌 / 产品线**：覆盖不同人群或价位
- **已出售 / 停用 / 授权品牌**：单独列，注明处置时间，避免用户误判

必须写清关系：自研 / 收购（哪一年）/ 授权运营 / 合资。收购品牌要能对上收购年份，对不上就标 `未查到收购时间`。

## 第五步：所属国家

**不要只写一个国名**，三者可能互不相同：

| 维度 | 内容 |
|---|---|
| 注册地 | 开曼 / 爱尔兰 / 中国境内…（决定法律归属） |
| 总部所在地 | 实际决策地 |
| 实控人国籍/背景 | 国资（中央/地方）/ 民营 / 外资，写出实控方 |

> 开曼注册 + 香港总部 + 中国内地经营的港股公司很常见，只写"美国公司""中国公司"都会失真。国企要写到"哪级国资委"。

## 第六步：中国区员工人数（四层口径，最易出错）

**先判断这家公司是哪种类型**，再取数。服务型公司（人力外包、物业、保安、客服、代运营、劳务派遣）四层数字能差三个数量级：

| 口径 | 含义 | 从哪取 |
|---|---|---|
| ① 自有员工（合并） | 本公司签劳动合同的人 | 年报「员工情况」，最常用 |
| ② 法人员工（单体） | 某个法人的在册人数 | 工商年报 / 社保参保人数 |
| ③ 派驻或管理的外包人员 | 公司在客户现场管理的人，**非本公司雇员** | 年报经营情况、项目披露 |
| ④ 服务对象人数 | 服务覆盖的员工总数，**更不是雇员** | 官网「服务 XX 万人」 |

**必标口径**：是否含港澳台 / 是否含外包派遣 / 是否含合资公司 / 统计截止日。给区间比给精确数更诚实，如 `约 1.2–1.5 万人（2024 年报大中华区口径，含港澳台）`。

**反向校验**：用「营收 ÷ 员工数 = 人均创收」验一遍。人均创收异常高（如 > 500 万）通常说明分母用了自有员工而分子含外包流水，此时必须补注。

## 第七步：中国区投资情况

拆成三类，**绝不能混成一个"投资 XX 亿"**：

| 类型 | 写法 |
|---|---|
| 已落地实体 | 公司名、成立时间、注册资本、持股比例、所在地、业务职能 |
| 已实际投入 | 可查的注册资本合计 / 官方公告的实际投资额，标年份与来源 |
| 已宣布未落地 | 明确标 `承诺额，截至 XXXX 年 X 月未落地` |

补充维度（有则写）：在华合资/入股（合资方、股比、时间）、研发中心与工厂数量、重大政府合作框架协议。

⚠️ 「投资标的库新增 N 家」「正在洽谈」属于**意向**，不得计入已投；「设立分公司」与「设立子公司」法律意义不同，照原文写。

## 交付前自检（9 项，缺一不可）

1. 主体是否唯一确定？名称不存在时，是否给了最接近的法人对照而不是直接拒答？
2. 每个营收数字是否都有"财年截至日 + 币种 + 口径 + 来源"？
3. 主营/次要的划分是否给了占比依据，而不是形容词？
4. 有分部毛利率时，是否算了毛利贡献占比、并指出与收入结构的背离？
5. 有没有合并范围变化导致不可比的年度？标注了吗？
6. 净利同比异常时，是否给了扣非净利并说明差异来源？
7. "所属国家"是否区分了注册地/总部/实控（国企是否写到国资委层级）？
8. 中国区投资里，有没有把承诺额/意向写成已投？
9. 员工数是哪一层口径？人均创收反向校验过了吗？

## 检索受限时怎么办

- 无法联网或一手资料搜不到：**开头就声明"本次未能核验一手资料"**，输出全部标 `未核实`，并列出建议用户提供的材料（年报 PDF、招股书、官网链接）。
- 绝不因为"大概记得"就填数字。记忆里的数字可能对应的是三年前的口径。
- 用户给了 PDF/年报链接 → 优先直接读原文取数，比自己搜更准。

## 与其他技能的边界

- 只要公司**财务深度分析、估值、投资建议** → 不归本技能，走金融/投研类技能。
- 只要**招聘信息、岗位、面试** → 归 HR 类技能。
- 本技能只做"这家公司是谁、做什么、多大、在 China 什么情况"的客观画像，不做买卖判断。
