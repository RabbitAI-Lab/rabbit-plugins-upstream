# 人物项目关系记忆库

[English](README.md)

将人物、项目与资源保存为带来源的实体和关系，按层级查看关联，导出当前 BOT 的结构化关系图数据。

## 能做什么

将人物、项目与资源保存为带来源的实体和关系，按层级查看关联，导出当前 BOT 的结构化关系图数据。

## 用法示例

安装后将下面任意一条发给助手，并提供所需文件或参数。

```text
记住这个项目由小李负责，客户是示例公司，并标记信息来源。
```

```text
查看这个项目与哪些人员和资源有关。
```

```text
导出当前助手保存的人物项目关系，方便我核对。
```

## 运行方式与边界

Python 3.10+，仅标准库。处理当前助手工作区内选定的资料，报告保存到新目录。

资料及关系由用户提供，不自动从聊天中采集他人隐私。

## 运行要求

Python 3.10+；标准库
