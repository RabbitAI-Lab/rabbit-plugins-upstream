# Klik Next-Step Review

An educational, non-executing skill for deciding whether a proposed AI next step is ready to prepare, needs clarification, or should return to a person.

It uses five review dimensions: source, Context, scope, authority, and impact. It does not access accounts, send messages, execute actions, or request sensitive data.

## Use

Ask an agent to review a short, redacted description of a proposed next step. The skill returns a compact review card and one of three statuses:

- `Return to a person`
- `Clarify first`
- `Ready to prepare`

`Ready to prepare` only authorizes drafting or planning for human review. It never authorizes execution.
