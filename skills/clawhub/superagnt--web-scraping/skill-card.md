## Description:

Scrape, search, and map the web for agents — clean markdown, structured JSON, and site URL discovery.

This skill is ready for commercial/non-commercial use.

## Publisher:

[superagnt](https://clawhub.ai/user/superagnt)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to let agents scrape public web pages, search the web, and map site URLs. The returned content supports research, RAG, monitoring, and data-enrichment workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Requests send an API key and requested page or search information to the external superagnt service.

Mitigation: Use the service only if you trust it, avoid sending information you do not want processed there, and keep the API key private.
