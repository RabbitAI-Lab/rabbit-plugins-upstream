## Description:

Scrape, search, and map the web for agents — clean markdown, structured JSON, and site URL discovery.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and research agents use this skill to retrieve public web pages, search results, and site URLs for research, content extraction, and monitoring workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill sends requests through an external API using an API key, and the security scan was incomplete.

Mitigation: Use it only if comfortable with the service handling request data, protect the API key, and review the skill before deployment.
