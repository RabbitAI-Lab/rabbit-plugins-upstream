## Description:

Scrape, search, and map the web for agents — clean markdown, structured JSON, and site URL discovery.

This skill is ready for commercial/non-commercial use.

## Publisher:

[superagnt](https://clawhub.ai/user/superagnt)

## Use Case:

Developers can use the skill to let research, RAG, and monitoring agents retrieve public web pages, search for sources, extract structured information, and discover site URLs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill sends an API key to Superagnt and uses the service's credit-based API; scanner evidence also notes that its review was incomplete.

Mitigation: Use the service only if you trust Superagnt, keep the API key private, and check the account's available credits and usage before running requests.
