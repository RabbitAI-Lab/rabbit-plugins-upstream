## Description:

Scrape, search, and map the web for agents — clean markdown, structured JSON, and site URL discovery.

This skill is ready for commercial/non-commercial use.

## Publisher:

[superagnt](https://clawhub.ai/user/superagnt)

### License/Terms of Use:

MIT-0

## Use Case:

External developers and research agents use this skill to search public web content, retrieve pages as Markdown or structured data, and discover site URLs for research, RAG, monitoring, and enrichment workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The external API receives the URLs or queries submitted, and the security scan covered only part of the skill.

Mitigation: Submit only public material and queries you are comfortable sharing, avoid secrets or personal data, and review the integration before use.
