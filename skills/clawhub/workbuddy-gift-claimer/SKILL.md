## 常见问题（FAQ）

### ❓ 为什么领取失败？

| 可能原因 | 解决方法 |
|---------|---------|
| **软件界面变了** | 技能会自动学习新界面。如果连续失败3次，技能会自动尝试新发现的关键词 |
| **软件没打开** | 技能会自动启动。如果没找到安装路径，提示你手动打开 |
| **网络卡顿** | 技能等待60秒让界面加载，超时后提示"界面加载超时" |
| **按钮文字变了** | OCR会扫描所有文字，发现新按钮文字自动记录。可以在下次提问时说"重新学习" |
| **屏幕分辨率变了** | 技能使用比例坐标，适配不同分辨率 |

### ❓ 支持 Mac 吗？

**不支持。** 技能依赖 Windows 桌面自动化（pyautogui + OCR 截图），macOS 需要不同的技术方案，目前无法支持。

### ❓ 截图/视频学不会怎么办？

**常见原因：**
1. 截图模糊 → 重新截图，确保文字清晰
2. 按钮文字被截断 → 截图包含完整的按钮区域
3. 截图背景太复杂 → 截取包含目标按钮的最小区域即可

### ❓ 定时任务不执行怎么办？

1. 检查 Windows 任务计划程序是否被杀毒软件阻止
2. 检查电脑是否在凌晨时关机/休眠
3. 技能有开机补偿：开机后自动检测昨天是否遗漏，自动补领
