## Use Case: <br>
Developers and macOS users use this skill to list chats, inspect message history, watch conversations, and send iMessage/SMS messages through the imsg CLI. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill requires terminal access to local Messages data and permission to control Messages.app. <br>
Mitigation: Install only if comfortable with those permissions, review macOS permission prompts carefully, and grant access only in trusted environments. <br>
Risk: Send commands can deliver iMessage/SMS content to real recipients. <br>
Mitigation: Confirm the recipient, service, message text, and attachments before using any send command. <br>
