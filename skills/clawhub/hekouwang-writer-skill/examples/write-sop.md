# 流程演示：从素材写一份操作说明

> **示例，不是实测案例。** 以下机构、步骤和数据均为占位，不可作为真实办理依据。展示文档模式如何从素材形成可执行结构。

## 输入素材（占位）

- 读者：第一次参加内部设备借用流程的同事。
- 已确认步骤：提交申请 → 负责人确认 → 领取设备 → 归还并登记。
- 未确认信息：审批时限、领取地点、逾期处理方式。
- 目的：让读者知道按什么顺序办理，并识别需要向内部负责人确认的事项。

## 写作决策

按 WRITE 五步先锁定读者和用途，再将流程按时间顺序组织。未提供的时限和地点不猜测，保留为待确认项。每节先给核心句，步骤用清单表达。

## 成稿片段（示例）

### 申请与领取

1. 提交设备借用申请，并填写设备名称、使用人和计划归还日期。
2. 等负责人确认后再领取设备。
3. 领取时核对设备及配件，并记录当前状态。

**待确认**：申请入口、审批时限、领取地点需由设备管理员补充。
