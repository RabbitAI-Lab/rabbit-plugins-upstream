## Known Risks and Mitigations:

Risk: The skill is packaged as API/interface design guidance but requests broad read and command-execution access.

Mitigation: Review it as a broad automation skill and narrow the scope to API/interface design guidance before routine use.

Risk: The artifact describes file, credential, API, network, and command workflows that can affect sensitive data or local systems.

Mitigation: Define explicit command, file, credential, and network boundaries; run in a sandbox; and avoid exposing secrets in inputs, outputs, or logs.
