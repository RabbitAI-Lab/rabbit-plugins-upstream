## Description: <br>
Creates, checks, and edits PowerPoint presentations with support for layout management, template use, placeholder/master handling, and content or visual quality checks. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External users and developers use this skill to have an AI agent create presentations from templates, edit existing slides, inspect layout structure, manage placeholders and masters, and run content or visual quality checks for lightweight PowerPoint workflows. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Security review classified the release as suspicious because privacy and network behavior are inconsistent. <br>
Mitigation: Install only after reviewing each operation before it runs, and use copies of presentations rather than originals. <br>
Risk: The artifact exposes an optional callback_url and also claims local-only privacy. <br>
Mitigation: Avoid callback_url for confidential files and do not rely on local-only privacy unless the executing agent and tools block network access. <br>
