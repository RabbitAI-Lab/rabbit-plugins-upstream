## Description:

Search the web, read pages and documents as clean markdown, and pull one specific fact out of a page, with Sofya. Use when the user asks to look something up online, needs current information, gives a URL or PDF to read, or wants a price, date, spec or contact from a specific page.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers can use this skill to find web pages, read supplied URLs or documents as Markdown, and extract a requested fact from a page. It requires a Sofya API key or a connected Sofya MCP server.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Search queries, URLs, and prompts are sent to the external Sofya service.

Mitigation: Avoid including confidential information or secrets in inputs, and review the URLs and query content before sending them.
