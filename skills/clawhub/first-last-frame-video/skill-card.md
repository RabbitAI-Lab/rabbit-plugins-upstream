## Description:

Creates one short video transition between two approved images, then reviews whether the result matches its first and last frames.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

## Use Case:

Creators and developers use this skill to turn two approved images into a directed transition clip for transformations, reveals, and scene changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Shared device authorization grants broad Beatra account access, including wallet spending.

Mitigation: Review the requested account scope and wallet-spend permission before authorizing; keep the device credential private.

Risk: Verified automatic updates can replace local package files without separate confirmation.

Mitigation: Install only if you trust Beatra to deliver updates; turn off automatic updates if silent replacement is unwanted.

Risk: Installation registration shares device and environment metadata with Beatra.

Mitigation: Review the registration metadata before using the skill.

Risk: Video generation can spend credits and uncertain responses could lead to duplicate work.

Mitigation: Confirm the live cost estimate and sufficient balance before paid generation; recover uncertain requests with the same request identity.
