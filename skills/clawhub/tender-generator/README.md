# 智能项目文档生成器 (Tender Generator)

一个强大的 OpenClaw Skill，通过对话式交互智能生成全套规范化项目文档。

## ✨ 核心功能

- **对话式信息收集**：通过自然对话逐步收集项目、公司、报价等关键信息
- **智能模板匹配**：支持多套模板（默认/电力行业/政府采购等），自动匹配最佳模板
- **一键生成全套文档**：自动生成包含 10+ 份文档的完整项目文档包
- **智能数据填充**：自动将收集的信息填充到模板的对应位置
- **合规自检**：生成前自动检查文件完整性，确保无遗漏
- **隐私保护**：所有敏感信息仅在会话内处理，不记录到公开日志

## 📦 模板结构

```
templates/
├── 默认/                    # 默认通用模板（需用户自行准备 docx 文件）
│   ├── 00-封面.docx
│   ├── 01-身份证明.docx
│   ├── 02-资质文件.docx
│   ├── 03-承诺书.docx
│   ├── 04-能力证明.docx
│   ├── 05-报价明细.docx
│   ├── 06-业绩材料.docx
│   ├── 07-审计报告.docx
│   ├── 08-偏离说明.docx
│   └── 09-技术方案.docx
├── 电力行业/                # 电力行业专用模板（可选）
│   └── ...
└── 政府采购/                # 政府采购场景模板（可选）
```

> ⚠️ **重要提示**：本技能包**不包含实际的模板文件**（出于隐私和安全考虑）。用户需要自行准备对应的 `.docx` 模板文件，并按照上述命名规范放入对应目录。

## 🚀 使用方法

### 1. 安装技能

```bash
# 从 ClawHub 安装
openclaw skills install tender-generator

# 或从本地安装
openclaw skills install /path/to/tender-generator-skill
```

### 2. 准备模板文件

将你的项目文档模板文件（.docx 格式）按照命名规范放入 `templates/` 目录：

```bash
# 示例：准备默认模板
mkdir -p templates/默认
cp /path/to/your/封面.docx templates/默认/00-封面.docx
cp /path/to/your/身份证明.docx templates/默认/01-身份证明.docx
# ... 依此类推
```

### 3. 开始生成

在 OpenClaw 会话中直接说：

```
帮我生成一套项目文档
```

技能将引导你完成以下流程：
1. 选择模板
2. 收集项目信息
3. 收集公司信息
4. 收集报价信息
5. 上传技术文档（可选）
6. 确认所有信息
7. 生成并下载项目文档包

## 📝 模板占位符规范

模板文件中的占位符格式：

| 占位符 | 说明 | 示例 |
|--------|------|------|
| `{{project_name}}` | 项目名称 | 智慧社区建设项目 |
| `{{tender_number}}` | 招标编号 | ZB-2024-001 |
| `{{tenderer}}` | 招标人 | XX 市政府采购中心 |
| `{{deadline}}` | 投标截止日期 | 2024-12-31 |
| `{{company_name}}` | 公司全称 | XX 科技有限公司 |
| `{{credit_code}}` | 统一社会信用代码 | 91110000XXXXXXXXXX |
| `{{legal_rep}}` | 法定代表人 | 张三 |
| `{{total_price}}` | 总报价（含税） | ¥1,234,567.89 |
| `{{tech_params}}` | 技术参数（不可修改） | 响应时间≤3 秒 |

## 🔧 高级用法

### 自定义模板

你可以创建自己的行业模板：

```bash
mkdir -p templates/我的行业模板
# 复制并修改模板文件
cp -r templates/默认/* templates/我的行业模板/
# 修改模板中的固定内容
```

然后在对话中指定：

```
使用"我的行业模板"生成投标文件
```

### 批量生成

如需为多个项目批量生成，可以：

1. 准备一个包含多个项目信息的 JSON 文件
2. 使用脚本批量调用技能

## ⚠️ 注意事项

1. **模板文件需自行准备**：本技能包不包含实际的 `.docx` 模板文件
2. **敏感信息保护**：营业执照、法人身份证等文件需要手动替换为盖章扫描件
3. **技术参数不可修改**：用户提供的技术参数会被原样保留，不会被 AI 修改
4. **最终审核**：生成的文档仅供参考，正式使用前请务必人工审核
