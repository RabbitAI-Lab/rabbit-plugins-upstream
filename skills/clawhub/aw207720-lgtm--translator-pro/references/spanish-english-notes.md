# Spanish ↔ English Translation Notes

## Register: Tú vs Usted

- tú → informal "you" (casual, peer, familiar)
- usted (ud.) → formal "you" (business, legal, respectful)
- vos → alternate informal (River Plate: Argentina, Uruguay) — valid but flag region
- Default to usted for business and legal; switch to tú only if source uses tú
- In legal: always usted regardless of source familiarity

## Regional Variants

- **Castilian (Spain)**: vosotros, computer → ordenador, mobile → móvil, distinct "c" and "z" pronunciation (theta)
- **Latin American**: ustedes (no vosotros), computer → computadora, mobile → celular
- **Mexico**: authoritative for many US Spanish translations
- **Andean/Caribbean**: chévere (cool), pisco, unique slang
- Flag regionalisms in cultural notes; default to neutral Latin American for broad audience unless target region specified

## Subjunctive and Modal Nuance

- Spanish subjunctive often has no direct English grammatical equivalent
- "Es importante que venga" → "It's important that he comes" (subjunctive mood lost)
- Capture intention/nuance in word choice rather than grammar:
  - "Ojalá" → "I hope" / "If only" — adds wistfulness
  - "Quizás" → "Maybe / Perhaps" — subjunctive implies uncertainty
- Conditional "si" clauses: translate condition structure carefully

## Formatting

- Spanish uses inverted question/exclamation marks: ¿? ¡!
- Dates: DD/MM/YYYY (Spain, most of LatAm) — convert to target locale
- Numbers: comma as decimal separator, period as thousands separator (Spain) — varies by country
- Currency: use locale-appropriate symbol placement

## Common Pitfalls

- "Ser" vs "Estar": both = "to be" but different permanence — translate context, not word
- "Por" vs "Para": both can = "for" — direction vs cause/motive
- Gendered nouns: el problema (masculine despite -a ending), la mano (feminine despite -o ending)
- "Número" vs "Cantidad": número = number (count), cantidad = quantity/amount
