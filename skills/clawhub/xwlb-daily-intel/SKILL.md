# 新闻联播每日情报分析

从央视官网直采《新闻联播》官方文字稿，产出固定格式情报报告。

**为什么坚持一手直采**：tv.cctv.com 是央视官网，文字稿与播出内容逐条对齐（★★★★★），可回溯、可核对；二手聚合接口拿到的往往是标题列表或转述，无法支撑逐条溯源的情报分析。本技能内置实战验证的零依赖抓取脚本与完整坑位记录，这是它的核心价值。

## 执行步骤

### 1. 确定目标日期

任务说"昨天" = 执行日前一天。凌晨或晚间执行时注意日期换算。

### 2. 抓取官方文字稿（首选路径）

```bash
python3 scripts/fetch_xwlb.py [YYYYMMDD] [输出目录]
```

- 指定日期时直取 `tv.cctv.com/lm/xwlb/day/YYYYMMDD.shtml` 日期页，一次性拿到当日全部条目（含标题与全文）；
- 无日期参数时默认取 index 首屏最新一期；
- 输出 `<输出目录>/YYYYMMDD.md`，每条含标题、来源 URL、《央视网消息》全文；
- 纯 Python 标准库（urllib + re），零外部依赖；每页间隔 1s，单期 <1min；
- 输出目录不传时：环境变量 `XWLB_OUT` > 默认 `./data/xwlb`（相对当前工作目录）。

**当日可用性（实测）**：19:00 播出后，约 20:00–20:30 官方文字稿全量上线（实测某期 20:22 即 17 条中 16 条含全文）。定时任务排在 20:30 左右最稳；更早触发若官方条目 <10 或含全文 <6，等 10 分钟重跑、最多 4 次。

典型产出：13–26 条中约 12–18 条含全文。整期视频入口等条目仅标题级简介属官方惯例，标 [仅标题] 即可，不是抓取故障。

**快讯子条目兜底（probe_brief.py）**：国内/国际联播快讯的正文常不进「主要内容」区块，全文藏在视频页「视频简介」div 里。脚本判"仅标题"的快讯条目，用探针脚本补采：

```bash
python3 scripts/probe_brief.py URL1 URL2 …
```

- 三态输出：`BRIEF(n字)` 命中 / `EMPTY_BRIEF` 页面在但内容空 / `NO_DIV` 无该区块；
- 快讯 brief 上线时间晚于正文 10-15 分钟是常态；EMPTY_BRIEF 持续数探仍空则当晚可能不更新（9-26 型），按硬判据正常交付正文、快讯标注"待下次补齐"即可，次晨重抓通常 100% 恢复；
- 也适用于非快讯类单条新闻仅标题时的补采。

### 3. fallback（官网抓取失败或当日未上线时）

用你可用的搜索工具搜 `{月日} 新闻联播 主要内容`，骨架源依次考虑：民间文字版镜像（全文但属二手，需后核）、新浪 7x24 快讯（纯 HTML 可直抓）、财经媒体速览。

### 4. 官方信源定锚与二次核对

以官网文字稿为基线；对头条及关键数据，补搜新华网、人民网、部委官网核对口径。多源口径一致 → 置信度 ★★★★★/★★★★☆；有出入时在报告中明确标注冲突点，以官方口径为准。

### 5. 时间线自洽性核验（防旧文污染）

搜索结果常混入往年旧文。核对周年数、领导人行程时间线、URL 内嵌日期；与目标日期矛盾的结果一律丢弃。

### 6. 背景补充

对 1–3 个关键条目（元首外交 / 冲突 / 重大政策 / 宏观数据）补搜背景，用于第 7 步的推演。

### 7. 输出固定格式报告

用下方报告模板。四条硬规则：

- **条理硬规则（信息密度控制）**：①一条一义——一个要点条目 = 一条新闻，多条事件拆条，禁止合并；②条目结构固定 = **加粗短标题 +（★）** 独立一行 → 下方 2-4 个短 bullet（事实一句 / 关键数据 / 交叉佐证 / 待证实各占一行），数字进"数据"行、不嵌进长句；③禁止长括号链与嵌套补语——补充信息要么独立成 bullet、要么进存档不留报告；④快讯子条目每条独立一行（短句 + ★）；⑤推演段一条一编号、只推演不复述事实；⑥报告只留主干，全量细节在存档文件可溯源。
- 国内/国际联播快讯需拆出子条目逐条归类，不得遗漏；
- 事实【事实】与推演【观点】严格分区标注；查不到细节的标"待证实"，禁止编造；
- 敏感冲突类内容的搜索可能被安全策略拦截，不重试，用官方稿口径 + "待证实"标注即可。

### 8. 归档（如有持久化能力）

- 平台有日记 / 长期记忆系统：将报告要点写入执行日笔记，防止定时任务重发（去重依据 = 存档文件 + 笔记归档两者齐备）；
- 只有文件系统：按日期保存 Markdown 报告即可。

## 报告模板

```markdown
# 新闻联播 {YYYY-MM-DD} 情报报告

## 核心摘要
（3 句话：本期最重要的三件事及一句话定性）

## 分类要点
### ① 时政
**加粗短标题（信源 ★）**（★★★★★）
- 事实：一句话
- 数据：关键数字独立成行
- 佐证：交叉验证口径
- 待证实：查不到的细节（如有）
### ② 政策
### ③ 宏观经济与产业
### ④ 民生
### ⑤ 国际
（联播快讯拆子条目，每条独立一行：短句 + ★）

## 潜在影响推演【观点】
1. 推演一条一编号，只推演不复述事实（注明依据的报告条目）
2. ……

## 值得持续关注的信号
（后续值得跟踪的事态变化、政策落地节点、数据发布窗口）
```

## 质量标准

- 每条目至少一个官方信源或两家独立媒体佐证；
- 信源可信度基线：央视 / 新华 / 人民网 ★★★★★；主流财经媒体速览 ★★★★☆；联播转述外媒 ★★★☆☆；
- 推演必须落在"对普通人及相关行业意味着什么"，不能停留在复述新闻；
- 关键条目附可回溯来源（存档文件路径 + 交叉验证口径）。

## 坑位记录（实战验证，遇到故障先查这里）

- **官网 index.shtml 改版为 JS 动态加载**（反爬 cookie + 空容器，带 cookie 二访也无效）：主路径必须走 `day/YYYYMMDD.shtml` 日期页；页面 script 引用清单里的 `xwlb_data.js` 名字唬人，实为日历控件非数据文件。
- **文字稿提取正则别写窄**：视频页有多个文本区块，「视频简介」只是一行标题复述，全文藏在「主要内容」区块（以「央视网消息（新闻联播）：」开头）——匹配 `央视网消息|本台消息|记者从` 才能命中。
- **老 API 已死**：`vdn.apps.cntv.cn` 视频信息接口已失效（返回"该视频不存在"），直接抓视频页 HTML。
- **开场整期入口条目 URL 内嵌次日日期**（如 9 月 7 日期存于 /09/08/ 路径下）：从 URL 提取日期会错位一天——指定日期跑脚本时，产出文件以 target 参数命名（脚本已处理）。
- **当晚 20 点后即可全量抓当日期**：比直觉预期早得多，晚间定时任务可行；更早时段不足由重试逻辑兜底。
- **页面渲染类抓取工具不可用时**：改用 `curl -A "Mozilla/5.0 ..." + 正则去标签` 直抓 HTML。
- **搜索的 recency 过滤不保险**：旧文会混入（实例：80 周年活动报道混入 81 周年检索）→ 靠周年数与行程时间线矛盾识别排除；财联社 cls.cn 文章 ID 逐年递增（2025 约 213 万档，2026 约 247 万档），可辅助判断新旧。
- **敏感主题搜索被拦截**（返回 sensitive content blocked）：不反复重试；混合解析多个搜索结果时敏感内容会把整批输出一起拦掉 → 敏感 / 非敏感分开解析。
- **video_brief 是 class 不是 id**：`id="video_brief"` 匹配不到（探针脚本已按 class 实现）；另 curl URL 截断（.s 而非 .shtml）返回空页会误判 NO_DIV——排障先验 URL 完整性再怪正则。
- **快讯 brief 缺位三态判读**：BRIEF=命中即用；EMPTY_BRIEF 可能是晚 10-15 分钟上线（等再探）也可能是当晚不更新（终判交付、标次晨补）；同一晚两类可并存，分开判断，命中即交付，勿因一部分缺位推迟整期。
- **快讯子条数量逐日波动是播出差异非缺位信号**：判读只认探针三态，勿以子条数横向对比判缺位。
- **存档文件可能混入页面 JS 尾巴**：brief div 匹配过宽时把页面脚本一起带进来——清理时用视频 ID/URL（ASCII 锚点）定位替换，勿用长中文串做编辑匹配（中文弯引号 vs 直引号不一致会导致编辑工具静默失败）。

## 定时任务建议（可选）

若你的平台支持定时任务，推荐「晚间采集 + 次晨完整交付」双班架构（已实测最稳）：

- **晚间采集班**：每日 20:30 左右跑当日期落存档（快讯探针一次即可，不重试不死等）；
- **晨班完整交付**：次日晨间重抓一次（次日官网数据 100% 全量恢复，以重跑结果为准）→ 输出完整报告；晚间存档只当草稿；
- **单班方案（简化）**：每日 20:30 跑当日期 + sleep 600 重试最多 4 次，直接交付；条目 <10 或全文 <6 不达标时不硬交，标注后留给下次；
- **去重依据**：存档文件 + 笔记归档两者齐备 = 本期已交付，防迟到重跑 / 跨日撞车导致重发；
- **用户主动索要任何一期时无条件完整重发**——去重只约束定时任务，不约束用户开口。
