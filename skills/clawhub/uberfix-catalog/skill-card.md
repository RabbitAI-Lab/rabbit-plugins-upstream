## Use Case:

UberFix customers and support agents use this skill to browse service types and maintenance categories before submitting a request.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Catalog labels and categories may be mistaken for confirmed prices or service availability.

Mitigation: Report tool results as catalog options only; verify pricing and availability separately before making claims.

Risk: The skill cannot list services without a configured UberFix tool connector.

Mitigation: Install and configure the connector before using the skill; use the separate maintenance request flow to create requests.
