# 职责边界分析：智能体成长复盘 vs 相关技能

> 本文件记录了"智能体成长复盘"与现有技能的职责边界，供AI决策路由参考。

## 一、与`复盘提炼巧匠`的对比

| 维度 | 复盘提炼巧匠 | 智能体成长复盘 |
|------|-------------|---------------|
| 核心关注 | 项目或阶段性任务的方法论提炼 | 用户与智能体的双向成长变化 |
| 分析对象 | 项目文件体系、工作流程、模板 | 用户能力、智能体能力、人机协作 |
| 输出形式 | 方法论分析、可复用资产（技能/模板/检查清单） | 人机共同成长报告（Markdown+Word） |
| 时间跨度 | 项目周期 | 用户指定的任意时间段 |
| 与人的关系 | 关注项目本身 | 关注人与AI的关系变化 |
| 触发场景 | "总结项目经验""提炼方法论" | "回顾成长""智能体复盘""人机协作总结" |

## 二、与`session-brief`的对比

| 维度 | session-brief | 智能体成长复盘 |
|------|--------------|---------------|
| 核心关注 | 当前工作状态快照 | 阶段性的双方向变化 |
| 时间跨度 | 当前（一次性） | 一段时间（跨天/周/月） |
| 输出是否存档 | 不存档 | 正式存档报告 |
| 是否写回Memory | 否 | 是（需确认后） |

## 三、与`日志巧匠`的对比

| 维度 | 日志巧匠 | 智能体成长复盘 |
|------|---------|---------------|
| 核心关注 | 单日经历的双轨记录 | 跨阶段的综合成长分析 |
| 时间粒度 | 天 | 周/月/阶段 |
| 输出内容 | 工作事实表+生活叙事 | 8章节结构化成长报告 |
| 素材关系 | 日志是底层素材 | 可引用日志作为证据 |

## 四、与`朱海涛2号`的对比

| 维度 | 朱海涛2号 | 智能体成长复盘 |
|------|----------|---------------|
| 核心定位 | 朱海涛的AI思维参谋 | 通用成长复盘技能 |
| 是否结构化输出 | 否（自由对话） | 是（严格报告模板） |
| 适用范围 | 朱海涛个人 | 任何人机协作场景 |
| 是否处理Memory写回 | 可能（但不强制） | 流程化（先核对后写回） |

## 五、触发词冲突解决方案

如果多个技能的触发词同时匹配用户的输入，按以下优先级判断：

1. 如果用户明确提到"成长""变化""共同""AI赋能""人机"等关键词 -> **智能体成长复盘**
2. 如果用户提到"项目""方法论""经验提取""技能封装" -> **复盘提炼巧匠**
3. 如果用户提到"当前状态""简报""现在怎么样" -> **session-brief**
4. 如果用户正在口述今天的经历 -> **日志巧匠**
5. 如果用户简单询问"我最近怎么样"等 -> 可先由朱海涛2号回应，再判断是否需要转向本技能

**默认规则**：当不确定时，优先询问用户意图，不擅自路由。
