## Use Case:

E-commerce operators, designers, and developers use this skill to create Seedream 5.0 Lite product-detail-page visual modules from approved product evidence and optional reference images. The modules support PDP and marketplace content such as Amazon A+, Taobao, Tmall, JD, Douyin stores, Shopify pages, selling-point images, structure diagrams, step images, specification images, and long-form commerce visuals.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: AI Hive receives the API key and any product or reference images supplied for generation.

Mitigation: Use only authorized, non-confidential inputs and provide credentials only if the user is comfortable with AI Hive access.

Risk: Generated PDP imagery may imply unsupported product claims, specifications, certifications, reviews, effects, or comparisons.

Mitigation: Review every generated module against approved source material, and add or verify final text in a design tool before publishing.

Risk: Generated outputs are saved locally by default.

Mitigation: Choose an appropriate output directory and manage downloaded files according to the user's data-handling policy.
