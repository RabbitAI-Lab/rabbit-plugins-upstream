## Description:

Connects an agent to Speak AI and guides setup and common workflows for recordings, transcripts, search, meetings, and workspace tools.

This skill is ready for commercial/non-commercial use.

## Publisher:

[speakai](https://clawhub.ai/user/speakai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and workspace users use this skill to connect an agent to Speak AI and choose workflows for transcription, search, meeting capture, exports, and workspace management.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The documented local setup uses an unversioned MCP server package command, so a later install may run a different release.

Mitigation: Use a reviewed, version-pinned package setup and verify the external service connection is the one intended.
