## Description:

Helps agents connect to Speak AI and choose workflows for recordings, transcripts, search, clips, surveys, meetings, and workspace management.

This skill is ready for commercial/non-commercial use.

## Publisher:

[speakai](https://clawhub.ai/user/speakai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and workspace users can use this skill to connect an agent to Speak AI and find setup instructions, tool references, and workflows for analyzing and managing media and workspace data.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The local stdio setup uses an unversioned MCP server install command, so the release may be resolved at install time.

Mitigation: Review the server command and release before installing, and proceed only if you accept that the version is resolved at install time.
