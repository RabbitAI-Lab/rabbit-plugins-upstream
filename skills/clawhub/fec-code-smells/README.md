# Code Smell Diagnosis

Evidence-based diagnosis of the 24 canonical code smells with false-positive guards and frontend manifestations.

## Skill

- ID: `fec-code-smells`
- Category: `review-quality`
- Version: `2.9.0`
- Source: `skills/fec-code-smells/SKILL.md`

## Description

Use when diagnosing structural maintainability problems in existing frontend code before deciding how to refactor it, especially when evidence, false-positive checks, and candidate transformations are needed without editing business code.

Install or import this package with any skill runtime that understands the standard `SKILL.md` layout. The canonical source remains the Frontend Craft repository.
