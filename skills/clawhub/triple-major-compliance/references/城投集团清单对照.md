# 城投集团"三重一大"清单对照（校准 / 全链路标定范例）

> **用途**：演示 skill 如何处理"决策主体已逐条标定"的企业清单，并与 `企业清单结构化示例.md`（广东农垦大坪农场，只列事项不列主体）形成对照，校准两类清单的解析与路由逻辑。
> **示例企业**：某城投集团公司（河北省，2024-05-22 发布，公开范本，**有删减**）。
> **企业属性**：**地方国企 / 国有控股上市公司背景**——清单出现股东大会、董事会、监事会全套，且大量事项细分为「授权董事长决策」「授权总经理决策」。
> ⚠️ 本对照基于"有删减"的公开版本，正式使用须以企业最新有效完整版为准。

## 一、与农垦清单的核心差异（最大校准价值）

| 维度 | 广东农垦大坪农场 | 某城投集团 | 对 skill 的启示 |
|---|---|---|---|
| **主体标定方式** | 只列"哪些事项属三重一大"，**不列决策主体** | 每项**逐条标定**主体（党委决策 / 党委前置+董事会 / 授权董事长 / 授权总经理 / 股东大会） | 解析器须兼容两种：农垦型靠框架推断主体，城投型直接读取标定主体 |
| **采购是否进三重一大** | **进**：服务≥20万=公开招标=三重一大 | **整体不进**：「由公司直接管理的物资类、施工类和服务类采购，授权总经理决策」 | **采购落点企业差异极大，绝不可预设"采购必属/必不属三重一大"**，必须按 P1 原文判定 |
| **金额线风格** | 具体阈值型（服务20万/资产购置50万/投资100或50万） | 比例+绝对双锚 + 授权切分（见下） | 两种都要能解析 |
| **授权粒度** | 粗（董事会/经理层） | 极细（授权董事长 vs 授权总经理，按金额分层） | skill 路由须精确到"授权董事长"或"授权总经理"，不能笼统写"经理层" |

## 二、决策主体五级细化（框架缺的精细层）

城投清单呈现的真实决策主体不是"党委会→董事会"两段，而是**五级 + 授权切分**：

```
① 党委决策（直接定，不前置）
      ├─ 党的建设、贯彻部署、职工权益、安全生产追责、违规经营追责…
② 党委前置研究讨论 → 董事会审议 →（如需）股东大会决策
      ├─ 经营类重大（战略、投资、资产处置、融资、担保…）
③ 授权董事长决策     ← 《董事会授权方案》产物，大量日常重大经营事项落此
      ├─ 资产转让≤净资产30%、小型基建500-2000万、年度捐赠预算内调整、并购立项…
④ 授权总经理决策     ← 预算内执行、具体项目立项/可研、采购、大额合同付款…
      ├─ 预算内投融资还贷、小型基建≤500万、直接管理类采购…
⑤ 股东大会决策       ← 超比例标准（净资产30%等）或《公司法》11项
```

⚠️ **关键**：③ 与 ④ 的切分直接决定合规结论。例如小型基建：
- ≤500万 → 授权总经理
- 500万(含)–2000万 → 授权董事长
- >2000万且≤净资产30% → 党委前置+董事会
- >净资产30% → 党委前置+董事会+股东大会

若 skill 笼统归为"经理层决定"，会把"授权董事长"误判为"需上党委会"，反之亦然。

## 三、比例 + 绝对额双锚（研究中"同模板数字差十倍"的实锤）

城投大量使用"占净资产 X%"作为分层线，直接移植交易所/公司法标准：

| 事项 | 董事会线 | 股东大会线 | 备注 |
|---|---|---|---|
| 资产转让/并购 | 占净资产 ≤30%（五指标：总资产30%/归母净资产30%/利润30%/营收30%…） | >30% | 指标为负取绝对值 |
| 主业/参股投资 | ≤净资产30% | >30% | 同模板 |
| 资产减值核销 | 2000万以下且≤归母净利10% | >归母净利30% | 500万以下→授权董事长（第三档） |

这与研究里"平庄能源填1%/5%、深天马填10%/50%"同源——**同一模板、数字差十倍**，再次印证"重大"弹性，skill 必须用 P1 原文。

## 四、大额度资金运作的特殊原则（最该固化的一条）

清单第四条明示：

> **（一）大额度资金运作应与资金用途事项一并决策。**

含义与对 skill 的硬性要求：
- 资金类**不独立比金额**，而是跟着用途（投资/采购/捐赠/担保）合并判定。
- 预算内投融资还贷、大额合同付款 → 授权总经理（预算已二次确认）。
- **超预算资金调动（含捐赠赞助）** → 党委前置+董事会+股东大会（增量风险）。
- 年度捐赠预算总额内调整 → 授权董事长；**超预算捐赠** → 升格。
- ⇒ skill 若本事项已随"用途"类判定，则**不再单独判定资金类**，避免重复或漏判。

## 五、金融衍生 / 担保 / 财务资助：直移植交易所"五条标准"

清单担保（四-6）、财务资助（四-7）条款与研究中"十几家企业字面雷同"一致：
- 担保：单笔 >净资产10% / 总额 >净资产50% / 总资产30% / 负债率70%以上 / 12月累计超线
- 财务资助：单笔 >净资产10% / 负债率70% / 12月累计 >净资产10%

⇒ 这类事项**整类纳入**核查，阈值直接采用 P1 移植的交易所标准。

## 六、Step 2 匹配演示

**示例 1（采购极性反转）**：用户申报"公司直接管理的服务类采购，合同 80 万元"
- 匹配：第三条(十)-1「由公司直接管理的物资类、施工类和服务类采购，授权总经理决策」
- 结论：✅ **本清单下不属三重一大**（采购整体授权总经理），与农垦"服务≥20万=三重一大"完全相反
- 路由：授权总经理决策（无需党委前置/董事会）

**示例 2（授权切分）**：用户申报"小型基建项目投资 1200 万元"
- 匹配：第三条(二)-3 小型基建 500万(含)–2000万 → 授权董事长决策
- 结论：✅ 属重大项目安排，但**仅授权董事长**，未达党委前置/董事会线（2000万）
- 路由：授权董事长（非党委会、非股东大会）

**示例 3（资金随用途一并决策）**：用户申报"超预算对外捐赠 30 万元"
- 匹配：第四条(三) 超预算资金调动（含捐赠）→ 党委前置+董事会+股东大会
- 结论：✅ 属大额度资金运作，但**因已随"捐赠/超预算"用途判定**，不另起资金类单独判定
- 路由：党委前置研究讨论 → 董事会审议 → 股东大会决策

## 七、校准结论

1. **采购落点不可预设**：农垦（进）/ 城投（不进）两极对照，skill 必须按 P1 原文，禁止通用假设。
2. **授权切分须精确路由**：「授权董事长」≠「授权总经理」≠「党委前置+董事会」，三级权限直接决定合规结论。
3. **资金随用途一并决策**：大额资金类不独立比金额，已随用途判定的不重复判定。
4. **比例+绝对双锚是主流**：城投大量用"占净资产30%"，与交易所/公司法标准同源，skill 必须解析比例阈值而非只看绝对额。
5. **主体标定形态二分**：农垦型（只列事项）→ 靠框架推断；城投型（逐条标定）→ 直接读取。解析器两类都要兼容。

## 八、首轮未固化透的增量硬性要点

重读清单补出 4 个此前未单独固化的硬点（均来自城投清单原文）：

1. **涉职工利益事项的硬程序留痕**：第一条（十）末尾明示"上述事项原则上应至少提前7日听取企业工会意见，并通过职工代表大会或者其他形式听取职工群众的意见和建议"。⇒ skill 在涉职工切身利益（改制、职工安置、薪酬、中长期激励等）时，除查金额/主体，**须按 P1 清单载明的具体提前期与程序核查留痕**（如某企业要求提前7日听工会+职代会），不能仅以"金额达标"即判合规。→ 已补进 SKILL.md Step 3。

2. **"无金额也上会"的清单明文情形**：第一条（十一）6-（2）诉讼"未达到前款标准或者没有具体涉案金额的诉讼、仲裁事项，董事会基于案件特殊性认为可能对公司股票…产生较大影响"仍上会；金融衍生（八）资质核准及年度计划整类上会不论金额。⇒ **金额不是唯一判定维度**，当清单明文"无金额阈值也须上会"时，skill 不得因金额小判不属。

3. **权限随股权结构区分**：财务资助（七）免于上股东会的例外——"资助对象为公司合并报表范围内的控股子公司，且该控股子公司其他股东中不包含公司的控股股东、实际控制人及其关联人的，可以免于提交股东大会审议"。⇒ 解析时注意清单中"公司/所属企业/控股/参股"的区分，同一事项的决策主体随股权结构变化（如控股 vs 参股、是否含控股股东关联人）。

4. **"其他大额度资金 = 授权董事长"兜底授权条款**：第四条（六）"公司其他大额度资金运作事项，授权董事长决策"。⇒ 与重大决策的"其他重大事项 + 一事一议（党委会/董事会临时认定）"形成对照：资金类用"兜底授权"（归授权董事长），决策类用"兜底认定"（临时认定）。两类兜底机制 skill 都要能路由。
