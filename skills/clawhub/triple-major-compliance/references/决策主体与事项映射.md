# 决策主体与事项映射（通用框架）

> **性质说明**：本文件为"定性范围 + 决策主体权限"的**通用框架**，依据中办发〔2010〕17号、《公司法》、《中国共产党国有企业基层组织工作条例（试行）》、《国有企业公司章程制定管理办法》及典型集团细化指引整理。
> ⚠️ **本框架不含任何量化阈值**。具体"大额度资金"额度、各事项判定线**一律以用户上传的企业 P1 内部清单为准**。本文件仅解决"事项归哪一类、应由哪个治理主体决定/前置/审议"。

## 一、四类事项范围（定性，源自中办发〔2010〕17号）

| 类别 | 核心内容 | 与采购直接相关项 |
|---|---|---|
| 重大决策事项 | 贯彻路线方针政策、发展战略、改制重组、资产调整、产权转让、对外投资、机构调整等 | 涉及采购的资产处置、产权交易等需联动判断 |
| 重要人事任免 | 中层以上经营管理人员、下属单位班子、委派股东代表、推荐董监高 | 一般不直接属采购主场景 |
| 重大项目安排 | 年度投资计划、融资担保、重要设备技术引进、**采购大宗物资和购买服务**、**重大工程建设项目** | **采购主场景落点** |
| 大额度资金运作 | 预算内大额度资金调动使用、**超预算资金调动使用**、大额捐赠赞助 | 采购付款/超预算采购落点（阈值企业自定） |

## 二、五类治理主体及其权限

1. **股东（会）**
   - 《公司法》11 项职权（经营方针/投资计划、董监高选举报酬、预决算、利润分配、增减资、发债、合并分立解散、章程修改等）。
   - **上报股东（会）审批的事项，均须纳入"三重一大"范围，且决定权限在股东（会）。**
   - 股东可通过管控事项清单、子公司章程赋予更多审批权（如中长期战略、年度投资计划审批），须结合管控模式判定。

2. **党组织（决定）**——直接由党组织决定，不前置而直接定：
   - 贯彻落实党和国家路线方针政策、上级党委部署的重大意见/方案；
   - 领导班子/干部/人才队伍建设及重要人事任免、基层党组织与党员队伍建设；
   - 党建工作重要制度制定；党组织工作机构设置调整；
   - 作风建设、纪律建设、思政、精神文明、企业文化、统战、群团等。

3. **党组织（前置研究讨论）**——**必经前置程序**：
   - 除"党组织直接决定"以外的其余"三重一大"事项，**均须在决策前由党组织前置研究讨论**。
   - 依据：《关于进一步推进…的意见》要求董事会/经理班子研究三重一大前与党委沟通；《国有企业公司章程制定管理办法》明确"党组织研究讨论是董事会、经理层决策重大问题的前置程序"。
   - ⚠️ **关键澄清**：仅设**党支部（党总支）**、未设党委会的企业，若具备"人财物重大事项决策权"，由**党支部（党总支）集体研究把关**。"只有党委会才有前置权"的理解是片面的。

4. **职代会（审议/听取）**：
   - 涉及职工切身利益的重大事项须听取职代会意见：重大改革改制改组、合并分立解散清算方案、职工分流安置方案、薪酬及绩效考核制度、中长期激励等。

5. **董事会（审议 / 决定）**：
   - **上报股东的事项，均须先经董事会审议**；其余"三重一大"事项中，除去股东决定、党组织决定的，由董事会决定。
   - 董事会决定示例：中长期发展战略、三年滚动规划、经营计划和投融资方案、内部管理机构设置、经理层聘任及报酬、基本管理制度、全面风险与内控体系、涉及稳定的重大问题处理、较大安全环保事故及社会责任重大事项等。
   - 设董事会时，经理层在"三重一大"中主要角色是**拟订**，而非决定。

6. **经理班子**：
   - 设董事会 → 以拟订为主；
   - 只设执行董事/未设董事会 → 经营层共同参与、集体决策（原应由董事会决定的事项下沉至此）。

## 三、典型决策链（采购类）

```
[党组织前置研究讨论]  ← 重大问题必经前置（党支部/党总支 有决策权时由其集体把关）
        ↓
[职代会审议]          ← 仅当涉职工切身利益（如关联职工安置的改制采购）时插入
        ↓
[董事会审议]          ← 上报股东的事项必经此环节
        ↓
[股东（会）决定]       ← 仅当事项属《公司法》11项/股东管控清单授权时
        ↓
纪要 + 表决记录 + 归档留痕（全程必备）
```
经理层在设董事会时主要承担"拟订"，不入决定环节；未设董事会时参与集体决策。

## 四、采购场景映射速查

| 采购情形 | 归属类别 | 典型决策链 |
|---|---|---|
| 大宗物资采购 / 购买服务 / 重大工程 | 重大项目安排 | 党组织前置 → 董事会/经理层决定（涉职工利益加职代会） |
| 超预算采购 / 预算内大额度采购付款 | 大额度资金运作 | 同上加资金运作维度，阈值看 P1 |
| 采购关联重大改制/职工安置 | 重大项目安排 + 涉职工利益 | 党组织前置 → 职代会审议 → 董事会 →（如需）股东会 |
| 采购属重大投资/增资等需上报股东事项 | 跨越股东 tier | 党组织前置 → 董事会审议 → 股东会决定 |

> 注：具体金额线、哪些情形需上会论证（如单一来源）、授权切分，**全部以 P1 企业清单为准**；本框架仅用于定性归类与主体判定。
