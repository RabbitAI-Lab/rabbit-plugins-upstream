# 四类事项判定路由（实证校准 / 核心判定哲学）

> **依据**：90 家国有及国有背景企业、144 份公开"三重一大"制度文本的实证研究（2024–2025）。
> **一句话**：**"三重一大"的标准不是一把尺，而是四把——项目与资金用数字管，决策用清单管，人事用权限管。** 先判定事项落入哪一类，再套对应匹配方法，不可一律做金额比较。

## 一、四把尺子总表

| 类别 | 主流定法 | 匹配方法 | 必采字段 |
|---|---|---|---|
| 重大决策 | 开列清单（战略77% / 贯彻部署76% / 改制重组75% / 薪酬71% / 产权资产处置68% / 制度64% / 安全59% / 党建53%） | **清单包含判定** + 子项量化 | 是否在列举清单 / 兜底条款 |
| 重要人事 | 名单+层级（111份仅2份量化） | **名单 + 干部管理权限层级** | 岗位是否在 roster、层级是否达线 |
| 重大项目安排 | 必落数字（投资75% / 融资担保62% / 大宗物资采购和购买服务62% / 设备引进54% / 工程48% / 技改48% / 金融衍生41%） | **金额 / 比例阈值** | 金额、占比、预算内/外、累计 |
| 大额度资金运作 | 授权句式（>半数照搬17号文，仅32%写金额） | **是否超领导人员资金权限** | 预算内/外、累计、授权限额 |

## 二、各路匹配细则与实证样例

### 路径A 重大决策：清单管
- 量化标准只落在子项（产权转让 / 资产处置 / 损失核销）：渝开发单项账面 >100 万不良核销；中成股份"单项损失 > 最近审计总资产 0.3%"；临涣水务 >100 万一次性资产处置逐项决策。
- 系统性金额带：平庄能源 / 深天马按占净资产比例分层（经营层 / X%–Y% 董事会 / Y% 以上股东会），平庄填 1%/5%、深天马填 10%/50%——**同模板数字差十倍**，可见"重大"弹性。
- **兜底条款**：几乎每份制度末尾留"其他重大事项"，部分配套"一事一议"（党委会 / 董事会临时认定）。→ skill 遇不_clean匹配，路由兜底 / 一事一议，而非强行 yes/no。
- 注意：年度经营计划 / 预决算仅 46% 列入重大决策，其余放大额资金——"预算算决策还是算钱"各家不同，但**都上会**。skill 跨类别核查"是否上会"。

### 路径B 重要人事：权限管
- 仅中国核电（2025，12 职级含以上）、海汽集团（2022，高级主管级）量化；其余清一色"名单 + 层级"。
- 通行句式：直接管理领导人员及经营管理人员任免 + 三层列举（中层以上 / 下属班子、委派董监高、其他）。
- 逻辑 = 干部管理权限分级：高管依法董事会聘任但须党委前置 / 党管干部酝酿；中层党委会决定；一般人员授权经理层。
- **人事类必采集岗位层级 / 是否干部管理权限内**；党委会先议最刚性。

### 路径C 重大项目安排：数字管
- 定数三法：① 移植监管标准（交易所 10% 披露线 = 董事会审议线、50%+5000 万 = 股东会；公司法 30% 净资产 = 股东会）；② 自定绝对额（久远银海权益投资 2000 万 / 项目 3000 万；海汽集团车辆 2000 万 / 燃料 6000 万）；③ 比例 + 绝对双锚（龙建股份净资产 1%/10%/50% 阶梯 + 绝对额托底）。
- 跨度极大：秦川机床总部 30 万资本性支出即集体决策；中成股份工程定标线 1 亿。
- **采购 / 招标线常另起**：联环药业施工 400 万 / 货物 200 万 / 服务 100 万必须招标 + 向党委（扩大）会汇报；中天火箭工程 400 万 / 1000 万分档。
- **预算内 / 外双轨**：54% 单设预算外且门槛低一数量级（龙建股份预算内 1000 万 / 预算外 100 万）。
- 金融衍生：47 份仅 2 份设金额，其余**整类纳入不论金额**。
- 对外担保：凡量化几乎照搬交易所"五条标准"（单笔 > 净资产 10% / 总额 > 50% / 总资产 30% / 负债率 70% 以上 / 12 月累计超线）。

### 路径D 大额度资金：权限管（额度为辅）
- 中办发〔2010〕17号定义"超过领导人员有权调动使用的资金限额"；>半数照搬，九成以授权表述为基础，仅 32% 写绝对额。
- 金额跨度 10 万（康源水务）— 5000 万（淮北矿业预算外 5000 万–5 亿 / 中科三环 5000 万）。
- **预算双轨**：54% 单设预算外 / 超预算，门槛低一数量级；逻辑：预算内 = 二次确认，预算外 = 增量风险。
- **累计控制**：平庄能源预算外 <100 万可总经理批但累计不超年度预算 1%；蒙水股份捐赠"单笔 20 万或累计 40 万"双线——防化整为零。
- **捐赠赞助单列且门槛极低**：66% 单列，杰赛 1 万 / 兵设 5 万 / 利尔 10 万 / 主流 20–100 万——纪律风险通道，小金额也需集体决策。

## 三、对 skill 的硬性要求
1. **先分类、再匹配**：落入哪一类就用哪把尺，禁止对重大决策 / 人事做金额比较。
2. **必采字段**：预算内 / 外、累计金额、人事类岗位层级。
3. **兜底 / 一事一议路由**：不_clean匹配 → 交党委会 / 董事会认定，禁止强行判定。
4. **采购 / 招标线是独立轴**：与三重一大定性分离，但常内嵌于企业清单，需同时抽取。
5. **金融衍生默认整类纳入**；**捐赠赞助用极低门槛单独核查**。
