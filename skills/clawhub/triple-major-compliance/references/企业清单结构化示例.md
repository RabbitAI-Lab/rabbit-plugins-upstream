# 企业"三重一大"清单结构化示例（校准 / 少样本样例）

> **用途**：演示 skill 如何将一份真实企业清单转化为 Step 2 可消费的"匹配单元"，并验证匹配逻辑。
> **示例企业**：《广东农垦大坪农场有限公司"三重一大"事项清单》（2024-06-17 印发，公开范本）。
> **企业属性**：**地方国企 / 农垦系统**（广东省农垦集团 → 揭阳农垦集团 → 大坪农场有限公司），非央企。可用于验证"地方国企不套用央企53号采购方式四分类"的适用性。

## 一、该企业治理形态（影响决策主体判定）
- 设**党委**（清单由"农场有限公司党委会议审议通过"印发）。
- 设**董事会**，且清单四-6 明确存在"董事会向经营班子授权经营决策的重大事项清单" → 经理层以拟订/授权执行角色为主。
- 涉职工切身利益事项提交**职代会**（清单四-5）。
- 该清单"只列事项、不列各事项决策主体"，决策主体须由 `决策主体与事项映射.md` 框架推断 + 用户《董事会议事规则》《授权清单》确认。

## 二、采购相关"匹配单元"抽取（节选自真实清单）

| 事项名称 | 归属类别 | 采购子类 | 触发阈值 | 采购方式线索 |
|---|---|---|---|---|
| 本级购置 50 万元以上资产 | 重大项目安排(三-6) | 资产购置 | ≥50 万 | 未明，按招投标法/企业制度 |
| 本级公开招标购买服务、服务费 >20 万 | 重大项目安排(三-7) | 服务采购 | ≥20 万 | **公开招标**（农险承包方、评估/税务/法务/券商中介等） |
| 主产业投资 ≥100 万 | 重大项目安排(三-2) | 投资(含设备技术等) | ≥100 万 | — |
| 非主产业投资 ≥50 万 | 重大项目安排(三-3) | 投资 | ≥50 万 | — |
| 混合所有制企业投资 ≥100 万 | 重大项目安排(三-4) | 投资 | ≥100 万 | — |
| 500 万以上项目投资变更 ≥10% | 重大项目安排(三-5) | 投资变更 | 基数≥500万 且 变更≥10% | — |
| 资产净损失 >500 万处置 / 经营性资产报废报损 >净资产10% 或净值 >50 万 | 重大决策(三-6) | 资产处置 | 多阈值 | 办公会议审议 |
| 单项/批量价值 ≥50 万资产出租出借、对外投资、房产处置 | 重大决策(三-7) | 资产处置 | ≥50 万 | 办公会议审议 |
| 评估值 >100 万资产兼并出售 / 土地使用权转让 | 重大决策(三-8) | 资产处置/土地 | >100 万 | — |
| 预算外为下属提供 ≥100 万抵押担保、借款（主/非主产业） | 大额度资金运作(四-6/7) | 资金运作 | ≥100 万 | — |
| 新增预算外 ≥100 万融资方案 | 大额度资金运作(四-4) | 融资 | ≥100 万 | — |
| 200 万以上预算调整 | 大额度资金运作(四-3) | 预算调整 | ≥200 万 | — |
| 5 万以上对外捐赠、赞助 | 大额度资金运作(四-8) | 捐赠 | ≥5 万 | — |

> ⚠️ 注意：该企业**未设"大宗物资采购"笼统线**，而是拆成具体阈值（服务20万、资产购置50万）。skill 必须能解析这种"具体阈值型"清单，也要能解析"笼统类别型"清单，二者不可混用、不得套用通用金额线。

## 三、Step 2 匹配演示

**示例 1**：用户申报"公开招标购买农业保险服务，服务费 28 万元"
- 匹配：重大项目安排(三-7) 购买服务 ≥20 万 ✓
- 结论：✅ 属三重一大（重大项目安排）
- 决策链：党委会前置 → 董事会/经理层（依授权清单）
- 采购方式：清单已内嵌"公开招标"，与招投标法一致，无需套用央企53号四分类

**示例 2**：用户申报"本级购置办公设备 45 万元"
- 匹配：重大项目安排(三-6) 资产购置 ≥50 万 → 45<50 未达
- 复核：重大决策(三-7) ≥50 万资产出租出借/处置 → 购置非处置，不适用
- 结论：⚠️ 按本清单**未达**三重一大阈值，但处于灰色地带下沿（50万×±10%=45–55万）→ 建议提级审议，或确认是否含税后超 50 万

**示例 3**：用户申报"服务采购 15 万元"
- 匹配：三-7 阈值 20 万，15<20 → 不属本清单三重一大（除非落入其他类别）

## 四、校准结论
1. **阈值高度企业化、颗粒化**（服务20万/资产购置50万/投资100或50万），skill 必须解析 P1 原文，禁止套用通用线。
2. **清单常"只列事项不列主体"**，决策主体由框架推断 + 用户议事规则/授权清单确认。
3. **采购方式线索内嵌于清单**（服务>20万=公开招标）；地方国企不自动套用央企53号询比/竞价/谈判/直接四分类。
4. **±10% 灰地带**在 20 万阈值下 = 18–22 万，在 50 万下 = 45–55 万，可用但建议按企业实际敏感度调整。
5. **治理形态差异显著**：该企设党委+董事会+授权清单；若遇仅设党支部（党总支）的企业，前置主体应为党支部（党总支）——Step 1 须采集治理形态字段。
