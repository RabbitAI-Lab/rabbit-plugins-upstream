# 会议纪要要点模板（可直接复制使用）

> 用途：本技能 Step 4 模块 3 输出的可复制模板。所有模板均为**内部辅助草稿**，须由企业按正式议事规则补全、审签、归档。
> ⚠️ 脱敏提示：填写时请勿写入国家秘密、核心商业秘密、个人敏感信息；企业名称、供应商名称、具体金额建议用代号/区间脱敏。

---

## 模板一：党组织前置研究讨论纪要要点（党委/党支部集体研究把关通用）

```
【会议名称】XX 公司党组织前置研究讨论会议纪要
【会议时间】____年__月__日    【会议地点】________
【应到/实到】应到__人，实到__人，缺席__人（列明原因）
【主持人】________  【记录人】________

一、研究事项
  事项名称：________________________________________
  事项类别：□重大决策 □重大项目安排 □大额度资金运作
            □重要人事任免 □其他（兜底/一事一议）
  来源依据：依据 P1《XX 公司"三重一大"决策事项清单》第__条

二、前置研究内容
  1. 事项背景与必要性（含前期论证/可行性说明）：__________
  2. 合规审查意见（须附合规管理部门/首席合规官意见）：
     □已附  □未附（❌ 不得径直提交，须补齐）
  3. 风险与廉洁评估：__________________________________
  4. 是否涉及关联交易/利益冲突：□否 □是（须回避程序________）

三、前置研究结论（仅形成"把关意见"，不作最终经营决策）
  □原则同意，提请董事会/经理层按程序决策
  □原则同意，但须修改______后提请
  □暂不同意，理由：________________________

四、表决情况
  表决方式：□口头 □举手 □无记名投票
  同意__票 / 反对__票 / 弃权__票
  未到会成员意见（书面）：________________________

五、留痕要求
  □会议纪要  □表决记录  □合规审查意见附件  □论证/专家意见
  归档责任部门：________  归档时限：____个工作日内
```

## 模板三：总经理办公会 / 授权决策纪要要点（授权董事长/总经理情形）

```

【会议时间】____年__月__日    【主持人】________
【参会】经理层/相关部门；合规列席：□是 □否

一、决策事项：________________________________________
  授权依据：依据 P1《XX 公司清单》/《董事会授权方案》第__条，
            属「授权总经理 / 授权董事长」决策事项
  是否需党组织前置：□否（依清单不属前置范围） □是（须先前置）

二、事项内容与金额：__________________________________

三、讨论与意见：______________________________________

四、决定
  □同意，按________执行
  □不同意，理由：________________________
  □授权范围内常规审批，走日常采购流程（不属三重一大）

五、留痕
  □会议纪要/签批单  □合规审查（如适用）  □归档
```

## 使用须知

1. **三套模板按主体选填**：党组织前置（模板一）→ 董事会（模板二）→ 经理层/授权（模板三）通常递进；仅设党支部（党总支）且有决策权的企业，用模板一由党支部集体研究把关。
2. **兜底/一事一议**：事项不 clean 匹配清单时，在模板一/二"事项类别"勾选"其他（兜底/一事一议）"，并**明确记录认定理由与表决结果**，作为审计依据。
3. **禁止替代**：本模板不构成正式法律意见，不替代企业按《公司法》《国有企业基层组织工作条例》及内部议事规则作出的正式决议与签章。
4. **关联输出**：与本技能 Step 4 的"决策路径图""风险核查清单""合规声明书"配套使用。
