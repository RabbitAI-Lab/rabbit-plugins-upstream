# 短视频脚本批量生成

## Overview

输入产品 / 主题，批量产出可直接开拍的短视频脚本：每个脚本含钩子、分镜头表、口播文案、字幕文案、音乐音效建议。关键是「批量」与「差异化」——同主题的不同版本必须站在不同角度，而不是换个词的同义重复。

## When to use

- 用户要说短视频脚本、分镜头、口播文案、字幕文案。
- 用户给出产品名称 / 卖点 / 活动主题，要求出脚本或矩阵内容。

## 输入要求

- 必填：产品 / 主题 + 核心卖点。
- 缺省按常识补齐并说明假设：目标平台（抖音 / 视频号 / 小红书 / B 站）、时长（默认 30-45 秒）、目标人群、希望的版本数量（默认 3 个）。

## 脚本结构公式

`前 3 秒钩子` → `痛点共鸣` → `方案出现` → `卖点证明` → `行动号召`

- **钩子（前 3 秒）**：决定完播率。用反常识、提问、冲突、结果前置，不要自我介绍和品牌 slogen。
- **卖点证明**：演示、对比、数据、第三方背书，选最容易被拍出来验证的那一个。
- **行动号召**：明确下一步——点击购物车、评论区扣「1」、到店报暗号，一次只说一个动作。

## Workflow

1. **确认要素**：产品、卖点、人群、平台、时长、版本数。缺的关键信息先问，不缺的直接按假设产出并在开头声明。
2. **定角度矩阵**：为 N 个版本各配一个不同切入点，避免重复：
   - 痛点型（你遇到的问题）
   - 对比型（前后 / 有无 / 新旧）
   - 干货型（教一个技巧，顺带带出产品）
   - 场景型（具体使用场景沉浸式展示）
   - 测评 / 拆解型（第三方视角）
   - 反常识型（打破常见认知）
3. **逐版本写脚本**，每版套下列完整结构。
4. **平台适配收尾**：按目标平台调时长、语速、字幕密度与结尾方式。

## 单脚本输出模板

```
## 版本 1｜痛点型｜标题：xxx
- 一句话卖点：
- 时长 / 平台 / 目标人群：

### 前 3 秒钩子
- 口播：「……」
- 画面：……

### 分镜头表
| 镜头 | 时长 | 画面内容 | 景别 | 运镜 | 口播文案 | 字幕文案 |
|------|------|----------|------|------|----------|----------|

### 音乐 / 音效
- BGM：…（卡点位置：…）
- 音效：…

### 结尾行动号召
- 口播：「……」  字幕：「……」
```

## 平台适配要点

| 平台 | 时长 | 节奏 | 字幕 |
|------|------|------|------|
| 抖音 | 15-45s | 快，镜头 1.5-3s | 必须全程大字幕，短句断行 |
| 视频号 | 30-60s | 中，偏信任感 | 全程字幕，字号偏大 |
| 小红书 | 30-60s | 中，重干货与颜值 | 关键词字幕 + 封面标题 |
| B 站 | 1-3min | 慢，允许铺垫 | 可只在重点处字幕 |

## 关键规则

- **字幕 ≠ 口播全文照搬**：字幕是短句、口语断行，每行不超过 12-15 字。
- **口播口语化**：写出来要能自然念出口，避免书面长句与堆砌形容词。
- **每个镜头都要能拍**：写清楚画面内容与道具，不写「精彩画面」这类空话。
- **版本必须真差异化**：不同版本要有不同钩子类型与不同证明方式。
- **不夸大功效**：食品、美妆、医疗健康类避免绝对化用语与效果承诺。

## 自检清单

- [ ] 每个版本切入点不同，不是同义改写
- [ ] 每个脚本都有可拍摄的分镜表（含景别、运镜）
- [ ] 前 3 秒钩子明确写出来了
- [ ] 口播能念顺、字幕短句分行
- [ ] 有明确的单一行动号召
- [ ] 时长目标与平台匹配
