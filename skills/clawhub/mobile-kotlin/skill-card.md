## Description:

Guides Android developers in writing and refactoring modern Kotlin code with coroutines, Jetpack Compose, Hilt, Room, Gradle, and current Android platform practices.

This skill is ready for commercial/non-commercial use.

## Use Case:

Android developers use this skill when creating or refactoring Kotlin ViewModels, Compose screens, repositories, database and dependency injection code, tests, or Gradle configuration. It provides current Android coding guidance and implementation examples.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Suggested dependency or permission changes may affect the Android app.

Mitigation: Review dependency and manifest permission changes before applying them.

Risk: Database schema changes may affect stored user data.

Mitigation: Review migration changes and their tests before applying them.

Risk: Changing Android SDK levels can alter app behavior and platform requirements.

Mitigation: Ask before changing minSdk, targetSdk, or compileSdk.
