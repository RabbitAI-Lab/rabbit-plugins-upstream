# 橱柜转角，9种利用方法8.5

每家每户少不了橱柜，几乎大多户型都会碰到橱柜转角，此时转角的设计直接决定了空间的利用。
第一种：常规做法。

▲如图这种转角做法，各开各门，小门满足小空间利用，水槽另一边门打开才能使用转角空间。能利用上，但就是拿取东西非常麻烦，而且只能放置一些小的物件，空间相对比较浪费
▲但是这种做法，不论怎么拿取，都非常费力，而且内部也只能塞一些不常用的小物件第二种：交叉层板+联动门▲如图内部交叉层板设计，能充分利用内部空间，拿取也非常方便▲交叉层板设计，还能满足不同物件高低不同的收纳，不论是平时不用的锅碗瓢盆，甚至是小的家电都可以收纳自如▲用来作为厨房里头锅具的收纳，也是完全足够▲也可以根据空间大小，把内部层板内缩，这样上下左右拿取物品更方便▲当然也可以不用交叉层板，但是需要注意板材的固定以及封边处理；交叉层板可以更好满足层板的固定以及后期机器封边的方便▲如果U型厨房，两个转角都可以利用联动门的形式，内部层板根据格局和需求，交叉或者不交叉都是可以满足空间的最大利用的第三种：大角度铰链+对开门▲如图也可以采用大角度铰链对开门的设计，也可以满足转角空间的利用，但是一定注意柜门太小不建议这样做，开启空间相对较小了▲同样对开门内部层板也可以采用交叉做法，满足空间最大化利用，同时满足拿取物品的方便第四种：转角直接留空▲如图转角位置刚好是高低台，此时无法共用转角，采用一边直接留空的形式，内部转角采用收纳盒满足不常用物品的收纳，留下的空间刚好满足一个小推车的位置，拿取使用也更方便▲当然如果害怕直接放小推车凌乱，也可以给留空位置做上柜门，前提是提前需要看好大小位置，防止小推车放进去柜门关不上。这样做关上柜门以后，视觉能更统一▲当然也可以采用特定的小推车，直接安装柜门，这样柜门和小推车一体，转角位置随时拉出来使用收纳空间▲当然也可以转角整体留空，采用这种三部分组成的小推车，用来充分利用转角空间▲也可以一边留空，内部采用抽拉层板设计，这样拿出小推车或者打开柜门以后，层板抽拉自如，拿取物品更方便第五种：斜切钻石转角柜▲如图把转角空间做成斜面处理，来拓展转角空间的大小，增加台面的利用率。一定要注意，除非是小空间无法满足操作台面，才这样使用，否则斜面做法必然会牺牲小户型厨房空间▲注意看上图，如果是直角处理，厨房空间要大很多，而这种斜边处理会占用更多厨房空间，所以前提一定是台面功能无法满足才这样做，比如上图因为切菜没有空间，这样做可以满足更大的切菜空间▲对于没有地方布局水槽的橱柜，也可以利用钻石转角的做法，满足水槽的布局，这个是成就功能牺牲空间，如果功能都可以实现，不建议这种牺牲空间的做法第六种：转角柜抽屉▲如图转角抽屉，造价昂贵，而且内部空间因为做抽屉更小，属于网红款式，但是并不实用▲当然你也可以直接让定制做转角抽屉，但是只要是抽屉，内部空间都会浪费，实际能用的空间非常小，而且定制造价以及难度都比较高▲当然你也可以一边做抽屉，只要定制抽屉是免费《全屋定制，不加钱的项目，可劲造》但是上图一定是柜门和抽屉分别打开，否则抽屉打开旁边柜门是无法打开的第七种：旋转五金拉篮▲如图转角拉篮，太常见的转角五金了，算是懒人的一种解决办法，前提是五金寿命比较长，收纳容量完全小于交叉层板的做法，造价远远高于普通交叉层板的做法。第八种：厨房大角柜▲厨房转角能这样设计当然是最好的，但是唯一的前提条件是空间大，就这一点百分之八十的厨房都无法满足了，虽然实用，但是太占地方了▲而且内部格局也可以采用交叉层板设计，满足不同物品大小的随手放置和拿取▲同样也可以采用大角度铰链对开门，实现空间的最大开启，内部层板可以满足更多的收纳，这种做法要比钻石型更节省地方第九种：吊柜转角的利用
▲如图，吊柜转角斜面处理，采用旋转五金，用来满足调料的随手拿取，非常方便▲如果害怕转角不好利用，也可以采用镂空的形式，可以满足随手拿取物品的需求，如果对油烟难打理心存疑虑最好封闭▲和地柜转角做法类似，联动门也可以解决转角空间的利用
