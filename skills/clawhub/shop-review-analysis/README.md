# 店铺口碑分析 · Shop Review Analysis

一个可移植的 Agent Skill，用跨平台证据回答“这家店怎么样”“值得去吗”“两家店哪个好”。覆盖大众点评、抖音、小红书与公开网页，核对具体分店、评分、人均、价格、口味、服务和好差评。

## 使用示例

- 成都点都德怎么样？重点看近期差评、真实预算和推荐菜。
- 成都有哪些广式早茶值得去？和点都德、大海湾比较价格、口味和差评。
- 使用我当前 Edge 的登录态，分析这家店适不适合两个人聚餐。

## 运行条件

宿主需要联网搜索和网页读取能力。读取登录后资料还需要可连接用户已登录浏览器的工具，以及对应平台的有效登录态。技能不包含爬虫、账号或 API 密钥，不自动安装软件，不绕过登录、验证码、付费或 App 限制。

这是指令工作流，适用于具备上述工具的 Codex、OpenClaw 和其他 Agent Skills 宿主；具体工具由宿主提供。Codex 的 `agents/openai.yaml` 提供可选中文显示信息，其他宿主可忽略。

## 工作方式

先核对城市和分店，再读取原始页面、近期消费体验及评论，区分平台统计、作者体验、宣传内容和分析推断。比较时分开记录平台人均、菜单单价、单次账单、套餐价及额外费用；保留相反体验，不把抽样好评率当成全店好评率。

输出包括消费建议、具体门店、价格和口味特点、负面问题、适合场景、来源链接、日期和覆盖限制。没有数据的字段会明确标注缺失。

## 安装

把整个技能文件夹放入宿主支持的 skills 目录。Codex 用户可放入 `~/.codex/skills/shop-review-analysis/`，再使用 `$shop-review-analysis` 或自然语言触发。OpenClaw 用户按其当前技能导入流程安装本目录或 ZIP；不需要运行仓库中的代码。
