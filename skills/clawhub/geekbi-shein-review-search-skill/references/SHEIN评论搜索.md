# SHEIN 评论搜索方法

## 适用问题

- 提炼好评卖点、差评原因、使用场景、规格偏好与产品改良方向。
- 验证商品评分是否由足够评论支撑，识别重复或极端反馈。
- 比较同一商品不同规格的反馈差异。

接口与字段见 [评论搜索接口](SHEIN评论搜索接口.md)。

## 查询和分析

1. 必须先取得明确商品 ID，并固定站点；不要只凭商品名称猜测。
2. 默认按评论时间倒序取样。要分析痛点时优先查低分评论，再用高分评论核验卖点。
3. 需要完整结论时继续分页，并记录筛选、页数、唯一评论数和时间范围。`total` 来自去重基数统计，超大评论集可能是近似值；不要只按 `total` 停止，应继续到返回不足一页、空页或 10000 条结果窗口上限。
4. 服务端按评论 ID 去重；分析时仍检查重复文案、空评论和仅图片反馈。
5. 将 `specs` 作为规格维度，不把它误写成 SKU ID；图片只作辅助证据。
6. 将发现分为高频共性、特定规格问题、个别异常和仍需验证四类。

## 输出边界

- 评论是用户表达样本，不自动代表全部购买者或真实退货原因。
- 评论量小、时间过旧、规格混杂或文本缺失时降低置信度。
- 不根据评论推断用户敏感属性或未提供的事实。
- 改良建议要对应可观察问题，并说明证据条数和样本边界。
