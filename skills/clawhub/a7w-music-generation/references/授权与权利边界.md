# 授权与权利边界（出片/出歌方必读）

> ⚠️ **本文是作业规范与风险清单，不是法律意见。** 正式的授权书请交由律师定稿。
> 本文解决的是：**你靠转授权赚钱，但你的权利依据在哪里。**

---

## 一、先看清权利链

```
Suno（模型 / 内容上游）
  └─ 中转商
      └─ 算力集市 a7w          ← 你在这里调用 music_generation
          └─ 你（出歌方 / 交付方）
              └─ 买家 / 客户
```

**每一层都需要有"能否继续往下授权"的明确依据。**
任何一层缺失，你出具的授权书就可能**超越你自己的权利范围**。

---

## 二、三个缺口与应对

### 🔴 缺口一：转授权未明确（最高优先）

| 项 | 内容 |
|---|---|
| 现状 | 现有条款只写了版权归属，**未写明能否再许可（转授权）给第三方** |
| 为什么致命 | **你恰恰是靠转授权赚钱的**——权利链里 a7w 那层有没有权往下给，条款没写 |
| 动作 | **取得上游书面确认**，必须是可留存的文字 |

**关键要求：要文字，不要语音。**

语音答复无法举证、无法引用条款、无法写进合同附件。微信打字、邮件、工单均可。

**话术模板（直接复制，微信发给上游）：**

```
您好，想确认一个授权口径，麻烦文字回复就行（不用语音，我要留档）：

我们通过算力集市 music_generation 生成音频，二次剪辑后交付给客户，
交付时会向客户出具授权书。想确认三点：

1）生成的音频，我们是否可以把使用权再许可（转授权）给我们的客户？
2）客户是否可用于商业用途（含广告投放、带货、平台分发）？
3）是否有排他性限制——同一首生成音频，我们能否分别授权给不同客户？

按 1/2/3 文字回复即可，谢谢。
```

拿到回复后，**把这段对话截图 / 导出，与条款一起归档**。

---

### ⚠️ 缺口二：条款来源未留痕

| 项 | 内容 |
|---|---|
| 现状 | 截图看不到平台名 / URL / 生效日期 |
| 后果 | 纠纷时**说不清"这是哪份文件第几条"**——无法作为证据引用 |
| 动作 | 重新留档，要求见下 |

**留档三要素（缺一不可）：**

1. **浏览器地址栏**（完整 URL）
2. **页面上的生效日期 / 更新日期**
3. **整页内容**（不要只截一段）

**做法**：

- 打印为 PDF（Chrome：Ctrl+P → 目标选"另存为 PDF"，勾选"页眉和页脚"以保留 URL 与日期）
- 或截整页图并同时截地址栏
- 命名规范：`平台_条款名_YYYYMMDD.pdf`
- 存进项目的 `_legal/` 目录，纳入版本管理

> 一条没有 URL 和日期的截图，**等于没有**。

---

### ⚠️ 缺口三：侵权责任 100% 由你承担

| 项 | 内容 |
|---|---|
| 现状 | 条款把侵权责任全部归于使用者（"与平台及运营方无关"） |
| 推论 | **你实际是承担最大担保责任的一方** |
| 动作 | 见下面两条红线 |

---

## 三、两条红线

### ❌ 红线一：不要做排他 / 独占授权

**排他独占 = 你在承诺"无第三方权利、只授权给你"** —— 这是担保责任最重的形态。

而你手上并没有上游出具的"可排他授权"依据。一旦上游把同一素材也授权给别人，
**违约的是你**。

**只做非排他授权**：同一音频可分别授权给多个客户，授权书里写明保留另行授权的权利。

### ❌ 红线二：授权书里不要出现绝对化担保

以下表述**不要写**：

- "保证原创"
- "保证不侵犯第三方权利"
- "独家授权 / 排他授权 / 唯一授权"
- "上游权利已全部取得"

改成"**不承担上游权利担保**"的边界表述。

## 四、授权书条款模板（可抄，建议律师过一遍）

```
一、授权范围

  1. 本授权仅授予【音频作品的使用权】，不构成任何上游权利（含但不限于
     模型提供方、算力平台及其上游供应商）的转让、担保或承诺。

  2. 本授权为【非排他、非独占】授权。授权方保留就同一音频向第三方
     另行授权的权利。

  3. 被授权方不得再向第三方转授权，除非事先取得授权方书面同意。

二、权利声明与免责

  1. 授权方不就音频的原创性、无第三方权利负担作出任何明示或默示担保。

  2. 因被授权方的具体使用方式（投放平台规则、二次改编、配合同步等）
     产生的合规责任，由被授权方自行承担。

  3. 上游权利状态发生变化的，授权方不承担赔偿责任，但应及时告知
     被授权方。

三、留痕

  授权方在交付时一并提供上游条款留档（含来源 URL 与日期），供被授权方核验。
```

## 五、开工前自检清单

- [ ] 是否已拿到上游**文字**答复，明确"可以转授权"？
- [ ] 上游条款留档是否含 **URL + 生效日期 + 整页**？
- [ ] 本批授权书是否写明 **非排他 / 非独占**？
- [ ] 是否已删除"保证原创""保证不侵权"等绝对化表述？
- [ ] 是否写明 **仅授予音频使用权，不含上游权利担保**？
- [ ] 是否约定被授权方**不得再转授权**（除非书面同意）？
- [ ] 上游答复与条款留档是否已归档到 `_legal/`？

---

## 六、一句话记住

> 你卖的是**音频使用权**，不是**版权本身**；
> 你给客户的是**非排他许可**，不是**独占授权**；
> 上游没写明能往下给的部分，**不要替它承诺**。
