## REA5-环境与恢复域范本

### 范本概述

覆盖 REA5-01~REA5-03 的产物样式：环境核验清单、故障处置记录、更新卸载记录。支持域产出，任何阶段可用。

### 范本正文

**【REA5-01 环境适配核验】核验清单样例**：

```markdown
## 环境核验
- 用例场景：{{JS 静态分析（无需引擎）}} → 就绪：工具可用，可进入 REA1

- 引擎：{{未配置（当前任务不需要）}}；若后续需要原生伪代码，需配置 Ghidra 或 IDA
- 额外依赖：{{无 / JADX 待配置（安卓任务时）}}
```

**【REA5-02 连接与故障处置】处置记录样例**：

```markdown
## 故障处置记录
- 症状：首次调用分析超时
- 定位：首次运行正在下载分析引擎包（体积较大）
- 处置：等待 2 分钟后重试一次
- 验证：第二次调用成功（秒级返回）
- 回到原任务：从 REA1-03 概要总览继续（未重做已完成步骤）
```

**【REA5-03 更新与卸载】操作记录样例**：

```markdown
## 操作记录
- 动作：{{在连接器市场更新到新版本 / npx rea-agents@latest setup 刷新}}
- 验证：工具可用；版本号 {{x.y.z}}
- 备注：证据文件与用户项目未受影响
```

### 结构要点标注

1. 处置恒为「诊断 → 修复 → 继续原任务」，禁止反复重装。
2. 症状先对照 requirements REA5-02 的故障表定位，再处置。
3. 修复后从断点继续，不从头重做。
4. 更新/卸载不得影响证据文件与用户项目。

### 替换清单

症状/定位/动作/验证结果替换为真实值；核验项按实际任务所需能力裁剪。
