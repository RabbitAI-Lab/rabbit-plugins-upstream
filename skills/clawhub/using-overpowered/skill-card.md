## Description:

Routes knowledge-work and enterprise-automation tasks through the smallest relevant combination of Overpowered suite skills, invoking gear-up only when a material execution capability is genuinely missing.

This skill is ready for commercial/non-commercial use.

## Publisher:

[raguets](https://clawhub.ai/user/raguets)

### License/Terms of Use:

MIT-0

## Use Case:

Agents and developers use this orchestration skill to choose a minimal set of Overpowered suite methods for complex knowledge work, enterprise automation, conflicting evidence, evolving artifacts, risky side effects, or proven capability gaps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate for broad enterprise or knowledge-work tasks and recommend downstream skills with sensitive access, mutation authority, automation, or durable-skill creation paths.

Mitigation: Review downstream skills separately before granting sensitive access or mutation authority.

Risk: Incorrect routing could add unnecessary skills or miss a relevant review step before risky side effects.

Mitigation: Confirm that the selected skill set is minimal and covers the task's material failure modes before acting.
