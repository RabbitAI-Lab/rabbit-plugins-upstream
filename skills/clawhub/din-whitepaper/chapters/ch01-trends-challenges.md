# 第1章：业务发展趋势与挑战

## 核心观点
AI 推理时代到来，网络流量模式从"内容分发"转向"模型访问+智能体协作"，集中式部署无法应对亿级并发，需要从网络层重构基础设施。

## 两大趋势

- **趋势一：AI 普及速度显著加快，用户从访问内容向访问 AI 模型转变**
  - DeepSeek-R1（2025-01-20 发布）以极低成本实现国际顶尖性能：推理速度提升 4 倍，API 调用成本仅为 GPT-4-Turbo 的近百分之一
  - 发布后不到一个月，DAU 从 100 万突破 3000 万，刷新行业纪录
  - 国内外 50+ 企业宣布接入（网安、汽车、智能硬件、金融、芯片、云服务），AI 从聊天工具演进为生产生活工具，形成不可逆的新业务场景
- **趋势二：AI Agent 无处不在，Agent 间通信显著增长**
  - Manus 发布多 AI Agent 协作视频，OpenAI 推出 Operator 智能体
  - 供应链、金融等复杂任务催生去中心化、高度实时、安全敏感的 Agent 间通信流量

## 流量模式的三重变化

- **南北向流量持续增长**：端云多模态交互。预测 2030 年仅中国市场 AI Token 引发日均网络流量 500TB，是当前全国移动网络日均总流量的 5.5 倍
- **东西向流量持续增长**：多 Agent 系统、分布式训练/推理架构的频繁协作（如金融风控中信用评估 Agent 与反欺诈 Agent 实时交换数据）
- **时延新要求**：复杂推理是多步骤流水线调用（通信→智算→存储→外部服务），时延过高直接导致用户放弃服务

## 三大挑战

1. **AI 推理基础设施能力不足**：全国移动电话 17.9 亿、宽带 6.7 亿、移动物联网 26.56 亿。十亿级并发时服务器与网络资源不足导致大量请求失败
2. **AI 推理网络架构及技术待完善**：需要在用户/IoT/智能体与算力资源之间构建高效并发访问的分布式推理网络，提供确定性体验保障
3. **AI 服务网络安全防护能力待提升**：数据安全与隐私泄露、数据篡改、资源滥用与恶意攻击、模型窃取与训练中断。DeepSeek 案例：峰值访问量超 4900 万次/日，多次服务不可用；2025-01-28 起遭大规模攻击，奇安信监测显示攻击从放大攻击演变为 HTTP 代理攻击，1/30 升级为由僵尸网络主导的攻击，烈度暴增上百倍

## 反模式
- **继续按云计算时代"云为中心"架构承载 AI 流量**：东西向+南北向双重增长超出传统架构设计假设
- **只扩算力不建网络**：推理体验的瓶颈在"最后一公里"的传输质量与调度，不在单纯算力堆叠

## 关键启示
1. AI 推理流量是确定性问题（时延/抖动/丢包敏感），不是尽力而为问题
2. Agent 间通信是新的流量物种，安全敏感且去中心化
3. 网络必须与算力协同设计（算网一体），不是算力的附属管道
