# DIN 技术白皮书 · 速查表

判断逻辑与量化阈值，一页纸掌握全书的"决策规则"。

## 一、场景 → 协同模式选型

- 数据保密+分支访问总部 → 算网一体安全推理（推理一体机 + 智享 WAN）
- 微调大模型但建不起本地集群 → 边云协同后训练（本地几卡 + 云租余量）
- 本地扩容难（机房/电力/液冷受限）→ 模型分层协同（Split Learning）
- 边缘即时响应 + 云端高精度兼顾 → 大小模型协同
- 场景漂移导致边缘模型精度降 → 训推协同进化（中训边推）
- 端到端时延敏感（具身智能/车路云）→ PD 分离

## 二、量化阈值（全书的硬数字）

- 协同训练丢包率红线：10⁻⁵ → 算效损失 >8%；目标 <10⁻⁹
- 协同训练时延抖动红线：数十 ms 时延 / 十 ms 抖动 → 吞吐降 >50%
- PD 分离丢包红线：10⁻⁵ → 推理服务直接中断（RDMA 流水破坏）
- KV Cache：MB-GB 级，首 token 百毫秒内传完
- 隐变量：几 KB-几十 KB，TBT 亚毫秒级抖动
- Qwen72B 微调成本对比：纯本地 128 卡 vs 边云协同本地 8 卡 + 云 120 卡
- 切片参考档位：时延 <1ms / 带宽 >10Gbps / 丢包 <0.01%
- DDoS 感知：分钟级 → 秒级（百毫秒周期 1:1 流统计）
- 2030 预测：中国 AI Token 日均流量 500TB = 当前全国移动日均 5.5 倍
- DeepSeek 基准：DAU 一月 100 万→3000 万；峰值 4900 万次/日；API 成本 ≈ GPT-4-Turbo 的 1/100

## 三、技术 → 解决问题映射

- 微流级流控 → 云边关键数据传输零丢包（队列隔离 + 反压）
- 层次化细粒度切片 → 差异化 SLA 硬隔离（G-SRv6 + 随流检测秒级纠偏）
- ARN / AI 业务识别 → 按应用分级服务（双向解耦）
- 集中式调度 / 算力路由 → 海量并发下的最优节点选择
- PHYSec → 长距链路零开销加密（257B 码块，物理层透明）
- DDoS 智能防护 → 秒级感知 + 前置溯源过滤
- 白+黑 APT 监测 → 基础设施自身防劫持

## 四、信号识别（看到什么意味着什么）

- 看到"RDMA + 丢包敏感" → 必须 10⁻⁹ 级丢包保障（微流级流控 + PFC 协同）
- 看到"KV Cache 跨广域" → 必须大带宽 + 百毫秒传输 + PHYSec 加密
- 看到"数据不出园区" → Split Learning 首尾层在边缘
- 看到"Agent 间通信" → 东西向流量，去中心化、安全敏感，规划切片和隔离
- 看到"MACSec 开销大" → 换 PHYSec（相干链路前提）
- 看到"秒级泛洪攻击" → 传统抽样检测失效，需要嵌入式 1:1 流统计

## 五、立场与边界

- DIN 是运营商立场方案：核心是把运营商存量能力（SRv6、切片、调度、相干传输）延伸到推理时代
- 不是所有场景都需要 DIN：单点部署、低并发、非敏感数据的传统推理服务用现有网络即可
- 白皮书未覆盖：具体商业模式、部署成本模型、与具体芯片/服务器厂商的适配
