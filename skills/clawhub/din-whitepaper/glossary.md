# DIN 技术白皮书 · 术语表

按字母序，定义含章节出处。

- **AI Agent（智能体）** — 具备自主决策与交互能力，可协同完成复杂任务的软件实体（Ch1）
- **ARN（Application Responsive Network，应用响应网络）** — 应用与网络之间的中间层，基于数据面开放网络能力可编程，让应用像调用操作系统一样调用网络资源；实现地址与服务解耦、网络与应用解耦（Ch4）
- **边云协同后训练（Post Training）** — 边缘部署模型首尾层保数据不出园区，云侧租用算力协同完成微调，RDMA 流水线并行，算效损失目标 <5%（Ch2）
- **层次化细粒度切片** — G-SRv6 融合网络切片，将物理网络按时延/带宽/可靠性维度划分（如 <1ms、>10Gbps、<0.01% 丢包），物理资源硬隔离（Ch4）
- **大小模型协同** — 大模型统筹+小模型执行的三种策略：能力调度、推理加速、场景自适应（Ch2）
- **DIN（Distributed Inference Network，分布式推理网络）** — 中国移动提出的面向普惠 AI 的新型网络，分布式架构实现端边网算协同（前言、Ch3）
- **东西向流量** — Agent 间、边云协同产生的横向流量，大带宽、高突发、对丢包高度敏感（Ch1、Ch3）
- **分布式推理** — 推理任务在端、边、云多节点拆分部署协同执行（Ch2）
- **G-SRv6** — 压缩型 SRv6 技术，提供高效可编程路径（Ch4）
- **PD 分离（Prefill-Decode 分离）** — Prefill（计算密集）在中心、Decode（访存密集）在边缘，KV Cache 中心下发边缘，RDMA 连接（Ch2）
- **PHYSec（以太网相干物理层安全）** — 安全协议下沉物理层对 257B 码流全加密，原生 PAD 域承载安全参数，零加密开销、上层透明（Ch4）
- **Split Learning（模型分层协同）** — 模型前几层与后几层部署边缘、其他层在云端，隐变量协同，保障原始数据不出园区（Ch2）
- **算力路由** — 算力感知、通告、联合路由的分布式调度方案，基于"算力+网络"多因子联合调度（Ch4）
- **算网一体安全推理** — "推理一体机/服务器 + 智享 WAN"（SRv6+IPSec 加密隧道）的高安全推理服务（Ch2）
- **随流检测** — 在业务流中嵌入检测标记（流标识、时间戳、序列号）逐跳采集时延/抖动/丢包，驱动 SRv6 路径秒级重优化（Ch4）
- **TBT（Time-Between-Tokens）** — Token 间时延，分层协同场景的 SLA 指标（亚毫秒级抖动）（Ch2）
- **TTFT（Time to First Token）** — 首 token 时延，PD 分离场景要求 KV Cache 百毫秒内完成传输（Ch2）
- **微流级流控** — 租户级+业务流级队列隔离、反压阈值精确控制、零丢包弹性传输（Ch4）
- **南北向流量** — 用户访问推理服务的纵向流量，高安全、高频交互、快速膨胀、对抖动极为敏感（Ch1、Ch3）
- **训推协同进化（中训边推）** — 边缘小模型收集不确定性数据上传，云端蒸馏后下发参数更新的闭环（Ch2）
- **隐变量** — Split Learning 云边协同传输的中间计算结果，几 KB 到几十 KB（Ch2）
- **KV Cache** — 推理过程的键值缓存，MB 到 GB 级，PD 分离场景的核心传输对象（Ch2）
- **智享 WAN** — 中国移动 Overlay+Underlay 融合 WAN 产品，基于 SRv6 和 IPSec 快速构建安全加密通道（Ch2）
- **确定性连接** — DIN 设计目标之一：广域丢包率 <10⁻⁹、微秒级抖动的数据传输能力（Ch3）
- **普惠 AI** — AI 服务低成本、广覆盖、人人可用的目标形态（前言）
- **AI Token 流量** — AI 推理引发的日均网络流量，2030 年中国市场预测 500TB/日（Ch1）
