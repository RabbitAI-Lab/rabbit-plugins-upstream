# DIN 技术白皮书 · 模式与技法库

## 一、协同推理模式（六种）

### 算网一体安全推理
- **何时用**：政务/金融/医疗等高保密行业，分支访问总部推理服务
- **怎么做**：总部推理一体机/服务器 + 智享 WAN（SRv6+IPSec 隧道加密）
- **代价**：加密通道开销，但保障数据全链路安全

### 边云协同后训练
- **何时用**：企业想微调大模型但本地建不起完整集群（Qwen72B 本地 128 卡 vs 本地 8 卡+云 120 卡）
- **怎么做**：模型首尾层在边缘（原始数据不出园区），中间层在云端，RDMA 流水线并行，计算掩盖通信
- **网络硬指标**：丢包 <10⁻⁹（10⁻⁵ 即损失 >8% 算效）；数十 ms 时延/十 ms 抖动即吞吐降 >50%；算效损失目标 <5%
- **代价**：网络不达标则训练吞吐腰斩

### 模型分层协同（Split Learning）
- **何时用**：企业本地扩容难（硬装周期长/无液冷/电力受限），推理数据敏感
- **怎么做**：前几层+后几层在边缘，其他层在云端，隐变量协同；可叠加 PD 分离（Prefill 与 Decode 首尾层在边缘）
- **网络硬指标**：隐变量几 KB-几十 KB，TBT 亚毫秒级抖动，零丢包
- **代价**：Split Learning 本身有计算开销，需合理切分层

### 大小模型协同
- **何时用**：兼顾精度与效率，或边缘资源受限
- **怎么做**：三策略——能力调度（大模型调用小模型）、推理加速（小模型先出结果大模型校正）、场景自适应（网络好走云端，边缘即时走本地）
- **网络侧**：设备内置 NPU+NP+CPU 异构算力板卡（几到几百 TFlops），"连接→感知→推理"跃迁

### 训推协同进化（中训边推）
- **何时用**：边缘小模型泛化能力不足、场景漂移导致精度骤降（如家庭机器人）
- **怎么做**：分级过滤收集不确定性数据（案例→token 粒度）→ 上传云端 → 适配器知识蒸馏微调 → 下发参数更新
- **安全**：云边通道加密（PHYSec），防参数窃取篡改

### PD 分离协同
- **何时用**：延迟敏感型服务（家庭具身智能、车路云协同）受广域网抖动影响
- **怎么做**：Prefill 在中心，KV Cache 下发边缘，Decode 在边缘流式返回；边缘存 KV Cache 降后续计算代价
- **网络硬指标**：KV Cache MB-GB 级百毫秒内传完；RDMA 连接 10⁻⁵ 丢包即服务中断

## 二、网络关键技术

### 微流级流控
- **何时用**：云边协同传输关键数据（隐变量、梯度、KV Cache），丢包敏感
- **怎么做**：租户级+业务流级队列隔离 → 每队列反压阈值 → 超阈值即发反压报文通知上游暂停 → 回落至停止门限恢复 → 零丢包弹性传输；边缘协同 DC 内 PFC
- **权衡**：牺牲部分链路利用率换零丢包；后续结合 AI 流量预测做主动拥塞避免

### 层次化细粒度切片（G-SRv6）
- **何时用**：多业务共用网络，需差异化 SLA 精准承诺
- **怎么做**：物理网络按维度切片（<1ms 时延型 / >10Gbps 带宽型 / <0.01% 丢包型）→ 应用识别后引入对应切片 → 物理资源硬隔离
- **运维闭环**：随流检测（流标识+时间戳+序列号逐跳采集）→ 质量地图 → SLA 偏差触发 SRv6 路径秒级重优化
- **权衡**：切片粒度 vs 资源利用率

### 推理业务识别（ARN）
- **何时用**：需要按应用提供差异化推理服务
- **怎么做**：端侧携带 ARN 标识（IPv6 可编程空间）→ 网络入口按标识分级服务；端侧无能力时网络侧 AI 识别（决策树/神经网络/知识推理增强/多专家）打标
- **设计哲学**：双向解耦——网络不感知应用（屏蔽多样性），应用不直触网络（双向封装隐藏隐私）

### 推理服务调度
- **集中式**：DNS → DIN 调度器（负载/就近/网络质量/均衡）→ 返回最优节点 IP → 用户直连
- **分布式（算力路由）**：边缘节点查算力路由表，"算力+网络"多因子联合调度
- **权衡**：集中式全局最优但调度器是瓶颈/单点；分布式可扩展但收敛复杂

### 以太网相干 PHYSec
- **何时用**：长距相干链路传输模型参数/KV Cache，MACSec 开销太大
- **怎么做**：安全协议下沉物理层 → 257B 码块 GMP 映射 → 相干复帧内比特流加密 → 原生 PAD 域承载安全参数 → 接收端解密还原
- **收益**：零加密开销、上层协议透明、掩盖流量特征、兼容 FlexOsec
- **权衡**：需相干链路硬件支持

### DDoS 智能防护
- **检测**：百毫秒周期多维流行为 1:1 统计 + 每 IP 流量模型流式学习 → 秒级感知（传统分钟级）
- **处置**：AI 溯源识别攻击源 → 前置过滤 + 线速处理流量型攻击 → 缓解清洗池压力
- **背景**：全球最大攻击已达 Tbps 量级，清洗带宽跟不上攻击增长

### 轻量化 APT 监测（白+黑）
- **何时用**：DIN 基础设施自身的入侵检测
- **怎么做**：白名单正常行为 + APT 知识库（样本特征+行为模式）→ 监控内核关键数据对象/系统文件/账号配置/异常进程
- **目标**：感知隐蔽持久的 APT 劫持

## 三、选型判断

- 数据不出园区是硬要求 → Split Learning 类（后训练/分层协同）
- 端到端时延敏感（车路云、具身）→ PD 分离
- 模型迭代快、场景漂移 → 训推协同进化
- 高并发访问瓶颈 → 调度技术（集中式起步，分布式演进）
- 长距链路安全 → PHYSec 替代 MACSec
