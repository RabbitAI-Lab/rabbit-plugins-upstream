# 创意元素六维度模型

## 维度详解

### 1. 色彩（color）

提取画面中的主色、辅色、点缀色，以及色彩之间的关系和调性。

| 子维度 | 提取内容 | 描述示例 |
|--------|---------|---------|
| 主色 | 画面中面积最大的 1-2 种颜色，附 HEX 色值 | "雾霾蓝 #7BA7BC"、"奶白 #F5F0EB" |
| 辅色 | 与主色搭配的次要颜色 | "浅灰 #D4D0CC"、"米黄 #EDE4D4" |
| 点缀色 | 小面积但高对比度的强调色 | "焦糖棕 #B5704F"、"珊瑚橘 #E8734A" |
| 色彩关系 | 色调搭配方式 | 互补色、类比色、单色调、三色搭配 |
| 饱和度 | 整体色彩鲜艳度 | 低饱和（莫兰迪）、高饱和（波普）、中等 |
| 明度 | 整体明暗倾向 | 高明度（明亮清新）、低明度（沉稳深邃） |

**常见色彩风格关键词**：莫兰迪色系、大地色、赛博朋克霓虹、马卡龙色、日系透明色、胶片色、复古色、克莱因蓝、多巴胺配色。

### 2. 材质/质感（texture）

提取画面中物体的表面纹理、材料感和光影特征。

| 子维度 | 提取内容 | 描述示例 |
|--------|---------|---------|
| 表面纹理 | 物体表面的物理肌理 | 编织纹、木纹、大理石纹、褶皱肌理 |
| 材料感 | 材质给人的触觉联想 | 磨砂金属、水洗棉麻、丝绒、液态玻璃 |
| 光泽度 | 反光特性 | 哑光、半光泽、镜面高光、油润感 |
| 透明度 | 光线穿透感 | 不透明、半透明（磨砂玻璃）、全透明 |

**常见材质关键词**：磨砂、拉丝、编织、针织、陶瓷釉面、原木、水磨石、亚克力、黄铜、做旧皮革、水泥、硅胶、亚麻、天鹅绒。

### 3. 风格标签（style）

提取画面的设计流派、文化风格和时代特征。

| 类别 | 关键词示例 |
|------|-----------|
| 东方美学 | 新中式、日式侘寂、禅意、东方极简、和风 |
| 西方现代 | 包豪斯、北欧极简、工业风、Art Deco、中世纪现代 |
| 复古/怀旧 | Y2K、80s 霓虹、复古未来、蒸汽波、维多利亚 |
| 自然/有机 | 波西米亚、田园、有机现代、生物亲和 |
| 前卫/实验 | 赛博朋克、解构主义、酸性设计、超现实主义 |
| 生活美学 | 慢生活、hygge、侘寂、地中海 |

**注意**：风格标签应该具体到可操作的粒度。"好看"不是风格，"日式侘寂 + 自然主义"才是。如果一个画面融合了多种风格，标注主要风格和次要风格。

### 4. 场景氛围（atmosphere）

提取画面传达的空间感、情绪基调和光线条件。

| 子维度 | 提取内容 | 描述示例 |
|--------|---------|---------|
| 空间感 | 场景的空间特征 | 开阔自然、紧凑都市、私密温馨、空旷冷寂 |
| 情绪 | 画面传达的情感 | 安静治愈、活力四射、神秘幽深、温暖慵懒 |
| 光线 | 光照条件和方向 | 晨光侧照、漫射柔光、硬光高对比、黄金时段、阴天柔光 |
| 温度感 | 色温倾向 | 暖调（偏黄橙）、冷调（偏蓝青）、中性 |
| 时间感 | 画面暗示的时间 | 清晨、午后、黄昏、深夜 |

**描述原则**：用具体的场景片段而非抽象形容词。"安静的午后光线透过百叶窗"比"温馨"有用得多。

### 5. 装饰图案（pattern）

提取画面中的具体纹样、图形元素和符号。

| 类别 | 关键词示例 |
|------|-----------|
| 自然图案 | 银杏叶、热带植物、樱花、藤蔓、贝壳纹 |
| 几何图案 | 网格、六边形、同心圆、条纹、波点 |
| 文化图案 | 云纹、回纹、佩斯利、阿拉伯花纹、非洲图腾 |
| 工艺图案 | 扎染纹、蜡染、刺绣纹、编织纹、手绘笔触 |
| 抽象图案 | 水墨晕染、泼墨、色块碰撞、渐变流动 |
| 无图案 | 纯色、材质本身即装饰 |

**注意**：如果画面没有明显图案，标注"无显著图案，以材质/色彩本身为装饰"。

### 6. 构图手法（composition）

提取画面的视觉组织方式、视角和空间安排。

| 子维度 | 提取内容 | 描述示例 |
|--------|---------|---------|
| 构图方式 | 主体的位置安排 | 中心对称、三分法、对角线、框中框 |
| 留白 | 空白区域的占比和作用 | 大面积留白、紧凑填满、适度留白 |
| 视角 | 拍摄/观看角度 | 平视、鸟瞰、微距特写、仰视 |
| 景深 | 焦点和虚化 | 浅景深虚化背景、全景清晰、前景虚化 |
| 层次 | 前后景关系 | 单层平面、前中后三层、多层叠加 |

**产品摄影常用构图**：中心构图（突出产品）、45度角（展示立体感）、平铺俯拍（flat lay）、场景化构图（产品在使用场景中）。

## 提取 Prompt（Stage 1 内部使用）

读取图片后，使用以下结构进行分析：

```
请仔细分析这张图片的视觉创意元素，按以下六个维度逐一提取。
每个维度给出 2-3 个具体描述项，并评估你对该维度提取结果的置信度（0-1）。

1. 色彩：识别主色、辅色、点缀色（附 HEX 色值），以及色彩关系（互补/类比/单色调）和饱和度倾向
2. 材质/质感：识别表面纹理、材料感和光泽特性
3. 风格标签：判断设计流派、文化风格、时代特征（给 2-3 个具体标签）
4. 场景氛围：描述空间感、情绪基调、光线条件和时间感
5. 装饰图案：识别具体纹样、图形元素（如果没有，标注"无显著图案"）
6. 构图手法：分析构图方式、留白比例、视角和景深

输出为 JSON 格式：
{
  "source": "图片简要描述（一句话）",
  "elements": {
    "color": {
      "primary": ["颜色名 #HEX", ...],
      "accent": ["颜色名 #HEX", ...],
      "relationship": "色彩关系描述",
      "saturation": "低/中/高"
    },
    "texture": ["材质描述1", "材质描述2", ...],
    "style": ["风格标签1", "风格标签2", ...],
    "atmosphere": ["氛围描述1", "氛围描述2", ...],
    "pattern": ["图案描述1", "图案描述2", ...] 或 ["无显著图案"],
    "composition": ["构图描述1", "构图描述2", ...]
  },
  "confidence": {
    "color": 0.X,
    "texture": 0.X,
    "style": 0.X,
    "atmosphere": 0.X,
    "pattern": 0.X,
    "composition": 0.X
  }
}
```

**置信度评估标准**：
- 0.9+：视觉特征非常明显，几乎不会误判（如大面积纯色、明显的几何图案）
- 0.7-0.9：特征比较明显，但细节可能有偏差（如材质纹理、风格混合）
- 0.5-0.7：特征模糊或多种解读可能（如氛围情绪、复合风格）
- <0.5：该维度在画面中不突出或难以判断
