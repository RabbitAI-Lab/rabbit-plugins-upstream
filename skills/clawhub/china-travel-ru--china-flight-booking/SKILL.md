# Бронирование авиабилетов в Китай

## Описание

Ваш универсальный помощник для путешествий в Китай. Этот навык предоставляет 5 мощных функций для иностранных туристов:

1. **Поиск авиабилетов** — Поиск рейсов в/из/внутри Китая с ценами и расписанием в реальном времени
2. **Поиск отелей** — Поиск отелей с ценами, рейтингами и ссылками для бронирования в реальном времени
3. **Билеты на достопримечательности** — Открытие достопримечательностей с ценами на билеты и часами работы
4. **Планировщик поездки** — Генерация персональных многодневных планов поездки
5. **Советы для путешественников** — Получение ответов о визе, оплате, транспорте, еде и многом другом

## Поток данных и конфиденциальность

Запросы пользователей отправляются на безопасный прокси-сервер (SCF), который внедряет токены аутентификации и перенаправляет запросы в TripGenie API. Прокси автоматически обрабатывает генерацию партнерских ссылок. Личные данные пользователей не сохраняются и не регистрируются. Все коммуникации зашифрованы по HTTPS.

## Когда использовать

- Найти рейсы в китайский город из вашей страны
- Искать внутренние рейсы между китайскими городами
- Сравнить варианты рейсов по дате, классу кабины или типу поездки

Ключевые слова: рейс в Китай, лететь в Пекин, Шанхай рейс, внутренний рейс Китай, Китай авиабилеты, бизнес класс, эконом

## Выполнение

### Шаг 1: Определение параметров из запроса пользователя

| Параметр | Описание | Пример |
|----------|----------|--------|
| origin | Город/аэропорт вылета (обязательно) | "Moscow" |
| destination | Город/аэропорт прибытия (обязательно) | "Beijing" |
| date | Дата поездки YYYY-MM-DD (обязательно) | "2026-08-15" |
| trip_type | "one way" или "round trip" (необязательно) | "round trip" |
| cabin | Класс кабины (необязательно, по умолчанию: эконом) | "business" |

### Шаг 2: Запуск скрипта

```bash
python scripts/china_travel.py flight "<origin>" "<destination>" "<date>" "[trip_type]" "[cabin]" --locale=ru
```

**Важно:** Всегда включайте параметр `--locale=ru` для получения результатов на русском языке.

### Шаг 3: Отображение результатов

API возвращает структурированный Markdown с названиями авиакомпаний, номерами рейсов, временем вылета/прилета, ценами и ссылками для бронирования. Представьте контент напрямую пользователю.

## Примеры

**Пользователь:** "Найди рейс из Москвы в Пекин 15 августа"
```bash
python scripts/china_travel.py flight "Moscow" "Beijing" "2026-08-15" --locale=ru
```

**Пользователь:** "Туда и обратно бизнес класс из Нью-Йорка в Шанхай"
```bash
python scripts/china_travel.py flight "New York" "Shanghai" "2026-09-01" "round trip" "business" --locale=ru
```

## Другие доступные функции

Этот навык также поддерживает:
- `hotel` — Поиск и бронирование отелей по всему Китаю
- `attraction` — Поиск достопримечательностей и цен на билеты
- `itinerary` — Генерация многодневных планов поездки
- `tips` — Советы для путешественников, виза, оплата, транспорт

## Примечания

- Поддерживаются как названия городов, так и коды аэропортов
- Ссылки для бронирования ведут напрямую на Trip.com (международная версия)
