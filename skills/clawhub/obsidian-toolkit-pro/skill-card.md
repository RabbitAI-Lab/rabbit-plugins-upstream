## Description:

Provides AI agents with Obsidian vault tools for bulk note management, wikilink refactoring, advanced templates, plugin workflows, Canvas editing, multi-vault synchronization, and knowledge graph analysis.

This skill is ready for commercial/non-commercial use.

## Use Case:

Obsidian users and their AI agents can organize and update vaults, create templates and Dataview queries, manage Canvas files, and analyze note links. Review changes before running bulk edits or synchronizing a vault.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Git synchronization can upload private notes or sensitive plugin settings.

Mitigation: Confirm repository access, preserve existing exclusions, exclude private notes and sensitive settings, and review staged contents before pushing.

Risk: Bulk vault changes can move, rewrite, or delete unintended content.

Mitigation: Back up the vault and preview bulk changes before applying them.
