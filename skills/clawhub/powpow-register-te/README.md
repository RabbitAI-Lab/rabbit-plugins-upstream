# powpow-register

PowPow బుడగ రిజిస్ట్రేషన్ అసిస్టెంట్ (OpenClaw వెర్షన్): ఒక కొత్త వినియోగదారుని "బుడగ అంటే ఏమిటో కూడా తెలియని"
స్థితి నుండి "అకౌంట్ యాక్టివేటైంది, వన్-క్లిక్ లాగిన్, ఆడటం మొదలుపెట్టాం" అనే స్థాయికి తీసుకెళ్తుంది —
ప్రొడక్ట్ పరిచయం (UI స్క్రీన్‌షాట్‌లతో సహా), agent తరపున రిజిస్ట్రేషన్ (ప్రొఫైల్ ఫోటో అప్‌లోడ్‌తో సహా),
Alipay/PayPal సబ్‌స్క్రిప్షన్ ఆర్డర్ మరియు డబ్బు రాక ట్రాకింగ్, డబుల్-లింక్ వన్-క్లిక్ లాగిన్, ఎర్రర్ ట్రబుల్‌షూటింగ్.

**v2.0.0 నుండి ఇది ఏజెంట్-సహాయక మోడ్, మరియు v2.2.0 నుండి ప్లాట్‌ఫామ్ ఉచిత పరీక్ష కాలంతో కూడా తగ్గుమారు పొందుతుంది**: కోర్ స్క్రిప్ట్ `scripts/powpow-register.mjs` సున్నా-నిర్భరత వాడదు
(Node ≥ 18); యూజర్ సంభాషణను ఒకే ఒక సారి వదిలేయాలి: ఇన్‌బాక్స్‌లో ధృవీకరణ కోడ్ చూడటానికి. ప్రస్తుత ఉచిత పరీక్ష కాలంలో నిర్మాణమైన ఖాతా వెంటనే అన్ని ఫీచర్లను ఉపయోగించవచ్చు — సబ్‌స్క్రిప్షన్ చెల్లింపు ఐచ్ఛికం; పరీక్ష కాలం ముగిసి యూజర్ సబ్‌స్క్రిప్షన్ పేజీపై దిగితే ప్రవాహం స్వయంచాలకంగా చెల్లింపు పాత్‌కు మారుతుంది. Node లేకుండా, లేదా యూజర్ స్వయంగా చేయాలని కోరినప్పుడు, స్వయంచాలకంగా స్వచ్ఛ మార్గదర్శక మోడ్‌కు తిరిగి వెళ్తుంది.

## ఇన్‌స్టాల్

```
openclaw skills install @durenzidu/powpow-register
```

## ఫీచర్లు

1. **ప్రొడక్ట్ పరిచయం**: ~120 పదాల ఓపెనింగ్ + ప్యాకేజీలో అంతర్గతంగా ఉన్న UI స్క్రీన్‌షాట్‌లు
   (`assets/screenshots/` లో 6 చిత్రాలు: మ్యాప్ పేజీ, పోస్ట్ వివరాల పేజీ మొదలైనవి; సందర్భాన్ని బట్టి 1–3
   చిత్రాలను ఎంచుకుని పంపండి; బాహ్య ఇమేజ్ హోస్టింగ్ అవసరం లేదు, ఆఫ్‌లైన్‌లో కూడా పనిచేస్తాయి).
2. **agent తరపున రిజిస్ట్రేషన్**: agent చురుకుగా యూజర్‌నేమ్/నిక్‌నేమ్ సూచించడం, పాస్‌వర్డ్ రెండింటిలో ఒకటి
   (వినియోగదారు ఇవ్వడం లేదా agent సృష్టించడం), వెరిఫికేషన్ కోడ్ పంపడం మరియు సబ్మిట్ చేయడం, ప్రొఫైల్ ఫోటో
   డైరెక్ట్ అప్‌లోడ్ (≤5MB, SVG కాదు), సాధారణ ఎర్రర్ల ఆటోమేటిక్ స్వాధీనత (ఆక్రమించబడటం/గడువు ముగింపు/రేట్ లిమిట్).
3. **ఒకే-క్లిక్ లాగిన్ (రెండు లింక్లు)**: విజయవంత నిర్మాణం వెంటనే, లాగిన్ లింక్ యూజర్‌ను నేరుగా హోమ్ పేజీకి ఎక్కిస్తుంది (ఉచిత పరీక్ష కాలంలో ఒకే క్లిక్‌తో వాడదు);
   సబ్‌స్క్రిప్షన్ పేజీపై దిగితే (పరీక్ష కాలం ముగిసింది) లేదా యూజర్ అప్‌గ్రేడ్ కోరుకుంటే సబ్‌స్క్రిప్షన్ ప్రవాహాన్ని అనుసరించండి — డబ్బు రాక తర్వాత కొత్త లాగిన్ స్థితికి మార్పు జరుగుతుంది మరియు పూర్తి సభ్యత్వ లింక్ హోమ్ పేజీకి ఎక్కిస్తుంది
   (ప్లాట్‌ఫామ్ అధికారిక `me?token=` సేతువు ద్వారా, ఇది స్వయంచాలకంగా HttpOnly కుక్కీ నాటుతుంది).
4. **సబ్‌స్క్రిప్షన్ చెల్లింపు**: Alipay (నెలవారీ ¥6.99 / త్రైమాసికం ¥19.99 /
   ఏడాది ¥69.99, వన్-టైమ్ కొనుగోలు, ఆటో-రిన్యూ కాదు) మరియు PayPal (Premium Monthly, సుమారు $1/నెల,
   ఆటో-రిన్యూవల్, ఎప్పుడైనా రద్దు చేయవచ్చు) రెండింటిలోనూ agent తరపున ఆర్డర్ + డబ్బు రాక పోలింగ్;
   వీచాట్ QR/హువావే IAP మార్గం చూపిస్తుంది.
5. **ఎర్రర్ ట్రబుల్‌షూటింగ్**: వెరిఫికేషన్ కోడ్ రాకపోవడం, యూజర్‌నేమ్/ఇమెయిల్ ఆక్రమించబడటం, 403 యాక్టివేట్
   కాకపోవడం, అకౌంట్ లాక్ వంటి సాధారణ సమస్యలు — అన్నీ ప్లాట్‌ఫారమ్ సోర్స్ కోడ్ నుండి, ఆధారాలతో సహా.

## భద్రత

- **పాస్‌వర్డ్** ఎన్విరాన్‌మెంట్ వేరియబుల్ ద్వారా మాత్రమే స్క్రిప్ట్ ప్రాసెస్‌లోకి వెళ్తుంది, కమాండ్ లైన్
  పారామీటర్‌లో ఎప్పుడూ రాయబడదు, డిస్క్‌లో నిల్వ ఉండదు, స్టేట్ ఫైల్‌లోకి వెళ్ళదు; agent సృష్టించిన
  పాస్‌వర్డ్ ఒకసారే చూపబడి వినియోగదారు సేవ్ చేసుకోవడానికి ఉపయోగపడుతుంది.
- **వెరిఫికేషన్ కోడ్** అధికారిక రిజిస్ట్రేషన్ API కి మాత్రమే, వాడగానే వదిలివేయబడుతుంది; స్టేట్ ఫైల్
  (ఇమెయిల్/యూజర్‌నేమ్/token/ఆర్డర్ నంబర్) సిస్టమ్ టెంపరరీ డైరెక్టరీలో నిల్వ ఉంటుంది, ప్రక్రియ ముగిశాక
  `cleanup` ఒకే క్లిక్‌తో తొలగించబడుతుంది.
- **చెల్లింపు**: agent ఆర్డర్ సృష్టించడం, చెల్లింపు పేజీ తెరవడం, డబ్బు రాకను పోలింగ్ చేయడం మాత్రమే
  చేస్తుంది; వినియోగదారు Alipay/PayPal అకౌంట్ లేదా చెల్లింపు ఆధారాలను ఎప్పుడూ తాకదు, తరపున చెల్లించదు.
  చెల్లింపు ఎప్పుడూ వినియోగదారు మరియు అధికారిక చెల్లింపు పేజీ మధ్యలోనే జరుగుతుంది.
- అన్ని రిక్వెస్ట్‌లు అధికారిక డొమైన్ `https://global.powpow.online` కి మాత్రమే వెళ్తాయి; ఏ key లుడు ఉండవు.
