# powpow-register

PowPow బబుల్ రిజిస్ట్రేషన్ అసిస్టెంట్ (OpenClaw వెర్షన్): కొత్త వినియోగదారుని «బబుల్ అంటే ఏమిటి» తెలియని స్థితి నుంచి
«ఖాతా యాక్టివేట్ అయి వాడుకోవడానికి సిద్ధం» వరకు తీసుకెళ్లండి — ఉత్పత్తి పరిచయం (ఇంటర్ఫేస్ స్క్రీన్షాట్లతో సహా),
దశలవారీ రిజిస్ట్రేషన్ గైడ్, లోపాల పరిష్కారం, సబ్స్క్రిప్షన్ యాక్టివేషన్ వివరణ.

పూర్తిగా గైడ్-రకం skill, ఎలాంటి స్క్రిప్ట్ లేదు, ఎలాంటి డిపెండెన్సీ లేదు; అన్ని రిజిస్ట్రేషన్ చర్యలు వినియోగదారు
బ్రౌజర్/యాప్లో స్వయంగా పూర్తి చేస్తారు.

## ఇన్స్టాలేషన్

```
openclaw skills install @durenzidu/powpow-register
```

## లక్షణాలు

1. **ఉత్పత్తి పరిచయం**: ~120 పదాల పరిచయం + GitHub పబ్లిక్ రిపోజిటరీలో హోస్ట్ చేయబడిన ఇంటర్ఫేస్ స్క్రీన్షాట్ల లింక్లు
   (మ్యాప్ పేజీ, పోస్ట్ డీటైల్ పేజీ మొదలైన 6 ఫోటోలు, సందర్భానికి తగ్గట్టు 1–3 పంపండి).
2. **రిజిస్ట్రేషన్ గైడ్**: ఫీల్డ్ నియమాలు (యూజర్నేమ్/పాస్వర్డ్/ఇమెయిల్ వెరిఫికేషన్ కోడ్/మొబైల్ నంబర్/ప్రొఫైల్ ఫోటో),
   థర్డ్-పార్టీ లాగిన్ (Google/Watcha/హువావే), రేట్-లిమిట్ పరామితులు, అన్నీ ప్లాట్ఫారమ్ సోర్స్ కోడ్ నుంచి తీసి సోర్స్ సూచించబడ్డాయి.
3. **లోపాల పరిష్కారం**: వెరిఫికేషన్ కోడ్ అందకపోవడం, యూజర్నేమ్/ఇమెయిల్ ఇప్పటికే వాడుకలో ఉండటం, 403 యాక్టివేట్ కాకపోవడం, ఖాతా
   లాక్ మొదలైన 13 సాధారణ సమస్యలు.
4. **సబ్స్క్రిప్షన్ యాక్టివేషన్**: PayPal (వెబ్) / WeChat స్కాన్ (మాన్యువల్ నిర్ధారణ) / హువావే IAP (HarmonyOS) మూడు
   మార్గాల వివరణ మరియు పరిష్కారం; ప్రస్తుత చెల్లింపు చైన్ నేరుగా మళ్లీ వాడుకోవచ్చు, skill కేవలం దారి చూపుతుంది.

## భద్రత

- ఎలాంటి కీ (key) ఉండదు; స్క్రిప్ట్ లేదు, వినియోగదారు రహస్యాలను (credentials) తాకదు.
- **ఎప్పుడూ అడగదు** వినియోగదారు పాస్వర్డ్, వెరిఫికేషన్ కోడ్ లేదా చెల్లింపు రుజువు; రిజిస్ట్రేషన్ మరియు చెల్లింపు అన్నీ ప్లాట్ఫారమ్
  పేజీల్లోనే జరుగుతాయి.
