# 项目周报知识库初始化说明

## 首次使用

### 方式1：手动填写md模板
1. 复制本目录下的模板文件到 `knowledge/项目周报知识库/`
2. 编辑填写项目清单、群聊关联表、成员归属表
3. 完成后说"生成周报"

### 方式2：对话式填写
1. 说"生成周报"
2. AI检测到知识库不存在，询问初始化方式
3. 选择"2. 对话式填写"
4. 按AI提示填写信息

### 方式3：Excel模板填写（推荐）
1. 说"生成周报"
2. AI检测到知识库不存在，询问初始化方式
3. 选择"3. Excel模板填写"
4. AI发送Excel模板文件
5. 下载、填写、上传
6. AI验证并确认后写入

## 模板文件说明

| 文件 | 用途 |
|------|------|
| 项目清单模板.md | 项目基本信息 |
| 群聊关联表模板.md | 项目与群聊对应关系 |
| 成员归属表模板.md | 成员归属分类 |
