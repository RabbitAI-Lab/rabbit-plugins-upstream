## Description: <br>
Sogni Creative Agent Skill lets agents generate and edit images, video, music, personas, loops, and multi-step creative workflows through Sogni AI's decentralized GPU network. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External users, developers, and creative teams use this skill to direct an agent to create, edit, animate, and organize image, video, music, persona, and loop workflows through Sogni AI. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Prompts, referenced media, face photos, voice clips, preferences, and long-term memories may be sent to Sogni or persisted locally when those features are used. <br>
Mitigation: Use these features only with media and memories the user intends to share or persist, avoid saving sensitive persona or memory data unless intentional, and review local Sogni configuration data when privacy matters. <br>
Risk: Self-update, npm, git, sudo, or global package maintenance paths can change installed code or system-level packages. <br>
Mitigation: Approve update or privileged maintenance actions only when they are intentional, and treat update notices as maintenance prompts rather than generation output. <br>
