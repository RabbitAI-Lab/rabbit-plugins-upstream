## Known Risks and Mitigations:

Risk: The skill is a broad reasoning and persona overlay that can reshape agent behavior across many tasks.

Mitigation: Review before installation, prefer workspace-scoped installation, and avoid global persona additions unless that behavior is intended.

Risk: The artifact encourages deeper reasoning and self-correction, which may increase token usage and response latency.

Mitigation: Enable it for tasks that benefit from deeper analysis, such as coding, research, planning, and complex problem-solving.

Risk: A broad skill could interfere with higher-priority host, safety, developer, or user instructions if the host applies it incorrectly.

Mitigation: Verify that the host keeps system, developer, safety, and user instructions above this skill in the instruction hierarchy.
