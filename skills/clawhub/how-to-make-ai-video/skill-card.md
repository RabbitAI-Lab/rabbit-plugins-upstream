## Description:

Finds relevant AI video skills and tutorials on varg how to, then presents suitable options, install commands, and steps for the requested task.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT

## Use Case:

External users and developers use the skill to find suitable AI video creation or editing skills, compare options, and follow installation and generation guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill directs agents to submit newly built skills for publication without a clear user approval step.

Mitigation: Use non-sensitive search prompts, review downstream installation commands, choose deliberately whether to use a varg account, and require explicit approval of the destination and exact submission contents before publishing project details.
