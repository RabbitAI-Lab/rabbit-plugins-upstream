## Description:

Finds suitable AI video tutorials and skills, then outlines options and production steps for an agent to follow.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

AI video creators and agents use this skill to find a suitable video workflow, compare options, and plan production steps before generating media.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow may upload project content to GitHub or send still images to external providers.

Mitigation: Review what each service will receive, use an appropriately private repository, and proceed only when the data sharing is acceptable.

Risk: Recommended skill installation commands are not pinned to a reviewed source revision.

Mitigation: Review the installer and skill source, then pin them to a version or commit before running the install commands.
