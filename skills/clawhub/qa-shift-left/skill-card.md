## Description:

Helps QA and development teams review requirements, design, and code early to identify testability gaps and plan shift-left testing activities.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kokxi](https://clawhub.ai/user/kokxi)

### License/Terms of Use:

MIT-0

## Use Case:

QA practitioners and developers use this skill to assess requirements for testability, review technical designs and code from a testing perspective, and plan early quality gates and test activities.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Short shift-left testing phrases may activate this Chinese-language planning skill unexpectedly.

Mitigation: Confirm the user's intended task and preferred language before applying its checklists.

Risk: Bash access can run commands beyond the planning task if used without oversight.

Mitigation: Keep shell use user-directed and limited to project inspection or test commands.
