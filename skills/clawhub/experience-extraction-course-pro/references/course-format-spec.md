# 课程、PPT 与讲师手册格式规范

仅在开发课程大纲、模块详案、PPT 逐页稿或讲师手册时读取本文件。

## 一、课程定位

```markdown
# [课程名称]

## 课程定位
- 目标学员：
- 典型工作问题：
- 学习基础：
- 课程用途：
- 建议时长：
- 应用场景：
- 资料依据：
- 默认假设与待确认项：
```

学习目标使用“能识别、能判断、能完成、能设计、能纠正”等行为表达。

## 二、课程大纲

```markdown
## 课程大纲

| 模块 | 主要行为目标 | 核心方法 | 案例 | 练习交付物 | 岗位应用 | 建议时长 |
|---|---|---|---|---|---|---|
```

大纲要求：

- 每个模块只有一个主要行为目标。
- 模块从问题识别、方法掌握到综合应用逐步推进。
- 讲解、案例、练习、点评和总结的时间总和不得超过课程时长。
- 不为追求模块数量拆分高度重复的内容。

## 三、模块详案

```markdown
## 模块 X：[模块名称]

- 主要行为目标：
- 应用场景：
- 建议时长：
- 核心问题：
- 核心方法：
  - 适用条件：
  - 判断标准：
  - 关键动作：
  - 预期结果：
  - 风险边界：
- 知识降维：
- 案例：
- 课堂练习：
- 学员交付物：
- 合格标准：
- 优秀标准：
- 常见错误与反馈：
- 岗位应用动作：
- 讲师提示：
```

模块必须满足“目标—方法—案例—练习—点评—应用”闭环。

## 四、PPT 逐页稿

### 1. 单页格式

```markdown
### 第 X 页：[页面类型]

- 页面标题：
- 核心观点：
- 知识要点：
  1. 
  2. 
  3. 
- 本页结论：
- 建议版式：
- 建议视觉素材：
- 讲师提示：
- 案例或互动：
- 建议用时：
```

不是每页都必须放案例和互动。只在关键页填写，普通内容页可写“无”。

### 2. 页面信息限制

| 要素 | 建议 |
|---|---|
| 页面标题 | 约 10—16 字，表达主题 |
| 核心观点 | 一句话说清本页立场 |
| 知识要点 | 通常 3—5 条，避免长段落 |
| 本页结论 | 一句话便于记忆与行动 |
| 建议用时 | 与总课时一致 |

### 3. 常用页面类型

| 页面类型 | 教学作用 | 主要内容 |
|---|---|---|
| 开场页 | 建立问题意识 | 真实痛点、后果、学习价值 |
| 目标页 | 明确成果 | 学员课后能完成的行为 |
| 事件页 | 提供事实 | 场景、任务、行动、结果 |
| 方法总览页 | 建立框架 | 核心方法及关系 |
| 动作页 | 教会执行 | 步骤、工具、注意点 |
| 判断页 | 教会取舍 | 信号、标准、误区、边界 |
| 信念页 | 形成触发 | 信念、行为转化、行动触发器 |
| 降维页 | 解释难点 | 白话、场景、类比、正反例 |
| 案例页 | 展示应用 | 冲突、判断、行动、结果 |
| 练习页 | 促进迁移 | 任务、输入、交付物、标准 |
| 复盘页 | 形成反馈 | 答案、错误、合格与优秀标准 |
| 总结页 | 收束行动 | 核心结论、岗位行动 |

### 4. 页数与时长

页数以教学节奏为准，不机械套固定比例：

- 30 分钟：通常 8—15 页。
- 60 分钟：通常 15—25 页。
- 2 小时：通常 25—45 页。
- 半天：通常 40—70 页。

案例讨论和练习会占用较长时间，应减少对应讲解页数。若逐页建议用时之和超过总课时，必须调整。

## 五、案例

```markdown
### 案例：[名称]

- 案例类型：
- 来源标签：
- 对应目标：
- 背景与角色：
- 关键冲突：
- 限制条件：
- 错误做法：
- 专家判断与行动：
- 结果或后果：
- 方法映射：
- 复盘问题：
- 建议用时：
```

案例页不要提前泄露全部答案。可将情境、讨论与复盘拆为连续页面。

## 六、课堂练习

```markdown
### 练习：[名称]

- 对应目标：
- 练习方式：
- 情境与输入：
- 学员任务：
- 学员交付物：
- 建议用时：
- 点评维度：
- 合格标准：
- 优秀标准：
- 常见错误：
- 参考答案或示例：
```

合格标准回答“最低做到什么算掌握”，优秀标准回答“高质量表现还多了什么”。

## 七、题库

```markdown
## 练习题库

### 题目 X：[名称]
- 题型：
- 对应模块：
- 检验目标：
- 题干：
- 学员任务：
- 参考答案：
- 评分或点评要点：
- 常见错误：
```

题库数量按课程时长和用户要求确定。题型应覆盖动作、判断、纠错和迁移，不必每次凑齐所有类型。

## 八、讲师手册

```markdown
## 讲师手册

### 课前准备
- 需要掌握的背景：
- 需要准备的资料、工具和案例：
- 需要提前了解的学员信息：
- 场地或线上环境：
- 可能涉及的敏感与合规边界：

### 课程运行表
| 环节 | 建议用时 | 讲师动作 | 学员动作 | 关键产出 |
|---|---:|---|---|---|

### 开场与衔接
- 开场问题或案例：
- 模块衔接话术：
- 重点强调：

### 难点预警
| 难点 | 学员可能表现 | 讲解策略 | 备用案例或追问 |
|---|---|---|---|

### 互动话术
| 场景 | 引导话术 | 深挖追问 | 收束方式 |
|---|---|---|---|

### 练习点评指南
- 点评顺序：
- 合格标准：
- 优秀标准：
- 常见错误：
- 纠偏话术：

### 课后跟进
- 学员行动清单：
- 岗位应用任务：
- 一周后回访问题：
- 学习效果证据：
```

讲师提示应解释“怎么教”，不要重复页面文字。

## 九、完整课程交付顺序

用户明确要求完整课程时，建议按以下顺序交付；内容很长时分批输出：

1. 课程定位与资料判断。
2. 方法论萃取与来源说明。
3. 课程大纲与课时分配。
4. 各模块详案。
5. PPT 逐页稿。
6. 案例与课堂练习。
7. 按需题库。
8. 讲师手册。
9. 质量检查与待确认项。

## 十、交付质量检查

| 检查项 | 合格标准 |
|---|---|
| 目标 | 每个核心模块有一个可观察行为目标 |
| 方法 | 有条件、判断、动作、结果、边界 |
| 案例 | 服务目标并呈现真实取舍 |
| 练习 | 有明确交付物 |
| 点评 | 同时有合格标准与优秀标准 |
| 应用 | 明确岗位使用场景和行动 |
| PPT | 页面信息简洁，时长总和合理 |
| 讲师手册 | 提供讲法、互动、纠偏和跟进 |
| 来源 | 原资料、推断、仿真和外网内容分开 |
