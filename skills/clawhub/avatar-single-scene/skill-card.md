## Description:

Use when someone wants one polished host-on-camera beat: a speaking person with intake and approval gates before generation.

This skill is ready for commercial/non-commercial use.

## Use Case:

External creators, marketers, and developers use this skill to plan and generate one approved speaking-avatar video scene with a script, voice choice, portrait or still source, motion prompt, and explicit approval gates before paid generation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prerequisite installation commands may fetch external skill sources.

Mitigation: Review the visible npx install commands before use and pin or otherwise verify skill sources when your environment requires supply-chain controls.

Risk: Portrait, audio, and script material may be uploaded to Pruna generation services.

Mitigation: Use only material you are authorized and comfortable uploading, and apply any privacy, consent, or data-handling requirements before generation.

Risk: Paid generation can spend API credits after approval gates.

Mitigation: Keep the approve plan and approve still gates in place before starting avatar generation.
