Developers and site operators use this checklist to publish a static site on Tencent Cloud COS, configure domain and HTTPS settings, and diagnose access errors.

Global; mainland China custom domains require ICP filing.

## Known Risks and Mitigations:

Risk: Making website objects public or changing DNS, domain binding, and HTTPS settings can expose content or disrupt a live site.

Mitigation: Confirm each cloud-console change before applying it, restrict public read to intended website objects, and verify the site and DNS afterward.
