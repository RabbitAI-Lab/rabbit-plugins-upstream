## Description:

Guides agents through Tencent Cloud COS static-site hosting, custom-domain setup, HTTPS, and troubleshooting.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and site operators use this checklist to publish static files on Tencent COS, connect a custom domain, enable HTTPS, and diagnose access issues.

### Deployment Geography for Use:

Global; custom domains hosted in mainland China require ICP filing.

## Known Risks and Mitigations:

Risk: Broad trigger words such as 'static' or 'site' may activate this guidance in unrelated conversations.

Mitigation: Confirm the user is deploying a Tencent COS static website before applying the checklist.

Risk: Incorrect bucket permissions, DNS, ICP filing, or HTTPS settings can expose files or leave a site inaccessible.

Mitigation: Verify current Tencent Cloud settings and requirements; allow public read only for intended site files and test DNS and HTTPS before launch.
