## 顾问陪谈任务要求清单

顾问陪谈每种任务类型的零件清单——必选组件、可选组件、组装顺序、领域约束。按清单逐项产出。

---

### AC1 心理与关系

#### 域级说明

**域定位**：提供情绪支持、认知梳理与关系议题的陪伴式咨询，严守伦理与转介边界。

| 维度 | 内容 |
|------|------|
| 价值链形态 | 接入→澄清→概念化→干预→转介 |
| 独立成域的理由 | 受伦理与危机识别约束，验收看功能改善与安全，且危机情形优先于任何技术 |
| 穷尽性 | 5 个任务覆盖「接入→澄清→概念化→干预→转介」的 5 个环节；按输入物、失败模式、验收标准三条判据互不重叠，无未覆盖环节 |
| 知识要点 | CBT 认知模型：情境 → 自动思维 → 情绪 → 行为；认知歪曲（全或无、灾难化、读心、过度概括、应该式）；情绪评估：情绪强度 0-10 自评、持续时间、功能影响（睡眠/食欲/工作）；倾听技术：反映、澄清、具体化、情感反映、总结；危机识别：自伤意念、计划、手段可及性；保护性因素；关系议题：依恋类型（安全/焦虑/回避/混乱）、非暴力沟通（观察-感受-需要-请求）、边界设定；伦理：知情同意、保密例外、双重关系禁止、能力边界 |
| 判定标准 | 先建立安全感再进入干预，不得跳步；每次对话须收敛到一个可执行动作；危机信号出现时转介优先于任何技术；不得给诊断标签，只描述现象 |
| 常见失范 | 过早给建议；用"想开点"替代具体技术；越界做诊断；忽略危机信号 |
| 范本结构 | 现状与主诉 → 情绪与功能评估 → 议题概念化 → 本次工作重点 → 可执行动作 → 下次跟进 → 边界与转介说明 |

#### AC1-01 情绪状态评估与澄清
- **必选组件**: 主诉、情绪强度评分、持续时间、功能影响、危机筛查结果
- **可选组件**: 既往史、支持系统
- **组装顺序**: 接住情绪→澄清具体化→评强度→查功能→筛危机
- **约束**: 须做危机筛查；不得贴诊断标签
- **格式**: 评估小结

#### AC1-02 认知重构对话
- **必选组件**: 情境记录、自动思维、歪曲类型、证据检验、替代想法
- **可选组件**: 情绪日志
- **组装顺序**: 还原情境→抓自动思维→标歪曲→查证据→生成替代
- **约束**: 须由来访者自己得出；不得强加
- **格式**: 认知记录表

#### AC1-03 压力与情绪调节训练
- **必选组件**: 技术选择（呼吸/接地/行为激活/延迟行动）、步骤、练习安排
- **可选组件**: 触发场景、可用时间
- **组装顺序**: 定场景→选技术→带练→布置练习→复盘
- **约束**: 技术须当场可练；须给最小剂量
- **格式**: 调节方案+练习记录

#### AC1-04 关系议题咨询
- **必选组件**: 关系图谱、互动模式、依恋倾向、沟通脚本
- **可选组件**: 具体冲突事件
- **组装顺序**: 还原事件→找模式→看边界→写表达脚本→演练
- **约束**: 不得评判关系中的第三方；不得劝分劝合
- **格式**: 关系梳理+沟通脚本

#### AC1-05 咨询资源匹配与转介
- **必选组件**: 边界判定、转介理由、资源类型（精神科/心理咨询/社工/热线）、准备清单
- **可选组件**: 所在地资源、医保情况
- **组装顺序**: 判边界→说明理由→给资源类型→备就诊清单
- **约束**: 须给可及的现实渠道；不得推荐具体牟利机构
- **格式**: 转介建议单

### AC2 命理排盘

#### 域级说明

**域定位**：以四柱八字体系做结构化排盘与文化解读，明示象征属性。

| 维度 | 内容 |
|------|------|
| 价值链形态 | 校时→排盘→旺衰→大运→建议 |
| 独立成域的理由 | 以排盘规则准确性为技术验收点，解读须声明象征属性，不得作确定性断言 |
| 穷尽性 | 4 个任务覆盖「校时→排盘→旺衰→大运→建议」的 5 个环节；按输入物、失败模式、验收标准三条判据互不重叠，无未覆盖环节 |
| 知识要点 | 四柱：年柱、月柱、日柱、时柱，各由天干地支组成；日干为「日主」代表自身；天干十神：比肩、劫财、食神、伤官、偏财、正财、七杀、正官、偏印、正印（依日主与其他干支关系定）；地支藏干：本气、中气、余气；十二长生（长生、沐浴、冠带…）表旺衰；五行生克：木生火、火生土、土生金、金生水、水生木；木克土、土克水、水克火、火克金、金克木；格局：月令取格，正官格、七杀格、正财格、偏财格、食神格、伤官格、正印格、偏印格、建禄格、羊刃格；大运流年：起运岁数按节气与出生日期推算，十年一运；流年逐年；真太阳时校正：按出生地经度与均时差校正出生时间；定格四步：看月令透出何神 → 判日主旺衰（得令/得地/得生/得助）→ 定用神（扶抑、调候、通关三法择一）→ 校验格局是否成立；十神生克链：比劫生食伤、食伤生财、财生官杀、官杀生印、印生比肩；顺生隔位即为克 |
| 判定标准 | 排盘须用真太阳时校正，并说明校正值；四柱须完整对应节气月，不得用农历月替代；解读须区分"盘面事实"与"象征引申"；须明示文化象征属性，不作确定性断言 |
| 常见失范 | 不做真太阳时校正导致时柱错；用农历月代替节气月定月柱；把象征解读说成必然结果；以命理劝阻就医或重大决策 |
| 范本结构 | 排盘基本信息 → 四柱与藏干 → 十神分布 → 五行旺衰 → 格局判定 → 象征性解读 → 建议与声明 |

#### AC2-01 四柱排盘
- **必选组件**: 真太阳时校正、四柱干支、地支藏干、十神表、长生位
- **可选组件**: 出生时间地点、历法转换
- **组装顺序**: 校时→定节气月→排四柱→取藏干→配十神→标长生
- **约束**: 须做真太阳时校正；月柱须按节气
- **格式**: 命盘

#### AC2-02 五行旺衰与格局判定
- **必选组件**: 五行计分表、旺衰判定、格局结论、用神方向
- **可选组件**: 命盘、节气深浅
- **组装顺序**: 统计五行→判旺衰→取月令格→定用神
- **约束**: 须给计分依据；格局须说明取格理由
- **格式**: 旺衰与格局分析

#### AC2-03 大运流年推演
- **必选组件**: 起运岁数、大运表（干支/十神/起止年）、流年要点
- **可选组件**: 命盘、当前年龄
- **组装顺序**: 算起运→排大运→配十神→推流年→标主题
- **约束**: 须说明推算方法；不得给确定性事件预测
- **格式**: 大运流年表

#### AC2-04 命名与用字建议
- **必选组件**: 候选名字、五行属性、字义、音韵、书写
- **可选组件**: 姓氏、性别、家族避讳
- **组装顺序**: 定用神→选五行字→筛字义音形→组合→校验
- **约束**: 须避免生僻字与不良谐音；须说明仅为建议
- **格式**: 命名建议

### AC3 卦象占断

#### 域级说明

**域定位**：以易经、六爻、梅花、小六壬体系起卦解卦，作情境反思之用。

| 维度 | 内容 |
|------|------|
| 价值链形态 | 起卦→成卦→取象→断辞 |
| 独立成域的理由 | 以起卦方法一致与象义对应为验收点，须落到具体情境 |
| 穷尽性 | 4 个任务覆盖「起卦→成卦→取象→断辞」的 4 个环节；按输入物、失败模式、验收标准三条判据互不重叠，无未覆盖环节 |
| 知识要点 | 八卦：乾☰天、兑☱泽、离☲火、震☳雷、巽☴风、坎☵水、艮☶山、坤☷地；六十四卦：上下卦组合，卦名、卦辞、爻辞；本卦、互卦、变卦；六爻：纳甲装卦（京房），配六亲（父母/兄弟/子孙/妻财/官鬼）、六神、世应；动爻与变爻；梅花易数：以时间/数字/外应起卦，体用生克判吉凶；小六壬：大安、留连、速喜、赤口、小吉、空亡，按月日时推位；解卦原则：先看卦象整体，再看动爻，再看世应关系；象数理占并重；装卦五步：定卦宫 → 安世应 → 纳甲支 → 配六亲 → 附六神；动爻以○×标记，变爻另起一卦；用神取法：问财取妻财、问事业取官鬼、问文书取父母、问子女取子孙、问自身取世爻 |
| 判定标准 | 起卦方法须说明并保持一致；卦象须给完整信息（本卦/互卦/变卦/动爻）；解读须落到具体情境，不得空谈卦辞；须明示象征属性 |
| 常见失范 | 起卦方法前后不一；只解卦辞不看动爻；给出确定性祸福断言；以卦象劝阻就医 |
| 范本结构 | 起卦信息与方法 → 卦象（本/互/变） → 卦辞爻辞 → 象义分析 → 情境对应 → 建议与声明 |

#### AC3-01 起卦与卦象生成
- **必选组件**: 起卦方法、时间/数字、本卦、互卦、变卦、动爻
- **可选组件**: 所问事项
- **组装顺序**: 定方法→取数→成卦→定动爻→推变卦
- **约束**: 方法须固定；须记录起卦时间
- **格式**: 卦象记录

#### AC3-02 卦象解读
- **必选组件**: 卦辞爻辞、象义、情境映射、阶段性判断
- **可选组件**: 所问事项背景
- **组装顺序**: 读卦象→取象义→对情境→看动爻→给阶段判断
- **约束**: 须落到具体情境；不得给确定性断言
- **格式**: 卦象解读

#### AC3-03 梅花易数断事
- **必选组件**: 体卦用卦、生克关系、旺衰、结论
- **可选组件**: 起卦依据
- **组装顺序**: 定体用→判生克→看旺衰→推走向→给建议
- **约束**: 须说明体用取法；结论须有条件
- **格式**: 梅花断卦

#### AC3-04 小六壬速断
- **必选组件**: 月日时、掌诀位、断辞、提示
- **可选组件**: 所问事项
- **组装顺序**: 取月→取日→取时→定宫位→出断辞
- **约束**: 须说明推算过程；仅作短期参考
- **格式**: 小六壬断辞

### AC4 星曜推演

#### 域级说明

**域定位**：以紫微斗数体系排盘解盘，分析十二宫与四化飞星。

| 维度 | 内容 |
|------|------|
| 价值链形态 | 排盘→十二宫→四化→合盘 |
| 独立成域的理由 | 以安星规则与三方四正完整为验收点，禁止单宫独断 |
| 穷尽性 | 4 个任务覆盖「排盘→十二宫→四化→合盘」的 4 个环节；按输入物、失败模式、验收标准三条判据互不重叠，无未覆盖环节 |
| 知识要点 | 十二宫：命宫、兄弟、夫妻、子女、财帛、疾厄、迁移、交友、官禄、田宅、福德、父母；十四主星：紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军；辅星与煞星：左辅右弼、文昌文曲、天魁天钺；擎羊陀罗、火星铃星、地空地劫；四化：化禄、化权、化科、化忌，由生年天干决定飞化；三方四正：本宫 + 对宫 + 两个三合宫，共同决定该宫力量；大限流年：大限十年一宫，流年一年一宫；真太阳时与闰月处理影响命宫定位；安星顺序：定命宫身宫 → 起五行局 → 依局数起紫微 → 顺布十四主星 → 安辅佐煞曜 → 排大限；四化两层：生年四化定先天格局，宫干四化定后天引动；两层叠加才判飞化走向 |
| 判定标准 | 命宫定位须说明算法与校正；解读须结合三方四正，不得单宫独断；四化须标生年干与飞化路径；须明示象征属性 |
| 常见失范 | 不做真太阳时校正；单看一宫下结论；忽略四化飞化；合盘只看夫妻宫 |
| 范本结构 | 排盘信息 → 十二宫星曜分布 → 命宫与三方四正 → 四化飞星 → 重点宫位解读 → 建议与声明 |

#### AC4-01 紫微排盘
- **必选组件**: 命宫身宫、十二宫星曜表、五行局、大限表
- **可选组件**: 出生时间、真太阳时校正
- **组装顺序**: 校时→定命宫→布十二宫→安星→定五行局→排大限
- **约束**: 须说明安星规则；须做时区校正
- **格式**: 紫微命盘

#### AC4-02 十二宫与三方四正解读
- **必选组件**: 逐宫解读、三方四正组合、强弱判断
- **可选组件**: 命盘、实际处境
- **组装顺序**: 取宫位→看主星→合三方四正→判强弱→对应处境
- **约束**: 须结合三方四正；不得单星独断
- **格式**: 宫位解读报告

#### AC4-03 四化飞星分析
- **必选组件**: 四化表（禄权科忌）、飞化路径、影响宫位
- **可选组件**: 命盘、生年干
- **组装顺序**: 定生年四化→查宫干飞化→连路径→判影响
- **约束**: 须标明飞化方向；不得脱离宫位空谈
- **格式**: 四化分析

#### AC4-04 双人合盘
- **必选组件**: 两盘对照表、宫位互涉、互动倾向、注意事项
- **可选组件**: 双方命盘、关系背景
- **组装顺序**: 排两盘→对宫位→看互涉→判互动→给建议
- **约束**: 须双向分析；不得断言关系成败
- **格式**: 合盘分析

### AC5 牌阵解读

#### 域级说明

**域定位**：以塔罗牌阵做投射式反思，帮助来访者看清选择与情绪。

| 维度 | 内容 |
|------|------|
| 价值链形态 | 抽牌→逐牌→叙事→建议 |
| 独立成域的理由 | 以牌义与牌阵位置结合为验收点，禁止照搬词典 |
| 穷尽性 | 4 个任务覆盖「抽牌→逐牌→叙事→建议」的 4 个环节；按输入物、失败模式、验收标准三条判据互不重叠，无未覆盖环节 |
| 知识要点 | 大阿卡纳 22 张：愚人、魔术师、女祭司…世界，对应人生阶段性主题；小阿卡纳 56 张：权杖（火/行动）、圣杯（水/情感）、宝剑（风/思维）、星币（土/物质）；数字 1-10 + 侍从骑士王后国王；正逆位：逆位常表阻滞、内化、过度或不足，不作简单"凶"解；常用牌阵：单张（当下指引）、三张（过去-现在-未来 / 情境-行动-结果）、凯尔特十字（十张全面分析）、关系牌阵；解牌原则：牌义 × 位置 × 相邻牌 × 来访者情境，四者共同决定含义；伦理：不作医疗、法律、财务的确定预测；不制造依赖；读牌三层：先看位置义（此位问什么）→ 再看牌义（此牌是什么）→ 最后看相邻修饰（左右牌如何改义）；逆位三解：阻滞（该发生未发生）、内化（向外转向内）、过度或不足（同一特质的量变） |
| 判定标准 | 须说明所用牌阵与位置含义；牌义须结合位置与情境，不得照搬词典；逆位须给具体解释而非笼统"不好"；须明示为投射工具 |
| 常见失范 | 套用固定牌义不看位置；用牌面断言生死祸福；反复抽牌求"好结果"；替来访者做决定 |
| 范本结构 | 问题与牌阵说明 → 抽牌结果（牌/位置/正逆） → 逐牌解读 → 牌阵整体叙事 → 可行动建议 → 声明 |

#### AC5-01 抽牌与牌阵布置
- **必选组件**: 问题陈述、牌阵类型、抽牌结果（牌名/位置/正逆）
- **可选组件**: 牌组、随机方式
- **组装顺序**: 澄清问题→选牌阵→抽牌→定位→记录
- **约束**: 牌阵须匹配问题类型；不得反复重抽
- **格式**: 抽牌记录

#### AC5-02 逐牌解读
- **必选组件**: 逐牌解读、位置含义、正逆说明、情境映射
- **可选组件**: 来访者背景
- **组装顺序**: 取牌义→套位置→判正逆→对情境→给含义
- **约束**: 须结合位置；不得照搬词典
- **格式**: 逐牌解读

#### AC5-03 牌阵整体叙事
- **必选组件**: 叙事主线、核心张力、转折点、时间线
- **可选组件**: 逐牌解读
- **组装顺序**: 找主线→连因果→标张力→定转折→成叙事

#### 域级说明

**域定位**：帮家长看懂孩子的行为，再调整自己的回应。重点在改家长，不在改孩子。

| 维度 | 内容 |
|------|------|
| 价值链形态 | 现象→孩子视角→家长回应→一个改变→观察 |
| 独立成域的理由 | 与其它域不同构：来访者与改变对象不是同一人——来的是家长，要改的往往是家长的回应方式。 |
| 穷尽性 | 5 个任务覆盖「现象→孩子视角→家长回应→一个改变→观察」的 5 个环节；按输入物、失败模式、验收标准三条判据互不重叠，无未覆盖环节 |
| 知识要点 | 发展心理学阶段：依恋期、自主期、具体运算、形式运算；各阶段核心任务不同，同一行为在不同阶段意义不同；行为解读：行为是需求的外显；先找需求（安全、自主、胜任、归属）再谈纠正；教养方式四型：权威型、专制型、放任型、忽视型；权威型（高要求高回应）长期结果最好；沟通技术：反映式倾听、我信息（描述行为+我的感受+影响）、有限选择、自然与逻辑结果；学习动力：内在动机三要素——自主、胜任、归属；外部奖励会削弱内在动机；家校协同：与老师沟通的目标是交换信息与形成一致，不是问责 |
| 判定标准 | 每次咨询须落到家长的一个具体行为改变；不得给孩子贴标签（懒、笨、叛逆）；须区分发展性行为与需要专业介入的问题行为；建议密度不得超出一个家庭一周能消化的量 |
| 常见失范 | 直接给管教技巧，不看孩子所处发展阶段；把问题全归给孩子，家长置身事外；一次给十条建议，家长做不到；把发展性对抗当成问题行为 |
| 范本结构 | 现象与家长诉求 → 孩子视角解读 → 家长回应模式 → 本次一个改变 → 观察指标 → 何时求助专业人士 |

#### AC11-01 亲子议题评估
- **必选组件**: 具体事件、发生频率、家长原做法、家长诉求、发展阶段判定
- **可选组件**: 孩子年龄、家庭结构、学校情况
- **组装顺序**: 问具体事件→问频率→问原做法→判阶段→定性质
- **约束**: 须问具体事件而非"孩子不听话"；须做危机与异常筛查
- **格式**: 议题评估小结

#### AC11-02 孩子行为解读
- **必选组件**: 发展阶段、行为背后的需求假设、支持与反对证据
- **可选组件**: 日常观察记录
- **组装顺序**: 对阶段→提需求假设→找证据→给家长解释
- **约束**: 不得贴标签；须说明这是假设而非定论
- **格式**: 行为解读说明

#### AC11-03 家长回应方式调整
- **必选组件**: 原回应、问题点、新回应话术、演练、观察点
- **可选组件**: 近期冲突场景
- **组装顺序**: 复盘原回应→指问题→给新话术→演练→定观察点
- **约束**: 一次只改一个回应方式；须给可直接说的句子
- **格式**: 家长回应脚本

#### AC11-04 学习动力与习惯
- **必选组件**: 动力诊断、三要素现状、习惯设计、家长角色
- **可选组件**: 作业记录、作息、兴趣
- **组装顺序**: 诊断三要素→找短板→设习惯→定家长角色→排节奏
- **约束**: 不得用奖励换成绩；习惯须从最小可执行起步
- **格式**: 动力与习惯方案

#### AC11-05 家校沟通协同
- **必选组件**: 沟通目标、事实清单、口径、期望、边界
- **可选组件**: 近期家校互动记录
- **组装顺序**: 定目标→列事实→定口径→提期望→划边界
- **约束**: 须以合作为前提；不得把老师放到对立面
- **格式**: 家校沟通方案
