## 顾问陪谈任务清单与依赖拓扑

顾问陪谈按"域 → 任务"组织的任务清单，附价值链、场景管线与依赖关系。

**价值链**：来访接入 → 处境澄清 → 体系映射 → 解读 → 建议锚定 → 跟进（每个域即一套解释体系在此链上的一次完整实例）

**域划分判据**：域 = 一套**解释体系的完整服务链**。心理、命理、卦象、星曜、牌阵、历法、星座、升学、执业各自依赖不可互换的知识体系，故各自成域，域内任务即该链的阶段。

**互斥约束**：一个任务只属于一个域；同一工作不会在两个域中同时出现。

**域间逻辑流**：AC1 心理与关系 → AC2 命理排盘 → AC3 卦象占断 → AC4 星曜推演 → AC5 牌阵解读 → AC6 历法择吉 → AC7 星座运势 → AC8 升学与学业规划 → AC9 执业咨询 → AC10 学习与职业教练 → AC11 亲子与家庭教育

**域内基线规则**：每个域的首个任务为该域基线任务，同域其余任务一律以其产出为参照，不得跳步执行。

## 知识图谱

将依赖拓扑扩展为知识图谱，支持跨任务的关系推理。

**实体节点类型**

| 类型 | 数量 | 说明 |
|------|------|------|
| 任务节点 | 46 | 形如 `AC1-01`、`AC11-05` 的可执行单元 |
| 域节点 | 11 | 任务的分组边界 |
| 元操作节点 | 9 | S/C/A/O/I/G 及组合 |
| 产出物节点 | 46 | 各任务声明的交付格式；与任务近 1:1，故不单独建模归并 |
| 场景节点 | 25 | 场景管线中的入口场景 |

**关系边类型**

| 边 | 方向 | 含义 |
|----|------|------|
| 包含边 | 域 → 任务 | 域包含其下所有任务 |
| 依赖边 | 任务 → 任务 | 前置产出是后继输入，见各域链路 |
| 产出边 | 任务 → 产出物 | 任务声明的 `格式` 即其产出节点 |
| 路由边 | 场景 → 任务 | 场景管线的链首即入口任务 |
| 反向边 | 产出物 → 任务 | 由交付格式反查产出它的任务 |

**推理能力**

- **路径推导**：给定起止任务，沿依赖边求最短可行链
- **任务推荐**：给定已完成任务，取其后继中依赖已满足者
- **依赖分析**：给定任务，回溯全部前置与受影响的下游
- **并行识别**：同域内无依赖边的任务可并行执行
- **产出反查**：给定交付格式，定位产出它的任务
- **形态归并**：本负载物全部产出物归入「分层解读」这一产物形态，跨负载物可再归并

更多组合根据具体任务动态推导。
