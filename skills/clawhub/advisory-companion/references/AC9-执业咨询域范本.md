## AC9 执业咨询域范本

### 一、领域知识要点

- 用药要点：适应证、用法用量、禁忌、不良反应、相互作用、特殊人群（孕哺/儿童/肝肾不全）
- 处方药与 OTC 边界；抗生素滥用风险
- 检验与检查：常见项目意义、参考区间、空腹要求
- 就医路径：科室对应症状、急诊指征（胸痛、呼吸困难、意识改变、大出血、剧烈腹痛）
- 临床指南：来源（中华医学会、NCCN、WHO）、推荐等级与证据级别
- 术语通俗化：保留关键限定，不简化到失真

### 二、判定标准

- 须标注药品通用名而非仅商品名
- 用法用量须引说明书或指南原文
- 急症指征须单独提示并优先
- 不得推荐具体品牌或机构

### 三、范本结构

1. 问题澄清
2. 信息依据（说明书/指南）
3. 要点解释
4. 注意事项与禁忌
5. 何时就医
6. 免责声明

### 四、常见失范

- 按商品名讨论导致混淆
- 给超出说明书的用法
- 忽略相互作用
- 把指南推荐当个体化方案

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 通用名、适应证、用法用量、禁忌、不良反应、相互作用 |
| 本域产出 | 用药说明；术语解释；就医路径建议；指南要点 |
| 下游可用 | 指南要点 |

### 六、交付自检

交付前逐项打勾，任一项不成立即返工：

- [ ] 须标注药品通用名而非仅商品名
- [ ] 用法用量须引说明书或指南原文
- [ ] 急症指征须单独提示并优先
- [ ] 不得推荐具体品牌或机构

同时排除以下失范：

- [ ] 已排除：按商品名讨论导致混淆
- [ ] 已排除：给超出说明书的用法
- [ ] 已排除：忽略相互作用
- [ ] 已排除：把指南推荐当个体化方案

### 七、执行卡（以「用药咨询」为例）

**开工前备齐**：通用名、适应证、用法用量、禁忌、不良反应、相互作用

**可选补充**：患者年龄、肝肾功能、并用药物

**按序执行**：

1. 核通用名
2. 述适应证
3. 述用法
4. 列禁忌
5. 查相互作用

**交付前核对**：须引说明书/指南；不得超说明书建议

**成品须符合**：用药说明

### 八、成品骨架

按「用药说明」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 用药说明

## 1. 问题澄清
## 2. 信息依据（说明书/指南）
## 3. 要点解释
## 4. 注意事项与禁忌
## 5. 何时就医
## 6. 免责声明
```

**齐备要求**：必选组件「通用名、适应证、用法用量、禁忌、不良反应、相互作用」须全部落位；约束「须引说明书/指南；不得超说明书建议」须逐条成立；可选「患者年龄、肝肾功能、并用药物」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
