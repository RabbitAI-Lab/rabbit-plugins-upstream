## AC1 心理与关系域范本

### 一、领域知识要点

- CBT 认知模型：情境 → 自动思维 → 情绪 → 行为；认知歪曲（全或无、灾难化、读心、过度概括、应该式）
- 情绪评估：情绪强度 0-10 自评、持续时间、功能影响（睡眠/食欲/工作）
- 倾听技术：反映、澄清、具体化、情感反映、总结
- 危机识别：自伤意念、计划、手段可及性；保护性因素
- 关系议题：依恋类型（安全/焦虑/回避/混乱）、非暴力沟通（观察-感受-需要-请求）、边界设定
- 伦理：知情同意、保密例外、双重关系禁止、能力边界

### 二、判定标准

- 先建立安全感再进入干预，不得跳步
- 每次对话须收敛到一个可执行动作
- 危机信号出现时转介优先于任何技术
- 不得给诊断标签，只描述现象

### 三、范本结构

1. 现状与主诉
2. 情绪与功能评估
3. 议题概念化
4. 本次工作重点
5. 可执行动作
6. 下次跟进
7. 边界与转介说明

### 四、常见失范

- 过早给建议
- 用"想开点"替代具体技术
- 越界做诊断
- 忽略危机信号

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 主诉、情绪强度评分、持续时间、功能影响、危机筛查结果 |
| 本域产出 | 评估小结；认知记录表；调节方案+练习记录；关系梳理+沟通脚本；转介建议单 |
| 下游可用 | 转介建议单 |

### 七、执行卡（以「情绪状态评估与澄清」为例）

**开工前备齐**：主诉、情绪强度评分、持续时间、功能影响、危机筛查结果

**可选补充**：既往史、支持系统

**按序执行**：

1. 接住情绪
2. 澄清具体化
3. 评强度
4. 查功能
5. 筛危机

**交付前核对**：须做危机筛查；不得贴诊断标签

**成品须符合**：评估小结

### 八、成品骨架

按「评估小结」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 评估小结

## 1. 现状与主诉
## 2. 情绪与功能评估
## 3. 议题概念化
## 4. 本次工作重点
## 5. 可执行动作
## 6. 下次跟进
## 7. 边界与转介说明
```

**齐备要求**：必选组件「主诉、情绪强度评分、持续时间、功能影响、危机筛查结果」须全部落位；约束「须做危机筛查；不得贴诊断标签」须逐条成立；可选「既往史、支持系统」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
