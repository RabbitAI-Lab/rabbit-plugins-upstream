## AC10 学习与职业教练域范本

### 一、领域知识要点

- 学习科学：间隔重复、提取练习、刻意练习、费曼技巧
- 技能拆解：把目标技能拆成可练的最小单元，每个单元配达标标准
- 反馈回路：即时反馈、延迟反馈、外部校准三种来源与频率
- 职业路径：能力盘点、岗位地图、可迁移能力、作品集
- 动机维持：进度可见、目标梯度、社群约束
- 停滞诊断：平台期、错误练习、动机枯竭三类成因与对策

### 二、判定标准

- 计划须拆到每周可执行的动作
- 每个动作须有可验证的达标标准
- 须设计反馈来源与频率
- 不得承诺速成

### 三、范本结构

1. 现状与目标
2. 能力盘点与差距
3. 技能拆解与练习单元
4. 周计划与达标标准
5. 反馈与校准
6. 停滞预案

### 四、常见失范

- 只给书单不给练习
- 计划密度过高无法持续
- 无反馈导致错误动作固化
- 用意志力解释停滞

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 能力清单（项/自评/证据）、目标能力集、差距排序 |
| 本域产出 | 能力盘点评分表；学习路径与周计划；转型路径图；停滞诊断与调整方案 |
| 下游可用 | 停滞诊断与调整方案 |

### 六、交付自检

- [ ] 计划须拆到每周可执行的动作
- [ ] 每个动作须有可验证的达标标准
- [ ] 须设计反馈来源与频率
- [ ] 不得承诺速成

同时排除以下失范：

- [ ] 已排除：只给书单不给练习

### 七、执行卡（以「能力盘点与差距分析」为例）

**开工前备齐**：能力清单（项/自评/证据）、目标能力集、差距排序

**可选补充**：过往项目与作品、目标岗位要求

**按序执行**：

1. 列现有能力
2. 找证据
3. 对目标
4. 算差距
5. 排优先级

**交付前核对**：能力须有证据支撑；不得只凭自评

**成品须符合**：能力盘点评分表

### 八、成品骨架

按「能力盘点评分表」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 能力盘点评分表

## 1. 现状与目标
## 2. 能力盘点与差距
## 3. 技能拆解与练习单元
## 4. 周计划与达标标准
## 5. 反馈与校准
## 6. 停滞预案
```

**齐备要求**：必选组件「能力清单（项/自评/证据）、目标能力集、差距排序」须全部落位；约束「能力须有证据支撑；不得只凭自评」须逐条成立；可选「过往项目与作品、目标岗位要求」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
