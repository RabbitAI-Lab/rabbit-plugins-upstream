# Fundraising Guide — 融资指南

> 融资不是创业成功的标志，而是放大器。本技能帮你判断是否需要融资、如何准备材料、如何管理投资人关系、如何高效完成交割。

## 能力

- 评估资本需求：Bootstrapping 还是 VC？取决于市场野心和商业模式复杂度
- 打磨叙事和材料：「为什么是现在」的故事、Pitch Deck 结构、投资人清单
- 执行融资流程：外联节奏、高密度会议排期、管理 momentum
- 优化投资人关系：系统化请求和汇报结构，从 Cap Table 中提取最大价值
- 定位退出策略：从强势地位出发，让收购方主动找你

## 使用方式

```
/fundraising-guide 我在纠结 Bootstrap 还是融资，帮我分析
/fundraising-guide 帮我构建 Pitch Deck 的故事线
/fundraising-guide 融资节奏怎么安排？应该同时见多少投资人？
```

## 工作流

1. **资本需求评估** — Bootstrap 还是 VC？基于野心和商业模式决定
2. **叙事打磨** — 构建「为什么是现在」的故事 + Pitch Deck + 投资人清单
3. **融资执行** — 外联节奏 → 高密度会议周 → 维持 momentum → 快速闭环
4. **投资人关系** — 定期更新、战略性请求、利用投资人网络
5. **退出规划** — 让公司变得不可或缺，让少数买家感到威胁

## 核心原则

### Bootstrapping 是基本功
> 「Bootstrapping 对创业者很好，因为他们有更多练习赚钱的机会，越来越擅长经营成功企业最基本的技能——赚钱。」— Jason Fried

从第一天起掌握赚钱能力。只有在商业模式确实需要大量前期资本（如硬件、工厂）时才寻求投资。

### 第一页决定一切
> 「大多数人缺少最重要的幻灯片：第一页。这页展示时间最长，你要放最强的点。第二重要的是最后一页。」— Uri Levine

投资人快速形成判断。把最令人印象深刻的数据或洞察放在第一页。用数据页回应每个常见反对意见。

### 拒绝 = 免费修改建议
> 「投资人会以拒绝的形式给反馈。他们会说'市场不够大'，我就加一页说明市场多大。他们说'你和其他公司一样'，我就加一页展示所有玩家和我们的差异化。」— Melanie Perkins

把每次投资人拒绝当作修改 Pitch Deck 的提示。为每个批评新增一页数据驱动的回应。

### 野心决定融资路径
> 「Bootstrapping 是为了现金流的生活方式企业。融资是为了创造 10 亿美元年收入的公司。」— Patrick Campbell

基于野心的终极规模选择融资路径。目标是 10 亿美元退出和快速市场占领 → VC。追求效率和自主权 → Bootstrap。

### 从强势地位退出
> 「M&A 永远是创造 Plan B。任何公司只有 2-3 个买家会觉得你的东西极度战略重要。你要找出自己带来竞争优势的领域，然后对那个潜在买家施加痛苦。」— Julia Schottenstein

最好的退出是把公司建得不可或缺，让少数潜在买家感到威胁。不要主动求收购——让他们来找你。

## 适用场景

- 不确定该 Bootstrap 还是融资
- 准备种子轮或 A 轮融资
- Pitch Deck 被投资人反复拒绝，需要诊断
- 收到 Term Sheet 但不确定条款是否合理
- 考虑是否出售公司

## 限制

- 融资环境随市场剧烈变化（牛市的建议在熊市不适用）
- 不同地区和阶段的融资规范差异大
- 不适用于非股权融资（债务融资、Grant 等）
- 消费级和企业级 SaaS 的融资逻辑不同
