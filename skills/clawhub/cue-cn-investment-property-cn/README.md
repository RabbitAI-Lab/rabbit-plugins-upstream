# 投资性房地产·逐条挂源

给一份财报或公告，把**投资性房地产**这一族科目读成一张**每个数都能回到原句**的登记表：概况、计量模式、成本模式明细、公允价值模式明细、转换与处置。

投资性房地产是资产负债表上一块容易出错的科目：**它用哪种模式计量、转换差额去了哪儿、处置损益怎么算出来的**，三件事都只有披露说了算。本件逐条登记披露原话，判断留给人。

**不打处置建议、不做公允价值预测、不点评评估结论、不给评级与目标价。** 计量模式只认披露写法；转换差额的去向照抄原句，不按准则方向补。

## 一、三十秒跑通（零输入）

不给任何数据文件，也能跑出一份完整合规的成品，看它长什么样、判据怎么打：

```bash
python3 scripts/check_investment_property.py --demo
```

把这份样例存下来再跑一遍机检，它能自己过：

```bash
python3 scripts/check_investment_property.py --demo > 样例投资性房地产稿.md
python3 scripts/check_investment_property.py 样例投资性房地产稿.md
# → 样例投资性房地产稿.md 结论：五道全过（零发条）
```

接着换成你自己那份稿子：

```bash
python3 scripts/check_investment_property.py 你的投资性房地产稿.md
```

退码 `0` 全过、`1` 有发条、`2` 用法错、`3` 读不到文件或空稿。

### 拿不到成品时，从原文开始的三步

1. **定主体与报告期**，拿到年报或半年报原文（附注「投资性房地产」「公允价值计量」「非经常性损益」三处）。
2. **每节抄事实，连原句一起抄**：一条 = 一行，行末挂 `「原句」〔锚：页/表〕[S#]`。
3. **跑一遍自检**，红一条改一条：

```bash
python3 scripts/check_investment_property.py --selftest   # 7 档内置夹具自检
```

### 先确认通道在场（可选）

配了 `CUE_API_KEY` 才需要这一步。先列目录，再按目录里的路由地址确认工具在场：

```bash
CATALOG="https://cuecue.cn/api/mcp-catalog"
curl -s "$CATALOG" | head -c 2000
# 从目录里取本组的路由地址，确认工具在场
curl -s -X POST "$ROUTING_URL" \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

没配凭据也照常出稿：把财报放进工作区走用户直供那条路，代价是附注里的公允价值层级表与转换明细只能在自己手头的文件里翻。

## 二、五道机检在管什么

| 码 | 名称 | 判什么 | 最常拦住的情况 |
|---|---|---|---|
| `IP-STRUCT` | 形制 | 头部四件自标、`- 主体：`／`- 报告期：` 在场；七节齐且**有序**；前五节各至少一条发现行；五六七节不得留白 | 七节缺一节；某节只有小标题；多出一节不认识的节名；节序被调换 |
| `IP-QUOTE` | 原句与锚 | 每条发现行以「」原句＋〔锚：…〕＋`[S#]` 收尾；来源行带可点 URL 与检索日；引用的编号须已在来源节登记 | 只写数字没抄原句；来源行只有标题没有链接；引用了 `[S9]` 但来源节没有这一号 |
| `IP-NOSELF` | 不得自推 | 计量模式只认披露写法（「成本模式／公允价值模式」或等价表述须在原句里）；转换差额写了金额须写去向，去向须与本行原句一致 | 见「存在活跃市场」就写「公允价值模式」；写了差额 320 万元却不写去了其他综合收益还是当期损益；原句说其他综合收益、行里写当期损益 |
| `IP-GAP` | 未取到两向点名 | 正文写了未取到而第六节没列要发，反之也发；零缺口须显式写「未取到：无」 | 用「不适用」「无此项」「无需披露」搪塞 |
| `IP-LINE` | 红线 | 处置建议、公允价值预测、评估结论点评、评级与目标价零命中；引文先洗掉再判 | 「建议尽快处置」「下一年公允价值有望上行」「评估值偏保守」 |

## 三、四条红线（这件的立身之本）

1. **计量模式只认原句。** 「存在活跃市场」只是采用公允价值模式的条件之一，推不出「已采用公允价值模式」。披露没写，就照实写计量模式未取到。
2. **转换差额的去向只认原句。** 准则定的是方向，具体到这家公司这一笔只有披露知道。自用房地产转投资性房地产的差额进其他综合收益还是当期损益，照抄那一句；写了金额没写去向同样发条。
3. **估值技术与层级只照抄，不点评。** 附注写的是市场法还是收益法、落在第三层级、输入值是什么，就登记什么；不评方法优劣、不评评估值高低、不预测下一期公允价值。
4. **不打处置建议。** 要不要卖、什么时候卖、以什么方式转让，一律 `[待人工]`；本件只登记处置收入、账面价值与处置损益三行数字。

## 四、一条发现长什么样

```markdown
- 期末账面价值：8,600.00 万元「投资性房地产期末账面价值 86,000,000.00 元」〔锚：2025 年年报·第 96 页·附注五·投资性房地产〕[S1]
```

没取到的，自成一行、照实写：

```markdown
- 期初公允价值：未取到：本报告期采用成本模式，附注未披露公允价值
```

转换差额的写法——金额与去向必须在同一行、且与原句一致：

```markdown
- 自用转投资性房地产：转换差额 320.00 万元计入其他综合收益「自用房地产于转换日转为本公司投资性房地产，转换日公允价值大于账面价值的差额计入其他综合收益」〔锚：2025 年年报·第 97 页·附注五·投资性房地产〕[S1]
```

## 五、和另外几枚包怎么分

| 你手上是 | 用哪枚 |
|---|---|
| 投资性房地产、计量模式、转换与处置、公允价值层级 | **本件** |
| 应收票据、应付票据、背书、贴现、终止确认 | `cn-notes-receivable-cn` |
| 存货、应收账款、合同资产的余额与账龄 | `cn-working-capital-quality` |
| 商誉减值测试、资产组划分 | `cn-goodwill-impairment-risk` |

投资性房地产的**减值准备**这一格，本件只登记数字与附注原话，不评减值是否充分——减值测试那一套归 `cn-goodwill-impairment-risk`。固定资产与在建工程不在本件射程内：本件只认披露里点名「投资性房地产」的那几段。

## 六、素材从哪来

- **用户直供**：手头的年报 PDF、公告，走解析通道读成能检索的正文。
- **通道取证**：配了 `CUE_API_KEY` 后可走财报检索与原文解析。装好 skill ≠ 已配凭据 ≠ 通道已连，三层分开看。
- **附注常在几百页的 PDF 里**（投资性房地产明细表、公允价值层级表、转换与处置明细），长附件与扫描件交给解析腿（`cue-omni-reader`）：先取大纲，再按节取用。计费与可用性以服务端返回为准。
- **转手件一律降级**：第三方整理与媒体解读要标注「未与附注原文核对」，代价是这一行的证据密度只到二手。

本件不发请求、不代付费，消耗以服务端返回为准。
