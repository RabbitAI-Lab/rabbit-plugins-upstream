## Description:

This skill is ready for commercial/non-commercial use.

Octen users and developers can use the skill to work with connected Octen data, search and research, extract web content, run model conversations, create embeddings, and request image or video generation.

## Known Risks and Mitigations:

Risk: Setup may execute changing remote installers without clear user approval.

Mitigation: Review and approve a pinned, verified CLI installation separately, including any additional agent skills it installs.

Risk: Downloaded installers, the CLI runtime, and live connector behavior are outside this artifact review.

Mitigation: Confirm the intended generation inputs and credit use rather than relying on read-only labels.
