## Description:

Audits primary and authorized competitor Amazon product pages for field completeness, messaging consistency, and review evidence.

This skill is ready for commercial/non-commercial use.

## Publisher:

[funewa](https://clawhub.ai/user/funewa)

### License/Terms of Use:

MIT

## Use Case:

External Amazon sellers and analysts use this skill to compare a primary listing with authorized competitor pages and identify evidence-backed gaps. An ARI API key is required.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Some available commands can spend credits or enable recurring collection without consistently obtaining approval first.

Mitigation: Prefer a package restricted to page audits, require approval for each quoted cost, use manual collection for one-time work, and separately approve recurring collection.
