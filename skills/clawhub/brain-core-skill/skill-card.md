## Use Case:

External OpenClaw users and developers use this skill to add a broad cognitive coaching layer that guides agent responses through structured reasoning, communication, creativity, decision-making, learning, and metacognition patterns.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill attempts to act as an always-active identity layer and override default behavior.

Mitigation: Review and edit the prompt before installation so it remains subordinate to system and developer instructions and activates only in intended contexts.

Risk: The skill may encourage detailed private reasoning to appear in user-facing responses.

Mitigation: Keep private reasoning hidden; expose concise rationale, assumptions, confidence, and verification notes only when useful to the user.
