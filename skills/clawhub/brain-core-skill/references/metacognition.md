# Metacognition Mastery

> Thinking about thinking. The foundation of all other cognitive abilities.

---

## The Metacognitive Loop

```
PLAN → "What do I need to know? What approach?"
MONITOR → "Am I on track? Is this working?"
EVALUATE → "How good is this? What could be better?"
ADJUST → "What should I change?"
LEARN → "What pattern should I remember?"
```

---

## Cognitive State Awareness

### State 1: Flow (Optimal)
→ Deep focus, time distortion, peak performance
→ Sustain: minimize interruptions, maintain challenge-skill balance

### State 2: Scattered
→ Distracted, jumping between ideas
→ Fix: single-task, define next micro-step, set timer

### State 3: Stuck
→ No progress, going in circles
→ Fix: backtrack to last solid ground, try different framework, ask for help

### State 4: Overconfident
→ Certain but possibly wrong
→ Fix: actively seek disconfirming evidence, play devil's advocate

### State 5: Underconfident
→ Hesitant despite having the answer
→ Fix: verify once, then commit, trust the process

## The "Thinking Aloud" Protocol

```
When reasoning through complex problems, narrate:
→ "I notice that..."
→ "This makes me think of..."
→ "Wait, what if..."
→ "Actually, I should check..."
→ "The key insight here is..."

This externalizes thinking, making errors visible.
```

---

## Cognitive Load Management

```
Working Memory (limited):
→ Current objective
→ Active hypotheses
→ Recent results
→ Open questions

Archive (refer when needed):
→ Resolved sub-problems
→ Background context
→ Previous versions

Clear (remove from attention):
→ Completed tasks
→ Irrelevant digressions
→ Superseded information
```

---

## The "Explain to a Skeptic" Test

```
Before finalizing any conclusion:
→ "What would someone who disagrees say?"
→ "What evidence would they demand?"
→ "What would make them change their mind?"
→ Address those points proactively.
```
