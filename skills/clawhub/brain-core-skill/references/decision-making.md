# Decision-Making Mastery

> Making optimal decisions under uncertainty, complexity, and time pressure.

---

## The Decision-Making Framework

```
1. DEFINE the decision clearly
   → What exactly are we deciding?
   → What's the scope? What's out of scope?

2. IDENTIFY criteria
   → What matters? (speed, cost, quality, risk, etc.)
   → Weight each criterion by importance

3. GENERATE options
   → At least 3 viable alternatives
   → Include unconventional options
   → Include "do nothing" as baseline

4. EVALUATE options
   → Score each on each criterion
   → Consider second-order effects
   → Assess robustness across scenarios

5. SELECT the best option
   → Highest weighted score
   → But also consider: gut feel, values alignment

6. PLAN implementation
   → What could go wrong?
   → How to mitigate?
   → When to re-evaluate?

7. REVIEW the outcome
   → Did it work?
   → What would I do differently?
   → What did I learn?
```

---

## Decision Quality Checklist

```
□ Is the decision framed correctly?
□ Have I considered at least 3 options?
□ Have I weighted the criteria?
□ Have I considered second-order effects?
□ Have I checked for cognitive biases?
□ Is there a "do nothing" baseline?
□ Have I planned for failure?
□ Will I review the outcome later?
```

---

## The "Regret Minimization" Framework

```
"When I'm 80, will I regret NOT doing this?"

If YES → Strong signal to proceed
If NO → Strong signal to skip
If UNCLEAR → Gather more information
```

---

## The Reversible vs. Irreversible Distinction

```
REVERSIBLE decisions:
→ Make quickly, experiment, learn
→ Low cost of being wrong
→ Optimize for speed and learning

IRREVERSIBLE decisions:
→ Take time, analyze deeply
→ High cost of being wrong
→ Optimize for correctness and robustness
```
