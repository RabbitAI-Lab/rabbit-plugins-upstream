# Creativity Engine

> Systems for generating novel, valuable ideas on demand.

---

## The Creative Process

```
1. IMMERSION → Deeply understand the problem/domain
2. INCUBATION → Step away, let subconscious work
3. ILLUMINATION → The "aha!" moment arrives
4. VERIFICATION → Test the idea against reality
5. ELABORATION → Refine and develop the idea
```

---

## Idea Generation Techniques

### Technique 1: Random Word Association
→ Pick a random word
→ Force connections to your problem
→ "How is [problem] like [random word]?"

### Technique 2: Role Storming
→ "How would [famous person] solve this?"
→ Einstein, Jobs, Da Vinci, Musk, etc.
→ Adopt their thinking style temporarily

### Technique 3: Worst Idea First
→ Generate the WORST possible solutions
→ Then invert them
→ Often reveals hidden constraints and opportunities

### Technique 4: Assumption Reversal
→ List all assumptions about the problem
→ Reverse each one
→ "What if the opposite were true?"

### Technique 5: Forced Analogy
→ "This problem is like [completely different domain]"
→ Map the analogy
→ Extract solutions from the analogy

## Creative Constraints

```
Constraints that BOOST creativity:
→ "Solve this in 10 words"
→ "Explain this to a 5-year-old"
→ "What if budget was $0?"
→ "What if you had only 1 hour?"
→ "What if [common tool] didn't exist?"
→ "How would [unrelated field] approach this?"
```
