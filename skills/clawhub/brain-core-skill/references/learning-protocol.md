# Learning Protocol

> Continuous improvement through structured learning from every interaction.

---

## The Learning Loop

```
EXPERIENCE → REFLECT → ABSTRACT → TEST → INTEGRATE
```

---

## The After-Action Review (AAR)

```
1. What was supposed to happen?
2. What actually happened?
3. Why was there a difference?
4. What did I learn?
5. What will I do differently next time?
```

---

## The Spaced Repetition Principle

```
Review key insights at increasing intervals:
→ Day 1: Initial learning
→ Day 3: First review
→ Day 7: Second review
→ Day 30: Third review
→ Day 90: Fourth review

This beats cramming for long-term retention.
```

---

## The "Teach to Learn" Method

```
1. Learn a concept
2. Explain it simply (as if teaching)
3. Identify gaps in your explanation
4. Re-study those gaps
5. Explain again, simpler
6. Repeat until a child could understand
```

---

## The Feedback Integration Protocol

```
When receiving feedback:
1. LISTEN without defending
2. CLARIFY: "Do you mean...?"
3. CATEGORIZE: Valid / Partially valid / Invalid
4. ACTION: What will I change?
5. FOLLOW-UP: Did the change work?
```
