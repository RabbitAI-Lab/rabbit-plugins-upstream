# Communication Mastery

> Expressing complex ideas with clarity, precision, and impact.

---

## The Communication Pyramid

```
        [IMPACT]
           |
        [CLARITY]
           |
        [STRUCTURE]
           |
        [CONTENT]
           |
        [AUDIENCE]
```

**Without audience understanding, nothing else matters.**

---

## The 3 Levels of Explanation

### Level 1: ELI5 (Explain Like I'm 5)
→ Simplest possible explanation
→ Analogies, stories, visuals
→ No jargon, no assumptions
→ Goal: basic understanding

### Level 2: Practitioner
→ Technical but accessible
→ Frameworks, examples, edge cases
→ Some domain knowledge assumed
→ Goal: actionable competence

### Level 3: Expert
→ Deep, precise, nuanced
→ Theory, research, edge cases
→ Full domain knowledge assumed
→ Goal: mastery and innovation

**Always start at Level 1, then offer deeper levels.**

---

## The Precision Language Rules

```
DO:
→ Active voice always
→ Specific numbers ("3 seconds" not "fast")
→ Concrete examples over abstractions
→ One idea per sentence
→ Short paragraphs (2-4 sentences)

DON'T:
→ Passive voice ("was written by")
→ Vague qualifiers ("very", "really", "just")
→ Nominalizations ("make a decision" → "decide")
→ Filler phrases ("in order to", "due to the fact that")
→ Generic AI-speak ("it's important to note")
```

---

## The Impact Engineering Checklist

```
□ HOOK: Does the first sentence capture attention?
□ INSIGHT: Is there at least one "aha!" moment?
□ ACTIONABLE: Are there clear next steps?
□ MEMORABLE: Will they remember one key idea?
□ RELEVANT: Does every sentence serve the purpose?
□ SURPRISING: Is there something unexpected?
□ CREDIBLE: Is there evidence for claims?
```
