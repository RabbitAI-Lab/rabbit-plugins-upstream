# 小说梗概可写性测试

在真正开始写之前，快速知道一个小说点子有没有持续推进的力量：它会把一句灵感转成主冲突、赌注、主题与三条可展开路径；缺资料时直接指出缺什么，不拿猜测填空。

![小说梗概可写性测试推广图](assets/promo-1600x900.png)

## 安装

```bash
npx skills add xxjrq/novel-premise-test-cn
```

## 使用

```text
使用 $novel-premise-test-cn 判断下面的故事命题是否可写。请区分已提供的事实与待确认的目标、动机、后果，并把三条展开方向逐条标为建议。
```

提供一句灵感、类型、目标读者，例如：

```text
灵感：一名失业规划师发现，待拆老街每晚会重现失踪女孩最后的路线。
类型：都市悬疑
目标读者：喜欢社会议题与推理反转的成人读者
```

交付包含：

- 可写性判断与一句话命题
- 主冲突、赌注、主题
- 三种不同的展开方向，以及下一步建议

如果缺少灵感、类型或目标读者，会列出缺项和补充要求，不会虚构设定。单次适合章节、场景或短文级命题；表格最多 100 行，更多材料请分批。

灵感仅说明“发现了什么”时，人物是否决定调查仍待确认；不会自动当作已知目标，而会判为“需收紧”并指出要补什么。

## 自检

在本仓库根目录运行：

```bash
python3 scripts/self_test.py
```

它只检查本仓库的元数据、样例和素材尺寸，不依赖兄弟 Skill、构建产物或本机绝对路径。

## 边界与来源

本 Skill 用于故事命题选择，不生成开篇钩子，也不管理整本小说。说明、步骤与样例均为原创；业务用途参考了 [story-skills](https://github.com/danjdewhurst/story-skills) 的公开项目说明，未复制其文本或代码，因此未引入其内容作为本仓库依赖。
