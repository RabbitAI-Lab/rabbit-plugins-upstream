## Description:

Helps sellers discover and evaluate Amazon keywords using search demand, purchase activity, product competition, PPC bids, click concentration, and SPR.

This skill is ready for commercial/non-commercial use.

## Use Case:

Amazon sellers and marketplace analysts use this skill to expand seed keywords and assess demand and competition across supported Amazon marketplaces.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup may install or update npm packages, download Node, alter PATH, or configure an API token.

Mitigation: Review setup before installing; prefer a preinstalled, pinned qhkit version in a controlled environment and handle the token securely.

Risk: Keyword lookups incur variable qhkit credit charges, especially for large result sets.

Mitigation: Check the current credit estimate and obtain user approval before paid calls or large batches.
