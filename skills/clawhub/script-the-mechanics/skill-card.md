## Description:

Guides skill authors to move exact, repeatable counting, parsing, and arithmetic into small scripts that return compact results.

This skill is ready for commercial/non-commercial use.

## Publisher:

[goofproof](https://clawhub.ai/user/goofproof)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and skill authors use this guidance to put deterministic calculations and data checks into short scripts, leaving interpretation and writing to the agent.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Scripts built from this guidance could introduce unexpected dependencies or network access.

Mitigation: Keep scripts small and reviewable, prefer the standard library, and disclose any network calls or dependencies in the resulting skill.
