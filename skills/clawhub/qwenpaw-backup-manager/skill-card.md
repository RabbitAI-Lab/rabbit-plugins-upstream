## Description:

Helps back up and restore QwenPaw skills, settings, sessions, and memory.

This skill is ready for commercial/non-commercial use.

## Publisher:

[trend0522](https://clawhub.ai/user/trend0522)

### License/Terms of Use:

MIT-0

## Use Case:

QwenPaw users and administrators back up local skills, settings, sessions, and memory before upgrades or workspace migrations, and restore them when recovering from data loss.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Restoring a backup can replace current local skills, settings, sessions, or memory.

Mitigation: Create a fresh backup and confirm the affected QwenPaw profile or workspace before restoring.
