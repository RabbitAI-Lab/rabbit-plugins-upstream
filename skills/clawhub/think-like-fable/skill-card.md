## Description:

Think Like Fable guides an agent to apply rigorous reasoning by clarifying intent, decomposing problems, focusing effort on risk, verifying claims, separating knowns from guesses, challenging conclusions, and communicating answer-first.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dennisrongo](https://clawhub.ai/user/dennisrongo)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to make an agent apply a rigorous reasoning posture for high-stakes decisions, root-cause analysis, architecture calls, security judgments, and other tasks where confident wrong answers are costly.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad phrases and influence the agent's reasoning style in high-stakes tasks.

Mitigation: Installers should review the disclosed activation behavior and use it where a rigorous reasoning posture is appropriate.

Risk: Over-application could add unnecessary rigor to trivial mechanical edits or casual questions.

Mitigation: Follow the artifact's scope guidance to avoid loading it for trivial tasks and to layer it under more specific task skills.
