## Use Case:

Developers, designers, and frontend engineers use this skill to turn design briefs, style direction, and component requirements into responsive frontend code, design tokens, interaction guidance, and accessibility-aware UI implementation notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can guide an agent to edit project files and run normal frontend commands.

Mitigation: Use it only in projects where file edits and command execution are expected, and review generated changes before merging or deployment.

Risk: Command or API-key handling can expose secrets or run unintended actions if copied without review.

Mitigation: Keep credentials in environment variables, avoid committing secrets, and review any command or API-key handling before execution.
