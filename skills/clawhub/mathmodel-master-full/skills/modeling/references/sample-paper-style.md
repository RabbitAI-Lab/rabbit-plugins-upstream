# 深层参考：优秀论文范文风格

## 读取时机

当需要模仿优秀论文的结构、摘要节奏、逐题写法、章节组织或终稿表达时，读取本文件。样本文档位于 `assets/sample-papers/C24104220149.pdf`。

不要复制范文原文，不要复用范文中的数据、结论、题目背景或模型结果。只学习其论文组织方式、表达节奏和论证结构。

## 范文结构特征

该范文采用“逐题展开 + 每题独立建模求解 + 章末小结”的结构，适合多问式国赛/CUMCM 赛题。

该范文页数较长、图表较密、算法和模型对比较充分。模仿时应学习其“图文并重、逐题深入、模型原理和结果对比都展开”的写法，而不是只模仿标题结构。

推荐借鉴的正文结构：

```text
题目
摘要
关键词
一、问题重述
  1.1 问题背景
  1.2 本文拟解决的问题
二、模型假设与符号说明
  2.1 模型的基本假设
  2.2 模型符号说明
三、技术路线图
四、问题一的模型建立与求解
  4.1 问题分析
  4.2 模型建立与求解
  4.3 本章小结
五、问题二的模型建立与求解
  5.1 问题分析
  5.2 模型建立与求解
  5.3 本章小结
……
九、模型评价与推广
  9.1 模型的优点
  9.2 模型的缺点
  9.3 模型改进与推广
参考文献
附录：代码
```

## 摘要写法

摘要采用“总述 + 逐题摘要 + 关键词”的模式。

写作节奏：

1. 第一段交代研究背景、总体任务、核心方法链和工具。
2. 后续按“针对问题一……”“针对问题二……”逐题概括。
3. 每个问题摘要段包含：问题困难、采用方法、关键过程、量化结果、有效性说明。
4. 对预测或分类问题，给出主要精度指标。
5. 对优化问题，给出最优方案或 Pareto 前沿等核心结果。
6. 关键词覆盖任务、方法和核心模型，不只写题目名词。

摘要不要只写“建立模型并求解”。应写清楚“用什么模型、解决什么问题、得到什么结果、结果如何验证”。

## 问题重述写法

问题重述分为“问题背景”和“本文拟解决的问题”。

背景段写法：

- 先说明现实背景和研究价值。
- 再说明现有方法或实际场景的不足。
- 最后引出本文需要建模解决的任务。

拟解决问题部分按原题问题编号展开，每个问题写成一个短段：

```text
（1）……：基于……数据，分析……，构建……模型，并评估……。
（2）……：针对……问题，引入……变量或约束，建立……模型，以提升……。
```

这一部分不写具体结果，只写任务和建模目标。

## 技术路线图写法

范文在假设和符号之后设置“技术路线图”，用于把多问题之间的关系可视化。

使用规则：

- 多问赛题建议保留技术路线图。
- 技术路线图按问题编号展开。
- 每个问题只展示关键步骤，例如数据获取、特征分析、模型选择、模型测试、结果分析。
- 若前一问结果进入后一问，应在路线图中体现衔接。

## 分问题章节写法

每个问题单独成章，统一使用：

```text
X.1 问题分析
X.2 模型建立与求解
X.3 本章小结
```

问题分析中说明该问题的难点、数据基础和模型选择理由。

模型建立与求解中按实际过程分小节，例如：

- 数据分析与特征提取
- 模型原理
- 参数寻优
- 模型训练
- 结果对比
- 模型分析

本章小结用于回收该问题的结果，写清楚最终结论和该结论如何支撑后续问题。

## 模型组合与对比风格

范文不是只使用单一模型，而是常用“候选模型对比 + 最优模型选择”的写法。

可借鉴方式：

- 分类问题：比较多个分类模型，并用准确率、召回率等指标说明效果。
- 参数寻优问题：比较多种优化算法或修正形式。
- 预测问题：比较深度模型、机器学习模型和传统模型。
- 多目标优化问题：同时给出单目标转化方法和智能优化方法，并比较结果。

使用这种写法时，必须有对比指标。不要只列模型名称。

## 结果表达风格

结果表达强调量化：

- 给出关键数值。
- 给出模型优于基准或对比模型的幅度。
- 对最优组合、最优方案或关键参数明确落点。
- 对多目标优化给出 Pareto 前沿或权衡解释。

图表后必须解释结果，不要只放图。

## 篇幅与视觉密度借鉴

参考范文的正文不应写得过短。对于完整国赛/CUMCM 论文，正文应不少于 30 页，并且通过以下内容自然达到篇幅：

- 每个问题都有问题分析、模型建立、求解过程和本章小结。
- 数据和结果部分包含足够多的图表。
- 关键算法写出底层原理和步骤。
- 模型之间有对比，结果有指标支撑。
- 检验、敏感性分析和模型评价不是形式化段落。

不要靠附录代码、原始数据表或空白页增加页数。

## 模型评价与推广写法

终稿末尾可以使用“模型评价与推广”，分为：

- 模型优点：对应本文实际工作，例如多模型对比、模型改进、泛化能力检验、可解释性增强。
- 模型缺点：承认数据、时间、算力、参数寻优、泛化范围等限制。
- 模型改进与推广：与缺点对应，说明后续可增加数据、特征、约束或推广场景。

缺点要真实，不要写成无关痛痒的套话。

## 使用约束

- 只模仿结构和表达方式，不模仿具体内容。
- 不要把范文的题目背景、磁芯损耗模型、数值结果迁移到其他题目。
- 若当前赛题不是多问式结构，可保留“逐问题章节”的思想，但调整章节名称。
- 若当前赛题要求强制格式，优先遵守赛题格式。
