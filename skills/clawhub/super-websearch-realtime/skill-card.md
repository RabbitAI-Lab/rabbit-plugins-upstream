This skill is ready for commercial/non-commercial use. <br>

### License/Terms of Use: <br>


## Use Case: <br>
External users and agents use this skill to search for recent information, prioritize current authoritative sources, summarize findings, and disclose when real-time search is unavailable or results may be incomplete. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Search topics may be sent to the web search provider, which can expose passwords, private documents, confidential business details, or other sensitive information if users include them in queries. <br>
Mitigation: Avoid entering sensitive or confidential material as search topics; use the skill for ordinary current-information searches and redact private details before requesting web search. <br>
Risk: Real-time search results can still be incomplete, stale, or unavailable when the required web search tool is unsupported. <br>
Mitigation: Prefer recent authoritative sources, state uncertainty clearly, and disclose when the response falls back to non-real-time knowledge. <br>
