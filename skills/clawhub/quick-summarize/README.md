# Quick Summarize Skill

A skill for OpenClaw that produces concise, structured summaries of text, URLs, or files.

## Install

```bash
clawhub install quick-summarize
```

## Usage

Once installed, the skill is automatically available when the agent determines summarization is needed.

## What It Does

- Summarizes any text input into a brief structured format
- Key points extracted automatically
- Action items flagged when present
