## Description:

Quickly summarize any text, URL, or file content into a concise structured brief.

This skill is ready for commercial/non-commercial use.

## Publisher:

[terrycarter1985](https://clawhub.ai/user/terrycarter1985)

### License/Terms of Use:

MIT-0

## Use Case:

External users, employees, and developers use this skill to turn long text, URLs, or file content into TL;DRs, executive summaries, key points, and action items.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may read and summarize user-provided files, private URLs, or sensitive text.

Mitigation: Install and use it only when summarizing that content is intended; avoid sensitive files or private URLs unless the content should be read for the summary.

## Reference(s):

- [ClawHub skill page](https://clawhub.ai/terrycarter1985/skills/quick-summarize)

## Skill Output:

**Output Type(s):** [text, markdown, guidance]

**Output Format:** [Markdown structured summary with Summary, Key Points, and optional Action Items sections]

**Output Parameters:** [1D]

**Other Properties Related to Output:** [2-3 sentence overview, 3-7 one-line key points, optional action items, and a note when content is already brief.]
