# Input contract

Node.js24.16+. action add: id(lowercase letters/numbers/_/-,1..64), title, url(publicHTTPS), scope:{tag:"body"|"main"|"article"} or {id:"element-id"}, intervalMinutes15..10080(default60), ignoreLinesContains:[], includeKeywords:[], optional delivery:{agentId,channel,accountId,to}. Arrays max20 terms, each <=200characters. One workspace holds <=10subscriptions. add/pause/resume/ack/dismiss/record-schedule/export require a unique requestId. Identical add retry reuses its baseline. check:{id} always fetches; no saved requestId is reused as a permanent poll key. list, show:{id}, pending:{id}. pause/resume retain data. dismiss:{id,eventId,reason} marks a manually reviewed event handled without a delivery claim. ack:{id,eventId,receipt:{confirmedByDeliveryTool:true,toolCallId,delivery}} requires real delivery evidence. schedule-spec:{id} returns poll request and route but creates no timer. record-schedule:{id,receipt:{confirmedByScheduler:true,jobId,intervalMinutes,nextRunAtMs,delivery}} records native read-back. export:{id} writes changes.md, changes.json, baseline.txt. No-change checks can still return previously undelivered events. Pending backlog cap20; resolve it before further changes. Recent resolved/filtered history cap19 plus pending; excerpts max20added/20removedlines, each500characters, with counts and truncation flags. Selected text <=60000characters. Fetch failures and invalid/ambiguous regions do not replace the baseline.

JSON input is a workspace file up to 1 MiB. Successful exports return files [{path,bytes,sha256}]. All processing stays under the active workspace; writes use new export directories and retain source files. For image/PDF operations, requestId is 1..80 ASCII letters, numbers, _ or -. An identical retry verifies saved source/output hashes.
