# 账号选题规划 (ym-content-topic-planner)

按账号定位规划一个周期的选题，并**先去重再规划**——避开已经讲过的角度，按系列组织，每期带目标与钩子。交付的是一张能直接照着发的排期表，不是一堆散点灵感。

## 何时使用

- 用户提到「选题规划」「下一步发什么」「内容排期」时
- 用户说「感觉没东西发了」「选题去重」时
- 用户提供一批历史标题，想看哪些还能做、哪些已经讲过时

## 运行前提

- 依赖：无第三方依赖，纯文本处理
- 不联网抓取平台热点：热点需用户自己提供，本技能不冒充"实时热点分析"

## 输入契约

| 输入 | 必需 | 说明 | 缺失时怎么办 |
|---|---|---|---|
| 账号定位 | 是 | 做什么内容、给谁看 | 定位模糊（如"什么都发"）→ 先问三个问题：给谁看 / 解决什么问题 / 你和别人有什么不同，问清再开始 |
| 已发内容清单 | 否 | 历史标题或主题，越多越好 | 没有 → **明确告知无法去重**，本次只做规划，输出每项标"未查重"，不得假装查过 |
| 更新频率 | 否 | 每周几条 | 无 → 按每周 3 条排，并在开头注明假设 |
| 目标平台 | 否 | 视频号 / 小红书 / 公众号 / 抖音 | 无 → 按通用内容形态排，不做平台专属优化 |
| 周期目标 | 否 | 涨粉 / 互动 / 转化 / 沉淀 | 无 → 默认"涨粉 + 沉淀"混合，并在排期表标注 |

## 执行步骤

1. **确认定位三要素** — 把用户给的定位拆成 受众 / 问题 / 差异点 三行，写在开头请用户确认。定位模糊时先问三个问题再继续，不硬做。

2. **建立已有内容索引** — 把用户给的历史标题归类到主题簇（3~8 个簇），每个簇写：簇名 / 已讲角度 / 已用形式 / 条数。用户没给历史清单时，跳过此步并在输出第二节明确写"未提供历史内容，本次未做去重"。

3. **逐条去重判定** — 新选题与已有内容逐条比对，按 `references/dedup-rules.md` 的三档判定：重复（剔除）/ 可做但需标明差异（降级）/ 全新角度或新痛点（优先）。每条必须写出判定依据（对照历史哪一条），不许只写结果。

4. **按系列组织** — 把选题归入 2~4 个系列（如"避坑系列""拆解系列""案例系列"），系列内部有递进关系（从入门到进阶），便于用户追更。系列划分规则见 `references/dedup-rules.md`。

5. **逐期填充五要素** — 每期写：标题候选（给 2 个）/ 目标（涨粉、互动、转化、沉淀四选一）/ 钩子（开头 3 秒说什么，要具体）/ 核心内容三点 / 形式（口播、图文、案例、拆解）。

6. **出排期表** — 按频率安排到具体日期或序号，标注系列归属与节奏。**避免同系列连发**（连续两条同系列会让用户疲劳），同系列之间至少隔一期。

7. **给选题储备池** — 另给 10 个备用选题，标"储备"，供断更救急。储备题同样要过一遍去重（有历史清单时）。

8. **列出待确认假设** — 把本次所有假设（频率、平台、目标、去重范围）集中列出，请用户确认或纠正。

失败行为：定位模糊且不补充 → 只问三个问题，不输出排期；要求"照搬某个爆款" → 拒绝抄袭，给同方向的原创改法。

## 输出格式

Markdown，五节：

```
## 一、定位确认
- 受众：[谁]
- 解决什么问题：[问题]
- 与别人的不同：[差异点]

## 二、已有内容索引与去重结论
| 主题簇 | 已讲角度 | 条数 | 本次处理 |
|---|---|---|---|
| [簇名] | [角度] | [n] | 剔除/降级/可延伸 |

## 三、周期排期表
| 期数 | 标题候选 | 系列 | 目标 | 钩子（开头 3 秒） | 核心三点 | 形式 | 去重结论 |
|---|---|---|---|---|---|---|---|
| 1 | [标题 A] / [标题 B] | [系列名] | 涨粉 | [具体钩子] | 1…2…3… | 口播 | 全新角度 |

## 四、选题储备池（10 个）
- [选题]（角度：[一句话]）

## 五、需确认的假设
- [假设项]
```

## 能力边界

- 不保证流量与涨粉：只做选题规划，不预测哪条会火
- 不抓取平台实时热点（用户需自己提供）
- 不抄袭他人具体选题：只给方向与原创改法，不照搬
- 不做竞品账号监控与数据追踪
- 不生成正文：本技能只出选题与钩子，不写完整稿件

## 常见坑

1. **假装去重过** — 用户没给历史清单，输出却写"已避开重复内容"。规避：无清单时第二节必须写"未查重"，每条标"未查重"。
2. **换汤不换药算新选题** — "三个沟通技巧"和"沟通要注意的三件事"被当成两个选题。规避：按"问题是否相同"判定而不是"标题是否相同"。
3. **钩子写成标题复述** — 钩子写"今天讲讲如何沟通"，等于没钩子。规避：钩子必须是具体冲突、反常识或悬念，能让人停 3 秒。
4. **同系列连发** — 三期连着同一个系列，观众疲劳取关。规避：同系列之间至少隔一期，排期表上标系列一眼看出。
5. **全是涨粉目标** — 每期都标"涨粉"，账号没有沉淀内容。规避：四类目标混排，至少留一部分沉淀型选题。
6. **储备池与正式排期重复** — 10 个储备里有 3 个和排期撞车。规避：储备题同样过一遍去重，撞车的替换掉。

## 验收用例

- 正常：给出定位 + 20 条历史标题 → 五节齐全，排期表每条有去重结论与钩子
- 边界 1：无历史清单 → 第二节明确写"未查重"，不假装查过
- 边界 2：定位模糊（"什么都发"）→ 先问三个问题，不硬出排期
- 失败：要求照搬某个爆款选题 → 拒绝抄袭，给同方向的原创改法
