## 世界方法论要求清单

世界建造器每种任务类型的"零件清单"——必选/可选组件、组装顺序、约束。按清单逐项产出。

---

### W0 世界需求解析域

#### wb-00 世界需求解析
- **必选组件**: 用户原始输入、世界名称（用户提供或临时占位）、世界类型（架空/改编/混合/未来/历史，五选一）、世界用途（小说/游戏/电影/跑团/纯设定/多用途）、已知维度清单（从输入中明确提取的信息：已有地理描述/已有历史事件/已有物种/已有技术设定等）、缺失维度清单（输入中未提及的12维）、用户明确要求（输出格式/世界规模/生成偏好）
- **可选组件**: 输入来源类型（直接描述/灵感概念/需求驱动/自由创作/改编现有IP）、世界的核心冲突或主题（如：资源匮乏/种族对立/技术伦理）、参考作品（用户提到了哪些已有世界作为灵感）
- **组装顺序**: 接收输入→提取世界名称→判断世界类型→确定世界用途→枚举已知维度→枚举缺失维度→记录用户明确要求→提取核心冲突和参考文献
- **约束**: 不可编造用户未提供的信息作为"已知维度"；世界类型五选一（架空/改编/混合/未来/历史）；缺失维度清单必须覆盖全部12个维度；世界用途影响后续的生成粒度（游戏世界需要更多空间维细节，小说世界需要更多文化政治维细节）
- **格式**: 世界需求解析报告（Markdown）

#### wb-01 维度填充策略
- **必选组件**: 12维填充策略表（每维标注策略类型+信息来源）、用户输入提取项、推理推导项、主动询问项、默认值填充项
- **四种策略类型**:
  - **直接提取**: 用户输入中已明确的信息，直接填入对应维度
  - **推理推导**: 基于已填充维度逻辑推导（如：设定了冰河期气候→推导植被类型和农业模式→推导社会结构和经济模式）
  - **主动询问**: 用户输入完全未提及且无法推导的维度，列出具体问题等待用户回答
  - **默认值**: 对世界定位不关键且用户未提及的维度，使用类型默认值（如：架空幻想世界的技术默认=中世纪水平；未来世界的地理默认=地球或类地行星）
- **必选组件：四种信息来源（每维必须标注使用的信息源层级）**:
  - **第1层 个人输入（权威源）**: 用户直接提供或通过主动询问获取，不可被LLM猜测覆盖。主导维度：核心法则（魔法/物理体系）、世界核心冲突、关键美学取向。特点：只有用户自己知道的世界创意，无替代源
  - **第2层 网络搜索（验证源）**: 通过WebSearch验证科学事实，不可用时降级为LLM内置知识并标注"未网络验证"。主导维度：地理科学规律、历史类比参考、真实文化人类学数据、物理学/生物学基准
  - **第3层 LLM推理（推导源）**: 从已填充维度逻辑推导，必须标注推导链路。主导维度：技术→经济推导、资源→政治推导、地理→文化推导、法则→技术约束推导
  - **第4层 默认值（兜底源）**: 世界类型预定义默认值，必须标注"默认值"不可冒充推导结果。主导维度：非核心区域的生态环境填充、辅助文化群体的习俗、边远地区的技术水平
- **信息源可靠性递降规则**: 上一层可用时必须使用上一层，不可跳过。第1层不可坠降（无替代源），第2层网络不可用时坠降到第3层，第3层推导失败时坠降到第4层
- **可选组件**: 策略优先级排序、询问问题的具体措辞、信息源坠降记录
- **组装顺序**: 逐维分析→策略标注→信息源层级标注→推导链路记录→询问问题拟定→默认值选择
- **约束**: 推理推导必须基于可验证的逻辑链，不可跳跃；主动询问的问题必须具体（如"这个世界有几个智慧种族？它们各自的生理特征是什么？"而非"你想有什么种族？"）；默认值必须标注为默认值，不可冒充推导结果；每维必须标注信息源层级
- **格式**: 12维填充策略表（Markdown表格）

#### wb-02 执行顺序确定
- **必选组件**: 域执行顺序方案、并行/串行标注、关键依赖路径、跨维咬合检查节点标注、管线模式选择（P1-P7中适用于世界生成的主导模式）
- **执行顺序默认规则**:
  - 实体层三域（W1空间时间/W2法则生命/W3物质技术）可并行填充——它们各自独立但共享物理基底
  - 社会层（W4文化/政治/经济）依赖实体层完成——社会形态被地理、资源、物种、技术共同决定
  - 抽象层（W5认知/W6审美动态）依赖社会层完成——知识体系和审美取向诞生于具体社会条件
  - 整合层（W7）依赖全部前序域完成
- **跨维咬合检查节点**:
  - A点（实体层验收）：wb-12, wb-22, wb-32 并行执行
  - B点（社会层验收）：wb-43（含社会层三维间咬合+与实体层跨层咬合）
  - C点（抽象层验收）：wb-51, wb-62（含抽象层三维间咬合+与前两层跨层咬合）
  - 终点：wb-70 全维度咬合矩阵检测
- **可选组件**: 管线模式调整说明（用户有特殊需求时，如：先构建社会层再反推实体层——不推荐但技术上可行）
- **组装顺序**: 依赖分析→并行可能性评估→执行顺序排定→咬合节点标注→管线模式选择
- **约束**: 尊重自然依赖关系，不人为串行可并行的域；W4不可跳过（世界必须有社会结构，即使是无人世界也需要标注"无社会层"原因）；实体层三域并行是推荐策略，但各域内部任务保持串行
- **格式**: 执行顺序图（Markdown流程图+管线模式标注）

#### wb-03 输入模式检测
- **必选组件**: 输入类型判定（Mode A自然语言/Mode B角色引用/Mode C混合）、判定依据（检测到的角色Skill文件路径或缺失）、路由决策、路由理由
- **检测规则**:
  - 扫描输入中是否包含路径模式：`~/.workbuddy/skills/`、`character-`前缀、`references/character-data.md`
  - 扫描输入中是否包含角色Skill命名特征（cb-任务ID、Character Builder产物）
  - 如检测到≥1个角色Skill引用 → Mode B或Mode C
  - 如仅有自然语言描述 → Mode A
- **可选组件**: 输入质量评估、混合输入的比例分析
- **组装顺序**: 输入扫描→模式判定→路由决策→理由记录
- **约束**: 判定必须给出明确依据，不可模糊；Mode C必须明确哪些维度从自然语言填充、哪些从角色提取
- **格式**: 输入模式检测报告（Markdown）

### W1 空间与时间域

#### wb-10 空间锚定
- **必选组件**: 世界整体空间描述（行星/平面/环形/多层/虚空等世界形态）、大陆与海洋分布（大陆数量/面积比例/大陆名称）、地形地貌系统（山脉走向/平原分布/沙漠位置/森林覆盖/水系网络）、气候系统（气候带划分/季风环流/洋流/极端气候区域）、天文设定（恒星类型/卫星数量/自转公转周期/日长年长/季节循环/潮汐）、区域划分（自然地理分区或人文区域命名）、可居住区域与不可居住区域
- **可选组件**: 详细地图描述、地理位置对文化的暗示、特殊地理奇观、地下/水下/天空/太空等非地表空间
- **组装顺序**: 世界形态→大陆海洋→地形地貌→气候系统→天文设定→区域划分→可居区域
- **约束**: 地理结构需遵循地球科学原理（高山的迎风面和背风面降水差异、纬度与气候带关系等），架空时标注偏离点和偏离理由；气候系统必须自洽——沙漠不应紧邻雨林无地理屏障；天文设定影响日长年长季节，需与气候设定一致；区域划分的命名应反映其地理特征或历史来源
- **格式**: 空间锚定报告（Markdown + 地形描述）

#### wb-11 时间锚定
- **必选组件**: 历法体系（计时单位/历法类型/纪年方式）、纪元与时代分期（每个时代：名称/时间跨度/核心特征/起止事件）、关键历史事件时间线（至少5个里程碑事件：含时间/事件/影响/参与者）、历史驱动力分析（什么力量推动历史前进：技术/人物/经济/自然/魔法/外部入侵等）、考古层（深层历史——创世或远古/传说时代——口述史诗和神话/信史时代——有文字记载的历史）
- **可选组件**: 并行时间线（不同文明的历史并行对照）、被遗忘的历史（世界中有但当代角色不知道的历史事件）、未来时间表（从"现在"到故事发生时间的规划）
- **组装顺序**: 历法体系→纪元分期→关键事件时间线→历史驱动力→考古层
- **约束**: 时间线必须自洽——事件A不能既是事件B的原因又发生在事件B之后；历史驱动力需要与前序事件形成因果链；考古层的"传说时代"历史可能与信史矛盾，但需标注这是"不同文明的历史诠释差异"还是"设定的客观事实"；纪元分期的名称需符合该文明的命名逻辑
- **格式**: 时间锚定报告（Markdown + 时间线描述）

#### wb-12 时空一致性校验
- **必选组件**: 校验结果（PASS/FAIL/FLAG）、不通过项的问题说明、修正建议
- **四项校验内容**:
  1. **气候-历史匹配**: 世界的气候变迁是否与地质年代和历史事件一致——不通过标志：永冻冰原上的800年热带帝国
  2. **地理-文明匹配**: 文明起源地是否具备文明发展所需的地理条件（大河流域、可驯化动植物、可防御地形等）——不通过标志：沙漠中心的无水源大型帝国
  3. **天文-历法匹配**: 历法体系是否与天文设定一致——不通过标志：无卫星的世界有"月"的概念
  4. **空间-事件匹配**: 关键历史事件是否被地理条件支持——不通过标志：无海洋的世界有"跨洋贸易帝国"
- **可选组件**: 特例说明（刻意设计的反常，如魔法维持的沙漠帝国）
- **组装顺序**: 气候历史→地理文明→天文历法→空间事件
- **约束**: 四项必须全部评估；FLAG项（有张力但合理的）需解释维持合理性的特殊设定
- **格式**: 校验报告（Markdown检查表）

### W2 法则与生命域

#### wb-20 法则定义
- **必选组件**: 物理法则体系声明（"与现实相同"或偏离清单）、偏离现实的物理法则详细说明（如有）、魔法/超自然体系完整定义（如存在：能量来源/施法者条件/施法规则/魔法分类/限制与代价/魔法与物理法则的交互边界）、自然规律（地质灾害频率/气候极端事件周期/生态自我修复能力）、关键自然常数（与现实相同或不同的基本常数：重力加速度/大气成分/放射性衰变速率等）
- **魔法体系必须包含的子项**（如存在魔法设定）:
  - 能量来源：魔力来自哪里（环境/生命/神明/异界/情绪/契约）
  - 施法者条件：谁能施法（天赋/血统/训练/仪式/道具/随机）
  - 施法规则：如何施法（咒语/手势/符文/冥想/献祭/领域展开）
  - 魔法分类：魔法类型（元素/召唤/变化/预言/防护/死灵/心灵等）
  - 限制与代价：使用魔法的限制（体力消耗/寿命折损/材料消耗/冷却时间/只能使用N次/特定条件下不可用）
  - 魔法与物理的边界：魔法能改变物理法则的程度（魔法是否守恒/魔法是否可以创造物质/魔法与热力学定律的关系）
- **可选组件**: 法则的发现史（不同文明对自然法则的不同理解）、法则的局域性（不同区域是否有不同的规则）
- **组装顺序**: 物理法则→魔法体系→自然规律→关键常数
- **约束**: 物理法则不可内部矛盾——若设定重力为地球一半，则建筑高度/生物体型/大气厚度必须一致推导；魔法体系必须有代价——不允许"免费万能魔法"；魔法与物理法则的交互必须明确定义边界（魔法可否创造质量？可否逆转时间？）；法则的偏离点必须明确标注"与现实不同的设定"
- **格式**: 法则定义报告（Markdown + 魔法体系表格）

#### wb-21 生命定义
- **必选组件**: 智慧物种清单（每种：名称/生理特征/寿命/繁殖方式/感知能力/特殊能力/种群数量级/地理分布）、非智慧生物生态（生产者清单/消费者分层/分解者/关键物种或基石物种）、生态系统结构（食物链层级/共生关系/竞争关系/生物地理分区）、生命起源理论（世界的科学解释或创世神话中的生命起源——两个版本可能不同，需标注哪个是"客观事实"哪个是"文明信仰"）、疾病与医疗条件（主要疾病/医疗水平/瘟疫史）
- **智慧物种子项必须包含**:
  - 生理特征：体型/感官/代谢/运动方式/环境适应性
  - 社会倾向：独居/群居/家族/部落/国家、合作/竞争倾向
  - 演化路径：与其他物种的演化关系（共同祖先/独立起源/魔法创造/外星迁移）
  - 与其它物种的关系：支配/共生/竞争/捕食/被崇拜
- **可选组件**: 灭绝物种清单与灭绝原因、神话生物（被认为存在但客观不存在的生物——标注区别）、生态系统脆弱性分析
- **组装顺序**: 智慧物种→非智慧生物→生态系统→生命起源→疾病医疗
- **约束**: 智慧物种的生理特征必须与气候/重力/大气等空间维和法则维设定一致；生态系统必须自洽——没有顶级掠食者的食物链会崩溃；物种地理分布必须与空间维的地理隔离和气候带一致；智慧物种数量（≥1），若只有人类则声明"无其它智慧物种"
- **格式**: 生命定义报告（Markdown + 物种表格）

#### wb-22 法则-生命校验
- **必选组件**: 校验结果（PASS/FAIL）、不通过项说明
- **四项校验内容**:
  1. **物理-生理匹配**: 物种生理特征是否被物理法则支持——不通过标志：高重力世界的瘦高脆弱物种
  2. **魔法-物种匹配**: 如有魔法体系，施法能力是否被物种生理支持——不通过标志：无神经系统的植物施法者
  3. **生态-气候匹配**: 生态系统分布是否与气候带一致——不通过标志：热带雨林食物链中有北极熊
  4. **演化-时空匹配**: 物种演化路径是否被时间跨度和地理演化支持——不通过标志：没有地理隔离却演化出完全不同的人形智慧物种
- **可选组件**: 魔法共生体分析（物种与魔法的特殊关系）
- **组装顺序**: 物理生理→魔法物种→生态气候→演化时空
- **约束**: 四项必须全部评估；跨维度矛盾必须修正，不可"算了不管了"
- **格式**: 校验报告（Markdown检查表）

### W3 物质与技术域

#### wb-30 物质定义
- **必选组件**: 元素体系（基本元素/化合物/特殊物质——若与现实相同则声明）、矿产资源分布（金属矿/能源矿/宝石/稀有物质的地理分布表和地图相关性）、能源类型（生物质能/化石燃料/水力/风力/地热/魔法能/核能/太阳能/暗物质能等，每类的可用性和分布）、物质稀缺性分级（常见/不常见/稀有/传说级，每级的代表物质和分布逻辑）、物质特性（是否有不同于现实的特殊材料——如比钢硬10倍的木材、常温超导体等，需定义其来源和限制）
- **可选组件**: 资源勘探历史（什么文明发现了什么资源）、资源的可持续性分析（可再生/不可再生/消耗速率）
- **组装顺序**: 元素体系→矿产分布→能源类型→物质稀缺性→物质特性
- **约束**: 资源分布必须与空间维的地理条件一致——煤矿存在于沉积盆地，金矿存在于火成岩区域；如有魔法资源（魔晶/魔力矿等），需定义生成机制（死去的远古魔法生物的化石/魔力浓度凝结/异界渗透）；资源的稀缺性分级需与经济维的贸易和阶层设定一致
- **格式**: 物质定义报告（Markdown + 资源分布表）

#### wb-31 技术定义
- **必选组件**: 技术等级声明（参考卡尔达肖夫指数或自定义等级：石器/青铜/铁器/古典/中世纪/文艺复兴/蒸汽/电气/原子/信息/星际/神级等）、核心技术清单（能源技术/材料加工/信息传递/运输/武器/医疗/建筑/农业，每项标注技术水平）、技术掌握者（谁拥有技术：普及/精英/教会/工匠行会/国家垄断/失落文明）、技术传播路径（技术扩散速率/贸易路线上的技术传播/军事征服带来的技术转移/技术封锁壁垒）、技术瓶颈（当前技术卡在什么问题上——如：有蒸汽机但冶金技术不足以造高压锅炉）
- **可选组件**: 技术史（重要发明的发明者/发明时间/社会影响）、失传技术（曾经存在但已失传的技术及失传原因）、外来技术（与其他世界/文明接触获得的技术）
- **组装顺序**: 技术等级→核心技术清单→技术掌握者→技术传播→技术瓶颈
- **约束**: 技术等级必须与物质维的资源条件一致——无铁矿文明无法进入铁器时代，无化石燃料的文明蒸汽时代需魔法替代能源；技术传播必须与地理维的交通条件和政治维的权力结构一致；技术瓶颈必须有明确的物理/资源/社会原因；不允许"就剩这一个技术没突破其他都超先进"的科技树——技术是系统工程，冶金的落后会连锁影响建筑/武器/工具
- **格式**: 技术定义报告（Markdown + 技术清单表）

#### wb-32 物质-技术校验
- **必选组件**: 校验结果（PASS/FAIL）、不通过项说明
- **三项校验内容**:
  1. **资源-技术等级匹配**: 技术等级是否被可用资源支持——不通过标志：无铜锡矿的青铜文明
  2. **能源-技术规模匹配**: 技术应用规模是否被能源供给支持——不通过标志：有电但没有发电能力的文明
  3. **传播-地理匹配**: 技术传播路径是否被地理条件支持——不通过标志：被3000公里沙漠隔离的两个文明拥有同源同步技术
- **可选组件**: 替代资源路径分析（如缺少铁矿，文明可能的替代技术路线）
- **组装顺序**: 资源技术→能源技术→传播地理
- **约束**: 三项必须全部评估；替代路径（如：用魔法替代蒸汽机）必须标注为"架空设定替代"并解释替代的可行性
- **格式**: 校验报告（Markdown检查表）

### W4 社会层域

#### wb-40 文化填充
- **必选组件**: 主要社会/文明清单（每种：名称/核心价值观体系/社会结构/家庭形态/性别角色/人口规模/地理分布）、语言体系（语系分类/通用语/方言分布/死语/书写系统/识字率）、习俗与仪式（生死婚嫁/节日/成年礼/日常礼仪/待客之道/禁忌）、道德体系与价值观（善/恶/荣誉/耻辱/自由/秩序的定义和优先级）、文化传播与融合（文化圈划分/核心文化区/边缘文化区/文化冲突带/文化交流路径）
- **社会结构子项必须包含**:
  - 核心组织单位：个人/家庭/氏族/部落/城邦/国家——哪个是基础
  - 社会分层：阶级/等级/种姓制度，是否允许流动
  - 性别角色：社会对性别/性别的定义和角色分配
  - 年龄分层：老人/成人/青年/儿童的社会角色和权利
- **可选组件**: 小众亚文化（主流文化内部的边缘群体文化）、文化变迁（当代文化正经历什么变化）、文化的物质表现（建筑风格/饮食/服饰——这些在审美维进一步展开）
- **组装顺序**: 文明清单→社会结构→语言体系→习俗仪式→道德价值观→文化传播
- **约束**: 文化设定必须与物种维一致——不同物种如果共存，必须定义跨物种文化互动模式；语言分布必须与地理维和历史维的迁移/征服历史一致；习俗必须能在物质维和技术维的设定中找到物质基础（对太阳的崇拜发生在太阳能丰富的区域）；核心价值观体系需与生存环境匹配——资源匮乏环境的文化倾向于集体主义和资源共享，资源丰裕环境的文化可能更倾向个人主义；每个文明至少定义3个核心仪式或习俗
- **格式**: 文化填充报告（Markdown + 文明对照表）

#### wb-41 政治填充
- **必选组件**: 政体类型清单（每种政体：名称/归属文明/统治方式/权力合法性来源/继承规则）、权力结构（中央集权/分封制/联邦制/城邦联盟/无政府等，附权力流程图）、主要派系（政党/家族/军事集团/宗教组织/秘密结社/商业行会，每派：目标/资源/影响力范围/盟友与敌人）、领土与边界（各国/各势力领土范围及历史演变、争议区域/无人区/缓冲区）、法律体系（法律类型：成文法/习惯法/神裁法/法典，法律执行者，法律对社会各阶层的不同适用性）、外交关系（势力间关系矩阵：同盟/敌对/中立/附庸/宗主/贸易伙伴）
- **可选组件**: 政治思想史（不同政治理念的起源和竞争）、非正式权力结构（"影子政府"——黑帮/情报机构/跨国组织/魔法院士会等实际掌握权力的非官方实体）、政治制度对个体的日常影响
- **组装顺序**: 政体类型→权力结构→主要派系→领土边界→法律体系→外交关系
- **约束**: 政体类型必须与经济维的生产方式匹配——农业经济支撑封建/帝国制度，工业经济支撑代议制/议会制；领土边界必须有地理/历史/军事根据——不可凭空画线；派系斗争必须反映资源分配/文化价值观/认知理念的根本矛盾；法律体系的复杂度必须与技术维的信息记录技术匹配——无文字文明不可能有成文法典
- **格式**: 政治填充报告（Markdown + 势力关系矩阵）

#### wb-42 经济填充
- **必选组件**: 生产方式（主要生产方式：农业/狩猎采集/畜牧业/手工业/工业/信息/魔法经济，各生产方式占比和分布）、贸易体系（贸易路线地图描述/主要贸易品/贸易组织/贸易壁垒/关税/走私路线/贸易中心城市）、货币与金融（货币类型：实物货币/金属币/纸币/魔法币/信用/以物易物，货币体系：单一货币/多重货币/无货币经济，通货膨胀/贬值历史，信贷体系：有/无/高利贷合法/禁止放贷/寺院放贷）、资源分配与阶层分化（谁控制关键资源/贫富差距/基尼系数定性描述/社会流动性/最低生存保障/饥荒频率）、经济周期（繁荣/衰退/危机的周期性规律及其触发因素）
- **可选组件**: 经济思想（什么经济学说主导）、非正式经济（黑市/灰色经济/地下经济规模与结构）、经济依附关系（殖民地/经济殖民地/资源诅咒型经济）
- **组装顺序**: 生产方式→贸易体系→货币金融→资源分配→经济周期
- **约束**: 贸易路线必须沿地理维度中可通行的路径——沙漠/山脉/海洋构成天然贸易壁垒；货币体系必须被物质维和技术维支持——金币需要金矿和铸币技术，纸币需要印刷技术；阶层分化必须能还原为资源控制和经济结构——"富人有钱"不是解释，"富人控制了X资源并通过Y制度维持垄断"才是；经济周期必须与政治维的法律和动态维的循环模式一致
- **格式**: 经济填充报告（Markdown + 经济数据表）

#### wb-43 社会层校验
- **必选组件**: 校验结果（PASS/FAIL）、不通过项说明
- **五项校验内容**:
  1. **文化-政治咬合**: 文化价值观是否与政治体制自洽——不通过标志：极端集体主义文化中存在完全无组织的小政府
  2. **经济-政治咬合**: 经济基础是否支持政治上层建筑——不通过标志：自给自足的游牧部落拥有复杂的官僚税收系统

  4. **阶层-文化-技术咬合**: 社会阶层的分化是否与文化价值观和技术条件匹配——不通过标志：人人平等意识形态的社会存在世袭贵族
  5. **社会层-实体层咬合**: 社会层三维是否与实体层设定一致——不通过标志：冰河期设定中存在全球贸易网络
- **可选组件**: 张力分析（社会层内部的设计张力是否有叙事价值）
- **组装顺序**: 文化政治→经济政治→语言领土贸易→阶层文化技术→社会实体
- **约束**: 五项必须全部评估；社会层内部矛盾若为刻意设计（如：殖民地的文化与被殖民政体的冲突）需标注这是"设计的动态冲突"
- **格式**: 校验报告（Markdown检查表）

### W5 认知域

- **格式**: 认知填充报告（Markdown + 宗教/意识形态对照表）

- **组装顺序**: 知识技术→信仰政治→教育经济→信息法则

### W6 审美与动态域

#### wb-60 审美填充
- **必选组件**: 视觉艺术（绘画/雕塑风格及代表作品类型、建筑风格及代表建筑类型——受材料/气候/技术约束、城市布局逻辑——有机生长/网格规划/环形/按阶级分区）、听觉艺术（音乐体系——音阶/调式/乐器类型、音乐功能——仪式/娱乐/叙事/魔法媒介、代表性音乐形式）、文学与叙事传统（史诗/诗歌/小说/戏剧的文体传统、故事母题库——英雄之旅/创世/洪水/战争等反复出现的主题）、服饰与身体装饰（材料来源/阶级区分/日常与礼仪服饰差异/身体改造——纹身/穿环/缠足/整容等）、审美理念（核心美学概念——什么是美/和谐/崇高/丑/恐怖——这些概念的哲学来源和文化根源、审美变迁——曾经流行但已过时的审美、不同阶层/文明的审美冲突）
- **可选组件**: 跨文化审美影响（哪个文明的审美标准主导了什么区域）、禁忌美学（被视为堕落/不道德的审美取向）
- **组装顺序**: 视觉艺术→听觉艺术→文学传统→服饰身体→审美理念
- **约束**: 建筑风格必须被物质维的可用材料和技术维的建筑技术约束——没有森林的文明建筑不是木结构；服饰必须反映物质维的纺织材料和气候条件；审美理念必须与文化维的价值观一致——集体主义文化中的"美"定义往往与个人主义文化不同；城市布局必须反映政治维的权力结构——宫殿/神庙位于城市中心的文明与市场位于城市中心的文明有根本不同的权力逻辑
- **格式**: 审美填充报告（Markdown + 风格对照表）

#### wb-61 动态填充
- **必选组件**: 自然循环（季节循环/水循环/碳循环/魔力循环/能量循环/生态演替——这些循环的周期和幅度）、历史周期性（帝国兴衰周期/技术革命周期/宗教改革周期/大灭绝事件的周期模式和驱动力——是外部冲击还是内部矛盾积累？）、冲突模式（资源冲突——水/土地/矿/能源/魔法资源争夺的历史和现状；意识形态冲突——宗教战争/主义对抗/文明冲突；领土冲突——边界战争/殖民扩张/独立运动；代际冲突——新一代的价值观与老一代的冲突模式和爆发点）、熵增与退化（知识流失的机制——图书馆烧毁/口述传统中断/知识分子被清洗；文明崩溃的诱因——生态崩溃/外敌入侵/内部腐化/技术失控；生态退化的历史——过度开发导致的荒漠化/物种灭绝）、未来轨迹（基于前11维设定的合理未来推演——不是"注定发生的命运"而是"在高概率路径上的走向"：至少描绘3条可能路径：最可能路径/乐观路径/悲观路径）
- **可选组件**: 蝴蝶效应节点（哪些看似微小的事件可能改变世界轨迹）、预言与命运（世界内是否有真正的预言能力——这本身属于法则维定义，但在动态维中体现）
- **组装顺序**: 自然循环→历史周期性→冲突模式→熵增退化→未来轨迹
- **约束**: 动态维的所有内容必须可从前11维推导——帝国的兴衰不是"编剧需要"而是经济/政治/空间/技术条件的必然结果；循环的周期和幅度必须被法则维支持——魔力循环的周期必须与魔法体系的能量来源一致；冲突模式必须有具体的资源/意识形态/领土根源——不可"他们就是互相仇恨"；未来轨迹必须有推导链——路径A基于X趋势，路径B基于Y断裂；不允许"不可知论的未来"——世界建造的任务就是把可推导的未来推导出来，不确定的地方标注"概率"
- **格式**: 动态填充报告（Markdown + 循环图 + 未来情景）

#### wb-62 抽象层校验
- **必选组件**: 校验结果（PASS/FAIL）、不通过项说明
- **四项校验内容**:
  1. **审美-物质咬合**: 审美标准是否被物质资源约束——不通过标志：无石料文明拥有巨石建筑传统
  2. **动态-法则咬合**: 演变规律是否与法则维一致——不通过标志：完全线性进步史观中的魔法文明应有"魔法进步"而不是"技术进步"
  3. **认知-动态咬合**: 知识体系中的历史认知是否与动态维的客观历史一致——不通过标志：循环史观文明的认知维中所有历史都是线性叙事
  4. **抽象层-社会层咬合**: 审美/动态的设定是否与社会层矛盾——不通过标志：经济完全平等的乌托邦中居然存在奢华与简约的审美阶级对立
- **可选组件**: 三轴协同验证（认知/审美/动态三维是否形成互构关系——认知范式是否影响审美取向，审美取向是否影响动态演变方向）
- **组装顺序**: 审美物质→动态法则→认知动态→抽象社会
- **约束**: 四项必须全部评估；抽象层的内容不可脱离社会层和实体层而悬浮存在——审美不是"作者喜欢哥特风"，动态不是"故事需要世界大战"，必须能落到具体维度的咬合上
- **格式**: 校验报告（Markdown检查表）

#### wb-70 12维完整性校验
- **必选组件**: 12维校验表（每维PASS/FAIL/EMPTY）、FAIL项的问题说明、EMPTY项的原因说明、跨维咬合矩阵检测结果
- **12维逐维检查**:
  1. 空间维：地理/气候/天文/区域已填充 → 是/否
  2. 时间维：历法/纪元/事件/驱动力/考古层已填充 → 是/否
  3. 法则维：物理法则/魔法体系/自然规律/常数已填充 → 是/否
  4. 生命维：智慧物种/非智慧生物/生态系统/演化/疾病已填充 → 是/否
  5. 物质维：元素/矿产/能源/稀缺性/特性已填充 → 是/否
  6. 技术维：技术等级/核心技术/掌握者/传播/瓶颈已填充 → 是/否
  7. 文化维：文明清单/语言/习俗/价值观/传播已填充 → 是/否
  8. 政治维：政体/权力结构/派系/领土/法律/外交已填充 → 是/否
  9. 经济维：生产方式/贸易/货币/阶层/周期已填充 → 是/否
  10. 认知维：知识体系/信仰/教育/信息传播/认知范式已填充 → 是/否
  11. 审美维：视觉艺术/听觉艺术/文学/服饰/审美理念已填充 → 是/否
  12. 动态维：自然循环/历史周期/冲突模式/熵增/未来轨迹已填充 → 是/否
- **跨维咬合矩阵检测**（重点检测66对跨维组合）:
  - 实体层内咬合（15对）：空间-时间、空间-法则、空间-生命、空间-物质、空间-技术、时间-法则、时间-生命、时间-物质、时间-技术、法则-生命、法则-物质、法则-技术、生命-物质、生命-技术、物质-技术
  - 实体层→社会层咬合（18对）：每3维实体×6维社会子维度
  - 社会层内咬合（3对）：文化-政治、文化-经济、政治-经济
  - 社会层→抽象层咬合（9对）：每3维社会×3维抽象子维度
  - 抽象层内咬合（3对）：认知-审美、认知-动态、审美-动态
  - 跨层循环咬合（18对）：抽象层→实体层的反向咬合（动态→空间、动态→法则等）
- **咬合检测逻辑**: 任一对跨维组合中，若维A的设定对维B有逻辑约束（如：高重力→限制生物体型），则检查维B的设定是否满足该约束。不满足的标记为FAIL
- **可选组件**: 维度质量评分（每维1-5分的完整度和自洽性评分）、世界整体可信度评分
- **组装顺序**: 逐维检查→FAIL汇总→EMPTY原因记录→跨维矩阵扫描→咬合冲突标注→校验报告
- **约束**: 12维必须逐一检查；EMPTY维必须说明是"此世界不需要"还是"待用户补充"；跨维咬合检测必须运行全部66对检测对——这是世界建造区别于松散世界观编辑器的地方；咬合冲突的检测逻辑见各域校验(wb-12/22/32/43/51/62)
- **格式**: 12维校验报告（Markdown检查表 + 咬合矩阵）

#### wb-71 世界Skill组装
- **必选组件**: SKILL.md（frontmatter+世界概述+12维数据摘要+元操作映射+管线编排+降级模式）、references/world-data.md（完整12维世界数据，每维完整展开）、references/world-requirements.md（世界作为技能时的行为约束——即从该世界导出角色/故事时的约束规则）

  - frontmatter: name(世界英文名)/author:world-builder/description(世界一句话描述+触发词，末尾必须包含`world-builder`)
