## W0域范本：玛雅古典世界的独立生成——需求解析与模式判定

- **类型**: 独立生成 (Mode A)
- **对应域**: W0 世界需求解析与输入模式检测域
- **来源**: Character Library P10异文化锚定型：伊察姆纳 + P07衰退驱动型：顾长渊 + P08边界维持型：衡
- **日期**: 2026-07-12

### 输入
用户输入：「基于古典玛雅文明（公元250-900年）的历史真实，结合P10伊察姆纳的角色设定，生成一个名为"星辰纪元"的玛雅式奇幻世界。时间设定在文明的最后一百年——天文学知识登顶而文明即将因未知原因解体。」

### 输出

#### wb-03 输入模式检测
**检测到的角色Skill引用**: 1个（P10伊察姆纳——作为"世界灵感来源"而非提取源）
**角色计数**: 1 → 不满足Mode B条件(需≥2)
**输入类型判定**: 纯自然语言描述 + 单个角色作为灵感参考 → **Mode A**
**路由决策**: 按标准12维流程独立生成，角色数据作为维度锚定参考（非提取源）

#### wb-00 世界需求解析
**世界名称**: 星辰纪元（K'inich Haab'——玛雅语"太阳历"）
**世界类型**: 异文化锚定奇幻——以真实玛雅文明为文化根基的架空世界
**已知维度线索**:
- 文化维：玛雅多神信仰、三界宇宙观、血祭仪式、祭司-天文学垄断（P10伊察姆纳数据）
- 法则维：时间循环≠线性时间、长计历/卓尔金历/哈布历三重循环并存（P10数据）
- 技术维：二十进制数学+零概念+裸眼天文观测（P10职业维）
**缺失维度**: 空间（玛雅地理如何奇幻化）、生命（除人类外的神性生物）、政治（城邦格局）、经济（可可豆货币体系）等
**用户意图**: 生成一个可为P10伊察姆纳提供世界观背景的完整世界Skill

#### wb-01 维度填充策略
12维全部走L3 LLM推理——玛雅文明有丰富的历史人类学文献可推导。文化维以P10伊察姆纳的维6文化数据为锚定（古典玛雅文明·尤卡坦半岛·祭司阶层·三界宇宙论），其余维度基于玛雅类型范式推导。
**信息源**: L3(11维推导) + P10角色数据作为文化锚点（非提取源），律法维中的时间三重循环=核心创新。

#### wb-02 执行顺序确定
**域执行顺序**: W0→W1/W2/W3(实体层并行)→W4(社会层)→W5/W6(抽象层并行)→W7
**管线模式**: P3并行汇聚——空间/法则/生命三域可并行（玛雅世界的空间结构和时间法则是各自独立的基础设定），在社会层汇聚
**关键依赖**: W1空间（尤卡坦地理）→W4政治（城邦分布格局）；W2法则（时间循环衰减）→W6动态（文明衰落的主因）

### 说明
- 仅1个P10角色引用不满足Mode B条件（需要≥2个来自同一世界的角色），因此走Mode A独立生成——但角色数据中的文化维可作为世界文化维的锚定参考
- 玛雅世界的核心创新是"时间循环不是永恒——而是正在衰减"——这一设定来自P10伊察姆纳的发现（维3名人锚点中隐含的"时间循环衰减"），从角色数据反推为世界法则
