## Description: <br>
World Builder helps agents create structured fictional world skills from a concept or from multiple Character Builder outputs, using a 12-dimension model for physical, social, and abstract world layers. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[wavegeometry](https://clawhub.ai/user/wavegeometry) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Creative writers, game designers, and developers use this skill to generate or extract self-consistent fictional world structures and package them as world skill files. It supports both concept-first world building and extraction of shared world layers from multiple Character Builder skills. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated world skill descriptions may contain inaccurate trigger words, inconsistent constraints, or misleading guidance. <br>
Mitigation: Review generated skill descriptions and scan generated skill files before installation or enablement. <br>
Risk: Character extraction mode may read Character Builder skill paths supplied by the user. <br>
Mitigation: Only provide paths to Character Builder skills that are intended to be read for the world-building task. <br>
