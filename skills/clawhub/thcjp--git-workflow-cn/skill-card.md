This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and teams use this skill to get structured Git workflow assistance in Chinese, including branch operations, merge-conflict handling, conventional commit suggestions, rollback guidance, and repository maintenance steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can guide command and write actions in Git repositories.

Mitigation: Review every proposed command before execution and confirm the target repository, branch, ref, and path scope.

Risk: The artifact includes destructive cleanup, reset, history-rewrite, and garbage-collection examples.

Mitigation: Run these commands only after backups are available and the user has explicitly approved the exact operation and target.
