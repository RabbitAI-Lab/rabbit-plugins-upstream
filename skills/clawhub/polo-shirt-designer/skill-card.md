## Description:

Generates customized polo shirt design drafts for print and manufacturing on demand using garment specifications, reference images, and personalized text or logos.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ai-hub-admin](https://clawhub.ai/user/ai-hub-admin)

### License/Terms of Use:

MIT-0

## Use Case:

Designers, apparel sellers, and manufacturers use this skill to specify polo shirt designs, prints, and logos and obtain online design drafts for print or manufacturing on demand.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Design prompts, reference image links, and generated design details are sent to an external service.

Mitigation: Use the service only for approved designs; avoid proprietary artwork and private image URLs unless approved for external sharing.

Risk: Running an unpinned CLI command may use an unreviewed package version.

Mitigation: Prefer a pinned, trusted CLI installation path.
