## Description:

Lists seven ticket-order platforms and guides installation of their separate Cinema Agent integrations.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Cinema Agent users and developers use this suite to discover seven ticket-order platform integrations and install only the platform packages they need. The suite lists available integrations; the separate packages supply platform-specific declarations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installing platform packages may enable routing, cinema pre-binding, and order or market-analysis polling.

Mitigation: Install only the integrations you intend to use and review each separate platform package before installation.
