## Description:

Provides Chinese-language Java development conventions based on the Alibaba Java Development Manual (Songshan edition), covering coding style, exception logging, unit testing, security, MySQL, project structure, and design guidance.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill when writing, reviewing, or troubleshooting Java code and database-backed Java services against a Chinese-language conventions manual.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad Java-adjacent trigger terms may invoke the skill when a narrower answer is needed.

Mitigation: Confirm the user is asking for Java development conventions before applying the manual's recommendations.

Risk: Test and database examples may be copied into live database-backed projects without sufficient review.

Mitigation: Treat examples as review patterns and adapt them with project-specific database isolation, rollback, and safety checks.
