# 章节初稿撰写指南（深度节点 B 输入）

> 用途：LLM 依据本指南为每章起草初稿正文，注入 `config.chapters[].body`，由生成器渲染。
> 原则：点对点呼应评分项、可量化、有出处、不夸大；不得出现模板腔与内部策略术语。

## 每章起草要点

### 1. 投标函 / 商务偏离表
- 直接响应招标核心条款，明确「完全响应」；
- 不写超出授权的承诺。

### 2. 资格审查资料
- 逐条对应资格条件，引用佐证页码；
- 客观分「应得尽得」，缺项即风险。

### 3. 技术方案 / 服务方案
- 每条评分标准单独成段，标题呼应评分项；
- 用数字、比例、时限替代模糊词；
- 关键承诺在其他章节有落点（无偏离索引可溯源）；
- 复杂方案处标注图表占位（chart 字段）。

### 4. 项目实施计划
- 阶段、里程碑、责任、时限清晰；
- 配甘特图占位。

### 5. 人员投入
- 岗位、资质、投入比例与简历对应；
- 配组织架构图占位。

### 6. 售后服务 / 应急
- 响应时间、可用率、备件用具体数字承诺。

## 禁止
- 禁止模板化空话、内部策略术语、夸张修辞；
- 禁止虚构资质、业绩、数据；
- 禁止第一信封（双信封）出现价格信息。

## 注入示例
```json
{ "level": 2, "title": "项目总体实施方案",
  "body": ["我方深刻理解本项目的核心目标……", "实施分四阶段：……"],
  "chart": { "title": "图 2-1 实施组织架构图", "hint": "含项目经理与各专业组" } }
```
