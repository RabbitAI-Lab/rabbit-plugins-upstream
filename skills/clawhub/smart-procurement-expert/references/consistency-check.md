# 一致性审查方法论（深度节点 A）

> 来源：合同与招投标文件一致性审查助手 v1.1.0，已用真实项目（黄平县人民医院）端到端验证。
> 用途：严格审查投标文件 / 中标通知书 / 拟签合同与招标文件的**实质性一致**，识别文字游戏与隐蔽让利。

## 一、Step0 输入闸门（强制）

审查启动前**必须**齐备以下材料，缺一则中止并提示用户补充：

- 招标文件（含补遗、澄清）
- 投标文件（含承诺函、报价、技术响应）
- 中标通知书（如已进入签约阶段）
- 拟签合同文本（如已起草）

未完成 Step0 不得进入比对。对应测试用例 TC9。

## 二、效力层级（冲突裁决次序）

1. 招标文件（含法定效力附件）
2. 投标文件中的实质性承诺
3. 中标通知书
4. 法律法规（法释〔2020〕25 号等）
5. 知识库（仅参考，须可溯源）

低层级与高层级冲突时，以高层级为准，并在报告中标注冲突点与风险等级。

## 三、检索熔断（防幻觉）

- 比对涉及法规/案例时，优先检索知识库；
- 若检索返回**低置信 / 无匹配 / 矛盾**，立即熔断：停止断言，显式标注「未命中，建议人工复核」；
- 严禁用模型记忆填补法规空白。

## 四、独立第三方声明

每次审查开头声明：以中立审查者立场逐条比对，不替招标方或投标方任何一方圆场；结论仅基于提供文件与可溯源依据。

## 五、比对维度

| 维度 | 检查点 |
|---|---|
| 标的 | 名称、规格、数量、服务范围 |
| 价款 | 合同价 vs 中标价 vs 投标报价，隐蔽下浮 |
| 质量 | 标准、质保期、验收 |
| 履行期限 | 工期/服务期，擅自缩短或延长 |
| 违约责任 | 是否弱化、免除对方责任 |
| 实质性条款 | 招标文件★号/废标条款是否被背离 |

## 六、风险分级

- 🔴 红：背离实质性条款 / 存在废标或合同无效风险 → 必须修改
- 🟡 黄：表述模糊、可能争议 → 建议澄清
- 🟢 绿：一致或无实质影响

## 七、测试用例（TC1–TC9 要点）

- TC2 实质性响应：投标承诺与招标文件★号条款逐条对应；
- TC6 前置风险：投标阶段未响应招标实质要求（如资质缺项）须在签约前暴露；
- TC9 输入闸门：缺材料时正确中止（同 Step0）。

## 八、输出

套用 `templates/consistency-check.md`：含独立第三方声明、逐项比对表、风险等级、法条/条款定位、修复建议。
