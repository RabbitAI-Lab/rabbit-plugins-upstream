# 商机甄别与投标决策方法论

> 对应流程节点：投前阶段 · 商机甄别（节点 1）。
> 借鉴 B「商机甄别 / 投标研判」环节的优点，按我们的规范重写；决策点严格标注「需人工确认」。

## 一、目标

把一条采购公告 / 邀请 / 截图，快速转化为**可判断「要不要投」的结构化情报**，避免盲目投入标书编制资源。

## 二、输入

- 采购公告、投标邀请书、公示截图、口头转述（须标注来源可信度）；
- 企业自身能力素材（资质、业绩、人员、地域、产能）。

## 三、抽取字段（结构化）

| 字段 | 说明 |
|---|---|
| 项目名称 / 采购人 / 代理机构 | 主体与联系人 |
| 预算 / 最高限价 | 利润空间基准 |
| 采购方式 | 公开招标 / 邀请招标 / 竞争性谈判 / 询价 / 单一来源 / 框架协议 |
| 法域判定 | 招投标法 / 政府采购法 / 国企采购（见 `legal-domains.md`） |
| 关键时间节点 | 报名、答疑/澄清、保证金、递交截止（用 deadline 推算并设提醒） |
| 资格门槛要点 | 资质、业绩规模、人员、财务、特定条件 |

## 四、投标可行性评估维度

1. **资格契合**：资质 / 业绩 / 人员 / 财务是否硬达标；任一硬缺口 → 高风险放弃。
2. **预算与利润**：限价下毛估成本与毛利，低于盈亏线需人工确认是否低价抢标。
3. **履约周期与地理**：工期 / 交付地是否在能力半径内。
4. **竞争态势**：已知对手数量与实力、是否有明显优势方。
5. **履约风险**：技术难度、验收标准、维保期限。

## 五、否决 / 废标风险初判（初扫）

对照知识库 `招投标评标否决AI知识库(7460608999968055)` 与 `招标文件汇集(7439473860155957)`，初扫：
- 资格门槛是否含「★号」硬性否决项；
- 我方是否存在明显不满足项；
- 时间节点是否过紧。

> 初判仅为情报级，不替代第四步实质性一致性审查。

## 六、决策点（⚠️ 需用户确认，禁止代答）

- 是否参与投标；
- 报价区间与策略边界；
- 商务承诺的弹性边界（工期、维保等）。

## 七、输出

套用 `templates/opportunity-screening.md`：商机摘要 + 时间节点表 + 可行性评分 + 初判风险 + 推进意见 + 待补充资料。
