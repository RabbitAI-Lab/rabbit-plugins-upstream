# 两法分轨判定（Step0 必读）

我国招采活动分两条并行法轨，在「工程」处交叉。本技能**所有任务入口先判定法域**，再走对应分支，避免术语与程序「张冠李戴」。

## 一、两条法轨

| 维度 | 招投标法体系 | 政府采购法体系 |
|---|---|---|
| 核心法 | 《招标投标法》+ 实施条例 | 《政府采购法》+ 实施条例 |
| 主要规章 | 各行业招标规定 | 87 号令（货物服务）、74 号令（非招标）、94 号令（质疑投诉） |
| 典型术语 | 否决投标、中标、招标人/投标人 | 废标、成交、采购人/供应商 |
| 救济机关 | 投诉 → 发改部门 / 行业主管部门 | 质疑 → 采购人；投诉 → 财政部门 |
| 公告媒介 | 依法必须招标项目指定媒介 | 中国政府采购网等指定媒介 |

## 二、法域判定表（Step0）

| 场景 | 法域 | 术语/程序分支 |
|---|---|---|
| 依法必须招标的工程建设项目 | 招投标法 | 否决投标 / 中标 / 发改投诉 |
| 政府采购货物、服务 | 政府采购法 | 废标 / 成交 / 财政投诉 |
| 政府采购工程（达到招标规模） | **双法叠加** | 采购启动受政府采购法管，招标程序受招投标法管；显式标注两步各走哪套 |
| 国有企业采购（非依法必须招标） | 国企采购规则 | 参照国资监管特殊规定 |
| 其他（如企业内部采购） | 按内部制度 | 不在本技能主覆盖，转介 |

## 三、交叉场景处理（政府采购工程）

- 采购人资格、资金、采购方式审批 → 走**政府采购法**；
- 招标公告、投标人资格、评标、中标 → 走**招投标法**；
- 输出中须用注释显式区分：「【政府采购法】……【招投标法】……」，不得混用一套术语。

## 四、术语对照（易错点）

| 同一行为 | 招投标法语境 | 政府采购法语境 |
|---|---|---|
| 投标/响应不合格被淘汰 | 否决投标 | 废标（或资格审查不通过） |
| 选定供应商 | 中标 | 成交 |
| 结果争议 | 异议 → 投诉（发改/行业） | 质疑 → 投诉（财政） |

> 本技能输出时随法域切换术语；若用户文件混用，以招标文件原文术语为准并在审查报告中提示。
