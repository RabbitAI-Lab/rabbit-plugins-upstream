# 评分建模方法论（借鉴并优化）

> 借鉴成熟评分建模实践（客观/主观分区分、写作深度指引、无偏离索引、佐证链目录），按我们的规范重写。

## 一、目标

把招标文件的评分办法翻译成**可执行的响应策略**，让用户清楚「凭什么得分、靠什么拿高分、用什么佐证」。

## 二、客观分 vs 主观分

| 类型 | 特征 | 响应策略 |
|---|---|---|
| 客观分 | 凭证书/资质/业绩硬条件给分，无自由裁量 | 逐项核验资格，确保「应得尽得」，缺项即风险 |
| 主观分 | 评委自由裁量（方案、服务、业绩质量） | 用写作深度 + 佐证链拉高分，避免空话 |

## 三、写作深度指引（主观分）

- **点对点**：每条评分标准单独成段，标题直接呼应评分项；
- **可量化**：用数字、比例、时限替代「完善」「高效」等模糊词；
- **有出处**：关键承诺在投标文件其他章节有对应落点；
- **不夸大**：不写超出实际能力的承诺（避免履约风险与虚假响应）。

## 四、无偏离索引

- 建立「评分项 → 投标响应位置」对照表；
- 标注每项「完全响应 / 正偏离 / 负偏离」；
- 任何负偏离必须显式说明并评估废标风险（🔴/🟡）。

## 五、佐证链目录

- 为每项得分点规划佐证材料（证书编号、合同关键页、检测报告）；
- 在响应文件中建「佐证索引」，标明每份佐证对应哪一分值；
- 客观分佐证须可核验，主观分佐证须可溯源。

## 六、价格分异常检测（前沿维度）

价格分是综合评分法中最易出错的环节，须做异常检测：

- **计算复核**：用招标文件公式（如基准价法、差值法）独立重算我方价格分，核对生成器/人工计算是否一致；
- **报价分布研判**：若我方报价显著偏离均值（过高或过低），评估「陪标/围标」嫌疑信号与中标概率；
- **临界值提示**：报价落在否决临界（低于成本预警、高于限价）须 ⚠️ 需用户确认；
- **扣除后价格**：中小企业价格扣除后参与评审的口径须与评分办法一致。

## 七、ESG 与前沿评分项（前沿维度）

- **ESG 绿色加分**：识别绿色认证 / 碳足迹 / 绿色供应链评分项，规划佐证（见 `frontier-adaptation.md` 第四节）；
- **评定分离**：识别「评标委员会推荐候选人、招标人定标」模式，响应策略侧重「入围即胜」；
- **信创适配**：若评分含「适配名录 / 自主可控」要求，须对应列明适配产品与清单版本（注意：现行表述用「适配名录」而非「目录」）。

## 八、输出

套用 `templates/score-model.md`：评分项拆解表 + 客观/主观分类 + 无偏离索引 + 佐证链规划 + 价格分异常检测 + ESG/前沿维度 + 风险标注。
