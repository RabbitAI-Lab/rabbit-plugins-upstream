# 图表占位与可视化增强方法论

> 对应流程节点：投中阶段 · 图表占位（节点 7）。
> 借鉴 B「可视化增强 / 图表占位索引」优点，按我们的规范重写；与深度节点 B 的 `chart` 字段联动。

## 一、目标

在章节初稿中标注**应插入图表的位置与说明**，让技术/服务方案「图表化」而非纯文字堆砌，提升主观分可读性。

## 二、推荐图表类型与适用章节

| 图表 | 适用章节 | 占位说明要点 |
|---|---|---|
| 技术路线图 | 技术方案 | 阶段、里程碑、交付物 |
| 组织架构图 | 项目团队 | 角色、汇报关系、人数 |
| 进度甘特图 | 实施计划 | 任务、起止、依赖、关键路径 |
| 实施流程图 | 服务方案 | 环节、责任人、时限 |
| 人员配置图 | 团队投入 | 岗位、资质、投入比例 |
| 网络/系统拓扑 | 技术方案 | 节点、链路、冗余 |
| 资金/成本计划表 | 报价与履约 | 科目、金额、时点 |

## 三、占位规范

每个图表占位须含：
- **标题**：如「图 3-1 项目实施甘特图」；
- **说明**：该图要表达的核心信息；
- **数据来源提示**：如「依据报价明细与里程碑计划生成」。

## 四、与深度节点 B 联动

在 `config.chapters[].chart` 注入占位描述（字符串或 `{title, hint}`），生成器会渲染为灰色底纹居中提示段落，用户据此插入真实图表。

示例章节条目：
```json
{
  "level": 2,
  "title": "项目实施计划",
  "body": "本项目分四阶段实施……（起草正文）",
  "chart": { "title": "图 3-1 项目实施甘特图", "hint": "依据里程碑计划生成" }
}
```

## 五、输出

套用 `templates/chart-index.md`：图表占位清单（图号 / 标题 / 所在章节 / 说明 / 状态）。
