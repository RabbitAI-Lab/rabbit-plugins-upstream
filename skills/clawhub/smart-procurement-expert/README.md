# 智慧招采专家

## 一句话定位
投标人侧的招投标与政府采购**全流程合规导航助手**——从看清招标文件、组织得分策略，到生成同格式标书骨架、严格审查一致性，再到评标应对与质疑投诉救济，一条龙导航；格式对齐与合规正确一并交付。

## 核心优势
- **两法分轨（Step0 法域判定）**：动笔前先判定场景落在招投标法 / 政府采购法 / 双法叠加，术语、救济、规章各走各支，不张冠李戴。
- **三档安全护栏**：需人工确认 / 可自动生成 / 禁止（代决策、伪造佐证、打探评标专家），「决策留给人」。
- **深度节点 A · 一致性严格审查**：Step0 输入闸门 + 检索熔断 + 效力层级 + 独立第三方声明，已用真实项目端到端验证。
- **深度节点 B · 真实 docx 生成**：解析招标文件 → 同格式可编辑骨架，四套编号体系、H1–H5 全进目录、完整中文章号，工程链路经真实跑测。
- **评分建模**：客观/主观分区分、无偏离索引、佐证链目录，直击「凭什么得分」。

## 与知识库的深度联动（最大亮点）
本技能联动 IMA 招投标/政府采购系列知识库，让「格式正确」升级为「合规正确」：

| 联动知识库 | 在本技能中的作用 |
|---|---|
| 招标文件、采购文件汇集（7439473860155957） | 学习真实招标文件结构/格式/章节组织 |
| 招投标评标否决AI知识库（7460608999968055） | 识别否决雷区，反向规避格式/目录缺失导致的否决 |
| 招投标实务与合规（7463402595160740） | 招投标法域法条解释、合规红线 |
| 政府采购实务与合规（7463496212028405） | 政府采购法域合规/实务（补强分轨） |
| 招投标异议投诉处理（7480160395744474） | 招投标法域救济路径、时限、文书格式 |

- **效力层级**：用户招标文件 ＞ 投标文件/合同 ＞ 知识库，结论须可溯源。
- **按需检索、控成本**：仅在格式歧义或合规疑问时调用，不盲目全量。
- **防幻觉护栏**：知识库未命中明确标注「建议人工复核」。

## 使用示例（工程类招标 → 投标文件）

1. **上传招标文件** → Step0 判定为「依法必须招标工程」（招投标法域），解析出 scheme4 工程编号、实测页边距、章节列表。
2. **联动知识库（亮点）**：否决库判例要求连续页码目录页与独立签字页 → 骨架据此内置；实务库建议按「资格/商务/技术」分册；样本库验证章节属行业通行结构。
3. **确认章节与项目信息** → 用户确认。
4. **一键生成骨架** → 封面【正本】、连续页码目录、H1–H5 大纲、页脚、独立签字页。
5. **一致性审查** → 用深度节点 A 严格比对投标承诺与招标实质条款，输出红/黄/绿风险报告。
6. **你填充实质内容**。
