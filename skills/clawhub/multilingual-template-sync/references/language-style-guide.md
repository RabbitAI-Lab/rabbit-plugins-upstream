# Language Style Guide

## French (fr)

- Use formal "vous" register for all customer-facing copy.
- Greetings: "Bonjour" / "Bonjour à vous".
- Currency: use "€" after the amount with a non-breaking space (e.g., "50 €").
- Dates: DD/MM/YYYY format.
- Keep punctuation rules: non-breaking space before "!", "?", ":", ";".

## Korean (ko)

- Use 하십시오체 (formal polite ending -ㅂ니다/습니다) for all customer-facing copy.
- Greetings: "안녕하세요" / "안녕하십니까".
- Currency: "₩" before the amount (e.g., "₩50,000").
- Dates: YYYY년 MM월 DD일 format.
- Honorifics: use high honorifics (-시-) when referring to the customer's actions.

## General Rules

- Keep placeholders (e.g., `{name}`, `{order_id}`) untranslated.
- Preserve Markdown formatting and emoji.
- Match the tone of the source language—do not add or remove formality.
- For right-to-left languages (Arabic, Hebrew), ensure the template structure supports RTL markers.
