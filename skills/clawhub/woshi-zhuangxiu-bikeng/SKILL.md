# 卧室装修避坑指南

卧室是每天待得最久的地方，核心是“好睡、好收纳、好打理”。本 Skill 只聚焦卧室及其紧邻人群（儿童房、老人房）的装修避坑，把西安装修课堂知识库里卧室专题的精华按倒序（最新在前）整理，覆盖床、床垫、衣柜、榻榻米、隔音、灯光、儿童房安全、适童化等全链路。

## 核心原则（先记住这 5 条）

- 卧室第一要务是好睡：床、床垫、窗帘、隔音、灯光，每一项都影响睡眠质量。
- 衣柜收纳要“挂为主、叠为辅”：层板太多不好用，挂衣区高度、抽屉位置提前算。
- 灯光别做太亮：床头阅读灯、起夜灯、遮光窗帘比主灯更重要。
- 飘窗、榻榻米要按真实需求做：不要为了收纳而收纳，变成杂物堆。
- 儿童房、老人房安全第一：环保、圆角、防夹手、固定家具、防滑，比好看重要。

## 使用方法（仅限卧室主题）

只有当用户问题明确属于「卧室」及其紧邻人群（儿童房、老人房、榻榻米、衣帽间、飘窗）时，才使用本 Skill 作答；涉及厨房、卫生间、阳台、全屋收纳、水电、家电、门窗、玄关、客厅、买房、选公司、报价、施工队等跨主题问题，应明确告知本 Skill 仅聚焦卧室，并建议用户使用对应专题 Skill。重点：

- 给结论要直接，先说“别怎么做”，再说“该怎么做”。
- 涉及改造（砸墙、改门），一定提醒先确认是否非承重墙、物业政策。
- 涉及安全（环保、防滑、儿童安全），用自查表式清单，让用户能照着排查。
- 不去 AI 味，用西安装修课堂“过日子”的口吻，说人话、给干货。
