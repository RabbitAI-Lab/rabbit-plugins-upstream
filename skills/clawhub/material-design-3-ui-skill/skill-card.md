## Description:

Design, redesign, review, or implement user interfaces using Google Material Design 3 (M3), Material You, and optional Material 3 Expressive principles.

This skill is ready for commercial/non-commercial use.

## Publisher:

[skydashnet](https://clawhub.ai/user/skydashnet)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and product teams use this skill to design, implement, and review Material Design 3 interfaces, flows, and design systems. It helps agents produce accessible, adaptive specifications and implementation guidance grounded in semantic tokens and component behavior.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Remote installer shortcuts can execute downloaded code without a local review.

Mitigation: Review a local copy pinned to a specific commit before installation; avoid piping remote scripts directly to a shell or interpreter.

Risk: Force installation may overwrite local edits.

Mitigation: Back up local changes before using the force option.

Risk: Uninstalling removes this skill's copies across supported agent locations.

Mitigation: Check the affected installation locations and preserve any files needed before uninstalling.
