## Description:

Copywriting Master helps agents generate conversion-focused Chinese marketing copy for ecommerce pages, ads, community scripts, landing pages, email, headlines, and A/B testing ideas using common copywriting frameworks and templates.

This skill is ready for commercial/non-commercial use.

## Use Case:

External marketers, growth teams, founders, and agent users can use this skill to draft and adapt marketing copy across ecommerce, ads, social posts, email, landing pages, and community campaigns. It is intended for conversion-oriented copy generation and includes reminders to avoid illegal marketing uses and to review sensitive-industry claims.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security evidence says the skill requests command execution and file-writing authority that is broader than clearly needed for a markdown copywriting template library.

Mitigation: Install with constrained tool permissions where possible; require review before executing shell commands or creating or overwriting output files.

Risk: Marketing copy can contain sensitive or non-compliant claims, especially in regulated areas such as medical, financial, or education campaigns.

Mitigation: Review generated copy for legal, brand, and platform compliance before publication; use the skill's own guidance to flag risky wording and provide compliant alternatives.
