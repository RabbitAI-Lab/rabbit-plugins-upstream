## Description:

Generates a nested table of contents from headings in a Markdown document.

This skill is ready for commercial/non-commercial use.

## Publisher:

[hmahmadcs](https://clawhub.ai/user/hmahmadcs)

### License/Terms of Use:

MIT-0

## Use Case:

Users and teams working on long README files or design documents can preview a Markdown table of contents and choose whether to add it to the document.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The generated TOC is a preview, not a safe automatic replacement of an existing section.

Mitigation: Review the TOC and obtain confirmation before writing to an intended document.
