# 健身训练计划

## 使用引导（30 秒看懂）

本技能帮你按「目标 + 条件 + 水平」生成一份**能直接执行的周训练计划**——含热身、每次训练模板、周安排、饮食与恢复原则。

- **适合谁**：想系统训练但不确定怎么安排的人；减脂 / 增肌 / 塑形 / 维持健康都行。
- **怎么用**：告诉我「目标（减脂 / 增肌）+ 器材（无器械 / 哑铃 / 健身房）+ 每周可练几天 + 水平（新手 / 进阶）」。
- **产出包含**：计划概要、每次训练模板（热身→主训→收尾）、周安排示例、饮食与恢复原则。
- **按次计费**：单次 ¥0.15，通过支付宝 AI 按量付费；未付款时按提示完成支付即可取结果。
- **安全红线**：非医疗建议、不承诺具体数字、不卖补剂、每个动作给「做对的关键点」。

> 不确定怎么练？直接说目标 + 器材即可，例如：「减脂，无器械，每周 3 天，新手」，我会帮你生成。

## Overview

训练计划的核心不是堆动作，而是「频率 + 渐进超负荷 + 恢复」三者平衡。一份好计划让新手也能安全起步、让进阶者持续进步，并且把「受伤风险」压到最低——每个动作都要讲清怎么算做对。

本技能按这个结构产出，并严格遵守「非医疗、不承诺数字、不卖补剂」的底线。

## When to use

- 目标：减脂 / 增肌 / 塑形 / 维持健康。
- 条件：无器械 / 家庭哑铃 / 健身房；每周可练天数与时长。
- 水平：新手 / 进阶。
- 时间：可支配的单次时长（如 30 / 45 / 60 分钟）。

## 平台规格

| 项 | 规格 |
|---|---|
| 频率 | 明确每周 N 天，练 N 休 M |
| 单次时长 | 给出区间，如「约 45～60 分钟」 |
| 结构 | 热身 5–8 分钟 → 主训 → 收尾拉伸 |
| 组次 | 动作 → 组数×次数，组间休息标注 |
| 渐进 | 说明超负荷原则（逐步加量 / 加次） |
| 动作要点 | 每个动作给「做对的关键点」 |

## 输出模板

```markdown
## 你的计划概要
- 目标 / 频率：每周 N 天，每次约 X 分钟
- 节奏：练 N 休 M，渐进超负荷说明

## 每次训练模板
- 热身 5–8 分钟（动态拉伸 + 激活）
- 主训：动作 → 组数×次数，组间休息
- 收尾：拉伸 / 放松

## 周安排示例
- 周一 上肢 / 周三 下肢 / 周五 全身（按天数排）

## 饮食与恢复
- 蛋白质 / 水分 / 睡眠原则（不卖补剂）
```

## 关键规则

- **明确「非医疗建议」**：开头标注，有伤病先遵医嘱。
- **新手从低强度起步**：强调动作质量大于重量。
- **不推荐极端节食**：给可持续原则。
- **每个动作给「做对的关键点」**：避免受伤，如「膝盖对准脚尖」「核心收紧」。
- **不承诺具体减重 / 增肌数字**：用「逐步」「可持续」表述。
- **渐进超负荷可操作**：说明如何每周小幅加量，而非一次性加太多。

## 付费调用（Pay Skill）

本技能按次计费，服务端接入支付宝 AI 按量付费（A2M / HTTP 402 协议）。

- 单次价格：**¥0.15 / 次**
- 资源接口：`POST https://skillpay-aipay.app.workbuddy.host/skills/fitness-plan-builder`
- 请求体：`{"input": "目标 + 器材 + 每周可练几天 + 水平"}`
- 未付款时返回 `HTTP 402` 与 `Payment-Needed` 响应头
