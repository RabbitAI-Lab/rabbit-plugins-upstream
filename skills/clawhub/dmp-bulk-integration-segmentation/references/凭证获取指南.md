# 凭证获取指南（AK/SK）

使用本技能前，需先获取明日DMP OPEN API 凭证：Access Key（AK）与 Secret Key（SK）。

## 申请方式（二选一）

**方式一：邮件申请**
- 收件人：product@mingdata.com
- 邮件主题：【明日DMP API开通申请】
- 邮件内容：公司名称、联系人、联系方式、使用场景

**方式二：在线表单申请**
- https://doc.weixin.qq.com/forms/ANEAJwfLAAoADMAHwbhAPICNUE0vDRd8f#/fill

## 安全提示
- AK/SK 属于敏感信息，请勿泄露。
- 建议仅在受信环境中配置，避免在公共对话/公共屏幕明文展示。

## 凭证格式参考
- Access Key：通常为固定长度字符串
- Secret Key：通常为固定长度字符串
