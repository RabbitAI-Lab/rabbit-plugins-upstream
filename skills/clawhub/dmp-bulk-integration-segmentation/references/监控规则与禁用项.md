# 监控规则与禁用项（方案2：定时任务监控，按批量圈包口径）

本技能的监控用于：
- 在“同批串行创建完成”后，自动检查本批任务计算状态
- 本批全部成功后才进入下一批

## 1. 状态查询接口
- 查询接口：`/api/open-api/audience/manage/taskList`（POST）
- 入参：audienceIds（本批创建返回的 audienceId 列表）
- 状态：audienceStatus（0失败/1成功/2等待中/3计算中）

## 2. 定时任务监控（强制）

### 2.1 执行方式
- 使用平台提供的“定时任务工具”创建监控任务（每 60 秒触发一次）。
- 监控任务必须绑定到**当前会话**，并关闭外部投递（避免发消息到外部IM）。

### 2.2 禁用方式（强约束）
- **禁止**使用命令行方式创建定时任务（会导致会话绑定错误，监控无法自动触发）。

### 2.3 任务模板（示例）
> 说明：以下为“定时任务工具”的参数模板，具体字段名以你们平台实现为准，但必须满足：
> - 会话目标=当前会话
> - 投递=不投递

```json
{
  "name": "DMP任务状态监控-<project_id>",
  "schedule": {"kind": "every", "everyMs": 60000},
  "payload": {
    "kind": "agentTurn",
    "message": "检查DMP任务状态：projectId=<project_id>，audienceIds=<本批audienceId列表>。若本批全部成功则继续下一批；若失败按失败策略处理；全部批次完成后输出汇总并结束监控。"
  },
  "sessionTarget": "current",
  "delivery": {"mode": "none"}
}
```

## 3. 批间规则（必须遵守）
- 禁止在未完成上一批计算的情况下创建下一批
- 禁止同批并发创建（必须串行创建，逐个等待创建接口返回 audienceId）
