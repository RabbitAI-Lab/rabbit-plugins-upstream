# 交易动作模型

最终报告面向用户时只能输出下列交易动作。内部信号可以保留 `ADD`、`REDUCE_REVIEW`、`ROTATE_REVIEW` 等审计码，但不得作为主文案。

## 动作全集

| 类别 | 动作 | 金额字段 | 执行含义 |
|---|---|---|---|
| 买入 | 小额新增 | `buy_amount > 0` | 买入门禁通过，可提交 App 预填交易，仍需用户确认 |
| 买入 | 回落再买 | `buy_amount = 0` | 价格信号存在，但实时/夜盘偏热，今天不追，等回落后再确认 |
| 买入 | 禁止新增 | `buy_amount = 0` | 官方组合回撤、盘中执行回撤、资金、申购、数据或反证阻断新增 |
| 卖出/轮动 | 降低暴露 | `sell_amount > 0` | 风险或趋势转弱，形成明确调出草案 |
| 卖出/轮动 | 换出到强势方向 | `sell_amount > 0` | 当前方向弱，且有明确更强迁入方向 |
| 卖出/轮动 | 暂不调出 | `sell_amount = 0` | 有风险信号，但数据、成本、替代方向不足，今天不卖 |
| 防守配置 | 转入防守仓 | 组合层字段 | 牛市退潮或熊市模式下，卖出资金优先进入现金/货基/短债/纯债/黄金/红利低波观察，不强行买入权益 |
| 防守配置 | 现金等待 | 组合层字段 | 没有高置信迁入方向，资金不再追加权益，保留现金等待右侧 |
| 持有 | 持仓不动 | `buy_amount = sell_amount = 0` | 无可执行交易方案，今天不买不卖不换 |
| 持有 | 继续持有 | `buy_amount = sell_amount = 0` | 因子未触发交易，维持原仓位 |
| 持有 | 暂不卖出 | `sell_amount = 0` | 夜盘/实时修复降低卖出必要 |
| 风控 | 不追涨 | `buy_amount = 0` | 实时/夜盘涨幅偏高或拥挤，今天不追加 |
| 风控 | 只复盘 | `buy_amount = sell_amount = 0` | 关键数据、数据指纹、非交易日或 15:00 后交易窗口关闭，只给复盘，不给交易 |

交易窗口是最高优先级门禁。若 `execution.run_at >= 15:00`、`execution.is_trading_day=false` 或交易日状态不可确认，所有动作即使有价格信号也必须降级为 `只复盘`，`buy_amount=sell_amount=0`，说明“今天不提交交易，下一交易日重新确认”。已在 15:00 前由用户提交的在途交易，只能作为“交易后复盘”展示，不得继续生成当天补单。

## 必填字段

每只基金必须输出：

```json
{
  "trade_action": {
    "code": "BUY_SMALL | BUY_WAIT_PULLBACK | BUY_BLOCKED | REDUCE_EXPOSURE | ROTATE_OUT | ROTATE_WAIT_DATA | HOLD_STAY | HOLD_NO_SELL | NO_CHASE | REPLAY_ONLY",
    "label": "小额新增 | 回落再买 | 禁止新增 | 降低暴露 | 换出到强势方向 | 暂不调出 | 持仓不动 | 继续持有 | 暂不卖出 | 不追涨 | 只复盘",
    "category": "buy | sell | rotate | hold | wait | blocked",
    "buy_amount": 0,
    "sell_amount": 0,
    "net_amount": 0,
    "instruction": "今天如何执行",
    "reason": "为什么是这个动作"
  }
}
```

## 硬规则

- 不允许把“复核、观察、关注、看夜盘”作为最终动作。
- 没有明确金额时，不得输出“降低暴露”或“换出到强势方向”。
- 没有明确迁入方向时，不得输出“换出到强势方向”。
- 没有权益迁入方向时，不得为了显得有动作而强行推荐基金；应输出“现金等待”或“转入防守仓”。
- 宽基指数基金不是防守仓。沪深300、中证A500只能作为低 Beta 权益观察仓；熊市确认时也应降权。
- 卖出前必须完成防踏空审查：若卖出后某方向完全归零，必须写明重新进入条件；若只卖弱腿并保留强腿，写明这是战术降风险。
- 缺少逐日净值、BIAS20/MA、组合回撤或申购状态时，不得输出可执行买入。
- 盘中执行回撤估算接近或超过用户回撤阈值时，即使官方净值回撤尚未确认，也不得输出可执行买入；组合层动作改为现金等待或转防守。
- QDII 普通估值只解释官方/估算归属收益；今日执行只看 `get_night_estimate` 夜盘执行层。夜盘缺失、过期、覆盖率弱、汇率缺失或交易夜盘不匹配时，新增金额必须为 0。
- 所有交易动作都是草案，真实交易必须由用户在 App 确认。

`转入防守仓` 和 `现金等待` 是组合层/方向层动作，不能伪造成逐基金引擎 `trade_action.label`。报告可以在“组合建议/方向迁移”里写它们，但逐基金动作必须原样呈现引擎输出。

## 次日条件动作

收盘后、15:00 后或非交易日，只能输出次日条件动作，不得写成今天可执行。格式必须包含：

- `如果继续杀跌`：下一交易日优先降低哪些高风险方向。
- `如果弱反抽`：哪些不买回，哪些等待资金流确认。
- `如果强反包`：哪些卖出不追悔，哪些保留仓位参与，何时允许分批恢复。

条件动作不能绕过 `get_quant_strategy_context.execution`，下一交易日必须重新取数。
