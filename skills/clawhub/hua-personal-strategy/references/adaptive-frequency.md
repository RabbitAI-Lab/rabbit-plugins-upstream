# 自适应调仓频率策略

## 背景

2026-07-15 回测发现：被动月度再平衡（+36.7%）远优于信号引擎实际操作（-4.95%）。根因是固定频率信号在震荡市产生大量噪音交易。

## 核心思路

**波动率决定调仓频率，偏离度决定是否行动。**

不再每天给10只基金出信号，而是：
1. 先检测市场波动率 regime
2. 根据 regime 确定"多久看一次"和"偏离多少才动"
3. 偏离不到位 = 不出信号 = 不交易

## 波动率 Regime 划分

| Regime | 年化波动率 | 调仓频率 | 触发阈值（偏离MA20） | 单笔仓位上限 |
|--------|-----------|---------|---------------------|-------------|
| 低波动 | <15% | 月度 | >8% | 5-8% |
| 中波动 | 15-25% | 双周 | >5% | 3-5% |
| **中高波动** | **25-35%** | **每周** | **>3%** | **1-2%** |
| 高波动 | >35% | 周内多次 | >2% | 0.5-1% |

## 计算方法

### 1. 波动率计算
```
# 20日滚动年化波动率
daily_returns = [close[i]/close[i-1] - 1 for i in range(1, 21)]
ann_vol = std(daily_returns) * sqrt(252)
```

### 2. 偏离度计算
```
# 每只基金的 BIAS20
bias20 = (current_nav - MA20) / MA20 * 100%

# 沪深300 指数偏离
benchmark_bias = (current_index - MA20_index) / MA20_index * 100%
```

### 3. 信号门禁
```python
def should_emit_signal(regime, bias20):
    """根据 regime 和偏离度决定是否出信号"""
    thresholds = {
        'low': 8.0,      # 低波动：偏离>8%才动
        'medium': 5.0,   # 中波动：偏离>5%
        'medium_high': 3.0,  # 中高波动：偏离>3%
        'high': 2.0      # 高波动：偏离>2%
    }
    threshold = thresholds.get(regime, 5.0)
    return abs(bias20) >= threshold
```

## 与现有引擎的集成点

### 在 signal_rules.py 中
1. **新增 `volatility_regime` 检测层**：在信号生成前，先计算20日年化波动率，判断 regime
2. **修改信号触发条件**：当 `abs(bias20) < threshold` 时，直接返回 HOLD/只复盘，不进入后续信号逻辑
3. **调整仓位系数**：`MODE_COEFFICIENT` 根据 regime 动态调整

### 在报告输出中
1. 报告必须展示当前波动率 regime 和触发阈值
2. 当信号被 regime 门禁阻断时，报告写"波动率 regime 为 X，偏离不足 Y%，暂不操作"

## 回测验证

用 `run_portfolio_backtest` 对比以下策略：
1. **当前策略**：每日信号 + 固定阈值
2. **自适应策略**：波动率 regime + 偏离阈值
3. **被动策略**：月度再平衡

预期：自适应策略在波动率高时交易更频繁但仓位更小，在波动率低时交易更少但仓位更大，整体优于固定频率策略。

## 注意事项

- 波动率 regime 切换时不要立即调整，用 3-5 天确认期避免频繁切换
- 高波动 regime 下单笔仓位要小（0.5-1%），因为大波动 = 大风险
- 低波动 regime 下可以加大仓位（5-8%），因为小波动 = 低风险
- 这个策略的核心是**减少噪音交易**，不是增加交易
