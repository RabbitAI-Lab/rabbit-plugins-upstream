## Description:

Helps brand IP, virtual idol, short-drama, and fan-community operators turn fan-voted story ideas into vote branches, campaign assets, AI-HIVE generation commands, task records, and acceptance checks.

This skill is ready for commercial/non-commercial use.

## Use Case:

External creators, brand teams, short-drama operators, and fan-community managers use this skill to plan fan-vote co-created story campaigns, prepare scripts, prompts, storyboards, runnable commands, and review checklists, and submit AI-HIVE image or video generation only after reviewing inputs and cost-sensitive routing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: AI-HIVE generation can incur costs.

Mitigation: Review prompts, generation mode, routing, and any batch settings before running generate commands.

Risk: Reference images or videos may be uploaded to AI-HIVE.

Mitigation: Use only media the user is authorized to upload and avoid sending sensitive personal or proprietary material unless approved.

Risk: Initialization can store an API key locally.

Mitigation: Prefer environment variables where appropriate, keep local credential files private, and do not paste real API keys into chat, logs, screenshots, or committed files.
