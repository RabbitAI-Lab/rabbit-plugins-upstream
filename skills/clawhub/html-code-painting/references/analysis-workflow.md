# 观察分析工作流（analysis-workflow）

临摹或还原任何画作之前，必须按本流程完成系统性观察。目标：看懂一幅画是如何"被造出来"的，
而不是看到什么画什么。

## 一、五轮观察法（对参照图依次回答）

### 第 1 轮：构图与动线（眯眼整体看 30 秒）
- 画面长宽比是多少？（名画常为 3:2 / 4:3 / 1:1 / 手卷可达 20:1）
- 视觉重心落在哪？距左/右边界各约百分之几？
- 引导线是什么？（河流 S 形、山脊对角线、建筑透视线、人群视线方向）
- 用 5×5 网格覆盖画面，把每个主要对象的**所在格 + 起止比例**记下来。
  例："塔位于 (3,1)–(3,2) 格，宽约占画面 6%"——这一步是还原精度的骨架。

### 第 2 轮：色块归纳（想象把画压缩成 16×16 像素）
- 压缩后剩几个大色块？各自是什么颜色（写下 hex 猜测值）？
- 主色:辅色:点缀大致比例？（多数自然场景接近 60:30:10，日落可到 45:45:10）
- 整张画的**平均明度**偏亮/中/暗？平均饱和度偏高/中/低？

### 第 3 轮：光影
- 光从哪个方向来？正光/侧光/逆光/顶光？
- 最亮的三处在哪？最暗的三处在哪？
- 投影方向与长度？（投影长度≈物体高度×cot(太阳高度角)，侧光投影长、顶光短）
- 有没有大气透视？（远景对比度下降、色调向天色靠拢）

### 第 4 轮：笔触与质感
- 边缘软硬：哪些轮廓锐利（前景主体），哪些模糊（远景、水面）？
- 笔触方向是否跟随形体（沿山体走向皴擦/沿毛发方向扫笔）？
- 材质区分：金属/水/皮肤/布/树叶各自的反光特征如何区分？

### 第 5 轮：细节清单
列出 8–15 个"点睛细节"，按视觉中心→四周排序。例：
远山宝塔、水口瀑布、芦苇间的小舟、屋檐一角、飞鸟三两。
**还原度很大程度由这些小东西决定**——大色块像了但细节空了，观感就是"AI 图"；细节到位才是"画作"。

## 二、色彩提取实操

### 有脚本环境（推荐）
```bash
python analyze_reference.py painting.jpg --grid 4
```
输出九宫格平均色、全图暗部/亮部代表色、建议画布宽高比。

### 无脚本时的人工估色技巧
- 阴影不是黑色：先确定主光色，阴影 ≈ 主色的补色系 + 明度 -30%~-40%。
  例如阳光暖黄 (#F2D4A0) 的场景，阴影用蓝紫灰 (#6B6E93) 而非深灰。
- 高光不是白色：是光源色本身（夕阳高光=#FFD9A8，阴天高光=#EAEAEA）。
- 中间调用手指在脑中"调"：地面绿 ≠ 纯绿，土黄+墨绿的混合 (#7A7B4F) 才可信。

## 三、分层规划表

分析完成后填写此表，它就是代码里的图层顺序（自上而下 = 绘制顺序由后到前）：

```
L5 前景点睛  | 最前 | 树枝、人、船桨水纹   | 锐利边缘、最饱和
L4 中景主体  |      | 房屋、桥、人物群体    | 次级细节密度
L3 大地形    |      | 山体、树林剪影        | 边缘微糊、青灰偏色(大气透视)
L2 水面/地面 |      | 倒影(垂直翻转+波纹扰动)| soft-light/multiply
L1 天空氛围  | 最后 | 渐变+云形+光晕        | screen 混合的亮部
```

## 四、验证问题（每层完成时自问）

1. 这一层放到整幅里，明度关系对不对？（可以临时加 `filter: blur(4px)` 全图眯眼检查）
2. 远景是否比近景更接近天色？
3. 视觉中心是否比四周拥有 50% 以上的元素密度？
4. 把我的配色和原图并排，第一感觉是"同一张画的不同照片"，还是"两张不同的画"？
