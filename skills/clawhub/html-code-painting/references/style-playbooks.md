# 八大画种风格手册（style-playbooks）

每册包含：调色板 / 结构特征 / 笔触技法 / 完成判定标准。
作画时先选定画种，配色与技法**以此为准绳**，不得随性漂移。

---

## 1. 水墨山水（含青绿山水）

- **调色板**：墨阶五色 #1A1A1A(焦) #333(浓) #595959(重) #8C8C8C(淡) #C9C9C4(清)；
  纸底 #F2EEE3；青绿版加 石青 #3D6E8F、石绿 #6E8B5E、赭石 #96604A。
- **结构**：三远法——高远(仰视主峰)、深远(层叠纵深)、平远(横向铺陈)。
  近景坡石+树 → 中景水面留白 → 远山淡墨。**留白即云即水，占总面积 30–45%**。
- **笔触**：山用皴(斧劈/披麻，见 svg-techniques §3)；树先勾后点叶(胡椒点/介字点)；
  苔点聚散有致。线要有提按（stroke-width 渐变 path 或两笔叠压模拟）。
- **判定合格**：眯眼看全图是否"黑-灰-白"三段节奏分明；无留白=失败；
  墨色无浓淡变化=失败。

## 2. 青绿山水（《千里江山图》型手卷）

- **调色板**：头青 #2E6E8E、二青 #4A86A8、草绿 #7FA263、汁绿 #A8BC7A、
  赭石底 #8B5A3C、金泥点缀 #C8A24B。山脚暖、山头冷青，主峰最饱和。
- **结构**：长卷构图（推荐画布宽高比 ≥ 10:1），山势开合起伏 S 形推进，
  每 1000px 一个视觉高潮（主峰/水口/桥亭）。平坡—山体—水面三段循环。
- **笔触**：山体轮廓勾勒填色，内部留 20% 底色透出做旧绢感 (#E8DFC8)；
  水纹用细密平行弧线（间距 8–12px）。
- **判定合格**：整卷有至少 3 次"开合"节奏；绢黄底与青绿色相撞但和谐；
  细节密度手卷两端不塌方。

## 3. 印象派油画（莫奈/梵高向）

- **调色板**：不用纯黑纯白。阴影=钴蓝紫系 #4A5580/#5C6B8A，亮部=柠檬黄+橙 #F2C94C/#EF8354，
  天空蓝 #87A7C4，草地橄榄绿 #7C8C4F。
- **结构**：对角线构图多见；天空占 50–70%；物体边缘被光斑吞噬（形融法）。
- **笔触**：**短促并列笔触是灵魂**——同一区域 3–6 种邻近色小段 stroke 并置
  （Canvas 循环生成最有效率），方向顺形体转；绝不大面积平涂。
- **判定合格**：局部放大能看到杂色并置而不是单色块；整体退远色彩混合成立体感。

## 4. 浮世绘（葛饰北斋向）

- **调色板**：普鲁士蓝 #274B69/#3E6B8E 主导 + 米白 #EFE3C8 + 朱红点缀 #B5432E +
  芥末黄 #D9A64A。每个色块**纯色平涂，零渐变零纹理**。
- **结构**：大剪影层级分明（如巨浪框住富士山）；天空常有横向条带式渐变带
  （用 4–6 条阶梯色带模拟，不做平滑渐变）；前景物体可以极端巨大切断画面边框。
- **笔触**：轮廓线均匀深褐/深蓝粗线；浪花爪形曲线阵列。
- **判定合格**：任何两块相邻色都有清晰描边或形状分离；画面像木刻而非水彩。

## 5. 低多边形游戏风景（塞尔达/纪念碑谷向）

- **调色板**：单光源驱动——同对象受光面/背光面两色差 ΔL≈15%；
  全景主色不超过 5 个色相。示例草原：#88C070(受光草)/#5E9956(背光)/#EAB364(土路)/#77AEDD(天)/#F2E9DC(雾远景)。
- **结构**：几何化剪影：山=三角组，树=球+柱，云=扁平胶囊组合；圆角大于 0。
  中轴或三分构图。
- **笔触**：完全无纹理（可选一层极淡噪点防塑料感），阴影形状全部几何化锐利投影。
- **判定合格**：任意元素可数出"几个面"；投影方向全局一致；看起来"能玩"。

## 6. 扁平插画 / HUD 信息图风

- **调色板**：品牌双主色 + 2 辅助色 + 中性灰阶；明度至少拉开 4 档保证层次。
- **结构**：强网格对齐；元素几何规则化；常用 30° 视角等距(isometric)辅助表达体积。
- **笔触**：无缝隙平涂 + 圆角统一(4/8/16px 三档)；细节用"减号法"
  （挖透明洞）而非加线条。
- **判定合格**：删掉任何一个色都显脏 → 说明配比正确；图标级元素在 32px 下仍可辨识。

## 7. 夜景霓虹城市

- **调色板**：基底层低饱和蓝紫 #1A2038/#232B4A；霓虹点限 3 色 —— 品红 #FF3D8A /
  青 #29E6FF / 琥珀 #FFB13D。地面湿反光是必备(倒影 multiply+screen 叠)。
- **结构**：透视街景一点消失；招牌密度由近及远递减；天空几乎纯暗只留少量楼顶红点。
- **笔触**：辉光滤镜(svg-techniques §7)；文字招牌要真实字符不可乱码条；
  强光处核心白区占比 ~20%（不然像色卡不像灯）。
- **判定合格**：能感到"空气污染般的体积光"；三处以上冷暖对比不喧宾夺主。

## 8. 水彩插画

- **调色板**：透明感优先——所有颜色不透明度 60–85%，靠多层叠加成色；
  典型清新谱系:雾霾蓝 #A9C2CC、藕粉 #E8B4B8、鼠尾草绿 #A8B5A0、奶油黄 #F0DEA6。
- **结构**：大量留白(40%+)；湿边深、内部浅的单层"水印式"形体；
  构图轻松不对称。
- **笔触**：深色细勾线只用于眼点位(轮廓不需要闭合)；颜料沉淀颗粒可选加水彩滤镜。
- **判定合格**：颜色边界有水痕(深→浅→纸色)；没有一处 100% 实心死色。

## 通用完成清单（交付前最后一遍）

1. 五轮观察法里记录的细节清单完成了几条？（≥80%）
2. 有没有至少一个"人味"瑕疵点（倾斜的伞、歪的窗、一只孤鸟）让画面不像程序生成？
3. 缩到 25% 大小看整体 vs 放大到 200% 看质感，两者都成立才算完成。
