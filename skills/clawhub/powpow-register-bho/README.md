# powpow-register

PowPow बबल रजिस्ट्रेशन सहायक (OpenClaw संस्करण): नया उपयोगकर्ता के "बबल का होला" ना जाने से
"खाता एक्टिवेट, ठीक से इस्तेमाल कर सके ला" ले चहुँपावेला — उत्पाद परिचय (इंटरफेस स्क्रीनशॉट समेत), चरण-दर-चरण रजिस्ट्रेशन गाइड, गलती जाँच,
सबस्क्रिप्शन एक्टिवेशन के बिबरन।

पूरा गाइडेंस वाला skill, स्क्रिप्ट चाहे डिपेंडेंसी नइखे; सगरी रजिस्ट्रेशन काम उपयोगकर्ता ब्राउज़र/ऐप में करेला।

## इंस्टॉल

```
openclaw skills install @durenzidu/powpow-register
```

## काम

1. **उत्पाद परिचय**: ~120 शब्द के शुरुआत + GitHub सार्वजनिक रिपॉजिटरी में होस्टेड इंटरफेस स्क्रीनशॉट लिंक
   (नक्शा पेज, पोस्ट बिबरन पेज आदि 6 गो, परिस्थिति अनुसार 1–3 गो चुन क भेजीं)।
2. **रजिस्ट्रेशन गाइड**: फील्ड नियम (यूजरनेम/पासवर्ड/ईमेल कोड/फोन नंबर/प्रोफाइल फोटो), थर्ड-पार्टी लॉगिन
   (Google/Watcha/Huawei), रेट लिमिट पैरामीटर, सगरी प्लेटफॉर्म सोर्स कोड से लिहल गइल आ जगह लिखल बा।
3. **गलती जाँच**: कोड ना मिले, यूजरनेम/ईमेल लिहल गइल, 403 एक्टिवेट ना भइल, खाता लॉक आदि
   13 गो आम समस्या।
4. **सबस्क्रिप्शन एक्टिवेशन**: PayPal (वेब) / WeChat स्कैन (मैनुअल कन्फर्म) / Huawei IAP (HarmonyOS) तीन गो
   रस्ता के बिबरन आ जाँच; मौजूदा पेमेंट चेन सीधा फेरु से इस्तेमाल हो सकेला, skill सिर्फ रास्ता देखावेला।

## सुरक्षा

- कवनो सीक्रेट की नइखे; स्क्रिप्ट नइखे, उपयोगकर्ता के क्रेडेंशियल से छू नइखे।
- **कब्बो ना** उपयोगकर्ता के पासवर्ड, कोड चाहे पेमेंट क्रेडेंशियल माँगीं; रजिस्ट्रेशन आ पेमेंट सगरी प्लेटफॉर्म पेज पर पूरा होला।
