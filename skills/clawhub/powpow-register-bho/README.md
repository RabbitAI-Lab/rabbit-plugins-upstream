# powpow-register

PowPow बुलबुला रजिस्टर सहायक (OpenClaw संस्करण): एगो नया यूज़र के "बुलबुला का बा" से ले के "खाता चालू, एक क्लिक लॉगिन, अब खेलब" ले पहुँचावे — प्रोडक्ट परिचय (इंटरफेस स्क्रीनशॉट सहित), agent से रजिस्टर करवावल (प्रोफाइल फोटो अपलोड सहित), Alipay/PayPal सदस्यता ऑर्डर बनावल आ पैसा जमा देखरेख, दू लिंक से एक क्लिक लॉगिन, एरर पड़ताल।

**v2.0.0 से ई agent-सहायता मोड बा, आ v2.1.0 से PayPal भी संभालल जा सकत बा**: मुख्य स्क्रिप्ट `scripts/powpow-register.mjs` में कौनो डिपेंडेंसी नईखे (Node >= 18), यूज़र पूरा समय गप्पा से ना जुदाला, खाली दू बेर छोड़ के जाए पड़ला: ईमेल में सत्यापन कोड देखे, Alipay/PayPal कैशियर पर पैसा देवे। Node ना बा या यूज़र खुदे करे चाहला त, अपने-आप सिर्फ-निर्देश मोड में लौट जाला।

## इंस्टॉल

```
openclaw skills install @durenzidu/powpow-register
```

## फीचर

1. **प्रोडक्ट परिचय**: ~120 शब्द के शुरुआत + skill के साथे बंदल इंटरफेस स्क्रीनशॉट (`assets/screenshots/` में 6 गो: नक्शा पेज, पोस्ट डिटेल पेज वगैरह, हालत हिसाब से 1–3 गो चुन के भेजीं; बाहरी इमेज-होस्ट के जरूरत नईखे, ऑफलाइन भी चली)।
2. **करवावल रजिस्टर**: agent खुदे यूज़रनेम/निकनेम सुझावे, पासवर्ड दू में से चुनवावे (यूज़र देवे या agent बनावे), सत्यापन कोड भेजे आ रजिस्टर भेजे, प्रोफाइल फोटो सीधे अपलोड (≤5MB, SVG ना), आम एरर अपने-आप संभालल (लीन भइल/मेयाद निकलल/रेट-लिमिट)।
3. **एक क्लिक लॉगिन (दू लिंक)**: रजिस्टर सफल होत ही "आधा-लॉगिन" लिंक सीधे सदस्यता पेज पर; पैसा जमा भइला पर नवा लॉगिन हालत ले के पूरा मेंबर लिंक सीधे होमपेज पर (प्लेटफॉर्म के आधिकारिक `me?token=` पुल से, HttpOnly cookie अपने-आप लग जाला)।
4. **सदस्यता पेमेंट**: Alipay (मासिक ¥6.99 / त्रैमासिक ¥19.99 / वार्षिक ¥69.99, एक बेर के खरीद, अपने-आप रिन्यू नई) आ PayPal (Premium Monthly, करीब $1/महीना, अपने-आप रिन्यू, कबो भी रद्द) दुनो में agent ऑर्डर बनावेला + जमा देखरेख; WeChat QR/Huawei IAP खातिर रास्ता दिखावल।
5. **एरर पड़ताल**: कोड ना आवल, यूज़रनेम/ईमेल लीन भइल, 403 अन-एक्टिवेटेड, खाता लॉक वगैरह आम समस्या — सगरी प्लेटफॉर्म के सोर्स कोड से लिहल, जगह-जगह निशान लगावल बा।

## सुरक्षा

- **पासवर्ड** सिर्फ एनवायरनमेंट वेरिएबल से स्क्रिप्ट प्रोसेस में जाला, कभो कमांड-लाइन आर्ग्युमेंट में ना, डिस्क पर ना, स्टेट फाइल में ना; agent बनवल पासवर्ड यूज़र सांभरे खातिर खाली एक बेर देखावल जाला।
- **सत्यापन कोड** सिर्फ आधिकारिक रजिस्टर API खातिर बा, इस्तेमाल भइला पर छोड़ दिहल जाला; स्टेट फाइल (ईमेल/यूज़रनेम/token/ऑर्डर नंबर) सिस्टम के टेम्प डायरेक्टरी में रहेला, प्रक्रिया खतम होते `cleanup` एक क्लिक में साफ कर देला।
- **पेमेंट**: agent खाली ऑर्डर बनावे, कैशियर खोले, पैसा जमा पूछे करी; यूज़र के Alipay/PayPal खाता या पेमेंट क्रेडेंशियल कभो ना छुवे, कभो ऊसर से पैसा ना देवे। पैसा सदा यूज़र आ आधिकारिक कैशियर के बीचे दिहल जाला।
- सगरी रिक्वेस्ट सिर्फ आधिकारिक डोमेन `https://global.powpow.online` पर जाला; कौनो गोपन कुंजी नईखे।
