# 体检报告解读话术台（免费）

面向医疗健康从业者。把体检单上的箭头讲成人话，并整理出该问医生的问题。**永久免费，无需付费、无需授权（MIT-0）。**

## 功能说明

1. **输入即出方案**：你给报告中的异常项（项目名+数值+参考区间）、年龄性别、既往病史（可选），直接产出结构化结果，不需要先想清楚框架。
2. **解决的痛点**：体检报告满页箭头，普通人看不懂哪些要紧、哪些是生理波动，容易过度焦虑或直接忽略。
3. **产出内容**：①逐项通俗解释（这项是查什么的、偏离意味着什么趋势）②分级：建议尽快就医 / 复查观察 / 无需紧张 ③就医前准备（挂什么科、带上什么、问哪 3 个问题）④生活方式可调整项

## 适用场景

- 行业：医疗健康
- 典型任务：把体检单上的箭头讲成人话，并整理出该问医生的问题
- 适合人群：需要快速拿到可执行方案、又不想从零搭框架的一线从业者与个体经营者

## 不适用

**不做诊断、不给用药建议**；分级只按常见参考区间提示关注程度，最终以医生面诊为准；出现危急值会明确提示急诊。

## 使用方式

1. 一次性给出报告中的异常项（项目名+数值+参考区间）、年龄性别、既往病史（可选）（信息越具体，结果越可用）
2. 需要调整时，直接说「把第 2 条换成…」「再加一个…」，不必重新描述背景
3. 拿到结果后按「先做哪一项」排序执行；涉及金额、法律、医疗、安全的事项，按本文档的边界说明先做人工确认
