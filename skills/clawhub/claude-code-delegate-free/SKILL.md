# 代码委派基础版
## 能力简介
- 编程任务的委派与编排：接收自然语言描述的编程需求，转化为可执行的子任务序列
- 任务分类与简单分解：将复杂需求拆分为基础代码生成、代码补全、简单重构等可管理单元
- 基础代码生成与输出校验：根据子任务生成对应代码片段，并对输出做基础语法与格式校验
- 执行日志记录：记录每个子任务的执行状态与耗时，便于回溯问题
## 快速入门指南
1. 确认运行环境满足依赖说明中的要求
2. 在AI Agent对话中调用本技能,提供必要的输入参数
3. 检查输出结果,根据需要进行后续处理

> 详细的输入输出格式请参考下方章节说明。
## 场景介绍
| 场景 | 输入 | 输出 |
|---|---|---|
| 代码生成 | 自然语言描述的函数需求 | 对应语言的函数实现 |
| 代码补全 | 已有代码片段与补全意图 | 补全后的完整代码 |
| 简单重构 | 待重构代码与重构目标 | 重构后的代码 |
| 文档生成 | 代码文件路径 | 函数级注释或 API 文档 |

**不适用于**：需要跨多仓库深度分析、大规模批量改写、复杂架构决策的场景（请使用高级版）
## 使用指南
1. 接收用户的自然语言编程需求，明确目标语言与运行环境
2. 将需求分解为若干子任务，按依赖顺序排列
3. 依次执行子任务，生成代码片段并做基础语法校验
4. 汇总结果，输出完整代码与执行日志
5. 若执行中出现错误，按异常处理章节的指引重试或回退

### 功能边界条件

以下列出代码委派基础版技能的五个具体边界场景，以表格形式呈现。

| 边界条件 | 描述 | 例子 |
| --- | --- | --- |
| 无效任务描述 | 任务描述不清晰或不符合规范 | '请帮我写一个程序，但是我不知道要做什么' |
| 代码生成错误 | 生成代码不符合目标语言规范 | '生成一个Python函数，但是返回类型错误' |
| 输入格式错误 | 输入参数格式不正确 | 'target_language: java' |
| 超出处理能力 | 任务复杂度超出技能处理能力 | '生成一个复杂的机器学习模型代码' |
| 网络连接问题 | 网络连接不稳定或中断 | '技能无法连接到LLM API' |

## 核心特点
- **自动化执行**: 将编程任务委派给 AI
- **文件处理**: 支持多种文件格式的读取、解析和写入操作
- **API集成**: 通过标准化接口调用外部服务并处理响应
- **命令执行**: 在安全沙箱中执行系统命令并收集结果
