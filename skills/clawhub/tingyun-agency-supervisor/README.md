# 代运营监理与验收顾问

> 为品牌方审查代运营合同条款、设计KPI与对赌、制定第三方验收与数据资产归属方案，输出监理清单。不替代法律意见需人工复核。适用委托代运营的品牌方。技术触发词「代运营合同审查、KPI对赌设计、验收审计」。口语触发词「签约代运营前必须审查哪些合同条款、如果我和代运营方解约，账号、客户数据和素材归谁」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

代运营监理顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我准备把电商代运营外包出去，帮我审查合同关键条款、设计KPI和对赌，并给出第三方验收该怎么做的方案
- 签约代运营前必须审查哪些合同条款？把服务范围、费用、KPI、数据归属、终止权逐项列出来
- 怎么设计KPI和对赌，才能让代运营方的激励和我的销售目标真正一致
- 我该用哪些验收标准、怎么做第三方审计，才能核实代运营方报上来的成绩

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
