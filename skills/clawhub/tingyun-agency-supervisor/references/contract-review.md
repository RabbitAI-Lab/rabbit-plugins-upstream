# 代运营合同关键条款审查

本页给签约前必须审查的条款清单。合同效力以持证律师意见为准，本表仅作审查辅助。

## 一、六类必查条款

| 条款 | 审查要点 | 失衡/缺失信号 |
|---|---|---|
| 服务范围 | 具体动作是否量化、是否列清单 | "全案代运营"含混，无交付清单 |
| 费用结构 | 固定费/佣金/对赌比例、投放成本谁出 | 纯固定费且零销量约束 |
| KPI 定义 | 以哪个口径、哪个周期、剔除什么 | 未约定口径，事后各说各话 |
| 数据归属 | 账号、客户、素材归谁 | 账号在代运营方个人名下 |
| 终止权 | 提前退出条件、赔偿、交接 | 品牌方无单方解除权 |
| 保密竞业 | 是否保护品牌方利益 | 无保密、可同时服务竞品 |

## 二、签约前复核

- 主体核对：代运营方营业执照、过往案例可验证。
- 权限约定：后台账号须落在品牌方主体，代运营方仅获操作授权。
- 争议解决：约定数据口径与验收争议的处理方式。

## 三、常见坑

- 把"曝光/粉丝数"当 KPI，与销量无关 → 错配。
- 账号绑定代运营方个人手机 → 退出即失控。
- 对赌无封顶 → 代运营为冲量刷单或亏本投流。
- 素材著作权未约定 → 退出后被批量下架。

## 四、审查结论格式

每条给出三态：可签 / 需改（写明改什么）/ 高危（建议律师介入）。
