# KPI 对赌设计与第三方验收

## 一、KPI 设计原则（对齐激励）

代运营方收益应与其真正能影响的指标挂钩：

- 采用"基础服务费 + 阶梯佣金/对赌"，而非纯固定费。
- 目标设为"可归因"指标（如代运营负责的渠道 GMV），不拿品牌方整体盘子考核。
- 对赌设封顶与底线，避免为冲量造假或亏本投放。
- 周期与口径提前约定，验收时不再扯皮。

## 二、验收标准约定

验收前必须书面约定：

| 项 | 约定内容 |
|---|---|
| 数据来源 | 以平台后台导出为准，非截图 |
| 统计周期 | 自然月/活动期，明确起止 |
| 归因口径 | 哪类订单计入、退单如何剔除 |
| 剔除项 | 刷单、异常退款、内部单不计入 |

## 三、第三方审计方法

1. 独立拉取平台后台数据，与代运营方报告交叉核对。
2. 抽样订单溯源：订单号→支付→物流→退款，验证真实。
3. 投放花费凭证比对：广告后台花费 vs 代运营报账。
4. 异常筛查：退款率突高、同一设备多单、短时集中下单。

判断：凡代运营方只给"截图不给后台导出"的，标记为不可核，验收不通过。

## 四、虚报核查清单

- 数据好得偏离行业常态（如 ROI 异常高）。
- 退款率与行业相比偏低或突降。
- 关键节点才冲量、平时平淡。
- 拒绝提供后台导出权限。
