# 评审专家判例法指引（即时判定规则）

> 评审委员会（组长/成员）在评审环节遇到争议时的**即时判例法指引**。输入一个争议点，即时查询全国 5万+ 真实投诉处理决定中同类问题的财政部门判定规则，告知"若如此认定、未来被投诉后通常如何纠偏"，并提示是否启动澄清程序要求供应商提供客观佐证。

## 能做什么
- 把评审争议归一到标准类型：★条款/实质性参数认定、异常低价-成本认定、品牌认定-倾向性、评分争议、澄清边界。
- 从「政府采购投诉AI知识库」（5万+ 真实投诉处理决定）抽取**类案判定口径**——财政部门对同类问题如何认定（如"客观参数不得仅凭承诺函认定通过"）。
- 给出**未来被投诉风险等级**（高/中/低）+ 类案支撑。
- 给出**澄清/佐证决策提示**：是否启动澄清（87号令第51条）、澄清请求内容（要求厂家彩页/检测报告/成本构成说明）、留痕要求、红线（不得替供应商补材料）。

## 典型场景
> 专家争议："★脱水缸容量≥5L，供应商仅提供承诺函，能否认定通过？"
> 系统即时指引：
> - 判定口径：客观参数须以厂家彩页/检测报告/实物等客观材料认定，不得仅凭承诺函（87号令第51条澄清边界）。
> - 风险：高——若仅依承诺函认定通过，未来被投诉后财政部门通常要求提供厂家公开发布彩页或检测报告作事实审查依据，无客观佐证则认定可能被纠正。
> - 决策提示：启动澄清程序，要求供应商提供客观佐证；评审报告留痕。

## 核心纪律（为什么可信）
1. **类案非判例**：中国系成文法国家，类案仅作参考、非约束性先例。
2. **即时原则**：每次聚焦单一争议点，输出精简指引卡，不展开深度研究（除非要求扩展）。
3. **证据形式敏感（核心）**：客观事实类参数，供应商仅以书面承诺/自我声明响应，必须预警"不得仅凭承诺函认定通过"，提示启动澄清要客观佐证。
4. **答必有据**：判定口径/法条/类案编号均挂 KB 原文出处；检索无命中标【依据待核】。
5. **澄清边界**：指引须合法（87号令第51条），不得替供应商补材料、不得变相放宽。
6. **排除法规噪声与港澳台**：法规文档不计入判定口径；港澳台因法域不同排除。

## 知识库
- 政府采购投诉AI知识库（`7450416392468005`）：案例主源（5万+ 真实投诉处理决定）。
- 政府采购实务与合规（`7463496212028405`）：法条主源（87号/94号/财库2016-198/财库2026-2等标准条款解释）。

## 与家族技能的关系
- 本技能是**预防向（评审现场即时指引）**，与 `gp-complaint-winrate`（攻向·投诉胜诉率预判）、`gp-objection-caselaw`（守向·质疑答复类案智库）构成"攻-守-防"三脚架，共用同一案例库。

## 使用前提
- 知识库须已挂载并可检索；不可检索时整体降级为"依据待核"，不伪称查到口径。
- 本技能仅服务政府采购；工程招投标评审请使用对应技能。

## 安全护栏
- 不协助应回避不回避、纵容量身定制（萝卜坑）、串通、违规认定；澄清指引严守 87号令第51条边界。
