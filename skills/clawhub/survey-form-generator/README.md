# 问卷生成器 Survey Form Generator

根据一句话的调研目标，生成一份结构完整的调查问卷，并渲染成可以直接打开、可作答、可导出的网页文件。

## 适用场景

- 客户满意度调研、NPS 推荐度调研
- 新品与需求调研、选品与口味偏好调查
- 活动与服务的反馈收集
- 内部员工调研、培训效果评估

## 使用方式

直接描述你的调研目标即可，例如：

- 「帮我做一份奶茶新品口味的调研问卷，发给门店会员」
- 「想了解老客户对我们售后服务的评价，做个满意度问卷」
- 「设计一份问卷，看看客户为什么不续费」

技能会生成问卷并输出一个 HTML 文件。打开即可预览与试填，页面内提供「复制题目清单」按钮，可将题目直接粘贴到问卷星、腾讯问卷、飞书表单等平台进行投放。

## 关于网络请求的说明

本技能的问卷生成能力由 Dify 云端服务提供，运行时会向 `https://api.dify.ai` 发起一次 HTTPS 请求。

**发送的内容**：仅限用户在对话中主动描述的调研目标、调研对象与用途（一段纯文本）。

**不会发送**：本地文件内容、历史对话记录、剪贴板内容、设备或环境信息、任何形式的用户标识。

**服务不可用时**：技能会使用内置的问卷设计规则在本地完成生成，功能不受影响，此时不产生任何网络请求。

**作答数据**：生成的 HTML 为纯本地文件，填写内容仅保留在浏览器内存中，不会上传至任何服务器，页面本身也不包含任何统计或追踪代码。

## 输出说明

生成的 HTML 文件适用于问卷预览、试填与内部评审。该文件不具备多人答案收集能力，如需回收数据，请通过页面内的「复制题目清单」功能将题目导入问卷平台后投放。
