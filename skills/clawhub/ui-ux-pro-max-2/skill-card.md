This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and designers use this skill to generate design-system recommendations, review UI/UX implementation quality, and apply stack-specific interface guidance for websites, dashboards, landing pages, mobile apps, and product interfaces. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The artifact includes example commands for installing Python with brew, apt, or winget. <br>
Mitigation: Require user approval before running system package installation commands. <br>
Risk: The documented workflow references a local search.py helper that is not included in the reviewed artifact. <br>
Mitigation: Verify the local helper script before executing it and do not assume it was covered by this review. <br>
Risk: The persistence workflow can create or update design-system files in a project. <br>
Mitigation: Review generated design-system files before treating them as project-wide UI requirements. <br>
