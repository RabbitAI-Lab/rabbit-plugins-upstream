## Description: <br>
Helps API developers and backend or platform teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
API developers, backend teams, developer-experience teams, and maintainers use this skill to create, refine, and validate OpenAPI or Swagger documentation that makes REST APIs understandable and usable by other engineers. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad implicit-invocation wording may activate the skill during general API, backend, or documentation conversations. <br>
Mitigation: Narrow the trigger wording or disable implicit invocation when precise activation is required. <br>
