# 非诉业务实务指南

## 一、合同审查

### 审查流程
1. **主体审查**：核实当事人身份信息、资质证照、授权文件
2. **标的审查**：合同标的是否合法、确定、可能
3. **条款审查**：逐条审查权利义务条款
4. **风险审查**：识别合同风险点并提出修改建议
5. **形式审查**：签字盖章、日期、附件是否完备

### 合同审查清单

#### 主体条款
- [ ] 当事人名称/姓名是否与营业执照/身份证一致
- [ ] 统一社会信用代码/身份证号是否填写
- [ ] 法定代表人/授权代表信息是否准确
- [ ] 联系地址、电话是否有效
- [ ] 是否有签约授权（非法定代表人签字时）

#### 标的条款
- [ ] 标的物描述是否明确（名称、规格、型号、数量）
- [ ] 标的物是否合法（不违反法律禁止性规定）
- [ ] 是否附详细清单/技术规格书

#### 价格与支付条款
- [ ] 价格是否明确（含税/不含税）
- [ ] 币种是否明确
- [ ] 支付方式（银行转账/承兑汇票等）
- [ ] 支付节点（预付款/进度款/验收款/质保金）
- [ ] 发票类型及开具时间
- [ ] 逾期付款违约金条款

#### 交付条款
- [ ] 交付时间/期限
- [ ] 交付地点
- [ ] 交付方式
- [ ] 运输费用及风险负担
- [ ] 验收标准与验收程序
- [ ] 异议期约定

#### 权利义务条款
- [ ] 双方权利义务是否对等
- [ ] 是否存在不合理加重一方责任的条款
- [ ] 格式条款是否履行提示说明义务

#### 违约责任条款
- [ ] 违约情形是否明确
- [ ] 违约金比例是否合理（过高可能被调整）
- [ ] 损害赔偿范围是否明确
- [ ] 解除权行使条件

#### 争议解决条款
- [ ] 管辖法院约定是否有效（协议管辖）
- [ ] 仲裁条款是否有效（仲裁机构名称是否准确）
- [ ] 适用法律约定

#### 期限与终止条款
- [ ] 合同有效期
- [ ] 终止条件
- [ ] 解除条件及程序
- [ ] 合同终止后的后续义务

#### 其他条款
- [ ] 保密条款
- [ ] 知识产权条款
- [ ] 不可抗力条款
- [ ] 通知送达条款
- [ ] 合同变更条款
- [ ] 附件清单

### 常见合同类型审查要点

#### 买卖合同
- 标的物所有权转移时点
- 风险转移时点
- 质量标准与异议期
- 检验期间约定

#### 租赁合同
- 租赁物描述
- 租赁期限（不超过20年）
- 租金及调整机制
- 优先承租权/优先购买权
- 装修及恢复原状

#### 借款合同
- 借款金额与用途
- 利率约定（不超过LPR四倍）
- 还款方式与期限
- 担保方式
- 提前还款约定

#### 建设工程合同
- 工程范围
- 工期及延误责任
- 工程款支付节点
- 质量标准与保修期
- 竣工验收程序
- 工程结算

#### 房屋买卖合同
- 房屋基本信息（坐落、面积、性质）
- 产权状况（是否有抵押、查封）
- 成交价格及支付方式
- 过户时间及费用承担
- 交房时间及标准
- 户口迁出约定
- 违约责任

## 二、法律尽职调查

### 尽调流程
1. **确定尽调范围**：根据交易目的确定调查深度
2. **收集资料**：向目标公司发出资料清单
3. **审查分析**：逐项审查法律风险
4. **问题汇总**：编制问题清单
5. **出具报告**：撰写尽职调查报告

### 尽调内容清单

#### 公司基本信息
- 营业执照、章程
- 注册资本及实缴情况
- 股东结构及出资情况
- 公司历史沿革（设立、变更）
- 分支机构情况

#### 资产权产
- 不动产（土地使用权、房屋所有权）
- 知识产权（商标、专利、著作权、域名）
- 主要固定资产
- 资产抵押/质押情况

#### 合同与业务
- 重大合同清单
- 客户/供应商依赖性
- 关联交易
- 业务资质/许可

#### 劳动人事
- 员工人数及社保缴纳
- 劳动合同签订情况
- 历史劳动争议
- 高管/核心员工竞业限制

#### 诉讼仲裁
- 正在进行的诉讼/仲裁
- 历史诉讼记录
- 执行案件
- 行政处罚记录

#### 税务
- 税务登记
- 纳税情况
- 税务处罚
- 税收优惠依赖

#### 环保合规（如适用）
- 环评批复
- 排污许可
- 环保处罚

### 尽调报告结构
1. 尽调概述（范围、方法、限制）
2. 公司基本情况
3. 资产情况
4. 业务与合同
5. 劳动人事
6. 诉讼仲裁
7. 税务合规
8. 发现的问题与风险
9. 法律建议

## 四、律师函

### 律师函类型
1. 催款函
2. 催告函（要求履行合同义务）
3. 解除合同通知函
4. 禁止侵权警告函
5. 律师声明

### 律师函撰写要点
1. 事实陈述：客观、准确
2. 法律依据：引用具体法条（执行防虚构协议）
3. 要求事项：明确、具体、有期限
4. 法律后果：不履行的后果
5. 落款：律所名称、律师签名、日期

## 五、法律意见书

### 法律意见书结构
1. **首部**：致函对象、出具背景
2. **事实摘要**：简要陈述相关事实
3. **法律分析**：
   - 法律问题识别
   - 法条检索与适用（执行防虚构协议）
   - 涵摄分析
4. **法律结论**：明确回答法律问题
5. **建议**：操作建议和风险提示
6. **声明与限制**：意见书的假设条件和限制
7. **落款**：律所名称、律师签名、日期

### 法律意见书审查要点
- 事实是否准确完整
- 法条引用是否经过溯源验证
- 分析逻辑是否严密
- 结论是否明确
- 风险提示是否充分
- 是否有兜底声明
