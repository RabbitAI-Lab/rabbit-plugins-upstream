# 刑事法律实务指南

## 一、刑事诉讼程序要点

### 立案
1. 公安机关立案侦查
2. 检察院直接受理立案（贪污贿赂、渎职等）
3. 自诉案件（告诉才处理、被害人有证据的轻微刑事案件）

### 侦查
1. 强制措施：拘传、取保候审、监视居住、拘留、逮捕
2. 侦查期限：一般2个月，可延长
3. 律师介入：犯罪嫌疑人自被侦查机关第一次讯问或采取强制措施之日起，有权委托辩护人

### 审查起诉
1. 检察院审查起诉期限：1个月，可延长15日
2. 退回补充侦查：以2次为限，每次1个月
3. 认罪认罚从宽制度：犯罪嫌疑人自愿认罪的，可以依法从宽处理

### 一审
1. 公诉案件：检察院向法院提起公诉
2. 审限：受理后2个月内宣判，至迟不超过3个月
3. 简易程序：可能判处3年以下的，可适用简易程序
4. 速裁程序：可能判处3年以下，事实清楚，证据确实充分，被告人认罪认罚

### 二审
1. 上诉期限：判决10日，裁定5日
2. 全面审查原则
3. 上诉不加刑原则

### 审判监督程序（再审）
1. 当事人及其法定代理人、近亲属申诉
2. 法院/检察院自行发现

## 二、强制措施与取保候审

### 取保候审申请
**适用条件：**
1. 可能判处管制、拘役或独立适用附加刑
2. 可能判处有期徒刑以上刑罚，采取取保候审不致发生社会危险性
3. 患有严重疾病、生活不能自理，怀孕或正在哺乳自己婴儿的妇女
4. 羁押期限届满，案件尚未办结

**保证方式：**
1. 保证人保证
2. 保证金保证

**申请要点：**
1. 提交取保候审申请书
2. 提供社会危险性低的理由
3. 提供保证人或保证金
4. 提出保证义务承诺

### 羁押必要性审查
1. 申请主体：犯罪嫌疑人/被告人及其法定代理人、近亲属、辩护人
2. 审查主体：人民检察院
3. 申请时机：逮捕后随时可申请

## 三、常见罪名分析要点

### 侵犯公民人身权利罪

#### 故意伤害罪（第234条）
**构成要件：**
- 主体：已满16周岁（致人重伤/死亡的，已满14周岁）
- 客体：他人身体健康权
- 主观：故意（直接或间接）
- 客观：非法损害他人身体健康，造成轻伤以上后果

**伤害程度与量刑：**
- 轻伤：3年以下有期徒刑、拘役或管制
- 重伤：3年以上10年以下有期徒刑
- 致人死亡或以特别残忍手段致人重伤造成严重残疾：10年以上有期徒刑、无期徒刑或死刑

**辩护要点：**
1. 伤情鉴定异议（申请重新鉴定）
2. 正当防卫认定
3. 故意vs过失的区分（过失致人重伤罪）
4. 被害人过错
5. 民事赔偿达成和解
6. 认罪认罚

#### 故意杀人罪（第232条）
**量刑：** 死亡→死刑、无期徒刑或10年以上有期徒刑；情节较轻→3年以上10年以下

**辩护要点：**
1. 罪名定性（故意杀人vs故意伤害致死）
2. 自首/立功
3. 被害人过错
4. 精神状态鉴定
5. 防卫过当

###侵犯财产罪

#### 盗窃罪（第264条）
**立案标准：**
- 数额较大：1000-3000元以上（各省标准不同）
- 多次盗窃：2年内盗窃3次以上
- 入户盗窃、携带凶器盗窃、扒窃：无数额要求

**量刑：**
- 数额较大/多次/入户/携带凶器/扒窃：3年以下
- 数额巨大：3年以上10年以下
- 数额特别巨大：10年以上或无期

**辩护要点：**
1. 数额认定异议
2. 既遂vs未遂
3. 盗窃vs侵占（遗忘物）
4. 盗窃vs职务侵占
5. 退赃退赔
6. 初犯偶犯

#### 诈骗罪（第266条）
**立案标准：** 3000-10000元以上（各省标准不同）

**辩护要点：**
1. 诈骗vs民事欺诈的区分
2. 诈骗金额的认定
3. 共同犯罪中的地位（主犯vs从犯）
4. 退赃退赔

### 危害公共安全罪

#### 危险驾驶罪（第133条之一）
**情形：**
1. 醉驾：血液酒精含量≥80mg/100ml
2. 追逐竞驶，情节恶劣
3. 超员/超速
4. 违反危险化学品安全管理规定

**量刑：** 拘役，并处罚金

**辩护要点：**
1. 酒精含量鉴定异议
2. 是否有从重情节（事故、逃逸、抗拒检查）
3. 是否有从轻情节（自首、认罪认罚、赔偿）
4. 缓刑适用可能性

#### 交通肇事罪（第133条）
**立案标准：**
1. 死亡1人或重伤3人以上，负事故全部或主要责任
2. 死亡3人以上，负事故同等责任
3. 造成公共财产或他人财产直接损失，负全部或主要责任，无能力赔偿30万元以上
4. 酒后/吸毒后驾驶致1人以上重伤，负全部或主要责任

**量刑：**
- 基本档：3年以下有期徒刑或拘役
- 逃逸或其他特别恶劣情节：3年以上7年以下
- 因逃逸致人死亡：7年以上

### 贪污贿赂罪

#### 贪污罪（第382条）
**主体：** 国家工作人员
**立案标准：** 3万元以上

#### 受贿罪（第385条）
**主体：** 国家工作人员
**立案标准：** 3万元以上

**辩护要点：**
1. 主体身份认定（是否属于国家工作人员）
2. 是否利用职务便利
3. 收受财物与谋取利益的关系
4. 金额认定
5. 自首/立功
6. 退赃

## 四、量刑情节汇总

### 法定从轻/减轻情节
1. **自首**（第67条）：犯罪后自动投案，如实供述
2. **立功**（第68条）：揭发他人犯罪、提供重要线索
3. **从犯**（第27条）：在共同犯罪中起次要或辅助作用
4. **未遂**（第23条）：已经着手实行犯罪，由于意志以外的原因未得逞
5. **中止**（第24条）：在犯罪过程中自动放弃犯罪或自动有效防止犯罪结果发生
6. **防卫过当**（第20条第2款）
7. **避险过当**（第21条第2款）
8. **已满75周岁故意犯罪**（第17条之一）
9. **限制刑事责任能力人**（第18条第3款）
10. **又聋又哑的人或盲人犯罪**（第19条）

### 法定从重情节
1. **累犯**（第65条、第66条）
2. **教唆不满18周岁的人犯罪**（第29条）
3. **武装掩护走私**（第157条）

### 酌定情节
1. 认罪认罚
2. 退赃退赔
3. 被害人谅解
4. 初犯偶犯
5. 犯罪动机
6. 犯罪手段
7. 损害后果
8. 案发后的表现

## 五、刑事辩护策略

### 无罪辩护
1. 证据不足：证据链断裂、关键证据缺失
2. 不构成犯罪：行为不符合构成要件
3. 正当防卫/紧急避险
4. 未达到刑事责任年龄
5. 精神病鉴定

### 罪轻辩护
1. 定性辩护：此罪应为彼罪（如故意杀人→故意伤害致死）
2. 从轻减轻情节辩护
3. 量刑辩护：争取较轻刑罚

### 程序辩护
1. 非法证据排除
2. 管辖异议
3. 超期羁押
4. 侦查程序违法

### 认罪认罚从宽
1. 适用条件：自愿如实供述犯罪事实，真诚悔罪
2. 从宽幅度：一般可减少基准刑10%-30%
3. 量刑建议协商
4. 速裁程序/简易程序适用

## 六、刑事附带民事诉讼

### 提起条件
1. 被害人因犯罪行为遭受物质损失
2. 在刑事诉讼过程中提起

### 赔偿范围
1. 物质损失：医疗费、误工费、护理费等
2. 不包括精神损害抚慰金

### 调解
1. 附带民事诉讼可以调解
2. 被告人赔偿后可作为量刑从轻情节
