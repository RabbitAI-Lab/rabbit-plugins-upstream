# 法律思维分析框架

## 一、IRAC+中国实务改良版

### I — Issue（法律问题识别）

**问题识别方法：**
1. 从事实中提取法律关系
2. 确定争议焦点
3. 将争议焦点转化为法律问题

**常见法律问题类型：**
- 实体问题：权利义务是否存在、行为是否构成犯罪、责任如何承担
- 程序问题：管辖权、诉讼时效、举证责任
- 证据问题：证据是否充分、证据效力如何

**问题表述规范：**
"XX行为是否构成XX罪/是否应当承担XX责任"

### R — Rule（法律规则检索）

**检索步骤：**
1. 执行法律检索流程（流程A）
2. 执行案例检索流程（流程B）
3. 确定请求权基础（民事）或罪名构成要件（刑事）

**民事请求权基础检索顺序（重要）：**
1. 合同请求权（违约责任请求权、解除合同请求权）
2. 缔约过失请求权
3. 无因管理请求权
4. 物权请求权（返还原物、排除妨害、消除危险）
5. 不当得利请求权
6. 侵权请求权（一般侵权、特殊侵权）
7. 占有保护请求权

**刑事罪名构成要件检索：**
1. 四要件体系：犯罪主体、犯罪客体、主观方面、客观方面
2. 或三阶层体系：构成要件该当性、违法性、有责性
3. 确认是否有修正案修改
4. 确认相关司法解释的细化规定

### A — Application（涵摄分析）

**涵摄方法：**
将案件事实归入法律规则的构成要件，逐一分析是否符合。

**民事涵摄分析模板：**
```
构成要件1：XX（如：行为人实施了侵权行为）
- 事实：当事人XX做了XX
- 分析：该行为是否满足"侵权行为"的定义
- 结论：符合/不符合

构成要件2：XX（如：造成了损害后果）
- 事实：当事人遭受了XX损害
- 分析：损害是否可确认
- 结论：符合/不符合

...

综合结论：各要件是否全部满足
```

**刑事涵摄分析模板：**
```
主体要件：XX罪的主体要求
- 事实：被告人XX的身份/年龄/精神状态
- 分析：是否符合犯罪主体要求
- 结论：符合/不符合

主观要件：故意/过失
- 事实：被告人的行为表现/供述
- 分析：是否具有犯罪故意/过失
- 结论：符合/不符合

客观要件：实行行为+危害结果+因果关系
- 事实：被告人实施了XX行为，造成了XX结果
- 分析：行为与结果之间是否有因果关系
- 结论：符合/不符合

客体要件：是否侵犯了XX社会关系
- 分析：本案侵犯的客体
- 结论：符合/不符合

综合结论：是否构成XX罪
```

### C — Conclusion（结论与策略）

**结论要素：**
1. 法律问题回答
2. 胜败概率评估
3. 策略建议
4. 风险提示

## 二、民事案件分析框架

### 请求权基础分析
1. 识别可能适用的请求权基础
2. 按检索顺序逐一分析
3. 确定最优请求权基础
4. 分析请求权竞合时的选择策略

### 诉讼标的识别
1. 确认法律关系性质（合同/侵权/物权等）
2. 确认诉讼请求内容（确认/给付/变更）
3. 确认诉讼标的金额

### 管辖审查
1. 级别管辖：基层/中级/高级
2. 地域管辖：被告所在地/合同履行地/侵权行为地等
3. 专属管辖：不动产、港口作业等
4. 协议管辖：是否有管辖协议
5. 管辖异议风险

### 诉讼时效审查
1. 一般诉讼时效：3年（民法典第188条）
2. 特殊诉讼时效：国际货物买卖/技术进出口（4年）
3. 最长保护期：20年
4. 时效起算点：知道或应当知道权利受侵害之日
5. 时效中断/中止事由

### 常见民事案由分析要点

**工伤赔偿：**
- 工伤认定前置：是否已进行工伤认定
- 劳动能力鉴定：伤残等级鉴定
- 赔偿项目：医疗费、停工留薪期工资、伤残补助金、一次性工伤医疗补助金、一次性伤残就业补助金等
- 未缴社保的特殊处理：由用人单位承担全部赔偿责任
- 工伤与交通事故竞合：双赔规则

**交通事故人身损害：**
- 责任认定：交警事故认定书
- 赔偿项目：医疗费、误工费、护理费、交通费、住院伙食补助费、营养费、残疾赔偿金、精神损害抚慰金等
- 农村户口按城镇标准赔偿的条件
- 交强险与商业险的赔偿顺序

**民间借贷：**
- 借贷关系成立：借条/借款合同+款项交付凭证
- 利息约定：是否约定、是否超过法定上限
- 诉讼时效：从约定还款日起算
- 电子证据：微信转账、支付宝记录

## 三、刑事案件分析框架

### 罪名构成要件分析
1. 检索罪名法条（刑法分则条文）
2. 检索相关司法解释
3. 逐要件分析
4. 分析此罪与彼罪的区分

### 证据链条审查
1. 证据是否合法收集
2. 证据之间是否相互印证
3. 是否有合理怀疑未被排除
4. 证明标准是否达到"事实清楚，证据确实、充分"

### 量刑情节分析
**法定情节：**
- 从轻/减轻：自首、立功、从犯、未遂、中止
- 从重：累犯、前科
- 免除：犯罪情节轻微不需要判处刑罚

**酌定情节：**
- 认罪认罚
- 退赃退赔
- 被害人谅解
- 初犯偶犯
- 犯罪动机
- 损害后果

### 辩护策略选择
1. **无罪辩护**：证据不足/不构成犯罪/正当防卫/紧急避险
2. **罪轻辩护**：定性错误（此罪应为彼罪）、从轻减轻情节
3. **程序辩护**：非法证据排除、管辖异议、超期羁押
4. **量刑辩护**：聚焦量刑从轻减轻

### 常见罪名分析要点

**故意伤害罪：**
- 伤情鉴定：轻伤/重伤/轻微伤（决定罪与非罪）
- 故意vs过失的区分
- 正当防卫的认定
- 量刑：轻伤3年以下，重伤3-10年，致人死亡10年以上/无期/死刑

**盗窃罪：**
- 数额标准：数额较大/巨大/特别巨大（各省标准不同）
- 入户盗窃、携带凶器盗窃、扒窃（无数额要求）
- 既遂vs未遂
- 盗窃 vs 职务侵占 vs 侵占的区分

**危险驾驶罪：**
- 醉驾标准：血液酒精含量≥80mg/100ml
- 是否有从重情节（事故、逃逸、抗拒检查等）
- 认罪认罚从宽适用
