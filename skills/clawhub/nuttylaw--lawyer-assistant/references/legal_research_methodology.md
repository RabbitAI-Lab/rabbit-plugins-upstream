# 法律检索方法论

## 一、检索策略

### 关键词构建
1. **法律名称检索**：直接搜索"《中华人民共和国XX法》全文"
2. **主题检索**：组合关键词"法律主题+条款/规定/最新/现行有效"
3. **司法解释检索**："最高人民法院关于+主题+的解释/规定"
4. **地方性法规检索**："XX省/市+主题+条例/规定"

### 检索词优化技巧
- 添加"现行有效"过滤已废止法律
- 添加"最新"获取最新修正版本
- 使用法条引用格式"第X条"精确定位
- 添加"全文"获取完整条文

## 二、法律渊源体系

### 宪法
- 《中华人民共和国宪法》— 全国人民代表大会
- 宪法修正案

### 法律（全国人大及其常委会制定）
- 基本法律：民法典、刑法、刑事诉讼法、民事诉讼法、行政诉讼法等
- 非基本法律：劳动合同法、社会保险法、道路交通安全法等
- 法律修正案

### 司法解释
- 最高人民法院司法解释（法释〔YYYY〕X号）
- 最高人民检察院司法解释
- 两高联合司法解释

### 行政法规（国务院制定）
- 条例、规定、办法
- 注意区分行政法规与部门规章

### 地方性法规
- 省级人大及其常委会制定
- 设区的市级人大及其常委会制定
- 注意适用地域范围

### 部门规章
- 国务院各部委制定
- 效力低于法律和行政法规

### 规范性文件
- 各级行政机关发布的通知、意见、决定等
- 不属于正式法律渊源，但具有参考价值

## 三、民法典体系结构（重要参考）

《民法典》于2021年1月1日施行，替代了以下法律：
- 《婚姻法》《继承法》《民法通则》《收养法》《担保法》《合同法》《物权法》《侵权责任法》

民法典结构：
1. 总则编（第1-204条）
2. 物权编（第205-462条）
3. 合同编（第463-988条）
4. 人格权编（第989-1039条）
5. 婚姻家庭编（第1040-1118条）
6. 继承编（第1119-1163条）
7. 侵权责任编（第1164-1258条）

检索民法典条文时，注意确认是否经过修正（目前现行版本为2020年通过版）。

## 四、刑法体系要点

### 刑法修正案
《刑法》自1997年修订以来，已通过多个修正案（至2024年已有刑法修正案（十二））。检索刑法条文时，必须确认：
1. 当前条文是否经过修正案修改
2. 修正案的生效时间
3. 是否有溯及力问题

### 刑事司法解释
最高人民法院、最高人民检察院发布了大量刑事司法解释，对罪名认定、量刑标准有详细规定。检索时注意：
1. 司法解释的效力等同于法律适用解释
2. 司法解释之间可能有新旧替代关系
3. 注意"两高"联合发布的司法解释

## 五、检索结果验证清单

对每条检索结果，逐项确认：

- [ ] 法律名称是否完整准确
- [ ] 条款号是否正确
- [ ] 条文原文是否完整（未截断）
- [ ] 发布机关是否正确
- [ ] 施行日期是否正确
- [ ] 效力状态是否确认（现行有效/已废止/已修改）
- [ ] 是否为最新版本
- [ ] 检索来源URL是否记录
- [ ] 是否经过交叉验证（至少2个来源）

## 六、常见检索陷阱

1. **旧法新引**：引用已被替代的法律（如引用《合同法》而非《民法典》）
2. **条文错位**：法律修正后条文序号可能变化
3. **司法解释混淆**：同一主题可能有多个司法解释，注意适用哪个
4. **地方差异**：地方性法规仅在本行政区域内有效
5. **时间效力**：法律的时间效力问题（溯及力）
6. **特别法与一般法**：同一事项可能有多部法律调整，注意特别法优先原则
