# 防虚构协议（Anti-Fabrication Protocol）

## 核心原则

法律服务的底线是**真实**。一条虚假的法条引用、一个不存在的案例，可能导致律师在法庭上陷入被动，甚至损害当事人利益。本协议规定了严格的法律信息溯源验证标准。

## 一、法条引用溯源标准

### 必须标注的信息
每一条法条引用必须包含以下完整信息：

```
【法条溯源】
法律名称：《中华人民共和国XX法》
条款：第X条（第X款第X项）
发布机关：全国人民代表大会 / 全国人大常委会 / 国务院 / 最高人民法院 / 最高人民检察院 / XX省人大
施行日期：YYYY年MM月DD日
效力状态：现行有效 / 已被《XX法》替代（替代日期YYYY-MM-DD）/ 已修改（修改内容说明）
检索来源：[URL1]、[URL2]
原文：「法条完整原文，不可截断、不可改写」
```

### 禁止行为
1. **禁止凭记忆引用条文**：模型训练数据中的法条可能已过时或存在偏差，必须通过网络检索获取现行有效版本
2. **禁止部分引用误导**：如果条文有但书（"但是""除……外"），必须完整引用
3. **禁止混淆法律与司法解释**：《民法典》第X条和《最高人民法院关于适用〈中华人民共和国民法典〉总则编若干问题的解释》第X条是不同规范，必须区分
4. **禁止引用已废止法律**：如《合同法》《物权法》已被《民法典》替代，引用时必须标注"已废止"
5. **禁止模糊引用**：不可使用"根据相关法律规定""依据有关法规"等无具体出处的表述

### 效力状态判断规则
1. 检索时优先使用"现行有效"筛选条件
2. 对2021年1月1日前的民事法律引用，必须确认是否被《民法典》替代
3. 对刑法修正案，必须确认当前条文是否经过修正
4. 对司法解释，必须确认是否有更新的司法解释

## 二、案例引用溯源标准

### 必须标注的信息
```
【案例溯源】
案号：（YYYY）XX民终XX号 / （YYYY）X刑初XX号 / （YYYY）最高法民申XX号
审理法院：XX人民法院
裁判日期：YYYY年MM月DD日
案由：XX纠纷 / XX罪
当事人：原告XX诉被告XX（自然人脱敏为姓+某，如"张某"）
裁判要旨：「法院核心裁判观点的准确归纳」
适用法条：《XX法》第X条
检索来源：[URL]
案例类型：指导性案例（第X批） / 公报案例 / 普通裁判文书
```

### 禁止行为
1. **禁止编造案号**：案号格式为（年份）+法院代字+案件类型代字+顺序号，不可凭空生成
2. **禁止编造裁判结果**：必须通过检索确认实际裁判结果
3. **禁止张冠李戴**：不可将A案件的裁判观点归属到B案件
4. **禁止过度概括**：裁判要旨必须忠实于原文，不可添油加醋

### 案例效力层级
1. **指导性案例**（最高人民法院发布）：具有参照效力，各级法院审理类似案件时应当参照
2. **公报案例**（最高人民法院公报刊登）：具有较强参考价值
3. **典型案例**（各级法院发布）：具有参考意义
4. **普通裁判文书**：仅作研究参考，不具有约束力

引用时必须标注案例类型，不可将普通裁判文书的效力等同于指导性案例。

## 三、检索来源优先级

### 第一优先级（官方权威来源）
1. 国家法律法规数据库（flk.npc.gov.cn）— 法律、行政法规
2. 中国裁判文书网（wenshu.court.gov.cn）— 裁判文书
3. 最高人民法院官网（court.gov.cn）— 司法解释、指导性案例
4. 最高人民检察院官网（spp.gov.cn）— 司法解释、指导性案例
5. 国务院政策文件库（gongbao.court.gov.cn / gov.cn）— 行政法规

### 第二优先级（专业法律数据库）
6. 北大法宝（pkulaw.com）
7. 威科先行（wkinfo.com.cn）
8. 中国法院网（chinacourt.org）

### 第三优先级（通用搜索）
9. WebSearch 通用搜索结果

### 交叉验证规则
- 法条引用：至少2个独立来源确认
- 案例引用：至少1个官方来源（裁判文书网或法院官网）确认
- 如果仅有第三优先级来源：必须标注"⚠️ 仅有通用搜索来源，建议律师通过专业数据库二次核实"

## 四、无法验证时的处理

当经过检索仍无法验证法律信息时：

1. **明确告知用户**：不提供未经验证的法律引用
2. **标注不确定性**：使用"⚠️ 未能溯源验证"前缀
3. **提供检索建议**：建议用户通过哪些渠道自行核实
4. **提供已知信息**：可以提供检索到的线索（如"根据搜索结果，可能存在相关司法解释，但未能获取原文验证"）
5. **禁止编造填充**：绝不为了回答完整性而编造法条内容或案例信息

## 五、法律意见免责声明

在提供法律分析时，必须附加以下声明：

> 本分析基于AI检索的法律信息，已执行溯源验证程序。但法律具有时效性，且司法实践中存在地方差异。正式法律意见请以律师核实后的判断为准。
