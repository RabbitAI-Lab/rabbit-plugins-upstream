# 劳动争议专题实务指南

## 一、劳动争议处理程序

### 仲裁前置原则
劳动争议必须先经劳动仲裁，对仲裁裁决不服的才能向法院起诉（部分终局裁决除外）。

### 劳动争议范围
1. 因确认劳动关系发生的争议
2. 因订立、履行、变更、解除和终止劳动合同发生的争议
3. 因除名、辞退和辞职、离职发生的争议
4. 因工作时间、休息休假、社会保险、福利、培训及劳动保护发生的争议
5. 因劳动报酬、工伤医疗费、经济补偿或赔偿金等发生的争议
6. 法律法规规定的其他劳动争议

### 仲裁管辖
1. 劳动合同履行地
2. 用人单位所在地
3. 双方分别向上述两地申请仲裁的，由劳动合同履行地管辖

### 仲裁时效
1. **一般时效**：1年（从知道或应当知道权利被侵害之日起）
2. **劳动报酬争议**：劳动关系存续期间不受1年限制；劳动关系终止的，自终止之日起1年内提出
3. **时效中断**：主张权利、请求权利救济、对方同意履行义务
4. **时效中止**：不可抗力或其他正当理由

### 一裁终局案件
**适用条件**：追索劳动报酬、工伤医疗费、经济补偿或赔偿金，不超过当地月最低工资标准12个月金额的争议；因执行国家劳动标准在工作时间、休息休假、社会保险等方面发生的争议。

**效力**：
- 对劳动者不终局（劳动者可在15日内起诉）
- 对用人单位终局（仅可申请撤销，30日内向中院申请）

### 诉讼程序
1. 不服仲裁裁决的，15日内向法院起诉
2. 起诉状中可将仲裁请求列为诉讼请求
3. 注意：劳动争议案件受理费较低（10元/件，简易程序5元）

## 二、确认劳动关系

### 认定标准（劳社部发〔2005〕12号）
1. 用人单位和劳动者符合法律、法规规定的主体资格
2. 用人单位依法制定的各项劳动规章制度适用于劳动者，劳动者受用人单位的劳动管理，从事用人单位安排的有报酬的劳动
3. 劳动者提供的劳动是用人单位业务的组成部分

### 事实劳动关系认定要素
1. **人格从属性**：受用人单位管理、指挥、监督
2. **经济从属性**：由用人单位支付劳动报酬
3. **组织从属性**：纳入用人单位的组织体系

### 证据材料
1. 劳动合同（最直接证据）
2. 工资支付凭证或记录
3. 工作证、服务证
4. 考勤记录
5. 其他劳动者的证言
6. 工作服、门禁卡
7. 微信/钉钉/企业微信的工作沟通记录
8. 社保缴纳记录（注意：缴纳社保不等于必然存在劳动关系，但系重要参考）
9. 银行流水（工资发放记录）
10. 纳税记录（个税申报）

### 特殊情形

#### 劳务关系vs劳动关系
- 劳动关系：有从属性，受劳动法保护
- 劳务关系：平等主体之间的合同关系，受民法典调整
- 区分关键：是否有从属性（管理、指挥、监督）

#### 建筑施工中劳动关系
- 建筑公司将工程分包给不具备用工主体资格的组织或个人，该组织或个人招用的劳动者与建筑公司之间是否存在劳动关系：一般不认定劳动关系，但建筑公司承担用工主体责任（工伤保险责任）

#### 新就业形态
- 网约车司机、外卖骑手、网络主播等
- 根据实际用工特征判断：强从属性→劳动关系；弱从属性→民事关系
- 关注最高法及相关部委最新政策

## 三、劳动合同

### 劳动合同订立
1. 用工之日起1个月内订立书面劳动合同
2. 超过1个月不满1年未订立：支付双倍工资
3. 超过1年未订立：视为已订立无固定期限劳动合同

### 劳动合同类型
1. **固定期限劳动合同**
2. **无固定期限劳动合同**：
   - 劳动者在该用人单位连续工作满10年
   - 用人单位初次实行劳动合同制度或国企改制
   - 连续订立两次固定期限劳动合同后续订
4. **以完成一定工作任务为期限的劳动合同**

### 试用期
1. 合同期限3个月以上不满1年：试用期不超过1个月
2. 合同期限1年以上不满3年：试用期不超过2个月
3. 合同期限3年以上或无固定期限：试用期不超过6个月
4. 同一用人单位与同一劳动者只能约定一次试用期
5. 试用期工资不低于本单位相同岗位最低工资或合同约定工资的80%，且不低于最低工资标准

### 劳动合同解除

#### 协商解除
- 用人单位提出：支付经济补偿
- 劳动者提出：不支付经济补偿

#### 用人单位单方解除
1. **过失性解除**（第39条）：无需支付经济补偿
   - 在试用期间被证明不符合录用条件
   - 严重违反用人单位规章制度
   - 严重失职，营私舞弊，给用人单位造成重大损害
   - 同时与其他用人单位建立劳动关系，对完成本单位工作任务造成严重影响
   - 以欺诈、胁迫等手段订立合同致使合同无效
   - 被依法追究刑事责任

2. **非过失性解除**（第40条）：提前30日通知或支付代通知金，支付经济补偿
   - 患病或非因工负伤，医疗期满后不能从事原工作也不能从事另行安排的工作
   - 不能胜任工作，经过培训或调整岗位仍不能胜任
   - 客观情况发生重大变化，合同无法履行，协商不成

3. **经济性裁员**（第41条）：支付经济补偿
   - 依照企业破产法规定进行重整
   - 生产经营发生严重困难
   - 企业转产、重大技术革新或经营方式调整，经变更合同后仍需裁减人员
   - 其他因客观经济情况发生重大变化致使合同无法履行

#### 违法解除
- 用人单位违法解除：劳动者要求继续履行的应当继续履行；不要求继续履行或已不能继续履行的，支付赔偿金（经济补偿2倍）
- 劳动者违法解除：给用人单位造成损失的，承担赔偿责任

### 经济补偿计算
1. **计算标准**：工作年限×月平均工资
2. **年限**：每满1年支付1个月工资；6个月以上不满1年按1年计算；不满6个月支付半个月工资
3. **月平均工资**：解除/终止前12个月平均工资（税前）
4. **封顶**：月工资超过当地上年度职工月平均工资3倍的，按3倍计算，最高不超过12年
5. **赔偿金**：经济补偿×2

## 四、工资与工时争议

### 工资支付
1. 工资应当以法定货币支付，不得以实物及有价证券替代
2. 至少每月支付一次
3. 不得克扣或无故拖欠
4. 加班工资计算：
   - 工作日加班：150%
   - 休息日加班（不能补休）：200%
   - 法定休假日加班：300%

### 拖欠工资争议要点
1. 举证责任：用人单位保存2年工资支付记录
2. 劳动者主张拖欠工资的，需证明劳动关系和工资标准
3. 用人单位需证明已足额支付

### 工时制度
1. **标准工时制**：每日8小时，每周40小时
2. **综合计算工时制**：经审批，以周/月/季/年为周期综合计算
3. **不定时工时制**：经审批，不执行加班费规定

### 年休假
1. 工作满1年不满10年：5天
2. 工作满10年不满20年：10天
3. 工作满20年：15天
4. 未休年休假的，用人单位应支付300%工资（含正常工资）

## 五、社会保险争议

### 社保争议类型
1. 未办理社保登记
2. 未缴纳社保费用
3. 未足额缴纳社保费用
4. 社保待遇损失争议

### 司法实践要点
1. **征缴争议**：社保费的征缴属于行政范畴，一般不在劳动仲裁/法院受理范围
2. **待遇损失争议**：因用人单位未缴社保导致劳动者社保待遇损失的，可主张赔偿
   - 养老保险损失：无法补缴的，赔偿养老待遇损失
   - 医疗保险损失：报销医疗费用
   - 生育保险损失：生育医疗费和生育津贴
   - 失业保险损失：失业保险金
   - 工伤保险损失：按工伤保险条例标准承担全部赔偿责任

### 未缴社保的后果
1. 劳动者可据此解除劳动合同（第38条），并主张经济补偿
2. 行政责任：社保征收机构责令限期缴纳，加收滞纳金
3. 未缴社保期间的工伤：由用人单位按工伤保险条例标准承担全部赔偿

## 六、竞业限制与保密

### 竞业限制
1. 适用主体：高级管理人员、高级技术人员和其他负有保密义务的人员
2. 期限：不超过2年
3. 经济补偿：解除或终止劳动合同后支付
4. 违约责任：劳动者违反竞业限制的，支付违约金

### 保密义务
1. 商业秘密的范围界定
2. 保密期限
3. 违约责任

## 七、劳动争议仲裁实务

### 仲裁申请书要点
1. 申请人/被申请人信息
2. 仲裁请求（明确、具体、有金额）
3. 事实与理由
4. 证据清单

### 常见仲裁请求
1. 确认劳动关系
2. 支付拖欠工资
3. 支付加班费
4. 支付经济补偿/赔偿金
5. 支付未签书面劳动合同双倍工资差额
6. 赔偿社保待遇损失
7. 工伤赔偿（详见民事法律实务指南）

### 庭审要点
1. 举证：劳动关系存在、工资标准、拖欠金额、违法解除
2. 质证：对用人单位证据的真实性、合法性、关联性发表意见
3. 辩论：围绕争议焦点展开

### 调解策略
1. 评估案件胜败概率
2. 确定调解底线
3. 分期付款方案设计
4. 调解协议的可执行性（可申请法院司法确认）
