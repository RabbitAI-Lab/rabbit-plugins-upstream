# 强制执行专题实务指南

## 一、执行程序流程

### 执行立案
1. **申请条件**：
   - 法律文书已生效
   - 义务人未在期限内履行
   - 申请人在执行时效内（2年）提出申请
2. **提交材料**：
   - 强制执行申请书
   - 生效法律文书副本
   - 申请人身份证明
   - 被执行人财产线索
3. **立案期限**：法院7日内决定是否立案

### 执行措施
1. **查询**：向银行、不动产登记中心、车管所、证券登记机构查询财产
2. **冻结/查封**：冻结银行账户、查封房产/车辆
3. **划拨/扣押**：划拨存款、扣押动产
4. **拍卖/变卖**：对查封扣押财产进行司法拍卖
5. **提取**：提取被执行人的收入（租金、工资等）
6. **搜查**：对被执行人住所或财产隐匿地进行搜查

### 执行结案方式
1. 自动履行
2. 强制执行完毕
3. 达成执行和解
4. 终结本次执行程序（终本）
5. 终结执行
6. 不予执行

## 二、财产线索查找方法

### 银行存款
1. 通过法院网络查控系统查询
2. 申请律师调查令到银行查询
3. 从合同、发票、转账记录中获取账号信息

### 不动产
1. 不动产登记中心查询
2. 从抵押合同、租赁合同中获取房产信息
3. 实地走访被执行人住所/经营场所

### 车辆
1. 车管所查询
2. 小区物业/停车场排查
3. 保险公司查询投保信息

### 股权/投资
1. 国家企业信用信息公示系统查询
2. 申请调查令到市场监督管理局查询
3. 从工商档案中获取投资信息

### 应收账款/债权
1. 从合同中查找应收账款
2. 从财务报表中查找债权
3. 向被执行人的债务人了解

### 知识产权
1. 中国商标网查询商标
2. 国家知识产权局查询专利
3. 中国版权保护中心查询著作权

### 其他财产
1. 住房公积金
2. 养老保险金
3. 商业保险现金价值
4. 微信/支付宝账户余额
5. 信托产品
6. 第三方支付平台账户

### 财产查找策略
1. **先易后难**：先查银行存款（网络查控），再查不动产、车辆
2. **以点带面**：从一个线索扩展到其他财产
3. **关联人查询**：配偶、关联公司、合伙人
4. **生活轨迹追踪**：消费习惯、出行记录反映财产状况

## 三、执行异议

### 案外人执行异议
**适用情形**：案外人对执行标的主张所有权或其他足以排除执行的实体权利

**程序**：
1. 在执行程序终结前提出
2. 向执行法院提交书面异议
3. 法院15日内审查
4. 异议成立的，裁定中止对该标的的执行
5. 对裁定不服的，可在15日内提起执行异议之诉

### 当事人/利害关系人执行行为异议
**适用情形**：对执行措施、执行程序等执行行为不服

**程序**：
1. 向执行法院提出书面异议
2. 法院15日内审查
3. 对裁定不服的，10日内向上一级法院申请复议

### 执行异议之诉
1. **案外人执行异议之诉**：案外人对驳回异议裁定不服
2. **申请执行人执行异议之诉**：申请执行人对中止执行裁定不服

### 常见执行异议类型
- 所有权异议：主张对执行标的拥有所有权
- 共有权异议：主张对执行标的拥有共有权
- 租赁权异议：主张对执行标的拥有租赁权（买卖不破租赁）
- 期待权异议：主张对执行标的享有期待权（如期房买卖）

## 四、限制措施

### 限制高消费
**适用条件**：被执行人未按执行通知书指定的期间履行生效法律文书确定的给付义务

**限制内容**：
1. 乘坐飞机、高铁
2. 在星级以上酒店消费
3. 购买不动产
4. 租赁高档写字楼
5. 子女就读高收费私立学校
6. 支付高额保费购买保险理财产品
7. 其他非生活和工作必需的消费行为

### 纳入失信被执行人名单
**适用条件**：
1. 有履行能力而拒不履行
2. 以伪造证据、暴力、威胁等方法妨碍、抗拒执行
3. 以虚假诉讼、虚假仲裁等方式规避执行
4. 违反财产报告制度
5. 违反限制消费令
6. 无正当理由拒不履行执行和解协议

**后果**：
1. 社会公示
2. 信用惩戒（贷款、招投标、政府采购等）
3. 限制高消费
4. 限制出境

### 限制出境
**适用条件**：被执行人未履行生效法律文书确定的义务，且有出境可能

## 五、执行特殊情形

### 执行和解
1. 双方当事人自行达成和解协议
2. 和解协议应提交法院备案
3. 一方不履行和解协议的，可申请恢复执行原判决
4. 也可就和解协议另行起诉

### 执行担保
1. 被执行人提供财产担保或保证人担保
2. 法院可暂缓执行
3. 暂缓执行期限届满仍不履行的，可直接执行担保财产

### 执行转破产
**条件**：
1. 被执行人为企业法人
2. 不能清偿到期债务，且资产不足以清偿全部债务或明显缺乏清偿能力
3. 经申请执行人之一或被执行人同意

**程序**：
1. 执行法院征询当事人意见
2. 当事人同意的，移送有管辖权的法院进行破产审查
3. 破产立案后，执行程序中止

### 参与分配
**适用条件**：
1. 被执行人为公民或其他组织（非企业法人）
2. 被执行人的财产不能清偿所有债权
3. 其他债权人申请参与分配

**程序**：
1. 在被执行财产被执行完毕前提出申请
2. 按法定顺序分配

### 执行不能与终本
**终本条件**：
1. 已向被执行人发出执行通知
2. 已责令被执行人报告财产
3. 已通过网络查控和线下调查查找财产
4. 未发现可供执行财产或发现的财产不能处置
5. 自执行立案之日起已超过3个月

**终本后**：
1. 发现财产线索可申请恢复执行
2. 不受申请执行时效期间限制

## 六、执行策略

### 申请执行人策略
1. **财产线索前置**：在申请执行前尽可能收集财产线索
2. **保全与执行衔接**：诉讼中已保全的财产直接进入执行
3. **多措并举**：同时申请限制高消费、纳入失信名单
4. **律师调查令**：申请律师调查令查找财产
5. **悬赏执行**：申请发布悬赏公告查找财产线索
6. **追加被执行人**：在符合条件时追加股东、配偶等为被执行人

### 追加被执行人常见情形
1. **未足额出资股东**：公司财产不足以清偿债务，股东未足额出资
2. **抽逃出资股东**：股东抽逃出资
3. **一人公司财产混同**：一人有限责任公司的股东不能证明公司财产独立于自己财产
4. **分支机构**：法人分支机构被执行，法人本身可作为被执行人
5. **配偶**：执行依据明确为夫妻共同债务

### 被执行人应对策略
1. **执行异议**：对执行行为或执行标的提出异议
2. **执行和解**：与申请人协商达成分期履行方案
3. **财产申报**：如实申报财产
4. **解除限制**：履行义务后申请解除限制措施
5. **执行转破产**：资不抵债时考虑破产程序
