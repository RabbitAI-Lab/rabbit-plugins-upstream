# 视频人物参考卡

把已有、且用户确认可使用的角色资料，收束成一张可交给分镜、脚本或图像团队复用的中文人物约束卡。产出的是一致性文本素材，不生成图像，也不做通用提示词优化。

## 输入

请提供以下三项：

1. **授权角色参考图描述**：只写可确认的外貌、发型、体态、辨识物与材质；本地资料中的字段保留原值。
2. **故事**：人物身份、场景、情绪或剧情中的稳定定位。
3. **造型限制**：不可改变的服装、年代、色彩、妆容、禁用元素或拍摄边界。

如果三项任一缺失，先输出“资料缺失”，逐项说明缺什么、为什么会影响一致性，并只提出最少的补充问题。不得用常识补全人物细节。

## 工作流

1. 分开记录“已知事实”和“建议”。已知事实只能来自输入；建议必须标注为建议。
2. 提取跨镜头不变项：脸部轮廓、肤色表述、发型、体态、年龄段（仅当输入明确）、标志性配件与整体气质。
3. 写出服装基线：主服装、层次、颜色、面料、配饰与禁止变化；故事需要换装时，将换装列为“允许变体”，并说明保持不变的识别锚点。
4. 将故事动作转为可拍摄的动作范围：姿态、手部、视线、情绪强度与禁用动作；不要添加输入没有支持的武器、职业或身体特征。
5. 用下列卡片格式交付。短句优先，可直接复制到分镜文档。

## 交付格式

```markdown
# 人物参考卡｜<角色名或暂定代号>

## 使用范围
- 适用：<视频/故事场景>
- 资料状态：已根据用户授权描述整理；未核实项不作事实使用。

## 已知事实
- 外观：...
- 发型与体态：...
- 识别锚点：...
- 故事定位：...

## 服装基线
- 主造型：...
- 色彩与材质：...
- 必须保留：...
- 允许变体：...
- 禁止变化：...

## 动作与表演约束
- 可用动作：...
- 视线与姿态：...
- 情绪范围：...
- 禁用动作：...

## 跨镜头一致性检查
- [ ] 识别锚点仍可见或有合理替代
- [ ] 服装基线未被无说明地改动
- [ ] 动作未越过故事或造型限制

## 建议（非已知事实）
- ...
```

## 边界

- 只处理用户授权或可公开使用的角色资料。
- 不根据图片猜测敏感身份、健康状况或未明确的年龄等信息。
- 不生成、编辑或检索图像；若需要新图像，说明这超出本 Skill 范围。
- 不把建议写成事实，也不重复泛化的提示词优化。
