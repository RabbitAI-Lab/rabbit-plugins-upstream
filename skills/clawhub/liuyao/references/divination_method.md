# 起卦方法详解

## 一、真实起卦（推荐）

### 工具准备
- 三枚硬币（可用硬币代替，统一背面朝上）
- 安静环境，心无杂念

### 操作步骤

**第一步：集中意念**
心中默念所问之事，明确一个核心问题。

**第二步：掷币**
手捧硬币，掷币六次。

**第三步：记录**
从下往上记录爻象：

| 掷币结果 | 符号 | 含义 | 是否变动 |
|----------|------|------|----------|
| 三正面 | O | 老阳 | 变阴（--） |
| 三背面 | X | 老阴 | 变阳（—） |
| 两正一背 | — | 少阳 | 不变 |
| 两背一正 | -- | 少阴 | 不变 |

**第四步：排列成卦**
从上往下排列六爻，得到主卦；动爻变化后得到变卦。

### 记录示例

```
问事：这份工作适合我吗？

第1次（初爻）：两正一背 → —
第2次（二爻）：三正面   → O  ← 动
第3次（三爻）：两背一正 → --
第4次（四爻）：两正一背 → —
第5次（五爻）：三背面   → X  ← 动
第6次（上爻）：两正一背 → —

主卦（从上往下）：—  X  —  --  —  O
变卦（动爻变化）：—  —  --  --  —  --
```

## 三、起卦原则

| 原则 | 说明 |
|------|------|
| 一事一占 | 一个问题起一卦，不多事同问 |
| 心诚则灵 | 意念集中，问题明确 |
| 不疑不占 | 已有答案的问题无需再占 |
| 不再三占 | 同问题多次起卦，结果可能矛盾 |
| 静心后起 | 情绪激动、疲惫、酒后不宜起卦 |

## 四、常见问题

**Q：硬币哪面算正？**
A：硬币有字的一面为正面（数字面），背面为花或国徽面。也可以自己定义，只要统一即可。

**Q：掷币时手抖影响结果吗？**
A：不影响。掷币结果是物理随机，只要意念集中即可。

**Q：可以替别人起卦吗？**
A：可以，但必须知道对方所问何事，最好由对方亲自起卦。

**Q：静卦（无动爻）如何解？**
A：静卦无变化，事态维持现状，解卦重点在看世应关系和六亲配置。
