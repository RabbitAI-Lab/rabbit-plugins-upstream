- 位置：五爻（君位），为卦中最高贵的位置

⑥ **变卦参考**：三爻动→主卦家人变山火贲。贲卦有修饰、文采之意，对应面试的自我展示环节

**解卦判断**

- 用神居五爻君位，得天时地利
- 变卦贲卦，面试表现良好

**结论**：✅ 能获得此工作
**应期**：官鬼爻旺相且动在当月→一个月内；世应相生+日建扶助→近期应验

**后续验证**：一周后收到录用通知

## 六、案例学习要点

### 总结规律

| 情况 | 判断依据 |
|------|----------|
| 官鬼爻旺相 | 有利变动，如升职、考试 |
| 妻财爻旺相 | 财运亨通 |
| 官鬼爻休囚 | 不利变动 |
| 妻财爻受克 | 破财、亏损 |
| 动爻生用神 | 吉事可成 |
| 动爻克用神 | 凶事需防 |

### 常见应期

| 情况 | 通常应期 |
|------|----------|
| 旺相发动 | 当日或当月 |
| 休囚发动 | 数月后 |
| 冲合应期 | 逢冲或逢合之日 |
| 墓库 | 冲墓之日 |
