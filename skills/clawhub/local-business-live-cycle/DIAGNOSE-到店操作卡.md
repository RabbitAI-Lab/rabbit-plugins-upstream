## 🔍 第3步：判断 + 出方向

### 综合判断

| 维度 | ✔️ 好的信号 | ⚠️ 需要注意 |
|------|-----------|-----------|
| 老板意愿 | 愿意出镜 / 愿意试 | 怕上镜 / 觉得没用 |
| 店的条件 | 有位置播 / 有引流品 | 店太小 / 没有适合直播的品 |
| 基本准备 | 抖音号已开 / 会上架商品 | 啥都没弄 |
| 问题定位 | 知道问题在哪 | 完全没头绪 |

### 方案方向（根据判断勾选）

**如果店没问题、缺拉人：**
- [ ] 帮她开抖音来客/企业号
- [ ] 上架引流品（XX价格让她算成本）
- [ ] 设计开播时间（建议固定，比如每天下午4点发福袋）
- [ ] 给她写初版逐字稿（仿照 CASE-某奶站门店.md）
- [ ] 建议：先播3场再说，不用想太多

**如果店也有问题：**
- [ ] 先解决承接能力（出餐流程/人力安排）
- [ ] 再想直播的事

**如果老板不出镜：**
- [ ] 考虑拍烤鸭制作过程的短视频代替直播
- [ ] 或者找店员出镜

## 📝 备用速查

### 没有直播过的商家，核心卡点通常就3个：

| 卡点 | 一句话化解 |
|------|----------|
| "不知道播什么" | 不用想内容，就做一件事：发福袋→喊人进店 |
| "怕没人看" | 先发福袋，福袋抽着的时候人是不会走的 |
| "觉得没用" | 你现在的客人怎么来的？多一个渠道就多一批人 |

### 最低启动方案（什么都不用准备的版本）

```
① 打开抖音 → 点底部"+" → 选"直播"
② 手机架在烤鸭操作台前（背景露出烤鸭）
③ 发福袋（10个鸭翅/10个鸭头免费抽）
④ 说一句话循环："XX的邻居们，今天我直播发福利"
⑤ 等5分钟，开始说："9.9半只烤鸭，拍了来店里拿"
⑥ 30分钟下播

不需要贴片、不需要暖场、不需要话术
先播了再说
```
