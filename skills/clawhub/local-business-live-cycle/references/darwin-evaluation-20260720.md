# Darwin 评估发现（2026-07-20）

Darwin Skill 2.0 对 local-business-live-cycle v2.1.0 的独立评估，基于 3 个测试 prompt 的子 agent 实测。

## 测试 Prompt

| ID | Prompt | 期望 |
|----|--------|------|
| 1 | 帮我诊断门店 | 引导20道题，出诊断报告 |
| 2 | 写一条口播视频，我是开火锅店的 | 出带Hook+5铁律的稿子 |
| 3 | 复盘昨天那场直播，卖了8单，场观300 | 按复盘框架分析 |

## 评分

| Prompt | 分数 | 核心问题 |
|--------|------|---------|
| 1（诊断） | 9/10 | ✅ 最成熟的部分，20题+扣分制+fallback |
| 2（写视频） | 7/10 | ⚠️ 与诊断耦合过紧，缺少「跳过诊断直接写」分支 |
| 3（复盘） | 6/10 | ⚠️ 两个复盘框架混淆（六部曲 vs T+3d闭环） |

## 3个发现 + 修复方案

### 发现1：两个复盘框架冲突（🔴 P0）
第三章「六部曲」和第六章「内容迭代闭环」是两套复盘逻辑。用户说「复盘」时AI不知道该走哪个。
**修复：** 加了入口选择「复盘直播」/「复盘视频」，AI自动判断。

### 发现2：写视频与诊断耦合过紧（🟡 P1）
写视频 Step 1 要求「与诊断结果联动」，但用户可能只想写视频不想做20题诊断。
**修复：** 支持 `先诊断再写视频` 和 `直接写，不用诊断` 两种模式。

### 发现3：异常处理覆盖不全（🟡 P1）
Fallback 只覆盖诊断场景，写视频和复盘场景没有。
**修复：** 新增口播文案 fallback 表（5种场景：不知道拍什么/太长/价格不对/不会拍/盲预测）。

## 已应用版本

v2.1.1（以上3个修复全部合并发布）
