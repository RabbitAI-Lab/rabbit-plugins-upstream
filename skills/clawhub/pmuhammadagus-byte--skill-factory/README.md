# Skill Factory for OpenClaw

Skill meta-level yang mengubah agent menjadi **Skill Architect** — mampu merancang, membangun, dan mengirim skill legendary-tier dari nol.

## Konsep

Skill Factory adalah **"skill compiler"** — mengambil deskripsi domain dan mengeluarkan skill package yang lengkap, terstruktur, dan siap produksi.

## Instalasi

### OpenClaw Lokal
```bash
cp -r skill-factory ~/.openclaw/skills/
```

### Kimi Claw (Browser)
1. Buka Kimi Claw → Skill Workshop
2. Upload folder `skill-factory`
3. Aktifkan skill

## Cara Penggunaan

Setelah aktif, minta agent membuat skill apa pun:

```
"Buatkan skill untuk data analysis"
"Buatkan skill untuk social media management"
"Buatkan skill untuk project management"
"Buatkan skill untuk creative design"
"Buatkan skill untuk customer support"
```

Agent akan otomatis menjalankan **7 Fase Protokol**:

## 7 Fase Protokol Pembuatan Skill

### Fase 1: Needs Analysis
→ Domain deep dive
→ User persona mapping (Novice, Competent, Expert)
→ Success criteria definition
→ Skill lifecycle mapping

### Fase 2: Architecture Design
→ Skill structure blueprint
→ Component relationship map
→ Reasoning engine design
→ Output system design

### Fase 3: Core Building
→ Write SKILL.md (the brain)
→ Define purpose, triggers, directives
→ Install reasoning protocols
→ Set quality standards

### Fase 4: Reference Building
→ Frameworks (proven methods)
→ Patterns (recurring structures)
→ Standards (quality benchmarks)
→ Examples (case studies)
→ Advanced (expert techniques)

### Fase 5: Template Building
→ Quick-start (for novices)
→ Standard (for competent)
→ Advanced (for experts)
→ Checklist (quality assurance)

### Fase 6: Quality Assurance
→ 10-dimension audit
→ Stress testing (edge cases, ambiguity, integration)
→ Novice & expert testing
→ Polish to legendary tier

### Fase 7: Packaging & Delivery
→ Structure skill folder
→ Write README.md
→ Create installation guide
→ Document known limitations

## 12 Komponen Skill Legendary

Setiap skill yang dihasilkan memiliki:
1. **Crystal-clear Purpose** — Tujuan spesifik dan memukau
2. **Trigger Intelligence** — Aktivasi yang tepat sasaran
3. **Reasoning Architecture** — Berpikir multi-lapisan
4. **Framework Library** — Koleksi metode terbukti
5. **Output Specifications** — Standar yang terukur
6. **Edge Case Protocols** — Penanganan error graceful
7. **Context Management** — Manajemen konteks cerdas
8. **Tool Mastery** — Penggunaan tool yang surgical
9. **Voice & Persona** — Suara yang konsisten dan berkarakter
10. **Reference Architecture** — Referensi yang komprehensif
11. **Template System** — Template siap pakai untuk semua level
12. **Self-Improvement Loop** — Mempelajari dari setiap interaksi

## 8 Design Patterns

Skill Factory menerapkan pola desain berulang:
1. **Protocol Pattern** — Protokol konsisten sebelum eksekusi
2. **Framework Selection Pattern** — Pilih framework berdasarkan konteks
3. **Quality Gate Pattern** — Verifikasi sebelum pengiriman
4. **Fallback Chain Pattern** — Rantai fallback untuk error handling
5. **Progressive Disclosure Pattern** — Pengungkapan bertahap
6. **Multi-Persona Pattern** — Melayani semua level pengguna
7. **Confidence Calibration Pattern** — Kalibrasi kepercayaan
8. **Self-Correction Pattern** — Koreksi diri berkelanjutan

## 10-Dimension Quality Audit

Setiap skill di-audit pada 10 dimensi:
1. Purpose Clarity
2. Reasoning Depth
3. Framework Richness
4. Output Quality
5. Edge Case Handling
6. Context Awareness
7. Tool Integration
8. Voice & Persona
9. Reference Quality

**Target: 85+ untuk elite, 95+ untuk legendary**

## Catatan

- Skill ini bekerja sebagai **meta-skill** — ia membuat skill lain
- Setiap skill yang dihasilkan adalah **standalone** dan bisa langsung digunakan
- Proses pembuatan mengikuti **standar industri** untuk skill design
- Open Source — bebas dimodifikasi dan didistribusikan
