# Common Pitfalls in Skill Building

> Mistakes that destroy skill quality. Avoid at all costs.

---

## Pitfall 1: The Vague Purpose
```
SYMPTOM: "This skill helps with X"
PROBLEM: Doesn't specify when, why, or how
FIX: "This skill transforms agents into [role] producing [output] 
      using [method]. Activate when: [specific conditions]"
```

## Pitfall 2: The Missing Trigger
```
SYMPTOM: Skill activates for wrong tasks or misses right ones
PROBLEM: No clear activation conditions
FIX: Define explicit triggers AND anti-triggers
```

## Pitfall 3: The Shallow Reasoning
```
SYMPTOM: "Just do X, then Y, then Z"
PROBLEM: No thinking, just following steps
FIX: Add analysis, framework selection, verification, review
```

## Pitfall 4: The Framework Famine
```
SYMPTOM: Only one framework for all situations
PROBLEM: One-size-fits-all doesn't fit anything well
FIX: Build a library with selection logic
```

## Pitfall 5: The Quality Void
```
SYMPTOM: No definition of "good" output
PROBLEM: Inconsistent, unpredictable quality
FIX: Define minimum, excellent, and legendary bars
```

## Pitfall 6: The Error Blindness
```
SYMPTOM: "Use this tool" with no error handling
PROBLEM: Crashes when anything goes wrong
FIX: Add fallback chains, graceful degradation
```

## Pitfall 7: The Context Amnesia
```
SYMPTOM: Forgets user preferences, repeats questions
PROBLEM: No context management
FIX: Track state, remember preferences, compress old context
```

## Pitfall 8: The Generic Voice
```
SYMPTOM: Sounds like every other AI
PROBLEM: No distinctive personality
FIX: Define voice, tone, signature phrases, forbidden patterns
```

## Pitfall 9: The Reference Dump
```
SYMPTOM: References are just lists with no organization
PROBLEM: Hard to find, hard to use
FIX: Organize by purpose, add cross-references, include examples
```

## Pitfall 10: The Template Desert
```
SYMPTOM: No templates, users start from scratch
PROBLEM: High barrier to entry, inconsistent output
FIX: Create quick-start, standard, and advanced templates
```

## Pitfall 11: The Novice Exclusion
```
SYMPTOM: Only serves experts
PROBLEM: Beginners can't use it
FIX: Design for all 6 stages: Novice to Legendary
```

## Pitfall 12: The Expert Boredom
```
SYMPTOM: Only serves beginners
PROBLEM: Experts outgrow it quickly
FIX: Include advanced techniques, customization, innovation triggers
```

## Pitfall 13: The Static Skill
```
SYMPTOM: Never improves, never learns
PROBLEM: Becomes outdated, misses opportunities
FIX: Build in feedback integration, versioning, improvement loops
```

## Pitfall 14: The Over-Engineering
```
SYMPTOM: Too complex, too many components
PROBLEM: Hard to maintain, hard to use
FIX: Start simple, add complexity only where needed
```

## Pitfall 15: The Under-Engineering
```
SYMPTOM: Too simple, misses critical aspects
PROBLEM: Doesn't deliver value
FIX: Cover the full domain, handle edge cases
```
