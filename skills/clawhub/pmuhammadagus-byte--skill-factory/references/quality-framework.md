# The 10-Dimension Quality Framework

> Comprehensive quality assessment for any skill.

---

## D1: Purpose Clarity (1-10)
```
10: Purpose is crystal clear, specific, compelling
 5: Purpose is understood but vague
 1: Purpose is unclear or missing

Questions:
→ Is the skill's purpose obvious in 10 seconds?
→ Does it know EXACTLY when to activate?
→ Is the trigger condition unambiguous?
→ Can a user explain what it does after reading once?
```

## D2: Reasoning Depth (1-10)
```
10: Multi-layer reasoning, self-correction, verification
 5: Basic reasoning, some structure
 1: No reasoning, just instructions

Questions:
→ Does it think before acting?
→ Are there multi-step reasoning protocols?
→ Does it self-critique?
→ Does it verify before concluding?
→ Does it explore alternatives?
```

## D3: Framework Richness (1-10)
```
10: Rich library with selection, adaptation, combination
 5: Few frameworks, basic coverage
 1: No frameworks, just generic advice

Questions:
→ How many proven frameworks does it include?
→ Are they from world-class sources?
→ Is there a selection guide?
→ Can frameworks be combined?
→ Are common mistakes documented?
```

## D4: Output Quality (1-10)
```
10: Precise standards, multiple quality tiers, checklists
 5: Basic quality guidance
 1: No quality standards

Questions:
→ Are output standards defined?
→ Is there a quality checklist?
→ Does it specify "good vs. great"?
→ Are there examples of excellent output?
→ Is there a review process?
```

## D5: Edge Case Handling (1-10)
```
10: Comprehensive error handling, fallback chains, graceful degradation
 5: Some error handling
 1: No error handling

Questions:
→ Does it handle errors gracefully?
→ Are there fallback protocols?
→ Does it anticipate failure modes?
→ What happens with bad input?
→ What happens when tools fail?
```

## D6: Context Awareness (1-10)
```
10: Intelligent context management, memory, compression
 5: Basic context handling
 1: No context management

Questions:
→ Does it manage context intelligently?
→ Can it handle large inputs?
→ Does it track state across turns?
→ Does it remember user preferences?
→ Does it compress irrelevant info?
```

## D7: Tool Integration (1-10)
```
10: Surgical tool use, parallel execution, error recovery
 5: Basic tool usage
 1: No tool integration

Questions:
→ Does it use tools optimally?
→ Are there tool selection rules?
→ Is error recovery covered?
→ Are results interpreted, not just pasted?
→ Is parallel execution used?
```

## D8: Voice & Persona (1-10)
```
10: Distinctive, consistent, adaptable, memorable
 5: Basic voice definition
 1: No voice or persona

Questions:
→ Is the voice consistent?
→ Is the persona well-defined?
→ Does it adapt tone to context?
→ Is it distinctive (not generic AI)?
→ Are there signature phrases?
```

## D9: Reference Quality (1-10)
```
10: Comprehensive, authoritative, well-organized, cross-referenced
 5: Basic references
 1: No references

Questions:
→ Are references comprehensive?
→ Are they from authoritative sources?
→ Are they well-organized?
→ Are there cross-references?
→ Are examples included?
```

## D10: Completeness (1-10)
```
10: Covers entire domain, templates, quick-start, advanced
 5: Covers main areas
 1: Incomplete or missing key areas

Questions:
→ Does it cover ALL aspects of the domain?
→ Are there templates?
→ Is there a quick-start guide?
→ Are there advanced techniques?
→ Is there a troubleshooting section?
```

---

## Scoring Interpretation

```
90-100 = LEGENDARY (minor polish only)
80-89  = ELITE (targeted upgrades)
70-79  = GOOD (major overhaul needed)
60-69  = AVERAGE (rebuild recommended)
0-59   = BASIC (complete rebuild)
```
