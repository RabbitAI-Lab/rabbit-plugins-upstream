# The Anatomy of a Legendary Skill

> Complete breakdown of what makes a skill legendary.

---

## The 5 Tiers

```
TIER 1: FUNCTIONAL (60-69)
  → It works. Basic instructions.

TIER 2: STRUCTURED (70-79)
  → Has frameworks and templates.

TIER 3: INTELLIGENT (80-89)
  → Has reasoning and self-correction.

TIER 4: ELITE (90-96)
  → World-class frameworks, multi-layer quality.

TIER 5: LEGENDARY (97-100)
  → Transcends frameworks, creates new paradigms.
```

---

## The 12 Components

### C1: CRYSTAL-CLEAR PURPOSE
```
BAD:  "This skill helps with writing"
GOOD: "Transforms any agent into an elite copywriter producing 
        high-converting sales copy using proven frameworks"

Must answer: WHAT, WHEN, WHY, WHO
```

### C2: TRIGGER INTELLIGENCE
```
EXPLICIT: "Write a...", "Create a..."
IMPLICIT: User mentions pain points
ANTI: Task outside domain
```

### C3: REASONING ARCHITECTURE
```
MINIMUM: Pre-analysis, framework selection, execution, review
ADVANCED: Multi-path, self-critique, verification, meta-review
```

### C4: FRAMEWORK LIBRARY
```
Not just ONE framework. A LIBRARY with:
→ Selection logic
→ Adaptation rules
→ Combination strategies
→ Common mistakes
```

### C5: OUTPUT SPECIFICATIONS
```
Structure: Required + optional sections
Quality: Minimum + excellent + legendary bars
Style: Voice, tone, forbidden, signature
```

### C6: EDGE CASE PROTOCOLS
```
Error handling, ambiguity resolution, constraint handling
```

### C7: CONTEXT MANAGEMENT
```
Memory, compression, cross-reference
```

### C8: TOOL MASTERY
```
Selection, execution, interpretation, error recovery
```

### C9: VOICE & PERSONA
```
Voice definition, tone adaptation, consistency
```

### C10: REFERENCE ARCHITECTURE
```
Organization, depth, currency
```

### C11: TEMPLATE SYSTEM
```
Quick-start, standard, advanced, checklist
```

### C12: SELF-IMPROVEMENT
```
Feedback integration, versioning
```
