# Skill Design Patterns

> Recurring patterns that make skills powerful.

---

## Pattern 1: The Protocol Pattern
```
BEFORE every [task], execute [protocol]:
1. [Step 1]
2. [Step 2]
3. [Step 3]
```
→ Ensures consistency
→ Prevents skipping critical steps
→ Creates predictable quality

## Pattern 2: The Framework Selection Pattern
```
If [condition A], use [Framework X]
If [condition B], use [Framework Y]
If [condition C], combine [X] + [Z]
```
→ Adapts to context
→ Prevents one-size-fits-all
→ Empowers intelligent choice

## Pattern 3: The Quality Gate Pattern
```
Before delivering, verify:
□ [Check 1]
□ [Check 2]
□ [Check 3]
```
→ Catches errors before shipping
→ Creates accountability
→ Ensures minimum quality

## Pattern 4: The Fallback Chain Pattern
```
Plan A: [Primary approach]
Plan B: If [condition], [alternative]
Plan C: If [worse], [minimal viable]
Plan D: If all fail, [escalation]
```
→ Handles failure gracefully
→ Maintains productivity
→ Reduces frustration

## Pattern 5: The Progressive Disclosure Pattern
```
Quick Start → Core Directives → Deep Dives → References
```
→ Serves all skill levels
→ Doesn't overwhelm beginners
→ Doesn't bore experts

## Pattern 6: The Multi-Persona Pattern
```
For NOVICE: [Simple version]
For COMPETENT: [Framework version]
For EXPERT: [Advanced version]
```
→ Serves entire user spectrum
→ Grows with the user
→ Maximizes utility

## Pattern 7: The Confidence Calibration Pattern
```
High confidence (>90%): [Verifiable facts]
Medium (60-90%): [Reasonable inferences]
Low (<60%): [Speculation with caveats]
```
→ Builds trust
→ Prevents overconfidence
→ Manages expectations

## Pattern 8: The Self-Correction Pattern
```
After [step], ask:
→ "Is this correct?"
→ "What could go wrong?"
→ "How can I improve?"
```
→ Catches errors early
→ Continuously improves
→ Models good thinking
