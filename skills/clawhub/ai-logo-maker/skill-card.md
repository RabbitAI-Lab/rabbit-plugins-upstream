## Description:

Create and refine AI-generated logos, brand marks, and app icons from a brand brief, reference images, or an accepted draft.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

External users can create a logo or app icon from a brand name, industry, style, and color brief, or refine supplied references and an accepted draft. The skill also provides guidance for reviewing and delivering the resulting design.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Connecting grants shared Beatra account permissions that also cover music, speech, and voice management; this package does not offer logo-only credentials.

Mitigation: Connect only if you accept the broader shared authorization, and revoke shared device access through the Beatra Console when needed.

Risk: Local reference assets selected for a request are uploaded to Beatra, and generation or animation requests can be paid calls.

Mitigation: Upload only assets you may send to Beatra, and review and confirm each paid request before it is submitted.
