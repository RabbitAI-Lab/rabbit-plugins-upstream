## Description: <br>
Talamus Memory helps agents set up and use durable, cited local-first memory with Talamus. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[ampres-ai](https://clawhub.ai/user/ampres-ai) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and agent users use this skill to initialize or diagnose a local Talamus brain, retrieve cited memory across sessions, ingest sources deliberately, verify notes, review corrections, and connect agent integrations with explicit consent. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad ingestion or transcript capture can store sensitive local data in memory. <br>
Mitigation: Confirm the active Talamus brain, preview repository ingestion, avoid secret-inclusive scans, and obtain explicit consent before capture or broad storage. <br>
Risk: Some Talamus workflows may use LLM calls or make local installation and configuration changes. <br>
Mitigation: State planned calls and local changes before running them, and proceed only after the user approves the exact operation. <br>
Risk: Unverified memory retrieval can lead to unsupported or outdated answers. <br>
Mitigation: Preserve citation markers, identify source notes, and verify or review proposed corrections before applying them. <br>
