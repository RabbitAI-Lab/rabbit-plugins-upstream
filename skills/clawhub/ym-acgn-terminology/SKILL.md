# ACGN黑话翻译官 (ym-acgn-terminology)

把 ACGN 圈子黑话翻译成圈外人能懂的人话，每个词给出来源、圈内含义、一句话生活类比、场景例句与风险标注。命中词条库直接用标准释义，保证同一个词每次解释一致；查不到的按构词法与语境推断并标注「库外推断，供参考」。

## 何时使用

- 用户说「黑话什么意思」「二次元用语」「圈子黑话」「梗解释」，或贴了一段圈内发言要翻译时
- 用户要给长辈、同事、客户解释某个词，需要「人话版」时
- 用户在职场/群里看到不懂的缩写，要判断能不能回、怎么回时
- 用户自己想入坑，要搞懂一批常用词时

## 运行前提

- 依赖：纯文本生成，无第三方依赖、不联网、不读取本地文件
- 词条释义来自 `references/term-dict.md`，生成前先读该库
- 不做实时热梗追踪，新梗未入库时按库外推断处理
- 不调用任何脚本，释义匹配由模型按词条库完成

## 输入契约

| 项 | 必需 | 说明 |
|---|---|---|
| 用语 | 必需 | 一个或多个词/短语，可成句。可一次给一批，逐条译 |
| 用途 | 可选 | 给长辈解释 / 职场场合判断 / 自己入坑学习；默认「自己理解」，决定解释口径与风险标注力度 |

**缺失处理：** 用语缺失时说明需要用户提供具体词，不编造释义。用途缺失默认「自己理解」，但仍对职场高危词标风险。批量输入时若其中某词语境不清（如缩写多义），对该词先回问语境再给释义，不与其他词混为一谈。

## 执行步骤

1. **读词条库** — 先载入 `references/term-dict.md`，确认库内已收录的词与更新日期。

2. **逐词匹配** — 每个用语去库里查：
   - 命中：直接用库内五字段标准释义，不擅自改写，保证一致性
   - 未命中：按构词法（缩写还原、谐音、反讽）与上下文推断，并在该词结论处明确标「库外推断，供参考」
   - 缩写多义：先问用户语境再解释，不硬猜

3. **按用途调口径** — 用途为「给长辈解释」时，一句话解释用最生活化的类比，跳过圈内黑话；用途为「职场判断」时，重点标风险与替代说法；用途为「自己学习」时，五字段全给。

4. **标风险与替代** — 职场高危词（ntr、本子、里番、擦边、福利、ymjm 等）必须给「换成人话怎么说」的替代表达，并明说长辈/同事面前慎用。

5. **输出交付** — 每个词固定五字段返回；批量时逐词列出，高危词单独高亮。未命中词标库外推断。

## 输出格式

每个词固定五字段：

```
【词】养生番
- 原义与来源：……
- 圈内含义：……
- 给圈外人的一句话解释：……（生活类比）
- 使用场景与例句：……
- 风险标注：……
```

职场高危词额外加一行：

```
- 换成人话怎么说：……
```

## 词条库结构与覆盖

`references/term-dict.md` 按五个分类组织，生成时先定位词所属分类再取释义：

- 番剧类型与追番词（追番应援）：养生番、泡面番、厕纸番、神作、烂作、催更、养肥、入坑、出坑、生肉、熟肉、字幕组、补番、追番、完结撒花、万年坑
- 弹幕互动：前方高能、空降、弹幕护体、名场面、高能、催泪、名梗、战 Future、弹幕打卡
- 剧情与角色：立 flag、工具人、主角光环、套路、反套路、龙套、发糖、喂糖、刀、BE、HE、发刀、破防、上头、下头、燃、梦女、苏、塌房
- 社群梗：典、典中典、yyds、绝绝子、蚌埠住了、寄、退退退、栓 Q、emo、社死、嗑 CP、本命、推、白学、姨母笑、救命
- 职场高危：ntr、本子、里番、擦边、福利、鬼畜、ymjm（隐晦缩写）

库内共 60 余条，每条五字段完整；职场高危词额外给「换成人话怎么说」。新出的热梗若不在库内，按库外推断处理并标注日期限制。

## 用途口径对照

同一词对不同用途解释口径不同，按用户给的用途切换：

| 用途 | 一句话解释 | 风险标注 | 是否给五字段全量 |
|---|---|---|---|
| 给长辈解释 | 最生活化类比，不堆圈内词 | 高危词直接换成中性说法 | 否，给核心三字段即可 |
| 职场场合判断 | 保留原义，重点标风险 | 必须标慎用并给替代 | 是，风险字段置顶 |
| 自己入坑学习 | 五字段全给 | 照常标 | 是 |

## 翻译示例

命中词条（养生番，用途：自己理解）：

```
【词】养生番
- 原义与来源：圈内戏称，指节奏慢、不费脑、适合睡前看的轻松番，约 2010 年后流行
- 圈内含义：画风治愈、剧情平淡、无大起大落，看了解压助眠
- 给圈外人的一句话解释：像睡前喝杯温牛奶，图个放松不图刺激
- 使用场景与例句：想放松时说「最近只看养生番，刺激的全跳了」
- 风险标注：长辈面前可用，无风险
```

命中词条（典，用途：职场判断）：

```
【词】典
- 原义与来源：经典（classic）缩写，作形容词
- 圈内含义：形容行为/发言很「经典」（常带调侃或反讽）
- 给圈外人的一句话解释：像说「这操作很经典（多半不是夸）」
- 使用场景与例句：「你这发言太典了」
- 风险标注：职场慎用，反讽语气易被当真
- 换成人话怎么说：「你这说法很套路/很典型，我先确认下你的本意」
```

库外推断（某新出谐音梗未入库）：

```
【词】XX（库外推断，供参考）
- 原义与来源：按构词法推断为……（标注推断依据）
- 圈内含义：推断为……
- 给圈外人的一句话解释：……
- 使用场景与例句：……
- 风险标注：未在词条库，释义为推断，建议以语境为准
```

## 验收用例

- 正常：查「养生番」和「典」→ 都给出圈外人一句话解释、有例句；「典」标注职场慎用并给替代说法
- 边界：一次给一批词（含未入库新梗）→ 命中用库内释义，未命中标库外推断
- 失败：用语为空 → 说明需要具体词，不编造

## 能力边界

- 不做实时热梗追踪，收录截至库内标注的更新日期
- 不对具体作品/人物做评价，只解释词义
- 不确定的词义不装确定，明确标库外推断或建议问语境
- 不替用户在群里发言，只给判断与替代表达
- 不把库外推断当定论输出，凡推断必标「库外推断，供参考」

## 常见坑

1. **词义随时间漂移** — 现象：「立 flag」原指剧情触发标记，现在日常也用来指「说大话要倒霉」，按旧义解释会错位。原因：词从剧情用语泛化成日常用语。规避：释义同时给原义与当前圈内用法，注明漂移。
2. **同一词圈内圈外含义相反** — 现象：「典」圈内常带反讽，圈外人当褒义「经典」理解，照圈内义直译会冒犯。原因：反讽用法外溢。规避：圈内含义写明反讽语气，给长辈版换中性说法。
3. **缩写词多义** — 现象：yyds 是「永远的神」，但很多缩写随圈不同义不同，硬猜会错。原因：首字母缩写高度依赖语境。规避：缩写先问语境再解释，不默认唯一义。
4. **谐音梗有时效性** — 现象：「蚌埠住了」「栓 Q」火一阵就冷，长辈永远听不懂。原因：谐音梗依赖当期热度。规避：长辈面前一律还原成原词（绷不住了/谢谢），不教谐音。
5. **直接照搬词条原句给长辈听不懂** — 现象：把「前方高能」原句甩给长辈，他不懂。原因：跳过生活类比。规避：用途为「给长辈解释」时只用一句话生活类比，不堆圈内词。
6. **高危词在职场误发** — 现象：群里顺手回「这波 ntr」，被举报。原因：没标风险。规避：高危词强制给替代说法，并明说长辈/同事面前慎用。
