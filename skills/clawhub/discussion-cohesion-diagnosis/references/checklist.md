# Cohesion Checklist — Discussion 连接与衔接逐条检查清单

## 使用方法
按顺序检查每一项，✓ 通过，✗ 缺失，⚠ 弱。

---

## Section 1: Topic Sentences（主题句）

- [ ] 每段第一句是 claim/topic sentence，不是 results 复述
- [ ] Topic sentence 预告本段要 claim 什么
- [ ] Topic sentence 与上一段有逻辑联系

## Section 2: Connective Variety（连接词多样性）

- [ ] 至少 3 种连接词类型（sequential / causal / contrastive / additive / exemplifying / concessive）
- [ ] 不是只依赖 "Furthermore" / "Moreover"
- [ ] 段落内有因果连接（"because" / "thus"）
- [ ] 段落内有对比连接（"however" / "in contrast"）

## Section 3: Connective Density（连接词密度）

- [ ] 每段 2-4 个连接词（不是 5+ 个）
- [ ] "Furthermore" / "Moreover" 在一段内最多出现 1-2 次
- [ ] 没有无连接词的段（除非是结论 wrap）
- [ ] 没有每句 1 个连接的"机械堆叠"

## Section 4: Forward Motion（前向推进）

- [ ] 每段都在推进 Discussion 的核心 claim
- [ ] 没有"原地踏步"段（只重复 Results 无新 claim）
- [ ] 每段有"so what"
- [ ] Discussion ≠ Results 精简版

## Section 5: Narrative Thread（叙事主线）

- [ ] 能用 1 句话总结全 Discussion 主线
- [ ] 段间逻辑递进（不仅是堆叠）
- [ ] 多重 claim 时主线不冲突
- [ ] Closing 段呼应主线

## Section 6: Inter-paragraph Transitions（段间过渡）

- [ ] 段 1 → 段 2 有过渡（topic sentence 或衔接词）
- [ ] 段 N → 段 N+1 主题不突然跳转
- [ ] 没有"段落独立成文"现象
- [ ] 新段落引入有 signal（"Turning to..." / "Building on..."）

## Section 7: Anti-Pattern Check（反模式）

- [ ] ❌ 整段都是 "Furthermore / Moreover / Additionally"
- [ ] ❌ Discussion 像 Results 的精简版
- [ ] ❌ 段落之间无任何衔接
- [ ] ❌ 没有任何 topic sentence
- [ ] ❌ 段间主题突然断裂

---

## 严重度判定

| 缺失项数 | 严重度 |
|---|---|
| 0-2 | Minor |
| 3-5 | Major |
| 6+ | Critical |
