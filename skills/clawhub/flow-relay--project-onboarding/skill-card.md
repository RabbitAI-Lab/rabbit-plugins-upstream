## Description:

Prepare a role-specific onboarding brief for a Flow Relay project by checking existing onboarding insights first and answering targeted follow-up questions with citations.

This skill is ready for commercial/non-commercial use.

## Publisher:

[flow-relay](https://clawhub.ai/user/flow-relay)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, product managers, and other new project members use this skill to get an orientation tailored to their role and project focus. It surfaces relevant existing insights, answers follow-up questions with citations, and suggests a few next things to inspect.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: An onboarding brief could include unsupported claims if project evidence is incomplete or unclear.

Mitigation: Use retrieved insights and source citations for claims, and identify gaps instead of filling them with assumptions.

Risk: A tailored brief may be unavailable when AI access is not granted.

Mitigation: Use the documented fallback sources or explain which access is required for generation.
