# PromptKit - AI Prompt Engineering Expert 🎯

Auto-select and apply the best of 56 prompting frameworks to generate clear, structured, and effective prompts.

Inspired by **56 Framework Prompting by @\_khaamal**.

---

## 🚀 Quick Start

```bash
clawhub install promptkit
```

## ⚡ How to Use

### Quick — just ask
> "PromptKit, write a prompt for email marketing"

### Guided — step-by-step
> "PromptKit, guided"

### Advanced — full control
> "PromptKit, prompt using CO-STAR for Instagram caption, casual tone, skincare brand"

## 🎯 Auto-Select

| Need | Framework |
|------|-----------|
| Article / blog | C-A-R-E |
| Caption / social | T-A-G, CO-STAR |
| SEO / meta | R-T-F |
| Storytelling | COAST |
| Brainstorm | R-I-S-E |
| Strategy | S-O-L-V-E, D-R-E-A-M |
| Problem solving | P-A-C-T, OSCAR |
| Research | R-A-C-E, TRACE |
| Code / math | PAP, CoT |
| Decisions | ToT, Debate |
| Explanation | Analogy |
| What-if | Counterfactual |
| Copywriting | CO-STAR, GRADE |
| Product desc | GRADE |

---

## 🧩 56 Frameworks

**Writing & Content:** C-A-R-E, T-A-G, R-T-F, CO-STAR, GRADE, COAST

**Analytical:** P-A-C-T, R-I-S-E, D-R-E-A-M, S-O-L-V-E, R-A-C-E, TRACE, A-P-E, PECRA, OSCAR, RODES, TRACI

**Advanced:** Rule-Based, CoT, PAP, Self-Consistency, APE, ToT, GoT, Least-to-Most, Few-Shot CoT, Stepwise Refinement, Chain of Verification, Progressive Summarization, Constraint-Based, Deliberation

**Creative:** Error-Driven, Inversion, Roleplay+Constraint, Counterfactual, Problem-Solving, Reverse Engineering, Analogy, Persona Comparison, Time-Travel, Cross-Domain Transfer, Multi-Stage, Layered Abstraction, Debate, Test-and-Improve, Perspective Shift, Recursive, Exploration vs Exploitation, Heuristic, Comparative, Simulation, Creative Constraints
