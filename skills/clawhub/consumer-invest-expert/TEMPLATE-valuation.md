# 模板：估值方法与单店经济模型（Unit Economics）

> 适用：消费连锁股权投资、RBF 回报测算、收并购标的估值。无需外部技能即可手动计算；复杂建模可配合 `finance-ops` 技能。

## 一、单店经济模型（UE）

```
月营收        = 客单价 × 日均交易笔数 × 30
月变动成本    = 原料成本(约营收25-35%) + 平台/加盟分包费 + 变动人工
月固定成本    = 房租 + 固定人工 + 水电 + 总部摊销 + 营销
店级经营利润  = 月营收 − 月变动成本 − 月固定成本
经营利润率    = 店级经营利润 / 月营收
回本周期(月)  = 单店总投资 / 店级经营利润
坪效          = 年营收 / 门店面积
```

**关键判断线（峰畔实践）**
- 加盟续签率 < 70% → 单店模型「一票否决」（可能是算出来的，不是做出来的）。
- 回本周期 > 36 个月 → 模型偏重，RBF/股权扩张需谨慎。
- 经营利润率 < 15% → 价格战抗风险能力弱。

## 二、估值方法选择

| 方法 | 适用阶段 | 公式 | 倍数参考 |
|---|---|---|---|
| PS（市销率） | 成长期连锁、未盈利 | 企业价值 = 年化营收 × PS | 餐饮连锁 1-3x；茶饮 2-5x（看增速） |
| PE（市盈率） | 成熟期、稳定盈利 | 股权价值 = 净利润 × PE | 消费品牌 15-30x |
| PB（市净率） | 重资产/零售 | 股权价值 = 净资产 × PB | 0.8-2x |
| DCF | 现金流可预测 | Σ(自由现金流/(1+WACC)^t) + 终值 | WACC 8-12% |
| 可比交易法 | 收并购 | EV = 营收 × EV/营收 或 EBITDA × EV/EBITDA | EV/营收 0.5-2x；EV/EBITDA 8-15x |

**可比公司锚点（来源：峰畔智库 / 公开财报，需核实）**
- 古茗（港股）：市值约235亿港元，下沉市场+供应链逻辑。
- 遇见小面（港股）：市值超35亿港元，川渝面馆第一股。
- 瑞幸：31048家店（2025），数据驱动+联营模式（RBF变体）。

## 三、RBF 回报测算

```
月分成        = 门店月营收 × 分成比例(2%-10%)
年分成        = 月分成 × 12
投资回收期    = 投资本金 / 年分成
封顶倍数 cap  = 累计分成上限 / 投资本金（常见 1.5x-2.5x）
单店 IRR      ≈ (累计回报 / 本金)^(1/联营年数) − 1
```

**示例**（摘自第13章）：单店投入50万，月营收20万，分成8% → 月分成1.6万，年19.2万，3年累计57.6万（回报≈15%）；月营收30万→3年86.4万（回报≈73%）；月营收10万→3年28.8万（亏损≈42%）。体现风险共担。

## 四、敏感性分析（必做）

对投资决策，至少做三情景：
- 乐观：营收 +20%、利润率 +3pct
- 基准：当前模型
- 悲观（压力测试）：营收 −20%、闭店率升至20%、价格战致客单价 −15%

输出：各情景下回本周期、IRR、cap 达成概率，并标注「消费长期下行周期可能才刚开始」的压力基线。
