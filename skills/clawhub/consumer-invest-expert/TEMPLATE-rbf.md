# 模板：RBF 联营投资条款设计

> 来源：第13章《RBF联营投资》+ 峰畔资本加速器实践。用于设计单店级收入分成融资方案。

## 一、核心机制（不稀释股权、按收入分成）

| 条款 | 设计要点 | 常见区间 |
|---|---|---|
| 投资金额 | 单店投入（装修+设备+首批原料） | 30万-200万/店 |
| 分成比例 | 门店月营收的比例 | 2%-10%（视模型与期限） |
| 联营期 | 匹配门店租约 | 3-5年 |
| 封顶倍数 cap | 累计分成上限 / 本金 | 1.5x-2.5x |
| 无收入不分账 | 亏损月不分账，风险共担 | 强制条款 |
| 回本周期 | 本金 / 年分成 | 目标 18-30 个月 |
| 风控触发线 | 续签率<70% / 闭店率>20% → 重新定价或止损 | 监控指标 |
| 退出机制 | 租约到期不续则结束；或转股权 | 单店级→公司级升级 |

## 二、双轨模式

- **不占股联营**：纯收入分成，0%股权。适合品牌方不愿稀释、投资方只想拿门店现金流。
- **小股比+营收分成**：如 5%-15% 股权 + 分成。适合投资方看好公司级成长，RBF 作为「前置筛选器」为后续股权/收并购铺垫（见第13章协同关系）。

## 三、适用边界（来自第13章）

**适用**：单店模型已验证（有几家盈利店）、标准化品类（咖啡/奶茶/烘焙/快餐）、加盟体系升级（城市合伙人）。
**不适用**：早期未验证模型、非门店型（纯电商/DTC）、需大额公司级投入（几千万以上，应走股权/收并购）。

## 四、回报测算模板

```
月分成   = 月营收 × 分成比例
年分成   = 月分成 × 12
回收期   = 本金 / 年分成
cap达成  = min(累计分成, 本金×cap)
单店IRR  = (cap达成 / 本金)^(1/联营年数) − 1
```

## 五、与直营/加盟对比（决策用）

| 维度 | 直营 | 加盟 | RBF |
|---|---|---|---|
| 资金来源 | 品牌方 | 加盟商 | 投资方 |
| 股权稀释 | 无 | 无 | 无 |
| 控制权 | 品牌方 | 加盟商 | 品牌方运营+监督 |
| 风险 | 品牌方独担 | 加盟商独担 | 双方共担 |
| 品质管控 | 强 | 弱 | 强 |

**结论**：RBF 比直营轻（投资方出钱）、比加盟紧（品牌方运营）、比股权安全（不稀释）。与收并购构成连续投资链：RBF验证→规模化→收并购突破品类。
