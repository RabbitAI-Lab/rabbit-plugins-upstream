# 模板：收并购（M&A）交易结构设计

> 来源：第11章《收并购》+ 第12章《产业资本》+ 第14章《赋能式投资经营》。用于标的筛选、交易结构与整合方案。

## 一、收并购三种目的（先想清楚买什么）

| 目的 | 买的是什么 | 判断标准 |
|---|---|---|
| 买品牌 | 品类心智占位 | 自建需5年以上 → 买比建划算 |
| 买品类 | 品类卡位（与主品牌心智不兼容时） | 碳酸→果汁 必通过收购 |
| 买渠道 | 区域渠道网络/经销商关系 | 缺渠道覆盖时，买比自建快 |

## 二、交易结构选择

| 结构 | 说明 | 适用 |
|---|---|---|
| 现金收购 | 一次性现金支付 | 买方现金充足、标的清晰 |
| 换股 | 以股换股 | 双方上市公司/拟上市 |
| Earn-out | 分期按业绩支付 | 信息不对称、激励原团队 |
| 对赌（业绩承诺） | 未达承诺补偿 | 早期/高成长标的 |

**对赌/Earn-out 设计要点**：设定营收/净利阈值、补偿上限、原团队留任绑定、审计机制。

## 三、估值

```
企业价值 EV   = 股权价值 + 净负债
EV/营收       = 标的营收 × 行业倍数（消费 0.5-2x）
EV/EBITDA     = EBITDA × 8-15x
协同溢价       = 供应链降本(采购/生产/物流协同 15-20%) + 渠道增量
```

## 四、整合系统能力四层（成败关键）

1. **战略判断**：该买什么（心智/用户互补/供应链协同/团队留任）。
2. **交易能力**：估值/融资/法律/税务/合规；可联合产业资本组财团分散风险（如安踏+方源收购亚玛芬）。
3. **整合能力**：独立运营 vs 合并、团队留任、供应链/渠道/数据打通。
4. **赋能能力**：让1+1>2（注入供应链/零售/数字化能力）。

## 五、协同效应（产业资本独特价值）

- 采购协同：多品牌联合采购降本 15-20%。
- 生产协同：共享产线，固定成本摊薄。
- 物流协同：区域配送中心共享，单店物流下降。

## 六、前提四问（出手前自检）

主品牌够强？有资本能力？有整合/赋能团队？有清晰品牌矩阵战略？四个「是」再动手。

## 七、案例锚点（来源：峰畔智库 / 公开报道，需核实）

- 安踏收购 FILA 中国（约6亿港币，买高端运动时尚心智）→ 年营收近300亿。
- 安踏牵头财团收购亚玛芬体育（约371亿元，买高端户外/专业运动心智）。
- 百胜中国81亿收购必胜客中国大陆（品牌矩阵+渠道协同）。
- 大钲资本收购 Blue Bottle（控股+深度运营）。
- 鲜芋仙加入 CFB 集团（锐峰资本任财务顾问）。
- 3G资本：百威英博/汉堡王/卡夫亨氏（控股并购+零基预算，警惕过度成本削减伤创新）。
- 丹纳赫 DBS：600+次并购、年均21%回报（投前匹配度+投后植入+长期赋能）。
