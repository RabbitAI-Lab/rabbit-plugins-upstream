# 模板：消费连锁投资尽调清单（DD Checklist）

> 适用：股权投资、RBF、收并购的尽职调查。分商业/财务/法律三层 + RBF专项。

## 一、商业尽调（BDD）
- [ ] 赛道：空间、增速、集中度（CR5）；参照系（台湾/日本走过的路）。
- [ ] 周期定位：闭店率、加盟续签率、客单价趋势（见 `TEMPLATE-four-supreme-cycle.md`）。
- [ ] 单店模型（UE）：客单价、日均单量、变动/固定成本、经营利润率、回本周期（见 `TEMPLATE-valuation.md`）。
- [ ] 四超格局打分：超级品牌/供应链/渠道/数据，0-3分（短板=生死线，长板=天花板）。
- [ ] 终局路径：顶天立地/铺天盖地/地方之王/掌握周期。
- [ ] 加盟体系：加盟商结构、续签率、管控力度、城市合伙人成熟度。
- [ ] 供应链：自建/代工、采购规模、成本优势、万店支撑能力。

## 二、财务尽调（FDD）
- [ ] 收入确认：直营（总额法）vs 加盟（加盟费/原料销售/特许权使用费）区分清晰。
- [ ] 成本可追溯：单店成本结构、总部摊销合理性。
- [ ] 利润可审计：经审计财务报表、税务合规（社保/发票/个税）。
- [ ] 现金流：经营性现金流、单店现金回正周期。
- [ ] 关联交易：向加盟商销售原料的定价公允性（蜜雪模式：收入主要来自供应链）。

## 三、法律尽调（LDD）
- [ ] 商标/品牌权属清晰，无争议。
- [ ] 特许经营备案（商务主管部门）合规。
- [ ] 加盟合同：解约、区域保护、续约条款。
- [ ] 劳动合规：社保、用工。
- [ ] 数据合规：会员数据收集与使用（个保法）。

## 四、上市披露专项（Pre-IPO）
- [ ] 加盟模式披露：加盟商数量、收入贡献占比、续签率。
- [ ] 收入确认政策披露一致。
- [ ] 食品安全与投诉处理机制。

## 五、RBF 专项验证
- [ ] 单店盈利已验证（≥3家盈利店）。
- [ ] 续签率 ≥ 80%、闭店率 < 10%（健康）。
- [ ] 模型可复制（跨区域验证店）。
- [ ] 分成比例与 cap 对双方公平，无收入不分账条款落实。
- [ ] 风控触发线（续签率<70%/闭店率>20%）写入合约。

> 提示：本清单为通用框架，具体项目按赛道调整；涉及法律/税务/审计事项，提示用户咨询持证专业人士。
