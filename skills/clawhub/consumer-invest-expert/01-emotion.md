# 第1章 所有消费，本质上都是情绪消费

Chapter 1 - Version 1 - ready for review


第一部·以史为鉴 · 第一人称产业投资人视角
预估篇幅：8,000字

海底捞到底卖什么？

卖火锅的？那为什么不去街边火锅店吃，要排队两小时去海底捞？

卖服务的？那服务值多少钱？免费美甲、擦皮鞋、生日歌——这些服务的成本，真的能覆盖它比同行高30%的客单价吗？

我在消费行业做投资这些年，每次看餐饮项目都会问创始人一个问题：你的品牌到底在卖什么？大多数人的回答是：卖产品。火锅卖火锅，奶茶卖奶茶，面包卖面包。

这个回答不及格。

海底捞卖的不是火锅，是"被重视的欢乐感"。

你想想你去海底捞的经历。一个人去吃，服务员在你对面放一个玩偶陪吃。过生日，一群服务员围过来唱歌——尴尬，但你会笑。等位时免费美甲、下跳棋、吃水果——你等了两小时，但没有生气，甚至觉得有意思。

这些不是"服务"，这些是情绪设计。海底捞的每一个动作，都在制造一种情绪：你在这里被重视了，你在这里很开心。

火锅是载体，情绪才是产品。

这个判断不是我拍脑袋想出来的。在我看过的数百家消费企业里，凡是穿越过周期的品牌，都有一个共同特征：它们知道自己卖的不是产品，是情绪。

## 情绪消费对照表

让我把几个你熟悉的品牌放在一起看：

|||||
|---|---|---|---|
|海底捞|火锅|被重视的欢乐感|客单120元|
|星巴克|咖啡|第三空间归属感|客单35元|
|泡泡玛特|潮玩手办|惊喜与情感连接|单个59-69元|
|蜜雪冰城|奶茶|平价多巴胺|客单6-10元|


看清楚了吗？

星巴克卖的咖啡，成本不超过5块钱，但你能坐一下午。你买的是"在第三个地方待着"的感觉——不是家，不是办公室，是"第三空间"。霍华德·舒尔茨把这个概念从意大利带回来，做成了全球最大的咖啡连锁。咖啡是载体，归属感才是产品。

泡泡玛特卖的是塑料手办吗？成本几块钱的塑料玩具，卖59块。为什么有人买？因为拆盲盒那一刻的惊喜感，因为抽到隐藏款的成就感，因为放在桌面上每天看到时的情感连接。塑料是载体，惊喜才是产品。

蜜雪冰城更极端。6块钱一杯柠檬水，你以为它卖的是便宜？不，它卖的是"花6块钱就能获得的快乐"——平价多巴胺。当你的目标用户是三四线城市的年轻人，6块钱的快乐就是最好的情绪定价。

所有消费，本质上都是情绪消费。

这不是一句口号，而是一个分析框架。当你用这个框架重新审视品牌，会发现很多反直觉的真相。

## 为什么情绪比产品更重要

你可能会问：产品难道不重要吗？当然重要。产品是1，情绪是后面的0——没有1，后面再多的0也没有意义。但只有1没有0，你最多做到及格，做不到卓越。

让我用一个对比来说明。

2018年前后，新茶饮赛道爆发。喜茶、奈雪的茶、乐乐茶……几十个品牌涌入。它们的产品差距大吗？不大。都是芝士奶盖茶、水果茶、鲜奶茶，供应链来源都差不多，甚至配方都互相"借鉴"。

五年后，格局完全不同。喜茶成了头部，有些品牌已经消失了。差距来自产品吗？不是。差距来自情绪定位。

喜茶卖的是"灵感之茶"——喝喜茶的那一刻，你觉得自己是个有品味、有灵感的年轻人。这个情绪定位精准地击中了20-30岁城市白领的自我认同。它的门店设计、杯套文案、联名活动，全都在强化这个情绪。

而那些消失的品牌，大多只有一个模糊的产品定位——"好喝的茶"。好喝是标配，不是差异化。当消费者记不住你卖什么情绪，你就只是一个功能性的选择，而不是一个有粘性的品牌。

产品决定你能不能上场，情绪决定你能不能留在场上。

这个判断在快消品领域同样成立。可口可乐卖的不是糖水，是"打开快乐"的感觉。农夫山泉卖的不是水，是"大自然搬运工"的信任感。三顿半卖的不是速溶咖啡，是"精品生活方式"的自我标榜。

你可能会说：这些太虚了。我是个务实的人，我只看产品和数据。

好，那我们用数据说话。

## 情绪与周期韧性：多巴胺经济的抗周期能力

2020年到2023年，中国消费行业经历了一轮剧烈调整。很多品类大幅下滑，但有一些品类逆势增长。

你猜哪些品类最抗跌？

不是刚需的米面粮油（它们持平），不是高端奢侈品（它们分化严重），而是——多巴胺经济品类。

||||
|---|---|---|
|咖啡|持续正增长|提神+仪式感|
|巧克力|稳健|愉悦感|
|碳酸饮料|稳健|爽快感|
|奶茶|逆势扩张|即时快乐|
|辣条/卤味|稳健|刺激感|


为什么？因为经济下行期，人们的压力更大，更需要"花小钱买快乐"。心理学上叫"口红效应"——经济越差，越需要低价的慰藉品。但口红效应只解释了"为什么低价品好卖"，没有解释"为什么多巴胺品类好卖"。

答案在于：多巴胺是最便宜的快乐来源。

6块钱一杯蜜雪冰城，15块钱一杯瑞幸，20块钱一杯喜茶——这些价格带来的多巴胺分泌，远比一辆豪车或一次旅行来得即时、来得高频。当大额消费被推迟，人们会把快乐预算转移到小额高频的多巴胺消费上。

这不是中国独有的现象。日本2003年经济长期低迷时期，同样的事情发生过——啤酒、巧克力、甜品的销量不降反增。美国2008年金融危机后，快餐和甜品的消费也在增长。

多巴胺经济品类天然具有穿越周期的韧性。 这不是运气，是人性。

所以当我在看消费项目时，第一个问题不是"你的产品好不好"，而是"你的产品能不能制造多巴胺"。如果能，这个品类天生就有更强的抗周期能力。如果不能——比如某些功能性食品、健康代餐——你就需要问自己：在经济下行期，消费者会不会为你的产品减少开支？

## 战略起点：用一句话说出你的品牌在卖什么情绪

我见过太多创始人，能花两小时讲产品配方、供应链优化、门店模型，但说不清楚一句话：你的品牌在卖什么情绪？

这不是小事。这是战略设计的起点。

如果你说不清楚自己在卖什么情绪，你就无法做以下决策：

无法定价。 情绪决定价格带。卖"被重视的欢乐感"可以定价120元，卖"平价多巴胺"只能定价6元。如果你不知道自己卖什么情绪，你的定价就是拍脑袋。

无法设计门店体验。 海底捞的门店设计围绕"被重视"——等位区、生日歌、陪吃玩偶，每一个触点都在强化这个情绪。如果你不知道自己卖什么情绪，你的门店就只是一个卖东西的空间，而不是一个制造情绪的场景。

无法选择营销策略。 泡泡玛特的营销围绕"惊喜"——盲盒、隐藏款、联名款，每一个动作都在制造期待感。如果你不知道自己卖什么情绪，你的营销就是跟风——别人做联名你也做联名，别人做直播你也做直播，但永远慢半拍。

无法判断品类延展的边界。 海底捞能从火锅延展到自热火锅、火锅底料，因为"被重视的欢乐感"可以迁移到家庭场景。但如果一个卖"专业感"的品牌去做娱乐化产品，消费者会觉得违和。情绪定位决定了你能做什么、不能做什么。

所以我的建议很简单：在谈周期、谈终局、谈收并购之前，先回答这个问题——你的品牌在卖什么情绪？

用一句话说出来。不是一段话，不是一页PPT，是一句话。

如果你说不出来，停下来想。这个问题答不清楚，后面所有的战略推演都是空中楼阁。

## 一个实操工具：情绪定位画布

最后给你一个工具，帮你想清楚这个问题。

我把它叫"情绪定位画布"，很简单，四个格子：

┌─────────────────┬─────────────────┐
│  表面产品        │  底层情绪        │
│  （你卖什么）     │  （你卖什么感觉） │
├─────────────────┼─────────────────┤
│  情绪定价        │  情绪触点        │
│  （这个情绪值多少）│  （哪里能感受到） │
└─────────────────┴─────────────────┘

拿海底捞举例：

|||
|---|---|
|表面产品|火锅|
|底层情绪|被重视的欢乐感|
|情绪定价|客单120元（比普通火锅贵30%）|
|情绪触点|等位服务、生日歌、陪吃玩偶、免费美甲|


拿蜜雪冰城举例：

|||
|---|---|
|表面产品|柠檬水/奶茶|
|底层情绪|平价多巴胺|
|情绪定价|客单6-10元|
|情绪触点|雪王IP、洗脑主题曲、"你爱我我爱你"|


你试着填一下自己品牌的。如果"底层情绪"那一格你填不出来，或者填了一个"好喝""好吃""性价比高"这种不是情绪的词——说明你的品牌还没有情绪定位。

这不是小事。没有情绪定位的品牌，在周期下行时最先被消费者抛弃。 因为当钱包变紧，消费者会先砍掉那些"没有情绪附加值"的功能性消费，保留那些"让我有感觉"的情绪消费。

这一章是全书的起点。在接下来的章节里，我会带你看周期、看终局、看收并购——但所有这些战略推演的前提，是你先想清楚一个问题：

你的品牌，在卖什么情绪？

所有消费，本质上都是情绪消费。想清楚这一点，你才能开始谈穿越周期。
