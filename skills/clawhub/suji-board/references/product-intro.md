# 速记板 · 产品功能介绍

## 一句话定位

把零散文字随手收进来，自动编号整理，分门别类归档，一键导出成 Word 文档。

## 起名由来

「速」是粘贴即收、回车即记的快；「记」是文字记录的本质。客户一眼就懂是干嘛的，好记好传播。

（备选名：文仓 / 顺手记，偏收纳感或轻量感。）

## 客户向功能介绍

你有没有这种时候：从网上、群里、文档里复制了一堆文字，散落在各个窗口，想整理成一份汇报或资料，却要从头排版、反复粘贴，越理越乱？

速记板就是干这个的——收、编、存、出，一条龙。

- **粘贴即记录**：Ctrl+V 直接贴，或敲回车逐条添加，每条自动编号。复制内容时序号不跟着跑，贴出去干干净净。
- **每条都能整理**：太长可一键折叠收起；暂时不用的存进草稿箱，不参与编号也不进导出；删掉的进回收站，误删随时找回。
- **文件夹归档**：建文件夹分主题，把 txt / doc / docx / md 等文档拖进去或上传，文件名、大小、上传时间清清楚楚，点开就能看正文、能复制、能删除。
- **一键成稿**：随时导出标准 .docx 文件，直接发给同事、交差、存档，不用再手动排版。
- **本地保存，不联网不登录**：关掉网页内容也在，纯本地存储，没有账号、没有上传，隐私放心。

## 适合谁用

频繁摘抄资料的研究员、写日报周报的职场人、做调研和竞品整理的同事，以及任何「复制了很多、整理很头疼」的人。

## 为什么想用

不用打开笨重的笔记软件，不用建账号，浏览器里一个页面就能把碎片文字变成结构化文档。从「复制粘贴的混乱」到「一份能发的 Word」，中间只差一个速记板。

## 技术亮点（对内/上架详情用）

- 单文件 HTML，零依赖、无需联网、无需安装。
- 纯本地存储（localStorage），数据不出本机。
- 导出的是标准 OOXML .docx（ZIP 容器），Word / WPS / Pages 均可打开。
- 兼容 Chrome / Edge / Firefox / Safari 等主流桌面浏览器，并做了响应式适配。
