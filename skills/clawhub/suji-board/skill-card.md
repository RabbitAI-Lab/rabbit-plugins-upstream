## Description: <br>
suji-board is a zero-dependency, local browser note board that helps users collect text fragments, manage pasted or dragged images, organize documents in folders, and export structured notes to Word .docx files. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Employees, external users, and developers use this skill when they need a local-first note board for collecting copied text, organizing attached images and files, and producing a Word document from fragmented notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Pasted notes, images, and selected files remain in the browser's local storage on the machine where the HTML app is used. <br>
Mitigation: Avoid storing sensitive material on shared machines and clear browser storage when the data is no longer needed. <br>
