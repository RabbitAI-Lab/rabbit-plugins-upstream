# 本地邮件摘要（Local Mail Digest）

本地运行的邮件摘要与待办提取工具。**数据不出电脑、零依赖（仅 Python 标准库）、可私有化**。

把一堆邮件变成一份结构化清单：优先级 / 项目分组 / 待办 / 截止日，并能推送到手机。

## 为什么
邮箱是待办黑洞。本工具不替你回邮件，只把「谁、什么主题、几号截止、要做什么」抽成一眼能扫完的清单，且全程在你电脑上跑，邮件不上传任何云。

## 特性
- 零依赖：仅 Python 标准库，无需 pip install
- 数据不出电脑：邮件本机处理
- 多源导入：宿主邮箱连接器（零配置）/ IMAP 直连 / 文本粘贴
- 智能分层：高/中/低优先级（语义判定：紧急 / 截止 / 需行动）
- 待办与截止日整句提取
- 可选本地 LLM 增强（真 AI 理解，失败自动降级）
- 输出 HTML / Markdown / JSON（供 Agent 框架消费）
- 手机推送：SMTP 发自己、企业微信 / 飞书机器人

## 快速开始
```bash
# 1. 宿主已连邮箱连接器 → 零配置
python host_adapter.py --emails-json emails.json --json 摘要.json

# 2. 自托管 IMAP（配一次授权码）
python digest.py --imap you@qq.com --json 摘要.json

# 3. 兜底：复制邮件文字存 txt
python digest.py --txt 邮件.txt --json 摘要.json
```

## 授权与隐私
- IMAP 直连需邮箱服务商提供的「授权码」（应用专用密码），非登录密码；配一次后永久自动。
- 默认不联网；仅当你主动接入本地 LLM 或手机推送时才出网。
- 本工具不读取、不上传你的邮件内容到任何第三方。

## 常见问题（FAQ）

**这个工具会把我的邮件上传到云端吗？**
不会。邮件只在你自己的电脑上处理，默认不联网。只有当你主动接入本地 LLM 或手机推送时才出网，且推送内容由你决定。

**邮箱太多处理不过来怎么办？**
连上邮箱（或复制邮件文字），它每天自动过一遍收件箱，输出一份清单：谁要你做什么、几点截止、红黄绿优先级。你只需扫清单，不用一封封翻。

**它和 Superhuman / Spark 这类邮件客户端有什么区别？**
那些是把邮件搬到它们的云服务里分析。这个是本地跑、数据不出电脑，且定位是「邮件→待办清单」的提取组件，可嵌进你自己的自动化，不绑定某个客户端。

**没有编程基础能用吗？**
能。借宿主邮箱连接器是零配置；IMAP 直连只需配一次邮箱授权码；最兜底的是直接复制邮件文字存 txt 跑。

**规则版和本地模型版差在哪？**
规则版用关键词+语义判定抽待办/截止/优先级，日常够用；接本地模型（Ollama/Hermes）升级为更深的理解，失败会自动降级回规则版。
