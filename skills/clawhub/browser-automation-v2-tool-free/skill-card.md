## Description: <br>
浏览器自动化(免费版) helps agents run lightweight single-page browser automation for opening pages, waiting for loads, extracting data, filling basic forms, retrying timeouts, and closing tabs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and individual automation users use this skill for authorized single-page data collection, page-summary extraction, timeout retry workflows, tab cleanup, and simple form-filling tasks. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill supports credentialed form submission, which can expose passwords or other sensitive data if used on untrusted sites. <br>
Mitigation: Review each task before execution, use only authorized sites, and require explicit confirmation before entering real credentials. <br>
Risk: Callback URLs can send browser automation results to external destinations. <br>
Mitigation: Use callback URLs only when the destination is trusted and appropriate for the data being processed. <br>
