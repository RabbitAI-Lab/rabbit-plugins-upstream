# 空窗期强对流潜势评估协议

> **定位**：本文件为**条件触发的参考协议**（非 SKILL.md 本体内容）——仅当满足触发条件（见"触发判定"）时加载执行。设计原则：SKILL.md 保持台风预测的单一职责与精简，日常强对流评估方法论独立存放，便于日后拆分独立 skill（如"日常天气预测"）。
>
> **来源**：2026-08-18 杭州强对流误判案例——常规天气预报渠道（官方App/网页）上午中午显示"无雨"，傍晚西湖区中南部突发短时暴雨；官方 16:18 雷电黄 + 16:27 暴雨黄才发布预警，且预警发出后**约 20 分钟**即开始降雨并迅速增强为暴雨（用户实测）。

## 能力边界（诚实声明，先讲清楚再给结论）

- **可做**：趋势性风险评估（T+12~24h）——判断"今天午后到傍晚对流触发条件是否成熟"，给出**四色潜势等级（🔵🟡🟠🔴）+ 时段窗口**
- **不可做**：精确落区/时次/量级预报（T+0~2h）——属雷达短临外推范畴，连市气象台也只能提前 1-2 小时点名到区；**官方预警发出后到实际降雨可能仅剩 20 分钟**（8/18 案例）。任何工具都无法提前 12h 预测"西湖区中南部今晚短时暴雨"。以官方短临预警为最终依据

**可预测性四层**（用于向用户解释"为什么报不准"）：

| 提前量 | 预报层级 | 能回答 | 不能回答 |
| --- | --- | --- | --- |
| T-72h~24h | 常规预报渠道（官方App/网页/工具/MCP） | 晴/多云/阵雨可能 | 落区·时次·量级（格点平滑抹掉局地对流） |
| T-12h~6h | 气象台趋势预报（午报层级） | 午后雷阵雨、局地短时暴雨的趋势 | 精确落区 |
| T-6h~2h | 临近预报 | 对流触发概率上升 | 落区仍模糊 |
| T-0~2h | 短临预警（雷达外推） | **精确点名到区/街道**；但预警→降雨可能仅剩 20min~2h | 官方预警即此机制 |

## 触发判定

以下条件**任一满足**即加载执行本协议：

1. 无活跃编号台风 + 无残涡影响（空窗期"简要说明"场景），且省/市气象台趋势预报含"阵雨或雷雨/局地短时暴雨"类表述
2. 用户询问"今天/今晚会下雨吗""为什么预报没雨却下雨"类日常强对流问题
3. 报告/回复中出现"多云、午后有分散性阵雨或雷雨"表述时（对照"典型形势"判断是否需升级提示）

## 强对流潜势五档等级（🟢正常起步，🔵🟡🟠🔴与官方预警颜色对齐）

**说明**：潜势等级是**预测性评估**（三要素成熟度推演），官方预警是**已发布事实**——两套体系颜色对齐便于用户理解，但含义不同：潜势 🟡 也可能因当日对流未触发而无预警；潜势 🟠 时应主动提醒"关注官方预警升级"。**🟢 为无风险档（官方预警色环无绿色，以 🟢 表示"无预警、正常天气"），🔵🟡🟠🔴 严格对应官方蓝/黄/橙/红预警级别。**

| 等级 | 名称 | 判据（三要素组合） | 输出含义 | 官方预警对照 |
| ---- | ---- | ---- | ---- | ---- |
| 🟢 绿 | 无/极低潜势（正常） | 要素普遍一般（如副高强控、湿度低、无抬升条件） | 正常天气，无对流风险，可正常安排 | 无预警 |
| 🔵 蓝 | 低潜势 | 要素偏弱但非全无（局地对流条件一般） | 局地零星雷阵雨可能，无明显风险 | 通常无预警，偶发雷电蓝警 |
| 🟡 黄 | 中潜势（默认） | 能量/水汽/抬升中-强组合，出现"午后分散性阵雨雷雨、局地短时暴雨"类表述 | 局地短时强降水/雷暴大风可能，落区离散 | 雷电黄/暴雨蓝黄 |
| 🟠 橙 | 高潜势 | 三要素显著（桑拿天+高湿+切变线/季风槽叠加），官方已提示"局部暴雨/雷暴大风" | 短时暴雨/冰雹/8-10级雷暴大风概率高 | 雷电橙/暴雨黄橙 |
| 🔴 红 | 极高潜势（罕见） | 极端能量+充足水汽+强抬升（如锋前暖区+强切变） | 极端短时强降水（1h 50mm+）/龙卷可能 | 暴雨橙红/强对流红 |

**等级判定锚点**：①三要素普遍一般、官方无对流提示 → 🟢；②官方仅"局部阵雨"无"短时暴雨"字样且三要素弱偏中 → 🔵；③报告出现"多云、午后有分散性阵雨或雷雨、局部短时暴雨"表述，潜势**默认至少 🟡**；④叠加"桑拿天/高湿/闷热"且官方口径出现"局部暴雨、雷暴大风"时升 🟠；⑤官方发布强对流橙/红预警或预报"极端短时强降水"时升 🔴。**不得仅转述"多云"二字而省略潜势等级（至少给 🟢/🔵 之一）。**

## 三要素简评

从省/市气象台预报文本提取，每项 1 行：

| 要素 | 判据 | 高风险信号 |
| ---- | ---- | ---- |
| 能量 | 副高控制强弱+午后最高气温 | 高温/桑拿天=不稳定能量累积；副高"根基不稳、环流浅薄"时对流暗流涌动 |
| 水汽 | 相对湿度/闷热程度 | 湿度居高不下、体感闷热=低层水汽充足 |
| 抬升 | 切变线/辐合/地形/午后加热 | 副高边缘+季风倒槽+午后热力抬升叠加 |

## 输出模板

- **强对流潜势**：🟢/🔵/🟡/🟠/🔴 + 三要素简评各 1 行 + 时段窗口（如"午后到傍晚 14-20 时"）+ 一句"精确落区以官方短临预警为准；预警发出到降雨可能仅剩 20min~2h"
- **铁律**：潜势 ≥ 🟡 时，显式写"**常规天气预报渠道（官方App/网页）显示的'无雨'不代表安全——午后对流局部突发、落区离散，关注气象台临时预警**"，覆盖用户的认知盲区
- **冲突核查**：比较常规预报渠道显示（晴/多云）与官方趋势预报（阵雨雷雨）——不一致时**以官方趋势为准**并显式提示"App 显示无雨但官方趋势有对流风险"

## 典型形势对照

副高边缘"晴热+午后雷阵雨"是华东夏季最经典的对流配置（2026-08-18 杭州即此类），潜势默认 🟡 起步；副高南侧季风槽逼近（8/19-23 浙江沿海多雨期）时浙南/沿海升 🟠，杭州为边缘波及维持 🟡。

## 常规预报渠道"无雨"误判机制（解释用）

1. **格点平滑**：常规渠道"今日天气"来自数值模式格点预报（9km+），对流是局部突发短时的，网格平均后显示"多云"
2. **不展示短临产品**：主界面只放 24h/48h 常规天气现象，0-6h 雷达外推在二级页面或需主动查询
3. **中午确实无法报**：对流云团当天午后加热+水汽辐合才触发，中午只有条件概率
4. **预警-降雨时间窗极短**：即使官方短临预警发出，到实际降雨可能只剩 20min~2h（8/18 案例=20 分钟）——**想提前规避，唯一抓手是上午/中午的趋势预判（五档潜势），把心理预期从"无雨"调到"傍晚可能突袭"**

## 案例复盘（2026-08-18 杭州·误判根源案例）

- 08:00/14:00 浙江气象口径：全省多云、午后有分散性阵雨或雷雨、**有雷雨地区局部有短时暴雨**——趋势方向正确
- 16:18 杭州市气象台雷电黄色预警；16:27 暴雨黄色预警（点名滨江区、西湖区中南部、拱墅区、上城区傍晚前后短时暴雨）——短临仅提前 1-2h
- **16:27 预警发出后约 20 分钟，西湖区用户观测位置开始降雨并迅速增强为暴雨**（用户实测，极端但真实）——官方预警到降雨的极限提前量实证
- 差距本质：趋势风险提示在报告中淹没于常规表述，未升级为醒目"强对流潜势🟡+时段窗口"，用户被常规渠道"无雨"带走——**输出格式问题，非能力问题**

## 案例复盘（2026-08-19 杭州·晨报）

- **评估（08:13 执行，06:00 时段）**：天气态=空窗期（CMA 无活动台风，编号清零第 6 天；92W/94W/95W 未编号）；强对流潜势 🟡（午后到傍晚分散性阵雨/雷雨、局地短时暴雨可能；三要素：能量中-强/水汽充足/抬升=午后热力+季风槽逼近）；时段窗口=午后 14-20 时 + 后半夜季风槽降水启动；铁律提醒"App 无雨≠安全"触发
- **待验证**：①午后对流是否如评触发（对照 8/18 案例——App 无雨但 16:18 雷电黄/16:27 暴雨黄点名）②后半夜季风槽降水是否按预报启动 ③8/20 杭州多雨时段（部分中雨、阵风 5 级）强度验证
- **背景**：8/19 起杭州进入一轮较长时间多雨时段（19 日后半夜启动→20-22 集中→23-24 减弱）；浙江降雨核心区为浙南和沿海（局地暴雨），杭州为边缘波及；无冷空气，闷热持续
- **模式三执行要点记录**：晨报侧重当日全天趋势+午后到傍晚对流潜势；本次评估用"中央气象台强对流展望+浙江省气象台+市气象台"三源交叉（1 次 WebFetch + 4 次 WebSearch）

## 案例复盘（2026-08-19 杭州·午报 → 天气态切换）

- **执行（12:45，14:00 时段）**：天气态=**切回模式一**——CMA 台风网 8/19 11时收录新编号**2618 沙德尔**（热带风暴 18m/s），空窗期终结（8/18 记忆"8/19-21 关键窗口"兑现）；沙德尔由 92W 发展，位于关岛东南约 1000km（约 8-10°N/150°E），距我国沿海 3000km+，当前无直接影响
- **晨报 🟡 评估延续核查**：午报仍维持杭州今日午后局部对流潜势 🟡（33-34℃ 桑拿天+高湿+东风波边缘抬升），并叠加"后半夜降水启动"时段（19 日后半夜季风槽/东风波降水上线，20 日转明显）；中央气象台强对流预报点名浙江东部短时强降水（20-50mm/h 局地 70+）佐证
- **三要素简评（午报复核）**：能量=中-强（34℃+闷热累积，副高边缘不稳）；水汽=充足（湿度高，体感闷热）；抬升=午后热力+东风波/季风槽边缘辐合，**三要素维持 🟡 级组合，未升级 🟠**
- **待验证**：①今日午后至傍晚对流是否触发及落区（对照 8/18 案例预警-降雨 20min 窗口）②后半夜降水启动时点 ③8/20 东风波"部分中雨、阵风 5 级"强度
- **切换记录价值**：本案例为"空窗期→台风期"自动切换的首次实证——晨报模式三（空窗期）+午报模式一（台风追踪）同日衔接，说明双模式判定应"以 CMA 台风网实时列表为准"，任一时刻有新编号即切换，无需等待下一周期

## 与台风追踪的关系

空窗期强对流多由季风槽/偏东气流/副高边缘触发，与台风残涡系统是**两套机制**（教训⑤：空窗期强对流≠台风影响）。台风追踪报告引用本协议时，须先声明"非台风系统"，再按本协议评估，避免套用台风研判框架系统性高估风险。

## 定时任务执行规范（模式三：空窗期天气研判）

**背景**：2026-08-19 起，原三个台风追踪定时任务升级为"气象研判"双模式（台风期执行模式一/二，空窗期自动切模式三）。本协议即模式三的执行依据。

**触发与切换**：任务先查 CMA 台风网——有追踪中编号→模式一（台风追踪）；无编号但残涡/残余降雨实质影响重点城市→模式二（残涡追踪）；无编号且无残涡影响→**本模式**（同时顺带核查是否已有新编号，若有立即切回模式一）。

**采集清单**（每次 1-2 次搜索覆盖）：

1. 浙江省/杭州市气象台当日及次日预报（趋势）——中国天气网省级/市级页面或 WebSearch
2. 中央气象台预警列表——确认重点城市无生效暴雨/山洪/地灾预警；顺带查新台风编号
3. 常规预报渠道冲突核查——若用户提及/已知常规渠道显示"无雨"而官方趋势有对流风险，显式提示"以官方趋势为准"

**三时段侧重点**（配合每日 06:00/14:00/20:00 三次任务）：

| 时段 | 侧重点 |
| ---- | ---- |
| 晨报 06:00 | 当日全天趋势预判，重点评估午后到傍晚对流潜势（五档等级） |
| 午报 14:00 | 午后到傍晚对流触发窗口（强对流误判高发时段，三要素是否成熟、潜势是否升级） |
| 晚报 20:00 | 夜间至次日凌晨降水/大风（冷空气南下常夜间加强），回看当日实况验证潜势命中率 |

**输出规范**（聚焦杭州市西湖区）：

- 内容：当日实况与趋势（温度/云量/风向/湿度）；强对流潜势评估（三要素简评 + **五档等级🟢🔵🟡🟠🔴** + 时段窗口）；突发阵风/降雨预警提示（含"常规预报渠道'无雨'不代表安全"铁律，适用时）；冷空气/系统性大风降雨提示（如有）；台风空窗状态一句话
- 文件名：`杭州西湖区_[月日]_[时分]_天气研判.md`（如杭州西湖区_0819_1400_天气研判.md），保存 workspace 根目录
- 潜势 ≥ 🟡 时标题加 `⚠️`；≥ 🟠 时建议加"关注官方预警升级"提醒
- 每次执行后追加实测数据到本文件"案例复盘"节（含：评估五档等级 vs 当日实况对照）

**迭代要求**：本模块处于真实使用验证期——每次执行检查：①三要素判据是否有效（潜势等级 vs 实况命中率）②时段窗口是否准确 ③是否有常规预报渠道与官方趋势冲突案例 ④五档等级划分是否贴合实际（是否过松/过紧，🟢/🔵 分界尤其要验证）。发现问题即更新本文件或 SKILL.md 触发指针。
