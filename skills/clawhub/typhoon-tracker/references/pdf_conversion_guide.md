# PDF 转换指南（PDF Conversion Guide）

> **定位**：本文件为**条件触发的参考协议**（非 SKILL.md 本体）——仅当用户明确要求将 Markdown 转为 PDF 时加载执行。设计原则：PDF 转换是**可选需求**，非每次追踪的常驻流程，故详细命令、参数、避坑清单与自查规范下沉本文件，SKILL.md 本体只保留触发入口（轻指针）。
>
> **调用方式**：当用户触发 PDF 转换（"转pdf/导出pdf/生成pdf"等）时，加载本文件并按其执行。依赖脚本 `scripts/generate_pdf.py` 位于 skill 目录。

## 触发条件

用户明确要求将 Markdown 转为 PDF 时触发。

用户触发词（任一即可）：

- "转pdf""转成pdf""导出pdf""生成pdf""输出pdf"

## 执行方式

调用 skill 目录下的 `scripts/generate_pdf.py`：

```bash
python scripts/generate_pdf.py <输入.md> [-o <输出.pdf>] [--title ...] [--subtitle ...] [--author ...] [--date ...]
```

## 参数说明

- `input`：Markdown 文件路径（必填）
- `-o/--output`：输出 PDF 路径（默认与输入同名换 .pdf 后缀）
- `--title`：封面标题（默认从 Markdown 一级标题提取）
- `--subtitle`：封面副标题（默认从第二个一级标题提取）
- `--author`：封面作者（默认"user"）
- `--date`：封面日期（默认系统当前日期）
- `--image-dir`：图片搜索目录（默认 Markdown 文件所在目录）

**依赖**：`pip install markdown pygments playwright pypdf && playwright install chromium`

## 执行流程

1. 确认目标 .md 文件存在
2. **检查 Markdown 格式**（见下方"PDF生成格式避坑指南"，避免渲染异常）
3. 执行 `generate_pdf.py`
4. 通过 present_files 展示生成的 PDF

## PDF生成格式避坑指南

`generate_pdf.py` 基于 Python-Markdown + Playwright/Chromium 渲染，部分 Markdown 语法在 PDF 中渲染异常。**生成 PDF 前必须检查以下格式问题：**

**1. 禁用引用块（`>` 开头）——改用普通段落**

引用块中多行连续文本在 PDF 中可能不换行，导致内容挤在一行。

❌ 禁止：

```markdown
> **生成时间**：2026年8月9日 01:17 CST
> **数据截止**：CMA 8/8 18时橙色预警
> **核心目的**：快速提取信息
```

✅ 改为：

```markdown
**生成时间**：2026年8月9日 01:17 CST

**数据截止**：CMA 8/8 18时橙色预警

**核心目的**：快速提取信息
```

**关键**：字段间用**空行**分隔，确保 PDF 正确换行。

**2. "加粗标题+冒号"后跟列表——必须加空行**

`**标题**：` 后直接跟 `-` 列表（无空行）时，PDF 可能将列表项粘连成一段。

❌ 禁止：

```markdown
**⚡ 关键信息**：
- 第一项
- 第二项
```

✅ 改为：

```markdown
**⚡ 关键信息：**

- 第一项
- 第二项
```

**关键**：`**标题**：` 后**加空行**再写列表项。冒号可放在加粗内部或外部，但列表前必须有空行。

**3. 列表前后必须有空行**

所有 `-` 列表和 `1.` 有序列表的前一行和后一行都必须是空行，否则 PDF 渲染时列表可能被并入前段。

**4. 表格前后建议加空行**

表格前后的空行虽非强制，但加上可避免表格与前段文本粘连。

**5. 案例**

- 问题：精简研判报告 PDF 中引用块未换行、加粗标题后列表粘连
- 修正：去掉所有 `>` 引用块 → 普通段落+空行；所有列表前加空行
- 结果：PDF 渲染正常

**自查清单（生成 PDF 前过一遍）：**

- [ ] 文档中无 `>` 引用块（全文搜索 `>` 开头行）
- [ ] 所有 `**标题**：` 后跟列表的地方，列表前有空行
- [ ] 所有列表前后都有空行
- [ ] 表格前后有空行（建议）
