当需要确认当前部署环境的网络可达性、定时任务能力和媒体支持时加载此文件。结合 SKILL.md 的"三层搜索策略"安全降级。

## 容错策略

1. **超时阈值**：WebFetch/WebSearch 对国际源设置 **10秒超时**，超时即跳过
2. **跳过并降级**：国际源访问失败时，跳过该源，不阻塞流程
3. **降级说明**：在报告中标注"（JMA/JTWC等国际源未获取，交叉验证覆盖降低）"
4. **置信度调整**：国际源全部不可用时，路径预报置信度上限降为"中"
5. **替代方案**：国际源不可用时，通过 WebSearch 搜索国内媒体对国际预报的引用，间接获取国际源信息

## 环境判断规则

- **不确定时**：先尝试访问一个国际源（如JMA），成功则假设国际源可用，失败则切换到国内源优先模式
- **PC客户端环境**：假设可访问全部源（用户已配置代理或无限制）
- **国内服务器环境**：假设国际源可能受限，优先使用国内源+间接引用
- **移动端/飞书环境**：云端处理，国际源可达性取决于云端服务器位置；输出适配为文本格式

## OpenClaw 国内服务器搜索降级（实测 2026-08-06）

**实测发现**：腾讯云 OpenCloudOS 上部署的 OpenClaw，其内置 `web_search` 工具使用 DuckDuckGo provider，**在国内服务器直连下超时/不可用**（DuckDuckGo 被墙）。但 `web_fetch` 工具可直连国内源（CMA、省市气象台、12306、cn.bing.com 均返回 200）。

### 降级策略（国内服务器部署时强制生效）

当 `web_search` 连续 2 次超时或返回 error 时：

1. **切换为 WebFetch 直连搜索**：用 `web_fetch` 访问 cn.bing.com 搜索页替代 web_search：
   ```
   https://cn.bing.com/search?q=[URL编码的搜索词]
   ```
   实测 cn.bing.com（200）、so.com（200）在国内服务器直连可用。

2. **优先 WebFetch 国内权威源**（替代搜索的可靠数据源）：
   - CMA 台风网：`https://typhoon.nmc.cn/web.html`（直连 200）
   - CMA 公报：`https://news.weather.com.cn` 
   - JMA：`https://www.jma.go.jp/bosai/typhoon/index.html`（实测可直连）
   - 省市气象台官网、12306、地铁官网（国内源全部直连可用）

3. **置信度调整**：web_search 不可用但 WebFetch 直连国内源成功时，数据完整性不受影响；仅当国际模型对比（GFS/ECMWF）无法获取时，路径预报置信度上限降为"中"。

4. **报告标注**：如所有搜索手段均受限，报告中标注"（国际源未获取，交叉验证覆盖降低）"。

5. **不要重复重试**：web_search 失败 2 次即切换方案，避免浪费循环时间。
