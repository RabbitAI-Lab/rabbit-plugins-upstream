## Description:

Guides a pre-mortem by imagining a plan has failed, ranking possible causes, and defining mitigations before a commitment.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ysskrishna](https://clawhub.ai/user/ysskrishna)

### License/Terms of Use:

MIT-0

## Use Case:

Project teams and decision-makers can use this skill before a launch, migration, or other hard-to-reverse commitment to identify and rank plausible failure causes, define mitigations, and set decision tripwires.

### Deployment Geography for Use:

Global
