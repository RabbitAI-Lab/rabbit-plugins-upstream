## Description:

Helps plan Haokan video topics by reviewing relevant videos, titles, and comments and producing evidence-backed topic ideas.

This skill is ready for commercial/non-commercial use.

## Publisher:

[devinchen2014](https://clawhub.ai/user/devinchen2014)

### License/Terms of Use:

MIT-0

## Use Case:

Content creators and marketing analysts use this skill to identify Haokan video topics, compare content angles, and incorporate audience feedback into a prioritized topic list.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The examples execute the latest SocialDataX npm package with access to the user's API key.

Mitigation: Trust the package source before installation, use a limited environment, and pin the package version where possible.

Risk: Small samples or hot-search terms may be mistaken for platform-wide trends or video performance.

Mitigation: Label hot-search terms as leads, report sample size and missing data, and avoid unsupported performance claims.
