# Checklist — Results 衔接与连贯检查清单（23 项）

用法：逐项判定 通过 ✅ / 不通过 ❌ / 不适用 N/A；不通过项记入诊断报告。
正例措辞参照各维度后的范式句（均出自 examples.md 溯源例句）。

## D1 连接词与过渡语（5 项）

1. □ 每个追加同类结果的句子是否有追加标记（Additionally / Moreover / also / We also observed…）？
2. □ 每个与前文相反或例外的结果是否有对比标记（In contrast / however / Conversely / Nevertheless / but not），且对比双方结构平行？
3. □ 假设检验结果是否用过渡语锚定假设（In line with Hypothesis 1a… / Contrary to Hypothesis 1b…）？
4. □ however / therefore / thus 的每次使用是否与真实逻辑关系一致（转折处有反转、因果处有依据），无误用？
5. □ 是否存在过渡语堆砌（连续两句以上以 Moreover/Furthermore/Additionally 开头）？若有，标记为问题。

## D2 句间衔接（6 项）

6. □ 每个 this/these/such 是否带名词（these scores / such effects / this cluster）且先行对象唯一明确？
7. □ 每个裸 it/they 的先行词是否在最近一句内且无歧义候选？
8. □ 核心术语是否在 Results 全节保持一致（同一概念不换名），必要的同义复现（these results → our findings）是否可追溯？
9. □ 所有缩写是否首次出现时给出全称定义（如 constrained intermediate model (CIM)），之后直接使用缩写？
10. □ which 关系从句是否紧邻其先行成分，指代无歧义（如 "…integration (p<0.001) questions, which did not differ from each other"）？
11. □ 是否存在连续 3 句以上无任何衔接手段（无连接词、无指代、无词汇复现）的段落？若有，标记为问题。
11b. □ 每个带定冠词/定指的概念（The Stroop effect / the P300 / our hypothesis）首次出现时是否已被引入（presupposition check）？未引入即定指 = 指称预设失败，标记为问题。

## D3 段落连贯（6 项）

12. □ 每个 Results 段落首句是否为主题句，明示本段分析目的（To test whether…, we conducted… / Next, we examined… / We aimed to identify…）？
13. □ 每个小节的开头是否先承接上一小节结论再引出本节任务（Having shown that…, we further examined… / The above behavioral results showed…, We then turned to…）？
14. □ 段内各句是否都服务于段首主题句声明的目的，无中途偏题？
15. □ 段内推进是否遵循可预测顺序（总→分、总体检验→follow-up 检验、目的→手段→结果）？
16. □ 较长段落（≥5 句）段末是否有收束句（Taken together… / Overall… / These results support our hypothesis that…）？
17. □ 段首假设与段末结论是否呼应（hypothesized → support our hypothesis，形成环形结构）？

## D4 信息流（5 项）

18. □ 各句是否遵循 given→new：句首为已引入信息、句尾为新发现？
19. □ 是否存在新信息（未引入的术语/条件/脑区）突然出现在句首造成话题断裂的句子？若有，标记为问题。
20. □ 平行列举（多个条件/脑区/题型）的讨论顺序是否与前文首次引入的顺序一致？
21. □ 开启新子话题时是否有过渡标记或元话语（Here we report… / With this approach… / 设问句 + To test this…）？
22. □ 图表引导句是否承接前句刚引入的信息（如 "Variability … is illustrated in Fig. 3" 以旧信息作主语）？
