## Known Risks and Mitigations:

Risk: Medical DICOM files can contain sensitive health information.

Mitigation: Use the skill only with files the user has provided or explicitly authorized, and do not send DICOM content to external services without separate approval.

Risk: The skill is a very general DICOM reasoning aid and may be insufficient for clinical or regulated workflows.

Mitigation: Add workflow-specific safeguards, validation checks, and appropriate expert review before using outputs in clinical or regulated settings.
