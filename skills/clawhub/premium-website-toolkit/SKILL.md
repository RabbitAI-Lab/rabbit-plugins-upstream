# Premium Website Toolkit

## Headline

Check a Website Against Premium Standards, Then Pick the Right Toolkit, in Plain Words

## Hook

Give your AI agent one website. It checks the site against a premium bar, in plain words, then tells you which toolkit picks fit that site, and why, with a fix draft for owner review.

## Pain, in plain words

Most AI built websites look the same. A purple gradient, a centered headline, and three cards in a row. The layout looks finished, but it does not look premium, and it does not look like a real business. The fix is not more decoration. The fix is a clear bar first, then the right tools for that site only.

## What you get

A premium check for one website, then toolkit picks for that site only. The check covers layout, color, motion, components, and copy. The picks cover six areas: design MCPs, slop removal patterns, animation libraries, SVG asset generators, color palette visualizers, and UI component libraries. It gives you a fix draft to review, never a changed live site by itself.

## Who this is for

People who build websites with an AI agent, for a small business, and want the site to look premium, polished, and liveable. People who run a business website, and want to know what looks cheap on it, and what to change first. People who want tool picks for one site, not a long list of tools to learn.

## Why this saves money

A premium check stops you from rebuilding a whole site when only a few things look cheap. A short pick list stops you from buying, or learning, tools you do not need for this site. A fix draft, reviewed first, stops a live site from changing in a way the owner did not approve.

## Technical, for coders

Structured premium check and toolkit pick guide for one website: premium bar checks, slop tells, layout, color, motion, component, and copy checks, plus toolkit picks in six areas, ready to brief any AI agent, or a human builder. No guarantee of more sales, more visitors, or a higher rank, and no claim that a toolkit pick alone makes a site premium. The fix draft is for owner review, not a live change.

## Purpose

Check one website against a premium bar, then give toolkit picks that fit that site, with a fix draft for owner review. The skill checks first, then picks, then drafts. It does not change a live site, publish anything, or buy a tool, without a separate approval from the owner.

## How to use it

Fast path: If the user already gives the site URL, the goal of the site, and the audience in the first message, do NOT ask a long list of questions first. Do the full premium check and the toolkit picks in the SAME reply, then the fix draft. Never stop at questions alone.

Step 1: run the premium check, and list each check as Pass, Fail, or Not confirmed, with evidence.
Step 2: list the slop tells found, with evidence from the site.
Step 3: give toolkit picks for this site only, one pick per area that fits, with a plain reason for each pick.
Step 4: write the fix draft, labelled DRAFT, NOT SENT, with owner approval needed.
Step 5: run the missing checks at the end, and list what is complete, missing, or not confirmed.

Ask only what is missing, in plain words, one short list at a time:
1. What is the site URL, or paste the page text, in plain words?
2. What is the goal of the site, sell, book, call, or show work?
3. Who is the site for, in plain words?
4. What does premium mean for this business, in plain words, or use the bar below?
5. What is the one page, or the one section, to check first, or the whole site?
6. What tools, if any, does the site already use, or Not confirmed?

If the user does not know an answer, mark it Not confirmed, and use the most common answer for that business type, and say so, marked Suggested, not confirmed. Do not invent an answer. If the user says use the live site for a question, use only what is visible on that site, and say so.

## The premium bar, in plain words

This is the bar every check is judged against. A site passes only if the evidence shows it.
1. No purple gradients. A gradient that looks purple and black, or purple and blue, is a slop tell.
2. No centered headline plus three cards cliche. A centered headline, then three cards in a row, is a slop tell.
3. Premium, polished, and liveable layout. The page looks like a real business made it, not a template filled in.
4. Project details as statistics. Real work is shown with real numbers, in the same format everywhere on the site.
5. Strictly consistent number formatting site wide. One format for numbers, one size system, everywhere.
6. One color palette, used the same way on every page. No new color on each section.
7. Motion with a purpose. Animation helps the visitor read, or act. It does not move for its own sake.
8. Consistent components. Buttons, headings, spacing, and cards look the same everywhere they repeat.
9. Clean SVG assets. Shapes and icons fit the brand, and do not look like stock decoration.
10. Plain copy, in the voice of the business. Short sentences, simple words, no fancy words, no claim the business did not make.

## Slop tells

List every slop tell found, with evidence. A slop tell is a sign the site was built by AI with no human check.
- Purple gradient, or purple and black palette.
- Centered headline plus three cards in a row.
- Bento grid with no real content inside it.
- Emojis in headings.
- Liquid glass effects on every section.
- Dot grids, radial orbs, or sparkle icons with no purpose.
- Animated arrows, or hover animations on everything.
- Copy that says it is not X, it is Y.
- No real demo, no real photo, no real project shown.
- Rainbow coloring, or a new color on each section.

For each tell found, say where it is on the site, in plain words, and what the fix draft changes. If no tell is found, say so, with evidence, do not invent one.

## Toolkit picks, current picks dated 12 Nov 2026

Tool lists go stale fast. The picks below are current picks dated 12 Nov 2026, not a permanent list. Check the tool's own page before using it, and say what you found there. Do not use a tool only because it is on this list.

The six tool names visible in the source reels are: Animaster, Skiper UI, Vengeance UI, Motion Primitives, Haikei, Realtime Colors. Do not add a tool name that is not on this list. Do not state a tool's price, link, or feature unless you checked the tool's own page first, and say so.

Give picks in these six areas, one pick per area that fits this site, or say Not needed for this site:
1. Design MCPs: what the site needs from a design tool, in plain words, and which named tool fits, if one fits.
2. Slop removal patterns: which slop tell to remove first, and the pattern to use instead, in plain words.
3. Animation libraries: what motion the site needs, if any, and which named tool fits, if one fits.
4. SVG asset generators: what shapes or icons the site needs, and which named tool fits, if one fits.
5. Color palette visualizers: what the palette check found, and which named tool fits, if one fits.
6. UI component libraries: which components repeat on the site, and which named tool fits, if one fits.

For each pick, give a plain reason, in one line: what it fixes on this site, and what it does not fix. A pick that fits no check on this site is Not needed, and must not be added to look complete.

## Hard rules

- Never mark Pass without evidence.
- Never invent a tool name, a price, a link, a stat, a partner, a testimonial, or a result.
- Never claim a tool does something unless you checked the tool's own page, and say so.
- Never change a live site, publish anything, or buy a tool, without a separate approval from the owner.
- Never use a real business as an example. Examples in this skill are fictional, labelled Example only.
- Suggested items must be marked Suggested, not confirmed.
- A fix draft is not a promise of more sales, more visitors, or a higher rank.
- Keep the draft in plain, short sentences. The owner may not be a technical reader.
