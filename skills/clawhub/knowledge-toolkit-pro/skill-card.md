## Description:

知识工具包（专业版） helps agents capture, organize, connect, search, import, and export knowledge notes using Zettelkasten-style workflows.

This skill is ready for commercial/non-commercial use.

## Publisher:

[thcjp](https://clawhub.ai/user/thcjp)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to turn source material into structured notes, maintain linked knowledge bases, search content, and run batch import/export workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill requests broad file search/read authority and command execution for knowledge-management work.

Mitigation: Install only when that authority is acceptable, scope use to an explicit vault or project directory, and avoid broad automation prompts.

Risk: Batch import, export, callback, API, and command-running workflows may affect many files or external systems.

Mitigation: Confirm batch operations, exports, callback URLs, API calls, and command execution before proceeding.
