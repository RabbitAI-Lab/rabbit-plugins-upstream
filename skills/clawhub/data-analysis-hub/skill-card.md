## Description:

数据分析理调 provides a methodology-first data analysis framework for statistical rigor checks, analytical pitfall detection, approach selection, output standards, and escalation of risky findings.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External users, developers, and analyst teams use this skill to guide data analysis tasks, report generation, statistical interpretation, data visualization planning, and method selection. It is intended for structured analytical guidance rather than real-time streaming data processing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The release evidence reports that the skill declares write and command-execution capabilities beyond its documented data-analysis guidance purpose.

Mitigation: Review before installation; prefer a version that removes exec and write permissions or documents exact commands, file changes, approvals, and safeguards.

Risk: Data-analysis guidance can still lead to misleading conclusions when sample size, confounders, multiple comparisons, or causal assumptions are not checked.

Mitigation: Require the skill's statistical rigor checks, uncertainty reporting, and escalation steps before using outputs for decisions.
