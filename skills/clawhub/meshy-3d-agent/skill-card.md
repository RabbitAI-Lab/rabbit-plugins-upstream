## Description:

Creates and prepares 3D models for digital use and physical printing, including texturing, rigging, animation, conversion, printability repair, and slicer handoff.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, creators, and makers use this agent to generate or modify 3D assets, create animations, and prepare models for physical printing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts, selected input files, and task requests are sent to Meshy for processing.

Mitigation: Only submit inputs you are comfortable sharing with Meshy.

Risk: Cloud processing can consume Meshy credits.

Mitigation: Set a budget and confirm the intended paid stages before creating assets; treat a plan refusal as a stop.

Risk: The separately installed Meshy CLI's runtime security guarantees are unverified.

Mitigation: Review and approve the CLI installation and account access before use.
