## Description:

Creates and prepares 3D models, textures, animations, reference images, and assets for 3D printing with the Meshy CLI.

This skill is ready for commercial/non-commercial use.

## Publisher:

[arlieeee](https://clawhub.ai/user/arlieeee)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to generate, convert, texture, rig, or animate 3D assets and prepare models for 3D printing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: ClawScan marks the release suspicious with medium confidence, citing global CLI installation without approval, an API-key option that conflicts with the stated browser sign-in method, and missing disclosure before user content is sent to Meshy.

Mitigation: Require approval before global installation, clarify or remove the API-key authentication option, and disclose before sending descriptions, images, or model files to Meshy.

Risk: The scan was partial because several local references could not be resolved.

Mitigation: Review the unresolved references and repeat the security scan before relying on its result.
