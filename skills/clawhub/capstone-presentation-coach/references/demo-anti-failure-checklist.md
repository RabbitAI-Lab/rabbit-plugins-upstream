# Demo Anti-Failure Checklist

## T-minus 1 hour (pre-run checklist)

- [ ] Battery fully charged (and charger packed)
- [ ] Latest firmware flashed and verified
- [ ] All wiring solid; no loose jumpers
- [ ] Demo environment ready (network / host app / phone pairing)
- [ ] Spare USB cable packed
- [ ] Backup demo video on the presentation laptop AND in the cloud
- [ ] Slides page numbers verified; backup slides after the thanks page

## Demo narration structure

1. Before: one sentence — "You are about to see [the feature] demonstrated [condition]."
2. During: point at the hardware — "this step is the [sensor] working; you can see [signal] on the [display/serial]."
3. After: bridge to data — "the numbers you just saw match the results on the testing slide."

A silent demo is a wasted demo. Narration is half the score.

## Crash lines (when it truly fails on stage)

Stay calm. Say: "The rig ran [X hours] continuously before this session; this room may have [interference]. I recorded the full demonstration earlier — let me play it."

Then play the video. Honesty + preparation = bonus points. Panic + improvisation = the opposite.

## Degraded-mode plans (prepare in advance)

| Demo dependency | Degraded mode |
|------|------|
| Cloud connectivity | Local offline mode with cached data |
| Phone app | Spare phone with everything pre-paired, or a screen recording |
| Camera/vision | Pre-captured input images processed live |
| Motors under load | Reduced load / lower speed variant that still shows control quality |
