## Description:

Use this skill for Gupshup requests to read, create, and update data through the connected account.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

Users use this skill to list Gupshup message templates and send text or approved template messages through a connected account.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup directs the agent to execute downloaded installer code without clear user approval.

Mitigation: Review the installer and approve its execution separately before running it.

Risk: Messages sent through the connected Gupshup account may reach unintended recipients or contain unintended content.

Mitigation: Approve the recipient and exact message content before sending.
