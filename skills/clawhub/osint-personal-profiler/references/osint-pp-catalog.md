### D1 目标发现与源映射域

| ID | 任务类型 | 说明 | 依赖 | 元操作映射 |
|----|---------|------|------|-----------|
| D1-01 | 目标身份确认 | 从最小识别信息（姓名/昵称/邮箱/手机号）初步确认目标身份，识别同名歧义风险 | 无（入口） | S→C |
| D1-01B | 标识符强度分级与消歧 | 对输入的识别信息按强度分级（强标识符=手机号/邮箱/身份证/精确URL，中标识符=姓名+公司/学校/城市，弱标识符=仅姓名/常见昵称）。强标识符可唯一锁定；中标识符需组合确认；弱标识符触发消歧流程（列出候选+请求用户补充强标识符） | D1-01 | C→I |
| D1-02 | 公开信息源发现 | 按8级搜索查询模板跨平台搜索：①手机号精确→②邮箱精确→③用户名派生（从邮箱前缀/昵称派生出跨平台用户名搜索）→④姓名+公司→⑤姓名+城市→⑥site:平台限定→⑦深搜已有源（在天眼查等已命中平台中深入股东/高管/变更记录挖掘个人关联）→⑧可选增强（反向图片搜索百度识图/Google Images、Wayback Machine缓存搜索）。覆盖10类平台；输出信息源地图 | D1-01B | S→O |
| D1-03 | 信息源优先级排序 | 按信息密度（高/中/低）和可信度（高/中/低）对源进行排序，生成收集优先级矩阵 | D1-02 | C→O |

## 依赖拓扑摘要

### 域内链路

**目标发现链路**: D1-01 → D1-01B → D1-02 → D1-03
**实体层上半链路**: D2-01 → D2-02 → D2-03（维2依赖维1上下文，维3依赖维1推断）
**实体层下半链路**: D3-01, D3-02, D3-03（维4-6相对独立）
**社会层链路**: D4-01 → D4-02（层级推断依赖关系网络）
**抽象层链路**: D5-01 → D5-02 → D5-03 → D5-04（能力→功能→动机→动态，逐层递进）
**跨源关联链路**: D6-01 → D6-02 → D6-03
**画像组装链路**: D7-01 → D7-02‖D7-03 → D7-04

### 跨域协同链路

**主收集管线**: D1-03 → D2-01‖D3-02 → D4-01 → D5-01 → D6-01 → D7-01 → D7-04
**并行分支**: D2 和 D3 可并行执行（实体层上下半独立）
**守护贯穿**: G操作贯穿整个管线（每步收集前检查法律边界）
**迭代反馈**: D6-03（缺口）→ D1-02（发现新源）→ 补充收集
**消歧反馈**: D1-01B（弱标识符无法锁定）→ 请求用户补充强标识符

### 三轴协同链路

**执行轴+创新轴**: 推断引擎（D5）调用创新轴的模式迁移（从已知模式推断未知维度）
**执行轴+内容轴**: 收集过程使用清单法（12维为固定Schema），输出使用样本法（参考exemplars）
**三轴全开**: 复杂目标→创新推断→结构化填表→守护验证→输出
