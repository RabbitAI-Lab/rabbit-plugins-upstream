## Known Risks and Mitigations: <br>
Risk: The skill can surface destructive, disruptive, or offensive security commands in ordinary administration contexts. <br>
Mitigation: Review every command before use, restrict execution to authorized systems, and avoid blindly running examples for packet capture, scanning, deletion, secure wipe, shell profile changes, breach search, or exploit-related workflows. <br>
Risk: The refresh script can replace reference content from an upstream repository. <br>
Mitigation: Use the refresh script only when the upstream content is trusted and reviewed for the specific release. <br>
