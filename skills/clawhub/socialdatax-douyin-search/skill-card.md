## Description:

Helps agents search Douyin trending topics, videos, image posts, and creators for content and competitor research using SocialDataX.

This skill is ready for commercial/non-commercial use.

## Publisher:

[devinchen2014](https://clawhub.ai/user/devinchen2014)

### License/Terms of Use:

MIT-0

## Use Case:

Researchers, marketers, and developers use the skill to explore Douyin trends, find relevant posts and creators, and summarize observable content and competitor signals.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill runs the current latest npm package while using a SocialDataX API key, exposing users to supply-chain changes.

Mitigation: Prefer a pinned, reviewed package version or a trusted preinstalled CLI before providing the API key.
