## Known Risks and Mitigations:

Risk: Search terms are sent to SocialDataX and may expose sensitive query intent.

Mitigation: Avoid confidential or personal search terms.

Risk: API usage may incur charges.

Mitigation: Check account pricing and use page or item limits for searches.

Risk: The CLI package and its dependencies introduce software supply-chain and execution risk.

Mitigation: Prefer an exact reviewed CLI version over @latest and run it with only the credentials and filesystem access it needs.
