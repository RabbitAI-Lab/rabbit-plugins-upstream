## Description:

Helps agents research Douyin hot searches, posts, creators, and content trends using SocialDataX.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Content researchers, marketers, and analysts use this skill to find Douyin hot searches, search videos and image posts, discover creators, and study content trends and competitors.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Running an unpinned npm package with access to the SocialDataX API key creates a supply-chain risk.

Mitigation: Review and pin the package version or use a controlled internal install, and run it without unrelated secrets.
