# PowPow Register (የአረፋ ምዝገባ አጋዥ)

አዲስ ተጠቃሚን "Bubble ምን እንደሆነ አላውቅም" ከሚለው ወደ "በአንድ ጠቅታ ገብቼ፣ ለመጫወት ዝግጁ" ይወስዳል — ሁሉም ውይይት ውስጥ። ተጠቃሚው ውይይቱን አንድ ጊዜ ብቻ ይለቃል፦ **የማረጋገጫ ኮድን በኢንቦክስ ለማየት**። መድረኩ በአሁኑ ጊዜ በነጻ የሙከራ ወቅት ላይ ነው፦ ከተመዘገበ በኋላ ሁሉም ባህሪያት ይገኛሉ፣ ክፍያ አያስፈልግም፤ የደንበኝነት ክፍያ አማራጭ የአባልነት ማሻሻያ ነው (ወኪሉ የክፍያ ገጹንም ይከፍታል እና ገንዘብ መድረስን ይከታተላል)።

**ስሪት 2.2.0** · 2026-10-18 (ከ v2 ጀምሮ ይህ የወኪል አማራጽ ሁኔታ ነው፦ የስክሪፕት ውል እና ሙሉ ቅደም ተከተል በ `references/agent-flow.md`፤ የመስክ ደንቦች፣ የፍጥነት ገደቦች እና የስህተት ችግር በ `references/registration-flow.md`፤ የክፍያ ጣቢያዎች በ `references/payment-and-activation.md`፤ የምርት ቅጽበታዊ ገጽ ዝርዝር በ `references/screenshots.md`። ከ v2.1.0 ጀምሮ የ PayPal ደንበኝነትም በወኪሉ ሊሠራ ይችላል፣ ከ Alipay ጎን ለጎን አማራጽ ሆኖ። ከ v2.2.0 ጀምሮ መድረኩ በነጻ የሙከራ ወቅት ገብቷል፦ ተመዝገብ እና በአንድ ጠቅታ ግባ — ወዲያውኑ ተጠቀም፤ ክፍያ አማራጽ ማሻሻያ ሆኗል — ተጠቃሚው ማለግጠፊያውን ጫኖ ወደ ደንበኝነት ገጽ ከወረደ፣ የሙከራ ወቅቱ አልቋል፣ ከደረጃ 7 የክፍያ ፍሰትን ተከተል፤ ፍሰቱ ራሱን ይበጃል፣ ስክሪፕት መቀየር አያስፈልግም።)

የቅኝቶች ሕጎች (ጠንካራ ሕጎች)፦

- የጥቅሉ ፋይል በአጣቃቂ ሲጠፋ፣ በ `references/screenshots.md` ውስጥ ወዳሉት የተቀመጡ አገናኞች ይመለሱ (ማስታወሻ፦ በቻይና ውስጥ ላይከፈቱ ይችላሉ)።

ግለጻውን ከጨረሱ በኋላ ምርጫውን ለተጠቃሚው ተይዛል፦ **«ማስመዝገብ ከፈለጉ፣ በሦስት ደቂቃ ውስጥ መለያዎን በውይይቱ ውስጥ እንገነባለን፤ የሚያስፈልግዎ የኢሜይል ማረጋጋጫ ኮድን አንዴ መመልከት ብቻ ነው።»**

## 2 ኛ ደረጃ፦ የምዝገባ መረጃ ማረጋገጥ (በአንድ ዙር አንድ ጥያቄ ብቻ፣ ሁሉንም በአንድ ጊዜ አትጠይቅ)

- **የተጠቃሚ ስም** (ግዴታ)፦ ከውይይቱ አውድ / ከስርዓቱ የተጠቃሚ ስም **በራስ-ተነሳሽነት አንድን ይጠቅሙ** (2~50 ፊደላት፣ ትልቅ/ትንሽ ፊደል አይለያይም)፤ ተጠቃሚው ካወቀ ይጠቀሙት፣ መቀየር ከፈለገ ይቀይሩ።
- **የመግቢያ ቃል** (ግዴታ፣ መጀመሪያ ከሁለቱ አንዱን ይጠይቁ)፦
  - ተጠቃሚው ራሱ የሚሰጥ → ከዚያ በኋላ በአካባቢ ተለዋዋጭ ወደ ስክሪፕቱ ይተላለፋል፣ **በጭራሽ ወደ ትዕዛዝ መስመር ክርክር አይጻፍም**፤
  - ወኪሉ የሚፈጥር → `node scripts/powpow-register.mjs gen-password` ያሂዱ፣ የተፈጠረውን የመግቢያ ቃል **ወዲያውኑ ለተጠቃሚው በመላክ እንዲያስቀምጥ ያድርጉ** (ይህ አንዴ ብቻ ይታያል፣ ከዚያ በኋላ አይመለስም)።
- **ኢሜይል** (ግዴታ)፦ ተጠቃሚው ራሱ መስጠት አለበት — ይህ የመለያው የማንነት መሠረት ነው፣ **በምትኩ አትገምግሙ**።
- **ቅጽል ስም** (አማራጭ)፦ ነባሪው ከተጠቃሚ ስም ጋር እኩል መሆኑን ይጠቅሙ።
- **የመገለጫ ምስል** (አማራጭ)፦ ተጠቃሚው የአካባቢ የምስል መንገድ ቢሰጥ (≤5MB፣ SVG ስላልሆነ) ስክሪፕቱ በቀጥታ ያስገባዋል፤ ከሌለ ይዘሉት (መድረኩ ነባሪ አርማ ይጠቀማል)፤ የምስል መፍጠር ችሎታ ካለዎ፣ ለተጠቃሚው አንድ ማድረግ እንደሚችሉ በራስ-ተነሳሽነት ይጠቅሙ።
- **የሞባይል ቁጥር** (አማራጭ፣ የቻይና ቁጥር)፦ በነባሪ ይዘሉት፤ ተጠቃሚው ራሱ ማስተሳሰር ሲፈልግ ብቻ ይጠይቁ።

ከተረጋገጠ በኋላ `prepare-suggest --username U --nickname N --email E` በማሂድ ወደ የሁኔታ ፋይል ያስገቡ (ከዚያ በኋላ register መረጃውን አያመላክትም)።

## 3–4 ኛ ደረጃ፦ የኢሜይል ማረጋጋጫ ኮድ (ከውይይቱ መውጣት የሚገባው ብቸኛው ክፍል)

```
node scripts/powpow-register.mjs send-code --email <ኢሜይል>
```

ከዚያ ለተጠቃሚው በግልጽ ይንገሩት፦ **ወደ ኢሜይልዎ ገብተው 6-አሃያውን የማረጋጋጫ ኮድ ይፈልጉ፣ በ 10 ደቂቃ ውስጥ ይጸናል፣ የስፓም/የማስታወቂያ ኢሜይል ማስታወሻውን ማየትዎን አይርሱ**፤ ካገኙት ተመልሰው ኮዱን ይላኩልን። መላኩ 60 ሰከንድ ቀዝቃዛ ጊዜ አለው፣ በተከታታይ አትንኩ።

## 5 ኛ ደረጃ፦ ምዝገባ ማስገባት (ወኪል ተይዞ ይሠራል)

```
POWPOW_REGISTER_PASSWORD=<የመግቢያ ቃል> node scripts/powpow-register.mjs register --code <ማረጋጋጫ ኮድ> [--username U] [--nickname N] [--avatar <የአካባቢ የምስል መንገድ>] [--phone P]
```

ሲሳክ መለያው ወዲያውኑ ይፈጠራል (pending ሁኔታ፣ 3 የመጀመሪያ ባጆች ጋር)። የተለመዱ ስህተቶች በራስ ይፈቱታል፣ ተጠቃሚውን አያቋርጡም፦

| ስህተት | አፈታት |
|---|---|
| 用户名已存在 (የተጠቃሚ ስም አስቀድሞ አለ) | በራስ ተለዋዋጭ ይጠቅሙ (የተጠቃሚ ስም + ቁጥር)፣ ተጠቃሚው ካረጋገጠ በኋላ በቀጥታ ይመንጨቱ (የማረጋጋጫ ኮዱ አሁንም ይጸናል፣ ዳግም መላክ አያስፈልግም) |
| 邮箱已被使用 (ኢሜይል አስቀድሞ ተጠቅሷል) | ከተጠቃሚው ጠይቁ፦ ሌላ ኢሜይል ይቀይሩ፣ ወይስ በእውነት አስቀድሞ መለያ አለው (ወደ መግቢያ/የተረሳ የመግቢያ ቃል ይመለሱ) |
| 邮箱验证码错误或已过期 (የኢሜይል ማረጋጋጫ ኮድ ስህተት ወይም አልፏል) | ከ 10 ደቂቃ በላይ ከሆነ → ዳግም `send-code` |
| 发送/注册过于频繁（429） (መላክ/ምዝገባ በጣም ተደጋጋሚ (429)) | 1 ደቂቃ ይጠብቁና ይመንጨቱ፣ ለተጠቃሚው መንገር በቂ ነው |

## ደረጃ 6፦ በአንድ ጠቅታ መግባት (ከምዝገባ በኋላ ቀጥታ ወደ መነሻ ገጽ)

1. ምዝገባው ከተሳካ ወዲያውኑ፦
   ```
   node scripts/powpow-register.mjs login-link --target home
   ```
2. ማለግጠፊያውን ለተጠቃሚው ላክ፦ **ጫን እና ቀጥታ ወደ መነሻ ገጽ ትገባለህ፣ አስቀድሞ ገብተሃል**። መድረኩ በአሁኑ ጊዜ በነጻ የሙከራ ወቅት ላይ ነው — ከተመዘገበ በኋላ ሁሉም ባህሪያት ይገኛሉ (ማጎር ገጽ፣ ካርታ፣ ዲጂታል ሰው፣ ቼክ-ኢን ወዘተ)፣ **ክፍያ አያስፈልግም**።
3. ተጠቃሚው ገብቷል ብሎ እንዲያረጋግጥ ጠይቅ፤ ሁለት ሁኔታዎች አሉ፦
   - **ወደ መነሻ ገጽ ወረደ** → ቀጥታ ወደ ደረጃ 8 ተሻገር ለመጨረስ፤ ምዝገባው ተጠናቋል፤
   - **ወደ ደንበኝነት ገጽ ወረደ** → የመድረኩ ነጻ የሙከራ ወቅት አልቋል፤ ለተጠቃሚው "ነጻ የሙከራ ወቅቱ አልቋል፣ አሁን የአባልነት ደንበኝነት ያስፈልጋል" በል፣ ከዚያ ደንበኝነት ለመጨረስ ደረጃ 7 ተከተል፣ ከደንበኝነት በኋላ ወደ ደረጃ 8 ተመለስ።
4. ተጠቃሚው ራሱ ማሻሻል ወይም መድረኩን መደገፍ ከፈለገ → ወደ ደረጃ 7 ሂድ (ደንበኝነት በፈቃድ ነው፤ አትገፋፋ)።
## ደረጃ 7፦ የደንበኝነት ማሻሻያ (አማራጽ — ደረጃ 6 ሲጠይቅ ብቻ)

1. በመጀመሪያ ግማሽ-መግቢያ ማለግጠፊያ ላክ የክፍያ ተመላላሽ ገጽ "ክፍያው ተሳክቷል" ብሎ በትክክል እንዲያሳይ፦
   ```
   node scripts/powpow-register.mjs login-link --target pending
   ```
   ማለግጠፊያውን ለተጠቃሚው ላክ፦ ጫን እና አሳሹ ቀጥታ ወደ ደንበኝነት ገጽ፣ አስቀድሞ ገብቷል።
2. **ተጠቃሚው የክፍያ ዘዴ እንዲመርጥ ጠይቅ** — ሁለቱንም ጣቢያዎች አሳይ፦
