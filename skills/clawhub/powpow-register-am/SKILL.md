# PowPow Register (የአረፋ ምዝገባ አጋዥ)

አዲስ ተጠቃሚን ከ«አረፋ ምን እንደሆነ አለማወቅ» እስከ «መለያ ተነቃቃ፣ በአንድ ጠቅታ ተገብቷል፣ መጫድ መጀመር» ድረስ ይወስዳል — ሁሉም በውይይት ውስጥ ይከናወናል። ተጠቃሚው በሁለት ጊዜ ብቻ ለአፍታ ከውይይቱ ለመውጣት ይገባዋል፦ **ወደ ኢሜይል ገብቶ የማረጋጋጫ ኮድ ለማየት**፣ **በአሊፓይ የክፍያ ገጽ ላይ ለመክፈል** (ወኪሉ የክፍያ ገጹን በራስ ይከፍታል)።

**ቅጽ 2.0.1** · 2026-10-08 (ከ v2 ጀምሮ በተጠቃሚ ድርሻ የሚሠራ ወኪል ሁነታ ነው፦ የስክሪፕት ውልና ሙሉ ቅደም ተከተል በ `references/agent-flow.md`፤ የመስክ ሕጎች፣ ገደቦችና የስህተት አፈታት በ `references/registration-flow.md`፤ የክፍያ መስመሮች በ `references/payment-and-activation.md`፤ የምርት ቅኝቶች ዝርዝር በ `references/screenshots.md`። ከ v2.0.1 ጀምሮ የምርት ቅኝቶች ከስኪሉ ጋር በ `assets/screenshots/` ተሸክመዋል፣ ከውጭ የምስል ማስቀመጫ አይጠቀሙም)

- የምዝገባ ምኞት፦ «አረፋ ልመዝገብ»፣ «የ powpow መለያ ይፍጠሩ»፣ «አረፋ እንዴት ይመዘገባል»፣ «sign up powpow»
- ምዝገባ መቆለፍ፦ «የማረጋጋጫ ኮድ አይመጣም»፣ «የተጠቃሚ ስም አስቀድሞ አለ ይላል»፣ «የመግቢያ ቃሉ በየጊዜው አይወጣም»

**አይነቃቃም ለ**፦ ልጥፍ ማስቀመጥ/ዲጂታል ሰው መፍጠር (→ powpow-simple)፤ የዌብ ኮድ ልማት (የልማት ስኪልን ይመልከቱ)። ተጠቃሚው ማስመዝገብም ልጥፍ ማስቀመጥም ሲፈልግ፦ መጀመሪያ ይህን ስኪል ያጠናቅቁት፣ ከተነቃ በኋላ ወደ powpow-simple ይተዋወቁ።

ግለጻውን ከጨረሱ በኋላ ምርጫውን ለተጠቃሚው ተይዛል፦ **«ማስመዝገብ ከፈለጉ፣ በሦስት ደቂቃ ውስጥ መለያዎን በውይይቱ ውስጥ እንገነባለን፤ የሚያስፈልግዎ የኢሜይል ማረጋጋጫ ኮድን አንዴ መመልከት ብቻ ነው።»**

## 2 ኛ ደረጃ፦ የምዝገባ መረጃ ማረጋገጥ (በአንድ ዙር አንድ ጥያቄ ብቻ፣ ሁሉንም በአንድ ጊዜ አትጠይቅ)

- **የተጠቃሚ ስም** (ግዴታ)፦ ከውይይቱ አውድ / ከስርዓቱ የተጠቃሚ ስም **በራስ-ተነሳሽነት አንድን ይጠቅሙ** (2~50 ፊደላት፣ ትልቅ/ትንሽ ፊደል አይለያይም)፤ ተጠቃሚው ካወቀ ይጠቀሙት፣ መቀየር ከፈለገ ይቀይሩ።
- **የመግቢያ ቃል** (ግዴታ፣ መጀመሪያ ከሁለቱ አንዱን ይጠይቁ)፦
  - ተጠቃሚው ራሱ የሚሰጥ → ከዚያ በኋላ በአካባቢ ተለዋዋጭ ወደ ስክሪፕቱ ይተላለፋል፣ **በጭራሽ ወደ ትዕዛዝ መስመር ክርክር አይጻፍም**፤
  - ወኪሉ የሚፈጥር → `node scripts/powpow-register.mjs gen-password` ያሂዱ፣ የተፈጠረውን የመግቢያ ቃል **ወዲያውኑ ለተጠቃሚው በመላክ እንዲያስቀምጥ ያድርጉ** (ይህ አንዴ ብቻ ይታያል፣ ከዚያ በኋላ አይመለስም)።
- **ኢሜይል** (ግዴታ)፦ ተጠቃሚው ራሱ መስጠት አለበት — ይህ የመለያው የማንነት መሠረት ነው፣ **በምትኩ አትገምግሙ**።
- **ቅጽል ስም** (አማራጭ)፦ ነባሪው ከተጠቃሚ ስም ጋር እኩል መሆኑን ይጠቅሙ።
- **የመገለጫ ምስል** (አማራጭ)፦ ተጠቃሚው የአካባቢ የምስል መንገድ ቢሰጥ (≤5MB፣ SVG ስላልሆነ) ስክሪፕቱ በቀጥታ ያስገባዋል፤ ከሌለ ይዘሉት (መድረኩ ነባሪ አርማ ይጠቀማል)፤ የምስል መፍጠር ችሎታ ካለዎ፣ ለተጠቃሚው አንድ ማድረግ እንደሚችሉ በራስ-ተነሳሽነት ይጠቅሙ።
- **የሞባይል ቁጥር** (አማራጭ፣ የቻይና ቁጥር)፦ በነባሪ ይዘሉት፤ ተጠቃሚው ራሱ ማስተሳሰር ሲፈልግ ብቻ ይጠይቁ።

ከተረጋገጠ በኋላ `prepare-suggest --username U --nickname N --email E` በማሂድ ወደ የሁኔታ ፋይል ያስገቡ (ከዚያ በኋላ register መረጃውን አያመላክትም)።

## 3–4 ኛ ደረጃ፦ የኢሜይል ማረጋጋጫ ኮድ (ከውይይቱ መውጣት የሚገባው ብቸኛው ክፍል)

```
node scripts/powpow-register.mjs send-code --email <ኢሜይል>
```

ከዚያ ለተጠቃሚው በግልጽ ይንገሩት፦ **ወደ ኢሜይልዎ ገብተው 6-አሃያውን የማረጋጋጫ ኮድ ይፈልጉ፣ በ 10 ደቂቃ ውስጥ ይጸናል፣ የስፓም/የማስታወቂያ ኢሜይል ማስታወሻውን ማየትዎን አይርሱ**፤ ካገኙት ተመልሰው ኮዱን ይላኩልን። መላኩ 60 ሰከንድ ቀዝቃዛ ጊዜ አለው፣ በተከታታይ አትንኩ።

## 5 ኛ ደረጃ፦ ምዝገባ ማስገባት (ወኪል ተይዞ ይሠራል)

```
POWPOW_REGISTER_PASSWORD=<የመግቢያ ቃል> node scripts/powpow-register.mjs register --code <ማረጋጋጫ ኮድ> [--username U] [--nickname N] [--avatar <የአካባቢ የምስል መንገድ>] [--phone P]
```

ሲሳክ መለያው ወዲያውኑ ይፈጠራል (pending ሁኔታ፣ 3 የመጀመሪያ ባጆች ጋር)። የተለመዱ ስህተቶች በራስ ይፈቱታል፣ ተጠቃሚውን አያቋርጡም፦

| ስህተት | አፈታት |
|---|---|
| 用户名已存在 (የተጠቃሚ ስም አስቀድሞ አለ) | በራስ ተለዋዋጭ ይጠቅሙ (የተጠቃሚ ስም + ቁጥር)፣ ተጠቃሚው ካረጋገጠ በኋላ በቀጥታ ይመንጨቱ (የማረጋጋጫ ኮዱ አሁንም ይጸናል፣ ዳግም መላክ አያስፈልግም) |
| 邮箱已被使用 (ኢሜይል አስቀድሞ ተጠቅሷል) | ከተጠቃሚው ጠይቁ፦ ሌላ ኢሜይል ይቀይሩ፣ ወይስ በእውነት አስቀድሞ መለያ አለው (ወደ መግቢያ/የተረሳ የመግቢያ ቃል ይመለሱ) |
| 邮箱验证码错误或已过期 (የኢሜይል ማረጋጋጫ ኮድ ስህተት ወይም አልፏል) | ከ 10 ደቂቃ በላይ ከሆነ → ዳግም `send-code` |
| 发送/注册过于频繁（429） (መላክ/ምዝገባ በጣም ተደጋጋሚ (429)) | 1 ደቂቃ ይጠብቁና ይመንጨቱ፣ ለተጠቃሚው መንገር በቂ ነው |

## 6 ኛ ደረጃ፦ በአንድ ጠቅታ መግባት (አገናኝ 1) + ክፍያ

1. ምዝገባ ሲሳክ ወዲያውኑ፦
   ```
   node scripts/powpow-register.mjs login-link --target pending
   ```
   አገናኙን ለተጠቃሚው ይላኩ፦ **ከተከፈተ አሳሹ በቀጥታ ወደ የደንበኝነት ገጽ ይወርዳል፣ አስቀድሞ የገባበት ሁኔታ ነው** — ከዚያ በኋላ ክፍያ ሲጠናቀቅ የመመለሻ ገጹ «ክፍያ ተሳክቷል» በትክክል ያሳያል። (በዚህ ሁኔታ የይዘት ገጾች አሁንም ወደ የደንበኝነት ገጽ ይመለሳሉ፤ ይህ የመድረኩ የክፍያ ግድግዳ መደበኛ ሥራ ነው፣ ችግር አይደለም፣ የውስጥ ሜካኒዝሙንም ለተጠቃሚው ማብራራት አያስፈልግም።)
2. ከሦስት ጥቅሎች አንዱን ይምረጡ፣ በማሳየት ጊዜ ዋጋውን ይጨምሩ፦
   - ወርሃዊ **¥6.99** (መጀመሪያ ለመሞከር ይመከራል) / የሩብ ዓመት **¥19.99** / ዓመታዊ **¥69.99** — በአሊፓይ አንዴ በመክፈል ለተጠቀሰው ጊዜ ይከፈታል፣ **በራስ አይታደስም**
3. ተጠቃሚው ከመረጠ በኋላ፦
   ```
   node scripts/powpow-register.mjs create-order --package monthly
   ```
   ስክሪፕቱ የክፍያ ገጹን የፋይል መንገድ ይመልሳል፣ **በስርዓት ትዕዛዝ በቀጥታ ይክፈቱት** (Windows፦ `start <ፋይል>`፤ macOS፦ `open <ፋይል>`፤ Linux፦ `xdg-open <ፋይል>`)። አሳሹ በራስ ወደ አሊፓይ ይፋዊ የክፍያ ገጽ ይዘላል፣ ተጠቃሚው በ QR ኮድ ወይም በአሊፓይ ውስጥ ገብቶ ይከፍላል።
4. በየ 10–15 ሰከንድ `query` አንዴ ያሂዱ `paid` እስኪመልስ ድረስ (ገንዘብ መግባቱ በተለምዶ ከጥቂት ሰከንድ እስከ አንድ ደቂቃ ይወስዳል)። ተጠቃሚው የክፍያ ገጹን በመካከል ከዘጋ → በቀጥታ ዳግም `create-order` (አሮጌው ትዕዛዝ በ 2 ሰዓት በራስ ይዘጋል፣ መጨነቅ አያስፈልግም)።
5. ለውጭ አገር / አሊፓይ የሌላቸው ተጠቃሚዎች፦ በደንበኝነት ገጹ ላይ ያለውን የ PayPal መስመር ይጠቀሙ (ስኪሉ ተይዞ አይሠራም፣ መንገዱን መምሪት በቂ ነው)፤ የ WeChat QR ኮድ መስመር በእጅ ማረጋገጫ ነው፣ ገንዘብ መግባቱ ይዘገያል። ከከፈሉ በኋላ ተመልሰው እንደ 7 ኛ ደረጃ ይቀጥሉ።

## 7 ኛ ደረጃ፦ ትክክለኛ መግባት (አገናኝ 2)

ገንዘብ መግባቱ ሲረጋገጥ፣ መጀመሪያ የቅርብ ጊዜ የደንበኝነት አባልነት ያለው የመግቢያ ሁኔታ ይተኩ፣ ከዚያ ወደ መነሻ ገጽ የሚወርድ አገናኝ ይፈጥሩ፦

```
POWPOW_REGISTER_PASSWORD=<የመግቢያ ቃል> node scripts/powpow-register.mjs refresh-login
node scripts/powpow-register.mjs login-link --target home
```

አገናኙን ለተጠቃሚው ይላኩ፦ **ከተከፈተ በቀጥታ ወደ መነሻ ገጽ ይወርዳል፣ ሙሉ የአባልነት ሁኔታ** — በዚህ የምዝገባ ሙሉ ሂደቱ ይጠናቀቃል።

## 8 ኛ ደረጃ፦ ማጠናቀቅ

1. `node scripts/powpow-register.mjs cleanup` በማሂድ የአካባቢ ጊዜያዊ የሁኔታ ፋይል ያጽዱት (የክፍለ-ጊዜ ማረጋገጫ)።
