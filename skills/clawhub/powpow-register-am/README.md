# powpow-register

የPowPow Bubble ምዝገባ ረዳት (የOpenClaw ስሪት)፡ አዲስ ተጠቃሚን ከ«Bubble ምን እንደሆነ ከማወቅ» እስከ «መለያው መነቃቃትና በአግባቡ መጠቀም» ድረስ ምራ — የምርት መግቢያ (የስክሪን ቅጽበታዊ ገጽታዎችን ጨምሮ)፣ የደረጃ በደረጃ የምዝገባ መመሪያ፣ የስህተት መፈተሻ እና የደንበኝነት ማንቃት ማብራሪያ።

የመመሪያ ብቻ የሆነ skill፣ ስክሪፕት ወይም ጥገኛ የለውም፤ ሁሉም የምዝገባ ተግባራት በተጠቃሚው በአሳሽ/App ውስጥ ይከናወናሉ።

## መጫን

```
openclaw skills install @durenzidu/powpow-register
```

## ተግባራት

1. **የምርት መግቢያ**፡ ~120 ቃላት መክፈቻ + በGitHub ሕዝብ ማከማቻ ላይ የተስተናገዱ የስክሪን ቅጽበታዊ ገጽታ ማገናኛዎች (የካርታ ገጽ፣ የልጥፍ ዝርዝር ገጽ ወዘተ. — 6 ቱ፣ እንደ ሁኔታው 1–3 ላክ)።
2. **የምዝገባ መመሪያ**፡ የቅጽ መስኮች ህጎች (የተጠቃሚ ስም/የይለፍ ቃል/የኢሜይል ማረጋገጫ ኮድ/የስልክ ቁጥር/የመገለጫ ምስል)፣ የሶስተኛ ወገን መግቢያ (Google/Watcha/Huawei) እና የመጠን ገደብ መለኪያዎች — ሁሉም ከመድረክ ምንጭ ኮድ የተወሰዱ፣ ምንጩ ተጠቁሟል።
3. **የስህተት መፈተሻ**፡ የማረጋገጫ ኮድ አለመድረስ፣ የተጠቃሚ ስም/ኢሜይል መያዝ፣ 403 አለመነቃቃት፣ መለያ መቆለፍ ወዘተ. 13 የተለመዱ ችግሮች።
4. **የደንበኝነት ማንቃት**፡ ሦስት መንገዶች — PayPal (ድረ-ገጽ) / የWeChat QR ቅኝት (የሰው ማረጋገጫ) / የHuawei IAP (HarmonyOS) — ማብራሪያ እና መፈተሻ፤ ያለው የክፍያ ሰንሰለት በቀጥታ እንደገና መጠቀም ይቻላል፣ skill የሚሰራው መምራት ብቻ ነው።
