# powpow-register

የ PowPow አረፋ ምዝገባ አጋዥ (የ OpenClaw ቅጽ)፦ አዲስ ተጠቃሚን ከ«አረፋ ምን እንደሆነ አለማወቅ» እስከ
«መለያ ተነቃቃ፣ በአንድ ጠቅታ ተገብቷል፣ መጫድ መጀመር» ድረስ ይወስዳል — የምርት ግለጻ (የበይነገጽ ቅኝቶችን ጨምሮ)፣ በወኪል ድርሻ የሚሠራ ምዝገባ
(የመገለጫ ምስል ማስገባትን ጨምሮ)፣ የአሊፓይ/PayPal ደንበኝነት ትዕዛዝ መፍጠርና ገንዘብ መግባቱን መከታተል፣ በጥንድ አገናኝ በአንድ ጠቅታ መግባት፣ የስህተት አፈታት።

**ከ v2.0.0 ጀምሮ በወኪል ድርሻ የሚሠራ ሁነታ ነው፣ ከ v2.1.0 ጀምሮ PayPal ንም ማስተናገድ ይቻላል**፦ ዋናው ስክሪፕት `scripts/powpow-register.mjs` ዜሮ ጥገኛነት
(Node ≥ 18) አለው፣ ተጠቃሚው ሁሉም በውይይት ውስጥ ይከናወናል፣ በሁለት ጊዜ ብቻ ለአፍታ ይወጣል፦ ወደ ኢሜይል ገብቶ ማረጋጋጫ ኮድ ለማየት፣ በአሊፓይ/PayPal
የክፍያ ገጽ ላይ ለመክፈል። Node ከሌለ ወይም ተጠቃሚው ራሱ ማድረግ ሲፈልግ፣ በራስ-ሰር ወደ ንጹህ መመሪያ ሁነታ ይመለሳል።

## ተግባራት

1. **የምርት ግለጻ**፦ ~120 ቃላት መክፈቻ + ከጥቅሉ ጋር የተሸከሙ የበይነገጽ ቅኝቶች (በ `assets/screenshots/` ውስጥ 6 ምስሎች፦
   የካርታ ገጽ፣ የልጥፍ ዝርዝር ገጽ ወዘተ፤ በሁኔታው መሠረት 1–3 ይምረጡ፤ ከውጭ የምስል ማስቀመጫ ወይም ከመስመር ውጭ መሆን አያስፈልግም)።
2. **በድርሻ የሚሠራ ምዝገባ**፦ ወኪሉ በራስ-ተነሳሽነት የተጠቃሚ ስም/ቅጽል ስም ይጠቅማል፣ የመግቢያ ቃል ከሁለት አንዱን ይምረጫል (ተጠቃሚው ይሰጳል ወይም ወኪሉ ይፈጥራል)፣
   የማረጋጋጫ ኮድ መላክና ማስገባት፣ የመገለጫ ምስል ቀጥታ ማስገባት (≤5MB ያልሆነ SVG)፣ የተለመዱ ስህተቶችን በራስ ማስተካከል (መያዝ/ማለፍ/ገደብ)።
3. **በአንድ ጠቅታ መግባት (ጥንድ አገናኝ)**፦ ምዝገባ ሲሳክ «ግማሽ መግቢያ» አገናኝ ወዲያውኑ በቀጥታ ወደ የደንበኝነት ገጽ ይሰጣል፤ ክፍያ ገንዘብ ሲገባ
   አዲስ የመግቢያ ሁኔታ ተተክቶ ሙሉ የአባልነት አገናኝ በቀጥታ ወደ መነሻ ገጽ ይሰጣል (በመድረኩ ይፋዊ `me?token=` ድልድይ፣ HttpOnly cookie በራስ
   ይተከላል)።
4. **የደንበኝነት ክፍያ**፦ አሊፓይ (ወር ¥6.99 / ሩብ ዓመት ¥19.99 / ዓመት ¥69.99፣
   አንዴ በመክፈል ለተጠቀሰው ጊዜ፣ በራስ አይታደስም) እና PayPal (Premium Monthly፣ በግምት $1/ወር፣ በራስ ያድሳል፣ በማንኛውም ጊዜ መሰረዝ ይቻላል) ሁለቱም በወኪሉ ትዕዛዝ መፍጠር + ገንዘብ መግባት መጠየቅ ይስተናገዳሉ፤ የ WeChat QR ኮድ/የሁዋዌ IAP መንገድ መምሪያ።
5. **የስህተት አፈታት**፦ ማረጋጋጫ ኮድ አለመምጣት፣ የተጠቃሚ ስም/ኢሜይል መያዝ፣ 403 ያልተነቃ፣ መለያ መታጠር የመሳሰሉ
   የተለመዱ ችግሮች፣ ሁሉም ከመድረኩ ምንጭ ኮድ የተወሰዱ ሲሆኑ ምንጫቸው ተምልክቷል።

## ደህንነት

- **የመግቢያ ቃል** በአካባቢ ተለዋዋጭ በኩል ብቻ ወደ ስክሪፕቱ ሂደት ይተላለፋል፣ በጭራሽ ወደ ትዕዛዝ መስመር ክርክር አይጻፍም፣ በዲስክ አይቀመጥም፣ ወደ የሁኔታ ፋይል አይገባም፤
  ወኪሉ በፈጠረው የመግቢያ ቃል ተጠቃሚው እንዲያስቀምጥ አንዴ ብቻ ይታያል።
- **የማረጋጋጫ ኮድ** ለይፋዊ የምዝገባ በር ብቻ ይጠቀማል፣ ሲጠናቀቅ ይጣላል፤ የሁኔታ ፋይል (ኢሜይል/የተጠቃሚ ስም/token/የትዕዛዝ ቁጥር)
  በስርዓቱ ጊዜያዊ ማውጫ ይቀመጣል፣ ሂደቱ ሲጠናቀቅ `cleanup` በአንድ ጠቅታ ያጽዳዋል።
- **ክፍያ**፦ ወኪሉ ትዕዛዝ መፍጠር፣ የክፍያ ገጽ መክፈት፣ ገንዘብ መግባቱን መፈተሽ ብቻ ነው፤ የተጠቃሚውን የአሊፓይ/PayPal መለያ
  ወይም የክፍያ ማረጋገጫ በጭራሽ አይነካም፣ በጭራሽም አይከፍልም። ክፍያ ሁልጊዜ በተጠቃሚውና በይፋዊ የክፍያ ገጽ መካከል ይከናወናል።
- ሁሉም ጥሪዎች ወደ ይፋዊ ጎራ `https://global.powpow.online` ብቻ ይሄዳሉ፤ ማንኛውም ቁልፍ አይዟቸውም።
