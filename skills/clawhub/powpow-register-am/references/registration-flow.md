# የምዝገባ ሂደት ዝርዝር — powpow-register

ችግሮችን ለማስተካከል ሲፈተሽ የሚመረመር። ሁሉም ሕጎች ከመድረኩ ምንጭ ኮድ የመጡ ናቸው (የ Next.js የፊት-ጀርባ ተመሳሳይነት ፍተሻ)፣ ምንጫቸውም ተምልክቷል።
መድረኩ ሲዘመን በመስመር ላይ ያለው ትክክለኛ ባህርይ ይበልጣል።

ኢሜይሉ መመዝገቡን ወይም አለመመዝገቡን አያሳይም።

## የወኪል ተይዞ-ሂደት ሁነታና የዌብ ምዝገባ እኩያነት

የ skill ስክሪፕቱ የሚጠራው **ተመሳሳይ የብዙሃን API ጥቅሎች** ናቸው (`/api/auth/register`፣ `send-code`፣ `login`፣
`/api/auth/me`)፤ ከምዝገባ ገጹ ቅጽ ማስገባት ጋር ሙሉ በሙሉ ተመሳሳይ የፍተሻ፣ የገደብና የስህተት መንገዶች ስላሏቸው — የዚህ ፋይል
ሁሉም ሕጎች ለሁለቱም ሁነታዎች እኩል ናቸው። የስክሪፕቱ ቅደም ተከተልና የትዕዛዝ ውል `references/agent-flow.md` ውስጥ አለ።

## ከተሳካ ምዝገባ በኋላ የሁኔታ ፍሰት

> **ነጻ የሙከራ ወቅት (ከ 2026-10-18 ጀምሮ፤ የመድረኩ ትክክለኛ ባህሪይ ይቀዳል)**፦ አዲስ የተመዘገበ መለያ **ሁሉንም ባህሪያት በቀጥታ መጠቀም ይችላል**
> (ማጎር ገጽ፣ ካርታ፣ ዲጂታል ሰው፣ ቼክ-ኢን ወዘተ) ክፍያ አልባ፤ ያልተመዘገቡ መለያዎች ከይዘት ገጾች አይከለከሉም። በዚህ ክፍል የተገለጸው "pending ማቆም"
> የሙከራ ወቅቱ ከሚያልቅ በኋላ መደበኛ ሁኔታ ነው — ያኔ ጊዜ ሲደርስ የመድረኩ ትክክለኛ ባህሪይ ይቀዳል።

1. ተጠቃሚው በ `accountStatus: 'pending'` ይቀመጣል እና **3 የመጀመሪያ ባጆች** (register መንገድ).
2. ሰርቨሩ ሁለት HttpOnly ኩኪዎችንም ያስገባል፦ JWT (ገጾችን በቀጥታ መድረስ ይችላል) እና pendingUserToken (ለደንበኝነት ፍሰት የመለያ መታወቂያ).
3. በመደበኛ ሁኔታ (የሙከራ ወቅት አልቋል / ነጻ ወቅት የለም)፣ የምዝገባ ገጽ `pending_payment` ይለያል → ወደ `/subscription` ይመላላሳል
   (`next` የተመላላሽ መለኪያውን ጠብቆ)፤ በወኪል አማራጽ ሁኔታ፣ `me?token=…&redirect=/subscription` ተመሳሳይ ውጤት ያመክንዳል.
   **በነጻ የሙከራ ወቅት ይህ ደረጃ አይነሳም** — ከተመዘገበ በኋላ ቀጥታ ወደ መነሻ ገጽ ሂድ እና መጠቀም ጀምር.
4. ክፍያ ተጠናቋል → `accountStatus` `active` ይሆናል (**Alipay በሰርቨር-ጎን notify በራስ-ሰር ያገበራል**;
   PayPal በ Webhook ያገበራል፤ WeChat QR ኮድ በእጅ ይረጋገጣል፤ Huawei IAP በ `activate-huawei` ያልፋል).
   ዝርዝር ለማየት `payment-and-activation.md` ተመልከት።

በመደበኛ ሁኔታ፣ ያልተገበሩ (pending) ተጠቃሚዎች ዋና መረጃዎችን (ማጎር ገጽ፣ ካርታ፣ የዲጂታል ሰው ውይይት፣ ቼክ-ኢን ወዘተ) ሲጠይቁ 403 ያገኛሉ፤
የተጋሩ የመልእክት ማለግጠፊያዎች የተለዩ ናቸው (ክፍት ሆነው ይቀመጣሉ)። በነጻ የሙከራ ወቅት ይህ ማቆም ተቋርጧል እና ሁሉም ክፍት ነው።

## ስለ መግባት ጥቂት እውቀት (ለአፈታት በአግድም)

መግቢያ **የተጠቃሚ ስም / ኢሜይል / የሞባይል ቁጥር** ሦስት-በ-አንድ ግቤትን ይደግፋል (ከሦስቱ አንዱ በመለያ ስም ሆኖ ሊያገለግል ይችላል)።
የተረሳ የመግቢያ ቃል፦ የመግቢያ ገጽ → «የተረሳ የመግቢያ ቃል» → የምዝገባ ኢሜይልዎን በማስገባት 6 አሃያ የማረጋጋጫ ኮድ ይቀበላሉ → ይመልሱ።
