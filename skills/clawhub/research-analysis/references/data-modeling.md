# 数据量化建模方法论

## 一、指标体系搭建

### 指标分层框架
```
                    [北极星指标]
                   /      |      \
           [核心指标1] [核心指标2] [核心指标3]
          /    |    \     |        /    \
     [过程指标] [过程指标] [过程指标] [过程指标]
```

### 北极星指标选择原则
1. **反映核心价值**：指标能体现产品为用户创造的核心价值
2. **可衡量可拆解**：能被拆解为可操作的子指标
3. **领先指标**：是业务结果的先行指标，而非滞后指标
4. **团队可影响**：团队的工作能直接或间接影响该指标

### 常见行业北极星指标
| 行业 | 北极星指标 |
|------|-----------|
| 电商 | GMV = DAU × 转化率 × 客单价 × 复购 |
| SaaS | 月度经常性收入(MRR) |
| 内容平台 | 日均内容消费时长 |
| 社交 | 日活用户互动次数 |
| 工具类 | 周活跃使用天数 |
| 金融 | AUM(资产管理规模) |

### 指标定义模板
```
| 指标名称 | 定义 | 计算公式 | 数据来源 | 更新频率 | 负责人 |
|---------|------|---------|---------|---------|--------|
| DAU | 日活跃用户数 | 当日登录且有有效行为的去重用户数 | 埋点数据 | 每日 | 产品 |
| 转化率 | 访问到购买的转化 | 订单数/访问UV | 埋点+交易 | 每日 | 运营 |
```

## 二、市场规模测算

### TAM/SAM/SOM 模型
| 层级 | 含义 | 测算方法 |
|------|------|---------|
| **TAM** (Total Addressable Market) | 整个市场的总规模 | 自上而下：行业报告数据 |
| **SAM** (Serviceable Addressable Market) | 可服务的市场 | 自上而下：TAM × 目标客群占比 |
| **SOM** (Serviceable Obtainable Market) | 可获取的市场 | 自下而上：目标用户数 × 渗透率 × 客单价 |

### 自下而上估算公式
```
SOM = 目标用户数 × 预期渗透率 × 年客单价

示例：
- 目标用户：中国25-35岁职场女性 = 8000万
- 预期渗透率：5% = 400万
- 年客单价：¥1,200
- SOM = 400万 × ¥1,200 = ¥48亿
```

### 费米估算（Fermi Estimation）
适用于数据不完整时的快速估算，将大问题拆解为多个可估算的小问题：
```
问题：估算北京有多少家奶茶店

拆解：
1. 北京常住人口 ≈ 2200万
2. 人均每周喝奶茶频率 ≈ 1.5杯（年轻人偏高，老年人偏低，取加权平均）
3. 每周总消费 = 2200万 × 1.5 = 3300万杯/周
4. 每家店日均出杯量 ≈ 200杯（小型店100-150，中型200-300，取中值）
5. 每周出杯量 = 200 × 7 = 1400杯/周
6. 奶茶店数量 ≈ 3300万 / 1400 ≈ 23,571家

验证：2024年实际数据约2万家，估算合理
```

## 三、单位经济模型(Unit Economics)

### 核心公式
```
LTV (Life Time Value) = ARPU × 毛利率 × 平均生命周期
平均生命周期 = 1 / 流失率

CAC (Customer Acquisition Cost) = 总获客成本 / 新增用户数

健康度判断：
- LTV / CAC > 3：健康
- LTV / CAC = 1-3：需优化
- LTV / CAC < 1：不可持续

回本周期 = CAC / (ARPU × 毛利率)
理想回本周期 < 12个月
```

### 电商单位经济示例
```
| 指标 | 数值 | 说明 |
|------|------|------|
| 客单价 | ¥150 | 平均订单金额 |
| 毛利率 | 25% | 扣除商品成本 |
| 单客年订单数 | 8 | 复购频率 |
| ARPU(年) | ¥1,200 | ¥150 × 8 |
| 年毛利 | ¥300 | ¥1,200 × 25% |
| 年流失率 | 40% | |
| 平均生命周期 | 2.5年 | 1/0.4 |
| LTV | ¥750 | ¥300 × 2.5 |
| CAC | ¥120 | 获客成本 |
| LTV/CAC | 6.25 | 健康 |
| 回本周期 | 4.8月 | ¥120/¥300×12 |
```

## 四、漏斗分析

### 标准转化漏斗
```
曝光(100万) → 点击(5万, CTR 5%) → 访问(4.5万, 到达率90%) 
→ 注册(1.35万, 注册率30%) → 首次购买(2700, 首购率20%) 
→ 复购(1080, 复购率40%)
```

### 漏斗分析要点
1. **逐级转化率**：计算每步的转化率
2. **行业基准对比**：与行业平均水平对比找出薄弱环节
3. **分群对比**：不同用户群的漏斗表现差异
4. **优化优先级**：优先优化"绝对流失量最大"的环节

### 常见优化方向
| 漏斗环节 | 常见问题 | 优化方向 |
|---------|---------|---------|
| 曝光→点击 | 创意不吸引 | A/B测试素材、优化文案 |
| 点击→到达 | 落地页加载慢 | 优化页面性能、预加载 |
| 到达→注册 | 注册流程繁琐 | 减少必填项、一键注册 |
| 注册→首购 | 缺乏购买动机 | 新人优惠、首单引导 |
| 首购→复购 | 满意度低/无触达 | 满意度调研、复购触达 |

## 五、Cohort 留存分析

### Cohort 分析表
```
注册月份 | 第1月 | 第2月 | 第3月 | 第4月 | 第5月 | 第6月
2024-01  | 100%  | 45%   | 32%   | 28%   | 25%   | 23%
2024-02  | 100%  | 48%   | 35%   | 30%   | 27%   | -
2024-03  | 100%  | 52%   | 38%   | 33%   | -     | -
2024-04  | 100%  | 55%   | 40%   | -     | -     | -
```

### 分析要点
1. **横向看趋势**：同一 cohort 的留存随时间衰减速度
2. **纵向看改善**：不同 cohort 在同一时间节点的留存对比（判断产品优化效果）
3. **拐点识别**：留存曲线在哪个时间点趋于稳定（判断产品黏性）
4. **分群对比**：不同获客渠道/用户特征的 cohort 留存差异

### 健康留存曲线特征
- 首月大幅下降后逐渐趋平（"L型"或"曲棍球棒型"）
- 趋平的位置越高越好（理想 > 20%）
- 如果持续下降不平（"直线下降型"），说明产品缺乏核心价值

## 六、ROI 测算

### ROI 基本公式
```
ROI = (收益 - 投入) / 投入 × 100%

年化ROI = (年收益 - 年投入) / 年投入 × 100%
```

### 投资决策分析
```
| 项目 | 投入 | 年收益 | ROI | 回本周期 | 优先级 |
|------|------|--------|-----|---------|--------|
| 项目A | ¥50万 | ¥20万/年 | 40% | 2.5年 | P1 |
| 项目B | ¥30万 | ¥15万/年 | 50% | 2年 | P0 |
| 项目C | ¥100万 | ¥12万/年 | 12% | 8.3年 | P3 |
```

### 敏感性分析
对关键变量进行±20%波动测试，观察对结论的影响：
```
基础假设：用户增长20%，ARPU ¥100，CAC ¥50
- 乐观：增长30%，ARPU ¥120 → LTV/CAC = 8.4
- 基准：增长20%，ARPU ¥100 → LTV/CAC = 5.0
- 悲观：增长10%，ARPU ¥80  → LTV/CAC = 2.8

结论：即使在悲观情况下LTV/CAC仍>1，项目可行
```

## 七、趋势预测方法

### 1. 线性趋势外推
适用于稳定增长的数据：
```
Y = a + bX
其中 b = (nΣxy - ΣxΣy) / (nΣx² - (Σx)²)
```

### 2. 同比/环比分析
```
同比增长率 = (本期值 - 去年同期值) / 去年同期值 × 100%
环比增长率 = (本期值 - 上期值) / 上期值 × 100%
```

### 3. 移动平均
- 简单移动平均(SMA)：消除短期波动，显示长期趋势
- 加权移动平均(WMA)：近期数据权重更高
- 指数移动平均(EMA)：对近期数据更敏感

### 4. 季节性调整
```
季节指数 = 各季度平均值 / 全年季度平均值
调整后数据 = 原始数据 / 季节指数
```

## 八、数据可视化建议

### 图表选择指南
| 数据关系 | 推荐图表 | 工具 |
|---------|---------|------|
| 趋势变化 | 折线图、面积图 | VChart/Chart.js |
| 对比分析 | 柱状图、条形图 | VChart/Echarts |
| 占比构成 | 饼图、环形图、堆叠图 | VChart |
| 相关关系 | 散点图、气泡图 | VChart |
| 分布情况 | 直方图、箱线图 | VChart |
| 漏斗转化 | 漏斗图 | VChart |
| 留存分析 | 热力图 | VTable |
| 多维对比 | 雷达图 | VChart |

### 可视化设计原则
1. **一图一论点**：每张图只表达一个核心观点
2. **标题即结论**：图表标题写结论而非描述
3. **标注数据来源**：每张图底部标注数据来源和日期
4. **配色专业**：使用品牌色或专业色板，避免过多颜色
5. **中国股市惯例**：涨用红色，跌用绿色（与欧美相反）
