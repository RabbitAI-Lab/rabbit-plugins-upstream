# 用户研究与画像方法论

## 一、用户研究方法体系

### 研究方法选择矩阵

| 研究目标 | 推荐方法 | 样本量 | 周期 |
|---------|---------|--------|------|
| 了解用户是谁 | 深度访谈、人口统计调研 | 10-30人(定性) / 500+(定量) | 1-3周 |
| 了解用户行为 | 行为数据分析、日记研究 | 全量数据 / 20-50人 | 2-4周 |
| 了解用户需求 | 深度访谈、焦点小组 | 15-30人 | 1-2周 |
| 了解用户态度 | 问卷调查、NPS调研 | 500+ | 1-2周 |
| 了解用户体验 | 可用性测试、用户旅程分析 | 5-15人 | 1-2周 |

### 定性 vs 定量
| | 定性研究 | 定量研究 |
|---|---------|---------|
| **回答什么** | Why & How | What & How Many |
| **方法** | 访谈、观察、焦点小组 | 问卷、数据分析、A/B测试 |
| **样本量** | 小（10-30） | 大（500+） |
| **输出** | 洞察、假设、故事 | 统计、趋势、验证 |
| **最佳实践** | 先定性探索，再定量验证 | 先定性探索，再定量验证 |

## 二、用户画像(Persona)构建方法

### 画像维度框架

#### 基础维度
| 维度 | 内容 | 数据来源 |
|------|------|---------|
| 人口统计 | 年龄、性别、地域、教育、收入 | 注册数据、问卷 |
| 职业信息 | 行业、职位、工作场景 | 问卷、访谈 |
| 设备特征 | 终端、系统、网络环境 | 埋点数据 |

#### 行为维度
| 维度 | 内容 | 数据来源 |
|------|------|---------|
| 使用频率 | 日活/周活/月活、使用时长 | 埋点数据 |
| 功能偏好 | 高频功能、功能使用路径 | 埋点数据 |
| 消费行为 | 付费意愿、客单价、复购率 | 交易数据 |
| 渠道来源 | 获客渠道、触达偏好 | 归因数据 |

#### 心理维度
| 维度 | 内容 | 数据来源 |
|------|------|---------|
| 核心动机 | 使用产品的根本原因 | 深度访谈 |
| 痛点/障碍 | 使用中的困难和不满 | 访谈、客服数据 |
| 价值观 | 消费观、品牌偏好、生活方式 | 访谈、问卷 |
| 决策因素 | 影响决策的关键因素 | 访谈、问卷 |

### 画像模板
```
## 用户画像：[画像名称，如"效率型职场妈妈"]

### 📋 基本信息
- 年龄：30-40岁
- 性别：女性
- 城市：一二线城市
- 职业：企业中层管理
- 收入：家庭年收入30-60万
- 设备：iPhone + iPad

### 🎯 核心特征
- 使用频率：每日2-3次，每次5-15分钟
- 高峰时段：早晨7-8点、晚间21-23点
- 核心场景：碎片化时间处理工作+家庭事务
- 付费意愿：中高，重视时间效率

### 💡 核心需求
1. [需求1]：快速完成XX任务，不想花时间学习
2. [需求2]：在多设备间无缝切换
3. [需求3]：数据安全可靠，尤其涉及家庭信息

### 😣 主要痛点
1. [痛点1]：现有产品功能太复杂，上手成本高
2. [痛点2]：跨设备同步经常出问题
3. [痛点3]：担心隐私泄露

### 📝 典型用户故事
"作为一名职场妈妈，我每天在工作和家庭之间奔波。我需要一个能在碎片时间快速完成XX的工具，简单好用、数据安全。我不想花时间研究功能，打开就能用最重要。"

### 🎨 推荐策略
- 产品策略：[针对该画像的产品方向]
- 运营策略：[触达渠道和内容策略]
- 定价策略：[价格敏感度与付费模式建议]
```

## 三、用户旅程地图(User Journey Map)

### 模板结构

```
阶段：认知 → 兴趣 → 评估 → 购买 → 使用 → 忠诚/流失

| 阶段 | 用户行为 | 触点 | 想法/感受 | 痛点 | 机会点 |
|------|---------|------|----------|------|--------|
| 认知 | 在社媒看到广告 | 抖音/小红书 | "这个看起来不错" | 广告和实际不符 | 真实案例内容营销 |
| 兴趣 | 搜索品牌词 | 搜索引擎 | "靠谱吗？" | 搜索结果有负面 | SEO+口碑管理 |
| 评估 | 对比竞品 | 对比网站 | "哪个更值？" | 信息不对称 | 透明对比+试用 |
| 购买 | 下单支付 | APP/网站 | "希望别踩坑" | 支付流程繁琐 | 一键支付优化 |
| 使用 | 首次使用 | 产品内 | "怎么开始？" | 新手引导不足 | 优化onboarding |
| 忠诚 | 持续使用/推荐 | 社群/口碑 | "真好用！" | 缺乏激励机制 | 建立推荐奖励 |
```

### 绘制要点
1. 基于真实用户数据（访谈+行为数据），非凭空想象
2. 标注情绪曲线（用户在每个阶段的情绪高低点）
3. 识别关键时刻(Moment of Truth)：影响用户决策的关键节点
4. 每个阶段都要有"机会点"，不是只列痛点

## 四、需求洞察方法

### Kano 模型应用
详见 `analysis-frameworks.md` 第十节

### 需求优先级评估矩阵
```
         高影响
           |
    P1     |    P0
  (重要但不急) | (重要且紧急)
-----------+-----------
  P3     |    P2
 (不重要不急) | (紧急不重要)
           |
         低影响
    低紧急  ←→  高紧急
```

### 需求挖掘工具
| 工具 | 用途 | 操作方式 |
|------|------|---------|
| 5Whys | 挖掘深层需求 | 连续追问5次"为什么" |
| 用户故事映射 | 梳理需求全景 | 按用户旅程横向展开功能需求 |
| 亲和图(Affinity Diagram) | 整理碎片需求 | 将需求卡片聚类分组 |
| 优先级矩阵 | 排序需求 | 按"价值×成本"四象限分类 |

## 五、用户分群方法

### 常用分群模型

#### 1. RFM 模型
| 维度 | 含义 | 评分 |
|------|------|------|
| **R**ecency | 最近一次消费距今时间 | 越近分越高 |
| **F**requency | 消费频次 | 越多分越高 |
| **M**onetary | 消费金额 | 越高分越高 |

分群结果：
| RFM组合 | 用户类型 | 策略 |
|---------|---------|------|
| 高高高 | 重要价值用户 | 维系，VIP服务 |
| 高低高 | 重要发展用户 | 提频次，交叉销售 |
| 低高高 | 重要保持用户 | 召回，专属优惠 |
| 低低高 | 重要挽留用户 | 流失预警，深度挽留 |
| 低低低 | 一般/流失用户 | 低成本触达或放弃 |

#### 2. 用户生命周期分群
| 阶段 | 特征 | 核心策略 |
|------|------|---------|
| 新手期(0-7天) | 刚注册，未形成习惯 | 新手引导、首单优惠 |
| 成长期(7-30天) | 开始活跃，探索功能 | 功能推荐、习惯养成 |
| 成熟期(30天+) | 稳定使用，有付费行为 | 价值挖掘、会员体系 |
| 衰退期 | 活跃度下降 | 流失预警、精准召回 |
| 流失期 | 超过30天未活跃 | 召回campaign、降级触达 |

#### 3. 行为聚类分群
- 基于用户行为数据（功能使用、频率、时段、路径等）
- 使用 K-Means / 层次聚类等算法自动分群
- 为每个簇命名并构建画像
