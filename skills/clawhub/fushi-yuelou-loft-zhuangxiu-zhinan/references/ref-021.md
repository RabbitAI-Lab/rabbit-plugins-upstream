# 35㎡蜗居LOFT，这样装最好住

LOFT公寓因为能一层变两层，拓展功能，非常适合年轻人居住，在今天房价居高不下，年轻人压力巨大的社会上，这种户型非常受年轻人的欢迎。自己住后面不论是出售或者出租，都很受年轻人的青睐。
今天这套建面只有35平，实际面积20平的蜗居LOFT，在同类户型里头属于非常小的，还好层高4.5米的跨度完全满足动静分离的预想。
▲如图就是一个层高4.5米的开间户型，格局需要自己根据需求进行分割。因为户型小，而且大窗户朝南，光线倒是非常完美

▲设计后的布局，搭建钢构分割上下动静分离，一楼入户左手分割卫生间，门厅和开放厨房一体共用；客餐厅就是作为楼梯会客两用空间；为了让空间显得更开阔，楼上分割了一半面积，剩余一半挑空刚好给楼下客厅，让空间以及光线更加通透，这样楼上只需要一间卧室，而且可以满足开放卧室的需求，实现完美动静分离
▲一楼入户第一视角，因为空间非常小，光线不错，所以采用大面积原木色系搭配，可以让空间更显温馨；右手进门矮柜鞋柜满足收纳，与开放式厨房融为一体，定制的延伸分区满足更多功能，同时可以让空间有延伸放大的功能；左手分割卫生间
▲过道开放区域兼顾很小的厨房，而且还满足了洗烘机的布局，一个人住，偶尔做个简单的烹饪还是必不可少的；上头超薄吊柜满足收纳的同时可以避免进门口的视觉拥挤
▲进门右手矮柜和橱柜一体定制，满足进门换鞋需求，很小的台面满足平时的偶尔烹饪需求
▲空间实在太小，所以只需要一间卧室，这样钢结构只需要搭建一半面积，节省费用的同时，可以让大面积保持挑空状态，不论是空间还是光线都能敞亮开阔；同时楼梯没有做钢结构定制，而是完全采用定制收纳的柜的形式，满足楼梯和收纳双重功能，单独定制的铁艺扶手满足功能同时不会有厚重感
▲搭建分割以后，剩余的公共区域实在太小，一个人住，干脆不要沙发不要电视，直接布局书桌电脑，用来满足平时的在家办公就行；原有飘窗布局休闲功能，一个小圆几搭配，这里可以满足平时休闲和就餐功能。空间反传统更显灵活，朝南窗户光线一览无余
▲简单的原木书桌满足平时办公，紧挨一楼卫生间侧墙打造衣柜收纳，满足平时衣物的放置
▲很小的飘窗铺上垫子在阳光的照射下，这里是完美的角落；暖气片刚好侧面布局，不占地。平时休闲就餐完全够用
▲楼上卧室空间，与挑空区域玻璃护栏分割，开放格局让空间和光线都开阔明亮；内部侧墙简单的卡座一个挂杆设计，既不影响空间的开阔，同时满足衣物的随手悬挂，一个人住足够使用
▲楼上卧室全景，非常简单干净，明亮的色彩搭配，原有消防管道因为层高原因，统一刷成白色，尽量让视觉更整洁
▲玻璃护栏满足功能，同时视觉保持空间的通透时尚
▲床头一角，组合挂画以及玻璃台灯的营造，夜晚一个人也能温馨幸福
▲一楼的卫生间因为暗卫，采用经典小白砖与原木的搭配，灯光下更明亮
▲另一边是单独的淋浴间，尽头背景采用花砖铺贴，让小空间能更有活力
