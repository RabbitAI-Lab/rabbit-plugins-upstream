# 40㎡LOFT公寓，一人温暖住

挑高公寓户型，常见的挑高开间，需要自己分割，满足一个人入住即可。
毛坯实景，挑高开间户型，隔层需要自己分割，各个功能区也需要自行规划设计。分割出来一二层的结构规划，二层因为可以占用过道空间，所以面积多出来一部分赠送的面积，可以拓展二层的面积使用。设计后规划，一楼满足楼梯以及卫生间规划，剩余空间因为需要一个岛台，所以放弃了传统客餐厅的做法，满足了开放厨房和岛台的布局，满足更多的收纳和一个人的独处休闲；二楼空间满足卧室私密空间，同时规划卫生间，利用过道赠送空间满足储物间的规划。最大的亮点在于，二楼采用局部玻璃面，满足引光到一楼，让光线和视觉更加通透
隔层自行搭建，没有采用施工速度快的钢结构，而是采用混凝土现浇，第一是最大化保证层高，楼下无需重新吊顶，直接可以处理；进门左手利用过道区域楼梯布局，楼梯下方满足了杂物以及进门的收纳，最大化保证大面积的空间利用因为空间比较小，楼梯下方留空位置是小冰箱的预留，目前布帘遮挡一下；开放厨房对面，楼梯末尾水吧台功能，这里满足平时的烧水咖啡功能水吧台特写，木质温润的台面，摆上各种常用的器具，利用垂直墙面隔板以及挂钩，满足功能性和装饰性的兼顾水吧台侧墙同样是隔板和挂钩，满足一个餐具的随手收纳反过来看全景，一楼不做传统客餐厅布局，而是采用开放式橱柜延伸收纳满足，中间岛台定制，同时兼顾客餐厅以及办公使用，简洁也拓展了收纳储物开放厨房，一字定制，白色与温润的木色搭配，功能满足同时视觉空间也美观简洁，吊柜下方手扫灯可以满足夜晚细节的操作灶具右侧利用金属架满足常用电器的合理收纳台面延伸高柜一直到阳台空间，满足空间的收纳储物；二楼楼板镂空，局部采用钢化玻璃，引光入室，同时弱化一楼层高的压抑感二楼的钢化玻璃采光区域，弱化一楼的压抑，同时满足了采光的通透楼梯很小，采用木质与白色搭配，玻璃轻盈的扶手，视觉空间也能更温馨楼梯侧墙排列功能性的感应灯，满足夜晚的照明；楼梯尽头是楼上卧室的玻璃移门，可以满足视觉和光线的通透二楼过道紧邻的卫生间采用玻璃移门，满足采光视觉通透，同时节省空间，利用过道实现的储藏室没有装门，采用布帘遮挡二楼卧室全景，玻璃移门可以满足采光需求，床尾一排衣柜满足收纳，同时书桌布局满足平时的办公所需二楼卧室局部的钢化玻璃区域，刚好满足采光通透，同时视觉上放大整体空间反过来看二楼全景，床尾一排衣柜，靠窗户满足洗烘机以及书桌的功能靠窗户满足洗烘机的镶嵌，同时满足了一个小的工作区楼上利用过道空间实现的储藏室，可以收纳平时的杂物楼上卫生间绿色的小花砖搭配清新，淋浴独立的玻璃隔断
