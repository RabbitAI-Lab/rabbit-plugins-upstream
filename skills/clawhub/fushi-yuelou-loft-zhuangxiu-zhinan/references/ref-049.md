# 35m²复式公寓，单身如何把生活过成诗

房价太高，对于现在不靠父母的单身人士来说，能有一套属于自己的房子，比登天还难。而公寓就是为了单身而准备的礼物。让自己过得舒适，才能让爱的人拥有明天。

▲建面35平小复式公寓，一层除了一个封闭的卫生间外就是一个大开间，需要规划厨房、客厅以及休闲区域，还得容纳楼梯空间；二楼就是单独睡眠区，需要有基本的收纳、娱乐、工作和休闲区域。很小，空间已经失去很多，品味一定要赢回来。

▲进门过道采用金属铁艺的置物架，兼顾进门鞋柜 以及挂衣服使用，一个人住，也没有多少鞋子，多半以装饰为主。旁边椭圆形复古的镜子配置，每天出门都可以臭美一下。接着是复古的斗柜，摆上一些时尚的摆件，非常养眼。厨房很小，公寓房没有烟道，所以一个人也不做饭，一字橱柜，小冰箱、洗衣机镶嵌，平时最多洗个水果杯子之类
▲转过来客厅和阳台全景，绿色复古的变色，采用简单线条勾勒，金色挂钟以及壁灯搭配，非常有格调。阳台单独地台做了休闲处理，纱帘相隔，平时看书或者三五好友周末聚会都是没有问题的。因为空间有限，采用铁艺的旋转楼梯在尽量节省空间的前提下满足功能。
▲两层地台休闲定制，纱帘分割，隐藏氛围灯晚上空间更温馨。铁艺的镂空楼梯，视觉上极简优雅
▲客厅阳台摆上小几，摆几个蒲团，平时三五好友过来聊天喝茶，欣赏窗外美景，也是不错的生活
▲楼上空间，简单布置地台床，床对面电视柜收纳，平时一个人欣赏大片非常惬意。因为一人住，不要衣柜，右手角落简单铁艺挂衣架布置，平时挂衣服，看上去空间更简洁
▲背景简单的高级灰变色，左边极简吊线灯以及落地灯辅助照明，绿植装饰。右边两幅清新挂画布置，空间清爽不显得单调
▲卧室靠近窗户位置做了小吧台空间，平时也兼做工作台，搭配轻奢的金色款式，非常有格调
▲窗户的另一边做了一个单独休闲区，金色的单椅边几布置，侧墙简单隔板，平时可以放一些酒水或者书籍，一个人喝着小酒，悠闲自在
▲一楼门口的卫生间，因为是暗卫，整体浅色瓷砖搭配，淋浴单独分割，统一黑色极简五金质感搭配
