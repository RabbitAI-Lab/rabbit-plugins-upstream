# 45㎡LOFT单身公寓，简单装修入住

市场上一般公寓LOFT有两种，一种就是直接挑空，没有分割，购买之后需要自己分割；一种就是开发商已经分割好的；两者在价位其实区别不大，如果自己分割自由度能高一点。今天这套属于开商分割好的，一层大概面积在45平左右，一个人住完全满足。

▲一楼布置图，作为公共活动区使用。进门右手过道兼顾的是厨房，左手是一楼卫生间，因为一个人住，楼上还有卫生间，干脆一楼卫生间空置起来作为了储藏室，平时里头放些杂物；因为是分割好的，基本的格局已经固定，无法大的改动，所以只能布局基本功能即可；门厅进来左手餐厅定了吧台空间，就餐兼顾办公；剩下的空间其实就是客厅位置；这就是一楼的全部
▲二楼就是睡眠区，除过一间卧室以外，楼梯的另一边，是一个卫生间和一个衣帽间，两个空间几乎都没有光线
▲门厅以及右手过道的厨房，地面是北欧经典的花砖，干净时尚；高级灰的橱柜吊柜定制，角落刚好放置冰箱；很小，偶尔做饭还是可以的
▲门厅进来左手餐厅的位置，打造一个矮柜兼顾水吧台功能，两个隔板满足一些基本收纳，视觉上不至于太压抑；定制的石材吧台，用来兼顾就餐和办公，侧墙延伸黑色石材，延伸对比，空间加一点质感
▲黑色的吊灯，黑色的石材延伸，与黑色吧椅呼应，与白色对比，层次分明，更有质感
▲全景空间，右手是楼梯空间，黑色加玻璃的扶手简单质感，为了让客厅完整，新砌墙分割区域，可以沙发区更具安全感
▲因为有投影的需求，但是又不想大面积吊顶，所以电视墙上方采用斜切吊顶的形式，满足了投影的隐藏；同时几何斜切的线条感可以给空间增加活力
▲有颜值时尚的单椅和落地灯布局，空间设计感和高级感都有了
▲深色布艺沙发质感搭配，背景是组合黑白灰挂画，竖百叶的搭配不仅让采光通透，视觉更简洁大气
▲楼上卧室，粉色图案的壁布装饰，搭配白色的床铺，角落化妆台功能，富有艺术感的吊灯布局，温馨惬意
▲利用柱子以及吊顶形成的空间，做了开放式的衣橱，这里平时可以收纳随手物品以及衣物，拉上帘子保证空间的整洁
