## 冷链物流规则

### 运输模式判定
| 货物重量 | 运输模式 | 备注 |
|---------|---------|------|
| < 2 吨 | 零担拼车 | 小批量不走专车 |
| 2-3 吨 | 最小冷链车 | 按整车计算 |
| 3-10 吨 | 中大型车 | 省内/区域 |
| 10+ 吨 | 省际干线 | 长途运输 |

### 关键规则
- 吨级以下（<2吨）均为零担拼车，不按专车计算
- 分析供应商物流成本差异时，小批量分供不因物流产生差异
- 零担拼车按实际装载量/体积分摊费用

## 成本差异分析公式

### 价格差异
```
价格差异 = (实际单价 - 标准单价/基准单价) × 实际采购量
正值 = 不利差异（成本上升）
负值 = 有利差异（成本下降）
```

### 数量差异  
```
数量差异 = (实际采购量 - 标准采购量/基准采购量) × 标准单价
正值 = 不利差异
负值 = 有利差异
```

### 结构差异（品类组合）
```
结构差异 = Σ(品类i实际占比 - 品类i基准占比) × 品类i基准单价 × 总采购量
```

## 降本方法论

### 成本控制模型 1.0
基于全品类视角的成本控制框架：
1. 价格基线建立：按品类建立基准价格区间（历史12个月均价 ± 合理波动）
2. 供应商分级管理：S/A/B/C四级，差异化合作策略
3. 季度复盘机制：每季度对核心品类进行成本复盘
4. 异常响应流程：价格/成本异常在 24h 内触发预警

### 8 大降本妙招
1. **源头直采**：跳过中间商，直连生产基地/工厂
2. **集中采购**：合并需求，提升议价权
3. **标准化**：统一规格减少定制成本
4. **长期锁价**：签订框架协议锁定价格
5. **替代竞争**：引入备选供应商维持竞价
6. **物流合并**：多品类拼车，降低物流费率
7. **损耗管控**：优化库存周转，减少过期/损坏
8. **数据驱动**：用历史数据指导采购节奏和库存水位

### 两聚焦一落实
- **聚焦核心品类**：TOP 20% 品类占 80% 成本，集中资源管理
- **聚焦核心供应商**：TOP 5 供应商占 60%+ 采购额，重点维护
- **落实数据驱动**：每一笔降本决策都要有数据支撑
