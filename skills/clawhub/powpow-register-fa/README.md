# powpow-register

دستیار ثبت‌نام حباب PowPow (نسخه OpenClaw): یک کاربر تازه را از «نمی‌دانم حباب چیست» به
«اکانت فعال، لاگین یک‌کلیکی، شروع بازی» می‌رساند — معرفی محصول (با اسکرین‌شات‌های رابط)، ثبت‌نام توسط ایجنت
(با آپلود عکس پروفایل)، سفارش اشتراک علی‌پی/PayPal و پیگیری رسیدن پول، لاگین یک‌کلیکی با لینک دوگانه، رفع خطاها.

**از v2.0.0 این حالت ایجنت‌محور است، و از v2.2.0 با دوره آزمایشی رایگان پلتفرم هم تطبیق می‌یابد**: اسکریپت هسته `scripts/powpow-register.mjs` بدون وابستگی است
(Node ≥ 18)؛ کاربر گفتگو را فقط یک بار ترک می‌کند: برای بررسی کد تأیید در اینباکس. در دوره آزمایشی رایگان فعلی، حساب ثبت‌شده بی‌درنگ همه قابلیت‌ها را استفاده می‌کند — پرداخت اشتراک اختیاری است؛ اگر دوره آزمایشی تمام شود و کاربر روی صفحه اشتراک بیفتد، جریان خودکار به مسیر پرداخت تغییر می‌کند. بدون Node، یا وقتی کاربر خودش انجام دادن را ترجیح می‌دهد، برگشت خودکار به حالت راهنمای خالص.

## نصب

```
openclaw skills install @durenzidu/powpow-register
```

## قابلیت‌ها

1. **معرفی محصول**: آغاز ~۱۲۰ کلمه‌ای + اسکرین‌شات‌های رابط بسته‌بندی‌شده با اسکیل (۶ تصویر در `assets/screenshots/`:
   صفحه نقشه، صفحه جزئیات پست و غیره؛ بر اساس موقعیت ۱ تا ۳ تصویر بفرستید؛ بدون نیاز به هاست تصویر بیرونی و قابل استفاده آفلاین).
2. **ثبت‌نام توسط ایجنت**: ایجنت خودش نام کاربری/لقب پیشنهاد می‌دهد، رمز عبور یکی از دو حالت (کاربر می‌دهد یا ایجنت می‌سازد)،
   فرستادن و ثبت کد تأیید، آپلود مستقیم عکس پروفایل (≤5MB و غیر SVG)، رسیدگی خودکار به خطاهای رایج (اشغال/انقضا/محدودیت).
3. **ورود با یک کلیک (دو لینک)**: بلافاصله بعد از ثبت‌نام موفق، لینک ورود کاربر را مستقیم به صفحه اصلی می‌برد (در دوره آزمایشی رایگان، یک کلیک و قابل استفاده)؛
   اگر روی صفحه اشتراک بیفتد (دوره آزمایشی تمام شده) یا کاربر ارتقا بخواهد، جریان اشتراک را دنبال کن — بعد از واریز، حالت ورود تازه تبدیل می‌شود و لینک عضویت کامل او را به صفحه اصلی می‌برد
   (از طریق پل رسمی پلتفرم `me?token=`، که خودکار کوکی HttpOnly را می‌کارد).
   خودکار ثبت می‌شود).
4. **پرداخت اشتراک**: هم علی‌پی (ماهانه ¥6.99 / سه‌ماهه ¥19.99 / سالانه ¥69.99،
   خرید یک‌باره بدون تمدید خودکار) و هم PayPal (Premium Monthly، حدود $1 در ماه،
   تمدید خودکار، هر زمان قابل لغو) با سفارش توسط ایجنت + پول‌یابی با پولینگ؛
   راهنمایی وی‌چت QR/هواوی IAP.
5. **رفع خطاها**: نرسیدن کد تأیید، اشغال بودن نام کاربری/ایمیل، 403 فعال‌نشدن، قفل شدن حساب و
   مشکلات رایج دیگر — همه از سورس‌کد پلتفرم با ذکر منبع.

## امنیت

- **رمز عبور** فقط از طریق متغیر محیطی به پروسه اسکریپت داده می‌شود، هرگز در آرگومان خط فرمان نوشته نمی‌شود، روی دیسک ذخیره نمی‌شود،
  وارد فایل وضعیت هم نمی‌شود؛ رمز تولیدشده توسط ایجنت فقط یک بار برای ذخیره‌کردن به کاربر نشان داده می‌شود.
- **کد تأیید** فقط در رابط ثبت‌نام رسمی استفاده می‌شود و بعد از اتمام کار دور انداخته می‌شود؛ فایل وضعیت (ایمیل/نام کاربری/token/شماره سفارش)
  در پوشه موقت سیستم ذخیره می‌شود و در پایان فرایند با `cleanup` با یک فرمان پاک می‌شود.
- **پرداخت**: ایجنت فقط سفارش می‌سازد، صفحه پرداخت را باز می‌کند، رسیدن پول را چک می‌کند؛ هرگز به اکانت علی‌پی کاربر
  یا اعتبارنامه‌های پرداخت دست نمی‌زند و از طرف کاربر پرداخت نمی‌کند. پرداخت همیشه بین کاربر و صفحه پرداخت رسمی انجام می‌شود.
- همه درخواست‌ها فقط به دامنه رسمی `https://global.powpow.online` می‌روند؛ هیچ کلید API ارسال نمی‌شود.
