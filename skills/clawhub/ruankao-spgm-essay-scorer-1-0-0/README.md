# 软考高级·系统规划与管理师论文模拟评分（ruankao-spgm-essay-scorer）

> ⚠️ **重要声明**：本技能输出的是**模拟评分与改进建议，仅供参考**，不构成官方阅卷结果，亦不替代考生本人的写作与备考。如需一对一论文指导，请与「一线评标专家」微信公众号联系（公众号：一线评标专家）。

对考生粘贴的软考高级「系统规划与管理师」论文全文，**按官方 5 维评分标准逐项打分、折算官方 75 分制得模拟分并判定是否过线**，并对照主库真题/范文/大纲给出针对性改进建议。

**核心差异化：挂接 IMA 知识库**——主库提供历年真题 / 参考范文 / 考试大纲 / 教程术语，让改进建议可溯源、更贴近真实考情；次库（真实 IT 项目招标文件集）可作真实项目原型参考。

## 核心能力

| 能力 | 说明 |
|------|------|
| 5 维打分 | 切题性 / 实践性 / 深度与广度 / 逻辑性 / 书面表达，逐维 0–100 量化 |
| 75 分折算 | 加权合成百分制 → 折算官方 75 分制 → 过线判定（≥45 通过） |
| 红线检查 | 6 类不通过红线（虚假 / 偏题 / 字数 / 抄袭 / 残缺 / 立场）逐项排查 |
| 改进建议 | 按失分维度给可落地修改建议，对照主库真题/范文/大纲溯源 |
| IMA 知识库挂接 | 主库真题 / 范文 / 大纲 / 教程，改进建议更贴近考情 |

## 适用科目

- 系统规划与管理师（高级）——IT 服务规划、运营、持续改进、营销、团队、风险、质量、运维等方向

## 使用方法

1. 触发：提及「系规论文评分 / 打分 / 模拟阅卷 / 论文质量评估 / 这篇论文能得多少分」。
2. 提供：论文全文（建议完整粘贴）+ 对应题目原文；项目信息模糊时按模板补充背景。
3. 获取：标准 Markdown 模拟评分报告（五维明细 + 75 分折算 + 过线判定 + 红线检查 + 改进建议）。
4. （可选）授权后调用 IMA 主库，对照历年真题范式、参考范文结构、考试大纲给出溯源式改进建议。

## 评分模型速览

- 内部「百分制 5 维量表」：切题性 25 / 实践性 25 / 深度与广度 20 / 逻辑性 15 / 书面表达 15（权重合计 1.00）。
- 官方分 = 百分制 × 0.75（满分 75）；过线线 = 45。
- 档位：优秀（官方 ≥ 60）/ 通过（45–59）/ 不通过（< 45）。
- 任一红线触发即判不通过。详细锚点见 `references/scoring_rubric.md`。

## 安全护栏

- **严禁编造**：评分仅基于用户粘贴的真实文本，不臆造项目信息。
- **不代写/不替考**：输出评分与建议，引导用户自行修改完善，避免诚信风险。
- **次库不冒用**：招标项目仅作背景样例，须替换为用户本人实际参与的项目。
- **红线高亮**：缺摘要 / 项目概述 / 正文核心任一部分，或项目虚假 / 严重偏题，会显著失分乃至判不通过。
