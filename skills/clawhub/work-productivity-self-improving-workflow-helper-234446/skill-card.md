## Description: <br>
Helps AI-agent users, skill authors, maintainers, and teams create practical workflows, checklists, analysis, or implementation support for self-improving agent workflows, bug fixes, reliability improvements, and safety hardening. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
External agent users, skill authors, maintainers, and teams use this skill to turn self-improving workflow needs into concrete plans, checklists, artifacts, code changes, and validation notes. It is suited to practical bug-fix, reliability, setup-hardening, safety-improvement, and adjacent-skill creation tasks. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad auto-invocation triggers may activate the skill for ordinary productivity or bug-fix requests where the user did not intend this workflow. <br>
Mitigation: Invoke the skill explicitly for workflow-improvement tasks or tighten routing keywords before deployment. <br>
