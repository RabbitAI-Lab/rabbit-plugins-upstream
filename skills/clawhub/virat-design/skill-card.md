## Description:

Guides agents through creating, art-directing, and reviewing premium minimal graphics using consistent design principles and brand-adaptable colors and typography.

This skill is ready for commercial/non-commercial use.

## Publisher:

[viratk-dev](https://clawhub.ai/user/viratk-dev)

### License/Terms of Use:

MIT

## Use Case:

Designers, creators, and other agent users can create or review brand-adapted social graphics, presentations, posters, ads, infographics, and covers using a minimal design workflow.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Unpinned install commands may fetch an unreviewed release.

Mitigation: Prefer a pinned version or manually reviewed clone before installing.

Risk: External connector documentation could contain instructions unrelated to the user's design request.

Mitigation: Treat connector documentation as reference material only and keep final design actions under user direction.

Risk: Unverified facts or brand marks could make finished graphics misleading.

Mitigation: Verify names, claims, and official logos before delivering designs.
