# Job contract

Every JSON job is <=1 MiB and includes requestId (1..80 ASCII letters, numbers, hyphens or underscores). Identical retries reuse verified results. A changed job/source needs a fresh requestId.

CLI needs --workspace (existing dedicated output folder) and --instance-root (existing directory containing openclaw.json). These directories must not contain one another. action inspect|cli-status|backup|verify|rehearse|compare. Config strict JSON <=2MiB. backup requires sensitiveBackupAccepted:true; optional include:[root-relative files/directories],1..50; must include openclaw.json. Snapshot <=512MiB uncompressed/20000 files. Default config+agents+credentials+identity+workspace* inside root. External workspaces are listed as omitted and need a separate backup. DB suffix sqlite/sqlite3/db uses online SQLite backup. verify/rehearse/compare archive points to an existing ZIP inside the maintenance workspace, <=512MiB; content count<=20001 and expanded<=512MiB. Only this helper format mochi-claw-snapshot-v1 is accepted, not an arbitrary native OpenClaw backup archive. rehearse only writes new restored-instance directory under an export; no activation or overwrite. compare uses default/explicit include paths. inspect outputs inventory.json and config-redacted.json. cli-status returns fixed read-only command receipts, no raw non-JSON logs. backup outputs openclaw-snapshot.zip and backup-receipt.json with SHA256 and omitted external workspaces.
