## Description: <br>
Helps backend, platform, and developer-experience teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to turn API documentation requests into practical workflows, checklists, code-oriented guidance, and validation steps for OpenAPI or Swagger REST API documentation. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad triggers may activate the skill for generic API or developer-experience prompts. <br>
Mitigation: Review whether the task is specifically about OpenAPI or Swagger REST API documentation before relying on the skill output. <br>
Risk: Documentation guidance can introduce inaccurate API behavior, schemas, or examples if source inputs are incomplete. <br>
Mitigation: Validate generated documentation against the service implementation, OpenAPI tooling, and the user's stated success criteria. <br>
