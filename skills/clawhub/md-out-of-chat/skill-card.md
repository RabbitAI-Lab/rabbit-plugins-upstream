## Description:

Converts a named Markdown file or recent notes in a named folder into mobile-friendly, local HTML pages.

This skill is ready for commercial/non-commercial use.

## Publisher:

[bonniegeng-max](https://clawhub.ai/user/bonniegeng-max)

### License/Terms of Use:

MIT

## Use Case:

People and developers use this skill to read or share named Markdown reports, notes, and chat exports on a phone. It can also convert recently modified Markdown files in a folder the user names.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Conversion reads the specified Markdown files and may overwrite corresponding HTML files.

Mitigation: Name only the files or folder you intend to convert, and check existing HTML outputs before conversion.

Risk: Publishing a rendered page could expose sensitive Markdown content.

Mitigation: Review the content before requesting a public URL, and confirm deployment separately.
