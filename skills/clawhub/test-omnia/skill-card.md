## Description: <br>
Omnia provides agent continuity and cognitive health guidance for persistent memory, crash recovery, append-only audit trails, heartbeat monitoring, coherence checks, and witness-gated critical actions. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and external users use Omnia to add persistent identity, recovery, audit logging, health checks, and human approval patterns to AI agents that need continuity across sessions. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Cross-session memory and append-only audit logging may retain broad user queries, actions, secrets, or raw user content longer than intended. <br>
Mitigation: Use only when persistent memory is intended; define logging scope, exclude secrets and raw user content by default, and configure storage, deletion, and retention policies before real use. <br>
