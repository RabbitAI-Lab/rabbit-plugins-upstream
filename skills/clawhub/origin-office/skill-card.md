## Description:

origin-office helps agents convert native DOCX and PPTX files into anchorable, verifiable Benxiang objects with structure hashes for inspection, document tracking, and clause-level citation.

This skill is ready for commercial/non-commercial use.

Developers and document automation teams use this skill when DOCX or PPTX content needs to become AI-addressable structured objects, with verification support for source/package consistency and later document review workflows.

Risk: The skill instructs users to clone and run an external repository.

Mitigation: Run the workflow only on documents intended for processing and only in an approved environment.
