## Description:

理解开发需求，结合现有代码和规范形成可执行方案。适用于开始改动或调整方案；轻量任务保留短计划，中等和重型任务说明设计、依赖与验收。

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers use this skill to turn development requests into actionable plans grounded in the project's current code, standards, dependencies, and acceptance checks. It can produce a brief plan for a small change or a structured plan for larger work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A plan may misstate current behavior or applicable project standards if repository evidence is incomplete.

Mitigation: Check cited code paths, active standards, and acceptance criteria against the workspace before implementation; identify missing evidence and unresolved decisions.
