## Description: <br>
Manage entity status transitions in Basic Memory: archive completed work, move notes between status folders, update frontmatter, and handle edge cases. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[phernandez](https://clawhub.ai/user/phernandez) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
External users and developers use this skill to keep Basic Memory notes aligned with lifecycle status, including completing, archiving, pausing, cancelling, or reactivating entities while preserving historical context. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Ambiguous completion or bulk-archive requests could move the wrong Basic Memory notes or set an unintended lifecycle status. <br>
Mitigation: Review matched entities and destination folders before approving bulk moves or status changes, and ask for clarification when matches are ambiguous. <br>
