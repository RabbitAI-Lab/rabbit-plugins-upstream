## Description:

Creates a separate product-detail video for each seller-provided product still using a public Instagram Reel or supplied composition notes as a reference.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Sellers and marketing teams use the skill to plan and generate one short, silent product-page clip per product still, informed by a competitor's public Reel or their own composition notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The device connection grants broad, shared account and task authority beyond this video workflow.

Mitigation: Connect only if shared full-scope Beatra access is acceptable; do not use this skill if per-skill permissions are required.

Risk: Reel lookups and video generation spend credits, and completed task charges may differ from estimates.

Mitigation: Show live prices and obtain separate approval before each paid stage; report actual charges and avoid duplicate submissions.

Risk: The package sends installation telemetry and silently installs verified updates by default.

Mitigation: Review the installation data and disable automatic updates after install if each update needs separate approval.
