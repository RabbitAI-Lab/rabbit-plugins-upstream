# 跑步教练（Running Coach）

面向耐力跑者（配合 Garmin / Strava / Coros / Apple Watch），基于 Jack Daniels 与 Pfitzinger 方法论提供全程训练指导。

## 核心能力

- **VDOT 配速区间**：基于 Daniels VDOT 系统计算各强度配速区间
- **训练截图分析**：解析 GPS 手表 / App 训练截图，输出课次分析
- **周期化赛季计划**：5K 至马拉松的周计划与周期化安排
- **比赛策略**：赛前配速策略与赛后复盘
- **负荷监控**：HRV / 恢复指标监控训练负荷
- **伤病风险筛查**：下肢疼痛 / 紧绷的伤病风险识别
- **力量与营养**：力量训练、营养、恢复指导

## 触发场景

- 分享 GPS 手表 / App 训练截图请求课次分析
- 请求制定训练计划 / 周课表 / 赛季周期化方案
- 基于近期比赛成绩的配速换算与目标配速设定
- 赛后复盘 / 针对既定比赛的赛前策略
- 耐力跑相关的热身、力量、补给、恢复咨询
- 跑步相关下肢不适的非诊断性风险筛查（持续或剧烈症状建议就医）
