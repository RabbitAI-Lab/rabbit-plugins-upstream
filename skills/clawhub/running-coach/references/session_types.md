# Session Types

## Easy (E) — recovery / easy run
- **HR:** Z1-Z2 (≤ 75% HRR)
- **RPE:** 1-3
- **Pace:** clearly slower than goal marathon pace (> +30s/km)
- **Use:** recovery, base volume, aerobic base
- **Test:** can finish and speak a full sentence; no fatigue next day

## Steady (S) — progressive run
- **HR:** Z2 → Z3 transition (60-82% HRR)
- **Trait:** HR keeps climbing, not steady-state; usually progressive segments
- **Use:** aerobic efficiency, race-pace feel
- **Test:** HR rises from Z2 into Z3 with no plateau

## Tempo (T) — threshold
- **HR:** Z3-Z4 (82-93% HRR), ~LT 85-95%
- **Pace:** LT pace ± 10s/km
- **Duration:** steady 20-40min
- **Trait:** steady pace, HR stabilises on a plateau
- **Use:** raise LT, race specificity
- **Test:** "not sure if it's tempo" when HR won't plateau ≠ tempo

## Interval (I) — repeats
- **HR:** hard segment Z4-Z5 (93-100% HRR), recovery Z1-Z2 between
- **Structure:** structured sets with recovery segments
- **Use:** VO2max, running economy
- **Sub-types:** Cruise Interval (Z4), Strides (short/fast), VO2max Interval (Z5)

## Long Run (L) — distance
- **Distance:** > 15km or ≥ 25% weekly volume
- **HR:** Z1-Z2
- **Pace:** Easy pace or slightly faster (≤ goal marathon pace + 20s)
- **Use:** endurance, fat metabolism, race mental simulation
