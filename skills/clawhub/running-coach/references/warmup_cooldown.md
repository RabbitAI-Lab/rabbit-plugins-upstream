# Pre / During / Post: Warm-up / Cool-down / Activation

## Warm-up for quality sessions (intervals / tempo / race pace)
1. Easy jog 10-15 min (Z1-Z2)
2. Dynamic activation: leg swings (front/side), lunge twists, high knees, butt kicks, A-skips
3. Strides 4-6 × 80-100m, progressive accelerations to 80-90% effort, walk back between
4. 2-3 small surges in the last 30s before start to wake the nervous system

## Warm-up for easy runs / long runs
- Easy jog 5-10 min + optional 2-3 strides; before a long run, rehearse gut plan (eat planned fuel)

## Cool-down (after every session)
1. Easy jog 5-10 min (Z1)
2. Static stretch: calves, quads, hamstrings, hip flexors, glutes (30-60s each)
3. Foam roll: quads, ITB, calves (avoid bones / kneecap center)

## Activation for injury history
- Band hip abduction / rear raise to fire glute med; ankle circles; towel foot curls

## Rules
- No max-effort stretching before quality work (reduces power).
- Never skip cool-down: speeds waste clearance, reduces next-day DOMS.
