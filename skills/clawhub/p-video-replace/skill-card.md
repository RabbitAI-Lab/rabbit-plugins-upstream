This skill is ready for commercial/non-commercial use.

## Use Case:

Creators and video editors use this skill to swap a person, outfit, or product in existing footage using reference images while preserving the camera move and audio.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Source videos and reference images are uploaded to Pruna.

Mitigation: Confirm the user is comfortable sharing those assets with Pruna before uploading.

Risk: API access requires a PRUNA_API_KEY.

Mitigation: Use the key only for authorized Pruna requests and keep it out of shared outputs.

Risk: Prerequisite installs use mutable references, and an option can disable the safety checker.

Mitigation: Review or pin prerequisite installs in controlled environments and leave the safety checker enabled unless policy explicitly allows otherwise.
