## Use Case: <br>
Developers and technical users can use this skill for explicit P2P messaging and small file-transfer workflows, including connection setup, message sending, file transfer, and basic troubleshooting. It should not be used as a generic coding, testing, or deployment assistant outside those P2P communication tasks. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill asks for broad command execution and file read/write capabilities. <br>
Mitigation: Install and run it only for explicit P2P messaging or file-transfer tasks, and use a dedicated folder for received files and local history. <br>
Risk: The security summary says the skill also tells agents to use it for unrelated development tasks. <br>
Mitigation: Avoid using it for generic coding, testing, or deployment work unless the task is directly tied to the P2P communication workflow. <br>
