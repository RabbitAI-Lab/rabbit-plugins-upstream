## Description: <br>
Web search and scraping via Firecrawl API for searching the web, scraping pages, crawling sites, and extracting structured data from web pages. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[ashwingupy](https://clawhub.ai/user/ashwingupy) <br>

### License/Terms of Use: <br>


## Use Case: <br>
Developers and agents use this skill to retrieve web search results, scrape individual URLs, crawl websites, and return page content through Firecrawl. It is useful when a workflow needs current web content or structured web data via an API key authorized by the user. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Search terms, target URLs, and retrieved page content are sent to Firecrawl using the user's API key. <br>
Mitigation: Avoid submitting secrets, token-bearing links, internal-only systems, private documents, or regulated data unless the organization has approved Firecrawl use. <br>
