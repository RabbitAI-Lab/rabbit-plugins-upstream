# 装修全能体（尺寸 + 施工 + 验收 + 预算 + 合同 + 环保 + 材料 + 避坑 + 工程标准）

## 触发条件（Trigger）
- 某空间布局 / 柜体家具深高（玄关、客厅、厨房、餐厅、卧室、儿童房、书房、卫生间、阳台）
- 开关插座高度/数量/类别（16A/防溅/USB）、水路进水口预留、灯光色温/光束角
- 装修流程耗时、物料什么时候买、预埋/嵌入式电器何时定尺寸
- **施工流程 / 工艺标准 / 验收要点 / 避坑**（拆改墙体、水电开槽与打压、防水闭水、吊顶龙骨、瓷砖空鼓、乳胶漆、卫浴安装、无主灯、定制家具）
- 装修避坑（空开、插座位置、坐便孔距、承重墙等）
- **预算**：大概要花多少钱、总价框算、硬装/主材/定制/备用金怎么切分、半包vs全包、城市参考价
- **合同**：怎么签防增项、付款比例、闭口合同、质保年限、9类材料写进合同、定金vs订金、签约核对清单
- **环保/甲醛**：板材等级(ENF/E0)、入住检测标准(GB/T 18883)、通风晾放、治理误区
- **材料选型**：主材/辅材怎么分、板材/瓷砖/门窗/台面/五金/填缝怎么选、市场价格区间作比价锚点
- **质量通病与避坑**：吊顶开裂/检修口/转角、墙面裂纹空鼓、玻化砖上墙空鼓、地砖空鼓错台、电管线槽裂缝、涂料泛碱等"常见病"的成因与管控措施
- **收房验房**：三书一证一表、毛坯/精装房验房清单、承重墙标识、相位/等电位/活线/CCC玻璃
- **竣工**：逐类验收标准、维保与图纸交接、开荒保洁、污染物与空置时间

## 操作契约（Operating Contract）
1. 先判定问题属于「尺寸布局 / 施工验收（九大工种） / 预算合同环保」哪一类。
2. 尺寸施工类优先给**具体数值区间 + 验收标准**（如防水高度180–200cm、水管打压0.8MPa降≤0.05MPa），再给原则。
3. 预算合同环保类优先给**红线数值 + 可执行清单**（如 3331 付款、增项≤5%、ENF≤0.025），不模糊。
4. 涉及水电/插座/预埋/防水必须在「不可逆节点」核对；涉及签约/付款必须提示"闭口合同+尾款≥10%质保金"红线。
5. 凡明确避坑（counter-example）主动提示用户。
6. 不编造书中/资料中没有的工艺/验收/价格数值；合成资料中具体型号价格以"门店实际为准"标注。

## 工作流程（Workflow）
1. **归类**：定位到九大空间之一、水电/灯光/物料栈、九大工种，或预算/合同/环保问题。
2. **查基准**：尺寸类先套三大基础尺寸；施工类先套对应工种验收表；预算类先套切分框架/总价框算；合同类先套闭口合同+付款红线；环保类先套板材等级+检测标准。
3. **取数值**：从下方「知识速查」或 `synthesis.md`(尺寸) / `synthesis-construction.md`(施工验收) / `synthesis-budget-contract-eco.md`(预算合同环保) / `synthesis-references.md`(材料选型/质量通病/收房验房/竣工) 取要点。
4. **给避坑**：附带该场景易错点（预算超支、增项、甲醛超标等）。
5. **标节点**：若涉及购买/预埋/签约，提示物料时序、不可逆红线或闭口合同要求。

## 知识速查·尺寸（Synthesis，非原文照抄）
### 三大基础尺寸
- 过道：紧凑60 / 舒适80 / 宽松100 / 双人并行120 cm
- 餐桌到墙：紧凑60 / 舒适80 / 椅后过人≥100 cm
- 家具高：椅座45、餐桌70-75、台面80-90 cm

### 九大空间关键尺寸
- **玄关**：柜深35-40、底空20-25；换鞋凳40-42；开放格30-40；台面=身高×0.6(90-105)
- **客厅**：沙发座深48-60；沙发↔茶几40-50；背景墙↔电视≥250；电视中心高90-100；面宽250-300放三人/>600放L+单
- **厨房**：过道≥80；台面深60(取60)；高=身高/2+5(灶台低8-10)；吊柜深30-35；U形短边≥170长边≥240
- **餐厅**：方桌四人140×80/六人180×90/八人220×100；圆桌六人Ø110-130；到墙紧凑60舒适80过人100；餐边柜深40
- **卧室**：床双150/180-200；床尾过道80-120；衣柜深55-60；短衣90-100/长衣140-160/挂裤60-80/抽屉15-20
- **儿童房**：榻榻米床宽120-150高45；上下床宽80-120二层高130-160；楼梯踏步高30；书桌高75腿活动≥80
- **书房**：书桌深≥60；书柜深30-35层板高30单格宽≤60；双人台≥200
- **卫生间**：单盆宽60-120台盆高80-85；坐便孔距30.5/35/40(不买通用)；淋浴最小80×100花洒高90-100；三分离最小235×140四分离≥5.8m²
- **阳台**：洗衣柜深60；叠放宽70高180/并排宽135高90；清洁柜宽30-40深40-60

### 水电灯光
- **插座高(cm)**：玄关130/15；沙发旁30×2+空调220；电视柜40+立式50；餐边柜20+冰箱50；厨房小厨电30/水槽40/蒸烤180/烟机220(≥10个)；床头70/对面90/书桌30/空调220；卫智能马桶40/洗漱30/洗衣130(防溅)；智能窗帘顶20-30/扫地30
- **进水口高(cm)**：台盆45/坐便20/电热水器170/花洒110/洗衣机叠放120/燃气热水器150/厨房台盆45/洗碗机45；冷热水间距除电热水器10外均15，左热右冷
- **线径**：普通2.5mm²、厨房/卧室空调/直热电热水器4mm²；冰箱独立回路(总闸外)；水区漏保
- **灯光**：射灯离墙嵌入20-30/轨道40-50，灯间距70-140；光束角15°展示/24°局部/36°洗墙/60°基础；色温家居3000-4000K

### 附录
- 流程：量房设计→拆建水电(最不可逆)→瓦木油→厨卫吊顶+地板；总时长≥3月
- 物料七步：设计前(制冷制热换气预埋)→定制家具前(嵌电器尺寸)→水电前(家具电器五金灯具)→瓦工前(瓷砖窗地板)→油工前(漆壁纸背景墙门)→补漆前(五金洁具灯具)→入住前(成品软装)

## 知识速查·施工验收（取自 synthesis-construction.md）
### 总红线（不可逆）
拆改动错承重墙=拆一砌预算翻倍；水电封槽后无法改；防水贴砖后漏了要砸；预埋(龙头/花洒/轨道/壁挂马桶水箱)必须水电前买好。

### 拆改
- 三类禁拆墙：承重墙(厚>20cm/声沉/黑体)、配重墙(老房阳台)、外立面墙
- 新砌墙验收：平整度≤3mm、垂直度≤2mm(2m靠尺)；植筋间距<50cm末端90°弯钩；顶部斜砌；厨卫底部防潮地梁20–30cm；门洞过梁两侧进墙≥20cm；新旧墙挂网；等~1月干透再刮腻子

### 水电强电 12 点（必须达标）
分色(火红零蓝地双色)；16管≤3线/20管≤4线同回路；开槽宽=管径+10深=管径+15(混凝土横槽≤30/其他≤50cm)；就近斜拉活弯可抽拉；管卡转角≤15直线≤80cm；电路上水路下、厨卫走顶；出墙螺纹管/黄蜡管；接线盒锁母+盒内留~10cm+86型；线管内无接头；兆欧表+相位仪检测

### 水路
上热下冷左热右冷、平行间距15cm；台盆出水口50/花洒110cm、出墙25mm；吊顶内热水管包保温棉；热熔接管、交叉用过桥弯、穿墙金属保护套；管卡冷60/热30cm；**打压0.8MPa 2h降≤0.05MPa**；排水6秒≥5L；检查口不封死；完工拍照留底

### 防水
铲能撕动的原层→基层封槽拉毛墙固找平→双组分薄涂多层2–3遍(首层固4–8h交叉涂二层)；高度统一180–200cm、地面返上30cm、门口外延50两侧20cm；有地暖加丙纶；**闭水48h水位不降**(提前招呼楼下)

### 木工吊顶
边龙骨膨胀螺栓≤60cm；吊杆≤100(端头≤30)cm；主龙80/副龙40cm双铆钉；自攻螺钉板边15mm、埋入0.5–1mm油工防锈漆；短边错缝>30cm；L形转角两边≥30cm；接缝留3–5mm倒角；大面积平吊起拱3–5mm。吊顶前预埋10设备(风口/筒射灯/磁吸轨道/移门轨道/烟道/灯带型材/幕布/窗帘盒：手动双层18–20电动20–25单层10/15cm)

### 瓦工/油工
瓷砖612/715/918/1228尺寸；墙压地；完成面高度统一；瓷砖验收6要点(空鼓/平整/坡度/留缝/色差/阴阳角)。乳胶漆滚涂2–3遍(5–35℃/湿<80%/含水<10%)，**刷完密封晾干≥24h再开窗**；余漆留存补漆。微水泥6遍涂+2遍磨+双组分聚氨酯罩面2–3遍

### 卫浴/灯具
坐便孔距305/400mm(不买两种孔距)；台盆上沿85–95cm、镜柜底边~120cm；自己买中性玻璃胶(透明为主瓷白用于白位)。无主灯：射灯15/24/36°、筒灯60–120°；色温同品牌；磁吸轨道侧轨+紫铜扁线+壁厚≥1.6mm(品牌不通用木工前定)；筒射灯开孔前油工已完须磁铁找龙骨

## 知识速查·预算/合同/环保（取自 synthesis-budget-contract-eco.md）
### 预算（先定总盘再切分）
- **切分**：硬装50% / 主材25% / 定制10% / 备用15%；软装家电单列；**必留备用金 10%–15%**。
- **总价框算**：套内面积×城市等级×档次。中等自住：一线1500–2200、新一线/二线1200–1700、三四线900–1400 元/㎡。
- **房型总价速算(万元·建面)**：两居70–90㎡中等11–18；三居100–130㎡中等15–26；四居140㎡+中等21–36。
- **各板块口径**：硬装半包600–1200/㎡；主材800–1800/㎡；全屋定制1000–2500/㎡投影；暖通200–600/㎡；设计管理费(半包+主材)×8%–15%。
- **半包基准**：管理费约6%；瓷砖损耗约10%；水电约4米/㎡(新房减半)；瓦工约85元/㎡；油工约43元/㎡(含铲墙皮墙固腻子打磨乳胶漆)。

### 合同（守住钱袋子，红线优先）
- **付款 3331**：开工30%→水电30%→泥木30%→竣工10%；**首期≤30%、尾款≥10%作质保金**，验收合格再付。
- **闭口合同是底线**：总价一次锁定；增项须业主书面签字且≤5%，超出公司承担；漏项责任归乙方；拒绝"按实结算/暂定"。
- **工期质保**：工期精确到日；延期违约金0.1%–0.3%/天(上限≤5%总价)；**防水+水电≥5年、其他≥2年**。
- **9类材料写进合同**：电线/板材/水管/防水/石膏板/油漆/腻子粉/水泥/开关插座(品牌+型号+规格+等级)。
- **损耗封顶**：电线≤5%、瓷砖≤8%，超耗公司承担。
- **定金vs订金**：定金不退、订金可退；没定方案前一分定金别交。
- **签约核对**：主体是公司非个人、附件骑缝章、不签空白合同、拒绝阴阳合同、7节点(拆改/水电/防水/瓦工/木工/油漆/竣工)到场验收签字、水电交付CAD走向图+全景照片。

### 环保/甲醛（源头控制为主）
- **板材等级**：ENF≤0.025、E0≤0.05 mg/m³；无"零甲醛"，问检测报告。
- **入住标准**：GB/T 18883-2022 密闭12h 甲醛≤0.08 mg/m³（居住标准，比 GB50325 更严）；老幼孕妇更严；宣称即入住仅约29%真达标。
- **来源**：板材胶水+腻子；用无醛胶、成品耐水腻子；乳胶漆看十环/法国A+认证、VOC达标。
- **通风晾放**：晾3–6个月，夏季高温加速；对流通风+风扇，柜门抽屉全开；布艺先水洗暴晒。
- **治理误区**：不信"一次治理永久达标"；绿植炭包仅心理作用；检测用专业机构/电化学仪，别信网红试纸；有味≠甲醛高，以数值为准。

## 知识速查·材料选型与质量通病避坑（取自 synthesis-references.md）
### 材料选型速查
- **主材/辅材**：主材=装修后可见(地板瓷砖洁具橱柜门窗灯具开关插座卫浴吊顶石材地漏水槽五金)；辅材=隐蔽(龙骨水泥沙砖防水管件电线腻子胶漆)。
- **板材**：实木颗粒(柜体主流)/多层实木(高端防潮)/中纤板(门板背板忌潮)/大芯板(现场木工)/三聚氰胺免漆板/实木；门板饰面 双饰面→防火→吸塑→亚克力→包覆→烤漆→实木。
- **瓷砖**：釉面(最常见)/通体/抛光/玻化(地面)；**填缝演进：白水泥→勾缝剂→美缝剂→瓷缝剂(最优)**，大砖厨卫建议美缝/瓷缝。
- **门窗**：断桥铝(隔音隔热密封最好，推荐) > 塑钢(保温好久晒掉色) > 铝合金(广用不耐隔热) > 木(温馨易变形)。
- **地漏**：防臭优先**水封式**；回型地漏工艺。
- **台面**：人造石英石(性价比最高首选) > 人造石/亚克力(可一体造型) > 不锈钢/天然石(脆多孔或有放射性)。
- **计价**：橱柜延米法(含底+吊柜，局部只底柜按2/8或4/6折算)或柜体法；半包200–300、全包700–800 元/㎡作比价锚点(非实时价)。

### 收房验房（毛坯+精装）
- **收房**：开发商须交"三书一证一表"；面积误差>3%可退房或开发商补差价；**标识承重墙严禁拆改**；查水电位置防错挖。
- **精装验收要点**：相位仪测插座左零右相接地在上；卫生间查等电位；弱电查"活线"(抽动灵活)；7层+外开窗/面积>1.5㎡/落地窗玻璃离地<500mm须有CCC；瓷砖空鼓/泛水坡度/渗漏；坐便冲水通畅与墙垂直；中央空调/新风漏水的漏氟噪音检查；净高四纵四横误差≤10mm。

### 水电深化（补施工手册）
- 工期约9天；**走顶不走地、走竖不走横**(顶部漏水易发现、墙上横槽破坏承重)；冷热水管间距>20cm。
- **线径**：照明/普插2.5mm²、厨房插/空调插4mm²；载流量2.5→28A、4→35A、6→48A。
- **回路**：大功率独回路(空调冰箱烤箱洗衣机热水器浴霸)；冰箱独回路外出只留冰箱；16A回路例 饭锅3A+微波4A+烤箱4A+其他4A=15A。
- **质检**：强弱电禁共管共底盒、交汇弱电管裹铝箔≥100mm；底盒开关下沿1400mm±100；**淋浴冷热水中心150mm±5、左热右冷间距≥100mm**；打压0.6–0.8MPa 30min降≤0.05MPa；马桶坑距300/400mm；排水坡度≥1%+存水弯防臭。

### 质量通病避坑（家装高频项，含管控措施）
- **吊顶开裂/检修口周边开裂**：伸缩缝15–20mm+背条；检修口四周加固轻钢/型钢龙骨+四角加丝杆+副龙下0.5mm"回"字白铁皮；转角裁"L"型0.5mm镀锌铁皮加固+上口50付龙斜撑；主龙大吊/挂钩**正反扣**安装。
- **墙面电管线槽裂缝**：预埋深度(管外表面距原粉刷面)**≥15mm**+管卡牢；槽内清垃圾浇水润冲洗；分层粉刷+界面剂贴网格布+纸胶带批腻子；抹灰24h后湿润养护≥3天。
- **玻化砖上墙空鼓**（淘汰水泥砂浆直接上大砖老法）：砖背开浅横槽冲洗净+**玻化砖/重砖粘结剂+界面剂，锯齿镘刀5–7mm**+砖缝≈1mm+挂贴法。
- **地砖空鼓/错台**：干硬性砂浆、板块浸水晾干浇素水泥浆轻击压实；**留缝1–2mm**；养护洒水≥7天禁上人；大面积设伸缩缝。
- **涂料泛碱**：涂刷前基层含水率**≤10%**、温度≥10℃、完工及时封闭门窗。
- **不同材料地面交接**：用成品收边条、选变形系数相近材料。

### 定制家具深化（橱衣柜同源）
- 五大件：柜体+门板+五金+台面+电器；操作台高≥750(擀面≥900)；布局U形较理想、洗切炒动线优先。
- **环保现代化**：认 **GB/T 39600-2021 ENF(≤0.025)/E0(≤0.05)/E1(≤0.124)**；不追模糊"欧标E0级"(旧国标E2/E1/E0 mg/L写法已过时)，落地以国标等级+检测报告为准。
- 五金参考：铰链 海蒂诗/百隆/DTC；功能拉篮 凯斯宝玛/铂格/悍高（选购比对非强制）。

### 竣工与环保入住
- 验收：地砖平整无漏贴、勾缝饱满不泛黄；乳胶漆无刷痕流坠起皮裂纹透底；插座左零右火上接地+潮湿位防水罩；**洁具陶瓷类不得用水泥砂浆固定**、接触处打密封胶、出水左热右冷。
- 提醒：办维保清算增减项、**交接水电隐蔽工程图纸**(后期打孔避让)；家具不拖地；墙面打孔避水电管；勤通风。
- 环保：甲醛(板材胶)/氡(红色花岗岩不宜家装)/TDI(聚氨酯)；根本买正品+通风；晾3–6个月；绿植(绿萝/虎尾兰/芦荟)辅助非主力。

## 知识速查·工程标准验收红线（现行规范纠正，详见 synthesis-standards.md）
> 编译自《建筑装饰装修工程施工技术手册》+《中建八局技术标准培训宣贯》，已把原书引用的 **GB 50210-2001→2018、GB 50325-2010→2020、GB 50222-2001→2017、GB 50045-2005→并入 GB 50016-2014(2018版)** 等过期规范全部纠正；工装幕墙、工业地坪章节已摈弃。

### 通用纠正（先念一遍，别用旧版号）
- 工程验收：**GB 50210-2018 标准**（2018-09-01，原 2001 规范已废止）；室内污染：**GB 50325-2020 标准**（2020-08-01，原 2010 规范已废止）；安全玻璃：**JGJ 113-2015**；护栏：**GB 50352-2019 / GB 50096-2011**；人造板甲醛：**GB 18580-2017**（E1≤0.124 / E0≤0.050 / ENF≤0.025）。

### 各工种红线（家装适用）
- **抹灰**：总厚≥35mm 须加强网；不同基体交接处抗裂网搭接≥100mm；普通抹灰平整/阴阳角/分格 ≤4mm、高级≤3mm；外墙滴水槽宽深均≥10mm。
- **吊顶**：吊杆距主龙端≤300mm；设计无要求时起拱短跨 1/200~1/300；**重型灯具/吊扇/风管严禁装在龙骨上**（GB 50210-2018 强制 7.1.12，须独立吊挂）；石膏板螺钉距包封边10~15mm、切割边15~20mm。
- **轻质隔墙**：轻钢竖龙中距≤600mm（贴砖面层≤420mm）；玻璃隔墙用安全玻璃。
- **楼地面**：瓷砖/石材**空鼓率≤5%/自然间**；木搁栅间距≤300mm、与墙留缝≥10~20mm；卫生间楼板四周混凝土翻边**≥200mm**（≥C20）；踏步高差≤10mm。
- **门窗**：铝合金窗型材壁厚**≥1.4mm**、门**≥2.0mm**（主控）；塑料门窗固定点≤600mm、平开≤80N/推拉≤100N（铝合金推拉≤50N）；安全玻璃（JGJ113-2015）：7层+外开窗、单块>1.5㎡、落地窗底距装修面**≤500mm**（原书900mm已纠正）、倾斜/天窗。
- **饰面砖**：内墙满粘、粘结砂浆厚5~8mm、基层抹灰每遍≤7mm；无空鼓裂缝。
- **涂饰**：溶剂型基层含水率≤8%、乳液/腻子≤10%、木材≤12%；腻子粘结强度≥0.3MPa；抹灰/吊顶/细部/地面/电气完成并验收后再涂。
- **细部**：橱柜台面宽≥500mm、高宜800mm、灶台高≤700mm、底板距地≥100mm；阳台/临空**护栏<24m≥1.05m、≥24m≥1.10m**、栏杆间距≤0.11m；栏板玻璃≥12mm钢化或≥16.76mm钢化夹层。

### 室内污染物限量（GB 50325-2020 Ⅰ类住宅 · 工程验收）
- **甲醛≤0.07、苯≤0.06、甲苯≤0.15、二甲苯≤0.20、TVOC≤0.45、氨≤0.15、氡≤150**（较2010版更严：甲醛0.08→0.07，新增甲苯/二甲苯）。入住看 **GB/T 18883-2022 密闭12h：甲醛≤0.08、TVOC≤0.60**。

### 淘汰/禁用于家装的工艺（红线，明确摈弃）
木门窗现场制作、散热器罩、现场无计量配水泥砂浆、107/801胶、现场熬沥青、纸筋/麻刀石灰+水刷石/干粘石/水磨石现制、石棉制品、油性溶剂型涂料现场大量涂刷——一律不带入家装答案；门窗应成品采购工厂化加工，粘结用瓷砖胶/预拌砂浆。

### 中建八局企业标准补充（ZJQ08-SGJB 210-2017，实操加严参数 · 详见 synthesis-standards.md §8）
家装适用第4–9/11–13章，第10章幕墙+工业地坪已摈弃；该 2017 企业标准的旧国标引用按 §1 纠正为现行版。重点补充：
- **吊顶起拱（精确 tiered）**：面积≤50㎡ 短跨 1‰~3‰；>50㎡ 为 3‰~5‰；同标高>100㎡ 或单向>15m 设伸缩缝。
- **吊顶灯具重量分级**：≤1kg 直接装面板、≤3kg 装主龙骨、>3kg（吊扇/空调）必须吊挂承重结构（GB50210-2018 强条 7.1.12 落地）；潮湿房纸面石膏板单层≥12mm/双层各≥9.5mm。
- **门窗安装偏差**：铝合金窗槽口≤1500→1.5mm、>1500→2mm、垂直2.5mm、标高5mm；塑料门窗固定点距角/中框 150~200mm、间距≤600mm。
- **抹灰允许偏差**：普通/高级 立面垂直 4/3mm、表面平整 4/3mm、阴阳角 4/3mm。

## 质量门（Quality Gates）
- 尺寸必须带区间与适用条件，不给孤立数字。
- 水电/插座/预埋/防水类答案必须标注「不可逆节点核对」。
- 施工验收类给出明确数值+「必须达标」判定，不模糊。
- 预算类给切分框架+区间，标注"以当地报价单为准"，不算死单价。
- 合同类必带红线（闭口合同/3331付款/增项≤5%/质保≥5年），不泛泛而谈。
- 环保类必给国标数值(ENF/E0、18883 密闭12h≤0.08)，不替用户做检测结论。
- 材料类给选型依据+区间，标注"价格以门店实际为准"，不编造实时单价；环保等级用现行国标(ENF/E0/E1)，不沿用旧E2/E1/E0 mg/L写法。
- 验房/竣工类给可勾选清单与合格判定（相位/等电位/活线/CCC/空鼓/泛水），不替用户做现场结论。
- 施工流程类按六维（工艺流程/材料选型/材料验收/施工质量要点/施工质量通病防治/施工验收）组织答案，引用 synthesis-construction-flow.md，不漏维度。

## 边界行为（Boundary）
- 不替代设计师现场量房；尺寸数值为通用基准，特殊户型/无障碍需调整。
- 不编造品牌型号与实时价格；不编造原书/资料没有的工艺/验收/价格数值（原书图片表格已提炼，需逐字回查原书页；合成资料中具体型号价格以"门店实际为准"标注）。
- 本 Skill 覆盖 尺寸+施工+验收+预算+合同+环保 的**知识速查与红线提示**；若用户发来**报价单/合同原件/现场照片要求"帮我审"**，建议配合本机专用诊断 skill（报价审核/合同审核类）做深度审计，本 Skill 可先基于知识库指出常见风险点。

## 自测（Self-Tests）
1. 问「厨房过道做多宽」→ ≥80cm且台面深取60，提示过道/台面深最易忽视。
2. 问「冰箱插座留哪」→ 留侧边非背后，冰箱独立回路总闸外。
3. 问「卫生间三分离最小多大」→ 235×140，门最小宽80。
4. 问「水管怎么验收」→ 打压0.8MPa、2h降≤0.05MPa，且检查口不封死、完工拍照。
5. 问「新房墙体能拆吗」→ 承重墙/配重墙/外立面墙三类禁拆，拆错拆一砌预算翻倍。
6. 问「防水做多高」→ 统一180–200cm、地面返上30cm、门口外延50两侧20cm，闭水48h。
7. 问「装修大概多少钱」→ 先按切分框架(硬装50/主材25/定制10/备用15)，再用套内面积×城市×档次框算区间，标注以当地报价为准。
8. 问「合同怎么签才不被加钱」→ 闭口合同+3331付款(尾款≥10%质保金)+增项≤5%且须书面签字+9类材料写进合同。
9. 问「板材E0和ENF哪个好/多久能入住」→ ENF≤0.025优于E0≤0.05；晾3–6个月+密闭12h检测≤0.08(GB/T18883)再住，不信"即入住"。
10. 问「收房要查什么/精装房怎么验」→ 三书一证一表；验相位(左零右相)、等电位、弱电活线、7层+外开窗CCC；瓷砖空鼓/泛水坡度；中央空调新风漏水漏氟；净高误差≤10mm。
11. 问「吊顶为什么开裂/怎么防」→ 伸缩缝未断开/检修口未加固/转角未加强；管控：伸缩缝15–20mm+背条、检修口四周加固轻钢龙骨+四角丝杆+"回"字白铁皮、转角L型镀锌铁皮+斜撑、主龙大吊正反扣。
12. 问「玻化砖上墙空鼓怎么办/大砖怎么贴」→ 淘汰水泥砂浆直接上墙；用玻化砖粘结剂+界面剂、锯齿镘刀5–7mm、砖缝≈1mm、挂贴法；砖背开浅横槽冲洗净。
13. 问「断桥铝和铝合金门窗选哪个/台面选什么」→ 断桥铝隔音隔热密封更好(推荐)；台面人造石英石性价比最高首选，不锈钢/天然石各有短板。
14. 问「装修公司报价哪些会加钱」→ 对照隐性增项清单：找平/阳角条/满挂网/美缝/大砖人工/双眼皮吊顶/水电超点位/老房拆除修复/上楼垃圾费等均大概率加钱，签约前核进闭口合同。
15. 问「门窗型材壁厚多少/铝合金窗够不够」→ 铝合金窗主要受力部位壁厚≥1.4mm、门≥2.0mm（GB 50210-2018 主控），低于此数为不合规，须换。
16. 问「护栏做多高/阳台栏杆多高」→ 临空<24m≥1.05m、≥24m≥1.10m（GB 50352-2019/GB50096），栏杆间距≤0.11m 防攀爬；栏板玻璃≥12mm钢化或≥16.76mm钢化夹层。
17. 问「住宅甲醛合格线是多少」→ 工程验收看 GB50325-2020 Ⅰ类：甲醛≤0.07、TVOC≤0.45；入住看 GB/T18883-2022 密闭12h：甲醛≤0.08；两标准测量条件不同都要看，原书 GB50325-2010（0.08）已废止。
18. 问「瓷砖空鼓多少算合格/规范空鼓率」→ 每自然间空鼓砖≤总数5%（GB 50209 / 对接 50210-2018）；边角局部空鼓可但不得集中；卫生间楼板四周混凝土翻边≥200mm。
19. 问「哪些工艺已经被淘汰不能用了」→ 木门窗现场制作/散热器罩/107胶/现场熬沥青/纸筋石灰水刷石/石棉制品已禁；门窗应工厂成品、粘结用瓷砖胶；原书 GB50210-2001 已废止，按 2018 版执行。
20. 问「吊顶起拱多少/伸缩缝怎么设」→ 设计无要求时面积≤50㎡短跨 1‰~3‰、>50㎡为 3‰~5‰；同标高>100㎡或单向>15m 设伸缩缝（中建八局 2017 7.1.10/7.1.11，比旧"3‰"更精确）。
21. 问「吊灯/空调能不能直接挂吊顶龙骨上」→ ≤1kg(筒灯射灯烟感)直接装面板、≤3kg 装主龙骨、>3kg或震颤设备(吊扇/空调)必须吊挂建筑承重结构（GB50210-2018 强条 7.1.12 + 中建八局 7.1.15）。
22. 问「铝合金/塑料门窗安装允许偏差多少」→ 铝合金窗槽口≤1500→1.5mm、>1500→2mm、垂直2.5mm、标高5mm；塑料门窗固定点距角/中框150~200mm、间距≤600mm（中建八局 2017 企业标准，作加严内控）。
23. 问「施工流程按哪六维拆」→ 工艺流程/材料选型/材料验收/施工质量要点/施工质量通病防治/施工验收，逐步骤拆解（见 synthesis-construction-flow.md）；不可逆项（拆改/水电/防水/预埋）优先。
24. 问「玻化砖能不能水泥砂浆直接上墙」→ 已淘汰老法；用玻化砖粘结剂+界面剂、锯齿镘刀批刮5–7mm满粘、砖缝≈1mm、挂贴法（见步骤6 通病防治维度）。
25. 问「水电走顶还是走地」→ 走顶不走地、走竖不走横；墙横槽破坏承重，应走顶后再竖下到点位，混凝土墙横槽≤30cm其他≤50cm不切钢筋。
26. 问「防水闭水试验做多久」→ 注水20–40mm、48h水位无明显回落为合格；厨房/阳台无地漏不做；门槛止水坎不能省。
27. 问「抹灰什么情况要挂网/加强」→ 总厚≥35mm加强；不同基体交接（砖墙/混凝土/轻质墙）必须挂抗裂网、与各基体搭接≥100mm（隐蔽验收），防开裂空鼓。

28. 问「每道工序怎么盯才不踩坑/小白能照着干吗」→ 按 `construction-flow/NN-*.md` 六维细则逐步执行；不可逆工序（拆改/水电/防水/抹灰内挂网/吊顶承重）须在封闭前过门禁 G1–G8，每步第六维给允许偏差(mm)+检验方法拿尺量；G9 环保入住前按 GB/T18883 检测。
29. 问「裱糊/软包/细部(橱柜护栏门窗套)怎么做」→ 壁纸基层含水≤8%、阳角包过≥20mm；软包木龙骨防腐含水≤12%；橱柜台面≥500mm宽、高宜800/灶台≤700、底板距地≥100；护栏1.05/1.10m、栏板玻璃≥12mm钢化(CCC)；详见 `construction-flow/11-*.md`、`12-*.md`。
