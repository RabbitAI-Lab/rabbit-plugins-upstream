# 步骤 9 · 门窗工程

> **本步定位**：全屋"眼睛"与安保，型材壁厚/安装垂直度/密封直接关系隔音隔热防漏。成品化采购、工厂加工（淘汰现场做木门窗）。
> **关联**：前接抹灰/拆改（洞口尺寸合格、预埋件隐蔽验收），后接腻子收口/五金洁具。

---

## 一、工艺流程

1. **洞口验收**：洞口尺寸偏差（表面平整/正侧面垂直/对角线均 ≤3mm）；预埋件隐蔽验收合格；相邻洞口通线（垂直方向相邻相对偏差 ≤10mm，全楼 ≤15–20mm）。
2. **弹落位线**：按 50 线+垂直线弹门窗基准线，同类型洞口横平竖直。
3. **框安装**：
   - 铝合金/塑料：框就位→调垂直/水平/标高→临时固定→**膨胀螺栓/固定片**固定（距角/中框 **150–200mm**、间距 **≤600mm**）。
   - 木门：预埋木砖（半砖大、间距 ≤1.2m）或膨胀栓固定。
4. **填缝**：框与墙间隙用**闭孔弹性材料（发泡胶）填嵌饱满**，外侧耐候密封胶（胶缝有效厚 >6mm 或三角截面宽 >8mm）。
5. **扇/五金**：合页距扇端 ~200mm、框扇铰链配合间隙 ≤胶条厚；锁点分布合理；推拉窗装防脱落装置。
6. **玻璃**：按洞口用安全玻璃（见质量要点）；外窗/落地窗玻璃底边 <500mm 或 >1.5㎡ 须 CCC。
7. **清理保护**：交工前揭保护膜、擦净。

---

## 二、材料选型

| 类型 | 选型要点 | 适用 |
|---|---|---|
| 断桥铝 | 铝合金升级，隔音隔热密封最好 | **推荐**家装外窗 |
| 塑钢 | 保温好、久晒掉色 | 性价比 |
| 铝合金 | 价廉不耐隔热 | 普通 |
| 木门 | 温馨易变形，须烘干含水≤12% | 室内 |
| 玻璃 | 中空玻璃（空气层按节能）；安全玻璃（钢化/夹层） | 按部位 |

**型材壁厚红线（GB 50210-2018 主控项）**：金属门受力部位截面最小壁厚 **≥2.0mm**，窗 **≥1.4mm**（铝合金窗 GB/T 8478 同）。塑料门窗内衬增强型钢壁厚符合产品标准。

---

## 三、材料验收

- 门窗：查出厂合格证、性能检测报告（抗风压/水密/气密/传热）、型材壁厚（游标卡尺：门≥2.0/窗≥1.4mm）。
- 玻璃：查 CCC、厚度、钢化/夹层标识、无划伤气泡；中空玻璃双道密封（单道 10±2mm）。
- 五金：查型号规格、不锈钢铰链（厚 ≥1.5mm）、无锈蚀。
- 复验：人造木板门窗套甲醛（GB 50325）。

---

## 四、施工质量要点

- **壁厚红线**：门受力部位 ≥2.0mm、窗 ≥1.4mm（强条，进场游标卡尺抽测）。
- 固定点距角/中框 150–200mm、间距 ≤600mm；严禁固定在砖缝。
- 框墙缝隙闭孔弹性材料填实+外侧耐候胶密封（有效厚 >6mm）。
- 安全玻璃：7 层及以上外开窗、面积 >1.5㎡、玻璃底边离地 <500mm 落地窗须 CCC；栏板玻璃 ≥12mm 钢化或 ≥16.76mm 钢化夹层（JGJ 113-2015 底边 500mm 规则）。
- 推拉窗防脱落装置必装；平开窗铰链同轴。
- 开关力：推拉门窗 ≤100N、平开 ≤80N（用测力计）。

---

## 五、施工质量通病防治

| 通病 | 原因 | 防治 |
|---|---|---|
| 渗漏/透风 | 填缝不实、胶缝薄 | 闭孔发泡填实+耐候胶>6mm |
| 启闭不畅/下垂 | 五金不当、未调 | 铰链同轴、防脱落装、开关力达标 |
| 非安全玻璃伤人 | 误用普通玻璃 | 按部位用钢化/夹层+CCC |
| 框变形 | 临时固定物未拆/硬物顶 | 完成后及时移除临时固定 |

---

## 六、施工验收（GB 50210-2018 门窗）

**主控项**：品种/类型/规格/开启方向符合；**金属门壁厚≥2.0mm、窗≥1.4mm**；安装牢固；安全玻璃符合；隐蔽验收（预埋/锚固/密封）有记录。

**铝合金门窗允许偏差**

| 项目 | 允许偏差 |
|---|---|
| 槽口宽高 ≤1500mm | 1.5mm |
| 槽口宽高 >1500mm | 2mm |
| 槽口对角线 ≤2000mm | 3mm |
| 槽口对角线 >2000mm | 4mm |
| 正侧面垂直度 | 2.5mm |
| 横框水平度 | 2mm |
| 横框标高 | 5mm |
| 推拉扇与框搭接量 | 1.5mm |

**留缝（木门）**：内门对口缝 1–2.5mm、卫生间门 8–12mm、门扇与地面 内门5–8mm/卫生间8–12mm。

**交付**：垂直标高达标、开关灵活、密封胶顺直、玻璃 CCC 合规 → 交接。

> 工具清单：水平仪、垂直检测尺、游标卡尺、测力计、发泡胶枪、密封胶枪、橡皮锤。
