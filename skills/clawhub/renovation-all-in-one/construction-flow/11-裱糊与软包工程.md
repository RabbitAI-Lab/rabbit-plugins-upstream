# 步骤 11 · 裱糊与软包工程（壁纸 / 墙布 / 软包墙面）

> **本步定位**：墙面"饰面"的柔性方案——替代乳胶漆的另一种面层，常见于卧室背景墙、儿童房（无纺布）、客厅造型墙；软包用于床头、视听墙，吸音保暖。
> **关联**：前接抹灰/涂饰基层（六维基层完成、含水率达标），后接踢脚线/开关灯具/家具。与乳胶漆二选一，亦可分区共存。
> **规范更新**：原书引用 GB 50210—2001，现行 **GB 50210-2018**（2018-02-08 发布，2018-10-01 实施）。本章数值默认按 2018 版高级抹灰基层要求执行。

---

## 一、工艺流程

**A. 裱糊（壁纸 / 墙布）通用流程**
1. **基层交接**：混凝土/抹灰基层平整度、立面垂直度、阴阳角方正须达《GB 50210-2018》**高级抹灰**标准（表面平整 3mm、立面垂直 3mm、阴阳角方正 3mm、分格条缝直线度 3mm）。
2. **含水率红线**：混凝土或抹灰基层含水率 **≤8%**；木材基层含水率 **≤12%**（含水超标必起翘脱层）。
3. **封闭底漆 + 腻子**：满刮腻子 2–3 遍，基层坚实牢固、无粉化/起皮/空鼓/酥松/裂缝/泛碱；**腻子粘结强度 ≥0.3MPa**（GB 50210 主控）。打磨平整后涂封闭底胶（抗碱、提高粘结）。
4. **弹线分幅**：以门窗洞口/阴阳角为基准弹垂直线，保证纸幅对花、不显接缝；窄幅壁纸对花搭接、宽幅墙布对花拼接。
5. **裁纸与润纸**：长度放出 20–50mm 余量（上、下各留）；PVC 壁纸需"闷水"润胀、纯纸/无纺布按胶种决定是否润纸，避免上墙后继续膨胀起皱。
6. **裱贴（先里后外、阴角搭接、阳角包过）**：
   - **阴角**：先裱压在里面的一侧，再搭贴上面一侧，**搭接宽度控制在纸幅对花允许范围**（一般 2–3mm 对花缝，不准超宽叠糊）；阴角不准整幅纸跨两面墙（必出现空鼓褶皱）。
   - **阳角**：壁纸/墙布**包过阳角 ≥20mm**（不准在阳角处拼缝，阳角是最易磕碰处，拼缝必翘）。
   - 顺序：先上后下、先里后外；刮板赶压排气，由中向两边刮平，挤出的胶液及时擦净。
7. **收边**：上下口、开关插座处用刀割方正，压边严密。

**B. 软包（墙面/门扇）流程**
1. 墙面/门扇基层处理（同含水率要求）→ 木龙骨（白松烘干料，含水率 **≤12%**）防腐处理（涂刷防腐剂，强条：必须符合设计）。
2. 按设计分格弹线，分格宽度 **≤1000mm**；龙骨间距与分格匹配。
3. 固定内衬弹性芯材（泡沫塑料/矿棉/海绵/玻璃棉），厚度按设计（常见 **≥10mm** 单层，需增厚时叠加），满铺无褶皱。
4. 面料（人造革/织物）绷紧包覆，用粘结或暗钉固定，形状正确、厚度达标、拼花对缝；周边收口压条顺直。
5. 底层也可用其他人造板材作基面（须做防腐/防潮），再固定芯材与面料。

## 二、材料选型

| 材料 | 选型要点 | 适用 |
|---|---|---|
| 纯纸壁纸 | 环保透气、不耐擦、易泛黄 | 卧室、短期风格 |
| 无纺布壁纸 | 环保经用、透气、好施工（最常用） | 全屋通用、儿童房首选 |
| PVC 壁纸 | 最易施工、耐擦洗，但**不透气、不环保** | 公区/厨卫邻侧背景，**儿童房禁用** |
| 云母片壁纸 | 安全绝缘、光泽好 | 背景墙 |
| 植物纤维壁纸 | 最环保透气阻燃 | 高端、儿童房 |
| 软包面料 | 阻燃织物/人造革，色彩花纹按设计 | 床头、视听墙 |
| 内衬芯材 | 阻燃海绵/玻璃棉/矿棉，厚度按设计 | 吸音保温 |
| 胶黏剂 | 配套专用壁纸胶，禁 107/801 胶 | 全类 |
| 封闭底漆 | 抗碱底胶 | 基层封闭 |

**环保**：壁纸/墙布/胶黏剂/软包内衬材料的有害物质限量须有检验报告；儿童房禁用 PVC 壁纸。

---

## 三、材料验收

- **燃烧性能等级**：壁纸、墙布种类/规格/图案/颜色/**燃烧性能等级**必须符合设计要求（主控，查合格证+性能检验报告）。
- **有害物质**：封闭底漆、腻子、胶黏剂、软包内衬材料的有害物质限量检验报告（进场复验）。
- **基层封闭底漆/腻子/底胶 + 软包内衬**：纳入隐蔽工程验收（裱糊前、软包前各做一次）。
- 壁纸卷批号一致（避免色差），墙布门幅与龙骨间距匹配（卷材幅宽 > 横向龙骨间距 60mm 以上方可固定）。

---

## 四、施工质量要点

- 基层：**含水率达标（混凝土/抹灰≤8%、木材≤12%）+ 达高级抹灰平整度** + 腻子粘结强度 ≥0.3MPa，是裱糊不掉的根。
- 弹线对花：以阳角/门窗为基准，避免接缝落在显眼处。
- 裱贴：先里后外、阴角搭接、阳角包过 ≥20mm；刮板排气赶平、胶液擦净。
- 软包：木龙骨**防腐处理**（强条）、含水率 ≤12%；芯材满铺、面料绷紧无褶、拼花对缝。
- 交叉工序：裱糊/软包前完成水电开槽挂网、空调孔、开关底盒，避免事后打洞破坏面层。

## 五、施工质量通病防治

| 通病 | 原因 | 防治 |
|---|---|---|
| 空鼓 / 脱层 | 基层含水高、未涂底胶、胶量不足 | 含水≤8%/≤12%、封闭底胶、满刮胶 |
| 翘边 / 阳角开缝 | 阳角拼缝、余量不足、未包过 | 阳角包过≥20mm、上下留余量 |
| 气泡 / 褶皱 | 未赶压排气、未润纸膨胀 | 刮板由中向边赶压、PVC 闷水 |
| 搭接错缝 / 花不对 | 弹线偏、对花错位 | 垂直线基准、宽搭窄对花 |
| 泛色 / 透底 | 基层泛碱未封、壁纸太薄 | 抗碱底漆、选厚型/加衬 |
| 软包开裂 / 面料松 | 木龙骨未防腐变形、绷不紧 | 防腐+烘干料、绷紧暗钉固定 |

---

## 六、施工验收（GB 50210-2018 裱糊与软包）

**主控项**：壁纸/墙布品种、规格、图案、颜色、**燃烧性能等级**符合设计；基层处理达标；粘贴牢固，**不得有漏贴、补贴、脱层、空鼓、翘曲**；软包面料/内衬/边框材质符合设计。

**一般项目 · 裱糊允许偏差**（mm）：

| 项目 | 允许偏差 | 检验方法 |
|---|---|---|
| 立面垂直度 | 3 | 2m 垂直检测尺 |
| 表面平整度 | 2 | 2m 靠尺+塞尺 |
| 阴阳角方正 | 3 | 直角检测尺 |
| 接缝直线度 | 3 | 拉 5m 线、不足 5m 通线 |
| 接缝高低差 | 0.5 | 钢直尺+塞尺 |
| 接缝宽度 | 1 | 钢直尺 |

**一般项目 · 软包允许偏差**（mm）：

| 项目 | 允许偏差 | 检验方法 |
|---|---|---|
| 垂直度 | 3 | 2m 垂直检测尺 |
| 边框表面平整度 | 3 | 2m 靠尺+塞尺 |
| 阴阳角方正 | 3 | 直角检测尺 |
| 边框直线度 | 3 | 拉 5m 线 |
| 分格条（缝）直线度 | 6 | 拉 5m 线 |
| 对角线长度差 | 3 | 钢尺 |

**观感**：壁纸/墙布粘贴牢固、无气泡空鼓翘边皱褶斑污；拼接处花纹图案吻合、不离缝不搭接、不显拼缝；周边平直、无纸毛；软包面松紧一致、无凹凸不平。

> 工具清单：2m 靠尺、垂直检测尺、直角检测尺、塞尺、钢直尺、刮板、毛刷、弹线墨斗、含水率仪、裁纸刀。
