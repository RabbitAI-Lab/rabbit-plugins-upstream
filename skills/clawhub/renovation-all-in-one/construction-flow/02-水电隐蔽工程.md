# 步骤 2 · 水电隐蔽工程

> **本步定位**：全屋隐蔽工程的"血脉"，**封槽贴砖后无法改**，是整装里最易偷工、竣工最难返工的环节。工期约 9 天。
> **关联**：前接拆改/中央空调新风地暖定位，后接防水/贴砖。水电交底需中央空调、新风、定制家具、净水、壁挂坐便厂家到场。

---

## 一、工艺流程

**总流程**：水电定位交底 → 弹线放样 → 开槽 → 布管穿线/接管 → 固定管卡 → 打压/绝缘检测 → 验收拍照 → 封槽。

**1. 定位交底**：业主+设计师+水电工+厂家（中央空调/新风/定制家具/净水/壁挂坐便）共同确认点位（插座、给水、排水、回水、设备电源）。
**2. 放线**：地面完成线为基准；插座下沿 = 地+30cm，开关下沿 = 地+130cm，吊顶完成线统一。
**3. 开槽**：宽 = 管径+10mm，深 = 管径+15mm（或 1.5 倍）；混凝土墙横槽 ≤30cm、其他墙 ≤50cm，**不切断钢筋**；已铺地暖严禁开槽。
**4. 布管穿线**：
- 强电：16 管 ≤3 根线、20 管 ≤4 根线，同管只同回路；线管内无接头，接线在盒内。
- 弱电：强弱电不同管、间距 ≥30cm，交叉处弱电管满裹锡箔 ≥100mm；整线穿敷无中间接头。
- 水路：冷热水水平平行上热下冷、垂直左热右冷、平行间距 ≥15cm（标准 >20cm）；热熔接管同轴线不旋转、按标准加热时间。
**5. 固定**：电管卡转角 ≤15cm、直线 ≤80cm；冷水管卡 ≤60cm、热水 ≤30cm，三通转弯 15cm 内增设。
**6. 检测**：强电兆欧表绝缘、相位仪测插座；水路 **打压 0.8MPa、2h 降 ≤0.05MPa**。
**7. 验收拍照留底**，贴瓷砖标贴，封槽前完成。

## 二、材料选型

| 材料 | 选型要点 |
|---|---|
| 电线 | 阻燃 ZC-BV；照明/普通插座 **2.5mm²**，厨房/空调/卫生间/热水器 **4mm²**；冰箱独回路 |
| 线管 | PVC 红蓝分色（强电红/弱电蓝）或镀锌JDG；16/20 规格 |
| 水管 | PPR 热水管（S3.2 以上），壁厚达标；认品牌+官方质保（热熔焊接） |
| 底盒 | **86 型**（118/120 型后期换面板麻烦）；锁母固定 |
| 角阀/软连接 | 自己买：坐便单向阀、燃气热水器球阀、电热水器角阀 |
| 前置过滤器/回水 | 零冷水热水器提前设计回水水路；前置过滤器水槽下三通 |

**线径安全载流量**：2.5mm²→28A、4mm²→35A、6mm²→48A。电流(A)=功率(W)/220。

---

## 三、材料验收

- 电线：查 CCC 标志、线径实测（游标卡尺）、绝缘皮厚均匀、同回路同色一致；阻燃性能抽检。
- 水管：查出厂合格证、管系列/壁厚、无砂眼；热熔施工查焊口同轴无缩径。
- 底盒：86 型标准、无破损、敲落孔规整。
- 进场复验：电线绝缘电阻、导管壁厚；按批留样。

---

## 四、施工质量要点

- **"走顶不走地，走竖不走横"**：顶部漏水易发现不殃及楼下；墙上横槽破坏承重，应走顶后竖下到点位。
- 同管只同回路、线管内无接头；完工抽拉确认**是活线**（直线 >15m 或 >3 个直角弯设分线盒，可用插座代）。
- 强弱电禁共管共底盒；交汇弱电满裹铝箔 ≥100mm。
- 冷热水左热右冷、间距 ≥15cm；出水口台盆高 50cm、花洒高 110cm、出墙 25mm（短了装不了阀、长了盖不住装饰盖）。
- 吊顶内热水管包保温棉防冷凝；墙槽刷防水层。
- 排水：马桶坑距 **300/400mm**（不建议买两种孔距）；管路坡度 ≥1%；设存水弯防臭；检查口**千万别封死**。
- 潮湿区（卫生间/有地漏阳台）**禁止地面布电路**。
- 导线与燃气管平行 ≥300mm、交叉 ≥100mm；与热源同面 ≥500mm。

## 五、施工质量通病防治

| 通病 | 原因 | 防治 |
|---|---|---|
| 封槽后死线抽不动 | 弯头 <90°、同管超根数、横槽过长 | 活弯 >90°、管卡固定、超长设分线盒、完工抽拉验收 |
| 水压不足/焊口漏 | 热熔过熔缩径、同管主干细 | 标准加热时间、同轴线不旋转；主干粗分枝细 |
| 强弱电干扰 | 共槽/间距不足/未包铝箔 | 不同管、交叉满裹铝箔 ≥100mm、间距 ≥30cm |
| 卫生间地面触电 | 潮湿区地面布线 | 严禁；电路走顶 |
| 后期打孔打断管 | 无隐蔽图 | 水电完工拍照+贴砖标贴+交图 |

## 六、施工验收

**强电 12 点（必须达标）**：分色一致；套管埋墙根数合规；开槽深度合规不切钢筋；就近活弯可抽拉；管卡间距合规；电上水下、厨卫走顶；出墙用螺纹管/黄蜡管禁裸线；盒锁母固定、盒内留 ~10cm 线；线管内无接头；同回路线径一致；兆欧表绝缘；相位仪测插座零火地正确。

**水路**：左热右冷、间距 ≥15cm；淋浴冷热水中心 **150mm±5**；打压 **0.8MPa、2h 降 ≤0.05MPa**；排水 6 秒灌 ≥5L 通畅。

**回路设计**：总闸 + 照明/普通插座(2.5mm²) + 厨房/卫生间/空调(4mm², 漏保) + 冰箱(独立回路，长期离家不断电) + 中央空调/新风。厨房、卫生间、电热水器、空调均 4mm²。

**交付**：隐蔽工程图 + 全景照片交付业主；打压表贴现场；活线抽拉合格 → 签字进入防水。

> 工具清单：激光放线仪、开槽机、热熔机、弯管弹簧、兆欧表、相位仪、打压泵、管钳。
