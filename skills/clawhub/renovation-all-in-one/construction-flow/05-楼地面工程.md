# 步骤 5 · 楼地面工程（找平层 + 面层铺装）

> **本步定位**：全屋"地平"，影响地板/瓷砖完成面高度一致、踢脚线顺直、厨卫泛水。涵盖找平层、砖面层、石材面层、木/复合地板。
> **关联**：前接防水/水电，后接踢脚线/定制家具/门安装。地面辐射供暖在此段内或前序完成。

---

## 一、工艺流程

**A. 找平层（为贴砖/铺地板打底）**
1. 基层清理、弹 +500mm 水平线；地漏处找 0.5% 泛水。
2. 贴灰饼（50mm 见方，纵横 ≤1.5m），有坡度地面坡向地漏。
3. 铺水泥砂浆：厚度 **≥20mm**（设计无要求时）；厚度 <30mm 用砂浆、≥30mm 用细石混凝土。
4. 刮平、搓毛、养护。

**B. 砖面层（地砖）**
1. 砖浸水晾干；弹线排砖（非整砖排隐蔽处）。
2. 干硬性水泥砂浆（1:3 或 1:2.5）厚 ~10–30mm 试铺。
3. 砖背刮素水泥浆/专用粘结剂，轻击压实、随铺随检平整度。
4. 留缝 1–2mm（玻化砖/大砖用瓷砖胶+背胶，见步骤 6）；养护禁上人 ≥7 天。

**C. 木/复合地板**
1. 基层平整（3m 内误差 ≤3mm）、干燥（含水率：水泥基 ≤9%，木基层 ≤当地平衡含水率）、洁净。
2. 木龙骨（防腐处理）间距 **≤300mm**，与墙留 20mm 伸缩缝；垫层地板板缝 ≤3mm。
3. 地板铺装：相邻板接头错开 ≥200mm；四周墙留缝（面积 >30m² 或边长 >8m 留 8–12mm），备伸缩。
4. 锁扣胶接/悬浮铺装，拼三排修整后再涂胶续铺。

---

## 二、材料选型

| 面层 | 选型要点 |
|---|---|
| 地砖 | 釉面砖(墙地通用)/通体砖/抛光砖/玻化砖(地面主流)；吸水率低的瓷质更耐磨 |
| 粘结材料 | 普通砖用水泥砂浆；**玻化砖/大砖必须瓷砖胶+背胶**（淘汰水泥砂浆直贴大砖） |
| 木地板 | 实木(需龙骨)/实木复合/强化(复合)；环保认 GB/T 39600 ENF/E0 |
| 龙骨 | 落叶松/樟子松，防腐处理；截面按跨度 |
| 找平材料 | 水泥砂浆/自流平（厚度薄、平整度高） |

**避坑**：大砖（750×1500 以上）人工贵、对基层平整度要求高，买质量好的；地砖地板平铺须提前定厚度保证完成面高度一致。

---

## 三、材料验收

- 砖：查合格证、放射性（A 类可用室内）、尺寸偏差、平整度、色差；同批同色号。
- 板材：查甲醛释放量（GB/T 39600 ENF≤0.025/E0≤0.05/E1≤0.124 mg/m³）、含水率 ≤12%、无翘曲。
- 水泥：≤3 个月、安定性合格。
- 进场复验：砖吸水率/破坏强度；板材甲醛（人造板，GB 50325 复验）。

---

## 四、施工质量要点

- 找平层厚度 ≥20mm、强度达标（水泥砂浆 ≥M15）；与下一层结合牢固无空鼓。
- 地漏周边 0.5% 泛水，坡向地漏无倒坡。
- 砖铺：干硬性砂浆、砖背素浆、轻击压实；留缝 1–2mm。
- 木地板：龙骨间距 ≤300mm、防腐、留 20mm 边缝；面积 >30m² 留伸缩缝。
- 楼梯踏步：相邻踏步高差 ≤10mm、两端宽差 ≤10mm（旋转梯 ≤5mm），做防滑。

---

## 五、施工质量通病防治

| 通病 | 原因 | 防治 |
|---|---|---|
| 地砖空鼓 | 基层不净、结合层太稀、未压实 | 基层冲净晾无积水；干硬性砂浆；轻击压实；养护禁上人 |
| 地砖错台 | 未留缝、无伸缩缝 | 留缝 1–2mm；大面积设伸缩缝 |
| 木地板异响软塌 | 龙骨间距大、未固定、基层不平 | 龙骨≤300mm、紧固；3m 误差≤3mm |
| 不同材料交界面缺陷 | 未划区、边缝不直 | 成品收边条；变形系数相近材料 |
| 泛水倒坡积水 | 地漏未找坡 | 0.5% 坡向地漏、泼水试验 |

## 六、施工验收（GB 50209-2010 / GB 50210-2018）

**砖面层主控项**：砖与下一层粘结牢固；**单块边角允许局部空鼓，但每自然间空鼓砖 ≤总数 5%**（小锤轻敲）。

**允许偏差（砖面层）**：表面平整度 ≤2mm（2m 靠尺）、接缝直线度 ≤2mm、接缝高低差 ≤0.5mm、踢脚线上口平直 ≤3mm。

**木地板**：表面平整 ≤2mm、接缝平直、板间留缝均匀、行走无松动异响。

**交付**：泼水试验不积水；空鼓率 ≤5%；踢脚线出墙 8–12mm 顺直；伸缩缝留设 → 交接。

> 工具清单：水平仪、靠尺+塞尺、橡皮锤、线坠、灰饼模、地板敲击检查、含水率测试仪。
