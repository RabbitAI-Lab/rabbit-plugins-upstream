# 步骤 12 · 细部工程（橱柜 / 窗帘盒 / 窗台板 / 门窗套 / 护栏扶手 / 花饰）

> **本步定位**：装修"收口"与"功能件"——定制橱柜、护栏扶手、门窗套、窗帘盒窗台板。单件体量小，却是安全与质感的关键（护栏是强条重灾区）。
> **关联**：前接水电/墙地砖/涂饰（点位预留、基层完成），后接灯具/电器/家具进场。多数为**工厂定制+现场安装**，验收以安装为准。
> **规范更新**：原书 GB 50210—2001 → 现行 **GB 50210-2018**；护栏高度执行 **GB 50352-2019《民用建筑设计统一标准》**（临空高度<24m 为 1.05m，≥24m 为 1.10m）；栏板玻璃强条执行 GB 50210-2018 第 12.5.5 条。

---

## 一、工艺流程

**A. 橱柜（工厂定制 + 现场安装）**
1. **一次量尺**：水电改造前，按厨房格局初测，确定水电位、烟道、燃气表位置。
2. **二次复尺**：墙地砖完工后精测，下单生产（生产周期一般 15–30 天，**须排进工期**）。
3. **安装顺序**：地柜（调平、可调脚找水平）→ 台面（现场接驳、石英石拐角直角拼接、打胶）→ 吊柜（胀栓固定、水平垂直）→ 五金（铰链/拉篮/气撑）→ 台面开孔（灶孔/盆孔/拐角最易裂，需加衬）。
4. **台面接驳**：石英石不能一体圆弧造型，接驳缝打胶打磨；灶孔/盆孔四周加衬板防裂。

**B. 护栏与扶手（现场/成品）**
1. 预埋件（或后置埋件）验收：位置、数量、规格正确。
2. 放线、立杆（大立柱+扶手管壁厚 **≥1.2mm**）→ 校正垂直度 → 拉通线安装中间立柱 → 焊接/紧固其他杆件。
3. 扶手安装、弯头配件收口；栏杆间距 **≤110mm**（防儿童坠落，强条 GB 50096）。
4. **栏板玻璃**：承受水平荷载的栏板玻璃用 **≥12mm 钢化玻璃** 或 **≥16.76mm 钢化夹层玻璃**（强条）。

**C. 门窗套 / 窗帘盒 / 窗台板**
1. 检查洞口垂直度、预埋木砖/铁件齐全且间距合理。
2. 骨架（木龙骨/细木工板）：面板厚 10mm 时横撑间距 ≤400mm；面板厚 5mm 时 ≤300mm；面板与龙骨涂胶+钉固（钉长 = 面板厚 3 倍、间距 100mm）。
3. 面板安装、收口；窗台板净料厚度 **≥20mm**，窗宽 >1m 时中间加横向木条（间距 500mm 左右）防弯。

## 二、材料选型

| 部件 | 选型要点 |
|---|---|
| 橱柜柜体 | 实木颗粒板（主流）/ 实木多层（高端防潮）；认 **GB/T 39600-2021 ENF≤0.025 / E0≤0.05** 最严 |
| 门板 | 双饰面→吸塑→亚克力→包覆→烤漆→实木（由低到高）；包覆门板不开裂变形小 |
| 台面 | **人造石英石（性价比首选，硬、不能一体造型）** vs 人造石/亚克力（可圆弧一体）；认 GREENGUARD+NSF |
| 五金 | 铰链 百隆 Blum / 海蒂诗 Hettich / 国产 DTC；拉篮 凯斯宝玛/铂格/悍高；封边 ABS 最佳 |
| 护栏钢材 | 立柱/扶手管壁厚 ≥1.2mm（受力计算确定）；不锈钢/碳钢防腐 |
| 栏板玻璃 | 承受水平荷载用 ≥12mm 钢化 或 ≥16.76mm 钢化夹层（须有 CCC） |
| 门窗套板材 | 人造板游离甲醛 ≤0.12mg/m³（GB 50325 测定）；木纹美观、无脱胶空鼓；木材含水率 ≤12% |

**环保（现代化修正）**：旧"欧标E0级(mg/L)"为 GB 18580-2001 过时写法；现行 **GB/T 39600-2021** 认 ENF/E0/E1（mg/m³），合同与验收落地以国标等级+检测报告为准，不追营销话术。

---

## 三、材料验收

- 橱柜：板材合格证 + 性能检验报告 + **甲醛释放等级报告（ENF/E0/E1）**；台面 GREENGUARD/NSF（高端）；五金品牌核对。
- 护栏：钢材壁厚实测 ≥1.2mm；玻璃 **CCC 标识** + 厚度报告（≥12mm 钢化 / ≥16.76mm 夹层）。
- 门窗套/窗台板：人造板游离甲醛 ≤0.12mg/m³、含水率 ≤12%、无脱胶开裂空鼓；胶合板木纹一致无疤痕。
- 隐蔽验收：预埋件（或后置埋件）、护栏与预埋件连接节点。

---

## 四、施工质量要点

- **橱柜尺寸红线**：台面宽度 **≥500mm**；台面高度（含粘贴厚度）**宜 800mm**；**煤气灶台高度 ≤700mm**；底板距地 **≥100mm**；操作台高 ≥750mm 算合理、擀面 ≥900mm。
- **橱柜安装**：水平、垂直、柜门缝隙一致（门板缝隙 2mm 级）；台面无接缝划痕、打胶顺直；水槽/灶孔加衬防裂。
- **护栏安全强条**：高度 **1.05m（临空<24m）/ 1.10m（临空≥24m）**；栏杆间距 **≤110mm**；安装必须牢固；栏板玻璃 ≥12mm 钢化或 ≥16.76mm 夹层。
- **门窗套**：检查洞口垂直度与预埋件；面板与龙骨涂胶钉固（钉长=板厚3倍、间距100mm）；横撑间距随板厚（10mm→≤400mm / 5mm→≤300mm）。
- **窗台板**：净料厚 ≥20mm；宽 >1m 中间加横向木条（500mm 间距）防弯。

## 五、施工质量通病防治

| 通病 | 原因 | 防治 |
|---|---|---|
| 橱柜门缝不齐 / 高低差 | 地柜未调平、铰链未调 | 可调脚找平、铰链微调、缝隙一致 |
| 台面接缝/开裂 | 石英石接驳不当、灶盆孔无衬 | 接驳打胶打磨、孔周加衬板 |
| 护栏松动 / 晃动 | 预埋件缺失、焊接不实 | 预埋件验收、满焊+防腐、手扳检查 |
| 栏杆间距过大 | 按旧习惯做 >110mm | 按 ≤110mm 强条，防儿童坠落 |
| 栏板玻璃碎裂 | 用普通玻璃/厚度不足 | 强制 ≥12mm 钢化或 ≥16.76mm 夹层、CCC |
| 门窗套空鼓/开裂 | 骨架间距大、未涂胶 | 横撑间距达标、涂胶钉固、含水率≤12% |
| 窗台板弯曲 | 厚度不足、无中间支承 | 净料≥20mm、宽>1m 加横向木条 |

## 六、施工验收（GB 50210-2018 细部）

**主控项**：橱柜/护栏等材料品种、规格、数量符合；安装牢固；**护栏高度、栏杆间距、安装位置符合设计**（强条，必须）；栏板玻璃品种/层数/厚度符合（强条）。

**一般项目 · 橱柜安装允许偏差**（mm）：

| 项目 | 允许偏差 | 检验方法 |
|---|---|---|
| 外形尺寸 | 3 | 钢尺 |
| 立面垂直度 | 2 | 2m 垂直检测尺 |
| 门与框/门与门错缝 | 2 | 钢直尺 |
| 门板水平间隙 | 1.5 | 塞尺 |
| 门板上下间隙 | 2 | 塞尺 |

**一般项目 · 窗帘盒、窗台板允许偏差**（mm）：

| 项目 | 允许偏差 | 检验方法 |
|---|---|---|
| 水平度 | 2 | 1m 水平尺+塞尺 |
| 上口、下口直线度 | 3 | 拉 5m 线 |
| 两端距窗洞口长度差 | 2 | 钢尺 |
| 两端出墙厚度差 | 3 | 钢尺 |

**一般项目 · 门窗套允许偏差**（mm）：

| 项目 | 允许偏差 | 检验方法 |
|---|---|---|
| 正、侧面垂直度 | 3 | 2m 垂直检测尺 |
| 门窗套上口水平度 | 1 | 1m 水平尺+塞尺 |
| 门窗套上口直线度 | 3 | 拉 5m 线 |
| 表面平整度 | 1 | 2m 靠尺+塞尺 |

**一般项目 · 护栏和扶手允许偏差**（mm）：

| 项目 | 允许偏差 | 检验方法 |
|---|---|---|
| 护栏高度 | 3 | 钢尺 |
| 栏杆间距 | 3 | 钢尺 |
| 扶手直线度 | 4 | 拉通线+钢尺 |
| 扶手高度 | 3 | 钢尺 |

**花饰安装**：位置正确、固定牢固；表面洁净无缺损；允许偏差（独立花饰中心线 10mm、大面 5mm 级，按 2018 版表 12.8 执行）。

> 工具清单：钢尺、2m 靠尺/垂直检测尺、水平尺、塞尺、拉线、含水率仪、手扳检查（护栏牢固度）、CCC 核验。
