## 0. 作者的方法论（元原则）
- 硬装工艺 = 人的「骨骼」（不重视如骨质疏松，会致命）；尺寸预留 = 「肌肉」（不协调影响日常舒适）；风格 = 「服装」（可后期软装弥补）。
- 三者中最容易出错、最需反复确认的就是**尺寸**——它系统性强、适合提前学习，不能只看灵感图或网文。
- 书中尺寸是「底层逻辑」级的基础数据，长期不过时。

## 1. 三大类基础尺寸（一切空间尺寸的地基）
| 维度 | 紧凑 | 舒适 | 宽松/过人 | 双人并行 |
|------|------|------|-----------|----------|
| 过道宽度 | 60cm | 80cm | 100cm | 120cm |
| 餐桌到墙面/柜 | 60cm（仅落座起身） | 80cm（拉椅有空间） | 100cm（椅后可过人） | — |
| 座椅座面高 | 45cm（餐椅/办公椅/单人沙发）；换鞋凳/沙发降至35–42cm；床46–50cm |
| 餐桌/书桌高 | 70–75cm |
| 台面高（橱/岛/餐边） | 80–90cm |

> 应用：衣柜到床边最小距离、厨房过道最小宽都应做到 80cm；客厅茶几与电视柜之间过道 120cm。

## 2. 九大空间布局与关键尺寸

### 2.1 玄关
- 柜深 **35–40cm**（放得下 45 码鞋，内长≤33cm）；进深 40cm 可放鞋盒。
- 底部挑空 **20–25cm**（打扫+拖鞋，可加感应灯/插座）。
- 层板：鞋高差异大（运动鞋12–15、高跟12–14、高筒靴35–40cm）→ **用活动层板**。
- 换鞋凳高 **40–42cm**（大腿平行地面）。
- 中间开放格高 **30–40cm**；台面高≈身高×0.6（**90–105cm**）。
- 三类户型：细长形（两侧墙距<150cm 只能单侧柜；≥160cm 可双侧，门后加 5cm 门档、门离侧墙≥40cm）、开门见墙式（入户正对墙，深度≥125cm）、开放式（做隔断或小柜）。

### 2.2 客厅
- 沙发深：紧凑≈75（座高45）/ 舒适 85–100（座高40）；座面深 **48–60cm**（过深小腿无法下垂，过浅坐不住）。
- 长度：单人 80–120 / 双人 120–180 / 三人 180–250 / 四人·L 形 >250cm。
- 面宽匹配：250–300cm 放三人；400–600cm 三人+单人；>600cm 三人+2单人 或 L+单人。
- 沙发↔茶几 **40–50cm**；沙发背景墙↔电视墙 **≥250cm**；电视柜深 35–50cm。
- 电视尺寸：沙发靠背到电视 250cm→80″投影(60″电视)、350cm→100″投影(70″)、450cm→120″投影(80″)；屏幕中心高 **90–100cm**（坐姿视平线100–110，中心略低10）。
- 布局变体：传统电视中心 / 横厅（沙发后书房，过道≥100，舒适150）/ 面对面去电视化（保主通道80–100）/ 围合式（宽≥350cm）。

### 2.3 厨房（金厨银卫，尺寸最密、花费最高）
- 地柜三区：灶台 70–90cm、备菜 60–90cm（最好>90）、水槽 60–90cm（推荐大单盆）。
- 台盆：推荐**台下盆**（台上难打理、台中施工要求高）。
- 地柜深 35/55/60（操作舒适选60）；高=**身高÷2+5cm**，灶台区低 8–10cm。
- 吊柜深 30–35（与地柜差≈25，防碰头）；高 60–80；烟机处悬挂 170–180cm，无则 140–160cm。
- 高柜深 60；高 220–240cm。
- 五种布局：一字形（总宽≥135、过道≥80）/ 二字形（≥170）/ **L 形（最常用）** / U 形（短边开间≥170、长边≥240）/ 岛形（中岛深45–60，餐桌到台面≥100；半岛深35–60）。
- 收纳三原则：**就近、分类、动线**。五金：铰链带阻尼、骑马抽、下拉篮（贵）、转角小怪物。
- ⚠️ 最易被忽视的是**过道宽≥80cm**与**台面深**（35/55/60 三标准）。

### 2.4 餐厅
- 方形桌：双人 80×80 / 四人 140×80 / 六人 180×90 / 八人 220×100cm。
- 圆形桌（直径）：双人 60–80 / 四人 90–100 / 六人 110–130 / 八人 130–150cm。
- 餐桌到墙/餐边柜：紧凑60、舒适80、椅后过人 **≥100cm**。
- 餐边柜深 **40cm**（紧凑30–35，嵌电器才需60）；中间开放格高 45cm，台面 85–90cm。
- 餐桌吊灯距桌面 **70–75cm**。

### 2.5 卧室（主卧）
- 床宽：单 90–140 / 双紧凑 150 / 双宽松 180–200cm。
- 床边离墙 60–90（最小30、可靠墙）；床尾过道 80–120（最小60）；床↔衣柜 80–120。
- 衣柜深 **55–60cm**（净深≈55；<50 只能正挂；薄柜35 放鞋包配饰）。
- 收纳分区高：短衣 90–100（杆<200）/ 长衣 140–160 / 挂裤 60–80（杆<100）/ 抽屉 15–20 / 拉篮 20–30。
- 七大模块：挂衣 / 挂衣+抽屉 / 综合 / 长衣 / 杂物 / 配饰 / 鞋柜（可自由组合）。
- 衣帽间：L 形最小 345×280；U 形 380×280（一侧薄柜35–60）。

### 2.6 儿童房（次卧 8–10m²，核心是留出活动区）
- 榻榻米落地床宽 120–150cm，高 30+床垫≈45cm；上下床宽 80–120cm，**二层高 130–160cm**（距屋顶 120–140）。
- 楼梯踏步高 30cm（三级）；滑梯坡度 **≤45°**。
- 书桌高 75cm，桌下腿活动 ≥80cm。
- 布局：榻榻米 / 上床下桌 / 书桌靠窗 / 开间>进深 等，原则=省去多余过道、留足中间活动空间。

### 2.7 书房（高房价下多为「工作间」）
- 书桌深 **≥60cm**；放台式机时吊柜到桌面 **80cm**；双人台长 ≥200cm。
- 书柜深 30–35（推荐30）；层板高 30cm；单格宽 ≤60（不超100，防板材压弯）；**做到顶**。
- 布局：客卧+书房（最小 260×300）/ 储物间+书房（宽≥205）/ 客厅+书房（面宽≥450）；可用半墙隔断保私密。

### 2.8 卫生间（六大模块灵活组合）
- 洗漱：单盆宽 60–120、台盆高 80–85；冷热水高 45（间距≥10）；双盆 120–170（前方过道≥70）；区宽≥60 深≥120。
- 坐便：面宽 35–45、深 75、高 85–115；两侧 15–20；前方 ≥45；**孔距 30.5/35/40cm（不买多孔距通用）**；占用宽≥75 深≥120。
- 淋浴：最小 **80×100**、舒适 90×100；花洒高 90–100（冷热水间距15、左热右冷）；顶喷 190–200（≤230）。
- 洗衣：滚筒 60×60×85（深60–65），叠放/并排；插座高 130；前方 ≥80；占用宽≥60 深≥140。
- 浴缸：宽 70–80、长 120–180、高 60cm。
- 布局：三分离最小 235×140；紧凑两分离；酒店式 155×140；四分离 ≥5.8m²（260×225）；外置干湿 155×140。
- 洁具选购：虹吸智能坐便（**不壁挂**）、恒温花洒（注空气）、钢化玻璃淋浴门、嵌入式浴缸；地漏湿区深水封/干区重力芯。
- 五金高：毛巾杆 110–130、浴衣钩 160–180、厕纸 65–70、置物架 140–150、电热毛巾架 120–130cm。
- 浴室柜：镜柜高增到 100（深15）、平面一体台盆、抽拉龙头、不对称镜柜、抽屉地柜、实木多层板防潮、斜面隐形把手（缝≈2cm）。

### 2.9 阳台（功能型：洗衣晾晒+收纳）
- 洗衣/烘干标准 60×60×85；叠放柜宽 **70** 高 180，并排宽 **135** 高 90。
- 插座/进水留**侧面**（非机器后）：叠放插 130 高、并排 50 高；排水三通 1 个。
- 清洁柜宽 30–40（深40–60）/ 清扫工具宽 40–60（高180）/ 杂物宽 40–80（下75·中105·上60）。
- 小水槽高 75–85、宽>40；吊柜深 30–35（与洗衣柜差，防碰头）。

## 3. 电路 / 水路 / 灯光预留数据

### 3.1 电路
- 线径（铜芯）：开关·普通插座 **2.5mm²**；厨房插座·卧室空调·直热电热水器 **4mm²**。分色：零蓝、火红（或黄绿）、地黄绿双色（必接）。
- 回路**按功能**设计（非按房间）；水区（厨房/卫/阳台家务）装漏电保护；**冰箱单独回路（总闸外）**，外出可只留冰箱电。
- 各空间插座高度（cm）：
  - 玄关：双控开关130；柜中空插座130、小夜灯/烘鞋器15。
  - 客厅：主灯双控130；沙发两侧五孔30（×2）、空调16A三孔220、投影插座到顶；电视柜40、立式空调50、四孔插座（两头插头）2个。
  - 餐厅：开关130；餐边柜台面下20、冰箱50。
  - 厨房：至少10个；蒸烤180、冰箱50、小厨电带开关五孔30（3–4个）、水槽净水/小厨宝40（3个）、烟机220；中岛+4–6；烤箱/洗碗机插座留**旁侧柜内**（非机器后）。
  - 卧室：入口双控；床头70（或藏柜后）；床对面90（卷发棒等）；书桌30（×3）；空调220。
  - 卫生间：4–6个；智能马桶40、洗漱台面下30、洗衣叠放130；近水源带防溅盒；电热水器16A三孔。
  - 智能家电：预留零线+无线开关替双控；智能窗帘顶20–30、摄像头顶10、扫地/拖地30、吸尘150–160。

### 3.2 水路
- 全屋：前置过滤器（**必装**，反冲洗型，1–100μm）→ 中央净水（可选，KDF+活性炭或超滤）→ 分两路：RO 直饮（0.1–1μm）/ 软水（洗澡洗衣）。
- 进水口高度（左热右冷；冷热水间距**除电热水器为10cm外均15cm**）：
  - 台盆 45 / 坐便器 20（距排水口中心宽≈25）/ 电热水器 170（间距10）/ 花洒 110。
  - 洗衣机叠放 120 / 燃气热水器 150 / 厨房台盆 45 / 洗碗机 45（均纯冷水留侧边）。
- 零冷水燃气热水器：无回水管则在最远端装单向阀借冷水管回水。

### 3.3 灯光
- 射灯离墙：轨道 40–50cm、嵌入 20–30cm；灯间距 70–140cm；光束角 15°展示/24°局部/36°洗墙/60°基础。
- 吊灯：餐厅底距地 150–160、卧室 180–220、床头 150–160cm。
- 壁灯：走廊 200–220、床头 150–160cm。
- 色温：家居 **3000–4000K**（3000 偏黄增温、4000 近自然）；厨房中岛 4000K、餐厅 2800K 暖光。少数 5000–6000K 冷白。
- 柜内灯：柜门类靠外向内照，抽屉类靠外向外照。

## 4. 附录（流程与物料）
- **装修流程耗时**：量房设计 → 墙体拆建+水电改造（最不可改，改=重装）→ 瓦工/木工/油工（瓷砖无空鼓·木工报价全包·油工干透）→ 厨卫吊顶+地板（地板须在定制家具与室内门之前，保证收边贴合）。实际总时长一般 **≥3 个月**。
- **物料购买七步**（解决买早没地放、买晚尺寸无法预留）：
  1. 设计前：制冷（中央空调/风管机）、制热（地暖/暖气）、换气（新风）——预埋电器先定。
  2. 定制家具前：嵌入式电器定款式尺寸（否则柜门打不开/留空错/插座错）。
  3. 水电改造前：定制家具+普通电器+预装五金+灯具（决定水电布局，装修大头）。
  4. 瓦工前：瓷砖、室内窗、地板（地板有≥半月进货周期）。
  5. 油工前：漆/壁纸/背景墙位置+定制室内门（门订货≈1月）。
  6. 补漆前：五金洁具、门、防盗门、开关插座、灯具。
  7. 入住前：成品家具软装进场（先确认尺寸，勿冲动买齐）。

## 5. 跨空间通用避坑（counter-example 归纳）
- ❌ 空气开关买大安培防跳闸 → ✅ 跳闸是保护，勿乱买大号。
- ❌ 插座全用五孔 → ✅ 灵活配四孔（电视柜两头插头）、USB（人多）。
- ❌ 冰箱插座留背后 → ✅ 留侧边，插拔方便。
- ❌ 嵌入式烤箱/洗碗机插座留机器后 → ✅ 留旁侧可开门橱柜。
- ❌ 多孔距通用坐便器 → ✅ 按实际孔距（30.5/35/40）买。
- ❌ 纯白浴室柜 → ✅ 莫兰迪/原木色（白易黄）。
- ❌ 卡座替代餐椅（显储物强）→ ✅ 体验差、定制贵，不推荐。
- ❌ 异型书架/开放格滥用 → ✅ 新手选基础款，加柜门藏乱。
