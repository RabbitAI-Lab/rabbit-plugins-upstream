## 1. 材料选型速查（主材 / 辅材 / 价格区间）

来源 `[材料选择]`。价格为市场常见区间，作**比价锚点**用，非实时报价。

### 1.1 主材 vs 辅材
- **主材**（装修后可见/成型成品）：地板、瓷砖、洁具、橱柜、门、灯具、开关插座、热水器、龙头花洒、烟机灶具、壁纸、吊顶、石材、地漏、水槽、净水机、垃圾处理器、五金件。
- **辅材**（隐蔽/被覆盖）：龙骨、水泥、沙子、砖、防水材料、水暖管件、电线、腻子、胶、木器漆、乳胶漆、地漏角阀软连接、保温隔音材料。

### 1.2 板材（定制家具/木工核心）
| 类型 | 特点 | 适用 | 备注 |
|---|---|---|---|
| 实木颗粒板（刨花板） | 碎料+胶热压，隔音耐污耐老化，密度大强度低 | 柜体主流 | 国内好基材：露水河、大亚 |
| 多层实木板（胶合板） | 木片+胶，奇数层，环保性较好、最贵 | 柜体（高端）、防潮处 | 综合性能常优于颗粒板 |
| 中纤板（密度板） | 纤维+胶，易加工、不耐潮、握钉差 | 门板背板、造型 | 忌潮；作柜体背板 OK |
| 大芯板（细木工板） | 两单板夹木条，单向抗弯、便宜、甲醛偏高、怕潮 | 现场木工 | 定制少用 |
| 三聚氰胺板（免漆板/生态板） | 纸浸胶压基材，耐磨耐腐经济 | 柜体 | 封边易崩边 |
| 实木板 | 天然纹路、贵、施工要求高 | 高档 | 少用 |
- **门板饰面层级**（由低到高）：双饰面板 → 防火板 → 吸塑(PVC) → 亚克力 → 包覆膜 → 烤漆 → 实木。包覆门板（五合一/六面包覆）不开裂、变形小。
- **环保现代化**（见第 6.5 节）：认 **GB/T 39600-2021** 的 **ENF(≤0.025) / E0(≤0.05) / E1(≤0.124) mg/m³**，不认模糊的"欧标E0级"。

### 1.3 瓷砖 / 填缝
- 瓷砖类型：釉面砖（家装最常见，陶制吸水高/瓷制吸水低）、通体砖（耐磨简洁）、抛光砖（光滑易脏）、玻化砖（石英抛光，常用地面）。
- 填缝演进（**水泥砂浆直接勾缝已淘汰**）：白水泥(不防水) → 勾缝剂(不防水) → **美缝剂**(树脂，防水耐污，可能收缩) → **瓷缝剂**(高档美缝，最优)。大砖/厨卫建议美缝或瓷缝。

### 1.4 门窗 / 地漏 / 吊顶
- 门窗：木(温馨但易变形) / 铝合金(广用价廉不耐隔热) / 塑钢(保温好久晒掉色) / **断桥铝(铝合金升级，隔音隔热密封最好，推荐)**。
- 地漏：水封式(防臭最稳) / 翻板 / 弹簧 / 硅胶芯。**防臭优先水封式**；回型地漏工艺常见。
- 吊顶：石膏板(客餐厅造型) / PVC(廉价) / **铝扣板(厨卫标配，可拆卸检修)** / 桑拿板(阳台)。层高一般 2.8m，吊顶下吊 15–20cm。

### 1.5 涂料 / 墙材
- 腻子(找平)、底漆(提高附着力)、乳胶漆(面漆)。乳胶漆价格区间大（30–250 元/L 级），全屋标配≤3色（含白）。
- 墙纸：纯纸(环保透气不耐擦) / 无纺布(环保经用) / PVC(最易施工但不透气、不环保、**儿童房禁用**) / 云母片(安全绝缘) / 植物纤维(最环保透气阻燃)。
- 硅藻泥：防火防潮"最环保"说法存争议，**市场混乱**，作备选不盲信。

### 1.6 台面 / 橱柜计价
- 台面：天然石(纹理好但脆、多孔、或有放射性) / 不锈钢(易刮氧化) / 人造石(亚克力，可一体造型但硬度低) / **人造石英石(性价比最高，国内热门首选)**。
- 橱柜计价：①**延米法**（含底柜+吊柜，局部只要底柜按 2/8 或 4/6 折算）；②**柜体法**（底柜+吊柜分别计价）。例：3 米延米×2000 元=6000 元；或 3 组底柜(1200/组)+2 组吊柜(800/组)=5200 元。

## 2. 开工准备与收房验房

来源 `[装修前准备]` `[精装房验房]` `[二手房收房]`。

### 2.1 收房流程
双方互验材料 → 验房 → 检查面积 → 领钥匙 → 签物业协议缴物业费 → 办产权证 → 签入住交接单。
- 业主带：购房合同、贷款合同、还款单据、身份证、照片、收楼通知书。
- 开发商须给：**"三书一证一表"**——建设工程质量认定证书、住宅使用说明书、住宅质量保证书、房地产开发建设项目竣工综合验收合格证、竣工验收备案表。
- 面积误差：合同有约定按合同；无约定且误差 **>3%**，购房者有权退房并获全额房款+利息；不退房则开发商承担超 3% 部分差价。

### 2.2 验房要点（毛坯）
1. 墙面平整、防水；2. **标识承重墙，严禁拆改**；3. 检查水电位置防错挖；4. 面积/层高复核。
- 关键术语：开间(东西宽)/进深(南北长)；层高(楼板到楼板)/净高(净剩值)；套内建筑面积 vs 公摊面积；家居动线(室内移动路径)。

### 2.3 精装房验收速查（逐工种 checklist，来源 `[精装房验房]`）
- **入户门**：表面平整无划痕、门锁牢固开关正常、门吸牢固、猫眼已装。
- **配电箱**：横平竖直、回路标示对应正确；**相位仪测插座：左零右相、接地在上**；短路保护测试。
- **等电位**：数量/安装/防护到位（卫生间必查）。
- **弱电**：箱内分线清晰、无裸露强电；**查"活线"——抽动露出线路应灵活**；弱电与强电间距合规。
- **门窗**：铝合金/塑钢表面无划伤、启闭顺畅、外泄水孔无堵、密封胶顺直；**7层及以上外开窗/面积>1.5㎡/玻璃底边离地<500mm 的落地窗须有"CCC"标识**。
- **墙地面**：瓷砖空鼓/水平度/平整度/色差/砖缝饱满；木地板无异响软塌；踢脚线平直打胶。
- **厨卫**：墙地砖空鼓、泛水坡度(不积水)、渗漏；橱柜水平垂直、柜门灵活缝隙一致；台面无接缝划痕；地漏排水正常；坐便冲水通畅、与墙垂直；淋浴房玻璃有 CCC、打胶严密。
- **中央空调/新风**：漏电/漏水/漏氟(肥皂水检漏)/噪音检查；新风风量逐口测、主机远离起居室、软连接避震。
- **净高/实测**：四纵四横，客厅主卧地面到顶棚误差≤10mm、开间进深误差≤10mm。
- **环保**：室内甲醛/苯/TVOC 等符合 GB/T 18883；噪音白天≤50dB。

## 3. 预算 / 合同 / 增项避坑

来源 `[装修前准备]` `[隐性增项]`（前 v3.0 已有框架，此处补**具体增项清单**）。

### 3.1 预算组成与方式
预算 = 设计费 + 人工费 + 材料费(主材+辅材) + 家具软饰 + 家电设备 + 备用金。
- 做法建议**"减法"**：先定高价家具家电，再倒推装修预算。
- 包工方式价（参考）：半包 200–300 元/㎡；全包 700–800 元/㎡；1500 元/㎡≈快捷酒店档，2000≈三星，4000≈五星。
- 半包(公司出设计+辅材+施工，主材自购) / 全包(全包) / 清包(只施工)。

### 3.2 隐性增项清单（整装报价单必核，来源 `[隐性增项]`）
**基础施工里"标配不含、大概率加钱"的项：**
- 乳胶漆：找平、PVC阳角条修直、深色漆调漆、墙面满挂纤维网 —— 均加钱；全屋标配≤3色。
- 瓷砖：通铺/大砖(750×1500、800×800)人工加钱；400×800 以上墙砖需背胶辅料钱；美缝剂加钱；过门石建议取消做通铺。
- 防水：保护层、过门石防水坝加钱；无地漏区不做防水。
- 吊顶：双眼皮吊顶、平面天花吊顶(轻钢龙骨+石膏板)加钱。
- 水电：超出点位数量加钱；花灯、卫浴挂件安装加钱；第二个卫生间整项加钱。
- 老房：非承重墙拆除、拆除后修复、窗帘盒、配电箱移位、成品保护、材料上楼费、垃圾搬运/外运费、综合管理费 —— 均加钱。

**签约红线（与 v3.0 一致）：** 闭口合同是底线；增项≤5% 须书面签字；尾款≥10% 作质保金；质保 防水水电≥5年、其他≥2年；合同附图样+报价单；变更须书面同意再动工。

## 4. 水电工程深化（来源 `[水电攻略]` + 施工手册水电章）

### 4.1 基本
- 水电改造=水路+电路拆改优化；隐蔽工程，**最易偷工、竣工难改**；工期约 **9 天**；水电工报价常最高。
- 主流程：水电定位 → 开槽 → 水管电线安装(布线) → 水电验收。

### 4.2 走线与开槽
- **"走顶不走地，走竖不走横"**：顶部漏水易发现不殃及楼下；墙上横向开槽破坏承重，**应走顶后再竖下到点位**。地面开槽切 3cm 深，不可见楼板钢筋；已装地暖不可开槽。
- 冷热水管间距 **>20cm**（标准）；主干粗、分枝细（长距拉管末端水压弱）。

### 4.3 回路与线径（关键数值）
- 线径安全载流量：2.5mm²→28A，4mm²→35A，6mm²→48A，10mm²→65A。
- **照明/普通插座 2.5mm²；厨房插座、空调插座 4mm²**；同回路火零接地线径一致。
- 大功率电器**单独回路**：空调、冰箱、烤箱、洗衣机、热水器、浴霸；冰箱独回路（外出可只留冰箱）。
- 电流(A)=功率(W)/220V；例 2匹空调≈1471W≈7A，10A 插座仅容 1 台、16A 容 2 台（空调通常独插）。
- 潮湿区域（卫生间/阳台有地漏）**禁止地面布电路**。

### 4.4 水电质检标准（验收必查）
- 强弱电**禁止共管、共底盒**；交汇处弱电线管满裹铝箔延伸≥100mm。
- 导线分色识别（火/零/地）；线头绝缘包裹。
- 底盒：入室开关下沿离地 **1400mm±100**；并排底盒高低误差≤5mm；管卡直向 600–800mm/档、转角 150–200mm/档。
- 导线与热源同面≥500mm；与燃气管平行≥300mm、交叉≥100mm。
- **给水**：左热右冷、平行间距≥100mm；淋浴冷热水中心 **150mm±5**；淋浴出水口 900–1100mm、洗手盆 450–600mm、浴缸 650–750mm。
- 顶部同铺：电管在上、水管在下，留间隙；出水口下方不得设插座；水龙头与插座空间允许时≥500mm 且插座高于错位。
- **打压试验：0.6–0.8MPa（约 6–8kg/cm²），静压 30 分钟回落≤0.05MPa 为合格**（与施工手册 0.8MPa 一致）。
- 排水：马桶坑距 **300/400mm**；管路坡度≥1%；设存水弯防臭；管口临时封口防堵。

## 5. 质量通病与避坑（来源 `[八局质量通病]`，筛选家装相关项）

> 原手册含吊顶/墙柱面/楼地面/室外/栏杆等，以下只保留**家庭装修高频项**，并附"管控措施"作避坑依据。纯工装项（石材干挂泛碱、环氧自流平、耐磨地面分格缝、金属栏杆焊接）已摈弃。

### 5.1 吊顶
- **石膏板吊顶开裂**：伸缩缝处石膏板未断开/腻子填实断开位 → 伸缩缝宽 15–20mm、背面放背条、单独石膏线条成品放置。
- **检修口开裂/周边开裂**：四周未加固无吊杆 → 深化时综合空调消防检修需求定位；四周加固轻钢/型钢龙骨+四角加丝杆；副龙下装 0.5mm 厚≥300mm 宽"回"字白铁皮。
- **转角龙骨未固定**：转角开裂 → 副龙完成后转角裁"L"型 0.5mm 镀锌铁皮加固；转角上口加 50 付龙骨斜撑；封板前应力释放；隐蔽工程封板前完成。
- **主龙骨大吊/挂钩**：必须**正反扣安装**，穿心螺丝拧紧、卡件卡紧。
- **面层平整度**：放线误差、螺丝未紧固、龙骨扭曲、石膏板受潮 → 紧固所有螺丝卡件、调直吊杆、更换变形龙骨、按规存放石膏板。
- **石膏线接缝开裂**：拼缝未留"V"口、背面无加固 → 拼板前刨"V"口；转角错开 30mm 用"L"字切割成一整块；接缝设加强板。**（注：原书"顶面转角"表述，家装有吊顶角部同理）**

### 5.2 墙柱面
- **涂料墙面泛碱**：基层含水率大、温湿度未控、完工未封闭门窗 → 基层平整洁净；**涂刷前基层含水率≤10%**；施工温度≥10℃；完工及时封闭门窗。
- **电管线槽部位乳胶漆裂缝**：预埋深度不够、槽内未清理、未分层粉刷 → **预埋管线外表面距原粉刷面≥15mm**且管卡牢固；槽内清垃圾、浇水润、冲洗；水泥砂浆分层粉刷，界面剂贴网格布+纸胶带批腻子；抹灰 24h 后湿润养护≥3天。
- **墙面裂纹/空鼓/脱落**：基层处理差、少工缺序、随意加大配比、不挂网 → 基层干净；受力集中处挂铁丝网；控制水灰比；吸水率高的基体浇水润；分层抹灰；养护。
- **玻化砖上墙空鼓脱落**（**淘汰"水泥砂浆直接上大砖"老法**）：基层未处理、砖背污迹、铺贴过密 → 检查粉刷层、浇水润；砖背开浅横槽、冲洗净；**用玻化砖/重砖粘结剂+界面处理剂，锯齿镘刀批刮 5–7mm**；砖缝≈1mm 避免密拼；建议挂贴法。
- **墙砖拼缝不齐**：材质平整度差、水平线失控 → 来料检验；上下砖交界留 1mm 缝；严格控制水平线、每两排调一次。

### 5.3 楼地面
- **地砖空鼓**：基层不净、结合层太稀、未压实、养护期上人 → 基层冲净晾至无积水；**干硬性砂浆**拌匀；结合层拍实揉平；板块浸水晾干浇素水泥浆轻击压实；养护期禁上人。
- **地砖错台**：同理 + 未留缝、无伸缩缝 → 铺前扫浆即铺结合层；干硬性砂浆；砖背钢丝刷去晶粉浸水晾干；**留缝 1–2mm**；养护洒水≥7天禁上人；大面积设伸缩缝（楼面结构伸缩缝位）。
- **不同材料地面交界面缺陷**（地砖/木地板/石材拼接）：前期策划未划区、边缝不直、变形系数不同 → 合理划分；**用成品收边条**；选变形系数相近材料。

## 6. 定制家具深化（来源 `[橱柜]`，橱衣柜同源）

### 6.1 五大组成
柜体 + 门板 + 五金 + 台面 + 电器。衡量标准：操作流畅性 + 存放合理性。

### 6.2 结构
地柜 / 吊柜 / 高柜 / 半高柜 / 岛台 / 吧台；特殊柜：碗碟吊柜、斜角围栏柜、红酒杯架。

### 6.3 板材（与第 1.2 节一致，补充）
- 基材三件套：实木颗粒(碎料+胶)、中纤板(纤维丝+胶，可加工性好)、实木多层(木片+胶，环保较好最贵)。
- 饰面决定用途：双饰面板(柜体主流)、吸塑、亚克力、包覆、烤漆、实木(门板)。
- 品牌参考（选购时比对，非强制）：基材 露水河/大亚/艾格；饰面纸 夏特/IP/苏德克；封边 ABS 最好(瑞好/都肯)；胶 德国胶王/汉高/赫米特。

### 6.4 台面 / 五金 / 电器
- 台面：**石英石(硬、不能一体造型、拐角直角拼接)** vs 人造石/亚克力(温润、可圆弧一体造型)；顶尖认证 GREENGUARD(室内空气)、NSF(可接触食物)。常见台面问题：灶孔/盆孔/拐角/接驳缝/前裙。
- 结构五金：铰链(海蒂诗 Hettich=发明者、百隆 Blum、国产 DTC)、偏心件、吊码(明/隐藏)、层板托、气撑、可调脚、地脚板。
- 功能五金：调味拉篮、碗碟拉篮、锅篮、转角拉篮(小怪物/大怪物/飞碟/转筒)、吊柜拉篮；品牌 凯斯宝玛 Kesseboehmer、铂格 Peka、悍高。
- 电器：烟机(侧吸/塔式/中式/直吸)、灶(集成灶 美大/火星人)、水槽(单/双/集成)、净水器、垃圾处理器、洗碗机(嵌入式/台式/水槽式/台面嵌入)、蒸烤。

### 6.5 环保标准现代化（修正橱柜资料过时说法）
- 橱柜资料写"欧标E级 E2(≤5.0)/E1(≤1.5)/E0(≤0.5) mg/L，定制行业不存在欧标E0级" —— 这是 **GB 18580-2001 旧国标**写法，已过时。
- **现行国标 GB/T 39600-2021**：ENF(≤0.025) / E0(≤0.05) / E1(≤0.124) mg/m³。**家庭装修认 ENF 最严、E0 次之**，不追模糊的"欧标E0级"。"欧标E0"在家装行业是营销话术，落地以国标等级+检测报告为准。
- 日本 F★★★★(≤0.3mg/L) 可作高端参照，但国内合同/验收认国标。

### 6.6 厨房布局与尺寸
- 样式：一字型 / L型 / 川字型 / **U型(较理想)** / 中西厨。
- 操作台高 **≥750mm** 算合理；擀面需 **≥900mm**。洗切炒动线优先；水槽双槽分工明确；碗碟篮≈700mm(有洗碗机/消毒柜时)；米面放水槽两侧柜；调味拉篮放操作台附近。

## 7. 竣工验收与环保入住（来源 `[竣工攻略]`）

### 7.1 竣工验收标准（逐类）
- 地面：地砖平整无漏贴错贴、周边顺直、无裂纹掉角；勾缝饱满不泛黄。
- 墙顶涂料：无色差/返碱/返色/刷纹；乳胶漆均匀无刷痕流坠起皮裂纹透底；分色清晰无相互污染。
- 开关面板：同房间高度一致、操作灵活；插座**左零右火上接地**，潮湿位加防水罩；紧贴墙面无缝隙。
- 灯具：端正、灯珠齐全。
- 洁具：**陶瓷类不得用水泥砂浆固定**；端正牢固下水无渗漏；与台面墙地接触处打密封胶；出水左热右冷、装角阀。

### 7.2 竣工提醒
- 办售后维保、清算增减项；**交接水电隐蔽工程图纸资料**（后期打孔挂件避让用）。
- 家具进场不拖地避免划伤；墙面打孔**避开水电管**；勤通风散味（注意通风方式）。
- 装修垃圾：装企清运≈200元/车，或物业代清 5–10元/㎡；建材（开关/龙头/瓷砖）可回收。
- 开荒保洁顺序：粗扫→吸尘(吊顶灯带/橱柜内/窗槽)→擦橱柜台面窗框→擦玻璃→地面二次清理。

### 7.3 环保与健康（与 v3.0 环保一致，补来源）
- 污染物：甲醛(板材/家具/漆/胶)、氡(土壤石材，红色花岗岩如印度红不宜家装)、TDI(聚氨酯泡沫/漆)。
- 防治根本：**买正品 + 开窗通风**；白色墙面发黄多因 TDI，木漆与墙漆工序错开≥1周。
- 入住：GB/T 18883 密闭 12h 甲醛≤0.08mg/m³ 为参考；通风晾放通常 3–6 个月；有孕妇幼儿从严。
- 绿植辅助：绿萝/虎尾兰/芦荟净化空气（辅助非主力）。
