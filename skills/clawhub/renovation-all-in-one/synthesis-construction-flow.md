# 装修施工流程 · 六维深度手册（总览索引）

> **用途**：从零装修一套房子的"师傅带徒弟"级施工图。小白照此执行，可在无监管情况下把控每道工序的工艺、材料、验收。
> **结构**：12 个施工步骤，每步拆成 **6 个维度**（工艺流程 / 材料选型 / 材料验收 / 施工质量要点 / 施工质量通病防治 / 施工验收）。
> **配套**：本文为索引与门禁；每步细则有独立文件 `construction-flow/NN-*.md`，点击对应文件名查阅。
> **适用**：现代家庭装修（毛坯/老房重装）。纯工装、建筑主体、已淘汰工艺（幕墙、工业地坪、现场熬沥青、107/801 胶、玻化砖水泥砂浆直贴等）已剔除。
> **版权**：来源为用户正版/自有资料（personal_local），仅本地要点合成，未整段照搬原文。

## 〇、六维方法说明（每步都按这 6 问做）

| 维度 | 回答的问题 | 落点 |
|---|---|---|
| 1. 工艺流程 | 先做什么后做什么，怎么做 | 顺序 + 关键动作 |
| 2. 材料选型 | 买什么、怎么挑 | 选型表 + 避坑 |
| 3. 材料验收 | 进场怎么验、查什么证 | 合格证/检测报告/复验 |
| 4. 施工质量要点 | 现场盯什么才不出错 | 主控动作清单 |
| 5. 施工质量通病防治 | 常见翻车怎么防 | 通病→原因→防治表 |
| 6. 施工验收 | 完工怎么判合格 | 主控/一般项 + 允许偏差表（带规范号）|

**规范基线（已做过期纠正）**：GB 50210-2018（装饰验收，原 2001 作废）、GB 50325-2020（污染物，原 2010 作废）、GB 50352-2019（护栏高度）、GB 18580-2017 / GB/T 39600-2021（板材甲醛 ENF≤0.025/E0≤0.05/E1≤0.124 mg/m³）、GB/T 18883（入住甲醛≤0.08mg/m³ 密闭12h）、GB 50209-2010（楼地面）、GB/T 23445（聚合物水泥防水）、GB/T 25181（瓷砖胶）、JGJ 113-2015（安全玻璃底边 500mm）、GB 50096（住宅栏杆间距≤110mm）、GB 50016（防火）。

## 一、施工主线（12 步顺序）

```
拆改与新建墙体 → 水电隐蔽工程 → 防水工程 → 抹灰工程 → 楼地面工程
→ 饰面砖粘贴 → 吊顶工程 → 轻质隔墙 → 门窗工程 → 涂饰工程
→ 裱糊与软包 → 细部工程（橱柜/护栏/门窗套）
```

> 注意：实际穿插——水电在水电步一次性布完；吊顶/隔墙/门窗/涂饰/细部可在多阶段并行；但**隐蔽（水电、防水、抹灰内挂网）必须先于面层封闭**。

## 三、里程碑验收门禁（不过不许进下一道）

每道门禁是"上一道工序没过，绝不允许覆盖/封闭"，否则后续无法整改。

| 门禁 | 位置 | 必过项 | 不合格后果 |
|---|---|---|---|
| **G1 拆改结构安全** | 01 后 | 三类承重墙/梁/柱未动；新砌墙植筋+地梁+挂网合格 | 结构隐患，无法补救 |
| **G2 水电隐蔽** | 02 后、封槽前 | 打压 0.8MPa/2h 降≤0.05MPa；绝缘电阻合格；**活线**（抽动自如）；强弱电交叉铝箔≥100mm；相地序对 | 封槽后漏水/短路只能砸墙 |
| **G3 防水闭水** | 03 后、贴砖前 | 厨卫/阳台闭水 **48h**，楼下与相邻墙无渗；门槛石返上+门口外伸 | 贴砖后渗水殃及楼下，全砸 |
| **G4 抹灰基层** | 04 后 | 总厚/加强层合规；平整度达高级抹灰；线槽挂网 | 面层开裂、瓷砖空鼓 |
| **G5 楼地面/饰面砖** | 05–06 后 | 空鼓：砖面层 **≤5%**、单砖边角空；泛水不积水；留缝一致 | 空鼓脱落、积水 |
| **G6 吊顶承重** | 07 后 | 重型设备(>3kg 灯具/风管)独立吊承重(强条 7.1.15)；吊杆端头≤300mm | 吊顶坠落伤人 |
| **G7 门窗安全玻璃** | 09 后 | 7 层及以上外开/面积>1.5㎡/底边离地<500mm 落地窗有 CCC；壁厚达标 | 玻璃碎裂伤人 |
| **G8 护栏强条** | 12 后 | 高度 1.05/1.10m；栏杆间距 ≤110mm；栏板玻璃 ≥12mm 钢化(CCC) | 坠落事故，验收一票否决 |
| **G9 环保入住** | 全部完 | GB/T 18883 密闭 12h 甲醛 ≤0.08mg/m³（参考）；通风 3–6 月 | 健康风险，从严孕妇幼儿 |

## 四、通用工具清单（贯穿全程）

- **测量**：2m 靠尺、垂直检测尺、水平尺、直角检测尺、钢直尺、卷尺、激光投线仪、拉线。
- **检测**：塞尺、含水率仪、压力表（打压 0–1.0MPa）、绝缘电阻摇表、空鼓锤、相位检测仪。
- **工艺**：刮板、打磨机/砂纸、滚刷/羊毛刷、美纹纸、弹线墨斗、电锤/电钻、批刀。
- **核验**：CCC 标识核验、材料合格证/检测报告/复验报告归档。

## 五、给小白的执行纪律（照做不出大事）

1. **隐蔽优先**：水电、防水、抹灰内挂网、吊顶承重——这些被盖住的，必须在盖前验收。
2. **每步留证**：材料合格证+检测报告+闭水/打压照片+隐蔽验收记录，归档备查（也是维权凭据）。
3. **强条不碰**：护栏高度/间距、栏板玻璃、门窗壁厚、吊顶>3kg 吊承重、安全玻璃 CCC——这些是强条，错了验收不过且危险。
4. **偏差带尺**：本文每步第六维都给了允许偏差（mm）和检验方法，拿尺去量，不靠眼。
5. **环保认国标**：板材甲醛认 GB/T 39600（ENF/E0/E1），不认"欧标E0"营销话术；入住前检测 GB/T 18883。
6. **闭口合同**：增项≤5% 书面签字、尾款≥10% 质保金、防水水电质保≥5 年其他≥2 年（见 `synthesis-budget-contract-eco.md`）。
