Pay-per-call market intelligence for AI agents via **x402**.
Dual rail: **Base USDC (live)** and **Solana /sol/v1/**\* (**402 accepts live**; SVM client for paid settle).

**Publisher:** [korra.finance](https://korra.finance)

**Disclaimer:** Descriptive research only. **Not financial advice.** Vedetta
does not give buy/sell instructions; do not present stance/confidence fields
as trading recommendations. **Descriptive market analysis only — not financial advice.**

Upstream product: https://vedetta.dethboy.com  
Official live skill: https://vedetta.dethboy.com/SKILL.md  
Version in this package: **2.12.0-v8**

## Package layout

```
vedetta/
  SKILL.md           # Hermes / agent skill (required)
  LICENSE
  README.md
  PUBLISH.md
  scripts/
    pay.mjs          # x402 payer client (Base EVM)
    pay-sol.mjs      # x402 payer client (Solana SVM)
    setup.sh         # one-time Node client install
```

Note: do **not** ship a `skill-card.md` — ClawHub generates the listing card itself.

## Local install (Hermes)

```bash
hermes skills install /path/to/vedetta --name vedetta
# or from URL
hermes skills install https://vedetta.dethboy.com/SKILL.md --name vedetta
```

## One-time payment client

```bash
bash scripts/setup.sh
export VEDETTA_X402_PRIVATE_KEY='0x...'   # dedicated low-balance Base USDC wallet
cd ~/.vedetta-client && node pay.mjs '/v1/feed?limit=1'
# Sol (after dedicated SVM lab key + green light):
# export VEDETTA_X402_SOLANA_PRIVATE_KEY='...'
# node pay-sol.mjs '/sol/v1/feed?limit=1'
```

## Publish to Skill Hub / ClawHub

### Option A — ClawHub web submit
1. Zip this folder (or use the prebuilt `vedetta-skill.zip`).
2. Open https://clawhub.ai/submit
3. Upload the zip / point at the skill directory containing `SKILL.md`.
4. Fill publisher as **korra.finance** and the disclaimer in the ClawHub form
   (listing card is generated by ClawHub — do not upload a skill-card.md).
   Suggested disclaimer paste:
   > Descriptive research only. Not financial advice, investment recommendations, or buy/sell instructions.

### Option B — clawhub CLI (if installed)
```bash
npx clawhub login
npx clawhub publish ./vedetta-skill \
  --slug vedetta \
  --name "Vedetta — x402 Market Intelligence" \
  --version 2.12.0-v8
```

### Option C — Hermes helper
```bash
hermes skills publish ./vedetta-skill --to clawhub
# Note: Hermes currently prints the manual submit URL for ClawHub.
```

### Option D — Hosted install URL (already works)
```bash
hermes skills install https://vedetta.dethboy.com/SKILL.md --name vedetta
```
