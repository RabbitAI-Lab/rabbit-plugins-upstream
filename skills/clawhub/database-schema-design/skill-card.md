## Description: <br>
Document or design a database schema with entity relationships, table definitions, constraints, indexes, access patterns, normalization decisions, and migration notes. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineers use this skill to create or review database schema design documents for relational systems, including ER diagrams, DDL, indexes, access patterns, normalization trade-offs, and migration notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated SQL, index choices, or migration notes may be incorrect for a specific database engine, version, workload, or production environment. <br>
Mitigation: Review generated DDL and migration guidance with a database engineer, test changes in staging, and validate them against real access patterns before applying them to a live database. <br>
