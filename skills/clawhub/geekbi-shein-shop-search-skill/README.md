# 极鲸云 SHEIN 店铺搜索 Skill

通过极鲸云提供的真实 SHEIN 店铺数据，帮助国内跨境卖家搜索目标店铺、筛选竞品店铺，并分析经营规模、近期增长、商品结构、粉丝变化、口碑和托管模式，为竞店调研、经营对标和市场竞争判断提供依据。本 Skill 专注店铺层级，不提供店内单品明细。

## 主要能力

| 能力 | 可以解决的问题 |
| --- | --- |
| SHEIN 店铺搜索 | 按店铺名称或 ID、站点和可信类目 ID 定位目标店铺，获取可直接访问的店铺详情链接 |
| 竞品店铺筛选 | 按全托管或半托管、开店时间、销量、销售额、评分、评论数、商品数、粉丝数和平均价格筛选可比店铺 |
| 店铺榜单研究 | 查找热销店铺、高评论店铺、热销新店和最近开店的店铺，快速建立竞店候选清单 |
| 经营表现分析 | 结合近 3 个月、累计及日周月销量与销售额，判断店铺规模、近期增长和回落风险 |
| 商品与粉丝变化 | 结合商品总数、周期商品数、粉丝总数及变化率，判断经营扩张速度和用户资产变化 |

## 适用场景

本项目适合以下任务：

- 搜索指定 SHEIN 店铺并获取可信店铺链接。
- 查找头部店铺、热销店铺和直接竞争店铺。
- 筛选最近开店、近期增长较快或具有潜力的新店。
- 对比全托管与半托管店铺的经营规模和表现。
- 分析店铺销量、销售额、商品规模、粉丝和口碑。
- 评估店铺近期增长、商品供给变化和经营风险。
- 建立竞品店铺清单并完成经营对标。
