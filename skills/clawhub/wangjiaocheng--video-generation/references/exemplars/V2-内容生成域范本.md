## V2-内容生成域范本

### V2-01 宣传片生成范本

**任务目标**：生成品牌宣传片、产品宣传片、企业宣传片

**执行步骤**：

1. **确定宣传主题**
   - 品牌宣传：传达品牌理念
   - 产品宣传：展示产品特点
   - 企业宣传：展示企业实力

2. **编写宣传脚本**
   - 开头：吸引注意力
   - 中间：展示内容
   - 结尾：总结升华

3. **设计宣传画面**
   - 画面风格：与品牌一致
   - 画面节奏：有张有弛
   - 画面效果：有视觉冲击力

4. **选择宣传音效**
   - 背景音乐：与品牌调性一致
   - 音效：增强画面效果
   - 旁白：专业、有感染力

**输出示例**：

```markdown
## 宣传片设计方案

### 宣传主题
- 主题：品牌宣传片
- 目标：提升品牌形象

### 宣传脚本
- 开头：品牌logo+品牌口号
- 中间：品牌故事+产品展示+用户评价
- 结尾：品牌愿景+联系方式

### 宣传画面
- 画面风格：现代、科技感
- 画面节奏：快慢结合
- 画面效果：流畅、有视觉冲击力

### 宣传音效
- 背景音乐：现代、有节奏感
- 音效：转场音效、强调音效
- 旁白：专业、有感染力
```

### V2-02 短视频生成范本

**任务目标**：生成抖音、快手、小红书短视频

**执行步骤**：

1. **确定视频主题**
   - 热门话题：蹭热点
   - 产品展示：突出产品特点
   - 生活分享：有趣、有共鸣

2. **编写视频脚本**
   - 开头：3秒内吸引注意力
   - 中间：展示内容、有节奏
   - 结尾：有互动、有引导

3. **设计视频画面**
   - 竖屏：9:16比例
   - 画面清晰：1080p
   - 节奏快：符合短视频特点

4. **添加视频效果**
   - 字幕：清晰、易读
   - 音效：增强效果
   - 特效：有创意

**输出示例**：

```markdown
## 短视频设计方案

### 视频主题
- 主题：产品使用技巧
- 目标：展示产品功能

### 视频脚本
- 开头：你知道这个产品还有这个功能吗？
- 中间：演示产品功能+使用技巧
- 结尾：你还知道哪些使用技巧？评论区告诉我

### 视频画面
- 画面比例：9:16竖屏
- 画面清晰：1080p
- 节奏快：每个镜头2-3秒

### 视频效果
- 字幕：白色字幕+黑色描边
- 音效：转场音效、强调音效
- 特效：文字特效、画面特效
```

### V2-03 教学视频生成范本

**任务目标**：生成教学视频、培训视频、教程视频

**执行步骤**：

1. **确定教学目标**
   - 知识目标：掌握某个知识点
   - 技能目标：学会某个技能
   - 态度目标：培养某种态度

2. **编写教学脚本**
   - 导入：引起兴趣
   - 讲解：系统讲解
   - 练习：巩固知识
   - 总结：回顾重点

3. **设计教学画面**
   - 画面清晰：易于理解
   - 字幕清楚：辅助理解
   - 节奏适中：便于学习

4. **录制教学讲解**
   - 语音清晰：易于听懂
   - 语速适中：便于理解
   - 重点突出：强调关键点

**输出示例**：

```markdown
## 教学视频设计方案

### 教学目标
- 知识目标：掌握Python基础语法
- 技能目标：学会编写简单程序
- 态度目标：培养编程兴趣

### 教学脚本
- 导入：展示Python能做什么
- 讲解：变量、数据类型、运算符
- 练习：编写简单程序
- 总结：回顾重点知识

### 教学画面
- 画面清晰：代码演示+操作演示
- 字幕清楚：关键代码+解释说明
- 节奏适中：每个知识点3-5分钟

### 教学讲解
- 语音清晰：标准普通话
- 语速适中：每分钟150字
- 重点突出：强调关键代码
```

### V2-04 微电影生成范本

**任务目标**：生成品牌微电影、故事微电影、情感微电影

**执行步骤**：

1. **确定故事主题**

   - 情感故事：引起共鸣

   - 开头：设置悬念
   - 中间：发展情节

3. **设计故事画面**
