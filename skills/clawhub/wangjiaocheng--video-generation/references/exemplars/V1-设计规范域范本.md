## V1-设计规范域范本

### V1-01 画面系统应用范本

**任务目标**：应用画面规范：分辨率、帧率、画幅比

**执行步骤**：

1. **分析视频类型**
   - 宣传片：高清、专业
   - 短视频：流畅、竖屏
   - 教学视频：清晰、标准
   - 微电影：电影感、艺术感

2. **选择分辨率**
   - 4K (3840×2160)：高端宣传片、电影
   - 1080p (1920×1080)：标准视频、社交媒体
   - 720p (1280×720)：短视频、移动设备

3. **选择帧率**
   - 60fps：游戏视频、运动视频
   - 30fps：标准视频、日常记录
   - 24fps：电影、微电影

4. **选择画幅比**
   - 16:9：标准视频、YouTube
   - 9:16：短视频、抖音/快手
   - 1:1：社交媒体、Instagram

**输出示例**：

```markdown
## 画面系统应用方案

### 视频类型
- 类型：宣传片
- 用途：产品推广

### 分辨率选择
- 分辨率：1080p (1920×1080)
- 选择理由：兼容性好，适合社交媒体传播

### 帧率选择
- 帧率：30fps
- 选择理由：自然、真实，适合宣传片

### 画幅比选择
- 画幅比：16:9
- 选择理由：标准宽屏，适合横屏观看
```

### V1-02 音频系统应用范本

**任务目标**：应用音频规范：音量、音效、背景音乐

**执行步骤**：

1. **设定音量规范**
   - 旁白音量：-6dB ~ -3dB
   - 背景音乐：-12dB ~ -6dB
   - 音效：-6dB ~ 0dB

2. **选择音效**
   - 转场音效：增强视觉效果
   - 强调音效：突出重点内容
   - 环境音效：营造氛围

3. **选择背景音乐**
   - 风格匹配：与视频风格一致
   - 节奏匹配：与剪辑节奏配合
   - 情感匹配：与内容情感一致

4. **选择音频格式**
   - AAC：标准视频
   - MP3：社交媒体
   - WAV：专业制作

**输出示例**：

```markdown
## 音频系统应用方案

### 音量规范
- 旁白音量：-6dB
- 背景音乐：-12dB
- 音效：-6dB

### 音效选择
- 转场音效：whoosh音效
- 强调音效：叮咚音效
- 环境音效：无

### 背景音乐选择
- 风格：现代、科技感
- 节奏：中等节奏
- 情感：专业、可信赖

### 音频格式
- 格式：AAC
- 选择理由：兼容性好，音质高
```

### V1-03 字幕系统应用范本

**任务目标**：应用字幕规范：字体、大小、位置、样式

**执行步骤**：

1. **选择字幕类型**
   - 标题字幕：突出、醒目
   - 说明字幕：清晰、易读
   - 对话字幕：自然、不干扰画面

2. **设定字幕字体**
   - 标题字幕：黑体
   - 说明字幕：宋体
   - 对话字幕：宋体

3. **设定字幕大小**
   - 标题字幕：48px
   - 说明字幕：32px
   - 对话字幕：28px

4. **设定字幕位置**
   - 标题字幕：居中
   - 说明字幕：下方居中
   - 对话字幕：下方居中

5. **选择字幕样式**
   - 白色字幕+黑色描边：标准字幕
   - 白色字幕+半透明背景：信息字幕
   - 彩色字幕：强调字幕

### V1-04 节奏系统应用范本

**任务目标**：应用节奏规范：剪辑节奏、转场效果、时长控制

**执行步骤**：

1. **确定剪辑节奏**
   - 宣传片：快节奏
   - 短视频：快节奏
   - 教学视频：中等节奏
   - 微电影：慢节奏

2. **选择转场效果**
   - 切换：标准转场
   - 溶解：时间转换
   - 闪白：强调、高光
   - 滑动：方向转换

3. **控制时长**
   - 宣传片：30秒-2分钟
   - 短视频：15-60秒
   - 教学视频：5-15分钟
   - 微电影：5-30分钟

4. **设计节奏变化**
   - 开头：吸引注意力
   - 中间：保持节奏
   - 结尾：总结升华

**输出示例**：

```markdown
## 节奏系统应用方案

### 视频类型
- 类型：宣传片
- 时长：1分钟

### 剪辑节奏
- 整体节奏：快节奏
- 开头：快速吸引注意力
- 中间：保持快节奏
- 结尾：稍慢，总结升华

### 转场效果
- 主要转场：切换
- 强调转场：闪白
- 时间转场：溶解

### 时长控制
- 总时长：60秒
- 开头：10秒
- 中间：40秒
- 结尾：10秒

### 节奏变化
- 0-10秒：快节奏，吸引注意力
- 10-50秒：中等节奏，展示内容
- 50-60秒：慢节奏，总结升华
```
