## Known Risks and Mitigations:

Risk: Optional local hooks can persist and affect future coding work.

Mitigation: Preview deployment with a dry run and review target configuration before enabling hooks.

Risk: User-wide hook installation can affect unrelated projects.

Mitigation: Avoid user-wide scope unless intended, and regenerate the installed-hooks record for the local machine.
