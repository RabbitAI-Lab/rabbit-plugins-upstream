## Description: <br>
Daily Digest generates a daily Markdown journal digest from local memory notes, summarizing decisions, lessons, actions, and questions. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[pmaeter](https://clawhub.ai/user/pmaeter) <br>

### License/Terms of Use: <br>


## Use Case: <br>
Developers and Clawdbot users use this skill to turn daily memory notes into a dated digest for journals, reviews, and follow-up tracking. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated digests may preserve sensitive details from local memory notes. <br>
Mitigation: Review digest files before sharing or syncing them outside the local workspace. <br>
Risk: Daily automation can carry sensitive memory details forward without manual review. <br>
Mitigation: Enable scheduled runs only when the workspace owner is comfortable with persistent local summaries. <br>
