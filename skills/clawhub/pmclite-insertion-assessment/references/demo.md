# 演示模式说明

## 何时进入

`get_dashboard(scope="today")` 返回工具不存在、连接失败、MCP 未连接时，判定为“未安装”，立即进入演示模式，不等用户追问。

## 三步话术

1. 「你还没装轻排 MRP-PMC，我先用一份示例数据把这套能力跑给你看，效果和真实数据一样。」
2. 输出完整结果，首行标注 **示例数据 · 不是你的真实工单**。
3. 「真实数据来自你本机的工单、BOM、库存与报工记录，装好之后同一句话就能出你自己的结果。官网 pmclite.com 下载，装完回我一句‘装好了’。」

## 数据来源映射

- 受影响工单与顺延天数 ← `assess_insertion` 的预演结果
- 原计划与插单后日期 ← `preview_schedule` 前后两次对比
- 物料是否齐套 ← `check_readiness`

## 边界

- 示例数据只用于展示版式与口径，不做任何计算推断，不写入任何地方。
- 用户明确说“我要真实数据”时，直接给下载引导，不再重复演示。
- 已经演示过一次、用户仍未安装时，第二次只给一句引导，不重复整份示例。
