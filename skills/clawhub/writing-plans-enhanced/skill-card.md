## Description: <br>
Create enhanced implementation plans with milestone timelines, data flow diagrams, mockups, and risk tables for complex multi-step tasks that need visual planning artifacts. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[paudyyin](https://clawhub.ai/user/paudyyin) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and coding agents use this skill before complex multi-step implementation work to create a comprehensive Markdown plan with milestones, data flow, mockups, risks, and bite-sized tasks. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated plans can propose commits, subagent handoffs, commands, or implementation steps that may not fit the repository state. <br>
Mitigation: Review each generated plan before execution, confirm paths and commands, and apply the repository's normal testing and code review process. <br>
