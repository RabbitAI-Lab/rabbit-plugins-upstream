# AI国学大师 (Guoxue Master)

一站式国学智能助手。AI驱动的经典解读、诗词赏析、成语典故、易经占卜、节气养生、每日国学——让传统文化触手可及。

## 能做什么

输入一句话，自动完成以下功能：

1. 📖 **经典解读**：四书五经、道德经、庄子、孙子兵法、菜根谭等白话解读+原文对照
2. 🎵 **诗词赏析**：唐诗宋词元曲，含注释/译文/创作背景/艺术手法赏析
3. 📝 **成语典故**：6万条成语查询，释义+出处典籍+历史故事+现代用法
4. ☯️ **易经占卜**：AI模拟六爻金钱卦，64卦完整卦象+爻辞+白话解读
5. 🌿 **节气养生**：24节气查询，含习俗/农谚/中医养生/饮食建议
6. 📅 **每日国学**：每日推送精选名句，附带深度解读和现代启示
7. 📄 **交互式HTML报告**：一键生成精美可视化报告

## 参数说明

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `--mode` | ✅ | - | 功能模式：`classic`/`poetry`/`chengyu`/`yijing`/`jieqi`/`daily`/`report`/`demo` |
| `--query` | ❌ | - | 查询关键词（经典名句、诗名、成语等） |
| `--output` | ❌ | ./guoxue_report.html | 输出HTML报告路径 |
| `--api-key` | ❌ | - | LLM API Key（DeepSeek/OpenAI兼容；无Key使用内置数据库） |
| `--api-base` | ❌ | https://api.deepseek.com/v1 | API Base URL |
| `--model` | ❌ | deepseek-chat | 模型名称 |

## 工作流程

### 经典解读流程
1. 接收用户查询（经典名/篇章名/关键字）
2. 从内置数据库搜索匹配内容
3. 提供原文+白话译文+背景解读+现代启示
4. 如用户要求报告，生成HTML可视化报告

### 诗词赏析流程
1. 搜索匹配诗词（按诗名/作者/内容）
2. 提取：原文、注释、译文、作者背景、创作背景、艺术手法
3. 如需深度分析，调用LLM补充
4. 生成HTML格式赏析报告

### 易经占卜流程
1. 执行六爻模拟（随机生成六爻）
2. 确定本卦、变卦、动爻
3. 检索卦辞、爻辞、彖传、象传
4. 白话解读卦象含义
5. 输出HTML占卜报告

### 节气养生流程
1. 确定当前/指定节气
2. 检索该节气的三候、习俗、农谚
3. 推荐对应中医养生方案（饮食/作息/经络）
4. 生成HTML节气养生卡

### 综合报告流程
1. 理解用户意图，确定分析维度
2. 加载内置知识库 + 网络搜索补充
3. 分板块生成内容
4. 生成交互式HTML综合报告

## 知识库说明

### 内置数据库
- **经典文本**：四书五经、道德经、庄子、菜根谭等20+经典核心篇章
- **诗词库**：唐诗300首、宋词200首精选，含注释和赏析
- **成语库**：600+高频成语，含出处和典故
- **易经64卦**：完整卦辞/爻辞/彖传/象传 + 白话解读
- **24节气**：每节气含三候/习俗/农谚/养生

### 网络增强
- 内置数据不足时，自动搜索补充
- 查询诗词创作背景等扩展信息
- 热点国学话题实时搜索

## 注意事项

- 易经占卜仅供娱乐和文化了解，不构成决策依据
- 养生建议基于《黄帝内经》和传统中医理论，不能替代专业医疗建议
- 回答中涉及中国香港、中国台湾、中国澳门时，必须明确标注地区归属
- 所有经典引用优先采用权威版本（中华书局/上海古籍出版社版本为主）
