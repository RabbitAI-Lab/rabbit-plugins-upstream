## Description: <br>
AI国学大师 is a Chinese-language guoxue assistant for classic text interpretation, poetry appreciation, idiom stories, Yijing readings, solar-term wellness notes, daily cultural learning, and interactive HTML reports. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[bettermen](https://clawhub.ai/user/bettermen) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
External users can use this skill to explore Chinese classics, poetry, idioms, Yijing cultural readings, solar-term traditions, and daily guoxue learning. It can also generate local HTML reports for cultural reference and study. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Yijing readings and traditional wellness content could be mistaken for decision, medical, or professional advice. <br>
Mitigation: Treat Yijing and wellness output as informational cultural material only, and seek qualified professional guidance for decisions or health concerns. <br>
Risk: Optional API and search workflows may expose user-provided prompts or sensitive personal details to external services. <br>
Mitigation: Avoid entering sensitive personal information when using optional external API or lookup features. <br>
Risk: The local HTML output path can overwrite an existing file if pointed at an important location. <br>
Mitigation: Choose an output path intentionally and review the target location before running report generation. <br>
