## Description:

This skill helps an agent summarize current-week Markdown daily reports from a fixed local folder into a concise weekly work report and next-week plan.

This skill is ready for commercial/non-commercial use.

## Publisher:

[shijiezheng702-source](https://clawhub.ai/user/shijiezheng702-source)

### License/Terms of Use:

MIT-0

## Use Case:

Employees and individual contributors use this skill to turn current-week Markdown daily reports into a realistic weekly work summary, learning summary, and actionable plan for the following week.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill reads Markdown daily reports from a fixed local folder that may contain sensitive work information.

Mitigation: Keep sensitive reports out of C:\Users\zsj\Desktop\WorkBuddyFile or ask the agent to confirm the files before summarizing.

Risk: The weekly report quality depends on the accuracy and completeness of the selected current-week daily reports.

Mitigation: Review the source reports and the generated weekly summary before sharing it.
