## Description:

This skill helps an agent read current-week Markdown daily report files from a configured local WorkBuddyFile folder, consolidate work notes, remove duplicates and invalid details, and draft a natural personal weekly report.

This skill is ready for commercial/non-commercial use.

## Publisher:

[shijiezheng702-source](https://clawhub.ai/user/shijiezheng702-source)

### License/Terms of Use:

MIT-0

## Use Case:

Employees use this skill to turn local Markdown daily work reports for the current week into a concise weekly summary and next-week plan. The skill is intended for personal productivity workflows where the agent may read local work notes under the configured weekly folders.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may read and summarize sensitive business or personal content from current-week Markdown daily report files in the configured WorkBuddyFile weekly folders.

Mitigation: Review those folders for sensitive content before using broad weekly-report requests, and only keep intended report files in scope.
