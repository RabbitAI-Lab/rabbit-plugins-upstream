# 视频创作工作流生成器 · 使用指南

这个工具是一个"生成 skill 的 skill"。它不直接帮你选题、写文稿、做封面，而是按你的**平台、垂类、人设**，把这一整套能力量身定制成一个独立、可安装、开箱即用的专属工作流 skill——覆盖选题、文稿、标题、封面的完整链路。

你只用回答三个最基础的问题，剩下的受众画像、爆款打法、变现路径、平台算法动向，它自己联网研究补齐，先给你一份定位诊断确认方向，确认后再落地生成。

本指南假设你已经把生成器装好了（部署步骤见仓库 README），下面只讲两件事：**怎么生成你的第一个工作流**，以及**怎么用生成出来的产物做内容**。

---

## 第一部分：生成你的第一个专属工作流

整个过程你要参与的地方很少——回答三个问题、确认一次方向，剩下都是它自己跑。

### 1. 唤起生成器

在 Claude Code 或 Codex 里，用大白话说出你的需求就能唤起它，比如：

- "帮我做个账号工作流"
- "我想在抖音做美食测评账号"
- "定制一套视频创作流程"

> 📷 **截图占位符 1**：在 Claude Code / Codex 对话框里输入上面这类触发语、生成器被唤起后开始回应的画面。让读者看到"说人话就能触发，不用记命令"。

### 2. 回答三个问题

它只会问你三件事，一句话全说全也行：

1. **平台**——抖音 / B站 / 小红书 / 视频号 / 百家号，可多选
2. **垂类**——做什么内容方向，如财经、职场、历史、美食、科技测评
3. **人设**——以什么身份、什么口吻出镜，如"资深投资人""过来人前辈""专业测评师"

它**不会**追问你"目标受众是谁""怎么和别人差异化"这类问题——那些是它研究出来的，不该甩给你。所以放心，问答很短。

> 📷 **截图占位符 2**：一个真实的三问三答片段，最好是用户一句话把三件事说全（例如"我想在抖音做职场账号，人设是裸辞的大厂过来人"），生成器确认理解后直接进入研究。

### 3. 等它联网研究 + 看定位诊断

拿到三件事后，它会联网研究这个平台×垂类的受众画像、近期爆款、竞品格局、变现路径和平台算法动向，然后给你一份**定位诊断**，包含三块：

- **目标受众**：具体画像 + 受众心声（用受众自己的口语讲他们心里在想什么）
- **差异化定位**：相比现有竞品，你打的是哪个没被占满的角度
- **内容方向**：3-5 个具体的选题大类

**这是一个必须停下来的确认点。** 觉得哪里不对，直接用大白话调：

- "受众再窄一点"
- "差异化换个角度"
- "内容方向去掉反常识纠偏这条"

调到满意为止。它不会自作主张往下走。

> 📷 **截图占位符 3**：一份完整的定位诊断输出，能看到"目标受众 / 差异化定位 / 内容方向"三块，末尾是那句邀请你确认的话。这是整个生成过程最关键的一屏。

### 4. 确认后，它自动生成整套工作流

你说"确认"或"没问题，开始生成"之后，它就按规范把研究成果落地成一整套产物 skill，并自己跑一遍结构校验。这一步不需要你再来回确认，等它做完统一汇报即可。

生成完它会给你一份**交付说明**，告诉你：

- 产物生成在哪个目录、该放到哪里才能用
- 配了哪些触发词，之后怎么一句话唤起
- 选题 / 标题 / 封面 / 文稿四个模块怎么单独调用
- 哪些脚本要填 API key、填在哪

> 📷 **截图占位符 4**：生成完成后的交付说明画面，能看到产物目录名（形如 `<账号名>-workflow`）和触发词清单。

### 5. 装上产物，填好密钥

按交付说明把产物目录放到对应位置：

- **Claude Code**：`~/.claude/skills/<账号名>-workflow`
- **Codex**：`~/.codex/skills/<账号名>-workflow`

产物里做联网研究和生成封面的脚本要用到 API key。**真实密钥只填进产物目录下的 `.env` 文件**（这个文件已被 `.gitignore` 排除，不会被提交）——把 `.env.example` 里的占位符换成你自己的真实值即可。随产物提交的 `.env.example` 永远只放占位符。

> 📷 **截图占位符 5**：`.env` 文件填好密钥的示意（记得把真实 key 打码），旁边可以标一句"真实密钥只进 .env，绝不进任何会被提交的文件"。

装好、填好，产物就能独立运作了——它是自包含的，不再依赖生成器本身。

## 第二部分：用产物工作流生产内容

产物装好后，它就是你这个账号的专属"作战手册"。用法有两种：走完整流程，或单独调某个模块。

### 完整流程

从零做一条视频，链路是这样，中间有**两个人工决策点**：

```
选题 → 【你确认选定方向】 → 标题 → 封面 → 【你确认标题和封面】 → 文稿 → 审查
```

- **选题**：模块开头会先查内容库去重、找系列，再结合实时热点给你一批选题
- **确认方向**：从选题里挑一个，或让它调整
- **标题 / 封面**：基于选定方向生成，标题继承了深度分析逻辑，不是套模板
- **确认标题封面**：满意了再往下
- **文稿**：按选定的标题写口播稿，兑现标题承诺
- **审查**：交付前的强制终审，过一遍硬门禁、受众复审、事实与立场

> 📷 **截图占位符 6**：完整流程跑一遍的串联截图，或者只截其中一个人工确认点（比如选题列表 + "你挑哪个"的提问），让读者直观看到"哪里该我做决定"。

### 单模块独立调用

不是每次都得从选题走到底。四个模块都能单独唤起——已经有选题只想起标题、已经定了标题只想生成封面，直接说需求就行：

- "起个标题"
- "生成封面"
- "写文稿"
- "帮我想几个选题"

它会认出你要的是哪个模块，跳过前面的步骤直接干。

> 📷 **截图占位符 7**：单独唤起某个模块的例子，比如只说"给这个选题起 5 个标题"，产物直接进标题模块出结果。

### 内容资产库

产物每产出一条内容，都会自动结构化沉淀到一个独立于 skill 的长期数据库里。它的好处是：

- **选题时自动去重**，不会让你反复做同一个题
- **能找系列**，方便做成系列内容
- **重装产物 skill 不影响历史内容**，数据独立存放

你正常用就行，存档是自动的，不用手动管理。

---

## 一句话回顾

生成阶段你只做两件事：**回答三个问题** + **确认一次定位诊断**。之后装上产物、填好密钥，就能用它走完整流程或单独调模块来源源不断做内容。真正需要你动脑的，永远是那几个人工决策点——选哪个题、用哪个标题封面，其余的它都替你跑了。
