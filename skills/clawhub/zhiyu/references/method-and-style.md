# 方法与表达归纳

## 核心分析模型

### 1. 市场宽度与指数背离

先比较指数颜色与涨跌家数。若上证偏强但多数个股下跌，进一步检查银行等权重板块是否护盘，并将其描述为结构分化或跷跷板，而不是“市场全面走强”。

### 2. 位置优先于形态

同一根十字星或阳线，只有放在前高、平台、趋势线、颈线、整数关口附近才有解释力。先定位置，再谈 K 线含义。

### 3. 量价验证

- 放量突破：增加突破可信度，但仍等待收盘或回踩确认。
- 缩量上涨：提示动能不足或存量博弈，不直接等同于下跌。
- 缩量止跌：结合十字星、前低或支撑位，判断抛压可能衰竭。

### 4. 多周期结构

日线决定主要位置，60 分钟用于确认双底、颈线回踩、均线排列或收敛。不同周期冲突时降低结论强度。

### 5. 点位推导

优先使用可画出来的依据：前高/前低、平台边界、趋势线交汇、颈线、整数关口。每个点位必须回答“为什么是这里”。

### 6. 条件式应对

把判断写成条件树：

- 若放量站上压力位并回踩不破，则看下一目标位。
- 若冲高不破且量能衰减，则偏向震荡或回踩。
- 若跌破支撑且不能快速收回，则原判断失效，转向下一支撑。

## 常用文章模板

```text
明确观点：我更倾向于接下来[偏强/偏弱/震荡]，观察周期是[时段]。

为什么这么判断？
第一，[市场宽度、成交额或量价事实]。
第二，从[指数][周期]K线来看，[结构]正处在[关键位置]。
第三，[板块/外围市场]提供了[验证或反向约束]。

接下来讨论关键点位：[支撑]来自[依据]，[压力]来自[依据]。
若[触发条件]，则观察[下一点位]；若[失效条件]，原判断需要修正。

应对上，重点是[等待确认/控制仓位/分批加减]。走一步看一步，根据盘面变化更新观点。

以上为基于公开数据的技术分析，不构成投资建议。
```

## 质量检查

- 是否写清数据截止时间？
- 是否有明确结论和适用周期？
- 每个关键点位是否有来源？
- 是否至少有两类证据互相验证？
- 是否给出反向情景和失效条件？
- 是否避免确定收益、确定涨跌和个性化买卖指令？
