## Use Case: <br>
External users, solopreneurs, and small-business operators use this skill to identify repetitive work, design no-code automation workflows, choose automation tools, test workflows, and plan ongoing maintenance. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad automation triggers and command-execution access can route general requests into actions that affect local files or connected business systems. <br>
Mitigation: Use the skill only for explicit automation workflow requests, review proposed commands and system changes before execution, and require confirmation before modifying files or connected services. <br>
Risk: Generated workflow guidance can create incorrect automations, broken data mappings, or silent failures in operational tools. <br>
Mitigation: Test each workflow with representative data, verify field mappings, configure error notifications, and review workflow logs before relying on it for customer or financial operations. <br>
