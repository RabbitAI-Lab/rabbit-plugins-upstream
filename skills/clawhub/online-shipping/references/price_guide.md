# 运费试算 · 客户上手指南

对应官网页面：https://xdccy.com/send/SellerDelivery.aspx
（登录后在「寄件下单」页填写发件/收件的省市区与重量，页面会展示各快递公司的预估运费列表。
本技能做的就是把这份列表搬到对话里，并且能一次比价很多条路线。）

## 一、最快上手：一句话查价

直接把三段信息告诉助手就行：

> 从 **深圳南山** 寄到 **杭州西湖**，**1.5 公斤**，多少钱？

助手会自动完成：解析地址 → 登录校验 → 查价 → 按价格从低到高列出快递公司。

输出长这样：

```
====================================================================
  小递查查 · 快递运费试算
====================================================================
  发件：广东省 深圳市 南山区
  收件：浙江省 杭州市 西湖区
  重量：1.5 kg
--------------------------------------------------------------------
  快递公司                  预估运费         市场价   说明
  ----------------------------------------------------------------
  圆通速递                ¥ 7.20     ¥ 10.00   预约当天取件
  申通快递                ¥ 8.50     ¥ 12.00   全国31个省市互寄
  顺丰速运               ¥ 18.00     ¥ 23.00   时效最快
  ----------------------------------------------------------------
  共 3/4 个可用渠道；最便宜：圆通速递 ¥ 7.20
  最贵：顺丰速运 ¥ 18.00（价差 ¥ 10.80）
```

- **预估运费** = 实际要付的价格；**市场价** = 原价，用来看折扣力度。
- 显示 `¥ -.--` 的渠道表示**该地区不可达**，右边会写明原因。

## 二、地址怎么写都行

不用记规范名称，怎么写都能识别：

| 你写的 | 识别结果 |
|---|---|
| `广东省深圳市南山区` | 广东省 / 深圳市 / 南山区 |
| `广东,深圳,南山` | 广东省 / 深圳市 / 南山区 |
| `广东 深圳 南山` | 广东省 / 深圳市 / 南山区 |
| `深圳南山` | 广东省 / 深圳市 / 南山区（省份自动反查） |
| `北京朝阳` | 北京市 / 北京市 / 朝阳区（直辖市自动补全） |
| `东莞南城` | 广东省 / 东莞市 / 南城街道（直筒子市） |
| `新疆乌鲁木齐天山` | 新疆维吾尔自治区 / 乌鲁木齐市 / 天山区 |

**详细地址可以一起写**，会让报价更准：
`广东省深圳市南山区科技园路1号` → 区县识别为南山区，`科技园路1号` 作为详细地址传给接口。

> 只写到市、没写区县时，脚本会兜底估算并**明确告警**，
> 不会假装精确。看到告警请补上区县。

## 三、批量比价（选承运商最有用）

如果你有一批订单要决定走哪家快递，把路线整理成 CSV 交给助手：

```csv
寄件,收件,重量
广东 深圳 南山,浙江 杭州 西湖,1
广东省深圳市南山区,北京市朝阳区,2.5
上海 浦东,四川 成都 武侯,3
```

- 表头支持中文（`寄件,收件,重量`）或英文（`from,to,weight`），也支持没有表头。
- 可选列：`寄件详细地址`、`收件详细地址`。

```bash
python price_query.py --batch routes.csv --output 报价结果
```

输出会逐条列出最低价渠道：

```
  [  1] 广东省 深圳市 南山区 → 浙江省 杭州市 西湖区  1kg   圆通速递 ¥ 7.20（3个可用）
  [  2] 广东省 深圳市 南山区 → 北京市 北京市 朝阳区  2.5kg 圆通速递 ¥ 8.00（3个可用）
```

并导出 `报价结果.csv` / `报价结果.json`，可直接用 Excel 打开。

## 四、第一次使用：需要登录一次

报价查询用的是**网页登录身份**（存在浏览器里的 token），必须真实登录一次才能拿到。

好消息是：**登录页只有「用户名或邮箱 + 密码」两个字段，没有短信验证码和滑块**
（验证码和滑块是注册页的）。所以只要把账号密码给助手，登录会自动完成：

```bash
python web_login.py --username 138****1234 --password '你的密码'
```

流程是：自动填表 → 自动点登录 → 取回 token → 窗口关闭。你不需要操作。

token 会保存在凭据文件中，之后很长一段时间都不用再登录。

常用命令：

```bash
python web_login.py --check     # 看看登录状态还在不在
python web_login.py             # 已有 token 就复用，否则人工填写
python web_login.py --force     # 重新登录（换账号或 token 过期时）
```

> 账号通常就是手机号，`--username` 和 `--phone` 等价。
> 若页面额外弹出验证码或滑块（异常风控时），脚本会继续等待你手动完成。

## 五、常用命令速查

```bash
# 单条试算
python price_query.py --from "广东 深圳 南山" --to "浙江 杭州 西湖" --weight 1.5

# 只看最便宜的前 5 个
python price_query.py -f "广东 深圳 南山" -t "浙江 杭州 西湖" -w 1 --top 5

# 带详细地址（报价更准）
python price_query.py -f "广东省深圳市南山区科技园" -t "浙江省杭州市西湖区文三路" -w 2

# 导出到文件（生成 .json 和 .csv）
python price_query.py -f "广东 深圳 南山" -t "北京 朝阳" -w 1 --output 报价

# 批量比价
python price_query.py --batch routes.csv --output 报价结果

# 浏览器模式兜底（接口异常时用，需 Playwright）
python price_query.py -f "广东 深圳 南山" -t "北京 朝阳" -w 1 --headed
```

## 六、FAQ

**Q：为什么提示「未查询到快递渠道」？**
A：常见三种原因——① 账号未开通在线寄件功能；② 该地区暂无可用渠道；
③ 区县填错导致匹配不上。先核对地址，再检查账号权限。

**Q：为什么提示登录失效？**
A：网页 token 会过期。脚本遇到 401 会**自动引导重新登录并重试一次**；
若仍失败，手动执行 `python web_login.py --force`。

**Q：预估运费和实际下单价格一样吗？**
A：预估运费是渠道基于重量和路线的报价，实际下单可能因附加服务（保价、
包装等）略有差异。需要精确到分请以实际下单页为准。

**Q：重量有限制吗？**
A：与官网一致，单件不超过 9999（kg）。支持小数，如 `0.5`、`2.5`。

**Q：能查港澳台或国际件吗？**
A：不能。城市库只覆盖中国大陆 31 个省级行政区。

## 七、自助排查清单

遇到问题按顺序自查：

1. 执行 `python web_login.py --check` 确认登录 token 是否存在
2. 若已过期，执行 `python web_login.py --force` 重新登录
3. 确认发件/收件的**省市区填写完整**（区县级缺失最容易导致无渠道）
4. 单独跑一次地址解析验证输入：`python region.py "广东 深圳 南山"`
5. 把报错原文发回会话，助手会带着上下文继续协助处理
