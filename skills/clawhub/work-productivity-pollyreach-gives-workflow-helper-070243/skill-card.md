This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External developers, skill authors, maintainers, and AI-agent users use this skill to turn PollyReach-style demand into local-friendly workflows, checklists, implementation plans, and validation notes for productivity, reliability, and adjacent skill work. <br>

## Known Risks and Mitigations: <br>
Risk: The skill has broad auto-trigger wording, so it may be invoked for loosely related productivity or phone-workflow requests. <br>
Mitigation: Narrow trigger terms or disable implicit invocation so agents use it only for explicit PollyReach-style workflow, reliability, checklist, or implementation-support requests. <br>
Risk: Generated workflow or implementation guidance can be incomplete or mismatched to a user's operational constraints. <br>
Mitigation: Review outputs against the stated success criteria, assumptions, and remaining risks before using them for production work. <br>
