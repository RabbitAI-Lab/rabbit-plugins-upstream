## 功能食品行业职能群 — 任务要求清单（Requirements）

本文件是本技能的第二层结构：125 个能力单元的执行口径（每个任务类型一节：必选组件/可选组件/组装顺序/约束/格式）、15 域域级说明（每域含行业执行口径注入节）与多域总览；文末附「行业校准总表」与「合规红线速查」两节（全域强制依据）。单元结构属性（ID/依赖/元操作/身份叠加/自治度）以 FFO-catalog.md 为唯一权威。

### 多域总览

#### 全局执行细则

**执行流程细则**（六步，Step 0-4）：

1. **首次加载**：读取 FFO-catalog.md，获取 15 域 125 单元完整索引、完整依赖拓扑与 17 条管线模板
2. **任务判定（Step 0）**：判定任务特征——复杂度（单单元=简单；单域 3-7 单元=中等；跨域 8+ 单元=复杂）、内容类型（结构化成品为主）、创新需求（默认常规执行；策略类单元按需产出差异化方案）
3. **行业校准（Step 1）**：本技能行业校准**已预置**——直接加载本文件·行业校准总表（15 域行业术语/法规/流程/风险）与合规红线速查，不再运行时推导行业；组织校准保留运行时注入——识别用户组织规模（初创/中小/大型），注入管理颗粒度（初创从简、大型多法人合并）。R1-R5 行业定位：R1 信息密度 高（法规/标签/工艺口径密集，执行前必读对应参考文件，禁止凭记忆输出专业口径）；R2 创造性 中（内容/策略类可创造，合规/财务/认证类零创造）；R3 交互性 中高（信息卡展示、身份播报、🟨 单元须确认）；R4 规范性 极高（食品法规为硬约束，违规即阻断）；R5 迭代性 中（复盘/评估/预算循环类单元启用 ↻）
4. **任务编排（Step 2）**：单元匹配（集群路由表定位）→ 复合需求按依赖拓扑展开为多单元管线（优先复用 17 条预编排管线）→ 读取本文件对应域单元要求与 FFO 域范本作为执行口径与输出形态参照 → 依赖检查（缺失先补执行或请用户提供同等必选组件，无依赖冲突的单元并行执行 ‖）
5. **展示与执行（Step 3）**：先展示管线编排模式并获用户确认（🟨 半自动），再按展示纪律执行——依次显示所有涉及能力单元的完整信息卡并重点播报身份叠加（🎭 主身份 × 协同身份），跨域交接以身份语言叙事
6. **整合交付（Step 4）**：汇总各单元产出 → 跨单元一致性检查（数字/日期/产品名/声称口径勾稽自洽）→ 按用户要求格式交付 → 归档建议

**单元自治度纪律**：⬛ 全自动单元直接执行；🟨 半自动单元在关键确认点等待用户输入后再继续；⬜ 辅助单元按 P实现括注分工。

**降级模式**：标准模式（读取 references/、执行能力单元、生成全部产出文件、展示完整信息卡）；只读模式（仅单元匹配与管线规划、输出规划报告与名册预览，不写入任何文件）；禁写模式（无法落盘时，将全部产出以代码块形式输出，由用户手动保存）。

#### 能力单元信息卡 Schema

每个能力单元的信息卡含 10 字段，严格按序渲染：

1. **单元ID**（如 B6-01）
2. **名称**（任务类型）
3. **元操作**（S/C/A/O/I/G + 中文含义括注）
4. **输入**（本单元消费的数据/材料，含上游单元交付物）
5. **输出**（本单元产出的交付物）
6. **依赖**（上游单元 ID 清单，来自 catalog）
7. **AI自治度**（⬛/🟨/⬜）
8. **组合接口**（输出字段的下游消费方 = 刚性依赖 + 自愿消费依赖）
9. **身份叠加**（🎭 加粗重点显示，行业化身份栈）
10. **P实现**（LLM/工具/技能/人机/组合）

#### 展示协议（六项，强制纪律，任何执行不得省略）

1. **管线名册**：管线执行前，展示全部涉及单元的名册表（ID/名称/依赖/身份叠加）
2. **执行播报**：每个单元执行前播报 `主身份 × 协同身份 × 协同身份`（与信息卡身份叠加行一致）
3. **身份重点显示**：身份叠加行加 🎭 标记与加粗
4. **全量名册**：跨域管线执行前合并展示各域名册，体现多团队协作阵容
5. **协作叙事**：跨域交接以身份语言叙事（如"渠道商分级策略师的分级结论，交由面点产能排程官安排供货"）
6. **叙事保全**：全程不暴露内部机制表述（内核/封装等设计语言不出现在对用户输出中，用户问及机制时以身份语言简要回应）

#### 身份覆盖与边界

375 个行业化身份（125 主 + 250 协同）全部唯一无重名，行业泛化由本文件·行业校准总表预置注入；医生、律师等行业交付端专业者身份不预置，本技能定位为功能食品企业的组织职能支撑团队、不替代行业交付专业人员（研发科学家、烘焙大师、医生等专业判断由企业真实人员承担，技能输出物为其提供结构化支撑）。

#### P实现默认规则

P实现标注为该单元处理环节的实现方式组合：LLM（纯语言推理生成）；LLM+工具（生成+表格/计算类工具）；LLM+人机确认（🟨 单元在关键点等待用户确认）；人机组合（⬜ 单元 AI 完成清单/方案、人完成执行）；工具+LLM（数据/监控类先工具后解释）。覆写规则：用户环境缺少对应工具时降级为 LLM 并在输出中标注"待人工核验"。

#### 行业执行口径总则（全部单元适用）

1. **普通食品红线**：产品为普通食品，任何对外表述不得宣称疗效、不得暗示医疗效果；涉及疾病人群一律"遵医嘱"
2. **声称闸口**：凡需检测报告支撑的声称（高膳食纤维/0蔗糖/低GI/NRV%/营养成分功能声称），取得报告前一律不写；报告取得后按 GB 28050 追加
3. **法规时效**：涉及 GB 2760、GB 28050、药食同源目录的口径，标注"以最新有效版本为准"
4. **数据三分类**：法规标准（准，核对最新版）/ 工艺参数（通用参考值，需批适配）/ 市场与临床数据（相对比较用，不作精确医学数据引用）
5. **内部数据隔离**：内部实测与机理数据仅限内部使用，对外一律转化为体验化表述
6. **AI 内容标识**：AI 辅助生成的对外内容须按《人工智能生成合成内容标识办法》添加标识

### X0 路由编排域

#### 域级说明（含行业执行口径）

X0 域是编排层，承担任务路由、行业校准、名册展示与管线总控。**行业执行口径**：路由时优先识别功能食品行业高频任务族（新品合规上市、经销商全流程、宣称合规、药食同源供应、食养课件）；行业校准直接加载本文件·行业校准总表预置口径，仅对组织形态做运行时推导；名册与播报执行六项展示协议；管线优先复用 PL1-PL5 行业专属管线。

#### X0-01 食企任务路由与单元匹配

- **必选组件**: 意图识别结论（任务类型+涉及域）、匹配单元或管线清单（含 ID）、匹配依据说明（逐条对应任务特征）
- **可选组件**: 备选路由方案（当需求可多域解法时）、缺失信息追问清单
- **组装顺序**: 意图识别→关键词比对集群路由表→单元/管线匹配→依据说明→输出
- **约束**: 匹配必须引用集群路由表关键词；复合需求必须说明是否命中预编排管线；不得跳过依据说明
- **格式**: 路由结论表（Markdown：任务/单元或管线ID/依据）

#### X0-02 功能食品行业与组织双校准

- **必选组件**: 行业校准结论（引用本文件·行业校准总表与合规红线速查的加载声明）、组织形态判定（规模/形态）、校准后执行口径要点
- **可选组件**: 组织画像推导依据、校准差异提示（相对通用口径的调整点）
- **组装顺序**: 加载预置行业校准→组织形态判定→口径要点归纳→向用户确认（🟨）
- **约束**: 行业校准不得脱离本文件·行业校准总表另行推导；组织校准须给出推导依据；校准结论注入后续全部单元执行上下文
- **格式**: 校准卡片（Markdown：行业口径引用+组织判定+要点清单）

#### X0-03 食企身份名册编排与信息卡展示

- **必选组件**: 管线内全部单元的完整信息卡（10 字段 Schema）、名册表（ID/名称/依赖/身份叠加）、身份叠加重点标记（🎭+加粗）
- **可选组件**: 各域团队阵容小结（官团队视角）、并行段标注
- **组装顺序**: 按 catalog 取单元结构属性→按 requirements 取输入/输出字段→生成信息卡→按执行序排列名册
- **约束**: 10 字段严格按 Schema 顺序；身份叠加与 catalog 单元索引列完全一致；不得省略任何单元
- **格式**: 名册表 + 逐单元信息卡（Markdown）

#### X0-04 食企管线编排与执行通报

- **必选组件**: 管线编排模式图（编排符号表达式）、执行通报（逐单元：身份播报+产出摘要+交接说明）、扇入整合结论
- **可选组件**: 并行段执行说明、异常中断与补执行记录
- **组装顺序**: 名册展示→用户确认编排（🟨）→按依赖拓扑执行→逐单元播报→扇入整合→一致性检查
- **约束**: 执行前必须获用户确认；依赖未就绪不得执行下游；一致性检查须覆盖数字/日期/产品名/声称口径
- **格式**: 编排模式图 + 逐单元执行通报（Markdown）

### N1 人力资源域

#### 域级说明（含行业执行口径）

N1 域覆盖食企组织运转的人才职能。**行业执行口径**：核心岗位序列为食品研发（粮油/食品科学/微生物）、面点工艺（中式/西式）、品控（GB 体系）、渠道销售（合规话术胜任）、营养顾问；食品生产岗位入职须核验健康证明等从业要求；销售岗培训重心是合规话术纪律（对内机理/对外体验双轨，见合规红线速查）；薪酬对标食品制造业市场分位；产线用工关注倒班与季节性用工合规。

#### N1-01 食企组织架构与产线编制规划

- **必选组件**: 部门架构图（研发/生产/品控/渠道/职能）、层级与职责边界、编制测算表
- **可选组件**: 业务量与编制的联动假设、阶段化编制规划
- **组装顺序**: 业务解读→架构设计→职责边界→编制测算→确认（🟨）
- **约束**: 架构须覆盖食品企业关键职能（研发/生产/品控/QS 宣称管理）；编制测算须标注假设
- **格式**: 架构图（文本树）+ 编制测算表（Markdown）

#### N1-02 研发面点品控岗位说明书与职级

- **必选组件**: 目标岗位说明书（职责/任职资格/汇报关系/职级）、职级体系表
- **可选组件**: 关键岗位胜任力要点、职业发展通道说明
- **组装顺序**: 职责提炼→任职资格→职级映射→成稿→确认（🟨）
- **约束**: 食品专业岗位任职资格须含专业资质项（如食品科学学历、烘焙技师等级、健康证）；销售岗须含合规话术能力项
- **格式**: 岗位说明书（Markdown，逐岗位一节）

#### N1-03 食企招聘需求与渠道策略

- **必选组件**: 需求分析表（岗位/人数/ urgency）、渠道组合策略（院校/行业/猎聘/产线推荐）、投放计划
- **可选组件**: 雇主品牌要点、人才地图线索
- **组装顺序**: 需求分析→渠道比选→策略成稿→确认（🟨）
- **约束**: 研发类岗位须列出对口院校与专业方向；渠道类岗位侧重行业经验
- **格式**: 需求分析表 + 渠道策略表（Markdown）

#### N1-04 食企简历筛选与实操面试评估

- **必选组件**: 筛选结论清单（通过/待定/淘汰+理由）、结构化面试题库（含实操题）、评估记录表
- **可选组件**: 人才梯队建议、薪酬匹配提示
- **组装顺序**: 资格比对→筛选→面试设计→评估执行→录用建议（🟨）
- **约束**: 面点/工艺岗必须设计实操环节；评估记录须可追溯
- **格式**: 筛选清单 + 面试题库 + 评估表（Markdown）

#### N1-05 食企入职与试用期管理

- **必选组件**: 入职安排清单（材料/设备/导师）、试用期目标书、转正评估机制
- **可选组件**: 入职培训日程、师徒结对安排
- **组装顺序**: 材料核对（含健康证）→安排生成→目标书成文→跟踪机制
- **约束**: 生产相关岗位入职材料必须包含食品从业人员健康证明项；试用期目标须可量化
- **格式**: 入职清单 + 试用期目标书（Markdown）

#### N1-06 食企产销绩效目标与考核方案

- **必选组件**: 指标分解表（组织→部门→岗位）、评分规则、申诉机制
- **可选组件**: 权重设计依据、考核日历
- **组装顺序**: 目标分解→指标定义→权重与规则→机制成文→确认（🟨）
- **约束**: 产销类指标须区分产量/质量/动销维度；质量指标不得与产量指标冲突（食品安全优先）
- **格式**: 指标分解表 + 方案正文（Markdown）

#### N1-07 食企薪酬福利体系设计

- **必选组件**: 薪级薪档表、福利结构、激励方案（含产线计件/销售提成口径）
- **可选组件**: 市场对标摘要、总额测算表
- **组装顺序**: 对标→结构设计→激励规则→总额测算→确认（🟨）
- **约束**: 销售提成设计不得诱导违规话术（合规一票否决项写入激励约束）
- **格式**: 薪酬体系表（Markdown）

#### N1-08 食企员工关系与产线用工合规

- **必选组件**: 合同与制度合规审查清单、用工风险点清单（分级）、处置建议
- **可选组件**: 争议案例预案、制度修订建议
- **组装顺序**: 法条核查→审查执行→风险分级→处置建议→确认（🟨）
- **约束**: 覆盖产线倒班工时、季节性用工、实习生使用等食品行业高发风险；涉及法规标注时效
- **格式**: 审查清单 + 风险清单（Markdown）

#### N1-09 食企培训体系与人才发展

- **必选组件**: 分层培训体系图（新员工/在岗/晋升）、年度培训计划、人才发展通道
- **可选组件**: 培训预算框架、内部讲师机制
- **组装顺序**: 能力建模→体系设计→计划编排→通道成文→确认（🟨）
- **约束**: 培训体系须与 B10-04 课程开发衔接；销售序列必修合规话术模块
- **格式**: 体系图 + 计划表（Markdown）

#### N1-10 食企离职管理与人才盘点

- **必选组件**: 离职流程清单、面谈记录模板、九宫格盘点结果、继任建议
- **可选组件**: 关键岗位离职风险预案
- **组装顺序**: 流程执行→面谈→九宫格盘点→继任建议→回流 N1-01（↻）
- **约束**: 核心研发与渠道岗位离职须启动知识交接检查（联动 B10-08）；盘点结果校准后输出
- **格式**: 流程清单 + 盘点九宫格 + 继任表（Markdown）

### N2 财务会计域

#### 域级说明（含行业执行口径）

N2 域覆盖食企财务运转。**行业执行口径**：成本核算采用"原料→调配粉/母料→成品"三级归集，区分自产与代工两条成本线（代工线含结算核验）；经销商赊销须管控账期与应收账龄；农产品原料采购关注进项抵扣口径；存货管理关联保质期（联动 B6-03）；费用审核对照部门预算（联动 N2-04）；涉及税务优惠以最新税法为准。

#### N2-01 食企会计核算与账务处理

- **必选组件**: 凭证审核记录、记账凭证清单、期末结账核对表
- **可选组件**: 科目体系优化建议
- **组装顺序**: 凭证审核→记账编制→试算平衡→结账核对→确认（🟨）
- **约束**: 存货科目须支持按批次/保质期辅助核算；业务口径与 B6 域单据勾稽
- **格式**: 凭证清单 + 核对表（Markdown）

#### N2-02 食企费用报销审核与支付

- **必选组件**: 票据审核记录（真实性/合规性）、预算比对结论、支付/驳回建议

B9 域是经营闭环的风控端，**本技能的硬约束中枢**。**行业执行口径**：适用法规清单为 GB 2760（添加剂）、GB 28050（营养标签与声称）、广告法（疗效与绝对化禁止）、《人工智能生成合成内容标识办法》、食品生产许可审查规则；宣称风险地图覆盖五维（疾病治疗词/功效保证词/绝对化用语/医学机制展开/疾病配图）；标签必备项九要素（品名/配料表/净含量/生产者/日期/保质期/贮存条件/执行标准号与 SC 证号/营养成分表）为审核基准；双轨话术纪律（对内机理/对外体验）为培训核心；销售话术、直播脚本与投放稿口径一致性为专项检查项。执行依据本文件·合规红线速查。

#### B9-01 食品法规义务与宣称风险地图

- **必选组件**: 适用法规清单（版本/时效标注）、合规义务分解表、宣称风险地图（五维分级）、责任映射
- **可选组件**: 监管动态简报
- **组装顺序**: 法规扫描→义务分解→风险分级→映射→确认（🟨）
- **约束**: 法规以最新有效版本为准并标注核验日期；风险地图覆盖内容/标签/渠道话术三类载体
- **格式**: 清单 + 风险地图（Markdown）

#### B9-02 食品宣称与投放材料合规审核

- **必选组件**: 审核记录表（逐维：疾病词/功效保证/绝对化/机理展开/疾病配图/AI标识/标签要素）、不合格项标注与改稿要求、放行/拦截结论
- **可选组件**: 典型问题案例卡
- **组装顺序**: 逐维审核→标注→改稿要求→放行判定→确认（🟨）
- **约束**: 拦截即阻断发布（含印刷下单前拦截）；声称类逐条对照检测报告；与 B3-06 审核记录互相索引
- **格式**: 审核记录表（Markdown）

#### B9-03 经销代工资质合规评估

- **必选组件**: 合作方资质核查清单（经销/代工/平台：证照/信用/合规历史）、评估结论、准入/拒绝建议
- **可选组件**: 高风险名单机制
- **组装顺序**: 清单核对→背景筛查→评估→建议→确认（🟨）
- **约束**: 代工厂须核验对应品类生产许可；核查记录留痕
- **格式**: 核查清单 + 评估结论（Markdown）

#### B9-04 食企内审与整改追踪

- **必选组件**: 审计计划、发现清单（分级）、整改追踪表（责任人/时限/验证）
- **可选组件**: 审计报告
- **组装顺序**: 计划→执行→发现汇总→整改追踪→闭环
- **约束**: 覆盖宣称合规与标签专项审计；重复发现项升级处理
- **格式**: 清单 + 追踪表（Markdown）

#### B9-05 食品业务风险评估与最小化

- **必选组件**: 风险登记册（风险/可能性/影响/等级）、高风险项最小化措施（如"需报告声称先不写"）、监测指标
- **可选组件**: 风险热图
- **组装顺序**: 识别→评估→措施→监测设定→确认（🟨）
- **约束**: 措施可执行可验证；配方数据泄露风险与 N4-02 联动
- **格式**: 登记册 + 措施表（Markdown）

#### B9-06 食品合规培训与话术纪律

- **必选组件**: 分角色培训方案（销售/客服/内容/管理）、双轨话术考核题库、学习效果记录
- **可选组件**: 合规文化物料
- **组装顺序**: 方案设计→课程开发（联动 B10-04）→考核→效果记录→确认（🟨）
- **约束**: 销售岗全覆盖并考核通过后上岗；话术考核以对外合规版为标准答案
- **格式**: 方案 + 题库 + 记录（Markdown）

#### B9-07 市场监管沟通与迎检

- **必选组件**: 沟通事项登记、迎检材料包（证照/记录/制度）、承诺事项追踪表
- **可选组件**: 沟通话术指引
- **组装顺序**: 事项登记→材料准备→沟通/迎检→追踪→确认（🟨）
- **约束**: 材料真实一致；承诺事项限时闭环
- **格式**: 登记表 + 材料包清单（Markdown）

#### B9-08 宣称违规事件应对与整改

- **必选组件**: 事件记录（事实/影响/处置）、根因分析、制度层整改、验证关闭记录
- **可选组件**: 同类风险排查清单
- **组装顺序**: 响应→根因→整改→验证→关闭→确认（🟨）
- **约束**: 整改到制度/流程层而非仅个案纠正；验证留证
- **格式**: 事件报告 + 整改记录（Markdown）

### B10 知识管理与培训域

#### 域级说明（含行业执行口径）

B10 域是经营闭环的沉淀端。**行业执行口径**：知识库分类覆盖纤维科学/产品体系/面点工艺/法规合规/渠道运营五域；**知识库≠课件**——知识库是内容底稿（全、准、可溯源），课件是表达设计（少、精、有节奏），转化遵循"底稿抽要点→补案例实操→加互动检验"；培训对象分五类（生产面点岗/研发岗/销售渠道岗/医生营养师客户/加盟商终端），抽课口径完全不同；工艺参数类知识标注"通用参考值，需批适配"；问答库答案执行对外合规口径；案例入库前脱敏。

#### B10-01 纤维科学与工艺知识库建设

- **必选组件**: 知识分类体系（五域分类/标签/权限）、入库规范（来源标注/时效标注/审核人）、检索规范
- **可选组件**: 知识地图
- **组装顺序**: 分类设计→规范成文→检索机制→确认（🟨）
- **约束**: 每条知识标注来源与时效；合规类知识标注"以最新法规为准"
- **格式**: 分类表 + 规范（Markdown）

#### B10-02 面点工艺与品控 SOP 手册

- **必选组件**: SOP 清单（工艺/品控/渠道/行政）、SOP 文档（步骤/参数/检查点/记录表单）、版本记录
- **可选组件**: 关键工序图示说明
- **组装顺序**: 清单→编写→参数核对→版本管理→确认（🟨）
- **约束**: 高纤面点工艺 SOP 须含纤维吸水补水（每 1% 纤维补 3-8 倍水）、谷朊粉 2-6%、酵母 1.2-1.5%、和面延长、醒发缩短、炉温降 10-20℃ 等参考参数并标注适配要求；参数标注"通用参考值"
- **格式**: SOP 文档包（Markdown）

#### B10-03 消费者渠道问答库与卡片

- **必选组件**: 问题分类清单（食用方法/产品知识/储存/人群适用/合规边界）、标准化答案卡（含对外口径）、禁答清单（疾病问题→引导遵医嘱）
- **可选组件**: 高频问题Top榜
- **组装顺序**: 收集→分类→标准化→卡片化入库
- **约束**: 全部答案过合规口径（合规红线速查）；疾病相关一律"遵医嘱"；答案与检测报告数值一致
- **格式**: 分类清单 + 答案卡（Markdown）

#### B10-04 食品五类对象课程开发

- **必选组件**: 培训需求分析（分五类对象）、课程大纲（模块/课时/形式）、课件包、考核方案
- **可选组件**: 讲师手册骨架
- **组装顺序**: 需求调研→对象抽课→大纲→课件→考核设计→确认（🟨）
- **约束**: 五类对象差异化抽课（生产面点岗抽工艺实操砍法规细节；销售岗抽产品与合规话术砍工艺细节；医生客户抽科学与数据；加盟商抽产品/销售/合规）；销售模块含话术演练
- **格式**: 需求分析 + 课程包（Markdown）

#### B10-05 食品培训实施与四级评估

- **必选组件**: 实施计划、签到与考核记录、四级评估（反应/学习/行为/结果）
- **可选组件**: 优秀学员激励建议
- **组装顺序**: 计划→实施→考核→评估→改进回流 B10-04
- **约束**: 考核不合格补训重考；行为层评估在岗后 30 天
- **格式**: 计划 + 评估报告（Markdown）

#### B10-06 食品最佳实践案例库

- **必选组件**: 案例入库标准、案例卡（背景/做法/结果/启示）、脱敏标签、检索索引
- **可选组件**: 案例来源通道说明
- **组装顺序**: 标准制定→筛选→撰写→脱敏→入库
- **约束**: 案例数据脱敏（企业/人名/敏感数字）；结果数据可验证
- **格式**: 案例卡（Markdown）

#### B10-07 食研面点渠道胜任力模型

- **必选组件**: 岗位胜任力模型（食研/面点/渠道/品控）、行为分级描述、盘点校准记录
- **可选组件**: 发展建议生成规则
- **组装顺序**: 模型构建→分级→盘点校准→输出→确认（🟨）
- **约束**: 模型与 N1-02 岗位说明书对齐；分级行为可观察
- **格式**: 模型 + 校准记录（Markdown）

#### B10-08 工艺渠道经验萃取与传承

- **必选组件**: 萃取访谈提纲、经验卡（情境/做法/要点）、方法论提炼文档
- **可选组件**: 传承计划
- **组装顺序**: 提纲设计→访谈→萃取→提炼→确认（🟨）
- **约束**: 工艺经验经工艺负责人确认后入库；萃取物脱敏
- **格式**: 访谈提纲 + 经验卡（Markdown）

#### 15 域行业校准注入

##### X0 路由编排域
- 术语：职能群、能力单元、合规闸口、双轨话术
- 流程特征：复合任务优先走 PL1-PL5 行业管线；任何含对外产出的任务在编排时预插 B3-06/B9-02
- 风险：编排遗漏合规闸口 = 最高级编排失误

##### N1 人力资源域
- 术语：健康证（食品从业人员健康管理）、产线计件、倒班、季节性用工、感官评定员
- 流程特征：核心岗位序列=食品研发（粮油/食品科学/微生物）、面点工艺（中式/西式）、品控、渠道销售、营养顾问；销售岗入职必修合规话术并考核上岗
- 风险：产线工时合规、销售激励诱导违规话术、关键工艺人员离职知识流失

##### N2 财务会计域
- 术语：三级成本归集（原料→调配粉/母料→成品）、代工结算、经销赊销账期、农产品进项抵扣、促销返利
- 流程特征：自产与代工双成本线；存货按批次与保质期辅助核算；渠道费用与动销挂钩
- 风险：临期报废税务处理、返利入账口径、研发投入归集

##### N3 行政办公域
- 术语：SC 生产许可证、检测报告编号体系、商标命名风险、执行标准号、版号管理
- 流程特征：证照档案四类核心（SC 证/检测报告/商标/专利）；合同高频类型=经销协议/代工合同/采购合同/合作框架（条款要点：独家供应/锁价/IP 归属/违约责任）
- 风险：标签印刷前未过合规审核、商标使用的功效语境风险

##### N4 信息技术域
- 术语：配方数据分级、健康服务系统（小程序/AI 客服）、产线工控终端
- 流程特征：最高保护等级=配方与工艺数据；系统台账三类（ERP/健康服务/知识库）
- 风险：配方外泄（合作方场景）、检测报告误读（格式转换错误）

##### B1 情报采集与监测域
- 术语：纤维缺口（人均摄入 vs 推荐 25-30g）、低 GI 国标进程、断碳 vs 保碳路线、代餐/控糖赛道
- 流程特征：竞品分析双动作（配料表拆解 + 声称合规比对）；路线之争为对内认知、对外不点名攻击同行
- 风险：代谢人群数据被误作医学引用、竞品违规声称被模仿

##### B2 资质认证与监管域
- 术语：SC 生产许可、低 GI 认证、声称门槛（详见合规红线速查）、药食同源目录、批次留样
- 流程特征：检测报告编号与产品一一对应；配方/标签变更即触发变更评估；认证时机结合国标进程
- 风险：声称先于检测报告投放、标签要素缺失、续证逾期

##### B3 内容生产与传播域
- 术语：安全底稿、双轨话术（对内机理/对外体验）、体验化表述、AI 生成内容标识
- 流程特征：内容三分类投放（可投放/需报告/禁投）；直播与销售话术须与投放稿口径一致
- 风险：疗效词、绝对化用语、疾病配图、命名语义暗示（详见合规红线速查）

##### B4 活动运营与执行域
- 术语：招商路演、试吃动线、样品冷链到位、展会洽谈
- 流程特征：物料话术先预审后印制；冷冻样品温控留痕；招商不承诺收益
- 风险：现场话术跑偏、样品断链、意向数据口径不一

##### B5 客户与伙伴运营域
- 术语：经销商分级、动销、回款、询价统一对接（渠道源性保护）、联合生意计划（JBP）
- 流程特征：客户四类（经销/终端/专业机构/加盟商）；健康度=动销+回款+终端反馈
- 风险：多头询价破坏价格体系、窜货、向专业机构过度承诺

##### B6 供应链与运营保障域
- 术语：药食同源目录合规、五类纤维复配、超微粉碎（300-1000 目参考值）、冷链（-18℃）、CAPA、双源备选
- 流程特征：原料准入=目录合规+批检核验；自产/代工双线排程；工艺参数为通用参考值需批适配
- 风险：目录外原料、单源断供、冷链断链、批次追溯断点

##### B7 数据分析与决策域
- 术语：动销、复购、人群画像（控糖/减脂/中老年/家庭）、指标字典
- 流程特征：北极星指标从动销/复购/回款中选；人群分析仅作运营参考不作功效暗示
- 风险：指标口径漂移、内部数据外流

##### B8 流程协同与项目管理域
- 术语：新品上市、建厂审批节点、跨部门三角（研发-合规-渠道）、食安危机分级
- 流程特征：新品走 PL1；危机响应口径统一并限时上报
- 风险：合规在项目中被后置、危机口径不一

##### B9 合规审核与风控域
- 术语：疗效宣称、绝对化用语、标签必备项九要素、广告法、AI 标识办法
- 流程特征：五维宣称审核（疾病词/功效保证/绝对化/机理展开/疾病配图）；直播与话术一致性专项检查
- 风险：拦截失效（印刷/发布后才发现）、整改仅个案不达制度层

##### B10 知识管理与培训域
- 术语：知识库≠课件、五类培训对象、抽课口径、工艺参数适配标注
- 流程特征：知识底稿全准可溯源，课件少精有节奏；五类对象差异化抽课（生产面点/研发/销售渠道/医生营养师客户/加盟商终端）

### 合规红线速查（全域强制）

本文件是全部涉对外表述单元的强制依据（B3/B4/B5/B9 及任何产出对外材料的单元）。产品为**普通食品**：不宣称疗效、不暗示医疗效果、不使用绝对化用语、疾病人群一律"遵医嘱"。执行口径以 GB 2760、GB 28050、广告法等**最新有效版本为准**。

#### 1. 营养声称门槛（GB 28050 口径速查）

| 声称 | 门槛 |
|------|------|
| 高膳食纤维 / 富含膳食纤维 | 膳食纤维 ≥ 6 g/100g（固体） |
| 膳食纤维来源 / 含膳食纤维 | 膳食纤维 ≥ 3 g/100g |
| 低糖 | 糖 ≤ 5 g/100g（固体） |
| 无糖 | 糖 ≤ 0.5 g/100g |
| 低 GI | GI ≤ 55（对应国标） |
| 铝残留（面制品） | ≤ 100 mg/kg |

> **声称闸口纪律**：凡需检测报告支撑的声称（高膳食纤维/0 蔗糖/低 GI/NRV%/营养成分功能声称），**取得报告前一律不写**；取得报告后按 GB 28050 追加，数值与报告一致。

#### 2. 标签必备项（九要素）

品名、配料表、净含量、生产者名称与地址、生产日期、保质期、贮存条件、**执行标准号与 SC 证号**、营养成分表。任一缺失即审核不通过（联动 B9-02、N3-11 印刷前置拦截）。

#### 3. 禁用表述清单（五维）

| 维度 | 禁止表述示例 |
|------|-------------|
| 疾病治疗 | 治疗 / 预防 / 诊断 / 治愈 / 根治 / 逆转 / 修复黏膜 / 拮抗幽门螺杆菌 |
| 功效保证 | 见效 / 有效率 / 减重 / 停药 / 无负担 |
| 绝对化 | 绝对不升糖 / 完全不升糖 / 绝对安全 / 最有效 |
| 医学机制（对外展开） | 胰岛素分泌刺激 / 神经递质改善 / β 细胞修复（作为功效表述时） |
| 疾病配图 | 血糖仪 / 病历 / 药品包装等疾病相关配图 |

#### 4. 安全表述替换对照表

| 原表述（不可用） | 安全表述（可用） |
|------------------|------------------|
| 降血糖 | 平稳餐后血糖响应 / 低升糖 |
| 不升糖 | 慢升糖（延缓血糖上升） |
| 减肥 / 减重 | 高纤饱腹 / 适配低卡碳水需求 |
| 治疗便秘 | 促进肠道通畅 / 规律排便 |
| 修复胃黏膜 | 温和养护胃肠道 / 胃部舒适 |
| 增强免疫 | 免疫营养支持 / 提供营养底物 |
| 药效 / 疗效 | 药食同源属性 / 中式滋补（仅作原料属性描述） |
| 五高人群专用 | 关注血糖血脂血压人群的膳食选择参考 |

#### 5. 对外三条铁律（销售与直播话术）

1. **讲机理，不讲疗效**——讲"膳食纤维如何工作"，不讲"能治什么病"
2. **讲慢升糖，不讲不升糖**——"不升糖是伪科学"，人必须适量摄入碳水
3. **讲营养，不讲药**——产品是普通食品不是药；涉及疾病人群一律"遵医嘱"

**高风险场景应答方向**：
- "能降血糖吗？" → "本品是普通食品，提供膳食纤维，帮助延缓碳水吸收、平稳餐后血糖响应。健康管理请遵医嘱。"
- "能替代降糖药吗？" → "**绝对不能**。任何用药调整必须由医生决定。"
- "多久见效？" → "膳食纤维是营养补充，没有'见效'的说法，长期坚持有助于改善膳食结构。"
- "有检测报告吗？" → 出示最新检测报告原件，只念报告文字，不额外解释。

#### 6. 双轨话术（对内 vs 对外）

| 维度 | 对内（培训/内部资料） | 对外（宣传/招商/社媒/消费者） |
|------|----------------------|------------------------------|
| 定位叙事 | 可展开完整机理与设计逻辑 | 只讲体验：吃得对、吃得饱、有得吃 |
| 数据 | 可用内部实测数据 | 只用已获检测报告数据；内部数据不外流 |
| 竞品对比 | 可内部拆解路线差异 | 不点名攻击同行 |
| 人群建议 | 可展开适用与禁忌细节 | 保留"慎用/遵医嘱"提示 |

> 口诀：**对内讲机理，对外讲体验；对内讲数据，对外讲感受。**

#### 7. 产品命名风险管理

产品名含血糖/体重语义词（如"糖""轻"）时：广告中仅作商标使用，**不得**附加任何血糖/减重语义语境，不与功效语境词并列出现；新命名优先中性词。

#### 8. AI 生成内容标识

AI 辅助生成的口播、文案、图像等对外素材，按《人工智能生成合成内容标识办法》添加显式标识；发布前逐条核验（B3-09 检查项）。

#### 9. 原料合规要点

- 药食同源类配料须在国务院卫生行政部门公布的"既是食品又是中药材"目录内，且用量合规（目录以最新公布批次为准）
- 食用菌原料须为可食用品种
- 添加剂符合 GB 2760 食品类别与最大使用量；面制品优先无铝膨松剂（铝残留 ≤100mg/kg）
- 脱氢乙酸钠等限用/禁用动态以最新标准为准

#### 10. 数据引用纪律（三分类）

| 类型 | 可靠性 | 用法 |
|------|--------|------|
| 法规标准 | 准 | 以最新有效版本为准，标注核验日期 |
| 工艺参数 | 通用参考值 | 按设备/批次/环境适配，不直接承诺 |
| 市场与临床数据 | 多来源差异大 | 相对比较与趋势判断；对外以最新检测报告为准 |

**三条自律**：矛盾数据不强行统一（标注不确定性）；商业软文来源标为"行业测评"口径；健康表述严守本文件红线。

4. 红线词扫描通过（五维零命中）
