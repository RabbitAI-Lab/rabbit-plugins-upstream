# FFO-单元信息卡模板（10 字段标准格式）

> 使用说明：为管线内每个能力单元生成完整信息卡时，复制本模板逐字段填充；字段顺序不可调整；身份叠加行加 🎭 标记与加粗重点显示。字段取数来源：结构属性取 catalog 单元索引，输入/输出与组合接口取 requirements。 占位符以 `{}` 花括号标注，复制后逐项替换，不得留空占位交付。

```
单元ID：{X0-01 / N1-01 / B1-01}
名称：{任务类型名称}
元操作：{S/C/A/O/I/G}（{感知/认知/行动/组织/交互/守护}）
输入：{本单元消费的数据/材料，含上游交付物}
输出：{本单元产出的交付物（对应 requirements 格式字段）}
依赖：{上游单元 ID 清单，无则"无（入口）"}
AI自治度：{⬛ 全自动 / 🟨 半自动 / ⬜ 辅助}
组合接口：{下游消费方 = 刚性依赖 + 自愿消费依赖（取自 catalog 依赖拓扑）}
身份叠加：🎭 {行业化主身份} × 协同{行业化协同身份} × 协同{行业化协同身份}
P实现：{LLM / LLM+工具 / LLM+人机确认 / 人机组合 / 工具+LLM}
```

**填充示例**：

```
单元ID：B3-06
名称：内容审核与质量标准
元操作：G（守护）
输入：B3-03 内容成稿；合规红线速查（requirements）红线清单
输出：审核记录表（逐维）+ 放行/拦截结论
依赖：B3-03
AI自治度：🟨
组合接口：B9-02（刚性）；B3-04（消费放行稿）
身份叠加：🎭 合规内容质检官 × 协同红线词扫描员 × 协同GB28050声称核验员
P实现：LLM+人机确认
```
