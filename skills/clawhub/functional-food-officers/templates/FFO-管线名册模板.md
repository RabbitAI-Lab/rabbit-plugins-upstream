# FFO-管线名册模板（管线名册与执行播报）

> 使用说明：管线执行前（Step 3）用本模板生成名册并获用户确认（🟨）；执行中逐单元按"执行播报"格式播报身份叠加。六项展示协议全文见 requirements·多域总览·展示协议。 占位符以 `{}` 花括号标注，复制后逐项替换，不得留空占位交付。

## 一、管线名册（执行前展示）

```
【管线名册】{管线编号与名称（如 PL1 高纤新品合规上市线）}
编排模式：{B1-01→B2-01→…⇉[…]→…}

| 序 | ID | 名称 | 依赖 | 身份叠加 |
|----|----|------|------|---------|
| 1 | {ID} | {名称} | {依赖} | 🎭 {主身份} × 协同{身份} × 协同{身份} |
| … | | | | |

请确认编排（🟨）：确认后按依赖拓扑执行；并行段将同步推进。
```

## 二、执行播报（逐单元）

```
▶ {ID} {名称}
  身份播报：🎭 {主身份} × 协同{身份} × 协同{身份}
  产出：{交付物名称（对应 requirements 格式）}
  交接：{下游单元}（{交接内容摘要}）
```

## 三、跨域协作叙事（交接时）

```
{上游主身份}的{交付物}，交由{下游主身份}承接——{一句话说明下游将做什么}。
（示例：合规内容质检官的放行结论，交由食品材料审核官做最终投放审核——复核声称与检测报告的一致性。）
```

## 四、扇入整合（执行完）

```
【整合交付】全部 {N} 个单元完成。
一致性检查：数字 ✓ / 日期 ✓ / 产品名 ✓ / 声称口径 ✓（勾稽自洽）
最终交付：{交付物清单}
```
