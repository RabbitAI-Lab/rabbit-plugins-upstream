## Description: <br>
Helps AI-agent users, skill authors, maintainers, and teams create practical ontology-style workflows, artifacts, checklists, analyses, and implementation support for work-productivity needs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, maintainers, skill authors, and agent users use this skill to turn ontology-style productivity needs into concrete local-friendly workflows, checklists, templates, analysis, code changes, or decision support. It is intended for bug fixing, setup hardening, reliability improvement, and creating adjacent skills from a validated job-to-be-done. <br>
