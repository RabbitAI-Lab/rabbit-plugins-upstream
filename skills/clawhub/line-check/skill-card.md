## Description:

Use when asked to audit a repository, assess project health, find the highest-value improvements a repo needs, check whether a project is ready for contributors or coding agents, or decide what to work on next in a codebase.

This skill is ready for commercial/non-commercial use.

## Publisher:

[solomonneas](https://clawhub.ai/user/solomonneas)

## Use Case:

Developers and engineering teams use this skill to assess a repository's health and readiness, then prioritize high-value improvements into an actionable backlog.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Audit recommendations may be incomplete or context-dependent, and the skill may run installed Brigade diagnostics while inspecting repository content.

Mitigation: Use it only on repositories you are authorized to audit, review any diagnostics before enabling them, and verify findings against project context before acting.
