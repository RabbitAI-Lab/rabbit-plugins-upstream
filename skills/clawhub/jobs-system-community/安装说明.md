# Jobs-System（社区演示版）安装说明

本包是 Jobs-System 的对外开源演示版：三层推理框架（理解意图 / 拷问 / 答案）
+ 表达层（Voice），附一套可运行的结构校验壳，用于展示框架辨识度与表达效果。

## 1. 安装

把 `Jobs-System-Community/` 整目录复制到技能目录之一：

- 用户级：`~/.workbuddy/skills/Jobs-System-Community/`
- 项目级：`<你的项目>/.workbuddy/skills/Jobs-System-Community/`

复制后重命名为 `Jobs-System`（与 SKILL.md 的 `name` 对齐）即可被加载：
`~/.workbuddy/skills/Jobs-System/`

## 2. 依赖

Python 3.13（托管运行时）+ 标准库，零第三方依赖。不联网、本地优先。

## 3. 目录结构

```
Jobs-System-Community/
├── SKILL.md                  # 三层推理框架 + Voice 规范
├── README.md                 # 方法论与设计说明
├── jobs-voice.md             # 表达层规范
└── references/
    ├── product_shell.py      # 产品壳：渲染决策单 + 八门结构校验
    ├── cognitive_bridge.py   # 共振桥接
    ├── lattice_resolver.py   # 格栅解算
    ├── quality_matrix.py     # 语义维度与信号聚合
    └── _selftest_record.json # 自测样例决策记录（演示用）
```

## 4. 命令行自测

```bash
cd Jobs-System-Community/references
python product_shell.py render --record _selftest_record.json --tier 双向门
```

输出决策单 + 八门结构校验（证据充分性准入 / 决策框定 / 自我盘点 / 结论自证 /
表达保真 / 维度覆盖 / 跨界类比 / 落地性）。样例应全 PASS。

## 5. 说明

- 本版为社区演示版，用于展示框架与表达效果，不包含内部完整方法论。
