## Description:

Turns an interactive single-file HTML prototype into a shareable Chinese-language product requirements document with real screenshots and rules drawn from the prototype's code.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jes614753-sketch](https://clawhub.ai/user/jes614753-sketch)

### License/Terms of Use:

MIT-0

## Use Case:

Product managers and developers use this skill to document interactive HTML prototypes as self-contained PRDs, capturing working interface states and distinguishing implemented rules from recommendations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Inspecting a prototype without authorization could expose information that should not be shared.

Mitigation: Use only prototypes you are permitted to inspect and review the completed PRD before sharing.

Risk: The workflow starts a local web server and a headless browser.

Mitigation: Use the documented staging directory and isolated browser profile, then close both processes when finished.
