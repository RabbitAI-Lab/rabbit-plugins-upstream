## Description:

Helps turn blog posts or documents into narrated videos with storyboards and voiceover through dLazy's hosted file-to-video workflow.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and teams can use this skill to request a narrated video from a blog post or document, including an outline, storyboard, and voiceover.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The blog-to-video title does not reflect the broader file-to-video workflow used by the skill.

Mitigation: Confirm that the hosted file-to-video workflow fits the intended content before use.

Risk: Attached local files are uploaded to dLazy's hosted service.

Mitigation: Attach only files you are comfortable sharing with dLazy.

Risk: Using the CLI requires an API key and installation of a third-party package.

Mitigation: Review the pinned CLI package and source before installation, and use a revocable API key.
