## Description:

Guides creators in turning blog posts and other documents into narrated videos using dLazy.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Creators and marketing teams can ask an agent to turn a blog post or document into a narrated video. The supplied English instructions instead describe image generation, so the intended workflow needs confirmation before use.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and attached local files may be sent to dLazy services.

Mitigation: Share only content approved for this third-party service; avoid private or regulated documents unless that sharing is acceptable.

Risk: The listing says blog-to-video, the Chinese instructions use a broader file-to-video workflow, and the English instructions describe image generation.

Mitigation: Confirm the intended command and output with the publisher before running the skill or relying on its results.

Risk: Using the skill requires a locally stored API key and installation or execution of a third-party CLI.

Mitigation: Review the pinned CLI before installing it and protect or rotate the API key as appropriate.
