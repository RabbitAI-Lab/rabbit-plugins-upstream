# 常见问题与排错

按「看到什么 → 为什么 → 怎么做」组织。错误正文来自 CLI 或服务端的用户文案，直接照原文对照即可。

## 安装与登录

| 看到 | 原因 | 怎么做 |
| --- | --- | --- |
| `metadig: command not found` / 不是内部或外部命令 | 刚装完 PATH 未刷新，或安装脚本没跑完 | 重开终端；仍不行重跑安装脚本（`curl -fsSL https://waytometa.cn/cli/install.sh \| bash` 或 PowerShell `iwr https://waytometa.cn/cli/install.ps1 -useb \| iex`），二进制装在 `~/.metadig/`（Windows `%USERPROFILE%\.metadig\`），可先用绝对路径 `~/.metadig/metadig --version` 验证 |
| `尚未登录` | 本地没有凭证且没设 `METADIG_TOKEN` | `metadig login`；无浏览器环境见下 |
| `登录已过期或无效`（401） | 凭证约 30 天过期，或 `METADIG_TOKEN` 里是旧令牌 | `metadig login` 重新授权；检查是否有过期的 `METADIG_TOKEN` 在覆盖本地凭证 |
| `令牌无效或已过期` | `--token` 给的令牌不可用，CLI 已把它清掉 | 确认令牌来源；优先走 `metadig login` 浏览器授权 |
| `授权已过期或链接已被使用` / `等待授权超时` | 授权链接 10 分钟有效且一次性 | 重新 `metadig login` |
| 浏览器打不开 | 服务器 / 容器 / SSH 会话 | `metadig login --no-open` 打印链接，让用户在任何已登录设备上打开授权；或让用户提供令牌走 `METADIG_TOKEN` |
| 明明 `login` 成功却还是别的账号 / 401 | `METADIG_TOKEN` 环境变量优先级高于本地凭证 | `unset METADIG_TOKEN`（或确认它就是想用的令牌） |
| 连到了错误环境（本地 / 生产） | 凭证里记录了登录时的 `apiBase`，与 `--api-base` / `METADIG_API_BASE` 不一致 | 用同一基址重新 `login`；`metadig whoami` 会打印当前 API |

## 提交与等待

| 看到 | 原因 | 怎么做 |
| --- | --- | --- |
| `提交请求超时，结果不确定` | 提交请求 15 分钟未返回；任务**可能已受理并预扣积分** | 用提示里的 `metadig status <任务ID>` 查；确认 `FAILURE` / 查不到再重提。**不要**看到超时就重复提交 |
| `相同内容正在生成中，请稍候或稍作修改后重试` | 同项目、同参数的任务还在进行中（服务端去重） | 等它完成，或改一点参数 / 提示词；完成或失败后可原样重提 |
| `提交过于频繁，请稍后再试` / `操作过于频繁` | 未充值账号有每小时 / 每天生成次数限制；或短时间连点 | 停下来告诉用户，稍后再试；充值后限制解除 |
| `您的积分不足…` / `积分不足（含进行中的任务占用）…` | 余额扣掉在途任务的预留后不够本次估算 | 停止提交，提醒用户到网页充值或订阅；等在途任务完成也会释放预留 |
| `该模型为会员专属，开通会员后即可使用。` | 模型带 `plan-only` 标签，用户是免费档 | 换 `metadig models` 里非会员模型，或告知用户需订阅 |
| `该模型/渠道正在维护中…` | 后台临时下架 | 换模型或换 `--channel` |
| `模型 X 不支持<方式>` | `-m` 指定的模型不在该生成方式的目录里（如该模型不支持首尾帧） | 按错误里的可用清单换模型，或换生成方式 |
| `模型 X 当前已停用` | 目录里 `disabled: true` | 换模型 |
| `模型 X 不支持渠道 Y` | `--channel` 不在模型 `channels` 里 | 用错误里列出的渠道 |
| `--last 需要与 --first 搭配使用` | 只给了尾帧 | 补 `--first` |
| `--first/--last 与 --ref 系列不能同时使用` | 首帧模式与参考模式混用 | 二选一：首尾帧图走 `--first/--last`，人物 / 风格 / 视频参考走 `-r/--ref-video/--ref-audio` |
| stderr 警告 `比例 X 不在该模型档位…` / `分辨率…` / `时长…` | 显式值不在目录档位内，CLI 只提示不拦截 | 大概率服务端会拒绝或回落默认；改成 `metadig models <模型ID>` 列出的档位 |
| stderr 警告 `参考图 N 张超过该模型上限 M` | 参考素材超限 | 减到 M 张以内 |
| 任务 `FAILURE` 且 `detail` 有说明 | 生成失败（内容安全、素材不合规、上游异常等），**不扣积分** | 读 `detail`；换提示词 / 素材 / 模型再试，不要原样重提 |
| `等待超时（2 小时）` | CLI 等待硬上限 | 任务本身不受影响，稍后 `metadig status <任务ID>`；平台侧超时会自动失败退款 |
| 等了很久没动静 | 视频任务几分钟到十几分钟很正常；非 TTY 每 15 秒才打一行进度 | 看 stderr 的「预计约 N 分钟」；不要重复提交 |
| `任务提交未成功，请重新生成` | 任务在服务端没有落库（极少见） | 直接重新提交，不扣积分 |

## 素材与下载

| 看到 | 原因 | 怎么做 |
| --- | --- | --- |
| `文件不存在：…` / `不是文件：…` | 路径错误或是目录 | 用相对当前工作目录的正确路径；含空格的路径加引号 |
| `直传存储失败` | 对象存储直传两次失败且文件 >100MB 无法回退中转 | 压缩 / 裁短素材后重试 |
| `上传失败：…` | 中转上传被拒（类型或大小超出套餐上限） | 换格式或缩小文件；上传上限与网页端一致 |
| `任务尚未完成（当前：…）` | `download` 只能下载 `SUCCESS` 的任务 | 用 `metadig status <任务ID> --wait -o <目录>` 等完成后自动下载 |
| `任务没有可下载的产物` | 任务无产物 URL（文本类结果或异常） | 看 `status --json` 的 `text` / `detail` |
| `下载失败（HTTP 4xx/5xx）` | 产物 URL 暂时不可达 | 稍后重试 `metadig download <任务ID>` |

## 行为与预期不符

- **画布上没看到节点**：确认没有加 `--no-canvas`；产物归属看 `metadig project current`（可能落到别的项目）。`--json` 里没有 `nodeId` 表示未建节点（`--no-canvas` 或占位失败，产物仍在项目「历史文件」里）。
- **落到了「CLI 项目」而不是用户想要的画布**：用 `-p <项目ID>` 或在目录里 `metadig project use <项目ID>`；`metadig project list` 可查项目 ID。
- **出了 1 张而不是 `-n` 张**：部分模型固定单张出图，属预期；需要多张就多提交几次。
- **`history` 里看不到链接**：设计如此，`history` 只列记录，链接用 `status <任务ID>`。
- **`--json` 输出里混进了别的文字**：只解析 stdout；进度、警告都在 stderr。用 `2>/dev/null` 或分别捕获。
- **命令 / 参数在本机 CLI 不存在**：本地 CLI 版本旧，重跑安装脚本升级；不要改用内部接口绕过。
- **想连测试环境**：`metadig --api-base http://localhost:6603 <命令>` 或 `METADIG_API_BASE`；登录也要带同一基址。

## 安全提醒

- 授权链接只在用户自己的设备上打开；别人的授权链接一律不点。
- 令牌只放环境变量或 `~/.metadig/credentials.json`，不要写进代码、日志或对话记录。
- `metadig logout` 删除本地凭证；`METADIG_TOKEN` 需另行清除。
