## Description:

product video, product demo video, product ad video, product showcase — turn a product's photos or link into a polished demo / ad video. Use when the user wants a product demo, showcase, or ad video.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External users and ecommerce marketers use this skill to turn product listings, catalogs, specifications, manuals, or photos into conversion-oriented shopping and advertising videos, with multilingual voiceover and an optional virtual host.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Files attached to a request are uploaded to dLazy media storage.

Mitigation: Attach only materials you are authorized and comfortable sending to the service.

Risk: The API key and project context persist, and requests may consume organization credits.

Mitigation: Use an organization you intend to authorize, monitor credit use, and revoke the API key when it is no longer needed.
