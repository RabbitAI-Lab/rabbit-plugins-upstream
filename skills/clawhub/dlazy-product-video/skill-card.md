## Description:

Turns product photos, specifications, or listing links into product demo and advertising videos through dLazy's hosted service.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Sellers and marketers use this skill to request product showcase and advertising videos from product images, documents, or shopping links, with optional multilingual voiceover and a virtual host.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and attached files may be sent to dLazy's hosted service.

Mitigation: Review content before sharing and avoid uploading sensitive files unless approved.

Risk: Authentication can save an API key in local CLI configuration.

Mitigation: Use a per-invocation API key environment variable when local key storage is unsuitable.

Risk: Using the skill requires installing and trusting a third-party CLI.

Mitigation: Review the CLI and its published package before installing.
