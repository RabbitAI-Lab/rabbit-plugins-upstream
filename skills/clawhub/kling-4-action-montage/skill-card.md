## Description:

Guides agents to create fast-paced Kling 4 action montages from three or four key-frame images and a concise prompt.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

External creators and developers use this skill to turn reference stills and a concise prompt into a fast-paced Kling 4 action montage, then review and trim the usable sections.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The installer is unpinned and may change between releases.

Mitigation: Review the install source and verify the version before running it.

Risk: Reference images and prompts are sent to an external generation service.

Mitigation: Use only material approved for external sharing; avoid sensitive or confidential content unless sharing has been approved.
