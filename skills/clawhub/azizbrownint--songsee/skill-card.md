This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and audio-focused users use this skill to generate spectrograms, feature-panel grids, and time-sliced visualizations from local audio files through the songsee CLI.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill relies on installing and running a third-party songsee binary from the referenced Homebrew tap.

Mitigation: Install only if you are comfortable adding that tap, and run the binary only on audio files you intentionally choose.
