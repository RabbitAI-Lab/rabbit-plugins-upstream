# 人生之路 · Life Path

> 基于《论语·为政》孔子六阶段人生论的全维度智慧助手

子曰："吾十有五而志于学，三十而立，四十而不惑，五十而知天命，六十而耳顺，七十而从心所欲，不逾矩。"

## 简介

本技能以孔子六阶段人生论为核心框架，融合古今中外人生阶段理论（埃里克森八阶段、荣格人生阶段、马斯洛需求层次、黄帝内经），为用户提供：

- **六阶段深度解读** — 每阶段6层剖析（原文/译文/深度解读/现代启示/常见误解/实践建议）
- **人生阶段定位评估** — 交互式问答定位当前阶段，5维度评分
- **个性化行动指南** — 三层结构（立即行动→短期目标→阶段目标）
- **人生时间线可视化** — 交互式 HTML 报告，中式美学风格
- **经典金句查询** — 每阶段5句经典语录
- **古今中外理论对照** — 跨文化视角的人生阶段比较
- **人生反思引导** — 针对当前阶段的核心反思问题

## 设计理念

- **年龄是坐标，不是标准** — 以心理成熟度和修炼完成度为准，不以年龄生硬划分
- **每阶段有核心品质** — 志向 → 独立 → 通透 → 智慧 → 包容 → 自在
- **递进关系明确** — 先有方向才能立根基，有根基才能形成判断，有判断才能理解命运，理解命运才能包容，包容到极致才能自在
