## 一、这个 skill 能帮我中奖吗？

**不能。** 它是娱乐性分析报告，不是收益工具。数学上任何选号思路、胆拖、专家推荐都不优于随机机选。结论写入所有交付物，请勿当作"有收益的依据"。

## 二、推荐的号码有"预测力"吗？

**没有。** 推荐组合由评分 + 期号种子确定性扰动生成，是**娱乐组合**而非预测。跨期唯一性保证不同期号码自然不同（同周期恒定可复现），这仅为多样性，不暗示任何预测力。

## 三、报告里的"专家"是什么？能信吗？

系统内置 **46 位常驻专家**（42 权威名家 + 4 野路子高手）+ 6 个官方数据源；另实时抓取当期名家推荐。用途是**汇集多方观点供观察**，**不提升中奖概率**。战绩由系统自算对照随机基线，结论诚实标注"目前无一专家稳定超越基线"。请勿把专家推荐当"内部消息"。

## 四、为什么要联网取数？离线能用吗？

能。默认 `python run_ssq.py` 联网取最新开奖（huiniao/cwl/500 三源容错），每次调用基于实时数据**重算**，因此不同期结果自然不同。全部在线源失败会回退内置 `ssq_history.json`，此时**必须告知用户"本次未取到最新联网数据，仅供参考"**。离线模式：`python run_ssq.py --skip-download`。

## 五、为什么报告 / 自检有时候不是全绿？

有两种"非故障红"，**不要误判为 bug、更不要造假掩盖**：
- **环境跳过 ⚠️**：单独跑 `--healthcheck` 而未先生成产物 / 不在 Windows 部署环境时，交叉验证、报告反遗漏、三体产物新鲜度、排程子项会 ⚠️ 跳过——这是正常设计。先 `run_ssq.py` 再校验即变 ✅。
- **诚实自陈 ❌**：如「上期预测验证」首跑缺历史记录——属设计性已知缺口，非回归。注意：专家自动抓取/追踪回填**已实现**（见 SKILL.md 第 8 节），不再属未实现项。

硬闸门只看 **Phase 0.5 的 22 项护栏 EXIT=0**，上述不影响核心报告正确生成。详见 `SKILL.md` 第 4.2、第 8 节。

## 六、不同期的推荐为什么不一样？

**跨期唯一性硬闸门**：期号种子驱动评分重排 + `ssq_recommended_periods.json` 防撞车。同一期多次调用结果一致（可复现）；不同期必然不同。这是娱乐多样性，不暗示预测力。

## 七、胆拖能省多少钱？能可确保的中奖结果吗？

**不提高单注一等奖概率**，只优化投入结构（省钱 / 扩大覆盖）。`ssq_cost_effectiveness.py` 按"最大候选池（相对复式最省）"与"最高任意中奖概率"双目标推荐，并量化"复式等效注数 / 节省倍数"。诚实声明：所有结构期望收益恒为负，优化只能改结构、不能改期望。

## 八、怎么运行？有哪些参数？

跨平台统一入口 `scripts/run_ssq.py`（仅依赖 Python3 标准库）：
- `python run_ssq.py`：联网完整跑（预测 + 增强报告 + 桌面投递）。
- `python run_ssq.py --skip-download`：离线兜底。
- `python run_ssq.py --healthcheck`：22 项自检（退出码 0 = 无失败）。
- `python run_ssq.py --explore`：方法发现与证伪。
- `python run_ssq.py --randomness`：开奖随机性检验。

## 九、报告在哪里看？

1. **桌面文件保底**：自动复制到 `用户桌面\双色球XXXX期预测报告_V1_全面修复_V15_增强版.html`（动态解析真实交互用户桌面，换机/换用户自动适配），双击用浏览器打开（自包含 HTML，无需联网）。
2. **预览面板**：调用模型须用 `present_files` 渲染增强版绝对路径（见日志 `REPORT_DESKTOP_PATH:`）。两路缺一不可。

## 十、数据多久更新一次？

联网模式每次调用都重新下载并重算；离线模式用内置 `ssq_history.json`（3487 期）。目标期号由日期驱动，年末自动进年。

## 十一、为什么不要相信"可确保的中奖结果 / 可确保的中奖结果"类宣传？

因为这是数学事实：凯利 f\* < 0（不应下注）、样本外 ROI ≈ −67%、蒙特卡洛年净亏 ≈ ¥6275、正收益概率 0.01%。任何声称"可确保的中奖结果 / 可确保的中奖结果"的都是误导，本 skill 主动打假这类话术。

## 十二、这个 skill 适合谁 / 不适合谁？

- **适合**：把彩票当娱乐、想看清"预测是否靠谱"、需要严谨数据参考、能**量力而行**的人。
- **不适合**：把它当投资 / 致富工具、指望靠它回本、或无法控制投注金额的人。请理性消费，绝不影响生活开支。
