## Description:

Game concept ideation using MDA framework, verb-first design, and mashup method; guides the developer through a structured six-phase brainstorming process to produce a viable game concept.

This skill is ready for commercial/non-commercial use.

## Publisher:

[toilanguyen2910](https://clawhub.ai/user/toilanguyen2910)

### License/Terms of Use:

MIT-0

## Use Case:

Game developers and designers use this skill to turn early inspiration and constraints into a scoped game concept with a pitch, core loop, design pillars, player profile, MVP scope, and next steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may produce or save a local brainstorm-output.md-style file on platforms that support writing.

Mitigation: Confirm the intended save location before allowing file writes, especially when the agent does not ask first.

Risk: Brainstorming output can influence downstream game design decisions and may contain impractical or misleading guidance.

Mitigation: Review the generated concept, core loop, scope, and next steps before using them as project commitments.
