## 概览
本文档定义了用户提供的检验指导书模板的格式要求，用于指导智能体验证模板合规性并正确提取模板结构。

## Excel模板要求

### 基本要求
- 文件格式：`.xlsx` 或 `.xls`
- 表格位置：第一个工作表（Sheet）
- 表头位置：第一行或前几行中包含检验字段的行

### 必需字段
模板必须包含以下字段（字段名可变体，见字段映射规则）：
- 检验项目（或：检验项、项目）
- 检验方法（或：方法）
- 检验标准（或：标准）
- 检验频次（或：频次）

### 可选字段
模板可包含以下字段：
- 备注
- 检验工具
- 抽样方案
- 责任部门
- 其他自定义字段

### 模板示例

#### 示例1：标准格式
| 检验项目 | 检验方法 | 检验标准 | 检验频次 | 备注 |
|---------|---------|---------|---------|------|
|         |         |         |         |      |

#### 示例2：扩展格式
| 序号 | 检验项目 | 检验方法 | 检验标准 | 检验工具 | 检验频次 | 责任部门 | 备注 |
|-----|---------|---------|---------|---------|---------|---------|------|
|     |         |         |         |         |         |         |      |

#### 示例3：带表头行
```
XX公司检验指导书
产品名称：          产品型号：          文件编号：
版本：              生效日期：          
================================================================
检验项目    检验方法    检验标准    检验频次    备注
```

### 格式建议
- 表头应清晰可识别，避免合并单元格
- 如有标题行，表头应在前10行内
- 字段名建议使用标准命名，便于自动识别

## Word模板要求

### 基本要求
- 文件格式：`.docx`
- 表格位置：文档中的第一个表格
- 表头位置：表格的第一行

### 必需字段
与Excel模板相同，必须包含检验项目、检验方法、检验标准、检验频次四个字段。

### 模板示例

#### 示例：标准表格格式
```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│ 检验项目 │ 检验方法 │ 检验标准 │ 检验频次 │   备注   │
├──────────┼──────────┼──────────┼──────────┼──────────┤
│          │          │          │          │          │
└──────────┴──────────┴──────────┴──────────┴──────────┘
```

### 格式建议
- 使用标准表格，避免嵌套表格
- 表头应在第一行
- 避免在表格前有大量文本干扰识别

## 字段映射规则

### 标准字段映射表

| 标准字段名 | 可识别的变体 | 映射到字段 |
|-----------|-------------|-----------|
| 检验项目 | 检验项、项目、检验内容 | item |
| 检验方法 | 方法、检测方法、测试方法 | method |
| 检验标准 | 标准、技术标准、判定标准 | standard |
| 检验频次 | 频次、检测频次、抽检比例 | frequency |
| 备注 | 备注、说明、备注说明 | remark |
| 检验工具 | 工具、检测工具、检测设备 | tool |
| 抽样方案 | 抽样、抽样方法 | sampling |
| 责任部门 | 部门、责任单位 | department |

### 模糊匹配规则
当字段名不是标准名称时，脚本会尝试模糊匹配：
- 字段名包含标准名称 → 自动映射
- 字段名被标准名称包含 → 自动映射
- 无法匹配 → 保留原字段名，不填充数据

### 示例
- "外观检验项目" → 包含"检验项目" → 映射到 item
- "检验方法说明" → 包含"检验方法" → 映射到 method
- "检测标准" → 包含"标准" → 映射到 standard

## 模板验证

### 验证流程
当用户提供模板时，智能体应执行以下验证：

1. **文件格式验证**
   - 检查文件扩展名是否为 `.xlsx`、`.xls` 或 `.docx`
   - 如格式不支持，提示用户并提供支持的格式列表

2. **表格存在性验证**
   - Excel：检查是否有工作表
   - Word：检查是否包含表格

3. **表头识别验证**
   - 尝试提取表头字段
   - 检查是否包含必需字段

4. **必需字段验证**
   - 检查表头是否包含检验项目、检验方法、检验标准、检验频次（或其变体）
   - 如缺少必需字段，提示用户具体缺少的字段

### 验证结果处理

#### 验证通过
- 提示用户：模板验证通过，将使用您提供的模板生成检验指导书
- 记录模板的字段映射关系

#### 验证失败
- 提示用户具体问题：
  - "模板缺少必需字段：检验标准"
  - "无法识别Word模板中的表格结构"
  - "模板格式不支持，请提供Excel(.xlsx)或Word(.docx)格式"
- 询问用户：是否使用通用格式生成？

## 常见问题

### Q1：模板有多个工作表，使用哪个？
A：默认使用第一个工作表。如需使用其他工作表，建议单独提供。

### Q2：模板有合并单元格，能否识别？
A：表头行的合并单元格可能影响识别。建议取消合并或使用标准格式。

### Q3：模板字段名与标准不同，能否使用？
A：可以。脚本支持字段名模糊匹配，只要包含标准字段名的关键字即可。

### Q4：模板中有额外的公司信息行，是否影响？
A：不影响。脚本会在前10行内查找表头行。

### Q5：Word模板中表格前有文字说明，能否识别？
A：可以。脚本会提取文档中的第一个表格作为模板。

### Q6：模板只有三个必填字段，能否使用？
A：不能。模板必须包含四个必填字段（检验项目、检验方法、检验标准、检验频次），缺少任何一个都会提示用户。

### Q7：能否使用PDF格式的模板？
A：不支持。当前仅支持Excel和Word格式的模板。建议将PDF模板转换为Excel格式。

## 模板使用建议

### 对用户的建议
1. 使用Excel模板更稳定，推荐优先使用
2. 表头字段名尽量使用标准名称
3. 避免复杂的表格结构和合并单元格
4. 如有特殊字段，可在备注中说明

### 对智能体的建议
1. 用户上传模板后，立即验证并反馈结果
2. 验证失败时，明确告知问题并提供建议
3. 不要假设模板可用，必须经过验证
4. 保留模板验证的详细日志，便于问题排查
