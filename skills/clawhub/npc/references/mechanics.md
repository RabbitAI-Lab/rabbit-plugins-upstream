# 机制：七轴 · 九型 · 判定

## 一、七轴（方向统一：读数越高 = 越像 NPC）

| # | 轴 | 测什么 | 高分意味着 |
|---|---|---|---|
| 1 | `script` **台词** | 你说的话有多少是重复的 | 话语系统已被格式化 |
| 2 | `route` **路线** | 日程的可预测程度 | 你不是在过日子，是在巡逻 |
| 3 | `goal` **目标** | 你的目标里有多少是自己定的 | 任务系统在你之外 |
| 4 | `voice` **表达** | 说不出「没被要求的话」的程度 | 深度交互端口长期关闭 |
| 5 | `echo` **回声** | 说出来之后，有没有作用 | 通道畅通，反馈回路是断的 |
| 6 | `reset` **重置** | 下班时有多少进度被清零 | 你在循环里 |
| 7 | `serve` **服务** | 你的产出服务于谁的 KPI | 你是「为玩家服务」的 |

### `echo` 轴是怎么来的（不要删掉这段）

**第一版方案只有六轴，`voice` 和 `echo` 是一条。** 把它拆成两条，来自 Dora 自己的答案（2026-09-21）：

> 「我每天都在脱口而出，及时发泄，从不内耗。」

这句话意味着她的 `voice` 是**低的**（表达通畅、不积压）。但她依然觉得自己像 NPC。

**所以断裂不在「说不出」，在「说了没用」。** 这是两种完全不同的困境：

| | 说出来了吗 | 有作用吗 | 处境 |
|---|---|---|---|
| 隐藏 NPC / 路人甲 | ❌ 说不出 | — | 端口关闭 |
| **公告员** | ✅ 说了 | ❌ 没人接 | **端口开着，对面没人** |

后者更隐蔽——**因为它看起来完全正常**。这个人每天在说话、在表达、情绪很健康，所以没有人（包括他自己）会认为他出了问题。

「这不重要」「没有意义」这两句口头禅，就是长期零回声之后的**自我降级**：先把话降级，再说出去，这样被忽略的时候就不疼了。

`echo` 轴测的就是这件事。**它是这个 Skill 里最有价值的一条轴，也是最容易做丢的一条。改题库时优先保它。**

## 二、九型索引

| key | 类型 | 姿态 | 特征轴（`disc`） | 一句话 |
|---|---|---|---|---|
| `bystander` | 路人甲 | 待机 | route↑ voice↑ serve↓ | 你不是没参与剧情，你是这条街本身 |
| `board` | 告示板 | 巡回 | serve↑ script↑ voice↓ | 所有人都从你这里领任务，包括你自己 |
| `smith` | 铁匠 | 值守 | serve↑ route↑ | 活越干越多，然后你变成了一个产能黑洞 |
| `guard` | 守卫 | 值守 | script↑ echo↑ | 事故从来没发生过，所以没人相信事故会来 |
| `tavern` | 酒馆老板 | 后台运行 | script↓ voice↓ | 整个世界的传闻都从你这里过，除了你自己的 |
| `healer` | 治疗师 | 巡回 | serve↑ reset↑ | 你把所有人都加满了，除了你自己那条 |
| `hidden` | 隐藏 NPC | 待机 | voice↑ goal↑ | 你是这张地图的前代主角，触发条件一直没到 |
| `portal` | 传送点 | 巡回 | route↓ serve↑ | 所有人都从你这里去了别的地方 |
| `herald` | 公告员 | 后台运行 | echo↑ voice↓ | 你什么都说出来了，只是没有人在听 |
| `not_npc` | 你不是 NPC | 在线 | 稀有解（见下） | 这张卡很少出 |

完整档案（位置价值 / 卡点 / 判词 / 支线）在 `data/types.json`——**改文案只改那里**，这里不重复存正文。

### 两条不能破的设计原则

**① 先写「这个位置的价值」，再写卡点。顺序不能颠倒。**

九个类型全部是真实需要的位置，不是九种毛病。守卫是唯一在承担「什么都没发生」的人；治疗师是团队的血液循环系统；酒馆老板掌握着三年的组织记忆。

**如果判词把某个类型写成贬义，这个 Skill 就变成了一次集体嘲笑**——用户笑完会有轻微羞耻感，不会转发。

**② 用游戏原型名，不用岗位名。**

「你是铁匠」比「你是技术骨干」有意思，而且不得罪任何具体岗位。这也是 Dora 定的：世界观架空，规避现实映射风险。

## 三、判定流程

```
答案串 → 七轴 raw → 按锚点归一化(0-100) → 判型 → 浓度 → 坐标
```

### 第 1 步：稀有解优先

```python
if goal < 35 and voice < 35 and echo < 50:
    return not_npc        # 你不是 NPC
```

**必须最先判。** 它要求三轴同时低，条件极严，放后面会被普通类型抢走。

稀有解的存在价值：**只有存在「否」的可能，「是」才可信。** 实际占比 5.7%；audit 里设了上限告警（>6% 会 warn）。

### 第 2 步：特征轴判别

```python
score_t = mean( sign_k × z_k  for k in t.disc )
取 score 最高的类型
```

- `z_k` = 该轴相对全样本的 z-score（均值、标准差在 `--calibrate` 时算好，写在 `meta.calibration.stats`）
- `t.disc` = 该型 2–3 条特征轴，`+1` 越高越像，`-1` 越低越像

**为什么用「平均」而不是「加权和」**（踩过的坑，别改回去）：

加权和会让负权重型在低分端累积出虚假优势。实测中「酒馆老板」一度吃掉 34% 的样本——因为它同时有 `script -3 / voice -3 / serve -2` 三条负权重，**任何「什么都低」的人都会被它的负分吸走**。改用平均后回到 12%。

同理，**为什么不用欧氏距离**：题库里的选项是「抱团」的（一组自主动机强的选项会同时让多个轴变低），签名在空间里的实际分布和拍脑袋设的期望值对不上，导致中间型签名吞掉整片区域。实测隐藏 NPC 一度占 33%。

**两个方案都试过、都不行，才换到特征轴判别。** 如果将来分布又歪了，先调 `disc` 的特征轴，不要改判定算法。

### 第 3 步：浓度

```python
concentration = 0.6 × 七轴平均 + 0.4 × 最高轴
```

纯平均会稀释「只有一条轴极度严重」的情况——**公告员就是这种**。她的七轴里只有 `echo` 是 100，其余都很低，纯平均只有 25%，看起来像「你只有 25% 像 NPC」，完全失真。加权后 55%，符合直觉。

### 第 4 步：坐标（社交钩子的载体）

```python
crc = CRC32(答案串的 UTF-8 字节)          # 必须用字节，不能用 UTF-16 码元
zone = zones[crc % 25]                     # 东/南/西/北/中 × 一~五区
num  = crc % 10000 + 1                     # 第 N 号刷新点
姿态  = 类型自带的 stance（值守/待机/巡回/后台运行/在线）
```

坐标行示例：`东三区 · 第 0417 号刷新点 · 值守`

**确定性生成**：同样的答案永远得到同一个坐标。这条是硬要求——否则双人对照、二次测试全都不可复现。

## 四、达标线（`--calibrate` 后应落在这个范围）

| 指标 | 达标 | 当前实测 |
|---|---|---|
| 九型可达性 | 全部 > 0 | ✅ 全可达 |
| 单型占比 | 4% – 17% | ✅ 4.4% – 15.5% |
| 稀有解占比 | 3% – 6% | ✅ 5.7% |
| 七轴锚点 | P95 − P5 ≥ 4 | ✅ 最小 route（1→6） |
| 卡片宽度 | ≤ 54 列 | ✅ 53 |
| 禁词 | 0 命中 | ✅ 0 |

## 五、改数据后的完整流程（顺序不能颠倒）

```bash
# 1. 改题库或类型定义（data/questions.json / data/types.json）
# 2. 重新校准锚点 + stats，并看九型分布
python -X utf8 scripts/npc.py --calibrate
#    分布歪了 → 调 types.json 的 disc 特征轴，回到第 2 步
# 3. 门禁
python -X utf8 scripts/npc.py --audit
python -X utf8 scripts/npc.py --selftest
# 4. 重新生成单文件点选页（必须，页面里的锚点是构建时嵌进去的）
python -X utf8 scripts/build_quiz_html.py --out npc-demo.html
# 5. JS 与 Python 引擎对拍
python -X utf8 scripts/build_quiz_html.py --verify
```

**第 4 步最容易漏。** 页面的 `calibration` 是构建时写死的，改了锚点不重新生成，页面和命令行会给出不同结果。
