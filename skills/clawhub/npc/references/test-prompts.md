# 回归用例

改数据之后把下面跑一遍。**看分布不够，必须读卡片。** 分布正常但判词难看的组合是完全可能的。

---

## A. 出题

- [ ] `--questions` → 12 题全出，题干无错别字，每题 3–4 个选项
- [ ] `[系统]` 开场白四条完整，末尾有「格式随意」的说明
- [ ] 一屏内可读，不被终端截断

---

## B. 解析容错（`--selftest` 已覆盖，人工再抽验一次）

| 输入 | 期望 |
|---|---|
| `ABCDABCDABCD` | 12 |
| `1A 2B 3C 4D 5A 6B 7C 8D 9A 10B 11C 12D` | 12 |
| `A，B、C D\nA B C D A B C D` | 12 |
| `Ａ　Ｂ　Ｃ`（全角） | 3 |
| `1.D 2、A 3）C` | 3 |
| `ABZQ1!@#` | 2（只留合法字母） |
| 空串 | 0 + 退出码 2 |

---

## C. 出卡（九型各跑一例，人工读）

**这是最重要的一节。** `--calibrate` 告诉你分布对不对，告诉不了你卡片难不难看。

每型读一遍，自问三个问题：

1. **这一段有没有「冷 → 翻 → 温」？** 还是三段都在温（那就成鸡汤了）？
2. **有没有出现禁词？** 有的词你写的时候不觉得，读的时候会刺眼。
3. **「位置价值」那段有没有被写成贬低？** 守卫、治疗师、路人甲最容易写偏。

各型的参考触发答案（用于快速复现某一型）：

| 型 | 关键选项 |
|---|---|
| 公告员 | q5C + q10C + q11C（回声拉满，其余压低） |
| 铁匠 | q1C + q2A + q3B + q6B + q8C（服务 + 路线双高） |
| 路人甲 | q1A + q3A + q4C + q6A（台词 / 路线高，服务低） |
| 守卫 | q1B + q2A + q4B + q9D（台词最固定） |
| 治疗师 | q1A + q3C + q6C + q12B（服务 + 重置） |
| 传送点 | q3D + q8C + q12B（路线低 + 服务高） |
| 告示板 | q1B + q2A + q3C（服务 + 台词高，表达低） |
| 酒馆老板 | q1D + q4A + q9A（表达低 + 台词低） |
| 隐藏 NPC | q4C + q7D + q12C（表达高 + 目标高） |
| 你不是 NPC | q2C + q6D + q7A + q8D + q11D + q12D |

> 表里的组合只用于快速跳到某一型，不是「标准答案」。跑完记得回读卡片。

---

## D. 出口协议

构造一份 **浓度 ≥ 78 且回声 ≥ 65** 的答案，确认：

- [ ] 出口段落出现
- [ ] 出口段落里**没有任何**比喻、数字游戏、世界观包装
- [ ] 出口在卡片最底部，在免责声明之后

反例检查：构造一份高浓度但回声低的答案，确认出口**不**出现（避免保险丝误触发）。

---

## E. 边界

| 用例 | 期望 |
|---|---|
| 12 题全选 A | 出一个合理类型，**不该**是稀有解 |
| 全选「反 NPC」选项 | 应该出稀有解「你不是 NPC」 |
| 只答 3 题 | 补齐 + 末尾注记，不追问 |
| 完全无合法答案 | 退出码 2，明确提示 |
| 同一答案跑两次 | 卡片逐字节一致（确定性） |
| 同一答案在 HTML 页和命令行 | 结果完全一致（`--verify` 覆盖） |

---

## F. 卡片观感

- [ ] 宽度 ≤ 54 列，手机上不用横滚
- [ ] 折行处标点不在行首
- [ ] 数字没被折到行首（「接近 0」的 0）
- [ ] 参数面板的条形在等宽字体下对齐
- [ ] 复制出来的纯文本卡在微信里排版不乱

---

## G. 整体手感（最后一关，也最主观）

把卡片发给一个人看，观察第一反应。

- 如果对方**先笑，然后沉默两秒**——调性对了。
- 如果对方**先说「好准」，然后马上想转发**——传播性对了。
- 如果对方**说「挺有道理」然后没有下文**——判词太软了，回去加冷和翻。
- 如果对方**有点不舒服**——检查是不是把位置写成了贬义，或者出口协议漏了。
