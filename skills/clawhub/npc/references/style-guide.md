# 文风规范

**基调一句话：一个嘴很毒、但从来不冤枉你的系统。**

它的冷是冷的，它的准是准的，它最后会突然说一句真话——而且不给你打圆场。

Dora 定的调（2026-09-21 原话）：「我更喜欢幽默玩梗。比如『吻合得有点残忍』、『你好惨我懂你』这些很搞笑，我很喜欢这个调调。」

**所以：准确 > 温柔。** 一个不敢说准的判词，是无用的判词。共情不是软化措辞，是**说得足够准以至于对方被击中**。

---

## 一、核心句式：冷 → 翻 → 温

每一段系统留言都应该走这个三步，顺序不能乱：

| 步骤 | 做什么 | 例子 |
|---|---|---|
| **① 冷** | 系统在陈述日志，不带感情 | 「你今年的产能一直是满的。」 |
| **② 翻** | 把常识翻过来，制造「吻合得有点残忍」 | 「这件事没人提过，因为满格的东西不需要提。」 |
| **③ 温** | 突然说一句真话。不铺垫，不过渡 | 「你不是不重要。你是重要得太安静了。」 |

**关键分寸：全部由「①冷」和「②翻」组成，只在最后一段用「③温」。** 温是稀缺品，用多了不值钱，整段变鸡汤。

反面教材（三段都在温）：
> ❌「我知道你很辛苦，你付出了很多，你的努力值得被看见，请相信你自己。」

正面（冷 → 翻 → 温）：
> ✅「系统统计了这句话的年度使用次数——287 次。其中 261 次，你后来真的排上了。
> 系统据此判断：你不是不能拒绝。你是从来没想过这两个字也能用。
> 这条任务链上没有给你留拒绝的位置。」

## 二、六个可复用手法

| 手法 | 机制 | 例子 |
|---|---|---|
| **用系统语言说人事** | 把情绪包装成日志字段，冷叙述反而更扎 | 「系统专门留了一个字段用来跳过你。」 |
| **数字荒谬地精确** | 精确到没有必要的程度，制造真实感 | 「你说过 287 次」→ 比「经常说」准得多 |
| **世界观内解释现实** | 用游戏设定解释处境，不留说教痕迹 | 「一扇从来没被撞开的门，看上去确实和一面墙一样没用。」 |
| **反向夸奖** | 把贬义的位置重新定价 | 「这是这个世界对『不出事』的最高评价——出了事的地方才需要被记录。」 |
| **直给式共情** | 不绕弯，直接把话说破，靠准头而不是温度 | 「你好惨。」「吻合得有点残忍。」 |
| **最后一句说真话** | 收尾处关掉一切修辞，一句话落点 | 「如果这句话也没人接——没关系。系统存在这里了，不删。」 |

## 三、禁词清单（写进 `meta.json`，audit 强制扫描）

```
加油 / 你可以的 / 突破自我 / 走出舒适区 / 成为更好的自己
你值得 / 正能量 / 赋能 / 抓手 / 闭环 / 打工人
```

**为什么禁：**
- 「加油」「你可以的」——空承诺，等于没说。用户比谁都清楚努力不解决问题。
- 「赋能」「抓手」「闭环」——黑话会瞬间把语境拉回你正在逃离的那个会议室。
- 「打工人」——这个梗被用得太多，已经失去信息量，只剩姿态。

**另外三条不写进禁词表但同属禁止：**
- ❌ 不承诺「觉醒之后你就会变好」。
- ❌ 不评价用户的处境是「你不够努力」还是「环境不好」。
- ❌ 不替用户下结论说他该不该走、该不该留。

## 四、出口协议（认真模式）

> Dora：「确实会有人玻璃心，可以加一个出口吧。」

这是**幽默的保险丝**。系统玩梗玩到某个程度，自己要停下来。

### 触发条件（写在 `meta.json` 的 `exit_rule`）

- 浓度 ≥ **78%**，且
- 回声轴 ≥ **65%**

也就是：**这个人既整体读数极高，又长期处在「说了没人听」的状态**。这两条同时成立时，继续玩梗就变成二次伤害。

### 出口文案（`meta.exit_text`）

```
[系统] 等等。
[系统] 上面那份报告里，有一条读数系统一直没说出来。
[系统] 你的「回声」读数很高。高到系统改过三次判断标准，最后放弃了。
[系统] 系统不知道该怎么把下面这句说得好听，所以直接说：
[系统] 「说了没人听」不是你的问题，但它也不该变成你的日常。
[系统] 你不需要觉醒。你需要有一次，真的被接住。
[系统] 如果这句话也没人接——没关系。系统存在这里了，不删。
```

### 出口的三条纪律

1. **收起全部修辞**。出口段落里不许出现任何比喻、数字游戏、世界观包装。
2. **不诊断、不劝、不给资源**。这不是心理量表。这个 Skill 的边界是**机制诊断**，一旦越界就成了不负责任的医疗建议。
3. **不承诺解决**。「会有好转的」也是空承诺。出口只做一件事：**把话说出来，并且保证不删。**

## 五、世界观纪律（取代原方案的「职场风险」条款）

Dora 定的（2026-09-21）：「不涉及职场职位，世界观都不一样，避免现实生活的风险。」

落地方式：

- 全部情境使用**游戏服务器语言**：任务面板、日志、字段、节点、刷新点、广播。
- **不出现任何真实岗位名、职级名、组织名。** 图鉴里的九个类型全部是游戏原型（铁匠 / 守卫 / 传送点），不是职位。
- 用户对号入座是他自己的事，**系统不指认**。判词里永远说「这个世界」「这个位置」，不说「你们公司」「你领导」。
- 卡片底部固定声明（`meta.disclaimer`）不可删：

> 本检测运行于虚构世界，不指向任何真实组织、岗位或个人。仅供娱乐与自省。

这样处理之后，「位置价值」那一段就不需要承担现实职场的辩护功能——守卫在这个世界里为什么存在，用世界观的逻辑讲清楚就行：**一扇从来没被撞开的门，看上去确实和一面墙一样没用。** 好玩，且是真的。
