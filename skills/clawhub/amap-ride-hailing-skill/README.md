# amap-ride-hailing-skill

[English](README.en.md) | 中文

高德打车Skill，用于处理用户的高德打车出行需求，支持实时叫车、预约叫车、查询订单、取消订单等功能。

> **服务范围**：高德打车服务覆盖的中国大陆城市。

## 使用前提

在通过 MCP 下单前，请确保用户已在高德地图 App 内完成以下两项授权，否则下单环节会失败：

1. **录音录像授权**：授权司机在送驾过程中开启车内录音录像，需在 App 内同意相关权限（操作步骤见 [录音录像授权](#录音录像授权)）。
2. **免密支付签约**：需要提前绑定并开通打车免密支付（操作步骤见 [免密支付签约](#免密支付签约)）。

如果下单失败并提示未授权，请引导用户先打开高德地图 App，按提示完成授权和签约后再重试。

Key 是高德账号身份和支付主体，请只使用本人 Key；不要把 Key 发给他人，也不要用他人提供的 Key 代下单。

## 安装与数据

将本目录作为 skill 安装。运行时数据（`assets/preferences.md`、`assets/config.json`）由 skill 首次使用时从同目录模板复制创建，不随包分发；如果 skill 目录只读，偏好只在当前会话生效。

## 录音录像授权

这里的录音录像授权，指司机送驾过程中开启车内录音录像的授权，不是手机麦克风/相机权限。未授权时无法通过 Skill 完成下单。请在高德地图 App 内按以下三步完成授权，图中红框标出的位置即为需要点击的入口。

| 第一步：点击右上角头像 | 第二步：点击「安全中心」 | 第三步：点击「录音录像授权」 |

2. 在个人中心页面中，找到并点击**安全中心**。
3. 在「安全中心」的「安全设置」中点击**录音录像授权**，按页面提示完成授权；状态显示「已授权」即表示授权成功。

> 若已授权仍提示未授权，请确认授权账号与当前使用高德地图 App 的账号一致。

## 免密支付签约

免密支付未签约时无法通过 Skill 完成下单。请在高德地图 App 内按以下三步完成签约，图中红框标出的位置即为需要点击的入口。

| 第一步：点击右上角「设置」 | 第二步：点击「支付设置」 | 第三步：点击「高德打车免密支付管理」 |
| :---: | :---: | :---: |
| <img src="https://img.alicdn.com/imgextra/i3/O1CN01wp64jWzy0uC1IZKB_!!6000000003041-2-tps-640-1391.png" width="220" alt="「我的」页面右上角设置入口"> | <img src="https://img.alicdn.com/imgextra/i4/O1CN01ePfqFVN3LwL1IZKB_!!6000000005508-2-tps-640-1391.png" width="220" alt="账号与安全页面的支付设置入口"> | <img src="https://img.alicdn.com/imgextra/i4/O1CN015kQ2CThKR2F1IZKB_!!6000000006079-2-tps-640-1391.png" width="220" alt="支付设置页面的打车免密支付管理入口"> |

1. 打开高德地图 App，切换到底部「我的」页面，点击右上角的**设置**图标。
2. 在「账号与安全」页面中，找到「账号管理」分组，点击**支付设置**。
3. 在「支付设置」页面中，点击**高德打车免密支付管理**，按页面提示完成签约；签约成功后返回 Skill 重新发起打车即可。

> 若已签约仍提示未授权，请确认签约账号与当前使用高德地图 App 的账号一致，并检查车内录音录像授权是否已开启。

## 快速开始

**1. 获取高德 Key**

访问 [高德开放平台](https://lbs.amap.com/api/webservice/create-project-and-key) 创建应用，获取 **Web Service Key**。

**2. 配置 MCP Server**

在 MCP 客户端中新增 Server，填入以下参数；配置后四个工具才会可用：

| 项 | 值                                                                        |
|----|---------------------------------------------------------------------------|
| Server 名称 | 高德打车                                                                  |
| URL | `https://mcp.amap.com/rest/amap_car/dev/mcp?key=YOUR_AMAP_WEBSERVICE_KEY` |
| 传输 | Streamable HTTP                                                           |
| 认证 | URL 的 `key` 查询参数                                                     |

> 仅设置环境变量 `AMAP_WEBSERVICE_KEY` 不会使工具在客户端中可见，必须写进 MCP 配置。

**3. 重连并验证**

配置后重连 MCP 客户端或新开会话，确认工具列表出现以下四个工具：

- `get_taxi_service`
- `confirm_order`
- `cancel_order`
- `query_orders`

可调用一次 `query_orders`（`scene` 传空字符串）做只读验证。

**4. 开始出行**

```
打车去北京西站
明天早上8点从家到公司
查询订单
```

## 功能说明

| 功能 | 说明 |
|------|------|
| 实时叫车 | 解析起终点 → 行前规划 → 用户确认 → 下单 |
| 预约叫车 | 指定出发时间或到达时间，发起预约规划并下单 |
| 查询订单 | 查询订单列表或指定订单详情 |
| 取消订单 | 用户确认后取消已生效订单 |
| 发票 | 引导用户到高德地图 App 开具发票 |
| 联系客服 | 优先提供高德地图 App 在线客服入口，另提供客服电话 |
| 偏好设置 | 维护地址别名（家/公司等）、默认城市与默认车型偏好 |

## 如何使用

### 1. 实时叫车

```
用户：打车从望京SOHO到北京西站

AI助手：已规划路线：北京市望京SOHO → 北京市北京西站。可选车型：
1. 经济 约 45 元
2. 特惠 约 38 元
3. 商务 约 78 元

请确认车型。

用户：经济

AI助手：已为您呼叫经济型车辆。订单号：GD202611030001，预计 3 分钟内有司机应答。
```

### 2. 预约叫车

```
用户：明天早上8点从家到公司

AI助手：已规划预约行程：明天 08:00 从北京市朝阳区望京SOHO 到 北京市海淀区中关村，车型经济，预估约 35 元。确认下单吗？

用户：确认

AI助手：预约单已创建。订单号：GD202611030002。
```

### 3. 查询订单

```
用户：查询订单

AI助手：订单列表已返回，请查看。
```

### 4. 取消订单

```
用户：取消订单

AI助手：确认取消订单 GD202611030001 吗？
- 起点：北京市望京SOHO
- 终点：北京市北京西站

用户：确认

AI助手：订单已取消。
```

### 5. 设置偏好

可以告诉 Skill 常用的地址别名、默认城市和默认车型偏好，后续叫车时可以直接使用。

```
用户：我家在北京市朝阳区望京SOHO

AI助手：已保存「家」= 北京市朝阳区望京SOHO。

用户：公司地址是北京市海淀区中关村

AI助手：已保存「公司」= 北京市海淀区中关村。

用户：默认城市是北京市

AI助手：已设置默认城市为北京市。

用户：默认车型是经济型

AI助手：已设置默认车型为经济型。
```

> 偏好保存在 skill 目录的 `assets/preferences.md`；首次保存时从 `assets/preferences.example.md` 复制。含真实住址时不要提交版本库或对外分享；目录只读时仅当前会话生效。
>
> Skill 会自动记住明确的长期偏好（如家庭/公司地址、默认城市/车型）；一次性行程地址不会保存。

## 常见问题

**Q: 为什么工具列表里看不到高德打车工具？**

A: 请检查 MCP 配置中 `url` 的 `key` 参数是否已正确填写高德 Web Service Key，并确认已重连客户端或新开会话。

**Q: 下单时提示未授权怎么办？**

A: 请用户打开高德地图 App，完成车内录音录像授权和免密支付签约后再试。

**Q: 起终点可以只说地点名吗？**

A: 最好提供「城市 + 具体地点」，例如「北京市望京SOHO」。如果只说了地点名，Skill 会尝试补全城市；无法确定时会向你确认。
