# 用户偏好模板

> 模板：`preferences.example.md`；运行时数据：同目录的 `preferences.md`。不要把真实地址写进模板。
> 用户数据文件可能包含真实住址，不要提交版本库或对外分享；复制或写入失败时，偏好只在当前会话生效。
> 空值表示未设置。
