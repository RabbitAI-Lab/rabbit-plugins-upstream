# 高德打车 MCP 工具契约

本文只写工具参数契约与返回场景。

本文覆盖行前规划、确认下单/取消和查询订单；`confirm_order` 处理创建或取消确认。

## 1. get_taxi_service（行前规划）

新建或更新行前打车规划，包括选点、再来一单与返程。

| 参数名 | 类型 | 必填 | 说明                                                                                                                                                                                                    |
|--------|------|------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `destination` | string | ✅ | 目的地，**具体地点**，如"天安门"、"北京西站"                                                                                                                                                            |
| `origin` | string | ✅ | 出发地，**具体地点**，如"望京SOHO"                                                                                                                                                                      |
| `origin_city` | string | ✅ | 出发地所在城市，必传。使用行政区全称，如"北京市"、"上海市"，不接受"北京""上海"等简称；与目的地在同一城市时，两个城市填同一个全称；无法确定时先向用户确认，不得留空或猜测                                |
| `destination_city` | string | ✅ | 目的地所在城市，必传。使用行政区全称，如"北京市"、"上海市"，不接受"北京""上海"等简称；与出发地在同一城市时，两个城市填同一个全称；无法确定时先向用户确认，不得留空或猜测                                |
| `departure_time` | string | | 出发时间，`yyyy-MM-dd HH:mm`；即时用车或未指定时填空字符串；与非空 `arrival_time` 互斥                                                                                                                  |
| `arrival_time` | string | | 到达时间，`yyyy-MM-dd HH:mm`；未指定时填空字符串；与非空 `departure_time` 互斥                                                                                                                          |
| `vehicle_type` | string[] | | 车型需求。仅允许：经济、优享、商务、豪华、专车、特惠、出租车、无人车、顺风车、拼车、接机单、送机单、代驾、秒送跑腿、包车；排除项在枚举前加 `"不要"`（如 `["不要特惠"]`）；只传上述枚举值。无要求为 `[]` |
| `vehicle_brands` | string[] | | 汽车品牌或品牌型号需求，非枚举值（如 `["宝马5系", "不要某品牌"]`）。无品牌偏好为 `[]`                                                                                                                   |
| `price_range` | string[] | | 价格区间（元），固定两个元素 `["最小价格", "最大价格"]`，字符串数字；无要求为 `["", ""]`                                                                                                                |
| `price_reference` | string | | 价格偏好；无要求为空字符串                                                                                                                                                                              |
| `power_source` | string | | 能源偏好。仅允许：油车、电车；无要求为空字符串                                                                                                                                                          |
| `vehicle_body` | string[] | | 车身偏好。仅允许：MPV、SUV；无要求为 `[]`                                                                                                                                                               |
| `incar_environment` | string[] | | 车内环境要求。仅允许：空气清新；无要求为 `[]`                                                                                                                                                           |
| `driver_requirements` | string[] | | 司机要求。仅允许：驾驶平稳、服务好、保持车内安静、提前开窗通风、不要打电话；无要求为 `[]`                                                                                                               |
| `route_requirements` | string[] | | 路线要求。仅允许：不走高速、拥堵少、最快、最便宜；无要求为 `[]`                                                                                                                                         |
| `waypoints` | string[] | | 途经点列表，按途经顺序排列，每项为明确的 POI 名称；无要求为 `[]`                                                                                                                                        |
| `businessData` | string | | 场景上下文。首次规划、改车型或改其他条件后重新规划、再来一单、返程填空字符串；仅用户选点后的再次规划传选点场景原值                                                                                      |

## 2. confirm_order（确认订单）

确认创建或取消操作。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `businessData` | string | ✅ | 用户本轮明确确认的目标订单及操作所对应的有效待确认场景返回的 `businessData` 原始字符串，不得修改；不得仅按返回新旧选择 |
| `cardScene` | string | ✅ | 与上述 `businessData` 来自同一次待确认场景返回的 `cardScene` 原始字符串，不得修改 |

> 取消确认场景（`amap_car_cancel_confirm`）同样通过 `confirm_order` 确认，两个字段取自取消确认场景的返回。

## 3. cancel_order（取消订单）

对用户明确要取消的生效订单发起取消。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `businessData` | string | ✅ | 来自上下文中对应订单的 `businessData` 原始字符串，不得修改；有多次订单返回时，取用户明确指定要取消那一次的原值 |

## 4. query_orders（查询订单）

查询高德打车订单列表或订单详情。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `scene` | string | | 查询场景：`"列表"`、`"详情"`；用户未明确场景或要查所有订单时填空字符串 `""` |
| `businessData` | string | | 查询明确目标且上下文中有对应订单时传其原值；查询全部订单或没有目标时省略 |

---

## cardScene 取值

判据是返回值里的 `cardScene`；取值含义见下表，对应的用户交互见 `../SKILL.md`「规划与下单」。

| `cardScene` | 场景 | 说明 |
|-------------|------|------|
| `amap_car_point` | 选点 | 起终点不唯一 |
| `amap_car_plan` | 规划 | 已勾选车型（可多个）/ 全部车型列表 / 预估价 |
| `amap_car_order` | 订单 | 下单成功 |
| `amap_car_cancel_confirm` | 取消确认 | 取消操作 |
| `amap_car_order_list` | 订单列表 | 查询、取消 |
| `amap_car_abnormal` | 异常 | 返回失败说明 |
| `amap_car_default` | 未分类兜底 | 无匹配场景 |
