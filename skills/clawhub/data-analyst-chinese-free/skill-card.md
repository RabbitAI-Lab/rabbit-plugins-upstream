## Use Case: <br>
Data analysts, product managers, operations teams, and finance users can use this skill to generate Chinese-language Python analysis templates, charts, summaries, and Markdown-style reports for common business datasets. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated analysis code may read datasets, write outputs, or execute commands in the user's workspace. <br>
Mitigation: Review generated code before execution and keep sensitive datasets scoped to the intended files. <br>
Risk: Optional API URLs or callback_url values may send data to endpoints the user did not intend to trust. <br>
Mitigation: Use only trusted API and callback URLs, and provide any required credentials through environment variables rather than hardcoding them. <br>
