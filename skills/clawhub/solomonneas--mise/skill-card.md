## Description: <br>
Use before any creative or build work - a new feature, component, behavior change, or "let's build X" - to turn an idea into a design the user approved and a written spec, before a line of code. <br>

This skill is ready for commercial/non-commercial use. <br>

[solomonneas](https://clawhub.ai/user/solomonneas) <br>

## Use Case: <br>
Developers and engineering teams use this skill to turn feature, component, and behavior-change ideas into approved designs and written specs before implementation begins. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The workflow deliberately slows small build requests by requiring design and user approval before coding. <br>
Mitigation: Use it in repositories where a strict design-before-code process is acceptable. <br>
Risk: The skill can create and commit durable spec documents. <br>
Mitigation: Use it where persistent design history is desired, and review the written spec before handoff to implementation. <br>
