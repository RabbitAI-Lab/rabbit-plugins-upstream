## Description:

Helps users research public GitHub repositories, trends, and developer activity without a GitHub token.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and researchers use this skill to find trending open-source projects, review public repository details, and examine developers' public GitHub activity.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installing the ClawLink plugin requires sign-in and one-time device pairing.

Mitigation: Review the plugin and approve pairing only if you intend to use ClawLink.

Risk: Each public GitHub lookup consumes credit; bulk lookups can increase costs.

Mitigation: Check the current per-call price and ask before large batches or expensive calls.

Risk: The skill cannot access private repositories or make changes on GitHub.

Mitigation: Use it only for public research, and use another authorized tool for private data or write actions.
