# apply · 定位、核验并应用

1. **定位。** 读取选定候选或决定，找到实际生效的条款、锚点及引用方。负责人对明确候选执行 `apply` 或已给出决定和写入授权时，直接按该决定更新相应的 L0 通则、L1 专题或 L2 功能条款。只处理选定项，保留其范围和例外。暂缓、拒绝、仍有多个选项的项保留原状态。决定明确时可跳过起草。
2. **核验。** 对照候选中的原文、当前条款、选定文字和决定，核对范围、例外和证据。候选或原规则发生了影响语义的变化，列出变化，单独请人决定受影响的部分。纯路径或措辞变化可继续；当前内容已等价时，确认引用可达后结束。彼此依赖的条款一起核对再写，独立且已定的项可继续。
3. **应用。** 在权威位置写出修订后的完整要求。新规范按[现行规范模板](../assets/standard.md)组织，旧规范沿用原文风格。合并或退役前逐项核对对象、条件、例外和引用者，保留独有内容及可恢复的前态。只在有明确替代、退出条件已满足或问题域确已消失时撤下。同步实际受影响的入口、引用和必要的来源记录。把决定记在可持久追溯的位置，现行页面不链接待定区；候选可按项目约定标记已采纳并指向现行条款。
4. **从读者入口复核。** 确认能从入口找到本条；旧引用应能到达替代条目，或随已退役的要求一并移除。语义有变化，用一个应命中的例子和一个不应命中或应被拒绝的例子，说明具体判断。已有结构检查则沿项目原入口运行。报告改了哪条、谁受影响、什么仍待定，分清规范、代码和实际运行各验证到哪一步。
