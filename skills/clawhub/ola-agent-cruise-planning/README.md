# Cruise Planning Agent

An intelligent assistant designed to help you plan your cruise vacations seamlessly. Get insights, recommendations, and booking assistance.

由 [CruiseSkillBridge](https://cruiseskillbridge.com) 发布到 [ClawHub](https://clawhub.ai)。

## 安装

```bash
openclaw skills install @OWNER/ola-agent-cruise-planning
```

> 将 `OWNER` 替换为 ClawHub 发布者 handle。
