# Data Audit — 更新日志

## [1.1.0] - 2026-07-25

### 新增
- ⚡ **过滤扫描**：`--filter` 按扩展名过滤（如 `.csv,.json`）
- 🚫 **忽略模式**：`--ignore` 支持 glob 通配符忽略（如 `__pycache__`, `*.tmp`）
- 📋 **忽略文件**：`--ignore-file` 从文件加载忽略模式（类似 `.gitignore` 语法）
- 📏 **深度限制**：`--depth` 控制递归扫描深度
- 📊 **CSV 导出**：`--export-csv` 支持快照/对比/健康检查的 CSV 输出
- ⏱️ **进度显示**：`--progress` 大目录扫描时显示进度
- ⚙️ **配置文件**：`--config` 从 JSON 文件加载参数，`--init-config` 生成模板
- 🔢 **版本号**：`--version` 显示工具版本

### 增强
- 🎯 快照/对比报告增加 tool_version 和 elapsed_seconds 字段
- 📈 健康检查增加总问题数和检查时间戳
- 🧹 配置文件支持 skip_hidden / skip_symlinks 参数
- 📝 操作日志上限从无限制调整为保留最近 1000 条

## [1.0.0] - 2026-07-19

### 新增
- 数据目录 SHA256 快照生成（递归扫描，跳过隐藏文件）
- 快照对比：新增/删除/修改文件检测
- 文件元数据追踪：大小、修改时间、哈希值
- 操作日志记录与历史查询
- 数据健康检查（空目录、不可读文件等）
- JSON 报告导出
