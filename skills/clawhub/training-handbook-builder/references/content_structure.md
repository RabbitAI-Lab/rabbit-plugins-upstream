# 培训手册内容结构参考

## 通用九模块结构

以下结构适用于大多数培训手册，可根据具体主题灵活调整：

### 第一章 时代背景与政策框架
- 行业趋势数据（市场规模、增长率）
- 国家/行业政策文件详解
- 配套政策与标准体系表格

### 第二章 核心概念与技术基础
- 核心概念对照表（概念 | 定义 | 实践意义）
- 技术架构图解
- 主流工具/产品现状

### 第三章 全场景应用详解
- 按目标受众的核心工作场景逐一展开
- 每场景含：痛点分析 → AI赋能方案表格 → 实践案例 → 工具推荐
- 这是手册的核心章节，建议占全文40%以上篇幅

### 第四章 标杆案例深度解析
- 2-3个典型案例
- 每个案例含：建设背景 → 创新模式 → 应用全景表 → 关键启示

### 第五章 实用工具速查手册
- 工具全景表（类别 | 名称 | 功能 | 场景 | 费用）
- 平台建设选型参考
- 工具选择决策矩阵

### 第六章 安全与合规保障
- 安全挑战分析
- 合规要求对照表
- 实操清单

### 第七章 领导力转型与组织变革
- 角色转型对照表
- 核心能力模型
- 组织变革三阶段路径

### 第八章 行动规划与实施路线
- 30天速赢计划表
- 半年深化路线图
- 效果评估指标体系

### 第九章 常见问题与答疑
- 认知层面FAQ（3-5问）
- 实操层面FAQ（3-5问）

### 附录
- A: 关键政策文件索引
- B: 推荐学习资源
- C: 术语表

## 内容素材格式规范

在使用 `generate_handbook.py` 的 `render_content` 函数时，内容项支持以下格式：

### 普通段落
```python
"paragraph: 这里写正文段落内容。"
```

### 三级标题
```python
("heading3", "三级标题文字")
```

### 彩色表格
```python
("table",
 ["列标题1", "列标题2", "列标题3"],
 [["行1数据1", "行1数据2", "行1数据3"],
  ["行2数据1", "行2数据2", "行2数据3"]],
 [5, 4, 7])  # 列宽(cm)
```

### 重点提示
```python
("tip", "提示文字内容")
```

### 实践案例
```python
("case", "案例标题", "案例正文内容")
```

### 编号列表
```python
("numbered", [
    ("条目标题1", "条目内容1"),
    ("条目标题2", "条目内容2"),
])
```

### 分页符
```python
("pagebreak",)
```

## 排版设计原则

1. **可打印性优先**：A4纸、合理边距、适合双面打印
2. **视觉层次清晰**：通过颜色和大小区分标题层级
3. **信息密度适中**：每页不超过500字正文，表格占比约40%
4. **案例与提示突出**：用颜色和缩进区分常规内容和重点内容
5. **工具友好**：使用Word域代码实现目录和页码的自动更新
