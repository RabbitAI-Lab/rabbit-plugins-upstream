## Description:

Use DebugBundle for runtime error reporting, crash reporting, incident reporting, incident response, live app monitoring, and production monitoring focused on runtime failures, customer-facing incidents, and endpoint health—not generic infrastructure metrics. Investigate exceptions, alerts, logs, observability signals, health checks, and debug bundles; review product analytics; and guide evidence-based fixes through CLI primarily, with MCP where needed.

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: Using the wrong project or API host could expose or affect unrelated operational data.

Mitigation: Confirm the intended project and API host before hosted operations.

Risk: Member credentials could be exposed if copied into chat or command arguments.

Mitigation: Keep member credentials private and use existing saved or server-side authentication.

Risk: Capture-rule changes can discard future diagnostic evidence.

Mitigation: Review the specific proposed rule and authorize management changes deliberately.
