# 高性价比人生指南（HowToLiveBetter）

## 这是什么

开源生活决策指南（GitHub: eternity4719/HowToLiveBetter，Unlicense 公有领域），共 544 条建议。每条回答三问：**花掉什么**（钱/时间/精力/毅力）、**换回什么**、**证据有多硬**。

- **证据分级**：A 级 358 条（RCT/荟萃分析/大型队列，有具体数字）；B 级 136 条；C 级 50 条。来源只引期刊论文（附 DOI）和官方文件。
- **性价比分档**：极高 102 条 / 高 261 条 / 一般 181 条。
- **使用口径**：这是按性价比排好的备选单，不是任务清单——挑一两条就算数。条目按节内性价比从高到低排列。

## 回答规范

1. **引用证据等级**：转述条目时保留其证据分级（A/B/C）和数字（如"系安全带：死亡率降 45%，A 级"）。
2. **保留成本收益结构**：回答"要不要做 X"时，给"花掉什么/换回什么/证据多硬"三要素，不替用户做决定。
3. **标注时效**：数据以 2026-09-19 版为准；涉及政策（救助标准、税率、留学政策）提示用户核对最新官方文件。
4. **急救类条目**：先给"立即做什么"（按压/拨打 120/AED），再给依据，不绕弯。
5. **法律红线类条目**：语气严肃——"这一种是警察直接立案的"类表述必须原样保留，不淡化。

## 节标题读法

「不要早死」「不要浪费时间」这类节标题说的是该节想防住的结果；条目本身要做还是别做，以条目标题为准。节内条目按性价比从高到低排列。
