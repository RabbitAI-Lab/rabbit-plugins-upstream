# Temu 图搜同款接口

## 调用脚本

```bash
python3 scripts/temu_image_search.py \
  --image "/path/to/product.jpg" \
  --param "siteId=48" \
  --param "page=1" \
  --param "size=20"
```

脚本将图片上传后执行图搜，再输出与 Temu 商品搜索一致的 JSON 数据。查询需要登录；服务端要求暂停时遵循 [查询暂停与恢复流程](查询暂停与恢复流程.md)。

## 图片输入

`--image` 支持以下输入：

| 输入形式 | 示例或规则 |
| --- | --- |
| 本地文件或会话附件 | 使用图片在当前运行环境中的真实文件路径 |
| 文件地址 | `file:///path/to/product.jpg` |
| 图片网址 | `http://` 或 `https://` 开头的可直接下载地址 |
| Data URI | `data:image/png;base64,...` |
| Base64 | 使用 `base64:...` 前缀 |
| 标准输入 | 使用 `--image -`，从标准输入读取原始图片字节 |

- 图片最大为 10M。
- 脚本根据图片内容识别 JPEG、PNG、GIF、WebP、BMP、TIFF、AVIF 和 HEIC/HEIF 等常见格式，不只依赖文件扩展名。
- 对聊天中上传的图片，优先使用平台提供的本地附件路径；不要把图片内容打印到对话、日志或思考过程。
- 图片 URL 无法直接下载、需要网页 Cookie 或存在防盗链时，先下载为本地临时文件再传入。查询结束后可以删除本地临时副本。

## 查询参数

所有 `--param` 都复用 [Temu 商品搜索接口](Temu商品搜索接口.md) 已定义的参数、校验、站点映射、筛选规则、排序字段和分页规则，包括：

- 默认美国站站点 ID `48`；其他国家或地区先通过站点列表解析。
- `keyword`、`catIds`、`hostingMode`。
- 销量、销量增长率、销售额、销售额增长率、库存、店铺销量、同款数、价格、供货价、评分、评论数和时间范围。
- `page`、`size`、`sort`、`order`。

图片候选与这些条件取交集。未指定 `sort` 时按图片相似度排序；指定 `sort` 后，在图片候选中按业务字段排序。分页查询多页时，每一页必须使用同一张图片和同一组筛选、排序条件，只改变页码。用户要求全部同款或完整市场分析时，使用单页最大值 200，并依据 `data.total` 继续请求后续页，不能只读取第一页。

不要传服务端内部地区编号；站点统一使用 `siteId`。筛选和排序参数范围以商品搜索接口文档为准。

## 成功响应

```json
{
  "code": 0,
  "data": {
    "total": 460,
    "list": []
  }
}
```

- `data.total` 是图片候选与全部商品筛选条件交集后的命中数。
- `data.list` 与 Temu 商品搜索返回的 `data.list` 使用完全相同的结构和完整字段。
- 服务端为每个商品返回 `linkUrl`，指向极鲸云 Temu 商品详情页。对用户展示时必须将商品标题写成 `[商品标题](<linkUrl>)`。

## 失败处理

- `code != 0`、HTTP 非 2xx、响应不是 JSON 或缺少 `data` 时查询失败。
- 服务端返回一级 `msg` 时，只向用户展示该中文文案，不打印错误 JSON、请求参数、英文响应字段或内部状态。
- 服务端返回 `jumpUrl` 时，按 [查询暂停与恢复流程](查询暂停与恢复流程.md) 暂停；用户完成操作后，使用原图片和原查询条件重新调用。
