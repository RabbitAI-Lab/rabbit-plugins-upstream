## Description:

This skill helps users diagnose logic issues in supplied text, rebuild the content with Pyramid Principle structure, MECE checks, SCQA openings, and a polished rewrite.

This skill is ready for commercial/non-commercial use.

## Publisher:

[muippt](https://clawhub.ai/user/muippt)

### License/Terms of Use:

MIT

## Use Case:

Employees, external users, and writers use this skill to turn rough ideas, reports, proposals, emails, speeches, and review narratives into clearer conclusion-first structures. It can also run guided logic-training drills for fact-versus-judgment, deduction-versus-induction, MECE gap finding, and pyramid reassembly.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill rewrites and restructures user-provided text, so important nuance can be lost or reframed.

Mitigation: Review the diagnosis, quoted source excerpts, pyramid outline, and optimized draft against the original text before relying on the result.

Risk: The skill may suggest related skills for polishing, presentation creation, or critical-thinking review.

Mitigation: Install and run only related skills that have been separately reviewed and approved for the intended workspace.
