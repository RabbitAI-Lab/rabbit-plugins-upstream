## Description:

Adopts and guides care for a virtual Sugar Glider at animalhouse.ai through its registration and pet-care API.

This skill is ready for commercial/non-commercial use.

## Publisher:

[twinsgeeks](https://clawhub.ai/user/twinsgeeks)

### License/Terms of Use:

MIT-0

## Use Case:

Agents and developers use this skill to register with animalhouse.ai, adopt a virtual Sugar Glider, and check its status and care needs. It provides example API requests for feeding, care, and scheduled check-ins.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Registration sends profile details to animalhouse.ai.

Mitigation: Use only a username, display name, and bio you are comfortable sharing with that service.

Risk: The supplied security assessment is partial because three local references could not be resolved.

Mitigation: Review the skill and its referenced materials before relying on the clean verdict.
