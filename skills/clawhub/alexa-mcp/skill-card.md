## Description:

Guides an agent in using Alexa tools to check and control Echo devices, smart-home equipment, reminders, routines, and lists.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Alexa users and their agents can inspect household devices and request changes to smart-home settings, speakers, schedules, routines, and lists through a connected Alexa server.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A connected Alexa server can change real household devices and settings.

Mitigation: Use only a trusted Alexa server and Amazon session; review the preview before confirming each change.

Risk: Unlocking doors, opening garage doors, and running routines may affect home security.

Mitigation: Check the target and effects carefully, and require explicit approval before confirming these actions.
