## Known Risks and Mitigations:

Risk: Actions depend on a trusted Alexa MCP server enforcing confirmation tokens; some changes affect home security or multiple thermostats.

Mitigation: Use a trusted server and check each preview before confirming, especially for locks, garage doors, routines, and vacation mode. Enter Amazon credentials only on amazon.com.
