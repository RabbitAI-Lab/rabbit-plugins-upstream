# 维修安全操作规范

## 电气安全

### 基本原则
1. **断电操作**：维修任何电器前，必须拔掉电源插头或断开对应空开
2. **验电确认**：用试电笔或多用表确认无电后操作
3. **电容放电**：大电容（微波炉高压电容、空调启动电容、开关电源）即使断电也可能存有高压电，需用电阻放电
4. **单手操作**：带电检修时尽量单手操作，另一手放背后（减少电流经过心脏的风险）
5. **绝缘鞋/干燥地面**：站在干燥木板上操作
6. **严禁湿手操作**：手湿不碰电器

### ⚠️ 必须找专业电工的情况
- 配电箱冒烟/有焦味
- 频繁无规律跳闸
- 需要改动入户主线
- 老旧房屋铝线线路
- 没有地线的两孔插座环境
- 三相380V设备

### 换保险丝安全步骤
```
1. 断开总闸
2. 用试电笔确认配电箱无电
3. 找到烧断的保险丝
4. 更换同规格保险丝（绝对不能换更大电流的！）
5. 推闸测试
```

## 燃气安全

### ⚠️ 燃气泄漏紧急处置
如果闻到煤气味（类似臭鸡蛋味）：
1. **立即关闭燃气总阀门**
2. **打开所有门窗通风**
3. **严禁开关任何电器**（包括灯、排风扇、门铃——开关火花可能引爆！）
4. **不要使用手机/电话**（到室外再打电话）
5. **不要按门铃/不要开关灯**
6. 到室外拨打燃气公司抢险电话

### 日常注意事项
- 燃气灶用后随手关阀门
- 定期用肥皂水检查管道接口是否漏气（冒泡=漏气）
- 燃气软管2年更换一次
- 热水器必须有排烟管通到室外
- 不要在燃气管道上挂东西

### 自己更换燃气灶电池/点火针
- 更换电池安全，不影响燃气管道
- 清洗/调节点火针位置安全
- ⚠️ 涉及燃气管道拆装的必须找燃气公司或有资质人员

## 高空作业安全

### 需要高空作业的场景
- 更换吸顶灯
- 外墙空调维修
- 擦窗户外部
- 屋顶作业

### 安全要求
- 使用稳固的人字梯（不要用椅子/凳子代替）
- 梯子放在平地上，四脚稳固
- 梯子张开角度合适（有锁定装置）
- 有人扶梯或监护
- 登高不超过梯子倒数第三级
- 不侧身探出太远

### ⚠️ 以下情况找专业人员
- 高度超过3米
- 需要接触外墙
- 需要爬出窗外
- 没有合适的安全装备

## 化学品安全

### 常见家用化学品
| 化学品 | 风险 |
|--------|------|
| 管道疏通剂（强碱） | 腐蚀皮肤/眼睛，遇水产热喷溅 |
| 84消毒液（次氯酸钠） | 刺激性气体，不要与洁厕灵混用（产生氯气=毒气） |
| 洁厕灵（盐酸） | 腐蚀性，不要与84混用 |
| 除霉剂 | 含漂白剂，避免吸入 |
| PVC胶水 | 含挥发性有机物，通风使用 |
| 玻璃胶/结构胶 | 中性款较安全，酸性款有刺激性 |
| 油漆/稀释剂 | 易燃，通风使用 |

### 使用原则
- 戴橡胶手套
- 在通风处使用
- 远离儿童
- 不要混合不同清洁剂
- 溅入眼睛立即用大量清水冲洗并就医

## 工具使用安全

### 电钻/冲击钻
- 戴护目镜（防止碎屑入眼）
- 瓷砖钻孔用瓷砖专用钻头，先低速定位
- 确认钻孔位置没有电线/水管（可用墙体探测仪）
- 长发扎起，不戴手套（防卷入）

### 角磨机/切割机
- ⚠️ 必须戴护目镜和口罩
- 切割片有方向，不要装反
- 切割片破损/变形立即更换
- 不要站在切割片旋转平面内

### 电烙铁/热风枪
- 使用后放在烙铁架上
- 不要用手试温度
- 焊锡烟有害，在通风处或使用吸烟仪
- 远离易燃物

### 梯子
- 使用前检查有无断裂/松动
- 不要超过承重限制
- 不要站在最顶部两级

## 维修前通用检查清单

在动手维修任何设备前，逐项确认：

- [ ] 设备已断电/断气/断水
- [ ] 已阅读设备说明书/查到拆机教程
- [ ] 手边有合适的工具
- [ ] 工作区域通风/照明良好
- [ ] 已拍照记录拆前状态（帮助复原）
- [ ] 小零件有容器放置（防止掉落丢失）
- [ ] 拆下的螺丝按顺序排列
- [ ] 知道如何复原
- [ ] 安全装备齐全（手套/护目镜按需）
- [ ] 已告知家人你在维修（防止有人误通电/通水）
- [ ] 手机在手边（紧急情况可求助）

## 特殊设备安全

### 微波炉高压维修
⚠️ **微波炉内部有高压电容（断电后仍存有数千伏高压）**
- 非专业人士不要拆微波炉外壳
- 必须拆修时：断电后等待至少 30 分钟，用 10KΩ/5W 电阻对电容放电
- 不要触碰磁控管和高压电容引脚

### 空调外机维修
- ⚠️ 高空作业，系好安全带
- 断电操作（内外机都断电）
- 制冷剂（氟利昂）不要直接排放到空气中
- 不要用明火检漏（R32/R290 制冷剂可燃）

### 燃气热水器
- ⚠️ 绝对不要安装在浴室/密闭空间（一氧化碳中毒风险）
- 排烟管必须通向室外
- 定期检查排烟管是否堵塞/破损
- 使用时保持通风

### 车辆千斤顶
- 必须在硬质平地上使用
- 拉紧手刹，轮胎前后放挡块
- 支撑点必须是车辆指定举升点（不是随便顶）
- 顶起后必须用安全支架支撑（不要只靠千斤顶）
- ⚠️ 不要钻到只用千斤顶支撑的车底
