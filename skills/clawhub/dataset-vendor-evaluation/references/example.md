# Worked example: size versus useful additions

Synthetic assessment. The existing roster contains 100 target clinicians.

Vendor A advertises a large directory. In its curated demonstration sample, most entries overlap the roster; three appear new, but their identities and dates have not been verified. Price and reuse terms are unknown.

Vendor B supplies a bounded delivery with 20 verified additional target clinicians and dated facility affiliations. The supplied evaluation terms permit the intended pilot use. Product confirms those fields answer a current customer request; implementation cost remains an estimate.

Recommend a bounded pilot of B to measure match quality, update behavior and usability. Do not call A's unknown identities confirmed new coverage. Do not infer B's financial return from 20 additions alone. A useful additional field on an existing clinician should be counted as enrichment rather than dismissed as duplication.

If the target population changes to a state neither source covers, revisit the recommendation instead of repeating the earlier ranking.
