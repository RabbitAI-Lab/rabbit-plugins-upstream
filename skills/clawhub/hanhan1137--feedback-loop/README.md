# Feedback Loop 🔁

把「用户的每一次反馈」变成 Agent 的长期记忆和行为准则：说好就固化、说错就反思、达成共识就写死。

## 核心能力
- 🧭 **反馈强度分级**：随口夸/明确认可/强指令/随口吐槽/明确批评/强负反馈——六级对应不同处理深度，不小题大做也不漏重要反馈
- 📝 **结构化落盘**：统一 `[正]/[反]/[定]/[约]` 条目格式，grep 一键定位
- 🔗 **完整落盘链**：重要反馈走 feedback-log → conclusions → MEMORY → 验证可检索四步，堵「结论静默消失」
- 🧘 **立场一致性**：已达成结论先查再开口，不重新推理、不横跳
- 🛡️ **回滚保护**：改机制/记忆文件前先快照，出问题精确回滚
- 🧪 **触发词消歧**：区分「真反馈」和「普通对话」，宁可不误触

## 使用
1. 用户对 Agent 的输出给出评价（称赞/批评/达成共识/改主意）
2. 按分级表定级，走对应处理路径
3. 重要反馈走完整落盘链，每步写完当场验证可检索
4. 立场一致自检：涉及已达成结论的话题，先查再答
