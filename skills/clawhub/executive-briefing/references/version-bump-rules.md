# 版本联动细则

## 三段式 SemVer

| 段位 | 触发条件 | 示例 |
|------|---------|------|
| **X**.0.0 | 增删章节、重组结构、合并/拆分 Part | V2.6.0 → V3.0.0 |
| X.**Y**.0 | 表格行列增删、策略描述修改、数据更新、新增子节 | V3.0.0 → V3.1.0 |
| X.Y.**Z** | 格式修正、错别字、链接修复、编号修正 | V3.0.1 → V3.0.2 |

## 合并变更规则

一次修改涉及多级别时，取最高级别：

| 同时发生 | 结果 |
|---------|------|
| 新增 Part（Major）+ 表格更新（Minor） | → Major（X+1, Y=0, Z=0） |
| 策略修改（Minor）+ 错别字修正（Patch） | → Minor（Y+1, Z=0） |

> **原则：一次 bump，取最高影响级别。**

## 删章处理

| 操作 | 级别 | 说明 |
|------|------|------|
| 删除整个 Part | Major | 架构级变更 |
| 删除单个子节 | Minor | 内容级变更 |

## 文件命名约定

统一使用三段式，Patch 为 0 也写全：

```
✅ 01-战略规划-v1.0.0.md
✅ 01-战略规划-v3.2.1.md
❌ 01-战略规划-v1.0.md
❌ 01-战略规划-v3.md
```

## 使用

```bash
python3 scripts/bump.py --major    # X+1, Y=0, Z=0
python3 scripts/bump.py --minor    # Y+1, Z=0
python3 scripts/bump.py --patch    # Z+1
```
