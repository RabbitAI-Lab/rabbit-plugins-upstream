# 千门八将108局：底层逻辑分析

> 千门八将不是108个散装计谋，它是一个完整的**战略元模型**——把人类博弈策略按照机制分类的周期表。

---

## 一、第一性原理：什么是一个「局」？

### 定义

**局 = 信息差 × 激励设计 × 时间杠杆 × 关系拓扑**

**核心公理：现实是被建构的。高手不下棋子，高手设计棋盘。**

| 要素 | 含义 | 核心问题 |
|------|------|---------|
| **信息差** | 我知道你不知道的东西 | "你按什么信息做决策？" |
| **激励设计** | 我改变了你的得失计算 | "你为什么要走这条路？" |
| **时间杠杆** | 我用时间来放大效果 | "什么时候是最佳时机？" |
| **关系拓扑** | 我重新排列了人与人之间的连线 | "你能联系谁、不能联系谁？" |

108局 = 这四个要素的排列组合。有些局信息差拉满（鼠尾局），有些局激励扭曲拉满（金山局），有些局时间杠杆拉满（伏龟局），最好的局四者皆有。

---

## 二、元结构：天-地二元 = 战略的完整光谱

```
         阳谋（天局36）                       阴谋（地局72）
    ┌──────────────────────┐        ┌──────────────────────────┐
    │ 系统层 / 结构性压制     │        │ 个体层 / 心理性操纵         │
    │                        │        │                          │
    │ 特征：知道也防不住       │        │ 特征：一旦被识破就失效       │
    │ 类比：纳什均衡          │        │ 类比：信号博弈             │
    │      公地悲剧           │        │       道德风险            │
    │      先发优势           │        │       逆向选择            │
    │                        │        │                          │
    │ 用法：建立在结构上       │        │ 用法：建立在认知差上         │
    │ 效果：你不配合也得配合    │        │ 效果：你配合是因为你不知道    │
    └──────────────────────┘        └──────────────────────────┘
```

> **阳谋用结构赢你，阴谋用认知差赢你。真正的战略高手两者并用。**
- **阳谋** ≈ 博弈论中的 Dominant Strategy（不管对手怎么玩，我都赢）
- **阴谋** ≈ 博弈论中的 Bayesian Game（利用对手的认知盲区取胜）

## 三、八大天局 = 战略的8步操作系统

> **定延缀役借藏隐将不是一个菜单，是一个流程。**

| # | 类别 | 战略阶段 | 核心动作 | 关键问题 |
|---|------|---------|---------|---------|
| 1 | **定局** | 框架定义 | 定义游戏规则 | "这个游戏叫什么？规则由谁定？" |
| 2 | **延局** | 时间创造 | 创造战略缓冲 | "怎么拖到我的牌齐了再开打？" |
| 3 | **缀局** | 网络编织 | 串联分散力量 | "把谁串起来？怎么串？" |
| 4 | **役局** | 力量动员 | 让棋子动起来 | "怎么让棋子以为自己在下棋？" |
| 5 | **借局** | 杠杆放大 | 借用外部力量 | "用谁的力打我的仗？" |
| 6 | **藏局** | 意图隐藏 | 掩盖真实目标 | "怎么让你只看到A，我在做B？" |
| 7 | **隐局** | 深度渗透 | 让力量变成环境 | "怎么让我的意志变成空气？" |
| 8 | **将局** | 决胜收网 | 打出致命一击 | "什么时候收网？怎么收？" |

> 流程：定 → 延 → 缀 → 役 → 借 → 藏 → 隐 → 将。可以循环、跳过、并行，但逻辑上每一步建立在前一步基础上。

## 四、六大地球类别 = 人类心理的6个攻击面

72地局之所以分成6类，是因为它们分别攻击人的**6个决策漏洞**：

| 类别 | 攻击维度 | 心理机制 | 一句话本质 | 现代心理学对应 |
|------|---------|---------|-----------|--------------|
| **神仙局** | 信仰系统 | 对未知的敬畏与盲从 | 人需要一个可以跪的东西 | Authority Bias, Superstition |
| **人物局** | 身份认同 | 自我形象的执着 | 人需要觉得自己是某种人 | Identity Theory, Ego Defense |
| **生肖局** | 性格特质 | 固定反应模式 | 人的性格就是最大的可预测漏洞 | Big Five, Habit Loops |
| **资源局** | 生存欲望 | 对稀缺和贪婪的本能 | 人面对得失时理性归零 | Scarcity Bias, Loss Aversion |
| **情感局** | 关系羁绊 | 爱与归属的需求 | 人心最软的地方就是最强杠杆 | Attachment Theory |
| **手段局** | 认知漏洞 | 思维捷径的系统缺陷 | 人脑用启发式而非理性运行 | Cognitive Biases, Heuristics |

> 6个维度覆盖人的全部决策路径：信仰 → 身份 → 性格 → 欲望 → 关系 → 认知。

## 五、贯穿108局的5条底层法则

### 法则1：信息不对称法则
> **谁掌握信息差，谁就拥有定义现实的能力。**

| 体现的局 | 操作 |
|---------|------|
| 鼠尾局 | 只露出一小部分利益，藏住全局 |
| 迷兔局 | 放出多个虚假信息，让人分不清真假 |
| 井蛙局 | 刻意屏蔽外界信息，局限对方眼界 |
| 弥天局 | 编造宏大谎言，细节包装到位 |
| 河狸局 | 不断放出碎片化信息，慢慢拼凑出虚假事实 |

**现代映射：** 数据垄断、算法黑箱、选择性信息披露、信息茧房
**防御方法：** 拓展信息源、交叉验证、追问"我不知道什么？"

---

### 法则2：激励扭曲法则
> **不是强迫人，是让人"自愿"走到你想让他走的路。**

| 体现的局 | 操作 |
|---------|------|
| 金山局 | 刻意展露短期收益，制造暴富假象 |
| 小河局 | 小利不断投喂，逐步加大投入 |
| 危冠局 | 捧高对方地位，用虚荣心牵制 |
| 花翎局 | 用荣誉头衔牵制，让人追逐虚利 |
| 打渔杀家局 | 先予厚利麻痹对手，待其倾尽家底后一次性收割 |

**现代映射：** 游戏化设计、会员体系、期权金手铐、庞氏骗局
**防御方法：** 反问"他为什么要给我这个好处？"、计算长期总成本

---

### 法则3：时间杠杆法则
> **慢局吃复利，快局吃信息差。收益 = 局势强度 × 时间。**

| 体现的局 | 操作 |
|---------|------|
| 天恒局 | 长期缓慢布局，温水渗透 |
| 伏龟局 | 长期隐忍不动，等待对手松懈 |
| 石中绕丝局 | 细微处长期布局，丝丝缠绕，日久难以挣脱 |
| 石中挤油局 | 慢慢压榨价值，一点点索取 |
| 潜龙鲧洪局 | 低谷隐忍蛰伏，暗中积蓄实力 |

**现代映射：** 长期主义投资、复利效应、温水煮青蛙式变革、沉没成本陷阱
**防御方法：** 定期复盘"我是怎么走到这一步的？"、设置止损线

---

### 法则4：关系拓扑法则
> **你不是要赢每个人，你要占据关系网络的关键节点。**

| 体现的局 | 操作 |
|---------|------|
| 天斗局 | 制造两方对立，自己居中观望，坐收渔利 |
| 隔情局 | 离间两人关系，制造隔阂，逐个击破 |
| 破冰局 | 打破对方原有圈子，切断原有人脉 |
| 七星聚汇局 | 整合分散资源与人脉，搭建统一平台 |
| 暗线穿珠局 | 暗中串联分散势力，悄无声息整合资源 |

**现代映射：** 平台战略、社交网络中介中心性、供应链关键节点控制、分而治之
**防御方法：** 保持多元连接、不被单一渠道控制、警惕"只能依靠我"的信号

---

### 法则5：身份建构法则
> **人对现实的反应，本质是对自我叙事（我是谁）的反应。**

| 体现的局 | 操作 |
|---------|------|
| 圣母局 | 刻意塑造善良人设，博取信任 |
| 朱衣局 | 塑造光鲜体面人设，靠外表气场获取信赖 |
| 伪善局 | 表面仗义热心，内心算计 |
| 太公钓鱼局 | 长线造势立人设，静候目标主动登门 |
| 麻衣局 | 扮作落魄普通人，伪装弱势博取同情 |

**现代映射：** 品牌叙事、个人IP、人设经济、企业文化洗脑
**防御方法：** 区分"人设"和"人品"、观察一致性和长期行为

## 五条法则的关系

```
        信息差 ──→ 激励扭曲
           ↓           ↓
        时间杠杆 ←── 关系拓扑
                       ↓
                   身份建构
```

> 最好的局，五条法则同时发力——信息差让你看不清，激励扭曲让你主动走，时间杠杆让你走不脱，关系拓扑让你无处可去，身份建构让你觉得这都是你自己的选择。

## 六、内化三层次

| 层次 | 能力 | 表现 |
|------|------|------|
| **Level 1：识局** | 事后能认出别人在用什么局 | "原来他当时用的是伏龟局" |
| **Level 2：拆局** | 事中能识别并破解正在发生的局 | "等一下，这不对劲，他在用井蛙局屏蔽我的信息" |
| **Level 3：化局** | 事前预见局势走向，自然做出最优应对 | 不需要刻意分析，直觉已经替你算完了 |

> 108局不是让你背的，是让你泡在里面的。每天接触、每天分析、每天反思，108天后这些局的"味道"会进入你的直觉。
