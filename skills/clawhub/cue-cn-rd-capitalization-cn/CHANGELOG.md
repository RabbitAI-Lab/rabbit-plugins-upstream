# 变更记录

### 0.1.0 — 2026-11-13（新建：研发支出资本化的逐条挂源）

首版。`研发支出资本化`／`开发支出`／`资本化率` 这三个词在仓内 `grep`（全 `*.md`）**零命中**，ClawHub 检索同样 n=0。**这一类是纯空白位**。

**一、五块内容**

1. **研发投入与资本化概况**：研发投入合计、其中费用化、资本化金额、资本化率、占营业收入比；
2. **开发支出明细**：期初余额、本期增加、本期转入无形资产、本期转入当期损益、期末余额；
3. **资本化与费用化的划分**：划分标准原文、研究阶段支出、开发阶段支出、资本化起始时点、在研项目与所处阶段；
4. **资本化条件的满足情况**：五项条件原文、本期满足条件的项目数、条件判断依据、资本化金额占开发支出增加额比；
5. **无形资产摊销与减值**：资本化形成无形资产原值、摊销年限、本期摊销额、摊销政策、减值准备。

**二、五道机检（`scripts/check_rd_capitalization.py`）**

| 码 | 判什么 |
|---|---|
| `RD-STRUCT` | 头部四件自标 + `主体：`／`报告期：` + 七节按序 + 前五节各至少一条发现行 |
| `RD-QUOTE` | 每条发现行以「」+〔锚：…〕+[S#] 收尾；来源行带 URL 与检索日；引用编号都登记 |
| `RD-NOSELF` | 阶段划分与资本化条件只认原句；比例自算须标〔自算〕带分子分母；三个数不得拼成等式 |
| `RD-GAP` | 正文与第六节两向点名；零缺口写 `未取到：无`；禁「不适用」类措辞 |
| `RD-LINE` | 研发成色、资本化建议、利润影响、评级目标价 |

**三、离线 runner 三档**

档① 机检自测 ／ 档② 好样坏样逐枚单跑 ／ 档③ 16 支边界形逐枚单跑（12 支该红、4 支反证）。每支注入都先断言落地、都只钉一道码。档数由 runner 末行现算，文档里不写死。

**四、包级测试（`tests/test_rd_capitalization.py`，15 条）**

入口契约（`--help` 退 0／无参退 2／缺件退 3／空稿退 3／自测退 0）、零输入（`--demo` 能跑、能过自己的机检、确定性、与 good 夹具字节相同）、判据行为（坏样五道齐发、好样零发条）、首次运行埋点（落一枚空文件、同日不增殖、失败静默、无 HOME 静默）。

**五、为什么建这一枚**

下载的杠杆只有上更多新件（每枚首 48h 约 85，之后归到 6~8/日），这是本仓 22 天序列上唯一站得住的推论。而挑件的唯一标准是「这个位置是空的」——不是「这个词搜索量高」。研发支出资本化在仓内与平台两侧都是零，同时它是**最直接改当期利润**的一节（资本化把费用挪进资产），结构固定、可逐条挂源，与既有件的边界也干净（减值走 goodwill-impairment-risk、税收走 tax-policy-card、补助走 gov-grant-quality）。

**六、第一版自己踩的四处（记下来给下一枚用）**

1. **口径行里的「写未取到」被当成缺口登记。** 第六节有一行 `- 口径：……披露只给两个时第三个写未取到，不自行轧差补齐。`，判据原样按「行里含未取到」认成缺口，于是好样自己红了一条假 `RD-GAP`（「第六节点名了「口径：研发投入合计、资本」，正文没有这条表述」）。**改为只认带冒号的登记形**（`未取到：`），叙述形不算。
2. **自推坏样把原句里唯一的词族也删掉了。** 第一版把「研究阶段的支出……开发阶段的支出……」整段换成一句不含阶段词的原文，结果整行只剩项名，而项名是被剥掉的——**码没发出来**。改为保留原句、把值位换成带「开发阶段」的写法，让「开发阶段」成为原句之外唯一的词族。**这与上一枚同一类教训：坏样要坏在判据真正看的地方。**
3. **注入点选在「未取到」行会连带两道码。** 第⑦支最初改的是 `- 条件判断依据 未取到：……` 那一行，整行换掉后两向对账断了（假 `RD-GAP`）、该行也没了三元组（假 `RD-QUOTE`），测出来的红分不清归属。**改为改一条有完整三元组的行，在值位里加一句原句之外的判断。** 每支注入只用该项自己那句话，是 runner 里写死的规矩，这次是自己先犯了。
4. **坏样要五道齐发，不能只有一支结构坏。** 第一次用 `--demo` 派生的 `BAD_STRUCT` 直接存成 `bad-rd.md`，跑出来只发 `RD-STRUCT` 一道——runner 档② 要求五道齐，直接不合。改为把五支单点注入合成一份坏样。

**七、红线自查**

零网络、零凭据、零外部依赖；`--demo` 零输入可跑且与 good 夹具字节相同；坏样五道齐发无连带码；本件不在场景图表一孤点清单内（`consumes: [parsed-doc]`，`produces: [structured-note]` 有真实接入）。
