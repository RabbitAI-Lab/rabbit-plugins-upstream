## 二、活动总结模板

### 导师评价模板

用户可以提供 3-5 个关键词，AI 自动扩写为完整段落。关键词与生成内容的对应关系：

| 关键词 | 生成方向 |
|--------|---------|
| 讲解细致/详细 | 专家在授课过程中讲解细致入微，从基础理论到操作技巧层层递进，对学员提出的问题均给予了耐心解答。 |
| 互动积极/气氛活跃 | 本次培训气氛活跃，学员积极提问，与导师展开了深入的互动交流，形成了良好的学习氛围。 |
| 操作指导到位 | 在模型操作环节，导师对每位学员进行了逐一指导，针对个人操作中的问题给出了针对性建议，确保每位学员都能掌握操作要领。 |
| 理论结合实践 | 培训将理论授课与模型操作紧密结合，先通过理论讲解打牢基础，再通过实操巩固所学知识，取得了良好的教学效果。 |
| 学员进步明显 | 通过培训前后的对比，学员的操作熟练度和自信心均有显著提升，培训效果得到了学员的一致认可。 |
| 需要更多实操时间 | 建议未来在条件允许的情况下，适当延长模型操作时间，为学员提供更多动手练习的机会。 |
| 课程内容丰富 | 本次培训内容设置科学合理，涵盖了从基础理论到临床应用的多个维度，信息量大但条理清晰。 |

**扩写示例：**

输入关键词：`讲解详细、互动积极、理论结合实践`

生成结果：
> 本次培训班整体效果良好。专家在授课过程中讲解细致入微，从基础理论到操作技巧层层递进，对学员提出的问题均给予了耐心解答。培训气氛活跃，学员积极提问，与导师展开了深入的互动交流，形成了良好的学习氛围。培训将理论授课与模型操作紧密结合，先通过理论讲解打牢基础，再通过实操巩固所学知识，取得了良好的教学效果。

## 三、改善建议模板

| 关键词 | 生成方向 |
|--------|---------|
| 报名来源/学员筛选 | 后续需进一步对报名来源进行分析，重点关注学员的科室分布及内镜操作经验年限，确保参训学员具备相应的基础技能，同时加强与BU端的沟通协作，提高培训资源的精准匹配度。 |
| 课程时长/实操时间 | 根据学员反馈，部分课程内容可在时间分配上进一步优化，建议适当延长模型操作环节的时间，为学员提供更充足的动手练习机会。 |
| 课程内容难度 | 后续课程可考虑根据学员基础进行分层教学，设置基础班和提高班，因材施教，提升培训的针对性和效果。 |
| 器械设备 | 建议后续在培训中增加更多型号器械的操作体验，帮助学员全面了解不同器械的特点和应用场景。 |
| 课后跟进 | 建议加强培训后的学员随访和操作数据收集，持续跟踪学员在临床中的操作情况，评估培训的长期效果。 |
