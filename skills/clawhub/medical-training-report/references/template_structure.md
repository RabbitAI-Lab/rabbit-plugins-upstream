# 活动报告模板结构说明 v3.0

本文件描述 v3.0 生成的 docx 文档结构，供生成脚本和 AI 参考。

## v3.0 核心变化

- **统一模板**：三种会议模式（offline / hybrid / online）公用一个结构
- **新增活动致辞**：在基本信息表之后、日程之前
- **会议详细内容按模式分支**：线上部分 → 理论授课 → 操作 → 病例讨论 → 纯线上环节
- **新版总结**：分环节亮点（授课/操作/病例讨论/线上课程）

---

## 文档整体结构

报告由两个主表格组成：

### 表格 0：基本信息表（11行 × 2列）

| 行 | 左列（字段名） | 右列（内容） |
|----|---------------|-------------|
| 0 | 活动报告书（合并单元格，居中加粗标题） | |
| 1 | 会议基本信息（合并单元格，灰色背景分区标题） | |
| 2 | 会议名称 | [内容] |
| 3 | 主办单位 | [内容] |
| 4 | 会议时间 | [线上/线下分别说明] |
| 5 | 会议地点 | [内容] |
| 6 | 参会专家 | [医院+姓名，多行] |
| 7 | 会议规模 | [各课程人数] |
| 8 | 参加员工 | [部门：姓名，多部门分行] |
| 9 | 项目介绍 | [一段话描述] |

### 一、活动致辞（v3.0 新增）

在基本信息表和培训内容表之间的段落：

- **标题**："一、活动致辞"（微软雅黑，加粗）
- **致辞专家**：姓名+医院
- **主持人**：姓名+单位（默认"[培训部门]"）
- **致辞正文**：AI 生成或用户提供，2-3 句开场致辞

---

### 表格 1：培训内容表（1行 × 1列）

此单元格内包含以下内容，按顺序排列：

### 二、活动日程

- **标题**："二、活动日程"（微软雅黑，加粗）
- **嵌套日程表**：时间 | 内容 | 讲者/专家（3 列）
  - 如有多个课程模块，首行合并标注模块名
  - 表头灰色背景

---

### 三、会议详细内容（按 meeting_mode 分支）

#### 模式：hybrid（线上+线下）

```
三、会议详细内容

[线上培训]
  - 线上理论课程列表（题目 + 讲者）
  - QUIZ 答题情况（参与人数 + 平均分 + 满分）
    （如有 Excel 路径，自动解析并附嵌套成绩表）

[线下培训]
  四、理论授课
    - 每个讲座一段：
      题目 | 讲者（医院）
      内容摘要（AI 根据 PPT 总结 | 用户提供）
    - PPT 照片嵌入（如有）

  五、模型操作与考核
    - 操作名称 + 概况描述
    - 考核统计：参与人数 / 平均分 / 满分
    - 嵌套成绩表（序号 | 姓名 | 省份 | 医院 | 得分）

  六、病例讨论（如有）
    - 每个病例：
      [题目] 发表人（医院）
      病例概述
```

#### 模式：offline（纯线下）

```
三、会议详细内容

  一、理论授课
    - 同 hybrid 线下部分

  二、模型操作与考核
    - 同 hybrid 线下部分

  三、病例讨论
    - 同 hybrid 线下部分
```

#### 模式：online（纯线上）

```
三、会议详细内容

  [每个会议环节一段]
    环节名称 | 讲者
    3-5 句话总结（AI 根据文字版转录提炼）
```

---

### 四、总结（v3.0 新版）

- **标题**："四、总结"（微软雅黑，加粗）
- **总参训人数**
- **学员反馈**：反馈人数 + 满意度平均分
- **各环节亮点**（分项列出）：
  - 授课亮点
  - 操作亮点
  - 病例讨论亮点（如有）
  - 线上课程亮点（如有）
- **改善建议**（如有）

---

### 结尾

- **合影照片**（如有）：居中，按文件名排序
- **签名区**：
  - 空行留白
  - 落款：[培训部门]（右对齐）
  - 日期

---

## 格式规范

| 元素 | 字体 | 字号 | 说明 |
|------|------|------|------|
| 标题（一二三四） | 微软雅黑 | 12pt | 加粗 |
| 正文 | 宋体 | 10.5pt | |
| 表格内容 | 宋体 | 9pt | |
| 表头 | 宋体 | 9pt | 加粗，灰色背景 |
| 活动报告书标题 | 微软雅黑 | 14pt | 加粗 |

- 表格边框：全边框（单线）
- 嵌套表格位于对应说明段落之后
- 分区标题行（如"会议基本信息"）：灰色底色 `#D9D9D9`
- 合影照片：居中，宽度不超过页面宽度
- 段落间适当留白

## v3.0 生成函数映射

| 文档区域 | 对应函数 | 说明 |
|---------|---------|------|
| 基本信息表 | `create_basic_info_table()` | 10行 × 2列 |
| 活动致辞 | `create_activity_opening()` | 标题 + 专家 + 主持 + 致辞 |
| 活动日程 | `create_schedule_table()` | 嵌套日程表 |
| 线上部分(hybrid) | `create_online_part()` | 课程列表 + QUIZ |
| 理论授课 | `create_lecture_section()` | 讲座 + PPT 摘要 |
| 模型操作 | `create_operation_section()` | 操作 + 成绩表 |
| 病例讨论 | `create_case_discussion_section()` | 病例列表 |
| 纯线上环节 | `create_online_sessions()` | 文字版总结 |
| 总结 | `create_new_summary()` | 分环节亮点 |
| 主调度 | `create_training_content_table()` | 按 meeting_mode 分发 |
