# 活动报告信息收集模板 v3.0

v3.0 核心升级：**三种会议模式公用一个统一模板**。根据会议类型选择对应模式，AI 会自动适配内容结构。

## 快速定位：我该选哪个模式？

| 会议形式 | 模式 | meeting_mode | 材料示例 |
|---------|------|-------------|---------|
| 全天线下理论+操作+病例讨论 | 纯线下 | `offline` | PPT照片 + 操作成绩 + 病例讨论材料 |
| LMS线上理论学习 + 线下操作 | 线上+线下 | `hybrid` | 海报 + QUIZ Excel + 线下操作成绩 |
| 纯线上培训/直播 | 纯线上 | `online` | 会议文字版转录 + 日程 + 参会名单 |

> 如不确定，默认使用 `hybrid`（最常见的胆胰双E培训形式）。

---

## 四种输入方式

1. **图片提取模式**（最省事）— 直接发海报/PPT照片/签到表/成绩表截图
2. **极简模式**（推荐）— 一句话 + Excel + 照片 + 关键词
3. **标准模式** — 逐项填写
4. **自由文本** — 自然语言描述

---

## 图片提取模式

直接把活动当天的材料拍照/截图发过来：

| 材料 | 提供形式 | AI 提取内容 |
|------|---------|------------|
| 日程海报 | 图片/截图 | 会议名称、时间、地点、专家、日程表、主办单位 |
| PPT 照片 | 图片/截图（逐页） | 讲座题目、讲者、内容摘要（2-3句话） |
| 签到表 | 照片 | 学员姓名、医院（潦草字迹标注 [?] 确认） |
| 考核成绩表 | **Excel 最可靠**，也可截图 | 姓名、医院、得分（自动排序、算平均分） |
| QUIZ Excel | Excel / 截图 | 参与人数、平均分、满分 |
| 病例讨论PPT | 图片/截图 | 发表人、医院、题目、病例概述 |
| 会议文字版 | 文本/Word | 线上会议各环节逐段总结 |
| 合影照片 | 文件夹路径 | 自动嵌入报告 |

**工作流程**：AI 提取 → 生成汇总表确认 → 用户纠错 → 生成报告。

## 极简模式（推荐）

### 一句话 + Excel + 关键词 + 照片

```

致辞专家：[姓名+医院]，主持人：[默认"[公司][培训部门]"]

专家：[姓名+医院]，多人的话分行

项目类型：[ERCP / EUS-FNA / ESD / 胆胰双E] → AI 自动生成项目介绍

日程：[未提供→AI提醒/从海报提取]

--- 以下按模式选填 ---
[hybrid 模式]
  线上课程+QUIZ：直接发 Excel → 自动解析
  PPT照片：发送线下理论授课PPT的截图 → AI逐页总结
  操作成绩：Excel 或 截图

[offline 模式]
  PPT照片：理论授课PPT → AI 总结
  操作成绩：Excel 或截图
  病例讨论：PPT照片 或 题目+发表人

[online 模式]
  会议文字版：粘贴完整文字转录
  日程：从文字版或海报提取

--- 通用 ---
关键词（3-5个）：[讲解详细、互动积极、理论结合实践]
合影照片：提供文件夹路径
参加员工：部门 + 姓名
```

## 标准模式（逐项填写）

### 一、会议基本信息

```
会议名称：[如：胆胰双E技术普及培训（春季班）北京站]
会议模式：[offline / hybrid / online]  ← v3.0 必填
主办单位：[如：[公司]（北京）× [合作单位]]
会议时间：
  - 线上：[如：5月11-16日（线上/LMS）]
  - 线下：[如：5月17日（线下，[培训中心]）]
会议地点：[如：LMS & [公司]北京医疗教育培训中心]
参会专家：[医院+姓名，多人分行]
会议规模：[如：ERCP 12人，EUS-FNA 15人]
参加员工：[部门：姓名，多部门分行]
项目介绍：[留空→AI自动生成]
课程类型：[ERCP / EUS-FNA / ESD / 胆胰双E]
```

### 二、活动致辞（v3.0 新增）

```
致辞专家：[姓名+医院，必填]
主持人：[姓名+单位，默认"[公司][培训部门]"]
致辞内容：[留空→AI自动生成开场致辞]
```

### 三、培训日程

```
时间 | 内容 | 讲者/专家
-----|------|----------
08:00-08:30 | 签到 | /
...
```

> 首选从日程海报图片自动提取。

  概述：[上传PPT→AI总结；或手动填写]

#### === 线上+线下 (hybrid) ===

先填写线上部分：

```

  课程 #1：《ERCP的器械准备及十二指肠镜操作技巧》— 讲者：张三

```

## Excel 格式要求

### 1. 操作考核成绩表

Excel 第一行为表头，支持以下列名（不区分大小写）：

| 必填 | 可选 | 说明 |
|------|------|------|
| 姓名 | 序号 | 不提供则自动按得分降序编号 |
| 得分 | 省份 | |
| | 医院 | |

支持的表头关键词：
- 序号: `序号` `编号` `No.` `No`
- 姓名: `姓名` `学员姓名` `名字`
- 省份: `省份` `省` `地区`
- 医院: `医院` `单位` `医院名称` `工作单位`
- 得分: `得分` `成绩` `分数` `操作得分` `Score`

> 成绩自动按降序排列，整数得分不显示小数位。

### 2. QUIZ 答题情况表

支持两种格式，自动识别：

**A. 明细表格式**（推荐）：
| 序号 | 姓名 | 省份 | 医院 | QUIZ得分 |
|------|------|------|------|----------|

**B. 汇总表格式**：
| 参与人数 | 平均分 | 满分 |
|----------|--------|------|

支持的表头关键词：
- 得分列: `QUIZ得分` `QUIZ成绩` `答题得分` `线上测试得分` `理论得分` `测验得分`
- 参与人数: `参与人数` `答题人数` `QUIZ人数`
- 平均分: `平均分` `QUIZ平均分` `均分`
- 满分: `满分` `总分` `QUIZ满分`

> 明细表会自动汇总参与人数和平均分。

### 3. 学员反馈统计表

支持两种格式，自动识别：

**A. 明细表格式**（推荐，可自动按课程分组统计）：
| 序号 | 姓名 | 课程 | 满意度评分 | 自信度提升 | 器械了解程度提升 |

**B. 汇总表格式**：
| 反馈人数 | 满意度评分 | 满意度满分 |
