# Research Workflow Orchestrator Skill

Lightweight public skill for coordinating local research work across multiple agents and tools.

## Purpose

This skill routes work, splits tasks only when needed, and keeps handoffs concise. It is intentionally minimal and is not a full project-management framework.

## What It Is For

- task routing
- light decomposition
- handoffs between agents
- simple status tracking
- local orchestration
- release preparation for reusable workflow behavior

## What It Is Not For

- long-term memory
- experiment logs
- manuscript storage
- project archive
- heavy project-control files

## Release Note

This is the public-facing version of the lightweight orchestrator. Keep wording generic and remove local assumptions before publishing.
