## Description: <br>
Build a personal project management system that scales from simple lists to structured planning. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[ivangdavila](https://clawhub.ai/user/ivangdavila) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
External users use this skill to organize personal, client, learning, and creative projects as local project folders with README, task, note, review, and archive guidance. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Local project notes may contain deadlines, collaborators, client contact information, rates, or billing notes if the user asks the agent to store them. <br>
Mitigation: Avoid storing sensitive information unless plain local files under ~/Clawic/data/projects/ are acceptable; review the project folder before sharing or backing it up. <br>
