# Knowledge Collector - 装备所知识收集系统

> 面向装备所55位同事的知识收集与共享工具

## 快速开始

### 方式1: 直接告诉AI
在美信中 @AI 说：
```
记录一条知识：[你的内容]
```

### 方式2: 群聊自动识别
当你在群里分享技术内容时，AI会自动识别并提示是否记录。

### 方式3: 批量导入
```
导入知识：D:\projects\my_docs\
```

## 知识分类

你的知识会自动归类到以下分类中：

| 方向 | 类型 | 层级 |
|------|------|------|
| 非标自动化 | 方案/设计/软件/算法 | L1方案~L4经验 |
| 物流自动化 | 方案/设计/软件/算法 | L1方案~L4经验 |
| 工业视觉 | 方案/设计/软件/算法 | L1方案~L4经验 |

## 什么内容值得记录？

- ✅ 项目方案总结（做完了别忘了沉淀）
- ✅ 设计选型经验（为什么选这个型号）
- ✅ 代码模块（可复用的功能块）
- ✅ 踩坑记录（别再踩第二次）
- ✅ 故障排查过程（下次遇到秒解决）
- ✅ 技术调研结论（省得别人再查一遍）

## 审核流程

1. 你提交知识 → AI自动分类+整理
2. 确认后直接入库
3. 研究室负责人收到通知，审核后标记为"已验证"
4. 全所同事可以检索使用

## 常见问题

**Q: 我的信息会泄露吗？**
A: 知识库仅在装备所内部使用，不会外传。

**Q: 分类错了怎么办？**
A: 入库前会给你预览，可以修改。入库后也可以联系负责人更正。

**Q: 批量导入支持什么格式？**
A: .md, .txt, .py, .st, .cpp, .pdf
