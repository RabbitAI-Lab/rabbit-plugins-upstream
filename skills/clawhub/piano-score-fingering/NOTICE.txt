Distribution note
-----------------

The research sources used to formulate the professional fingering guidance are
listed in references/professional-fingering-rules.md. The papers themselves are
not copied into or redistributed with this Skill.

The public package intentionally excludes general-purpose PDF libraries,
compatibility runtimes, compiled bytecode, process-launching tests, and sample
documents with external DTD declarations. Runtime scripts use the Python
standard library, do not access the network, and do not launch external
programs.

Keep this NOTICE.txt file with redistributed copies or substantial portions of
this Skill. Do not remove the PianoPlayer copyright or license notice from
PianoPlayer-derived source files.
