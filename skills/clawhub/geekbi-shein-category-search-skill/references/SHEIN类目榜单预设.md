# SHEIN 类目榜单查询预设

每次选择一个主预设，只补充站点、分页、用户明确的关键词或层级。不同层级类目通常不直接排名。

## 预设

### 热销类目

```text
sort=totalSold
order=desc
```

按累计总销量排序，不自动增加层级、时间或销量门槛。

### 蓝海类目

```text
sort=dsr
order=desc
```

至少同时检查总销量、月增长、商品数、店铺数和平均价格。蓝海指数是预计算信号，未知公式，不能单独作为进入依据。

## 补充方法

- 近期需求增长：按月销量或销售额增长率降序，并设置绝对量门槛。
- 需求增长快于供给：比较需求增长率与商品数、店铺数的对应 Rate；周期商品数、店铺数本身是均值，不是变化量。
- 半托管渗透：分别用半托管商品数/商品数、半托管店铺数/店铺数计算；分母为零或缺失时不计算。

默认入口 `1` 名称为“全部”但当前映射 `us`，不是跨站聚合；明确美国用 `2`。排序方向只用 `asc|desc`。
