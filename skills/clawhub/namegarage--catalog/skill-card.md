## Description:

Find published domains by project description or keywords and check their current prices. Use the anonymous public catalog interfaces when a user asks about domains for sale on this site.

This skill is ready for commercial/non-commercial use.

## Publisher:

[namegarage](https://clawhub.ai/user/namegarage)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to search Namegarage’s public domain catalog by project idea, keywords, budget, or TLD, then compare current prices and review listing details.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Search terms are sent to Namegarage.

Mitigation: Use general keywords and avoid confidential project details.

Risk: A catalog result or price does not reserve a domain or establish availability elsewhere.

Mitigation: Review the returned listing before a purchase decision; treat absence from this catalog as inconclusive.
