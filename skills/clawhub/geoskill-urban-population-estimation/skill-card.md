## Description:

Estimate population density from building volume, residential ratio, night-light correction and land-cover weights with total conservation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ruiduobao](https://clawhub.ai/user/ruiduobao)

### License/Terms of Use:

MIT

## Use Case:

Developers, GIS analysts, and urban researchers use this skill to run a local Python workflow that allocates a total population across raster cells from building volume, night lights, and land-cover weights.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security evidence reports under-disclosed network geocoding and broad credential-handling helpers, including a hardcoded Earthdata password.

Mitigation: Review before installing; remove or scope credential and network helpers, remove and rotate hardcoded Earthdata credentials, and document or disable network and cache behavior before use with sensitive credentials.
