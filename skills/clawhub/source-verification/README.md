# 信源甄别·反投毒信息过滤器 · WorkBuddy Skill

"被软文和垃圾信息源包围？AI 搜索时代内容农场泛滥，同一篇'TOP 榜单'通稿出现在几十个网站，融资额、估值、市场份额全是抄的。信源甄别在信息入口执行三层过滤（域名信誉→内容指纹→交叉验证），输出 P0/P1/P2 可信度分级，拦截营销通稿与内容农场，让调研、简报、选题只吃干净信息。内置信源黑白名单（持续维护），单一来源自动标注'待验证'，软文丢弃必留痕。适合自媒体调研、行业研究、资讯采集、内容创作前的信息源质检。Source credibility triage & content-farm filter."

## 解决什么问题

AI 搜索时代，内容农场和营销通稿泛滥：

- 同一篇"TOP 榜单"通稿出现在几十个不相干网站，数据全是抄的
- 融资额、估值、市场份额等关键数字给不出可溯源链接
- 标题乱码、多站雷同、通稿句式——批量软文的典型痕迹
- 搜索"哪个服务商最好"，前排全是投放软文，真实信息被埋

信源甄别在**信息入口**做三层过滤：域名信誉（黑白名单）→ 内容指纹（通稿识别）→ 交叉验证（双信源确认），输出 P0/P1/P2 可信度分级，软文丢弃必留痕。

## 安装

### WorkBuddy 技能市场（推荐）

在 WorkBuddy 中搜索「信源甄别·反投毒信息过滤器」一键安装。

### 手动安装

下载本技能目录，放入 `~/.workbuddy/skills/信源甄别/`，重启 WorkBuddy 即可。

### 环境依赖

无。纯规则型技能，无需 Python 环境、无需 API Key、无网络请求。

## 使用

对话中直接触发，无需命令：

- "帮我看看这个来源靠不靠谱" + 丢链接
- "核查一下这篇报道的信源"
- 任何引用外部信息的调研/简报产出前，可要求"先过一遍信源甄别"

技能会自动执行三层过滤，按 P0 采用 / P1 待验证 / P2 丢弃留痕 输出分级。
