# 信源甄别（信息入口反投毒组件）

> 定位：source-level（信源级）粗筛。判断"这个来源可不可信"。
> 与「事实核查」的分工：本组件管**入口**（信源分级），事实核查管**出口**（文案断言的逐条精核）。两者串联使用，不互相替代。
> 溯源：2026-10-18 GEO 赛道调研实战沉淀——该赛道 1200+ 服务商伴随海量软文农场，同一篇"TOP 榜单"通稿出现在数十个不相干域名，手工分级标记后固化为本组件。

## 1. 触发条件

满足任一即执行：

- 执行 WebSearch / 网页抓取 / 阅读用户提供的链接之后
- 产出引用外部信息的报告、简报、调研、榜单类内容之前（强制自检）
- 定时任务（午间简报、选题推荐、羊毛巡查等）拉取外部信息入池时

**不触发**：纯本地文件、桂皮的私人经验与原创观点、常识性问答。

## 2. 三层过滤流程

### 2.1 L1 域名信誉层（秒判）

读取 `信源黑白名单.md`，按域名匹配：

- **命中白名单** → 快速通道，直接进入 L3 交叉验证（跳过 L2）
- **命中黑名单** → 丢弃，但必须留痕（记录域名+命中原因）
- **未收录域名** → 按域名特征初判（"xx新闻网/快讯"模式、文库站、文档站、境外可疑镜像站标记为可疑），进入 L2

### 2.2 L2 内容指纹层（通稿识别）

逐项扫描，命中任意一项即降级为"存疑"：

1. **通稿句式**：高频出现"据悉""相关团队完成了""权威认证""首选推荐""TOP 榜单""当之无愧"
2. **数据无出处**：融资额、估值、市场规模、份额等关键数字给不出可溯源链接
3. **多站雷同**：同一文本出现在多个不相干域名（内容农场网络的铁证）
4. **编码异常**：标题乱码、字符集错乱——批量通稿采集错误的典型痕迹
5. **时间矛盾**：标注日期与内容事实冲突（如把旧闻当时闻发）

### 2.3 L3 交叉验证层（与「事实核查」衔接）

- 同一事实有 **≥2 个独立信源**一致 → 定级 P0
- 仅单一信源 → 定级 P1，标注"待验证"
- 信源互相矛盾 → 不定级，向桂皮呈现分歧双方口径，不强行结论

## 3. 信源黑白名单使用规则

- 文件：`信源黑白名单.md`（与本文件同目录）
- 时机：L1 层必读；新增信源域名先查名单再判断
- **维护铁律**：
  1. 名单变更必须经桂皮确认，**禁止自动追加**（防止名单本身被投毒——有人为推广自家官网而污染白名单）
  2. 每月复审一次白名单：抽查其近期内容是否已变质为软文渠道
  3. 黑名单条目需附"收录日期+收录原因"，无因可查的条目复审时清理
  4. 新域名默认进"观察区"，命中两次指纹特征才转黑名单

## 4. 输出契约（强制格式）

所有引用外部信息的产出，按以下分级呈现：

```
P0 采用：多源验证或官方一手源
P1 待验证：单一来源，标注"单一来源，待验证"
P2 已丢弃：软文/农场内容，留痕说明（域名+命中哪层规则）
```

**留痕是硬要求**：P2 丢弃不能静默删除，必须在产出中以一句话说明丢弃原因，便于桂皮复核判断尺度，也便于沉淀新黑名单条目。

## 5. 铁律

1. **不盲从白名单**：白名单媒体的具体栏目仍要过 L2（头部媒体发软文是常态）
2. **单一来源不出结论**：拿不到第二信源就标"待验证"，禁止用"据悉"糊弄
3. **技能只降风险，不防投毒**：三层过滤降低中招概率，终极防线是交叉验证
4. **时间成本控制**：紧急场景（定时任务）允许"P1 单一来源+标注"快速通道，不强制全量交叉验证
5. **不反向操作**：不得为迎合已有结论而挑选性信源；发现自有产出引用错误必须回头改

## 6. 与现有技能的关系

| 技能 | 关系 | 说明 |
|------|------|------|
| 事实核查 | 下游衔接 | 本组件定级 P0/P1 后，事实核查对文案断言做 statement-level 精核；顺序不可倒 |
| 时效复核 | 互补 | 时效复核管"数字过期没有"，本组件管"来源可不可信" |
| 内容事实性审核 | 同家族不同层 | 它属内容合规审核入口的发布前门控，本组件在信息入口更前置 |
| 资讯采集 | 上游 | 采集脚本后续可在入池环节调用 L1 域名过滤（阶段三规划） |
| 链接内容提取 | 并行 | 它管"拿全内容"，本组件管"信不信"，可先后调用 |

**协作链路**：资讯采集 → **信源甄别（入口分级）** → 事实核查（断言精核） → 内容输出
