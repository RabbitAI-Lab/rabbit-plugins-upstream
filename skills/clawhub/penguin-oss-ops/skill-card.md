## Description:

Provides Tencent-inspired open source operations guidance for project release decisions, governance, community building, contributor development, and project health metrics.

This skill is ready for commercial/non-commercial use.

## Publisher:

[qikairo7](https://clawhub.ai/user/qikairo7)

### License/Terms of Use:

MIT-0

## Use Case:

Open source program offices, maintainers, and community managers use this skill to plan when to open source a project, structure governance and collaboration, grow contributors, and evaluate community health. It does not provide license legal advice or project-specific technology selection.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may expect this guidance skill to perform GitHub write operations, which depend on a separate oss-workflow route.

Mitigation: Confirm the companion workflow is available and follow its checklist before handling issues, pull requests, comments, commits, pushes, or repository creation.
