## Known Risks and Mitigations: <br>
Risk: The skill runs local quantum_lab repository commands, including dependency installation, notebooks, demos, and local server startup. <br>
Mitigation: Confirm the exact subcommand before execution, review requirements.txt before any pip install, and use notebooks or the local server only when intended. <br>
