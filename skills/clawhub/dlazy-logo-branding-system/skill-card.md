## Description:

Guides stepwise logo design and brand identity development from a core mark through consistent variants and real-world applications.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Designers, brand teams, and other users develop a logo concept, gather feedback, and extend an approved mark into a consistent visual identity and branded assets.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and referenced media files are sent to dLazy cloud services for generation.

Mitigation: Review content and file sensitivity before submitting them to the service.

Risk: Using the dLazy CLI requires an API key and installing or running a third-party package.

Mitigation: Review the CLI source and package before use, prefer an on-demand invocation if avoiding a global install, and revoke or rotate the key when no longer needed.

Risk: The skill's instructions contain a 1.0.9 versus 1.2.3 CLI version mismatch and its supposed English file is not translated.

Mitigation: Confirm the intended CLI version before installing and consult the available Chinese instructions where necessary.
