## Description:

Guides a phased logo-design process from core mark concepts through consistent brand variants and visual applications.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Designers, brand teams, and other users can plan and develop a logo, review concepts, and extend a confirmed mark into a consistent brand identity and applications.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected media files are sent to dLazy cloud endpoints during generation.

Mitigation: Use the service only when those inputs are suitable for third-party processing; check selected files before sending.

Risk: Using the service requires an API key, which may be saved locally by the CLI.

Mitigation: Use an environment variable if persistent key storage is unsuitable, and protect or rotate the key as needed.

Risk: Installing or running the third-party CLI executes a separate package.

Mitigation: Verify the intended @dlazy/cli version and use the on-demand npx option if a persistent global installation is unwanted.
