## Description:

A professional pipeline for building everything from a core mark to a complete brand visual system, ensuring creative quality, execution consistency, and shippable delivery.

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: The workflow requires CLI authentication and setup of an external package, and the security review had partial coverage.

Mitigation: Review the CLI package and confirm it is the intended dLazy package before installing or authenticating.

Risk: Prompts and supplied media may be sent to dLazy hosted services for generation.

Mitigation: Avoid submitting confidential prompts or media unless they are approved for processing by the external service.
