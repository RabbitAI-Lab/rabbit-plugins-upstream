## Description:

A professional pipeline for building everything from a core mark to a complete brand visual system, ensuring creative quality, execution consistency, and shippable delivery.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Designers, brand teams, and other users can plan and iteratively develop a logo, its variants, and a coordinated brand identity system with approval at each phase.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The artifact mentions conflicting CLI versions, including 1.0.9 and 1.2.3.

Mitigation: Confirm the intended @dlazy/cli version before installing or running it.

Risk: Authentication may leave an API key stored in local CLI configuration.

Mitigation: Use DLAZY_API_KEY for temporary access if persistent storage is unwanted, and rotate or revoke the key when needed.

Risk: Logo prompts and supplied media may be sent to dLazy's hosted service.

Mitigation: Provide only prompts and assets you are comfortable sharing with that service.
