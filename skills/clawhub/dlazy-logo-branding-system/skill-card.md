## Description:

Guides a stepwise logo and brand identity workflow from initial concepts through consistent visual assets and applications.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Designers and brand teams use this skill to explore logo concepts, confirm a core mark, and develop consistent variants, social assets, and brand identity guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected media files are sent to dLazy cloud services.

Mitigation: Review what you submit and avoid sharing sensitive brand materials without authorization.

Risk: Installing and authenticating the external CLI creates package and credential exposure.

Mitigation: Review the CLI package before installation, prefer an environment-scoped install or npx when appropriate, and rotate or revoke unused API keys.

Risk: Conflicting version notes and unclear language behavior can cause incorrect expectations.

Mitigation: Confirm the installed CLI version and expected output language before relying on the workflow.
