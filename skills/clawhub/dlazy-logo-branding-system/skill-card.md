## Description:

Guides agents through stepwise logo creation and consistent brand identity design, from core marks to finished applications.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Designers, brand teams, and other users can plan and refine logos, then extend an approved mark into a coordinated brand system with generated visual assets.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installing and running an external CLI requires trusting the package and its service.

Mitigation: Review the dLazy CLI package and service before installation or use.

Risk: Prompts and selected local media can be sent to dLazy-hosted APIs.

Mitigation: Share only prompts and media approved for upload to the service.

Risk: Logging in can save an API key in the local CLI configuration.

Mitigation: Use DLAZY_API_KEY if you do not want the key saved in the CLI config file.
