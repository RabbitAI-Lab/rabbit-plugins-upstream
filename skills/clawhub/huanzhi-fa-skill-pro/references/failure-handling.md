# Failure 失败处理路径

## 场景 1：API / 依赖不可用
```
输入 → [检查依赖] → 不可用 → 重试 1 次 → 仍失败
  → 降级输出：使用本地规则逻辑（funding_diagnosis.py 无外部依赖）
  → 提示用户：「因外部服务不可用，已使用本地规则替代」
```

## 场景 2：输入无效
```
输入 → [格式校验] → 无效
  → 返回明确报错：「请在输入中包含 {X} 字段」
  → 提供示例模板
```

## 场景 3：输出校验失败
```
生成输出 → [validate_output()] → 失败
  → 重试 1 次 → 仍失败
  → 降级：输出部分结果 + 标注「部分字段因校验失败不可用」
```

## 场景 4：用户遇到情绪危机
```
情绪关键词触发 → [情绪支持模块]
  → 先共情 → 建议休息 → 持续3次未缓解 → 建议专业帮助
```

## 错误响应格式
```
系统当前无法完成此操作。
原因：[具体原因]
建议操作：[第一步做什么]
替代方案：[备用方案]
状态码：[A001/A002/A003/E001]
```
