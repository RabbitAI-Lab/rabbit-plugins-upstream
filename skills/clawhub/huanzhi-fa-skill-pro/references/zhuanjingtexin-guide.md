# 专精特新申报指南 — 完整路径图
> 焕智AI FaSkill Pro — OPC初创企业AI融资顾问

## 晋升阶梯

```
创新型中小企业（第一步）
    ↓ 6-12个月
专精特新中小企业（第二步）
    ↓ 12-18个月
专精特新「小巨人」（第三步）
    ↓ 18-24个月
国家重点「小巨人」→ 最高600万奖补（终极目标）
```

## 各层级核心指标

### 创新型中小企业
- 研发投入占比≥3%
- 研发人员占比≥10%
- 知识产权数量≥1项
- 主营收入增长率≥10%
- 主营业务收入占比≥70%
- 评分≥60分

### 专精特新中小企业
- 细分市场年限≥2年
- 研发费用总额≥100万
- 研发投入占比≥3%
- 上年度营收≥1000万
- 知识产权：1项发明或2项实用新型
- 评分≥60分

### 专精特新「小巨人」
- 细分市场年限≥3年
- 主营业务收入占比≥70%
- 上年度营收≥1亿
- Ⅰ类知识产权≥2项发明专利
- 近2年营收增长率≥5%
- 全国市场占有率≥10%（或细分领域前三）
- 评分≥70分

## 关键时间节点
- 创新型中小企业：每月开放申报
- 专精特新中小企业：每年1-2批
- 小巨人：每年1批（通常3-4月）
- 国家重点小巨人：每年1批（通常联合申报）

## 材料清单
1. 营业执照
2. 审计报告（近2年）
3. 纳税证明
4. 知识产权证书
5. 研发项目清单
6. 研发人员花名册
7. 社保缴纳证明
8. 主导产品说明
9. 细分市场占有率说明（小巨人需）
10. 为大企业配套证明（小巨人需）
11. 质量管理体系认证（小巨人需）

## 奖励汇总
- 创新型中小企业：无直接奖励
- 专精特新中小企业：各区10-30万奖励
- 专精特新「小巨人」：国家+各区合计最高600万奖补
- 国家重点「小巨人」：中央财政+地方配套合计最高1000万

## 注意事项
- 政策以政府最新公布为准
- 申报前务必核实官方文件
- 建议提前6-12个月准备材料
- 知识产权发明专利需提前1-2年布局
