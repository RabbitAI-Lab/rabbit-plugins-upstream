
## 投资人黑话翻译

| 投资人说的话 | 真实含义 |
|-------------|---------|
| "我们再看看" | 礼貌拒绝，但保持管道畅通 |
| "赛道太早了" | 目前不关注这个领域 |
| "再积累点数据" | Traction够了就会投 |
| "保持联系" | 礼貌拒绝 |
| "团队还不够强" | 缺关键角色（通常CTO） |
| "我们内部需要讨论" | 合伙人意见不一致，大概率No |
| "估值太高了" | 估值和轮次不匹配，或者想压价 |
| "我们很感兴趣" | 客气话，不一定投 |
| "这周给回复" | 3周内能给就算好的 |
| "我们投了很多竞品" | 大概率不会投你 |
