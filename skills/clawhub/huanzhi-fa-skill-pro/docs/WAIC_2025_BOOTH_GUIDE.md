## 软件准备

### 演示电脑

```bash
# 1. 安装Ginkley UGS
curl -fsSL https://ginkley.ai/install.sh | bash

# 2. 克隆FaSkill Pro
git clone https://github.com/ginkley/huanzhi-fa-skill-pro.git
cd huanzhi-fa-skill-pro

# 3. 验证所有脚本
python3 scripts/funding_diagnosis.py '{"mau": 50000, "monthly_revenue": 200000}'
python3 scripts/policy_matcher.py '{"district": "徐汇区", "sector": "AI智能体", "stage": "刚注册"}'
python3 scripts/zhuanjingtexin_assessor.py '{"company_name": "演示公司", "rd_ratio": 0.15}'

# 4. 运行测试
python3 -m pytest tests/ -v

# 5. 加载到Ginkley
ginkley load huanzhi-fa-skill-pro
```

### 平板电脑

```bash
# 安装Ginkley App（移动端）
# 或使用浏览器访问 https://ginkley.ai/app
```

## 应急方案

| 问题 | 解决方案 |
|------|----------|
| 网络断连 | 切换手机热点，使用离线版（所有脚本纯Python，无需联网） |
| 设备故障 | 备用电脑/平板立即顶替 |
| 人流过大 | 引导扫码，后续线上使用 |
| 人流过少 | 主动邀请周边展台交流，演示录像循环播放 |
| 技术问题 | 现场无法解决→记录问题，会后回复 |
