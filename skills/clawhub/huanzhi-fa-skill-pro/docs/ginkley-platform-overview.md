## 什么是 Ginkley UGS？

Ginkley UGS（User-Generated Skills）是一个让每个人都能构建、分享、组合AI技能的开放平台。

就像Web 2.0时代用户生成内容（UGC）改变了互联网一样，Ginkley相信AI时代用户生成技能（UGS）将改变人与AI的协作方式。

### 核心理念

```
智能不应该是碎片化的调用，
而是可以生长、组合、传递的技能。
```

### 基本单元

**`.skill`** — 每一个技能都有名字、有结构、有边界

- 开发者可以像整理思想一样整理AI
- 构建属于自己的智能体系
- 从一个技能到完整的Agent
- 从个人工作流到团队协作网络

## 开始使用

### 1. 安装Ginkley
```bash
# macOS / Linux
curl -fsSL https://ginkley.ai/install.sh | bash

# Windows
iwr -useb https://ginkley.ai/install.ps1 | iex
```

### 2. 创建一个Skill
```markdown
# SKILL.md
name: my-first-skill
description: 我的第一个技能
version: 1.0.0
author: "@你的名字"
```

### 3. 发布到商店
```bash
ginkley publish
```

### 4. 在对话中使用
```
Ginkley，帮我加载 my-first-skill
```
