## 快速上手

### 第一步：启动Skill

在Ginkley UGS平台中，输入以下任一指令启动FaSkill Pro：

```
"帮我看看融资准备度"
"我想查政策补贴"
"我被投资人拒绝了"
"分析一下这个TS条款"
```

### 第二步：对话引导

首次使用时，FaSkill Pro会问你4个问题建立画像：

1. **公司阶段**：刚注册 / 有产品 / 有收入 / 准备融资 / 已融资
2. **融资经验**：首次 / 有过 / 有成功退出
3. **沟通风格**：直接/详细/简短
4. **使用频率**：偶尔/每周/每天

### 第三步：选择模块

根据你的需求，直接说出触发词：

| 模块 | 触发词 | 示例 |
|------|--------|------|
| 🩺 融资诊断 | "看看准备好了吗" | "看看我的项目准备好了吗" |
| 🛡️ TS条款 | "TS" "条款" | "投资人要求2x清算优先权" |
| 🧠 Capital EQ | "焦虑" "被拒" | "又被拒了，感觉没戏" |
| 🏛️ 政策雷达 | "政策" "补贴" | "上海AI公司能申请什么补贴" |
| 🤝 FA撮合 | "找FA" | "帮我找个FA" |
| 📊 投后管家 | "投后" "下一轮" | "帮我看看什么时候准备下一轮" |

## 常见问题

### Q: 融资诊断准吗？
A: 诊断基于8个维度、行业基准和确定性算法，相同输入始终产生相同输出。但请注意：**诊断结果是参考，不保证融资成功**。

### Q: 政策补贴信息是最新的吗？
A: 政策数据库定期更新，但**以政府最新公布为准**。申报前请务必核实官方文件。

### Q: FA撮合怎么收费？
A: FaSkill Pro本身**不收费**。FA撮合模块仅做信息匹配，后续FA服务费用由用户和FA机构自行协商。

### Q: 上传的文件安全吗？
A: 建议上传前**脱敏处理**。本Skill不存储用户敏感信息。

### Q: 支持英文吗？
A: 支持中英双语。用英文提问会得到英文回复。

## 最佳实践

### ✅ 使用建议
- **提供越多数据，诊断越准确**：月活、收入、团队、融资额等
- **明确你的区域**：政策匹配需要知道注册区域
- **诚实面对情绪**：Capital EQ模块是安全的情绪出口

### ❌ 注意事项
- 不要上传**含敏感个人信息**的文件
- 不要依赖本Skill做**最终法律/财务决策**
- 不要期望**承诺融资成功**——这是任何FA都无法保证的
