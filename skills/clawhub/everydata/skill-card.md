## Known Risks and Mitigations:

Risk: External data retrieval and AI processing may expose submitted records to a service that retains request parameters and service logs.

Mitigation: Exclude sensitive records unless authorized, and review EveryInfra’s privacy policy before submitting data.

Risk: Paid API calls may incur usage costs.

Mitigation: Limit the API key to needed products and check current catalog prices before calling APIs.
