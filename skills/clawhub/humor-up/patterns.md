# Pattern construction detail

Read this before composing anything longer than a one-liner, or when the quick
table in SKILL.md isn't enough. Each pattern: how to build it, and the failure
mode that kills it.

## Misdirection 误导反转
Build: find a phrase with a hidden second meaning → write a setup where only
the obvious meaning is visible → one short clause forces the hidden reading →
reveal word last. Fails when: the reveal arrives early, or the hidden meaning
needs explaining.

## Literal reading 字面理解
Build: pick a dead metaphor or boilerplate everyone reads on autopilot → treat
it as literally, bureaucratically true → state one airtight absurd consequence,
deadpan. Fails when: you wink. The moment the narrator signals "joke," the
logic collapses. (弱智吧式:"在线等,挺急的" is deadpan's Chinese uniform.)

## Escalation 顺势夸张
Build: start from something true → escalate along the premise's OWN axis, not
sideways → stop one beat after it breaks; last step concrete and visualizable.
Fails when: random absurdity replaces the premise's logic, or you over-escalate
into noise.

## Understatement 轻描淡写
Build: pick a failure with emotional weight → find the most bureaucratically
positive frame for it ("保值", "mint condition") → deliver with zero commentary.
Fails when: you add a sad-face beat after. The reader must do the emotional
math themselves.

## Wordplay / pun 双关·谐音梗
Build: only when BOTH meanings are simultaneously true of the situation → the
surface reading must be a complete natural sentence → never bend grammar to
force the sound. Fails when: only the sound matches (强行谐音 = 谐音梗扣钱).
Test: if either meaning is irrelevant, cut the joke.

## Rule of three 三段式
Build: items A and B same category, tone, and grammatical shape → item C same
shape, opposite content, usually self-incriminating → C is the shortest.
Fails when: the pattern breaks on item two (no tension), or C runs longer
than A+B.

## Analogy 神比喻
Build: two far-apart domains → each mapped detail true of BOTH → end on the
most damning correspondence. Fails when: the mapping is decorative — if any
other domain could substitute, the analogy isn't working.

## Reversal 身份反转
Build: name the official relationship → show one concrete behavior that only
makes sense inverted → let the reader infer the flip. Fails when: you announce
it ("so really WE work for THEM!").

## Self-deprecation 自嘲
Build: set up a small vanity → contradict with evidence, not confession →
keep affection for the narrator. Fails when: it tips into self-pity; "I'm such
a failure lol" has no specific detail and no warmth.

## Anti-joke 反笑话
Build: use a recognizable joke frame so the reader braces for wordplay →
answer with unadorned truth, slightly darker than expected → the missing twist
IS the twist. Fails when: the flat answer is merely boring instead of
pointedly true.

## Hyper-specific detail 细节暴击
Build: broad shared experience → zoom into one detail so precise it feels like
surveillance ("备注少冰", the desk–watercooler–badge-reader loop) → the detail
quietly indicts the narrator. Fails when: too niche for the audience to
picture instantly.

## 歇后语 (two-part allegorical saying)
Build: one vivid concrete scene —— a verdict carried by homophone or metaphor.
Modern deployment: classic form, modern topic ("年终奖问HR——泥菩萨过江").
Fails when: the second half restates the scene instead of resolving it at a
different level.

## Callback 回环
Build (multi-joke sets only): plant an element doing normal work early →
re-summon it at the close where its meaning has soured or flipped. Fails when:
the audience doesn't remember the plant, or the return repeats instead of
recontextualizing.

## Parallel deflation 对仗泄气 (中文)
Build: clause one with positive accounting (省了三千) → clause two, identical
grammar, opposite ledger (花了八千) → optional shortest third beat as verdict
(赚的是感觉,亏的是余额). Fails when: the parallelism breaks — the grammar of
both clauses must match exactly.
