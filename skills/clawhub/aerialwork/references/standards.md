# 标准与法规清单

> 引用条款前必须核对标准最新版本与原文；以下条目为选型/计算常用基础框架，版本号标注置信度较高的现行版本。

## 1. 设计与安全(核心)

| 标准 | 覆盖 | 用途 |
|---|---|---|
| GB/T 25849-2010《移动式升降工作平台 设计、计算、安全要求和试验方法》 | MEWP 设计计算、稳定性、结构、液压电气、试验 | 国内设计计算书主依据 |
| EN 280:2013+A1:2015 | MEWP 设计计算、安全要求、试验方法 | GB/T 25849 的技术参照；出口欧盟 |
| ANSI/SAE A92.20 | MEWP 设计计算与试验 | 出口美国 |
| ANSI/SAE A92.22 | MEWP 安全使用(操作、培训) | 美国市场使用合规 |

要点概念(计算书必须体现)：
- **稳定性**：按标准规定的载荷组合、倾翻线位置、试验系数核算；GB/T 25849 与 EN 280 对静、动稳定及试验加载有明确规定，系数以原文为准。
- **设计风速**：MEWP 工作状态设计风速通常取 **12.5 m/s(约 6 级风)**，具体限值以标准原文与机器铭牌为准。
- **结构强度试验**：平台额定载荷过载试验系数、结构应力与变形限值按标准条款执行。
- **安全装置**：急停、倾斜保护、限位/限幅、载荷限制、防坠落/围栏、下降阀(液压锁)等配置与验证。

## 2. 车载式高空作业车(道路车辆属性)

| 项目 | 说明 |
|---|---|
| GB/T 9465-2018《高空作业车》 | 车载式高空作业车产品标准 |
| 车辆公告 | 车载式作为专用汽车须进入道路机动车辆产品公告方可销售上牌，改装须由具备资质企业完成 |
| 驾驶证 | 驾驶车载高空作业车按对应车型驾驶证要求(一般 C 类以上，以车管部门认定为准) |
| 行驶/作业状态转换 | 作业时支腿、回转等安全联锁与说明须符合说明书与标准 |

## 3. 边界：是否属于特种设备

- 自行式/拖式 MEWP(剪叉、臂式、桅柱、蜘蛛)一般**不属于**《特种设备目录》起重机械范畴；
- 流动式起重机(汽车起重机等)属特种设备，与车载高空作业车是不同设备类型；
- 起重机械制造许可事项以现行目录与主管部门解释为准，涉大吨位复合车型先与属地市场监管部门确认。

## 4. 结构/液压/电气通用标准(设计输入引用)

| 标准 | 用途 |
|---|---|
| GB/T 3811《起重机设计规范》 | 臂架类结构设计与载荷组合可借鉴 |
| GB 50017《钢结构设计标准》 | 钢结构强度、稳定、疲劳 |
| GB 50009《建筑结构荷载规范》 | 风载荷(基本风压 w₀=v²/1600 kPa) |
| GB/T 1591《低合金高强度结构钢》(Q355 等) | 结构板材 |
| GB/T 3766《液压系统通用技术条件》 | 液压系统设计 |
| GB/T 7935《液压元件 通用技术条件》 | 泵、阀、缸、马达 |
| GB 5226.1《机械电气安全 机械电气设备 第1部分：通用技术条件》 | 电控回路 |
| ISO 13849-1 | 安全相关控制回路性能等级(PL)评估 |

## 5. 认证与出口(涉出口项目时)

- 欧盟：机械指令/机械法规框架下的 CE、EN 280 合规；噪音与发动机排放适用欧盟阶段要求。
- 北美：ANSI/SAE A92 系列；发动机排放适用 EPA/加州 CARB 阶段要求；车载式另涉 FMVSS/DOT。
- ISO 16368(移动式升降工作平台相关国际标准族)与各国采用情况以最新有效版本为准，涉认证前逐项核对。

## 6. 行业组织与培训

- IPAF(International Powered Access Federation)：全球高空作业设备行业组织，发布全球市场年报与操作培训体系(PAL 等)，其统计是行业销量/租赁渗透率的常用引用源。
- 中国工程机械工业协会装修与高空作业机械分会：国内行业统计与活动。
