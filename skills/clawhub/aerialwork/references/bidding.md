# 招投标信息检索与标书作业指南

## 1. 招标信息渠道清单

| 平台/渠道 | 覆盖 | 建议用法 |
|---|---|---|
| 中国招标投标公共服务平台(cebpubservice) | 法定招标公告汇总 | 按项目名称关键词检索，查招标文件原文链接 |
| 全国公共资源交易平台及各省分平台 | 工程建设、政府采购 | 按地域筛选，适合查本地主机厂/园区项目 |
| 中国政府采购网(ccgp.gov.cn) | 政府采购意向与公告 | 提前锁定政采意向公开 |
| 央企电子招标平台(国网、国铁、中石化等) | 央企集中采购 | 需注册供应商库，提前做准入 |
| 第三方标讯平台(千里马、剑鱼、乙方宝、比地、中国采购与招标网等) | 聚合与订阅 | 做关键词订阅和补盲，线索仍需回源官方平台核验 |
| 成交/中标公示 | 真实中标价与供应商 | 价格情报与竞对跟踪的核心来源 |

## 2. 检索策略

1. **关键词组合**：`高空作业平台 / 高空作业车 / 登高车 / 升降平台 / 举升车` × `采购 / 租赁 / 维保 / 维修改造` × 地域(省市/园区/项目名)。
2. **多平台交叉**：官方平台定标讯时效，第三方平台做订阅提醒；同一项目核对两处以上防止信息失真。
3. **中标公示跟踪**：记录中标人、中标价、型号配置，形成竞对价格带画像(区分采购价/租赁价/含税费口径)。
4. **订阅动作**：对长期跟踪类任务建议每周固定检索频次并增量去重(收到"定期帮我盯某地区高空作业平台招标"类指令时，用自动化任务实现)。

## 3. 标书结构要点

### 资格审查部分
- 营业执照、ISO 9001/14001/45001、同类项目业绩(合同/验收单)、产品检测报告(有资质检测机构出具)、财务与信用记录(信用中国、裁判文书、被执行信息核查)。

### 技术标
- 技术参数响应表(逐条响应+偏离说明，格式见 assets/bid_response_template.csv)；
- 技术方案：设备配置清单、安全装置与标准符合性说明、安装调试与验收方案、培训计划、售后网点与 SLA；
- 涉安全标准引用 EN 280/GB/T 25849/ANSI A92 符合性声明。

### 商务标
- 分项报价：整机、运输、保险、培训、备件包、质保期后维保费；
- 付款方式、质保期、培训人天数、违约条款逐项评估。

## 4. 控制项与风险识别(投标前必做)

| 风险项 | 特征 | 应对 |
|---|---|---|
| 指定品牌/型号 | 参数唯一指向某品牌 | 评估偏离说明与质疑可行性，记录证据 |
| 门槛筹码化 | 注册资本、业绩数量/金额、指定检测机构 | 逐条核对资格自查，不可控项提前放弃 |
| 围标串标 | 报价离奇趋同、保证金来源集中 | 不参与，留档记录 |
| 废标条款 | 封装、授权、保证金、格式 | 编制废标项检查表逐项签字 |
| 不平衡报价 | 清单漏项、单价畸高/畸低 | 招标方复核；投标方控制单价结构 |

## 5. 报价策略要点

- 成本拆分：整机出厂成本+运输+保险+培训+备件+质保准备金；
- 竞对价格带来自中标公示(注意配置差异与是否含租赁/服务)；
- 租赁标注意计费模式(台班/月租/季度)、进退场费、燃油/电费承担、维保响应 SLA、停租条件；
- 报价调整空间与下调底线分层列明，输出时给"报价-毛利"敏感性简表。
