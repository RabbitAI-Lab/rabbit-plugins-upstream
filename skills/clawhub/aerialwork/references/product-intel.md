# 产品信息收集与竞品分析方法

## 1. 信息源分层(按可信度排序取数)

| 层级 | 来源 | 用途 | 注意 |
|---|---|---|---|
| 一手 | 厂商官网/官方样本库(Spec Sheets)、新品发布会、上市公司年报/公告 | 参数、型号谱系、战略与产能 | 样本参数为厂标值，注明下载日期 |
| 行业协会 | 中国工程机械工业协会装修与高空作业机械分会、IPAF 年报 | 行业保有量、租赁渗透率、销量趋势 | IPAF 全球年报是海外销量统计的常用引用源 |
| 媒体与展会 | 行业媒体(international Access / Vertikal.net 等)、bauma China、APEX、ARA Show 展商名录 | 新品、市场格局、厂商动态 | 展会报道常为提前披露，需与样本核对 |
| 贸易数据 | 海关进出口编码数据、上市公司披露 | 出口量价、区域结构 | 注意 HS 编码归并问题 |
| 价格情报 | 招投标成交公示、租赁商公开报价、经销商渠道价 | 真实成交价带 | 成交公示是最接近真实的价格源，注意配置差异 |

## 2. 品牌谱系(定位参考，信息随时间变动，输出时标注获取日期)

| 区域 | 品牌/厂商 | 备注 |
|---|---|---|
| 美系 | JLG(Oshkosh 旗下)、Genie(Terex 旗下)、Snorkel | 臂式(曲臂/直臂)产品线全 |
| 加系 | Skyjack(Linamar 旗下) | 剪叉为主，成本与周转口碑较好 |
| 欧系 | Haulotte(法)、Niftylift(英)、CTE(意)、Ruthmann(德，车载/履带) | 欧洲本土与消防/特种渠道 |
| 德/意 蜘蛛车 | Teupen(德)、Multitel(意)、Palazzani(意) | 蜘蛛式细分强势 |
| 国产头部 | 浙江鼎力、星邦智能(SinoBoom)、徐工 XCMG、中联重科、临工重机(LGMG)、柳工 | 臂式+剪叉全谱系，出口增长快 |
| 其他国产 | 京城重工、美通重工等及区域厂商 | 细分与性价比市场 |

> 厂商并购、股权、中文名会变动；正式输出前至少核对一次官网/最新公告。

## 3. 产品档案模板(逐产品一张卡)

```
品牌/厂商：
机型系列与整机型式(剪叉/曲臂/直臂/桅柱/蜘蛛/车载)：
平台高度 / 作业高度：
额定载荷(平台/延伸平台)：
水平伸距、跨越能力：
整机质量 / 轴距轮距 / 外形尺寸：
驱动形式与能源(柴/电/锂电/混动)：
爬坡能力、转弯半径、轮胎形式：
安全装置清单(急停/倾斜/限位/载荷/液压锁)：
控制与通信(选装件、车队管理终端)：
价格带(来源+日期)：
目标市场与交付情况：
信息来源与获取日期：
```

## 4. 竞品对比方法

1. **同口径**：同平台高度档、同载荷档、同作业型式对比；不同口径合并比较时先换算作业高度。
2. **固定维度**：性能(平台高度/伸距/载荷)→ 尺寸与通过性 → 质量与地面承载 → 能源与续航 → 安全配置清单 → 价格(标注来源) → 交付周期 → 售后网点 → 二手机残值。
3. **差异验证**：关键差异参数须回源(样本 PDF 原文或第三方检测报告)，不允许凭印象写差异。
4. **版本控制**：同机型有前代/改款时标注区分(如 Genie XC/XC3 系列与旧款代次)，摘录样本年份。

## 5. 输出规范

- 每个数据点格式：`数值 + 来源(样本/年报/公示) + 获取日期`。
- 区分三类数据口径：厂标值 / 检测报告值 / 市场成交值。
- 行业规模/销量引用 IPAF 或协会口径时，写明"IPAF 口径/协会口径"，不把不同口径混算。
