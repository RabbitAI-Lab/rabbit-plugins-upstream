# 高空作业平台(MEWP)专业工作流

## Overview

本技能把高空作业平台(MEWP, Mobile Elevating Work Platform)的典型工程与商务任务固化为四条可复用工作流：**选型(A)、工程计算(B)、产品信息收集(C)、招投标信息检索与标书(D)**。用户为中国叉车/高空作业机械研发工程技术人员时，输出须符合其既有质量要求：数据真实、公式与表格齐备、型号与信号级细节具体、拒绝表面化分析。

## 工作流决策树

| 用户意图 | 走哪条模块 |
|---|---|
| 该买/租什么机型、工况匹配、机型对比、品牌建议 | 模块A → references/selection.md |
| 稳定性、结构强度、风载、电机、液压、油缸校核、出设计计算书 | 模块B → scripts/mewp_calc.py + references/standards.md |
| 查机型参数、品牌谱系、行业销量数据、竞品档案 | 模块C → references/product-intel.md |
| 找招标公告、筛项目、编标书、控标项与报价分析 | 模块D → references/bidding.md |
| 标准条款、法规边界(特种设备/公告/驾驶证)、认证出口 | references/standards.md |

## 通用准则(所有模块必须遵守)

1. **数据真实优先**：参数、价格、销量必须来自标准原文、厂商官方样本、权威数据源或官方公告，并标注"来源+获取日期"。无法核实的项必须显式标注"待核实"，严禁虚构具体型号参数、价格或业绩。
2. **结论先行**：输出先给结论/推荐，再给依据过程。选型与标书类结论用表格承载；技术类输出给出公式、代入值与中间结果。
3. **安全类计算只定位为"初算"**：稳定性、结构强度等安全攸关结果，必须提示按标准原文与具备资质机构复核；脚本中默认的安全系数、载荷组合标注为"提示值，需按标准核定"。
4. **单位与口径**：统一公制。高度区分"平台高度"与"作业高度"(作业高度≈平台高度+2 m 人体高度)；载荷单位 kg/kN；压强 MPa/bar；风速 m/s。财务默认人民币。
5. **术语规范**：MEWP=移动式升降工作平台；剪叉式(scissor)、曲臂式(articulated)、直臂式(telescopic/直臂)、桅柱式(mast/垂直桅柱)、车载式(truck-mounted 高空作业车)、蜘蛛式/履带式(spider/crawler)。

## 模块A：选型

执行步骤：

1. **收集工况输入清单**（缺项先问，不要默认）：最大作业高度、水平伸距需求、额定载重(含人数与工具)、室内/室外、地面条件(水泥地/沥青/淤泥/软弱地面/楼板阳台)、门口与通道净宽净高、转场方式(自行/拖车/车载)、坡度、使用频次、能源偏好(锂电池/柴油/交流电)、特殊要求(无痕轮胎、越障、绝缘、防爆)。
2. **机型匹配**：按 references/selection.md 的决策矩阵进行初筛，给定 2–3 个备选机型并说明取舍理由；禁止只给单一机型。
3. **关键参数核对**：平台高度 vs 作业高度换算、额定载荷余量(人员+材料)、稳定系数与支腿跨距、最小离地间隙与转弯半径、爬坡能力(按工况坡度)、整机质量与地面承载(楼板/阳台按 kN/m² 校核)、驱动与轮胎形式、续航与充电条件、道路行驶需求(车载式涉公告与驾驶证问题)。
4. **品牌与配置建议**：按用户预算与交付周期分层推荐(海外高端/国产头部/性价比)，对比表须含：平台高度、额定载荷、水平伸距、整机质量、外形尺寸、驱动能源、质保、交付周期、价格带(标注来源，"待核实"可接受)。
5. **全寿命视角**：大额或长期项目补充购置 vs 租赁对比(台班/月租价、维保成本、残值、资金占用)。

## 模块B：工程计算

1. **先跑脚本初算**，再人工/标准复核：

```bash
# 稳定性初算(稳定力矩/倾翻力矩比)
python scripts/mewp_calc.py tipping-check --mass 3200 --span 2.4 --cg-arm 1.05 --load 300 --reach 3.2
# 风载荷
python scripts/mewp_calc.py wind-load --speed 12.5 --area 3.5 --coef 1.3
# 电机功率校核(扭矩法)
python scripts/mewp_calc.py motor-check --torque 220 --speed 2400 --rated 75
# 液压油缸出力与泵系统校核
python scripts/mewp_calc.py hydraulic-check --pressure 24 --bore 100 --rod 56 --flow 40
# 油缸缸径选型与压杆稳定校核
python scripts/mewp_calc.py cylinder-size --load 80 --pressure 24 --stroke 900 --mount pinned
```

2. **脚本边界**：脚本只做确定性工程初算，输出含公式与中间量便于复核；不替代标准条款、不替代整车公告与认证计算。
3. **设计计算书结构**（用户要求出正式计算书时按此组织）：总体参数与设计输入 → 载荷与载荷组合 → 整机稳定性 → 结构强度(臂架/剪叉/平台/车架，含焊缝与销轴) → 液压系统(泵、阀、油缸、马达) → 电气与安全回路(急停、限位、倾斜保护、载荷传感，按 GB 5226.1/ISO 13849-1 思路) → 电机选型(S2/S9 工作制裕量) → 结论与风险提示。所有系数必须写明出处或"按标准条款核定"。
4. **标准对照**：计算依据条款对照 references/standards.md 中的 GB/T 25849-2010、EN 280:2013+A1:2015、ANSI/SAE A92.20 逐条核对。

## 模块C：产品信息收集

1. **按 references/product-intel.md 的信息源分层取数**：一手(厂商官网样本/发布会/公司公告)、二手(行业协会、行业媒体、展会)、数据(IPAF 全球年报、中国工程机械工业协会、海关出口)、价格情报(招投标成交公示、租赁商公开报价)。
2. **产品档案模板**（每条产品输出结构化卡片）：品牌/厂商、机型系列、整机型式、平台高度、额定载荷、水平伸距、整机质量、外形尺寸、驱动能源、爬坡能力、安全装置清单、价格带(注明来源与日期)、目标市场与交付情况。
3. **竞品对比方法**：同平台高度同吨级对比，对比维度固定(性能/尺寸/质量/安全配置/价格/交付/售后网点)，差异项注明验证来源与时间。
4. **数据时效**：品牌归属、型号谱系、销量数据会变动，输出须标注获取日期，并提示以官网最新样本为准。

## 模块D：招投标信息检索与标书

1. **检索渠道**：按 references/bidding.md 的平台清单，用"高空作业平台/高空作业车/登高车/升降平台 + 采购/租赁/维保 + 地域"组合检索，优先中国招标投标公共服务平台、全国公共资源交易平台、中国政府采购网及央企电子招标平台；第三方标讯平台做订阅与补盲。成交公示是中标的真实价格情报源。
2. **标书要点**：资格条件自查(营业执照、体系认证 ISO 9001/14001/45001、同类业绩合同、检测报告、财务与信用记录)；技术标编制(技术参数响应表逐条响应、偏离说明、安装调试与培训、售后网点与响应 SLA)；评标前先识别控制项(指定参数、注册资本、业绩门槛、指定检测机构)并评估围标风险；报价按"整机+运输+保险+培训+备件"拆分，提示不平衡报价与废标条款风险。
3. **交付物**：输出投标响应一览表 + 技术方案框架 + 控标项与风险提示清单，均用表格承载。
