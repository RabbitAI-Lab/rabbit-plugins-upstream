# 验收标准

## 功能验收

| 编号 | 验收项 | 验收标准 | 优先级 |
|------|--------|---------|--------|
| AC-1 | 实例列表查询 | `list` 子命令可列出当前账号下所有 RDS 实例，返回 JSON 格式 | P0 |
| AC-2 | 单实例详情查询 | `show <instance-id>` 子命令可查询指定实例的完整详情 | P0 |
| AC-3 | 监控指标查询 | `metrics <instance-id>` 子命令可查询 CPU/内存/磁盘指标 | P0 |
| AC-4 | 能力列表 | `capability-list` 子命令返回 Skill 名称、版本和能力清单 | P0 |
| AC-5 | --help 输出 | `--help` 显示所有子命令和参数说明 | P0 |

## 可靠性验收

| 编号 | 验收项 | 验收标准 | 优先级 |
|------|--------|---------|--------|
| RE-1 | 凭据缺失场景 | AK/SK 未配置时退出码 3，输出明确错误信息 | P0 |
| RE-2 | 无效实例 ID | 查询不存在的实例 ID 时返回错误信息 | P0 |
| RE-3 | API 超时 | API 超时时输出错误信息，不崩溃 | P1 |
| RE-4 | 网络异常 | 网络不可达时输出错误信息，不崩溃 | P1 |

## 安全验收

| 编号 | 验收项 | 验收标准 | 优先级 |
|------|--------|---------|--------|
| SE-1 | 无硬编码凭据 | AK/SK 不��现在脚本/配置文件中 | P0 |
| SE-2 | 只读操作 | Skill 不执行任何创建/修改/删除操作 | P0 |
| SE-3 | 超时控制 | 所有 API 调用有 30 秒超时 | P1 |
