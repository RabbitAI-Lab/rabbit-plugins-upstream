## Description: <br>
Package SEO helps agents improve discoverability for npm packages, GitHub repositories, and AI agent skills with keyword-rich metadata, README structure, badges, and publishing checklists. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[nextfrontierbuilds](https://clawhub.ai/user/nextfrontierbuilds) <br>

### License/Terms of Use: <br>


## Use Case: <br>
Use this skill when publishing or auditing package, repository, or agent skill metadata for clearer descriptions, stronger keywords, consistent README content, badges, and cross-platform publishing alignment. <br>

### Deployment Geography for Use: <br>
Not geography-specific; intended for online package, repository, and skill publishing workflows. <br>

## Known Risks and Mitigations: <br>
Risk: Generated SEO copy can include inaccurate public claims, compatibility statements, badge links, or trend-based keyword suggestions. <br>
Mitigation: Review descriptions, badges, compatibility claims, and keyword choices for accuracy before publishing. <br>
Risk: Aggressive keyword use can make package metadata misleading or reduce readability. <br>
Mitigation: Use only relevant keywords and keep descriptions aligned with the actual package, repository, or skill behavior. <br>
