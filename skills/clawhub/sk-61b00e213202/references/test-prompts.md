# 回归用例与预期结果

跑法：

```bash
python -X utf8 scripts/linggen.py --card "<答案串>" [--config alt|fan]
python -X utf8 scripts/linggen.py --scores "<答案串>" --paper N
python -X utf8 scripts/build_quiz_html.py --verify   # JS↔Python 全用例对拍
```

## 手工回归用例（改引擎或数据后逐条核对）

| # | 输入 | 预期 |
|---|---|---|
| 1 | `--card "P01:AAAAAAAA"` | 不报错；同一命令跑两次，帖码与道号完全一致 |
| 2 | `--card "P01:1a2b3c4a5b6c7a8b"` | 与用例 1 同结果（大小写不敏感） |
| 3 | `--card "01，1Ａ，２Ｂ，3C4A5B6C7A8B"` | 与用例 1 同结果（全角、顿号容错） |
| 4 | `--card "P01:1A2B3C"` | 出卡，末尾印「剩下的题，替你答了。」（已答 ≥5 时不印；此例 3 题 <5，仍出卡不拦第二次） |
| 5 | `--card "1A2B3C4A5B6C7A8B"`（无卷号） | 退出码 2，提示缺卷号，**不许猜卷号** |
| 6 | `--card "P99:1A2B3C4A5B6C7A8B"` | 退出码 2，卷号不存在 |
| 7 | 帖码手改一个天干字后反解 | 校验失败，明确报错（退出码 3 路径）；恰好撞上合法校验的改法不算失败 |
| 8 | `--config fan` 出四灵根卡 | 判词出现点名版本；`--config alt` 同一答案为不点名版本；其余字段完全一致 |

## audit / selftest 必须全绿的项目

- 逐题五行峰值 = 3（金木水火土各一个 3）
- 六档品质全可达（随机采样 12 万次内含变异至少一例）
- 品质分布逐档在目标 ±8 个百分点内（**六档逐档校验，不只看伪灵根合计**）
- 帖码编码→反解往返 500 例一致
- 帖码字符集纯净：正则 `[0-9A-Za-z-]` 零命中
- 宗门方向断言：主属性木 → 滋养沧浪门 / 磨砺锐金堂（五属性全测）
- 题干禁词零命中
- 卡片每行显示宽度 ≤ 64（CJK 记 2）
- 同一答案跑两次结果完全一致（确定性）
- JS↔Python 对拍 18 个用例全部一致

## 已知边界

- `--calibrate` 的「目标分布」以模拟人群（softmax 偏好 + 强/中庸混合）为基准，不是真实用户数据。上线后拿真实分布回填 `tiers.json` 的 `target_distribution` 并重跑校准
- 变异灵根触发条件含三个参数（min_top / max_gap / min_lead），全在 `meta.json`；改任何一个都要重跑 `--audit`
