## Description: <br>
Write structured PRDs with interactive HTML feature demos including code samples and configuration. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[paudyyin](https://clawhub.ai/user/paudyyin) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Product managers, developers, and product teams use this skill to draft structured product requirements documents with problem statements, goals, user stories, requirements, success metrics, and acceptance criteria. It can also produce self-contained HTML feature explainers with code samples, configuration notes, and before/after walkthroughs. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: HTML explainer sections may default to Chinese-language content. <br>
Mitigation: Request the desired output language explicitly when generating explainers for teams that need another language. <br>
Risk: Generated PRDs or explainers may contain incomplete or misleading product requirements if used without review. <br>
Mitigation: Have product and engineering reviewers validate requirements, code samples, configuration details, and success metrics before using the output for planning or implementation. <br>
