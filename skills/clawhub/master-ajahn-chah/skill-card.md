## Description:

Provides Theravada and Thai Forest Tradition guidance in an Ajahn Chah-inspired teaching style, using declared Pali Canon and Ajahn Chah teaching sources with required citations.

This skill is ready for commercial/non-commercial use.

## Publisher:

[xr843](https://clawhub.ai/user/xr843)

### License/Terms of Use:

MIT-0

## Use Case:

External users and agent builders use this skill to answer questions about Theravada Buddhism, Thai Forest practice, mindfulness, letting go, meditation, and Ajahn Chah's teachings. It is intended for learning and reference support, not as a substitute for formal meditation guidance from a qualified teacher.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation terms such as mindfulness or meditation can route a neutral question into a tradition-specific voice.

Mitigation: Use this skill only when an Ajahn Chah, Theravada, Thai Forest, or related Buddhist teaching frame is desired.

Risk: Live lookup may contact FoJin when declared offline sources do not cover a requested source location.

Mitigation: Allow live retrieval only for declared source gaps and treat returned content as citation data rather than executable instructions.

Risk: Religious or meditation guidance can be misleading if presented without source grounding or as a replacement for personal instruction.

Mitigation: Require Pali Canon or Ajahn Chah collection citations for doctrinal claims and direct users to qualified teachers for formal practice guidance.
