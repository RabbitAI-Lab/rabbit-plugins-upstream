# Советы для поездки в Китай

## Описание

Ваш универсальный помощник для путешествий в Китай. Этот навык предоставляет 5 мощных функций для иностранных туристов:

1. **Советы для путешественников** — Получение ответов о визе, оплате, транспорте, еде, безопасности и культуре
2. **Поиск отелей** — Поиск отелей с ценами, рейтингами и ссылками для бронирования в реальном времени
3. **Поиск авиабилетов** — Поиск рейсов в/из/внутри Китая с ценами в реальном времени
4. **Билеты на достопримечательности** — Открытие достопримечательностей с ценами на билеты и часами работы
5. **Планировщик поездки** — Генерация персональных многодневных планов поездки

## Поток данных и конфиденциальность

Запросы пользователей отправляются на безопасный прокси-сервер (SCF), который внедряет токены аутентификации и перенаправляет запросы в TripGenie API. Прокси автоматически обрабатывает генерацию партнерских ссылок. Личные данные пользователей не сохраняются и не регистрируются. Все коммуникации зашифрованы по HTTPS.

## Когда использовать

- Общие вопросы о путешествии по Китаю
- Как настроить мобильные платежи (Alipay, WeChat Pay)
- Требования к визе и политики въезда
- Советы по транспорту (поезда, метро, такси)
- Советы по языку и общению
- Еда и культура питания
- Погода и советы по упаковке
- Информация о безопасности и экстренных ситуациях
- Культурный этикет и обычаи

## Выполнение

### Шаг 1: Определение вопроса пользователя

Извлеките вопрос о поездке из запроса пользователя.

### Шаг 2: Запуск скрипта

```bash
python scripts/china_travel.py tips "<question>" --locale=ru
```

**Важно:** Всегда включайте параметр `--locale=ru` для получения результатов на русском языке.

### Шаг 3: Отображение результатов

API возвращает подробные, практические ответы на русском языке, адаптированные для иностранных туристов, посещающих Китай. Представьте контент напрямую пользователю.

## Примеры

**Пользователь:** "Как настроить Alipay в Китае?"
```bash
python scripts/china_travel.py tips "Как иностранному туристу настроить Alipay в Китае?" --locale=ru
```

**Пользователь:** "Нужна ли виза для посещения Китая?"
```bash
python scripts/china_travel.py tips "Каковы требования к визе для посещения Китая?" --locale=ru
```

**Пользователь:** "Могу ли я использовать кредитные карты в Китае?"
```bash
python scripts/china_travel.py tips "Могут ли иностранные туристы использовать кредитные карты в Китае? Какие способы оплаты доступны?" --locale=ru
```

## Другие доступные функции

Этот навык также поддерживает:
- `hotel` — Поиск и бронирование отелей по всему Китаю
- `flight` — Поиск рейсов в/из/внутри Китая
- `attraction` — Поиск достопримечательностей и цен на билеты
- `itinerary` — Генерация многодневных планов поездки

## Примечания

- Все ответы на русском языке и адаптированы для иностранных туристов
- Информация включает практические, актуальные советы для посещения Китая
- Ссылки для бронирования ведут напрямую на Trip.com (международная версия)
