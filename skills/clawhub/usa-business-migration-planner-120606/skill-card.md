## Use Case: <br>
Developers, analysts, and technical users use this skill to structure vibe-coding work into scoped outcomes, implementation steps, reusable checklists, and verification notes that improve code efficiency and quality. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill name suggests USA business migration, but the artifact behavior is a generic vibe-coding workflow helper. <br>
Mitigation: Confirm the intended use before installation, and rename or replace the skill if users expect business migration planning. <br>
Risk: Broad implicit triggers could route unrelated software-and-data requests to this skill. <br>
Mitigation: Narrow activation keywords and trigger examples to coding workflow improvement before deployment. <br>
Risk: The skill may provide workflow guidance that does not match a user's actual constraints. <br>
Mitigation: Require the agent to restate outcomes, constraints, inputs, and success criteria before producing artifacts or code changes. <br>
