## Use Case: <br>
External agent users, skill authors, maintainers, and teams use this skill to turn Nano Pdf-style workflow requests into actionable plans, checklists, analyses, code changes, or decision support. ## Known Risks and Mitigations: <br>
Risk: Broad trigger terms and implicit invocation may activate the skill for ordinary PDF, editing, or workflow requests where it is not intended. <br>
Mitigation: Confirm the skill is appropriate before using it for sensitive or unrelated tasks, and review generated guidance before acting on it. <br>
Risk: Workflow, code, shell command, or configuration suggestions may be incorrect or incomplete for a user's local environment. <br>
Mitigation: Validate outputs against the stated success criteria, run local checks where applicable, and keep assumptions and remaining risks visible. <br>
