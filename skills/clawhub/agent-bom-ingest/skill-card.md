## Description:

Validate and ingest operator-pushed agent-bom inventory JSON from AWS, Azure, GCP, Snowflake, CMDB, or endpoint collectors for local findings, graph, policy, provenance, or auditor-ready exports without giving agent-bom direct cloud credentials.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, platform engineers, and security teams use this skill to validate canonical inventory JSON, run local agent-bom scans, and produce JSON, SARIF, HTML, Markdown, CycloneDX, or SPDX outputs for automation, audits, and review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Malformed or incomplete inventory could produce misleading local findings or audit exports.

Mitigation: Validate inventory against the packaged schema and require trustworthy discovery_provenance and permissions_used fields before scanning.

Risk: Optional control-plane push could expose inventory or credentials if pointed at an untrusted destination or if tokens are pasted into chat.

Mitigation: Use optional push only with an operator-owned AGENT_BOM_PUSH_URL and keep API tokens in environment variables rather than chat or command output.
