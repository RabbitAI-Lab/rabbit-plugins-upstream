# 微信公众号文章模板创作

## 概述

本技能提供微信公众号文章**排版模板**的交互式创作工具，产出可直接复用的 HTML 模板结构。模板中保留 `{{占位符}}` 供下游 Article 写作 skill 在生成具体文章时填入内容——**本技能不负责填充文章内容**。

**定位**：模板工厂 — 产出排版结构 → 下游技能消费（填充标题、段落等实际内容）。

**核心能力**：
- 7 套预设行业模板，即选即用
- 10 大类排版要素逐项自定义
- 输出微信公众号兼容的内联样式 HTML

**微信公众号技术约束（强制遵守，详见 `references/custom-config.md` 第 0 节及 `references/wechat-html-spec.md`）**：

**绝对禁止（会被移除或失效）**：
- `<script>` 标签、内联事件（onclick 等）
- `<style>` 标签、外部 CSS 引用
- `position: fixed` / `position: sticky`
- `<iframe>` 标签、Canvas、表单元素（input/button/select）
- CSS 伪元素（::before, ::after）
- **`<div>` 标签**（不可靠，会被编辑器过滤或自动转为 `<section>`，排版容器强制使用 `<section>`）

**强制规范**：
- 所有样式必须使用内联 `style` 属性
- **排版容器唯一合法标签：`<section>`**，任何情况下不使用 `<div>`
- 表格表头使用 `<td style="font-weight:600;">` 替代 `<th>`
- 图片必须添加 `display:block; max-width:100%; height:auto; margin:0 auto;`
- 全局容器需包含标准 font-family 和 `word-break:break-all`
- 简单表格结构，不使用 `colspan` / `rowspan`
- 复杂 SVG 可能被过滤，仅使用基本图形（线、圆）
- 不依赖 `counter-reset` 等 CSS 计数器
- `text-transform: uppercase` 建议用预转大写文本替代

## 步骤 3：完全自定义模式

按照以下顺序，每次引导用户配置 1 个排版要素。每配置完一项，展示当前的效果说明。

**配置顺序**（10 类要素）：

**第 1 项：正文字体及大小**

## 输出规范

### 模板定位

本技能产出的是**排版模板**，不是成品文章。模板保留 `{{占位符}}`，由下游 Article 写作 skill 在生成具体文章时填入内容。

**模板保留以下内容**（使用 `{{占位符}}` 标记，由下游 skill 填充）：
- 一级标题、副标题、日期、作者等头部信息
- 文章的具体正文段落内容

**模板包含以下结构**（排版骨架）：
- 头部样式（一级标题 h1 + 装饰 + 作者/日期）
- 二级标题 h2 装饰样式、正文段落 p 样式
- 引用块 blockquote、划重点 span、代码块 pre/code
- 表格 table、列表 ul/ol/li
- 分隔线、底部关注区（二维码 + 公众号名称）
- 各行业独特的配色和视觉风格

### HTML 输出要求

1. 所有样式内联，不使用 class 或外部 CSS
2. 不使用 CSS 伪元素（::before, ::after）
3. 所有装饰效果使用实际 HTML 元素（span, section）实现
4. **排版容器只用 `<section>`，严禁 `<div>`**
5. 图片使用 `img` 标签，必须添加 `display:block;max-width:100%;height:auto;margin:0 auto;`
6. 不使用 `<script>`、`<iframe>`、`<canvas>`、表单元素
7. 颜色值使用标准格式：`#RRGGBB` 或 `rgba(r,g,b,a)`
8. 字体大小使用 `px` 单位，正文默认 17px，辅助文字 ≥ 13px
9. 使用 `section` 对内容区域进行语义分组
10. 输出不包含 `<html>`、`<head>`、`<body>` 外围标签
11. 表格表头使用 `<td style="font-weight:600;">` 而非 `<th>`
12. 全局容器包含标准 font-family 栈、`word-break:break-all` 和 `box-sizing:border-box`
13. 不依赖 `counter-reset`、`text-transform:uppercase`

### 移动优先设计原则

微信公众号文章主要在移动端阅读，模板设计必须以移动端为首要考虑：

1. **正文字号 17px**：在 375px 宽度的 iPhone 屏幕上保证清晰可读
2. **列表 padding-left ≥ 32px**：确保编号/符号在移动端不被压缩或截断
3. **表格字号 ≥ 15px**：表格在窄屏上容易挤压，字号不能太小
4. **代码字号 ≥ 14px**：保证代码可读性
5. **box-sizing: border-box**：全局容器添加此属性，防止 padding 撑破宽度
6. **单元格 padding 优化**：表格单元格采用 `padding:12px 10px`（竖向大于横向），适配窄屏
7. **图片 max-width: 100%**：确保图片不超出屏幕宽度
8. **避免固定宽度**：不使用 `width:XXXpx` 的固定宽度容器（图片除外）

### 输出前自检清单

- [ ] 无 `<script>`、无内联事件、无 `<style>` 标签
- [ ] **无 `<div>` 标签，所有容器均为 `<section>`**
- [ ] 图片均含 `max-width:100%; display:block; height:auto`
- [ ] **正文字号默认 17px**，辅助文字 ≥ 13px
- [ ] **列表 padding-left ≥ 32px**，字号 ≥ 17px
- [ ] **表格字号 ≥ 15px**，代码字号 ≥ 14px
- [ ] 无 `position:fixed/sticky`
- [ ] 表格使用 `<td>` 非 `<th>`，无 colspan/rowspan
- [ ] 全局容器含 font-family、word-break 和 **box-sizing:border-box**
- [ ] 保留 `{{占位符}}` 不填充，供下游 skill 使用

### 文件输出

将最终生成的模板 HTML 写入当前工作目录下的 `outputs/wechat-template.html`。
