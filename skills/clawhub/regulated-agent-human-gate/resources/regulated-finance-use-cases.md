# Regulated Finance Use Cases

## Supplier Payment

Inspect amount, beneficiary novelty, beneficiary account changes, purchase order, invoice, budget exception, high-risk country, and agent execution scope.

## Stablecoin Off-ramp

Inspect KYC status, AML risk, sanctions, Travel Rule obligations, wallet and bank ownership, recent account changes, amount thresholds, and provider uncertainty.

## Loan Approval Assistant

The agent may recommend but must not grant final approval. Preserve model input, output, rationale, missing data, identity anomalies, and final human decision.

## Account Control Change

Changing phone, payout account, security settings, device binding, withdrawal limits, or authorized persons should default to stronger gates.
