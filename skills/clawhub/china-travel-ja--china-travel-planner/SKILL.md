# 中国旅行プランナー

## 説明

中国旅行のためのオールインワン旅行コンパニオン。このスキルは外国人旅行者向けに5つの強力な機能を提供します：

1. **旅行プラン** — AIでパーソナライズされた複数日の旅行プランを生成
2. **ホテル検索** — リアルタイムの料金、評価、予約リンクでホテルを探す
3. **フライト検索** — 中国への/中国発/中国内のフライトをリアルタイムの料金で検索
4. **観光地チケット** — チケット料金、営業時間で観光スポットを発見
5. **旅行アドバイス** — ビザ、支払い、交通、食事などに関する回答を取得

## データフローとプライバシー

ユーザーのクエリは安全なプロキシサーバー（SCF）に送信され、認証トークンが注入されてTripGenie APIに転送されます。プロキシはアフィリエイトリンクの生成を自動的に処理します。ユーザーの個人データは保存または記録されません。すべての通信はHTTPSで暗号化されています。

## 使用する場面

- 中国の都市への複数日旅行を計画
- ホテル、観光スポット、食事を含む完全な旅程を取得
- 興味や予算に基づいて旅行プランをカスタマイズ

キーワード：中国 旅程、中国旅行計画、北京3日間、上海旅行プラン、成都旅行、旅行プランナー、日程別

## 実行

### ステップ 1：ユーザーのリクエストからパラメータを抽出

| パラメータ | 説明 | 例 |
|-----------|------|-----|
| city | 都市名（英語または日本語、必須） | "Chengdu" or "成都" |
| days | 日数（必須） | 3 |
| travelers | 旅行者数（任意、デフォルト：2） | 2 |
| interests | 旅行の興味（任意） | "パンダと食事" |
| budget | 予算レベル（任意） | "中級" |

### ステップ 2：スクリプトを実行

```bash
python scripts/china_travel.py itinerary "<city>" <days> [travelers] "[interests]" "[budget]" --locale=ja
```

**重要：** 常に `--locale=ja` パラメータを含めて、日本語での結果を取得してください。

### ステップ 3：結果を表示

API は構造化された Markdown で日別の旅程を返します。時間帯、アクティビティの説明、ホテルのおすすめ、レストランの提案、予約リンクが含まれます。内容を直接ユーザーに表示します。

## 例

**ユーザー：** "北京への3日間の旅行を2名で計画して"
```bash
python scripts/china_travel.py itinerary "Beijing" 3 --locale=ja
```

**ユーザー：** "パンダと辛い食事を中心とした5日間の成都旅程、中級予算"
```bash
python scripts/china_travel.py itinerary "Chengdu" 5 2 "pandas and spicy food" "mid-range" --locale=ja
```

## その他の利用可能な機能

このスキルは以下もサポート：
- `hotel` — 中国のホテルを検索して予約
- `flight` — 中国への/中国発/中国内のフライトを検索
- `attraction` — 観光スポットとチケット料金を検索
- `tips` — 旅行アドバイス、ビザ、支払い、交通のヒント

## 注意

- 都市名は英語または日本語で入力できます
- 予算レベル："budget"（低予算）、"mid-range"（中級）、"luxury"（高級）
- 予約リンクは Trip.com（国際版）に直接遷移します
