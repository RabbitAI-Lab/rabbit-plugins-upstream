## Description:

lgd-crypto-guard helps agents assess AI privacy-computing, encryption, and data-minimization systems against the LGD registered, evidenced, and gated control framework using a local zero-dependency rubric.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, compliance reviewers, and agent operators use this skill to run a local rubric-based self-check for AI systems that handle privacy computing, encrypted data workflows, or data minimization. It supports evidence-gap analysis and gate decisions, but does not replace legal, regulatory, or professional review.

### Deployment Geography for Use:

Global
