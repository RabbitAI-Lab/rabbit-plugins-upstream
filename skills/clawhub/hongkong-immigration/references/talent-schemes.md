# 赴港工作、升学、定居：人才计划与长期签证

适用：任何国籍（含内地居民）想在香港工作、创业、升学或最终取得永居的用户。
内地居民获批后还需办 D 逗留签注（见 mainland-permits.md）。

注意：2025–2026 年香港人才政策调整频繁（配额、计分方式、续签口径均有变动），
本文只给稳定框架；具体门槛数字回答前必须搜索入境处官网/官方新闻公报核实，
并注明"截至 X 年 X 月"。

## 主要路径速览

| 计划 | 适合人群 | 核心条件（框架） | 特点 |
|------|----------|------------------|------|
| 高才通 (TTPS) | 高收入者或名校毕业生 | A 类：上年收入达港币 250 万级；B/C 类：合资格大学学士 + 工作年限区分（C 类有年度配额） | 先获身份后找工作，审批快 |
| 优才 (QMAS) | 综合背景优秀人才 | 现行综合计分制按 12 项评核准则审查，达到当时门槛才可递交 | 无需雇主，准则与门槛可调整 |
| 专才 (ASMTP) | 已获香港雇主聘用的内地居民 | 学士或专业资格 + 相关经验；薪酬需达市场水平 | 绑定雇主，换工作须先获批 |
| 一般就业政策 (GEP) | 已获香港雇主聘用的海外/外籍人士（含台澳） | 与 ASMTP 类似，面向非内地人士 | 同上；内地居民不适用 |
| IANG | 香港高校毕业生 | 毕业后申请，首段逗留期已延长（近年为 24 个月口径），可自由求职 | 留学转就业主通道 |
| 学生签证 | 赴港就读 | 获院校录取，经院校担保申请 | 毕业后接 IANG |
| 受养人签证 | 上述获批者的配偶及未成年子女 | 随主申请人 | 可在港工作（多数类别） |

其他小众路径：输入中国籍香港永久性居民第二代计划、资本投资者入境计划(CIES)、
科技人才入境计划(TechTAS)。用户背景特殊时再搜索详情。

## 选择建议（决策顺序)

1. 有香港雇主 offer → 专才/一般就业政策，最直接。
2. 无 offer 但收入高或名校学历 → 高才通（条件符合时优先，审批最快）。
3. 无 offer、背景综合 → 优才；先核实现行评核规则再评估。
4. 愿意读书 → 留学 + IANG，成本可控且成功率高。
5. 资金充裕不想就业 → 投资移民 CIES。

## 续签与永居

- 通常模式"3+3+2"或"2+3+3"（高才 A 类等有差异），获批后按签证期续签。
- 续签核心是"实质贡献"：在港真实工作/业务记录（近年审核明显收紧，
  强调工作关联、真实办公地址与薪税单据）。
- 连续通常居住满 7 年可申请香港永久性居民身份；"通常居住"看生活重心，
  不是简单数天数。
- 香港永居、特区护照、回乡证与内地户籍分属不同管理制度；申请证件或
  办理户籍变更前，须分别核对香港入境处、香港中旅及户籍地公安的现行要求，
  不把某一证件申请直接推定为户籍必然注销。
