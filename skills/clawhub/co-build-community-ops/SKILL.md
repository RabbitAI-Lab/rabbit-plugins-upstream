# S6 · 共建社区运营框架

## R — 原文 (Reading)

> 其根本特征在于：消费即投资、行动贡献即投资，共建者通过行为、关系、时间、知识与资源的贡献共同推动事业成长。
>
> 借助 Web3 共建社区实现融人、融智、融资源、融市场，升级商业模式和快速裂变发展。
>
> — "价值互联网产业应用蓝皮书"编写组，第二篇·第三章（事业共同体 p20）/ 第一篇·导言（四融 p21）

## I — 方法论骨架 (Interpretation)

这套方法论要解决的，是把"一堆用户"变成"一支事业共同体"，而不是把社区当成拉新群。

它的核心逻辑分三层：

1. **重新定义"投资"**：在传统商业里只有出钱才算投资、才有分红权；这里把"消费行为"和"行动贡献"（分享、创作、传播、共建、运维）都视为投资。用户买你的产品、帮你传播、给你提建议，都等于往事业里投了"行为资本"，理应共享成长收益。这就是"消费即投资、行动贡献即投资"。

2. **通证只是"粘性工具"，不是目的**：别把通证当炒作标的。它在这套框架里是"计量尺 + 连接器"——把每个人的行为贡献记下来、变成可确认的权益，把原本松散的用户/合作者/生态方绑成一张协同网。社区的价值不在人多人少，而在"行为贡献是否被认可、是否被回馈"。

3. **四融把外部资源转为协同资源**：事业共同体不是自己养全套资源，而是用共建机制把外部"人、智、市场、资源"吸进来——融人（社区化协作降人工）、融智（开放创新降研发）、融市场（社群传播降获客）、融资（权益融资扩产能）。四融一齐发力，生态资源才变成你的协同动能，实现低成本的裂变式增长。

一句话：它是组织范式，不是营销技巧——成败看"贡献是否被真实计量与回馈"，不是看拉了多少人。

## A1 — 书中的应用 (Past Application)

### 案例 1: 道衍数科「学习即创业」Web3 商学苑（c13）
- **问题**：Web3 转型存在"人才鸿沟"，有案例却缺能落地的实操人才，育人侧与用人侧割裂，学员学完无处转化价值。
- **方法论的使用**：把 Web3 商学苑设计为共建社区——分层课程体系（商业思维/超级个体实操/事业焕新研学）+ 产业侧咨询陪跑，用区块链学分记录学习、分享、实训行为，形成"行为即贡献、贡献即激励"闭环，把非标准化个体参与转为可度量贡献。
- **结论**：学员既是学习者也是共建者，数字学分可兑换权益并链接 B 端企业转型需求，社区自组织裂变。
- **结果**：形成"学习即创业"共识，呈现自组织裂变、动态迭代的成长态势，是境内"共建社区运营"的直接范例。

### 案例 2: 星巴克 120 亿美元咖啡树 RWA（c08）
- **问题**：农业是最难融资的行业，普通消费者难以参与，传统价值链割裂，用户只是"买咖啡的人"。
- **方法论的使用**：以 10 美元超低门槛让消费者成为"咖啡树主人"，实现"消费即投资"；每株咖啡树生成动态 NFT、物联网实时更新生长数据，投资者可感可知、可分享收益，把消费行为转为对事业的股权投资。
- **结论**："资产上链 + 数据感知 + 社群共建"让消费者从流量变成事业共有人。
- **结果**：私募募资 24 亿美元，上线首月流动性池达 5000 万美元，咖农凭链上数据获巴西银行 5 亿美元绿色信贷——四融中的"融资 + 融市场"被直接兑现。

### 案例 3: 红糖链品 MiWan.LOVE 农产品实物锚定数字资产（c14）
- **问题**：农业产业链价值分配失衡（利润集中在流通环节、种植户议价弱），资产流动性缺失，种植户难回笼资金。
- **方法论的使用**：以 348 个非标蔗田单元为锚定资产，把种植户、平台、消费者拉进共建社区——无人机/无人车/种植大模型把"种植-生长-收割"数据上链，前端用数字资产把消费端与生产端连接，让消费者"消费即投资"种植户的事业。
- **结论**：沉睡资产被激活，种植户提前回笼资金、终端收益占比提升，社区与生产端正和博弈。
- **结果**：形成可复制的良性商业闭环，为产业变革型项目提供"社区 + 实物锚定"样本。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 运营者/创业者手上有用户或生态资源，但苦于"拉新就死、活跃靠烧钱"，想把用户转成长期共建者。
2. 想做一个创作者社区、会员体系、产业社群，却只在做"粉丝群/积分群"，缺少"消费即投资"的真实组织范式。
3. 项目方想把外部的人、创意、渠道、资源吸进来协同，但不知道怎么设计机制让对方"愿意来、留得下、有回报"。
4. 想验证自己的社区到底是不是"真共建"还是"伪社群"——担心自己做成了拉新噱头。
5. 内容创作者想把自己粉丝/读者变成事业共同体，让传播、共创行为获得可确认的权益。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么从 0 搭一个共建社区 / 事业共同体？"
- "怎么让用户变成共建者，而不是流量耗材？"
- "消费即投资、行动贡献即投资 怎么落地？"
- "怎么设计黏性工具 / 通证让社区自增长、自裂变？"
- "怎么用四融（融人融智融市场融资源）把外部资源转为我的协同资源？"

### 与相邻 skill 的区分

- 与 **S5 贡献计量与分配设计器**（f02 主）的区别：S5 偏"把多元贡献可信计量并公平分润的可代码化经济模型"（确权→计量→分配→可追溯，写进合约）；S6 偏"怎么从 0 组织与运营事业共同体、用什么黏性工具、怎么用四融转化资源"。用户问"社区怎么搭、怎么活跃、怎么裂变"用 S6；问"贡献怎么计量、收益比例怎么定、规则怎么写进合约"用 S5。两者天然配套：S6 搭骨架，S5 填血肉。
- 与 **S9 OPC / 超级个体落地清单**（p22 主）的区别：S6 是**平台/企业侧**从 0 搭社区与四融机制；S9 是**个体侧**"我作为承接单元怎么接单、怎么累计回报"。不从零搭社区、只关心自己能接什么活的个体用 S9。
- 与 **S2 合规边界红线检查**（p02 主）的区别：S2 判境内能不能做（严禁代币化等加密金融）；S6 在"非金融数字化赋能"框架内谈社区运营，但若社区要发代币化融资必须先过 S2。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定义共同体价值主张与"消费即投资"共识**
   - 引导用户说清：这个事业共同体为谁解决什么真问题？用户/生态方的"消费行为"和"行动贡献"分别是什么、各自对应什么事业权益？产出一句话价值主张 + 一张"行为→事业投资"映射清单。
   - 完成标准：用户能清楚写出"谁因什么行为、成了事业的什么投资人、该共享什么收益"，且收益锚定真实产业现金流而非拉新返利。

2. **设计"行动 → 贡献 → 通证"闭环**
   - 帮用户把关键行为（消费、分享、创作、共建、运维）拆成可计量的贡献点，确定通证作为"粘性工具"的三重角色：记账凭据（记贡献）、权利凭据（对应收益/治理）、结算凭据（预言机触发自动清算）；并设计初始分配规则草案。
   - 完成标准：产出"行为清单 → 通证计量口径 → 权益映射"草案，且标注每项属商品/治理型（非金融、境内可探索）还是债权/股权型（需境外合规通道）；难客观计量的贡献（创意、声誉）先走社区协商而非强行量化。
   - 判停条件：若方案核心依赖"面向境内居民发代币募资/代币升值叙事"，则跳转 S2 合规边界红线检查，本步不得推进至融资设计。

3. **搭建四融黏性工具并设治理闭环**
   - 用四融杠杆设计具体黏性工具：融人（社区化任务/共建入口）、融智（开放共创/提案激励）、融市场（社群传播返权益）、融资（权益凭证而非集资）；并就资产组合调整、服务商更换等重大事项设链上投票治理，分配规则经社区确认后写入合约（接力 S5）。
   - 完成标准：产出"四融工具矩阵 + 治理投票机制"方案，且能答出"社区凭什么自增长、贡献凭什么被真实回馈"——有真实审计与兑现路径，而非仅靠拉新叙事。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只把"发个币/积分、建个群"当营销噱头、并无真实贡献计量与回馈意图 → 应先做 S1 概念辨析或回归 S5，而非用 S6 严谨搭组织范式。
- 用户要的是**通证分配规则与合约代码**（用 S5）；或用户是**个体想接单累计**（用 S9）；或问题是**境内能不能发币/代币化融资**（用 S2）。
- 项目纯融资导向、靠"消费即投资"包装集资盘 → 立刻转 S2，本 skill 不覆盖任何涉加密金融的合规判定。

### 作者在书中警告的失败模式

- **"伪 RWA"以"赋能实体/贡献分配"为名实为变相集资盘（ce18）**：历史大量项目用"贡献即确权 / 消费即投资"叙事掩盖资金池运作，收益主要来自拉新而非真实产业现金流，社区治理形同虚设、决策集权。判定红线：无真实分配审计、收益靠拉人头、治理流于形式。
- **智能合约代码偏差与预言机喂价的责任真空（ce04）**：社区一旦"代码即法律"自动执行，开发者、发行人、预言机商、托管方责任边界不清，链下司法常不认可代码权利，出事时参与者无救济通道。须预置多源预言机 + 形式化验证 + 应急开关 + 责任条款。
- **"慢资产快金融"错配与监管套利（ce06）**：用快金融逻辑包装慢资产、监管真空期套利，事后被追责；社区若强调"币价升值、已获批"却无真实锚定与第三方审计，崩盘风险极高。

### 作者的盲点 / 时代局限

- **"通证激励真能持续激活贡献"实证不足**：编写组含项目方（道衍数科等），对"激励沦为拉新噱头"的披露可能选择性弱化；运营者须自行验证社区真实活跃度与分润兑现率。
- **"贡献可被通证精准计量"未证**：创意、关系、声誉类贡献难以客观度量，强行量化会失真；社区运营应优先把可量化行为做成闭环，主观贡献走协商。
- **"代码化分配必然更公平"未证**：规则由少数人定义，存在"代码即法律"寡头风险；社区须有真实的链上投票治理制衡。
- 成稿于 2025 年，监管（香港沙盒、稳定币合法化）仍在快速演化，跨境社区设计须以最新合规口径为准。

### 容易混淆的邻近方法论

- 把"共建社区"当"用户社群/粉丝群/DAO"——作者明确定义其为融人融智融资源融市场的**社会型组织载体**，通证是粘性工具（t12），不是纯 DAO 也不只是粉丝群。
- 把"事业共同体"当"合伙企业/法律实体"——它是组织形态与治理趋势描述，强调"共识事业 + 按贡献分配"而非资本纽带（t13）。
- 与 S5（分配机制设计）、S9（个体接单）的区别见 A2。


### 合规红线与使用须知（普通用户必读）

本技能提炼自《价值互联网产业应用蓝皮书（2025）》（蓝皮书编写组，主编：梁超杰）第三篇·第五章「合规边界」，仅供风险识别与科普参考，**不构成任何投资建议、法律意见或投资邀约**。

- 中国境内开展价值互联网与通证经济产业应用，**不得涉及通证代币化等加密金融行为**，应聚焦"非金融"的数字化赋能（溯源、贡献计量、RDA 真实数据资产等）。
- 包括稳定币在内的虚拟货币，**在中国境内发行与交易属于非法金融活动**（央行等十部门 2021 年《关于进一步防范和处置虚拟货币交易炒作风险的通知》）。境外交易所、项目向中国境内居民提供服务同样属非法。
- **连带责任无死角**：不仅直接参与违法，为境外违规项目提供账户、资金划转、技术支持也依法追责——"只是帮忙做技术"不能免责。
- 任何以"Web3/区块链"为名、要求充值、拉人头返利、承诺升值预期的，极可能是资金盘，**请勿参与、勿投资、勿转发**。

> 引用原文："不能涉及通证代币化等加密金融行为，而应聚焦探索'非金融'的数字化赋能产业提效方向。""包括稳定币在内的虚拟货币无法满足 KYC、AML 等要求，在中国境内发行与交易虚拟货币属于非法金融活动。" —— 第三编·第五章（合规边界）／ p02、ce03
