## Description:

Helps create a complete outfit image from up to eight product images, using prompts to specify each item's placement and appearance.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

E-commerce sellers and creative teams use this skill to combine product photos into a coordinated outfit image, with prompts describing how each item should be worn and how the scene should look.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security review flags external processing of images and prompts, and says some components could not be fully analyzed.

Mitigation: Review the provider's privacy implications before use; avoid confidential or identifiable images unless you have verified the provider and accept the transfer.
