# 图生视频 Prompt 模式库

按内容类型组织的 Prompt 模式、负向 Prompt 词汇与失败控制。所有模式遵循统一结构：

```
[保真声明] + [主体运动] + [环境运动] + [镜头运动] + [节奏] + [视觉质量] + [结束状态]
```

---

## 1. 单图动效（Single-frame animation）

**场景**：照片、插画、海报的主体动态化，保持整体构图不变。

**模式**：保持构图 → 微动效（发丝、衣角、光影、粒子、水面）→ 一个镜头运动。

**示例（人物）：**
```
保持画面构图与人物形象不变，女孩缓缓转头看向镜头，嘴角微微上扬，发丝被微风拂动，镜头缓慢推近，电影质感，逆光金色光线
```

**示例（插画/二次元）：**
```
保持原画构图与画风不变，樱花花瓣从画面左侧飘落，背景云层缓缓流动，人物衣角轻轻摆动，固定机位，日系清新风格，柔和光线
```

**示例（宠物）：**
```
保持宠物姿态与场景不变，橘猫的耳朵微微抖动，尾巴轻轻摇摆，眼睛缓慢眨动，镜头固定机位，温暖午后氛围，浅景深
```

---

## 2. 首尾帧过渡（Start/end-frame transition）

**场景**：白天→夜晚、季节变化、状态转变、场景演进。

**模式**：描述过渡路径（逐渐/平滑）→ 固定机位或缓慢横移 → 明确两个端点的关键差异。

**示例（时间过渡）：**
```
从白天到夜晚的平滑过渡，天空由蓝色渐变为深蓝星空，建筑窗户灯光逐渐亮起，固定机位，城市纪实风格
```

**示例（季节过渡）：**
```
从春到秋的季节变换，樱花树逐渐变为红叶，花瓣飘落转为落叶飞舞，镜头缓慢拉远，电影质感，暖色调
```

**示例（天气过渡）：**
```
从晴天到雨天的过渡，乌云逐渐聚集，光线变暗，雨滴开始落下，路面渐湿，镜头固定，自然纪实风格
```

**要点**：两张图的构图与主体位置应相近；过渡路径写"逐渐/平滑/缓慢"，避免跳变描述。

---

## 3. 人物表演（Character performance）

**场景**：照片人物做动作、表情变化、视线转移。

**模式**：保真声明（身份/面部/年龄/发型/服装/肢体数量）→ 单一连贯动作 → 视线逻辑。

**示例：**
```
保持人物外貌、发型、服装与背景完全不变，她缓缓抬头望向远方，眼中泛起泪光，深吸一口气，镜头缓慢推近，纪录片风格，自然光，宁静氛围
```

```
保持人物形象不变，他举起右手向镜头挥手，随后转身走向画面深处，脚步自然，镜头跟随移动，手持摄影风格，轻微晃动，纪实感
```

**要点**：一次只给一个主动作；动作描述要具体（"缓缓抬头望向远方"优于"动一下"）；避免肢体数量/方向矛盾。

---

## 4. 产品展示（Product showcase）

**场景**：商品动态展示、环绕视角、细节特写。

**模式**：保真声明（几何/标签/材质/颜色/比例/品牌标识）→ 环境动效（光影、烟雾、反光）→ 环绕或推近镜头。

**示例（数码产品）：**
```
保持产品外形、Logo、材质与标签文字完全不变，产品在展台上缓缓旋转，背景光影流动，镜头缓慢环绕，棚拍质感，高光细节清晰
```

**示例（美妆/食品）：**
```
保持瓶身设计、标签与配色不变，背景雾气缓缓升腾，瓶身水珠凝结滑落，镜头缓慢推近，微距特写，柔和顶光，高级感
```

**要点**：品牌标识与文字必须声明保持静态可读；运动优先给环境（光/烟/水珠）而不是产品形变。

---

## 5. 海报动效（Poster animation）

**场景**：静态海报、封面、KV 图分层动效化。

**模式**：文字与 Logo 保持静态 → 分层动画（前景/中景/背景独立运动）→ 光线与粒子点缀。

**示例：**
```
海报文字与Logo保持静态清晰，背景云层缓慢流动，前景人物衣摆飘动，金色粒子缓缓上升，镜头固定机位，电影质感，高级配色
```

**要点**：文字/Logo 是保护锚点，绝不形变；用"背景层/前景层"分层描述各自运动。

---

## 6. 环境动态（Environment motion）

**场景**：风景、天气、水体、自然现象。

**模式**：自然运动描述（物理可信）→ 缓慢运镜 → 光线氛围。

**示例（山水）：**
```
湖面泛起层层涟漪，远山云雾缓缓流动，倒影随水波轻颤，镜头缓慢横移展现全貌，中国水墨画风格，清晨柔光，宁静空灵
```

**示例（城市）：**
```
城市街道霓虹灯闪烁，行人匆匆走过，雨水反射霓虹光芒，镜头缓慢上升俯瞰，赛博朋克风格，高对比度冷色调
```

**要点**：环境类优先"缓慢/流动/飘散"等自然词；避免突兀的大幅运动。

---

## 7. 多镜头社交视频（Multi-shot social clip）

**场景**：3-6 个镜头的完整短视频（节日宣传、产品发布、人物故事）。

**模式**：拆镜头 → 每镜头一张源图 → 保持一致性 → 逐镜头生成 → 给出分镜表。

**示例分镜表（产品发布 40 秒，每镜头 10 秒）：**

| 镜头 | 时长 | 运动 | 转场 | Prompt 要点 |
|------|------|------|------|------------|
| 1 环境 | 10s | 缓慢推近 | 淡入 | 发布会现场氛围，灯光流动 |
| 2 产品 | 10s | 环绕 | 硬切 | 产品缓缓旋转，保持Logo不变 |
| 3 特写 | 10s | 微距推近 | 硬切 | 细节材质特写，水珠/光影动态 |
| 4 收尾 | 10s | 缓慢拉远 | 淡出 | 产品全景，稳定收尾帧 |

**要点**：逐镜头分别生成比单次长生成一致性更可靠；不承诺剪辑/字幕/音乐同步，除非有对应工具。

## 8. 负向 Prompt 与保真约束

### 常见失败模式

| 失败 | 说明 |
|------|------|
| 面部变形 | 人物五官扭曲、身份漂移 |
| 肢体异常 | 手指数量错误、肢体方向矛盾 |
| 文字扭曲 | Logo/标题/标签形变、乱码 |
| 物体漂移 | 主体位置漂移、边缘闪烁 |
| 过度运动 | 大幅运动导致失真 |
| 风格突变 | 画风/色调与原图不一致 |

### 负向 Prompt 词汇（平台支持时单独给出）

```
变形、扭曲、模糊、低质量、多余手指、肢体异常、文字乱码、闪烁、抖动、
过度运动、颜色失真、身份变化、风格突变、水印、噪点
```

### 保真约束语句（平台不支持负向时内嵌主 Prompt）

- "保持构图与主体完全不变"
- "人物外貌、发型、服装保持不变"
- "Logo 与文字保持静态清晰可读"
- "产品外形、标签、材质、颜色不变"
- "画面稳定，无闪烁"
- "自然流畅的微动效，避免过度运动"

---

## 9. 失败控制与重试

| 失败现象 | 调整策略 | 重试指令示例 |
|---------|---------|-------------|
| 主体变形 | 加强保真声明、降低运动强度 | "保持人物面部与身份不变，仅让发丝微动，运动幅度最低" |
| 动作不明显 | 具体化动词、加环境动效 | "让长发明显飘动，衣角摆动，微风拂过" |
| 过渡生硬 | 固定机位、描述过渡路径 | "固定机位，从 A 到 B 平滑渐变，中间无跳变" |
| 画面闪烁 | 降低运动幅度、加稳定约束 | "画面稳定无闪烁，运动幅度最低" |
| 文字扭曲 | 明确文字保持静态 | "文字与 Logo 完全静止、清晰可读，不要变形" |
| 风格突变 | 强化原图风格描述 | "严格保持原图的画风、色调与光照方向" |

**重试纪律**：一次生成失败或明显缺陷 → 针对性调整后最多重试 1 次 → 仍失败则如实报告并给出可复制的优化 Prompt 供用户在其他平台使用。

## 10. 镜头运动与风格词汇表

### 镜头运动

| 运动 | 中文描述 | 英文 |
|------|---------|------|
| 推近 | 镜头缓慢推近 / 逐渐放大主体 | dolly in / zoom in |
| 拉远 | 镜头缓缓拉远 / 展现全貌 | dolly out / zoom out |
| 横移 | 镜头向右横移 / 缓慢平移 | pan |
| 升降 | 镜头缓慢上升 / 从下往上 | tilt up / tilt down |
| 环绕 | 镜头环绕主体旋转 | orbit |
| 固定 | 固定机位 / 镜头保持静止 | static / locked |
| 手持 | 手持摄影风格，轻微晃动 | handheld |

### 光线

| 类型 | 描述 |
|------|------|
| 自然光 | 清晨柔光、正午阳光、黄昏暖光、月光 |
| 人造光 | 霓虹灯光、烛光、台灯暖光、路灯 |
| 特殊光效 | 逆光金色光线、丁达尔效应、光斑散景、体积光 |

### 风格

| 类别 | 关键词 |
|------|--------|
| 电影感 | 电影质感、胶片感、宽银幕、电影级画面 |
| 动漫 | 日系动漫风、二次元、新海诚风格 |
| 写实 | 超写实、纪录片风格、自然纪实 |
| 艺术感 | 油画质感、水彩风格、赛博朋克、蒸汽朋克 |
| 情绪色调 | 暖色调、冷色调、高对比度、低饱和度、复古色调 |
| 氛围词 | 温暖、宁静、神秘、梦幻、治愈、清新、史诗感、孤独、浪漫、紧张 |
