# 平台路由与语法适配速查

选择生成平台或适配 Prompt 语法时的参考。核心原则：根据目标效果、画面结构、当前工具可用性与用户权限选择，不宣称某平台普遍最优。

## 选择原则

1. **先查可用性**：检查当前会话已连接的 Connector / 可调用生成器。只有真实可调用的平台才能"直接执行"；其余一律按"仅支持 Prompt 交付"处理。
2. **按任务匹配**：不同平台擅长不同任务（见下方决策表）。
3. **尊重用户点名**：用户明确说某平台时优先适配该平台，除非它无法满足硬性要求。
4. **不假装调用**：绝不能因为知道某平台的 Prompt 格式就宣称调用过该服务。

## 平台分类

| 类别 | 说明 | 处理方式 |
|------|------|---------|
| 可直接执行 | 当前会话已连接（如内置 VideoGen、已连接的视频 Connector） | 直接调用生成 |
| 仅 Prompt 交付 | 未连接，或输入不支持当前任务 | 返回推荐平台 + 可直接复制的 Prompt 与参数 |

## 内置 VideoGen（默认执行通道）

WorkBuddy 内置工具，未连接任何第三方视频平台时的首选执行通道。

- **输入**：文本描述 + 可选首帧图片 + 可选尾帧图片
- **输出**：本地 MP4 文件
- **语法**：中文或英文 Prompt 均可；中文语义理解良好
- **时长**：默认 10 秒，适合 10 秒短视频
- **分辨率**：仅 720P / 1080P
- **负向 Prompt**：不支持显式负向参数 → 将保真约束写成正向语句内嵌到主 Prompt（如"保持构图与主体不变"）
- **调用**：ToolSearch 加载 → DeferExecuteTool 执行（详见 SKILL.md「直接执行：VideoGen 调用规范」）

## 主流平台速查

以下为知识性参考。当某平台通过 Connector 接入时，以其实际文档与工具参数为准。

### Kling 可灵（快手）
- **擅长**：人像动态化、首尾帧过渡、运动幅度控制
- **语法**：中文自然语言友好；显式首尾帧支持
- **关键参数**：时长（10 秒）、运动幅度（low/medium/high）、镜头控制
- **负向 Prompt**：支持
- **适配要点**：人物照片动态化优先；保真声明 + 单一动作 + 运动幅度 low/medium

### 即梦 Jimeng（字节跳动 Seedance）
- **擅长**：中文语义理解、首尾帧、多主体一致性
- **语法**：中文自然语言
- **关键参数**：时长、分辨率、运动强度
- **负向 Prompt**：部分支持
- **适配要点**：首尾帧与叙事型短视频；描述过渡路径而非并列两个状态

### Runway（Gen-3 / Gen-4）
- **擅长**：电影感运镜、镜头控制（camera control）、风格一致性
- **语法**：英文为主；支持显式 camera movement 描述
- **关键参数**：motion、camera、duration、aspect ratio
- **负向 Prompt**：支持
- **适配要点**：海报动效、产品展示、电影感镜头运动；英文 Prompt + 单独 camera 指令

### Pika
- **擅长**：特效动效（Pikaffects）、趣味变化、夸张效果
- **语法**：英文简短指令
- **关键参数**：motion scale、camera、特效参数
- **负向 Prompt**：不支持显式负向
- **适配要点**：趣味/创意类动效；约束写成正向语句

### Luma Dream Machine
- **擅长**：物理真实感、流体、自然运动
- **语法**：英文自然语言
- **关键参数**：duration、aspect ratio
- **负向 Prompt**：不支持显式负向
- **适配要点**：环境动态、水/烟雾/自然现象；描述物理可信的运动

### Hailuo 海螺（MiniMax）
- **擅长**：人物表演、表情、动作连贯性
- **语法**：中文友好；描述动作与表演
- **关键参数**：时长、分辨率
- **负向 Prompt**：部分支持
- **适配要点**：人物表演类；保真声明 + 具体表演动作

### Veo（Google Gemini）
- **擅长**：高质量写实、长镜头、复杂场景
- **语法**：英文；详细场景描述
- **关键参数**：duration、resolution（可达 1080p 及以上）
- **负向 Prompt**：支持
- **适配要点**：高质量写实需求；英文详细描述 + 负向 Prompt

## 决策表

| 任务类型 | 首选 | 备选 | 理由 |
|---------|------|------|------|
| 单图动效（人物） | 可灵 / VideoGen | 海螺 | 人物保真强 |
| 单图动效（风景） | VideoGen | Luma | 自然运动 |
| 首尾帧过渡 | 可灵 / 即梦 | VideoGen | 首尾帧支持成熟 |
| 产品展示 | Runway | 即梦 | 电影感运镜 |
| 海报动效 | Runway / Pika | VideoGen | 精致运镜或特效 |
| 环境动态 | Luma | VideoGen | 物理真实感 |
| 多镜头社交视频 | 可灵 / 即梦 | VideoGen 逐镜头 | 一致性较好 |

> **当前会话无第三方平台连接时**：无论任务类型，一律走内置 VideoGen 直接执行；只有 VideoGen 不满足硬性需求（如用户明确点名其他平台）时才按"仅 Prompt 交付"返回其他平台的执行包。

## 通用语法适配规则

1. **语言**：平台偏好英文 → 把 Prompt 翻译成英文，保真声明保持句首。
2. **负向 Prompt**：平台支持 → 单独给出；不支持 → 写成"保持 X 不变，不要改变 Y"的正向约束。
3. **运动强度**：平台支持运动幅度参数 → 默认 low/medium；不支持 → 用"缓慢/逐渐/微微"等词汇控制。
4. **镜头控制**：平台支持 camera 参数 → 显式给出；不支持 → 把镜头运动写进主体描述（如"镜头缓慢推近"）。
5. **首尾帧**：平台支持首尾帧 → 分别提供首帧/尾帧；不支持 → 用文字描述过渡目标状态。
6. **时长**：超出平台单次上限 → 拆成多镜头分别生成，不要请求超长单次生成。
