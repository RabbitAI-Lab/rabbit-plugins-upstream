## Known Risks and Mitigations: <br>
Risk: The skill may save inferred project conventions and stack details in local memory files. <br>
Mitigation: Review files under ~/Clawic/data/nextjs/ before using the skill on sensitive repositories and remove details that should not persist locally. <br>
Risk: Guidance and code examples can be misapplied to the wrong Next.js version or deployment target. <br>
Mitigation: Confirm the project Next.js version, router type, authentication model, and deployment target before applying generated code or configuration changes. <br>
Risk: Authentication, caching, and deployment recommendations may affect application security or freshness guarantees. <br>
Mitigation: Review generated changes before execution, run production-mode builds when validating caching behavior, and keep authentication checks in the data layer for protected reads and writes. <br>
