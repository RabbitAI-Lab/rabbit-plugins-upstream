## Description:

Create Codex hooks. Use when you want to create a hook, write hooks.json, add hook scripts, or automate behavior around agent events.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers use this skill to create or update Codex hooks that configure event-triggered command or prompt behavior around agent workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Hooks intentionally persist and can affect future agent behavior after installation.

Mitigation: Review generated hook scripts and hooks.json entries carefully, keep events and matchers narrow, and prefer project-scoped hooks when possible.
