# Presentation Delivery — 演讲表达

> 把演示文稿变成有说服力的演讲。覆盖叙事结构设计、节奏控制、观众互动技巧和 Q&A 应对策略。

## 能力

- **叙事结构**：设计开场钩子、核心论点、支撑论据和行动号召的完整叙事弧
- **节奏控制**：根据内容密度分配时间，控制 Slide 切换节奏，管理演讲时长
- **观众互动**：设计互动环节（提问、投票、讨论），根据观众反应调整演讲方向
- **Q&A 应对**：准备常见问题的回答策略，处理挑战性问题和突发情况
- **演讲技巧**：肢体语言、声音控制、眼神交流和讲台管理

## 使用方式

在 Claude Code 中使用 `/presentation-delivery` 调用。

```
/presentation-delivery 帮我把这个产品介绍改成 5 分钟 Pitch
/presentation-delivery 为这个技术分享设计叙事结构
/presentation-delivery 准备投资人可能会问的 10 个问题和回答
/presentation-delivery 帮我练习下周的路演演讲
```

## 工作流

1. **明确目标** — 确定演讲目的（说服/教育/激励）和核心信息
2. **设计结构** — 用英雄之旅或问题-方案-证据框架搭建叙事
3. **分配时间** — 为每个 Slide 分配时间，设定关键转折点
4. **准备互动** — 设计互动环节和 Q&A 应对策略
5. **演练反馈** — 模拟演讲，根据反馈调整节奏和内容

## 适用场景

- 创业者向投资人路演
- 独立开发者做产品 Demo
- 技术分享和会议演讲
- 客户提案和竞标演示

## 限制

- 不涉及 Slide 的视觉设计（参考 presentation-design）
- 不涉及 PPT 文件制作（参考 presentation-creator）
- 演讲效果受练习程度影响，技能提供框架但需要实际演练
- 文化差异可能影响演讲风格的适用性
