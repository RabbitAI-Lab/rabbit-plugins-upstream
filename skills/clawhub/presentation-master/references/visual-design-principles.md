# 视觉设计原则手册（Visual Design Principles）

> 子技能 `presentation-design` 给了"视觉层级、信息图表、配色"的方向，但没给出**字号阶梯怎么定、图表怎么选、对比度怎么算、栅格怎么用**的可执行规则。本篇把视觉决策从"好看就行"升级为带阈值的决策矩阵。

## 1. 字号阶梯（Type Scale）

用固定比例（如 1.25 大三度）生成层级，避免随意字号：

| 角色 | 倍数 | 示例（基准 32px） |
|------|------|-------------------|
| 页标题 | 2.0 | 64px |
| 区块标题 | 1.5 | 48px |
| 正文 | 1.0 | 32px |
| 注脚 | 0.75 | 24px |

> 反模式：一页出现 6 种字号 → 层级感消失。限制在 4 档以内。

## 2. 图表选型矩阵

| 你想表达 | 用 | 不用 |
|----------|----|------|
| 趋势 / 随时间变化 | 折线图 | 饼图 |
| 占比 / 构成（≤5 类） | 饼图/环图 | 折线图 |
| 类别对比 | 柱状图 | 雷达图 |
| 分布 / 相关性 | 散点图 | 饼图 |
| 排名 | 条形图（横向） | 折线图 |
| 多变量关系 | 雷达图（谨慎） | 一堆饼图 |

铁律：**一张图只讲一件事**。图标题要说结论（"X 增长 3 倍"），不是"X 趋势"。

## 3. 配色与对比度

- 主色 ≤1，辅助色 ≤2，中性色（灰/黑/白）打底。
- 文本/背景对比度 ≥4.5:1（WCAG AA），大文本 ≥3:1。
- 用色编码时**同时给文字/形状标签**，别让色盲用户丢失信息。
- 渐变少用，避免廉价感与可读性下降。

对比度公式见 `figma-master` 的 `design-review-checklist.md`（同一组织，复用阈值）。

## 4. 栅格与留白

- 用 12 列栅格对齐元素，避免自由摆放。
- 页边距 ≥ 5% 宽度，元素不贴边。
- 留白是内容：一页塞满 = 没有重点。内容占页面 ≤70%，其余留白。

## 5. 一致性扫描（辅助命令）

```bash
# 扫描硬编码颜色（应来自主题/模板）
grep -rnoE '#[0-9a-fA-F]{6}' slides/ | sort | uniq -c

# 检查字号档位是否失控（统计出现的 font-size 种类）
grep -rhoE 'font-size:\s*[0-9]+px' slides/ | sort | uniq -c
```

## 6. 典型坑与规避

| 坑 | 表现 | 规避 |
|----|------|------|
| 字号太多档 | 层级混乱 | 限 4 档，用比例阶梯 |
| 饼图塞 10 类 | 看不清 | 改条形图/合并小类 |
| 图标题写"X 趋势" | 没结论 | 写结论句 |
| 低对比文字 | 看不清 | ≥4.5:1 |
| 只靠颜色编码 | 色盲丢信息 | 加标签/形状 |
| 一页塞满 | 无重点 | 内容 ≤70%，多留白 |

## 7. 配色与字体配对

| 场景 | 主色 | 辅助 | 字体配对 |
|------|------|------|----------|
| 科技/投资 | 深蓝 | 青/橙点缀 | Inter + Inter（粗体做标题） |
| 消费/品牌 | 品牌主色 | 中性灰 | 展示体标题 + 无衬线正文 |
| 教育/温和 | 绿/暖橙 | 米白 | 圆体标题 + 无衬线正文 |

> 字体不超过 2 族：一族做标题（可展示体），一族做正文（无衬线）。第三族必乱。

## 8. 图标与交付

- **图标**：同一套图标库（线性/面性统一），尺寸对齐栅格，描边粗细一致。
- **图片**：用真图而非占位灰块；压缩到合理体积，避免首页巨图拖慢加载。
- **交付前扫描**：
  ```bash
  grep -rnoE '#[0-9a-fA-F]{6}' slides/ | sort | uniq -c   # 散色应来自主题
  grep -rhoE 'font-size:\s*[0-9]+px' slides/ | sort | uniq -c  # 字号档位应 ≤4
  ```

## 9. 实战：一页数据页的视觉改造

改造前：深底 + 6 种字号 + 饼图塞 9 类 + 文字对比度 2.8:1。
改造后：
- 字号收 4 档（64/48/32/24），标题结论化"X 增长 3 倍"
- 饼图改横向条形图，合并小类到"其他"
- 文字改 `#111827`（对比度 4.6:1）
- 主色蓝 + 辅助橙点缀，其余中性灰
- 12 列栅格对齐，内容占 65%

改造后可读性、扫读性显著提升，且通过 `figma-master` 的一致性扫描。

## 10. 视觉反模式（扩展）

| 反模式 | 后果 | 修正 |
|--------|------|------|
| 字号 >5 档 | 层级乱 | 限 4 档 |
| 饼图 >5 类 | 看不清 | 改条形/合并 |
| 图标题写"趋势" | 无结论 | 写结论句 |
| 低对比文字 | 看不清 | ≥4.5:1 |
| 只靠颜色编码 | 色盲丢信息 | 加标签 |
| 一页塞满 | 无重点 | 内容 ≤70% |
| 渐变滥用 | 廉价 | 少用 |
| 字体 >2 族 | 杂乱 | 标题+正文 |
| 图标混风格 | 不专业 | 统一一套 |
| 无栅格 | 错位 | 12 列对齐 |

## 11. 逐页视觉走查清单

对每页过一遍，记录不达标项：
```
页1 标题: 字号64 ✓ / 对比度 ✓ / 内容占比60% ✓
页2 图表: 一图一事 ✓ / 标题结论 ✓ / 配色≤主1+辅2 ✓
页3 表格: 对齐 ✓ / 字号统一 ✓ / 无散色 ✓
...
```
汇总后一次改完，再复走查，避免改一页漏一页。

## 12. 视觉检查清单

- [ ] 字号 ≤4 档，遵循比例阶梯
- [ ] 每图只讲一件事，标题是结论
- [ ] 图表选型匹配数据意图（见矩阵）
- [ ] 文本对比度 ≥4.5:1
- [ ] 用色 ≤主1+辅2+中性，含标签不靠色
- [ ] 12 列栅格对齐，页边距 ≥5%
- [ ] 内容占页 ≤70%，留白充足
- [ ] 已跑一致性扫描，无失控字号/散色

## 13. 演示母版与主题系统

把视觉规则固化到母版/主题，比每次手调更稳、更易维护：

- **定义主题变量**：主色/辅色/中性色、字号阶梯、间距、圆角、阴影都做成变量（CSS 自定义属性或设计工具 Styles），改一处全篇生效。
- **母版页**：每页套同一母版，页眉/页脚/页码/Logo 位置统一，杜绝"每页各放一个标题、位置还不一样"。
- **栅格锁定**：母版内置 12 列栅格参考线，元素只能落网格交点，避免自由摆放错位。
- **字体配对写死**：标题一套、正文一套，配在主题里，禁止单页临时换字体族。
- **暗色模式**：另建一套暗色主题变量，复用同一套语义名（如 `--text-primary`），不靠自动反色——自动反色常把低对比文字翻成更看不清。
- **示例调色板**（深蓝科技风）：

  | 角色 | 变量 | 值 | 用途 |
  |------|------|-----|------|
  | 主色 | `--color-primary` | `#1d4ed8` | 关键强调、主按钮 |
  | 辅色 | `--color-accent` | `#f97316` | 点缀、高亮一处 |
  | 中性-文字 | `--text-primary` | `#111827` | 正文（对比度 4.6:1） |
  | 中性-底 | `--bg` | `#ffffff` | 背景 |
  | 中性-次 | `--text-muted` | `#6b7280` | 注脚（仅大文本用） |

## 14. 视觉走查的执行流程

不要凭感觉"看一眼"，按固定流程走查，避免漏项也避免改一漏一：

1. **缩略图总览**：把所有页缩成缩略图排开，先检查整体节奏——是否某段页型雷同、是否某页突兀断裂、密度是否忽高忽低。
2. **逐页过清单**：用"视觉检查清单"（见 `## 12`）逐页打勾，记录不达标项与所在页。
3. **统一改**：汇总所有问题后一次性改完，再复走查；单页零散改容易改好这页又带崩那页。
4. **灰度/投影测试**：投到实际设备看对比度与字号，屏幕预览和实际投影常差一截，浅灰文字一投影就糊。

> 走查的铁律：**先总览节奏，再逐页细节，改完复走查**。视觉缺陷往往是系统性的（如全篇字号档失控），单页修无意义。

## 15. 常见视觉决策问答

- **Q：一页要不要加背景图？** A：除非图直接支撑论点，否则用纯色/轻渐变底；装饰图抢注意力。
- **Q：强调色用几个？** A：一页最多一个高亮色，处处高亮等于无强调。
- **Q：字号阶梯怎么定？** A：用固定比例（如 1.25）生成 4 档，不随手定。
- **Q：图表配色和主题冲突？** A：图表用主题辅色系，不与主色打架；类别多时加形状标签。
- **Q：要不要动画？** A：转场 ≤300ms，提供 `prefers-reduced-motion` 降级，不遮挡内容。
- **Q：一页塞两张图？** A：除非强对比，否则一页一图，第二张放备注或拆页。
