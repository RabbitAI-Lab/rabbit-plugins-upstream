# 幻灯片内容规则手册（Slide Content Rules）

> 子技能 `presentation-design` 讲"视觉层级、信息图表、排版"，`presentation-creator` 讲"控制信息密度"，但没把**一页多少字算密、标题层级怎么统一、跨页一致性怎么查**量化成可机械检查的清单。本篇把内容密度规则固化，并直接对应 [scripts/check_presentation.py](../scripts/check_presentation.py)。

## 1. 字数预算（密度红线）

每页非空白字符数建议上限（与脚本 `presentation_rules.json` 的 `max_chars_per_slide` 对齐）：

| 页型 | 字数上限 | 说明 |
|------|----------|------|
| 标题/过渡页 | 20 | 大字少字 |
| 内容页 | 120 | 要点化，非段落 |
| 图表页 | 60 | 图为主，注脚为辅 |
| 收尾页 | 40 | CTA 一句话 |

> 经验：观众读一页文字需要 5–10 秒。若一页要读 30 秒，你讲的时候他们都在默读，没听你说话。把段落拆成要点（bullet），每点 ≤20 字。

## 2. 标题层级规范

- 每页**必须有且只有一个标题**，用统一层级（默认 `#`，即一级标题）。
- 页内小标题用更深层级（`##`/`###`），不得与页标题同级，避免层级混乱。
- 跨页标题层级必须一致：不能第 3 页用 `#`、第 5 页用 `##`。

脚本会查：每页缺标题 → ERROR；页标题层级 ≠ 配置 `title_level` → ERROR；跨页层级混用 → ERROR。

## 3. 一致性规则

| 规则 | 检查 | 违反表现 |
|------|------|----------|
| 标题不重复 | `forbid_duplicate_titles` | 两页同名"背景"，观众困惑 |
| 层级统一 | 标题层级一致 | 混用 `#`/`##` |
| 术语统一 | 人工 | 同一概念多种叫法 |
| 时态统一 | 人工 | 中英混排时态跳变 |

## 4. 决策矩阵：一段话该留还是拆

| 情况 | 处理 |
|------|------|
| 一段 >120 字 | 拆成 2–3 个 bullet |
| 一页 >3 个要点 | 拆页或归并 |
| 一个要点 >20 字 | 缩写，细节放备注 |
| 含数据 | 转图表（见 `visual-design-principles.md`） |

## 5. 可执行的检查命令

```bash
# 检查大纲：字数/标题层级/重复标题
python3 scripts/check_presentation.py outline --file deck.md

# 自检：校验内置资产（规则+示例大纲）应为 0 ERROR
python3 scripts/check_presentation.py selfcheck
```

## 6. 格式约定（Markdown deck）

用 `---` 分隔页，每页首行是标题：

```markdown
# 开场：为什么这件事重要
一句话钩子 + 一个数据点。

---

# 我们的方案
- 要点一（≤20 字）
- 要点二（≤20 字）
```

## 7. 典型坑与规避

| 坑 | 表现 | 规避 |
|----|------|------|
| 一页写满段落 | 观众只读不听说 | 拆 bullet，每点 ≤20 字 |
| 标题缺失 | 不知这页讲啥 | 每页一个标题 |
| 标题层级乱 | 结构混乱 | 统一层级，页标题用 `#` |
| 标题重复 | 两页同名困惑 | 禁止重复标题 |
| 字数爆表 | 信息过载 | 跑脚本卡 120 字红线 |
| 中英混排时态乱 | 不专业 | 统一时态与术语 |

## 8. 信息图表化决策

| 内容形态 | 转成 | 不转成 |
|----------|------|--------|
| 趋势 | 折线图 | 段落 |
| 对比 | 条形图 | 表格长文 |
| 占比 | 环图（≤5 类） | 饼图（>5 类） |
| 流程 | 箭头图 | 列表 |
| 关系 | 矩阵/ Venn | 文字描述 |

铁律：一图只讲一件事，图标题写结论（"X 增长 3 倍"），不是"X 趋势"。

## 9. 备注页与多语言排版

- **备注页**：给演讲者的提示，不放观众可见页；含数据出处、可能的追问。
- **多语言**：中英混排时统一标点（全角/半角一致），术语首次出现给原文。
- **数字**：大数用 `1.2M` 而非 `1200000`，提高扫读性。
- **强调**：一页最多一个高亮色，避免处处加粗等于没强调。

## 10. 实战：把一段 200 字段落拆成合规页

原文（超密）：
> 我们的系统首先采集用户行为日志，经过清洗后存入数据湖，再用实时管道做特征工程，最后模型在线推理并返回推荐结果，全程监控延迟与准确率指标。

拆后（每页一主张）：
```
# 数据采集与清洗
- 行为日志采集，异常值过滤
- 落数据湖，供离线/实时复用

# 实时特征工程
- 流管道计算特征
- 特征版本化管理

# 在线推理与监控
- 模型实时返回推荐
- 监控延迟与准确率
```
每页 ≤120 字、要点化、无大段。跑 `check_presentation.py outline` 应 0 ERROR。

## 11. 内容反模式（扩展）

| 反模式 | 后果 | 修正 |
|--------|------|------|
| 段落 >120 字 | 观众只读不听说 | 拆 bullet |
| 标题缺失 | 不知讲啥 | 每页一个标题 |
| 标题层级乱 | 结构乱 | 统一 `#` |
| 标题重复 | 混淆 | 禁重复 |
| 中英时态乱 | 不专业 | 统一 |
| 一图多意 | 看不懂 | 一图一事 |
| 满页艺术字 | 廉价 | 克制字体 |
| 无备注页 | 演讲卡壳 | 每页备备注 |

## 12. 长文档转演示的提炼法

把一份报告变成演示，不是复制而是提炼：

| 文档元素 | 演示处理 |
|----------|----------|
| 摘要段 | → 钩子页（取最反直觉一句） |
| 章节标题 | → 路线图各页标题 |
| 数据表 | → 图表（结论作标题） |
| 论证段落 | → 每页一个主张 + 证据 bullet |
| 结论段 | → 总结 CTA 页 |
| 附录 | → 备注页 / Q&A 预案 |

铁律：演示是**论点集**不是**文档搬家**；能删的删，能图的图，能说的说。

## 14. 数据叙事与图表文案

把数据放上屏，不是贴表格，而是讲一个结论。规则：

- **结论前置**：图表标题写结论（"X 增长 3 倍"），不写"X 趋势"；观众先读结论再读图。
- **一图一事**：一张图只承载一个论点，双轴/双主题图一律拆。
- **去装饰**：删网格线、3D 立体、阴影、图例冗余；只留支撑结论的必要元素。
- **标注关键值**：在折线拐点、柱状顶端直接标数字，观众不必回头比对坐标轴。
- **排序有逻辑**：条形图按值降序（除非是时间序列必须按时间）；乱序会误导注意力。

决策树（给数据选载体）：
```
数据形态 = 序列随时间？
 ├─ 是 → 折线（横轴时间，纵轴量）
 └─ 否 → 数据是占比？
          ├─ 是（≤5 类）→ 环图，最大块从 12 点钟起
          └─ 否 → 数据是排名/对比？
                   ├─ 是 → 横向条形（按值降序）
                   └─ 否 → 是关系/分布？
                            ├─ 是 → 散点
                            └─ 否 → 表格（但先确认能否转图）
```

## 15. 远程演示的字号与可读性

远程观看距离远、屏幕参差，现场标准要上调：

- **正文字号 +1 档**：现场 32px，远程至少 36–40px；标题同步放大。
- **对比度再拉高**：远程压缩会降对比，文本/背景 ≥5:1 比 4.5:1 更稳。
- **减少一页信息量**：远程注意力更易散，每页要点减到 3 个以内，密度比现场再低一档。
- **高亮唯一**：一页最多一个高亮色，远程下弱对比的"次级强调"几乎不可见。
- **备注兜底**：远程易冷场，每页备注写"下一句要抛的问题"，维持互动。

> 远程演示的铁律：**字大一点、字少一点、对比强一点**。宁可少讲，别让观众眯眼。
