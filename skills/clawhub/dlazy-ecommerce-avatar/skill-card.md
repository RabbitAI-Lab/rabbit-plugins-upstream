## Description:

Guides creation of ecommerce spokesperson videos with reusable avatar portraits, product scripts, speech, lip-synced clips, and supporting footage.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and marketing teams use this skill to plan and produce short product-selling videos with a consistent AI spokesperson for ecommerce channels.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and media assets are sent to dLazy services during generation.

Mitigation: Use the service only for content you are comfortable uploading.

Risk: Using the dLazy CLI can store an API key locally.

Mitigation: Protect the local key and review how the CLI stores credentials before signing in.

Risk: Generation requests consume credits, including costly avatar-video steps.

Mitigation: Review credit costs and use --dry-run to check commands where recommended before generation.
