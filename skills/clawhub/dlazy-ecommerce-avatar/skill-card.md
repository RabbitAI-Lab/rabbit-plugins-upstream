## Description:

Provides portrait recipes and a workflow for creating ecommerce spokesperson videos, from scripting and voice generation through avatar animation and B-roll.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

External creators and ecommerce teams use this skill to create reusable virtual spokesperson portraits and product selling videos. It provides portrait prompts, scripting and voice guidance, avatar generation steps, and video assembly workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Selected images, audio, and video clips are sent to external providers.

Mitigation: Use assets you are authorized to share, review each provider’s privacy terms, and avoid submitting confidential material.

Risk: Paid generation can incur costs, and the CLI API key is saved locally.

Mitigation: Use --dry-run to inspect estimated costs and protect the saved API key.
