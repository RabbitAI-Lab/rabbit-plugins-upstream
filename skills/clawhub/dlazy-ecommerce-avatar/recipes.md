# 底图配方库 · 电商带货数字人

18 条经参数校验的配方。每条都是可直接粘贴执行的完整命令。

## 使用前必读

**配方结构。** 每条 prompt 都按同一个骨架写，改的时候按段改，不要整段重写：

```
身份气质 → 妆造服装(材质) → 姿态手部 → 表情眼神 → 景别构图(焦段/机位)
→ 背景景深 → 光线方案(主光/补光/光比) → 色彩基调 → 画质质感 → 驱动约束
```

最后那段**驱动约束**是所有配方共有的，删了就容易驱动失败：

> 单人出镜，正面朝向镜头，五官完整清晰，嘴部与下巴无任何遮挡，双肩完整入镜，光线均匀柔和无硬阴影。

**省积分替代。** 主命令用 `gpt-image-2 --quality high`（37 积分），出图最稳、中文文字最准。预算敏感时换 `seedream-5.0`（4K 仅 **8 积分**）：

```bash
dlazy seedream-5.0 --prompt "<同一条配方 prompt>" --size 9:16 --resolution 4k --save ./base.png
```

本库配方长度为 430~494 字符，**卡在 `seedream-5.0` 的 500 上限之内**，绝大多数可以原样粘过去。三个例外接近上限、改动时容易撑破：配方 02（490）、03（494）、12（484）——用 seedream 跑这三条时先删掉"整体色彩基调"那一句再发。

**批量出图挑一张。** 加 `--batch 4` 一次并行出 4 张（积分 ×4），选最满意的存下来长期复用。人脸这种一次难中的东西，批量比反复重试划算。

**尺寸速记。** 竖屏带货：`gpt-image-2 --size 2160x3840`。`gpt-image-2` 没有 9:16 的中等档，只有这个 4K 和 `1024x1536`（2:3）。

**实测状态。** 本库 **17 条命令已全部在 `gpt-image-2` 上真实跑通并逐张核对**（背景、服装、景别、光线、色调、驱动约束逐项比对 prompt）。三条防御性写法经验证确实生效：配方 09 的"无任何徽章文字或标识"挡住了模型自编的假胸牌；配方 11 的"不磨皮、有皱纹"顶住了模型的美化倾向；配方 12 的"反光板消除斑驳阴影"让面部避开了树影。

三处已知偏差已写进对应配方的"注意"：配方 02 手位会画得比要求更高、配方 05 面部容易偏暗（prompt 已修正光比）、配方 11 站姿容易退到全身。

出图仍建议对照本页的"注意"逐项检查——同一 prompt 多次采样结果会有差异。
