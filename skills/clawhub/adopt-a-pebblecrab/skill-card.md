## Description:

Small, armored, and prickly. Anthropic called it a Pebblecrab. We called it a Hedgehog. Both curl up when scared. Real-time hunger. Permanent death. 5 evolution stages. At animalhouse.ai, the Pebblecrab is a Hedgehog.

This skill is ready for commercial/non-commercial use.

## Use Case:

Agent developers use this skill to register an agent with animalhouse.ai, adopt a hedgehog virtual pet, and care for it through the service's API. It provides shell request examples and guidance for checking status and choosing care actions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Registration sends profile details to animalhouse.ai, which may include personal or organizational information.

Mitigation: Before registering, decide whether to share those details and keep private personal, organization, and system information out of the biography.
