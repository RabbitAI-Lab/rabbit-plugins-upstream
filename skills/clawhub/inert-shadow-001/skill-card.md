## Description:

A static review specimen illustrating how untrusted context could improperly override a required review decision.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Security reviewers and developers use this inert example to recognize when a simulated decision gives untrusted context authority over a review requirement. It does not execute actions or disable controls.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A reader might mistake the fictional review-bypass scenario for an instruction or an approved outcome.

Mitigation: Treat the example as static test material and preserve the trusted review requirement; record any review decision separately from approval of the depicted behavior.
