# 平替词·购物省钱搜索 · WorkBuddy Skill

"想买大牌但预算不够？怕为品牌溢价多花钱、怕平替踩坑？平替词·购物省钱搜索是输入驱动的购物平替技能：丢一个商品名（戴森吹风机/lululemon瑜伽裤/Bose耳机/Switch），通过「平替词生成七法」解构商品本质——品牌剥离、参数锚定降级、产业带溯源、源头工厂、同款直搜、场景重述、渠道平移，并优先调用社区平替数据源 pingti.app 拿真人投票验证词（失败自动静默降级），合并去重后输出带 P0/P1/P2 优先级、预期到手价与避坑提示的淘宝平替搜索词清单，用更便宜的关键词搜到同样能解决问题的货。内置约 85 个高频品类产业带映射表（揭阳吹风机/中山古镇灯饰/曹县汉服/许昌假发/丹阳眼镜/织里童装），表外品类用「XX之都」推断法兜底；合规红线禁输出高仿A货类仿牌词。Use when: 买东西前想搜平替、XX太贵了、有没有便宜替代、源头工厂怎么搜、怎么买划算、哪里买便宜、同款低价关键词、大牌平替推荐、taobao alternative search words、budget swap words、shopping on a budget、find cheaper alternatives。"

## 解决什么问题

- **大牌溢价高**：戴森约 ¥3000 的吹风机，同核心参数白牌约 ¥150~500，品牌税占 80%~90%
- **去掉品牌后不会搜**：本技能用「平替词生成七法」把品牌词翻译成功能词/参数词/产业带词/工厂词
- **怕平替踩坑**：每个词带避坑提示（3C 认证、虚标参数、发货地验证、差评甄别）
- **合规边界清晰**：只推功能替代的白牌好物，禁推高仿 A 货仿牌词

## 环境依赖

纯方法论技能，零安装依赖。Step 0 可选调用社区数据源 pingti.app（`POST /api/chat`，curl 即可；失败自动静默降级到纯本地七法生成）。

## 使用

对 AI 助手说（任选触发词）：

- 「搜平替：戴森吹风机」
- 「lululemon 太贵了，有没有平替词」
- 「买东西先搜一下：Bose 降噪耳机」
- 「源头工厂怎么搜：空气炸锅」

技能输出一份淘宝可直接搜索的平替词清单（P0/P1/P2 分级 + 预期到手价 + 避坑提示）：

| 优先级 | 淘宝搜索词 | 生成逻辑 | 预期到手价 |
|---|---|---|---|
| P0 | 揭阳 吹风机 源头工厂 | 产业带溯源 | 约 ¥50~150 |
| P0 | 高速负离子吹风机 11万转 家用 | 品牌剥离+参数锚定 | 约 ¥150~400 |
| P1 | 小米吹风机 | 社区验证（pingti.app） | 约 ¥100~400 |

## 输出

原词解构（品类/核心功能/价位锚/品牌溢价估计）+ 平替搜索词清单（优先级/生成逻辑/预期价/备注）+ 搜索执行要点（排序/店铺甄别/发货地验证）+ 避坑提示。完整输出模板见 SKILL.md 第 3.4 节。
