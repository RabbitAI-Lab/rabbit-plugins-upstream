# 1. 技能定位与边界

## 1.1 干什么

用户输入一个词（品牌名、型号、品类名、甚至一句需求描述），本技能输出一份**淘宝可执行的平替搜索词清单**：用这些词去淘宝搜，能搜到解决同样问题的更便宜商品。

平替的本质一句话：**把「品牌溢价词」转译成「功能词 / 参数词 / 产业带词 / 工厂词」**。

## 1.2 不干什么（与「薅羊毛助手」的边界）

| 场景 | 归属 |
|---|---|
| 「戴森吹风机太贵，用什么词能搜到便宜替代」 | **本技能** |
| 「戴森吹风机在哪买最便宜 / 有没有隐藏券 / 哪个平台划算」 | 薅羊毛助手 |
| 「今天有什么神券 / 今日好价」 | 薅羊毛助手 |

判定口诀：**换词搜替代 → 本技能；同物找低价 → 薅羊毛助手。** 若用户表述同时含两层意图（「戴森哪有便宜的替代还不踩坑」），先走本技能出平替词，再提示可对选中的目标款转询薅羊毛助手查券。

## 1.3 数据源（双轨，社区优先）

| 数据源 | 角色 | 说明 |
|---|---|---|
| pingti.app（社区平替） | **优先调用** | 「最佳平替」站点，输入商品名返回 AI 生成的平替词 + 一句理由，带 up/down/funny 投票，代表社区真人验证过的方向 |
| 七法本地生成 | 主力兜底 | 不依赖外部 API，保证 pingti 挂了也能出完整方案 |

pingti.app 的角色是**社区验证候选词**，不是主力：它一次只返回一个词、偏渠道方向（二手/拼多多）、有 429 限流，所以必须与七法结果合并使用，且其返回词先过第 6.1 节合规红线。

# 2. 核心方法论：平替词生成七法

同一商品至少用 3~5 种方法生成候选词，覆盖不同省钱路径。每法给出「适用场景 + 示例」。

## 2.1 品牌剥离法

去掉品牌名，保留「品类 + 核心参数」。适用于功能标准化、品牌溢价高的品类（戴森、Bose、lululemon、无印良品等）。

- 输入：戴森吹风机 → 输出「高速负离子吹风机 11万转 家用」
- 输入：Bose QC 耳机 → 输出「头戴式主动降噪蓝牙耳机」

## 2.2 参数锚定降级法

先识别原商品「80% 体验由哪 20% 参数决定」，只保留关键参数，砍掉营销参数。

- 吹风机关键参数 = 风速（转速）+ 负离子；营销参数 = 外观、配色、智能温控频次
- 扫地机器人关键参数 = 吸力（Pa）+ 导航方式（LDS/视觉）；营销参数 = App 皮肤、语音包
- 瑜伽裤关键参数 = 面料克重 + 裸感贴合度；营销参数 = 侧袋设计、品牌 logo

## 2.3 产业带溯源法

把品类映射到源头产业带，用「产地 + 品类」搜索。这是省钱幅度最大、质量最稳的一类词。映射表见第 4 章；表内没有的品类，用第 4.2 节推断法。

- 输入：吹风机 → 「揭阳 吹风机」「揭阳 电吹风 源头工厂」
- 输入：四件套 → 「南通 四件套 源头」

## 2.4 源头工厂法

加「厂家直销 / 源头工厂 / 工厂直发 / 批发」等工厂属性词，过滤中间经销商。

- 「吹风机 厂家直销」「空气炸锅 源头工厂」
- 注意：淘宝个人店也能挂这些词，需配合第 5.2 节甄别。

## 2.5 同款直搜法

直接搜「XX 平替 / XX 同款 / 大牌平替 / 山姆同款 / 胖东来同款 / 无印良品平替」。

- 风险提示：此类词下假货/仿款混杂，仅作候选不作首推；必须在避坑区提醒甄别「功能替代」与「假冒品牌」。

## 2.6 场景重述法

彻底忘掉原商品名，从真实使用场景重新描述需求，往往能发现没见过的新品类方案。

- 输入：Dyson 吸尘器 → 场景「租房党 掉发多 每天吸地 预算 300」→ 「无线吸尘器 大吸力 宠物毛发」
- 输入：Switch → 场景「掌上玩塞尔达」→ 「win 掌机 开源系统」

## 2.7 渠道平移法

同一关键词换渠道搜，价格台阶再降一级：

- 淘宝词 → 复制到 1688 搜（同源厂货，常见 3~5 折）
- 闲鱼搜「全新未拆 / 公司礼品 / 展会赠品」（低价全新）
- 注意：1688 多数不包邮、需凑起批量，适合非急需品。

# 3. 执行流程（五步）

## 3.0 Step 0：调用 pingti.app 拿社区验证词（优先，失败静默降级）

**每次执行先跑这一步**，拿社区真人投票验证过的平替词。

调用方式（Bash 工具；注意：若环境注入了失效的代理端口，先用 `no_proxy=\"*\" HTTPS_PROXY=\"\" HTTP_PROXY=\"\"` 清空代理变量再请求，否则 curl 会卡死）：

```bash
no_proxy="*" HTTPS_PROXY="" HTTP_PROXY="" https_proxy="" http_proxy="" \
  curl -s --max-time 15 -X POST "https://pingti.app/api/chat" \
  -H "Content-Type: application/json" \
  -H "User-Agent: Mozilla/5.0" \
  -d '{"messages":[{"role":"user","content":"{输入词}"}]}'
```

返回格式：`{"response":"平替词","reason":"一句调侃式理由"}`。

规则：

1. **查询变体**：最多依次查 2 个变体（原词、「{原词}的平替」），每次间隔 2 秒防 429；拿到第一个有效词即可停，想提升覆盖率再查第二个；
2. **成功**：词进候选池，标注来源「社区验证」；reason 中有信息量的部分（如「二手」暗示渠道方向）提炼进备注，俏皮话删去；
3. **失败处理**：超时 / 429（「访问服务器太频繁了」）/ 网络错误 / 返回无法解析 → **静默降级**到纯七法生成，不阻塞、不在输出里报错，至多标注「社区源暂不可用」；
4. **合规过滤**：返回词先过第 6.1 节红线（如「华强北耳机」在耳机语境指向仿牌 → 丢弃该词），命中则当次调用视为无效，继续七法；
5. **渠道转换**：pingti 推荐词常指向非淘宝渠道（拼多多/闲鱼/二手），按第 6.2 节第 4 条转换为淘宝可搜等价词或明确标注主战场。

## 3.1 Step 1：输入解构

逐项写出，不允许跳过：

1. 品类（这是什么）
2. 核心功能（不可妥协，通常 1~2 条）
3. 可降级功能（可以砍的营销参数）
4. 典型使用场景
5. 原词价位锚（公知价位，写「约」并标注置信度）
6. 品牌溢价粗估（原价中大约多少比例是品牌税）

## 3.2 Step 2：生成候选词

对输入词至少应用 3 种方法（七法中选最适配的），每词标注：

- 生成逻辑（用了哪法；来自 pingti 的标「社区验证」）
- 预期到手价区间
- 一句话备注（为什么这个词能替代 / 风险点）

**与 Step 0 社区词合并**：pingti 返回词若与七法生成的词同向（如同为二手渠道、同为首推方向），合并为一条并在生成逻辑列标「社区验证+{七法名}」；若方向不同，单独成条。社区词通常给 P1（真人投票背书方向对，但偏渠道、未必能直接在淘宝搜到同款）；与七法强词撞车时以七法词为主、社区词作备注。

## 3.3 Step 3：排序分级

| 级别 | 判定标准 |
|---|---|
| P0 | 省钱幅度大且踩坑风险低（产业带词/参数词为主），优先搜 |
| P1 | 有效但有甄别成本（工厂词/渠道词） |
| P2 | 搜得到但风险高或省钱有限（同款直搜词） |

## 4.2 表外品类推断法（映射表查不到时）

1. 回忆该品类的「之都/之乡」称号（如中国眼镜之乡=丹阳、中国鞋都=晋江/温州、中国瓷都=景德镇）；
2. 仍不确定时，先搜「XX 之都」「XX 产业带」「XX 产地批发」确认，再把确认的产地写进生成的搜索词；
3. 推断不出产地时，退回第 2.1 节品牌剥离法 + 第 2.7 节渠道平移法（1688/闲鱼），这两个方法不依赖产地知识。

# 5. 淘宝搜索实操技巧

## 5.1 排序与筛选

1. 排序选「销量」而非「综合排序」——综合前几位多为直通车广告位；
2. 先裸搜看销量前 20 的自然价位带，再用价格筛选把区间收到该价位带的 60%~80%；
3. 同义词换着搜：同一商品不同写法的结果差异极大（电吹风/吹风机、四件套/床品套件）。

## 5.2 识别源头好店

1. 店铺类型优先级：企业店/工厂店/旗舰店 > 五年以上老店 > 个人 C 店；
2. 看「回头客」比例与开店年限，回头客率高的白牌厂店通常品控稳定；
3. 发货地与搜索词中的产业带是否一致（搜「揭阳吹风机」而发货地在廊坊，需警惕）；
4. 详情页有车间/生产线实拍的多为真工厂店。

## 5.3 评价甄别

1. 重点看差评和追评，信息量高于好评；
2. 差评集中在「质量/做工/与描述不符」→ 品控问题，放弃；
3. 差评集中在「物流慢/包装破」→ 可接受；
4. 带图追评看实物与详情页的色差、做工细节。

## 5.4 拍立淘以图搜图

在别处（小红书/朋友家/线下店）看到心仪商品，用淘宝相机图标以图搜图，直接找同款最低价货源，是最快的平替路径。

# 6. 避坑与合规红线

## 6.1 合规红线（不可违反）

1. **不生成指向假冒品牌/侵权的搜索词**：「高仿」「A 货」「1:1」「超 A」「原单」等一律禁止输出；
2. 本技能的「平替」指**功能替代的白牌好物**，不是假货。同款直搜词（第 2.5 节）必须附甄别提醒；
3. 药品、医疗器械、婴配方奶粉、保健食品不做平替推荐，引导认准国药准字/OTC/注册证号的正规渠道；
4. pingti.app 返回的词先过红线再入池：「华强北耳机」类借地名电子市场名义指向仿牌的一律丢弃；站点风格偏娱乐化，其推荐词必须按常识复核后再用。

## 6.2 价格异常识别

1. 到手价低于正品公价 1~2 折的，大概率翻新、瑕疵品或货不对板，宁可不买；
2. 白牌电器必须查 3C 认证（详情页/认证编号），无 3C 的电器不推荐；
3. 「工厂直销」但起批量要求极高的（如 1000 件起）不适合个人，改走 1688 分销或换词；
4. pingti.app 渠道词转换：其推荐常是「拼多多瑜伽裤」「二手 XX」这类非淘宝词——要么转换为淘宝等价词（「瑜伽裤 义乌」「瑜伽裤 厂家直销」），要么在备注明确「该词主战场在拼多多/闲鱼」，不许原样当成淘宝搜索词输出。
