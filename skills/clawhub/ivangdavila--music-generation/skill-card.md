## Known Risks and Mitigations:

Risk: Music prompts, lyrics, uploaded audio, and related metadata may be sent to third-party providers.

Mitigation: Use providers only when their terms allow the intended data use, and avoid confidential or unreleased material unless sharing is approved.

Risk: API keys and provider credentials may be exposed or over-scoped during experimentation.

Mitigation: Use throwaway or scoped API keys, store credentials outside prompts and source files, and rotate keys after testing.

Risk: Unpinned package installs or cloned repositories can introduce supply-chain risk.

Mitigation: Review dependency versions and run local setup commands inside an isolated virtual environment or container.
