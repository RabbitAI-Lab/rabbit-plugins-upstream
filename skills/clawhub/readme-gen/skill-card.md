## Description:

Generates a project README.md from its structure and common project files.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vexify-build](https://clawhub.ai/user/vexify-build)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to draft a project README with an overview, installation and usage steps, a file tree, and licensing information.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A generated README may reveal private filenames, internal scripts, or sensitive project details.

Mitigation: Review the README and remove sensitive details before publishing.

Risk: Template examples may misstate a project's commands or license.

Mitigation: Confirm installation and usage commands and licensing against the project before publishing.
