## 一级目录说明
- 三藏经文：经藏 / 律藏 / 论藏 原文（巴利语—中文对照）
- 义注：经藏、律藏的注释（Atthakatha）
- 复注：复注（Tika）
- 藏外典籍：藏外文献

## 常用经文快速定位
- 转法轮经 SN 56.11（四圣谛） -> 三藏经文/经藏/相应部/大品（相应部）
- 大念处经 MN 10（四念处） -> 三藏经文/经藏/中部/根本五十经
- 入出息念经 MN 118 -> 三藏经文/经藏/中部/后五十经
- 法句经 Dhammapada -> 三藏经文/经藏/小部/法句
- 本生 Jataka（偈颂） -> 三藏经文/经藏/小部/本生-1、本生-2
- 本生故事（序分+叙事+结分，菩萨身份据此）优先查 -> 义注/经藏义注/小部义注/本生义注-1~7
- 法句义注故事 -> 义注/经藏义注/小部义注/法句义注
