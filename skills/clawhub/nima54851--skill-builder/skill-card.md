## Description:

Skill Builder helps agents create OpenClaw-style agent skills, including SKILL.md content, supporting scripts and references, packaging guidance, and release preparation.

This skill is ready for commercial/non-commercial use.

MIT-0

## Use Case:

Developers and agent builders use this skill to design, scaffold, document, package, and prepare OpenClaw-style skills for release.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated or scaffolded skills can influence future agent behavior if enabled without review.

Mitigation: Review and scan each generated skill before enabling or publishing it.

Risk: The skill may create files under an OpenClaw skills workspace during setup or packaging.

Mitigation: Confirm the intended workspace path and inspect generated files before use.
