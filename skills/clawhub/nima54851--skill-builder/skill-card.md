## Description: <br>
Skill Builder helps agents create OpenClaw skills by designing the skill structure, drafting SKILL.md and supporting files, and packaging releases for ClawHub. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[nima54851](https://clawhub.ai/user/nima54851) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and agent builders use this paid workflow to create OpenClaw skills from a user request, including SKILL.md content, optional scripts, references, assets, and package validation steps. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill includes off-platform payment and contact details for obtaining the full package. <br>
Mitigation: Review the payment and support channel before sending payment information or relying on post-payment delivery. <br>
Risk: Following the workflow may create files in an OpenClaw skills workspace. <br>
Mitigation: Review target paths and generated files before running package commands, then scan the resulting skill before deployment. <br>
