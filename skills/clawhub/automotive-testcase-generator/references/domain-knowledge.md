# 车载领域测试知识库（Automotive Domain Knowledge）

> 本文件是 `automotive-testcase-generator` 的领域知识底座。生成用例前通读一遍；
> 具体阶段二/三的**方法选择与质量属性表以内联在 SKILL.md 的为准**，本文件提供背景知识、标准依据与测试要点。

## 1. 知识体系总览：三大支柱

车载测试的核心 = **汽车电子架构认知 + 通信/诊断协议 + 行业标准体系**，再叠加测试方法与工具链。

```
车载测试能力模型
├── ① 汽车电子知识（EEA 架构、ECU、域控制器）
├── ② 总线与协议（CAN / CAN FD / LIN / FlexRay / 车载以太网 / SOME-IP / 诊断协议）
├── ③ 标准与规范（AUTOSAR、ISO 26262、ISO 21434、ASPICE、OEM 企标）
├── ④ 测试方法（V 模型、MIL/SIL/HIL、故障注入、残余总线仿真、场景测试）
└── ⑤ 工具链（CANoe/CAPL、vTESTstudio、DiVa、INCA、CarMaker/PreScan、dSPACE/NI）
```

## 2. 汽车电子电气架构（EEA）

| 概念 | 说明 | 测试关注点 |
|---|---|---|
| ECU（电子控制单元） | 单一功能控制器（发动机、ABS、车窗…） | 每个 ECU 是测试对象（SUT） |
| 域控制器架构 | 智驾域/座舱域/车身域/动力域/底盘域 | 跨域信号交互、中央计算 |
| 网关（GW） | 跨网段转发、路由 | 路由表验证、防火墙策略 |
| OTA | 空中升级 | 升级中断、版本回滚、安全校验 |

## 3. 关键总线与通信协议

| 协议 | 速率/特点 | 典型应用 | 测试要点 |
|---|---|---|---|
| CAN | 500kbps~1Mbps，差分信号 | 底盘、动力、车身控制 | 错误帧检测、位定时、CRC、重发机制 |
| CAN FD | 数据段最高 8Mbps | 新平台替代 CAN | 速率切换、位填充 |
| LIN | 20kbps，主从结构 | 车窗、座椅、雨刮 | 主从调度、响应超时 |
| FlexRay | 10Mbps，时间触发 | 线控制动（历史方案） | 时间触发确定性 |
| 车载以太网 | 100M/1G/2.5G | ADAS、信息娱乐、OTA | 时延、QoS、AVB/TSN |
| SOME/IP | 服务导向中间件 | SOA 架构通信 | 服务发现（SD）、超时、序列化 |
| DoIP | 基于以太网的诊断 | 车云诊断、远程诊断 | 车辆发现、TLS、端口 13400 |

**总线测试通用要点**：报文周期、信号初始值/默认值、错误帧注入后行为、总线负载率、断线/恢复。

## 4. 诊断协议（UDS 重点）

| 协议 | 说明 | 关键概念 |
|---|---|---|
| OBD-II（SAE J1979） | 排放相关诊断 | 模式 01-0A、PID |
| UDS（ISO 14229） | 现代 ECU 主流诊断 | 会话控制(10)、安全访问(27)、DTC(19/14)、读数据(22)、写数据(2E)、例程(31)、刷写 |
| DTC | 故障存储与读取 | 三字节结构、状态位（确认/待确认/历史） |
| ODX（ISO 22901） | 诊断描述文件 | 诊断自动化数据源 |

**诊断测试要点**：会话切换、安全访问失败锁定、DTC 置位/清除、刷写中断恢复、负响应码（NRC）验证。

## 5. 标准与规范体系（国标/行标/企标）

| 层级 | 示例 | 测试意义 |
|---|---|---|
| 国标（强制） | GB 7258 机动车运行安全 | 准入底线，强制项不可豁免 |
| 国标（推荐） | GB/T 28046 环境试验（等同 ISO 16750）、GB/T 32960 新能源远程监控、GB/T 21437 电气传导耦合（等同 ISO 7637） | 国内量产准入 |
| 行标 | QC/T 系列（如 QC/T 29106 低压电线束） | 行业统一要求 |
| 企标 | 主机厂 OEM 验收规范 | **通常严于国标，量产验收线** |
| 国际对应 | ISO 26262 / 21434 / 16750 / 11452、CISPR 25、AUTOSAR、ASPICE | 企标多等同/参考国际标准 |

| 标准 | 名称/主题 | 测试意义 |
|---|---|---|
| AUTOSAR CP/AP | 汽车开放软件架构 | RTE、COM、DCM、DEM 模块行为 |
| ISO 26262 | 功能安全（ASIL A-D） | 安全机制验证、故障注入、ASIL 覆盖 |
| ISO 21434 | 网络安全 | 安全启动、SecOC、诊断安全访问 |
| ASPICE | 软件过程改进 | 测试流程合规（SYS.4/SWE.6） |
| ISO 16750 | 电气环境条件与试验 | 温湿度、振动、电压变化 |
| ISO 11452 / CISPR 25 | EMC | 抗扰/发射测试 |
| GB/T 28046 | 等同 ISO 16750 | 国内量产准入 |
| GB/T 32960 | 新能源汽车远程监控 | 数据上报合规 |
| GB/T 21437 | 等同 ISO 7637 传导耦合 | 瞬态传导测试 |
| QC/T 系列 | 行标 | 行业统一要求 |

**处理原则**：企标 > 国标 > 行标；冲突取更严值；强制国标（GB）为底线。

## 6. 测试类型全景图

| 测试类型 | 说明 | 常用手段 |
|---|---|---|
| 功能测试 | 按需求验证 ECU/系统功能 | 台架 + 测试用例 |
| 网络/协议测试 | 报文、信号、周期、超时、错误帧 | CANoe 分析 + CAPL |
| 诊断测试 | UDS 服务、DTC、刷写 | CANoe.DiVa、诊断仪 |
| 通信一致性测试 | 节点与总线规范一致性 | 一致性测试套件 |
| 性能测试 | 响应时间、吞吐、启动时间 | 打点统计 |
| 鲁棒性/容错测试 | 丢帧、错帧、总线负载异常、电压异常 | 故障注入 |
| 环境与可靠性 | 高低温、湿热、振动、盐雾 | 环境箱、振动台 |

| 功能安全测试 | 安全机制、失效响应 | 故障注入 + ASIL 覆盖分析 |
| ADAS/智能驾驶测试 | 感知、决策、执行在场景中的表现 | 场景仿真 + 实车 |

## 7. 核心测试方法

- **V 模型**：需求分析 → 系统设计 → 详细设计 →（实现）→ 单元/集成/系统/验收测试，测试从需求阶段介入。
- **MIL / SIL / HIL**：模型在环 → 软件在环 → 硬件在环（ECU 实物 + 实时机 + I/O 板卡）。
- **残余总线仿真（Restbus）**：被测 ECU 之外的总线节点由 CANoe 仿真补齐。
- **故障注入**：短路、断路、信号漂移、总线断连、电压跌落，验证容错与降级。
- **场景测试（ADAS）**：参数化组合天气、光照、交通参与者、路面，评估系统表现。
- **用例设计**：等价类、边界值、状态迁移、判定表 + 需求追溯矩阵（RTM）。

## 9. 典型风险点（探索性用例灵感）

1. **上下电竞态**：快速连续上下电、上电瞬间触发功能
2. **总线降级**：某网段断线后跨域功能行为
3. **信号异常值**：信号发送全 F / 初始未定义值
4. **OTA 中断**：升级中断后重启恢复与版本回滚
5. **时钟/时间戳**：时间跳变、时区切换对日志/诊断的影响
6. **多屏联动**：分辨率/刷新率切换、热插拔
7. **电压边界**：9V/16V 边界、电压跌落瞬间功能状态
8. **休眠唤醒**：异常唤醒源、唤醒风暴、休眠失败功耗异常
9. **重复触发**：按钮连点、指令风暴、重复订阅服务
10. **数据一致性**：仪表显示值 vs 总线实际信号值核对

## 12. UDS 诊断服务速查（ISO 14229）

| 服务 | 功能 | 请求示例 | 常见 NRC |
|---|---|---|---|
| 10 | 诊断会话控制 | 10 01（默认）/10 03（扩展） | 22 条件不满足 |
| 11 | ECU 复位 | 11 01（硬复位）/11 03（软复位） | 22 |
| 19 | 读取 DTC 信息 | 19 02（按状态掩码） | 31 请求超出范围 |
| 14 | 清除 DTC | 14 FF FF FF | 22 / 72 一般编程失败 |
| 22 | 按 DID 读数据 | 22 F1 90 | 31 |

| 27 | 安全访问 | 27 01 / 27 02（seed/key） | 35 无效密钥 / 37 超时 |

**测试关注点**：会话超时回默认、安全访问失败锁定策略、DTC 状态位（确认/待确认/历史）流转、刷写中断恢复、NRC 正确性。

## 13. CAN 报文故障注入场景

| 注入场景 | 验证预期 |
|---|---|
| 报文周期超时（>3 倍周期） | 信号进入替代值，功能降级或报警 |
| 注入 CRC/位错误帧 | ECU 忽略该帧，不影响后续通信 |
| 总线断连 | 相关功能进入安全状态，恢复后自愈 |
| 总线短路（隐性/显性） | Bus-off 后重启逻辑正确 |
| 信号值越界（物理值域外） | 按替代值处理，不产生误动作 |
| 负载率过高（>70%） | 高优先级报文优先，低优先级降速 |
| 重复报文 ID | 按接收方策略处理，不崩溃 |

## 14. 功能安全测试（ISO 26262）要点

- 按 ASIL A-D 等级确定安全机制与测试深度（ASIL D 需故障注入全覆盖 + 定量指标）
- 常见安全机制：信号合理性检查、看门狗、ECC/CRC、双通道冗余、失效安全值
- 故障注入点：传感器信号（超限/冻结）、总线（断连/乱序）、电源（跌落/瞬断）、内存（位翻转）
- 验证目标：故障检测时间、进入安全状态时间、降级行为、恢复行为
