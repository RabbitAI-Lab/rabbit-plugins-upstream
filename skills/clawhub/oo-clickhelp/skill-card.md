## Description:

Use ClickHelp to read, create, and update data through the connected account.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and support teams use this skill to search and read ClickHelp projects, publications, and topics, and to create or update topics through their connected account.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The first-time setup fallback runs downloaded software without verification or a clear approval step.

Mitigation: Install a reviewed, verified CLI yourself and require approval before downloaded setup code runs. Review automatic agent-skill installation and grant only the ClickHelp permissions needed.
