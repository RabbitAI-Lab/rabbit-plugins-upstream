# 单伟建投资哲学

本 skill 基于单伟建三本著作的原文（约75万字）深度蒸馏。源材料是用户提供的正版电子书，经逐章逐节阅读提炼，不是书评或二手转述。

## 三本原著

1. **《金钱博弈》（Money Games）** — 1997-1998亚洲金融危机中收购韩国第一银行。18章+序曲+尾声+附录。核心投资实战教材。
2. **《金钱风云》（Money Man）** — 2002-2004收购深圳发展银行。24章+后记。中国国情下的交易结构案例。
3. **《走出戈壁》（Out of the Gobi）** — 从文革失学到沃顿教授再到投资家。29章。人格根基与人生哲学。

## 如何使用

0. **理解思想体系**（先读这一步，再做具体查询）：
   - 跨书印证体系 → `references/synthesis/cross-book-map.md`（10个主题，每个主题含三书印证+公开言论印证+观点索引）

1. **按问题类型路由**：
   - 银行收购/不良资产/危机投资 → `references/chapters/money-games.md`
   - 中国交易/政治判断/诉讼策略 → `references/chapters/money-man.md`
   - 逆境/学习能力/长期主义 → `references/chapters/out-of-the-gobi.md`
   - 跨书综合框架 → `references/investing-principles.md`
   - 理解逻辑关系/「为什么」类问题 → `references/synthesis/cross-book-map.md`

2. **按维度路由**（用户问题落在哪个人生领域）：
   - 人生抉择/教育/职业转型/风险判断 → `references/dimensions/life-decisions.md`
   - 企业管理/项目管理/法务/风控 → `references/dimensions/management-legal.md`
   - 识人/信任/招聘/用人 → `references/dimensions/people-judgment.md`
   - 银行业认知/银行估值/不良资产 → `references/dimensions/banking.md`
   - 公开采访/最近言论/万达恒大/人民币观点/中美关系 → `references/dimensions/public-statements.md`

3. 应用时引用具体原则和出处（书名+章节），不要模糊诉诸权威。
4. 绝不编造原文不存在的观点。超出原著范围时明确说明。

## 核心认知：三大支柱

1. **交易工程**：结构设计（危机买入、好银行坏银行分离、买或卖安排）
2. **政治判断**：读懂对方内部（国有体制决策链条、官僚动机、面子与里子）
3. **人格韧性**：长期不确定中的耐心与学习（源自戈壁滩经历）
4. **宏观视野**：汇率、消费、国际关系判断（源自FT文章、HBR访谈及公开演讲）

四大维度是三大支柱在人生活场景中的展开：人生抉择（韧性如何用）、管理法务（工程如何落地）、识人（政治如何读）、银行业认知（行业底层模型）。
