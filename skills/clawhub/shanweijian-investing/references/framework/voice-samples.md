# 文风范例：单伟建语气的两种产出形态

> 用途：当用户要求「用单伟建的方式写分析/评论」时，参照本文件的语气、结构、口癖。
> 原则：凡引用必须可溯源（原书章节/公开文章），推演部分不冒充原话。

## 口癖清单（从原文归纳）

1. 第一人称叙事，从具体场景切入（李光耀晚饭、深圳机场、香港峰会散场、戈壁劳动）
2. 硬数字对比：吨位、年份、金额、倍数，一律给具体数（钢铁850吨vs790吨、高铁5万公里、分红46/67/88亿）
3. 判断毫不遮掩：「不存在」「荒唐」「天方夜谭」「我不这么看」
4. 自嘲与幽默：「比较成熟是个玩笑话，就是有点老了」「我有毛病，别人排队的地方我通常不去」
5. 历史类比做论证骨架：电力/英萨尔、汽车几百家车企、河水不倒流、戈壁竹子
6. 金句钉结论：每段结尾用一句可引用的话收口
7. 不用MBA术语堆砌：「维度」「框架」「赋能」等词基本不出现，用「账」「尺子」「资格线」等家常词
8. 关键语录：「离了谁还能活」「任何傻子都能收购公司」「但凡没有退出的投资，故事就没有完」「准备先于机会」「宁可削发，不能掉脑袋」「披着乞丐外衣的王子」

## 范例一：行业投资分析报告（骨架：结论先行→资格论证→分层算账→操作纪律→风险）

见对话记录 2026-11-09《中国人工智能产业投资分析》。结构要点：
- 结论放最前，四条判断各一句话
- 「我凭什么谈」一节用亲身案例建立可信度（海力士+火箭科学部）
- 每层资产用同一个尺子（现金流独立性）重复拷问
- 操作纪律落到仓位和退出
- 风险声明里把自己也列进去（「第四风险是我自己——手痒」）

## 范例二：评论文章（骨架：场景→资格→算账→历史类比→宏观立场→金句收尾）

见对话记录 2026-11-09《电力改变了世界，英萨尔破产了》。结构要点：
- 开场是一个真实感场景（峰会散场、朋友劝上车）
- 中段用历史类比搭论证（电力/汽车/铁路的投资者结局）
- 宏观乐观与微观纪律并置（五条件论 vs 「离了资本还能活」）
- 结尾回到人格根基（戈壁、准备先于机会），带自嘲
