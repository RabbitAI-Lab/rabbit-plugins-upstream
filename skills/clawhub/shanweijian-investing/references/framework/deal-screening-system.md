# 单伟建式投资筛选与决策管理体系

> 本文件从三本原著 + 公开言论中提炼出一套可操作的「筛选→评估→结构→投后→退出」体系。
> 每条规则都标注出处（观点编号/章节/公开言论），保证有据可查。
> 用途：对任何潜在收购标的做系统化打分和否决判断。

## 一、体系总览：五环筛选器 + 三道门

```
初筛（五环打分卡）→ 深筛（否决项清单）→ 尽调（三条验证线）
→ 结构设计（激励对齐四层次）→ 投后（换人→制度→激励）→ 退出（三条预埋路径）
```

单伟建的原话锚点：
- 「但凡没有退出的投资，故事就没有完，就胜负未卜。」（金钱博弈）
- 「任何傻子都能收购公司，而在收购后发生了什么才是最重要的。」（金钱博弈·庞德曼）
- 「我们不是垃圾收集者，我们是资产的修复者。」（金钱博弈，界面新闻引用）
- 「买下深陷危机的企业……前提是，你必须有能力把有毒的资产和干净的现金流做外科手术式的切割。」（金钱博弈）

## 二、五环筛选器（每环0-10分，加权总分）

### 环1：现金流独立性（权重30%）——「离了谁还能活」

判断母体信用塌了之后，资产自身的造血是否完好。

检验项：
- [ ] 过去3年经营性现金流是否为正且稳定？（要看到具体数字）
- [ ] 收入是否依赖母公司输血/关联交易？
- [ ] 客户/用户是否因为母体负面标签而流失？（分「已经流失」vs「可能流失」）
- [ ] 该资产在母体消失后，社会/市场是否仍然需要它？

出处锚点：太盟四铁律之一「离了谁还能活」；珠海万达商管2021-2023分红46/67/88亿（累计超200亿）证明资产没病、病在母体（public-statements.md 第九节）。
原著印证：韩一银行的存贷款客户在危机中并未消失（money-games 观点16/19）。

### 环2：安全边际（权重25%）——「两三折的清算价」

检验项：
- [ ] 当前定价相对峰值/重置成本/可比公司，折让多少？
- [ ] 折价的来源是什么？（母体信用创伤 vs 资产本身问题——前者可修复，后者不可修复）
- [ ] 卖方是否处于被迫出售状态（清盘/到期对赌/监管压力）？被迫出售才有极端价格。
- [ ] 我出价后，还有多少人能出比我更高的价？

出处锚点：「当别人因恐惧而退缩时，市场才会给出两三折的清算价」；恒大物业40.26亿港元 vs 2021年400亿估值（-80%）、8.2倍PE vs 同业11-15倍（wx-13）。

### 环3：可切割性（权重20%）——「外科手术式切割」

检验项：
- [ ] 目标资产的法人与母体债务是否已经法律隔离？（上市地位/BVI SPV/独立法人）
- [ ] 有毒部分（应收账款、担保、历史负债）能否明确划归卖方？
- [ ] 品牌、牌照、员工合同是否可整体承接？
- [ ] 「过去的风险归卖方，未来的风险归买方」这条线画得清吗？（money-games 观点19）

出处锚点：好银行/坏银行结构（观点16）；恒大交易中CEG Holdings BVI层面的负债切割（wx-13）；韩一银行NPL剥离（money-games 第16-17章）。

### 环4：治理可修复性（权重15%）——「问题在股东，不在资产」

检验项：
- [ ] 资产的核心问题是「股东层面的信用/资金问题」还是「业务本身坏死」？前者可修复。
- [ ] 我能否获得足够控制权（或等效控制：董事会多数+财务控制）来实施改造？
- [ ] 需要换的人能不能换？需要立的制度能不能立？
- [ ] 原管理层是资产还是负债？（王健林40%保留=资产；周林失控=负债，见 money-man）

出处锚点：投后公式「换人→制度→激励对齐」（cross-book-map.md 主题四）；「控制权不足时条款是替代品，控制权本身就是最强保护」（四铁律之二）。

### 环5：退出预埋（权重10%）——「买之前先想怎么卖」

检验项：
- [ ] 至少有一条不依赖运气的退出路径：分红现金流退出 / 行业整合者接盘 / 公开市场估值修复 / IPO
- [ ] 「买或卖」类双向期权是否可能设计？（政府或对手方有回购义务时）
- [ ] 维持上市地位是否本身就是退出安排？（恒大物业案例：不私有化=成本最低退出）
- [ ] 持有期需要多长？我的资金结构（基金期限）能否匹配？

出处锚点：「但凡没有退出的投资，故事就没有完」（money-games）；深发展→平安分步退出（money-man 观点559/623/653）。

## 三、一票否决清单（深筛阶段，任一命中即放弃）

1. **修不了**：资产本身坏死（技术淘汰/牌照吊销/核心团队解散），只是价格便宜——对应「先判断能不能修，再判断值不值得修」（investing-principles.md 原则9）。
2. **切不开**：有毒资产与干净现金流无法法律切割，母体债权人可追索到标的。
3. **拿不到控制**：无法获得改造所需的控制权或等效影响力，对方不按商业逻辑出牌（钱不是唯一变量，政权/司法结构才是——money-games 韩国教训）。
4. **算不清账**：核心财务数据无法验证（假账/关联交易吞噬现金流）。
5. **监管死亡**：交易命门握在单一审批环节，且该环节有明确的政治反对理由。
6. **资金错配**：持有期超过资金结构允许（短期钱做长期事）。

## 四、尽调三条验证线

1. **数据线**：现金流表逐月核对（不是年报，是月报）；前20大客户访谈。
2. **人心线**：管理层/员工/客户/监管四方访谈——「了解对方内部政治比了解立场更重要」（investing-principles.md 原则4）。
3. **压力线**：设定三种结局推演——最好/基准/最坏，每种结局下我的回报各是多少？最坏结局是否可承受？（money-games 的买或卖安排本质就是把「最坏结局」变成对方的选择题）

## 五、结构设计四层次（按进化顺序）

1. **风险切割**：过去风险归卖方，未来风险归买方（韩一：好银行/坏银行）。
2. **激励对齐**：不靠信任靠机制（买或卖安排——定价方必须公允，否则自伤）。
3. **控制权优先**：股权>对赌条款，董事会席位>承诺函（万达：不设对赌因为拿到60%）。
4. **退出预埋**：交易文件里预先写好退出机制（分步交易/维持上市/双向期权）。

## 六、投后管理公式

```
价值创造 = 换人（该换的换）× 制度（风控/审批/激励）× 激励对齐（管理层持股/与回报挂钩）
```

- 银行案例：重建信贷审批独立性、止蚀机制、薪酬与资产质量挂钩（money-games 第14-15章，观点181-195）。
- 物业/商管案例：维持经营团队稳定+治理重建+品牌切割（恒大物业下一步的关键）。
- 反面教材：深发展时期「换不动的人」造成的治理内耗（money-man 相关章节）。

## 七、打分卡模板（对任意标的复制使用）

| 环节 | 权重 | 得分(0-10) | 加权 | 关键证据 |
|------|------|-----------|------|----------|
| 现金流独立性 | 30% | | | |
| 安全边际 | 25% | | | |
| 可切割性 | 20% | | | |
| 治理可修复性 | 15% | | | |
| 退出预埋 | 10% | | | |
| **总分** | 100% | | | |

判定线：
- **≥8.0**：符合单伟建式标的，进入尽调
- **6.5-8.0**：有瑕疵，逐项列出补强方案后再定
- **<6.5**：放弃（或等待价格/结构改善）

## 八、案例示范：万达 vs 恒大物业（用本体系打分）

### 万达（2024，600亿/60%新达盟）

| 环节 | 得分 | 依据 |
|------|------|------|
| 现金流独立性 | 9 | 3年累计分红超200亿；商管费独立收缴 |
| 安全边际 | 8 | 较2021年IPO方案估值大幅缩水；解除对赌压力 |
| 可切割性 | 9 | 新达盟新平台、股权干净、与万达集团债务隔离 |
| 治理可修复性 | 8 | 60%控制权+董事会席位；保留王健林40%运营价值 |
| 退出预埋 | 8 | 分红退出已验证；不赌IPO |
| **加权总分** | **8.5** | 教科书级「母体塌了资产没塌」案例 |

### 恒大物业（2026，40.26亿港元/51.016%）

| 环节 | 得分 | 依据 |
|------|------|------|
| 现金流独立性 | 8 | 物业费基本盘独立；但恒大关联应收已减值（毒已切） |
| 安全边际 | 9 | vs 2021年估值-80%；8.2倍PE vs 同业11-15倍 |
| 可切割性 | 7 | BVI SPV切负债，但清盘人程序+要约义务增加复杂性 |
| 治理可修复性 | 6 | 恒大负面标签需2-3年修复（中金判断）；控制权够但品牌修复难 |
| 退出预埋 | 8 | 维持上市=成本最低退出；35-45%估值修复空间 |
| **加权总分** | **7.6** | 边际更大但风险更高，符合「高难度高回报」困境投资特征 |

两案对比结论（体系语言）：万达是「资产干净、价格合理」的标准题；恒大物业是「资产更便宜、但修复工程更难」的高难题——两者都是同一逻辑链（韩一→深发展→万达→恒大）上的应用，难度递增、单伟建的工具箱不变。

## 九、当前市场应用指南（2026-11视角）

### 筛选方向（按五环反推）

方向1：**困境母体下的物管/商管/轻资产运营平台**
- 逻辑：房地产开发见顶，但「轻资产管理时代才刚刚拉开序幕」（单伟建专栏）；母体去杠杆制造折价，资产现金流独立。
- 候选类型：出险房企旗下仍独立运营的物管公司、商业运营公司；母体清盘/重整中的上市子公司。
- 注意：查清应收账款减值是否充分、与母体的品牌/诉讼切割是否完成。

方向2：**母体暴雷的产业资产（上市地位独立）**
- 逻辑：环1环2高分，环3环4决定成败。
- 候选类型：系族企业（母体债务危机）旗下经营正常的上市/准上市实体。
- 关键尽调：法人独立性与担保链切割。

方向3：**深度折价的金融/公用资产**
- 逻辑：市值显著低于净资产或分红能力被短期信用事件压制。
- 候选类型：区域性银行、公用事业、高股息运营商中「治理可修复」的标的。
- 关键：单伟建只投他能改造的对象——银行业他的工具箱最厚（两本书记录的都是银行改造）。

方向4：**政策转向受益+错杀的消费/内需资产**
- 逻辑：他的宏观立场（更大力度刺激内需、人民币渐进升值、提高居民收入）指向内需链修复。
- 候选类型：被地产/宏观悲观情绪连累的品牌消费、服务、医疗。

### 明确不做（否决项应用）

- 纯价格便宜但资产坏死的（如淘汰产能）
- 无法切割的母体连带（担保链复杂且无隔离结构）
- 需要预测「底部时间」的（他从不预测底部，只要求「离了谁还能活」+安全边际）
