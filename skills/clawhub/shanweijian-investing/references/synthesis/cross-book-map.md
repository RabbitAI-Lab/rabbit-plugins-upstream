# 主题一：危机买入的完整逻辑链

## 【主题阐述】

单伟建四次重大困境投资（1998韩一银行 → 2002深发展 → 2024万达 → 2026恒大物业）呈现同一条逻辑链：

1. **不预测底部，只判断「离了谁还能活」**——母体信用塌了，但资产自身的现金流没塌，这就是下注的唯一理由。
2. **危机带来安全边际**——别人因恐惧退缩时，市场才会给出两三折的清算价。
3. **有能力做外科手术式的切割**——把有毒资产和干净现金流切开，否则危机买入就是接飞刀。
4. **成交只是起点**——买入后的改造才是价值创造的开始。

# 主题二：交易结构设计哲学

## 【主题阐述】

单伟建的交易结构设计有四个递进层次，每次交易都比上一次更精妙：

1. **好银行/坏银行分离**（韩一银行）——把历史不良风险从买方身上切走
2. **买或卖安排**（韩一银行）——用激励对齐代替信任，让政府5年后被迫选择买或卖
3. **分步交易 + 增发架构**（深发展→平安）——先控盘改造，再分步退出
4. **不设对赌 + 维持上市 + BVI SPV**（万达/恒大物业）——条款是控制权不足时的替代品，控制权本身就是最强保护

## 【三书印证】

### 《金钱博弈》：好银行/坏银行 + 买或卖

- **章节指向**：第2章「火中取栗」（结构雏形）、第16章「狮子开口」（政府要价）、第17章「鹬蚌相争」（买或卖条款）
- **核心金句**：「好银行/坏银行模式——将失败银行一分为二，不良资产放进政府全资拥有的坏银行，好资产保留在好银行。」（观点16原文）
- **核心金句2**：「交易结构设计的核心是风险切割——过去的风险归卖方，未来的风险归买方。」（观点19原文）
- **核心金句3**：「交易结构设计的最高境界不是让一方赢，而是让双方的激励对齐。「买或卖」安排让定价方必须公允，否则自己的利益也会受损。」（观点60原文）
- **观点索引**：观点16/19/21（好银行坏银行）、观点60/64/69/75/241/242（买或卖）、观点148（激励对齐即风控）
- **quotes 路径**：quotes/money-games-quotes.md 推荐序/第2章/第16章/第17章

### 《金钱风云》：分步交易 + 增发架构

- **章节指向**：第12章「水到渠成」（签约）、第23章「时不我待」（平安分步交易）
- **核心金句**：「中国政府并不缺钱，缺的是国外先进的银行管理方式，所以欢迎外资。」——理解对方的真实需求才能设计对的结构。
- **核心金句2**：「政府决心退出企业，只当裁判，不当球员。」
- **核心金句3**：「我料想这笔交易会让深发展的股民满意，因为不管是增发或要约收购，每股定价都是39.9元。」
- **观点索引**：观点133（收购协议核心）、观点559（定向增发方案：深发展向平安定向增发新股）、观点623（39.9元报价）、观点653（要约定价）
- **quotes 路径**：quotes/money-man-quotes.md 第一章第5句、第二十三章

- 收购价分两档：恒大持股部分0.8359港元/股，CEG Holdings部分0.7271港元/股 + 承担5亿元人民币税费负债

- CEG Holdings是恒大为持有恒大物业股权设立的BVI离岸SPV——在离岸层面切割资产与债务，是国际投行标准操作

- 出处：public-statements.md 第八节 + wx-13（界面新闻）

结构设计的最高境界不是让一方赢，而是让双方的激励对齐——「买或卖」安排如此，不设对赌如此，BVI SPV也是如此。

# 主题三：谈判方法论——千刀万剐式让步与政府博弈

## 【主题阐述】

单伟建的谈判方法论在韩国和中国的应用呈现清晰的异同：

**相同点**：
- 都强调让步必须有底线，每一次让步都要计算累积影响
- 都需要读懂对方内部政治，找到真正的决策者
- 都遵循「不把对手逼到墙角」的原则

**不同点**：
- 韩国谈判：决策者集中在金监会（李宪宰），谈判对手是技术官僚
- 中国谈判：决策链条更长（市政府→省政府→国务院→监管），面子政治更重要
- 中国谈判需要「隐性监管支持」但不能让管理层知晓，否则失去紧迫感

## 【三书印证】

### 《金钱博弈》：韩国政府谈判

- **章节指向**：第8章「主帅上阵」、第11章「最后通牒」、第12章「峰回路转」
- **核心金句**：「英文中也有千刀万剐一说，叫death by a thousand cuts，可见此刑并非中国人的专利。」
- **核心金句2**：「我和李宪宰谈成的任何事情，都可能被尹律师、金监会的团队或李宪宰本人推翻。」——谈判成果的脆弱性
- **核心金句3**：「虽然南理宇不给力，甚至起了反作用，但真正决策者是李宪宰。」——识别真正决策者

### 《金钱风云》：深圳政府谈判

- **章节指向**：第7章「唇枪舌剑」、第9章「风云诡谲」、第10章「功败垂成」

- **核心金句**：「在成长的过程中，我渐渐意识到对权威不能盲从，要问个是非。如果权威是错误或愚蠢的话，就不应……」——谈判中不盲从对方权威的前提。

## 【公开言论印证】

- 「搞投行只有20%是搞金融，80%是搞关系。」（《财经》专访）

# 主题四：投后管理——银行改造 vs 物业/商管管理

## 【主题阐述】

从韩一银行到恒大物业，投后管理的核心没变，但具体操作随行业而变：

**不变的三件事**：
1. 买的是信贷文化/运营文化，不是资产负债表
2. 换人是第一刀——不能沿用导致危机的旧团队
3. 治理重构——董事会控权、制度重建、激励对齐

**变的部分**：
- 银行改造：风控独立性、止蚀机制、信贷决策权与业务拓展权分离
- 物业/商管：品牌去化、中后台切割、数字化、增值服务变现

## 【三书印证】

### 《金钱博弈》：银行改造

- **章节指向**：第13章「一鼓作气」到第15章「破旧立新」、第16章「狮子开口」
- **核心金句**：「被渣打尽职调查后评价为「风险管理体系比渣打自己的还要好」。」——投后改造的标杆验证

- **观点索引**：观点24（买银行=买信贷文化）、观点126/128/130（风控独立性）、观点136（投后核心）、观点360（渣打评价）、观点138（海力士止蚀）、观点313/316（首席信贷官教训）

## 【公开言论印证】

### 万达商管的治理重构

- 「万达商管的经验中，可以平移的包括治理重构、董事会控权、人效考核、租金/费率坪效逻辑。」（柏文喜，中国企业资本联盟副理事长）
