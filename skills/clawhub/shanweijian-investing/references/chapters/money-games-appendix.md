# Money Games appendix — commercial banking primer

From the original appendix (附录 商业银行入门).

## Core concepts

- **商业银行**：吸收存款、发放贷款。与投行的区别：投行在客户和资本市场之间充当中介，收取费用。
- **存款与贷款的利差**：银行赚钱的核心是存款利率和贷款利率之间的差额。利差补偿银行承担贷款风险。
- **资本充足率（BIS ratio）**：银行资本金占风险加权总资产的比例。国际标准由巴塞尔的国际清算银行制定。
- **不良贷款（坏账）**：借款人无法还本付息的贷款。次级以下（次级、可疑、损失）统称不良贷款。
- **准备金**：银行为抵销贷款损失预留的资金。贷款风险越高，准备金越多。
- **贷款分类**：正常、关注、次级、可疑、损失。传统分类看是否还本付息；前瞻性分类判断未来还款能力。
- **风险定价**：根据客户风险等级收取不同利率。最优惠利率（prime rate）之上的部分是风险溢价。
- **成本收入比**：运营成本与营业收入之比。必须小于1银行才能赢利。
- **资产回报率（ROA）与股本回报率（ROE）**：净利润除以总资产或股本金。
- **单一客户集中度**：贷款不应过度集中于单一借款人。韩国危机前银行对单个企业的贷款可达资本金的50%，远超国际惯例10%。

## Key lessons

- 银行是高杠杆业务：存款是负债，贷款是资产。放出去的钱收不回来就赔钱。
- 信贷文化是银行成败的根本。韩国危机的核心原因是银行没有信贷文化——贷款靠关系而非还款能力。
- 政府干预银行是双刃剑：政策支持贷款帮助了产业崛起，但也埋下了系统性风险的种子。
- 准备金不足会让资本金迅速消失。前瞻性分类法能提前识别风险，但旧的会计准则掩盖了真实状况。
- 高杠杆 + 政府隐性担保 + 关系型信贷 = 系统性崩溃的配方。
- 银行的核心竞争力是风险控制和客户关系，不是资产规模。
