## Description:

Uttera helps agents transcribe, summarize, translate, analyze, and generate audio, including speech, music, and sound effects.

This skill is ready for commercial/non-commercial use.

## Publisher:

[uttera](https://clawhub.ai/user/uttera)

### License/Terms of Use:

MIT-0

## Use Case:

Users and developers can process recordings into transcripts, summaries, translations, speaker timelines, pronunciation assessments, and signed reports, or create spoken audio and soundscapes from text and voice samples.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Selected audio or text and the Uttera API key are sent to Uttera for processing.

Mitigation: Submit only approved inputs and keep the API key private.

Risk: Actions can spend credits from the user's Uttera account.

Mitigation: Confirm the requested action and expected cost before expensive generation.

Risk: Voice cloning could be used without the speaker's consent.

Mitigation: Clone only the user's own voice or a speaker's voice with explicit consent.
