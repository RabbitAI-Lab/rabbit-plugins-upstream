## Description: <br>
Helps agent users and skill maintainers create SkillScan-style workflows, checklists, analysis, and implementation support for bug fixing, setup hardening, security review, and reliability improvements. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>

## Use Case: <br>
AI-agent users, skill authors, maintainers, and teams use this skill to turn security-focused productivity needs into practical plans, checklists, decision aids, code changes, and verification notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad implicit activation settings could make this workflow helper appear in unrelated security, workflow, or bug-fix conversations. <br>
Mitigation: Narrow activation terms or disable implicit invocation when precise skill routing is required, and review whether the skill is applicable before using its output. <br>
