# Default image slots

The generator loads these raster images automatically. User --images entries override only the named slots; relative paths resolve beside that JSON file. Full generation provenance and checksums are in default-images/manifest.json.

| Image key | Bundled asset | File |
|---|---|---|
| `page-image` | `workspace-brief` | `default-images/workspace-brief.webp` |
| `chat-avatar` | `avatar-editor` | `default-images/avatar-editor.webp` |
