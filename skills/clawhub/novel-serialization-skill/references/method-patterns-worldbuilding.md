# World-Building Templates

This module provides structured templates for building consistent, immersive fictional worlds. Each template is designed to be filled out incrementally and referenced by other modules (character design, chapter writing, continuity tracking).

---

## 1. Magic System Template

Use this template to define the rules, limitations, and costs of magic in your world.

```
# Magic System: [Name]

## Overview
- **Type**: [e.g., hard/soft/systematic/ambient]
- **Source**: [Where magic comes from]
- **Practitioners**: [Who can use it]

## Rules
1. [Rule 1]
2. [Rule 2]
3. [Rule 3]

## Limitations
- [Limitation 1]
- [Limitation 2]

## Costs
- [Cost 1]
- [Cost 2]

## Schools/Traditions
| Name | Focus | Notable Practitioners |
|------|-------|----------------------|
|      |       |                      |

## History
- [Key historical events related to magic]

## Impact on Society
- [How magic shapes culture, economy, politics]
```
