# Chapter Writing Templates

This module provides structured templates and patterns for writing consistent, engaging chapters. All templates should reference the world-building and character templates defined in their respective modules.

---

```

**Timeline**: [When this chapter takes place]
**Location**: [Where this chapter takes place]

```

## 3. POV Rules

### Point-of-View Guidelines

1. **Single POV per Scene**: Each scene should be told from one character's perspective only.
2. **Deep POV**: Write in close third or first person. Avoid head-hopping within scenes.
3. **POV Character Filter**: Describe the world through the POV character's senses, knowledge, and biases.
4. **Scene Breaks**: Use clear scene breaks (*** or chapter breaks) when switching POV characters.

### POV Character Rotation
| Chapter | POV Character | Reason |
|---------|--------------|--------|
| 1       |              |        |
| 2       |              |        |
| 3       |              |        |

### POV Consistency Checklist
- [ ] Only one POV character per scene
- [ ] Scene breaks clearly mark POV changes
- [ ] Information revealed matches POV character's knowledge
- [ ] Voice is consistent with character's voice profile

## 4. Pacing Formula

### Scene-to-Sequel Ratio
- **Action Scenes (Scene)**: Goal → Conflict → Disaster → New Goal
- **Reaction Scenes (Sequel)**: Reaction → Dilemma → Decision

### Pacing Guidelines
| Element | Recommended Frequency | Notes |
|---------|----------------------|-------|
| Action Scene | Every 2-3 chapters | Drives plot forward |
| Reaction Scene | After major action | Processes emotional impact |
| Exposition | Sparse, integrated | Weave into action/dialogue |
| Dialogue | 30-50% of word count | Varies by genre |
| Description | 10-20% of word count | Sensory details only |

### Tension Curve Template
```
Chapter 1:  [Setup - Low tension]
Chapter 2:  [Rising action - Medium tension]
Chapter 3:  [Complication - High tension]
Chapter 4:  [Crisis - Peak tension]
Chapter 5:  [Resolution - Release]
```

## 5. Dialogue Formatting Template

### Dialogue Rules
1. **New Speaker = New Paragraph**: Each speaker gets their own paragraph.
2. **Dialogue Tags**: Use simple tags (said, asked) unless voice differentiation requires emphasis.
3. **Action Beats**: Use action beats instead of tags when possible.
4. **Voice Differentiation**: Each character should have distinct speech patterns (see character voice profiles).

### Dialogue Example Template
```
"Dialogue text," [character] said/asked.

[Action beat instead of tag.]

"More dialogue," [character] replied, [action].
```

### Dialogue Quality Checklist
- [ ] Each character's voice is distinguishable
- [ ] Dialogue reveals character or advances plot
- [ ] Dialogue tags are minimal and clear
- [ ] Subtext exists beneath surface conversation
- [ ] Dialogue matches character's voice profile

## 7. Style Consistency Rules

Maintaining consistent style across chapters is essential for reader immersion and professional quality. Apply these rules to every chapter draft.

### 7.1 Voice Register

- **Consistency**: Each POV character maintains a consistent voice register throughout the narrative. A scholarly character uses different vocabulary and sentence structure than a street-smart character.
- **Register Levels**:
  - **Formal**: Used by authority figures, in official settings, or by characters with educated backgrounds
  - **Standard**: The default narrative voice; accessible but not colloquial
  - **Informal**: Used by casual characters, in relaxed settings, or for internal monologue
  - **Colloquial**: Regional dialects, slang, or character-specific speech patterns (use sparingly)
- **Rule**: Never shift a character's register mid-scene without narrative justification (e.g., a formal character deliberately using slang to fit in).

### 7.2 Tense Conventions

- **Primary Tense**: Choose one primary narrative tense (past or present) at the project level and maintain it consistently.
  - **Past Tense** (recommended for serialization): "She walked into the room..." — Natural for storytelling, easier for readers
  - **Present Tense**: "She walks into the room..." — Creates immediacy, but can feel strained over long narratives
- **Internal Monologue**: Match the tense of the internal monologue to the narrative tense.
  - Past narrative: "She remembered how he had said..."
  - Present narrative: "She remembers how he says..."
- **Flashbacks**: Use clear temporal markers when shifting to flashbacks. In past-tense narratives, flashbacks typically use past perfect ("She had seen this before").
- **Rule**: Never mix past and present tense within the same scene without explicit temporal framing.

### 7.3 Terminology Lock

- **Term Registry**: Maintain a glossary of all invented terms, place names, character names, and specialized vocabulary. Refer to `method-patterns-character.md` for character name conventions and `method-patterns-worldbuilding.md` for world-building terminology.
- **Spelling Consistency**: Once a term is established, its spelling must not change. Common pitfalls:
  - Character names: "Eldrin" vs. "Eldrinne" (always use the established spelling)
  - Place names: "The Silver Tower" vs. "silver tower" (capitalization consistency)
  - Magic terms: "Weave" vs. "the weave" (establish article usage early)
- **Introduction Rule**: When introducing a new term for the first time, provide context or a brief descriptor. Thereafter, use the term without explanation.
- **Cross-Reference**: Maintain the project glossary at `references/glossary.md` (when generated) and update it whenever new terms are introduced.

### 7.4 Forbidden Patterns

Avoid these common writing pitfalls that break immersion or consistency:

- **Info-Dumping**: Never deliver a paragraph of pure exposition. Weave world-building details into action, dialogue, or character thought.
- **Head-Hopping**: In single-POV scenes, never access another character's thoughts or feelings. Describe only what the POV character can perceive.
- **Tense Slippage**: Watch for accidental tense shifts, especially when writing dialogue tags or action beats.
- **Filter Words**: Minimize words that create distance between reader and experience: "she saw," "he felt," "she noticed," "she heard." Prefer direct description.
  - Weak: "She saw the dragon fly overhead."
  - Strong: "The dragon flew overhead."
- **Adverb Overuse**: Limit adverbs, especially in dialogue tags. "She said angrily" is weaker than showing anger through action or dialogue content.
- **Duplicate Descriptions**: Avoid repeating the same physical description or setting detail across chapters. Reference previous descriptions rather than restating them.
- **POV Violation**: Never reveal information the POV character could not know in the current scene (unless using omniscient narration consistently).

### 7.5 Style Checklist

Before finalizing any chapter, run through this quick style check:

- [ ] Narrative tense is consistent throughout (no past/present mixing)
- [ ] POV character's voice/register is consistent with their profile
- [ ] All invented terms match the established glossary spelling
- [ ] No info-dumps or exposition paragraphs longer than 3 sentences
- [ ] No head-hopping within single-POV scenes
- [ ] Filter words minimized (saw, felt, noticed, heard, etc.)
- [ ] Adverb usage in dialogue tags is minimal
- [ ] No duplicate descriptions that repeat earlier chapters verbatim
- [ ] Flashbacks are clearly marked with temporal transitions
- [ ] Character names spelled consistently (check against character sheets)
