# Character Design Templates

This module provides structured templates for designing compelling, consistent characters. Characters should be designed with awareness of the world-building elements defined in [method-patterns-worldbuilding.md](method-patterns-worldbuilding.md).

---

## 1. Character Sheet Template

```
# Character Sheet: [Character Name]

## Identity
- **Full Name**: [Name, aliases, titles]
- **Age**: [Apparent age / actual age]
- **Gender**: [Gender identity]
- **Occupation**: [Profession/role]
- **Alignment**: [Moral/ethical alignment]

## Physical Description
- **Appearance**: [Height, build, distinguishing features]
- **Distinguishing Marks**: [Scars, tattoos, birthmarks]
- **Typical Attire**: [Clothing style]

## Psychology
- **Personality Traits**: [Big Five / MBTI / custom]
- **Motivations**: [What drives them]
- **Fears**: [What they fear]
- **Flaws**: [Character flaws]
- **Quirks**: [Unique habits]

## Backstory
- **Origin**: [Where they came from]
- **Key Life Events**: [Defining moments]
- **Relationships**: [Family, friends, enemies]

## Character Arc
- **Starting State**: [Who they are at beginning]
- **Catalyst**: [What changes them]
- **Transformation**: [How they change]
- **Ending State**: [Who they become]

## Voice Profile
- **Speech Patterns**: [Accent, vocabulary, cadence]
- **Catchphrases**: [Recurring expressions]
- **Communication Style**: [Direct, indirect, formal, casual]

## Relationships Map
| Character | Relationship | History | Current Status |
|-----------|-------------|---------|----------------|
|           |             |         |                |

## Notes for Consistency
- [Notes for maintaining character consistency across chapters]
```

## 2. Relationship Matrix Template

```
# Relationship Matrix: [Novel/Project Name]

## Core Relationships
| Character A | Character B | Relationship Type | History | Current Dynamic | Tension Points |
|-------------|-------------|-------------------|---------|-----------------|----------------|
|             |             |                   |         |                 |                |

## Relationship Arcs
### [Pair 1]
- **Beginning**: [How they start]
- **Development**: [How it changes]
- **Climax**: [Key moment]
- **Resolution**: [Where it ends]
```

---

## 3. Character Arc Template

```
# Character Arc: [Character Name]

## Act 1: Setup
- **Status Quo**: [Normal world]
- **Inciting Incident**: [What disrupts equilibrium]
- **First Choice**: [Character's initial response]

## Act 2: Confrontation
- **Rising Action**: [Challenges that test character]
- **Midpoint**: [Major revelation or reversal]
- **All Is Lost**: [Lowest point]

## Act 3: Resolution
- **Climax**: [Final test/confrontation]
- **New Equilibrium**: [How character has changed]
- **Theme**: [What the arc says about the story's theme]

## Arc Consistency Checklist
- [ ] Character actions align with established psychology
- [ ] Changes feel earned, not abrupt
- [ ] Arc supports thematic elements
- [ ] Relationships evolve naturally with arc
```
