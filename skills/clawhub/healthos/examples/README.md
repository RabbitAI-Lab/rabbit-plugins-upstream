# Example prompts

- "What's my health summary for today?"
- "How did I sleep this week?"
- "Show me my resting heart rate trend over the last 14 days."
- "How many workouts did I do last week and how many calories?"
- "What was my heart rate range yesterday?"

(Glucose and nutrition summaries require the `health:glucose:read` and
`health:nutrition:read` scopes, which are not part of this first release of the
skill.)
