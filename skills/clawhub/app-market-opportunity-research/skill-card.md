## Description:

Research app-market opportunities using Crawlora app catalogs, historical charts, live store listings, release notes, reviews, and Google Trends. Use for app niche assessments, competitor maps, chart-movement analysis, and evidence-backed unmet-need hypotheses.

This skill is ready for commercial/non-commercial use.

## Publisher:

[crawlora-org](https://clawhub.ai/user/crawlora-org)

### License/Terms of Use:

MIT-0

## Use Case:

Product teams, app founders, and market researchers can use the skill to map competitors and assess a defined app niche using store listings, chart history, release activity, reviews, and search-interest signals. It helps form evidence-backed opportunity hypotheses while keeping demand, market size, and revenue estimates distinct from observed signals.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Using the skill requires providing a Crawlora API key to Crawlora's service.

Mitigation: Use a key only if you intend to use the service; keep it in the environment and avoid sharing it in prompts or logs.
