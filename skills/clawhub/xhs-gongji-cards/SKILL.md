# 小红书「公基常识 · 每日5题」图文

把 5 道公基/常识判断题做成 10 张 1080×1440 竖版卡片（题→解析交替）+ 可直接发布的标题/正文/标签。

## 产出物

```
<项目目录>/
├── days/dayNN.json      # 题库，每天一份，永不覆盖
├── dayNN/
│   ├── 01-第1题.png 02-第1题解析.png … 10-第5题解析.png
│   └── 文案.md
└── preview.png          # 当天 10 张的总览，只给用户看，不上传
```

## 工作流

### 1. 定位项目目录

先找已有项目（含 `days/day*.json` 的目录，习惯用 `xhs-gongji/`）。没有就新建，并把本技能 `assets/day_template.json` 复制成 `days/day01.json` 起头（它只是格式样例，题目要重写）。

### 2. 确认今天的 Day N

列出 `days/*.json`，**N = 最大天数 + 1**。不要覆盖已有题库，也不要问用户天数。

### 3. 写 `days/dayNN.json`

先读 `references/playbook.md`：板块权重、轮换建议、标题公式、标签池、审校清单。

```json
{
  "day": 4,
  "cover_hook": true,
  "hook": "今天这5题，第2题体制内才熟",
  "items": [
    {"tag": "法律常识", "q": "题干", "options": ["A项","B项","C项","D项"],
     "answer": 1, "why": ["第一段", "第二段"], "tip": "记一句"}
  ]
}
```

硬规则（脚本按这些尺寸排版）：

- 5 题覆盖 5 个不同板块，并避开 `days/*.json` 里已经出过的考点。
- 题干 ≤16 字最稳；超过必然折行，**折行处不能劈开词**（「普通钢笔」不能断成「普通钢 / 笔」）。
- **不要在 q / options / why / tip 里写换行符**：脚本会自动剥掉并统一按像素宽度折行。发现某张图把词劈开了，**改句子**（加两个字或删两个字把断点挪走），不要靠 `\n` 硬凑。
- 题干**不要以全角引号 `“` / 书名号 `《` 开头**：字形左侧留白会让朱红竖标看起来悬空，加个引导词（「成语“刻舟求剑”…」）即可。
- 选项 ≤14 字；解析每段 ≤60 字、共 2 段；`tip` ≤24 字，能一行放下。
- `answer` 是下标 0–3，A/B/C/D 分别 0/1/2/3。答案必须核对，拿不准就换题；同一期答案字母要打散。
- 首图的 `hook` 每期换一句，别连着用同一句。

### 4. 出图

```powershell
& "<PY>" "<skill>/scripts/make_cards.py" "<项目>/days/dayNN.json"
```

`<PY>` 用带 Pillow 的解释器；`<skill>` 是本技能目录。脚本按 JSON 所在位置推断输出：`days/` 的上一层生成 `dayNN/`，并在同一层写 `preview.png`。

### 5. 自检（必做）

用 read_image 看 `preview.png`，重点查：

- 有没有文字溢出卡片、卡片被撑破；
- 折行有没有劈开词、数字（「800毫米」被拆成「8 / 00毫米」）；
- 解析卡的最后一张是否最满，会不会压到 `preview.png` 底部的进度点。

发现问题改 JSON 重新出图，不要手改 PNG。

### 6. 写 `dayNN/文案.md`

**照抄 `references/playbook.md` 第五节的 Markdown 骨架**，只换内容，不要自创结构：标题 3 选 1（第 1 个固定「公基常识DayN｜…」）+ 正文 ≤6 段（带 1️⃣ 序号）+ 9 个标签 + 答案速查表 + 互动引导。

### 7. 交付

用 present 交付 `文案.md` 和 `preview.png`；回复里给 5 题答案速查表，并用一句「错了几道？评论区报个数」收尾。

## 版式规格

| 项 | 值 |
|---|---|
| 画布 | 1080×1440（3:4） |
| 纸色 / 墨色 | (250,246,239) / (32,36,46) |
| 主题色 | 题目朱红 (198,74,48)、答案墨绿 (14,110,101) |
| 题干 / 选项 / 解析 | 56 / 38 / 33 px，行高 88 / 56 / 58 |
| 字体 | 微软雅黑粗体（题干、答案、记一句）+ 常规（正文） |
| 页眉 | 左上角红色胶囊「公基常识 · 每日5题」，右侧 DAY NN 与页码 |

配色、字号都在脚本顶部，改样式只改脚本，不要逐张手工修图。

## 常见坑

- PIL 没有 emoji 字形，`✓`、`🙋` 会渲染成方框 → 卡片文字只用汉字和中文标点。
- 标点不能出现在行首、数字/单位不能拆开：脚本 `units()` 已处理，改脚本时别删。
- 图片顺序固定「题 → 解析」，发布时按 01–10 顺序上传。
- `preview.png` 只是预览，不要混进待上传的 10 张。
