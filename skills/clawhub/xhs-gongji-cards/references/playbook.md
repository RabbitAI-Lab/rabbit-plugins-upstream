# 出题与发布手册

## 一、板块权重（决定长期选题配比）

公基/常识判断七大板块的题量权重（多套真题统计，参考 [成公教育·常识高频考点](https://www.cgzj.com/gk/12976.html)）：

| 板块 | 每套题量 | 备注 |
|---|---|---|
| 政治理论 | 6–8 | 分值最高，含党史、马哲、毛中特、习思想 |
| 法律 | 4–6 | 民法典、刑法、宪法、行政法 |
| 文史 | 2–3 | 成语典故、文学史、科举、传统节日 |
| 科技 | 2–3 | 生活物理化学、生物医学、航天、材料 |
| 时政 | 2–3 | 时效性强，慎用（易过期） |
| 地理 | 1–2 | 国情、分界线、气候、地名 |
| 经济 | 1–2 | 恩格尔系数、CPI、货币政策、税种 |

单期只出 5 题，最佳配比是 **1 政治 + 1 法律 + 1 文史 + 1 科技 + 1 生活/地理/经济轮换**。
每 5 期至少要有 2 期带政治理论，否则长期跑偏。

## 二、轮换与查重

出题前先读 `days/*.json` 全量，列出已出过的「板块 + 考点」，新题避开：

```powershell
Get-ChildItem days\*.json | ForEach-Object { (Get-Content $_ -Raw | ConvertFrom-Json).items | ForEach-Object { $_.tag + ' | ' + $_.q } }
```

高频考点的常见变体可以复用同一「考点族」，但不能同一句题干。例如「科举」考过「正式确立于哪个朝代」后，下一期可考「殿试始于哪个朝代」「八股文盛行于哪个朝代」。

## 三、题目写作

**题干**：≤16 字一行放得下最稳。超了就必折行，折行处会劈开词，观感很差。

- 好：「防卫过当，依法应当如何处罚？」「秦岭—淮河一线大致相当于？」
- 差：「航天员在空间站里，为什么用普通钢笔、圆珠笔写不出字？」（会断成「普通钢 / 笔」）
- **不要以全角引号或书名号开头**：`“刻舟求剑”错在……` 会因字形左侧留白，让朱红竖标和文字之间空出一截，看起来像竖标悬空。改成 `成语“刻舟求剑”错在……` 加个引导词即可。

**选项**：≤14 字，四个长度接近；干扰项要「像」，不能一眼假。四个选项都只有两三个字时，卡片右侧会空出一大片，给短选项补限定词（「一个月」→「试用期一个月」）。
**答案**：严格核实，拿不准换题；5 题答案字母打散（B/C/A/B/D 这种）。
**解析**：两段，每段 ≤60 字。第一段给依据（法条、原理、原文），第二段给易错点或延伸。每段控制在 **40–48 字（约两行）**最稳：太短卡片会显得空，超过 50 字更容易在词中间折行。**发现图上把词劈开了，就改句子**（加减两个字把断点挪走），不要插换行符。
**记一句**：≤24 字，一句话能背走，最好带对比或口诀，例如「最大器官＝皮肤，最大内脏＝肝脏」「四立分四季」。

## 四、标题公式

固定前缀，方便做系列、便于搜索：

```
公基常识Day{NN}｜{钩子}
```

钩子四选一：

1. 押错率型：「第3题最容易记混」「这5题全对的不到三成」
2. 圈层型：「第2题体制内才熟」「考过编的秒选」
3. 反常识型：「这题看着简单，90%的人选错」
4. 场景型：「第5题，夏天每天都在发生」

一次给 3 个备选，第一个最推荐。

## 五、正文模板（≤6 行）

```
{一句情绪化开场}😅

今天5道：{板块1}/{板块2}/{板块3}/{板块4}/{板块5}👇

1️⃣ {问句1}
2️⃣ {问句2}
3️⃣ {问句3}
4️⃣ {问句4}
5️⃣ {问句5}

错几道？评论区报个数～
```

问句要口语化、有画面，不要照抄题干（照抄会被判定重复、也少人点开）。

`文案.md` 固定用这个骨架（标题正文用代码块包起来，方便手机端整段复制）：

````markdown
# Day 0N 发布文案（可直接复制）

## 标题（三选一）

1. **公基常识DayN｜{钩子A}**
2. 每天5道公基常识·第N天｜{钩子B}
3. {钩子C}

## 正文

```
{正文，≤6 段}
```

## 标签

```
#公基常识 #常识判断 #公考 #事业单位考试 #考编 #行测 #每日一题 #知识分享 #学习打卡
```

## 本期答案速查

| # | 板块 | 答案 | 考点 |
|---|---|---|---|
| 1 | 法律常识 | B 减轻或免除处罚 | 刑法20条，防卫过当「应当」减免 |
| 2 | … | C 六个月 | … |

## 互动引导

- 评论区置顶：「DayN 你对了几道？明天想看政治还是科技？」
- {挑 1 道最容易错的题，补一句提示}
````

骨架之外**不要新增任何章节**（不要再写「发布建议」「选题依据」「图片说明」之类）；
「时段建议」只在对话里告诉用户，不写进 `文案.md`，保证每篇结构完全一致。

格式硬要求：

- 标题写 `DayN`（不补零：Day2、Day3、Day9），卡片上的 `DAY 0N` 由脚本补零，两者不需要统一。
- 三个标题里，第 1 个必须加粗，固定以「公基常识DayN｜」开头。
- 「正文」「标签」两节要用 ``` 代码块包住，方便用户整段复制。
- 答案速查表的「答案」列写成「字母 + 空格 + 选项全文」，「考点」列一句话。
- 「互动引导」固定两条，第二条必须是挑出的那道易错题。

## 六、标签池（每次取 9 个）

固定 6 个：`#公基常识 #常识判断 #公考 #事业单位考试 #考编 #行测`
轮换 3 个：`#每日一题 #知识分享 #学习打卡 #备考日常 #省考 #教师编 #三支一扶 #刷题`

## 七、发布建议

- 时段：7:30–8:30、12:00–13:00、20:00–22:00。
- 首图用 `01-第1题.png`（带 hook 那句），信息流里最抓眼。
- 评论区自己置顶一条互动问题，收集下期选题： 「明天想看政治还是科技？」
- 10 张图按 01–10 顺序上传，不要打乱「题 → 解析」的节奏。

- [ ] 脚本无 WARN 输出
- [ ] preview.png 里没有溢出、断词、压字
- [ ] 文案.md 标题 3 个、正文 ≤6 行、标签 9 个
