# 出题与发布手册

## 一、板块权重（决定长期选题配比）

公基/常识判断七大板块的题量权重（多套真题统计，参考 [成公教育·常识高频考点](https://www.cgzj.com/gk/12976.html)）：

| 板块 | 每套题量 | 备注 |
|---|---|---|
| 政治理论 | 6–8 | 分值最高，含党史、马哲、毛中特、习思想 |
| 法律 | 4–6 | 民法典、刑法、宪法、行政法 |
| 文史 | 2–3 | 成语典故、文学史、科举、传统节日 |
| 科技 | 2–3 | 生活物理化学、生物医学、航天、材料 |
| 时政 | 2–3 | 时效性强，慎用（易过期） |
| 地理 | 1–2 | 国情、分界线、气候、地名 |
| 经济 | 1–2 | 恩格尔系数、CPI、货币政策、税种 |

单期只出 5 题，配比是 **1–2 道真题 + 3–4 道高频常识点**；高频常识点按 **1 政治 + 1 法律 + 1 文史 + 1 科技 + 1 生活/地理/经济轮换** 取。
每 5 期至少要有 2 期带政治理论，否则长期跑偏。

## 二、真题配额（每期 1–2 道，必选）

每天 5 题里固定放 **1–2 道真题**（推荐 2 道），其余用高频常识点补满。

**算真题的范围**：国考（副省级/地市级/行政执法）、省考（联考与独立命题）、事业单位（联考 A/B/C 类、各地市统考）、三支一扶/选调等编制类考试的「常识判断」「公共基础知识」卷。

**不算真题**：

- 机构模拟题、原创迁移练习；
- 只写「真题改编」、没有年份和题号的题；
- 把几道原题拼在一起的「综合题」；
- 只在标题里写「历年真题」、题后没有出处的题库题。

**位置轮换**：两道真题不要每期都放在第 1、2 题，按 1/3 → 2/4 → 3/5 轮换，避免读者形成「只有前两题是真题」的印象。真题在哪一题，文案速查表的「考点」列就标出出处。

**配比建议**：真题优先选法律、政治、公文、科技这些高频板块；文史、地理、经济类真题如果核验不到原卷，就用高频常识点补，不硬凑。

## 三、真题检索与核验

### 检索优先级

1. **青云培训学校「每日一练」逐题页**（qy.school）：每页带原卷截图、题号与答案，最稳。形如
   `https://www.qy.school/daily-practice/daily-practice-2023-85-<hash>`
2. **粉笔 / 华图 / 中公的题库真题页**：页面必须明确标出年份、考试名称、题号。
3. **各省人事考试网 / 人社厅**发布的真题 PDF 与官方答案解析。
4. **真题汇编扫描页**：能看到原卷版面（题号、选项排版）。

### 检索词

- `2024 国考 行测 地市级 常识 第88题`
- `2023 事业单位联考 公基 真题 解析`
- `2022 省考 常识判断 真题 答案`

找到后，用题干里的独特短语再搜一次做交叉验证；只有一家小站收录、又看不到原卷页图的，先当没找到。

### 核验三步（缺一不可）

1. 页面能明确看到「年份 + 考试 + 题号」，或原卷页图上能对上题号；
2. 四个选项完整、与题干对应（选项数或顺序对不上 = 不是同一题）；
3. 答案自己推一遍，和页面答案一致；不一致或网上答案有争议 → 换题。

**查不到就换题**：不要用「我记得是某年考过」凑数，也不要标一个没核实的年份。宁可这一期两道真题都出自同一场考试，也不要编出处。

### 解析怎么写

真题解析自己写，不要照抄机构解析：

- 第一段讲原题依据（法条、原理、原文），点明「本题考的是……」；
- 第二段讲易错点或延伸，可以提一句「当年这道题的错误率很高」；
- 不要写「某机构解析认为」，也不要带课程/公众号广告。

### 记录

把 `source`（完整出处）和 `point`（考点）写进当日 JSON，作为下一期查重的台账。

## 四、轮换与查重

出题前先读 `days/*.json` 全量，列出已出过的「板块 + 考点 + 出处」，新题避开：

```powershell
Get-ChildItem days\*.json | ForEach-Object {
  $d = Get-Content $_ -Raw -Encoding utf8 | ConvertFrom-Json
  $d.items | ForEach-Object { $_.tag + ' | ' + $_.point + ' | ' + $_.q + ' | ' + $_.source }
}
```

**两层查重**：

1. **题号级**：同一 `source`（年份 + 考试 + 题号）永不复用，哪怕换问法、换选项顺序也不行；
2. **考点级**：`point` 相同或同族，相邻两期不重复；隔一期可以换变体。

同考点族的变体示例：「科举」考过「正式确立于哪个朝代」后，下一期可考「殿试始于哪个朝代」「八股文盛行于哪个朝代」，但不能同一句题干。

## 五、题目写作

**题干**：≤16 字一行放得下最稳。超了就必折行，折行处会劈开词，观感很差。

- 好：「防卫过当，依法应当如何处罚？」「秦岭—淮河一线大致相当于？」
- 差：「航天员在空间站里，为什么用普通钢笔、圆珠笔写不出字？」（会断成「普通钢 / 笔」）
- **不要以全角引号或书名号开头**：`“刻舟求剑”错在……` 会因字形左侧留白，让朱红竖标和文字之间空出一截，看起来像竖标悬空。改成 `成语“刻舟求剑”错在……` 加个引导词即可。

**选项**：≤14 字，四个长度接近；干扰项要「像」，不能一眼假。四个选项都只有两三个字时，卡片右侧会空出一大片，给短选项补限定词（「一个月」→「试用期一个月」）。

**答案**：严格核实，拿不准换题；5 题答案字母打散（B/C/A/B/D 这种）。

**解析**：两段，每段 ≤60 字。第一段给依据（法条、原理、原文），第二段给易错点或延伸。每段控制在 **40–48 字（约两行）**最稳：太短卡片会显得空，超过 50 字更容易在词中间折行。**发现图上把词劈开了，就改句子**（加减两个字把断点挪走），不要插换行符。

**记一句**：≤24 字，一句话能背走，最好带对比或口诀，例如「最大器官＝皮肤，最大内脏＝肝脏」「四立分四季」。

### 真题改写

- 题干可以压缩背景铺垫（「根据材料……」这类可删），但**不能删掉解题所需信息，不能改答案**；
- 选项保持原题四项；为了让长度接近，可以微调措辞，但正确项的含义不能动；
- 答案以原卷/官方答案为准；网上答案与官方冲突且查不清 → 换题；
- `tag` 用「板块 · 题源缩写」：`法律常识 · 2024国考`、`政治理论 · 2023事业单位联考`、`科技常识 · 2022广东省考`；脚本会自动拆成两枚胶囊——绿色「板块」+ 红色「真题 · 题源」，两枚都印在题目卡顶部，读者不看解析也知道这是真题、考什么板块；
- `source` 写完整但克制：`2024年国考行测（地市级）第88题`，控制在 30 字内；
- `point` 写成「板块·考点」：`刑法·正当防卫`、`党史·遵义会议`，方便查重。

## 六、标题公式

固定前缀，方便做系列、便于搜索：

```
公基常识Day{NN}｜{钩子}
```

钩子四选一：

1. 押错率型：「第3题最容易记混」「这5题全对的不到三成」
2. 圈层型：「第2题体制内才熟」「考过编的秒选」
3. 反常识型：「这题看着简单，90%的人选错」
4. 场景型：「第5题，夏天每天都在发生」

一次给 3 个备选，第一个最推荐。钩子只用于 `文案.md` 的标题，**不要印到首图**：题目卡从标签直接开始。

## 七、正文模板（≤6 行）

```
{一句情绪化开场}😅

今天5道：{板块1}/{板块2}/{板块3}/{板块4}/{板块5}👇

1️⃣ {问句1}
2️⃣ {问句2}
3️⃣ {问句3}
4️⃣ {问句4}
5️⃣ {问句5}

错几道？评论区报个数～
```

问句要口语化、有画面，不要照抄题干（照抄会被判定重复、也少人点开）。

`文案.md` 固定用这个骨架（标题正文用代码块包起来，方便手机端整段复制）：

````markdown
# Day 0N 发布文案（可直接复制）

## 标题（三选一）

1. **公基常识DayN｜{钩子A}**
2. 每天5道公基常识·第N天｜{钩子B}
3. {钩子C}

## 正文

```
{正文，≤6 段}
```

## 标签

```
#公基常识 #常识判断 #公考 #事业单位考试 #考编 #行测 #每日一题 #知识分享 #学习打卡
```

## 本期答案速查

| # | 板块 | 答案 | 考点 |
|---|---|---|---|
| 1 | 法律常识 | B 减轻或免除处罚 | 刑法20条，防卫过当「应当」减免（2024国考） |
| 2 | … | C 六个月 | … |

## 互动引导

- 评论区置顶：「DayN 你对了几道？明天想看政治还是科技？」
- {挑 1 道最容易错的题，补一句提示}
````

骨架之外**不要新增任何章节**（不要再写「发布建议」「选题依据」「图片说明」之类）；
「时段建议」只在对话里告诉用户，不写进 `文案.md`，保证每篇结构完全一致。

格式硬要求：

- 标题写 `DayN`（不补零：Day2、Day3、Day9），卡片上的 `DAY 0N` 由脚本补零，两者不需要统一。
- 三个标题里，第 1 个必须加粗，固定以「公基常识DayN｜」开头。
- 「正文」「标签」两节要用 ``` 代码块包住，方便用户整段复制。
- 答案速查表的「答案」列写成「字母 + 空格 + 选项全文」，「考点」列一句话；真题那一行在末尾补「（2024国考）」这样的出处，非真题不补。
- 「互动引导」固定两条，第二条必须是挑出的那道易错题。

## 八、标签池（每次取 9 个）

固定 6 个：`#公基常识 #常识判断 #公考 #事业单位考试 #考编 #行测`
轮换 3 个：`#每日一题 #知识分享 #学习打卡 #备考日常 #省考 #教师编 #三支一扶 #刷题`

## 九、发布建议

- 时段：7:30–8:30、12:00–13:00、20:00–22:00。
- 首图用 `01-第1题.png`，题目卡顶部直接是「板块 + 真题 · 题源」胶囊，不再印文章标题；标题留给文案。
- 评论区自己置顶一条互动问题，收集下期选题： 「明天想看政治还是科技？」
- 10 张图按 01–10 顺序上传，不要打乱「题 → 解析」的节奏。
