## Description:

Builds editable, responsive local websites from product or service descriptions with sourced copy and JishuDB-backed revisions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[bowen-aijishu](https://clawhub.ai/user/bowen-aijishu)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to build editable local landing pages, product demos, and small showcase sites from product or service briefs, with source attribution and revisions retained in JishuDB.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill requires JishuDB setup and storage before it can build a website; installation and authorization can affect local configuration and grant write access.

Mitigation: Before approval, review the displayed release, install paths, client configuration, local MCP URL, and requested JishuDB write/OAuth permissions; decline setup if those changes are not acceptable.
