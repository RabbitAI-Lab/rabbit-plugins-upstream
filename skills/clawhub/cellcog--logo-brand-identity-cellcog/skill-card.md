## Description:

Create logos and complete brand identities with CellCog, including brand kits, color palettes, typography, guidelines, social and web assets, and video from a single brief.

This skill is ready for commercial/non-commercial use.

## Publisher:

[cellcog](https://clawhub.ai/user/cellcog)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers can ask an agent to create logos and cohesive brand identity materials from a brief, including palettes, typography, guidelines, and social or web assets.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Submitted briefs and assets may contain information the user does not want to share with CellCog.

Mitigation: Submit only briefs and assets the user is comfortable sharing with CellCog.

Risk: The CellCog API key grants full account access, and usage consumes credits.

Mitigation: Use a separate revocable API key and monitor its use.

Risk: Installing the CellCog dependency introduces dependency risk.

Mitigation: Review the dependency and prefer fixed, reviewed versions when installing.
