## 简短介绍

MC 全生态智能适配工程师是一款专为 Minecraft 模组玩家和整合包作者打造的智能管理工具。通过 AI 驱动的自动化流程，让模组环境配置、崩溃排查、版本迁移等繁琐工作一键完成。支持 Forge、NeoForge、Fabric、Quilt 四大加载器（V1.1.0 Quilt 深度支持），覆盖 MC 1.16.5 至 1.21.4+ 全版本。支持 12 种语言自动检测（含阿拉伯语 RTL），AI Agent 在线翻译+学习机制，跨平台路径检测（Windows/macOS/Linux）。

## F6 存档同步：路径权限说明

F6 只操作显式允许的目录，备份与恢复使用同一套校验。

**默认白名单（用户不做任何配置时的完整清单）**
- `.minecraft/saves`
- `.minecraft/config`
- `.minecraft/mods`
- `.minecraft/resourcepacks`
- 启动器自定义存档目录（仅当它位于 `.minecraft` 之内时收录；网易版对应 `MCLDownload/Game`）

**用户额外添加**
- 界面/命令行新增的目录并入白名单：`--allowed-dirs "D:\MySaves"`（分号分隔多个），写入**本机** `data/save_sync_allowlist.json`，下次仍生效。同步目录里的 `mc_sync_config.json` 不能扩大白名单，避免云端配置被篡改后提权。
- 本次操作指定的同步目录（`--sync-dir`）只并入本次运行的白名单，不持久化、不跨次记忆。

**受保护目录：默认拒绝，当次授权才放行**
- 范围：`C:\Windows`、`Program Files`、`Program Files (x86)`、`ProgramData`、系统盘根目录、用户主目录本身（其下子目录需显式添加）。
- 默认一律拒绝，程序不主动触碰；也不会因为配置文件里写了这些路径就放行。
- 只有用户在**某一次具体操作**中同时给出 `--allow-hard-path <路径>` 与 `--confirm-hard-path` 才执行：
  - 只给 `--allow-hard-path`：不执行，返回风险提示并要求确认。
  - 不给 `--allow-hard-path`：直接拒绝。
- 每次操作单独确认，没有全局开关，不记住历史授权。
- 留痕：`data/save_sync_audit.jsonl` 记录时间、路径、操作类型、用户是否确认。

**越权处理**
- 路径先规范化再解析真实路径，`..` 穿越、符号链接/目录联接（junction）跳出白名单都会被拦截。
- 恢复时逐个校验 ZIP 成员，拒绝 `../` 成员与符号链接成员；备份时逐个校验文件与子目录。
- 被拦截的路径不会静默跳过：写入日志，并在报告 HTML 中列出（最多 20 条，超出显示总数）。

**残余风险（如实说明）**
- 受保护目录是"默认拒绝 + 当次确认"的门禁，不是物理不可写。用户显式确认后，程序在技术上仍可写入该路径。若需要更严格的口径，可改为仅允许白名单内路径可写（去掉确认门）。

- **AI 智能分析**：基于崩溃日志的智能错误识别，覆盖内存溢出、光影冲突、Mixin 冲突等 25+ 种场景

## 使用方式

### 快速开始

1. 下载 Skill 发布包（zip 格式）
2. 解压到任意目录
3. 双击 `mc-skill-start.bat` 启动交互式菜单
4. 按菜单提示选择所需功能

### 命令行调用

```bash
# 解析模组 JAR
python main.py --feature jar_parser --jar-path "create.jar"

# 搜索并下载模组
python main.py --feature mod_searcher --query "Create" --mc-version "1.21.1" --loader "neoforge"

# 分析崩溃日志并自动修复
python main.py --feature auto_fix --crash-log "crash.txt" --fix-mods-dir "C:\...\mods"

# 评估模组移植可行性
python main.py --feature migration_assess --jar-path "mod.jar" --from-mc-version "1.20.1" --to-mc-version "1.21.1" --from-loader "forge" --to-loader "neoforge"

# 阿拉伯语翻译模组（V1.0.4新增）
python main.py --feature translator --mods-dir "C:\...\mods" --lang ar_sa
```

### 系统要求

- Python 3.10+
- Windows / macOS / Linux
- 网络连接（模组搜索与版本查询功能需要）
