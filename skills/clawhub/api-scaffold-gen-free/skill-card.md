## Description: <br>
Generates REST and GraphQL API scaffold code, authentication templates, basic tests, and mock API server starting points for Node.js and Python projects. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[thcjp](https://clawhub.ai/user/thcjp) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to generate starter API routes, schemas, authentication middleware, test templates, and mock services for new backend projects. It is best suited to clearly scoped Node.js or Python API scaffolding requests. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated scaffold work may include file writes, package installation, server startup, or network test commands. <br>
Mitigation: Review proposed writes and exec commands before approval, especially package installs, server startup commands, network tests, and changes inside an existing project. <br>
Risk: Generated starter code may use in-memory storage or basic authentication templates that are not production-ready as-is. <br>
Mitigation: Replace in-memory storage with a real database and add production-grade secret management, token refresh, authorization, and environment-specific configuration before deployment. <br>
