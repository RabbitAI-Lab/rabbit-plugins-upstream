# NOTICE

## 第三方代码与素材

本技能不包含任何第三方源码、二进制依赖或外部素材的复制件：

- 运行时代码全部原创，仅使用 Python 标准库（`argparse`、`hashlib`、`json`、`pathlib`、`shutil`、`subprocess`、`zlib` 等）。
- 仓库内 fixture 为脚本生成的合成数据（虚构 Skill 名、虚构会话），不是真实用户数据。
- 图标为项目自绘的纯色几何图形，由 `scripts/make_icons.py` 生成，无第三方字体或图形库。

## 数据边界

审计默认只读元数据，不读取会话、备份、日志或数据库正文。发布包不包含个人路径、公司资料、密钥或真实会话内容。
