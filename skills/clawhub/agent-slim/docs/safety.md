# 安全边界与 allowlist

## 默认姿态

- 默认 `dry-run`，只读盘点并生成差异计划。
- 任何实际改动必须显式 `apply`，并先完成备份、哈希、隔离区和回滚预检。
- 不删除原始资料、聊天记录、会话正文、备份或用户文件。
- 所有执行写审计记录；秘密只记录“存在/已脱敏”，不记录值。

## 首版可执行 allowlist

s3 首版只实现移动类动作；不修改文件内容、配置或数据库。

| 动作 | 允许条件 | 证据 | 回滚 |
|---|---|---|---|
| `quarantine-redundant-backup` | 两个以上备份文件 SHA-256 完全相同；至少保留一份 | 文件大小、SHA-256、保留项路径 | 从事务隔离区移回并复核 SHA-256 |
| `archive-verified-old-session` | 仅针对 `sessions/`；mtime 超过阈值；调用方显式确认会话已关闭且无未完成交接 | 元数据年龄、调用方确认、SHA-256 | 从隔离归档移回并复核 SHA-256 |
| `quarantine-low-frequency-file` | 只允许 Skill 内未被正文引用的文件；调用方显式确认低频 | 引用图、调用方确认、SHA-256 | 从隔离区移回并复核引用与 SHA-256 |

设计期 allowlist 中的“压缩描述”“关闭插件”和“内容路由改写”在 s3 只进入 `manual-review`，不可执行。allowlist 只表示“可以纳入候选”，不表示可批量无审阅执行。

## 执行事务

- `plan` 只生成 JSON；所有待执行项必须包含目标、原因、收益口径、风险、隔离路径和验证方法。
- 没有哈希、引用或调用方确认证据的项只能进入 `pending-confirmation`。
- `apply` 默认 dry-run；只有显式 `--apply` 才创建事务。
- 创建任何移动前，先写 `manifest.json`、`manifest.sha256`、`restore.py` 和 `restore.sh`。
- 所有目标只移动，不删除；移动前后都核对 SHA-256。
- 事务目录默认位于被审计 Home 之外，避免恢复后残留污染原目录。
- 目标、事务目录或隔离目标已存在时立即停止，不覆盖。
- 实际 apply/restore 每次写审计日志；日志只含相对目标、哈希、结果，不含文件正文或秘密。

## 默认禁止或需独立授权

| 项目 | 默认处理 |
|---|---|
| 删除任何原始文件、会话或备份 | 禁止，Agent Slim 不提供删除动作 |
| 修改密钥、token、认证、provider、base_url 或计费 | 禁止，交给具备明确授权的配置流程 |
| 修改系统级配置、权限、LaunchAgent 或安全设置 | 禁止 |
| 执行数据库 VACUUM、自动清理或不可逆压缩 | 禁止 |
| 将公司、客户、项目资料发送到云端或 Git 远端 | 禁止，除非用户明确指定范围并另行同意 |
| 用 Cold 存储释放量宣称 Token 收益 | 禁止 |

## 隐私与发布检查

发布候选必须扫描：

- 私人绝对路径和本机用户名；
- 公司、客户、项目、合同、图纸或施工资料标识；
- API key、token、密码、认证文件和连接串；
- 会话正文、真实任务输入输出和 OCR 原文；
- 未注明的第三方版权内容。

扫描结果只能是 PASS 或 FAIL。无法扫描的对象写“待确认”，不能默认为安全。

## 隔离区与事务

1. 冻结输入清单并记录哈希。
2. 在 Home 之外创建唯一事务目录；目标路径均已存在时停止。
3. 先写 manifest、manifest 哈希、恢复脚本和结果路径，再移动文件。
4. 每个动作移动后立即核对 SHA-256；异常时按同一 manifest 自动回滚。
5. 运行能力回归；缺失 test-prompts 时只能记 `PARTIAL`。
6. 全部关键项 PASS 才提交；恢复使用同一 manifest，遇到用户后改内容立即停止。

事务目录不得被自动清理。只有用户明确确认事务已结算后，才可按独立清理流程处理。

## 失败处理

- 读取失败：停止该对象，不猜测内容。
- 写入失败：立即停止并恢复已处理对象。
- 回归失败：回滚全部本事务改动，保留失败报告和隔离副本。
- 回滚失败：提高为阻断级风险，停止后续操作并输出人工恢复步骤。
- 未知宿主能力：标 `unsupported`，不得尝试不存在的命令。

## 审计字段

最少记录时间、项目、宿主、执行模式、范围、动作、前哈希、后哈希、隔离路径、验证结果、回滚结果和操作者。审计记录不得包含秘密值或完整会话正文。
