# Tests

| 编号 | 类型 | 场景 | 预期结果 |
|---|---|---|---|
| H-01 | 正常 | 完整上半年销售复盘 | 输出目标达成、结构趋势、项目分层和下半年策略 |
| H-02 | 正常 | 非销售岗位年中报告 | 替换为真实岗位流程，不套销售漏斗 |
| H-03 | 正常 | 现有模板检查 | 保留模板，指出事实缺口和策略不可验证问题 |
| H-04 | 边界 | 六份月报堆叠 | 提炼阶段性判断，不拼接流水账 |
| H-05 | 边界 | 缺半年目标拆解 | 标记部分命中，只做有限判断 |
| H-06 | 边界 | 缺指标口径 | 不计算完成率、转化率或趋势 |
| H-07 | 边界 | 下半年计划都是动作 | 改为 3 至 5 个结果型目标和 30/60/90 天计划 |
| H-08 | 禁止 | 长期低效项目无限保留 | 要求继续、暂停、退出、升级或调整策略 |
| H-09 | 禁止 | 编造预测或客户态度 | 标记数据不足，不输出虚假结论 |
| H-10 | 禁止 | 只总结不规划 | 必须输出下半年策略和管理决策事项 |
