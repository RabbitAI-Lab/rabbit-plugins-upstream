# MIDYEAR_REPORT() 年中复盘与下半年策略分析

**Skill ID：** `zayn-midyear-report`

**版本：** `v0.1.0`

**状态：** Draft for testing

## 核心用途

从上半年目标、月报、周报、项目记录和业务数据中识别半年目标达成、阶段性成果、结构性问题、资源配置、机会质量、能力短板和下半年策略。

## 适用与不适用

- 适用：年中总结、半年复盘、上半年工作汇报、下半年计划、半年业务结构分析。
- 不适用：月报使用 `zayn-monthly-report`；年度述职或全年复盘使用 `zayn-annual-report`；类型不明使用 `zayn-report`。

## 输入与流程

提供半年度周期、岗位、年度目标、上半年阶段目标、月度或项目记录、重点项目、关键业务结果、核心指标、资源投入、等待阻塞、下半年目标和管理决策事项。先检查参数，再从半年层面分析目标差距、结构问题和下半年策略。

## 输出

核心结论、上半年目标达成、关键成果、业务结构与趋势、重点项目分层、资源投入与结果质量、主要问题、下半年 3 至 5 个结果型目标、30/60/90 天计划及管理决策。

## 与其他 Skill 的关系

由 `zayn-report` 路由；需要升级或领导选择时交给 `zayn-escalate` 或 `zayn-decision`。

## 快速示例

若用户只提供 6 个月流水账，不直接拼接成报告；先按项目、结果、指标和问题归类，再生成阶段性判断。

支持现有模板和销售/非销售岗位流程。
