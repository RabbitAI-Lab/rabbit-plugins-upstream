# 行测数量关系 · 每日1题（小红书图文）

每期固定产出：3 张 1080×1440（3:4）图 + 1 份文案 + 台账一行。

```
<项目>/
├─ days/dayNN.json        本期题库（永不覆盖）
├─ days/_index.md         已发台账（去重）
├─ dayNN/
│  ├─ 01-题目.png         题干 + A/B/C/D
│  ├─ 02-答案.png         答案 + 3–5 步 + 验证 + 口诀 + 另解
│  ├─ 03-考点.png         识别 / 关键 / 避坑 + 口诀 + 下期
│  └─ 文案.md             标题 3 选 1 + 正文 + 标签
└─ preview.png            3 张总览，只自检，不上传
```

## 硬性规则

- 题目必须来自可核实的真题页（题库/机构页），**不得自编，不得改数据**。只允许断句、把“问”改成“问：”并单独分段。
- 答案自己复算一遍，解析每一步都要能对上选项。查不到年份/考试名就只写“公务员行测真题·××问题”，**不编年份**。
- 同一道题永不复用；同一题型 7 天内不重复（查 `days/_index.md`）。
- 图片里禁止 emoji（PIL 画成方框）、禁止二维码；导流只放正文。
- 不手改 PNG。版式不对就改 JSON 或脚本。

## 工作流

### 1. 定位项目

先找当前目录的 `xhs-shuliang/`；若没有，但 `D:\文档\deepseek-harness\default-workspace\xhs-shuliang` 存在，优先复用那个（保持台账连续）；都没有就新建：

```
xhs-shuliang/days/_index.md   # 表头：| Day | 题型 | 题干摘要 | 答案 | 来源 |
```

把本技能的 `scripts/make_cards.py` 复制到 `xhs-shuliang/scripts/`（若已存在且内容一致则跳过）。`<skill>` 指本技能目录。

### 2. 选题（先查台账）

- 必拿四类轮转：工程 → 行程 → 容斥 → 利润；其余穿插排列组合与概率、几何、和差倍比、最值、年龄、浓度、牛吃草、循环周期。
- 读 `days/_index.md`，避开最近 7 天的题型；`day` = 最大 Day + 1。
- 详细配比、找题源、方法题眼见 `references/playbook.md`。

### 3. 找题 + 核答案

在可信题库检索（公开真题库、高途、粉笔、华图、中公、公务员考试网），优先选**题干、四个选项、答案、解析齐全**的页面，记下 URL 与页面名。
**首选 `https://gwy.gkzhenti.cn/`**：整卷页 `/paper/<id>` 匿名可读，直接给出题干+四选项；`/answer/<id>` 给逐题答案；`/explain/<id>` 给解析。站内搜索要登录，整卷页不用——搜索引擎抓不到真题时的兜底就是它。
自己按解析复算；解析缺失就自己解，但题目数据原样保留。把过程压成 3–5 步“秒杀”写法，并拟一句口诀。
题干超过 135 字就换一道更短的题，不要删条件。

### 4. 写 `days/dayNN.json`

复制 `assets/template.json` 后逐项替换。字段是版式红线：

| 字段 | 限制 / 说明 |
|---|---|
| `day` / `topic` | 期数 / 题型，如“工程问题-效率比例型” |
| `source` | `{name, url}`，台账与文案用 |
| `hook` | ≤14 字，首图钩子 |
| `tag` / `subtag` | 题型 / 细分方法 |
| `q` | 题干；用 `\n` 把“问：…”单独成段 |
| `options` / `answer` | 4 项（≤5 字）/ 下标 0=A |
| `answerText` | 答案短语 ≤6 字 |
| `steps` | 3–5 条，每条 ≤24 字 |
| `verify` | 回代验证 ≤30 字 |
| `alt` | 另解一行 ≤40 字 |
| `tip` | 口诀 ≤20 字，两分句对仗 |
| `points` | 3 条 `{t,b}`：识别 / 关键 / 避坑，b ≤26 字 |
| `next` | 下期题型 |
| `titles` | 3 条，≤20 字 |
| `body` | 3 段，段内可 `\n`；总 ≤6 行 |
| `tags` | 9 个 `#` 标签 |

### 5. 出图 + 文案

```powershell
& "<PY>" "<项目>/scripts/make_cards.py" "<项目>/days/dayNN.json"
```

`<PY>` 优先 `C:\Users\Administrator\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe`（含 Pillow），否则 `python`。
脚本按 JSON 位置推断输出：`days/` 上一层生成 `dayNN/`，并写 `preview.png`；`titles/body/tags` 齐全时同时生成 `文案.md`。
打印 `WARN` 必须改短 JSON 重跑。

### 6. 自检（必须看图）

用 read_image 逐张看，对照 `assets/style-reference.png` 和 `references/playbook.md` 的审校清单：

- 字体、纸色、朱红/墨绿与参考图一致；
- 行首无标点，比例/算式/数字单位没被拆开；
- 题干不溢出，选项不被压，口诀框不压页脚/下期预告；
- 题干与源题逐字一致，答案与选项一致。

不合格改 JSON 重跑，不要交差。

### 7. 更新台账 + 交付

往 `days/_index.md` 追加：`| Day | 题型 | 题干摘要(≤20字) | 答案 | 来源 |`。
用 present 交付 3 张图 + `文案.md`；回复里直接贴标题、正文、标签，并说明答案在第 2 张。

## 常见坑

- **找不到真题页**：换关键词（题型 +“真题 + 解析”），或换一道；绝不拿模拟题冒充真题。
- **解析算不通**：放弃该题，不要改题迎合答案。
- **题干末行只剩一两个字**（如“…回到B / 点？”）：脚本已自动降字号重排；仍不行就微调句子两三个字，或把“问：…”单独成段。
- **题干连 38px 都放不下**：换更短的题，或把“问：…”单独成段；不要删条件。
- **折行劈开词**（如“三个队”断成“三个 / 队”）：微调句子两三个字把断点挪走；不要手改 PNG。
- **WARN 出现**：按提示删字、分段，不要改脚本坐标。
