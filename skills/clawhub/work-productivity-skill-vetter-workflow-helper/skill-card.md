## Description: <br>
Helps AI-agent users, skill authors, maintainers, and teams create practical workflows, artifacts, checklists, analyses, code changes, and decision support for skill vetting, bug fixing, setup hardening, safety, and reliability work. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, skill authors, maintainers, and AI-agent users use this skill to turn skill-vetting and reliability requests into concrete plans, templates, checklists, analyses, code changes, or decision aids. It is intended for practical workflow support around security review, bug fixing, setup hardening, and adjacent skill creation. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill has broad auto-invocation terms around skill vetting, security, GitHub, bug fixes, and setup hardening, so it may activate in contexts where a narrower skill would be preferred. <br>
Mitigation: Review the trigger terms and implicit invocation policy before installation, and route or disable the skill where precise activation is required. <br>
Risk: The skill can produce workflow, checklist, analysis, code, shell-command, and configuration guidance that may be incorrect or incomplete for a specific environment. <br>
Mitigation: Review generated outputs before use, scan proposed skill changes before deployment, and validate results against the stated success criteria. <br>
