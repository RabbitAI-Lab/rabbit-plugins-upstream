## Description:

Helps creators create and update BioFlow link-in-bio page drafts, including page titles and content blocks, without publishing live pages.

This skill is ready for commercial/non-commercial use.

## Publisher:

[bsalaeddin](https://clawhub.ai/user/bsalaeddin)

### License/Terms of Use:

MIT-0

## Use Case:

BioFlow creators use this skill to create link-in-bio pages or make user-directed changes to page drafts, including titles and the order or contents of blocks. Publishing is a separate action.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Removing blocks or overwriting draft fields can discard intended draft content.

Mitigation: Review the requested changes and require explicit confirmation before destructive or overwrite actions.

Risk: Draft changes may not match what the creator intends to publish.

Mitigation: Review the updated draft and publish separately only when ready.
