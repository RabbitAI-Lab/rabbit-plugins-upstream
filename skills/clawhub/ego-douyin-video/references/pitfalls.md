# 避坑（抖音创作者中心）

创作者发布页没有 wujie / shadow DOM。snapshot、`page.click`、`role:` 定位可以直接用。下面这些例外是脚本已经处理过的，Agent 重试时不要绕开。

1. **位置权限弹窗会打断脚本。** 首次点击上传时抖音可能请求地理位置，ego 以 user-control 错误结束本次调用。让人在浏览器里处理（建议拒绝），再用 JSON 里的 `spaceId` 重跑。点击通常已经生效，脚本探测到 `/content/post/video` 就跳过上传。这个 space **不要关**。
2. **标题是独立 input，限 30 个码位。** placeholder 含「作品标题」。React 受控输入必须走 native setter，加上 `input` / `change`。直接改 `.value` 框架不认。简介才是 contenteditable。空标题、超长标题在写配置时就失败，不会打开浏览器。
3. **上传按钮文本可能被拆成「上传」「视频」。** 按去掉空白后 `=== "上传视频"` 匹配，别用精确单行文本。隐藏节点（`offsetParent === null`）跳过。
4. **发布按钮是 `<button>`，自身文本精确「发布」。** 页面另有「同时发布 / 不同时发布 / 立即发布 / 定时发布」。TreeWalker 只认 BUTTON 的直接文本节点，再 `scrollIntoView({ block: "center" })` 后坐标点击。
5. **简介编辑器是 contenteditable**（占位「添加作品简介」）。click 聚焦后 `execCommand('insertText')`，写入后回读比对。不一致就是失败。
6. **成功信号是 URL 含 `content/manage`，或正文「发布成功」。** 管理列表可能延迟刷新，首屏不一定立刻看到新作品。确认时用管理页搜索标题，不要只看第一屏。
7. **默认设置就能发。** 公开、允许保存、立即发布。调用方没另说就不要改。本技能不实现额外开关。
8. **上传页规则（平台限制，脚本不转码）。** 1 小时以内、16G 以内。超过约 40 秒更适合横版；竖屏短视频尽量再短一些。支持 4K，推荐画幅含 9:16。非标准竖屏（例如 608×1080）可以直接传，平台会适配。
9. **续跑不要重新上传。** `spaceId` 对应的页如果已经在发布表单，脚本只填标题、简介和点发布。
10. **ego 内嵌 Node 不继承 shell 环境变量。** 参数由 `publish.sh` 写入 `/tmp/douyin-video-publish.json`。不要裸跑 `publish.js`，也不要指望 `VAR=x ego-browser nodejs` 能读到 `VAR`。
11. **每次发布前先 `check-login`。** 退出码 `2` 必须停。缺 `ego-browser` 也是 soft-fail，不要硬调浏览器。在 Ego 里登录抖音效果更好。
12. **默认关掉 space。** 登录检查和发布成功都是 `finish({ keep: [] })`。只有 keep 为 `1` 才把成功后的页面留着。登录墙和位置权限打断是例外：space 要留着才能续跑。
13. **评论还没脚本化。** 管理页有评论入口，但发布后的评论链路没有实测脚本。需要评论时人工处理，不要在这个技能里猜选择器。以后补路径时再加脚本和测试。
