# 调用方提供的输入（通用）

本技能**不绑定**任何产品目录，也**不下载**视频（没有 yt-dlp）。调用方自己准备本地文件。发布前确认调用方有权发布该文件。

| 字段 | 必填 | 说明 |
|------|------|------|
| `video` | 是 | 本机视频路径，例如 `/absolute/path/to/video.mp4` |
| `title` | 是 | 作品标题，独立输入框，最多 30 个 Unicode 码位。占位含「作品标题」。写完要回读 |
| `desc` | 是 | 简介，contenteditable。话题写在同一字符串里，例如 `简介 #话题1 #话题2`。写完要回读 |
| `spaceId` | 否 | 登录 handOff 或位置权限弹窗中断后续跑。不要为了重试新开一个 space |
| `keep` | 否 | 第 5 个参数 `1` 才在成功后保留浏览器页。默认 `finish({ keep: [] })` |

系列栏目（播客、课程等）应在**自己的发布清单**里给出上表字段，不要把产品路径写进本技能。

默认公开、允许保存、立即发布。调用方没另说就不要改这些开关。本技能不填评论。
