# 输出模板

用真实内容替换占位符；信息缺失时保留待确认标记，不得编造。

## 即时消息

```text
[称呼]，关于[事项]，我的建议是[结论或请求]。

目前确认的信息是：[关键事实]。
主要影响是：[影响或风险]。
我已经做了：[已采取动作]。

建议按[推荐方案]处理，原因是[核心依据]。
想请您确认：[需要决定的事项]，最好在[时间]前回复，以便[下一步]。
```
简单事项压缩成一至三段，不重复背景。

## 正式邮件

```text
主题：[需要审批/确认/知悉] + [事项]

[称呼]：

结论/请求：
[一句话说明希望上级决定什么。]

背景与事实：
- [事实一]
- [事实二]

影响与风险：
- [影响]
- [风险或不确定性]

方案：
- 推荐：[方案及理由]
- 备选：[确有必要时填写]

请确认：
[批准范围、选择项或所需支持]

时间要求：
[回复期限及原因]
```

## 口头汇报

```text
1. 先说结论：我建议/需要……
2. 两个关键事实：……
3. 当前影响：……
4. 我已经采取的动作：……
5. 推荐方案：……
6. 请您决定：……
```

准备三个追问：依据是什么、风险多大、为什么推荐这个方案。

## 管理会议

```text
议题：
期望结论：
已确认事实：
当前影响：
方案比较：
推荐方案：
需要决定：
负责人和期限：
```

## 审批系统

```text
申请事项：
申请范围：
业务或工作原因：
金额/资源/期限：
依据与附件：
风险与控制措施：
推荐处理：
期望审批时间：
```

## 请假或工作安排

```text
[称呼]，我申请在[日期/时段]请假/调休/调整工作安排，共[时长]。
[必要原因类别，避免过度披露隐私]。

工作安排如下：
- [事项]由[人员/方式]覆盖；
- [事项]将在[时间]前完成；
- 紧急情况可通过[方式]联系。

请您确认是否可以批准，谢谢。
```

## 未回复跟进

```text
[称呼]，跟进一下之前关于[事项]的请示。
由于[截止时间或影响]，需要在[时间]前确认[具体决定]。
我的建议仍是[推荐方案]；如需补充材料，我可以马上提供。
```

## 回应上级追问

```text
针对您问的[问题]：
- 已确认事实：[事实]
- 仍待确认：[未知项]
- 对当前建议的影响：[影响]
- 建议下一步：[动作]
```
