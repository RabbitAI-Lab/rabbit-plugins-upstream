# UPWARD_COMMUNICATION() 上级沟通与管理沟通

**Skill ID：** `zayn-upward-communication`

**版本：** `v0.1.0`

**状态：** Draft for testing

## 核心用途

把事实、影响、建议和请求整理成直属主管、经理、部门负责人或老板能够快速理解、判断和回复的沟通内容。

本 Skill 面向所有岗位和行业，不把销售、客户或金额信息作为默认前提。

## 适合岗位

适用于销售、技术、研发、产品、运营、项目管理、财务、采购、行政、人力资源、客服及其他需要进行上下级沟通的岗位。

## 适用场景

- 汇报进展、结果、变化或异常
- 申请预算、费用、权限、资源或政策例外
- 请领导在多个方案中作出决策
- 升级超出个人权限或影响较大的问题
- 协调工作优先级、延期、范围或资源冲突
- 申请请假、调休、远程办公或培训
- 表达不同意见、风险提醒或改进建议
- 讨论绩效、职责、工作压力或职业发展

## 需要提供什么

最低需要提供：

1. 沟通对象
2. 沟通事项
3. 沟通目的
4. 希望上级作出的决定或动作
5. 回复期限或紧急程度

建议补充已确认事实、当前影响、已采取动作、方案、推荐意见、限制条件、风险、沟通渠道和期望语气。

## 会输出什么

默认输出：

1. 沟通类型与目标
2. 参数完整度与待确认项
3. 上级最关心的问题
4. 建议沟通策略
5. 可直接使用的沟通文本
6. 上级可能追问的问题
7. 后续跟进建议

用户只要求一段可发送的文字时，默认直接提供简洁版本，不强制展示完整分析。

## 支持的形式

- 微信、企业微信、飞书、钉钉等即时消息
- 正式邮件
- 面谈或电话提纲
- 一对一或管理会议提纲
- OA、费用、采购等审批说明
- 未回复跟进和上级追问答复

## 不会做什么

- 不替代业务、财务、法务、人事或技术判断
- 不虚构制度、权限、预算、金额或证据
- 不把建议、申请或预计写成已经批准
- 不建议隐瞒风险、绕过审批或越级施压
- 不要求用户披露与管理决策无关的敏感隐私

## 如何使用

直接说明事项和沟通目标即可，例如：

```text
我需要向经理申请把项目上线时间推迟一周。测试还有两个高风险问题没有关闭，技术建议先修复。我想用飞书说明情况并请经理确认新日期。
```
