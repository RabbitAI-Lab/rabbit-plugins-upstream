## Description: <br>
Writes PRDs for AI-powered features, covering uncertainty UX, model approach, evaluation criteria, guardrails, fallback behavior, data flywheel, and cost and latency budgets. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Product managers, founders, designers, and developers use this skill to draft PRDs for AI or LLM-powered features. It helps specify the user problem, uncertainty experience, model approach, evaluation bar, guardrails, fallbacks, data feedback loop, and rollout criteria. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: A generated PRD may overstate readiness if stakeholders do not validate the proposed model behavior, evaluation threshold, privacy boundary, or rollout plan. <br>
Mitigation: Review the PRD with product, engineering, privacy, and safety owners before using it to approve implementation or launch. <br>
