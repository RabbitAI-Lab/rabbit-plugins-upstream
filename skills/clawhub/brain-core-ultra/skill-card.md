## Description:

Activates high-level reasoning and decision orchestration for problem decomposition, hypothesis testing, truth ranking, tool selection, anti-hallucination, and completion verification.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agent users use this skill to apply a structured reasoning loop to complex, analysis-heavy tasks that require decomposition, fact verification, tool selection, self-critique, and completion checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill acts as a broad reasoning overlay and may influence many agent responses.

Mitigation: Install only when a global reasoning layer is intended, and keep core agent identity, platform policy, and more specific skills authoritative.

Risk: Always-on analytical guidance can add unnecessary process to simple tasks or high-risk workflows.

Mitigation: Prefer explicit opt-in or clear operating limits for complex, high-risk, or analysis-heavy tasks.
