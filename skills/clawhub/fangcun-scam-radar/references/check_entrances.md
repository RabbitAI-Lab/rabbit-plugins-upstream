# 官方查验入口详解（check_entrances.md）

> 本 skill 独门价值所在：多数防骗内容只教"特征"，这里给"去哪验"。所有入口为官方渠道，写明能查到什么。

## 1. 机构持牌查询

| 入口 | 怎么用 | 能查到 |
|---|---|---|
| 中国证监会官网（csrc.gov.cn）"监管对象"栏目 | 输入机构全名 | 合法证券期货经营机构名录 |
| 中国证券业协会（sac.net.cn） | "信息公示"→从业人员/会员机构 | 券商及从业人员执业注册信息 |
| 中国证券投资基金业协会（amac.org.cn） | "信息公示"→私募基金管理人/基金销售机构/投顾机构 | 基金销售、私募、投顾资质 |
| 国家金融监督管理总局官网 | 金融许可证查询 | 银行/保险机构金融许可证 |

**判定口径**：机构名查无 = 无资质开展相应业务。注意用**全名**查，"XX集团旗下"要一层层剥到持牌主体。

## 2. 合法投顾业务查询

- 基金业协会"基金投顾试点机构名录"：只有名录内机构可以做基金投资顾问业务。
- "智能荐股软件/老师带单/机器人选股"不在名录 = 无资质。依据：《证券基金投资咨询业务管理办法（征求意见稿）》明确"程序化咨询"实质开展自动化投顾即需持牌，不得以"工具"规避监管。

## 3. 平台与 App 来源核实

| 入口 | 怎么用 | 能查到 |
|---|---|---|
| 工信部 ICP 备案查询（beian.miit.gov.cn） | 输网站域名 | 网站主办者主体是否与"机构"一致 |
| 手机官方应用商店 | 搜同款 App | 对照开发者主体、下载量、评价；**非官方渠道安装包风险极高** |
| 工信部 App 通报记录 | 搜机构名+"通报" | 是否有违规收集个人信息被通报的历史 |

## 4. 非法集资与风险名单

- 处置非法集资部际联席会议（国家金融监督管理总局官网）公告区；
- 各地地方金融监督管理局官网的"风险提示"栏目；
- 中国货币网、沪深交易所官网对非法证券活动的风险提示。

## 5. 报案与止付（钱已转出时）

| 步骤 | 动作 |
|---|---|
| 1 | 拨打 96110（全国反诈专线）或 110 |
| 2 | 联系转账所用银行/支付机构申请紧急止付、冻结 |
| 3 | 国家反诈中心 App 内举报 + 上传聊天记录/转账凭证 |
| 4 | 到属地公安机关经侦/刑侦部门报案登记 |

**行为约束**：不承诺追回、不评估追回概率、不替警方定性；只给路径并强调"越早报警止付窗口越大"。

## 6. 消费维权（课已买、费难退时）

- 全国 12315 平台（市场监管）：培训机构虚假宣传、退费纠纷；
- 中国消费者协会及地方消协：理财课陷阱专项投诉渠道（中消协 2026.4 已发布过相关提示）；
- 国家金融监督管理总局 12378 热线：被诱导"贷款买课"涉及违规放贷的金融消费者投诉。

## 时效声明

以上入口与政策依据以**当下官方公示为准**；机构名录动态变化，给用户的每次答复都应附"请以当下官方公示为准，自行查验"。
