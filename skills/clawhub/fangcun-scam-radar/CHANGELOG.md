## 1.0.2 (2026-10-30)

健壮性与发布化。

- 输入结构校验：`claims` 非 dict 从裸 Traceback 改为优雅报错并给出修正指引；输入 JSON 支持 BOM（Windows 记事本存档）
- 「信息待补」压缩为汇总一段（N 条未确认特征），不再一次甩 13 行
- 定性词黑名单补变体（应该买/该买哪个/肯定翻倍/保证追回/帮你追回）
- frontmatter 补平台必填字段（display_name/display_name_en/description_zh/description_en/version/author/license）
- tests/ 快照治理工具化（regen_snapshots.py，regenerate/verify 双模式）

## 1.0.1 (2026-10-30)

分级与事实修正。

- **修复**：监管禁区特征（虚拟币/外汇保证金/出金缴费）单命中即"高度存疑"——原逻辑权重 3 仍落入"存疑"，与 SKILL「命中即高度存疑」不符（实测确认的 bug）
- `withdraw_fee` 维度从"资金去向"（权重 2）改归"监管禁区"（权重 3），与 SKILL 文字一致
- 官方入口更新：银保监会 → 国家金融监督管理总局（SKILL Step3 表、对话流三、check_entrances §6/dialog_flows）
- tests/ 全部快照按当前脚本重新生成（原基线跨多代脚本，新旧混杂已统一）

## 1.0.0 (2026-10-29)

首发版本。

- 核心功能：五特征+监管禁区自检（持牌/收益表述/流程/资金去向/收费模式 + 虚拟币/外汇保证金/出金缴费三条监管红线，权重最高）
- 输入：case.json / --scenario 四场景预设（荐股群/低价课/陌生App/保障当理财卖）/ --demo
- 输出：核对分级（低风险/存疑/高度存疑——是核对结果非定性）+ 官方查验路径 + 报案止付路径
- 对话式十问剧本（references/interview.md）：人话提问 + 高危即时响应（钱已转出/逼单/要求隔离家人→立即给 96110 路径）
- 铁律：绝不输出"是骗局"类定性（内置定性词黑名单，命中拒绝输出）
