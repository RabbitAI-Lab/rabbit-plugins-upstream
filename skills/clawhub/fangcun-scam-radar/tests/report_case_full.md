## 命中特征（按你口述的事实）

- **承诺保本/稳赚/固定收益**（维度：收益表述）
  - 核对/查验：常识核对：收益与风险成正比是基本规律，「保本+高收益」本身是矛盾表述。正规机构从不承诺收益。
- **宣称收益显著高于常规水平**（维度：收益表述）
  - 核对/查验：对照常识：宣称收益越高，风险与可疑度越高，请核对产品底层是什么、在哪监管。
- **晒他人收益截图诱导**（维度：收益表述）
  - 核对/查验：常识核对：收益截图可任意伪造，不构成任何资质或业绩证明。
- **资质证明含糊/拒绝/称海外牌照**（维度：持牌）
  - 核对/查验：官方查验：证监会官网「监管对象」公示、中国证券业协会/基金业协会官网查询机构名。查无即无资质。
- **不做风险测评直接带买**（维度：流程）
  - 核对/查验：正规开户流程必须先做风险测评；跳过测评属违规展业信号。
- **要求转入个人账户/不明App充值**（维度：资金去向）
  - 核对/查验：正规投资资金走银行第三方存管、进自己名下账户。要求转个人账户的，立即停止。
- **资金无第三方存管**（维度：资金去向）
  - 核对/查验：官方查验：向你的开户银行核实是否存在对应存管协议。
- **制造紧迫感（名额有限/过时不候）**（维度：流程）
  - 核对/查验：常识核对：正规产品不会用倒计时逼单。紧迫感是防你冷静核实的常用手法。

## 标准查验流程（无论命中多少，建议都走一遍）

1. **查持牌**：证监会官网「监管对象」公示 / 中国证券业协会 / 中国证券投资基金业协会官网，搜机构全名。
2. **查投顾资质**：基金业协会「基金投顾机构名录」——名录外任何「智能投顾/老师带单」均无资质。
3. **查 App 来源**：只从官方应用商店下载；工信部 ICP 备案查询核对网站主体。
4. **核对资金路径**：确认资金走银行第三方存管、进入自己名下账户；任何「转给个人/充值到陌生App」都应停止。
