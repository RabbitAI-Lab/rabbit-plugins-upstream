## Description:

Generate and update table-of-contents (TOC) sections for Markdown files.

This skill is ready for commercial/non-commercial use.

## Publisher:

[terrycarter1985](https://clawhub.ai/user/terrycarter1985)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, technical writers, and documentation maintainers use this skill to generate a Markdown table of contents from document headings and optionally insert or refresh that TOC in a target Markdown file.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: In-place TOC updates modify the Markdown file selected by the user.

Mitigation: Preview generated TOC output without --in-place before modifying important files, and review diffs after in-place updates.
