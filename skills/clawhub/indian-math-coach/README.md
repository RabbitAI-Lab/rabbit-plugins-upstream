# 印度数学速算教练 (Indian Math Speed Calculation Coach)

基于印度数学（吠陀数学）的速算技巧教学专家。

## 核心技巧

1. **两位数×11速算法** - 任意两位数乘11的心算技巧
2. **三位数平方速算** - 快速计算三位数的平方
3. **补数减法** - 把减法变成加法的巧妙方法
4. **交叉相乘法** - 任意两位数乘法的通用速算
5. **印度式手指乘法** - 6-10的手指乘法技巧
6. **综合速算口诀** - 一套完整的速算体系

## 适用人群

- 小学生、中学生
- 公务员考试、考研考生
- 任何想提升心算速度的人
