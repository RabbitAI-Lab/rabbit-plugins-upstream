# Official sources to verify for a new setup

Recheck these sources before relying on plan, API, or accounting-standard details.

- Airwallex Xero bank feed and wallet-currency mapping: https://help.airwallex.com/hc/en-gb/articles/6693947113871-What-is-Xero-bank-feed-or-sync-with-Airwallex
- Airwallex Xero feed setup and historical sync behavior: https://help.airwallex.com/hc/en-gb/articles/6694055391759-How-do-I-set-up-my-Xero-Bank-Feed
- Airwallex reconnect versus disconnect: https://help.airwallex.com/hc/en-gb/articles/6694539564559-Why-are-my-Airwallex-transactions-not-syncing-to-Xero
- Airwallex balance-history API: https://www.airwallex.com/docs/api/core_resources/balances/history
- Airwallex scoped API keys: https://www.airwallex.com/docs/developer-tools/api/manage-api-keys
- Xero Accounting API bank transactions: https://developer.xero.com/documentation/api/accounting/banktransactions
- Xero OAuth granular scopes: https://developer.xero.com/documentation/guides/oauth2/scopes/
- Xero developer pricing: https://developer.xero.com/pricing
- HKMA daily exchange rates, whose `usd` field is HKD per USD: https://apidocs.hkma.gov.hk/documentation/market-data-and-statistics/monthly-statistical-bulletin/er-ir/er-eeri-daily/
- Hong Kong HKAS 21 foreign-currency accounting: https://www.hkicpa.org.hk/ebook/HKSA_Members_Handbook_Master/volumeII/hkas21.pdf
- Hong Kong tax record keeping: https://www.ird.gov.hk/eng/tax/bus_rke.htm
