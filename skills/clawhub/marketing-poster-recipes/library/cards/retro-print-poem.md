# retro-print-poem · 诗意复古印刷海报

> 输入类型：**图生图（必须用户上传照片）**｜引擎：ImageGen｜稳定性：**中**（竖图可能被转横版——验收必查画幅）
> 配方来源：基于公开的"诗意复古印刷海报"创作思路整理重构，非直接照搬任何单一第三方 prompt

## 适用场景

要高级感、诗意、杂志编辑风——大字衬线 + 半调网点 + 英文诗句。适合花/食物/人像等有向上延伸空间的主体。

## 输入要求

- **用户照片 1 张**（主体需有辨识度、适合向上延伸——花枝/食物/人物均可）
- 主体选择原则：先观察照片，选最有辨识度者；保留关键场景、视角、姿态，不随意增添物体

## 生成 Prompt（原文照录，与用户照片一起投喂）

```text
请将我上传的照片制作成一张 3:4 竖版诗意复古印刷海报。先观察照片，选择最有辨识度、适合向上延伸的主体，保留原照片的关键场景、视角、姿态和主体关系，不随意增添物体。
【排版与大字】上方约三分之一为干净暖白纸色留白，放置两段与照片情绪呼应的简短英文诗句，用克制的小号打字机字体；中部根据主题选定一个简短英文情感词（如 SWEET / HUSH / FREE / ZEST / DRIFT，选情绪词不选名词，不要用 FLAVOR、PRESENTS 这类中性词），以横跨画面的巨大高对比衬线大写字呈现。
【核心特征·必须实现】真实摄影主体必须从下方原场景自然向上延伸，真正穿过大字的笔画之间、遮挡住部分字母笔画，并越过字顶进入上方留白——这是本海报最重要的视觉特征，绝对不能做成"文字带在上、照片在下"的上下拼接。主体与原场景保持连接、比例正常，优先调整文字位置和取景让主体压在大字之上，不要拉长头颈、扭曲身体或制造漂浮物；遮挡适量，保持单词清晰可读，整张海报应是连续画面。
【衔接与配色】利用主体轮廓、光线、背景色与网点疏密，让照片在字间及主体周围自然衔接留白，避免上下矩形拼接、笔直横切边、抠图白边和生硬渐变。大字颜色从照片的花瓣、果实、枝叶、墙面、羽毛或水色中提取，与主色协调且保持可读对比，不固定使用蓝色；小诗和细节标记采用同色系深色，依据原图强化光色情绪，同时保留照片辨识度。
【印刷网点】在大字与风格化照片内部加入细密、清晰可见的圆形彩色印刷网点，青、洋红、黄等墨点可轻微错位，暗密亮疏。整体像复古杂志的彩色半调印刷，而非普通噪点或划痕；主体仍保持真实摄影材质，上方暖白相对干净。
【缩略图与克制】右上角放一张宽约占画面 15%–18% 的原始照片缩略图，完整展示原图、保持比例、不裁切、不调色，配细边框及准确的 "ORIGINAL" 标注，置于诗句与主体之外的留白处。整体克制、诗意，英文准确，无额外标题、新增水印或无关装饰；只输出一张完整海报，不要拼图或样机。
```

## 大字单词怎么选（Day2 实测规律）

从照片主题提炼一个简短英文情感词：木槿花→HUSH、水面鸭群→DRIFT、抱花跃起→FREE、柑橘→ZEST、甜点→SWEET。**选情感词不选名词**，与诗句情绪呼应。

> **2026-11-26 实测补充**：混元引擎自行选词会偏离规律（曾选 FLAVOR / PRESENTS 这类中性词或名词）。**求稳时直接在 prompt 里显式指定单词**（如「大字单词用 SWEET」），不交给引擎自选。本卡 prompt 已内置情感词候选清单与"不用中性词"约束，但仍建议在填槽时主动指定。

## 坑与备注（来自 Day2 逐字稿实测 + 2026-11-25/26 混元实测）

- **竖图可能被转成横版**：验收第一步先查画幅 3:4 竖版，错了重生成（混元实测：显式指定竖版尺寸时 1/1 稳定）
- **主体识别能力强**（能认出甜品并生成主题），可放心交给模板自动选词
- 单词被主体遮挡是设计特征不是缺陷（保持可读即可）
- **【核心坑·2026-11-26 实测可复现 → 已修复】主体不穿字是混元引擎的稳定失败点，不是偶发**：甜点盘始终留在大字下方、未向上延伸遮挡笔画，且照片区与大字区出现水平硬分界（上下拼接）。已将「必须穿字遮挡」改写为 prompt 内强制前置指令，**改后实测成功**（JOY 穿字 + 遮挡笔画达成）；验收仍须重点检查，若仍失败重试至多 2 次
- **【2026-11-25/26 实测 → 已修复】选词偏离情感词规律**（引擎选了 FLAVOR / PRESENTS）。已内置候选词 + 禁用中性词约束，改后实测选 JOY（情感词）；最稳做法是填槽时显式指定单词
- **引擎水印在右下角**（混元/豆包同款）：成品交付前提醒用户去水印，或排版留白时预留出右下角区域
