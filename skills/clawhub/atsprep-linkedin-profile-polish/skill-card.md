## Description:

Check and improve a LinkedIn headline and About section with ATSPrep's rules - score what's there, explain the issues, and write keyword-rich headline options from the user's real role and skills. Use when someone asks to improve, rewrite or review their LinkedIn headline, summary, About section or profile.

This skill is ready for commercial/non-commercial use.

## Use Case:

People preparing for a job search use this skill to review their LinkedIn headline and About section, understand issues, and draft clearer profile copy grounded in their actual role, skills, and results.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Profile text submitted for checks or writing suggestions is sent to ATSPrep; some optional ATSPrep tools also send text to an AI service.

Mitigation: Share only text the user wants ATSPrep to process, and notify them before using optional AI tools.

Risk: The bundled script supports an endpoint override, and file-based input can leave temporary text on disk.

Mitigation: Check any endpoint override and delete temporary input files after use.
