# 报告字段与呈现规则

## 逐行结果

以预算原始顺序呈现：

| 字段 | 要求 |
|---|---|
| 工作表/行号 | 可回到原文件定位 |
| 原预算项目 | 保留原文，不静默改名 |
| 原始金额 | 保留币种及含税口径 |
| 异常状态 | 已确认异常 / 高度疑似 / 待核异常 / 潜在漏项 |
| 可能异常 | 一条记录只描述一个可处理问题 |
| 异常类型 | 计算、重复、规格、数量、期间、单位、单价、性质、归属、地区/场馆、税费、加成、合规、验收、漏项等 |
| 涉及金额 | 精确值、上限、区间或“待核” |
| 判断依据 | 预算内关系、附件、合同、场馆规则、历史数据或可比询价 |
| 需要补充 | 精确到该行所需材料 |
| 建议处理 | 核减、拆分、重算、转押金、按实结算、补规格、补询价、暂缓支付等 |

同一行有多个异常时拆成多条记录，并重复行号。不要把规格、重复和税费问题揉成一段。

## 无异常行

若用户要求全表逐行审核，保留无异常行并写：“当前材料下未发现明确异常；不代表已验证价格公允。”若只要求问题清单，可隐藏无异常行，但说明审核覆盖的总行数。

## 金额标签

- **可直接核减**：已有充分证据，且不影响已确认范围；
- **暂缓支付**：需取得验收或第三方凭证后支付；
- **待核金额**：该行全部或部分金额尚不能验证；
- **潜在增项**：预算可能漏项，标注计算口径或无法量化；
- **押金/现金占用**：可退往来款，不列作最终成本。

多个异常指向同一金额时不得重复汇总。先建立“行号—金额影响”去重关系，再计算汇总。

## 汇总顺序

1. 已确认异常清单及可直接核减金额；
2. 高度疑似和待核项目及涉及金额；
3. 潜在漏项和增项风险；
4. 可退押金及现金占用；
5. 按优先级排列的补件清单；
6. 不能由现有材料判断的事项。

不要输出供应商总分、预算健康分或红黄绿综合评级。风险优先级可用于安排补件和谈判，但不能伪装成事实结论。

## 措辞

使用可复核措辞，例如：“第22行注明含运输，第35行再次列运输，存在范围重叠，需核对原始设备报价。”或“未提供型号、租期和点位，当前无法判断单价是否合理。”

避免“肯定有水分”“行业价就是”“供应商故意虚报”，以及在证据不足时写“应直接删除”。
