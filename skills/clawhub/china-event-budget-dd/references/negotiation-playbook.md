# 一线砍价方法

当用户明确要求压价、市场比价、谈判话术或给出成交红线时读取本文件。不要将审核中的“待核”自动改写为“应删除”。

## 十二个一线动作

1. **先锁硬约束**：先写清安全、消防、场馆、已确认尺寸与核心视觉，不以减配开价。
2. **把碎项并回总包**：同一交付物的材料、基层、人工、安装和管理不得分别吃满。
3. **按工程量复算**：把“项”转换为平方米、米、根、串、人天、车次或点位。
4. **先拆交叉项**：追问谁完成、共用哪批人员或车辆；只删重复边界，不留责任真空。
5. **现成品替代定制**：非核心视觉优先租赁、库存、电商或标准件，只为必要改制付费。
6. **视觉件锁样板**：先确认点位、密度、远观效果、样板和验收照片，再谈包价。
7. **人员按人天核销**：拆成岗位×人数×班次/天数×单价，以实名名单、排班和签到结算。
8. **官方费只认票据**：电箱、审图、证件和场馆管理费只按官方价目和原始账单恢复。
9. **先证明必要性**：差旅、备用金、特殊设备及临时人员先列触发条件和审批路径。
10. **用第一口和红线双价**：第一口负责锚定；红线是内部上限，只在对方补齐证据后放开。
11. **把增项口封死**：写清含税、运输、安装、拆除、等待、损耗、高空和夜间条件及除外项。
12. **让步要交换条件**：每次涨价都要换回清单、样板、凭证、账期、质保或不增项承诺。

## 逐项谈判字段

| 字段 | 要求 |
|---|---|
| 原报价 | 保留原币种、含税口径及行号 |
| 第一口 | 可以向供应商报出的谈判锚点 |
| 成交红线 | 内部可接受上限，不对外显示 |
| 一线动作 | 合包 / 工程量复算 / 去重 / 替代 / 按实 / 凭据 / 封口 |
| 必须核验 | 为该行解锁红线的具体证据 |
| 现场约束 | 不得为压价而破坏的安全、合规或效果底线 |
| 谈判话术 | 可直接发给供应商，包含价格、条件和增项边界 |

## 报价原则

- 可以用低位市场锚点作为第一口，但要标明城市、日期、规格和服务口径。
- 成交红线要为硬约束、价格波动及合理供应商利润预留空间。
- 用户已确认的现场条件优先于经验推测；不要为完成压价目标而否定硬约束。
- 客观存在的工作不直接删除；可通过去重、改变执行方、按实结算或降低非必要规格压价。
- 审图、电箱、证件、保险等官方或第三方费用，优先凭票据按实结算，不使用一般市场均价强压。
