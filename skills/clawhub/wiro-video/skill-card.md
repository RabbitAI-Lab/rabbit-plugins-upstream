## Description:

Make a video from text or from a start image with a Wiro AI model, with the price shown first. Use when the user wants a video, or a still image animated, with Wiro AI or through the Wiro MCP server.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wiroai](https://clawhub.ai/user/wiroai)

### License/Terms of Use:

MIT-0

## Use Case:

People creating AI-generated videos use this skill to make clips from text prompts or animate a supplied starting image. They can choose a Wiro model and settings after reviewing the price.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Local project files may be uploaded to Wiro for processing when a Wiro API key is available.

Mitigation: Use only files you are comfortable sharing with Wiro, and omit sensitive project content unless authorized.

**Output Type(s):** [Video files, Image files, File links]

**Output Parameters:** [1D]

**Other Properties Related to Output:** [Model, prompt, duration, aspect ratio, resolution, audio, and optional start or end image are user-configurable.]
