# 认知负荷评估师（Cognitive Load Auditor）

## 一句话简介
基于人因工程学经典理论（希克定律、米勒定律），快速评估界面认知负荷，生成结构化优化报告。

## 详细说明
认知负荷评估师是一个专为产品经理、UX 设计师和学生打造的 AI 技能。您只需描述您要评估的界面（APP、网页、表单等），该技能便会自动引导您提供关键信息，然后从 8 个核心维度逐项检查，并结合量化指标，给出综合评级与优先级明确的改进建议。

该技能将抽象的认知心理学理论转化为可操作的检查清单，帮助您在设计早期发现可能导致用户困惑、错误或放弃的问题。

## 功能特点
- 🔍 **8 维评估体系**：涵盖单一焦点、信息组块、视觉分组、视觉层级、单次聚焦、最小选择、工作记忆、渐进呈现。
- 📊 **量化指标辅助**：自动计算信息密度、决策点数量、预估操作步数，并与理论阈值对比。
- 📈 **综合评级**：根据不通过项数给出低/中/高认知负荷评级，直观反映问题严重性。
- 📝 **结构化报告**：输出包含总览、逐项详情、改进建议（紧急/建议）和理论依据的完整 Markdown 报告。
- 🔧 **灵活可调**：评估阈值可根据具体场景调整，适应不同复杂度需求。

## 使用方法
1. 在 ClawHub 中启动该技能（或直接对话触发）。
2. 当您说出“评估认知负荷”、“这个界面复杂吗”、“分析表单设计”等关键词时，技能会自动启动。
3. 按照技能的提示，提供界面类型、核心任务和界面描述（文字即可）。
4. 技能将自动完成评估并生成报告。

```markdown
# 认知负荷评估报告
