## Description:

Evaluates interface cognitive load using Hick's Law, Miller's Law, and an eight-point UX checklist, then produces a structured optimization report.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zxw-wwwww](https://clawhub.ai/user/zxw-wwwww)

### License/Terms of Use:

MIT-0

## Use Case:

Product managers, UX designers, and students use this skill to assess whether an app, web page, form, or admin interface asks users to process too much information or make too many decisions. The skill turns interface descriptions into a concise cognitive-load rating, supporting metrics, and prioritized improvement recommendations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may provide private product screenshots or sensitive interface details for evaluation.

Mitigation: Share only interface details intended for UX review, and avoid submitting confidential screenshots or proprietary flows unless they are approved for analysis.
