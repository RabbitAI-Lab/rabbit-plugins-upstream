## Description:

基于希克定律与米勒定律，系统性评估界面认知负荷，输出结构化评分与优化报告。

This skill is ready for commercial/non-commercial use.

## Use Case:

Product managers, UX designers, and students use this skill to assess app, web, backend, or form interfaces for cognitive load. It guides the user through collecting interface context, scores eight usability dimensions, and returns prioritized improvement guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generic questions about whether an interface is complex may trigger the structured audit flow when the user expected ordinary discussion.

Mitigation: Confirm whether the user wants a cognitive-load audit before collecting interface details and generating the structured report.
