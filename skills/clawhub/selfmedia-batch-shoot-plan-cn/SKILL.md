# 批量拍摄排期单

把已确定的内容变成可直接带到现场的拍摄排期。输入必须是已有脚本和实际拍摄条件；本 Skill 不补写剧情、不创造分镜。

## 输入

提供以下信息，可用表格、清单或 JSON：

- 每条脚本的编号、标题、场景、人物、动作/台词摘要；可附成片计划时长（不是现场拍摄耗时）
- 已知场地、道具和服装；场地可拍时段与人物可用时段为可选信息，缺失时只影响钟点排期，不是必填失败
- 已确定机位；若未给，标记为“待定”，不擅自设计镜头
- 可选：拍摄日期、设备限制、素材项目代号

每次最多处理 100 行脚本/场景记录。超过时按批次编号拆分后再提交。

## 工作方法

1. 核对必要字段：脚本编号、场景、人物、动作/台词摘要；缺其中任何一项先列缺项，不编脚本。场地映射未给标“待确认”、机位未给标“待定”，不擅自创造现场或镜头；仍可按已知场景给非钟点预排顺序。
2. 以“场地 → 场景布置 → 机位 → 出镜人物”排序，优先减少换景、挪机位与道具搬运。
3. 为每个拍摄单元输出场次顺序、所需人物/道具、机位状态、成片计划时长原值和现场拍摄耗时。成片计划时长不能当拍摄耗时；布置、排练、单条拍摄、重拍与转场耗时缺乏依据时全部标“待确认”，不得相加成钟点日程。只有这些耗时和场地/人物可用时段均明确时才排开始结束时间；否则只给非钟点顺序。
4. 生成唯一、可检索的素材命名表；默认格式为 `项目_日期_场景_机位_脚本号_条次`。

## 交付格式

先列出“资料核对”。资料齐全时交付两张 Markdown 表：

1. **拍摄顺序表**：序号、场地/布置、机位、脚本号、人物、道具、成片计划时长、实际拍摄耗时、现场备注。
2. **素材命名表**：脚本号、场景、机位、条次规则、文件名示例、对应拍摄序号。

核心字段不全时改为“缺项清单 + 可继续整理的已确认项”。仅缺时段、场地映射、机位、成片时长或现场耗时等细项时，标待确认并可先给非钟点顺序，不报必填失败、不声称现场排期已可执行。

## 质量边界

- 同一场景、布置和机位相邻安排；人物档期冲突必须标红说明而非强行排入。
- 保留用户脚本编号与术语，不改剧情。
- 文件名只使用字母、数字、短横线或下划线，避免空格和重复。
