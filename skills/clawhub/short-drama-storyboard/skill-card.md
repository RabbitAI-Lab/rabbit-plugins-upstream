## Description:

把中文短剧剧本和视觉设定写成有戏剧职责、连续性边界与冻结关键帧提示词的分镜 Markdown。用户提出“拆分镜/设计镜头/做镜头表”“场次视觉计划/调度故事板”“比较导演方案”“写首帧/关键帧提示词”或检查轴线、站位、视线、持物连续性时使用；不生成媒体。

This skill is ready for commercial/non-commercial use.

## Use Case:

编剧、导演和分镜创作者可用它把已接受的短剧剧本与视觉设定转成逐镜分镜和可冻结关键帧提示词，并核对覆盖、调度与连续性。

### Deployment Geography for Use:

Global

Mitigation: Review those tools before running them.
