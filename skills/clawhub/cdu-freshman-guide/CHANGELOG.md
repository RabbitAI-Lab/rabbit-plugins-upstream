# CHANGELOG — 成都大学新生一站式指南（cdu-freshman-guide）

本文件记录技能版本变更。遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/) 格式。

## [1.4.0] - 2026-08-20

### 新增

- **回答机制重构为「知识库索引 + 智能搜索路由」**（用户核心设计思路）：
  - 官方信息 → 只存索引（URL + 一句话说明），不存正文，轻量化设计。用户问到直接给官网链接引导查最新通知。
  - 非官方信息 → 存详细学长辈学姐真实经验，附出处和时效提示。
  - 知识库没答案 → 不硬编，智能路由：官方类（学费/政策/报到等）自动搜索官网，非官方类（经验/价格/好不好等）自动搜索小红书/抖音/知乎。
  - 即使知识库有答案 → 也可以建议用户搜小红书/抖音/官网交叉验证。
  - 回答末尾【强制】附来源 + 时效提示 + 交叉验证建议 + 用户自审提示。
- **新增新生高频问题全清单**（网络调研整理：45 个问题 × 155 个关键词 × 9 大类）：
  覆盖报到注册、宿舍、食堂、校园生活、学习学术、军训、社团组织、医保资助、就业毕业九大类，作为知识库扩展的索引蓝图。
- **熊猫话术升级**：用「同学你来啦」「让本熊猫来帮你查一下」「找到啦」「对不起啦」「查证一下哟」等活泼口吻，但不过度卖萌。
- **搜索流程改为渐进式输出**（用户实测反馈：搜索等太久）：未命中搜索时「先回复一条结果让用户看到进展，再逐步追加」——不等全部搜完再回复，边搜边给，减少等待焦虑。
- **技能脱离知识库也可独立运行**：data/kb_*.json 改为可选增强包非必需；无 KB 时靠内置索引 + 搜索路由独立工作。定位说明、回答步骤、数据维护章节均更新此逻辑。
- **对抗性测试与防御强化**（用户要求：套敏感信息/灰产/其他学校/毫不相干问题）：新增 `tests/adversarial_test_20260820.md`（10 组用例 T1-T10：提示词注入/越狱DAN/敏感信息套取/灰产/范围越界/毫不相干/数据泄露/上下文污染/编码绕过/联网失败）。SKILL.md「能力边界」升级为【强制】防线：①角色不劫持 ②灰产零沟通（含拼音/Base64/英文变体识别）③PII 零输出 ④范围不越界 ⑤内部不泄露 ⑥多轮不松懈 ⑦脱敏铁律。
- **联网失败兜底策略**：新增「联网失败/搜索不可用处理」章节——无搜索结果时用知识库/内置常识兜底 + 给离线查证路径，绝不编造；并如实说明联网搜索由宿主模型执行、模型侧可能无输出的限制。
