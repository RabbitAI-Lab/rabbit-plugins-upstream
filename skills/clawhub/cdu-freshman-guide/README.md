# 成都大学新生一站式指南（cdu-freshman-guide）

> 🐼 熊猫向导，带你消除信息差。

一个为成都大学新生打造的 AI 技能：**数据来源于 11 个真实 QQ 互助群、24 万+ 条群聊大数据**（脱敏后人工策展），把散落在群里、只有混群蹲消息才能拿到的学长学姐踩坑经验，变成随问随答的一站式指南。选课、走读、宿舍规则、医保资助、租房、就业……不混群，也能拿到真实沉淀的经验。

## 数据亮点：真实群聊大数据 × 人工策展

- 📊 **24 万+ 条群聊原始数据**，覆盖 11 个成都大学互助群（专业大群、班级群、新生群、十栋宿舍群、租房互助等）。
- 🧠 **不靠"猜"，靠真实经验**：每一版答案都来自学长学姐实际踩坑后、在群里真实沉淀的对话，混群蹲几个月才能攒下的经验，装进这一个技能。
- ✂️ **脱敏 + 人工策展**：个人身份信息全部掩码；从海量原文里人工提炼出 **99 条 FAQ + 10 流程 + 15 地点 + 13 通知 + 26 官方渠道**，只留精华、不留噪音。
- 📕 **官方制度补充**：参考《成都大学学生手册（2021 版）》，把转专业、综测构成、住宿用电/门禁/调宿/走读、困难认定、勤工助学、借阅证等官方制度提炼入问答，全部标注出处并提示「以最新规定为准」。
- 🏛️ **官方渠道联网核实**：关键 URL 逐条联网验证，并纳入问答标注出处。

## 它解决什么问题？

新生最怕的不是"不知道"，而是"不知道去哪知道"：

- 选课什么时候开始？错过了怎么办？
- 走读怎么办理？要准备什么材料？
- 宿舍几点关门？晚归会怎样？
- 医保怎么报销？助学金什么时候发？
- 学校附近租房什么价位？有什么坑？
- 四六级、素质学分、档案转递……官方通知去哪看？

这些经验散落在各个 QQ 群，新生不混群就不知道。**熊猫向导把它们沉淀成了结构化知识库**，随问随答。

## 快速开始

安装技能后，直接问问题即可：

```
新生什么时候选公选课？
走读怎么办理？
宿舍几点关门？
学校附近租房什么价位？
四六级什么时候报名？
```

熊猫向导回答风格活泼有温度：以「同学你来啦！让本熊猫来帮你查一下吧 → 找到啦！（答案）→ 来源与时效提示」为标准话术；没收录的问题会诚实说「对不起啦，这个问题好像没有收录」，并给出具体查证路径。**回答自动附来源链接 + 时效免责提示**：涉及报到、缴费、选课、军训、放假等会随学年变化的信息，会标注对应时点、给官方查证链接，并提示「可能有过时或偏差，去官网查证一下哟」，避免误导新生。

## 能力总览

知识库分五层，回答时逐层递进。**但知识库是可选增强包，不是技能必需项**——无 `data/kb_*.json` 文件时，熊猫向导靠内置索引 + 智能搜索路由（搜官网 / 小红书 / 抖音）仍能独立回答新生提问。知识库文件仅提供更精确的策展经验，加速命中。

| 层级 | 内容 | 示例 |
|---|---|---|
| ① 常见问答 | 高频问题 Q→A | 选课、走读、宿舍、医保、租房、就业 |
| ② 办事流程 | 步骤+材料+地点+时间 | 走读、四六级、素质学分、晚归登记 |
| ③ 地点导航 | 校园地点/设施 | 校医院、学工办、宿管中心、食堂 |
| ④ 重要通知 | 时效性通知摘要 | 返校时间、门禁管理、安全用电 |
| ⑤ 官方渠道 | 官网/公众号/小程序 | 教务处、学生处、就业网、文新学院公众号 |

## 如何维护知识库

1. 新群聊数据 → 运行 `python scripts/desensitize.py --input <原始目录> --output <输出目录>` 脱敏
2. 人工策展 → 在 `scripts/build_kb.py` 中补充知识条目
3. 运行 `python scripts/build_kb.py` 校验（PII 残留 + 灰色交易 + schema）并生成 JSON
4. 更新 `CHANGELOG.md` 与版本号

## 常见问题（FAQ）

**Q：这个技能是官方做的吗？**
A：不是。这是社区贡献的技能，数据来自学生互助群的真实经验（脱敏后），不代表学校官方立场。

**Q：信息会不会过时？**
A：会。群聊经验有时效性（尤其价格、套餐、通知），知识库标注了"截至 2026-08"，重要事项请以官方渠道为准。

**Q：为什么不做代课/代取？**
A：这些违反校规，可能面临处分。熊猫向导会明确拒绝并提示风险，引导走正规流程。

**Q：数据覆盖哪些学院？**
A：目前以文新学院/网新专业/10栋宿舍为主，其他学院经验可能缺失，欢迎贡献补充。
