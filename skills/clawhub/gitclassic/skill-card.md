## Description: <br>
GitClassic helps AI agents browse GitHub through a fast, no-JavaScript, read-only interface for public repositories, file contents, READMEs, search, and optional PRO private-repository access via GitHub OAuth. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, engineers, and AI agents use GitClassic to quickly read GitHub repositories, files, READMEs, documentation, and search results through clean server-rendered HTML. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Optional PRO private-repository access uses a third-party GitHub OAuth flow. <br>
Mitigation: Review GitHub OAuth scopes and GitClassic privacy, caching, and retention practices before using private repositories; use direct GitHub access for highly confidential repositories. <br>
