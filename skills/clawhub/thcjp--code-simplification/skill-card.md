## Known Risks and Mitigations:

Risk: The skill is named as a code-simplification helper but server security evidence says it describes broader development automation, file, API, credential, and command behavior.

Mitigation: Review the skill before installation and use it only when broad development automation is intended, not merely code simplification.

Risk: The skill may propose or rely on shell command execution.

Mitigation: Approve commands only when the exact command, files touched, and network or API behavior are clear; run it in a sandboxed project workspace when possible.

Risk: The artifact describes API keys or access credentials as prerequisites.

Mitigation: Do not provide API keys or other secrets unless the need is explicit and scoped; prefer least-privilege or test credentials.
