# 九三学社社情民意信息写作格式规范

## 一、格式方面

### 1. 页面设置

| 项目 | 规格 |
|------|------|
| 上边距 | 3.7cm |
| 下边距 | 3.5cm |
| 左边距 | 2.8cm |
| 右边距 | 2.6cm |

### 2. 行距设置

- 段前：0行
- 段后：0行
- 行距：固定值29磅

### 3. 标题

- 字体：方正小标宋简体
- 字号：二号
- 对齐：居中

### 4. 作者标注

- 格式："某某某（九三学社社员、社会职务）反映："
- 字体：三号黑体
- 若作者为人大代表或政协委员，该身份前置标注
- 社会职务只写主要职务，不堆砌

### 5. 正文

- 小标题：楷体，三号
- 正文主体：仿宋体，三号
- 正文字数：2500字以内

### 6. 摘要

- 位置：标题下方，正文上方
- 字数：200-300字左右
- 内容：简要介绍文章最核心内容（问题概述+建议要点）
- 摘要与正文之间空一行

## 二、内容方面

### 1. 信息分类与结构

#### 第一类：单纯反映问题

- 第一部分：存在的问题
- 第二部分：分析问题出现的原因

#### 第二类：问题+对策建议（更常用）

- 第一部分：存在的问题
- 第二部分：解决问题的建议

### 2. 问题部分写作要求

- 每个问题以"一是""二是""三是"等序号引导
- 须引用数据或案例作为佐证材料，增强可信度和说服力
- 数据或案例须注明引用来源
- 引用来源使用角标尾注形式（如[1][2]），在正文末尾列明

### 3. 建议部分写作要求

- 对应问题逐一提出建议
- 每条建议须有明确的责任主体（如"财政部""国家数据局"等）
- 须有具体操作路径和政策工具
- 避免空泛表述，力求务实可落地

### 4. 数据使用规范

- 审慎使用AI工具，避免AI"幻觉"编造数据
- 所有数据须真实可查、可溯源
- 数据来源格式：来源机构/媒体，文献标题，日期
- 如数据无法溯源，宁可不引用，不可编造

### 5. 尾注格式

正文末尾以如下格式列出所有引用来源：

```
数据及案例来源
[1] 来源机构/媒体，文献/文件标题，日期
[2] 来源机构/媒体，文献/文件标题，日期
```

## 三、语言风格

- 正式严谨，符合党政机关公文规范
- 简洁直接，避免冗余修饰
- 问题分析有理有据，建议提出务实可行
- 开篇宜采用对仗式或提炼式表述
- 各部分之间逻辑呼应，结尾凝练有力
