## 7. 《静态资产清单》模板（阶段 7，阶段 12 上传与阶段 13 回填的唯一依据）

| 老 URL | 内容 hash（SHA256，去重键） | 类型（图片:页头/产品主图/新闻缩略/内容配图/背景/字体；CSS:全局/页面；JS:公共库/交互） | 归属（页面/产品/新闻/共享） | 是否外链/老图床 | 是否需重传 | 新站相对 URL（已上传填入） | 是否已上传 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| old.com/up/a.jpg | sha256:… | 图片:产品主图 | 产品 A | 否 | 是 | /up/xxx.jpg（阶段 12 上传后回填） | 否（待上传） |
| old.com/static/common.css | sha256:… | CSS:全局 | 共享 | 否 | 是 | /css/common.css（阶段 13 上传后回填） | 否（待上传） |
| old.com/js/lib.js | sha256:… | JS:公共库 | 共享 | 否 | 是 | /js/lib.js（阶段 13 上传后回填） | 否（待上传） |

> 约束：
> - **按内容 hash 去重**：同 hash 的多份引用（缩放图 / 带 `?v=` 缓存串 / 路径别名）合并为一条，只传一次，跨页共用同一新 URL；记录全部引用点。
> - 「是否需重传」= 是 的每一**唯一 hash 项**，必须进入阶段 12（图片）/ 阶段 13（CSS/JS）的 MCP 上传队列并实际上传；上传后把返回的服务器相对 URL 填入「新站相对 URL（已上传填入）」（同 hash 所有引用行同步更新），并把「是否已上传」改为 是。
> - 阶段 13 生成页面时，用本表已上传的「新站相对 URL」替换 HTML/CSS 中的全部老站资源引用（老域名 / CDN 域名 / `old.com`，含 `img src` / `background-image` / `url()` / `<link href>` / `<script src>`），禁止页面上线后残留老站资源地址。
> - 本清单是静态资产（图片 / CSS / JS）上传与回填的**唯一依据**；产品主图按产品逐条保留、不参与跨产品合并；共享资源（logo / 全局 CSS / 公共 JS 库）全局去重、一次上传多页复用；识别阶段不得"识别完即视为完成"，未上传回填的资产不得视为已迁移。

## 12. 《301 重定向规则表》模板（阶段 15）

| 老 URL（精确/前缀） | 新 URL | 重定向类型 | 实现层（平台/服务器） | 状态 |
| --- | --- | --- | --- | --- |
| https://old.com/about.html | https://new.com/about.html | 301 精确 | 平台重定向配置 / Nginx | 待落地 |
| https://old.com/product/a.html | https://new.com/product-detail.html?id=3052188 | 301 精确 | 平台重定向配置 / Nginx | 待落地 |
| https://old.com/products/* | https://new.com/products/ | 301 前缀 | Nginx rewrite | 待落地 |

规则：
- 1:1 → 精确 301；合并 → 旧多个 URL 301 到新版块页；丢弃且无相关页 → 尽量 301 到最相关栏目，确实无相关再 410；高权重 URL 禁止 404。
- 实现层：平台支持则经建站助手确认工具落地（写前展示影响）；不支持则交付本表由运维在 Nginx/CDN 配置。

## 13. 用户交互表单定义（所有提问以表单呈现，禁止聊天框逐条追问）

> 约定：以下每个表单都用**表单 UI**呈现（文本填写框 + 单选 / 下拉 / 多选控件），用户一次填完 / 勾选提交。**绝不**让用户在聊天框里逐条回答，也**绝不**让用户把 URL / Token / 域名等直接打在聊天气泡里。表单字段用下表描述，Agent 按自身表单 / 问题 UI 能力映射（文本 → 文本框；radio → 单选；select → 下拉；checkbox → 多选）。必填项缺失或逻辑矛盾时，在表单内回显校验提示退回重填，不改用聊天追问。

### §13.5 《版权合规确认表单》（§2.1，原样迁移 / 1:1 复制模式强制门禁）

- 触发：仅当《迁移需求收集表单》`migrateMode` = 原样迁移（1:1 复制 UI）时在开工前呈现；重新设计模式建议展示但不强制门禁。
- 结构：4 项声明均为「必读 + 勾选确认」；第 1 项（权利承诺）为硬性门禁，未勾选不得进入阶段 2 抓取与阶段 13 复制生成。

| key | label | 控件 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| rightsOwner | 权利承诺 | checkbox（必读） | 是（硬性门禁） | 勾选即承诺：本人是**网页全部著作权、素材、商标的合法权利人，有权授权本工具复刻，不存在第三方版权** |
| disclaimer | 免责提示 | checkbox（必读） | 是 | 勾选即知悉：工具仅提供技术能力，**版权真实性由用户自行承担，用户承诺承担全部侵权赔偿责任** |
| outsourceContract | 外包合同提示 | radio（必读） | 是 | 选项：① 网页非外包 / 已确认著作权完整转让给我 → 可据权利承诺主张；② 网页系外包制作且**未确认转让** → 应先澄清或改走「重新设计」模式 |
| complaintFreeze | 投诉冻结授权 | checkbox（必读） | 是 | 勾选即知悉并接受：收到第三方版权投诉后，本工具将**立即冻结该站点的复制（复刻）能力**，直至权利争议澄清 |

- `outsourceContract` = ② 时：表单回退，要求用户先澄清著作权归属，或改选「重新设计」模式；不允许在「未确认转让」下据 `rightsOwner` 主张权利。
- 表单提交后：Agent 将老站 URL 记入本次迁移会话的合规确认记录；开工前（阶段 2 / 阶段 13）比对本地《版权投诉冻结清单》，命中即冻结拒绝执行。

| method | 验证方式 | radio | 是 | DNS TXT 记录验证（推荐）/ 根目录验证文件 / HTML Meta 标签；切换方式时表单重放对应放置说明 |
