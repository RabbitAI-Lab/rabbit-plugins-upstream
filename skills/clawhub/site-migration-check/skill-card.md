## Description:

Plan and verify a domain move, HTTPS switch, URL restructure, platform change, redesign or site merge without losing search traffic. Use for "site migration checklist", "redirect map", "moving to a new domain", "switching CMS", "traffic dropped after relaunch", or a pre-launch SEO go/no-go check.

This skill is ready for commercial/non-commercial use.

## Use Case:

SEO professionals, site owners, and developers use this skill to plan a site migration, map old URLs to appropriate destinations, assess launch readiness, and investigate post-launch traffic changes. It provides migration risks, go/no-go checks, monitoring steps, and rollback criteria.
