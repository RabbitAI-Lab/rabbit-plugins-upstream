# 政企行政助手（gov-entity-admin）

> 政府、企事业单位通用行政辅助技能（独立行政方向，与招投标、政府采购等专业领域无关联）。

## 简介

本技能面向政府机关、企事业单位的行政文书与流程协调场景，帮助起草、整理、跟踪、提醒各类行政文书与事务。定位为"整理、起草、跟踪、提醒"，不做决策、裁定或代行职权。

## 功能

- 正式公文：备忘 / 指令 / 函 / 通知（结构化起草）
- 会议纪要：按"议程 → 讨论 → 决议 → 行动项"整理
- 定期报告：周报 / 月报 / 季报 / 年报（先写结果再写动作）
- 会议准备：简报、立场、预判反方、待批事项
- 跨部门通信：正式语体、引用既往往来、明确行动请求
- 合规节点：申报期限、审计预备、文档留痕
- 心跳提醒：临近期限 / 逾期待办提示（无数据源时静默）

## 使用方式

- 命令行：`@skill:gov-entity-admin`
- 或直接描述行政文书任务，例如："把今天上午的协调会整理成会议纪要""给办公室发个备忘催一下材料"。

## 范围边界

**做**：通用行政文书起草、流程跟踪与提醒。

**不做（自身边界）**：
- 不做专业业务判定（如人事裁定、财务合规结论、法律意见）
- 不代签、不代发、不代章
- 不臆造文号、法条、数据；缺失信息显式标注"待补"
- 不确定时标注"需经办人确认"

> 本技能与招投标、政府采购专业栈（如 `bid-*`、`gov-procurement-*`）为零交集，互不抢触发。

## 输出规范

- 各文档类型使用对应 XML 标签包裹（`<memo>` / `<meeting_minutes>` / `<briefing>` 等）
- 空缺字段填"待补 / 待签 / 待定"，不得自行补全
- 详见 `SKILL.md` 内「文档类型与输出契约」与「少样本示例」
