## Rules
- A3 图框(GB/T 14689)：幅面 420×297mm，装订边左侧20mm、其余三边5mm；外框线(图纸边界)细实线0.25mm，内框线粗实线(建议0.7~1.0mm)；四边中点各画一条对中符号(粗实线,长5mm)。
- 标题栏(GB/T 10609.1)：180×56mm，紧贴右下角内框线；分区=更改区|签字区|名称及代号区；区域右上方放第一角投影符号(GB/T 14692)。
- 标题栏布局(用户强制)：每个标签(图名/比例/图号/日期等)后**必须接一个独立的空白内容单元格**，标签|内容相邻不同格；签字类(制图/审核)内容留空供填写。**禁止**标签后直接跟值、共用一格(用户 2026-08-03/04 明确要求, 2026-08-08 再次纠正)。
- 线型(GB/T 17450/4457.4)：统一线宽组，粗实线 d 取 1.0、细线 d/2=0.5；粗实线用于可见轮廓/内框/标题栏外框/对中符号，细实线用于尺寸线/界线/剖面线/标题栏内隔线。
- 国标尺寸标注(GB/T 4458.4)：尺寸界线细实线、末端超出尺寸线 2~3mm；尺寸线两端画实心闭合三角箭头(长约 3~5 倍线宽)；尺寸数字沿尺寸线/轴测方向书写，数字处用白底遮挡避免被线穿过；单位 mm 不标符号。
- 字体(GB/T 14691)：长仿宋；图样名称/单位用 7~10 号，序号/尺寸数字/技术要求正文/标题栏文字用 3.5~5 号；一张图最多 3 种字号。
- 比例(GB/T 14690)：优先用原值 1:1、缩小 1:2/1:5/1:10/1:20/1:50/1:100 等，填在标题栏"比例"栏。
- 技术说明放标题栏上方或右上角空白，标题"技术要求"，编号 1、2、3 逐条；图例放标题栏右侧或说明下方，用"符号/线样+文字"解释特殊符号与线型。
- CAD模板(.dwt)：用 ezdxf 生成 DXF 模板，预设图层(粗实线/细实线/虚线/细点划线/双点划线/文字/图框/标题栏并设线宽)、线型(CONTINUOUS/DASHED/CENTER/PHANTOM)、文字样式(GB_HZ长仿宋/GB_NUM直体/GB_ITA斜体15°)、标注样式(GB_DIM)；交付 .dxf，用户可在 AutoCAD 中'另存为 .dwt'当作模板。
- 工具坑点：reportlab 的 landscape(A3) 会抛 ValueError: too many values to unpack，必须改用 pagesize=(420*MM, 297*MM)，其中 MM=2.8346；等轴测投影 iso(x,y,z)=((x-y)*cos30,(x+y)*sin30+z)。
- 正式图纸一律双格式交付：PDF(查看/打印) + DXF(CAD编辑) 同时回传；文件命名带版本+日期分钟。
- 交付流程(默认)：**所有绘图任务一律走正式工程图纸流程**——按主体外接矩形选择能完整容纳的最小标准图幅(A0/A1/A2/A3/A4及加长)，再画图框 + 标题栏(图名/比例/图号) + 轴测主体 + 国标尺寸标注 + (必要时)技术要求/图例，PDF+DXF 双格式交付。纯线稿只用于绘制中途的快速预览，不允许作为正式交付。图幅不固定默认(用户 2026-08-08 修改：去A3默认，按主体选幅)。
- DXF中文字体防"方块/问号"(关键坑)：汉字样式必须用 SHX 大字体组合——`doc.styles.add(名,font="gbenor.shx"); st.dxf.bigfont="gbcbig.shx"`(ezdxf 的 styles.add() 不支持 bigfont 关键字，须先建样式再设 .dxf.bigfont)；或改用 TrueType `font="仿宋"/"simfang.ttf"`(无需大字体)。纯西文/数字用 gbenor.shx(直体)/gbeitc.shx(斜体15°)。所有含中文的实体(TEXT/MTEXT/ATTDEF/ATTRIB)必须统一指向该中文样式，禁止用默认 Standard(无 bigfont，中文必方块)。生成后务必跑字体自检脚本 check_dxf_fonts.py：遍历全部样式+块内实体，确认每个汉字样式已配 bigfont/TrueType、实体引用样式均已定义。

## Examples
- reportlab 错误示范：canvas.Canvas('x.pdf', pagesize=landscape(A3)) → 报 ValueError；正确：canvas.Canvas('x.pdf', pagesize=(420*MM, 297*MM))
- 国标尺寸线错误：界线画到尺寸线端点为止 → 报规范问题；正确：界线末端再延伸 2~3mm 超出尺寸线。
- 线型错误：全部用一种线宽 → 被指"线型层级不明显"；正确：粗实线 d=1.0 与尺寸细线 0.5 形成明显粗细对比。
- 字体错误：ATTDEF"图名内容"误用默认 Standard 样式(无 bigfont) → CAD 中图名变方块；正确：`attdef.dxf.style='GB_HZ'`(gbenor.shx 西文 + gbcbig.shx 大字体组合)；生成后用 check_dxf_fonts.py 验证汉字样式均配大字体、实体样式均已定义。

## CAD端字体方块修复手册(端到端) — 用于生成后用户在CAD中自检
- 检测：STYLE 查看标题栏文字样式的字体名(如gbenor.shx)与大字体(gbcbig.shx)；检查 CAD安装目录\Fonts 是否存在该字体；检查系统区域语言是否中文(简体,中国)。
- 安装：SHX字体(缺失时)从明经通道(mjtd.com)/晓东CAD(xdcad.net)论坛下载，复制到 CAD安装目录\Fonts；TTF(宋体/黑体)从微软下载，复制到 C:\Windows\Fonts；装后必须重启CAD。
- 替换方案：gbenor.shx 缺失→simplex.shx 或 Arial；gbcbig.shx 缺失→宋体 或 hztxt.shx。
- CAD内修复：STYLE 选中标题栏样式，字体名选 gbenor.shx + 大字体选 gbcbig.shx，点"应用"并"置为当前"；用 RECOVER 打开图纸修复内部数据。
- 系统修复(管理员CMD)：net stop FontCache → del /f /q %windir%\ServiceProfiles\LocalService\AppData\Local\FontCache* → net start FontCache；再 SFC /ScanNow 和 DISM /Online /Cleanup-Image /RestoreHealth。
- PDF导出：PUBLISH/EXPORT 选打印机 "DWG to PDF.pc3"，在"自定义特性→图形"勾"嵌入所有字体"；打印样式表选 monochrome.ctb(黑白)或 acad.ctb(彩色)。
- 输出：修复后的DWG + 修复日志(缺失字体名、下载来源、安装路径、替换字体) + 用Adobe Acrobat/浏览器打印预览验证文字清晰无方框。
- 适用：AutoCAD/中望/鸿鹄/CAXA，Windows。AI无法直接操作时，请用户提供 STYLE 截图 + Fonts文件夹列表 + CAD版本号。

## AI绘图输入规范提示词(整合修正版) — 用于引导完整绘图流程
【任务】按用户设计需求绘制CAD图纸：先 1:1 画主体(mm)，再按主体外接矩形选标准图幅与比例，最后加图框/标题栏/图例/说明。
【绘制规则】
1 主体：严格 1:1，单位统一 mm；"主体"=零/部件/建筑实体本身，排除辅助线、尺寸标注、图框。画完测量外接矩形(长×宽)作为选幅依据。
1b 主体定义细化：按图纸类型界定主体——机械件=零件外形/孔/螺纹/倒角/圆角/键槽等结构特征；装配图=装配件组合体含配合/连接方式；建筑平面=墙/柱/门门窗/楼梯/阳台等；立面=外轮廓/门窗/装饰线条/檐口等；剖面=被剖墙体/楼板/梁柱/基础+可见立面；电路原理=元器件及导线；给排水=管道走向/管件/用水设备；暖通=风管水管/设备/风口。主体绘制规则：1:1且单位mm、坐标原点取主体左下角或中心(0,0)、主体放独立"主体"图层(白7号色/Continuous/线宽机械0.35建筑0.5)、先轮廓后内部细节再倒角圆角、必须封闭、不得遗漏内部细节。外部矩形 Lx×Ly 用 DIST/LIST 测，圆形=直径正方形，不规则取最小外接矩形。排除元素：尺寸/公差/粗糙度/基准/剖切/中心线/剖面线/引线/序号明细/标题栏图框/技术要求/图例/指北针/比例尺/版本。常见错误：辅助元素混图层、主体非1:1、轮廓不封闭、遗漏细节、单位不一致。
1c 单位统一：默认长度 mm、角度 度(°)、精度长2位/角1位。换算：1m=1000mm、1cm=10mm、1in=25.4mm、1ft=304.8mm、1yd=914.4mm、市制里/丈/尺/寸=500000/3333.3/333.3/33.3mm。CAD单位设置 UNITS：长度小数、精度0.00、角度十进制度、角度精度0.0、插入比例毫米、方向东0°逆时针正。DIMSTYLE 主单位=小数/精度0.00/小数分隔符句点，换算单位乘数按需(英转公25.4)。常见错误：米当毫米(12m→12000mm)、混用厘米毫米、导入英制未 SCALE 25.4、标注精度不一、弧度当度。检查：DIST 验证已知尺寸、LIST 看坐标、UNITS 看单位、INSERT 已知尺寸块(A4图框297×210)验证。特殊场景：米制图仍以mm画但标注加m后缀；英制先mm画后 SCALE 1/25.4 并在标题栏注明；草图单位不明先问用户不得自假设；不同精度统一按最高(0.1mm)画。输出：标题栏标"单位：mm"，含换算单位需在说明注明换算关系。
1d 图层管理：命名规范(≤20字符，英/拼)：主体PART/ZT、图框BORDER/TK、标题栏TITLE/BTL、图例LEGEND/TL、说明NOTE/SM、标注DIM/BZ、中心线CENTER/ZXX、剖面线HATCH/PMX、虚线HIDDEN/XX、文字TEXT/WZ、尺寸线DIMLINE/CCX、填充FILL/TC、参考线REF/CKX、图块BLOCK/TK。颜色：主体白7/图框红1/标题栏黄2/图例青4/说明绿3/标注蓝5/中心线红或洋红6/剖面线灰8/虚线洋红或蓝/填充灰8/参考线灰9/图块随块。线型：主体图框标题栏图例说明标注剖面线文字尺寸线填充=Continuous、中心线=CENTER、虚线=HIDDEN、参考线=DASHED或DASHDOT、图块随层；LTSCALE=图纸比例倒数×10。线宽(按方案A国标)：图框外框(纸边)=0.25细、图框内框=0.7±粗、标题栏/图例=0.25、主体=0.35机械/0.50建筑、说明标注中心线剖面线虚线文字尺寸线填充=0.18、参考线=0.13、图块随层。管理：每层只放一种元素、绘制时冻结/关闭不需层、完成锁定防误改、按功能排序、PURGE清空层、优先企业标准。错误：全放0层/命名混乱/属性不一致/未冻结锁定/图层过多过少。输出：图层设置表(名称/颜色/线型/线宽)+确认元素正确分配+图层管理器截图。颜色注意事项：避免鲜艳/刺眼色、避免与背景色相近、黑白打印时应确保不同颜色打印后灰度有区别。
1d2 打印样式与图层状态控制：打印样式分 CTB(颜色相关，基于颜色映射：如1号红→黑、线宽映射、淡显) 和 STB(命名样式，基于图层名，适用大型/协作)。建议：黑白打印全映射黑+按层线宽；彩色保留原色；参考线/填充可淡显50~80%。图层状态：开/关(LAYOFF/关=不可见不可编不可打印/临时隐藏)、冻结/解冻(不参与重生成/长期不用/当前层不可冻结)、锁定/解锁(LAYLCK/可见不可编/保护已完)、打印/不打印(参考线辅助线不打印)。图层过滤器：名称/颜色/线型/状态/组过滤器用于快速筛选管理。
1d3 图层工具与标准：常用工具 LAYER(LA)管理器新建/删除/重命名/置当前；LAYERTOOLS 系列：LAYISO隔离/LAYUNISO恢复/LAYOFF关/LAYON开/LAYFRZ冻结/LAYTHW解冻/LAYLCK锁/LAYULK解锁/LAYCUR置当前/LAYMRG合并/LAYDEL删除带对象层；LAYMCUR匹配为当前层；LAYWALK漫游(动态显示选定层)。转换：LAYTRANS图层转换器(映射标准层，接收外部图纸统一标准)、LAYERSTATE图层状态管理器(保存/恢复开冻结锁等)、LAYMRG合并(源层对象移目标层后删源层，不可撤销)。标准：GB/T 50001-2017 命名"专业代码-图层内容-图层属性"(如A-WALL建筑墙、S-COLU结构柱)、颜色按专业统一；企业标准=统一规则+DWT样板+定期清理；ISO 13567 命名"专业-内容-属性-状态"(如A-WALL-PART)。技巧：图层组/过滤器/DWT样板起步/PURGE清理。常见问题：图层删不掉(含对象/当前层/被参照→删对象、切当前层、清参照)、显示异常(关冻结/颜色线型错/范围→查状态、重置、REGEN重生成)、打印不显示(设不打印/样式错/线宽细→查打印、调样式、增线宽)。
1e 图幅选择与比例确定：标准横向图幅 GB/T 14689：A0=1189×841、A1=841×594、A2=594×420、A3=420×297、A4=297×210；加长幅面(A3×3/×4、A4×3/×4)用于细长形。选择原则：能完整容纳主体+全部辅元素并留边距；优先标准图幅，容纳不了再加长；不宜过大过小；考虑打印设备最大幅面。选择步骤：1) 测 Lx×Ly;2) 所需最小宽度=Lx+左右边距(如40)+标题栏占用(180), 高度=Ly+上下边距(30)+标题栏(50);3) 与标准图幅比选能容纳的最小者;4) 不够选加长幅。比例=图幅/主体外接矩形(取较小值后向下归到标准比例 1:1/1:2/1:5/1:10/1:50/1:100/1:200/1:500/1:1000)，留白占图幅10%~20%。图框(按方案A国标)：外框(纸边)=0.25细、内框=0.7粗、内外框间距 装订边左20~25 其余5mm(A2~A4)或10mm(A0/A1)；标题栏右下角180×56(GB)含图名/图号/比例/单位/日期/签名；放独立 BORDER/TK、TITLE/BTL 层。错误：图幅过小图形超框、过大留白多、比例非标准、线宽设错、标题栏信息不全。输出：所选图幅尺寸+名称、比例及计算过程、确认图框标题栏正确放置、图幅布局示意。
1f 图框模板：外框与内框(按方案A国标线宽)：**外框(纸边)=0.25细、内框(绘图区)=0.7粗**，颜色红1号/BORDER/TK层；内外框间距：装订边(左横装/上竖装)留25mm，其余边留5mm(A2~A4)/10mm(A0~A1)；线连续无断开转角直角。标题栏：右下角 **180×50mm(本部分指定；GB标准为180×56，需与既有统一时确认)**，黄色2号/TITLE/BTL层，字高 图名5-7、其余3-5、签字及材料重量2.5-3.5；含 图纸名称/图号/比例/设计单位/设计人/审核/日期/材料/重量/共X张第X张。图例：标题栏上方，宽与标题栏一致(180)高50-100；说明：左上角，宽200-300高50-100；图例/说明距内框线10mm。使用流程：选图幅→调图框模板(.dwg)→插主体居中→填标题栏→加图例说明→检查。错误：外内框线宽相同、装订边方向错、标题栏尺寸不符、信息不全、图例说明与标题栏重叠。输出：图框模板.dwg+标题栏填写示例+确认无重叠+布局示意。
2 图幅与比例：**根据主体外接矩形尺寸选择能完整容纳的最小标准图幅**（A0=1189×841/A1=841×594/A2=594×420/A3=420×297/A4=297×210，必要时加长幅），**不固定默认图幅**；主体过大/过小相应选更大/更小幅面。比例用国标推荐 1:1/1:2/1:5/1:10/1:50/1:100/2:1/5:1（用户 2026-08-08 修改：去A3默认，按主体选幅）。
3 图框(GB/T 14689)：**外框(纸边)细实线0.25mm、内框粗实线0.7~1.0mm（注意方向勿写反）**；装订边(左)20~25mm 其余5mm；四边对中符号；主体左下角对齐或居中。
4 标题栏(GB/T 10609.1)：右下角；**每个标签(图名/图号/比例/日期/材料/重量/单位等)后必须接独立空白内容单元格，标签|内容相邻不同格；签字类(制图/审核/设计)留空**。图名文字5~7mm、其余2.5~3.5mm。
5 图例：图框内右下角(标题栏上方)或左下角，符号+文字说明，大小与比例协调。
6 说明文字：左上角或标题栏上方，填未注公差/表面处理/热处理/装配等；字高3~5mm；DXF中汉字用 gbenor.shx+gbcbig.shx 大字体(防方块)。
7 图纸布局(横/竖可选, 视情况选用；2026-08-08 用户提供竖版规范)：**竖版与横版布局均可，根据主体形态/场景/用户要求选择使用，非强制。** 竖版布局(竖向图幅，最短 A4=210×297)：装订边(左)25、其余三边10；自下而上 图框下边→标题栏(底部, 高约30, 宽=图框宽, 标签|内容分格, 文字正向)→间距10→图例(高约50, 宽同)→间距10→说明/技术要求(高约40, 宽同)→间距10→绘图区(顶部)；竖版时标题栏放底部横贯、图例与说明不放顶部、文字正向。横版布局(横向图幅)：标题栏右下角(180×56 或按横版规范)，主体在左绘图区。选图幅：按主体量级(名义尺寸 S=max(Lx,Lz) ≤ 图幅短边)选相称图幅，比例取能容纳的最小标准比(1:1/1:2/2:1...)。实现引擎：`cad/gb_figure.py`(V3, 横/竖自动选择 + 自动选图幅与比例)。

9 平滑回转体(lathe) ENT：`('lathe',cx,cy,contour)`，contour=list of (z,r) 折点。引擎用 Catmull-Rom 样条插值 r(z)(C1 连续, 过所有折点)，等轴测下自动画**左右两条平滑母线**(替代阶梯圆柱)+**顶口整圆**+**底前缘半圆**。用于流线型/脉动瓶/可乐瓶等平滑弧形轮廓。折点写法：圆柱段用等 r 两点、腰身用减小 r 点、肩/颈用递减 r 收窄(如可乐瓶 [(0,32.5),(30,33),(70,25),(110,32),(140,30),(165,20),(190,12.5),(200,12.5)])。DIMS 按最大/腰身/瓶口半径与总高标注；母线在 DXF 以 48 点平滑折线输出(视觉等价 SPLINE)。选幅保比例(>1:2 自动升图幅)。**线连接自检(2026-08-09)：底圆前缘弧须含左右母线端点(θ0/θ180)严格闭合，避免悬空断点；母线端与顶口圆 θ0/180 点重合。已验证闭合。**
**遮挡(2026-08-09)：lathe 参与遮挡判定——`occluded` 用 `lathe_fwd_depth`(最大半径圆柱近似, 偏保守删隐藏线)，被该 lathe 挡住的后续实体(cyl/box/另一lathe)隐藏线会被正确裁剪；自身段靠 `i==skip` 排除不自挡。已验证：同轴柱穿过瓶身→柱在瓶内部分隐藏、两端露出可见、无外泄；单一回转体不受影响。**选幅保比例(>1:2 自动升图幅)。已验证：脉动瓶→A3 横 1:2、经典可乐瓶→A3 横 1:2。**瓶底拱形与中心线(2026-08-09)：lathe 自动画瓶底外凸拱弧(拱高=按瓶高 5%, 范围 4~10mm, 中央下凸)；generate 自动画竖直点画中心线(CENTER 层)贯穿回转体轴并上下延伸(伸出量=max12,8%瓶高)。回转体图必备中心线, 与技术要求"以中心线为基准"呼应。**
10 渲染质量自检规范(每次出图后自动核对, 2026-08-09 汇总用户三份提示词)：
- **线连接**：母线端点与顶圆(θ0/180)、底圆(θ0/180)严格闭合；圆自闭合(_circ 首尾重合)；无悬空断点/错位。检查法：ezdxf 读 DXF 按图层统计孤立端点数(主体层≈0)。
- **重叠**：全图无重叠线段、无多余/孤立线(OVERKILL 语义)。
- **遮挡/隐藏线**：lathe/cyl/box 互相参与遮挡；回转体只画可见轮廓(母线+顶口圆+底前弧)；被前方实体挡住的线正确裁剪(不穿透显示)。
- **文字**：标题栏/图例/技术说明文字无跑框、无重叠、方向正向(竖版从左到右)；字高按幅面(A4 3.5~5、A0~A3 5~7)。
- **中心线**：回转体须画竖直点画中心线贯穿旋转轴并伸出两端(与技术说明"以中心线为基准"呼应)；点画线样式正确(CENTER 层/linetype).
- **标注不穿实体**：等轴测回转体优先用引线式标注(generate 的 LDIMS 参数: (文本,锚点3D,方向3D)，从轮廓点引细实线到图外、文字标引线端)，不画横穿实体的尺寸线；标注分散放射状不交叉；字高按幅面.
- **图框要素**：标题栏外框**四边完整**；说明/图例框顶边与内框线留 GAP 不贴合；右侧栏三板块垂直分层留距；对中符号/装订边规范. **标题栏格网(2026-08-09)**：按内容紧凑设计无冗余空格——签字区(制图/审核/日期,左)+信息区(比例/图号/张次,中)+**图名大格(右侧跨全高, 字最大最醒目)**；仅制图/审核签字格留空(待手填)，其余每格均有标签或值，不做无意义空行/空列.。
- **DWG导出 / 默认三格式交付(2026-08-09)**：正式工程图纸**默认交付 PDF+DXF+DWG 三格式**（不再仅双格式）——引擎(gb_figure.py)直接产 PDF+DXF，DWG 用 `cad/dxf2dwg.sh`：ODA File Converter(AppImage, Autodesk 官方免费, 无 root 用 `--appimage-extract` 解压 /tmp)+系统 Xvfb(`xvfb-run`) 命令行 DXF→DWG，无损保留图层/文字/图名(已回读验证)。版本默认 ACAD2018，可指定 ACAD2000~2021。
- **比例与图幅**：主体+尺寸标注完整在绘图区内、不被图框切割；比例=实际标准比(STD)且与标注一致；方向符合幅面(A0~A3 横/A4 竖)。
- **字体**：GB_HZ(gbenor+gbcbig)无方框/乱码(用 check_dxf_fonts.py 核验)。
- **文件**：PDF+DXF 双交付，命名含版本+日期(精确到分钟)。
验证流程：引擎出图→fitz 渲染 PDF 为 png→image_reading 核对(线连接/遮挡/文字/比例)+ezdxf 孤立端点统计+字体自检。
【输出】1) DXF(或DWG)+PDF 双交付；2) 图层命名规范(主体/图框/标题栏/图例/说明/标注)并赋颜色线型；3) 国标尺寸标注(界线超2~3mm/实心三角箭头/数字沿轴向/单位mm)；4) 提供图幅尺寸、比例、主体实际尺寸说明。

1i 比例标注：标准比例系列(GB/T 14690-1993)：原值1:1；放大 2:1/5:1/10:1/20:1/50:1/100:1；缩小 1:2/1:5/1:10/1:50/1:100/1:200/1:500/1:1000/1:2000/1:5000。优先原值1:1，过大过小选标准放大/缩小。位置：标题栏"比例"字段标整图主比例；多视图同比例仅注一次；不同比例视图每个下方单独注"比例 1:50"(字高3-5)；局部放大图上方标放大比例"I 2:1"/"A 5:1"。格式：半角冒号无空格(1:100，禁全角1：100)、字体与图纸一致、字高3-5、放 TEXT/WZ 或 NOTE/SM 层(绿3或白7)、标题栏居中/视图下方左或居中。多视图处理：冲突时(如主1:100+放大5:1)放大图下方标"5:1"、标题栏注"除注明外，比例均为1:100"；同比例视图用相同格式和字高。比例与尺寸标注：**标注值显示实际尺寸而非图形尺寸**(1:100中实际5000mm图形50mm但标注显示5000)；标注样式设"测量单位比例"因子(1:100图纸因子=100)使标注自动显示实际值；不同比例视图需独立标注样式/独立因子。错误：标题栏未标比例、不同比例视图未单独标、全角冒号、比例因子错致标注值不符、放大图未标比例。输出：标题栏主比例+不同比例视图独立标注+放大图比例编号+因子正确尺寸一致+比例标注示意。
