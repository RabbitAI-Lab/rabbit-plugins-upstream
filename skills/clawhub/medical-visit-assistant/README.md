# Medical Visit Assistant

一个用于 OpenClaw 的“就医辅助与医疗信息整理” Skill。

## 它能做什么？

1. **症状采集**
   - 帮用户把零散的症状描述整理成结构化信息
   - 根据情况主动询问重要缺失信息

2. **病情时间线**
   - 按时间整理症状、检查、就诊和用药经历

3. **就医摘要**
   - 生成可以直接给医生看的简洁病情摘要
   - 同时生成约 30 秒的口头描述

4. **检查报告解释**
   - CT / MRI / X 光 / 超声 / 化验等
   - 将专业术语解释成容易理解的语言
   - 明确哪些结论不能仅凭报告确定

5. **医生问题清单**
   - 根据用户情况生成看诊时值得询问医生的问题

6. **用药信息整理**
   - 整理药名、剂量、频率、开始时间、效果和不良反应等用户提供的信息
   - 不擅自调整处方药

7. **就诊记录**
   - 整理看完医生后的诊断意见、检查、治疗方案、药物和复诊安排
   - 明确区分“医生说的”和“Skill 的解释”

8. **风险提醒**
   - 对可能存在严重风险的描述优先提醒用户及时寻求医疗帮助
   - 不把聊天当作急诊分诊或医学诊断

## 三种主要用法

### 1. 我要去看医生

例如：

> 我明天准备去骨科，你帮我整理一下应该怎么跟医生说。

### 2. 帮我看检查报告

例如：

> 这是一份腰椎 CT 报告，帮我解释一下。

### 3. 帮我记录这次就医

例如：

> 我今天看完医生了，帮我把这次就诊记录整理一下。

## 安全定位

这个 Skill 的定位是：

**帮助用户更好地准备就医和管理医疗信息，而不是替代医生进行诊断或治疗。**

对于突然出现的严重症状、明显恶化的症状或可能危及生命的情况，应优先寻求当地紧急医疗帮助。
