# 转录文字忠实清稿

把已有转录稿变得可读、可审阅，同时保住原话的事实、立场和不确定性。

## 输入

- 用户拥有或授权的原始转录文本（最多 6000 字或约 20 分钟）。
- 可选的说话人、时间标记，以及清稿程度：`轻度`（仅明显口误/重复）、`常规`（整理语气词与断句）、`保守`（尽量保留口语）。

没有原始转录文字时，先索取文字；说话人无法区分时，要求用户标明或允许统一标为“说话人”。音频没有作为证据提供时，不得纠正数字、专名，也不得补造漏词。

## 工作方式

1. 只处理用户提供的文字；保留时间码、说话人归属和关键否定、数量、限定词。
2. 清除无信息的口头填充、明显连读重复，调整标点和段落；不把观点改写成营销文案。
3. 用 `[待确认：原因]` 标记听不清、疑似专名、数字或语义无法确定的位置，绝不猜测。
4. 输出干净稿、修改清单和待确认项。若用户指定清稿尺度，以其尺度优先。

## 输出格式

```markdown
## 干净稿
（保留说话人/时间标记的清稿）

## 修改清单
- 原文：… → 清稿：…（原因：删除无信息填充/合并重复/标点）

## 待确认
- [时间/说话人] 原文片段（原因：听不清/专名/数字无音频证据）
```

不要声称听过、核对过或转录过不存在的音频。对任何未提供证据的部分，宁可保留原文或标为待确认。
