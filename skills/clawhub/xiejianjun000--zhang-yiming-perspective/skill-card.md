## Description:

A persona-style skill that applies Zhang Yiming-inspired mental models to entrepreneurship, product strategy, organization design, personal growth, and investment questions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[xiejianjun000](https://clawhub.ai/user/xiejianjun000)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and users invoke this skill when they want business, product, management, personal growth, or investment analysis framed through Zhang Yiming-inspired mental models. It is intended for perspective-taking and decision framing, not as a source of real statements from Zhang Yiming.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The README recommends an unpinned global npx install path.

Mitigation: Install through the reviewed ClawHub path when possible, and use the npx path only after separately reviewing and trusting the current package or repository.

Risk: Persona-style answers may be mistaken for actual statements by Zhang Yiming.

Mitigation: Treat outputs as a public-source-based perspective simulation and preserve the skill's honesty boundary that it cannot predict Zhang Yiming's real response to new questions.
