## Description:

Helps turn product photos, listings, or specifications into conversion-focused ecommerce ad videos through dLazy's hosted video workflow.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Sellers, marketers, and creators use this skill to turn product images, descriptions, or listing links into shopping ads and ecommerce videos, with support for multilingual voiceover and an optional virtual host.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Product prompts and optional attached files are sent to dLazy's hosted service.

Mitigation: Send only content approved for the service; avoid uploading sensitive product files without review.

Risk: Using the dLazy CLI requires an API key and installation of a third-party package.

Mitigation: Review the pinned @dlazy/cli package and source before installation, and protect or rotate the API key as needed.
