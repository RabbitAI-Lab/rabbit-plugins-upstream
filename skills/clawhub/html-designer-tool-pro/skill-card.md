## Description:

HTML设计工具专业版 helps agents generate and manage enterprise HTML/CSS design systems, including design tokens, reusable component libraries, multi-theme support, batch page generation, and team-oriented brand consistency guidance.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, designers, and product teams use this skill to create HTML/CSS design-system assets, reusable UI components, theme configurations, and batch-generated static pages for commercial web projects. It is intended for design creation, UI work, brand visuals, and automated design-system workflows, not 3D modeling or animation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may generate or suggest Python, Node, npm, ping, or integration commands with broad local file and command authority.

Mitigation: Review generated commands and scripts before execution, run them in a controlled workspace, and avoid passing untrusted input directly into command arguments.

Risk: Optional third-party design-platform integrations may require API keys or service credentials.

Mitigation: Configure credentials only when intentionally connecting a third-party platform, prefer environment variables, and avoid hard-coding secrets in generated files.

Risk: Generated design-system code and configuration may not match project accessibility, performance, browser, or brand requirements without review.

Mitigation: Validate generated HTML/CSS, themes, and component outputs with project-specific accessibility, responsive layout, performance, and brand checks before deployment.
