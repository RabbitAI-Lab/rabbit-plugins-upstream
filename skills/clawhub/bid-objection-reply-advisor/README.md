# 招投标异议答复辅助（招标人版）· 招盾

依法必须招标的招投标项目中，招标人/招标代理机构收到异议后的"防御盾牌"：
依法受理登记 → 判断异议是否成立 → 生成纠正/驳回/切割答复 → 预判投诉风险与投诉阶段应对。

## 核心能力
- **受理登记与多时钟时限计算**（我方答复 3日·日历日 / 异议提出四分型时限）
- **防守拆解与三重法理校验**（事实 / 法律 / 因果，程序违法从紧）
- **成立纠正 / 不成立驳回 / 部分成立切割**
- **《投诉风险预判书》**（内部，含薄弱句标记与投诉阶段应对预案）
- **答复前依法暂停**招投标活动的刚性义务提示（实施条例第22/54条）

## 法律轨道（唯一）
《招标投标法》第20/22/33/37/40/54/65条 · 《招标投标法实施条例》第20/22/23/32/44/46/49/54/55/60/82条 · 《工程建设项目招标投标活动投诉处理办法》（七部委令第11号·2013年23号令修正）第7/9/25条 · 各省实施细则（检索 KB）。
