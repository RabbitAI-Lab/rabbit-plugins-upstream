# 真实案例与基准数据

来源：Agentman《2026 Agent Skills 生态报告》、Gartner、Workera、主文章及扩展阅读包。用于佐证方法论与增强说服力。

## 一、生态与基准（定量）

- **标准化进程**：Anthropic 2025-10 推 Agent Skills，2025-12-18 发布为开放标准 agentskills.io；采纳者含 OpenAI Codex、Cursor、Gemini CLI、VS Code、Goose、Databricks、Spring AI、Mistral
- **规模**：官方 showcase ~40 兼容产品；社区目录 SkillsMP 抓取自 GitHub 公开技能约 **190 万**
- **质量现状（SkillsBench）**：分析 47,150 个公开技能，**平均质量仅 6.2/12**；安全审计 22,511 个技能发现 140,963 个问题；Snyk 检测 **36% 技能含提示注入**
- **漏洞率**：大规模分析 42,447 个技能，**26.1%** 含至少一项漏洞；另一审计 36.82% 有安全问题
- **Gartner**：预测 2026 年底 **40%** 企业应用集成任务专属 AI Agent（2025 年 <5%）
- **Workera 2026 基准**：14 项核心 AI 能力中仅 13% 员工具备 Agentic AI 技能；62% 企业试验 Agentic AI，仅 3% 能跨部门规模化

## 二、策展最佳实践（Agentman）

- 只用审核后**顶部四分位**技能（评分≥9）：平均提升代理通过率 **16.2 个百分点**，医疗域达 **+51.9 分**
- 安全视同开源依赖：装社区技能前审源码；选带安全扫描/认证的目录
- 写聚焦技能（拆 2–3 个针对性技能）优于单体文档
- 利用可移植标准：按 agentskills.io 写一次，跨兼容平台免改运行

## 三、企业落地案例

- **IBM AskHR**：自动遏制率 94%、工单减 75%、成本降 40%
- **JPMorgan LLM Suite**：30 秒生成 5 页 PPT（原 3–4 小时）
- **Klarna**：AI 客服等效 853 全职人力
- **Cognizant**：35 万员工部署 Agent Skills（aigenticlab 引）
- **Accenture**：3 万人部署
- **Agentman Medman（医疗后台）**：资格核查代理每次 $0.50，对比 CAQH $7.97，证策展技能生产可用

## 四、采用驱动力与趋势（H2 2026）

- 68% 生产代理部署已采用 MCP 或等效工具层，技能自然叠加其上
- 竞争从目录规模转向**信任基础设施**（安全扫描成门槛）
- 质量基准驱动采购（如 SkillsBench 分数）
- 业务职能技能（产品/营销/运营/受监管垂直）增速快于编码技能
- 垂直深度胜水平广度，通用技能商品化

## 五、对"构建企业级技能"的启示

1. 质量与安全是最大短板 → 本技能的生成+审查+治理闭环正中要害
2. 聚焦 + 策展（顶部四分位）远比堆量有效 → 设计器坚持单一职责、最小技能集
3. 企业级 = 治理信封 → 生产前置安全审查、版本 pin、审计、回滚
4. 真实 ROI 来自垂直场景（IBM/JPMorgan/Klarna/Medman）→ 优先从高频、痛点明显、爆炸半径小的工作流切入
