# Pass/Fail Evals

Fix every failure before returning an edit or sending a substantive reply.

## Meaning and evidence

- PASS if the writer's point, intended reader action, and level of certainty are preserved.
- FAIL if the edit invents or silently strengthens claims, examples, numbers, quotations, sources, opinions, or emotion.
- FAIL if unsupported attribution remains polished into false authority.

## Voice

- PASS if the writer would recognize the vocabulary, cadence, bluntness, humor, uncertainty, edge, and level of polish.
- PASS if strong human sentences and useful roughness remain.
- FAIL if the edit flattens the voice into generic professional prose.
- FAIL if every paragraph becomes equally tidy, compressed, or symmetrical.
- FAIL if signature vocabulary is mechanically removed or artificially inserted as a voice costume.

## Clarity

- PASS if the reader can identify the point, actor, mechanism, constraint, and next action where the draft supports them.
- PASS if specific facts and concrete details survive.
- FAIL if the edit swaps buzzwords while leaving the abstraction intact.
- FAIL if jargon or metaphor does emotional work instead of explanatory work.

## Decision state

- PASS if decision-supporting writing distinguishes known facts, unknowns, missing inputs, prior decisions, and open questions where relevant.
- PASS if the reader can tell whether a decision, approval, recommendation, input, or no action is needed.
- FAIL if polished context hides the ask, ownership, uncertainty, or informational status.
- FAIL if the edit manufactures certainty or a decision that the source does not support.

## Pattern review

- PASS if unnecessary contrasts, negative lists, throat-clearing, faux insights, dramatic reveals, superficial analysis, puffery, grand metaphors, rhetorical setups, robotic rhythm, recap endings, fake-profound kickers, formatting clutter, and em-dash clusters are removed.
- PASS if an apparent pattern remains because it is precise, necessary, quoted, or genuinely characteristic of the writer.
- FAIL if pattern removal damages meaning or voice.

## Mode behavior

- PASS if edit mode returns the clean version and a short, specific change note.
- PASS if detect mode names each pattern, quotes the exact line, gives a short fix, and does not rewrite or guess authorship.
- PASS if pre-send mode returns only the corrected reply.
- FAIL if detect mode assigns an AI-likelihood score or treats style as proof of authorship.

## Final read

- PASS if the result sounds natural when read aloud to a sharp colleague.
- PASS if the amount of editing is proportional to the actual problem.
- FAIL if the piece could have been produced by any generic professional-writing prompt.
