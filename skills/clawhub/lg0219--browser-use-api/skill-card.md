## Description: <br>
Cloud browser automation via Browser Use API for AI-driven web browsing, scraping, form filling, and multi-step web tasks when local browser control is unavailable or unsuitable. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[lg0219](https://clawhub.ai/user/lg0219) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and agents use this skill to delegate web browsing, scraping, form filling, and multi-step web workflows to Browser Use's cloud browser service. It is most useful when simple page fetches or local browser tools are not available or suitable. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Task prompts, browser activity, and screenshots may be processed by Browser Use's external cloud service. <br>
Mitigation: Use the skill only when that provider processing is acceptable, and avoid sending credentials, private pages, regulated data, or sensitive form inputs unless approved. <br>
