# 类案匹配与成立/不成立对比方法论

> **Scope & Language / 适用范围与语言（法域限定·已声明）**：本文件为 `gp-objection-caselaw` 技能（专为中国大陆《政府采购法》体系设计）的参考文档。文中检索式、抽取字段、对比逻辑均对应中文法定采购语境，以中文表述为法域内在要求（justified by statutory domain），非未经同意的强制语言切换。

本文件为 `gp-objection-caselaw` 的深度参考，描述第二步（类案检索）与第三步（成立/不成立对比）的可执行细则。SKILL.md 仅保留骨架，细节在此。

---

## A. 检索式构造

1. **先归类争议类型**（见 SKILL.md 第四步）：资格条件 / 技术参数（含★实质性条款）/ 评分办法 / 程序违法 / 代理行为 / 中标结果 / 其他。
2. **抽取关键事实词**：从"质疑核心诉求 + 被质疑条款 + 我方拟回应"中提取 2–4 个高区分度词。
   - 技术参数类：★实质性条款、检测报告、书面承诺、主频/参数达标、功能实现、样品、现场演示。
   - 程序违法类：应回避、串通、限定专利、排斥潜在供应商、泄露信息。
   - 评分类：主观分、打分畸高畸低、客观分误判、废标条款。
3. **构造检索式**：`争议类型词 + 关键事实词` 组合，例如：
   `技术参数 实质性条款 检测报告 书面承诺 处理器主频`
4. **双路召回**：关键词召回（精确命中条款/文号）+ 向量召回（语义相似），取并集后按相关度过滤 `min_relevance≥0.82`。

---

## B. 高度相似筛选标准（四要件）

| 要件 | 说明 |
|---|---|
| ① 同争议类型 | 与本案归入同一争议大类 |
| ② 事实结构相似 | 如同为"★参数 + 以承诺函回应 + 质疑成立/不成立" |
| ③ 法条相邻 | 适用同一或相邻法条（如都引用实施条例第20条） |
| ④ 相关度达标 | Hybrid 召回 `relevance≥0.82` |

不满足④的仅作"背景参考"，不计入 Top-N 高度相似清单；不满足①②③任一项但相关度高的，单列"相关但不高度相似"提示用户。

---

## C. 单案结构化抽取字段

对每条命中类案，抽取以下字段（用于对比表）：

```
- 地区 / 处理机关（哪级财政）
- 文号 / 决定日期
- 争议焦点（一句话）
- 被投诉人（采购人/代理）回应方式
- 证据形式（承诺函 / 检测报告 / 实物 / 第三方证明 / 现场演示 / 无）
- 财政认定：成立 / 不成立 / 部分成立
- 事实依据（为什么这么认定）
- 法律依据（具体条款+款项）
- 处理决定（驳回投诉 / 责令整改 / 重新采购 / 中标无效 / 其他）
```

---

## D. 成立/不成立对比分析（核心输出）

### D1 分组
- **成立组**：列出所有"质疑成立/部分成立"类案。
- **不成立组**：列出所有"质疑不成立/驳回"类案。

### D2 共性归纳
- 成立组共性：事实充分？证据客观？程序/资格性违法属实？影响权益或结果？
- 不成立组共性：事实不成立？已补正？属评审自由裁量？未影响权益？

### D3 反转差异点（最有价值）
筛选"同一争议类型、结果相反"的案例对，回答：**差异在哪？**
常见差异轴：
- 证据形式（客观证据 vs 口头/函件承诺）
- 事实充分性（有/无采购文件原文佐证）
- 程序瑕疵严重性（可补正的形式瑕疵 vs 实质性违法）
- 是否影响结果（实体违规论因果；程序/资格违法不论因果）
- 法条适用精准度（具体条款 vs 空引）

### D4 本案映射与预测
将【当前质疑】映射到对应组，给出：
- 预测结论：成立 / 不成立 / 存疑
- 置信依据：引用 D3 差异轴 + 对应类案编号
- 可补强方向：差哪个证据/哪条法条 → 指向堵漏

## E. 检索结果可信度标注

| 情形 | 标注 |
|---|---|
| 命中≥3 条高度相似且结论一致 | 高置信 |
| 命中但结论分裂（成立/不成立都有） | 中置信，须看 D3 反转差异 |
| 仅背景参考（相关度<0.82） | 低置信，仅参考 |
| 检索为空 / 库未连接 | 【依据待核】，不得伪称匹配 |
