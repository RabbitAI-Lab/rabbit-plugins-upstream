# 质疑答复函模板（六要素 · 对外文本）

> **Scope & Language / 适用范围与语言（法域限定·已声明）**：本文件为 `gp-objection-caselaw` 技能（专为中国大陆《政府采购法》体系设计）的参考文档。质疑答复函六要素格式与法定术语依《政府采购质疑和投诉办法》（94号令）第十五条，以中文法定表述为法域内在要求（justified by statutory domain），非未经同意的强制语言切换。

本文件为 `gp-objection-caselaw` 第五步的输出模板。严格遵循《政府采购质疑和投诉办法》（财政部94号令）第十五条六要素。生成时**用本项目真实信息替换占位符**，并附类案支撑与证据补强要求。

## 质疑答复函（草稿）【对外文本】

```
──────────────────────────────────────
关于《[项目名称]》（项目编号：[XXX]）质疑事项的答复函

[质疑供应商全称]：

我单位（[采购人/采购代理机构全称]）于 [YYYY年MM月DD日] 收到贵方提交的
关于上述项目的《质疑函》。根据《中华人民共和国政府采购法》及其实施条例、
《政府采购质疑和投诉办法》（财政部令第94号）等规定，现就贵方质疑事项答复如下：

一、质疑事项
[逐条列明供应商质疑事项，与《质疑函》一致]

二、审查情况与事实依据
[针对每条质疑，说明我方核查的事实：调取了哪些文件/记录，事实认定是什么。
 涉及客观事实类（如★参数达标）的，此处应载明已收取的"事实依据"类型：
 检测报告/实物照片/第三方证明/现场演示记录等；若仅以书面承诺函回应，
 须同步提示内部风险（见风险预警清单）。]

三、法律依据与答复意见
[逐条给出结论：成立/不成立/部分成立。
 不成立/驳回必须引用具体法条编号+款项，例如：
 "根据《政府采购法实施条例》第二十条第（X）项……"；
 成立/部分成立须说明纠正方案（修改文件/重新采购等）。
 每条可附类案参考：参见类案匹配清单编号 [N]（[地区][文号] 同类处理口径）。]

四、告知投诉权利
如贵方对本答复不满意，可在答复期满后 15 个工作日内，向
[XX市/区财政局政府采购监管处] 提起投诉。

五、答复人
[采购人/采购代理机构全称]（盖章）
[YYYY年MM月DD日]

──────────────────────────────────────
剩余工作日提醒：⚠️ 自收到质疑函次日起算，须于 7 个工作日内书面答复
（94号令第13条）。本草稿生成日距截止日约 X 个工作日，请尽快经法务/采购
部门审核后发出。
```

## 填写要点（内部检查清单）

- [ ] 六要素齐全：① 质疑供应商名称 ② 收到日期+项目名称编号 ③ 事项+答复+事实依据+法律依据 ④ 告知投诉权利（含15工作日+财政全称）⑤ 答复人名称 ⑥ 答复日期
- [ ] 驳回/不成立结论含具体法条编号+款项（铁律5）
- [ ] 客观事实类质疑已载明"事实依据"证据类型，未仅靠承诺函（铁律4）
- [ ] 未泄露其他供应商商业秘密（铁律6）
- [ ] 每条结论可溯源 KB 或本项目文件，无【依据待核】支撑的驳回/成立结论（铁律2）
- [ ] 附剩余工作日提醒（铁律7）
