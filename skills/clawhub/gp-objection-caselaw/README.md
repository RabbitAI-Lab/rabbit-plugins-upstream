# 政采质疑类案智库（判例法辅助）

> 政府采购场景下，采购人/采购代理机构"被质疑"时的**类案匹配 + 成立/不成立对比 + 被推翻风险预警**答复辅助智库。

## 它能做什么

收到供应商质疑后，输入**质疑核心诉求**，技能将：

1. 从「政府采购投诉AI知识库」（约 5 万条真实投诉处理决定）匹配**全国高度相似类案**；
2. 比对类案中"质疑成立"与"质疑不成立"的**事实依据与法律适用**，提炼规律；
3. 识别我方拟答复的**薄弱环节与被推翻风险**（典型如：仅以书面承诺函回应客观事实类 ★ 参数质疑）；
4. 辅助撰写含六要素的**质疑答复函草稿**，并附投诉风险预判。

## 重要说明

- **中国系成文法国家，类案仅作参考、非约束性先例。** 本技能匹配出的案例用于"提炼事实认定与法律适用规律"，不得表述为"应当据此判决"。
- 本技能仅服务**政府采购**（采购人/代理机构被质疑场景），不处理工程招投标异议。
- 不替代律师/法务意见，正式发出前须经审核确认。

## 与「政采盾牌」的关系

本技能是**类案检索引擎**（专注找相似案例 + 对比规律 + 风险预警）；`gp-objection-reply-advisor`（政采盾牌）是**全流程防御盾**（受理登记→五步工作流→投诉预判）。两者互补，可联动使用。
