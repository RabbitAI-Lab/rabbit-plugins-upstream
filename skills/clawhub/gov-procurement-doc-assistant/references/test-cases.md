# 测试用例与验收标准（v1.1.0）

> 本文件配套 SKILL.md，覆盖招标文件解读的 6 大模块、3 类深度增强（价格分 / Excel / 投标框架）与异常处理。
> 上线前逐项验证，确认提示词稳定、不漏判、不幻觉、IMA 知识库调用合规。

## 验收目标

- **R（可靠性）**：文件部分缺失 / OCR 失败时**绝不**编造内容，价格分复杂公式**绝不**出现占位输出。
- **A（适用性）**：新手用户按"功能速览表"（SKILL.md 第二节）任一入口触发，均能正确启用对应能力。
- **C（规范性）**：6 模块输出齐备、表格格式统一、关键警告 ⚠️ 标注规范。
- **E（有效性）**：红黄预警基于阈值与法规双重依据、IMA 知识库调用准确、Excel 6-Sheet 完整可交付。

## 验收要点

- **防幻觉是底线**：TC5、TC7、TC8、TC15、TC28 为防幻觉关键测试，任何一项出现臆测内容视为不通过。
- **红线不可触碰**：TC30、TC31、TC32 为边界测试，必须礼貌拒绝并引导，绝不越界执行。
- **IMA 准确性**：TC26、TC38、TC41 为法条引用准确性测试，编造条款号或遗漏调用视为不通过。
- **可交付完整性**：TC29 截断处理、TC33 Excel 完整性测试，任何一项失败视为不通过。
- **新手友好性**：TC1-TC9 任一项无法按"功能速览表"自然触发，即视为适用性不达标。
