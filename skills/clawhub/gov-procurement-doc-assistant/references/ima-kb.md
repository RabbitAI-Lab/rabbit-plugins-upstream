# IMA 知识库调用策略（v1.1.0）

> 本文件配套 SKILL.md 第六节，规范 IMA 知识库的调用时机、检索语句写法、置信度分层与降级策略。
> 目的：让 IMA 作为"法条溯源与案例补充"增强提示词内建知识，而非作为唯一判定引擎，避免召回不稳导致的漏判 / 误判 / 输出漂移。

## 一、知识库标识

**用户当前可用的政府采购知识库（已实测可检索）**：

- `knowledge_base_id: 7463496212028405`
- **名称**：政府采购实务与合规（KB-A）
- **覆盖内容**：
  - 法律法规全文：政府采购法、87 号令（政府采购货物和服务招标投标办法）、94 号令（政府采购质疑和投诉办法）、74 号令（政府采购非招标采购方式管理办法）、财库〔2020〕46 号《促进中小企业发展管理办法》、国办发〔2025〕34 号《本国产品标准》等。
  - 典型案例：政府采购投诉处理决定书（含真实项目编号、违规情形、处罚结论）。
  - 专项整治动态：财政部"四类违法"专项整治口径与最新政策。
  - 处罚标准：失信名单、禁入期、罚款比例等。

> 若运行时该知识库不可用或 ID 变更，跳过本节，仅依赖提示词内建法条，并在 data_gaps / 异常处理中说明。

## 二、检索触发条件（五类必调场景）

与 SKILL.md 第六节对应，下述场景**必须**调用 IMA 知识库：

| 序号 | 触发场景 | 检索目标 | 期望输出 |
|---|---|---|---|
| 1 | 涉及"投标无效 / 废标 / 资格审查"认定 | 87 号令 + 实施条例 + 政府采购法 | 具体条款号与原文 |
| 2 | 涉及"差别待遇 / 歧视性条款"（注册地、所有制、规模等） | 87 号令第 20 条 + "四类违法"专项整治口径 | 禁止性条款 + 整改要求 |
| 3 | 涉及"中小企业预留 / 联合体 / 进口产品 / 本国产品" | 财库〔2020〕46 号 + 国办发〔2025〕34 号 | 政策适用条件 + 比例要求 |
| 4 | 涉及"实质性条款与文件解释规则" | 财政部指导案例 37 号 | 文件歧义时的解释规则 |
| 5 | 用户对某条款定性有疑义 | 投诉处理决定书类案 | 同类情形的历史认定结论 |

> ⚠️ **不触发**：纯商务条款的合理性判断（付款节奏、违约金比例）→ 属阈值预警范畴，不检索；价格分公式的数学演算 → 不检索。

## 三、检索语句写法（提升召回精度）

**原则**：具体优先于宽泛；带法条项号 + 场景词。

| 场景 | 推荐检索语句（示例） | 反例（避免） |
|---|---|---|
| 投标无效认定 | "87 号令 投标无效 情形 第 XX 条" | "投标" |
| 差别待遇 | "87 号令 第 20 条 差别待遇 排斥潜在投标人" | "歧视" |
| 中小企业 | "财库 2020 46 号 中小企业 预留 比例" | "中小企业" |
| 本国产品 | "国办发 2025 34 号 本国产品 标准" | "国产" |
| 案例参照 | "投诉处理决定书 虚假材料 处罚" | "案例" |

> 单次检索聚焦一个法律概念 / 一类条款，不堆叠多个不相关关键词。

## 四、置信度分层与处理口径

| 来源类型 | 置信度 | 用法 |
|---|---|---|
| 法律法规原文（政府采购法、87/94/74 号令等） | 高 | 可直接作为 legal_basis / evidence |
| 投诉处理决定书（真实案例，含文号） | 高 | 作为类比参考，标注来源，可佐证定性 |
| 财政部 / 发改委指导案例 | 高 | 同上 |
| 一线评标专家实务文章 / FAQ | 中 | 用于否定性规则、特殊主体处理、背景说明 |
| 网络自媒体 / 知乎 / 论坛 | 低 | 仅作参考，不得作为判定依据，不得提升 risk 等级 |

**结果处理规则**：

- 仅当 IMA 返回内容与内置法条一致、且来源为"高"置信度时，才追加到 evidence 或 reasoning，并在 evidence 中标注 `source="IMA KB: 文档标题"`。
- "中 / 低"置信度来源仅作背景说明，不得据以单独提升 risk 等级。
- 若 IMA 返回与内置法条冲突，以 IMA 为准（实时性 + 权威性），并将冲突点记入 data_gaps 供人工复核。
- 不同轮次检索结果应保持一致；如不一致，降权处理并在 reasoning 注明。

## 五、降级策略

| 场景 | 处理方式 | 用户提示模板 |
|---|---|---|
| KB 检索无结果 | 标注"知识库未收录相关法规 / 案例" | "法条引用基于模型内置知识，建议人工核实条款准确性。" |
| KB 与已知法规矛盾 | 以 KB 为准并记录分歧 | "⚠️ IMA 知识库返回内容与内置法条存在分歧，已按 KB 优先处理；分歧点见 data_gaps。" |
| `mcp__ima-mcp__search_knowledge` 工具不可用 | 降级为纯内置法条模式 | "⚠️ 知识库检索服务暂不可用，本次合规判定基于模型内置法规，未经过 IMA 验证。" |
| KB 返回内容过多（> 100KB） | 仅读取前 2-3 条 `highlight_content` 提取关键法条 | （自动处理，不打扰用户） |

## 六、调用频次建议

- 单次解读（1 份标书 6 模块）→ 建议调用 **3-5 次** IMA，覆盖：① 资格审查 ② 废标条款 ③ 差别待遇类 ④ 中小企业 / 本国产品 ⑤ 争议类条款。
- 不超过 **8 次**（避免 token 浪费与输出漂移）。
- 同类条款合并检索（如多个疑似差别待遇条款合并一次查询），不重复检索。

## 七、与同类技能的关系

本技能的 IMA 检索**仅服务于**"政府采购法体系内"的合规判定（KB-A）；

- 招投标法体系下的关联关系认定 → 切换到 `bid-related-party-expert` 技能（KB-B：招投标实务与合规）。
- 企业历史黑历史 / 行政处罚 → 切换到 `bid-compliance-due-diligence` 技能。
- 跨体系合规问题（同时涉及政采 + 招投标）→ 串行调用相关技能，不在单技能内越界检索。
