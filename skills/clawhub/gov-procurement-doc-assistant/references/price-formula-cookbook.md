# 价格分公式解析手册（v1.1.0）

> 本文件配套 SKILL.md 第五节 3a（价格分引擎），提供五类常见价格分公式的标准化解析、变量拆解、预检卡模板与情景测算示例。
> 目的：让模型在面对复杂公式时**先做预检、再做计算**，避免直接代入导致的误判或占位输出。

---

## 一、五类常见公式 + 解析模板

### 类型 1：基准价法（最常见）

**公式原型**：
```
价格得分 = 满分 × (评标基准价 / 投标报价)
评标基准价 = 有效报价的算术平均值 × (1 - K)
```
其中 K 为现场抽取的下浮系数（常见 0%–10%）。

**预检卡字段**：
- 满分 = ___
- K = ___（待用户确认或按典型值 5% 试算）
- 竞争对手有效报价 = [___]（待用户输入）

**计算示例**（满分 30，K=5%，对手 A=100 万、B=110 万，我方 C=105 万）：
- 均值 = (100+110+105)/3 = 105 万
- 基准价 = 105 × 0.95 = 99.75 万
- C 得分 = 30 × (99.75 / 105) = **28.5 分**

---

### 类型 2：低价优先法

**公式原型**：
```
价格得分 = 满分 × (最低有效报价 / 投标报价)
```

**预检卡字段**：
- 满分 = ___
- 最低有效报价 = ___（即所有有效报价中的最小值，需用户输入或假设）

**计算示例**（满分 30，对手 A=100 万、B=110 万，我方 C=105 万）：
- 最低有效报价 = 100 万（A）
- C 得分 = 30 × (100 / 105) = **28.57 分**

**注意**：此法下越低越好，但有"低于成本"或"异常低价"审查风险。

---

### 类型 3：复合评分法（本国产品 + 基准价）

**公式原型**：
```
价格得分 = 满分 × [ (评标基准价 / 投标报价) × W1 + (本国产品金额 / 投标总金额) × W2 + ... ]
```
其中 W1 + W2 = 1（或各权重项明示）。

**预检卡字段**：
- 满分 = ___
- 各权重项 = {W1: ___, W2: ___, ...}
- 基准价计算方式 = ___
- 本国产品比例 = ___（待用户输入）

**v1.1.0 强制要求**：必须先输出预检卡、列出所有变量与待确认参数，**用户未确认前不进入计算**。

---

### 类型 4：区间评分法（分段函数）

**公式原型**：
```
若 投标报价 ≤ P1：得分 = 满分
若 P1 < 投标报价 ≤ P2：得分 = 满分 × α（线性递减）
若 P2 < 投标报价 ≤ P3：得分 = 满分 × β（继续递减）
若 投标报价 > P3：得 0 分或按废标处理
```

**预检卡字段**：
- 各档位阈值 = {P1: ___, P2: ___, P3: ___}
- 各档位得分系数 = {α: ___, β: ___, ...}
- 是否触发废标 = 是 / 否

**计算示例**（满分 30）：
- P1 = 90 万（≤ 得 30 分）
- P2 = 105 万（90-105 万得 30×(1-(报价-P1)/(P2-P1))）
- P3 = 120 万（> 120 万得 0 分）
- 我方 C = 100 万 → 30 × (1 - (100-90)/(105-90)) = 30 × (1 - 10/15) = 30 × 1/3 ≈ **10 分**

---

### 类型 5：含 K 值矩阵的不确定参数法

**场景**：公式含现场抽取系数 K（如下浮率、调整系数、权重系数等），且评标现场才确定。

**预检卡字段**：
- 满分 = ___
- K 的取值范围 = {下限: ___, 上限: ___}
- K 的典型值 = [0.90, 0.95, 1.00, 1.05, 1.10]（或按招标文件规定的步长）

**输出要求**：列出不同 K 值下的得分矩阵（如下表），而非单一数值。

| K 值 | 我方报价 | 基准价 | 价格得分 |
|---|---|---|---|
| 0.90 | 105 万 | 99.75 × 0.90 = 89.78 万 | 30 × (89.78/105) ≈ 25.65 |
| 0.95 | 105 万 | 99.75 × 0.95 = 94.76 万 | 30 × (94.76/105) ≈ 27.07 |
| 1.00 | 105 万 | 99.75 × 1.00 = 99.75 万 | 30 × (99.75/105) ≈ 28.50 |
| 1.05 | 105 万 | 99.75 × 1.05 = 104.74 万 | 30 × (104.74/105) ≈ 29.92 |
| 1.10 | 105 万 | 99.75 × 1.10 = 109.73 万 | 30 × (109.73/105) ≈ 31.35（可能封顶） |

**注意**：得分可能因 K 值变化出现 ≥ 满分 的理论值，需按满分封顶处理。

## 二、复杂公式的"待确认参数"清单

下列参数**必须**列入预检卡、待用户确认后方可计算：

| 参数 | 典型场景 | 默认兜底（仅试算用） |
|---|---|---|
| K（下浮率） | 基准价法、调整系数 | 5% |
| 本国产品比例 | 复合评分法 | 100%（假定全部为国产） |
| 中小企业扣除比例 | 87 号令价格分扣除 | 10% |
| 价格分满分 | 所有公式 | 30 分（按常见值试算） |
| 竞争对手报价 | 所有公式 | 不可假定（必须用户提供） |
| 是否含"低于成本"审查 | 低价优先法 | 是 |

> 用户未确认的参数，须在输出中**显式标注"⚠️ 假定值"**，并说明"实际结果以招标方现场确认为准"。

---

## 三、强制输出规范

1. **公式原文逐字摘录**（不翻译、不简化）。
2. **逐项展示算式**（如 `30 × (99.75 / 105) = 28.5`），不得用"经计算得 X 分"等占位表述。
3. **真实代入数值**（含我方报价、对手报价、K 值等），不得用"X"等占位符代替数值。
4. **不确定性标注**：含未确认参数时，明示"⚠️ 该公式含未确认参数 X，本次仅按假定值试算"。
5. **风险提示**：若最优报价接近预算 / 限价，提示"接近限价，存在成本压力"；若低于行业基准 30% 以上，提示"⚠️ 可能触发低于成本审查"。

---

## 四、典型误区警示

| 误区 | 正确做法 |
|---|---|
| 直接用"我方报价 = 满分"假设 | 必须代入真实对手报价均值 |
| 忽略 K 值的影响 | 列出 K 值矩阵（最差 / 典型 / 最佳三档） |
| 把本国产品扣除当"加分" | 实为价格分计算时给予的价格优势，非另加分 |
| 忽略满分封顶 | 价格得分公式理论值可能 > 满分，须封顶处理 |
| 用"中标价 = 略低于基准"作为结论 | 应给出三档（最高得分 / 中间 / 保底）报价建议 |

## 五、交付物中的呈现建议

在 Excel Sheet 4 "评分项拆解"末尾的"价格分计算分析"区，按以下结构呈现：

```
[1] 公式原文（从标书评标办法逐字摘录）
[2] 公式类型识别（基准价法 / 低价优先 / 复合评分 / 区间评分 / 其他）
[3] 变量解析（列出每个变量的含义、来源、是否待确认）
[4] 公式预检卡（待用户确认的参数列表）
[5] 情景测算表（三档报价 + 预估得分）
[6] K 值矩阵（若含未知现场参数）
[7] 不确定性说明（哪些参数为假定值）
[8] 风险提示（接近限价 / 可能触发低于成本审查 等）
```

> 满足上述八项结构的价格分分析，方可视为"完整可交付"。
