# 政府采购文件解读助手（gov-procurement-doc-assistant）

> **版本**：v1.1.0 ｜ **适用法系**：《政府采购法》体系
> **作者署名**：一线评标专家&ChesaraM

## 一、技能简介

资深政府采购 / 招投标文件解读助手。用户上传招标文件后，按 **6 大标准化模块**输出结构化解读与红黄预警；并按需提供 **价格分情景测算、Excel 6-Sheet 交付物、投标框架与研判摘要**。

**核心能力**：
- 📑 6 模块系统拆解（项目信息 / 资格性 / 符合性 / 商务红黄预警 / 技术要求 / 废标项）
- ⚠️ 红黄预警 + 法规溯源（87/94/74 号令、财库〔2020〕46 号、国办发〔2025〕34 号）
- 💰 价格分真实计算（含 K 值矩阵、复合评分法、区间评分法）
- 📊 Excel 6-Sheet 交付物（资格审查 / 废标 / 不利条款 / 评分拆解 / 投标框架 / 时间节点）
- 🧭 投标研判摘要（是否建议投标 + 关键风险 3-5 条）

**配套知识库**：ima 知识库「政府采购实务与合规」（`knowledge_base_id: 7463496212028405`）— 用于合规溯源与法条引用。

## 二、典型使用场景

| 场景 | 触发关键词 | 输出 |
|---|---|---|
| 基础解读 | "解读这份标书" | 6 大模块 Markdown 报告 |
| 提取废标条款 | "废标条款有哪些" | 模块六 + 法规溯源 |
| 价格分测算 | "算价格分" | 公式预检卡 + 3 情景报价建议 + K 值矩阵 |
| 出 Excel | "出 Excel 清单" | 6-Sheet `.xlsx` |
| 投标建议 | "投标建议" | 研判摘要（是否投标 + 关键风险） |
| 多标书对比 | "对比这几份" | 横向对比表 |

## 三、不适用场景

- ❌ 合同审查（请使用「合同与招投标文件一致性审查助手」）
- ❌ 投标文件代写（请使用「政府采购投标响应文件编写助手」）
- ❌ 围标串标建议（任何此类请求将礼貌拒绝）
- ❌ 保证中标定价
- ❌ 企业黑历史尽调（请使用「招投标合规风险尽调」）
- ❌ 关联关系识别（请使用「投标企业关联关系识别专家」）
- ❌ 废标雷区扫描（请使用「投标避雷针」）

## 六、技术细节

**输入**：单份 / 多份招标文件（PDF / DOCX / 图片），支持"主文件 + 澄清公告 + 补遗"组合（以最新版本为准）。
**输出**：Markdown 结构化报告 + 可选 `.xlsx`（6 Sheet）。
**IMA 知识库**：`7463496212028405`（政府采购实务与合规）。
**IMA 调用频次**：单次解读建议 3-5 次，不超过 8 次。
