## Description: <br>
Research comparable YC launch demos and build a structured Google Doc for OysterWorkflow demo-video planning, including candidates, links, analysis dimensions, observations, and script ideas. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Founders, marketers, and product teams use this skill to research YC launch demos for AI-agent and workflow products and turn those observations into a structured Google Docs plan for OysterWorkflow demo-video production. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill uses the user's signed-in browser session and can create or edit Google Docs. <br>
Mitigation: Confirm the intended Google account and document before running, and use a new document when accidental edits to an existing document would be disruptive. <br>
Risk: The workflow may edit an existing document titled "demo plan 1" if the user does not choose a new target. <br>
Mitigation: Explicitly confirm whether to use the existing document or create a new Google Doc before writing research notes. <br>
