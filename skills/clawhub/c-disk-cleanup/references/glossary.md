# 给小白的话术库（每项都用大白话解释）

助手在给用户出"清理菜单"时，用下面这套话术，让不懂电脑的人也能判断要不要清。

---

## 一、系统临时文件（最安全，建议清）

- **是什么**：Windows 和软件干活时留下的"草稿纸"，用完本该自己扔，但经常忘了。
- **在哪**：`C:\Windows\Temp`、`C:\Users\你\AppData\Local\Temp`
- **清了有啥影响**：几乎没影响，软件下次会自动重新建。能省几百 MB 到几 GB。
- **风险**：极低。个别软件正开着时会锁住一两个文件搬不走，关掉它或重启就好。

## 二、浏览器缓存（安全，建议清）

- **是什么**：你上网看过的图片、网页碎片，留着是为了下次打开快一点。
- **清了有啥影响**：第一次打开网站会稍慢一点点，但**不会丢你的书签、密码、账号**。
- **风险**：低。

## 三、Windows 更新缓存（安全，建议清）

- **是什么**：系统打补丁时下载的安装包，装完就没用了还占着地方。
- **清了有啥影响**：以后要重装补丁会重新下载，不影响已装好的系统。
- **风险**：低。

## 四、回收站（看情况）

- **是什么**：你以前"删除"的文件其实都躺这儿，没真没。
- **清了有啥影响**：**彻底找不回了**，所以必须你亲自确认。
- **风险**：中。只清你确定不要的。

## 五、桌面 / 下载文件夹（搬家，不删除）

- **是什么**：你存的文件、别人发你的压缩包、安装包等都默认堆在 C 盘。
- **我们怎么做**：**不删**，而是把它们"搬"到别的盘，并在 C 盘留个"传送门"（junction），你用起来和以前一模一样，但物理上不占 C 盘了。
- **风险**：极低，文件完好无损。

## 六、应用缓存（如微信/QQ 收的文件、视频软件缓存）

- **是什么**：聊天软件收的图片视频、视频软件边看边下的临时文件。
- **注意**：这里**可能混着你要的东西**（比如别人刚发给你的资料）。
- **我们怎么做**：单独列出来给你看大小，让你决定哪些敢清；绝不偷偷清你的聊天文件。
- **风险**：中。涉及你的资料，必须你点头。

## 七、休眠文件 / 虚拟内存（进阶，需特别确认）

- **休眠文件 hiberfil.sys**：你"合盖休眠"用的，关掉休眠能省几 GB，但以后不能休眠了（关机/睡眠还在）。
- **虚拟内存 pagefile.sys**：系统防卡顿用的，一般**不建议动**。
- **风险**：中高。这两项我们默认不动，除非你明确要。

## 八、系统文件 / 软件安装目录（禁区，我们不碰）

- `C:\Windows` 主体、`Program Files` 里系统自管的、驱动目录等。
- 这类只走微软官方工具（磁盘清理 / DISM / 压缩），不做野路子删除。

---

## 一句话原则

**能自动清的**：临时文件、浏览器缓存、更新缓存——安全、可再生。
**必须你确认的**：回收站、你的文档、聊天文件、休眠/虚拟内存——可能含重要资料。
**我们不碰的**：系统核心目录，只交给微软官方工具。
