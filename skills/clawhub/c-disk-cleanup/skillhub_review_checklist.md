## 一、市面 C 盘清理软件调研（哪些广泛用、有什么问题）

### 使用广泛的代表
| 软件 | 群众基础 | 主要问题 |
|------|----------|----------|
| **360 安全卫士 / 360 清理** | 国内装机量最高 | 安装默认捆绑360浏览器/压缩/管家；广告弹窗多、部分版本难永久关；清理强但"顺手"装一堆 |
| **腾讯电脑管家** | 高 | 偶尔弹游戏广告；清理+杀毒一体，偏重 |
| **火绒安全** | 口碑好、轻量无广告 | 清理功能偏基础，深度不够 |
| **CCleaner** | 国际老牌、免费版够用 | ①注册表清理收益存疑、有误删风险；②2017 年供应链被投毒事件；③母公司 Avast 曾陷卖用户数据争议；有隐私上传顾虑 |
| **Wise Disk Cleaner / Dism++ / Glary / 金舟优化大师 / 小番茄** | 细分人群 | 多为免费但夹广告或诱导付费；Dism++ 绿色口碑好但偏硬核；部分"免费版阉割"催会员 |
| **Windows 自带磁盘清理 / 存储感知** | 人人都有 | 最安全，但清不干净（清不到微信/QQ缓存、大文件），用户不知怎么用 |

### 通病总结（= 我们的机会）
1. **捆绑 + 广告**：装一个送全家桶，弹窗烦人。
2. **黑箱一键清**：不知道删了啥、能不能恢复，误删资料难找回。
3. **注册表清理存疑**：对普通电脑收益小、风险大（CCleaner 类）。
4. **常驻后台占资源**：清理完还赖着不走。
5. **隐私上传**：部分工具收集/上传使用数据。
6. **免费版阉割**：核心功能收费，催会员。
7. **治标不治本**：不碰大文件、微信缓存、系统组件这些真正吃空间的。

### 我们的差异化（文案就这么打）
✅ 不捆绑、不弹广告、不上传隐私
✅ **先报告后动手 + 每次确认**（反"黑箱"）
✅ **只搬不删、可恢复**（反"误删"）
✅ 记住你的习惯，越用越省心
✅ 免费、纯本地、不常驻

## 二、skillhub 上架审核：重点注意事项（按风险高低）

### 🔴 红线级（一碰就拒 / 必须改）
1. **绝不静默删除 / 未经确认改动文件。**
   - 本 skill 已设"铁律"：任何移动/删除前必须先展示内容+影响并取得明确指令；`safe_ops.ps1` 默认 DryRun，必须带 `-Confirmed` 才动手。
   - 审核通常会看脚本里有没有 `rm -rf` / `del /S /Q` / 直接 `Remove-Item` 不询问。我们改为**只搬不删 + 回收站兜底**，且脚本里没有任何无确认删除。
2. **不碰系统禁区。** 明确列出 `Windows\Installer`、`WinSxS` 主体、`WindowsApps`、驱动目录不碰；系统级只走微软官方工具（磁盘清理/DISM/compact），且只做标准安全项（不加 `/ResetBase`）。
3. **个人目录高风险操作必须二次确认。** 桌面/下载/文档/微信文件等，本 skill 一律"搬"而非"删"，且涉及用户资料的类别（回收站、appCache、休眠文件）默认 `confirmed=false`，需用户每次点头。

### 🟡 材料级（影响通过速度与信任）
4. **SKILL.md 必须有清晰 description + 风险标注。** 本版已加 `risk_level: medium`、`requires_consent: true`、`tags`，并写明触发词。
5. **脚本必须"默认安全"。** 所有脚本默认只读/模拟；真正改动要显式开关 + 用户确认。已用 `-Confirmed` 开关 + 默认 DryRun 实现。
6. **禁止写死路径/假设环境。** 原版写死 `D:\`，本版改为 `find_backup_drive.ps1` **自动探测**非 C 盘，找不到则用回收站兜底并提示"不释放空间"。这点对审核很关键（避免"假设用户有D盘导致报错"）。
7. **说明资源占用 / 不常驻。** 在 description 或说明里点明"本地一次性执行，不常驻后台、不上传数据"。
8. **给出"误操作如何恢复"。** 本 skill 的备份目录（`备份_<日期>`）+ 回收站机制即恢复路径，文案要写清。

### 🟢 加分项（提升过审率与口碑）
9. **面向小白的话术。** glossary.md 用大白话解释每类文件，符合"供电脑不精通的人"定位，也是审核喜欢的"负责任"表现。
10. **记忆/习惯机制。** habit.json 让工具越用越懂用户，是差异化亮点，建议在 skill 简介里强调。
11. **双模式设计。** 开荒 + 日常，覆盖"爆满急救"和"长期维护"两场景，定位清晰。
12. **本地化中文 + 合规。** 全中文、不涉及任何敏感内容，符合国内平台要求。
