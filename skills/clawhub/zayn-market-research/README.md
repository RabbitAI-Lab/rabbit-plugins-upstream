# MARKET_RESEARCH() 行业与市场调研

- Skill：`zayn-market-research`
- 用途：在明确边界内研究产业链、需求、技术、竞争、供应、价格、监管、机会与风险。
- 不适用：边界模糊的规模估算或搜索结果摘要。
- 输入：行业/产品、地区、客户、目的、时间、深度、问题。
- 最低条件：产品、地区、时间、客户和用途明确。
- 流程：定义边界→来源计划→交叉验证→结构分析→机会风险。
- 输出：市场结构、趋势、竞争、供应、监管、机会、风险和来源。
- 证据：共享来源、证据、时效和引用规则。
- 协作：下游 competitor-analysis、product-selection、opportunity。
- 示例：研究 2025–2026 年德国中小企业服务器备件市场。
- 版本：v1.0.0
