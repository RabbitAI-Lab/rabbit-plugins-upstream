## Description: <br>
Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to turn REST API documentation requests into practical OpenAPI or Swagger documentation workflows, checklists, analysis, code changes, or implementation support. It is aimed at teams that need API behavior, parameters, and validation criteria to be understandable to other engineers. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad implicit invocation may activate the skill on loosely related API or documentation prompts. <br>
Mitigation: Confirm the user request is about OpenAPI, Swagger, REST API documentation, or a closely related developer-experience task before applying the workflow. <br>
Risk: Generated documentation workflows, checklists, or code suggestions may be incomplete for a specific API stack or schema style. <br>
Mitigation: Validate outputs against the user's stated success criteria, available API source files, and relevant OpenAPI or Swagger tooling before relying on them. <br>
