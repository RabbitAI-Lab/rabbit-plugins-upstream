# powpow-register

Помощник регистрации PowPow (версия для OpenClaw): ведёт нового пользователя от «не знаю, что такое PowPow» до «аккаунт активирован, можно пользоваться» — презентация продукта (со скриншотами интерфейса), пошаговое ведение по регистрации, разбор ошибок, описание активации подписки.

Чисто справочный навык: без скриптов и зависимостей; все действия по регистрации пользователь выполняет сам в браузере / приложении.

## Установка

```
openclaw skills install @durenzidu/powpow-register
```

## Возможности

1. **Презентация продукта**: вступление ~120 знаков + ссылки на скриншоты интерфейса, размещённые в публичном репозитории GitHub (страница карты, страница поста и др. — 6 картинок, отправляйте 1–3 в зависимости от ситуации).
2. **Ведение по регистрации**: правила полей (имя пользователя / пароль / код подтверждения / телефон / аватар), вход через сторонние сервисы (Google / Watcha / Huawei), параметры лимитов — всё взято из кода платформы с указанием источника.
3. **Разбор ошибок**: не приходит код, занятые имя / почта, 403 до активации, заблокированный аккаунт и др. — 13 типовых проблем.
4. **Активация подписки**: описание и диагностика трёх каналов — PayPal (веб) / WeChat скан (ручное подтверждение) / Huawei IAP (HarmonyOS); существующие платёжные пути можно использовать напрямую, навык лишь показывает дорогу.

## Безопасность

- Не содержит ключей; нет скриптов, не касается учётных данных пользователя.
- **Никогда не** просите у пользователя пароль, код подтверждения или платёжные данные; регистрация и оплата полностью выполняются на страницах платформы.
