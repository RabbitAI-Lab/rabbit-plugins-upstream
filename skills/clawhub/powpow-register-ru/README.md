# powpow-register

Помощник регистрации в PowPow Пузырь (издание OpenClaw): проводит нового пользователя от «не знаю, что
такое Пузырь» до «аккаунт активирован, вход в один клик, можно играть» — представление продукта (со
скриншотами интерфейса), делегированная agent'у регистрация (с загрузкой аватара), оформление подписки
через Alipay или PayPal и отслеживание зачисления, вход в один клик по двойной ссылке, разбор ошибок.

**С v2.0.0 — режим делегированного выполнения agent'ом, с v2.1.0 и PayPal**: основной скрипт `scripts/powpow-register.mjs`
без зависимостей (Node ≥ 18), пользователь ни на секунду не выпадает из диалога, кроме двух коротких
выходов: сходить в почту за кодом и оплатить в кассе Alipay или PayPal. Нет Node, или пользователь хочет всё сам —
автоматический откат в режим чистого сопровождения.

## Установка

```
openclaw skills install @durenzidu/powpow-register
```

## Возможности

1. **Представление продукта**: вступление ~120 знаков + встроенные в пакет скриншоты интерфейса
   (`assets/screenshots/`, 6 картинок: страница карты, страница поста и т.д.; по сцене выбирайте 1–3;
   без внешнего хостинга, работает офлайн).
2. **Регистрация делегированно**: agent сам предлагает имя пользователя/ник, пароль на выбор (даёт
   пользователь или генерирует agent), отправка и ввод кода подтверждения, прямая загрузка аватара
   (≤5 МБ, не SVG), автоматическая обработка частых ошибок (занято / истёк / лимит частоты).
3. **Вход в один клик (двойная ссылка)**: сразу после успешной регистрации даётся ссылка «полувхода»
   прямиком на страницу подписки; после зачисления оплаты состояние входа обновляется и выдаётся ссылка
   полного участия прямиком на главную (через официальный мост платформы `me?token=`, автоматически
   сажающий HttpOnly cookie).
4. **Оплата подписки**: и Alipay (месяц ¥6.99 / квартал ¥19.99 / год
   ¥69.99, разовая покупка без автопродления), и PayPal (Premium Monthly, около $1/мес, автопродление, отмена в любой момент) — заказ делегирован agent'у + опрос зачисления;
   QR-код WeChat / Huawei IAP — только показать дорогу.
5. **Разбор ошибок**: не приходит код, имя пользователя/почта заняты, 403 не активирован, блокировка
   аккаунта и другие частые проблемы — всё из исходников платформы, с указанием источников.

## Безопасность

- **Пароль** попадает в процесс скрипта только через переменную окружения, никогда в аргументы командной
  строки, не пишется на диск и не попадает в файл состояния; пароль, сгенерированный agent'ом,
  показывается один раз для сохранения пользователем.
- **Код подтверждения** используется только в официальном интерфейсе регистрации и выбрасывается после
  применения; файл состояния (почта/имя пользователя/token/номер заказа) лежит в системном временном
  каталоге, по завершении потока вычищается одной командой `cleanup`.
- **Оплата**: agent только создаёт заказ, открывает кассу и проверяет зачисление; никогда не касается
  аккаунта Alipay/PayPal пользователя или его платёжных инструментов, никогда не платит за него. Оплата всегда
  происходит между пользователем и официальной кассой.
- Все запросы уходят только на официальный домен `https://global.powpow.online`; никаких ключей в составе нет.
