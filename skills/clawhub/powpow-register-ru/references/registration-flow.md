# Детальный процесс регистрации — powpow-register

Документ для справки при разборе ошибок. Все правила взяты из кода платформы (единая валидация фронтенда и бэкенда на Next.js), с указанием источника. При обновлениях платформы ориентируйтесь на фактическое поведение на сайте.

## Вход

- Страница регистрации: https://global.powpow.online/register
- Страница входа: https://global.powpow.online/login
- Страница подписки: https://global.powpow.online/subscription
- Если пользователь зашёл по ссылке с `?next=...`, после регистрации и оплаты он автоматически вернётся на исходную страницу.

## Поля формы и правила

| Поле | Обязательно | Правило | Источник в коде |
|---|---|---|---|
| Аватар | Нет | Картинка ≤5 МБ, SVG не поддерживается; сервер автоматически сжимает (>100 КБ → 400×400 / качество 90) | `src/app/api/auth/register/route.ts` |
| Имя пользователя | Да | 2–50 символов, после trim хранится в **нижнем регистре** (Tom и tom — одно имя; и регистрация, и вход не различают регистр) | там же (schema zod) |
| Пароль | Да | 8–100 символов, обязательно заглавная буква, строчная буква и цифра | там же |
| Подтверждение пароля | Да | Совпадает с паролем (проверка только на фронтенде) | `src/app/(public)/register/page.tsx` |
| Никнейм | Нет | ≤100 символов; если не заполнен, по умолчанию имя пользователя | register route |
| Почта | **Да** | Корректный формат e-mail, ≤255 символов; одна почта — один аккаунт | register route |
| Код подтверждения | **Да** | 6 цифр; **действует 10 минут**; после успешной проверки аннулируется; повторная отправка помечает старый код как использованный | `src/lib/email-verification.ts` |
| Телефон | Нет | Континентальный китайский номер, начинается с `1[3-9]`, всего 11 цифр; один номер — один аккаунт | register route |

На странице также есть три кнопки входа через сторонние сервисы: **Google, Watcha, аккаунт Huawei** (`GoogleSignInButton` / `WatchaLoginButton` / `HuaweiLoginButton`). У стороннего аккаунта нет локального пароля; при попытке войти по паролю будет сообщение «该账号未设置密码，请使用其他方式登录»（у этого аккаунта не задан пароль — войдите другим способом）.

## Параметры лимитов и защита от перебора

| Действие | Лимит | Источник |
|---|---|---|
| Отправка регистрации | **3 раза/мин/IP**, превышение — 429 | `src/lib/rate-limit.ts` `REGISTER_RATE_LIMIT` |
| Отправка кода подтверждения | 1 раз/мин/IP **и** 1 раз/мин/почта, превышение — 429; у кнопки на фронтенде обратный отсчёт 60 с | `src/app/api/auth/register/send-code/route.ts` |
| Проверка кода | Не более **5 попыток** на почту за 10 минут; при достижении лимита отказ даже с верным кодом — нужно запросить новый | `src/lib/email-verification.ts` |
| Отправка кода при забытом пароле | 1 раз/мин/IP | `src/app/api/auth/forgot-password/route.ts` |
| Вход | 5 раз/мин/IP; **5 неудачных попыток подряд блокируют аккаунт на 30 минут** (423), в процессе показывается убывающее число попыток | `src/app/api/auth/login/route.ts`, `rate-limit.ts` |

**Приватность**: при отправке кода / забытом пароле, независимо от того, зарегистрирована почта или нет, интерфейс возвращает одинаковый текст успеха и не раскрывает, зарегистрирована ли почта.

## Переходы статуса после успешной регистрации

1. Пользователь сохраняется с `accountStatus: 'pending'`, стартовые **3 значка** (register route).
2. Сервер одновременно ставит два HttpOnly cookie: JWT (прямой доступ к `/subscription`) и pendingUserToken (удостоверение в процессе подписки).
3. Страница регистрации обнаруживает `pending_payment` → переход на `/subscription` (сохраняется параметр возврата `next`).
4. После оплаты → `accountStatus` становится `active` (PayPal — автоматическая активация через Webhook; WeChat скан — ручное подтверждение; Huawei IAP — через `activate-huawei`). Подробности — в `payment-and-activation.md`.

Обращения неактивированного (pending) пользователя к основным API (лента, карта, общение с цифровыми людьми, отметки и т.д.) всегда возвращают 403; исключение — ссылки на посты (остаются публично доступными).

## Таблица типовых ошибок

| Сообщение | Причина | Что делать |
|---|---|---|
| 「用户名已存在」 | Имя пользователя занято (без учёта регистра) | Сменить имя пользователя |
| 「邮箱已被使用」 | Почта уже зарегистрирована | Сменить почту; либо войти + «забыл пароль», чтобы восстановить старый аккаунт |
| 「邮箱验证码错误或已过期」 | Код введён неверно / прошло более 10 минут / отказ после 5 ошибок | Нажать «Отправить снова», использовать код из **самого последнего** письма |
| Не приходит код подтверждения | Лимит 60 секунд; или код попал в спам / рассылки | Дождаться конца отсчёта и отправить снова; проверить папку спама |
| 「手机号已被使用」 | Телефон уже привязан к другому аккаунту | Удалить телефон (необязательное поле) или сменить номер |
| 「注册请求过于频繁」/ 429 | Достигнут лимит 3 регистрации/мин/IP | Подождать несколько минут и повторить |
| 409「用户名或邮箱已被注册」 | Совпадение имени с кем-то в момент отправки (страховка от одновременных записей) | Сменить имя или почту и повторить |
| 「图片大小不能超过5MB」/「不支持 SVG」 | Аватар не соответствует правилам | Сменить картинку или пропустить аватар |
| Регистрация прошла, но вход выдаёт 403「请完成订阅以激活账户」 | Аккаунт всё ещё pending | Войти и по подсказке на странице перейти на `/subscription` и завершить подписку |
| Вход 423「账户已锁定」 | Пароль введён неверно 5 раз подряд | Подождать 30 минут |
| Вход 401「还剩 N 次尝试机会」 | Неверный пароль, близко к блокировке | Хорошо подумать перед следующей попыткой или сразу пойти «забыл пароль» |
| 「该账号未设置密码，请使用其他方式登录」 | Аккаунт через сторонний сервис (Google/Watcha/Huawei) | Войти исходной кнопкой стороннего сервиса |
| 「该账号已注销」 | Аккаунт деактивирован (deactivate) | Нужно регистрироваться заново |

## Полезное о входе (заодно для диагностики)

Вход поддерживает ввод **имени пользователя / почты / телефона** (любое из трёх работает как имя аккаунта). Забыли пароль: страница входа → «забыл пароль» → введите зарегистрированную почту, получите 6-значный код → сбросьте.
