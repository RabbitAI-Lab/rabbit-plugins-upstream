# Скриншоты интерфейса продукта — powpow-register

Используются при необходимости в ходе работы. Когда пользователь не знает PowPow или нужно «увидеть», как выглядит готовый продукт, отправьте нужную ссылку.

## Правила ссылок

- Основная ссылка (raw): `https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-0N.jpg`
- Зеркало (если raw не открывается, `N` = 1–6): `https://cdn.jsdelivr.net/gh/durenzidu/durenzidu@main/screenshots/powpow-0N.jpg`
- Картинки лежат в публичном репозитории, их можно отправлять наружу; **не** скачивайте их в папку навыка и не отправляйте локальные пути.
- За раз отправляйте только 1–3 картинки по текущей теме.

## Список

### powpow-01.jpg — Страница цифрового человека

![Страница цифрового человека](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-01.jpg)

Карточка цифрового человека, созданного из реального человека / исторической личности: статус онлайн, место, описание, «начать разговор» и т.д.
**Использовать**: для рассказа «после регистрации можно общаться с цифровыми людьми на карте».

### powpow-02.jpg — Страница редактирования поста

![Страница редактора постов](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-02.jpg)

Редактор поста / путевого журнала, в правом нижнем углу группа плавающих кнопок.
**Использовать**: когда пользователь спрашивает «что я смогу делать после регистрации» / «где писать».

### powpow-03.jpg — Страница карты (пузырьки + цифровые люди)

![Страница карты](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-03.jpg)

Вся публичная карта: посты с геолокацией собираются на карте в виде «пузырьков», цифровые люди приколоты аватарами в реальных местах.
**Использовать**: **главная картинка для презентации продукта** — «ваши путевые заметки превратятся в пузырёк на карте».

### powpow-04.jpg — Личный профиль (цифровые активы)

![Страница профиля](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-04.jpg)

Страница пользователя: друзья / подписки / подписчики, а также «цифровые активы» — баланс значков, мои пузырьки, мои цифровые люди.
**Использовать**: при фразе «при регистрации дают 3 значка» показать, где значки; когда пользователь спрашивает «какие у меня активы».

### powpow-05.jpg — Страница сюжетного прогресса

![Страница прогресса сюжета](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-05.jpg)

Сюжетная механика платформы (пример «永乐·1421»): прогресс глав, заработок значков, ролевая игра.
**Использовать**: «что ещё можно делать кроме постов» / «как зарабатывать значки».

### powpow-06.jpg — Страница поста (готовый пример)

![Страница поста](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-06.jpg)

Опубликованный путевой журнал: автор, метка места, текст, иллюстрации; внизу лайк / комментарий / репост / закладка.
**Использовать**: **вторая картинка на старте** — «именно это увидит человек, когда откроет ваш пузырёк на карте».

## Шпаргалка по ситуациям

| Что говорит пользователь / текущий момент | Какую картинку отправить |
|---|---|
| Начало: «что такое PowPow» | powpow-03 + powpow-06 |
| «Что можно делать после регистрации?» | powpow-02 + powpow-01 |
| «Что за значки / что у меня есть?» | powpow-04 |
| «Что ещё можно делать кроме постов?» | powpow-05 |
| Разбор ошибок регистрации / подписки | обычно картинки не нужны; отправляйте, только если нужно показать, где находится элемент на странице |
