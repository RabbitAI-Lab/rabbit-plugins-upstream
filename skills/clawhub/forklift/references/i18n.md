# 多语言响应模块（中 / 英）

> 本模块自 **v2.4** 起新增。核心规则:**按用户提问语言自动匹配回答语言**,
> 双语资源标签、双语触发词、双语输出模板统一在本文件治理。
>
> 覆盖范围:全部模块（品牌/选型/故障/标准/销售/招投标/图表）。

---

## 一、核心规则（**第一硬规则**）

```
用户用中文提问 → 全程中文回答（含表格表头、图表标题、字段名、注释）
用户用英文提问 → 全程英文回答（含表格表头、图表标题、字段名、注释）
用户中英混用   → 以"主要叙述语言"为准
用户明确指定   → 以用户指定为准（"用英文答""switch to Chinese"）
```

### 1.1 语言识别规则

| 输入特征 | 判定 | 输出 |
|----------|------|------|
| 全中文 / 中文为主（中文占比 > 60%） | 中文 | 简体中文 |
| 全英文 / 英文为主（英文占比 > 60%） | 英文 | English |
| 中英各半 | 看**句式主干**语言 | 主干语言 |
| 仅品牌名/型号（如 "Hangcha XE25"） | 视为英文 | English |
| 仅中文品牌名（如 "杭叉 XE25"） | 视为中文 | 简体中文 |
| "forklift 怎么选" | 中文为主 | 简体中文 |
| "How to choose 叉车" | 英文为主 | English |

### 1.2 不可切换项（**无论何种语言都必须保留**）

以下内容**永远保持原样**,不翻译、不转写:

1. **标准编号**:`GB/T 43756-2024`、`ISO 23308`、`EN 1757` 等（编号本身不变）
2. **品牌原名**:`Hangcha`、`Anhui Heli`、`BYD Forklift`、`Linde`、`Toyota`
3. **型号**:`XE25`、`CPD30`、`8FBE15`、`K2` 等
4. **公司/股票代码**:`600761.SH`、`603298.SH`、`KION.DE`
5. **单位符号**:`t`、`mm`、`kW`、`V`、`Ah`、`MPa`
6. **版权行**:`Copyright (c) 2026 杨鹏飞` 与署名 `杨鹏飞 / 叉车技术老炮`
7. **URL 与文件路径**

> 中文回答可用中文量词（"3 吨"）;英文回答用英文单位（"3 t"）。

## 二、语言切换触发词

### 2.1 切到英文
- "answer in English"、"in English please"、"switch to English"
- "用英文回答"、"英文版"、"给我英文的"、"英语输出"
- 用户提问本身为英文

### 2.2 切到中文
- "用中文回答"、"切回中文"、"中文版"、"answer in Chinese"
- "中文再讲一遍"、"换成中文"

### 2.3 双语输出（显式请求才做）
- "中英对照"、"双语"、"中英文都要"、"bilingual"
- → 输出方式:**段落级双语**优先（中文段落 + 英文段落并列）,
  而非句内混排。表格用**双列表头**（"销量 Sales"）。

> ⚠️ 未显式要求双语时,**不要**主动输出双语,会增加噪音、拉长篇幅。

### 3.5 词表使用规则

- 术语表中**未收录**的名词 → 优先直译 + 首次出现时括注中文原名
- **不造词**：不把"浮动踏板"新造为 "floating pedal" 后又混用 "suspended pedal"
  （本表以 `suspended pedal` 为准,首次出现可括注 floating pedal）
- **单位换算**：英文回答中可保留 SI 原单位,不强制转英制;若用户用磅/英尺,
  则同时给出 SI 换算值

| 模块 | 中文版要点 | 英文版要点 |

## 五、输出模板的双语示例

### 5.1 中文（默认）

```
场景:冷库室内作业,货架 6m,通道 2.8m
建议:
- 吨位:1.5-2 t
- 动力:锂电（LFP,带低温加热）
- 类别:ISO Class II 前移式
- 品牌带:比亚迪 / 杭叉 XE / 丰田 8FBE
- 预算:18-28 万元（单台参考）
- 风险点:低温充电效率,LFP 选带加热版
参考:selection-guide.md 第 X 节
```

### 5.2 英文（用户用英文提问时）

```
Scenario: Cold-storage indoor operation, 6 m racking, 2.8 m aisle
Recommendation:
- Capacity: 1.5-2 t
- Power: Li-ion (LFP, with low-temperature heating)
- Class: ISO Class II reach truck
- Brand shortlist: BYD / Hangcha XE / Toyota 8FBE
- Options: fully enclosed cabin + anti-condensation heater
- Budget: CNY 180k-280k per unit (reference only)
- Risks: low-temperature charging efficiency; choose the heated LFP variant
Reference: selection-guide.md, section X
```


## 六、硬规则（给 LLM 的执行约束）

1. **语言匹配是默认行为**,不需要用户显式要求。
2. **语言一致性要贯穿全文**:标题、表格表头、图表标签、脚注、免责声明
   全部同语言。**禁止**中文正文配英文表头（除非用户要求双语）。
3. **不可切换项**（标准号/品牌/型号/股票代码/版权行）永远保持原形。
4. **不主动双语**:除非用户明确要求,不做中英对照输出。
5. **术语一致性**:同一回答内同一概念只用一种译法,按第三节术语表。
6. **英文回答同样遵守全部硬规则**:不编造参数、不报价、销售必联网、
   招投标必带链接、图表默认 SVG。
7. **数据时点**:英文回答的日期格式用 `YYYY-MM-DD`,不写 `Sep 12, 2026`
   与 `2026-09-12` 混用。
8. **诚实优先**:若某模块资料仅中文,英文回答中如实说明
   （"Detailed standards text is available in Chinese only; the summary below is translated."）
9. **不降低精度**:英文回答不得因翻译而省略关键参数或免责声明。
10. **版权行保留原文**:`资料来源:杨鹏飞/叉车技术老炮维护的 forklift-expert`
    在英文回答中也保持中文署名,可后附英文说明。

## 七、边界与已知局限

| 局限 | 说明 | 处理 |
|------|------|------|
| 数据源多为中文 | 国内标准、协会公报以中文为主 | 英文回答下如实标注来源语言 |
| 英文资料覆盖差 | 国内品牌英文型号资料少 | 型号保留原文,不做音译 |
| 单位习惯差异 | 用户可能用英制 | 用户用英制则双单位并列 |
| 术语存在多译 | 如"前移式"有 reach truck 等 | 以本文件术语表为准 |
| 图表字体 | SVG 用系统字体栈 | 不引外部字体,保证离线可渲染 |
