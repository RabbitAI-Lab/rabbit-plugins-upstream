# 叉车招投标信息播报模块（周度汇总 · HTML 交付）

> 本模块自 **v2.4** 起新增。当用户咨询**叉车招投标信息**时激活,
> 自动以**提问日所在自然周**为数据窗口,联网汇总一周内的招标/中标/开标/废标信息,
> 最终交付一份 **自包含 HTML 播报页**（可离线打开、可转发）。
>
> 数据基准:**实时联网检索**。本地库不存招投标数据（时效性 < 7 天,无缓存价值）。

- "招标信息"、"投标信息"、"中标公告"、"开标公告"

- "最近叉车采购"、"叉车采购公告"、"叉车询价"
- "电叉招标"、"锂电叉车采购"、"AGV 招标"、"立体库叉车采购"
- "某单位叉车采购中标结果"

## 二、核心时间规则（**本模块第一硬规则**）

> **数据窗口 = 提问日所在那一周（自然周,周一 00:00 至周日 23:59）**

```
提问日 2026-09-12(周六) → 数据窗口 2026-09-07(周一) ~ 2026-09-13(周日)
提问日 2026-09-15(周二) → 数据窗口 2026-09-14(周一) ~ 2026-09-20(周日)
```

**边界规则**：

| 情况 | 处理方式 |
|------|----------|
| 本周信息量 ≥ 3 条 | 只播报本周 |
| 本周信息量 < 3 条 | 本周为准,**另起"上周补充"小节**并标注窗口日期 |
| 本周 0 条 | 如实说明"本周暂未检索到",再给上周补充 + 建议关注渠道 |
| 用户指定"本周/上周/本月" | 以用户指定为准,但**仍以自然周粒度**组织 |
| 用户指定具体日期区间 | 按用户区间,并在报告头标注实际窗口 |
| 提问日为周一且当天数据极少 | 允许扩展到"近 7 天滚动窗口",须显式标注 |

> ⚠️ **禁止**:不给窗口日期就播报（每条播报必须能在报告头看到起止日期）。
> ⚠️ **禁止**:把上月数据混进本周窗口而不标注。

## 三、模块工作流（五段式）

```
┌──────────────────────────────────────────────────────────┐
│ 段 0：锁定周窗口                                          │
│  ├─ 取提问日 → 推导本周一/周日                            │
│  └─ 报告头写明：数据窗口 YYYY-MM-DD ~ YYYY-MM-DD          │
└──────────────────────────────────────────────────────────┘
                          ↓
┌──────────────────────────────────────────────────────────┐
│ 段 1：多渠道联网检索                                      │
│  ├─ 政府采购网、公共资源交易中心、招标信息聚合平台           │
│  ├─ 中国招标投标公共服务平台、企业自主采购平台(e 采等)       │
│  ├─ 关键词组合：叉车 / 电叉 / 锂电叉车 / 平衡重 / 前移式 /   │
│  │  堆高车 / AGV / 工业车辆 / 电动搬运车 + 招标/中标/采购   │
│  └─ 至少 2 个独立来源交叉验证；查不到就如实说"未检索到"      │
└──────────────────────────────────────────────────────────┘
                          ↓
┌──────────────────────────────────────────────────────────┐
│ 段 2：信息清洗与分类                                      │
│  ├─ 按类型分：招标公告 / 中标结果 / 开标记录 / 变更澄清 /   │
│  │  流标废标 / 询价采购                                   │
│  ├─ 按车型分：平衡重 / 前移式 / 堆高车 / AGV / 特种(防爆、  │
│  │  冷库、越野) / 混编包                                  │
│  └─ 按金额分：< 50 万 / 50-200 万 / 200-1000 万 / > 1000 万│
└──────────────────────────────────────────────────────────┘
                          ↓
┌──────────────────────────────────────────────────────────┐
│ 段 3：结构化汇总                                          │
│  ├─ 统计：条数、总预算/中标额、平均单台价、区域分布          │
│  ├─ 关联：同一项目的"招标→中标"链路合并展示                 │
│  └─ 预警：本周截止的关键时间点（投标截止/开标日）            │
└──────────────────────────────────────────────────────────┘
                          ↓
┌──────────────────────────────────────────────────────────┐
│ 段 4：HTML 交付                                          │
│  ├─ 生成自包含 HTML（内联 CSS + 内联 SVG,零外部依赖）       │
│  ├─ 移动端适配（viewport + 响应式表格/卡片）                │
│  ├─ 写入 /workspace 并 present_files 交付                  │
│  └─ 同时在对话里给"文字版要点"（3-6 条高信号摘要）           │
└──────────────────────────────────────────────────────────┘
```

## 五、字段规范（每条信息必填）

| 字段 | 必填 | 说明 | 缺失处理 |
|------|------|------|----------|
| 项目名称 | ✅ | 原文标题,不改编 | 无则不入库 |
| 发布日期 | ✅ | 公告发布日 YYYY-MM-DD | 无则标"未标注" |
| 类型 | ✅ | 招标/中标/开标/变更/废标 | 从标题判定 |
| 采购单位 | ✅ | 招标人全称 | 无则标"未公开" |
| 项目地点 | ✅ | 省-市 | 无则"未公开" |
| 采购内容 | ✅ | 车型 + 数量（如"3 吨锂电平衡重 ×12 台"） | 无则原文括注 |
| 预算/中标额 | ⭕ | 万元,原文口径 | 无则"未公开" |
| 中标单位 | ⭕ | 仅中标类 | 无则"未公示" |
| 关键时间 | ⭕ | 投标截止 / 开标日 | 无则"以公告为准" |
| 来源 | ✅ | 平台名 + 链接 | **无链接不入库** |
| 检索日期 | ✅ | 报告头统一标注 | — |

> **硬约束**：任何一条信息**必须带可点击来源链接**。无源不收录。
> 宁可少报 3 条真实信息,不凑 10 条来源不明的。

## 六、输出模板（HTML 报告结构）

HTML 页面按以下区块组织（**顺序固定**）：

```
1. 报告头
   - 标题：叉车招投标信息播报
   - 数据窗口：YYYY-MM-DD ~ YYYY-MM-DD（第 N 周）
   - 检索日期、生成时间
   - 条数徽章（招标 x 条 / 中标 y 条 / 其他 z 条）

2. 本周速览（核心数据卡）
   - 公告总数 | 总预算规模 | 最大单笔 | 覆盖省份数
   - 用 SVG 条形图展示"区域分布"或"金额区间分布"

3. 重点推荐 TOP 3（橙色高亮卡）
   - 金额最大 / 数量最多 / 截止最急
   - 每张卡：项目名 + 单位 + 台数 + 金额 + 关键时间 + 链接

4. 招标公告清单（表格）
   - 项目名称 | 采购单位 | 地区 | 车型/数量 | 预算 | 投标截止 | 来源

5. 中标结果清单（表格）
   - 项目名称 | 采购单位 | 中标单位 | 中标额 | 中标日期 | 来源

6. 变更 / 澄清 / 废标（如有）
   - 只列与在办项目相关的,避免噪音

7. 时间预警（本周必盯）
   - 未来 7 天内截止的投标 → 按截止时间升序

8. 趋势观察（可选,信息量够时）
   - 本周 vs 上周条数对比
   - 车型偏好、区域热度

9. 数据来源与免责
   - 来源平台清单 + "以官方公告为准"声明
   - 作者版权行
```

## 七、HTML 交付技术规范

### 7.1 硬性要求

| 要求 | 说明 |
|------|------|
| **零外部依赖** | ❌ CDN、外链 CSS/JS、外链字体、外链图片 全部禁止 |
| 内联 CSS | `<style>` 标签写在 `<head>` 内 |
| 内联 SVG | 图表直接写 `<svg>`,不引外部图片文件 |
| 中文编码 | `<meta charset="utf-8">` |
| 移动端适配 | `<meta name="viewport" content="width=device-width, initial-scale=1">` |
| 响应式 | 表格在窄屏改为卡片堆叠（媒体查询 `max-width: 640px`） |
| 可离线 | 双击文件即可打开,断网功能完整 |
| 可转发 | 单文件,微信/邮件可直接发 |

### 7.2 视觉规范

```
主色        深蓝 #1a2a4a   （标题、表头、正文强调）
强调色      橙   #ff6b35   （重点卡、关键数字、柱状图首名）
成功/中标   绿   #2e7d32
警告/截止   红   #d32f2f
次要文字    灰   #6b7280
边框/分隔   浅灰 #e5e7eb
背景        白   #ffffff / 浅灰底 #f9fafb

字体栈  -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif
圆角    8px（卡片）/ 4px（标签）
阴影    0 1px 3px rgba(0,0,0,.08)
```

### 7.3 移动端适配要点

```css
@media (max-width: 640px) {
  table, thead, tbody, th, td, tr { display: block; }
  thead { display: none; }
  tr { border: 1px solid #e5e7eb; border-radius: 8px; margin-bottom: 12px; padding: 10px; }
  td { border: none; padding: 6px 0; }
  td::before { content: attr(data-label); font-weight: 700; color: #1a2a4a; display: block; font-size: 12px; }
}
```

> 每个 `<td>` 必须带 `data-label="字段名"`,否则窄屏卡片会丢失字段含义。

### 7.4 文件命名与落盘

```
文件路径：/workspace/叉车招投标信息播报_YYYY-MM-DD.html
（日期取"提问日",便于归档排序）

交付方式：写入 /workspace → 调用 present_files 展示
```

## 八、硬规则（给 LLM 的执行约束）

1. **必须锁周窗口**：报告头必须写明本周一~周日日期,无窗口不播报。
2. **必须联网**：不许凭印象编造招标项目名称、金额、单位名。
3. **必须有链接**：每条信息带可点击来源链接,无源不收录。
4. **必须交付 HTML**：不是 Markdown 私信了事,必须生成 `.html` 文件并 present。
5. **必须零依赖**：HTML 断网可开,不引任何 CDN。
6. **必须移动端适配**：viewport + 响应式表格。
7. **必须标检索日期**：报告头 + 页脚双标。
8. **必须区分类型**：招标 / 中标 / 变更 / 废标 分组,不混排。
9. **不编造金额**：原文没写金额就标"未公开",不估算、不推测。
10. **不合并项目**：不同项目不合并成一条,同一项目招标+中标可分链路关联。
11. **辟谣：不做投标承诺**：不给"这个标能中""建议报 xx 价"这类结论。
12. **信息不足要诚实**：本周确实没搜到,就写"本周暂未检索到公开信息",
    并给替代渠道与上周参考,不要凑数。
13. **不做虚假实时**：不使用"实时监控""自动抓取中"等误导表述。
14. **版权保留**：页脚标注"资料来源:杨鹏飞/叉车技术老炮维护的 forklift-expert"。

## 十、不在范围内

- 帮用户写投标文件、技术方案 → 超出本模块,提示走标书/方案类技能
- 报价策略、围标串标等违规建议 → **明确拒绝**
- 未公开的内部招标信息 → 只能引公开渠道
- 预测谁中标 → 不做
- 供应商黑名单/资质评价 → 无权威数据支撑,不做
- 非叉车类招标（土建、IT、办公用品）→ 不触发本模块,除非用户明确要求

## 十二、版本与更新

- 模块版本:**v1.1(2026-09)**

- 数据刷新:**每次提问实时联网**,不缓存
