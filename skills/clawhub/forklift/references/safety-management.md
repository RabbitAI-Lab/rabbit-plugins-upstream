# 第一部分：周期性彻底检验制度

## 一、什么是"彻底检验"（Thorough Examination）

与日常检查、预防性维护不同，彻底检验是由**胜任人员（competent person）**执行的系统性检验，目的是发现 deterioration（劣化）并判断其是否会导致危险状态。

| 对比项 | 日常/使用前检查 | 预防性维护 | 彻底检验 |
|-------|---------------|-----------|---------|
| 执行人 | 操作员 | 维修人员 | 胜任人员 |
| 频次 | 每班 | 按小时/月 | 法定周期 |
| 性质 | 目视 + 功能确认 | 保养更换 | 系统性判定 + 出具报告 |
| 输出 | 检查表 | 维修记录 | **书面报告（法定）** |

## 二、必须检验的时点

1. **首次投入使用前**——除非设备全新且持有 12 个月内签发的合格声明（EC declaration of conformity），或从其他方接收时随附了上次检验的物证
2. **安装后、首次使用前**（安全依赖安装条件的设备）
3. **在新场地/新位置组装后、投入使用前**
4. **周期性检验**（见下节）
5. **异常情况发生后**——任何可能危及设备安全的事件（碰撞、超载、倾翻、改装、长期停用、极端环境暴露）

## 三、检验周期

| 设备类型 | 最长检验间隔 |
|---------|------------|
| 用于**提升人员**的设备或提升附件 | **至少每 6 个月** |
| 其他起重设备 | **至少每 12 个月** |
| 采用**书面检验方案**（examination scheme）的 | 按方案规定的间隔，可长于或短于上述值 |

> 检验方案由胜任人员制定，依据缺陷产生的风险水平确定间隔。
> 上述周期为**上限**，不是推荐值。

## 四、胜任人员（Competent Person）

- 须具备被检设备足够的**实践与理论知识及经验**，能发现缺陷与薄弱点，并判断其对安全与继续使用的影响
- 须**独立且公正**，可来自外部机构，也可来自企业内部
- 内部人员须有真实授权与独立性，能不受干扰地作出建议
- **原则：执行彻底检验的人，通常不应是执行该设备日常保养的人**——避免自己检验自己的作业
- 若确由同一人承担（仅限对他人伤害风险低的场合），须在风险评估中说明决策过程，且**保养应在检验完成之后**进行

## 五、检验报告必备内容

一份完整报告至少包含：

| # | 内容 |
|---|------|
| 1 | 设备识别信息（含唯一编号、位置） |
| 2 | 上次彻底检验的日期 |
| 3 | 安全工作载荷（SWL）；若随配置变化，则记录检验时最后配置的 SWL |
| 4 | 安装/新址组装后首次检验：声明为该类检验，并说明是否安装正确、可否安全运行 |
| 5 | 其他检验：声明属于 6 个月 / 12 个月 / 按方案 / 异常后 哪一类，并说明可否安全运行 |
| 6 | 发现的缺陷：识别出有缺陷或可能成为危险的部件，并描述缺陷 |
| 7 | 为消除危险所需的修理、更换或改装事项 |
| 8 | 对"尚未成为但可能成为危险"的缺陷：预计成为危险的时限 + 所需修复措施 |
| 9 | 下次彻底检验的最晚日期 |
| 10 | 若含测试：测试详情 |
| 11 | 检验日期 |
| 12 | 报告人姓名、地址、资质；是否自雇，若受雇则雇主名称地址 |
| 13 | 代表报告人签署者的姓名与地址 |
| 14 | 报告日期 |

## 六、缺陷报告

- 发现缺陷应**尽快（as soon as practicable）**书面报告给设备使用控制方，必要时同时报告出租方/承租方
- 存在** imminent risk（ imminent = 紧迫危险）**的缺陷，须约定专门的沟通方式
- 若修复在检验后立即完成，报告中仍须记录缺陷与修复情况

## 七、记录保存期限

| 记录类型 | 保存期限 |
|---------|---------|
| 合格声明（EC declaration） | 操作该设备期间全程保存 |
| 首次投入使用前检验报告 | 直至停止使用该设备 |
| 提升附件的首次检验报告 | 报告作出后 2 年 |
| 安装/新址组装后检验报告 | 直至在该地点停止使用 |
| 周期性检验报告 | 直至下次报告作出，或 2 年，**孰晚** |
| 检查记录 | 直至下次记录作出 |

- 可纸质或电子保存；电子系统须防止未授权篡改，并能输出书面副本
- 通常存放在设备使用场所；空间或安全受限时可异地存放，但须易于调取且位置为控制方所知
- **可延长保存**：有助于识别重复缺陷或磨损趋势时，宜长期保留并定期回顾

## 八、转移与流转

- 设备**离开企业**（出售、出租、转场）时，须随附上次彻底检验已完成的**物证**
- 从他方**接收**的设备，无该物证不得投入使用

# 第二部分：设备风险管理流程

## 一、四步循环

```
识别危害 → 评估风险 → 控制风险 → 维护与复查控制措施
     ↑                                          │
     └──────────────────────────────────────────┘
```

### 1. 识别危害
- 全生命周期巡查：采购 → 安装 → 使用 → 变更 → 检查 → 维护保养 → 存放 → 退役
- 关注移动设备、起升设备、动力传动、高压电、储能元件、噪声与振动

### 2. 评估风险
考虑：伤害可能性、后果严重度、暴露频次、现有控制措施有效性

### 3. 控制风险（见下节层级）

### 4. 维护与复查
- 控制措施须**随时间保持有效**
- 定期复查确认按预期运行

## 二、控制措施层级（Hierarchy of Controls）

**必须自上而下逐级考虑，不能跳级。**

| 层级 | 措施 | 叉车/起重场景示例 |
|------|------|-----------------|
| **1. 消除** | 消除风险源 | 把物件设计成可在使用点直接搬运的尺寸/重量/形状，从而不需要起重设备 |
| **2. 替代** | 用低风险方案替换 | 用输送系统替代叉车运送物料（注意：引入输送机的新风险，须使总风险下降） |
| **3. 隔离** | 把危害与人隔开 | 混凝土隔离墩把移动设备与行人分开；人车分流通道 |
| **4. 工程控制** | 物理控制手段 | 超速自动制动；防碰撞联锁；**联锁防护罩**；超载限制器；倾翻保护结构 |
| **5. 行政控制** | 制度与程序 | 挂牌制度确保维护期间设备断电；限速规定；作业许可；培训与监督 |
| **6. PPE** | 个体防护 | 安全帽、防护眼镜、手套、高能见度服装 |

> **关键原则**：行政控制与 PPE **不从源头控制危害**，依赖人的行为与监督，单独使用时效果最差。
> 工程控制优先于行政控制，这是设计与选配时的判断依据。

## 三、全生命周期控制点

| 阶段 | 控制要点 |
|------|---------|
| 采购与租赁 | 明确设计用途；索取计算/分析/测试/检验结果；索取安全使用条件；核对防护装置与警示装置 |
| 安装调试 | 按制造商要求安装；调试后验证；保留安装检验报告 |
| 使用 | 按设计用途使用；不得超载；不得用于设计外用途 |
| 变更 | **任何改动都需重新评估风险**；改装后可能需重新检验 |
| 检查 | 按周期检查；异常情况后补检 |
| 维护保养与清洁 | 隔离能量源后再作业；按制造商周期 |
| 存放 | 防止未经授权使用；防倾倒；防环境劣化 |
| 退役拆解处置 | 释放所有储能；按流程销毁或转让并移交资料 |

## 四、设计方与供应链的信息传递义务

设计方、制造商、进口商、供应商须向下游逐级传递：

1. 设备的设计或制造**用途**
2. 计算、分析、测试或检验的**结果**
3. **安全使用的必要条件**

> 这条对整机厂与零部件供应商都有约束力：出口机型的技术文件包必须包含上述三类信息。

## 五、能量隔离与上锁挂牌（LOTO）

**上锁（lock-out）是最有效的隔离程序。** 挂牌（tag-out）不能单独作为隔离手段——只有锁能真正隔离。

### 标准八步

1. 停机（shutdown）
2. 识别**所有**能源与其他危害
3. 识别**所有**隔离点
4. 隔离所有能源
5. **控制或释放所有储存能量**
6. 对所有隔离点上锁
7. 对设备控制、能源与危害点挂牌
8. **试启动验证**（在不使测试者或他人暴露于风险的前提下尝试重启）

### 关键警告

> **试启动失败只能说明主电源已隔离，不代表所有储能已释放。**
> 必须另外采取措施安全释放：
> - 液压压力
> - 气压
> - 悬挂重物（如门架、货叉、属具自重）
> - 压缩弹簧

### 能源清单（须逐一排查）

电力（ mains / 电池）、液压、气压、重力/悬挂负载、弹簧储能、动能（飞轮、惯性）、化学品、热能、辐射

### 锁具管理
- 每个隔离点一把锁，钥匙唯一，**不得有重复钥匙**（除专人保管的备用钥匙）
- 允许多人同时作业时，使用多孔锁具（lock box / hasp），每人一锁
- 每把锁对应唯一标签与钥匙

## 六、相关标准体系（索引）

| 体系 | 覆盖环节 |
|------|---------|
| AS/NZS 2359 系列（工业叉车） | 设计 / 制造 / 使用 全环节 |
| ISO 5053-1 / GB/T 6104.1 | 工业车辆分类 |
| GB/T 10827 系列 | 稳定性与验证 |

# 第三部分：叉车作业现场管理

## 一、设备侧

| 措施 | 要求 |
|------|------|
| 预防性维护计划 | 建立并执行，确保设备持续处于良好状态 |
| 使用前检查 | 操作员按清单执行系统化、彻底的班前检查 |

## 二、人员与作业侧

| 措施 | 要求 |
|------|------|
| 持证上岗 | 只指派**完成相应培训并持有有效证书**的人员操作叉车 |
| 安全作业程序（SWP） | 为**每一项**叉车作业活动制定，并传达至操作员 |
| 钥匙管控 | 钥匙存放于**上锁的钥匙柜**，只发给授权操作员；用后归还；**不得留置在点火开关上** |
| 安全带 | 操作员就座后必须系好安全带 |
| 用途限制 | 只用于设计用途（搬运托盘/起升放置在货物上的载荷）；**严禁用于载运人员** |
| 现场监督 | 设监督人员确保作业按 SWP 执行 |

> **严禁用货叉或临时板件载人**。确需高处作业，必须使用与叉车匹配的**专用作业平台**（非集成式工作平台），并按规定固定。
> 伸缩臂叉车属叉车的一个特殊类型，**严禁当作起重机使用**，不得用吊钩或绳索从臂端吊运。

## 三、作业场所：交通管理计划（TMP）

须建立并实施交通管理计划，典型要素：

| 要素 | 说明 |
|------|------|
| 限速 | 叉车作业区设置限速标识并标明限速值 |
| 出入口隔离 | 作业区出入口设置**安全护栏**并配适当标识 |
| 盲区观察 | 转角、交叉口等战略位置设置**凸面镜** |
| 人车分流 | 叉车与行人路线**分离并清晰标识**；行人通道设**物理隔离**，防止人员进入叉车路径 |
| 照明 | 作业区照度充足 |

## 四、高风险场景专项

| 场景 | 要点 |
|------|------|
| 用属具夹持圆桶等圆形物件 | 须使用专用夹具（如桶夹），不得仅靠货叉夹持 |
| 转弯（尤其带起升载荷） | 减速；注意后摆与横向稳定性 |
| 特种设备（防爆、冷库） | 须原厂件 + 有资质人员维护 |
| 长期租赁 | 出租方可代为执行彻底检验，但**不转移使用方的法定义务** |
| 二手设备流转 | 必须随附上次彻底检验的物证 |

## 附：与国内体系的对照提示

| 议题 | 国内常见做法 | 海外体系强调点 |
|------|------------|--------------|
| 定期检验 | 特种设备法定检验（按 TSG 要求） | 彻底检验由独立胜任人员执行 + 书面报告 + 保存期限明确 |
| 检验独立性 | 常由维保单位一并出具 | 强调检验与维护人员分离 |
| 风险控制 | 侧重于操作规程与培训 | 强调**工程控制优先于行政控制**的层级顺序 |
| 能量隔离 | 挂牌较多 | 强调**上锁**唯一有效，挂牌不可单独使用 |
| 人车管理 | 车间划线为主 | 强调交通管理计划 + 物理隔离 |

> 出口机型做安全设计时，按海外体系的严格口径准备，通常可同时满足国内要求。
