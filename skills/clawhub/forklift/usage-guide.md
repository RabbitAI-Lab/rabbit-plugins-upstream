# Forklift Expert Usage Guide

## Start here
Keep the full skill folder together. `SKILL.md` is the entrypoint; supporting Markdown files contain focused workflows. Documentation is English. Responses can still follow the user's requested language using `i18n.md`.

Read the applicable safety guidance, choose the primary module, and normally add only one or two supporting modules. Charts and language handling are cross-cutting. Current laws, model specifications, sales figures and procurement notices require current primary evidence when research tools are available. If tools are unavailable, disclose that limitation and avoid claiming live verification.

## Standard workflow
1. Confirm the user's objective, jurisdiction, truck type and important missing constraints.
2. Read the primary module and supporting references.
3. Gather evidence from official, regional sources where needed; preserve source dates and uncertainty.
4. Apply the relevant output template. Separate source facts from engineering advice.
5. Add a chart only when it helps; retain the underlying table.
6. Apply a final style and factual-consistency pass.

## Example requests
- "Compare forklift brands available in the UK": use brands and international markets; verify regional service and product availability.
- "Select a truck for a cold store": use selection and model retrieval. Ask for temperature, load, load centre, lift height, aisle and duty cycle; do not invent a model, capacity or price.
- "Summarize US forklift sales": use sales and international sources. Distinguish shipments from revenue and disclose the reporting window.
- "Is this standard current?": use standard retrieval and the relevant jurisdiction. Verify edition, amendments, effective dates and legal relevance.
- "The truck will not lift": use after-sales and fault diagnosis. Capture make, model, serial, symptoms and codes; isolate hazardous equipment before qualified inspection.
- "Create an SVG comparison": use the source table and chart module. Mark fictional examples clearly.
- "Answer in English": use English prose while preserving exact technical identifiers.
- "Prepare this week's tender bulletin": use tender broadcast and international procurement sources; deliver self-contained HTML and state the research cut-off.
- "Record the repair result": archive only a real reported outcome; if writing is unavailable, return an unsaved draft and say so.

## Integration and limitations
Install or copy the entire folder rather than the entrypoint alone. In a file-reading assistant, load relevant references directly. In retrieval systems, preserve headings, tables and source context; avoid fragments that detach numbers from their definitions. These instructions are runtime guidance, not a requirement to train a model.

Do not fill specifications from memory, manufacture sources, claim unavailable tools ran, or claim a file was saved without checking it. Keep market boundaries, dates and legal jurisdictions explicit. Manufacturer documentation and applicable local law take precedence over generic examples.
