# 叉车标准检索模块（联网版）

> 本模块在标准问答场景触发,提供"本地知识库 + 联网实时检索"双轨能力。
> 当 `../standards.md` 已覆盖的标准即可直接回答;当涉及**最新状态、具体条款、
> 未在本地库收录的标准、或用户明确要求"查一下"**时,必须联网检索后作答。
> 更新基准:2026-06;联网检索结果以官方原文为准。

---

## 一、何时激活本模块

满足以下任意一条即进入联网检索流程（在读完 `standards.md` 之后）:

1. **指定标准号但本地库无记录**:例如 `GB/T 4xxxx-2026`、`ISO 5053-3`、`EN 1xxxx` 等
2. **确认状态/时效**:用户问"这个标准还现行吗""有没有被替代""哪天实施"
3. **最新动态**:用户问"2026 年新出了什么叉车标准""最近有什么标准征求意见稿"
4. **标准具体内容/条款**:用户问"GB 38031-2025 对热失控怎么要求的""ISO 23308 试验循环怎么跑"
5. **标准下载/获取渠道**:用户问"在哪能看全文""哪里能买到正版"
6. **模糊检索**:用户只给关键词(如"叉车 防爆 标准""锂电叉车 运输"),需反查标准号

> 若仅问本地库已明确收录、状态稳定的标准(如 GB/T 43756-2024 的名称/状态),
> 可直接用 `standards.md` 回答,不必联网;但涉及"最新/是否已更新"一律联网确认。

## 二、在线检索权威数据源（优先级排序）

| # | 数据源 | 用途 | 链接 / 检索方式 |
|---|------|------|------|
| 1 | **国家标准全文公开系统** | GB / GB/T 在线预览、确认状态与实施日期 | `openstd.samr.gov.cn` → 输入标准号检索 |
| 2 | **全国标准信息公共服务平台** | 标准公告、代替关系、征求意见稿 | `std.samr.gov.cn` → 标准号 / 关键词检索 |
| 3 | **工标网** | GB / 行标 / 团标一站式检索、替代关系 | `www.csres.com` → 标准号 / 名称检索 |
| 4 | **SAC/TC 332 全国工业车辆标委会** | 叉车国标归口、立项/报批动态 | 中叉网"标讯" `www.chinaforklift.com` 转述 |
| 5 | **ISO 在线浏览** | ISO 标准状态、英文原题名 | `www.iso.org` → search standard number |
| 6 | **中国标准服务网** | 已发布标准购买/下载 | `www.cssn.net.cn` |
| 7 | **品牌官网 / 行业协会** | 标准落地口径、企业解读 | 见 `brands.md` |

> ⚠️ 公众号"叉车技术老炮"可作背景,**不可作为标准状态/条款的唯一来源**(数据源不稳定)。

## 三、联网检索流程（给 LLM 的执行步骤）

```
步骤 1  本地定位
  └─ 先读 standards.md,确认该标准是否已收录、状态是否明确
  └─ 若已收录且用户仅问名称/状态 → 直接答,注明"本地库基准 2026-06"

步骤 2  联网确认（以下任一情形必须执行）
  ├─ 情形 A 已知标准号 → 用该号在 数据源 1/2/3 检索,确认:
  │     状态(现行/废止/未实施)、实施日期、是否已被替代(代替关系)
  ├─ 情形 B 模糊关键词 → 用关键词在 数据源 3(工标网) 反查标准号,
  │     再走情形 A 的确认步骤
  └─ 情形 C 问具体条款 → 优先 数据源 1 看公开预览/摘要;
        不足则用 数据源 7(品牌/协会解读) 交叉验证

步骤 3  交叉验证（硬规则）
  └─ 状态、实施日期、代替关系至少 2 个独立来源一致方可下结论
  └─ 来源冲突或查不到 → 如实告知"未能在公开渠道确认",不编造

步骤 4  输出（见下方"输出模板"）

步骤 5  版权与免责
  └─ 回答中标注:资料来源:杨鹏飞/叉车技术老炮维护的 forklift-expert
  └─ 不提供标准全文付费下载链接,引导到官方渠道
```

```

"<标准号> 代替 <旧标准号>"

# 按关键词反查标准号

# 查最新 / 征求意见

```

```

名称:xxx
状态:现行 / 废止 / 未实施（联网核验日期:YYYY-MM-DD）
实施日期:xxxx-xx-xx
代替关系:代替 GB/T xxxx-xxxx / 被 GB/T xxxx-xxxx 代替（如有）
关键内容:xxx（条款级要点,联网检索补充）
适用:xxx

【在线核验来源】
- 国家标准全文公开系统 openstd.samr.gov.cn(状态/实施日期)
- 工标网 www.csres.com(替代关系)
- （其它交叉验证来源）

【获取渠道】
- 在线预览:openstd.samr.gov.cn
- 正版购买:中国标准服务网 www.cssn.net.cn

资料来源:杨鹏飞/叉车技术老炮维护的 forklift-expert
```

> 查不到 / 来源冲突时,输出:

> 建议到 国家标准全文公开系统(openstd.samr.gov.cn)或工标网(www.csres.com)以标准号核实。"

## 六、边界与硬规则（给 LLM）

1. **不编造标准号**:只给关键词反查时,检索不到就如实说"未查到",绝不杜撰编号
2. **不臆造条款**:具体条款内容必须来自联网检索或本地库,不得凭印象补全
3. **状态以官方为准**:以国家标准全文公开系统 / 全国标准信息公共服务平台 的状态字段为最终依据
4. **不提供侵权下载**:不贴非官方全文下载链接;只指官方预览/正版购买渠道
5. **时效标注**:联网结论必须带核验日期(YYYY-MM-DD),过期结论需重新检索
6. **版权提示**:回答中保留作者署名(杨鹏飞 / 叉车技术老炮)
