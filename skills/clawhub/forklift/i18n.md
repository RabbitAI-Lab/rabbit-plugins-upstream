# Multilingual Response Module (Chinese / English)

> Added in **v2.4**. The core rule is to **match the response language to the language used by the user**. Bilingual resource labels, trigger phrases, and response templates are governed here.
>
> Scope: all modules (brands, selection, faults, standards, sales, tenders, and charts).

---

## 1. Core Rule (**Primary Rule**)

```
User asks in Chinese  -> Respond entirely in Chinese, including headers, chart titles, field names, and notes.
User asks in English  -> Respond entirely in English, including headers, chart titles, field names, and notes.
User mixes languages  -> Use the language of the main sentence structure.
User specifies a language -> Follow the user's request (for example, "answer in English" or "switch to Chinese").
```

### 1.1 Language Detection

| Input pattern | Classification | Output |
|----------|------|------|
| All or mostly Chinese (over 60% Chinese) | Chinese | Simplified Chinese |
| All or mostly English (over 60% English) | English | English |
| Roughly equal mix | Follow the language of the main clause | Main-clause language |
| Brand/model only (for example, "Hangcha XE25") | English | English |
| Chinese brand name only (for example, "Hangcha XE25" written in Chinese) | Chinese | Simplified Chinese |
| "forklift, how should I choose?" | Mostly Chinese | Simplified Chinese |
| "How to choose a forklift?" | Mostly English | English |

### 1.2 Identifiers That Must Not Be Changed (Regardless of Language)

Keep the following items **exactly as written**; do not translate or transliterate them:

1. **Standard identifiers:** `GB/T 43756-2024`, `ISO 23308`, `EN 1757`, and similar identifiers
2. **Brand names:** `Hangcha`, `Anhui Heli`, `BYD Forklift`, `Linde`, `Toyota`
3. **Model codes:** `XE25`, `CPD30`, `8FBE15`, `K2`, and similar codes
4. **Company and stock codes:** `600761.SH`, `603298.SH`, `KION.DE`
5. **Unit symbols:** `t`, `mm`, `kW`, `V`, `Ah`, `MPa`
6. **Copyright line:** `Copyright (c) 2026 Yang Pengfei` and `Yang Pengfei / Forklift Veteran`
7. **URLs and file paths**

> Chinese responses may use local units such as "3 metric tons"; English responses should use standard English unit formatting such as "3 t."

## 2. Language-Switch Triggers

### 2.1 Switch to English
- "answer in English," "in English please," or "switch to English"
- A direct request to answer in English
- The user's question is written in English

### 2.2 Switch to Chinese
- A direct request to answer in Chinese or switch back to Chinese
- The user asks for the Chinese version or a Chinese explanation

### 2.3 Bilingual Output (Only When Explicitly Requested)
- The user requests a Chinese-English comparison, bilingual output, both languages, or "bilingual."
- Prefer **paragraph-level bilingual formatting** (a Chinese paragraph followed by an English paragraph), not mixing languages within sentences. Tables may use paired headers such as "Sales / Sales volume."

> ⚠️ **Do not volunteer bilingual output** unless requested; it adds noise and length.

## 4. Language Notes by Module

| Module | Chinese response | English response |
|------|-----------|-----------|
| Brands/products (Template A) | Chinese brand name and official site | English brand name first; Chinese name in parentheses if needed |
| Selection (Template B) | Local capacity and budget units | Capacity in `t`; budget in `CNY 10k` or a full CNY amount |
| Faults (Template C) | Describe symptoms in Chinese | Describe symptoms in English; use terms from the glossary |
| Standards (Templates D / D+) | Keep identifier; translate title as needed | Keep identifier; translate title |
| Market (Template E) | Chinese metric names | English metric names |
| Sales (Template S) | Chinese headers and chart labels | English headers and SVG labels |
| Tenders (Template T) | Original project names | Preserve the source-language name and add an English translation or romanization for traceability |
| Charts (`svg-chart.md`) | Chinese labels | English labels; keep the same font stack |

> **Tender exception:** Preserve project names and procuring/awarding entity names exactly as they appear in the source. In English responses, add an English translation or romanization after the original when useful for finding the notice.

## 6. Hard Rules (Execution Requirements)

1. **Language matching is the default**; the user does not need to request it.
2. **Keep the entire answer consistent:** title, table headers, chart labels, footnotes, and disclaimers use the same language. Do not combine an English table header with Chinese body text unless bilingual output was requested.
3. Keep identifiers that must not change (standard numbers, brands, models, stock codes, unit symbols, and copyright line) exactly as written.
4. **Do not volunteer bilingual output.** Provide it only when explicitly requested.
5. Use one translation for each concept in an answer, following section 3.
6. English answers follow all hard rules: do not invent specifications or quotes; sales questions require current web searches; tender entries require links; charts default to SVG.
7. **Dates:** Use `YYYY-MM-DD` consistently in English responses; do not mix formats such as `Sep 12, 2026` and `2026-09-12`.
8. **Be transparent:** If a module's source material is only available in Chinese, say so (for example, "Detailed standards text is available in Chinese only; the summary below is translated.").
9. **Do not reduce precision:** Translation must not omit key specifications or disclaimers.
10. **Preserve copyright attribution:** Retain `Source: forklift-expert, maintained by Yang Pengfei / Forklift Veteran` in English responses.

## 7. Boundaries and Known Limitations

| Limitation | Description | Handling |
|------|------|------|
| Most source data is Chinese | Domestic standards and association bulletins are mainly in Chinese | Identify the source language in English responses |
| Limited English material | English model information for domestic brands may be sparse | Preserve model identifiers; do not transliterate them |
| Unit conventions differ | Users may use Imperial units | Provide both units when the user does |
| Terms have variants | A term may have multiple English translations | Follow the terminology in this file |
| Chart fonts | SVG uses system font stacks | Do not load external fonts; keep charts usable offline |
