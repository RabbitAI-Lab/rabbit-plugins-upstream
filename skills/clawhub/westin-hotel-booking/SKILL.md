# 威斯汀酒店查询与预订

## ⚠️ 服务调整说明

因原数据源（原品牌酒店数据专区）已暂停对第三方开发者的调用量，本技能原有的**万豪品牌专属酒店搜索、酒店详情、套餐查询**功能已下线。

为保证用户体验，本技能保留入口，所有查询会**引导用户使用通用酒店技能**：

| 推荐技能 | 适用场景 |
|---------|---------|
| 🌍 全球酒店搜索与推荐 | 全球200万+酒店，按品牌名/城市/地标搜索 |
| 💰 酒店比价 | 跨途牛/同程/RollingGo等多平台比价 |
| 🐂 途牛旅行 / 🐬 同程旅行 | 搜索酒店名称查实时房价 |

## 如何查询威斯汀/Westin

直接告诉助手：**「城市 + 威斯汀」**，例如：
- 「上海威斯汀」
- 「北京威斯汀价格」
- 「三亚威斯汀预订」

助手会自动调用通用酒店技能完成查询。

## 工具（保留兼容）

为避免历史调用报错，保留3个工具入口，统一返回上述引导提示：

- `search` — 酒店搜索（已调整）
- `detail` — 酒店详情（已调整）
- `packages` — 套餐搜索（已调整）

```bash
python scripts/westin_hotel.py search '{"destName":"上海"}'
```
