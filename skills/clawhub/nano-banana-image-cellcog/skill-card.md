## Use Case: <br>
Developers and creative teams use this skill to ask an agent to generate, edit, and plan coherent image sets through CellCog and Nano Banana workflows. It is aimed at multi-image projects such as product shots, character-consistent series, story sequences, and reference-based image edits. <br>

Mitigation: Confirm the publisher is trusted before installation and provide the API key only in an environment where CellCog use is approved. <br>
