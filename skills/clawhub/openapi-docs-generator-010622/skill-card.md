## Description: <br>
Helps API developers and backend or platform teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to turn API context, constraints, and success criteria into actionable OpenAPI or Swagger documentation, checklists, workflows, code changes, or validation guidance. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate for broad API documentation or developer-experience requests. <br>
Mitigation: Invoke it explicitly for OpenAPI or Swagger documentation tasks, or tighten trigger text before deployment. <br>
Risk: Generated documentation guidance can be incomplete or misaligned with an API's real behavior if source inputs are missing. <br>
Mitigation: Review outputs against the service implementation, constraints, and success criteria before publishing or applying changes. <br>
