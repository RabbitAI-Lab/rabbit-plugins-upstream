```
① 场景与光影总述块 → ② 人物描述块 → ③ 光源参考块 → ④ 面部描述参考块 → ⑤ 景深参考块 → ⑥ 时间轴块 → ⑦ 画幅比例

① 场景与光影总述 → ② 人物描述（从右到左编号） → ③ 光源参考 → ④ 面部描述参考 → ⑤ 景深参考 → ⑥ 时间轴（从①号人物开始） → ⑦ 画幅比例
```

```
镜头一镜到底，运镜顺滑稳定，缓慢推进、环绕、后拉、横移，不跳切，不出现人物错乱，不出现多余人物，{场景排除词}，人物五官清晰，服装干净整齐，动作自然，不穿模，不扭曲
```

```
长相、发型、服装、气质差异明显，无双胞胎感，无重复脸
```

## 七、seedance-video-gen 一键生成

### 前置条件

1. **API Key**：前往 https://redfox.hk/settings/api-keys?source=clawhub 注册获取 REDFOX_API_KEY
2. **Python 3.6+**
3. **requests 库**：`pip3 install requests`

### 生成命令

**⚠️ 直接使用完整提示词整体生成，不分镜头脚本分别生成。**

```bash
python3 "$SKILL_PATH/scripts/videogen.py" "{完整视频生成提示词}" --ratio {9:16或16:9} --resolution 1080p --duration {8/10/12/15} --no-audio --prefix cinematic -o ~/Downloads/QoderVideos
```

### 生成策略

| 策略 | 说明 | 推荐 |
|------|------|------|
| **完整提示词整体生成** | 一条提示词，1次API调用，3-15分钟 | ✅ 所有版本推荐 |
| ~~分镜生成~~ | ~~分镜头分别生成后拼接~~ | ❌ 不推荐，不符合一镜到底原则 |

> 生成完成后视频保存至 `~/Downloads/QoderVideos/`，需后期添加BGM并卡点。
