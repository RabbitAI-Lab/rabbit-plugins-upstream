# BGM卡点节奏规则与时间轴对齐方案

本文档详细记录豆志刚运镜体系中BGM卡点的精确规则，供生成脚本时参考调用。

---

## 一、卡点核心原则

### 1.1 卡点逻辑

- 每一个运镜转场/焦点切换/画面变化必须对应BGM的重鼓点
- 运镜速度与BGM节奏同步：快节奏段落用快运镜，慢节奏段落用慢运镜
- 单镜头时长（2-3s）对应BGM的乐句长度（通常2-4拍）
- 画面定格点对应BGM的重拍或尾音

### 1.2 卡点精度要求

- 运镜变化与鼓点误差不超过±0.1s（约3帧@60fps）
- 转场瞬间与重鼓点精确同步
- 定格收尾与BGM尾音落下同步
- 全程不可出现画面与音乐脱节的情况

## 二、标准12s脚本BGM时间轴

### 2.1 《爱的主打歌》卡点节奏（默认BGM）

```
时间轴：0s----2s----4s----6s----8s----10s----12s
BGM：   [前奏] [鼓点1] [鼓点2] [鼓点3] [鼓点4] [鼓点5] [尾音]
运镜：   遮挡    对焦    环绕    后拉    全景拉   定镜
        转场    切换    运镜    镜头    伸运镜   收尾
```

### 2.2 精确卡点时间表

| 时间点 | BGM事件 | 画面事件 | 卡点类型 |
|--------|---------|----------|----------|
| 0.0s | 前奏开始 | 遮挡人物开始走过 | 起始 |
| 1.8-2.0s | 第一重鼓点 | 遮挡转场完成，焦点开始切换 | 转场卡点 |
| 2.0s | 鼓点衔接 | 焦点锁定核心人物 | 焦点卡点 |
| 3.0s | 节奏段落 | 人物定格1秒 | 定格卡点 |
| 4.0s | 第二重鼓点 | 环绕运镜开始 | 运镜启动卡点 |
| 6.0s | 第三重鼓点 | 后拉镜头开始 | 运镜切换卡点 |
| 8.0s | 第四重鼓点 | 全景拉伸开始 | 运镜切换卡点 |
| 10.0s | 第五重鼓点 | 定镜收尾开始 | 定镜卡点 |
| 11.5-12.0s | 尾音落下 | 画面定格收尾 | 收尾卡点 |

### 2.3 鼓点类型说明

| 鼓点类型 | 特征 | 对应画面 |
|----------|------|----------|
| 重鼓点（Kick） | 低频强劲，最明显 | 转场/焦点切换/运镜切换 |
| 军鼓（Snare） | 中频清脆，次明显 | 人物姿态变化/定格 |
| 踩镲（Hi-hat） | 高频轻快 | 微小画面变化/背景动态 |
| 尾音 | 音乐收束 | 画面定格收尾 |

## 四、推荐BGM清单

### 4.1 卡点型BGM（首选）

| BGM名称 | BPM | 特点 | 适配场景 |
|---------|-----|------|----------|
| 《爱的主打歌》 | ~120 | 重鼓点明显，节奏感强 | 默认首选，群像版 |
| 《Actor》 | ~100 | 低沉鼓点，氛围感强 | 西装氛围感 |
| 《Industry Baby》 | ~140 | 快节奏，能量感强 | 街头潮流风格 |
| 《Opportunist》 | ~110 | 中速，高级感 | 商务/高级感 |
| 《Play Date》 | ~130 | 轻快卡点 | 运动/活力风格 |

### 4.2 氛围型BGM（备选）

| BGM名称 | 特点 | 适配场景 |
|---------|------|----------|
| 《Interstellar》主题 | 史诗感，缓慢推进 | 古风/大场景 |
| 《Blade Runner 2049》主题 | 赛博朋克，冷调 | 未来感/科技风 |
| 氛围电子乐 | 无明显鼓点，纯氛围 | 艺术感/极简风 |

### 4.3 BGM选择规则

- 优先选择有明显重鼓点的BGM，便于卡点
- BGM总时长与视频时长匹配（可截取高潮段落）
- BGM风格与视频风格统一
- 避免选择人声过多的BGM（纯音乐/节奏型优先）
- 避免选择节奏变化过大的BGM（保持匀速节奏）

## 五、BGM与运镜速度对照

| BGM节奏段 | 运镜速度 | 运镜类型 |
|------------|----------|----------|
| 前奏（缓慢） | 零（定点） | 遮挡转场 |
| 重鼓点（强劲） | 零（定点） | 焦点切换/定格 |
| 节奏段落（匀速） | 低速匀速 | 环绕运镜 |
| 节奏段落（匀速） | 中速匀速 | 后拉镜头 |
| 高潮段落（加速） | 慢速匀速 | 全景拉伸 |
| 尾音（收束） | 零（定点） | 定镜收尾 |

### 5.1 速度匹配原则

- BGM节奏越快，运镜速度可适当加快（但仍需匀速）
- BGM节奏越慢，运镜速度越慢，营造氛围感
- 无论BGM节奏如何，运镜必须保持匀速，不可忽快忽慢
- 卡点瞬间可微加速或微减速（幅度<10%），但不可明显

## 六、后期剪辑卡点操作指南

### 6.1 卡点剪辑流程

1. 导入BGM，在时间轴上标记所有重鼓点位置
2. 将分镜素材按顺序排列在时间轴上
3. 将每个分镜的转场点对齐到对应的重鼓点
4. 微调每个分镜的入点/出点，确保卡点精度±0.1s
5. 在转场点添加交叉溶解（0.1-0.2s），确保自然过渡
6. 在定格点添加微缩放效果（1.0x→1.02x），增强冲击力

### 6.2 卡点效果增强

- 在重鼓点处添加轻微画面缩放（1.0x→1.03x→1.0x，持续0.1s）
- 在转场点添加轻微闪白/闪黑（0.05s），增强转场冲击力
- 在定格点添加轻微抖动效果（可选，增强节奏感）
- 注意：所有特效必须克制，不可过度使用
