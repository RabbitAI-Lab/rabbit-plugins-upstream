# Core Workflow

> 本文档记录 cinematic-camera-script 的核心执行流程，从 SKILL.md 提取。Agent 执行时按本文档步骤操作。

---

## 完整工作流程

### Step 1: 确认输入方式

判断用户的输入类型：

| 输入方式 | 识别条件 | 处理方式 |
|----------|----------|----------|
| **图片输入** | 用户上传/提供了图片文件 | 使用 Read 工具读取图片，深度解析图片内容（人物外貌、服装、姿态、背景环境、光影条件），基于解析结果生成提示词 |
| **简单描述** | 用户提供了主体、背景、场景的文字描述 | 基于描述内容填充提示词模板 |
| **模板选择** | 用户仅指定了风格/人数等参数 | 选择对应的内置模板，按参数定制 |

#### 1.1 图片输入 - 深度解析规则

当用户上传图片时，对图片进行以下维度的深度解析：

**人物解析**（按从右到左的顺序）：
- 人物数量、性别、大致年龄段
- 每位人物的：发型、服装（颜色/款式/面料质感）、配饰、姿态、表情
- 人物站位关系（谁在最右、谁在中间、谁在最左）
- 人物间的差异度（确保AI不会生成重复脸/双胞胎感）
- 每位人物的**核心视觉标识**（最突出的1-2个外观特征，用于后续运镜段落中反复锚定身份）

**背景解析**：
- 场景类型（室内/室外/天台/走廊等）
- 建筑风格与材质
- 关键场景元素（窗户、家具、泳池、雕塑等）
- 背景色调倾向（冷调/暖调/中性）

**光影解析**：
- 主光源方向与类型
- 环境光特征（城市天光、室内射灯、烛光等）
- 人物面部光影效果（高光边缘、明暗对比、阴影层次）

**风格提取**（图片输入专属）：
- 图片整体色调（冷灰低饱和/暖白清新/高饱和鲜艳/暗调压抑等）
- 图片氛围基调（严肃/活泼/温馨/史诗/商业广告等）
- 图片视觉风格分类（写实摄影/动漫二次元/古风/现代都市/产品广告等）
- **以上风格信息直接写入提示词的"场景与光影总述块"，不覆盖为内置风格。视觉风格忠实还原图片原貌。**

#### 1.2 运镜起始规则

**运镜必须从画面中最右侧的主体开始**。无论用户上传的图片还是文字描述，第一位出现在镜头中的主体是最右侧的人物，然后通过环绕、平移、后拉逐步向左递进展现其他人物。

### Step 2: 确认需求参数

向用户确认以下参数（如有缺失则使用默认值）：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 视频时长 | 10s | 可选8s/10s/12s/15s |
| 人物数量 | 4人 | 可选1人/2人/4人/6人+ |
| 视频风格 | 见下方规则 | 图片输入时从图片提取，文字/模板输入时默认"西装氛围感" |
| BGM类型 | 《爱的主打歌》卡点 | 可选其他卡点BGM |
| 画幅比例 | 9:16竖屏 | 可选16:9横屏/1:1方形 |
| 氛围基调 | 严肃冷厉 | 可选压抑对峙/温暖柔和/轻松活泼 |

#### 风格确定规则

| 输入方式 | 风格确定方式 | 说明 |
|----------|-------------|------|
| **图片输入** | **直接从图片提取** | 不使用任何内置风格模板。解析图片本身的光影、色调、氛围、场景风格，原样还原到提示词中。**禁止用内置风格覆盖图片原有风格** |
| **文字描述** | 从描述中提取 | 用户说"街头潮流"就用街头潮流，说"古风"就用古风 |
| **模板选择** | 使用默认值 | 默认"西装氛围感"，可选街头潮流/古风/运动/商务/豪门等 |

### Step 3: 加载参考文档

根据需求加载对应的参考文档：
- 需要运镜参数细节时 → 读取 `references/camera-movements.md`
- 需要构图光影规范时 → 读取 `references/shot-composition.md`
- 需要BGM卡点规则时 → 读取 `references/bgm-sync.md`
- 需要AI生成提示词时 → 读取 `references/ai-prompts.md`

### Step 4: 生成完整提示词

基于输入内容和需求参数，按照**完整提示词结构**生成一条可直接使用的完整视频提示词。

#### 4.1 完整提示词结构（七块式）

```
① 场景与光影总述块：画质/场景/光影/色调/氛围基调
② 人物描述块：每位人物的年龄/发型/服装/配饰/姿态/表情/站位（从右到左编号）
③ 光源参考块：具体光源类型列表
④ 面部描述参考块：面部质感/光影/表情细节
⑤ 景深参考块：光圈/景深/虚化效果
⑥ 时间轴块：逐秒运镜+人物动作+画面变化描述
⑦ 结尾块：画幅比例
```

#### 4.2 提示词编写核心原则

1. **一镜到底**：提示词描述的是一条连续长镜头，不是多个分镜拼接
2. **从右开始**：时间轴第一个出场的是最右侧人物
3. **具体物理描述**：用具体外貌/服装/动作替代抽象词汇（不用"氛围感拉满""高级感"）
4. **人物差异化**：每位人物必须有明确的外观差异描述，防止AI生成重复脸
5. **负面约束词**：必须包含"不出现人物错乱，不出现多余人物，人物五官清晰，服装干净整齐，动作自然，不穿模，不扭曲"
6. **运镜术语**：使用"缓慢推进""环绕""后拉""横移""一镜到底"等具体术语
7. **人物一致性锚定（极重要）**：在时间轴的每个运镜段落中，提到某号人物时必须**重复其编号+核心视觉标识**，防止AI在长镜头中混淆人物身份。具体规则：
   - 每个时间段首次提到某号人物时，必须带"（{核心视觉标识}的{角色名/身份}）"
   - 同一时间段内再次提到同一人物可省略，但跨时间段必须重新锚定
   - 运镜段落切换时（如从"环绕"到"后拉"），涉及的每个人物都必须重新锚定编号+视觉标识
   - 在最终全景定格段落，所有人物必须逐一列出编号+核心视觉标识+最终姿态

### Step 5: 输出完整内容

输出格式包含以下模块（全部输出，不可省略）：

```
1. 脚本核心说明（风格定位/时长/BGM/画质标准）
2. 详细分镜脚本（逐秒拆解，每个分镜含：时间/画面主体/人物动作/运镜参数/光影色调/卡点节奏）
3. 核心运镜通用规则（五大规则）
4. 实拍操作小贴士（针对实拍场景）
5. ★ 完整视频生成提示词（一键提示词，可直接复制使用或直接调用视频生成）
```

### Step 6: 询问是否生成视频

脚本输出完成后，必须向用户询问：**"是否需要按照此脚本直接生成视频？"**

#### 6.1 用户选择不生成

流程结束。提示用户完整提示词可直接复制到任意AI视频生成工具使用。

#### 6.2 用户选择生成视频

当用户确认需要生成视频时：

**第一步：检查前置条件**

| 前置条件 | 检查方式 | 不满足时的处理 |
|----------|----------|----------------|
| REDFOX_API_KEY | 检查环境变量/配置文件/询问用户 | 告知前往 https://redfox.hk/settings/api-keys?source=clawhub 注册获取 |
| Python 3.6+ | `python3 --version` | 告知需安装 Python |
| requests 库 | `python3 -c "import requests"` | 告知运行 `pip3 install requests` |

**第二步：使用完整提示词直接生成**

直接使用 Step 5 输出的"完整视频生成提示词"整体生成，不使用分镜头脚本分别生成。调用 videogen.py 脚本。

**第三步：执行视频生成**

调用 seedance-video-gen 技能，向用户说明：生成需要3-15分钟，自动轮询等待，视频保存到指定输出目录。

## 视频生成集成说明

本技能与 `seedance-video-gen` 技能深度集成，支持在脚本输出后直接生成视频。

### 集成架构

```
cinematic-camera-script（脚本+完整提示词生成）
    ↓ 输出"完整视频生成提示词"
seedance-video-gen（整体视频生成，不分镜）
    ↓ 调用 Seedance 2.0 模型
MP4 视频文件输出
```

### seedance-video-gen 技能信息

- **底层模型**：火山方舟 Seedance 2.0（doubao-seedance-2-0-260128）
- **支持时长**：4-15秒
- **支持比例**：16:9 / 4:3 / 1:1 / 3:4 / 9:16 / 21:9 / adaptive
- **支持分辨率**：480p / 720p / 1080p
- **API平台**：redfox.hk（需注册获取API Key）
- **生成耗时**：3-15分钟

### 注意事项

- seedance-video-gen 最高分辨率1080p，4K需后期Upscale
- 视频不包含BGM，BGM需后期添加卡点
- 直接使用完整提示词整体生成，不分镜头脚本分别生成
- 多人物场景（4人+）提示词需强调人物差异化描述和负面约束词
- 如效果不理想可固定种子后微调提示词重试

## 画质标准规范

- **分辨率**：4K（实际生成最高1080p，需后期Upscale）
- **帧率**：60fps
- **色调**：电影感冷调质感，冷灰低饱和
- **对比度**：高对比度，暗部压色，亮部通透
- **画面要求**：干净无杂色，无多余入镜物体

---

## 五大通用规则（贯穿全程）

1. **一镜到底**：全程连续长镜头，无剪辑硬切，画面衔接零痕迹
2. **运镜丝滑**：所有运镜缓慢匀速，不跳切，不抖动，不出现人物错乱
3. **从右开始**：运镜从画面最右侧主体开始，逐步向左/向内递进展现所有人物
4. **构图原则**：中心构图、对称构图为主，人物居中，留白高级
5. **光影统一**：全程统一光影体系，不随意切换色调
