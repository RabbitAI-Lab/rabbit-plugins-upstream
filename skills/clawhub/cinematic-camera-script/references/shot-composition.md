# 构图原则、光影色调与人物站位美学参考

本文档详细记录豆志刚运镜体系中的构图规范、光影色调标准与人物站位美学，供生成脚本时参考调用。

---

## 一、构图原则

### 1.1 中心构图（核心构图法）

- 人物始终居于画面中心或黄金分割点
- 9:16竖屏中人物垂直居中，水平居中
- 适用于：定点对焦、低速环绕、定镜收尾

```
┌─────────────┐
│             │
│             │
│     人物     │
│   (居中)     │
│             │
│             │
└─────────────┘
```

### 1.2 对称构图（群像构图法）

- 双人/多人场景中采用对称站位
- 左右人物镜像对称或近似对称
- 适用于：匀速后拉、全景拉伸

```
┌─────────────┐
│             │
│   人物    人物  │
│   (左)  (右) │
│             │
└─────────────┘
```

### 1.3 三分法+留白构图

- 人物置于画面下1/3处，上方留白
- 留白区域展现环境氛围（天空/建筑）
- 适用于：全景拉伸运镜、定镜收尾

```
┌─────────────┐
│   留白区域   │
│  (天空/建筑) │
│─────────────│
│  人物群像   │
│  (下1/3)    │
└─────────────┘
```

### 1.4 构图禁忌

- 禁止画面拥挤，人物之间需保持适当间距
- 禁止人物头部贴顶或脚部出画（特写除外）
- 禁止杂乱背景元素干扰主体
- 禁止水平线倾斜（除非刻意营造动感）

## 二、光影色调规范

### 2.1 光影标准

| 光影要素 | 规范 |
|----------|------|
| 主光源 | 自然光侧逆光（45-135度侧逆光） |
| 辅助光 | 无需人工补光，利用环境反射光 |
| 人物光效 | 边缘发光（轮廓光），面部立体 |
| 暗部处理 | 暗部压色，不提亮，保持层次 |
| 亮部处理 | 亮部通透，不过曝，保留细节 |
| 光比 | 高光比（约1:4-1:8），增强戏剧感 |

### 2.2 色调标准

| 色调要素 | 规范 |
|----------|------|
| 基础色调 | 冷灰调，低饱和 |
| 色温 | 偏冷（约5000-6500K） |
| 对比度 | 高对比度 |
| 饱和度 | 低饱和（降20-30%） |
| 阴影色调 | 偏青蓝 |
| 高光色调 | 微暖白 |
| 黑色阶 | 深沉不灰，纯净黑色 |
| 白色阶 | 通透不刺眼，柔和白色 |

### 2.3 色调统一规则

- 全程色调统一，禁止中途切换色调
- 如需色调变化，仅允许在转场点微调（幅度<10%）
- 后期调色建议：降低饱和度20-30%，提升对比度15-20%，阴影偏青蓝
- LUT推荐：电影感冷调LUT（Teal & Orange变体，偏冷版）

## 三、人物站位美学（杜琪峰风格）

### 3.1 单人站位

- 人物居中站立，体态挺拔
- 双臂交叉抱于胸前（默认姿态）
- 或单手叉腰，另一手自然下垂
- 脚部站位：双脚与肩同宽，重心均匀

### 3.2 双人站位

```
对称式：
  人物A          人物B
  (叉腰)        (抱臂)
  
错落式：
  人物A
         人物B
  (前侧)      (后侧)
```

- 两人间距约0.8-1.2m
- 姿态互补：一人抱臂一人叉腰，或一人正面一人微侧
- 视线方向：均直视镜头，或一人看镜头一人看侧方

### 3.3 四人站位（标准群像）

```
         [人物C 叉腰]
[人物B 扶杆]  [人物A 抱臂]  [人物D 抬手]
         (中心位)
```

| 位置 | 人物 | 姿态 | 作用 |
|------|------|------|------|
| 中心 | 人物A | 抱臂，体态挺拔 | 气场核心，视觉焦点 |
| 左侧 | 人物B | 单手扶杆/扶墙 | 平衡构图，增加线条感 |
| 右侧 | 人物C | 叉腰 | 姿态独立，对称美感 |
| 远侧 | 人物D | 抬手定型 | 增加画面高度层次 |

### 3.4 六人扩展站位

```
         [人物E 抬手]
[人物B 扶杆]  [人物A 抱臂]  [人物D 叉腰]
  [人物C 单手插兜]    [人物F 微侧身]
```

- 前排3人，后排3人，错落分布
- 中心人物始终为视觉焦点
- 外围人物姿态各异但气场统一
- 间距均匀，不拥挤不松散

### 3.5 站位通用规则

- 所有人物造型风格统一（如统一西装/统一色调）
- 姿态各异但气场统一（不可有人松懈有人紧绷）
- 人物之间有层次感（前后错落，高低不同）
- 视线统一朝向镜头（除非刻意营造不看镜头的氛围感）
- 中心人物永远是视觉焦点，其他人物起衬托作用

## 四、人物造型规范

### 4.1 西装氛围感（默认风格）

| 要素 | 规范 |
|------|------|
| 服装 | 统一西装/西装外套，剪裁合体 |
| 内搭 | 纯色高领/衬衫，无花纹 |
| 发型 | 高马尾/利落短发，精致造型 |
| 妆容 | 干净通透，淡妆，高级感 |
| 配饰 | 极简，不超过2件（手表/耳钉） |
| 鞋履 | 皮鞋/靴子，与西装色调统一 |

### 4.2 其他风格适配

- **街头潮流**：统一 Oversize 外套/卫衣，棒球帽，运动鞋
- **古风**：统一汉服/新中式服装，发髻精致，折扇/油纸伞道具
- **运动**：统一运动套装，运动鞋，干净利落
- **商务休闲**：统一衬衫+西裤，卷袖，领带可选

### 4.3 造型统一规则

- 所有人物服装色调统一（可深浅渐变但同色系）
- 造型风格一致，不可混搭
- 发型精致度统一
- 配饰极简，不可过多
- 面料质感高级，纹理清晰可辨

---

## 五、背景环境规范

### 5.1 背景选择标准

- 极简建筑背景（混凝土/玻璃幕墙/纯色墙面）
- 干净户外场景（天空/广场/极简走廊）
- 无杂乱元素，无路人入镜
- 背景色调与人物服装协调

### 5.2 背景层次要求

- 前景层：遮挡转场人物（虚化）
- 中景层：核心人物群像
- 远景层：天空/建筑/动态元素（流云/远景车辆）
- 三层层次分明，增加画面纵深感

### 5.3 背景动态元素

- 远景可有轻微动态：流云、远景车辆、飘动的旗帜
- 动态元素不可过大或过快，避免分散注意力
- 动态元素仅作为氛围加持，不可成为画面主体
