# 六大核心运镜技法详细参数库

本文档详细记录豆志刚运镜体系中六大核心运镜技法的精确参数，供生成脚本时参考调用。

---

## 运镜1：前景遮挡转场（0-2s）

### 核心逻辑
利用人物从镜头极近位置横向走过，身体完全虚化形成天然前景遮挡，实现无缝转场开篇。

### 精确参数

| 参数 | 数值/描述 |
|------|-----------|
| 镜头状态 | 静止定点，不移动 |
| 焦距 | 广角端（约24-35mm等效） |
| 对焦模式 | 连续自动对焦，轻微对焦切换 |
| 人物距离 | 距镜头0.3-0.5m极近距离 |
| 人物移动 | 横向匀速走过，速度约0.5m/s |
| 虚化程度 | 人物完全虚化（景深极浅） |
| 运镜速度 | 零（定点拍摄） |
| 抖动控制 | 全程丝滑无抖动，可使用AI防抖 |

### 技术要点
- 人物走过时身体必须完全虚化，不可清晰入焦
- 走过速度匀速缓慢，避免快速移动导致画面撕裂
- 遮挡瞬间与BGM第一重鼓点精确同步
- 背景需干净极简，无杂乱元素干扰

### 适配场景
- 开篇钩子镜头
- 任何需要自然过渡的场景切换
- 单人/群像脚本的开篇第一镜

---

## 运镜2：定点对焦切换（2-4s）

### 核心逻辑
前景遮挡人物走过之后，焦点瞬间锁定后方核心人物，实现主体亮相。

### 精确参数

| 参数 | 数值/描述 |
|------|-----------|
| 镜头状态 | 静态稳镜，不移动 |
| 焦距 | 中长焦（约50-85mm等效） |
| 对焦模式 | 焦点切换：前景虚化 → 后景锁定 |
| 对焦速度 | 快速锁定（0.3-0.5s内完成） |
| 景深控制 | 浅景深，背景虚化突出主体 |
| 人物距离 | 距镜头2-3m |
| 运镜速度 | 零（定点拍摄） |
| 定格时长 | 焦点锁定后定格1s |

### 技术要点
- 焦点切换必须丝滑自然，不可生硬跳焦
- 人物面部精准对焦，眼神光清晰可见
- 背景虚化程度适中，保留环境氛围但不喧宾夺主
- 定格1秒强化人物高级感，给观众记忆时间

### 适配场景
- 主体人物首次亮相
- 产品/造型展示亮相
- 单人脚本的核心展示镜

## 运镜3：低速环绕运镜（4-6s）

### 核心逻辑
镜头低速向左轻微环绕，小范围动态运镜，角度缓慢变化，营造迈克尔贝式动态张力。

### 精确参数

| 参数 | 数值/描述 |
|------|-----------|
| 镜头状态 | 低速环绕移动 |
| 运镜方向 | 向左环绕（逆时针） |
| 环绕角度 | 15-30度（小范围） |
| 环绕半径 | 1-1.5m |
| 运镜速度 | 极低速，匀速不变速 |
| 持续时长 | 2s |
| 画面范围 | 单人特写转中近景 |
| 抖动控制 | 全程丝滑，AI防抖开启 |

### 技术要点
- 环绕角度控制在15-30度，不可过大导致眩晕
- 速度必须匀速，不可忽快忽慢
- 人物保持站姿不动，仅镜头移动
- 背景远景需有轻微动态元素（流云/远景车辆），增加画面层次
- 明暗对比增强，人物亮部突出，暗部压色

### 适配场景
- 迈克尔贝动态感营造
- 单人主体特写展示
- 需要动态张力但不剧烈的场景

## 运镜4：匀速后拉镜头（6-8s）

### 核心逻辑
从单人中近景匀速向后拉镜，纳入侧边第二位人物，形成双人对称构图。

### 精确参数

| 参数 | 数值/描述 |
|------|-----------|
| 镜头状态 | 匀速向后拉镜 |
| 运镜方向 | 正后方直线后退 |
| 拉镜距离 | 1-1.5m（从中近景拉至中景） |
| 运镜速度 | 匀速，无快慢波动 |
| 持续时长 | 2s |
| 构图变化 | 单人中近景 → 双人中景 |
| 人物站位 | 两人对称站位 |
| 抖动控制 | 全程丝滑平稳 |

### 技术要点
- 拉镜速度必须绝对匀速，不可有加速或减速
- 第二位人物在拉镜过程中自然入画，位置精准
- 两人站位对称，画面平衡规整
- 拉镜过程中焦点保持在中心人物，第二位人物入画后焦点可微调
- 构图遵循对称美学，视觉舒适高级

### 适配场景
- 人物扩容（从1人扩展到2人）
- 双人关系展示
- 群像递进的中间过渡镜

---

## 运镜5：全景拉伸运镜（8-10s）

### 核心逻辑
镜头持续大范围慢拉，依次呈现四位人物，层层递进打开视野，展现完整群像。

### 精确参数

| 参数 | 数值/描述 |
|------|-----------|
| 镜头状态 | 大范围慢拉全景运镜 |
| 运镜方向 | 正后方直线后退 |
| 拉镜距离 | 2-3m（从中景拉至全景） |
| 运镜速度 | 慢速匀速，视野逐步打开 |
| 持续时长 | 2s |
| 构图变化 | 双人中景 → 四人全景 |
| 人物站位 | 四人错落有致，姿态各异 |
| 背景加持 | 远景加入天空/建筑/动态元素 |

### 四人站位标准（杜琪峰群像美学）

```
        [人物C 叉腰]
[人物B 扶杆]  [人物A 抱臂(中心)]  [人物D 抬手定型]
```

- 中心人物：抱臂，体态挺拔，气场核心
- 左侧人物：单手扶杆/扶墙，姿态利落
- 右侧人物：叉腰，姿态独立有型
- 远侧人物：抬手定型，增加画面高度层次

### 技术要点
- 拉镜速度比运镜4更慢，营造层层递进的仪式感
- 人物依次入画，不可同时全部出现
- 四人姿态各异但气场统一，造型风格一致
- 远景背景需有层次（天空+建筑+地面），提升大片质感
- 构图饱满但不拥挤，留有适当呼吸空间

### 适配场景
- 群像完整展现
- 团队/组合亮相
- 高级感氛围视频的高潮镜

## 运镜6：定镜收尾定格（10-12s）

### 核心逻辑
镜头完全静止，稳定定镜收尾，画面定格留足记忆点。

### 精确参数

| 参数 | 数值/描述 |
|------|-----------|
| 镜头状态 | 完全静止，零移动 |
| 持续时长 | 2s |
| 画面范围 | 四人完整全身群像，全景定格 |
| 构图要求 | 构图饱满，人物造型整齐 |
| 收尾方式 | BGM尾音落下，画面定格 |

### 技术要点
- 镜头绝对静止，不可有任何微移或抖动
- 画面统一高级，人物造型整齐划一
- 构图饱满但不拥挤，四人均在画面内
- 结尾干净利落，不拖泥带水
- 与BGM尾音同步，音乐落下即画面定格

### 适配场景
- 所有脚本的收尾镜
- 需要留记忆点的结尾
- 品牌Logo/标语展示的承载镜
