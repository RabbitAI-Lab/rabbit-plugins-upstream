# AI视频生成完整提示词模板与编写指南

本文档提供基于豆志刚运镜体系的**完整提示词模板**和编写规范。所有提示词采用**七块式结构**，一条提示词描述完整视频，直接整体生成，不分镜头分别生成。

---

## 一、完整提示词七块式结构

### 1.1 结构总览

一条完整的豆志刚风格视频提示词由以下七块组成，按顺序输出：

```
① 场景与光影总述块
② 人物描述块
③ 光源参考块
④ 面部描述参考块
⑤ 景深参考块
⑥ 时间轴块（核心运镜描述）
⑦ 结尾块（画幅比例）
```

### 1.2 各块详解

#### ① 场景与光影总述块

描述整体场景、光影、色调、氛围基调。包含：
- 画质声明（4K写实现代电影质感）
- 场景完整描述（地点、建筑元素、材质、远处可见景观）
- 整体光线描述（偏暗/偏亮、主光源方向、环境光类型）
- 人物轮廓光效（高光边缘、明暗对比）
- 氛围基调（严肃/压抑/温暖/活泼等）

示例：
```
4K写实现代电影质感，高端奢华顶楼天台，全景落地窗、极简大理石吧台、深色皮质沙发、金属艺术雕塑、无边泳池边缘、远处城市天际线与霓虹灯光，整体光线偏暗，以侧逆光、室内暖色射灯、冷色城市天光和环境反光为主，人物轮廓有明显高光边缘，面部明暗对比强烈，局部有柔光过渡，阴影层次丰富，气氛严肃、压抑、锋芒毕露。
```

#### ② 人物描述块

每位人物**从右到左编号**，逐位详细描述。包含：
- 年龄段、发型、服装（颜色/款式/面料/质感）
- 配饰（手表/腰带/首饰等）
- 站位位置（画面右侧/中间/左侧/右侧后方/左侧后方）
- 姿态（站/坐/手部动作）
- 表情与眼神（直视镜头/冷厉/锐利/阴鸷/冷淡等）
- 与其他人物的外观差异强调
- **★ 核心视觉标识**：从每位人物的描述中提取最突出的1-2个外观特征，作为后续时间轴段落中反复锚定身份的标记。格式："{服装颜色+款式}+{发型或标志特征}"，例如"酒红色丝质衬衫+低马尾""金黄色虎皮裙+火眼金睛"

**关键规则**：
- 运镜从最右侧（①号人物）开始
- 每位人物必须有明确的外观差异，写"长相、发型、服装、气质差异明显，无双胞胎感，无重复脸"
- 人物数量根据用户需求设定（1人/2人/4人等）
- 核心视觉标识必须在人物描述块中明确标注，供时间轴块引用


#### ⑥ 时间轴块（核心运镜描述）

逐秒描述运镜、人物动作、画面变化。**运镜从最右侧①号人物开始**。

**关键约束词（必须包含）**：
```
镜头一镜到底，运镜顺滑稳定，缓慢推进、环绕、后拉、横移，不跳切，不出现人物错乱，不出现多余人物，不出现古代物品（按场景调整），人物五官清晰，服装干净整齐，动作自然，不穿模，不扭曲。
```

**★ 人物一致性锚定规则（极重要，必须严格遵守）**：

AI视频模型在长镜头中容易混淆人物身份（如①号变成③号、③号变成④号）。为防止角色错位，时间轴中每个段落必须遵守以下锚定规则：

1. **首次出现锚定**：每个时间段首次提到某号人物时，必须带完整标识："①号人物（{核心视觉标识}的{角色名}）"
   - ✅ 正确："①号人物（金黄色虎皮裙+火眼金睛的孙悟空）缓慢转身正对镜头"
   - ❌ 错误："①号人物缓慢转身正对镜头"（缺少视觉标识，AI可能渲染成其他角色）

2. **跨段落重新锚定**：运镜段落切换时（如从"环绕"切换到"后拉"），涉及的每个人物都必须重新锚定编号+视觉标识
   - ✅ 正确："5-7秒 镜头匀速向后拉远，①号人物（金黄色虎皮裙+金箍的孙悟空）缓慢转身正对镜头……酒红衬衫的②号人物留在画面左后方"
   - ❌ 错误："5-7秒 镜头匀速向后拉远，①号人物缓慢转身正对镜头……②号人物留在画面左后方"

3. **全景定格逐一列出**：最终全景段落必须逐一列出所有人物的编号+核心视觉标识+最终姿态
   - ✅ 正确："四人固定姿态：右侧①号人物（金黄色虎皮裙的孙悟空）抱棒机敏、中后②号人物（深紫僧袍的沙僧）持铲沉稳、中心③号人物（红袈裟的唐僧）骑白马、最左④号人物（黑僧袍的猪八戒）扶耙憨厚"
   - ❌ 错误："四人固定姿态：右侧人物抱棒、中后人物持铲、中心人物骑马、最左人物扶耙"

4. **核心视觉标识选取规则**：从人物描述块中提取最突出的1-2个外观特征
   - 优先选取：服装颜色+款式、标志性配饰、发型、面部特征
   - 例如："酒红色丝质衬衫+低马尾""深紫色僧袍+白色僧帽箍""黑色高领羊绒衫+背头油头"

## 五、提示词编写避雷清单

| 禁止写法 | 原因 | 替代方案 |
|----------|------|----------|
| 氛围感拉满 | AI不理解"氛围感" | 写具体光源和光影效果 |
| 商业大片质感 | 太抽象 | "4K写实现代电影质感" |
| 高级感 | 无物理对应 | 写具体色调："冷灰低饱和色调，高对比度" |
| 气场沉稳 | 无物理对应 | 写具体姿态："双手插兜，眼神直视镜头，体态挺拔" |
| 迈克尔贝环绕 | AI不识别人名 | "镜头顺滑匀速环绕至人物身后" |
| 分镜/分段生成 | 不符合一镜到底原则 | 一条完整提示词，一镜到底 |
| 矛盾指令（快速运镜+极度稳定） | AI无法同时执行 | 二选一，豆志刚风格用缓慢运镜 |
| 缺少人物差异化描述 | AI生成重复脸 | 每位人物写明外观差异，加"无双胞胎感，无重复脸" |
| 缺少负面约束词 | 人物可能变形/错乱 | 加"不出现人物错乱，不穿模，不扭曲" |
| ★ 时间轴中只写编号不写视觉标识 | **AI在长镜头中混淆角色身份（①号变③号、③号变④号）** | **每个段落首次提到人物时带"编号+核心视觉标识"，如"①号人物（金黄色虎皮裙+火眼金睛的孙悟空）"** |
| ★ 时间轴中跨段落不重新锚定 | **运镜切换时AI丢失角色追踪，渲染成错误角色** | **每个运镜段落切换时，涉及的人物都重新锚定编号+视觉标识** |
| ★ 全景定格只写"四人固定姿态" | **AI不知道谁是谁，随机分配姿态** | **逐一列出：右侧①号人物（{视觉标识}）{姿态}、中后②号人物（{视觉标识}）{姿态}……** |
| ★ 图片输入时覆盖为内置风格 | **破坏图片原有视觉风格，生成与图片不符的视频** | **忠实还原图片色调/光影/氛围，运镜逻辑用豆志刚体系，视觉风格用图片本身的** |

## 六、seedance-video-gen 集成方案

### 6.1 技能信息

| 项目 | 说明 |
|------|------|
| 技能名称 | seedance-video-gen |
| 底层模型 | Seedance 2.0（doubao-seedance-2-0-260128） |
| API平台 | redfox.hk |
| 支持时长 | 4-15秒 |
| 支持比例 | 16:9/4:3/1:1/3:4/9:16/21:9/adaptive |
| 支持分辨率 | 480p/720p/1080p |

### 6.2 前置条件

| 条件 | 检查方式 | 不满足时处理 |
|------|----------|-------------|
| REDFOX_API_KEY | `echo $REDFOX_API_KEY` 或检查配置文件 | 引导前往 https://redfox.hk/settings/api-keys?source=clawhub 注册 |
| Python 3.6+ | `python3 --version` | 引导安装 |
| requests库 | `python3 -c "import requests"` | `pip3 install requests` |

### 6.3 生成命令

**直接使用完整提示词整体生成（不分镜头）**：

```bash
python3 "$SKILL_PATH/scripts/videogen.py" "{完整视频生成提示词}" --ratio {9:16或16:9} --resolution 1080p --duration {4-15} --no-audio --prefix cinematic -o {输出目录}
```

⚠️ **不要使用分镜头脚本分别生成**。一条完整提示词直接整体生成视频。

### 6.4 API Key配置方式

| 方式 | 命令 | 适用场景 |
|------|------|----------|
| 环境变量 | `export REDFOX_API_KEY=ak_密钥` | 全局生效 |
| 命令行参数 | `--api-key ak_密钥` | 临时使用 |
| 配置文件 | `mkdir -p ~/.qoder/apis && echo '{"api_key":"ak_密钥"}' > ~/.qoder/apis/redfox.json` | 持久存储 |

### 6.5 常见问题与处理

| 问题 | 原因 | 处理 |
|------|------|------|
| 人物面部变形 | 缺少面部约束词 | 添加"人物五官清晰，不穿模，不扭曲" |
| 人物重复/双胞胎 | 缺少差异化描述 | 每位人物写明外观差异，加"无重复脸" |
| 运镜不流畅 | 提示词描述矛盾或不具体 | 用"一镜到底，运镜顺滑稳定，缓慢推进、环绕、后拉" |
| 画面中出现多余人物 | 缺少负面约束 | 加"不出现多余人物" |
| 场景出现不当元素 | 缺少排除指令 | 加"不出现古代物品"（现代场景）等 |
| ★ 角色错位（①号变③号、③号变④号） | 时间轴中只写编号不写视觉标识，AI在长镜头中丢失角色追踪 | 每个段落首次提到人物时带"编号+核心视觉标识"，跨段落重新锚定，全景定格逐一列出。详见时间轴块的人物一致性锚定规则 |
| ★ 已入画人物在后拉段落中消失 | 未强调人物保持在场 | 在后拉/横移段落末尾加"此段落中①号人物（{视觉标识}）和②号人物（{视觉标识}）保持在画面右侧，不消失不变形" |
| ★ 图片输入后视频风格与图片不符 | 提示词覆盖为内置"豆志刚冷灰低饱和"风格 | 图片输入时忠实还原图片色调/光影/氛围，运镜逻辑用豆志刚体系，视觉风格用图片本身的 |
| ★ 全景定格时人物姿态随机分配 | 只写"四人固定姿态"未逐一指定 | 逐一列出：右侧①号人物（{视觉标识}）{姿态}、中后②号人物（{视觉标识}）{姿态}…… |
