## Description:

Create and edit JSON Canvas files (.canvas) with nodes, edges, groups, and connections. Use when working with .canvas files, creating visual canvases, mind maps, flowcharts, or when the user mentions Canvas files in Obsidian.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and knowledge workers use this skill to create, update, and validate Obsidian JSON Canvas .canvas files for visual canvases, mind maps, flowcharts, project boards, and research maps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated or edited .canvas files may contain incorrect file paths, external links, malformed JSON, duplicate IDs, or dangling edge references.

Mitigation: Review .canvas changes before relying on them and validate JSON parsing, unique IDs, required node fields, allowed enum values, and edge references against existing nodes.
