## Description: <br>
Skill Forge helps developers create, evaluate, and improve agent skills through routed interviews, SkillHub comparison, structured authoring, validation, and handoff to a separate publishing skill. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[edwardwason](https://clawhub.ai/user/edwardwason) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and skill authors use this skill to decide whether a skill is worth creating, gather requirements, generate or improve skill package files, and evaluate quality before publishing handoff. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can create or edit skill package files in a user-selected directory. <br>
Mitigation: Use it only in the intended skill directory and review proposed file changes before confirming writes. <br>
Risk: Users may try to use the skill for publishing or security vetting, which is outside its stated scope. <br>
Mitigation: Use the separate publisher or security-review tools for those tasks. <br>
