## Description:

When a change has effects past the immediate fix—incentives, scale, feedback—trace consequence chains with timing and probability before committing.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, architects, and decision makers use this skill to trace second- and third-order consequences before committing to strategic, policy, incentive, or architecture choices.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can add unnecessary analysis overhead when applied to routine local edits or purely mechanical changes.

Mitigation: Use it only for decisions with lasting coupling, incentives, scale effects, or cross-party consequences.

Risk: Speculative consequence chains can mislead decisions if low-probability links are padded beyond useful evidence.

Mitigation: Require probability, timing, and a clear mechanism for each kept link, and stop when additional links no longer change the decision.
