## 工程识别

当前工程属于麟览公司 AI 试点项目。主要工程类型参考 `AGENTS.md` 第 16 节。

## 核心规则

1. **产品思维优先**：从用户场景出发，先理解业务价值再动手
2. **最小可行方案**：先跑通主流程，再迭代优化
3. **渐进式交付**：每个阶段产出可验证的结果
4. **安全合规**：不硬编码密钥/Token/连接串，不处理未脱敏数据

## 任务分级

- **1WEEK级**（>3天）：新功能、架构变更、跨系统改造 → 完整 context + 8 个核心文件
- **3DAY级**（1-3天）：接口开发、局部流程调整 → context 精简版 + 5 个核心文件
- **1DAY级**（<1天）：Bug fix、配置修改 → review-summary + ai-usage-record
