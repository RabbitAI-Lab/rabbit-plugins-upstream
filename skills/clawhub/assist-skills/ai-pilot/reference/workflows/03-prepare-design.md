# 开始设计 workflow

触发词：`开始设计`、`设计方案`、`帮我做技术设计`

定位：按需能力指令。只处理技术设计，不自动补跑需求、测试或编码流程。

## 执行步骤

1. 定位当前任务目录；如不明确，先询问任务编号。
2. 优先读取 `requirement.md` 和 `context.md`；缺失时说明继续设计的风险。
3. 1WEEK/3DAY级任务如缺关键业务规则、接口约束、权限规则或数据口径，应提示最小补充项。
4. 读取 `ai-pilot/standards/02-design-template.md`。
5. 生成或更新 `design.md`，包含方案概览、影响范围、关键流程、接口/数据库变更、风险与测试建议。
6. 只提示可选下一步，不自动执行测试用例或编码流程。

## 按需边界

- 不因缺少 `requirement.md` 自动补写需求，除非用户明确要求。
- 涉及跨系统接口、权限、资金、审批、生产数据或不可逆数据变更时，应提醒人工确认。
- 1DAY级缺陷修复可生成简化设计，聚焦原因、修改点、影响范围和验证方式。
