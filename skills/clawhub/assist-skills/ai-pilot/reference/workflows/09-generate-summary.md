# 生成阶段汇总 workflow

触发词：`生成阶段汇总`、`汇总 AI 试点数据`、`生成阶段 Review`

定位：负责人按需指令。用于阶段 Review、中期 Review 或试点总结，不属于普通任务必经流程。

## 执行步骤

1. 确认汇总范围：全部任务、指定任务编号列表或指定日期范围。未提供时默认扫描 `ai-pilot/poc/` 下所有任务目录。
2. 确认输出路径；未提供时默认生成 `ai-pilot/poc/_summary.md`。
3. 只读取任务产物，不扫描业务源码或整个仓库。
4. 优先读取每个任务目录中的：
   - `ai-usage-record.md`
   - `context.md`
   - `review-summary.md`
   - `test-execution-log.md`
5. 按需参考其他任务产物，但不建议读取业务代码。
6. 参考 `ai-pilot/reference/summary-template.md` 的结构生成汇总报告，不修改原模板。
7. 只汇总已有任务产物中的事实，不编造工时、采纳率、功能规模、代码占比或问题。
8. 遇到缺失数据，用“未填写”、“未记录”或“无法判断”标注。
9. 输出阶段结论：有效场景、主要风险、下阶段改进建议。

## 建议汇总内容

- 任务汇总表。
- 工具使用统计。
- context 填写率、有效性反馈和常见缺失项。
- 功能规模估算和 AI 生成代码占比（%）的填写率、均值和未填写原因，所有此类数据均标注为估算值。
- 自定义指令汇总：高频自定义指令、场景分布、建议纳入参考指令库的指令。
- 风险与问题。
- 下阶段改进建议。
