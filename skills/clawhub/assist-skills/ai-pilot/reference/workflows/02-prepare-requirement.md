# 梳理需求 workflow

触发词：`梳理需求`、`分析需求`、`帮我理需求`

定位：按需能力指令。只处理需求整理，不自动补跑设计、测试或编码流程。

## 执行步骤

1. 定位当前任务目录；如不明确，先询问任务编号。
2. 读取 `context.md`；如不存在，说明风险并询问是否基于用户当前描述继续。
3. 1WEEK/3DAY级任务检查 context 是否达到最低质量门槛；未达到时提示最小补充项。
4. 读取 `ai-pilot/standards/01-requirement-spec-template.md`。
5. 输出需求理解、范围边界、待澄清问题、验收标准草案和风险点。
6. 待用户确认后，生成或更新 `requirement.md`。
7. 只提示可选下一步，不自动执行设计流程。

## 按需边界

- 不自动生成 `design.md`、`test-cases.md` 或代码。
- 业务规则、权限规则、流程规则、数据口径或验收标准不明确时，优先提问。
- 1DAY级小改动可基于问题现象和用户指定范围生成简化需求说明。
