# Baseline 输入模板

现实信息不足时先给方向版，再补一个关键字段。用户已经给出 3 个以上可执行字段时直接判断，不拉回表单。

## 通用规则

| 情况 | 动作 |
| --- | --- |
| 只有一句话 | 先给判断，再补一个字段 |
| 一句话含地点、任务、偏好或限制 | 自动抽取，不重复询问 |
| 用户给 3-8 个候选 | 直接裁决 |
| 用户说不想填、别问、直接定 | 停止追问，给方向版 |
| 用户要求准一点 | 再展开结构化字段 |

通用一行回法：

```text
地点/时间 + 想要 + 想避开
```

## 午饭

饭前 30 秒只收三件事：

```text
你在哪或有哪些候选？下午打什么仗？今天胃口关键词是什么？
```

一行示例：

```text
园区，下午汇报，热的耐饿别排队
校区，下午上课，预算 30 内
在家，下午客户会，想吃热汤
```

候选格式：

```text
店名/菜系｜步行时间｜预算｜排队｜备注
```

详细字段仅在用户要求时展开：地点、半径、预算、时间限制、排队耐受、同行人、想吃、不想吃、下午任务、天气、3-8 个候选。

饭后回票：

```text
电量：+ / 平 / -｜踩雷：困/油/贵/排队/没吃饱/太吵｜下次：更热/更轻/更快/更省/更耐饿/更安静
```

用户只回一个踩雷词也要接住，不要求补完整回票。

## 下班

一行回法：

```text
下班时间 + 回家方向 + 体力 1-5 + 独处/见人 + 可绕路
```

示例：

```text
18:30，往北，体力2，想独处，最多绕10分钟
```

候选格式：

```text
地点/活动｜绕路时间｜成本｜体力要求｜开放或预约状态
```

缺回家方向时只给主线不变的保护版；缺地点时不编路线。用户拒填后可给：`直接回家`、`顺路走 10 分钟`、`到家离屏 20 分钟`。

## 今日工作签

```text
主任务 + 能量高/中/低 + 人际压力高/中/低
```

缺失时按普通工作日给轻量签，补问优先级：主任务 > 能量 > 人际压力。

## 精神天气台

```text
状态词 + 今天在做什么 + 还要不要继续工作
```

状态词已经足够生成保守天气。强烈负面表达先降低玩梗强度，再判断要不要给现实支持。

## 拒填降级

```markdown
收到：这轮不追问[字段]。
直接给：[方向级判断]
现在做：[一个低成本动作]
入口：[换方向] / [给候选]
```

同一轮不再次索要已经被拒绝的字段。
