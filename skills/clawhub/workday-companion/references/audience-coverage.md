## Four Required Audiences

### 办公室打工人

常见场景：

- 会议、汇报、方案、跨部门对齐、ddl、临时需求。
- 午饭选择受排队、同事偏好、外卖时间影响。
- 下班后需要在恢复精力和处理生活事务之间取舍。

写法：

- 可写“会议脑”“ddl”“对齐需求”。
- 少用公司内部黑话，避免默认所有人都在大型公司或平台团队。

### 通勤族

常见场景：

- 早晚高峰、换乘、晚点、步行距离、天气。
- 午饭和下班安排受路线影响很大。

写法：

- 下班模块要考虑“顺路”“少换乘”“不绕远”。
- 最低快乐方案可以是买饮料、绕公园 10 分钟、安静坐一站。

### 学生 / 实习生

常见场景：

- 上课、实习、组会、作业、社团、考试周、第一次汇报。
- 预算敏感，社交压力可能来自同学、导师、带教或同事。

写法：

- 午饭预算和校区距离很重要。
- 工作签可以覆盖“今天先问清楚标准”“别把实习当毕业答辩”。

### 自由职业 / 远程办公者

常见场景：

- 在家办公、咖啡店办公、客户沟通、自我管理、边界模糊。
- 下班感弱，需要人为制造收工仪式。

写法：

- 今日工作签要有“关掉一个任务入口”的建议。
- 下班放行单可输出“离开工位 20 分钟”的低成本方案。

## Coverage Checklist

新增模板、demo 或素材时检查：

- 是否至少有一个非办公室场景。
- 是否适配预算敏感用户。
- 是否适配独处用户和社交用户。
- 是否保留远程办公、学生/实习、通勤场景。
- 是否避免单一城市、单一行业、单一收入水平。

## Audience Router

先按用户原话判断场景，场景不明时走大众工作日版。

| 用户线索 | 适配场景 | 语言倾向 |
| --- | --- | --- |
| 会议、汇报、方案、同事、老板 | 办公室打工人 | 可用任务、沟通、汇报、会议 |
| 地铁、公交、换乘、回家方向、晚点 | 通勤族 | 强调顺路、少绕、少换乘 |
| 上课、考试、作业、导师、带教、实习 | 学生 / 实习生 | 强调预算、标准、少脑补 |
| 在家、咖啡店、客户、自由职业、远程 | 自由职业 / 远程办公者 | 强调边界、收工、自我管理 |
| 只有“累、饿、烦、随便” | 大众工作日 | 避免行业词，给低耗动作 |

## Non-standard Workday Adapter

用于周末、休息日、补班、值班、调休、自由职业无固定上下班等场景。目标是保留工作伴侣的结构，但把语气和动作改成当天责任强度。

触发线索：

- 当前日期可判断为周末。
- 用户明说周末、休息日、补班、值班、调休。
- 用户说自由职业、项目日、今天没有上下班、在家处理一点事。
- 用户说只想整理、收尾、补作业、赶考试、陪家人后再处理工作。

适配表：

| 场景 | 今日工作签 | 午饭判官 | 精神天气台 | 下班放行单 |
| --- | --- | --- | --- | --- |
| 周末休息但想整理 | 改成今日小任务签 | 优先低折腾、顺手吃 | 降低任务压迫感 | 改成休息续航计划 |
| 补班 / 值班 | 保留工作签，但降低野心 | 优先近、稳、少排队 | 识别额外消耗 | 下班强调恢复和明早风险 |
| 自由职业项目日 | 改成项目推进签 | 看出门成本和准备成本 | 识别边界模糊 | 改成收工边界计划 |
| 学生周末学习 | 改成学习任务签 | 看预算、校区/家附近 | 识别考试/作业压力 | 改成晚间恢复安排 |

输出规则：

- 不强行使用标准上班语气；用 `今天责任强度` 代替默认工作强度。
- 如果用户没说今天是否要工作，先给低责任版，再留一个入口：`补今天任务`。
- 周末语境下，动作要更小：30 秒、5 分钟、一个收尾块。
- 下班模块可改名为 `收工/休息计划`，但保留低风险路线和明早风险提醒。
- 午饭和下班仍遵守现实候选池规则，不编店名、路线和活动。

首屏写法：

```markdown
场景：已识别[周末/补班/值班/自由项目日]
直接给：[低责任或值班版判断]
现在做：[一个收尾动作]
入口：补今天任务 / 低责任版 / 每阶段出图
```

## Jargon Downshift

场景不明时，把窄词换成大众词：

| 窄场景词 | 大众替换 |
| --- | --- |
| 评审 | 汇报 / 讨论 |
| 对齐需求 | 沟通任务边界 |
| owner | 负责人 |
| 排期 | 时间安排 |
| 复盘 | 回看今天哪里卡住 |
| 摸鱼 | 低耗回血 |
| 工位 | 桌前 / 学习位 / 工作位 |
| 大型公司/平台团队 | 公司 / 单位 / 团队 |

执行规则：

- 用户原话里有行业词时可以沿用，但不要扩写成更多黑话。
- 面向学生、实习、远程、自由职业时，优先用他们的真实场景词。
- 午饭和下班模块优先适配地点、预算、体力、路线，不按职业刻板判断。
- 图卡文案避免行业暗号，除非用户明确要办公室梗。

## First-screen Audience Adapter

识别到非办公室场景时，首屏要立刻换词和动作，不把办公室默认语境带过去。

### 学生 / 实习

- 把 `评审/对齐/需求` 换成 `汇报/作业/标准/带教反馈`。
- 午饭优先看预算、校区距离、排队和下午课表。
- 工作签优先给 `先问清标准`、`先交一个可反馈版本`。
- 下班或课后方案优先低成本、近距离和不影响第二天。

### 远程 / 自由职业

- 把 `下班` 扩展成 `收工边界`。
- 今日工作签优先给 `关掉一个任务入口`、`设一个交付窗口`。
- 精神天气优先识别边界模糊、输入过载和自我管理成本。
- 下班逃生优先给离开桌前、散步、断开消息、到点收工。

### 通勤

- 下班方案优先顺路、少换乘、少绕路和天气。
- 午饭如果发生在通勤中，优先便携、快、预算稳。
- 入口优先 `补方向`、`少绕路`、`直接回家版`。

首屏格式：

```markdown
场景：已识别[学生/实习/远程/通勤]
直接给：[贴合该场景的判断]
现在做：[一个低成本动作]
入口：[场景相关短词] / [补字段]
```

## Copy Examples

- 办公室：今天适合把复杂问题拆成三个可交付小块。
- 通勤：今晚别绕大圈，快乐要顺路才可持续。
- 学生/实习：今天先问清标准，少用脑补补齐别人的期待。
- 远程/自由职业：先设一个收工边界，让今天有结束感。
