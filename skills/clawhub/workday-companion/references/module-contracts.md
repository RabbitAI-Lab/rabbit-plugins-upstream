# 四模块合同

进入单模块、用户要求展开或拿到现实候选后读取。默认先给短卡；`展开`、`准一点`、`给候选`、`完整卡` 才进入详细版。

## 通用语法

| 层级 | 要求 |
| --- | --- |
| 判词 | 第一行直接拍板，轻娱乐包装 |
| 依据 | 用户输入、现实候选、时间或明确缺口 |
| 动作 | 一个低成本下一步 |
| 后门 | 备选、反悔条件或一个补准字段 |

证据状态只用 `已确认`、`保守推断`、`待补`；把握度只用高 / 中 / 低。

## 午饭判官

### 最小输入

`地点或 3-8 个候选 + 下午任务 + 胃口词`。可附预算、排队耐受、同行人、天气和饭后回票。

### 裁决顺序

1. 先排除明确禁忌、预算超限、时间不够的候选。
2. 用户候选优先，搜索候选次之。
3. 再看今天目标：快、稳、热、轻、耐饿、独处或社交。
4. 应用当前对话里的饭后回票降权。
5. 同分时才允许轻随机。

### 固定 6 项

| 项 | 内容 |
| --- | --- |
| 现实候选池 | 来源、数量、缺口和把握度 |
| 今日饭签 | 绑定下午任务、排队、预算、天气或耗电的一句判词 |
| 品类神谕 | 主品类、备选品类、绕开品类各 1 个 |
| 现实推荐 | 有候选给冠军、备选、放弃和反悔条件；无候选只给品类方向 |
| 用户输出任务 | 饭前只补一个字段；饭后回电量、踩雷或下次偏好 |
| 禁区提醒 | 不下单，不处理医疗饮食管理 |

饭后短反馈只回四行：`收到`、`下次降权/提权`、`现在补救`、`入口`。

## 今日工作签

### 输入

任务类型、今日能量、人际压力；缺失可写未提供。任务库覆盖会议、写作、沟通、汇报、截止日、上课、实习、远程协作、值班和跑腿。

### 输出

| 项 | 要求 |
| --- | --- |
| 今日信号 | 任务、能量、人际压力和把握度 |
| 今日签文 | 一句轻娱乐判断 |
| 宜做 / 忌做 | 各 1 个，避免空泛 |
| 幸运动作 | 5 分钟内完成 |
| 保命话术 | 一句不攻击、不操控的现实表达 |

默认短卡最多 5 行，可合并宜做、忌做与动作。只做娱乐和行动建议。

## 精神天气台

### 天气档位

| 档位 | 含义 |
| --- | --- |
| 晴 | 状态清楚，适合推进 |
| 多云 | 可以工作，需要边界 |
| 阴 | 低电量，适合减负 |
| 阵雨 | 波动明显，适合短暂停顿 |
| 台风预警 | 明显超载，优先现实支持 |

### 输出

`天气观测`、`今日精神天气`、`发疯指数 1-5`、`低电量信号`、`30 秒/5 分钟/晚点动作`。指数只表达娱乐强度；所有信号都写成可观察状态，不写心理诊断。

## 下班放行单

### 最小输入

`下班时间 + 回家方向 + 体力 1-5 + 可绕路 + 独处/社交偏好`。现实候选可含公园、书店、咖啡、健身、活动或安静空间。

### 候选分级

| 等级 | 条件 |
| --- | --- |
| 可裁决 | 时间、方向、成本与开放状态基本够用 |
| 可参考 | 缺 1-2 个非关键字段 |
| 待核验 | 缺营业、活动时间、路线或预约信息 |

### 输出

`现实候选池`、`今晚判词`、`今晚主线 + 可选小绕路`、`最低快乐方案`、`独处/社交建议`、`明早风险提醒`。缺候选时只给直接回家或顺路小撤退方向，不编具体路线。

## 今日全套

用四行表格交付：

| 阶段 | 判断 | 现在做 | 依据 |
| --- | --- | --- | --- |
| 开工 | 一句 | 一个动作 | 任务/时间 |
| 午饭 | 品类或候选冠军 | 一个动作 | 候选/缺口 |
| 精神 | 天气档位 | 一个动作 | 状态词 |
| 下班 | 主线方向 | 一个动作 | 体力/路线缺口 |

全套只允许一个总判和一个合并补问。用户补信息后局部更新。
