## Description: <br>
Helps AI-agent users, skill authors, maintainers, and teams create practical Proactive Agent-style workflows for bug fixes, setup and safety hardening, reliability improvements, and adjacent skill patterns. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External AI-agent users, skill authors, maintainers, and teams use this skill to turn requests for Proactive Agent-style productivity support into concise plans, templates, checklists, automation outlines, code changes, or decision aids. It is intended for local-hardware-friendly workflows that clarify goals, make reasonable assumptions, and validate outputs against the user's success criteria. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate for generic productivity or bug-fix requests because its trigger wording is broad. <br>
Mitigation: Confirm that the user's request is actually about Proactive Agent-style workflow support before applying the workflow. <br>
Risk: Generated plans, checklists, code changes, or shell commands could be incomplete or incorrect for the user's environment. <br>
Mitigation: Review proposed outputs against the stated success criteria and test any code or commands in a controlled local environment before relying on them. <br>
