## Description:

Guides agents in creating spoken narration and voiceovers from scripts using Gemini 3.1 Flash TTS through Replicate.

This skill is ready for commercial/non-commercial use.

## Publisher:

[pruna-ai](https://clawhub.ai/user/pruna-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to prepare scripts, voice and style settings, and Replicate requests for narration, explainers, and video voiceovers.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Selected scripts and prompts are sent to Replicate's API.

Mitigation: Confirm the content is appropriate to share with Replicate before submitting a request.

Risk: Example related-skill installation commands are unpinned.

Mitigation: Review install commands and prefer trusted or pinned sources before running them.

Risk: A Replicate API token is needed for requests.

Mitigation: Keep REPLICATE_API_TOKEN private and scoped to this use.
