# 任务拆解自检清单

派活前逐条确认：

## 原子性
- [ ] 每个原子任务文件数 ≤ 5
- [ ] 每个原子任务 API 端点 ≤ 5
- [ ] 每个原子任务包含测试

## 验收条件
- [ ] 每个任务有 3-5 条验收条件
- [ ] 每条验收条件是可执行的命令（curl/ls/jar tf）
- [ ] 第一条验收条件是文件存在性验证
- [ ] 包含边界条件验收（空值/重复/并发）

## 依赖关系
- [ ] 依赖图已绘制
- [ ] 依赖图无循环
- [ ] 每个节点的输入能量产
- [ ] 并行分支已标记

## 上下文隔离
- [ ] 每个原子任务只给最小上下文
- [ ] 不传递整个项目背景
- [ ] 任务描述自包含（agent 拿到就能干）

## 产物
- [ ] 拆解产物已写入 docs/decompose/{date}-{project}/
- [ ] 包含：需求说明 / 依赖图 / API 清单 / 任务分配表

## 效率
- [ ] 拆解耗时合理（< 预估执行耗时的 10%）
- [ ] 并行度 ≥ 3（有余地时）
