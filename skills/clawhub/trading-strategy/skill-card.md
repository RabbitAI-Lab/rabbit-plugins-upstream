## Description: <br>
Trading Strategy helps agents develop and explain trading strategies using technical analysis, backtesting, risk controls, position sizing, chart patterns, and trend identification. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, traders, and strategy analysts use this skill for educational trading-strategy development, technical-analysis discussion, risk-control planning, and backtesting workflow guidance across A-shares, US stocks, crypto, and Polymarket strategies. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Users could mistake educational trading or backtesting output for financial advice. <br>
Mitigation: Present outputs as educational analysis only and require independent review before any trading decision. <br>
Risk: Generated Python backtesting code could be run without review. <br>
Mitigation: Review generated Python before execution and run it in a controlled local sandbox. <br>
Risk: Users could connect generated workflows to brokerage, exchange, wallet, or other real-money systems. <br>
Mitigation: Do not connect outputs to real-money systems unless the operator deliberately adds, reviews, and controls that integration. <br>
