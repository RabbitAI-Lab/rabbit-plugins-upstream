# ORDER() 订单确认

**Skill ID:** `zayn-order`
- 所属分类：订单与交付
- 一句话用途：下单或内部执行前检查订单信息是否完整、一致并具备执行条件
- 当前版本：`v0.1`
- 当前状态：Draft for testing
- 规则是否完成：是，初版规则已建立
- 是否已有测试案例：否，等待真实脱敏案例
- 下一步待办：测试参数解析、最低运行条件、判断规则、风险和输出结构

ORDER() 用于下单或内部执行前，检查订单信息是否完整、前后是否一致，以及是否具备进入执行阶段的条件。它不负责订单确认后的跨部门启动，也不负责完整交付排期。

完整规则见 [SKILL.md](SKILL.md)，调用模板见 [examples.md](examples.md)，测试要求见 [tests.md](tests.md)。
