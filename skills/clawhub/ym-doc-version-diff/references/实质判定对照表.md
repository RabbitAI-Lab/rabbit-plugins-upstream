# 实质性修改判定对照表

判定目标：判断一处"修改"是**实质性修改**还是**纯格式/措辞调整**。
唯一标准：是否改变了事实内容。改变事实内容的为实质；只改变表达方式、不改变事实的为格式。

## 一、算「实质性修改」的情形（必须给旧值 → 新值）

| 类别 | 判定特征 | 示例 |
|---|---|---|
| 数字 | 任何数量、比例、阈值、序号、计数变化 | 数量 100 → 200；比例 10% → 15% |
| 日期 | 时间点、期限、生效日、截止日变化 | 交付日 2026-03-01 → 2026-04-15；期限 30 天 → 60 天 |
| 金额 | 价格、费用、违约金、赔偿额、预算变化 | 服务费 10 万 → 12 万；违约金 5% → 10% |
| 主体 | 责任方、受益方、签署方、归属方变化 | 乙方 A 公司 → 乙方 B 公司；甲方联系人变更 |
| 范围 | 适用对象、地域、产品、条款覆盖面的增减 | 适用区域"全国" → "华北地区"；清单新增一项 |
| 义务 | 责任、交付物、配合事项、保证条款增删改 | 新增"需提供季度报告"义务；删除保密义务 |
| 条件 | 触发条件、前提、验收标准、退出机制变化 | 付款条件"验收后" → "到货即付"；生效条件变更 |

> 以上任一类变化，即为实质性修改，进入变更总览表"是否实质=是"列，并必须给出旧值新值。

## 二、算「纯格式/措辞调整」的情形（不计入实质修改）

| 类别 | 判定特征 | 示例 |
|---|---|---|
| 同义替换 | 意思不变只换说法 | "须" → "应"；"甲方" → "发包方"（且全文一致替换） |
| 标点符号 | 标点增删改，不影响语义 | 句号改逗号、增加顿号 |
| 换行/分段 | 仅排版变化 | 一段拆成两段、合并段落 |
| 大小写 | 仅英文字母大小写变化 | "MySQL" → "mysql" |
| 空格 | 增删全角/半角空格、缩进 | 中英文间空格增减、列表缩进调整 |

> 注意：同义替换若出现"局部替换导致范围变化"（如只把某一条里的"甲方"改"发包方"而其他条没改），可能暗示主体范围调整，应升级为可疑项提示复核，不默认判格式。

## 三、高风险字段清单（任何涉及都单列复核）

以下字段一旦发生改动，无论幅度大小，都进"需重点复核"清单：

1. **金额** — 价格、费用、违约金、赔偿、预算、分成比例
2. **日期/期限** — 生效日、交付日、截止日、履约期限、质保期
3. **责任主体** — 签署方、付款方、交付方、连带责任方
4. **违约条款** — 违约情形、违约金、解除权、赔偿责任
5. **排他条款** — 独家、排他、竞业、不竞争约定
6. **权利义务边界** — 知识产权归属、数据权属、保密范围
7. **终止/退出机制** — 解约条件、退出流程、争议解决方式

> 高风险项标注风险级别：涉及金额/违约/主体/排他的实质改动默认"高"；仅日期/期限变化可标"中"。

## 四、容易判错的三类情况

1. **单位变化伪装成同值** — "10000 元"改为"1 万元"数值未变属格式；但"1 万元"改为"10 万元"属实质，单位变化常伴随数值变化，必须核对数值。
2. **新增限定词改变范围** — "免费提供"改为"免费提供一次"，加了次数限定，属范围/义务实质修改，不是措辞微调。
3. **数字在句中被重排** — 原"3 个工作日内"改为"3 日内"，数字 3 未变属格式；但"3 个工作日"改"5 个工作日"属实质。
