# 文档版本变更核对报告

> 复制本文件填充内容。实质性修改必须带「旧值 → 新值」，高风险项必须进第三节。

```
## 一、对齐方式说明
- 对齐依据：[标题层级 / 条款编号 / 段落序号 / 语义段落]
- 是否分段比对：[是/否，超 2 万字时说明]
- 结构是否有重排：[是/否，若有说明重排情况]
- 版本来源：[用户提供文本 / 文件路径（脱敏后）]

## 二、变更总览表
| 序号 | 类型 | 位置 | 旧值 | 新值 | 是否实质 | 风险级别 |
|------|------|------|------|------|----------|----------|
| 1 | 修改 | [第 X 章/条] | [旧值] | [新值] | 是 | 高 |
| 2 | 新增 | [插入位置] | — | [新增内容摘要] | 是 | 中 |
| 3 | 删除 | [原位置] | [删除内容摘要] | — | 是 | 低 |
| 4 | 位置移动 | [第 X → 第 Y] | — | — | 否 | — |
| 5 | 仅格式 | [位置] | — | — | 否 | — |

> 类型取值：新增 / 删除 / 修改 / 位置移动 / 仅格式或措辞调整
> 实质修改才填旧值新值；格式与移动留「—」。

## 三、需重点复核
- [序号] [位置]：[涉及金额/日期/责任主体/违约/排他/期限的实质改动，写清旧值新值]
  - 风险点：[为什么需要复核]

## 四、纯格式调整
> 仅列数量与位置，不展开内容。设为忽略格式差异时可整节删除。
- 共 [N] 处：
  - [位置 1]：[换行/标点/同义替换/大小写/空格]
  - [位置 2]：……
```

## 填写约束

1. 第二节中「是否实质=是」的每一行都必须有「旧值」与「新值」两列内容
2. 涉及金额/日期/主体/违约/排他/期限的改动，必须同时出现在第三节
3. 位置移动和纯格式不计入实质修改数量
4. 不写任何对改动原因或好坏的评价
