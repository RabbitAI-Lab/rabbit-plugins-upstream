# 动作白名单（v0.1）

> v0.1 只自动生成一种动作：`camera_follow`。其它动作等你需要时再手写。

## 一、默认动作：camera_follow

```json
{
  "id": "act_x",
  "target": "camera",
  "type": "camera_follow",
  "category": "duration",
  "slotIndex": 0,
  "slotSpan": 1,
  "easing": "linear",
  "params": {
    "followTarget": "<对象 id>",
    "damping": 0.2,
    "offsetY": -40,
    "smoothEntry": true,
    "smoothEntryDuration": 300,
    "constrainBounds": true
  }
}
```

- `followTarget` 必须是**场景内对象 id**（角色根 composite），不是角色名。
- `slotIndex: 0` = 这个块的第一段语音。
- 对白块跟随说话人；单角色场景的旁白也跟随；多角色旁白不跟随（避免乱晃）。

## 二、可以手动加的动作

| 动作 | 用途 | 最小参数 |
|---|---|---|
| `camera_move` | 推拉 / 平移 | `params: { x, y, zoom }` |
| `camera_shake` | 震动（打脸 / 爆炸） | `params: { intensity, decay, frequency }` |
| `set_anim` | 播放对象动画 | `params: { animations: [{ animName, action }] }` |
| `set_transform` | 瞬间位移 / 缩放 | `params: { x, y, scaleX, scaleY }` |
| `tween_transform` | 渐变位移 / 缩放 | `params: { x, y, scaleX, scaleY }` |
| `set_visual` | 显隐 / 翻转 / 层级 | `params: { visible, flipX, zIndex }` |
| `set_audio` | 播放音效 / BGM | `params: { action, volume, loop }` |
| `set_text` | 改文字 | `params: { content, fontSize, color }` |

## 三、不要自动加的动作

- `set_light` / `tween_light`：默认环境光 1.0，不要逐块改亮度。
- `camera_shake`：只在明确需要「震一下」时手写，不要每块都震。
- `set_screen_effect`：闪白 / 黑幕，容易滥用。

## 四、动作和槽位

- 每个 block 的 `actions[]` 里，`slotIndex` 从 0 开始。
- 动作时长由 `slotSpan` 控制；`1` = 当前槽位。
- 一个 block 可以挂多个动作，按 `order` 排序。
