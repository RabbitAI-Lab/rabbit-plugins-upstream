# 表情九宫格 Prompt

> 一张图出 8 个表情，切图后直接进工程。比逐张出更一致、更省。

## 正向

```
【主体】{{角色名}}，与角色整身图完全相同的造型、服装、配色、描边粗细
【画风锁】粗黑描边（8px），扁平纯色块，无渐变、无光影、无纹理、无 3D；极简几何造型，表情包质感；
色板只用：黑 #111111、白 #FFFFFF、主色 #F2C94C、辅色 #EB5757、冷色 #2D9CDB、肤色 #F7D7B8。
【构图】3×3 九宫格，每格一个头部/上半身特写，正面，居中，格子之间留白均匀。
【九格内容】
第 1 格：平静——两个黑点眼，一条横线嘴
第 2 格：开心——弯月眼，大弧笑，腮红
第 3 格：愤怒——倒八字眉，方口咬牙，头顶青筋
第 4 格：悲伤——下垂眼，倒弧嘴，两行泪
第 5 格：惊讶——大圆眼，O 形嘴，头顶感叹号
第 6 格：无语——一条横线眼，直线嘴，额头三条竖线
第 7 格：得意——半闭眼，歪嘴笑，挑眉
第 8 格：崩溃——蚊香眼，波浪嘴，灵魂出窍
第 9 格：空白（纯白）
【背景】纯白 #FFFFFF
【输出】1024×1024 方图，九宫格对齐，每格等大
```

## 负向

```
写实，照片，3D，光影，渐变，纹理，复杂背景，多个不同角色，
文字，水印，logo，签名，格子大小不一，角色变形，多余肢体
```

## 切图

```bash
python3 scripts/split_sheet.py 表情九宫格.png --out 角色/阿强/
```

脚本会把 3×3 切成 9 张，并按顺序命名：

```
exp_平静.png / exp_开心.png / exp_愤怒.png / exp_悲伤.png / exp_惊讶.png
exp_无语.png / exp_得意.png / exp_崩溃.png / _cell9.png
```

## 检查

- 9 格角色必须是同一个人（发型、衣服、配色一致）。
- 每格居中，不要被格子边界裁到。
- 第 9 格空着没关系，切出来删掉即可。
