# 背景 Prompt

> 背景只负责「这是哪」，不抢角色。默认不含人物、不含文字。

## 正向

```
【场景】{{地点：工位 / 会议室 / 出租屋 / 教室 / 街道 / 餐厅}}
【时间/气氛】{{早晨 / 白天 / 夜晚 / 加班}}
【画风锁】粗黑描边（6px），扁平纯色块，无渐变、无光影、无纹理、无 3D；
低饱和配色：灰蓝 #B8C4CE、米色 #E8E0D0、浅灰 #D9D9D9；
背景整体比角色低 20% 饱和，不能抢主体。
【构图】{{9:16 竖 / 16:9 横}}，正面或微透视，画面下方留出角色站位（至少 1/3 高度空地），
不出现人物、不出现文字、不出现品牌 logo。
【元素】{{桌子 / 电脑 / 白板 / 投影 / 窗 / 文件堆}}
【输出】1080×1920 或 1920×1080，单场景。
```

## 负向

```
人物，角色，剪影，文字，字幕，logo，水印，签名，
写实照片，3D 渲染，复杂光影，渐变，噪点，纹理，
多个场景拼贴，透视错乱，过于拥挤
```

## 示例（工位-早晨）

```
【场景】开放式办公室的一个工位
【时间/气氛】周一早晨，冷清，灯只开了一半
【画风锁】……（同上）
【构图】9:16 竖，正面，下方 1/3 留空给角色
【元素】一张桌子、两台电脑、一个马克杯、一把转椅、背景是文件柜和百叶窗
【输出】1080×1920
```

## 注意

- 同一地点不同时间 = 两张背景（`工位-白天` / `工位-夜晚`）。
- 背景不要画角色站位线、不要画字幕框。
- 竖屏剧优先 9:16；如果 app 工程是 16:9，出 16:9。
