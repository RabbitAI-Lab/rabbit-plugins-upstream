# 封面 Prompt

> 平台封面：大字 + 角色大脸 + 一个冲突点。不要放剧情细节。

## 正向

```
【主体】{{角色名}} 的大头特写，{{表情：震惊 / 得意 / 崩溃}}，占画面 60%
【场景】{{极简背景：纯色 / 办公室剪影}}
【大字】「{{封面标题，6–10 字}}」，粗黑体，白字黑边，放在画面上方 1/3
【画风锁】粗黑描边（10px），扁平纯色块，无渐变、无光影、无纹理、无 3D；表情包质感。
【配色】主色 #F2C94C + 黑 #111111 + 白 #FFFFFF；最多加一个辅色 #EB5757。
【构图】9:16 竖图，主体居中偏下，标题在上，右下角留 15% 安全区（平台会挡）。
【输出】1080×1920。
```

## 负向

```
写实，照片，3D，复杂背景，多个角色，小字，长句，二维码，
水印，logo，签名，低对比，标题被裁切
```

## 注意

- 标题 6–10 字，必须能一眼读完。
- 不要放「第 1 集」这种小字，平台会挡。
- 封面和第一帧不要一样，否则浪费一次抓眼机会。
