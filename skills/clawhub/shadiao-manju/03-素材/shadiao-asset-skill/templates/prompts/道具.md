# 道具 Prompt

> 只出单个物体，白底，不带场景、不带人物。

## 正向

```
【道具】{{名称：咖啡杯 / 合同 / 手机 / 工牌 / 键盘 / 泡面}}
【画风锁】粗黑描边（8px），扁平纯色块，无渐变、无光影、无纹理、无 3D；
色板与角色一致：黑 #111111、白 #FFFFFF、主色 #F2C94C、辅色 #EB5757、冷色 #2D9CDB。
【构图】单个物体，正面或 3/4 视角，居中，占画面 70%，四周留白。
【背景】纯白 #FFFFFF。
【输出】1024×1024 方图。
```

## 负向

```
人物，手，场景，桌子，背景元素，文字，水印，logo，签名，
写实照片，3D 渲染，光影，渐变，纹理，多个物体，复杂细节
```

## 注意

- 剧本里只出现一次、不被使用的道具，可以不出图。
- 道具要和角色的描边粗细、配色一致。
- 需要「被拿起 / 被拍桌」的道具，出正面 + 侧面两张（可选）。
