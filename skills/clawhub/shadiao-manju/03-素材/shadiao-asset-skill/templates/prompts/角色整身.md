# 角色整身 Prompt

> 复制整段，替换 `{{}}` 占位。先出主角，满意后再用主角图做参考出配角。

## 正向

```
【主体】{{角色名}}，{{性别}}，{{年龄感}}，{{体型}}，{{发型}}，{{服装}}，{{标志物}}
【画风锁】粗黑描边（8px），扁平纯色块，无渐变、无光影、无纹理、无 3D；极简几何造型，表情包质感；
色板只用：黑 #111111、白 #FFFFFF、主色 #F2C94C、辅色 #EB5757、冷色 #2D9CDB、肤色 #F7D7B8。
【构图】正面全身，站姿，双臂自然下垂或微微张开，居中，四周留白 ≥8%，不裁切。
【表情】中性（平静），两个黑点眼，一条横线嘴。
【背景】纯白 #FFFFFF，无任何场景元素。
【比例】{{头身比：火柴人 1:4 / Q版 1:3 / 熊猫头}}
【输出】1024×1536 竖图，单个角色。
```

## 负向

```
写实，照片，3D 渲染，PBR，光影，投影，渐变，噪点，纹理，
复杂背景，场景元素，多个角色，侧身，坐姿，手持道具，
文字，水印，logo，签名，多余手指，多余肢体，解剖细节，
恐怖，血腥，低分辨率，模糊
```

## 出图后

1. 检查：描边粗细、头身比、颜色是否和已有角色一致。
2. 白底转透明：`python3 scripts/white_to_alpha.py 角色/阿强/body.png --trim`
   > 这一步**原地覆盖** `body.png`，但会先把原图存成 `body.orig.png`；确认没问题再删备份。
   > 只想看效果就先复制一份再跑，别直接对唯一原图动手。
3. 命名：`角色/阿强/body.png`
