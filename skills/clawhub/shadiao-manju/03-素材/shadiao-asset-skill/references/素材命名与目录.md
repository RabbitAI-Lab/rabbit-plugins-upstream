# 素材命名与目录

## 一、目录结构

```
03-素材/
├── 角色/
│   └── <角色名>/
│       ├── body.png
│       ├── exp_平静.png
│       ├── exp_开心.png
│       ├── exp_愤怒.png
│       ├── exp_悲伤.png
│       ├── exp_惊讶.png
│       ├── exp_无语.png
│       ├── exp_得意.png
│       ├── exp_崩溃.png
│       ├── full_平静.png … full_崩溃.png   # 8 张预合成整身表情（推荐）
│       └── face.json            # 可选：表情对齐参数
├── 背景/
│   └── <场景名>.png
├── 道具/
│   └── <道具名>.png
├── 音效/
│   ├── 闹钟.wav
│   ├── 开门.wav
│   ├── 咚.wav
│   ├── 乌鸦.wav
│   ├── 灵魂出窍.wav
│   └── 叮.wav
├── BGM/
│   └── bgm_loop.wav
├── 封面/
│   └── 第NN集.png
└── 素材索引.json
```

- 角色名 / 场景名 / 道具名**必须和剧本 JSON 一致**（大小写、空格、标点都一致）。
- 文件名用中文可以，但不要带 `/ \ : * ? " < > |`。
- 一个角色一个目录，不要把表情堆在根目录。

## 二、尺寸

| 类型 | 建议 |
|---|---|
| 角色整身 | 1024×1536（竖） |
| 表情 | 1024×1024（方） |
| 背景 9:16 | 1080×1920 |
| 背景 16:9 | 1920×1080 |
| 道具 | 1024×1024 |
| 封面 9:16 | 1080×1920 |

## 二点五、face.json（可选）

如果表情图和整身图的脸对不齐，在角色目录放一个 `face.json`：

```json
{
  "x": 0.5,
  "y": 0.197,
  "scale": 0.6
}
```

- `x` / `y`：脸中心在整身图里的归一化坐标（0–1）。默认 `0.5 / 0.197`（1024×1536 头部中心）。
- `scale`：表情图缩放。默认 `0.6`；脸偏大就调小（0.5），偏小就调大（0.7）。
- 改完重跑 `make_index.py` 和 `build_anime.mjs`。

## 三、素材索引.json

由 `scripts/make_index.py` 生成，不要手写。

```json
{
  "characters": [
    {
      "name": "阿强",
      "gender": "male",
      "dir": "角色/阿强",
      "body": "角色/阿强/body.png",
      "face": { "x": 0.5, "y": 0.197, "scale": 0.6 },
      "expressions": {
        "平静": "角色/阿强/exp_平静.png",
        "开心": "角色/阿强/exp_开心.png"
      }
    }
  ],
  "backgrounds": [
    { "name": "工位", "file": "背景/工位.png" }
  ],
  "props": [
    { "name": "咖啡", "file": "道具/咖啡.png" }
  ],
  "cover": "封面/第01集.png"
}
```

路径**全部相对 `03-素材/`**。04 生成工程时会按这些路径拷贝进 `<剧名>_cache/assets/`。

## 四、命名冲突

- 同名背景不同集？加编号：`工位-白天.png` / `工位-夜晚.png`。
- 同名角色不同形态？用 `阿强-西装` 这种后缀，但**剧本里只写 `阿强`**，索引里加 `aliases`。
