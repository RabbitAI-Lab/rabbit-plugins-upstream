# 沙雕画风规范

## 一、画风锁（每条 prompt 都要带）

```
【画风锁】
粗黑描边（6–10px），扁平纯色块，无渐变、无光影、无纹理、无 3D；
极简几何造型，表情包质感；色板只用 6 色：黑 #111111、白 #FFFFFF、
主色 #F2C94C、辅色 #EB5757、冷色 #2D9CDB、肤色 #F7D7B8；
背景纯白 #FFFFFF；不出现文字、水印、logo、签名。
```

> 这段逐字照抄，不要每条改写。改写 = 画风漂移。

## 二、头身比

| 类型 | 头身比 | 适用 |
|---|---|---|
| 火柴人 | 1:4 ~ 1:5，圆头 + 单线四肢 | 吐槽、快节奏、成本最低 |
| Q 版三头身 | 1:3，大头小身 | 有剧情线、需要表情 |
| 熊猫头 | 头是熊猫表情包，身体是火柴人 | 强吐槽、强情绪 |

同一部剧只用一种。混用会像两部片。

## 三、配色

- 主角：主色（黄）+ 黑
- 对手：辅色（红）+ 黑
- 配角：冷色（蓝）+ 黑
- 旁白 / 系统：黑白
- 背景：低饱和灰蓝 / 米色，不能抢角色

## 四、描边与细节

- 描边统一 **8px**（1024 图）；缩到 512 时按比例。
- 手指可以省略（火柴人）或 3 根（Q 版），不要 5 根写实手指。
- 眼睛：两个黑点 / 两条线 / 熊猫头用现成表情。
- 嘴：一条线 / 一个弧 / 一个方形（大喊）。

## 五、禁止项（写进负向）

```
写实、照片、3D 渲染、PBR、光影、投影、渐变、噪点、纹理、
复杂背景、场景元素、多个角色、文字、水印、logo、签名、
多余手指、多余肢体、解剖细节、恐怖、血腥
```

## 六、一致性检查

出完一组图，并排看：

1. 描边粗细一样吗？
2. 头身比一样吗？
3. 配色是同一套吗？
4. 眼睛/嘴的画法一样吗？
5. 背景都是纯白吗？

有一项不一样 → 重出，不要凑合。
