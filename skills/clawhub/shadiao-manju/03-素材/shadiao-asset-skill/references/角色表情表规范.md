# 角色表情表规范

## 一、整身图（body.png）

| 项 | 要求 |
|---|---|
| 内容 | 正面全身、站姿、四肢自然张开 |
| 背景 | 纯白 #FFFFFF |
| 尺寸 | 1024×1536（竖）或 1024×1024 |
| 留白 | 四周 ≥ 8% |
| 表情 | 中性（平静） |
| 禁止 | 侧身、坐姿、手持道具、多个角色 |

## 二、表情差分（exp_*.png）

固定 8 个，文件名必须完全一致：

```
exp_平静.png
exp_开心.png
exp_愤怒.png
exp_悲伤.png
exp_惊讶.png
exp_无语.png
exp_得意.png
exp_崩溃.png
```

### 表情画法（火柴人 / Q 版通用）

| 表情 | 眼睛 | 嘴 | 附加 |
|---|---|---|---|
| 平静 | 两个点 | 一条横线 | 无 |
| 开心 | 两个弯月 | 大弧笑 | 腮红两点 |
| 愤怒 | 倒八字 | 方口/咬牙 | 头顶三条青筋 |
| 悲伤 | 下垂点 | 倒弧 | 两行泪 / 阴影线 |
| 惊讶 | 大圆眼 | O 形 | 头顶感叹号 |
| 无语 | 一条横线眼 | 一条直线 | 额头三条竖线 |
| 得意 | 半闭眼 | 歪嘴笑 | 挑眉 |
| 崩溃 | 蚊香眼 | 波浪嘴 | 灵魂出窍 / 裂开 |

### 九宫格方案

一张 3×3，中心放平静，其余 8 格放 8 表情（可空一格放「说话」）。切图后用文件名对应。

## 三、熊猫头

- 头：经典熊猫头表情包（黑白、粗描边、大脸）。
- 身体：火柴人，细线，可穿简单衣服（一件 T 恤 / 西装）。
- 表情：直接换熊猫头贴图，不做五官变形。
- 注意：只用「通用熊猫头」形态，不复制具体作者的原创表情包；自己重绘。

## 四、表情与剧本的对应

剧本 `emotion` 列 → 表情：

| 情绪 | 表情 |
|---|---|
| 平静 / 中性 / 温柔 / 慵懒 | 平静 |
| 开心 / 喜悦 / 高兴 / 惊喜 / 得意 | 开心 / 得意 |
| 愤怒 / 暴怒 / 生气 / 抓狂 | 愤怒 |
| 悲伤 / 低落 / 哽咽 / 哭腔 / 委屈 | 悲伤 |
| 惊讶 / 震惊 / 惊恐 / 害怕 | 惊讶 |
| 无语 / 无奈 / 尴尬 / 敷衍 / 摆烂 | 无语 |
| 厌恶 / 嘲讽 / 冷笑 / 嫌弃 | 得意（歪嘴） |
| 崩溃 / 社死 / 心虚 | 崩溃 |

## 五、尺寸与压缩

- 原始出图 1024 起，不要低于 768。
- 最终进工程的图建议 ≤ 500KB；用 `sips -Z 1024` 或 `ffmpeg -vf scale=1024:-1` 压。
- 透明 PNG 用 8-bit RGBA，不要 16-bit。
