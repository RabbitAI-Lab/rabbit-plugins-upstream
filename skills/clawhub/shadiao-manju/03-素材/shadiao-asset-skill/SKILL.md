# 沙雕素材

> 一句话：**画风统一比画得好看重要。** 同一部剧里所有角色必须像同一个画师画的。

## 〇、输入与输出

| | 内容 |
|---|---|
| 输入 | `01-剧本/剧本.json` 的 `characters[]` 与 `scenes[]` |
| 输出 | `03-素材/角色/ · 背景/ · 道具/ · 封面/` + `素材索引.json` |
| 画风 | 火柴人 + 熊猫头（默认）；粗描边、扁平色、纯色底 |

## 一、要出哪些图

按优先级：

1. **每个角色**：`body.png`（整身正面）+ 8 张表情 `exp_*.png`
2. **每个场景**：1 张背景（同场景多集复用）
3. **关键道具**：剧本里被「使用 / 抢夺 / 展示」的道具
4. **音效**：`音效/` 下按 `配音表.sfx` 命名（闹钟/开门/咚/乌鸦/灵魂出窍/叮）
5. **BGM**：`BGM/bgm_loop.wav`，循环铺底
6. **封面**：每集 1 张（可选，平台封面用）

表情固定 8 个：`平静 / 开心 / 愤怒 / 悲伤 / 惊讶 / 无语 / 得意 / 崩溃`。

## 二、工作流

### 1. 锁画风

先把 `references/沙雕画风规范.md` 的「画风锁」抄进每一条 prompt。不要每条重写。

### 2. 出角色整身

用 `templates/prompts/角色整身.md`，一个角色一条。**先出主角**，满意后再把主角图当参考出其他角色。

### 3. 出表情

两条路，选一条：

- **A（推荐）**：用 `templates/prompts/表情九宫格.md` 出一张 3×3 表情表，再用 `scripts/split_sheet.py` 切成 8 张。
- **B**：用整身图做参考，逐张出表情（一致性更好，但慢）。

### 4. 去白底

生图默认纯白底。用 `scripts/white_to_alpha.py` 转透明：

```bash
python3 scripts/white_to_alpha.py 角色/阿强/body.png --fill-holes
```

> **白衣服/白脸/白鞋必须加 `--fill-holes`**，否则 flood fill 会把白色区域一起抠成透明。
>
> **表情图（exp_*.png）同样必须加 `--fill-holes`**。少加一次，预合成出来的整颗头就是半透明的
> （近景会发灰、还会在头边留一圈白色月牙）。已经抠坏的表情图最好**重新生成**，
> 不要用「按轮廓补回白色」的脚本硬补——那个补法会在头边缘留下不透明白边。
> app 的表情系统支持 `blendMode: multiply`，白底也能用；但身体建议透明，避免挡住背景。

### 4.5 预合成整身表情（推荐）

直接让 app 叠「身体 + 表情头」会有双描边/贴纸边。先预合成：

```bash
python3 scripts/compose_bodies.py --season-dir 99-项目/<剧名>/第01季
```

输出 `full_平静.png … full_崩溃.png` 8 张整身图。
需要走位/睡觉时，再补 `full_走路.png` / `full_睡觉.png`（同样是整身图）。
`build_anime.mjs` 会优先用整身图（symbol 的 8 个 material），不再贴脸。

**compose 的两个防坑点（已内置）**：
1. 贴表情图时，mask 要和表情图自身的 alpha 取交集；否则表情图的透明区会把身体「擦」出洞。
2. **不要在 compose 之后再做「填回白色」**——形态学闭运算会把填充区外扩 1–2px，
   在头边留一圈不透明白边（近景就是「白色月牙 + 第二圈描边」）。白脸的不透明由 exp 图保证。

### 4.6 生成「会说话」的嘴（说话时嘴动）

静态整身图说话时嘴不动，像配音的纸片人。加一层嘴叠加：

```bash
python3 scripts/make_mouth.py --season-dir 99-项目/<剧名>/第01季
```

脚本会：
1. 在每张 `exp_<表情>.png` 下半部自动检测嘴巴位置（不同表情嘴的位置/大小不一样）；
2. 换算到整身画布坐标，写 `角色/<名>/mouth.json`；
3. 生成一张张开的嘴 `角色/<名>/mouth.png`（黑色圆角形状，透明底，120×120）。

`mouth.json` 结构：

```json
{
  "_sprite": { "width": 120, "height": 120, "mouthW": 108, "mouthH": 84, "closedHeight": 7 },
  "平静": { "x": 0.5026, "y": 0.4025, "w": 0.0743, "h": 0.0089, "open": false }
}
```

- `x/y`：嘴中心，整身画布归一化坐标
- `w`：嘴宽（归一化），用来定 scaleX
- `closedHeight`：合嘴时的高度（像素），太小会看不见、太大会一直有个厚嘴唇
- **人工修正**：自动检测在「鼻子离嘴太近」时会抓错（熊猫头的愤怒/悲伤会叠到鼻子上），
  这时在同目录写 `mouth.override.json`，把不准的表情改掉或设成 `null` 关掉叠加：

```json
{ "愤怒": null, "坐": { "x": 0.501, "y": 0.345, "w": 0.109, "h": 0.019, "open": false } }
```
- **没检测到的表情 = 本来就是大张嘴**（开心/惊讶/崩溃/得意），工程里会自动跳过，不叠层

### 4.7 一次出 9 个表情：九宫格（推荐）

一张图里画 3×3 九个表情，比出 9 张图省 8 次调用，而且**九个头的尺寸/描边/色板天然一致**
（分开画一定会飘，近景就是双描边、白脸红一块青一块）。

```bash
# 1) 出一张九宫格（第一次用先确认 prompt 和引擎）
python3 scripts/gen_seedream.py \
  --out 角色/阿强/_九宫格.png --raw --size 2048x2048 \
  --refs 角色/阿强/body.png \
  --prompt "【主体】3×3 九宫格表情图，同一个人…每格只画头部特写…"

# 2) 切成单张 exp_*.png（白底转透明 + 统一缩放 + 居中）
python3 scripts/cut_sheet.py --sheet 角色/阿强/_九宫格.png --out-dir 角色/阿强 \
  --names 平静,开心,愤怒,悲伤,惊讶,无语,得意,崩溃,说话 --size 300 --preview

# 3) 预合成整身图
python3 scripts/compose_bodies.py --char-dir 角色/阿强
```

**九宫格 prompt 的五个要点**：
1. 明确写「3×3 九宫格」+ **逐格列出顺序和表情**（AI 会照着排）
2. 「每格只画头部特写，不画身体」
3. 「九个头部大小完全一致，各自居中」
4. 「纯白背景」+ 禁止项写清：文字、数字、格子线、光影、渐变
5. 带角色 `body.png` 当参考图，保证是同一个人

**第 9 格建议画「说话」**（嘴微张），后面做口型/特写能用。

**换表情后必须重算 `face.json`**：九宫格切出来的头是居中的，和旧的手工表情不对齐。
用旧合成图量一遍再写回（`scale = 旧图头宽 / 新 exp 头宽`，`x/y = 旧图头中心 / 画布尺寸`），
否则头上会出现第二圈描边。

### 4.8 换角色物种（狼/狐狸/老虎…）

换一个角色形象 ≠ 换一张表情图。身体图里**自带旧头**，新头盖不住（熊猫的圆耳朵会露在狼头两侧）。
正确做法是三步：

1. **出一张「无头身体」**（一次出图，需先确认）

```
【主体】卡通角色的身体部件素材：正面站立的躯干和四肢，黑色西装、白衬衫、红领带、黑皮鞋。
**头顶以上不要画头**：脖子处是一个干净的圆形开口，像「没有安装头部」的角色素材。
【禁止】头部、脸、眼睛、耳朵、鼻子、嘴、牙齿
```

2. **把身体缩小、下移，给头腾出空间**：脖子在画面最上面时，头没地方放。
   用 PIL 把身体缩到 ~0.57、底部对齐 y=1440，再贴到 1024×1536 画布上。

3. **重算 `face.json`**：头宽对齐肩宽（卡通大头给到 1.5–1.6 倍肩宽），
   `y` 让头的下沿压在领口上一点点（否则会出现脖子断层）。

如果实在拿不到无头身体，`face.json` 里可以写 `eraseHead` 先把旧头擦掉：

```json
{ "eraseHead": [{ "x": 0.499, "y": 0.318, "r": 0.245 }] }
```

但**同物种换头才可靠**（擦除形状和新头形状一致）；跨物种擦不干净，别硬来。

### 5. 出背景 / 道具 / 封面

用对应 prompt 模板。背景**不要人物**，道具**不要场景**。

### 6. 写素材索引

`scripts/make_index.py` 扫描目录，生成 `素材索引.json`：

```bash
python3 scripts/make_index.py --season-dir 99-项目/<剧名>/第01季
```

### 7. 自检

- [ ] 所有角色同一画风（描边粗细、配色、头身比一致）
- [ ] 8 个表情齐全，文件名正确
- [ ] 8 张 `full_*.png` 整身表情已生成（推荐）
- [ ] 身体透明（或纯白 + 下游用 multiply）
- [ ] 背景没有人物、没有文字
- [ ] 道具是单个物体、白底
- [ ] `素材索引.json` 里的路径全部存在
- [ ] 表情和整身图的脸对得上；对不齐就在角色目录加 `face.json` 调 `x / y / scale`

## 四、生图通道

默认用本目录的 Seedream 脚本，密钥只从环境变量 `ARK_API_KEY` 读（脚本不打开任何配置文件）：

```bash
export ARK_API_KEY="你的火山方舟密钥"     # 或 source 自己的密钥文件
python3 scripts/gen_seedream.py \
  --out 角色/阿强/body.png \
  --prompt "……" --size 1024x1536
```

> ⚠️ 数据边界：prompt **和每一张 `--refs` 参考图（base64）都会发到火山方舟**。
> 有版权的参考图、含真人的照片、未公开的角色设定，先确认能不能外发。
> 不想联网就用宿主自带的本地生图，或手动准备素材。

也可以走宿主自带的 `generate_image` / `edit_image`，或者即梦、可灵、Midjourney 等外部工具。

**统一要求**：出图后按规范命名并放进 `03-素材/`，再跑 `make_index.py`。

> 如果你本地另有一套 `23-视频制作/05-图片制作/cinematic-image-studio`，也能用，命令见那个 skill。
> 本仓库不包含它，不影响主流程。
