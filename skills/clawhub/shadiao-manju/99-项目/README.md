# 99-项目

所有沙雕漫剧项目都放这里，**一剧一根目录，一季一子目录**。

```
99-项目/
└── <剧名>/
    ├── 全剧设定.md
    └── 第01季/
        ├── 00-立项/立项单.md
        ├── 01-剧本/第01集.md · 剧本.json
        ├── 02-配音/第01集/S001.mp3 · 配音表.json
        ├── 03-素材/角色/ · 背景/ · 道具/ · 素材索引.json
        ├── 04-工程/<剧名>.anime · <剧名>_cache/tts/ · 校验报告.md
        ├── 05-成片/第01集.mp4
        └── 06-质检/上线检查单.md
```

## 硬规则

1. **不许把产物写到 skill 目录外**（Desktop / /tmp / 别的 skill）。
2. 剧名一旦定了不要改（路径、工程名、音频目录都靠它）。
3. 多季用 `--season 2`；跨季共享 `全剧设定.md`。
4. 生成工程前先确认 `03-素材/素材索引.json` 存在。

## 示例项目

仓库带一个 `示例-周一打工人/`：2 个角色、1 个场景、三集 47–48 秒，用来对照目录结构和产物格式。可以直接复制改名当模板。

成片 mp4 和生成物不入库；素材、剧本、配音表保留，按 04 的命令重新生成工程。
