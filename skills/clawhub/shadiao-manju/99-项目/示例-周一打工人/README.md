## 仓库里保留了什么

- `01-剧本/`：三集人读版剧本、机器读版 JSON、生成脚本 `make_eps.py`
- `02-配音/`：三集 `配音表.json`（音频文件按 `.gitignore` 忽略，可重新合成）
- `03-素材/`：两个角色的整身图、8 表情、嘴位参数、背景、道具、音效、BGM
- `05-成片/`：三张封面

`04-工程/` 是生成目录，`.anime` 不入库。

## 固定素材（三集共用，不再换）

- **背景**：`会议室.png`（Seedream 5.0 pro 出图，空白板 + 长桌 + 两排椅）
- **阿强**：蓝色圆头、白连帽卫衣，9 表情九宫格（平静/开心/愤怒/悲伤/惊讶/无语/得意/崩溃/说话）
- **老板（狼）**：灰色狼头 + 黑西装红领带，无头身体 + 9 表情九宫格，`bodyScale 1.30`
- **音效 / BGM**：闹钟、开门、脚步、咚、乌鸦、灵魂出窍、叮 + `bgm_loop.wav`

## 跑一遍

```bash
# 1) 合成配音（edge，秒级；台词会发到微软在线服务，私密内容改用 --engine say）
python3 02-配音/shadiao-voice-skill/scripts/tts_batch.py \
  --project 示例-周一打工人 --season 1 --episode 1 --engine edge

# 2) 生成工程
node 04-工程/shadiao-anime-skill/scripts/build_anime.mjs \
  --project 示例-周一打工人 --season 1 --episode 1

# 3) 打开 app，预览，导出；然后 ffmpeg 收尾
python3 05-出片/shadiao-export-skill/scripts/mix_audio.py \
  --video raw.mp4 --out mixed.mp4 \
  --manifest 99-项目/示例-周一打工人/第01季/02-配音/第01集/配音表.json \
  --sfx-dir 99-项目/示例-周一打工人/第01季/03-素材/音效 \
  --bgm 99-项目/示例-周一打工人/第01季/03-素材/BGM/bgm_loop.wav
```

`render_ep.sh` 是把上面这些串起来的一条龙脚本，里面写死了无头 Chrome 导出的路径，换机器要改 `CHROME` / `FAA_HOME`。

## 剧本写法（三集都是同一套）

痛点 → 夸张成一条规则 → 老板一本正经定 → 阿强一本正经执行 → 老板自己被规则打死 →
阿强把「说不出口的话」说出口 → 冷幽默 + 黑屏字幕。

剧本源：`第01季/01-剧本/make_eps.py`（三集都在这一个文件里，改完重跑即可）
