# 沙雕出片

> 一句话：**工程已经准备好了，你只需要点两下。** 剩下的交给 ffmpeg。

## 〇、前置检查

- [ ] `04-工程/校验报告.md` 是「通过」
- [ ] `04-工程/<剧名>.anime` 存在
- [ ] `04-工程/<剧名>_cache/tts/` 里有 mp3
- [ ] `04-工程/<剧名>_cache/assets/` 里有角色和背景图
- [ ] app 已启动（`bash 00-工作台/setup_app.sh start`）
- [ ] 已打 9:16 补丁（`bash 00-工作台/patch_vertical.sh apply`）
- [ ] 浏览器是 Chrome / Edge

## 一、在 app 里导出（人工，约 1 分钟）

1. 打开 `http://localhost:5173`
2. 点「打开项目文件夹」→ 选 `99-项目/<剧名>/第NN季/04-工程`
3. 打开 `<剧名>.anime`
4. 点「预览」，从头听一遍（重点听：有没有没声音的块、字幕是否对得上）
5. 点「导出」：
   - 分辨率：1080×1920 竖屏（补丁后预设里才有）
   - 帧率：30 / 60
   - 质量：高
   - 字幕：建议开
6. 导出完成后，把 mp4 移到 `05-成片/第NN集.mp4`

> 导出是浏览器端逐帧渲染 + 编码，1 分钟成片大约要等 1–3 分钟，不要中途切后台。

## 二、ffmpeg 收尾

```bash
bash 05-出片/shadiao-export-skill/scripts/postprocess.sh \
  99-项目/<剧名>/第01季/05-成片/raw.mp4 \
  99-项目/<剧名>/第01季/05-成片/第01集.mp4 \
  --ratio 9:16
```

常用参数：

| 参数 | 作用 |
|---|---|
| `--ratio 9:16` | 竖屏，1080×1920，不足补黑边 |
| `--ratio 16:9` | 横屏，1920×1080 |
| `--crf 20` | 质量，越小越清晰（18–23） |
| `--no-loudnorm` | 不做 -16 LUFS 响度统一 |
| `--cover 3` | 额外抽第 3 秒做封面 `cover.jpg` |

## 三、字幕重烧（推荐）

app 自带字幕是「白字 + 黑底方块」。导出时把 `showSubtitles` 设为 **false**，
再用 `burn_subtitles.py` 烧一版带关键词高亮、淡入/弹入的字幕：

```bash
python3 05-出片/shadiao-export-skill/scripts/burn_subtitles.py \
  --video 05-成片/第01集-混音.mp4 \
  --out   05-成片/第01集.mp4 \
  --manifest 02-配音/第01集/配音表.json \
  --crf 20 --ratio 9:16
```

- 关键词（摸鱼 / 老板 / KPI / 灵魂 / 翻倍…）自动黄色高亮
- 半透明黑底 + 描边 + 淡入 + 轻微弹入
- 同时做一层很轻的暗角/饱和度调整，画面更有质感

## 三点五、黑屏结尾卡（add_endcard.py）

沙雕片的标准收尾：一句冷幽默 → 黑屏字幕。纯 ffmpeg，不依赖 app。

```bash
python3 scripts/add_endcard.py --video out-sub.mp4 --out 第01集.mp4 \
  --line1 "本故事纯属虚构" \
  --line2 "如有雷同，说明你们公司也这样" \
  --duration 2.4
```

- 自动读原片分辨率/帧率，生成同规格黑卡拼到尾部（+2.4s）
- 音轨自动补等长静音，不会出现「后半段没声音」
- `--line1` 主句，`--line2` 副句（灰色、小一号）
- 顺序：混音 → 重烧字幕 → **结尾卡**（最后一步，避免字幕工具重编码丢掉它）

## 三点八、一集到底：render_ep.sh（只留一个成片）

手动跑七步太容易漏。项目里放一个 `render_ep.sh`，一条命令从剧本跑到成片：

```bash
bash 99-项目/<剧名>/render_ep.sh 1 "如有雷同，说明你们也不敢回"
```

它依次做：写剧本 → 校验 → 配音 → 生成工程 → 无头导出（起 Chrome、轮询产物、收工）→
混音 → 重烧字幕 → 加结尾卡 → **删掉 raw/混音/sub 中间件**，只留 `第0N集.mp4` 和封面。

- 前置：`npm run dev`（Vite）和 upload server 必须在跑
- 导出是异步的，脚本用「轮询文件是否出现」而不是 sleep 固定秒数
- 连做多集直接串：`bash render_ep.sh 1 && bash render_ep.sh 2 && bash render_ep.sh 3`

## 四、音效 + BGM 混音

app 导出的是**只有人声**的成片。音效和 BGM 走后期混音，不依赖 app 的音频轨：

```bash
python3 05-出片/shadiao-export-skill/scripts/mix_audio.py \
  --video 99-项目/<剧名>/第01季/05-成片/第01集-raw.mp4 \
  --out   99-项目/<剧名>/第01季/05-成片/第01集-混音.mp4 \
  --manifest 99-项目/<剧名>/第01季/02-配音/第01集/配音表.json \
  --sfx-dir 99-项目/<剧名>/第01季/03-素材/音效 \
  --bgm     99-项目/<剧名>/第01季/03-素材/BGM/bgm_loop.wav
```

- 音效按 `配音表.json` 的 `sfx` 字段 + 句首时间自动摆放
- 命名约定：`闹钟.wav` / `开门.wav` / `脚步.wav` / `咚.wav` / `乌鸦.wav` / `灵魂出窍.wav` / `叮.wav`
- 多音效用 `+` 拼：`脚步+咚`
- BGM 默认循环铺满，音量 `0.12`；音效默认 `0.45`
- 混音后再跑 `postprocess.sh` 做响度归一 + faststart

## 五、导出后检查

- [ ] 全片有声，没有「突然静音」的块
- [ ] 字幕和声音对齐
- [ ] 角色没有被裁出画面
- [ ] 背景铺满，没有黑边 / 白边
- [ ] 音量：手机外放不炸、不闷
- [ ] BGM 不盖人声；音效卡在点上（咚/叮/乌鸦）
- [ ] 字幕只有一层（app 字幕已关），关键词高亮正确
- [ ] 首帧能抓人（标题/冲突在第 1 秒内）

## 六、常见问题

| 症状 | 原因 | 处理 |
|---|---|---|
| 打开文件夹提示「未找到 .anime」 | 选错了目录 | 选 `04-工程`，不是 `99-项目` |
| 预览没声音 | 音频没在 `_cache/tts/` | 重跑 `04-工程/shadiao-anime-skill/scripts/build_anime.mjs` |
| 导出卡住 | 浏览器内存不足 | 关掉其他标签页；降低分辨率到 720×1280 再试 |
| 导出文件很大 | 默认码率高 | 跑 `postprocess.sh --crf 23` |
| 导出只有 1920×1080 横屏 | 没打竖屏补丁 | `bash 00-工作台/patch_vertical.sh apply` 后重启 |
| 画面比例不对 | 工程画布不是 9:16 | 04 生成时加 `--width 1080 --height 1920` |
| 字幕被平台挡 | 底部安全区 | 在 app 里把字幕上移，或 05 加 `--safe-bottom`（待加） |
