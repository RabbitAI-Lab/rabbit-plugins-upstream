# 沙雕质检

> 一句话：**发布前把片子当陌生人看一遍。** 你自己知道剧情，观众不知道。

## 一、质检流程

1. **静音看一遍**：关掉声音，看画面能不能看懂「谁倒霉了」。
2. **闭眼听一遍**：不看画面，听不听得懂完整故事。
3. **1.5 倍速看一遍**：节奏有没有拖。
4. **手机外放看一遍**：音量、字幕、安全区。
5. **对单勾选**：`references/上线检查单.md`。

## 二、必过项（不过不发）

| 项 | 标准 |
|---|---|
| 前 3 秒 | 有冲突 / 反常 / 打脸，不能是背景介绍 |
| 笑点密度 | 60 秒 ≥ 4 个；90 秒 ≥ 6 个 |
| 结尾 | 反转 / 打脸 / 钩子，不能是总结 |
| 音画同步 | 字幕与声音误差 < 200ms |
| 静音成立 | 关声音仍能看懂主线 |
| 合规 | 无政治/低俗/暴力/歧视/真实人物诽谤 |
| 授权 | 素材、音乐、音色都有来源 |
| AI 标识 | 已标注 AI 生成 |
| 安全区 | 字幕/标题不被平台 UI 遮挡 |

## 三、输出

`06-质检/上线检查单.md`，包含：

- 成片路径、时长、分辨率
- 逐项勾选结果
- 未通过项 + 修改建议
- 发布信息（标题 / 封面 / 话题 / 发布时间）

## 四、常见打回原因

| 原因 | 修法 |
|---|---|
| 前 3 秒太温 | 把最炸的一句提到第 1 行 |
| 中段平 | 加一个「新人物 / 新道具 / 身份揭露」 |
| 结尾泄气 | 换成反转或下一集问题 |
| 字幕太小 | 字号 ≥ 48（1080 宽），关键词加粗 |
| 音量忽大忽小 | 05 跑 loudnorm |
| 封面和首帧一样 | 重做封面，放大脸 + 大字 |
| 音色串戏 | 回 02 检查一角色一音色 |
