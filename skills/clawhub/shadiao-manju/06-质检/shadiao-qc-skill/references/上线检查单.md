## 二、内容（逐项打勾）

- [ ] 前 3 秒有冲突 / 反常 / 打脸
- [ ] 60 秒内 ≥ 4 个笑点（90 秒 ≥ 6 个）
- [ ] 每 10–20 秒有一个新信息
- [ ] 结尾有反转 / 打脸 / 钩子
- [ ] 没有解释笑话
- [ ] 没有「今天就到这里」式收尾
- [ ] 角色说话方式能区分
- [ ] 剧情没有前后矛盾

## 三、音画

- [ ] 全片有声，没有静音块
- [ ] 字幕与声音误差 < 200ms
- [ ] 字幕没有错别字
- [ ] 字幕字号 ≥ 48，手机能看清
- [ ] 字幕在安全区内（底部留 15%）
- [ ] 角色没有被裁切
- [ ] 背景铺满，没有黑边
- [ ] 手机外放音量正常，不炸不闷

## 四、静音 / 闭眼测试

- [ ] 静音看：能看懂谁倒霉了
- [ ] 闭眼听：能复述完整故事
- [ ] 1.5 倍速：节奏不拖

## 五、合规

- [ ] 无政治敏感
- [ ] 无低俗 / 软色情
- [ ] 无暴力血腥
- [ ] 无地域 / 性别 / 民族歧视
- [ ] 无真实人物诽谤 / 影射
- [ ] 未授权 IP 已改
- [ ] 素材为自制或可商用
- [ ] 音乐为平台曲库或可商用
- [ ] 音色不指向可识别真人
- [ ] 已标注 AI 生成
- [ ] 标题 / 封面不夸大、不误导

## 六、发布物料

- [ ] 标题（≤ 20 字，含冲突/悬念）
- [ ] 封面（大字 + 大脸，和首帧不同）
- [ ] 话题（3–5 个，平台相关）
- [ ] 简介 / 钩子句
- [ ] 发布时间（目标人群活跃时段）
