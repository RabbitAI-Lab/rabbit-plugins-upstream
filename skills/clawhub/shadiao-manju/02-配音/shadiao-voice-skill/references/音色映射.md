## 三、怎么用

```bash
# 1) 先听参考
open "../23-视频制作/10-音色制作/抖音/搞笑解说.WAV"

# 2) 在剧本 characters[].voice 里写预设名
#    { "name": "阿强", "voice": "云希-清亮少年" }

# 3) 跑配音
python3 02-配音/shadiao-voice-skill/scripts/tts_batch.py --project <剧名> --season 1 --episode 1 --engine edge
```

> `--engine edge` 会把台词文本发到微软在线语音服务；不能外发的剧本用 `--engine say` 或 `--engine clone`（本地）。

## 四、克隆模式怎么走

`--engine clone` 时，脚本会：

1. 先查 `voices.json` 里该预设的 `cloneRef`；
2. 有 → 用这条 WAV 做零样本参考；
3. 没有 → 用 `10-音色制作/voice-timbre-library/assets/source/音色音频/aishell3/` 的默认参考。

**合规闸门**（脚本强制执行）：

- 不加 `--clone-consent` → 直接退出，一句都不合成；
- 参考音频在 `10-音色制作/抖音/` 下 → 判定「未登记授权」，默认拦截，只有 `--allow-unverified` 才放行（仅内部测试）；
- 放行后 `配音表.json` 会标注 `"license": "unverified"`，对外发布前必须换成 `aishell3` 或自录参考。
