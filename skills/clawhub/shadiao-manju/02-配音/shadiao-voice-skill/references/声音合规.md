# 声音合规

> 声音能指认到具体的人，风险高于图片。以下是一票否决项，不因「只是内部测试」而放宽。

## 一、一票否决

1. **禁止克隆 / 模仿可识别真人**——《民法典》第 1023 条：声音保护参照肖像权。
   - 明星、主播、CV、同事、朋友、家人，全都不行。
   - 拿真人录音做零样本参考也不行。
2. **未经授权不得使用他人录音制品**（著作权法 · 录音制作者权）。
3. **不得用 AI 音色冒充真人发言**（虚假信息，比侵权更重）。
4. **不得指向特定动漫 / 影视角色**做商业使用（如「野原小新」「黛玉」这类角色名，只能作为内部音色类型参考，不能对外宣称是角色本人）。

## 二、抖音 21 条参考怎么用

`23-视频制作/10-音色制作/抖音/` 下的 WAV **没有授权留证**，且包含可指认角色名。默认策略：

| 用途 | 允许？ | 说明 |
|---|---|---|
| 听感参考（挑音色类型） | ✅ | 只用它决定「要一个快的吐槽男声」 |
| edge-tts 预设逼近 | ✅ | 不复制原音频，只用参数 |
| IndexTTS 零样本克隆 | ⚠️ | 默认**不做**；需用户书面确认来源与用途 |
| 对外发布 | ❌ | 除非已登记授权，否则必须换 `aishell3` / 自录 |

`tts_batch.py --engine clone` 的前置闸门（脚本强制，不是口头约定）：

- 必须加 `--clone-consent` 声明已获授权，否则直接退出、不合成；
- 参考音频落在 `10-音色制作/抖音/` 下会被判定为「未登记授权」，默认拦截；
  只有加 `--allow-unverified` 才放行，且仅限内部测试。

`配音表.json` 里会按参考音频来源标注：

```json
"license": "unverified",       // 抖音参考（未登记授权）
"license": "user-provided",    // 使用者自备参考，需自行确认授权
"license": "dataset",          // 未指定参考，回落 aishell3 公开数据集
"licenseNote": "抖音参考未登记授权，对外发布前必须替换"
```

## 三、推荐的可商用音色源

| 来源 | 授权 | 位置 |
|---|---|---|
| `aishell3` | Apache-2.0 | `10-音色制作/voice-timbre-library/assets/source/音色音频/aishell3/` |
| 自录 | 自己拥有 | 自己录，按 `10-音色制作` 的降噪链处理 |
| edge-tts 预设 | 微软服务条款 | 只用参数，不下载音色库 |
| macOS `say` | 系统自带 | 离线兜底 |

## 四、发布前检查

- [ ] 没有克隆可识别真人
- [ ] 抖音参考只做听感 / 或已登记授权
- [ ] 音色不指向特定动漫影视角色
- [ ] 已标注 AI 生成
- [ ] 没有用 AI 音色冒充真人发言
- [ ] 音乐 / 音效有授权或用平台曲库
