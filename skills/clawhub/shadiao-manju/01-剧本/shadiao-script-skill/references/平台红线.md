# 平台红线

> 沙雕可以荒诞，但不能踩线。以下按「一票否决」和「高风险」两级处理。

## 一、一票否决（写了就删）

| 类型 | 具体 |
|---|---|
| 政治敏感 | 领导人、党政机关、军队、国旗国徽的戏谑/影射 |
| 违法犯罪教学 | 诈骗、赌博、制毒、翻墙、黑客的具体操作 |
| 色情低俗 | 性暗示、软色情、擦边、未成年性化 |
| 暴力血腥 | 虐待、自残、详细伤害过程、血腥画面 |
| 歧视仇恨 | 地域黑、性别歧视、民族/宗教歧视、身材/外貌羞辱 |
| 真实人物 | 诽谤、影射、未经授权改编真人真事 |
| 未授权 IP | 直接使用他人动漫/影视/游戏角色、台词、剧情 |
| 虚假信息 | 编造灾情、疫情、政策、金融信息 |
| 未成年人伤害 | 诱导危险动作、校园霸凌美化 |

## 二、高风险（要改）

| 类型 | 风险 | 改法 |
|---|---|---|
| 拿老板/同事开刀 | 可对号入座 | 改虚构公司、虚构姓名、夸张到不可能 |
| 方言/口音 | 容易被指地域黑 | 只做音色，不做「某地人都怎样」的判断 |
| 网络热梗 | 过时快、可能侵权 | 用结构，不用原句；不依赖单一梗 |
| 医疗/金融/法律 | 可能被当成建议 | 加「剧情效果，不构成建议」 |
| AI 生成 | 平台要求标识 | 发布时勾选「AI 生成」/ 文案标注 |

## 三、版权边界

- 小说改编：只用**你原创 / 已授权 / 公版**的内容。
- 授权不明：改成「摘要 + 评论」，或只保留宽泛类型元素，重写全新故事。
- 素材：角色/背景/道具必须自制或可商用；不直接抠他人动画帧。
- 音色：不克隆可识别真人（详见 `02-配音/.../声音合规.md`）。
- 音乐：用平台曲库或可商用音乐；不直接搬影视/游戏 BGM。
