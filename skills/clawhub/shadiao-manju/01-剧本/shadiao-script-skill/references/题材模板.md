# 题材模板

> 不知道写什么时，从这里挑一个骨架，换人物和细节即可。每个骨架都给「钩子 → 升级 → 反转」。

## 1. 打工人

- **人设**：全公司最卷的人，卷的全是没用的事
- **钩子**：提前一小时到公司，发现老板睡在他工位
- **升级**：他决定不叫醒老板，开始表演「我很忙」
- **反转**：老板醒了，说「你演得不错，升你当演员」
- **笑法**：反差 + 死鱼眼旁白

## 2. 校园

- **人设**：全班倒数第一，但特别会讲道理
- **钩子**：老师让他上台讲学习经验
- **升级**：他讲了一套完整的「如何合理摆烂」
- **反转**：老师记了笔记，说「下周家长会你来讲」
- **笑法**：身份反转 + 误解

## 3. 家庭

- **人设**：全家的「翻译官」，专门翻译爸妈的潜台词
- **钩子**：妈妈说「随便你」，他当场掏出翻译器
- **升级**：翻译器连续翻译三句，句句扎心
- **反转**：爸爸掏出同款翻译器，翻译妈妈对他的评价
- **笑法**：递进重复 + 反应镜头

## 4. 修仙 / 玄幻

- **人设**：穿越成最弱弟子，唯一技能是「嘴硬」
- **钩子**：全宗门嘲笑他修为为零
- **升级**：他用嘴硬把长老说到道心不稳
- **反转**：宗门连夜修改门规：禁止和他说话
- **笑法**：夸张 + 反差

## 5. 职场面试

- **人设**：面试官比候选人还紧张
- **钩子**：候选人掏出简历，面试官先跪了
- **升级**：两人开始互相面试
- **反转**：公司其实是候选人开的
- **笑法**：身份反转

## 6. 萌宠 / 动物拟人

- **人设**：一只自以为是的猫，负责全家的安全管理
- **钩子**：它发现家里进了「可疑生物」（一只苍蝇）
- **升级**：它制定三级作战计划，全程失败
- **反转**：苍蝇自己飞走了，它宣布「成功驱逐」
- **笑法**：夸张 + 死鱼眼旁白

## 7. 神话 / 历史人物（公版）

- **人设**：神仙也要打卡上班
- **钩子**：如来佛祖因为 PPT 没交被点名
- **升级**：众神开始互相甩锅
- **反转**：玉帝说「这锅我背，反正我不用下班」
- **注意**：只用公版神话形象，不做宗教戏谑；不影射现实机构

## 8. 悬疑 / 反转

- **人设**：一个总能推理出错误答案的侦探
- **钩子**：案发现场只有一杯没喝完的咖啡
- **升级**：他连续排除三个嫌疑人，全排错
- **反转**：凶手是那杯咖啡（咖啡因过量）
- **笑法**：误解 + 反差

## 选题材三问

1. 观众 3 秒内能不能看懂「谁倒霉了」？
2. 这个题材能不能用 2 个角色 + 1 个场景演完？
3. 结尾有没有一个能截图转发的句子？
