# 音频优先

> 沙雕动画的时间轴由音频驱动。观众很多是「听」完的，不是在盯画面。
> 铁律：**删掉所有画面提示，只听台词，仍然知道谁在、在哪、发生了什么、为什么变。**

## 一、必须写进台词的五类信息

| 信息 | 错误写法 | 正确写法 |
|---|---|---|
| 人物进出 | 画面：老板走进来 | 旁白：老板推门进来，手里还端着我的咖啡。 |
| 地点变化 | 画面：切到会议室 | 旁白：十分钟后，我被叫进了会议室。 |
| 道具使用 | 画面：阿强拿起合同 | 阿强：这合同我先看看……等等，怎么是卖身契？ |
| 动作/表情 | 画面：阿强震惊 | 旁白：阿强的表情，像刚发现自己工位被卖了。 |
| 情绪转折 | 画面：老板变脸 | 老板：刚才说加薪是开玩笑的，你怎么还当真了？ |

## 二、一行一句的粒度

- 一行 = 一个说话单元 = 一条字幕 = 一段 TTS。
- **≤ 30 字**，约 4–6 秒。
- 一句里不要同时完成「解释 + 反转 + 吐槽」三件事，拆成三行。

### 拆分示例

❌ 太长：
> 旁白：阿强本来想摸鱼，结果发现老板在工位睡觉，于是他决定拍照发群，没想到老板突然醒了。

✅ 拆成四行：
1. 旁白：阿强本来想摸鱼。
2. 旁白：结果发现老板正睡在他工位上。
3. 阿强：这必须拍照发群。
4. 旁白：他刚举起手机，老板睁眼了。

## 三、桥接句

时间、地点、话题、关系、道具跳变之前，必须有一句桥接：

- 时间：「第二天」「三年后」「半小时后」
- 地点：「他刚走到门口」「镜头一转，会议室里」
- 关系：「顺便说一句，这老板是他亲舅」
- 道具：「问题就出在那杯咖啡上」
- 动机：「他本来不想管，直到听见那句『扣工资』」

没有桥接 = 观众听不懂 = 划走。

## 四、旁白与对白的配比

- 60 秒：旁白 40–60%，对白 40–60%。
- 纯旁白会变成「有声小说」，纯对白会失去信息。
- 每个场景至少一句旁白（交代时空）+ 两句对白（让人物自己演）。

## 五、音效不是信息载体

音效只做气氛和节奏，**不能承担剧情**。

- ✅「音效：咚」配合「老板把合同拍桌上」
- ❌ 只写「音效：电话铃」，却不说谁接、说了什么

## 六、朗读测试

写完一集，用系统朗读 / edge-tts 粗读一遍，检查：

> ⚠️ 用 edge-tts 粗读会把**整段台词文本发到微软在线语音服务**，不是本地处理。
> 未公开、含商业信息或不能外发的剧本，请改用 `--engine say`（macOS 本地）或 `--engine clone`（本地 IndexTTS）。

1. 有没有哪句听不懂？（改）
2. 有没有哪句太长、喘不过气？（拆）
3. 有没有哪句必须看画面才懂？（搬进台词）
4. 闭眼听，能不能复述出完整故事？（不能就重写）
