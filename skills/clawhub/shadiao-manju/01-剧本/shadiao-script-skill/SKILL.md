# 沙雕剧本

> 一句话：**先让人耳朵笑，再让眼睛笑。** 沙雕动画靠旁白和对白推进，画面是配料，不是主菜。

## 〇、输入与输出

| | 内容 |
|---|---|
| 输入 | 一句话 / 段子 / 小说章节 / 热点 / 链接 / 文件；可选：平台、集数、时长 |
| 输出 | `01-剧本/第NN集.md`（人读）+ `01-剧本/剧本.json`（机器读） |
| 默认 | 9:16 竖屏、单集 60–120 秒、3–8 个角色、2–6 个场景 |

## 一、极简两角色 · 离谱规则流（默认写法，先按这个来）

> 一句话：**选痛点 → 夸张成规则 → 老板定、员工认真执行 → 老板自己翻车 → 冷幽默收尾。**

2 个角色、1 个场景、40–60 秒，不靠人设靠**规则**。想写别的类型再往下看第二节。

### 第 1 步：选一个真实痛点

从办公室常见事里挑一个，要求：**大家都懂、不敏感、两句话能说清**。

| 可用痛点 | 夸张后 |
|---|---|
| 秒回消息 | 群里 3 秒不回「收到」算旷工 |
| 日报字数 | 日报不满三千字算没上班 |
| PPT 高端大气 | PPT 不高端大气，算没做 |
| 下班前发需求 | 需求必须在下班前 1 分钟发 |
| 周报写闭环 | 周报必须有闭环，闭不了就闭环人 |
| 汇报要有抓手 | 没有抓手的工作不算工作 |

### 第 2 步：夸张成一条规则

**公式：真实痛点 + 夸张 100 倍 = 沙雕规则。**

规则必须**可执行、可量化、可翻车**（3 秒 / 三千字 / 1 分钟）。不可量化的规则演不出来。

### 第 3 步：两个角色只干两件事

- **老板**：一本正经地定离谱规则，**真心觉得合理**。
- **员工**：一本正经地**执行**离谱规则，越认真越好笑。

> ⚠️ **不要给员工加吐槽人设**。不许翻白眼、不许阴阳怪气、不许讲道理。
> 他只要平静地说离谱话、认真地做离谱事，笑点自己就出来了。

### 第 4 步：四段式结构

| 段 | 时间（40s 版） | 内容 |
|---|---|---|
| 钩子 | 0–8s | 老板宣布离谱规则 |
| 执行 | 8–22s | 员工认真照做，出现第一个离谱结果 |
| 升级 | 22–35s | 结果失控，老板自己被卷进来 |
| 反转 | 35–43s | **老板先翻车**，员工一句话点破 → 黑屏字幕 |

> 关键：**翻车的必须是老板**，不是员工。员工翻车只是惨，老板翻车才叫爽。

### 第 5 步：台词短、少解释、多重复

- **每句 ≤ 15 字**（比常规 30 字更狠，短才有节奏）。
- 不解释规则为什么合理，直接执行。
- 关键名词**重复 3 次以上**才形成笑点（赋能 / 降本增效 / 收到 / 闭环）。
- 结尾一句冷幽默就停，**不要总结道理**，后面接黑屏字幕。

### 万能填空模板

```
老板：宣布个新规定：______。
员工：这会不会太______？
老板：这是为了______。
员工：明白，我______。
（下一秒 / 第二天，结果出现：______。）
老板：怎么______？
员工：您不会也______吧？
老板：……我用的是______。
员工：那现在谁在______？
（手机响 / 打印机出纸 / 群里刷屏）
员工：______。            ← 冷幽默点破
老板：……                ← 或者只给一句硬撑
```

### 写完检查 6 条

- [ ] 前 10 秒出现了离谱规则
- [ ] 一个定规则、一个认真执行（员工没在吐槽）
- [ ] 有连续升级，不是原地讲道理
- [ ] 反转是**老板先翻车**
- [ ] 台词都短，能删的解释性废话都删了
- [ ] 结尾一句冷幽默就黑屏

### 标准输出（本模式）

- 21–24 行台词，40–45 秒
- 1–2 个场景（工位 / 会议室够用）
- 最后加一张黑屏字幕卡：`本故事纯属虚构` + `如有雷同，说明你们公司也这样`

## 二、通用工作流（非「离谱规则流」时用）

### 1. 定骨架（先问，别猜）

只问 3 件事，一次问完：

1. **给谁看 / 发哪**：抖音 / 快手 / 视频号 / B站；
2. **做几集、每集多长**：默认 1 集 60–90 秒；
3. **有没有必须保留的梗 / 人设 / 结尾**。

用户已经说清楚的不重复问。没说的按默认值走，并在剧本开头标注「默认值」。

### 2. 定人设（反差是沙雕的发动机）

每个角色写三行：

```
名字：
一句话人设：        # 例：全公司最卷，但卷的全是没用的事
反差/执念：          # 例：怕鬼，却天天加班到凌晨
```

角色数控制在 **3–5 个**。超过 6 个，观众记不住，配音也贵。

### 3. 定结构（按地点分场景）

- 一场 = 一个地点；换地点才换场。
- 同一地点的连续对话不要拆场，用台词里的「走过来 / 坐下 / 转身」表达。
- 单集 2–6 场；超过 6 场，删或并。

### 4. 写台词（一行一句，音频优先）

铁律：**把画面提示删掉，只听台词，仍然知道谁在、在哪、发生了什么。**

- 一行 = 一个说话单元，**不超过 15 字**（离谱规则流）/ 30 字（其它类型）。短句才有节奏。
- 动作、进出、道具、转场，全部写进旁白或对白：
  - ✅「旁白：阿强端着咖啡走进工位，发现老板正坐他的椅子上。」
  - ❌「画面：阿强走进工位，老板坐在椅子上。」
- 旁白是「死鱼眼解说」：冷静地讲荒诞的事。
- 每个角色有自己的说话方式，不能全员同一张毒舌嘴。
- 每 10–20 秒必须有一个笑点 / 信息点 / 身份变化 / 悬念。

### 5. 收尾（反转或钩子）

最后 2–3 行必须完成一件事：反转、打脸、升级、或抛下一集的问题。不要用「今天就到这里」收尾。

### 6. 落盘两份

- `第NN集.md`：给人审，格式见 `templates/单集剧本.md`
- `剧本.json`：给机器读，字段见 `templates/结构化剧本.json`
- 跑校验：`python3 scripts/validate_script.py <md> [--json <json>]`

## 四、输出格式（硬约束）

### Markdown（人读）

```markdown
# 第01集：<集标题>

## 一、本集目标
- 钩子：<前 3 秒发生什么>
- 主笑点：<本集最大的笑点>
- 结尾：<反转 / 钩子>

## 二、角色表
| 角色 | 人设一句话 | 音色 | 性别 |
|---|---|---|---|
| 阿强 | 全公司最卷，卷的全是没用的事 | 云希-清亮少年 | 男 |

## 三、场景表
| 场景 | 地点 | 出场角色 | 画面要点 |
|---|---|---|---|
| S1 | 工位-早晨 | 阿强、老板 | 两台电脑、一杯咖啡 |

## 四、台词表
| 序号 | 角色 | 台词 | 情绪 | 音效 | 场景 |
|---|---|---|---|---|---|
| 1 | 旁白 | 周一早上八点，阿强提前一小时到公司。 | 平静 | 闹钟 | S1 |
| 2 | 阿强 | 只要我够早，老板就抓不到我摸鱼。 | 得意 | | S1 |
```

### JSON（机器读）

```json
{
  "title": "周一打工人",
  "season": 1,
  "episode": 1,
  "durationTarget": 60,
  "hook": "提前一小时到公司，发现老板睡在工位",
  "reversal": "老板才是真摸鱼",
  "characters": [
    { "name": "阿强", "persona": "全公司最卷", "voice": "云希-清亮少年", "gender": "male" }
  ],
  "scenes": [
    { "id": "S1", "title": "工位-早晨", "background": "工位", "actors": ["阿强", "老板"], "props": ["咖啡"] }
  ],
  "lines": [
    { "seq": 1, "speaker": "旁白", "type": "narration", "text": "周一早上八点，阿强提前一小时到公司。", "emotion": "平静", "sfx": "闹钟", "scene": "S1" }
  ]
}
```

**字段约束**：

- `type`：`narration`（旁白/叙述/解说）或 `dialogue`；
- `emotion`：必须是 `02-配音/references/情绪表.md` 里的中文情绪名；
- `scene`：必须出现在 `scenes[].id`；
- `scenes[].props`：可选，写剧本里会被用到的道具名，必须和 `03-素材/道具/<名>.png` 一致；
- `speaker`：旁白类固定写 `旁白`，其余必须出现在 `characters[].name`；
- `text`：≤ 30 字，不含标点堆叠；
- `seq`：从 1 连续递增。

## 六、常见失败

| 失败 | 表现 | 修法 |
|---|---|---|
| 画面依赖 | 关键信息只在「画面」列 | 搬进旁白/对白 |
| 段子堆砌 | 全是梗，没有故事 | 先写「谁想要什么、谁挡着」，再挂梗 |
| 全员毒舌 | 每个角色都一个腔调 | 给每个角色一个「说话习惯」 |
| 开头温吞 | 前 3 秒在介绍背景 | 从冲突/反常/打脸开场，背景后置 |
| 结尾泄气 | 「今天就到这里」 | 换成反转 / 悬念 / 下一集问题 |
| 场景太多 | 8 个地点、每场 2 句 | 合并到 2–6 场 |
