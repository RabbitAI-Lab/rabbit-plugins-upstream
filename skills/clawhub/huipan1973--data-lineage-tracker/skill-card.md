## Description:

Track data origin, transformations, and flow through construction systems. Essential for audit trails, compliance, and debugging data issues.

This skill is ready for commercial/non-commercial use.

## Publisher:

[huipan1973](https://clawhub.ai/user/huipan1973)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and data governance teams use it to record construction data sources and transformations, trace upstream and downstream dependencies, assess change impact, validate lineage, and prepare audit reports.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Lineage records and exports may expose project system locations, owners, transformation details, or operational data.

Mitigation: Limit stored fields, restrict access to lineage reports and exports, and review them before sharing.

Risk: The security scan was benign, but one tool-misuse check was only partially completed.

Mitigation: Review the skill and any generated code or commands before execution; treat the scan as reassuring, not a guarantee.
