## Description:

Read-only DeFi intelligence for opportunity research, portfolio diagnostics, allocation analysis, route previews, Trail Heat, and Sybil review. Never executes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[parmasanandgarlic](https://clawhub.ai/user/parmasanandgarlic)

### License/Terms of Use:

MIT-0

## Use Case:

External users and AI agents use this skill to compare DeFi protocols, airdrops, and points programs, review public-wallet risk, and model hypothetical allocations. It supplies time-bound research and decision context; any transaction requires a separate user-directed execution flow.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: An optional tier/setup check sends a public agent address and the skill identifier to FarmDash.

Mitigation: Skip onboarding for keyless Scout research; if a tier/setup check is requested, review the data disclosure and consent before sending it.
