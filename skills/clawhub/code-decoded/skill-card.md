## Description:

Turn a codebase into a self-contained interactive HTML course for onboarding, walkthroughs, or stakeholder explanation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[leostehlik](https://clawhub.ai/user/leostehlik)

### License/Terms of Use:

MIT

## Use Case:

Developers, onboarding teams, and stakeholders use this skill to turn a codebase into an interactive walkthrough of its architecture, key flows, and relevant code.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated HTML may contain source snippets, internal file paths, or architecture details.

Mitigation: Review the HTML before sharing it outside the project.

Risk: Security assessment coverage is partial because a local path-like reference could not be resolved.

Mitigation: Consider the limited agency finding and incomplete evidence when deciding whether to install.
