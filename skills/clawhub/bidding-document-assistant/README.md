# 投标文件编制助手

> 通用投标文件格式排版技能：按招标文件格式自动生成投标文件骨架（docx），不填充实质性内容。

## 功能简介

- 按招标文件要求生成结构正确、格式规范的投标文件 **docx 骨架**（空壳框架）
- 支持四种编号体系：纯阿拉伯级联 / 阿拉伯+符号转换 / 政府格式 / 工程格式
- 支持解析招标文件 `.docx` 提取章节结构与字体信息
- 支持自定义封面【正本】标签、X/100 页脚格式、目录域
- 联动 IMA 知识库（招标文件汇集 + 评标否决 AI + 实务与合规）学习真实样式、规避格式否决雷区
- 不支持 PDF 解析；不生成投标实质性内容（方案/报价/证明等）

## 使用方式

1. 上传招标文件 `.docx` → 自动解析章节结构
2. 或手动输入章节列表 / 使用默认 14 章节框架
3. 选择编号体系、填写项目信息
4. 生成 `.docx` 骨架文件，自行填充内容

详见技能包内 `SKILL.md`。
