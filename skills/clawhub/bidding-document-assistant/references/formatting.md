# 投标文件格式规范

> 来源：参考《标书模板.V1.0-2022.3.9》标准排版要求
> 扩展：支持多套编号体系动态配置

## 页面设置

| 参数 | 值 | 说明 |
|------|-----|------|
| 纸张大小 | A4 (11906 × 16838 DXA) | |
| 页边距 | 上下左右各 2.5 cm (1440 DXA) | 统一等边距（可配置） |

## 字体样式

默认格式为全部宋体，实际使用时可按招标文件要求调整。

| 样式 | 默认字体 | 默认字号 | 粗体 | 行距 |
|------|----------|----------|------|------|
| 正文 (Normal) | 宋体 (SimSun) | 小四 (12pt) | 否 | 1.5倍 |
| 标题1 (H1) | 宋体 (SimSun) | 小二 (18pt) | **是** | 1.5倍 |
| 标题2 (H2) | 宋体 (SimSun) | 三号 (16pt) | **是** | 1.5倍 |
| 标题3 (H3) | 宋体 (SimSun) | 小三 (15pt) | **是** | 1.5倍 |
| 标题4 (H4) | 宋体 (SimSun) | 四号 (14pt) | **是** | 1.5倍 |
| 标题5 (H5) | 宋体 (SimSun) | 小四 (12pt) | **是** | 1.5倍 |
| 表格表头 | 宋体 (SimSun) | 小四 (12pt) | **是** | 1.25倍 |
| 表格正文 | 宋体 (SimSun) | 五号 (10pt) | 否 | 1.25倍 |

> 注：正文字体和标题字体可分开设置。例如政府/事业单位格式中，正文用仿宋，标题用黑体。
> 最低标题到五级，六级标题不推荐。

## 标题编号体系（四套预设）

用户启动技能时，从以下四套体系中选择，或上传招标文件后自动解析匹配。

### 体系一：纯阿拉伯数字级联（推荐默认）

| 层级 | 编号格式 | 示例 |
|------|----------|------|
| 一级 (H1) | 1, 2, 3…… | 1 投标函 |
| 二级 (H2) | 1.1, 1.2…… | 1.1 投标人资格 |
| 三级 (H3) | 1.1.1, 1.1.2…… | 1.1.1 基本资格 |
| 四级 (H4) | 1.1.1.1, 1.1.1.2…… | 1.1.1.1 财务状况 |
| 五级 (H5) | 1.1.1.1.1, 1.1.1.1.2…… | 1.1.1.1.1 资产要求 |

> 纯阿拉伯数字级联到底，不转符号。适用于大多数通用招标项目。

### 体系二：阿拉伯数字+符号转换

| 层级 | 编号格式 | 示例 |
|------|----------|------|
| 一级 (H1) | 1, 2, 3…… | 1 投标函 |
| 二级 (H2) | 1.1, 1.2…… | 1.1 投标人资格 |
| 三级 (H3) | 1.1.1, 1.1.2…… | 1.1.1 基本资格 |
| 四级 (H4) | (1), (2), (3)…… | (1) 安全性需求 |
| 五级 (H5) | ①, ②, ③…… | ① 通信安全 |

> 三级以内用数字级联，四级转括号序号，五级转圈号。原标准体系的保留方案。

### 体系三：政府/事业单位格式

| 层级 | 编号格式 | 示例 |
|------|----------|------|
| 一级 (H1) | 一、二、三…… | 一、资格审查资料 |
| 二级 (H2) | （一）（二）（三）…… | （一）基本资格条件 |
| 三级 (H3) | 1, 2, 3…… | 1 企业营业执照 |
| 四级 (H4) | （1）, （2）, （3）…… | （1）营业执照副本 |
| 五级 (H5) | ①, ②, ③…… | ① 原件扫描件 |

> 正文通常为仿宋体，标题为黑体。括号为全角。

### 体系四：工程类格式

| 层级 | 编号格式 | 示例 |
|------|----------|------|
| 一级 (H1) | 第一章、第二章…… | 第一章 总则 |
| 二级 (H2) | 第一节、第二节…… | 第一节 项目概况 |
| 三级 (H3) | 一、二、三…… | 一、工程范围 |
| 四级 (H4) | （一）（二）（三）…… | （一）土建工程 |
| 五级 (H5) | 1., 2., 3.…… | 1. 地基处理 |

> 适用于建筑工程、市政工程等招标文件。

## 封面格式

- 右上角标注 **【正本】** 字样（针对正本文件）；副本则标注 **【副本】**
- 项目名称、代理编号居中排列
- 投标人名称、地址居中排列
- 日期居中排列（格式：20XX年X月）
- 封面无页眉页脚，不编页码
- 自定义项目编号按招标文件要求显示（如代理编号、项目编号等）

## 页眉页脚

| 区域 | 内容 |
|------|------|
| 页眉 | 项目名称居左（封面页不加） |
| 页脚 | 页码格式：X / 总页数（如 1/100），首页不显示，从第二页起显示 |
| 页码起始 | 封面页不计入页码，正文从第2页开始编号 |

### 页脚实现说明

```
封面（独立节）     → 无页脚，不编页码
目录页（第二节）   → 页脚显示：2/总页数（若无单独目录则由此开始）
正文各章节         → 页脚显示：3/总页数、4/总页数……
```

实际生成时：
- 封面单独为一节，不设页脚
- 正文部分为一节，设置 `pageNumbers.start: 2`，页码从2开始
- 正文节使用 first 页脚（空）+ default 页脚（显示 当前页/总页数）

## 目录

- 展示至前三级标题 (H1-H3)，必要时展示至四级
- 一级目录加粗
- 宋体小四，1.5倍行距
- 每降一级左侧缩进2字符
- 使用 Word TOC 域自动生成

## 段落设置

- 首行缩进：2字符 (480 DXA)
- 行距：1.5倍 (360 twips for 12pt)
- 段前段后：0行
- 所有段落起始处必须空两个汉字

## 表格设置

| 属性 | 值 |
|------|-----|
| 表头字体 | 宋体 小四(12pt) 加粗 居中 |
| 表体字体 | 宋体 五号(10pt) 左对齐 |
| 表头背景 | 浅蓝 #D9E2F3 |
| 边框 | 黑色单线 1pt |
| 单元格边距 | 上下60 DXA，左右100 DXA |
| 行距 | 1.25倍 (300) |
| 表注（表尾） | 宋体五号，左缩进2字符，段前1行，1.5倍行距 |

注意事项：
- 整个表格居中排版
- 表格画得越紧凑越美观
- 同一表格尽量避免跨页

## 图注

- 居中，宋体五号加粗，1.5倍行距，段前0行，段后0行

## 格式配置项速查

所有可自定义的格式参数：

| 配置项 | 说明 | 示例值 |
|--------|------|--------|
| 页面宽度 | 纸张宽度 (DXA) | 11906 (A4) |
| 页面高度 | 纸张高度 (DXA) | 16838 (A4) |
| 页边距 | 上下左右 (DXA) | 1440 (≈2.5cm) |
| 正文字体 | 字体名 | SimSun / 仿宋_GB2312 |
| 正文字号 | 字号 (half-pt) | 24 (小四) / 28 (四号) |
| H1~H5字体 | 每级标题的字体名 | SimSun / SimHei |
| H1~H5字号 | 每级标题的字号 (half-pt) | 36, 32, 30, 28, 24 |
| H1~H5加粗 | 每级标题是否加粗 | true / false |
| 编号体系 | 四套预设 + 自定义 | scheme1 / scheme2 / scheme3 / scheme4 / custom |
| 自定义编号 | 每级编号的格式模板 | '{n}.', '（{cn}）' 等 |
| 章节列表 | 按招标文件动态生成 | [{level, title}, ...] |
| 项目编号 | 封面上的自定义编号 | 按招标文件格式 |

## docx-js 编程常量

```javascript
// 页面（A4, 2.5cm全等边距）
const PAGE_W = 11906;
const PAGE_H = 16838;
const MARGIN = 1440;  // ~2.5cm

// 字体（全部宋体）
const FONT = 'SimSun';  // 正文、标题、表格统一用宋体

// 字号 (half-points)
const SIZE_BODY = 24;    // 小四 12pt
const SIZE_H1 = 36;      // 小二 18pt
const SIZE_H2 = 32;      // 三号 16pt
const SIZE_H3 = 30;      // 小三 15pt
const SIZE_H4 = 28;      // 四号 14pt
const SIZE_TABLE = 20;   // 五号 10pt

// 行距 (twips)
const LINE_BODY = 360;   // 1.5倍
const LINE_TABLE = 300;  // 1.25倍

// 首行缩进
const INDENT_FIRST = 480; // 2字符
```
