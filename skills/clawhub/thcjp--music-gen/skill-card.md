音乐生成工具专业版 helps agents support AI music generation workflows, including batch generation, platform selection, license tracking, music library management, and quality audits.

This skill is ready for commercial/non-commercial use.

External creators, content teams, and developers use this skill to coordinate commercial music generation tasks, manage generated music assets and licenses, and produce audit or library outputs for projects.

## Known Risks and Mitigations:

Risk: The skill's activation language is broader than a music-specific workflow while the skill can run commands and write files.

Mitigation: Constrain use to music generation, music library management, and related audit/report tasks before activating the skill.

Risk: The skill may propose commands, file writes, API-key usage, database actions, or CI/CD changes.

Mitigation: Review each proposed command, write operation, credential use, database action, or CI/CD step before allowing execution.
