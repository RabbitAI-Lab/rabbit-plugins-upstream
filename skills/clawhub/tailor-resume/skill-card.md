## Description: <br>
Tailor and polish an existing resume in Google Docs for a particular job when the user provides an editable Google Docs resume link plus either direct recruiter feedback or a direct role-description link, improving relevance, clarity, keyword alignment, and emphasis while remaining strictly truthful and avoiding invented qualifications, experience, metrics, or outcomes. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External job seekers and resume reviewers use this skill to update an existing Google Docs resume for a specific role based on recruiter feedback or an official role description while preserving truthful, supported claims. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may read and edit a live Google Docs resume, so changes can persist in the user's document. <br>
Mitigation: Use the skill only with the intended editable resume, confirm document access, and review the final edits before relying on the updated resume. <br>
Risk: Role targeting can tempt unsupported claims, keyword stuffing, or overstated qualifications. <br>
Mitigation: Keep recruiter feedback and role descriptions as targeting guidance only, require user confirmation for new facts, and omit claims that are unsupported by the resume or explicit user confirmation. <br>
