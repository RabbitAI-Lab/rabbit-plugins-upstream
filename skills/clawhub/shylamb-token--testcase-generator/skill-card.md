## Description: <br>
Generates structured test cases from requirements documents, PRDs, user stories, API definitions, or UI specifications, with support for coverage analysis and Markdown, CSV, or Excel output. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, QA engineers, and product teams use this skill to turn requirements, acceptance criteria, or API specifications into actionable test cases, test matrices, and coverage reviews. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: CSV or Excel export may write local files and could overwrite an existing testcase file. <br>
Mitigation: Ask the user to confirm the destination filename before creating CSV or Excel output, especially when testcases.csv or testcases.xlsx already exists. <br>
