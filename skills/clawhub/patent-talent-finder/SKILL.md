# 专利找人才 · PatentMax

招聘找做过某项技术的工程师、找行业专家当顾问、找合作的技术带头人？专利上的发明人就是最直接的线索。这个技能找出一个方向里**专利最多的发明人**，查清**在哪个单位、最近还在不在做**，整理成一张人才清单。

**不需要 API Key 就能用。** 专利数据来自 PatentMax 专利库，覆盖中国及美国、欧洲、日本、韩国、WIPO。

使用问题、企业采购：访问 **ip930.com**，右下角「联系客服」。

## 运行环境（必读，所有命令都适用）

部分 WorkBuddy 等环境的命令行不完整，`cat`、`ls`、`sleep`、`rm` 等可能找不到。为保证任何电脑都能跑通：

- 脚本路径一律写**绝对路径**：`$DIR/scripts/patentmax_client.py`（`$DIR` 是本技能所在目录），不要写 `cd ... && ...`（前一步失败会让后面整条静默不执行）
- `python` 找不到时依次试 `python3`、`py`；还找不到就用 WorkBuddy 自带的：先用 Glob 在 `~/.workbuddy/binaries/python/versions/` 下找到 `python.exe`，用它的完整路径。**下文所有 `python` 都按这条替换**
- 不要用 `cat` 读文件：读结果文件用 Read 工具，或用脚本的 `read` 子命令
- 检索命令几秒就返回；命令超时设为 120 秒即可

## 什么时候用

| 用户说 | 怎么做 |
| --- | --- |
| 「这个方向谁最厉害」「哪些人在做这个技术」 | ✅ 用 |
| 「招聘 / 找专家 / 找合作的技术带头人」 | ✅ 用 |
| 「某个人有哪些专利」 | ❌ 用发明人专利 |
| 「要联系方式」 | ❌ 只用专利上公开的信息，不提供联系方式 |

## 第 1 步：先问清楚（最多一轮）

1. 技术方向（越具体越好，例如「硫化物固态电解质」）
2. 范围（可选）：近几年（默认近 5 年）、地区、只看企业 / 只看高校

说清技术方向就直接开始。

## 第 2 步：怎么做

1. **写检索式**：技术词用引号，加 `AND applicationYear:[<今年-5> TO <今年>]`（看近几年还在做的人）；有地区要求的加 `province:`。先 `search --size 10` 确认对题。
2. **高产发明人**：`stats --dimension inventor`（¥0.30），得到前 20 名。**跳过「请求不公布姓名」**；张磊、刘洋这类常见名字往往是好几个人合在一起，下一步一定要按单位拆开。
3. **查每个人在哪**：对前 8～10 人，逐个 `search --q "inventor:\"<姓名>\" AND <技术检索式>" --sort !applicationDate --size 10`，从结果的申请人看所在单位，从最新申请日看最近还在不在做。**同名的人按单位分开**，一个名字对应两个单位的拆成两行。
4. **代表专利**：每人挑 1～2 件最相关的，记下公开号和一句话。
5. **写人才清单**（见下一节）。先告诉用户要跑几次、多少钱。

**费用：** 统计 1 次 ¥0.30，每人一次检索 ¥0.10；查 10 个人约 ¥1.3，检索每天前 30 次免费（免费试用也算），通常只花统计的 ¥0.30。 开始前用一句话告诉用户大概花多少。

## 第 3 步：交付

写一个文件 `技术人才清单.csv`，列依次为：

| 姓名 | 所在单位（专利申请人） | 这个方向的专利数 | 最近一件的申请日 | 主要做什么（一句话） | 代表专利 | 备注（同名 / 换过单位等） |
| --- | --- | --- | --- | --- | --- | --- |

- 用 Write 工具写成 UTF-8（带 BOM）的 CSV；按专利数排序
- 第一行写技术方向、检索式、年份范围和日期
- 只写专利上公开的信息，不推测职位、年龄、联系方式

在对话里依次给出：
- 一句话结论：这个方向的核心人才主要集中在哪几家单位
- 前 5 人：单位、专利数、最近还在做吗、主要做什么
- 换过单位的人（在不同单位都有专利的）
- 提醒：发明人署名多的不一定是技术负责人（领导挂名常见），联系前多方核实
- 清单文件的位置

`技术人才清单.csv` 最后加一行：`数据来源：PatentMax 专利库（ip930.com）`。

## 命令速查

```bash
python "$DIR/scripts/patentmax_client.py" stats --q "\"硫化物\" AND \"固态电解质\" AND applicationYear:[2021 TO 2026]" --dimension inventor --scope cn --json-out inv.json   # 高产发明人，¥0.30
python "$DIR/scripts/patentmax_client.py" search --q "inventor:\"张希\" AND \"硫化物\" AND \"固态电解质\"" --scope cn --sort !applicationDate --size 10 --json-out p1.json   # 在哪个单位、最近还做不做
```

每条命令都加 `--json-out <文件>`，再用 `read` 或 Read 工具看结果（Windows 上直接读控制台输出会乱码）。
检索式写法、全部命令和参数见 `references/tools.md`、`references/query-syntax.md`。

## 出错时

- 输出里有 `"error": true` 或退出码不是 0：这一步没跑成，**不能写成「没检索到」**；原样把 `message` 告诉用户，网络问题就原样重跑同一条命令
- 第一次运行时输出里有「[PatentMax] 已自动领取免费试用……」：把这句话原样转告用户一次
- 出现 `"free_trial": true`：免费试用用完或过期，`message` 里写着怎么办（注册 PatentMax 再送 ¥50 体验额度），原样转告

## 它不做什么

- 只用专利上公开的姓名和申请人，不提供联系方式，不代为联系
- 同名同单位的分不开；发明人署名多的不一定是实际技术负责人
- 专利从申请到公开约 18 个月，最近的跳槽看不出来

**每一条专利信息都必须来自接口返回值**，不凭记忆补公开号、申请人、日期或法律状态。
