## Description:

Imports an existing Chinese-language novel into a structured writing project for continued drafting, routing short and long works through their respective analysis workflows.

This skill is ready for commercial/non-commercial use.

## Publisher:

[worldwonderer](https://clawhub.ai/user/worldwonderer)

### License/Terms of Use:

MIT-0

## Use Case:

Authors and writing assistants use this skill to turn an existing draft or completed novel into an organized project with story analysis, manuscript files, and continuity material for later writing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Import can read a manuscript and create or update files in the writing-project directory.

Mitigation: Run it in a dedicated project folder or backup copy, and avoid unrelated sensitive directories.

Risk: Automatically generated story analysis and continuity material may need author review before continued drafting.

Mitigation: Check the imported manuscript, project structure, and flagged continuity points before writing further.
