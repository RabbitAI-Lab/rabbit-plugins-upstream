## Use Case: <br>
Developers and engineers use this skill to profile frontend, backend, and API performance issues, identify measured bottlenecks, apply focused fixes, and add regression guards such as monitoring, tests, or CI performance budgets. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Profiling commands, CI tooling, or performance changes proposed by an agent could be inappropriate to run directly in production. <br>
Mitigation: Review proposed commands and code changes before execution, and prefer staging or representative test environments for measurement and verification. <br>
Risk: Optimization without measurement can introduce unnecessary churn or regressions. <br>
Mitigation: Require baseline measurements, profiling evidence, post-change verification, and regression guards such as monitoring, tests, or CI performance budgets. <br>
