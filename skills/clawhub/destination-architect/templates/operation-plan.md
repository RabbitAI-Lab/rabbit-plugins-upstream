# 运营计划模板

> 三阶段路线。每阶段有明确目标、用户、内容、节奏。

---

## 一、三阶段路线

### 阶段 1：冷启动（0-6 个月）

**目标：** 验证价值假设——是否有用户愿专程来 + 复购 + 传播

| 维度 | 设计 |
|------|------|
| 时间 | 0-6 个月 |
| 第一批用户 | [最有可能为价值买单的种子用户，具体到生活方式] |
| 内容种子 | 1-2 个可传播核心内容：[具体内容] |
| 渠道 | [选最契合目标用户的高密度渠道，不广撒网] |
| 验证目标 | [客流 / 复购率 / 传播率 的具体目标] |

**通过标准：**
- 用户愿专程来：[具体标准]
- 用户愿复购：复购率 > [X]%
- 用户愿传播：NPS > [X]

**未通过则：** 价值假设未验证，调整产品或定位，不进入增长阶段。

---

### 阶段 2：增长（6-24 个月）

**目标：** 扩大认知 + 建立用户资产

| 维度 | 设计 |
|------|------|
| 时间 | 6-24 个月 |
| 内容矩阵 | 围绕核心定位扩展，但守住一个核心 |
| 社交传播 | 设计可被用户主动传播的"社交货币" |
| 渠道扩张 | 从单渠道到多渠道 + ROI 校验 |
| 用户运营 | 一次性游客 → 持续用户 |
| 节奏 | 节庆 / 季节性内容 / 限定体验 制造持续热度 |

**关键指标：**
- 客流年增长：[X]%
- 复购率：[X]%
- 用户资产沉淀：会员数 [X]

---

### 阶段 3：成熟（24+ 个月）

**目标：** 持续创新 + 文化沉淀

| 维度 | 设计 |
|------|------|
| 时间 | 24 个月以后 |
| 内容更新 | 持续迭代核心体验，避免"看腻" |
| 用户资产 | 会员 / IP 衍生 / 在地社群 |
| 二次增长 | 新产品 / 新场景 / 新人群 |
| 数据驱动 | 用真实运营数据指导决策 |
| 文化沉淀 | 从"项目"升级为"目的地品牌资产" |

**判断标准：** 复购率稳定 + NPS 稳定 + 现金流持续为正

## 四、用户运营路径

| 阶段 | 用户状态 | 运营重点 | 转化漏斗 |
|------|---------|---------|---------|
| 认知 | 听说过 | 内容触达 | 触达 → 兴趣 |
| 兴趣 | 想来 | 决策辅助 | 兴趣 → 到访 |
| 到访 | 来了 | 体验保障 | 到访 → 复购 |
| 复购 | 再来 | 复购钩子 | 复购 → 传播 |
| 传播 | 推荐 | 社交激励 | 传播 → 拉新 |
| 忠诚 | 长期 | 用户资产沉淀 | 长期留存 |
