## 三、关键指标目标值

> 每个数字必须带证据标签。禁止裸数字。见 [core/information-discipline.md](../core/information-discipline.md)。

| 指标 | 目标值 | 证据标签 | 来源 / 区间 | 判定依据 |
|------|--------|---------|-----------|---------|
| 客流量（年） | | 实测/引用/假设/未知 | | 与容量匹配 |
| 停留时间 | | 实测/引用/假设/未知 | | 决定消费机会 |
| 客单价 | | 实测/引用/假设/未知 | | 与目标用户匹配 |
| 转化率 | | 实测/引用/假设/未知 | | 嵌入式 > 50% |
| 复购率 | | 实测/引用/假设/未知 | | > 15% 算健康 |
| NPS | | 实测/引用/假设/未知 | | > 30% 算优秀 |

**硬门禁：** 含 `[假设]` 标签的关键指标，不得进入投资判断的"通过"结论，须先经 [core/falsification-engine.md](../core/falsification-engine.md) 证伪。
**无可靠同类数据时：** 写"无可比数据"，给区间 + `[假设]`，不得编造确定值。

```

校验：获客成本 < 客均贡献 × 复购次数 × 利润率
结果：[通过 / 不通过]
```

### 5.2 可持续性校验

```
运营第 1 年：收入 ___ - 成本 ___ = 利润 ___

结果：[通过 / 不通过]
```
