# Module：最小成本证伪器（旗舰机制）

> 本 Skill 真正的产品不是方案，也不是审查报告，而是：**用最小的钱，把一个决策变成可证伪的。**

## 为什么要这个模块

在四轮审查中发现的问题：审查输出的是"判断"，但判断没有地面真值。信息量不变，自信度却上升——这是制造自信，不是生产判断。

本模块把 Skill 从"意见机器"改造为"仪器"：不产判断，产**可被现实推翻的最小实验**。

---

## 三条铁律

1. **分析不是交付终点，"可证伪的下一步"才是。** 任何输出如果没有这一项，视为未完成。
2. **预注册：判定阈值必须在看到结果之前锁定。** 事后改阈值 = 没有阈值。
3. **硬门禁：如果设计不出廉价证伪实验，则判定"该项目尚不值得分析"。** 不是说不做，是说现在做等于赌。

---

## 成本上限（硬约束）

| 约束 | 默认值 | 说明 |
|------|--------|------|
| 单次实验成本 | ≤ 项目总投资 × 1% | 花 1% 避免 99% 的沉没损失 |
| 单次实验周期 | ≤ 关键决策窗口 | 实验必须早于投决 |
| 拒绝理由 | 超上限即升级为"投资级"实验，若无法设计则输出不可证伪标记 |

---

## 单点假设证伪流程（每个核心假设各跑一次）

### Step 1：拆点

从核心价值假设中拆出**单点假设**。打包假设不可证伪。

- ❌ "这个项目能成功" —— 不可证伪
- ✅ "目标用户愿为'真实慢村'支付 ≥800 元/晚" —— 可证伪

### Step 2：定义证伪条件

明确写出：**什么结果出现，这个假设就被推翻。**

- "若 30 个抽样用户中，愿意支付 ≥800 元者 < 6 人（20%），则该假设被推翻。"

### Step 3：事前锁定阈值

判定阈值写在实验前，且写明"锁定时点"。任何人（包括用户）在看到结果后要求改阈值，须触发 [decision-calibration.md](decision-calibration.md#合理化警报) 的合理化警报。

### Step 4：设计最低成本实验

| 要素 | 要求 |
|------|------|
| 方法 | 能低成本逼近真相的最笨办法（问卷 < 试运营 < 建设） |
| 成本 | 给出金额区间，非拍脑袋 |
| 周期 | 给出天数 |
| 样本 | 给出量与来源 |
| 判定 | 引用 Step 3 阈值 |

**优先级：** 能用问卷验证的，绝不用试运营；能用试运营验证的，绝不先建设。

### Step 5：决策规则（先于结果）

| 实验结果 | 决策 |
|---------|------|
| 假设被证伪 | 止损 / 重构价值主张 / 换假设 |
| 假设被证实 | 进入下一最小实验（不是直接全量投入） |
| 结果不确定 | 加样本 / 换方法，或标记"不可判定" |

### Step 6：不可证伪标记

若某核心假设无法设计出廉价实验（成本超上限、周期超窗口、无法构造判定条件），必须显式输出：

> **【不可证伪】该假设无法在本项目预算与周期内验证。当前分析等于赌。**

---

## 反事实检验（附加）

对每个假设，额外回答一句：

> 如果这个假设是错的，我们最早会从哪里看出来？

用于建立投后监测信号，与 [workflows/failure-analysis.md](../workflows/failure-analysis.md) 的早期信号对接。

---

## 输出契约

```
《最小成本证伪计划》
逐假设：
- 假设（单点、可证伪）
- 证伪条件
- 判定阈值（锁定时点）
- 最低成本实验（方法 / 成本 / 周期 / 样本）
- 决策规则（证伪 / 证实 / 不确定 各自动作）
- 反事实检验（最早信号）

汇总：
- 总验证成本估算
- 不可证伪假设清单（如有）
- 结论：可先验证后决策 / 应直接止损 / 尚不值得分析
```

## 与商业模型的衔接

证伪实验结果 → 回填 [core/business-model.md](business-model.md) 的单客经济模型与关键指标，替换其中的 [假设] 值。未经证伪的假设不得进入投资判断。
