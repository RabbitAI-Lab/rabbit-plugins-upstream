# Module 1：地方价值发现引擎

> 发现一个地方真正值得开发的价值，而不是把资源包装成卖点。

## 核心提问

> 为什么游客愿意专程来到这里，而不是去其他地方？

如果回答不出来，或者答案是"我们这里有 XX 资源"，那么价值判断尚未成立。资源 ≠ 价值。

---

## 输入清单

| 维度 | 必须收集的信息 |
|------|--------------|
| 地理位置 | 经纬度 / 距核心城市距离 / 交通可达性 / 所在区域文旅带 |
| 历史文化 | 历史脉络 / 文化符号 / 非遗 / 在地民俗 / 口传故事 |
| 自然资源 | 地貌 / 气候 / 水文 / 物候 / 自然景观独特性 |
| 产业基础 | 主导产业 / 手工业 / 农特产 / 现有文旅业态 |
| 人口结构 | 常住人口 / 年龄结构 / 流出情况 / 在地人才 |
| 交通条件 | 机场 / 高铁 / 高速 / 最后一公里 / 季节通行性 |
| 政策环境 | 文旅政策 / 土地政策 / 专项资金 / 限制性条款 |

信息缺失时必须显式标注「未知」，不得用假设填充。

---

## 三层分析模型

### Layer 1：资源层 — 有什么？

不要罗列资源清单，要分类判断资源的**可塑性**。

| 资源类型 | 识别要点 | 可塑性判断 |
|---------|---------|----------|
| 自然资源 | 山水林田湖草沙 | 是否独特到值得专程？还是只是"还不错"？ |
| 人文资源 | 古建 / 民俗 / 节庆 | 是否仍在生活中存活？还是博物馆化的标本？ |
| 历史资产 | 名人 / 事件 / 遗址 | 是否有时代共鸣？还是只剩地方自豪感？ |
| 产业资产 | 手艺 / 农产 / 工艺 | 是否可体验化？是否可产品化？ |

**关键判断：** 资源是"在地存活"还是"标本保存"？标本化的资源很难转化为体验。

### Layer 2：价值层 — 为什么重要？

四个寻找方向，缺一不可地审视：

| 方向 | 提问 | 判断标准 |
|------|------|---------|
| 独特性 | 全国 / 全省 / 全市范围内，这是唯一吗？ | 不是唯一 → 价值弱 |
| 稀缺性 | 复制难度高吗？需要时间 / 自然 / 历史累积吗？ | 可快速复制 → 稀缺性低 |
| 情绪价值 | 能触达当代人的什么情绪？治愈 / 逃离 / 归属 / 自由？ | 无情绪触达 → 仅是景观 |
| 时代价值 | 契合当下社会的什么深层需求？慢 / 真 / 连接 / 意义？ | 无时代共鸣 → 缺乏当代购买理由 |

**反例：** "我们这里有千年古寺" — 这是资源，不是价值。价值是"在焦虑时代提供 30 分钟的精神停顿"。

### Layer 3：转化层 — 如何变成产品？

输出三个核心结论：

```
1. 核心价值定位
   一句话：游客来这里是为了获得 ________（不是"看 XX"，而是"得到 XX"）

2. 目的地主题
   主题不是口号，是所有产品 / 空间 / 内容的统一锚点

3. 差异化竞争点
   相对替代目的地的不可替代之处（必须能通过 Layer 2 的四问）
```

## 文化 IP 创造路径（Module 6）

> 把文化资产转化为长期资产，避免假文化、硬包装、同质化。

### 转化链路

```
地方文化（在地真实）
    ↓ 提炼
故事体系（叙事结构）
    ↓ 塑造
内容 IP（可识别的符号系统）
    ↓ 设计
体验产品（可消费的场景）
    ↓ 运营
商业资产（可复利的长期价值）
```

### 三条红线

1. **真实性红线** — 不编造历史、不嫁接文化、不符号空转
2. **生活性红线** — 文化必须在当代生活中有存活形态，而非纯博物馆化
3. **时代性红线** — 必须找到文化与当代人精神需求的连接点

### 优先寻找

> 真实文化中的现代价值，而非现代包装下的虚假文化。

判断标准：游客离开后，能否向朋友用一句话转述这个文化 IP？转述不出来 = IP 未成立。

---

## 常见陷阱

| 陷阱 | 表现 | 破解 |
|------|------|------|
| 资源崇拜 | "我们有 XX 资源，肯定能做" | 资源不等于价值，问"游客为什么专程来" |
| 仿造热门 | 抄张家界 / 抄袁家村 / 抄阿那亚 | 不可复制的是时机 / 团队 / 在地，不是形态 |
| 硬包装 | 给无文化地强行套文化符号 | 寻找真实存活的文化，而非编造 |
| 时代错位 | 复古 / 怀旧当作核心卖点 | 慢 / 真 / 归属是当代需求，复古只是壳 |
| 地方自豪 | "我们这里是 XX 之乡" | 地方自豪是内部视角，游客不为此付费 |

---

## 输出契约

```
《地方价值模型》
- 资源清单（按可塑性分级）
- 价值四问结论（独特性 / 稀缺性 / 情绪价值 / 时代价值）
- 核心价值定位（一句话）
- 目的地主题
- 差异化竞争点（相对至少 2 个替代目的地）
- 文化 IP 转化路径（如有）
- 关键未知与验证方法
```
