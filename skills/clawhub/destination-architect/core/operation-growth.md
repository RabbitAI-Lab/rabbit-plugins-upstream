# Module 7：增长运营引擎

> 让项目持续产生游客。一次开业不是终点，是起点。

## 核心原则

- 不是"开业即巅峰"
- 三阶段设计：冷启动 → 增长 → 成熟
- 每阶段用户、内容、节奏不同

---

## 三阶段模型

### 阶段 1：冷启动（0-1）

**目标：** 获得第一批真实用户，验证价值假设。

| 维度 | 设计要点 |
|------|---------|
| 第一批用户 | 不是"所有目标客群"，而是最有可能为价值买单的种子用户 |
| 内容种子 | 1-2 个能引发传播的核心内容（不是堆砌内容） |
| 渠道选择 | 不广撒网，选最契合目标用户的高密度渠道 |
| 验证目标 | 不追求数量，追求"是否有人愿意专程来 + 复购 + 传播" |

**关键判断：** 如果冷启动期用户不愿传播、不愿复购，后续增长就是烧钱。

### 阶段 2：增长期（1-10）

**目标：** 扩大影响，建立认知。

| 维度 | 设计要点 |
|------|---------|
| 内容矩阵 | 围绕核心价值扩展内容，但守住"一个核心定位" |
| 社交传播 | 设计可被用户主动传播的"社交货币"内容 |
| 渠道扩张 | 从单渠道到多渠道，但保持 ROI 校验 |
| 用户运营 | 从一次性游客转化为持续用户（会员 / 社群 / 复购） |
| 节奏设计 | 节庆 / 季节性内容 / 限定体验 制造持续热度 |

### 阶段 3：成熟期（10-N）

**目标：** 持续创新，避免衰退。

| 维度 | 设计要点 |
|------|---------|
| 内容更新 | 持续迭代核心体验，避免"看腻了" |
| 用户资产 | 沉淀长期用户（会员 / IP 衍生 / 在地社群） |
| 二次增长 | 新产品 / 新场景 / 新人群拓展 |
| 数据驱动 | 用真实运营数据指导决策，不靠直觉 |
| 文化沉淀 | 从"项目"升级为"目的地品牌资产" |

---

## 运营能力模块

### 内容营销

| 内容类型 | 作用 | 关键 |
|---------|------|------|
| 引流内容 | 触达新用户 | 高传播性，不靠投放也能扩散 |
| 体验内容 | 在地内容生产 | 让游客主动生产内容（UGC） |
| 品牌内容 | 建立目的地认知 | 长期叙事，不靠单次活动 |
| 转化内容 | 推动决策 | 真实用户证言 > 营销文案 |

### 社交传播

| 设计要点 | 提问 |
|---------|------|
| 传播触发 | 什么内容 / 画面 / 故事会让用户主动分享？ |
| 社交货币 | 用户分享后能获得什么身份表达？ |
| 平台选择 | 用户在哪个平台表达这种身份？小红书 / 抖音 / 微信？ |
| KOL 策略 | 不是头部 KOL，是与目标用户价值观契合的 KOC |

### 用户运营

| 阶段 | 用户状态 | 运营重点 |
|------|---------|---------|
| 认知 | 听说过 | 内容触达 |
| 兴趣 | 想来 | 决策辅助 |
| 到访 | 来了 | 体验保障 |
| 复购 | 再来 | 复购钩子 |
| 传播 | 推荐 | 社交激励 |
| 忠诚 | 长期 | 用户资产沉淀 |

### 活动运营

| 活动类型 | 频次 | 目标 |
|---------|------|------|
| 日常内容 | 持续 | 维持热度 |
| 主题节庆 | 季节性 | 制造高峰 |
| 限定体验 | 不定期 | 复购触发 |
| 文化活动 | 长期 | 文化沉淀 |

### 数据分析

| 数据维度 | 用途 |
|---------|------|
| 客流来源 | 渠道 ROI 校验 |
| 停留分布 | 优化空间布局 |
| 消费分布 | 优化产品结构 |
| 复购行为 | 用户分层运营 |
| 传播数据 | 内容效果校验 |

## 输出契约

```
《运营增长路线》
- 三阶段路线（冷启动 / 增长 / 成熟 各阶段目标 + 策略）
- 内容矩阵（引流 / 体验 / 品牌 / 转化）
- 社交传播设计（触发点 / 社交货币 / 平台 / KOC）
- 用户运营（认知 → 忠诚 全链路）
- 活动运营（日常 / 节庆 / 限定 / 文化）
- 数据指标体系
- 关键未知与验证方法
```

## 常见陷阱

| 陷阱 | 表现 | 破解 |
|------|------|------|
| 开业即巅峰 | 投入大量开业营销，后续乏力 | 三阶段设计，开业只是起点 |
| 内容堆砌 | 大量内容但无核心 | 1-2 个核心内容引爆 |
| 投放依赖 | 不投放就没客流 | 设计可自传播的内容 |
| 一次营销 | 靠节庆 / 活动短暂拉动 | 持续运营节奏 |
| 数据缺失 | 凭感觉做决策 | 数据指标体系先行 |
