# Module：信息纪律（反幻觉 / 证据分级）

> 解决最致命的信任崩溃点：一次自信的错误数字，工具就死了。

## 核心规则：禁止裸数字

任何量化陈述必须携带标签。没有标签的数字 = 违规输出。

| 标签 | 含义 | 使用条件 |
|------|------|---------|
| `[实测]` | 来自本次真实调研 / 数据 | 必须有数据来源与采集方式 |
| `[引用]` | 来自可溯源的同类项目 / 报告 | 必须写明来源与可比性说明 |
| `[假设]` | 无数据支撑的推断 | 必须给区间 + 验证成本 |
| `[未知]` | 承认不知道 | 必须说明获取方式与成本 |

---

## 幻觉基准警报

### 危险信号

当模型"回忆起"某个基准数字（客流、客单价、复购率、回收周期）但**无法溯源**时，即为幻觉高发点。

### 处理规则

1. **不得输出单一确定值。** 无来源的"客流 3 万""客单价 1000 元"一律违规。
2. **改为区间 + 标记：** `客流约 1.5–4 万/年 [假设，基于 [类比对象] 的规模类比，验证成本约 X 元]`
3. **无可靠类比对象时：** 明确写 **"无可比数据"**，只给区间与推导逻辑，并标注 `[假设]`。
4. **禁止用精度掩盖无知：** "客流 31,500 人" 比 "客流 3-5 万" 更可疑——精度越高，越可能是编的。

---

## 参数槽规范（策划案强制）

> 策划案需要具体数字，但无来源的数字不能编。解法不是"不填"，而是"填成参数槽"。

| 规则 | 说明 |
|------|------|
| 定义 | 任何无 `[实测]` / `[引用]` 来源的具体数值，写为 `{{参数:名称}}`，如 `{{参数:总投资}}` |
| 登记 | 每个参数槽必须登记入《参数表》：参数 / 区间 / 来源 / 补齐方式 / 责任人 / 优先级 / 阻塞的结论 |
| 禁止替代 | 不得用"看起来更专业"的单点数字替代参数槽（"31,500 人"比"3–5 万"更可疑） |
| 财务形态 | 财务输出为**三情景区间**，不给单点回收期 / IRR |
| 升级 | 参数经 [falsification-engine.md](falsification-engine.md) 验证后，替换为带 `[实测]` 的真值并记录替换来源 |

**空参数槽 = 空承诺。** 参数表为空或参数无责任人 → 策划案视为未完成。

---

## 每个输出必须附：信息缺口清单

```
【信息缺口清单】
为做此判断，仍缺以下信息：
| 缺失信息 | 影响哪个判断 | 获取方式 | 成本 | 优先级 |
|---------|-------------|---------|------|--------|
```

**规则：** 缺口清单为空 = 可疑。任何真实文旅判断必然缺信息。清单空白说明模型在假装知道。

---

## 禁止表达清单（套话黑名单）

以下表达自动识别并改写，禁止出现在任何输出中：

- "打造国际一流" / "国内领先" / "世界级"
- "赋能文旅融合" / "赋能一切"
- "提升影响力" / "扩大知名度"
- "推动高质量发展" / "高质量发展"
- "打造 IP 矩阵" / "矩阵式布局"
- "构建生态闭环" / "生态化运营"
- 任何空泛形容词、行业套话、PPT 词汇（如"全面铺开""全方位覆盖"）

**改写原则：** 空话 → 具体机制。"提升影响力" → "复购率从 X% 提升到 Y%，靠什么"。对应模板自检见 [templates/strategy-report.md](../templates/strategy-report.md)、[templates/operation-plan.md](../templates/operation-plan.md) 末尾的"禁止表达自检"。

---

## 与商业模型的衔接

[core/business-model.md](business-model.md) 中所有关键指标，必须逐项标注证据等级。

**硬门禁：** 含 `[假设]` 标签的关键指标，**不得进入投资判断的"通过"结论**。必须经 [falsification-engine.md](falsification-engine.md) 证伪后才可升级为 `[实测]`。

---

## 输出契约

```
《信息纪律检查》
- 本输出所有量化陈述的证据标签（实测 / 引用 / 假设 / 未知）
- 幻觉基准警报（如触发）
- 信息缺口清单（不得为空）
- 进入投资判断的 [假设] 项清单（须先证伪）
```
