# Module：落地执行设计（M8）

> 承接 Step 9 策划案组装。把判断转为**可执行的实施、组织与合规**三张表。
> 本模块不产生方案创意，只负责让方案"能被执行"。

## 覆盖的落地要件

| 要件 | 输出 | 关键约束 |
|------|------|---------|
| 实施路线图 | 分期 + 里程碑 + 预算 + 责任人 | 每期必须有可验收的里程碑；预算用参数槽 |
| 运营组织 | 架构 + 人力配置 + 关键 SOP | 本地团队能力缺口必须显式标注 |
| 合规审批 | 审批清单 + 责任人 + 周期 | 未完成合规不得进入建设期 |

---

## 一、实施路线图

### 分期结构（默认三期，可按项目调整）

| 期 | 目标 | 关键里程碑（可验收） | 预算 | 责任人 |
|----|------|-------------------|------|--------|
| 验证期 | 用最小成本证伪核心假设（对接 [falsification-engine.md](falsification-engine.md)） | {{参数:验证期里程碑}} | {{参数:验证期预算}} | {{参数:验证期负责人}} |
| 建设 / 筹备期 | 在假设被证实后，完成硬件与团队 | {{参数:建设期里程碑}} | {{参数:建设期预算}} | {{参数:建设期负责人}} |
| 运营 / 迭代期 | 跑通单客经济，进入复购 | {{参数:运营期里程碑}} | {{参数:运营期预算}} | {{参数:运营期负责人}} |

### 硬规则

1. **验证期必须先于建设期。** 未经证伪的 [假设] 不得进入建设期（对接 [information-discipline.md](information-discipline.md) 硬门禁）。
2. **里程碑必须可验收。** 禁止"完成前期工作"类不可判定表述，改写为"完成 X，达到 Y 阈值"。
3. **预算一律参数槽。** 不写单点金额；无法估值的写 `{{参数:...}}` 并登记入《参数表》。

---

## 二、运营组织

| 设计 | 内容 |
|------|------|
| 组织架构 | 决策层 / 运营层 / 一线执行（按实际规模裁剪） |
| 关键岗位 | 运营负责人 / 内容与传播 / 体验交付 / 商业招商 / 客服 |
| 人力配置 | 各岗人数与来源（本地 / 外派），**优先用本地就业满足政策诉求** |
| 能力缺口 | 本地缺什么能力、从哪补（招聘 / 外包 / 培训），缺口的补齐成本参数槽化 |
| 关键 SOP | 到店接待 / 体验交付 / 投诉处理 / 应急安全 四类最小 SOP |

**判断标准：** 若本地无运营团队且无补齐方案 → 实施路线图不得进入建设期（这与 [Step 1](../workflows/destination-analysis.md#step-1-项目诊断) 的"关键约束"联动）。

## 三、合规审批清单

| 审批项 | 主管方 | 前置条件 | 预计周期 | 责任人 | 是否阻塞 |
|--------|--------|---------|---------|--------|---------|
| 用地性质 / 流转 | {{参数:自然资源主管方}} | 土地权属清晰 | {{参数:周期}} | {{参数:负责人}} | 是 |
| 文物保护限制 | {{参数:文物主管方}} | 文保范围界定 | {{参数:周期}} | {{参数:负责人}} | 是 |
| 消防 / 安全 | {{参数:消防主管方}} | 建筑合规 | {{参数:周期}} | {{参数:负责人}} | 是 |
| 环保 / 生态红线 | {{参数:环保主管方}} | 环评 | {{参数:周期}} | {{参数:负责人}} | 是 |
| 经营许可 / 特种行业 | {{参数:市场监管主管方}} | 主体资质 | {{参数:周期}} | {{参数:负责人}} | 是 |
| 食品 / 卫生（如涉餐饮住宿） | {{参数:卫健主管方}} | 场地合规 | {{参数:周期}} | {{参数:负责人}} | 是 |

**硬规则：** 合规清单为**阻塞项**，不得以"边建边办"绕过。任一"是"未闭环 → 策划案标注【合规未闭环，不得开工】。

## 与 honesty 边界的衔接

本模块**不替代**：[诚实边界](../SKILL.md#诚实边界) 已声明的法律与合规审查、专业设计。它只输出"待办清单与责任分工"，实际合规判定必须由持牌主体完成。

## 输出契约

```
《落地执行设计》
- 实施路线图（三期 + 里程碑 + 预算参数槽 + 责任人）
- 运营组织（架构 / 岗位 / 人力来源 / 能力缺口 / 四类 SOP）
- 合规审批清单（审批项 / 主管方 / 周期 / 责任人 / 是否阻塞）
- 阻塞项清单（未闭环则不得进入建设期）
```
