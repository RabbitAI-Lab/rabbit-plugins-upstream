# Module 4：商业模式设计引擎

> 确保项目不仅好看，而且赚钱。好看 ≠ 能活，能活 ≠ 能赚。

## 核心原则

> 商业模式不是事后附加的，是从一开始就约束产品设计的。

任何体验产品在设计时就要回答：谁付钱？付多少？付几次？为什么持续付？

---

## 收入模型

### 收入类型矩阵

| 收入类型 | 例子 | 利润率 | 复购性 | 依赖前提 |
|---------|------|--------|--------|---------|
| 门票 | 景区门票 | 中 | 弱 | 客流量足够大 |
| 餐饮 | 正餐 / 小吃 / 咖啡 | 中 | 中 | 停留时间足够长 |
| 住宿 | 主题民宿 / 酒店 | 高 | 强 | 留客过夜 |
| 商业空间 | 租金 / 联营 | 低（稳定） | 强 | 客流持续 |
| 文创 | 衍生品 / 礼品 | 中 | 中 | IP 已成立 |
| 活动 | 节庆 / 体验课程 | 中 | 中 | 内容运营能力 |
| 会员 | 年卡 / 俱乐部 | 高 | 强 | 复购场景存在 |
| IP 授权 | 品牌授权 / 联名 | 极高 | 弱 | IP 已成资产 |

### 收入结构陷阱

| 陷阱 | 表现 | 后果 |
|------|------|------|
| 单一门票依赖 | 门票收入占比 > 70% | 客流下滑即崩塌 |
| 一次性消费主导 | 无复购产品 | 三年后死掉 |
| 政府补贴依赖 | 政策性收入占比高 | 政策变动即崩塌 |
| 高投入低产出 | 建设成本远超运营收入 | 投资无法回收 |
| 假商业闭环 | 收入看起来多元，实际都靠门票输血 | 拆开看即塌 |

## 成本模型

| 成本类型 | 内容 | 控制杠杆 |
|---------|------|---------|
| 建设成本 | 土建 / 景观 / 装修 / 设备 | 一次性，决策时锁定 |
| 运营成本 | 物业 / 安保 / 保洁 / 能耗 | 随客流规模变动 |
| 内容成本 | 演艺 / 活动 / 内容更新 | 与体验质量挂钩，不可过度压缩 |
| 人力成本 | 服务 / 运营 / 营销团队 | 与体验质量挂钩 |
| 营销成本 | 获客 / 渠道 / 推广 | 随规模递减 |

**关键判断：** 哪些成本是不可压缩的（决定体验质量），哪些是可以优化的（不影响体验）。

---

## 关键指标

| 指标 | 含义 | 判断标准 |
|------|------|---------|
| 客流量 | 单位时间到访游客数 | 与目的地容量匹配 |
| 停留时间 | 平均游客停留时长 | 决定消费机会 |
| 客单价 | 人均消费金额 | 与目标游客层级匹配 |
| 转化率 | 体验 → 消费 转化比例 | 嵌入式消费 > 50% |
| 复购率 | 二次到访比例 | > 15% 算健康 |
| 推荐率 | NPS / 主动传播比例 | > 30% 算优秀 |

## 四个必答问题（强制回答）

### Q1：谁付钱？

不要回答"游客"，要回答具体到：
- 什么层级的游客？
- 在什么场景下？
- 为什么这个人群愿意付？
- 付的是体验费还是商品费还是身份费？

### Q2：为什么付钱？

不是"因为有 XX 资源"，而是：
- 游客购买的是功能价值还是情绪价值？
- 付费动机是必需 / 享受 / 身份？
- 替代选择是什么？为什么不去替代？

### Q3：收入增长在哪里？

不是"客流增加"，而是：
- 是客单价提升？通过什么？
- 是复购率提升？通过什么？
- 是新场景拓展？拓展到哪里？
- 增长的天花板在哪？

### Q4：如何避免一次性消费？

必须有明确答案：
- 复购产品是什么？
- 复购钩子是什么？
- 持续内容更新机制？
- 用户资产沉淀机制？

## 商业闭环校验

```
单客经济模型：
  获客成本 < 客均贡献 × 复购次数 × 利润率

  如不成立 → 商业模式不成立

可持续性校验：
  收入 - 成本 = 利润 > 0（运营第 3 年）

  如不成立 → 商业不可持续

抗风险校验：
  客流下降 30% 后是否仍可维持运营？

  如不成立 → 抗风险能力弱
```

## 输出契约

```
《商业模型》
- 收入结构（收入类型 + 占比 + 依赖前提）
- 成本结构（成本类型 + 控制杠杆 + 不可压缩项）
- 关键指标目标值（客流 / 停留 / 客单价 / 转化 / 复购 / NPS）
- 四问回答（谁付 / 为什么付 / 增长在哪 / 如何避免一次性）
- 单客经济模型校验
- 抗风险校验
- 关键未知与验证方法
```

## 常见陷阱

| 陷阱 | 表现 | 破解 |
|------|------|------|
| 乐观估算 | 客流假设虚高 | 用同类项目实际数据校验 |
| 收入堆砌 | 看起来多元实际靠门票 | 拆开看每项收入的真实占比 |
| 成本遗漏 | 忽略内容 / 营销成本 | 全成本核算 |
| 增长幻觉 | 假设客流持续增长 | 假设客流下降 30% 后是否成立 |
| 政府依赖 | 政策性收入占比高 | 假设补贴退出后是否成立 |
