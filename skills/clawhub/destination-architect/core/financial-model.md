# Module：参数化财务测算模型（M9）

> 承接 Step 9。让策划案"算得出来"，但不"编得出来"。
> 核心原则：**缺数据的不是不填，而是填成参数槽 + 区间 + 敏感性，而非单点假数。**

## 为什么是"参数化"而不是"给个数"

传统策划案给单点数字（投资 3 亿、客流 50 万、回收 8 年），看起来可落地，实则不可证伪。
本模块把财务模型拆成 **参数 → 公式 → 区间 → 敏感性**，让每个数字都能被回填、被追责、被推翻。

---

## 一、参数槽（建模的原子单位）

所有未来源的取值一律写成 `{{参数:名称}}`，并登记入《参数表》（模板见 [templates/proposal.md](../templates/proposal.md)）。

| 参数 | 含义 | 取值区间 | 来源 / 补齐方式 | 责任人 | 阻塞的结论 |
|------|------|---------|---------------|--------|-----------|
| {{参数:总投资}} | 建设 + 筹备总投入 | 区间 `[假设]` | 造价咨询 / 同类项目 | | 回收期 |
| {{参数:目标年客流}} | 稳定年客流 | 区间 `[假设]` | 试运营实测（[falsification-engine.md](falsification-engine.md)） | | 收入 |
| {{参数:客单价}} | 人均消费 | 区间 `[假设]` | 用户调研 | | 单客经济 |
| {{参数:复购率}} | 年复购比例 | 区间 `[假设]` | 试运营实测 | | 三年现金流 |
| {{参数:毛利率}} | 综合毛利率 | 区间 `[假设]` | 同类财务 | | 回收期 |
| {{参数:年运营成本}} | 固定 + 可变 | 区间 `[假设]` | 预算编制 | | 现金流 |

**规则：**
1. 参数槽**不得**被"看起来更专业"的单点数字替代（写"31,500 人"比"3–5 万"更可疑）。
2. 每个参数必须登记：区间 + 来源 + 补齐方式 + 责任人 + 阻塞了哪个结论。
3. 补齐后替换为带 `[实测]` 标签的真值，并在《参数表》记录替换来源与时间。

## 二、测算结构

### 2.1 投资

```
总投资 {{参数:总投资}} = 建设投资 + 筹备投资 + 不可预见费({{参数:不可预见费率}})
```

### 2.2 收入（分结构，禁止单一依赖）

| 收入项 | 公式 | 依赖参数 | 占比目标 |
|--------|------|---------|---------|
| 门票 | 客流 × 票价 × 转化率 | {{参数:年客流}}、{{参数:票价}} | < 30% |
| 住宿 | 房源数 × 入住率 × 房价 × 365 | {{参数:房源数}}… | |
| 餐饮 | 客流 × 转化率 × 客单 | | |
| 体验 / 文创 | 客流 × 转化率 × 客单 | | |

**判断标准：** 单一收入占比 > 70% `[假设]` = 结构风险。

### 2.3 成本

```
年成本 {{参数:年运营成本}} = 人力 + 内容 + 营销 + 维护 + 能耗 + 不可压缩项
```

### 2.4 回报

| 指标 | 输出形式 | 说明 |
|------|---------|------|
| 单客经济 | 获客成本 vs 客均贡献 × 复购次数 × 利润率 | 校验式，非单值 |
| 回收期 | **区间**（乐观 / 基准 / 悲观） | 三情景，不给单点 |
| IRR | **区间** `[假设]` | 与机会成本对比 |
| 第 3 年现金流 | 正 / 负 / 不确定 | 不确定即标"无法判定" |

**禁止：** 输出单一确定回收期（如"8 年"）而不给区间与情景假设。

**强制项：** 必须做"客流下降 30% `[假设]`"压力测试（对接 [investment-review.md](../workflows/investment-review.md) 约束）。

---

## 四、与硬门禁的衔接

> 含 `[假设]` / 参数槽的关键指标，**不得进入投资判断的"通过"结论**（[information-discipline.md](information-discipline.md) 硬门禁）。

因此本模块的输出默认形态是：**《参数化财务模型 + 三情景敏感性》**，投资判断只能是"谨慎投 / 不建议投"，直到关键参数经 [falsification-engine.md](falsification-engine.md) 升级为 `[实测]`。

---

## 输出契约

```
《参数化财务模型》
- 参数表（参数 / 区间 / 来源 / 补齐方式 / 责任人 / 阻塞结论）
- 投资结构
- 收入结构（占比 + 依赖前提）
- 成本结构
- 单客经济校验式
- 回收期 / IRR（三情景区间）
- 敏感性 / 压力测试表
- 待实测升级参数清单（进入投资"通过"前必须先证伪的项）
```
