# Module 2：游客洞察引擎

> 理解游客真正购买的是什么，而不是分析"游客喜欢什么景点"。

## 核心转换

不要问：游客喜欢什么景点？
要问：游客为什么愿意付出时间、金钱和注意力？

前者是市场调研，后者是动机洞察。本模块只做后者。

---

## 游客需求五层模型

| 层级 | 需求类型 | 例子 | 付费意愿 | 复购动力 |
|------|---------|------|---------|---------|
| L1 | 功能需求 | 吃、住、行、安全 | 低（基础品） | 无 |
| L2 | 体验需求 | 新鲜、有趣、好玩 | 中（一次性） | 弱 |
| L3 | 情绪需求 | 放松、治愈、陪伴、逃离 | 高 | 中 |
| L4 | 身份需求 | 证明自己的生活方式、审美、品味 | 很高 | 强 |
| L5 | 传播需求 | 值得分享、社交货币、人设表达 | 高 | 强 |

### 关键洞察

- **只满足 L1-L2 的目的地**：游客来一次就走，靠门票经济，无复购
- **触达 L3 的目的地**：游客愿意停留、愿意付费、产生情感连接
- **触达 L4-L5 的目的地**：游客主动传播、形成身份认同、复购率高

**判断标准：** 你的目的地能在哪一层提供价值？决定了客单价上限与复购率上限。

### 层级陷阱

- 大量景区停留在 L1-L2，靠"项目丰富度"竞争，结果是同质化 + 价格战
- 真正的护城河在 L3-L5，因为情绪 / 身份 / 传播无法被快速复制
- 跳过 L1 直接做 L3-L5 是空中楼阁——基础体验不过关，情绪无从谈起

## 输出契约

```
《游客洞察报告》
- 核心游客画像（不是"中高端家庭"这种废话，而是具体到生活方式 / 价值观 / 消费习惯）
- 深层动机（停在五层模型的哪一层？为什么？）
- 消费场景（在什么情境下愿意付费？付什么费？）
- 传播动力（什么内容会让游客主动分享？人设表达点在哪？）
- 当前层级 → 目标层级（如何升维？）
```

## 画像构建原则

### 禁止

- "目标客群：中高端家庭"
- "面向 25-40 岁都市白领"
- "吸引亲子客群"
- 任何用人口学标签替代动机洞察的描述

### 必须

- 描述具体的生活方式（"周末逃离都市的程序员家庭"）
- 描述价值观（"追求真实感、反感过度商业化"）
- 描述消费习惯（"愿意为情绪价值付费，反感门票捆绑"）
- 描述传播行为（"喜欢在小红书分享'隐藏宝藏地'人设"）

## 必答问题

任何游客洞察必须回答：

1. **游客为什么愿意花一天时间来到这里？** — 不是"我们有 XX 资源"，而是"游客获得 XX"
2. **游客来这里是为了证明什么？** — 身份需求层
3. **游客会向朋友怎么描述这里？** — 传播需求层
4. **游客为什么来第二次？** — 复购动力
5. **游客愿意为什么付费？不愿意为什么付费？** — 真实付费动机

回答不出来 = 洞察未成立。

## 常见误区

| 误区 | 表现 | 破解 |
|------|------|------|
| 资源视角 | "我们有温泉，所以游客会来" | 资源 → 需求的转化链条要拆解 |
| 人群标签 | "面向亲子家庭" | 改为"什么样的亲子家庭、解决什么需求" |
| 功能堆砌 | "增加更多游乐项目就能吸引游客" | 项目丰富度 ≠ 体验深度 |
| 自我感动 | "我们这里很美，游客肯定喜欢" | 美不等于购买理由 |
| 传播幻想 | "游客会自发传播" | 必须设计传播点，不能期待自发 |
