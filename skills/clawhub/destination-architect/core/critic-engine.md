# Module：反向审查引擎

> 本 Skill 的第一层机制：在任何投入之前，缩小选择题。
> 旗舰机制见 [falsification-engine.md](falsification-engine.md)（把选择题变成可证伪的实验）。

## 核心原则

- 任何方案生成之前，必须执行 4 轮专家级审查
- 每轮审查模拟不同角色，提出不同质疑
- 不通过审查的方案，标注为「未验证草稿」
- 每次输出必须附加失败预测
- 每次输出后必须执行自我反思

---

## 对抗真实性机制（防止"审查是戏剧"）

**已知缺陷：** 四轮审查若在同一模型、同一上下文、同一信息上运行，就是角色扮演，不是对抗。信息量不变而自信度上升 = 制造自信。

以下机制用以制造**人为的信息不对称**，让四轮真正不同：

### 机制 1：输入切片差异化

每轮审查**只喂该角色的信息切片**，不喂全套：

| 轮次 | 只允许看到 | 禁止看到 |
|------|-----------|---------|
| 价值审查 | 资源清单 + 目标用户 | 财务模型、运营计划 |
| 竞争审查 | 竞争格局 + 用户画像 | 财务模型、内部规划 |
| 商业审查 | 财务模型 + 同类数据 | 价值叙事、愿景文本 |
| 游客审查 | 体验设计 + 价格 | 投资额、政府诉求、愿景 |

**目的：** 让每轮基于有限信息独立判断，避免后见之明污染。

### 机制 2：Steelman 义务（先立后破）

每轮审查**必须先构造该立场最强的版本**，再提出质疑。

- ❌ "这个价值很虚" —— 直接否定
- ✅ "支持者最强的论证是：__。即便如此，它仍未回答：__。" —— 先立后破

**规则：** 未构造 steelman 就提出的质疑，视为不合格。

### 机制 3：反方举证责任

审查的每个质疑必须**引用具体证据**（数字、同类案例、可观察信号），不得只给断言。

- ❌ "市场风险高"
- ✅ "同类项目 X 首年客流 Y，本项目假设 Z 倍于 X，缺少支撑"

### 机制 4：自我证伪义务

每轮结论必须回答：

> 什么会让我这轮的结论是错的？

用于把"审查通过"从"我同意"降级为"暂未被推翻"。

## 四轮专家级审查（强制执行）

### 第一轮：价值审查

**模拟角色：** 价值审查者（批判性思维）

**审查问题：**

1. 是否真正解决用户需求？（不是"有资源"，而是"有需求"）
2. 是否只是资源包装？（把无价值资源包装成卖点）
3. 是否存在不可替代性？（去掉营销包装后还剩什么）
4. 价值定位是否经得起"为什么专程来"的反复追问？
5. 时代价值是否成立？还是只是地方自豪？

**输出：** 《价值判断报告》

**通过标准：** 5 问中至少 3 问有清晰、不绕圈的回答。

---

### 第二轮：市场竞争审查

**模拟角色：** 竞争者（复制者视角）

**审查问题：**

1. 谁可以复制？（地域 / 资源 / 团队 / 时机 哪个不可复制）
2. 替代方案是什么？（不是同业，而是"满足同一需求的其他方式"）
3. 用户为什么选择你而不是替代方案？
4. 复制难度有多高？时间窗口有多长？
5. 你的优势是结构性还是营销性的？

**输出：** 《竞争风险报告》

**通过标准：** 能清晰说出至少 1 个不可在 1 年内被复制的优势。

---

### 第三轮：商业审查

**模拟角色：** 投资人

**审查问题：**

1. 投资回报在哪里？（现金流来源 / 回收周期 / IRR 估算）
2. 收益是否合理？（与同类项目对比，是否过于乐观）
3. 是否依赖政府输血？（补贴 / 政策性收入占比）
4. 单客经济模型是否成立？（获客成本 vs 客均贡献）
5. 三年后现金流能否为正？

**输出：** 《商业可行性报告》

**通过标准：** 不依赖补贴的运营第 3 年现金流为正。

---

### 第四轮：游客真实审查

**模拟角色：** 真实游客

**审查问题：**

1. 如果我是游客，为什么我要花一天时间来到这里？（不是"因为这里有 XX"，而是"我能得到 XX"）
2. 我会向朋友怎么描述这里？（一句话能否转述）
3. 我会主动分享什么画面 / 内容？
4. 我会来第二次吗？为什么？
5. 我会推荐给谁？为什么推荐？

**输出：** 《游客购买理由报告》

**通过标准：** 5 问中至少 4 问有具体、可信、可触达的回答。

## 失败预测机制（强制附加）

### 强制提问

> 如果三年后失败，最可能原因是什么？

### 六类风险分析

| 风险类型 | 提问 | 早期信号 |
|---------|------|---------|
| 市场风险 | 客流不及预期 / 替代品崛起 / 政策转向 | 同类项目扎堆 / 周边竞品落地 |
| 用户风险 | 用户画像错位 / 需求变迁 / 复购不足 | 冷启动传播率低 / 复购率 < 10% |
| 运营风险 | 团队能力不足 / 内容更新乏力 / 服务崩塌 | 内容更新周期 > 6 个月 / 投诉率上升 |
| 商业风险 | 单客经济不成立 / 收入单一 / 成本失控 | 客单价 < 预期 60% / 门票依赖 > 70% |
| 文化风险 | 文化真实性受质疑 / IP 同质化 / 价值观冲突 | 在地居民反感 / 媒体负面 / 用户吐槽"假" |
| 政策风险 | 土地 / 环保 / 安全 / 文保 政策变化 | 用地性质争议 / 生态红线 / 文保限制 |

### 输出

```
《失败预警报告》
- 三年后最可能的失败原因（具体到根因）
- 六类风险逐项评估（高 / 中 / 低 + 早期信号）
- 最高优先级风险（Top 3）
- 监测指标（运营中应监控的早期信号）
- 缓解措施（针对 Top 3 风险）
```

## 专家自我反思（每次输出后强制）

每次分析结束必须回答以下 8 个问题，缺一不可：

1. **当前最大的未知是什么？** — 标注未验证的核心假设
2. **哪些判断只是我的假设？** — 区分"已知"与"假设"
3. **什么证据可以验证？** — 给出可低成本验证的方法
4. **如果预算减少 50%，方案还能成立吗？** — 验证核心价值是否依赖堆砌
5. **如果竞争者复制，优势在哪里？** — 验证护城河
6. **有没有更简单、更低成本的验证方式？** — 寻找 MVP 验证路径
7. **本次结论的预测是否已登记？锁定时点是什么？** — 见 [decision-calibration.md](decision-calibration.md)
8. **如果本 Skill 的判断从未经校准，本次结论应打几折？** — 未校准则标注"未经校准"

**反思原则：** 反思不是否定方案，是让用户带着"已知未知"做决策，而非盲目相信方案。

## 反例库（常见"假通过"）

| 假通过 | 表现 | 破解 |
|--------|------|------|
| 价值假通过 | "我们有 XX 资源所以有价值" | 资源 ≠ 价值，问"游客为什么专程来" |
| 竞争假通过 | "我们是唯一做 XX 的" | 唯一不等于不可复制，问复制难度 |
| 商业假通过 | "客流 100 万，门票 100 元，收入 1 亿" | 客流假设虚高，用同类项目校验 |
| 游客假通过 | "目标客群：中高端家庭" | 人群标签 ≠ 购买理由 |
| 失败假通过 | "风险可控" | 必须具体到根因，不能泛泛而谈 |

## 输出契约

```
《反向审查报告》
- 第一轮 价值判断报告
- 第二轮 竞争风险报告
- 第三轮 商业可行性报告
- 第四轮 游客购买理由报告
- 失败预警报告（六类风险 + Top 3）
- 自我反思（8 问回答）
- 综合判断：值得做 / 谨慎做 / 不建议做
- 关键未知与最低成本验证路径
```

## 综合判断输出格式

```
综合判断：[值得做 / 谨慎做 / 不建议做]

核心理由（3 条以内）：
1. ...
2. ...
3. ...

必须先验证的关键假设（Top 3）：
1. ... → 验证方法：...
2. ... → 验证方法：...
3. ... → 验证方法：...

最大风险：
...

建议下一步：
...
```
