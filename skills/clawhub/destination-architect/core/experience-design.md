# Module 3 + 5：目的地产品设计与空间体验设计引擎

> 从资源创造体验产品。设计游客完整体验旅程，而非罗列景点 / 建筑 / 活动。

## 核心原则

- 禁止：简单罗列景点、建筑、活动
- 必须：设计游客完整体验旅程
- 空间不是展示资源，空间应该引导行为

---

## 完整体验旅程（5 节点强制设计）

### 节点 1：到达前 — 如何产生期待？

| 设计要点 | 提问 |
|---------|------|
| 信息触点 | 游客在哪里第一次听说这里？看到什么？ |
| 期待构建 | 第一印象能否建立"值得专程来"的期待？ |
| 决策成本 | 从兴趣到下单的转化阻力有多大？ |
| 预体验 | 是否有内容 / 故事让游客在出发前已经"进入"目的地？ |

**关键：** 期待 > 实际体验 = 失望；期待 < 实际体验 = 惊喜。要管理期待，不是无限拉高。

### 节点 2：到达时 — 如何形成第一印象？

| 设计要点 | 提问 |
|---------|------|
| 第一眼视觉 | 进入目的地的第一眼看到什么？是否有"啊"的瞬间？ |
| 感官冲击 | 视觉 / 听觉 / 嗅觉 / 触觉的第一个烙印是什么？ |
| 情绪启动 | 第一印象要触发什么情绪？平静 / 震撼 / 温暖 / 自由？ |
| 现实落差 | 是否立即与日常都市形成对比？ |

**关键：** 第一印象决定游客是否愿意"放下手机"开始体验。

### 节点 3：游览中 — 如何产生高潮？

| 设计要点 | 提问 |
|---------|------|
| 节奏设计 | 是否有张弛节奏？不是一路密集刺激，也不是一路平淡？ |
| 情绪曲线 | 是否有明确的情绪高潮点（peak moment）？ |
| 参与转化 | 游客是观看者还是参与者？能否从被动观看转为主动参与？ |
| 记忆锚点 | 游客离开后会记得哪个具体瞬间？ |

**关键：** 没有高潮的旅程 = 平淡体验 = 不会复购、不会传播。

### 节点 4：消费时 — 如何自然转化？

| 设计要点 | 提问 |
|---------|------|
| 消费时机 | 消费场景是否在情绪高点之后？还是突兀插入？ |
| 价格合理性 | 价格是否匹配情绪价值？还是与门票捆绑引发反感？ |
| 商品意义 | 游客购买的是商品还是意义？是否承载体验记忆？ |
| 转化阻力 | 支付 / 选择 / 携带的阻力是否最小化？ |

**关键：** 好的消费转化是"游客想买"，差的是"被推销"。

### 节点 5：离开后 — 如何传播和复购？

| 设计要点 | 提问 |
|---------|------|
| 离别情绪 | 离开时的情绪是什么？不舍 / 满足 / 期待再来？ |
| 传播触发 | 什么内容 / 画面 / 故事会让游客主动分享？ |
| 社交货币 | 游客分享后能获得什么身份表达？ |
| 复购钩子 | 是否有未完成的内容 / 升级的体验作为复购理由？ |

**关键：** 离开后的传播和复购，比到达前的获客更重要——这是复利。

## 产品体系设计

### 产品分层

| 层级 | 作用 | 客单价 | 复购率 |
|------|------|--------|--------|
| 引流产品 | 低门槛获取用户 | 低 | 弱 |
| 核心体验产品 | 提供 L3-L5 价值（情绪 / 身份 / 传播） | 中-高 | 中-强 |
| 高客单产品 | 提升客单价 | 高 | 中 |
| 复购产品 | 设计二次消费理由 | 中 | 强 |

**判断标准：** 引流产品不能成为唯一产品——会陷入门票经济陷阱。

### 游线设计原则

- 不是把所有景点串起来，而是设计**情绪曲线**
- 节奏：紧 → 松 → 高潮 → 沉淀 → 余韵
- 每段游线必须有一个"会被记住的瞬间"
- 停留节点 = 消费节点 = 情绪节点

## 空间体验设计

### 核心原则

> 空间不是展示资源。空间应该引导行为。

| 原则 | 错误做法 | 正确做法 |
|------|---------|---------|
| 引导行为 | 把展板铺满空间 | 用空间节奏引导游客停下来 / 走 / 看 / 触 |
| 视觉记忆点 | 每个角落都"美化" | 设计 1-3 个标志性画面，其余留白 |
| 停留节点 | 全程通畅无停留 | 设计自然停留点，停留即消费机会 |
| 消费触点 | 商业空间集中一隅 | 把消费节点嵌入情绪高点之后 |

### 空间四层设计

| 层级 | 设计要点 |
|------|---------|
| 整体布局 | 主入口 / 核心区 / 配套区 / 离开动线 的关系 |
| 动线设计 | 单线 / 环线 / 自由式的选择依据是体验节奏，不是空间形状 |
| 视觉记忆点 | 1-3 个"必拍画面"——游客拍照即传播 |
| 停留与消费 | 每个停留节点对应一个消费场景或情绪场景 |

### 反例

- ❌ "把文化资源做成展板" — 展板是单向信息，不产生体验
- ❌ "每个角落都做景观" — 视觉过载 = 无记忆点
- ❌ "商业街集中布置" — 与体验动线分离 = 低转化
- ❌ "入口即售票处" — 第一印象让位给商业逻辑

## 输出契约

```
《体验产品设计》
- 完整体验旅程（5 节点逐个设计）
- 产品体系（引流 / 核心 / 高客单 / 复购）
- 游线设计（情绪曲线 + 记忆锚点）
- 空间布局（动线 / 视觉记忆点 / 停留 / 消费触点）
- 内容活动（支撑体验的运营内容）
- 关键未知与验证方法
```

## 常见陷阱

| 陷阱 | 表现 | 破解 |
|------|------|------|
| 项目堆砌 | 把游乐设施 / 项目当作产品 | 产品 = 完整体验旅程，不是项目清单 |
| 视觉过载 | 每个角落都设计 | 留白 + 1-3 个核心记忆点 |
| 商业突兀 | 在情绪低谷插入消费 | 消费节点嵌入情绪高点之后 |
| 一次性消费 | 没有复购钩子 | 设计未完成内容 / 升级体验 |
| 自我感动 | "我们的设计很美" | 美不等于购买理由，问游客是否记得住 |
