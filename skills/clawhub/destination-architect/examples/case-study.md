# 案例演示：某山地古村文旅项目

> 这是一个**虚构示例**，用于展示 Destination Architect Skill 的完整 10 步工作流（Step 0–9）如何执行。
> 正文演示 Step 1–7 主线；Step 0 委托诊断与 Step 8 证伪/校准见文末「升级机制演示」；Step 9 策划案组装见 [templates/proposal.md](../templates/proposal.md)。
> 注意：真实使用时，每一步的输出必须基于真实数据，本案例仅演示结构。

---

## Step 1：项目诊断

### 项目基本情况

某山地古村位于 [省份] [县市]，海拔 800 米，距省会 2.5 小时车程。村内 200 余户，常住人口 60 人（多为老人），明清古建保存约 40%。

### 核心诉求

| 诉求方 | 诉求 | 冲突 |
|--------|------|------|
| 投资方 | 8 年内回本，IRR > 12% | 与"小众"定位有张力 |
| 政府 | 乡村振兴示范 + 带动就业 | 与"小众"定位有张力 |
| 运营 | 守住文化真实性 | 与"客流规模"诉求冲突 |

### 资源基础

| 资源类型 | 内容 | 可塑性 |
|---------|------|--------|
| 自然 | 山地 / 古树林 / 山泉 | 中 |
| 人文 | 在地民俗（半数仍存活） | 高 |
| 历史 | 明清古建 40% 保存 | 中 |
| 产业 | 手工造纸（仅 2 户仍在做） | 中-高 |

### 关键约束

- 土地：村集体建设用地，限制商业开发
- 政策：部分古建文保单位，限改造
- 团队：本地无文旅运营经验团队

### 关键未知

| 未知项 | 重要性 | 获取方法 |
|--------|--------|---------|
| 真实客流潜力 | 高 | 同类项目实际数据 + 实地踏勘 |
| 在地居民意愿 | 高 | 入户访谈 |
| 目标用户付费意愿 | 高 | 用户调研 |

---

## Step 2：价值发现

### 价值四问

| 维度 | 判断 | 依据 |
|------|------|------|
| 独特性 | 中-高 | 古建 + 在地民俗 + 手工造纸组合在区域内唯一 |
| 稀缺性 | 中 | 类似古村在全省 10+ 个，但保存完整 + 在地存活的少 |
| 情绪价值 | 高 | 慢、真、归属，契合都市焦虑 |
| 时代价值 | 高 | "真"是当代稀缺，"慢"是当代需求 |

### 核心价值定位

> 游客来这里是为了获得"在真实的人居古村中放慢 24 小时"。

### 目的地主题

**"真实慢村"** — 不是怀旧景区，是仍在生活的村庄。

### 差异化竞争点

相对替代目的地：

| 替代目的地 | 共同点 | 我们的差异 |
|----------|--------|----------|
| 周边某古镇 | 古建 | 仍在生活，非商业景区 |
| 周边某度假村 | 山地环境 | 真实人居 vs 人工景观 |

### 文化 IP 路径

手工造纸 → "纸的旅程"体验产品 → 在地工坊 IP → 文创衍生 → 长期资产

---

## Step 3：战略定位

### 一句话定位

> 一个仍在生活的山地古村，为都市人提供 24 小时的真实慢生活。

### 核心用户画像

- 生活方式：周末逃离都市的 28-40 岁知识工作者家庭
- 价值观：追求真实感，反感过度商业化，重视在地性
- 消费习惯：愿为情绪价值付费，反感门票捆绑
- 传播行为：在小红书分享"隐藏宝藏地"人设

### 不可替代性

- 真实人居：村庄仍在生活，不是景区化标本（不可在 1 年内复制）
- 在地工艺：手工造纸仍有人在做（不可快速复制）

### 三年愿景

冷启动验证后，年客流 3-5 万（不追求规模），复购率 25%+，NPS 40+，现金流第 3 年为正。

---

## Step 4：体验产品设计（节选）

### 完整体验旅程

**到达前：** 小红书 / 朋友推荐触达，看到"仍在生活的古村"，产生期待。
**到达时：** 进村前一段山路，第一眼看到炊烟 + 古树林，与都市形成落差。
**游览中：** 不是观光，是参与——和村民一起造纸、走山路、吃在地饭。
**消费时：** 住宿 + 体验课 + 在地农产，嵌入自然，无强制消费。
**离开后：** 带走自己造的纸 + 在地故事，主动分享"我找到一个真实的小村"。

### 产品体系

| 产品 | 客单价 | 复购率 |
|------|--------|--------|
| 引流：山泉景观（免费） | 0 | - |
| 核心：24 小时慢村体验（住宿 + 体验） | 800-1200 | 中 |
| 高客单：私享在地工艺课 | 1500+ | 中 |
| 复购：四季限定体验 | 600 | 强 |

---

## Step 5：商业设计（节选）

### 收入结构

| 收入类型 | 占比目标 |
|---------|---------|
| 住宿 | 50% |
| 体验课 | 20% |
| 餐饮 | 15% |
| 文创（造纸衍生） | 10% |
| 其他 | 5% |

门票 = 0（不收门票，靠体验住宿）

### 单客经济模型

```
获客成本：~150 元（小红书 + 朋友推荐，KOC 投放低）
客均贡献：~1000 元
复购次数：1.25
利润率：~35%

校验：150 < 1000 × 1.25 × 0.35 = 437.5 → 通过
```

### 四问回答

1. **谁付钱：** 28-40 岁知识工作者家庭，为"真实慢生活"付费。
2. **为什么付：** 购买情绪价值（逃离 + 归属），不是购买景观。
3. **增长在哪：** 客单价（私享课）+ 复购（四季限定），不追客流规模。
4. **避免一次性：** 四季限定 + 造纸工坊会员 + 在地社群。

---

## Step 7：风险审查（强制）

### 第一轮：价值审查

| 审查问 | 回答 | 通过 |
|--------|------|------|
| 是否真正解决用户需求？ | 解决"逃离都市 + 真实感"需求 | ✓ |
| 是否只是资源包装？ | 不是，价值在体验而非资源 | ✓ |
| 是否存在不可替代性？ | 真实人居 + 在地工艺，1 年内难复制 | ✓ |
| "为什么专程来"经得起追问？ | 24 小时真实慢生活，可答 | ✓ |
| 时代价值？ | "真"与"慢"是当代稀缺 | ✓ |

**结论：** 价值审查通过。

### 第二轮：竞争审查

| 审查问 | 回答 |
|--------|------|
| 谁可以复制？ | 类似古村 10+ 个，但"仍在生活 + 在地工艺"组合难复制 |
| 替代方案？ | 都市近郊民宿（但缺真实感） |
| 用户为什么选你？ | 真实感 + 在地性 + 慢节奏，替代品无 |
| 复制难度？ | 真实人居 + 工艺存活需时间，窗口 3-5 年 |
| 优势性质？ | 结构性（在地真实），非营销性 |

**结论：** 竞争审查通过。

### 第三轮：商业审查

| 审查问 | 回答 |
|--------|------|
| 投资回报？ | 6-8 年回本（建设投入低，靠体验非建景） |
| 收益是否合理？ | 与同类小众目的地主对比合理 |
| 是否依赖政府输血？ | 不依赖，收入来自住宿 + 体验 |
| 单客经济？ | 通过（见 Step 5） |
| 第 3 年现金流？ | 预计为正（客流 3 万 × 客均 1000 × 利润 35%） |

**结论：** 商业审查通过，但需验证客流假设。

### 第四轮：游客审查

| 审查问 | 回答 |
|--------|------|
| 为什么花一天来？ | "我能在一个仍在生活的古村里放慢 24 小时" |
| 怎么描述？ | "我找到一个真实的小村" |
| 分享什么？ | 炊烟 / 古树林 / 自己造的纸 |
| 会来第二次吗？ | 四季不同体验，会 |
| 推荐给谁？ | 同样追求真实感的朋友 |

**结论：** 游客审查通过。

### 失败预测

**三年后最可能的失败原因：** 在地居民流失导致"真实人居"瓦解，沦为景区标本。

| 风险类型 | 评估 | 早期信号 |
|---------|------|---------|
| 市场风险 | 中 | 周边类似项目扎堆 |
| 用户风险 | 低 | 目标用户明确 |
| 运营风险 | 高 | 本地无运营团队 |
| 商业风险 | 中 | 客流假设需验证 |
| 文化风险 | 高 | 居民流失 = 价值崩塌 |
| 政策风险 | 低 | 已与文保协调 |

**Top 3 风险：**
1. 居民流失 → 缓解：与村民共建利益分享机制
2. 运营能力不足 → 缓解：引入有经验运营合伙人
3. 客流不及预期 → 缓解：先做 3 个月试运营验证

### 自我反思

1. **最大未知：** 真实客流潜力（3 万是否可达）
2. **假设：** 目标用户愿为"真实"付费（需用户调研验证）
3. **验证证据：** 3 个月试运营 + 用户调研
4. **预算减 50%：** 仍可成立（建设投入本就不高，核心在体验设计）
5. **竞争者复制：** 真实人居 + 在地工艺难复制
6. **更低成本验证：** 不建设，先用现有民居试运营 3 个月

### 综合判断

```
综合判断：谨慎做（值得做，但需先验证客流假设）

核心理由：
1. 价值真实成立（四轮审查通过）
2. 商业模型合理（不依赖规模，靠体验住宿）
3. 最大风险可缓解（居民共建 + 试运营验证）

必须先验证的关键假设：
1. 客流 3 万是否可达 → 3 个月试运营
2. 目标用户付费意愿 → 用户调研（最低成本）
3. 在地居民意愿 → 入户访谈

三年后最可能的失败原因：居民流失导致价值崩塌

建议下一步：不急于建设，先做 3 个月试运营验证客流与付费意愿。
```

---

## 本案例的关键启示

1. **不收门票** — 收门票 = 景区化，与"真实人居"价值冲突
2. **不追求客流规模** — 3 万 vs 30 万，前者保价值，后者毁价值
3. **试运营先行** — 不建设先验证，最低成本验证核心假设
4. **居民共建** — 居民流失是最大风险，利益分享是核心缓解措施
5. **反向审查通过 ≠ 包票** — 仍有未知，但带着已知未知做决策

# 升级机制演示（v2）

> 以下演示本 Skill 升级后的 Step 0 / 证据标签 / 证伪器 / 校准 / 反合理化如何改变输出。

## 演示 1：Step 0 委托诊断

**使用者原话：** "帮我写个方案，我们想拿这个村申请省级文旅示范项目。"

**委托诊断：**

```
- 委托类型：合法性生产（已有决定，需要"能过审"的文本）
- 真实瓶颈：政治/决策（项目是否能上，取决于申报，不取决于分析）
- 本 Skill 边际价值：低——卡点不在分析
```

**响应：** 声明不做合法性包装。若仍需文本，输出必须标注"应要求生成，非独立判断"。这避免了把 Skill 误用为合理化工具。

---

## 演示 2：证据标签（同一指标的 before / after）

**❌ 升级前（裸数字）：**

> 预计年客流 3 万人，客单价 1000 元，复购率 25%。

**✅ 升级后（带标签）：**

> 预计年客流 1.5–4 万人 `[假设，基于 3 个同类小众目的地规模类比，无可比公开数据，验证成本约 2 万元/3 个月试运营]`；客单价 800–1200 元 `[假设，来自目标用户调研缺位，需验证]`；复购率目标 25% `[假设，行业基准 10–20%，本项目取上限因"四季限定"设计，未经证实]`。

**改变：** 不提供虚假确定性；把"3 万人"这个可能被记住并用于决策的数，换成"区间 + 验证成本"。

---

## 演示 3：最小成本证伪计划（旗舰）

| 假设 | 证伪条件 | 阈值（锁定） | 实验方法 | 成本 | 周期 | 证伪后动作 |
|------|---------|------------|---------|------|------|----------|
| 用户愿为"真实慢村"支付 ≥800 元/晚 | 抽样 30 人中愿付 ≥800 元者 < 6 人 | 20% | 定向问卷 + 定金测试 | ~0.5 万 | 2 周 | 重构价值主张或降级定位 |
| 年客流可达 1.5 万+ | 试运营 3 个月实际客流 < 3750 人 | 3750 人 | 用现有 5 间民居试运营 | ~15 万 | 3 个月 | 止损或缩小规模 |
| 在地居民愿参与共建 | 意向签约 < 村内 30% 户 | 30% | 入户访谈 | ~0.2 万 | 2 周 | 更换选址或调整模式 |

**硬门禁校验：**

- 总投资假设 2000 万 → 单次实验上限 20 万。以上三项均低于上限 ✅
- 结论：**可先验证后决策，无需先建设**

**不可证伪项：** 无（三项均可廉价验证）。

## 演示 4：预测登记（先于结论）

| 预测 | 置信度 | 时间窗 | 验证方式 | 判定阈值 | 锁定时点 |
|------|--------|--------|---------|---------|---------|
| 定向问卷中 ≥20% 用户愿付 800+ 元 | 中 | 2 周 | 问卷 | 20% | 2026-10-05 发出问卷前 |
| 3 个月试运营客流 ≥3750 人 | 中 | 3 个月 | 实际计数 | 3750 | 试运营开始前 |
| 居民意向签约率 ≥30% | 中 | 2 周 | 入户访谈 | 30% | 访谈开始前 |

**校准状态：未经校准**（本 Skill 历史判断尚无回访记录）→ 本页结论标注"未经校准"，使用者据此打折。

## 演示 5：反合理化警报

**使用者（在已给出"谨慎做"后）：** "你太保守了，直接说值得做吧，我拿去汇报。"

**响应：**

```
【合理化警报】
检测到结论被重述请求，但未发现新证据。

原始判断：谨慎做（置信度：中）
原始预测：见预测登记（3 条，均已锁定）

请问：什么新证据改变了原判断？

- 若无新证据 → 不改变结论。若你仍需要"值得做"的文本，可提供，但必须标注：
  「本文为应要求重述，非基于新证据的分析结论，不改变原判断。」
```

**改变：** 工具不再"被重问到同意"。原始判断与预测被保留，重述被标记。这是从"合理化机器"回到"决策辅助"的关键机制。
