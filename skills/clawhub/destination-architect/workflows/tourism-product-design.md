## 设计流程

### 阶段 1：完整体验旅程设计（5 节点强制）

逐节点回答（详见 [core/experience-design.md](../core/experience-design.md#完整体验旅程5-节点强制设计)）：

#### 节点 1：到达前

| 设计 | 内容 |
|------|------|
| 信息触点 | 游客在哪里第一次听说这里？ |
| 期待构建 | 第一印象是什么？ |
| 决策成本 | 转化阻力如何降低？ |
| 预体验 | 出发前已"进入"目的地的内容？ |

#### 节点 2：到达时

| 设计 | 内容 |
|------|------|
| 第一眼视觉 | 进入的"啊"瞬间？ |
| 感官冲击 | 视 / 听 / 嗅 / 触 的第一烙印？ |
| 情绪启动 | 触发什么情绪？ |
| 现实落差 | 与日常的对比？ |

#### 节点 3：游览中

| 设计 | 内容 |
|------|------|
| 节奏设计 | 张弛节奏如何？ |
| 情绪曲线 | 高潮点在哪？ |
| 参与转化 | 何时从观看者变参与者？ |
| 记忆锚点 | 游客会记住哪个瞬间？ |

#### 节点 4：消费时

| 设计 | 内容 |
|------|------|
| 消费时机 | 嵌入情绪高点之后？ |
| 价格合理性 | 匹配情绪价值？ |
| 商品意义 | 承载体验记忆？ |
| 转化阻力 | 支付 / 选择 / 携带 最小化？ |

#### 节点 5：离开后

| 设计 | 内容 |
|------|------|
| 离别情绪 | 不舍 / 满足 / 期待再来？ |
| 传播触发 | 主动分享什么？ |
| 社交货币 | 分享后获得什么身份表达？ |
| 复购钩子 | 二次消费理由？ |

---

### 阶段 2：产品体系设计

| 产品层级 | 设计 | 客单价 | 复购率 |
|---------|------|--------|--------|
| 引流产品 | 低门槛获客 | 低 | 弱 |
| 核心体验产品 | 提供 L3-L5 价值 | 中-高 | 中-强 |
| 高客单产品 | 提升客单价 | 高 | 中 |
| 复购产品 | 二次消费理由 | 中 | 强 |

**判断标准：** 引流产品不能是唯一产品。

---

### 阶段 3：游线设计

设计情绪曲线而非景点串联：

```
紧 → 松 → 高潮 → 沉淀 → 余韵
```

- 每段游线必须有一个"会被记住的瞬间"
- 停留节点 = 消费节点 = 情绪节点
- 节奏：避免一路密集刺激或一路平淡

---

### 阶段 4：空间体验设计

| 设计层 | 内容 |
|--------|------|
| 整体布局 | 主入口 / 核心区 / 配套区 / 离开动线 |
| 动线设计 | 单线 / 环线 / 自由式（按体验节奏） |
| 视觉记忆点 | 1-3 个"必拍画面"（拍照即传播） |
| 停留与消费 | 每个停留节点对应消费 / 情绪场景 |

**核心原则：** 空间不是展示资源，空间应该引导行为。

---

### 阶段 5：内容活动设计

| 活动类型 | 频次 | 目标 |
|---------|------|------|
| 日常内容 | 持续 | 维持热度 |
| 主题节庆 | 季节性 | 制造高峰 |
| 限定体验 | 不定期 | 复购触发 |
| 文化活动 | 长期 | 文化沉淀 |

---

## 输出契约

```
《体验产品设计》
- 完整体验旅程（5 节点逐个设计）
- 产品体系（引流 / 核心 / 高客单 / 复购）
- 游线设计（情绪曲线 + 记忆锚点）
- 空间布局（动线 / 视觉记忆点 / 停留 / 消费触点）
- 内容活动（日常 / 节庆 / 限定 / 文化）
- 关键未知与验证方法
```

---

## 工作流执行约束

1. **5 节点不可省略** — 缺一个节点等于旅程不完整
2. **产品体系必须有复购产品** — 没有复购产品 = 一次性消费陷阱
3. **空间设计必须基于行为引导** — 不是堆砌景观
4. **每个设计决策必须能回答"游客为什么为此付费"**
