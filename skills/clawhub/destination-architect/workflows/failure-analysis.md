## 阶段 1：四轮专家级审查（强制执行）

### 第一轮：价值审查

调用 [core/critic-engine.md](../core/critic-engine.md#第一轮价值审查)。

**模拟角色：** 价值审查者

**审查 5 问：**

1. 是否真正解决用户需求？
2. 是否只是资源包装？
3. 是否存在不可替代性？
4. 价值定位是否经得起"为什么专程来"的反复追问？
5. 时代价值是否成立？

**输出：** 《价值判断报告》

**通过标准：** 5 问中至少 3 问有清晰、不绕圈的回答。

---

### 第二轮：市场竞争审查

调用 [core/critic-engine.md](../core/critic-engine.md#第二轮市场竞争审查)。

**模拟角色：** 竞争者（复制者视角）

**审查 5 问：**

1. 谁可以复制？
2. 替代方案是什么？
3. 用户为什么选择你而不是替代方案？
4. 复制难度有多高？时间窗口有多长？
5. 你的优势是结构性还是营销性的？

**输出：** 《竞争风险报告》

**通过标准：** 能清晰说出至少 1 个不可在 1 年内被复制的优势。

---

### 第三轮：商业审查

调用 [core/critic-engine.md](../core/critic-engine.md#第三轮商业审查)。

**模拟角色：** 投资人

**审查 5 问：**

1. 投资回报在哪里？
2. 收益是否合理？
3. 是否依赖政府输血？
4. 单客经济模型是否成立？
5. 三年后现金流能否为正？

**输出：** 《商业可行性报告》

**通过标准：** 不依赖补贴的运营第 3 年现金流为正。

---

### 第四轮：游客真实审查

调用 [core/critic-engine.md](../core/critic-engine.md#第四轮游客真实审查)。

**模拟角色：** 真实游客

**审查 5 问：**

1. 如果我是游客，为什么我要花一天时间来到这里？
2. 我会向朋友怎么描述这里？
3. 我会主动分享什么画面 / 内容？
4. 我会来第二次吗？为什么？
5. 我会推荐给谁？为什么推荐？

**输出：** 《游客购买理由报告》

**通过标准：** 5 问中至少 4 问有具体、可信、可触达的回答。

## 阶段 2：失败预测（强制附加）

### 强制提问

> 如果三年后失败，最可能原因是什么？

调用 [core/critic-engine.md](../core/critic-engine.md#六类风险分析)。

| 风险类型 | 评估 | 早期信号 |
|---------|------|---------|
| 市场风险 | 高 / 中 / 低 | |
| 用户风险 | 高 / 中 / 低 | |
| 运营风险 | 高 / 中 / 低 | |
| 商业风险 | 高 / 中 / 低 | |
| 文化风险 | 高 / 中 / 低 | |
| 政策风险 | 高 / 中 / 低 | |

### Top 3 风险排序

按"可能性 × 影响度"排序，选出 Top 3 风险，每个给出：
- 根因
- 早期监测信号
- 缓解措施

## 阶段 3：专家自我反思（强制）

调用 [core/critic-engine.md](../core/critic-engine.md#专家自我反思每次输出后强制)。

回答 8 问：

1. 当前最大的未知是什么？
2. 哪些判断只是我的假设？
3. 什么证据可以验证？
4. 如果预算减少 50%，方案还能成立吗？
5. 如果竞争者复制，优势在哪里？
6. 有没有更简单、更低成本的验证方式？
7. 本次结论的预测是否已登记？锁定时点是什么？
8. 如果本 Skill 的判断从未经校准，本次结论应打几折？

## 阶段 5：证伪与校准（Step 8，强制收尾）

| 预测 | 置信度 | 时间窗 | 验证方式 | 判定阈值 | 锁定时点 |
|------|--------|--------|---------|---------|---------|
| | 高/中/低 | | | | |

**顺序强制：** 预测登记不得晚于结论发布。

### 5.3 校准状态声明

- 若本 Skill 历史判断未经回访校准 → 本次结论标注"**未经校准**"

### 5.4 一页结论

## 工作流执行约束

1. **不可跳过** — 任何方案未通过本工作流都标注为「未验证草稿」
2. **四轮审查不可合并** — 每轮视角独立，且必须执行信息切片差异化（见 [core/critic-engine.md](../core/critic-engine.md#对抗真实性机制防止审查是戏剧)）
3. **每轮必须先 steelman 再质疑** — 未构造最强反方论证的质疑视为不合格
4. **每个质疑必须举证** — 引用数字 / 同类案例 / 可观察信号，不得只给断言
5. **失败预测必须具体到根因** — 不能用"风险可控"敷衍
6. **自我反思必须诚实** — 区分"已知"与"假设"
7. **综合判断必须给结论** — 不能模棱两可
8. **Step 8 不可跳过** — 未产出"可证伪的下一步"与"预测登记"的输出视为未完成
9. **结论之后不得被无证据重述改变** — 触发合理化警报（见 [core/decision-calibration.md](../core/decision-calibration.md#合理化警报)）
