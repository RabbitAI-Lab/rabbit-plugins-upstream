# 工业领域测试知识库（Industrial Domain Knowledge）

> 本文件是 `industrial-testcase-generator` 的领域知识底座。生成用例前通读一遍；
> 具体阶段二/三的**方法选择与质量属性表以内联在 SKILL.md 的为准**，本文件提供背景知识、标准依据与测试要点。

---

## 1. 知识体系总览

工业测试 = **工业控制架构认知 + 现场总线/工业协议 + 可靠性/安全标准 + 测试方法**。

```
工业测试能力模型
├── ① 系统架构（PLC/DCS、SCADA、HMI、MES、边缘计算）
├── ② 通信协议（Modbus、OPC UA、Profinet、Profibus、EtherNet/IP、MQTT、IEC 61850）
├── ③ 标准（IEC 61508/62061 功能安全、IEC 62443 网络安全、GB/T 系列）
├── ④ 可靠性（7×24 运行、断电恢复、冗余/热备、看门狗）
└── ⑤ 环境（高低温、粉尘、振动、EMI）
```

## 2. 系统架构与测试关注点

| 层级/子系统 | 说明 | 测试关注点 |
|---|---|---|
| 现场设备层 | 传感器、执行器、变频器、伺服、仪表 | 数据采集正确性、量程、精度 |
| 控制层 | PLC、DCS、运动控制器 | 控制逻辑、扫描周期、程序下载 |
| 监控层 | SCADA、HMI | 画面、趋势、报警、操作权限 |
| 管理层 | MES、ERP、报表 | 工单、产量、配方、追溯 |
| 通信层 | 网关、交换机、OPC 服务器 | 协议转换、断连重连、实时性 |

## 3. 工业通信协议测试要点

| 协议 | 特点 | 测试要点 |
|---|---|---|
| Modbus RTU/TCP | 简单通用、主从 | 功能码、寄存器寻址、超时、异常码 |
| OPC UA | 跨平台、加密、信息模型 | 节点浏览、订阅/发布、证书、会话管理 |
| Profibus/Profinet | 西门子生态 | 报文格式、诊断、PN 设备更换 |
| EtherNet/IP | CIP 协议 | 隐式/显式消息、连接管理 |
| MQTT | 云端轻量 | 发布订阅、QoS、遗嘱消息、断连重连 |
| IEC 61850 | 电力自动化 | GOOSE/SV 报文、实时性 |

**通信测试通用要点**：掉线/重连行为、超时阈值、数据刷新率、多客户端并发、错误报文处理、协议版本兼容。

## 4. 标准与规范体系（国标/行标/企标）

| 层级 | 示例 | 测试意义 |
|---|---|---|
| 国标 | GB/T 15969（PLC）、GB/T 2423（环境试验）、GB/T 17626（EMC，等同 IEC 61000-4）、GB/T 30976（工业控制系统信息安全） | 国内验收底线 |
| 行标 | 机械/电力/石化行业标准（JB/T、DL/T 等） | 行业统一要求 |
| 企标 | 设备厂商/集成商验收规范 | **通常严于国标，验收线** |
| 国际对应 | IEC 61508 / 62061、IEC 62443、IEC 61000-4 | 国标多等同采用 |

| 标准 | 内容 | 测试意义 |
|---|---|---|
| IEC 61508 / 62061 | 功能安全（SIL） | 安全回路、安全 PLC 验证 |
| IEC 62443 | 工业网络安全 | 安全等级 SL、访问控制、补丁 |
| GB/T 15969 | PLC 编程语言 | 梯形图/ST 逻辑行为 |
| GB/T 2423 | 环境试验方法 | 高低温/湿热/振动条件 |
| GB/T 17626 | EMC 试验（等同 IEC 61000-4） | ESD/浪涌/EFT 试验 |
| GB/T 30976 | 工控系统信息安全 | 安全等级测试 |
| GB/T 4728 / 6988 | 电气图形符号 | 图纸一致性 |
| ISO 9001 | 质量管理 | 测试流程合规 |
| 防爆/防护等级 | Ex、IP 防护 | 防爆认证、IP 等级验证 |

**处理原则**：企标 > 国标 > 行标；冲突取更严值；强制认证（防爆/CE）不可豁免。

## 6. 核心测试方法

- **控制逻辑测试**：用仿真 PLC/软 PLC 跑梯形图/ST，判定表覆盖组合条件，状态迁移覆盖设备状态机。
- **协议一致性**：对照协议规范逐条验证报文格式与行为。
- **故障注入**：断电、断线、寄存器写异常值、CPU 复位、冗余主备切换。
- **长时间可靠性**：7×24 运行监控内存、日志、响应衰减。
- **边界与等价类**：量程边界、报警阈值上下限、配方参数边界。

## 7. 典型风险点（探索性用例灵感）

1. **断电恢复**：运行中断电，恢复后状态保持与自动重启
2. **通信断线**：主站/从站断线后报警与重连行为
3. **冗余切换**：主备切换时机、切换期间数据连续性
4. **扫描周期**：程序膨胀后扫描周期超限、任务抖动
5. **报警风暴**：大量报警并发时的响应与排序
6. **寄存器异常值**：0xFFFF/-1/NaN 等异常值对逻辑的影响
7. **程序下载**：在线下载导致设备停机或丢步
8. **配方切换**：配方下发中断电/切换不完整
9. **看门狗**：逻辑死循环触发的复位与恢复
10. **时间同步**：NTP 跳变对历史数据与报警时间戳的影响

## 10. 协议报文级测试要点

### Modbus RTU/TCP
- 功能码验证：03 读保持寄存器、04 读输入、06 写单寄存器、16 写多寄存器
- 异常码验证：01 非法功能、02 非法数据地址、03 非法数据值、04 从站故障
- 地址边界：寄存器 0x0000 / 0xFFFF、越界地址
- 超时与重试：请求超时阈值、从站无响应重试次数

### OPC UA
- 会话/订阅管理：会话超时、订阅丢失、发布间隔
- 节点浏览：命名空间、节点类型、浏览深度
- 证书与安全策略：无/签名/加密策略验证
- 断线重连：服务器重启后客户端自动恢复订阅

## 11. 报警优先级与抑制规则

| 主题 | 要点 |
|---|---|
| 等级 | 紧急/高/中/低（如 A/B/C），按等级显示颜色与排序 |
| 抑制规则 | 设备停止时抑制运行类报警、级联报警只报根因 |
| 去抖 | 信号抖动时间窗内不重复触发 |
| 死区/回差 | 避免阈值附近频繁翻转 |
| 风暴控制 | 并发报警限流、按等级批量显示、可暂停声光 |

## 12. 工业网络安全（IEC 62443）测试要点

- 安全等级 SL1-SL4 对应测试深度（SL1 基本防护，SL4 高安全）
- 访问控制：账户策略、权限分级（操作员/工程师/管理员）、口令策略与锁定
- 通信安全：加密传输、证书校验、明文协议禁用（如 Modbus 裸 TCP 限内部网段）
- 端口与服务：最小化开放端口、未用服务禁用
- 补丁与审计：固件版本基线、安全日志记录与导出
