## Description: <br>
Registers external services with health checks, central config, and unified execution. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[athola](https://clawhub.ai/user/athola) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to define service registry patterns for coordinating multiple external services, including service configuration, health checks, execution results, retries, failover, and service selection. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill normalizes external service calls and local command execution without enough scoping or safety warnings. <br>
Mitigation: Review the skill before installation and only configure services and command templates that the user controls. <br>
Risk: Registered services may receive prompts, file paths, or file contents that include secrets or sensitive data. <br>
Mitigation: Avoid sending secrets or sensitive files through registered services and use API keys with minimal permissions. <br>
Risk: Local or third-party execution paths can run unexpected commands if templates are not constrained. <br>
Mitigation: Require explicit confirmation or allowlists before enabling any local command or third-party execution path. <br>
