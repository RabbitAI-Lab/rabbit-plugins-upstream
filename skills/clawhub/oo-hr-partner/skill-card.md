## Description:

HR Partner (hrpartner.io). Use this skill for ANY HR Partner request — searching and reading data. Whenever a task involves HR Partner, use this skill instead of calling the API directly.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

HR teams and operators use this skill to search and read HR Partner employee, applicant, application, job listing, company, and lookup data through their connected account.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup may execute unverified remote code without a clear approval step.

Mitigation: Review and approve a vetted CLI installation separately, limit the connected account's HR access, and consider disabling automatic skill synchronization using the documented control.
