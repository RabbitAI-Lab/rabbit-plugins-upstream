## Description:

Guides agents in planning and editing HyperFrames Studio films with readable timelines, consistent scene structure, and safe content placement.

This skill is ready for commercial/non-commercial use.

## Publisher:

[heygen-com](https://clawhub.ai/user/heygen-com)

### License/Terms of Use:

## Use Case:

Creators and developers use this skill to plan and build HyperFrames Studio films while keeping project changes aligned with user intent and timeline conventions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Unrequested changes to project files or locked storyboard frames.

Mitigation: Confirm the requested change before editing, keep no-change requests read-only, and preserve locked frames.

Risk: Companion skills may be absent or differ from the workflow this skill expects.

Mitigation: Review the referenced HyperFrames companion skills before use and run HyperFrames checks after edits.
