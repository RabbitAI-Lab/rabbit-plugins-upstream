## Description:

Turn a user-supplied wrong-item script and authorized stills into one wrong item talking clip per still.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

External educators and agents use this skill to plan and produce short talking clips from teacher-supplied wrong-item scripts and authorized still images. It guides consent checks, slot planning, Beatra speech/video calls, billing confirmation, task polling, and delivery of one clip per still.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The package uses shared full-scope Beatra device authorization.

Mitigation: Review the Beatra authorization page before approving, restrict installation to users who accept that access, and disconnect with the bundled uninstall guidance when access is no longer needed.

Risk: Silent automatic updates are enabled by default.

Mitigation: Disable automatic updates in managed environments with `python3 scripts/mcp_client.py update --auto off` and run explicit update checks when change control is required.

Risk: Installation metadata is sent to Beatra.

Mitigation: Install only where sharing package, version, platform, and stable installation-reference metadata with Beatra is acceptable.

Risk: Billable clone, speech, and video operations can consume Beatra credits.

Mitigation: Use the skill's separate confirmation cards, current model pricing checks, opaque request IDs, and task polling before submitting or recovering paid work.
