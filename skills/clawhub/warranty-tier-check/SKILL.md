# 质保档位速判

## 这是什么

输送带投标，保固期写错一档，轻则客户废标、重则中标后兑现不了赔到肉疼。

这个技能是你的**保固档位初判器**：你把工况说清楚，它按四档框架给你一个**有依据的初判结论**——判哪一档、为什么、哪些点还需要人工确认，再送你一段可以直接粘进标书的保固条款话术模板。

它做的是「初判」：给方向、给依据、给话术；最终写进合同的那一行，必须过人工确认——这也是它给你「需人工确认项」清单的原因。

## 四档框架

| 档位 | 适用语义 | 典型场景（行业通用参考） |
|---|---|---|
| **通用档** | 常规工况的通用保固承诺 | 常温、无特殊耐热/耐磨/防燃要求的普通物料输送 |
| **T1** | 基础加强档 | 轻度特殊工况：轻度高温、轻度磨损或轻度腐蚀，单要素超标 |
| **T3** | 中档专项 | 中等特殊工况：中高温物料或明显磨蚀环境，多要素叠加 |
| **T4** | 高温专项档 | 高温工况：烧结矿、水泥熟料、焦炭等高温物料连续输送 |

## 怎么用（一句话就够）

把**工况三要素**报给本技能即可：

1. **物料温度**：输送物料的正常温度和峰值温度（例：正常 80℃，峰值 120℃）
2. **物料类型**：输送什么（例：烧结矿 / 水泥熟料 / 石灰石 / 粮食）
3. **环境条件**：露天/室内、湿度、粉尘、腐蚀性、倾角、带速等

**示例：**

> 「烧结矿输送，物料温度 150℃，露天多尘，帮我判一下保固档位」

你会得到三段式结论：

- **档位初判**：建议报 T4（示例）
- **判定依据**：物料温度超高温线 + 高温物料类型 + 环境叠加因素，逐条列给你看
- **需人工确认项**：比如「峰值温度持续时间」「客户合同对保固期的明确要求」「上一单同类项目实报档位」

外加一段**保固条款话术模板**，可直接改数字粘进标书。

## 工作规矩

1. **三要素不齐先追问**：温度、物料、环境缺一项，先问清再判，不猜着判
2. **结论带依据**：每一条判定理由都写明对应哪个要素，不让用户"信我就行"
3. **初判不是承诺**：输出档位一律标注「初判」，附人工确认项；最终档位以企业内部规则表和合同为准
4. **话术可粘可用**：给的话术模板留出待填位（保固月数、适用范围），不替用户拍死数字
5. **不代做商务决策**：报哪一档影响成本与竞争力，本技能给依据，决策权在你

## 四条边界

1. **不替代合同评审**：只判档位方向，不审合同全文、不算违约成本
2. **不臆造内部规则**：四档框架与行业通用参考公开可查，企业内部温度阈值等细节以你方规则表为准
3. **不碰价格**：不同档位的报价影响由你自己测算，本技能不涉价格
4. **不存敏感数据**：你报的工况信息只用于当次判定，不落盘、不回传

## 与家族产品的关系

- **标书漏填速查**（免费技能）：管"标书写没写漏"；本技能管"保固档位写哪档"。建议两个都装，出标前各跑一遍。
- **标书参谋**（订阅专家）：整套投标判断力——保固判定、避坑清单、台账方法、模板规范全都有，还每月更新避坑清单。本技能是它的单点试吃版。
