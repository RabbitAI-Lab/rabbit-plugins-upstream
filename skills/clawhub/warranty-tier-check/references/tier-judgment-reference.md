# 四档保固期判定参考（v1.0）

> 术语对照：本技能对外用「质保」，行业内也常说「保固」；「质保档位速判」技能名里的「质保」与知识库里的「保固」是同一个概念的两套叫法，判定逻辑完全一致。

## 一、判定三要素

档位判定只看三个要素，缺一不可：

| 要素 | 要问清什么 | 为什么关键 |
|---|---|---|
| 物料温度 | 正常温度 + 峰值温度 + 峰值持续时间 | 温度是耐热档位的第一判据，峰值温度决定上限 |
| 物料类型 | 输送什么物料 | 烧结矿/熟料/焦炭=高温类；矿石=磨损类；粮食/化肥=常规类 |
| 环境条件 | 露天/室内、湿度、粉尘、腐蚀、倾角 | 环境是叠加因素，能把档位往上推一档 |

## 二、四档判定框架

### 通用档
- 工况：常温（物料温度接近环境温度）、常规物料（粮食、砂石、一般散料）
- 判定口令：**三要素全常规 → 通用档**
- 话术基调：标准质量保证条款，保固期按合同通用约定

### T1（基础加强档）
- 工况：**单要素超标**——轻度高温（物料微热）、轻度磨损（含棱角散料）或轻度腐蚀（化肥等），只超一项且不严重
- 判定口令：**只超一项、程度轻 → T1**
- 话术基调：在通用条款上加一句针对性加强承诺

### T3（中档专项）
- 工况：**中等特殊工况**——中高温物料、明显磨蚀环境，或两个要素同时偏高
- 判定口令：**程度中等，或两要素同时偏高 → T3**
- 话术基调：专项耐热/耐磨条款，写明适用工况范围

### T4（高温专项档）
- 工况：**高温工况**——烧结矿、水泥熟料、焦炭等高温物料连续输送，或峰值温度明显超出普通耐热范围
- 判定口令：**高温类物料连续输送，或峰值温度高 → T4**
- 话术基调：高温专项保固条款，明确限定物料温度范围，防止超范围使用

## 三、行业通用参考区间（初判用，非承诺）

| 档位 | 物料温度参考带 | 备注 |
|---|---|---|
| 通用档 | ≈ 环境温度 | 温度要素可忽略 |
| T1 | 微热（手感热但物料未明显升温） | 单要素超标 |
| T3 | 中温区（明显升温但未达高温物料级） | 常见：中温熟料、温矿 |
| T4 | 高温区（烧结/熟料/焦炭级） | 必须写明温度限定 |

> ⚠️ 具体温度阈值以企业内部规则表为准（订阅版随 v1.1 灌装）。本表只是公开的行业常识带，用于初判方向。

## 四、三段式输出格式（判定时照这个给）

```
【档位初判】建议报：X 档
【判定依据】
  1. 物料温度：…… → 对应……
  2. 物料类型：…… → 对应……
  3. 环境条件：…… → 对应……
【需人工确认项】
  □ 客户标书对保固期的明确要求（几 months/years）
  □ 峰值温度与持续时间（决定是否升档）
  □ 上一单同类项目实报档位（对齐口径）
【话术模板】
  本项目输送带产品自验收合格之日起质保 XX 个月，
  适用工况为：物料温度不超过 XX℃ 的 XX 类物料输送……
```

## 五、常见错配（判定时主动提醒）

1. **客户要 24 个月但工况是 T4** → 主动提醒：高温档兑现 24 个月成本高风险大，给出谈判话术（缩工况范围/分档保固）
2. **只看峰值温度漏了持续时间** → 提醒补问
3. **露天高湿环境按通用档报** → 提醒环境叠加可能升档
4. **照抄上一单档位不看本次工况** → 强调每单都要过一遍三要素
