## Description: <br>
Generates a structured acceptance report from test cases, functional acceptance results, performance metrics, security findings, and architecture context, including final pass, conditional pass, or fail conclusions. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[golngod](https://clawhub.ai/user/golngod) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
QA engineers, delivery teams, and project owners use this skill to turn acceptance testing, performance, and security evaluation results into a seven-section report for sign-off decisions. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated acceptance conclusions can be misleading if the supplied test results, defect lists, performance metrics, or security findings are incomplete or inconsistent. <br>
Mitigation: Validate the source data and review calculated summaries, defect severity, security conclusions, and final acceptance status before using the report for sign-off. <br>
Risk: Inputs may include architecture context, project test results, defect details, performance metrics, and security findings. <br>
Mitigation: Provide only information approved for the agent environment and avoid unnecessary confidential or sensitive details. <br>
