## Use Case:

Developers and engineers use this skill to call MiMo models through RunAPI for text generation, verified synchronous image requests, streaming, or compatibility clients that require Responses or Anthropic Messages protocols.

## Known Risks and Mitigations:

Mitigation: Confirm the integration should use RunAPI for MiMo and provide only the RunAPI API key in the documented environment variable.
