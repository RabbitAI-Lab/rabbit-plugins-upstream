# 色板预设与自定义推导(theme-presets)

> 预设 = **完整可替换 theme.css 的文件**,存于 `assets/presets/`,变量名与默认 theme.css 完全一致。
> 用户选定后:复制对应预设 → 覆盖项目 `assets/theme.css`。技能目录内的默认 theme.css 永不动。
> 所有模板/片段/配方均通过 `var()` 引用,换色板零改动。
> **品牌风格预设(Linear/Apple/Notion 等 11 个)见 `brand-styles.md`**;本文只列 5 套通用预设。

## 一、预设速查

| 预设(文件) | 风格关键词 | 适用主题 | 主色 | 深底 | 强调 |

| 联想红深蓝 `lenovo-default.css` | 品牌感、力量、制造/科技 | 默认通用 | #E2232A | #0A2E5C | #F39800 |
| 商务蓝 `business-blue.css` | 稳健、专业、金融/咨询 | 汇报路演、述职立项 | #2563EB | #0B2447 | #F59E0B |

## 三、自定义主色推导(用户给 1 个 hex 时)

输入 hex → 转 HSL(h,s,l),按下列规则推导全套色板:

1. **主色** = 输入原样;**主色深** = 同 h,s,明度 −12%(下限 8%)
2. **深底** = 同 h,饱和度压到原值的 55%(钳制 25%-60%),明度 12%-16%;**深底浅** = 深底明度 +12%
   - 输入接近无彩色(s<10%)→ 深底退化为中性炭黑系(#121212/#2A2A2A)
3. **强调色** = 互补色(h+180°),饱和度 ≥60%,明度 45%-55%;输入无彩色 → 默认 #F39800
4. **文字色阶** = 带微弱主色调的中性灰:primary (h,15%,15%)、secondary (h,8%,40%)、tertiary (h,6%,60%)
5. **承载色**:off-white (h,25%,97%)、border-light (h,12%,90%)、border-medium (h,10%,84%)
6. **深底文字混合色**(预算混合,与 theme.css 既有惯例一致):on-navy-sub ≈ 白 85% 混深底、on-navy-dim ≈ 白 70% 混深底(逐通道加权平均)

### 护栏(必须执行,并在确认卡中报告调整)

- 主色过浅(l>70%)→ 自动压暗至 l≤60% 并告知
- 深底明度必须 ≤20%;深底与 on-navy-text(白)对比度 ≥7:1
- 主色在白底上对比度 ≥3:1(大字号装饰用途);不达标自动微调并标注"已调整"
- 推导完成后**先给用户看色板预览(各色值+一句话用途)二次确认,再写文件**——自定义是唯一需要二次确认的分支

## 四、防漂移护栏

新增/修改变量时,必须 5 套同步(包括 lenovo-default.css)。
