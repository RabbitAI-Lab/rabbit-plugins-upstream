# 引导式访谈指南(interview-guide)

> 制作任何 deck 之前,按本指南完成访谈。**目标:用最少的轮次,把"内容、样式、形式、结构"确认到不需要返工的程度。**
> 总控:**5 阶段 16 问 + 1 个大纲确认环节(Q5)**,收尾另有确认卡环节。配套文档:
> 骨架 `narrative-skeletons.md`、色板 `theme-presets.md`、密度 `density-tiers.md`、
> 设计总纲 `design-principles.md`、原型库 `page-archetypes.md`、内容深化 `content-deepening.md`。

## 提问方式规则

1. 每阶段一轮交互:先一句纯文本说明本阶段目的,再用 **AskUserQuestion** 批量抛出该阶段 1-3 个封闭式问题(视觉阶段至多两轮)
2. AskUserQuestion 使用约束:每次调用 ≤4 问、每问选项 ≤4、**推荐项置首**;开放题(主题、自定义 hex、大纲修改意见)用纯文本,不用 AskUserQuestion
3. 每个推荐项的确定依据(关键词推断规则)写在本文各阶段表格里——**推断出的推荐项要说明理由**("ESG 主题,推荐墨绿可持续")
4. 选项无法满足时用户可选"其他"自由输入,正常采纳

**多轴冲突的消解规则**(命中多行或轴间张力时):

1. **Q3b 看赌注,Q8c 看受众正式度** —— 两轴独立,不互推。"董事会融资路演"= 深度打磨(赌注高)+ 克制(受众正式),不矛盾。
2. **Q6c 图片政策 与 Q8c 形式**:Q6c=①纯文字图表 且 Q8c=③丰富 → 合法,但图示只能来自形状/图标/图表(不用照片);抛 Q8c 时说明这一点。
3. **Q2 阅读档 与 Q8c 丰富型**:阅读档单页信息量大,图示会挤压文字 → 阅读档下 Q8c 丰富型**不置首**(降为平衡),用户仍可选。
4. **Q9 零装饰 与 结构色面下限**:零装饰**不豁免**色带/深色面板/表头底纹(它们是结构不是装饰)——抛 Q9② 时必须说这句。
5. **品牌风 与 Q6b/Q7**:Q6 选品牌风 → Q6b 跳过(档案自带风格);选深态品牌(Linear/Spotify/Ferrari/NVIDIA)→ Q7③ 置首。

## 智能跳过规则(硬规则)

1. **已答即跳**:用户已显式给出的答案直接采用,不重复问;下一阶段开场白复述"已记录:主题=X、受众=Y"
2. **强推断即跳**:强信号可推断的(如"20 页培训 PPT"含骨架+页数)不问,但确认卡中标注"(推断)",给用户否决机会
3. **快速通道**:用户任何时刻说"都按默认/你看着办/快点" → **跳到最少交互底线**(不是跳过全部):
   未答项按推断总表取值、内容深化层降为快速档(全跳),**但仍走 Q6 色板 + Q5 大纲确认这两问**,再出确认卡。
   > **口径归一(2026-08-06 第六轮 P3)**:此前三处三说——本文规则 3 写"跳过剩余全部问题…直接出确认卡"、
   > 规则 4 写"保留 Q6 与 Q5"、content-deepening 收尾写"全部跳过…直接进 Q5"(保 Q5 不保 Q6)。
   > 规则 3 与 4 **字面直接冲突**。现统一为本条:快速通道 = 跳到底线,不是跳过底线。
   > 理由:色板与大纲是**返工最贵**的两个决定(改色板=重写 theme + 全页复检;改结构=重写全部页面),
   > 而这两问各只需一次交互。跳过它们省 2 次交互,可能换来整份 deck 重做。
4. **最少交互底线**(任何路径都不可跳):**Q6 色板** 与 **Q5 大纲确认**。即使信息极全、即使走快速通道。
5. **顺序可调**:某问的回答顺带覆盖了后续问题 → 标记已答,后续跳过(见下方依赖图,别凭感觉判断)

## 三条路径与依赖图(2026-08-06 第六轮 P3)

> 此前访谈是**线性 17 问脚本**,"顺序可调"只给了一个例子,真实依赖散在各问的括号补丁里
> ("2026-08-05 修复死路""2026-08-03 修复")——每条依赖都是事后打补丁,不是结构。现在显式建表。

**路径选择**(开场即定,可中途升降档):

| 路径 | 触发 | 问哪些 | 交互轮次 |

| **深度** | Q3b=深度打磨(推断总表标粗的族),或用户要求"帮我深挖" | 标准 + 内容深化层(见 content-deepening.md) | 5-7 + 深化 |

**依赖图**(左侧答案成立 → 右侧动作;主循环按此跳过,不再逐问自行判断):

|---|---|---|
| Q6 = 品牌风 | **关闭 Q6b** | 品牌档案自带风格个性 |

**重入与版本**(此前未定义):brief 落盘后的修改分两类——
**① 样式类**("换商务蓝""字再大点"):改 brief 对应行 + 重跑受影响页,**不重访谈、不重深化**,`访谈轮次` 不变。
**② 结构类**("加两页竞品对比""换个叙事顺序"):改大纲表 + `访谈轮次` +1,深度档需重跑委员会的**受影响页**(不必全跑);
重新走 Q5 确认。判据:**动了大纲表的行数或页序 = 结构类**。
