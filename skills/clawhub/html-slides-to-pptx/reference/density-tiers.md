# 信息密度三档(density-tiers)

> 使用场景决定信息密度。访谈 Q2 选定档位后,**把本表对应列的参数整段拷入 deck-brief.md 的
> "版式与密度参数"小节**——此后写每页只对照 brief,不再回查本表。
> 字号阶已于 2026-08-02 重校准(1px=0.5pt;旧阶正文 18-20px=9-10pt 为 PPT 脚注级,已上调);
> 原则与推导见 `design-principles.md`,两表数值必须一致。

## 档位参数表

| 参数 | 演讲形式(默认) | 混合形式 | 阅读形式 |
|---|---|---|---|
| 页头主标题 | 56-64px | 52-60px | 44-52px |
| 封面主标 | 88-120px | 80-104px | 64-88px |
| 区块/卡片标题 | 32-38px | 28-34px | 24-30px |
| 正文字号 | **24-28px** | 20-24px | 17-20px |
| 注释/来源 | ≥16px | ≥15px | ≥14px |
| **字号绝对下限**(全角色,含页码页脚) | 14px | 14px | 14px |
| **正文破档下限** | 22px | 18px | 16px |
| 每页要点/条目上限 | ≤5 | ≤6 | ≤8 |
| 每要点字数 | ≤16 字(短语) | ≤24 字(短句) | ≤36 字(可成句) |
| 单页正文总行数上限 | ≤12 行 | ≤18 行 | ≤28 行 |
| 每页信息块(卡片/格子)上限 | ≤4 | ≤5 | ≤6 |
| 单页表格行数上限(含表头) | ≤6 行 | ≤8 行 | ≤12 行 |
| 单页图表系列数上限 | ≤3 系列 | ≤4 系列 | ≤6 系列 |
| **版面填充下限**(2026-08-02 新增) | 内容区利用率 ≥85%(airy 页豁免) | 同左 | 同左 |
| **Scale-to-fill 触发线**(2026-08-02 新增) | 内容 <60% 上限 → 字号取 26-28px、行距 1.6-1.8 | 同左,取 22-24px | 同左,取 19-20px |
| 备注策略 | **每页详尽**:时间分配+串场词+核心逻辑(沿用【开场·30秒】风格) | **关键页写**:章节首页+数据页+结论页,其余不写 | **不写**(正文自解释),仅标注数据来源 |
| 版式倾向 | 大字大留白、裸排要点、 airy 页呼吸 | 折中 | 双栏密排、编辑文字页为主 |

> ⚠️ **"破档下限"不是默认值**(2026-08-06 第四轮实测教训):
> 演讲档正文的默认取值区是**上一行的 24-28px**,22px 是**红线**。
> 实测 96-107 段样张正文中位数几乎全部恰好落在 22px —— 红线被当成了默认值,
> 页面因此又小又平。写页时:没有特殊理由取 24-28px;内容 <60% 时按 scale-to-fill 取上限。
> 同理,注释下限 16px 也不是"注释都写 16px"的意思。

## 执行规则

1. 参数拷入 brief 即为该 deck 的**硬约束**;写每页时对照自检(要点数/行数/字号/填充率/表格行数/图表系列数)。
2. 同内容下,阅读形式总页数可比演讲形式少约 1/3;访谈 Q3 页数推荐按档位换算并提示用户。
3. 任何一页超标时:**演讲/混合档优先拆页,阅读档优先精简措辞**——不允许缩字号破档。
4. 备注与档位绑定是默认策略;用户在访谈中显式另选(如阅读形式也要备注)时,以用户为准并在 brief 标注。
5. **表格/图表密度**:表格行数含表头计数;超限时演讲/混合档**拆页**或转可展开附件页,阅读档可换紧凑行距(仍受"单页正文总行数上限"约束);图表系列数超限时拆为多图(每图 ≤ 上限),不要用堆叠/双轴硬塞——可读性优先于信息量。
6. **少而满规则(2026-08-02 新增)**:本页内容量 <60% 档内上限时,**必须**按 scale-to-fill 上调字号/行距/间距把内容带撑满(内容区 320-940,利用率 ≥85%);**禁止**"内容少+下限字号+底部留白"。这是底部留白问题的一号解药。
7. **字数与字号联动(2026-08-02 新增)**:字号取档内上限时,每要点字数同步收紧(演讲 ≤16 字)——大字必须少字;需要长句就降字号档或拆页。
