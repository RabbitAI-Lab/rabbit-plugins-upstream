# 信息密度三档(density-tiers)

> 使用场景决定信息密度。访谈 Q2 选定档位后,**把本表对应列的参数整段拷入 deck-brief.md 的
> "版式与密度参数"小节**——此后写每页只对照 brief,不再回查本表。

## 档位参数表

| 参数 | 演讲形式(默认) | 混合形式 | 阅读形式 |
|---|---|---|---|
| 页头主标题 | 52-56px | 48-52px | 40-48px |
| 封面主标 | 88-130px | 80-110px | 64-88px |
| 卡片/区块标题 | 26-30px | 24-28px | 22-26px |
| 正文字号 | 18-20px | 16-18px | 14-16px |
| 每页要点/条目上限 | ≤5 | ≤6 | ≤8 |
| 每要点字数 | ≤20 字(短语) | ≤30 字(短句) | ≤40 字(可成句) |
| 单页正文总行数上限 | ≤15 行 | ≤20 行 | ≤30 行 |
| 每页信息块(卡片/格子)上限 | ≤4 | ≤5 | ≤6 |
| **单页表格行数上限**(2026-07-27 D5) | ≤6 行(含表头) | ≤8 行(含表头) | ≤12 行(含表头) |
| **单页图表系列数上限**(2026-07-27 D5) | ≤3 系列 | ≤4 系列 | ≤6 系列 |
| 备注策略 | **每页详尽**:时间分配+串场词+核心逻辑(沿用【开场·30秒】风格) | **关键页写**:章节首页+数据页+结论页,其余不写 | **不写**(正文自解释),仅标注数据来源 |
| 版式倾向 | 卡片大留白、统计带大字 | 折中 | 允许双栏密排、条目堆叠为主 |

## 执行规则

1. 参数拷入 brief 即为该 deck 的**硬约束**;写每页时对照自检(要点数/行数/字号/表格行数/图表系列数)。
2. 同内容下,阅读形式总页数可比演讲形式少约 1/3;访谈 Q3 页数推荐按档位换算并提示用户。
3. 任何一页超标时:**演讲/混合档优先拆页,阅读档优先精简措辞**——不允许缩字号破档。
4. 备注与档位绑定是默认策略;用户在访谈中显式另选(如阅读形式也要备注)时,以用户为准并在 brief 标注。
5. **表格/图表密度(2026-07-27 D5)**:表格行数含表头计数;超限时演讲/混合档**拆页**或转可展开附件页,阅读档可换紧凑行距(仍受"单页正文总行数上限"约束);图表系列数超限时拆为多图(每图 ≤ 上限),不要用堆叠/双轴硬塞——可读性优先于信息量。

## 推荐逻辑(访谈 Q2 如何置推荐项)

- 主题/用途含"汇报、路演、宣讲、培训、讲课、发布会" → **演讲形式**置首
- 含"文档、材料、阅读版、发出去看、白皮书" → **阅读形式**置首
- 无法判断 → **演讲形式**置首(PPT 默认形态)
