# 叙事骨架(narrative-skeletons)

> 骨架 = **脚手架,不是模具**。它只回答"先讲什么后讲什么、每页承担什么职能",
> 不约束版式细节;每页怎么排仍由内容与 html-spec 的全空间决定。

## 防僵化设计(使用骨架时必须遵守)

1. **弱绑定**:下表"推荐布局/配方"列是**默认建议而非约束**——某页该用分栏还是三卡,由内容决定(访谈 Q8 默认"自动")。
2. **大纲确认闸**:骨架生成的大纲必须逐页给用户确认(访谈 Q5),可增删/换序/合并/推翻;**deck-brief 以用户确认版为准,骨架从此不再被回查**。
3. **自由结构选项**:用户可随时选"不用骨架/我自己给大纲"——骨架是加速器,不是必经之路。
4. **何时打破骨架**:内容天然是时间线/对比/清单时,别硬套问题-方案型;页数缩放时按下表"压缩点/扩展点"调整。

validate/convert/提取器**不知道骨架的存在**——它不参与任何校验,版式层灵活性零损失。

## 骨架选择推断(访谈 Q4 如何置推荐项)

| 主题关键词 | 推荐骨架 |
|---|---|
| 培训/工作坊/教学/练习/训练营 | 骨架 1 · 培训工作坊型 |
| 汇报/路演/融资/述职/立项/评审 | 骨架 2 · 汇报路演型 |
| 提案/方案/解决/痛点/优化 | 骨架 3 · 问题-方案-收益型 |
| 发布/新品/上线/产品介绍 | 骨架 4 · 产品发布型 |
| 无法推断 | 骨架 3(最通用)置首 |

## 骨架 1 · 培训工作坊型(12 页基准)

| 页 | 类型 | 内容职能 | 推荐布局 | 配方/片段 |
|---|---|---|---|---|
| 01 | 封面 | 主题+一句话承诺+版本徽章 | A 深底+渐变条 | gradient-bar |
| 02 | 目标+议程 | 学习目标 + 全天模块地图 | C stack 条目 | 配方4 |

| 04 | 概念讲解 ① | 第一个核心概念 | C 三卡片 | 配方1 |

| 06 | 演示/案例 | 完整走一遍流程或真实案例 | A 大截图位+标注 | — |
| 07 | 动手练习 | 练习任务书(材料/步骤/产出) | C stack 步骤 | 配方4 |
| 08 | 练习复盘 | 常见结果点评、好/差对照 | B 卡片对照 | — |
| 09 | 常见坑 FAQ | 3-5 个高频问题与解答 | C stack 条目 | 配方4 |
| 10 | 行动清单 | 带回去的模板/清单/下一步 | grid 格子 | 配方3 |
| 11 | 总结 | 三点带走(与学习目标呼应) | C 三卡片 | 配方1 |

密度变体:演讲档 — 07 练习页备注含计时与巡场提示;阅读档 — 09 FAQ 扩为 6-8 条,删 06 截图页改为文字流程。
