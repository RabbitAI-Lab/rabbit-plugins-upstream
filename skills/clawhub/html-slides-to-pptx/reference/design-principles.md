# 设计总纲(design-principles)

> **写每一页之前必读。** 本文件定义六件事:版面分区、字号阶、scale-to-fill、去 AI 味反模式、视觉形式、节奏规则。
> 与 `html-spec.md` 的分工:html-spec 是**转换契约**(写了能不能无损转 PPTX);本文件是**设计契约**(写出来像不像专业人类做的)。
> 与 `density-tiers.md` 的分工:本文件是原则与推导;density-tiers 是访谈 Q2 选定档位后的**速查参数表**(拷入 brief 即硬约束)。两表数值必须一致。
> 默认优先级:deck-brief > 本文件。brief 里用户显式拍板的,以 brief 为准。

## 一、版面分区系统(1920×1080)

```
┌────────────────────────────────────────────┐
│ 页眉区  y:60–280   kicker/页标题/页码        │
├────────────────────────────────────────────┤
│                                            │
│ 内容区  y:320–940  主体内容(高 620px)       │
│                                            │
├────────────────────────────────────────────┤
│ 页脚区  y:980–1040 页脚/页码(二选一)        │
└────────────────────────────────────────────┘
  左右边距 100px → 内容宽 1720px
```

**满填规则(硬约束,airy 原型除外)**:
1. 内容带顶 ≤ 360px、内容带底 ≥ 880px —— 内容区**垂直利用率 ≥85%**
2. 内容少则**放大字号/行距/间距**把内容带撑满,绝不允许"小字堆在上半截、底部空 300px"
3. 各内容块在内容区内**均匀分布**(顶对齐标题区、底对齐页脚区),不是全部挤向顶部

**airy 原型(豁免满填规则,留白是其设计语言)**:封面 / 章节分隔 / 大字观点 / 引用 / 行动号召收尾。
airy 页也要**垂直居中平衡**,不是"内容偏上、底部空白"。

**出血规则**:仅 airy 原型与全出血大图页允许元素贴边/出血;内容页严守 100px 边距。

## 二、字号阶(2026-08-02 重校准 · D-A 稳健档)

换算:1px = 0.5pt。旧阶(正文 18-20px = 9-10pt)是 PPT 脚注级别,已全部上调。

| 角色 | 演讲形式 | 混合形式 | 阅读形式 |
|---|---|---|---|
| 封面主标 | 88-120px (44-60pt) | 80-104px | 64-88px |
| 页标题 | 56-64px (28-32pt) | 52-60px | 44-52px |
| 区块/卡片标题 | 32-38px (16-19pt) | 28-34px | 24-30px |
| **正文** | **24-28px (12-14pt)** | 20-24px | 17-20px |
| 注释/来源 | ≥16px | ≥15px | ≥14px |
| 页码/页脚 | 14-16px | 14-16px | 14-16px |

**铁律**:
1. **绝对下限 14px** —— 任何文字(含来源标注)不得小于 14px
2. **正文档内下限**:演讲 22px / 混合 18px / 阅读 16px —— 低于即破档(缩字号破档,旧规不变)
3. **层级对比**:页标题 ≥ 1.8×正文;区块标题 ≥ 1.2×正文;封面主标 ≥ 3×正文
4. **行高**:标题 1.15-1.25;正文 1.5-1.7;scale-to-fill 时放宽到 1.6-1.8
5. 字重对比:标题 700-800、正文 400、强调 700 —— 靠字重+字号分层,不靠堆颜色

## 三、Scale-to-fill(字号与内容量联动)

> 人类设计师的本能:内容少 → 字放大、行距拉开、铺满画布。AI 的典型病:内容少 → 小字挤上半截。

| 本页内容量(相对档内上限) | 字号策略 | 行距/间距策略 |
|---|---|---|
| < 60% | 字号取档内**上限区** | 行距 1.6-1.8,条目间距加大(24→40px) |
| 60-80% | 档内中间值 | 行距 1.5-1.6,常规间距 |
| ≥ 80% | 档内**下限区**(不低于档内下限) | 行距 1.45-1.55,紧凑间距 |

**两个禁止**:
- ❌ 缩字号破档(旧规):内容超上限 → 拆页/精简,不许缩字
- ❌ 小字配少内容(新规):内容 < 60% 还用下限字号 → 等于制造底部留白,违反满填规则

**联动约束**:字号取上限时,每要点字数上限同步收紧(演讲档 ≤16 字/点,见 density-tiers)。大字就必须少字。

## 四、去 AI 味反模式清单(12 条)

> 每条 = 反模式 ✗ → 正例 ✓ + 豁免条件。这些模式是"主流 AI PPT"的视觉指纹,人类专业 deck 极少这样排。
>
> **结构形状豁免总则(2026-08-05 增补)**:本清单判负的是**装饰性堆砌**(kicker/渐变条/徽章/阴影三件套),不是**结构性形状**——承载信息组织的卡片/图标/流程/漏斗/循环/色带是合法页面形式(见第五章),**不计入装饰预算、不受卡片矩阵限额**。判定标准一句话:形状上有信息(文字/图标/数据)= 结构;只为好看 = 装饰。

**1. 三件套页头** — ✗ 每页都 kicker+大标题+副标题 → ✓ kicker/副标题仅章节首页与封面;内容页直接 action title(可两行)。豁免:阅读档可保留副标题。
**2. 万物皆卡片** — ✗ 所有要点装进等宽卡片 → ✓ 卡片仅用于**真并列实体**(产品/方案/角色/案例);要点、结论、步骤默认**裸排**(粗体引导词+分行)。豁免:用户 brief 指定卡片风。结构豁免(2026-08-05):图标要点网格(原型 23)等**图示卡片**是并列信息的合法承载,不受"默认裸排"约束;判负的是无图标、无差异、可合并为一段文字的纯文字卡片堆叠。
**3. 页底结论条** — ✗ 每页底部一条渐变/深色"总结条" → ✓ 仅章节收尾页可用。结论应该写在标题里(action title),不是钉在页底。
**4. 渐变装饰条** — ✗ 每页顶部/底部渐变条 → ✓ 仅封面/章节分隔/收尾页。内容页用 1-2px 细线或不用。
**5. 序号圆圈** — ✗ 每个列表项都套色圈数字 → ✓ 仅流程/步骤类页面;其余直接大数字裸排(40px+ 数字+标题)或不编号。结构豁免(2026-08-05):流程/步骤/编号图示页(原型 13/24)的序号与形状组合合法。
**6. 徽章/胶囊** — ✗ 到处贴 badge → ✓ 仅状态标注(新增/试点/Beta)与封面版本号。结构豁免(2026-08-05):图示中的语义标记(原型 29 的 VS 徽章、状态点、阶段标)合法。
**7. 等宽卡片矩阵** — ✗ 全页 3-4 张等宽卡当万能布局 → ✓ 每 deck ≤2 页卡片矩阵;同原型不连续(见节奏规则)。优先用不对称分栏、编辑式、裸列表替代。结构豁免(2026-08-05):**限额对象收窄为纯文字卡片矩阵**;图标要点网格(原型 23)不计入 ≤2 页限额(仍受"同原型不连续 >2 页"约束)。
**8. 装饰超编** — ✗ 一页集齐 kicker+装饰线+徽章+渐变条+页脚 → ✓ **每页装饰元素 ≤2 件**(装饰线/徽章/渐变条/图形点缀各计 1 件)。口径(2026-08-05):装饰预算仅计**装饰件**;结构形状(卡片/图标/流程/漏斗/图表/表格)不计件。
**9. 高亮通胀** — ✗ 每页多处彩色强调词 → ✓ **每页高亮 ≤1 处**;其余靠字重分层。
**10. 居中崇拜** — ✗ 标题正文全居中 → ✓ 默认**左对齐**编辑网格;居中仅封面/收尾/大字观点页。
**11. 恒等分栏** — ✗ 永远 1:1 或 1:1:1 → ✓ 优先不对称(7:5、3:2、2:1),主辅分明。
**12. 四角齐全** — ✗ 每页页码+页脚+logo+章节名全上 → ✓ 页脚与页码**二选一**;章节名靠 kicker 或分隔页,不双管齐下。

> 判断口诀:**"人类会这样排吗?"** —— 拿不准时,想麦肯锡/苹果发布会/好杂志的内页:它们克制、左对齐、标题即结论、装饰极少。

**克制 ≠ 饥饿 ≠ 单调**(2026-08-02 增补内容自检;2026-08-05 增补形式自检):
> 去 AI 味反模式砍掉的是**装饰**(kicker/渐变条/徽章/点缀),不是**内容**,也不是**结构形状**。每页写完做两组自检:
>
> 内容单薄自检:
> ① 这页除了标题还有几个信息点?<3 个 → 加例子/数据/对照(内容性丰富,非装饰性堆砌)
> ② 有没有"例子(个人)/例子(团队)"这类可抄模板?没有 → 补
> ③ 空页面/半空页面是失误,不是风格——airy 只豁免封面/分隔/大字/引用/收尾
>
> 形式单调自检(2026-08-05):
> ④ 这页除了文字还有什么视觉元素?答案为"只有细线" → 这是纯文字页,对照形式偏好档(第五章)检查全 deck 占比
> ⑤ 这页的形式与前后页重复吗?同形式连排 >3 页 = 单调——**换形式,不换内容**
>
> 专业 deck 的"素"来自视觉克制,来自**信息密度 + 留白 + 形式变化**的平衡;单调与堆砌同为失误——**克制管装饰,不管形式**。

## 五、视觉形式(Visual Form)—— 治"单调"的一等公民

> 2026-08-05 第三轮重构新增。反模式清单管"装饰别滥用",本章管"形式要丰富"——两者同遵一句话:**装饰克制,结构形状大胆**。

### 形式五类(按页面主导视觉元素分)

| 形式 | 定义 | 归属原型 |
|---|---|---|
| 文字型 | 纯文字+细线,无其他视觉元素 | 2/3/5/6/7/8/12/17/21/22 |
| 图示型 | 形状/图标承载信息:图标网格/chevron 流程/漏斗/金字塔/循环/辐射/对比卡/色带 | 13(chevron 款)/14/15/16 + 23-30 |
| 图表型 | data-chart 图表 / `<table>` 表格为主角 | 18/19/20 |
| 图片型 | 照片/截图/全出血大图 | 10/11 |
| 混合型 | 两种主角组拼(一页仍只有一个"主主角") | 9 |

### 形式偏好三档(访谈 Q8c 选定,写入 brief 与 slides.config.json)

| 档 | 纯文字内容页占比上限 | 同形式连排上限 | 每内容页非文字视觉元素 |
|---|---|---|---|
| 文字克制型 text | 不限(2026-08-05 前的现行行为) | 不限 | 不强制 |
| **平衡型 balanced(默认推荐)** | **≤50%** | **≤3 页** | **≥1 个** |
| 图示丰富型 rich | ≤30% | ≤2 页 | ≥2 个 |

### 计数口径(validate 与人工自查同款)

- **计入**:形状(最小边 ≥8px;全画布底色块除外)、内联 SVG 图标、`data-chart` 图表、`<table>`、`<img>`
- **不计入**:1-2px 细分隔线/中缝、纯装饰点缀(仍受装饰预算 ≤2 件约束)、页眉/页脚/页码
- **纯文字页**:内容页中计入元素数 = 0 的页;**分母 = 内容页数**(封面/章节分隔/大字观点/引用/收尾等 airy 页不参与)

### 形式与内容的关系

- **先有信息结构,后选图示形式**:并列 → 图标网格/卡片;先后 → chevron/流程;递减 → 漏斗;分层 → 金字塔/层级;循环 → 循环图;辐射 → 中心辐射;对比 → 对比卡阵/双栏;分节论述 → 色带。为显得丰富而硬套图示,与为显得专业而硬凑 XY 轴,同属外行特征
- 图示页信息点仍守密度档上限(演讲档每页要点数与每点字数不变):**形状让信息更易读,不是让信息更少**
- 一页只用一种图示(一个主角);图示与图表/表格可组拼(如 23+18),但全页视觉元素总数不宜超过 12 个

## 六、节奏与变化规则(整 deck 层面)

1. **原型多样性**:每 deck ≥6 种页面原型(原型库见 `page-archetypes.md`);**形式分布**按第五章形式偏好档执行
2. **不连续**:同原型不连续超过 2 页;卡片矩阵全 deck ≤2 页
3. **呼吸感**:每 3-4 页满填内容页,插 1 页 airy 页(分隔/大字观点/引用)让读者喘气
4. **深浅交替**:深底页(封面/分隔/收尾)间隔分布,不连排也不缺席
5. **议程呼应**:议程页的章节结构 = 分隔页序列 = kicker 序列,三者一致

## 七、Action title(标题即结论)

- ✗ 空标题:"市场分析""产品介绍""关于 XX 的若干思考" —— 任何 deck 都能用的标题 = 废标题
- ✓ 结论标题:"企业 AI 落地的瓶颈不在模型,在数据管道" —— 只适用于本页内容
- 写法:主谓宾完整句,≤30 字,可两行(56-64px × 1.15-1.25 行高,两行正好撑满页眉区)
- 空标题只允许出现在:封面(品牌位)、分隔页(章节名)、附录
- 副标题(若用)= 给结论补一个证据/数字,不是换一种说法重复标题
