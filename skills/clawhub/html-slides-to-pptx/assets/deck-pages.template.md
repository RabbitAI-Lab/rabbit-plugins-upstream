## 填卡纪律

- **一页一卡,写页前填**。填不出 ② 的可验证事实 → 这页现在还不该写,回去补料或换页。
- ⑦ 超标当场拆页/精简,**不要写完再截图发现**(改一行 vs 改一屏)。
- ④ 的三问答"不答"是合法的,但要写清"留给第 N 页"或"本 deck 不覆盖";空着不算答。
- 本文件**不进 deck 正文**,也不需要用户确认(需求已在 Q5 冻结);它是执行草稿,可随页面迭代改。

| # | 要说的一句 | 挂的事实(数字+单位/专有名词/时间范围/具体例子) | 出处(六类之一) |
|---|---|---|---|

**出处六类**(必须落到其中一类,不许写"行业报告""业内数据"这种无主语的话):

| 类别 | 写法 | 强制配套 |
|---|---|---|
| 素材 §N | 用户给的全文稿/资料包的具体位置 | 无 |
| insights #N | `deck-insights.md` 洞察编号 | 无(该洞察自己已带依据强度) |
| 用户口述 | 访谈里用户亲口说的 | 无 |
| 公开可核验 | **机构 + 报告名 + 年份**三段齐全 | 缺任一段 → 降为「模型知识」 |
| **模型知识** | 生成模型的参数化知识与推理 | **必须带限定词 + 本页入 `hedgePages`**,或改标「待补」 |
| 待补 | 该条现在拿不出来 | 该条**不进页面**,进待补数据清单(见 ⑥) |

- **危险的不是用模型知识,是不标注的模型知识**:数字+单位的形态很容易看着像实测值。
  标了就落到既有的 hedgePages 机制上,成为可审计约束;不标就是"说得很像真的,一查全无出处"。
- 挂不上事实的条目:{删掉 或 降级为限定词句(见 ⑤)};**不留"跟不上事实"的句子**
