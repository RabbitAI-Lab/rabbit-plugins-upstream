## Description: <br>
Generates functional test cases from PRDs, Git commit history, or user stories and outputs an Excel test report. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[addxing](https://clawhub.ai/user/addxing) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and testers use this skill to turn product requirements, commit logs, or user stories into prioritized functional test cases and an Excel-style report for self-testing and review. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Input materials may contain confidential PRDs, user stories, or commit details. <br>
Mitigation: Only provide materials approved for this workflow and avoid sharing sensitive project details unless they are acceptable test-generation inputs. <br>
Risk: Generated test cases may miss important coverage or suggest priorities that do not match the product risk. <br>
Mitigation: Review and adjust the generated cases, priorities, and expected results before relying on the report. <br>
