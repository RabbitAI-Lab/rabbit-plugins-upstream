# 02 · 快速开始

## 1. 选择接入方式

| 场景 | 推荐 | 原因 |
|---|---|---|
| MCU + W5500/lwIP/4G 模组，能保持 TCP | **TCP 41032** | 协议最简单，有回执，可收下行指令 |
| 电池供电，周期唤醒 | **UDP 40501** | 一包完成唤醒+上报，不用维护长连接 |
| 已有 MQTT 栈 / 网关 | **MQTT 1883** | 发布订阅，适合多设备汇聚 |
| 需要 TLS | 网关/模组侧做 TLS | 平台南向端口当前是明文 |

## 2. PC 上跑通

### 2.1 Linux / macOS / WSL

```bash
cd aiot-c-sdk
cc -std=c89 -Wall -Wextra -Iinclude -Iport \
   examples/host_tcp_demo.c src/aiot.c src/aiot_json.c port/aiot_port_posix.c \
   -o host_tcp_demo
./host_tcp_demo ciot.yzlkj.com 41032 <设备ID> <设备密码> 30
```

### 2.2 Windows（MinGW）

```powershell
gcc -std=c89 -Iinclude -Iport `
    examples/host_tcp_demo.c src/aiot.c src/aiot_json.c port/aiot_port_posix.c `
    -lws2_32 -o host_tcp_demo.exe
.\host_tcp_demo.exe ciot.yzlkj.com 41032 <设备ID> <设备密码> 30
```

### 2.3 预期输出

```text
connecting ciot.yzlkj.com:41032 as AIOTSDK-0001 ...
[demo] connected, waiting for login...
[demo] login func=lgn code=0 result=...
[demo] report -> sent
[demo] result func=get_time code=0 fid=T1 result=2026-11-04 01:07:50
[demo] result func=facs code=0 fid=F1 result=(json)
```

在平台设备详情页下发 `set sw=1`，应看到 `ORDER` 和 `order_reply -> sent`。

> 设备必须已经在平台创建，并且 `protocol` 与连接方式一致（TCP 设备连 41032，UDP 设备连 40501，MQTT 设备连 1883）。

## 3. 最小 MCU 程序

> SDK 使用 C89 类型别名 `aiot_u8` / `aiot_u16` / `aiot_u32` / `aiot_i32`（定义在 `aiot_types.h`），不依赖 `<stdint.h>`。BSP 回调也建议使用这些类型。

```c
#include "aiot.h"

static aiot_client_t cli;
static aiot_u8 tx[2048];
static aiot_u8 rx[4096];

static int net_send(void *user, const aiot_u8 *data, size_t len)
{
    (void)user;
    return bsp_tcp_send(data, len) == (int)len ? 0 : -1;
}

static aiot_u32 now_ms(void *user)
{
    (void)user;
    return HAL_GetTick();
}

static void on_event(void *user, const aiot_event_t *ev)
{
    (void)user;
    switch (ev->type) {
    case AIOT_EV_LOGIN:
        if (ev->code == 0) {
            aiot_kv_t kv[] = {{"temp", "25.5"}, {"hum", "60"}};
            aiot_report(&cli, kv, 2, NULL);
        }
        break;
    case AIOT_EV_ORDER:
        if (strcmp(ev->cmd, "set") == 0) {
            aiot_kv_t kv = {"sw", "1"};
            aiot_order_reply(&cli, ev->tra, &kv, 1);
        }
        break;
    default:
        break;
    }
}

void app_init(void)
{
    aiot_config_t cfg = {0};
    cfg.device_id = "WANCD2-0000001008";
    cfg.password = "设备密码";
    cfg.mode = AIOT_MODE_TCP;
    cfg.send = net_send;
    cfg.now_ms = now_ms;
    cfg.on_event = on_event;

    aiot_init(&cli, &cfg, tx, sizeof tx, rx, sizeof rx);
}

/* 网络连接成功 */
void app_on_tcp_connected(void)
{
    aiot_client_connected(&cli);
}

/* 网络收到数据 */
void app_on_tcp_data(const aiot_u8 *data, size_t len)
{
    aiot_client_rx(&cli, data, len);
}

/* 主循环 */
void app_loop(void)
{
    aiot_client_poll(&cli, HAL_GetTick());
}
```

### 关键顺序

```text
TCP 连接成功
   → aiot_client_connected()   // SDK 发 lgn
   → 收到 lgn code=0          // AIOT_EV_LOGIN
   → 才能 aiot_report()       // 否则 AIOT_ERR_STATE
   → 主循环 aiot_client_poll() // 心跳/超时
断线
   → aiot_client_disconnected()
   → 重新连接后再次 aiot_client_connected()
```

## 4. 事件说明

| 事件 | 何时产生 | 典型处理 |
|---|---|---|
| `AIOT_EV_CONNECTED` | 调用 `aiot_client_connected()` 后 | 打印/置标志 |
| `AIOT_EV_LOGIN` | 收到 `lgn` 回执 | `code=0` 后开始上报；否则检查密码 |
| `AIOT_EV_RESULT` | 收到任意 `result` | 按 `ev->func`/`ev->fid` 处理；`ev->code` 为平台错误码 |
| `AIOT_EV_ORDER` | 收到下行 `order` | 执行 `ev->cmd`，用 `ev->tra` 回执 |
| `AIOT_EV_TIMEOUT` | 登录超时 / TCP 长时间无回执 | 关闭 socket，重连 |
| `AIOT_EV_ERROR` | 本地发送失败、缓冲区溢出、JSON 解析失败 | 记录 `ev->error`，必要时重连 |
| `AIOT_EV_DISCONNECTED` | 调用 `aiot_client_disconnected()` | 清理业务状态 |

`ev->args_json` / `ev->result_json` 指向 SDK 内部 RX 缓冲，**只在回调期间有效**。需要保存请拷贝。

## 5. 缓冲区怎么定

`aiot_init()` 要求：

- `tx_cap >= 256`
- `rx_cap >= 256`

推荐：

| 场景 | TX | RX |
|---|---:|---:|
| 只发几个测点，无 OTA | 512–1024 | 1024 |
| 常规项目 | 1024–2048 | 2048 |
| 支持 OTA `upfs` / `gfcet` 大分片 | 2048 | 4096 |

- UDP 单包建议 < 1200 字节；测点很多时分包。
- `facs_his` 一包最多 1000 点，TX 可能超过 2 KB；SDK 会返回 `AIOT_ERR_OVERFLOW`，应分批。
- RX 是“单行最大长度”，不是累计；SDK 处理完一行会搬移剩余数据。

## 6. 常用 API 组合

### 实时上报

```c
aiot_kv_t kv[] = {
    {"temp", "25.5"},
    {"hum",  "60"},
    {"sw",   "1"},
};
aiot_report(&cli, kv, 3, NULL);
```

### 分步构造

```c
aiot_report_begin(&cli, "F1");
aiot_report_add(&cli, "temp", "25.5");
aiot_report_add(&cli, "hum", "60");
aiot_report_end(&cli);
```

### 历史补传

```c
aiot_backfill_begin(&cli, 1792714948u, "H1");
aiot_backfill_add(&cli, "wd", "11");
aiot_backfill_timestamp(&cli, 1792716748u);
aiot_backfill_add(&cli, "wd", "12");
aiot_backfill_end(&cli);
```

### 下行回执

```c
/* 默认自动确认，SDK 已回 order_conf */
aiot_kv_t kv = {"sw", "1"};
aiot_order_reply(&cli, ev->tra, &kv, 1);
```

如果要自己控制确认时机：

```c
cfg.no_auto_order_conf = 1;
...
aiot_order_confirm(&cli, ev->tra);
/* 执行 ... */
aiot_order_reply(&cli, ev->tra, &kv, 1);
```

### UDP

```c
cfg.mode = AIOT_MODE_UDP;
aiot_client_connected(&cli); // 直接 ONLINE

aiot_kv_t kv[] = {{"wd", "26.5"}, {"sf", "61"}};
aiot_udp_wakeup(&cli, kv, 2, "W1");

/* 等 lgn_facs 回执后 */
aiot_request_order(&cli, "G1");
aiot_request_time(&cli, "T1");
```

### MQTT

```c
cfg.mode = AIOT_MODE_MQTT;
cfg.product_id = "AIOTMQ";
/* 连接 MQTT broker 成功后 */
aiot_client_connected(&cli);
```

`aiot_client_connected()` 会通过 `cfg.send` 发布 `hear`；`cfg.send` 应把 payload 发布到 `south/{product}/{device}/up`。收到 `down/order` 后调用 `aiot_mqtt_rx()`。
