# 05 · 移植指南（裸机 / AT 模组 / lwIP / W5500 / RTOS）

SDK 与网络硬件完全解耦。移植只做三件事：

1. 提供 `aiot_send_fn`：把一段字节发到已建立的 TCP/UDP 连接；
2. 提供 `aiot_now_fn`：返回 1 ms 单调时间；
3. 把收到的数据交给 `aiot_client_rx()`（TCP）或 `aiot_client_rx_datagram()`（UDP）。

---

## 1. 状态机与调用时序

```text
             ┌──────────────┐
             │    IDLE      │
             └──────┬───────┘
        TCP connect │ UDP/MQTT ready
                    ▼
          ┌──────────────────┐
          │  WAIT_LOGIN (TCP)│
          └──────┬───────────┘
        lgn code=0│ lgn code!=0 / timeout
                 ▼
          ┌──────────────┐
          │   ONLINE     │◄──── 业务上报/心跳/下行
          └──────┬───────┘
        disconnect / timeout
                 ▼
             IDLE / ERROR
```

推荐主循环：

```c
for (;;) {
    if (net_is_connected()) {
        if (!sdk_started) {
            aiot_client_connected(&cli);
            sdk_started = 1;
        }
        aiot_client_poll(&cli, now_ms());
    } else if (sdk_started) {
        aiot_client_disconnected(&cli);
        sdk_started = 0;
    }
    os_delay(20);
}
```

> 不要在 `on_event` 里做长时间阻塞；SDK 回调发生在解析过程中，阻塞会拖慢整条 TCP 流。

---

## 2. 时间基准

要求：**单调递增、1 ms 单位、允许 32 位回绕**。

```c
/* STM32 HAL */
aiot_u32 now_ms(void *user) { (void)user; return HAL_GetTick(); }

/* FreeRTOS */
aiot_u32 now_ms(void *user) { (void)user; return (aiot_u32)(xTaskGetTickCount() * portTICK_PERIOD_MS); }

/* bare-metal SysTick 1ms */
volatile aiot_u32 g_ms;
void SysTick_Handler(void) { g_ms++; }
aiot_u32 now_ms(void *user) { (void)user; return g_ms; }
```

SDK 使用 `(aiot_u32)(now - since) >= interval`，回绕安全。

## 3. ESP8266 / ESP32 AT 模组

### 3.1 连接

```text
AT+CIPMUX=0
AT+CIPSTART="TCP","ciot.yzlkj.com",41032
```

收到 `CONNECT` / `CONNECT OK` 后：

```c
aiot_client_connected(&cli);
```

### 3.2 发送

SDK 的 `send` 回调会被要求发送完整帧（TCP 已带 `\n`）：

```c
static int at_send(void *user, const aiot_u8 *data, size_t len)
{
    (void)user;
    if (len > 2048) return -1;       /* AT 模组单包限制 */
    uart_printf("AT+CIPSEND=%u\r\n", (unsigned)len);
    if (!wait_for_prompt(1000)) return -1;
    uart_write(data, len);
    return wait_for_send_ok(5000) ? 0 : -1;
}
```

> 发送回调是阻塞的。若主循环不能阻塞 5 秒，请把发送放到独立 UART 任务/队列，`send` 只入队并返回 0；但要保证入队顺序与 TCP 字节流一致。

### 3.3 接收

```text
+IPD,<len>:<payload>
```

解析出 payload 后：

```c
aiot_client_rx(&cli, payload, len);
```

如果一次 `+IPD` 被 UART 中断拆成多段，建议先拼到环形缓冲，凑够 `<len>` 再喂给 SDK。

### 3.4 断线

`CLOSED` / `ERROR` / `WIFI DISCONNECT`：

```c
aiot_client_disconnected(&cli);
/* 关闭 socket，退避 1s/2s/5s/10s 重连 */
```

## 4. W5500 / 硬件 TCP/IP

W5500 的 Socket n 提供 `send()` / `recv()`。把 socket 号放在 `user` 上下文：

```c
typedef struct {
    aiot_u8 sock;
} w5500_ctx_t;

static int w5500_send(void *user, const aiot_u8 *data, size_t len)
{
    w5500_ctx_t *ctx = user;
    aiot_u16 sent = 0;
    while (sent < len) {
        aiot_u16 n = send(ctx->sock, data + sent, (aiot_u16)(len - sent));
        if (n == 0) {
            if (++retry > 100) return -1;
            delay_ms(1);
            continue;
        }
        sent += n;
    }
    return 0;
}
```

接收：

```c
aiot_u16 avail = getSn_RX_RSR(sock);
if (avail > 0) {
    aiot_u8 buf[512];
    int n = recv(sock, buf, sizeof buf);
    if (n > 0) aiot_client_rx(&cli, buf, n);
}
```

注意 W5500 的 `recv` 可能返回部分数据；SDK 内部按 `\n` 拆帧，没问题。

## 5. lwIP（raw / netconn / socket）

### 5.1 netconn

```c
struct netconn *conn = netconn_new(NETCONN_TCP);
netconn_connect(conn, IP_ADDR, 41032);

/* 接收任务 */
struct netbuf *buf;
while (netconn_recv(conn, &buf) == ERR_OK) {
    void *data;
    u16_t len;
    netbuf_data(buf, &data, &len);
    aiot_client_rx(&cli, data, len);
    netbuf_delete(buf);
}
```

### 5.2 socket

```c
int n = recv(fd, buf, sizeof buf, 0);
if (n > 0) aiot_client_rx(&cli, buf, n);
```

### 5.3 发送

`send()` 可能只发送部分字节；必须循环直到全部发送，或返回 `-1` 让 SDK 报错：

```c
static int sock_send(void *user, const aiot_u8 *data, size_t len)
{
    int fd = *(int *)user;
    size_t off = 0;
    while (off < len) {
        int n = send(fd, data + off, len - off, 0);
        if (n <= 0) return -1;
        off += n;
    }
    return 0;
}
```

## 6. UDP 低功耗

UDP 不需要 `connect` 成功回调，但需要：

1. 打开一个 UDP socket 并 `connect` 到 `ciot.yzlkj.com:40501`；
2. `aiot_client_connected()` 标记 ONLINE；
3. 每次唤醒：

```c
aiot_kv_t kv[] = {{"wd", "26.5"}, {"sf", "61"}};
aiot_udp_wakeup(&cli, kv, 2, "W1");   /* ack 任意字符串 */
```

4. 收包：

```c
int n = udp_recv(buf, sizeof buf, 3000);
if (n > 0) aiot_client_rx_datagram(&cli, buf, n);
```

5. 收到 `lgn_facs code=0` 后，再发 `get_order` / `get_time`：

```c
aiot_request_order(&cli, "G1");
```

### 低功耗建议

- 一次唤醒只发一包 `lgn_facs`，把要补的数据尽量合并；
- `ack` 用递增序号，方便判断是否丢包；
- 未收到回执不要无限等，超时后休眠；
- 大量历史数据用 TCP 补传，不要用 UDP 分片。

## 7. MQTT 适配

### 7.1 已有 MQTT 栈（推荐）

不需要 `port/aiot_mqtt_client.c`。只需：

1. 用设备 ID/密码连接 broker；
2. 订阅：
   - `south/{product}/{device}/down/order`
   - `south/{product}/{device}/down/result`
3. 收到的 payload 交给：

```c
aiot_mqtt_rx(&cli, payload, len);
```

4. `cfg.send` 把 SDK 给的 payload 发布到 `south/{product}/{device}/up`：

```c
static int mqtt_publish_cb(void *user, const aiot_u8 *data, size_t len)
{
    return my_mqtt_publish(UP_TOPIC, data, len, 1) == 0 ? 0 : -1;
}
```

SDK 生成的 payload 不含 `top`，符合平台 MQTT 上行格式。

### 7.2 使用自带客户端

`port/aiot_mqtt_client.c` 是 QoS1、无 TLS、无重传的极简实现，适合 PC/网关/RTOS。裸机一般已有 lwIP MQTT，不建议重复造轮子。

## 8. 内存与栈

### 8.1 静态分配

```c
static aiot_client_t g_cli;   /* 约 300 B */
static aiot_u8 g_tx[2048];
static aiot_u8 g_rx[4096];
```

不要这样：

```c
void foo(void) {
    aiot_client_t cli;
    aiot_u8 tx[2048], rx[4096];
    aiot_init(&cli, ..., tx, ..., rx, ...);
} /* 返回后指针全部悬空 */
```

### 8.2 解析栈

`handle_frame()` 在栈上放 `aiot_json_tok_t[AIOT_JSON_MAX_TOKENS]`：

- 128 tokens ≈ 1 KB
- 64 tokens ≈ 0.5 KB

在启动文件里把 `Stack_Size` 至少设为 0x800（2 KB），并留出业务栈。

### 8.3 不用 malloc

SDK 内部没有 `malloc/free`。所有缓冲由调用方提供，适合安全认证/长期运行设备。

## 9. 重连策略

建议指数退避：

```c
static aiot_u32 backoff = 1000;
on_disconnect:
    aiot_client_disconnected(&cli);
    delay(backoff);
    backoff = min(backoff * 2, 60000);
    reconnect();
on_login_success:
    backoff = 1000;
```

不要在密码错误（`code=3`）时疯狂重连；记录错误并等待人工/远程修正。
