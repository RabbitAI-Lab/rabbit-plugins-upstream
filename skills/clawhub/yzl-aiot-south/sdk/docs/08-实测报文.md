# 08 · 实测报文摘录（2026-11-04）

以下报文来自平台测试环境 `ciot.yzlkj.com` 的真实设备联调。密码、会话 token、设备 ID 的部分字符已替换/省略；字段结构保持原样。

测试设备：

| 方式 | 设备类型 | 用途 |
|---|---|---|
| TCP 41032 | `AIOTSDK-*` | 登录、facs、get_time、下行 set |
| UDP 40501 | `TD98-*` | lgn_facs、get_order、get_time |
| MQTT 1883 | `AIOTMQ-*` | CONNECT、SUBSCRIBE、QoS1 PUBLISH、下行 set |

## 1. TCP

### 1.1 登录

```text
→ {"top":"func","ter":"AIOTSDK-0001","data":[{"func":"lgn","args":["<PASSWORD>"],"fid":"L1"}]}\n
← {"top":"result","ter":"AIOTSDK-0001","data":[{"func":"lgn","code":0,"result":"<TOKEN>","fid":"L1"}],"ack":""}\n
```

### 1.2 实时数据

```text
→ {"top":"func","ter":"AIOTSDK-0001","data":[{"func":"facs","args":["temp","25.5","hum","60","ver","aiot-c-sdk/1.0 \"demo\""],"fid":"F1"}]}\n
← {"top":"result","ter":"AIOTSDK-0001","data":[{"func":"facs","code":0,"result":null,"fid":"F1"}],"ack":""}\n
```

注意 `ver` 中的引号被正确转义；平台存储为 `aiot-c-sdk/1.0 "demo"`。

### 1.3 校时

```text
→ {"top":"func","ter":"AIOTSDK-0001","data":[{"func":"get_time","args":["1"],"fid":"T1"}]}\n
← {"top":"result","ter":"AIOTSDK-0001","data":[{"func":"get_time","code":0,"result":"2026-11-04 01:14:48","fid":"T1"}],"ack":""}\n
```

平台文档说 `"1"` 返回 Unix 时间戳，实测返回格式化字符串。

### 1.4 下行 set

平台推送：

```text
← {"top":"order","ter":"AIOTSDK-0001","data":[{"cmd":"set","args":["AIOTSDK-0001","sw","0"],"tra":"11c1160013cc1365"}],"ack":"3724261884"}\n
```

SDK 自动回 `order_conf`，应用执行后回 `facs_reply`：

```text
→ {"top":"func","ter":"AIOTSDK-0001","data":[{"func":"order_conf","args":["11c1160013cc1365"],"fid":"F2"}]}\n
→ {"top":"func","ter":"AIOTSDK-0001","data":[{"func":"facs_reply","args":["11c1160013cc1365","AIOTSDK-0001","sw","0"],"fid":"F3"}]}\n
```

平台随后返回两行：

```text
← {"top":"result","ter":"AIOTSDK-0001","data":[{"func":"order_conf","code":0,"result":null,"fid":"F2"}],"ack":""}\n
← {"top":"result","ter":"AIOTSDK-0001","data":[{"func":"facs_reply","code":0,"result":null,"fid":"F3"}],"ack":""}\n
```

平台指令状态变为 `succeeded`。

## 2. UDP

### 2.1 唤醒+上报

```text
→ {"top":"func","ter":"TD98-2011121433","data":[{"func":"lgn_facs","args":["<PASSWORD>","TD98-2011121433","wd","26.5","sf","61"],"fid":"L1"}],"ack":"W1"}
← {"top":"result","ter":"TD98-2011121433","data":[{"func":"lgn_facs","code":0,"result":null,"fid":"L1"}],"ack":"W1"}
```

### 2.2 拉取指令

```text
→ {"top":"func","ter":"TD98-2011121433","data":[{"func":"get_order","args":[],"fid":"F2"}],"ack":"G1"}
← {"top":"result","ter":"TD98-2011121433","data":[{"func":"get_order","code":0,"result":null,"fid":"F2"}],"ack":"G1"}
```

无挂起指令时 `result=null`。

### 2.3 校时

```text
→ {"top":"func","ter":"TD98-2011121433","data":[{"func":"get_time","args":["1"],"fid":"T1"}]}
← {"top":"result","ter":"TD98-2011121433","data":[{"func":"get_time","code":0,"result":"2026-11-04 01:14:58","fid":"T1"}],"ack":""}
```

### 2.4 关键观察

如果连续发送 `lgn_facs`、`get_order`、`get_time` 三个数据报，而不等待 `lgn_facs` 回执，`get_order` 可能先被处理并返回：

```json
{"func":"get_order","code":4,"result":"未登录"}
```

所以 SDK 示例在收到 `lgn_facs code=0` 后才发 `get_order`。

## 3. MQTT

### 3.1 CONNECT

```text
Client ID: AIOTMQ-0001
Username:  AIOTMQ-0001
Password:  <PASSWORD>
Keepalive: 60s
```

匿名连接返回 `Not authorized`；设备 ID + 设备密码返回 `Success`。

### 3.2 订阅

```text
SUBSCRIBE south/AIOTMQ/AIOTMQ-0001/down/order QoS1
SUBSCRIBE south/AIOTMQ/AIOTMQ-0001/down/result QoS1
```

### 3.3 上报

```text
PUBLISH south/AIOTMQ/AIOTMQ-0001/up QoS1
{"ter":"AIOTMQ-0001","data":[{"func":"facs","args":["temp","24.5","hum","55","ver","aiot-c-sdk/1.0 mqtt"],"fid":"F1"}]}
```

平台不返回普通 `facs` 的 result（MQTT 通道特性）。

### 3.4 下行 set

```text
PUBLISH south/AIOTMQ/AIOTMQ-0001/down/order QoS1
{"top":"order","ter":"AIOTMQ-0001","data":[{"cmd":"set","args":["AIOTMQ-0001","sw","1"],"tra":"f9e6b5133a9827e4"}],"ack":"..."}
```

设备回：

```text
PUBLISH south/AIOTMQ/AIOTMQ-0001/up QoS1
{"ter":"AIOTMQ-0001","data":[{"func":"order_conf","args":["f9e6b5133a9827e4"]},{"func":"facs_reply","args":["f9e6b5133a9827e4","AIOTMQ-0001","sw","1"]}]}
```

平台指令状态变为 `succeeded`。

---

## 4. 结论

- TCP/UDP/MQTT 三条链路都能完成“登录/唤醒 → 上报 → 下行 → 回执 → 平台状态更新”的闭环。
- TCP 的回执是逐行返回的，一请求多回执；SDK 必须按行拆。
- UDP 是“一问一答”，且 `lgn_facs` 与后续请求之间要留出处理时间。
- MQTT 的认证在 CONNECT 层，topic 必须严格匹配型号 ID/设备 ID。
- `get_time` 返回类型与文档有差异，设备侧应兼容字符串和数字。
