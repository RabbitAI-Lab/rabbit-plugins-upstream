## Description:

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use the skill to review a Videntic Project’s AI visibility, tracked competitors, mentions, citations, and Technical Audit findings, then receive evidence-based recommendations or request supported changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Granting broader Workspace or action permissions than needed can expose more project data or allow unintended changes.

Mitigation: Choose only the Workspace and action permissions needed; prefer read-only access for analytics.

Risk: Requested changes can affect usage allowances or future tracking.

Mitigation: Review material effects and obtain any needed consent before making a supported change.

Risk: Sharing credentials in chat could expose account access.

Mitigation: Complete OAuth through the client and never paste credentials into chat.
