# 利他销售思维教练（lita-sales-coach）

一个 WorkBuddy 技能（Skill），把"利他销售"从话术技巧升级为可运行的**沟通思维教练**：识别客户意图 → 自动路由到合适的框架 → 重构话术 → 对现有话术做利他度审计打分。

> 核心理念：利他不是讨好，是让对方更容易做出适合自己的选择。真正的影响力，源于对他人的成全。

## 这套技能解决什么

多数销售话术训练只给"模板"。这个技能给的是**思维框架 + 临场判断**：

- 客户说"再考虑考虑"，是犹豫还是怕被坑？该用哪套话术？
- 一段话术为什么"不利他"、哪里逼单了、该怎么改？
- 金融场景怎样既专业又不违规、敢说"这款可能不适合您"？

## 五层能力框架

| 层 | 解决什么 | 来源 |
| --- | --- | --- |
| 哲学层（理论底盘） | 利他沟通为什么有效：非暴力沟通 NVC 四要素 | 《非暴力沟通》浓缩 9 句 |
| 表达层 | 怎么说才利他、有温度、可成交 | 利他话术 7 原则 + 万能公式 |
| 思维层 | 销冠怎么看人、怎么转换思维 | 销冠夸人技术 + 6 大思维转换 + 自测 |
| 沟通层 | 客户 / 向上汇报如何治理信任 | GPS-R 信任治理模型 |
| 抗挫层 | 被拒 / 逆境如何反弹 | 逆商 CORE 模型 |

## 核心能力

1. **意图识别与路由** — 拿到客户原话，先用 NVC 反推其底层未被满足的需要，再自动选定主用层和最佳应答结构（覆盖 10 类常见客户意图，含多意图冲突与金融合规铁律）。
2. **话术重构** — 给"普通表达 ❌ → 利他表达 ✅"对比，并点出对应 NVC 哪一环；请求类优先套用万能公式。
3. **利他度审计与打分** — 对现有话术做六维打分（观察 / 感受 / 需要 / 请求 / 价值 / 合规），算利他指数与评级，定位不利他根因，输出更新后话术。
4. **场景适配** — 内置金融（保险、银行理财、信用卡、贷款、信托）与软件/AI 产品（ERP、SaaS、AI）改写示例库，金融场景强制先挂"合规护栏"：如实披露、适当性匹配、揭示风险、敢说"不适合"。

## 安装

将本仓库内容复制到 WorkBuddy 用户级技能目录：

```bash
# 用户级（推荐，所有项目可用）
cp -r lita-sales-coach ~/.workbuddy/skills/

# 或在 WorkBuddy 中通过"技能"入口导入本仓库
```

安装后在对话中说"用利他销售思维教练，把'……'改成利他表达"即可触发。

## 使用示例

- 改写："把'这款产品收益高您闭眼买就行'改成利他表达" → 触发意图路由 + 金融合规护栏 + 更新话术
- 审计："分析这段话术哪里不利他并打分" → 六维打分 + 利他指数 + 修改意见 + 更新版
- 路由："客户说'这个信托收益高，我全买了'" → 先识别为风险盲区，先揭示波动与流动性风险，而非顺势夸产品

- 内容整理自公开公众号素材（成交有术、老枪职场笔记、职场人成长计划等），用于学习与方法沉淀。
