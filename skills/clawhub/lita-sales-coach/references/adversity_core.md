# 抗挫层 · 逆商 CORE 模型

> 副标题：比情商更重要的"反弹力"
> 底部文案：我们无法控制天气，但可以控制如何应对风雨。

## C — 掌控感（Control）
我能否影响这件事？
哪怕只有 10% 的控制权。

## O — 责任担当（Ownership）
承担解决责任，
而非抱怨环境。

## R — 影响范围（Reach）
将挫折"圈禁"，
不祸及生活其他方面。

## E — 持续时间（Endurance）
视逆境为暂时，
而非永久诅咒。

## 教练用法
- 用户被客户拒绝 / 丢单 / 受挫时，用 CORE 四问帮其重建反弹力：
  1. **C**：这件事里，你还能影响哪 10%？（找到可控点）
  2. **O**：你能承担哪部分解决责任？（停止抱怨环境）
  3. **R**：这次挫折的影响边界在哪？不让它蔓延到其他事。
  4. **E**：把它定位为"暂时"，不是"永远"。
- 与思维层"把拒绝当数据收集"联动：CORE 管心态，复盘日志管方法。
