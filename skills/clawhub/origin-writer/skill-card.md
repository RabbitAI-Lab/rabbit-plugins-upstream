## Description:

Origin Writer helps authors and writing agents maintain long-form fiction continuity by treating each chapter as a transaction that pairs prose with reviewed state changes for characters, objects, foreshadowing, and timelines.

This skill is ready for commercial/non-commercial use.

## Use Case:

External authors, editors, and agent workflows use this skill to draft or continue long-form fiction while tracking world state, character knowledge, object ownership, foreshadowing, and timeline consistency. It is suited to novel-writing workflows that need repeatable checks before accepting chapter-level changes.
