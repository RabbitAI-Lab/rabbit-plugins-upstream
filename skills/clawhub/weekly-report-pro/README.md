# Weekly Report Pro

Auto-collect Git commits + user dictation → structured weekly report. No fluff, results-oriented.

## Features

- 🔍 Auto-scans local Git repos and collects commits from the past 7 days
- 💬 Asks you once for non-code work, metrics, blockers, and next-week plans
- 📄 Generates structured reports in 4 role templates: Developer, Operations, Sales, Manager
- 🎨 3 output styles: DingTalk (emoji+concise), Feishu (headings), Email (formal)
- 🔒 Privacy-first: all data stays local, nothing uploaded

## Quick Start

1. Say "Write my weekly report" or "生成周报"
2. Point to your code directories when asked
3. Answer a few quick questions about your week
4. Get a polished, results-oriented report

## Requirements

- Python 3.8+
- Git (for commit collection)

## Who Is This For?

- Developers who want Git commits auto-summarized
- Tech leads who need to report team progress
- Anyone who hates writing weekly reports from scratch
