# 上架文案 — 周报生成器 Pro

## 基本信息
- **技能名称**:周报生成器Pro(自动收集素材·拒绝流水账)
- **一句话简介**:别的周报工具帮你润色,它帮你把活儿自动收集齐——Git提交+待办+口述,一句话出一份领导爱看的周报。
- **分类**:效率办公
- **标签**:周报、日报、工作总结、汇报、Git

## 详细介绍(发布表单粘贴)

**周五下午5点,你还在翻聊天记录想"我这周干了啥"?**

市面上的周报技能都是"你把内容给我,我帮你排个版"。
周报生成器 Pro 反过来:**素材它自己收**。

**三步出稿:**
1. 🔍 自动扫描你的代码仓库,汇总本周 Git 提交(只读,不上传)
2. 💬 一次性问齐补充项:非代码工作、量化数据、阻塞、下周计划(也可直接丢待办文件/聊天记录/口述)
3. 📄 按角色出稿:程序员/运营/销售/管理者四套模板,钉钉/飞书/邮件三种排版

**写作铁律(内置):**
- 结果导向:"完成退款链路并联调通过",而不是"参与了开发"
- 能量化就量化:提交数、解决问题数、转化率
- 同项目多条提交自动合并成一条成果
- 不编造:素材里没有的事绝不出现在周报里

**使用示例:**
- "写周报"
- "根据 ~/code 目录的提交生成本周周报,钉钉风格"
- "帮我把这段语音整理成正式周报"(粘贴口述内容)

**隐私:** Git 记录仅本机读取,不上传任何数据。
