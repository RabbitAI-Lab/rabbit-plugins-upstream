# Symptoms Guide — Quick Reference

A symptom-to-cause reference to help match what you observe to possible diagnoses.

## How to Use

1. Identify the primary symptom you observe.
2. Check the possible causes below.
3. Use `garden_doctor.py diagnose` with the symptom(s) for ranked, confidence-scored results.

## Symptom → Possible Causes

### Yellow Leaves

| Pattern | Likely Causes |
|---|---|
| Lower/older leaves yellowing uniformly | Overwatering, nitrogen deficiency, natural aging |
| New leaves yellow with green veins | Iron deficiency |
| Interveinal yellowing (between veins) | Iron or magnesium deficiency |
| Yellowing + brown spots | Early blight, leaf spot, bacterial spot |
| Yellow speckling/stippling | Spider mites |
| General yellowing + wilting | Overwatering/root rot |
| Yellowing + sticky residue | Aphids, scale, whiteflies (honeydew) |

### Brown Spots / Patches

| Pattern | Likely Causes |
|---|---|
| Brown spots with concentric rings | Early blight |
| Brown spots with yellow halos | Leaf spot (fungal or bacterial) |
| Water-soaked dark patches | Late blight, cold stress |
| Brown crispy tips/edges | Low humidity, salt buildup, nutrient burn, underwatering |
| Brown sunken lesions on fruit | Anthracnose, blossom end rot (bottom of fruit) |
| Brown/black mushy roots | Root rot (overwatering or fungal) |

### Wilting / Drooping

| Pattern | Likely Causes |
|---|---|
| Wilting + wet soil | Overwatering, root rot |
| Wilting + dry soil | Underwatering |
| Wilting + no recovery at night | Bacterial wilt |
| Wilting + mushy stem | Root rot |
| Drooping + hot weather | Heat stress |
| Sudden widespread wilt | Bacterial wilt, cold shock |

### White / Powdery / Fuzzy Growth

| Pattern | Likely Causes |
|---|---|
| White powdery spots | Powdery mildew |
| White cottony masses | Mealybugs |
| Gray fuzzy mold | Botrytis (gray mold) |
| White crust on soil | Salt buildup |
| White fuzzy growth under leaves | Late blight (sporulation) |

### Holes / Chewed Leaves

| Pattern | Likely Causes |
|---|---|
| Large irregular holes | Caterpillars, slugs/snails |
| Small holes + dark droppings | Caterpillars |
| Holes + slimy trails | Slugs/snails |
| Ragged edges | Caterpillars, earwigs |
| Tiny pinprick holes | Flea beetles |

### Sticky Residue / Honeydew

| Pattern | Likely Causes |
|---|---|
| Sticky leaves + insects on new growth | Aphids |
| Sticky leaves + hard bumps on stems | Scale insects |
| Sticky leaves + white flying insects | Whiteflies |
| Sticky leaves + black sooty coating | Sooty mold (secondary to pest honeydew) |

### Webbing

| Pattern | Likely Causes |
|---|---|
| Fine webbing on plant | Spider mites |
| Webbing with caterpillars | Fall webworm / tent caterpillar |

### Distorted / Deformed Growth

| Pattern | Likely Causes |
|---|---|
| Twisted/cupped leaves | Herbicide drift |
| Narrow strap-like leaves | Herbicide drift |
| Stunted distorted new growth | Aphids, thrips |
| Deformed fruit with corky scars | Catfacing (cool weather pollination) |
| Blisters on leaf undersides | Edema |

### Leaf Drop

| Pattern | Likely Causes |
|---|---|
| Sudden leaf drop | Draft stress, cold shock, temperature stress |
| Lower leaf drop | Overwatering, nitrogen deficiency, natural aging |
| Leaves yellow then drop | Overwatering, pest stress, low light |

### Stunted Growth

| Pattern | Likely Causes |
|---|---|
| Overall stunting + pale leaves | Nutrient deficiency, low light |
| Stunting + root problems | Root rot, nematodes |
| Stunting + visible pests | Aphids, spider mites (chronic) |

### Color Changes (Not Yellow)

| Pattern | Likely Causes |
|---|---|
| Purple/reddish leaves | Phosphorus deficiency, cold stress |
| Dark green + stunted | Excess nitrogen |
| Silvery streaks | Thrips |
| Bleached/white patches | Sunburn |

## By Plant Type

### Tomatoes / Peppers

Common problems: early blight, late blight, blossom end rot, bacterial wilt, aphids, hornworms, catfacing

### Houseplants (Monstera, Pothos, etc.)

Common problems: overwatering/root rot, spider mites, mealybugs, low humidity, low light, scale

### Succulents

Common problems: overwatering, etiolation (low light), mealybugs, sunburn (if moved too fast)

### Roses

Common problems: powdery mildew, black spot, aphids, Japanese beetles, rust

### Herbs (Basil, Mint)

Common problems: downy mildew, aphids, fusarium wilt (basil), root rot (mint in soggy soil)

## Tips for Accurate Diagnosis

1. **Report multiple symptoms** — the more symptoms you provide, the higher the confidence.
2. **Be specific** — "brown spots with yellow halos" is better than "brown spots."
3. **Note the progression** — which leaves were affected first (top/bottom, old/new)?
4. **Check the soil** — wet vs. dry is critical for watering diagnosis.
5. **Inspect undersides of leaves** — for pests like spider mites and aphids.
6. **Check for webbing, sticky residue, visible insects** — pest indicators.
7. **Consider the environment** — recent temperature changes, repotting, or relocation.
