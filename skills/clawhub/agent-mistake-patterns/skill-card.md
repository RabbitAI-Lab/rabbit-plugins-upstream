## Description:

Helps AI agents recognize recurring mistake patterns and apply self-correction routines for note retrieval, workflow checks, edit anchoring, debugging, error archiving, root-cause classification, and fix verification.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mowenqwq](https://clawhub.ai/user/mowenqwq)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, engineers, and agent operators use this skill to improve agents with persistent notes or memory systems by identifying repeated error patterns, adding pre-action checks, and closing the loop after mistakes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may encourage an agent to consult existing personal notes and write mistake archives.

Mitigation: Use it only in workspaces where that memory behavior is intended and appropriately scoped.
