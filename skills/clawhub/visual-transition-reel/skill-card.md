## Description:

Guides creation of multi-scene video reels with transitions between composed shots and optional narration.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Creators and production teams use this skill to plan, generate, review, and assemble multi-scene video montages with transitions between shots.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Unpinned prerequisite installation commands can retrieve changed skill code.

Mitigation: Review the prerequisite skill sources and prefer pinned versions or a trusted installer before installing.

Risk: Generated and reference media are uploaded to external media-generation services.

Mitigation: Approve uploads and confirm permission to share any reference images, video, or audio before generation.

Risk: Generated stills, clips, and the final reel can overwrite files in the chosen workspace.

Mitigation: Use a dedicated output directory and check existing files before running generation or assembly.
