# 分镜表字段规范（Storyboard Table Spec）

分镜表是流水线的唯一数据源。生成或校验分镜表时严格按本规范。

## 标准列（11 列）

| 列名 | 必填 | 说明 |
|---|---|---|
| shot_id | ✅ | 镜号，格式 `S01`、`S02`…，全表连续不跳号 |
| scene | ✅ | 场景号/场景名，如 `SC03-天台夜晚`，同场景连续排列 |
| shot_size | ✅ | 景别：远/全/中/近/特（大特写标 `特写-微`） |
| camera_move | ✅ | 运镜，用 shot-vocabulary 词库标准词，如 `缓推`、`跟摇`、`手持晃动` |
| duration_s | ✅ | 单镜时长秒数，竖屏短剧 4-15s；超过 15s 必须拆镜 |
| characters | ✅* | 出场角色名，多个用 `+` 连接，必须与锚点表一致；t2v 空镜可空（*i2v/fl2v 必填） |
| action_visual | ✅ | 画面动作描述：谁 + 在哪 + 做什么 + 关键道具/表情，一段具体可视化文字 |
| dialogue_vo | ➖ | 台词/旁白，保留原文语言；无则留空 |
| sfx_music | ➖ | 音效/音乐提示，如 `雨声+低音鼓点渐强` |
| frame_mode | ✅ | `i2v`（首帧驱动）/ `fl2v`（首尾帧）/ `t2v`（纯文生视频） |
| negative_extra | ➖ | 本镜额外负面词（默认负面库已全局生效，只写增量） |

## frame_mode 选择规则

1. 默认 `i2v`：有明确首帧画面、动作从静止开始的镜头
2. `fl2v`：需要精确落点的镜头——转场匹配、动作收尾、集末悬念定格（尾帧=下一镜首帧可保证跨镜衔接）
3. `t2v`：无合适首帧、纯氛围/空镜（雨夜街道、爆点物飞出）时使用

## 校验规则（--check 模式执行项）

1. 必填列无空值（t2v 空镜的 characters 除外）；shot_id 连续；frame_mode 在三值之内
2. duration_s 在目标模型档位内（如海螺 4-15s；其他模型以当期官方文档为准）
3. i2v/fl2v 镜头的 characters 中每个角色都能在锚点表找到，锚点串非空
4. fl2v 镜头必须能指出尾帧来源（下一镜首帧 or 悬念定格描述）
5. 同场景内景别变化有镜头逻辑（忌连续两个完全相同景别+机位）

## CSV 样例

```csv
shot_id,scene,shot_size,camera_move,duration_s,characters,action_visual,dialogue_vo,sfx_music,frame_mode,negative_extra
S01,SC01-天台夜晚,特写-微,缓推,5,沈青梧,沈青梧指尖攥皱的离婚协议特写纸角颤抖,你以为你赢了？,雨声+心跳低音,i2v,
S02,SC01-天台夜晚,近景,急拉,6,沈青梧+陆峥,沈青梧转身甩发陆峥在门口逆光站立,三年了我一天都待不下去,风声骤起,fl2v,画面抖动过度
```

## 产出格式

确认分镜表后同时给用户两份：Markdown 表格（人读、可改）+ 同名 CSV（喂脚本导出）。
