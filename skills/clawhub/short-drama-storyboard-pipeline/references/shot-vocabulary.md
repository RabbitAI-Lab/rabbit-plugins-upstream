# 竖屏短剧镜头语言词库（Shot Vocabulary for 9:16 Vertical Drama）

面向 9:16 竖屏短剧/漫剧的景别、运镜、节奏词库。生成 `shot_size`、
`camera_move` 与画面描述时从这里取词，保证提示词可被视频模型稳定理解。

## 竖屏 9:16 构图原则

1. 主体居中或上三分之一：竖屏两侧信息容量小，面部和冲突物放中轴
2. 字幕安全区：底部 1/4 留白（对白字幕位），关键动作避开该区
3. 纵深代替横移：竖屏横向空间窄，用前后景纵深（前景门框/肩部过肩）
   制造层次，少用横向大调度
4. 特写使用率高于横屏：短剧情绪浓度高，近景+特写占比建议 50%+

## 景别词库

| 景别 | 用途 | 短剧典型场景 |
|---|---|---|
| 远景 | 环境交代 | 开场城市/雨夜街道空镜 |
| 全景 | 人物全身+环境关系 | 登场亮相、追逐 |
| 中景 | 膝上/腰上，对话主力 | 对峙、谈判、日常对话 |
| 近景 | 胸上，情绪承载 | 质问、隐忍、转身 |
| 特写 | 面部/物件 | 泪痣颤抖、攥皱协议、耳环反光 |
| 特写-微 | 极端细节 | 瞳孔收缩、指尖血珠、协议签名 |

## 运镜词库（camera_move 标准词）

1. 静态系：`固定` `固定微晃`（呼吸感）
2. 推拉系：`缓推`（聚焦/压迫）`急推`（惊吓点）`缓拉`（揭示环境）`急拉`（关系揭示）
3. 摇移系：`左摇` `右摇` `跟摇`（追随行走）`横移`（竖屏慎用）
4. 升降系：`升镜`（离别/渺小感）`降镜`（压迫登场）
5. 手持系：`手持晃动`（冲突/慌乱）`跟拍`（跟随主角背影）
6. 组合系：`缓推+降` `急拉+升`（一个镜头内先后的组合，写明先后顺序）

## 短剧节奏定式（补全用户粗分镜时套用）

1. 黄金 3 秒开场：第 1 镜必须是特写级冲突/悬念物（攥皱的信、耳光瞬间、
   瞳孔地震），禁用空镜开场
2. 钩子密度：每 15-30 秒一个信息钩（新人物、反转、物件揭示）
3. 情绪对比镜：高潮台词后接 1 个静景/物件空镜做呼吸
4. 集末定格：最后一镜用 `fl2v` 落到悬念定格（门被推开半扇、回眸、
   手机亮起），尾帧即钩子画面
5. 对话正反打：中景交代→近景正反打→特写收情绪，三镜一组循环

## 转场词（写进下一镜提示词开头）

`硬切`（默认，不写）`匹配剪辑`（形状/动作匹配）`甩镜转场`（同方向甩）`黑场起`

## 表演情绪词（action_visual 强化用）

`眼眶泛红强忍` `指尖发白攥紧` `嘴角冷笑渐收` `瞳孔骤缩` `肩膀塌下一寸`
`深呼吸后扯出假笑` `睫毛颤动没睁眼`——用可观察的身体细节，不用「伤心地」。
