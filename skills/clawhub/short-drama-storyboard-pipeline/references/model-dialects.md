# 模型提示词方言速查（Model Dialects）

六类目标模型的首帧图 / 图生视频提示词差异。**一次会话锁定一个目标模型，
不混用方言。** 各家的时长档位、分辨率、参考图张数随版本变化快，生成前先提醒
用户核对当期官方文档；本文件只固化「结构方言」，不固化易变参数。

## 1. 海螺 H3（MiniMax Hailuo）— 结构化三段式

唯一使用结构化字段的模型，参考已装 `h3-prompt-writing` 技能的完整规范：

1. 输出语言：**英文**（对白、画面内文字保留原文）
2. 三段结构，顺序固定：
   `integrated_multimodal_description` → `overall_soundscape` → `non_diegetic_music`
3. 模式映射：首帧驱动=I2VA；首尾帧=FL2VA（描述两帧之间连续路径）；
   纯文生视频=T2VA；定妆照参考=Ref2VA
4. 参考图标签 `<Picture 1>`、`<Video 1>`、`<Audio 1>` 全段一致
5. 时长 4-15s，描述的运动量与 duration_s 匹配
6. 角色锚点串译成英文后放进 description 的 subject 描述，逐字复用

## 2. 即梦（Jimeng / Dreamina，字节）— 中文自然语言 + 首尾帧

1. 中文提示词可直接使用；结构：`[运镜词] + 主体+动作 + 环境 + 光线氛围 + 画质词`
2. 首帧图：文生图支持中文，锚点串原样嵌入；竖屏比例显式声明
3. 首尾帧模式：上传首帧+尾帧图，文字描述两帧之间的运动路径
4. 运镜偏好口语化动词：`镜头缓缓推近` `镜头快速拉远` `镜头跟随她转身`
5. 生成口型对白镜头时，台词写进提示词并注明「角色开口说话」

## 3. 可灵（Kling，快手）— 中文 + 运镜控制

1. 中文提示词；结构类似即梦：`主体+场景+动作+运镜+氛围+画质`
2. 支持运镜控制项与提示词并用：提示词写运动，控制面板选运镜类型，
   两者不要冲突（写了「镜头静止」又选「推进」会打架）
3. 首尾帧模式稳定，适合 `fl2v` 镜头
4. 负面提示词字段可用，直接放全局负面库

## 4. Seedance（字节）— 多镜头叙事向

1. 支持一次生成内多个连续镜头（多镜头叙事），同一提示词内用镜头分隔描述
   ——短剧场景连续对话组镜可合并生成，减少跨镜跳变
2. 中文可用；人物一致性依赖参考图/详细锚点描述
3. 首帧图生成建议配套 Seedream/即梦文生图，风格词统一

## 5. Vidu（生数科技）— 主体参考一致性

1. 核心优势：参考图生视频（主体参考），把定妆照作为角色参考直接锁定外观
   ——一致性要求最高的镜头优先分配给 Vidu
2. 中文提示词，描述动作与镜头；角色外观交给参考图，文字只管运动
3. 首尾帧模式可用

## 6. Runway（Gen-3/4）— 英文短句

1. 英文提示词，短句直给：`Handheld close-up. She crushes the paper,
   trembling fingers, rain on rooftop.`
2. 首尾帧用 first/last keyframe 上传表达，文字只写中间运动
3. 无负面字段：负面约束改写为正向锁定句放在句尾
4. 锚点串需译成英文（与 H3 共用同一份英文锚点译文，保持全流程一致）

## 首帧图提示词通用模板（图生图/文生图）

```
[风格前缀：如 电影感真人短剧写实风格 / 2D日漫画风漫剧 / 3D卡通渲染]
[锚点串]，[景别+竖屏构图：中景居中，9:16 竖幅，底部留字幕区]，
[action_visual 画面化]，[光线：逆光轮廓/冷雨夜霓虹/暖黄室内光]，
[画质：胶片颗粒感，高清细节，浅景深]
```

要点：一镜一图一主体焦点；锚点串必须原样出现；风格前缀全表统一。

## 方言切换自检

切换目标模型时逐项确认：输出语言（中/英）？结构字段还是自然段？
首尾帧如何表达？参考图/角色参考怎么给？负面词有没有承载字段？
时长档位以官方文档为准了吗？
