# 角色一致性锚点（Consistency Anchor）

跨镜头角色脸崩是短剧/漫剧量产第一痛点。本技能的解法：**把角色外观压缩成一条
逐字锁定串（Anchor），所有镜头、所有模型、所有提示词中原样复用，一个字都不改。**

## 锚点串公式

```
<ANCHOR 角色名> 年龄段+性别+族群，发型+发色+发长，2-3 个面部识别特征，
脸型+眼型，体型；本集服装：服装类型+颜色+材质+关键细节，配饰。
</ANCHOR>
```

示例：

```
<ANCHOR 沈青梧> 26岁中国女性，齐腰黑直发中分，左眼角小泪痣、右眉尾浅疤，
瓜子脸杏眼薄唇，身高165cm纤细肩窄；本集服装：月白色改良旗袍立领盘扣
真丝材质，银色小圆耳环。
</ANCHOR>

<ANCHOR 陆峥> 30岁中国男性，黑色短发微乱额前碎发，剑眉薄唇左耳骨钉，
高鼻梁深眼窝，身高185cm宽肩窄腰；本集服装：黑色高领羊绒衫+炭灰大衣，
腕表银链。
</ANCHOR>
```

## 写锚点的五条硬规矩

1. 具体可画：每个特征都要能被文生图模型画出来；禁用「帅气」「气质好」等抽象词
2. 识别特征选稳定的：痣、疤、发型、瞳色 > 易变的表情、姿势、光线
3. 基础外观与服装分层：发型五官是基础层永不改；服装写「本集服装」子句，
   换装只改子句（并在分镜表 characters 列标注 `角色名@服装B`）
4. 全表逐字一致：锚点串一经确认，S01 到 S50 逐字相同，含标点
5. 数量克制：单镜出场角色 ≤3；群众演员不配锚点，用泛化描述

## 定妆照（角色参考图）生成提示词模板

用于先把角色钉死，再开始批量出分镜图。三视图一次锁定：

```
角色三视图设定图，同一人物：正面半身、侧面半身、背面全身，
[锚点串基础层]，纯浅灰背景，均匀柔光，服装设计稿风格，
高清细节，无水印 --ar 3:2
```

定妆照确认后，作为参考图/角色参考上传：

1. 即梦 / 可灵：图生视频时作首帧风格基准；有角色参考功能则优先用
2. Vidu：主体参考（参考图生视频）模式，直接把定妆照作为角色参考
3. 海螺 H3：Ref2VA 模式，用 `<Picture 1>` 标签引用定妆照
4. Seedream / 即梦文生图：定妆照作垫图或风格参考

## 全局负面提示词库（每镜默认叠加）

```
脸部崩坏，五官错位，面部扭曲，双眼不对称，多余手指，手指畸形，
肢体缺失，肢体重复，面部油光，过度磨皮，网红脸同质化，
服装细节漂移，文字水印，logo，画面模糊，低分辨率
```

负面词用各模型自己的 negative prompt 字段承载；不支持负面字段的模型
（如部分图生视频），把负面约束改写成正向锁定句（如「五官清晰对称，
双手自然」）放进提示词尾部。
