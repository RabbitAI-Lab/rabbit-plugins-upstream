# MBTI 测评计分规则

> 定位说明：本工具为**自我认知参考工具**，结果不构成任何心理学临床诊断，也不作为招聘、晋升等人事决策依据。

## 一、四维度说明

| 维度 | 极性 | 含义 |
|------|------|------|
| E / I | 外向 Extraversion / 内向 Introversion | 精力来源：外部世界 vs 内心世界 |
| S / N | 感觉 Sensing / 直觉 iNtuition | 信息获取：具体事实 vs 抽象模式 |
| T / F | 思考 Thinking / 情感 Feeling | 决策方式：逻辑分析 vs 价值感受 |
| J / P | 判断 Judging / 知觉 Perceiving | 生活方式：计划有序 vs 灵活开放 |

## 二、三版本抽题规则

题库中每道题均带有 `version_added` 标记（1 / 2 / 3），按版本抽取：

| 版本 | 抽题规则 | 总题数 |
|------|----------|--------|
| quick | `version_added == 1` | 70 题 |
| standard | `version_added <= 2` | 93 题 |
| pro | 全部题目（`version_added <= 3`） | 144 题 |

### 各版本维度分布（E/I、S/N、T/F、J/P 顺序）

| 维度 | quick（v1） | standard（v1+v2） | pro（全量） |
|------|-------------|-------------------|-------------|
| E/I | 16 | 21 | 32 |
| S/N | 19 | 26 | 40 |
| T/F | 18 | 24 | 38 |
| J/P | 17 | 22 | 34 |
| 合计 | 70 | 93 | 144 |

## 三、计分步骤

### 步骤 1：逐题计数

对每道题，根据用户选择的 A 或 B，从题库中读取该选项对应的极性值（E/I/S/N/T/F/J/P），累加到所属维度的对应极性计数器。

### 步骤 2：维度判定

对每个维度，比较两极计数，多者胜：

```
if E_count > I_count → 该维度结果为 E
if I_count > E_count → 该维度结果为 I
```

### 步骤 3：平票规则

某维度两极计数完全相等时，按惯例取以下极性：

- E/I 平票 → 取 **I**
- S/N 平票 → 取 **N**
- T/F 平票 → 取 **F**
- J/P 平票 → 取 **P**

### 步骤 4：组合结果

四个维度各取胜出极性字母，组合得到 16 型之一：

```
[E或I] + [S或N] + [T或F] + [J或P] = MBTI 类型
```

16 种可能结果：ISTJ, ISFJ, INFJ, INTJ, ISTP, ISFP, INFP, INTP, ESTP, ESFP, ENFP, ENTP, ESTJ, ESFJ, ENFJ, ENTJ

### 验证规则

- 总答题数必须等于当前版本的总题数（70 / 93 / 144）
- 各维度两极计数之和必须等于该维度在该版本下的题数
- 若用户跳过题目，需提示补答后再计分

## 四、倾向百分比（逐维归一）

```
倾向百分比 = 胜极题数 / 该维度在该版本下的总题数 × 100%
```

注意：分母使用**当前版本**的维度题数，而非全量题数。例如 quick 版 E/I 维度共 16 题，用户胜极（如 E）计 11 题，则 E 倾向百分比 = 11/16 × 100% ≈ 69%。

## 五、清晰度（Clarity）

衡量该维度倾向的明确程度，逐维计算：

```
clarity = |倾向百分比 - 50| × 2
```

取值范围 0–100，分为四档：

| clarity 值 | 档位（中文/英文） | 含义 |
|------------|-------------------|------|
| ≤ 25 | 轻微 / Slight | 该维度两极倾向接近均衡 |
| ≤ 50 | 中等 / Moderate | 有一定方向性但不强烈 |
| ≤ 75 | 清晰 / Clear | 方向性明确 |
| > 75 | 非常清晰 / Very Clear | 极强的单极倾向 |

- **综合清晰度** = 四个维度 clarity 的平均值。
- 报告规则：任一维度处于**轻微档（Slight）**时，报告必须标注「边界倾向，重测可能变化」的提示。

## 六、Top3 相似类型

用于呈现与用户最接近的其他类型，算法基于曼哈顿距离：

1. 构建用户的四维倾向百分比向量，例如 `(E: 69, S: 55, T: 80, J: 60)`。
2. 构建 16 型的标准向量：每个维度取偏好极为 100、另一极为 0，例如 INTJ = `(I: 100, N: 100, T: 100, J: 100)`。
3. 计算用户向量与各类型标准向量的**曼哈顿距离**（四维差值绝对值之和，范围 0–400）。
4. 相似度百分比：

```
相似度% = (1 - 距离 / 400) × 100
```

5. 取距离最小的前 3 个类型（排除用户自身类型）作为 Top3 相似类型，按距离从小到大排序展示。

## 七、答案文件格式（score.py 的输入）

```json
{
  "version": "quick | standard | pro",
  "nickname": "可选昵称",
  "answers": [
    {"id": 1, "choice": "A"},
    {"id": 2, "choice": "B"}
  ]
}
```

字段说明：

- `version`：答题版本，决定计分时的维度题数分母（70 / 93 / 144）。
- `nickname`：可选，仅用于报告展示。
- `answers`：答题记录数组；`id` 为题号，`choice` 为选项（A 或 B）；元素数量必须与对应版本总题数一致。
