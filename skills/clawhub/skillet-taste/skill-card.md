## Description:

Guides developers to write and observe a failing test before implementing a feature, bugfix, or behavior change.

This skill is ready for commercial/non-commercial use.

## Publisher:

[escoffier-labs](https://clawhub.ai/user/escoffier-labs)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to define expected behavior with a minimal failing test, verify the failure, then implement and validate the smallest change that passes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Mitigation: Preserve existing work and limit deletion to explicitly approved changes; prefer a recoverable workflow.
