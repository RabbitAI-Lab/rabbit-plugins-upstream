## Description:

Searches a T+1 TikTok creator database by market, followers, engagement, product category, gender, and language to help identify creators for outreach.

This skill is ready for commercial/non-commercial use.

## Use Case:

Marketers and creator-outreach teams use this skill to find TikTok creators matching audience, engagement, and commerce criteria across markets.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup can install or upgrade Node and qhkit and change the local PATH.

Mitigation: Prefer a preinstalled, pinned qhkit version; review installation and PATH changes before approving setup.

Risk: Configuring a qhkit token changes local credentials for a paid external service.

Mitigation: Review credential changes and confirm the intended Qinghu site before configuring a token or making paid calls.
