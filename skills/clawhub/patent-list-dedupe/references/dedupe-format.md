# 本地清单格式
输入为UTF-8或带BOM的UTF-8 CSV，首行为表头，默认公开号列名“公开号”，可用--column更改。其他格式先转成新CSV，保留原件。号码需含国家代码与种类码，例如演示号码CN1234567A；格式匹配不证明号码真实存在。

只统一全半角、大小写和空白；A/B公开文本不同，申请号、专利族、申请人别名均不自动归并。不能确认的号码逐行保留。相同公开号非空字段值不同列冲突，不静默挑选真值。输出目录需为空或不存在，输入文件保持原样。

原始明细用JSON保留每个原值，避免表头重名和带引号、逗号、换行导致列丢失。CSV的来源行号指记录结束物理行，含多行字段时可能跨行。空行遵循CSV标准库行为，不计作记录。汇总为公开号口径，不是发明/申请案/专利族口径。
