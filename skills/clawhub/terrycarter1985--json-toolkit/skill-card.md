## Known Risks and Mitigations:

Risk: Untrusted jq installations could introduce unsafe tooling into a user's shell workflow.

Mitigation: Install jq only through package managers you trust.

Risk: Recipes that use output redirection can overwrite existing files when placeholders are copied without review.

Mitigation: Choose output filenames carefully and review commands before running them.
