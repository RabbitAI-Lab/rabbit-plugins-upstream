## Description:

Uses OOMOL's GPTZero connector to detect whether plain-text documents were generated by AI and return document-, paragraph-, and sentence-level scores.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to run GPTZero AI-text detection through an OOMOL-connected account, using live connector schemas to prepare valid requests and interpret returned detection scores.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: First-time setup includes remote installer commands such as curl piped to bash or irm piped to iex.

Mitigation: Review the installer source before use, prefer a trusted and versioned oo CLI installation path, and do not let an agent run installer commands automatically.

Risk: The skill sends user-provided text to GPTZero through an OOMOL-connected account for detection.

Mitigation: Confirm the text is appropriate to submit to the connected third-party service before running detection.
