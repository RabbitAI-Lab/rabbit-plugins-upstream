## Description:

This skill lets an agent use GPTZero through an OOMOL-connected account to detect whether plain-text documents were generated by AI.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and external users use this skill to run GPTZero text-detection requests through an OOMOL-connected account and receive document-, paragraph-, and sentence-level AI-generation scores.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup instructions can lead an agent to execute an unverified remote installer on the user's machine.

Mitigation: Do not let an agent run the remote installer automatically; install the oo CLI only from a trusted, preferably pinned or verifiable source and approve authentication or connection steps manually.
