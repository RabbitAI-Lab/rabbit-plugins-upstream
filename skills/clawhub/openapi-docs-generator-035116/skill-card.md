## Description: <br>
Helps backend and platform teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to turn REST API documentation needs into actionable OpenAPI or Swagger workflows, checklists, code or configuration guidance, and validation steps. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate on broad API-related phrasing rather than only explicit OpenAPI or Swagger documentation requests. <br>
Mitigation: Require clear user intent before applying the workflow, and narrow trigger wording when publishing or deploying the skill. <br>
