## Description:

从主 ASIN 与已授权竞品的商品字段、图片和评论证据中提炼可验证的差异化方向与待验证问题。

This skill is ready for commercial/non-commercial use.

## Use Case:

Amazon 卖家和产品团队可用它对照主商品与已授权竞品的商品信息、图片和评论，整理有证据支持的差异化方向及后续验证问题。它仅用于产品定位讨论。

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security review flags broader account controls and possible credit spending during operations described as previews; it does not establish malicious intent.

Mitigation: Prefer a corrected release limited to differentiation analysis with previews that cannot spend credits. For this version, set ARI to ask before every charge, use quote or operations quote for previews, and explicitly request one-time manual collection.
