# 主题执行任务

每个 Phase 就是一个独立执行单元。标准模板的依赖字段填“无”或用顿号隔开的编号，Task 自动继承阶段前置。旧编号及证据路径沿用。

## 公共上下文

- 工作区与资料目录：填写路径；下文代码路径相对工作区，文档路径相对本文件。
- 目标与方案：填写已有资料位置及本轮范围。
- 项目规范：有关规则入口；缺失时如实说明。
- 用户约束：允许写入的范围、验证环境及特殊要求。
- 最终 Phase：P002。

## Phase P001：第一项可验收结果

- 目标：本阶段独立交付的具体结果。
- 依据：需求或方案的编号、章节。
- 依赖：无。
- 状态：未完成。
- 必读输入：现在可以打开的文件和章节。
- 交付给后继：产物路径、调用入口、验收证据位置。
- 实施者可写产物：列出本阶段允许修改的文件或模块，单列允许新建的文件。
- 验收：外部可观察结果与边界。
- 检查：工作目录、命令或操作、预期。
- 进度与证据：实施者回报改动和验证结果。只有主执行者在本清单勾选 Task、更新 P001 状态，并回填证据或引用 verification/P001.md。

### Task

- [ ] T001 实现具体路径内的目标行为。
  - 依赖：无。
- [ ] T002 完成该行为的内部评审与必要测试。
  - 依赖：T001。

## Phase P002：后继结果与累计验收

- 目标：本阶段交付的后继结果及累计效果。
- 依据：剩余目标及整个功能的验收。
- 依赖：P001。
- 状态：未完成。
- 必读输入：当前已有资料；列明从 P001 接收的产物、使用入口与证据。
- 实施者可写产物：列出本阶段允许修改或新建的文件，包括接通前置产物所需的改动。
- 验收：后继行为成立，累计结果覆盖本轮全部目标。
- 检查：从实际用户入口给出输入，经过 P001 的能力，对照预期检查最终输出。
- 进度与证据：实施者回报改动和验证结果。只有主执行者在本清单勾选 Task、更新 P002 状态，并回填累计验收证据或引用 verification/P002.md。

### Task

- [ ] T003 实现后继行为。
  - 依赖：无。
- [ ] T004 完成内部评审、必要验证及累计验收。
  - 依赖：T003。
