## Description: <br>
Converts TRPG rules into a structured briefing_package for the TRPG AI GM engine. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and TRPG creators use this skill to convert active tabletop role-playing game rules, scenarios, and reference material into a briefing_package for a single-player AI GM experience. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill is designed to inspect and edit multiple active local TRPG rule, scenario, and briefing_package files. <br>
Mitigation: Use it in a dedicated TRPG project folder and review the proposed file changes before deployment. <br>
Risk: Converted package content could introduce incorrect or misleading game guidance if source rules are ambiguous. <br>
Mitigation: Review generated package files and resolve any conversion questions before using the package with players. <br>
