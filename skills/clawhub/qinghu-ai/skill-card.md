## Known Risks and Mitigations:

Risk: Installing or upgrading an unpinned qhkit package can execute unreviewed code and alter the local Node/npm environment.

Mitigation: Review and trust the package before use; prefer a pinned or preinstalled version and approve environment changes.

Risk: Configuring an API token and uploading selected media exposes credentials and content to the Qinghu service.

Mitigation: Use a trusted token and confirm which files will be uploaded before submitting tasks or requesting estimates that upload media.

Risk: Installation steps may persistently change the shell PATH.

Mitigation: Avoid editing shell startup files unless persistent PATH changes are explicitly intended.
