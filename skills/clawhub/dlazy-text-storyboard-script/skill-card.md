## Description:

Turns user-provided themes, outlines, or structured copy into detailed short-video storyboard scripts.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Video creators and scriptwriters use the skill to turn themes, outlines, or structured copy into detailed short-video shot plans, preserving the original copy in spoken-script segments.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The artifact directs users to configure and run an external image-generation CLI, beyond the skill's stated storyboard-writing purpose; the CLI was not inspected in the partial scan.

Mitigation: Use the CLI only if you need that workflow, and review its requirements and external processing before installing or sending it content.
