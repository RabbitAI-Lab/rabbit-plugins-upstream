# guidance 路由

- “查重用哪个”“本科/硕博/期刊选什么” → `common/product-selection-playbook.md` + 对应品牌 `products-and-scope.md`。
- “检索哪些库”“怎么判断重复”“连续多少字” → `common/retrieval-and-matching-principles.md`；具体品牌再读其产品资料。
- “为什么学校更高”“两家结果不一样” → `common/cross-system-differences.md`。
- “报告怎么看”“总相似/复制比/引用率什么意思” → `common/report-interpretation.md`。
- “引用为何标红”“参考文献要不要删”“文件怎么准备” → `common/preflight-checklist.md` + `common/professional-faq.md`。
- “价格/时效/格式/隐私” → 实时 `products`/页面 + 对应 common 资料。
- “给这篇文件算字符” → character-count；“用维普/万方/知网提交” → 对应 lane；“降重/降 AIGC” → reduction；“报告是不是真的” → report-verify。

实时答案中的商品字段必须原样带出来源。仅咨询时不创建订单；有具体文件和明确执行意图时才转产品 lane。
