# 万方产品与检索范围

## 当前接入产品的选择

提交前执行：

```bash
python3 scripts/paper_check_client.py products --lane wanfang
```

当前 CQCCJY 目录可能返回：

| `productCode` | 当前产品名 | 场景 |
|---|---|---|
| `WF_UNDERGRADUATE` | 万方本科版 | 本科毕业论文 |
| `WF_GRADUATE` | 万方硕博版 | 硕博学位论文 |
| `WF_VOCATIONAL` | 万方高职高专版 | 高职高专论文 |
| `WF_JOURNAL` | 万方期刊版 | 期刊投稿/编辑场景 |
| `WF_TITLE` | 万方职称版 | 职称评审、已发表材料 |
| `WF_NEW_LITERATURE` | 万方新文献版 | 新文献检测场景，使用前确认页面说明 |
| `WF_MONOGRAPH` | 万方专著版 | 专著/长篇作品 |
| `WF_COURSEWORK` | 万方课程作业版 | 课程作业 |
| `WF_TEXT_AIGC` | 万方文本 AIGC 检测 | AI 生成内容风险，不是重复率 |

当前接口返回的 `fileType`、`hintMinCount`、`hintMaxCount`、`acceptTimeRequired`、计费模式和价格是执行依据。即使万方官方通用页面支持更多格式，本 Skill 也不得提交当前接口未声明的格式。

## 当前官方比对范围口径

万方个人文献版官方常见问题列出的资源类型包括学术期刊、优先出版、国内外重要会议、博士/硕士学位论文、报纸、互联网学术资源、学术网络文献、专利、特色英文资源、标准、法律法规和新方志等。

官方 2025 年范围调整说明还明确：

- 本科论文、高职高专论文检测类型增加大学生论文联合比对库；
- 硕博士论文检测类型增加硕博论文联合比对库；
- 其他检测类型不因此自动增加上述联合库。

必须把“产品类型”和“联合库权限”一起解释，不能说所有万方版本都含联合比对库。最终仍以订单报告列出的检测范围为准。

## 专业提交经验

- 官方建议在可选时优先用 DOC/DOCX，因为 PDF 的章节、脚注和文本层可能造成解析差异；但执行时先服从当前接口 `fileType`。
- 接受修订并删除批注后再上传，避免报告内容混入修改痕迹。
- 参考文献应有明确标题并规范著录；有效识别还取决于正文确有引用、格式正确且原文被比对库收录。
- 作者信息有助于自引识别，不要用“匿名”或占位名代替真实作者，除非用户明确选择匿名且页面支持。
- 职称/已发表材料的收稿或发表时间可能影响时间范围判断；只有当前产品/页面要求时提交，不能编造。

## 报告解读

万方报告会区分总体相似、来源片段，以及当前版本中的参考文献引用与自引等信息。必须使用报告实际字段；检测完成前不能预告最终指标。报告保留期以当前 CQCCJY 页面和接口为准，不照搬万方官网其他渠道的保留天数。
