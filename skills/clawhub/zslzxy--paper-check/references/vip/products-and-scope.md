# 维普产品与检索范围

## 当前接入产品的选择

每次推荐或提交前先执行：

```bash
python3 scripts/paper_check_client.py products --lane vip
```

当前 CQCCJY 目录可能返回以下产品代码；名称、价格、计费单位、限制和是否仍可用均以本次接口结果为准：

| `productType` | 当前产品名 | 适用意图 |
|---|---|---|
| `dxs` | 大学生版 | 本/专科毕业论文 |
| `yjs` | 研究生版 | 硕博学位论文 |
| `bjb` | 编辑部版 | 期刊编辑、未发表稿件等编辑场景 |
| `zc` | 职称版 | 职称评审、已发表材料 |
| `zy` | 作业版 | 课程作业 |
| `ky` | 科研版 | 科研稿件/成果场景 |
| `format_dxs` | 格式检测大学生版 | 格式规范检测，不是文本查重 |
| `aigc` | AIGC | AI 生成内容风险，不是重复率 |

## 官方公开的能力边界

维普公开产品资料将 VPCS 描述为文本相似性/学术不端线索检测，公开的资源类型包括中外期刊、学术会议、硕博学位论文、自建特色资源和互联网资源；机构可配置检测范围与自建库。公开报告指标包括总相似比、引用率、复写率、自写率及来源片段等。

这只是产品能力概述，不等于当前个人产品必然包含每个库。实际解释顺序是：

1. 当前订单报告显示的检测范围；
2. 当前用户端产品说明；
3. 官方公开资料；
4. 其他历史材料仅作背景，不作为承诺。

机构版可有自建库和范围配置，因此个人预检与学校终检不能保证相同。

## 维普结果解读重点

- 先使用报告原名解释总相似比、复写、引用、自引/自写等指标，不自行重算。
- 大段复写和单一来源集中比零散术语命中更值得优先处理。
- 引用识别依赖正文与参考文献结构；“列在参考文献里”不等于正文复用自动合规。
- 产品升级、比对资源库更新会造成结果浮动；当前官方站点曾明确发布升级后结果可能波动的说明。
