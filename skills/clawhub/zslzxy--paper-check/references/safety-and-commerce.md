# 安全、隐私与商业边界

## 不发生的动作

统一 Skill 不自动支付、不预扣余额、不生成支付二维码、不自动购买产品，也不绕过验证码或官方页面。用户明确产品并提交文件后，允许调用对应产品的前置解析/未支付任务接口；任何回答都必须区分“已创建前置任务”和“已正式检测/已支付”。

## 价格

- 只引用产品接口当前返回的公开名称、售价和计价模式。
- 售价是页面当前配置，不是永久承诺；结算以用户在现有页面最终确认的金额为准。
- 不计算隐藏折扣、供应商成本或员工分成，不承诺退款规则。
- 用户要进一步问费用、支付或退款，调用 `guidance` 的答疑接口获取当前公开来源。

## 配置归属

发布配置只配置一个业务归属用户 ID（CQCCJY 为 2，Fanyu 为 77）。每个 lane 另外配置自己的 API 域名和现有用户端入口。外部 Agent 不能改变这些值，也不能通过 `provider` 把请求串到其他产品 lane。

## 论文与任务标识

- 客户端只在需要的产品 lane 上传论文正文；不要把正文复制进 `question`，也不要把文件内容写入日志。
- 不在回答、日志或长期记忆中暴露上传 URL、签名请求头、身份/任务内部字段。
- `order_no` 和结果 URL 是带时效的任务能力，只发给当前用户，不公开传播。
- 不展示服务端配置、数据库标识、供应商凭据、对象键或异常栈。
