# 产品选择决策手册

产品选择不是“哪个查得更严”的竞猜，而是把用户的送检场景与最终审核方的口径对齐。推荐前先确认约束，再读取实时产品目录。

## 先问四个问题

1. **最终审核方指定哪个系统、哪个版本？** 学校、期刊、职称评审单位或导师有明确要求时，直接服从要求，不推荐替代品牌。
2. **文稿是什么类型？** 本/专科、硕博、期刊投稿、已经发表的职称材料、课程作业、专著、科研稿件，分别进入对应产品族。
3. **用户要解决什么问题？** 文本相似性、AIGC 疑似、格式规范、参考文献质量、数据与图像可信度、字符统计是不同任务，不得混成一个“查重”。
4. **现在是预检还是终检？** 预检用于发现问题，终检要尽量保持品牌、版本、文件和提交信息与审核方一致。

只要前两项有一项不明确，就先做咨询，不创建订单。用户只问概念或产品差异时，也不上传文件。

## 决策优先级

按以下顺序判断，前一条覆盖后一条：

1. 审核方书面或页面指定的品牌与版本；
2. 审核方实际使用的产品类型；
3. 论文阶段和用途；
4. 是否需要联合比对库、自建库、发表时间等特定能力；
5. 当前接口实时返回的格式、字符上限和价格；
6. 用户的预算和时间偏好。

不得因为某产品便宜、当前有库存或模型熟悉，就把它描述成指定系统的等价替代品。

## 场景映射

| 场景 | 首选产品族 | 必须补问 |
|---|---|---|
| 本科/专科毕业论文 | 本科、大学生或高职高专版本 | 学校指定品牌；是否为终稿 |
| 硕士/博士学位论文 | 硕博或研究生版本 | 学校指定品牌；是否涉及联合比对库 |
| 期刊投稿/编辑初审 | 期刊或编辑部版本 | 期刊指定系统；稿件是否已公开 |
| 职称评审、已发表论文 | 职称或已发表文献版本 | 收稿/发表时间；评审单位要求 |
| 课程作业 | 作业版或课程作业版 | 是否只是教学预检 |
| 科研稿件/项目成果 | 科研版或与审核方匹配的版本 | 送检用途和保密等级 |
| 专著/长篇作品 | 专著版 | 当前字符上限和支持格式 |
| AI 生成内容风险 | 对应品牌的 AIGC 产品 | 审核方指定品牌、语言、是否只检测正文 |
| 只想知道篇幅 | `character-count` | 无需选择查重品牌 |

## AIGC 的品牌路由

- 明确说“万方 AIGC”时，读取万方目录并选择实时返回的 AIGC 产品代码。
- 明确说“知网 AIGC”时，读取知网目录并选择实时返回的 AIGC 产品代码。
- 明确说“维普 AIGC”或未指定品牌但接受当前维普 AIGC 流程时，走 `aigc` lane；先创建支付草稿，支付后才能上传。
- 只说“查 AI 率”且审核方可能指定系统时，先问品牌，不擅自用任意检测器。

## 推荐表达模板

> 你的【审核方/用途】要求是【要求】。因此优先选【品牌 + 实时产品名】；它与文稿类型匹配。若只是前期自查，可以把其他系统当作风险筛查，但不能承诺与最终审核结果一致。当前价格、格式和字符上限我会从实时产品目录读取后再确认。

## 禁止使用的销售话术

- “这个系统一定最严/最准/和学校百分百一致。”
- “先用便宜系统查到某个比例，另一个系统一定也能过。”
- “个人版必然包含学校自建库。”
- “重复率低就不存在学术不端。”
- “AIGC 比例能证明作者使用了 AI。”
