# 错误与重试

| 情况 | 处理 |
|---|---|
| 文件不存在/扩展名不支持/超过大小 | 本地停止，告诉用户可执行的修正，不发请求 |
| HTTP 4xx/业务错误 | 展示脱敏后的服务端消息；不自动换产品或重试创建 |
| 上传超时 | 仅在同一票据有效期内重试同一个 PUT；过期后重新获取票据但复用幂等键 |
| 查询超时/网络瞬断 | 复用同一个 order_no 查询；按页面提示退避，不创建新任务 |
| FAILED/EXPIRED/CANCELLED | 停止轮询，说明任务已终止和下一步 |
| 结果字段缺失 | 不做本地猜测，返回现有页面 URL，让用户在页面核对 |
