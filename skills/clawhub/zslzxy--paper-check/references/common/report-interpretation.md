# 检测报告专业解读

解读报告的目标不是只报一个百分比，而是回答：哪个指标、哪些片段、命中了什么来源、该如何合规处理。

## 五步解读法

1. **核对身份**：品牌、产品版本、报告编号、题名、作者、检测时间和文件版本是否正确。
2. **核对范围**：报告列出的数据库、联合库/自建库、时间范围和排除设置是什么。
3. **确认指标定义**：先采用报告自身术语和说明，不把三家指标强行改成同一个名字。
4. **定位高风险片段**：看章节分布、连续大段、单一来源集中度和来源性质。
5. **形成处理清单**：区分规范引用、需要重写论证、元数据错误、可解释术语和无需改动的内容。

## 常见指标家族

- **总体相似指标**：全文被系统判为相似内容的汇总比例；不同系统可能称总相似比、总文字复制比等。
- **引用相关指标**：系统识别为引文或参考文献引用的相似部分。写了引号或参考文献不代表系统一定识别，仍取决于格式、正文引用和比对库收录。
- **复写/非引用相似**：与来源相似但未被归为规范引用的部分，通常比单纯总值更需要逐段检查。
- **本人已发表/自引指标**：依赖作者信息和来源识别；自引并不自动等于可以无限复用。
- **单篇最大来源**：观察内容是否过度集中于一个来源，比“多篇零散相似”更能提示结构性风险。
- **章节指标**：用于发现摘要、文献综述、方法、结论等局部高风险，不能只看全文平均值。

只有报告实际出现某指标时才使用对应名称。不要自行计算“原创率 = 100% - 某个指标”，除非报告明确给出同一口径。

## 片段处置分类

| 片段类型 | 建议 |
|---|---|
| 必要定义、法律条文、标准表述 | 核对引用和适用范围；不要为了降重歪曲含义 |
| 直接引用 | 使用规范引号/引文格式并提供准确来源；控制引用比例 |
| 文献综述 | 按主题综合多来源并加入评价，不逐篇拼接摘要 |
| 方法与实验步骤 | 区分通行方法和本研究具体设计，补充来源与自己的参数选择理由 |
| 数据与结论 | 不得虚构或改写事实；用原始数据、推理过程和限制说明支撑 |
| 与本人既有成果相似 | 明确引用本人作品，避免重复发表或不当自我复制 |
| 大段单一来源 | 回到研究问题重构论证，不能只做同义词替换 |

## 阈值回答规则

“多少算合格”只能由学校、期刊、评审单位或当前产品明确规则回答。Skill 可以帮助用户读取要求并解释报告，但不得创造通用的 10%、15%、20% 合格线，也不得把系统页面的展示阈值说成学术不端认定标准。

## AIGC 报告

AIGC 疑似比例/片段是模型风险提示，不是文本相似指标，也不能单独证明使用了某个模型。解读时同时检查语言、文本长度、公式/引文、模板化表达和模型版本；建议保留研究笔记、数据、版本记录和引用证据，用人工审查补足模型结论。

## 输出模板

> 这份报告来自【品牌/版本】，检测时间为【时间】。本次应重点看【报告原名指标】，全文值为【值】；风险主要集中在【章节/片段】，相似来源以【来源类型或单篇来源】为主。建议先处理【最高风险问题】，并核对【引用/作者/时间/文件格式】。该结果是相似性线索，不等同于学术不端认定；是否达标以【学校/期刊规则】为准。
