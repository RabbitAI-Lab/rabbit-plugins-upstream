# 字符统计标准

## 用户可见名称

真实文件统计的主名称固定为：**字符数（不计空格）**。不要简写成“汉字数”“字数”或“英文单词数”。

## 两种口径必须分开

- **Word 字符数（不计空格）**：Word 的统计指标，通常排除空格字符，但具体版本对脚注、文本框、域和隐藏内容可能有差异。
- **维普解析字符数（不计空格）**：本 Skill 的 `character-count` lane 由维普解析服务返回，使用 `word_count`/等价字段。它不是本地估算，也不自动等于其他品牌的查重计费字数。

文件、表格、公式、脚注和引用范围不同，会使 Word 与供应商数字不一致。没有真实解析结果时，不给出“精确维普字符数”。

## 处理要求

1. 具体文件 + “多少字符/多少字/篇幅” → 调用维普字符统计异步任务。
2. 纯概念 + 无文件 → 只解释上述口径，不创建任务。
3. 成功结果必须来自维普文件解析接口，并展示 `word_count` 和浏览器结果地址；接口没有返回的精度或估算标志不得自行补充。
4. 字符统计不提交正式查重、不自动支付、不创建检测报告。
