# 论文查重与检测知识

## 术语边界

- **相似度/重复率**：检测系统按照自己的数据库、切分算法、引用识别和阈值规则，对文本片段相似情况计算出的指标。它不是“抄袭判决”，也不能脱离报告明细解释。
- **检测版本**：维普、万方、知网及同一品牌的本科/硕博/期刊/AIGC/格式等版本是不同商品。必须以实时产品目录的 `productType`/`productCode` 为准，不能由模型猜测。
- **字符/计费字数**：解析服务中的计费字段可能受正文范围、表格、公式、脚注和格式影响；不能用本地 `len(text)` 或 Word 页面数代替供应商结果。
- **报告**：只有任务状态和服务端字段明确说明报告可用时，才称为“报告已生成/可下载”。创建任务、解析完成、支付成功、供应商提交和报告生成是不同阶段。

## 解读原则

1. 先确认产品和版本，再解释指标；同一篇文章在不同数据库的数值不应直接比较。
2. 报告中的总相似度、去除引用、单篇最大来源等字段必须原样标注来源，不能做二次四舍五入或承诺达标。
3. 用户只要求计数时走 `character-count`，不创建查重订单；用户要求检测时必须先选择品牌/版本。
4. 检测结果受提交版本、数据库更新、引用格式和时间影响。Skill 只负责准确提交和展示服务端结果，不承诺“必过学校系统”。
5. 检索范围的解释按“当前报告 → 当前产品页面/接口 → 厂商官方资料”取证；产品定位、联合比对库和机构自建库不能混为一谈。
6. 厂商未公开的算法阈值、固定字符长度和权重不得根据网络传言补全。

## 不应做的事

- 不把 AIGC 分数说成重复率，也不把重复率说成抄袭结论。
- 不伪造结果、改写报告、绕过验证码或自动支付。
- 不从模型记忆填写价格、时效、退款和当前产品限制；检索范围必须引用当前报告、用户端页面或厂商官方资料，并说明适用版本。
