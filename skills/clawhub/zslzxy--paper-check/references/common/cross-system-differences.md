# 不同系统结果差异诊断

同一篇论文在维普、万方、知网之间数值不同是预期现象；同一品牌前后两次也可能变化。不要先判断谁“错了”，先按变量逐项排查。

## 八类差异来源

| 变量 | 典型影响 | 诊断方法 |
|---|---|---|
| 品牌与产品版本 | 比对资源、专用库、指标规则不同 | 对照订单中的品牌、产品代码和报告检测范围 |
| 机构版与个人版 | 机构可能配置自建库、联合库、排除规则 | 询问学校/期刊实际版本，不承诺个人预检等同终检 |
| 数据库更新时间 | 新发表、网络或联合库内容加入后命中变化 | 对照两份报告检测日期和来源文献 |
| 文件版本 | 目录、致谢、附录、声明或修改内容不同 | 比较文件哈希、字符数和章节 |
| 文件格式与解析 | PDF 换行、扫描层、脚注、公式、文本框可能解析不同 | 优先按实时支持格式提交；可用 DOCX 复核解析 |
| 标题、作者、时间 | 影响自引识别、已发表文献判断或报告元数据 | 填写真实题名、作者、收稿/发表时间 |
| 引用与参考文献格式 | 影响引文和参考文献识别 | 检查“参考文献”标题、著录格式、正文引用对应关系 |
| 检测范围与排除项 | 总指标口径不同 | 比较总相似、排除引用、排除本人、单一来源等同口径指标 |

## 专业比较方法

只有满足以下条件时，两个数值才值得直接讨论：

1. 同一文件内容和格式；
2. 同一品牌、同一产品版本；
3. 相近检测时间；
4. 相同题名、作者和时间信息；
5. 相同检索范围与排除设置；
6. 比较的是同名、同定义指标。

否则应该比较“风险片段和来源”，而不是纠结百分点差异。

## 常见问答

### “预检很低，学校为什么更高？”

先检查学校是否使用了不同品牌/版本、机构自建库或联合比对库，再检查最终提交文件和引用格式。预检是风险筛查，不能作为学校结果保证。

### “为什么 PDF 和 Word 不一样？”

两种格式的章节结构、换行、脚注和文本层可能被不同解析。只要当前产品支持，通常优先提交结构清晰、已接受修订且已删除批注的 DOC/DOCX；最终仍服从审核方格式要求。

### “为什么第二天重查变了？”

数据库、算法或产品配置可能更新；文件与元数据也可能变化。维普官方升级公告和知网协议都明确体现了资源/系统更新可能造成结果浮动。

### “哪个系统更严格？”

“严格”没有跨系统统一量尺。专业答案是指出它们的目标版本、比对范围和报告口径，而不是给品牌排固定高低。
