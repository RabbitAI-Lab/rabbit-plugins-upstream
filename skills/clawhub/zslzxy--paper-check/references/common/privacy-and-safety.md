# 隐私、安全与额度

- 上传前明确说明文件会交给 CQCCJY 对应检测服务解析/处理，用户未同意时不上传。
- 当前公开配置不要求用户登录、MCP 授权或 API Key；这不等于可以绕过站点现有风控和业务规则。
- 每个环境固定员工归属：CQCCJY 员工2，Fanyu 员工77。调用方不能覆盖。
- 服务端每日新任务上限固定 50 次，单文件大小和扩展名以配置与接口返回为准。
- 不记录论文正文、签名上传地址、Cookie、Authorization、对象存储键或完整异常栈。
- 不自动支付、自动扣余额、重复上传、批量猜测产品、绕过验证码或伪造报告真伪。
- 报告验真遇到验证码、人工审核或页面不可用时，明确说“无法自动判断”，并提供官方入口。
