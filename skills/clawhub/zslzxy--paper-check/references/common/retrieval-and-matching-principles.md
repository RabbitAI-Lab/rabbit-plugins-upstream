# 检索范围与相似性识别原理

本文件用于专业解释，不代表披露厂商内部算法。除非厂商官方资料或当前报告明确说明，不要把行业通用流程说成维普、万方或知网的专有实现。

## “检索范围”包含什么

检索范围至少有四层，回答时不能只罗列数据库名称：

1. **资源类型**：期刊、学位论文、会议、报纸、图书、专利、标准、互联网学术资源等。
2. **专用比对库**：大学生/硕博论文联合比对库、机构自建库、个人自建库、同批次互检库等；是否包含取决于版本和机构配置。
3. **时间边界**：资源库更新时间、用户选择的截止时间、职称稿件的收稿/发表时间都会改变候选文献。
4. **送检范围**：系统从文件中实际解析出的正文、引用、参考文献、脚注、表格和公式；解析不到的内容不会凭空参与比对。

因此，“两个页面都写了期刊库”不代表实际资源、更新时间、版本权限和命中结果相同。

## 行业级处理链路

可以用下面的概念链路解释相似性检测：

1. **文件解析**：从 DOC/DOCX/PDF/TXT 等文件提取可检测文本，识别章节和元数据。
2. **文本预处理**：规范字符、切分句段，尝试识别参考文献、引文、作者和非正文区域。
3. **候选检索**：用字词、指纹、倒排索引、语义特征等方法，从大规模比对库找出可能相关的候选来源。
4. **片段比对**：对送检片段与候选来源做更细的相似性判断，记录来源、位置和相似片段。
5. **归类与排除**：按报告规则区分复写、引用、自引、专业术语或排除项。
6. **指标汇总**：按系统当期规则汇总全文与章节指标并生成报告。

这说明检测不是简单的全文字符串搜索，也不是“碰到固定连续字数就一律标红”。特别是流传的“知网连续 13 个字相同就算重复”等说法，不应当作当前官方规则；没有实时官方依据时必须明确为未经证实的经验说法。

## 厂商公开说明可说到什么程度

- 维普公开产品资料描述过动态语义、文本指纹、片段切分、参考文献预处理和字词句段综合比对；只能据此说明其公开技术方向，不能推导具体阈值。
- 万方公开资料描述过句子级语义检索/相似性算法和文本预处理，并明确支持中英文相似性检测；不能据此承诺任意文本都能识别。
- 知网当前公开使用协议明确说明，送检文献会与用户选择的资源库和时间范围比对；未公开的阈值、切分长度和权重不可猜测。

## 为什么改几个词不一定解决问题

检测可能同时观察词汇、句法、片段结构、语义或来源聚集情况。机械替换同义词、颠倒语序或插入无意义字符既可能仍被识别，也可能破坏论证质量。专业建议应是：

1. 回到原始来源，确认自己是否真正理解；
2. 需要引用的内容按规范引用并标明来源；
3. 用自己的论证结构重新组织，而不是逐句“洗稿”；
4. 数据、结论、专有定义不可为降指标而歪曲；
5. 修改后用最终版本、同一产品重新检测。

## 回答边界

- 报告中显示的“检测范围”优先于本文件的概述。
- 当前产品页面/接口优先于历史官方宣传页。
- 涉及机构自建库或联合比对库时，没有报告或机构说明就回答“无法确认”。
- 检测报告只能提供相似性线索，学术不端认定仍需规则与人工判断。
