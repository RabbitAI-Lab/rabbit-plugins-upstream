# 竞品页失败时的有限交付

这是离线构造的失败边界示例，不是线上故障或真实用户案例。输入 [failure-input.json](../failure-input.json) 中，青禾产品 HTML 可读；杉木记录为 `failed`、原因为 `simulated_timeout`。只交付这些输入支持的内容，杉木所有页面内容指标保留“未验证”，不写成 0 分。

| 检查项 | 青禾（模拟可读） | 杉木 |
| --- | --- | --- |
| 可识别问答对 | 0 | 未验证 |
| 匹配品牌 Organization | 1 | 未验证 |
| 来源区域外链候选 | 0 | 未验证 |
| 可计算的双方差距 | 不可计算 | 不可计算 |

[CSV](竞品差距矩阵.csv) 保留矩阵，[evidence.json](evidence.json) 中 `comparisons[0].competitor_minus_brand` 为 `null`。这不是青禾胜过杉木的证据。

## 三项执行安排

1. **恢复竞品同槽位证据，优先级高。** 由分析负责人取得杉木同一产品页的一份可读 HTML 导出或实际获取记录，保留 URL、时间、最终 URL 和状态；取得一份即可停止补证，不扩大站点扫描。未恢复前不评判其 FAQ、实体或来源能力；恢复后重新比较该槽位。
2. **核实青禾导入说明的自有改进，优先级中。** 当前可读页只说支持 CSV、详细字段联系支持。产品支持与编辑确认字段及失败处理后，可将其写成完整页内说明。这是来自品牌自身页面的改进建议，尚不能称为竞品差距。验收以步骤可执行、信息属实为准。
3. **补充真实 AI 样本，按需执行。** 输入包含一次 `query_failed`、一次 `not_run` 和一次 `simulated` 回答，真实回答分母和原生引用分母均为 0，真实引用总数为 `null`。分析负责人若要回答“谁被 AI 引用”，先取得固定问题下的真实回答及原生来源导出；若该问题不在本次范围，保留“AI 引用未实测”即可结束。不把失败和模拟记为零引用，也不提供排名。
