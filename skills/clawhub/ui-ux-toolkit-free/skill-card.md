## Description: <br>
A searchable UI/UX design database that lets personal developers query styles, color palettes, typography, UX rules, and Tailwind-oriented guidance for basic design systems. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[thcjp](https://clawhub.ai/user/thcjp) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers use this skill to look up UI/UX design resources, generate basic design-system recommendations, and get html-tailwind implementation guidance for personal projects. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill asks agents to run local Python search commands, but the package evidence only includes SKILL.md and no scripts/search.py file. <br>
Mitigation: Confirm the referenced script exists in the installed package and review each command before execution. <br>
Risk: Generated design guidance may be incomplete for complex product, accessibility, or brand requirements. <br>
Mitigation: Review recommendations against project requirements, accessibility expectations, and human design judgment before implementation. <br>
