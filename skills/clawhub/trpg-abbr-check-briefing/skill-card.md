## Description: <br>
Use this skill when checking and fixing English abbreviations in a briefing_package. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[ice26985850](https://clawhub.ai/user/ice26985850) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
TRPG authors and maintainers use this skill to review briefing packages, rules, scenarios, and related YAML or Markdown files so player-facing English abbreviations include Chinese full terms. It helps agents make consistent abbreviation fixes while preserving technical keys, formulas, and documented table exceptions. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad abbreviation fixes may change many briefing, rule, scenario, and configuration files in one pass. <br>
Mitigation: Specify the exact folder or files to edit and review the resulting diff before accepting changes. <br>
