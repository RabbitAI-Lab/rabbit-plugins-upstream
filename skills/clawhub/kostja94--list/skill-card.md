## Description:

Guides list layout design for compact, linear content displays such as blog indexes, documentation lists, and search results.

This skill is ready for commercial/non-commercial use.

## Publisher:

### License/Terms of Use:

MIT-0

## Use Case:

Developers and designers use this skill to choose, structure, and review list layouts for text-heavy content where users scan titles, metadata, excerpts, and links.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate for broad list-design requests where a more specific skill is better suited, such as blog indexes, grids, cards, or crawlability-specific work.

Mitigation: Use the more specific related skill when the request focuses on blog-page generation, grid layout, card structure, or search crawlability.

Risk: Infinite scroll can make list content unavailable to crawlers.

Mitigation: Use paginated component pages or traditional pagination for SEO-critical list content.
