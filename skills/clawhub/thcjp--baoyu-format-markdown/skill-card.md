## Description: <br>
Formats plain text or Markdown files with frontmatter, titles, summaries, headings, bold text, and lists for structured content workflows. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, content teams, and workflow builders use this skill to have an agent format provided text or Markdown into cleaner structured Markdown for marketing, advertising, conversion, and growth content workflows. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill requests shell-command access for a task that usually only requires reading and editing Markdown. <br>
Mitigation: Review before installation and prefer a narrowed version that limits authority to Markdown reading and editing unless shell execution is explicitly needed. <br>
Risk: Broad, generic execution instructions may lead to unsuitable or misleading formatting changes. <br>
Mitigation: Provide explicit formatting goals and review the generated Markdown before publishing or using it in marketing workflows. <br>
