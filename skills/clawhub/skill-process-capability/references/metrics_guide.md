## 概述

过程能力分析是质量管理的重要工具，用于评估生产过程满足规格要求的能力。

### 核心公式框架

| 指标类型 | 计算公式 | 适用场景 |
|---------|---------|---------|
| CP/CPK | (USL-LSL)/(6σ) | 短期能力(组内变异) |
| PP/PPK | (USL-LSL)/(6σ) | 长期能力(整体变异) |
| CMK | 机器能力指数 | 单一机器/工位 |

### 数据要求

- **最小样本量**: 建议≥30个样本点
- **数据分布**: 独立同分布
- **规格限**: 必须明确USL/LSL

## 过程能力指数(CP系列)

### CP(过程能力指数)

```
CP = (USL - LSL) / (6σ)
```

- **含义**: 过程在理想状态(均值居中)下的潜在能力
- **特点**: 反映过程的"最大能力"，不考虑偏移

### CPK(过程能力指数-修正)

```
CPK = min(CPU, CPL)
CPU = (USL - μ) / (3σ)
CPL = (μ - LSL) / (3σ)
```

- **含义**: 考虑过程均值偏移后的实际能力
- **解读**: CPK ≤ CP，等于CP时表示均值居中

### K(偏移系数)

```
K = |μ - T| / ((USL - LSL) / 2)
其中 T = (USL + LSL) / 2 (目标值)
```

- **范围**: 0 ≤ K ≤ 1
- **含义**: 均值偏离目标值的程度

### 修正后的CPK

```
CPK_corrected = CP × (1 - K)
```

## 过程性能指数(PP系列)

### PP

```
PP = (USL - LSL) / (6σ_long)
```

- **特点**: 使用整体标准差(σ_long = σ_n-1)
- **与CP区别**: 反映长期整体性能，包含所有变异来源

### PPK

```
PPK = min(PPu, PPl)
PPu = (USL - μ) / (3σ_long)
PPl = (μ - LSL) / (3σ_long)
```

### CP与PP的关系

| 关系 | 含义 |
|-----|------|
| CP > PP | 短期波动小于长期波动，过程较稳定 |
| CP < PP | 存在异常波动源，需调查 |
| CP ≈ PP | 过程稳定，短期=长期 |

## 辅助指标

### CMK(机器能力指数)

```
CMK = min(CMU, CML)
CMU = (USL - μ) / (3σ_m)
CML = (μ - LSL) / (3σ_m)
```

- **σ_m**: 使用极差法估算的机器短期变异
- **特点**: 仅考虑机器本身，不含操作员、材料等影响

### CPM(目标能力指数)

```
CPM = (USL - LSL) / (6σ_t)
其中 σ_t = sqrt(σ² + (μ - T)²)
```

- 考虑了均值偏离目标的影响

## PPM与合格率

### PPM计算

基于正态分布假设:

```
PPM_upper = (1 - Φ((USL - μ) / σ)) × 10⁶
PPM_lower = Φ((LSL - μ) / σ) × 10⁶
PPM_total = PPM_upper + PPM_lower
```

### 合格率换算

| PPM | 合格率(%) | 等级 |
|-----|----------|------|
| 0.27 | 99.99973 | 6σ |
| 3.4 | 99.99966 | 4.5σ |
| 66.8 | 99.9933 | 4σ |
| 2,700 | 99.73 | 3σ |
| 66,807 | 93.32 | 2σ |

## 分布拟合检验

### 正态性检验

#### Kolmogorov-Smirnov检验

```
H0: 数据服从正态分布
H1: 数据不服从正态分布
p-value > 0.05 → 不拒绝H0，认为正态
```

#### Shapiro-Wilk检验

- 适用于样本量 n < 5000
- 更适合小样本检验

### 二项分布拟合

适用于计数型数据(不合格品数):

```
参数: n (样本量), p (不合格率)
估计: p̂ = x̄ / n
```

### 泊松分布拟合

适用于稀有事件(缺陷数):

```
参数: λ (平均缺陷数)
估计: λ̂ = x̄
```

## 指标等级判定

### 通用等级标准

| 等级 | CPK范围 | 评价 | 建议 |
|-----|--------|------|-----|
| A | ≥ 2.00 | 优秀 | 保持现状 |
| B | 1.67 - 2.00 | 很好 | 继续监控 |
| C | 1.33 - 1.67 | 良好 | 保持 |
| D | 1.00 - 1.33 | 合格 | 改善 |
| E | 0.67 - 1.00 | 差 | 必须改善 |
| F | < 0.67 | 很差 | 紧急改善 |

### 行业标准对照

| 行业 | 最低要求 | 说明 |
|-----|---------|-----|
| 汽车(IATF 16949) | CPK ≥ 1.33 | 关键特性 |
| 六西格玛 | CPK ≥ 2.00 | 追求目标 |
| 一般制造 | CPK ≥ 1.00 | 最低要求 |
| 医药 | CPK ≥ 1.45 | FDA要求 |

## 常见问题

### 1. CPK为负数
- 原因: 过程均值超出规格限
- 处理: 必须先调整过程中心

### 2. CP很大但CPK很小
- 原因: 过程波动小但均值偏移大
- 处理: 调整过程均值至规格中心

### 3. CP<1但满足规格要求
- 原因: 短期波动大，但均值居中
- 处理: 需同时改善偏移和波动
