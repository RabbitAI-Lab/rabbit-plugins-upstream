## Working memory — read at the start of a session
**`WORKING.md`** at the repo root holds the current stage's state (decision log, dead ends, next steps). Read it before acting. During work, append meaningful decisions (1–3 lines) — don't wait for session end. At stage end, distill settled conclusions into long-term memory and reset the file. (A working thread in a subfolder may have its own WORKING.md.)
