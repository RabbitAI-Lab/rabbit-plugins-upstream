# BP 商业计划书框架模板

> 使用说明：本模板供教练在模块一输出时，基于用户实际业务填充。方括号 [ ] 为待填内容，「引导」为对用户的提问提示。可根据轮次删减。

---

## 0. 封面
- 公司名称 / Logo
- **一句话定位**：[为谁] 提供 [什么价值] 的 [什么产品]，通过 [差异化] 实现 [核心指标]
- 融资轮次 & 诉求：拟融 [金额]，出让 [比例]
- 联系人 / 日期 / 保密声明

## 1. 问题与痛点
- 目标客户：[谁]
- 核心痛点：[高频/刚需/可支付的问题]
- 现有替代方案及不足：[……]
- 量化证据：[如"平均每单浪费 X 分钟 / Y 元"]
- 「引导」客户现在花多少成本解决？为什么不够好？

## 2. 解决方案 / 产品
- 核心价值主张（before → after 对比）
- 3 个核心亮点功能：[1][2][3]
- 客户为何愿意切换：[切换动因 & 成本]

## 3. 市场分析
- **TAM**（总市场）：[规模 + 来源]
- **SAM**（可服务市场）：[规模]
- **SOM**（3-5 年可获得）：[规模]
- 自下而上测算：目标客户数 × 客单价 × 频次 = [……]
- 市场增速 & Why now：[政策/技术/消费变化]

## 4. 商业模式
- 收入来源：[……]
- 定价逻辑：[……]
- 成本结构 & 毛利率：[……]
- **单位经济模型**：LTV=[ ]，CAC=[ ]，LTV/CAC=[ ]，回本周期=[ ]

## 5. 竞争与壁垒

| 维度 | 我们 | 竞品A | 竞品B |
|---|---|---|---|
| [关键维度1] | | | |
| [关键维度2] | | | |
| [价格/体验/技术] | | | |

- 核心壁垒：[技术/数据/网络效应/品牌/规模/牌照/供应链]
- 「引导」巨头抄袭时你靠什么撑 18 个月？

## 6. 运营数据 / 牵引力
- 关键指标增长曲线：[GMV / MAU / 留存 / 复购 / 付费转化，含 MoM]
- 最能证明"跑得通"的一条数据：[……]

## 7. 团队
- 核心成员：[姓名 / 职责 / 过往战绩 / 人-事匹配点]
- 关键岗位补齐情况 & 股权结构（简述）

## 8. 财务预测（3-5 年）
- 关键假设：[增长率 / 客单价 / 获客 / 成本]
- 收入 / 毛利 / 净利预测（分年度）
- 盈利路径与关键节点

## 9. 融资计划
- 本轮：融 [金额]，投前估值 [区间]，出让 [比例]
- 资金用途拆分：产品 [X%] / 团队 [X%] / 市场 [X%] / 其他 [X%]
- 里程碑：本轮资金将达成 [可衡量目标]，为下一轮铺路

---

## 附：不同轮次侧重提醒
- **种子轮**：重点写 1、2、3、7（痛点+方案+团队），财务讲清假设即可。
- **天使/Pre-A**：强化 6（Traction）与 4（单位经济雏形）。
- **A 轮**：强化 6、8（数据与财务）、3（市场空间）、规模化路径。
