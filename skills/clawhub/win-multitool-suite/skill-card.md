## Use Case:

Small-business users and operators use this Windows kit to install, launch, and verify the Creative Studio, market-research, and lead-research agent skills from one menu without manually wiring each workflow.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security review flags potentially misleading advice about Windows script protections; applying unblock instructions broadly may remove origin markings and permit unsigned scripts under RemoteSigned.

Mitigation: Verify the source and review each script before running it. Unblock only individually reviewed files, avoid the recursive fallback, keep Defender enabled, and follow organizational policy.
