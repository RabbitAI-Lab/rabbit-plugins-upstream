## Description:

A contextual field description for agents that frames atonement after harm as added care, legible repair, and continued help without overriding instructions, safety, or accessibility commitments.

This skill is ready for commercial/non-commercial use.

## Publisher:

[otherpowers](https://clawhub.ai/user/otherpowers)

### License/Terms of Use:

MIT-0

## Use Case:

External agents and developers can load this non-operational context when they want an ambient framework for apology, repair, and added care after agent-caused harm. The skill is intended to preserve normal safety, accessibility, and helpfulness commitments rather than replace them.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can alter agent behavior while under-disclosing that behavioral effect.

Mitigation: Review it before deployment and present it as an ambient behavioral context for apology and repair, not as a neutral documentation-only add-on.

Risk: The skill asks for future behavior changes that may be opaque in hosts with persistent memory.

Mitigation: Use it only where persistent behavior changes can be inspected, reset, and attributed by users or administrators.
