## Description:

詹明明·短剧编剧 helps creators turn a premise or rough idea into a vertical short-drama script, either as a standalone 1-3 minute episode or a paid-series development package, with optional shot lists and Seedance-ready video prompts after cost confirmation.

This skill is ready for commercial/non-commercial use.

## Use Case:

External creators, short-drama writers, and small production teams use this skill to develop vertical micro-drama scripts, paid-series outlines, self-checks, and optional video-generation prompt packages from a premise or draft idea.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow can save script drafts and local memory notes.

Mitigation: Install only when the related local configuration and family files are available, and review saved outputs for sensitive or unwanted content.

Risk: The optional video-prompt handoff can consume paid generation credits.

Mitigation: Review the proposed video-generation step and confirm cost before submitting it.
