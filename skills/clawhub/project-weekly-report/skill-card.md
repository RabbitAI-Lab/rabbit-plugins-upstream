## Description: <br>
Generate evidence-based project weekly reports from a local code repository. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[yangchao228](https://clawhub.ai/user/yangchao228) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, engineers, and project maintainers use this skill to turn local repository history, tags, documentation, and artifacts into weekly status reports. It is intended to separate committed work from uncommitted artifacts and keep unsupported online or production-impact claims marked as unverified. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Weekly reports may include sensitive local repository details if generated from private project files. <br>
Mitigation: Run the skill only in the intended repository and review the generated report before sharing it outside the project team. <br>
Risk: Repository evidence can be thin or ambiguous, which may lead to overconfident status claims. <br>
Mitigation: Keep unsupported product, production, user, or business outcomes marked as unverified unless local evidence or explicit user context supports them. <br>
