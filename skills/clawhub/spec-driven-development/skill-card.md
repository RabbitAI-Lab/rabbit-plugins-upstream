This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to turn early project, feature, or change requests into structured specifications before implementation, especially when requirements are unclear or incomplete.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill requests broad command, file, API, and credential-related authority that is not well scoped to writing specifications.

Mitigation: Use it only in a constrained environment and require explicit approval before it runs commands or processes local files.

Risk: The skill appears to be generic generated content rather than a tightly scoped spec-writing assistant.

Mitigation: Review the skill carefully before installing and confirm that its behavior matches the intended specification workflow.

Risk: Credential-related behavior is mentioned without a clearly identified external service.

Mitigation: Avoid providing real API keys unless the target service and required calls are known and approved.
