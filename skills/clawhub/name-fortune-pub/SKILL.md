# 姓名学 · 81数理吉凶

> 初五数智出品 | 命理系列

## 功能

姓名学是研究姓名与命运关系的学问：

1. **五格剖象法**：
   - 天格（姓氏笔画+1）：先天运
   - 人格（姓末字+名首字）：主运
   - 地格（名字笔画之和）：前运
   - 外格（总格-人格+1）：社交运
   - 总格（姓名总笔画）：后运
2. **81数理吉凶**：每个数理对应吉/凶/半吉
3. **三才配置**：天格/人格/地格的五行生克关系
4. **姓名五行**：字的五行属性与八字喜用的配合

## 使用方式

「帮我分析一下名字张三的五格数理」
「我叫李明远，这个名字好不好？」
「给宝宝起名，姓王，五行喜用是木火」

## 温馨提示

姓名学是传统文化的一部分，仅供参考。好名字不如好品行。
