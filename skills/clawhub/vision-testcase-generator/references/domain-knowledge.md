# 视觉领域测试知识库（Vision Domain Knowledge）

> 本文件是 `vision-testcase-generator` 的领域知识底座。生成用例前通读一遍；
> 具体阶段二/三的**方法选择与质量属性表以内联在 SKILL.md 的为准**，本文件提供背景知识、指标定义与测试要点。

---

## 1. 知识体系总览

机器视觉测试 = **成像系统认知 + 算法评测指标 + 数据/样本管理 + 鲁棒性与性能验证**。

```
机器视觉测试能力模型
├── ① 成像系统（工业相机、镜头、光源、采集卡）
├── ② 算法功能（缺陷检测、定位、测量、识别、OCR、读码、3D）
├── ③ 评测指标（准确率、误检率/漏检率、精度、重复性、鲁棒性）
├── ④ 数据集（样本量、标注质量、正负样本平衡、过拟合）
└── ⑤ 性能（帧率、处理延迟、吞吐、并发、长时间稳定）
```

## 2. 成像系统与测试关注点

| 组件 | 说明 | 测试关注点 |
|---|---|---|
| 工业相机 | 面阵/线扫、分辨率、帧率 | 分辨率、帧率、曝光/增益、坏点、触发 |
| 镜头 | 焦距、光圈、景深、畸变 | 畸变、分辨率匹配、景深范围、对焦 |
| 光源 | 环形/条形/同轴/背光 | 均匀性、亮度可调、频闪、过曝/欠曝 |
| 采集卡 | 接口（GigE/USB3/CameraLink） | 带宽、丢帧、触发同步 |
| 算法平台 | Halcon/OpenCV/VisionPro 等 | 算法行为、版本兼容 |

## 3. 核心评测指标（用例验证标准）

| 指标 | 定义 | 测试用例示例 |
|---|---|---|
| 准确率 | 正确判定占比 | 1000 张样本判定准确率 ≥ 99.5% |
| 误检率（FPR） | 良品误判为不良的比例 | 误检率 ≤ 0.5% |
| 漏检率（FNR） | 不良品漏判为良品的比例 | 漏检率 ≤ 0.1% |
| 精度/重复性 | 测量/定位结果的偏差与波动 | 重复 30 次标准差 ≤ 0.02mm |
| 鲁棒性 | 光照/角度/遮挡/模糊/噪声下的稳定性 | 各干扰条件下准确率 ≥ 95% |
| 处理延迟 | 单张图像处理耗时 | P95 ≤ 50ms |
| 吞吐/帧率 | 单位时间处理能力 | ≥ 20 fps |
| 过拟合 | 训练集好、新样本差 | 独立测试集验证 |

## 4. 功能测试要点（按算法）

| 功能 | 测试要点 |
|---|---|
| 缺陷检测 | 缺陷类型覆盖（划痕/脏污/缺角/气泡）、阈值边界、微小缺陷极限 |
| 视觉定位 | 定位精度、旋转/缩放变化、遮挡部分定位、多目标定位 |
| 尺寸测量 | 量程边界、单位换算、标定系数、公差边界（±0.01mm 级） |
| OCR | 字符集覆盖、字体/字号变化、模糊/倾斜、误读率 |
| 读码 | 码制覆盖、破损/遮挡/反光、最小码尺寸、读取率 |
| 3D 视觉 | 点云有效性、深度精度、遮挡/阴影、平面拟合 |

## 5. 鲁棒性测试维度（核心层必测）

| 干扰维度 | 测试用例示例 |
|---|---|
| 光照变化 | 亮度 ±30%、强反光、阴影、频闪 |
| 角度/位姿 | 倾斜 ±10°、旋转、高度变化 |
| 遮挡/污染 | 局部遮挡、油污、灰尘、雾 |
| 图像质量 | 模糊、噪声、压缩、低分辨率 |
| 材质差异 | 高反光/哑光/透明/同色系 |
| 环境干扰 | 震动、外部光源、电磁干扰 |

## 6. 数据与样本管理测试要点

- **样本覆盖**：正/负样本比例、各缺陷类型样本量、边界样本
- **标注质量**：标注一致性（多人标注校验）、标注错误率
- **数据集划分**：训练/验证/测试独立，测试集不参与调参
- **过拟合检查**：独立测试集准确率 vs 训练集准确率差距
- **数据版本**：数据集版本管理、可复现性

## 7. 性能与稳定性测试要点

- 单张处理延迟、批量吞吐、多线程并发
- 长时间运行（≥8h/7×24）内存泄漏、帧率衰减
- 相机断连重连、采集卡丢帧
- 高负载下（满帧率+高分辨率）资源占用

## 9. 评测指标计算公式与口径

以缺陷检测为例（P=不良，N=良品）：

| 指标 | 公式 | 说明 |
|---|---|---|
| 准确率 Accuracy | (TP+TN)/(TP+FP+FN+TN) | 总体判定正确比例 |
| 漏检率 FNR | FN/(TP+FN) | 不良品漏判为良品比例，**重点指标** |
| 误检率 FPR | FP/(TN+FP) | 良品误判为不良比例 |
| 精确率 Precision | TP/(TP+FP) | 检出为不良中的真实不良比例 |
| 召回率 Recall | TP/(TP+FN) | 与漏检率互补（Recall = 1 - FNR） |
| 重复性 | 同一目标重复测量 N 次的标准差 | 测量/定位稳定性（如 ≤ 0.02mm） |

**口径注意**：指标必须注明样本构成与判定口径（逐像素 vs 逐目标 vs 逐图），否则不可比；验收时使用独立测试集。

## 10. 相机/光源测试要点

| 对象 | 测试要点 |
|---|---|
| 相机分辨率 | 标称分辨率实测、坏点/坏列检测 |
| 帧率 | 满分辨率实测帧率、触发模式帧率 |
| 曝光/增益 | 曝光范围、增益噪声（高增益噪点）、自动曝光收敛 |
| 触发 | 硬触发延迟、触发抖动、丢触发 |
| 镜头 | 畸变（桶形/枕形）、景深范围、中心/边缘分辨率 |
| 光源 | 均匀性（中心 vs 边缘亮度差）、亮度调节范围、频闪频率 |
| 成像质量 | 过曝/欠曝、反光抑制、运动模糊 |

## 11. 视觉专项测试速查

| 专项 | 标准/设备 | 关键验收点 |
|---|---|---|
| 标定 | 标定板/标定软件 | 重投影误差 ≤0.1px、手眼标定精度、多相机坐标一致 |
| 成像质量 | USAF 1951 分辨率测试卡 | 分辨率达标、畸变 <0.5%、SNR/动态范围、坏点检出 |
| 光源 | 光源控制器/照度计 | 均匀性 ≥90%、无频闪、亮度稳定性 ±2% |
| 算法评测 | 数据集/评测脚本 | FNR/FPR 达标、独立测试集、过拟合检查 |
| 性能 | 高速相机/打点统计 | 帧率达标、P95 延迟、吞吐、多相机同步偏差 |
| 稳定性 | 长时间运行监控 | 8h/24h 无内存泄漏、精度漂移在允许范围、断连自动恢复 |
| 3D 视觉 | 点云采集设备 | 点云精度、深度噪声、平面拟合误差、体积测量偏差 |

## 12. 标准与规范体系（国标/行标/企标）

机器视觉检测领域**专门国标较少**，测试依据以「国际图像质量标准 + 企标/甲方验收规范」为主：

| 层级 | 示例 | 测试意义 |
|---|---|---|
| 国际图像质量 | ISO 12233（分辨率测试卡）、ISO 15739（图像噪声） | 成像质量验收依据 |
| 国标/设备安全 | GB 4793.1（测量控制电气设备安全） | 设备电气安全 |
| 企标/甲方规范 | 相机厂商 SDK 规范、甲方检测验收规范 | **主要验收线** |

**处理原则**：甲方验收规范/企标是主要验收依据；漏检率/误检率/精度/帧率等指标必须在需求或验收规范中量化，缺省时标注 `[假设]` 并提示澄清。
