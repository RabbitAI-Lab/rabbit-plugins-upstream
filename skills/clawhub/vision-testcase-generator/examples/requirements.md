# 视觉测试输入（真实案例演示）

## 需求：手机背板划痕/脏污检测系统

1. 检测两类缺陷：划痕、脏污，输出 OK/NG 判定
2. 漏检率 ≤ 0.1%，误检率 ≤ 0.5%（基于 10000 张标注样本验收）
3. 单张图像处理时间 ≤ 80ms（1280×960 灰度图）
4. 支持光照变化 ±20% 的鲁棒性，准确率不下降超过 1%
5. 检测结果保存 NG 图像并记录缺陷类型、坐标
6. 支持检测阈值在线调整（0.5~0.95），调整后立即生效
7. 相机断线后自动重连，重连期间缓存触发信号不丢帧

> 输入形式：需求描述文本（无文档附件），期望按 SKILL.md 五阶段流程输出测试用例。
