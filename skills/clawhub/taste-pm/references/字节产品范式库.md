# 字节产品范式库

把字节系产品验证过的设计规律，整理成做产品时可逐条对照的"弹药"。配合 SKILL.md 的六步法使用。

---

## 一、布局骨架选型（第④步核心）

按产品定性（第②步）直接选骨架，这是 web 产品最关键的一步选错全盘错：

| 产品类型 | 骨架 | 范本 | 要点 |
|---|---|---|---|
| 消费型(移动) | 底部 5 Tab | 抖音/红果/汽水 | `主流/发现/➕创作/消息/我的`；Tab≤5、单手可达；"我的"最右兜个人资产；创作型把➕放正中凸起 |
| 对话助手型(web) | 对话流 | 豆包 | 中间对话区 + 底部居中输入框；`/` 唤技能列表、`+` 接多模态；左侧会话列表自动分组；常用功能卡片前置到首屏 |
| 创作工具型(web) | 三栏工作台 | 扣子 Coze | 左配置(人设/编排) / 中编排画布(拖拽节点+连线) / 右即时调试预览；配资源库(插件/知识库可复用共享) + 模板商店 |
| 生成型(web) | 左参右果 | 即梦 | 左 prompt+参数(模型/比例/数量) / 右结果画廊；结果可原地局部重绘、扩图、二次编辑；灵感社区降冷启动 |
| 协作/中后台(web) | 左侧边栏+内容区 | 飞书/扣子工作空间 | 导航可拖拽排序、折叠、隐藏；以某个高频模块(如消息)为中枢打通其余 |

---

## 二、消费型 feed 形态选型判据

PM 的核心决策。选错，停留时长和转化全崩：

- **单列沉浸全屏** ← 内容是视频/音频/短剧 / 强算法分发 / 拼停留时长 / 中心化。一屏一内容，上下滑切换。范本：抖音、汽水(听歌竖滑切歌)、红果(刷剧)。
- **双列瀑布卡片** ← 内容是图文/商品/长内容检索 / 要用户主动挑 / 容错率高。一屏多选项，点击进入。范本：抖音商城、红果剧场、剪映模板。
- **混用**：同产品按"场"切——抖音电商(内容场单列 + 商城货架双列)、红果(首页刷流单列 + 剧场找剧双列)。一个负责"逛/被动刷"，一个负责"找/主动检索"。

---

## 三、头条卡片信息密度库

信息流卡片备齐这几种样式应对不同内容：

- **纯文**：标题 + 来源 + 评论数 + 时间。
- **左文右图**：最常见图文形态。
- **多图(组图)**：吸引点击，但增加视觉杂乱，慎用。
- **大图/视频**：视频标题内嵌封面以压缩卡片高度。

卡片标配元素：`标题 + 来源/作者 + 互动数(评论/赞/已售) + 时间`。统一圆角、高对比标题、充足留白。
沉浸式页面用三段式叠加：内容铺满全屏(背景) + 右侧竖排操作栏(头像/赞/评论/分享，带实时计数) + 底部信息层(账号/文案/配乐)。

---

## 四、入口哲学：消费优先，打开即用

- 首屏不放货架/搜索框/空白主页，直接给可消费/可用的默认态（feed / 自动播放 / 对话框 / 工作台）。
- **冷启动到第一次消费/可用 = 0 点击**，这是验收标准。
- 核心动作 0~1 步触达；点赞/互动 1 步（双击/单点）。
- 工具型例外是"打开即工作台"，对话型是"打开即可输入"——但同样不绕路。

---

## 五、即时反馈 + 就地浮层

- 互动给动画即时回馈（双击爱心）。
- 数字实时刷新（赞数/库存/金币/已售）制造正反馈与紧迫感。
- 评论/分享/下单/确认用 **bottom sheet 底部浮层**或弹层，用户操作时不离开主内容（"留在内容里"原则）。
- web 工具型：流式输出、画布实时调试、单节点试运行、生成结果即时进画廊——改一处即时看到结果，缩短反馈环。

---

## 六、跳转逻辑：短链、就地、闭环

- 消费 → 创作：同栏对称放置，看完即可做（抖音➕、剪映直发抖音）。
- 内容 → 交易：内容里直接挂车，浮层下单不跳出。
- 内容 → 个人页：点头像/作者即达主页(作品聚合)。
- 行为 → 资产/激励：观看/阅读时长沉淀为金币/钱包，"我的"页承接。
- 一切跳转优先"就地浮层"，其次同栈深入，**避免把用户甩出主流量场**。
- 给轻负反馈（不感兴趣/长按菜单）反哺算法。

---

## 七、激励/变现缝进主路径（不拦截）

- 把"商业/激励引擎"单列成一级入口（红果/番茄"福利"、电商"购物车"），钱的路径只 1 跳。
- 变现缝进主路径而非拦路：音乐=订阅软墙叠加在免费试听上；短剧=广告墙替代付费墙(IAA)，金币/提现激励缝进刷流。
- 把"注意力成本"替代"货币成本"，用免费规模换广告收入。

---

## 八、web 工具型的降门槛铁律（扣子范本）

- 把复杂能力封装成：**拖拽节点 / 选模型 / 填 prompt + 一键生成/发布**，非专业用户也能走完"打开→创作→发布"。
- **模板 + 商店做复用闭环**：商店按场景分类，一键复制到自己空间再改造；资源(插件/知识库/工作流)库化、可团队共享。
- **消费-创作对称**：让用户从"用别人的"无缝跳到"做自己的"——体验→复制→编辑→发布回商店。消费侧引流，创作侧沉淀。

---

## 九、一条主线（设计新产品时的推导顺序）

确定主消费/使用对象 → ②定性 → 按④选布局骨架 → ③核心动作零步触达定首屏 → 排主干/枝叶、商业引擎单列 → 消费型再定 feed 形态(判据二)与卡片(库三) → ⑤用即时反馈+就地浮层+短链闭环串起体验 → ⑥落到 Semi/Arco 组件。
