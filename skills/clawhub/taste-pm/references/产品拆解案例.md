# 字节产品拆解案例库

13 个字节系产品的真实结构拆解。每个按固定模板：**入口与首屏 / 信息架构 / 核心页面布局 / 交互与即时反馈 / 跳转闭环 / 体现的范式**。设计新产品时，找一个最像的范本照着推。

> 置信度备注：来自公开评测/拆解文与官方商店文案，未逐一对照最新版截图。Tab 命名随版本变动，以结构含义为准。

## 消费型

### 抖音 / TikTok —— 单列沉浸原型机
- **入口**：打开即全屏自动播放推荐视频，零点击进入消费。核心创作"➕"在底部正中凸起。
- **信息架构**：底部 5 Tab（首页/朋友/➕/消息/我）；顶部页内切换：关注/推荐/同城。主干是"推荐"全屏流。
- **页面布局**：单列沉浸全屏，三段式叠加——视频铺满 + 右侧竖排操作栏(头像/赞/评论/分享带计数) + 底部信息层(账号/文案/配乐)。
- **交互反馈**：上滑=下一条(唯一主手势)；双击=点赞跳爱心；评论/分享走 bottom sheet 不离开视频；无限刷。消费 0 步、点赞 1 步。
- **跳转闭环**：视频→点头像→创作者主页；挂车→商品；➕→拍摄创作闭环。消费与创作对称放置。

### 今日头条 —— 单列列表 + 频道 + 卡片库
- **入口**：打开即"推荐"频道图文流，搜索框置顶。
- **信息架构**：底部 Tab(首页/视频/发布/消息/我)；顶部可滑动频道栏(关注/推荐/热点/本地…)可编辑增删。
- **页面布局**：单列竖向列表。卡片 4 样式——纯文/左文右图/三图/大图视频。统一圆角、高对比标题。
- **交互反馈**：点击进详情页(底部即评论+相关推荐，读完继续消费)；下拉刷新、上拉加载；右下"叉"=不感兴趣即时反馈算法。
- **跳转闭环**：卡片→详情→作者主页/相关推荐/评论区；视频卡片→沉浸播放。

### 汽水音乐 —— 打开即放歌 / 全单曲推荐
- **入口**：打开第一眼直接进播放页(已在放歌)，对标网易云/QQ音乐的"歌单货架/搜索"，汽水是"已经在放的播放器"。
- **信息架构**：底部仅 3 Tab——播放(主干)/发现/我的。极简。
- **页面布局**：播放页单列沉浸，封面+模糊虚化背景；只推单曲不推歌单；预加载约 8 首队列。
- **交互反馈**：上下滑=切歌(照搬抖音手势)；点赞=一键入默认歌单；节奏触发屏幕闪烁+震动。听歌 0 步、切歌 1 滑。
- **跳转闭环**：与抖音账号深度打通(收藏的歌/BGM 双向同步)；VIP 软墙叠加在免费试听上不阻断消费。

### 红果短剧 —— 免费看 + 激励引擎 + 双范式
- **入口**：打开即单列沉浸推荐流，进来就在播一集短剧，竖屏全屏。
- **信息架构**：底部 Tab——首页(刷)/剧场(找)/我的，部分版本金币/福利独立成 Tab。首页+剧场是两条找剧主干，一被动一主动。
- **页面布局**：首页单列沉浸竖屏；剧场双列/九宫格卡片(封面+剧名+分类)。一个 App 两种范式覆盖"逛"和"找"。
- **交互反馈**：上下滑=切内容；任意选集/小窗/倍速；一键追剧；金币观看实时累积。
- **跳转闭环**：刷剧→追剧/评论→"我的"看追剧；**激励引擎**：看广告解锁后续剧集(广告墙替代付费墙 IAA)，金币可提现反向拉长停留(平均~28分钟)。

### 番茄小说 —— 免费阅读 + 福利激励
- **入口**：打开直接进"书城"(非书架)，智能推荐书单；"继续阅读"以浮层出现在 Tab 上方。
- **信息架构**：底部 Tab——书城(推荐)/书架/福利/我的。"福利"单列一级 Tab，现金激励是主引擎。
- **页面布局**：书城单列流式智能推荐(封面+书名+简介+标签)；阅读器全屏沉浸，上下滑翻页。
- **交互反馈**：点书→详情→直接进阅读器，路径极短；阅读时长实时累积金币；点屏中部唤底部菜单。
- **跳转闭环**：书城→详情→阅读器→加书架；阅读→金币→福利页提现，内容消费↔现金激励闭环。

## 创作 / 工具型（web，做 web 的主要参考）

### 扣子 Coze —— 三栏工作台标杆
- **入口**：打开是平台定位 + 一排开箱能力卡片(写作/PPT/表格/生图)；创作入口在左侧"工作空间→创建智能体"；首屏前置"智能体推荐"。
- **信息架构**：左侧导航分三类——工作空间(创作)/资源库(复用)/商店(流通)。标准中后台布局，不是对话流。
- **页面布局（最值得抄）**：智能体编辑页三栏——左"编排"(选模式/写人设Prompt) + 中"技能"(挂大模型/插件/知识库/工作流) + 右"调试预览"(实时对话测试)。工作流画布(FlowGram)：拖拽节点+连线定义数据流，开始/结束/LLM/工具/条件/循环节点，单节点试运行。商店卡片网格+左侧分类。
- **交互反馈**：搭最小 Bot 五步(新建→写提示词→加技能→预览→发布)；右栏流式输出、画布可视化看数据流转、调试日志。
- **跳转闭环**：智能体←挂载→工作流/插件/知识库/数据库；商店体验 Bot→一键复制到空间→改造→发布回商店，消费-创作对称。

### 即梦 Dreamina —— 左参右果生成工作台
- **入口**：首屏"灵感/生成/资产"三模块 + 他人作品瀑布流(降冷启动) + "开启 Agent 模式"。
- **信息架构**：左/顶导航——灵感(社区)/生成(创作)/资产(管理)/发现/短片。创作工具 + 内容社区双层。
- **页面布局**：左右两栏——左侧 prompt 输入+模型/比例/精细度/数量参数；右侧结果画廊，结果可局部重绘/扩图/高清/抠图二次编辑。视频生成额外有运镜/首尾帧。
- **交互反馈**：出图三步(描述词→选参数→立即生成)；结果即时进画廊，所见即所得二次编辑。
- **跳转闭环**：文生图→图生视频→智能画布编辑→资产库；灵感社区作品可看 prompt 仿做(消费→创作)。

### 剪映 / CapCut —— 低门槛创作闭环
- **入口**：打开首页中心是巨大"开始创作"按钮，旁列"剪同款/拍摄/图文成片"。首屏是创作工作台。
- **信息架构**：底部 Tab(剪辑/剪同款/创作/消息/我)。"剪同款(模板)"与"剪辑(专业)"并列两主干。
- **页面布局**：首页功能宫格+模板双列瀑布；剪辑页三段式(预览区+时间轴轨道+工具栏)。
- **交互反馈**："一键成片/剪同款"把专业剪辑压到 2-3 步；即时预览所见即所得；新手高手共用界面分流入口。
- **跳转闭环**：剪辑完成→一键直发抖音(剪映创作→抖音分发跨产品闭环)；模板本身是 UGC，消费即生产。

### Trae —— AI IDE（定位）
- AI 驱动全流程编程协作平台(非补全插件)。两模式：Builder(从需求自动生成完整项目)/Chat(对话答疑改代码)。把 IDE 改造成 Agent 协作工作台。

## 对话 / 助手型（web）

### 豆包 Doubao —— 对话流 + 功能前置
- **入口**：打开即大对话输入框 + 一排功能卡片，无配置直接开聊。"打开即用"极致。
- **信息架构**：左侧会话列表(按"智能体/豆包"分组，可重命名/归档/删除)+ 中间对话区。功能不靠导航树，前置成对话页快捷入口。
- **页面布局**：输入框底部居中；右侧"+"接多模态(图/文档/视频链接)；"/"召唤技能列表；功能入口前置(写作/生图/AI搜索/PDF/翻译)；左侧"智能体"分组挂垂直角色。
- **交互反馈**：打开到完成 1 步(直接输入)；流式输出；多端账号同步历史/收藏/设置。
- **跳转闭环**：对话为中枢，写作/生图/搜索/PDF 收敛进同一对话框(用 `/` 或 `+` 切换)不跳出；智能体作为预设角色挂会话列表。

### 猫箱 BagelBell —— 角色扮演（定位）
- AI 角色创建 + 沉浸式剧情聊天。用户 DIY 角色(声音/形象/人设/剧本)与虚拟角色演绎剧情。消费(聊)-创作(建角色)对称，偏情感陪伴。

## 交易型 / 协作型

### 抖音电商 —— 内容场 + 中心场双引擎
- **入口**：无独立首屏，电商寄生在抖音消费流(视频挂车/直播购物车)；另有"抖音商城版"独立 App 走货架。
- **信息架构（四域模型）**：短视频+直播(内容场，激发兴趣) / 商城+搜索(中心场，承接成交)。
- **页面布局**：内容场单列沉浸(视频+商品浮层)；中心场双列商品瀑布+搜索+金刚区。一体系内单列与双列按场切换。
- **交互反馈**：视频→点购物车浮标→商品弹窗→下单，不离开内容流；库存/价格实时刷新制造紧迫。
- **跳转闭环**：内容激发兴趣→商品页→下单→订单进商城/个人中心；从"逛"到"买"短链就地完成。

### 飞书 / Lark —— 消息为中枢的一体化工作台
- **入口**：打开即"消息"(IM)，作为连接所有模块的中枢。
- **信息架构**：移动端底部约 5 Tab(消息/日历/应用/云空间/通讯录)；PC/Web 左侧竖向侧边栏(约 7 项，可拖拽排序/隐藏/折叠)。
- **页面布局**：三栏 IM(会话列表|聊天窗|详情)；文档=在线协作编辑器；工作台=应用启动器聚合一三方应用。
- **交互反馈**：消息已读/输入状态、@提醒；文档实时多人协作光标；消息中可 @文档/@日历。
- **跳转闭环**：以"消息"为中枢打通 IM↔文档↔日历↔会议↔多维表格，对象互相引用嵌套(all-in-one)。B 端协作逻辑，但"一个入口聚合一切、模块互通"哲学与 C 端一致。
