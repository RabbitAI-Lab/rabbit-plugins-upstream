# 设计系统落地词汇表

第⑥步用。把产品结构落到字节系开源设计系统的组件与布局规范。**这是落地词汇表，不是设计重心**——重心永远是前五步的信息架构与交互。

---

## 一、选型：Semi vs Arco

| 维度 | 选 Semi Design | 选 Arco Design |
|---|---|---|
| 出品 | 抖音前端 + MED 团队 | GIP UED + 架构前端 |
| 框架 | React 首选(社区有 Vue 移植) | 同时有 React + Vue 两套 |
| 维护 | ✅ 抖音背书，活跃(v2.58+) | ⚠️ 2025 起社区基本停摆，Issue/PR 积压 |
| 协作 | ✅ DSM + D2C/Figma 工具链最强 | Design Lab(平台不稳) |
| 主题 | ✅ 3000+ Token，可视化、暗色自动 | less-loader / Design Lab |

**默认建议**：新建 web 中后台 → **Semi(React)**；需要 Vue 或现成后台脚手架 → **Arco Pro Vue 模板**，但锁版本、备自维护。两者设计语言同源(24 栅格、8px 间距、顶栏+侧栏+内容区)，切换成本低。

GitHub：Semi `github.com/DouyinFE/semi-design`(~9.9k★)；Arco `github.com/arco-design/arco-design`(~5.6k★)。
设计价值观：Arco 四值「清晰/一致/韵律/开放」，核心"务实的浪漫主义"(arco.design/docs/spec/values)。Semi 核心"高质量稳定默认 + 按需开放定制"。

## 二、标准中后台页面骨架

```
Layout
├── Header   顶部导航 / Logo / 全局操作
├── Sider    侧边栏 Navigation(Semi) / Menu(Arco)
├── Content  Breadcrumb 面包屑 → PageHeader/标题 → Tabs 分区 → 内容区(24 栅格 Row/Col)
└── Footer
```
模块间距走 8px 倍数(8/16/24/32)；Row 用 gutter 控间距，推荐 (16+8n)px。

## 三、组件选型口诀（按场景）

- **列表页**：`Table` + 顶部筛选 `Form` + `Pagination` + `Button` 操作区。
- **详情页**：`Descriptions` / `Card` + `Tabs` 分区。
- **表单页**：`Form` + Input/Select/DatePicker/Cascader/Upload + `Modal` 确认。
- **反馈**：轻提示 `Toast`(Semi)/`Message`(Arco)；重确认 `Modal`/`Popconfirm`；系统通知 `Notification`；侧滑表单 `Drawer`；加载 `Spin`+`Skeleton`。
- **导航**：侧边 `Navigation`/`Menu`、`Breadcrumb`、`Tabs`、`Steps`、`Pagination`、`Tree`、`Anchor`。

## 四、Token 落地

颜色/字体/圆角/阴影/间距全走 Token，**不写魔法值**。
- Semi：3000+ Token 分层，全局级+组件级深度定制，暗色自动；DSM 在线调主题、一行代码接入；Figma 稿可经 D2C/Figma 插件直出代码(JSX+SCSS/Emotion/Tailwind)。
- Arco：less-loader 或 Design Lab 定制；色彩算法生成。

## 五、字节做 web 的典型技术栈（背景参考，非本 skill 输出内容）

> PM 排期/选型/跨团队沟通时锚定，但**设计稿里不要写这些**——除非用户专门问。

`Rsbuild/Rspack 构建 → Modern.js + React/TS 开发 → Semi/Arco UI → Garfish 微前端 → 跨端上 Lynx`，后端 Go 为主。
- 构建：Rspack(Rust 平替 webpack)/Rsbuild。
- 框架：Modern.js(React 全栈底座)。
- 微前端：Garfish。
- 跨端：Lynx(2025 开源，对标 RN，框架无关；注意 Hippy 是腾讯的不是字节的)。
- UI/图标：Semi、Arco、IconPark、xgplayer、ByteMD。
- AI/Agent：Coze、UI-TARS、deer-flow、trae-agent。
