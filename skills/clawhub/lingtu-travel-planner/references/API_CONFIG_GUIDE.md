## API 配置指南（首次使用必读）

本技能的实时天气和路线规划功能依赖两个第三方 API，用户需自行申请免费的 API Key 并配置到系统中。

### 🔑 和风天气 API（天气数据）

**注册步骤：**
1. 打开 [和风天气开发平台](https://dev.qweather.com/) → 点击「注册」
2. 使用手机号或邮箱注册，完成实名认证
3. 进入「控制台」→「项目」→ 点击「创建项目」
4. 免费订阅选择「开发版」，即可获得 API 访问权限

**获取凭证：**
- 在「控制台」→「项目」页面找到以下信息：
  - **API Host**（API主机地址）：格式为 `xxxxxxx.re.qweatherapi.com`
  - **API Key**（API密钥）：一串字母数字组合

**免费额度：**
- 开发版免费：1000次请求/天
- 超出后当天空闲，次日自动恢复
- 如果频繁查询，建议缓存已查过的城市ID避免重复请求

### 🗺️ 高德地图 API（路线规划 + POI搜索 + 地理编码）

**注册步骤：**
1. 打开 [高德开放平台](https://lbs.amap.com/) → 点击「注册」
2. 使用手机号注册，完成个人开发者认证
3. 进入「控制台」→「应用管理」→「我的应用」
4. 点击「创建新应用」→ 填写应用名称（如"旅行规划"）→ 选择应用类型
5. 在应用下点击「添加 Key」→ 服务平台选「Web服务」→ 提交

**获取凭证：**
- 创建成功后会显示 **API Key**：一串字母数字组合
- 基础地址固定为：`https://restapi.amap.com/v3`

**免费额度：**
- 个人开发者免费：5000次请求/天
- 超出后需要升级为企业认证（个人用户一般用不完）

### 📝 配置到系统

拿到 API Key 后，**直接告诉我以下信息**，我会帮你保存到安全存储：

> "帮我配置旅行技能API：
> 和风天气 Host：xxxxx.re.qweatherapi.com
> 和风天气 Key：xxxxxxxxxx
> 高德地图 Key：xxxxxxxxxx"

或者也可以自己通过 `memory_edit(key="secret")` 手动添加。

### ✅ 配置验证

配置完成后，试着对我说"查一下苏州的天气"。如果返回了结构化的温度、天气状况等数据，说明配置成功。如果提示"API调用失败"，请检查：
- API Key 是否复制完整（注意不要有多余空格）
- 和风天气的 Host 是否包含完整的子域名
- 高德地图的服务平台是否选择了「Web服务」（不是「Web端JS」）

### ❓ 常见问题

| 问题 | 解决办法 |
|------|---------|
| 和风天气 API 返回 code=400 | Key 无效或未激活，等待 5 分钟后重试 |
| 高德 API 返回 status=0 | Key 无效或服务平台选错，检查是否选了「Web服务」 |
| 不想申请 API Key | 本技能仍可正常使用——天气和路线功能会自动降级为联网搜索模式，只是数据精度略低 |
| API 额度用完 | 当天自动降级为搜索模式，次日恢复 |
