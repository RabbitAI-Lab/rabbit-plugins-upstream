# 养生公众号日更

一句话跑完：**定病根 → 查重 → 成文 2000 字+ → 合规自检 → 排版 HTML → 入全文库。**

> 首次使用：告诉 AI 你的文章存放目录（如 你的常用文章目录），AI 记住后续直接用。

---

## 公众号长文该长什么样

| 维度 | 要求 |
|---|---|
| 篇幅 | **2000 字+** |
| 开头 | 真人故事铺垫，**有细节**（具体症状、具体场景、具体对话） |
| 结构 | `## 小标题` + 完整段落，分点讲透 |
| emoji | **几乎不用**，靠排版和加粗区分层次 |
| 结尾 | 引导评论 + 在看 + 后台回复关键词 |

> ⚠️ 公众号靠**家庭群转发 + 搜一搜**起量，标题别把一半读者排除在外——能中在男女身上的话题，就别只写单一性别的人群词（详见下方人群词分流）。

---

## 标题公式（4 款轮换，禁止连续两天同款）

| # | 句式 | 例 |
|---|---|---|
| A | [人群/年龄+痛点]？[否定一个常见误解]，是这N件事在拖后腿——[人群词]该懂的N件事 | 掉发、腰酸、怎么睡都累？不是年纪大，是肾气悄悄亏了——30岁后都该懂的3件事 |
| B | [权威身份]提醒：[症状列举]，多半不是[常见归因] | 皮肤科医生提醒：脸上长斑、口苦、睡不着，多半不是熬夜 |
| C | 把[身体部位/习惯]说透：为什么你[痛点]多年，越调越糟？ | 把脾胃说透：为什么你戒了冰饮，胃还是寒的？ |
| D | [数字/时间]只做对了一件事，[结果反转] | 换季全家没一个感冒的，我家只做对了一件事 |

两种风格都可用：**痛点反差式** 或 **权威提醒式**（"皮肤科医生提醒：……"，不点医院名）。

### ⚠️ 人群词按话题分流（核心打法，别一律写"女人"）

公众号流量靠**家庭群转发 + 搜一搜**：养生文常被老婆转给老公、女儿转给爸。
标题带"女人"，男读者直接划走，转的人也觉得不好转给男的——等于自断转发链，连搜索入口都进不去（男性也搜"肾虚掉发"）。

**先判断题型，再选人群词：**

| 题型 | 判断标准 | 人群词 | 示例 |
|---|---|---|---|
| **通用型** | 男女老少都可能中（肾虚、脾胃、湿气、睡眠、护肝、三高、血压、痛风、免疫力） | `30岁后` / `上了年纪` / `很多人` / `全家都该知道` | 掉发、腰酸、怎么睡都累？不是年纪大，是肾气悄悄亏了——**30岁后都该懂的3件事** |
| **女性专属** | 只有女性会中（经期、气血、产后、妇科、备孕、美容养颜） | 保留 `女人` | 经期总推迟？这3件事在拖后腿——**女人该懂的3件事** |

一句话原则：**能中在男人身上的话题，标题就别把男人排除掉。**

## 正文骨架

```
# 标题

开头段：一个具体人物的场景（按题型选人），
        带细节（粉底救不回来、黑眼圈挂到颧骨 / 腰酸得直不起来、夜里起夜三四趟），
        最后一句点题"今天说三件事"

| 题型 | 开头人物 |
|---|---|
| 通用型 | 朋友、同事、读者、门诊大爷 |
| 女性专属 | 闺蜜 |

⚠️ **开头写法轮换（别超过两天同款）**：上面这种「人物吐槽→我一句话点破→今天说三件事」是默认款，
轮换选项：
- B 读者来信式：后台收到一条留言，整段引用，回信一样展开
- C 自曝式：讲"我自己去年踩过的坑"，反转在"后来才知道"
- D 场景白描式：不开人物故事，直接白描一个公认场景（电梯里人人打哈欠/体检报告出来一圈人叹气），再抛问题

## 第一件：xxx（信号/原因）
    ① 症状1  ② 症状2  ③ 症状3
    解读：多半是 xx 叠加 xx
    做法：先别急着买贵妇精华，记清自己中了几条

## 第二件：xxx（做法/方案）
## 第三件：xxx（内调/习惯）

## 写在最后
    收束 + 一句金句 + 互动提问（评论区聊聊）

---
**觉得有用，点个「在看」让更多朋友看见。**（+ 引流闭环，见下方合规说明）
```

## 流程

### Step 1 · 定病根（先于一切）

⚠️ **第一步就先定病根，再展开全篇**——翻最近 7 天的篇目，挑一个没用过的病根
（肝郁 / 气血两虚 / 脾胃虚寒 / 秋燥伤肺 / 肾精不足…）。
**不要先写完再回头查重**：病根一撞，症状、忌口、运动必然全跟着撞，返工更费事。

### Step 2 · 查重（动笔后、入库前，逐项自检 6 条）

拿最近 7 天的篇目逐条比，**中 2 条以上就重写**：

| # | 自查项 | 典型翻车 |
|---|---|---|
| 1 | 症状清单 | 重复 3 个以上（脸油 / 大便黏 / 身体沉 / 舌苔厚） |
| 2 | 体感比喻 | 换一个字："湿棉被" → "湿衣服" |
| 3 | **病根** | 把上一篇的病根又写进来 |
| 4 | 忌口 | 同一串：冰 / 甜 / 油腻 |
| 5 | 运动处方 | 同一张方子：快走 30 分钟、微汗 |
| 6 | 段落骨架 | 小标题结构 + 段内句序一致 |

⚠️ **第 3 条最致命**：病因一旦相同，症状、忌口、运动必然全跟着撞。

⚠️ **换词不算避重，换角度才算**——词全换过、论点没换的文章，查重工具测不出，
读者一眼看穿。另：**同一标题公式最多连续 2 篇**，第 3 篇必须换句式，否则读者一眼看穿套路。

### Step 3 · 成文

套模板，2000 字+，**引流闭环必带**（写法见合规说明）。
⚠️ 动笔前先读昨天的文章：标题句式（4 款轮换池）和开头写法（4 款轮换）**今天都要换款**，不许连用；
可选模块也按昨天有没用过来增删，别每篇模块长得一样。

### Step 4 · 合规自检（每篇必做）

### 🚨 平台合规红线

| 风险项 | 禁止 | 允许的写法 |
|---|---|---|
| **疗效承诺** | 根治、彻底解决、一定有效、百分百、包好、治愈、永不复发 | "有助于""很多人反馈""慢慢调养" |
| **极限词**（广告法） | 最有效、第一、国家级、全网最低、顶级 | "比较""常见""不少人觉得" |
| **医疗资质** | 编造具体医院名、医生姓名、药品名、问诊过程 | "一位行医三十多年的老中医"（不点名）"皮肤科医生提醒"（不指名医院） |
| **引流方式** | ✅ 公众号可用「后台回复『XX』领资料包」，属平台允许的动作 | 别在文末直接放个人联系方式，用后台关键词承接 |
| **AI 口吻** | "作为AI""本文由AI生成" | 一律真人视角 |

**自检动作**：成文后先逐项扫上表（疗效/极限词/编造/引流/AI口吻），再人工通读一遍抓语境问题。命中就改掉再交付，禁止带违规内容入库或发布。

### Step 5 · 排版版 HTML（必做）

同目录生成同名 `.html`：品牌色（如 `#c2185b`），`max-width: 680px`。
⚠️ **样式必须写内联 `style=`，不要用 `class=`**——公众号后台粘贴时会过滤 class，只有内联样式才能保留加粗/色字/色块。

### Step 6 · 入全文库

```bash
python "$SKILL_PATH/scripts/add_to_library.py" <文章.md路径>
```

自动转 HTML 卡片、按日期倒序插入全文库（最新在顶）、更新篇数统计。

## 硬性规则

| 规则 | 说明 |
|---|---|
| 篇幅 | **2000 字以上** |
| 加粗 | 用 `<strong>…</strong>` 标签（公众号后台更稳） |
| 人设 | 有朋友（护士等），第一人称"我"；女性专属话题才用闺蜜 |
| 权威 | 引用医生/皮肤科，**不编造具体医院和药名** |
| 语气 | 温暖、像姐姐聊天，不说教 |
| 时令 | ⚠️ 与当前日期一致（8 月写"年底了"是事故） |
| 引流 | 「后台回复关键词」合规可用；文末不放个人联系方式 |
| 查重 | 先定病根再动笔，6 条自检过关才算完成 |

## ⚠️ 关于「同质化」——别搞错敌人

很多作者担心「用同一套模板会不会被平台判同质化」。真实规则是：

- **平台不会因为多人用同一套写作框架就限流或封号**——就像用同一个 PPT 模板不会出事。封号只认违规（导流、疗效承诺、医疗编造）。
- **真正会伤你的是「自己跟自己撞」**：同一个号连着发同一个结构、同一个角度、同一批词，老读者看腻、完读率掉，推荐自然跟着掉。
- 所以本 skill 内置两道防线：**Step 1 定病根**（先定角度再动笔，从源头避免换词不换角度）+ **Step 2 查重 6 条**。每天动笔前花一分钟过一遍，比事后补救管用得多。
