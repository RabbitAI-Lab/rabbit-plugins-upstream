# 中国観光地チケット

## 説明

中国旅行のためのオールインワン旅行コンパニオン。このスキルは外国人旅行者向けに5つの強力な機能を提供します：

1. **観光地チケット** — チケット料金、営業時間、予約リンクで観光スポットを発見
2. **ホテル検索** — リアルタイムの料金、評価、予約リンクでホテルを探す
3. **フライト検索** — 中国への/中国発/中国内のフライトをリアルタイムの料金で検索
4. **旅行プラン** — パーソナライズされた複数日の旅行プランを生成
5. **旅行アドバイス** — ビザ、支払い、交通、食事などに関する回答を取得

## データフローとプライバシー

ユーザーのクエリは安全なプロキシサーバー（SCF）に送信され、認証トークンが注入されてTripGenie APIに転送されます。プロキシはアフィリエイトリンクの生成を自動的に処理します。ユーザーの個人データは保存または記録されません。すべての通信はHTTPSで暗号化されています。

## 使用する場面

- 中国の都市の観光スポットややるべきことを探す
- 特定の観光スポットのチケット料金と営業時間を取得
- 興味に基づいてアクティビティを発見（歴史、自然、食事など）

キーワード：中国 観光地、北京 やるべきこと、上海 観光、万里の長城 チケット、紫禁城、兵馬俑、観光スポット、チケット、観光

## 実行

### ステップ 1：ユーザーのリクエストからパラメータを抽出

| パラメータ | 説明 | 例 |
|-----------|------|-----|
| city | 都市名（英語または日本語、必須） | "Xi'an" or "西安" |
| days | 滞在日数（任意、デフォルト：1） | 2 |
| interests | 興味キーワード（任意） | "歴史と文化" |

### ステップ 2：スクリプトを実行

```bash
python scripts/china_travel.py attraction "<city>" [days] "[interests]" --locale=ja
```

**重要：** 常に `--locale=ja` パラメータを含めて、日本語での結果を取得してください。

### ステップ 3：結果を表示

API は構造化された Markdown で観光スポット名、チケット料金、営業時間、予約リンクを返します。内容を直接ユーザーに表示します。

## 例

**ユーザー：** "西安では何が訪問できる？"
```bash
python scripts/china_travel.py attraction "Xi'an" --locale=ja
```

**ユーザー：** "北京で2日間の歴史観光スポット"
```bash
python scripts/china_travel.py attraction "Beijing" 2 "history" --locale=ja
```

## その他の利用可能な機能

このスキルは以下もサポート：
- `hotel` — 中国のホテルを検索して予約
- `flight` — 中国への/中国発/中国内のフライトを検索
- `itinerary` — 複数日の旅行プランを生成
- `tips` — 旅行アドバイス、ビザ、支払い、交通のヒント

## 注意

- 都市名は英語または日本語で入力できます
- 予約リンクは Trip.com（国際版）に直接遷移します
