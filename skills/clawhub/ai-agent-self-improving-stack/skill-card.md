## Description: <br>
Installs five agent workflow tools for reflection, proactivity, learning, local memory, and extracting reusable skills from successful interactions. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and agent users use this skill to install and coordinate a self-improvement stack that helps an agent remember local context, learn from corrections, act proactively, and turn successful patterns into reusable skills. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Component skills may store local memory and adapt behavior over time. <br>
Mitigation: Before enabling the stack on sensitive work, review each component skill and confirm what it stores, where it stores it, and how to disable or clear memory. <br>
Risk: Bundled self-improvement workflows can change future agent behavior based on accumulated history. <br>
Mitigation: Use the stack only where adaptive behavior is intended, and periodically review stored knowledge and extracted skills for accuracy. <br>
