## Description: <br>
Cobra Claw is an AI dojo discipline that provides quick lookups, practice katas, and shell tools for applying Strike First, Strike Hard, No Mercy guidance. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and agent users use this skill to load a themed response discipline and run local shell helpers for doctrine lookup, quotes, katas, patrol checks, and trophy tracking. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>

Mitigation: Install from the reviewed package, inspect any externally cloned version before execution, and run only expected commands. <br>
