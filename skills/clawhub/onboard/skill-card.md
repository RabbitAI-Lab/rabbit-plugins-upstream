## Description:

Use /onboard for a focused Codex onboarding flow that learns basic preferences, picks a first goal, and routes the user to the right next action.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Codex users use this skill to complete a short onboarding interview, save basic work preferences when available, choose a first goal, and receive a concise handoff to the right next action.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The onboarding flow may save a user's name and work context into persistent personal rules by default.

Mitigation: Review before installing, clearly tell users what will be remembered, and provide an explicit opt-out or easy deletion path.
