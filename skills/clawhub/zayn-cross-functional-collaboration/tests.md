# Tests

## 测试原则

1. 是否适用于不同岗位，不偏向销售场景。
2. 是否区分已确认事实、用户判断和待确认信息。
3. 是否识别过早承诺风险。
4. 是否识别推责和情绪化表达。
5. 是否生成明确下一步动作。
6. 是否避免强行补全缺失信息。
7. 是否尊重人工判断。

## 统一运行协议测试

1. 是否先进行参数解析。
2. 是否输出参数状态表。
3. 是否正确识别已命中、部分命中、缺失、冲突和待验证。
4. 是否会自动补全缺失参数。
5. 是否在信息不足时要求用户补充。
6. 是否定义最低运行条件。
7. 是否在未达到条件时强行分析。
8. 是否区分分析模式、直接回复模式和协同推进模式。
9. 是否把待验证信息写成事实。
10. 是否尊重人工判断。
