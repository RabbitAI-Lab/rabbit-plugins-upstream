## PDF文档生成要求清单

PDF文档生成每种任务类型的"零件清单"——必选/可选组件、组装顺序、设计约束。按清单逐项产出。

---

### 输出格式规范

#### PDF文档结构

```pdf
%PDF-1.4
1 0 obj
<< /Type /Catalog
   /Pages 2 0 R
>>
endobj

2 0 obj
<< /Type /Pages
   /Kids [3 0 R]
   /Count 1
>>
endobj

3 0 obj
<< /Type /Page
   /Parent 2 0 R
   /MediaBox [0 0 612 792]
   /Contents 4 0 R
   /Resources << /Font << /F1 5 0 R >> >>
```

### F0 需求分析域

#### F0-01 文档类型识别
- **必选组件**: 用户需求描述、文档类型判断（报告/手册/证书/表单）、类型选择理由
- **可选组件**: 文档类型参考示例
- **组装顺序**: 需求收集→类型特征分析→类型判断→理由记录
- **约束**: 文档类型必须基于用户需求，不可强行套用
- **格式**: 文档类型识别报告（Markdown）

#### F0-02 内容复杂度评估
- **必选组件**: 文档内容元素数量、结构复杂度、交互复杂度、复杂度等级（简单/中等/复杂）
- **可选组件**: 复杂度评估依据
- **组装顺序**: 元素统计→结构分析→交互评估→等级判定
- **约束**: 复杂度评估必须基于客观标准
- **格式**: 复杂度评估报告（Markdown）

#### F0-03 格式要求分析
- **必选组件**: 格式类型（正式/非正式/学术）、格式要求列表、格式复杂度
- **可选组件**: 格式要求优先级
- **组装顺序**: 格式需求收集→格式类型判断→要求列表→复杂度评估
- **约束**: 格式要求必须基于用户实际需求
- **格式**: 格式要求分析报告（Markdown）

#### F0-04 输出格式选择
- **必选组件**: 格式选择（标准PDF/模板应用/自定义）、选择理由、格式特点说明
- **可选组件**: 格式对比分析
- **组装顺序**: 需求汇总→格式匹配→选择决策→理由记录
- **约束**: 格式选择必须基于需求分析结果
- **格式**: 格式选择报告（Markdown）

### F1 设计规范域

#### F1-01 颜色系统应用
- **必选组件**: 色系选择（purple/teal/coral/pink/gray/blue/green/amber/red）、层级选择（50/100/200/400/600/800/900）、颜色应用场景（标题/正文/边框/背景）
- **颜色系统规范**:

| purple | #EEEDFE | #CECBF6 | #AFA9EC | #7F77DD | #534AB7 | #3C3489 | #26215C |
| teal | #E1F5EE | #9FE1CB | #5DCAA5 | #1D9E75 | #0F6E56 | #085041 | #04342C |
| coral | #FAECE7 | #F5C4B3 | #F0997B | #D85A30 | #993C1D | #712B13 | #4A1B0C |
| pink | #FBEAF0 | #F4C0D1 | #ED93B1 | #D4537E | #993556 | #72243E | #4B1528 |
| gray | #F1EFE8 | #D3D1C7 | #B4B2A9 | #888780 | #5F5E5A | #444441 | #2C2C2A |
| blue | #E6F1FB | #B5D4F4 | #85B7EB | #378ADD | #185FA5 | #0C447C | #042C53 |

- **颜色应用规则**:
  - **正式文档**：800标题 + 600副标题 + 900正文
  - **非正式文档**：600标题 + 400副标题 + 800正文
  - **学术文档**：900标题 + 800副标题 + 900正文
- **可选组件**: 颜色对比度检查、无障碍颜色选择
- **组装顺序**: 文档类型分析→色系选择→层级选择→应用场景分配→颜色代码应用
- **约束**: 颜色选择必须基于设计规范，不可凭感觉；必须考虑对比度和可读性
- **格式**: 颜色应用方案（Markdown表格）

#### F1-02 字体系统应用
- **必选组件**: 标题字体（标题1=24px/标题2=18px/标题3=14px）、正文字体（12px）、辅助文字（10px）、字重（400常规/500粗体）、行高（1.4-1.6倍）
- **字体规范**:

| 元素 | 字体 | 大小 | 字重 | 行高 |
|------|------|------|------|------|
| 标题1 | 黑体 | 24px | 500 | 1.4 |
| 标题2 | 黑体 | 18px | 500 | 1.4 |
| 标题3 | 黑体 | 14px | 500 | 1.4 |
| 正文 | 宋体 | 12px | 400 | 1.6 |
| 辅助文字 | 宋体 | 10px | 400 | 1.6 |

- **字体族**:
  - `--font-heiti`: 黑体，SimHei
  - `--font-songti`: 宋体，SimSun
  - `--font-kaiti`: 楷体，KaiTi
- **可选组件**: 字体加载方案、字体回退方案
- **组装顺序**: 元素类型识别→字体选择→大小选择→字重选择→行高设置
- **约束**: 字体必须使用规范字体；字重只使用400和500
- **格式**: 字体应用方案（Markdown表格）

#### F1-03 布局规则应用
- **必选组件**: 页面尺寸设置（A4：210mm × 297mm）、页边距设置（上下25.4mm，左右31.7mm）、页眉页脚设置（距离12.7mm）、页码设置
- **布局规范**:
  - **页面尺寸**：A4：210mm × 297mm
  - **页边距**：上25.4mm，下25.4mm，左31.7mm，右31.7mm
  - **页眉页脚**：页眉距离12.7mm，页脚距离12.7mm
  - **页码**：页脚居中，使用阿拉伯数字
- **可选组件**: 响应式布局方案
- **组装顺序**: 页面尺寸计算→页边距设置→页眉页脚设置→页码设置
- **约束**: 页面尺寸必须使用规范值；页边距必须符合要求
- **格式**: 布局方案（Markdown）

#### F1-04 样式系统应用
- **必选组件**: 样式类型选择（标题/正文/列表/表格/图片）、样式类应用、自定义样式补充
- **预设样式类**:

| 样式名 | 用途 | 格式 |
|--------|------|------|
| 标题1 | 一级标题 | 黑体，24px，居中，填充50层级 |
| 标题2 | 二级标题 | 黑体，18px，左对齐，填充100层级 |
| 标题3 | 三级标题 | 黑体，14px，左对齐，填充200层级 |
| 正文 | 正文内容 | 宋体，12px，两端对齐，首行缩进2字符 |
| 列表 | 列表内容 | 宋体，12px，左对齐，项目符号或编号 |
| 表格 | 表格内容 | 宋体，10px，居中，边框1像素 |
| 图片 | 图片说明 | 宋体，10px，居中，图下方 |

- **可选组件**: 自定义样式类、样式覆盖方案
- **组装顺序**: 元素类型识别→样式类选择→自定义样式补充→样式应用
- **约束**: 必须使用预设样式类；样式必须保持一致性
- **格式**: 组件样式方案（Markdown）

### F2 内容生成域

#### F2-01 页面结构生成
- **必选组件**: 页面类型设计、页面布局、内容分布
- **页面结构规范**:
  - 封面：标题、副标题、作者、日期
  - 目录：目录标题、章节列表、页码
  - 正文：标题、正文、图表、图片
  - 附录：附录标题、补充材料
  - 封底：版权信息、联系方式
- **可选组件**: 结构优化建议
- **组装顺序**: 结构设计→页面布局→内容分布→结构验证
- **约束**: 结构必须符合文档类型要求；层次必须清晰
- **格式**: 页面结构代码

#### F2-02 内容元素生成
- **必选组件**: 标题生成、正文生成、列表生成、表格生成、图片生成、图表生成
- **内容元素规范**:
  - 标题：使用标题样式，层次分明
  - 正文：使用正文样式，首行缩进
  - 列表：使用列表样式，层次清晰
  - 表格：使用表格样式，数据对齐
  - 图片：使用图片样式，清晰美观
  - 图表：使用图表样式，数据清晰
- **可选组件**: 内容元素优化
- **组装顺序**: 元素类型识别→样式选择→内容生成→格式应用
- **约束**: 内容元素必须符合规范要求
- **格式**: 内容元素代码

#### F2-03 交互元素生成
- **必选组件**: 超链接生成、书签生成、表单字段生成
- **交互元素规范**:
  - 超链接：使用蓝色字体，有下划线
  - 书签：使用层次结构，便于导航
  - 表单字段：使用标准表单控件，便于填写
- **可选组件**: 交互元素优化
- **组装顺序**: 元素类型识别→元素设计→元素生成→交互测试
- **约束**: 交互元素必须符合规范要求；必须保持易用性
- **格式**: 交互元素代码

#### F2-04 安全设置生成
- **必选组件**: 密码保护设置、权限控制设置、数字签名设置
- **安全设置规范**:
  - 密码保护：设置打开密码和权限密码
  - 权限控制：设置打印、复制、编辑权限
  - 数字签名：添加数字签名，确保文档完整性
- **可选组件**: 安全设置优化
- **组装顺序**: 安全需求分析→密码设置→权限设置→签名设置
- **约束**: 安全设置必须符合实际需求；必须保持文档安全
- **格式**: 安全设置代码
