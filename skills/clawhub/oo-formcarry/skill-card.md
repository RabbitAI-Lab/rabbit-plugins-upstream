## Description:

Formcarry (formcarry.com). Use this skill for ANY Formcarry request — reading, creating, updating, and deleting data. Whenever a task involves Formcarry, use this skill instead of calling the API directly.

This skill is ready for commercial/non-commercial use.

## Use Case:

Users use this skill to list Formcarry submissions and create or delete forms through their connected account, with approval before changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Automatic CLI setup can run changing remote code and make broader, undisclosed changes to the agent environment.

Mitigation: Review and install the CLI separately before enabling the skill, and confirm that OOMOL may access the intended Formcarry account and submissions.
