## Description:

Creates or prunes CLAUDE.md from verified repository commands, architecture boundaries, and exceptional conventions, retaining only rules that prevent a concrete agent error.

This skill is ready for commercial/non-commercial use.

## Publisher:

### License/Terms of Use:

MIT-0

## Use Case:

Developers and repository maintainers use this skill to create or prune CLAUDE.md guidance from verified repository facts so future coding agents follow concrete build, test, architecture, and convention constraints.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A resulting CLAUDE.md can influence future agent behavior in the repository.

Mitigation: Review the resulting CLAUDE.md before relying on it; the security evidence reports no hidden commands, credential access, network calls, or background persistence.
