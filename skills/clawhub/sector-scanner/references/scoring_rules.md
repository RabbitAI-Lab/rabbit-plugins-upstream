# 评分规则与资金流向分类

## 个股评分算法 (score_stock)

基础分 20 分，满分 100 分，通过以下维度加减分：

### 1. 均线趋势 (MA)

| 条件 | 加减分 | 说明 |
|------|--------|------|
| MA5 > MA10 > MA20 (多头排列) | +22 | 短中期均线完美排列 |
| MA5 > MA20 | +12 | 短线站上中期均线 |
| MA5 < MA20 | -6 | 短线弱于中期均线 |
| 价格 >= MA60 | +12 | 站上60日长期均线 |
| 价格 < MA60 | -8 | 跌破60日长期均线 |

计算窗口: MA5 (5日), MA10 (10日), MA20 (20日), MA60 (60日)

### 2. 动量指标 (MACD)

| 条件 | 加减分 | 说明 |
|------|--------|------|
| DIF > DEA 且 MACD > 0 (金叉) | +15 | MACD 金叉多头信号 |
| DIF < DEA 且 MACD < 0 (走弱) | -8 | MACD 死叉空头信号 |

计算参数: EMA12, EMA26, DEA(9)

### 3. 量能分析 (Volume Ratio)

量比 = 当日成交量 / 过去5日平均成交量

| 条件 | 加减分 | 说明 |
|------|--------|------|
| 量比 >= 1.8 且涨幅 > 0 | +14 | 放量上涨，资金主动买入 |
| 量比 >= 1.2 | +7 | 温和放量 |
| 量比 < 0.6 | -4 | 明显缩量 |

### 4. 涨跌幅评分

| 条件 | 加减分 | 说明 |
|------|--------|------|
| 涨幅 >= 5% | +14 | 强势涨幅 |
| 涨幅 >= 2% | +8 | 红盘走强 |
| 涨幅 > 0% | +4 | 红盘 |
| 跌幅 <= -5% | -12 | 跌幅偏大 |
| 跌幅 <= -2% | -6 | 绿盘走弱 |

### 5. 20日价格位置

位置 = (当前价 - 20日最低) / (20日最高 - 20日最低)

| 条件 | 加减分 | 说明 |
|------|--------|------|
| 位置 >= 0.8 | +8 | 20日高位强势 |
| 位置 <= 0.25 | -5 | 20日低位承压 |

## 资金流向分类 (classify_flow)

综合信号 = 涨幅 * 0.7 + (量比 - 1) * 2.0 + (评分 - 50) / 20

| 信号值 | 分类 | flow_level | 中文标签 |
|--------|------|------------|----------|
| >= 3 | main_inflow | +2 | 主力流入 |
| >= 1 | slight_inflow | +1 | 微流入 |
| <= -3 | main_outflow | -2 | 主力流出 |
| <= -1 | slight_outflow | -1 | 微流出 |
| 其他 | balanced | 0 | 平衡 |

---

## 板块热度标签 (heat_label)

基于板块内所有个股的平均评分：

| 平均分 | 热度 | 说明 |
|--------|------|------|
| >= 70 | 强势 | 板块整体表现强劲 |
| >= 55 | 回暖 | 板块正在走强 |
| >= 40 | 震荡 | 板块方向不明 |
| >= 30 | 低迷 | 板块整体偏弱 |
| < 30 | 弱势 | 板块明显走弱 |

---

## 板块资金流向

取板块内所有个股 flow_level 的平均值（四舍五入）：

| 平均 flow_level | 标签 |
|-----------------|------|
| >= 2 | 主力流入 |
| = 1 | 微流入 |
| <= -2 | 主力流出 |
| = -1 | 微流出 |
| = 0 | 平衡 |

---

## 数据来源

- 实时行情: TDX 通达信行情协议 (pytdx)
- K线数据: TDX 日线 (80根)
- 全市场股票列表: 新浪财经 API (备选: TDX get_security_list)
- 服务器: 4台 TDX 服务器自动 failover，每台最多重试 3 次
