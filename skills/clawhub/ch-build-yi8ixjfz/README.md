# 宝洁八大问

基于宝洁八大问的行为面试准备技能。通过选择题启发式引导，帮助用户挖掘个人经历、构建STAR故事、模拟面试追问、优化答案表达。

## 安装

```bash
# ClawHub
clawhub install guipi888/pg-eight-questions

# SkillHub
skillhub install pg-eight-questions
```

## 功能

- **经历挖掘**：从用户经历中匹配最适配的故事
- **STAR构建**：填空式引导，手把手搭框架
- **模拟面试**：AI追问 + 5维度评分
- **答案优化**：逐句优化，补量化、强化个人贡献
- **复盘追踪**：记录练习进度，追踪薄弱点

## 使用指南

### 触发方式

安装后，在任意对话中说以下任意一句即可触发：

- 准备宝洁八大问
- 行为面试准备
- STAR 法则
- 面试准备
- 经历挖掘
- 模拟面试

### 完整流程概览

技能会引导你完成以下 6 个环节，每次对话聚焦 **1 个问题**：

```
经历挖掘 → 问题匹配 → STAR 构建 → 模拟面试 → 答案优化 → 复盘追踪
```

### 各环节详细说明

#### 1. 经历挖掘

**目的**：从你的背景中找出最适配的故事

**交互方式**：
1. 你选择当前状态（在校学生 / 在职人员 / 转行 / 其他）
2. 你选择最主要的经历类型（社团负责人 / 实习 / 课程项目 / 志愿者 / 其他）
3. 系统自动推荐最可能匹配的宝洁八大问问题（4 个 + 1 个「其他」）

**提示**：如果某个经历你很满意，先记下来，后面 STAR 构建会用到。

#### 2. 问题匹配

**目的**：根据你的经历，选出最先准备的问题

**交互方式**：
- 系统基于经历-能力映射，推荐 4 个最匹配的宝洁八大问问题
- 你选择 1 个开始准备
- 可以随时说「换一个」切换问题

**提示**：优先选你最熟悉、最有数据支撑的那个问题。

#### 3. STAR 构建

**目的**：把你的经历组织成结构化的 STAR 故事

**交互方式**：
- 系统按 **S → T → A → R** 顺序引导
- 每一步提供 **4 个具体选项 + 1 个「其他」**
- 你只需选择题，降低组织语言的门槛
- 选「其他」时，系统会追问开放式问题补全细节

**各步要点**：
- **S（情境）**：背景是什么？资源/时间/团队有什么限制？
- **T（任务）**：你的角色是什么？负责什么？
- **A（行动）**：你具体做了什么？用了什么方法？
- **R（结果）**：最终数据如何？有什么后续影响？

**提示**：尽量选带数字的选项，比如「提升了 30%」「减少了 2 天」。

#### 4. 模拟面试

**目的**：在真实面试压力下检验你的故事

**交互方式**：
1. 系统出题（标准问法）
2. 你作答
3. 系统追问 **2-3 个问题**（3 个追问方向 + 1 个「其他想补充的细节」）
4. 系统给出 **5 维度评分**（每个 1-5 分）

**评分维度**：
- 情境清晰度：背景易懂，复杂度足够
- 行动具体性：用具体动词描述自己做了什么
- 结果量化：有数据支撑，影响范围明确
- 结构完整性：STAR 四要素齐全
- 故事说服力：整体连贯、有说服力

**提示**：作答时尽量口语化，就像真的在面试一样。不要背诵，要讲出感觉。

#### 5. 答案优化

**目的**：把初版答案改得更专业、更有说服力

**交互方式**：
1. 系统逐句诊断原答案的问题（废话、空泛形容词、量化不足等）
2. 给出优化版完整答案
3. 逐条标注修改说明

**常见优化点**：
- 删除「优秀的」「巨大的」「快速的」等空泛词
- 加入具体数字、百分比、时间范围
- 把「我们」改成「我」，明确个人贡献
- 前 10 秒抓注意力，结果前置

#### 6. 复盘追踪

**目的**：追踪练习进度，识别薄弱点

**交互方式**：
- 说「我的进度」或「复盘」即可查看
- 系统展示每个问题的掌握程度（分数趋势）
- 指出薄弱问题 Top 2
- 推荐下一步优先练习哪个问题
- 如果某个故事已练习 3 次以上，推荐新故事

**提示**：建议每个问题至少练习 2-3 次，用不同故事反复打磨。

### 使用建议

| 场景 | 建议 |
|------|------|
| 首次使用 | 先完整走一遍「经历挖掘 → STAR 构建」，不追求完美 |
| 面试前 1 周 | 每天练习 2-3 个问题，重点做「模拟面试」 |
| 面试前一天 | 只看「复盘追踪」里的薄弱问题，巩固 2-3 个核心故事 |
| 面试后 | 回来更新故事，加入真实面试中的反馈 |

### 注意事项

- 每次对话聚焦 **1 个问题**，不要同时准备多个
- 选择经历时，优先选**你有量化数据**的那个
- 遇到「其他」选项时，尽量提供具体细节，系统会帮你整理
- 如果某个问题的故事已经练习 3 次以上，建议换一个新故事，避免模板化
