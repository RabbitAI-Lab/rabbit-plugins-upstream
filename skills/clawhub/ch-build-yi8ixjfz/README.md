# 宝洁八大问

基于宝洁八大问的行为面试准备技能。通过选择题启发式引导，帮助用户挖掘个人经历、构建STAR故事、模拟面试追问、优化答案表达。

## 安装

```bash
# ClawHub
clawhub install guipi888/pg-eight-questions

# SkillHub
skillhub install pg-eight-questions
```

## 功能

- **经历挖掘**：从用户经历中匹配最适配的故事
- **STAR构建**：填空式引导，手把手搭框架
- **模拟面试**：AI追问 + 5维度评分
- **答案优化**：逐句优化，补量化、强化个人贡献
- **复盘追踪**：记录练习进度，追踪薄弱点

## 使用方式

用户说"准备宝洁八大问"或"模拟面试"时触发。每次对话聚焦一个问题，引导用户完成从经历挖掘到答案优化的完整流程。
