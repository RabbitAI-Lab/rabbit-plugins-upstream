# 宝洁八大问技能

通过选择题启发式引导，帮助用户系统化准备宝洁八大问行为面试。

## 核心流程

1. **经历挖掘**：用户选择经历类型 → 系统推荐最匹配的经历 → 建立经历-能力映射
2. **问题匹配**：根据经历自动推荐最适配的宝洁八大问问题
3. **STAR构建**：每一步提供4个具体选项+1个「其他」，用户选择题启发式回忆
4. **模拟面试**：出题 → 作答 → 2-3轮追问 → 5维度评分
5. **答案优化**：原答案诊断 → 优化版 → 修改说明
6. **复盘追踪**：练习进度表 + 薄弱点识别 + 下一步建议

## 题库概览

| 问题 | 考察能力 |
|------|----------|
| 领导力 | 影响团队、驱动结果 |
| 说服力 | 说服他人、达成共识 |
| 团队协作 | 跨部门/跨角色协作 |
| 决策能力 | 复杂情境下做决定 |
| 数据分析 | 用数据驱动判断 |
| 影响力 | 无授权情况下影响他人 |
| 处理模糊性 | 在信息不全时推进 |
| 学习能力 | 快速学习新技能 |

## 评分维度

每个维度1-5分：
- 情境清晰度：背景易懂，复杂度足够
- 行动具体性：用具体动词描述自己做了什么
- 结果量化：有数据支撑，影响范围明确
- 结构完整性：STAR四要素齐全
- 故事说服力：整体连贯、有说服力

## 使用方式

用户说"准备宝洁八大问"或"模拟面试"时触发。每次对话聚焦一个问题，引导用户完成从经历挖掘到答案优化的完整流程。
