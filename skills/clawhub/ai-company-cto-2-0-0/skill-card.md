## Description:

AI Company CTO is a governance skill for designing, deploying, and optimizing autonomous AI-agent collaboration systems, with coverage for MLOps, security hardening, technology portfolio planning, CTO+CISO approval, and STRIDE architecture input.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, technical leaders, and AI-governance operators use this skill to plan and govern an AI-company CTO function, including agent collaboration architecture, MLOps lifecycle controls, technology portfolio planning, risk assessment, and CTO+CISO approval workflows.

## Known Risks and Mitigations:

Risk: Broad CTO automation authority and generic triggers may cause the skill to activate in high-impact governance or architecture contexts.

Mitigation: Require explicit invocation for high-impact work and keep human approval available for production changes, data modification, permission changes, and external API actions.

Risk: The artifact requests file read/write access, API network access, and agent orchestration capabilities.

Mitigation: Install and run the skill in a constrained workspace with least-privilege access and review proposed changes before applying them.
