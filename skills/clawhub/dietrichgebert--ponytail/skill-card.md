## Description:

Guides coding agents to make the smallest complete change and explain it concisely.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dietrichgebert](https://clawhub.ai/user/dietrichgebert)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to guide coding agents toward minimal, complete changes that respect existing patterns, tests, and safety checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The coding style stays active for the session and may affect unrelated tasks.

Mitigation: Say 'stop ponytail' or 'normal mode' before unrelated work.
