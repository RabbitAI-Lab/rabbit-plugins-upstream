## Description:

A coding mode that favors the smallest complete change and concise replies.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dietrichgebert](https://clawhub.ai/user/dietrichgebert)

### License/Terms of Use:

## Use Case:

Developers use this skill to make focused, complete coding changes while following the project's conventions and reporting skipped work or remaining risks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The coding mode remains active for the session and may affect later tasks.

Mitigation: Say 'stop ponytail' or 'normal mode' when you no longer want it active.
