## Description:

Lazy senior dev mode for any coding task: the smallest change that fully solves it, and a reply a busy human understands in one read.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dietrichgebert](https://clawhub.ai/user/dietrichgebert)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to guide an agent toward small, complete coding changes and concise handoffs across a session.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The minimal-change style remains active for the whole session and may influence unrelated tasks.

Mitigation: Say 'stop ponytail' or 'normal mode' before unrelated tasks if this style is not wanted.
