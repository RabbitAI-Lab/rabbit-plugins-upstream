## Description:

Guides coding agents toward small, maintainable solutions using YAGNI, existing code, and standard-library features before adding abstractions.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers use this skill to steer coding, refactoring, bug fixes, and reviews toward minimal changes without omitting required validation or safeguards.

### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: The minimalist coding preference remains active for coding tasks until the mode is changed or disabled.

Mitigation: Switch modes or say 'normal mode' when fuller design exploration or a different coding style is needed.
