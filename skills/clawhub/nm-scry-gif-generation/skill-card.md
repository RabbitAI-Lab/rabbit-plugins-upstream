## Description:

Converts webm/mp4 to optimized GIFs with ffmpeg

This skill is ready for commercial/non-commercial use.

## Publisher:

### License/Terms of Use:

## Use Case:

Developers and engineers use this skill to turn video recordings into shareable animated GIFs, adjusting frame rate, dimensions, palette, and dithering to balance quality and file size.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Following the ffmpeg installation example may require running a package-manager command with elevated privileges.

Mitigation: Review the install command and package source before running it, and use elevated privileges only if you intend to install ffmpeg and trust that source.
