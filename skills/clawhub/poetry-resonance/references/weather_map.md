# 天气 → 诗映射表

> 模式 C 日签的天气关联层。调用 wttr.in 免 key API（`https://wttr.in/<城市拼音>?format=j1`，取 current_condition 的 weatherDesc 英文关键词映射到下表类别；?lang=zh 可取中文描述）。查询只发城市名，禁止外发用户任何个人内容（同搜韵硬约束）。API 失败静默跳过，用户口报天气（"今天下雨"）可直接替代。

## 类别映射规则

weatherDesc 含 Rain/Drizzle/Shower/Thunder → 雨；Snow/Sleet/Blizzard → 雪；Clear/Sunny → 晴；Fog/Mist/Haze → 雾；Wind/Gale → 风；30C+ → 暑热；0C- → 严寒

## 雨

- 莫听穿林打叶声，何妨吟啸且徐行（苏轼·定风波）——雨天没伞索性慢慢走，旷达首选
- 随风潜入夜，润物细无声（杜甫·春夜喜雨）——春夜细雨，好雨知时节
- 夜雨剪春韭，新炊间黄粱（杜甫·赠卫八处士）——夜雨中现割的韭菜，招待老友的温度
- 白雨跳珠乱入船（苏轼·六月二十七日望湖楼醉书，底库可取）——夏天的急雨，砸出节奏感

## 雪

- 晚来天欲雪，能饮一杯无（白居易·问刘十九，待补库）——天要下雪了，来我家喝酒吗（冬日邀友天花板）
- 窗含西岭千秋雪（杜甫·绝句）——窗框里的雪山，日常里的远意
- 欲渡黄河冰塞川，将登太行雪满山（李白·行路难）——大雪封路式的人生卡顿
- 燕山雪花大如席（李白·北风行，底库可取）——北方暴雪的夸张修辞课

## 晴

- 两个黄鹂鸣翠柳，一行白鹭上青天（杜甫·绝句）——大晴天，眼睛变回相机
- 春风得意马蹄疾，一日看尽长安花（孟郊，待补库）——好天气+好心情的标准像
- 晴空一鹤排云上，便引诗情到碧霄（刘禹锡·秋词，待补库）——秋日晴天专用

## 风

- 长风万里送秋雁，对此可以酣高楼（李白·宣州谢朓楼）——起风了，登高正当时
- 大风起兮云飞扬（刘邦·大风歌，待补库）——狂风天的霸气侧漏
- 秋风吹不尽，总是玉关情（李白·子夜吴歌）——秋风起，思念跟着起

## 雾

- 日照香炉生紫烟，遥看瀑布挂前川（李白·望庐山瀑布）——雾气+晨光=紫烟，雾天的浪漫
- 烟涛微茫信难求（李白·梦游天姥吟留别，底库可取）——大雾封山，仙气缭绕
- 云深不知处（贾岛·寻隐者不遇，待补库）——雾天找人，只在此山中

## 暑热（30C+）

- 飞流直下三千尺，疑是银河落九天（李白·望庐山瀑布）——热到极致想看瀑布
- 炎蒸乃如许（杜甫·热，底库可取）——杜甫的热到写诗吐槽

## 严寒（0C-）

- 瀚海阑干百丈冰（岑参·白雪歌，待补库）——极寒天想起边塞
- 千山鸟飞绝，万径人踪灭（柳宗元·江雪，待补库）——独钓寒江雪的孤独美学

## 使用规则

1. 日签关联优先级：节气 > **天气** > 星期。同一天若节气与天气都有强关联，节气优先、天气作推荐理由的辅助（"处暑，又赶上一场秋雨"）
2. 天气诗句应季优先：春雨配春夜喜雨、秋雨配秋风吹不尽
3. 标注"待补库"的：模式引用时用自身知识核对原文并标注，下次扩库顺手入库
4. 用户口报天气时直接用口报类别，跳过 API
