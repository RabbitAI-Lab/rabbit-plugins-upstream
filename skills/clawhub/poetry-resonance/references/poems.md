# 诗库 · 李白卷

> 结构化诗库。以李白为主，字段含「朝代·作者」，后续扩展其他诗人直接追加条目即可。
> 共鸣场景要具体到生活/工作画面，不要泛泛。

## 目录（按情绪场景速查）

- 壮阔震撼：望庐山瀑布 / 望天门山 / 蜀道难 / 关山月
- 逆境不服：行路难 / 将进酒 / 上李邕 / 宣州谢朓楼
- 得意畅快：早发白帝城 / 南陵别儿童入京
- 孤独自处：月下独酌 / 独坐敬亭山
- 思乡：静夜思 / 春夜洛城闻笛 / 峨眉山月歌
- 友情送别：赠汪伦 / 黄鹤楼送孟浩然之广陵 / 送友人 / 闻王昌龄左迁龙标遥有此寄 / 客中行
- 岁月与月亮：把酒问月 / 子夜吴歌·秋歌 / 秋浦歌
- 闲适出尘：山中问答 / 庐山谣
- 爱情容貌：长干行 / 清平调

### 望庐山瀑布 · 李白（唐）
- 原文：日照香炉生紫烟，遥看瀑布挂前川。飞流直下三千尺，疑是银河落九天。
- 人话背景：李白五十岁上下漫游庐山，见瀑布而写，是他浪漫夸张手法的极致——不写实，写"被震到说不出话"的感觉。
- 情绪内核：面对壮阔自然时的失语与惊叹。
- 共鸣场景：旅行看到瀑布/大江/雪山/星空被震撼；熬了很久的项目终于上线那一刻的冲击感。
- 金句：飞流直下三千尺，疑是银河落九天。
- 配图意境：瀑布水汽、大面积留白水墨、银河星轨。
- 日签关联：夏季丰水期、出行季、黄金周。

### 望天门山 · 李白（唐）
- 原文：天门中断楚江开，碧水东流至此回。两岸青山相对出，孤帆一片日边来。
- 人话背景：25岁的李白初出四川、顺江东下，年轻气盛，看什么都开阔。
- 情绪内核：初见天地之大，孤身一人却不怕，反而豪情满怀。
- 共鸣场景：毕业远行/第一次去大城市/新城市入职第一周；独自开始一项新事业。
- 金句：两岸青山相对出，孤帆一片日边来。
- 配图意境：江面开阔、孤舟、日出。
- 日签关联：开学季、毕业季、开年第一个工作日。

### 蜀道难 · 李白（唐）
- 原文（节选）：噫吁嚱，危乎高哉！蜀道之难，难于上青天！……一夫当关，万夫莫开。
- 人话背景：借蜀道之险写世路之难，通篇夸张惊叹，是李白想象力的代表。
- 情绪内核：明知前路极难，仍要用气势把它说出来。
- 共鸣场景：接手一个公认的"硬骨头"项目；跨行转岗；考研考公冲刺期。
- 金句：蜀道之难，难于上青天。／一夫当关，万夫莫开。
- 配图意境：栈道、绝壁、云雾山峦。
- 日签关联：项目启动日、挑战性任务开场。

### 行路难·其一 · 李白（唐）
- 原文（节选）：金樽清酒斗十千，玉盘珍羞直万钱。停杯投箸不能食，拔剑四顾心茫然。……长风破浪会有时，直挂云帆济沧海。
- 人话背景：李白被"赐金放还"赶出长安，朋友设宴送别，他吃不下去——但最后还是相信自己会有扬帆的那天。
- 情绪内核：陷入低谷的茫然 + 不肯认输的底气。李白失意诗的招牌：丧到底，最后一句必翻盘。
- 共鸣场景：被裁员/项目黄了/方案被毙的当晚；努力很久看不到结果的时候。
- 金句：长风破浪会有时，直挂云帆济沧海。
- 配图意境：风浪中的帆、暗色海面透出光。
- 日签关联：周一开工、低谷期、季度末冲刺。

### 将进酒 · 李白（唐）
- 原文（节选）：君不见黄河之水天上来，奔流到海不复回。……人生得意须尽欢，莫使金樽空对月。天生我材必有用，千金散尽还复来。……与尔同销万古愁。
- 人话背景：李白政治失意后与朋友喝酒，一半是狂放，一半是巨大 的失落——越喊"得意须尽欢"，越说明不得意。
- 情绪内核：怀才不遇的愤懑，用豪饮把它盖过去；"天生我材必有用"是给自己打气的话。
- 共鸣场景：被否定但不服气的时候；聚会散场后的复杂心情；想辞职的那个晚上。
- 金句：天生我材必有用，千金散尽还复来。
- 配图意境：奔流黄河、酒杯、篝火。
- 日签关联：周五晚上、聚会日、失意期自我打气。

### 上李邕 · 李白（唐）
- 原文：大鹏一日同风起，扶摇直上九万里。假令风歇时下来，犹能簸却沧溟水。世人见我恒殊调，闻余大言皆冷笑。宣父犹能畏后生，丈夫未可轻年少。
- 人话背景：年轻李白拜见名士李邕被冷遇，直接写诗回敬：别看我年轻，大鹏迟早上天。年轻人被轻视时的教科书式回应。
- 情绪内核：年少气盛，被看轻也不内耗，直接反击。
- 共鸣场景：会上发言被 senior 打断；作品被说"你没经验"；年轻人初入职场被质疑。
- 金句：大鹏一日同风起，扶摇直上九万里。
- 配图意境：大鹏展翅、风云。
- 日签关联：开学/入职第一天、被质疑后的早晨。

### 宣州谢朓楼饯别校书叔云 · 李白（唐）
- 原文（节选）：弃我去者，昨日之日不可留；乱我心者，今日之日多烦忧。长风万里送秋雁，对此可以酣高楼。……抽刀断水水更流，举杯销愁愁更愁。人生在世不称意，明发弄扁舟。
- 人话背景：李白在谢朓楼送别族叔，一大半在倒自己的苦水：昨天留不住，今天全是烦心事。但写起秋景依然开阔。
- 情绪内核：成年人的愁——烦却说不清具体为啥烦；李白给出的出口是"抽刀断水"式的承认：有些愁消不掉，那就先登高喝酒。
- 共鸣场景：说不清原因就是很烦的一天；工作琐事堆叠的周三下午；深夜emo。
- 金句：抽刀断水水更流，举杯销愁愁更愁。／长风万里送秋雁。
- 配图意境：高楼、雁阵、长风、江水。
- 日签关联：处暑及初秋（长风万里送秋雁）、周三倦怠期、烦心事多的时候。

### 早发白帝城 · 李白（唐）
- 原文：朝辞白帝彩云间，千里江陵一日还。两岸猿声啼不住，轻舟已过万重山。
- 人话背景：李白因永王案被流放夜郎，走到白帝城忽遇大赦——掉头回家。全诗的"快"不只是船快，是如释重负的心快。
- 情绪内核：劫后余生的轻快，压在身上的大山忽然搬走。
- 共鸣场景：体检报告没事、大项目验收通过、久等的结果终于来了、解封/出关那一刻。
- 金句：轻舟已过万重山。
- 配图意境：轻舟顺流、彩云、两岸青山后掠。
- 日签关联：周五、长假前最后一天工作日、坏消息解除的日子。

### 南陵别儿童入京 · 李白（唐）
- 原文（节选）：白酒新熟山中归，黄鸡啄黍秋正肥。……仰天大笑出门去，我辈岂是蓬蒿人。
- 人话背景：42岁的李白接到朝廷征召，以为自己终于要被重用了，告别家人时按捺不住的得意。"仰天大笑"是中国诗里最爽的出门。
- 情绪内核：长期等待终于等来机会的扬眉吐气。
- 共鸣场景：拿到 offer、方案终于获批、创业启动、考试上岸。
- 金句：仰天大笑出门去，我辈岂是蓬蒿人。
- 配图意境：大笑出门、秋日晴空。
- 日签关联：周五下班、offer/上岸日、出发去新事业的日子。

### 月下独酌·其一 · 李白（唐）
- 原文（节选）：花间一壶酒，独酌无相亲。举杯邀明月，对影成三人。……永结无情游，相期邈云汉。
- 人话背景：李白在长安做闲官，无人陪酒，干脆邀请月亮和自己的影子凑一桌。孤独被他玩出了浪漫。
- 情绪内核：一个人的孤独，不自怜，反而自得其乐——把"没人陪"过成"和月亮喝酒"。
- 共鸣场景：一个人吃火锅/看电影/过周末不觉得惨；独居的晚上；一个人旅行。
- 金句：举杯邀明月，对影成三人。
- 配图意境：月下独酌、花影。
- 日签关联：十五月圆夜、独处周末、一个人过节。

### 独坐敬亭山 · 李白（唐）
- 原文：众鸟高飞尽，孤云独去闲。相看两不厌，只有敬亭山。
- 人话背景：晚年李白游敬亭山，鸟飞光了云也走了，只剩他和山对望。历尽繁华后的安静。
- 情绪内核：热闹散尽后与自己的相处；不依赖任何人陪伴的自在。
- 共鸣场景：退出群聊的清净；一个人爬山；关掉手机的一晚。
- 金句：相看两不厌，只有敬亭山。
- 配图意境：独坐山亭、远山、闲云。
- 日签关联：独处日、周末爬山、数字排毒日。

### 静夜思 · 李白（唐）
- 原文：床前明月光，疑是地上霜。举头望明月，低头思故乡。
- 人话背景：26岁的李白旅居扬州（一说他处）病中望月。全世界中国人都会背的一首，背的是肌肉记忆，懂它要等离家之后。
- 情绪内核：不设防的一瞬间被乡愁击中。
- 共鸣场景：加班到深夜走出写字楼抬头看到月亮；出租屋里过节；和爸妈视频挂断之后。
- 金句：举头望明月，低头思故乡。
- 配图意境：窗前月光、清冷色调。
- 日签关联：中秋、月末想家时、深夜加班。

### 春夜洛城闻笛 · 李白（唐）
- 原文：谁家玉笛暗飞声，散入春风满洛城。此夜曲中闻折柳，何人不起故园情。
- 人话背景：客居洛阳的春夜，不知谁家笛声吹《折柳》，整座城都想家了。乡愁被一声音乐触发。
- 情绪内核：某个偶然的声音/气味瞬间勾起思念。
- 共鸣场景：异国街头听到中文歌；闻到食堂饭菜像妈妈做的；老歌前奏响起。
- 金句：此夜曲中闻折柳，何人不起故园情。
- 配图意境：春夜、笛声、灯影。
- 日签关联：春天的夜晚、海外游子、听到老歌的日子。

### 峨眉山月歌 · 李白（唐）
- 原文：峨眉山月半轮秋，影入平羌江水流。夜发清溪向三峡，思君不见下渝州。
- 人话背景：年轻的李白第一次离开蜀地，坐船顺江东下，一路回头看峨眉山的月亮。出发与不舍同时发生。
- 情绪内核：离开家乡时一边向往一边回头。
- 共鸣场景：离家上学/工作第一晚；搬离住了很久的城市。
- 金句：峨眉山月半轮秋，影入平羌江水流。
- 配图意境：江上月、行舟。
- 日签关联：开学季离乡、九月、出发的日子。

### 赠汪伦 · 李白（唐）
- 原文：李白乘舟将欲行，忽闻岸上踏歌声。桃花潭水深千尺，不及汪伦送我情。
- 人话背景：村民汪伦盛情款待李白数日，李白走时他踏歌相送。李白直接把自己名字写进诗里——真朋友不整虚的。
- 情绪内核：被朋友的用心击中；朴素情谊胜过千言万语。
- 共鸣场景：朋友凌晨来机场接你；同事默默帮你扛了锅；离别时对方的意外用心。
- 金句：桃花潭水深千尺，不及汪伦送我情。
- 配图意境：渡口、桃花、舟。
- 日签关联：送别日、友情相关节日、朋友结婚。

### 黄鹤楼送孟浩然之广陵 · 李白（唐）
- 原文：故人西辞黄鹤楼，烟花三月下扬州。孤帆远影碧空尽，唯见长江天际流。
- 人话背景：李白在黄鹤楼送偶像孟浩然去扬州，看着船走远、帆变成小点、最后只剩长江。不舍，但没有挽留，只有目送。
- 情绪内核：成年人的送别——不拦着你去好地方，只是站很久。
- 共鸣场景：送朋友去外地发展/出国；车站机场目送；退群前最后的道别。
- 金句：孤帆远影碧空尽，唯见长江天际流。
- 配图意境：江面孤帆、烟柳三月。
- 日签关联：三月春天、毕业季、送别远行的人。

### 送友人 · 李白（唐）
- 原文：青山横北郭，白水绕东城。此地一为别，孤蓬万里征。浮云游子意，落日故人情。挥手自兹去，萧萧班马鸣。
- 人话背景：城外送别，李白看浮云像游子、落日像自己舍不得的心情，连马都舍不得地嘶鸣。
- 情绪内核：目送朋友远行时，周围一切都在替你说舍不得。
- 共鸣场景：搬家那天帮朋友扛完最后一箱；同事离职最后一天一起下楼。
- 金句：浮云游子意，落日故人情。
- 配图意境：青山落日、古道。
- 日签关联：离职季（金三银四）、秋天送别。

### 闻王昌龄左迁龙标遥有此寄 · 李白（唐）
- 原文：杨花落尽子规啼，闻道龙标过五溪。我寄愁心与明月，随君直到夜郎西。
- 人话背景：好友王昌龄被贬到偏远的龙标（今湖南黔阳一带）做小官，"左迁"就是贬官。李白听说后写诗寄他——自己没法送，就把牵挂托付给月亮，让月亮替自己一路陪他过去。
- 情绪内核：帮不上忙的担心，用浪漫的方式送达：我陪不了你，月亮可以。
- 共鸣场景：朋友被调岗/外派/去了很远的地方，想安慰却见不到面；深夜想起某个远方的朋友，想发消息又怕打扰。
- 金句：我寄愁心与明月，随君直到夜郎西。
- 配图意境：暮春柳絮、杜鹃啼鸣、明月、驿路远山。
- 日签关联：暮春（杨花落尽时）、朋友远行或离别的日子、月圆夜想朋友。

### 客中行 · 李白（唐）
- 原文：兰陵美酒郁金香，玉碗盛来琥珀光。但使主人能醉客，不知何处是他乡。
- 人话背景：做客他乡被主人款待，酒好、心意更好，喝着喝着他乡就不像他乡了。
- 情绪内核：被款待的温暖能消解漂泊感。
- 共鸣场景：出差被当地同事带去吃地道小馆；在陌生城市被朋友收留一顿饭。
- 金句：但使主人能醉客，不知何处是他乡。
- 配图意境：暖色酒盏、宴席灯火。
- 日签关联：出差日、被朋友请客的日子。

### 把酒问月 · 李白（唐）
- 原文（节选）：今人不见古时月，今月曾经照古人。古人今人若流水，共看明月皆如此。唯愿当歌对酒时，月光长照金樽里。
- 人话背景：李白端着酒问月亮：我们看不到古时候的月亮，但今晚这轮月照过古人。人类一代代像流水，月亮始终是同一轮。
- 情绪内核：对时间的怅然 + 释然——正因人人如流水，共看同一轮月才显得珍贵。
- 共鸣场景：在中秋想"一千年前也有人这样看月亮"；逛博物馆看文物；和爸妈看他们年轻时的照片。
- 金句：今人不见古时月，今月曾经照古人。
- 配图意境：古人对月与现代人望月同框、长曝光月光。
- 日签关联：中秋、月圆之夜、博物馆日。

### 子夜吴歌·秋歌 · 李白（唐）
- 原文：长安一片月，万户捣衣声。秋风吹不尽，总是玉关情。何日平胡虏，良人罢远征。
- 人话背景：秋夜长安，家家在河边捣衣准备冬装，思念戍边的丈夫。李白写的是普通人的秋天。
- 情绪内核：秋声一起，思念跟着起；日常劳作里藏着的牵挂。
- 共鸣场景：换季整理衣柜看到家人织的毛衣；天一凉就想给爸妈打电话。
- 金句：秋风吹不尽，总是玉关情。
