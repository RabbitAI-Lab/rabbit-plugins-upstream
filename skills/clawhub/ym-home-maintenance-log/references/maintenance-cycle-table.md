# 各品类保养周期表与自做判定

本表为「建议周期」，实际以设备说明书与厂商官方建议为准。使用频率高、环境多尘/多油烟/潮湿的地区，周期应适当缩短；反之可延长。凡标「需专业人员」的项，技能输出中只写「联系专业人员」，不得给出具体拆机或带电操作步骤。

## 一、各品类保养周期与依据

| 品类 | 保养项 | 建议周期 | 依据 / 说明 |
|---|---|---|---|
| 空调（挂机/柜机） | 清洗滤网、外壳与出风口 | 换季使用前 + 使用期每 1~2 个月 | 滤网积灰影响风量、滋生霉菌与异味；高频使用缩短到每月 |
| 空调 | 深度清洗蒸发器与风轮、查制冷剂 | 每 1~2 年 | 涉及拆机与制冷剂，需专业人员；非用户自做范围 |
| 油烟机 | 油网、油杯清洗 | 每 1~2 周 | 油污堆积影响吸力、有火灾隐患 |
| 油烟机 | 叶轮/风道深度清洗 | 每 3~6 个月 | 重油烟家庭缩短；深度清洗常需拆机，建议专业人员 |
| 电热水器 | 排污、除垢、查镁棒 | 每 6~12 个月 | 内胆结垢影响效率与寿命，镁棒消耗需检查更换 |
| 电热水器 | 加热管、内胆检修 | 异常时 | 涉及拆机与电路，需专业人员 |
| 燃气热水器 | 清理进气滤网、外观 | 每 3~6 个月 | 外部可触及部分用户可做 |
| 燃气热水器 | 燃烧器、水路、气路检修 | 每 1~2 年或异常时 | 涉及燃气与燃烧，必须专业人员 |
| 净水器 | 滤芯更换（PP棉/活性炭） | 3~6 个月 | 具体以滤芯类型与水质/通量为准，说明书为准 |
| 净水器 | 滤芯更换（RO 反渗透膜） | 12~24 个月 | 出水变慢或 TDS 升高即提示更换 |
| 洗衣机 | 筒自洁 / 清洁剂洗内筒 | 每 1~2 个月 | 防止霉菌与异味，建议用专用清洁剂空转 |
| 洗衣机 | 清理滚筒密封圈、洗涤剂盒、排污泵滤网 | 每 1~3 个月 | 用户可自做，属外部可触及 |
| 燃气灶 | 炉头、火盖、盛液盘清洁 | 每 1~2 周 | 防堵塞、保火力均匀 |
| 燃气灶 | 气路、点火器、喷嘴检修 | 异常时 | 涉及燃气，需专业人员 |
| 冰箱 | 清理背部/底部散热网（冷凝器） | 每 3~6 个月 | 积灰影响散热与耗电 |
| 冰箱 | 内胆除味、密封条检查 | 每 1~3 个月 | 用户可自做 |
| 壁挂炉 / 地暖 | 系统排污、压力表查看 | 每供暖季前 | 用户可看压力表、排气 |
| 壁挂炉 / 地暖 | 燃烧、换热、水泵深度保养 | 每 1~2 年 | 涉及燃气与水路，需专业人员 |
| 微波炉 / 烤箱 | 内腔清洁 | 使用后即时或每周 | 用户可自做，断电后擦拭 |
| 洗碗机 | 清理滤网、加盐与亮碟剂 | 每 1~2 周 | 用户可自做 |
| 电视机 / 电脑 | 散热孔除尘 | 每 3~6 个月 | 用户可断电后外部除尘，不开壳 |
| 电动窗帘 / 智能锁 | 查电池、轨道润滑 | 每 6~12 个月 | 用户可换电池；机械卡顿建议售后 |

## 二、可自做 vs 必须找专业人员 判定表

判定原则：只动「外部可触及、不断电拆机、不碰燃气与制冷剂、不登高」的，属用户可自做；其余一律专业人员。

| 情形 | 判定 | 理由 |
|---|---|---|
| 拆机打开外壳（空调内机、油烟机叶轮、洗衣机内筒拆盖） | 需专业人员 | 拆装不当损坏设备，且有触电风险 |
| 涉及燃气（燃气热水器、燃气灶气路/燃烧器） | 需专业人员 | 燃气泄漏有爆炸与中毒风险 |
| 涉及电路（带电检测、更换加热管、主板维修） | 需专业人员 | 触电与短路风险 |
| 涉及制冷剂（加氟、放冷媒、检漏） | 需专业人员 | 需专用设备与资质，操作不当伤人且违法排放 |
| 高空作业（外机在高处、需出窗外） | 需专业人员 | 坠落风险，需高空作业资质与安全带 |
| 滤网/油网/滤芯/密封圈/散热网等外部可拆洗件 | 可自做 | 外部可触及、断电即可操作 |
| 压力表查看、电池更换、外部除尘 | 可自做 | 不拆机、不碰危险部件 |
| 设备异响/漏水/不制冷等故障 | 需专业人员 | 多为内部部件问题，先断电停用再报修 |

**输出纪律**：凡落入「需专业人员」的项，技能只写「建议联系品牌售后或持证专业人员处理」，不写任何拆机、通电、放冷媒、登高步骤。保修期内优先走官方售后，避免私拆失保。
