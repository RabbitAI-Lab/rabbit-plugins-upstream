# 鲁迅写作手法的现代应用场景 · v2.0

> v1.0 包含"商业文案""社交媒体"等矮化场景——这是对鲁迅的背叛。
> v2.0 **全部重写**：只保留鲁迅式写作真正有力量的场景。
>
> **鲁迅式写作不适合：软文、鸡汤、温情推送。**
> **鲁迅式写作适合：需要解剖、需要怀疑、需要让人"不舒服"的场景。**

---

## 场景 1：杂文 / 时评 / 批评文章（最核心）

### 适用技法组合
**反讽 + 对比 + 反问激愤 + 自我解剖**

### 典型主题
- 社会现象批评
- 文化反思
- 行业乱象解剖
- 制度性恶的揭示
- 集体冷漠的诊断

### 实战示例（主题：35 岁危机）

**v1.0 版本**（温情化）：
"昨晚，朋友老张把工牌剪了。35 岁整。
他没有哭。他把工牌的挂绳放进抽屉，绳子上还有汗渍。
……（温情个人成长故事）"

**v2.0 版本**（鲁迅式杂文）：
"昨晚，朋友老张把工牌剪了。35 岁整。
**HR 系统里的'35 岁红线'，比他自己更早知道他的生日**。
他不是被裁的。是被一个算法裁的。
我听完，没说'加油'。**我说不出'加油'**——我说'加油'，等于帮那个算法背书。
我想说真话，但真话是：不是他不够努力，是这种'努力'的定义本身，就在吃一代人。
**不是某个人坏。是这种用'35 岁红线'计算人的方式在吃人。**
他走了之后，我在朋友圈发了一段话。
点赞的人很多。**点赞的人里，有 3 个是 HR——他们正在裁下一个人**。
我们都在点赞。我们都在吃人。
我也是。"

### 技法标注（v2.0）
- **🆕 指向结构性恶**："不是某个人坏。是这种用'35 岁红线'计算人的方式在吃人。"
- **🆕 自我解剖**："点赞的人里，有 3 个是 HR——他们正在裁下一个人"
- **🆕 看客解剖**："我们都在点赞。我们都在吃人。"
- **🆕 鲁迅式结尾**："我也是。"——三字承担全部重量

## 场景 2：演讲稿（严肃场合）

### 适用技法组合
**反问激愤 + 象征 + 短句节奏 + 自我解剖意识**

### 典型主题
- 学术演讲
- 行业会议发言
- 毕业典礼致辞
- 公开演讲（不是营销）

### 实战示例（开场白）

"各位，我问大家三个问题——
今天，是谁在深夜关灯？是清洁阿姨。
今天，是谁在大年初一还在值班？是保安大哥。
今天，是谁在你失败的时候没有放弃你？是你自己。
但你自己，是从哪来的？
**是他们的每一个凌晨，每一次值班，每一次不肯放弃**。
**不是'我们为他们'。是我们就来自他们**。
**我们不是为他们鼓掌——我们就是他们的延续**。
——这个公司，不是'我们'的公司。**是'他们'的公司**。"

### 技法标注（v2.0）
- **🆕 解构"我们"**："我们不是为他们鼓掌——我们就是他们的延续"——拒绝廉价的"致敬"
- **🆕 鲁迅式冷峻**："这个公司，不是'我们'的公司。是'他们'的公司"
- **不煽情**：每个字都指向结构性承认，不是廉价感动

## 场景 3：悼词 / 人物速写（不温情化）

### 适用技法组合
**白描 + 片段连缀 + 自我解剖**

### 实战示例（主题：怀念一位普通同事）

"老李走了。
昨天我经过他的工位，屏幕还亮着。密码锁屏的图，是他家小狗。
他桌面有一支笔，笔帽丢了。他永远找不到笔帽。
他抽屉里有一包没拆的烟——他答应女儿要戒烟的。戒烟戒了三个月，那包烟就在抽屉里躺了三个月。
**他走的那天早上，他的狗应该还在家里等他——它不知道，戒烟成功的人，突然也不在了。**
他走的那天，把钥匙交给了我。钥匙上拴着一个塑料小鸭子，是他女儿挂的。
我捏着那个鸭子，愣了一会儿。
——**我答应他，我会继续帮他女儿把那包烟戒完。但我心里知道：他需要戒的，从来不是烟**。
**他需要戒的，是这个不让人停下来的系统。**
这系统里，我也是其中之一。"

### 技法标注（v2.0）
- **🆕 看客解剖 / 共谋承担**："这系统里，我也是其中之一"
- **🆕 指向结构性恶**："他需要戒的，是这个不让人停下来的系统"
- **🆕 自我解剖**："我心里知道"
- **鲁迅式余味**：结尾"这系统里，我也是其中之一"——三字冷峻

## 场景 4：评论员文章 / 时评

### 适用技法组合
**反讽 + 象征 + 短句节奏 + 看客解剖**

### 实战示例（主题：朋友圈点赞）

"凌晨，我看到一个朋友转发的社会新闻。
是个悲剧。
我点进去，看完，没点赞。
但我**截图保存**了。
保存完，发给我的另一个朋友，说："看看这个。"
我朋友看完，也没点赞。又截图。又发。
**这场悲剧，被我们传递了三次，点赞了零次**。
**没有人点赞，是因为'点赞'显得太轻。但'截图转发'让我们以为自己'在场'**。
我们都不在场。
**我们都是看客**。
**新闻里那个人，永远不知道，她的悲剧在凌晨三点被截图了 47 次，被点赞 0 次**。"

### 技法标注（v2.0）
- **🆕 看客解剖**："这场悲剧，被我们传递了三次，点赞了零次"
- **🆕 自我解剖**："我点进去，看完，没点赞。但我截图保存了"
- **🆕 指向结构性恶**：现代"截图转发"代替"点赞"成为看客的新形态
- **鲁迅式冷峻数据**："截图了 47 次，被点赞 0 次"——虚构但真实的数字

## 场景 5：学术性反思 / 学术随笔

### 适用技法组合
**对比 + 反讽 + 不给答案**

### 实战示例（主题：学术评价体系）

"中文系有个传统：每年评一次'优秀论文'。
去年评上的那位，论文题目是《论鲁迅杂文中的吃人主题》。
评委打分：95 分。
理由：选题新颖，论证严密，文笔流畅。
**没有人问：他自己有没有在吃人**。
**评委问的是论文好不好——不是这个人是不是还在吃人**。
我不是说他的论文不好——他的论文很好。
**我只是想：当我们评'鲁迅研究'优秀论文的时候，我们自己有没有真的变成鲁迅？**
**如果我们一边研究鲁迅，一边表演'鲁迅研究者'的体面——这和《肥皂》里的四铭，有什么区别？**
**我们都在做"研究吃人"的人——同时自己也吃人。**
这种自我解剖，在学术评奖体系里，是不允许的。
**不允许，意味着这种评奖体系，本身就在吃鲁迅**。"

### 技法标注（v2.0）
- **🆕 自我解剖**："我们自己有没有真的变成鲁迅"
- **🆕 指向结构性恶**："不允许，意味着这种评奖体系，本身就在吃鲁迅"
- **🆕 鲁迅式反讽**：四铭的当代版是"鲁迅研究者"
- **鲁迅式结尾**：不留温情，留"这种评奖体系，本身就在吃鲁迅"——这是鲁迅式解剖

## 场景 6：个人随笔（怀疑式）

### 适用技法组合
**象征 + 短句节奏 + 自我解剖**

### 实战示例（主题：回乡记）

"十年没回家。
下了高铁，又坐了三个小时大巴。路两边是山，山上还是树——和十年前一样。
镇上唯一变了的是多了三家快递站。
我妈在车站等我。她没有抱我——她从来不抱。
她看了我一眼，说：'瘦了。'
我'嗯'了一声。
回到家，桌上摆了八道菜。我爸没说话，给我倒了酒。
我端起酒杯，看见他眼角的皱纹——和十年前比，深了不止一倍。
**我没说话。我也不问**。
**我和他之间，已经有了一堵看不见的墙——十年没回家，这堵墙是我砌的**。
**我们都在砌墙。我们都在墙那边**。
八道菜里有六道是我小时候爱吃的。
**她记得我爱吃什么——但她不知道我现在爱吃什么**。
我吃了第一口，眼泪掉了下来。
**我没掉的是：她也在吃她自己——她不说为什么不抱我，她不说为什么记得我爱吃什么，她不说她自己十年过得怎么样**。
**我们都在演一个家**。"

### 技法标注（v2.0）
- **🆕 自我解剖**："这堵墙是我砌的"
- **🆕 看客解剖 / 共谋**："我们都在砌墙。我们都在墙那边"
- **🆕 指向结构性恶**："她也在吃她自己"
- **🆕 鲁迅式结尾**：不留温情，留"我们都在演一个家"

## 场景 7：高考作文（深度立意）

### 适用技法组合
**反讽 + 象征 + 鲁迅式结尾 + 自我解剖意识**

### 实战示例（题目：2026 高考作文 · "努力"一词的理解变化）

**v1.0 版本**（温情化）：
"高考前最后一个春天，母亲在我床头多摆了一个闹钟。
……（温情个人成长 + '努力是给自己用的'鸡汤警句）"

**v2.0 版本**（鲁迅式高考作文）：

[详见 SKILL.md v2.0 调用后的实战改稿]

**核心要点**：
- ✅ 不写"母亲很伟大"
- ✅ 不写"努力是给自己用的"鸡汤
- ✅ 写**"努力"这个词被偷换了含义**——指向结构性恶
- ✅ **叙述者也承担"看客"责任**
- ✅ **结尾不留廉价希望**

**鲁迅式高考作文可用立意**（备选）：

| 立意 | 鲁迅式笔法 |

| "卷" | "卷不是个人选择，是评价体系在吃人" |

| "成功" | "成功不是个人奋斗，是'必须成功'的规训在吃人" |
| "选择" | "选择不是自由，是'你以为有选择'的幻觉" |

## 🆕 场景 8：演讲稿（让观众"不舒服"）

### 适用技法组合
**反问激愤 + 象征 + 自我解剖**

### 实战示例（毕业致辞 · 鲁迅式）

"同学们，从今天起，你们就要毕业了。
按照惯例，我应该祝大家前程似锦。
但我不想祝你们前程似锦——因为'前程似锦'这四个字，让我想起一些事情。
'前程似锦'的背后，是什么样的评价体系？
是**用 35 岁红线计算人的体系**。
是**用'清北复交'标签化人的体系**。
是**用'房子车子票子'规训人的体系**。
**你们即将进入的，是一个吃人的体系——它会告诉你'你不努力'，但从来不会告诉你'这个努力的方向本身就是错的'**。
你们即将进入的，是一个看客的体系——**你的失败会被转发，你的悲剧会被截图，你的孤独会被消费**。
我祝你们什么呢？
**我祝你们在被这个体系吃的时候，至少知道自己在被吃。**
**我祝你们在变成看客之前，至少先意识到自己是看客。**
**我祝你们在说出'努力'这个词的时候，先问一句：这个词是谁定义的？**
——这就是我今天要祝你们的。"
（全场沉默三秒。）

### 技法标注（v2.0）
- **🆕 解构"前程似锦"**：这是鲁迅式反讽的最高形态——解构仪式本身
- **🆕 指向结构性恶**：毕业致辞里 3 个"体系"指认
- **🆕 自我解剖**：暗示"我也在这个体系里"
- **🆕 不给廉价希望**："我祝你们在被这个体系吃的时候，至少知道自己在被吃"
- **🆕 鲁迅式余味**：结尾"这就是我今天要祝你们的"——让听众"不舒服"三秒

## 🚫 不适合鲁迅式写作的场景（v2.0 明确删除）

- 🚫 **商业文案 / 产品软文** —— 鲁迅式写作的灵魂是解剖，不是营销
- 🚫 **社交媒体 / 朋友圈文案** —— 太重，不适合碎片化阅读
- 🚫 **鸡汤文 / 励志文** —— 鲁迅式写作的灵魂是反鸡汤
- 🚫 **节日祝福 / 温情推送** —— 鲁迅不给温情安慰
- 🚫 **"如何成功"的演讲** —— 鲁迅不解构成功神话
- 🚫 **婚礼致辞 / 满月酒发言** —— 这种场合不需要鲁迅

## 结语

> v2.0 应用场景的核心转变：
>
> **从"鲁迅技法工具箱"到"鲁迅精神立场"**
>
> 鲁迅式写作**只适合需要解剖、需要怀疑、需要让人"不舒服"的场景**。
>
> 如果你的场景需要让读者**舒服、感动、相信、希望**——**别用鲁迅**。
>
> 如果你的场景需要让读者**停下来想一想、看一看、解剖一下**——**用鲁迅**。
>
> 工具是死的，人是活的。
> 但**鲁迅式写作要求你冷下来**。

—— Richard，蒸馏自鲁迅小说全集 33 篇
