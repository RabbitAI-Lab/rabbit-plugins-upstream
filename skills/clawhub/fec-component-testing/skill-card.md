## Description:

Helps developers write and review frontend unit, component, and light integration tests focused on user-visible behavior.

This skill is ready for commercial/non-commercial use.

## Publisher:

[bovinphang](https://clawhub.ai/user/bovinphang)

### License/Terms of Use:

## Use Case:

Frontend developers use this skill to create and review React and Vue component tests, including interaction, accessibility, loading, error, and regression scenarios.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generic testing requests may activate this skill when a broader testing strategy, end-to-end flow, or existing validation failure needs a different workflow.

Mitigation: Confirm the task concerns frontend component or UI-adjacent tests; use the corresponding strategy, E2E, or validation workflow otherwise.
