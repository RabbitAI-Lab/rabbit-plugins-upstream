STEP

01

准备工作

开始之前，先安装依赖。建议使用虚拟环境，避免污染系统 Python。

安装完成后，用一行命令验证环境是否就绪：

pip install pandas matplotlib jupyter

python -c "import pandas; print(pandas.__version__)"

STEP

02

读取与清洗数据

拿到数据的第一步永远是看结构，而不是直接跑分析。

缺失值先处理，不要带着空值做统计。

重复订单要先去重，否则统计结果会虚高。

列名

user_id / int / 用户编号

金额

amount / float / 订单金额

时间

created_at / datetime / 下单时间

后台经验：清洗数据通常占整个项目 60% 的时间，值得单独排期。

STEP

03

可视化与结论

用 matplotlib 画一张趋势图，让结论自己说话。

结论先行：客单价上升了 12%，主要来自老用户复购。

+12%

客单价提升 · 老用户复购驱动
