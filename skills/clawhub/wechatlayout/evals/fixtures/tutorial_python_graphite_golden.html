I.

准备工作

开始之前，先安装依赖。建议使用虚拟环境，避免污染系统 Python。

安装完成后，用一行命令验证环境是否就绪：

pip install pandas matplotlib jupyter

python -c "import pandas; print(pandas.__version__)"

II.

读取与清洗数据

拿到数据的第一步永远是看结构，而不是直接跑分析。

缺失值先处理，不要带着空值做统计。

重复订单要先去重，否则统计结果会虚高。
