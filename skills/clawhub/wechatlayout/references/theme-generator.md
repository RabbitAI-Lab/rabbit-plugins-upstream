# 主题生成器（自定义公众号主题）

> 内置主题不够用时，用一句话描述或一张参考图，生成一套全新组件库并保存本地复用。

## 触发条件

- 用户说"生成一套新主题 / 自定义风格 / 按这张参考图做一套组件库"
- 用户对现有主题都不满意

## 工作流（4 步）

### Step 1: 收集偏好（一次问全，不逐字段追问）

必填：
- **主题描述**（一句话气质描述）或**参考图**

可选（留空则自动补全）：
| 字段 | 说明 | 示例 |
|------|------|------|
| 名称 | 主题中文名 | "暮色橙" |
| 英文标识 | 用于文件名 | `sunset-orange` |
| 主色 | 品牌色 hex | `#EA580C` |
| 背景色 | 页面底色 | `#FFFBEB` |
| 正文色 | 正文字色 | `#44403C` |
| 强调色 | 高亮/点睛色 | `#FCD34D` |
| 装饰色 | 辅助色 | `#FED7AA` |
| 字体偏好 | 衬线/无衬线 | "无衬线" |
| 圆角 | 组件圆角大小 | "8px" |
| 阴影 | 是否用阴影 | "轻阴影" |
| 适用场景 | 什么类型文章 | "美食/生活/旅行" |

用 AskUserQuestion 一次问全，不逐条追问。

### Step 2: 生成区块库 HTML

用以下提示词生成一个完整的区块库预览页面：

```
生成一个公众号排版组件区块库预览页面（单文件 HTML），要求：
- 主题气质：{用户描述的主题描述}
- 主色：{主色或自动推导}
- 背景：{背景色或自动推导}

页面包含以下区块，连续排布在同一页面：
1. 封面标题区（文章标题 + 副标题 + 日期）
2. 引言卡片（带署名槽位）
3. 目录导读（3 个核心看点）
4. 章节标题 x3（编号 01/02/03 + 英文标签）
5. 子标题 x2
6. 正文段落 x3（含关键词下划线、加粗、高亮各 1 处）
7. 引用块 x2（浅底引用 + 居中金句）
8. 数据卡 x2
9. 代码块（深色）x1
10. 图片占位 x1（带说明）
11. 表格 x1
12. 分割线
13. 产品徽章 x2
14. 步骤标签 x3
15. 作者签名区

技术约束：
- 所有样式内联（style=""）
- 所有文字用 <span leaf=""> 包裹
- 禁止 <div>/<style>/<script>/class/id/position:fixed/float/display:grid
- 用 <section>/<p>/<span>/<strong>/<img>/<h3>
- 代码块每行一个 <p style="margin:0">，不用 white-space:pre

风格要求：
- {风格指导：据主题描述推导}
- 主色只在锚点出现（全文 ≤5 处）
- 大面积白底 + 灰阶，彩色只做点缀
```

将生成的 HTML 保存到 `assets/theme-previews/{英文标识}.html`，让用户在浏览器整页浏览确认风格。

### Step 3: 转换为标准主题库 + 登记

用户确认风格后，将预览页面转换为标准主题库格式 `references/theme-{英文标识}.md`。

转换时必须：
1. **补 `<span leaf="">` 包裹**——检查每个文字节点
2. **去掉预览用的 id 属性**（如果有）
3. **补齐五章节**：
   - 设计变量速查表
   - 各组件完整 HTML（从预览中提取，每个组件独立一个 ```html 块）
   - 完整文章模板骨架
   - 文章类型 → 组件组合配方表
   - Markdown → 组件映射规则表

### Step 4: 登记 + 校验

1. 在 `references/theme-index.md` 登记一行：
   ```
   | {中文名} | {英文标识} | {主色} | {适用场景} | theme-{英文标识}.md | border-bottom:2px solid {下划线色} |
   ```

2. 跑源头检查：
   ```bash
   python3 scripts/component_lint.py .
   ```
   必须 0 严重问题才算完成。

3. 交付后该主题即成为常驻可选主题，后续排版与内置主题完全同权。

## 颜色搭配推导规则

只给一个主色或一句气质描述时，按以下规则推导整套色板：

| 角色 | 推导方式 |
|------|---------|
| 主色 | 用户提供或从描述推导 |
| 浅底色 | 主色 + 大量白（mix 10-15%） |
| 浅边框 | 主色 mix 30% |
| 高亮色 | 与主色冷暖对比的第二色 |
| 中性灰阶 | 固定一套 `#111827 → #9CA3AF` |
| 下划线色 | 主色的浅色版（mix 50-60%） |
| 标题色 | `#1f2937`（深灰，所有主题通用） |
| 正文色 | `#374151` 或 `#4b5563`（所有主题通用） |

克制三原则：① 主色只在锚点出现（全文 ≤5 处）；② 大面积白底 + 灰阶；③ 一段内高亮 ≤2 种。
