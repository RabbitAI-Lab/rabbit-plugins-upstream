# Mode B: 公众号文章风格提取

> **Triggers**: "提取风格", "分析排版", "模仿公众号", "风格提取", "主题提取", "参考这篇文章的风格".
> **Resource**: `scripts/style_extractor.py` + `references/theme-index.md`.

从任意公众号文章 URL 自动提取视觉风格，并生成匹配的组件库。主题库从有限扩展到无限——用户可以模仿任何公众号的排版风格。

---

## 核心能力

| 能力 | 说明 |
|------|------|
| URL 抓取 | 支持 mp.weixin.qq.com 文章抓取（白名单限制），通过模拟浏览器 UA 抓取公开页面 |
| 颜色提取 | 从内联样式中提取颜色调色板（主色、背景色、文字色、强调色） |
| 排版提取 | 提取字体、字号、行高、字重等排版规则 |
| 间距提取 | 提取 margin、padding 等间距规则 |
| 主题生成 | 从提取的主色经 HSL 派生全套色阶，生成标准主题组件库格式（兼容 Mode A） |

---

## 工作流（6 步）

### Step 0: 输入

用户提供：
- **公众号文章 URL**（mp.weixin.qq.com/s/...）
- 或 **本地 HTML 文件**
- **输出主题名称**（可选，默认 extracted）

### Step 1: 抓取/读取 HTML

```bash
# 从 URL 抓取
python3 scripts/style_extractor.py https://mp.weixin.qq.com/s/xxx

# 从本地文件读取
python3 scripts/style_extractor.py --html article.html --output mytheme
```

### Step 2: 提取颜色调色板

分析所有内联样式中的颜色值，通过统计频率和亮度分析自动识别：
- 主色（出现频率最高的非中性色）
- 浅底色（高亮/背景区域的浅色调）
- 标题色/正文色/辅助文字色（根据亮度区分）
- 下划线色（主色的浅色变体）
- 深底白字背景（主色或深色变体）

### Step 3: 提取排版规则

| 提取项 | 说明 |
|--------|------|
| 字体 | 最常用的 font-family |
| 字号 | 提取前 5 种最常用字号 |
| 行高 | 提取前 3 种最常用行高 |
| 字重 | 提取前 3 种最常用字重 |

### Step 4: 提取间距规则

| 提取项 | 说明 |
|--------|------|
| Margin | 提取段落间距、组件间距 |
| Padding | 提取卡片内边距 |

### Step 5: 生成主题组件库

根据提取的颜色和排版，生成标准主题组件库文件：`references/theme-{name}.md`

生成的组件库包含：
1. 设计变量速查表
2. 各组件完整 HTML（内联样式 + `<span leaf="">` 包裹）
3. 完整文章模板骨架
4. 文章类型 → 组件组合配方表
5. Markdown → 组件映射规则表

### Step 6: 校验与注册

```bash
# 校验组件库源头（0 严重问题才算通过）
python3 scripts/component_lint.py .

# 登记到主题注册表（手动）
# 在 references/theme-index.md 中添加一行记录
```

## 质量标准

### 颜色提取质量
- 主色提取准确率 ≥ 80%
- 背景色提取准确率 ≥ 90%
- 文字色层次分明（标题 > 正文 > 辅助）

### 排版提取质量
- 字号提取误差 ≤ 2px
- 行高提取误差 ≤ 0.2

---

## 容错与降级

| 场景 | 处理方式 |
|------|---------|
| URL 抓取失败 | 提示用户提供本地 HTML 文件 |
| 颜色提取过少（<3 种） | 使用默认调色板填充缺失值 |
| 排版信息不足 | 使用标准值（字号 16px，行高 1.9） |

---

## 与 Mode A 的衔接

提取生成的主题组件库**完全兼容 Mode A**：
1. 用户可以在 Mode A 中直接选择提取的主题
2. 主题自动继承通用组件库（代码块、图片、小标签）
3. 支持 Mode A 的所有智能处理（章节编号、关键词下划线、全角标点等）

---

## 使用示例

```bash
# 从公众号文章提取风格，生成自定义主题
python3 scripts/style_extractor.py https://mp.weixin.qq.com/s/abc123 --output mybrand

# 使用新生成的主题进行排版
# 在 Mode A 中选择 "mybrand" 主题即可
```

---

## 限制与注意事项

- **反爬限制**：公众号文章可能有反爬机制，抓取可能失败
- **动态内容**：JS 渲染的动态内容无法提取
- **样式差异**：提取的风格基于文章的内联样式，可能与原始设计系统有差异
- **人工微调**：提取后建议人工检查并微调关键颜色和组件
