# 公众号真实粘贴测试清单

> **用途**：在微信公众号编辑器中实际粘贴测试，验证 Mode A 产出的 HTML 样式是否完整保留。
> **执行频率**：每次更新组件库或规则后，至少执行一次完整测试。
> **测试环境**：微信公众号后台编辑器（PC 端）

## 测试准备

1. 生成一份包含所有组件的测试文章 HTML
2. 打开微信公众号后台 → 新建图文消息
3. 复制生成的 HTML
4. 粘贴到公众号编辑器（直接粘贴，不使用"粘贴为纯文本"）
