# Mode A · Step 3.5: 配图建议（AI 判断配图点 + 文生图提示词）

> **触发**：Mode A 排版流程的 Step 3（解析结构）之后、Step 4（装配 HTML）之前执行。
> **资源**：`references/theme-index.md`（取主题主色）。
> **边界**：**只产出配图建议与文生图 prompt，不调用任何文生图 API**。出图交给用户或下游 skill（mad-story / x-design）。微信无法显示外链图，图片一律由用户上传至素材库后替换占位符。

---

## 为什么做（不配图的代价）

`validate_output.py --ops` 会提醒"未检测到图片，公众号文章建议配图"，但只提醒不给方案——用户知道缺图，却不知道配在哪、画什么。本文档把这个判断从用户手里接过来：AI 依据内容结构判断配图点，并生成可直接粘贴进任何文生图工具的 prompt。

---

## 工作流（4 步，全部在 Step 3 完成后就地执行）

### 3.5-1 判定是否需要配图

**用户一句话可关闭**：用户说过"不用配图 / 不要图 / 无图 / 不需要图"→ 跳过整个 Step 3.5，占位符保持原样。

无关闭指令时，按内容特征判定：

| 特征 | 判定 |
|------|------|
| 全文 <500 字 | 不配图（内容过短，配图是噪音） |
| 500–1500 字 | 建议 1 张（封面头图） |
| 1500–3000 字 | 建议 2 张（封面头图 + 1 张内容图） |
| >3000 字 | 建议 3 张（封面 + 章节过渡 + 数据/概念图） |
| 含表格或数据卡 | +1 张数据配图（并入总量） |
| 代码块 >3 处 | +1 张概念图（并入总量） |
| `##` 章节 ≥3 个 | 在信息密度最高的章节**之后**插 1 张章节过渡图 |

**总量上限 3 张**，呼应"克制三原则"——图是排版的一部分，不是填充物。

### 3.5-2 逐个选定配图点

| 配图角色 | 位置 | 何时用 |
|---------|------|--------|
| **封面头图 (hero)** | 引言卡之后、目录之前 | 全文 ≥500 字时默认建议 |
| **章节过渡图** | 信息密度最高的 `##` 章节之后 | 章节 ≥3 个且全文 >1500 字 |
| **数据配图** | 对应表格/数据卡组件之前 | 文中存在表格/数据卡 |
| **概念图** | 抽象概念段落之后 | 代码块 >3 处，或段落含难以直观的抽象概念 |

**选择标准**（AI 判断）：优先选「读者疲劳点」——连续正文 ≥4 段无任何组件（无列表/无引用/无代码块）、或信息密度突增的节点。

### 3.5-3 生成文生图 prompt

每个配图点按黄金模板生成 prompt。**模板参数化，不现场编**：

```
[主体/场景描述] + [风格限定] + [主色 #XXXXXX 点缀] + [氛围] + 无文字 + [画面比例]
```

**主色从 `theme-index.md` 取当前主题主色**（不重复维护色值，遵循颜色一致性规范）。

**黄金模板（按文章类型分发，覆盖 7 类）**：

| 文章类型 | 主体/场景模板 | 风格限定 |
|---------|--------------|---------|
| 教程/操作指南 | 人物正在操作工具/电脑的特写，桌面环境 | 写实摄影，浅景深 |
| 盘点/工具清单 | 同类物品的整齐网格陈列 | 极简产品摄影，统一背景 |
| 观点/深度分析 | 抽象概念的可视化（如路径分叉、天平、阶梯） | 扁平插画，几何构成 |
| 访谈/人物特稿 | 人物侧影/剪影，留白构图 | 电影感摄影，低饱和 |
| 数据复盘/报告 | 简洁数据图表/仪表盘 | 信息图表风格，线性图标 |
| 生活/情感随笔 | 生活场景氛围（街角、窗边、自然光） | 胶片质感摄影，暖调 |
| 案例实战 | 前后对比/成果展示 | 清晰产品图，白底 |

**封面头图额外约束**：构图中心留白 ≥40%（标题文字覆盖区域），不用人像正脸特写（避免与账号头像冲突）。

### 3.5-4 输出

1. **HTML 占位符升级**：原 `【插入图片】` 改为 `【插入图片：封面头图】` / `【插入图片：章节过渡】` 等带角色标签的占位，用户按角色找图替换。
2. **独立配图清单**：随产物交付一份 `{文件名}_配图建议.md`，同样存入 `<skill-base>/output/`，每张图含：

```markdown
## 配图 1/3 · 封面头图
- 位置：引言卡后、目录前
- 理由：教程类文章需要"动手实操"的第一印象，全文 2600 字，需封面锚点
- 尺寸：landscape_4_3
- 文生图提示词：
  `人物双手在笔记本电脑键盘上操作的特写，桌面整洁，写实摄影浅景深，翡翠绿 #059669 作为键盘背光点缀，工作氛围专注明亮，无文字，4:3`
```

3. **不自动出图**：清单交付给用户，由用户粘贴进任意文生图工具。生成后替换占位符，再按 Step 5 校验。

## 强制规则（Anti-patterns）

| 禁止 | 原因 |
|------|------|
| 调用文生图 API / 图床 | 越出排版边界，引入网络依赖 |
| 全文 >3 张配图 | 图是排版的一部分，克制三原则同样适用 |
| 为签名区/CTA 配图 | 深底 CTA 已有视觉锚点，再配图是噪音 |
| 为代码块内部/表格内部配图 | 破坏组件结构 |
| 同一段落内 2 张图 | 打断阅读节奏 |
| 配图建议做成强校验 | 内容短的文章不需要图，强制会骚扰用户 |
| 凭空编造主色 | 必须从 theme-index.md 取当前主题主色 |

---

## 与现有机制的关系

- **占位符机制不变**：Step 3.5 只升级占位符文案（加角色标签），组件仍是通用库的「居中素材占位板块」。
- **校验不变**：Step 3.5 不新增校验项。`validate_output.py --ops` 的"未检测到图片"warning 仅作为兜底提醒，不强制。
- **Mode B 无关**：配图建议只在 Mode A 排版时生成，Mode B 提取风格不涉及。
