## 选模板决策树

```
文章行业/类型？
├─ 科技知识（教程/测评/清单/工具盘点/数据复盘）→ Blueprint 蓝图（emerald）
├─ 观点评论（设计/科技评论/深度分析/高端品牌/随笔）→ Editorial 杂志（graphite）
├─ 美食生活（美食/探店/旅行/生活方式/温暖治愈）→ Kitchen 厨房手帐（sunset）
├─ 企业金融（企业发布/行业分析/金融/商业案例/数据报告）→ Report 研报（ocean）
├─ 时尚美妆（时尚/穿搭/美妆/节庆/促销/种草）→ Campaign 大秀（rose）
├─ 不确定但偏知识型 → Blueprint 蓝图（emerald，默认第一行）
└─ 不确定 → 用 AskUserQuestion 让用户选，附各模板一句话风格说明
```

> **注意**：决策按「行业 + 文章类型」选模板，不再仅按颜色偏好选主题。每个模板的组件、骨架、配方完全不同，切勿跨模板混用组件。
> **品牌账号优先**：若已生成品牌模板（Mode C），品牌账号日常发文直接用品牌模板，不套行业模板。

## 新增模板规范

新模板以 `references/theme-{英文标识}.md` 命名，必须包含：
1. 设计变量速查表（含 Type Scale）
2. 各组件完整 HTML（内联样式 + `<span leaf="">` 包裹），**至少包含 1-2 个行业专属组件**
3. 完整文章模板骨架（**与其他模板结构不同**）
4. 行业文章类型 → 组件组合配方表
5. Markdown → 组件映射规则表

添加后在本文件登记一行，并跑 `python3 scripts/component_lint.py .` 确认 0 严重问题。

## 颜色一致性维护

主题颜色值在 3 处文件中出现，修改任一处的颜色必须同步更新全部位置：

| 位置 | 文件 | 内容 |
|------|------|------|
| ① 注册表 | `theme-index.md`（本文件） | 模板表主色列 + 正文下划线 CSS 列 |
| ② 模板库 | `theme-{id}.md` | 设计变量速查表 + 各组件 HTML 内联色值 |
| ③ 换色规则 | `common-components.md` | 换色规则表（`{{主色}}`/`{{浅底色}}`/`{{下划线色}}` 映射） |

**修改流程：** 改色前先 `grep -rn "旧色值" references/` 扫出全部出现位置，逐处替换后再跑 `python3 scripts/component_lint.py .` 确认 0 严重问题。

## Design Tokens（排版与间距基准）

> 以下数值是各模板共通的**事实标准**，新增组件必须对齐此表，不可自创新值。

### Type Scale（字号阶梯）

| Token | px | 用途 | 典型组件 |
|-------|-----|------|---------|
| `--fs-display` | 28 | 大号数字/超大标题 | KPI 数值、Campaign 超大标题 |
| `--fs-heading-l` | 18-20 | 金句/章节标题 | 居中金句、Pull Quote、章节标题 |
| `--fs-heading` | 17 | 小标题/子标题 | 子标题 |
| `--fs-body` | 16 | 正文（默认） | 段落、列表 |
| `--fs-body-sm` | 15 | 次级正文 | Q&A 答句、要点框正文 |
| `--fs-caption` | 14 | 代码/提示/食材项 | 代码块、Callout、食材清单 |
| `--fs-meta` | 13 | 标签/统计说明 | 药丸标签、元信息、图注 |
| `--fs-footer` | 12 | 版权/GIF角标 | 版权脚注、GIF 标签、报告编号 |
| `--fs-micro` | 11 | 三图图注 | Lookbook 三图模式 |

### Line Height

| 场景 | 值 |
|------|-----|
| 大号数字（display） | 1.2 |
| 紧凑文字（标签/小标题） | 1.5 |
| 标准段落 | 1.6 – 1.7 |
| 舒适阅读段落 | 1.8 – 1.9 |
| 正文加下划线（需喘息空间） | 1.9 |

### Spacing Grid（间距）

| Token | px | 用途 |
|-------|-----|------|
| `--sp-xs` | 4 | 紧凑内间距（标签内 icon 与文字） |
| `--sp-sm` | 8 | 小间距（图与图注、Q与A之间） |
| `--sp-md` | 12 | 标准内间距（Callout padding、Feature gap） |
| `--sp-lg` | 16 | 内容块 padding（代码块、提示块） |
| `--sp-xl` | 20 | 组件间默认间距（`margin: 20px 0`） |
| `--sp-2xl` | 24 | 重要组件间距（图片、KPI 行、产品卡） |
| `--sp-3xl` | 28 | 金句/大组件间距 |
| `--sp-section` | 36-48 | 章节间距（各模板章节标题 `margin-top`） |
| `--sp-footer` | 32 | 版权脚注间距（正文末尾与版权行之间） |

### Gray Hierarchy（灰阶文字层次）

| Token | Hex | 用途 | WCAG 对比度（白底） |
|-------|-----|------|-------------------|
| `--gray-800` | `#1f2937` | 标题/强调 | 12.6:1 ✓ |
| `--gray-700` | `#374151` | 正文 | 10.3:1 ✓ |
| `--gray-600` | `#4b5563` | 次级正文 | 7.5:1 ✓ |
| `--gray-500` | `#6b7280` | 图注/标签/元信息 | 4.6:1 ✓ |
| `--gray-400` | `#9ca3af` | 版权/极弱信息（仅 ≤12px） | 2.8:1（仅小字装饰，不承载关键信息） |

> **规则**：正文及以上的文字必须使用 `--gray-700` 或更深色；`--gray-500` 仅用于辅助说明；`--gray-400` 仅用于版权脚注等非关键信息。各行业模板的正文色/辅助色遵循等价对比度标准（如 Kitchen 的 `#44403c`/`#78716c`、Report 的 `#334155`/`#475569`）。
