## Description:

AI logo and brand identity design powered by CellCog for generating brand kits, color palettes, typography recommendations, and brand guidelines.

This skill is ready for commercial/non-commercial use.

## Publisher:

[thcjp](https://clawhub.ai/user/thcjp)

### License/Terms of Use:

MIT-0

## Use Case:

Designers, marketers, founders, and developers use this skill to turn brand inputs such as name, industry, audience, and personality into a structured brand identity package. It is intended for logo concepts, color palettes, font pairings, and usage guidelines, not 3D modeling or animation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill requests broad command and file access without clear limits.

Mitigation: Run it in a sandbox or trusted workspace and require explicit approval before command execution, external service calls, or file writes.

Risk: Brand materials, API keys, or other sensitive inputs could be exposed during generation or logging.

Mitigation: Avoid providing sensitive brand assets or API keys unless required, and use environment-based secret handling when credentials are necessary.
