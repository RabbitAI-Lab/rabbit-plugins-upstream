## Description:

Generate six coordinated fashion marketing image concepts from one clothing reference image or Pinterest pin link, covering outfit, flat lay, detail, lifestyle, couple styling, and brand story formats.

This skill is ready for commercial/non-commercial use.

## Use Case:

Creators, marketers, and commerce teams use this skill to turn a clothing reference image or Pinterest pin into prompts and generated visual assets for Xiaohongshu or Pinterest-style lookbook campaigns.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow can fetch Pinterest or other linked image content and save reference images in the workspace.

Mitigation: Review the source link and saved reference image before generation, and only use images the user is authorized to process.

Risk: Generated fashion images consume ImageGen credits and may not match the intended audience or subject if default model attributes are unsuitable.

Mitigation: Confirm the cost preview and override model, platform, aspect ratio, or subject attributes before creating the final images.
