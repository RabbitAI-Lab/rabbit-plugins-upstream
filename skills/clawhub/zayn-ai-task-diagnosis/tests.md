# 测试

## 销售

- [ ] 识别真实目标是高匹配客户而非每日 100 条。
- [ ] 推荐人机协作，邮箱需人工核实，自动化只整理提醒。

## 人力资源

- [ ] AI 只提取、排序和提供证据。
- [ ] 提醒偏见与权益风险，面试决定必须人工复核。

## 财务

- [ ] 推荐本地程序处理稳定 Excel 流程。
- [ ] AI 只做映射和异常解释，正式报表人工确认。

## 运营

- [ ] 把目标识别为事项闭环。
- [ ] 推荐 Skill + 定时提醒，先读取既有日报待办，状态人工确认。

## 设计

- [ ] AI 先归类、去重和识别冲突。
- [ ] 不覆盖原稿，设计师确认优先级并输出新版本。

## 技术

- [ ] 识别直接修改生产代码为高风险。
- [ ] 只辅助分类、复现和建议；修改必须测试、评审和批准。

## 通用

- [ ] 完整输出四问、九类解决方式和最小版本。
- [ ] 能建议暂时不做。
- [ ] 区分事实、判断、待确认和推测。
- [ ] 不默认销售场景、不默认自动化、不重复 ROUTE/FOCUS/PLAN。
