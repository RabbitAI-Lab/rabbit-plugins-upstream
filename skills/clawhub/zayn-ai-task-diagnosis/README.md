# AI_TASK_DIAGNOSIS() AI 任务四问

这是 WorkFn 的通用前置诊断入口，不属于任何单一岗位。它在创建 Skill、自动化、程序、工作流或 AI 助手前，先判断真实目标、变化频率、已有证据和最终责任，再选择最低成本的解决方式。

## 与现有 Skill 的关系

```text
用户提出 AI 需求
→ AI_TASK_DIAGNOSIS()
→ 普通对话 / Skill / 自动化 / 程序 / 模板 / 人工 / 人机协作 / 暂时不做
```

如果选择 WorkFn Skill，再交 `zayn-route` 选择具体 Skill；已确定任务需要减重时交 `zayn-focus`；需要计划时交 `zayn-plan`；需要领导决策表达时交 `zayn-decision`。本 Skill 不替代这些能力。

## 最小使用

提供当前任务、最终想得到的结果，并尽量说明多久发生一次、已有数据和工具、谁确认结果。Skill 会先补最关键的缺口，再输出诊断报告和最小版本。

## 限制

不直接执行用户原任务，不默认全自动，不做最终财务、法律、人事、客户关系、安全或不可逆决定，不覆盖原始数据，不为展示能力扩大系统。
