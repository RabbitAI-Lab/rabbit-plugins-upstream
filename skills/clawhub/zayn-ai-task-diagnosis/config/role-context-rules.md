# 岗位和行业适配

先识别岗位、行业、对象、频率、风险、工具、数据源和最终责任人。背景会改变判断时只问最必要信息。

- 销售/客服：检查过早承诺、证据、内部信息暴露、客户信任、责任和未经确认外发。
- HR：检查偏见、关键词替代判断、候选人权益、敏感信息和人工复核。
- 财务：检查可追溯、审批、原始账目、公式版本、付款税务责任。
- 技术/产品：检查需求、生产环境、版本回滚、测试审查、技术事实和范围。
- 内容/设计：检查受众、品牌、版权事实、审美判断、发布渠道和版本。
- 运营/项目：检查负责人、截止时间、后续动作、闭环、重复记录和系统回填。
- 采购/供应链：检查供应商证据、价格交期时效、质量风险、付款和责任边界。
- 教育/培训：检查学习目标、适龄性、反馈责任、个人信息和教师复核。
