# 解决方式分类

| 类型 | 适用条件 |
|---|---|
| 普通对话 | 一次性、临时分析、方案讨论、低成本验证、规则未稳定 |
| Skill | 重复出现、判断框架稳定、输入变化、仍需上下文与人工确认 |
| 定时自动化 | 固定时间/频率、数据会变化、有接收人和后续动作 |
| 条件自动化 | 依赖外部状态、阈值、回复、审批、交付或异常 |
| 程序工具 | 输入输出稳定、规则明确、批量、固定格式、本地可靠计算 |
| 模板/SOP | 不需复杂判断、主要问题是步骤不统一或避免遗漏 |
| 人工处理 | 低频、经验依赖强、数据不足、关系情绪重要、错误成本高 |
| 人机协作 | AI 缩小范围，人工最终判断，多阶段需不同工具 |
| 暂时不做 | 目标/数据/场景/责任人/后续动作不清，维护成本高于价值 |

允许组合，但先用最简单方案验证，再逐步升级。
