## Description: <br>
Web Tools helps agents search and extract web content, analyze page performance, deploy static sites to GitHub Pages, and convert common file formats to Markdown. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[cooperiano](https://clawhub.ai/user/cooperiano) <br>

### License/Terms of Use: <br>

## Use Case: <br>
Developers and agents use this skill to gather web information, extract readable page content, review performance metrics, convert documents or media into Markdown, and prepare static GitHub Pages deployments. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Automated GitHub Pages deployment could create, push, configure, or publish a site without enough scoping or confirmation. <br>
Mitigation: Before deployment, confirm the target repository, visibility, files to publish, GitHub credentials, Actions workflow changes, and whether the published site will be public. <br>
