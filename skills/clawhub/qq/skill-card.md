## Description: <br>
QQ robot and open-platform development guide for choosing between the official QQ Bot API and the community OneBot ecosystem, implementing official bot authentication, WebSocket events, message types, Ark cards, Mini Programs, and OAuth. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineers use this skill to plan and implement QQ bot, QQ Channel, QQ Mini Program, and QQ OAuth integrations, including route selection between official APIs and community OneBot tooling. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill provides implementation guidance involving QQ AppSecret values and access tokens. <br>
Mitigation: Keep secrets on the server side, avoid pasting credentials into agent sessions, and review generated code before deployment. <br>
Risk: Community OneBot routes can involve protocol-side implementations with account enforcement risk. <br>
Mitigation: Use the official QQ Bot API for public or commercial services and treat community routes as personal-use guidance with explicit risk acceptance. <br>
Risk: API examples are skeleton guidance and platform permissions, review status, and rate limits may affect behavior. <br>
Mitigation: Verify implementation details against official QQ documentation and test in a sandbox before production use. <br>
