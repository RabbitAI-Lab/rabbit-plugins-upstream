# Mga Product Screenshot — powpow-register

Kunin kung kinakailangan habang tumatakbo. Kapag walang konsepto ang user sa Bubble, o kailangang "makita" kung ano ang hitsura ng tapos na produkto, ipadala na lang ang kaukulang link.

## Mga Panuntunan sa Link

- Pangunahing link (raw):
  `https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-0N.jpg`
- Mirror (gamitin kapag hindi mabuksan ang raw, `N` ay 1–6):
  `https://cdn.jsdelivr.net/gh/durenzidu/durenzidu@main/screenshots/powpow-0N.jpg`
- Nasa pampublikong repo ang mga larawan, maaaring direktang i-share; **huwag** i-download sa folder ng skill, huwag magpadala ng local path bilang kapalit ng larawan.
- Bawat beses ay magpadala lang ng 1–3 larawang may kaugnayan sa kasalukuyang paksa.

## Listahan

### powpow-01.jpg — Digital na tao details page

![Digital na tao details page](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-01.jpg)

Card pagkatapos gawing digital na tao ang totoong tao/historikal na pigura: online status, kinalalagyan, talambuhay ng pigura, "Simulan ang Pag-uusap", atbp.
**Gamitin kapag**: nagpapakilala ng "pagkatapos magrehistro ay makakausap mo ang mga digital na tao sa mapa".

### powpow-02.jpg — Post editing page

![Post editing page](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-02.jpg)

Interface sa pagsusulat ng post/talaarawan ng paglalakbay, may grupo ng floating buttons sa kanang sulok sa ibaba.
**Gamitin kapag**: nagtanong ang user ng "ano ang magagawa ko pagkatapos magrehistro" "saan magsusulat".

### powpow-03.jpg — Mapa page (mga bula + digital na tao)

![Mapa page](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-03.jpg)

Buong tanawin ng pampublikong mapa: ang mga post na may lokasyon ay naiipon bilang "bula" sa mapa, ang mga digital na tao ay nakapin ang avatar sa totoong lokasyon.
**Gamitin kapag**: **unang larawan sa pagbubukas ng pagpapakilala ng produkto** — "ang talaarawan ng paglalakbay na iyong ipo-post ay magiging isang bula sa mapa".

### powpow-04.jpg — Personal page (digital assets)

![Personal page](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-04.jpg)

Sariling pahina ng user: mga kaibigan/finofollow/followers, at "digital assets" — badge balance, aking mga Bubble, aking digital na tao.
**Gamitin kapag**: "libreng 3 badge sa pagrehistro" para ipakita kung saan nakalagay ang badge; nagtanong ang user ng "ano ang mga asset ko".

### powpow-05.jpg — Story progress page

![Story progress page](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-05.jpg)

Gameplay ng story sa loob ng platform (halimbawa「Yongle · 1421」): progress ng chapter, pagkamit ng badge, roleplay.
**Gamitin kapag**: nagtanong ang user ng "bukod sa pag-post, ano pa ang malalaro" "paano kumita ng badge".

### powpow-06.jpg — Post details page (halimbawa ng tapos na)

![Post details page](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-06.jpg)

Isang nai-publish nang talaarawan ng paglalakbay: may-akda, location tag, laman, mga larawan, at sa ibaba ay may like/comment/share/save.
**Gamitin kapag**: **pangalawang larawan sa pagbubukas** — "kapag binuksan ng iba ang iyong bula sa mapa, ito ang kanilang makikita".

## Mabilisang Pagtingin Ayon sa Sitwasyon

| Sinasabi ng user / kasalukuyang bahagi | Aling larawan ang ipapadala |
|---|---|
| Pagbubukas ng pagpapakilala "ano ang Bubble" | powpow-03 + powpow-06 |
| "Ano ang magagawa ko pagkatapos magrehistro?" | powpow-02 + powpow-01 |
| "Ano ang badge / ano ang meron ako?" | powpow-04 |
| "Bukod sa pag-post, ano pa ang malalaro?" | powpow-05 |
| Pagtingin sa error ng rehistro/subscription | kadalasan ay hindi kailangan ng larawan; kung talagang kailangang ipaliwanag ang posisyon ng pahina saka magpadala |

## Mga Tandaan sa Pagpapanatili

Wala pang screenshot ng **registration page** at **subscription page** ang kasalukuyang library ng mga larawan. Kung sa hinaharap
ay idadagdag sa repo na `durenzidu/durenzidu` sa folder na `screenshots/` (halimbawa `powpow-07.jpg` registration page, `powpow-08.jpg`
subscription page), magdagdag lang ng section sa dokumentong ito ayon sa parehong format, at maaaring mai-refer din ito ng gabay sa SKILL.md.
