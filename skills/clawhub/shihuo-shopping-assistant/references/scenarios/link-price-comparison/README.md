# 链接比价场景包

本场景处理用户发来渠道商品链接、短链或口令并询问怎么买更合适。入口必须含链接或口令；结论只针对链接本身对应的规格，不换规格、不换商品。

| 文件 | 作用 |
| --- | --- |
| `README.md` | 说明本场景边界和文件用途 |
| `workflow.md` | 定义链接解析、层级收口、同规格比价、转链的每一步，末尾给出选哪种回复 |
| `output.md` | 定义标准回复、追问、兜底三种回复各由哪些模块组成，以及骨架和删除规则 |

与 `price-comparison` 的区别：本场景的比较基准是用户给的链接，输出要给出「换哪个渠道更划算」；`price-comparison` 从关键词或图片入手，没有基准链接。用户在链接之外还要求找隐藏券、补贴券时，走 `link-coupon` 场景。
