# 商品推荐场景包

本场景只处理用户没有唯一目标商品、希望按需求挑选的关键词或图片入口，不接受商品链接。产出是 1 至 4 个真实候选加选择依据，并为匹配度最高的主候选按用户诉求选一个参考 SKU，继续给出该规格的全网购买选项。

口径不写在本文。业务口径和全局约束在 SKILL.md，字段含义在 `references/tools/`。

| 文件 | 作用 |
| --- | --- |
| `README.md` | 场景边界与文件清单 |
| `workflow.md` | 每步调哪个工具、怎么过滤、产出什么，末尾选哪种回复 |
| `output.md` | 标准回复、兜底两种回复的模块构成、骨架和删除规则 |
