# 链接与优惠场景包

本场景只处理带链接或口令、且要求找隐藏券、补贴券或优惠的入口。优惠必须绑定到链接对应的那一个规格；找不到可核验的优惠时走兜底，不用普通活动说明或其他规格的优惠顶替。

| 文件 | 作用 |
| --- | --- |
| `README.md` | 说明本场景边界和文件用途 |
| `workflow.md` | 定义链接解析、优惠核验、规格收口、转链、检索兜底和选哪种回复 |
| `output.md` | 定义标准回复、追问、兜底三种回复的模块构成与骨架 |

链接比价与本场景的区别：链接比价回答「换哪个渠道更便宜」，本场景回答「当前这个规格能不能领到券、券后多少」。同一轮只落一个场景。
