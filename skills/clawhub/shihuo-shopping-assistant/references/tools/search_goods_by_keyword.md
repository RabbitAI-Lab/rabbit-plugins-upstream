# search_goods_by_keyword

自然语言入口的商品发现工具。按关键词返回识货站内商品候选，只有商品层基础信息，不含属性、款式、SKU 和渠道价。

## 入参

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| query | string | 是 | 检索关键词，如品牌、型号或品类，最少 1 个字符 |
| brand_id | string | 否 | 品牌 ID 过滤。不透明字符串，固定 12 字符、区分大小写、原样回传；只能用工具返回过的 `brand_id`，不能凭品牌名自己编 |
| root_category_id | string | 否 | 一级类目 ID 过滤。不透明字符串，固定 12 字符、区分大小写、原样回传；同样只能用工具返回的 ID |
| price_from | number | 否 | 价格下限，单位元，是数字不是字符串，不带 `￥` |
| price_to | number | 否 | 价格上限，单位元 |
| sort | string | 否 | 排序，枚举只有 `hot`（热度）。不传即接口默认序，不存在价格排序、销量排序取值 |
| page | integer | 否 | 页码，从 1 开始，最大 10，默认 1 |
| page_size | integer | 否 | 每页条数，1～30，默认 10 |

`price_from`/`price_to` 只在用户明确给出预算区间时传，取值必须是用户原话里的数值，不自行放宽或收窄。用户没提排序就不传 `sort`。

## 响应字段解释

| 路径 | 类型 | 是否恒有 | 含义 | 展示与限制 |
| --- | --- | --- | --- | --- |
| data.goods | array | 是 | 商品候选列表 | 可能为空数组，空数组即无命中，按 `not_found` 口径处理 |
| data.goods[].goods_id | string | 是 | 商品 ID，不透明字符串，固定 12 字符、区分大小写 | 后续 `goods_detail`、`goods_styles`、趋势工具的 `goods_id` 唯一来源，必须原样回传 |
| data.goods[].goods_name | string | 是 | 商品名称 | 原样展示。不从名称推导材质、代数、适用场景或真伪 |
| data.goods[].brand_id | string | 否 | 品牌 ID，不透明字符串，固定 12 字符、区分大小写 | 空串时省略；可作为后续搜索的 `brand_id` |
| data.goods[].root_category_id | string | 否 | 一级类目 ID，不透明字符串，固定 12 字符、区分大小写 | 空串时省略；可作为后续搜索的 `root_category_id` |
| data.goods[].brand_name | string | 否 | 品牌名称 | 空串时省略，不用商品名里的词猜品牌 |
| data.goods[].price | string | 否 | 商品层价格，格式 `￥199` | 固定称“站内展示价”。它不是到手价、不是最低价、不含券后计算 |
| data.goods[].sales | number | 否 | 销量，整数 | 保留接口口径直接陈述，不改写成“销量第 N”“最畅销”，不同商品间的销量不作排名结论 |
| data.goods[].image_url | string | 否 | 商品主图 | 不从图片颜色或外观推导配色、材质、规格 |
| data.goods[].href | string | 否 | 识货商品入口 | 只有 `https://m.shihuo.` 开头才能展示；若返回 `shihuo://` 开头则视为不可展示并省略，按 `link_convert.md` 的展示规则处理 |
| data.page | number | 是 | 当前页码 | 用于翻页自查，不向用户展示 |
| data.has_more | bool | 是 | 是否还有下一页 | 翻页只看这个字段，不用当前返回条数猜测 |

列表顺序是相关度/热度序，不代表价格高低或推荐优先级。需要按价格或销量组织展示时，自己按 `price`、`sales` 排序并说明排序依据。

## 怎么用返回结果

1. 先确认商品：用户点名了具体型号时只保留 `goods_name` 与用户指定型号对应的候选，可识别清晰等价写法，不以相近型号替换。信息足够时直接匹配；用户要帮选时，根据需求与真实字段选择并说明参考商品；只有无法依据现有条件确定、且会影响结论的歧义才展示真实选项并追问，不设固定排序选择规则。
2. 候选不足时按 `has_more` 翻页，翻到候选足够或 `has_more=false` 为止。同一组参数不重复调用，换页必须真的换 `page`。
3. 关键词无命中时可换一次更简洁的检索词，但保留用户指定的型号和筛选条件，不擅自放宽目标；仍无命中时说明未找到对应商品，需要继续定位才请用户补充商品信息，不凭空生成候选。
4. 本工具的字段就是全部可用事实：参数、热度、鉴别记录用 `goods_detail`，配色、款式用 `goods_styles`，规格用 `search_sku`，历史价用对应层级的趋势工具。需要全网比价时先确认配色 / 规格与 SKU，再调用 `goods_sku_price_comparision`，结果按所在场景 `output.md` 的模块骨架展示。只查询用户所需内容，不为参数或配色问题强制追加比价。

## 调用说明

自然语言入口首调本工具。适用于用户描述品类、报出品牌型号、要找同类或相似商品。

不适用：用户只给图片（用 `search_goods_by_image`）、用户给商品链接或分享文本（先 `link_parse`）、已定位商品后问事实或价格（用对应商品工具）。本工具不返回属性、`style_id`、`goods_sku_id`、筛选项和渠道报价，这类结论一律不引用它。

结果处理按 `index.md` 的“失败与异常处理”：`input_required` 说明 `query` 为空，先补齐；`not_found` 不用同参数盲目重试；`failed` 的重试按通用规则执行，仍失败时说明未能取得候选，不用记忆中的商品补齐。
