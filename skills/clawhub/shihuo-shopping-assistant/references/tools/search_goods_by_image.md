# search_goods_by_image

图片入口的商品发现工具。按图片 URL 返回识货站内相似商品候选，字段与关键词搜索完全一致，区别只在入口和“相似≠同款”的口径。

## 入参

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| image_url | string | 是 | 待识别的商品图片 URL，最少 1 个字符。必须是用户提供的原始图片地址，不自己拼接、不改写 |
| brand_id | string | 否 | 品牌 ID 过滤，不透明字符串，固定 12 字符、区分大小写、原样回传，只能用工具返回过的 ID |
| root_category_id | string | 否 | 一级类目 ID 过滤，不透明字符串，固定 12 字符、区分大小写、原样回传，同上 |
| price_from | number | 否 | 价格下限，单位元，数字不带 `￥` |
| price_to | number | 否 | 价格上限，单位元 |
| sort | string | 否 | 排序，枚举只有 `hot` |
| page | integer | 否 | 页码，从 1 开始，最大 10，默认 1 |
| page_size | integer | 否 | 每页条数，1～30，默认 10 |

不把图片内容转成关键词再去搜；本工具的入参只有图片地址和过滤条件。

## 响应字段解释

| 路径 | 类型 | 是否恒有 | 含义 | 展示与限制 |
| --- | --- | --- | --- | --- |
| data.goods | array | 是 | 相似商品候选列表 | 可能为空数组；**这是视觉相似结果，不能称为“同款”或“就是你图里那双”** |
| data.goods[].goods_id | string | 是 | 商品 ID，不透明字符串，固定 12 字符、区分大小写 | 后续商品工具的 `goods_id` 来源，必须原样回传 |
| data.goods[].goods_name | string | 是 | 商品名称 | 原样展示；不能反过来当作用户图片的商品名 |
| data.goods[].brand_id | string | 否 | 品牌 ID，不透明字符串，固定 12 字符、区分大小写 | 空串省略 |
| data.goods[].root_category_id | string | 否 | 一级类目 ID，不透明字符串，固定 12 字符、区分大小写 | 空串省略；可作为后续搜索的 `root_category_id` |
| data.goods[].brand_name | string | 否 | 品牌名称 | 空串省略；不能由图片外观断定品牌 |
| data.goods[].price | string | 否 | 商品层价格，格式 `￥199` | 固定称“站内展示价”，不是到手价 |
| data.goods[].sales | number | 否 | 销量，整数 | 保留接口口径，不改写成排名 |
| data.goods[].image_url | string | 否 | 候选商品主图 | 只是候选图；不与用户原图做相似度判断，不写“匹配度高” |
| data.goods[].href | string | 否 | 识货商品入口 | 只展示 `https://m.shihuo.` 开头；`shihuo://` 视为不可展示 |
| data.page | number | 是 | 当前页码 | 内部使用 |
| data.has_more | bool | 是 | 是否还有下一页 | 翻页只看这个字段 |

## 怎么用返回结果

1. 结果是视觉相似候选，不直接视为用户图片中的同款。信息足够时结合用户条件与真实字段直接匹配；用户要帮选相似款时，可根据需求选择并说明参考商品；只有无法依据现有条件确定、且会影响结论的歧义才展示真实选项并追问，不设固定排序选择规则。
2. 不从图片自行生成任何事实：商品名、品牌、配色名、材质、尺码、版本、价格只取返回字段或用户后续确认，图片本身不是证据。
3. 候选不足按 `has_more` 翻页；需要确认商品时只展示与用户条件相关的真实候选，不擅自换成相近型号。
4. 无结果时不把图片“翻译”成关键词转投关键词搜索，也不猜品类。按 `index.md` 的“失败与异常处理”请用户补一张更清晰的图片或补充商品文字信息。
5. 确认商品后按需查属性或商品层历史；只问配色或款式历史时定位到款式即可。需要 SKU 历史或全网比价时，再通过 `goods_styles` → `search_sku` 确认配色 / 规格与 SKU；相似候选不直接当作已确认 SKU，比价结果按所在场景 `output.md` 的模块骨架展示。

## 调用说明

图片入口首调本工具。适用于用户上传或给出商品图片 URL，想找同类、相似款或据图定位商品。

不适用：用户给的是文字描述（用 `search_goods_by_keyword`）、用户给的是商品链接或分享文本（先 `link_parse`）、已确认商品后的事实与价格查询（用对应商品工具）。本工具不返回属性、`style_id`、`goods_sku_id` 和渠道报价。

结果处理按 `index.md` 的“失败与异常处理”：`input_required` 说明 `image_url` 为空；`not_found` 不用同一张图重复重试；`failed` 的重试按通用规则执行，仍失败时说明未能取得相似候选。
