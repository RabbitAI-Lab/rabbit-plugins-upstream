# 严格提示词：生成「单文件 HTML 翻阅式卡片工具书」

> 把下面的提示词原样交给任意一个支持写代码 / 生成 HTML 的 agent，它即可独立完成本任务。
> 替换 `{{...}}` 占位符为真实内容；其余结构、CSS、JS 一律照抄，不要"优化"掉关键约束。

---

你是一名前端排版工程师。请产出【单文件 HTML】的「翻阅式卡片工具书」，主题为《{{书名}}》。

## 【形态】左右翻页卡片书，每屏一页，不要竖向长滚动
页序如下（顺序即翻页顺序）：
1. 封面（图书馆 / 书架大图 + 由浅到深渐变蒙版压标题，副标题，一句导语）；
2. 使用方法（4 步"遇事翻一翻"指引）；
3. 目录页（N 张缩略卡：编号 + 名称 + 一句描述，点任意一张跳到该卡）；
4..N+3. N 张主题卡（每张：编号徽章 + 名称 + 核心命题 + 原文引用含出处 +
   3 个现实场景[工作与决策 / 团队与管理 / 个人成长] + "↑ 返回目录"）；
N+4. 封底（引流钩子占位 + 免责声明）。

## 【翻页】无滑动动画，立即跳页
四种入口，全部即时跳页（不要加 transition）：
① 屏幕左右边缘悬浮圆形箭头：左箭头固定在最左、右箭头固定在最右；
   **绝不在同一个选择器上同时写 left 和 right**（按 .prev / .next 分别写）。
② 键盘 ← → 翻页。
③ 手机横滑翻页（位移阈值 50px，且 |dx| > |dy| 才触发，避免误伤纵向滚动）。
④ 顶部「目录 ▾」下拉选主题 → 跳到对应卡。
首张禁用左箭头、末张禁用右箭头（置灰）。

## 【视觉】
- 米色纸感背景 + 极淡噪点纹理；
- 衬线标题（Noto Serif SC 回退到 Songti SC / SimSun）；
- 书签色带（主题色圆角标签）；
- 纸张多层阴影 + inset 顶部高光，模拟纸厚；
- hero 用在线图时，断网降级为深色底色（不破图）。

## 【响应式】
clamp() 字号、auto-fit 栅格、100dvh 撑满视口；移动端不裁切；
移动端隐藏顶栏区块锚点但保留「目录 ▾」下拉。

## 【关键约束（务必遵守，否则会出 bug）】
1. 卡片容器用 `align-items: safe center`（保留 `center` 作回退），防止内容超高时卡片顶部被裁、不可滚动到。
2. 目录页是独立可跳转页，必须保留（不是导航栏下拉的替代品）。
3. 所有 CSS / JS 内联，单文件，无外部依赖（除可选 hero 在线图）。
4. 中文金句注明"以权威版本为准"，引用建议核对原书。
5. 导航栏下拉项与目录页缩略卡的 `id` 必须一一对应（`#c01`、`#c02`…）。

## 【交付】
输出完整单文件 HTML，本地浏览器打开即用；移动端窄屏不裁切、左右箭头不重叠。
