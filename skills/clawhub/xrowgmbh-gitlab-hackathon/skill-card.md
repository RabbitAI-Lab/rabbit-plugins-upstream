## Description:

Plan and execute fair GitLab hackathon participation, including Quarterly and Transcend Hackathons, by analyzing rules, selecting qualifying issues/MRs, tracking scoring levers, and keeping an exploit watchlist.

This skill is ready for commercial/non-commercial use.

## Publisher:

[xrowgmbh](https://clawhub.ai/user/xrowgmbh)

### License/Terms of Use:

MIT-0

## Use Case:

External GitLab contributors use this skill to plan eligible hackathon work, select reviewable contributions, and track requirements while following fair contribution practices.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Hackathon dates, eligibility rules, deadlines, and scoring details can change, making an old plan inaccurate.

Mitigation: Recheck the linked official event pages, current API, and contribution-points guide before acting.

Risk: GitLab CLI use with GITLAB_TOKEN can perform authenticated actions in the account's permitted scope.

Mitigation: Use a narrowly scoped token and review each target project and command before running it.
