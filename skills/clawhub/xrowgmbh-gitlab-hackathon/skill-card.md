## Description:

Plan and execute fair GitLab hackathon participation, including Quarterly and Transcend Hackathons, by analyzing rules, selecting qualifying issues/MRs, tracking scoring levers, and keeping an exploit watchlist.

This skill is ready for commercial/non-commercial use.

## Publisher:

[xrowgmbh](https://clawhub.ai/user/xrowgmbh)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and GitLab contributors use this skill to plan fair hackathon participation, identify manageable issues and merge requests, and track event requirements and contribution activity.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: GitLab commands may use the configured token to perform account actions during hackathon work.

Mitigation: Use a token with only the access needed, keep it private, and review each write action before running it.
