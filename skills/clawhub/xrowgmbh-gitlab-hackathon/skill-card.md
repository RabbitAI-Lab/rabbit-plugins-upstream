## Description:

Helps participants plan fair GitLab hackathon contributions by checking event rules, choosing reviewable work, and tracking eligibility and scoring.

This skill is ready for commercial/non-commercial use.

## Publisher:

[xrowgmbh](https://clawhub.ai/user/xrowgmbh)

### License/Terms of Use:

MIT-0

## Use Case:

Hackathon participants and developers use this skill to check GitLab event requirements, prioritize qualifying contributions, and prepare fair, reviewable merge requests.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A GitLab token or project access could permit unintended changes.

Mitigation: Grant only the minimum permissions needed and review proposed actions before execution.

Risk: Incorrect comments, labels, issue closures, or merge requests could affect public projects or prize-bearing events.

Mitigation: Review each proposed contribution for accuracy, fairness, and project eligibility before posting.

Risk: Hackathon rules, dates, and scoring can change between events.

Mitigation: Verify current event requirements and contribution points using the linked GitLab resources before acting.
