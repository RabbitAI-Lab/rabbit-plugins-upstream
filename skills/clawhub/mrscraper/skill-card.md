## Description:

Read web pages, search the web, and run AI scrapers with natural-language instructions through the MrScraper API.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ai-mrscraper](https://clawhub.ai/user/ai-mrscraper)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to read public web pages, search the web, start or rerun scrapers, and retrieve extraction results through the MrScraper APIs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Request inputs and target URLs are sent to the MrScraper APIs, and the supplied scan did not verify what data users choose to send.

Mitigation: Review target URLs and request content before each run, and send only information you are comfortable sharing with MrScraper.
