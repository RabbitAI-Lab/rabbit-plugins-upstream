## Description:

Create or revise document, PDF, web, or review images with the requested format, sharp raster output, and artifact validation.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and document authors use this skill to create or revise images for documentation, PDFs, web pages, and release artifacts while preserving requested formats and checking the final result.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Image creation or document rebuilds may change project assets unexpectedly.

Mitigation: Review generated images and rebuilt documents before merging changes.

Risk: The validation script scans the repository path it is given.

Mitigation: Run it only on repositories you intend to scan.
