## Description:

Create or revise document, PDF, web, or review images with the requested format, sharp raster output, and artifact validation.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and content creators use this skill to create or revise images for documents and websites while preserving requested formats and checking final artifacts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Image revisions and document rebuilds can change deliverables beyond the intended image.

Mitigation: Review changed files and check the final images and documents against the requested format and appearance.

Risk: Running the image checker against the wrong repository can give misleading validation results.

Mitigation: Pass the intended repository root to the checker and inspect its missing or stale image reports.
