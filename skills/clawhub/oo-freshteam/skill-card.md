## Description:

Search and read Freshteam data through an OOMOL-connected account.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

Employees and recruiting teams use the skill to look up Freshteam employee records, job postings, applicant fields, and candidate source information.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup instructs the agent to execute code downloaded from the internet without verification.

Mitigation: Review setup before enabling it; install a verified, version-pinned oo CLI yourself and require approval for subsequent software or agent-skill changes.
