# RMA() 退换货判断

**Skill ID:** `zayn-rma`
- 所属分类：客诉与售后
- 一句话用途：判断是否接受退回、退运与运费边界、检测流程和后续处理路径
- 当前版本：`v0.1`
- 当前状态：Draft for testing
- 规则是否完成：是，初版规则已建立
- 是否已有测试案例：否，等待真实脱敏案例
- 下一步待办：测试参数、证据、最低运行条件、责任边界和输出结构

RMA() 用于判断是否接受退回、如何退回、谁承担运费、退回后如何检测，以及最终可能采用维修、换货、退款或拒收中的哪一种处理路径。它不默认接受客户退货。

完整规则见 [SKILL.md](SKILL.md)，调用模板见 [examples.md](examples.md)，测试要求见 [tests.md](tests.md)。
