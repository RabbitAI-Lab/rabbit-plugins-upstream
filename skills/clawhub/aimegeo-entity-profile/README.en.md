# Brand and product fact records

Organize user-supplied or inspected materials into entity records for companies, brands, and products, preserving source references and uncertainty states. The Python tool validates structure and summarizes records; it does not verify facts online or infer whether two names identify the same entity.

See [SKILL.md](SKILL.md), [data format](references/profile-contract.md), and `examples/`. Run `python3 scripts/self_test.py`.

Version 1.0.2, MIT-0; see [LICENSE](LICENSE). Earlier source provenance and attribution records are available in [SOURCE-ORIGIN.md](SOURCE-ORIGIN.md).
