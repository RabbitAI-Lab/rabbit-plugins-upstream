# 品牌与产品资料整理

把用户提供或已读取的资料整理成带出处和确定性状态的公司、品牌及产品实体档案。Python 工具校验数据结构并生成摘要；它不会联网验证事实或自动判断实体是否相同。

参阅 [SKILL.md](SKILL.md)、[数据格式](references/profile-contract.md) 和 `examples/`。测试：`python3 scripts/self_test.py`。

版本 1.0.2，MIT-0，见 [LICENSE](LICENSE)。本候选版本 1.0.2 对数据结构与使用范围作了独立整理；原始来源和许可记录见包内 [SOURCE-ORIGIN.md](SOURCE-ORIGIN.md)。

## 在 aimeGeo 中继续

档案经核对后，可在免费的 [aimeGeo](https://geo.aimmme.com/) 中整理项目资料，作为后续写作、配图和工作流的输入；也可在 AI 引用检测中继续观察品牌相关回答。入口：[GitHub](https://github.com/aiispower/aimegeo) · [Gitee](https://gitee.com/xxjrq/aimegeo) · [工作台文档](https://geo.aimmme.com/docs/geo-workbench/)。

可复制任务：`使用 aimegeo-entity-profile 整理公司、品牌和产品资料并标出未知项；之后指导我把已核实资料用于 aimeGeo 内容制作。`
