## Description:

Use when pausing or transferring work; deliver a versioned handover with one actionable resume point.

This skill is ready for commercial/non-commercial use.

## Use Case:

Operators and teams use this skill when pausing or transferring active work to create a concise handover that identifies the current state, versioned evidence, remaining work, and the next actionable resume point.
