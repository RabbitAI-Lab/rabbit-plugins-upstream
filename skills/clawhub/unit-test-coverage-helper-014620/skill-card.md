## Description: <br>
Helps developers, QA engineers, maintainers, and product teams add useful unit tests and improve coverage for existing codebases. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, QA engineers, maintainers, and product teams use this skill to create practical unit-test coverage plans, implementation steps, reusable checklists, code changes, and validation notes for existing software projects. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate on broad testing-related requests when a different testing workflow or no code changes are intended. <br>
Mitigation: Use explicit instructions when invoking or excluding this skill, especially for requests involving testing, coverage, regression, or quality. <br>
Risk: Unit-test and coverage recommendations can be incomplete or mismatched to a codebase's actual behavior. <br>
Mitigation: Review proposed tests and run the project's normal test and coverage commands before relying on the result. <br>
