# 调用方提供的输入（通用）

本技能**不绑定**任何产品目录。Agent / 人在开工前备齐：

| 字段 | 必填 | 说明 |
|------|------|------|
| `video` | 是 | 本机视频绝对路径（常用竖版 1080×1920 mp4） |
| `description` | 是 | 视频描述正文 |
| `tags` | 否 | 话题行，如 `#话题1 #话题2`，另起一行追加在描述末尾 |
| `short_title` | 是 | 短标题：≤16 字；符号白名单有限（书名号/引号/冒号/加号/问号/百分号/摄氏度）；全角逗号改空格；避免版本号小数点 |
| `cover` | 否 | 封面图绝对路径（竖版约 3:4，JPG 更稳）；不传则用默认帧，人可后补 |
| `location` | 否 | 默认改成「不显示位置」；若要保留城市由人说明 |
| `declare_original` | 否 | 是否勾选声明原创 |
| `activity_query` | 否 | 活动搜索词；搜不到就保持「不参与活动」 |

系列栏目（播客、课程等）应在**自己的发布清单 / 文案文件**里给出上表字段，不要把产品路径写进本技能。
