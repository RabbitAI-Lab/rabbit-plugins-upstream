## Description:

Live Stream Script generates reusable livestream scripts and prompts for e-commerce, entertainment, education, warmups, product introductions, closing language, and audience interaction.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ckchzh](https://clawhub.ai/user/ckchzh)

### License/Terms of Use:

MIT-0

## Use Case:

Content creators, livestream hosts, and commerce teams use this skill to draft opening, warmup, product presentation, urgency, interaction, and closing scripts for live broadcasts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A bundled script saves entered topics or prompts to a local history file.

Mitigation: Avoid entering confidential campaign plans, customer data, secrets, or unpublished business details unless the logging behavior is removed or clearly controlled.

Risk: The package has unclear command mapping across bundled shell and Python scripts.

Mitigation: Review the command wrappers and expected entry points before installation or agent use.
