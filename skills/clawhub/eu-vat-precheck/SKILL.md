# 欧洲VAT申报预检

## 红线
- 只做预检，不做申报。不得声称预检通过等同于合规。
- 不生成可直接提交给税局或平台的正式文件。
- 信息不足时如实说明"无法判断"，不猜测。
- 不请求任何 API Key、密码或网络访问权限。

## 数据时效
- `references/` 中的税率与截止日数据为 2026 年度整理版本，可能随各国税法调整而变化。
- 引用具体税率或截止日时，必须注明"以各国税局最新公告为准"。

## 工作流

### Step 1：信息收集
一次性向用户收集：
1. 申报国家：德国 / 法国 / 意大利 / 西班牙 / 英国 / 其他欧盟国
2. 申报周期：月度 / 季度 / 年度
3. 申报表草稿：销售额、销项税、进项税、税率
4. 平台对账单摘要：各平台销售额、平台代扣税金额
5. 是否已注册 OSS / IOSS：是 / 否 / 不确定
6. 销售对象类型：纯 B2C / 含 B2B / 不确定
7. 是否有欧盟境内库存移仓，如 FBA 跨国调仓

信息不全时，基于已有信息预检，并标明"因信息缺失无法检查的项"。

### Step 2：逐项预检
参照 `references/rule-table.md` 和 `references/deadlines.md` 检查：

A. 税率适用：申报税率是否与申报国当期标准税率一致；跨境 B2C 是否误用本国税率。

B. 供应地判定：先区分卖家设立地。仅在单一欧盟成员国设立的卖家，适用 EU-wide €10,000/年阈值，跨越后供应地切换为目的地国；非欧盟设立的卖家（如中国跨境卖家）不适用该阈值，自第一笔欧盟境内远程销售起即按目的地国规则征税。检查是否存在应切换未切换、或错误按本国供应地申报的情况。

C. OSS/IOSS 注册匹配：有跨境 B2C 但声明未注册 OSS → 高风险；IOSS 仅适用于 ≤€150 的进口低值货物，货值 >€150 须走标准进口清关，检查是否存在超阈值误用 IOSS。

D. B2B/B2C 分类：是否将 B2B 按 B2C 处理或反之；有企业客户但未收集 VAT 号 → 提示。

E. 申报周期与截止日：周期是否符合该国法定规则；是否临近截止日。

F. 币种换算：是否使用平台结算汇率而非税点日 ECB 汇率；多币种是否统一换算后申报。

### Step 3：生成预检报告
固定三段式 Markdown：

第一部分：风险摘要
一句话给出整体风险等级：🔴 高风险 / 🟡 需关注 / 🟢 未见明显高频错误。🟢 不构成合规结论。

第二部分：逐项结果表
| 检查项 | 结果 | 风险等级 | 依据 | 建议动作 |
|---|---|---|---|---|
| 税率适用 | 发现 X | 🔴/🟡/🟢 | 具体说明 | 具体修正建议 |

风险等级：
- 🔴 高风险：平均纠正成本 >€2,000 或可能导致账户冻结
- 🟡 需关注：平均纠正成本 €500–€2,000
- 🟢 未见异常：未发现明显问题，不构成合规结论

第三部分：下一步建议
按优先级排列 1–3 条具体动作。涉及补申报或注册时注明"建议与你的税务代表确认"。

### Step 4：追问限制
用户可追问已检查项。每次只针对已检查项展开，不扩展到未收集信息领域。用户要求生成申报表时回复："本 Skill 只做预检，不生成申报表。建议将报告交给你的税务代表或会计师。"
