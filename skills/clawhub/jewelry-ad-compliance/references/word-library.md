# 珠宝营销文案合规词库（红 / 橙 / 黄 三级）

> 本词库供 `jewelry-ad-compliance` skill 审查时使用。依据《中华人民共和国广告法》及珠宝饰品行业监管常见违规点整理。
> 等级定义：
> - 🔴 红（高危）：基本必违规，广告法明令禁止或执法中极易认定违规，原则上直接判「违规」。
> - 🟠 橙（中危）：需结合上下文判断是否违规，重点看是否用于比较、排名、形容、功效宣称。
> - 🟡 黄（低危/建议）：非违规但建议优化、补充资质或备注查证，降低投诉/误解风险。
>
> 补充自家历史投诉词：在对应等级表格追加一行，`类别` 填「历史客诉」，并在「风险说明」注明来源案件。保存即生效。

## 🔴 红（高危 / 基本必违规）

| 词条 | 类别 | 风险说明 | 合规建议 |
|------|------|----------|----------|
| 国家级、国家特级、国家免检 | 通用·绝对化用语 | 广告法第9条禁止"国家级"等用语 | 删除，改用具体、可核实的描述 |
| 最高级、最高端、最高档、最高 | 通用·绝对化用语 | 广告法第9条禁止"最高级" | 删除或改"高端""高规格" |
| 最佳、最优、最好、最优秀、最先进 | 通用·绝对化用语 | 广告法第9条禁止"最佳"等 | 改"优选""出色""深受喜爱" |
| 第一、销量第一、排名第一、行业第一、中国第一、全球第一、No.1、TOP1、销量冠军 | 通用·绝对化用语 | 广告法第9条禁止"第一"等排名用语（无法定有效排名证明时） | 删除；"第一时间"等顺序义可豁免 |
| 唯一、独家、绝无仅有、空前绝后、史无前例 | 通用·绝对化用语 | 禁止"唯一"等绝对化表述 | 改"甄选""特色""少见" |
| 世界级、全球领先、世界领先、国际领先 | 通用·绝对化用语 | 禁止"世界级"等无依据领先宣称 | 删除或改"面向全球市场" |
| 领袖、领导者、领军、龙头、鼻祖、创始者、始创者、标杆（无依据） | 通用·绝对化用语 | 暗示行业领导地位且无依据 | 改"深耕XX年""专注XX领域" |
| 100%、百分百、绝对、万能、全能 | 通用·绝对化用语 | "100%有效""绝对"等绝对化/保证性表述 | 改具体、可验证的数值或表述 |
| 驰名商标、中国名牌、国家免检、免检产品 | 通用·禁用标识 | 广告法禁止在广告中使用"驰名商标"及"中国名牌""免检"字样 | 删除 |
| 千足金、万足金、万纯金 | 珠宝·纯度虚假 | 国标 GB 11887 已取消"千足金/万足金"称谓，统一为"足金"；超标准宣称违规 | 改"足金999 / 足金999.9"，按实际含金量标注 |
| 纯金（作纯度宣称） | 珠宝·纯度虚假 | 易误导为 100% 黄金，实际饰品最高为足金999.9 | 改"足金"并标注具体含金量 |
| 立即见效、100%有效、立竿见影（功效承诺） | 珠宝·功效/迷信 | 珠宝饰品宣称疗效/保证性效果违规 | 删除功效承诺，仅描述材质/工艺 |
| 改善睡眠、缓解焦虑、增强免疫力、治疗、消炎、止痛、降血压 | 珠宝·功效/医疗 | 广告法第十七条：非医疗产品不得涉及疾病治疗功能、不得使用医疗用语；水晶/饰品作健康功效宣称必违规 | 删除功效宣称，仅作饰品/材质描述 |
| 稳赚不赔、保本保收益、零风险（投资保证） | 珠宝·投资保证 | 商品不得作保本/收益保证，涉虚假宣传与误导 | 删除收益保证表述 |

## 🟠 橙（中危 / 需结合上下文研判）

| 词条 | 类别 | 风险说明 | 合规建议 |
|------|------|----------|----------|
| 极致、极致工艺、极致之美 | 通用·绝对化倾向 | 常被认定为绝对化，需看是否用于商品形容且无依据 | 无依据改"精湛""出众" |
| 完美、完美无瑕、完美品质 | 通用·绝对化倾向 | "完美"用于商品形容风险高，需上下文判断 | 改"优良""精工""近乎无瑕"（钻石瑕疵须真实） |
| 顶级、顶尖、顶级大师 | 通用·绝对化倾向 | 作排名/绝对形容且无依据则违规 | 改"资深""高级""经验丰富的" |
| 至尊、尊享、尊贵（作等级宣称） | 通用·绝对化倾向 | 暗示最高等级，需依据支撑 | 弱化表述，避免等级暗示 |
| 独一无二（形容商品） | 通用·绝对化倾向 | 设计 uniqueness 可，暗示唯一供应则违规 | 看语境，避免"唯一在售"类暗示 |
| 举世无双、天下无双、绝版 | 通用·绝对化倾向 | 需真实，否则构成虚假/绝对化 | 慎用，确有依据再使用 |
| 领先、行业领先（无依据） | 通用·比较 | 需真实数据支撑 | 补充依据或删除 |
| 首选、首选品牌、必买、必入、闭眼入 | 通用·诱导 | 暗示消费决策，易构成诱导 | 改"热门""人气之选""推荐" |
| 优于、胜过、比XX好（比较） | 通用·比较 | 需真实对比数据，否则违规 | 补充数据或删除比较 |
| 神器、王者、王牌 | 通用·绝对化倾向 | 需看语境，多作绝对化形容 | 弱化表述 |
| 著名设计师、大师（未核实） | 珠宝·背书 | 需真实身份与授权 | 核实身份/授权或删除 |
| 招财、辟邪、转运、安神、保健、养生（明示功效） | 珠宝·功效/迷信 | 民俗寓意可，明示真实功效/医疗作用违规 | 仅作文化寓意，注明"寓意"勿宣称真实功效 |
| 升值、保值增值、投资首选 | 珠宝·投资诱导 | 暗示收益，需风险提示 | 加"投资有风险"或弱化表述 |
| 限量、限量的（无真实数量） | 珠宝·虚假促销 | 需真实限量证据，否则虚假宣传 | 标明真实数量/期限 |
| 明星同款、XX代言（未授权） | 珠宝·代言 | 需获得授权，否则侵权/虚假 | 确认授权或删除 |
| 价值翻倍、年年涨价、只涨不跌、稳涨（升值暗示） | 珠宝·投资诱导 | 升值暗示无依据则违规，且普通饰品不宜作收益承诺 | 删除或加"市场有风险"提示 |

## 🟡 黄（低危 / 建议优化或查证）

| 词条 | 类别 | 风险说明 | 合规建议 |
|------|------|----------|----------|
| 天然翡翠、天然A货 | 珠宝·材质 | 需权威鉴定证书佐证，否则易引发"以次充好"投诉 | 附证书编号/检测机构 |
| 南非钻、产地钻 | 珠宝·产地 | 需产地证明，无凭证的产地宣称易投诉 | 附凭证或删除产地宣称 |
| 足金、18K、铂金 Pt950（未标含量） | 珠宝·材质标注 | 应明确标注材质与含量，避免歧义 | 规范标注（如"足金999""Au750"） |
| 老坑、帝王绿、玻璃种、冰种 | 珠宝·描述 | 需真实，避免虚标等级/以普通料冒称名贵种 | 客观描述或附鉴定结果 |
| 证书、国检、GIA、NGTC | 珠宝·证书 | 须真实机构，切勿虚构检测机构 | 核对机构真实性，标注可查编号 |
| 投资、收藏价值 | 珠宝·投资 | 建议弱化并加风险提示，避免误导 | 加"市场有波动，投资需谨慎" |
| 免费、赠品、满赠 | 珠宝·促销 | 需明示条件与范围，避免"虚假优惠" | 写清规则与有效期 |
| 限时、倒计时、抢购 | 珠宝·促销 | 需真实期限，勿制造虚假紧迫感 | 标注真实截止时间 |
| 材质未标注 | 珠宝·合规 | 贵金属首饰依法须标注材质与含量 | 补全标注 |
| 永久、终身（质保承诺） | 珠宝·承诺 | 需明确范围，避免无法兑现的承诺 | 明确质保范围与条件 |
