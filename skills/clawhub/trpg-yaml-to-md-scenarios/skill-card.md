## Description: <br>
Generates human-readable Traditional Chinese Markdown TRPG scenarios from existing structured YAML scenario files. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[ice26985850](https://clawhub.ai/user/ice26985850) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, game masters, and TRPG content authors use this skill to turn structured YAML scenario files into readable Traditional Chinese Markdown scenarios for tabletop play, printing, or tablet reference. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated Markdown may creatively expand scenario descriptions beyond the source YAML. <br>
Mitigation: Review generated Markdown against the original YAML before publishing, sharing, or running the scenario. <br>
Risk: The skill is intended to process formal TRPG scenario YAML files and write companion Markdown files in the same directories. <br>
Mitigation: Run it only in workspaces where the scenario directories are expected inputs, and confirm original YAML files remain unchanged. <br>
