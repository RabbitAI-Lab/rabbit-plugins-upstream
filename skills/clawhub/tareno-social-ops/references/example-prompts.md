# Tareno example requests

Choose requests appropriate to the authorized account and live tool inventory. These examples describe capability coverage, not a completed test of every client.

1. Show my Tareno workspaces and connected social accounts. Include available audience counts and publishing-health warnings, and tell me which values are unavailable.
2. Show all draft, scheduled, published and failed posts for my selected workspace this week. Identify gaps in the content calendar.
3. Open this Tareno post and summarize its text, media, target account, scheduled time and current status.
4. List recent posts and videos from my connected Instagram account, including content published outside Tareno where the provider permits.
5. Open this account-owned video and show its available caption, media, permalink and metadata.
6. Show the available analytics for this individual post. Request fresh provider data if supported and clearly label missing or cached metrics.
7. Read the available comments on this account-owned post and summarize recurring questions, feedback and possible follow-up content. Do not reply to or moderate comments.
8. Summarize my social performance this month across connected platforms. Explain the reporting period, data freshness and missing coverage.
9. Drill into my LinkedIn performance this quarter and identify the strongest observed content patterns using available metrics.
10. Use my recent analytics to propose next week's content strategy and repurposing opportunities. Separate observations from recommendations.
11. Check the supported formats, character limits and required fields for my selected publishing accounts before preparing campaign content.
12. Show the Pinterest boards and TikTok creator options available for my selected accounts so I can choose valid publishing targets.
13. Turn this campaign brief into distinct LinkedIn, Instagram and Threads drafts for my connected accounts. Save drafts only; do not schedule or publish.
14. Prepare a seven-day campaign with platform-specific draft copy, titles and existing media from my library. Flag any missing assets or unsupported formats.
15. Adapt this approved draft into German and English versions with the supplied brand voice. Save each version as a draft and preserve the original facts.
16. Update this existing editable draft with the revised caption, accessible image descriptions and selected media.
17. Find reusable images and videos in my Tareno media library for this campaign before requesting new assets.
18. Import this public HTTPS image or video URL into my Tareno media library with the supplied filename, folder and tags.
19. Extract the real transcript and available timestamps from this supported public social video URL, then propose draft posts based on the transcript.
20. Resolve a temporary downloadable video link for this supported public social video URL. Do not import or republish it automatically.
21. Request scheduling approval for these reviewed posts at the supplied times in Europe/Berlin. Show the exact targets, timestamps and Tareno approval link.
22. Request approval to publish this reviewed post now to the selected connected account. Check the action status and distinguish approval pending from successful publication.
23. Request approval to move this scheduled post to the supplied date and time. Keep the account and content unchanged.
24. Request approval to update the caption or media of this scheduled post. Show exactly what will change before publication.
25. Request approval to delete this identified draft or scheduled post, then check the final action status. Do not delete an already published platform post.
26. Check which Get Viral discovery and Quick Blueprint features are currently available to my Tareno account and plan.
27. Find public reference videos about my topic on a currently supported discovery platform. Show the returned sources and available metrics without inventing popularity figures.
28. List my existing Get Viral projects and their latest analysis states so I can continue an earlier project.
29. Create a Quick Blueprint project from my topic and up to five public reference videos, using the supplied target platform, language, audience, brand voice and content goal. Do not start a paid analysis yet.
30. Show the AI-credit quote for this Quick Blueprint project and request Tareno approval before starting the analysis. Track the run and retrieve the available summary, script and production blueprint when complete.
