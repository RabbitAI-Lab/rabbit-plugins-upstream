## Description: <br>
Helps frontend teams create practical workflows, checklists, analysis, and implementation support for fixing mobile responsiveness, navigation layout, and cross-device UI issues. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Frontend developers, designers, startup teams, and maintainers use this skill to plan, implement, and validate responsive web interface fixes across phone and desktop layouts. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate for broad frontend or layout requests, not only narrow mobile responsiveness fixes. <br>
Mitigation: Invoke the skill explicitly for responsive-layout work or refine trigger wording before deployment when precise routing is required. <br>
Risk: Responsive layout recommendations may miss project-specific design, accessibility, or framework constraints. <br>
Mitigation: Validate proposed changes against the stated success criteria, target breakpoints, navigation behavior, and any project accessibility requirements. <br>
