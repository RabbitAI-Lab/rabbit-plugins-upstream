## Description:

Synthesize text into natural-sounding speech with Doubao TTS through dLazy.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to turn Chinese or English text into spoken audio with a choice of voices and speaking speeds.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Submitted text or media is sent to dLazy's hosted service.

Mitigation: Share only content you are comfortable sending to dLazy.

Risk: Using the service requires a dLazy API key.

Mitigation: Keep the key private and revoke or rotate it if exposed.

Risk: Generic text-to-speech requests may trigger this skill unintentionally.

Mitigation: Request Doubao TTS explicitly when you want to use this service.
