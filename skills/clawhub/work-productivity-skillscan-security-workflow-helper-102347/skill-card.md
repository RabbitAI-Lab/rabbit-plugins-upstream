## Description: <br>
Helps AI-agent users, skill authors, maintainers, and teams create SkillScan-style workflows, checklists, analysis, code changes, and decision support for security hardening, bug fixes, setup safety, and reliability improvements. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
External developers, AI-agent users, skill authors, maintainers, and teams use this skill to turn SkillScan-style security and productivity needs into practical workflows, checklists, implementation help, and validation notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Implicit invocation is broad and may activate on generic security, bug-fix, or workflow requests. <br>
Mitigation: Narrow or disable implicit invocation so the skill activates for explicit SkillScan or ClawHub skill-review workflow requests. <br>
Risk: Workflow, checklist, code, or configuration guidance may be incomplete for a user's environment. <br>
Mitigation: Review generated outputs, validate them against the stated success criteria, and scan resulting skills or code changes before deployment. <br>
