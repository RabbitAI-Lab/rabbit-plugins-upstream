## Description:

Join the TableJourney partner program and earn 50% of the commission on bookings made by people your agent sends, through the REST API or MCP tools, with no browser.

This skill is ready for commercial/non-commercial use.

## Use Case:

Agents help the person or company operating them join TableJourney's partner program, create referral links, review referral activity, and manage payout setup. Enrollment and payout details should be authorized by the operator.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Signup accepts partner terms on behalf of the operator, so an agent could enroll someone without their informed approval.

Mitigation: Review the linked terms with the operator and obtain explicit authorization before submitting signup or accepting terms.

Risk: Partner setup involves an API key, payout details, and financial and tax information.

Mitigation: Protect the API key, confirm payout details separately with the operator, and explain the financial and tax information requested before proceeding.
