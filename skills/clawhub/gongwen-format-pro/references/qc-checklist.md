# 公文格式质检项清单

`scripts/gongwen_check.py` 的检查逻辑与判定阈值。人工复核时也可照此清单逐项打勾。

## 分级口径

| 级别 | 判定标准 | 结论影响 |
|---|---|---|
| **高** | 违反 GB/T 9704-2012 强制性规定，直接影响公文效力外观 | 存在任意一项即判「不通过」 |
| **中** | 不符合国标推荐做法或通行规范，影响规范性但不致命 | 不影响「合规」结论，建议整改 |
| **低** | 提示性偏差、可选要素缺失 | 仅提示 |

无高级别问题 → **合规**；有高级别问题 → **不通过**。脚本不做加权评分，避免「85 分算不算过」的争议。

## 一、页面设置（check_page）

| 项 | 期望 | 容差 | 级别 |
|---|---|---|---|
| 上边距 | 3.7cm | ±0.15cm | 高 |
| 下边距 | 3.5cm | ±0.15cm | 高 |
| 左边距 | 2.8cm | ±0.15cm | 高 |
| 右边距 | 2.6cm | ±0.15cm | 高 |
| 纸张规格 | 21.0 × 29.7cm（A4） | ±0.15cm | 高 |
| 文档网格 | 指定行和字符网格（linesAndChars / snapToChars） | — | 中 |

## 二、标题（check_title）

标题定位规则：**第一个字号 ≥ 20pt 且非红色**的段落。先排除红色是关键——发文机关标志是红色大字，若不排除会被误判为标题。

| 项 | 期望 | 级别 |
|---|---|---|
| 存在 2 号字标题 | 有 | 高（缺失） |
| 标题字号 | 22pt（2 号），容差 ±0.6pt | 高 |
| 标题字体 | 方正小标宋简体 / 华文中宋 / 宋体（回退许可） | 中 |
| 标题对齐 | 居中 | 高 |

## 三、正文与层级（check_body）

参与判定的段落须通过 `is_body_like()` 过滤，依次排除：

1. 红色文字（红头、印章占位）
2. 字号 ≥ 20pt（标题）
3. 字号 ≈ 14pt（4 号，属页码/版记，另检）
4. 发文字号行、主送机关行（顶格且以冒号结尾）、成文日期行、机关署名等短行

**例外**：命中层次序号（`一、` `（一）` `1.` `（1）`）的短行**不被排除**，否则「一、总体要求」这类短标题会漏检。

| 项 | 期望 | 级别 |
|---|---|---|
| 正文字号 | 16pt（3 号），容差 ±0.6pt | 高 |
| 无正文段落被识别 | — | 高 |
| 一级标题字体 | 黑体 | 中 |
| 二级标题字体 | 楷体_GB2312 | 中 |
| 三、四级及普通正文字体 | 仿宋_GB2312 | 中 |
| 首行缩进 | 1.13cm（2 字），容差 ±0.15cm | 中 |
| 行距 | 固定值 28 磅，容差 ±2 磅 | 中 |

**两个例外**：

1. **首行缩进**——整段左缩进 ≥ 0.5cm 的行不判首行缩进错误。这类是附件说明续行、抄送回行等「与上行文字对齐」的排法，国标另有规定。
2. **无序号小标题字体**——无层次序号、长度 ≤ 30 字且不以句读（。；：，！？、）收尾的行，视为提行小标题，不按普通正文的「仿宋」要求判错。实务中这类标题常用黑体或楷体提行，与排版脚本对 Markdown `#` 的处理口径保持一致。

## 四、版头与主体要素（check_elements）

| 项 | 期望 | 级别 |
|---|---|---|
| 发文字号年份括号 | 六角括号〔〕，不得用 [] () | 高 |
| 发文字号序号虚位 | 〔2026〕12号，不写 012号 | 高 |
| 成文日期数字 | 阿拉伯数字，不用汉字「二〇二六年」 | 高 |
| 成文日期虚位 | 8月6日，不写 08月06日 | 中 |
| 主送机关冒号 | 全角「：」，不用半角 ":" | 中 |
| 附件说明标点 | 附件名称后不加句号/分号/逗号 | 中 |
| 版记字号 | 14pt（4 号） | 中 |

## 五、页码（check_footer）

| 项 | 期望 | 级别 |
|---|---|---|
| 页脚存在 PAGE 域 | 有 | 中 |
| 一字线 | 使用「—」（U+2014），非半角「-」 | 中 |
| 页脚距边界 | 约 2.8cm，容差 ±0.3cm | 低 |

## 六、结构完整性（check_structure）

| 项 | 说明 | 级别 |
|---|---|---|
| 层级跳跃 | 出现「（一）」但全文无「一、」 | 低 |
| 一级序号连续性 | 一、二、三…是否跳号或重复 | 低 |

## 已知不检查的项

以下依赖版式渲染或语义判断，脚本不做机械判定，需人工核对：

- 发文机关标志上边缘距版心的实测距离（受 space_before 与行高叠加影响）
- 印章是否骑年盖月、是否下压署名
- 版记是否落在最后一面、末条线是否与版心下边缘重合
- 标题回行是否「词意完整、排列对称」
- 行文关系是否恰当（上行/平行/下行）、文种选用是否准确
- 内容真实性、数据准确性
