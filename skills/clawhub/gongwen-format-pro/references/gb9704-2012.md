# GB/T 9704-2012 参数速查

《党政机关公文格式》国家标准的可执行参数汇总。本表用于脚本实现与人工核对，条款以正式发布文本为准。

## 一、用纸与版心

| 项目 | 规定值 |
|---|---|
| 纸张 | A4，210mm × 297mm（GB/T 148） |
| 上页边距 | 37mm ± 1mm |
| 下页边距 | 35mm ± 1mm |
| 左页边距 | 28mm ± 1mm |
| 右页边距 | 26mm ± 1mm |
| 版心尺寸 | 156mm × 225mm |
| 每页行数 | 22 行 |
| 每行字数 | 28 字 |
| 行距实现 | 固定值约 28 磅（linePitch 580） |
| 装订 | 左侧装订，两个订位，距上下各 1/4 处 |

注：一字 = 3 号字宽度 ≈ 0.565cm；「空二字」= 1.13cm，脚本以此值判定首行缩进。

## 三、要素编排要点

### 版头
- 三要素（份号、密级、紧急程度）都在首页版心上方**左上角**依次顶格排列。
- 联合行文：发文机关标志按发文机关顺序排列，主办机关在前；机关名称过多时可压缩字号，但上下边界不得超过规定。
- 上报公文：发文机关标志上边缘距版心上边缘 **80mm**（下行文为 35mm），为签发人留出位置。

### 主体
- 标题**不加标点**（书名号、引号等必要标点除外）。
- 主送机关名称过多导致首页不能显示正文时，可移至版记（主送机关位置改列于版记抄送上方）。
- 附件说明的序号使用「1.」「2.」，名称后**不加任何标点**。
- 成文日期：年月日**不编虚位**，如「2026年8月6日」不写成「2026年08月06日」；年份不能简写。
- 印章：单一机关行文，印章端正居中下压发文机关署名，上距正文（或署名）一行之内，「骑年盖月」。

### 版记
- 版记置于公文**最后一面**，末条分隔线与版心下边缘重合。
- 版记上下各一条分隔线：首条为粗线（约 0.35mm），末条为粗线，中间要素间用细线（0.25mm）分隔。
- 版记内所有要素均为 **4 号仿宋**（这是 v1.4 之前常见的踩坑点，勿用 3 号）。
- 无抄送、印发机关等要素时，版记可省略；会议纪要一般不设版记。

### 页码
- 国标要求**全篇编页码**，包括首页。「首页不编页码」是部分单位内部惯例，不是国标要求。
- 空白页不编页码也不算页数。
- 页码形式：`—  1  —`，即数字两侧各一条**一字线（—，U+2014）**，不是半角连字符。

## 四、15 种法定公文

决议、决定、命令（令）、公报、公告、通告、意见、通知、通报、报告、请示、批复、议案、函、纪要。

其中**纪要**格式特殊：一般标注「××××会议纪要」，不加发文机关标志红线与版记，不加盖印章，出席、列席、请假人员在正文之前列明。本技能用 `--minutes` 处理。

## 五、字体可用性说明

国标点名的「方正小标宋简体」「仿宋_GB2312」「楷体_GB2312」属于特定厂商字库，多数系统未预装。脚本的处理策略：

| 国标字体 | 回退候选（依次探测） |
|---|---|
| 方正小标宋简体 | FZXiaoBiaoSong-B05S → 方正小标宋简体 → 华文中宋 STZhongsong → 宋体 SimSun |
| 仿宋_GB2312 | FangSong_GB2312 → 仿宋 FangSong → 华文仿宋 STFangsong |
| 楷体_GB2312 | KaiTi_GB2312 → 楷体 KaiTi → 华文楷体 STKaiti |
| 黑体 | SimHei 黑体 → 华文黑体 STHeiti |
| 宋体 | SimSun 宋体 → 新宋体 NSimSun |

回退只影响**本机预览效果**，不影响文档结构合规性。送审、付印前应在装有公文字库的机器上用 `--strict-font` 重新生成，或直接安装字库。
