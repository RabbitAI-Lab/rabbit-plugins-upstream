## Description:

Suggests clear unit-test names from short behavior descriptions, following existing test-naming patterns when available.

This skill is ready for commercial/non-commercial use.

## Publisher:

[hmahmadcs](https://clawhub.ai/user/hmahmadcs)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to name new unit tests or replace vague test names based on the behavior under test and their project's conventions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A suggested name may misstate the behavior being tested or differ from the project's naming convention.

Mitigation: Check each name against the test assertions and existing test names before adopting it.
