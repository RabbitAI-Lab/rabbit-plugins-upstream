## 逐張文案與畫面設計

### 1. 收到收到

讓角色做出雙手接住訊息泡泡、快速點頭或敬禮的動作。文字建議置於畫面上方或角色側邊，以兩行排版：「收到／收到」，第一行略小、第二行略大，形成節奏感。避免搭配太多文件、信封或訊息圖示，以免縮小後變得混亂。

### 2. 辛苦了

讓角色遞出飲料、毛巾、點心或做出溫柔拍肩動作。文字使用單行大字，置於角色上方，保留臉部與手部空間。色彩採暖色系，描邊清楚；不要把「辛苦了」畫成過度疲憊或病態，以免把過勞當成笑點。

### 3. 晚點回

讓角色一手拿手機、一手比出稍等手勢，旁邊搭配小時鐘或訊息提示。文字可放在角色下方，採兩段式：「晚點／回」，每段不超過四字。避免使用「馬上回」等可能被理解為明確時間承諾的文案。

### 4. 又開會

讓角色抱著筆電或坐在會議桌前，眼神放空，背景可用重疊的會議通知卡片。文字放在上方，採粗體短句「又開會」，搭配小型時鐘或會議圖示。此張建議標示為熟同事/朋友用語，不要設計成指向特定主管的攻擊畫面。

### 5. 我先走

讓角色背著包、揮手走向出口或關閉筆電。文字放在角色移動方向的前方，使用斜向速度線，但不要讓文字靠近裁切邊界。可加「明天見」作為小字，但正式製作時建議主文字仍維持「我先走」，避免字數過長。

### 6. 需求又變了

讓角色面對不斷增加的便利貼、版本標籤或變形中的文件，表情採無奈而非憤怒。文字分兩行：「需求／又變了」，每行保持高對比。公開版可改為「我先確認需求範圍」，並以同一構圖製作低衝突版本。

### 7. 先撐住

讓角色一手扶住快倒下的文件堆或進度條，一手比加油手勢。文字放在進度條上方或下方，不要壓住角色臉部。視覺可以誇張，但應加入小型休息符號、飲水或時鐘，避免傳達「必須無限加班」的訊息。

### 8. 網路卡住

讓角色停格成像素化或被旋轉載入圖示包圍，畫面可有斷續的 Wi‑Fi 圖示。文字置於下方並留出透明安全邊界。不要畫成角色被嘲笑或無法工作；對客戶版本可使用「連線不穩，請稍等一下」作為替代文案。

### 9. 腦袋當機

讓角色頭上出現小型載入圈、空白視窗或打轉符號，表情保持可愛自嘲。文字置於畫面上方，單行大字。不要使用醫療診斷、精神疾病標籤或自傷暗示；安全版本可改為「腦袋需要重整一下」。

### 10. 準時下班

讓角色開心關閉筆電、打卡或走出辦公室，背景使用夕陽、出口或收工提示。文字採大字置於上方，角色放在下方偏中央。不要畫成逃避責任；可搭配完成清單打勾，表達工作告一段落後的健康界線。

## 共通排版規格

| 項目 | 建議 |
| --- | --- |
| 文字長度 | 主文案優先控制在 2–8 個中文字；超過 10 字改做安全替代句或後製排版 |
| 位置 | 避開臉、手勢與重要道具；四周預留安全邊界 |
| 字體 | 粗體、簡潔、縮小後仍可辨識；同套貼圖維持同一字體性格 |
| 描邊 | 使用高對比描邊與陰影，避免背景和文字同色 |
| 層級 | 每張只保留一個主訊息；小字只作補充，不要搶主文案 |
| 背景 | 若交給 `line-sticker-factory` 色鍵去背，避免角色與文字使用背景鍵色 |
| 生成方式 | 生成模型文字視為草稿；錯字或字形不穩時改成留白圖再後製 |
| 一致性 | 固定角色比例、視角、服裝、配色與字體位置邏輯 |

## 使用與擴充原則

若要實際驗證人氣，應另收集使用者投票、貼圖點擊、下載或對話使用資料；在沒有這些資料前，不得把本指南的排名描述成市場調查結果。新增文案時，沿用 `workplace-meme-catalog.md` 的欄位，並補上「文案版本、排版位置、主要動作、替代句與公開風險」。
