# 小沙彌向善用語專區｜網站整合參考

## 網站定位

「小沙彌向善用語專區」是搭配 `line-sticker-master` 使用的台灣繁體中文語料瀏覽器。網站以「寺院晨光紙本」為視覺方向，將向善日常用語整理成可搜尋、可分類、可複製的貼圖 Prompt 素材庫。

| 項目 | 目前內容 |
| --- | --- |
| 公開 GitHub | https://github.com/qpooqp777/little-monk-kind-words-site |
| GitHub Pages | https://qpooqp777.github.io/little-monk-kind-words-site/ |
| 類別 | 12 類 |
| 語料 | 144 筆，每類 12 筆 |
| 單句操作 | 複製完整單格 Prompt |
| 整類操作 | 選擇類別後複製該類 12 格 Prompt |
| 部署方式 | GitHub Actions 建置並部署 GitHub Pages |

## 內容欄位

每筆語料均應包含下列欄位，與 Skill 的 12 格腳本格式相容：

| 欄位 | 用途 |
| --- | --- |
| 類別 | 例如慈悲、感恩、包容、鼓勵、安定、自省、和善、善行、尊重、和解、分享、祝福 |
| 貼圖文字 | 台灣繁體中文的短句 |
| 適合情境 | 說明何時可以自然使用 |
| 小沙彌動作 | 角色的主要姿勢或行動 |
| 表情 | 溫柔、安心、認真、感動等情緒方向 |
| 視角 | 正面、側面、三分之二側面、俯角或仰角 |
| 手繪特效 | 蓮花、木魚、茶杯、光線、雲朵等非文字圖案 |

## 使用流程

先在網站以類別或關鍵字找到適合的語料。若只要製作單一貼圖，使用該筆的「收下這句」複製完整 Prompt；若要製作完整 12 格套組，先選擇單一類別，再使用「收下該類 12 格」一次複製。複製內容會以真正換行分隔，方便直接貼入圖像生成模型或 Prompt 編輯器。

「全部語料」只適合瀏覽、搜尋與挑選，不提供整類複製，避免誤複製過長的 144 筆內容。網站的搜尋、分類、今日一句與單句複製不會改變 Skill 的角色 bible 或生成規格。

## 與 LINE 貼圖 Skill 的銜接

網站適合作為 Skill 的語料選擇層；`SKILL.md` 仍負責角色一致性、4×3 網格規格、文字審核、去背檢查與 `line-sticker-factory` 整合。從網站複製的 12 筆內容應放回單一網格 Prompt 的第 1–12 格，並補上同一份角色 bible、背景、尺寸、外框、負面提示詞與文字後製備案。

如果圖像模型無法可靠生成繁體中文，請保留網站提供的動作與排版資訊，只生成文字留白版本，再以後製工具加入文案。小沙彌主題可維持二頭身、溫柔、向善與不說教的表現，避免把宗教信仰變成嘲諷、威嚇或道德壓迫。

## GitHub Pages 維護

網站儲存庫使用 `.github/workflows/pages.yml`。推送到 `main` 後，工作流會執行 `pnpm install --frozen-lockfile`、`pnpm check`、`pnpm build`，成功後部署 `dist/public`。Vite 在 GitHub Actions 中使用 `/little-monk-kind-words-site/` base path；本機開發仍使用根路徑。

更新網站內容或介面後，至少確認公開頁面的首頁、圖片資產、分類索引、整類複製與手機版版面，再將對應網站連結保留在 README 與本參考文件中。
