# Framework Sources

This skill packages several published, tested frameworks into one discovery-to-roadmap workflow rather than inventing a new methodology.

- **Peter Drucker, "Innovation and Entrepreneurship" (1985)** — the seven sources of innovation (the unexpected, incongruities, process need, industry/market structure change, demographics, perception shifts, new knowledge). Used in Phase 1–2 to shape which workflow questions surface real opportunities rather than surface-level complaints.
- **Clayton Christensen, Jobs-to-be-Done** — frames each candidate opportunity around the job the business or customer is actually trying to get done, not the tool they currently use to do it. Used in Phase 2's opportunity mapping.
- **Impact–Feasibility / Value–Effort matrix** — a standard prioritization tool used across AI and automation consulting practice (structured process inventory → impact scoring → feasibility scoring → priority matrix → pick the top one or two). Used directly in Phase 3.
- **The data-rich / process-heavy heuristic** — a screening rule from AI use-case identification practice: the strongest AI candidates combine substantial unstructured information with meaningful process effort (hours and multiple steps, not a single click). Used in Phase 2.
- **AI Readiness scoring practice** — data quality, process documentation, process ownership, and error tolerance/recoverability as the standard sub-factors for whether a workflow is actually ready for AI, independent of how valuable it would be. Used in Phase 3 and the scoring rubric.
- **Build vs. buy heuristic** — commodity problems (shared across many businesses) favor buying; problems tied to proprietary data or a genuine differentiator favor building. Standard in technology strategy and applied directly in Phase 5.

### Context stats worth citing in a real assessment (verify currency before quoting)

- Industry estimates commonly cited in automation-opportunity literature put 20–30% of employee time on tasks that are automatable (Forrester-sourced estimate, widely referenced in automation consulting).
- Broad industry surveys have repeatedly found that only a minority of companies have redesigned workflows around AI rather than layering AI on top of unchanged processes — this is why Phase 4's "no AI" filter and Phase 1's process documentation questions matter more than tool selection.

No proprietary or paid framework is required to use this skill — everything above is documented, publicly available business/strategy methodology, applied conversationally with no external API calls.
