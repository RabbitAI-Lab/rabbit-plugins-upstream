# SOLUTION() 售后方案

**Skill ID:** `zayn-solution`
- 所属分类：客诉与售后
- 一句话用途：事实和责任基本明确后比较维修、换货、退款、补发等方案并给出风险可控建议
- 当前版本：`v0.1`
- 当前状态：Draft for testing
- 规则是否完成：是，初版规则已建立
- 是否已有测试案例：否，等待真实脱敏案例
- 下一步待办：测试参数、证据、最低运行条件、责任边界和输出结构

SOLUTION() 用于在事实和责任基本明确后，对维修、换货、退款、补发、折扣、下单时补发等售后方案进行比较，并给出风险可控的建议。它不负责前置事实调查，也不在责任未确认时直接给方案。

完整规则见 [SKILL.md](SKILL.md)，调用模板见 [examples.md](examples.md)，测试要求见 [tests.md](tests.md)。
