## Description:

Query and update persistent 6-DoF SE(3) spatial world state, kinematic object trajectories, and task affordances for embodied robots and ROS 2 nodes via the SlashML Embodied Robotics API and MCP tools.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and robotics engineers use this skill to record and retrieve object poses, trajectories, workstation zones, and affordances for embodied agents and ROS 2 applications.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Spatial observations may contain sensitive workspace information and are sent to an external service for storage.

Mitigation: Review observations for sensitive details and confirm you are comfortable with the external service receiving and storing them before recording data.
