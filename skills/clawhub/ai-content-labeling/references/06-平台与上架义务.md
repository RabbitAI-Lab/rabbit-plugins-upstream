# 06 平台与上架义务

> 用途：回答「传播平台有什么义务」「应用商店审核要准备什么」。
> 核对基准日：2026-08-27

## 1. 传播平台四步核验（中国）

| 步骤 | 动作 |
|---|---|
| 1. 核验 | 检查文件元数据是否含隐式标识 |
| 2. 分类 | ①明确标明→加"属于生成合成内容"提示 ②用户声明→加"可能为生成合成内容"提示 ③检测到痕迹→加"疑似生成合成内容"提示 |
| 3. 写回 | 前三类情形在文件元数据中添加传播要素信息（生成属性、平台名称或编码、内容编号） |
| 4. 功能 | 提供标识功能，提醒用户主动声明 |

## 2. 平台技术实现建议

- 上传管线接入元数据解析器（检测隐式标识）；
- 发布流程按检测结果自动加提示标签；
- 用户发布界面提供"AI 生成声明"开关；
- 下载时回写传播要素元数据。

## 3. 应用商店上架审核（中国）

- App 上架/上线审核：**说明是否提供 AI 生成合成服务**；
- 提供的：**提交生成合成内容标识相关材料**（标识方法说明、实现方案）；
- 审核不通过风险：未说明/未提交材料。

## 4. 欧盟平台相关

- 超大型平台（DSA 框架）对合成内容传播有额外要求；
- Article 50 机器可读标记的检测：平台可提供"疑似 AI 生成"提示（类似中国核验逻辑）；
- 透明度行为守则签署方按守则执行。

## 5. 平台合规检查清单

- [ ] 上传解析：元数据隐式标识检测
- [ ] 发布提示：三档提示标签（明确/可能/疑似）
- [ ] 用户声明功能：发布时 AI 生成声明开关
- [ ] 元数据回写：传播要素信息
- [ ] 上架材料：AI 生成服务说明 + 标识方案
- [ ] 举报与处置：标识违规内容处理机制
- [ ] 日志留存：配合监管溯源
