# 05 隐式标识技术方案

> 用途：回答「隐式标识用什么技术」「元数据字段怎么定」「水印怎么选」。
> 核对基准日：2026-08-27（技术方案为选型参考，注意配套强制性国标《网络安全技术 人工智能生成合成内容标识方法》）

## 1. 两种技术路线

| 路线 | 原理 | 优点 | 缺点 | 适用 |
|---|---|---|---|---|
| **元数据标识** | 在文件头部写入描述性信息（EXIF/XMP/ID3/容器级） | 实现简单、可读性好 | 易被剥离（转码/重存丢失） | 合规快落地 |
| **数字水印** | 在内容信号（像素/音频/视频帧）内嵌入不可见标记 | 抗篡改、转码后仍可检测 | 实现复杂、可能影响质量 | 强合规/防伪 |

**建议**：**元数据 + 水印双轨**——元数据快速合规，水印增强抗剥离（鼓励方向）。

## 2. 元数据字段模板（工具 `metadata` 命令生成）

核心字段（对应中国办法要求）：

| 字段 | 说明 | 示例 |
|---|---|---|
| `content_attribute` | 生成合成内容属性信息 | `ai_generated` |
| `provider_name` | 服务提供者名称或编码 | `Provider-Code-001` |
| `content_id` | 内容编号 | `GEN-20260827-0001` |
| `generated_at` | 生成时间 | `2026-08-27T16:00:00+08:00` |
| `label_version` | 标识方案版本 | `1.0` |
| `modality` | 内容类型 | `image` |

## 3. 水印方案选型

| 类型 | 技术 | 抗性 | 复杂度 |
|---|---|---|---|
| 图像可见水印 | 角标叠加 | 低（可裁剪） | 低 |
| 图像隐写水印 | DCT/DWT 域嵌入 | 中（抗压缩） | 中 |
| 音频水印 | 频谱/相位调制 | 中 | 中 |
| 视频帧水印 | 关键帧嵌入 | 中 | 中 |
| 语义水印（内容指纹） | 特征向量嵌入 | 高 | 高 |

**选型建议**：
- 快速合规 → 元数据（当天可上）；
- 防伪要求 → 隐写水印；
- 深度伪造溯源 → 内容指纹/凭证方案（如 C2PA 类内容凭证标准）。

## 4. 中欧复用方案

中国隐式标识（元数据+水印）≈ 欧盟机器可读标记——**一套方案两用**：

```
统一标识 SDK（元数据写入 + 水印嵌入 + 导出校验）
   ├─ 中国模式：按标识办法字段写元数据 + 显式提示
   └─ 欧盟模式：同一元数据满足机器可读标记 + 深度伪造披露
```

## 5. 落地步骤

1. 确定内容类型（文本/图片/音频/视频/虚拟场景）；
2. 选元数据方案（先）+ 水印方案（后）；
3. 建统一标识 SDK/服务；
4. 接入生成管线（产出即标）；
5. 导出链路校验（文件含显式+隐式）；
6. 测试剥离/转码抗性；
7. 配合国标与法规更新迭代。
