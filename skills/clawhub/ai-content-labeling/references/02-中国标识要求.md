# 02 中国标识要求

> 用途：回答「中国显式/隐式标识具体怎么要求」「平台义务」「上架审核」。
> 核对基准日：2026-08-27（依据：四部门《人工智能生成合成内容标识办法》，2025-09-01 施行）

## 1. 双标识制度

**显式标识**（用户可明显感知）：以文字、声音、图形等方式呈现。
**隐式标识**（用户不易感知）：通过技术措施在生成合成内容**文件数据**中添加。

## 2. 显式标识要求（按内容类型）

| 内容类型 | 显式标识要求 |
|---|---|
| 文本 | 起始/末尾/中间适当位置添加文字提示或通用符号提示；或在交互界面/文字周边加显著提示 |
| 音频 | 起始/末尾/中间适当位置添加语音提示或音频节奏提示；或在交互界面加显著提示 |
| 图片 | 适当位置添加显著提示标识 |
| 视频 | 起始画面和播放周边适当位置加显著提示；可在末尾/中间适当位置加 |
| 虚拟场景 | 起始画面适当位置加显著提示；可在持续服务过程中适当位置加 |
| 下载/复制/导出 | **文件中必须含满足要求的显式标识** |

## 3. 隐式标识要求

- 按《深度合成管理规定》第 16 条，在生成合成内容**文件元数据**中添加隐式标识；
- 隐式标识包含：**生成合成内容属性信息、服务提供者名称或编码、内容编号**等制作要素信息；
- 鼓励添加数字水印等形式的隐式标识；
- 文件元数据 = 按特定编码格式嵌入文件头部的描述性信息（来源/属性/用途）。

## 4. 传播平台义务（四条）

| # | 情形 | 平台动作 |
|---|---|---|
| 1 | 元数据明确标明为生成合成内容 | 发布内容周边加显著提示，明确提醒属于生成合成内容 |
| 2 | 未核验到隐式标识，但用户声明为生成合成 | 加显著提示，提醒"可能为生成合成内容" |
| 3 | 未核验到隐式标识、用户未声明，但检测到显式标识/其他痕迹 | 识别为疑似生成合成内容，加显著提示 |
| 4 | 平台自身 | 提供必要标识功能，提醒用户主动声明发布内容是否含生成合成内容 |

**对应动作**：前三项情形均须在文件元数据中添加传播要素信息（生成属性、平台名称或编码、内容编号）。

## 5. 应用程序分发平台义务

- 上架/上线审核时：要求 App 服务提供者说明是否提供 AI 生成合成服务；
- 提供生成合成服务的：**核验其生成合成内容标识相关材料**。

## 6. 服务提供者其他义务

- 用户服务协议中**明确说明标识方法、样式等规范**，提示用户阅读理解标识管理要求；
- 用户申请"不含显式标识"的生成内容：可在协议明确用户标识义务与使用责任后提供，**并留存提供对象信息等相关日志不少于 6 个月**；
- 履行算法备案、安全评估手续时，按本办法提供标识相关材料；
- 加强标识信息共享，配合防范打击相关违法犯罪。

## 7. 禁止行为（任何人）

不得恶意删除、篡改、伪造、隐匿生成合成内容标识；不得为他人实施上述行为提供工具或服务；不得通过不正当标识手段损害他人合法权益。
