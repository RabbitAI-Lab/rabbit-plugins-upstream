# 04 各类内容标识做法

> 用途：回答「文本/图片/音频/视频/虚拟场景具体怎么标」。
> 核对基准日：2026-08-27

## 1. 文本内容

**显式标识**：
- 起始/末尾/中间适当位置添加文字提示或通用符号提示（如"AI 生成内容"、"本文由 AI 生成"、⚠️ 通用符号）；
- 交互场景：界面/文字周边加显著提示标识（如固定提示条）。

**隐式标识**：文本文件元数据（如 Markdown/HTML 头部、文档属性）写入生成属性与服务商编码。

**实操建议**：模板自动追加标识行；接口层统一注入。

## 2. 图片内容

**显式标识**：
- 适当位置添加显著提示标识（如角标水印"AI 生成"）；
- 下载/导出文件须含显式标识（不能只在预览界面显示）。

**隐式标识**：图像元数据（EXIF/XMP/IPTC 写入生成属性、服务商编码、内容编号）+ 数字水印（可叠加）。

**实操建议**：生成管线末端统一加角标 + 写 EXIF；水印方案见 05 模块。

## 3. 音频内容

**显式标识**：
- 起始/末尾/中间适当位置添加语音提示（如"本音频由 AI 生成"）或音频节奏提示；
- 交互界面加显著提示。

**隐式标识**：音频元数据（ID3 等）+ 音频水印（频谱/相位水印）。

**实操建议**：输出前自动拼一段语音提示；元数据统一注入。

## 4. 视频内容

**显式标识**：
- 起始画面 + 播放周边适当位置加显著提示标识；
- 可在末尾/中间适当位置加。

**隐式标识**：视频容器元数据 + 帧内水印。

**实操建议**：渲染管线在起始画面叠加标识层；容器级元数据注入。

## 5. 虚拟场景

**显式标识**：起始画面适当位置加显著提示；持续服务过程中可适当位置加。

**隐式标识**：场景数据元数据。

## 6. 下载/复制/导出链路（中国强制）

所有类型内容，提供下载/复制/导出功能时，**文件中必须含满足要求的显式标识**——不能只在平台内显示，文件本身也要带。

## 7. 通用实现架构（建议）

```
AI 生成管线 → 内容产出
   │
   ├─ 显式标识层（模板/角标/语音提示，按类型）
   ├─ 隐式标识层（元数据写入 + 数字水印）
   └─ 校验层（导出前验证文件含标识）
```

**落地优先级**：先做显式标识（成本低、合规快），再做元数据隐式标识，最后上数字水印（防篡改强度高）。
