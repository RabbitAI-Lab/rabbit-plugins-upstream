# 知网报告下载、解读与验真

## 下载

订单完成后优先打开：

    https://cnki.cqccjy.cn/pzw/check?orderNo={order_no}

页面通过本站 HTTPS 下载代理获取报告，避免把供应商 HTTP 地址直接交给用户。只有 report 命令拿到真实 HTTPS 地址时，JSON 才填写 report_download_url。

页面实际操作条件是 order.status=COMPLETED；只有存在 reportPreviewUrl/reportMobilePreviewUrl 时才显示在线预览，只有 canDeleteReport=true 时才显示删除报告。删除后不能继续下载，skill 不提供删除命令。

页面顶部还会展示 productName、论文标题、作者、提交检测时间、statusLabel；结果卡可能使用 wordCount、rateInfo、reportNum。不同产品的报告字段不保证相同。

## 解读

解读报告时只使用报告实际出现的字段。常见字段可能包括总文字复制比、去除引用文献复制比、去除本人已发表文献复制比、单篇最大文字复制比、章节/片段和相似来源，但不同产品和报告版本可能不同。

- 不补造报告没有的指标；
- 不用 100%-重复率 计算并宣称“原创率”；
- 不把总文字复制比直接等同于抄袭比例；
- AIGC 报告与文字复制检测报告是不同类型，不能互相替代；
- 是否达标只依据学校、期刊或单位当年度书面要求。

## 验真

首选统一入口：https://vpcs.cqccjy.cn/pwp/verify 。进入后选择“知网报告验真”。统一入口不可访问时，备用知网官方页面：https://check7.cnki.net/codeverify/ 。

知网当前页面通常要求：

1. 选择“学术不端检测报告单”或“AIGC报告单”；
2. 从报告首页 №: 后复制报告单编号，不复制字段名、题名、作者或页码；
3. 由用户本人识读并填写验证码；
4. 查询后交叉核对报告类型、题目、作者/送检主体、检测时间和编号。

Skill 不猜验证码、不代提交、不索取账号密码、不把完整报告上传到非官方网站。无记录时先检查报告类型、首尾空格、换行和 0/O、1/I 等字符混淆；仍不一致就停止连续试错并联系官方支持。

验真通过只说明官方系统能找到对应记录，不代表论文合格、重复率达标或 AIGC 结论一定正确。

## 报告下载故障处理

1. 先保留原 orderNo，重新打开本站 /pzw/check 或 /zw/check。
2. 确认 status=COMPLETED，再点“下载报告”。
3. 浏览器拦截下载时按浏览器提示保留文件或更换浏览器；不要把临时 URL 复制到第三方网站。
4. 若本站报告地址为空、过期或返回非 HTTPS，停止连续重试并联系客服。
