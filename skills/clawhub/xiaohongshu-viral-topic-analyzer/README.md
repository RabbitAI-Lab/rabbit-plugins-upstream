# 小红书爆款选题分析器

> 把「不知道发什么」变成「有一张可执行的选题表」

## 它解决什么问题

做小红书最耗时的不是写，是**决定写什么**。大多数人选题靠刷同行的爆款，结果是：

- 追热点追到同质化，发出去没有水花
- 选题凭感觉，发了 20 篇都不知道哪种类型有效
- 知道要「垂直」，但不知道垂直之后具体发什么

这个 Skill 把选题从「灵感问题」变成「工程问题」——用固定的分析模型、公式库和结构模板，稳定产出可执行的选题方案。

## 核心方法

### 一、四象限模型：先判断选题值不值得做

小红书的流量有两条独立通道：**搜索**（用户主动找）和**推荐**（系统推给可能感兴趣的人）。
同样的选题，在哪个象限决定了该怎么写。

| | 搜索意图强 | 搜索意图弱 |
|---|---|---|
| **竞争低** | 🟢 黄金区（必做） | 🟡 机会区（试水） |
| **竞争高** | 🟠 血战区（要差异化） | 🔴 高风险区（易爆难沉淀） |

起号期配比建议：黄金 50% / 机会 30% / 血战 15% / 高风险 5%。

### 二、选题四类土壤

- **痛点型**：用户已经知道有问题，正在搜解法 → 搜索流量稳
- **决策型**：A vs B 的选择困境 → 转化率最高
- **场景型**：具体到「周五下班直接出发」的生活切片 → 推荐流量好
- **情绪型**：立场和反差 → 爆发力强但不可控

### 三、18 个标题公式 + 8 类开头钩子

标题公式按「搜索型 / 身份型 / 情绪型 / 结构型」四组分类，每个公式带真实结构示例。
开头钩子分 8 类（反常识、具体代价、身份自曝、时间锚点、场景代入、数据冲击、排除法、提问直击），
并给出「选题类型 → 钩子」的匹配决策表。

### 四、4 种笔记结构模板

测评横评 / 教程方法 / 避坑踩雷 / 场景故事，每种给出分段骨架和字数控制。

## 输出契约

对每个选题，强制输出 6 个字段（缺一项视为不合格）：

| 字段 | 说明 |
|---|---|
| 选题标题 ×3 | 三个变体，钩子类型不重复 |
| 钩子类型 | 标明用了哪一类 |
| 目标人群 | 具体到「谁在什么场景下会点开」 |
| 流量逻辑 | 搜索型 / 推荐型，为什么有分发优势 |
| 竞争度 | 低/中/高 + 判断依据（6 个可观察信号） |
| 内容结构 | 按模板给出分段骨架 |

## 质量红线

这个 Skill 会**拒绝**以下输出：

- 标题里出现「干货」「分享」「必看」「yyds」等零信息量词
- 选题无法回答「目标用户会主动搜索它吗」
- 3 个标题变体钩子类型重复
- 只用「年轻人」「女性」「上班族」这种无法定位的人群描述
- 给出「保证爆款」类承诺

## 使用方式

```
用户：我做露营装备的账号，不知道发什么

Skill 输出：
1. 赛道拆解（四类土壤各 5 条）
2. 选题清单表（含竞争度评分）
3. 挑 3 条展开详细方案（封面文案+开头钩子+正文骨架+标签）
4. 三周执行节奏
```

## 适用与边界

**适用**：小红书内容创作者、品牌新媒体运营、个人 IP 冷启动

**边界**：
- 不承诺流量结果，只提供选题与结构方法
- 不生成虚假使用体验（未真实使用会明确标注「方法推演」）
- 涉及医疗、金融、法律建议时提示咨询专业人士
