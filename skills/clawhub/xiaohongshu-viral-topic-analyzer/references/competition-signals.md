# 竞争度判断的 6 个信号

## 为什么要判断竞争度

同样的选题，在红海里做等于石沉大海，在蓝海里做等于白捡流量。
**判断依据必须是可观察的信号**，不能凭感觉说「这个好像挺火」。

## 信号 1：搜索联想词的数量与质量

在平台搜索框输入核心词，看下拉联想：

| 现象 | 判断 |
|---|---|
| 下拉全是「XX 哪个牌子好」「XX 怎么选」 | 🟠 竞争高（大量商家在做 SEO） |
| 下拉出现「XX 后悔」「XX 缺点」 | 🟢 机会（说明用户有未被满足的疑虑） |
| 下拉只有泛词（「XX 推荐」） | 🟢 蓝海（还没人系统做） |
| 下拉出现长尾具体场景（「XX 小户型」「XX 新手」） | 🟢 黄金区 |

## 信号 2：头部笔记的发布时间

看搜索结果第一屏的笔记日期：

- 大多是**近 3 个月** → 竞争激烈，内容更新快，需要更强角度
- 大量是**一年以前** → 🟢 内容老化，可以用新信息切入
- 混杂但有明显"考古"高赞 → 🟢 该选题有长尾生命力

## 信号 3：头部笔记的互动结构

| 赞 / 藏 比例 | 含义 |
|---|---|
| 收藏 ≈ 点赞（0.8–1.2） | 工具型内容，长期有效 → 值得做，但要给新东西 |
| 收藏 >> 点赞（>1.5） | 强工具属性，用户觉得"以后要用" |
| 点赞 >> 收藏（>3） | 情绪型，看完就走 → 难沉淀 |

## 信号 4：内容同质化程度

翻 5 篇头部笔记，看它们的**目录结构**是否雷同：

- 5 篇都是「先讲原理→再列产品→最后推荐」 → 🟠 高度同质，需要差异化结构
- 每篇切入角度都不同 → 🟢 该选题还有空间
- 有 3 篇以上用了同一张对比表/同一套话术 → 🟠 说明已经形成"标准答案"，新人难超越

## 信号 5：评论区的问题密度

看高赞笔记的评论区：

- 大量「求链接」「多少钱」 → 需求真实，转化好 → 🟢 值得做
- 大量「我用了不好用」「XX 更好」 → 有争议，说明没有公认答案 → 🟢 差异化机会
- 评论区几乎没人提问 → ⚠️ 要么内容已经闭环，要么是刷的

## 信号 6：商业投放密度

搜索结果里带「赞助」「广告」标记的比例：

- 超过 30% → 🟠 商业化严重，自然流量被挤压
- 低于 10% → 🟢 自然流量空间大
- 完全没有 → 🟡 可能是需求太小，要确认是不是伪需求

## 综合评分表

给每个信号打 1-3 分（3 = 最有利），总分：

| 总分 | 竞争度判定 | 行动建议 |
|---|---|---|
| 15–18 | 🟢 低竞争 | 直接做，优先排期 |
| 11–14 | 🟡 中等 | 做，但必须有差异化角度 |
| 7–10 | 🟠 高竞争 | 只在有独特资源/数据时做 |
| ≤6 | 🔴 极高 | 放弃，或换更细的切分 |

## 使用纪律

1. **不许凭印象判断**——必须说明用了哪几个信号、观察到什么
2. **数据来源要说清**——是搜索结果、下拉词、还是评论区抽样
3. **无法观察时明确说明**：「当前无法直接观察平台数据，以下是基于品类常识的推演，建议你实际搜索验证」

## 常见误判

- **把「没人做」当成蓝海** → 可能是伪需求
- **把「很多人在做」当成红海** → 可能是需求旺盛但供给不足
- **只看点赞数** → 点赞高不代表转化高，要看收藏和评论提问
- **忽略内容时效** → 去年的爆款方法今年可能已失效
