# 选题四象限模型

## 模型说明

小红书的内容分发有两条独立通道：**搜索**（用户主动找）和 **推荐**（系统推给可能感兴趣的人）。
两条通道对选题的要求完全不同——这是判断选题质量的第一性原理。

| | 搜索意图强 | 搜索意图弱 |
|---|---|---|
| **竞争度低** | 🟢 **黄金区**：必做，先占位 | 🟡 机会区：适合起号期试水 |
| **竞争度高** | 🟠 血战区：要有差异化角度 | 🔴 高风险区：易爆但难沉淀 |

**起号期（前 20 篇）** 建议配比：黄金区 50%、机会区 30%、血战区 15%、高风险区 5%。

## 四类选题土壤

### 1. 痛点型（搜索意图强，竞争中等）

用户已经知道自己有问题，正在搜解决方案。

**特征**：标题里天然带「怎么」「为什么」「是不是」「能不能」
**优势**：搜索流量稳定，评论区容易形成真实互动
**风险**：容易写成说明书，缺人味

**示例（家装）**：
- 「小户型厨房，油烟机到底选侧吸还是顶吸」
- 「装修完才发现：这 5 个插座位置必须提前留」
- 「为什么你家厨房总有一股味」

### 2. 决策型（搜索意图强，竞争高）

用户在两个选项之间犹豫，需要有人帮他做决定。

**特征**：A vs B、价位段对比、品牌横评
**优势**：转化率最高，容易涨精准粉
**风险**：红海严重，必须给出**别人没测过**的维度

**示例（咖啡机）**：
- 「2000 和 5000 的半自动咖啡机，差的是这 3 个零件」
- 「同价位 4 台磨豆机横评：只有 1 台值得买」
- 「别买意式机：除非你能接受这 2 个代价」

### 3. 场景型（搜索意图中，竞争低）

把一个具体生活场景讲透，用户因为「这就是我」而点开。

**特征**：时间 + 地点 + 身份 + 具体事件
**优势**：推荐流量好，容易做出记忆点
**风险**：泛场景（「周末在家」）等于没场景

**示例（露营）**：
- 「带 3 岁娃露营，我最后悔带的三样东西」
- 「下雨天在车里煮咖啡，我用这套装备」
- 「周五下班直接出发，2 小时车程内的营地清单」

### 4. 情绪型（搜索意图弱，竞争不确定）

讲立场、讲态度、讲反差，靠情绪驱动传播。

**特征**：有明确观点，甚至有点冒犯
**优势**：爆发力最强，容易出爆款
**风险**：不可控，容易引战，且难沉淀精准粉

**示例（职场）**：
- 「我拒绝了年薪多 20 万的 offer，因为我算过一笔账」
- 「劝你别在 30 岁前做管理」
- 「工作五年，我删掉了所有工作群」

## 使用方法

1. 拿到赛道后，先在表里找到对应行（找不到就用最近似的，说明推演依据）
2. 按四类土壤各生成 5 条
3. 用 `competition-signals.md` 给每条打竞争度
4. 按「黄金区优先」排序输出

## 常见错误

- **只做痛点型**：内容像说明书，账号没有性格
- **全做情绪型**：可能出爆款，但粉丝不精准，变现难
- **决策型不给新维度**：同质化测评没人看
- **场景写得太宽泛**：读者感受不到「这就是我」
