# 开头钩子类型（8 类）

## 为什么开头决定一切

小红书信息流的滑动成本极低。**正文前 20 个字**决定了：
- 是否继续读（完读率）
- 是否互动（评论/收藏率）

完读率低 → 系统停止分发。所以开头不是「引出主题」，而是**制造继续读的理由**。

## 八类钩子

### H1 反常识（最强，也最容易翻车）

先抛一个违反直觉的判断，再用正文解释。

```
「你家越干净，越容易过敏。」
「健身房里练得最狠的，往往是进步最慢的。」
```

**适用**：有真实依据的反差结论
**风险**：无依据的标题党会被评论区反噬
**搭配选题**：情绪型、痛点型

### H2 具体代价

用一个具体的钱/时间/健康损失开场。

```
「这个插座装错，我多花了 2800 块返工。」
「买了三个猫砂盆，才明白 60 块的错在哪。」
```

**适用**：避坑类、决策类
**要点**：数字必须具体，模糊的「花了不少钱」无效

### H3 身份自曝

先交代「我是谁」，建立可信度。

```
「做了 8 年室内设计，我自己家只做了 3 个柜子。」
「娃两岁半，这是我换的第 6 个奶瓶。」
```

**适用**：需要专业背书的领域
**要点**：身份要具体到年和领域，不要「一个宝妈」

### H4 时间锚点

用时间跨度建立「我试过了」的信任。

```
「用了 3 个月，说 2 个没人提的缺点。」
「入住一年，这 4 个决定我还想做第二次。」
```

**适用**：长期使用的产品、装修、习惯养成
**要点**：时间要够长（至少 1 个月），短测没说服力

### H5 场景代入

把一个高度具体的场景摊开，让读者「对号入座」。

```
「周五晚上 11 点，我在改第 7 版方案，电脑突然蓝屏。」
「出租房厨房只有 2 平米，我把洗衣机塞进了阳台。」
```

**适用**：场景型选题
**要点**：时间+地点+动作都要具体

### H6 数据冲击

用一个极端数字制造注意力。

```
「测了 23 款，只有 2 款值得买。」
「一年省下 1.2 万，方法就在这 3 行字。」
```

**适用**：横评、方法论
**要点**：数字要真实可核对，夸大会被扒

### H7 排除法

先缩小范围，制造「剩下的都是精华」的预期。

```
「排除掉 10 个网红款，我只留下了这个。」
「试遍了 5 种方法，只有这个坚持下来了。」
```

**适用**：清单型内容
**要点**：要说清排除理由，否则显得武断

### H8 提问直击

用读者心里正在想的问题开场。

```
「为什么你敷面膜越敷越干？」
「同样是 3000 块的手机，为什么拍照差这么多？」
```

**适用**：痛点型、科普型
**要点**：问题必须是用户真的在搜的原话，不是自己想出来的

## 钩子选择决策表

| 选题类型 | 首选钩子 | 备选 |
|---|---|---|
| 避坑/痛点 | H2 具体代价 | H8 提问直击 |
| 决策/横评 | H7 排除法 | H6 数据冲击 |
| 教程/方法 | H4 时间锚点 | H3 身份自曝 |
| 场景故事 | H5 场景代入 | H4 时间锚点 |
| 观点/情绪 | H1 反常识 | H3 身份自曝 |

## 反模式（禁止）

- **自我铺垫**：「最近很多姐妹问我…」——浪费开头黄金位
- **无信息过渡**：「今天想跟大家聊聊…」——零钩子
- **标题重复**：开头把标题再念一遍，等于浪费 20 字
- **过度承诺**：「看完这篇你就懂了」——读者反而不信

## 自检

- [ ] 前 20 字有具体信息（数字/时间/身份/场景）
- [ ] 没有「最近」「今天」「想跟大家」这类铺垫
- [ ] 钩子类型与选题匹配
- [ ] 钩子承诺的，正文确实回答了
