## Description:

Helps QA teams estimate test effort from requirement complexity, change scope, historical baselines, and risk factors, producing phased estimates for smoke, functional, regression, and specialized testing.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kokxi](https://clawhub.ai/user/kokxi)

### License/Terms of Use:

MIT-0

## Use Case:

QA engineers, test leads, and project managers use this skill to estimate testing person-hours or person-days for release planning. It structures estimates by method, work breakdown, adjustment factors, confidence, and risk buffer.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: General project-planning requests may invoke the skill even when the user only intended a scheduling discussion.

Mitigation: Confirm that a test-effort estimate is desired before using its output to alter release plans or staffing allocations.

Risk: Testing estimates can materially affect release planning and resource commitments.

Mitigation: Review generated estimates with the project manager or test lead before changing a real release plan or schedule.
