## Known Risks and Mitigations: <br>
Risk: Installing or running unfamiliar test tooling can execute project dependencies or scripts. <br>
Mitigation: Install only the dependencies needed for the target test stack, prefer pinned versions or lockfiles, and run unfamiliar projects in a container or throwaway environment. <br>
Risk: The Bash eval helper can become unsafe if adapted to run user-controlled strings. <br>
Mitigation: Use fixed trusted commands for shell assertions, or avoid eval when command strings can come from untrusted input. <br>
