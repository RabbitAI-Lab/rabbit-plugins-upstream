## Description: <br>
A methodology skill for designing full-color pixel narrative RPGs in single-file HTML5, covering palette ramps, tile scenes, dialogue and emotion systems, collectible memories, full-color CGs, rhythm minigames, and dynamic BGM. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External developers and game designers use this skill to plan and implement full-color pixel narrative RPG chapters with disciplined palettes, tile maps, dialogue, memories, lightweight minigames, procedural audio, and publishing checks. <br>

## Known Risks and Mitigations: <br>
Risk: The artifact references a detailed SOP file that is not present, so some promised command and code templates may be unavailable. <br>
Mitigation: Review generated steps against the available SKILL.md content and request or supply missing templates before relying on SOP-specific instructions. <br>
Risk: The skill may generate substantial trilingual game text, which can create localization and text-overflow issues in a compact pixel RPG interface. <br>
Mitigation: Review Chinese, English, and Japanese text in-game and run screenshot checks for dialog width, layout overflow, and readability. <br>
