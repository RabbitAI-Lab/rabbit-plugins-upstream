## Description:

Publish a site, page, report, dashboard, slide deck, document, portfolio or small web app at a ShipStatic link anyone can open, with no account needed and optional built-in password protection. Use when the user asks to publish something, deploy or host a static site or a build folder, put it online, or get a link others can open. Not for HTML the user only wants to see, download or keep as a file.

This skill is ready for commercial/non-commercial use.

## Use Case:

Site creators and developers use this skill to publish browser-ready sites and other web content at a shareable ShipStatic link, optionally protected by a password.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Files in the selected folder may become publicly accessible after publishing.

Mitigation: Review the entire folder before publishing and remove anything that should not be shared; request password protection when appropriate.

Risk: The user's existing ShipStatic setup may publish into an account, and replaced site versions may remain accessible until expiration or deletion.

Mitigation: Review the deployment result and account destination; treat earlier published versions as accessible until they expire or are deleted.
