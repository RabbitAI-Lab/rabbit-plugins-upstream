## Description:

Publish a site, page, report, dashboard, slide deck, document, portfolio or small web app at a ShipStatic link anyone can open, with no account needed and optional built-in password protection. Use when the user asks to publish something, deploy or host a static site or a build folder, put it online, or get a link others can open. Not for HTML the user only wants to see, download or keep as a file.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users can use an agent to prepare and publish browser-based sites, pages, reports, dashboards, documents, portfolios, or small web apps and receive a shareable ShipStatic link.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The publishing guidance was flagged as a possible concern because it may publish without a separate confirmation step.

Mitigation: Confirm the user has asked for publication and review the files before publishing.
