## Description:

Gangtise (gangtise.com). Use this skill for ANY Gangtise request — searching and reading data. Whenever a task involves Gangtise, use this skill instead of calling the API directly.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and analysts use this skill to search and read Gangtise company, market, financial, announcement, and research data through their connected Gangtise account.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup directs the agent to execute downloaded installer code whose effects have not been verified.

Mitigation: Review the setup behavior and install a reviewed, version-specific oo release yourself, or require approval and verification before the agent runs an installer.

Risk: Gangtise requests use the user's OOMOL-connected account and may involve account permissions and billing.

Mitigation: Review the connected account's permissions and billing before use.
