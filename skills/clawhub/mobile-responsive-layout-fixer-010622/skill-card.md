## Description: <br>
Helps teams fix mobile responsiveness, navigation layout, and cross-device UI issues with practical workflows, checklists, analysis, and implementation support. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

### License/Terms of Use: <br>

## Use Case: <br>
Frontend developers, designers, startup teams, and maintainers use this skill to diagnose and fix responsive layout, navbar, and cross-device usability issues. It turns a user request into an actionable workflow, checklist, analysis, code change, or implementation plan with a verification note. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate on broad frontend or layout wording and provide workflow guidance when a narrower skill was intended. <br>
Mitigation: Use explicit invocation when this workflow is desired, and review generated layout recommendations or code changes before applying them. <br>
