## 叙事任务清单与依赖拓扑

叙事建造器按叙事构建管线组织的方法论执行任务清单，附任务间关系和元操作映射提示。

**域间逻辑流**：N0(nb-03) → N1（并行导入）→ N2 → N3 → N4 → N5

**管线总览**：
```
nb-03 输入模式检测
  ├── Mode A：nb-00 → nb-01 → nb-02 → N1(内联生成) → N2 → N3 → N4 → N5
  └── Mode B：nb-00 → nb-01 → nb-02 → N1(世界+角色并行导入) → N2 → N3 → N4 → N5
```

---

### N0 叙事需求解析域

叙事构建的入口域，检测输入模式并路由到对应管线。

**域内流**：nb-03（入口）→ 模式判定 →
- **Mode A**（直接叙事构建）：nb-00 → nb-01 → nb-02 → N1（内联角色/世界生成）
- **Mode B**（角色驱动编排）：nb-00 → nb-01 → nb-02 → N1(nb-10, nb-11)
- **Mode C**（混合）：以Mode B为主管线，故事描述作为约束

| ID | 任务类型 | 说明 | 依赖 | 元操作映射 |
|----|---------|------|------|-----------|
| nb-03 | 输入模式检测 | 检测输入类型（Mode A纯故事描述/Mode B角色文件引用/Mode C混合），判定叙事构建模式，路由到对应管线 | 无（入口） | S→C |
| nb-00 | 叙事需求解析 | 解析用户输入的叙事需求：目标叙事类型（短篇/长篇/系列/剧本/游戏）、叙事风格、目标读者、主题方向、World Builder/Character Builder输出可用性评估 | nb-03 | S→C |
| nb-01 | 编排策略确定 | 基于需求解析结果确定编排策略：叙事结构候选集、视角策略、节奏偏好、World Builder/Character Builder依赖策略（完全依赖/部分依赖/完全降级） | nb-00 | C |
| nb-02 | 执行顺序确定 | 确定6域的执行顺序和并行/串行策略，识别域间的关键依赖路径，标注降级节点 | nb-01 | C→A |

---

### N1 输入整合域

消费World Builder和Character Builder输出，将外部设定转化为叙事可用输入。

| ID | 任务类型 | 说明 | 依赖 | 元操作映射 |
|----|---------|------|------|-----------|
| nb-10 | 世界导入与整合 | 消费World Builder输出，提取叙事关联的世界元素：世界观规则、地理环境、历史背景、社会结构、技术水平、魔法/科技体系、当前局势。验证导入完整性和可用性，标注缺失项。如World Builder不可用，按降级模式处理 | nb-02 | S→C |
| nb-11 | 角色导入与整合 | 消费Character Builder输出，提取叙事关联的角色元素：角色动机、能力、关系网络、文化背景、动态特征。验证导入完整性和可用性，标注缺失项。如Character Builder不可用，按降级模式处理 | nb-02 | S→C |

### N2 结构设计域

叙事框架设计——为故事搭建骨架。

| ID | 任务类型 | 说明 | 依赖 | 元操作映射 |
|----|---------|------|------|-----------|
| nb-20 | 情节结构设计 | 选择并适配叙事结构框架：三幕式（铺垫→对抗→解决）、英雄之旅（12步）、弗赖塔革金字塔（5步）、非线性结构（环形/碎片/多线）、模块化结构（单元剧）。基于世界设定和角色设定确定结构参数：幕长比例、转折点位置、高潮节点 | nb-10, nb-11 | C→A |
| nb-21 | 视角选择 | 确定叙事视角策略：第一人称（有限/可靠/不可靠）、第二人称（直接/隐含）、第三人称（有限/全知/客观）。基于角色设定确定视角角色的选择依据，定义视角切换规则（如多POV叙事） | nb-10, nb-11 | C→A |
| nb-22 | 节奏与冲突设计 | 设计叙事张力曲线和冲突层次：外部冲突（角色vs角色/社会/自然/技术）、内部冲突（角色vs自我）、哲学冲突（价值观对立）。设计节奏型（渐强/波动/爆发性）、平静段分布、余音处理 | nb-20 | C→A |
| nb-23 | 结构校验 | 验证结构层内部一致性：结构框架与故事类型匹配度、视角选择与角色设定一致、节奏设计与结构框架兼容。标注不一致项并给出修正建议 | nb-20, nb-21, nb-22 | G |

### N3 编排执行域

叙事内容的核心编排——将结构骨架填充为血肉。

| ID | 任务类型 | 说明 | 依赖 | 元操作映射 |
|----|---------|------|------|-----------|
| nb-30 | 事件编排 | 构建因果事件链：基于情节结构生成事件序列、定义事件间的因果逻辑（因为A所以B，B导致C）、标注关键转折事件（激励事件、中点转折、危机、高潮）。每个事件标注：参与者（角色）、触发条件、事件类型（行动/决策/意外/揭示）、节奏位置（加速/减速） | nb-20, nb-22 | C→A→O |
| nb-31 | 场景构建 | 将事件链落地为具体场景：每个场景包含场景要素（时间/地点/氛围）、参与角色及入场/退场、核心动作/对话/内心活动、场景功能（推进情节/揭示角色/建立氛围/传递主题）。场景间衔接设计（硬切/淡入淡出/平行剪辑） | nb-30 | A→O |
| nb-32 | 主题编织 | 将主题线索贯穿于情节和场景中：确定核心主题（1-3个），为每个事件和场景标注主题关联度，设计主题的递进层次（暗示→暗示加强→明确呈现→反转/深化→收束），确保主题"展示而不说教" | nb-20, nb-30 | C→A |
| nb-33 | 对白与叙述设计 | 确定叙事声音和风格：叙述者的声音特征（正式/口语/诗意/冷峻/温暖）、叙述节奏（句子长短、段落呼吸）、对白风格（基于角色逐一设计说话方式、语域、习惯用语）、描写与叙述的比例、内心独白策略 | nb-11, nb-21 | A→O |
| nb-34 | 编排校验 | 验证编排层内部一致性：事件因果链无断链或逻辑跳跃、场景功能未冗余（无"无用场景"）、主题线索在场景中确实有映射、角色对白与其设定一致、视角规则在场景中被遵守 | nb-30, nb-31, nb-32, nb-33 | G |

### N4 校验域

| ID | 任务类型 | 说明 | 依赖 | 元操作映射 |
|----|---------|------|------|-----------|
| nb-40 | 叙事一致性检查 | 全篇一致性验证：世界规则一致性（各场景是否遵守世界设定）、角色行为一致性（角色在不同场景的行为是否保持其性格）、情节一致性（是否有自相矛盾的事件）、时间线一致性（时间流逝是否合理） | nb-34 | G |
| nb-41 | 节奏验证 | 全篇节奏验证：张力曲线是否符合设计、高潮位置和力度是否合理、平静段的长度是否恰当、信息释放节奏是否自然（不堆砌不拖沓） | nb-34 | G |
| nb-42 | 主题一致性检查 | 全篇主题一致性验证：主题贯穿是否完整（不中断不消失）、主题深化是否自然（不跳跃不说教）、主题与情节是否有机融合（不贴标签）、多主题之间是否协调（不冲突不混乱） | nb-34 | G |

## 依赖拓扑摘要

**N0 需求解析链路**：nb-03 → nb-00 → nb-01 → nb-02

**N1 输入整合链路**：nb-10, nb-11（并行，均依赖nb-02）

**N2 结构设计链路**：nb-10, nb-11 → nb-20 → nb-21 → nb-22 → nb-23

**N3 编排执行链路**：nb-20, nb-22 → nb-30 → nb-31, nb-32, nb-33（nb-31依赖nb-30，nb-32和nb-33可与nb-31部分并行）→ nb-34

**N4 校验链路**：nb-34 → nb-40, nb-41, nb-42（三任务可并行）

**N5 输出链路**：nb-40, nb-41, nb-42 → nb-50 → nb-51 → nb-52

**完整处理链路**：
```
nb-03 → nb-00 → nb-01 → nb-02 → [nb-10, nb-11] → nb-20 → nb-21 → nb-22 → nb-23 
→ nb-30 → [nb-31, nb-32, nb-33] → nb-34 → [nb-40, nb-41, nb-42] 
→ nb-50 → nb-51 → nb-52
```

**并行节点**：
- N1层：nb-10和nb-11可并行（世界和角色独立导入）
- N4层：nb-40、nb-41、nb-42可并行（三种校验互不依赖）
- N3层：nb-32和nb-33可在nb-30完成后与nb-31并行

更多组合根据具体任务动态推导。
