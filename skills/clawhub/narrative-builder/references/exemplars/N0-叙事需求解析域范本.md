## N0域范本：P06集体身份——"我们"叙事的需求解析

- **类型**: 角色驱动编排 (Mode B)
- **对应域**: N0 叙事需求解析域
- **来源**: Character Library P06集体身份型：青岚 · 陆明远 · 沈霜月
- **日期**: 2026-07-13

### 输入
用户输入：引用P06三角色Skill（青岚·陆明远·沈霜月），要求"以青岚（集体意识）的第一人称复数视角，编排陆明远决定离开青岚宗时引发的意识分裂叙事。"

### 输出

#### nb-03 输入模式检测
角色引用: 3（P06青岚/陆明远/沈霜月）≥ 2 → **Mode B**。无世界Skill → 从角色数据提取。

#### nb-00 叙事需求解析
**目标叙事类型**: 内在冲突叙事——不是人与人的对抗，而是"一个意识如何面对自己的一部分要离开自己"。
**叙事风格**: 第一人称复数"我们"视角——这是P06的核心叙事创新。叙述者=青岚——同时是300个弟子的集合意识。
**核心叙事命题**: 当陆明远说"我要离开"时——青岚无法说"我"或"你"——因为这句话的每一部分都在撕裂它的语法结构：谁在说？对谁说？离开是什么意思——当一个身体的部分说"我要离开"那个身体？
**主题方向**: 集体中的个人自由、分离作为存在的创伤、"我们"如何面对"你"

#### nb-01 编排策略确定
**叙事结构**: 非传统弗赖塔革——采用"旋涡式"结构：从青岚正常的300声合唱开始→一个声音开始不和谐（陆明远的离开念头）→不和谐扩散→高潮=陆明远正式说"我要离开"的瞬间（这一瞬间青岚经历了三百年来第一次"分裂"——不是愤怒，是"一部分的我想要一部分的我离开"）→下降=青岚独自面对陆明远离开后的"空洞"（一个意识节点消失了）→结局=沈霜月的坚守让青岚重新定义自己——"我们"可以少一个，但"我们"还是"我们"。

**视角策略**: 第一人称复数"我们"——全篇不使用"我"指代青岚（除了在最高潮处引用青岚P06维5的核心焦虑："我这个词像一只不合脚的鞋"）。在陆明远正式离开的瞬间，叙事短暂切换为陆明远的第三人称——让读者看到"从外面看到青岚"的样子。

**依赖策略**: 完全依赖P06三个角色——青岚(维11动机=生存+关系、维7关系=陆明远是"最闪亮的突触"、维12动态=当前处于"危机阶段")。陆明远和沈霜月提供对峙视角。

#### nb-02 执行顺序
N0→N1(导入三角色+提取青岚宗世界观碎片)→N2(结构: 旋涡式+第一人称复数)→N3(事件: 不和谐→扩散→分裂→空洞→重新定义)→N4(校验: 第一人称复数的语法一致性)→N5(输出)

### 说明
- P06青岚的集体身份是叙事建造器的终极创新测试——它要求叙述者本身就是一个悖论："我们"是一个"它"——一个不能用单数思考却一直在用单数讲述自己的存在
- 选择P06而非P07的关键理由：P07衰退叙事仍可用传统叙事技术表达（第三人称有限视角），但P06的"我们"叙事要求叙事建造器处理全新的技术问题：如何在"一个叙述者"中容纳"300个声音"
