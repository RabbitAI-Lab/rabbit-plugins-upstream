## Description:

帮助电商运营人员基于已批准的商品实拍图生成符合商品事实与渠道规范的主图候选，并设计单变量 A/B 测试；图片本身不保证转化效果。

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

面向电商运营人员和商品团队，用已批准的商品实拍图制作白底基线图、场景图、配色 SKU 组和 A/B 候选，并在发布前核对商品事实与目标渠道规范。

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security review is incomplete because referenced files or paths were unavailable to the scanner.

Mitigation: Review any missing files and paths before installing the CLI.

Risk: The CLI uses an optional API key and sends prompts and uploaded product images to dLazy services.

Mitigation: Review the CLI before installation, use an authorized API key, and upload only approved product images cleared for external processing.
