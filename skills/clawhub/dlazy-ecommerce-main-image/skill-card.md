## Description:

Guides creation and editing of accurate ecommerce main-image candidates from approved product photos, including single-variable A/B variants.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Ecommerce sellers and creative teams use this skill to prepare product-image prompts and commands for white-background, comparison, lifestyle, color-SKU, and A/B-test main images. They review each result against the actual product and marketplace requirements before publishing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Selected product photos are uploaded to dLazy's cloud service.

Mitigation: Use only approved commercial images and confirm that cloud upload is permitted before running commands.

Risk: Generated images can misrepresent product details or violate marketplace image rules.

Mitigation: Compare outputs with the actual SKU and check current platform requirements before publishing.

Risk: CLI installation and API-key use require trusting a third-party service.

Mitigation: Confirm the pinned dLazy CLI package is trusted and rotate or revoke the API key when no longer needed.
