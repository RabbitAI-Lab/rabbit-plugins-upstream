## 产出：转链服务 HTTP API 文档（供直接集成调用）

- 依据 `src/client.js` + 实测请求，整理出两份交付物：
  - `API.md` — 面向人工阅读的完整接口文档（信封规约、7 个接口、错误码、计费、Node/Python 示例）
  - `openapi.yaml` — OpenAPI 3.0.3 规范，可直接导入 Postman/Apifox
- 实测结论（已写入文档，避免下次重复探测）：
  - Base `http://st.aidata366.com`，前缀 `/api/v1`
  - **所有响应 HTTP 状态码恒为 200**，业务成败只看 `code`；后端是 FastAPI（参数校验错误信息为 pydantic 风格）
  - `POST /auth/cli-session` 实测返回 `access_token/expires_in(600)/login_path/qr_path/register_path/register_qr_path`
  - `POST /auth/cli-session/check` pending 时仅返回 `{"status":"pending"}`；`access_token` 非法 → `1001` + pydantic 报错
  - 未带 token 请求任意鉴权接口 → `{"code":1002,"message":"未登录或 Token 无效/过期","data":null}`
- 待确认项已单列在 API.md 第 11 节：任务中间态确切取值、logout 的 data 结构、会话过期的 status 值、限流阈值。
