# 尺寸适配交付前自检清单

任何一项不通过，先修复再交付。

## A. 规格对齐（6 项）

- [ ] 每个目标平台有确切比例+分辨率
- [ ] 时长上限已核对（超时的先剪再适配）
- [ ] 文件大小限制已核对
- [ ] 广告位规格以投放后台为准并注明
- [ ] 编码为 MP4(H.264)+AAC 或平台指定格式
- [ ] 帧率与源一致

## B. 策略正确性（6 项）

- [ ] 无任何非等比拉伸
- [ ] crop 版本逐关键镜头确认主体不出画
- [ ] 竖转横未使用硬 crop（或已确认主体安全）
- [ ] pad 结构合理（模糊/品牌色/标题区）
- [ ] pad 底色符合品牌规范
- [ ] 策略选择理由已写明

## C. 主体与字幕（6 项）

- [ ] 人脸全程完整（抽查主体移动最大的镜头）
- [ ] 产品特写镜头单独检查过
- [ ] 字幕无缺行缺字
- [ ] 被切字幕的版本已标注"需重烧"
- [ ] 字幕字号在目标画幅内可读（手机实况预览）
- [ ] 关键文字信息不依赖被裁掉的区域

## D. 安全区（5 项）

- [ ] 9:16 版本关键内容避开底部 20%
- [ ] 9:16 版本关键内容避开右侧按钮列
- [ ] 顶部标题遮挡区已检查
- [ ] CTA/促销信息在中部安全区
- [ ] Stories/Reels 广告版检查了顶 14%/底 20%

## E. 交付完整性（5 项）

- [ ] 按 output-template.md 输出
- [ ] 每版本有策略+取舍+风险说明
- [ ] 风险镜头给了时间码
- [ ] 建议的额外复用版本已列出
- [ ] 遗留问题（重烧字幕/重构图/先剪辑）已列出

## 快速红线（任一命中即打回）

- 画面有拉伸变形
- 字幕被切一半没提示
- 只看首帧就定了 crop
- 没写每个版本用了什么策略
