## Description: <br>
Assesses an organization's AI security posture across 12 enterprise domains and returns maturity scores, control gaps, prioritized remediation guidance, and compliance alignment. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Security practitioners, developers, and enterprise AI teams use this skill to assess AI control maturity, identify gaps, and plan remediation across identity, data protection, prompt injection defense, API security, monitoring, compliance, incident response, and related domains. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may send sensitive security posture, control gaps, or internal architecture details to ToolWeb's external assessment service. <br>
Mitigation: Submit only information the user is authorized to share, use a dedicated ToolWeb API key, and review ToolWeb privacy and retention terms before sending detailed assessment inputs. <br>
Risk: The registry summary references an older OT/ICS assessment description while the current artifact describes an enterprise AI security controls assessment. <br>
Mitigation: Confirm the current SKILL.md behavior and intended AI security assessment scope before installation or use. <br>
