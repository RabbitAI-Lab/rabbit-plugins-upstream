## Description:

AI Excel spreadsheet generation powered by CellCog for financial models, budget templates, data trackers, projections, pivot tables, complex formulas, XLSX output, data manipulation, analysis, charts, and professional formatting.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill to ask an agent to create Excel workbooks and spreadsheet-based tools. It supports financial models, budgets, trackers, business templates, analysis sheets, formulas, charts, formatting, and interactive HTML outputs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Spreadsheet prompts may be sent to CellCog's external service, which can expose confidential, regulated, or secret data if users include it in prompts.

Mitigation: Use this skill only after approving CellCog as an external service and avoid sending secrets, regulated personal data, or confidential business data unless organizational review permits it.

Risk: Financial models, formulas, projections, and analysis spreadsheets can contain costly calculation or assumption errors.

Mitigation: Review formulas, assumptions, and generated workbook outputs before using them for business, financial, or operational decisions.
