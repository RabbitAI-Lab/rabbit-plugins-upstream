# Oxford (documentary-note) quick reference

## Footnote templates (first citation, full form)

| Type | Template |
|---|---|
| Book | `Author, Title of Book (Place: Publisher, Year), p. X.` |
| Chapter | `Author, 'Chapter Title', in Editor (ed.), Book Title (Place: Publisher, Year), pp. xx-xx.` |
| Journal | `Author, 'Article Title', Journal Name, Volume, no. X (Year), pp. xx-xx.` |
| Web page | `Author, 'Page Title', Site Name, Day Month Year, URL.` |
| Report | `Organisation, Report Title (Place: Publisher, Year), p. X.` |
| Newspaper | `Author, 'Article Title', Newspaper Name, Day Month Year, p. X.` |

## Subsequent notes (shortened)

| Situation | Template |
|---|---|
| Same author, cited before | `Surname, Short Title, p. X.` |
| Same source as the note immediately before | `Ibid., p. Y.` (same page: `Ibid.`) |
| Two authors | `A. Author and B. Author, ...` |
| 4+ authors | `A. Author et al., ...` |
| No author | start with the title |

## Bibliography

- Alphabetical by author surname; full first-citation form, no page numbers for whole works
- `Place: Publisher, Year` retained in bibliography entries
- Author name inverted in the bibliography (`Surname, Initial.`), but NOT in footnotes (natural order)
- Every footnote source appears in the bibliography

## Mechanics

- Superscript note numbers after punctuation, running in sequence, one number per note
- Quote page numbers live in the footnote, never in the running text
- Access dates for changeable web content: `accessed Day Month Year`
- Law: use OSCOLA, not Oxford general (`Smith v Jones [2024] UKSC 1 [15]`; statutes `Act Year`, s X)

## ibid. caution

`Ibid.` binds to the immediately preceding note. Any inserted note silently re-points every later `ibid.`. Prefer shortened notes where the draft will be edited.
