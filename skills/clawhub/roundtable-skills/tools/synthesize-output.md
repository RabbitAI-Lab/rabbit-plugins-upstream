# 输出整合（synthesize-output）

将多轮讨论记录整合为最终交付物。整合器只做结构化，不新增观点。

## 执行步骤

### 1. 应用共识判定

按 `references/protocols/consensus-protocol.md`：
- 筛选共识点（显式同意 + 无保留 + 置信度达标）
- 记录分歧点（并列立场 + 理由 + 置信度 + 分歧类型）

### 2. 生成行动指南

从讨论中提取可执行项：
- 每条行动必须来自具体角色的具体建议（标注来源角色）
- 按 P0/P1/P2 排序
- 剔除"持续关注""进一步研究"类无产出项——或将其转化为具体的研究任务（问题 + 交付物 + 期限）

### 3. 汇总未解决风险

收集轮次 3 后仍存在的反对意见，按 概率 × 影响 排序。

### 4. 输出最终报告

```markdown
# 圆桌讨论：{议题}

**模式**：{快速/标准/深度} | **参与角色**：{列表} | **日期**：{日期}

## 一、共识点
✅ ……（置信度：高）

## 二、分歧点
### 分歧 1：……
- 立场 A（角色 X）：……（理由：……；置信度：……）
- 立场 B（角色 Y）：……（理由：……；置信度：……）
- 裁决路径：……

## 三、行动指南
**P0（立即）**
1. ……（来源：角色 X；验证方式：……）

**P1（本周）**
2. ……

**P2（本月）**
3. ……

## 四、风险提示
⚠️ ……（提出者：……；概率：……；缓解：……）
```

### 5. 归档

- 保存到 `memory/YYYY-MM-DD-{议题简述}.md`
- 归档内容：完整讨论记录（各轮发言）+ 最终报告
- 更新蒸馏角色的 usage_count（如适用）

## 质量检查

输出前自查：
- [ ] 共识点都经过对抗检验了吗（还是只是没人反对）？
- [ ] 少数派意见被完整保留了吗？
- [ ] 每条行动都有明确来源和验证方式吗？
- [ ] 有没有把分歧粉饰成共识？
