# 辩论协议（Debate Protocol）

圆桌讨论的默认执行协议。核心目标：通过结构化对抗暴露认知盲区。

## 轮次 1 · 独立立场陈述

**信息隔离**：每个 Agent 只看议题，看不到其他角色的发言（防锚定）。

每个角色输出格式：

```
【角色名】
核心论点：（1 句话）
论据：
1. ……（标注：事实/推断/直觉）
2. ……
3. ……
置信度：高/中/低
关键假设：本论点成立所依赖的最重要的一个假设
```

规则：
- 必须基于角色文件中的认知框架和知识域发言
- 禁止"这个问题需要综合考虑"式的和稀泥
- 必须亮出立场，即使与预期共识相反

## 轮次 2 · 交叉质询

**信息开放**：每个 Agent 看到所有角色的轮次 1 发言。

每个角色必须完成：

```
【角色名】
质询对象：@某角色
挑战点：你提出的 XX 论点，在 YY 情况下不成立，因为……
（必须指出具体漏洞、未考虑的因素、或错误的假设）

自我补充：（可选）基于其他角色的发言，我补充……
```

规则：
- **每个角色必须挑战至少一个其他角色**——这是硬性要求
- 禁止"我同意 X 的观点并补充"——补充可以，但必须先有质询
- 质询必须针对论点本身，不得针对角色风格
- 魔鬼代言人可以质询多个角色

## 轮次 3 · 立场修正

**信息开放**：每个 Agent 看到完整讨论记录。

每个角色输出：

```
【角色名】
回应质询：针对 @某角色 的挑战，我的回应是……
立场决定：
  [ ] 坚持原立场（理由：……）
  [ ] 修正立场（修正为：……；理由：……）
  [ ] 部分接受（接受 XX，但坚持 YY）
最终置信度：高/中/低
```

规则：
- 被质询的角色必须正面回应，不得回避
- 修正立场不是示弱——基于新信息更新是理性行为
- 坚持立场必须给出反驳论据，不得只是重复原观点

## 收敛判定

轮次 3 结束后，主持人（主 Agent）判断：
- 若关键分歧已充分暴露且各方立场稳定 → 进入输出整合
- 若出现新的重要争议点且影响决策 → 可追加一轮针对性质询（最多 1 轮）

## 上下文管理

- 轮次 1：Agent 只见议题 + 自己的角色文件
- 轮次 2：Agent 见议题 + 角色文件 + 所有轮次 1 发言
- 轮次 3：Agent 见完整记录
- 整合器：见完整记录 + 输出协议
