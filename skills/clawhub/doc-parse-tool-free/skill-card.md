## Known Risks and Mitigations: <br>
Risk: The skill asks for command and file access for document processing. <br>
Mitigation: Review the skill before installing, run it only in a constrained workspace, and grant file or command access only for documents and commands you trust. <br>
Risk: External document sharing and callback URL behavior are under-explained. <br>
Mitigation: Use it only with documents you are comfortable processing through configured tools or services, avoid callback URLs unless the destination is trusted, and prefer local OCR paths for sensitive personal, legal, financial, or business documents. <br>
