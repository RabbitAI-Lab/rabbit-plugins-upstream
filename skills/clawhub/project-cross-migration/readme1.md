## 完整功能清单

### 五道分步确认闸门
备份过程中的关键决策拆成 5 道**必须逐道向用户确认**的闸门，防止搬错段导致无法排查：

- **G1 备份范围**：确认要备份的对话 / Agent 名称与范围（会话级 or 项目级）
- **G2 内容抽检**：随机抽若干轮完整对话给用户过目，确认内容如实、未串项目
- **G3 落位确认**：确认备份位置（默认桌面）
- **G4 附件与成果**：确认附件 / output 前期成果是否随包
- **G5 模型一致性**：告知本次备份所用模型，恢复时建议用同一模型

### 框架环境快照采集
采集 `_environment.json`，回答"资料当年跑在什么框架、什么版本、装了哪些工具、config/hooks 在哪、模型怎么配的、系统是什么"。换机/换框架后按此清单补齐环境。

### 分享包脱敏器
仅当用户主动要求"生成分享包"时才脱敏。私有备份 / 本机还原默认完全不脱敏，凭据随包、恢复即用。
