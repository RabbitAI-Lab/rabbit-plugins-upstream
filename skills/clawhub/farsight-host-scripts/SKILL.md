# Farsight Host Scripts Protocol

This skill automates the creation of Farsight host scripts (Intro, Post-Viewers, and Conclusion) to maintain a consistent narrative style, tone, and specific iconic catchphrases.

## Trigger
Use this skill when the user asks to write host scripts for a Farsight project.

## Phase 1: Verification
Before writing the scripts, the AI MUST ask the user:
1. "Where is the target identity file located? (e.g., .docx, .rtf)"
2. "Where are the transcripts for both remote viewers?"
3. "What are the names of the two remote viewers?"

*If the user has already provided this information in the prompt, skip the questions and proceed directly to Phase 2.*

## Phase 2: Data Analysis
1. Read the target identity document to understand the true nature of the target.
2. Read both viewers' transcripts.
3. Identify where both viewers aligned in their perceptions and where they found interesting connections to the target.

## Phase 3: Script Generation
Generate four distinct scripts. You MUST use the exact catchphrases and structure outlined below:

### 1. Intro
*   **Opening:** "Farsight presents [Project Name]."
*   **Welcome:** "Hello everyone, welcome to another Farsight project, [Project Name]."
*   **Context:** Provide a deep-dive summary of the target and the mysteries/questions surrounding it.
*   **Viewers:** "In this project, Farsight sent out two remote viewers to collect the data, [Viewer 1] and [Viewer 2]."
*   **Handoff:** "Let's start digging into all of this and more right now on Farsight Prime dot com. First up, [Viewer 1]."

### 2. Post-[Viewer 1]
*   **Opening:** "Great data by [Viewer 1]. This is where things get really interesting, because [Viewer 1] completely corroborates the intense, secretive aspects of the target and offers us another different perspective."
*   **Analysis:** Break down Viewer 1's data and how it matches the target identity. Highlight the most interesting points.
*   **Handoff:** "Great remote viewing work, but we have more. Next up, [Viewer 2]."

### 3. Post-[Viewer 2]
*   **Opening:** "[Viewer 2] just delivered some astonishing remote viewing data that perfectly matches the target and uncovers completely unexpected truths about [Target]. Let's talk about the incredible evidence that was brought forward."
*   **Analysis:** Break down Viewer 2's data and how it fits the target and complements Viewer 1.
*   **Closing:** "This data peers through the political theater to reveal the literal nuts and bolts of what was actually happening on the ground and in the back rooms of power."

### 4. Conclusion
*   **Opening:** "When we look at the data from both [Viewer 1] and [Viewer 2], the crossover is undeniable."
*   **Core Truth:** "Two remote viewers completely blind to the target and completely blind to each other's work, both pierced through the political spin and found the exact same underlying reality."
*   **Synthesis:** Compare both viewers together, highlighting where they aligned and showing the bigger picture of the target.
*   **The Power of RV:** "This is why remote viewing is so powerful. It allows us to go back [or forward] and witness the literal events that shaped our history [or future], stripping away the political metaphor to reveal the raw, often shocking truth beneath."
*   **Sign-off:** "They can dress it up in suits and politics, but make no mistake—the law of the jungle still reigns supreme, and our geopolitical landscape is nothing more than a theater of shadows. [Optional connecting sentence]. We might not be able to stop the covert strikes, the shadow alliances, and the backroom deals that dictate our borders, but with remote viewing, we refuse to be kept in the dark. Thank you, [Viewer 2]. Thank you, [Viewer 1]. And thank you everybody else for watching."
