## Description:

Automates the creation of Farsight host scripts (Intro, Post-Viewers, Conclusion) using a consistent narrative style and specific iconic catchphrases.

This skill is ready for commercial/non-commercial use.

## Publisher:

[azizbrownint](https://clawhub.ai/user/azizbrownint)

### License/Terms of Use:

MIT-0

## Use Case:

External users preparing Farsight projects use this skill to turn a target identity file and two remote viewer transcripts into a structured set of host scripts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill reads user-provided target identity and transcript files to generate scripts.

Mitigation: Provide only files that are appropriate to use for the script-writing task.

Risk: Generated scripts may overstate or misrepresent source material if the provided documents are incomplete or ambiguous.

Mitigation: Review the final scripts against the target identity and both transcripts before publication.
