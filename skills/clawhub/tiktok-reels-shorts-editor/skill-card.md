## Description:

Reframe horizontal 16:9 footage into 9:16 vertical short-form videos with subject tracking and captions.

This skill is ready for commercial/non-commercial use.

## Use Case:

Creators, editors, and social media teams use this skill to turn horizontal footage into short-form vertical videos for TikTok, Reels, and Shorts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Media supplied by URL is processed through the external Levea service.

Mitigation: Submit only media you are comfortable making accessible by URL and processing through Levea.

Risk: The editing plugin or MCP server requires an API key.

Mitigation: Protect the API key in the tool configuration and review the separate plugin or MCP server before installation.

Risk: Edits can proceed from a generated plan.

Mitigation: Enable requirePlanApproval and review the plan before approving edits when you want approval first.
