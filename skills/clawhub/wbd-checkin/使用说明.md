# WorkBuddy 手机端签到积分 · 使用说明

> 适用版本：v3.3.1（手机端无需电脑）

## 先看这里

**手机就能完成，不需要电脑。** 手机端走「绑定本人号码 → 收验证码 → 换取凭据」，整个过程在你的手机上结束，不需要开发者工具，也不需要先把凭据从电脑搬过来。

| 你的情况 | 怎么做 |
|---|---|
| 主要在**手机**上用 | 按「手机三步」走一遍，之后每天说「签到」即可 |
| 主要在**电脑**上用 | 走「电脑取凭据」那条路，一次粘贴，同样能长期跑 |
| 两边都用 | 各录一次，签到是幂等的，哪边先签另一边会自动跳过 |

## 手机三步（推荐）

在手机的 WorkBuddy 里对助手说「绑定手机号 13xxxxxxxxx」，或直接执行：

```bash
cd 本技能目录
python3 scripts/self_login.py --bind 13xxxxxxxxx   # ① 绑一次，之后不用再输号码
python3 scripts/self_login.py --send               # ② 平台把验证码发到你手机
python3 scripts/self_login.py --code 123456        # ③ 回填验证码，换取凭据
```

第三条成功后，凭据已写入本技能目录的 `config.json`，接着就能签：

```bash
python3 scripts/checkin.py
```

**有几条限制，是刻意做的：**

- 号码只能来自 `--bind`，脚本没有「随便给个号码」的入参
- 两次发送间隔至少 120 秒，每天最多 3 次
- 换号码要先 `--unbind`，不能悄悄换

日常签到不需要再碰上面三条，只说「签到」就行。

## 电脑取凭据（备选）

如果手机端不方便，可以在电脑上取一次，再把那串内容录进来。

### 第 1 步：拿到自己的登录凭据

1. 用浏览器打开 WorkBuddy 网页端，正常登录
2. 按 `F12` 打开开发者工具，切到 **Network（网络）** 面板
3. 随便点一个页面操作，找到任意一个发往 `copilot.tencent.com` 的请求
4. 在 **Headers** 里找到 `Authorization`，复制 `Bearer ` 后面那一长串（不含 `Bearer ` 本身）

> 这串东西就是你本人账号的通行证，等同于登录状态。**不要发给任何人**，包括贴到群里、提交到代码仓库。

### 第 2 步：录入

```bash
python3 scripts/setup.py --token '你复制的那串'
```

或者不带参数运行 `python3 scripts/setup.py`，它会提示你粘贴，回车即录入。

**粘贴不用清洗。** 下面这些都能自动识别，不用手动删前缀：

- `Bearer eyJhbGci...`
- `Authorization: Bearer eyJhbGci...`
- 带引号、带首尾空格、末尾带分号
- 连同一整条 `curl -H '...'` 命令一起复制
- 一整段 JSON 片段

看到 `[已写入] .../config.json（权限 0600）` 就成了。

### 第 2.5 步：让它长期不用管（强烈建议）

只录上面那一串，**约 28 天后会失效**，你得重取一次。如果那时忘了，连续记录就断了。

多录一个「续期凭据」，之后每次运行都会自动延长有效期，只要不连续一个月不签，就再也不需要手动重来。

**怎么取：** 还在网络面板里，找一条发往 `.../auth/token/refresh` 的请求（在页面上停留一会儿、或切个页面就会出现），看它的请求头，复制 `X-Refresh-Token` 那一行的值。

**怎么录：**

```bash
python3 scripts/setup.py --token '访问凭据' --renew-key '续期凭据'
```

录完 `python3 scripts/setup.py --check` 会显示 `[续期] 已录入`。

### 第 3 步：验证

```bash
python3 scripts/checkin.py --dry-run
```

这一步只查状态、不领取。返回「今日未签到」或「今日已签到」都说明凭据可用。

### 第 4 步：签到

```bash
python3 scripts/checkin.py
```

成功会输出类似：

```
✅ 签到成功，本次 +20，连续 6 天，累计 320
```

## 想每天自动跑

技能本身不注册任何后台任务。要它每天自己跑，用你自己系统里的计划任务即可：

**macOS / Linux**

打开系统自带的计划任务工具，添加一条每天执行的任务，执行内容填：

```
cd /你的/技能目录 && /usr/bin/python3 scripts/checkin.py
```

执行时间按你自己的作息设置，建议放在每天固定上班之后。

**Windows**

打开「任务计划程序」，新建一个基本任务，触发器选「每天」，操作选「启动程序」，
程序填 `pythonw.exe`，参数填 `scripts\checkin.py`，「起始于」填技能目录。

注意：任务由你的系统负责调度，本技能不注册任何自启项，卸载技能后请自行删除这条任务。

## 常见问题

**问：这东西会不会偷偷读我的登录信息？**
答：不会。脚本只读它自己目录下的 `config.json`，不遍历目录、不碰浏览器数据、不碰客户端文件。你可以直接打开 `scripts/` 下每个文件逐行检查，全部 Python 源码不到 600 行。

**问：token 存哪儿？安全吗？**
答：存在本技能目录的 `config.json`，文件权限 600（只有你自己能读）。不想留了就跑 `python3 scripts/setup.py --purge`，文件立刻删除。

**问：token 会过期吗？**
答：会。录了续期凭据的话，每次运行都会自动延长一次，长期不用管；没录的话一般 28 天到期，届时签到会报「凭据已失效」，按第 2 步重新录一次即可。

**问：会不会重复领取、把账号搞异常？**
答：不会。脚本每次先查当天状态，已签到就直接返回，不重复请求领取接口。重复运行是安全的。

**问：能同时签多个号吗？**
答：不能，也不打算支持。技能只服务你自己的一个账号。

**问：会不会绕过什么验证？**
答：不会。凭据失效就停下，要求你重新提供，不尝试自动恢复、不模拟他人登录。手机端那一步是向平台请求一次验证码，验证码只发到你绑定的那个号码，还要你本人回填，脚本无法代你通过。

**问：换手机了或者重装了怎么办？**
答：重新走一次「手机三步」，绑定同一个号码即可。

**问：电脑和手机能同时用吗？**
答：能。同一个凭据在两边各存一份，互不影响，签到是幂等的，哪边先签另一边会自动跳过。

## 它主动不做的事

| 事项 | 说明 |
|---|---|
| 读本机登录态 | 不扫描、不读取、不解密任何客户端或浏览器数据 |
| 多份凭据 | 只保存你录入的那一组，不存历史副本、不做多组轮替 |
| 换地址重试 | 只请求官方地址，不做备用域名兜底 |
| 批量操作 | 只服务一个账号，无多账号逻辑 |
| 常驻后台 | 不注册自启、不留进程，只在被调用时跑一次 |
| 打印凭据 | 任何输出都不含凭据内容或片段 |
