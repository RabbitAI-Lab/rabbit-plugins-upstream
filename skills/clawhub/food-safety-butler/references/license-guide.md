# 食品经营许可证办理与后厨合规指南（模式 B 依据）

> 通用流程依据《食品经营许可和备案管理办法》（国家市场监管总局令第 78 号，2023 施行）。各地政务中心/市场监管局口径不一，以下为通用主线，办前务必咨询属地监管所。

## 一、办理全流程（四步）

```
核名 / 主体登记
   ↓
递交图纸 + 申请书（装修前先报图，避免返工）
   ↓
装修施工（严格按图纸 + 下方合规要点）
   ↓
现场核查（监管所上门，逐项打分）
   ↓
领证（制售范围、经营项目须与现场一致）
```

| 步骤 | 负责方 | 核心材料 | 周期提示 | 注意 |
|---|---|---|---|---|
| 1 核名/登记 | 经营者 | 营业执照（含餐饮经营范围）或预核名 | 1–3 个工作日 | 经营项目写清：热食/冷食/生食/饮品/糕点 |
| 2 报图 | 经营者+设计 | 平面布局图、设备设施图、流程图、申请书 | 提前交，避免装修返工 | 水池数量、专间、三防须在图上一目了然 |
| 3 装修 | 施工方 | 按图施工 | 2–6 周 | 地砖防滑、墙面贴砖到顶、排水坡向正确 |
| 4 现场核查 | 监管所 | 现场+台账+人员健康证 | 受理后 5–10 工作日 | 核查当天全员健康证有效、卫生到位 |

## 二、后厨布局合规要点

### 1. 水池配置（最常驳回项）
- **独立分设、不得混用、标识清晰**：洗菜池、洗肉池、洗水产池、洗手池、餐饮具清洗消毒池。
- 数量按经营规模，但"荤/素/水产/餐具/洗手"五类至少分设；小店最低不少于 3 个独立功能池，且餐饮具洗消池单独。
- 洗手池旁配皂液、干手、消毒液；不得与洗菜洗肉共用。

### 2. 墙面与地面
- 墙面：易清洗、不透水、浅色瓷砖，操作区**贴砖到顶**（至少到 2 米且无缝隙藏污）。
- 地面：防滑、不渗水、易排水，有适当坡度与地漏（带防鼠网）；不得用木地板、地毯。
- 吊顶：防霉、易清洁； cooking line 上方装排烟罩并接油水分离。

### 3. 三防设施
- 防鼠：出入口挡鼠板（高 ≥60cm、与地面/门缝 ≤6mm）、地漏防鼠网、孔洞封堵。
- 防蝇：纱窗完好、出入口风幕机或胶帘（重叠、离地 ≤2cm）、灭蝇灯（离地 1.5–2m、不直照食品操作台、粘纸定期更换）。
- 防虫：定期开展有害生物防治（PCO）并有记录。

### 4. 专间要求（冷食/生食/裱花类必查）
- 独立专间，入口设**预进间（二次更衣 + 洗手消毒）**。
- 独立空调（温度 ≤25℃）、空气消毒设施（紫外线灯，按 1.5W/㎡、离地 2m、无人时开启并有记录）。
- 专用工用具、独立冷藏、非手动式水龙头、空气幕/缓冲间。
- 无明沟，地漏带水封。

### 5. 仓储与流程
- 生进熟出单向动线，避免交叉；原料、半成品、成品分区。
- 仓库离墙离地、通风防潮、分类上架。

## 三、常见驳回原因 → 整改动作

| 驳回原因 | 整改动作 |
|---|---|
| 水池数量不足/混用 | 增设为独立功能池并贴标，洗消池单独 |
| 地砖不防滑 | 更换为防滑地砖，做排水坡度 |
| 墙面未贴砖到顶 | 操作区补贴瓷砖至顶 |
| 无挡鼠板/纱窗破损 | 加装合规挡鼠板、修复纱窗 |
| 专间缺二次更衣/空气消毒 | 增设预进间、紫外线灯并建消毒记录 |
| 布局导致生熟交叉 | 重排动线，生进熟出单向 |
| 排水无防鼠网/地漏无封 | 加装防鼠网、水封地漏 |

## 四、迎检话术培训（高频问题标准答法）

| 检查员可能问 | 标准回答要点 |
|---|---|
| "你们多久消一次毒？" | "餐饮具每餐次物理/化学消毒，有消毒记录本可查，消毒柜常态开启。" |
| "这菜哪进的？" | "均从资质齐全供应商采购，索证索票和进货台账都在，可即时调取。" |
| "健康证都齐吗？" | "全部在岗直接接触食品员工健康证有效并公示，可逐一核对。" |
| "过期原料怎么处理？" | "执行先进先出，每日盘点，临期标识、过期立即废弃并记录，绝不上台面。" |
| "冷菜在哪做？" | "在专用冷食间，二次更衣、空气消毒、专用工具，符合专间要求。" |
| "灭蝇灯/挡鼠板呢？" | "三防设施按规范配置并日常维护，有虫害防治记录。" |

**陪同技巧**：安排专人（店长/食安员）陪同，走预设干净动线，主动展示公示栏→台账→消毒记录→员工穿戴，避免被随意打开无关柜门引发新问题。
