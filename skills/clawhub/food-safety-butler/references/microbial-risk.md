# 微生物风险评估方法（Pro 步骤 4 依据）

> 本文供 ATP 清洁度判定与"危险温度带细菌增殖"推算使用。数值为通用参考区间，不作医学诊断依据。

## 一、ATP 荧光检测（清洁度）

| ATP (RLU) | 判定 | 含义与动作 |
|---|---|---|
| < 200 | ✅ 合格 | 表面洁净，维持现有清洁 SOP |
| 200 – 500 | 🟡 警戒 | 存在有机物/生物膜残留，加强清洁频次与点位 |
| > 500 | 🔴 高风险 | 清洁严重不足，立即深度清洁+复测，追溯交叉污染 |

- RLU（Relative Light Unit）反映物体表面 ATP 总量，间接表示微生物与食物残渣水平。
- 适用：砧板、餐具、操作台、设备把手等关键点涂抹检测。
- 注意：ATP 不区分死/活菌，仅作清洁验证指标；菌落总数需实验室培养确认。

## 二、危险温度带（Danger Zone）

- **区间**：10℃ – 60℃（部分标准取 5℃–60℃；本系统采用 10℃–60℃）。此区间致病菌可快速繁殖。
- **关键控制**：烹饪后热藏 ≥60℃；冷藏 ≤8℃；冷却/再加热须快速通过此带。

## 三、细菌增殖代数推算

致病菌（如金黄色葡萄球菌、沙门氏菌、蜡样芽孢杆菌）在危险带代时 g 约 **20–30 分钟**。

公式：
```
增殖代数  n = t / g          （t = 在危险带停留时长，g = 代时，取 25 min）
增殖倍数 ≈ 2ⁿ
```

示例：
- t = 2h (120 min)，g = 25 min → n ≈ 4.8 → 倍数 ≈ 2^4.8 ≈ **28 倍**
- t = 4h (240 min) → n ≈ 9.6 → 倍数 ≈ 2^9.6 ≈ **780 倍**

**风险警示写法（报告用）**：
> 该冷冻品实测 -10℃（CL ≤-12℃），推测曾脱离冷冻、进入 10–60℃ 危险带。按代时 25 min 估算，若暴露 2h，致病菌可增殖约 28 倍；暴露 4h 可达约 780 倍，存在急性食物中毒实质风险，须立即隔离并追溯冷链断点。

## 四、综合风险等级映射（供 Detailed Findings 表"风险等级"列）

| 偏离幅度 | 风险等级 |
|---|---|
| 实测在 CL 内 | Low |
| 轻微偏离（如冷藏 8.5℃、ATP 300 RLU） | Medium |
| 显著偏离（如冷冻 -10℃、健康证过期、烹饪未测温） | **High** |
| 多 CCP 同时偏离或存在即食食品暴露 | **Critical** |
