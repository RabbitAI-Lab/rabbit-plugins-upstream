# 可复用检查清单模板（直接套用输出）

> 模式 A 自查或迎检前自检时，按门店类型勾选。✅=达标，⚠️=预警，❌=危险。

## 模板一：日常班前 / 迎检速查（10 分钟）

**人员**
- [ ] 在岗直接接触食品员工健康证有效且公示 ✅/❌
- [ ] 晨检记录完整（发热/腹泻/伤口/化脓性皮肤病）✅/⚠️
- [ ] 工作衣帽口罩整洁、无首饰/长甲/指甲油 ✅/⚠️

**环境**
- [ ] 地面无积水油污、排水通畅 ✅/⚠️
- [ ] 垃圾桶带盖不溢出、餐厨垃圾日清 ✅/⚠️
- [ ] 灭蝇灯开启、纱窗完好、挡鼠板在位 ✅/⚠️

**食材**
- [ ] 无过期/腐败原料（翻查冰箱底层）✅/❌
- [ ] 冷冻≤-18℃、冷藏0–8℃有记录 ✅/⚠️
- [ ] 荤/素/水产砧板刀具色标分开 ✅/❌

**台账公示**
- [ ] 证照、量化分级、投诉电话公示 ✅/⚠️
- [ ] 进货查验（索证索票）台账齐全可溯 ✅/❌
- [ ] 餐饮具消毒记录完整 ✅/⚠️

## 模板二：周检深度清单

- [ ] 冰箱除霜清洁、温度计校准 ✅/⚠️
- [ ] 排烟罩油垢清理、油水分离正常 ✅/⚠️
- [ ] 虫害防治（PCO）记录更新、无鼠迹蟑迹 ✅/⚠️
- [ ] 食品添加剂"五专"管理（专人/专柜/专册/专用称/专用记录）✅/❌
- [ ] 专间（冷食/生食/裱花）空气消毒、二次更衣、温度≤25℃ ✅/❌
- [ ] 留样（如适用）量足、时限、专用冰箱 ✅/⚠️
- [ ] 废弃油脂去向记录、合规处置 ✅/⚠️

## 模板三：新店办证前自查（对照 license-guide.md）

- [ ] 水池五类独立分设并贴标（菜/肉/水产/手/餐具）✅/❌
- [ ] 墙面贴砖到顶、地面防滑有坡度 ✅/❌
- [ ] 三防到位（挡鼠板≥60cm、纱窗、灭蝇灯、风幕/门帘）✅/❌
- [ ] 专间含预进间二次更衣+空气消毒（冷食/生食/裱花）✅/❌
- [ ] 生进熟出单向动线、无交叉 ✅/⚠️
- [ ] 排水防鼠网、地漏水封 ✅/⚠️
- [ ] 员工健康证、培训、制度上墙准备就绪 ✅/⚠️

---

**使用方式**：将以上模板套入 SKILL.md 的"模式 A 输出格式"，把勾选项转化为 🟢/🟡/🔴 三色清单；❌ 一律进"危险区"，⚠️ 进"预警区"，✅ 进"安全区"。
