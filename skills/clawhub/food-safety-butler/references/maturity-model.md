# 合规成熟度评估模型（L1–L5）

> 依据 ISO 22000 体系思想与能力成熟度通用框架。供"步骤 1 — 合规成熟度评估"评级与输出升级路线图。

## 一、五级定义

| 等级 | 名称 | 特征 | 典型表现 |
|---|---|---|---|
| **L1** | 初始级 | 无标准化，靠个人经验 | 无统一 SOP、无台账、出事才救火 |
| **L2** | 可重复级 | 有 SOP 但未落地验证 | 制度挂在墙、执行靠人、无监控记录 |
| **L3** | 已定义级 | 集团统一制度、流程标准化 | 全国一套 SOP、定期培训、但靠人工巡检 |
| **L4** | 已管理级 | 数字化监控 + 预警 | IoT 温度、AI 巡检、看板预警、数据可追 |
| **L5** | 优化级 | 数据驱动持续优化 | 预测性风控、自动纠偏、体系自我迭代 |

## 二、评级判定要点（按证据）

- **制度层**：有无集团统一 SOP、培训档案、内审制度。
- **执行层**：SOP 实际落地率、巡检覆盖率、记录完整率。
- **数字化层**：温度/视频/台账是否自动采集；能否实时预警与追溯。
- **优化层**：是否用数据反哺标准迭代、是否有预测模型。

## 三、差距分析与升级路线图（模板）

| 当前 → 目标 | 关键差距 | 路线图里程碑（季度） |
|---|---|---|
| L2 → L4 | 制度未数字化、监控盲区大 | Q1 统一 SOP 上线；Q2 冷链 IoT 覆盖 ≥80%；Q3 预警看板；Q4 达标 L4 |
| L3 → L4 | 缺实时数据与自动预警 | Q1 监控补点；Q2 数据中台；Q3 预警规则；Q4 验收 |
| L1 → L3 | 完全无体系 | Q1–Q2 建制度；Q3 培训落地；Q4 内审达标 L3 |

**验收口径**：以"数字化监控覆盖率""SOP 落地率""违规发生率"三项硬指标是否达目标区间为准。
