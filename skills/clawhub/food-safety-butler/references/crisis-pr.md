# 危机公关与投诉处理预案（异物 / 打假 / 举报）

> 适用：顾客在餐品中吃到头发/虫子/异物、职业打假人上门、被投诉举报至 12315/市场监管。目标是**合法合规化解、固定证据、避免事态升级与行政处罚扩面**。本文件不构成法律意见。

## 一、总原则（先记住这四条）

1. **先安抚，不激化**：无论对方是否为"职业打假"，第一时间表达重视、道歉、带离现场到安静处沟通。
2. **不承认违法、不签署空白文件**：可以说"我们非常重视，会核查"，不要现场承认"我们卫生不达标/有毒"。
3. **全程留痕**：保存实物证据（异物原物、同批次留样）、监控录像、沟通录音（注意告知合规）、票据与对话记录。
4. **分级处理**：普通消费纠纷走协商赔偿；涉嫌违法的由监管判定，企业配合整改而非对抗。

## 二、标准接待话术

### 场景 1：顾客现场反映"吃到头发/异物"

```
店长/食安员：
"非常抱歉给您不好的体验，我们马上跟进。
 能否把这份餐品连同异物留给我们封存保全？我们调监控和留样核实。
 您看是先休息一下，我们给个让您满意的方案？"
```
- 动作：封存剩余餐品+异物、打印/导出该单监控、查该餐品留样（如有）、记录顾客联系方式。
- 避免说："不可能，我们很干净""你是不是自己放的"。

### 场景 2：职业打假人/神秘顾客

```
"感谢您对我们门店的关注。您反映的问题我们已记录（时间/单号/问题）。
 我们按公司流程处理，相关情况会向属地市场监管所如实说明并整改。
 如需索赔，请留下书面材料与联系方式，我们法务会依规对接。"
```
- 不争吵、不给现金私了诱导、不承诺超法定赔偿。

### 场景 3：监管/12315 转办

```
"我们已收到反馈，正在自查并保全证据。
 会按时提交情况说明、监控、台账、健康证等材料，配合整改。"
```

## 三、赔偿处理流程（法律边界）

- **法律依据**：《食品安全法》第 148 条——生产不符合安全标准食品或经营明知不符合安全标准食品，消费者可要求**价款十倍或损失三倍**赔偿；增加赔偿不足 **1000 元** 的，按 **1000 元** 计。
- **关键区分**：
  - "异物混入（头发/虫）"多属服务瑕疵/不符合食品卫生要求，协商或依《民法典》侵权/合同责任处理，未必触发十倍；但监管可就卫生问题处罚。
  - "经营不符合安全标准的食品"（过期、腐败、来源不明）才可能触发十倍+行政处罚。
- **建议动作**：
  1. 先核实事实与证据（异物是否属实、是否本店责任）。
  2. 事实清楚的小额纠纷：主动依"退一赔三/不足千补千"或协商额度快速了结，签署和解书（含"双方再无争议"条款）。
  3. 存疑或高额索赔/疑似敲诈：不私了，固定证据，请律师/法务评估，必要时报警（敲诈勒索）或走调解。

## 四、证据固定清单

- [ ] 异物原物（密封保存、标注时间单号）
- [ ] 同批次餐品留样（如有）
- [ ] 监控录像（导出备份，注意保存期限）
- [ ] 该单点单/支付/出餐记录
- [ ] 沟通录音/书面记录
- [ ] 员工当班与健康证、相关台账

## 五、对内动作

- 立即暂停涉事环节，复查同类风险（如该员工、该时段、该原料）。
- 如属实，24h 内完成整改并留档，作为后续对监管"已主动改正"的从轻情节。
- 全员简短通报，不传播猜测、不指责顾客。

> 免责声明：本预案为合规应对建议，具体赔偿与法律责任以监管认定和司法裁判为准。
