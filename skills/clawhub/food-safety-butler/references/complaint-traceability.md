# 客诉溯源闭环管理（门店→央厨→供应商）

> 供"步骤 5 — 客诉溯源闭环管理"。建立全链路溯源，定位根源、明确责任、防再发。

## 一、溯源链路与责任主体

```
顾客客诉
  → 门店（操作/储运/现制）
    → 中央厨房（加工/分装/批次）
      → 供应商（原料/资质/农残/冷链到货）
```

| 环节 | 可能根源 | 责任主体 | 常见证据 |
|---|---|---|---|
| 门店 | 交叉污染、温度失控、人员卫生、餐具未消毒 | 门店店长/食安员 | 监控、测温记录、健康证、消毒记录 |
| 中央厨房 | 批次混用、冷却不当、分装污染 | 央厨品控 | 批次台账、留样、加工记录 |
| 供应商 | 原料带菌/过期、资质缺失、农残超标 | 供应链部/供应商 | 到货验收、检测报告、溯源码 |

## 二、闭环五步

1. **接诉留痕**：封存剩余餐品+异物、导出监控、记录单号与时间（参照 `crisis-pr.md`）。
2. **链路反查**：凭小票/溯源码上溯门店→央厨批次→供应商到货。
3. **根因判定**：区分"原料 / 操作 / 储运"三类根源，定位责任主体。
4. **纠正与追责**：门店即时整改、央厨复检批次、供应商冻结/除名（无溯源记录一律视为违规）。
5. **防再发**：更新集团 SOP、补充监控点、纳入培训与内审。

## 三、闭环输出写法

> 客诉「XX 店吃到异物」溯源：小票码 → 门店批次 B0321 → 央厨分装线 2 → 供应商 S 到货验收缺农残报告。**根因：供应商准入资质不全（CCP1 失守）**。措施：冻结供应商 S、全量重审、门店加强异物挑拣；责任：供应链部 + 该店长。防再发：准入系统加农残必检卡点。
