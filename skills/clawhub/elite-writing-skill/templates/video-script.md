# Video Script Template

## Pre-Writing
- [ ] Platform identified (YouTube/TikTok/Instagram)
- [ ] Length determined (short <60s / medium 3-5min / long 10-20min)
- [ ] Hook designed for first 3 seconds
- [ ] Framework selected

---

## Structure

### HOOK (0-3 seconds)
[Pattern interrupt - visual or verbal]
[Promise of value - "By the end of this..."]

### INTRO (3-15 seconds)
[Who you are (brief)]
[Why they should listen]
[What they'll learn]

### MAIN CONTENT
[Point 1 - with example]
[Point 2 - with example]
[Point 3 - with example]

### TRANSITIONS
[Visual or verbal bridge between points]
[B-roll suggestions]

### CONCLUSION (15-30 seconds)
[Summary of key points]
[Call to action - subscribe, comment, visit link]
[Final hook - tease next video]

---

## Production Notes
- [ ] B-roll identified for each section
- [ ] On-screen text planned
- [ ] Music cues noted
- [ ] Cut points marked
