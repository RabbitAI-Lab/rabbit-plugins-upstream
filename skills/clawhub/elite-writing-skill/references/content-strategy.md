# Content Strategy & SEO Mastery

> Systems for creating, optimizing, distributing, and measuring content that ranks, engages, and converts.

---

## 1. The Content Strategy Framework

```
1. AUDIENCE RESEARCH
   -> Who are we talking to?
   -> What do they search for?
   -> What content do they share?
   -> Where do they hang out?

2. CONTENT PILLARS
   -> 3-5 core themes that define your expertise
   -> Each pillar has 10+ sub-topics
   -> Every piece of content maps to a pillar

3. CONTENT TYPES
   -> Awareness: Blog posts, social media, videos
   -> Consideration: Case studies, comparison guides, webinars
   -> Decision: Product pages, demos, testimonials
   -> Retention: Tutorials, newsletters, community content

4. DISTRIBUTION CHANNELS
   -> Owned: Website, email, app
   -> Earned: PR, guest posts, mentions
   -> Paid: Ads, sponsored content
   -> Social: LinkedIn, Twitter, TikTok, etc.

5. MEASUREMENT
   -> Traffic: Page views, unique visitors, sources
   -> Engagement: Time on page, scroll depth, comments
   -> Conversion: Leads, signups, purchases
   -> SEO: Rankings, backlinks, domain authority
```

## 2. SEO Content Optimization System

### Keyword Research Protocol
```
STEP 1: Seed Keywords
-> Brainstorm 20 terms your audience searches for
-> Use tools: Google Keyword Planner, Ahrefs, SEMrush

STEP 2: Intent Classification
-> Informational: "how to", "what is", "guide"
-> Navigational: Brand names, product names
-> Commercial: "best", "top", "vs", "review"
-> Transactional: "buy", "discount", "free trial"

STEP 3: Difficulty Assessment
-> Search volume (monthly)
-> Keyword difficulty (0-100)
-> Current ranking competitors
-> Content gap analysis

STEP 4: Topic Clustering
-> 1 pillar page (broad, high-volume)
-> 5-10 cluster pages (specific, long-tail)
-> Internal linking between cluster and pillar
```

### On-Page SEO Checklist
```
[x] Title tag: 50-60 chars, keyword at front, compelling
[x] Meta description: 150-160 chars, includes CTA
[x] H1: One per page, includes primary keyword
[x] H2-H6: Logical hierarchy, includes related keywords
[x] URL: Short, descriptive, keyword-rich
[x] First 100 words: Primary keyword appears naturally
[x] Image alt text: Descriptive, includes keywords where natural
[x] Internal links: 3-5 per 1000 words
[x] External links: 2-3 to authoritative sources
[x] Schema markup: Article, FAQ, HowTo where applicable
[x] Page speed: <3 seconds load time
[x] Mobile optimization: Responsive design
[x] Readability: Flesch score 60-70 for general audience
```

### Content Quality Signals (Google's E-E-A-T)
```
E - EXPERIENCE
-> Does the writer have first-hand experience?
-> Include personal anecdotes, case studies, original research

E - EXPERTISE
-> Does the content demonstrate deep knowledge?
-> Include data, citations, expert quotes

A - AUTHORITATIVENESS
-> Is the source trusted in the field?
-> Build backlinks, get mentioned by authorities

T - TRUSTWORTHINESS
-> Is the information accurate and safe?
-> Cite sources, update regularly, correct errors
```

## 5. The Headline Optimization System

### Headline Formulas That Work

**For SEO:**
```
[Number] [Adjective] [Keyword] [Year]
-> "17 Best Copywriting Formulas for 2026"

How to [Keyword] [Benefit]
-> "How to Write SEO Content That Ranks in 30 Days"

[Keyword]: The [Adjective] Guide [Year]
-> "Technical Writing: The Complete Guide 2026"
```

**For Social Media:**
```
[Controversial Statement]
-> "Copywriting is dead. Here's what replaced it."

[Curiosity Gap]
-> "The writing technique nobody talks about (but everyone uses)"

[Personal Story Hook]
-> "I wrote 1,000 headlines. Here's what I learned."
```

### Headline Testing Protocol
```
1. Write 10 variations
2. Score each on:
   -> Curiosity (1-10)
   -> Clarity (1-10)
   -> Emotional impact (1-10)
   -> SEO value (1-10)
3. Pick the highest total score
4. A/B test top 2 if possible
```

## 6. The Content Refresh Protocol

**Every 6 months, audit existing content:**

```
STEP 1: IDENTIFY DECLINING CONTENT
-> Pages with >20% traffic drop
-> Pages ranking on page 2-3 of Google
-> Pages with outdated information

STEP 2: ANALYZE COMPETITION
-> Who ranks above you now?
-> What do they have that you don't?
-> What's the content gap?

STEP 3: UPDATE AND EXPAND
-> Add new sections
-> Update statistics and examples
-> Improve readability
-> Add multimedia (images, videos, charts)
-> Strengthen internal linking

STEP 4: REPUBLISH AND REDISTRIBUTE
-> Update publish date
-> Share on social media again
-> Include in newsletter
-> Pitch to relevant communities
```

## 9. The Content Quality Scorecard

**Rate each piece 1-5:**

```
RELEVANCE (Does it serve the audience?)
[x] Directly addresses audience pain point
[x] Matches search intent
[x] Aligns with content pillar

DEPTH (Is it comprehensive?)
[x] Covers topic thoroughly
[x] Includes unique insights
[x] Cites credible sources

READABILITY (Is it accessible?)
[x] Clear structure with headings
[x] Short paragraphs (3-4 sentences max)
[x] Visual breaks (images, lists, quotes)
[x] Jargon explained or avoided

ENGAGEMENT (Will people finish it?)
[x] Strong hook in first 100 words
[x] Storytelling elements
[x] Actionable takeaways
[x] Clear next step/CTA

SEO (Will it rank?)
[x] Keyword optimization
[x] Internal/external linking
[x] Meta tags optimized
[x] Mobile-friendly
[x] Fast loading

SCORING:
20-25 = Exceptional (promote heavily)
15-19 = Good (minor improvements)
10-14 = Average (significant revision needed)
<10 = Poor (rewrite or archive)
```

## 10. Social Media Writing Formulas

### LinkedIn Post Structure
```
HOOK (First 2 lines, before "...see more")
-> Contrarian opinion, surprising stat, or personal story

BODY (3-5 short paragraphs)
-> Expand on the hook
-> Include 1-2 key insights
-> Use line breaks for readability

CTA
-> "What's your experience?" or "Share your thoughts"

HASHTAGS
-> 3-5 relevant hashtags
```

### Twitter/X Thread Structure
```
TWEET 1: Hook (standalone value)
TWEET 2-4: Core insights (one per tweet)
TWEET 5-7: Examples/evidence
TWEET 8: Key takeaway
TWEET 9: CTA (follow, reply, check link)
```

### Instagram Caption Structure
```
HOOK (First line, emojis)
-> "The writing mistake costing you followers"

BODY
-> Short, punchy paragraphs
-> Use emojis as bullet points
-> Include 1-2 CTAs

HASHTAGS
-> 20-30 relevant hashtags
-> Mix of popular and niche
```
