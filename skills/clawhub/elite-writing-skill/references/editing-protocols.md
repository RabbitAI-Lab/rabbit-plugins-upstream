# Advanced Editing Protocols

> Professional-grade editing techniques used by top editors at The New Yorker, Wired, and major publishing houses.

---

## 1. The Macro Edit (Structural)

**Before touching a single sentence, evaluate the whole:**

```
□ PURPOSE ALIGNMENT
  -> Does every section serve the stated purpose?
  -> If the purpose changed during drafting, update the intro

□ FLOW ANALYSIS
  -> Read only the first sentence of each paragraph
  -> Do they tell a coherent story?
  -> If not, reorder paragraphs

□ PACING CHECK
  -> Are there sections that drag?
  -> Are there sections that feel rushed?
  -> Balance: dense info with lighter moments

□ REDUNDANCY HUNT
  -> "Did I already say this?"
  -> Merge similar paragraphs
  -> Cut repeated examples

□ STRUCTURAL INTEGRITY
  -> Does the argument build logically?
  -> Are there logical gaps?
  -> Is the conclusion supported by the body?
```

## 2. The Micro Edit (Sentence-Level)

### The "So What?" Test
**For every sentence, ask:**
```
"So what?"
-> If the answer isn't obvious, the sentence is weak.
-> Either strengthen it or cut it.
```

### The "By Zombies" Test (Passive Voice)
```
Add "by zombies" to the end of any sentence.
If it makes sense, it's passive voice.

"The report was written [by zombies]." -> PASSIVE
"I wrote the report [by zombies]." -> Doesn't make sense -> ACTIVE
```

### The "Read Backwards" Technique
```
Read the last sentence first, then second-to-last, etc.
-> Isolates each sentence from context
-> Reveals awkward phrasing invisible in normal reading
-> Catches grammar errors
```

### The "One Breath" Rule
```
If you can't say a sentence in one breath, it's too long.
-> Break into 2-3 shorter sentences
-> Or use a colon/semicolon strategically
```

## 3. The Voice Consistency Audit

```
□ TENSE CHECK
  -> Pick one tense. Stick to it.
  -> Past for narratives, present for instructions

□ PERSON CHECK
  -> First person (I/we): Personal stories, opinions
  -> Second person (you): Instructions, guides
  -> Third person (he/she/they): News, reports
  -> NEVER mix within a section

□ FORMALITY CHECK
  -> Scan for words that break the chosen register
  -> "gonna" in a formal report? Fix it.
  -> "utilize" in a casual blog? Fix it.

□ TONE AUDIT
  -> Read aloud in the target voice
  -> Does it sound natural?
  -> Would the target audience nod along?
```

## 4. The Clarity Protocol

### FOG Index Reduction
```
Calculate approximate reading level:
-> Average sentence length + percentage of long words
-> Target: 8th-10th grade for general audience
-> Target: 12th grade+ for technical audience

Techniques to reduce fog:
-> Replace 3-syllable words with 1-2 syllable alternatives
-> Break sentences >25 words
-> Use concrete examples over abstractions
```

### The "Explain to a 10-Year-Old" Test
```
Take the most complex paragraph.
Explain the same concept to a 10-year-old.
If you can't, you don't understand it well enough.
Rewrite using that simplified explanation.
```

### The Jargon Purge
```
For every technical term:
-> Is it necessary? (Audience expects it?)
-> If yes: Define on first use
-> If no: Replace with plain English

Exceptions:
-> SEO content (keywords must appear)
-> Technical docs (audience knows the terms)
-> Industry publications (shared vocabulary)
```

## 5. The Persuasion Polish

### The Objection Pre-emption
```
List every reason someone might NOT take action:
-> "Too expensive" -> Address value, ROI, payment plans
-> "Too complicated" -> Emphasize simplicity, support
-> "Not for me" -> Show relatable examples
-> "I'll do it later" -> Create urgency
-> "I don't trust you" -> Social proof, guarantees

Weave answers into the copy BEFORE they object.
```

### The Scarcity/Urgency Calibration
```
LEGITIMATE urgency:
-> "Doors close Friday at midnight"
-> "Only 3 spots remaining"
-> "Price increases tomorrow"

FAKE urgency (AVOID):
-> "Limited time!" (no specific deadline)
-> "Only 5 left!" (when there are actually 500)
-> "Act now!" (with no reason)

Rule: If the urgency isn't real, don't use it.
```

### The Social Proof Placement
```
Where to place social proof for maximum impact:
-> After the promise (validates the claim)
-> Before the CTA (removes final doubt)
-> After the price (justifies the cost)
-> In the objection section (addresses skepticism)

Types of social proof:
-> Testimonials (with specific results)
-> Case studies (with numbers)
-> Client logos (familiar brands)
-> User counts ("Join 10,000+ users")
-> Expert endorsements
-> Media mentions
```

## 6. The Rhythm & Music Edit

### Sentence Length Variation
```
Short. Punchy. Impact.

Then a medium sentence that flows naturally and carries the reader forward.

And then a longer, more complex sentence that builds momentum through multiple clauses, creating a sense of movement and energy before landing with a definitive conclusion that resonates.

Short again. Reset.
```

### Paragraph Rhythm
```
Avoid:
-> Walls of text (5+ sentences per paragraph)
-> Staccato paragraphs (every paragraph is 1 sentence)

Target:
-> Mix: 2-sentence, 3-sentence, 4-sentence paragraphs
-> Use 1-sentence paragraphs for emphasis ONLY
-> No paragraph >5 sentences without a visual break
```

### Transition Quality
```
WEAK transitions:
-> "Also..."
-> "In addition..."
-> "Furthermore..."

STRONG transitions:
-> "But here's what most people miss..."
-> "That brings us to the real problem..."
-> "Here's where it gets interesting..."
-> "The catch?"
-> "But wait - there's more..."
```

## 7. The Final Polish Checklist

```
□ SPELLING
  -> Run spell-check
  -> Check homophones (their/there/they're, its/it's)
  -> Verify proper nouns (names, brands, products)

□ GRAMMAR
  -> Subject-verb agreement
  -> Pronoun reference clarity
  -> Modifier placement
  -> Parallel structure in lists

□ PUNCTUATION
  -> Oxford comma consistency
  -> Em dash vs. en dash vs. hyphen
  -> Quotation mark style (US vs. UK)
  -> Apostrophe usage

□ FORMATTING
  -> Heading hierarchy (H1 > H2 > H3)
  -> Consistent bullet styles
  -> Number formatting (1,000 vs 1000)
  -> Date formatting consistency

□ LINKS
  -> All internal links work
  -> All external links work
  -> Anchor text is descriptive
  -> No broken links

□ IMAGES
  -> Alt text on all images
  -> Images compressed for web
  -> Captions where appropriate
  -> Source attribution

□ NUMBERS & DATA
  -> All statistics cited
  -> All numbers accurate
  -> Percentages calculated correctly
  -> Currency/formatting consistent

□ LEGAL & ETHICS
  -> No unsubstantiated claims
  -> No copyright violations
  -> Required disclaimers included
  -> Privacy policy referenced if collecting data
```

## 8. The "Sleep On It" Rule

```
After completing the final edit:

1. STEP AWAY for at least 2 hours (preferably overnight)
2. RETURN with fresh eyes
3. READ ALOUD one final time
4. FIX anything that feels off
5. Only then, publish

Fresh eyes catch errors that tired eyes miss.
```

## 9. The Peer Review Protocol

```
If possible, have someone else review:

QUESTIONS FOR REVIEWER:
1. "What is the main point?" (Checks clarity)
2. "Where did you get bored?" (Checks pacing)
3. "What confused you?" (Checks clarity)
4. "What would make you take action?" (Checks persuasion)
5. "Does this sound like [brand voice]?" (Checks consistency)

RED FLAGS TO WATCH FOR:
-> Reviewer asks "What do you mean by...?" -> Clarity issue
-> Reviewer skips a section -> Pacing issue
-> Reviewer disagrees with premise -> Logic issue
-> Reviewer isn't compelled to act -> Persuasion issue
```

## 10. Common Writing Errors & Fixes

| Error | Example | Fix |
|-------|---------|-----|
| **Nominalization** | "make a decision" | "decide" |
| **Weak verbs** | "is responsible for" | "manages" |
| **Redundancy** | "advance planning" | "planning" |
| **Vague qualifiers** | "very important" | "critical" |
| **Passive voice** | "was written by" | "wrote" |
| **Wordiness** | "due to the fact that" | "because" |
| **Jargon** | "leverage our core competencies" | "use our strengths" |
| **Cliches** | "think outside the box" | Original phrasing |
| **Hedging** | "It seems that perhaps" | Direct statement |
| **Nominal string** | "customer satisfaction improvement initiative" | "improving customer satisfaction" |
