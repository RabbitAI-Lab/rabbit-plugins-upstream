# Elite Writing Skill for OpenClaw

Skill ini dirancang untuk **mentransformasi AI Agent apa pun** menjadi penulis elit tingkat dunia — dari copywriting dan content strategy hingga technical documentation dan creative storytelling.

## Apa yang Membuat Skill Ini "Tingkat Tertinggi"?

Bukan sekadar "tulis dengan baik". Skill ini menyuntikkan **arsitektur berpikir penulis top 1%**:

- Framework copywriting dari legenda seperti Ogilvy, Halbert, Bencivenga
- Teknik storytelling dari Pixar, Campbell, dan screenwriter Hollywood
- Standar technical writing dari Google, Microsoft, dan Stripe
- Strategi content & SEO yang terbukti ranking #1
- Sistem editing 7-layer yang digunakan editor The New Yorker

## 📦 Instalasi

### OpenClaw Lokal
```bash
# Copy ke direktori managed (semua agent bisa pakai)
cp -r elite-writing-skill ~/.openclaw/skills/

# Atau ke workspace agent spesifik
cp -r elite-writing-skill /path/to/workspace/skills/
```

### Kimi Claw (Browser)
1. Buka **Kimi Claw** di kimi.com
2. Masuk ke **Skill Workshop**
3. Upload folder `elite-writing-skill`
4. Aktifkan skill

## 🎯 Protokol Utama (Dari SKILL.md)

Setiap kali menulis, agent menjalankan:

```
1. AUDIENCE ANALYSIS      -> Siapa pembaca? Apa yang mereka inginkan?
2. PURPOSE CLARIFICATION  -> Apa tujuan eksak tulisan ini?
3. TONE MAPPING           -> Suara dan nada yang tepat
4. STRUCTURE DESIGN       -> Framework mana yang paling cocok?
5. HOOK ENGINEERING       -> 5 variasi hook, pilih yang terkuat
6. DRAFT                  -> Tulis dengan framework terpilih
7. 7-LAYER EDITING        -> Edit struktur, clarity, concision, rhythm, voice, persuasion, proofreading
8. POLISH                 -> Final voice check, rhythm check, impact check
```

- **Content Repurposing Engine**: 1 artikel jadi 10+ konten
- **Headline Optimization**: 10 formulas + sistem scoring
- **Social Media Writing Formulas**: LinkedIn, Twitter, Instagram

## ✂️ Sistem Editing 7-Layer

1. **Structural Edit** -> Flow, order, redundancy
2. **Clarity Edit** -> Understandability, jargon, examples
3. **Concision Edit** -> Cut 20%, eliminate weak words
4. **Rhythm Edit** -> Sentence length variation, readability
5. **Voice Edit** -> Consistency with defined voice/tone
6. **Persuasion Edit** -> CTA, objections, social proof
7. **Proofreading** -> Grammar, spelling, links, formatting
