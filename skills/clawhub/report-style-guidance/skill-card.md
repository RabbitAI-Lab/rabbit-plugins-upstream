## Description:

Provides executive report style guidance and formats stakeholder status reports using the active workspace reporting style.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wxt-ai](https://clawhub.ai/user/wxt-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Employees, external stakeholders, and reporting teams use this skill to establish executive report style guidance and format status reports for stakeholder review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation language may cause the skill to be invoked for reporting requests where its style or formatting assumptions are not intended.

Mitigation: Review generated style guidance and formatted status reports before sharing them with stakeholders, and narrow activation wording in a future release if accidental use is observed.
