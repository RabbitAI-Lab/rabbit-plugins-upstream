# 测试

- [ ] 正常：完整参数生成带来源的企业画像。
- [ ] 缺失参数：仅进入初步分析。
- [ ] 主体冲突：同名公司未确认时停止归因。
- [ ] 来源冲突：并列版本，不静默选择。
- [ ] 时间过期：旧团队和旧产品线标记历史。
- [ ] 禁止推断：官网自述不视为独立证据。
- [ ] 低质量来源：匿名内容只作为线索。
- [ ] 无结果：不得写“公司不存在”。
- [ ] 跨 Skill：正确区分 `zayn-customer-profile`。
- [ ] 数据边界：不编造营收、员工、客户。
- [ ] 数据不足时不得评分。
- [ ] 来源：关键结论均有来源关系。
- [ ] 非销售：支持采购、合规、战略岗位。
