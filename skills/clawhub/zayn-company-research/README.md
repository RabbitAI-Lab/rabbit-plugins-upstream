# COMPANY_RESEARCH() 企业公开信息调查

- Skill：`zayn-company-research`
- 核心用途：确认企业主体并整理公开背景、业务、规模信号、团队、认证和动态。
- 适用：潜在客户、供应商、合作伙伴、竞争对手的公开调查。
- 不适用：内部交易画像、法律意见、直接合作决策。
- 输入：名称、国家、官网/域名或注册线索、目的、时间范围、重点方向。
- 最低条件：主体可基本确认、辖区和目的明确、同名风险可控。
- 流程：主体确认→研究问题→来源分级→交叉验证→事实/推断分离→结构化输出。
- 输出：主体、背景、业务、规模信号、团队、市场、资质、动态、缺口与来源。
- 证据：遵守 `../shared/` 下的主体、来源、时效、证据和引用规则。
- 风险边界：未找到不等于不存在，不编造营收、员工或客户。
- 协作：公开信息交给本 Skill；业务行为交给 `zayn-customer-profile`；合作判断交给 `zayn-company-fit`。
- 快速示例：调查 Example Ltd 在德国的注册主体、官网业务和近两年公开经营信号。
- 版本：v1.0.0
