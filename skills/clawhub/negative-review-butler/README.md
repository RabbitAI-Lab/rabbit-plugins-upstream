# 差评管家 (negative-review-butler)

把一堆差评从"逐条煎熬一小时"变成"审核发布十分钟"：**截图或复制评价内容丢进来**，自动分类分级、高危预警、生成引用具体问题点的个性化回复草稿——人工审核后粘贴回平台即可。

## 它能做什么

- 输入：商家后台评价页的**截图 / 复制粘贴文本 / 导出文件**，三种方式任选（各平台后台都能截图，无需任何导出工具）
- 输出：分类分级的回复草稿清单——高危差评（食品安全等）置顶标红并附处理提示、每条草稿引用该评价的具体问题、附补救建议与同类问题经营提示
- 内置双行业模板：**餐饮/本地生活**（美团、大众点评、饿了么）与**电商**（淘宝、京东、拼多多），自动识别可手动指定

## 快速体验

没有现成差评？直接对 Agent 说：

> 给我看看差评管家的输出效果示例

## 建议用法：每日十分钟

每天开店/上班后，花 2 分钟把昨日新评价截图发来（美团外卖评价次日展示，早上处理正合节奏），10 分钟内审核发布完当日回复——差评的黄金处理窗口是 24 小时。

## 边界与安全

- 只产出草稿，**不自动发布**：回复代表品牌，人工审核是必要环节
- 高危差评（异物、腹泻、受伤等）给的是处理指引而非话术应付
- 数据本地处理，输出自动脱敏
- 需要全自动拉取评价、定时汇总、多门店汇总？属于 API 对接定制服务，见下方联系方式
