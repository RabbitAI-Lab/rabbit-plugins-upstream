# 学习计划表模板规范 (v2.0.2)

> ⚠️ v2.0 新增：支持用户自定义模板。

## 自定义模板编写指南

### 占位符模式（推荐）

在 Excel 模板中放入 `{{DAILY_DATA}}` 占位符，Skill 自动在占位符位置插入按天分组的视频数据。

**可用占位符**：

| 占位符 | 说明 | 是否必须 |
|--------|------|----------|
| `{{DAILY_DATA}}` | 数据插入标记点 | **必须** |
| `{{COURSE_TITLE}}` | 课程大标题 | 可选 |
| `{{REGISTRATION_INFO}}` | 报名阶段说明文字 | 可选 |
| `{{PHASE_TITLE}}` | 精讲阶段标题 | 可选 |
| `{{EXAM_INFO}}` | 考试介绍内容 | 可选 |
| `{{EXAM_PHASE}}` | 考试阶段内容 | 可选 |
| `{{SCORE_INFO}}` | 成绩查询内容 | 可选 |

**占位符模板编写要点**：
1. 占位符放在数据应出现的位置（通常紧接表头行下方）
2. 表头行必须在占位符行上方（尽量紧邻）
3. 占位符行上方的所有内容原样保留
4. 占位符行下方的所有内容原样保留（如考试信息区）
5. 表头列名推荐使用中文关键词（见下方自动检测关键词），以便列映射

### 自动检测模式

如果模板不含占位符，Skill 扫描表头行匹配以下关键词：

| 字段 | 匹配关键词 |
|------|-----------|
| 时间安排 | 时间安排、日期、天次、第.*天 |
| 学习时长 | 学习时长、时长、课时 |
| 学习章节 | 学习章节、章节、课程内容 |
| 学习目标 | 学习目标、目标 |
| 目标验证 | 验证方式、目标验证、验证 |
| 学习内容 | 学习内容、知识点 |
| 项目实战 | 项目实战、实战 |
| 综合项目 | 综合项目、综合实战 |
| 课后作业 | 课后作业、作业 |
| 学习要求 | 学习要求、学习方法、要求 |
| 学习资料 | 学习资料、资料 |

## 内置默认模板（向后兼容）

> ⚠️ 使用前必读

| 约束项 | 规则 |
|--------|------|
| **输出路径** | 必须为 .xlsx 扩展名；禁止写入系统目录（C:\Windows, /etc, /bin 等）；禁止路径遍历（../） |
| **输入校验** | 每日学习时长: 0.25–16h；视频数量上限: 500；标题长度上限: 300字符 |
| **防注入** | 视频标题自动对 `= + - @` 前缀加单引号转义，防止 CSV/Excel 公式注入 |
| **默认文案** | 所有默认文案已通用化，不含特定平台、机构或个人信息 |
| **日志安全** | 脚本不输出完整文件路径到 stdout |

## 列定义（B→L，A列留白）

| 列 | 字母 | 宽度 | 内容 | 说明 |
|----|------|------|------|------|
| 1 | B | 14 | 时间安排 | "第X天"，同天行合并 |
| 2 | C | 13 | 学习时长（H） | 视频时长小时数，2位小数 |
| 3 | D | 44 | 学习章节 | 视频标题原文，自动防注入 |
| 4 | E | 38 | 学习目标 | 学员学完应达到的能力 |
| 5 | F | 34 | 目标验证方式 | 如何检验目标达成 |
| 6 | G | 44 | 学习内容 | 视频覆盖的知识点编号 |
| 7 | H | 16 | 项目实战 | 空或课程项目 |
| 8 | I | 16 | 综合项目实战 | 空或综合项目 |
| 9 | J | 16 | 课后作业 | 统一填写 |
| 10 | K | 18 | 学习要求及方法 | 同天合并 |
| 11 | L | 18 | 学习资料 | 同天合并 |

## 行结构

```
R1  大标题（深蓝底白字，14pt）
R2  学员培训报名阶段【开课前完成】（蓝底白字）
R3  报名说明（灰底黑字，3条）
R4  精讲阶段【X月XX日-X月XX日 共约N课时】（蓝底白字）
R5  空行分隔
R6  表头（浅蓝底白字）
R7+ 数据区（每天一组 + 小计行）
---  考试介绍和备考资料（蓝底白字标题 + 灰底内容）
---  考试阶段
---  成绩查询和证书维持
```

## 从 Excel 读取视频（替代方式）

```json
{
  "course_name": "...",
  "daily_hours": 2,
  "input_excel": {
    "path": "用户提供的Excel文件路径",
    "sheet_name": "Sheet1",
    "title_col": 1,
    "dur_col": 2,
    "header_row": 1
  },
  "output": "output/学习计划.xlsx"
}
```

> ⚠️ `input_excel.path` 必须来自用户明确提供的文件路径，Agent 不得自行扫描或推断。
