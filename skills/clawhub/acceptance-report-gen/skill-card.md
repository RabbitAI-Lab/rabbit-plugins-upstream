## Description: <br>
Generates system acceptance reports by consolidating test execution results, functional acceptance conclusions, and performance and security assessments. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[golngod](https://clawhub.ai/user/golngod) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
QA, delivery, and engineering teams use this skill to turn user-provided test results, module verdicts, defect lists, and performance or security assessments into a structured acceptance report. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated acceptance conclusions can influence delivery decisions when the supplied test, performance, or security data is incomplete or incorrect. <br>
Mitigation: Review the report and final conclusion against source test evidence before using it for delivery decisions. <br>
Risk: Publisher provenance is third party and server-resolved GitHub import provenance is unavailable. <br>
Mitigation: Confirm the publisher identity before installation when author provenance matters. <br>
