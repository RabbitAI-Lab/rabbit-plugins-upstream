# zentao-work-stats — 禅道用户工作内容分析报告生成器

连接禅道数据库，通过主表 + zt_action 操作日志综合追踪指定用户在指定时间段内的所有工作内容（需求、任务、Bug、工时），生成完整的 Markdown 分析报告。

⚠️ **安全和隐私警告**：
- 本技能访问用户工作数据，必须获得明确授权
- 仅用于合法的工作分析和绩效评估（经授权）
- 报告包含敏感信息，请妥善保管
- 使用只读数据库账号，遵守最小权限原则

## 功能

- **双表追踪**：通过 zt_action 操作日志 + 主表联合分析，不遗漏任何工作记录
- **需求分析**：追踪用户创建、指派、编辑、评审的所有需求
- **任务分析**：追踪用户创建、完成、关闭的所有任务，含工时统计
- **Bug 分析**：追踪用户提交、修复、关闭的所有 Bug，含严重度分布
- **工时统计**：汇总 zt_effort 日志，按对象类型和月度统计
- **月度趋势**：按月统计操作次数，展示工作节奏
- **产品分布**：统计用户在各个产品中的参与度

## 依赖

- Python 3.8+
- pymysql（需要用户自行安装）
- 禅道数据库访问权限（只读即可，需要 SELECT 权限）

## 使用

当需要生成禅道用户工作报告时，激活此 skill：
- "生成禅道用户工作报告"
- "创建禅道工作统计"
- "输出禅道工作分析报告"

**必须提供信息**：
- 目标用户账号（如 `WHF01089`）
- 分析的时间范围（如 `2026年`、`2026-01-01 到 2026-07-23`）

## 配置

数据库连接信息在 `config.json` 中配置。

⚠️ **重要**：
- 不要将 `config.json` 提交到公共代码仓库
- 使用环境变量或配置管理工具存储敏感信息
- 确保文件权限仅限授权用户访问
