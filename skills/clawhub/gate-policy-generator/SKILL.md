## 痛点
- agent **越权**调用它不该碰的工具（删库、外发、改配置）
- **误删误发**：没有二次确认，一条指令就真发出去了
- **失控循环**：agent 自己转圈跑飞，烧光 token 还不停
- 团队**没有统一权限边界词汇**，各 agent 各说各话
