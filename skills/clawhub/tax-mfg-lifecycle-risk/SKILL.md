## 能为你做什么（制造业涉税风险六大场景）
---

### 一、设立阶段税务
- 🏭 **股改个税**：有限公司变股份公司净资产折股，个人股东留存收益转增按20%缴个税。
- ⚠️ **高频风险**：资本公积（股本溢价）转增口径混淆、非货币出资未备案递延。
- 🛡️ **合规设立**：技术成果投资入股可递延，技术合同认定登记，非货币出资合规。

**典型问法：**
```
"股改净资产折股要交个税吗？"
"非货币出资怎么交税？"
```

### 二、运营阶段进项与增值税务
- 📊 **进项分类**：建立可抵扣/不得抵扣清单，不得抵扣项作转出。
- ⚠️ **高频风险**：集体福利/非正常损失违规抵扣、接受虚开发票。
- 🛡️ **四流一致**：核验发票流/资金流/合同流/货物流，防范虚开。

**典型问法：**
```
"制造业进项怎么分类管理？"
"出口退税单证怎么管理？"
```

### 三、研发加计与加速折旧
- ⚙️ **双优惠协同**：研发加计100%、固定资产≤500万一次性扣除、大型设备分期权衡。
- ⚠️ **合规要点**：盈利年度优先一次性扣除，亏损年度权衡后期抵扣。
- 🛡️ **辅助账同源**：研发费辅助账与A107012一致，研发/生产领料区分。

**典型问法：**
```
"固定资产加速折旧怎么选？"
"研发费辅助账怎么建？"
```

### 四、小税种与环境税
- 🌿 **环保税**：按监测或排污系数按季申报，排放数据留痕。
- 🪨 **资源税**：原矿/选矿分别核算，应税产品销售额计量准确。
- ⚠️ **风险点**：房产税自用/出租划分、城镇土地使用税免税土地误用。

**典型问法：**
```
"环保税怎么申报？"
"资源税怎么核算？"
```

### 五、重组与扩张税务
- 🔄 **特殊性处理**：满足合理商业目的/资产股权≥50%/经营连续/权益连续。
- 🔗 **债资比**：关联方借款利息超标（一般>2:1）不得扣除，须监测。
- ⚠️ **风险点**：合并分立股东一致性未达成、跨区域预缴分摊错误。

**典型问法：**
```
"企业重组特殊性税务处理条件？"
"关联方债资比超标怎么办？"
```

### 六、清算与注销清税
- 🧾 **清算所得**：全部资产可变现价值减净值减费用税费加债务清偿损益。
- 👤 **剩余财产**：超投资成本部分个人股东按20%缴个税。
- ⚠️ **风险点**：未清税即注销、资产处置未缴土增/增值税。

**典型问法：**
```
"清算所得怎么算？"
"注销前税务怎么清？"
```

## 重要提示与边界声明

**重要提示**
1. **口径以官方为准**：政策文号、比例、时限以税务总局/财政部/生态环境部最新规定为准，落地前须联网核验。
2. **分阶段管控**：以"事前防范—事中控制—事后监督"三位一体管理五阶段风险。
3. **进项须分类**：不得抵扣项目须标注隔离并作进项转出，防范违规抵扣。
4. **提前规划**：股改、重组、清算等重大交易须前置税务规划。

**边界（本技能不做的）**
- **不代办**：税务登记、优惠备案、注销清税等需登录操作的事项
- **不代理**：税务争议代理等需执业资质的事务
- **不担保**：优惠认定、稽查结论等最终以主管机关为准

**服务说明**
- 每次提问都能获得完整闭环：智能问答 → 结构化结果 → 政策依据溯源 → 真实案例关联 → 实操辅导 → 反馈评价 → 合规报告

**隐私保护**
- 仅在本机生成随机匿名标识用于服务调用，不会采集任何设备信息或个人隐私数据。
