# 每日提醒任务

题库建好后，为用户创建一个每日定时任务，到点自动用默认浏览器打开题库。

## 必须理解的约束：localStorage 同源隔离

题库的**全部**学习数据都存在浏览器 localStorage：练习进度、错题本、收藏、
打卡记录、以及每道题的记忆强度 `ease`。localStorage 按「来源（origin）」严格隔离。

```
用户双击 index.html   → file:///D:/.../index.html        → 数据仓库 A
内置预览面板打开       → http://127.0.0.1:<随机端口>/...  → 数据仓库 B（端口每次还会变）
```

**因此：提醒任务绝对不能用 `present_files` 或任何本地 HTTP 预览方式打开题库。**
那样用户会看到一个进度全空的题库，并且此后数据在两个仓库之间永久分裂，无法合并。

正确做法是调用 `scripts/open_quiz.py`，它始终以 `file://` 打开系统默认浏览器，
与用户平时双击的行为完全一致。

同理，也要提醒用户：**不要把站点目录换位置**。文件路径变了，`file://` 的 URL 就变了，
在 Chrome 等浏览器上可能读不到原来的数据。如果确实要移动，建议先在设置页导出数据。

## 创建任务

先问用户希望几点被提醒（这是唯一需要询问的参数），然后创建：

```
automation_update(
  mode        = "create",
  name        = "每日复习提醒 · <题库名>",
  scheduleType= "recurring",
  rrule       = "FREQ=DAILY;BYHOUR=<小时>;BYMINUTE=<分钟>;BYSECOND=0",
  cwds        = "<站点所在的工作目录>",
  prompt      = <见下方模板>,
  status      = "ACTIVE"
)
```

`rrule` 示例：

| 用户说 | rrule |
| --- | --- |
| 每晚 8 点 | `FREQ=DAILY;BYHOUR=20;BYMINUTE=0;BYSECOND=0` |
| 每天早上 7:30 | `FREQ=DAILY;BYHOUR=7;BYMINUTE=30;BYSECOND=0` |
| 只在工作日晚 9 点 | `FREQ=WEEKLY;BYDAY=MO,TU,WE,TH,FR;BYHOUR=21;BYMINUTE=0;BYSECOND=0` |

## prompt 模板

任务的 prompt 只描述要做的事，**不要**写调度时间或工作目录（那些由参数承载）。

```
用系统默认浏览器打开本地题库，提醒用户完成今天的复习。

执行步骤：
1. 运行命令打开题库（这是唯一正确的打开方式，不要用预览面板）：
   <python> "<skill-dir>/scripts/open_quiz.py" "<站点绝对路径>"
2. 用一句话提醒用户开始今日复习，附带一句简短的鼓励。
   语气自然、不说教，每天换一种说法，不要千篇一律。

注意：题库的学习进度存在浏览器本地存储中，你无法读取。
所以不要声称「你今天有 N 道题待复习」或「你已连续打卡 N 天」——这些数字你拿不到，
说了就是编造。只需把页面打开并给一句鼓励即可。
```

最后一段至关重要。Agent 读不到 localStorage，若不明确禁止，它很容易编造具体数字，
用户打开一看对不上，信任立刻崩塌。

## 创建后告知用户

创建成功后，明确告诉用户三件事：

1. 提醒时间，以及到点会发生什么（自动弹出浏览器打开题库）
2. 可以在**设置 → 数据管理**里查看和管理这个定时任务
3. 学习数据只存在这台电脑的这个浏览器里，清缓存或换浏览器会丢失

## 用户不想要提醒时

若用户明确表示不需要，跳过创建，并在收尾时说明「以后想加随时说一声」即可，
不要反复劝说。
