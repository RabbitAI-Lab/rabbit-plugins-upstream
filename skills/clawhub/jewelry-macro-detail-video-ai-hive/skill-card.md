## Description:

Helps agents turn authorized jewelry product assets into macro-detail video production plans, storyboard prompts, AI-HIVE generation commands, task records, and acceptance checks.

This skill is ready for commercial/non-commercial use.

## Use Case:

External jewelry brands, ecommerce teams, advertisers, and content production agents use this skill to create concise production briefs, shot plans, prompts, runnable AI-HIVE commands, and quality checks for jewelry macro-detail videos. It is intended for workflows where source media, product facts, channel requirements, budget, and review responsibilities are available before generation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: AI-HIVE API key exposure.

Mitigation: Keep the local API key file private and avoid placing real keys in prompts, logs, screenshots, or version-controlled files.

Risk: Unintended upload of selected media to AI-HIVE.

Mitigation: Upload only media files the user has chosen and is authorized to use.

Risk: Paid generation tasks may be submitted with unwanted parameters.

Mitigation: Review the final prompt, model mode, routing mode, and pricing snapshot before running generation; use a small sample before batch work.
