# Harvard quick reference (Cite Them Right baseline)

## Reference list templates

| Type | Template |
|---|---|
| Book | `Surname, Initial. (Year) Title of book. Edition (edn). Place: Publisher.` |
| Journal | `Surname, Initial. (Year) 'Title of article', Journal Name, Volume(Issue), pp. page-page. doi: 10.xxxx/xxxxx` |
| Chapter | `Surname, Initial. (Year) 'Title of chapter', in Editor, F. (ed.) Book title. Place: Publisher, pp. xx-xx.` |
| Web page | `Surname, Initial. (Year) Title of page. Available at: URL (Accessed: Day Month Year).` |
| Report | `Organisation (Year) Title of report. Report number. Place: Publisher. Available at: URL (Accessed: date).` |
| Newspaper | `Surname, Initial. (Year) 'Title of article', Newspaper Name, Day Month, p. x.` |

## In-text

| Situation | Example |
|---|---|
| Parenthetical | (Smith, 2024, p. 12) |
| Narrative | Smith (2024, p. 12) argues ... |
| Two authors | (Smith and Jones, 2024) |
| 3+ authors | (Smith et al., 2024) [Cite Them Right; some variants list all] |
| No date | (Smith, no date) |
| Secondary source | (Eriksson, 1984, cited in Willman, 2022, p. 203) |
| Direct quote | 'quote text' (Smith, 2024, p. 12) |
| Multiple | (Smith, 2024; Jones, 2023) alphabetical, semicolon |

## Signature marks

- Article/chapter titles: single quotation marks. Book/journal titles: italics.
- Online sources: `Available at: URL (Accessed: Day Month Year)` — mandatory.
- Edition: `(3rd edn)`. Editors: `(ed.)` / `(eds.)`.
- `p.` single page, `pp.` ranges, hyphen in ranges.
- Corporate authors spelled out; no publisher location in modern variants.
- List alphabetical by lead author; same author+year: `(2024a)`, `(2024b)`.
- Only sources cited in text appear in the list, and every citation has an entry.

## Variant warning

Harvard is a family, not a standard. Lock the local variant (module handbook, Cite Them Right, institutional guide) before writing and stay consistent. Known divergence points: place of publication, et al. threshold, quotation mark style, doi formatting, Accessed-date requirement.
