## Description:

Use the Feng Shui API through an OOMOL-connected account to search and read Feng Shui data.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External users and developers use this skill to query Feng Shui API for zodiac, compatibility, calendar, house-direction, and Lu Ban ruler calculations through an OOMOL-connected account.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup may run unverified installation code or make lasting agent changes through automatic skill synchronization.

Mitigation: Review the CLI release, require approval before running an installer, and review or disable automatic skill synchronization (OO_SKILLS_SYNC_DISABLED).

Risk: Calculation inputs are sent through OOMOL to Feng Shui API.

Mitigation: Submit only information you intend to share.
