# SHEIN 图搜同款方法

## 适用问题

- 用户上传照片、截图、商品图或图片链接，希望找视觉相似商品。
- 判断某个外观在 SHEIN 的销量、价格带、竞争密度与切入空间。
- 对视觉候选继续按类目、托管模式、销量、价格、评分或上架时间筛选。

调用契约见 [图搜同款接口](SHEIN图搜同款接口.md)，商品字段与筛选语义见 [商品搜索接口](SHEIN商品搜索接口.md)。

## 工作流

1. 直接提交原图，不先将图片主观改写为关键词。
2. 图搜形成阈值内视觉候选池，再用商品条件筛选。
3. 用户只要相似商品时返回代表性结果；用户要完整分析时保持同图、同筛选，仅改变页码，以每页 200 条翻完服务端候选池与筛选条件的全部交集。
4. 用销量、销售额、价格、上架时间、评分、评论数、同款数（跟卖数）和店铺实力交叉判断。
5. 需要痛点时取得明确商品 ID 后再查评论。

## 边界

- 视觉相似不保证同工厂、同材质、同规格、同质量或知识产权状态。
- 服务端单次视觉候选池最多 1000 个；`total=1000` 时可能已触及候选上限，不能称 SHEIN 全平台全部同款。
- 接口未返回可验证的相似度分数时，不宣称结果按“最相似”排序；只称视觉候选。
- 用户指定业务排序后，结果代表候选池内的业务指标排序，不再代表图像相似顺序。
- `similarNum` 对外统一称为“同款数（跟卖数）”，并遵守商品搜索的竞争评估口径。
- 侵权、商标、版权、外观专利与供应链真实性必须另行核验。
