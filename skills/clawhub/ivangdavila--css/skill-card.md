## Description: <br>
Writes and debugs CSS for layout, stacking, responsive behavior, theming, render performance, component styling, cross-engine compatibility, print output, and modern CSS features, while excluding visual design taste decisions such as palette, spacing scale, and typeface choice. <br>

This skill is ready for commercial/non-commercial use. <br>

[ivangdavila](https://clawhub.ai/user/ivangdavila) <br>

## Use Case: <br>
Developers and engineers use this skill to diagnose CSS failures, author production styles, modernize stylesheets, and tune browser compatibility, accessibility, responsiveness, and rendering performance. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may retain CSS-related preferences and memory in ~/Clawic/data/css/. <br>
Mitigation: Review or delete config.yaml and memory.md in that directory if retained CSS preferences are not desired. <br>
Risk: CSS recommendations can depend on project conventions and target browser support. <br>
Mitigation: Confirm the relevant support target and test generated CSS in the target engines before release. <br>
