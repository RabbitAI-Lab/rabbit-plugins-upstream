# ZHC 桥报文协议（OFFICE-WEB 2.4 / 线上协议 1.0）

桥是 ZHC 程序导出 Office 与网页产物的后端。它被语言内核以**常驻子进程**方式拉起，
stdin/stdout 按行交换 JSON：一行一个请求，一行一个响应，无长度前缀、无帧头。

## 一、进程约定

| 项 | 值 |
|---|---|
| 启动方式 | 内核 fork 出 `python -X utf8 桥/zhc_bridge.py`，`cwd` 与标准流由内核接管 |
| 编码 | UTF-8；读入时容忍 BOM（`utf-8-sig`） |
| 换行 | 一律按字节读 `\n`，避免 Windows 文本模式把 `\r\n` / `\x1a` 当作结束 |
| 超时 | 单次调用 30 秒，超时判 `B006` |
| 生命周期 | 随宿主进程存活；`桥可用()` 为假时内核不再尝试重启，直接走降级 |
| 定位 | 默认查找「与 `zhc.py` 同级的 `桥` 目录」，路径在编译期烧入产物；可用环境变量 `ZHC_BRIDGE_HOME` 覆盖 |

## 二、请求

```json
{"版本":"1.0","模块":"表","方法":"导出xlsx","参数":{ }}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `版本` | 是 | 必须为字符串 `"1.0"`，否则 `B002` |
| `模块` | 是 | `表` / `文档` / `页面` / `桥` |
| `方法` | 是 | 见方法表，不存在则 `B001` |
| `参数` | 否 | 必须是 JSON 对象，缺省视为 `{}`；非对象则 `B004` |

## 三、响应

成功：

```json
{"成功":true,"结果":{"路径":"库存.xlsx","行数":120,"列数":6,"字节":1654}}
```

失败：

```json
{"成功":false,"错误":{"码":"B004","信息":"参数校验失败：某行元素个数与列数不一致"}}
```

**约定**：任何异常都必须转成响应，禁止把栈打到 stdout；栈信息只允许写 stderr。
跨进程绝不能出现「响应是半截 JSON」或「响应是纯文本日志」——内核遇到非协议 JSON 一律判 `B002`。

## 四、方法表

| 模块 | 方法 | 产物 | 默认后缀 |
|---|---|---|---|
| `表` | `导出csv` | CSV（UTF-8 带 BOM） | `.csv` |
| `表` | `导出xlsx` | Excel 工作簿（纯标准库手写 OOXML） | `.xlsx` |
| `文档` | `导出docx` | Word 文档（标题 + 段落 + 表格） | `.docx` |
| `页面` | `导出html` | 响应式静态页（流体排版，不含 script） | `.html` |
| `桥` | `版本` | 返回协议版本与已支持产物清单 | — |

## 五、参数结构

### 通用表格参数（`表`、`文档`、`页面` 共用）

```json
{
  "列": [{"名":"编号","类型":"整数"}, {"名":"名称","类型":"文本"}],
  "行": [[1,"螺母"], [2,"垫片"]],
  "路径": "D:/出库/库存.xlsx",
  "工作表": "数据"
}
```

| 字段 | 必填 | 约束 |
|---|---|---|
| `列` | 是 | 数组，元素必须含 `名` 与 `类型`；`类型` ∈ 11 个中文类型名 |
| `行` | 是 | 二维数组，**每行元素个数必须等于列数**，否则 `B004` |
| `路径` | 否 | 绝对路径或相对 `cwd` 的路径；缺省按「时间戳 + 默认后缀」生成 |
| `标题` | 否 | 文档/页面标题，缺省 `ZHC 数据页` |
| `段落` | 否 | 仅 `文档.导出docx` 使用，字符串数组，渲染在表格之前 |
| `工作表` | 否 | 仅 `表.导出xlsx` 使用，缺省 `数据` |

## 六、错误码

| 码 | 含义 | 触发条件 | 上层处置 |
|---|---|---|---|
| `B001` | 后端不存在或已断开 | 桥脚本缺失、进程退出、方法未注册 | 内核标 `桥可用()` 为假，之后不再拉起 |
| `B002` | 报文非法 | 请求非 JSON 对象、版本不符、响应不是协议 JSON | 视为实现缺陷，须修，不允许吞掉 |
| `B003` | 缺依赖 | 该产物所需第三方库缺失 | 让 ZHC 侧走降级路径 |
| `B004` | 参数校验失败 | 列/行结构不合法、行列不齐、`参数` 非对象 | 修调用方，不重试 |
| `B005` | 写盘失败 / 内存不足 / 后端异常 | 目录不可写、磁盘满、内部异常 | 换路径后重试一次，仍失败则上报 |
| `B006` | 调用超时 | 单次超过 30 秒 | 缩短数据量或换路径，不无限重试 |

## 七、降级规则（重要）

| 产物 | 桥失败时的行为 |
|---|---|
| `表.导出xlsx` | **自动降级为 CSV**，返回 `{"成功":true,"降级":true,"实际格式":"csv"}` |
| `文档.导出docx` | **不降级**，原样返回 `{"成功":false,"错误":{"码":"B001"}}` |
| `页面.导出html` | **不降级**，原样报错 |

智能体据此判断：拿到 `降级:true` 说明产物是 CSV 而非 xlsx，不得向用户谎称产出了 Excel。

## 八、自检

```bash
python -X utf8 scripts/zhc.py scripts/示例/导出表格.zc --run
```

- 桥可用：产出 `库存.xlsx`（约 1654 字节），终端打印导出行列数。
- 桥不可用：产出同名 `.csv`，报文含 `降级:true`。

单测桥本身：

```bash
echo {"版本":"1.0","模块":"桥","方法":"版本","参数":{}} | python -X utf8 scripts/桥/zhc_bridge.py
```
