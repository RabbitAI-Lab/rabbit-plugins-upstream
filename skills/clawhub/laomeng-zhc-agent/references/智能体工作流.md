# 智能体工作流（ZHC 智能体身份）

本文件面向**调用 ZHC 生态的智能体**：给你一套可复现的动作序列、判据与失败处置，
让你在一台没装过 ZHC 的机器上也能把中文源码跑到出产物。

## 一、开工三步探测

```bash
python -X utf8 scripts/zhc.py --api        # 1. 反射语言面：关键字/类型/内置/错误码
python -X utf8 scripts/zhc.py <样例.zc> --诊断   # 2. 期望 {"ok": true}
python -X utf8 scripts/zhc.py <样例.zc> --run    # 3. 期望打印预期结果
```

三步都过，才认为环境就绪。任一步失败，先读中文报错原文——ZHC 的错误信息是可读的，
不要跳过报错直接猜。

`--api` 返回的关键计数（0.2.4 / ZHC-LANG-1.0）：关键字 44、类型名 11、内置函数 39、错误码 38。
若实际数值与此不符，说明内核被替换过，后续所有判据都要重新校准。

## 二、写代码的硬约束（实测踩过坑）

1. **函数参数必须写 `名:类型`**。`函数 平方(甲) 返回 整数` → `E014 参数名非法`；
   正确写法 `函数 平方(甲:整数) 返回 整数`。
2. **没有 `break` / `continue`**。循环只能靠条件或标志位退出；
   写 `结束循环` → `E202 无法识别的语句起始 '结束'`。
3. **`结束` 是块闭合关键字**，用于闭合 `如果`、`循环`、`当`、`函数`。但不得写成
   `结束循环`（四字连写）——语言里没有这个关键字，会报 `E202`。
4. 字符串用半角双引号，字符串拼接用 `,` 连接 `输出` 的参数，或 `+` 连接两个文本。
5. 类型名写中文：`整数 浮点 文本 逻辑 字节 无符号 指针 表 记录 列表 任意值 空`。
6. 注释用 `#` 到行尾。

## 三、编译与运行

| 动作 | 命令 | 判据 |
|---|---|---|
| 仅编译 | `python -X utf8 scripts/zhc.py 源.zc` | 退出码 0，生成同名 `.exe`（默认保留 C 中间文件） |
| 编译并运行 | `... 源.zc --run` | 标准输出即程序输出 |
| 仅诊断 | `... 源.zc --诊断` | `{"ok": true}` |
| 限时运行 | `... 源.zc --run --运行限时 5` | 超时按失败处理，防止死循环拖垮宿主 |
| 看生成的 C | `... 源.zc --emit-c` | 打印 C 源码 |
| 保留 C | `... 源.zc --keep-c` | 落盘 `源.c` |

产物默认落在**源文件所在目录**，不是 `cwd`。

## 四、Office 与网页产物

调 `表.导出xlsx` 一类内置函数时，桥（`scripts/桥/zhc_bridge.py`）必须与内核同级可寻址。
细节见 `references/桥报文协议.md`。智能体必须处理的两种情况：

- 返回含 `"降级": true` 且 `"实际格式": "csv"` → 实际产物是 CSV，向用户回报时必须说明格式；
- 返回 `{"成功": false, "错误": {"码": "B001"}}` 且目标是 docx/html → 不降级，属硬失败。

## 五、改代码前的合规红线

本生态按「分级门禁 + 冻结台账 + 缺陷挂账」推进，智能体动手前必须遵守：

1. **每版只增不改**：已冻结的关键字、内置函数签名、样本语义不得修改；新增走纯增量。
2. **正常不回退**：版本只进不退；只有故障触发才允许回退，且回退须留账。
3. **契约先行**：改语言面必须先升契约版本、跑祖先级回归门禁至零漂移，再动内核。
4. **冻结件可审计**：每次冻结必须产出快照 + SHA256 + 案卷，登记到冻结清单，不得只在口头声明。
5. **架构自检全绿才冻结**：9 项自检（C01~C09）必须全 PASS；有 WARN/FAIL 时不得立新冻结条目。

## 六、失败处置顺序

```
报错 → 读中文原文定位码位 → 对照 references/错误码表_E_1.0.md
     → 改源码（最常见：参数缺类型、误写 break）
     → 仍失败：--诊断 是否通过？通过则问题在运行期或产物路径
     → 导出类失败：桥在不在？桥版本能不能应答？
     → 全都不通：不要重试同一命令，改为复现最小样例
```

**禁止**：同一命令重复执行超过 2 次；把中文报错自行翻译成英文后再判断（会丢关键信息）。

## 七、产物回报口径

向用户回报时只讲三类事实：

1. 命令与退出码；
2. 真实落盘的绝对路径（不写"已生成"这类无路径的结论）；
3. 若是降级产物，明确说降级后的格式。

不得凭记忆声称产出过某个文件——必须能给出路径且文件真实存在。
