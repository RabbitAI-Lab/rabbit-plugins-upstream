# 老孟中文编程 · 智能体身份（ZHC Agent）

本技能是 ZHC 生态的**智能体侧**：它不教你写中文代码（那是语言身份 `laomeng-zhc` 的职责），
它教你**如何把 ZHC 装进一个自动化运行环境并稳定跑通**——语言服务接入、编译调度、
桥后端排障、产物降级识别，以及生态演进时不得越过的合规线。

## 身份边界

| | 语言身份 `laomeng-zhc` | 智能体身份（本技能） |
|---|---|---|
| 关心 | 语法、类型、内置函数、错误码 | 协议面、进程、路径、产物、门禁 |
| 产出 | 能通过诊断的中文源码 | 可复现的运行环境与可审计的版本 |
| 判据 | `--诊断` 返回 `{"ok": true}` | LSP 诊断零漂移、桥报文合规、门禁全 PASS |

两套身份共用同一份内核，差异只在标志（智能体标志带朱点）与关注面。

## 何时使用

- 把 ZHC 接入 VS Code 之外的编辑器（Neovim、JetBrains、Sublime、TextMate）；
- 起 LSP 服务、排查"无诊断/补全只有关键字/中文变问号"；
- 让 ZHC 程序导出 xlsx／docx／html，并判断是否发生降级；
- 升级 ZHC 版本、改语言面之前做合规校验；
- 把 ZHC 塞进 CI 或批量流水线，需要可判定的通过/失败口径。

## 环境就绪三步

```bash
python -X utf8 scripts/zhc.py --api                    # 反射语言面
python -X utf8 scripts/zhc.py scripts/示例/基础.zc --诊断   # 期望 {"ok": true}
python -X utf8 scripts/zhc.py scripts/示例/基础.zc --run    # 期望打印结果
```

三步全过才算就绪。任一步失败先读中文报错原文，不要凭经验猜。

## 关键路径约束

1. **内核与语言服务必须同级**：`zhc.py` 与 `zhc_lsp.py` 放同一目录，否则 LSP 启动即退出。
   可用环境变量 `ZHC_HOME` 指定内核目录。
2. **桥必须在 `桥/` 子目录**：默认查找「与 `zhc.py` 同级的 `桥` 目录」，且路径在编译期烧入产物；
   换机器需重编译，或用 `ZHC_BRIDGE_HOME` 覆盖。
3. **Python 解释器必须 UTF-8 模式**：统一加 `-X utf8`；否则中文源码与产物可能乱码。
4. **产物落在源文件目录**，不是 `cwd`。

## 三条高频故障与判据

| 现象 | 判据 | 处置 |
|---|---|---|
| `E014 参数名非法` | 函数参数缺 `名:类型` | 补类型，如 `函数 平方(甲:整数) 返回 整数` |
| `E202 无法识别的语句起始 '结束'` | 误用 `结束循环` | 语言无 break/continue，改条件或标志位退出 |
| 导出拿到 CSV 而非 xlsx | 报文含 `"降级": true` | 桥不可用；向用户回报真实格式，不得谎称 Excel |

## 演进红线（改代码前必读）

1. 每版**只增不改**：已冻结关键字、内置签名、样本语义不得动。
2. **正常不回退**：版本只进不退；仅故障触发回退，且必须留账。
3. **契约先行**：先升契约版本并跑祖先级回归至零漂移，再动内核。
4. **冻结必留痕**：快照 + SHA256 + 案卷，登记冻结清单，禁止口头声明。
5. **架构自检全绿才冻结**：C01~C09 全 PASS；有 WARN/FAIL 不得立新条目。
