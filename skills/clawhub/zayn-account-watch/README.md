# zayn-account-watch

中文名称：客户动态跟踪与商机信号分析  
显示名称：`ACCOUNT_WATCH()`  
版本：v1.0.0

## 核心用途

持续检查已确认企业的官网、LinkedIn、展会或活动官网等公开来源，识别相对历史状态的变化，判断业务相关性与行动价值，并维护去重、处理和观察状态。

> `zayn-account-watch` 是分析 Skill，不是调度器。

## 适用与不适用场景

适用于首次基线扫描、定期增量复查、客户参展或活动窗口、产品/市场/组织变化、招聘与采购线索、合作与风险动态。

不适用于一次性公司背景调查、全网舆情统计、未经验证的商机定性、跟进节奏编排、最终对外话术、私人账号监控或绕过访问限制。

## 输入与最低条件

输入包括客户主体、我方产品/服务与关系背景、来源范围、上次/本次检查时间、跟踪目标和历史状态。正式增量扫描要求主体、可靠官方来源、我方背景、目标、时间边界和可比较历史均明确；缺少上次检查时间时只做近期/基线扫描。

## 运行流程

确认主体和来源 → 选择扫描模式 → 收集带时间的公开动态 → 去重 → 信号分类 → 评估行动价值 → 给出动作与停止条件 → 保存状态。

## 信号与动作

信号分为采购与需求、联系机会、战略变化、风险和弱信号；状态分为强业务、可跟进、观察、风险、无行动价值和信息不足。动作只能从立即联系、活动前/后联系、轻互动、转交、补充调查、持续观察、暂不行动、风险升级中选择。

## 状态管理与去重

保存公司、来源、检查时间、事件 ID、发布时间、首次/最后发现时间、信号类型和状态、动作及结果。相同 URL、同一公告的转载、同内容同时间事件应合并；旧内容再转发不视为新信号；已处理事件仅在实质变化时再次提醒。

## 与自动化和其他 Skill 的关系

自动化负责任务时间和通知，ACCOUNT_WATCH() 负责分析。主体背景交 `zayn-company-research`；阶段性舆情交 `zayn-social-listening`；具体商机、跟进和表达依次交 `zayn-opportunity`、`zayn-followup`、`zayn-reply`。

## 隐私与合规

只使用公开或获授权数据；不监控私人账号，不推断敏感属性，不绕过权限或付费限制，不把个人观点当企业立场，不利用负面事件冒犯式触达。

## 快速示例

“对比 2026-07-01 以来 A 公司官网、LinkedIn 和展会官网的变化。我们提供数据中心备件，希望判断是否有会面或项目线索。”Skill 应先核对主体、来源和时间，再去重并输出信号、行动窗口、风险与状态更新。
