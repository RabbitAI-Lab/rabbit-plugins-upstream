## Description:

Groups keywords into page-level clusters, maps each cluster to an existing or new page, and flags cannibalization using a connected Conqueror MCP server.

This skill is ready for commercial/non-commercial use.

## Publisher:

[samuelnoah45](https://clawhub.ai/user/samuelnoah45)

### License/Terms of Use:

MIT-0

## Use Case:

External SEO practitioners and content teams use this skill to turn keyword lists, saved keyword sets, Search Console data, or domain data into page-level keyword maps, content priorities, and page brief recommendations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can use connected Conqueror project data, including possible Search Console query and page performance.

Mitigation: Install only when this data access is intended, and review the proposed clusters and mappings before relying on them.

Risk: Incorrect keyword clusters, page mappings, or cannibalization labels could lead to misleading SEO content decisions.

Mitigation: Review the mapping summary, cluster table, and page briefs before changing content plans or confirming any tag save action.
