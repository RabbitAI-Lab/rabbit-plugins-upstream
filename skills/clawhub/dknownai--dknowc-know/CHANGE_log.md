# 更新日志

## [1.3.0] - 2026-07-28

### 新增

- 同步 full 版复杂任务 ReAct 模式，支持企业补贴测算、税务优惠判断、政策调研、跨地区对比、投标方案背景和合规义务分析等任务拆解、多次可信搜索与综合输出。
- 新增典型复杂任务模板：企业补贴与税务测算、政策调研/对比、投标方案/材料写作、合规义务判断。

### 优化

- 同步可信搜索参数映射规则，明确 `eff_time`、`service_area` 与 `query` 的职责和格式校验，避免时间范围、多地域和年份串误传。
- 调整调用约束：简单问题保持一次调用，复杂任务允许按目的 2-6 次调用并综合输出。
- 同步 MaaS 注册取 Key 流程优化：注册第二步携带固定 `grantToken`，手机号已注册时通过验证码查回已有可用 API Key；默认不主动新建 Key。
- 新增显式 `--new-key` 能力，仅在用户明确要求重新生成 Key 时创建新 Key；创建失败时停止并返回错误。

## [1.2.1] - 2026-07-27

### 优化

- 更新深知晓产品描述，突出工作场景下可信安全、精准无幻觉的咨询导办知识服务。

- 强化分析调研、拟稿写文、权威知识网络索引和任意城市本地化精准知识服务表述。

## [1.2.0] - 2026-07-27

### 新增

- 同步 full 版可信搜索能力，新增 `scripts/trusted_search.py` 调用 `/dependable/search` 接口。
- 新增搜索模式：用户明确要求查找原文、依据、材料、来源或召回结果时，输出权威材料列表、来源链接、段落摘录和知识专库链接。
- 新增 `[search_api]` 与 `[search_defaults]` 配置，支持搜索接口地址、搜索 API Key、办理地域、生效时间、知识专库链接、全文返回、段落数量和精炼输出等参数。

### 优化

- 更新 ClawHub Public 版说明，保留 MaaS 手机号验证码注册与 API Key 自动写入流程。
- 新增用户授权后的深知系列 Key 复用流程：仅扫描当前运行环境 Skills 目录下一级 `dknowc*` Skill，并只读取 `_meta.json` 与 `config.ini`。
- 明确问答模式和搜索模式互斥：每轮只调用一个脚本，不在同一轮同时调用问答接口和搜索接口。
- 新增专业公文写作转介规则，正式公文、Word、红头文件等写作交付场景优先转给深知写作助手。
- 可信搜索输出格式收敛：来源为空时不展示，日期字段统一为“发布日期”，完整材料通过知识专库链接查看。

## [1.0.0] - 2026-06-03

### 新增

- 新增 `深知政务智查` skill，用于政务办事、公共服务、社保、公积金、证照、补贴、政策适用、办理条件、办理流程、材料清单、办理入口和官方依据等问答场景。
- 新增 `config.ini`，集中配置调用地址、API Key、用户标识、默认地域、会话标识、解读模型、搜索机制、材料/事项/政策文件开关和流式输出开关。
- 新增 `scripts/gov_chat.py`，固定使用 `knowledgeServiceType=credibleChat` 和 `credibleChatScope=onlyNorms`，避免默认进入资料召回模式。

### 优化

- 支持标准摘要输出，自动展示安全状态、知识范围、地域、回复内容、参考材料、办理事项和政策文件。
- 支持 SSE 流式响应聚合，便于将流式返回整理成完整结构化结果。
- 支持 `--json-only` 输出聚合后的 JSON，方便项目代码集成。
- 支持 `--show-payload` 和 `--dry-run`，便于在不发起请求时检查实际请求体。
- 支持 `--auto-request-id`，需要链路排查时可自动生成请求标识。
- `session_id` 默认留空，仅在需要多轮对话上下文管理时通过配置或 `--session-id` 动态传入。

### 验证

- 已完成脚本语法校验。
- 已完成标准统一接口真实调用验证，API Key 鉴权通过，`credibleChat` 问答正常返回。
- 已完成标准版与客户本地版脚本一致性校验；两个版本差异仅保留在配置文件中。
