# 孙子兵法十三篇 → 交易策略翻译

## 1. 计篇 → 庙算评估
原文："夫未战而庙算胜者，得算多也；未战而庙算不胜者，得算少也。多算胜，少算不胜，而况于无算乎！"

交易翻译：开仓前必须完成系统评估（趋势/情绪/基本面/资金四维打分），得分不足则不开仓。

执行规则：
- 四维打分：趋势30% + 情绪30% + 基本面20% + 资金20%
- 总分<6 → 不交易
- 每次交易必须记录庙算理由，事后复盘验证

## 2. 作战篇 → 速战速决
原文："兵贵胜，不贵久。"

交易翻译：短线波段策略，持仓周期明确（建议5-20个交易日），避免长期套牢。

执行规则：
- 开仓时即设定持仓周期上限（20日）
- 超过周期未达目标 → 强制复盘，决定去留
- 追求资金效率，不恋战

## 3. 谋攻篇 → 上兵伐谋
原文："上兵伐谋，其次伐交，其次伐兵，其下攻城。"

交易翻译：优先通过预判和策略赚钱（伐谋），其次靠消息面（伐交），最次靠硬扛（攻城）。

执行规则：
- 优先：提前布局逻辑清晰的板块（政策/业绩预期）
- 次之：跟随板块轮动节奏
- 避免：无脑追涨杀跌硬扛

## 4. 军形篇 → 先胜后战
原文："胜兵先胜而后求战，败兵先战而后求胜。"

交易翻译：只在胜算高时出手。先确认趋势+位置+情绪都占优，再买入。

执行规则：
- 三重确认：趋势多 + 位置低 + 情绪未过热
- 任一缺失 → 降低仓位或放弃

## 5. 兵势篇 → 造势/趋势跟踪
原文："激水之疾，至于漂石者，势也。"

交易翻译：顺势而为。趋势确立后跟随，趋势破坏后离场。

执行规则：
- 多头排列（MA5>MA10>MA20）→ 持有
- 放量突破20日新高 → 加仓信号
- MA5死叉MA20 → 离场信号
- 长上影/天量滞涨 → 势尽预警

## 6. 虚实篇 → 避实击虚
原文："兵之形，避实而击虚。"

交易翻译：不追高（避实），埋伏低位（击虚）。

执行规则：
- 20日涨幅>30% → 实，不追
- 20日涨幅<10% + 缩量回调 → 虚，关注
- 换手率>15%天量 → 实（出货嫌疑）
- 温和放量3-8% → 虚（吸筹迹象）

## 7. 军争篇 → 仓位与速度
原文："百里而争利，则擒三将军。"

交易翻译：仓位过重、追太远 = 风险失控。控制单只仓位，保留现金。

执行规则：
- 单只 ≤ 20% 总仓（高分时）
- 总仓位 ≤ 80%，保留20%现金
- 持仓 ≤ 8 只

## 8. 九变篇 → 应变预案
原文："智者之虑，必杂于利害。"

交易翻译：开仓前必须想好止损/止盈/黑天鹅预案。

执行规则：
- 止损：-8% 或破MA20
- 止盈：+15%减半，+30%清仓
- 黑天鹅：次日无条件减半

## 9. 行军篇 → 观察信号
原文："杖而立者，饥也；汲而先饮者，渴也。"

交易翻译：从量价细节观察主力意图（类似盘口语言）。

执行规则：
- 尾盘急拉 = 次日可能低开
- 早盘急拉回落 = 出货
- 缩量阴跌 = 无人接盘，继续观望
- 放量长阳 + 缩量回调 = 健康

## 10. 地形篇 → 认清处境
原文："知彼知己，胜乃不殆；知天知地，胜乃可全。"

交易翻译：认清自己（资金/风格/心态）和市场环境（牛熊/板块周期）。

执行规则：
- 自评：资金量、风险承受、持仓周期
- 环境：大盘牛熊、板块周期位置
- 不匹配 → 调整策略或空仓

## 11. 九地篇 → 因地制宜
原文："投之亡地然后存，陷之死地然后生。"

交易翻译：不同市场阶段用不同策略。

执行规则：
- 牛市初期：重仓持有
- 牛市后期：逐步减仓
- 熊市：空仓或轻仓短线
- 震荡市：高抛低吸

## 12. 火攻篇 → 情绪控制
原文："主不可以怒而兴师，将不可以愠而致战。"

交易翻译：情绪上头时禁止交易。

执行规则：
- 连续亏损2次 → 强制停手1天
- 当日亏损>5% → 次日不交易
- 追涨冲动 → 先写庙算，不足6分不买

## 13. 用间篇 → 信息情报
原文："明君贤将，所以动而胜人，成功出于众者，先知也。"

交易翻译：消息面要辨真伪，信走势不信消息。

执行规则：
- 利好落地 = 见光死风险
- 公司澄清/问询 = 证伪
- 龙虎榜看主力性质
- 消息与走势背离 → 信走势
