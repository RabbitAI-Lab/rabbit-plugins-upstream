# 回测验证框架（backtest_notes.md）
# 孙子兵法量化交易系统 v1.1.0
# 说明：本文件记录回测思路与验证框架，即使暂无完整历史数据，也给出可复现的验证方法。

## 一、验证目标

验证「六维兵法评分」作为 A 股买卖决策框架的**历史有效性**：

- 胜率（Win Rate）：兵法总分 ≥ 6 时买入，持有 N 日后盈利比例
- 盈亏比（Profit/Loss Ratio）：平均盈利 / 平均亏损
- 最大回撤（Max Drawdown）：按兵法信号满仓模拟的最大净值回撤
- 夏普比率（Sharpe Ratio）：风险调整后收益

## 二、可选标的池（建议）

| 类型 | 示例 | 说明 |
|---|---|---|
| 科技成长 | 半导体ETF、AI ETF、通信ETF | 高波动，兵法虚实篇/势篇信号敏感 |
| 大盘蓝筹 | 沪深300成分股 | 低波动，用于验证风控有效性 |
| 小盘题材 | 换手率>5%的题材股 | 测试用间篇/虚实篇有效性 |
| 持仓复盘 | 用户历史持仓记录 | 最高价值：验证实际执行效果 |

> 建议先跑**用户历史持仓复盘**（已知买卖点），再扩展到公开标的池。

## 三、回测样本区间

- 最短区间：最近 **12 个月**（覆盖一个完整市场周期）
- 建议区间：**2024-01-01 至 2026-12-31**（含牛熊切换）
- 分段验证：牛市（2024Q4-2025Q1）、震荡市（2025Q2-Q3）、回调（2025Q4）、反弹（2026）

## 四、信号定义（回测用）

| 信号 | 触发条件 | 平仓条件 |
|---|---|---|
| 买入 | 兵法总分 ≥ 6 且 军争篇 ≥ 6 | — |
| 加仓 | 兵法总分 ≥ 8 且 势篇 ≥ 7 | — |
| 减半 | 盈利 +15% 或 虚实篇降至 <5 | — |
| 清仓 | 亏损 -8% 或 兵法总分降至 <5 或 盈利 +30% | — |

## 五、回测步骤（可复现）

1. **数据准备**
   - 获取标的日K线（开盘/收盘/最高/最低/成交量/换手率/流通市值）
   - 计算每日 MA5/MA10/MA20、RSI(14)、20日涨幅、60日高低点
   - 获取每日消息标签（公告/澄清/龙虎榜，可用 NLP 分类或人工标注）

2. **逐日评分**
   - 对每日数据跑 `sunzi_score.py`，得到每日兵法总分
   - 生成每日信号序列（买入/持有/减半/清仓）

3. **模拟交易**
   - 初始资金：100,000 元
   - 手续费：单边 0.03%（ETF）或 0.05%（个股）
   - 按信号序列模拟买卖，记录每笔交易

4. **指标计算**
   - 胜率 = 盈利交易数 / 总交易数
   - 平均盈利 = 盈利交易平均收益率
   - 平均亏损 = 亏损交易平均收益率
   - 盈亏比 = 平均盈利 / |平均亏损|
   - 最大回撤 = max(1 - 净值_t / max(净值_1..t))
   - 夏普比率 = (年化收益 - 无风险利率) / 年化波动率

## 六、预期基准（参考）

| 指标 | 随机买入（基准） | 兵法系统目标 |
|---|---|---|
| 胜率 | ~50% | ≥ 55% |
| 盈亏比 | ~1.0 | ≥ 1.5 |
| 最大回撤 | -30% ~ -50% | ≤ -25% |
| 夏普比率 | 0.2 ~ 0.5 | ≥ 0.8 |

> 若回测结果未达目标，优先调整：虚实篇换手率分档阈值、势篇RSI阈值、九变篇止损幅度。
