# 兵法信号明细表

## 趋势信号（势篇）

| 信号 | 条件 | 分值 |
|---|---|---|
| 多头排列 | MA5 > MA10 > MA20 | +3 |
| 放量突破 | 量能>5日均量1.5倍 且 创20日新高 | +3 |
| 站稳突破位 | 突破日收阳且次日不破 | +3 |
| RSI强势 | 50 ≤ RSI(14) ≤ 70 | +1 |
| RSI超买 | RSI(14) > 80 | -2 |
| RSI超卖 | RSI(14) < 30 | +1 |
| 势尽 | 长上影 或 天量滞涨 | -3 |

## 位置信号（虚实篇）

| 信号 | 条件 | 分值 |
|---|---|---|
| 高位 | 20日涨幅 > 30% | -3 |
| 低位 | 20日涨幅 < 10% | +2 |
| 天量 | 换手率 > 15% | -2 |
| 温和放量 | 换手率 3-8% | +2 |
| 高估 | PE/PB > 行业均值50% | -2 |
| 近高 | 距60日高点 < 10% | -1 |
| 近低 | 距60日低点 < 15% | +2 |
