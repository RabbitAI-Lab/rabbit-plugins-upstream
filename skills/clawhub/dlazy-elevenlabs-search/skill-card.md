## Description:

Search the ElevenLabs voice library by keyword, source, and category, with playable previews to help choose a voice for text-to-speech.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers and agents can search the ElevenLabs voice library, filter results by source and category, and review playable previews before selecting a voice for text-to-speech.
