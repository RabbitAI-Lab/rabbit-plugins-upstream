## Description:

Search the ElevenLabs voice library by keyword, source, and category, with playable previews to help choose a voice for text-to-speech.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers can search for ElevenLabs voices using a short description and source or category filters, then review playable samples before choosing a voice for text-to-speech.

### Deployment Geography for Use:

Global
