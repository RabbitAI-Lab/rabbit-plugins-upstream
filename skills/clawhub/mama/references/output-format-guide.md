# 输出格式

默认输出 Markdown。

```markdown
# 多账户邮箱智能体

检查时间：2026-06-27 10:00
检查范围：最近 2 小时
新邮件：5 封
重点邮件：2 封

## 重点事项

### 1. 关于材料报送的通知
- 账号：work
- 发件人：sender@<域名>
- 命中原因：上报、时间要求
- 识别到的时间：6月30日前
- 摘要：……
- 待办：按要求完成材料报送

### 2. 关于培训报名的通知
- 发件人：training@<域名>
- 命中原因：培训
- 摘要：……
- 待办：确认是否需要报名或转发相关同事。
```

无重点邮件时：

```markdown
# 多账户邮箱智能体

本轮已检查，暂无需要重点关注的邮件。
```

## 查阅和快速转发

检查后可使用交互模式：

```bash
python scripts/process_digest.py --since-hours 2 --review
```

流程：

1. 输出可查阅邮件列表。
2. 直接输入序号查看邮件正文、链接和附件。
3. 查看后提示输入对方完整邮箱地址。
4. 发信服务器在初始化时根据邮箱域名自动生成；确认发送时直接转发，否则生成 `.eml` 草稿。
5. 如果本轮检查保存了原始邮件，快速转发会把原始 `.eml` 作为附件附上，便于接收方查看完整邮件。
