## Description:

Report Briefing turns supplied reports, whitepapers, and benchmark studies into grounded, interactive digital-human briefing courses with voice question support.

This skill is ready for commercial/non-commercial use.

## Publisher:

[personwiseai](https://clawhub.ai/user/personwiseai)

### License/Terms of Use:

MIT-0

## Use Case:

Employees, external teams, and agents use this skill to create PersonWise briefing courses from user-supplied reports, whitepapers, or benchmark studies. The resulting course presents the report's findings, methods, and limits while allowing grounded voice questions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may install or update the PersonWise CLI.

Mitigation: Install or update only with explicit approval and only when the user intends to use PersonWise.

Risk: Selected reports or images may be uploaded to PersonWise.

Mitigation: Upload only user-selected materials that the user is comfortable sending to PersonWise.

Risk: Course creation can consume existing course credits.

Mitigation: Create only the authorized number of courses and do not purchase credits automatically.

Risk: A course can be published or changed to link access when requested.

Mitigation: Keep courses private by default and review requested public or link access before publishing.
