## Description:

Use BankGPT to generate, scan, analyze, compare, merge, and summarize financial data assets across the app's invoice, receipt, table, and AI analysis flows.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users can use this workflow to guide financial data from generation or file scanning through analysis, comparison, merging, reusable asset storage, and a final human-readable summary.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Financial files may contain sensitive information when processed and saved through BankGPT.

Mitigation: Before use, consider whether you are comfortable sending financial files to BankGPT and saving records there; avoid sensitive or unnecessary information unless you accept that handling.
