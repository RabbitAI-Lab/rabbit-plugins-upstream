## Description:

Creates structured workflow skills with an orchestrator SKILL.md and supporting phase files.

This skill is ready for commercial/non-commercial use.

## Publisher:

[yumingtao](https://clawhub.ai/user/yumingtao)

### License/Terms of Use:

MIT

## Use Case:

Developers designing multi-stage agent workflows can turn a description, requirements document, existing commands, or an existing skill into an orchestrator and phase-file skill package.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated workflows may include powerful tools without establishing that each tool is needed; the security review was also partially incomplete.

Mitigation: Review the generated workflow and its allowed tools before installation or use, and keep only permissions required for the workflow.
