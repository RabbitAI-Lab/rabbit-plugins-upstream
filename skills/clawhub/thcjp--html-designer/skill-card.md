## Known Risks and Mitigations:

Risk: The skill requests broad read, write, and command execution capability for a design workflow.

Mitigation: Run it only in a trusted workspace or sandbox, review proposed file changes and commands before execution, and limit access to unrelated project files.

Risk: The artifact discusses API keys and external API use without a tight design-specific scope.

Mitigation: Do not provide real API keys unless the exact service, destination, and project data being sent are understood and approved.
