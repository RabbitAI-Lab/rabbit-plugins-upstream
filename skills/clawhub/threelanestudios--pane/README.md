# Pane ClawHub Skill

OpenClaw skill for operating [Pane](https://paneapp.ai) through its local Gateway API.

Published to ClawHub as `@threelanestudios/pane`.

## Publishing

After merging to `main`, publish with:

```bash
clawhub skill publish ./ --slug @ThreeLaneStudios/pane --version <from SKILL.md frontmatter> --changelog "<what changed>"
```

See `PUBLISHING.md` for full reference.
