# 产品案例

## 产品重新打光

```text
对图1产品进行重新打光，重建高光、反射和暗部，背景更换为纯白或干净品牌背景，提高材质质感和光泽，保持主要结构、材质和颜色不变。
```

适用：
- 小设备
- 水杯
- 珠宝
- 手表
- 护肤品
- 家居产品

## 产品场景合成

```text
图1产品放入图2场景中，保持产品结构、颜色和材质不变，匹配场景光线方向、透视关系和真实比例，照片级真实感。
```

常见场景：
- 庭院
- 北欧客厅
- 海边
- 度假村
- 主卧

## 产品角度变换

```text
保持图1产品结构不变，输出正面、左45°、右45°和细节特写，镜头视角和透视关系清晰稳定。
```

## 材质替换

```text
图1产品使用图2的材质或图案，自然贴合产品结构，保持原始比例和主要造型不变。
```

## 产品精修

适用：
