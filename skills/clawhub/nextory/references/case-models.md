# 模特与贴身服饰案例

## 鞋类 / 腿部特写

```text
成年模特仅展示膝盖以下或臀部以下区域，鞋子为视觉中心，姿势自然，双脚完整可见，柔和漫射光，背景简洁，整体为高级编辑风格。
```

## 韩国 / 亚洲模特展示

```text
成年亚洲女性模特穿着图1服饰，韩国潮流或日常时尚风格，姿势专业自然，画面真实上镜，服装结构清晰可见。
```

## 日本成熟氛围风格

```text
成年日本风格女性模特穿着图1服饰，在柔和卧室或生活化场景中进行高级时尚展示，整体气质成熟、迷人但不过度夸张。
```

## 女款贴身服饰

```text
图1为专业女性时装模特参考，图2为贴身服饰产品参考。保持模特身份感、体态和专业气质不变，保持产品版型、结构化上装、肩带、腰头、下摆、细密花纹织物/轻薄网状织物/柔和缎面材质不变。整体为商业服饰目录摄影，端正自然，重点展示剪裁、面料、结构和穿着效果。
```

## 男士贴身下装 / 家居服

```text
图1为专业男性时装模特参考，图2为男士贴身下装或家居服产品参考。保持腰头高度、前片结构、裤腿长度、棉感/莫代尔材质和贴身关系不变，整体为商业男士服饰目录摄影，成熟、简洁、自然。
```

## 配饰展示

写法重点：
- 产品是第一视觉中心
- 面部或身体只是承载体
- 不能遮挡关键结构
