# 产品模板

产品主图、材质特写、官网产品图、四视图先读 `references/ecommerce-product-polish-system.md`。

## 重新打光

```text
对图1产品进行重新打光，重建高光、反射和暗部，背景干净，提高材质质感和光泽，保持结构和颜色不变。
```

## 场景合成

```text
图1产品放入图2场景中，匹配光线方向、透视关系和真实比例，保持产品本体不变。
```

## 角度变换

```text
保持图1产品结构不变，输出正面、45°角、侧面或指定角度展示，透视关系清晰稳定。
```

## 材质替换

```text
图1产品使用图2材质或图案，自然贴合结构，保持主体比例和主要造型不变。
```

## 产品精修

```text
只修改指定褶皱、绑带、表面颗粒或瑕疵，其他部分保持不变。
```
