# 品牌语气层映射表

## 目标

把“轻奢、法式、运动、极简、买手店风”从抽象形容词，变成稳定可见的画面规则。

使用原则：
- 1 个主语气
- 最多 1 个辅助语气
- 直接映射到色板、灯光、构图、材质、道具、模特状态

## 一、轻奢

### 画面特征

- 低饱和中性色
- 细腻面料和金属/皮革高光
- 光线柔和但有轮廓层次
- 留白克制，节奏平稳
- 强调“贵但不浮夸”

### 稳定词库

中文：
- 低饱和奶油色
- 骨白、燕麦、暖灰、深棕
- 柔和轮廓光
- 细腻皮革光泽
- 克制金属高光
- 安静高级感

英文：
- quiet luxury
- understated elegance
- soft sculpted light
- muted neutrals
- refined leather sheen
- restrained premium styling

### 避免跑偏

- 不要高饱和撞色
- 不要大量堆道具
- 不要夸张闪光灯和廉价反光

### 参考观察

- TOTEME：极简、克制、材质先行
- Max Mara：经典、时间感、安静的优雅

链接：
- [TOTEME](https://toteme.com)
- [Max Mara](https://world.maxmara.com)

## 二、法式

### 画面特征

- 暖中性色或低对比日光
- 随性但不凌乱
- 带生活气和呼吸感
- 比轻奢更松弛、更贴近日常

### 稳定词库

中文：
- 巴黎日常感
- 松弛自然
- 亚麻、棉、旧木、奶油墙面
- 窗边柔光
- 微乱但精致

英文：
- parisian ease
- effortless elegance
- warm window light
- lived-in texture
- relaxed tailoring
- soft daytime editorial

### 避免跑偏

- 不要过度精修成冷白棚拍
- 不要把法式写成过于甜腻公主风
- 不要过多奢华金属和镜面材质

### 参考观察

- Sézane：温暖、日常、柔和法式生活感
- A.P.C.：克制、巴黎式简洁和利落

链接：
- [Sézane](https://www.sezane.com)
- [A.P.C.](https://www.apc-us.com)

## 三、运动

### 画面特征

- 动态身体线条
- 清爽高对比或科技冷色
- 结构清晰，功能感强
- 面料弹力、透气和支撑感要写清楚

### 稳定词库

中文：
- 运动功能感
- 清爽高对比
- 肌肉线条清晰
- 弹力支撑
- 透气面料
- 动态姿势

英文：
- performance-driven
- athletic energy
- breathable technical fabric
- dynamic body line
- clean contrast lighting
- active lifestyle campaign

### 避免跑偏

- 不要过度柔美或卧室化
- 不要太多无意义道具
- 不要把运动写成单纯街拍

### 参考观察

- Nike：身体动势、技术面料、清晰功能表达

链接：
- [Nike](https://www.nike.com)

## 四、极简

### 画面特征

- 大面积留白
- 单一主视觉中心
- 色板非常克制
- 线条、轮廓、比例优先

### 稳定词库

中文：
- 大留白
- 干净轮廓
- 纯净背景
- 线条优先
- 冷静理性

英文：
- minimal modern
- clean silhouette
- disciplined composition
- quiet palette
- negative space
- pure backdrop

### 避免跑偏

- 不要叠加太多风格词
- 不要大面积纹理和复杂家具
- 不要把极简写成空洞无质感

### 参考观察

- COS：干净结构、日常奢感、理性构图
- TOTEME：极简但不空，重材质和比例

链接：
- [COS](https://www.cos.com)
- [TOTEME](https://toteme.com)

## 五、买手店风

### 画面特征

- 更强的“被挑选过”的编辑感
- 色调克制但有策展感
- 道具更少，但每件都像被精挑细选
- 模特和商品关系更像陈列与搭配

### 稳定词库

中文：
- 策展感
- 买手店陈列逻辑
- 低密度高质感道具
- 带呼吸感的空间
- 选品感

英文：
- curated boutique mood
- editorial merchandising
- selective styling
- gallery-like spacing
- tactile premium materials
- quiet fashion curation

### 避免跑偏

- 不要把买手店风写成杂乱生活方式图
- 不要过多商业促销语言
- 不要高密度布景和强烈电商感

### 参考观察

- A.P.C.：简洁、克制、材料感强
- TOTEME/COS：视觉上接近策展式陈列

链接：
- [A.P.C.](https://www.apc-us.com)
- [TOTEME](https://toteme.com)
- [COS](https://www.cos.com)

## 六、直接映射规则

当用户只说一个品牌语气词时，默认这样映射：

- `轻奢`：暖灰/骨白/深棕 + 柔和轮廓光 + 皮革/金属细节 + 克制道具
- `法式`：窗边暖光 + 亚麻棉布 + 日常空间 + 松弛身体姿态
- `运动`：功能面料 + 清晰体态 + 高对比或冷调光线 + 动态姿势
- `极简`：纯净背景 + 线条优先 + 大留白 + 单焦点构图
- `买手店风`：策展式空间 + 低密度高质感道具 + 编辑感搭配

## 七、推荐输出格式

当用户要求品牌感时，建议在结果中单独输出：

```text
【品牌语气层】
- 主语气:
- 辅助语气:
- 色板:
- 布光:
- 构图:
- 材质重点:
- 道具密度:
- 文案区:
```

## 八、当前官方案例吸收建议（2026-05）

不要照搬品牌文案或具体画面，吸收的是：
- 视觉秩序
- 色板
- 材质表达
- 模特状态
- 陈列逻辑

推荐优先观察：
- TOTEME：轻奢 / 极简
- Max Mara：轻奢 / 经典
- Sézane：法式
- A.P.C.：法式 / 买手店风
- Nike：运动
- COS：极简 / 买手店风
