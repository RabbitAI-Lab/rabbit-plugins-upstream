# 场景、海报与电商交付案例

## 氛围场景

常见方向：
- 圣诞
- 玄关
- 北欧客厅
- 酒店套房
- 意大利大牌感

写法重点：
- 场景丰富但不盖过产品
- 光线跟随产品逻辑
- 产品结构、颜色、材质不变

## 电商海报

```text
给图1产品做一张电商海报，保留产品本体，设置主标题、副标题和留白区，背景与品牌语气一致。
```

## 电商固定交付格式

### 主图

```text
输出一张主图，产品居中，占画面约80%-85%，背景纯净，阴影克制，适合列表页或首屏展示。
```

### 四视图

```text
输出正面、侧面、背面、细节特写四张图，保持产品一致，仅改变机位与裁切。
```

### 九宫格

```text
输出3x3九宫格，包含hero、正面、背面、侧面、材质特写、结构特写、模特/使用图、卖点图、补充信息图。
```

### 详情页

```text
输出一组详情页视觉，包括hero首屏、材质页、结构页、场景页、细节页、尺寸或覆盖度说明页。
```

## 品牌语气层案例吸收

- 轻奢：安静中性色、轮廓光、细腻材质
- 法式：窗边暖光、松弛生活感
- 运动：功能面料、清晰体态、动态姿势
- 极简：大留白、单焦点、纯净背景
- 买手店风：策展感、低密度高质感道具
