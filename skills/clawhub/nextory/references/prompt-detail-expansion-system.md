# 提示词细节扩写系统

## 目标

把用户的简短需求扩写成信息完整、约束清楚、可直接复制的高质量提示词。

细节扩写不是把形容词堆长，而是补齐画面生成真正需要的信息：
- 主体
- 保留项
- 变化项
- 空间位置
- 镜头与构图
- 光线
- 色彩
- 材质
- 真实细节
- 输出用途
- 负面约束
- 复跑建议

## 一、细节密度比例

一条高质量 prompt 建议按这个比例写：

| 层级 | 占比 | 内容 |
| --- | --- | --- |
| 硬约束 | 35% | 主体、参考图、不可变项、禁止变化项 |
| 空间镜头 | 20% | 位置、比例、视角、景别、焦距、画幅 |
| 质感真实 | 25% | 光线、色彩、材质、皮肤/表面/阴影细节 |
| 风格用途 | 10% | 品牌语气、商业用途、交付格式 |
| 纠错约束 | 10% | 负面词、复跑建议、局部重绘位置 |

如果 prompt 变长，优先保留硬约束、空间镜头和材质真实层，删除空泛风格词。

## 二、扩写顺序

按以下顺序扩写，不要跳：

```text
1. 任务类型：生成 / 改图 / 复刻 / 电商 / 人像 / 产品
2. 参考图角色：图1是什么，图2是什么，图3是什么
3. 不可变项：主体身份、产品结构、颜色、材质、logo、版型
4. 允许变化项：背景、光线、构图、姿态、道具、画幅
5. 主体位置：画面区域、占比、前中后景
6. 角度关系：主体角度、产品角度、镜头角度
7. 人物自然：表情、眼神、重心、手部、皮肤、服装接触
8. 产品精致：边缘、标签、材质高光、阴影、反射、比例
9. 光线色彩：主光方向、补光、阴影、主色、辅助色、点缀色
10. 输出用途：平台主图、官网图、详情页、社媒图、海报
11. 负面约束：只写质量控制和错误避免
12. 复跑策略：如果不准，下一轮先修什么
```

## 三、从短句到完整提示词

### 用户说得很短

用户说：
```text
参考这张图，做人像更自然一点
```

扩写方向：
```text
以图1作为专业人物参考，保持脸型轮廓、五官比例、发型分缝、肤色冷暖、自然妆感、肩颈线条和体态不变。
表情改为轻微放松的自然神态，眼神看向镜头附近但不僵硬直视，身体重心自然偏向一侧，肩膀放松。
使用 85mm 人像镜头，中浅景深，柔和侧前方主光，保留真实皮肤纹理、细小毛孔、自然肤色变化和真实发丝边缘。
```

### 用户要电商产品更精致

用户说：
```text
把这个产品做高级点
```

扩写方向：
```text
以图1作为产品参考，保持产品轮廓、比例、颜色、材质、logo位置、标签区域和关键结构不变。
产品位于画面中央，占画面约 78%-85%，以正面轻微 3/4 视角展示，镜头与产品中线平齐。
使用大面积柔光箱从左前上方打光，右侧保留柔和阴影，底部有自然接触阴影。
材质边缘清晰，表面高光受控，标签平整不变形，背景为干净浅灰或纯白，适合电商首图。
```

## 四、中文与英文分工

中文提示词：
- 更适合表达完整决策
- 写清逻辑、保留项、允许变化项
- 可以包含中文结构化描述

英文提示词：
- 更适合模型执行
- 保留数字、位置、角度
- 用摄影语言和产品摄影语言表达
- 不机械直译中文

英文提示词推荐结构：
```text
Use image [X] as the [role] reference and preserve [locked attributes].
Create [deliverable type] for [use case].
Place [subject/product] at [position], occupying about [ratio] of the frame.
Show it from [angle], photographed from [camera angle] with [lens/framing].
Use [lighting setup], [shadow behavior], [color palette].
Emphasize [material details], [realistic details], [fidelity constraints].
Avoid [quality errors].
```

## 五、详细但不啰嗦的判断

好的详细提示词应该：
- 有数字：占画面比例、旋转角度、镜头高度、留白比例
- 有方向：主光从哪里来、阴影落在哪里、视线看向哪里
- 有层次：前景、中景、背景分别做什么
- 有触感：材质是哑光、柔光、颗粒、细纹、镜面还是半透明
- 有限制：哪些不能变，哪些可以变
- 有用途：主图、详情页、人像头像、官网 banner、社媒广告

不好的详细提示词通常：
- 只有堆词，没有空间关系
- 只有风格，没有主体锁定
- 只有“高级、精致、真实”，没有材质和光线
- 负面词过长且包含无关内容
- 中文和英文信息不一致

## 六、最终自检

输出前检查：
- 是否把用户短需求扩写成完整可执行 prompt
- 是否有参考图角色和不可变项
- 是否写清位置、角度、比例、镜头
- 是否有人像真实层或产品精致层
- 是否有场景化负面词
- 是否给出复跑策略
