# 参考图保真与精确模仿系统

## 目标

把“模仿更精确、1:1还原、照着参考图做”拆成可执行的锁定矩阵。

核心原则：
- 先判断每张参考图承担什么角色，再写提示词
- 先锁定不可变项，再写允许变化项
- 用具体视觉事实替代“像、类似、参考”
- 对高风险细节给出复刻风险提示
- 精确模仿不等于无限复制；只锁定用户提供或授权参考里的视觉特征

## 一、参考图角色矩阵

多图任务必须先分配角色：

| 参考角色 | 必须锁定 | 禁止混淆 |
| --- | --- | --- |
| 人物/模特参考 | 脸型、五官比例、发型、肤色、妆感、体态、气质 | 不要把服装或场景也默认继承 |
| 产品参考 | 结构、比例、颜色、材质、logo位置、边缘细节 | 不要改品牌、logo、结构和关键比例 |
| 服装/面料参考 | 版型、织纹、透明度、垂坠、缝线、褶皱 | 不要只写“同款衣服” |
| 姿势参考 | 身体朝向、手势、重心、裁切、视线方向 | 不要连光线和身份也一起复制 |
| 场景参考 | 空间布局、道具关系、背景层次、景深 | 不要改变主体比例 |
| 风格参考 | 光线、色彩、构图、氛围、胶片/棚拍质感 | 不要迁移具体人物、logo和文字 |

## 二、保真等级

根据用户需求选择一个等级，并在输出里写清。

### L1 风格借鉴

只保留：
- 光线
- 色调
- 构图语言
- 氛围

写法：
```text
仅参考图2的低饱和色调、柔和侧光和留白构图，不复制图2的人物身份、服装款式、logo或文字。
```

### L2 局部高保真

保留主体或产品的关键部分，允许场景、角度、光线变化。

写法：
```text
保持图1产品的瓶身比例、瓶盖结构、正面标签位置、半透明玻璃材质和主色不变，只改变背景、布光和画面构图。
```

### L3 严格复刻

尽可能复刻参考图中的主体、构图、角度、光线、色彩、材质和遮挡关系。

写法：
```text
以图1为严格复刻参考，保持主体身份特征、姿势、镜头高度、画面裁切、光线方向、背景道具位置和整体色调一致，只做必要的画质提升。
```

### L4 电商一致性

用于四视图、详情页、九宫格。每张图变化机位或信息重点，但产品本体必须一致。

写法：
```text
整组图片保持同一产品结构、颜色、材质、logo位置、版型和比例完全一致，每张图只改变视角、裁切和信息重点。
```

## 三、不可变项与可变项

输出提示词前必须列出：

```text
不可变项：
- 主体/产品:
- 脸部/体态:
- 服装/面料:
- logo/文字:
- 构图/角度:
- 光线/色彩:

允许变化项：
- 背景:
- 道具:
- 镜头距离:
- 光线强度:
- 情绪氛围:
```

如果用户没有指定允许变化项，默认只允许：
- 清晰度提升
- 轻微光线优化
- 轻微背景清洁
- 真实感增强

## 四、人物参考保真

当参考图是人物时，提示词需要拆成“身份感”与“自然感”两层。

必须锁定：
- 脸型轮廓：圆脸、鹅蛋脸、长脸、下颌线强弱
- 五官比例：眼距、鼻梁、唇形、眉眼间距
- 发型：长度、分缝、卷直、发量、刘海
- 肤色与妆感：肤色冷暖、底妆轻重、唇色、眉形
- 体态：肩宽、腰臀比例、身高感、站姿重心
- 气质：成熟、松弛、专业、冷淡、亲和

不要写：
- `same person` 作为唯一约束
- `identical face` 但不描述脸部特征
- `perfect skin` 或 `doll-like`

推荐写法：
```text
以图1为成年模特参考，保持图1模特的脸型轮廓、眉眼比例、鼻梁高度、唇形、发型分缝、肤色冷暖、自然妆感、肩颈线条和成熟气质不变；表情只做轻微自然化，保持同一身份感，不改变年龄感和五官比例。
```

英文写法：
```text
Use image 1 as the professional fashion model reference. Preserve the facial outline, eye spacing, brow shape, nose bridge, lip shape, hairstyle parting, skin tone, natural makeup, shoulder-neck line and polished catalog presence. Keep the same identity impression while making only subtle natural expression refinement.
```

## 五、产品参考保真

必须锁定：
- 正面比例
- 轮廓和边角
- logo位置与方向
- 材质反光
- 颜色和透明度
- 包装文字区域
- 接缝、扣件、开口、盖子、拉链等结构

推荐写法：
```text
保持图1产品的整体轮廓、宽高比例、正面 logo 区域、瓶盖/扣件/缝线结构、材质反光、颜色和透明度不变；不新增图1中没有的花纹、文字、配件或结构。
```

## 六、服装/面料参考保真

必须锁定：
- 版型
- 领口、袖口、腰头、肩带、腿口
- 面料纹理
- 厚薄与透明度
- 贴合或垂坠关系
- 缝线位置
- 图案大小和方向

推荐写法：
```text
保持图2服装的领口高度、肩带宽度、腰头位置、腿口包边、缝线走向、面料纹理、透明度和贴合关系不变；面料在身体转折处保留自然张力和轻微褶皱。
```

## 七、精确模仿提示词结构

中文结构：
```text
以[图X]作为[角色]参考，保留[不可变项]。
只允许改变[允许变化项]。
主体位于[位置]，以[产品/人物角度]展示，镜头从[镜头角度]拍摄。
光线保持/调整为[光线方向与质感]，色彩保持/调整为[色彩系统]。
材质必须表现为[材质细节]，避免[错误变化]。
```

英文结构：
```text
Use image [X] as the [role] reference and preserve [locked attributes].
Only change [allowed changes].
Place the subject at [position], shown from [subject/product angle], photographed from [camera angle].
Use [lighting direction and quality], with [color palette].
Emphasize [material details], avoid [forbidden changes].
```

## 八、复刻风险提示

如果存在以下情况，要在输出后加【复刻风险】：
- 小字、logo、复杂图案容易变形
- 手指、首饰、肩带、蕾丝边缘容易错位
- 透明材质、高反光材质容易出现错误反射
- 多人、遮挡、镜面、复杂背景容易改变空间关系
- 参考图分辨率低，无法判断细节

提示写法：
```text
【复刻风险】该图包含小字/logo/手部遮挡/透明材质，模型可能无法一次性稳定复刻，建议先生成整体构图，再对文字、手部或材质细节做局部重绘。
```

## 九、保真自检

输出前检查：
- 是否明确每张参考图角色
- 是否列出不可变项和允许变化项
- 是否把“像”拆成脸型、结构、材质、光线或构图
- 是否禁止新增无关 logo、文字、饰品、花纹
- 是否把产品角度和镜头角度分开写
- 是否说明整组电商图的一致性约束
- 是否给高风险复刻元素单独提醒
