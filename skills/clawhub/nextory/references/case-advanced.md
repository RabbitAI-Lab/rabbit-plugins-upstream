# 高级技巧案例

## 标签控制 / 红框保护

适用：
- 局部不希望被改动
- 局部需要尺寸修正

## 物品识别与描述

先让模型标注识别对象，再基于标注名称重写 prompt。

```text
在图片上用中文标注，你识别的物品名称
```

## 安全合规写法

- 换脸场景：
  - 不写“使用图2的脸”
  - 写“参考图2的角色特征，商业摄影风格”
- 时尚展示：
  - 不写高风险审核词
  - 写“专业时装模特、商业服饰目录语境、端正自然姿态”

## 文案添加

适用：
- 跑步机
- 海报标题
- 电商详情卖点

写法重点：
- 单独列出文案内容
- 明确文字区域
- 如果是复杂小字，建议后期补
