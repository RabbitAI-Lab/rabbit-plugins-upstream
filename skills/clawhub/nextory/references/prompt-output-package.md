# 完整提示词包输出模板

## 目标

让输出不止是一段 prompt，而是一套可直接复制、可复跑、可调参、可局部修复的提示词包。

适用场景：
- 用户说“更完善”
- 用户要直接拿去生成
- 用户要 1:1 复刻或高保真
- 用户要人物更自然
- 用户要人像更真实
- 用户要电商产品图更精致
- 用户要电商成组图
- 用户要 Flux / Nonbana / Nano Banana / Midjourney 等平台提示词

## 一、默认完整输出

```text
【需求理解】
一句话说明要生成什么、保留什么、改变什么。

【参考图角色】
- 图1:
- 图2:
- 图3:

【模仿保真矩阵】
- 保真等级:
- 不可变项:
- 允许变化项:
- 禁止变化项:
- 复刻风险:

【空间与角度蓝图】
- 主体/产品位置:
- 主体/产品角度:
- 镜头角度:
- 占画面比例:
- 前中后景:

【人物自然度控制】（如适用）
- 表情:
- 眼神:
- 姿态重心:
- 手部:
- 皮肤:
- 服装接触:

【人像真实感增强】（如适用）
- 身份保真:
- 皮肤纹理:
- 眼神光:
- 微表情:
- 头发边缘:
- 镜头与光线:

【电商产品精致度】（如适用）
- 产品一致性:
- 产品角度 / 镜头角度:
- 边缘与轮廓:
- 光线与接触阴影:
- 材质表面:
- 背景与留白:

【细节扩写层】
- 硬约束:
- 空间镜头:
- 质感真实:
- 输出用途:
- 复跑策略:

【质感增强层】
- 视觉焦点:
- 光线:
- 色彩:
- 材质:
- 真实细节:
- 风格语气:

【中文主提示词】
可直接复制的一整段中文 prompt。

【English Prompt】
可直接复制的一整段英文 prompt，不机械直译中文。

【保真增强 Add-on】
用于提高参考图一致性的短段落。

【人物自然度 Add-on】（如适用）
用于降低假脸、僵硬姿势、塑料皮肤的短段落。

【人像真实感 Add-on】（如适用）
用于增强皮肤纹理、眼神光、微表情、发丝边缘和真实镜头感。

【产品精致度 Add-on】（如适用）
用于增强产品边缘、标签、反光、接触阴影、材质和背景留白。

【负面提示词】
按任务类型定制，不要只堆通用词。

【生成建议】
- 推荐画幅:
- 推荐镜头/景别:
- 建议先跑整体还是先跑主体:
- 需要局部重绘的位置:
- 如果第一轮不准，下一轮优先修什么:

【质量自检】
- 保真:
- 自然:
- 质感:
- 空间:
- 合规:
```

## 二、短版输出

当用户只要“给我 prompt”时，也不要只给一句。至少输出：

```text
【中文提示词】
...

【English Prompt】
...

【负面提示词】
...

【关键锁定】
- ...

【生成建议】
- ...
```

## 四、平台适配

### Flux / Nonbana / Nano Banana 类

更适合自然语言长句：
- 写完整主体关系
- 写清图1/图2角色
- 写清保留项和允许变化项
- 写清光线、材质、镜头

模板：
```text
Use image 1 as [role] and image 2 as [role]. Preserve [locked attributes]. Only change [allowed changes]. Create [final image]. [position/angle/camera]. [lighting]. [palette]. [materials]. [naturalness/fidelity add-on]. Avoid [negative constraints].
```

### Midjourney 类

更适合主 prompt 加参数：
- 核心画面放前面
- 风格和镜头放中段
- 画幅参数放最后
- 不要把负面词写得过长

模板：
```text
[subject and locked reference], [composition], [lighting], [material details], [style direction], [camera/lens], natural realism --ar [ratio] --style raw
```

### Stable Diffusion / SDXL 类

更适合正负分离：
- 正向 prompt 写主体、材质、镜头、光线
- 负向 prompt 单独放畸形、低质、错误细节
- 如果有参考图，建议配合 ControlNet / IP-Adapter / inpainting 等工作流，但不要在提示词里假装已经控制住

## 五、复跑策略

如果第一轮不够像：
1. 优先强化不可变项，不要先加风格词
2. 减少允许变化项
3. 把“像”改成 5-8 个具体特征
4. 对手部、文字、logo、蕾丝、透明材质做局部重绘

如果第一轮人物不自然：
1. 降低夸张表情
2. 给身体重心和支撑点
3. 简化手部动作
4. 加真实皮肤纹理和自然眼神光
5. 删除 `perfect / flawless / doll-like / ultra smooth`

如果第一轮人像不真实：
1. 增加皮肤纹理、眼神光和微表情
2. 降低磨皮和锐化
3. 给身体重心、肩线和手部动作
4. 明确镜头焦距和主光方向

如果第一轮产品不精致：
1. 强化边缘清晰和接触阴影
2. 增加材质专属细节
3. 明确标签区域和 logo 位置保持不变
4. 减少背景道具，先用白底主图锁定产品

如果第一轮质感不够：
1. 增加光线方向和阴影描述
2. 增加具体材质触感
3. 降低背景道具密度
4. 明确主色、辅助色、点缀色
5. 删除空泛高级感词

## 六、输出自检

输出前检查：
- 是否用户能直接复制主提示词
- 是否英文 prompt 保留了中文关键约束
- 是否有保真增强 Add-on
- 人物任务是否有人物自然度 Add-on
- 人像任务是否有人像真实感 Add-on
- 产品任务是否有产品精致度 Add-on
- 负面词是否按场景定制
- 是否提供失败后的复跑策略
