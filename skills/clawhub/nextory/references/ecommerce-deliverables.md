# 电商固定交付格式指南

## 目标

把“做一套电商图”拆成稳定可执行的交付格式，而不是一条过大的总提示词。

涉及产品主图、官网产品图、材质特写、四视图时，先读 `references/ecommerce-product-polish-system.md`，补齐产品一致性、边缘、标签、反光、接触阴影、材质和背景留白。

推荐固定交付格式：
- 主图
- 模特图
- 四视图
- 详情页
- 九宫格

## 一、先判断销售渠道

### 1. 平台型主图

适用于：
- Amazon
- Temu
- 速卖通
- 大多数白底商品列表页

默认规则：
- 纯白或近白背景
- 产品是唯一主角
- 阴影干净克制
- 不加复杂文字、边框、贴纸、无关道具
- 产品尽量填满主体区域，避免太小

可见事实写法：
- `纯白无缝背景，产品居中，占画面约 85%`
- `只有产品本体，无干扰道具，无水印，无多余文字`

### 2. 品牌官网主图

适用于：
- DTC 官网首页
- PDP 首图
- 社媒广告入口图

默认规则：
- 背景可以不是纯白，但必须克制
- 产品是第一焦点
- 可以带品牌语气、留白和轻量道具
- 要有“首屏抓人”的视觉中心

## 二、五种固定交付格式

## 1. 主图

### 用途

- 列表页点击
- 商品首屏
- 广告封面

### 写法重点

- 只保留一个主视觉中心
- 交代产品位置、占比、朝向
- 控制背景干净度
- 平台图更偏功能，品牌图更偏气质

### 标准骨架

```text
保持图1产品结构、比例、材质、颜色和 logo 不变。输出一张电商主图，产品位于画面中央，占画面约 80%-85%，以[正面/左45°/右45°]展示，背景为[纯白/浅灰/品牌色纯净背景]，阴影克制干净，无多余道具和文字，产品边缘清晰，适合电商首图展示。
```

## 2. 模特图

### 用途

- 展示上身效果
- 传达比例、气质、穿搭和生活方式

### 写法重点

- 产品是第一焦点，模特是承载体
- 不能让头发、手臂、动作遮挡关键结构
- 讲清楚半身/全身/近景
- 讲清楚产品在模特身体上的落点

### 标准骨架

```text
保持图1模特身份和气质不变，保持图2产品结构、材质和颜色不变。输出一张电商模特图，模特以[全身/半身/近景]展示，产品位于[身体位置]，关键结构完整可见，模特姿势自然专业，画面兼具销售清晰度与品牌感。
```

## 3. 四视图

### 用途

- 详情页标准展示
- 结构清晰
- 降低退货和误解

### 推荐拆分

#### 服装 / 内衣

1. 正面
2. 侧面或 3/4
3. 背面
4. 细节特写

#### 鞋包配饰

1. 正面 hero
2. 侧面
3. 背面 / 内里
4. 材质或五金细节

#### 家居 / 产品

1. 正面
2. 45° 角
3. 功能或背面
4. 材质 / 接口 / 结构特写

### 标准写法

```text
输出一组四视图，分别为正面、侧面、背面和细节特写。保持产品版型、材质、颜色、结构比例完全一致，每张图只改变机位和裁切方式，不改变产品本身。
```

## 4. 详情页

### 用途

- 商品卖点拆解
- 材质说明
- 版型和功能解释

### 推荐页序

1. Hero 首屏
2. 核心卖点页
3. 材质页
4. 结构页
5. 上身/使用场景页
6. 细节页
7. 尺寸或覆盖度说明页
8. 颜色/套装补充页

### 详情页不是一张图

如果用户说“详情页”，默认理解为一组页面，不要只输出一张图 prompt。

### 标准写法

```text
输出一组电商详情页视觉，至少包含 hero 首屏、材质细节、结构卖点、上身/使用场景和尺寸/覆盖度信息页。保持产品本体一致，每页只改变信息重点、裁切和构图。
```

## 5. 九宫格

### 用途

- 海外电商缩略展示
- 社媒种草九连图
- 商品信息一屏看完

### 推荐 3x3 布局

1. Hero 主图
2. 正面
3. 背面
4. 侧面
5. 材质特写
6. 结构特写
7. 模特图 / 使用图
8. 卖点说明页
9. 尺寸/颜色/场景收尾页

### 标准写法

```text
输出一组 3x3 九宫格电商图，分别承担 hero、正面、背面、侧面、材质特写、结构特写、模特/使用场景、卖点说明、尺寸或补充信息的角色。整组视觉风格统一，产品结构和颜色保持一致。
```

## 三、输出规则

每张产品图都要补齐：
- 产品一致性
- 产品角度与镜头角度
- 边缘与轮廓
- 光线与接触阴影
- 材质表面
- 背景与留白

当用户点名固定交付格式时，最终输出建议至少包含：

```text
【交付类型】
【总视觉方向】
【品牌语气层】
【每张图的角色】
【每张图的空间与角度蓝图】
【每张图的中文提示词】
【每张图的 English Prompt】
```

不要只给一句“做九宫格电商图”，要拆图。

## 四、品牌语气与交付格式的搭配

- `轻奢` 更适合：官网主图、详情页、模特图
- `法式` 更适合：模特图、详情页、九宫格
- `运动` 更适合：模特图、详情页、四视图
- `极简` 更适合：主图、四视图、官网首图
- `买手店风` 更适合：官网主图、九宫格、详情页

## 五、当前可参考的官方案例观察（2026-05）

### SKIMS

观察要点：
- 同一商品页常见正面、侧面、背面、上身图、局部细节和白底平铺
- 适合作为服装、塑形、内衣类“四视图 + 模特图”参考

链接：
- [SKIMS Product Page](https://skims.com/products/seamless-sculpt-bralette-sienna)

### Shopify 官方建议

观察要点：
- 强调清晰、统一、以产品为中心
- 适合作为电商主图与详情图的一般原则参考

链接：
- [Shopify Product Photography Guide](https://www.shopify.com/au/blog/12206313-the-ultimate-diy-guide-to-beautiful-product-photography)

### Amazon 主图规范

观察要点：
- 平台主图偏功能展示
- 纯白背景、主体足够大、少干扰元素

链接：
- [Amazon Main Image Guidance](https://sell.amazon.com/blog/amazon-image-requirements)
