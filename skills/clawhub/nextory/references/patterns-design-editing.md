# 海报与编辑模板

## 海报

```text
给图1产品制作一张海报，保留产品本体，设置主标题、副标题和文案留白区，背景与品牌语气一致。
```

## 详情页

```text
输出一组详情页视觉，包括hero首屏、材质页、结构页、场景页、细节页和尺寸说明页。
```

## 九宫格

```text
输出3x3九宫格，分别承担hero、正背侧、材质、结构、模特/使用图、卖点图和补充信息图的角色。
```

## 图像编辑

```text
保持主体身份和结构不变，只修改指定背景、姿势、表情、颜色或局部元素。
```

## 多图融合

```text
以图1作为主体参考，以图2作为材质或风格参考，以图3作为场景参考，明确每张图的角色，不要混写。
```
