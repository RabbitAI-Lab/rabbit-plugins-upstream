## Description: <br>
Use this skill when writing a public-facing introduction for a TRPG rule system, such as a README or publishing page. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[ice26985850](https://clawhub.ai/user/ice26985850) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
External TRPG designers and publishers use this skill to have an agent read rule materials and draft a concise Traditional Chinese public introduction for potential players. The skill is intended for README files, itch.io pages, GitHub releases, and TRPG community sharing. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill writes a [rule name]_介紹.txt file in the rule directory, which could overwrite an existing introduction. <br>
Mitigation: Confirm the target rule directory and check for an existing [rule name]_介紹.txt file before running the skill. <br>
Risk: A public introduction may overstate references, setting details, or player-facing claims if the available rule materials are incomplete. <br>
Mitigation: Review the generated introduction against the source rulebook, scenario files, and reference-work statements before publishing. <br>
