## Description: <br>
Write high-quality agent skills (SKILL.md files) for ClawdHub/MoltHub. Use when creating a new skill from scratch, structuring skill content, writing effective frontmatter and descriptions, choosing section patterns, or following best practices for agent-consumable technical documentation. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and agent builders use this skill to create, structure, review, and publish high-quality SKILL.md files for ClawdHub or MoltHub. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Publishing commands can create or update a skill release if run unintentionally or from the wrong directory. <br>
Mitigation: Review commands before execution and run npx molthub@latest publish only from the intended skill directory when publishing is desired. <br>
Risk: Skill-writing guidance can produce incorrect, outdated, or misleading instructions if applied without review. <br>
Mitigation: Review generated skill content and scan the skill before deployment. <br>
