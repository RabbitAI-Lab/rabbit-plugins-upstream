## Known Risks and Mitigations:

Risk: Manual deployment snippets could be copied without checking paths, remotes, tags, or local environment assumptions.

Mitigation: Review each command and target path before execution, and treat deployment snippets as examples until adapted to the local release process.

Risk: Strong persuasion and anti-rationalization patterns can over-constrain agent behavior if applied outside user-benefiting quality, safety, and correctness requirements.

Mitigation: Reserve persuasion patterns for documented failure modes and requirements that serve the user's explicit goals, safety, or quality standards.
