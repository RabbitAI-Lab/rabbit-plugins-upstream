## Description: <br>
Helps API developers and backend teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, backend teams, developer-experience teams, and maintainers use this skill to turn API documentation requests into scoped workflows, checklists, examples, code or configuration guidance, and validation steps for OpenAPI or Swagger REST API documentation. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate on broader API or developer-experience requests that are not clearly about API specifications or documentation. <br>
Mitigation: Confirm the request is about OpenAPI, Swagger, REST API documentation, or related API documentation workflows before relying on the output. <br>
Risk: Documentation guidance may be incomplete if the user does not provide the relevant routes, schemas, examples, or existing API specification. <br>
Mitigation: Ask only for missing inputs that materially change the output, state assumptions clearly, and validate the result against the user's success criteria before publishing or implementing changes. <br>
