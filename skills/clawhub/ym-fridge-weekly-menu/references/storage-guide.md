# 食材分区与保鲜期对照表

SKILL.md 步骤 1、步骤 2 引用本表做分区与"易坏优先"排序。以下为常温/冷藏常规存放的大致保鲜期，实际受温度、湿度、包装影响，仅供排菜参考，不替代食品安全判断。

## 一、叶菜与易坏（优先 1~3 天内消耗）

| 食材 | 大致保鲜期 | 保存要点 | 优先等级 |
|---|---|---|---|
| 菠菜、小白菜、生菜等绿叶菜 | 2~3 天 | 擦干水分、厨房纸包裹装袋冷藏，勿沾水 |
| 香菜、小葱 | 3~5 天 | 洗净擦干，水养或裹纸冷藏 |
| 菌菇（香菇、金针菇） | 3~5 天 | 原包装或纸袋冷藏，勿密封积水 |
| 豆腐、豆制品 | 1~2 天 | 浸水泡冷藏，当天吃完最佳；有酸味即弃 |
| 切开的瓜果（半个西瓜、切开的冬瓜） | 1~2 天 | 保鲜膜包切口冷藏，切面发黏即弃 |
| 豆芽 | 1~2 天 | 冷藏，出水变味即弃 |

## 二、根茎与耐放（可排 4~7 天或更久）

| 食材 | 大致保鲜期 | 保存要点 | 优先等级 |
|---|---|---|---|
| 胡萝卜、白萝卜 | 1~2 周 | 去叶、装袋冷藏 |
| 土豆、洋葱、红薯 | 数周（阴凉通风） | 避光通风，勿冷藏发芽 |
| 西红柿（熟软） | 3~5 天 | 冷藏；偏生可常温催熟后尽快吃 |
| 茄子、青椒、黄瓜 | 4~7 天 | 冷藏，黄瓜易失水需包好 |
| 大蒜、生姜 | 数周 | 阴凉干燥，生姜可冷藏 |

## 三、肉蛋水产（严格按期限，疑坏即弃）

| 食材 | 大致保鲜期 | 保存要点 | 优先等级 |
|---|---|---|---|
| 鲜肉（猪牛羊鸡） | 1~2 天 | 冷藏；2 天内吃不完立即冷冻 |
| 鲜鱼、虾、贝类 | 当天~1 天 | 冷藏并尽快烹调，有腥臭味即弃 |
| 鸡蛋 | 3~4 周 | 冷藏，大头朝上；散黄、粘壳即弃 |
| 冷冻肉禽 | 1~3 个月 | 冷冻，-18℃ 以下；反复解冻降级 |
| 熟食、卤味 | 1~2 天 | 冷藏，隔夜需彻底加热 |

## 四、主食与干货（耐放，按需取用）

| 食材 | 大致保鲜期 | 保存要点 | 优先等级 |
|---|---|---|---|
| 大米、面粉、挂面 | 数月~1 年 | 密封防潮 |
| 面包 | 2~3 天 | 常温或冷冻，冷藏易变干 |
| 面条、粉条、干货 | 数月~1 年 | 防潮密封 |
| 速冻水饺、汤圆 | 按包装 | 冷冻，勿反复冻融 |

## 五、调味品（基本不影响排菜，仅标注可用）

| 食材 | 说明 |
|---|---|
| 油、盐、酱、醋、糖、料酒、生抽老抽 | 长期，排菜时默认都有，不计入易坏 |
| 新鲜香料（罗勒、薄荷） | 3~5 天，按叶菜处理 |
| 番茄酱、蚝油（开封） | 冷藏，数月，按需用 |

## 使用纪律

- 保鲜期是"大致"参考，凡是**状态异常**（发黏、异味、长毛、变色、过期、解冻后复冻发灰）一律按"疑似变质"处理，建议丢弃，不进入菜单。
- 排菜时按"优先等级"从易坏到耐放铺开；保鲜期跨不了一周的，明确提示"X 天内吃完"或"建议冷冻延长期限"。
