# 替代食材对照库

SKILL.md 步骤 6 引用本库生成每道菜的替代方案。每组标注"是否改变做法"——改变做法意味着替换后烹饪方式或火候需调整，必须提示用户。

## 一、蔬菜类（大多可直替，不改做法）

| 原食材 | 可替换 | 是否改做法 | 说明 |
|---|---|---|---|
| 青菜 / 小白菜 | 油麦菜、生菜、鸡毛菜、菠菜 | 否 | 清炒/白灼通用，时令互换 |
| 番茄 | 圣女果（做汤/炒蛋时） | 否 | 圣女果更甜，整道菜偏甜 |
| 土豆 | 山药、芋头（做主食替代） | 是 | 山药芋头更粉，蒸煮时间不同 |
| 胡萝卜 | 白萝卜（炖煮时） | 是 | 白萝卜出水多、味清，需减量调味 |
| 青椒 | 彩椒、尖椒（不吃辣换彩椒） | 否 | 彩椒不辣，颜色更杂 |
| 茄子 | 西葫芦（焖烧时） | 是 | 西葫芦出水快，缩短烹饪时间 |
| 黄瓜 | 西葫芦（凉拌时） | 否 | 口感近似 |
| 洋葱 | 大葱白、韭葱 | 是 | 洋葱爆香基底味不同，需补蒜提味 |
| 冬瓜 | 丝瓜（做汤时） | 否 | 同属清爽瓜类 |
| 西兰花 | 菜花、芦笋 | 否 | 焯水时间略调 |

## 二、肉蛋水产类

| 原食材 | 可替换 | 是否改做法 | 说明 |
|---|---|---|---|
| 鸡胸肉 | 鸡腿肉、瘦猪肉 | 是 | 鸡腿更嫩多汁，去骨时间不同；鸡胸偏柴需嫩化处理 |
| 猪肉末 | 牛肉末、鸡肉末 | 否 | 调味略调（牛肉需更多去腥） |
| 牛肉 | 羊肉（炖煮时） | 是 | 羊肉膻味重，需加去膻配料 |
| 虾仁 | 鲜贝、鱼块（海鲜过敏禁替海鲜） | 是 | 熟成时间不同，鱼块需去骨 |
| 鸡蛋 | 鸭蛋、鹌鹑蛋 | 否 | 鸭蛋腥味略重，鹌鹑蛋需更多颗数 |
| 三文鱼 | 鳕鱼、龙利鱼 | 是 | 油脂含量不同，煎制时间调整 |
| 火腿/香肠 | 培根、午餐肉 | 否 | 咸度不同，注意减盐 |

## 三、主食与蛋白替代（常影响做法）

| 原食材 | 可替换 | 是否改做法 | 说明 |
|---|---|---|---|
| 牛奶 | 豆浆、燕麦奶 | 是 | 豆浆遇酸/热易结块，做甜品、奶白汤时慎用；植物奶不凝固 |
| 米饭 | 面条、馒头（主食互换） | 是 | 炒饭换炒面，火候与用油量不同 |
| 豆腐 | 豆干、内酯豆腐 | 是 | 老豆腐煎、嫩豆腐煮，做法不可混用 |
| 面粉 | 米粉、低筋/高筋粉 | 是 | 筋度不同，烘焙/煎炸成败差异大 |
| 芝士 | 芝士片、马苏里拉 | 是 | 拉丝与融化性不同，焗烤需选对 |

## 四、调味与特殊替代

| 原食材 | 可替换 | 是否改做法 | 说明 |
|---|---|---|---|
| 料酒 | 啤酒、白酒（少量） | 是 | 酒精度不同，去腥用量调整 |
| 砂糖 | 冰糖、蜂蜜 | 是 | 冰糖需化开，蜂蜜高温易苦，后放 |
| 辣椒 | 黑胡椒、花椒（不吃辣） | 是 | 辣味换香麻，整体风味走向变 |
| 奶油 | 椰浆（乳糖不耐） | 是 | 椰浆风味明显，甜咸菜都受影响 |

## 使用纪律

- 每道菜至少给 1 个替代；标"改做法"的必须附一句调整说明（如"换鸡腿肉需缩短煎制时间"）。
- 用户给定过敏物时，替代不能引入同类过敏原（如海鲜过敏不能用贝类替虾仁）。
- 本库未覆盖的食材，按"同类、同烹饪特性"原则给替代，并注明"非标准替换，做法需自行微调"。
