# 模型 API 用量与预算估算

[English](README.md)

按导出的 Token 用量和自己填写的模型单价估算费用，区分缓存输入与输出，分别汇总币种并检查预算。

## 能做什么

按导出的 Token 用量和自己填写的模型单价估算费用，区分缓存输入与输出，分别汇总币种并检查预算。
