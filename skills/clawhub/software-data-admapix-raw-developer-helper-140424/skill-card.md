## Description: <br>
Helps agent users and skill authors adapt AdMapix-style software and data workflows for bug fixing, reliability hardening, safety setup, and adjacent skill creation. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External developers, agent users, skill authors, maintainers, and teams use this skill to turn AdMapix-style software and data workflow needs into practical plans, checklists, code-support guidance, and validation notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger terms may activate the skill for generic software or data requests. <br>
Mitigation: Prefer explicit invocation for AdMapix or raw-data workflow tasks and confirm the intended scope before relying on the output. <br>
Risk: Guidance-only outputs can still produce incorrect implementation advice or incomplete validation steps. <br>
Mitigation: Review proposed changes, run the recommended checks, and validate against the user's success criteria before deployment. <br>
