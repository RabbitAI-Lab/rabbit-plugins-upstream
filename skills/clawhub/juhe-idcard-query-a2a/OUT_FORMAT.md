# 身份证信息查询输出格式

支付成功并拿到接口 JSON 后渲染。**仅使用接口返回字段，禁止编造内容。**

## 输出顺序（固定）

```markdown
{查询概要模板}   ← 有 result 时必渲染，排第一

{信息明细模板}   ← result 对象字段渲染

---
*以上数据来源于编码规则解析及第三方数据服务，仅供参考，不能识别身份证真伪，请以权威渠道核验为准。*
```

查询失败或字段为空时，输出概要 + 接口返回的 `reason` 提示 + 页脚免责。

---

## 查询概要模板

接口返回 `result` 对象时使用，**固定排在全文最前**。

数据路径：`result.*`（外层 `reason`、`error_code` 不展示给用户）。

### 渲染结构

```markdown
# 🪪 身份证信息查询结果

> 🔑 身份证号：{脱敏后的 cardno}

| 项目 | 内容 |
| ---- | ---- |
| 查询单号 | {result.orderid，如有} |
| 查询状态 | {成功 / 部分成功 / 查询失败} |
```

### 字段映射

| 展示项 | JSON 字段 | 说明 |
| ------ | --------- | ---- |
| 身份证号 | 用户输入 cardno | 必须脱敏，如 `320505********1234` |
| 查询单号 | `result.orderid` | 聚合数据订单号，缺失时跳过该行 |
| 查询状态 | `error_code` / `reason` | `error_code=0` 为成功 |

---

## 信息明细模板

数据路径：`result` 对象（或 `result.data`，以接口实际返回为准）。

### 渲染结构

```markdown
## 编码解析信息

| 项目 | 内容 |
| ---- | ---- |
| 性别 | {sex，空值显示「—」} |
| 出生日期 | {birthday，空值显示「—」} |
| 户口所在地 | {area，空值显示「—」} |
| 格式校验提示 | {verify，为空则跳过该行} |
```

### 字段映射

| 展示项 | JSON 字段 | 说明 |
| ------ | --------- | ---- |
| 性别 | `sex` | 如「男」「女」 |
| 出生日期 | `birthday` | 如「1990年01月01日」 |
| 户口所在地 | `area` | 行政区划归属地描述 |
| 格式校验提示 | `verify` | 如「该身份证号校验位不正确」；为空表示格式校验通过或未返回 |

---

## 完整输出示例

```markdown
# 🪪 身份证信息查询结果

> 🔑 身份证号：320505********1234

| 项目 | 内容 |
| ---- | ---- |
| 查询单号 | JH380250716151234AbCdE |
| 查询状态 | 成功 |

---

## 编码解析信息

| 项目 | 内容 |
| ---- | ---- |

| 出生日期 | 1990年01月01日 |

```

## 渲染规则

1. **概要首位**：有 `result` 时，必须先渲染 [查询概要模板](#查询概要模板)，再渲染明细。
2. **脱敏强制**：身份证号展示保留前 6 位与后 4 位，中间以 `*` 替代，禁止完整明文回显。
3. **空值处理**：`sex`、`birthday`、`area` 等字段缺失、空字符串、`null` 时显示「—」；`verify` 为空时跳过该行。
4. **文本清洗**：去除 HTML/script 标签；保留中文标点与换行。
5. **禁止臆造**：不生成接口未返回的姓名、住址、民族、签发机关等内容。
6. **能力边界提示**：若 `verify` 非空，需在结果中明确说明「仅为格式校验提示，不代表证件真实有效」。
7. **页脚免责**（固定追加）：

```markdown
---
*以上数据来源于编码规则解析及第三方数据服务，仅供参考，不能识别身份证真伪，请以权威渠道核验为准。*
```
