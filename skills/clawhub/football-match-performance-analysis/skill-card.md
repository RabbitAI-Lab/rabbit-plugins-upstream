## Description:

Explain a completed football (soccer) match from SofaScore statistics, incidents, and lineups, including beginner-friendly briefs for coaches or parents. Use for sourced post-match explanations; use multi-sport-match-research for basic cross-provider fixture checks.

This skill is ready for commercial/non-commercial use.

## Use Case:

External readers, including coaches and parents, use this skill to create concise, source-grounded post-match football briefs from SofaScore match statistics, incidents, and lineups.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Search terms and requests are sent to Crawlora, and API use can consume credits.

Mitigation: Use a dedicated API key and leave private information out of searches.

Risk: Retrieved odds may be mistaken for a prediction or an explanation of match performance.

Mitigation: Label odds as a retrieved snapshot and keep them separate from match-performance evidence.
