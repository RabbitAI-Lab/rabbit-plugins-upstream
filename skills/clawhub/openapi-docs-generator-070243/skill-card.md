## Description: <br>
Openapi Docs Generator helps API developers and backend teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
API developers, backend teams, developer-experience teams, and maintainers use this skill to create practical OpenAPI or Swagger documentation workflows, checklists, implementation support, and validation notes for REST APIs. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger wording may cause this skill to activate during general API documentation conversations where another skill or no skill was intended. <br>
Mitigation: Clarify the desired skill or explicitly name another skill when the task is not about OpenAPI or Swagger documentation. <br>
