## Description:

Turns a script, outline, shot list, blog post, or theme into an editable rough-cut video using the user's own footage.

This skill is ready for commercial/non-commercial use.

## Publisher:

[reelary](https://clawhub.ai/user/reelary)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and editors use this skill to assemble their own indexed footage into a rough cut, montage, recap, or highlight reel. It selects clips for script or shot-list lines, saves an editable project, and can export an MP4.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The command-line fallback has a routine dependency risk.

Mitigation: Use a reviewed, pinned Reelary version for the CLI fallback, index only footage intended for agent use, and review the draft before exporting.
