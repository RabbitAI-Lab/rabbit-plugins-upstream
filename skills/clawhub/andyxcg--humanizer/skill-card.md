## Use Case:

External users, writers, editors, and developers use this skill to humanize or review articles, novels, resumes, social posts, academic writing, and official/business prose while preserving the author's intended voice.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad polish or humanize triggers and file-edit permissions can affect user documents unintentionally.

Mitigation: Invoke the skill with clear text or file paths, and review diffs before accepting file changes.

Risk: Style edits can change meaning, tone, or intentional literary voice.

Mitigation: Review the rewritten text against the source; when a device may be intentional, the skill is designed to preserve it and note that choice.
