# 중국 관광지 티켓

## 설명

중국 여행을 위한 올인원 여행 동반자. 이 스킬은 외국인 여행자를 위해 5가지 강력한 기능을 제공합니다:

1. **관광지 티켓** — 티켓 요금, 영업 시간, 예약 링크로 관광명소 발견
2. **호텔 검색** — 실시간 요금, 평점, 예약 링크로 호텔 찾기
3. **항공권 검색** — 중국행/중국발/중국 내 항공편을 실시간 요금으로 검색
4. **여행 플랜** — 맞춤화된複数日の 여행 계획 생성
5. **여행 조언** — 비자, 결제, 교통, 음식 등에 대한 답변 받기

## 데이터 흐름 및 개인정보 보호

사용자 쿼리는 안전한 프록시 서버(SCF)로 전송되며, 인증 토큰이 주입되어 TripGenie API로 전달됩니다. 프록시는 제휴 링크 생성을 자동으로 처리합니다. 사용자 개인 정보는 저장되거나 기록되지 않습니다. 모든 통신은 HTTPS로 암호화됩니다.

## 사용할 때

- 중국 도시의 관광명소와 할 일 찾기
- 특정 관광명소의 티켓 요금과 영업 시간 받기
- 관심사에 기반한 활동 발견 (역사, 자연, 음식 등)

키워드: 중국 관광명소, 베이징 할 일, 상하이 관광, 만리장성 티켓, 자금성, 병마용, 관광명소, 티켓, 관광

## 실행

### 1단계: 사용자 요청에서 매개변수 추출

| 매개변수 | 설명 | 예시 |
|---------|------|-----|
| city | 도시명 (영어 또는 한국어, 필수) | "Xi'an" or "시안" |
| days | 체류 일수 (선택, 기본값: 1) | 2 |
| interests | 관심사 키워드 (선택) | "역사와 문화" |

### 2단계: 스크립트 실행

```bash
python scripts/china_travel.py attraction "<city>" [days] "[interests]" --locale=ko
```

**중요:** 항상 `--locale=ko` 매개변수를 포함하여 한국어 결과를 받아주세요.

### 3단계: 결과 표시

API는 구조화된 Markdown으로 관광명소명, 티켓 요금, 영업 시간, 예약 링크를 반환합니다. 내용을 직접 사용자에게 표시합니다.

## 예시

**사용자:** "시안에서 무엇을 방문할 수 있어?"
```bash
python scripts/china_travel.py attraction "Xi'an" --locale=ko
```

**사용자:** "베이징에서 2일간의 역사 관광명소"
```bash
python scripts/china_travel.py attraction "Beijing" 2 "history" --locale=ko
```

## 기타 사용 가능한 기능

이 스킬은 다음도 지원합니다:
- `hotel` — 중국 호텔 검색 및 예약
- `flight` — 중국행/중국발/중국 내 항공권 검색
- `itinerary` —複数日の 여행 계획 생성
- `tips` — 여행 조언, 비자, 결제, 교통 팁

## 주의사항

- 도시명은 영어 또는 한국어로 입력할 수 있습니다
- 예약 링크는 Trip.com (국제판)으로 직접 이동합니다
