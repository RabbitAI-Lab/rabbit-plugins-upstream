# Stoic Coach · 斯多葛刻意练习教练

> 你无法控制发生在自己身上的事，但可以控制如何应对它。

一个 [CodeBuddy](https://www.codebuddy.com/) / Claude Code 风格的 **Skill**：不做甩清单的工具人，做**一步步提问引导你完成练习**的斯多葛教练，并把每次练习存档，随时间积累出"更了解自己"的洞察——和一张**困境地图**：看清痛点里不可控的部分，找到属于自己的可控项。

**给被情绪困住的人一个出口。**

## 它能做什么

- 🏛️ **26 项斯多葛练习**（5 大模块）：控制二分法、四大美德、正念与智慧模式、热爱命运与全然接纳、韧性训练（含第二支箭·两层痛苦拆解）
- ⚡ **三分钟微练习**：低电量入口——疲惫、练不动的时候不进深水区，"力竭的人做不了深蹲"
- 🗺️ **困境地图**：练习收尾时记下这次看清的不可控、找到的可控（`reflect`），随时间积累成你自己的地图（`map`）——练习是过程，地图是资产
- 🗣️ **教练式逐问引导**：一次只问一个问题，先共情后引导，苏格拉底式地把结论留给你自己；完整节奏示范见 `references/example-session.md`
- 🎯 **智能推荐**：`recommend` 命令基于你的历史记录和当下情绪推荐下一个练习，并提示电量边界
- 📈 **持久化追踪**：每次练习记录前后不适分数与一句话收获（JSONL 追加写入，安全不丢数据）；**持平（9→9）与改善一样如实存档——存的是事实，不是表演**
- 🔍 **自我洞察报告**：你的练习模式、最有效的练习、高频情绪标签、困境地图小结——用你自己的原话照镜子
- 📜 **每日一句**：按日期轮换的斯多葛语录（同一天稳定同一句）
- 📂 **随时导出**：Markdown / JSON 备份你的练习史与困境地图

## 快速开始

```bash
# 安装到 CodeBuddy 的 skills 目录
git clone https://github.com/bonniegeng-max/stoic-coach.git ~/.codebuddy/skills/stoic-coach
```

也可以从 ClawHub 安装：

```bash
clawhub install @bonniegeng-max/stoic-coach
```

然后对 CodeBuddy 说：

| 你说 | 它做 |
|------|------|
| "开始今天的斯多葛练习" | 教练开场 → 推荐 → 逐问引导 → 存档 → 看清落档 |
| "我有点焦虑，想练一下斯多葛" | 直接进入教练流程，推荐匹配练习 |
| "推荐一个斯多葛练习" | 运行 recommend：基于历史+情绪推荐，附电量提示 |
| "我很疲惫，练不动" | 只推三分钟微练习，或建议你去做件"享受当下"的事 |
| "责任分类法怎么做？" | 参考查询模式：直接给步骤+出处，不进教练流程 |
| "看看我的斯多葛练习进度" | 统计总览 + 洞察报告 |
| "看看我的困境地图" | 展示你看清的不可控、找到的可控 |
| "来一句斯多葛语录" | 每日一句 + 解读 |

> 触发说明：本 skill 仅响应**明确提及斯多葛/练习**的意图。单纯的情绪倾诉（未提到斯多葛或练习）不会触发。

## 数据与隐私

所有记录只存在你本地：

- 默认：`~/.stoic-coach/journal.jsonl`
- 多设备同步：设置环境变量 `STOIC_COACH_DATA_DIR` 指向网盘同步目录
- 导出：`python3 scripts/stoic.py export --format md`
- 注意：记录为**明文 JSONL**，包含你的心得原话。如涉及敏感内容，建议将存储目录设到加密盘，导出的备份也请妥善保管

## 设计哲学

1. **教练和说教者的区别，是一次只问一个问题**
2. 数字只是镜子，镜子里的人是你——洞察报告永远引用你自己的原话
3. **分数持平也是如实记录**：看清结构是手术，不是麻药——存的是事实，不是表演
4. **看清不可控不是失败，找到可控不在大小，在于真的去做**——困境地图存的是落点，不是情绪
5. **低电量不进深水区**：力竭的人做不了深蹲，维持接触也是练习
6. 斯多葛主义是"进步者之路"：追求进步，而非完美
7. 本 skill 是哲学练习工具，不替代专业心理帮助
