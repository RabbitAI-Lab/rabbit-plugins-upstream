# 日常例程 · 晨间预演 / 晚间复盘 / 周回顾

> 用途：SKILL.md 路由 **F. 日常例程** 的执行手册。三条流程都是**轻例程**——3–5 分钟、不问状态分、不走逐问教练流程。目的不是多练，是"每天见面"：让 skill 从难受时才用的工具，变成日复一日的陪伴。
>
> 共同铁律：**收尾比落档重要**。用户状态低时，先陪完再说记录的事，或直接跳过。

## 一、晨间预演（morning）

**信源**：马可·奥勒留《沉思录》卷二第 1 节（"清晨对自己说：今天我会遇到多管闲事的人、忘恩负义的人、傲慢的人……"——即语录库第 12 条）；塞涅卡《道德书信》第 91 封（*premeditatio malorum*——预想逆境不是诅咒，是提前写好应对）。

**四步**（一次一问，不问状态分）：

1. **一句话状态**（`--state-note`）："睡醒后的第一感觉，一句话？"
2. **预想一件困难**（`--difficulty`）："今天最可能硌你一下的是什么？"——只要一件，不要清单。
3. **一个预案**（`--plan`）："它来的时候，你的第一个动作是什么？"
4. **一句准则**（`--principle`，可选）："今天想守住哪一句？"——可引用语录，也可用用户自己的话。

**落库**：
```bash
python3 scripts/stoic.py morning --state-note "..." --difficulty "..." \
    --plan "..." --principle "..." [--tags 工作]
```

**话术要点**：
- 预演困难 ≠ 制造焦虑：焦点永远在**应对动作**。用户一旦滑向反复苦恼（"万一更糟怎么办"），拉回："好，预演完了。你的第一个应对动作是什么？"
- 用户说"今天没什么困难"：接受，不硬凑。**预演失效的那天，正是胜利的一天。**
- 用户在晚上说"晨间"：不纠正时间，直接走流程——"那就预演明天"。

## 二、晚间复盘（evening）

**信源**：塞涅卡《道德书信》第 83 封（睡前自省："今天我治好了什么毛病？抵挡了什么诱惑？"）；毕达哥拉斯学派的睡前自问传统（"我今天哪里越过了界限？"）。

**三问**（一次一问）：

1. **今天推进了什么**（`--progress`）——哪怕很小也算。"今天有一件事，是可以算数的吗？"
2. **可以放下什么**（`--let-go`）——"有什么没做完、但今晚可以不带上床的？"
3. **明天接什么**（`--next`）——"明天最值得接上的一件，是什么？"

**落库**：
```bash
python3 scripts/stoic.py evening --progress "..." --let-go "..." --next "..." [--tags 工作]
```

**话术要点**：
- 收尾不是审判：绝不用"今天是不是浪费了"开场；"什么都没推进"也是有效回答——放下即收束。
- `let_go` 不落困境地图：map 的写入口**只有 reflect**，晚间放下是日常操作，不是"看清"。

## 三、周回顾（weekly）

**跨 type 聚合口径**（`stoic.py weekly` 已实现）：

| 记录类型 | 计入什么 |
|---------|---------|
| practice（无 type 或 type=practice） | 练习次数、模块分布、前后不适分均值、最有效练习、标签 |
| reflection | 本周新增不可控 / 可控抓手数 |
| morning | 次数（并入高频标签统计） |
| evening | 次数（并入高频标签统计） |

**输出 6 段**：练习次数与模块分布 / 状态分数变化 / 困境地图新增 / 高频标签 / 本周最有效练习 / 下周一个重点建议。

**使用**：用户问"这周怎么样 / 回顾一下"时运行 `python3 scripts/stoic.py weekly`，把结果翻译成人话。也可在晨/晚例程里顺带一句"周日可以回顾一周"。**不主动推销**，等用户开口。

**注意**：weekly 只读不写；`--days` 可调窗口（默认 7）。

## 四、边界说明（重要）

- **morning ↔ 练习 23（预设逆境）**：练习 23 是正式深练习——聚焦**单件拖延很久的事**，走完整流程 + 状态分；morning 是 3 分钟轻例程——预想**今天**，无状态分。用户想深挖某个具体恐惧 → 练习 23；用户只想把一天过明白 → morning。判断不准时问一句："你是想拆开看，还是先过好今天？"
- **morning ↔ 语录第 12 条**：语录是默念素材，`daily` 轮换到它时自然呼应；morning 是主动预演动作。不重复，不冲突。
- **reflect 是困境地图唯一写入口**：morning 的 difficulty、evening 的 let_go 都不进 map；用户说出"看清"级别的发现时，引导落 reflect。
- **recommend 只推练习 1–26**：morning/evening 不进推荐池；低电量时 recommend 已推微练习或休息，例程不与之叠加。
- **危机边界照旧**：任何自伤、自杀、暴力、严重医疗/精神危机信号，先转介专业帮助，不进任何例程。
