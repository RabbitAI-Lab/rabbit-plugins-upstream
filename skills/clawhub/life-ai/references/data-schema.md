# 人生数据采集总表（隐私优先版）

**采集红线（必须遵守）：**
- 不采集：真实姓名、出生日期（用年龄区间）、学校/单位名称（用行业大类）、家族病史、既往病史、用药/治疗史、生化与影像体检数据、基因数据、身份证件信息。
- 财务数据一律用合成数据（结构/比例真实、数值虚构），足以做比例分析与趋势分析。
- 伤病只记功能性约束（如"跑跳暂缓"），不记录诊断名称、症状细节、治疗经过。
- 原则：数据的价值来自连续性和结构，不来自敏感细节。有身份信息才能识别的"专业度"是伪需求。

P0=必记，P1=本月补齐，P2=进阶。

## A. 静态基础档案（profile.md）— P0

| 数据项 | 等级 |
|---|---|
| 年龄区间、身高、常态体重、体脂率 | L1 |
| 健康目标与强度偏好 | L1 |
| 作息现状、饮食忌口（有无）、用餐场景 | L1 |
| 身份类型（学生/在职大类）、目标行业 | L1 |

## B. 常规体测（替代原"体检级"）— P1

| 指标 | 频率 |
|---|---|
| 体重、体脂率、腰围 | 每周~每月 |
| 静息心率、血压 | 每周 |
| 生化/影像/基因类项目 | **不采集** |

## C. 动态血糖 CGM — P2（可选）

- 只记录数值型结果：平均血糖、波动幅度、"食物 → 反应"标签对。
- 不记录任何与身份、就诊、诊断相关的内容。

## D. 日常连续监测（穿戴设备）— P1

| 数据项 | 工具 | 频率 |
|---|---|---|
| 睡眠时长、深睡占比、入睡/醒来时间 | 手环/手表/戒指 | 每日 |
| HRV、静息心率、血氧 | 同上 | 每日 |
| 体重、体脂率、肌肉量 | 体脂秤（固定条件） | 每日 |
| 步数、活动消耗 | 手机/手环 | 每日 |
| VO2max | 手表估算 | 每月趋势 |

## E. 饮食 — P0（每日）

- 每餐照片（避免人脸）→ 热量/蛋白/碳水/脂肪估算。
- 饮水、咖啡因、酒精；进食窗口。

## F. 运动 — P0（训练日）

- 力量：动作、重量、组数、次数。
- 有氧：类型、时长、心率区间。

## G. 心理与认知 — P0（每日 30 秒）

- 精力、情绪、压力各 1-5 分；深度工作/备考时长。

## H. 人生规划层 — P1~P2

| 数据项 | 频率 | 脱敏规则 |
|---|---|---|
| 技能清单与熟练度自评 | 每季度 | 直接记（L1） |
| 项目/作品履历 | 完成时追加 | 不含单位内部信息 |
| 收支结构、储蓄率 | 每月 | **合成数据**：数值虚构、比例真实 |
| 时间日志（抽样 1 周） | 每季度 | 直接记 |
| 决策日志：信息、备选项、理由、复盘 | 决定发生时 | 薪资/资产/人名用代号或合成值 |
| 年度目标 + 季度 OKR | 每季复盘 | 直接记 |
