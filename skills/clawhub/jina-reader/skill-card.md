## Description: <br>
Web content extraction via Jina AI Reader API with read, search, and ground modes for URL-to-markdown conversion, web search with content extraction, and fact-checking. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and agents use this skill to retrieve clean web content, run web searches with extracted result content, and check factual claims through Jina AI Reader services. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Requested URLs, search queries, CSS selectors, and fact-check text are sent to Jina AI's external service. <br>
Mitigation: Use only approved public or shareable inputs, and avoid private intranet links, secrets, credentials, personal data, regulated data, and confidential business material unless third-party processing is approved. <br>
