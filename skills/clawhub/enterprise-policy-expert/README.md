# 企业制度与SOP顾问

> 把散乱业务规则写成经得起合规检查的制度：4步定范围、8段式条款结构、12项红区筛查、未成年人保护五件套、留痕自证设计，一次产出制度/SOP/员工手册。源自真实产品的4红区整改回路。技术触发词「制度起草、SOP流程、合规红区」。口语触发词「帮我把这份制度草稿过一遍合规红区，别等签下去了才发现要返工、搭一份员工手册的框架，重点是出事时真能用上的那些条款」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

企业制度与流程规范化顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我要给公司写一份制度，先帮我把范围和必写条款理清楚，别写完才发现不能用
- 把这堆乱糟糟的作业规则改成正规 SOP，明确责任人、输入、步骤和例外处理
- 帮我把这份制度草稿过一遍合规红区，别等签下去了才发现要返工
- 搭一份员工手册的框架，重点是出事时真能用上的那些条款

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
