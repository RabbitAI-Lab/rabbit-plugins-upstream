## Description: <br>
Helps AI-agent users, skill authors, maintainers, and teams turn proactive-agent workflow needs into practical plans, checklists, artifacts, analysis, code changes, and verification notes. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External developers, AI-agent users, skill authors, maintainers, and teams use this skill to clarify a productivity workflow request, produce a concrete deliverable, and validate the result against explicit success criteria. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger wording and implicit invocation may select the skill for general productivity or task-planning requests beyond the intended proactive-agent workflow use case. <br>
Mitigation: Prefer explicit invocation for proactive-agent workflow help and narrow trigger wording if maintaining the package. <br>
Risk: Generated plans, artifacts, code changes, or configuration guidance may not fit the user's actual constraints if inputs are incomplete. <br>
Mitigation: Restate outcomes, constraints, inputs, and success criteria before execution, then validate the result and list remaining risks or follow-up work. <br>
