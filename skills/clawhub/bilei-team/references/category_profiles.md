# 品类适配层（v5.8 新增）

> **为什么需要这个文件**：技能反复被单一品类污染——用充电头压测，就把充电头的媒体名、协议名、价格坑写进通用规则。结果规则文件越来越像"充电头专用说明书"，换个品类要么失效，要么误导。
>
> **这一层的职责**：把「品类专属知识」集中放到这里，**规则文件只保留与品类无关的判据**。新增品类时只改这个文件，不动 agent1–4 的规则。

---

## 零、怎么用（三次读表）

| 时点 | 读哪部分 | 拿去干什么 |
|---|---|---|
| **Step 0 需求结构化时** | 查本文件第一、二节，对该品类建档 | 产出「门槛候选清单 + 关键指标 + 垂类信源 + 权重调整」四项 |
| **派 Agent 1 时** | 第二节「垂类信源」列 | 写进 prompt，否则它只会搜通用引擎，拿不到该品类的拆解/实测圈 |
| **派 Agent 2 时** | 第一、二节「门槛候选 + 关键指标」列 | 写进 prompt 作为门槛筛查的起点，**不让它自己猜** |
| **定稿前** | 第四节权重覆盖指引 | 检查默认权重是否被误用 |

**铁律：本表的「门槛候选」是候选，不是结论。** 每个具体需求的门槛必须按用户实际设备/场景重新确认（同一品类，不同搭配，门槛不同：60W 头对 MacBook Air 够用，对 16 寸 Pro 就是废的）。表里给的是**该往哪查**，不是**答案**。

## 一、门槛型规格候选（按品类索引）

判据（与 `agent2_quant.md` 一致）：二值性 / 跨代断层 / 隐性 / 锁定性。满足任一即为门槛。

| 品类 | 门槛候选（先查这些） | 关键性能指标 | 垂类信源 | 典型坑 |
|---|---|---|---|---|
| **充电 / 电源 / 线材 / 扩展坞** | 快充协议档位与电压区间（如 SPR AVS 9–20V vs EPR AVS 15–28V）、单口 vs 多口分配策略、接口速率等级（USB 2.0/3.2/TB）、PD 反向供电瓦数、线材是否 E-Marker | 实测输出功率、转换效率、纹波、满载壳温、空载功耗、协议兼容数 | 充电头网 ChargerLAB、什么值得买横评区、英文 best-batteries 类 | **同名不同档**（都叫"140W"但 AVS 档段不同）；多口标称功率是"总功率"而非"每口功率" |
| **手机 / 平板 / 整机** | 网络频段与运营商兼容、是否国行双卡、电池是否可换、系统大版本支持年限 | 实测续航、充电功率、屏幕实测亮度/频闪、散热、性能释放曲线 | Notebookcheck、DXOMARK、先看评测、GSMArena | 标称续航虚高；"同型号不同批次换屏/换芯" |
| **影像（相机/镜头/云台/运动相机）** | **卡口与电子触点代次、对焦协议、Log 输出位深、是否支持外录、ND 是否内置** | 实测续航（分段）、读出速度、果冻效应、防抖级数实测 vs 标称、暗角与色散 | PetaPixel、DPReview、ProVideo Coalition、opticallimits | 标称续航注水 60%+；"同款同名不同配"（畅拍版/大师版） |
| **音频（耳机/音箱/麦克风）** | **编解码支持（LDAC/aptX Lossless/LC3）、是否多点连接、延迟模式、麦克风是否波束成形** | 频响曲线实测、失真 THD、降噪深度 dB（分频段）、实测延迟 ms、佩戴压耳力 | RTINGS、Crinacle、SoundGuys、Soomal | "支持 hi-res"只代表能解，不代表调音；降噪 dB 是取峰值不取全频段 |
| **显示（显示器/电视/投影）** | 接口版本与 DSC、HDMI 2.1 是否满血（48Gbps）、面板类型与子像素排列、是否支持 VRR/ALLM | 实测色域覆盖（非标称）、ΔE、峰值/持续亮度、响应时间实测、输入延迟 | RTINGS、TFTCentral、DisplaySpecifications、先看评测 | 标称"4K144"但接口只够跑 4K60；"支持 HDR"仅指能解码 |
| **存储 / 网络 / NAS** | **厂商兼容列表 QVL、CMR vs SMR、2.5G/10G 口有无、PCIe 代次与通道数** | 顺序/随机读写实测、缓外速度、丢包与吞吐实测、满载温度、噪音 | ServeTheHome、Tom's Hardware、Chiphell 实测帖、STH 论坛 | 不在 QVL 内整机不识别；SMR 盘写放大严重 |
| **白电（冰箱/洗衣机/空调）** | **安装尺寸与开孔、电压/频率、排水/排气条件、是否需专用插座、能效等级** | 实测能耗、噪音 dB(A)、洗净比/制冷量实测、故障率（售后口径） | 中消协比较试验、中国家电网实验室、RTINGS（部分） | 装不进去就是装不进去；能效标称与实测差一档 |
| **清洁电器（扫地机/洗地机/吸尘器）** | **越障高度与门槛通过性、是否需上下水改造、地毯识别、耗材是否通用** | 实测吸力（Pa 非全部）、边角清洁率、续航实测、噪音、基站自清洁效果 | RTINGS、中消协比较试验、先看评测 | 标称吸力是峰值且口径不统一；续航含"低档" |
| **厨电 / 小家电** | 容量与实际可用容积、功率与家庭电路承载、是否有 3C、内胆材质 | 实测加热效率、温控精度、噪音、清洁难度、耗材成本 | 中消协比较试验、中国家电网、什么值得买横评 | 标称容量含无效空间；"静音"无量化标准 |
| **家具 / 家居（椅/床垫/柜）** | **尺寸与入户通道、承重、气压棒等级（SGS/BIFMA）、板材环保等级（E0/ENF）** | 人体工学调节范围、实测承重、气味/VOC、五金件寿命 | 什么值得买实测帖、Chiphell、BIFMA 认证查询 | 环保等级商家自填难核；"人体工学"无强制标准 |
| **户外 / 运动 / 出行** | **防护等级 IP 实测 vs 标称、是否可上飞机（电池 Wh）、认证（CE/CPSC）、承重与快拆兼容** | 实测续航、防水实测、重量、耐磨、低温性能 | OutdoorGearLab、REI 评测、什么值得买实测 | 电池 Wh 超 100 需航司批准；IP 等级常为"送测样机" |
| **母婴 / 个护 / 健康** | **是否药监备案/注册（器械类）、适用年龄与体重区间、是否有召回史、材质安全（BPA/甲醛）** | 实测精度（体温/血压等）、噪音、续航、清洁便利 | 药监备案库、中消协比较试验、儿科/口腔专业媒体 | **这类必须查备案号**，无备案即为不合规；参数虚标后果最重 |
| **膳食补充剂 / 保健食品（入口类）** | **① 法定身份：保健食品「蓝帽子」批准文号 vs 普通食品/跨境补充剂（普通食品不得宣称保健功能）；② 标签是否给出有效成分 mg/份（"油重 500mg" ≠ "EPA+DHA 100mg"）；③ 每日剂量能否达到循证量级；④ 氧化值/重金属检测是否可复核；⑤ 不适宜人群与禁忌标注** | **每 1000 mg 有效成分成本**（不是每粒/每瓶单价）、有效成分实含量、氧化指标（TOTOX/过氧化值/酸价）、年服用成本、**等剂量口径下的年成本** | 特殊食品信息查询平台、市场监管总局/中消协消费提示、`samrdprc.org.cn`、EFSA Journal / FDA qualified claim / 中国保健食品功能目录、Cochrane 与 PubMed RCT（**必查资助方**）、上海市消保委等消委会比较试验、《消费者报道》成分检测、中国营养学会 DRIs | **口径陷阱最多**：油重 vs 有效成分、每粒 vs 每 2 粒 vs 每 100g、"180粒"常是 3 瓶套装；**卖家自营检测报告 = 厂商付费委托，L3b 不是 L2**；SEO「十大品牌」通稿污染极重（实测 T=20）；**跨剂量比年成本不成立，必须固定等剂量再比** |
| **服务 / 软件 / 订阅 / 保险 / 课程**（非实物，见第三节） | **资格与准入、覆盖范围与除外责任、自动续费与退订路径、数据可导出性、服务地域限制** | 实际可用性、响应时效、限速/限量阈值、涨价的合同依据 | 见第三节专属规则 | **实物类方法基本全部失效**，尤其比价工具、3C、抽检 |

## 二、表外品类兜底（表里没有时，按这四问推）

不要因为"表里没有"就退回只看参数。四问推出来的门槛，往往比表里抄的更准：

1. **这东西在什么情况下会「完全用不了」？**（不是不好用，是用不了）→ 那就是门槛
2. **用户已有的什么东西必须跟它配？**（旧镜头、旧底座、旧电池、旧会员）→ 兼容性即门槛
3. **官方参数表最不可能写、但实测一定会暴露的是什么？**（协议握手、分配策略、限制条款）→ 隐性门槛
4. **它宣传的那个数字，是按什么口径量的？**（总功率 vs 单口、峰值 vs 持续、含无效空间 vs 有效）→ 口径即门槛

把四问结果写进 Step 0 的「硬约束」栏，再派活。**这四问是通用能力，不是某一品类的知识**——所以它能覆盖无限品类，而档案表只能覆盖已知的。

## 三、服务 / 软件 / 订阅 / 保险 / 课程（实物方法失效区）

这一节单列，因为**技能原本的四个 Agent 全部是按实物设计的**，直接套会系统性出错。

| 环节 | 实物类的做法 | 非实物类必须改成 |
|---|---|---|
| 价格取证 | 慢慢买/史低曲线/大促窗口 | **这些工具无数据，不要硬跑**。改为：官网定价页存档（`web.archive.org` 查历史价）、条款版本对比、同类服务横向报价 |
| 质量取证 | 3C、抽检、召回、拆解、纹波 | **全部无适用**。改为：SLA 条款逐条读、用户投诉（黑猫/应用商店差评/知乎）、实际限速与降级实测、退款纠纷判例 |
| 门槛 | 协议/接口/尺寸兼容 | **资格与除外责任**：能否在本地区用、是否要实名/资质、免赔额与除外条款、是否有"最终解释权"式陷阱 |
| TCO | 购机价 + 耗材 + 维修 + 残值 | **订阅总价 + 涨价历史 + 退出成本（数据迁移/违约金）**。涨价史比首年价重要得多 |
| 推荐强度 | 实测支撑 | 条款清晰度 + 退订可行性 + 是否有集体投诉。**"随时可退"必须去读条款验证，不能信宣传** |

**铁律：非实物类不得出现"拆解""抽检""3C""历史最低价"这类词**，出现即说明 Agent 套错了模板。

## 四、权重覆盖指引（默认权重会被误用）

`premium_decision.py` 的六维固定为 `safety / performance / durability / service / noise / price`，**维度不能增删，只能调权重**（`case.json` 传 `weights` 即自动归一化）。

默认 `SCENARIO_WEIGHTS` 是为"通用家电/小件"设的，`noise` 权重仅 0.05–0.10。**以下品类必须覆盖，否则结论会错**：

| 情形 | 必须覆盖 | 建议起点 |
|---|---|---|
| 噪音是核心体验（空调/油烟机/扫地机/耳机/风扇/冰箱/投影） | 调高 `noise` | `{safety:10, performance:25, durability:15, service:10, noise:25, price:15}` |
| 耗材/订阅是主要成本（净水器/打印机/剃须刀/软件） | 调高 `price`，且把耗材算进 TCO | `{safety:10, performance:20, durability:15, service:10, noise:5, price:40}` |
| 安全关键（涉电涉水涉婴/承重/制动） | 调高 `safety` | `{safety:40, performance:20, durability:20, service:10, noise:0, price:10}` |
| 售后是主要风险（大家电/整机/高价件） | 调高 `service` | `{safety:15, performance:20, durability:20, service:30, noise:5, price:10}` |
| **入口类（保健食品/膳食补充剂）** | 调高 `safety`，`noise` 置 0，`performance` 承载「有效剂量与功效证据强度」 | `{safety:35, performance:30, durability:5, service:5, noise:0, price:25}`；`hold_years:1`，`price` 填**等剂量年成本**而非单瓶价，`annual_consumable:0`、故障率/维修/残值一律 0 并写进 data_gaps |

**六维装不下该品类核心能力时**：用 `performance` 承载"该品类最核心的那项能力"，并在报告里显式写清"本表中 performance 指 XX"。**不许因为维度不够就改用形容词打分**——那会退回 v1 的错误。

## 五、怎么新增一个品类（扩展方法）

新增时只改本文件，按以下顺序填：

1. 先跑第二节四问，得到门槛候选；
2. 再搜 2–3 篇该品类的专业横评，反推"他们都在测什么" → 关键性能指标；
3. 找该品类的拆解/实测圈在哪里（论坛、垂类站点、UP 主） → 垂类信源；
4. 记录一个**真实翻车过的坑**（口径、兼容、虚标） → 典型坑；
5. 若该品类有特殊的权重敏感项，在第四节加一行。

**填完必须验证一次**：假装要买这个品类，看能不能只靠这一行派出准确的 Agent 1/2 任务。派不出来说明这一行写空了。
