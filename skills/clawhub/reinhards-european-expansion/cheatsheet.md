# 决策规则与推理辅助

> 沃尔夫冈·赖因哈德《征服世界》中的决策规则、判断标准与推理指南

## 核心判断规则

### 扩张动力判断

| 当你看到... | 应分析... | 因为... |
|------------|----------|--------|
| "欧洲统一扩张"的叙事 | 哪些政治体在竞争 | 碎片化竞争才是真正驱动力，不存在统一意志 (Ch1) |
| 少数人征服大帝国 | 疾病、联盟、法律、生态四重力量 | 军事行动只是冰山一角 (Ch6) |
| "技术优势决定胜负" | 组织制度差异 | sepoy体系证明制度优势比武器代差更关键 (Ch5) |
| "理性规划的扩张" | 错误假设+政治博弈+运气的交织 | 哥伦布的成功源于地球周长估算错误+地理巧合 (Ch2) |
| "先发者永远领先" | 知识外溢路径和竞争者进入方式 | 任何基于信息不对称的垄断都有保质期 (Ch3, Ch4) |

### 殖民统治形态判断

| 殖民地特征 | 预测类型 | 预测结果 |
|-----------|---------|---------|
| 沿海商站、兵力有限、面对成熟贸易网络 | 据点型 | 低成本但控制力脆弱，知识外溢后瓦解 (Ch3) |
| 温带气候、大量欧洲移民、原住民人口稀少 | 移民型 | 长期形成独立国家，原住民被替换 (Ch13-14) |
| 少数欧洲人、大量非欧洲人口、经济价值高 | 统治型 | 间接统治，去殖民化最复杂 (Ch5, Ch15, Ch19) |

### 现代化成败判断

| 条件 | 预测 | 理由 |
|------|------|------|
| 制度允许"换操作系统不换主机"（如日本天皇+幕府） | 现代化成功概率高 | 制度改革可在不否定整体前提下进行 (Ch16) |
| 皇帝本身即制度核心，改革=否定合法性 | 现代化失败概率高 | "中体西用"陷阱，技术无法转化为制度能力 (Ch16) |
| 只引进技术拒绝制度改革 | 必然失败 | 甲午战争证明没有制度现代化的技术现代化是空中楼阁 (Ch16) |

## 决策树

### 贸易公司是否会演变为殖民统治？

```
贸易利益是否大到需要军事保护？
├── 否 → 维持纯贸易（据点型）
└── 是 → 是否介入当地政治以保护贸易？
    ├── 否 → 维持武装商站
    └── 是 → 被扶持方是否反过来依赖公司军事支持？
        ├── 否 → 有限政治影响
        └── 是 → 沉没成本是否迫使更深介入？
            ├── 否 → 间接影响
            └── 是 → 升级为直接统治（非意图后果）
```
规则：每一步升级都是"为了保护上一轮投入"，而非实现帝国蓝图 (Ch5)

### 去殖民化路径预测

```
殖民地是否有大规模白人定居者？
├── 有 → 去殖民化=存在性战争（阿尔及利亚、罗得西亚、南非）
└── 无 → 殖民母国是哪种类型？
    ├── 英国 → 渐进移交，保留制度框架（加纳→尼日利亚）
    ├── 法国 → 公投突变或全民独立（1960年14国同时独立）
    ├── 葡萄牙 → 顽抗到底，殖民战争反噬母国（1974年康乃馨革命）
    └── 其他 → 国际压力决定速度（荷兰在印尼被美国/联合国迫使撤退）
```
规律：白人定居者规模越大，去殖民化越暴力越漫长 (Ch22)

## 关键阈值与转折信号

| 阈值/信号 | 含义 | 案例 |
|----------|------|------|
| 贸易商品代际转移 | 上一代领先者将被淘汰 | 香料→纺织品→饮品，VOC衰落、EIC崛起 (Ch4) |
| 人口崩溃>50% | 社会组织不可逆瓦解 | 美洲原住民人口降80-90%后无法有效抵抗 (Ch6) |
| 殖民国家开始大规模发展投入 | 去殖民化加速器启动 | 晚期殖民主义培养了推翻自身的精英 (Ch22) |
| "白人威信"军事失败 | 殖民合法性永久碎裂 | 1942年新加坡沦陷后殖民秩序不可恢复 (Ch21) |
| 帝国财政收入>20%依赖单一来源 | 资源诅咒/系统性脆弱 | 西班牙白银依赖导致制造业萎缩（荷兰病）(Ch7) |
| 殖民地税收占帝国GDP小比例但机会成本大 | 剥削影响被低估 | "财富外流"对印度资本积累的灾难性影响 (Ch5) |

## 诊断"闻味"指南

| 闻到... | 实际可能是... |
|--------|-------------|
| "文明使命"/"教化使命" | 经济剥削的意识形态包装 (Ch17-18) |
| "和平移交权力" | 帝国将暴力代价转嫁给本地社会的退出策略 (Ch21-22) |
| "自由贸易" | 以武力为后盾的市场准入（鸦片战争）(Ch16) |
| "发展援助"/"结构调整" | 殖民时期"文明化使命"的后殖民延续 (Ch24) |
| "传统权威"/"习惯法" | 殖民者发明/重构的"传统"（间接统治建构）(Ch19) |
| "无人之地"（terra nullius） | 否定原住民土地权利的法律虚构 (Ch14) |
| "帝国胜利" | 财政危机的前兆（七年战争→美国革命）(Ch10) |
| "改革改善了治理" | 革命的温床（托克维尔陷阱）(Ch11) |

## 权衡矩阵

### 殖民治理模式选择

| 维度 | 间接统治（英） | 同化（法） | 强迫种植（荷） |
|------|-------------|-----------|-------------|
| 行政成本 | 最低 | 中等 | 低（利用现有结构） |
| 利润提取 | 中等 | 低 | 最高（国家预算1/3） |
| 政治稳定 | 高（利用本地精英） | 中（制造"黑皮肤的雅各宾派"） | 低（饥荒引发动荡） |
| 长期遗产 | 族群分裂 | 语言/文化依附 | 单一经济锁定 |
| 典型失败 | 尼日利亚妇女战争 | 法国"黑皮肤的法国人"理想破灭 | 爪哇饥荒 |

### 去殖民化后的制度路径预测

| 殖民遗产类型 | 独立后预测 |
|------------|----------|
| 资源丰富+精英培养不足 | 资源诅咒+外国干预+独裁（刚果模型）(Ch22) |
| 单一经济+国际金融机构介入 | 经济依附持续（加纳可可模型）(Ch24) |
| 宗教/族群被殖民者利用 | 分治暴力+持续冲突（印巴/巴以模型）(Ch21) |
| 白人定居者社会 | 种族压迫制度化（南非模型）(Ch22) |
| 武装斗争建国 | 军事化政治+威权主义（阿尔及利亚/越南模型）(Ch22) |

## 关键反模式速查

| 反模式 | 正确理解 |
|--------|---------|
| 欧洲有统一扩张意志 | 碎片化竞争才是驱动力，各国互相拆台 (Ch1) |
| 技术优势决定征服 | 组织制度优势+对手内部瓦解更关键 (Ch5) |
| 殖民剥削使所有人贫困化 | 部分本地精英获利，剥削机制是重塑分配结构 (Ch5) |
| 帝国主义=经济决定论 | 民族声望、战略焦虑、意识形态同等重要 (Ch17-18) |
| 去殖民化=进步 | 独立后可能经历内战、独裁、种族灭绝 (Ch21-22) |
| 殖民主义全是坏事 | 殖民遗产是辩证的：铁路、医学、民族国家框架也是遗产 (Ch24) |
