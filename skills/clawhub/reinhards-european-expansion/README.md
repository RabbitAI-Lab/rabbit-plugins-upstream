# 征服世界：欧洲扩张全球史知识库技能

> 沃尔夫冈·赖因哈德经典巨著的结构化智能助手技能，600年全球史一手分析框架即装即用。

## 这是什么？

这是一个**智能助手知识库技能**，将沃尔夫冈·赖因哈德（Wolfgang Reinhard）的《征服世界：一部欧洲扩张的全球史，1415～2015》（全三册）转化为你的智能助手可以直接引用的结构化知识库。

安装后，你无需重新翻书，智能助手就能基于书中实际内容回答关于欧洲扩张史、殖民主义、帝国主义、全球化等话题的深度问题。

## 技能包含什么？

| 文件 | 内容 | 用途 |
|------|------|------|
| `SKILL.md` | 12个核心分析框架 + 章节索引 + 58条主题索引 | 智能助手的核心参考，常驻内存 |
| `chapters/ch01-ch24` | 24章深度摘要（每章含核心观点、框架、概念、案例） | 按需加载，问哪章读哪章 |
| `glossary.md` | 48个专业术语（含德/西/葡原文） | 术语精确定义 |
| `patterns.md` | 15个分析模式（含适用场景与权衡） | 深度分析参考 |
| `cheatsheet.md` | 决策规则、判断矩阵、诊断指南 | 快速推理辅助 |

## 核心分析框架一览

1. **碎片化竞争驱动扩张** — 为什么是欧洲而非中国
2. **发展差距（Entwicklungsdifferenz）** — "为什么是欧洲"的核心分析工具
3. **殖民地类型学（三分法）** — 据点型/移民型/统治型
4. **贸易→统治升级阶梯** — 商业组织如何滑向政治统治
5. **征服四重奏** — 疾病、联盟、法律、生态的交织力量
6. **制度弹性决定长期胜负** — 路径依赖与被迫退路的价值
7. **军事优势来自制度而非技术** — sepoy体系的启示
8. **海洋即系统** — 风带-洋流结构与航海知识制度化
9. **最小武力、最大制度的海上帝帝国** — 葡萄牙的节点控制模式
10. **恐慌驱动的瓜分** — 帝国主义的非经济驱动力
11. **晚期殖民主义的发展陷阱** — 发展政策如何加速去殖民化
12. **殖民遗产的三层分析** — 物质层/制度层/话语层

## 技术规格

- **原著规模**: 全三册，约13万字中文
- **技能规模**: SKILL.md 约4,000 tokens + 24个章节文件（按需加载）
- **Token 效率**: 比将全书放入上下文节省 24-51 倍 token 消耗
- **语言**: 中文为主，关键术语保留德文/西班牙文/葡萄牙文原文
- **格式标准**: Agent Skills 开放标准（SKILL.md 格式）
