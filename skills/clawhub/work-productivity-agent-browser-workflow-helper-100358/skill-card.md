Risk: Broad trigger wording may activate the skill for ordinary browser, automation, CLI, or bug-fix requests. <br>
Mitigation: Invoke it deliberately for Agent Browser workflow planning, setup hardening, reliability work, or adjacent skill creation. <br>

Mitigation: Review generated artifacts, run local validation, and check assumptions before deployment. <br>
