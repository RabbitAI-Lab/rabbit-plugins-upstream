## Known Risks and Mitigations: <br>
Risk: Generated package-add commands may change a project dependency set. <br>
Mitigation: Review package installation commands before running them and align them with the project's package manager and dependency policy. <br>
Risk: Remote media assets can expose sensitive project data or create unreliable renders. <br>
Mitigation: Prefer local or trusted media assets for sensitive projects and verify remote asset permissions, CORS behavior, and availability. <br>
Risk: Cloud transcription can send confidential audio to an external provider. <br>
Mitigation: Check provider privacy, retention, consent, and compliance terms before using cloud transcription for confidential audio. <br>
