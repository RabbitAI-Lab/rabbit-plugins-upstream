# Lessons — 跨任务复盘经验库

> **定位**：复盘晋升机制的存储层。B10 复盘格产出的是"单任务经验"，本文件存放的是"跨任务规则"——
> 下次设计 skill 时，Phase 0 后注入高频规则、各格引导时按触发格取用。**这是让复盘积木真正跑起来的关键一环。**

## 晋升机制（与主流水线的联动协议）

```
B10 复盘（10-复盘.md，任务级）
  ① 复盘产出「规则候选」：失败/成功 → 归纳为通用规则
  ② 晋升检查（四问，全过才写入本文件）：
     a. 跨任务可复用？（不是单案例特例、不含任务专名）
     b. 有明确触发时机？（哪一格 B0X、看到什么信号就该想起它）
     c. 有真实证据？（来源任务可溯，不是想当然）
     d. **能落检查项吗？**（能写成机器判定的正则/枚举就当天加进 validate_skill 或
        check_blueprint 并注明检查名；不能就写「不适用 + 理由」——见 L10 / D-132）
  ③ 写入**权威源** `library/lessons.json` 条目区（保持 ID 递增）后跑
     `python scripts/compile_library.py --write` 重编译本文件；并在 10-复盘.md 标注「已晋升 → LXX」
     ⚠️ 本 md 是**生成物，禁止手改**——手改会被下次重编译覆盖，且 `knowledge verify` 的 C5 报 E013
  ④ 引用计数（**机器写回，F6 钩子**），两个入口：
     · 手动：`check_blueprint.py <蓝图目录> --tick-lesson LXX`（多条逗号分隔）
     · **自动（推荐）**：在 B10 按「LXX → 落点」格式写回流标注后跑
       `check_blueprint.py <蓝图目录> --tick-reflow` —— 自动提取 ID、+1 计数、
       写「最近命中」与「回流：落点」（**幂等**，同天同蓝图不重复计数）
       —— 两个入口都写 `library/lessons.json` 的 `refs / lastHit / reflow` 字段并按需重编译
  ⑤ 降级：连续 10 个任务引用为 0（以机器计数为准）→ 移入文末归档区（防知识库腐烂）
```

**注入时机**（对设计师的指令）：
- **Phase 0 后**：读本文件，取「引用计数 × 触发格」与当前任务最相关的 TOP 3 规则，在 B01 前口头提示（不阻塞）。
- **各格引导中**：命中某条规则的「触发信号」时，先讲规则再继续引导。
- **B10 收尾**：问用户"本任务有没有值得晋升进经验库的规则？"——有则走②的四问检查。
