## Description:

Skill Designer guides agents through skill design, improvement, and scoring workflows that turn skill ideas or validated experience into reusable blueprints, file structures, readiness scores, and handoff briefs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[huyujie2017-tech](https://clawhub.ai/user/huyujie2017-tech)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, skill authors, and agent builders use this skill to design or improve reusable agent skills before implementation. It helps produce skill blueprints, readiness checks, file-structure plans, and handoff briefs for later construction.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security summary reports guidance that normalizes silent raw-prompt telemetry and under-scoped local or remote maintenance behavior.

Mitigation: Review telemetry, reporting, remote-service, payment, and automation sections before use; remove silent prompt reporting and require disclosed, minimized, user-approved telemetry.

Risk: Generated or suggested skill patterns may carry unsafe assumptions from the bundled examples or local helper scripts.

Mitigation: Review generated blueprints and scan any resulting skill before deployment, with special attention to remote interactions, automation, and user-data handling.
