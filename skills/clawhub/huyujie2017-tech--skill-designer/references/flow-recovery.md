# 流程恢复协议（Flow Recovery）— 机器状态机

> v1.6.0 起从"口头快照"升级为**机器可读状态**：蓝图落盘 + checkpoint 表 + 检查脚本，断点续跑不再靠记忆或口头复述。

---

## ① 状态载体：蓝图目录 + checkpoint

Phase 0 确认后由 `scripts/init_blueprint.py` 生成蓝图目录，**进度状态全部落在 `index.md` 的 checkpoint 表**（五字段）：

```
## 进度快照（checkpoint）

| 字段 | 值 |
|------|-----|
| 当前格 | B05 |
| 已完成 | B01,B02,B03,B04 |
| 本格产物 | 输入输出契约已定 |
| 待确认 | 边界 3 条 |
| 下一步 | B06 决策积木 |
| 更新时间 | 2026-08-20 |
```

**更新纪律**：每格收尾（产物写入对应文件后）必须更新此表——没更新 checkpoint 就等于没走完当前格。

## ② 断点续跑协议（机器优先）

新对话 / 会话中断后，**先跑机器检查，再说话**：

```
python scripts/check_blueprint.py <蓝图目录>
```

| 情况 | 动作 |
|------|------|
| 蓝图目录存在 | 读检查报告：缺口格、一致性警告、checkpoint → 复述"我们停在 X，已完成 Y，缺 Z。接着走？" |
| 报告有一致性警告（C2 等） | 先按警告修正（声明已完成但有填空 → 补填或回退状态） |
| 蓝图目录缺失 | 从对话内最近一个已确认格重放（三句话小结 + "对吗"），确认后补跑 init 落盘 |
| 用户想重来 | 尊重，但提示"已完成格的产物可复用，不必重填" |

> 脚本不可用时降级：直接读 index.md 的 checkpoint 表人工续跑（表格本身就是状态机）。

## ③ 卡壳恢复状态机（4 种卡壳 → 标准恢复动作）

| 卡壳类型 | 症状 | 自动恢复动作 |
|------|------|------|
| 用户沉默 / 不确定 | 连续 2 次无实质回答 | 给**二选一**（设计师基于画像推测 A/B），缩小范围，不空等 |
| 回答跑题 | 答的内容与该格 MVP 无关 | 复述该格 MVP 问题 + 用"想象一个具体的人在什么场景打开它"拉回 |
| AI 漏格 / 跳格 | 发现前一格产物缺失 | 跑 check_blueprint 确认缺口 → 回退到缺失格补填（不回退已确认格） |
| 会话中断 / 重开 | 忘了进行到哪 | 跑 check_blueprint 读状态 → 按 ② 续跑 |

> 恢复动作优先用**封闭式选项**（给 A/B/C），而非开放式追问——卡壳时开放式问题会加剧沉默。

## ④ 回退协议

用户说"第 N 格我理解错了 / 改主意了" → **只回退到第 N 格**重填，N 之前的已确认产物不动：

```
例：走到 B07，用户说"B03 设计模式我改主意了"
  → 回退到 B03 重填模式处方
  → B04–B06 若不受影响则保留；受影响则从 B03 顺延重走
  → 更新 checkpoint（已完成列表同步增删），继续
```

判据：**只有被改动格的下游产物才需要重走**；上游与无关格保持不动。回退后必跑一次 check_blueprint 校验状态一致性。

## ⑤ 重试上限（可触线规则）

> **为什么单列**：回退与恢复是最容易"无限打转"的环节——agent 不知道试到几次该停。每条都给**数字上限 + 到顶后动作**，到顶动作是**换策略**而不是"再试一次"。
> 与主路由 [SKILL.md](../SKILL.md) §2「⚖️ 可触线规则」同源，本页是它的展开。

| 动作 | 上限 | 到顶后动作（换策略，不是再试） |
|------|------|------------------------------|
| 同一卡点套用 ③ 状态机自动恢复 | **至多 2 次** | 第 3 次**转人工确认**并输出卡点诊断（说明已试过什么、为什么卡住），不继续自动恢复 |
| 同一格回退重填（④） | **至多 2 次** | 第 3 次**停下拉通整体需求**——多半是上游 B01–B03 没定清楚，回退到源头而非当前格 |
| 断点续跑时 `check_blueprint.py` 连续报错 | **至多 2 次** | 第 3 次**降级人工读** `index.md` checkpoint 表续跑（表格本身就是状态机） |
| 用户沉默给二选一 | **至多 2 轮** | 第 3 轮给**默认方案 + 一句话假设声明**，继续推进不停摆 |

**元纪律**：修改本页任何恢复/回退规则时，必须同步检查是否仍带数字上限——`validate_skill.py` 第 12 项会扫主路由，本页靠人工守。
