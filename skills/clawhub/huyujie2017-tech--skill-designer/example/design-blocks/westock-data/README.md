## 一句话结论

westock-data 是**"防呆优先"**的成熟数据 skill——它几乎每条纪律都是针对**已观察到的 agent 失败模式**反向写成的。它有两样我们没有的东西：**纪律的可数上限**、**可验证性决定严格度**。更关键的是，回照自己时照出一个真 bug：**我们教别人"规则要可触线"，自己的主路由却 0 条可触线规则**。

## 三条元设计

| ID | 名称 | 一句话原则 |
|---|---|---|
| M1 | 失败模式驱动设计 | 先枚举 agent 会怎么错，再把每条错写成可执行边界 |
| M2 | 成本显性化 | 每条纪律写出"不这么做的代价"——理由栏是执行动力 |
| M3 | 约束前置 + 完整性自检 | 漏项的前置比不前置更危险（它自己在此翻车：D1） |

> M2 与既有「成本感知设计」（memory-manager-v2）同源，**在第三个不同来源的 skill 上再次独立出现**——建议升格为设计原则库一级条目。
