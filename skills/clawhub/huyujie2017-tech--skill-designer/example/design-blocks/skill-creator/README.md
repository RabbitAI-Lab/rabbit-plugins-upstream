> **一句话**：官方"施工手册"的极简基线——与 skill-designer **正交互补**（creator=怎么写好 / designer=该不该做、做什么），值得学的不是它的流程和脚本，而是三个能让四阶段对话问得更准、蓝图落得更实的手法。

## 五维对比结论（速览）

| 维度 | 结论 |
|------|------|
| 架构定位 | 正交互补，非竞争：设计前置 vs 施工落地 |

## 同批入库的独特性三挖（对话技术，与 A-054 同族）

- **B02 · 资产挖掘**："你有哪些别人没有的资料可以喂进来？"
- **B03 · 创意确认**（AI 建议三件套之前问）："有没有想注入的独特玩法/原则/哲学？"——防「按建议」批量采纳淹没用户创意
- **B05-O · 模板贴样**："有现成模板/样例要贴着做吗？"——样例即输出事实源

## 方法论沉淀

**好的采样不是把别人的好全搬来，而是先查自己库里有没有，再只拿真缺的那几块**；用定位标尺（"能不能让四阶段对话产出更好的蓝图"）过滤候选，并把不收录的理由写清楚（防下次误升格）。
