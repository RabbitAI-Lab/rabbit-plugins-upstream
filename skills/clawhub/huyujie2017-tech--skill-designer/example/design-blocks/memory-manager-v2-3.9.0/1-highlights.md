## 亮点条目（来自 skill-rebuild · memory-manager-v2-3.9.0）

### A-301 · 把运营成本做成一等公民功能
- **落位**：B01
- **触发信号**：设计任何输出会进上下文或消耗 token 的 skill 时
- **证据**：memory-manager SKILL.md:21-25『定位：让进上下文的记忆更小、更准、更省 Token』+ SKILL.md:134-139 三色预算灯与『估算』标注；token.py:205-291 统一 token 折算口径
- **要点**：给 skill 定位时先问『它的运营成本是什么』，把成本项（token/时间/存储）提升为一等功能（预算灯、趋势、节流阀），而不是事后补丁

### A-302 · 给定时破坏性动作设预览默认
- **落位**：B01
- **触发信号**：用户要求定时自动化且任务含删除/归档等破坏性动作时
- **证据**：memory-manager SKILL.md:159-172：每周清理默认以预览排定，--execute 仅显式 opt-in，并声明『启发式可能静默误归档』的风险
- **要点**：无人确认场景的默认行为必须是 dry-run，破坏性执行永远 opt-in；且把这条护栏写进 SKILL.md 让评审/用户看得见

### A-303 · 分级设计触发词体系
- **落位**：B02
- **触发信号**：写 SKILL.md 触发设计或 description 时
- **证据**：memory-manager SKILL.md:29-75：一级直触/二级上下文/三级明确请求三级触发词表，每条带命令映射+场景例句，末尾附排除规则（NOT for）
- **要点**：触发词按『用户语气明确度』分级而不是罗列关键词，排除规则防误触；每条触发词都要能映射到具体命令和例句

### A-304 · 建立四级操作门禁矩阵
- **落位**：B06
- **触发信号**：skill 含任何写操作、删除或配置修改时
- **证据**：memory-manager SKILL.md:79-87 门禁表（只读/预览/破坏性/配置四级+覆盖方式）；cli_handlers.py:40-57 _require_confirmation 非 TTY 拒绝+--force 显式跳过
- **要点**：把操作风险做成显式矩阵（默认行为+覆盖方式）而非散落的 if 判断；『非 TTY 自动拒绝 + --force opt-in』是自动化友好与安全的平衡解

### A-305 · 用输入指纹做缓存失效判据
- **落位**：B07
- **触发信号**：命令存在重复计算（排序/扫描/打分）且输入可枚举时
- **证据**：memory-manager core_rank.py:26-55 _rank_signature：SHA256(文件集{path,mtime,size}+权重+版本) 相同即复用历史分级；注释写明『必须实时 stat 而非 lru 否则缓存永不失效』的踩坑推理
- **要点**：缓存失效判据=全部输入的决定论指纹；踩坑推理写进代码注释，防止后人改回有缺陷的实现

### A-306 · 在冷路径写穿透填充缓存
- **落位**：B07
- **触发信号**：冷加载慢、缓存可后置生成且写入失败不致命时
- **证据**：memory-manager core_load.py:37-63 _persist_summary：冷加载实时生成摘要并原子落盘（tmp+os.replace），落盘失败仅下次不命中不影响本次返回
- **要点**：只读路径可以有非致命写副作用——『顺手把缓存填热』；前提是失败语义清晰：降级为下次重算，绝不影响本次结果

### A-307 · 收敛安全原语到单点迭代器
- **落位**：B05
- **触发信号**：多个命令都需要遍历/读写同一类敏感文件时
- **证据**：memory-manager config.py:390-416 iter_memory_files：symlink 跳过、路径穿越校验、MEMORY.md 保护全部收敛在一个生成器里，16 个模块统一走它
- **要点**：安全校验必须收敛为单一 choke point，散在 N 处必有 1 处漏；任务分析阶段就识别『哪些操作要过同一道闸』

### A-308 · 用内置自检验证安全声称
- **落位**：B08
- **触发信号**：SKILL.md 声称了安全能力（注入防护/路径防御）需要给出证据时
- **证据**：memory-manager cli_handlers.py:522-556 _handle_self_test：验证 prompt 注入按数据处理、恶意 ZIP 穿越被拦截、核心命令冒烟，输出 JSON 可作 CI 证据
- **要点**：安全声称要配『可执行的证明』而非文档表格；self-test 输出结构化 JSON，评审和自动化都能直接消费

### A-309 · 把量化质量门写进版本复盘
- **落位**：B10
- **触发信号**：版本发布复盘或质量收尾时
- **证据**：memory-manager CHANGELOG.md:3-9：『CC>10=1、嵌套>4=1、文件>800行=0、pytest 40 passed、评分 9.4』+ 遗留项显式列出（i18n_audit.py main=12 建议后续拆分）
- **要点**：复盘记三件事：量化指标行（可机器复核）、修了什么+为什么、遗留项清单——下次迭代从遗留项开始而非从零开始

### A-310 · 分层设计依赖并优雅降级
- **落位**：B03
- **触发信号**：skill 需要跨环境分发或目标机器可能离线时
- **证据**：memory-manager SKILL.md:19『纯标准库；可选 colorama/jieba/tiktoken 缺失时自动回退』；config.py:133-142 colorama 缺失回退空色表；token.py:249-258 tiktoken 缺失回退 CJK 启发式+lru 上限防内存膨胀
- **要点**：依赖分『核心零依赖+增强可选』两层，每个可选依赖都要写明降级路径并把降级声明写进兼容性说明——降级后功能不受影响才是真零依赖
