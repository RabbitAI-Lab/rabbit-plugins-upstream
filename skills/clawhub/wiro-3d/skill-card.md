## Description:

Turn a photo or a description into a 3D model file (GLB and more) with a Wiro AI model. Use when the user wants a 3D model made from a photo or a description with Wiro AI or through the Wiro MCP server.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and creators can turn a photo or text description into 3D model files with a Wiro AI model through the Wiro MCP server.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A local project file may be sent to Wiro for external processing when an API key is available.

Mitigation: Use only files you are comfortable sharing with Wiro and confirm before starting generation.
