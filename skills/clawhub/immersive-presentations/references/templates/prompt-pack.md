# Prompt Pack

Reusable prompts for invoking the skill.

## Create A Full Presentation

```text
Use $immersive-presentations to create a complete immersive web presentation from this briefing.

Topic:

Audience:

Goal:

Duration:

Tone:

Important ideas/data/examples:

Technical stack:

Use the existing gsap-motion skill for animation execution if available.

Do not build a deck. Build an experience that can be presented.
```

## Convert A Conventional Deck Into An Experience

```text
Use $immersive-presentations to transform this conventional slide outline into an immersive narrative web presentation.

Replace slides with acts and scenes. Identify visual metaphors, persistent objects, scene transitions, interaction, presenter mode, debug mode, responsive behavior, accessibility, and where gsap-motion should execute the motion.

Original outline:
```

## Review An Existing Presentation

```text
Use $immersive-presentations to review this presentation as an immersive narrative experience.

Find where it still behaves like a deck, where scenes lack visual demonstration, where motion is decorative, where continuity breaks, and where presenter/accessibility/responsive behavior is missing. Then propose concrete fixes.
```

## Generate Only The Narrative Plan

```text
Use $immersive-presentations to create only the narrative architecture and scene plan for this topic. Do not implement code yet.

Include acts, scene list, visual metaphors, object permanence, camera behavior, interaction model, pacing, accessibility notes, and gsap-motion delegation notes.
```
