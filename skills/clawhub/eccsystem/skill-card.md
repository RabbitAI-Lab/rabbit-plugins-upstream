## Known Risks and Mitigations: <br>
Risk: The bundled installer can change local agent or project state by installing, overwriting, or uninstalling skills. <br>
Mitigation: Review the installer and bundled skills before use, run dry-run mode or a throwaway agent profile first, and avoid force or uninstall modes unless backups are available. <br>
Risk: Some bundled workflows encourage high-impact actions such as reading local agent configuration, modifying agent files, running evaluations, capturing traces, sending configuration data to external APIs, or merging repository changes. <br>
Mitigation: Require explicit confirmation and clear scope before taking those actions, especially when working with sensitive repositories, credentials, or production systems. <br>
