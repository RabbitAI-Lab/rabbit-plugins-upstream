## Description:

Detect, validate and write JSON-LD structured data. Pick schema types by page type, fill Google's required properties, link entities in one @graph, and drop retired rich results. Use for "add schema to my site", "check my structured data", "fix Rich Results Test errors", "product schema", "missing field shippingDetails".

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: JSON-LD sent to external validation services may contain private or unpublished information.

Mitigation: Remove or replace private and unpublished values before using third-party validators; use sanitized sample data when validating privately held content.
