# Official source pairings

Rule: whenever a formal policy or procedure page is surfaced, pair it
with the platform's own friendlier creator-facing guidance when one
exists, friendly first for orientation, formal one click away for the
letter of it. For complicated issues, surface several current official
sources together as reassurance: seeing the platform explain the same
thing in more than one place, in more than one register, is itself
calming and confirms the skill isn't the only voice saying it. All
links open in new tabs. Metadata convention per S-08: accessed date
always; "Last updated" only when the source states one (none of the
pages below do).
