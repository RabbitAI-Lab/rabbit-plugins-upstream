## Description:

A productivity toolkit that checks live capabilities and uses a remote service to create and process downloadable files.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Individuals use this skill to request presentations, cover art, web pages, subtitles, audio track separation, and document conversions, then receive downloadable results. Available services are checked against the live catalog.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Materials uploaded to the remote provider may contain sensitive information, and remote data retention is unverified.

Mitigation: Upload only materials intended for remote processing, and avoid sharing private task credentials or download links in public logs.

Risk: A paid order or balance payment could be submitted without checking its exact terms.

Mitigation: Review the quoted deliverables and price, then confirm each specific order before payment.
