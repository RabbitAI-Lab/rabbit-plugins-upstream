## Use Case: <br>
Developers and agents use this skill to work with local PDFs, including extracting text and tables, creating or modifying documents, merging or splitting pages, handling forms, and generating PDF-processing code or shell commands. <br>

### Deployment Geography for Use: <br>

## Known Risks and Mitigations: <br>
Risk: PDF extraction, decryption, and table or text processing can expose sensitive or confidential document contents. <br>
Mitigation: Review commands before running them and use only authorized documents, especially when working with encrypted, sensitive, or confidential PDFs. <br>
Risk: Examples that write merged, split, encrypted, decrypted, OCR, or extracted output files can modify local work products or create unintended copies. <br>
Mitigation: Run examples in a controlled working directory, inspect output paths, and keep backups of source PDFs before writing new files. <br>
