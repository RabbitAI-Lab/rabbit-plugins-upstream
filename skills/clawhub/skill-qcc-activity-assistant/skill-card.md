## Use Case: <br>
QCC practitioners, quality teams, and presentation preparers use this skill to inventory QCC project materials, create PPT outlines, draft speaker notes, check pre-presentation completeness, and summarize uploaded chart images in the context of the project storyline. <br>

## Known Risks and Mitigations: <br>
Risk: The skill can activate for broad presentation or speech-writing requests. <br>
Mitigation: Use it only for QCC project work and avoid providing unrelated private documents when the conversation is not about a QCC project. <br>
Risk: Generated QCC presentation materials may reflect incomplete or inaccurate project inputs. <br>
Mitigation: Run the skill's inventory and completeness checks first, then have the user verify key project facts, chart interpretations, conclusions, and speaker notes before use. <br>
Risk: The packaged artifact only contains SKILL.md, while the skill text references scripts, templates, and reference documents. <br>
Mitigation: Confirm the required local scripts, templates, references, and Python dependencies are available before relying on file generation workflows. <br>
