## Use Case:

Analysts and reporting teams turn supplied metric summaries into HTML digests for stakeholder planning and leadership updates.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A local HTML report containing supplied metric data may be exposed if saved in a shared or sensitive directory.

Mitigation: Choose a dedicated workspace output folder and review the report before sharing it.
