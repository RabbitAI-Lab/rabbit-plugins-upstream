## Description:

Creates or completes editable PowerPoint presentations with slide copy, speaker notes, and sources retained in JishuDB.

This skill is ready for commercial/non-commercial use.

## Publisher:

[bowen-aijishu](https://clawhub.ai/user/bowen-aijishu)

### License/Terms of Use:

MIT-0

## Use Case:

People preparing work updates, proposals, or knowledge-sharing talks use this skill to create or repair an editable slide deck with speaker notes and cited sources.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow may install and launch persistent JishuDB Desktop software and change the host's MCP client configuration.

Mitigation: Review the setup plan and require clear user confirmation before running any installer execute command.

Risk: Presentation sources and drafts may be retained in JishuDB.

Mitigation: Obtain task-specific approval for source access, transfer, destination, and retention before uploading materials.
