## Description:

Helps coding agents search past local AI coding sessions for decisions, fixes, and project context using deja-vu.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vshulcz](https://clawhub.ai/user/vshulcz)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and coding agents use this skill to recall past decisions and successful fixes before making changes, recommending tools, or repeating investigations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad searches across local AI coding sessions can expose sensitive details from other tools or projects.

Mitigation: Review the privacy scope before installing; use project-scoped, task-specific recalls and avoid sharing unrelated sensitive history.
