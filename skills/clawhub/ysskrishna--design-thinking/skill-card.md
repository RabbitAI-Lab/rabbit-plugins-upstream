## Description:

Use for design thinking, or when a product or service problem needs user understanding before solutions: "what do users really need?", "how might we...", "plan a discovery sprint", "validate this concept". Skip when the spec is frozen or the task is code maintenance.

This skill is ready for commercial/non-commercial use.

## Use Case:

Product, service, and UX teams use this skill to understand unclear user needs, frame a design challenge, explore concepts, describe low-fidelity prototypes, and plan validation before building.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security review is marked benign but incomplete because one local reference could not be resolved.

Mitigation: Review the unresolved reference and relevant guidance before relying on the skill's recommendations.

Risk: Design conclusions may overstate what is known when little or no real user input is available.

Mitigation: Keep the point of view narrow, label inferences, and do not invent research or user quotes.
