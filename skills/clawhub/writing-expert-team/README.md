# 写作专家团（Writing Expert Team）

把“高质量内容生产”做成一支可模拟的多角色团队。单个 AI 运行时在同一会话内按“团长路由”切换角色，从模糊想法一路走到排版成稿，复现团队协作效果。

> 适配平台：WorkBuddy / 同类支持 SKILL.md 的 Agent 运行时。纯文本与逻辑，无私有依赖，开箱即用。

## 它能帮你做什么

- **自媒体爆款文批量生产**（小红书 / 公众号 / 知乎）：内置经 100+ 篇法律科普爆款验证的「爆款公式」。
- **强合规领域科普文**（法律 / 财税 / 医疗）：强制「法律审核」红线，杜绝失效法条与违规表述。
- **个人写作风格克隆**：6 维风格画像 + 多画像切换，克隆你的文字味道。
- **单角色求助**：只要选题、只要审稿、只要排版，按需调用，不必跑完整流程。

## 两大差异化资产（本技能独有）

1. **爆款公式**（`references/viral_formula.md`）：标题钩子 / 4 种开头 / 4 种正文结构 / 法条“划重点 + 大白话” / 结尾三件套。已在真实流量验证。
2. **发布红线底座**（`references/redlines.md`）：中文引号、HTML 实体、字体字形覆盖、法律合规四道质量闸门，从源头杜绝“豆腐块标题”“英文直引号”等发布事故。

## 10 角色流水线

`刘风格 → 赵选题 → 张素材 → 王整理 → 李文章 → 吴查查 → 周审稿 → 刘律师 → 陈排版 → 公众号发布`，由 `S.流程调度员` 与 `M.元数据桥接师` 统一管理。完整职责见 `references/roles.md`。

## 快速开始

| 你想做的事 | 直接说 |
|---|---|
| 跑完整流程 | 「启动写作流程，选题：二手房定金纠纷，受众：购房小白」 |
| 只要选题 | 「帮我策划 5 个高潜选题」 |
| 只要审稿 | 「按法眼金线审这篇稿子」 |
| 克隆风格 | 「分析我的写作风格，建一个画像」 |
| 中途接入 | 「我已有选题和素材，帮我整理框架」 |

## 配套工具

- **`scripts/redline_check.py`** — 可移植红线检查器，扫描 `.md/.txt` 中的英文直引号与 HTML 实体，支持 `--fix` 自动修复：
  ```bash
  python scripts/redline_check.py ./articles --fix
  ```
- **`examples/sample_difayan_article.md`** — 一篇按爆款公式产出的真实样例成品，先看质量再决定。

## 自定义

- **风格**：首次运行刘风格会引导建立画像；可建多个画像适应不同平台。
- **知识库（可选）**：王整理支持 IMA / 微信读书 / 印象笔记 / 公众号文章 / 本地 Markdown 导入；未配置仍可正常工作。
- **排版导出**：若环境已有小红书切图 / PPT / 长图脚本可直接调用，否则陈排版输出“排版指令集 + 视觉化提纲”。
- **法律审核**：默认通用三核查联网核实；若已装法律审核类专家技能可在该步加载增强，不强制依赖任何私有技能。

## 商标与合规

本技能为通用写作方法论工具。示例中涉及的法律条文请以最新官方版本为准；产出内容发布前请自行复核，本技能不替代执业法律意见。
