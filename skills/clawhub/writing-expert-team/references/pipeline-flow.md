# 管道流程定义（S.流程调度员核心规范）

> 定义写作管道的默认执行顺序、分支逻辑、异常处理、状态追踪。

---

## 一、默认执行顺序

```
步骤1: 刘风格（风格打磨）  ← 仅首次或风格变更时执行
步骤2: 赵选题（选题策划）
步骤3: 张素材（调研挖掘）  ← 基于用户选中的选题
步骤4: 王整理（知识整理）  ← 基于素材清单
步骤5: 李文章（文章撰写）  ← 基于框架+素材+风格
步骤6: 吴查查（事实核查）  ← 基于初稿
步骤7: 周审稿（审稿优化）  ← 基于核查后的文稿
步骤8: 刘律师法律审核      ← 周审稿优化单用户确认后触发
步骤9: 陈排版（排版设计）  ← 基于终稿+发布平台，刘律师审核通过后触发
步骤10: 公众号排版与发布（可选）← 陈排版完成后触发
```

## 二、触发条件与分支

### 首次启动（完整流程）
```
用户指令: "启动写作流程，选题为X，受众Y"
→ S 执行步骤1-8，步骤8（刘律师法律审核）通过后继续步骤9-10
```

### 已有风格（跳过步骤1）
```
用户指令: "用已有风格写X"
→ S 跳过步骤1，从步骤2开始，自动加载缓存的风格编码
```

### 单步重做
```
用户指令: "重做选题" / "重新调研"
→ S 从指定步骤重新执行，下游步骤标记为 pending 等待重新触发
```

### 单步跳过
```
用户指令: "跳过排版" / "不需要排版"
→ S 标记该步骤为 skipped，继续下游
```

### 插入步骤
```
用户指令: "在写完后再加一轮核查"
→ S 在指定位置插入额外步骤，重新编号下游
```

### 仅执行某角色
```
用户指令: "只做选题" / "只要排版"
→ S 仅执行指定角色，不触发管道
```

### 发布到公众号
```
用户指令: "发布到公众号" / "排版发布"
→ S 触发步骤10（公众号排版与发布）
→ 子步骤10a: 调用本机公众号排版工具（如已配置的主题预览类技能）→ 生成主题HTML + 预览链接
→ 子步骤10b: 调用本机公众号发布工具（需用户已配置 API）→ 检查配置 → 推送草稿（可选）
```

### 刘律师法律审核（普法类文章强制，其他可选）
```
用户指令: "法律审核" / "刘律师审核"
→ S 触发步骤8（刘律师法律审核）
→ 审核通过后，步骤9（陈排版）执行，完成后用户可说"发布到公众号"触发步骤10
```

## 三、异常处理

### 输出不达标
```
触发条件: 角色输出缺少必要字段、格式严重偏离规范
处理:
  1. S 检查 M 标准化后的产出物，验证必要字段是否存在
  2. 若不达标，标记当前步骤为 failed
  3. 重新触发该角色（最多重试2次）
  4. 2次仍不达标，向用户报告并等待指示
```

### 核查红灯过多
```
触发条件: 吴查查报告红灯数 >= 2
处理:
  1. S 将核查报告传递给周审稿
  2. 周审稿在优化单中标注"必改"项
  3. S 判断是否需要回退到李文章重新撰写（红灯 >= 3 时建议回退）
```

### 优化单必改项过多
```
触发条件: 周审稿优化单中"必改"项 >= 3
处理:
  1. S 触发李文章根据优化单修改
  2. 修改后重新走吴查查 → 周审稿
  3. 最多循环2轮，超过则交付用户终审
```

## 四、状态追踪格式

S 在每个步骤完成后更新 `pipeline-state.yaml`：

```yaml
session_id: {自动生成的会话ID}
current_step: {当前步骤序号}
started_at: {管道启动时间}
steps:
  - step: 1
    role: 刘风格
    status: done | in_progress | pending | failed | skipped
    doc_id: style_001
    started_at: 2026-06-05T15:30:00+08:00
    completed_at: 2026-06-05T15:32:00+08:00
    retry_count: 0
  # ... 每个步骤
notes: ""
```

## 五、用户交互点

管道在以下节点暂停，等待用户确认：

1. **步骤2之后**：赵选题输出5个选题，用户选择（或自定义）
2. **步骤7之后**：周审稿输出优化单，用户决定是否采纳修改
3. **步骤8之前**：用户确认是否需要法律审核（普法类文章必选）
4. **步骤8之后**：刘律师法律审核报告交付，用户确认修改（如有🔴/⚠️项）
5. **步骤9之前**：用户确认发布平台
6. **步骤9之后**：陈排版完成，终稿交付，用户复核
7. **步骤10触发**：用户复核确认无误后，可说“发布到公众号”触发步骤10（公众号排版发布）

其他步骤自动流转，不暂停。
