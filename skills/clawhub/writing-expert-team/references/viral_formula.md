# 爆款法律科普文写作公式（地产法眼验证版）

> 本公式来自「地产法眼」栏目 100+ 篇法律科普爆款文的沉淀，已在真实流量中验证有效。适用于小红书 / 公众号 / 知乎等平台的强共鸣科普文。其他领域可整体平移，仅需替换领域词与法条。

## 一、基础参数

- **长文字数**：2000–2500 字（模块 3 起标准；早期 1500 字为旧版，不建议沿用）。
- **叙事视角**：第一人称“律师/顾问”视角，亲历者口吻建立信任。
- **句式**：短句为主（平均句长 12–18 字），反问句多，节奏如“短句蓄势→长句解释→短句收尾”。
- **语气**：有温度、不鸡汤、像朋友聊天；口语词（吧 / 呢 / 啊）自然出现。
- **Emoji 适度**：📌 重点、💡 提示、⚠️ 风险、🔴 硬伤、📖 法条。不堆砌。

## 二、标题公式

```
标题 = 具体金额 / 痛点场景  +  (疑问句 | 法律结论)  +  [时效钩子]
```

示例：
- 痛点 + 疑问句：「签了二手房合同，房东突然反悔，定金能退吗？」
- 金额 + 法律结论：「逾期交房超 90 天，你可以解除合同并索赔」
- 痛点 + 时效钩子：「2024 年起，这 3 种物业费你可以拒交（附依据）」

反例（禁用）：「商品房买卖合同纠纷的法律分析」「论物业管理的若干法律问题」——像论文目录，3 秒内抓不住人。

## 三、4 种开头钩子（任选其一）

1. **凌晨求助消息**：模拟读者深夜发来咨询的口吻（“昨天半夜，一个粉丝给我发消息……”），制造即时感。
2. **真实咨询故事**：讲一个具体当事人的遭遇，带场景细节与情绪。
3. **场景短句轰炸**：连续 3–5 个“你是否……”短句，让读者对号入座。
4. **痛点列举共鸣**：罗列目标读者踩过的坑（“交了定金被吞 / 收房发现漏水 / 物业乱收费”）。

钩子目标：前 3 行让读者觉得“这说的就是我”。

## 四、4 种正文结构（任选其一，勿混用）

1. **坑一 / 坑二 / 坑三**：并列排雷式，每个坑 = 场景 + 法律点 + 破解。
2. **壹 / 贰 / 叁 / 肆 / 伍 / 陆**：中文序号分块，层层递进，适合体系化讲解。
3. **概念辨析递进**：A 是什么 → B 是什么 → A 与 B 区别 → 怎么用，适合易混概念。
4. **判断表 + 场景破解 + 操作顺序**：先给“什么情况适用什么规则”的判断表，再拆解典型场景，最后给操作步骤清单。

## 五、法条呈现铁律

- **划重点 + 大白话翻译**，绝不贴大段法条原文。原文吓退读者。
- **标准 / 比例用表格**（如赔偿比例、时效天数）。
- 每条法条必须注明：**法律名称 + 具体条款编号**（如《民法典》第 577 条）。
- 数字（工资标准、赔偿金额、天数）必须注明**时效与来源地区**（如“以广州市 2024 年标准为例”）。
- 易混制度要区分主体权利：如“一裁终局”需说明劳动者可起诉、用人单位只能申请撤销。

## 六、结尾三件套（缺一不可）

1. **实操清单**：读者可照做的 3–5 步动作。
2. **金句**：一句可截图传播的句子（有共鸣、有节奏）。
3. **裂变引导 + 栏目标识**：
   - 裂变：「转发给正在看房 / 买房的朋友」
   - 栏目 slogan：「关注「地产法眼」，守护你的每一平方米」
   - 法律依据汇总（列出本文引用的主要法条）
   - 免责声明（“本文为普法分享，不构成个案法律意见，具体案情请咨询律师”）
