# 默认项目文档模板

## 文件清单

请将你的项目文档模板文件（.docx 格式）按照以下命名规范放入此目录：

| 文件名 | 说明 | 占位符示例 |
|--------|------|------------|
| `00-封面.docx` | 项目封面页 | `{{project_name}}`, `{{tender_number}}` |
| `01-身份证明.docx` | 法人及授权代表身份证明 | `{{legal_rep}}`, `{{company_name}}` |
| `02-资质文件.docx` | 营业执照等资质证明 | `{{company_name}}`, `{{credit_code}}` |
| `03-承诺书.docx` | 项目承诺书 | `{{company_name}}`, `{{deadline}}` |
| `04-能力证明.docx` | 资格能力证明文件 | `{{company_name}}`, `{{credit_code}}` |
| `05-报价明细.docx` | 报价单及分项明细 | `{{total_price}}`, `{{company_name}}` |
| `06-业绩材料.docx` | 过往业绩证明材料 | `{{company_name}}` |
| `07-审计报告.docx` | 财务审计报告（需替换为实际文件） | - |
| `08-偏离说明.docx` | 技术/商务偏离说明 | `{{project_name}}` |
| `09-技术方案.docx` | 技术实施方案 | `{{tech_params}}`, `{{project_name}}` |

## 使用说明

1. **准备模板文件**：将你的 `.docx` 模板文件重命名为上述名称，放入此目录
2. **添加占位符**：在模板文件中需要填充的位置添加 `{{占位符}}` 格式的占位符
3. **测试验证**：使用技能生成文档包，检查填充是否正确

## 占位符参考

- `{{project_name}}` - 项目名称
- `{{tender_number}}` - 项目编号
- `{{tenderer}}` - 项目发起方
- `{{deadline}}` - 截止日期
- `{{company_name}}` - 公司全称
- `{{credit_code}}` - 统一社会信用代码
- `{{legal_rep}}` - 法定代表人
- `{{total_price}}` - 总报价
- `{{tech_params}}` - 技术参数（不可修改）

## 注意事项

- 营业执照、身份证、审计报告等文件需要手动替换为实际盖章/扫描件
- 技术参数必须原样保留，不得修改
- 生成后请人工审核所有文件
