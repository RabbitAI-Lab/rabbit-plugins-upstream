# 标书自动生成技能使用指南

## 概述

本技能已完善为自动化标书生成系统，可以自动收集信息并生成全套标书文档。

## 快速开始

### 1. 准备信息

创建一个 JSON 文件（如 `info.json`），包含以下信息：

```json
{
    "项目名称": "玛卡巴卡",
    "项目编号": "123455",
    "招标人": "奶龙",
    "投标截止日期": "2026 年 10 月 1 日",
    "公司全称": "南京理工大学",
    "统一社会信用代码": "12100000466007597C",
    "公司地址": "南京市玄武区孝陵卫街道孝陵卫街",
    "法定代表人": "马瑞",
    "授权代表": "库里",
    "授权代表电话": "18325690011",
    "银行账号": "4301017709001057330",
    "开户银行": "南京市工商银行军管支行",
    "开户银行联行号": "102301000132",
    "总报价": "待定"
}
```

### 2. 运行生成脚本

```bash
cd /home/ym/.openclaw/workspace/tender-generator-skill
python3 scripts/generate_bid.py --info info.json --output output --use-tma
```

### 3. 查看生成的文档

生成的文档将保存在 `output/` 目录中：

- `00-封面.docx` - 项目封面
- `01-承诺书.docx` - 承诺书
- `02-营业执照信息.docx` - 营业执照信息
- `03-报价单.docx` - 报价单
- `04-偏离表.docx` - 技术/商务偏离表
- `05-资格证明.docx` - 资格能力证明
- `06-技术文件.docx` - 技术实施方案

## 参数说明

| 参数 | 简写 | 说明 | 默认值 |
|------|------|------|--------|
| `--info` | `-i` | 包含项目信息的 JSON 文件路径 | 必填 |
| `--output` | `-o` | 输出目录 | ./output |
| `--template` | `-t` | 模板目录 | ./templates/默认 |
| `--use-tma` | - | 使用 TMA.docx 作为技术文件内容源 | 否 |

## 示例

### 基本用法

```bash
python3 scripts/generate_bid.py --info info.json
```

### 指定输出目录

```bash
python3 scripts/generate_bid.py --info info.json --output my_bid_documents
```

### 使用 TMA.docx 作为技术文件

```bash
python3 scripts/generate_bid.py --info info.json --use-tma
```

## 注意事项

1. **信息完整性**：请确保 JSON 文件中包含所有必要信息，否则生成的文档中相应字段可能为空。

2. **技术文件**：如果使用了 `--use-tma` 参数且存在 `TMA.docx` 文件，脚本会尝试将其内容整合到生成的技术文件中。

3. **文档审核**：生成的文档仅供参考，正式使用前请务必人工审核。

4. **盖章和签字**：需要盖章和签字的文件（如承诺书、营业执照等）需要手动替换为实际盖章/签字版本。

## 扩展功能

### 添加新的文档类型

编辑 `scripts/generate_bid.py` 文件，在 `create_document_with_info` 函数中添加新的文档类型处理逻辑。

### 自定义模板

可以修改 `scripts/generate_bid.py` 中的文档生成逻辑，添加自定义的样式、格式或内容。

## 技术支持

如有问题，请检查：
1. Python 版本是否为 3.8+
2. 是否已安装 `python-docx` 库
3. JSON 文件格式是否正确
4. 文件路径是否正确
