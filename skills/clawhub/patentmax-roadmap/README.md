## 初衷

> **没有约束，就没有建议。**

「建议全面布局、重点保护核心技术、兼顾国内外市场」——这类话之所以听着正确又毫无用处，是因为它没有承接任何约束。

真实的布局决策长这样：你 9 月要在车展首发，所以 8 月前必须把核心专利申完；你今年只有 15 件额度，所以得砍掉三个次要方向；你的前驱体配比不想公开，所以那部分更适合走工艺秘密而不是申请专利。

**这些约束才是布局建议的骨架。** 所以这个 Skill 专门要你填十个字段：未来规划、现有资产、自身优势、已知风险、证据数据、公开时点、申请偏好、预算与数量、保密边界、排除方向。

一个都不填，脚本会直接拦下来——那种情况下跑出来的东西，不值得你花这个钱。

## 跟情报分析的区别

| | 企业情报分析 | 技术路线分析（本 Skill） |
| --- | --- | --- |
| 回答 | **现状是什么** — 谁在做、格局怎么分 | **该怎么做** — 往哪走、怎么布 |
| 输出 | 竞争格局、对手动作、我方位置 | 路线比选、布局方案、申请节奏 |
| 关键输入 | 行业素材 | 行业素材 **+ 业务约束** |

典型顺序：**情报分析看清格局 → 路线分析定方向 → 查新确认具体方案 → 申请**。

在不了解格局的情况下做布局，等于闭着眼睛下注。

## 关键在业务约束

十个字段，全部可选，但填得越全建议越贴合实际。完整说明和 JSON 示例在 `references/context-guide.md`。

时间紧的话**至少填这三个**：

| 字段 | 为什么关键 |
| --- | --- |
| `future_plan` | 不知道你要往哪走，就没法判断该在哪布局 |
| `budget_and_volume` | 能申请 3 件和能申请 30 件，策略完全不同 |
| `disclosure_timing` | **硬约束**——自己先公开会破坏自己的新颖性，申请必须赶在公开前 |

用户常说「这些是内部信息不方便给」。要解释：这些只用于生成建议、不进报告公开部分；不给的话拿到的是一份放之四海而皆准的空话——**付了钱却什么都没得到，比不跑还糟**。

## 怎么用

在 [api.ip930.com](https://api.ip930.com/features/api-platform) 创建密钥，设成环境变量：

```bash
export PATENTMAX_API_KEY="pm_live_你的密钥"
```

```bash
python scripts/patentmax_roadmap.py create \
  --subject "钠离子电池正极材料的技术路线与专利布局" \
  --materials-file ./materials.md \
  --objective "在层状氧化物与聚阴离子两条路线中选一条，并给出今年 15 件申请的布局方案" \
  --context-file ./context.json \
  --competitors "宁德时代新能源科技股份有限公司,中科海钠科技有限责任公司" \
  --markets "CN,US" \
  --wait --yes
```

随时用 `python scripts/patentmax_roadmap.py fields` 打出那十个字段的填写说明。

跑几十分钟，进度实时打出来。完成后：

```bash
python scripts/patentmax_roadmap.py download --report-id <report_id> --out 技术路线方案.docx
```

只用 Python 标准库，不需要 `pip install`。没有 Python 的 curl 示例在 `references/faq.md`。

新用户注册即送 ¥50 体验额度。

## 输出什么

**路线比选** — 几条候选各自的专利拥挤度、绕行空间、技术成熟度，**并给出明确倾向**。你是因为选不出来才来问的，把选择题再丢回去等于没帮上忙。

**布局方案** — 哪几件先申请、哪些可以晚、哪些只要实用新型、哪些值得走 PCT，**和你的预算与数量对得上**。

**申请节奏** — 按公开时点倒排：9 月车展首发 → 8 月送样前完成核心申请 → 7 月定稿交底书。

**风险清单** — 绕不开的核心专利是哪几件，**每一件带公开号**，能追溯。

## 它不做什么

**不出保证性结论。** 不写「这条路线没有专利风险」「已绕开全部障碍专利」。18 个月公开窗口意味着竞争对手最新的布局大概率不在数据里。

**不是法律意见。** 权利要求怎么写、能不能授权、是否构成侵权，要专利代理人出具意见。这份报告是技术与商业参考。

**不讲现状。** 「对手在做什么」是企业情报分析的活。这个 Skill 假设你已经大致知道格局，要的是下一步怎么办。

**不做具体方案的查新。** 「我这个具体想法有没有人做过」是查新任务。
