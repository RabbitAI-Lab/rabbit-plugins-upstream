# Skill Positioning Review 评分规则

总分 25 分，每项 0–5 分。

1. **标题清晰度**：展示名能否说明类别与用途，而非内部代号。
2. **用户聚焦度**：能否点名核心受众及明确不服务对象。
3. **场景具体度**：是否包含可识别的触发时刻和任务。
4. **独特结果**：结果是否区别于通用助手或功能清单。
5. **可信证据**：示例、流程、经验或限制是否支撑承诺。

## 解释

- 0–10：需重做；不能交给 copy 阶段包装
- 11–17：需收窄；先解决最大定位冲突
- 18–21：清晰；可生成 Storefront Copy Brief
- 22–25：强定位；brief 应保留具体证据，避免泛化

## Brief 质量门槛

交接前必须具备受众、触发、问题、结果、单一主张、差异化、证据、禁止声称和投放约束。未知信息明确写入 open_questions；不得由 copy 阶段猜测。
