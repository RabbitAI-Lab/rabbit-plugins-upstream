## Description: <br>
Guides agents working on OpenClaw brand, design-system, public-page, and design-audit tasks using canonical project guidance. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

### License/Terms of Use: <br>

## Use Case: <br>
Developers and design-focused agents use this skill to route OpenClaw interface work to the right brand, design-system, marketing-page, or audit guidance before changing product or public web surfaces. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Design or brand changes can drift from canonical OpenClaw tokens, typography, imagery, or page patterns. <br>
Mitigation: Route work through the relevant OpenClaw design reference and validate affected pages in a real browser at desktop and mobile sizes. <br>
Risk: Redistributing fonts, logos, mascot artwork, photos, or illustrations without recorded rights can create licensing issues. <br>
Mitigation: Use only assets with repository-local license evidence or explicit recorded permission, and keep unsupported assets in the existing consumer. <br>
