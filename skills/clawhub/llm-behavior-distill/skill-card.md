## Description: <br>
Distills behavior patterns from open-source large language models into reusable agent modules for reasoning, tool orchestration, long-context handling, subagent coordination, compression, safety checks, expert routing, compliance checks, and multilingual handling. <br>

This skill is ready for commercial/non-commercial use. <br>

## Known Risks and Mitigations: <br>
Risk: The skill may shape agent behavior toward Chinese-language examples and automatic module routing. <br>
Mitigation: Review generated behavior plans for the intended language, audience, and selected module route before deployment. <br>
Risk: Automatic routing can select an unintended behavior module for ambiguous tasks. <br>
Mitigation: Use manual module selection or add task-specific routing constraints for high-impact workflows. <br>
