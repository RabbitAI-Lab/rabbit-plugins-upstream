# 【名称】置于"喜欢错误"的位置——乐于犯众多的小错，承受小的伤害
- 适用情境：设计一个系统、流程或投资组合，需要在"平时看起来完美"与"出事时不致命"之间选择时；也适用于一个长期零差错的组织准备做风险体检时
- 核心操作：1. 先把自己归位——如果你希望成为反脆弱类的，那么就将自己置于"喜欢错误"的情况下，也就是"厌恶错误"的右边，乐于犯众多的小错，承受小的伤害；2. 对左右两栏做对照自查：在左栏的脆弱类中，错误是罕见的，但是一旦发生，后果则是极其严重的，也是不可逆的；而右栏的错误则是微小和良性的，甚至是可逆的，并能迅速克服；3. 优先做减法——减少不利因素，而不是增加有利因素，通过降低自己暴露于负面"黑天鹅"事件的概率，让反脆弱性顺其自然地发挥作用；4. 主动制造可承受的局部失败，如果能够理性地进行试错，将错误当作一种信息源，那么，试错过程中出现的随机要素其实并没有那么随机；5. 检查错误的关联性——好的系统，如航空业天生就会有些彼此独立的小错误，或者说彼此负相关的错误，一个错误的发生会降低未来犯错的概率
- 前提假设：脆弱性与齿轮不可逆转的特征类似，其造成的损害也是不可逆的；一个亟须压力的反脆弱性系统如果长期缺乏压力源反而会变得更加脆弱
- 常见坑：把"零事故"记录当成安全证据；只在事后复盘而不制造事前的小失败；允许小错但让小错之间高度关联，于是一家银行的崩溃会提高下一家银行崩溃的概率
- 迁移场景：投资组合与仓位设计、工程发布与灰度策略、组织容错机制、应急预案演练、个人职业路径选择
- 边界反例：事物的反脆弱性一般以某个压力水平为限，超过阈值照样碎裂；且在一个系统中，为了其他单元或者整体的利益，往往有必要牺牲某些单元——并非所有单元都能被保住
- 原文原句："如果你希望成为反脆弱类的，那么就将自己置于“喜欢错误”的情况下，也就是“厌恶错误”的右边，乐于犯众多的小错，承受小的伤害。"
- 置信度：板上钉钉

# 【名称】凸性效应——从波动中赚到的比你失去的多
- 适用情境：评估一项暴露于波动中的安排（仓位、定价、供给承诺、排期、健康方案）时；也适用于决定该追求稳定还是拥抱波动时
- 核心操作：1. 先判曲直——如果你从一个给定变化中获得的利大于弊，那么你由此绘制的曲线就是凸性的；反之就是凹性的；2. 用一句话定方向：如果你从波动中赚到的钱比你失去的要多，那么你会喜欢更多的波动性；3. 记住凹性一侧的代价——风险的凹性越大，来自意外事件的伤害就越大，而且大得不成比例；4. 放弃平均值，改看偏差：如果一个人在变化面前是脆弱的，那么平均数的概念就是没有意义的——温度的偏差远比平均温度重要；5. 用假设扰动法检验——只需对假设进行一个小小的变更，然后看看影响有多大，以及这种影响是否会持续加剧；6. 判据最终落在不对称性上：如果潜在收益大于潜在损失，那么你对波动源就具有反脆弱性，反之亦然
- 前提假设：其反应是非线性的（不是一条直线，不是"线性"的）；在非线性情况下，简单的"有害"或"有益"的陈述都会失灵，关键在于剂量
- 常见坑：用平均温度式的指标掩盖波动伤害；把"证明无害的证据"与"缺乏证据证明有害"混为一谈；做"实证研究"却不使用凸性偏见等非线性效应模型
- 迁移场景：期权与仓位结构、产能与库存策略、服务等级承诺设定、训练与康复计划、产品定价与促销节奏
- 边界反例：当收益与损失接近对称、且波动不可承受时，凸性判据不适用，此时应转用冗余与安全边际；且非自然的东西需要证明其利益，但自然的事物则不需要，不能反向举证
- 原文原句："如果你从波动中赚到的钱比你失去的要多，那么你会喜欢更多的波动性。"
- 置信度：板上钉钉

# 【名称】在游戏中投注——谁提意见，谁下注
- 适用情境：采信一份外部预测、评级、咨询建议或内部方案时；也适用于自己准备公开发表判断、给出承诺之前
- 核心操作：1. 先问下注——每一个决策者都应该"在游戏中投注"，如果依赖他的信息或意见的人可能受到伤害的话；2. 对预测类工作设硬性要求：任何进行预测或经济分析的人都应该拿出东西作为赌注，因为别人的利益有赖于这些预测的准确性；3. 排座次——我们需要把创业者和风险承担者置于金字塔的顶端，而不管他们"失败"与否，学者、空谈者和政客则都应该被置于金字塔的底端；4. 对自己反向执行：如果你有自己的看法，你就必须这样做，否则，你就不会持有真正的意见；5. 把它升级为信念承诺——它要求摈弃空头支票，秉持某一个信念，乃至个人愿意为其承担风险；6. 见欺诈即揭露，因为如果你看到欺诈而不揭露欺诈，那么你就是同谋
- 前提假设：转嫁脆弱性的影响可能贯穿整个历史，只是如今由于现代化带来的相互依赖性的增强，这种影响变得更为严重了
- 常见坑：把头衔、机构背书或话语的笃定程度当成可信度；接受"错了也不用负责"的建议；用妥协换取和气，而妥协就是纵容
- 迁移场景：外部顾问与研究报告采信、投资建议评估、内部立项评审、专家证言权重、KPI 与问责机制设计
- 边界反例：当判断者确无能力承担下注后果、且其意见仅作参考不进入决策链时，强行要求下注会把所有发声者赶出场；另需区分经验与研究——经验是不会受过滤式选择的影响的，而研究工作却会影响
- 原文原句："每一个决策者都应该“在游戏中投注”，如果依赖他的信息或意见的人可能受到伤害的话"
- 置信度：板上钉钉
- mechanism：暴露于波动时的收益损失不对称决定了事物的凹凸性，凸性一侧从混乱中获益、凹性一侧被意外事件的伤害放大；把决策权与后果承担绑在一起，能阻止脆弱性从空谈者向行动者转嫁，使错误留在小、可逆、可学习的那一栏
- transferable_core：凡做判断，先问三件事——我对波动是凸还是凹，我的错误是小而可逆还是大而不可逆，我是否为这个判断下了注；三问皆过才算站到了反脆弱的一侧
- 一手原句: "如果一个人在变化面前是脆弱的，那么平均数的概念就是没有意义的——温度的偏差远比平均温度重要。"
