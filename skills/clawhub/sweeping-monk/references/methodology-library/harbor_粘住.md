# 【名称】找出核心问题——一次只说一件事，并把它压成一句谚语
- 适用情境：要在信息过载的环境里传达一件事（汇报、提案、结案陈词、授课、发布），或自己因为选择过多而迟迟定不下来时
- 核心操作：1. 愿意为找核心下苦功——想要战胜这种决策的麻痹，交流者需要付出艰苦的努力来找出核心问题；2. 一次只说一件事：如果你同时说三件事，就等于什么都没说；3. 给目标排序——决定优先次序就是把重要目标置于次重要目标之前，把"至关重要"的目标置于"有用"的目标之前；4. 把核心压缩到可以复述的短句：必须确定你的信息足够简单和具体而有用，把它变成一句谚语（"名字、名字，还是名字"），使员工在复杂的环境中也能作出选择；5. 按角色收敛数量——律师们必须在他们的结案陈词里着重陈述1～2个论点而不是10个；老师必须把大部分的精力用在怎样使他的两三个观点具有黏性；6. 把时间花在开头——如果有两小时用于写作，最好的方法是用头1小时45分钟确定一条好的导语，那么后面的一切都会变得简单；7. 对不可控的外部变量用"确定事件原则"锁死：他决定，如果共和党获胜，他就买；如果民主党获胜，他也会买
- 前提假设：复杂环境天然吸引注意力，而决策的麻痹会带来焦虑和不理性——想一想有些学生同时错过了一个精彩的讲座和一场好看的电影，就是因为他们无法决定哪个更好
- 常见坑：把核心埋在材料里让人自己找——他总是倾向于掩藏事件的导语，即最重要的信息；关注介绍形式而不是信息本身；失败的广告有个最普遍的原因，那就是广告商忙于自我吹嘘，却忘了告诉客户他们为什么要买
- 迁移场景：战略与年度目标表述、产品定位口号、结案与答辩、课堂教学设计、危机沟通口径、个人日程的优先级
- 边界反例：需要完整可追溯的技术规格、法律要件或医学剂量清单，压成一句谚语会丢掉必须逐条保留的约束，此时应完整罗列，把谚语只用作导航
- 原文原句："想要战胜这种决策的麻痹，交流者需要付出艰苦的努力来找出核心问题。"
- 置信度：板上钉钉

# 【名称】先破坏别人的推测机器，再把它修好——指出他们知识中的缺口
- 适用情境：开场、引入一个全新主题，或需要让对方对一件"他以为自己已经懂了"的事重新产生兴趣时
- 核心操作：1. 先破坏再修复——如果你想让创意更有黏性，你就必须先破坏别人的推测机器，然后再把它修好；2. 破坏的手段是违反直觉：找出信息中与直觉相违背的东西，用违反直觉的方式传递信息；3. 修复的手段是把机器修好，说清直觉为什么会错；4. 指出缺口而不是硬塞内容——你应该指出他们知识中的缺口；5. 先判断对方缺的是"缺口"还是"深渊"：如果这是一种知识的深渊而非缺口，就必须往深渊中填入足够的知识，把深渊变成缺口；6. 从对方已经知道的东西入手——要想把学生吸引到一个新的主题上来，就必须从强调他们已经知道的某些东西入手：这是你已经知道的，现在这些是你未知的；7. 先摆背景再留悬念——把与事情有关的背景充分展现给人们，使得他们能够开始倾注自己的注意力，并创造一个有悬念的事件或谜，在交流的过程中慢慢地揭开答案；8. 对过度自信者先挫败其固有思维模式——如果一个人坚持认为自己无所不知，那就连缺口理论都很难起了作用了
- 前提假设：好奇心来自知识的缺口；最基本的吸引别人注意力的方法是打破常规
- 常见坑：只破坏不修复，把对方晾在困惑里；对完全陌生的主题直接留缺口，结果对方连缺口在哪儿都看不见；让惊吓效果喧宾夺主，而不是为核心信息服务
- 迁移场景：课程与培训开场、产品发布与路演、内部变革沟通、科普与风险沟通、招聘宣讲、文章标题与导语设计
- 边界反例：面向必须立刻执行、无暇思考的场合（应急指令、值班交接、告警处置），先制造意外再解释会拖慢响应，此时应直接给出结论与动作
- 原文原句："如果你想让创意更有黏性，你就必须先破坏别人的推测机器，然后再把它修好。"
- 置信度：板上钉钉

# 【名称】可验证的凭据——把可信度交给受众，让他自己试出结果
- 适用情境：要让人相信一个反直觉的说法、改变一个已经形成的行为，或在权威不被信任的环境里推动行动时
- 核心操作：1. 先把可信度交出去——温迪把可信度转交给了顾客；2. 设计一个可验证的凭据：这种做法要求顾客自己验证一个说法，是一个"可验证的凭据"；3. 让人先尝后买——可验证的凭据可以极大地提升可信度，因为他允许顾客"先尝后买"；4. 使用可试验的证据使人们可以自己试出结果；5. 少使用权威，多使用非权威；6. 用具体化铺路，因为具体化允许人们把自己的知识带入新的信息，而统计数据本身不会有帮助，是标准和环境使得它们有用；7. 用故事而非裸数据承载结论——63%的人记得那个故事，只有5%的人记得个别的数据
- 前提假设：我们的直觉是有缺陷的，但是谁愿意相信这一点呢；人性化原则允许我们用直觉来考虑和评价信息内容的可信程度
- 常见坑：以为堆更多专家、更多数据就能换来信任——他仔细地整理数据和细节，仍不能使他清除障碍；把"可验证"做成无法当场验证的复杂实验；忘了我们可能会因为事情能引起我们更多的情绪而记住它，而不因为它们是更常发生的
- 迁移场景：产品体验设计（试用、演示、沙箱）、健康与安全宣导、辟谣与反诈、内部推行新流程、销售证据设计、数据汇报的可信度包装
- 边界反例：后果不可逆或验证成本过高的主张（药物剂量、结构安全、金融合规），不能靠"你自己试"，必须由权威与规范先行背书
- 原文原句："可验证的凭据可以极大地提升可信度，因为他允许顾客“先尝后买”"
- 置信度：板上钉钉
- mechanism：注意力是稀缺资源，而复杂性会诱发决策麻痹，所以第一道关是压缩——找出核心、一次只说一件事、把它变成一句谚语；核心要被听进去，第二道关是打破——用违反直觉的信息破坏对方的推测机器、指出知识缺口，再把机器修好；核心要被相信并转化为行动，第三道关是交权——权威与数据都不构成亲身体验，只有让受众自己试出结果，可信度才真正落地
- transferable_core：传播链条上三道关卡各有解法，且顺序不可颠倒——"记住"靠压缩成一个核心，"注意"靠破坏推测机器并留出知识缺口，"相信"靠把验证权交给对方；任何一道跳过，后面的都白费
- 一手原句: "使用可试验的证据使人们可以自己试出结果。"
