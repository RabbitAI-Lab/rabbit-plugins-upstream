# 【名称】恒常会合与习惯——因果推断只建立在经验的会合上
- 适用情境：要把两个反复同现的现象断言为因果关系时（业务归因、药效判断、政策评估、数据相关性解读）；也适用于被问"凭什么说这是原因"而无法给出机制解释时
- 核心操作：1. 先把公理摆出来——各种物象之间并没有可以发现出的联系，由此及彼的推测只建立在所经验到的恒常而有规则的会合上；2. 清点例证数目，看会合是否恒常、是否规则，而不是去找那条看不见的"必然联系"；3. 承认习惯的作用——心被习惯所推移来期待相似结果，习惯就是人生的最大指导；4. 把结论限定为"期待将来有类似过去的一串事情发生"，不升级为"洞见了自然的能力"
- 前提假设：自然使我们远离开她的秘密，她只使我们知道物的少数表面性质，感官和理性都告知不了我们物象有什么性质可以使它产生某种结果
- 常见坑：把反复同现误当成窥见了自然的能力；用"我看到过一百次"去替代对会合规则的清点；在例证稀少时提前把结论推到完全的地步
- 迁移场景：A/B 实验归因、医学疗效判断、风控规则提炼、增长复盘、管理咨询中的因果主张
- 边界反例：属第一类对象（几何、代数、三角等只凭思想运作即可确定的命题）时不靠会合；且单一例证不能推翻一百个例证所得的结论
- 原文原句："因此，习惯就是人生的最大指导。只有这条原则可以使我们的经验有益于我们，并且使我们期待将来有类似过去的一串事情发生。"
- 置信度：板上钉钉

# 【名称】使信念和证据适成比例——平衡相反的实验
- 适用情境：要评估一份他人证言、一条爆料、一份异常报告或一次"史无前例"的宣称值多少信任时；也适用于自己已经相信了什么，需要校准置信度时
- 核心操作：1. 先查证人的品质与数量、说话是否有利可图、是否带着疑虑或狂猛专断的样子；2. 再看事实本身的反常程度——事实越奇特神异，由证言得来的明验便按比例减低其力量；3. 把相反的各种实验平衡一下，从大数中减去小数，以便知晓较大明验的精确力量；4. 让信念的强度停在证据所余的力量上，不多给一分；5. 极端情形下，若各国作者一致记载、传说家喻户晓、旅客所见并无丝毫差异或矛盾，就应当认它是真实的
- 前提假设：在关于实际事情的推论方面，经验虽是我们的唯一的指导者，但这种指导者不能永久是无误的；凡有直觉或解证确定性的属第一类，实际的事情只能得到或然性
- 常见坑：因为事实新奇就一并拒绝，或因为证人多就一并接受；忘了"一个聪明人就使他的信念和证据适成比例"——把信念当成开关而非刻度；把"缺乏证据证明有害"当成"证明了无害"
- 迁移场景：尽职调查、新闻事实核查、专家证言采信、医疗个案报告评估、内部举报核实
- 边界反例：当证言本身就是唯一可得的材料、且无从做相反实验的平衡时（如孤例历史事件），只能停在高度存疑，不能推进到确信
- 原文原句："因此，一个聪明人就使他的信念和证据适成比例。"
- 置信度：板上钉钉

# 【名称】观念的关系与实际的事情——先给命题分类，再决定要什么等级的证据
- 适用情境：一个断言引发争论、久议不决时；设计研究方案前确定该要什么强度的证据时；评审他人论证、判断其是否用错了标准时
- 核心操作：1. 先把命题归到两类之一——属第一类的，有直觉的确定性或解证的确定性，如几何、代数、三角诸科学；属第二类的，是实际的事情，其真实性不论如何明确，那种明确也和前一种不一样；2. 对第一类，要求解证，承认了前提就不能不承认结论；3. 对第二类，放弃解证要求，只按经验与信念-证据比例来处理，接受结论只能是或然的；4. 若发现对方拿经验证据去证明"观念的关系"，或拿解证标准去苛责"实际的事情"，当场指出类别错配
- 前提假设：关于实际事情的一切理论似乎都建立在因果关系上，而对因果关系的知识又是从经验来的；一切经验上的结论都依据"将来定和过去相契"这个假设
- 常见坑：用解证的口吻陈述经验结论（把"我见过很多次"说成"必然如此"）；反过来，对只需思想运作即可确定的命题去堆砌经验材料；在因果推论里由已知结果外推出超出结果的新性质
- 迁移场景：研究方案设计、立项评审、政策论证、辩论拆解、产品方案评审中的"这算证明还是算经验"
- 边界反例：当命题同时含有两类成分（如应用数学于物理世界）时，需拆成两段分别定标准，不能整体套用一类
- 原文原句："人类理性（或研究）的一切对象可以自然分为两种，就是观念的关系（RelationsofIdeas）和实际的事情（MattersofFact）。"
- 置信度：板上钉钉
- mechanism：物象之间并无可发现的联系，因果推断只建立在恒常会合上，再由习惯推移人心形成期待；因此一切关于实际事情的结论都只具或然性，其强度只能按相反实验的平衡结果而定；凡自称超越经验而洞见必然联系的断言，都落回了观念的关系那一类而与实际的事情不相干
- transferable_core：先分类再定证明标准——对只凭思想即可确定的命题求解证，对关于事实的命题只求或然并按证据强弱分级；任何因果主张都必须交代它赖以成立的会合例证数目与相反实验的差额
- 一手原句: "换句话说就是：我们如果在许多例证下见某两种物体一一如焰与热，雪与冷 恒常会合在一块；则在火焰或雪重新呈现于感官时，我们的心便被习惯所推移来期待热或冷，而且相信，那样一种性质确是存在的，以为只要我们靠近一点，它就可以表现出来。"
- 来源溯源 / 大卫·休谟《人类理解研究》::第一节、第二节、第8章、第十一章、第一章、第二章、第三章
