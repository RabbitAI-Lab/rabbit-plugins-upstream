# 【名称】分析法——展示发现的过程，而不只是给出证明
- 适用情境：要向别人传授一个尚未被接受的思路、写一份需要让人真正接受而不只是点头的论证，或所处理的前提本身仍有争议时
- 核心操作：1. 采用分析法——我在我的沉思里仅仅采用分析法，因为我认为这种方法是最真实、最好的教学方法；2. 把发现的路径原样展示出来，而不是只摆出证明完毕的结论；3. 把力气花在第一概念上——在属于形而上学的问题上，主要的困难在于清楚、分明地领会第一概念；4. 让读者自己走一遍这条路：如果读者们愿意遵循这个方法并且仔细注视它所包含的一切东西，他们就会把这样证明了的东西理解得同样完满，就跟他们自己发现了它一样成为他们自己的东西；5. 顺序上可以正着走也可以反着走——为了找到真理，我们当然总是从特殊的概念开始以求达到一般的概念，虽然我们也可以反过来，找到了一般的概念，然后再由之而推论出其他的特殊的概念
- 前提假设：至于综合法，它无疑地是你们希望我采用的方法，虽然在几何学里所谈的东西上它仅次于分析法的地位，但是它对于形而上学的东西却不怎么合适；凡前提本身还需要被重新领会的问题，形式上的证明蒙不过去
- 常见坑：把"结论已被证明"当成"结论已被传授"；跳过第一概念的澄清直接推演；按书的厚薄或书名来判断书的好坏
- 迁移场景：技术方案评审、论文与教材写作、新人带教、客户提案、跨部门说服
- 边界反例：结论已是共识、只需快速复核的场合（回归测试报告、常规审计、已定型的计算复核），综合法更省篇幅，展开发现过程是浪费
- 原文原句："如果读者们愿意遵循这个方法并且仔细注视它所包含的一切东西，他们就会把这样证明了的东西理解得同样完满，就跟他们自己发现了它一样成为他们自己的东西。"
- 置信度：板上钉钉

# 【名称】在领会得清楚、分明之前不下判断——让同意的强度对齐领会的强度
- 适用情境：被要求在信息不足时表态、做高风险判断，或评审他人结论却说不清自己凭什么赞成时
- 核心操作：1. 先分清两种"清楚"——把我们事实上领会得非常清楚的东西同我们记得以前曾领会得非常清楚的东西区别开来，否则就会陷入循环论证；2. 让同意的强度对齐领会的强度：在给予同意之前领会得越清楚的东西上，我们所面临的达不到目的的危险就越小，而那些对于原因还不认识就冒然下什么判断的人就失败；3. 守住举证方向——并不需要把那些我们不知道其真实性因而并没有当做真实的东西接受下来的都证明是假的，而是必须仔细注意不要把我们不能证明为真实的东西都当做真实的接受下来；4. 认下错误的归属：错误，就其作为错误而言，并不取决于上帝的什么实在的东西，而仅仅是一种缺陷；是在他没有在我的理智里放进一种清楚、明白的认识的某些事物上去下判断，是我没有使用好这个自由；5. 让推论所依据的原则来自最可靠、最明显的概念，而不是模糊不清的东西
- 前提假设：在这些东西里边，有一些是那么清楚，同时又是那么简单，以致我们不可能想到它们而不认为它们是真的
- 常见坑：把"我暂时看不出问题"当成"我已经领会清楚"；让模糊的大词充当已经解决的概念；把不下判断拖成不下决心
- 迁移场景：高风险投资决策、人事与晋升判断、技术选型评审、医疗方案选择、公共议题表态
- 边界反例：代价极低且完全可逆的日常选择，把标准拉到"清楚、分明"会拖垮效率；但凡原因还不认识就冒然下判断的场合，则必败
- 原文原句："假如它所按照其行事的东西不是被清楚认识的，谁能使它是靠得住呢？有谁（不管是哲学家也好，神学家也好，或者仅仅是运用理性的人也好）不承认，在给予同意之前领会得越清楚的东西上，我们所面临的达不到目的的危险就越小，而那些对于原因还不认识就冒然下什么判断的人就失败？"
- 置信度：板上钉钉

# 【名称】先给反驳分类——查它建筑在误解了的词句上，还是错误的假定上
- 适用情境：收到成堆评审意见、被公开质疑、或自己正准备反驳别人时
- 核心操作：1. 先给反驳归类——即使我记住了这些反驳，我也认为它们都是建筑在几个误解了的词句，或者几个错误的假定上的；2. 分辨三种货色：对成见的误解、显然错误的假定、吹毛求疵，只对前两种动真格；3. 先问"它是什么"再问"它是否存在"——按照真正的逻辑的规律，决不要问什么东西是否存在，如果首先不知道它是什么的话；4. 查词：同一个词是否被两个本原混用了——最初起那些名子的人也许没有在我们心里把我们由之而吃饭、生长以及不用思维而做的、跟动物做的同样的其他一切活动的这个本原，同我们由之而思维的本原区分开来，他们把二者都叫做灵魂；5. 守住举证责任——你不应该要求我，让我来证明什么东西是假的，理由仅仅在于我不知道它，所以才不承认它；6. 立好自己的尺子——我的思维并不是衡量事物是否真实的尺子，但每一个人的思维，也就是说，每一个人对一件事物的知觉或认识，对于他本人来说应该是衡量这件事物的真或假的尺子
- 前提假设：衡量真假的尺子落在每个人自己的知觉上，因此人人都必须留心自己的知觉，而不能接受别人高兴给我们提出来的见解或者离奇古怪的东西，尽管我们一点也看不出来这些东西
- 常见坑：把吹毛求疵当实质反驳逐条应战；替本该负举证责任的一方去证伪；用找碴儿怀疑别人说话的形式和词句来代替真正的质疑——一个人要想把他的认识提高到比一般人的认识水平以上，就应该把找碴儿怀疑一般人说话的形式和词句当做可耻的事
- 迁移场景：论文审稿答复、方案评审意见处理、舆情与评论区应对、代码评审争议、合同与需求条款的措辞核查
- 边界反例：当反驳确实指向推论所依据的原则本身——这些推论所依据的原则并不是模糊不清的，也不是大家不知道的，而是从一些最可靠、最明显的概念里得出来的——而不是落在词句或假定时，分类法不能用来打发，必须回到原则重新论证
- 原文原句："因为，即使我记住了这些反驳，我也认为它们都是建筑在几个误解了的词句，或者几个错误的假定上的。"
- 置信度：板上钉钉
- mechanism：论证的说服力不来自形式，而来自读者能否重走发现之路，因此传授要用分析法；判断的可靠性不来自意志的强度，而来自领会的清楚、分明程度，错误只是在理智尚未清楚时滥用下判断自由的缺陷；而来自他人的反驳，绝大多数不是对论证本身的攻击，而是落在误解了的词句或错误的假定上，先分类再应战即可
- transferable_core：把"结论—领会—反驳"三段拆开处理：呈现时给出发现过程而非证明结果，表态前让同意强度对齐领会强度，受击时先判别对方打的是词句、假定还是原则本身；举证责任始终落在提出主张的一方
- 一手原句: "一个人要想把他的认识提高到比一般人的认识水平以上，就应该把找碴儿怀疑一般人说话的形式和词句当做可耻的事。"
