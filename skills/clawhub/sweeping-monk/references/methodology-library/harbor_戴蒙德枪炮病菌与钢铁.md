# 【名称】影响接受新技术的四个考虑——相对经济利益、社会价值和声望、既得利益、优点的可见性
- 适用情境：推动一项新技术、新工具或新流程在组织内外落地，需要诊断它为什么推不动
- 核心操作：1. 先算相对经济利益——与现有技术相比较的相对经济利益，这是第一个也是最明显的因素；2. 再算社会价值和声望——第二个考虑是社会价值和声望，这种考虑可以不顾经济利益；用新东西能不能让人显得更体面、更先进；3. 排查既得利益——另一个因素是是否符合既得利益，谁会因为这套东西落地而失去位置、预算或话语权；4. 让优点变得可见——影响接受新技术的最后一种考虑，是新技术的优点能够很容易地看到，看不见的好处等于没有好处；5. 评估当地的开放度——在广泛地区内，有些社会对新事物可能比较开放，有些社会对新事物可能比较抵制，把推广节奏与当地开放度匹配
- 前提假设：人们能够认识有用的植物，因此大概也会认识当地适合驯化的更好的植物，如果这种植物存在的话，也不会仅仅由于文化保守主义和禁忌而不去那样做；也就是说"落后"通常不是因为愚昧
- 常见坑：把推不动归咎于用户保守或愚昧，而不去算那四项；只谈长期收益而忽略相对优势的即时可见性；忽略了被新技术动到奶酪的那批人
- 迁移场景：企业数字化转型、研发工具推广、农业与医疗新技术扩散、标准与协议的市场争夺、组织流程再造、开源项目采纳
- 边界反例：当采用由强制力或合规要求决定时（法定标准、强制安全规范），四项考虑退居其次；当切换成本极高且不可逆时，既得利益一项会压倒其余三项
- 原文原句："影响接受新技术的最后一种考虑，是新技术的优点能够很容易地看到。"
- 置信度：板上钉钉

# 【名称】自然实验——用自然形成的对照替代无法实施的干预
- 适用情境：研究对象是历史、生态、社会或组织层面的大尺度现象，直接实验不道德、不合法或不可能，但你需要拿出因果证据
- 核心操作：1. 明确承认约束——用直接的实验介入法来处理相关的变量可能是不道德的、不合法的或不可能的，所以必须把自然实验作为一种方法来使用；2. 主动扩大对照的数量：研究人类史的人可以利用多得多的自然实验，而不只是限于比较5个有人居住的大陆；3. 借鉴已成熟的正式程序——流行病学通过比较不同的人群（通常用历史追溯研究法）来对人类疾病作出论断，长期以来一直成功地运用正式的程序；4. 借鉴演化生物学根据对已知的演化史上的不同动植物的比较来作出结论的复杂方法；5. 用多重独立证据交叉验证，例如把关于作物的直接的考古学证据同比较间接的语言学证据结合起来；6. 手上所有年代数据先做校正——对从表面上看（即未经校正的）年代介于公元前约1000年至6000年之间的材料来说，精确的（经过校正的）年代要早几百年或1000年
- 前提假设：每一条冰川、每一团星云、每一次飓风、每一个人类社会，都是独一无二的，因为它受到那么多的变数的影响；历史科学只能提供事后的解释，事前的预测就比较困难了
- 常见坑：把自然实验当成真实验——任何领域的自然实验，不管是生态领域的还是人类史领域的，生来就容易受到可能的方法论的批评；只比较两三个案例就下普遍结论；忽略年代校正造成系统性偏差
- 迁移场景：政策效果评估、组织变革前后对比、市场与区域差异研究、流行病学回顾研究、A/B 不可行时的准实验设计、竞品与行业历史复盘
- 边界反例：当干预成本低、伦理无障碍时，应做真实验而非自然实验；当只存在单一案例且无近似对照组时，自然实验不成立
- 原文原句："生态学家也十分注意自然实验问题，因为在许多情况下，用直接的实验介入法来处理相关的生态变量可能是不道德的、不合法的或不可能的，所以生态学家必须把自然实验作为一种方法来使用。"
- 置信度：板上钉钉

# 【名称】是独立发明还是思想传播——用"非同一般的巧合"做归因检验
- 适用情境：解释一种能力、制度或技术的分布差异（为什么是这些地方而不是那些地方），需要排除"天赋/人种/基因"式的懒惰归因
- 核心操作：1. 先立归因基线——不同民族的历史遵循不同的道路前进，其原因是民族环境的差异，而不是民族自身在生物学上的差异；2. 做巧合检验：如果人类在没有文字的情况下生存了几百万年之后，多个社会在彼此相距不过几百年的时间内各自独立偶然想到同一个主意，这是非同一般的巧合，更可能的解释是思想传播；3. 查传播链上是否留下"借来的零件"——塞阔雅得到了纸和其他书写材料、得到了关于书写系统的思想、利用不同符号的思想，并得到了几十种记号形式，朝鲜谚文显然受到了中国方块字的启发，同时也受到了蒙古和西藏佛教经文的字母表音原则的启发；4. 用分布中心反推源头——如果在现代的某些地区内存在着属于某一特定语系的语言高度多样性现象，那么这些地区差不多就是该语系的早期分布中心；5. 用野生祖先的地理分布加首次出现年代交叉定位——出现年代最早的地点也许就是驯化最早的地点，如果该物种的野生祖先也在那里出现，情况就尤其如此
- 前提假设：环境地理和生物地理影响社会发展；地区人口的多少是预测社会复杂程度的最有力的唯一根据；历史分析的目的在于理解而非辩护，为了努力改变某个结果，了解是比再现或保持这种结果更经常使用的方法
- 常见坑：用能力或天赋解释分布差异；把"没有证据表明是传播"当成"证据表明是独立发明"；只依赖单一学科的证据
- 迁移场景：创新源头追溯、竞品功能抄袭与独立研发的判定、组织制度移植可行性评估、文化习俗传播研究、技术路线图归因、专利与学术优先权争议
- 边界反例：当确实存在完整的独立演化证据链（如不同地区的同一作物标本在形态、遗传或染色体方面的差异表明多次独立驯化）时，不能强行归为传播；对由极少数个人特质决定的事件（如一次未遂政变），结构性归因解释力有限
- 原文原句："如果人类在没有文字的情况下生存了几百万年之后，所有这些地中海和近东社会在彼此相距不过几百年的时间内，碰巧竟各自独立地偶然想到发明文字这个主意，这可能是一个非同一般的巧合。因此，在我看来，一个可能的解释就是思想传播，就像塞阔雅的情形一样。"
- 置信度：板上钉钉
- mechanism：大尺度差异不由参与者的天赋决定，而由三组环境变量决定——可驯化物种与技术的储备（供给端）、传播与接受的通道（扩散端，受相对经济利益、声望、既得利益、可见性四项调节）、人口规模与社会复杂程度（承载端，地区人口越多社会越复杂）；三者都属环境约束，因此可检验、可改变，而不是宿命
- transferable_core：遇到"为什么是 A 而不是 B"的问题，先排除天赋与道德归因，再沿供给—扩散—承载三段找环境约束；判断"各处都发明出来"的说法时，用巧合检验与传播链残迹逼问是独立发明还是思想传播
- 一手原句: "不同民族的历史遵循不同的道路前进，其原因是民族环境的差异，而不是民族自身在生物学上的差异。"
