# 【名称】价值关联与价值分析——用价值选出对象，用价值无涉守住结论
- 适用情境：确定一个文化科学/社会科学的研究对象、为一次研讨或一份评估报告划定事实与评价的边界、回应"你的立场是否影响了结论"的质疑
- 核心操作：1. 先承认研究对象的选择由价值关联和文化意义决定——只有始终无限多样的单个现象的某些我们赋予其一般文化意义的方面，才值得我们去认识；2. 做价值分析，阐明和确立价值与事件的文化意义之间清楚的联系，它同时给即将进行的因果分析提供决定性的"观点"；3. 承认价值分析实际上是抽出有关对象的无数可能的理解之一种，使之定向化，并借此而找到因果分析的入手处；4. 进入经验研究后严守价值无涉——区别认识和评价的能力，既履行了解事实真理的科学责任，又履行提出自己理想的实践责任
- 前提假设：任何文化科学的先验前提，不是指我们认为某种或任何一种一般的"文化"有价值，而是指我们是文化的人类，秉具有意识地对世界采取一种态度和赋予它意义的能力和意志；文化概念是一个价值概念，经验实在对我们来说是"文化"，因为并且只要我们把它置于与价值观念的关系之中
- 常见坑：以为价值关联只意味着好恶评价——价值虽然包括好恶评价在内，但要远远宽于单单的好恶评价；忘记使读者和自己在每时每刻都分明地意识到自己是依赖什么尺度来衡量现实并导出其价值判断，而不是通过各种不同的价值彼此之间不精确的挪移而在理想的冲突方面来回欺骗自己，同时想"给每个人都提供一些东西"
- 迁移场景：选题与开题论证、政策评估报告的事实/建议分栏写法、媒体与舆情分析中的事实与观点分离、企业战略研究中的立场披露、学术评审中的利益冲突声明
- 边界反例：需要给出行动建议与政策取舍的场合，价值无涉不等于放弃判断——经验科学只说明事实怎么样、它可能怎么样，而应当怎么样完全取决于人们自己依据于一定的价值取向所作的选择，两件事必须分开、也必须各自做完
- 原文原句："总之，经验科学只能告诉人们事实怎么样，它可能怎么样，低决不教导人们应当怎么样，后者完全取决于人们自己依据于一定的价值取向的选择。"
- 置信度：板上钉钉

# 【名称】理想类型——纯粹理想的界限概念，用来衡量和比较实在
- 适用情境：要为历史个体或其个别成份建立可操作的概念、要用一把尺去量现实与"如果纯粹如此将会怎样"的差距、要防止理论家把理论和历史相互换用
- 核心操作：1. 把理想类型当作纯粹理想的界限概念来构造——它不是历史实在或根本不是"本来的"实在，也不是实在应该当作样本而被分门别类地放在其中的图式；2. 用它来做衡量：为了阐明实在的经验内容中某些有意义的成分，实在要用这种界限概念去衡量，并与之进行比较；3. 以发生学的概念来把握历史个体或者它们个别的成份；4. 建立时回到简单因素并接受检验——发展的经验—历史的过程是否实际上就是所建立的过程，这只有借方法才可得到检验
- 前提假设：价值关联是理想类型得以成立的根据，但正是这个根据使它带上了很大的主观性片面性；概念的内容必定是始终流动不居的，理想类型没有或只在个别情况下具有完全的概念纯粹性
- 常见坑：由选择出来的概念标准所产生的类型系列，因而好象是具有规律必然性的类型的历史次序——这是最隐蔽的陷阱；没有什么比源于自然主义偏见的理论与历史的混合更加危险了；从根本上抛弃明确的概念表述，谁就不得不局限在文化现象的形式的方面，比如法律史方面；历史学家若拒绝努力去将这样的理想类型表述为"理论的体系"，结果总是或者他有意识或无意识地应用措词不当的未经逻辑的类似概念，或者是他停滞在不确定的"感觉"领域
- 迁移场景：历史个案的概念化、组织形态与市场结构的建模、政策基准线设计、用户画像与 personas、最佳实践参照系的建立
- 边界反例：理想类型仅仅是达到认识目的的手段，与自然科学的规律不同，它本身不成为目的，也不需要通过检验而得到证实；若把它的主观性贯彻到底而不加约束，人们在社会生活领域内只能获取零碎而无定型的东西
- 原文原句："它不是历史实在或根本不是‘本来的’实在，它几乎不是作为实在应该当作样本而被分门别类地放在其中的图式而起作用的，相反，它具有纯粹理想的界限概念的意义"
- 置信度：板上钉钉

# 【名称】因果归源——只取无限实在中具有文化意义的有限部分
- 适用情境：对个别事件、个别组织现象做因果解释，尤其当可列出的原因多到无从下手时——历史个案、事故复盘、战略归因、质性研究的因果链建构
- 核心操作：1. 先承认规定任何一个个别事件的原因的数量和方式往往是无限的，在事物本身之中并没有指明从中选择出唯一可以考虑的部分的现成标志；2. 放弃详尽无遗的追溯——从任何一个具体现象的整个实在出发的一种详尽无遗的因果追溯不仅在实践中是不可能的，而且简直就是荒谬之举；3. 只取我们赋予其一般文化意义的那些方面；4. 把已观察到的以及思维可及的人类社会生活事件的因果联系分解为某些最简单的因素，然后凭借概念对它们进行十分详尽无疑的分析；5. 解释这种个别的组合时，回溯到另外一些完全同样个别的组合，并使这种有意义性的基础和模式能够被理解
- 前提假设：只有凭借无限丰富的现象的有限部分才是有意义的这个假设，认识个别现象的想法才在逻辑上最终变得有意义；研究的对象是什么，以及这种研究深入因果联系的无限性之中达至多远，这取决于支配着研究者和他那个时代的价值观念
- 常见坑：迷恋愈普遍愈抽象的规律——规律愈"普遍"，亦即愈抽象，它们对于所需的现象因果归源的贡献就愈少，因而间接地为理解文化事件的意义所做的也就愈少；把这个经济因素的概念夸大得面目全非，以致于所有受任何一种外部手段束缚的人类利益都被包括进那个概念
- 迁移场景：事故根因分析、商业失败复盘、历史个案研究、政策效果归因、组织问题的边界划定、质性编码中的范畴收敛
- 边界反例：需要穷尽所有致因以分配责任或做安全兜底的场合（航空事故调查、医疗不良事件、合规问责），"只取有限部分"必须让位于制度性的穷尽清单；此外经济因素的分析在它提供那种表明对于具体历史事件的因果归源具有价值的联系的认识的范围内，是不能"为所欲为的"
- 原文原句："规定任何一个个别事件的原因的数量和方式往往是无限的，在事物本身之中，并没有指明从中选择出唯一可以考虑的部分的现成标志。"
- 置信度：板上钉钉
- mechanism：实在的原因在数量与方式上是无限的，而认识之所以可能，在于研究者凭价值关联从无限中切出有限的、具有文化意义的方面，再用概念把切下来的部分分解为最简单因素并回溯到另一些个别组合
- transferable_core：解释个别事件不是比谁列的原因更全，而是先声明你依据什么价值关联切出了哪一部分实在，再把这一部分做透；普遍规律的抽象度越高，对具体因果归源的贡献越小
- 一手原句: "只有始终无限多样的单个现象的某些我们赋予其一般文化意义的方面，才值得我们去认识。"
