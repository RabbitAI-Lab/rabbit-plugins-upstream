# 【名称】渐进的修补与批判性分析——渐进工程取代乌托邦工程
- 适用情境：要改造一个复杂的社会、组织或系统，手上却只有"彻底重建"的蓝图和"新秩序"的愿景
- 核心操作：1. 放弃整体蓝图，先采取有步骤的措施来反对某些错事，反对不公正或剥削等具体情况，反对可以避免的苦难（例如贫困和失业）；2. 把每一步"渐进的修补"与批判性分析相结合，这是取得实际成果的主要方法；3. 把问题提得容许失败——渐进工程工程师可以在改革的范围中不抱成见地提出自己的问题，而整体主义者做不到；4. 使理论服从明确性和实践的可检验性的标准；5. 在反复试验中学习，主动引入别人的批评来发现自己的错误
- 前提假设：这两种方法的区别不在规模和范围，而在别的方面；乌托邦工程师事先就一口咬定彻底改造是可能的和必然的，因而无法不抱成见地提问
- 常见坑：以为区别是"步子大还是步子小"；乌托邦工程为了继续干下去，在压制不合理的反对意见时也必定不断地压制合理的批评；把"容许失败"的纲领偷换成"改造人，使人适合于新社会"
- 迁移场景：组织变革、产品迭代、政策试点、制度改革、流程改造、技术系统重构的推进节奏设计
- 边界反例：必须一次成型、不可分步切换的对象（不可回滚的整体式基础设施迁移、一次性生效的法律架构），分步修补会造成长期不一致与双轨成本
- 原文原句：""渐进的修补"（有时这样来称呼）和批判性分析相结合，不论在社会科学还是在自然科学中都是取得实际成果的主要方法。"
- 置信度：板上钉钉

# 【名称】淘汰假理论——凡检验都解释为证伪而非证实
- 适用情境：拿一个方案、假说或判断去接受检验、评审、复盘，而你自己多半已经站在它那一边
- 核心操作：1. 把每一次检验重新解释为淘汰假理论——发现理论的弱点以便加以拒绝，如果它被检验所证伪的话；2. 主动搜寻反例而不是补证据：如果缺乏批判的态度，我们总会发现我们所希望的事情，将寻求和找寻证实，并忽视和无视可能危及我们心爱的理论的情况；3. 对直觉认识也要过筛——利用对自己的认识来形成关于别人的假说，但这些假说必须加以检验，必须用筛选的方法加以处理；4. 承认规律只能排除某些可能性，我们的知识在一定的意义上只是消极的知识；5. 从假说、偏见或某个问题入手，让它指导观察、帮助我们从无数的观察对象中选出感兴趣的对象，而不是等观察"归纳"出理论
- 前提假设：在科学发展的每一个阶段中，我们都是从性质上属于理论的某种东西入手的
- 常见坑：归纳主义偏见——以为在自然科学中我们逐步通过某种概括的方法从观察达到理论，并且能够通过某种归纳推理的方法来"证明"或甚至证实我们的理论；把"没有反例"当成"已被证实"
- 迁移场景：方案评审、投资尽调、A/B 检验、假设驱动的产品验证、事故复盘、论文同行评议
- 边界反例：探索性研究的早期尚无明确假说可淘汰时，以及以寻求和检验各个单称命题为主的描述性历史/个案工作，此时检验的对象是单称命题而非普遍规律
- 原文原句："重要的是要认识到这个观点所得出的结论。这就是：凡检验都可以解释为淘汰假理论——发现理论的弱点以便加以拒绝，如果它被检验所证伪的话。"
- 置信度：板上钉钉

# 【名称】方法论唯名主义——描述事物如何活动，而非追问它真正是什么
- 适用情境：讨论陷在定义与本质的拉锯里，各方都在争"它本质上是什么"，进展停摆
- 核心操作：1. 把问题从"它真正是什么"换成"它是如何活动的"；2. 在必要时灵活地引进新的名词，或者为了方便而对原有的名词下新的定义，大可不考虑原来的意义；3. 识别本质主义姿态——强调社会事件的性质特性、强调直觉悟性而反对纯粹的描述，正是与本质主义有密切关系的态度，历史决定论者往往持这种态度；4. 若确实绕不开本质，就按"事物即它的不变本质，只能通过它的变化而被理解"来处理，用变化与历史去刻画而不去追问实体
- 前提假设：方法论唯名主义者认为，科学的任务只是描述事物是如何活动的
- 常见坑：把定义之争当成事实之争；以为澄清了本质研究就推进了，结果退回中世纪关于共相的激烈论争
- 迁移场景：概念界定、需求评审、跨部门术语对齐、论文文献综述、标准与接口规范制定、争论僵局的破局
- 边界反例：需要稳定定义以界定责任与适用范围的契约、法律条文、技术规范，随意重定义会造成执行歧义与追责困难
- 原文原句："方法论唯名主义者认为，科学的任务只是描述事物是如何活动的，并且认为，要这样做就得在必要时灵活地引进新的名词，或者为了方便而对原有的名词下新的定义，而大可以不考虑原来的意义。"
- 置信度：板上钉钉
- mechanism：整体主义与本质主义共享一个预设——存在需要被"看穿"的整体与本质，于是改造被设计成一次性的彻底重建、争论被引导到定义之争；而渐进的修补把目标降为可失败、可检验的小步，批判态度把检验从"寻求证实"翻转为"淘汰假理论"，唯名主义把"是什么"翻转为"如何活动"，三者共同把不可检验的宏大主张换成可反驳的小主张
- transferable_core：凡无法一次看穿、又必须行动的对象，都用"小步可失败 + 主动找反例 + 只描述如何活动"来替代"整体蓝图 + 搜集证实 + 追问本质"
- 一手原句: "采取有步骤的措施来反对某些错事，反对不公正或剥削等具体情况，反对可以避免的苦难（例如贫困和失业），与试图实现一个遥远的理想社会蓝图截然不同。"
