# 【名称】内在有偏的样本——结论不会好于样本本身
- 适用情境：看到一份基于抽样调查的结论（民调、市场报告、用户调研、A/B 结论）需要判断可否采信，或自己正要设计一次抽样时
- 核心操作：1. 先问抽样的总体是什么——一个以抽样为基础的报告如果要有价值，就必须使用具有代表性的样本，这种样本排除了各种误差；2. 用随机样本的检验标准自查：总体中的每个名字或事物是否具有相同的几率被选进样本；3. 追问"为了得出这个结论，你调查了多少名被访者"，警惕不充分样本；4. 检查回收环节的自动除名——事实上，大多数持否定意见的人，已经随手将你的问卷丢进最近的纸篓中，从样本中自动除名了；5. 若使用分层抽样，核对自己掌握的分组比例是否正确，以及访问员能否准确判断受访者属于哪一组
- 前提假设：对样本研究后得到的结论不会好于样本本身；采用严重有偏的样本几乎能产生任何人需要的任何结果
- 常见坑：只盯着最后那个小数形式的平均数——当数据经过层层统计处理，最后简化成一个小数形式的平均数时，结论似乎被确定的光环所笼罩，但只要再仔细留心整个抽样过程，这个光环就会破灭；此外，即使你找不到任何破坏性的误差来源，但只要有产生误差的可能性，你就有必要对结果保留一定的怀疑
- 迁移场景：民意调查解读、用户研究报告评审、临床试验入组、A/B 实验分流、招聘数据复盘
- 边界反例：样本即总体（全量普查、完整日志、全部工单）时，抽样偏差不成立，此时只需核对口径与测量误差
- 原文原句："对样本研究后得到的结论不会好于样本本身。"
- 置信度：板上钉钉

# 【名称】没有透露的数据——追问全距与偏离水平
- 适用情境：对方用单个"平均数"（平均薪资、平均响应时延、平均客单价、平均家庭人数）支撑一项决策，而你完全看不到分布范围与离散程度时
- 核心操作：1. 追问被略去的两类数据——表明事物整体范围的全距，以及与平均数偏离水平的数据；2. 要求标明平均数到底是哪一种：当均值与中位数相差甚远时，注意那些没有标明类型的平均数；3. 用显著性检验判断结论是否只是机遇的产物，它是一种反映测验数据以多大的可能性代表实际结论、而不代表那些由于机遇产生的其他结论的方法；4. 把点估计改写成区间——真实的数据会落在某个数值加减误差的范围之内；5. 严格区分"正常的"与"期望的"，不要把正常区间当成个体应当达到的标准
- 前提假设：平均数——不管是否指明均值或中位数，都由于过于简单而导致无用；这些没有透露的数据其欺骗性在于人们经常忽略了它们的不存在，这当然也是使用这些数据的人获取成功的奥秘
- 常见坑：把"正常的"与"期望的"混为一谈导致事情变得更糟；按统计上的平均家庭（3.6 人）去盖两个卧室的房屋，可当越过算术平均数去注意它所不能代表的实际家庭人口范围时，我们发现 3 人或 4 人的家庭仅占总体的 45％
- 迁移场景：薪酬报告解读、性能 SLA 目标设定、容量规划、用户分层、KPI 口径评审
- 边界反例：分布高度对称且离散极小（如标准化工业件的尺寸检验），平均数已足以代表，追问全距的边际收益很低
- 原文原句："还有另一类没有透露的数据，它的遗漏也同样具有破坏性。这是表明事物整体范围的全距和与平均数偏离水平的数据。"
- 置信度：板上钉钉

# 【名称】相关关系的四种替代解释——先排除，再谈因果
- 适用情境：看到"X 与 Y 相关，所以要 X"的推断，或自己手上只有观测数据却想据此给出行动建议时
- 核心操作：1. 先写下那条被默认的前提——如果 B 紧跟着 A 出现，那么 A 一定导致 B，然后逐条排除替代解释；2. 检查第三因素：如果受到第三个因素——历史性或全世界范围内物价水平上涨——的影响，那么收入和价格两个数据都会上升；3. 检查因果方向：存在着真实的关系，但却无法确定何为因、何为果，有时因果可以不断地交换地位，或者可以同为因果；4. 检查是否只是机遇的产物：由于机会的存在，你或许可以通过一组数据来证明一些根本不存在的结论；5. 检查是否越界：不得出超过了推断相关关系的数据范围而得出的结论，而且正相关到了一定的程度后便急剧地转化为负相关；6. 若确需长期结论，只有当对同样一些妇女或者基本上同等的群体进行一段时间的研究后才能得到合理的结论
- 前提假设：相关显示了一种趋势，而这种趋势通常并不是那种理想的一对一关系
- 常见坑：把显著相关直接当成行动依据——即使某种相关关系是真实的，并有真实的因果关系，仍旧不能凭此做出行为决策；还有，那些能迷惑因果关系的统计处理和具有催眠作用的数字或者小数点，比迷信好不到哪儿上，反而更具有误导性
- 迁移场景：增长归因、A/B 结果解读、流行病学新闻判读、风控策略评估、组织效能分析
- 边界反例：有明确机制与随机对照实验支撑的因果链（药物双盲试验、工程中的应力—形变关系），无需再逐条排除替代解释
- 原文原句："即使某种相关关系是真实的，并有真实的因果关系，仍旧不能凭此做出行为决策。"
- 置信度：板上钉钉
- mechanism：一个统计结论的可信度由三段链条决定——样本是否有偏、被省略的分布信息是否被追问、相关是否通过了替代解释的排除；任一段失守，数字就会替结论撒谎
- transferable_core：面对任何以数据支撑的主张，先问三件事——样本是怎么来的、没说出来的是什么、除了因果还有什么解释；这三问适用于一切读数和被读数的场合
- 一手原句: "采用严重有偏的样本几乎能产生任何人需要的任何结果。"
