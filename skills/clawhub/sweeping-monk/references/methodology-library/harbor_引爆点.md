# 【名称】个别人物法则——联系员、内行和推销员
- 适用情境：要发起一场流行潮（推新品、传观念、做动员），资源有限、不知道该把力气花在谁身上时
- 核心操作：1. 先承认流行的兴起系于关键的少数人身上，放弃对全体人群平均用力；2. 找联系员——把我们和外部世界联系起来的那根重要的电话线，他认识的人横跨许多互不重叠的圈子；3. 找内行——热衷于帮助我们处理生活上的某些琐事、主动积累信息并乐意分享的人，让他把信息变得可用；4. 找推销员——天赋在于把他认为值得推销给大家的信息推销出去的人，让他把信息变得可信；5. 三类人各司其职、依次接力，缺一类则链条断裂
- 前提假设：观念、产品、信息和行为方式，都会像病毒一样地传播和流行开来；少数人的介入可以推动变革
- 常见坑：把预算按人头平分给所有人；只找名气最大的人而忽略真正处在连接点上的联系员；以为只要信息够好，不需要有人替它说话
- 迁移场景：新品上市的种籽用户筛选、内部变革的骨干识别、社群冷启动、招聘渠道设计、舆论引导
- 边界反例：当传播依赖强关系深度说服而非弱关系扩散时（如需要逐条核验证据的专业评审），关键少数人的连接优势会被削弱
- 原文原句："原来流行的兴起竞是系于关键的少数人身上，而他们在其间发挥的作用可以用本书概括的联系员、内行、销售员来形容。"
- 置信度：板上钉钉

# 【名称】环境威力法则——人对自己周围环境的敏感程度比他们所表现出来的更为强烈
- 适用情境：想改变一群人的行为，却发现讲道理、换人、加预算都不管用；或者需要解释为什么同一件事在不同场合结果截然不同
- 核心操作：1. 先假定环境是变量本身，而不是常量背景——发起流行的环境极端重要；2. 清理最显眼的失序信号，例如纽约市应用破窗理论通过整治环境来实现犯罪率的显著下降；3. 把组织规模控制在 150 人以下，超过这个数组织成员之间的沟通就开始存在问题、层级之间的界限开始严格；4. 警惕责任分摊——当人们处在人群中时会设想其他人会去报警，在场者越多出手的人反而越少；5. 找那些细微的、被忽略的环境因素下手，而不是改造人的内心
- 前提假设：人对自己周围环境的敏感程度比他们所表现出来的更为强烈；能否发起或斩断流行，很多时候取决于一些微小的因素
- 常见坑：把行为归因于人的品性或态度，而不去看他当时所处的物理与人群环境；人越多越安全、越容易得到帮助的直觉是错的
- 迁移场景：社区治安与街道治理、办公室工位与开放式布局设计、团队编制规模、会议人数控制、公共场所的求助设计、门店陈列
- 边界反例：需要个体承担明确责任的场景（一对一的托付、指定到人的问责），环境改造无法替代责任指派
- 原文原句："换句话说，要使人去关注身边的不幸者，有时这取决于人们身边细微的环境因素。环境威力法则认为，人对自己周围环境的敏感程度比他们所表现出来的更为强烈"
- 置信度：板上钉钉

# 【名称】附着力因素法则——稍稍改变一下呈现的形式就能改变一切
- 适用情境：投放已经到位、渠道也没问题，但信息就是粘不住人；需要在短时间内迅速提升一个说法或一件产品的附着力
- 核心操作：1. 先检查流行物本身——它应该具备能让人过目不忘，或至少给人留下深刻印象的附着力；2. 不要重写内容，稍稍改变一下你的节目呈现的形式，往往就能打造出下一个爆款；3. 把有限的资源集中用到关键方面，不撒胡椒面；4. 记住世界并非是我们一相情愿认为的我们直觉中的世界，先去测而不是先去猜；5. 保住一个基本信念：制造变化是可能的，人们能够主动引发流行潮
- 前提假设：观念、产品、信息和行为方式都会像病毒一样传播；所有能引起变化的因素都具有边际效益递增的效果
- 常见坑：以为加大投放量能弥补附着力的缺失；以为流出更多预算就等于优化关键方面；用自己从直觉中得来的世界模型推断他人的反应
- 迁移场景：广告创意与包装改版、课程讲授方式调整、产品命名与 slogan、内部通知的写法、短视频开头三秒设计
- 边界反例：当内容本身存在事实错误或合规风险时，形式优化只会放大危害；需要严格精确表达的技术文档也不宜为附着力牺牲准确
- 原文原句："第二法则是附着力因素，这条法则讲的是流行物本身所应具备的要素，它应该具备能让人过目不忘，或至少给人留下深刻印象的附着力"
- 置信度：板上钉钉
- mechanism：流行的爆发不靠均匀施力，而靠三处杠杆叠加——由联系员、内行、推销员这三类关键少数人承担扩散路径，由环境提供敏感度被严重低估的触发条件，由附着力保证信息本身粘得住人；三者同时越过引爆点，微小的投入就会以级数增长的方式放大
- transferable_core：想让任何东西流行，先换问题——不问"怎样才能影响所有人"，而问"哪几个关键少数人、哪个被忽略的环境细节、哪一种呈现形式的微调，能让系统自己越过临界点"
- 一手原句: "经验一：要想发起流行潮，就必须做到把有限的资源集中用到关键方面"
