# 【名称】干掉你最心爱的理论——与确认偏误作斗争
- 适用情境：手上已有一个判断，正在搜集信息决定要不要继续押注
- 核心操作：1. 反过来找反例而不是补证据——那位学生显然有个想法，并试图证明它不对，用各种数字试了一阵儿，直到再也找不到反例了，他才说出规则；2. 把矛盾观察制度化：一旦他的观察与他的理论相矛盾，他就会特别认真地对待它们，他始终随身携带着一个笔记本，强迫自己在30分钟之内记录下与他的理论相矛盾的观察；3. 识别"特例"话术：人们要么根本看不到对立的证据，要么干脆将它们作为"特殊情况"和"不可预见的困难"搁置一旁；4. 识别"在好转之前会先恶化"的陷阱——它是确认偏误的一种变体，如果有人建议你选择一条"先经历痛苦的道路"，你应该敲响警钟；5. 下狠手：干掉你最心爱的理论，这是一桩艰苦的工作，但作为聪明人士，你不会躲避的；6. 借助外力——请与跟你想法不同的人合作，跟那些与你拥有截然不同经验的人合作，因为你独自战胜不了它
- 前提假设：确认偏误是所有思维错误之父；直觉思维偏好可信的故事，作重要决定时不顺从它们对你是有好处的
- 常见坑：以为自己在"验证"，其实只在找支持；把"没找到反例"当成"已被证明"；面对专家意见时我们往往会比面对其他意见粗心许多，而权威也会出错
- 迁移场景：方案评审、投资判断、招聘评估、复盘会、研究假设检验、产品方向取舍
- 边界反例：在证据极度稀缺、尚无判废标准的早期探索阶段，过度搜寻反例会瘫痪行动；对已由明确里程碑检测的工作，照里程碑核对即可
- 原文原句："确认偏误是所有思维错误之父——它倾向于这样诠释新信息，让它们与我们现有的理论、世界观和信念相兼容。"
- 置信度：板上钉钉

# 【名称】拆解故事——望着里程碑，而不是望着天空
- 适用情境：读到或听到一个过于顺滑的叙事（案例分析、复盘、商业计划书、事故说明），想判断它漏掉了什么
- 核心操作：1. 默认每个顺滑的叙事都在删东西——故事偏误是指：用故事扭曲和简化现实，它们排斥不合适编进故事的一切；2. 直接拆解：请你将这些故事拆解开来，请你问问自己：这些故事想隐藏什么？；3. 把注意力从人挪到结构上——重要的不是那个倒霉蛋，而是桥梁设计；4. 盯住可检测的东西：里程碑是明确的，是可以检测的，请你望着里程碑，而不是望着天空；5. 抢救那些"不适合编进故事"的事实——我们喜欢听故事，不喜欢听抽象事实，这是一种不幸，因为为了不重要的方面，重要方面被忽视了；6. 记住直觉思维偏好可信的故事，作重要决定时不顺从它们对你是有好处的
- 前提假设：在媒体里，故事偏误像瘟疫一样肆虐；我们的大脑更容易接受壮观、华丽或大声的东西，我们的大脑是剧本式思维的，而不是量化思维的
- 常见坑：因为故事好记就以为它更真——两次死亡不是简单地先后发生的，而是有着情感联系的，于是你更容易记住它；把事后能自圆其说当成事前可预测
- 迁移场景：媒体报道与案例阅读、竞对与行业复盘、商业计划书与投资故事审阅、事故调查报告、内部汇报与晋升材料
- 边界反例：需要快速传播与记忆的场景（品牌传播、培训材料、安全宣导），故事的形式效率确实更高——只要不同时用故事替代事实核查
- 原文原句："故事偏误是指：用故事扭曲和简化现实，它们排斥不合适编进故事的一切。"
- 置信度：板上钉钉

# 【名称】行动偏误与不作为偏误——不明情形下的两头陷阱
- 适用情境：信息不足、形势不明，却面临"必须给个动作"的压力
- 核心操作：1. 先给冲动命名——这就是行动偏误：即使毫无用处，也要采取行动；2. 识别高发条件：特别是在遇到新情形或不明情形时，就会发生行动偏误；在不明情形下我们会产生要做点什么的冲动，随便什么——不管它有没有帮助；3. 看清它的收益是情绪性的：之后我们会感觉好受些，虽然其实什么也没有好转——事实甚至往往正好相反；4. 同时检查反向的坑——不作为偏误总是出现在无论放弃还是行动都会带来损害的地方，在这种情况下大多数人都会选择放弃，因为这样引起的损害主观看来更无害；5. 把问题从"我是不是该做点什么"换成"这里的损害来自行动还是来自不行动"；6. 警惕熟悉程序的自动启动：遇到一种新形势，他们不会说"我实在不知道我能向你提供什么建议"，相反，他们会启动一个他们熟悉的顾问程序——不管它合不合适
- 前提假设：我们今天的世界与过去不同——与行动相比，今天的世界奖励深刻的思考，这一转向让我们很难适应
- 常见坑：把"做了点什么"当成"推进了事情"；用现成的方法论套新形势，在这个基础上作决定——结果经常是灾难性的；在无论做与不做都有损害时，因主观上更好受而选择不做
- 迁移场景：危机响应的第一小时、事故处置、市场剧烈波动时的仓位决策、产品数据异常时的应对、管理层"必须给个说法"的压力场景
- 边界反例：有明确触发条件的动作（止损线、应急预案、已设定的里程碑）不应被"再想一想"拖延；从总体经济学来看，零风险没有太大的意义，除非后果巨大——不能借"深刻思考"之名回避必要的即时动作
- 原文原句："这就是行动偏误：即使毫无用处，也要采取行动。"
- 置信度：板上钉钉
- mechanism：大脑是剧本式思维而非量化思维，遇到模糊就用故事补洞、用行动止痒；确认偏误负责把矛盾信息过滤成"特殊情况"，故事偏误负责把不合适的细节删掉，行动偏误负责把焦虑兑换成无用的动作——三者共同把"感觉对了"包装成"判断对了"
- transferable_core：凡在信息不足时做判断，先问三件事——有什么证据能推翻我、这个叙事删掉了什么、我现在想做的这个动作到底改变了什么
- 一手原句: "我们全都是这些迅速反应者的后代，他们宁可不必要地多逃跑一次。但我们今天的世界与过去不同——与行动相比，今天的世界奖励深刻的思考。这一转向让我们很难适应。"
