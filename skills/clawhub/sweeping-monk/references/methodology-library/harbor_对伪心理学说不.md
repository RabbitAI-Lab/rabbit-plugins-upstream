# 【名称】可证伪性——理论必须指出哪些事情不会发生
- 适用情境：判断一个理论、模型、方法论或"大师课"式说法值不值得当真
- 核心操作：1. 问它排除了什么——理论必须两面兼顾，在告诉我们哪些事情会发生的同时，应该指出哪些事情不会发生；2. 检查对它的新证据进行评价时，新的数据是否具有证伪该理论的可能性；3. 用关联性原则检验：新的科学理论不仅仅要解释新的事实，还要兼容旧的事实；4. 警惕宣称"关于现实的全新观念"和"前所未有"、并把先前的数据宣布为无关的说法
- 前提假设：科学理论的表述应该遵循这样的原则——从中得出的预测有可能被表明是错误的
- 常见坑：接受了涵盖所有可能观察到的数据的理论，从此被禁锢在当前的思维方式中，失去了取得进步的可能；被"心理学不可能成为一门科学"这种非理性的主张所诱惑；把"无法反驳"误当成"已经证实"
- 迁移场景：评审研究假设、鉴别商业方法论与培训课、评估自己或他人的解释框架
- 边界反例：对已被确认过无数次、几乎不可能被未来的实验推翻的公理级结论，仍要求逐一证伪是无效劳动
- 原文原句："理论必须两面兼顾，也可以说，这项理论在告诉我们哪些事情会发生的同时，应该指出哪些事情不会发生。"
- 置信度：板上钉钉

# 【名称】聚合性证据原则——把结论建立在大量有些许差异的实验之上
- 适用情境：判断一个科学或经验结论是否可信，尤其是文献里每个研究都有瑕疵的时候
- 核心操作：1. 不坐等一个完美的或者关键的实验出现，而是对大量局部存在瑕疵的实验的总体趋势进行评估；2. 审查相关研究文献所呈现的瑕疵模式，看这些瑕疵是否都指向同一个方向；3. 检查不同类型的研究——流行病学调查、实验室研究、现场实验——是否趋向于汇聚在一个结论上；4. 看这一系列实验是否在支持某个假定理论的同时，共同排除了那些最主要的竞争性理论；5. 留意样本规模——当其他因素保持不变时，较大的样本总是能够更精确地估计出总体的真正数值
- 前提假设：聚合性证据原则允许我们将结论建立在大量有些许差异的实验来源之上
- 常见坑：用单个研究的缺陷否掉整个结论；被"研究结果是建立在许多研究的聚合上，而非某个单一的、具有决定意义的证明上"这一特性所误导；把某个实验的瑕疵当成推翻全部证据的理由
- 迁移场景：文献综述与 meta 判断、政策与医学证据评估、A/B 实验结果的综合解读、技术选型依据核查
- 边界反例：当所有研究共用同一套有偏方法或同一批样本时，瑕疵模式完全相同，聚合只是把同一个偏差放大
- 原文原句："当一系列实验始终支持某个假定的理论，同时又能共同排除那些最主要的竞争性理论时，研究就具有高度的聚合性。"
- 置信度：板上钉钉

# 【名称】警惕虚假相关——第三变量与选择性偏差
- 适用情境：用观测数据做决策、解读指标相关性、评估"用了 X 的人成绩更好"这类结论
- 核心操作：1. 先穷举第三变量解释——相关的产生可能是由于这两个变量都与未被测量的第三变量有关；2. 检查方向——当变量A和变量B之间存在相关时，在断定A的变化引起B的改变之前，必须清楚因果关系的方向可能是相反的，即从B到A；3. 用偏相关技术在统计上控制干扰变量，看相关是否仍然显著；4. 追问是不是选择性偏差——当不同生理、行为、心理特点的人们选择不同类型的环境时，就有可能出现选择性偏差；5. 能操纵变量就做真正的实验，这是确保选择性偏差不会捣乱的唯一方法
- 前提假设：两个变量之间仅仅存在相关，并不能保证一个变量的变化就会导致另一个的变化，也就是说，相关并不意味着因果关系
- 常见坑：当因果关系对我们来说显而易见时，当我们抱有根深蒂固的偏见时，或者当解释被理论定势所主宰时，就会很容易地把相关当作因果的证据；在查明相关是否真的说明因果之前，就大规模铺开训练与干预方案
- 迁移场景：增长归因分析、医学与公共卫生判断、教育政策评估、运营指标与绩效归因
- 边界反例：出于道德或伦理的考虑无法对变量进行操纵，或变量本身无法被操纵（如出生顺序、性别、年龄）时，只能依靠相关证据与复杂相关设计做出有限的因果推论，强行要求实验是不现实的
- 原文原句："两个变量之间仅仅存在相关，并不能保证一个变量的变化就会导致另一个的变化，也就是说，相关并不意味着因果关系。"
- 置信度：板上钉钉
- mechanism：单个理论必须先可被证伪才有被修正的可能；单个实验必然带瑕疵，故结论只能由大量瑕疵方向不一的实验聚合而来；而在相关层面，第三变量与选择性偏差会系统性地伪造因果外观，唯有操纵变量的实验能切断它——三条共同构成"从假说到可信因果"的过滤链
- transferable_core：先问理论排除了什么，再看证据是否从不同方法汇聚，最后确认相关背后有没有被操纵的变量在支撑；凡需把观测结论转化为行动依据的场合皆适用
- 一手原句: "尽管见证证据在检验理论的时候是无用的，但心理学研究指出，由于鲜活性效应，这类证据经常被人们过分地倚重：对于更为生动、并因此在记忆中更易提取的证据，人们会赋予其过高的权重。"
