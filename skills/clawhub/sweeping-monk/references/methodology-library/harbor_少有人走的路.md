# 【名称】自律四原则——推迟满足感、承担责任、尊重事实、保持平衡
- 适用情境：面对绕不开的人生或组织问题，且回避的代价已经高过面对的代价
- 核心操作：1. 推迟满足感——先解决问题再享受，把最难受的那件事放在最前面做；2. 承担责任——分清责任归属，既不给自己强加责任，也不把错误归咎于旁人；3. 尊重事实——以开放的心态、积极的努力，不断修订人生地图；4. 保持平衡——确立富有弹性的约束机制，必要的生气可以使我们更好地生存，但表达生气还要注意时机和场合
- 前提假设：自律，是解决人生问题的首要工具，也是消除人生痛苦的重要手段
- 常见坑：以为人生的目标就是逃避痛苦，于是得过且过，不再寻求更高层次的精神和意识的进步；把"我不能"、"我不可能"、"我做不到"挂在嘴边；或反过来把"我本来可以"、"我或许应该"、"我不应该"挂在嘴边；把情感压抑得荡然无存
- 迁移场景：个人习惯养成、团队与项目管理、危机应对、亲子教育
- 边界反例：需要即时止损或急救的情境（安全事件、急性危机、正在发生的伤害），先推迟满足感会放大损失
- 原文原句："所谓自律，是以积极而主动的态度，去解决人生痛苦的重要原则，主要包括四个方面：推迟满足感、承担责任、尊重事实、保持平衡。"
- 置信度：板上钉钉

# 【名称】批评他人之前，先进行自我反省
- 适用情境：要给下属、同事、伴侣、孩子提批评意见，或一场冲突正在升级
- 核心操作：1. 先认出冲突的实质——当我们和某人发生冲突，我们实质上是告诉对方"你是错的，我是对的"；2. 开口之前先自我反省，确认自己的观点是否有价值；3. 在两种批评方式中主动选后者：不是仅凭直觉就坚定自己是正确的，而是经过反省，确认自己有可能正确；4. 想让对方有所进步，首先就要进行自我完善，这样才能找到沟通的最佳契机和方式；5. 用诚实和谦虚打底——善于自我反省的人，才会表现得诚实和谦虚
- 前提假设：对别人提出批评，通常有两种方式：一种是仅凭直觉就坚定自己是正确的；另一种是经过反省，确认自己有可能正确
- 常见坑：把指出别人的缺点当成帮助——那只是在说"你是错的，我是对的，你应该做出改变"；给对方造成傲慢的印象；假装倾听，一边忙自己的事一边用"嗯、啊"应付；以为不批评就是爱
- 迁移场景：绩效面谈、家庭沟通、客户异议处理、公开反驳前的自检
- 边界反例：涉及安全红线、违法违规或正在发生的伤害时，第一时间制止优先于自我反省
- 原文原句："对别人提出批评，通常有两种方式：一种是仅凭直觉就坚定自己是正确的；另一种是经过反省，确认自己有可能正确。"
- 置信度：板上钉钉

# 【名称】真正的爱——促进心智成熟的自我完善意愿，靠实际行动证明
- 适用情境：判断一段关系（亲密关系、亲子、师生、团队合作）是不是真的在爱，以及该怎么投入
- 核心操作：1. 用定义检验——爱，是为了促进自我和他人心智成熟，而具有的一种自我完善的意愿；2. 用行动检验——真正的爱出自自我意愿，只能依靠实际行动来证明，其价值在于始终如一的行动；3. 区分爱与精神贯注——精神贯注的对象可能是股票，也可能是珠宝，未必会重视其心智的成熟，可能与智慧和责任无关，而且随时都可能消失；4. 检查意识思维和潜意识思维的目标是否一致；5. 承认爱是长期的和渐进的过程，投入的爱越多，经受的风险也就越大
- 前提假设：爱，是为了促进自我和他人心智成熟，而具有的一种自我完善的意愿
- 常见坑：把转瞬即逝的感觉或者精神贯注当成爱；超过能力的限制、对爱不加控制，结果是自欺欺人，给爱的对象带来伤害；以为不批评、不冲突就是爱；该倾听时没有全神贯注地倾听
- 迁移场景：亲密关系、育儿、带团队、mentoring、咨询与辅导类工作
- 边界反例：需要明确边界与责任的专业关系（如医生与病人、上级与下属），用"爱"替代专业界限会造成伤害并使判断失真
- 原文原句："爱，是为了促进自我和他人心智成熟，而具有的一种自我完善的意愿。"
- 置信度：板上钉钉
- mechanism：痛苦不可回避，自律提供处理痛苦的四条路径，自我反省把批评从权力宣示转为共同完善，而爱则被定义为推动双方心智成熟的意愿并要求以行动兑现——三者共同指向"以承担痛苦换心智成长"这一条主线
- transferable_core：把"回避痛苦"改写为"用自律承受痛苦、用反省校准关系、用持续行动兑现意愿"；凡涉及自我改变与影响他人改变的场合皆适用
- 一手原句: "自律，就是一种自我完善的过程，其中必然经历放弃的痛苦，其剧烈的程度，甚至如同面对死亡。"
