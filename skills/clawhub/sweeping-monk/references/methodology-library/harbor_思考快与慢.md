# 【名称】锚定效应——先发锚定与"为对方着想"的解药
- 适用情境：商谈报价、薪资谈判、项目估时、预算申报、法庭量刑等任何先有人抛出一个数字的场合
- 核心操作：1. 先假定任何一个公开谈判时的数字都对你有锚定效应，概率大时调用系统2抵制该效应；2. 若己方先出手，记住在协商中率先出击的一方往往会占有优势，第一次在集市上讨价还价先发锚定有着重大的影响；3. 若对方先出手，不要在其数字上"还价"，而要有意地为对方着想——把注意力集中在对方能接受的最低值或对方无法接受的费用上，以此否定能产生锚定效应的带有偏见的想法；4. 极端情况下直接终止这次商谈，明确告诉自己"如果那就是他们的提案，那么商谈就此结束吧"；5. 警惕对方抛出的荒谬小数字，被告律师提出一个微不足道的证明、里面提到一个荒谬的小损失，就是想让法官们拿这个损失做锚定
- 前提假设：锚定效应是由这个联想激发引起的，故事是否真实、是否可信一点都不重要；系统2的工作就是不信任（质疑），但它很忙也很懒惰
- 常见坑：以为识破了锚定值就不会受影响——看到随机或荒谬的锚定值的受试者会自信地说这个明显无用的信息没有影响他们的估测行为，事实上他们错了；在对方的数字上做调整而不是重新独立估值
- 迁移场景：采购议价、薪酬沟通、工期与预算估算、投资估值、诉讼请求金额设定、绩效评级校准
- 边界反例：当锚定值明显由随机程序生成、被判断者认定毫无信息价值时，锚定效应会消失；有充分行业基准与计算公式的定价场景，锚的影响可被约束
- 原文原句："例如，在第二个提议人将其注意力集中在对方能接受的最低值或对方无法接受的费用上时，锚定效应就会削弱或消除。大体来讲，有意地‘为对方着想’的策略也许是抵制锚定效应的好方法，因为它否定了能产生这些效应的带有偏见的想法。"
- 置信度：板上钉钉

# 【名称】回归平均值——最保守、最接近平均值的预测才是最准确的
- 适用情境：根据上一期表现预测下一期（业绩、考分、股价、伤病恢复、项目进度）；或要为"表扬之后退步、批评之后进步"这类现象找解释时
- 核心操作：1. 先记住只要两个数值之间的相关度不高，就会出现回归平均值的情况；2. 做数值预测时，把预测往平均值方向拉，而不是顺着上一期的极端值外推；3. 分解公式：第二天成绩＝一般水平＋运气，第一天高于一般水平的成绩等于高于一般水平的天赋加第一天的好运气，因此第二天最准确的预测通常是最保守、最接近平均值的；4. 看到极端结果后先问是不是小样本——小样本比大样本产生极端结果的概率大，大样本比小样本更精确，使用一个足够大的样本是降低这种风险的唯一方法；5. 作概率判断时往基础比率那方面想，让基础比率在预测时起主导作用，再用手头的证据做小幅修正
- 前提假设：成功等于天赋加运气，巨大的成功等于更多的天赋加更多的运气；通过分析证据得到的直观印象通常都会被夸大
- 常见坑：为回归现象编造因果故事（表扬使人骄傲、惩罚使人奋发）；忽视基础比率；用直觉而不是用计算来选定样本大小
- 迁移场景：绩效面谈与考核、投资组合复盘、A/B 测试样本量确定、招生与招聘评估、医疗效果评价、体育选材
- 边界反例：回归平均值虽然可以用来解释现象，却无法找出其中原因——当需要定位可干预的真实病因时，不能停在"这只是回归"；相关度极高（近乎确定性）的两个量之间回归现象不明显
- 原文原句："事实上，对选手第二天的表现最准确的预测通常是最保守、最接近平均值的，而不是基于第一天分数的预测。我的学生每次听到这样的结论都很惊讶。正因为如此，这种模式被称为“回归平均值”。"
- 置信度：板上钉钉

# 【名称】框架效应——在获得时偏向确定的事，在损失时偏向赌一把
- 适用情境：要向他人（或向自己）呈现一个方案、一组数据、一项风险；或发现同一事实换个措辞就得到相反决定时
- 核心操作：1. 先锁定中心点——同一个结果说成"第一个月的存活率是90%"还是"第一个月里，有10%的死亡率"，会直接翻转选择；2. 记住在获得时偏向确定的事，在损失时偏向赌一把；3. 意识到人们都讨厌损失，损失100美元的负面感受比赚取100美元所带来的满足感要强烈得多；4. 主动把"损失"转换成等量的"所得"，采用一个共同的框架再比较，问题会变得简单些；5. 面对群体决策时先让众人独立表达——想要从大量证据来源中获取最有用的信息，应设法使这些来源相互独立，讨论前先让每一位成员各自写下简短的意见
- 前提假设：你的道德感觉与框架相联系，与对实际情况的描述相联系，而不是实际情况本身；框架不应该被看成是种掩饰或曲解了潜在偏向的干预
- 常见坑：以为只有外行会受框架影响——受试者都是医生，实验者给他们看了两种肺癌治疗结果的数据，医生同样被框架左右；以为"讲清楚"就等于"讲得中立"
- 迁移场景：医疗方案告知、投资产品风险披露、政策宣导、产品定价（折扣 vs 附加费）、绩效反馈措辞、会议议程设计
- 边界反例：当受众具备统一换算标准且被强制要求在同一框架下比价时（招投标的规范化清单、强制统一披露口径），框架效应被制度性削弱
- 原文原句："在第一个月的存活率是90%，在第一个月里，有10%的死亡率。你已经知道了结果：在第一个框架下（84%的医生选择了它），手术治疗要比在第二个框架下（50%的受试者选择放射治疗）更受欢迎。"
- 置信度：板上钉钉
- mechanism：系统1自主运行、无法随意停止，它用联想激发代替计算，把锚定值、鲜活的框架和眼见即为事实的片段直接当成判断依据；系统2能监督，但它懒惰、能力有限且掌握的信息有限，默认认可系统1形成的观点或将其合理化。因此错误不来自恶意，而来自未被激活的审查
- transferable_core：凡涉及数字判断，先做三件事——识别锚、回归到平均值与基础比率、把损益换到同一框架下重述；凡是高风险决策，用制度（检查表、参考类别的预测、事前验尸、独立表达）代替对个人警觉性的依赖
- 一手原句: "不同的框架会触发不同的心理账户，且损失的严重性如何要看其指向的账户。"
