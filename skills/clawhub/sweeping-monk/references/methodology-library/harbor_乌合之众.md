# 【名称】断言、重复和传染——说服群体的三件套
- 适用情境：要说服群体（选民、陪审团、公众）接受某个主张或人选，而对方不具备逐条核验论证的能力或意愿
- 核心操作：1. 断言——把主张压成干净利落、不含推理与证据的断定；2. 重复——让同一断言反复进入视野，直到嵌进无意识；3. 传染——先拿下少数对别人有支配作用的灵魂人物，借他们的名望扩散；4. 用含义极其贫乏却能迎合极不相同愿望的新词来包装
- 前提假设：群体是不受推理影响的，它们只能理解那些拼凑起来的观念
- 常见坑：以为把道理讲透就能说服；在断言里夹带限定条件，反而削弱效力
- 迁移场景：竞选造势、产品发布、内部动员、社群运营、危机公关口径统一
- 边界反例：面对必须逐条核验证据的专业评审、学术同行评议、法庭质证时，断言链会被当场拆穿
- 原文原句："从他们的决定中也可以找到群众领袖的影响，和我们列举过的那些因素——断言、重复和传染——的作用。"
- 置信度：板上钉钉

# 【名称】用形象而非论证触动群众的想像力
- 适用情境：要让某件事被公众记住并转化为行动（公益倡导、风险沟通、品牌传播、政策宣导）
- 核心操作：1. 明确放弃论证路线——万万不可求助于智力或推理，绝对不可以采用论证的方式；2. 把事实转译成可被看见的鲜明形象；3. 让事件以"在公众面前发生"的醒目方式呈现，而不是交给周期性的统计数字；4. 用戏剧化场景承载，让所有观众同时体验同样的感情
- 前提假设：只有形象能吸引或吓住群体，成为它们的行为动机
- 常见坑：用统计数字替代具体形象——真实的规模性伤亡若只以每周发布的统计信息呈现，对民众的想像力几乎没有任何影响
- 迁移场景：公益募捐、产品演示、安全宣导、新闻发布选题
- 边界反例：需要精确量级判断的决策（工程安全阈值、医疗剂量、财务测算），形象化会牺牲准确性
- 原文原句："群体的想像力起作用的莫过于戏剧表演。所有观众同时体验着同样的感情，这些感情没有立刻变成行动，不过是因为最无意识的观众也不会认识不到，他不过是个幻觉的牺牲品，他的笑声与泪水，都是为了那个想像出来的离奇故事。"
- 置信度：板上钉钉

# 【名称】词语和套话——唤醒形象而不诉诸含义
- 适用情境：需要用一句话动员群体、给复杂主张贴一个能被记住的标签时
- 核心操作：1. 选用含义极其贫乏、因而能迎合极不相同各种愿望的新词；2. 让词语唤起宏伟壮丽的幻象，含糊不清反而增加它的神秘力量；3. 承认说理与论证战胜不了一些词语和套话，把力气花在选词而非补论证
- 前提假设：词语的威力与它们所唤醒的形象有关，同时又独立于它们的真实含义
- 常见坑：把口号写得精确严谨——精确会消解它唤醒形象的能力；误以为澄清定义就能赢回话语权
- 迁移场景：品牌命名、组织愿景表述、公共议题 framing、产品 slogan
- 边界反例：需要明确责任边界的契约、法律条文、技术规范，含糊套话会造成执行歧义与追责困难
- 原文原句："只有这些避免了分析和批判的观念，才能在群体眼里具有自然甚至是超自然的力量，让群体'肃然起敬，俯首而立'。"
- 置信度：板上钉钉
- mechanism：群体不受推理影响，只能理解拼凑起来的观念；词语与形象直接作用于群体的想像力，绕过理性审查，再经断言、重复、传染三条路径扩散，最终固化为无需讨论即可接受的判断
- transferable_core：说服群体的效力不取决于论证强度，而取决于形象的鲜明度、断言的干净度、重复的频度与传染的路径；凡需绕过理性审查的场合皆适用
- 一手原句: "只有形象能吸引或吓住群体，成为它们的行为动机。因此，最能活灵活现反映人物形象的戏剧表演，总是对群体有巨大的影响。"
