# 【名称】理念型——愈尖锐而明确便愈远离真实世界，也愈能善尽其责
- 适用情境：要从杂多的现实里整理出可分析的对象、要给一个历史或组织现象建立解释起点、要让同领域的概念彼此可比——目的理性行动的纯粹类型、纯粹经济理论、结构形态的分类
- 核心操作：1. 基于特定的观点，由杂多的现实里抽离出某些特征，整理成逻辑一致的思想秩序，做成概念工具；2. 把它构造成一个个尽可能展现完备之意义妥当性的概念单位，而不是取具有经验—统计性质的"平均"类型；3. 用它在型塑研究对象与设想其可能解释上导引我们的想像力；4. 拿现实过程与理念型的距离来反推行动者的真实动机——正可以通过现实过程与理念型的距离，使我们更容易获得关于行动者真实动机的知识
- 前提假设：社会行动的每一种理念型建构，在处理"在理想的情况下或在纯粹经济倾向的目的理性主导下，人们会如何行动呢"这类问题时，基本上都有着"脱离现实"的性质；承认并保留这种脱离现实，正是它起作用的方式
- 常见坑：把社会学概念中不可避免会含有的某种理性特质，与信仰理性动机的主导、甚至给予"理性主义"正面评价此两者混淆了；把理念型当作经验平均值去套现实；如果认为"个人主义式"的方法即包括任何意义下的个人主义的价值判断，那真是莫大的误解
- 迁移场景：历史事件的因果解释、组织与制度形态的分类、市场结构模型、产品用户画像、政策方案的基准线设定、benchmarking 中的参照系
- 边界反例：需要描述经验分布与频次的统计性工作时，理念型让位于"平均"类型；需要判断单个行动者的真实动机时，理念型只提供对照基准，不能替代对实际行动过程的核验
- 原文原句："理念型愈是尖锐而明确地被建构出来，意味着它愈远离真实的世界，但在这层意义下反而愈能够善尽其责。"
- 置信度：板上钉钉

# 【名称】动机——意义妥当与因果妥当双重校验，再以结果控制
- 适用情境：要判断某个人、组织或历史事件"为什么这样做"，尤其当可获得的只有自我告白、访谈或少数个案时——史料动机归属、质性访谈、失败复盘、竞品行为推断
- 核心操作：1. 先对既有的行动及其所表达出的主观意义作直接观察的理解；2. 区分两层判准——行为过程的关联是"主观上妥当的"或"意义上妥当的"，而因果上妥当的诠释要求根据经验规则发现它始终以同样的方式进行；3. 靠"思想实验"的不确定方法，持续思索着动机联系的元素以及建构出行动的可能步骤，以达成因果归属的判断；4. 最后以结果来控制可理解的意义诠释，正如每个假设需要通过实际过程来验证
- 前提假设：行动者对自己行动的主观意义经常只有不清楚的一份"感觉"，而非知道或"确切明白"；真正有其效果的、即被完全清楚意识到的有意义行动，在现实中始终只是一种边界的情况；主观诚实的自我告白也只具有相对的价值而已
- 常见坑：把对观察者而言似乎是相同或相似的行动过程，当成出自同一种动机；忽略行动者可能隐蔽了许多不愿承认的"动机"和"压抑"，或许这些才是其行动的真正驱动力；忘记在任何既定情境下的行动者经常会处于敌对或冲突的刺激之下；把功能参考架构的认知价值过于强调且其概念被不恰当地"物化"
- 迁移场景：历史与个案研究、组织诊断与离职复盘、用户访谈的动机推断、舆情事件归因、法律与合规中的意图认定
- 边界反例：缺少经验规则可依的一次性历史事件，诠释只能停在一种有几分确证基础的因果性假设；且若在此可以被假定具有理论上妥当性的诠释，并没有在某种程度上也与一些实际行动过程相关联的话，那么任何一个"法则"，无论它在理论上的论证多么完全，对于真实世界的行动的理解而言，也将是毫无价值的
- 原文原句："一般说来，以结果来控制可理解的意义诠释，正如每个假设需要通过实际过程来验证，是不可或缺的。"
- 置信度：板上钉钉

# 【名称】社会行动——以"有意义地指向他人"为判准
- 适用情境：判定一个现象是否属于社会学的研究对象——街头人群行为、模仿与学习、群众聚集中的个体反应、制度与秩序的效力评估、组织行为归因
- 核心操作：1. 先问行动者是否主观上把意义指向他人的行为——社会行动可以指向他人过去的、现在的或未来预期的行为，至于内在的行为意念也只有在指向他人行为时，才属于社会行动的范畴；2. 排除两类冒牌货：一类是众人基于同样的需要而各自做出的相同反应，一类是指向客观机会而非他人行动的观察学习；3. 对群体情境作专门处理——一个人只要处在"群众"聚集的场所，他的行动便会受到此一事实本身的强烈影响，某些特定的回应模式会因为个人感觉到自己属于"群众"的一部分而被激发出来，另一些模式则被压抑下去；4. 若判断的是秩序，则检验社会关系的内容是否指向可决定的"准则"，以及该秩序对行动者而言是否是义务性或视为楷模的
- 前提假设：社会学中并没有像个人的集合体去"行动"这类的东西；社会学常基于精确性或习惯的理由沿用了法律概念，但在使用上却赋予其完全不一样的意义；并非每种人与人之间的相互接触都具有社会性的特征
- 常见坑：把下雨时同时撑伞的一群行人当成社会行动；把"群众心理学"式的群体影响误认为个体之间的意义指向；把家具搬运公司在租约期满时登广告、推销员按固定日子拜访顾客这类由自利心或习俗驱动的规律性，直接当成有效力的秩序
- 迁移场景：用户行为研究（区分真社交行为与平行个体行为）、舆情与人群管理、组织制度的效力评估、模仿式学习与竞争情报的边界划分、集体责任的法律与伦理认定
- 边界反例：纯粹由生理反应或同样需要驱动的同步行为；仅指向客观机会的观察学习；以及只按习俗或自利心重复发生、尚未被行动者当作义务或楷模的规律性，都不足以称为社会行动或有效力的秩序
- 原文原句："并非每种人与人之间的相互接触都具有社会性的特征。"
- 置信度：板上钉钉
- mechanism：社会学的对象不是集合体的行动，而是个体赋予意义并指向他人的行动；先以主观意义的指向性筛出社会行动，再以"准则"与"义务或楷模"筛出秩序，两层判准缺一，解释就会落空
- transferable_core：判定"社会性"不看行为的同步性与相似性，只看行动者是否把意义指向他人；判定"秩序"不看规律是否重复出现，只看其内容是否指向可决定的准则并对行动者具有效力
- 一手原句: "只有当一种社会关系的内容是指向可决定的‘准则’才能被称为是一种‘秩序’。"
