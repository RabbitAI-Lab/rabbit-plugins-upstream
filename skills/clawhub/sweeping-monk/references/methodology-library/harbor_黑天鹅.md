# 【名称】证伪——通过负面例子而不是正面证据接近真相
- 适用情境：评估一个已被多次"验证"的判断（投资策略、用人判断、产品假设、学术假说），而手边的例子几乎全都是支持它的
- 核心操作：1. 先承认不对称：看见白天鹅不能证明黑天鹅不存在，我们的知识并不能通过一系列证实性的观察结果得到增加；2. 提出一个（大胆的）猜想，并开始寻找证明猜想错误的事例——波普尔针对这种不对称性提出了一项重大理论，其基础是一种叫做‘证伪’的方法（证明某事为错误），旨在区分科学与伪科学；3. 把注意力从"它在哪里奏效"转向"它在哪里不奏效"：你可以直接检验某个规律，着眼于该规律奏效的事例，也可以间接证明，着眼于它不奏效的地方；4. 清点沉默的证据——沉默的证据掩藏了事件的随机性，尤其是黑天鹅类型的随机性；人们总是提醒我们，腓尼基人没有写下任何东西，尽管据说是他们发明了字母表；5. 对成功故事降级处理：我们也许很喜欢那些成功故事，但太把它们当回事是不应该的，因为我们并没有看到全部事实
- 前提假设：对世界的认识只能被反驳推进，不能被举例累积；我们看到的样本，是沉默的证据筛过之后剩下的那一部分
- 常见坑：受试者头脑中有一个规律，他们举出旨在证明它的例子，而不尝试举出与他们的假设不一致的例子；用过去数据佐证——根据过去预测未来的问题可能比我们已经讨论的问题还要严重，因为相同的过去数据既可以证明一个理论，又可以同时证明完全相反的理论；把"没找到反例"当成"不存在反例"
- 迁移场景：投资 Thesis 的反面清单、A/B 测试的证伪设计、招聘中的反向背调、学术假说的批判性检验、风控模型的压力测试
- 边界反例：当只需排除一种特定风险、而不必刻画全貌时（如果你需要确定病人是否有癌症，而不是他是否健康），满足于否定性推理即可，因为它能够向你提供你所需要的确定信息
- 原文原句："由于一种我称为无知经验主义的思维方式，我们天生习惯于寻找能够证明我们的理论以及我们对世界的理解的例子，这些例子总是很容易找到。"
- 置信度：板上钉钉

# 【名称】平均斯坦与极端斯坦——别把钟形曲线用在极端斯坦
- 适用情境：要给一个领域建模或设定风险阈值，而该领域可能出现单个样本就压倒全部总和的结果（图书销量、财富、城市规模、战争伤亡、市场收益）
- 核心操作：1. 先分域：对于最大值不会与平均值相差太大的变量，高斯方法对我们很有用；对特性不明的历史数据和极端斯坦问题行不通；2. 检查两个核心假设是否成立——"第一核心假设：毎次抛硬币是独立的。硬币没有记忆。""第二核心假设：没有‘疯狂’的跳跃。"（把这里的"抛硬币"换成你自己的观察单位）；3. 一旦进入极端斯坦就停用平均斯坦的统计量：标准差的概念在平均斯坦以外毫无意义，相关性在平均斯坦以外没有意义；4. 记住事件越稀有，我们对其概率估计的错误越大，即使使用高斯方法；5. 承认极端斯坦中任意大的数字都是可能出现的——我们从没见过卖出2亿册的通俗书，但我们可以认为其可能性并不为零；6. 对复杂化补丁保持怀疑：补充性“飞跃”、压力测试、体制转换或者精巧的GARCH方法，虽然这些方法代表了人们付出的巨大努力，但它们都没能弥补钟形曲线的本质缺陷
- 前提假设：高斯钟形曲线的关键点在于大部分观察值集中在平均水平附近，也就是平均值，随着对平均值的偏离越来越大，偏离的可能性下降得越来越快（呈指数下降）；而极端斯坦的方法并不排斥长期的平淡无奇，它只是把全部影响集中在极少数事件上
- 常见坑：人们会找来没有跳跃性变化或极端事件的数据，向我‘证明’可以使用高斯分布——这正是证实谬误；一旦你让钟形曲线进入你的头脑，就很难把它赶出来；用西格玛、方差、标准差、相关性、R平方和夏普比率这些行话，把不适配的量度包装成严谨
- 迁移场景：投资组合的风险度量、内容与产品的销量预期、保险定价与巨灾模型、城市与平台规模的容量规划、KPI 目标值与考核分布设定
- 边界反例：在平均斯坦，随着样本规模的增大，观测到的平均值越來越稳定，在图中可以看到，分布越来越窄——比如犯罪统计学、死亡率等平均斯坦问题，高斯方法仍然对我们很有用；错的是把它搬到极端斯坦
- 原文原句："后来，弗兰克·伊西德罗·埃奇沃思（Frank Ysidro Edgeworth）把这种将钟形曲线用在一切地方的严重错误称为凯特勒错误。"
- 置信度：板上钉钉

# 【名称】杠铃策略——极度保守加极度冒险，不碰中等风险
- 适用情境：面对不可预测、概率不可计算的未来（市场崩盘、技术路线、职业路径），既不能不做决定，也不能假装自己算得出概率
- 核心操作：1. 放弃对概率的估计，转向对影响的处置——如果我的投资组合受到市场崩盘的影响，而市场崩盘的可能性是不可计算的，我能做的就只有购买保险，或者退出，把我不愿意发生损失的那部分金额投入风险较小的证券；2. 配置上走两端：你的策略应该极度保守或极度冒险，而不是一般保守或一般冒险，把85%～90%投入极为安全的投资工具，余下的10%～15%投入极具投机性的赌博中；3. 在冒险的那一端大量尝试：一定要参与大量这类小赌博，反复尝试的意思是尝试许多次；4. 选对下注的场子——在正面黑天鹅行业，过去没有揭示的东西几乎一定对你有利；考虑一下负面黑天鹅行业。你看到的过去的记录很可能高估了相关特征；5. 把生活中美好的偶遇最大化，让正面意外有机会找上门；6. 我关心前提甚于关心理论，我希望把对理论的依赖降至最低，脚踏实地，减少意外
- 前提假设：知道你无法预测，并不意味着你不能从未来的不可预测性中获益；接受人类存在认知自大这一事实。不要为此羞愧
- 常见坑：把钱投入“中等风险”的投资工具，看似稳健，实则在两端都不设防；我们的心理和智力都难以接受反复尝试，或者承认小的失败是生活的必需；人们讨厌波动性，因此采用可能招致重大失败的策略；不要被对一个黑天鹅事件的想象遮住眼睛，尽量多地从事这种小赌博——风险投资公司也会落入叙述谬误，被少数“合理”的故事蒙蔽，因为他们赌博的数量还不够多
- 迁移场景：资产配置、职业与第二技能的时间分配、研发组合（稳定现金流业务＋高风险探索）、内容创作的高频试错、应急预案里的保险与退出安排
- 边界反例：学会根据观点可能造成的损害而不是好听的程度来辨别它们——凡可能造成不可逆重大损失的领域，不适用"冒险的那一端"；杠铃成立的前提是小赌博真的又多又小，若把生存所需全押在一端，就不再是杠铃
- 原文原句："你的策略应该极度保守或极度冒险，而不是一般保守或一般冒险。不要把钱投入‘中等风险’的投资工具，而应该把一定比例的钱，比如85%～90%，投入极为安全的投资工具，余下的10%～15%投入极具投机性的赌博中。"
- 置信度：板上钉钉
- mechanism：在极端斯坦，概率不可计算而后果高度不对称；把资源放在中间地带，既得不到安全端的保护，也拿不到极端端的收益，于是把生存交给了那个没有被计算的尾部。杠铃把"不可计算"从一个预测问题转化为一个结构问题：一端用确定性锁住下限，一端用大量小额敞口去承接正面的意外
- transferable_core：凡概率不可知、后果不对称的抉择，都不去预测，而去改造自身结构——锁住下行、敞口上行、把一次大赌拆成许多次小赌
- 一手原句: "知道你无法预测，并不意味着你不能从未来的不可预测性中获益。"
