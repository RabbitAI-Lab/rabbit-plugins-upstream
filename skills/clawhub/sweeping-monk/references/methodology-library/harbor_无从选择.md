# 【名称】尽取者与满足者——只寻求"够好"而不必执意"最好"
- 适用情境：面对大量选项需要做出选择（购物、择业、择偶、选学校、选供应商），并希望在事后不为选择所苦
- 核心操作：1. 先给自己定标准：满足就是对足够好的事物的确定，而不再担心可能还有更好的；2. 按标准找到第一个达标的选项就停手——不要把"再看看"当成免费动作；3. 主动接受约束：最好接受而不是摆脱对选择自由的某些约束；4. 降低对选择结果的期望值，最好降低选择结果的期望值；5. 决定之后就不改了，不改变自己的决定要好一点；6. 最好不那么在意别人干什么，少做社会比较
- 前提假设：满足者可能如尽取者一般挑剔，两者的区别在于满足者对足够好的选择已经满意，而尽取者要的却是最好的；如果把收集所有选择信息的成本（时间、金钱和痛苦）都计算在内，满足实际上也是一种尽取的策略
- 常见坑：以为设定高标准是获得好结果的最好方法；以为留反悔余地总比没有好；陷在尽取者的循环里——尽取者不可能真正确定她找到了最好的毛衣，除非她比较了所有的毛衣，她也不可能确定她付出的是最佳价钱，除非他查遍了所有的标价
- 迁移场景：招聘与择校、采购选型、投资标的筛选、日程与任务取舍、婚恋决策、产品 SKU 与套餐设计
- 边界反例：当决策不可撤销且代价极高（重大手术方案、一次性大额并购），适度尽取是必要的；给他人做选择设计时，也不宜以减少责任为由替对方砍掉关键选项
- 原文原句："满足者可能如尽取者一般挑剔，两者的区别在于满足者对足够好的选择已经满意，而尽取者要的却是最好的。"
- 置信度：板上钉钉

# 【名称】高峰与结尾——改变收尾就能改变整段体验的记忆
- 适用情境：设计一段会被人记住并据此复购、复选的体验（服务流程、课程、会议、旅行、医疗与检查流程）
- 核心操作：1. 先接受规律——人类对过往体验的愉快记忆几乎完全取决于两个因素：对事情高峰时的感觉（最好或最坏），和对其结束时的感觉；2. 把资源从"平均改善全程"转向"制造一个明确的高峰"；3. 优先改收尾，因为结尾的权重与高峰相当：两段噪音同样难听、高峰部分完全一样，可第二段的结尾不那么刺耳，因此在人们的印象中它与第一段比起来不那么让人厌烦；4. 处理不可避免的痛苦时，宁可延长但让最后一段减轻——第二组病人经历了和第一组同样的不适，而且还多了一段时间，但完成检查后第二组病人表达的不适感却没有第一组强烈，因为他们最后一小段时间的难受程度减轻了；5. 记住下一次选择会基于记忆效用，而决策当下基于期望效用，两者并不一致
- 前提假设：今后的选择则会基于以前经验的记忆，这是"记忆效用"；决策基于"期望效用"，因此设计记忆就是设计未来的选择
- 常见坑：以为把全程每个环节都做到 80 分就等于好体验；把最难受的环节留在最后；用客观时长或总量去说服一个由高峰和结尾决定的记忆
- 迁移场景：服务蓝图与峰终设计、会议与培训收尾、产品引导流程、医疗与体检体验优化、客服投诉处理、旅行动线安排
- 边界反例：当体验需要被精确计量与问责时（剂量、工时、成本结算、法律时限），不能为改善记忆而牺牲客观记录；对持续进行的长期状态（长期居住、长期用药）也不适用以收尾取巧
- 原文原句："人类对过往体验的愉快记忆几乎完全取决于两个因素：对事情高峰时的感觉（最好或最坏），和对其结束时的感觉。"
- 置信度：板上钉钉

# 【名称】损失厌恶与框架效应——中心点的位置决定你算作获利还是损失
- 适用情境：制定或解读定价、折扣、附加费、退换货政策；或需要判断自己正在被哪种措辞牵着走
- 核心操作：1. 先找出中心点——用什么来判断某个价格究竟是打了折还是征收了附加费？顾客肯定不会光从看到的价格来判断，还需要知道标准价格或参考价格；2. 演练一遍换位：如果你认为是对现金结账的优惠，那就表明你将中心点设为信用卡付费，而将现金结账算作获利；3. 记住我们都讨厌损失，损失100美元的负面感受比赚取100美元所带来的满足感要强烈得多；4. 警惕获得效应——一旦某件东西给了你，那就是你的了，哪怕得到它不过几分钟，放弃它就是一种损失；5. 把同一结果用两套措辞各写一遍（存活率／死亡率、折扣／附加费），比较自己的反应是否翻转
- 前提假设：人们倾向于是避免冒险，即使面对潜在所得或潜在的正面结果，他们都讨厌冒险；如果风险增大的话，框架效应就更明显
- 常见坑：以为自己在比较价格，其实在比较措辞；以为免费试用没有成本——试用到手后再失去就是损失；忽略不同框架会触发不同心理账户这一事实
- 迁移场景：定价与促销文案、退换货与试用期政策设计、薪酬福利沟通、合同条款措辞、投资损益呈现、公益募捐话术
- 边界反例：当受众能立刻查到统一基准价并被要求按基准比价时（公开透明的比价平台、强制统一披露口径），框架操纵的空间被压缩；涉及法律强制表述的场景也不得随意换框架
- 原文原句："加油站用现金付款到底是不是一种优惠，用信用卡付费是不是加收了附加费？如果你认为是对现金结账的优惠，那就表明你将中心点设为信用卡付费，而将现金结账算作获利。"
- 置信度：板上钉钉
- mechanism：选择的痛苦不来自选项太少，而来自三条被忽略的结构性事实——尽取者要"最好"就必须穷尽比较，其信息成本未被计价；记忆由高峰与结尾而非总量与时长决定，故下一次的选择被上一次的收尾所操控；损失厌恶使同一结果在"获利"框架与"损失"框架下强度不对等，于是中心点设在哪里比事实本身更能决定决策
- transferable_core：改善选择质量的三把钥匙——把信息收集成本计入后接受"够好"、在体验上把资源集中投到高峰与结尾、在判断前先定位中心点并把损益换到同一框架下重述
- 一手原句: "我们都讨厌损失。我们都具有丹尼尔·卡尼曼和阿摩斯·特法斯克所说的损失厌恶"
