# 【名称】可反驳性划界——一切真正的检验都是有意的反驳
- 适用情境：要判断一个理论、模型、咨询结论或流行说法是不是真的能被检验，还是怎么说都不算错
- 核心操作：1. 把分界标准从"可证实性"换成"可证伪性"：一个系统只有作出可能与观察相冲突的论断，才可以看作是科学的；2. 把每一次检验重新定义为有意的反驳——一切真正的检验实际上都是有意的反驳，只有当一种理论成功地顶住了这些反驳的压力，我们才能声称它已为经验所确证或确认；3. 主动把说法说得更精确，因为一种理论愈是精确，愈易于遭到反驳，也就愈使人感到兴趣；4. 不把"驳不倒"当优点：一个理论的逻辑的或经验的不可反驳性，肯定不是一个认为这理论为真的充分理由；5. 警惕那些结构上就无法被反驳的表述——哲学或形而上学的理论根据定义将是不可反驳的，严格的或纯粹的存在陈述适用于整个宇宙，它所以是不可反驳的，仅仅因为不可能有能够反驳它的方法
- 前提假设：可检验性即等于可反驳性；正是经验反驳的可能性使经验的或科学的理论显出其特色
- 常见坑：沿用可证实性标准——它显然没有排除各种伪科学（如占星术），它并没有排除明显的形而上学陈述，却的确排除一切最重要、最有趣的科学陈述；把"找不到反例"误读为"已被确证"
- 迁移场景：评审会上识别"怎么都不算错"的表述、判断咨询报告与行业预言的可信度、识别伪科学话术、设定方案的可判废条件
- 边界反例：数学与纯逻辑理论也是通过试图反驳它来检验，但手段是证明与反例而非观察；纯存在陈述因结构上不可反驳而不适用此标准，不能据此判定它无意义
- 原文原句："一切真正的检验实际上都是有意的反驳。只有当一种理论成功地顶住了这些反驳的压力，我们才能声称它已为经验所确证或确认"
- 置信度：板上钉钉

# 【名称】试探和清除错误——用试错法替代辩证三段式
- 适用情境：面对互相对立的观点或方案，需要一个能把争论推进下去而不是"综合掉"的程序
- 核心操作：1. 认准通用方法：用来取得一个解答的方法通常都是一样的，这就是试探和清除错误的方法；2. 从一开始就抛出多个彼此独立的正题，而不是先立一个正题再等反题——用试错法作诠释的范围比用辩证法作诠释的范围稍微广泛一些，它很容易适于这样的情况：从一开始就提出许多不同的正题，它们互相独立，并且不一定是一个与另一个对立；3. 把检验理解为让弱点受最严格审查：检验理论就是使这些弱点受到尽可能严格的审查，这当然又是试错法的一种变形；4. 驳倒之后仍要回收有价值因素——尽管这里的观点或理论可能已被驳倒，但是其中仍然很可能有一种值得保留的因素，否则根本就不大可能会提出来，并且受到认真的对待；5. 对隐喻保持警惕：对辩证法家所用的许多隐喻，我们一定要当心，但不幸人们对这些隐喻往往过于认真了；6. 训练自己清楚确切地表达问题的艺术，即使这意味着要放弃某些微妙的隐喻和机智的语义双关
- 前提假设：我们正在讨论的程序规则，即推理规则，在某种程度上总是和一个语言体系有关；清楚确切地表达问题是可以训练出来的
- 常见坑：以为辩证法与演绎逻辑有关——我们没有理由相信辩证法与演绎有何相干；把"合题又成为产生新的反题的正题"当成思维规律来用；放任模糊——辩证法的模糊性是其危险之处，把辩证解释强加于各种发展以及全然不同的事物太容易了
- 迁移场景：方案选型会、观点辩论的组织、复盘会、头脑风暴的收敛环节、研究路线比较
- 边界反例：辩证三段式很好地描述了思想史的某些步骤，特别是观念和理论的某些发展，以及根据这些观念或理论所兴起的社会运动的某些发展——作为事后的描述可用，作为事前的方法则太松
- 原文原句："用来取得一个解答的方法通常都是一样的：这就是试探和清除错误的方法。"
- 置信度：板上钉钉

# 【名称】猜想和反驳两大环节——简单性、可独立检验性与新预言
- 适用情境：要产出并挑选一个新假说、新方案、新模型，而不是把旧说法重新包装一遍
- 核心操作：1. 让猜想同时满足三个要求：简单性、可独立检验性和不会很快就被证伪；2. 要求它产生新预言——特别是具有新效应、新的可检验结果的预言，而且只是这一新理论所提示、以前从未想到过的预言；3. 用判决性实验收口，因为在所有这些重要实例中，我们之所以需要新理论，都是为了找出旧理论的不足；4. 反驳的三条原理并用：批判；排除错误；判决性实验；5. 承认成功预测只是必要条件——成功的预测尽管并不是理论为真的充分条件，却至少是可独立检验的理论为真的必要条件；6. 提高似真性要同时做两件事：不仅要急于减少理论的虚假内容，而且还要增加其真理内容；7. 留意成功会稀释检验强度——如果一种理论经受了许多这样的检验，那么由于已把检验结果合并到背景知识中去，过一段时期以后可能就再也不会有可高度概然地预期出现反例的余地了
- 前提假设：科学的合理性就在于对新理论的理性选择，而不在于理论的演绎发展
- 常见坑：只顾满足前两个要求却提不出新预言——如果我们只设法提出能满足前两个要求而不能满足第三个要求的理论，科学也会由于同样的原因而停滞，并丧失其经验特点；把公理化演绎系统当成目的而不是台阶
- 迁移场景：研究选题与假设生成、产品假说的设计与判废、投资逻辑的证伪点设置、模型评估指标设计、路线图取舍
- 边界反例：探索性、描述性的早期工作还没有可设的新预言，此时强行要求判决性检验会扼杀材料积累；演绎系统本身是走向更丰富、更能经受检验的科学知识的台阶，不应把形式化当成终点
- 原文原句："我们必须设法相当经常地提出这样的理论，它们产生新的预言，特别是具有新效应、新的可检验结果的预言，而且只是这一新理论所提示、以前从未想到过的预言。"
- 置信度：板上钉钉
- mechanism：知识是假说，科学就是理性不断作出的假说，而这假说不断遭到批判，即被证伪；因为证实几乎总能找到、而反驳才提供信息，所以把检验从"搜集支持"翻转为"有意的反驳"，并让猜想承担可独立检验的新预言，理论的似真性才可能通过减少虚假内容、增加真理内容而提高
- transferable_core：凡要判断或推进一个主张，先问"什么观察能推翻它"，再问"它预言了什么以前没人想到的事"；两者都答不上来的，就不是可推进的知识
- 一手原句: "科学的合理性就在于对新理论的理性选择，而不在于理论的演绎发展。"
