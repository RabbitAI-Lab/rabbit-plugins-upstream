# 【名称】普遍怀疑与分解——怀疑到底，再把对象分成尽可能小的部分
- 适用情境：进入一个众说纷纭的领域、接手一堆既有结论、或要为一个问题找可靠起点时
- 核心操作：1. 先做一次清场——在一生中有一次对一切稍有可疑之处的事情统统加以怀疑，摆脱先入的偏见；2. 把衡量标准收回自己手里：这衡量的标准必须是我们自己的理性，不是权威，也不是道听途说，或者鲁莽武断、胡思乱想；3. 谨防感官的欺骗——有意识地对一切进行仔细分析，把它分成尽可能小的部分，小到一下就能清楚明白地洞察其本质；4. 以"清楚明白"为验收线：凡属理性清楚明白地认识到的，都是真的；5. 分不清"假"的不要急着打倒，批判不等于打倒，而是打倒假的，肯定真的
- 前提假设：我们的感觉常常欺骗我们：一座方塔，远看却是圆的；一根手杖插在水里，看来却像是折断的；我们还会做梦，梦中的现实都不真实，如果单用感官，实在无法觉察这类骗局
- 常见坑：把普遍怀疑做成虚无主义——他这一普遍怀疑是去伪存真的批判，并不是一概打倒的虚无主义；把标准外包给权威或道听途说；分解不到"清楚明白"就停手，于是把含混的大词当成已解决的单元
- 迁移场景：需求评审前清理先入之见、事故与故障的根因分解、概念与术语定义澄清、接手陌生代码库前的假设审查、论文选题前的前提检验
- 边界反例：时间极紧、后果不可逆的现场处置（急救、消防、止损），不容先普遍怀疑再逐层分解，此时应先按既定的临时行为规范行动
- 原文原句："因此我们必须时刻谨防感官的欺骗，有意识地对一切进行仔细分析，把它分成尽可能小的部分，小到一下就能清楚明白地洞察其本质。"
- 置信度：板上钉钉

# 【名称】临时行为规范——在判断上犹疑时，如何做到在行动上不犹疑
- 适用情境：证据不足、方向未定、但必须马上推进；或个人处在大改期，旧的确定性已经失效而新的尚未建立时
- 核心操作：1. 先承认这是"临时"的——当我受到理性的驱使、在判断上持犹疑态度的时候，为了不至于在行动上犹疑不决，为了今后还能十分幸运地活着，我给自己定下了一套临时行为规范；2. 在无法分辨哪种看法最正确的时候必须遵从或然性最大的看法，即便看不出哪种看法或然性大些也必须选定一种；3. 在有同样多的人接受的看法当中，总是选择最合乎中道的，因为最合乎中道、最不走极端的意见通常最便于实行；4. 选定了就坚决执行——一旦选定某种看法，哪怕它十分可疑，也毫不动摇地坚决遵循，就像它十分可靠一样；5. 学别人时以周围最明智的人为榜样，但要想知道他们真正的看法，一定要看他们的实际行动，不能光听他们说的话
- 前提假设：行动上犹疑不决的代价比看法上暂时选错的代价更大；临时规范是权宜之计，随时可以被更清楚明白的认识替换
- 常见坑：把临时规范当成终极真理，长期不换；学人只听其言不看其行；在两个极端之间来回摇摆而不取中道
- 迁移场景：创业方向未定时的推进节奏、政策未明时的合规选择、信息不足时的技术选型、组织转型期的过渡制度、个人职业空窗期的日常安排
- 边界反例：当证据已足以分辨哪种看法最正确，或决定的代价既低又可逆时，"哪怕十分可疑也坚决遵循"就不再必要，及时改道比坚定更经济
- 原文原句："在行动上尽可能坚定果断，一旦选定某种看法，哪怕它十分可疑，也毫不动摇地坚决遵循，就像它十分可靠一样。"
- 置信度：板上钉钉

# 【名称】从最简单、最一般的问题开始——让发现的每一个真理成为发现其他真理的规则
- 适用情境：进入陌生领域、从零搭建一套知识或系统、手头材料杂乱而工具尚未齐备时
- 核心操作：1. 从最简单、最一般的问题开始，而不是先啃最难的个案；2. 让成果转化为产能——所发现的每一个真理都是一条规则，可以用来进一步发现其他真理；3. 把对象改写成最容易把握的形式：为了便于分别研究它们，就把它们假定为线的关系，因为我发现这是最简单的，最能清楚地呈现在我们的想像和感官面前；4. 压缩记号——为了把它们记住或者放在一起研究，就该用一些尽可能短的数字来说明它们；5. 取各家之长互相纠偏，从几何学分析和代数里取来全部优点，而把它们的全部缺点互相纠正；6. 先立基础再往上盖——一切学问的本原都应当从哲学里取得，首先应当努力把这种确实可靠的基础建立起来
- 前提假设：真理并不是彼此孤立的、平列的，而是一些有主有从的原理，构成一个有机的体系；科学认识必须有一个扎扎实实的核心作为统帅，把形形色色的材料贯穿起来，统一成为有机的整体
- 常见坑：从最难的个案入手，每前进一步都要重造工具；只堆感性材料而不把它提炼成可复用的规则；记号过长，注意力耗在记忆而不是推理上
- 迁移场景：新领域的入门路径设计、技术债治理顺序、课程与教材编排、大型代码库重构、个人知识体系的搭建顺序
- 边界反例：面对时间窗口极短的一次性机会（抢发、救火），先立基础再推进来不及，只能先要结果、日后再补基础
- 原文原句："在这两三个月里，我从最简单、最一般的问题开始，所发现的每一个真理都是一一条规则，可以用来进一步发现其他真理。"
- 置信度：板上钉钉
- mechanism：认识要摆脱先入之见的束缚，先靠普遍怀疑清场；清场后用理性把对象分解到清楚明白的最小单元，再从最简单、最一般处起步，让每条已确立的真理转为发现下一条真理的规则，层层上筑成有主有从的有机体系；而在体系尚未建成、判断犹疑之时，行动由临时行为规范兜底，使怀疑不致变成瘫痪
- transferable_core：怀疑是清场不是拆台；"分解到清楚明白"是唯一可靠的推进单位；从最简单、最一般开始并让每条结论充当下一步的规则，是把零散材料变成有机体系的最小可行路径；在体系建成之前，用一套临时的、可替换的行为规范换取行动力
- 一手原句: "笛卡尔认识论的核心就是：凡属理性清楚明白地认识到的，都是真的。"
