# 【名称】接种预防效应——先接触一个能马上反驳的简短攻击以获得免疫力
- 适用情境：要让员工、学生、孩子或公众抵抗即将到来的说服、话术、同伴压力或谣言，提前做防护时
- 核心操作：1. 先给一个被削弱过的版本——让对方先接触到一个他们能够马上加以反驳的简短宣传；2. 逼他亲手反驳，而不是替他讲完道理：通过被迫检视自己捍卫信仰的理由，我们获得了捍卫信念的锻炼，这样在抵抗更强烈的攻击时准备就比较充分；3. 用角色扮演把反驳练成动作，例如让七年级学生练习如何反驳同学们的嘲笑；4. 优先给"文化范畴的公理"做免疫——当被攻击的观点属于文化范畴的公理时，免疫方式在产生抵抗力方面效果最好；5. 确认对方有反驳的余地，别让他的头脑被别的事占满
- 前提假设：在其他条件相同的情况下，当人们在面对与其重要信念背道而驰的宣传时，如果可能的话，往往会马上编造论据进行反驳
- 常见坑：把防护做成一次性灌输完整论证，结果对方根本没练过反驳；在冷战的高峰期，这一点时常被决策者忽视或误解；只讲抽象原则而不做角色扮演
- 迁移场景：销售与客户的话术免疫训练、青少年抵制同伴压力、辟谣与反诈宣传、竞品攻击前的客户预期管理、组织内的红队演练
- 边界反例：被攻击的内容是当场可核验的事实陈述而非文化范畴的公理时，免疫法收益有限；若受众的注意力正被别的事占满，他们就没有机会思考如何反驳，此时先做的是清除干扰而非加练
- 原文原句："如果人们先接触到一个他们能够马上加以反驳的简短宣传，那么就容易对充分展开且内容相同的宣传具有“免疫力”。"
- 置信度：板上钉钉

# 【名称】决策后不协调——把思想调整到与行动相一致
- 适用情境：自己或他人已经做出重大决定、公开表态、投入沉没成本之后，需要重新评估这条路线是否还成立时
- 核心操作：1. 先假定不协调已经在起作用——当思想与行动不符合时，决策者往往把自己的思想调整到与自己的行动相一致；2. 主动去找与自己决定相冲突的证据，因为不协调会蒙蔽双眼，使人对与现有决策相互冲突的情况置若罔闻；3. 分辨两种减压路径：把所选择行为的害处减到最小、益处增到最大，或者直接改变对这件事的态度；4. 给自尊做体检——自尊心很强的人更可能抗拒诱惑而不做不道德的事，因为不道德行为会产生极大的不协调；而自尊心较低的人做了愚蠢或不道德的行为不会体验到太多的不协调；5. 对危险信号做反向检查——住在危险区的人反而更可能通过拒绝思考或将预计的危险降到最低程度的方式来面对危险
- 前提假设：人们有一种坚持最初的猜测的倾向，并且会寻求验证她们最初的假设；大量证据都表明，确认偏见是人类思维普遍具有的倾向
- 常见坑：把"行动已经发生"当成"行动是对的"的证据；用加快投入来消除不协调，于是每次新的选择都是投入更多的武力；用自我辩解换取短期慰藉
- 迁移场景：项目继续/终止评审、投资加仓与止损、政策与战略复盘、个人职业与关系决策、学术立场更新
- 边界反例：真正的低风险可逆决定（换个会议时间、试试新工具），为消除微小不协调而反复自省会消耗决策带宽；但对危险与不可避免事件的自我辩解反应如果阻碍我们采取措施加强自身安全，从长期看来会造成致命的危害
- 原文原句："当思想与行动不符合时，决策者往往把自己的思想调整到与自己的行动相一致。"
- 置信度：板上钉钉

# 【名称】首因效应与稀释效应——安排和散发信息的方式决定别人怎样解释它
- 适用情境：安排出场或陈述顺序、设计汇报与广告、编排方案选项，或反过来发现自己正被呈现顺序牵着走时
- 核心操作：1. 先看时间——关键的变量是时间，即第一个宣传与第二个宣传相隔时间的长短，以及第二个宣传结束时与听众作出最后决定时的相隔时间的长短；2. 相隔极短时干扰最大，先讲者占优；听完就要立刻拍板时，后讲者占优；3. 涉及对人的印象时不必争论顺序：我们从某人身上最初获得的东西对我们对他的判断起着决定作用；4. 用稀释效应处理负面形象——增加非相关信息，因为关于一个人的非相关信息使该人似乎与他人相似，因此更普通，更与他人别无二致；5. 用清楚、生动、个人化的事例承载信息，而不是堆大量的统计数据；6. 对见多识广的受众改用双面论证，举出主要相反论点并逐一驳斥
- 前提假设：所有的判断都是相关的；我们如何看待人或事物取决于他们所处的环境背景
- 常见坑：以为论据扎实顺序就无所谓；忘了我们通常几乎无法控制所获信息的顺序——无论信息来自电视新闻节目还是来自平时对朋友和邻居的观察；对信息不足的受众硬用双面论证，等于替对手传播了反面论点
- 迁移场景：辩论与竞标出场顺序、述职与面试的自我呈现、产品对比页与竞品对照、危机公关中的负面稀释、问卷与方案选项排序
- 边界反例：需要按时间线或因果链还原事实的场景（事故调查、审计取证、故障复盘），调序会遮蔽因果，此时必须严格按发生顺序陈述
- 原文原句："但当问题涉及到如何影响别人对你的印象时，就不存在太多的争议：那句老话“把你最好的脚伸到前面”几乎很少有不灵验的时候；我们从某人身上最初获得的东西对我们对他的判断起着决定作用。"
- 置信度：板上钉钉
- mechanism：人是认知的吝啬鬼，靠启发式判断走思考捷径；先到的信息既因注意力递减而占据更多关注，又作为最初印象去解释后来不一致的事实；非相关信息把对象拉向"更普通"，从而稀释掉突出特征；于是判断并不由内容总量决定，而由内容所处的背景与先后决定
- transferable_core：凡要影响或复核一个判断，先管顺序、时机与参照物，再管论据；先到信息是解释框架而非待评估的证据之一，稀释则靠增加"普通"而非删除负面
- 一手原句: "所有的判断都是相关的；我们如何看待人或事物取决于他们所处的环境背景。"
