# 【名称】打破推测机器——先破坏，再修好
- 适用情境：要传达的观点是对的、也是重要的，但听众用自己的既有经验就能预测出你下一句要说什么，于是注意力立刻关闭
- 核心操作：1. 第一步，明确你要传达的主要信息——找到核心；2. 第二步，找出信息中与直觉相违背的东西，即核心信息中有什么出人意料的含义；3. 第三步，破坏听众的推测机器，用违反直觉的方式传递信息，破坏之后必须再把它修好；4. 用打破常规作为最基本的吸引注意力的方法——说到一半突然停顿、中间换一种语言讲两句这类简单的中断同样有效；5. 先让对方实践自己的思维模式，再用一个精心的设计出人意料地破坏它
- 前提假设：我们的大脑天生就对变化敏感，黏性创意最忌讳的是平淡无奇，创意越是出人意料，就越富有黏性
- 常见坑：只制造意外不给修补，听众记住了惊讶却没记住你要传达的核心信息；把出人意料做成与核心无关的猎奇，黏性归零
- 迁移场景：课堂导入、产品发布、汇报开场、安全宣导、新闻导语写作、需求评审的发言顺序
- 边界反例：要求听众严格按步骤复现的操作规程、应急手册、合规流程，意外化会干扰动作记忆
- 原文原句："如果你想让创意更有黏性，你就必须先破坏别人的推测机器，然后再把它修好。"
- 置信度：板上钉钉

# 【名称】知识缺口而非知识深渊——先填背景，再指出缺口
- 适用情境：希望对方对某个主题产生"想知道"的执着，而对方对该主题几乎一无所知、连提问的抓手都没有时
- 核心操作：1. 先判断对方拥有的是缺口还是深渊——已有背景知识、只差一块的叫缺口；毫无背景、完全无从下手的叫深渊；2. 若是深渊，必须往深渊中填入足够的知识，把深渊变成缺口，而不是直接提问；3. 再从强调他们已经知道的某些东西入手，把学生吸引到一个新的主题上来；4. 用"这是你已经知道的，现在这些是你未知的"这一结构把已知与未知的差距摆出来，明确指出他们知识中的缺口
- 前提假设：当人们想知道些事却无法实现的时候，他们就会执着地想消除这种痛苦，把我们的知识缺口填满
- 常见坑：对毫无背景的听众直接抛问题制造悬念——提问在深渊上不成立，只能得到冷漠；把背景一次性灌满，缺口被填平，好奇反而消失
- 迁移场景：课程导入、客户需求访谈、科普写作、路演开场、跨部门新项目说明、招聘宣讲
- 边界反例：对方只需要结论不需要理解的场景（故障告警、合规声明、值班交接），铺垫背景会制造噪音并延误行动
- 原文原句："你应该指出他们知识中的缺口。但如果他们对乔治亚大学牛头队不是很了解呢？这是一种知识的深渊而非缺口。在这种情况下，你必须往深渊中填入足够的知识，把深渊变成缺口。"
- 置信度：板上钉钉

# 【名称】找到创意的核心——用指挥官意图剔除多余
- 适用情境：可用材料很多但必须挑出一条最重要的信息，或团队因为信息过载、选择过多而迟迟无法作出决定时
- 核心操作：1. 分解创意直至最关键的本质，找出创意的核心；2. 剔除掉那些多余的和附属的因素，只保留核心；3. 用指挥官意图的形式把它写下来——它强迫你剔除那些也许重要但并非最重要的信息；4. 用 SUCCESs 评价标准表解释核心；5. 把核心信息当成决策锚，提醒人们什么是重要的，帮助他们避免作出不明智的选择
- 前提假设：所谓的"简约"就是"找出创意的核心"；如果我们无法区分何为"至关重要"、何为"有用"，我们就会被这种复杂性所麻痹
- 常见坑：把"重要"当成"至关重要"全部保留，等于没有核心；只做减法不写下来，团队各自理解的核心并不相同；增加选项而不收敛，反而降低了他们选择任何一种的概率
- 迁移场景：战略宣贯、产品定位、会议纪要、新闻导语、个人年度目标收敛、多方案评审
- 边界反例：需要完整保留细节与约束的场合（法律条款、实验步骤、事故复盘证据链），压缩会丢掉关键约束
- 原文原句："找出创意的核心就是分解创意直至最关键的本质。"
- 置信度：板上钉钉
- mechanism：大脑天生对变化敏感，只有破坏既有的推测机器，信息才能进入注意；进入注意之后，真正能留下来的只有被压缩到最关键本质的那一条核心；而当人们想知道些事却无法实现的痛苦，会驱动人主动去把知识缺口填满，深渊则让人直接放弃
- transferable_core：黏性不来自信息量，而来自破坏预测—压缩到核心—制造可填补的缺口这个固定顺序；凡是要让人记住并照做的场合，都可以按这个顺序重组表达
- 一手原句: "创意越是出人意料，就越富有黏性，我们应该找到人们知识上的缺口：当人们想知道些事却无法实现的时候，他们就会执着地想消除这种痛苦，把我们的知识缺口填满。"
