# 罗伯特·西奥迪尼《影响力》 方法卡（八卦炉·HarborLibrary 批次·确定性溯源）

## 【名称】互惠原则 / - 适用情境 / - 社交互动中接受他人帮助或礼物的情境 / - 核心操作(编号步骤) / - 1. 接受他人的礼物或帮助。
- 2. 在适当的时候回报对方。
- 前提假设 / - 人们倾向于回报那些给予他们帮助或礼物的人。
- 常见坑 / - 忽视回报时机，导致关系受损。
- 迁移场景 / - 商业合作、社交聚会等需要建立互惠关系的场合。
- 边界反例 / - 在某些文化背景下，直接回报可能被视为不自然或尴尬。
- 置信度 / - 八成·需看原始材料

## 【名称】权威性原则 / - 适用情境 / - 需要提升说服力或权威感的情境 / - 核心操作(编号步骤) / - 1. 展示专业知识或经验。
- 2. 使用权威人士的支持。
- 前提假设 / - 人们更愿意相信和跟随专家或权威人士的意见。
- 常见坑 / - 虚假声称专业知识或经验，损害信任。
- 迁移场景 / - 教育培训、产品推广等需要增强说服力的场合。
- 边界反例 / - 过度强调权威性可能导致反感，反而削弱说服力。
- 置信度 / - 八成·需看原始材料

## 【名称】社会证明原则 / - 适用情境 / - 通过观察他人的行为来决定自己的行为的情境 / - 核心操作(编号步骤) / - 1. 观察他人的行为。
- 2. 模仿或跟随他人的行为。
- 前提假设 / - 人们倾向于模仿他人的行为以获得安全感或归属感。
- 常见坑 / - 过度模仿他人的错误行为，导致负面结果。
- 迁移场景 / - 营销策略、团队建设等需要利用群体行为影响个体行为的场合。
- 边界反例 / - 当他人的行为明显不合理时，盲目跟随可能导致不良后果。
- 置信度 / - 八成·需看原始材料
