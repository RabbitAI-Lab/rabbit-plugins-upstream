# 【名称】反馈——以实际演绩而非预期演绩为依据的控制
- 适用情境：要造一台能稳定达成目标的机器、设计一套能自我纠偏的制度，或分析任何一个"知道有没有达到目的"的行动——火炮射击、船舶舵机、机车调速、驾驶、组织绩效复盘、个人技能练习
- 核心操作：1. 先给系统装上感觉器官，让它能把自己任务完成与否的情况记录下来；2. 把机器滞后于指定位置的程度记录下来，再利用这个差数给机器以一个补充的推进，这就是以实际演绩为依据的反馈；3. 给系统配上效应器官，使纠正动作真能作用于外界；4. 设置中枢决策器官，根据馈入的信息决定下一步动作，让反馈从调节特定动作升级为调节行为的全盘策略；5. 在自动化场景里补上双向通道——调度员能发码化信号给机器，机器也必须能回讯，调度员才能事先洞悉其工作情况
- 前提假设：必须先有一个可对照的准绳——给出一个免于受到批评的起点，也是给出一个用以和其他理论所能得到的成果进行比较的准绳；同时反馈系统自身的熵趋势须能被其他控制机构遏制在足够严格的限度之内
- 常见坑：只调节特定动作而不调节全盘策略，等于把高级反馈降回普通反射；反馈增益过高而自身失控会引发振荡；把回路交给机器之后不再追问其背后的动机和原理，等于把责任交给天风，任其吹逝
- 迁移场景：火炮与防空火控、船舶舵机与机车调速器、工厂自动化与电站无人值守、组织 KPI 与复盘回路、产品 A/B 与灰度发布、个人刻意练习（必须让练习者看到自己演绩的偏差）、制度与规则设计（准则须明确且可重复，行动者才能预先确定自己的位置，反馈才有对照基准）
- 边界反例：没有可测输出的场合（价值抉择、一次性不可重复的历史决断），反馈失去对照基准；开环即足够稳定的简单确定性任务，加反馈反而引入滞后与振荡
- 原文原句："反馈，即一种能用过去演绩来调节未来行为的性能。反馈可见是象普通反射那样简单的反馈，也可见是比较高级的反馈，在后一情况下，过去经验不仅用来调节特定的动作，而且用来调节行为的全盘策略。"
- 置信度：板上钉钉

# 【名称】学习——用过去演绩改变操作的一般方法
- 适用情境：要让机器、团队或个人从经验中真正长进而不只是单次纠错——训练动物走迷宫、防空火控、程序带编制、言语习得、组织经验沉淀、模型训练
- 核心操作：1. 先造出能把通过迷宫的总计划之成功与否全面记录下来的装置，不能记录就无法修改计划；2. 把说明演绩情况的信息送回，用它去改变操作的一般方法和演绩的模式，这一步才配称为学习；3. 用对飞机飞行的实际观测求得的统计材料，变换成控制高射炮的规则，使程序带本身发生变化——这是一种非常一般的反馈，能对仪器操作的整个方法作出改变；4. 把一般地传播"敬告所有与此事有关者"式的消息和特定通路的消息结合起来，因为新的程序带是在旧的自然刺激和新的伴随刺激之间经过多次反复的联系而后产生的；5. 追求的是制造多种多样学习机器的一般工程技术，而不只是造出一台特定的学习机器
- 前提假设：学习机的描述语言应与描述神经系统以及人和动物的行为的实际过程不太不同；条件反射对其刺激作出迅速的应答，并不必然地标志着条件反射的建立过程也是比较迅速的
- 常见坑：把"反应变快"误认为"已经学会"；只对特定动作打补丁而不去改变程序带；以为学习必须全部走数字式的特定通路，忽略了非直达消息在找到接收者之前不停传播的作用
- 迁移场景：机器学习与强化学习的设计、自适应控制、组织经验沉淀为流程与制度、个人刻意练习、教学设计（言语的学习自身就取决于每个人都听得到自己在讲话）
- 边界反例：一次性的、没有第二轮回可供修改一般方法的决断（战场单次部署、不可逆的手术）；以及行为由本能定型、成年期一开始就必须完整的情形（昆虫的机械定型限制了它的智力），学习空间本就极小
- 原文原句："但是，如果说明演绩情况的信息在送回之后能够用来改变操作的一般方法和演绩的模式时，那我们就有一个完全可以称之为学习的过程了。"
- 置信度：板上钉钉

# 【名称】通讯——讲者和听者联合起来反对混乱的博奕
- 适用情境：要评估一个组织、一套语言或一条信道到底在不在传递消息，还是只在制造通讯的姿态——学位论文选题、内部通报评审、人机接口语言设计、信息架构清理
- 核心操作：1. 把通讯看成讲者与听者联合起来为反对混乱力量而进行的博奕，先清点混乱来源：通讯中常见的种种困难和假想中的企图堵塞通讯的人们；2. 检查消息是否真有通讯价值——当存在着不需要通讯的通讯，这种通讯之所以存在只是为了使某人取得通讯传道师的社会声望和知识声望时，消息的质量及其通讯价值就会象秤锤那样笔直地降下来了；3. 给机器的各个部分规定一种适当的语言来相互交谈，除了在过程的初始阶段和最后阶段外，它们不向任何人讲话，也不听任何人的话；4. 用统计学与分布而非精确初值来描述系统，因为物理测量从来都不是精确的
- 前提假设：机器和生命体二者都可见作为局部反熵过程的例证；而局部反熵要靠信息来换取——仅当系统之外有光加进来、其温度不同于粒子自身的力学温度时，麦克斯韦妖才能不断地作工
- 常见坑：把通讯量当作通讯价值；在平衡态的系统里指望麦克斯韦妖还能分拣出秩序——那时我们顶多有暧昧不明的、来自四面八方的光，这样的光对于气体粒子的位置和动量是起不了什么指示作用的；只顾反对通讯工具造成的困难，却放过了那把已经把独创性连根砍除的斧头
- 迁移场景：学术写作与学位论文定位（应当有意识地把它作为进行积极创造的门径）、组织信息降噪、人机交互协议设计、艺术与科学中的创新取向、用统计分布替代精确预测的建模
- 边界反例：需要精确量值与严格可复现的实验报告、法律契约与制度条文，分布的模糊表述会损害可核验性；在已达到平衡态、无外部能量与信息输入的封闭系统里，任何"反熵"设计都只是幻觉
- 原文原句："他们认为，通讯是一种博奕，是讲者和听者联合起来为反对混乱力量而进行的博奕，这个混乱力量就是通讯中常见的种种困难和假想中的企图堵塞通讯的人们。"
- 置信度：板上钉钉
- mechanism：秩序的维持是对抗熵增的局部反熵过程；通讯双方必须联合起来与混乱力量博弈，靠信息（麦克斯韦妖式地选择性开门）换取秩序，而信息只有在系统之外存在温度差与能量输入时才换得到
- transferable_core：凡涉及秩序维持之处，先问"消息是否真有通讯价值"，再问"维持这份局部秩序的信息与能量从何而来"；通讯的价值不由通讯量决定，而由它抵消了多少混乱决定
- 一手原句: "我的意思从来都不是说，我们通常所理解的有关生命的那些特殊的物理、化学以及精神的过程和生命模拟（life-imitating）机中的那些过程等同。我只不过是说，它们二者都可见作为局部反熵过程的例证。"
