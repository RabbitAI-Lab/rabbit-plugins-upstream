## Description: <br>
Helps agent users, skill authors, maintainers, and teams create practical SkillScan-style workflows for bug fixes, setup hardening, reliability improvements, and adjacent skill creation. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
External developers, skill authors, maintainers, and teams use this skill to turn SkillScan-style needs into concrete plans, checklists, analysis, code changes, or decision support. It is intended for local-hardware-friendly workflow support around security review, reliability, setup hardening, and related productivity tasks. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad implicit invocation wording may select the skill for general security or workflow prompts outside the intended SkillScan-style scope. <br>
Mitigation: Invoke the skill explicitly or narrow trigger terms to SkillScan-specific phrases before deployment. <br>
Risk: Generated workflow, checklist, or code guidance may be incomplete or mismatched to a user's security requirements. <br>
Mitigation: Review outputs against local requirements and scan resulting skill artifacts before deployment. <br>
