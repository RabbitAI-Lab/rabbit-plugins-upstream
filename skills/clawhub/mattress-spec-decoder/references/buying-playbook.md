# Buying Playbook — Negotiation, Fingerprinting, Delivery

## Same-bed fingerprinting (defeating retailer-exclusive names)

1. Extract the spec stack: comfort material + density, base density, coil
   type + count + gauge, total height, cover material.
2. Search those specs (e.g. `"4 lb memory foam" "1.8 lb" 850 pocketed 12"`)
   across retailers. Retailer-exclusive names differ; spec stacks collide
   only when it's the same factory bed.
3. US brands built by the same factory groups (Leggett & Platt components,
   Somnigroup/Tempur-Sealy, Serta Simmons, Resleep/Anarchy/certiPUR mills)
   produce cross-brand twins constantly. The spec stack is the tell.
4. Verify with the trial period: order the cheaper twin, compare feel on the
   same base at home for a week; return the loser.

## Where the margin lives

- Mattress retail markup is historically 30–50%+. Floor models, holiday
  weekends (Presidents Day, Memorial Day, Labor Day, Black Friday — the four
  real discount windows in the US), and clearance of discontinued names are
  where the real discounts are.
- Boxed DTC brands have less negotiable pricing but genuine 100-night trials.
  Use the trial as your showroom.
- Frame the negotiation on the OUT-THE-DOOR price including delivery, haul-
  away, and protector — never the ticket price.

## In-store protocol (if you go)

1. Bring your `recommend` output: target firmness number and type candidates.
2. Spend 10–15 minutes per bed in YOUR sleep position. Memory foam needs
   several minutes to imprint; a 2-minute lie is a coin flip.
3. Test edge sitting (if you sit to dress) and partner motion (one rolls,
   the other lies still).
4. Write down the spec stack of every finalist — sales staff can pull
   density sheets on request; refusal is data.
5. Leave. Prices negotiated by phone/email the next day are lower.

## Trial periods and returns

- 100+ nights is the DTC norm; 30 nights is the floor before your body
  adjusts (spine and pressure points take 2–4 weeks to re-adapt).
- Return fine print: who pays return shipping ($50–200?), refund vs store
   credit, how many returns per year, "donation in lieu of return" options.
- Keep the mattress flat and dry during the trial; stains void everything.

## Delivery-day inspection

- Check the law tag: manufacture date (a bed warehoused 2 years has already
  aged), factory name (matches the brand's real maker), materials listing.
- Measure height: ±0.5" of spec is fine; an inch off = wrong model.
- Photograph the bed on the base before first use (condition baseline for
  warranty claims).
- Off-gas 1–3 days with windows open before sleeping on it.

## Warranty claim, step by step

1. Measure the sag properly: strip the bed, lay a string taut across the
   surface edge-to-edge, measure the gap at the deepest point with a ruler.
   Photograph with the ruler readable, camera dead-center, no load on bed.
2. Assemble: receipt, law tag photo, sag photos, warranty clause text.
3. File through the manufacturer (not the retailer) unless it's a retailer
   house brand. Cite the clause verbatim; state the measured depth in inches.
4. Expect one bounce-back asking for re-measurement or different photos —
   this is standard filtering, not rejection. Comply exactly.
5. Escalation: state AG consumer-protection division, or credit-card
   extended-warranty benefit if purchased on a card (many add a year).

## Topper-first rescue (before replacing)

If the support core is still healthy (no no-load sag, no edge collapse) and
the complaint is comfort, a $150–400 topper solves it:
- Too firm → 2–3" memory foam or latex topper (match your firmness gap).
- Too soft → firm latex or high-density foam topper 1–2".
- Hot → wool or breathable latex instead of more memory foam.
A topper cannot fix a sagging core — it molds into the dip within months.
