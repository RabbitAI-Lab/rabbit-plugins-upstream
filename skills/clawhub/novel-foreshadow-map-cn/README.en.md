# Foreshadowing Payoff Checklist

Turn a chapter summary or short passage into a practical foreshadowing tracker. See where a clue was planted, whether it paid off, and where an existing story beat could resolve it next. The Skill uses only supplied material; it does not rewrite a novel or issue an overall score.

![Foreshadowing Payoff Checklist promo](assets/promo-1600x900.png)

## Install

```bash
npx skills add xxjrq/novel-foreshadow-map-cn
```

## Use

Paste one chapter, scene summary, or short excerpt. Chapter numbers, character relationships, and known later beats are optional. The result tracks clues, first planting points, evidence, payoff status, and suggested recovery points. Tables are capped at 100 rows; send larger material in batches.

When context is missing, the Skill lists what is needed and marks uncertain items as pending confirmation rather than inventing plot facts.
