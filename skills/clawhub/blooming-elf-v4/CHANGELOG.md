6. 吸水盆 8 种仅提醒一次 → 强提醒 + 风险等级 + 30 天复检。
7. 病虫害 SOP 缺失 → IPM 四步。
8. 休眠期通则缺失 → 识别与处理四则。
9. 宠物毒性告警缺失 → 🐾 毒性旗（百合对猫致命）。

12. 鲜切花误列纯净水必选 + 漏保鲜剂 → 凉白开 + 保鲜剂三要素。
13. 诊断脉间黄化缺前置 → 先摸土 + 确认喜酸种。
14. 固定天数与主路径冲突 → 天数降上限。

## v4.0.3（2026-07-29）— 来自 6-7 月问题汇总报告 + 养花规范的养护知识与通用规则补充

> 来源：用户审阅两份 IMA 文档（`📋 2026年6-7月浇花系统问题汇总报告`、`养花命令与操作规范`），判断哪些该进 v4。**原则：纯养护知识 + 通用行为/提醒规则进 skill；用户专属配置（公司/家里/18:00 分时）只作 instance 数据，不写死成默认值。**

### 养护知识（补 `references/care-quickref.md` + `plant-library.md`）
- 喜酸植物补 ⚠️：月季、木槿耐碱/中性，**不加醋水**（月季用磷酸二氢钾，木槿不调酸）。
- 新增「施肥规则」：磷酸二氢钾 1:1000（花期促花，与醋水隔天不混壶）/ 生根水 1:500（换盆修根僵苗用，不按固定日期）/ 缓释肥 2-3 月 / 停肥 10-25（<15°C）。
- 新增「天气分支（提醒用）」：≥30°C 晴→晚喷；雨阴→不喷；连雨→今天不浇。
- 开花期注意补：开花植物别浇花心；非洲堇用浸盆法（坐浅水盘吸至微湿即取出，倒余水防烂根，绒毛叶不喷）。
- 含羞草修正：喜水、微潮即浇透（非"夏天少浇"），怕积水。

### 通用行为规则（补 SKILL.md）
- 用户说"浇了"→ 直接更新状态，不反问"要不要推日期 / 浇了没"。
- 吸水盆仍按日期提醒（水位低于阈值即补），不因类别跳过日期检查。
- 每天重核间隔不盲推：`next_water` 是上限参考，按土湿/天气当日判断。
- 不删改用户记录：既有内容（备注/历史）只增不改；鲜切花已丢 → 标 `已弃` 保留不删。
- 每日报花须说「共 N 盆」（N = 当天该浇土培+吸水盆数）。

### 提醒逻辑（补 SKILL.md，全部数据驱动，不写死用户专属时刻）
- 多实例按各 `instance` 的 `remind_time` + `location` 分别算、分别出清单；**禁止写死"公司早上/家里晚上"固定排程**（那是具体用户数据，非 skill 默认）。
- 超期预警 + 同一盆连续跳过追问。
- 施肥提醒按植物施肥配置列出（不写死特定植物名）。
- 喜湿植物在高温/傍晚触发喷雾提醒（按植物属性+天气）。

### 验证
- 本次为规则/知识增补，无脚本改动；`package_skill` 校验预计仍 valid。
- 版本 bump 4.0.2 → 4.0.3。
