# 修正版内置植物库（v4）

> **重要修正**：所有「水」列固定天数已标为**上限参考**，实际浇水以查土湿为准（手指插土 2–3cm / 掂盆变轻 / 筷子法）。RHS/UMD 一致指出：固定日程是室内植物头号死因，浇水过多害死植物多于任何其他原因。
> 🐾 毒性旗基于 ASPCA：🚫对猫致命(真百合) / ⚠️对猫狗有毒(草酸钙/皂苷/生物碱) / ⚠️对猫狗有毒(轻度) / 空 = 未见权威报道（不等于绝对安全）。逐条核验见 `references/toxicity-reference.md`。
> 🐦 鸟类毒性旗（养鸟家庭，如牡丹鹦鹉）：基于通用禽类毒植物学（禽类对草酸钙/皂苷/生物碱尤敏感）。🐦对鸟有毒 = 汁液或整株对鸟有刺激性/中毒风险；标「轻度」= 风险较低但仍需远离。🐦旗为安全提醒，具体以兽医清单为准。

## 🌸 鲜切花（12种）
