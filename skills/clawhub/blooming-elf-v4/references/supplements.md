# 养护补充规范（v4）

> 本文件承接 SKILL.md 中"养护补充规范"小节，提供可落地的详细 SOP。所有内容已对齐专家审计（见 `expert-audit-map.md`）。

## 1. 病虫害处置 SOP（IPM，落地专家点7）

触发词：有虫子 / 长毛 / 白粉 / 叶背蛛网。
四步闭环（RHS IPM：先物理后低毒，化学药剂最后手段）：

1. **识别隔离**：对照图鉴定位害虫；新植株先隔离 2 周观察。
2. **物理清除**：水冲叶背除红蜘蛛；酒精棉擦介壳虫；粘虫板监测。
3. **低毒药剂**：先喷皂液 / 园艺油 / 印楝油，而非直接强效农药。
4. **复查**：3–5 天后回看，未控再升级。

保留"严重病虫害建议拍照问专业花友"作为升级兜底，置于流程末端。

## 2. 休眠期识别与处理通则（落地专家点8）

**识别信号**：连续数周无新叶、基质干得明显变慢、老叶少量黄落（非突发）。
**处理四则**：
- **控水**：浇水间隔 ×1.5 倍起、干透再浇。
- **停肥停换盆**：完全停肥，不换盆。
- **减光但近窗**：擦叶除尘、转盆受光，挪近南/西窗补足光照。
- **保温避风**：远离窗户与暖气出风口。
**唤醒**：见新芽后**渐进**恢复浇水与光照，勿直接暴晒。
量化参考：休眠期浇水量较夏季降 30–50%，基质干到 3–5cm 深再浇，维持 16–20°C。

## 3. 光照量化对照表（落地专家点10）

| 定性词 | lux 区间 | 适用朝向/位置 | 手影法 |
|--------|---------|--------------|--------|
| 耐阴 | 2,000–10,000 | 北窗/室内深处 | 几乎无影 |
| 散射光 | 10,000–20,000 | 东/西窗 1–3 尺，或南窗拉纱帘 | 模糊影 |
| 喜光/喜暴晒 | >30,000 | 南窗直射或西窗下午 | 清晰硬影 |

- 提醒可输出："你这盆喜光，桌面约仅 3,000 lux，建议挪到南窗边。"
- 开花植物比观叶需更多光。

## 4. 诊断表前置判定（落地专家点13）

**强制**：用户说"叶子黄了/状态不好"→ 先问"是哪盆？"再套症状。
**脉间黄化（新叶黄、叶脉绿）前置判定**：
1. 先确认植物是否为喜酸种（杜鹃/栀子/茉莉/绣球）。
2. 先摸土：土湿/萎垂 = 浇水过多伤根（根系缺氧）→ 停水通风、改善排水，**不浇醋水**；土干且为喜酸植物 → 醋水 1:500 或螯合铁/酸性肥。
3. 排除缺光/肥害后再决定。

**诊断表**：

| 症状 | 原因 | 行动 |
|------|------|------|
| 老叶发黄掉落 | 正常代谢 | 不用管 |
| 新叶黄(叶脉绿) | 缺铁性黄化 | 先摸土+确认喜酸种→醋水/螯合铁 |
| 新叶整体发黄 | 缺氮/水多 | 少量通用肥/减少浇水 |
| 整株耷拉 | 缺水 | 浇透，阴凉处恢复 |
| 叶缘焦黄 | 太干/肥害 | 喷雾/停肥冲水，剪焦黄 |
| 叶片发黑变软 | 烂根 | 停水通风，剪黑叶 |
| 叶面白粉 | 白粉病 | 通风，减少喷水 |
| 叶背蛛网 | 红蜘蛛 | 叶背冲水，增湿 |
| 花苞掉落 | 环境变化/缺水 | 新花适应期；老花查水 |
| 水培叶枯(水还有) | 缺营养/烂根 | 白根补营养，黑根剪烂根 |

> 叶子蔫了 ≠ 缺水！必须先摸土。坏死叶剪掉。

## 5. 施肥公式（保留 v3，落地专家建议）

```
下次施肥 = 上次施肥 + 施肥间隔
```

| 肥料 | 间隔 | 备注 |
|------|------|------|
| 通用液肥 | 7-14 天 | 取 10 天中位 |
| 酸性肥 | 14 天 | 喜酸植物；**优先缓释/螯合型**，避免以醋水替代长效调酸 |
| 兰花专用肥 | 7-10 天 | 蝴蝶兰，稀释一半 |
| 高钾肥 | 14 天 | 柠檬树花果期 |
| 开花肥/磷钾肥 | 7-14 天 | 非洲堇/绣球花期 |
| 颗粒缓释肥 | 2-3 月 | 撒土表 |
| 生根剂 | 每月 1 次 | 严格 1:500 |

**不施肥**：冬季 10/25 后（<15°C）、新花到家 1-2 周缓苗、高温 >35°C、开花植物花期过半。

## 6. 换盆流程（保留 v3）

触发：根从盆底钻出 / 土半年以上没换 / 浇水立刻流出（板结）/ 明显停滞。
春秋最佳，避花期与极端温。新盆直径 = 原盆 +2–3cm。通用配土 泥炭+珍珠岩 3:1；多肉颗粒土；兰花水苔/树皮；喜酸泥炭+腐叶土。操作：提前1天浇透→脱盆→抖旧土1/3→剪黑根→新盆陶粒→装土→居中填土→定根水浇透→阴凉缓1周。缓苗1周不晒不施。

## 7. 抢救 SOP（保留 v3）

- **全蔫**：土干白→浸盆30分+阴凉缓4h；土湿→别浇，通风剪枯叶；茎硬能救，茎软没救扦插。
- **烂根**：脱盆抖土→剪黑根→多菌灵1:1000泡30分→晾根2h→换新土新盆→缓苗1周。
- **冻伤**：搬室内(非暖气房)→5-10°C缓1天→剪冻伤→不浇热水→1周看芽。
- **晒伤**：搬离强光→剪焦叶→散射光喷雾→1周看新叶。

## 8. 温度异常处理（保留 v3）

| 区间 | 行动 |
|------|------|
| >35°C | 早7前/晚7后浇；停肥；多喷雾；中午遮阴50% |
| <5°C | 搬室内远窗；停肥；不浇透；武汉绣球/茶花可户外过冬 |
| 5-15°C | 减水(+1-2天)；停肥(10/25后)；防霜 |
| 15-25°C | 正常 |
| 25-35°C | 加大水量(-0.5~1天)；早晚浇 |

## 9. 浇水黄金法则（保留 v3，强化）

1. 浇则浇透 2. 不干不浇（浇水过多为室内植物头号死因，RHS/UMD）3. 早晚浇 4. 水温室温 5. 盆底不积水（吸水盆除外）。
判断：手指插土2-3cm（推荐）/ 掂盆 / 筷子法。

## 10. 新手误区

| 误区 | 真相 |
|------|------|
| 每天浇一点 | 要么浇透，要么不浇 |
| 叶子蔫就浇水 | 先摸土！水多烂根也会蔫 |
| 多施肥长得快 | 薄肥勤施，新花1-2周不施 |
| 喷水=浇水 | 喷雾增湿，根喝不到 |
