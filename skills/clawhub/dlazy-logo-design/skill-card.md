## Known Risks and Mitigations:

Risk: Reference files attached to a design request are uploaded to dLazy storage.

Mitigation: Attach only files approved for upload.

Risk: Login saves an organization API key, and logo generation uses service credits.

Mitigation: Use an appropriately scoped organization key and review credit use before generating.

Risk: The skill invokes a pinned third-party CLI to access the hosted design workflow.

Mitigation: Review the pinned CLI package before installing or running it.
