## Description:

Helps create, refine, and evaluate brand logos with transparent-background results and previews in multiple contexts through dLazy.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Designers, brand teams, and other users can develop or assess a logo and preview it across brand applications with dLazy's hosted design service.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Logo prompts, project context, and explicitly attached reference files are sent to dLazy's hosted service.

Mitigation: Review prompts and attachments before sending, and avoid sharing sensitive or unauthorized brand materials.

Risk: Using the third-party CLI requires a dLazy API key and may leave a global CLI installation.

Mitigation: Use the on-demand npx option if preferred, and rotate or revoke the API key when access is no longer needed.
