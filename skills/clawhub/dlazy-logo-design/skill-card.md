## Description:

Logo design and brand identity skill for creating, upgrading, or evaluating logo marks, including brand-gene analysis, strategy, concepts, refinement, delivery, evaluation, transparent-background logo output, and multi-context preview.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

External users, designers, brand teams, and developers use this skill to create, upgrade, or evaluate a logo or brand mark through the dLazy hosted logo-design workflow.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and files attached with --files are sent to dLazy services.

Mitigation: Confirm before uploading confidential brand assets or reference files, and use the skill only where third-party hosted processing is acceptable.

Risk: The skill installs or runs a third-party CLI and may store a dLazy API key locally.

Mitigation: Prefer the pinned npx invocation for occasional use, review the CLI source in sensitive environments, and rotate or revoke API keys when needed.
