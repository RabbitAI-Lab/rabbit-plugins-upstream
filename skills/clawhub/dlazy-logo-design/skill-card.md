## Description:

Helps create, refine, and evaluate logos and brand identity, including transparent-background designs and multi-context previews.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Designers, brand teams, and other users can create, improve, or evaluate a logo and preview it across branding contexts using dLazy's hosted service.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Logo prompts and attached reference files are sent to dLazy's hosted service.

Mitigation: Share only prompts and files you are comfortable sending to dLazy; review attachments before uploading.

Risk: The local CLI stores a dLazy API key in the user's configuration.

Mitigation: Protect the local configuration and rotate or revoke the key if it may have been exposed.

Risk: A global CLI installation persists on the user's system.

Mitigation: Use the pinned npx option when a global installation is not needed.
