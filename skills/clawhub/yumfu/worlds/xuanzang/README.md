# 大唐西域记 / Xuanzang World

Playable historical Silk Road travel adventure for an original character. The 12-fascicle source is used as a route and geography reference, not copied into the package. Side stories are clearly transformative fiction and do not overwrite the recorded itinerary.

Primary local reference used during authoring: `~/clawd/skills/daily-xuanzang/references/structure.md` and the public-domain CBETA T51n2087 classical Chinese source.
