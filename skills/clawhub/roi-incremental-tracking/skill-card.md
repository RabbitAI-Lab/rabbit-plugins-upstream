## Description: <br>
Track your AI agent's ROI incrementally - log time saved and direct cash as deliveries happen, then close the cycle monthly with an HTML dashboard. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[thiagocaltoe](https://clawhub.ai/user/thiagocaltoe) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, operators, and teams using AI agents use this skill to track incremental ROI as work is delivered. It helps set up a lightweight local ledger, log conservative time-saved and confirmed cash-value entries, close monthly cycles, and generate an HTML dashboard. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill writes local ROI report files and may overwrite existing reports/roi data if used without checking the workspace first. <br>
Mitigation: Before setup or closeout, check whether reports/roi already contains data, preserve any existing files that matter, and ask the agent to avoid overwrites or make backups. <br>
Risk: The monthly dashboard is regenerated by running a local report script. <br>
Mitigation: Verify that reports/roi/render_roi_report.py exists and matches the expected skill-provided dashboard script before allowing it to run. <br>
