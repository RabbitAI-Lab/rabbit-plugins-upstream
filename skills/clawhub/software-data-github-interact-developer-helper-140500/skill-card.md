## Description: <br>
Helps agent users, skill authors, maintainers, and teams plan and execute GitHub-style developer workflows such as bug fixes, setup hardening, reliability improvements, and related skill creation. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

## Use Case: <br>
Developers, agent users, skill authors, maintainers, and teams use this skill to turn GitHub-style workflow requests into practical plans, artifacts, checklists, code changes, and verification notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad activation wording may select the skill for general GitHub, CLI, issue, API, or bug-fix requests where a narrower skill would be better. <br>
Mitigation: Confirm the user wants general developer workflow support before relying on the skill's guidance. <br>
Risk: The skill can propose commands or repository changes that may be incorrect for the user's project. <br>
Mitigation: Review proposed commands and code changes against the target repository, then run the suggested verification steps before applying them broadly. <br>
