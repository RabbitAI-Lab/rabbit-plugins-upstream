## Description:

Evaluates user-selected agent skills through static analysis, assigns a 100-point quality score, and provides review reports and improvement suggestions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[z-zihan](https://clawhub.ai/user/z-zihan)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and skill authors use this skill to assess a selected agent skill's quality and resilience, receive a scored review with improvement suggestions, and validate proposed fixes before approving them.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Proposed repairs, especially added translations, can introduce incorrect or misleading skill guidance.

Mitigation: Specify the exact skill or repository to review and inspect proposed changes before approving repairs; use the read-only audit as supporting information.
