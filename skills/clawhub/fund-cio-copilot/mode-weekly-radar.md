# Mode: 产业雷达（周报）· Radar

## 1. 定位与边界
- **是什么**：CIO Copilot 的"外部视野"补足。Screening / Evaluation / IC 处理"已进漏斗的项目"，Radar 处理"市场在发生什么、哪些赛道与区域值得关注"。
- **核心决策**：本期地方国资投资呈现哪些态势与可借鉴逻辑（情报研判，非项目级投资决策）。
- **边界**：
  - 情报类 Mode，**不产出 Decision Object、不写入 Decision Memory**（不属于项目决策，避免污染机构记忆）。
  - **情报自动化 ≠ 投资自动化（v2.6.2 写死）**：Radar 可自动采集、核验、归纳、推送；**任何标的进入 Investment Decision Flow 必须重新经过 Mandate / Gate / Evidence 流程**——每周自动跑完 ≠ 自动产生投资结论。
  - 但可维护独立的**「标杆案例库」**（研究智库，见 §11）：记录可复制范式 / 赛道锚点供横向借鉴，属情报研判，**不写项目级 Decision Object**，与 Decision Memory 分离、互不污染。
  - 可把显著赛道 / 区域趋势作为"环境输入"反馈给 Mandate 与 Screening，但本身不做项目级投资建议。
  - 辅助研判，不做投资决定；文末附信息说明与 AI 生成提示。

## 2. 触发信号
| 信号 | 路由 |
|------|------|
| "周报" / "产业雷达" / "地方国资上周投了什么" / "生成产业周报" | Radar |
| 自动化调度（每周一，覆盖上周） | Radar |

> 不确定时：这是情报周报需求，直接进 Radar，不要误路由到 Screening / Evaluation / IC。

## 3. 执行流程
```
1. 定窗口：上周一—周日（以公开披露时点为计，允许含 1—2 日边界案例）
2. 检索：WebSearch 多维覆盖（见 §4）
3. 核验：企查查工商核验核心国资标的（见 §5，内部动作，禁入正文）
4. 撰写：按公文标准成文（见 §6）
5. 交付：落盘 地方产业基金投资观察_YYYY-MM-DD.md + present_files
6. 标杆入库：自动执行 Capture（见 §11）——挑当周可复制范式 / 战略方向锚点案例，增量写入标杆案例库，并 Recall 历史同类供比对
```

## 4. 检索策略（多维全覆盖）
**三类必覆盖**：
- ① 基金直投（股权融资）被投企业
- ② 上市公司公告入股：定增 / 协议转让 / 拿控制权（"以投带引硬着陆"）
- ③ 广深外广东、川渝、陕西、鲁豫闽、东北及县域级平台直投

**赛道矩阵**：
- 硬科技：聚变 / AI·机器人 / 半导体 / 商业航天 / 低空 / 智能汽车 / 生物医药 / 量子
- 偏科方向：新能源储能 / 新材料 / 传统数字化 / 现代农业食品

**关键词模板**（每期轮换组合，示例）：
- `"地方产业基金 政府引导基金 直投 被投企业 2026年M月"`
- `"国资 上市公司 定增 协议转让 入股 控制权 2026年M月"`
- `"商业航天 低空经济 AI机器人 半导体 融资 国资 2026年M月"`
- `"川渝 陕西 山东 河南 福建 产业基金 投资 企业 2026年M月"`
- `"安徽 东北 县域 产业基金 直投 落地 2026年M月"`
- `"新能源储能 现代农业 食品 国资 产业基金 投资 2026年M月"`

> 检索要"广撒网 + 交叉验证"：同一案例至少两个独立来源（行业媒体 + 官方 / 公告 / 工商）才入表；单一来源且无法交叉验证的，标"待核实"。

## 5. 数据核验（内部动作 · 禁止进入正文）
- 工具：`qcc-company`（已连接）。
- 动作：对核心国资标的拉取工商股东名册 / 变更记录，确认"出资地方基金 / 国资"列的准确性。
- 判定：
  - 工商直接确认 → 正文采信；金额 / 持股非精确披露的标"约 / 测算"。
  - 新一轮出资人未体现在工商快照 → 正文用"以最新工商为准"或"待核实"，**不写"核验中 / 待工商"等过程字样**。
  - 企查查未覆盖或名称歧义 → 标"待核实"，不强行断言。
- ⚠️ 核验是发布前的质量关卡，其过程与中间状态一律不出现在最终报告。

## 6. 撰写标准（套用"深知公文写作"标准）
- **定调段**：开头用 1 段交代 时间 + 总体态势 + 报告逻辑（"总体态势—案例梳理—逻辑启示"），取代直接堆点。
- **一级标题**：用「动作 + 对象 + 效果」式小标题（如"硬科技融资延续高热，大额交易频现"），表述稳妥。
- **案例表（手机优先 · 竖向卡片式）**：必须带**连续编号表题**（用 `### 表1`、`### 表2`… 三级标题作分组小标题），按赛道分表。**不用宽表格**——原 5 列横表（企业｜赛道｜出资｜轮次&金额｜看点）在手机上需横滑、单元格长文本挤读，体验差；一律改为每家企业竖向卡片：
  ```
  **企业名称**（赛道）｜轮次&金额
  - 出资：出资地方基金/国资（及产业/财务方）
  - 看点：……
  ```
  区域维度用【区域】标签嵌入企业名下（如 `**企业（落子安徽淮北）**（赛道）`）或看点，不单设区域表。表前不写额外指引或 `>` 引用块（保持干净，适配公众号与手机阅读）。
- **启示章节**：用精简要点句（每条 1—2 句，直给判断与对策），不必展开"事实依据—判断—启示"长链；避免散点罗列。
- **文末**：信息说明（覆盖窗口 + 公开来源 + 约 / 测算 / 待核实 标注说明），压为 1 段短说明；不加【AI生成提示】独立行（用户已要求删除）。
- **字数控制（~3500 字，用户稳定偏好）**：正文（不含标题/说明）控制在约 3500 中文字（上限约 4000）；冗余解释从简——定调段 1 段（可含一句覆盖面说明）、主要特点 5 条短文（每条可加一句背景/后果）、各赛道表前加一句引导语（含金额合计/重点）、启示精简要点（每条可加一句动作建议）、文末说明压 1 段。被投企业卡片全保留（信息密度优先），每家看点可补一句尾注。

## 7. 简化规则（用户明确口径，必须遵守）
- ❌ 不逐条标注具体来源；来源统一在文末「信息说明」提醒。
- ❌ 数据核验动作不进正文。
- ❌ 不写"来源索引"独立章节。
- ❌ 不写"下期预告"。
- ❌ 不写 BlockQuote 移动端阅读指引（表前保持干净，适配公众号/手机）。
- ❌ 启示不做冗长"事实依据—判断—启示"长链（精简为要点句）。

## 8. 合规与口径
- 只引用公开信息（行业媒体、各地国资委 / 产投 / 城投官网、上市公司公告、企业工商变更）。
- **金额精确化（优先具体，用户稳定偏好）**：撰写时优先采用公开披露的**具体金额**（如"帕西尼10亿元战略轮""奕斯伟增资65亿元""必博累计9亿元"）。若初始来源只给"数亿元/超亿元/数千万元"等区间口径，须用 WebSearch 二次核验尝试补到具体数字（如"昉擎科技A1轮近10亿元""破壳机器人Pre-A轮1亿美元""智象未来三轮累计超21亿元""无界开物约2000万元天使轮"）。补不到单值的，保留区间并标"约/测算"；源头完全未公开的标"待核实"。**不编造具体数字**——区间与"待核实"宁可保留，也绝不臆造金额。
- 金额 / 持股为测算值 → 标"约 / 测算"；未披露 → 标"待核实"；**不编造**。
- 国资入股属公开工商 / 公告，可引用；涉及实际控制人或股权结构变化的，以最新工商登记为准。

## 9. 输出
- **标题（H1）**：`地方产业基金投资观察（YYYY/WW周）`。WW = 覆盖区间（上周一—上周日）主落点所在 ISO 周（取其周日所在周），YYYY = 该周年份；日期区间不再进标题，保留在文末【信息说明】"覆盖窗口"。例：覆盖 8/1–8/9 → 「地方产业基金投资观察（2026/32周）」。
- **文件名**：`地方产业基金投资观察_YYYY-MM-DD.md`（YYYY-MM-DD 为刊发日，取周一，仅作存储键，与标题周次独立）。
- **存储**：workspace 根目录。
- **结构**：一、本期主要特点 → 二、被投企业案例（按赛道分表·竖向卡片 + 区域覆盖小结）→ 三、投资逻辑与启示 → 文末信息说明 + AI生成提示。
- **交付**：落盘后调用 present_files 推送给用户（自动化场景用户可能在其他客户端接收）。
- **标杆案例库（辅助输出，不纳入正文）**：周报完成后按 §11 自动增量维护 `.workbuddy/decision_memory/benchmark_cases.jsonl` 与 workspace 根 `标杆案例库.md`，不影响周报交付。
- **推腾讯文档（稳定路径）**：用 `tencentdocs.py` 的 `doc.create_with_markdown`（参数 `base64_markdown` + `title`），走普通 DOC 端点，markdown 渲染为正式文本，手机/公众号复制友好。**禁止用 `create_smartcanvas_by_mdx`**——该 smartcanvas 端点长期不稳定（曾持续返回 code 12977 故障多小时）。同步机制同前：更新=重新 create 一份新文档，旧文档由用户手动清理（脚本无法删腾讯文档）。

## 10. 自动化
- **调度**：每周一（rrule `FREQ=WEEKLY;BYDAY=MO`），覆盖上一周。
- **幂等**：已存在同名文件则覆盖更新（同一周一不重复生成）。
- **与其他 Mode 协同**：Radar 输出可作为 Screening 的赛道 / 区域输入；发现值得跟进的标的，引导用户进入 Screening 做 Mandate Check。

## 11. 标杆案例库 · Capture + Recall（研究智库 · 独立于 Decision Memory）

- **目的**：把每期周报（及 H1 全景等半年度源）中"值得借鉴研究"的案例落成**可机读 + 可读**双份，逐步形成机构自己的"打法范式库"，供后续同类项目自动比对、不重复踩坑。
- **与 Decision Memory 的关系**：本库是**研究智库**，记录"可复制范式 / 赛道锚点"用于横向借鉴；**不写项目级 Decision Object**。Decision Memory 仍只存项目决策（Screening/Evaluation/IC 漏斗内），二者分离、互不污染。
- **入库筛选标准（三条卡，非金额大就入）**：
  1. 有可复制范式 —— 能抽象成"别的地方可照抄的交易结构 / 打法"；
  2. 是赛道定义性锚点 —— 即便不可复制，但定义了赛道量级与产业意义（如长鑫 / 星际荣耀），标 `definitional` 仅作参照；
  3. 排除两类 —— 金额巨无霸但普通地方接不住的（如奕斯伟 65 亿）、信息待核实的异常案（如天腾 8 亿天使）。
- **六大战略产业方向（主轴 · 必标）**：每个入库案例必须打 `strategic_direction` 标签，取值固定为六类（覆盖本案绝大多数硬科技 / 国资直投）；
  - ① 新一代信息技术（半导体 / AI / 量子 / 通信）
  - ② 高端装备制造（商业航天 / 机器人 / 工业母机 / 智能制造）
  - ③ 新材料
  - ④ 新能源（储能 / 固态 / 氢能 / 聚变）
  - ⑤ 生物医药（合成生物 / 脑科学）
  - ⑥ 新能源汽车（智能汽车 / 车规芯片）
  - 备注：若案例不属六大（如两面针日化、广东农业基金带农业），归 `其他（范式保留）`，单列不参与战略统计、但作跨方向方法论保留。口径以基金实际"六大"为准；遇基金口径不同（含节能环保 / 海洋装备、或不含新能源汽车），按基金口径重标。
- **双轴检索**：案例同时带两类标签，支持双轴交叉查询；
  - 轴 A（战略方向）：`strategic_direction` ∈ 六大 + 其他
  - 轴 B（跨范式）：`pattern_category` ∈ {以投带引·控股权锁定, 四重合力·跨区域联合, 早期硬科技·前置卡位, 县域下沉·串产业带, 耐心资本·退出闭环, 赛道金额锚}
- **Capture（落库）**：每期周报完成后由本 Mode 自动执行——挑出当周可复制范式 / 战略锚点案例，增量写入机读库（**去重**：同 `case_id` 或同"企业 + 同口径"已存在则跳过或更新 `source_week`），并同步更新可读 `标杆案例库.md`。
- **Recall（召回）**：
  - 新项目进 **Screening**：先按 `strategic_direction` + `pattern_category` 比对，命中即以本案库 `deal_structure` / `replicable_by` 作参照；
  - 进 **Evaluation**：比对 `track` + `replicability`，低可复制方向（量子 / 聚变 / 脑机）自动提示"需前置卡位额度、控小股"；
  - 周报撰写如引用已有标杆，备注其 `source_week` 标明时间坐标。
- **文件**：
  - 机读（`.workbuddy/decision_memory/benchmark_cases.jsonl`，每行一案例，字段：`case_id / strategic_direction / pattern_category / track / replicability / replicable_by / deal_structure / source_week / source / source_type / definitional`）。其中 `source` / `source_type` 用于标注案例来源（如公众号/公开分析聚合 `source_type: wechat_public_analysis`，可带 `source_week` 时间坐标）；周报/H1 来源用 `source_report` 区分。
  - 可读（workspace 根 `标杆案例库.md`：六方向分布表 + 跨范式表 + 不建议抄清单 + Recall 说明）
- **⚠️ 仅研究优先级研判**：本库标注"值得借鉴研究"属情报研判，**非具体项目投资决定**；最终以 IC 审议为准。
