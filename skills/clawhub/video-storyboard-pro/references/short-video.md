# 短视频分镜专项（15-60秒）

## 核心特征

- 时长：15-60秒
- 平台：抖音/视频号/小红书/B站短视频
- 目标：快速抓住注意力、完成单一信息传递、引导互动
- 节奏：快、紧凑、高密度

## 开篇钩子设计（最重要）

短视频的生死线在前3-5秒。

### 钩子类型库

| 类型 | 公式 | 示例 |
|------|------|------|
| 灵魂拷问 | "你有没有想过——" + 反常识命题 | "你有没有想过，你每天做的80%的工作，AI已经能做了？" |
| 数据冲击 | 惊人数字 + 对比 | "3小时 vs 30秒。同一个周报，不同的结果。" |
| 场景共鸣 | 描述一个普遍痛点 | "周五下午5:55，你还在对着空白文档发呆。" |
| 悬念制造 | 先给结果，留"怎么做到的" | "老板给我涨薪了，因为我做对了一件事。" |
| 身份挑战 | 直接对观众下定义 | "如果你还在手动写周报，这篇文章就是为你写的。" |

### 钩子设计铁律
- 不要说"大家好""今天我们来聊聊"
- 不要在第一帧放Logo
- 不要超过5秒才进入正题
- 第1帧：强视觉+一句话（黑底白字或极简构图）
- 第2帧：立即展开内容

## 节奏模型

```
[0-5s]   钩子——单镜头，黑底白字或冲击构图
[5-15s]  展开——3-5个快速镜头，景别交替
[15-25s] 核心——信息最密集段，含数据/演示
[25-30s] 收尾——情绪释放+行动号召
```

### 短视频景别节奏
- 每镜2-4秒（比长视频快50%）
- 景别必须交替：不连续2个同景别
- 关键信息用CU/XCU停留2s以上
- 每个镜头必须有明确的"这一秒在看什么"

## 竖版适配（9:16）

短视频默认竖版，对构图有特殊要求：

### 竖版构图要点
| 元素位置 | 效果 |
|---------|------|
| 中心偏上1/3 | 视觉重心（角色面部/关键物体） |
| 中心 | 对称构图（产品展示/数据大字） |
| 下方1/3 | 字幕安全区 |
| 画面两侧 | 留白，不要放关键信息（平台UI会遮挡） |

### 竖版镜头选择偏好
- 优先用中景/MS到特写/CU（全景在竖版中环境展示有限）
- 俯拍/仰拍比平拍更有视觉冲击
- 避免过宽的横摇镜头（竖版横向信息量小）

## 短视频分镜模板

### 模板A：知识科普型（30s）

| 镜号 | 景别 | 内容 | 时长 |
|------|------|------|------|
| 01 | CU文字 | 黑底白字灵魂拷问 | 3s |
| 02 | WS | 场景建置 | 2.5s |
| 03 | MS | 角色进入场景 | 2.5s |
| 04 | CU | 核心细节/数据 | 2s |
| 05 | XCU | 关键转折 | 2s |
| 06 | MS | 角色反应对比 | 3s |
| 07 | POV | 主观体验镜头 | 3s |
| 08 | CU文字 | 结论大字 | 3s |
| 09 | WS | 收尾+CTA | 3s |

### 模板B：产品体验型（25s）

| 镜号 | 景别 | 内容 | 时长 |
|------|------|------|------|
| 01 | CU | 痛点场景（角色皱眉） | 2.5s |
| 02 | POV | 看到产品/工具入口 | 2s |
| 03 | CU | 操作点击 | 1.5s |
| 04 | MS | 角色表情变化（困惑→惊讶） | 2.5s |
| 05 | CU | 屏幕效果展示 | 2.5s |
| 06 | MCU | 角色满足表情 | 2.5s |
| 07 | WS | 品牌Logo+CTA | 3s |

### 模板C：故事叙事型（45s）

| 阶段 | 镜头数 | 每镜时长 | 节奏 |
|------|--------|---------|------|
| 开端（困境） | 3镜 | 4-5s | 中速 |
| 发展（转折） | 4镜 | 2-3s | 快速 |
| 高潮（解决） | 3镜 | 2.5-3s | 最快 |
| 结尾（共鸣） | 2镜 | 5-6s | 放缓 |

## 音效设计速查

| 画面类型 | 配合音效 |
|---------|---------|
| 字幕出现 | 低频打字机声/轻击 |
| 数据出现 | 电子提示音/鼓点 |
| 情绪转折 | 静音0.5s + 新BGM进 |
| 产品Logo | 品牌音效 |
| 金句停留 | 钢琴单音/弦乐减弱 |

## 结尾行动号召CTA

| 目标 | CTA文案 | 配合画面 |
|------|---------|---------|
| 关注 | "每周更新，欢迎蹲" | Logo + 账号名 |
| 评论互动 | "你的工作中，哪个环节最想交给AI？评论区聊聊" | 角色微笑+手势引导 |
| 转化 | "点击主页链接，免费体验" | 二维码/链接展示 |
| 转发 | "转发给还在加班的那个朋友" | 金句大字 |
