# 长视频分镜专项（3-30分钟）

## 核心特征

- 时长：3-30分钟
- 类型：深度分析、教程、纪录片、产品深度测评、品牌故事
- 目标：深度信息传递、体系化认知建立、情感沉浸
- 节奏：有快有慢，但整体慢于短视频，需要章节化设计

## 长视频与短视频的本质差异

| 维度 | 短视频 | 长视频 |
|------|--------|--------|
| 注意力模型 | 3秒决生死 | 每3-5分钟需要重新"钩"一次 |
| 叙事结构 | 直线型（一个问题→一个答案） | 树状/网状（多主题交织） |
| 镜头节奏 | 2-4秒/镜，高度压缩 | 3-15秒/镜，有呼吸空间 |
| 品牌植入 | 结尾集中出现 | 分散穿插，每段1处 |
| 情绪曲线 | 单峰（建置→高潮→收尾） | 多峰（多个小高潮+大高潮） |

## 章节化设计（长视频核心）

### 章节结构模板

```
[00:00-00:45] 序章 — 总钩子
[00:45-03:00] 第一章 — 背景/问题引入
[03:00-06:00] 第二章 — 核心内容A
[06:00-09:00] 第三章 — 核心内容B
[09:00-12:00] 第四章 — 深入分析/案例
[12:00-14:00] 第五章 — 结论+展望
[14:00-15:00] 尾声 — 记忆锚点+CTA
```

### 每章内部结构（Mini三幕）

每章虽然内容不同，但内部遵循相同的Mini三幕结构：

```
章开篇（1-2镜）："接下来我们要解决什么问题？" —— 小钩子
章主体（3-8镜）：展开分析/展示/讲解
章收尾（1-2镜）：小结+过渡到下一章
```

### 章间转场设计

| 转场类型 | 操作 | 使用场景 |
|---------|------|---------|
| 问题桥接 | 用"但问题是……"引出下一章 | 逻辑递进型 |
| 对比跳转 | "与此相反的是……" | 对比分析型 |
| 悬念过渡 | "而真正的答案，在下一章" | 故事驱动型 |
| 音桥过渡 | 下一章的声音提前1-2秒介入 | 流畅衔接型 |
| 黑场呼吸 | 2秒黑屏+章节标题大字 | 信息密集型（给观众消化时间） |

## 长视频镜头节奏规律

### 景别节奏曲线

长视频的景别不是均匀分布的，而是有"呼吸节奏"：

```
建置段（慢呼吸）：VLS(5s)→WS(5s)→MS(8s)→CU(3s)
   ↓
展开段（快呼吸）：MS(3s)→CU(4s)→MS(3s)→CU(2s)
   ↓
高潮段（急促）：CU(2s)→XCU(1.5s)→CU(2s)→MCU(2s)
   ↓
收尾段（深呼吸）：CU(3s)→MS(4s)→WS(5s)→VLS(6s)
```

### 镜头时长分配原则

| 内容类型 | 推荐单镜时长 | 示例 |
|---------|------------|------|
| 场景建置/环境 | 4-8s | 城市航拍、办公室全景 |
| 人物对话 | 5-10s | 专家访谈、角色对白 |
| 数据展示/图表 | 4-6s | 需要阅读时间的静态画面 |
| 过程演示 | 3-8s | 操作步骤、流程动画 |
| 情绪/空镜头 | 5-15s | 风景、角色沉思、氛围 |
| 动作/快速切换 | 2-4s | B-roll快速剪辑 |

## 多峰情绪曲线设计

长视频不能只有一个高潮（观众会中途流失）。需要设计多个"微型高潮"：

```
情绪强度
  ↑     ╱╲      ╱╲      ╱╲
  │    ╱  ╲    ╱  ╲    ╱  ╲___
  │   ╱    ╲  ╱    ╲  ╱      ╲___
  │  ╱      ╲╱      ╲╱          ╲___
  │ ╱                                  ╲___
  │╱__________________________________________→ 时间
    序章   Ch1    Ch2    Ch3   Ch4   尾声
```

每个章节末尾必须有一个"小触动"（数据反差、情感共鸣、认知刷新），作为该章的微型高潮。

## B-Roll与A-Roll配合

长视频中，A-Roll（主要讲述/访谈画面）和B-Roll（辅助素材/环境画面）的配合至关重要：

| A-Roll内容 | 配B-Roll建议 | B-Roll景别 |
|-----------|-------------|-----------|
| 讲述市场趋势 | 数据图表动画、城市航拍、办公室场景 | WS/VLS |
| 讲述个人经历 | 角色相关场景、细节特写 | CU/MS |
| 讲解技术原理 | 流程图/动画、代码屏幕、设备特写 | XCU/CU |
| 讲述案例故事 | 案例场景再现、角色反应 | MS/CU |
| 总结观点 | 自然风景、空镜头、极简构图 | WS/VLS |

### B-Roll黄金法则
- A-Roll不超过20秒就切一次B-Roll（避免"大头讲话"疲劳）
- B-Roll不是随便塞的素材——必须与A-Roll的内容有明确关联
- B-Roll用动作匹配或形态匹配剪辑衔接

## 长视频品牌植入策略

品牌在长视频中可以分散出现，每次轻触：

| 时机 | 形式 | 时长 |
|------|------|------|
| 章节2中间（自然出现） | 作为案例或工具提到 | 5-10s |
| 章节4中间（深度展开） | 功能演示/效果展示 | 8-15s |
| 结尾 | Logo+品牌主张+CTA | 5-8s |
| 可选：章节间转场 | 品牌元素作为转场动画 | 1-2s |

## 长视频分镜模板（15分钟深度分析型）

| 章 | 镜头数 | 主要景别 | 节奏 | 关键技巧 |
|----|--------|---------|------|---------|
| 序章 | 3-5镜 | CU→WS→MS | 慢→中 | 强钩子+预告全篇结构 |
| Ch1 | 8-12镜 | WS→MS→CU | 中速 | 建立背景认知 |
| Ch2 | 10-15镜 | MS↔CU交替 | 快速 | 核心数据冲击 |
| Ch3 | 12-18镜 | CU↔XCU↔MS | 快→中 | 深入案例分析 |
| Ch4 | 8-12镜 | MS→WS | 中→慢 | 对比/反思 |
| 尾声 | 3-5镜 | WS→CU→WS | 慢 | 记忆锚点+情感收束 |

## 长视频独有技法

### 伏笔与回收（跨越章节的设计）

长视频可以在早期章节埋下视觉伏笔（一个未解释的画面/物品），在后期章节回收解释。

示例：
- 序章画面闪过一张旧照片（观众注意到但不理解）
- Ch3主角翻出同一张照片并讲述其故事
- 观众获得"原来如此"的满足感

### 重复蒙太奇（李杰—表现蒙太奇）

关键意象在视频中反复出现，每次出现赋予新的含义：
- 第一次：中性出现
- 第二次：关联到问题/困境
- 第三次：成为解决方案的象征

### 平行叙事（交叉蒙太奇）

两条线索交替呈现，在结尾汇聚：
- 线索A：个人视角/情感线
- 线索B：行业/数据/分析线
- 两条线在最后章节交汇

### 慢节奏"呼吸段"

在信息密集的章节之间插入1-2个慢节奏镜头（空镜+轻音乐+无旁白），给观众情绪"呼吸"的时间。这对于15分钟以上的视频至关重要。
