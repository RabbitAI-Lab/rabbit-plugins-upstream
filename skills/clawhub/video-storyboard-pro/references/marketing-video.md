# 营销视频分镜专项（30-120秒）

## 核心特征

- 时长：30-120秒
- 目标：品牌认知、产品种草、转化引导、二次传播
- 核心挑战：不让人反感的前提下完成品牌植入
- 最高追求：看完后不光记住产品，还**愿意主动分享**

## 营销视频三大层次

| 层次 | 目标 | 衡量标准 |
|------|------|---------|
| 基础层 | 让观众知道"这是什么产品" | 看完能说出产品名和核心功能 |
| 进阶层 | 让观众产生兴趣和信任 | 产生"我也需要""值得一试"的想法 |
| 最高层 | 让观众主动传播 | 截图分享、@好友、评论区讨论 |

## 品牌植入策略（核心）

### 品牌自然融入三原则

原则1：**产品是"解决方案"而非"推销对象"**
- 错误："仙踪问道AI助手功能强大，价格实惠，快下载吧！"
- 正确：展示用户痛点 → 展示解决方案（其中产品自然出现）

原则2：**品牌出现频次1-3处，点到即止**
- 1处：视频中段的产品使用场景（1-2个短镜头）
- 2处：视频结尾Logo+CTA（不超过3秒）
- 全文不堆砌品牌名，不做硬广

原则3：**品牌与内容价值绑定而非寄生**
- 内容本身有价值 → 品牌作为"提供价值的方式"出现
- 而不是"内容只是广告的包装"，一拆开就是推销

### 品牌植入时机

| 视频阶段 | 品牌出现方式 | 时长 |
|---------|------------|------|
| 0-5s（钩子） | 不能出现品牌 | 0s |
| 5-60%（痛点/问题） | 不出现品牌 | 0s |
| 60-80%（转折/方案） | 产品自然出现——"有人/有工具解决了这个问题" | 3-5s |
| 80-95%（效果展示） | 产品使用画面——POV或屏幕录制 | 3-5s |
| 95-100%（结尾） | Logo+品牌名+CTA | 2-3s |

### 营销文案句式参考

| 场景 | 推荐句式 | 避免句式 |
|------|---------|---------|
| 引出产品 | "后来我发现了一个工具……" | "隆重推荐XX产品" |
| 介绍功能 | "它可以帮你……" | "XX产品拥有行业领先的……" |
| 效果展示 | "用了之后，我的周报变成这样——" | "经过XX产品的优化，效率提升了80%" |
| 结尾推荐 | "如果你也想试试，可以……" | "赶紧下载吧，限时优惠！" |

## 故事五要素在营销视频中的特殊应用

### 钩子：情绪痛点触发

营销视频的钩子必须触及观众的真实痛点：
- "你知道一个市场人每天花多少时间做报表吗？"
- "我昨天被裁了——不是因为能力不够。"

### 悬念：问题放大

- 展示痛点的普遍性和严重性
- "你不是一个人。76%的职场人每周花5小时以上在重复性文案上。"

### 冲突：理想VS现实

- 对比蒙太奇：手动做的痛苦 vs AI一键生成的轻松
- 左右分屏或前后对比切镜

### 转折：产品介入的瞬间

- 场景：角色从困惑/疲惫的表情 → 点击/打开产品 → 惊讶/满足
- 这个瞬间要做戏剧化的视觉处理（推镜、慢动作、特写表情变化）

### 记忆锚点：品牌金句

- 金句必须包含品牌认知：让观众记住"这句话来自XX品牌"
- 示例："把时间还给创造，让AI替你做重复的事。——仙踪问道"
- 适合截图转发的金句特征：短（≤20字）、有态度、可独立理解

## 营销视频分镜模板

### 模板：痛点→方案型（60秒经典营销视频）

| 阶段 | 镜头 | 景别 | 内容 | 品牌 | 时长 |
|------|------|------|------|------|------|
| 钩子 | 01 | CU文字 | 痛点场景（黑底白字提问） | 无 | 3s |
| | 02 | MS | 角色在痛点场景中（疲惫/困惑） | 无 | 3s |
| 放大 | 03 | CU | 问题的具体表现（屏幕/道具特写） | 无 | 2.5s |
| | 04 | WS | 环顾四周——别人也这样（群体痛点） | 无 | 3s |
| 转折 | 05 | MS | 角色"发现"的表情变化 | 无 | 2s |
| | 06 | POV→CU | 打开产品/工具的瞬间 ★品牌首次出现 | 自然（产品界面） | 3s |
| 效果 | 07 | CU | 操作过程（产品功能展示） ★品牌二次 | 功能特写 | 3s |
| | 08 | MS | 角色表情：从困惑到惊喜的转变 | 无 | 3s |
| | 09 | CU | 效果特写（完成的结果画面） | 无 | 2.5s |
| 共鸣 | 10 | MS | 角色满足微笑，环境变亮（象征变化） | 无 | 4s |
| | 11 | WS→CU推 | 从全景环境推至角色满足的表情 | 无 | 4s |
| 锚点 | 12 | CU文字 | 金句大字 ★品牌第三次出现（可选） | 品牌名+金句 | 4s |
| CTA | 13 | WS | Logo+CTA ★品牌正式露出 | 品牌标识 | 3s |

**总时长：约40-45秒**

### 高级技巧

#### 技巧1：间接揭示（Kenworthy Vol.1）

不直接展示产品，而是展示使用产品后的变化。观众的好奇心会驱动他们自己去找"用了什么"。

示例：
- 镜头1：角色对空白文档发愁
- 镜头2：（跳过产品）直接展示完成的精美周报
- 镜头3：角色满足的表情
- 镜头4：Logo出现——"想知道怎么做到的吗？"

#### 技巧2：第三者验证

引入一个"使用者推荐"的视角，比品牌自述更有说服力：
- "我们部门新来的实习生，周报比我写得好。我问了一下……"（引出产品）

#### 技巧3：静默反应（Kenworthy Vol.2）

在展示产品效果后，用3秒无对白的静默反应镜头。无语的角色满足表情比任何台词都有说服力。

## 传播性设计要素

| 传播触发点 | 设计方法 |
|-----------|---------|
| "这也太方便了" | 展示效果对比时做足视觉反差 |
| "转发给XX看" | 内容直接点名特定人群的痛点 |
| "这句话说得太对了" | 金句设计瞄准职场共鸣（而非产品吹嘘） |
| "原来可以这样" | 展示一个"反常识但有效"的方法 |
| "我也要试试" | CTA设计低成本（"免费""30秒""一键"） |

## 禁止的营销误区

- 全程硬推销（品牌名每句话都出现）
- 虚假夸大效果（"100%提升""保证""必定"）
- 恐惧营销过度（制造焦虑但无解）
- 诋毁竞品
- 虚假限时/限量（"仅剩3份"——如果没有）
