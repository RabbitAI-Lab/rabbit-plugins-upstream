## Description: <br>
Privacy-first three-role writing framework for intent discovery, draft generation, reader-style review, style cloning, SEO optimization, long-form writing, and consent-gated writing memory. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Writers, creators, students, marketers, and developers use this skill to turn writing requests into structured drafts through Creator, Executor, Reader, and Evolution Analyst roles. It supports fast drafts, multi-version drafting, style cloning, SEO-oriented public content, and long-form chapter workflows with local memory controls. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can build long-term local writing preferences, SEO history, style fingerprints, drafts, and session records. <br>
Mitigation: Use it only when local retention is acceptable, review PRIVACY.md before installing, and delete MEMORY.md, session folders, style profiles, or the knowledge base when reuse is no longer wanted. <br>
Risk: Sensitive drafts or personal style samples could be retained in local memory or session files. <br>
Mitigation: Use local privacy mode or no-web-search for sensitive drafts, avoid providing unnecessary personal data, and use the documented deletion commands or manual file deletion after the session. <br>
Risk: Optional web research can transmit search terms derived from the writing topic. <br>
Mitigation: Require explicit consent before web research, review the exact search queries, and choose offline mode when topic disclosure is not acceptable. <br>
