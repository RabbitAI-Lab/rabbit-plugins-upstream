# 网络类项目案例（网络规划设计师）

本文档为**网规**资格提供可直接复用的网络类项目案例。每个案例含网络场景、典型技术方案与量化指标，用于建立素材库。

> 网规科目允许并鼓励网络/设备/链路类项目，"纯硬件项目"在此不扣分。

---

## 案例一：集团园区网高可用规划

**项目背景**：某集团园区覆盖 3 栋研发楼 + 2 栋数据中心楼，接入终端 1.2 万台，核心业务 7×24 不间断。

**典型技术方案**：
- 三层架构：接入（VLAN/Trunk）→ 汇聚（STP 防环）→ 核心（路由）
- 冗余：VRRP 双机热备、链路聚合（LACP）、堆叠
- 路由：OSPF 多区域划分、路由汇总减少 LSA
- 安全：防火墙分区（生产/办公/访客）、ACL、VPN
- 演进：IPv6 双栈、SDN 控制器统一编排

**可量化指标**：核心带宽 40G、可用性 99.99%、故障切换 < 1s。

**可适配论题**：园区网规划、网络高可用、网络安全体系。

## 案例二：证券公司数据中心网络改造

**项目背景**：同城双活数据中心网络重构，满足低时延交易与监管合规。

**典型技术方案**：
- 大二层/Overlay（VXLAN）实现跨中心二层互通
- 低时延转发优化、ECMP 等价多路径
- 业务隔离：交易网/管理网/存储网物理或逻辑分离
- 监控：telemetry 实时采集、链路质量探测

**可量化指标**：跨中心 RTT < 2ms、可用性 99.995%。

**可适配论题**：数据中心网络、高可用设计、网络性能优化。

## 案例三：集团广域网互联（多分支）

**项目背景**：5 地园区 + 3 个数据中心互联，生产网与办公网隔离。

**典型技术方案**：
- MPLS VPN / SD-WAN 实现多站点互联
- BGP 路由策略控制、路由反射器
- QoS 保障关键业务（语音/视频/交易）
- 零信任接入、分支安全加固

**可量化指标**：互联带宽 10G、关键业务抖动 < 5ms。

**可适配论题**：广域网规划、SD-WAN、网络可靠性。

## 素材库建设建议

- 重点描述"规划与设计理由"，而非设备清单
- 协议选型必须有权衡对比（如 OSPF vs IS-IS）
- 准备带宽/时延/可用性量化数据支撑论述
