# Changelog

## 1.1.0 (2026-07-19)

- **法规依据审计**：全部 31 条规则的 `legal_source` 字段逐条核查并修正
  - 修正法规名称错误：DISC-001 原引《证券投资咨询管理暂行办法》→ 更正为《证券、期货投资咨询管理暂行办法》
  - 修正条款引用错误：REG-004 原引《未成年人保护法》第76条（网络直播专用条款）→ 更正为《未成年人网络保护条例》（2024年施行）
  - 修正条款理解错误：REG-005 原引《互联网诊疗管理办法（试行）》第4条（允许性条款）→ 更正为《医疗机构管理条例》第23条（禁止无资质行医）
  - 修正引用不完整：REG-003 新增《算法推荐管理规定》第24条备案时限
  - 补充施行日期：15 条规则的 legal_source 新增了法规公布/施行日期（如《个人信息保护法》2021年11月1日施行）
  - 补充发布机关：REG-006（双减）标注中央/国办联合印发；REG-007（代币）标注七部委联合发布
  - 新增 `sources.references` 字段，收录 18 项法规的发布日期、施行日期和发布机关信息，方便后续交叉核对
- **误报修复（第二批）**：
  - REG-003：不再把"RECOMMENDATIONS"节标题算作算法推荐
  - FIN-003：不再把"数据分析/技术分析/合规检查"等工具名算作需资质用语
- **扩展规则库**：从 19 条规则增加到 31 条规则
- **新增类别**：
  - PRIVACY — 数据隐私合规（个人信息收集声明、用户同意机制、数据出境合规），基于《个人信息保护法》
  - REGULATORY — 专项监管合规（ICP备案、AIGC标识、算法备案、未成年人保护、医疗卫生红线、虚拟资产红线、教育培训合规、等保、反不正当竞争）
- **修复**：EXA-001 对"第三方数据/服务/平台"等合规术语的误报
- **评分改进**：
  - PASS / NEEDS_FIX / REJECT 阈值调整为 ≥70 / 40–69 / <40（实际代码已采用该阈值，现在 SKILL.md 文档对齐）
  - PRIVACY/REGULATORY 交叉建议集成到 check_recommendations
  - redline 一票否决制在评分和结论中明确体现
- **新增子命令**：check 全面检查现涵盖 PRIVACY 和 REGULATORY 扫描

## 1.0.0 (2026-07-19)

- 初始发布
- 五大检查模块：
  - FINANCE — 敏感金融用语检查（荐股/投资建议/保证收益/需资质用语）
  - DISCLAIMER — 免责声明检查（投资/法律声明位置与内容）
  - EXAGGERATION — 极限词与夸大描述检查
  - SECURITY — 安全红线（subprocess/exec/eval/JSON/版本号）
  - RECOMMENDATIONS — 改进建议
- 四个子命令：check / disclaimer / keywords / summary
- 文本和 JSON 两种输出格式
- 综合评分系统（0–100）与评估结论（PASS / NEEDS_FIX / REJECT）
- 批量扫描多 skill 目录并排序
- 纯 Python 标准库，零外部依赖，无网络请求
