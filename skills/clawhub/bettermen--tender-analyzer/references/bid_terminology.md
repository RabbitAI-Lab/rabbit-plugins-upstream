# 招投标领域专业术语词典

## 基础概念

| 术语 | 英文 | 定义 |
|------|------|------|
| 招标 | Tendering | 采购人发布采购需求，邀请供应商参与竞争的程序 |
| 投标 | Bidding | 供应商响应招标要求，提交报价和方案的行为 |
| 开标 | Bid Opening | 在规定时间和地点公开开启投标文件 |
| 评标 | Bid Evaluation | 评审专家按照评分标准对投标文件进行评审 |
| 定标 | Award of Contract | 确定中标供应商 |
| 中标 | Winning Bid | 被确定为合同签约对象 |

## 文件类型

| 术语 | 定义 |
|------|------|
| 招标文件 | 采购人发布的包含采购需求、投标人须知、评标办法等的完整文件 |
| 投标文件 | 投标人按照招标文件要求编制的响应文件 |
| 技术标 | 投标文件中关于技术方案的部分 |
| 商务标 | 投标文件中关于报价和商务条件的部分 |
| 资格预审文件 | 用于筛选合格投标人的前置审查文件 |

## 评标相关

| 术语 | 定义 |
|------|------|
| 评标委员会 | 由招标人代表和专家组成的评标决策机构 |
| 评分标准 | 对投标文件进行量化评审的指标和规则 |
| ★条款 / 实质性要求 | 不允许偏离的核心条款，不满足即无效投标 |
| 废标 | 投标文件被判定无效 |
| 流标 | 有效投标人不足3家导致招标失败 |
| 偏离表 | 投标人对招标文件要求的偏离情况说明 |
| 澄清 | 评标过程中对投标文件不明确之处的说明 |

## 报价相关

| 术语 | 定义 |
|------|------|
| 投标报价 | 投标人提出的合同价格 |
| 评标基准价 | 用于价格评分的参考价格 |
| 最高限价 | 招标文件规定的报价上限 |
| 低于成本价 | 报价低于合理成本(可能被否决) |
| 不平衡报价 | 总价正常但分项报价严重失衡 |

## 法律合规

| 术语 | 定义 |
|------|------|
| 围标 | 投标人之间串通操纵投标结果(违法行为) |
| 串标 | 投标人与招标人/代理机构串通(违法行为) |
| 挂靠 | 借用他人资质投标(违规行为) |
| 履约保证金 | 中标后为保证履约缴纳的保证金 |
| 质保金 | 质保期满前暂扣的部分款项 |

## 项目管理

| 术语 | 定义 |
|------|------|
| 里程碑 | 项目关键节点 |
| 交付物 | 按照合同应提交的产品/服务/文件 |
| SLA | 服务水平协议(Service Level Agreement) |
| 验收 | 对交付物是否满足合同要求的确认 |
| 变更管理 | 对项目范围/需求变化的管控流程 |
