# 招标评分办法参考标准

## 一、综合评分法 (最常见)

### 概述
综合评分法是指在满足招标文件实质性要求的前提下，按照招标文件中规定的各项评价因素进行综合评审，以评标总得分最高的投标人作为中标候选人的评标方法。

### 评分结构模板

```
总分100分 = 价格分(30-40分) + 技术分(30-50分) + 商务分(10-20分) + 其他(0-10分)
```

### 价格分计算公式

#### 1. 基准价法
```
偏差率 = (投标报价 - 评标基准价) / 评标基准价 × 100%

评标基准价计算方式:
- 方式A: 有效报价算术平均值
- 方式B: 有效报价算术平均值 × K% (K通常为95-98)
- 方式C: 最低价与平均价的加权组合

得分 = 满分 - |偏差率| × 扣分系数
扣分系数: 每偏离1%扣1-2分
```

#### 2. 低价优先法
```
得分 = (最低投标价 / 投标报价) × 价格分满分
```

### 技术分评分子项

| 子项 | 典型分值 | 评审要点 |
|------|----------|----------|
| 技术方案 | 15-20分 | 完整性、合理性、先进性 |
| 技术参数 | 10-15分 | 参数符合度、超标加分 |
| 实施方案 | 5-10分 | 进度、资源、风险管控 |
| 项目团队 | 3-5分 | 人员资质和经验 |
| 培训与售后 | 2-5分 | 培训计划、服务承诺 |

### 商务分评分子项

| 子项 | 典型分值 | 评审要点 |
|------|----------|----------|
| 企业业绩 | 5-10分 | 类似项目数量与金额 |
| 企业资质 | 3-5分 | 资质等级和种类 |
| 财务状况 | 2-3分 | 审计报告、营收规模 |
| 信誉评价 | 1-2分 | 客户评价、获奖情况 |

---

## 二、最低评标价法

### 概述
在满足招标文件实质性要求的前提下，以经评审的最低投标价作为中标条件。

### 评审流程
1. 资格审查: 不满足资格的直接淘汰
2. 符合性审查: 不满足实质性条款的淘汰
3. 价格评审: 修正计算错误后按价格排序
4. 最低价中标 (如有价格相同则按技术/业绩排序)

---

## 三、性价比法

### 概述
综合考虑技术/商务得分与报价的比值。

### 计算公式
```
性价比 = 技术商务总得分 / 投标报价
性价比最高者中标
```

---

## 四、两阶段评标法

### 阶段一: 技术方案评审
- 匿名评审技术方案(不含报价)
- 技术分达标者进入第二阶段

### 阶段二: 商务报价评审
- 开启商务标(含报价)
- 综合技术+商务得分确定中标

## 五、评审等级标准

| 等级 | 分数区间 | 说明 | 竞争力 |
|------|----------|------|--------|
| S | 95-100 | 卓越，所有方面均超额满足 | 极强 |
| A | 85-94 | 优秀，关键项均为高分 | 强 |
| B | 75-84 | 良好，基本满足要求 | 中等 |
| C | 65-74 | 合格，存在明显不足 | 较弱 |
| D | 55-64 | 较差，多项不达标 | 弱 |
| F | <55 | 不通过，可能存在废标风险 | 极弱 |

## 六、常见扣分项对照表

| 扣分项 | 常见扣分 | 严重程度 |
|--------|----------|----------|
| 技术方案不完整 | 3-8分 | 高 |
| 技术参数偏差 | 1-3分/项 | 中 |
| 报价高于基准价 | 0.5-2分/1% | 取决于偏离度 |
| 缺少关键人员 | 2-5分 | 高 |
| 业绩案例不足 | 2-5分 | 中 |
| 质保期不够 | 1-3分 | 中 |
| 培训方案缺失 | 1-3分 | 低 |
| 未响应★条款 | 直接废标 | 致命 |
| 格式不符合要求 | 1-2分 | 低 |
| 缺少签字盖章 | 直接废标 | 致命 |
