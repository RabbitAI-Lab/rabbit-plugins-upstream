# 中文学术写作风格指南

本 Skill 的改写依据。对照时引用条目编号（如 §1.2）。

## 1. 论著体（去口语化）

### §1.1 避免口语动词
| 口语 | 论著体 |
|---|---|
| 做了一个实验 | 设计/实施实验 |
| 看看…会不会 | 考察/检验…是否 |
| 搞 / 弄 | 构建 / 建立 |
| 用了 | 采用 / 使用 |

### §1.2 第一人称
- 避免"我""我们觉得"；用"本文""笔者""本研究"。
- "大家""很多人"→"研究者""既有研究"。

### §1.3 主观评价词
- "挺好的""还行""不错"→ 给出可操作化指标（显著提升 / 相关显著 / 达到 X）。
- "非常重要"→ 在结果章用数据支撑，在讨论章限定条件。

### §1.4 连接词
- "说白了""其实就是""然后然后"→"换言之""即""继而""进而"。
- 句首"还有""还有一点"→"此外""进一步地"。

## 2. 简洁性

### §2.1 去冗余
- "进行了一个…的实验"→"实验…"。
- "在一定程度上起到了一定的作用"→"部分有效"。
- "由于…的原因"→"由于…/因为…"。

### §2.2 长句拆分
单句超 50 字且含 3 层以上定语时，拆为 2–3 短句，主语前置。

## 3. 术语一致

### §3.1 锁定
全文同一概念统一术语，不混用（如不"句法启动/句法 priming/结构启动"三词混用）。首次出现给全称 + 英文/缩写，后文用简称。

### §3.2 缩写规则
首次出现写"中文全称（English Full Name, 缩写）"，后文只用缩写。摘要与正文各自独立首次定义。

## 4. 引文格式（GB/T 7714-2015，著者-出版年制）

### §4.1 正文夹注
- 单作者：(张三, 2020)
- 双作者：(张三, 李四, 2020)
- 三作者及以上：(张三等, 2020)
- 引具体页：(张三, 2020, p. 15)

### §4.2 文末参考文献
- 期刊：作者. 文献题名[J]. 刊名, 年, 卷(期): 起止页.
- 专著：作者. 书名[M]. 版次. 出版地: 出版者, 年: 页.
- 学位论文：作者. 题名[D]. 保存地: 保存单位, 年.

## 5. 事实与数据（不改）

### §5.1 标【待核】
原文出现但存疑的数字、样本量、p 值、引文年份，一律标【待核】交还作者核对，不在润色环节擅自修改或补全。
