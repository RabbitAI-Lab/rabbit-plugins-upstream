## Description:

Turns scripts into storyboarded, shot-by-shot videos through dLazy's hosted storyboard workflow.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to turn scripts or scene outlines into storyboarded, multi-shot videos with dLazy's hosted service.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and options are sent to dLazy, and attached files are uploaded to its storage.

Mitigation: Only submit prompts and files you are comfortable sharing with dLazy.

Risk: Login may save a dLazy API key in local CLI configuration.

Mitigation: Use a per-invocation API key when local storage is unsuitable; rotate or revoke keys if needed.
