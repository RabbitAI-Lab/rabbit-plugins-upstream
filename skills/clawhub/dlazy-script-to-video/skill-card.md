## Description:

Turns a script or scene breakdown into a storyboarded, shot-by-shot video by breaking down scenes, generating shots, assembling them, and validating the result.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers can use this skill to turn a screenplay or scene breakdown into a multi-shot animated short, with storyboarded shots, audio, subtitles, and a rendered video. It communicates with dLazy's hosted agent through the CLI and can upload attached reference files.

### Deployment Geography for Use:

Global
