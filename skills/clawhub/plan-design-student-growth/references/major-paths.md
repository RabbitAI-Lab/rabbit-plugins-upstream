# 专业与软件路线

以下顺序来自灵加教育公开课程体系的能力结构。它用于规划前置关系，不代表必须购买课程或学习全部软件。

## 主专业路线

| 专业方向 | 推荐能力顺序 | 典型项目出口 |
| --- | --- | --- |
| 平面/视觉传达 | PS 图像基础 -> Illustrator/AI 矢量与字体 -> 版式、品牌、包装 -> AE 动效 -> C4D 三维表达 -> AIGC 辅助探索 | 海报、画册、VI、包装、动态海报、IP 视觉 |
| 产品设计 | PS 表达 -> Rhino 建模 -> Keyshot 渲染 -> CAD 三视图 -> SubD/C4D 进阶 -> Illustrator/AI 排版 -> AIGC 概念辅助 | 电子产品、家具、穿戴产品、参数化或竞赛方案 |
| 环艺/室内 | CAD 图纸 -> PS 彩平与后期 -> 3Dmax 建模 -> V-Ray/Corona 渲染 -> SU/Enscape 场景 -> 施工图与材料 -> Illustrator/AI 展板 -> AIGC 概念辅助 | 住宅、工装、景观节点、施工图、空间展示 |
| 建筑景观 | CAD 总平 -> SU 建模 -> D5/实时渲染 -> PS 分析图与后期 -> Rhino 曲面 -> Illustrator/AI 展板 -> AIGC 概念辅助 | 公园、广场、建筑、异形构筑、分析图与竞赛展板 |
| 数字媒体 | PS 视觉基础 -> PR 剪辑 -> AE 合成/MG -> C4D 建模 -> Octane/OC 渲染 -> Illustrator/AI 排版 -> AIGC 辅助 | 短片、MG 动画、栏目包装、电商三维场景、潮玩 IP、动效 |

## 补充方向

- **插画**：先建立造型、构图和色彩，再用 PS 或 Illustrator/AI 完成角色、场景或系列主题；以系列作品而非零散临摹作为出口。
- **影视后期**：按 PS/视觉基础 -> PR 剪辑 -> AE 合成与特效 -> C4D 三维 -> 综合短片的顺序推进。
- **BIM**：先补 CAD 和工程图纸理解，再根据目标院校或岗位确认 BIM 建模、协同和出图软件栈；不要在未确认目标时承诺具体软件组合。
- **UI/交互**：先补版式、色彩、图标和信息层级，再进入界面、交互流程和原型；现有知识快照颗粒度较低，输出时标明为初步路线。

## 选软件规则

1. 先确定要交付的作品类型，再选最少工具组合。
2. 同类工具只选一个主工具，除非目标岗位或学校明确要求另一个。
3. 二维表达、三维表达和展示排版各形成一个闭环后，再增加高级插件。
4. AIGC 用于调研、发散、草图和变体，不替代设计判断、规范图纸和项目论证。
5. 设备性能不足时，先用轻量工具完成设计逻辑和表达，不把硬件不足误判为能力不足。

## 方向探索任务

用户无法确定专业时，为每个候选方向设计一个 2-4 小时的低成本任务：

- 平面/视传：为一个校园活动制作海报和两种版式变体。
- 产品：选择日常用品，画出问题、改进草图和一个简单三维或纸模。
- 环艺/室内：重构一个小空间，输出平面布局和一张氛围表达。
- 建筑景观：分析一个公共空间，输出场地问题图和概念总平草图。
- 数媒：用现有素材剪一段 20-30 秒短片或制作一个简单动效。

比较投入感、理解速度、修改意愿和成品满意度，再决定下一轮体验，不根据一次任务直接给出终身职业结论。
