# 07 网络安全体系与文档

> 用途：回答「ISO 81001-5-1 是什么」「和 13485/62304 怎么联动」「申报文档有哪些」。
> 核对基准日：2026-08-27

## 1. ISO/IEC 81001-5-1（产品网络安全工程）

**医械网络安全核心标准**（健康软件与健康 IT 安全、保密、可用性工程框架）：
- 全生命周期网络安全工程（设计→开发→上市→退役）；
- 威胁建模、安全需求、验证、漏洞管理；
- 与 IEC 62304（软件生命周期）、ISO 14971（风险管理）协同。

## 2. 标准联动图

```
ISO 14971 风险管理（总纲）
   ├── IEC 62304 软件生命周期（开发过程）
   ├── ISO/IEC 81001-5-1 网络安全工程（安全贯穿）
   ├── ISO 13485 质量体系（管理保障）
   └── ISO/IEC 27001 组织信息安全（组织层面）
```

**关系**：网络安全不是孤立标准——嵌在风险管理与质量体系里。

## 3. 网络安全文档体系（申报与体系）

| 文档 | 阶段 | 内容 |
|---|---|---|
| 网络安全计划 | 设计 | 目标、范围、资源 |
| 威胁模型 | 设计 | 攻击面、威胁、缓解 |
| 安全需求规格 | 开发 | 功能/安全需求 |
| SBOM | 开发 | 组件清单（05 模块） |
| 安全测试报告 | 验证 | 渗透/模糊/扫描 |
| 漏洞管理计划 | 上市前 | 分级、修复、披露 |
| 上市后监控计划 | 上市 | 漏洞监测、补丁分发 |
| 网络安全描述文档 | 申报 | 随注册提交（NMPA） |

## 4. 上市后网络安全监控

- 持续漏洞扫描（SBOM 联动）；
- 威胁情报跟踪；
- 补丁发布与分发（OTA 安全）；
- 安全事件响应（与不良事件报告衔接）；
- 定期网络安全评审（PSUR/年度）。
