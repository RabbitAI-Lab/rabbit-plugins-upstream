## Description:

Designs, edits, and verifies EasyEDA Pro schematics and PCBs using component data and project readback.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zhoushoujianwork](https://clawhub.ai/user/zhoushoujianwork)

### License/Terms of Use:

MIT

## Use Case:

Electronics developers and engineers use the skill to create or refine EasyEDA Pro projects, then check schematic connectivity, PCB geometry, design rules, and saved results.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security assessment reports an unverified installer that runs a downloaded script, weaknesses in design-editing and verification workflows, and incomplete scan coverage.

Mitigation: Follow the security guidance: consider avoiding installation until the installer is independently verified and the reported weaknesses and coverage gaps have been reviewed.
