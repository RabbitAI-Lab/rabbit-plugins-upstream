# GitHub 问题分诊与待办检查

[English](README.md)

分析单仓库导出的 Issue 与 PR，找出无人认领、长期未更新和标题相似项，生成待分诊清单，不修改远端。

## 能做什么

分析单仓库导出的 Issue 与 PR，找出无人认领、长期未更新和标题相似项，生成待分诊清单，不修改远端。

```text
检查这个仓库导出的 Issues，列出长期没人处理的问题。
```

```text

```

```text
检查这些问题标题是否相似，先给我候选清单，不自动关闭。
```

## 运行方式与边界

Python 3.10+，仅标准库。处理当前助手工作区内选定的资料，报告保存到新目录。

读取单仓库导出的 JSON；可配合已授权的 gh CLI 获取，不自动发评论、改标签或关闭问题。
