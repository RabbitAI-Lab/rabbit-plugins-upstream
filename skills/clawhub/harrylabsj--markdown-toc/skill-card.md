## Description: <br>
Generate a Table of Contents (TOC) from Markdown headings. Supports heading extraction, multiple output formats, and configurable level filtering. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[harrylabsj](https://clawhub.ai/user/harrylabsj) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, writers, and documentation maintainers use this skill to generate Markdown tables of contents from document headings, including filtered heading levels and optional anchor links. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Using the output option can write or overwrite the path provided by the user. <br>
Mitigation: Review the requested output path before running with -o or --output. <br>
