## Description:

Guides behavior-preserving frontend refactoring of variable meaning, field names, derived state, and reference/value identity in JavaScript, TypeScript, React, and Vue.

This skill is ready for commercial/non-commercial use.

## Publisher:

[bovinphang](https://clawhub.ai/user/bovinphang)

### License/Terms of Use:

MIT-0

## Use Case:

Frontend developers use this skill to make small, behavior-preserving data refactorings and check public contracts, UI behavior, and state identity after each change.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Refactoring can unintentionally change public contracts, UI behavior, or state identity.

Mitigation: Review each diff, preserve external mappings, and run relevant tests after each small step.
