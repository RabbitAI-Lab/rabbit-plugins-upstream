## Description:

Generate a table of contents (TOC) for a Markdown file by extracting its headers.

This skill is ready for commercial/non-commercial use.

## Publisher:

[terrycarter1985](https://clawhub.ai/user/terrycarter1985)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and technical writers use this skill to generate, update, or insert a Markdown table of contents from a document's headings.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may be used to edit a user-selected Markdown document when inserting a generated table of contents.

Mitigation: Review the edited document before committing or publishing changes.
