# project-planner

OpenClaw 项目规划与执行管理 Skill。

## 功能

- 项目初始化
- 目标与成功标准定义
- WBS 任务拆解
- 任务优先级与依赖
- 时间排期
- 项目进度追踪
- 延期自动重排
- 每日任务生成
- 风险识别
- 项目复盘
- 学业 / 研究 / 工作 / 创作 / 活动项目模式

## 安装

将 `project-planner` 文件夹放入 OpenClaw 的 skills 目录，或按你的 OpenClaw/ClawHub 工作流进行安装。

## 使用示例

> 帮我规划一个两周内完成的心理学课程PPT。

> 我已经完成资料搜集，更新一下项目进度。

> 这个项目延期了一天，帮我重新排期。

> 我今天只有1小时，我应该做什么？

> 项目完成了，帮我复盘。

## 设计理念

该 Skill 将“项目规划”和“项目执行”区分开：Project Planner 负责拆解、排期、追踪与调整；实际写作、检索、制作文件等工作可交给其他专业 Skill。
