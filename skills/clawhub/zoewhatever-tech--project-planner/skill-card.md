## Description:

项目规划与执行管理助手，将模糊项目目标转化为交付物、WBS任务、依赖关系、优先级、时间计划、风险清单和每日行动，并随进度变化更新计划、处理延期和支持复盘。

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and teams use this Chinese-language skill to turn school, research, work, creative, activity, and personal projects into actionable plans with milestones, WBS tasks, schedules, progress updates, risk checks, daily next actions, and retrospectives.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Project details may be stored or shared if the agent uses available file, calendar, reminder, web search, or other-agent tools.

Mitigation: Review what details will be stored or shared and approve those actions explicitly before allowing the skill to use those tools.

Risk: Plans may rely on assumptions when deadlines, available time, current progress, or hard requirements are missing.

Mitigation: Treat assumptions as provisional, confirm the key constraints, and update the plan as real project status changes.
