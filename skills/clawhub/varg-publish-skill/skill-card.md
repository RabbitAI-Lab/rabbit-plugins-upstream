## Description:

Turns an agent skill folder or repository into a Varg how-to listing and submits it for review after showing the card to the user.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT

## Use Case:

Developers and other skill authors use it to prepare a Varg how-to listing from a skill folder or repository and submit it for review. The skill shows the completed card to the person before publishing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The scan noted a search capability alongside the stated publishing purpose.

Mitigation: Use the skill when listing discovery as well as publishing is appropriate, and review the card before submission.

Risk: The skill uses unpinned tool references and the Varg API, which involves an external service.

Mitigation: Review the referenced tools and confirm you are comfortable using Varg and its account credentials before publishing.

Risk: The security scan was partial because one local reference could not be resolved.

Mitigation: Review the unresolved reference and available scan guidance before installing.
