## Description:

Prepares a varg how to listing from an agent skill, checks it against varg's media skill standard, and submits it for review after the user approves the exact card.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and skill publishers use this to prepare a varg how to catalog listing for an agent skill, check it against the catalog standard, and submit it for review after approving the exact card.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Submitting a listing makes skill details public and uses the user's varg account credentials.

Mitigation: Review the exact card, source link, and example media, and approve publication before submission.
