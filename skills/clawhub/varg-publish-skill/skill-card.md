## Description:

Turns a skill folder or repository into a varg how to listing, checks it against the varg media skill standard, prepares the listing card, and submits it for review after the person approves it.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

## Use Case:

Developers and skill publishers use it to prepare a varg how to listing from a skill folder or repository and submit the approved listing for review.
