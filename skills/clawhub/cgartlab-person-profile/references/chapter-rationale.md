# Chapter Rationale / 11 节结构的设计逻辑

本文件解释**为什么是这 11 节**、**为什么顺序是这个**。SKILL.md 讲的是「什么」，本文件讲的是「为什么」。

## 完整结构

1. 执行摘要
2. 关系网络
3. 时间线与主要作品/言论
4. 核心价值观
5. 思维模式
6. 方法论
7. 创作如何变成影响
8. 争议与风险点
9. 可信度与信息差异
10. 可操作建议
11. 主要参考来源

## 每节的深层逻辑

### 1. 执行摘要

**回答**：这个人是谁、值得学什么。

**为什么放第一**：读者打开档案的第一秒就要知道档案主旨。不写执行摘要，读者得读完整个档案才能提炼主旨，效率太低。

**写作要求**：
- 3 段左右
- 身份与成就（他是谁）
- 核心主张（他主张什么）
- 为什么值得学（对读者的价值）

**长度锚点**：Dan Koe 执行摘要 5 段，阮一峰 4 段。都在这区间内。

### 2. 关系网络

**回答**：他与谁有关、这些关联是"真事件"还是"概念对照"。

**为什么放第二（在时间线之前）**：关系网络是**结构性事实**，时间线是**过程性事实**。决策依据先给结构再给过程，读者有全局视角。

**6 类关系**：真实事件 / 合作 / 争议对照 / 同期 / 概念对照 / 无可核实交集。

**关键点**：
- **概念对照必须写清「无事实交集」**——防止日后被误传为影响关系
- **无可核实交集也是必要结论**——否定结论同样要写，因为二手文章最爱往空白处填「影响」

### 3. 时间线与主要作品/言论

**回答**：他在什么时候做了什么。

**格式**：表格（时间 / 事件 / 核心观点 / 来源与可信度）。

**规则**：
- 同一事实有两说（如年份、出版社），**并列写明**，不择一
- 争议性定性判断**不放在这里**，交给「争议与风险点」章节
- 时间线只放可核实的事件

**长度锚点**：≥ 20 条事件，覆盖从开始到最近的完整周期。

### 4. 核心价值观

**回答**：他相信什么。

**格式**：每段以**加粗的判断句**开头，写立场不写描述。

**关键规则**：
- 至少 1 条具体、可被反驳的判断
- 每条判断后必须做反例审查
- 反例只能取自档案已有材料，不许联网现找

**为什么要"可反驳"**：不可反驳的判断是描述不是立场。"他相信长期主义"是描述。"长期主义的价值在于让方法论成为可复用的产品，而非短期的流量"是立场。

### 5. 思维模式

**回答**：他怎么想问题、怎么下判断。

**写作要求**：用他自己的话与做法举证，不是分析者的解读。

**与"核心价值观"的区别**：
- 价值观：**相信什么**（Belief）
- 思维模式：**怎么想**（Thinking process）
- 方法论：**怎么做**（Doing）

### 6. 方法论

**回答**：可迁移的具体做法。

**格式**：编号或分段均可，动词开头。

**关键**：写"他做了什么"，不写"他主张什么"。方法论是可操作的动作，不是主张。

### 7. 创作如何变成影响

**回答**：作品 → 传播 → 变现或扩散的路径。

**可以用 mermaid 画流程图**。

**关键禁词**：**不写「闭环」**（这是商业黑话）。写清楚每一环具体是什么。

**范例结构**：
- 每一环：动作 + 时间 + 结果
- 明确区分「影响力扩散」和「个人商业变现」两条路径

### 8. 争议与风险点

**回答**：有据可查的争议、批评、失败。

**规则**：
- 只写有据可查的争议
- 同时写明**各方立场**
- 涉个人指控：只写法院或机构的结论，不渲染，不替任何一方下判断
- 搜索后查无实据的常见说法，可以列出来并注明「未获证实」

**为什么必须写**：不写争议，档案就变粉丝向内容。老板要的是决策依据，不是宣传稿。

### 9. 可信度与信息差异

**回答**：来源可信度、本次未能取得的来源、待核实清单。

**必须包含**：
- 5 级分级清单（哪些是 ①、哪些是 ②…）
- 本次未能取得的来源（逐条写明原因）
- 待核实清单
- 本档的引用标准（如"机构自述只作立场用"）

**关键点**：**不能只写"待核实"，必须写清为什么查不到**。

### 10. 可操作建议

**回答**：读者今天能做的具体动作。

**格式**：5 条左右，每条以**加粗的动词短语**开头。

**关键**：每条建议必须挂到档案里已经出现的具体证据或作品，不凭空发明。

### 11. 主要参考来源

**回答**：所有 URL 汇总，附可信度分级和访问日期。

**格式**：
```
- （来源名称）（可点开核验的 URL）（访问日期，可信度：高／中／低）
```

**规则**：
- 至少 10 条
- 每条必须附实际访问到的 URL
- 抓不到的写「未取得」，不能省

## 顺序设计的核心逻辑

### 前 3 节：全景 → 关联 → 时序

- **执行摘要**：读者第一眼知道档案主旨
- **关系网络**：读者知道档案里哪些人值得关注
- **时间线**：读者按时间了解他做了什么

这三节构成"外部事实"。

### 中间 3 节：从内到外的抽象递减

- **核心价值观**：他相信什么（最抽象）
- **思维模式**：他怎么想（次抽象）
- **方法论**：他怎么做（最具体）

这三节构成"内部机制"。

### 后 5 节：从影响承认到读者行动

- **创作如何变成影响**：他怎么做到这些的
- **争议与风险点**：承认边界
- **可信度与信息差异**：交代来源可信度
- **可操作建议**：读者能做什么
- **主要参考来源**：证据入口

## 常见错误

1. **把时间线放第一** → 决策依据变叙事
2. **把关系网络放最后** → 读者不知道档案里哪些人是重点
3. **缺「创作如何变成影响」** → 档案无法回答"怎么学"
4. **争议章节只写正面** → 档案变宣传稿
5. **可信度章节空写** → 档案失去自我证伪能力
6. **可操作建议凭空发明** → 挂不到档案证据上，读者不知道从哪来的

## 与 15 条硬规矩的关系

11 节结构定义「档案应该包含什么」；15 条硬规矩定义「写作时应该怎么做」。两者互补：结构是容器，规矩是纪律。
