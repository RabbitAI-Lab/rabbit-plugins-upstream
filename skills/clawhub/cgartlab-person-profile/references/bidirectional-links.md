# Bidirectional Links / 关系网络双向链规范

本文件定义档案之间的关系网络规则。

## 为什么必须双向？

**单向链会漂移**。A 档案链到 B，B 档案不链回 A，一段时间后：

- 有人读到 A 里"B 影响了 A"，去查 B 档案，发现 B 档案里没有 A
- 有人读到 B 里"A 是同期人物"，去查 A 档案，发现 A 档案里根本没 B
- 时间一长，档案之间的关联变得不可追溯

**双向链的代价**：每次新增档案，都要扫描全库补链。但收益是**档案库成为一个真正互联的知识网络**，而不是一堆孤立的传记。

## 6 类关系

### 1. 真实事件（真实事件）

有具体可核实的事件。

**判定标准**：能找到具体日期、地点、参与者、可核验的来源。

**范例**：
> - **[[李笑来]]｜真实事件（作品关联，非合作）**。阮一峰在 2016-05《要聊天，先付费》里引用了李笑来的付费社群作为"付费聊天"的案例（"李笑来老师众筹他的新书，每份金额 2555 元"）。

### 2. 合作（合作）

有具体合作产出。

**判定标准**：合著作品、共同项目、明确的合作关系。

**范例**：
> - **[[史蒂夫·乔布斯]]｜合作（产品设计）**。蒂姆·库克是乔布斯之后的 CEO，负责执行乔布斯的产品愿景。

### 3. 争议对照（争议对照）

彼此公开评论或对立。

**判定标准**：双方有可核实的公开立场表达，且立场对立。

**范例**：
> - **[[XX]]｜争议对照（付费社群模式）**。X 主张 A，Y 明确反对 A。

### 4. 同期（同期）

同一时代但无交集。

**判定标准**：活跃期重叠，但查不到任何直接交流。

**范例**：
> - **[[XX]]｜同期（无交集）**。两人活跃期重叠，但查不到任何直接交流。

### 5. 概念对照（概念对照）

方法 / 立场可并置。**必须写清「无事实交集」**。

**判定标准**：两人在某个方法论上有相似或对立，但**没有事实交集**（不是合作也不是争议）。

**关键点**：这类关联最容易被二手文章编成「影响」，读时必须回到双方出处。

**范例**：
> - **[[Ali Abdaal]]｜概念对照（写作即变现的路径相似）**。两人都是从"专业身份"跨到"内容创作者"，都靠写作变现且都有一套方法论。**未核到两人有直接交流或互评记录**。

### 6. 无可核实交集（无可核实交集）

明确否定结论，防止日后被误传。

**判定标准**：本次检索范围内没找到任何交集。

**关键点**：**否定结论同样要写**——二手文章最爱往空白处填「影响」，主动写"未核到"能阻止误传。

**范例**：
> - **[[Dan Koe]]｜无可核实交集（跨语言概念对照）**。两人在英文/中文创作者经济里的位置可并置，但**未在任何公开来源检索到阮一峰提及 Dan Koe**（本次检索范围：阮一峰博客全文检索、weekly README、Twitter/X @ruanyf 时间线）。属于跨语言概念对照。

## 补链操作规范

### 步骤 1：扫描全库

新增档案 A 后，扫描全库找：
- A 在时间线里出现过的其他人物
- A 档案引用的其他人物档案
- 其他档案引用过的 A

### 步骤 2：判断链什么类型

- **真事件 / 合作 / 争议对照** → 必须链
- **概念对照 / 同期 / 无可核实交集** → 可以链
- **完全无关** → 不链

### 步骤 3：追加条目

在对方档案「关系网络」章节末尾追加：

```
- **[[A]]｜类型（说明）。** 一段说明文字。
```

**格式要点**：
- 条目以加粗的人名 wikilink 开头
- 类型后括号里写关系的具体形式
- 冒号（这里是中文全角句点）之后是说明
- 一段说明文字，写清事件 / 时间 / 出处 / 判断依据

### 步骤 4：对方档案没有「关系网络」章节

历史原因，部分老档案可能没有「关系网络」章节。

处理：
1. 按模板格式新建整节（位置在执行摘要之后，时间线之前）
2. 先补 A 档案相关人物的双向链
3. 再补其他「同赛道」人物的概念对照链（至少 3-5 条）

### 步骤 5：验证双向链完整性

用校验脚本检查：

```bash
python scripts/check_bidirectional.py <library-root>
```

脚本会列出所有单向链（A 链到 B 但 B 没链回 A），老板需要决定是补还是撤。

## 常见错误

1. **凭空制造合作** → 查不到就写"无可核实交集"，不硬凑合作
2. **单向链不补回** → 违反双向链原则
3. **概念对照不写「无事实交集」** → 后续容易被误传为影响
4. **争议对照只写一方立场** → 必须双方立场并列
5. **同类关联重复写** → 一份档案里同一个关联人物只出现一次
6. **补链时改动对方档案原有内容** → 只在末尾追加，不动原有内容

## 判断边界案例

### 案例 1：档案里提到某人是同期人物

**判断**：写「同期（无交集）」还是「概念对照（无事实交集）」？

- 如果两人在**方法或立场上可并置** → 概念对照
- 如果只是**时代重叠**但没有可并置的方法 → 同期

### 案例 2：对方没有主动提及 A

**判断**：能不能写「概念对照」？

- 可以。**关键**是说明「无事实交集」，不能写成「A 影响了对方」

### 案例 3：A 在某篇文章里评价了 B

**判断**：真事件还是争议对照？

- 如果**只是提及**（如引用其观点） → 真实事件（引用非合作）
- 如果**明确评论或批评** → 争议对照

### 案例 4：老板说"这俩人有关"但查不到证据

**判断**：写什么？

- 写「无可核实交集」，并说明检索范围
- 如果老板有内部信息，让老板补充细节，不凭空造

## Pitfalls

1. **把概念对照写成"影响"** → 违反档案纪律
2. **补链时改动原有内容** → 只在末尾追加
3. **同一人写多次** → 一份档案里同一个关联人物只出现一次
4. **不写「未核到」** → 否定结论也要写
5. **争议对照只写一方立场** → 双方立场并列
6. **对方档案没关系网络章节就不管** → 主动新建整节
