# Evidence Grading / 5 级证据分级

本文件详解为什么用 5 级而不是常见的 3 级，以及每级的适用场景。

## 5 级分类

| 级别 | 定义 | 典型来源 | 使用规则 |
|---|---|---|---|
| **① 可靠事实** | 可独立复核的客观事实 | 官方数据库、机构公告、法院判决、可交叉验证的公开数据 | 可直接引用为事实 |
| **② 机构自述** | 主体自己发表的陈述 | 本人博客、官网、GitHub、公开演讲、访谈自述 | 只作立场证据，不作事实用 |
| **③ 旁人回忆** | 第三方视角的陈述 | 媒体报道、他人博客、访谈中被访者 | 可能带立场偏差，标注偏差可能 |
| **④ 作者推断** | 基于证据的合理推断 | 档案作者基于多项证据的判断 | 必须明标「推断」，且列出所依据的证据 |
| **⑤ 未知** | 本次未取得 | 无 | 标「未取得」，写清为什么未取得 |

## 为什么不用 3 级？

**3 级方案**：可靠 / 中等 / 不可靠。

**问题**：机构自述（本人博客）通常归到"中等"，但机构自述 ≠ 中等可靠的事实。它可能是：
- 精确的自述（如"我 2014 年在 X 公司"，可交叉验证）
- 立场表达（如"这是我最自豪的作品"，主观判断）
- 半真半假（细节精确但立场有倾向）

**5 级解法**：把机构自述独立成级，读者看到"② 机构自述"就明白：这是立场证据，不是硬事实。

## 每级使用范例

### ① 可靠事实

- GitHub API 返回的 star 数、创建日期、许可证 SPDX ID
- YouTube 频道页面的订阅数
- 法院判决书、监管机构的官方公告
- 出版物的 ISBN 与出版社信息

**范例**：
> 阮一峰的 `ruanyf/weekly` GitHub 仓库有 103k star（访问 2026-09-29，https://github.com/ruanyf/weekly，可信度：① 可靠事实）。

### ② 机构自述

- 阮一峰关于页（https://www.ruanyifeng.com/about.html）说"I was born in 1970s"
- Dan Koe 官网的自述
- 本人在访谈里的原话

**范例**：
> 阮一峰在个人关于页自述"I was born in 1970s"（机构自述，可信度：② 机构自述）。**不能**据此推断精确出生年份。

### ③ 旁人回忆

- 第三方博客提及"阮一峰约 1975 年出生"
- 媒体报道"李笑来在 2018 年录音中说过 X"
- 采访中被访者的回忆

**范例**：
> 2018 年搜狐一篇文章用"迈入不惑之年"侧证阮一峰 1970 年代初或中后期出生（旁人回忆，可信度：③ 旁人回忆）。但本人未确认精确年份。

### ④ 作者推断

- 档案作者基于多项证据的合理推断
- 时间线的合理补全

**范例**：
> 阮一峰的"技术转型"发生在 2008-2015 年间（作者推断，依据：2015 年图灵访谈自述已加入支付宝前端团队 + 2008 年获博士学位 + 中间的高校教职期，可信度：④ 作者推断）。具体年份未取得。

### ⑤ 未知

- 本次未取得的信息
- 无法交叉验证的传闻

**范例**：
> 阮一峰的精确出生年份未取得（本次检索范围：阮一峰官网、图灵访谈、主流百科、社交媒体，均未找到本人明确说明的出生年份）。

## 来源冲突的处理

**规则**：两说并列，不择一。

**范例**：
> 关于阮一峰博士就读院校，第三方一致归入上海财经大学（旁人回忆，可信度：③），但本人在所有自述中均未点名学校（机构自述，可信度：②）。本档案同时列出两种说法，不替其选择。

## 抓不到 ≠ 不存在

- **Wikipedia CRAWL_NOT_FOUND**：写"本次抓取失败"，不能写"无 Wikipedia 条目"
- **0 star / 0 fork**：写清仓库创建时间，让人判断是否是新仓库
- **需要登录才能看的页面**：写"本次未取得登录访问，标为未知"
- **需要付费的内容**：写"需付费访问，标为未知"

## 引用格式

**每条事实必须附**：
- 实际访问到的 URL（不是构造的 URL）
- 访问日期（YYYY-MM-DD 格式）
- 可信度级别（① 到 ⑤）

**范例**：
```
阮一峰的 `ruanyf/weekly` 第 400 期发布于 2026-06-12
（https://www.ruanyifeng.com/blog/2026/06/weekly-issue-400.html，
 访问 2026-09-29，可信度：① 可靠事实）
```

## Pitfalls

1. **把机构自述当可靠事实** → 混淆立场与事实
2. **来源冲突时择一** → 破坏档案的诚实度
3. **抓不到就写"不存在"** → 应该是"本次未取得"
4. **构造 URL** → 严禁。抓不到就承认抓不到
5. **推断没标** → 所有推断必须明标「作者推断」+ 依据
