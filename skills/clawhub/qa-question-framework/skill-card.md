## Description:

A QA testing question framework that helps testers identify requirement gaps and ask structured questions for requirement research, boundary confirmation, rule discovery, and technical clarification before test design.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kokxi](https://clawhub.ai/user/kokxi)

### License/Terms of Use:

MIT-0

## Use Case:

QA testers and test engineers use this skill when requirements are unclear or incomplete and they need structured prompts for product managers, developers, or other stakeholders before designing tests.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts or supporting documents may contain customer, identity, payment, or production data.

Mitigation: Use sanitized or masked examples and avoid pasting real sensitive data into prompts or documents.

Risk: The skill suggests installing the broader QA Test Skills set for the complete workflow.

Mitigation: Review the full skill set as a separate package decision before installing or using it.
