## Description: <br>
Helps AI-agent users, skill authors, maintainers, and teams plan, implement, and verify GitHub-style workflows for bug fixes, reliability improvements, setup hardening, and adjacent skill creation. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, AI-agent users, skill authors, maintainers, and teams use this skill to turn broad GitHub-style workflow needs into practical implementation plans, artifacts, checklists, code changes, and verification notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The broad trigger wording may invoke the skill for general GitHub or developer-support requests. <br>
Mitigation: Review the invocation context and narrow activation wording or use explicit skill calls when accidental use would be disruptive. <br>
Risk: The skill can produce implementation guidance, code changes, shell commands, or configuration snippets that may affect a project. <br>
Mitigation: Review generated changes before applying them and run the skill's suggested verification commands in a controlled workspace. <br>
