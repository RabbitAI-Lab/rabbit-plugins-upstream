# Knowledge Card — Kindle 纸书风格知识卡片生成器

生成高密度知识卡片，Kindle 电子书纸张风格。纯 HTML + Tailwind CDN，零依赖，浏览器直接打开。

## 特性

- **三种自动适配布局**：流程步骤型 / 对比框架型 / 单概念洞见型
- **Kindle 纸书暖色体系**：锁定 14 色配色系统，视觉统一
- **单文件输出**：每个卡片仅生成一个 `index.html`
- **零依赖**：纯 HTML + Tailwind CSS CDN，无需 npm install

## 目录结构

```
knowledge-card/
├── SKILL.md                    # Agent 执行指令
└── references/
    ├── card-template.html      # HTML 模板（含完整 CSS）
    ├── layout-rules.md         # 布局适配规则
    └── examples.md             # 三种类型示例 JSON
```

## 触发词

生成知识卡片、知识卡片、kindle 卡片、铸卡、知识图卡、图形卡片

## 配色

| 用途 | 色值 |
|------|------|
| 外背景 | `#e8e0d5` |
| 卡片底色 | `#f5f0eb` |
| Header | `#3c3a37` |
| 强调色 | `#b8a088` |
| 分割线 | `#e0d5c8` |
| 正文字 | `#7a7062` |

## 布局类型

| 内容特征 | 布局 | 结构 |
|---------|------|------|
| 有步骤/方法论 | 流程型 | 摘要 + 机制 + 行动 ①②③④ |
| 有对比/框架 | 对比型 | 摘要 + 机制 + 彩色分区对比 |
| 单一洞见/概念 | 概念型 | 摘要 + 展开 + 行动 1-2 项 |

## 示例

说一句「生成一张关于复利思维的知识卡片」即可自动生成。
