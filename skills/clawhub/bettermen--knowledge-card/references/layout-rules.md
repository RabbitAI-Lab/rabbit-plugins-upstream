# 内容适配规则参考

根据输入素材的内容特征，自动选择最合适的布局。

## 三种布局（由 `body_type` 决定）

### 1. 流程型 (process) — 默认
适用于：方法论、操作步骤、学习路径、工作流

**Body 结构：**
- 认知组：摘要 + 机制
- 执行组：◈ 行动标题 + 编号行动 1-4 项
- 金句

**判定条件：**
- 内容有明显步骤/阶段划分
- 包含"第X步""首先/然后/最后""How to"
- 有可执行的行动建议

### 2. 对比型 (compare)
适用于：框架对比、二分法观点、多维评估、选择决策

**Body 结构：**
- 认知组：摘要 + 机制
- 分区对比：2-5 个分区，每区有 label/badge/title/desc/color
- 金句（可选）

**判定条件：**
- 内容涉及 A vs B、多维分析
- 有明显对比关系（优劣/正反/多个方案）
- 含"选择/对比/比较/框架"

### 3. 单概念型 (concept)
适用于：单一洞见、核心概念、名言解读

**Body 结构：**
- 认知组：摘要 + 机制（可选）
- 概念展开 + 少量行动项
- 金句

**判定条件：**
- 内容聚焦单一概念
- 没有明显步骤流或对比结构
- 偏向启发/洞见类

## 颜色分区色板（对比型专用）

| 颜色 | 语义 | CSS class |
|------|------|-----------|
| red | 负向/问题/风险 | `.red` |
| yellow | 中性/注意/平衡 | `.yellow` |
| green | 正向/优势/机会 | `.green` |
| blue | 理性/分析/技术 | `.blue` |
| purple | 创造/灵性/深度 | `.purple` |
