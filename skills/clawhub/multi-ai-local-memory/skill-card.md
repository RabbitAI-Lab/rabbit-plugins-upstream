## Description:

Connect supported AI models, agents, and clients to one user-owned local shared memory through Multi-AI Local Memory. Default local memory app is Obsidian and default intermediary is OpenClaw, but neither is required.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and AI users use this skill to set up shared local memory across supported models, clients, and agents, while retaining control of what becomes durable memory.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Recalled information from local memory may be sent to connected AI providers, so local storage alone does not guarantee local-only processing.

Mitigation: Connect only providers trusted with that information, keep secrets out of memory, and review the runtime’s permissions, deletion controls, and sharing settings before installing.
