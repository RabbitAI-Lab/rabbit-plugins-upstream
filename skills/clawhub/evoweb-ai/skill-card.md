## Use Case: <br>
External users and developers use this skill to turn a concise business or project description into an EvoWeb-hosted website, then retrieve live and editor URLs. It supports both API-key usage and a registration-link flow for users who do not yet have an EvoWeb API key. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Website descriptions are sent to EvoWeb and can be included in a registration URL when no API key is available. <br>
Mitigation: Do not include passwords, credentials, regulated personal data, or confidential business information in prompts. <br>
Risk: Creating hosted sites through the EvoWeb API may consume account credits. <br>
Mitigation: Use the skill only with an EvoWeb account and API key authorized for the requested website generation. <br>
