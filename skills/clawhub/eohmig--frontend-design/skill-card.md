## Description:

Guidance for distinctive, intentional visual design when building new UI or reshaping an existing one. Helps with aesthetic direction, typography, and making choices that don't read as templated defaults.

This skill is ready for commercial/non-commercial use.

## Publisher:

[eohmig](https://clawhub.ai/user/eohmig)

### License/Terms of Use:

Apache 2.0

## Use Case:

Developers and designers use this skill to guide an agent toward distinctive, subject-specific frontend design decisions for new interfaces or redesigns. It focuses on visual direction, typography, layout, motion, copy, and self-critique rather than code execution.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill encourages using remembered preferences or prior design context for personalization, which may be inappropriate for sensitive or unrelated projects.

Mitigation: Avoid applying memory or prior project context when the current project is sensitive, unrelated, or requires strict isolation.

Risk: Design guidance can lead an agent to make subjective visual and copy choices that do not match the user's brand, audience, or accessibility needs.

Mitigation: Review generated UI decisions, copy, responsive behavior, keyboard focus, and reduced-motion handling before release.
