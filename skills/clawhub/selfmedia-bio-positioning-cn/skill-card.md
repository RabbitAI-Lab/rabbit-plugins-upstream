## Description:

根据创作者提供的真实资历、内容方向和目标受众，为本人中文账号生成简介、栏目定位与置顶内容建议，并在资料不足时指出缺项、不虚构经历或受众结论。

This skill is ready for commercial/non-commercial use.

## Use Case:

中文小店经营者、小说作者和自媒体创作者可用它根据自己的真实经历、内容方向和目标受众，整理账号简介、持续更新的栏目主题和置顶内容建议。

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Profile drafts may include personal facts that the creator does not want to make public, or wording that needs factual review.

Mitigation: Provide only facts suitable for a public profile and review the drafts before using them.

Risk: The optional npx installation command relies on a third-party installer.

Mitigation: Verify the installer and prefer reviewed, pinned versions where supported.
