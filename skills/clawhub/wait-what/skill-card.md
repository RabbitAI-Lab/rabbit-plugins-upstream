## Description:

Grill the user relentlessly about a plan, decision, or idea.

This skill is ready for commercial/non-commercial use.

## Publisher:

[thefirstelement](https://clawhub.ai/user/thefirstelement)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to stress-test plans, decisions, or ideas through structured rounds of frontier questions with recommended answers.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can create an intentionally intense questioning experience.

Mitigation: Use it only when that interaction style is desired and pause or redirect the agent if the questioning becomes unsuitable for the task.

Risk: The skill directs the agent to use available tools, local files, or sub-agents for fact-finding without asking first.

Mitigation: Run it in non-sensitive workspaces or explicitly instruct the agent to ask before inspecting files, running tools, or launching sub-agents.
