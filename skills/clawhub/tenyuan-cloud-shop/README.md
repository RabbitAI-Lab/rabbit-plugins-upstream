# 十元云铺万元利

普通人的云端小批发部。

一句话或一张图，即可自动生成独立迷你网站（云铺档口页），带实拍/示意标注和口播音频，方便直接分享到微信、朋友圈、抖音。

## 功能特点

- **零门槛开店**：不注册、不登录，发图或发字即开云铺
- **有图有真相**：自动区分实拍图与 AI 示意图，并如实标注
- **智能抽取**：识别品类、产地、卖点、联系方式
- **口播音频**：服务端自动生成档口介绍语音
- **分享友好**：档口页自带完整链接、一键复制/系统分享、微信二维码位
- **域名自适应**：换域名/环境部署，所有链接自动跟随

## 使用流程

1. 在 WorkBuddy 中打开「十元云铺万元利」
2. 上传一张产品照片，或输入文字描述
3. 等待系统自动生成云铺
4. 获得专属链接与分享文案，直接转发
5. （可选）上传微信收款/名片二维码挂到档口页
