## Description:

Recommends short-drama and manju creation skills matched to production stage, video model, and agent.

This skill is ready for commercial/non-commercial use.

## Use Case:

Creators and developers use this skill to choose short-drama or manju production skills for their workflow, agent, video model, and language, and to find installation guidance.

### Deployment Geography for Use:

Global

Mitigation: Review each recommended skill's SKILL.md, repository, and install command; run installs only with the user's approval.
