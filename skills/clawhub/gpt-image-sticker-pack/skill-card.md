## Description:

Turn a photo or character into a consistent set of 6–8 animated stickers with GPT Image 2.6, then export them for supported messaging platforms.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators use this skill to turn an approved photo, pet, or mascot into a consistent animated sticker pack and prepare files for supported messaging platforms. It is intended for sticker packs and emoji rather than standalone GIFs, game sprites, or static images.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Personal photos may be sent to external services without a clear privacy notice.

Mitigation: Before uploading personal photos, review how the named services handle and retain them.

Risk: The installer is unpinned, and the export script was only partially inspected in the security review.

Mitigation: Check the install source and review the export script before running it.
