## Description:

Creates an animated sticker pack from a photo or character and exports the stickers for supported messaging platforms.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

External users and creators use this skill to turn an approved photo, pet, or mascot into a consistent set of looping animated stickers and prepare exports for messaging platforms.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Personal photos may be processed by third-party services.

Mitigation: Use photos only with the subject's consent and review the service's data handling before upload.

Risk: The security review notes unpinned installer versions and partial script analysis, including a possible export-validation issue.

Mitigation: Review the exact release and its scripts before use, then manually inspect exports against the target platform's specifications.
