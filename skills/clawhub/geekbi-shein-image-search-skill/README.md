# 极鲸云 SHEIN 图搜同款 Skill

通过极鲸云提供的真实 SHEIN 图搜与商品数据，帮助跨境卖家使用商品图、实拍图或供应商图片查找 SHEIN 视觉相似商品，并分析候选商品的销量、价格、供货价、上架时间和同款竞争。图搜命中的是视觉相似候选，不自动证明商品的规格、材质、尺寸、功能或供应链完全相同；候选池命中数量也不同于每个商品的同款数（跟卖数）。

## 主要能力

| 能力 | 可以解决的问题 |
| --- | --- |
| SHEIN 图搜同款 | 使用本地图片、会话附件或图片网址查找 SHEIN 视觉相似商品，快速形成候选商品池 |
| 候选筛选与排序 | 在视觉候选中按站点、托管模式、销量、销售额、价格、供货价、评分、同款数和上架时间筛选或排序 |
| 市场表现分析 | 比较候选商品的销量、增长、销售额与生命周期，判断图片对应产品的市场热度 |
| 价格与竞争评估 | 分析站点售价、人民币供货价、同款数（跟卖数）和店铺分布，了解价格空间与同质化竞争 |
| 匹配审核与机会判断 | 区分强匹配、弱匹配和明显误匹配，在视觉相似边界内判断跟款或差异化开发机会 |

## 适用场景

本项目适合以下任务：

- 根据供应商图片、商品主图或实拍图查找 SHEIN 视觉同款。
- 使用截图或网页图片定位 SHEIN 在售相似商品。
- 按销量、价格、上架时间或同款数筛选图搜候选。
- 分析图片对应产品的市场热度、价格带与竞争程度。
- 比较多张产品图片各自的 SHEIN 市场表现。
- 判断一个图片款适合直接跟进、继续核验还是差异化开发。
- 为采购谈价、测款和规格核验建立候选商品清单。



