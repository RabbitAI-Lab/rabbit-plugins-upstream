# 事件分类体系

## 政策类 (policy)
| 子类 | 关键词 | 典型受益方向 |
|------|--------|-------------|
| 货币政策 | 降准、降息、MLF、LPR、逆回购 | 银行、券商、房地产 |
| 财政政策 | 减税降费、专项债、财政支出 | 基建、建材、工程机械 |
| 产业政策 | 新能源、半导体、人工智能、低空经济 | 对应产业链上下游 |
| 监管新规 | 行业准入、环保标准、数据安全 | 合规龙头企业 |
| 区域政策 | 自贸区、大湾区、雄安新区 | 区域内上市公司 |

## 财报类 (earnings)
| 子类 | 关键词 | 典型影响 |
|------|--------|---------|
| 业绩超预期 | 营收大增、净利润超预期 | 股价正面催化 |
| 业绩不及预期 | 亏损扩大、下滑、预警 | 股价负面压力 |
| 预告修正 | 上修/下修业绩预告 | 短期情绪波动 |
| 分红方案 | 高送转、特别分红、回购 | 价值重估 |
| 审计问题 | 非标意见、财务质疑 | 重大风险 |

## 行业类 (industry)
| 子类 | 关键词 | 典型受益方向 |
|------|--------|-------------|
| 供需变化 | 产能缺口、去库存、补库 | 龙头企业量价齐升 |
| 价格异动 | 涨价、跌价、限价 | 上游/下游利润重分配 |
| 技术突破 | 新工艺、新材料、量产 | 技术领先企业先发优势 |
| 产能调整 | 扩产、停产、限产 | 行业格局重塑 |
| 进出口 | 关税、出口管制、贸易壁垒 | 国产替代/出口受限 |

## 公司类 (company)
| 子类 | 关键词 | 典型影响 |
|------|--------|---------|
| 并购重组 | 收购、合并、借壳、分拆 | 估值重塑 |
| 股权变动 | 大股东变更、举牌、增持 | 控制权/治理变化 |
| 高管变更 | 董事长/CEO更换 | 战略方向调整 |
| 重大合同 | 大订单、框架协议 | 业绩弹性 |
| 负面事件 | 立案调查、处罚、事故 | 重大风险 |

## 宏观类 (macro)
| 子类 | 关键词 | 典型影响 |
|------|--------|---------|
| 经济数据 | GDP、CPI、PPI、PMI | 政策预期变化 |
| 国际经贸 | 中美关系、贸易协定、制裁 | 相关产业链 |
| 汇率利率 | 人民币升值/贬值 | 出口/进口型企业 |
| 大宗商品 | 原油、黄金、铜、铁矿石 | 资源类/制造类企业 |
| 地缘政治 | 冲突、制裁、国际会议 | 避险/风险情绪 |
