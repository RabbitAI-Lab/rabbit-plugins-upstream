〈填写指引：BUG-n 编号一经分配永不复用，跨轮次连续递增。级别沿用 TEST-PLAN 第 2 节口径。复现步骤写到"照做必现"的精度：前置状态、输入、操作序列；真实令牌、账号、个人数据一律占位符呈现（如 `<token>`、`<user-phone>`），禁止粘贴真实凭据。期望/实际分开写，不合并成"不符合预期"。状态只填：新建/修复待验/已关闭。〉

## 4. 回归结论

〈填写指引：修复回归范围 = 缺陷本身 + 受影响面。受影响面依据 PR-SUMMARY 变更面与缺陷所在模块推导，写明推导理由；只回归缺陷不复测受影响面视为不合格。回归结果写结论 + 关联用例清单。示例：BUG-2 修复后回归 TC-1/TC-4（缺陷本身）+ TC-7（库存模块受影响面），全部通过。〉

- 修复回归范围：〈缺陷本身 + 受影响面〉
- 回归结果：〈结论 + 依据用例〉
