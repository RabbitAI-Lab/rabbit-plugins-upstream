# PROGRESS：〈YYYY-iterN〉迭代工作日志

> **产出者**：全体执行者（人类 + AI 编程智能体）——当日事当日记，不攒批、不事后补写、不回改
> **受众**：迭代协作者、RETRO 提炼者、AI 编程智能体（会话恢复与上下文重建的第一入口）
> **归档**：`docs/process/progress/YYYY-iterN.md`（本文件即该迭代过程记录的唯一权威版本）
> **真值源**：过程事实本身；各条产出的细节以链接所指的 commit/PR/文档为准，本文件只存"做了什么 + 指向"，不复制内容
> **质量门禁**：① 追加式——既有日期小节不回改，纠错追加新条目并引用原条目 ② "做了什么"每条必含产出链接（commit hash / PR 号 / docs/ 相对路径） ③ 重大临时决策事后须补 ADR-NNNN 并在此回链 ④ 当日事当日记毕，跨日补记须注明补记日期与原因

## 状态说明

| 状态 | 何时使用 | 关键义务 |
|---|---|---|
| active | 迭代进行中 | §2 随做随记；每日小节三段齐全 |
| archived | 迭代收尾完成、RETRO 关闭后 | 转只读；历史勘误在下一迭代日志追加条目并引用本文件 |

迁移路径：active → archived（单向）。archived 后发现历史记录有误，不在本文件回改，在下一迭代日志追加勘误条目。

## 2. 工作记录

〈填写指引：按日期正序追加，每日一个三级小节，三段结构固定：做了什么 / 过程中的决策 / 阻塞与待办移交。只写事实与指向——不写评价（提炼判断属 RETRO，`templates/process/RETRO.md`）、不写计划（承诺属 ROADMAP）。无内容的小节段写"无"，不省略段标题；当天无工作可不建小节，但连续多个工作日无记录即违反门禁④。〉

〈AI 编程智能体恢复上下文时读本节：链接必须可直接解析（commit hash、PR 号、相对路径），"昨天那个文件"式指称一律禁止。〉
