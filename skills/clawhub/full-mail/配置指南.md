# 📧 Full-Mail 完整邮件功能配置指南

> 支持发送 (SMTP) 和接收 (IMAP) 邮件

---

## ⚙️ 配置步骤

### 1. 编辑配置文件

打开 `~/.openclaw/openclaw.json`，添加以下配置：

```json
{
  "skills": {
    "entries": {
      "full-mail": {
        "enabled": true,
        "env": {
          "EMAIL_SMTP_SERVER": "smtp.163.com",
          "EMAIL_SMTP_PORT": "465",
          "EMAIL_IMAP_SERVER": "imap.163.com",
          "EMAIL_IMAP_PORT": "993",
          "EMAIL_USER": "your-email@163.com",
          "EMAIL_PASSWORD": "你的授权码"
        }
      }
    }
  }
}
```

## 🔑 授权码获取方法

### 163 邮箱
1. 登录 https://mail.163.com/
2. 点击「设置」→「POP3/SMTP/IMAP」
3. 开启「IMAP/SMTP 服务」
4. 点击「生成授权码」
5. 短信验证后获取授权码

### QQ 邮箱
1. 登录 https://mail.qq.com/
2. 点击「设置」→「账户」
3. 开启「POP3/SMTP 服务」和「IMAP/SMTP 服务」
4. 点击「生成授权码」
5. 短信验证后获取授权码

### Gmail
1. 开启两步验证：https://myaccount.google.com/security
2. 访问 https://myaccount.google.com/apppasswords
3. 选择「邮件」和应用
4. 生成 16 位应用密码

## 📤 发送邮件用法

```bash
# 基础用法
python3 ~/.openclaw/workspace/skills/full-mail/send_email.py "收件人" "主题" "正文"

# 带附件
python3 ~/.openclaw/workspace/skills/full-mail/send_email.py "test@example.com" "测试邮件" "你好，这是测试内容" "/path/to/file.pdf"

# 多个收件人

```

## 📥 接收邮件用法

```bash
# 删除邮件
python3 ~/.openclaw/workspace/skills/full-mail/read_email.py delete 1
```

## ⚠️ 注意事项

1. **授权码 ≠ 登录密码** —— 必须使用邮箱服务商提供的授权码
2. **端口选择** —— SMTP: 465(SSL) 或 587(TLS)；IMAP: 993(SSL)
3. **配置安全** —— 不要将配置文件外泄
4. **频率限制** —— 避免短时间内大量发送/接收邮件

## 🔧 故障排查

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 认证失败 | 密码错误 | 检查是否使用授权码而非登录密码 |
| 连接失败 | 服务器/端口错误 | 检查 SMTP/IMAP 服务器配置 |
| 收件箱为空 | IMAP 配置错误 | 检查 IMAP 服务器和端口 |
| 发送失败 | SMTP 未开启 | 登录邮箱网页版开启 SMTP 服务 |
