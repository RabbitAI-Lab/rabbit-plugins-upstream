## Description:

AI Usage Policy Generator creates a one-page Markdown policy covering approved AI tools, permitted uses, prohibited uses, and escalation paths.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zhaoxinghua09-cell](https://clawhub.ai/user/zhaoxinghua09-cell)

### License/Terms of Use:

MIT

## Use Case:

Employees, managers, and developers use this skill to generate a concise AI usage policy for a team, including approved tools, allowed work, sensitive-data red lines, and escalation contacts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security review flags unpinned global installation commands that could install code different from the reviewed artifact.

Mitigation: Install from a pinned, verified release or reviewed commit, and review the artifact contents before use.

Risk: The generated policy is governance guidance and does not replace legal, compliance, or regulated professional review.

Mitigation: Have responsible stakeholders review the generated Markdown against current official requirements before adoption.
