# SC 食品生产许可证编号规范

## 一、基本信息

| 项目 | 内容 |
|------|------|
| **证标** | SC（"生产"汉语拼音首字母缩写） |
| **法规依据** | 《食品生产许可管理办法》（国家市场监督管理总局令）第30条 |
| **替代旧证** | QS 证（2018年10月1日起全面停发 QS 证） |
| **适用对象** | 食品、食品添加剂生产者 |

> ⚠️ 自2018年10月1日起，食品生产者新办理的生产许可证一律使用 SC 编号。QS 标志已废止，市场上仍印有 QS 标志的产品属于违规。

---

## 二、SC 编号格式

SC 编号由 **"SC" + 14位阿拉伯数字** 组成，共 17 位字符。

```
SC  X X X  X X  X X  X X  X X X X  X
   |  └─┘  └─┘  └─┘  └─┘  └────┘  └
   |  食品  省    市    县    企业    校
   |  类别  代码  代码  代码  顺序码  验
   |  编码                                码
   |
   "SC"
```

### 字段含义

| 字段 | 长度 | 含义 |
|------|------|------|
| **SC** | 2位字母 | "生产"汉语拼音首字母缩写 |
| **食品类别编码** | 3位数字 | 第1位=食品/食品添加剂识别码；第2-3位=类别编号 |
| **省（自治区、直辖市）代码** | 2位数字 | GB/T 2260 行政区划代码 |
| **市（地）代码** | 2位数字 | GB/T 2260 行政区划代码 |
| **县（区）代码** | 2位数字 | GB/T 2260 行政区划代码 |
| **企业顺序码** | 4位数字 | 0001-9999，按许可顺序流水编号 |
| **校验码** | 1位数字 | GB/T 17710 规定的 MOD 11,10 算法 |

## 四、行政区划代码

第 4-9 位按 **GB/T 2260《中华人民共和国行政区划代码》** 取值：

| 位次 | 含义 | 示例 |
|------|------|------|
| 第 4-5 位 | 省级代码 | 33=浙江、44=广东、43=湖南 |
| 第 6-7 位 | 市级代码 | 01=省会、02=地级市 |
| 第 8-9 位 | 县级代码 | 01=市辖区 |

完整代码查询：国家统计局 http://www.stats.gov.cn/tjsj/tjbz/xzqhdm/

## 六、与营销版面审核相关的重点

### 6.1 强制标示

- 根据 **GB 7718-2025 第 5.1 节**，预包装食品标签强制标示 **食品生产许可证编号**
- 应清晰标示在销售包装上，建议位置：**标签正面或背面，与生产者信息相邻**

### 6.2 合规风险点

| 风险类型 | 错误示例 | 正确做法 |
|---------|---------|---------|
| **使用旧 QS 证编号** | 标注"QS XXXX" | 应使用 SC 编号 |
| **SC 编号格式错误** | 字母写错（"SC"写成"5C"或"S.C."）| 严格按 SC+14位数字 |
| **SC 编号与企业不符** | 委托加工使用委托方 SC，但标签未明示 | 委托加工须明示委托关系 |
| **类别编码与产品不符** | 实际是饮料但 SC 编号是 105（乳制品） | 食品类别应与实际产品对应 |
| **保健食品未使用 127** | 保健食品使用 101（粮食加工品）| 27=保健食品 |
| **婴幼儿配方食品未使用 129** | 婴幼儿奶粉使用 105（普通乳制品）| 29=婴幼儿配方食品 |
| **冒用 SC 编号** | 借用其他企业的 SC 编号 | 严格使用本企业编号 |

### 6.3 委托加工特别要求

- **委托方**：SC 编号使用**委托方**的（受托方仅为加工方）
- **标签须明示**：标注"委托方：XXX"和"受托方：XXX"
- **食品类别**：应与委托方申报生产许可的类别一致

### 6.4 进口食品

- 进口食品包装上**不要求**标注中国 SC 编号
- 但须标示：原产国（地区）、进口商/代理商信息、境外生产企业注册编号

## 七、SC 编号校验算法

第 14 位**校验码**采用 **GB/T 17710-1999** 规定的 **MOD 11, 10** 算法：

```
校验码计算步骤：
1. 从左至右对前13位数字加权求和（权重从右至左 2,3,4,...,9,2,3,...）
2. 和值 MOD 11
3. 用 10 减去余数，再 MOD 10 得到校验码
```

实务中**一般无需手算**，扫描枪读取时会自动校验。

## 八、与商品条码的关系

| 项目 | SC 编号 | 商品条码（GTIN） |
|------|---------|------------------|
| **性质** | 行政许可编号 | 商品标识代码 |
| **颁发主体** | 市场监督管理部门 | 中国物品编码中心 |
| **作用** | 证明企业生产许可资格 | 标识商品（用于 POS 结算、追溯）|
| **强制要求** | ✅ GB 7718 强制标示 | ✅ GB 12904 强制标示 |

⚠️ **两者不可混淆**：SC 编号 ≠ 商品条码；两个都必须标注。
