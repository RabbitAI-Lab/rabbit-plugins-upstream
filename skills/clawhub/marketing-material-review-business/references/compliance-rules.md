## 一、极限词与绝对化用语规则

### 1.1 禁用极限词清单

| 类别 | 禁用词 | 说明 |
|-----|--------|-----|
| 最佳类 | 最佳、最优、最便宜 | 绝对化用语 |
| 第一类 | 第一、销量第一、领导者 | 需权威证明 |
| 顶级类 | 顶级、顶尖、极品、至尊 | 绝对化用语 |
| 完美类 | 完美、极致、绝佳、致臻 | 绝对化用语 |
| 史无前例 | 前所未有、史无前例 | 绝对化用语 |
| 极限促销 | 地板价、全网最低价、破价 | 虚假促销 |
| 其他 | 万里挑一、独一无二 | 极限词 |
| 夸大促销 | 史无前例、前所未有 | 绝对化用语 |

### 1.2 引证广告新规（2026-06-12《广告引证内容执法指南》）

**重要变化：** 在引证广告中使用"最高级""最佳"，或销量、销售额、市场占有率"第一"等用语进行宣传的，**不属于《广告绝对化用语执法指南》第六条第六项规定的豁免情形**

**不属于豁免的情形：**
1. 用语指向的地域<省级行政区域（如"全市第一""全区最佳"）
2. 用语指向的商品所属行业<《国民经济行业分类》规定的行业分类
3. 用语指向的商品无专有的产品或服务国家标准、行业标准
4. 其他不属于豁免的情形

**合规要求：**
- 引证内容的字体、字号、颜色需满足正常情况下能够清晰识别
- 不得利用减小字号、改变字体、使用与背景相近颜色文字等方式限缩对消费者不利信息
- 引用的数据、统计资料需真实可核验，规范标注出处、适用范围和有效期限

### 1.3 销量第一标注规范

**可以使用的条件:**
1. 注明数据来源(需要权威机构)
2. 严格按照数据来源的描述进行标注,不能随意更改
3. 注明区域和时间范围
4. "销量第一"几个字与具体产品名称的字体比例不能相差太大

**示例:**
- ✅ "销量领先(数据来源:XXX机构,2024年1-6月)"
- ❌ "销量第一" (无来源标注)

### 1.4 合规替代方案

| 禁用表述 | 合规替代 |
|---------|---------|
| 销量第一 | 销量领先 |
| 顶级品质 | 品质卓越 / 匠心品质 |
| 全网最低价 | 限时优惠 / 会员专享价 |
| 地板价 | 成本价 / 心动价 |
| 万里挑一 | 精选 / 百里挑一(有风险) |

## 二、功能宣称规则

### 2.1 保健功能禁止宣称

**普通食品不得宣称以下功能:**
- 疾病治疗或预防
- 保健功能(如增强免疫力、润肠通便)
- 美容养颜
- 减肥瘦身
- 抗疲劳、耐缺氧等

### 2.2 肠道相关敏感词(高风险)

**禁用表述:**
- 守护肠道、肠道健康、肠道好
- 润肠、通便、调节肠道
- 肠态、好肠态

**风险说明:**
- "调节肠道菌群"属于保健功能
- "守护肠道"有保健功能嫌疑
- 产品版面上不允许出现任何和肠道有关的图案和文字

**合规替代:**
- ✅ 好喝美味
- ✅ 营养丰富
- ✅ 纯正好奶

### 2.3 免疫相关敏感词(高风险)

**禁用表述:**
- 增强免疫力
- 提高抵抗力
- 增强抵抗力

**合规替代:**
- ✅ 营养丰富
- ✅ 健康成长

### 2.4 营养成分宣称规范

**可宣称(需有检测报告):**
- 叶黄素、DHA、ARA(营养强化剂)
- 营养成分表中已标注的含量

**不可宣称:**
- 生牛乳中的乳铁蛋白、维生素D(含量少,无法检出)
- 无检测报告的营养成分

## 三、对比宣称规则

### 3.1 禁止对比类型

- ❌ 与不特定竞品对比
- ❌ 暗示竞品存在问题
- ❌ 使用贬低性语言
- ❌ 虚假对比数据

### 3.2 合规对比类型

- ✅ 与自家产品历史对比
- ✅ 权威机构认证数据
- ✅ 客观事实陈述

### 3.3 领导者/第一宣称

**风险说明:**
- "领导者"概念与"销售第一"混用存在风险
- 需要有明确的时间概念和平台范围
- 需与具体产品关联

## 四、商标使用规则

### 4.1 禁止行为

- ❌ 商标与日常用语结合
  - "来XX认养一头牛"
  - "贾乃亮认养一头牛"
  - "勇敢宝贝棒棒哒"
- ❌ 商标单独使用降低显著性
  - 单独使用"认养一头牛"
- ❌ 变形或修改商标

### 4.2 规范使用

- ✅ 品牌名+产品类目
  - "认养一头牛纯牛奶"
- ✅ 使用注册商标符号®
- ✅ 保持商标完整性和独立性
- ✅ 可以使用【关注认养一头牛】

## 五、真实性与虚假宣传

### 5.1 官方认证规范

**禁用表述:**
- ❌ "官方认证"(未注明具体情况)
- ❌ "央妈认证"(未获授权,违反广告法)
- ❌ "央视推荐"(无实际背书)

**合规要求:**
- 需注明具体的认证机构
- 需有正式的授权文件
- 我司仅有"五好"有央视背书

**法规依据:**
- "央妈"称谓未获中央电视台授权
- 使用可能侵犯名称权、商标权
- 仅有采访介绍≠正式认证

### 5.2 数据引用规范

**合规要求:**
1. 注明数据来源(权威机构)
2. 注明区域和时间范围
3. 字体比例不能差距太大
4. 有适用范围需明确表示

**常用引证模板:**

| 宣称内容 | 引证脚注 |
|---------|---------|
| 全网儿童奶市占率第一 | 生意参谋、京东商智、抖音婵妈妈(2023-2024.10.1) |
| A2 β-酪蛋白亲和性 | 参考文献《Comparative effects of A1 versus A2 beta-casein...》 |
| 原奶指标优于欧盟标准 | 指体细胞、微生物指标 |
| 连续三年全国销售额第一 | 弗若斯特沙利文(2021-2023) |
| 三重有机认证 | GB/T19630-2019有机产品认证 |

## 六、促销活动的合规要求

### 6.1 抽奖活动

**必须公示:**

### 13.0 2026-04-18 最新动态

**【三大执法指南正式落地(2025年7月)】**

**(1)《广告法适用问题执法指南(一)》(2025年7月4日发布)--商业广告的定义与边界**

商业广告须同时具备以下四大特征:
1. **营销意图**:以推销商品或服务为目的
2. **媒体传播**:通过一定媒介和形式发布
3. **非特定受众**:面向不特定公众
4. **非强制性**:非出于满足公众知情权等强制性要求

**检查清单(区分商业广告 vs 其他商业营销宣传):**
- 是否具有营销意图(非强制性信息披露)
- 是否通过媒体/平台发布
- 是否面向不特定受众
- 是否可被合理认定为广告

**适用范围:** 《广告法》《互联网广告管理办法》等全部广告法规。

**(2)《广告法适用问题执法指南(二)》(2025年7月23日发布)--违法广告管辖规则**

目的:防止越权处罚或重复处罚("远洋捕捞"),维护经营主体合法权益。

核心管辖规则:
- 广告主所在地市场监管部门有管辖权
- 广告发布者所在地市场监管部门有管辖权
- 广告代言人所在地市场监管部门有管辖权
- 不得对异地企业进行"远洋捕捞"式执法

**(3)《广告法适用问题执法指南(三)》即将出台(2026年)**

**【《国家通用语言文字法》重大修订(2026年1月1日生效)】**

| 修订内容 | 合规要求 |

| 适用范围扩大 | 产品名称、包装、说明书文字全部纳入监管 |

| 处罚规则 | 违反广告法相关条款的,适用广告法较高处罚 |

### 13.0 2026年4月17日最新动态

**【重磅】SAMR《关于强化广告中提示性用语监管工作的通知》正式发布(2026年3月6日)**

市场监管总局发布通知,**为期半年**的 广告中提示性用语乱象清理整治正式启动。

**六大整治重点:**

1. **误导性大小字广告**:重点整治"大字吸睛、小字免责",技术复杂产品(手机、电脑、汽车)、服务行业(旅游、餐饮)、促销广告均纳入
   - 限缩性条件、交易前置条件等不利信息不得以难以识别的方式弱化
   - 情节严重可认定为虚假广告

2. **未标注/弱化标注提示用语**:重点关注"三品一械"(药品、医疗器械、保健食品、特殊医学用途配方食品)
   - 必须标注"请按药品说明书或者在药师指导下购买和使用""本品不能替代药品"等法定提示用语

3. **AI生成式广告**:
   - 未经权利人同意,擅自在广告中利用AI生成并使用他人形象 → 虚假广告
   - 以AI虚构人物形象为产品/服务推荐证明,未标注AI内容 → 虚假广告

4. **绝对化用语**:"第一""首创""最佳""领先"等加大监管
   - 萝卜坑式引证(以极窄限定条件支撑"第一"等宣称)将被认定为虚假广告

5. **引证广告监管**:
   - 必须显著标明引证内容出处
   - 明知/应知第三方调研报告无法公开查询仍作为出处 → 无出处认定
   - 歪曲、夸大统计数据,将概然性结论宣传为必然性结论 → 虚假广告

6. **广告主自证内容监管**:
   - 自有数据/实验需标明时间、地域等限定条件
   - 未标明或未以消费者可清晰识别方式标明 → 情节严重认定为虚假广告

**企业应对:**
- 立即审查所有在投广告的提示语、警示语、限制条件
- 确保不利信息字体、颜色、位置与主文案同等显眼
- 审查直播口播、详情页是否涉及AI生成内容标注

### 13.2 引用内容指引草案核心要点

**实验数据要求:**
- 必须注明检测机构、仪器设备、实验环境和方法论
- 不能在未证明普遍适用性的情况下展示为普遍适用

**统计数据要求:**
- 须通过科学方法收集,抽样需具有代表性
- 须说明与公布数据的差异

**摘录引用要求:**
- 须逐字复制原文;来源须真实可查且与公认科学知识一致

**显著性和局限性标注:**
- 适用范围、有效期、适用区域的限制,必须在正常可识别条件下清晰展示

### 13.3 绝对化用语安全港收窄(重要变化)

**2023年安全港规则(已收窄):**
- 事实性、可验证的绝对化用语若有明确时间和地域限制可使用
- 示例:"上海市2024年市场份额第一"

**2026年新收窄规则:**
- ❌ 不得通过人为缩窄市场细分来为绝对化用语辩护
- 如果定义的细分市场过于狭窄以至于误导消费者对业务真实市场地位的认识,将被认定为违规
- 示例:❌ "某区某街道2025年奶茶类销量第一" (人为缩窄市场)

### 13.4 AI生成内容责任(2026新规)

- AI生成的数据、深度合成内容视为广告主自创内容
- 广告主须承担全部证明责任,须能在执法检查时提供支撑证据
- 委托第三方进行实验/调查/统计用于广告的,若第三方明知用于广告,则与广告主共同承担责任

这是2026年广告合规领域最重要的法规动态。

| 引证类型 | 核心要求 |
|---------|---------|
| 实验数据 | 须注明检测机构、仪器、环境、方法论;不得以偏概全 |

### 16.4 AI生成广告合规(深化)

**核心原则:AI生成 ≠ 免责**

- 使用AI工具生成广告内容,广告主对内容**真实性、合法性承担完全责任**
- AI生成的实验数据、市场数据等视为"自制内容"
- 广告主须能提供执法时所需的一切支撑证据
- 算法推荐广告须确保"广告"标识清晰可识别

### 16.5 直播电商广告合规(持续收紧)

### 16.10 【新增】沈阳市广告提示性用语合规指引(2026年4月20日)

**来源:** 沈阳市市场监督管理局广告处
**依据:** 《广告法》+ 市监广发〔2026〕17号
**全文:** https://scj.shenyang.gov.cn/zwgk/fdzdgknr/gsgg/202604/t20260420_5017022.html

**四大总体合规原则:**

| 原则 | 核心要求 |
|------|---------|
| 真实准确 | 不得虚假夸大引人误解,不得以提示用语否定主宣传核心内容 |
| 显著清晰 | 普通消费者正常浏览/收听条件下可轻易注意、看清、听懂 |
| 完整规范 | 法定提示用语须完整准确原样标注,不得删减、篡改、模糊化 |
| 禁止误导 | 严禁"大字突出卖点、小字隐藏不利",严禁以提示用语为虚假宣传"免责" |

**分领域法定提示语要求:**

| 行业 | 法定提示语 | 位置要求 |
|------|----------|---------|
| 药品(非处方药) | "请按药品说明书或者在药师指导下购买和使用" | 标题下方/产品旁,不得闪放过快 |
| 医疗器械(个人自用) | "请仔细阅读产品说明书或者在医务人员的指导下购买和使用" | 同药品 |
| 含禁忌/注意事项的器械 | "禁忌内容或者注意事项详见说明书" | 同药品 |
| 保健食品 | "本品不能代替药物" | 清晰醒目,不得与主文案混淆 |
| 特殊医学用途配方食品 | "请在医生或临床营养师指导下使用" | 同保健食品 |
| 互联网广告 | "广告"显著标明;AI生成广告标注"AI生成" | 短视频/直播/探店/生活分享均须标注 |

**标注形式合规标准(新增详细规定):**
- 字体:合理比例,不得超细/浅色/透明字体
- 颜色:与背景高对比度,禁止相近色/渐变色隐藏
- 视频:广告文字提示不得闪放过快或声音过小

**"误导性大小字"认定标准:**
- ❌ 大字"全网最低价" + 小字"限特定型号" → 违规
- ❌ 大字"100%有效" + 小字"仅为企业愿景" → 虚假广告
- 小字提示仅限补充信息/解释条件/说明范围,不得用于"免责"

**重点整治六类违法违规情形:**
1. 法定提示用语缺失、删减、篡改、弱化(字体过小/颜色过浅/位置隐蔽)
2. "大字虚假宣传、小字免责"
3. 促销/服务广告隐瞒门槛、限制、费用、期限等关键信息
4. AI广告未标注AI生成、擅自使用他人AI形象
5. 互联网广告未显著标注"广告",以"种草""分享"变相规避
6. 绝对化用语、虚假引证、不标明数据来源或条件

### 16.11 【重要补充】市监广发〔2026〕17号全文(2026年3月13日实施)

**发文字号:** 市监广发〔2026〕17号 **发文机关:** 市场监管总局 **成文/实施:** 2026年3月6日/13日

**执法整治五大重点(含详细认定标准):**

**一、整治"误导性大小字"广告**
- 技术复杂产品(手机/电脑/汽车):以难以清晰识别的文字/语音表述技术性能限制条件 → 认定"内容不清楚、不明白";情节严重 → 虚假广告
- 大字宣称与实际不符 + 小字标注"仅为企业愿景" → 虚假广告
- 旅游/餐饮/促销广告:以难以清晰识别方式表述不利交易条件/促销前置条件 → 认定"不清楚不明白";情节严重 → 虚假广告

**二、查处不标注/弱化标注提示用语**
- "三品一械"未标注法定提示语 → 责令改正,可行政处罚
- AI生成广告:未经授权用他人形象/以AI虚构人物推荐未标注 → 虚假广告

**三、查处绝对化用语广告**
- 行业/领域/地域界定与国家标准不一致,导致误解市场地位 → 虚假广告
- 屡教不改反复多次制作发布 → 应当予以处罚

**四、加强引证广告监管**
- 不标明/难以清晰识别出处 → 依法查处
- 明知/应知第三方报告无法公开查询仍作为出处 → 认定为"无出处"
- 歪曲夸大统计/概然性结论宣传为必然性结论 → 虚假广告

**五、强化广告主自证内容监管**
- 自有数据/实验未标明时间/地域限制条件,或未以消费者可清晰识别方式标明 → 认定"不清楚不明白";情节严重 → 虚假广告

**六、强化广告发布媒介监管**
- 督促互联网平台落实责任,指导设计制作单位确保提示语字号比例合理/颜色显著区分
- 指导市场调研机构避免以不合理限缩范围为"首创""第一"背书

**执法原则:** 梯度监管,合理区分广告创意与"文字游戏",避免"一刀切"式执法。

## 十七、AI广告合规专项规则(2026年新增)

> **背景:** 市场监管总局2026年4月23日印发《关于深化互联网广告生态治理工作的通知》,首次提出"互联网广告生态治理"概念,启动为期半年的互联网广告市场秩序整治行动。《人工智能生成合成内容标识办法》2026年正式落地。

### 17.1 AI生成广告必须标注

| 情形 | 标注要求 | 违规后果 |
|-----|---------|---------|
| AI生成图片用于广告 | 须明确标注"AI生成"或等效提示 | 可认定为虚假广告 |
| AI生成文案/话术 | 须有明确标识区分AI与人工 | 行政处罚 |
| AI虚拟人物推荐 | 须标注"AI虚拟形象" | 未经授权用他人形象→虚假广告 |

### 17.2 AI广告四大高风险雷区(罚超百万)

1. **AI生成内容未标注** - 《人工智能生成合成内容标识办法》2026年正式落地,强制标注
2. **擅自使用他人AI形象** - AI爬取他人图片训练模型生成广告素材,侵犯商标/肖像权,罚超百万元
3. **AI换脸/盗声推荐** - 中广联《数字虚拟人管理办法》2026年严打
4. **AI广告素材无合规审核** - 企业须建立双重合规审核机制(内容合规+广告合规)

### 17.3 专项整治六大重点(2026.4.23起,为期半年)

1. **强化互联网广告导向监管** - 打击违反社会主义核心价值观的广告
2. **加强直播电商广告监管** - 直播带货中的广告合规
3. **强化AI生成式广告监管** ← **全新且最高强度**
4. **规范互联网弹窗广告**
5. **规范"矩阵式"广告投放** - 多账号矩阵式投放
6. **压实互联网平台主体责任**

### 17.4 数字虚拟人管理办法(中广联,2026年制定中)

- **AI换脸**:未经授权使用人脸→违规
- **盗声**:未经授权使用声音→违规
- **侵权**:AI虚拟人形象侵犯版权→违规
- **标识要求**:虚拟人广告须明确标注为AI生成

### 17.5 企业合规建议

1. 建立AI广告素材双重审核机制(合规审核+广告法审核)
2. 所有AI生成广告素材必须添加明确的AI生成标识
3. AI训练数据须确保有合法授权,避免使用他人商标/肖像
4. 直播脚本中涉及AI虚拟人须提前标注
5. 密切跟踪"三品一械"广告审查管理办法修订进展(修订中,预计更严格)

### 17.6 【2026-07-19新增】《广告引证内容执法指南》第17条——自证内容认定

> **来源:** 市场监管总局《广告引证内容执法指南》2026年第20号,2026年6月3日发布

**第17条核心规定:** 在广告中使用AI、深度合成等技术手段生成、合成的数据、资料、结论等内容 → 认定为**自证内容**

| 情形 | 认定类型 | 标注要求 |
|------|---------|---------|
| 广告主自行通过实验/测量/统计/调查等方式取得的数据 | 自证内容 | 可不表明出处(法另有规定除外),但须符合第9-13条要求 |
| 广告中使用AI/深度合成等技术生成/合成的数据/资料/结论 | **自证内容** | 可不表明出处,但须符合第9-13条要求 |
| 委托他人通过实验/测量/统计/调查等方式取得的数据 | 引证内容 | 须表明出处 |

**第9-13条核心要求(自证内容也须遵守):**
- 第9条:有适用范围/有效期限的须明确表示(实验复现条件/送检样品限制/地域行业范围)
- 第11条:不得利用减小字号/改变字体/相近颜色等方式限缩对消费者不利信息
- 第13条:绝对化用语豁免收紧(地域<省级/行业<国标/无专标均不豁免)

**第19条新增——广告经营者"应知"认定标准:**
- 接受委托开展实验/统计/调查等活动,明知或应知数据用于广告 → 认定为广告经营者
- **"应知"定义**:有**3次及以上**接受他人委托开展实验/统计/调查等活动,且数据在广告中被引用

**第16条——打击学术造假引流:**
- 广告主通过有偿新闻、学术造假等方式发表/发布有关新闻/学术文献/科研成果,再以其数据/结论作为广告引证内容
- 市场监管部门应向新闻出版、科技行业主管部门通报

## 十八、金融产品网络营销管理办法(2026年新增)

> **发布:** 2026年4月21日 | **实施:** 2026年9月30日
> **来源:** 中国人民银行、工业和信息化部、市场监管总局、金融监管总局、中国证监会、国家知识产权局、国家网信办、国家外汇局联合发布
> **公告编号:** 〔2026〕第9号

### 18.1 适用范围

- **金融机构**:经国务院或金融管理部门批准,在境内设立的从事金融业务的机构
- **金融产品**:存款、贷款、证券、资产管理产品、保险、贵金属、外汇产品、期货、衍生品、支付服务、投资顾问等
- **第三方互联网平台**:非金融机构自营的,为金融产品网络营销提供服务的网站、APP等

### 18.2 禁止性营销用语(营销版面审核重点)

**禁止使用以下诱导性用语:**
- ❌ "低风险" "低门槛" "秒到账" "高收益" "低利率" "无成本"
- ❌ 引用不真实、不准确或未经核实的数据和资料
- ❌ 明示或暗示保本、承诺收益、限定损失金额
- ❌ 简单依据短期/非常态业绩比较基准或过往业绩对产品进行展示排序
- ❌ 预测未来业绩,或利用模拟业绩、部分客户有利时段表现误导投资者
- ❌ 夸大保险责任或收益,将保险产品收益与存款、资管产品简单类比

### 18.3 营销行为规范

| 要求类别 | 具体规范 |
|---------|---------|
| 产品专区 | 存款、贷款、证券、资产管理、保险等多类别金融产品须分别设立宣传展示专区 |
| 算法推荐 | 不得设置诱导金融消费者和投资者过度消费的算法模型;须提供不针对个人特征的选项或关闭算法推荐选项 |
| 营销信息 | 向金融消费者发送营销信息或拨打营销电话,须提供拒收或退订选择;退订后不得再次发送 |
| 弹窗广告 | 须显著标明关闭标志并提供一键关闭功能 |
| 组合销售 | 不得默认同意,不得违法搭售金融产品 |
| 直播/短视频 | 须在金融机构自营平台或金融机构在第三方平台合法账号进行;营销人员须为金融机构从业人员 |

### 18.4 第三方互联网平台限制

- 不得超出金融机构委托范围,不得将委托业务转委托
- 为金融消费者购买金融产品提供转接渠道,须跳转至金融机构自营平台
- 在消费者即将进入购买环节时,应进行显著提醒并设置强制阅读时间
- 须加强对营销主体资质、资格核验,在账号主页展示金融业务资质认证材料

### 18.5 禁止行为

1. **非法金融活动营销**:任何机构和个人不得为非法金融活动提供网络营销服务
2. **私募类产品营销**:不得对私募类产品、场外衍生品开展面向不特定对象的网络营销
3. **非支付机构**:非银行支付机构不得将贷款、资管产品列入支付工具选项

### 18.6 违规处罚

- 金融机构违规:由金融管理部门采取出具警示函、监管谈话、责令整改、行政处罚等措施
- 第三方互联网平台违规:由网信部门、电信主管部门、市场监管部门依法处罚
- 涉嫌犯罪:依法移送司法机关追究刑事责任

## 十九、"清朗·整治AI应用乱象"专项行动(2026年新增)

> **部署时间:** 2026年4月30日 | **行动周期:** 为期4个月
> **来源:** 中央网信办印发通知

### 19.1 第一阶段:AI应用服务典型违规问题专项治理

**重点整治7类问题:**

1. **未按规定履行大模型备案登记义务** - 存在"应备未备"情形
2. **AI平台安全和审核过滤能力不足** - 模型底层安全能力缺失,价值导向偏差,缺乏安全围栏机制
3. **大模型训练语料安全问题** - 审核把关不严,使用未经授权的文字、图片、音视频数据
4. **AI数据投毒问题** - 篡改训练语料、伪造权威数据、使用GEO技术恶意营销
5. **生成合成内容标识落实不到位** - 未添加标识或标识不规范,未落实跨平台互识互认
6. **滥用AI技术开展违法违规活动** - 渗透入侵、恶意样本注入;未经授权提供"换脸拟声"服务
7. **开源模型安全管理不到位** - 缺乏身份认证和安全管理机制

### 19.2 第二阶段:整治AI信息内容乱象

**重点整治7类问题:**

1. **利用AI"魔改"经典、生成"数字泔水"** - 歪曲解构优秀传统文化、历史人物,植入低俗暴力内容
2. **制作发布虚假不实信息** - 涉时事政治、公共政策、社会民生等领域谣言;假冒党政军机关、新闻媒体
3. **假冒仿冒他人** - AI"换脸""换声"假冒公众人物;生成与公众人物合影、亲密照等
4. **制作发布暴力低俗等不良信息** - 暴力血腥、诡异猎奇、低俗擦边内容
5. **侵害未成年人权益** - 伤害恶搞未成年人形象,网络欺凌,"虐向""邪典"视频
6. **利用AI"托管"从事网络水军活动** - 模拟真人批量运营账号,刷量控评
7. **AI产品服务和应用程序违规** - 仿冒套壳AI网站,提供色情陪聊、"一键脱衣"、AI算命等违规功能

### 19.3 营销版面审核关注点

- AI生成广告素材须有明确标识("AI生成"等)
- 不得使用AI技术进行"换脸""拟声"制作广告
- 不得使用AI生成虚假信息用于产品营销
- 直播/短视频中涉及AI虚拟人须提前标注

## 二十一、奶粉运营专项合规规则(2026-05-13新增)

> 来源:奶粉运营培训专用PPT(2026-05-13)
> 整理:大崽

---

### 21.1 属性虚假宣传高风险项

| 错误宣传 | 正确做法 |
|---------|---------|
| 非有机写有机 | 确认有机认证资质 |
| 纯牛奶宣传"高蛋白" | 需≥3次检测报告方可宣称 |
| 低温奶宣传"鲜牛奶" | 低温奶≠鲜牛奶 |
| 零乳糖/成长牛奶宣传"纯牛奶" | 按实际属性标注 |
| 鱼油富硒奶粉宣传"低脂" | 核实产品是否满足低脂标准 |
| 牛奶属性写"进口" | 须标注具体来源国/牧场 |
| 冰淇淋棒写保质期100天(实际18个月) | 按实物标注 |
| 低脂奶宣传"低卡""低热量" | 所有液体奶均不属于低热量 |
| 零蔗糖酸奶宣传低卡 | 零蔗糖≠低卡 |
| 午餐肉/牛脆脆宣传低脂 | 核实脂肪含量 |

**参数虚假宣传高危项:**
- 低脂:须≤3g/100g,**除脱脂奶粉外所有奶粉均不满足**
- 高蛋白:仅限液体奶
- 低热量/低卡/0糖:所有产品均不属于
- **脱脂≠低脂**(不是同一概念)

### 21.2 功效宣传禁用语

| 禁用表述 | 合规替代 |
|---------|---------|
| 奶粉标题写"补钙" | 高钙 / 钙含量高 |
| 脱脂奶粉写"减肥""减脂" | 脱脂 / 轻盈 |
| 评论区内容宣传"增加免疫力" | 删除或标注"用户反馈" |
| 即食卤牛肉宣传"减脂" | 轻食 / 低脂 |
| 直播间宣传奶粉可以改善体质 | 营养丰富 / 健康之选 |
| 益生菌宣传促进肠道蠕动 | 益生菌 / 肠道菌群平衡(需证明) |
| 牛初乳宣传呵护免疫力 | 营养补充 |
| 涂磊直播间宣传"刮风下雨不怕" | 删除 |

**所有普通食品均不可按功效宣传表述:**
- 提升抵抗力/免疫力
- 保护肠道健康/保护眼睛
- 改善身体/缓解肠胃不适
- 长高 / 增强体力

**整治期:2026-03-06 至 2026-09-05**

|---------|-------------|
| "年纪大胃口差" | 消化功能衰退 / 老年健康问题 |
| "夜里难入眠白天没精神" | 失眠症 / 慢性疲劳 |
| "旅行走不远两步就喘气" | 心肺功能差 / 体力衰退 |

**认定标准:**

- 即使未明确声称功效,仍构成违规

**整改要求:**
- 新增物料:一律不允许使用
- 现有物料:建议2026-09-05前撤除

### 21.4 限时/促销标注规范(高频违规)

**违规场景:**

## 24. 食品标识监督管理办法(2025年发布,2027年3月16日实施)

**法规来源:** 国家市场监督管理总局令第100号

### 24.1 禁止标注内容(第七条)

1. 涉及疾病预防、治疗功能
2. 以欺骗、误导、夸大等方式作虚假描述
3. 违背科学常识、有违公序良俗、宣扬封建迷信
4. 标称"特供""专供""内供"党政机关或者军队等
5. **保健食品之外的其他食品不得在食品标识中声称具有保健功能(功效)**

### 24.2 婴儿配方食品特殊规定(第三十条)

- **0-6月龄**婴儿配方食品:不得在标签上进行含量声称和功能声称
- **6月龄以上**婴幼儿配方食品:不得对必需成分进行含量声称和功能声称

### 24.3 保健食品标识要求(第二十六条)

- 保健食品标签、说明书应当标明保健食品标志、保健食品注册号或者备案号
- 应设置警示用语区、标明警示用语
- 营养素补充剂产品还应当标明"营养素补充剂"字样

### 24.4 保健食品消费提示(第三十六条)

- 保健食品经营者应当在实体经营场所显著位置、网络销售保健食品主页面显著位置标注:
> **"保健食品不是药物,不能代替药物治疗疾病"**

### 24.5 文字字体高度要求(第十三条)

| 包装最大表面面积 | 营养成分表以外文字高度 |
|-----------------|----------------------|
| >150 cm2 | ≥2.0 mm |
| >400 cm2 | ≥2.5 mm |

生产日期和保质期到期日:字体高度≥3.0 mm(面积<35 cm2时≥2.0 mm)

### 24.6 瑕疵认定情形(第三十九条)

以下情形一般可认定为标签瑕疵,不按严重违法处理:
- 文字、符号、数字的字号、字体、字高不规范(错别字、多字、漏字、繁体字等)
- 净含量、规格标示方式和格式不规范
- 营养成分表数值修约间隔、"0"界限值、标示单位不规范
- 情节轻微,不影响食品安全,没有故意误导消费者

### 二、《广告绝对化用语执法指南》发布（2025年3月20日）

**核心要点：**
- 广告绝对化用语通常指《广告法》第九条第三项："国家级"、"最高级"、"最佳"以及含义相同或近似的其他用语
- **细化豁免情形，避免机械化执法：**
  1. 仅表明商品经营者的服务态度、经营理念、企业文化、主观愿望的
  2. 仅表达商品经营者目标追求的
  3. 绝对化用语指向内容与商品性能、质量无直接关联，且不会对消费者产生误导的
  4. 广告中使用的绝对化用语指向商品，但不具有误导消费者或贬低其他经营者客观后果的：
     - 仅用于对同一品牌或同一企业商品进行自我比较的
     - 仅用于宣传商品使用方法、使用时间、保存期限等消费提示的
     - 依据国家标准、行业标准、地方标准等认定的商品分级用语中含有绝对化用语的
     - 商品名称、规格型号、注册商标、专利中含有绝对化用语的
     - 依据国家有关规定评定的奖项、称号中含有绝对化用语的
     - 在限定具体时间、地域等条件下，表述时空顺序客观情况或宣传产品销量、销售额、市场占有率等事实信息的

### 23.2 第十三条合规检查流程

```
在广告中发现"最高级/最佳/第一"等用语？
    ↓
判断：是否为引证广告（引用第三方数据/结论）？
    ↓ 是 ↓
判断：是否满足以下任一情形？
  □ 地域<省级行政区域
  □ 行业分类<国家标准
  □ 无专有产品/服务标准
    ↓ 满足任一 ↓
结论：不属于绝对化用语豁免情形 → 虚假广告风险
    ↓ 不满足 ↓
仍需审查：是否真实、准确、有出处
```

### 23.3 AI生成广告专项（第十七条新规）

**重要变化：** 广告中使用AI/深度合成等技术手段生成的数据、资料、结论 → 认定为"自证内容"

**自证内容规则：**
- 可以不标明出处（法律法规另有规定除外）
- 但仍须满足第九至第十三条（适用范围/有效期/标注清晰度等）

**委托第三方 ≠ 自证：**
- 委托他人通过实验/测量/统计/调查取得 → 认定为引证内容（须标明出处）
- 明知或应知用于广告的 → 认定为广告经营者（共同责任）

## 二四、2026-06-29 《食品委托生产监督管理办法》重要更新

> **施行日期:** 2026年12月1日
> **来源:** 国家市场监督管理总局令（2026年发布）
> **链接:** https://www.gov.cn/gongbao/2026/issue_12646/202603/content_7064120.html

### 24.1 核心要点（一句话）

**委托方对委托生产的食品安全负主体责任，不能通过商标许可、特许经营等方式转嫁或免除。**

### 24.2 什么是食品委托生产

**第二条** 食品委托生产是指受托方按照**委托方的要求**，从事食品的全部或者部分环节的生产活动，并交付所生产食品的行为。

**采取商标许可、特许经营等方式生产食品，符合前款规定情形的，适用本办法。**

### 24.3 禁止转嫁责任

**第九条** 委托双方不得通过订立的委托生产合同，或者假借订立商标许可合同、特许经营合同等方式，**减轻或者免除自身依法应当承担的食品安全责任**。

**第二十三条** 委托方、受托方通过订立委托生产合同，或者假借订立商标许可合同、特许经营合同等方式，减轻或者免除自身依法应当承担的食品安全责任的：由县级以上地方市场监督管理部门责令改正，**处五万元以下罚款**。

### 24.4 委托方认定标准

**谁是委托方——判断标准：谁主导产品要求**

| 情形 | 委托方认定 |
|------|----------|
| 杭州生物掌握配方、技术资料、指定工艺和生产标准，A公司只要求放LOGO | 杭州生物（通过生物与工厂签署委托合同+明确约定产品要求提供方为生物） |
| 产品包装设计、配方、工艺标准由A公司指定 | A公司 |

### 24.5 不得委托生产的食品

**第三条** 根据法律法规、食品安全标准和食品生产许可有关要求，需要完整工艺生产的食品，**不得将部分环节委托生产**。

### 24.6 对认养一头牛的合规启示

**高风险场景：多方合作（品牌方+代工厂）**

| 风险点 | 建议 |
|-------|------|
| 委托生产合同未明确约定食品安全责任归属 | 立即审查现有合同，确保委托方责任不可转嫁 |
| 商标许可/特许经营合同中存在"免责条款" | 删除任何减轻/免除食品安全责任的条款 |
| 多方合作（品牌方+工厂）委托关系不清晰 | 梳理合作协议，明确谁是委托方及责任边界 |
| 代加工产品责任转嫁协议 | 核实是否存在违规的转嫁条款 |

**关键动作：**
1. 排查现有委托生产合同是否有效锁定了食品安全责任归属
2. 删除商标许可/特许经营合同中的"免责条款"（新法明确禁止）
3. 多方合作（品牌方+工厂）模式需要重新梳理委托关系
4. 关注2026年12月1日施行节点，提前完成合规整改
