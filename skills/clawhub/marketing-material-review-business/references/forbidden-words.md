## 十三、“无添加”“不含”“无”宣称规则（🔴高风险）

> 来源：2026-03-26【合规建议】关于宣称"无添加""不含""无"及其同义语的合规建议

### 13.1 定义

**"无添加"及其同义语：**
```
无添加、未添加、零添加、不添加、未使用、没加、没用、没使、没使用、未用
```

**"不含""无"及其同义语：**
```
零(0)、没有、0%、未含、零(0)含量、含量为0
```

### 13.2 禁用规则

1. **不得使用"无添加"及其同义语**
2. 使用"不含""无"时，相应配料或成分含量应为"0"
3. 国家食品法律法规允许添加但实际未添加的物质，才可宣称"不含""无"
4. 国家食品法律法规不允许添加到食品中的物质，**不得**使用"不含""无"宣称
5. 生产过程中原料含有某种物质，不得仅因非直接原料就宣称"不含""无"

### 13.3 合规表达格式

如需强调"0XX"，必须：
1. 提供检测报告（体现该成分含量为0或符合法规）
2. 增加标准注释：`【*XX含量未检出(依据GB XXXX 第X法)】`

**示例：**
| 宣称 | 标准注释 |
|------|---------|
| 0蔗糖 | 本产品蔗糖含量未检出（依据GB5009.8 第一法） |
| 0乳糖 | 本产品乳糖含量≤0.5g/100mL或g，符合GB 28050无乳糖标准 |
| 0色素、0香精、0防腐剂 | 本产品生产过程中未额外加入：人工合成色素、食用香精、食品防腐剂 |

## 十四、营养成分功能声称规则（🟡中-🔴高风险）

> 来源：2026-3-19【合规建议】营养成分功能声称的规定

### 14.1 保健功能红线（🔴最高风险）

**严禁任何明示或暗示涉及保健功能的宣称。**

**我国允许的保健功能（仅限保健食品）：**
```
有助于增强免疫力、有助于抗氧化、辅助改善记忆、缓解视觉疲劳、
清咽润喉、有助于改善睡眠、缓解体力疲劳、耐缺氧、有助于控制体内脂肪、
有助于改善骨密度、改善缺铁性贫血、有助于改善痤疮、有助于改善黄褐斑、
有助于改善皮肤水分状况、有助于调节肠道菌群、有助于消化、有助于润肠通便、
辅助保护胃黏膜、有助于维持血脂/血糖/血压健康水平、对化学性肝损伤有辅助保护作用、
对电离辐射危害有辅助保护作用、有助于排铅、有助于维持骨关节健康、补充维生素/矿物质
```

### 14.2 营养成分功能声称条件

**必须同时满足：**
1. 营养成分必须符合GB 28050附录D的宣称条件
2. 功能表述必须与附录D完全一致（不得删改、添加、合并）
3. 必须同时在营养成分表中标示该营养成分的含量及占NRV%

### 14.3 未涵盖营养成分规则

**GB 28050附录D中未规定的营养成分：**
1. 需权威文献支撑，且宣称需与文献完全一致
2. 文献涉及疾病治疗、预防功效及保健功能的**不得宣称**
3. 详情页同一页面不出现产品图，需有节点区分
4. 必须显著标明：`【*以上内容仅作为科普，不代表产品功效，请理性阅读】`
