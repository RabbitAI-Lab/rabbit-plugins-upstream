---

## 一、适用范围

**直播营销：** 通过互联网站、应用程序等网络直播平台，向公众推介商品或服务的行为

**适用主体：**
- 直播营销人员（主播）
- 直播间运营者
- 直播营销服务机构（MCN）
- 商品经营者
- 平台

---

## 二、直播营销人员要求

### 基本要求

| 要求 | 说明 |
|------|------|
| 真实身份 | 年满16周岁，真实身份信息 |
| 不得假冒 | 不得假冒他人名义 |
| 不得引流 | 不得导流到其他平台交易 |

### 禁止行为 🔴

| 禁止 | 说明 |
|------|------|
| 虚假宣传 | 夸大、虚构产品功效 |
| 刷单炒信 | 虚构观看人数、成交量 |
| 价格欺诈 | 先涨价后降价 |
| 假冒伪劣 | 销售假冒注册商标商品 |
| 违禁物品 | 销售法律法规禁止的商品 |
| 虚假承诺 | 虚假售后服务承诺 |

---

## 三、商品/服务宣传规范

### 禁止宣传内容 🔴

| 类型 | 示例 |
|------|------|
| 医疗效果 | 治病、防癌等 |
| 保健功能 | 增强免疫力、润肠等 |
| 绝对化用语 | 最佳、第一、顶级 |
| 虚假数据 | 夸大销量、功效 |
| 虚假代言 | 未使用却推荐 |

### 特殊品类要求 🟡

| 品类 | 要求 |
|------|------|
| 食品 | 不得宣称保健功能 |
| 化妆品 | 不得宣称医疗效果 |
| 医疗器械 | 需广告审查批文 |
| 药品 | 禁止直播推广 |

---

## 四、价格促销规范

### 合规要求 🟡

| 要求 | 说明 |
|------|------|
| 明示价格 | 标注商品价格 |
| 真实折扣 | 不得虚标原价 |
| 优惠说明 | 优惠券/红包使用条件 |
| 限时直播 | 标明促销时间 |

### 禁止行为 🔴

| 禁止 | 说明 |
|------|------|
| 价格欺诈 | 虚构原价、虚假优惠 |
| 先涨后降 | 活动前涨价 |
| 虚假最低价 | 非真实最低价宣传 |
| 捆绑销售 | 强制搭售 |

---

## 五、有奖销售规范

### 抽奖促销限额

| 奖项 | 最高价值 |
|------|----------|
| 单次最高奖项 | 不得超过5000元 |

### 合规公示 🟡

| 内容 | 要求 |
|------|------|
| 奖项设置 | 清晰标示 |
| 中奖概率 | 明确概率 |
| 兑奖条件 | 明确条件期限 |
| 中奖名单 | 定期公示 |

---

## 六、消费者权益保护

### 主播责任 🟡

| 责任 | 说明 |
|------|------|
| 知情权保障 | 真实介绍商品 |
| 选择权尊重 | 不得强制购买 |
| 退换货配合 | 配合售后问题 |
| 个人信息保护 | 不得泄露 |

### 直播间运营者责任 🟡

| 责任 | 说明 |
|------|------|
| 主体资质 | 依法取得经营资格 |
| 商品审核 | 审核商品合法性 |
| 宣传审核 | 审核宣传内容 |
| 售后服务 | 提供售后服务 |

---

## 七、平台责任

| 责任 | 说明 |
|------|------|
| 资质审核 | 审核入驻商家资质 |
| 内容监管 | 监测违规宣传 |
| 投诉处理 | 及时处理投诉 |
| 数据保存 | 保存直播内容三年 |

---

## 八、标识要求

### 直播营销标识 🟡

| 要求 | 说明 |
|------|------|
| 广告标识 | 付费推广需标明"广告" |
| 营销性质 | 明确商业推广性质 |
| 平台标识 | 符合平台规定 |

---

## 九、合规检查清单

### 直播前

- [ ] 主播身份真实有效
- [ ] 商品具有合法资质
- [ ] 宣传内容审核通过
- [ ] 促销规则明确

### 直播中

- [ ] 不得虚假宣传
- [ ] 不得夸大功效
- [ ] 价格真实透明
- [ ] 不得诱导交易

### 直播后

- [ ] 保留直播内容
- [ ] 处理售后问题
- [ ] 配合消费者维权

---

## 十、违规处罚

| 违规类型 | 处罚 |
|----------|------|
| 虚假宣传 | 罚款、吊销营业执照 |
| 价格欺诈 | 罚款、停业整顿 |
| 销售假冒商品 | 移送司法机关 |
| 违禁品销售 | 责令停止、罚款、吊销 |

**典型案例：**
- 网红直播夸大功效被罚
- 直播间价格欺诈被处罚
- 直播销售假冒伪劣被追究

## 十一、地方规定（浙江）

### 浙江省直播电商规范 🟡

| 要求 | 说明 |
|------|------|
| 主体登记 | 需办理市场主体登记 |
| 信息公示 | 公示经营信息 |
| 直播记录 | 保存直播视频不少于3年 |
| 投诉处理 | 建立投诉处理机制 |

---

## 十二、直播常见违规词

### 🔴 高风险词

| 类别 | 禁用词 |
|------|--------|
| 绝对化 | 第一、最佳、顶级、至尊 |
| 保健功能 | 增强免疫力、润肠、通便 |
| 疾病治疗 | 消炎、杀菌、抗癌 |
| 虚假承诺 | 无效退款、100%有效 |

### 🟡 中风险词

| 类别 | 谨慎用词 |
|------|----------|
| 极限促销 | 最低价、亏本销售 |
| 功效宣称 | 显著、明显改善 |
| 比较宣称 | 优于同类 |
