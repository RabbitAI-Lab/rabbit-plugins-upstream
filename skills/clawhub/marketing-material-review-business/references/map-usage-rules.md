# 中国地图使用合规规则

> 来源：关于规范使用中国地图的合规建议
> 更新日期：2026-04-10

---

## 一、法规依据

| 法规 | 要点 |
|------|------|
| 《地图管理条例》第十五条 |向社会公开的地图，应当报送审核 |
| 《地图管理条例》第二十二条 | 经审核批准的地图应显著标注审图号 |
| 《地图管理条例》第二十四条 | 不得出版不符合国家有关标准的地图 |
| 《广告法》第五十七条 | 违规发布广告罚款20-100万元 |

---

## 二、合规要求

### 🔴 禁止行为

| 禁止类型 | 说明 |
|---------|------|
| 手绘地图 | 鉴于手绘地图不准确，不能用于商业广告 |
| 未经审核的地图 |向社会公开的地图必须审核 |
| 无审图号地图 | 必须显著标注审图号 |
| 编辑后的地图 | 对标准地图进行放大、缩小、裁切、加注释等改动后需重新审核 |

### ✅ 合规使用

| 要求 | 说明 |
|------|------|
| 来源 | 仅使用自然资源部"标准地图服务系统"（http://bzdt.ch.mnr.gov.cn）的标准地图 |
| 审图号 | 必须显著标注审图号 |
| 格式 | JPG、EPS格式；幅面可选64开至对开 |
| 编辑 | 不得对标准地图进行任何编辑 |

---

## 三、审图号获取流程

1. 向自然资源主管部门提交地图审核申请
2. 提交材料：地图审核申请表、地图样图或样品、编制单位测绘资质证书
3. 审核通过后获得审图号
4. 在地图适当位置显著标注审图号

---

## 四、快速检查清单

- [ ] 地图是否来自标准地图服务系统？
- [ ] 地图是否标注了审图号？
- [ ] 地图是否未经编辑（放大/缩小/裁切/加注释）？
- [ ] 地图是否完整表达中国领土范围？
- [ ] 是否压盖重要岛屿等涉及国家主权的内容？
