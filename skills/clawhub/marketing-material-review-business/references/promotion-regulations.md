# 《规范促销行为暂行规定》核心条款

> 促销活动合规要点
> 依据：规范促销行为暂行规定（2020年）
> 更新日期：2026-04-10

---

## 一、总则

**适用范围：** 经营者折价、满减、买赠、抽奖等促销活动

**基本原则：**
- 合法正当
- 真实透明
- 规则明确

---

## 二、价格促销（第六条）🔴

### 禁止行为

| 禁止 | 示例 |
|------|------|
| 虚假折价 | 先涨价再打折 |
| 使用欺骗性价格标价 | 无依据划线价 |
| 不履行价格承诺 | 承诺最低价却不执行 |

### 合规要求

| 要求 | 说明 |
|------|------|
| 标示原价 | 标示真实参考价格 |
| 明示促销规则 | 促销条件、时间、方式 |
| 真实折扣 | 实际销售价格真实 |

---

## 三、促销广告（第七条）🟡

**促销广告应当：**

| 要求 | 说明 |
|------|------|
| 显著标明 | "促销"或"优惠" |
| 明示时间 | 促销起止日期 |
| 明示规则 | 参与条件、范围 |
| 不得虚假 | 不得欺骗性促销 |

---

## 四、有奖促销（第十条）🔴

### 禁止抽奖式促销

| 禁止 | 说明 |
|------|------|
| 烟草制品 | 不得作为奖品 |
| 麻醉药品等 | 禁止作为奖品 |
| 精子卵子等 | 禁止作为奖品 |

### 抽奖式促销限额

| 奖项设置 | 最高价值 |
|----------|----------|
| 最高奖项价值 | 不得超过5000元 |

### 合规公示要求

| 公示内容 | 说明 |
|----------|------|
| 奖项设置 | 奖项等级、数量 |
| 中奖概率 | 清晰标示 |
| 兑奖条件 | 领奖条件、期限 |
| 中奖名单 | 公示中奖名单 |

---

## 五、免担责任/最终解释权（第十五条）🔴

**禁止经营者：**

| 禁止内容 | 说明 |
|----------|------|
| "概不退换" | 侵犯知情权和选择权 |
| "保留最终解释权" | 违法格式条款 |
| 限制消费者权利 | 不得设定不公平条款 |

**合规表达：**
- 不得使用"概不退换"等绝对表述
- 退换货需符合《消保法》规定

---

## 六、特殊节日促销

| 节日 | 合规要点 |
|------|----------|
| 双11/618等 | 预售价不得高于活动期间售价 |
| 直播间专享价 | 需明确适用条件 |
| 限时秒杀 | 需标明数量、时间 |

---

## 七、促销合规检查清单

### 价格促销

- [ ] 标示原价，真实有依据
- [ ] 不得先涨价后打折
- [ ] 明示促销规则和时间
- [ ] 不得欺骗性价格标价

### 有奖促销

- [ ] 奖品不涉及禁止品类
- [ ] 最高奖项不超过5000元
- [ ] 公示奖项、中奖概率、兑奖条件
- [ ] 公示中奖名单

### 格式条款

- [ ] 不得使用"概不退换"
- [ ] 不得保留"最终解释权"
- [ ] 不得限制消费者合法权利

---

## 八、违规处罚

| 违规类型 | 处罚依据 |
|----------|----------|
| 虚假促销 | 《广告法》第28条 |
| 价格欺诈 | 《价格法》第14条 |
| 不当免责 | 《消保法》第26条 |

**罚款：** 二十万-一百万元（广告法）

---

## 九、直播促销特别规定 🟡

### 直播促销要求

| 要求 | 说明 |
|------|------|
| 真实返利 | 直播优惠需如实 |
| 明示条件 | 优惠券/红包使用条件 |
| 禁止刷单 | 不得虚构交易量 |
| 数据真实 | 不得虚假播放量 |

---

## 十、典型违规案例

| 违规 | 风险 |
|------|------|
| "最终解释权归本店" | 违法，侵犯消费者权益 |
| "概不退换"（限实体商品） | 违法，7日无理由退货除外商品除外 |
| 虚标原价 | 价格欺诈 |
| 奖品超5000元 | 违规有奖促销 |
| 烟草作为奖品 | 严重违规，禁止 |
