# 《中华人民共和国消费者权益保护法》核心条款

> 消费者权益保护核心要点
> 依据：中华人民共和国消费者权益保护法（2013年修订版）
> 更新日期：2026-04-10

---

## 一、消费者权利（第二章）

| 权利 | 内容 |
|------|------|
| 安全权 | 人身、财产安全 |
| 知情权 | 商品/服务真实情况 |
| 选择权 | 自主选择商品/服务 |
| 公平交易权 | 质量保障、合理价格 |
| 求偿权 | 人身财产损害赔偿 |
| 个人信息权 | 个人信息受保护 |
| 监督权 | 批评、建议、投诉、举报 |

---

## 二、经营者义务（第三章）🟡

### 基本义务

| 义务 | 内容 |
|------|------|
| 安全保障 | 确保人身财产安全 |
| 信息提供 | 真实、全面，不得虚假宣传 |
| 质量担保 | 符合说明/国家标准 |
| 退货义务 | 7日无理由退货（部分商品除外） |
| 不得设定不公条款 | 不得以格式合同限制消费者权利 |

---

## 三、虚假宣传（第二十条）🔴

**经营者向消费者提供有关商品或者服务的质量、性能、用途、有效期限等信息，应当真实、全面，不得作虚假或者引人误解的宣传。**

| 违规类型 | 示例 |
|---------|------|
| 虚假质量、性能、用途 | 与实际不符 |
| 引人误解宣传 | 模糊表述导致误解 |
| 不履行价格承诺 | 先涨价再打折 |
| 渗假质量表示 | 虚假认证标志 |

---

## 四、绝对化/虚假宣传处罚（第四十五条）🔴

| 情形 | 处罚 |
|------|------|
| 虚假宣传 | 没收违法所得，处违法所得一倍以上十倍以下罚款 |
| 无违法所得 | 处五十万元以下罚款 |
| 情节严重 | 责令停业整顿、吊销营业执照 |

---

## 五、"一"赔三"制度（第五十五条）🔴

**欺诈消费者行为的惩罚性赔偿：**

| 类型 | 赔偿标准 |
|------|----------|
| 欺诈行为 | 商品价款或服务费用的三倍 |
| 最低金额 | 不少于500元 |
| 明知缺陷仍销售 | 三倍赔偿（人身伤害适用） |

---

## 六、七日无理由退货（第二十五条）🟡

**不适用退货的商品：**

| 商品类型 | 示例 |
|---------|------|
| 定制商品 | 依消费者定制 |
| 鲜活易腐 | 生鲜食品 |
| 在线下载/拆封 | 数字商品、试听制品 |
| 报纸期刊 | 时效性商品 |
| 其他 | 消费者书面声明不退货 |

**退货要求：** 商品完好，经营者应退款

---

## 七、人身伤害赔偿（第四十九条）🔴

**经营者提供商品或者服务，造成消费者或者其他受害人人身伤害的，应当赔偿：**

| 项目 | 内容 |
|------|------|
| 医疗费 | 治疗费用 |
| 护理费 | 护理人员费用 |
| 交通费 | 合理交通费用 |
| 误工费 | 误工期间损失 |
| 造成残疾 | 残疾赔偿金、辅助器具费 |
| 造成死亡 | 丧葬费、死亡赔偿金 |

---

## 八、互联网消费权益（第四节）🟡

### 网络购物平台责任

| 情形 | 责任 |
|------|------|
| 平台不能提供销售者 | 平台赔偿 |
| 平台不能提供更有效联系方式 | 平台先行赔偿 |
| 平台作出更有利承诺 | 按承诺执行 |

### 个人信息保护

| 要求 | 说明 |
|------|------|
| 收集使用同意 | 需消费者同意 |
| 安全保障义务 | 防止信息泄露 |
| 泄露赔偿 | 应当赔偿损失 |

---

## 九、投诉举报（第五章）

| 途径 | 说明 |
|------|------|
| 协商和解 | 与经营者协商 |
| 调解 | 消费者协会调解 |
| 投诉 | 向行政部门投诉 |
| 仲裁 | 仲裁协议可申请仲裁 |
| 诉讼 | 向法院提起诉讼 |

---

## 十、审核检查清单

- [ ] 广告宣传内容真实，不得虚假
- [ ] 价格标示清晰，不得先涨后降
- [ ] 不得设定不公平格式条款
- [ ] 退换货政策合法合规
- [ ] 个人信息收集使用需同意
- [ ] 促销规则清晰透明
- [ ] 不得有欺诈行为
