# 《中华人民共和国广告法》核心条款

> 广告法核心审核要点
> 依据：中华人民共和国广告法（2022年修正版）
> 更新日期：2026-04-10

---

## 一、禁止情形（第九条）🔴

**广告不得有下列情形：**

| 条款 | 内容 | 风险等级 |
|------|------|----------|
| （一） | 使用或者变相使用中华人民共和国的国旗、国歌、国徽，军旗、军歌、军徽 | 🔴 最高 |
| （二） | 使用或者变相使用国家机关、国家机关工作人员的名义或者形象 | 🔴 最高 |
| （三） | 使用"国家级"、"最高级"、"最佳"等用语 | 🔴 最高 |
| （四） | 损害国家的尊严或者利益，泄露国家秘密 | 🔴 最高 |
| （五） | 妨碍社会安定，损害社会公共利益 | 🔴 最高 |
| （六） | 危害人身、财产安全，泄露个人隐私 | 🔴 最高 |
| （七） | 妨碍社会公共秩序或者违背社会良好风尚 | 🔴 最高 |
| （八） | 含有淫秽、色情、赌博、迷信、恐怖、暴力的内容 | 🔴 最高 |
| （九） | 含有民族、种族、宗教、性别歧视的内容 | 🔴 最高 |
| （十） | 妨碍环境、自然资源或者文化遗产保护 | 🔴 最高 |
| （十一） | 法律、行政法规规定禁止的其他情形 | 🔴 高 |

---

## 二、极限词/绝对化用语（第九条第三项）🔴

**禁止用语：**

```
最佳、最优、最、最大、最高级、最高端
顶级、顶尖、至尊、至臻、极致
第一、NO.1、TOP.1
首创、首家、独家
唯一、独占、绝无仅有
顶级品质、极致体验
史无前例、前所未有
```

**合规替代：**

| 禁用 | 替代 |
|------|------|
| 销量第一 | 销量领先 |
| 顶级品质 | 品质卓越/匠心品质 |
| 最佳 | 优良/优质 |
| 全网最低价 | 限时优惠/会员专享价 |

---

## 三、虚假宣传（第二十八条）🔴

**虚假或引人误解的内容：**

| 类型 | 示例 |
|------|------|
| 商品不存在 | 宣传不存在的功能/成分 |
| 性能与实际不符 | 夸大产品功效 |
| 虚假数据 | 无依据的百分比/排名 |
| 虚假荣誉 | 伪造检测报告/奖项 |
| 虚假产地 | 冒充原产地 |

**处罚：** 二十万元以上一百万元以下罚款

---

## 四、医疗、药品广告（第十六条）🔴

**禁止内容：**

- 表示功效、安全性的断言或保证
- 说明治愈率或有效率
- 与其他药品、医疗器械的功效和安全性比较
- 利用广告代言人推荐、证明
- 军队单位或人员名义形象

---

## 五、保健食品广告（第十八条）🔴

**禁止内容：**

- 表示功效、安全性的断言或保证
- 涉及疾病预防、治疗功能
- 声称或暗示为必需品
- 利用代言人推荐

**合规要求：**
- 必须显著标明"保健食品不是药物，不能代替药物治疗疾病"
- 必须标明警示语

---

## 六、普通食品广告（第二十八条）🔴

**红线：**

| 禁止宣称 | 说明 |
|---------|------|
| 保健功能 | 不得宣称增强免疫力、润肠等 |
| 疾病治疗 | 不得暗示对疾病有治疗作用 |
| 医疗术语 | 不得使用消炎、降压等 |

---

## 七、广告代言人（第三十八条）🟡

| 类型 | 要求 |
|------|------|
| 医疗、药品、医疗器械 | 不得使用代言人 |
| 保健食品 | 不得使用代言人推荐 |
| 虚假宣传受损者 | 不得使用代言人 |

---

## 八、未成年人相关（第四十条）🔴

**禁止：**

- 诱导未成年人请求家长购买
- 广告不应在针对未成年的媒体发布
- 不得含有劝诱饮酒内容
- 不得含有赌博内容

---

## 九、互联网广告（第四十四条）🟡

| 要求 | 说明 |
|------|------|
| 显著标明"广告" | 付费搜索需标明 |
| 一键关闭 | 弹窗广告需能一键关闭 |
| 发送拒绝 | 未经同意不得发送电子广告 |

---

## 十、处罚标准

| 情形 | 罚款 |
|------|------|
| 第九条禁止情形 | 二十万-一百万元 |
| 虚假宣传 | 二十万-一百万元 |
| 童化代言人 | 二十万-一百万元 |
| 情节严重 | 吊销营业执照 |

---

## 十一、审核检查清单

- [ ] 无"国家级"、"最佳"等绝对化用语
- [ ] 无保健功能宣称
- [ ] 无疾病治疗暗示
- [ ] 虚假宣传内容
- [ ] 数据有权威来源
- [ ] 地图使用合规
- [ ] 代言人合规
- [ ] 显著标明"保健食品不是药物"
