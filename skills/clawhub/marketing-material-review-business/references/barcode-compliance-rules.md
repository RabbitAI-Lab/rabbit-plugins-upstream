# 商品条码合规规则（参考库）

> **更新时间**：2026-07-07  
> **适用场景**：产品包装、多层包装（内包/中包/礼盒）、集团-子公司条码使用、委托加工  
> **重要性**：🔴 高风险（违反《商品条码管理办法》可处罚款 + 责令改正）

---

## 一、法规依据

### 1. 核心法规

| 法规 | 关键条款 | 说明 |
|------|---------|------|
| **《商品条码管理办法》**（总局令第76号，最新2026年修正版，依据总局令第127号）| 第六条、第十一条、第十四条 | 商品条码注册、编码、印制、应用的总体规范 |
| **新版《商品条码管理办法（征求意见稿）》**（2025-12-25）| 新增质量责任主体原则 | 强化"谁担责用谁码"原则 |
| **GB 12904-2008《商品条码 零售商品编码与条码表示》** | 4.2 编码原则 | 强制性国家标准 |
| **GB/T 16830-2008《商品条码 储运包装商品编码与条码表示》** | — | 推荐性国标 |
| **GB/T 15425-2014《商品条码 128条码》** | — | 推荐性国标 |

### 2. 核心规则提炼

**一物一码原则**（GB 12904 4.2.1）：
- 一个商品项目只能编一个代码
- 一个代码只能标识一个商品项目
- 禁止"一物多码"或"一码多物"

**基本特征变化原则**：
- 规格、净含量、包装、品牌、剂型等任一变化 → 必须编码新的商品项目代码

**质量责任主体原则**（新版征求意见稿）：
- 商品上应当使用**对商品承担质量责任的系统成员**的商品条码
- 委托他人生产 → 使用**委托方**注册的厂商识别代码
- 必须**明示委托关系**

**集团/子公司条码规则**（管理办法第六条）：
- 集团公司中具有独立法人资格的子公司需要使用商品条码的，**应当单独申请注册厂商识别代码**
- 经编码中心备案，子公司可使用集团授权的厂商识别代码（限于统一品牌同类产品）

**厂商识别代码有效期**：**2 年**，到期前 3 个月内办理续展

## 二、商品条码基础知识

### 1. EAN/UCC-13（GTIN-13）代码结构

```
X X X X X X X X X X X X X
└─┬─┘ └────┬────┘ └──┬──┘ └─┬─┘
  │        │         │      │
 前缀码  厂商识别代码  商品项目  校验码
(2-3位)  (7-10位)    代码     (1位)
```

| 段 | 长度 | 含义 | 分配主体 |
|---|------|------|---------|
| 前缀码 | 2-3 位 | 国家/地区代码（690-695 = 中国）| GS1 国际 |
| 厂商识别代码 | 7-10 位（含前缀码）| 标识企业身份 | 中国物品编码中心 |
| 商品项目代码 | 2-5 位 | 标识具体商品项目 | 企业自分配 |
| 校验码 | 1 位 | 校验整个编码的正确性 | 算法生成 |

### 2. 三种包装层级的条码关系

| 包装层级 | 是否独立销售 | 是否需要独立 GTIN | 备注 |
|---------|------------|----------------|------|
| **最小销售单元**（内包） | ✓ | ✓ | 必须有独立 GTIN |
| **组合销售单元**（4连包/6连包） | ✓（作为整体销售）| ✓（与内包 GTIN 不同）| 多个内包 + 组合外包装 |
| **礼盒/礼箱** | ✓（作为整体销售）| ✓（独立 GTIN）| 通常作为高端礼品 |
| **物流单元**（整箱） | ✗ | ✗（用 SSCC/ITF-14）| 不进入零售扫描 |

⚠️ **三种销售单元必须有 3 个不同 GTIN**，无论厂商识别码是否相同。

## 三、合规性核查清单

### ✅ 核查维度 1：厂商识别代码的合规性

| 核查项 | 合规标准 | 风险等级 |
|--------|---------|---------|
| 系统成员资格 | 厂商识别代码注册人必须是**中国商品条码系统成员** | 🔴 |
| 法人资格 | 集团子公司使用独立厂商识别码 → 子公司须有独立法人资格 | 🔴 |
| 资质匹配 | 使用条码的主体须对商品**承担质量责任** | 🔴 |
| 续展 | 厂商识别代码有效期 **2 年**，到期前 3 个月须续展 | 🟠 |
| 备案 | 子公司使用集团授权码 → 须经**编码中心备案** | 🟠 |

### ✅ 核查维度 2：一物一码原则

| 核查项 | 合规标准 | 风险等级 |
|--------|---------|---------|
| 销售单元独立编码 | 内包、组合包装、礼盒须分别独立 GTIN | 🔴 |
| 规格区分 | 不同规格（净含量）→ 独立 GTIN | 🔴 |
| 包装区分 | 不同包装形式（袋装/盒装/罐装）→ 独立 GTIN | 🔴 |
| 品牌区分 | 不同品牌 → 独立 GTIN | 🔴 |
| 配方区分 | 配方不同 → 独立 GTIN | 🟡 |

### ✅ 核查维度 3：质量责任主体一致性

| 核查项 | 合规标准 | 风险等级 |
|--------|---------|---------|
| 标签生产者信息 | 标签标注的生产者/委托者须与厂商识别代码主体**一致** | 🔴 |
| 委托关系明示 | 委托加工 → 标签上明示委托方/受托方 | 🔴 |
| 销售方资质 | 销售方若使用自己条码 → 须为系统成员 | 🟠 |
| 集团公司授权 | 子公司使用集团码 → 须有集团书面授权 + 编码中心备案 | 🟠 |

### ✅ 核查维度 4：条码物理质量

| 核查项 | 合规标准 | 风险等级 |
|--------|---------|---------|
| 条码等级 | GB 12904 第 9 章要求，符号等级 ≥ C 级（推荐 ≥ B 级）| 🟠 |
| 颜色搭配 | 条码颜色须符合 GB 12904 6.2 要求 | 🟡 |
| 尺寸 | 放大系数须符合 GB 12904 6.1 要求 | 🟡 |
| 放置位置 | 符合 GB/T 14257 要求 | 🟡 |
| OCR 识别 | 字体、对比度、清晰度 | 🟡 |

## 四、典型场景合规分析

### 场景 1：集团统一条码 vs 子公司独立条码

**情形**：集团 A + 子公司 B（独立法人）共同生产/销售同一类产品

| 方案 | 合规性 | 说明 |
|------|--------|------|
| 子公司 B 单独注册厂商识别码 | ✅ 合规 | 须 B 独立申请系统成员资格 |
| 子公司 B 经集团授权使用 A 的厂商识别码 | ⚠️ 须备案 | 须经编码中心备案，限于统一品牌同类产品 |
| 子公司 B 未经注册使用 A 的厂商识别码 | ❌ 违规 | 违反《管理办法》第六条 |

### 场景 2：多层包装（内包 + 4连包 + 礼盒）

**情形**：同一产品有 3 种销售单元

| 包装 | 推荐条码方案 | 合规性 |
|------|------------|--------|
| **内包**（单品销售）| 集团厂商识别码 + 独立项目代码 | ✅ |
| **4连包**（组合销售）| 集团/子公司厂商识别码 + **不同**项目代码 | ⚠️ 取决于质量责任主体 |
| **礼盒**（高端礼品）| 集团厂商识别码 + **不同**项目代码 | ✅ |

⚠️ **三种包装的 GTIN 必须互不相同**，即便厂商识别码相同，项目代码也不能复用。

### 场景 3：4连包用子公司"生物"条码是否合规？

**关键判断**：4连包的真实质量责任主体是谁？

| 情形 | 合规性 | 应使用条码 |
|------|--------|----------|
| "生物"是4连包真实生产/包装责任方 | ✅ | "生物"条码 |
| "生物"是受集团委托加工4连包 | ❌ | 应使用**集团条码**（委托加工用委托方代码）|
| "生物"仅是销售商，无生产参与 | ❌ | 不能用"生物"条码 |
| 代工厂生产，委托方未定 | ❌ | 须先确定质量责任主体 |

### 场景 4：委托加工

**情形**：A 委托 B 代为加工产品

| 核查项 | 合规要求 |
|--------|---------|
| 条码使用 | 使用**委托方 A** 的厂商识别代码及相应商品条码 |
| 标签标识 | **明示委托关系**（如"委托方：A；受托方：B"）|
| 责任承担 | 商品质量责任由委托方 A 承担 |
| 例外 | 若受托方 B 依法独立承担质量责任 → 可用 B 的条码（须明示）|

### 场景 5：电商平台条码识别

**情形**：产品多渠道销售（线下 + 电商）

| 核查项 | 说明 |
|--------|------|
| 同一产品多平台销售 | 须使用**同一 GTIN**（一物一码原则）|
| 平台 SKU 与 GTIN 关系 | 平台 SKU 可不同，但 GTIN 必须一致 |
| 跨境电商 | 须符合目的国条码规则 |
| 海外条码 | 须使用目的国前缀码（如美国用 000-019）|

## 五、常见违规情形与处罚

### 1. 常见违规情形

| 违规类型 | 具体表现 | 风险等级 |
|---------|---------|---------|
| **未经核准使用厂商识别码** | 未注册中国商品条码系统成员即使用条码 | 🔴 |
| **一物多码** | 同一商品使用多个条码 | 🔴 |
| **一码多物** | 一个条码标识多个商品 | 🔴 |
| **转让/出租厂商识别代码** | 厂商识别代码作为资产被转让 | 🔴 |
| **条码与商品信息不符** | 条码对应的商品信息与实际销售商品不一致 | 🔴 |
| **未续展使用过期条码** | 厂商识别代码有效期届满未续展 | 🟠 |
| **委托加工用错条码** | 委托加工场景未使用委托方代码 | 🔴 |
| **集团子公司未备案使用集团码** | 子公司使用集团码未经编码中心备案 | 🟠 |
| **条码质量不合格** | 符号等级低于 C 级、尺寸不合规 | 🟡 |
| **条码位置不当** | 放置位置影响扫描 | 🟡 |

### 2. 处罚依据

《商品条码管理办法》第三十二条：
- 责令改正
- 根据不同情况处以罚款
- 销售者进货时未查验系统成员证书 → 责令改正

## 六、版面审核中的条码核查重点

### 1. 审核时必查项

**A. 包装设计阶段**
- [ ] 包装上是否设计了商品条码
- [ ] 条码符号等级是否符合 GB 12904 要求（≥ C 级，推荐 ≥ B 级）
- [ ] 放大系数是否符合规范（通常 0.8-2.0）
- [ ] 颜色搭配是否合规（条+底色对比度足够）
- [ ] 条码放置位置是否便于扫描（避免曲面、转折处）
- [ ] OCR 字符是否清晰（人眼可识别数字）

**B. 标签内容合规性**
- [ ] 标签上的"生产者"或"委托者"信息是否与厂商识别代码主体一致
- [ ] 委托加工场景是否明示委托关系
- [ ] 集团/子公司条码使用是否符合《管理办法》第六条

**C. 多层包装方案**
- [ ] 内包、组合包装、礼盒是否分别独立 GTIN
- [ ] 商品项目代码是否独立（一物一码）
- [ ] 厂商识别代码选择是否符合质量责任主体原则

### 2. 风险标注规范

| 风险等级 | 标注方式 | 触发情形 |
|---------|---------|---------|
| 🔴 高风险 | 红色框 + 红色说明 | 一物多码 / 厂商识别码与生产者不符 / 未经注册使用 |
| 🟠 中风险 | 黄色框 + 黄色说明 | 委托关系未明示 / 厂商识别码未续展 / 符号等级边缘 |
| 🟡 低风险 | 绿色框 + 绿色说明 | 颜色搭配欠佳 / OCR 字符清晰度边缘 |

### 3. 常见审核案例

**案例 1：礼盒+内包+4连包条码混乱**
- ❌ 礼盒、内包、4连包共用同一项目代码 → 一物多码违规
- ✅ 三种包装分别独立 GTIN（项目代码必须不同）

**案例 2：子公司未经备案使用集团码**
- ❌ 集团授权但未编码中心备案 → 违规
- ✅ 集团书面授权 + 编码中心备案 + 统一品牌同类产品

**案例 3：委托加工标签未明示**
- ❌ "X 公司出品"但实际为委托加工 → 隐瞒委托关系违规
- ✅ 标签明示"委托方 X / 受托方 Y"

**案例 4：厂商识别码过期**
- ❌ 厂商识别码有效期届满后未续展 → 条码被注销 → 销售违规
- ✅ 到期前 3 个月内续展

**案例 5：扫码显示与标签不一致**
- ❌ 扫码显示集团 A，但标签标注子公司 B → 信息不一致
- ✅ 厂商识别代码主体、标签信息、扫码查询信息三者一致

## 八、常见问题 FAQ

**Q1：集团厂商识别码和子公司厂商识别码能否混用？**
A：不能。同一商品只能使用一个厂商识别码，且厂商识别代码主体须与质量责任主体一致。

**Q2：内包和礼盒能用同一个项目代码吗？**
A：不能。两种不同的销售单元必须有独立的 GTIN-13（包括不同的项目代码）。

**Q3：子公司"生物"能否直接借用集团厂商识别码？**
A：原则上须单独注册；如需使用集团码须经编码中心备案。

**Q4：委托加工的产品条码用委托方还是受托方？**
A：原则上用委托方。受托方独立承担质量责任的例外。

**Q5：商品条码有效期是多久？**
A：厂商识别代码有效期为 **2 年**，到期前 3 个月内办理续展。

**Q6：扫描显示"未找到商品信息"是否意味着条码违规？**
A：不一定。新产品 GTIN 注册到 GS1 数据库有滞后，但厂商识别代码主体与标签信息一致是基础要求。

**Q7：组合包装（4连包）是否必须有独立 GTIN？**
A：是的。组合包装作为独立销售单元，须有独立 GTIN，且与内包 GTIN 不同。

**Q8：电商平台 SKU 与商品条码 GTIN 是什么关系？**
A：SKU 是平台内部管理用，GTIN 是商品全球唯一身份标识。一款商品在不同平台可有不同 SKU，但 GTIN 必须一致。
