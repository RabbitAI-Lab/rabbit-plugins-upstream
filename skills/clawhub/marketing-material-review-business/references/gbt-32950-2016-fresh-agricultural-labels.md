# GB/T 32950-2016《鲜活农产品标签标识》

**标准性质：** 推荐性国家标准（GB/T）  
**发布日期：** 2016-08-29  
**实施日期：** 2017-03-01  
**发布机构：** 中华人民共和国国家质量监督检验检疫总局、中国国家标准化管理委员会

---

## 1. 适用范围

本标准规定了**鲜活农产品**标签标识的术语和定义、基本要求、标签标注内容及制作要求。

适用于以下鲜活农产品：
- 新鲜水果
- 新鲜蔬菜
- 肉类
- 鲜活水产品
- 蛋类
- 鲜奶
- 活畜禽
- 及其他新鲜农产品

---

## 2. 核心术语

| 术语 | 定义 |
|------|------|
| 鲜活农产品 | 新采摘的未经加工或仅做简单保鲜处理的农作物、畜禽、水产品 |
| 标签标识 | 产品上用于识别产品特征、属性、产地、生产者等信息的文字、符号、图案 |
| 产地 | 农产品的生产或采集地 |

---

## 3. 基本要求

### 3.1 标签标识基本原则
- **真实性** — 标签内容必须真实、准确，不得虚假宣传
- **合法性** — 符合国家相关法律法规要求
- **可识别性** — 文字清晰、图案明确，便于消费者识别
- **规范性** — 使用规范汉字，计量单位符合国家标准

### 3.2 标签标注方式
- 可采用**附着于产品、产品包装、产品容器或附带说明书**等方式
- 标签应牢固，不易脱落或模糊

---

## 4. 标签标注内容

### 4.1 必须标注项目（强制）

| 项目 | 要求 |
|------|------|
| 产品名称 | 应使用标准名称或常用名称，不得使用方言或易混淆的名称 |
| 产地 | 标注至地市级或以上，或按相关规定标注 |
| 生产日期/包装日期 | 必须标注，字迹清晰 |
| 净含量/规格 | 按规定标注计量单位 |
| 生产者或经销商名称、地址 | 必须标注 |

### 4.2 推荐标注项目

| 项目 | 说明 |
|------|------|
| 产品等级 | 按相关标准标注等级 |
| 质量/品质指标 | 如甜度、成熟度等 |
| 贮存条件 | 温度、湿度等特殊要求 |
| 保质期 | 最短保质期 |
| 食用方法 | 必要时提供 |
| 联系方式 | 客服电话等 |
| 产地编码 | 便于追溯 |

### 4.3 可选标注项目

- 品牌名称/商标
- 认证标志（有机、绿色、无公害等，需认证）
- 营养成分表
- 产品标准号
- 采摘日期/捕捞日期
- 养殖/种植方式

---

## 5. 特殊要求

### 5.1 转基因农产品
- 应标注"转基因"字样
- 标注转基因成分及含量（如适用）

### 5.2 地理标志产品
- 应标注地理标志专用标志
- 不得擅自使用地理标志名称

### 5.3 有机产品/绿色食品
- 必须标注认证标志和认证机构
- 需在包装有效期内

### 5.4 进口农产品
- 标注原产国（地区）
- 标注进口商/经销商信息
- 标注生产日期（国外原产日期或国内分装日期）

---

## 6. 标签制作要求

| 要求项 | 具体规定 |
|--------|----------|
| 文字高度 | 主标题不小于3mm，说明文字不小于1.8mm |
| 颜色对比 | 标签颜色与底色对比明显，便于识别 |
| 计量单位 | 使用国家法定计量单位 |
| 语言文字 | 必须使用规范汉字，进口产品可同时使用外文 |
| 字符高度 | 净含量数字高度不小于2mm |
| 耐候性 | 标签应具有一定的防水、防晒、耐磨性 |

---

## 7. 与营销版面审核相关要点

### 合规风险点

| 风险类型 | 示例 | 合规建议 |
|---------|------|---------|
| 虚假产地标注 | 标注"新疆哈密瓜"实际非新疆产 | 必须真实标注产地 |
| 虚假等级标注 | 标注"特级"但无依据 | 按实际等级标注 |
| 虚假认证标注 | 标注"有机"但未认证 | 未认证不得标注 |
| 夸大宣传 | 标注"纯天然"但实际使用了农药 | 不得虚假宣传 |
| 营养声称违规 | 普通食品标注保健功能 | 普通农产品不得宣称保健功能 |

### 营养成分表示要求

- 鲜活农产品**可自愿标注**营养成分
- 如标注，应符合GB 28050《预包装食品营养标签通则》
- 不得标注具有治疗、预防疾病功能的内容

###  广告法关联

- 鲜活农产品标签属于**广告**范畴，受《广告法》约束
- 不得使用绝对化用语（"第一"、"最佳"、"顶级"等）
- 不得虚假或引人误解的宣传
- 不得使用国家机关名义进行宣传

## 9. 违规处罚

违反本标准要求的，依据《产品质量法》、《广告法》等法律法规处罚：
- 责令改正
- 罚款
- 没收违法所得
- 情节严重吊销营业执照
