# GB 7718—2025 食品安全国家标准 预包装食品标签通则

## 一、基本信息

| 项目 | 内容 |
|------|------|
| **标准名称** | 食品安全国家标准 预包装食品标签通则 |
| **标准编号** | GB 7718—2025 |
| **发布日期** | 2025-03-16 |
| **实施日期** | 2027-03-16（过渡期两年） |
| **发布机关** | 中华人民共和国国家卫生健康委员会、国家市场监督管理总局 |
| **代替标准** | GB 7718—2011《食品安全国家标准 预包装食品标签通则》 |

---

## 二、适用范围

本标准适用于：
- 直接提供给消费者的预包装食品标签
- 非直接提供给消费者的预包装食品标签

**不适用于**：
- 为食品在储藏、运输过程中提供保护的食品储运包装标签
- 散装食品和现制现售食品的标识

---

## 三、术语和定义

| 术语 | 定义 |
|------|------|
| **预包装食品** | 预先包装或者制作在包装材料、容器中的食品 |
| **食品标签** | 食品包装上的文字、图形、符号及一切说明物 |
| **数字标签** | 食品包装上采用二维码等信息化手段展示的食品标签 |
| **配料** | 制造或加工食品时使用的任何物质，包括食品添加剂 |
| **生产日期** | 食品成为最终产品的日期 |
| **保质期** | 预包装食品在标签标明的贮存条件下保持品质的期限 |
| **规格** | 同一预包装内含有多件预包装食品时，对净含量和内含件数关系的表述 |

---

## 四、基本要求

1. **合法性**：应符合法律、法规和相应食品安全标准的规定
2. **清晰醒目持久**：使消费者易于辨认和识读，不应与食品或包装物分离
3. **科学性**：不得标示违背科学常识、公序良俗、贬低其他食品、封建迷信等内容
4. **真实准确性**：不得使用虚假、夸大等欺骗性语言文字、图形、符号
5. **保健功能禁止**：不得以任何方式明示或暗示食品具有预防、治疗疾病的作用；非保健食品不得明示或暗示具有保健功能
6. **文字规范**：应使用规范汉字；可同时使用繁体字、拼音、少数民族文字和外文（商标、邮箱、网址除外）

## 六、食品名称标示要求

### 6.1 属性名称要求

- 应在食品标签的醒目位置标示反映食品真实属性的名称
- 属性名称指能反映食品本身固有特性的专用名称

### 6.2 名称选择顺序

1. 优先选用国家标准、行业标准、地方标准、相关部门公告中已规定或采用的名称
2. 无标准名称时，使用能充分说明食品真实属性且不易使消费者误解的名称

### 6.3 其他名称的标示

- 可同时标示"新创名称""奇特名称""音译名称""地区俚语名称"或"商标名称"
- 含有易使消费者误解、混淆食品属性的文字时，应在属性名称临近位置用相同字体标示属性名称

---

## 七、配料表标示要求

### 7.1 基本规则

- 各种配料应按加入量**递减顺序**一一排列
- 加入量不超过2%的配料可不按递减顺序排列
- 加工过程中已挥发或去除的配料可不在配料表中标示

### 7.2 复合配料标示

- 应标示复合配料的名称，随后将原始配料在括号内按递减顺序标示
- 已有国家标准、行业标准、地方标准，且加入量＜25% 时，可不标示原始配料

### 7.3 食品添加剂标示

| 情况 | 标示方式 |
|------|----------|
| 直接标示 | 食品添加剂通用名称 |
| 归类标示 | 功能类别名称 + 通用名称 |
| 包装面积 ≤60cm² | 可用 INS 号代替通用名称 |

> 同一预包装食品的标签上，只能选择一种标示形式。

---

## 八、配料强调与定量标示

### 8.1 特别强调时的定量标示

在食品标签上特别强调添加或含有一种或多种配料或成分时，应在配料表中**明示或附加文字说明**标示该配料或成分的添加量或在成品中的含量。

**名称提及要求**：食品名称中提及的配料或成分，应标示其添加量或在成品中的含量。

### 8.2 含量较低或无时的定量标示

特别强调一种或多种配料或成分的含量较低或无时，应标示其在成品中的含量。

**"无"声称要求**：
- 使用"无""不含"等词汇时，相应配料或成分含量应为"**0**"
- **食品添加剂、污染物、不得添加的物质，不得使用"无""不含"等词汇进行声称**

**"不添加"禁止性要求**：
> **不得使用"不添加""不使用"及其同义语等词汇**

---

## 九、致敏物质标示要求

### 9.1 必须标示提示的致敏物质

以下配料用作配料时应提示：

| 序号 | 致敏物质 | 备注 |
|------|----------|------|
| a | 含麸质的谷物及其制品 | 小麦、黑麦、大麦、燕麦等 |
| b | 甲壳纲类动物及其制品 | 虾、龙虾、蟹等 |
| c | 鱼类及其制品 | — |
| d | 蛋类及其制品 | — |
| e | 花生及其制品 | — |
| f | 大豆及其制品 | — |
| g | 乳及乳制品（含乳糖） | — |
| h | 坚果及其果仁类制品 | — |

### 9.2 可能带入的致敏物质

生产过程中可能带入致敏物质时（如共用生产车间），**鼓励**标示致敏物质提示信息。

## 十、营养标签

营养标签的标示范围及标示方式按照 **GB 28050** 或 **GB 13432** 执行。

---

## 十一、日期标示要求

| 情况 | 要求 |
|------|------|
| 基本要求 | 按年、月、日顺序清晰标示生产日期和保质期到期日 |
| 保质期 ≥6个月 | 可仅标示保质期和保质期到期日 |
| 包装面积 ≤20cm² | 可仅标示保质期和保质期到期日 |
| 不得加贴、补印、修改 | 日期不得与包装物分离 |

---

## 十二、辐照食品标示要求

| 情况 | 标示要求 |
|------|----------|
| 整个食品经辐照处理 | 应在食品名称临近位置标示"辐照加工食品"或"经辐照处理" |
| 配料经辐照处理 | 应在配料表中括号内标示"辐照"，或在配料表临近位置标示"经辐照处理" |

---

## 十三、进口食品特殊要求

| 要求 | 说明 |
|------|------|
| 中文标签 | 必须有印刷或加贴的中文标签 |
| 原产国（地区） | 必须标示 |
| 生产者信息 | 须标示进口商/代理商信息及境外生产企业注册编号 |
| 外文对应 | 所有外文标示内容须与中文有对应关系（商标等除外） |

---

## 十四、与营销版面审核相关的重点条款

### 14.1 禁止性内容（关键）

| 禁止类型 | 具体内容 |
|----------|----------|
| **虚假宣传** | 不得使用虚假、夸大等欺骗性语言文字、图形、符号介绍食品 |
| **误导消费者** | 不得利用字号大小、色差、版面设计等方式误导消费者将食品与另一产品混淆 |
| **疾病治疗暗示** | 不得以任何方式明示或暗示食品具有预防、治疗疾病的作用 |
| **保健功能虚假宣传** | 非保健食品不得明示或暗示具有保健功能 |
| **"无/不含"滥用** | 食品添加剂、污染物、不得添加的物质不得使用"无""不含"声称 |
| **"不添加"禁用** | **不得使用"不添加""不使用"及其同义语** |
| **违背公序良俗** | 不得标示封建迷信、贬低其他食品等内容 |

### 14.2 定量标示要求

| 情况 | 要求 |
|------|------|
| 特别强调添加的配料 | 必须标示添加量或含量 |
| 名称中提及的配料 | 必须标示添加量或含量 |
| 特别强调"含量低/无" | 必须标示具体含量 |

### 14.3 标签版面要求

- 食品名称应位于**醒目位置**
- 净含量应与食品名称在**同一展示版面**
- 标签不应与食品或包装物**分离**
- 字体高度要求（"纯牛/羊奶/乳"等）不小于主要展示面高度的**1/5**

---

## 十五、核心要点速查

| 场景 | 规则 |
|------|------|
| 宣传"无糖" | 糖含量必须 = 0，且糖指任何碳水化合物 |
| 宣传"不添加"某物质 | **禁止**，不得使用"不添加""不使用"等表述 |
| 宣传保健功能 | 非保健食品不得明示或暗示 |
| 使用外文 | 必须有对应中文 |
| 日期标示 | 不得加贴、补印、修改 |
