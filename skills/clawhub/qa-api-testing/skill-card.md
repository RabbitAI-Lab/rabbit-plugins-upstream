## Description:

Provides Chinese-language guidance for testing RESTful, GraphQL, gRPC, and WebSocket APIs, including test matrices, contract assertions, and tool selection.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kokxi](https://clawhub.ai/user/kokxi)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and QA engineers use this skill to design API test cases, contract checks, mock strategies, and security and performance test plans for documented interfaces.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Security and load-test suggestions could affect live services if run without review.

Mitigation: Review proposed tests and run them only against systems and environments you are authorized to test.

Risk: Full API request and response logs may expose sensitive data.

Mitigation: Redact credentials and personal data before saving or sharing test logs.
