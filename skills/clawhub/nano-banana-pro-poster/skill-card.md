## Description:

Uses Nano Banana Pro through AI Hive to generate or edit distinctive poster visuals with clear art direction, visual metaphors, composition, materials, and series variations.

This skill is ready for commercial/non-commercial use.

## Use Case:

External creators, marketers, designers, and agent operators use this skill to create campaign posters, music festival posters, fashion posters, sports event posters, holiday retail visuals, exhibition posters, series posters, and social covers. It guides the agent to define a visual premise, choose a primary metaphor and focal action, run AI Hive image generation, and check poster-series consistency.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can upload prompts and selected reference images to AI Hive.

Mitigation: Avoid private, sensitive, or unlicensed source material and keep rights records for people, brands, artists, and collaboration assets.

Risk: The skill can store an AI Hive API key locally through its interactive setup flow.

Mitigation: Use the documented setup flow or environment variable, keep the local config private, and rotate the key if it is exposed.

Risk: Generated posters may include visual drift or assets that are not suitable for final brand, print, or social use.

Mitigation: Review generated outputs for reference-image fidelity, brand/logo safety areas, contrast, bleed, text readability, and series consistency before publication.
