# 👓 glass2claw

**Ray-Ban glasses → voice command → WhatsApp → OpenClaw previews a user-selected route for the photo.**

Hands-free life logging for the agentic era.

## 🛠️ Installation

Install the owner-qualified release:
```bash
openclaw skills install @jonathanjing/glass2claw
```

## 📸 How It Works

1. **You see something**: A wine bottle, a business card, or a rare tea.
2. **You say**: *"Hey Meta, take a picture and send this to myself on WhatsApp."*
3. **OpenClaw previews**: The photo lands in your WhatsApp session and is classified locally where possible.
4. **You confirm**: OpenClaw shows the destination and intended write or cross-session forward before acting, unless you have explicitly enabled an allowlisted route for that named destination.

## Prerequisites

- **Meta Ray-Ban glasses** with Meta AI enabled.
- **WhatsApp** linked to your Meta View app.
- **OpenClaw** running with the WhatsApp channel active.

## Privacy boundaries

- Treat every image and extracted identifier as private input.
- Do not forward to another participant, session, database, or channel without consent.
- Keep persistence off by default and show the selected destination before a write.
