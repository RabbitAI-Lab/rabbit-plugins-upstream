· 商户自研适用场景：商户同时使用美团系统和其他业务系统（如业务中台），需要两套系统数据互通，且商户自身具备开发能力。执行步骤：①客户自研或委托外部研发团队；②完成开放平台入驻；③购买【供应链旗舰版-业务数据接口-1年-智能版】；④根据业务需要调用对应接口。方案三：业务对接 · 代仓（三方WMS）适用场景：商户供应链业务使用美团系统，但采购或仓储履约使用第三方系统或外包给第三方公司管理，需要美团与第三方业务系统协同才能跑通完整业务流程。常见场景包括：代仓代配、代采、三方WMS/ERP系统对接。执行步骤：已对接过的代仓直接开通点位配置即可；未对接过的代仓需获取接口文档后由技术评估，评估完成后按付费流程提交四、已支持的API列表1、API接口：供应链API列表2、消息列表：供应链消息列表五、接口说明与注意事项1、总部接口与门店接口的区别：总部接口具有集团级权限，可查询所有门店数据；门店接口仅能查询本门店数据。部分功能仅门店侧有接口（如菜品消耗单），总部侧无对应接口。2、接口类型说明：平台接口分为查询接口（主动拉取数据）、操作接口（执行业务动作）和消息接口（被动接收推送）三类。建议优先使用消息推送接口实现实时数据同步，减少轮询压力。3、小数精度处理：美团供应链支持6位小数，若外部财务系统支持更高精度，推送时直接传递即可；回调场景下，外部系统回传数值精度不得超过美团供应链支持的位数，否则将报错拒绝处理。4、采销与联营的区别：当前开放接口API未对采销和联营模式做区分。若业务逻辑无差异，可直接使用；若存在模式差异，暂不支持，需关注后续版本更新六、常见问题FAQQ：技术调用报错如何处理？A：请加入供应链开放平台答疑群，将问题发至群内，产研同学会进行解答（仅供内部使用）。Q：代仓对接是否需要额外费用？A：已对接过的代仓商户无需额外收费，直接开通点位配置即可使用；若是新的代仓系统，需要技术评估后按付费流程处理。Q：开放平台入驻流程是什么？A：商户或其研发团队需前往美团技术服务合作中心，按照业务合作流程指南完成入驻，之后购买对应的接口商品即可开始对接。详情见：如何入驻Q：如何购买接口？A：通过联系“美团销售”或“4006260106”购买接口商品一、业务说明二、对接前准备三、对接方案说明方案一：数据对接-商户自研方案二：业务对接
