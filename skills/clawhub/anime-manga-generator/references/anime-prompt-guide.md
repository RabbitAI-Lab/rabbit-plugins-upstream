# 二次元漫画生成 - 提示词工程指南

## 一、角色设计提示词模板

### 1.1 基础角色结构
```
【基础信息】性别、年龄范围（萝莉/少女/御姐/正太/少年）
【外貌特征】发型+发色、瞳色瞳型、身高体型
【服装装备】风格（校服/和服/战斗服/日常）、颜色、配饰
【性格气质】通过表情、姿态、氛围体现
```

### 1.2 常见角色类型关键词

**少女系**
- 萝莉: 幼态、圆脸、大眼睛、娇小身材
- 少女: 青春活力、明亮眼神、自然姿态
- 御姐: 成熟优雅、冷艳气质、修长身材

**少年系**
- 正太: 可爱幼态、圆润特征
- 少年: 阳光帅气、运动感
- 成熟男性: 棱角分明、稳重气场

### 1.3 发型发色参考

| 类型 | 关键词 |
|------|--------|
| 短发 | 短发、波波头、碎发、刺猬头 |
| 中长发 | 及肩发、内扣、微卷 |
| 长发 | 直长发、波浪卷、双马尾、单马尾、麻花辫 |
| 特殊 | 呆毛、猫耳发、渐变色、挑染 |

**发色**
- 自然色: 黑色、棕色、金色、银白色
- 动漫色: 粉色、蓝色、紫色、红色、绿色、渐变

### 1.4 服装风格库

**日常类**
- 校服: 日式水手服、西装制服、针织背心裙
- 休闲: T恤牛仔裤、卫衣、连衣裙
- 和服: 振袖、浴衣、巫女服

**幻想类**
- 魔法: 法师袍、魔法少女装、斗篷
- 战斗: 机甲服、战斗装甲、忍者装束
- 奇幻: 精灵装、龙骑士铠甲、公主裙

**特色类**
- 女仆: 女仆装、围裙、头饰
- 洛丽塔: 蕾丝边、蝴蝶结、蓬蓬裙
- 哥特: 黑色系、十字架、蕾丝

## 二、场景与背景提示词

### 2.1 自然场景

**天空类**
- 晴空蓝天、晚霞火烧云、星空银河、彩虹
- 云层细节: 积云、卷云、流云、云海

**植物类**
- 樱花飘落、枫叶红叶、向日葵花田

**水域**
- 海边沙滩、湖面倒影、雨后水洼反光
- 瀑布、溪流、水下场景

### 2.2 建筑场景

**西式**

**现代**
- 都市夜景霓虹、天台夕阳、便利店

### 2.3 奇幻场景

- 浮空岛、水晶洞穴、魔法阵
- 龙的巢穴、精灵之森、未来都市
- 异世界传送门、星空战场

## 三、画风与艺术风格

### 3.1 主流动画风格

| 风格 | 关键词 | 特点 |
|------|--------|------|
| 日系萌系 | 大眼、柔和线条、粉嫩色调 | 可爱治愈 |
| 新海诚 | 细腻光影、真实感背景、高饱和度 | 唯美写实 |
| 吉卜力 | 手绘质感、温暖色彩、自然主题 | 温馨治愈 |
| 京阿尼 | 精致作画、细腻表情、日常感 | 高质量 |
| 厚涂 | 油画质感、强烈明暗对比 | 戏剧性 |

### 3.2 特殊画风

- **赛璐璐**: 平涂上色、清晰轮廓线、动画感强
- **水彩**: 透明感、晕染效果、淡雅清新
- **像素风**: 复古游戏感、点阵图案、8-bit/16-bit
- **低多边形**: 几何块面、简约现代、3D感

### 3.3 光影与氛围

**光线方向**
- 顺光: 明亮清晰、正面照明
- 侧光: 立体感强、戏剧性
- 逆光: 剪影效果、神圣感
- 顶光: 强烈对比、神秘感

**时间氛围**
- 清晨: 淡蓝调、薄雾、柔光
- 正午: 明亮、硬阴影、高对比
- 黄昏: 橙金色调、长影子、温暖
- 夜晚: 深蓝紫调、月光、星光、霓虹

**天气氛围**
- 晴天: 明亮通透、蓝天白云
- 雨天: 湿润反光、朦胧、忧郁
- 雪天: 白色纯净、柔和散射光
- 雾气: 神秘、层次感、虚实结合

## 四、构图与视角

### 4.1 景别

- **特写**: 面部/手部细节、情感表达
- **近景**: 胸部以上、突出表情
- **半身**: 腰部以上、展示上身姿态
- **全身**: 完整人物、展示服装动作
- **群像**: 多人构图、关系互动

### 4.2 视角

- 平视: 自然亲切、常规视角
- 俯视: 渺小感、展示环境全貌
- 仰视: 英雄感、压迫感、高大形象
- 45度角: 立体感强、动态感
- 鸟瞰: 全局视野、战略感

### 4.3 构图法则

- **三分法**: 主体放在交叉点
- **中心对称**: 稳重正式
- **对角线**: 动态张力
- **框架构图**: 利用前景框住主体
- **留白**: 简洁意境、想象空间

## 五、表情与动作

### 5.1 常见表情

| 表情 | 关键词 | 适用场景 |
|------|--------|----------|
| 开心 | 微笑、眯眼笑、大笑 | 友好、幸福 |
| 害羞 | 脸红、低头、眼神躲闪 | 恋爱、尴尬 |
| 生气 | 皱眉、咬牙、怒目 | 冲突、决心 |
| 惊讶 | 张嘴、瞪大眼、后退 | 突发事件 |
| 悲伤 | 泪眼、低头、嘴角下垂 | 离别、失落 |
| 冷酷 | 无表情、斜视、冷漠 | 高冷角色 |

### 5.2 动作姿势

**静态姿势**
- 站立: 双手叉腰、背手、抱臂
- 坐姿: 跷腿、托腮、侧坐
- 躺卧: 仰卧、侧躺、趴着

**动态动作**
- 奔跑: 追逐、逃离、冲刺
- 战斗: 挥剑、施法、格挡
- 舞蹈: 旋转、跳跃、伸展
- 日常: 挥手、指路、拥抱

## 六、高级技巧

### 6.1 角色一致性保持

生成系列图像时，固定以下元素：
```
核心特征锁:
- 发型发色（精确描述）
- 瞳色瞳型
- 标志性配饰/服装
- 特殊标记（痣、伤疤、纹身）

变化元素:
- 表情、动作、角度
- 场景、光影、季节
```

### 6.2 分镜叙事技巧

**四格漫画结构**
1. 起: 建立（场景/角色介绍）
2. 承: 发展（事件发生）
3. 转: 冲突/反转（高潮点）
4. 合: 结局（笑点/感动）

**视觉节奏**
- 远景→中景→特写（推进注意力）
- 静态→动态→静态（张弛有度）
- 正常→夸张→正常（喜剧节奏）

### 6.3 质量提升关键词

在描述末尾添加：
- `masterpiece` `best quality`
- `highly detailed`
- `professional illustration`
- `sharp focus`
- `vibrant colors`
- `soft lighting`
- `anime style`
- `trending on pixiv/artstation`

### 6.4 负面提示词（避免）
```
low quality, blurry, distorted anatomy,
bad proportions, extra fingers, mutated hands,
watermark, text, signature, ugly, deformed
```

## 七、完整示例

### 示例1: 角色立绘
```
二次元少女立绘，16岁左右，银白色长发及腰，
淡紫色眼眸，穿着深蓝色魔法学院制服，
外搭灰色斗篷，手持发光法杖，
自信微笑的表情，站姿优雅，
背景是黄昏时分的魔法塔露台，
远处可见浮空岛屿和新月，
新海诚风格的细腻光影，暖橙色调，
全身像，平视角度，高质量插画
```

### 示例2: 场景插画
```
吉卜力风格的夏日森林场景，
阳光透过茂密树冠洒下斑驳光点，
地面上覆盖着厚厚的绿色苔藓，
一条清澈的小溪蜿蜒流过，
溪边开满野花，几只蝴蝶飞舞，
远处隐约可见一座小木屋炊烟袅袅，
温暖治愈的氛围，水彩画质感，
横版构图，远景展示
```

### 示例3: 分镜序列
```
四格漫画分镜，同一角色：

第一格：粉色短发绿眼少女惊讶表情特写，
双手捂嘴，眼睛瞪大

第二格：少女转身奔跑背影，
裙摆飞扬，动态模糊效果

第三格：少女停下脚步侧面，
面前是一扇发光的神秘大门，

第四格：少女回头微笑正面，
眼神坚定充满期待，阳光照在脸上

保持角色一致性：粉色短发、绿色眼睛、
白色连衣裙、红色蝴蝶结发饰
```
