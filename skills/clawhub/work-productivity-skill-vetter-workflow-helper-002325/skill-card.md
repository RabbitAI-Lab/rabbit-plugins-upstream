## Description: <br>
Helps AI-agent users and skill maintainers create practical Skill Vetter-style workflows for bug fixes, setup hardening, reliability improvements, and adjacent skill adaptation. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
AI-agent users, skill authors, maintainers, and teams use this skill to turn Skill Vetter-style demand into practical local workflows, checklists, analysis, code changes, or configuration guidance. It is aimed at improving bug fixes, setup hardening, reliability, and adjacent skill authoring without requiring cloud-only tooling. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad automatic invocation could route unrelated security, GitHub, installation, or bug-fix conversations into this workflow. <br>
Mitigation: Install only when that routing is acceptable, or narrow the triggers to explicit Skill Vetter-related wording before use. <br>
