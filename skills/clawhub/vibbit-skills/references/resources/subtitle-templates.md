# Subtitle templates

There is no independent public dynamic-subtitle-template listing command. A regular packaging template ID is not a dynamic subtitle-template ID, and a local style is not a cloud resource.

Use real known template IDs and the supported style configuration. Inspect font, position, line breaks, emphasis, and animation on the final video. For translation style `type: 1`, use `subtitle_template_configs` entries with `subtitle_template_id`. Do not use the obsolete `subtitle_template_ids` field or invent query/create/edit endpoints. See [translation API](../api/translate_video.md).
