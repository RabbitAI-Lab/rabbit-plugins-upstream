# 角色成长弧线卡

把输入中的**已知事实**与**创作建议**分开，输出一张独立 Markdown 卡片。只设计角色成长，不续写正文、不规划营销、不替用户补造缺失资料。

## 输入

请提供以下三项；可以是 JSON、YAML 或带标题的 Markdown：

1. `角色设定`：身份、处境、核心关系与可见行为。
2. `故事概要`：冲突、目标和结局方向。
3. `已写章节`：至少列出章节编号或标题，以及各章已发生的关键事件。

若任一项缺失，先明确列出缺失字段并停止，不要编造。

## 工作流

1. 从三类输入抽取可核对的事实，并在每条后标明章节锚点；没有章节依据则标为“设定/概要依据”。
2. 归纳角色当前想得到什么（欲望）与阻碍其得到它的内在模式（缺陷）。
3. 选择一个会迫使旧模式失效的转折；它必须与已知冲突相连。
4. 定义最终选择：角色在代价面前主动选择的行动，而非抽象形容词。
5. 生成下列卡片。未知内容写“待确认”，建议内容写“创作建议”，不得伪装成已写事实。

## 输出格式

```markdown
# 角色成长弧线卡｜{角色名}

## 已知事实
- {事实}（依据：第{n}章／设定／概要）

## 核心欲望
- {角色想获得或守住的具体事物}（依据：…）

## 核心缺陷
- {反复出现、会制造代价的信念或应对模式}（依据：…）

## 成长弧线
| 阶段 | 角色状态 | 关键行动/认知 | 章节锚点 | 标记 |
| --- | --- | --- | --- | --- |
| 起点 | {旧状态} | {表现} | 第{n}章 | 已知事实 |
| 受压 | {旧模式的代价} | {失败或冲突} | 第{n}章 | 已知事实/创作建议 |
| 转折 | {旧模式失效} | {必须面对的选择} | 第{n}章或待安排 | 创作建议 |
| 终局 | {新状态} | {最终选择及代价} | 第{n}章或待安排 | 创作建议 |

## 转折
- 触发事件：{…}
- 旧模式为何失效：{…}
- 创作建议：{…}

## 最终选择
- {可被写成场景的主动行动}
- 代价：{…}

## 章节锚点清单
- 第{n}章《{标题/事件}》：{它如何服务弧线}（已知事实/创作建议）

## 待确认
- {只列确实无法从输入判断的信息}
```

## 边界

- 这是角色设计卡，不替代大纲、章节续写或人物诊断。
- 同一输入中冲突的内容，列为“待确认”，不擅自裁决。
- 本地资料的字段名、章节名与原文值保持原样；归纳与建议必须清晰标注。
