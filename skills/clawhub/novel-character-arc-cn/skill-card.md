## Description:

根据角色设定、故事概要和已写章节，整理角色的核心欲望、内在缺陷、转折、最终选择与章节锚点，输出独立Markdown成长弧线卡；已发生的事实与后续创作建议分别标注，资料缺失时指出缺项，不补造人物经历。

This skill is ready for commercial/non-commercial use.

Risk: 可选安装命令使用未固定版本的第三方 CLI 和仓库修订。

Mitigation: 运行前审查安装命令并优先固定版本；也可直接安装已检查的 Markdown 文件。

Mitigation: 只提供愿意与该写作助手分享的故事素材。
