# 展示禁忌清单（反向提示词精华）

## 台词禁忌

| 禁止使用 | 为什么 | 替换方案 |
|---------|-------|---------|
| "各位评委老师好，今天我来为大家介绍……" | 念稿腔，评委立刻判定你是在背稿 | 直接切入："我们这个项目解决的是[具体痛点]" |
| "这证明了我们的方案是可行的" | 自证心虚，评委觉得你不确定自己行不行 | 用数据说话："系统实测准确率达到XX%" |
| "接下来请看……" | 主持人腔，像在主持晚会 | 自然过渡："[模块名]完成后，我们进入下一个环节" |
| "我们的创新点在于……" | 套话，每个参赛队都说这话 | 具体描述："与传统方案相比，我们用[具体技术]替代了[传统方法]，效果提升了XX%" |
| "随着XX的快速发展……" | 万能开头，无信息量 | 直接说行业痛点数据 |
| "本项目将会……预计未来……" | 未落地表述，评委只看已实现的 | 只说已完成和已验证的成果 |

## PPT禁忌

| 禁止 | 为什么 |
|------|-------|
| 最后一页是致谢页 | 应该是成果量化总结页 |
| 团队介绍占整页 | 半页即可，评委不关心你是谁，关心你做了什么 |
| 一页超过3个核心概念 | 评委会跟不上 |
| 使用预先截图替代现场结果 | 评委一眼看出，直接扣分 |
| 播放录屏充数实操展示 | 必须现场实时产出结果 |

## 实操禁忌

| 禁止 | 为什么 |
|------|-------|
| 实操等待期沉默超过5秒 | 评委会觉得你不会操作 |
| 敲伪代码 | 必须是3-5行真实可运行片段 |
| 一个人全程不发言 | 必须每人都有上台时段 |
| 无声翻页/切屏 | 必须有台词过渡 |
| 物理硬件动作放在前面 | 必须放在最后5分钟（高潮） |

## 训练计划禁忌

| 禁止 | 替换 |
|------|------|
| "掌握XXX" | "能在X分钟内独立完成XXX" |
| "了解XXX" | "能用2句话说清XXX的原理" |
| "熟悉XXX" | "连续3次操作无误" |
