# 赛项规程要点

## 人工智能应用赛项（JSG2026038 省赛规程）

### 比赛时长与结构
- 技能操作：3小时
- 展示讲解：20分钟
- 合计：约3.5小时

### 技能操作环节（80%分值）
1. **数据准备**：数据采集、清洗、标注、增强
2. **基础算法**：传统机器学习算法应用
3. **深度学习**：模型选择、训练、调优、评估
4. **自选智能应用**：端边云架构，物理闭环可演示

### 展示讲解环节（20%分值）
- 项目方案介绍
- 技能展示（核心得分区）
- 价值总结

### 技术架构要求
- 必须采用端边云架构：数据采集（端）→ 算法处理（边/云）→ 结果反馈
- 必须有物理闭环：不能纯软件演示，必须有硬件/实物联动
- 必须可现场演示：系统必须能在比赛环境中实时运行

### 职业素养考核
- 团队协作：分工明确、配合流畅
- 代码规范：命名规范、注释清晰、结构合理
- 报告撰写：逻辑清晰、数据准确

## 双创竞赛赛项

### 核心产出物
1. **商业计划书（Word版）**：投行标准+比赛标准双重格式
2. **网评版PPT**：26-35页，内容详尽，佐证充分，故事线完整
3. **路演版PPT**：8-10页，字越少越好，纯靠人讲
4. **演讲稿/问答库**：路演台词+评委高频问题标准应答

### 展示时长
- 网评：纯材料评审，不现场展示
- 省赛路演：8分钟展示+5分钟答辩
- 国赛路演：15分钟展示+10分钟答辩
