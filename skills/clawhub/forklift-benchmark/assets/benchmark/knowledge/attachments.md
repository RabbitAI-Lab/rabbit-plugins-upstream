# 叉车属具知识库 / Forklift Attachments Knowledge Base

> 用途:Benchmark 中"装备属具 + 作业"任务的事实基线。
> 涵盖:货叉(标准/加长/调距)、侧移器、调距叉、夹抱器、旋转器、串杆、推拉器、倾翻器、称重叉等。
> 标准:GB/T 46909-2025《叉车属具 设计规范》、GB/T 5140-2005《叉车 挂钩型货叉 术语》、ISO 2329、ISO 13284、FEM/ITA 工业车辆属具规范。

### 2.2 货叉挂钩 / Fork Hook

| 规格 | 适用 | 标准 |
|------|------|------|
| **A 型挂钩** | 标准挂接,2 颗 M16 螺栓 | ISO 2329 / GB/T 5140 |
| **B 型挂钩** | 重型挂接,3 颗 M20 螺栓 | |
| **C 型挂钩** | 焊接固定,无快换 | 旧款 |
| **快换型挂钩** | 液压快换,1 分钟内更换 | 现代主流 |

### 2.3 货叉材质 / Material

| 材质 | 牌号 | 强度 | 适用 |
|------|------|------|------|
| 普通碳钢 | Q345B / 16Mn | σ_s = 345 MPa | 主流 |
| 高强钢 | Q690 / 30CrMnSi | σ_s = 690 MPa | 重载 |
| 不锈钢 | 304 / 316L | σ_s = 200-300 MPa | 食品/医药/冷库 |
| 钛合金 | TC4 | σ_s = 800 MPa | 极端环境(罕见) |

### 2.4 货叉检验 / Fork Inspection(GB/T 44679-2024)

- **厚度磨损** ≤ 10% 原始厚度;
- **垂直度偏差** ≤ 3%;
- **裂纹检测** — 磁粉/渗透/超声波;
- **变形** — 水平弯曲 ≤ 0.5% L,垂直弯曲 ≤ 0.5% L;
- **挂钩磨损** — 挂钩卡口高度磨损 ≤ 5%。

## 3. 侧移器 / Sideshifter

| 规格 | 行程 ±(mm) | 自重 (kg) | 适配吨位 | 适配叉车类别 | 备注 |
|------|------|------|------|------|------|
| **SS-1.5T-100** | ±100 | 50-70 | 1.0-1.8T | ISO II | 1-3T 平衡重 |
| **SS-2.5T-100** | ±100 | 70-100 | 1.8-2.5T | ISO II | |
| **SS-3.0T-150** | ±150 | 100-150 | 2.5-3.5T | ISO II/III | 主流 3T |
| **SS-5.0T-150** | ±150 | 150-220 | 4.0-5.5T | ISO III | |
| **SS-7.0T-200** | ±200 | 250-350 | 5.5-8.0T | ISO III/IV | |
| **SS-10T-200** | ±200 | 400-500 | 8.0-12.0T | ISO IV/V | |

### 核心参数
- **安装方式** — 卡板式(快换) / 焊接式(固定)
- **油路** — 2 路液压(左/右移动)
- **侧移力** — 10-30 kN(随吨位)
- **定位精度** — ±5 mm
- **降额系数 k_att** — 1.00(几乎不影响载荷)

### 适用场景
- 仓库内货位对齐偏差修正;
- 集装箱内狭窄空间作业;
- 装车时对正车厢门;
- 减小叉车换向次数。

## 14. 属具安全 / Attachment Safety

1. **降额系数 k_att** — 任何属具装配后必须查表降额,装载量 > 允许 = 超载,系统报警。
2. **锁紧确认** — 每次属具装备后,必须做 30s 静态试压 + 视觉锁紧确认。
3. **液压检查** — 软管无破损、接头无渗漏、油温 < 60℃。
4. **属具识别** — 启动前系统自动识别属具类型,加载对应控制曲线。
5. **限位器** — 旋转器、倾翻器必须有机械限位 + 电气限位双重保护。
6. **载荷图** — 每次更换属具,必须重贴载荷曲线表(GB/T 44679-2024 要求)。
