# 叉车作业场景拓扑知识库 / Forklift Operation Scene Topology

> 用途:Benchmark 仿真器场景生成的分类基线,所有任务须落到 7 大场景之一。
> 涵盖:典型尺寸、温度/光照、车速限制、典型任务、典型叉车、典型属具、典型事件。

---

## 0. 场景编码体系 / Scene Code

| 编码 | 中文 | 英文 | 主要车辆类型 |
|------|------|------|------|
| **S1_HIGH_BAY** | 高位立体库 | High-bay Warehouse | 三向堆垛 / 前移式 / VNA |
| **S2_BLOCK** | 平库 / 堆垛区 | Block Stacking | 平衡重 / 前移式 |
| **S3_DOCK** | 集装箱 / 货车装卸 | Container / Truck Dock | 重型平衡重 / 正面吊 |
| **S4_LINE_SIDE** | 生产流水线边 | Production Line Side | 平衡重 / 牵引车 |
| **S5_VNA** | 窄巷道 | Very Narrow Aisle | 三向堆垛 / VNA |
| **S6_OUTDOOR** | 户外交接区 | Outdoor Yard | 平衡重 / 越野 |
| **S7_MIXED** | 人机混行 | Mixed Traffic | 平衡重 / AGV |

## 1. S1_HIGH_BAY(高位立体库)

### 1.1 物理参数
| 参数 | 典型值 | 备注 |
|------|------|------|
| 库高 | 8-24 m | 高位库常见 12-24m |
| 货架深度 | 1-3 个托盘位 | 1-3PL |
| 巷道宽 | 1.6-2.5 m | 单深 / 双深 |
| 净空 | 8-24 m | 取决于库高 |
| 地面 | 钢筋混凝土地坪 | 表面平整度 3mm/2m |
| 温度 | 0-40°C | 冷藏 -25°C |
| 照度 | 50-200 lux | 顶部 LED 灯条 |
| 通风 | 强制通风 | 防叉车尾气(柴油场景) |

### 1.2 车速限制
- 直行 ≤ 8 km/h
- 转弯 ≤ 3 km/h
- 起升/下降 ≤ 0.3 m/s

### 1.3 典型任务
- 高位货架(8-12m)堆垛;
- 整托盘入库/出库;
- 库内倒垛;
- 库存盘点(WMS 联动)。

### 1.4 典型叉车
- **三向堆垛式** — 主流(12m 以下)
- **前移式** — 8m 以下
- **VNA(三向)** — 高位窄巷道
- **平衡重式** — 大件、低位

### 1.5 典型属具
- 标准货叉 / 调距叉
- 隔板夹(高位烟包、纸卷)
- 推拉器(无托盘滑板)

### 1.6 典型事件
- 货叉插入高位托盘;
- 降额曲线触发(>6.5m 需查表);
- 高位失稳风险(重心高、横向风扰);
- 库门/巷道门识别(高反射反光膜);
- 高度限位器触发;
- 巷道端部防撞。

## 2. S2_BLOCK(平库 / 堆垛区)

### 2.1 物理参数
| 参数 | 典型值 | 备注 |
|------|------|------|
| 库高 | 4-8 m | 一般库 |
| 堆垛层数 | 2-5 层 | 平衡重 |
| 巷道宽 | 3-4 m | 双向 |
| 净空 | 5-9 m | |
| 地面 | 环氧地坪 / 金刚砂 | 摩擦系数 0.6-0.8 |
| 温度 | 0-40°C | |
| 照度 | 100-300 lux | |
| 通风 | 自然 + 机械 | |

### 2.2 车速限制
- 直行 ≤ 15 km/h
- 转弯 ≤ 5 km/h
- 作业区 ≤ 8 km/h

### 2.3 典型任务
- 入库上架;
- 出库下架;
- 平移调整;
- 批次整理;
- 抽检。

### 2.4 典型叉车
- **平衡重式 1-3.5T** — 主流
- **前移式** — 1-2.5T
- **电动步行式** — 短距离补货

### 2.5 典型属具
- 标准货叉 / 侧移器 / 调距叉
- 箱体夹(家电)
- 卡板称(称重出库)
- 串杆(无托盘)

### 2.6 典型事件
- 货叉与货架横梁碰撞;
- 堆垛层数 > 3 失稳;
- 货物突出超出托盘;
- 多车相遇会车;
- 通道堵塞等待。

## 3. S3_DOCK(集装箱 / 货车装卸)

### 3.1 物理参数
| 参数 | 典型值 | 备注 |
|------|------|------|
| 站台高度 | 1.2-1.3 m | 与车厢齐平 |
| 集装箱规格 | 20/40 ft | ISO 668 |
| 集装箱净空 | 2.59 m (8'6") 或 2.90 m (9'6") | |
| 集装箱门宽 | 2.34 m (20') / 2.28 m (40') | |
| 月台长度 | 30-50 m | 多车位 |
| 雨棚 | 有 / 无 | 户外场景 |
| 地面 | 混凝土 | 室外 抗压 ≥ C30 |
| 温度 | -30 ~ 50°C | 严酷环境 |
| 照度 | 50-100 lux(夜间加强) | |

### 3.2 车速限制
- 站内 ≤ 10 km/h
- 月台 ≤ 5 km/h
- 集装箱内 ≤ 3 km/h(高密度作业)

### 3.3 典型任务
- 集装箱装货;
- 集装箱卸货;
- 月台调位;
- 甩挂运输对接;
- 海关监管货操作。

### 3.4 典型叉车
- **重型平衡重** 5-10T
- **集装箱正面吊** 8-45T
- **伸缩臂叉装车** 4-7T
- **侧面叉车**(长物料)

### 3.5 典型属具
- **集装箱吊具**(正面吊)
- 加长货叉(2.4m)
- 桶夹 / 软包夹(化工品)
- 旋转器(180° 倾倒)

### 3.6 典型事件
- 集装箱门未完全打开;
- 货物偏移需二次找正;
- 雨雪天气地面湿滑;
- 司机疲劳 / 视线盲区(高 1.5m 集装箱内);
- 月台边缘防坠落;
- 叉车与货车相对移动的安全确认(锁车楔 / 制动)。

## 4. S4_LINE_SIDE(生产流水线边)

### 4.1 物理参数
| 参数 | 典型值 | 备注 |
|------|------|------|
| 巷道宽 | 2-3 m | 紧凑 |
| 高度 | 4-6 m | |
| 地面 | 环氧地坪 / 防静电 | 摩擦系数 0.6 |
| 温度 | 5-35°C | 工厂车间 |
| 照度 | 200-500 lux | 充足 |
| 噪声 | 70-90 dB | 工业噪声 |
| 流水线速度 | 0.1-0.5 m/s | 视行业 |
| 上下料节拍 | 30-120 s/次 | |

### 4.2 车速限制
- 直行 ≤ 10 km/h
- 转弯 ≤ 3 km/h
- 接近流水线 ≤ 2 km/h(精确对接)

### 4.3 典型任务
- 上料(原料送到线边);
- 下料(成品入库);
- 半成品转运;
- 工序间缓存;
- 退料 / 报废品处理。

### 4.4 典型叉车
- **平衡重 1-3.5T** — 主流
- **牵引车 + 料车** — 长距离
- **前移式** — 紧凑场景
- **AGV** — 自动上下料

### 4.5 典型属具
- 标准货叉 / 调距叉
- 旋转器(配合产线方向)
- 卡板称(配料称重)
- 翻转器(注塑件、玻璃)

### 4.6 典型事件
- 与流水线的精准对接(±5cm);
- 产线节拍等待(空挡期 AGV 充电);
- 工人穿插作业(混合场景);
- 突发停线 / 急停协调;
- 静电 / 粉尘 / 油污干扰。

### 5.2 车速限制

- 库内堆垛 ≤ 0.5 m/s

### 5.3 典型任务

- 双深 / 三深货架存取;

### 5.5 典型属具

### 5.6 典型事件

- 货架变形检测;
- 失稳风险(高位 + 窄巷 + 高重心);
- 紧急疏散(单出口);
- 巷道端部撞货架。

## 6. S6_OUTDOOR(户外交接区)

### 6.1 物理参数
| 参数 | 典型值 | 备注 |
|------|------|------|
| 场地面积 | 500-5000 m² | 大型 |
| 地面 | 混凝土 / 沥青 | 户外 |
| 排水坡度 | 1-2% | 防积水 |
| 雨棚 | 有 / 无 | 部分 |
| 温度 | -30 ~ 50°C | 极端 |
| 照度 | 50-50000 lux(室外) | 动态 |
| 风速 | 0-20 m/s | 极端天气 |
| 雨雪 | 雨 0-50 mm/h,雪 0-20 cm | |
| 能见度 | 30-10000 m | 雾天极低 |

### 6.2 车速限制
- 直行 ≤ 15 km/h
- 转弯 ≤ 5 km/h
- 雨雪 ≤ 5 km/h
- 大风(>10 m/s)≤ 5 km/h

### 6.3 典型任务
- 集装箱堆场作业;
- 木材 / 钢材 / 管材堆场;
- 散货(沙石、粮食、化肥)装卸;
- 工程车辆调度。

### 6.4 典型叉车
- **越野平衡重** 3-7T
- **伸缩臂叉装车** 4-7T
- **重型平衡重** 5-16T
- **柴油叉车** 主流(户外)

### 6.5 典型属具
- 加长货叉 / 桶夹 / 软包夹
- 旋转器(180°)
- 串杆(滑板)
- 集装箱吊具(正面吊)

### 6.6 典型事件
- 雨雪湿滑制动距离增大 2-3 倍;
- 大风横向力(>10 m/s 限速);
- 阳光直射 / 逆光摄像头失效;
- LiDAR 雨雪误触发(噪点 + 30%);
- 路面不均(井盖、坑洞、坡度);
- 极端温度(-20°C) 电池衰减 30-40%。

## 7. S7_MIXED(人机混行)

### 7.1 物理参数
| 参数 | 典型值 | 备注 |
|------|------|------|
| 区域 | 车间 / 仓库 / 装卸区 | 综合 |
| 行人密度 | 0.1-1.0 人/m² | 视场景 |
| 车辆密度 | 0.01-0.1 辆/m² | |
| 路面 | 划线 / 标线 | 强制分道 |
| 温度 / 照度 | 取决于混合场景 | |

### 7.2 车速限制
- 直行 ≤ 8 km/h
- 转弯 ≤ 3 km/h
- 人车交汇处 ≤ 5 km/h
- 行人 5m 内 ≤ 2 km/h

### 7.3 典型任务
- 仓库内作业(工人 + 叉车);
- 装卸区作业(司机 + 装卸工);
- 厂区转运(行人 + 车辆);
- 巡检 / 维护任务。

### 7.4 典型叉车
- 平衡重(带声光报警)
- AGV(主动避让行人)
- 步行式(狭窄区)

### 7.5 典型属具
- 同 S2 / S4
- 强调属具端部保护(防撞软包)

### 7.6 典型事件
- **行人突然横穿** — 紧急制动 + 鸣笛;
- **盲区行人**(司机后视 1.5m 死角);
- **货叉端部撞击行人**(最严重工伤);
- **儿童 / 访客闯入**;
- **碰撞追踪**(RCS 雷达 + 360° 摄像头);
- **人车调度优化**(行人优先,车辆减速避让)。

## 9. 场景组合与转移 / Scene Composition

### 9.1 典型多场景任务
1. **入库全流程**:S3_DOCK(卸货) → S2_BLOCK(暂存) → S1_HIGH_BAY(上架)
2. **出库全流程**:S1_HIGH_BAY(下架) → S2_BLOCK(拣选) → S3_DOCK(装车)
3. **厂内物流**:S3_DOCK(到货) → S4_LINE_SIDE(上料) → S3_DOCK(成品发运)
4. **冷链**:S6_OUTDOOR(冷藏车对接) → S5_VNA(-25°C 高位库)

### 9.2 场景转移检测
- **跨场景切换**:门 / 雨棚 / 温区变化,Agent 须更新感知模型;
- **环境光变化**:室内 LED ↔ 室外日光,相机自动曝光;
- **路面变化**:环氧地坪 ↔ 沥青 / 雨雪,摩擦系数变化;
- **高度变化**:0m → 12m,门架自动调速。
