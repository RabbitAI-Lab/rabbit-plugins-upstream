# 叉车现场俚语词典 / Forklift Site Slang Dictionary

> 用途:Benchmark 语料库 + 现场指令识别 + 培训一致性。
> 收录:卡板、牛腿、货叉、地牛、抱夹、龙门、门架、前倾、后倾、起升、下降、横移、调距、串杆、压板称、夹包机等。
> 每条:标准术语 / 英文 / 典型用法例句。
> 来源:工厂现场 + 行业老炮经验 + ISO 5053 / GB/T 6104 术语对照。

---

## A. 基础结构类

### 1. 卡板 / Pallet
- **标准术语**:托盘(Pallet)
- **英文**:Pallet / Skid
- **常用类型**:木卡板、塑料卡板、钢卡板、纸卡板
- **典型用法**:
  - "把那批卡板拉到 3 号货架。" — Move those pallets to rack #3.
  - "卡板尺寸不对,1.0m 还是 1.2m?" — What size pallet, 1.0m or 1.2m?
  - "空卡板堆到回收区。" — Stack empty pallets at the recycling zone.

### 2. 牛腿 / Fork Arm / Fork Carriage
- **标准术语**:货叉架 / 叉架
- **英文**:Fork carriage / Fork arm
- **备注**:司机口中"牛腿"即叉车前端伸出、装货叉的支架
- **典型用法**:
  - "牛腿升到 2 米。" — Lift the carriage to 2 meters.
  - "牛腿前倾一点点。" — Tilt the mast forward a bit.

### 3. 货叉 / Fork
- **标准术语**:货叉
- **英文**:Fork / Tine
- **备注**:也叫"叉子""叉齿""扁担"
- **典型用法**:
  - "换副 1.2 米的货叉。" — Replace with 1.2m forks.
  - "货叉间距调到 60 厘米。" — Set the fork spacing to 60cm.

### 4. 龙门 / Mast(门架)
- **标准术语**:门架
- **英文**:Mast
- **备注**:司机叫"龙门",因外形象门框
- **典型用法**:
  - "龙门前倾 3 度再起升。" — Tilt the mast forward 3° before lifting.
  - "龙门降到最低。" — Lower the mast to the lowest position.

### 5. 门架 / Mast
- **标准术语**:门架
- **英文**:Mast
- **备注**:同"龙门",更正式说法
- **典型用法**:见上

### 6. 立柱 / Mast Upright
- **标准术语**:门架立柱
- **英文**:Mast upright / Mast channel
- **备注**:门架两侧的钢制立柱
- **典型用法**:
  - "立柱变形了,得换总成。" — The upright is bent, must replace the whole mast.

## B. 升降动作类

### 7. 起升 / Lift / Raise
- **标准术语**:起升
- **英文**:Lift / Raise
- **备注**:动词,指货叉上升
- **典型用法**:
  - "起升到 4 米停。" — Raise to 4 meters and stop.
  - "起升速度调慢点,装的是玻璃。" — Slow down the lift speed, carrying glass.

### 8. 下降 / Lower
- **标准术语**:下降
- **英文**:Lower
- **典型用法**:
  - "下降到地面,再后倾 5 度。" — Lower to the ground, then tilt back 5°.

### 9. 慢降 / Float Down / Soft Lower
- **标准术语**:慢降 / 缓冲下降
- **英文**:Float down / Cushion lower
- **备注**:防止压坏易碎品的低速下降模式
- **典型用法**:
  - "切换到慢降模式。" — Switch to float-down mode.

### 10. 快降 / Quick Lower
- **标准术语**:快速下降
- **英文**:Quick lower
- **典型用法**:
  - "空载用快降,效率高。" — Use quick lower when empty, more efficient.

## C. 倾角与横移类

### 11. 前倾 / Forward Tilt / Mast Forward
- **标准术语**:门架前倾
- **英文**:Forward tilt / Tilt forward
- **备注**:门架向前(操作者方向)倾斜,通常 5-7°
- **典型用法**:
  - "叉起来前倾 3 度。" — Lift and tilt forward 3°.
  - "前倾别超 5 度,前翻。" — Don't exceed 5° forward tilt, it'll tip.

### 12. 后倾 / Backward Tilt / Mast Back
- **标准术语**:门架后倾
- **英文**:Backward tilt / Tilt back
- **备注**:运输时防止货物滑落,通常 5-7°
- **典型用法**:
  - "行驶前门架后倾 5 度。" — Tilt the mast back 5° before driving.
  - "堆高时后倾到位。" — Tilt fully back for stacking.

### 13. 横移 / Sideshift
- **标准术语**:侧移 / 横向移动
- **英文**:Sideshift
- **备注**:属具(侧移器)的左右移动,通常 ±100-150mm
- **典型用法**:
  - "向右横移 50。" — Sideshift right 50mm.
  - "横移对齐货架。" — Sideshift to align with the rack.

### 14. 调距 / Fork Positioning
- **标准术语**:货叉间距调整
- **英文**:Fork positioning
- **备注**:调距叉属具的动作
- **典型用法**:
  - "调距到 80 公分。" — Set the fork spacing to 80cm.
  - "调距叉速度慢点,别夹坏。" — Slow down fork positioning, don't damage the load.

### 15. 微动 / Inch / Creep
- **标准术语**:微动 / 蠕动
- **英文**:Inching / Creep
- **备注**:低速(0.5-1 km/h)对位模式
- **典型用法**:
  - "切到微动模式,对准托盘孔。" — Switch to creep mode to align with the pallet hole.

## D. 属具与装置类

### 16. 地牛 / Pallet Jack(手动 / 电动)
- **标准术语**:手动 / 电动托盘搬运车
- **英文**:Manual pallet jack / Electric pallet truck
- **备注**:"地牛"=手动托盘车(因外形像趴着的牛)
- **典型用法**:
  - "用 2 台地牛把那批卡板拉过来。" — Use 2 pallet jacks to bring those pallets over.
  - "地牛没电了,去充。" — The electric pallet jack is dead, go charge it.

### 17. 抱夹 / Clamp / Bale Clamp
- **标准术语**:夹抱器 / 抱夹
- **英文**:Clamp / Bale clamp
- **备注**:用于无托盘货物(纸卷、棉包、化纤)
- **典型用法**:
  - "换上抱夹,搬那批纸卷。" — Switch to the clamp for the paper rolls.
  - "抱夹夹紧力调小点,纸卷变形。" — Reduce clamp force, paper rolls are deforming.

### 18. 夹包机 / Bale Clamp
- **标准术语**:夹包机 / 软包夹
- **英文**:Bale clamp
- **典型用法**:
  - "夹包机准备好,棉花包到了。" — Get the bale clamp ready, cotton bales arrived.

### 19. 串杆 / Push-Pull / Slip-sheet Handler
- **标准术语**:推拉器 / 串杆
- **英文**:Push-pull unit
- **备注**:用于无托盘的滑板作业
- **典型用法**:
  - "这单用串杆,客户不要托盘。" — Use the push-pull on this order, customer doesn't want pallets.
  - "串杆的滑板要换新的,旧的破了。" — Replace the slip sheets, old ones are torn.

### 20. 压板称 / Pallet Scale
- **标准术语**:卡板称 / 称重叉
- **英文**:Pallet scale / Weighing fork
- **备注**:称重用
- **典型用法**:
  - "过一下压板称。" — Weigh it on the pallet scale.
  - "压板称读数多少?" — What's the pallet scale reading?

### 21. 调距叉 / Fork Positioner
- **标准术语**:调距叉
- **英文**:Fork positioner
- **典型用法**:
  - "装上调距叉,这批货尺寸不统一。" — Attach the fork positioner, load sizes vary.

### 22. 侧移器 / Sideshifter
- **标准术语**:侧移器
- **英文**:Sideshifter
- **典型用法**:见"横移"

### 23. 旋转器 / Rotator
- **标准术语**:旋转器
- **英文**:Rotator
- **备注**:360° 旋转属具
- **典型用法**:
  - "装旋转器,把料斗倒空。" — Attach the rotator, empty the hopper.

### 24. 货叉套 / Fork Extension Sleeve
- **标准术语**:货叉加长套
- **英文**:Fork extension sleeve
- **典型用法**:
  - "装上 1.5 米的货叉套,货太宽了。" — Put on 1.5m fork extensions, load is too wide.

## E. 作业指令类

### 25. 叉货 / Pick Up / Lift a Load
- **标准术语**:叉取货物
- **英文**:Pick up a load / Lift a load
- **典型用法**:
  - "去叉那 3 包水泥。" — Go pick up those 3 bags of cement.

### 26. 卸货 / Drop / Set Down
- **标准术语**:卸下 / 放下
- **英文**:Drop / Set down
- **典型用法**:
  - "卸在 2 号月台。" — Set it down at dock #2.

### 27. 走车 / Drive / Go
- **标准术语**:行驶
- **英文**:Drive
- **典型用法**:
  - "走车去 3 号库。" — Drive to warehouse #3.

### 28. 倒挡 / Reverse
- **标准术语**:倒挡 / 倒车
- **英文**:Reverse
- **备注**:倒车必须鸣笛 + 看后视
- **典型用法**:
  - "打倒挡,鸣笛。" — Shift to reverse, sound the horn.

### 29. 鸣笛 / Horn / Beep
- **标准术语**:鸣笛
- **英文**:Sound the horn / Beep
- **备注**:必须 ≥ 90 dB(A) @ 1m
- **典型用法**:
  - "过拐弯必须鸣笛!" — Always sound the horn at intersections!

### 30. 急停 / Emergency Stop / E-Stop
- **标准术语**:紧急停止
- **英文**:Emergency stop
- **典型用法**:
  - "有人!急停!" — Person! E-stop!

## F. 故障与状态类

### 31. 没电 / Low Battery / Dead
- **标准术语**:电池电量低
- **英文**:Low battery
- **典型用法**:
  - "这车又没电了,去换台。" — This one's dead, swap for another.

### 32. 趴窝 / Breakdown / Out of Service
- **标准术语**:故障停机
- **英文**:Breakdown / Out of service
- **典型用法**:
  - "3 号叉车趴窝了,叫维修。" — Forklift #3 is broken down, call maintenance.

### 33. 链条松 / Loose Chain
- **标准术语**:起升链条松动
- **英文**:Loose mast chain
- **备注**:链条延伸率 > 3% 须换
- **典型用法**:
  - "链条松了,调一下张紧。" — Chain is loose, adjust tension.

### 34. 刹车软 / Soft Brake
- **标准术语**:制动性能下降
- **英文**:Soft brake / Weak brake
- **典型用法**:
  - "刹车软,马上报修。" — Brakes are weak, report for repair immediately.

### 35. 方向盘沉 / Heavy Steering
- **标准术语**:转向沉重
- **英文**:Heavy steering
- **典型用法**:
  - "这车方向盘沉,可能是转向泵漏油。" — Steering is heavy, probably steering pump leak.

### 36. 漏油 / Oil Leak
- **标准术语**:液压油泄漏
- **英文**:Hydraulic oil leak
- **典型用法**:
  - "地上有油,检查漏油点。" — Oil on the ground, check for leaks.

### 37. 灯不亮 / Light Out
- **标准术语**:灯光故障
- **英文**:Light out
- **典型用法**:
  - "倒车灯不亮,夜班看不见。" — Reverse light is out, can't see at night.

### 38. 报警 / Alarm / Warning
- **标准术语**:故障报警
- **英文**:Alarm / Warning
- **典型用法**:
  - "控制器报警了,看看啥代码。" — Controller alarm, check the code.

## J. 现场口音 / 方言 / 误用

### 53. 叉车 vs 铲车
- **标准术语**:叉车 / 工业车辆
- **英文**:Forklift / Fork lift truck
- **备注**:北方称"铲车",实际"铲车"指轮式装载机,与叉车不同
- **典型用法**:
  - "借个铲车来搬砖。" — 通常指装载机,非叉车;**误用**,注意辨别。

### 54. 堆高车 vs 叉车
- **标准术语**:堆垛车 / 前移式叉车
- **英文**:Stacker / Reach truck
- **备注**:堆高车(步行式)严格说属 ISO I 类,与平衡重式叉车(ISO IV/V)有别
- **典型用法**:
  - "用堆高车上货架,平衡重转不过弯。" — Use the stacker for the rack, the counterbalance can't turn.

### 55. 牛头 / Counterweight
- **标准术语**:配重 / 平衡重
- **英文**:Counterweight
- **备注**:司机口语叫"牛头",因形似牛头(尤其内燃叉车后部)
- **典型用法**:
  - "牛头撞了,看裂没裂。" — Hit the counterweight, check for cracks.

### 56. 小金刚 / Small Stand-up Forklift
- **标准术语**:小吨位平衡重 / 站驾式
- **英文**:Stand-up counterbalance / Small forklift
- **典型用法**:
  - "车间里用小金刚就够了,大叉车进不去。" — A small stand-up is enough for the workshop, big forklifts can't get in.

### 57. 跑偏 / Drift
- **标准术语**:方向跑偏
- **英文**:Directional drift
- **典型用法**:
  - "这车跑偏,调一下前束。" — This truck drifts, adjust the toe-in.

### 58. 打齿 / Grinding Gears
- **标准术语**:变速箱打齿
- **英文**:Grinding gears
- **典型用法**:
  - "变速箱打齿,得大修。" — Gears are grinding, needs overhaul.

### 59. 憋车 / Engine Stalling
- **标准术语**:发动机憋车
- **英文**:Engine stalling
- **典型用法**:
  - "内燃叉车憋车,可能是油路堵塞。" — ICE forklift stalling, maybe fuel line blockage.

### 60. 烧机油 / Burning Oil
- **标准术语**:烧机油
- **英文**:Burning oil
- **典型用法**:
  - "发动机烧机油,大修了。" — Engine burns oil, needs rebuild.

## K. Benchmark 语料库整合 / Benchmark Corpus Integration

### K.1 NLU 任务
- **意图识别** — "叉那 3 包水泥" → `PICK_UP` + `cement_bag` + 数量=3
- **指令解析** — "起升到 4 米" → `LIFT` + 目标高度=4m
- **位置定位** — "5 号月台" → `DOCK_5`
- **属具切换** — "装上抱夹" → `ATTACHMENT=clamp`
- **异常检测** — "链条松了" → `WARNING` + `maintenance_required`

| 鸣笛 | beep / horn | HORN |
| 跑偏了 | drift | DIRECTION_ERROR |
| 倒挡 | reverse | REVERSE_GEAR |
| 急停 | e-stop | E_STOP |
| 抱夹夹紧 | clamp tight | CLAMP_CLOSE |
| 调距 80 | position 80 | FORK_SPACING=80cm |
