## 一、Barra CNE5 风格因子（10 个）

- **来源**：MSCI Barra CNE5 风险模型十大风格因子（机构量化标配）。定义参考华安证券 / 中银证券《CNE5 十大风格因子》研报与 MSCI Barra 官方文档。
- **定位**：机构风险模型的标准「风格暴露」描述符，覆盖规模 / 贝塔 / 动量 / 残差波动 / 非线性规模 / 账面市值比 / 流动性 / 盈利收益率 / 成长 / 杠杆。
- **转写说明（QuantAll 约束）**：
  - 单因子直接 `out = 描述符`（引擎内部自动截面排名），不手动 `row_rank`；仅 Growth 为多子项复合（各子项先 `row_rank` 再相加）。
  - 复权价：`ac = d['close']*d['adj_factor']`。
  - Beta 用 `get_stock_index('000001','close')` 取上证综指收益作市场收益，再 `rolling_regbeta(ret, mkt, 252)`（252 交易日 ≈ 1 年）。
  - NLSIZE 简化：真实定义为 size^3 对 size 正交化；QuantAll 无截面多回归，用 `-(row_rank(ln市值)-0.5)^2` 的逆 U 形代理捕捉「中盘」暴露。
  - EarningsYield / Leverage 按 Barra 子因子权重做简化加权（无分析师预测数据，用 TTM 盈利 / 现金流替代）。
- **因子清单**：

  | 因子 | 含义 | 描述符 |
  |---|---|---|
  | CNE5_Size | 规模 | `ln(总市值)` |
  | CNE5_Beta | 系统性风险 | ret 对 mkt 的 252 日滚动 β |
  | CNE5_Momentum | 动量 | 复权价 `shift(21)/shift(252)-1`（12-1 月） |
  | CNE5_ResidualVol | 残差波动 | ret 252 日标准差 × √252 |
  | CNE5_NLSIZE | 非线性规模（中盘） | `-(row_rank(ln市值)-0.5)^2` |
  | CNE5_BookToPrice | 账面市值比 | 每股净资产 / 收盘价 |
  | CNE5_Liquidity | 流动性 | 20 日平均换手率 |
  | CNE5_EarningsYield | 盈利收益率 | `0.79×(1/PE_TTM) + 0.21×(每股OCF/价)` |
  | CNE5_Growth | 成长 | `row_rank(营收同比) + row_rank(净利同比)` |
  | CNE5_Leverage | 杠杆 | `0.35×资产负债率 + 0.27×权益乘数 + 0.38×产权比率` |

## 二、Piotroski F-Score（9 子项 + 1 合成 = 10 个）

- **来源**：Piotroski (2000)《Value Investing: The Use of Historical Financial Statement Information to Separate Winners from Losers》。9 条二元会计标准，0~9 分，高分 = 财务改善的质量股（原用于低 PB 价值股池内优选）。
- **转写说明**：
  - 财务数据按日向前填充（forward-filled），故「同比」用 `shift(252)`（≈ 1 年交易日）而非 `shift(4)`。
  - 各子项为二元信号 `(条件).astype(float)` → 1/0；合成 `Piotroski_FScore` = 9 项之和（0~9 连续）。
  - F4 应计（盈余质量）：`OCF/TA > ROA` ⟺ `每股OCF > 每股收益`（同除股本）。

  | 因子 | 组 | 标准 |
  |---|---|---|
  | F1_ROA | 盈利 | ROA > 0 |
  | F2_OCF | 盈利 | 每股经营现金流 > 0 |
  | F3_dROA | 盈利 | ROA 同比升（shift252） |
  | F4_Accrual | 盈利 | 每股OCF > 每股收益 |
  | F5_dLev | 杠杆 / 流动性 | 资产负债率 同比下降 |
  | F6_dLiq | 杠杆 / 流动性 | 流动比率 同比上升 |
  | F7_NoDil | 杠杆 / 流动性 | 总股本 同比未增 |
  | F8_dGM | 运营效率 | 销售毛利率 同比上升 |
  | F9_dATO | 运营效率 | 总资产周转率 同比上升 |
  | Piotroski_FScore | 合成 | 上述 9 项求和 |
