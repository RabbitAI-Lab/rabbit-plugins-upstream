## 一、中信证券风格因子体系

来源：中信证券量化策略（全球量化多因子模型 / 创业板风格因子定义）。

**7 大一级风格因子**（全球模型口径）：小市值、动量/反转、高流动性、高波动、高成长、低估值、高盈利。
**8 类口径**（创业板报告）：市值、盈利、成长、估值、研发、反转、波动率、流动性。

因子预处理通用流程：去极值 → 标准化 → 中性化（市值因子做行业中性，其余做行业+市值中性）→ 大类内等权相加。

## 二、申万宏源风格因子体系

来源：申万金工因子监控体系（从因子库筛选 33 个细分因子，合成 10 大类）。

**10 大类风格因子**（方向标注为与下期收益相关性方向）：
| 大类 | 方向 | 典型指标 |
|---|---|---|
| 规模 | 负向 | 总市值 |
| 估值 | 正向 | PB_LF、PE_TTM、PS_TTM |
| 分红 | 正向 | 股息率 |
| 盈利 | 正向 | ROE、ROA |
| 财务质量 | 正向 | 资产负债率(负向)、应计(负向) |
| 成长 | 正向 | 营收同比、净利润同比 |
| 反转 | 负向 | 过去 N 日收益取负 |
| 波动率 | 负向 | 日收益 rolling std |
| 流动性 | 负向 | 换手率、成交额/市值 |
| 分析师一致预期 | 正向 | 一致预测净利润同比 |

> 注：申万「纯因子指数」编制——低市盈率指数取 PE 最低 300 只（剔除亏损股及 ROE<2%），半年度调整，对情绪敏感。

## 三、转写映射（个股特征值）

| 风格 | 转写公式（QuantAll） | 字段 |
|---|---|---|
| 规模(负向) | `log(总市值)` | 总市值 |
| 估值-EP(正向) | `每股收益/(复权收盘价)` | 每股收益/close/adj_factor |
| 估值-BP(正向) | `市净率` | 市净率 |
| 成长-营收(正向) | `营收/营收.shift(252)-1` | 营业收入 |
| 成长-净利(正向) | `净利/净利.shift(252)-1` | 净利润 |
| 动量(正向) | `复权收盘价/复权收盘价.shift(60)-1` | close/adj_factor |
| 反转(负向) | `-(复权收盘价/复权收盘价.shift(20)-1)` | close/adj_factor |
| 波动率(负向) | `日收益.rolling(20).std()` | close/adj_factor |
| 流动性(负向) | `换手率` | 换手率 |
| 杠杆(负向) | `资产负债率` | 资产负债率 |
| 盈利-ROE(正向) | `净利润/(每股净资产×总股本)` | 净利润/每股净资产/总股本 |
| 非线性规模 | `-(row_rank(log市值)-0.5)^2` | 总市值（中盘暴露代理） |
