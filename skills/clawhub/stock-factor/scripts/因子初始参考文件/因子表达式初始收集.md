# 因子表达式初始收集（Initial Factor Expression Collection）

> **目的**：收集"可直接计算"的因子初始表达式，作为后续整理为「全A解析（QuantAll）」表达式的基线。
> **覆盖范围**：Alpha158（索引+指针）、技术指标、经典量价/基本面、FamaFrench 五因子。
> **表达式形态**：本文件中的表达式为**初始形态**，采用类 Qlib 算子记号（见第 0 节），**不是** QuantAll 代码。后续转写 QuantAll 时按第 5 节字段映射即可。
> **来源**：Alpha158 提取自 Qlib 官方 `Alpha158`；技术指标/经典因子为业界标准定义；FamaFrench 为 Fama & French (2015) 五因子模型。

---

## 0. 记号约定（Notation）

字段（单只股票时间序列）：
| 记号 | 含义 |
| --- | --- |
| `open / high / low / close` | 开 / 高 / 低 / 收 |
| `volume` | 成交量 |
| `vwap` | 成交量加权均价 |
| `ret` | 日收益率，`close/REF(close,1) - 1` |
| `cap` | 总市值 |
| `float_cap` | 流通市值 |
| `equity` / `net_asset` | 净资产（所有者权益） |
| `ni` / `ni_ttm` | 归母净利润 / TTM |
| `rev` / `rev_ttm` | 营业收入 / TTM |
| `ocf_ttm` | 经营现金流 TTM |
| `total_debt` / `total_asset` | 总负债 / 总资产 |
| `float_shares` | 流通股本 |

算子（向量化，沿时间轴）：
| 算子 | 含义 |
| --- | --- |
| `MA(x, N)` | N 日简单移动平均 |
| `EMA(x, N)` | N 日指数移动平均 |
| `WMA(x, N)` | N 日 Wilder 平滑（用于 RSI/ADX 等） |
| `STD(x, N)` | N 日标准差 |
| `HHV(x, N)` / `LLV(x, N)` | N 日最大值 / 最小值 |
| `REF(x, N)` / `DELAY(x, N)` | N 日前值 |
| `SUM(x, N)` | N 日求和 |
| `ABS(x)` / `MAX(x,y)` / `MIN(x,y)` | 绝对值 / 逐元素最大 / 最小 |
| `SIGN(x)` | 符号函数（±1 / 0） |
| `RANK(x)` | 截面排名归一化到 0–1 |
| `PCTILE(x, N, p)` | x 在 N 日窗口内的 p 分位（p∈[0,1]） |
| `LOG(x)` | 自然对数 |
| `COV(x,y,N)` / `CORR(x,y,N)` | N 日协方差 / 皮尔逊相关 |

> 防除零统一加 `1e-12`；方向列中"正向"= 因子值越大越好，"反向"= 越小越好。

## 2. 技术指标因子（详细表达式）

> 经典 TA 指标，Alpha158 仅含其中基础算子（ROC/MA/STD/BETA/Slope 等），此处补全关键技术面。

| 因子名 | 初始表达式 | 含义 / 方向 |
| --- | --- | --- |
| **RSI(N=14)** | `RS = WMA(MAX(close-REF(close,1),0),N) / (WMA(MAX(REF(close,1)-close,0),N)+1e-12)`；`RSI = 100 - 100/(1+RS)` | 相对强弱，>70 超买 <30 超卖（反向/区间） |
| **MACD_DIF** | `EMA(close,12) - EMA(close,26)` | 快慢线差（正向） |
| **MACD_DEA** | `EMA(MACD_DIF, 9)` | 信号线 |
| **MACD_BAR** | `2 × (MACD_DIF - MACD_DEA)` | 柱（动量强弱，正向） |
| **KDJ_K(N=9)** | `RSV = (close - LLV(low,9)) / (HHV(high,9) - LLV(low,9) + 1e-12) × 100`；`K = WMA(RSV,3)` | 随机快线 |
| **KDJ_D** | `WMA(K, 3)` | 随机慢线（金叉/死叉参考） |
| **KDJ_J** | `3×K - 2×D` | 乖离（>100 超买） |
| **BOLL_MID(N=20)** | `MA(close, N)` | 布林中轨 |
| **BOLL_UP** | `BOLL_MID + 2×STD(close, N)` | 上轨 |
| **BOLL_DN** | `BOLL_MID - 2×STD(close, N)` | 下轨 |
| **BOLL_PCTB** | `(close - BOLL_DN) / (BOLL_UP - BOLL_DN + 1e-12)` | 价格在通道中位置（0~1，反向） |
| **ATR(N=14)** | `TR = MAX(MAX(high-low, ABS(high-REF(close,1))), ABS(low-REF(close,1)))`；`ATR = MA(TR, N)` | 真实波幅（波动率代理，反向） |
| **NATR** | `ATR / close × 100` | 归一化波幅（反向） |
| **WILLIAMS_R(N=14)** | `-100 × (HHV(high,N) - close) / (HHV(high,N) - LLV(low,N) + 1e-12)` | 威廉指标（反向，<-80 超卖） |
| **CCI(N=20)** | `TP = (high+low+close)/3`；`CCI = (TP - MA(TP,N)) / (0.015 × MEANDEV(TP,N) + 1e-12)` | 顺势指标（>100 超买） |
| **STOCH_K(N=14)** | `100 × (close - LLV(low,N)) / (HHV(high,N) - LLV(low,N) + 1e-12)` | 随机 %K（反向） |
| **STOCH_D** | `MA(STOCH_K, 3)` | 随机 %D |
| **OBV** | 累加 `SIGN(close-REF(close,1)) × volume` | 能量潮（量价确认，正向） |
| **MFI(N=14)** | `MF = TP × volume`；`pos=SUM(MAX(MF,0),N), neg=SUM(MAX(-MF,0),N)`；`MFI = 100 - 100/(1 + pos/(neg+1e-12))` | 资金流量指标（反向） |
| **CMF(N=20)** | `SUM((2×close-high-low)/(high-low+1e-12)×volume, N) / (SUM(volume,N)+1e-12)` | 蔡金资金流（正向） |
| **AD** | 累加 `(2×close-high-low)/(high-low+1e-12) × volume` | 累积/分布线（量价确认） |
| **PVT** | 累加 `((close-REF(close,1))/REF(close,1)) × volume` | 价量趋势（正向） |
| **VWAP(周期)** | `SUM(TP×volume, N) / (SUM(volume,N)+1e-12)` | 成交量加权均价 |
| **ADX(N=14)** | `+DI = 100×WMA(MAX(high-REF(high,1),0)/ATR,N)`；`-DI = 100×WMA(MAX(REF(low,1)-low,0)/ATR,N)`；`DX = 100×|＋DI-－DI|/(＋DI+－DI+1e-12)`；`ADX = WMA(DX, N)` | 趋势强度（非方向，反向） |
| **AROON_UP(N=20)** | `100 × (N - IDXMAX(high, N)) / N` | 距 N 日最高天数（正向） |
| **AROON_DN(N=20)** | `100 × (N - IDXMIN(low, N)) / N` | 距 N 日最低天数（反向） |
| **AROON_OSC** | `AROON_UP - AROON_DN` | Aroon 振荡（正向） |
| **PSAR** | 抛物线 SAR（加速因子递增，多空切换） | 跟踪止损 / 趋势 |
| **DPO(N=20)** | `close - REF(MA(close, N+1), (N+1)/2)` | 去趋势价格振荡（反向） |
| **DON_UP(N=20)** | `HHV(high, N)` | 唐奇安上轨 |
| **DON_DN(N=20)** | `LLV(low, N)` | 唐奇安下轨 |
| **KELTNER_UP(N=20,k=2)** | `EMA(close,N) + k×ATR(N)` | 肯特纳上轨 |
| **KELTNER_DN** | `EMA(close,N) - k×ATR(N)` | 肯特纳下轨 |
| **TRIX(N=20)** | `EMA3 = EMA(EMA(EMA(close,N),N),N)`；`TRIX = 100×(EMA3 - REF(EMA3,1))/(REF(EMA3,1)+1e-12)` | 三重平滑动量（正向） |
| **EMV(N=14)** | `BOX = (HIGH+LOW)/2 - REF((HIGH+LOW)/2,1)`；`BROAD = (HIGH-LOW)/volume`；`EMV = MA(BOX/BROAD, N)` | 简易波动（正向） |
| **BIAS(N=20)** | `(close - MA(close,N)) / (MA(close,N)+1e-12) × 100` | 乖离率（反向） |
| **MTM(N=12)** | `close - REF(close, N)` | 动量（正向） |
| **HIST_VOL(N=20)** | `STD(ret, N)` | 历史波动率（反向） |
| **DOWNSIDE_VOL(N=20)** | `STD(MIN(ret,0), N)` | 下行波动率（反向） |
| **VOL_RATIO(N=5)** | `volume / (MA(volume, N) + 1e-12)` | 量比（正向，放量） |

## 3. 经典量价 / 基本面因子（详细表达式）

> 补全 Alpha158 缺口：反转、12-1 动量、估值、成长、质量、规模、流动性。基本面字段以 A 股数据库常见字段表达。

### 3.1 反转 & 动量（Reversal / Momentum）

| 因子名 | 初始表达式 | 含义 / 方向 |
| --- | --- | --- |
| **REV_1M** | `-REF(close, 1)/REF(close, 21) + 1`（即 -近20日收益） | 一月反转（反向） |
| **REV_3M** | `-REF(close, 1)/REF(close, 61) + 1` | 三月反转（反向） |
| **MOM_12_1** | `REF(close,1)/REF(close,251) - 1 - (REF(close,1)/REF(close,21) - 1)` | 12-1 动量（剔除近月，正向） |
| **REL_STR** | `ret_stock - ret_market`（个股收益 − 市场收益） | 相对强度（正向） |

### 3.2 估值（Value）

| 因子名 | 初始表达式 | 含义 / 方向 |
| --- | --- | --- |
| **BP** | `net_asset / cap` | 净资产/市值（正向，低 PB） |
| **EP_TTM** | `ni_ttm / cap` | 盈利收益率（正向，低 PE） |
| **SP_TTM** | `rev_ttm / cap` | 营收/市值（正向，低 PS） |
| **CFOP** | `ocf_ttm / cap` | 现金流收益率（正向） |
| **DP** | `dividend_yr / cap` | 股息率（正向） |
| **EP_TTM_PCT_1Y** | `PCTILE(EP_TTM, 250, 当前分位)` | EP 历史分位（正向） |
| **BP_PCT_3Y** | `PCTILE(BP, 750, 当前分位)` | BP 三年分位（正向） |

### 3.3 成长（Growth）

| 因子名 | 初始表达式 | 含义 / 方向 |
| --- | --- | --- |
| **NI_YOY_Q** | `(ni_q - REF(ni_q, 4)) / (ABS(REF(ni_q,4)) + 1e-12)` | 单季净利同比（正向） |
| **REV_YOY_Q** | `(rev_q - REF(rev_q, 4)) / (ABS(REF(rev_q,4)) + 1e-12)` | 单季营收同比（正向） |
| **NI_CAGR_3Y** | `(ni_ttm / REF(ni_ttm, 12))^(1/3) - 1`（一致预期复合） | 净利复合增速（正向） |

### 3.4 盈利质量（Profitability / Quality）

| 因子名 | 初始表达式 | 含义 / 方向 |
| --- | --- | --- |
| **ROE_TTM** | `ni_ttm / ((net_asset + REF(net_asset,4))/2)` | 净资产收益率（正向） |
| **ROA_TTM** | `ni_ttm / ((total_asset + REF(total_asset,4))/2)` | 总资产收益率（正向） |
| **GROSS_MARGIN** | `(rev_ttm - cost_ttm) / (rev_ttm + 1e-12)` | 毛利率（正向） |
| **NET_MARGIN** | `ni_ttm / (rev_ttm + 1e-12)` | 净利率（正向） |
| **LEVERAGE** | `total_debt / (total_asset + 1e-12)` | 资产负债率（反向） |

### 3.5 规模 & 流动性 & 波动（Size / Liquidity / Vol）

| 因子名 | 初始表达式 | 含义 / 方向 |
| --- | --- | --- |
| **LN_CAP** | `LOG(cap)` | 市值对数（规模，反向） |
| **LN_FLOAT_CAP** | `LOG(float_cap)` | 流通市值对数（反向） |
| **TURNOVER** | `volume / (float_shares + 1e-12)` | 换手率（正向，流动性） |
| **AMIHUD** | `MEAN(ABS(ret) / (volume×close + 1e-12), N)` | 非流动性（反向，越低越好） |
| **AMOUNT** | `close × volume` | 成交额（流动性） |
| **VOLATILITY_60** | `STD(ret, 60)` | 60 日波动率（反向） |

## 4. FamaFrench 五因子（详细定义）

> Fama & French (2015) 五因子模型。组合层用市值/账面比/盈利/投资分组构建多空组合；**单股票因子层**用公司特征表达（便于 A 股逐股计算）。

| 因子名 | 组合层定义 | 单股票特征（初始表达式） | 含义 / 方向 |
| --- | --- | --- | --- |
| **MKT_RF** | 市场组合收益 − 无风险利率 | `ret_market - rf` | 市场超额收益（正向） |
| **SMB** | 小市值组合 − 大市值组合 | `SIZE = -LOG(cap)`（小市值=正向） | 规模（小盘正向） |
| **HML** | 高 BM − 低 BM | `BM = net_asset/cap`（高 BM 正向） | 价值（正向） |
| **RMW** | 高盈利 − 低盈利 | `OP = (rev_ttm-cost_ttm)/(equity+1e-12)`（高盈利正向） | 盈利质量（正向） |
| **CMA** | 低投资 − 高投资 | `INV = (total_asset - REF(total_asset,4)) / (ABS(REF(total_asset,4))+1e-12)`；`CMA = -INV`（低投资正向） | 投资风格（保守正向） |

> 组合层为市值加权多空收益序列；单股票层为截面排序所用的公司特征。A 股实盘通常用单股票特征做截面排序（rank）后构建组合。

## 5. 备注：后续整理为 QuantAll 表达式的映射要点

- **价格字段**：QuantAll 用复权价 `adj_close = close × adj_factor`；初始表达式里的 `close` 转写时需用复权价（除非明确用原始价）。
- **成交量**：`volume → d['vol']`；`vwap` 多数免费源无，近似 `(high+low+close)/3`。
- **市值/基本面**：`cap → d['总市值']`，`net_asset/ni/rev/ocf → d['...']`（依数据库字段名经 `db_translate.json` 映射）。
- **算子映射**：`MA→Mean`、`STD→Std`、`REF→Ref`、`HHV/LLV→Max/Min`、`EMA→`需 QuantAll 是否支持（否则用 `Mean` 近似或手写）、`WMA(Wilder)→`需自行实现平滑。
- **截面类**：`RANK/PCTILE` 对应 QuantAll 的 `row_rank` / 分位；`CORR/COV` 对应 `Corr`。
- **防除零**：保留 `1e-12`。
- **禁止写法**：QuantAll 不支持 `import/循环/lambda/axis=1`，转写时需保持向量化。
- 本文件表达式形态与 QuantAll 无关，仅作"初始收集"基线；正式因子代码见后续整理产出。
