# 因子收集 · Fama-French / HXZ 风格因子

> 收集时间：2026-08-13 ｜ 目的：把资产定价模型（定价/风格暴露）因子纳入 stock-factor 技能候选池
> 定位：这些因子是「风格暴露描述符」，短周期（5 日）IC 普遍偏弱，属正常（与 Barra CNE5 同类）。技能只负责收集+转写，不纠结 IC。

## 一、Fama-French 三因子 / 五因子（1993 / 2015）

原模型构造的是**多空组合收益序列**（SMB/HML/RMW/CMA = 排序后首尾组收益差），用于解释截面收益。
在 QuantAll「单股票截面因子」框架下，转写为**个股风格特征值**（引擎自动排名）：

| 因子 | 原模型含义 | 个股特征值转写 |
|---|---|---|
| MKT | 市场超额收益 | 个股日收益 − 无风险利率（A 股近似用个股收益，或 `get_stock_index('000001')` 做基准） |
| SMB | 小盘−大盘 | `Size = log(总市值)` |
| HML | 高−低 账面市值比（价值） | `BM = 每股净资产 / 复权收盘价`、`EP = 每股收益 / 复权收盘价` |
| RMW | 高−低 营业盈利能力 | `OP = 营业利润 / 总资产` |
| CMA | 低−高 资产投资（保守−激进） | `Inv = Δ总资产 / 总资产`（年度，shift(252)） |

## 二、Hou-Xue-Zhang q 因子模型（2015，张橹等）

从投资 q-理论推导的四因子：MKT、规模(ME)、投资(I/A)、盈利(ROE)。
学界认为对 A 股解释力强于 HML。

| 因子 | 含义 | 个股特征值转写 |
|---|---|---|
| ME | 规模 | `log(总市值)` |
| I/A | 投资→资产比（投资越高预期收益越低） | `Δ总资产 / 总资产`（年度，shift(252)） |
| ROE | 盈利能力 | `净利润 / 净资产`（`每股净资产×总股本`） |

## 三、转写要点（A 股适配）

- **总资产(TA)推导**：库无 TA 原值，用 `TA = 每股净资产 × 总股本 / (1 − 资产负债率)`（来自 `db_translate` 中文名）。
- **同比/年度变化**：财务数据按日向前填充，故用 `shift(252)`（≈1 年交易日）而非 `shift(1)`。
- **Momentum**：`12 个月收益（剔除最近 1 月）≈ ac/ac.shift(252)-1`，直接作特征值。
- **单因子输出**：`out = 特征值`，引擎自动排名；复合/多子项才用 `row_rank` 先排名再组合。
