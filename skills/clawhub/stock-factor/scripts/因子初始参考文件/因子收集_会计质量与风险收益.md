# 因子收集（会计质量 / 风险收益异象）— 来源、公式与数据缺口

> 本批 3 套，全部 `batch_factor_analysis` 实跑验证（全市场 5593 只，2024-08-14~2026-08-07，feature_days=5），`error_code.names=[]`。
> 字段名均比对 `db_translate.json` + `available_data.d` 确认。

## 一、会计质量 / 困境预警（factor-AccountingQuality.json，暂留参考区待定）
来源：Ohlson(1980) O-Score、Mohanram(2005) G-Score、Novy-Marx(2013) 毛利率质量、Sloan(1996) 应计。
总资产推导统一用：`equity = 每股净资产×总股本`；`TA = equity/(1−资产负债率)`。

| 因子 | 公式要点 | 状态 |
|---|---|---|
| ACCT_OHLSON_OSCORE | 9 变量线性组合（规模对数、TL/TA、WC/TA、CL/CA、NI/TA、OENEG、CHIN、Z） | ✅ 通过（coverage 0.44，252 日窗口前半段 NaN，非 bug） |
| ACCT_MOHANRAM_GSCORE | 8 变量二元计分；**DEPI（折旧指数）缺口**，现用 **6/7 变量**近似 | ⚠️ DEPI 缺「折旧」绝对值 |
| ACCT_NOVYMARX_GP | 毛利 / 总资产（毛利率质量） | ✅ 通过 |
| ACCT_ACCRUALS_TA | −(扣非净利润−经营现金流)/总资产（Sloan 应计，负向=高质量） | ✅ 通过 |

**数据缺口（已备注）**：Mohanram G-Score 的 **DEPI** 需要「折旧费用」绝对值，本地库 `d` 中仅含比率类（如 `资本支出/折旧摊销`），无 `折旧与摊销` 绝对值列 → 该子项无法计算，已剔除。补齐需 tushare `income.da` 或 `cashflow.dep` 入库。

## 二、收益高阶矩 / 52 周高价异象（factor-ReturnMoment.json，已入库 task/）
纯价量驱动，无数据缺口。

| 因子 | 公式 | IC / IR |
|---|---|---|
| ANOM_52WK_HIGH | close / 252 日最高价（贴近高点） | IC −0.006 / top10%IR **−0.468** |
| ANOM_BETA / BETA2 | 252 日市场回归 β / β² | −0.064 |
| ANOM_DOWNSIDE_VOL | 下行半离差 rolling(252).std()（min(ret,0)） | IR **−0.256** |
| ANOM_SKEW | 60 日收益偏度 | IR **−0.550** |
| ANOM_KURT | 60 日收益峰度 | bottom10%IR +0.340 |
| ANOM_IDIOSKEW | 市场回归残差 60 日偏度 | IR **−0.303** |

> 修正记录：ANOM_DOWNSIDE_VOL 初版用 `ret.where(mkt<0)` 因 1D 市场序列与个股面板对齐失败全 NaN，改为个股自身半离差（`ret.where(ret<0,0)`）后正常。

## 三、违约距离 / 现金流收益率（factor-Merton_CashFlow.json，已入库 task/）

| 因子 | 公式 | IC / IR |
|---|---|---|
| MERTON_DD | Merton(1974) 违约距离 = (ln(E/D)+ (μ−½σ²)T)/(σ√T)，σ/μ 取 252 日收益年化，D=TA×资产负债率，E=总市值 | IR **−0.249** |
| CF_OCF_YIELD | 每股经营现金流 / 股价 | +0.071 |
| CF_FCF_YIELD | 每股企业自由现金流 / 股价 | −0.140 |
| CF_EBITDA_YIELD | 息税折旧摊销前利润 / 总市值 | bottom10%IR −0.205 |
| CF_DIV_YIELD | 股息率TTM（直接字段） | +0.121 |

无数据缺口：现金流类均可用 `每股经营现金流净额`/`每股企业自由现金流量`/`息税折旧摊销前利润`/`股息率TTM` + `总市值`/`总股本` 推导。
