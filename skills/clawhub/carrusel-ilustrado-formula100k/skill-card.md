## Description:

Creates ready-to-publish Instagram carousel PNGs with minimalist Xiaohei-style illustrations, optional UI mockups, generated image assets, and Chrome-rendered HTML slides.

This skill is ready for commercial/non-commercial use.

## Publisher:

[formula100k](https://clawhub.ai/user/formula100k)

### License/Terms of Use:

MIT-0

## Use Case:

External creators, marketers, and content teams use this skill to turn a prepared carousel script into illustrated 5-8 slide Instagram assets with image prompts, local HTML renders, and final PNG files.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow may use configured image-generation services, create local files under entregables/, render local HTML with Chrome headless, and send resulting images through Telegram.

Mitigation: Confirm provider costs, output destination, and Telegram delivery before running large batches; review generated images and local render files before publication.
