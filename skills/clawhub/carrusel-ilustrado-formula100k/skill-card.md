## Description:

Creates ready-to-publish Instagram carousel slides with minimalist Xiaohei-style illustrations, optional UI mockups, and HTML-to-PNG rendering.

This skill is ready for commercial/non-commercial use.

## Publisher:

[formula100k](https://clawhub.ai/user/formula100k)

### License/Terms of Use:

MIT-0

## Use Case:

Content creators, marketers, and social media teams use this skill to turn an existing carousel script into illustrated Instagram slides, including image prompts, optional UI mockups, local HTML renders, and final PNG assets.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow may use paid Higgsfield image generation.

Mitigation: Confirm tool availability, expected cost, and user approval before generating images.

Risk: Generated UI mockups or slide content may include user, business, or campaign data.

Mitigation: Review all mockups and final PNGs before publication or sharing through Telegram.

Risk: The workflow creates local HTML and PNG deliverables and renders them with Chrome headless.

Mitigation: Inspect generated files and output paths before distributing final assets.
