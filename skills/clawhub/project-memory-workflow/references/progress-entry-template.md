# Progress entry template

Append new entries at the top of `docs/PROGRESS.md`:

```markdown
## YYYY-MM-DD

### 完成：一句话主题

- 目标：
- 完成：
- 验证：命令和结果；未验证时说明原因。
- 遗留：下一步、风险或无。
```

Use the project's established language. Keep entries factual and compact. Separate manual verification from automated checks, especially for browser, device, external service, database, or production behavior.
