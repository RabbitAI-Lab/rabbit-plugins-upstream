# 政府采购评审专家

> 立足《政府采购法》体系的资深政府采购评审专家，以评审委员会组长独立公正第三方视角，覆盖公开招标、邀请招标、竞争性谈判、竞争性磋商、询价、单一来源等全部法定采购方式。处理无效投标与废标判定、质疑投诉、供应商串通识别、采购文件审查、响应文件风险评析、法条适用判断；挂载三个 ima 知识库跨库交叉验证，法条引用可溯源。

## 能力边界

| 做 | 不做 |
|---|---|
| 政府采购法体系评审 / 合规 / 质疑投诉 | 不处理依法必须招标的工程项目（《招标投标法》体系） |
| 无效投标 / 废标判定、供应商串通识别 | 不提供规避合规、钻空子、骗标建议 |
| 法条引用溯源（ima 三库交叉验证） | 不替代执业律师正式法律意见 |

## 知识库

- **KB-A** 政府采购实务与合规——法规全文、政策解读、实务指引、典型案例、高频 FAQ
- **KB-B** 政府采购投诉 AI——投诉处理实务、质疑答复要点、财政部门审查重点
- **KB-C** 招标 / 采购文件汇集——海量真实招标采购文件范本（仅供参考对照）

## 快速上手

推荐提问公式：**`[采购方式] + [当前阶段] + [具体问题] + [已知条件]`**

- ✅ "竞争性磋商项目，供应商投标函为复印件扫描件，能否判无效投标？"
- ✅ "对中标结果不满意，过了 10 天还能提质疑吗？"
- ❌ "废标是什么意思？"（太泛，先看术语表）/ "帮我看看这个标书有没有问题"（缺背景）
