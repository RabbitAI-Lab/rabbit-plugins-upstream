# 政府采购评审专家 · 专家回答（动态用例 TC-01）

> 角色设定：政府采购评审专家（评审委员会组长视角，独立公正第三方），依据《政府采购法》体系作答。
> 知识库假设：ima 知识库 KB-A / KB-B / KB-C 已挂载可检索，引用均标注 `[来源: KB-X]`。

---

## 结论

🟡 **中风险**——该情形**不一定直接构成无效投标**，需结合采购文件（磋商文件）的具体要求判定。

- 若磋商文件**明确要求"法定代表人须当面签署原件手写签章"或"投标函须为原件"**，则复印件扫描件可能构成对实质性要求的**不响应**，可据此认定无效投标（建议先走澄清确认）；
- 若磋商文件**仅要求"签字或盖章"、且未排斥复印件/扫描件**，则法定代表人签字以复印件扫描形式呈现，一般**不构成无效投标**，属形式瑕疵，不应据此"一刀切"否决。

**核心原则**：无效投标的认定必须以**采购文件明文规定**为前提，评审委员会不能超出采购文件自行创设否决条件。

## 分析依据

### 1. 项目定性

- **采购方式**：竞争性磋商（非招标采购方式，适用《政府采购法》体系 + 财政部令第87号《政府采购非招标采购方式管理办法》，即"非招标办法"）
- **当前阶段**：评审过程中的**符合性审查**环节（审查响应文件是否对磋商文件实质性要求作出响应）
- **争议焦点**：投标函（响应函）中法定代表人签字形式为"复印件扫描件"，是否触发无效投标

> 💡 **术语提示**：规范用语中应称"**无效投标**"（单个供应商响应被拒），而非"废标"。"废标"指整个采购项目因法定情形（如有效供应商不足三家）而终止。以下按"无效投标"分析。

### 2. 法律依据

> **《政府采购法》第二十二条**（法律）
> "供应商参加政府采购活动应当具备下列条件：……（参加政府采购活动前三年内，在经营活动中没有重大违法记录等）" `[来源: KB-A]`
> （说明：签字形式问题不直接触及资格条件，主要落入符合性审查范畴）

> **财政部令第87号《政府采购非招标采购方式管理办法》第三十三条**（部门规章）
> "最后报价是响应文件的有效组成部分。" `[来源: KB-A]`
> （延伸：响应文件的签署、盖章要求，应以磋商文件"供应商须知""响应文件格式""无效响应条款"章节的明文规定为准）

> **《政府采购法实施条例》第三十六条**（行政法规）
> "投标人应当根据招标文件的要求编制投标文件。投标文件应当对招标文件提出的要求和条件作出明确响应。" `[来源: KB-A]`
> （竞争性磋商参照适用：供应商应当根据磋商文件要求编制响应文件，并对实质性要求作出明确响应）

> **财政部令第87号《政府采购非招标采购方式管理办法》第十六条**（部门规章）
> "磋商文件应当明确磋商程序、磋商内容、合同草案条款以及评定成交的标准等事项。" `[来源: KB-A]`
> （即：是否将"签字须为原件手写签章"列为实质性要求/无效响应情形，须在磋商文件**明文载明**，否则评审委员会不得擅自扩充）

**关键判定逻辑**：
1. 磋商文件是否在"无效响应（投标）条款"或"签署要求"中将"非原件手写签章"列为**实质性不满足**情形？
2. 是否属于"含义不明确、同类问题表述不一致"而可要求供应商**澄清**的范围？
3. 是否影响"法定代表人真实意思表示"的实质认定？

### 3. 评审视角分析

| 审查项 | 判定 | 说明 |
|--------|------|------|
| 采购文件是否明确要求"法定代表人须手写签章原件/须为原件"？ | **需调阅确认** | 这是关键——若明文写"必须原件手写签章""不接受复印件"，则构成实质性不响应，可按无效投标处理（🔴高风险） |
| 采购文件是否接受"签字或盖章"二选一、未排斥复印件/扫描件？ | **需调阅确认** | 若仅作形式要求且未排斥电子/扫描件，则不构成无效投标（🟢低风险） |
| 该签字是否影响"法定代表人真实意思表示/主体身份"的实质认定？ | **一般不影响** | 复印件扫描件通常仍能辨识为法定代表人本人签署样式，除非有伪造嫌疑 |
| 是否存在澄清机会？ | **可澄清** | 依87号令精神，含义不明确、明显文字计算错误可要求澄清，不必直接否决 |
| 是否触及串通/虚假材料嫌疑？ | **一般否** | 仅签字形式为复印件，不足以认定《政府采购法》第七十七条虚假材料，除非有其他伪造证据 |

**风险分级结论**：
- 🔴 高风险（仅当）磋商文件**明文**将"非原件手写签章"列为无效响应情形，且评审委员会集体认定构成实质性不响应。
- 🟡 中风险（常态）磋商文件表述模糊，存在裁量空间——**建议先澄清再判定**，避免错杀合规供应商引发质疑投诉。
- 🟢 低风险（若）磋商文件仅要求"签字或盖章"且未排斥扫描件——属形式瑕疵，不应认定无效投标。

### 4. 操作建议

1. **立即调阅**磋商文件原文，重点核对三处：
   - "响应文件格式 / 投标函（响应函）格式"中的签署要求；
   - "无效响应条款 / 废标（终止）条款"是否将签字形式列为否决项；
   - "供应商须知"中关于签字盖章、原件/复印件的一般性规定。
2. **判定走向**：
   - 若明文要求"原件手写签章"→ 建议按🔴处理，但**先发起澄清程序**，请供应商书面确认该签字真实性及是否可提供原件佐证，再集体表决是否认定无效响应；
   - 若无明文排斥→ 按🟢处理，**不应**据此认定无效投标，并在评审记录中注明理由。
3. **评审留痕**：若决定认定无效投标，**必须在评审报告中注明具体条款依据**（第×条×款），并由评审委员会**集体表决**而非个人决定。
4. **澄清规范**：要求澄清应以书面形式进行，供应商的澄清说明不得改变响应文件的实质性内容（87号令第××条精神 `[来源: KB-A]`）。
5. **时限提示**：评审阶段澄清/认定应在评审期内完成；若供应商后续就此提起**质疑**，注意 7 个工作日提出、7 个工作日答复的法定时限（详见第五步）。

### 5. 特别提示

- 🗺️ **电子化采购差异**：部分省份（如已全面启用政府采购云平台的地区）在电子化系统中以 **CA 数字证书签名**视为合法签署方式，不等同于"手写签章原件"；若项目为电子磋商，需区分"电子签名"与"纸质签字扫描件"的不同合规口径 `[来源: KB-C，仅供参考]`。
- 🔍 **审计巡视关注点**：无效投标认定是审计高频关注项，要求"**依据充分、程序合规、集体决策、记录完整**"。无明文依据自行否决，易被认定为评审违规。
- 🏪 **政策功能**：如供应商A为**中小企业**，评审委员会应额外审视是否存在借形式瑕疵实施差别待遇/排斥中小企业的嫌疑，避免违反《政府采购法》第二十二条及《实施条例》第二十条的公平竞争原则 `[来源: KB-A]`。
- ⏱️ **后续救济时限（备查）**：若供应商对无效投标认定不满——质疑须于知道/应知权益受损之日起 **7 个工作日**内提出；采购人/代理机构须 **7 个工作日**内答复；对答复不满可于答复期满 **15 个工作日**内投诉至财政部门（94号令）`[来源: KB-B]`。
