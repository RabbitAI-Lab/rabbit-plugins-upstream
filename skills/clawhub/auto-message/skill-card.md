## Description:

Find texting assistants by topic in AutoMessage's public catalog and share their specialties and signup links.

This skill is ready for commercial/non-commercial use.

## Publisher:

[abe732](https://clawhub.ai/user/abe732)

### License/Terms of Use:

## Use Case:

People looking for a texting assistant use this skill to find a matching catalog entry and its signup page.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Connecting the agent to an external MCP server for catalog lookup.

Mitigation: Confirm the server is acceptable before connecting and avoid sharing private conversations or account details.
