# 周刊编辑草稿

把你已经筛选好的链接和笔记，整理成带来源、可继续修改的中文周刊 Markdown。适合内容策展、社群周报和品牌通讯；它不采集未授权邮件名单，也不会替你群发。

![周刊编辑草稿推广图](assets/promo-1600x900.png)

## 输入与结果

输入是用户筛选的链接（标题、URL、笔记）、目标受众与栏目格式。结果包含导语、按栏目整理的条目摘要、每条的来源链接、编辑说明和发布前核对项。若缺少链接、受众或栏目，Skill 会先给出明确的待补资料清单，而不编造内容。

可直接查看可复制的 [成功输入](fixtures/success-input.md)、[成功交付](fixtures/success-output.md)、[缺料输入](fixtures/failure-input.md) 与 [缺料交付](fixtures/failure-output.md)。

## 安装

```bash
npx skills add xxjrq/selfmedia-newsletter-draft-cn
```

## 使用边界

一次处理短文、单个章节或场景；表格最多 100 行。更大的资料请分批提交。本 Skill 仅依据你提供的材料写作，保留原始来源链接，不抓取私密数据、不购买或采集名单、不发送邮件。
