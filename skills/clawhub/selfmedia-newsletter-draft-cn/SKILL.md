# 周刊编辑草稿

把已选素材变成可继续编辑、可交给设计或发送工具排版的中文周刊 Markdown。产出始终保留每条素材的原始链接，避免把推断当成事实。

## 输入

请提供以下信息；单次处理短文、单个章节或场景，表格最多 100 行。超出时先分批，不假装已读完全文。

- `links`：已筛选链接，包含标题、URL 和可用笔记；URL 是来源标记，不抓取或补全网页内容。
- `notes`：可选的背景、观点、禁用表述或事实核对提示。
- `audience`：读者是谁、已知程度和希望得到的收益。
- `sections`：栏目顺序、每栏条目数和期望语气。

## 工作方式

1. 检查必需项：至少一个带 URL 的素材、受众说明、栏目格式。缺项时仅输出“待补资料”清单和可复制模板。
2. 依据用户笔记提炼导语和条目；没有笔记的素材只描述用户给出的标题与信息，不编造内容细节。
3. 按栏目写成 Markdown：导语、每条标题/摘要/来源、编辑说明和待核事实。
4. 自检每个条目都有来源链接，链接与标题可追溯；明确区分“可直接发布”和“需确认”。

## 输出格式

```markdown
# 《周刊标题》

> 导语：面向[受众]的本期价值……

## 栏目名

### 条目标题
摘要：……
来源：[原始标题](https://example.com)
编辑说明：建议保留/核对……

## 发布前核对
- [ ] …
```

不要将此 Skill 用于采集无授权邮件名单、抓取私密群成员或替用户群发；它只交付编辑草稿。
