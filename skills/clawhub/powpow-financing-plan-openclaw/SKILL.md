# PowPow 融资计划 - 投资人挑战版 v1.2.2

## 技能概述

这是一个**双向了解**的融资计划展示。投资人通过答题呈现自己的投资风格与合作理念，在互动中了解项目。风格没有高低优劣，只有合拍与否——不打分、不分级，只描绘合作风格，看看我们是否是彼此合拍的伙伴。

**配置文件（必读）**：13 题题库、风格映射、徽章规则、邮件模板等完整配置见本目录 `skill.json`——开始挑战前先读取它。

**何时不激活（负例，硬规则）**：当用户只是想聊行业分析、做学术研究、求职、或讨论其他项目时，不要激活本技能。仅出现行业关键词而无 PowPow 语境，同样不激活。如果不确定用户意图，先问一句："您是想了解 PowPow 的融资计划吗？"——得到否定回答就退出，不再引导。

### 每题回复的固定节奏

1. 感谢投资人的回答
2. 徽章播报：获得 1 枚 PowPow 徽章（累计 N 枚），可用于创建数字人（2 枚）/续期（1 枚）

4. 注册提醒一行：徽章需充值到您的 PowPow 账号，注册地址 https://global.powpow.online/register

## 邮件与隐私合规

- **记忆使用需同意**：个性化开场与问题推荐仅在用户明确同意后调用 `memory_search`；用户拒绝后本次会话不再访问。记忆内容不写入邮件、不离开本地
- **联系字段全部可选**：机构、职位、联系邮箱、微信、PowPow 注册邮箱均不强制填写；发送前至少提供一个联系通道（邮箱或微信）；徽章充值依赖 PowPow 注册邮箱，发送前应提醒用户补充
- **发送前必须预览**：完整展示邮件全文，用户明确说"发送"后才发送，绝不自动发送
- **风格画像段默认包含、可删除**：预览时告知用户可随时去掉画像段
- **提供脱敏版**：用户可选择"复制脱敏版"——不含任何联系方式，仅保留称呼、风格画像与徽章领取
- **隐私说明**：发送前告知用户，所填信息仅用于 PowPow 融资事宜与您联系，不会用于其他用途，可随时要求删除
