## Description:

使用 Nano Banana 2 / Gemini Image 把同一 SKU 的多角度商品图校准为统一的电商影棚批次，统一白底、白平衡、主体比例、阴影与光感，同时保护每个视角真实可见的端口、鞋底、缝线、标签和包装文字。

This skill is ready for commercial/non-commercial use.

## Use Case:

External commerce content teams and developers use this skill to normalize multi-angle product photos for the same SKU into a consistent studio batch while preserving view-specific product facts. It supports catalog workflows for marketplaces such as Amazon, Taobao, Tmall, JD.com, TikTok Shop, Shopify, and related e-commerce channels.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Selected product images are uploaded to AI Hive for generation.

Mitigation: Use --preview first to inspect the prompt and source order, and run the skill only with images approved for that service.

Risk: The skill stores or reads an AI Hive API key locally or from the environment.

Mitigation: Prefer environment-scoped credentials when possible and keep the local config file restricted to the current user.

Risk: Under-specified batch or view locks can produce retouches that alter product facts.

Mitigation: Provide the required truth sources, batch locks, view locks, and acceptance criteria before generating final images.
