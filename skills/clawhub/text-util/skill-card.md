## Description:

Lightweight text transformation utilities for uppercasing, lowercasing, reversing, and counting characters, words, and lines in text input.

This skill is ready for commercial/non-commercial use.

## Publisher:

[terrycarter1985](https://clawhub.ai/user/terrycarter1985)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and external users use this skill for quick local text transformations, including case conversion, string reversal, and character, word, and line counts without writing a separate script.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Sensitive text passed as command-line arguments may be exposed through shell history or local process listings on shared systems.

Mitigation: Avoid using the skill with secrets or confidential text in shared environments; use safer input handling for sensitive material.
