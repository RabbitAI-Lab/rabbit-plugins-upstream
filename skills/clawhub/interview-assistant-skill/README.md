# 面试助手（interview-assistant-skill）

> **参赛作品 · SkillHub 线上挑战赛（第 1 期）**
> 主题：**让开会更简单** ｜ 基于官方「腾讯会议 Skill（tmeet）」二创

把一场面试从「凭感觉」变成「有结构、可追溯、可对比」。覆盖 **会前准备 → 会中记录 → 会后评估** 完整闭环，全部建立在 tmeet 的通讯录与会议数据之上。

---

## 为什么做这个（差异化）

赛事介绍明确点名「面试」场景，但当前参赛作品中**几乎没有专门的面试助手**——多数集中在通用会议助手、行动项、纪要模板。面试是高频、强痛点、且最易被感知价值的场景，契合度天然高，是本期最值得冲奖的空旷赛道。

---

## 特性

- ✅ 全链路：会前画像+提纲 / 会中记录 / 会后评分与录用建议
- ✅ 对接 tmeet：通讯录检索候选人、拉取会议智能纪要/转写
- ✅ 本地兜底：无 tmeet 时用本地简历/纪要素材，附 `interview_helper.py`
- ✅ 五维度结构化：技术能力 / 相关经验 / 沟通表达 / 文化匹配 / 潜力
- ✅ 可追溯：缺失证据标「待验证」，不臆造结论
- ✅ 可独立运行：纯标准库 Python 脚本，零第三方依赖

---

## 快速开始

**在线模式**
> 用户：给候选人张三做画像，准备一场后端工程师面试。
> 助手：tmeet 通讯录检索张三 → 读 JD → 输出五维度面试提纲。

> 用户：刚结束张三的面试，生成评估表。
> 助手：tmeet 拉取本场纪要 → 抽信号 → 输出评分表 + 录用建议。

**本地模式**
```bash
python scripts/interview_helper.py \
  --resume examples/张三_简历.md \
  --jd examples/后端工程师_JD.md \
  --notes examples/张三_面试记录.md \
  --output 张三_评估表.md
```

---

## 辅助脚本 `scripts/interview_helper.py`

| 参数 | 说明 |
|------|------|
| `--resume` | 候选人简历/背景（.md/.txt） |
| `--jd` | 岗位 JD（.md/.txt） |
| `--notes` | 面试记录/纪要（.md/.txt） |
| `--output` | 输出评估表路径 |
| `--name` | 候选人姓名（用于标题） |

脚本用**可解释的关键词信号统计**对五个维度各打 1-5 分，并给出优势/风险/录用建议。它是评估逻辑的离线实现，也是「完成度 / 可独立运行」评分的支撑。

## 与比赛主题的契合

- **让开会更简单**：面试本身是一场高成本会议，本 Skill 把准备与复盘压缩到分钟级，直接降低面试会议全生命周期成本。

- **可独立运行 + README 完整**：附本地脚本与完整文档，满足海选 TRACE 自动评测要求。
