# 面试评估模板（evaluation_template）

> interview-assistant-skill 在会后阶段套用的结构化评估骨架。

```markdown
# 面试评估表 · {候选人}

| 维度 | 评分(1-5) | 信号说明 |
|------|----------|----------|
| 技术能力 | ★★★★☆ | 基于回答中的原理/源码/架构信号 |
| 相关经验 | ★★★★★ | 同类项目体量匹配 |
| 沟通表达 | ★★★★☆ | 逻辑性、复述确认 |
| 文化匹配 | ★★★★☆ | 协作、owner 意识 |
| 潜力 | ★★★★★ | 学习、开源、自驱 |

**综合录用建议：{强烈推荐/推荐/待定/不推荐}**

## 待验证项（记录中缺少信号，建议二面重点考察）
- {维度}：{具体问题}

## 岗位要求匹配（JD 关键词命中）
- {命中的要求关键词}

> 评估为辅助决策，最终录用由人判断；缺失证据项标「待验证」，不臆造。
```

## 五维度释义

- **技术能力**：知识点深度、解决问题思路、边界与原理意识。
- **相关经验**：与岗位要求的匹配度、同类项目体量。
- **沟通表达**：逻辑性、倾听、复述确认。
- **文化匹配**：协作风格、冲突处理、价值观契合。
- **潜力**：学习能力、自驱、成长性。

> 多人面试同一岗时，可将多份评估表并列，横向对比同一维度得分，辅助终面决策。
