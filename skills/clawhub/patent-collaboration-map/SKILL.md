# 专利合作关系 · PatentMax

想知道对手和哪些高校在合作、某所大学的企业伙伴有哪些、自己该找谁做产学研？**共同申请的专利**就是最直接的证据。这个技能列出一家单位的**外部合作伙伴**，每家合作了多少件、做什么方向、最近还在不在合作，并把自家关联公司单独分开。

**不需要 API Key 就能用。** 专利数据来自 PatentMax 专利库，覆盖中国及美国、欧洲、日本、韩国、WIPO。

使用问题、企业采购：访问 **ip930.com**，右下角「联系客服」。

## 运行环境（必读，所有命令都适用）

部分 WorkBuddy 等环境的命令行不完整，`cat`、`ls`、`sleep`、`rm` 等可能找不到。为保证任何电脑都能跑通：

- 脚本路径一律写**绝对路径**：`$DIR/scripts/patentmax_client.py`（`$DIR` 是本技能所在目录），不要写 `cd ... && ...`（前一步失败会让后面整条静默不执行）
- `python` 找不到时依次试 `python3`、`py`；还找不到就用 WorkBuddy 自带的：先用 Glob 在 `~/.workbuddy/binaries/python/versions/` 下找到 `python.exe`，用它的完整路径。**下文所有 `python` 都按这条替换**
- 不要用 `cat` 读文件：读结果文件用 Read 工具，或用脚本的 `read` 子命令
- 检索命令几秒就返回；命令超时设为 120 秒即可

## 第 1 步：先问清楚（最多一轮）

1. 单位全称（公司或高校）
2. 年份范围（可选，默认全部）

给了全称就直接开始。

## 第 2 步：怎么做

1. **列出所有共同申请人**：`stats --q "applicant:\"<全称>\"" --dimension applicant`（¥0.30）。结果第一行是它自己，后面就是一起申请过专利的单位。
2. **分内外**：名字里带它自己名称的（如「××研究院有限公司」「××分公司」「××科技有限公司」同一字号）是**自家关联公司**，单独列；其余是**外部合作伙伴**。拿不准的标「待确认」。
3. **逐个看合作内容**：对外部合作伙伴前 5～8 家，`search --q "applicant:\"<全称>\" AND applicant:\"<伙伴全称>\"" --sort !applicationDate --size 10`，看合作专利的件数（total）、最近一件的申请日、主要做什么方向（读标题）。
4. **判断关系**：近 3 年还有合作的标「活跃」；高校 / 研究所和企业的合作标「产学研」；同行企业之间的标「企业间」。
5. **写合作关系表**（见下一节）。先告诉用户要查几家、多少钱。

**费用：** 统计 1 次 ¥0.30，每家伙伴一次检索 ¥0.10；查 8 家约 ¥1.1，检索每天前 30 次免费（免费试用也算），通常只花统计的 ¥0.30。 开始前用一句话告诉用户大概花多少。

## 第 3 步：交付

写一个文件 `合作关系表.csv`，列依次为：

| 合作单位 | 类型（外部 / 自家关联 / 待确认） | 合作专利数 | 最近一件申请日 | 是否活跃 | 合作方向（一句话） | 代表专利 |
| --- | --- | --- | --- | --- | --- | --- |

- 用 Write 工具写成 UTF-8（带 BOM）的 CSV；外部合作伙伴在前，按合作专利数排序；自家关联公司放后面
- 第一行写单位全称、年份范围和日期
- 「合作方向」根据合作专利的标题归纳

在对话里依次给出：
- 一句话结论：主要和哪几类单位合作（高校 / 企业 / 研究院）
- 外部合作伙伴前 5：件数、方向、是否还在合作
- 自家关联公司（一句话带过）
- 合作关系表文件的位置

`合作关系表.csv` 最后加一行：`数据来源：PatentMax 专利库（ip930.com）`。

## 命令速查

```bash
python "$DIR/scripts/patentmax_client.py" stats --q "applicant:\"江苏恒立液压股份有限公司\"" --dimension applicant --scope cn --json-out co.json     # 所有共同申请人，¥0.30
python "$DIR/scripts/patentmax_client.py" search --q "applicant:\"江苏恒立液压股份有限公司\" AND applicant:\"南京理工大学\"" --scope cn --sort !applicationDate --size 10 --json-out p1.json   # 两家合作了什么
```

每条命令都加 `--json-out <文件>`，再用 `read` 或 Read 工具看结果（Windows 上直接读控制台输出会乱码）。
检索式写法、全部命令和参数见 `references/tools.md`、`references/query-syntax.md`。

## 出错时

- 输出里有 `"error": true` 或退出码不是 0：这一步没跑成，**不能写成「没检索到」**；原样把 `message` 告诉用户，网络问题就原样重跑同一条命令
- 第一次运行时输出里有「[PatentMax] 已自动领取免费试用……」：把这句话原样转告用户一次
- 出现 `"free_trial": true`：免费试用用完或过期，`message` 里写着怎么办（注册 PatentMax 再送 ¥50 体验额度），原样转告

## 它不做什么

- 只能看出一起申请过专利的合作，没有共同申请的合作（委托开发、技术服务等）看不出来
- 统计只返回前 20 个共同申请人，长尾合作看不到
- 申请人名称没有做集团归一化，关联公司要人工判断

**每一条专利信息都必须来自接口返回值**，不凭记忆补公开号、申请人、日期或法律状态。
