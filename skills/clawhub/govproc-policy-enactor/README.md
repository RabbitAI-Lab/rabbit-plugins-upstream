# 政采政策红利落实引擎（采购人版）（govproc-policy-enactor）

采购人 / 采购代理机构编制政府采购文件时，把法定政策红利**正确、合规地落实**进文件的辅助工具。输出可直接粘贴的条款模板与合规红线。

## 功能范围

- 中小企业预留份额 / 价格评审优惠（财库〔2020〕46号 + 财库〔2022〕19号）
- 项目所属行业绑定（GB/T 4754-2017）与划型标准
- 联合体 / 分包中的小微企业份额（≥30%）条款
- 绿色采购、强制节能（财库〔2019〕9号品目清单）
- 特殊群体视同：监狱企业（财库〔2014〕68号）、残疾人福利企业（财库〔2017〕141号）
- 乡村振兴 832 帮扶预留
- 工程类"双法交叉"显式判定与边界告知
- 采购人审查三原则 + 合规红线 + 降级策略

## 设计要点

- **正向落实 + 合规起草**：只做"把红利写进文件"，不做评标、不裁定投标人资格。
- **决策树驱动**：Mermaid 决策树 + CoT 步骤，降低分支遗漏。
- **法条溯源**：挂载知识库 `7463496212028405`「政府采购实务与合规」，比例与条款须引用库内原文（含发文号+条款号）。
- **双法分轨**：仅限政府采购法体系；依法必须招标工程仅边界告知并转介《招标投标法》。
- **状态管理**：槽位快照 + 关键槽位变更重判 + 结论确认-锁定。
- **降级策略**：KB 无命中 / 数据矛盾 / 解析失败均不臆造。
- **文档完整性预检**：仅上传采购需求书/技术规格时，提示补充完整招标文件，避免把"需求书无条款"误读为"项目无政策"。
