## Use Case:

Phantra account holders use this guide after installation to connect their workspace, review studio activity, learn available creation workflows, and approve any credit spending.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Reference photos and URLs are processed by Phantra and may contain material the user should not share.

Mitigation: Use only reference material the user is authorized and comfortable providing.

Risk: Image generation, effects, and rendering spend account credits.

Mitigation: Show the quoted cost and balance, then wait for the user's explicit approval before spending; do not repeat a spend.

Risk: The connected service implementation was not included in this review.

Mitigation: Review the service implementation separately when assessing risks beyond these setup instructions.
