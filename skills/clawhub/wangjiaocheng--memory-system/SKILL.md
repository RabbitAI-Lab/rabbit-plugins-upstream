# 多层记忆系统

## 定位

本技能提供从短期记忆到长期记忆的完整方法论。

**核心价值**：让AI具备分层记忆能力，实现信息的长期保存、按需检索和智能维护。

## 核心能力

### 分层存储能力

将记忆分为多个层级，每层有不同的作用域和生命周期：

- **Cloud Memory（云端记忆）**：跨项目的长期记忆，由服务器管理
- **Local Memory（本地记忆）**：用户级的本地记忆，跨项目共享
- **Workspace Memory（工作区记忆）**：项目级的工作区记忆，仅当前项目可见

### 记忆写入能力

根据信息类型和重要性，选择合适的存储层级：

- **自动写入**：完成重要工作后自动记录
- **手动写入**：用户明确要求记住的信息
- **选择写入**：根据信息类型选择存储层级

### 记忆检索能力

根据需求从合适的层级检索信息：

- **上下文注入**：自动注入相关记忆到上下文
- **按需检索**：根据用户请求检索特定记忆
- **智能匹配**：根据当前任务匹配相关记忆

### 记忆维护能力

定期维护记忆，确保信息的准确性和时效性：

- **清理过期**：删除过时或无用的记忆
- **合并重复**：合并重复或相似的记忆
- **归档旧记忆**：将旧记忆归档到长期存储

## 使用规则

### 执行流程

1. **记忆识别**：识别需要记忆的信息
2. **层级选择**：根据信息类型选择存储层级
3. **记忆写入**：将信息写入选定的层级
4. **记忆检索**：根据需求检索相关记忆
5. **记忆维护**：定期维护记忆系统

### 记忆写入规则

**写入时机**：
- 完成重要工作后
- 用户明确要求记住时
- 发现重要规律或模式时

**层级选择**：
| 信息类型 | 存储层级 | 原因 |
|----------|----------|------|
| 用户偏好/习惯 | Local Memory | 跨项目共享 |
| 项目规范/约定 | Workspace Memory | 仅当前项目需要 |
| 长期事实/知识 | Cloud Memory | 永久保存 |

**写入格式**：
```markdown
## 记忆标题

### 内容
[记忆的具体内容]

### 来源
[记忆的来源或上下文]

### 时间
[记忆的创建时间]

### 标签
[记忆的分类标签]
```

### 记忆检索规则

**检索时机**：
- 用户询问相关信息时
- 执行相关任务时
- 需要参考历史经验时

**检索策略**：
1. 首先检索Workspace Memory（当前项目相关）
2. 然后检索Local Memory（用户相关）
3. 最后检索Cloud Memory（全局相关）

**检索结果处理**：
- 将相关记忆注入上下文
- 根据相关性排序
- 过滤过时或无用信息

### 记忆维护规则

**维护频率**：
- 每天：清理临时记忆
- 每周：合并重复记忆
- 每月：归档旧记忆

**维护操作**：
- 清理：删除过时或无用记忆
- 合并：合并重复或相似记忆
- 归档：将旧记忆归档到长期存储

## 执行框架

本技能内嵌了完整的记忆管理执行框架。

**核心理念**：
- **分层存储**：不同层级存储不同类型的信息
- **按需检索**：根据需求从合适层级检索信息
- **智能维护**：定期维护确保记忆质量

**统一执行流程**：收到任务后按5步执行——记忆识别 → 层级选择 → 记忆写入 → 记忆检索 → 记忆维护。

### Step 0：记忆识别

识别需要记忆的信息：
- 信息类型（事实/偏好/规范/知识）
- 重要程度（高/中/低）
- 时效性（长期/短期/临时）
- 作用域（全局/用户/项目）

### Step 1：层级选择

根据信息特征选择存储层级：
- Cloud Memory：长期事实、全局知识
- Local Memory：用户偏好、个人习惯
- Workspace Memory：项目规范、工作约定

### Step 2：记忆写入

将信息写入选定的层级：
- 格式化记忆内容
- 添加元数据（时间、来源、标签）
- 写入到对应文件

### Step 3：记忆检索

根据需求检索相关记忆：
- 分析检索需求
- 从合适层级检索
- 过滤和排序结果
- 注入到上下文

### Step 4：记忆维护

定期维护记忆系统：
- 清理过时记忆
- 合并重复记忆
- 归档旧记忆
- 更新索引

## 事实纪律

1. 记忆写入必须准确，不可虚构
2. 记忆检索必须全面，不可遗漏
3. 记忆维护必须及时，不可延迟
4. 记忆格式必须规范，不可随意
5. 记忆安全必须保障，不可泄露
