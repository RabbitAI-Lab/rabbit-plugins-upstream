- **域ID**: M4

### 任务执行范本

#### M4-01 维护需求分析
**执行步骤**:
1. 分析维护目标
2. 界定维护范围
3. 设定维护频率
4. 确认维护需求
5. 输出维护需求分析

**输入示例**:
- 维护目标：保持记忆系统整洁和高效
- 维护范围：所有记忆层级
- 维护需求：定期清理过期记忆，合并重复记忆

**输出示例**:
- 维护目标：保持记忆系统整洁和高效
- 维护范围：Cloud Memory、Local Memory、Workspace Memory
- 维护频率：每天清理临时记忆，每周合并重复记忆，每月归档旧记忆
- 需求确认：维护需求明确

**注意事项**:
- 维护目标要明确，避免模糊
- 维护范围要合理，避免过宽或过窄
- 维护频率要适当，避免过于频繁或稀疏
