## M3 记忆检索域 范本

### 范本概述
- **域ID**: M3
- **域名称**: 记忆检索域
- **任务数量**: 5
- **范本状态**: 可用

### 任务执行范本

#### M3-01 检索需求分析
**执行步骤**:
1. 接收检索请求，明确检索目标
2. 分析检索范围
3. 设定检索条件
4. 确认检索需求
5. 输出检索需求分析

**输入示例**:
- 检索请求：查找用户的编程偏好
- 检索目标：获取用户喜欢的编程语言和用途
- 检索范围：用户级记忆

**输出示例**:
- 检索目标：获取用户编程偏好
- 检索范围：Local Memory
- 检索条件：标签包含"偏好"、"编程"
- 需求确认：检索需求明确

**注意事项**:
- 检索目标要明确，避免模糊
- 检索范围要合理，避免过宽或过窄
- 检索条件要准确，避免错误

#### M3-02 检索策略制定
**执行步骤**:
1. 选择检索方法
2. 确定检索顺序
3. 界定检索范围
4. 制定检索策略
5. 确认检索策略

**输入示例**:
- 检索目标：获取用户编程偏好
- 检索范围：Local Memory
- 检索条件：标签包含"偏好"、"编程"

**输出示例**:
- 检索方法：关键词检索、标签检索
- 检索顺序：先检索标签，再检索内容
- 检索范围：Local Memory
- 检索策略：使用关键词和标签进行检索，优先检索最近的记忆
- 策略确认：检索策略合理

**注意事项**:
- 检索方法要有效，避免无效
- 检索顺序要合理，避免混乱
- 检索范围要明确，避免模糊

#### M3-03 记忆检索执行
**执行步骤**:
1. 准备检索
2. 执行检索
3. 获取检索结果
4. 确认检索状态
5. 输出检索结果

**输入示例**:
- 检索策略：使用关键词和标签进行检索
- 检索范围：Local Memory
- 检索条件：标签包含"偏好"、"编程"

**输出示例**:
- 检索执行：已执行检索
- 检索结果：找到用户偏好Python用于数据分析
- 检索状态：成功
- 检索确认：检索成功，找到相关记忆

**注意事项**:
- 检索执行要准确，避免错误
- 检索结果要完整，避免遗漏
- 检索状态要及时更新，避免延迟

#### M3-04 结果过滤排序
**执行步骤**:
1. 制定过滤标准
2. 设定排序规则
3. 执行过滤排序
4. 确认过滤排序结果
5. 输出过滤排序结果

**输入示例**:
- 检索结果：找到多条相关记忆
- 过滤需求：只保留最相关的记忆
- 排序需求：按相关性排序

**输出示例**:
- 过滤标准：相关性高于0.8
- 排序规则：按相关性降序排序
- 过滤排序结果：保留最相关的3条记忆
- 结果确认：过滤排序结果合理

**注意事项**:
- 过滤标准要合理，避免过度过滤
- 排序规则要明确，避免混乱
- 过滤排序结果要准确，避免错误

#### M3-05 上下文注入
**执行步骤**:
1. 准备注入目标
2. 准备注入内容
3. 执行上下文注入
4. 确认注入状态
5. 输出注入结果

**输入示例**:
- 注入目标：当前对话上下文
- 注入内容：用户偏好Python用于数据分析
- 注入需求：在对话中体现用户偏好

**输出示例**:
- 注入目标：当前对话上下文
- 注入内容：已注入用户偏好
- 注入状态：成功
- 注入确认：上下文注入成功，对话将体现用户偏好

**注意事项**:
- 注入目标要明确，避免错误
- 注入内容要准确，避免虚假
- 注入状态要及时更新，避免延迟
