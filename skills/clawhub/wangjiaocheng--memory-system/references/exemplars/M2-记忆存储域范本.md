## M2 记忆存储域 范本

### 范本概述
- **域ID**: M2
- **域名称**: 记忆存储域
- **任务数量**: 5
- **范本状态**: 可用

### 任务执行范本

#### M2-01 存储层级选择
**执行步骤**:
1. 分析信息特征
2. 识别存储层级类型：Cloud/Local/Workspace
3. 确定选择理由
4. 确认存储层级选择
5. 输出存储层级选择结果

**输入示例**:
- 信息类型：偏好
- 信息内容：用户喜欢使用Python进行数据分析
- 信息特征：用户级偏好，需要跨项目共享

**输出示例**:
- 存储层级类型：Local Memory
- 选择理由：用户偏好需要跨项目共享，但不需要永久保存
- 选择确认：Local Memory是最佳选择

**注意事项**:
- 存储层级类型要准确，避免错误
- 选择理由要充分，避免牵强
- 选择确认要严格，避免问题

#### M2-02 记忆格式设计
**执行步骤**:
1. 分析记忆需求
2. 设计记忆格式
3. 确定记忆结构
4. 定义记忆字段
5. 确认记忆格式设计

**输入示例**:
- 记忆类型：偏好
- 记忆需求：存储用户编程偏好
- 格式要求：结构化、易于检索

**输出示例**:
- 记忆格式：Markdown格式
- 记忆结构：标题、内容、来源、时间、标签
- 记忆字段：title、content、source、time、tags
- 格式确认：格式规范，结构清晰

**注意事项**:
- 记忆格式要规范，避免随意
- 记忆结构要清晰，避免混乱
- 记忆字段要完整，避免遗漏

#### M2-03 元数据配置
**执行步骤**:
1. 定义元数据字段
2. 设定元数据值
3. 确认元数据格式
4. 配置元数据
5. 确认元数据配置

**输入示例**:
- 记忆格式：Markdown格式
- 记忆字段：title、content、source、time、tags
- 元数据需求：记录记忆的创建时间和来源

**输出示例**:
- 元数据字段：time、source、tags
- 元数据值：time=当前时间，source=用户对话，tags=[偏好, 编程, Python]
- 元数据格式：time=YYYY-MM-DD HH:mm:ss，source=字符串，tags=数组
- 配置确认：元数据配置完整

**注意事项**:
- 元数据字段要完整，避免遗漏
- 元数据值要准确，避免错误
- 元数据格式要规范，避免随意

#### M2-04 记忆写入执行
**执行步骤**:
1. 准备写入目标
2. 准备写入内容
3. 执行记忆写入
4. 确认写入状态
5. 输出写入结果

**输入示例**:
- 写入目标：Local Memory
- 写入内容：用户偏好Python用于数据分析
- 写入格式：Markdown格式

**输出示例**:
- 写入目标：Local Memory
- 写入内容：已写入用户偏好
- 写入状态：成功
- 写入确认：记忆已成功写入Local Memory

**注意事项**:
- 写入目标要明确，避免错误
- 写入内容要准确，避免虚假
- 写入状态要及时更新，避免延迟

#### M2-05 写入验证
**执行步骤**:
1. 制定验证标准
2. 选择验证方法
3. 执行写入验证
4. 确认验证结果
5. 输出验证报告

**输入示例**:
- 写入目标：Local Memory
- 写入内容：用户偏好Python用于数据分析
- 验证标准：记忆可检索、内容准确、格式规范

**输出示例**:
- 验证标准：记忆可检索、内容准确、格式规范
- 验证方法：检索测试、内容比对、格式检查
- 验证结果：通过
- 验证确认：记忆写入成功，验证通过

**注意事项**:
- 验证标准要严格，避免宽松
- 验证方法要有效，避免无效
- 验证结果要准确，避免错误

### 范本特征摘要
- **结构特征**: 按记忆存储流程组织，从存储层级选择到写入验证，步骤清晰
- **风格特征**: 专业、详细、实用，使用明确的输入输出示例
- **逻辑特征**: 从存储选择到写入验证，逻辑严密，步骤明确
