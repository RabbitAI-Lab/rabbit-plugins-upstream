## M1 记忆识别域 范本

### 范本概述
- **域ID**: M1
- **域名称**: 记忆识别域
- **任务数量**: 5
- **范本状态**: 可用

### 任务执行范本

#### M1-01 信息类型识别
**执行步骤**:
1. 接收信息，明确信息内容
2. 分析信息特征
3. 识别信息类型：事实/偏好/规范/知识
4. 确认信息类型
5. 输出信息类型识别结果

**输入示例**:
- 信息内容：用户喜欢使用Python进行数据分析
- 信息来源：用户对话
- 信息背景：用户正在讨论编程偏好

**输出示例**:
- 信息类型：偏好
- 信息特征：关于编程语言和用途的偏好
- 信息确认：用户偏好Python用于数据分析

**注意事项**:
- 信息类型要准确，避免混淆
- 信息特征要全面，避免遗漏
- 信息确认要严格，避免错误

#### M1-02 重要程度评估
**执行步骤**:
1. 制定重要程度评估标准
2. 分析信息重要性
3. 评估重要程度：高/中/低
4. 确认评估结果
5. 输出重要程度评估

**输入示例**:
- 信息类型：偏好
- 信息内容：用户喜欢使用Python进行数据分析
- 评估标准：影响频率、影响范围、影响程度

**输出示例**:
- 重要程度：高
- 评估依据：用户经常进行数据分析，Python是主要工具
- 评估确认：该偏好对用户工作影响较大

**注意事项**:
- 评估标准要客观，避免主观臆断
- 评估过程要严谨，避免草率
- 评估结果要准确，避免错误

#### M1-03 时效性分析
**执行步骤**:
1. 分析信息时效性特征
2. 识别时效性类型：长期/短期/临时
3. 评估时效性
4. 确认时效性分析结果
5. 输出时效性分析

**输入示例**:
- 信息类型：偏好
- 信息内容：用户喜欢使用Python进行数据分析
- 时效性特征：编程偏好通常长期有效

**输出示例**:
- 时效性类型：长期
- 时效性评估：编程偏好通常长期有效，除非用户明确表示改变
- 时效性确认：该偏好应长期保存

**注意事项**:
- 时效性类型要准确，避免错误
- 时效性评估要合理，避免过度乐观或悲观
- 时效性确认要严格，避免问题

#### M1-04 作用域确定
**执行步骤**:
1. 分析信息作用域特征
2. 识别作用域类型：全局/用户/项目
3. 确定作用域范围
4. 确认作用域确定结果
5. 输出作用域确定

**输入示例**:
- 信息类型：偏好
- 信息内容：用户喜欢使用Python进行数据分析
- 作用域特征：用户偏好应跨项目共享

**输出示例**:
- 作用域类型：用户
- 作用域范围：用户级，跨项目共享
- 作用域确认：该偏好应存储在Local Memory

**注意事项**:
- 作用域类型要准确，避免错误
- 作用域范围要明确，避免模糊
- 作用域确认要严格，避免问题

#### M1-05 记忆需求汇总
**执行步骤**:
1. 收集记忆识别结果
2. 制定记忆策略
3. 设定记忆优先级
4. 汇总记忆需求
5. 确认记忆需求汇总

**输入示例**:
- 信息类型：偏好
- 重要程度：高
- 时效性：长期
- 作用域：用户

**输出示例**:
- 记忆策略：长期保存用户偏好，跨项目共享
- 记忆优先级：高
- 记忆需求：需要将用户偏好存储到Local Memory，定期更新
- 需求确认：记忆需求明确，策略合理

**注意事项**:
- 记忆策略要合理，避免问题
- 记忆优先级要明确，避免混淆
- 记忆需求要全面，避免遗漏

### 范本特征摘要
- **结构特征**: 按记忆识别流程组织，从信息类型识别到记忆需求汇总，步骤清晰
- **风格特征**: 专业、详细、实用，使用明确的输入输出示例
- **逻辑特征**: 从信息识别到需求汇总，逻辑严密，步骤明确
- **格式特征**: 使用Markdown格式，包含步骤、输入输出示例、注意事项
