## 记忆系统方法论要求清单

记忆系统领域每种任务类型的"零件清单"——必选/可选组件、组装顺序、领域约束。按清单逐项产出。

---

### 记忆数据结构规范

#### 记忆字段定义

| 字段 | 类型 | 必选 | 说明 |
|------|------|------|------|
| id | string | 是 | 记忆唯一标识符 |
| title | string | 是 | 记忆标题 |
| content | string | 是 | 记忆内容 |
| type | string | 是 | 记忆类型：fact/preference/norm/knowledge |
| importance | string | 是 | 重要程度：high/medium/low |
| timeliness | string | 是 | 时效性：long-term/short-term/temporary |
| scope | string | 是 | 作用域：global/user/workspace |
| source | string | 是 | 记忆来源 |
| tags | array | 否 | 标签列表 |
| created_at | string | 是 | 创建时间，格式：YYYY-MM-DD HH:mm:ss |
| updated_at | string | 是 | 更新时间，格式：YYYY-MM-DD HH:mm:ss |
| accessed_at | string | 否 | 最后访问时间，格式：YYYY-MM-DD HH:mm:ss |
| access_count | number | 否 | 访问次数 |

#### 存储层级说明

| 层级 | 说明 | 适用场景 |
|------|------|----------|
| Cloud Memory | 云端记忆，跨项目共享 | 长期事实、全局知识 |
| Local Memory | 本地记忆，用户级共享 | 用户偏好、个人习惯 |
| Workspace Memory | 工作区记忆，仅当前项目 | 项目规范、工作约定 |

### M0 记忆协调域

#### M0-01 记忆需求分析
- **必选组件**: 记忆来源、记忆类型、记忆范围、记忆目标
- **可选组件**: 记忆优先级、记忆重要性
- **组装顺序**: 记忆接收→类型识别→范围确定→目标设定→需求汇总
- **约束**: 记忆来源必须可靠；记忆类型必须准确；记忆范围必须明确
- **格式**: 记忆需求分析报告（Markdown）

#### M0-02 记忆域选择
- **必选组件**: 可用记忆域列表、记忆域选择理由、记忆域组合方案
- **可选组件**: 记忆域依赖关系说明
- **组装顺序**: 需求分析→记忆域扫描→选择决策→组合设计
- **约束**: 记忆域选择必须基于记忆需求，不可强行套用
- **格式**: 记忆域选择报告（Markdown）

#### M0-03 执行顺序确定
- **必选组件**: 记忆任务依赖关系分析、执行顺序方案、关键路径识别
- **可选组件**: 并行执行可能性分析
- **组装顺序**: 依赖分析→顺序确定→关键路径识别
- **约束**: 执行顺序必须尊重记忆任务依赖关系
- **格式**: 执行顺序图（Markdown流程图）

#### M0-04 结果整合与优化
- **必选组件**: 各记忆任务执行结果汇总、整合方案、优化建议
- **可选组件**: 整合效果评估
- **组装顺序**: 结果收集→整合分析→优化建议
- **约束**: 整合必须保持各记忆任务输出的完整性
- **格式**: 整合报告（Markdown）
