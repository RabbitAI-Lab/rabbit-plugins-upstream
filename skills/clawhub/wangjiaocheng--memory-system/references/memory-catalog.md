## 记忆系统清单与依赖拓扑

记忆系统按使用流程组织的方法论执行任务清单，附任务间关系和元操作映射提示。

**域间逻辑流**：M0 → M1 → M2 → M3 → M4（执行框架按需调用）

---

---

### 依赖拓扑摘要

**入口任务**：M0-01, M1-01, M2-01, M3-01, M4-01

**关键路径**：M0-01 → M0-02 → M0-03 → M0-04

**并行机会**：
- M1-02, M1-03, M1-04 可并行执行
- M4-02, M4-03, M4-04 可并行执行

**域间依赖**：
- M0 域依赖 M1-M4 域的执行结果
- M1 域为 M2 域提供记忆需求
- M2 域为 M3 域提供存储的记忆
- M3 域为 M4 域提供检索结果
- M4 域为 M0 域提供维护结果
