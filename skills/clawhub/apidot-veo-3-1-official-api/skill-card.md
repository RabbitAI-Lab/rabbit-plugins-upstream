## Known Risks and Mitigations: <br>
Risk: API keys, private prompts, media URLs, callback URLs, or generated video URLs could be exposed during real APIDot API work. <br>
Mitigation: Keep APIDOT_API_KEY in a server-side secret store and avoid logging or sharing private prompts, media URLs, callback URLs, generated video URLs, or API keys. <br>
Risk: The skill may point agents to API workflows whose request fields, availability, or terms can change. <br>
Mitigation: Use the current APIDot docs and model pages before preparing payloads or making live API calls. <br>
