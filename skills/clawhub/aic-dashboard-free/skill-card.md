## Description: <br>
AIC Dashboard Free provides a lightweight, read-only local web dashboard for viewing recent inbox entries and browser session status from local files. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[thcjp](https://clawhub.ai/user/thcjp) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and operators use this skill to start a local monitoring dashboard for AI Commander inbox and session state. It is intended for local, read-only visibility into the latest mailbox summaries and browser session status. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The local dashboard can display mailbox summaries and session status, and access depends on a generated token that may be exposed through copied URLs or screenshots. <br>
Mitigation: Keep the generated URL private, avoid sharing screenshots or links that include the token, and stop the local service when it is no longer needed. <br>
