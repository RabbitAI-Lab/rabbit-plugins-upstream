# 功能介绍

个人技能工坊通过一问一答，把个人经验、已有材料和重复工作整理成 AI 可以读取和使用的技能。你负责说明希望完成的工作、提供材料和纠正理解，AI 负责整理规则、生成文件并记录验证结果。

当前版本为 **1.0.2 正式版**。本文介绍技能的设计与用法，验证范围和使用限制分别见[实测结果](TEST-RESULTS.md)与[已知问题](KNOWN-ISSUES.md)。

## 主要功能

| 功能 | 使用时的体验 |
| --- | --- |
| 一问一答 | 每轮围绕一个关键缺口提问，不一次给出整套问卷；信息足够后开始生成 |
| 主动吸收补充 | 你可以一次补充多条要求；已有信息直接采用，避免重复索取 |
| 从材料提炼规则 | 利用现有模板、好坏样例和历史说明，整理格式、判断依据及例外情况 |
| 有依据地补全 | 区分已知信息、推导、可逆默认和未知项；重要事实或业务口径缺依据时保留未知 |
| 生成技能文件 | 形成 `SKILL.md`，必要时附带参考资料、模板和确定性操作脚本 |
| 多轮修改 | 根据新要求更新技能，保留仍有效的规则和旧版本，标出需要重验的部分 |
| 继续已有工作 | 从可读取的会话记录与文件恢复要求；恢复能力依赖宿主能提供这些记录 |
| 分层验证 | 分别记录结构检查、实际任务执行、宿主加载情况，以及失败和未执行项 |

## 可以从哪些工作开始

例如周报整理、材料摘要、内容写作、表格处理、资料归档、固定流程检查。它们是可尝试的应用方向，并非本版本逐项完成验证的领域清单。

适合的起点是一件经常重复、有可提供输入、能观察结果好坏的工作。如果只是一次性的改写或查询，通常无需先制作技能。

## 你会得到什么

- 可复用的技能目录及最短启动语句。
- 已确认的规则、必要默认、尚未解决的问题。
- 根据任务需要生成的参考资料、模板或脚本。
- 已执行验证的结果和证据位置，以及没有验证的条件。

复杂任务可包含多项能力；最终交付范围取决于实际需求、材料和宿主工具。没有文件写入能力的纯聊天环境可以提供可复制文本，但这不等于已经在电脑上创建文件或执行脚本。

## 技能生成规则

工坊要求先把本次任务的输入、实体、处理规则、输出视图和完成条件写入生成技能，再派生引用、模板、示例及当前状态。生成规则包括来源冲突处理、数值与日期有效范围、CSV 物理起始行号、最新要求同步和实际输出检查。受限内容按适用字段和交付视图检查，要求保留普通内容；通过规范档案组织拒坏自检，记录遗漏或不适用的类别。这些规则和工具不保证生成者总能正确执行，已观察到的缺陷见[已知问题](KNOWN-ISSUES.md)。

## 环境要求

文本问答需要能够读取技能说明及相关资源的 AI 工具。文件读写、外部应用操作与脚本执行需要宿主提供相应能力。

包内可选本地工具使用 **Python 3.10+ 标准库**，用于结构审计和已采集实验记录的评估，不会自动调用模型、运行全部业务测试或替你发送消息。使用技能无需单独申请 TypeSafe/Jev API 密钥；所用 AI 工具自身的账号和费用按该工具规则处理。

开始使用请看[安装使用说明](INSTALL.md)。
