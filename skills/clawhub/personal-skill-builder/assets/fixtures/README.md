# 实验材料

这些文件是 personal-skill-builder 的固定合成实验输入，不能拿作用户真实业务材料。

- U09-session.json：恢复制作流程使用的旧记录。
- U13-damaged.xlsx：刻意损坏的附件，用于读取失败分支。
- U13-replacement.csv：后续轮提供的替代数据。

suite 使用 {{FIXTURES_DIR}} 占位。调度者将其替换为本目录的实际位置；不要把本机绝对路径写进可复用技能。

执行者只接收当前轮所需的文件；不要预读后续轮材料。原文件只读，各次实验写入各自输出目录。
## anomaly/（1.0.2-dev.8 新增）

合成夹具，供 `scripts/run_anomaly_selftest.py` 验证检查器：越界数量须显示未知、同实体冲突逐版本保留（来源行号/原始数量/普通备注）、硬要求不被弱化。含正确产物和已知坏产物（负数原样显示、补零、行号基准错位、漏备注/原始数量/版本/实体、规则被弱化或只在非必读文件）。只作模式参考，不是用户业务数据。

dev.9 增补：`matrix-*.json` 为四份拒坏矩阵（表格、冲突、多行/空行物理行号、规则弱化），`raw-ml.csv` 含空行与多行引号记录，表格夹具含非法日期；`../patterns/cn-currency.json` 为金额规则及正反例。

dev.10 增补：`raw-money.csv`、`money-*`、`matrix-restricted.json` 验证金额清理在全部输出字段生效（物品/备注/提醒漏清理、误删普通内容、残留裸数字均被拒）；`trace-*` 增加范围收窄条款；所有矩阵按 `../../mutation-profiles.json` 规范档案声明类别。
