## Known Risks and Mitigations:

Mitigation: Confirm user comfort before use, enable privacy mode where appropriate, and prefer aliases, percentages, and scale bands over raw names or amounts.

Risk: The skill can read and write portfolio notes when memory paths are configured.

Mitigation: Verify the configured memory path and privacy mode before installation or use.
