## Description: <br>
Figma Toolkit Free helps agents extract Figma design context, screenshots, variables, and assets and produce React or Vue component code. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[thcjp](https://clawhub.ai/user/thcjp) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and designers use this skill to turn individual Figma files or nodes into component code, export design assets, and extract design variables for personal workflows. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The security scan reports broad read, write, and command execution authority with vague create, modify, delete, and callback behavior. <br>
Mitigation: Review the skill before installation and require explicit confirmation before command execution, package installation, callback URL use, or any create, modify, or delete operation. <br>
Risk: Figma files and personal access tokens may be exposed to the agent and its Figma tooling during use. <br>
Mitigation: Use only Figma files and tokens that are appropriate to expose, scope tokens narrowly when possible, and keep output directories limited to the active project. <br>
