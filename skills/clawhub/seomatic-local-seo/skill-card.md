## Description:

Reviews a local business's Google Business Profile, local search positions, Search Console queries, and location pages, then recommends or stages relevant fixes through SEOmatic.

This skill is ready for commercial/non-commercial use.

## Publisher:

[minh42](https://clawhub.ai/user/minh42)

### License/Terms of Use:

MIT-0

## Use Case:

Local business owners and their agents can use this skill to review Google Business Profile performance, local rankings, customer reviews, Search Console queries, and location-page signals. It summarizes the main constraints and can stage profile or website changes for approval in SEOmatic.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may cause the skill to run for requests that are not relevant to a local business.

Mitigation: Invoke it when the user has a local-business SEO need, such as Google Maps visibility, Business Profile reviews, local rankings, or location pages.

Risk: The security review was partial because a referenced path could not be resolved.

Mitigation: Resolve the missing reference and complete the review before treating the security assessment as complete.
