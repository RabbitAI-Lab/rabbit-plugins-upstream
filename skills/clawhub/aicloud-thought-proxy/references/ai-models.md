## 模糊语言映射表

| 用户模糊说法 | 解析规则 |
|---|---|
| "最新模型" | 从该品牌型号列表选版本号最高 / 官方标注最新的（如 Qwen3.8-Max 而非 Qwen3.7-Max） |
| "最强模型" | 选能力最强旗舰（通常是最新 Max / Pro / Opus / 深度思考档；如 DeepSeek 选专家模式而非快速模式） |
| "专家模式" | 深度思考 / 推理模式（DeepSeek 专家模式） |
| "快速模式" | 标准即时回答模式（DeepSeek 快速模式） |
| "识图模式" | 多模态 / 视觉模型 |
| "带联网 / 联网搜索" | 开启该品牌的联网搜索开关 |
| "不需要联网" | 关闭联网搜索，纯知识回答 |
| "默认 / 你决定" | 选该品牌最均衡型号 + 标准模式 |

无法唯一确定时，列出候选并让用户确认，不擅自猜测。

## 打开对话页后的标准设置流程（通用）

1. 等待页面加载完成，识别对话输入框。
2. 按需设置模式：
   - 深度思考 / 专家模式：寻找侧栏或输入框附近模式按钮，点击切换（DeepSeek 在页面左侧）。
   - 联网搜索：寻找"联网搜索"开关，按用户意愿开 / 关。
3. 切换到纯文本模式（若站点提供），关闭无关组件，便于直接查看与复制代码。
4. 发送阶段 4 的协作协议消息，确认回复后再进入协作循环。

## 注意事项

- 站点可能强制手机验证码 / 扫码登录：提示用户手动完成。
- 部分站点（ChatGPT / Claude / Gemini / Grok）需要特定网络环境：若打不开或反复跳验证，告知用户并建议换国内品牌。
- 免费额度与会员限制可能影响回复长度 / 频率：遇到"继续生成"或限流提示时如实告知用户。
