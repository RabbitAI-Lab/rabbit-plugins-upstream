## Description:

Tally lets an agent read Tally forms and submissions through an OOMOL-connected oo CLI workflow.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers with connected OOMOL and Tally accounts use this skill to inspect Tally forms and submissions, including listing forms, fetching form details, and reading submission responses.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup instructions include remote installer commands that can execute local code.

Mitigation: Review before installing and prefer a pinned, verifiable oo CLI release or official installation flow that has been inspected.
