# Changelog

## 6.7.0

This first public release packages the evidence-conserving editing model and the original written-taboo risk mapping.

Highlights include the four editing gates, independent read-only fidelity audit, `NO-OP` rollback, `rewrite` / `conditional` / `review_only` dispositions, minimum-edit budget, short-text threshold clarification, and a public-source risk mapping that does not reproduce referenced guidance.

## Earlier development

The public release history begins at 6.7.0. Pre-release development history is intentionally not included in this repository.
