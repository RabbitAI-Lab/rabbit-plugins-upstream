# 学科分类体系

> 用于判定题目所属学科和子领域，确保解题策略选型正确。

## 一、数学 (Mathematics)

### 1.1 初等数学
| 子领域 | 典型题型 | 关键词 |
|--------|----------|--------|
| 数与代数 | 方程、不等式、函数 | 一元二次、因式分解、根 |
| 平面几何 | 三角形、圆、四边形 | 全等、相似、勾股定理 |
| 立体几何 | 柱锥球、空间位置 | 体积、表面积、截面 |
| 解析几何 | 直线、圆锥曲线 | 椭圆、双曲线、抛物线 |
| 三角函数 | 三角恒等变换、解三角形 | sin/cos/tan、正弦定理 |
| 数列 | 等差、等比、递推 | 通项公式、求和 |
| 概率统计 | 排列组合、期望方差 | 古典概型、二项分布 |
| 向量与复数 | 平面向量、复数运算 | 模长、夹角、共轭 |

### 1.2 高等数学
| 子领域 | 典型题型 | 关键词 |
|--------|----------|--------|
| 微积分 | 极限、导数、积分 | 洛必达、泰勒展开、定积分 |
| 线性代数 | 矩阵、行列式、特征值 | 秩、逆矩阵、对角化 |
| 概率论 | 随机变量、分布函数 | 正态分布、大数定律 |
| 离散数学 | 图论、组合数学 | 鸽巢原理、生成函数 |

## 二、物理 (Physics)

| 子领域 | 典型题型 | 关键词 |
|--------|----------|--------|
| 力学 | 牛顿定律、动量能量 | 受力分析、动能定理、万有引力 |
| 电磁学 | 电路、电磁感应 | 欧姆定律、楞次定律、左手定则 |
| 热学 | 热力学定律、理想气体 | PV=nRT、热机效率 |
| 光学 | 折射反射、干涉衍射 | 薄透镜、双缝干涉 |
| 近代物理 | 量子、相对论 | 光电效应、质能方程 |
| 振动与波 | 简谐运动、机械波 | 波长频率、波的叠加 |

## 三、化学 (Chemistry)

| 子领域 | 典型题型 | 关键词 |
|--------|----------|--------|
| 无机化学 | 元素周期律、化学平衡 | 氧化还原、配位化合物 |
| 有机化学 | 官能团、反应类型 | 加成、取代、消去 |
| 物理化学 | 热化学、电化学 | 焓变、原电池、电解池 |
| 分析化学 | 滴定、离子检验 | 酸碱滴定、沉淀 |
| 物质结构 | 原子轨道、分子构型 | sp杂化、VSEPR |

## 判定规则（优先级从高到低）

1. 公式中含 $E=mc^2$、$F=ma$ 等 → 物理
2. 化学方程式含 $→$、$⇌$、化学式 → 化学
3. DNA、ATP、光合作用等词 → 生物
4. 含文言文、之乎者也 → 语文·文言文
5. 英文段落 + 选择题 → 英语
6. 纯数学符号 → 数学
7. 朝代、人物、事件年号 → 历史
8. 地图、等温线、气候 → 地理
