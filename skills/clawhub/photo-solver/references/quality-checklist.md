# 解题质量检查清单

> 每次生成解题报告后，对照此清单逐项验证。全部通过才算合格。

## 题目识别

- [ ] 题号（如有）正确标注
- [ ] 已知条件完整提取，无遗漏
- [ ] 图表中的数据点/曲线趋势正确识别
- [ ] 模糊手写体的不确定处已标注"[疑似]"并提示用户确认
- [ ] 用户补充说明已纳入题目卡片

## 学科判定

- [ ] 学科标签正确
- [ ] 子领域细化到三级（学科→章节→知识点）
- [ ] 跨学科题目已标注混合学科
- [ ] 知识点标签数量 2-6 个（过少说明不够细，过多说明不够聚焦）

## 解题步骤

- [ ] 步骤拆分合理，每步聚焦一个问题
- [ ] 每步包含「做什么」+「为什么这样做」
- [ ] 步骤顺序逻辑自洽，不可跳步
- [ ] 公式使用 KaTeX 正确书写，无渲染错误
- [ ] 易错步骤已标注 ⚠️ 警告
- [ ] 计算题有验算环节
- [ ] 证明题每步标注了依据
- [ ] 多解情况均列出，标注最优

## 答案

- [ ] 答案醒目展示（绿色边框 + 加粗 + 大字号）
- [ ] 答案格式与题目要求一致（不要用分数答题却给小数）
- [ ] 选择题同时显示选项字母 + 内容
- [ ] 数值答案带有单位（物理/化学）
- [ ] 数量级检查已通过

## 举一反三

- [ ] 变式题与原题知识点相同/相近
- [ ] 变式题难度 ±1 级（不要差距过大）
- [ ] 有简要思路提示
- [ ] 不要只是改数字，要有方法层面的变化

## HTML 报告

- [ ] 文件能正常在浏览器打开
- [ ] KaTeX 公式全部渲染
- [ ] 移动端（375px 宽）阅读无横向滚动
- [ ] 打印样式不显示按钮和交互元素
- [ ] 折叠/展开功能正常
- [ ] 颜色对比度达标（文字可读）
- [ ] 无 JavaScript 报错
- [ ] 无硬编码的测试数据残留

## 边界情况

- [ ] 不完整题目已标注缺条件并说明假设
- [ ] 超出能力范围的题目已诚实告知
- [ ] 疑似考试作弊的实时题已拒绝

## 用户体验

- [ ] 文字回复中的总结 ≤ 5 行
- [ ] 完整答案在 HTML 报告中可查
- [ ] `present_files` 正确调用
