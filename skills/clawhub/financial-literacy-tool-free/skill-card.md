## Known Risks and Mitigations: <br>
Risk: The security review found that this mostly text-based financial education skill requests shell execution and file-writing authority without a clear need. <br>
Mitigation: Install or operate it with read-only Markdown access where possible, and avoid granting shell execution or file-writing permissions unless separately justified. <br>
Risk: Financial education content can be mistaken for personalized financial advice. <br>
Mitigation: Use the skill for general education only and confirm financial decisions against current regulations, product disclosures, and qualified professional advice. <br>
