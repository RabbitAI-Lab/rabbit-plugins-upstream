## Description:

Helps frontend and product teams fix mobile responsiveness, navigation layout, and cross-device UI issues with practical workflows, checklists, analysis, and implementation support.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, designers, startup teams, and maintainers use this skill to diagnose and fix responsive web layout, navigation, and cross-device usability issues. It produces practical workflows, checklists, analysis, implementation support, and verification notes for mobile and desktop interfaces.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad triggers may activate the skill for general frontend or layout requests where a more specific skill would be preferable.

Mitigation: Narrow trigger wording or confirm the user's responsive-layout intent before relying on the workflow.

Risk: Responsive layout recommendations or code edits may alter navigation and cross-device behavior.

Mitigation: Review changes in representative mobile and desktop viewports before deployment.
