## Description:

Helps frontend developers, designers, startup teams, and maintainers fix mobile responsiveness, navigation layout, and cross-device UI issues through practical workflows, checklists, analysis, and implementation support.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, designers, startup teams, and maintainers use this skill to turn a mobile responsiveness or navigation layout problem into a scoped workflow, concrete artifact, checklist, analysis, code change, or validation note.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation keywords may cause the skill to appear for general frontend or layout requests outside mobile responsiveness and navigation layout work.

Mitigation: Prefer explicit invocation for responsive-layout tasks and confirm the user's target viewport, layout problem, and success criteria before applying the workflow.
