## Description:

12-agent academic paper writing pipeline for planning, drafting, revising, citation checking, disclosure support, formatting, bilingual abstracts, and publication-oriented academic outputs.

This skill is for research and development only.

## Publisher:

[sedey999](https://clawhub.ai/user/sedey999)

### License/Terms of Use:

CC BY-NC 4.0

## Use Case:

External users, researchers, students, and academic writers use this skill to plan, draft, revise, review, format, and disclose AI assistance for academic manuscripts across multiple paper types and citation styles.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may process unpublished manuscript text and related academic materials.

Mitigation: Install and run it only where those materials are permitted, and protect or delete generated local reports and output packages that contain sensitive work.

Risk: Optional cross-model or API verification can send described content to another provider.

Mitigation: Enable external verification only after explicitly accepting that provider exposure for the relevant manuscript content.

Risk: Citation, formatting, and disclosure outputs can affect submission quality.

Mitigation: Review citation checks, formatting changes, and generated disclosure text before submitting academic work.
