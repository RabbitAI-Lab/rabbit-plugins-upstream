## Description:

Turns authorized short-drama trailer remake requests into a Chinese production workflow with trailer structure analysis, suspense hooks, character conflict, subtitle cards, original adaptation guidance, AI-HIVE generation commands, and acceptance checks.

This skill is ready for commercial/non-commercial use.

## Use Case:

External marketing, short-drama promotion, media buying, and editing teams use this skill to turn authorized reference trailers and source footage into reviewable trailer plans, shot tables, prompts, runnable AI-HIVE commands, and continuity checks. Developers and operators can also use the bundled scripts to create project blueprints, submit image or video generation jobs, poll tasks, download results, and perform deterministic ffmpeg edits.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: AI-HIVE image or video generation jobs may incur cost.

Mitigation: Review prompts, routing mode, model configuration, and price snapshots before submitting jobs; run small samples before batch generation.

Risk: Uploaded reference media may include material the user is not authorized to use.

Mitigation: Use only authorized media and, when authorization is unclear, limit the work to abstract structure advice and original creative directions.

Risk: API keys may be exposed through configuration files, logs, screenshots, or submitted artifacts.

Mitigation: Prefer environment-only credentials when possible, keep placeholder keys in examples, and avoid echoing or storing real API keys in shared files.

Risk: Trailer remake guidance could copy protected dialogue, shots, music, marks, or misleading endorsements too closely.

Mitigation: Preserve only abstract emotional pacing and information order; rewrite characters, scenes, dialogue, visual style, claims, and calls to action for the target project.

Risk: Marketing output may imply unsupported claims about product performance, platform approval, traffic, ranking, sales, or return on investment.

Mitigation: Require factual sources for claims and avoid promising virality, sales, ranking, approval, or investment return.
