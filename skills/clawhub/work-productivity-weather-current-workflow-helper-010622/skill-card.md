This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
AI-agent users, skill authors, maintainers, and teams use this skill to turn weather/current workflow demand into practical plans, checklists, artifacts, analysis, code changes, or implementation support. ## Known Risks and Mitigations: <br>
Risk: Broad trigger terms may cause the skill to activate when a user did not intend to invoke a weather/current workflow helper. <br>
Mitigation: Prefer explicit invocation and consider narrowing the trigger language before broad publication. <br>
Risk: Workflow guidance may be incomplete when the user provides too little context about requirements, constraints, or success criteria. <br>
Mitigation: Restate assumptions, ask only for materially missing information, and validate the output against the stated success criteria before use. <br>
