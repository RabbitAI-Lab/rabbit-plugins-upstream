# 地域类型模板（通用性核心）

> 本 skill 是「地方类型无关」的通用框架：六类关键词是普适骨架，但「特色类别」与「四库文献类型」随地域类型而变。榆林只是「边地型」的一个实例，不是模板本身。

## 二、六类通用骨架（普适，任何地方都填）

1. **政区地名**（按朝代分层）——任何地方都有沿革；
2. **制度经济**（按地域类型填空：边地=边防，水乡=水利漕运，沿海=海防盐政，民族=土司）——即榆林模板里的「军政边防」的泛化；
3. **人物**（按朝代分层）；
4. **民俗物产**（古代/近现代）；
5. **地理参照**（遗址/山川/关隘/陵墓/园林）；
6. **地貌生态**（今名/古名/古今对照）——任何地方都有地貌，只是类型不同（水乡=河网圩田，山地=丘陵梯田，草原=草场沙地）。

## 三、使用方式

1. 先判定目标地方所属的**地域类型**（可跨类，如「沿海+海防+侨乡」）；
2. 用六类通用骨架 + 对应地域类型的「特色类别」生成关键词；
3. 四库文献按该地域类型的「文献类型」查《四库全书总目》判定收录/存目；
4. 时间分层、四重证据、缺陷诊断等步骤对所有地域类型通用。

## 四、数据源的地域适配

- 古籍源（殆知阁 v20 二十四史/地理类、gujilab CC0）覆盖全国，通用；
- 「四库收录/存目预置索引」现为九边沿线种子，**其他地域类型需按各自文献类型另行扩充**；
- 现代地方资料（地方志、纪念馆、口述）对所有地域类型通用。
