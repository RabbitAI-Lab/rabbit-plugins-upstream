## 四、合规要点（公开发布 skill 的规范性底线）

1. **只用 CC0 / 明确开源授权的数据**；殆知阁类开放镜像使用时，须在产出中标注出处与"文本系整理本、非点校本，学术引用需对照权威版本"。
2. **绝不抓取 ctext**（明确 TOS 禁止）及其他反爬/需登录站点。
3. **四库收录/存目的权威判定**不依赖在线猜测，而依赖《四库全书总目》原书；skill 用"预置索引＋百科 API 辅助＋置信度分级"。
4. **古籍文本校勘底线**：开源整理本可作"工作底本/线索"，**学术结论必须回到影印本或点校本**（本 skill 强制插入"文津阁线下勘校"步骤）。
