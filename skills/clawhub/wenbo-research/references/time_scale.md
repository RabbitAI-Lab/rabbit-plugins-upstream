# 时间维度边界设定规范

> 用途：所有地方文史研究的时间维度必须遵守本规范。核心原则——**时代边界设定要合理，不拉跨度过大、不混古今、不臆断传承**。

## 一、三个边界

### 1. 史料边界（数据源的时间上限）

| 时段 | 数据源 |
|------|--------|
| 乾隆中期（约 1782）以前 | 四库全书、正史、方志古籍、水经注（开源古籍库） |
| 乾隆中期以后 | 方志（现代整理本）、档案、碑刻、近现代文献、口述史 |

判据：文献成书年代 vs 四库编纂年代（1772—1784）。四库收书下限即史料边界，此后内容四库覆盖不到。

### 2. 古今边界（时代分期锚点）

- **古代 / 近代分界：1840（鸦片战争）**
- **近代 / 现代分界：1949**
- 物产、地貌的「古名 / 今名」对照，须各标时间锚点（如「奢延水」秦汉、「无定河」唐宋以后），不得用无时间标签的「古称/今称」泛泛而指。

### 3. 历史复原精度（时间层粒度）

- 标准分层：先秦 / 秦汉 / 魏晋南北朝 / 隋唐 / 宋元 / 明清 / 近代 / 现代；
- 按地方实际可再细分（明清 → 明、清；明 → 明初、成化、明末）；
- 讨论某朝代须落到**具体时段/年份**（如「明成化十年」），不用笼统「明代」。

## 二、古今贯通的边界合理性（防止过度发挥）

- 古今贯通＝**同一地理空间的历史层叠加**，不是跨越断层的直接传承；
- 相隔久远的历史层（如秦汉与近现代），只作「地理连续 + 分时段叙事」，**不臆断直接文脉传承**；
- 仅当有明确传承证据（地名延续、族谱世系、制度沿袭、金石纪年）时，才可用「传承」表述；
- 例：路遥、柳青与秦汉上郡之间是「同一片黄土地的历史层」，而非「上郡文脉直接传至路遥」——后者需证据，不可默认。

## 三、关键词时间标签规范

- **政区地名**：标注建置朝代，必要时到年份（「榆林卫，明洪武设」「榆林府，清雍正置」）；
- **人物**：标注生卒/活跃朝代；
- **物产、地貌**：古今对照须带时间锚点（「奢延水(秦汉)=无定河(唐宋以后)」）；
- 时间分层输出时，`--era` 只取该时代及其之前的沿革层，不混入后世建置。

## 四、错误示范与纠正

| 错误表述 | 问题 | 纠正 |
|---------|------|------|
| 「秦汉上郡的文脉传到路遥」 | 跨两千年臆断传承 | 「同一黄土高原的地理层，秦汉上郡与现当代文学分属不同历史层」 |
| 物产写「古称糜子、今称小米」 | 古今对照无时间锚点 | 「糜子/谷子（古代物产）↔ 小米（今），陕北粟作延续」 |
| 「明代榆林」泛指 276 年 | 时间粒度太粗 | 「明成化九年（1473）迁镇」落到具体年份 |
| 用四库查民国县志 | 越史料边界 | 民国县志用现代整理本/档案，不归四库 |
