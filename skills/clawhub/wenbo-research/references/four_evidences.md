# 四重证据法 · 流失文物互证模板 · 缺陷诊断清单

> 用途：Step 6（流失文物—文献互证）、Step 7（四重证据整合）、Step 8（缺陷诊断）。

---

## 一、四重证据法

| 证据 | 内容 | 榆林示例 |
|------|------|----------|
| ① 文献 | 四库/正史地理志/方志/档案 | 《读史方舆纪要》《陕西通志》《延绥镇志》《汉书·地理志》 |
| ② 实物 | 现存馆藏 + 已上缴/流失文物的遥在溯源（图录/调阅） | 陕北汉画像石、明边塞军器 |
| ③ 口述/民俗 | 田野：参与观察、口述史、谱系访谈 | 信天游、走西口、秧歌、边塞饮食 |
| ④ 金石/图像 | 摩崖、碑刻、题记、画像石榜题 | 红石峡摩崖、镇北台、统万城、汉画像石榜题 |

> 原则：四重证据互相印证才下结论；单一证据只作线索，标注置信度。

> **历史复原硬规则（时间线索）**：讨论某一朝代的地方文史，必须使用「当时」的地名、地貌、物产称谓，**禁止古今混用**。例：论明代榆林卫，用「沙碛/平沙」而非「毛乌素沙地」，用「屯田/马/盐」而非「马铃薯/沙柳」。古今对应（如奢延水=无定河）须显式标注；用 `keywords.py <地> --era <朝代>` 生成该朝代的复原关键词集。

## 二、流失文物—文献互证对照表（模板）

| 字段 | 说明 |
|------|------|
| 文物类别/名称 | 器物或遗址类型 |
| 出土/属地 | 县/遗址 |
| 可能去向 | 上级馆/考古院 |
| 文献源（四库） | 读史方舆纪要/陕西通志/正史地理志对应条目 |
| 文献源（方志/金石） | 州县志·艺文古迹门 / 摩崖 / 画像石榜题 |
| 互证路径 | 文献↔实物↔金石↔口述 如何闭环 |
| 待补 | 调阅号/图录号/数字化状态 |

## 三、地方博物研究缺陷诊断清单（九条，可复用）

1. **重物轻文、库房思维**：学术底盘建立在"有什么藏品"上，无独立文献体系 → 实物一上缴即失语。
2. **方志浅表化使用**：只抄录＋白话翻译，不做版本对勘、史源追溯，不辨方志"层累"。
3. **四库删改未被识别**：把"净化本"当原始史料，边疆/民族结论建立在被篡改文本上。
4. **华夷/边塞单一叙事**：或王朝正统叙事，或反向地方中心主义，缺民族志"主位视角"，本地族群声音被遮蔽。
5. **民俗"抢救式"碎片化**：清单式采集，有民俗、无历史纵深，不接文献系统。
6. **民族志方法缺失**：无参与观察/口述史/谱系访谈，"民族特色"沦为展陈标签。
7. **学科断裂**：文献/考古/民俗/民族志/边疆史各自为政，未打通四重证据。
8. **数字化/检索底盘缺失**：无"地方文献专题库"，四库/方志中的地方材料散落无法汇聚。
9. **缺问题意识、无学术话语权**：停留在介绍性/宣传性，提不出可进学术讨论的问题。

> 诊断产出格式：每条问题须带证据（出处文件/段落）与置信度，宁可漏报、不可误报。
