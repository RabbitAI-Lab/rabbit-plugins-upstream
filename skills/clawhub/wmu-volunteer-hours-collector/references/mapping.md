## 专业名称模糊匹配规则

当原始数据中的专业名称不是完整规范名称时，使用以下优先级匹配：

1. **精确匹配**：原始数据去除空格后，与上表中"专业全称"精确匹配
2. **包含匹配**：原始数据包含上表中某个"专业全称"的关键部分，且上表的"专业全称"包含原始数据
3. **关键词匹配**：通过关键词推断：
   - "临外" → 临床医学（中外合作办学）
   - "护本" → 护理学
   - "护专" → 护理
   - "护理" → 需向用户确认是"护理学（护本）"还是"护理（护专）"
   - "眼本" → 眼视光医学
   - "眼专" → 眼视光技术
   - "眼八" → 眼视光医学（5+3一体化）
   - "临床" → 临床医学（但需结合学院判断是临一还是临二的临床医学）
   - 包含"班"的数据需分析是否为班级名而非专业名
4. **特殊规则**：
    - "生物医药数据科学"属眼生学院（眼视光学院、生物医学工程学院），直接使用全称
    - 若推断为研究生，保留原始数据并汇报
