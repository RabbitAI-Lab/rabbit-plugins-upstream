## Description:

Drafts short-form product promotion scripts from supplied product details or supported Douyin and Xiaohongshu listings.

This skill is ready for commercial/non-commercial use.

## Publisher:

[devinchen2014](https://clawhub.ai/user/devinchen2014)

### License/Terms of Use:

MIT-0

## Use Case:

Marketing teams and creators use this skill to draft shot-by-shot product videos with narration, on-screen text, demonstrations, and calls to action.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Online product lookups run an unpinned npm package with access to the SocialDataX API key.

Mitigation: Use supplied product details when possible; for online lookups, pin and review the package or use a controlled tool installation, and limit API-key exposure.
