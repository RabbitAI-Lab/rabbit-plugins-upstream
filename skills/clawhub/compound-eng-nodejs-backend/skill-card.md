## Known Risks and Mitigations:

Risk: Backend guidance may influence generated code and security checks.

Mitigation: Review changes against project requirements, run type checks and tests, and confirm framework-specific APIs against version-matched official documentation.

Risk: Unpinned diagnostic commands may run unexpected package versions.

Mitigation: Prefer project-local or pinned package-manager commands when running diagnostics such as npx examples.
