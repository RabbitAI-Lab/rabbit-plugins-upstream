# Starter Skill Template

This is a template for creating new OpenClaw skills.

## How to Use

1. Copy this folder
2. Rename it to your skill name
3. Customize all content
4. Add your domain-specific references
5. Test with Quality Assurance
6. Ship it

## Customization Checklist

- [ ] Rename skill in metadata
- [ ] Write compelling description
- [ ] Define identity and mission
- [ ] Create quick start protocol
- [ ] Write 3-7 core directives
- [ ] Design reasoning protocol
- [ ] Set output standards
- [ ] Define quality gates
- [ ] Build reference materials
- [ ] Create templates
- [ ] Write README
- [ ] Test thoroughly
