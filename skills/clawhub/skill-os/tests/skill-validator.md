# Skill Validator

> Automated validation framework for testing any skill.

---

## Validation Checklist

### Structure Validation
```
□ SKILL.md exists and is readable
□ README.md exists and is complete
□ references/ directory exists
□ templates/ directory exists (if applicable)
□ assets/ directory exists (if applicable)
□ No orphan files
□ No missing references
```

### Content Validation
```
□ Metadata header is present and valid
□ Purpose is stated clearly
□ Trigger conditions are defined
□ Core directives exist (3-7)
□ Reasoning protocol is documented
□ Output standards are defined
□ Quality gates are present
□ Safety & ethics section exists
```

### Reference Validation
```
□ All referenced files exist
□ No broken internal links
□ Frameworks have examples
□ Patterns have use cases
□ Standards have measurements
```

### Template Validation
```
□ Templates are fillable
□ Checklists are complete
□ Examples are realistic
□ Instructions are clear
```

---

## Automated Test Runner

```
RUN TESTS:
1. Load skill
2. Run structure checks
3. Run content checks
4. Run reference checks
5. Run template checks
6. Generate report

REPORT FORMAT:
- Total checks: [N]
- Passed: [N]
- Failed: [N]
- Warnings: [N]
- Score: [X/100]
```
