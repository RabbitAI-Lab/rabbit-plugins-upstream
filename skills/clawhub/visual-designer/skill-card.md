## Description:

A visual design skill bundle for brand identity, illustration, poster design, and web typography, with guidance on hierarchy, color, layout, and readability.

This skill is ready for commercial/non-commercial use.

## Publisher:

[skills-repo](https://clawhub.ai/user/skills-repo)

### License/Terms of Use:

MIT

## Use Case:

Developers and creators use this skill to plan and refine static visual assets, including brand systems, illustrations, posters, and web typography. It provides design principles and practical guidance while leaving final aesthetic decisions to the designer or client.

### Deployment Geography for Use:

Global
