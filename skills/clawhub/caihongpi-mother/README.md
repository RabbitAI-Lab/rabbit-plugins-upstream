# caihongpi-mothers — 彩虹屁·妈妈夸夸卡

> 夸的不是「妈妈」这个身份标签，是**具体那个人做的具体那件事**。不敷衍、不套模板，夸在细节上，让人读了鼻子一酸。

## 是什么

一个 Claude Code Skill，根据你分享的当妈真实经历/场景，生成走心的夸夸卡片。包含 **文字夸奖 + Gemini 文生图 Prompt + 小红书/抖音/快手三平台发布信息**。

## 触发词

求夸 · 求彩虹屁 · 夸夸我 · 需要夸夸 · 夸妈妈 · 今天好累求安慰

## 特色

- 🔔 **双通道触发**：主动求夸 + 被动情绪识别自动提议
- 🎨 **5×5×4 搭配**：5种写作风格 × 5种输出格式 × 4种图片风格
- 📱 **三平台适配**：小红书/抖音/快手各自发布信息
- 🎯 **7条夸奖原则**：扎根真实细节、夸在点上、多视角切入…

## 角色分工

| 角色 | 说明 |
|------|------|
| 主编 `caihongpi-mothers` | 统筹协调，最终输出 |
| 情绪识别器 | 分析情绪信号，判断是否提议夸夸 |
| 风格适配器 | 匹配最佳写作风格 + 输出格式 + 图片风格 |
| 文生图提示词写手 | 生成 Gemini (Imagen) 文生图 Prompt |
