# 极鲸云 Temu 类目搜索 Skill

通过极鲸云提供的真实 Temu 类目数据，帮助国内跨境卖家查询可信类目 ID、层级和完整路径，并分析类目市场规模、需求趋势、商品与店铺供给、价格和半托管渗透，为品类研究和赛道判断提供依据。本 Skill 提供类目级市场判断，类目数据不能直接证明具体单品机会。

## 主要能力

| 能力 | 可以解决的问题 |
| --- | --- |
| Temu 类目搜索 | 按中文或英文名称、层级和父类目查找类目，并用完整路径核验可信类目 ID |
| 类目市场规模 | 结合总销量、总销售额、近期销量与销售额，判断品类需求规模和市场体量 |
| 供需竞争分析 | 对比需求增长与商品数、店铺数及其变化，识别供给拥挤度和竞争压力 |
| 类目趋势研究 | 结合日、周、月销量和销售额增长率，识别近期增长、回落和异常波动 |
| 蓝海与经营模式 | 综合蓝海指数、价格、商品与店铺供给及半托管占比，筛选值得进一步验证的类目 |

## 适用场景

本项目适合以下任务：

- 查询 Temu 类目 ID、类目层级和完整归属路径。
- 搜索一级、二级或指定父类目下的直接子类目。
- 研究类目销量、销售额、商品数和店铺数等市场规模。
- 查找热销类目、蓝海类目和近期增长类目。
- 对比需求增长与商品、店铺供给增长，判断供需竞争。
- 分析类目平均价格和半托管商品、店铺渗透情况。
- 为后续品类调研确定可信的类目范围和筛选条件。
