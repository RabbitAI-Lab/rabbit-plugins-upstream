# 企业情报报告模板

> 报告用 Markdown 输出在对话中。**结论卡永远放最前**。所有数据标注时间范围（如「2023-07 至今」）。
> **全文只输出一遍**：按模板从头到尾写完即停，任何章节都不得重复出现第二次。
> **措辞红线**：涉及真实企业/机关，禁用「内定、暗箱、围标、串标、关系户、走过场、皮包公司」等定性指控词；
> 公开风险固定用「公开信息显示…（来源：链接）」陈述式句式，不下定性结论；事实与推断分开表述。
> **联系人红线**：只展示 API 返回的脱敏形态，完整联系方式一律引导主站会员。

## 正文链接规范

- 公司页、公告页链接**必须原样使用 API 返回的完整 `url`（含 `sk` 免登录参数）**，严禁删改 `sk`/`from` 参数或自行拼接——去掉 sk 用户点击会被登录墙拦截。
- 公司页首屏（业务词云/联系人/合作图谱）带 sk 免登录可直接查看；报告中涉及**更深度的企业分析对比**时，引导语固定为：「更深度的多公司在线对比分析，可登录知了标讯主站查看」——不要写"部分模块需登录"之类模糊表述。
- 第六节公开风险的来源链接原样输出（外部链接，如裁判文书网/新闻页），不做转写。

## HTML 报告导出（默认执行）

对话中输出 Markdown 报告后，**默认再生成一份 HTML 报告**（轻量追问模式仅当用户索要时生成）：

1. 把报告内容整理成 JSON（结构见 `scripts/render_report.py` 文件头注释；对比报告设 `"mode": "compare"`），写入临时文件
2. 运行 `python3 <skill目录>/scripts/render_report.py --in <report.json>`
3. 脚本输出生成的绝对路径（默认 `~/zlbx-company-intel-files/<公司名>_企业情报.html`），
   把该路径完整告知用户：「已生成可分享的 HTML 版报告：<路径>」

JSON 中的公司 `url`、公告 `url` 同样必须用 API 返回的原始链接（带 sk）。
