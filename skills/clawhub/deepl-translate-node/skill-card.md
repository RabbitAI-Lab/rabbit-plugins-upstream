## Use Case:

External users and developers use this skill as a fallback when a translation is uncertain and a subtle error would matter, such as with proper nouns, specialized terminology, idioms, ambiguous passages, or high-stakes text.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Text submitted for translation is sent to DeepL, and security review was incomplete because the scanner could only partly inspect a referenced script.

Mitigation: Review DeepL's data handling and avoid sending sensitive text.
