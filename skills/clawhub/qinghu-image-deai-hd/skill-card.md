## Description:

Helps users make AI-generated product and scene images look more realistic by enhancing detail, consistency, and clarity through Qinghu's image workflow.

This skill is ready for commercial/non-commercial use.

## Publisher:

[autoagc](https://clawhub.ai/user/autoagc)

### License/Terms of Use:

MIT-0

## Use Case:

External users and creators use this skill to improve the realism and clarity of authorized AI-generated images, especially product and scene images.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generating images may incur paid credits or require a subscription.

Mitigation: Check the current quote and subscription eligibility, and obtain user approval before submission.

Risk: The workflow uploads the selected image to an external service.

Mitigation: Avoid sensitive images and use only images the user owns or is authorized to process.

Risk: The skill may install or upgrade Node and qhkit and requires an API token.

Mitigation: Seek explicit approval before installation or upgrades and configure the token securely.
