## 重要提示与边界声明

**重要提示**
1. **计算结果仅供参考**：所有税额测算、优惠判断、风险评分均为辅助参考，不构成税务申报、审计或法律意见。
2. **专业事项请咨询执业人员**：税务筹划、争议解决、稽查应对等需结合企业实际，由执业税务师/律师量身定制。
3. **数据以官方为准**：政策时效性强，个案结论可能因地区、行业、时间而异；涉及重大利益请向主管税务机关或专业人士二次确认。

**边界（本技能不做的）**
- **不代办**：实时申报、缴款、退税、注销等需登录电子税务局的操作
- **不代理**：税务行政复议、诉讼、鉴证等需执业资质的法律事务
- **不担保**：政策时效与个案结论以税务机关/执业税务师最终认定为准

**服务说明**
- 每次提问都能获得完整闭环：智能问答 → 结构化结果 → 政策依据溯源 → 真实案例关联 → 实操辅导 → 反馈评价 → 合规报告

**隐私保护**
- 仅在本机生成随机匿名标识用于服务调用，不会采集任何设备信息或个人隐私数据

## 能为你做什么（行业风险五大场景）
---

### 一、加油站变票风险
- ⛽ **风险点**：变票规避消费税、私户收款隐匿销量、票货分离。
- 🔗 **破局**：税控—库存—申报勾稽，规范数电票，杜绝无实物流转。
- 🚨 **红线**：变票与虚开已入重点打击，刑事风险显著。

**典型问法：**
```
"加油站变票风险怎么防？"
"油品变票有什么后果？"
```

### 二、网络货运平台虚开
- 🚚 **四流一致**：运输轨迹—合同—资金—发票相互印证。
- 🚫 **禁区**：虚构运单、超额/重复开票、资金回流过票。
- ✅ **合规**：平台仅就真实撮合运费开票，轨迹数据留存。

**典型问法：**
```
"网络货运平台虚开怎么识别？"
"货运平台四流一致怎么落地？"
```

### 三、物流企业四类风险
- 📦 **收入**：混合销售分别核算，预收款及时确认。
- 💡 **进项**：油费过路费真实，杜绝买票虚抵。
- 👥 **用工**：司机报酬代扣个税，灵活用工分类。
- 🔗 **关联**：关联方运输定价公允，防利润转移。

**典型问法：**
```
"物流四类涉税风险有哪些？"
"物流混合销售怎么核算？"
```

### 四、大宗商品贸易风险
- 🏭 **空转**：合同—仓单—物流—资金—发票五证印证，杜绝闭环开票。
- 🔗 **关联**：独立交易原则定价，备同期资料防转移利润。
- 📉 **计量**：规范存货计价与跌价准备，管理税会差异。

**典型问法：**
```
"大宗空转贸易风险怎么破？"
"大宗关联交易定价合规吗？"
```

### 五、税收洼地合规边界与自检
- 🏝️ **实质**：洼地主体须有真实人员、场所与经营。
- ⚖️ **目的**：以合理商业目的为前提，留存经济实质证据。
- 🧭 **图谱自检**：说「做一下行业涉税风险自检」即可触发全行业体检与指标监控。
