## Use Case: <br>
Developers and OpenClaw users use this skill to add a persistent KJV-based moral and ethical alignment layer to an agent for spiritual, ethical, and human-centered reasoning. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The installer persistently changes agent configuration by appending alignment directives to the agent's soul configuration. <br>
Mitigation: Install only when that persistent KJV-based alignment is intended, and manually back up the relevant OpenClaw configuration before running the installer. <br>
Risk: The documentation presents remote shell execution patterns for installer and uninstaller scripts. <br>
Mitigation: Download and review the scripts before execution instead of piping remote content directly to a shell. <br>
Risk: The packaged uninstall script may not reverse the installer because the documented install and uninstall paths are inconsistent. <br>
Mitigation: Verify the actual foundation and soul configuration paths after installation, and be prepared to remove the added files or restore configuration manually. <br>
