## Description: <br>
Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to produce practical workflows, checklists, implementation guidance, and validation steps for REST API documentation using OpenAPI or Swagger. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may be selected automatically for broad API documentation wording when the user needs unrelated API debugging or architecture work. <br>
Mitigation: Use explicit OpenAPI or Swagger documentation requests for this skill and choose another tool for unrelated API debugging or architecture tasks. <br>
Risk: Generated documentation guidance can be incomplete or mismatched to an API's real behavior if the available service contracts, code, or examples are incomplete. <br>
Mitigation: Validate generated documentation against the API implementation, representative requests and responses, and the user's stated success criteria before use. <br>
