# 澄清问卷模板

> 这是生成给用户的「需求澄清问卷」的骨架。把需要澄清的问题**一次性全部列出**，写成 md 交给用户。

## 使用说明（放在问卷开头）

你可以用**三种方式**回答，任选其一：

1. **直接对话框回答**：把答案发在对话里（可以简答，如"读写 Excel、单机"）。
2. **在本 md 里填写**：把答案写在每题下方的"你的答案"处，写好后整份发回。
3. **让我来**：说"你来做 / 你定"，我会针对每道题给出参考答案 + 依据，你确认即可。

> 没想好的题可以留空，我会按默认假设补齐并标注"可推翻"。

## 生成时注意

1. **先提取已有，只问缺失（最重要）**：生成问卷前，先扫描用户已说/已提供的信息，映射到这 8 个维度；**只列出用户还没提供的维度**，已明确的维度标"已明确"即可，绝不重复问。
2. 用户信息很少（只简单描述了任务）→ 完整列出缺失维度；用户已提供部分 → 只列缺失的那几项。按实际情况判断，不机械套用。
3. 每条"为什么问"要写清它影响哪一层，让用户理解这个问题的价值，而不是被审问。
4. 若用户说"你来做"，针对每题给参考答案，格式统一为：`建议：xxx（依据：知识库某案例/某模式；默认假设，可推翻）`。
