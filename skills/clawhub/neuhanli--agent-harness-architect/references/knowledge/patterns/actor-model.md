## 核心思想

系统由隔离的"actor"组成，每个 actor 有自己的状态，彼此只通过异步消息通信，不共享内存。天然隔离、天然并发、崩溃可独立恢复。

## 可迁移到 harness 的哪一层

P（编排模式）、E（子代理隔离）

## 典型应用案例

Claude Code 的 subagents（隔离上下文，只回传结果）；多智能体系统中的子代理隔离。
