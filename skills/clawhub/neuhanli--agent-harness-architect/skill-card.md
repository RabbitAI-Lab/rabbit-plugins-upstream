## Description:

Agent Harness Architect helps developers clarify requirements, compare agent-harness patterns, and produce implementation-ready architecture designs using the H=(E,T,C,S,L,V)+P framework.

This skill is ready for commercial/non-commercial use.

## Publisher:

[neuhanli](https://clawhub.ai/user/neuhanli)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent engineers use this skill to turn an idea, requirements document, or existing agent architecture into a concrete agent-harness design. It supports requirement clarification, harness-layer tradeoff analysis, production-readiness checks, and Markdown design artifacts that can guide implementation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may cause the skill to engage on loosely related architecture requests.

Mitigation: Confirm the request is about agent-harness architecture and use the clarification workflow to narrow scope before producing a design.

Risk: Declared file and network permissions can affect workspace files or introduce new knowledge-base material.

Mitigation: Review proposed changes and require user confirmation before writing knowledge-base updates or adding network-sourced references.
