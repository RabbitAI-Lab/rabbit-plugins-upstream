## Description: <br>
FL Studio Python scripting for MIDI controller development, piano roll manipulation, Edison audio editing, workflow automation, and FLP file parsing with PyFLP. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[delorenj](https://clawhub.ai/user/delorenj) <br>

### License/Terms of Use: <br>


## Use Case: <br>
Developers and music-production automation authors use this skill to draft, review, and adapt FL Studio Python scripts for MIDI controllers, piano roll workflows, Edison audio editing, and FLP project parsing. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated scripts or PyFLP examples can modify FL Studio projects or MIDI controller behavior. <br>
Mitigation: Review generated scripts before running them in FL Studio, test controller behavior deliberately, and work on copies of important .flp files with backups available. <br>
