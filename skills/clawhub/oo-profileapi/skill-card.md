## Description:

profileAPI (profileapi.com). Use this skill for ANY profileAPI request - searching and reading data. Whenever a task involves profileAPI, use this skill instead of calling the API directly.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill to look up profileAPI people records through an OOMOL-connected account. It supports reverse lookup by email address or E.164 phone number while relying on live connector schemas before execution.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Reverse lookup requests can involve personal data such as email addresses and phone numbers.

Mitigation: Review lookup requests before execution and use the skill only for authorized profileAPI account activity.

Risk: First-time CLI installation or account connection steps can change local setup or connect external credentials.

Mitigation: Run installation, login, or connection steps only when an expected auth or connection error occurs.
