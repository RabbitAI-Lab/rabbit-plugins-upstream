## Description: <br>
Builds a new agent skill end-to-end by orchestrating five gated roles for specification, structure, implementation, compression, and independent review. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[vincentjiang06](https://clawhub.ai/user/vincentjiang06) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and skill authors use this skill to turn an explicit request for a new agent skill into a complete skill package with role guidance, schemas, validation scripts, and release records. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: A validation step can execute a harness path supplied by generated dossier content without explicit opt-in, sandboxing, or a path allowlist. <br>
Mitigation: Run the skill only on trusted repositories or sandbox harness execution and manually verify harness paths before execution. <br>
