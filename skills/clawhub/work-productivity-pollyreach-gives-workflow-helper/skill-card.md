## Description: <br>
Helps AI-agent users, skill authors, maintainers, and teams turn PollyReach-style workflow demand into practical plans, checklists, analysis, code changes, or implementation support. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External agent users, skill authors, maintainers, and teams use this skill to structure PollyReach-style productivity workflow requests into concrete artifacts, local-friendly implementation plans, checklists, analysis, or code changes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger wording may activate the skill for unrelated work-productivity or PollyReach-adjacent requests. <br>
Mitigation: Narrow triggers to explicit PollyReach or work-productivity workflow requests before deployment. <br>
Risk: Workflow suggestions could be applied without confirming user constraints or success criteria. <br>
Mitigation: Restate the outcome, constraints, available inputs, and success criteria before producing or applying artifacts. <br>
