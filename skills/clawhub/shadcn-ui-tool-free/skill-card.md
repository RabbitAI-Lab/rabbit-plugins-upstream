## Description: <br>
This skill helps developers build modern React interfaces with shadcn/ui, including component installation, Tailwind CSS customization, form validation, theme switching, responsive layouts, and reusable examples. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineers use this skill to add and configure shadcn/ui components in React projects, generate example UI code, and apply Tailwind CSS, react-hook-form, zod, and theme-switching patterns. It is intended for personal projects, learning shadcn/ui, and small React application UI development. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger wording could cause use outside shadcn/ui React UI work. <br>
Mitigation: Limit use to shadcn/ui React projects and avoid unrelated deployment, operations, or architecture tasks. <br>
Risk: Suggested npx or npm commands may install packages or create and modify project files. <br>
Mitigation: Review commands before execution and run them only in the intended project workspace under version control. <br>
Risk: Generated component, theme, or form code may introduce project-specific UI or validation defects. <br>
Mitigation: Review diffs, run the project's build and tests, and manually check affected screens before release. <br>
