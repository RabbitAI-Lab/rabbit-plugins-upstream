### 按条款检查要点

#### 4. 质量管理体系

| 条款 | 检查要点 |
|------|---------|
| 4.1 | 过程识别完整性、过程顺序和相互关系、删减合理性 |
| 4.2.1 | 质量手册结构、过程描述、文件引用 |
| 4.2.2 | 文件控制程序、审批流程、版本管理 |
| 4.2.3 | 记录控制程序、记录保存期限、可追溯性 |

#### 5. 管理承诺

| 条款 | 检查要点 |
|------|---------|
| 5.1 | 管理者承诺的证据(会议纪要、资源配置等) |
| 5.2 | 质量方针制定、批准、沟通、适宜性评审 |
| 5.3 | 质量目标建立、可测量性、分解情况 |
| 5.4 | 质量管理体系策划的完整性 |
| 5.5 | 职责权限定义、沟通机制建立 |
| 5.6 | 管理评审输入充分性、输出有效性、改进跟踪 |

### 不符合项判定准则

| 类型 | 判定标准 | 示例 |
|------|---------|------|
| 严重不符合 | 系统性失效或重复性不符合 | 关键过程未建立程序、多次相同不符合 |
| 主要不符合 | 过程未有效实施或效果不佳 | 检查表未执行、记录缺失 |
| 轻微不符合 | 偶发的不符合，体系基本有效 | 个别记录不及时、标识不清晰 |

## 附录:审核抽样技巧

### 抽样原则

1. 代表性:覆盖不同时间、人员、产品
2. 随机性:避免选择性抽样
3. 适度性:样本量与审核时间匹配

### 常用抽样表

| 对象总数 | 建议抽样数 |
|---------|-----------|
| 1-10 | 全部或2-3 |
| 11-50 | 3-5 |
| 51-100 | 5-8 |
| 101-500 | 8-13 |
| >500 | 13-20 |

### 抽样记录示例

```
记录编号: SP-CH-2024-001
抽样日期: 2024-XX-XX
抽样人: XXX
抽样对象: 2024年生产的不合格品处理记录
抽样方法: 随机抽样
样本量: 5份
样本列表: NCR-2024-001, 003, 005, 007, 010
抽取地点: 质量部档案室
```
