## 过程识别方法

### 1. 输入识别

| 识别维度 | 考虑要素 |
|---------|---------|
| 法规要求 | ISO 13485:2016、适用法规(NMPA/FDA/MDR) |
| 顾客要求 | 合同、订单、期望、反馈 |
| 组织特点 | 规模、产品类型、企业文化 |
| 生命周期 | 设计开发、生产、销售、服务、处置 |

### 2. 过程分类

| 过程类型 | 定义 | 示例 |
|---------|------|------|
| 管理过程 | 战略决策、资源配置、体系维护 | 管理评审、内部审核 |
| 增值过程 | 直接形成产品/服务 | 设计开发、生产制造 |
| 支持过程 | 为增值过程提供保障 | 采购、检验、设备维护 |
| 外包过程 | 外部供方执行 | 灭菌、运输、计量校准 |

## 乌龟图分析模板

### 乌龟图六要素

```
                        ┌───────────────┐
                        │     头        │
                        │   输出        │
                        └───────┬───────┘
                                │
        ┌───────────────────────┼───────────────────────┐
        │                       │                       │
   ┌────┴────┐            ┌─────┴─────┐           ┌────┴────┐
   │  上壳   │            │   左壳   │           │  右壳   │
   │   方法  │            │   输入   │           │   资源  │
   └────┬────┘            └─────┬─────┘           └────┬────┘
        │                       │                       │
        │                 ┌─────┴─────┐                 │
        │                 │     鱼身    │                 │
        │                 │   角色(谁) │                 │
        │                 │   准则(怎么做)│               │
        │                 └─────┬─────┘                 │
        │                       │                       │
        └───────────────────────┼───────────────────────┘
                                │
                        ┌───────┴───────┐
                        │     尾巴      │
                        │   监控/测量   │
                        └───────────────┘
```

### 乌龟图填写模板

| 要素 | 描述 |
|------|------|
| **输入** | 前序过程提供的原料、信息、服务等 |
| **输出** | 本过程产生的产品、信息、服务等 |
| **资源** | 执行过程所需的人力、设备、工具、环境等 |
| **方法** | 过程执行的步骤、程序、方法 |
| **角色** | 负责执行、配合、管理的岗位/部门 |
| **监控** | 过程有效性的监视测量指标和方法 |

## 删减合理性说明

### 常见删减场景

| 标准条款 | 可删减条件 | 删减说明模板 |
|---------|-----------|-------------|
| 7.3 设计开发 | 企业不进行设计开发活动 | 本组织不从事医疗器械的设计开发活动，所有产品均由外部设计或根据顾客提供的设计要求生产，故删减7.3条款。删减不影响组织提供满足顾客和适用法规要求产品的能力。 |
| 7.5 监视和测量可追溯性 | 法规不要求 | 根据适用的法规要求，本组织产品不需要实现可追溯性，故删减7.5.7.2和7.5.7.3关于追溯性的要求。 |
