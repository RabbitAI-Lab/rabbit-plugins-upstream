## 文件编写规范

### 文件结构要求

| 文件类型 | 内容要求 | 篇幅建议 |
|---------|---------|---------|
| 质量手册 | 体系范围、过程描述、职责分配 | 30-60页 |
| 程序文件 | 目的、范围、职责、程序、相关记录 | 3-10页 |
| 作业指导书 | 操作步骤、技术要求、设备参数 | 2-5页 |
| 记录表单 | 信息采集、签名确认、数据追溯 | 1-2页 |

### 文件审批流程

```
起草 → 审核(相关部门) → 会签(质量部) → 批准(管理者代表/总经理) → 发布
  ↓                                                                  ↓
修订 ← 回退(如需修改)                                    培训 → 实施
```

### 质量手册正文示例

```
1. 发布令

本质量手册依据ISO 13485:2016《医疗器械 质量管理体系 用于法规的要求》编制，
经审查批准，现予以发布实施。

本手册规定了公司质量管理体系的范围、过程及相互关系，是公司质量管理体系
文件的纲领性文件，是开展质量活动的依据，全体员工必须严格遵守。

                              总经理: __________
                              日期: __________

2. 组织概况

[组织名称]成立于[年份]，是一家专业从事[产品类型]研发、生产和销售的企业。
公司位于[地址]，拥有[面积]平方米的生产车间，具备年产[数量]台/套的生产能力。

公司建立了符合ISO 13485:2016标准的质量管理体系，确保产品质量稳定可靠，
为顾客提供安全有效的医疗器械产品。

3. 质量管理体系

3.1 通用要求

公司按照ISO 13485:2016标准的要求建立、实施、保持和持续改进质量管理体系，
包括所需过程及其相互作用。

质量管理体系覆盖以下范围:
- 产品: [具体产品名称/类别]
- 场所: [组织地址]
- 设计开发活动: □是 □否
- 生产活动: □是 □否
- 销售及售后服务: □是 □否

公司识别了质量管理体系所需的所有过程，包括管理过程、支持过程、增值过程
和外包过程，确定了过程顺序和相互关系，并配置了适当的资源以确保过程有效运行。

[详见:过程清单QP-XXX，过程乌龟图WY-XXX]

3.2 文件化要求

3.2.1 总则

质量管理体系文件包括:
a) 形成文件的质量方针和质量目标;
b) 质量手册;
c) 本标准所要求的形成文件的程序和记录;
d) 组织确定的为确保其过程有效策划、运行和控制所要求的文件,包括记录。

3.2.2 质量手册

公司编制了质量手册，描述了质量管理体系的范围，包括任何删减的细节和正当理由；
建立了质量管理体系所需文件的程序；确定了过程之间的相互作用。

[本手册版本:A/0]

注:R-主责 A-批准 C-参与

## 程序文件模板

### 程序文件格式

```
                                [组织名称]

                          程序文件

                    PROCEDURE DOCUMENT

文件编号: OP-XX-XXX
版本:     A/0
生效日期: __________
页码:     第 1 页 共 X 页

1. 目的
   明确本程序的目的和预期效果。

2. 范围
   规定本程序的适用范围和适用场所。

3. 职责
   | 角色 | 职责描述 |
   |------|---------|
   | 部门A | 负责... |
   | 部门B | 负责... |

4. 定义
   - 术语1: 定义说明
   - 术语2: 定义说明

5. 程序
   5.1 子流程1
       描述具体步骤...
   5.2 子流程2
       描述具体步骤...

6. 相关文件
   | 文件编号 | 文件名称 |
   |---------|---------|
   | QM-XXX  | 质量手册 |
   | OP-XX-XXX | 相关程序文件 |

7. 记录表单
   | 表单编号 | 表单名称 | 保存期限 |
   |---------|---------|---------|
   | FM-XX-001 | [表单名称] | 3年 |

8. 附件
   - 附件1: [流程图/表格模板]

编制: _________ 审核: _________ 批准: _________ 日期: _________
```

## 文件编码规则

### 编码结构

```
[文件类型代码]-[部门代码]-[序号]

示例:
OP-01-001
 │  │   │
 │  │   └─── 序号(三位数字)
 │  └─────── 部门代码
 └─────────── 文件类型代码
```

### 文件类型代码

| 代码 | 文件类型 | 说明 |
|------|---------|------|
| QM | 质量手册 | Quality Manual |
| OP | 程序文件 | Operating Procedure |
| WI | 作业指导书 | Work Instruction |
| FM | 记录表单 | Form |
| SP | 规格/标准 | Specification |
| GD | 指南文件 | Guideline |
| TL | 技术文件 | Technical Document |
| DR | 设计文件 | Design Record |

### 部门代码

| 代码 | 部门 | 说明 |
|------|------|------|
| 00 | 综合管理 | 通用/跨部门 |
| 01 | 质量部 | Quality |
| 02 | 管理代表 | Management |
| 03 | 研发部 | R&D |
| 04 | 生产部 | Production |
| 05 | 采购部 | Procurement |
| 06 | 仓储部 | Warehouse |
| 07 | 销售部 | Sales |
| 08 | 工程部 | Engineering |
| 09 | 人力资源 | HR |

### 版本表示方法

| 版本格式 | 说明 | 示例 |
|---------|------|------|
| A/0 | 首次发布 | A/0 |
| A/1 | A版第一次修订 | A/1 |
| B/0 | B版发布 | B/0 |
| B/1 | B版第一次修订 | B/1 |

 │  │   │     └─── 版本
 │  │   └───────── 序号

 └───────────────── 文件类型
