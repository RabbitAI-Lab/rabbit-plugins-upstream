# Workflow 06 — Motion System

Read [motion language](../references/motion-language.md), [typography motion](../references/typography-motion.md), and [GSAP engineering](../references/gsap-engineering.md).

1. Assign orient/connect/reveal/transform/respond/resolve roles.
2. Define timing and easing families, overlap rules, stagger logic, and directional meanings.
3. Define the layer/depth model and camera behavior if applicable.
4. Define typography behavior and splitting policy.
5. Create tokens or shared configuration suited to the existing stack.
6. Translate every motion class to reduced motion.
7. Map scene timelines and ownership boundaries.

Output a **Motion System** concise enough to guide implementation. Avoid a universal animation wrapper that erases scene-specific intent.
