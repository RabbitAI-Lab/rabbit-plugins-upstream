# Workflow 04 — Scene Design

Read [scene architecture](../references/scene-architecture.md), [scroll storytelling](../references/scroll-storytelling.md), the Experience Concept, and relevant entries in [the pattern index](../patterns/index.md).

1. Break the arc into the fewest scenes that create meaningful state changes.
2. Write a scene contract for each scene: purpose, entry, beats, layers, anchors, input mapping, exit, variants, and cleanup.
3. Draw the scene graph and identify persistent stage elements.
4. Define scroll/interaction pacing in semantic beats; reserve reading dwell.
5. Specify mobile and reduced-motion scene maps. They may differ structurally.
6. Validate that every scene advances information, feeling, or agency.

Output a **Scene Map**. Merge ornamental scenes; split scenes that contain competing focal moments.
