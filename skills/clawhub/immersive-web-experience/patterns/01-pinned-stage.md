# Pinned Stage

Hold a stage while scroll advances meaningful beats within one composition.

**Use when:** a subject changes state, assembles, or reveals evidence that benefits from staying spatially anchored.

**Build:** keep semantic content in logical DOM order; create one scene timeline; pin only for the active transformation; map labels to beats; reserve dwell for reading; release cleanly. Shorten or remove the pin on touch when it feels trapping.

**Continuity:** the anchored subject remains stable while supporting layers enter, transform, and exit.

**Avoid:** using a pin for static reading, stacking multiple nested pins, or assigning long arbitrary scroll distances. Reduced motion should present discrete states in normal flow.
