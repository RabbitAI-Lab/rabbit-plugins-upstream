# Object Continuity

Keep one semantic object present while its role, scale, crop, or context changes across scenes.

**Use when:** a product, artifact, image, word, or marker is the narrative spine.

**Build:** assign stable identity; decide whether the same node moves, a proxy takes over, or a canvas object is synchronized. Define ownership at scene boundaries and preserve focal features.

**Continuity:** position, trajectory, scale, lighting, or silhouette makes identity unmistakable.

**Avoid:** duplicating visible copies accidentally, losing the object offscreen, or allowing layout shifts to change its path. Reduced motion may keep a repeated static representation with a clear visual cue.
