# Gallery Conveyor

Move a curated stream of visual works through a continuous track with a stable viewing locus.

**Use when:** sequence, comparison, or catalog rhythm matters more than independent cards.

**Build:** use transforms on a measured track; support wheel/touch/drag only with one clear input authority; snap to meaningful items if needed; expose conventional previous/next and item links; virtualize only when asset volume warrants it.

**Continuity:** track direction, spacing, and focal window create the world.

**Avoid:** auto-moving content without controls, inaccessible drag-only navigation, and uniform card grids disguised by motion. Reduced motion uses a scrollable list or grid.
