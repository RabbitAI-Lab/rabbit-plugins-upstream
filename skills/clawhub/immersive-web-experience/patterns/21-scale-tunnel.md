# Scale Tunnel

Travel through nested frames, repeated contours, or portals whose scale implies depth.

**Use when:** recursion, levels, chronology, or progressive discovery is central.

**Build:** establish a vanishing anchor; recycle a limited number of layers; coordinate scale, opacity, and detail so the next frame becomes the stage. DOM transforms handle planar tunnels; Three.js is justified for free camera movement or real geometry.

**Continuity:** each frame inherits the previous frame's opening.

**Avoid:** rapid endless zoom, high layer counts, and contrast flicker. Limit vestibular intensity and replace with discrete nested frames under reduced motion.
