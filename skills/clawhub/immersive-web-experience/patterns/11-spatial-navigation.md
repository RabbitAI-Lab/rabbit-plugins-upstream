# Spatial Navigation

Arrange destinations as places in a stable spatial model and animate travel between them.

**Use when:** non-linear exploration is more meaningful than a linear document.

**Build:** expose a conventional navigation equivalent; define coordinates and directional rules; animate between named poses; preserve history/deep links; support keyboard and touch. Use DOM transforms for planar maps, Three.js for genuine 3D topology.

**Continuity:** persistent map, compass, landmarks, or minimap provides orientation.

**Avoid:** mystery navigation, hidden destinations, hover-only discovery, and camera travel for routine page changes. Reduced motion switches destinations without spatial flight.
