# CHS-DRG 2.0 → 3.0 关键变更对照

> 范围：ADRG 层面的名称/内涵调整、编码迁移、新增/删除  
> 数据来源：医保发〔2026〕22号 附件 1「DRG 3.0 分组方案」第 1 章「ADRG 2.0对比3.0」表

---

## 二、完全保留（362 个 ADRG 名称不变）

2.0 与 3.0 名称完全一致的 ADRG 共 **362 个**，覆盖大部分常见病组。这部分编码在 2.0 → 3.0 切换时**入组逻辑基本不变**。

## 五、临床/编码关键提示

1. **肿瘤治疗务必重新归类**：2.0 的 RL1/RL2/RM1/RN1/RN2/RU1 6 个 ADRG → 3.0 拆成 RP×8 + RN×4 + RL×5 + RM×2 + RU×2 共 **21 个 ADRG**，放疗/化疗/靶向/介入的组合方式直接决定 DRG 入组。

2. **早产儿/新生儿按入院体重**：2.0 出生体重 → 3.0 入院体重。**口径变了**。

3. **糖尿病分 3 类**：急性并发症（KS1，权重较高）、血管病变（KS2）、合并症（KS3）。编码顺序需重新考量。

4. **有创呼吸 ≥96h 是否伴 CRRT**：2.0 单一 ADRG → 3.0 拆为 AH2（伴 CRRT）和 AH3（不伴 CRRT），CRRT 操作（编码 39.95）存在与否决定编码。

5. **机器人辅助手术**：17.41-17.45 系列单独成组，不入常规外科组。编码时需特别留意。

6. **高危妊娠（811 条）**：触发后优先入 MDCO 妊娠组。产科病案首页必查。

7. **基层 31 病组**：统筹区内统一支付，三级医院与基层按同一标准结算。病案入组后**无论医院等级**都按该 DRG 支付。

## 七、查询方式

```bash
# 2.0 编码 → 3.0 对应
python3 docs/drg3.0_lookup_tool.py compare AE1
# → AE1 (2.0 肾移植) → AC2 (3.0 肾移植)

# 3.0 编码 → 2.0 反查
python3 docs/drg3.0_lookup_tool.py compare AC2 --reverse
# → AC2 (3.0 肾移植) ← AE1 (2.0 肾移植)
```
