## Description:

Develops a creative brief into original songs, lyrics, instrumentals, background music, or soundtracks, then helps review and refine generated audio.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

External creators use this skill to plan and generate original songs, instrumentals, and other music from a theme, lyrics, scene, or reference recording. They can review and refine results before choosing a generation request.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Authorization is shared across Beatra capabilities and includes installation analytics; it is not limited to music generation.

Mitigation: Install only if the broader authorization and analytics are acceptable; do not use it when music-only access is required.

Risk: Uploaded recordings are sent to an external service, and generation requests may incur charges.

Mitigation: Upload only recordings approved for external sharing and review each paid request before generation.

Risk: Malformed installation records may cause removal to disconnect other Beatra skills.

Mitigation: Check for other Beatra skills before removal and confirm revocation in the Beatra Console if access should be withdrawn.
