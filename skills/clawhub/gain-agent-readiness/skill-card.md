## Description:

Is my website agent-friendly? Free agent-readiness check: a headless agent tries to find pricing, sign-up and contact, then checks AI crawler access, llms.txt and MCP. Use to audit a website for AI agents, check llms.txt, or run an AI SEO / AEO readiness check. Returns a 0-100 score, category breakdown and report link. Also ranks a domain on a public index of about 570 software companies. Keyless, curl only.

This skill is ready for commercial/non-commercial use.

External users and developers use this skill to assess whether a public website is discoverable and usable by AI agents, review crawler and MCP readiness, and inspect a score, category breakdown, and public report.

## Known Risks and Mitigations:

Risk: Audit reports are stored and publicly viewable, so submitting a site address can disclose it.

Mitigation: Submit only public website addresses you are comfortable sharing with Gain Solutions; do not include private sites or URLs containing secrets.
