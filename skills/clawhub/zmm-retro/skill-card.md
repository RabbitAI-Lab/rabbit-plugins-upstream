## Description:

Post-publish retrospective skill for short-video creators that collects real platform data, compares it with pre-publish expectations, attributes performance through an observable funnel, and writes validated lessons back to skill memory.

This skill is ready for commercial/non-commercial use.

## Publisher:

[iamzifei](https://clawhub.ai/user/iamzifei)

### License/Terms of Use:

MIT-0

## Use Case:

External creators and creator-operators use this skill after publishing a short video to gather Douyin performance metrics, compare them with the original content hypothesis, identify supported explanations, and decide the next content action.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill reads broad local creator memory and content-planning notes and may write lessons back into memory and tracking files.

Mitigation: Install it only in the intended creator vault and review proposed memory or tracking updates before accepting them.

Risk: A single video result can be over-interpreted as a durable content rule.

Mitigation: Record first-time signals as n=1 hypotheses and promote them to effective methods only after repeated similar evidence.
