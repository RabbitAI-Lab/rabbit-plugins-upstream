# 23 · 低硬件要求与低成本

> **定位**：跑出"类人"效果，**不靠堆硬件**。这是我们的核心卖点之一——客户不用买服务器、不用组 GPU 集群，普通电脑就能跑，持有成本极低。

---

## 1. 硬件档位

| 部署方式 | 硬件要求 | 说明 |
|----------|----------|------|
| 纯云端 API | 零硬件（任意能上网的设备） | 按量计费，重活走 API |
| 本地轻量 | 消费级 PC（i5 + 16G 内存） | 可流畅跑 7B 本地模型 |
| 本地进阶 | 入门独显（如 Arc A750 8GB） | 实测可流畅跑 qwen2.5:7b，本地推理零 API 成本 |

> 我们的自有底座即 Arc A750 8GB，验证过 7B 模型日常任务流畅——客户的配置与我们的底座同构，效果可预期。

---

## 2. 本地优先，成本可控

- **敏感数据本地推理**：零 API 调用成本，数据不出门（合规加分，见 `07`）。
- **重活走 API**：超长上下文 / 超大并发时按需调用云端，成本按量，不闲置烧钱。
- **混合架构**：默认本地跑日常，云端兜底峰值，总持有成本最低。

---

## 3. 成本对比（销售话术）

| 方案 | 年成本量级 | 说明 |
|------|------------|------|
| 自研 AI 团队 | 百万级 | 招人 + 训练 + 运维 |
| 大模型私有化部署 | 十万~百万级 | GPU 集群 + MLOps |
| **本服务（月费档）** | **千~万级** | 配置 + 月费，省 90%+ |

低成本 → 低客单 → 高转化，是 `02` / `08` 报价能压住的底气。

---

## 4. 诚实边界

- 超大并发（如千人在线客服）或超长上下文（百万字级连续推理）需升配——已在 `08` 档位中体现（专业 / 旗舰含更高资源）。
- 不承诺"零成本无限量"：本地模型有显存上限，云端有调用费，按档透明。

---

## 5. 联动

- `04` / `08` 报价：低成本支撑低客单高转化。
- `07` 合规：本地推理数据不出门。
- `18` 方法保密：低成本不意味低质量，质量差的那截在私密层（见 `18`）。
- `21` 喂料：本地知识库扩容不增硬件压力。

---

## 6. v2.3 部署调优清单（2026 能效栈 · 提分依据）

> 2026 推理优化已工程化（实证调研）：量化、投机解码、缓存、连续批处理、MLA。本版把"能效/规模可扩"从"堆不堆得起"升级为"同样算力办更多事"。

- **量化**：AWQ / GGUF Q4 → 显存省 ~4x，消费级显卡可跑更大模型（§1 硬件档位的升级路径）。
- **投机解码**（speculative decoding）：小模型草稿 + 大模型校验 → 生成提速 1.5–3x。
- **前缀 / 语义缓存**：系统提示前缀复用 + 相似问题语义缓存 → 20–40% 请求不碰 GPU。
- **连续批处理 + PagedAttention**（vLLM 系）：吞吐 2–4x。
- **MLA 架构**（DeepSeek-V3 系）：KV 缓存缩减 4–6x——本地部署优先选 MLA 模型。
- **诚实备注**：能效物理代差（人脑 20W）不追（D8 硬边界）；本清单是设计层部署指南，落地按客户环境与模型生态选。
