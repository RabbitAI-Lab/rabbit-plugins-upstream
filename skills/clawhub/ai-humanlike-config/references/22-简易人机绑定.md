# 22 · 简易人机绑定（微信 / 支付宝 / 谷歌等）

> **定位**：客户用自己最熟悉的方式，**一键**把"真人"和"自己的数字人"绑定——这是 `14` 同意授权码（L0 绑定码）与 `07` 通行证的身份入口。绑定越简单，转化越高。

---

## 1. 支持的身份源

| 身份源 | 覆盖客群 | 备注 |
|--------|----------|------|
| 微信 | 国内个人 / 企业 | 扫码即绑 |
| 支付宝 | 国内个人 / 企业 | 实名强，天然可信 |
| 谷歌 | 海外客户 | OAuth 标准 |
| 手机号 | 通用兜底 | 短信验证码 |

---

## 2. 绑定流程（三步）

1. **扫码 / 点登录**：客户在绑定页选身份源，扫码或点授权。
2. **授权回跳**：身份源返回 openid / 昵称（不取通讯录、不取聊天记录）。
3. **绑定成功**：自动签发 `14` L0 绑定码 + `07` 通行证，打时间戳 + 哈希，双世界状态一致。

全程**无需填表**，30 秒内完成。

---

## 3. 隐私与合规

- **最小采集**：只取 openid / 昵称，绝不碰通讯录、聊天、相册。
- **告知同意**：绑定前明示用途（PIPL 告知同意，见 `07` / `11`）。
- **可撤销**：客户可随时解绑，解绑即 `14` L0 失效 + `07` 通行证注销。

---

## 4. 安全增强

- 微信 / 支付宝 / 谷歌本身已实名 + 二步，身份可信度足够。
- **高敏操作**（如删库、转账类工具）再叠 `14` L2 操作码，human-in-the-loop。
- 绑定态异常（异地 / 多设备）触发 `10` 异常熔断告警。

---

## 5. 跨境选择

- 国内客群 → 微信 / 支付宝优先（覆盖广、实名强）。
- 海外客群 → 谷歌 / 手机号（规避国内平台可达性问题）。
- 按客群自动推荐默认身份源，降低决策成本。

---

## 6. 联动

- `14` 同意授权码：L0 绑定码即本文件的产出。
- `07` 通行证：绑定同步签发通行证，全链路可追溯。
- `11` 权益保障：解绑 / 数据交接条款。
- `10` 安全加固：绑定态异常熔断。
