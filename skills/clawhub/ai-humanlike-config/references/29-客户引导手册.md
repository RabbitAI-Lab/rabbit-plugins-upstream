## 一、你的数字员工是什么

- 一句话：一个**记得住你、会主动、会干活、人设稳定**的 AI 助手。
- 由服务方按"四件套"（记忆 / 主动 / 工具 / 角色）配置交付，带**加密 ID 凭证**可验真（见 `17`）。

## 二、三步上手（新手必看）

1. **绑定自己**：用微信 / 支付宝 / 谷歌扫码，30 秒绑定本人（见 `22`）。
2. **开始对话**：像发消息一样吩咐它——"帮我查…""明天提醒我…"。
3. **看状态**：打开健康看板，随时看它在忙啥、健不健康（见 `08`）。

> 配好后的前 7 天服务方会**陪跑**，帮你跑通前 3 个真实任务（见 `12`）。

## 三、喂料：让它更懂你的业务

- 直接把 PDF / Word / Excel / 网页 / 语音拖进上传面板（或发到专属邮箱 / 微信），它就自动学会（见 `21`）。
- 喂得越多，它越懂你；冲突资料会自动提示你确认。

## 六、常见问题 FAQ

- **它忘事了？** 看有没有"写回记忆"；喂过的资料会沉淀，别喂完不确认。
- **它会乱来吗？** 不会——已设授权边界 + 高危动作二次确认（见 `10`）。
- **它说的话能直接用吗？** 关键决策（合同 / 财务 / 医疗 / 法律）请**自行复核**。
- **不想用了？** 随时可终止，数据按协议返还或销毁（见 `11`）。
