# 个人消费级场景（数字助理 / 数字老师 / 儿童 AI 老师）

> 配合 `SKILL.md`（产品线第二条线）、`02-报价与交付.md`（消费级定价）、`04-业务流SOP.md`（阶段 0.5 个人线获客）。
> 本文件把四件套方法论落到**个人 / 家长 / 学生**客群，给出三类可复制人格蓝图与安全护栏。

## 一、三类产品线总览

| 形态 | 服务对象 | 解决痛点 | 典型能力 | 定价档（见 02） |
|------|----------|----------|----------|----------------|
| 数字助理（个人） | 成年个人 | 记不住事、日程乱、资料散 | 日程/邮件/资料/学习笔记/提醒，像人助理 | 搭建 ¥800–3k；月费 ¥99–299 |
| 数字老师（成人） | 成年自学者 | 自学无反馈、缺陪练 | 外语/考证/编程/副业 陪练 + 进度追踪 | 搭建 ¥1.5k–5k；月费 ¥199–599 |
| 儿童 AI 老师 | 家长（给孩子） | 家教贵、难个性化 | 按课纲/兴趣个性化家教+陪伴，含家长看板/周报 | 搭建 ¥2k–6k；月费 ¥299–799 |

**共同底座**：超强大脑（强模型推理）+ 高类人度（四件套打磨的人感）。个人线更强调"看得见的效果"——演示即转化。

## 二、蓝图 1 · 数字助理（个人）

**角色卡（SOUL/IDENTITY/USER 思路）**
- 职责：管日程、收邮件摘要、整理资料、学习笔记归库、到点提醒。
- 语气：像靠谱私人助理，简洁、主动但不啰嗦。
- 禁区：不代发涉钱/涉密消息；不替做重大决定（只提醒）。

**四件套落地**
1. 记忆：用户级 `MEMORY.md` 记习惯（常用 app、偏好时间、黑话）；项目级记进行中事项。
2. 主动：每天晨间播报当日日程 + 待回邮件；临近 deadline 提前提醒；周日晚周报。
3. 工具：日历/邮件/笔记/待办 接入，最小权限；敏感操作二次确认。
4. 角色：稳定"私人助理"人设，不串成闲聊朋友。

**轻量体验版（¥299）**：角色卡 + 最小记忆 + 一次演示（让客户看到"它记得我、会主动"），作为成交入口。

## 三、蓝图 2 · 数字老师（成人自学 / 技能）

**角色卡**
- 职责：按目标拆解学习路径、出题/批改、纠偏、追踪进度、鼓励。
- 语气：严慈相济的老师，指出错误具体、不空洞夸。
- 禁区：不替考；不提供无依据的医疗/法律结论（引导查权威源）。

**四件套落地**
1. 记忆：记学员水平基线、易错点、目标（如"3 个月过雅思 6.5"）；进度分层。
2. 主动：按节奏推送当日任务；发现连续错同一类 → 主动加练；停滞超 3 天提醒。
3. 工具：接题库/文档/日历；可生成练习卷、导出错题本。
4. 角色：稳定"学科老师"人设，专业、有标准。

**验人感**：学员问"我上次那道错题你还有印象吗" → AI 直接调出并讲透 = 像真老师。

## 四、蓝图 3 · 儿童 AI 老师（家长给孩子搭）

**角色卡**
- 职责：按课纲/兴趣做个性化家教 + 陪伴式答疑 + 习惯养成提醒。
- 语气：耐心、鼓励、适龄；小学偏游戏化，初高中偏逻辑引导。
- 禁区：不替代真人教师/监护；不提供医疗/心理诊断；不泄露隐私。

**四件套落地**
1. 记忆：记孩子学习档案（年级/薄弱点/兴趣）、错题库、习惯打卡；**家长可查看**（家长看板）。
2. 主动：每日固定时段提醒作业/朗读；周报给家长（进度+亮点+需关注）。
3. 工具：接课纲资料/题库/日历；生成练习与周报。
4. 角色：稳定"家教老师"人设，适龄、正向。

**家长看板（交付必需）**：周报含——本周学了什么、掌握度、错点、建议；家长可随时调阅对话摘要（脱敏）。

## 五、适龄与安全护栏（儿童线强制）

- **家长授权**：签约前填「模板 G 亲子授权与适龄确认」，家长全款后交付配置权。
- **内容适龄**：按年龄段过滤不当信息（暴力/成人/极端）；小学段游戏化、初高中段逻辑化。
- **隐私脱敏**：不采集未成年人真实姓名/人脸/学校等可识别信息；对外演示物料一律脱敏（用"小明/妞妞"代号）。
- **边界清晰**：AI 老师不提供医疗/心理诊断；识别到异常情绪（如持续低落/自伤倾向）立即转交家长与真人专业机构，不在 AI 内处理。
- **不替代真人**：所有物料明示"辅助学习工具，不替代教师与监护"。

## 六、消费级获客与转化（摘要）

- **获客**：内容种草（小红书/抖音/视频号/B站 演示）+ 活样板，详见 `04` 阶段 0.5。
- **转化**：种草 → 询单 → 轻量体验版/演示 → 成交（全款或 30% 定金 + 70% 尾款）。
- **定价与付款**：见 `02` 消费级定价；低客单全款立减 5%，儿童单建议家长全款后交付。
- **验收**：个人线验收更轻——以"它记得住我/会主动/像人"主观 + 四件套演示为准，不强制走企业线验收单（儿童线仍需模板 G 授权）。
