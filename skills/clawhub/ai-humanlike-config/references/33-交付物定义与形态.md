# 33 · 交付物定义与形态（定稿）

> **定位**：回答"我们到底交付什么、是插件吗"——**不是传统插件**。两层交付物，各卖各的，别混。本文件是定稿口径，谈单 / 发布 / 定价 / 包装都以它为准。

---

## 1. 两层交付物（先分清）

| 层 | 是什么 | 本质 | 给谁 | 定价 |
|----|--------|------|------|------|
| **① 对外发布物 = Skill 技能包**（本包） | 方法论 + 诊断表 + 模板 + SOP + 知识库（36 文件） | **生产线 / 生产资料**——给 AI 代理装上"怎么配类人数字员工"的能力 | 数字员工配置师 / 同行 / 想自建的人 | 市场定价（一次性或订阅） |
| **② 对客户交付物 = 数字员工配置资产**（服务） | 标准配置包（角色三件套 + 记忆骨架 + 工具清单 + 主动规则 + 加密 ID）+ 文档 + 培训 + 售后 | **产品**——一键装到任意大模型，跑起来就是客户自己的类人数字员工（见 `31`） | 企业（数字员工）/ 个人（助理 / 老师 / 儿童 AI 老师） | `02` / `08` / `24` |

> 一句话：**Skill 包是"造数字人的生产线"，配置资产是"生产线造出来的产品"——两个都卖，别混。**

---

## 2. 对客户交付物清单（一单交付什么）

1. **标准配置包**：角色三件套（SOUL / IDENTITY / USER）+ 记忆骨架 + 工具清单 + 主动规则。
2. **加密 ID 凭证**：带数字签名，可验真出处（`17`）。
3. **交付文档**：搭建说明 + 改造指引 + 引导手册（`29`）。
4. **培训**：首周陪跑 + 操作录屏（`12`）。
5. **售后**：SLA + 月报 + 升版 + 转介绍（`20`）。

---

## 3. 交付物形态

- **线上**：交付门户（`30` 交付端口）下载配置包 + 文档，验收在线确认。
- **文件包**：标准配置包为一份目录（角色文件 + 记忆目录 + 工具清单 + README），可 zip 打包。
- **可迁移**：配置包模型无关，换平台 / 换模型不换人格（`31`）。

---

## 4. 是插件吗？FAQ

- **Q：你们交付的是插件吗？**
  A：不是传统插件。① 本 Skill 包是"技能包"（教 AI 代理怎么配），② 对客户交付的是"配置资产"（可直接跑的数字员工配置），都不是浏览器 / 系统插件。
- **Q：客户拿到配置资产后要装哪？**
  A：一键装到任意大模型 / 平台（WorkBuddy / Claude / Cursor / Coze / Dify / 本地 Ollama，见 `31`）。
- **Q：买断后客户能自己改吗？**
  A：能，配置归客户可自由改（`24`）；但获利引擎（私密层）不交付（`18`）。
