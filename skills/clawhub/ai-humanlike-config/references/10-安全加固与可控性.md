# 安全加固与可控性（防御能力交付模块）

> 配合 `08` 能力清单（#6 安全加固）、`07` 全链路可追溯（审计留痕→时间戳/哈希）、`09` 治理理念「可防」支柱。
> 本文件把"防黑客 / 防 AI 攻击"落成一个**可交付、可报价、可验证**的能力模块。

## 一、定位与红线（只防不攻）

- **我们做"防"，不做"攻"**：为客户配出的数字人提供**防御加固**——防注入、防越权、防滥用、异常熔断、审计留痕。这是差异化卖点，也是治理理念"可防"的落地。
- **红线（绝对不做）**：不为任何客户配置"主动攻击他人"的能力（打接口、爆破、投毒、越权刺探等）。对外任何物料**不得**宣称"能攻击"。可防御 ≠ 可进攻。
- **底座上限**：聪明度由底层模型决定，我们做的是"调教 + 约束 + 加固"——让它在角色内最稳、最可控，不凭空造"最聪明的大脑"。对外用"可控 / 可预期 / 不乱跑"，不用"最聪明 / 最强大"绝对词。

## 二、五层加固清单（交付标准动作）

| # | 加固层 | 做法 | 映射到四件套 / 治理 |
|---|--------|------|---------------------|
| 1 | 权限最小化 | 工具只给必要权限；不给 shell / 文件系统 blanket 权限；按角色发最小令牌 | 多工具调用·最小权限 |
| 2 | 输入校验 · 防注入 | 所有外部输入（用户/网页/邮件）当数据不当指令；识别 prompt injection / jailbreak 模式并拒执行 | 角色一致·禁区 |
| 3 | 越权拦截 | 跨角色 / 跨账号 / 跨项目动作一律二次确认；敏感操作白名单外禁止 | 主动执行·授权白名单 |
| 4 | 异常熔断 | 高频调用、敏感词外发、超阈值批量动作自动停机并告警 | 治理·可防 |
| 5 | 审计留痕 | 谁、何时、调了啥、改了啥，全程记录，串回 `07` 时间戳 / 哈希链 | 可追溯·取证 |

- **交付物**：「安全加固清单」（上述 5 层逐项勾选）+「加固测试报告」（注入样例 / 越权样例 / 异常样例的拦截结果）。
- **联动**：审计留痕（第 5 层）直接产出 `07` 所需的操作日志，交付时一并打时间戳 + 哈希，成为争议取证原始凭证。越权拦截（第 3 层）由 `14` 的「操作授权码」（L2）强制执行——白名单外高危动作须客户发一次性码才放行，human-in-the-loop。

## 三、与能力清单 / 报价关联

- 能力清单 `08` 中 **#6 安全加固** 即本模块；默认**可选加购项**（非默认带项），关键度=重要、大小=中。
- 报价形态（国内外双市场）：
  - **一次性加固费**：国内 ¥500–2k ／ 国外 $80–300（按数字人复杂度）。
  - **月费含安全巡检**：纳入 `04` 阶段 5 月费养护，每月跑异常复盘 + 注入回归测试（已在模板 E 养护清单留位）。
- 含敏感数据 / 上云任务的客户，**建议强制勾选** #6（合规要求）。

## 四、对外话术（站得住脚）

> "我们配的数字人——**可防御**（防注入 / 防越权 / 异常熔断）、**可控**（角色一致、边界清晰、不越权）、**可验证**（时间戳 + 指纹 + 哈希全链路）、**类人**（有记忆、会主动、像人）。"

四件套比"最 X"更值钱，也经得起查。绝不提"能攻击 / 最聪明 / 最强大"。

## 五、2026 安全对标矩阵（OWASP Agentic Top 10 覆盖 · v2.3 提分依据）

> OWASP 2025-12 发布《Agentic Applications Top 10（ASI01–ASI10）》，成为 agent 安全行业标准（Microsoft/NVIDIA/AWS 引用）。本版把我们的防线**逐条映射覆盖**，使"安全治理"领先幅度进一步拉开（前沿普遍 7 分、我们 9 分全覆盖）。

| OWASP ASI | 风险 | 我们的防线（模块） |
|-----------|------|--------------------|
| ASI01 目标劫持 | 注入/上下文篡改改目标 | 同意授权码目标锁定（`14`）+ 任务范围校验 + 指令/数据分离 |
| ASI02 工具滥用 | 越界调用 | 最小权限（§二）+ 参数校验 + 高危二次确认 |
| ASI03 身份/权限滥用 | 凭据窃取/越权 | 加密ID（`17`）+ 短时凭据 + 逐动作授权复核 |
| ASI04 记忆投毒 | 持久记忆被污染 | 记忆来源标记 + 租户隔离 + 冲突标黄 + 可清除（`11` 退款销毁） |
| ASI06 供应链 | 插件/MCP 被篡改 | 发布包白名单 + 版本锁定 + 变更复核 + 敏感扫描 0 命中（`18`） |
| ASI08 级联故障 | 单点失误连锁 | 异常熔断 + 爆炸半径限制 + 可回滚（§二 + `13` 版本化） |
| ASI09 人机信任滥用 | 用户盲目信任 | 审批屏展示影响与数据 + 透明可观测（`08`）+ 证据墙（`26`） |
| ASI10 失控Agent | 治理外运行 | 能力清单 + 行为监控 + 杀停/凭证吊销（`17`） |

- **记忆安全新战场（2026 实证）**：Zombie Agents（记忆注入持久攻击）、XAMT（多 Agent 隐蔽篡改）——我们的对应防线 = 来源溯源（`07`）+ 审计留痕（§二）+ 租户隔离，是 2026 记忆治理的**先手占位**。
- **口径**：不声称"绝对安全"（无绝对），只给"对照行业标准全覆盖 + 可审计可回滚"的可验证交付。
