# 20 · 售前 / 售中 / 售后服务标准

> **定位**：把"配数字人"从一次性交付，升级成**全周期服务体验**——售前让客户"看见配好的样子、敢签"，售中"按时高质量交付、客户会自己用"，售后"持续在场、续费+口碑+生态"。三段环环相扣，是复利与转介绍的根。

---

## 1. 售前（Pre-sales）— 让客户看见、敢签

| 动作 | 内容 | 联动 |
|------|------|------|
| 获客触达 | GEO/AEO 被动获客 + 内容种草（个人线） | `04` 阶段 0 / 0.5 |
| 免费诊断 | 用 `01` 诊断表给四件套缺口打分，出痛点报告 | `01` |
| 活样板演示 | 直接拿作者实例当 demo，现场配出"像人"的效果 | `03` 活样板 |
| 方案与报价 | 按 `02` 双市场档出方案 + 能力菜单勾选（`08`） | `02` / `08` |
| 初测定档 | 用 `16` 评测电池免费初测，给对标等级，建立信任锚 | `16` |

**目标**：把"抽象的方法论"变成"客户亲眼看见的可运行样片"，缩短决策周期。

---

## 2. 售中（During）— 按时交付、客户会用

| 动作 | 内容 | 联动 |
|------|------|------|
| 签约付定金 | 方案满意 → 付定金 50% → 接单触发 | `04` 0.5 / 阶段 2 |
| 搭建四件套 | 记忆架构 + 角色卡 + 工具清单 + 主动规则 | `00` |
| 安全加固 | 五层加固（权限最小/防注入/越权拦截/异常熔断/审计） | `10` |
| 发放授权码 | 四层授权码（绑定/能力/操作/熔断）双世界绑定 | `14` |
| 签发加密 ID | 带数字签名的出处凭证，戳穿冒用 | `17` |
| 交付可信三要素 | 时间戳 + 数字指纹 + 哈希，全链路可追溯 | `07` |
| 验收 | 按模板 D 四件套 + 验人感四条客观标准验收 | `04` 模板 D |
| 上手培训 | onboarding 三步走（手册 + 首周陪跑 + 录屏） | `12` |

**目标**：交付即"客户能自己跑起来"，不是丢个文档走人。

---

## 3. 售后（After）— 持续在场、续费+口碑

| 动作 | 内容 | 联动 |
|------|------|------|
| 月费养护 | 记忆养护 / 角色漂移校正 / 新增场景 | `04` 阶段 5 |
| SLA 承诺 | 服务时效档位（见下表） | `12` |
| 服务月报 | 价值回顾（用了啥 / 省了啥 / 下一步） | `12` |
| 升版 | 新能力 MAJOR 升版，重测刷新 | `13` / `16` |
| 转介绍激励 | 老带新月费减免，提粘性 | `04` 5.5 |
| 生态活动 | AI 挑战 / 组队接单 / 社群 | `15` |
| 支持渠道 | 微信 / 工单，分级响应 | `12` |
| 终止与交接 | 数据销毁 / 通行证注销 / 指纹保留 | `11` |

## 5. 联动一览

- `04` 业务流：售前→售中→售后即其阶段 0 / 0.5 / 1-4 / 5-6 的落地。
- `12` 专业服务标准：SLA / onboarding / 月报 / 脱敏。
- `13` 升版、`15` 活动、`16` 评测、`17` 加密 ID、`07` 追溯、`14` 授权码、`10` 安全、`02` 报价、`11` 权益。

> 三段服务不是"售后才重要"——售前决定能否成交，售中决定能否交付，售后决定能否复利。三环都强，飞轮才转得起来。
