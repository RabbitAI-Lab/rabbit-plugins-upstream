# 专业服务交付标准（信任感 · 让客户觉得"被专业服务"）

> 配合 `04-业务流SOP.md`（阶段 2 签约 / 阶段 4 交付 / 阶段 5 月费）、`08`（可观测看板）。
> 本文件把"客户为什么觉得我们专业、敢续费"落成**可量化的服务标准**：SLA、上手引导、价值月报、展示脱敏。
> 写给**服务方**看：这些是"显得专业"的硬动作，比口头承诺有说服力。

---

## 一、SLA / 服务承诺（专业服务的体面）

> SLA 是专业服务商的底线。没 SLA = 手工作坊感。按客户档位给不同承诺，避免对小单过度承诺。

| 指标 | 标准版起 | 专业 / 旗舰版 | 说明 |
|------|----------|---------------|------|
| 响应时效 | 工作日 24h 内 | 工作日 8h 内 | 企微 / 邮件 / 工单，非即时 |
| 故障恢复 | 48h | 24h | 数字员工不可用 / 核心工具断连 |
| 月费可用性 | ≥ 99% | ≥ 99.5% | 看板可观测（见 `08`） |
| 支持渠道 | 单一（工单/企微） | 多通道 + 月报复盘 | 不含 7×24 电话（除非旗舰定制） |
| 版本迭代 | 按需 | 季度回顾 + 主动优化 | 见阶段 5 |

**SLA 边界（写进协议）**
- 不可抗力 / 第三方平台故障（模型厂、API 提供方宕机）/ 客户自身环境导致的不计入违约；
- 超时未响应的补偿：以**延长月费服务期**形式（如延时 1 天补 1 天），不以现金赔、不叠加无限责任；
- SLA 仅对"已签约月费在期"客户生效，诊断 / 搭建单按项目节奏走，不适用持续 SLA。

## 二、Onboarding 上手引导（交付即"被服务"）

> 很多单"交付完客户不会用"→ 觉得不值 → 不续费。上手引导是续费钩子。

**交付后必做（3 步）**
1. **使用手册**：随交付三件套给「客户引导手册」（`29`，怎么用你的数字员工图文版：三步上手 / 喂料 / 日常用法 / FAQ，**不设版权壁垒、客户可自由修改分发、附免责声明**）。
2. **首周陪跑**：交付后 7 天建群 / 工单，主动帮客户跑通前 3 个真实任务，收集漂移点即时校正。
3. **培训录屏**：给客户团队录 10–15 分钟操作录屏（脱敏），作为内部培训资产，强化"买得值"。

**健康看板（透明杀手锏）**
- 交付即开「可观测看板」（`08` #5 默认带项）：客户随时看健康状态 / 任务进度 / 全局，不黑箱；
- 看板本身即信任锚点，谈单阶段就能演示（见 `06` AI 造 AI 活样板）。

## 三、服务月报 / 价值回顾（续费最有说服力的动作）

> 阶段 5 月费产出《月报》（模板 E 是养护清单，本文件给"客户视角价值版"结构）。月报让客户**看得见钱花得值**，续费阻力骤降。

**月报结构（客户视角）**
```
【数字员工服务月报】客户：__________  月份：__________
一、本月干了啥（量化）
  · 完成任务：__ 个  · 主动提醒/巡检：__ 次  · 调用工具：__ 次
  · 节省工时（估）：__ 小时  · 记忆写回：__ 条
二、健康状态（来自看板）
  · 可用性：__%  · 误触率：__%  · 角色漂移：□ 无 □ 已校正
三、优化与扩面
  · 本月新增场景/工具：__________
  · 下月计划：__________
四、权益标注
  · 转介绍减免（如有）：¥____ / $____（见阶段 5.5）
  · 展示优惠（如有）：见模板 H
五、待客户确认
  · __________
```

**要点**
- 数字要真：从看板 / 哈希日志（`07`）取，不编；编数 = 信任崩塌。
- 价值前置：第一段先讲"省了多少 / 干了多少"，客户一眼看到回报。
- 透明对账：减免 / 优惠逐月标注，避免后续纠纷。

## 四、展示素材脱敏规范（透明 = 信任，也防泄露）

> 客户愿意当展示用例（见 `02` 展示激励、`04` 模板 H），但"能展示什么、绝不能放什么"必须有规矩——既保护客户，也保护我们不被泄密反噬。

**✅ 可展示**
- 方法论产物：配置卡结构、架构说明、四件套落地思路；
- 脱敏效果：能力清单（`08`）、看板截图（隐去客户名 / 具体业务数据）；
- 量化价值：月报中的"节省工时 / 完成任务数"等**汇总数字**（不含个体信息）；
- 自有品牌案例：仅方法论产物口径，不露"自有品牌"关系（既有红线）。

**❌ 绝不展示**
- 客户真实名称 / Logo（除非书面授权可露）；
- 客户清单、报价、合同金额、对话原文；
- 未成年人真实姓名 / 人脸 / 学校（儿童线硬红线，见 `05`）；
- 密钥、凭证、内部系统截图；
- 可识别个人的业务数据（PIPL / GDPR 最小必要）。

**审批流**
- 任何对外展示素材，发布前过一遍脱敏清单 + 客户授权（模板 H）核对；
- 儿童 / 跨境素材额外加一道合规复核（PIPL / GDPR）。

---

## 五、与业务流联动

- **阶段 2 签约**：SLA 档位 + 本文件作为服务标准附件，客户签协议即认服务承诺。
- **阶段 4 交付**：交付三件套含使用手册 + 首周陪跑启动；开健康看板。
- **阶段 5 月费**：按月产出客户视角《月报》（本文件结构）+ 模板 E 养护清单。
- **展示用例**：对外素材按本文件第四节脱敏规范 + 模板 H 授权后发布。

> 专业感 = 标准可量化 + 交付有陪跑 + 价值看得见 + 边界写清楚。这四样齐了，客户从"试试"变"续费+转介绍"。
