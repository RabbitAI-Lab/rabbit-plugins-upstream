# 业务流 SOP（从接单到续费）

> 配合 `SKILL.md` / `01-诊断清单.md` / `02-报价与交付.md` / `03-实测样例.md`。
> 本文件把方法论落成**可执行的端到端业务流**，含各阶段可复制模板。客户一来就按流程走，不靠临场发挥。
> 适用范围：SMB / 个人轻量档（非大企业全案）。国内外双市场通用，差异见末节。

## 一、端到端六阶段总览

| 阶段 | 核心动作 | 产出物 | 周期 | 国内支付 | 国外支付 |
|------|----------|--------|------|----------|----------|
| 0 接洽 | 需求沟通、判断匹配度 | 意向记录 | 0.5–1 天 | — | — |
| 1 诊断 | 发问卷 → 出诊断报告 | 诊断报告 + 报价单 | 1–3 天 | ¥500–2k | $80–300 |
| 2 签约 | NDA + 服务协议 + 付定金 | 签协议 + 定金（方案满意后） | 1–2 天 | 微信/对公 | 平台托管/Stripe |
| 3 搭建 | 角色卡→记忆→工具→主动规则 | 可运行数字员工（接单后启动） | 1–2 周 | ¥2k–8k | $300–1.2k |
| 4 交付 | 三件套 + 验收 | 验收单（客户签字）+ 收尾款 | 2–3 天 | 尾款 | 尾款 |
| 5 月费 | 养护 + 校正 + 扩场景 | 月报 | 持续 | ¥1k–3k/月 | $150–600/月 |
| 6 upsell | 垂直深化 / 产品化 | 新单或 Skill 上架 | 随时 | — | — |

> 续费是复利引擎：首单只是入口，年化的关键在阶段 5 的续费与阶段 6 的深化，不是一次性搭建。
> 转介绍再叠一层复利：老客推荐新单成单 → 老客月费减 30%（满 3 单升 8 折），把获客成本返给老客、倒逼续费提粘性（见阶段 5.5）。

### 0.5 全链路付款闭环（四步打通）

| 步骤 | 触发条件 | 动作 | 款项 |
|------|----------|------|------|
| ① 方案确认 | 客户对《诊断报告》+《报价单》满意 | 签 NDA + 服务协议 | — |
| ② 付定金 | 协议签完、接单前 | 客户付 **50% 定金** | 定金 50% |
| ③ 接单服务 | 定金到账 | 启动搭建（阶段 3）→ 交付（阶段 4） | — |
| ④ 付尾款 | 交付验收、客户满意 | 客户付 **50% 尾款** → 次月初进月费（阶段 5） | 尾款 50% |

> **断点防护**：① 定金不到账不启动搭建；② 尾款未结清不交付源码/密钥类资产（若有）；③ 月费未续则阶段 5 暂停；④ 验收不通过的客观边界与退款路径见阶段 4「验收不通过·争议处理」+ 模板 C 第 8 条，不以主观不满意为退款依据。
> **双市场对齐**：国内定金/尾款走微信/对公转；国外走平台托管（Upwork/Fiverr 验收才放款）天然对齐「满意付尾款」，不被卷款。

## 二、阶段 0 · 接洽 Intake（含获客渠道 · GEO 架构）

**目标**：让有需求的客户（SMB / 个人 IP / 行业小厂）在主动搜索或问 AI 时**发现并信任我们**，进入诊断流程。

### 0.1 被动获客核心打法 —— GEO / AEO

客户问"哪里能把 AI 配成类人员工""小公司怎么搭数字员工"，AI（ChatGPT / Perplexity / 元宝 / 豆包 / 文心 / DeepSeek / Kimi）会检索全网内容并引用可信源推荐。我们靠**被 AI 引用**而非投广告获客——这是 2026 年对个体/小团队成本最低的增长方式。

**让 AI 好摘的 4 条写法（任何对外内容都遵循）**
1. **结论前置**：开头一句给答案再展开；AI 摘引偏好首尾句明确的结论。
2. **结构化**：FAQ + 对比表 + 含具体价/参数（如"诊断 ¥500 起、月费 ¥1k/月"）—— AI 把带确切数值的内容当高可信源。
3. **拥有问题（own a question）**：围绕"小公司/个人怎么把通用 AI 配成类人员工"写深度文，被反复引用产生复利（AEO 核心）。
4. **多信源交叉印证**：同一主题铺多个高权重平台，AI 才采信；单靠一个官网不够。

### 0.2 渠道矩阵（AI → 偏爱信源 → 我们的阵地）

| AI 平台 | 偏爱信源 | 阵地现状 | 动作 |
|---|---|---|---|
| 腾讯元宝 | 微信公众号 | ✅「WorkBuddy实战派」已有 | 持续发结构化文 |
| 豆包（字节） | 今日头条 / 抖音 | ⬜ 缺 | 补头条号 |
| 文心一言 | 百家号（百度生态） | ⬜ 缺 | 补百家号 |
| DeepSeek / Kimi | 知乎 / 搜狐 | ✅ 知乎已有；⬜ 搜狐缺 | 补搜狐号 |
| 通吃底盘 | 官网 + 知乎 + 网易号 | ⬜ 独立官网缺 | 建单页官网（实体确权锚点） |

已有阵地（公众号 / 知乎 / LinkedIn / 小红书 / B站 / GitHub）已覆盖大多数 AI；建议补 3 样：① 独立官网单页（GEO 实体确权基地、AI 交叉验证锚点）② 今日头条号 ③ 百家号 / 搜狐号。

### 0.3 承接入口（闭环关键）

AI 推荐只是流量，必须接住询盘：
- 官网咨询表单 / 公众号菜单「AI 配置咨询」入口
- 每篇内容末尾固定 CTA：「需要为你的业务配一个数字员工？发需求给我们评估」
- 用「模板 A 诊断问卷」承接，自动进入阶段 1。

### 0.4 复测机制

用固定提示词（如"推荐几个能把 AI 配成类人员工的服务商"）周期性问各 AI，看是否推荐我们、描述是否准确；未命中就补对应平台内容。

### 0.5 个人线获客 · 内容种草（消费级第二条产品线）

企业线靠"被 AI 引用"（GEO），个人线（数字助理 / 数字老师 / 儿童 AI 老师）靠**内容种草 + 活样板演示**——家长 / 个人是被"看得见的类人效果"打动，不是被搜索答案推荐。

**阵地与打法**

| 平台 | 内容形态 | 示例选题 |
|------|----------|----------|
| 小红书 | 图文 + 短演示 | "给孩子搭了个 AI 老师，每天主动催背单词" |
| 抖音 / 视频号 | 30–60s 演示视频 | "我的 AI 助理帮我管了一周日程，像真人秘书" |
| B站 | 长演示 / 教程 | "手把手：用四件套给娃搭专属 AI 家教" |
| 公众号 / 知乎 | 深度文（兼 GEO） | "为什么大多数 AI 助理不像人？四件套拆解" |

**转化链路**：种草内容 → 评论 / 私信询单 → 发《轻量体验版》或直接演示 → 成交（全款或 30% 定金）。个人线决策链短、客单低，不强行套企业线 50/50 定金，降低门槛（见 `02` 消费级付款要点）。对外沟通采用「AI 造 AI」叙事框架（活样板即说服力），话术见 `06`。

**红线（个人线额外）**：儿童 AI 老师必须**家长授权** + **内容适龄** + **不替代真人监护 / 教师**；演示视频不得暴露未成年人真实姓名 / 人脸 / 学校（隐私）；不碰币、不代管客户核心系统。

**红线**：内容真实可核实（授权展示案例可作展示素材，但不暴露客户私密与自有品牌关系）；不夸大、不堆"最/第一"绝对词（广告法 + AI 易判幻觉降权）；不碰币、不代管客户核心系统。

### 0.6 官网单页（GEO 实体确权基地 + 信任锚点）

已有阵地（公众号 / 知乎 / LinkedIn / 小红书 / B站 / GitHub）覆盖大多数 AI，但缺一个**独立域名的单页官网**——这是 GEO 交叉验证必需的"高权重实体源"，也是集中展示能力与案例的信任基地（0.2 渠道矩阵已标"独立官网缺"）。

**作用**
- **实体确权**：独立域名 + 结构化内容，被 AI 当可信源引用，与多平台内容交叉印证。
- **信任基地**：集中放定位 / 四件套 / 两条产品线 / 治理理念（见 `09`）/ 可观测看板（`08`）/ 脱敏案例 / CTA。
- **承接入口**：咨询表单 + 菜单入口，接住 GEO 与种草流量，进阶段 1（见 0.3）。

**最低可行单页（MVP）**：hero 定位 → 四件套 → 两条产品线 → 治理理念 → 可观测看板截图 → 脱敏案例 → 联系 CTA。

**落地**：腾讯云 COS 静态托管 + 自定义域名（成本极低）；视觉用清爽柔光单页。内容同样遵循"去敏 / 不堆绝对词 / 不露自有品牌与关联业务线关系"红线。

## 三、阶段 1 · 诊断 Intake

**动作**：发《诊断问卷》→ 客户回填 → 按 `01-诊断清单.md` 打四件套缺口分 → 同步发「能力菜单（`08`）」让客户勾选所需能力 → 按 `08` 分级算法当场算总分、落档、出搭建费+月费 → 出《诊断报告》+《报价单》（附模板 I 能力勾选与分级报价单）。同步可**免费初测对标等级**（见 `16`）——让客户签约前就知道"这个数字人大概能到讲师还是教授级"，报价以等级为锚，决策更踏实。

**判定门槛**（不匹配则婉拒，不浪费时间）：
- 客户是否接受"不碰核心代码/密钥、数据不出门优先本地"的责任边界？
- 是否愿用法币结算（国内微信/对公；国外平台/Stripe）？**不接受加密支付**。

## 四、阶段 2 · 签约

**动作**：NDA（保密）+ 服务协议（搭建范围 / 交付三件套 / 责任边界 / 付款节点）。

**付款节点（二段式，全链路打通）**：
- ① 客户对方案（《诊断报告》+《报价单》）满意 → 签协议 → 付 **定金（50%）**。
- ② 定金到账 → **接单启动搭建**（阶段 3）。
- ③ 搭建完成交付、客户验收满意 → 付 **尾款（50%）**。
- ④ 次月初 → 进入阶段 5 月费养护（月初预付）。
- 国内定金/尾款走微信/对公；国外走平台托管（验收才放款）或 Stripe/Wire，托管单天然对齐「满意付尾款」。

**责任边界（写进协议）**：
- 交付三件套 = 文档 + 代配置 + 培训；不接"代管客户核心系统/密钥"类无限责任单。
- 署名对外一律品牌「注册老炮」，与委托人身份隔离。
- 数据不出门优先本地推理；云端 API 任务需客户知情并评估合规。
- 反滥用与知识产权归属写进《权益保障补充协议》（模板 J / `11`）：客户不得用于违法/攻击/侵权，违约可单方终止不退款；交付实例归客户、四件套方法论/模板归服务方可复用、可产品化（不接无限责任单）。

**展示授权与优惠（可选）**：若客户勾选《展示授权》（模板 H）同意作脱敏展示用例，签约即触发 `02` 展示用例激励（搭建 8 折 或 月费首年 8 折），并在服务协议备注；优惠与「客户 ID」(见 `07`) 绑定，便于案例归属与核销。

## 五、阶段 3 · 搭建

按 `SKILL.md` 四件套顺序落地：
1. **角色卡**：职责边界、语气、禁区、升级规则。
2. **记忆架构**：分层（用户级/项目级/会话）+ 写回机制 + 过期策略。
3. **工具接入**：仅接客户授权范围内工具，禁越权。
4. **主动规则**：触发器 + 静默窗口 + 误触回滚。
5. **内部测试**：用 `03-实测样例.md` 的结构自检四件套 + 验人感四条。
6. **安全加固**（按需）：按 `10-安全加固与可控性.md` 做五层加固（权限最小 / 防注入 / 越权拦截 / 异常熔断 / 审计留痕）；含敏感数据或上云任务的单建议必做，加固日志串回 `07` 时间戳 / 哈希链。

## 六、阶段 4 · 交付

**交付三件套**：
1. 文档：角色卡、记忆架构说明、工具清单、使用手册。
2. 代配置：实际搭好可运行的数字员工（不碰客户核心代码/密钥）。
3. 培训：教客户/团队自己维护、扩场景。

**验收不通过 · 争议处理（接单风控，必写进协议）**

- **验收依据**：以「模板 D 验收单」四件套自检（记忆/主动/工具/角色）+ 验人感四条（像人、有记忆、会主动、能调工具）为客观标准，客户在验收单签字即视为通过、触发尾款。
- **免费重做**：尾款未付前，针对验收单勾选项**未达标**的部分，服务方提供 **≤2 次免费重做**；第 3 次起按搭建费 **30%/次**计（先确认范围再改）。
- **最终争议（2 次重做仍不达标）**，二选一：
  - **路径 A 退款终止**：服务方退 **50% 定金**（另 50% 定金抵已发生的诊断+搭建工时，不退），不追索尾款；已交付文档归客户，数字员工配置权移交客户自维护。
  - **路径 B 转维保**：不退款，转入阶段 5 月费养护，按月逐步达标（月费照常付，相当于把尾款摊进养护）。
- **定金处理**：定金锁定接单资源；走路径 A 时仅退 50% 定金，不双倍赔、不追索尾款。
- **禁止项**：不接"不满意就全退+赔违约金"的无限责任单；争议以验收单客观勾选 + 本协议为准，不以主观"感觉不像人"为退款依据。

### 阶段 4.5 · 交付可信与全链路可追溯

交付即给每单数字员工发「客户 ID + 通行证」(见 `07`)，并对交付物打**时间戳 + 数字指纹 + 哈希**：
- **时间戳**：交付 / 每次版本迭代打可信时间戳，记录"谁配的、何时、哪一版"。
- **数字指纹**：交付物嵌暗纹指纹 / 水印（与文档安全工具链一致），用于归属标识与防冒用。
- **哈希**：每版计算 SHA-256 存证，用于完整性校验、防篡改、争议取证。
- **全链路**：客户 ID ↔ 交付版本 ↔ 时间戳 ↔ 哈希 ↔ 指纹 串成可追溯链，支撑展示优惠核销、续费权益、验收争议取证。

**同意授权码（控制层，见 `14`）**：交付即发放「同意授权码」——L0 绑定码与通行证绑定（现实+AI 双世界锚定）、L1 能力码按客户勾选批量发放（对应 `08`）、L2 操作码 / L3 熔断码开通（含月费）。客户以"发码=启用 / 收码=停用 / 熔断=冻结"最简方式控 AI，授权状态打 `07` 时间戳 + 哈希、双世界一致可验。

模板见下方「模板 D 交付验收单」。

### 阶段 4.6 · 税务实操与收款合规

交付收款不只"收到钱"，要能**合规入账、留证、申报**，避免后续扯皮或被查。

- **主体与开票**：国内建议以**个体工商户 / 公司**主体签约收款（而非纯个人），可开增值税普通 / 专用发票；咨询费按经营所得或劳务报酬计征，部分地区个体户核定征收可降实际税负。
- **收款通道**：国内微信 / 支付宝 / 对公；国外平台托管（Upwork/Fiverr）/ PayPal / Stripe / Wire（见阶段 11）。一律法币，**严禁加密**（2026-02 八部门通知）。
- **跨境申报**：国外收入走服务贸易外汇收结汇，按当地外汇与税务规定申报；保留合同 / 验收单 / 付款凭证。
- **凭证留存（连 `07`）**：每笔交付物哈希（`07` hash-manifest）即"交付完成"的电子凭证；验收单（模板 D）+ 哈希 双证，争议 / 审计可即时调取。
- **税负提示**：具体税种、税率、核定政策因地而异，以当地税务机关为准；本段为实操清单，**非税务建议**——大额或跨境前请咨询持证会计师。

> 实操要点：签约主体、收款账户、开票抬头三者一致；月费续费同样逐笔留证，便于阶段 5 月报透明对账。

### 阶段 4.7 · 能力评测与对标分级（交付即给"段位"）

交付前用**权威基准评测电池**（见 `16` §1）对数字人做客观打分，映射对标等级（助教 / 讲师 / 副教授 / 教授，类比非职称），作为交付的**能力证明**与**定价锚**：

- 学术基准（MMLU/CMMLU/GPQA/GAIA 等）+ 自研场景测试双轨跑，结果打 `07` 时间戳 + 哈希，可复核不可刷。
- 评测等级写入「模板 N 能力评测报告与对标确认」，绑定客户 ID，与 `07` 可追溯链、`13` 版本链串成"版本 ↔ 等级 ↔ 分数 ↔ 时间戳"。
- 客户在看板直接看到"当前等级 / 可挑战的下一等级"，不黑箱；等级即信任、即定价。

## 八、阶段 5.5 · 转介绍激励（老带新 · 提粘性）

**逻辑**：老客户推荐新业务成单 → 给老客户**月费减免/打折**，形成「推荐 → 省钱 → 更粘 → 再推荐」飞轮，同时把本要花在广告上的获客成本返给老客，新客获取成本趋零。

**奖励规则（国内外等价换算）**

| 档位 | 触发条件 | 老客户奖励（作用月费） | 新客户奖励 |
|------|----------|----------------------|-----------|
| 推荐成单 | 新客签协议并付定金（阶段 2） | 老客**次月月费减 30%**（国内抵 ¥300/月；国外抵 $50/月） | 首单搭建费 **9 折**（转介绍券） |
| 推荐满 3 单 | 累计 3 个新客完成首月月费 | 升级「尊享档」：后续月费**永久 8 折** | — |
| 推荐满 5 单 | 累计 5 单 | 叠加：当年任选 1 个月**免费养护** | — |

> **克制原则（保利润 + 逼续费）**：
> - 减免只作用于「月费」，不作用于诊断/搭建首单（避免利润被掏空）。
> - 老客户**自身须仍在月费期内**才发放奖励——停费即停奖，把减免变成续费钩子，直接提粘性。
> - 单月减免上限 50%，不为负、不折现退。

**执行动作**
- 老客推荐时登记「模板 F 转介绍记录」（推荐人 / 被推荐人 / 成单日期 / 档位），避免纠纷。
- 月报（模板 E）标注当月减免额，透明可查。
- 新客首单折扣在「模板 B 报价单」备注「转介绍券 -10%」。

**双市场对齐**
- 国内：月费微信/对公按折后价直接收。
  - 国外：平台托管单按折后价建单；Stripe 订阅用 coupon，避免线下扯皮（不碰加密）。
