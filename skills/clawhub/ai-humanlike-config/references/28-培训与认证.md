# 28 · 培训与认证（把客户变成代理）

> **定位**：教客户自己上手这套方法论 + 认证体系——客户既能**自用**（降低对我们的依赖、用得更深），又能**转介 / 代理**（帮我们接单、一起赚钱）。客户变代理，生态从"我卖给你"变成"我们一起来"。

---

## 1. 分级培训

| 级别 | 对象 | 内容 | 联动 |
|------|------|------|------|
| 初级 | 新客户 | 四件套概念 + 数字人怎么用 / 喂料 / 绑定 | `00` / `21` / `22` |
| 中级 | 老客户 | 自己搭小场景：诊断 → 搭建 → 验收 | `01` / `00` / `16` |
| 高级 | 认证代理 | 完整交付流程 + 谈单话术 + 售后 | `04` / `20` |

---

## 2. 认证考核

- **实操考核**：用 `16` 评测电池考"能不能把 AI 配出类人效果"。
- **认证等级**：初级 / 中级 / 认证代理，逐级授予。
- **可验证认证**：发带签名的认证凭证（借 `17` 加密 ID 思路），可在线验真。
- **诚实口径**：认证是**能力类比**，非官方资质（沿用 `16` 口径）。

---

## 3. 代理权益（转介激励升级版）

| 权益 | 说明 |
|------|------|
| 更高返点 | 认证代理转介返点高于普通转介绍（`04` 5.5） |
| 组队优先 | 活动 `15` 组队接单优先派单 |
| 社群特权 | 专属群 / 内测资格（`13` 新能力先灰度） |
| 物料支持 | 谈单模板 / 案例卡（`26`）/ 话术（`06`） |

---

## 4. 合规红线

- 认证**不替代真人专业执业**（医疗 / 法律等不碰，沿用 `11`）。
- 代理不得冒用我方品牌对外乱承诺（`11` 反滥用）。
- 数据 / 客户资料按 `12` 脱敏与保密。

---

## 5. 报价

- 培训费：初级免费（随交付赠）/ 中级 ¥1k–3k / 高级 ¥3k–8k（$ 对标）。
- 认证费：考核 + 证书，按次或年费。
- 代理返点：成单分润比例写入代理协议（`11` 争议管辖）。

---

## 6. 联动

- `16` 考核基准、`17` 认证凭证、`04` 5.5 转介绍、`15` 活动组队、`13` 灰度内测、`06` 话术、`26` 案例物料、`11` 权益与反滥用。
