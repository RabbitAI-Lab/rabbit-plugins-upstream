# 25 · 多语言版本交付

> **定位**：数字人可配成多语言——面向海外客户、儿童双语启蒙、跨国业务。配置本身支持多语种，交付物关键文档也提供多语言版。这是 `05` 儿童老师、`21` 喂料、以及跨境客群的刚需。

---

## 1. 配置多语言

数字人的"人格层"全面支持多语：

| 组件 | 多语言做法 |
|------|------------|
| SOUL / USER | 角色卡写多语版本，按客群切换 |
| 角色提示词 | 系统提示支持中 / 英 / 日 / 韩 / 德 / 法 / 西 / 葡 / 俄 / 阿等 |
| 界面 | 前端文案 i18n，随浏览器 / 设置切换 |
| 记忆与喂料 | 知识库多语混库，按提问语言召回（见 `21`） |

---

## 2. 语言覆盖矩阵

| 语言 | 典型客群 | 合规注意 |
|------|----------|----------|
| 中文 | 国内全客群 | 国内 AI 服务备案 |
| English | 海外通用 | GDPR（欧盟） |
| 日 / 韩 | 东亚跨境 | 数据本地化倾向 |
| 德 / 法 / 西 / 葡 | 欧盟 / 拉美 | GDPR / LGPD |
| 俄 / 阿 | 跨境拓展 | 内容合规审查 |

> 合规：欧盟客群按 GDPR 单独同意 + 数据可注销（见 `07` / `11`）；涉及内容审查地区，交付前做合规滤检。

---

## 3. 交付物多语言

- 关键模板 / 手册（搭建说明、改造指引、验收单）提供 **中文 + English** 版。
- 按需扩：日 / 韩 / 德 / 法等，按客群报价叠加。
- 角色卡多语版随交付物一并发出，客户可自切（见 `24` 自改造）。

---

## 4. 与既有模块联动

- `05` 儿童老师：可配**双语启蒙**（如中英），家长切换。
- `21` 喂料：双语资料混库，自动按语种召回。
- `22` 绑定：海外客群用谷歌绑定，语言随账户区。
- `08` 报价：多语言配置 +X% 或含在旗舰档。
- 医疗背景（如客户为跨国医械）：多语 IFU / 标签 / 法规文件可直接喂库（`21`）。

---

## 5. 报价（联动 `02` / `08`）

- 单语 → 多语：+15%~30%（按语种数）。
- 旗舰档可含 3 语；超过按语加购。
- 交付物文档翻译：按页 / 按套计费，或含在搭建费。

---

## 6. 边界

- 多语言解决"说什么语言"，不解决"质量"——类人效果仍由四件套 + 私密层（`18`）决定。
- 机器翻译仅兜底，关键角色卡建议人工校译，避免腔调失真。
