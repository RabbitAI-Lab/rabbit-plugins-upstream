# 31 · 一键配置到任意大模型（换模型不换人格）

> **定位**：客户配好的数字 AI，**一键装到任意大模型 / 任意平台**——WorkBuddy、Claude Code、Cursor、Coze、Dify、元器、本地 Ollama 都行。底层模型随便换，人格（记忆 / 角色 / 工具 / 主动规则）不变。这是"买断自改造"（`24`）的底层能力，也是差异化卖点：平台只给 Bot，我们给**可迁移的类人资产**。

---

## 1. 标准配置包（一次配置，处处运行）

| 组件 | 内容 | 落哪 |
|------|------|------|
| 角色三件套 | `SOUL.md`（我是谁）+ `IDENTITY.md`（标识）+ `USER.md`（关于客户） | 任何支持人格文件的平台 |
| 记忆骨架 | 分层记忆（见 `32`）+ 写回规则 | 记忆文件 / 记忆层 API |
| 工具清单 | 声明式工具列表（名称 / 权限 / 触发） | 各平台工具配置 |
| 主动规则 | 定时任务 / 巡检 / 提醒 | 各平台定时 / 调度 |
| 加密 ID 凭证 | 出处可验（`17`），随包携带 | 交付物内 |

---

## 2. 一键导入四通道

1. **文件直读**：把配置包丢进支持人格文件的平台（WorkBuddy / Claude / Cursor）→ 自动生效。
2. **平台导入**：Coze / Dify / 元器等可视化平台，按"人设 + 知识库 + 工作流"三步粘进去。
3. **API 注入**：有工程能力 → 用配置包内容调平台 API 批量建。
4. **本地部署**：Ollama + 7B 本地模型（见 `23` 低硬件），配置包注入，数据不出门。

> 我们提供「四通道对照表」（每个平台怎么粘哪段），随交付附送（`29` 手册引用）。

---

## 3. 兼容矩阵（示例）

| 平台 / 模型 | 通道 | 备注 |
|-------------|------|------|
| WorkBuddy | 文件直读 | 本技能同生态，最顺 |
| Claude Code / Cursor | 文件直读 | 角色三件套原生支持 |
| Coze / 元器 / 百炼 | 平台导入 | 人设 + 知识库 + 工作流 |
| Dify / FastGPT | 平台导入 / API | 私有化可托管 |
| Ollama 本地 7B | 本地部署 | 低硬件、数据不出门 |
| OpenAI / 其他 API | API 注入 | 通用 |

---

## 4. 换模型不换人格（承诺）

- 配置包**模型无关**：不绑定某家模型，换模型只换"大脑"，不改人格。
- 换模型后重跑评测（`16`），给新的对标等级——人格稳定、能力分数如实更新。
- 换模型前备份记忆（`07` 哈希留证），回滚有据。

---

## 5. 诚实边界

- 一键配置交付的是**公开层配置**；私密层获利引擎（专有调参）不随包（`18`）。
- 不同平台能力有差异（如插件生态、记忆 API），四通道对照表如实标注"哪家支持什么"，不夸大。
- 本地 7B 与云端大模型的效果有差距（`23` 已诚实说明），按档选择。
