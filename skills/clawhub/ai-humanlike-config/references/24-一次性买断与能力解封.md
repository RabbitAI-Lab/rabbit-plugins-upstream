# 24 · 一次性买断与能力解封（可自改造）

> **定位**：客户不想被月费绑、想"一次付费、资产归我、自己改"——提供**买断模式**：付一笔，解锁全部能力（打开"能力封印"），拿到完整可运行配置，后续自己改造。

---

## 1. 买断交付物

- **完整可运行配置**：记忆架构 + 角色卡 + 工具清单 + 主动规则（公开层全量）。
- **配套文档**：搭建说明 + 改造指引 + 验收单。
- **能力解封**：不再按订阅门控，全部 `08` 能力一次开放。
- **加密 ID 随附**：买断数字人同样签发 `17` 出处凭证，可验真。

---

## 2. 自改造权

客户拿到交付物后，可自由改：
- 提示词 / 角色语气
- 工具清单（增删 API / 脚本）
- 记忆结构与喂料（`21`）
- 主动规则

我们提供**改造指引**（文档）+ **可选付费技术支持**（按次 / 包年）。

---

## 3. 与订阅的区别

| 维度 | 订阅（月费） | 买断 |
|------|--------------|------|
| 付费 | 持续月费 | 一次性 |
| 资产归属 | 配置在用，服务续 | 配置归客户 |
| 服务 | 含养护 / 升版 | 可选维护包 |
| 适合 | 想省心持续在场 | 想自主、控成本 |

两者可组合：买断 + 可选维护包，兼得资产归属与持续支持。

---

## 4. 诚实边界（关键）

- **买断 = 公开层全量**，客户可改造基于公开层。
- **获利引擎（私密层专有调参）仍归我们**，不在交付物内（见 `18`）。客户改造的质量上限，由私密层决定——这正是我们持续**升版服务**（`13`）的价值：想再上一个台阶，回来买升版。
- 不承诺"买断即获全部秘密"：方法论的护城河不在交付物，在私密层。

---

## 5. 版本与合规

- 买断含**当时最新版**；后续升版（`13`）另购或维护包含。
- **IP 不转让**：商标 / 方法论版权仍归我们（见 `11`），客户改后自负责任（见 `11` 免责）。
- 买断数字人仍受 `11` 反滥用 / 终止条款约束。

---

## 6. 报价（联动 `02` / `08` / `13`）

- 买断价 ≈ 搭建费 × 3~5 倍（或独立档），按 `08` 档位基线。
- 维护包可选：年费 = 月费档 × N，含养护 + 折扣升版。
- 多语言（`25`）/ 喂料额度（`21`）按档叠加。

---

## 7. 联动

- `08` 能力菜单：买断解锁全量。
- `13` 升版：买断后升版即增值接口。
- `18` 方法保密：买断不含私密层。
- `11` 权益保障：IP 归属 / 改后责任 / 反滥用。
- `17` 加密 ID：买断数字人同样可验真。
