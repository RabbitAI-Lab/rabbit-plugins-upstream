# 能力清单与分级报价（让客户勾选，按能力分级收费）

> 配套 `SKILL.md` / `02-报价与交付.md` / `04-业务流SOP.md`。
> 本文件解决两件事：① 把"像人"的能力**列成一张可勾选的菜单**（含关键度/大小/是否含造AI能力）；② 给出**按勾选自动分级报价**的透明算法。谈单时直接发这张表，客户打钩，报价当场出来，不靠拍脑袋。

---

## 0. 头号卖点 · 可观测看板（客户可见，不黑箱）

我们配的数字员工/数字助理，**运行状态客户一眼可见**——这是和普通"黑箱 AI 助手"最大的区别，也是转化时的杀手锏：

- **健康状态**：在线/离线、记忆库水位、角色漂移预警、工具连接状态，实时呈现。
- **任务进度**：在跑的任务、待办、已完成的活，带时间戳进度条，客户随时查"我那单啥进度"。
- **全局展示**：一个看板聚合"记忆/主动/工具/角色"四件套健康度 + 当月活跃度 + 下月养护计划。

> 卖点话术：**"你配的 AI 不是黑箱，状态、进度、全局一眼可见——像有个随时在线、看得见在干活的员工。"**
> 可观测看板本身是一项可勾选能力（见下方清单 #5），但建议**默认带**，因为它既是差异化卖点，也是信任锚点（和 `07` 可追溯天然互补：看板看"现在"，时间戳/哈希看"历史"）。

## 2. 分级算法（透明、可复核）

每项能力给一个**权重分**，客户勾选集合的总分 → 自动落档。算法公开，客户自己也能算：

```
权重 = 关键度基分 + 大小基分 + 造AI加成
  关键度基分：核心/关键 = 3，重要 = 2，可选 = 1
  大小基分：  大 = 3，中 = 2，小 = 1
  造AI加成：  含造AI能力 +5
```

各能力权重：
`#1=5 #2=5 #3=5 #4=5 #5=4 #6=5 #7=11 #8=4 #9=2 #10=2 #11=5 #12=4 #13=4 #14=3`

**落档规则**

| 总分区间 | 档位 | 说明 |
|----------|------|------|
| 含 #7（造AI） | **强制 ≥ 专业版** | 造AI能力是溢价核心，单独勾选即触发专业档起 |
| 14–22 | 基础版 Essential | 四件套核心 + 可观测，够用起步 |
| 23–34 | 标准版 Standard | + 防护/知识库/多语言，进阶 |
| 35–48 | 专业版 Pro | + 造AI + 可追溯 + 私有化，高阶自进化 |
| >48 或 含定制 | 旗舰版 Enterprise | 全量 + 多Agent + 语音 + SLA，面议 |

> 客户勾选后，总分与落档当场算出，写进「模板 I 能力勾选与分级报价单」，透明无歧义。

## 3. 分级报价（国内 / 国外双市场）

> 以下为**各档搭建费 + 月费**基准；与 `02` 的三档/消费级定价同源，本表是按能力模块化后的"档位版"。诊断费另计（见 `02`）。

### 国内（人民币 · 法币结算）

| 档位 | 典型能力组合 | 搭建费 | 月费 | 周期 |
|------|--------------|--------|------|------|
| 基础版 Essential | #1#2#3#4#5（四件套+看板） | ¥1.5k–3k | ¥299–599/月 | 搭建 3–5 天 |
| 标准版 Standard | 基础 + #6#8#12#9 | ¥3k–5k | ¥599–999/月 | 搭建 1–1.5 周 |

| 旗舰版 Enterprise | 全量 + #13#14 + SLA | ¥15k 起（面议） | ¥3k/月起（面议） | 定制 |

### 国外（美元 · 法币平台结算，服务贸易收结汇）

| 档位 | 搭建费 | 月费 |
|------|--------|------|
| 基础版 Essential | $250–500 | $45–90/月 |
| 标准版 Standard | $500–900 | $90–150/月 |
| 专业版 Pro | $1k–1.8k | $180–350/月 |

## 5. 勾选式报价流程（谈单 SOP）

1. 发「能力菜单」（§1）给客户，让其按业务需要打钩。
2. 当场算总分 → 落档（§2）→ 出搭建费+月费（§3），或勾单项加购（§4）。
3. 写入「模板 I 能力勾选与分级报价单」，客户确认。
4. 进阶段 2 签约（定金 50%）→ 阶段 3 搭建 → 阶段 4 交付（含可观测看板验收）→ 阶段 5 月费。
5. 可观测看板在交付时即开通，作为信任锚点贯穿月费期。

> 与 `06`「AI 造 AI」叙事配合：把"你能勾选的能力、勾完当场报价、配好看得见状态"讲成**透明、可控、不黑箱**的差异化，比"最聪明最强大"站得住脚也更有说服力。
> 交付后不是终点——能力持续分版本演进，新能力出来客户一键升版（见 `13`），把一次性搭建变"搭建 + 月费 + 升版"复利。
