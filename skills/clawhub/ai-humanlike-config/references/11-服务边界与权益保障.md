# 服务边界与权益保障（自我保护 + 透明增信）

> 配合 `04-业务流SOP.md`（阶段 2 签约 / 阶段 4 收尾）、`07`（可追溯）、`10`（安全加固）。
> 本文件把"我们到底保什么、不保什么、谁的东西归谁、客户乱用怎么止损"写成可落进协议的条款。
> 写给**服务方**看：既是风险防线，也因"边界写清楚"本身让客户更敢签——透明即信任。

---

## 一、免责与责任边界（最核心）

**1. AI 输出不保证 100% 准确**
- 数字员工基于大模型推理，输出可能因模型幻觉 / 知识截止 / 数据偏差出现错误。服务方已按四件套尽力调教，但**不保证输出绝对正确、完整、最新**。
- 客户对关键决策（签合同、财务、医疗、法律、重大业务动作）须**自行复核**后方可采用；因直接采用 AI 输出产生的后果，服务方不担责。

**2. 不替代真人专业服务**
- 数字员工 / 数字老师 / 儿童 AI 老师均为**辅助工具**，不替代真人医师、律师、教师、心理咨询师等专业判断。
- 涉及诊断、处方、法律意见、心理干预等，必须转交持证真人；产品设计上已设边界（见 `05` 儿童护栏、`10` 越权拦截）。

**3. 责任上限（封顶）**
- 无论因何引发（含违约、侵权、疏忽），服务方累计赔偿责任**不超过该客户已实际支付的服务费用总额**。
- 不承间接损失（利润损失、商誉损失、数据衍生损失等）。此上限写进协议第 6 条，避免"无限责任单"。

## 二、知识产权归属（防方法论被白嫖）

**1. 客户数据归客户**
- 客户提供的业务资料、客户清单、对话内容、项目上下文等，所有权与隐私权归客户；服务方仅在授权范围内为交付使用，不挪作他用（保密见 NDA / `04` 模板 C）。

**2. 方法论与交付框架归服务方**
- 四件套方法论、配置模板、角色卡结构、诊断表、SOP、本技能包本身，知识产权归服务方（品牌：注册老炮）。
- 为客户**具体业务代配出的运行实例**（角色卡内容、记忆架构、工具清单、文档）交付后归客户使用；但服务方**保留底层方法论的再使用权**，可沉淀为通用能力复用于其他客户，不构成侵权。

**3. 可复售沉淀**
- 重复交付中抽象出的通用模块，服务方有权产品化（如 Skill 上架，见 `04` 阶段 6 upsell），客户不享有分成或权属主张。
- 客户**不得**将服务方方法论 / 模板逆向工程、转售、冒充自有资产。

## 三、数据责任划分

| 事项 | 责任方 | 说明 |
|------|--------|------|
| 客户业务数据 | 客户 | 归客户所有，服务方按授权使用、按 `07` 留痕 |
| 本地推理数据 | 客户 | 优先本地，不出门；服务方不留存 |
| 云端 API 任务 | 双方 | 须客户知情 + 评估合规（PIPL/GDPR），密钥客户自管 |
| 交付物凭证（哈希/时间戳） | 服务方 | 按 `07` 存证，用于验收/争议取证 |
| 账号 / 密钥 / 核心系统 | 客户 | 服务方不接管、不代管（红线） |

> 数据不出门优先本地；必须上云的任务，客户须书面确认并自管凭证，服务方不碰核心密钥。

## 四、反滥用条款（呼应"只防不攻"）

> 客户用我们配的 AI 干坏事，会反噬我们——必须有"一键止损"条款。

**禁止用途（任一即违约）**
- 用于网络攻击、入侵、破解、爆破、投毒、钓鱼、诈骗等违法活动；
- 生成侵权 / 诽谤 / 歧视 / 色情 / 违规内容；
- 规避监管、洗钱、虚拟货币相关（2026-02 八部门通知）；
- 绕过本技能安全加固（见 `10`）强行注入恶意指令。

**违约处置**
- 服务方有权**单方面立即终止**服务、**不退款**、收回配置权与通行证；
- 已交付文档中嵌有的数字指纹 / 水印（`07`）保留，作为归属与追责证据；
- 涉及违法的，保留向监管 / 司法机关报告的权利。

## 五、终止与数据交接 / 销毁

**1. 终止情形**
- 客户原因：提前 15 天书面通知终止月费（与 `04` 模板 C 第 7 条一致）；
- 服务方原因：客户违约（见第四节）、长期欠款、业务不匹配；
- 自然终止：月费逾期超 __ 天视为终止。

**2. 终止后处理**
- **数据返还**：客户数据（如客户要求）在终止后 __ 个工作日内返还或应要求销毁，返还不含服务方方法论资产；
- **配置交接**：运行实例配置权移交客户自维护（路径 A 退款终止时同理，见 `04` 验收争议）；
- **客户不满意 · 退款条款（新增）**：客户对交付结果不满意，可申请退款——但退款以**销毁数字员工（含配置与数据）**为前提，防"退款还继续白用"：
  - 退款触发：验收不通过且经 `04` 争议处理仍无法达成一致，或月费期内客户明确不满意；
  - 退款条件：客户确认销毁该数字员工运行实例（配置 + 数据），服务方收回通行证 / 授权码并执行销毁；
  - 退款范围：按协议约定退还（如搭建费扣除已耗工时 / 已发生的服务费后，剩余部分退还），验收争议口径见 `04` 验收争议；
  - 销毁留证：销毁动作按 `07` 打时间戳 + 哈希留证，双方确认；
  - 指纹保留：交付物数字指纹 / 水印（`07`）服务方**保留**，不随退款销毁消除；
  - 通行证注销：退款销毁后客户 ID / 通行证 / 授权码同步注销（联动 `14`），展示授权、转介绍记录同步失效。
- **指纹保留**：交付物上的数字指纹 / 水印（`07`）服务方**保留**，用于归属标识与防冒用，不随终止消除；
- **通行证注销**：客户 ID / 通行证可注销，注销后权益（展示优惠、转介绍记录）同步失效。

## 六、争议管辖与法律适用（含跨境）

- **国内单**：适用中国大陆法律；争议先协商，协商不成提交服务方所在地（或约定地）**人民法院**管辖 / 或约定仲裁机构。
- **跨境单**：在协议中单独列明适用法（如客户所在地法或中立第三地法）与争议解决地；跨境数据传输须客户**单独同意**并满足 GDPR / 数据出境合规（见 `07`）。
- 争议解决期间，客户须**正常支付无争议部分**月费，不停服不停付制造僵局。
