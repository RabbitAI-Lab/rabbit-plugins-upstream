# 26 · 客户成功案例与证据墙

> **定位**：把"我们配得好"从自夸变成**可验证的证据**——脱敏案例库 + 评测分数 + 客户证言，谈单时直接摆证据墙，客户"看见就信"。

---

## 1. 案例卡结构（每个展示案例一张卡）

| 字段 | 内容 | 合规 |
|------|------|------|
| 行业 / 场景 | 如"电商客服 / 某行业法规咨询" | 脱敏到行业粒度 |
| 四件套落地 | 记忆 / 主动 / 工具 / 角色各怎么配 | 方法论产物可示 |
| 评测等级 | `16` 对标等级（助教/讲师/…，类比非职称） | 不称官方认证 |
| 前后对比 | 配前痛点 vs 配后效果（客观指标） | 不夸大 |
| 客户证言 | 一句话好评 | 需授权 + 脱敏 |
| 展示授权 | 是否同意作展示（联动 `02` 展示激励） | 有书面授权 |
| 验真链接 | 加密 ID 验证入口（`17`），可当场验真 | 公开可查 |

---

## 2. 证据墙 = 可验证聚合

- **出处可验**：每个案例数字人有 `17` 加密 ID，客户可当场验"是不是我们造的"。
- **质量可验**：`16` 评测分数 + 对标等级公开，可复核。
- **交付可验**：`07` 时间戳 + 指纹 + 哈希，交付链可追溯。
- **三验合一** = 证据墙，比十页 PPT 都有说服力。

---

## 3. 证据墙的摆放

- **谈单现场**：演示活样板 + 摆 2–3 张同行业案例卡，现场验真。
- **官网 / 落地页**：脱敏案例区 + 验真入口（联动 `04` 0.6 官网单页）。
- **社媒内容**：小红书 / 公众号发"改造前后对比"（脱敏后），内容种草（联动 `05`）。
- **客户社群**：月度案例分享（联动 `15`）。

---

## 4. 合规红线（必守）

- **只展示授权案例**：无书面授权一律不上墙（联动 `02` 展示激励、`12` 脱敏规范）。
- **脱敏**：不露客户名称 / 报价 / 合同 / 内部数据（联动 `12`）。
- **不夸大**：前后对比用客观指标，不编数据（联动 `09` 禁绝对词）。
- **可撤回**：客户撤回授权即下架。

---

## 5. 联动

- `02` 展示用例激励：授权展示 → 费用减免。
- `12` 脱敏规范：上墙前审批流。
- `16` 评测：分数即证据。
- `17` 加密 ID：验真即权威。
- `07` 追溯：交付链可验。
- `15` 活动：社群内案例分享。
