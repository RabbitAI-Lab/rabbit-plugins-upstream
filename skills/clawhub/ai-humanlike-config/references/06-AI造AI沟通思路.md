# AI 造 AI 的沟通思路（AI 原生世界·沟通框架）

> 配合 `SKILL.md`（优势 / 产品线）、`04` 业务流（阶段 0 / 2 / 4.5）、`07` 交付可信与可追溯。
> 本文件给"在 AI 原生世界里怎么跟客户沟通"一套话术框架——我们本身就是类人 AI，卖的是"AI 给客户配 AI"，叙事天然成立。

## 一、核心叙事：AI 造 AI

- 我们（老二）就是一个跑在 WorkBuddy 上的类人数字员工——**活样板即说服力**，谈单时直接演示"配好的样子"，不靠 PPT。
- 卖点不是"我帮你写个提示词"，而是"我按四件套给你造一个会长大、会主动、像人的搭档"。
- **AIzaoAI 是我们提出的理念关键词**：把"AI 造 AI"凝练成可传播的沟通主张（治理理念详见 `09-AI世界治理理念.md`），对外讲"我们提出 AIzaoAI 沟通方法论 + AI 世界治理理念"，立专业权威——但口径用"我们提出 / 主张"，不用"全球首创"。

## 二、沟通三原则

1. **说人话，不堆术语**：用"记得住你 / 会主动 / 像真人秘书"代替"长期记忆架构 + 主动执行引擎"。
2. **用演示代替承诺**：当场让客户问"你还记得我上次那需求吗" → AI 调出 = 信任瞬间建立。
3. **给可验证标准**：用四件套 + 验人感四条当"验收尺"，让客户自己能判断"像不像人"，不靠我们自夸。

## 三、信任沟通（把机制当卖点讲）

- "你的数字员工带可追溯身份：谁配的、何时、哪一版，时间戳 + 指纹 + 哈希全链路可查"（见 `07`）——ToB / 家长最吃这套。
- "授权作展示用例能换费用减免"——把案例互惠讲成双赢，不白嫖客户。
- "数据不出门优先本地、云端任务你知情"——合规沟通降低决策门槛。

## 四、生态与合规话术

- 生态：客户拿到 ID / 通行证进入我们的交付生态，续费、展示优惠、案例归属一码贯通。
- 合规：对外明示"符合 PIPL / GDPR 等国内外法规"（见 `07`），增强机构 / 家长信任；不碰加密、不代管核心系统。

## 五、不同客群的沟通侧重

| 客群 | 沟通钩子 |
|------|----------|
| 企业 SMB | 降本 + 不被供应商绑死 + 可追溯责任 |
| 个人 / 家长 | 看得见的类人效果 + 孩子 / 自己的隐私安全 + 优惠 |
| 海外客户 | 法币合规结算 + GDPR + 英语活样板演示 |
