# 30 · 客户端口体系（交付 / 付费 / 咨询 / 投诉建议）

> **定位**：把"接单靠聊天"升级成**四个标准化端口**——客户在哪都能进来、办哪件事走哪个口，服务过程全程留痕（`07`）。四口闭环 = 像一家正经公司，不像个体户。

---

## 1. 四端口总览

| 端口 | 客户来干嘛 | 入口形态 | 承载模块 |
|------|-----------|----------|----------|
| **咨询端口** | 想了解、想报价、想诊断 | 官网表单 / 公众号 / 微信 / 群 | `01` 诊断、`02` 报价、`16` 初测、`06` 话术 |
| **交付端口** | 验收、拿配置、看文档、学用法 | 交付门户（网页/文件夹） | `04` 验收、`07` 追溯、`12` 手册、`29` 引导 |
| **付费端口** | 付定金 / 尾款 / 月费 / 买断 | 收款链接 / 对公 / 平台托管 | `04` 0.5 付款闭环、`02` 报价、`24` 买断 |
| **投诉建议端口** | 不满意、提意见、要退款 | 专属邮箱 / 表单 / 群 @ | `11` 退款销毁、`04` 验收争议、`20` 售后 |

---

## 2. 各端口功能清单

**咨询端口**
- 免费诊断问卷（`01`）+ 能力菜单勾选（`08`）+ 免费初测定档（`16`）。
- 会话留痕：咨询记录打时间戳哈希，后续签约可直接引用。

**交付端口**
- 交付物下载（配置卡 / 文档 / 加密 ID 凭证 `17`）。
- 验收在线确认（模板 D）+ 交付可信三要素查询（`07`）。
- 引导手册在线版（`29`）+ 操作录屏。

**付费端口**
- 分阶段收款：定金 50% → 尾款 50% → 月费 → 升版费 → 买断费。
- 法币通道（微信 / 支付宝 / 对公 / Stripe 等，见 `02`），**不收加密货币**（红线）。
- 每笔收款回写哈希留痕，与订单 / 客户 ID 绑定（`07`）。

**投诉建议端口**
- 客户提交不满意 / 建议 → 自动转工单 → 按 SLA 响应（`20`）。
- 退款流程：走 `11` 退款条款（**退款以销毁数字员工为前提**）。
- 建议沉淀：转 `13` 升版需求池，客户建议被采纳可在月报公示（`12`）。

---

## 3. 四口打通链路

```
咨询（意向）→ 诊断/报价 → 付费（定金）→ 交付（验收+手册）→ 付费（尾款）→ 售后（月费/升版/买断）
                                                    ↑                      ↓
                                          投诉建议 ←—— 不满意/建议 ——→ 退款销毁 / 升版改进
```

- 每个环节都有 `07` 留痕，客户随时可查"我办到哪了"。
- 四口数据统一到客户 ID / 通行证（`07` / `22`），跨口不重复填表。

---

## 4. MVP 落地（先轻后重）

- **阶段一（轻）**：公众号 + 企微群 + 表单工具当端口，四口各一个入口，够用即可。
- **阶段二（中）**：交付门户网页（CO 静态托管，见 `04` 0.6）+ 收款链接。
- **阶段三（重）**：小程序 / 独立站，四口合一，看板化。

> 端口是**信任工程**不是技术工程：先让客户"找得到、办得成、有回执"，再谈自动化。

---

## 5. 合规

- 咨询 / 投诉数据含个人信息，按 PIPL 最小必要（`07` / `11`）。
- 付费端口走合规收款（见 `04` 4.6 税务实操），不碰加密币。
- 投诉建议渠道明示处理时限（SLA，见 `20`）。

---

## 6. 联动

- `04` 业务流（四口即其阶段入口）、`20` 售前中后、`07` 追溯、`11` 退款、`24` 买断、`12` 手册、`16` 初测、`01` / `02` / `08` 咨询报价。
