# 27 · 升级服务与旧 AI 改造

> **定位**：客户手里**已经有 AI / Agent**，但"不像人、没记忆、不主动"——做**旧改新**迁移服务。存量市场，比从零搭建更容易成交：客户痛点已存在，我们给"升级"而非"重来"。

---

## 1. 旧 AI 体检（引流入口）

- **免费 / 低价体检**：用 `01` 诊断表给存量 AI 打分，找出四件套缺口。
- **输出体检报告**：现状评分 + 缺口清单 + 改造报价（`08` 档位）。
- **价值**：客户先看到"差在哪、怎么补"，再决定改不改。

---

## 2. 改造服务包

| 模块 | 内容 | 联动 |
|------|------|------|
| 记忆补建 | 历史对话 / 资料清洗入库，建立分层记忆 | `00` / `21` |
| 主动规则 | 补定时任务 / 巡检 / 提醒，主动 ≠ 越权 | `00` |
| 工具接驳 | 原有 API / 系统平滑接入，最小权限 | `00` / `10` |
| 角色重铸 | 人设统一，不串角色 | `00` |
| 数据迁移 | 旧知识 / 配置迁移、清洗、去重 | `21` |
| 版本化 | 升级到能力版本管理（v1.0.0 起） | `13` |

---

## 3. 报价（双市场）

- **体检**：免费或 ¥200 / $30（引流）。
- **改造费**：按 `08` 档位 60–80% 折算（存量改造通常比从零快）。
- **升版维护**：改造后进入 `13` 升版体系，月费续费。
- 改造完重测（`16`），给新对标等级，交付"升级前后"证据（`26`）。

---

## 4. 诚实边界

- 改造基于**公开层**交付，私密层获利引擎不交付（`18`）。
- 存量系统若有客户自有代码 / 密钥，不碰、不越权（`10` / `11`）。
- 改造不承诺"原系统零风险"：接驳前做兼容评估，写入服务协议。

---

## 5. 联动

- `01` 体检入口、`00` 四件套落地、`08` 报价档、`13` 版本化、`16` 重测、`21` 数据迁移、`10` / `11` 安全与责任、`26` 案例证据。
