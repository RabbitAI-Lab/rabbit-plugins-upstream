# 交付可信与全链路可追溯（客户 ID / 通行证 + 时间戳 / 指纹 / 哈希）

> 配合 `SKILL.md`、`02` 展示用例激励、`04` 阶段 2（签约授权）/ 4.5（交付可信）、`06` 沟通思路。
> 本文件定义"交付即带身份与可追溯"的信任基础设施，使优惠核销、续费权益、验收争议均可全链路查证。

## 一、客户 ID 与通行证体系

- **发放**：每单成交为客户（及其数字员工）发放「客户 ID + 通行证」，作为生态内身份锚点。
- **用途**：权益核销（展示优惠 / 续费档）、案例归属、版本追溯、跨单识别。
- **形态**：通行证可为卡号 / 二维码 / 令牌，不含敏感个人信息；ID 与展示授权、月费状态绑定。
- **授权控制层（见 `14`）**：在通行证「身份」之上叠加「同意授权码」——把能力授予/吊销/熔断抽象成可发放的码，客户以最简单方式控 AI，且绑定状态在现实与 AI 双世界一致可验。
- **注销**：客户可随时注销 ID，注销后停止关联并删除可识别绑定（见第三节合规）。

## 二、全链路可追溯三要素

| 要素 | 作用 | 做法 |
|------|------|------|
| 时间戳 | 记录"谁配的、何时、哪一版" | 交付 / 每次版本迭代打可信时间戳（权威时间源或区块链存证） |
| 数字指纹 | 归属标识 + 防冒用 | 交付物嵌暗纹指纹 / 水印（与文档安全工具链一致） |
| 哈希 | 完整性校验 + 防篡改 + 取证 | 每版计算 SHA-256 存证，校验是否被改、证明归属 |

- **链路**：客户 ID ↔ 交付版本 ↔ 时间戳 ↔ 哈希 ↔ 指纹 串成可追溯链，任一环节可回溯。
- **应用**：展示优惠核销（模板 H 绑定 ID）、续费权益识别、验收争议取证（证明"这一版是我们配的、未被篡改"）。

## 三、合规（国家 + 国际）

- **国内（PRC）**：遵循《个人信息保护法》《数据安全法》《网络安全法》——最小必要采集、明示同意、加密存储、可查阅可删除（注销权）。
- **国际（GDPR 等）**：跨境传输需单独同意 / 标准合同；通行证不含特殊类别个人数据；哈希加盐防逆向。
- **通用**：不采集与服务无关的个人信息；展示用例一律脱敏；时间戳 / 指纹 / 哈希 存证不暴露原始私密内容。
- **红线**：ID / 通行证仅作生态识别与权益锚点，不收集与客户核心系统 / 密钥无关的数据；不碰加密支付。

## 四、与业务流联动

- 签约（阶段 2）：勾选展示授权 → 绑定客户 ID → 触发 `02` 展示用例激励。
- 交付（阶段 4.5）：打时间戳 + 指纹 + 哈希 → 形成可追溯交付物。
- 月费 / 转介绍：客户 ID 串联权益，优惠核销全链路可查。

## 五、落地实现规格（可直接照做）

> 第二节是"做什么"，本节是"具体怎么落地"。按客户敏感等级选档，不强行上链。

### 5.1 可信时间戳

| 档 | 做法 | 适用 |
|----|------|------|
| 轻量（默认） | 交付物元信息写 `signed timestamp`（服务方私钥签名的时间标记）+ 版本号；本地可信时钟 | 一般交付、内部留痕 |
| 权威（取证/争议） | 调用**权威可信时间戳服务**（RFC 3161，如联合信任 / 众信等第三方 TSA）生成时间戳令牌，附在交付包 | 展示用例、验收争议、对外确权 |
| 上链（强取证） | 将交付物哈希写入区块链（公开可验、不可篡改） | 高价值单、跨境确权 |

- 记录字段：`客户ID + 版本号 + 配置人 + 时间 + 时间戳令牌/交易哈希`。
- 工具：`openssl ts` / 第三方 TSA API / 区块链存证 API；无需自研。

### 5.2 数字指纹（归属标识 + 防冒用）

- **配置文件**：交付物头部嵌"归属指纹"注释块（含 服务方品牌标识 + 客户 ID + 版本号 + 时间戳哈希），他人盗用可被识别溯源。
- **文档类交付物**：加水印 / 暗纹（与既有文档安全工具链一致——暗纹指纹 / 电子签 / 水印）；可附版本二维码。
- **原则**：指纹只标归属与版本，**不含**客户私密内容（PIPL / GDPR）。

### 5.3 哈希（完整性 + 防篡改 + 取证）

- **算法**：每版交付物计算 `SHA-256`；校验时被改即不一致。
- **加盐（个人/敏感数据）**：含未成年人 / 个人信息的字段，哈希前**加盐（salt）**防彩虹表逆向——PIPL 最小必要 + GDPR 哈希加盐要求。
- **存证位置**：本地存证库（默认）+ 可选上链；验收争议时双方各自重算哈希比对即可证完整性，无需公开原文。
- **工具**：`sha256sum` / `openssl dgst -sha256` / 编程语言 `hashlib`，零成本自算。

### 5.4 串联成链（交付即带）

交付包结构示例：

```
交付包/
  ├─ 配置物（角色卡/记忆架构/工具清单/主动规则）
  ├─ 归属指纹（#5.2 注释块 + 水印）
  ├─ 时间戳令牌（#5.1）
  ├─ hash-manifest.txt（每文件 SHA-256 + salt 标记）
  └─ 客户ID ↔ 版本 ↔ 时间戳 ↔ 哈希 ↔ 指纹 对照表
```

任一环节可回溯：证明"这一版是我们配的、未被篡改、何时配的"。
