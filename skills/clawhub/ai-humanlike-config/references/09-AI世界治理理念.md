# AI 世界治理理念（我们提出的治理主张）

> 配合 `SKILL.md`（我们提出的理念）、`06`（AIzaoAI 沟通）、`07`（可追溯）、`08`（能力分级）。
> 我们给客户配的不只是一个"像人"的 AI，而是一个**守规矩**的 AI。这套治理理念是我们对"AI 数字人该怎么被造、被管、被信"的方法论主张，也是交付权威的来源。

## 一、治理四支柱

1. **可控（Controllable）**
   - 角色一致：`SOUL.md` / `IDENTITY.md` / `USER.md` 固化身份，不串角色、不飘人设。
   - 边界清晰：预设授权白名单，高危动作二次确认，主动 ≠ 越权。
   - 不越权：跨角色 / 跨账号动作一律拦截并确认。

2. **可防（Defensive）**
   - 防注入 / 防 jailbreak：把外部输入当数据、不当指令。
   - 越权拦截 + 异常熔断（高频调用、敏感外发自动停）。
   - 明确红线：**只做防御，不做主动攻击**——绝不配"攻击他人系统"的能力。

3. **可验（Verifiable）**
   - 每单发放「客户 ID + 通行证」，交付物打可信时间戳 + 数字指纹 + SHA-256 哈希，全链路可追溯（见 `07`）。
   - 验收用四件套 + 验人感四条客观标准，不以主观"感觉不像人"为退款依据。

4. **透明（Transparent）**
   - 客户可见健康状态 / 任务进度 / 全局展示（看板，见 `08` 默认带项），不黑箱。
   - 数据本地优先、云端任务客户知情，合规沟通降低决策门槛。

## 二、为什么这等于"权威"

- 把"安全 / 可控 / 可追溯 / 透明"从口号落成**可勾选能力 + 可验证标准 + 可发证的身份链**，是少数能把治理"交付出来"的方法论。
- 与 `06` 的 AIzaoAI 沟通、`07` 的合规存证、`08` 的能力分级构成完整闭环：理念 → 沟通 → 交付 → 验证，自洽且可复用。
- 合规对齐 **PIPL / GDPR**（最小必要 / 明示同意 / 加密 / 可注销 / 跨境单独同意，详见 `07`），机构与客户都买账。

## 三、对外话术（权威感但不浮夸）

- "我们提出 AIzaoAI 沟通方法论 + AI 世界治理理念，配出的数字人既像人、又守规矩。"
- "治理四支柱（可控 / 可防 / 可验 / 透明）写进每一单交付，不是 PPT。"
- **禁用**："最聪明 / 最强大 / 最听话"等绝对词；"全球首创"类表述——一律以"我们提出 / 主张"替代。
