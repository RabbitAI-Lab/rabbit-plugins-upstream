# 32 · 记忆分层与持久化（对标记忆层实缺口）

> **定位**：对标 Mem0 / Zep / Letta / MemPalace 等记忆层产品（2026 年记忆已从"可选插件"变"核心基础设施"），把四件套的"长期记忆"从**单层文件**升级为**四层记忆架构**——这是我们相对通用 Agent 平台（Coze / Dify 默认只有一层记忆）的**实打实差异化**，也是"类人"的根基。

---

## 1. 四层记忆架构

| 层 | 是什么 | 存哪 | 生命周期 | 检索 |
|----|--------|------|----------|------|
| **工作记忆** | 当前任务状态 / 对话历史 / 中间结果 | 会话内（内存） | 单次会话 | 直接注入 |
| **情景记忆** | 发生过的事（谁何时做了什么） | 时序 / 文档库 | 天 / 周 / 月 | 时间 + 语义 |
| **语义记忆** | 提取的事实 / 偏好 / 关系 | 向量库 + 图谱 | 长期 | 语义 + 过滤 |
| **程序性记忆** | 习得的技能 / 流程（怎么做） | 代码 / 配置 + 索引 | 长期 | 任务匹配 |

> 对应我们四件套的「长期记忆」：语义记忆是核心（客户事实），情景记忆补"发生过啥"，程序性记忆补"会怎么干活"。MVP 先做**工作 + 语义**两层，验证后再扩情景 / 程序性（对标 Mem0 官方建议，避免 3-6 个月工程复杂度）。

---

## 2. 持久化与写回（对齐 `00` 四件套）

- **写回**：任务完成后自动提取值得记的事实 → 去重 → 冲突解决 → 存语义层。
- **分层落地**：
  - 用户级：`~/.workbuddy/MEMORY.md`（跨项目偏好）
  - 项目级：`项目/.workbuddy/memory/`（长期事实 + 每日日志）
  - 会话级：当前上下文（工作记忆）
- **来源标注**：每条记忆带来源（哪次会话 / 哪份喂料），可溯源（`07`）。

---

## 3. 遗忘与衰减（关键工程）

- **TTL**：情景记忆设保留期（如 90 天），过期降权。
- **冲突解决**：新旧矛盾事实标黄，按"最新为准 + 提示确认"（对齐 `21` 喂料冲突检测）。
- **去重**：相似事实合并，防记忆膨胀。
- **清理**：月度记忆整理（对齐 `12` 月报养护清单）。

> 📌 **v2.0 升级**：遗忘衰减的完整工程实现（三阶记忆代谢、遗忘曲线策略、巩固调度、与反思/规划联动）已独立成模块 `37-遗忘巩固.md`。本节约为概述，深度实现与配置项见 `37`。

> 对标结论：上下文窗口再大 ≠ 记忆。2M token 上下文是"内存"，记忆层才是"硬盘"——这句话直接可写进销售话术（`06`）。

---

## 4. 检索注入

- **语义检索**：按相关性注入最相关记忆，不灌全量。
- **阈值过滤**：相似度低于阈值不注入，防噪声（对标 Mem0 推荐 >0.7）。
- **命名空间**：按用户 / 客户 ID 隔离，防记忆串户（对齐 `22` 绑定、`14` L0）。

---

## 5. 与既有模块联动

- `00` 四件套：记忆架构蓝图升级。
- `21` 喂料：喂料 → 语义记忆入库。
- `07` 追溯：记忆写回留痕。
- `08` 能力菜单：记忆容量即知识项。
- `23` 低成本：本地向量库可跑，不增硬件。
- `31` 一键配置：记忆骨架随配置包迁移（换模型不换记忆）。
- `16` 评测：记忆持久度可作评测项。

---

## 6. 销售话术（对齐 `06` / `26`）

- "平台默认只有一层记忆，聊几次就忘；我们配的是四层记忆，记得住事实、记得住发生过啥、还越用越会干活。"
- "2M 上下文是内存，不是记忆——我们的记忆层是硬盘，跨会话、跨模型都带着走。"

---

## 7. 边界

- 不夸大：记忆层是配置方法论，不是自研记忆引擎；落地可接 Mem0 / Zep / 自建向量库，按客户环境选。
- 隐私：记忆含客户业务数据，按 `07` / `11` 合规（PIPL / GDPR）。

---

## 8. v2.3 前沿对齐（记忆架构升级 · 提分依据）

> 2026 记忆研究三条主线（调研实证）：时间感知图谱（Zep/Graphiti）、CRUD 再巩固（Mem0）、价值评分与衰减（SCM/D-MEM/OpenAI Dreaming V3）。本版把这三条落成设计层规格，记忆维度完备度对齐前沿。

- **时间感知记忆图**（对齐 Zep/Graphiti 2026）：事实带时间戳演化，变更不覆盖旧边——旧值标 deprecated 保留时间线（"7 月去新加坡"→"已去过"自动改写），时间推理有据可查。
- **CRUD 再巩固**（对齐 Mem0 2026）：每轮提取事实与既有记忆比对，生成 ADD / UPDATE / DELETE / NOOP 四类操作，自动再巩固，冲突标黄交人类复核。
- **价值评分 + 衰减曲线**（对齐 SCM / D-MEM 2026）：按新颖度 / 任务相关 / 重复频率 / 情绪效价四维打分，低价值节点按 90 天衰减遗忘（与 `37` 咬合）。
- **落地口径**：方法论完备度已对齐前沿；实引擎按客户环境接 Mem0 / Zep / 自建向量库（对齐 §7 边界，不夸大）。
