# 21 · 客户自助喂料与知识扩容

> **定位**：客户自己往数字人的知识库"喂料"，就能扩大它的知识容量——不依赖我们、边际成本近零、越用越懂业务。这是**降低服务依赖、提升续费粘性**的关键能力。

---

## 1. 喂料入口（越方便越好）

| 入口 | 适用场景 |
|------|----------|
| 上传面板 | 客户后台拖拽 PDF/Word/Excel/网页 |
| 邮箱转发 | 把资料邮件转发到专属地址，自动入库 |
| API | 企业系统定时推送（如产品库变更） |
| 微信对话框 | 个人线客户直接发文件/链接给数字人 |
| 文件夹监听 | 指定目录放文件即自动摄取 |

---

## 2. 格式与处理流水线

- **支持格式**：PDF / Word / Excel / 网页 / Markdown / 语音转写文本。
- **流水线**：上传 → 清洗（去页眉页脚/乱码）→ 切片 → 向量化 → 入库（RAG）。
- **增量写回**：喂料即更新「长期记忆」层，不破坏角色卡与工具清单。

---

## 3. 质量护栏（防喂坏）

- **去重**：相同内容不重复入库。
- **冲突检测**：新旧资料矛盾时标黄，提示客户确认以哪份为准。
- **来源标注**：每条知识带"来自哪份资料 / 何时喂入"，可溯源。
- **敏感词过滤**：含个人敏感信息的资料按 PIPL 拦截或脱敏后入库。
- **人工审核（可选）**：高合规行业（如医疗）可设"喂入需审核"开关。

---

## 4. 容量档（联动 `08`）

| 档位 | 知识容量 |
|------|----------|
| 基础 | 约 50 万字符 |
| 标准 | 约 200 万字符 |
| 专业 | 约 800 万字符 |
| 旗舰 | 不限额 |

报价含基础喂料额度，超额按档加购（见 `02` / `08`）。

---

## 5. 边界（诚实）

- 喂料扩的是**知识容量**（"知道什么"），不碰**私密层调参**（"怎么配出类人效果"，见 `18`）——后者是我们的获利引擎，不随喂料开放。
- 喂错资料 ≠ 数字人变笨，冲突检测 + 来源标注保证可回退。

---

## 6. 多语言喂料（联动 `25`）

知识库支持多语言资料混库，按客户提问语言自动召回对应语种片段；跨国业务可中英双语并行喂养。

---

## 7. 联动

- `08` 能力菜单：知识容量即其中"记忆/知识"能力项。
- `00` 四件套：喂料落「长期记忆」层。
- `18` 方法保密：喂料不触及私密层。
- `25` 多语言：双语喂料。
- `12` 脱敏规范：喂料资料的脱敏处理。
