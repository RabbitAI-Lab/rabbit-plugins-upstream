# 能力评测与对标分级（用权威基准给数字人打分，按对标等级收费）

> 配套 `SKILL.md` / `08-能力清单与分级报价.md` / `13-数字人升级服务与能力版本管理.md` / `15-活动与生态运营.md` / `07-交付可信与全链路可追溯.md`。
> 本文件解决两件事：① 用**公认权威测试库**对咱们造出的数字人做客观能力评测，不靠自夸；② 把评测分数**映射成对标的「能力等级」（助教 / 讲师 / 副教授 / 教授）**，并据此**分级收费**——客户看得见"我的数字人达到了什么水平"，付费也按水平走。

---

## 0. 诚实口径（必须先说清）

- **不存在单一的"数字人专用测试库"**：学术界目前没有一份名为"数字人能力测试"的权威清单。我们说"用最权威的测试库"是指——**组一套「评测电池（benchmark battery）」，主体取自公认学术基准（公开、可复现、被学界引用），再叠加我们自研的场景化测试**。
- **"对标讲师/教授"是能力类比，不是真学术头衔**：这是给客户理解"水平高低"的沟通类比（如同"段位"），**绝不声称我们颁发国家承认的职称、也不声称数字人具备真人教授的法律资质**。对外话术沿用 `09` 红线：用"我们提出/主张""可验证"，不用"最/第一/官方认证"。
- **评测是"能力评估"不是"资格认证"**：结果只证明该数字人在我们设定的评测电池下的客观表现，用于定价与展示，不作医疗/法律/教育执业背书（见 `11` 免责）。

---

## 1. 评测电池怎么组（权威基准 + 自研场景）

按数字人的四类能力取对应基准，公开可查、可复现：

| 能力维度 | 权威基准（举例·公开学术） | 测什么 |
|----------|--------------------------|--------|
| 知识广度 | MMLU / CMMLU（中文）/ MMLU-Pro / GPQA | 跨学科知识覆盖（对标"懂多少") |
| 推理深度 | GSM8K / MATH / BIG-Bench Hard | 数学/逻辑/多步推理 |
| 工具与主动 | AgentBench / ToolBench / GAIA / WebArena | 调工具、主动完成多步任务 |
| 记忆与长上下文 | LongBench / 自研记忆回溯测试 | 跨会话记得住、不串 |
| 类人与对话 | MT-Bench / 自研"验人感四条"评分 | 像不像人、语气稳不稳 |
| 行业场景 | 客户行业公开题库（如医学/法律/教育公开卷） | 垂直专业度（脱敏、不触密） |

> **自研场景测试（关键差异点）**：学术基准测"模型底子"，我们额外加**场景化测试**——把客户真实业务任务做成题（如"处理一个退货工单并主动提醒超期"），测的是"配好的数字人"而非裸模型。这才是我们交付物的真水平，也是和裸模型拉开差距的证明。
> **评测可复现**：每次评测锁定基准版本 + 题目集 + 评分脚本，结果打 `07` 时间戳 + 哈希，客户可复核、可重跑，杜绝"自说自话"。

---

## 2. 对标等级映射（分数 → 能力等级）

把评测电池的综合分（加权）映射成四档**能力等级**——对内研发分层、对外给客户一个直观"段位"：

| 能力等级（类比） | 综合分区间 | 能力画像（客户能懂的话） | 对应 `08` 档位 |
|------------------|-----------|--------------------------|---------------|
| **助教级 Assistant** | 基准线–59 | 能答常规问题、会检索、管日程提醒；像"靠谱助教" | 基础版 Essential |
| **讲师级 Lecturer** | 60–74 | 知识扎实 + 能讲能教 + 稳定人设；像"能独当一面的讲师" | 标准版 Standard |
| **副教授级 Assoc. Prof.** | 75–89 | 强推理 + 主动 + 垂直深度；像"能带方向的副教授" | 专业版 Pro |
| **教授级 Professor** | 90–100 | 专家级、能自主闭环完成限定任务、可造 AI（含 #7）；像"领域教授" | 旗舰版 Enterprise |

> 映射公开透明，每档给出"达到该级须过哪些基准 + 场景测试"的硬指标，客户自己也能对照。
> **等级只升不降（除非重测下滑）**：每次升版（`13`）重测刷新等级；客户可在看板看见"当前等级 / 可挑战的下一等级"。

---

## 3. 评测协议（怎么测、怎么保证可信）

1. **锁环境**：评测前锁定数字人版本（DH-<客户ID>-vX.Y.Z，见 `13`）、基准集、评分脚本。
2. **双轨跑**：学术基准（自动跑分）+ 场景测试（人工 + 活样板演示核验）。
3. **留证**：评测报告 + 原始分 + 题目集哈希，统一打 `07` 可信时间戳 + SHA-256，纳入可追溯链。
4. **可复核**：客户可申请重跑；成绩变动以"新时间戳版本"为准。
5. **防刷**：场景测试含"不可预测变体题"，防止把答案写死刷分；高阶赛道（教授级）须真人复核 + 活样板演示（呼应 `15` 挑战活动评分）。

## 4. 按对标等级收费（评测即定价锚）

评测不是免费表演，是**定价依据**——等级越高，搭建费与月费越高（与 `08` 分级报价同源，本表是"以评测等级为入口"的另一种切法）：

### 国内（人民币 · 法币）

| 对标等级 | 搭建费 | 月费 | 说明 |
|----------|--------|------|------|
| 助教级 | ¥1.5k–3k | ¥299–599/月 | 入门，四件套 + 看板 |
| 讲师级 | ¥3k–5k | ¥599–999/月 | + 知识库/防护/多语言 |
| 副教授级 | ¥6k–10k | ¥1.2k–2k/月 | + 造AI/可追溯/私有化 |
| 教授级 | ¥15k 起（面议） | ¥3k/月起（面议） | 全量 + 多Agent + SLA |

### 国外（美元 · 法币平台）

| 对标等级 | 搭建费 | 月费 |
|----------|--------|------|
| 助教级 | $250–500 | $45–90/月 |
| 讲师级 | $500–900 | $90–150/月 |
| 副教授级 | $1k–1.8k | $180–350/月 |
| 教授级 | $2.5k 起（面议） | $450/月起（面议） |

**收费接口（三处联动）**
- **接单前**：先免费初测定档 → 报价按档走（阶段 1 诊断即出预估等级）。
- **升版即重测**：每次 MAJOR 升版（`13`）重测，等级上跳则补差价（升版费已含重测）；客户为"冲教授级"付费升版，构成持续收费。
- **活动榜单**：`15` 挑战活动直接用本评测电池打分排名，"教授级榜单"即最强活样板，倒逼升版与转介绍。
- 一律法币，严禁加密（红线见 `11`/`02`）。

## 5. 合规红线（诚实为本）

- **不虚假认证**：不称"国家/官方认证""颁发职称"；标注为"基于公开基准的能力评估（类比等级）"。
- **不替代执业**：教授级数字人不具医师/律师/教师执业资质，关键决策客户须真人复核（见 `11` 免责）。
- **基准版权**：所用学术基准遵循其各自许可（多为研究/开源可用）；我们不修改基准声称"自创权威"。
- **数据合规**：行业场景题用公开/脱敏数据，不触客户密、不泄未成年人信息（见 `12` 脱敏）。
- **可撤回**：客户可要求不出示评测等级/不进榜单；撤回即停展示，已结算不受影响。

---

## 6. 与其他模块联动

- **`08` 能力分级**：评测等级是 `08` 档位的"能力证明版"——勾选能力决定能跑哪些基准，分数决定落在哪档。
- **`13` 升版**：每次升版重测刷新等级，版本链（`07`）串"版本 ↔ 等级 ↔ 分数 ↔ 时间戳"。
- **`15` 活动**：挑战活动评分 = 本评测电池的赛道分数；榜单即信任锚。
- **`07` 可追溯**：评测报告/分数/题目集哈希入链，争议可取证。
- **`14` 授权码**：高阶评测（教授级活样板演示）走活动授权码约束范围。
- **`09` 治理**：评测的"可验"是治理理念四支柱之一的方法论落地。
