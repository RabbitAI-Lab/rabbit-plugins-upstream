# 报价与交付（money 闭环）

> 配合 `SKILL.md` 与 `references/01-诊断清单.md`。定价为 SMB / 个人轻量档，非大企业全案。

## 三档定价（国内 / 国外双市场）

### 国内（人民币 · 法币结算，零摩擦）

| 档位 | 内容 | 报价 | 周期 | 支付 |
|------|------|------|------|------|
| 诊断 | 四件套缺口盘点 + 搭建清单 + 报价估算 | ¥500–2k | 1–3 天 | 微信 / 支付宝 / 对公转账 |
| 搭建 | 角色卡 + 记忆架构 + 工具接入 + 主动规则 + 文档 | ¥2k–8k（复杂可至 ¥1.5w） | 1–2 周 | 同上 |
| 月费 | 记忆养护 + 角色校正 + 新增场景/工具 | ¥1k–3k/月 | 持续 | 同上 |

- 客群：SMB、个人 IP、行业小厂（如某垂直行业小厂搭合规知识库）。
- 引流：首单做轻量版（诊断 + 最小搭建）建立案例；年框可谈包年折扣（月费×10/年）。

### 国外（美元 · 法币平台结算，服务贸易收结汇）

| 档位 | 内容 | 报价 | 周期 | 支付 |
|------|------|------|------|------|
| 诊断 | 同上 | $80–300 | 1–3 天 | Upwork/Fiverr 托管、PayPal、Stripe、Wire |
| 搭建 | 同上 | $300–1.2k（标准 SMB）；复杂 $1.5k–5k | 1–2 周 | 同上 |
| 月费 | 同上 | $150–600/月（标准）；高端 $500–2k | 持续 | 同上 |

- 客群：海外 SMB、独立开发者、创作者、小团队。
- 参考锚点：海外 solo 配置师 2 单搭建 + 4 个续费 ≈ 月入 $9k（年 $108k）；复利在续费不在首单。

> **汇率红利**：国外同档约为国内的 5–7 倍，但获客/信任/合规成本更高，需权衡。单价高≠净收高，落地时以"能稳定续费"为优先。

## 消费级定价（个人 / 家长 / 学生）

> 与企业线三档并列的**第二条产品线**。客单低、决策快、靠内容种草 + 活样板演示转化（见 `04` 阶段 0 个人线）。场景见 `references/05-个人消费级场景.md`。

### 国内（人民币 · 微信 / 支付宝，零摩擦）

| 形态 | 内容 | 轻量体验版 | 标准搭建 | 月费养护 |
|------|------|-----------|----------|----------|
| 数字助理（个人） | 管日程/邮件/资料/学习笔记/提醒，像人助理 | ¥299（角色卡+最小记忆+演示） | ¥800–3k | ¥99–299/月 |
| 数字老师（成人） | 成人自学/技能陪练（外语/考证/编程/副业） | ¥499 | ¥1.5k–5k | ¥199–599/月 |
| 儿童 AI 老师（家长给孩子） | 按课纲/兴趣个性化家教+陪伴，含家长看板/周报 | ¥599 | ¥2k–6k | ¥299–799/月 |

### 国外（美元 · Stripe / PayPal / 平台托管，法币结算）

| 形态 | 标准搭建 | 月费养护 |
|------|----------|----------|
| 数字助理（个人） | $120–450 | $15–45/月 |
| 数字老师（成人） | $250–800 | $30–90/月 |
| 儿童 AI 老师（家长给孩子） | $350–1k | $45–120/月 |

**消费级付款要点**
- 低客单可**全款立减 5%**；或沿用 30% 定金 + 70% 尾款（比企业 50/50 更轻，降低决策门槛）。
- **儿童 AI 老师建议家长全款后交付**，减少尾款纠纷、责任清晰（家长授权 + 适龄护栏见 `05` 与模板 G）。
- 续费同样是复利引擎：个人/家长月费虽低，但量大、转介绍率高（家长群 / 学习群口碑强）。

**消费级获客钩子（内容种草）**
- 小红书 / 抖音 / 视频号 / B站 发"我给孩子搭的 AI 老师""我的 AI 助理帮我管了一周日程"类**演示短视频/图文**，情绪共鸣 + 看得见的类人效果。
- 用作者自身（跑在 WorkBuddy 上的类人数字员工）当活样板，家长/个人可直接体验"配好的样子"。
- 首单做轻量体验版（¥299 起）建立案例，再升标准搭建 + 月费。

## 能力分级报价（勾选式 · 详见 08）

把"像人"的能力列成可勾选菜单（关键度 / 大小 / 是否含造 AI 能力），客户打钩 → 当场算总分 → 自动落档 → 出价，透明不靠拍脑袋。完整能力菜单、权重算法、分级档位与加购价见 `references/08-能力清单与分级报价.md`。**可观测看板（健康 / 进度 / 全局客户可见）作为默认带项与信任锚点**，和 `07` 可追溯互补（看板看"现在"、时间戳/哈希看"历史"）。

## 能力评测对标分级（按分数定价 · 详见 16）

把勾选出的能力档位用**权威基准评测电池**做客观打分，映射成对标的「助教 / 讲师 / 副教授 / 教授」能力等级（类比，非真职称），等级越高搭建费 / 月费越高——评测即定价锚、也是最强信任证明。初测免费定档、升版（`13`）重测刷新、挑战活动（`15`）直接用评测分数排名。完整评测电池、等级映射、收费表与合规红线见 `references/16-能力评测与对标分级.md`。

## 展示用例激励（授权展示换优惠）

- **逻辑**：客户签署《展示授权》（模板 H）同意将其作为方法论展示用例（脱敏后公开案例 / 活样板引用），服务方给予费用减免，形成「客户得优惠、我们得案例」双赢。
- **优惠档（任选其一，不与转介绍叠加，单笔上限 30%）**：
  - 搭建费 **8 折**（标准搭建档适用）；或
  - 月费 **首年 8 折**（持续合作更划算）。
- **边界**：展示内容须脱敏（不暴露客户清单 / 报价 / 合同 / 未成年人真名人脸）；仅授权展示、仅方法论产物。
- **联动可追溯**：展示授权与「客户 ID」（见 `07`）绑定，优惠核销 + 案例归属全链路可查。

## 交付三件套（责任边界）

1. **文档**：角色卡、记忆架构说明、工具清单、使用手册。
2. **代配置**：实际搭好可运行的数字员工（不碰客户核心代码/密钥）。
3. **培训**：教客户/团队自己维护、扩场景。

> 不接"代管客户核心系统/密钥"类无限责任单；用三件套交付，责任清晰。

## 获客钩子（引流）

- 首单可做轻量版（诊断 + 最小搭建）建立案例。

## 红线
- 不碰客户核心代码/密钥；不越权执行。
- 数据不出门优先本地推理；云端 API 任务评估合规。
- 对外署名一律品牌**注册老炮**，与委托人身份隔离。
- **不收加密货币**：2026-02 八部门通知把虚拟货币相关（含 RWA、代币结算）定性违法、整治常态化。国外一律走法币平台结算（Stripe/PayPal/Wire/平台托管），收汇走服务贸易外汇收结汇，**不碰 USDT** 等任何代币。
