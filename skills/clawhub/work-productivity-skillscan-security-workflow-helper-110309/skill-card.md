## Description: <br>
Helps AI-agent users, skill authors, maintainers, and teams create practical SkillScan-style workflows, checklists, analyses, and implementation support for bug fixing, setup hardening, safety, and reliability work. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, skill authors, maintainers, and AI-agent users use this skill to turn SkillScan-style security and productivity needs into concrete plans, checklists, analyses, code changes, or workflow artifacts. It is aimed at local-hardware-friendly reliability, setup hardening, and adjacent skill creation tasks. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad activation keywords and implicit invocation may cause the helper to appear in unrelated security or productivity conversations. <br>
Mitigation: Before installing, narrow or disable implicit invocation so the helper activates only for explicit SkillScan or skill-security workflow requests. <br>
