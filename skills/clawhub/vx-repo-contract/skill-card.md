## Use Case:

Developers and coding agents use this skill to audit and normalize repository structure, configuration, and agent instructions in vx-managed projects.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill directs agents to post GitHub issue comments after code changes, potentially publishing project details without authorization.

Mitigation: Decide whether automatic issue comments are allowed; otherwise require explicit approval and review content before posting publicly.
