## Description:

根据真实故事梗概、小说类型和禁剧透点，撰写情绪人物、冲突类型、主题气质三种定位的中文书籍简介，每版120至220字，并给出18至36字卖点；适用于封底、商品页和读者导读，保留故事事实并避开指定剧透。

This skill is ready for commercial/non-commercial use.

## Use Case:

面向中文小说作者、网店经营者和自媒体创作者，依据他们提供的真实梗概、类型与禁剧透边界，撰写可用于封底、商品页或读者导读的多种简介和一句卖点。

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: 生成的简介可能偏离故事事实，或泄露用户标出的剧透内容。

Mitigation: 将梗概作为事实依据、把禁剧透点视为不可输出信息，并在发布前逐版核对事实与剧透边界。

Risk: 使用 README 中的安装方式可能无法固定所获取的版本或来源。

Mitigation: 安装前审阅并尽可能固定技能来源和版本。
