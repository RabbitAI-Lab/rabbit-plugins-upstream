# 小说简介与封底文案

把用户提供的真实故事信息转成可直接用于书籍封底或商品页的中文简介。交付重点是让目标读者知道“这本书为什么值得读”，而不是复述全部剧情。

## 需要的输入

先确认三项都已给出：

- `故事梗概`：主角、起点、核心冲突、重要关系或选择，以及可公开的结局范围。
- `类型`：如悬疑、言情、历史、科幻、治愈成长。
- `禁剧透点`：不可揭示的身份、反转、结局、死亡、关系或线索；没有则明确写“无”。

任一项缺失时，只指出缺少的字段并请用户补充，不以常见套路补写故事事实。

## 写作方法

1. 从梗概中抽取已知事实：主角、欲望/困境、阻力、代价和可公开的悬念。把建议性措辞与用户给出的事实分开。
2. 将禁剧透点视为不可输出信息：不直说、不用代称暗示，也不通过过于精确的后果泄露。
3. 写三版各 120–220 字的简介，事实一致但读者承诺不同：
   - **情绪/人物版**：突出人物关系、内心代价与共情。
   - **冲突/类型版**：突出类型钩子、目标、阻力和悬念。
   - **主题/气质版**：突出议题、时代或世界观与阅读余味。
4. 每版首句尽快建立人物或处境；避免空泛的“跌宕起伏”“扣人心弦”。不要添加梗概没有的人物、设定、事件或评价事实。
5. 另给一条 18–36 字的卖点：具体、可感知、无剧透，能概括人物、冲突或主题中的一个核心张力。

## 输出格式

```markdown
## 已知信息
- 类型：…
- 剧透边界：…

## 版本一｜情绪与人物
…

## 版本二｜冲突与类型
…

## 版本三｜主题与气质
…

## 一句卖点
…
```

交付前逐项核对：三版没有暴露禁剧透点；没有新增事实；三版的定位和首句不重复；卖点与简介一致。
