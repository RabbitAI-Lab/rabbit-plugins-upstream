## Description:

An automated integration test that verifies skill creation, metadata retrieval, version updates, and deletion through the ClawHub REST API.

This skill is for demonstration purposes and not for production usage.

## Use Case:

Developers and release testers use this temporary test skill to validate the ClawHub skill lifecycle, including publishing, inspecting, updating, and deleting a test entry.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The described workflow publishes, updates, and deletes a ClawHub entry.

Mitigation: Authorize changes only to the named temporary test entry and verify cleanup afterward.
