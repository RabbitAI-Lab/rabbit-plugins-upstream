# Gmail triggers via Agiexa (2)

Preview only - events that will be able to start an agent run after Agiexa launches (November 2026).

| Trigger | When it fires |
| --- | --- |
| `GMAIL_EMAIL_SENT_TRIGGER` | Triggers when a Gmail message is sent by the authenticated user |
| `GMAIL_NEW_GMAIL_MESSAGE` | Triggers when a new message is received in Gmail |
