## Description:

Gmail for Shopify via Agiexa (preview): the 61 tools and 2 triggers your OpenClaw agent gets when you connect Gmail to your Shopify store through Agiexa, launching November 2026. Explains use cases and joins the launch waitlist only with the user's permission.

This skill is ready for commercial/non-commercial use.

## Use Case:

Shopify merchants and OpenClaw users can use this preview to learn about planned Gmail workflows for customer support, supplier communications, and store operations, and optionally join Agiexa's launch waitlist. Gmail and Shopify actions are not available through this skill today.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Joining the waitlist sends the confirmed email, role, and any optional link or message to Agiexa.

Mitigation: Review the exact details and consent statement before submitting, and submit only after explicit confirmation.

Risk: The preview describes future Gmail and Shopify actions that are unavailable today.

Mitigation: Treat the listed tools and triggers as unavailable until launch; do not claim that an action was performed.

Risk: Some listed future Gmail tools can send messages or permanently delete email.

Mitigation: When those tools become available, verify the target and review the proposed action with the user before sending or deleting.
