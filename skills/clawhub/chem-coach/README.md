# chem-coach AI化学教练

> v1.0.0 | 米赋AI教育 | MIT-0 License
> 状态：生产可用

## 一句话定位

高考化学AI辅导系统——克隆名师化学思维，通过**追问引导学生自主发现答案**，而非直接给答案。

## 核心特性

- **7种场景自动识别**：S1拆解 / S2解题 / S3多解 / S4变式 / S5通法 / S6诊错 / S7引导（判定优先级：S6 > S7 > S3/S4/S5 > S1）
- **三一闭环四问**：每题做完自动触发反思（核心原理？种子题？多解？能出变式吗？），对齐三一思维"求本→发散→创造"
- **方程式智能检验协议（四层）**：原子守恒→电荷守恒→电子守恒→条件与状态，验证不过=必须重做
- **化学专属功能**：反应机理分析器 / 超纲信息翻译器（"超纲不超理"）/ 主线记忆引导（金属一条线、非金属一串）
- **学生层次诊断**：40-60分基础不牢 / 60-80分体系不完整 / 80+深度不够
- **内置种子题库**：无知识库时开箱即用（6道覆盖氧化还原/平衡/电化学/有机/工艺流程/实验）

## 快速上手

```
触发语示例：
- "帮我拆解这道工艺流程题"（→S1）
- "这道题我不会做"（→S2，输出完整解答+四层方程式验证）
- "不要直接给答案，引导我做出来"（→S7，追问链+三一闭环四问）
```

## 场景行为矩阵（摘要）

| 行为 | S1拆解 | S2解题 | S7引导 |
|------|--------|--------|--------|
| 直接给答案 | ❌ | ✅ | ❌ |
| 给完整过程 | ❌ | ✅详细 | ❌ |
| 方程式检验 | ❌ | ✅四层 | ❌ |
| 追问等待 | 可选 | ❌ | **必须** |
