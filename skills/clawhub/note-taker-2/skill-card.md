## Known Risks and Mitigations:

Risk: The security evidence says the skill is not clearly scoped and includes task-command, export, and persistent logging instructions beyond its stated note-formatting purpose.

Mitigation: Review command use, file locations, exports, and logging before installation; restrict execution and file permissions until the behavior is clarified.

Risk: Sensitive notes could be exposed through generated outputs, exports, or logs.

Mitigation: Avoid using sensitive notes until outputs and logging are reviewed, and inspect exported files or logs before sharing them.
