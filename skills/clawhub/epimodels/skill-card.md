Developers and epidemiological modelers use this skill to build, simulate, fit, and analyze disease models with the epimodels Python library, including intervention scenarios and uncertainty analysis.

### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: Python dependencies may affect the surrounding environment.

Mitigation: Install and run dependencies in an isolated Python environment.

Risk: Large or parallel simulations may exceed available compute resources.

Mitigation: Choose simulation counts and sizes appropriate for the machine.

Risk: Saved model traces may include sensitive data.

Mitigation: Review trace contents before saving or sharing model files.
