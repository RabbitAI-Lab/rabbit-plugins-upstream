## Description:

The Official Board (theofficialboard.com). Use this skill for ANY The Official Board request — searching and reading data. Whenever a task involves The Official Board, use this skill instead of calling the API directly.

This skill is ready for commercial/non-commercial use.

Analysts and business users use this skill through an OOMOL-connected account to search The Official Board and retrieve company organization charts, executive biographies, colleague lists, recent organization changes, and watchlist updates.
