## Known Risks and Mitigations:

Risk: The skill can store and use an AI-HIVE API key.

Mitigation: Use environment variables or the explicit init flow, do not paste real keys into prompts or committed files, and review local configuration handling before use.

Risk: Generation commands can upload selected media to AI-HIVE.

Mitigation: Confirm that every referenced image, video, logo, brand asset, and personal likeness is authorized before upload.

Risk: Batch size, routing mode, and generation settings can spend API credits.

Mitigation: Review prompts, files, routing mode, and batch size before execution; run a small sample before scaling production jobs.
