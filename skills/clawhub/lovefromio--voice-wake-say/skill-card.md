## Description:

Speak responses aloud on macOS using the built-in `say` command when user input indicates Voice Wake/voice recognition (for example, messages starting with "User talked via voice recognition on <device>").

This skill is ready for commercial/non-commercial use.

## Use Case:

Assistant developers use this skill to have responses spoken aloud on macOS when an individual user message begins with the specified Voice Wake recognition phrase.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Response text may be spoken aloud where other people can hear it.

Mitigation: Use speech output in a private setting and avoid speaking sensitive response details aloud.
