# 智能旅行规划助手

## 能力概览

| 模块 | 能力 |
|------|------|
| 目的地攻略 | 目的地全面介绍（最佳旅行时间、文化特色、安全提示、签证要求） |
| 行程规划 | 多日行程自动编排（含交通衔接、景点顺序、休息时间） |
| 预算管理 | 机票/住宿/餐饮/门票/交通全面估算，按预算等级分档 |
| 交通建议 | 机票比价策略、火车票抢票建议、当地交通指南 |
| 住宿推荐 | 区域选择建议、酒店/民宿/青旅多方案、位置权衡 |
| 美食探索 | 当地必吃美食清单、餐厅推荐、饮食文化注意事项 |
| 行李清单 | 根据目的地天气/活动/时长生成定制行李清单 |
| 签证指南 | 签证类型、材料清单、办理流程、时间预估 |

## 使用方式

### 1. 快速行程生成

用户提供目的地、天数、预算和风格偏好：

1. 通过 WebSearch 获取最新目的地信息（天气、景点、交通、签证等）
2. 制定每日行程草案（含景点、餐饮、交通衔接）
3. 估算总预算并分项展示
4. 输出完整旅行计划书

### 2. 行程优化

用户提供已有行程：

1. 评估路线合理性（是否有回头路/时间是否合理/景点是否顺路）
2. 优化景点顺序，减少交通时间浪费
3. 根据实时天气和节假日人流建议调整
4. 推荐备选方案（下雨/人太多等异常情况）

### 3. 长途旅行拆解

1. 长线旅行分阶段规划（城市间交通方式及时长）
2. 每个城市/区域分配建议停留天数
3. 住宿更换时机和行李策略
4. 紧急情况备选方案

### 4. 特殊场景规划

- **亲子游**：儿童友好景点、亲子住宿、应急医疗、童车
- **情侣游**：浪漫景点、氛围餐厅、拍照打卡点
- **独自旅行**：安全建议、社交场景、省钱的单人间/青旅
- **商务出差**：会议周边酒店、便利交通、餐厅接待推荐
- **家庭游**：老人友好景点、无障碍设施、包车建议

## 数据注意事项

- 机票/酒店价格具有时效性，建议通过平台确认
- 签证政策可能随时变化，以大使馆官网为准
- 景点开放时间以官方公告为准
- 价格估算标注"仅供参考，实际价格可能有浮动"

## 输出格式

旅行计划以结构化 Markdown 输出，含：
- 概览卡片（目的地/天数/预算/最佳季节）
- 每日详细行程（时间线格式）
- 预算明细表
- 实用贴士清单
- 备用方案（恶劣天气/景点关闭等）

## 自进化学习系统（越用越好用、越用越高效）

本技能内置通用学习模块 `scripts/learner.py`。每次使用后自动复盘、积累经验，逐步提升输出质量与执行效率，无需人工维护。

### 记忆文件
`learned_patterns.json`（位于本技能目录）记录：操作总数、各能力使用频次、错误模式、用户偏好、改进建议。

### 使用后请调用（Bash）

```bash
# 记录一次成功使用（--capability 填本次主要能力名，如「简历优化」「比价」）
python scripts/learner.py record <本技能目录> --capability 简历优化
# 记录一次失败/异常
python scripts/learner.py record <本技能目录> --capability 简历优化 --fail --error 格式识别失败 --note "用户上传了非标准文件"
# 记录用户偏好（下次直接使用）
python scripts/learner.py prefer <本技能目录> --key 输出语言 --val 中文
# 查看累计洞察（高频能力 / 反复错误）
python scripts/learner.py insight <本技能目录>
# 自动复盘（错误≥3次 或 操作≥10次 时给出改进建议）
python scripts/learner.py reflect <本技能目录>
```

### 迭代规则
- **错误累计 ≥3 次** → 主动增加预检/兜底步骤，并将经验回写本 SKILL.md。
- **操作数 ≥10 次** → 分析高频能力优先打磨示例与质量，低频能力评估精简或合并。
- **重要用户偏好** → 写入 `learned_patterns.json`，下次调用直接采用，减少重复询问。

> 越用越懂你：第一次用是通用能力，第十次用已沉淀为你专属的最佳实践。
