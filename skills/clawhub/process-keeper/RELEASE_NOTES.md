# Release Notes

## Public release

This repository is the public version of `process-keeper`.

### What changed from the local version

- private project names and paths were removed
- examples were rewritten to be generic
- the public README was added
- the MIT license was added
- the wording was tightened so the skill is easier to reuse in other repositories

### What stayed the same

- the core process-log workflow
- the compact entry template
- the trigger style
- the focus on decisions, fixes, and meaningful turning points
