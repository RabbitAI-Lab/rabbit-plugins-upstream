## 一页速背清单（名词解释为主）

```markdown
# 《课程名》一页速背（开卷/闭卷）

## 名词解释
- **术语A**＝关键词1；关键词2；（区别：…）
- **术语B**＝…

## 简答题眼 → 点
- 题眼1 → ① ② ③
- 题眼2 → ① ② ③ ④

## 论述四步（统一套）
界定 → 原因/机制 → 表现/案例词 → 意义或对策 → 收束
```

闭卷：定义控制在一行内。开卷：术语后可加「见第X章/第Y页」。

## 学科答题骨架（按课程选用）

### 马原 / 思政类论述

1. 原理界定（哪一对范畴/规律）  
2. 原理内容（要点编号）  
3. 方法论要求  
4. 结合材料/实际（若题有材料：先引材料关键词）  
5. 总结（反对错误倾向一句）

### 经管类（如微观经济学）简答/论述

1. 概念/假设  
2. 机制或图形逻辑（轴、曲线、均衡点关键词）  
3. 结论 / 比较静态  
4. 政策含义或局限（论述常要）

### 工科 / 软件工程名解+简答

1. 定义（是什么）  
2. 目的/解决什么问题  
3. 步骤或组成（有序编号）  
4. 优点/局限或与易混术语对比  

名词解释优先「定义 + 目的 + 组成」三件套，控制在 2–4 句。

## 压缩对照（自我检查）

| 原文常见废话 | 提纲应保留 |
|--------------|------------|
| 长案例故事 | 案例名 + 对应考点词 |
| 「本章介绍了…」 | 删 |
| 同一观点换说法三遍 | 留一句得分表述 |
| 大段背景 | 1 个背景词或删 |
| 公式推导全过程 | 结论式 + 符号含义（除非必考推导） |
