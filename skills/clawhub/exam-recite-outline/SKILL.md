# 期末背诵提纲

将课本章节、课件文本压缩为**轻量化背诵提纲**：剔除冗余，只留得分关键词；划分一/二级考点；按名词解释、简答、论述分类，并给出标准答题模板。

## 何时启用

- 用户上传 / 粘贴课件、教材章节、复习讲义
- 用户要求：期末背诵、精简提纲、考点分级、简答/论述模板、名词解释速背、开卷/闭卷清单
- 匹配下方提示词模板任一意图

## 提示词模板（示例）

**示例 1：** 根据这份微观经济学课件，压缩成期末背诵提纲，区分简答、论述必背考点。

**示例 2：** 马原整本书知识点整理精简背诵稿，按考试题型拆分答题模板。

**示例 3：** 软件工程课件提取核心名词解释，做成一页速背清单，适配开卷 / 闭卷考试。

## 工作流

### 1. 确认考试形态与范围

信息不足时一次问清（用户要直接出结果则按默认）：

| 项 | 默认 |
|----|------|
| 考试形式 | 闭卷（开卷则侧重定位索引，少背长段） |
| 题型 | 名词解释 + 简答 + 论述 |
| 范围 | 用户所给全部文本 |
| 篇幅 | 闭卷：能背完的压缩版；开卷：一页速查 + 定位关键词 |

判定输出模式：

| 模式 | 触发 | 侧重 |
|------|------|------|
| 完整背诵提纲 | 默认 / 示例 1、2 | 一二级考点 + 三类题型 + 答题模板 |
| 一页速背清单 | 示例 3 / 「一页」「速背」 | 名词解释为主，极短条 |
| 开卷速查版 | 明确开卷 | 目录式关键词 + 页码/章节锚点，少默写长文 |
| 闭卷默写版 | 明确闭卷 | 得分关键词、可背短句、模板填空骨架 |

### 2. 压缩原则（核心）

- **剔冗余**：例子铺陈、过渡句、重复表述、纯装饰性标题说明一律删
- **留得分点**：定义句、对比项、步骤、因果、条件、结论；用短词/短句
- **分级**：
  - **一级考点**：章/节级必考块（常考、老师强调、反复出现）
  - **二级考点**：一级下的得分点/子概念（简答展开用）
- **标必背**：简答、论述中标 `★必背`；了解即可标 `△`（可略背）
- **不编造**：课件未出现的「必考」不擅自添加；可标「高频候选（据材料归纳）」
- **可溯源**：尽量标注章/节/课件页；无则写「据所给课件」

### 3. 题型拆分规则

| 题型 | 从材料如何切 | 背诵形态 |
|------|--------------|----------|
| 名词解释 | 术语 + 一句话定义（+ 1 个区分点） | 30–60 字可默写 |
| 简答 | 3–6 个得分点，可编号 | 「总起句 + 点1…点N」 |
| 论述 | 框架题：是什么→为什么→怎么看/怎么办 | 答题模板 + 每层关键词 |

同一知识点可同时进两类（如先名词解释，简答再展开要点）。

### 4. 输出模板

详细空表见 [references/templates.md](references/templates.md)。默认结构：

```markdown

> 范围：… | 形式：开卷/闭卷 | 来源：课件/教材摘录

## 〇、怎么用这份提纲
- 闭卷：先背 ★必背 名词 + 简答得分点，再套论述模板
- 开卷：按「速查索引」定位，用模板现场填关键词

## 一、考点地图（一级 → 二级）
1. 一级考点 A
   - 二级：…
   - 二级：…
2. 一级考点 B
   - …

（可选 mermaid mindmap）

## 二、名词解释（速背）
| ★/△ | 术语 | 背诵定义（得分关键词加粗或「」标出） | 出处 |
|------|------|--------------------------------------|------|
| ★ | | | |

## 三、简答题（必背）
### ★ 题干候选：……
- 答题骨架：1. … 2. … 3. …
- 得分关键词：…
- 易漏点：…

## 四、论述题（必背 + 模板）
### ★ 题干候选：……
**标准答题模板：**
1. 破题/界定：（关键词）
2. 分论点一：…（论据关键词）
3. 分论点二：…
4. 分论点三 / 意义 / 对策：…
5. 收束：（一句总结）

- 论述：题眼 → 模板四步关键词

|--------|---------|------|
```

### 5. 标准答题模板（可复用套话）

按学科微调；材料有学科特色时优先用材料表述。

**名词解释：**  
`[术语]是指……（本质）。其特点/构成包括……。与〔易混概念〕的区别在于……。`

**简答：**  
`首先……；其次……；再次……；最后……。`（每点一句，点首用材料原词）

**论述（通用五段）：**  
1. 界定概念 / 亮明总论点  
2. 理论依据 / 原因分析（2–3 点）  
3. 表现 / 机制 / 案例关键词  
4. 意义 / 问题 / 对策（按设问选）  
5. 总结升华（回扣题干）

马原、经管、工科等专用骨架见 [references/templates.md](references/templates.md)。

### 6. 交付检查

- [ ] 已删废话，条目短、可背
- [ ] 一级 / 二级考点层次清楚
- [ ] 名词解释、简答、论述已分开（用户只要一类则只出一类）
- [ ] ★必背已标注；论述有可套用的答题模板
- [ ] 开卷有索引或一页清单；闭卷有关键词串
- [ ] 未把未出现内容写成「必考原题」

## 边界

- 不保证押中原题；「题干候选」是据材料归纳的备考问法
- 不替代学校指定复习范围或老师划的重点（若用户提供划重点，优先服从）
- 仅基于用户提供的课件/教材文字整理，不主动拉取整书盗版
