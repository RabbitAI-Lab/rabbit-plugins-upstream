# exam-recite-outline · 期末背诵提纲生成

输入课本章节、课件文本，剔除冗余内容，压缩精简背诵版提纲，划分一级二级考点，标注必背简答、论述题答题模板。

## 使用效果

上传课件 / 教材文字，输出轻量化背诵提纲：剔除废话只保留得分关键词，分名词解释、简答、论述三类整理，配套标准答题模板，大幅缩减背诵内容。

## 提示词示例

1. 根据这份微观经济学课件，压缩成期末背诵提纲，区分简答、论述必背考点。
2. 马原整本书知识点整理精简背诵稿，按考试题型拆分答题模板。
3. 软件工程课件提取核心名词解释，做成一页速背清单，适配开卷 / 闭卷考试。
