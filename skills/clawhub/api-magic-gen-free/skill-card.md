## Description: <br>
Api Magic Gen Free guides Java backend developers through using magic-api to create live HTTP endpoints from Web UI-authored scripts without writing traditional Controller, Service, DAO, Mapper, XML, or VO code. <br>

This skill is ready for commercial/non-commercial use. <br>

Developers and engineering teams use this skill to prototype, configure, and document magic-api based Java backend endpoints for internal tools, dashboards, CRUD services, and API integration work. <br>

## Known Risks and Mitigations: <br>
Risk: The skill helps create live database-backed endpoints that can take effect immediately after scripts are saved. <br>
Mitigation: Use staging first, review scripts before saving, and apply normal production change controls. <br>
Risk: An exposed magic-api Web UI could allow unauthorized endpoint or logic changes. <br>
Mitigation: Disable the Web UI in production or restrict access with strong authentication, network controls, and IP allowlists. <br>
Risk: Endpoint scripts may access sensitive databases or introduce unsafe query and authentication patterns. <br>
Mitigation: Restrict database permissions, use parameterized SQL, hash passwords, and avoid exposing arbitrary Java classes or Spring beans without review. <br>
