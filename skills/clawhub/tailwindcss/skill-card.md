## Description: <br>
Helps agents write, configure, migrate, and debug Tailwind CSS utility classes, theme settings, framework integrations, dark mode, variants, plugins, and build behavior. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[ivangdavila](https://clawhub.ai/user/ivangdavila) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill when writing, reviewing, or troubleshooting Tailwind CSS in web projects, including setup, migrations, framework wiring, design-system tokens, responsive behavior, accessibility checks, and production build issues. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may retain Tailwind-related preferences and project context in local files under ~/Clawic/data/tailwindcss/. <br>
Mitigation: Review or delete those local files if retaining that context is not desired. <br>
Risk: Generated Tailwind markup or configuration can produce missing styles, cascade conflicts, accessibility regressions, or build changes if applied without review. <br>
Mitigation: Review generated code and configuration, verify the built CSS artifact, and test focus states, responsive behavior, dark mode, and production builds before deployment. <br>
