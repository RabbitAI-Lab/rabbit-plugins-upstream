## Description:

Guides agents through the course-paper workflow, from extracting assignment requirements and checking sources to producing and reviewing a formatted Word document.

This skill is ready for commercial/non-commercial use.

## Publisher:

[liujw111](https://clawhub.ai/user/liujw111)

### License/Terms of Use:

MIT-0

## Use Case:

Students and academic writers use the skill to turn course assignment requirements into a sourced, formatted Word paper, with citation checks and a final review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Citation checks may miss errors, as the security guidance notes a possible citation-checking limitation.

Mitigation: Verify each citation against the original publication or an authoritative source before submission; treat automated checks as aids rather than proof.

Risk: The security review flags package-audit and credential-scanning behavior, an undeclared tool scope, and a partial review with three unresolved references.

Mitigation: Review the tool scope and relevant source files before installation or execution, resolve the missing references, and repeat the review when needed.
