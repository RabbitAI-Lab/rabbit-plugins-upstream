# 文献检索与筛选

课程论文不需要做系统综述，但至少要做到：**找到对的那十几篇，并且知道它们各自是什么货色。**

---

## 一、先定检索式，再开数据库

检索式的三段结构：

```
(主题词 A OR 同义词 A') AND (主题词 B OR 同义词 B') AND (限定条件)
```

例：
```
("工程伦理" OR "工程师责任") AND ("汽车" OR "整车" OR "车企") AND 近五年
```

三条纪律：

1. **同义词要穷举**。中文尤其重要："降本""削减成本""成本优化"是一个意思，只搜一个会漏一半。
2. **加限定词收窄**：年份、文献类型、学科分类。
3. **先宽后窄**。先用宽检索看总量，再逐条加限定，而不是一上来就精确到没结果。

---

## 二、数据库分工

| 库 | 适合找 | 注意 |
|---|---|---|
| 中国知网（CNKI） | 中文期刊、学位论文、会议 | 核心库看 CSSCI/北大核心标识 |
| 万方 | 中文期刊、学位论文、标准 | 与知网有重叠，用来补漏 |
| 维普 | 中文期刊 | 老文献收录较全 |
| Web of Science | 英文 SCI/SSCI | 看被引次数判断影响力 |
| Scopus | 英文综合 | 覆盖比 WoS 宽 |
| Google Scholar | 跨库检索、找引用链 | 质量参差，需自行判断 |
| 国家标准全文公开系统 | 强制/推荐性国标原文 | 核标准号、发布日、实施日 |
| 中国政府网 / 部委官网 | 政策原文 | 核发文机关、文号、日期 |

## 三、从一篇好文献往外扩

找到一篇高度相关的文章后，用四种方式扩：

1. **看它的参考文献**——往上追源头。
2. **看谁引了它**（知网的"被引文献"、Scholar 的 "Cited by"）——往下追进展。
3. **看它的同类**（知网"相似文献"）——横向补齐。
4. **看它的作者还有什么**——同一作者往往在同一问题上有多篇。

这比反复换关键词高效得多。

---

## 四、筛选：三分钟判断一篇值不值得读

按顺序看，任意一关不过就放弃：

| 关卡 | 看什么 | 淘汰信号 |
|---|---|---|
| 1. 出处 | 刊名、是否核心、出版社 | 明显的水刊、论文集、无主办单位 |
| 2. 摘要 | 有没有具体结论 | 通篇"具有重要意义" |
| 3. 方法 | 数据从哪来、怎么分析 | 没有数据来源，全靠"笔者认为" |
| 4. 引文 | 参考文献质量 | 全是网页、无近五年文献 |
| 5. 结论 | 是否超出证据 | 小样本得出普遍规律 |

**核心期刊不等于相关**，普刊也可能有一手材料。判断标准是**它能不能给你提供可引用的东西**：一个数据、一条规范、一个已被承认的判断。

## 五、读文献做笔记：只记三样

不要抄摘要。每读一篇，只记：

```
【能引用的那句话】原文，≤40 字，标注页码
【它解决/回答了什么】一句话
【它没解决什么】一句话 ← 这一条决定你的论文往哪写
```

第三样最重要。**你的论文位置，就藏在别人没解决的地方。**

## 六、文献管理工具

| 工具 | 特点 | 适合 |
|---|---|---|
| Zotero | 免费开源，浏览器插件抓取，CSL 样式丰富 | 首选，中文支持好 |
| EndNote | 功能全，Word 插件成熟 | 学校有授权则用 |
| NoteExpress | 中文文献支持好，内置知网格式 | 纯中文写作 |
| JabRef | 纯 BibTeX | LaTeX 用户 |

**课程论文用不用工具都行**，但如果你要引 20 篇以上，手工维护文献表一定会出错。至少用一个表格记录：作者、篇名、刊名、年、期、页码、链接、是否已核。

## 八、三个常见坑

1. **只搜中文**。很多议题的原始讨论在英文文献里，中文综述是二手的。
2. **只看近五年**。经典定义、原始理论往往在老旧文献里，近五年文献只覆盖应用。
3. **把综述当原始研究引用**。综述说的是"某研究发现了 X"，你要引的是那个研究，不是综述。
