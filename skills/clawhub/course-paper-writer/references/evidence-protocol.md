# 取证协议

课程论文的分数有一半压在"出处"上。这份文件规定怎么找、怎么记、怎么止损。

---

## 一、源的分级

| 级别 | 类型 | 用途 | 例子 |
|---|---|---|---|
| A | 原始规范、标准、法律、司法解释 | 支撑"应该怎样" | 国家标准全文公开系统、法规数据库、标准原文 |
| A | 官方调查与监管公告 | 支撑"发生了什么" | NTSB 事故报告（编号形如 HAR-19/03）、NHTSA 缺陷调查与召回文件、市场监管总局召回公告、应急管理部事故调查报告、法院判决书 |
| A | 权威教材、理论原著 | 支撑分析框架 | 课程指定教材；理论家原著或其可靠中译本 |
| B | 同行评议文献 | 支撑学术判断 | 知网/万方/CSSCI/SCI，近五年为主 |
| C | 权威媒体的事实报道 | 只佐证"发生过"，不支撑"应该怎样" | — |

**纪律：结论靠 A 和 B，事实可以靠 C。**

---

## 二、检索动作

1. **搜原话不搜主题词**。带引号搜半句原文，比对逐字一致。
2. **拿到页面立刻核对**，注意版本差异（标准有发布日和实施日，别混）。
3. 政策核到**发文机关 + 文号 + 实施日期**三件套。
4. 事故核到**官方调查报告编号**，不用媒体转述的数字。
5. 期刊文献核到**作者 + 篇名 + 刊名 + 年 + 卷(期) + 页码**。页码查不到就不写页码，**不要凑**。

---

## 三、记录表（边搜边填）

```
| 我要说的那句话 | 依据（原文或数据） | 出处（作者、篇名、刊名/出版社、年、卷期页） | 链接 |
```

填满这张表，等于论文已经写完一半——因为每句话都已经有主了。

**状态标注**：
- `已核`：逐字比对过原文
- `已核·二手`：只核到转述，原文未取
- `待定`：没找到，或找到但未比对

交付时把所有 `待定` 和 `二手` 集中列成"待核对清单"给用户。**这是本 Skill 的强制动作。**

---

## 四、数量纪律

- 参考文献条数 = 要求下限 + 20%（要求 10 篇就写 12 篇）。
- "近 N 年占比"要留余量，不要卡在 50% 写 50%——统计方式不同就会掉到线下。
- 单条直接引文 ≤ 40 字；超过 50 字的整段引文全文只留一处。
- 案例至少 2 个，且必须能说出**技术细节**：型号、参数、失效模式、时间线。写"某企业某车型出事故"零分。

---

## 五、常见陷阱

1. **政府公告、网页新闻不能当"学术文献"填进参考文献表。** 如果老师要求文献是发表的论文，就把公告类来源降级为正文括注（如"（NHTSA 召回报告 16V-344）"），文献表只留期刊、学位论文、专著。
2. **名人名言多为伪托**（"世界只需五台计算机""比空气重的机器飞不起来"），一律不用。
3. **争议未决的个案不做正面论据**——用来证明规范判断会被反驳。
4. **标准号、文号、实施日期三者都要核**，实施日期经常晚于发布日期，写错就露馅。
5. **PDF 是扫描件时**没有文本层，提取器只输出空。请用户贴文字，不要猜。

## 六、文献类型标识（GB/T 7714）

| 标识 | 类型 |
|---|---|
| `[M]` | 专著 |
| `[J]` | 期刊 |
| `[D]` | 学位论文 |
| `[S]` | 标准 |
| `[N]` | 报纸 |
| `[R]` | 报告 |
| `[Z]` | 其它 |
| `[EB/OL]` | 电子资源 |

顺序编码制：按正文**首次出现顺序**编号，重复引用用同一序号。

标准格式：`GB 44495—2024 汽车整车信息安全技术要求[S]. 北京: 中国标准出版社, 2024.`

期刊格式：`作者. 篇名[J]. 刊名, 年(期).`（页码不确定可省）

电子资源：`发布者. 题名[EB/OL]. (发布日期)[引用日期]. URL.`
