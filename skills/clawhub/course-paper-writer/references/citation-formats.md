# 引用格式速查

课程论文最常见的要求是 GB/T 7714；文科可能要求 APA 或 MLA，工科英文可能要求 IEEE。这里只放**够用**的部分——常见类型的完整格式和最常见的错误。

**总原则：页码拿不准就省，宁可少一项，不要错一项。**

---

## 一、GB/T 7714（中国国家标准，顺序编码制）

### 1.1 文献类型标识

| 标识 | 类型 | 标识 | 类型 |
|---|---|---|---|
| `[M]` | 专著 | `[J]` | 期刊 |
| `[C]` | 论文集 | `[N]` | 报纸 |
| `[D]` | 学位论文 | `[R]` | 报告 |
| `[S]` | 标准 | `[P]` | 专利 |
| `[Z]` | 其它 | `[EB/OL]` | 电子资源 |

### 1.2 各类格式

**专著**
```
作者. 书名[M]. 版本(第1版不写). 出版地: 出版社, 年份: 页码.
李正风, 丛杭青, 王前. 工程伦理[M]. 北京: 清华大学出版社, 2016: 44.
```

**译著**
```
原作者. 书名[M]. 译者, 译. 出版地: 出版社, 年份: 页码.
康德. 道德形而上学奠基[M]. 杨云飞, 译. 北京: 人民出版社, 2013: 12.
```

**期刊**
```
作者. 篇名[J]. 刊名, 年份, 卷(期): 起-止页.
李柏姝, 吴珊珊, 付立冬, 等. 基于工程伦理视角的汽车产品创新方法[J]. 内燃机与配件, 2023(6): 45-48.
```
> 无卷号时写 `2023(6)`；页码不确定可省，但不要编。

**学位论文**
```
作者. 篇名[D]. 城市: 学校, 年份.
洪乐平. 缺陷汽车产品召回制度完善研究[D]. 昆明: 昆明理工大学, 2024.
```

**标准**
```
标准号 标准名称[S]. 出版地: 出版者, 年份.
GB 7258—2017 机动车运行安全技术条件[S]. 北京: 中国标准出版社, 2017.
```

**电子资源**
```
发布者. 题名[EB/OL]. (发布日期)[引用日期]. URL.
工业和信息化部. 关于……的通知[EB/OL]. (2025-02-28)[2026-11-10]. https://...
```

**报纸**
```
作者. 篇名[N]. 报纸名, 出版日期(版次).
```

### 1.3 作者写法

- 3 人以内全列，用逗号分隔
- 超过 3 人，列前 3 人后加"，等"（英文用 "et al."）
- 西文作者姓前名后，名缩写不加点：`SMITH J A`

### 1.4 顺序编码制规则

1. 按正文**首次出现顺序**编号，从 1 开始。
2. 同一文献多次引用，用同一序号。
3. 正文用**上标方括号**：`……表明了这一趋势[3]`。
4. 序号位置在标点**之前**（中文习惯）或之后，全文统一即可。
5. 文献表按序号排列，不按作者字母序。

## 二、APA 7th（社科常用）

**正文内**：`(作者, 年份)` 或 `作者 (年份)`

**期刊**
```
Author, A. A., & Author, B. B. (Year). Title of article. Journal Name, Volume(Issue), pages. https://doi.org/xxxx
```

**专著**
```
Author, A. A. (Year). Title of work (2nd ed.). Publisher.
```

**网页**
```
Author, A. A. (Year, Month Day). Title of page. Site Name. URL
```

要点：文献表按作者姓氏字母序；标题只有首词和专有名词大写；DOI 写成完整链接。

---

## 三、IEEE（工科英文常用）

**正文内**：方括号数字 `[1]`，出现在标点之前。

**期刊**
```
[1] A. B. Author, "Title of paper," Journal Name, vol. 1, no. 2, pp. 1-10, 2024.
```

**专著**
```
[2] A. B. Author, Title of Book, 3rd ed. City, Country: Publisher, 2020, pp. 100-120.
```

**会议**
```
[3] A. B. Author, "Title," in Proc. Conf. Name, City, 2023, pp. 1-6.
```

要点：作者名首字母在前；篇名用引号；刊名斜体；按引用顺序编号。

---

## 四、MLA 9th（人文学科）

**正文内**：`(作者 页码)`

**文献表**
```
Author, First Last. Title of Book. Publisher, Year.
Author, First Last. "Title of Article." Journal Name, vol. 1, no. 2, Year, pp. 1-10.
```

要点：按作者姓氏字母序；书名斜体；篇名引号；不用 DOI，用 "Accessed" 日期给网页。

## 五、最常见的十个错误

| # | 错误 | 正确做法 |
|---|---|---|
| 1 | 政府公告、网页新闻混进文献表 | 若要求"发表的文献"，降级为正文括注 |
| 2 | 页码靠猜或凑 | 查不到就省，不要编 |
| 3 | 序号不连续（跳到 3、5、6） | 按首现顺序重排 |
| 4 | 正文有 [7]，文献表只有 6 条 | 加引文后必须整篇重排 |
| 5 | 同一文献出现两个序号 | 复用同一序号 |
| 6 | 标准不写标准号只写名称 | `GB 7258—2017` 必须完整 |
| 7 | 译著漏译者 | 必须写"某某, 译" |
| 8 | 期刊漏卷期，只写年份 | 能查到就写全 |
| 9 | 电子资源漏引用日期 | `[引用日期]` 是必需项 |
| 10 | 中英文标点混用 | 中文文献用中文标点，英文用英文标点 |

## 六、"近 N 年占比"怎么算

**必须先剔除 URL 里的访问日期**，否则会被当成出版年：

```python
import re

def pub_year(ref):
    s = re.sub(r"\[\d{4}-\d{2}-\d{2}\]", "", ref)   # 删掉 [2026-11-10]
    ys = re.findall(r"(?<!\d)((?:19|20)\d{2})(?!\d)", s)
    return int(ys[-1]) if ys else 0
```

统计完把**每一条的年份打出来**扫一眼。卡在 50% 线上最危险——换一种数法就掉下去了，建议做到 60% 以上。

## 七、快速自检

```
□ 文献条数 ≥ 要求下限（建议 +20%）
□ 近 N 年占比 ≥ 要求（建议 ≥60%）
□ 序号 1..N 连续
□ 正文引用数 = 文献表条数
□ 每条都有作者、篇名、出处、年份
□ 类型标识 [M]/[J]/[S]/[D] 正确
□ 译著有译者，标准有标准号
□ 页码无编造
```
