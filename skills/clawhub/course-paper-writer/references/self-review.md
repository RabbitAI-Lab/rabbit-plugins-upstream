# 交稿前自查：换五个人的眼睛看一遍

自己读自己的文章会瞎。交稿前强制切换五个视角，每个视角只问一类问题。

每换一个视角，**通读一遍全文**，不要在同一个视角里跳着看。

---

## 视角一：出题老师

**只问三件事：题目要求的，你答了没有？**

```
□ 题目/选题的每一个成分都有对应章节吗？
□ 内容要求里逐条列的（案例数、框架、分层、具体技术）都落到了吗？
□ 有没有哪一条要求，通篇找不到对应？
□ 评分表里权重最高的那一项，我的力气花够了吗？
```

**红旗**：论文写得不错，但和题目问的不是一回事。这是最常见的失分，而且作者往往最后才发现。

**做法**：把作业要求原文逐条抄成清单，每条后面写"在第 X 页第 X 节"。（找不到就是没有。）

---

## 视角二：挑刺的同行

**只问一件事：你的核心判断，站得住吗？**

```
□ 我的核心论点能用一句话说出来吗？
□ 这句话是可证伪的吗（有没有可能被反例推翻）？
□ 最强的反驳是什么？我在文中正面回应了吗，还是绕开了？
□ 有没有把"没找到反例"当成"没有反例"？
□ 结论的强度配得上证据的强度吗？
```

**红旗**：核心论点只能靠"我认为"支撑；对手的最强论证被简化成稻草人。

**做法**：替对手写一段 200 字的反驳，越狠越好。如果写不出来，说明你还没理解自己的论证。

---

## 视角三：查数据的审核

**只问一件事：每个数字、每条引文，凭什么？**

```
□ 每个具体数字都有出处吗（谁统计的、哪一年、什么范围）？
□ 每条引文的版本对吗（译者、版次、页码）？
□ 有没有"待定"没清掉的？
□ 引用的文献是原始研究，还是二手综述？
□ 时间线算过减法吗（"两个月后"到底几个月）？
□ 案例是官方文本，还是媒体转述？
```

**红旗**：出现一个查不到出处的漂亮数字。**一个假数据可以毁掉整篇文章的可信度。**

**做法**：逐句扫，凡是带数字、带引号、带"研究表明"的句子，全部圈出来，一条一条核对。核不到就删或标"待定"。

---

## 视角四：读第一遍的读者

**只问一件事：读得下去吗？**

```
□ 第一段有没有让我想读第二段？
□ 有没有连续三段都是抽象论述，没有一个具体例子？
□ 每段的第一句是不是在说这一段的主题？
□ 有没有哪句话我要读两遍才懂？
□ 有没有"随着……""众所周知""具有重要意义"这类可以整段删掉的话？
□ 破折号、括号、"的"字连用是不是太多了？
```

**红旗**：自己读的时候想跳过的段落，老师也会跳过。

**做法**：朗读一遍。读不顺的地方就是要改的地方。或者隔一天再读——隔夜能看出 80% 的问题。

---

## 视角五：排版检查员

**只问一件事：格式对不对？**

```
□ 标题字体字号居中
□ 姓名、学院、学号 字体字号
□ 摘要、关键词 字体字号
□ 一级/二级/三级标题，全文一致
□ 正文 字体、字号、行距、首行缩进
□ 参考文献 字体字号行距、悬挂缩进
□ 引用序号 1..N 连续，与文献表一一对应
□ 页边距、页码（如果要求）
□ 文件名符合命名规则
```

**红旗**：手动数出来的序号和文献表对不上。

**做法**：跑脚本，不要靠眼睛。

```bash
python scripts/check_paper.py 论文.docx --min 3500 --max 5000 --min-refs 10
python scripts/doctor.py .        # 如果要发布这个 skill
```

## 六、最后一道：字数与配额的算术

```
正文（含小标题）：____  要求 ____–____
正文（不含标题）：____
摘要（含标点）：  ____  要求 ____–____
摘要（不含标点）：____
参考文献：        ____ 条，近 N 年 ____ 条 = ____%
直接引文占比：    ____%  要求 ≤17%
```

**三档字数都要报。** 不同老师算法不同，报一个数等于赌博。

---

## 七、交稿前的最后一个问题

> 如果老师指着任何一句问"这句凭什么"，我能不能当场答上来？

答不上来的句子，就是还没写完的句子。

---

## 八、常见"看起来完成了其实没有"的信号

| 信号 | 实际意味着 |
|---|---|
| 每章字数差不多 | 大概率是模板填出来的，没有详略 |
| 每段都以总结句结尾 | 你在凑字数，不是在论证 |
| 全文没有一处承认局限 | 你没想过反例 |
| 结论和引言说的是同一件事 | 你没有推进，只是重复 |
| 参考文献全是近三年 | 你没读源头文献 |
| 参考文献全是网页和公告 | 你没读学术文献 |
| 案例只写"某企业" | 你没做功课 |
