# 论文结构模板库

不同文体的骨架差别很大。选错骨架，写得再用力也不对味。

---

## 一、先判断你要写哪一种

| 类型 | 判断特征 | 核心要求 |
|---|---|---|
| 论述型课程论文 | 给题目，要求有自己的观点 | 一个可证伪的判断 + 论证 |
| 案例分析 | 指定或自选案例 | 事实准确 + 框架切开 |
| 文献综述 | "研究现状""综述" | 有分类框架，不是流水账 |
| 读书报告 | 指定书目 | 读懂 + 评价，不是复述 |
| 调研报告 | 有数据收集 | 方法透明 + 结论不超数据 |
| 实验/技术报告 | 有实测 | 可复现 + 误差交代 |

---

## 二、论述型课程论文（最常见）

```
题目
摘要（问题—方法—结论）
关键词
一、引言
    1.1 现象/背景（从具体事实切入，不要"随着……"）
    1.2 已有讨论及其不足
    1.3 本文做什么（陈述句，不要三连问）
二、分析框架
    2.1 框架 A 的判据
    2.2 框架 B 的判据
    2.3 两者在哪里冲突
三、案例/材料一
    3.1 事实与细节
    3.2 用 A 切
    3.3 用 B 切
四、案例/材料二（对照）
五、为什么反复出现（机制）
六、怎么办（分层）
七、结语（散文 2~3 段）
参考文献
```

**字数参考**（以 4500 字为例）：引言 550 / 框架 700 / 案例一 800 / 案例二 700 / 机制 550 / 方案 750 / 结语 400。

**反模板三条**：
1. 各章颗粒度不同——可以是 3 节 / 0 节 / 4 节，有章分小节，有章连贯论述。
2. 每章留一处自我设限：承认反例、划出适用范围。
3. 结论分层：按单一标准分 2~4 层。

---

## 三、案例分析

```
一、案例选择理由（为什么是它，不是别的）
二、事实
    2.1 时间线（精确到年月日）
    2.2 技术细节（型号、参数、失效模式）
    2.3 官方结论（报告编号、处罚结果）
三、冲突点（谁与谁的什么义务相撞）
四、框架分析
    4.1 框架 A 会怎么判
    4.2 框架 B 会怎么判
    4.3 结论相反意味着什么
五、对照案例（可选，用来划界）
六、结论
```

**案例要过四关**：
- 有官方文本（调查报告 / 监管公告 / 判决书 / 标准原文）
- 有时间线（不是"某年"）
- 有技术细节（能说出参数和失效模式）
- 有定论（争议未决的案子不能当正面论据）

---

## 四、文献综述

```
一、引言：为什么综述这个问题、范围如何界定
二、检索与纳入（数据库、检索式、纳入排除标准）
三、主题分类（不是按时间罗列，是按问题分组）
    3.1 观点 A 及其代表研究
    3.2 观点 B 及其代表研究
    3.3 A 与 B 的分歧点
四、研究空白（已有研究没做什么）
五、结论与展望
```

**三条禁忌**：
1. 按时间顺序写"某某年谁研究了什么"——这是流水账。
2. 只罗列不评价——综述的价值在分类和判断。
3. 没有检索说明——读者不知道你找全了没有。

---

## 五、读书报告

```
一、这本书在讲什么（200 字以内说清）
二、它的论证结构（作者怎么一步步推的）
三、关键概念辨析（哪几个词是作者自己定义的）
四、我的评价
    4.1 成立的地方
    4.2 可疑的地方（要具体到页码）
五、与课程/现实的关联
```

**最常犯的错**：把读书报告写成内容摘要。摘要占三分之一就够了，剩下的必须是评价。

---

## 六、实验/技术报告（IMRaD）

```
Introduction   为什么做、问题是什么
Methods        怎么做的（可复现）
Results        结果（只陈述，不解释）
and
Discussion    结果意味着什么、局限在哪
```

**工科补充要求**：
- 参数写全（型号、量程、精度、环境条件）
- 误差要有交代（重复次数、标准差、系统误差来源）
- 图表要有单位、图例、误差棒
- 结论不能超出数据覆盖的范围

---

## 七、摘要的三种写法

**结构式**（工科、实证）：问题—方法—结果—结论，四句话。

**论点式**（人文、论述）：现象—既有解释不足—本文判断—依据。

**综述式**：范围—分类框架—主要分歧—空白。

三种都必须满足：**250–300 字、不出现"本文认为"、末句不给口号。**

---

## 八、结语怎么写

不要"第一、第二、第三"，不要"综上所述""小结"。

四步走，2~3 段连贯散文：

1. **回扣问题**，给总判断；
2. **提炼判断**——比引言更进一步的那一句；
3. **落到实践指向**；
4. **一句收束**——短判断，不是总结。

最后一句最好是一个短句。长句收尾会泄气。

---

## 九、标题层级

- 一级：一、二、三……（黑体，三号或四号）
- 二级：2.1、2.2……（黑体，四号或小四）
- 三级：3.2.1、3.2.2……（黑体，小四，通常顶格）

**三级标题不要滥用**。全文只有一两处三级标题，说明层级名存实亡——不如把内容并入二级。

**标题里不用问号、感叹号**，也不要层层带冒号做排比（"（三）程序之失：判决先于证据"连排四节很呆板），改成平铺直叙的断言。
