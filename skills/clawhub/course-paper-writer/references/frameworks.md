# 分析框架模块

按论文类型只读相关的一节。框架的作用不是贴标签，是让两个立场真正对撞。

---

## 一、工程伦理 / 技术类专业课

### 1.1 什么叫"伦理困境"

必须同时满足三条：

1. **两个义务都站得住**（保护安全 vs 保障可及性；企业生存 vs 数据最小化）；
2. **现有规范无法同时满足**；
3. **不是某一方违规造成的**。

写不出双方的正当性理由，说明题目没选对，或案例选错了。

**困境与失范的分界线**：一方明显违规、隐瞒、越过标准，那叫**失范**，只剩法律责任，没有伦理张力。写作时应把两类案例分开处理——用"一个困境案 + 一个失范案"对撞，并让分界线本身成为论点。

### 1.2 常用框架

| 框架 | 核心判据 | 原著 |
|---|---|---|
| 功利主义 | 最大多数人的最大幸福；可做成本—收益计算 | 边沁《道德与立法原理导论》；密尔《功利主义》 |
| 义务论 | 行为本身是否可普遍化；人不可仅作手段 | 康德《道德形而上学奠基》 |
| 美德伦理 | 有德性的工程师会怎么做 | 亚里士多德《尼各马可伦理学》 |
| 契约论/正义论 | 无知之幕后的公平；差别原则 | 罗尔斯《正义论》 |
| 责任伦理 | 对后代与不可逆后果负责 | 约纳斯《责任原理》 |
| 价值敏感设计 | 设计阶段就把价值嵌入 | Friedman, Kahn & Borning (2006) |

**加分写法：让两个框架对撞。** 功利主义算出"可以省"，义务论指出"把人当手段"，两个结论相反——这才是困境的证据。只用一套框架，等于做算术题。

### 1.3 把框架接到论点上的方法

常见错误是框架讲完就丢，案例里不再提。正确做法是**在案例处回指判据**：

> 回到第二章的判据："人是目的"在这里就是"用户在交付前知道自己买的是什么"。

教材里常有一句话能把抽象原则落到操作上。比如《工程伦理》在讲风险评估时说"以人为本"要体现"人不是手段而是目的"，其中一项就是尊重当事人的"知情同意"权——**这句话就是义务论与"披露/知情"类论点的桥**。找到这类句子，框架才接得上案例。

### 1.4 责任分层

教材通常把工程责任分三层：

1. 遵循程序标准与职业章程，目标是**避免指责**；
2. **合理关照**（reasonable care）：评估技术可能给他人带来的伤害并加以保护；
3. 超出义务的要求。

绝大多数现实决策停在第一层。"满足国标"就是那个"避免指责"。指出这一点，比空喊"工程师要有良心"有力得多。

### 1.5 可靠源

- 标准：国家标准全文公开系统（核到标准号 + 发布日 + 实施日）
- 事故：NTSB 报告（HAR-xx/xx）、NHTSA 召回报告（Part 573）、市场监管总局召回公告、应急管理部调查报告
- 政策：中办国办《关于加强科技伦理治理的意见》（2022-03）、科技部等《科技伦理审查办法（试行）》（2023）

## 二、思政 / 马克思主义理论

### 2.1 结构要求

这类论文的评分重心通常不在"创新"，而在**立场正确 + 文本准确 + 联系实际**。三个常见失分点：

1. 只复述文件，没有自己的判断；
2. 引用政策不回读原文（**必须回读**，转述容易把意思弄反）；
3. 联系实际停留在口号，没有具体主体和做法。

### 2.2 论证方式

- 用**概念史**推进：这个概念从哪来、怎么演变、今天指什么。
- 用**文本依据**支撑：引原著的完整句子并给出处在哪一卷哪一页。
- 联系实际要落到**具体行业/地区/群体**，不要写"某地"。

### 2.3 可靠源

- 党的重要文献、政府工作报告（核到发布机关与日期）
- 马克思主义理论研究和建设工程教材
- 《马克思主义与现实》《思想理论教育导刊》等 CSSCI 期刊

## 三、通用论证（其它学科）

### 3.1 三段式升级为四段

不要写"现状—问题—对策"。改成：

```
现象的具体形态 → 为什么会这样（机制） → 该怎么评价（标准） → 怎么改（分层）
```

第二段是关键：**机制**必须是可证伪的因果，不是"由于种种原因"。

### 3.2 每章留一处自我设限

承认反例、划出适用范围，比单向论证有分量。写法：

> 这一判断有一个前提：……。若该前提不成立，结论需要修正为……。

### 3.3 结论分层

按**单一标准**分 2~4 层，不要一刀切。例如按"是否可核验"分：可当场核验的 / 需要第三方数据的 / 无法核验只能靠程序保障的。

### 3.4 结语写法

不要"第一、第二、第三"，不要"小结""综上所述"。2~3 段连贯散文：

1. 回扣问题，给总判断；
2. 提炼本文比引言更进一步的那一句；
3. 落到实践指向；
4. 一句引文或断语收束。
