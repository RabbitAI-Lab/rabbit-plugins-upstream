# 课程论文写作流程

适用于：给定题目或选题清单、有明确格式与字数要求、要求提交 Word 文档的课程论文。

**产出物是 .docx，不是一段文字。** 全部工作围绕三件事：**约束不漏、出处可查、排版正确**。

## 0. 六条铁律

1. **每个论断可核验。** 事实有出处，数据有统计范围，引文有版本。
2. **不造词。** 术语用教材原话、标准原文、权威文献既有概念。
3. **案例要站得住。** 优先官方文件、监管公告、司法文书、标准原文、权威调查报告。
4. **先算后写。** 字数配额在动笔前分好，不要写完再删。
5. **反模板。** 各章颗粒度必须不同，禁止"三章各三节"；结语是散文不是清单。
6. **交付前自问**：如果老师逐句问"这句凭什么"，能不能当场答上来。

## 1. 读要求文件，填硬约束表

不要开口问用户要字数要求——要求就在文件里。

| 格式 | 工具 |
|---|---|
| `.docx` | `python-docx` 读段落与表格 |
| `.doc`（文件头 `D0CF11E0`） | `python scripts/extract_doc.py 要求.doc 要求.txt` |
| `.pdf` | `python scripts/extract_pdf.py 要求.pdf 要求.txt` |

两个提取器纯标准库，不依赖 LibreOffice。扫描件无文本层，提取为空就请用户贴文字，**不要硬猜**。

```
题目：        □给定 □自拟
字数：        ____ ～ ____ ，是否含摘要/参考文献：____
摘要：        ____ 字；关键词：____ 个
页数：        ____ 页
正文：        字体____ 字号____ 行距____（固定值/倍数）
标题层级：    ____ 级；各级字体字号
文献：        不少于____ 篇；近____ 年占比≥____%；格式____
必备要件：    □引言 □正文 □结语 □参考文献 □致谢 □附录
内容要求：    ____（如"至少2个真实案例""须用××框架"）
评分权重：    ____
提交：        截止____ 邮箱____ 命名规则____
```

**评分权重决定力气分配。** 例如"争议性 30%、框架 25%、案例 20%、分层 15%、格式 10%"——这条信息比字数更重要。

## 2. 题目 → 问题链

| 题目成分 | 必须回答 |
|---|---|
| "为什么……" | 因果与机制，不是"是什么" |
| "……的困境/冲突" | 冲突双方的正当性各是什么 |
| "如何……/路径" | 可操作的方案，且分层 |
| "……研究/探析" | 一个可证伪的判断 |

**"伦理困境"的判定标准**：必须存在两个都站得住的义务相互冲突，且现有规范无法同时满足。若一方明显违规，那是**失范**，不是困境——遇到就主动告诉用户换题或换案例。

详见 `references/frameworks.md`。

---

## 3. 找文献

不要一上来就写。先花二十分钟把文献找对。

三件事：

1. **定检索式**：`(主题词 OR 同义词) AND (限定)`，同义词要穷举。
2. **从一篇好文献往外扩**：看它的参考文献（追源头）、看谁引了它（追进展）、看相似文献（横补）。
3. **三分钟筛一篇**：出处→摘要→方法→引文→结论，任何一关不过就放弃。

详见 `references/literature-search.md`。

---

## 4. 联网取证

详见 `references/evidence-protocol.md`。要点：

- **源分三档**：A 档原始规范/标准/官方调查/权威教材，B 档同行评议文献，C 档权威媒体。结论靠 A 和 B，事实可以靠 C。
- **边搜边填记录表**：`我要说的那句话 | 依据 | 出处 | 链接`。填满即等于写完。
- **查不到就标"待定"**，绝不编造。交付时列成待核对清单。

文献数量：条数 = 要求下限 + 20%；近 N 年占比做到 60% 以上，不要卡着 50% 写。

---

## 5. 结构

通用骨架见 `references/paper-structures.md`。核心是**先选对文体**——论述型、案例分析、文献综述、读书报告、实验报告，骨架完全不同，选错就白写。

**反模板三条**：
1. 各章颗粒度不同（可以是 3 / 0 / 4 / 0）。
2. 每章留一处自我设限：承认反例、划出适用范围。
3. 结论分层：按单一标准分 2~4 层。

---

## 6. 写作与文风

写完之后必须过一遍 `references/ai-voice.md`。三个最高频的病灶：

| 病灶 | 例子 | 改法 |
|---|---|---|
| 引言末尾三连问 | "本文要回答的是：A 是什么，B 为什么……" | 删掉，改成陈述句或直接给案例 |
| 摘要末句表态 | "据此，本文主张……" | 改成研究结论的陈述 |
| 每段都配总结句 | "由此可见，……具有重要意义" | **写不出好总结就别写**，让事实收尾 |

另有十一类：意义通胀、-ing 尾巴、否定式排比、三连排比、同义词轮换、模糊归因、超长从句、破折号滥用、动词强过证据、创新性注水、引用堆砌。

**必须避免的词**：维度、抓手、赋能、闭环、范式、张力、勾连、建构、口径、边界、压缩、吸收。

需要表达这些概念时换成具体说法："口径"→"按什么统计"；"边界"→"标准下限以上"；"抓手"→"具体动作"。

---

## 7. 引用

详见 `references/citation-formats.md`（GB/T 7714 / APA / IEEE / MLA 速查 + 十个常见错误）。

三条硬规则：

1. 按正文**首次出现顺序**编号，重复引用用同一序号。
2. 正文用**上标方括号**，文献表按序号排。
3. 页码拿不准就省，**宁可少一项，不要错一项**。

---

## 8. 生成 DOCX

详见 `references/docx-formatting.md`。四个必设项：

```python
# 1. 中文字体必须同时设 eastAsia
for a in ("w:ascii", "w:hAnsi", "w:eastAsia", "w:cs"):
    rFonts.set(qn(a), "宋体")

# 2. 行距分两种
pf.line_spacing = Pt(20); pf.line_spacing_rule = WD_LINE_SPACING.EXACTLY  # 固定值
pf.line_spacing = 1.5                                                      # 倍数

# 3. 首行缩进"2 字符" = 2 × 正文字号（小四 12pt → 24pt）
pf.first_line_indent = Pt(24)
```

**上标引用用占位符**：正文写 `⟦n⟧`，渲染时切成上标 run 输出 `[n]`。写作与排版解耦，改序号只改占位符。

---

## 9. 交稿前自查

跑脚本，不要靠眼睛：

```bash
python scripts/check_paper.py 论文.docx --min 3500 --max 5000 --min-refs 10
python scripts/citation_formatter.py refs.txt --recent-years 5
```

然后换五个视角通读一遍，清单见 `references/self-review.md`：出题老师、挑刺的同行、查数据的审核、读第一遍的读者、排版检查员。

**字数必须报三档**：含小标题 / 不含小标题 / 不含标点。摘要单独报含标点和不含标点两档。

---

## 10. 交付

必须主动交代三件事：

1. **文件状态**：文件名、字数（三档）、估算页数、文献条数、近 N 年占比。
2. **待核对清单**：推测信息逐条列出（译者、版次、期号、页码、学院名、学号），标"请核对"。
3. **修改建议**：仍显机械的段落、可再压的地方、答辩可能被追问的点。

---

## 附：本 Skill 的边界

- 只做**学术写作流程**，不做代写期刊投稿、不伪造数据、不生成虚假引用。
- 查不到出处一律标"待定"，**不用看似合理的假引用填充**。这是硬约束。
- 涉及具体学科判断时，以用户提供的教材与标准原文为准，不作超出文本的推断。
- 页数是**估算**，精确页数请用 Word 或 LibreOffice 打开确认。
- 不替代查重、不规避 AI 使用声明。
