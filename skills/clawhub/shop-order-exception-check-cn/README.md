# 订单异常处理待办

![订单异常处理待办推广图](assets/promo-1600x900.png)

把脱敏订单状态、商家流程和时效规则变成一份清晰的人工处理待办：快速找出超时、缺项和状态矛盾，并按风险与截止时间排序。它不会接入店铺、调用订单接口，或执行发货、退款、通知。

## 使用

将以下内容直接提供给 Skill：

- 脱敏订单状态表：订单标识、当前状态、状态更新时间，以及可用的商品/内容项和前序状态；
- 正常流程：状态顺序及允许分支；
- 时效规则：各状态最长停留时间、当前核对时间和时区。

Skill 会输出“待补资料”（如有）、异常订单清单和人工处理顺序。资料字段及其原值被视为事实；建议会明确标为建议。缺少关键字段时只会指出缺失和影响，不会编造状态或时间。

可从 [成功样例](fixtures/success.md) 开始；[失败样例](fixtures/failure-missing-fields.md) 展示了缺少关键字段时应有的处理方式。

## 自测

在仓库根目录运行：

```bash
bash scripts/self-test.sh
```

自测只验证打包结构、关键字段、素材尺寸和成功/失败样例声明；不模拟或声称验证真实业务判断。真实结果始终取决于实际提供的订单资料、流程和时效规则。

## 边界

这是一个纯 Markdown 工作流，不需要浏览器登录或第三方 API。它输出待办，不变更订单，也不替代人工的发货、退款与客户沟通决定。
