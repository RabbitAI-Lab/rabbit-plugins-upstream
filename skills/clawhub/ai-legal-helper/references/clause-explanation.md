# 条款解读（Clause Explanation）

## 适用场景
- 用户拿到合同后某一条款"看不懂"或"想确认含义"
- 用户想了解"这条对我有什么影响"
- 用户想对比"两种条款写法哪个对我有利"

## 工作流（3 步法）

### Step 1：定位条款
- 用户引用条款的方式：摘抄全文 / 拍照 / 描述大意
- 必须确认条款所属合同类型 + 上下文
- 警惕：同一句话在不同合同中含义可能不同（如"违约金"在买卖合同 vs 劳动合同下规则不同）

### Step 2：拆解语义
按"原文 → 通俗解释 → 法律含义 → 实操影响"四层拆解：

```
【原文】（用户提供的条款原话）

【通俗解释】（白话文，假设用户是 18 岁普通成年人）

【法律含义】（法理上的标准解读 + 司法实践中的常见判决倾向）

【实操影响】（在什么情况下用户会受益 / 受损 / 承担义务）

【法律依据】（相关法条 + 类似判例）
```

### Step 3：给出对等性建议
若条款对用户明显不利，给出 2-3 个改写版本：
- 保守版（仅删除最不利条款）
- 平衡版（增加对等权利义务）
- 强势版（争取更有利条款，可能对方拒绝）

## 常见条款类型速查

| 条款类型 | 用户常问 | 关键风险点 |
|---|---|---|
| 违约金 | "XX% 是不是太高" | 超过实际损失 30% 法院可调减 |
| 管辖约定 | "为什么约定在我不熟悉的城市" | 异地诉讼成本 + 律师费翻倍 |
| 知识产权归属 | "我用业余时间写的代码归谁" | 模糊约定=公司所有（看劳动合同） |
| 竞业限制 | "离职后多久不能做同行" | 超过 2 年无效 / 必须给补偿 |
| 不可抗力 | "疫情算不算" | 看是否明文列举 + 是否尽通知义务 |
| 退订 / 解约 | "我中途能不能不干了" | 看违约责任 + 已发生成本分担 |
| 保密条款 | "我离职后能不能跟前同事吃饭聊业务" | 范围 / 期限 / 客户名单是否构成商业秘密 |

## 关键原则
- 永远用"人话"先讲一遍，再给法言法语
- 不确定时明说"司法实践有不同观点"
- 涉及金额 / 时间 / 范围的条款，必须给出"具体数字"建议（不要只说"约定明确"）
- 涉及人身 / 财产重大利益的条款，结尾加"建议咨询专业律师确认"
