# 合同智能审查（Contract Review）

## 适用场景
- 劳动合同 / 劳务合同 / 兼职协议
- 租赁合同（住房 / 商铺 / 设备）
- 买卖合同 / 销售合同
- 服务合同 / 咨询合同 / 外包合同
- 合作协议 / 合伙协议 / 股权协议
- 借款合同 / 投资协议
- 保密协议（NDA）/ 竞业限制
- 离婚 / 财产分割协议（家事）

## 工作流（5 步法）

### Step 1：解析输入
- 接受格式：PDF / Word / 图片（OCR）/ 纯文本 / 手写抄录
- 必做：合同主体识别（甲方 / 乙方 / 丙方）、合同类型判定、生效日期、金额、关键标的

### Step 2：条款切分
按 12 大标准模块切分（参考 `assets/prompt-templates.md` 的合同审查模板）：
1. 主体与资质
2. 标的与数量
3. 价款与支付
4. 履行期限与方式
5. 质量与验收
6. 知识产权
7. 保密与竞业
8. 违约责任
9. 不可抗力
10. 争议解决
11. 合同变更与解除
12. 其他（通知 / 附件 / 生效条款）

### Step 3：风险点扫描
对每个模块按下列 6 维评估：
- **缺失风险**：必备条款是否齐全？
- **歧义风险**：用语是否明确？是否可能产生两种以上理解？
- **不平衡风险**：双方权利义务是否对等？
- **法律冲突风险**：是否违反法律强制性规定？
- **可执行性风险**：违约责任是否可操作？
- **隐性成本风险**：是否隐藏费用 / 押金 / 排他条款？

### Step 4：输出报告
固定结构（参考主 SKILL.md 第 3 步）：
```
【合同基本信息】类型 / 主体 / 金额 / 期限
【风险等级】⭐ / ⭐⭐ / ⭐⭐⭐ / ⭐⭐⭐⭐
【风险点】
  1. 【缺失】缺少 XX 条款 → 建议补充
  2. 【歧义】第 X 条 "合理期限" 未定义 → 建议改为具体天数
  3. 【不平衡】违约金 XX% 显著高于法定上限 → 建议协商下调
  4. 【法律冲突】违反《XX法》第 X 条强制性规定 → 无效
【修改建议】（每条对应原文 → 建议替换为 …）
【法律依据】…
【免责声明】…
```

### Step 5：高风险升级清单
满足下列任一条件 → **必须引导转人工律师**：
- 合同金额 > 20 万元
- 涉及不动产 / 股权 / 知识产权转让
- 涉外因素（任一方为境外主体）
- 涉及刑事风险条款
- 涉及诉讼 / 仲裁
- 客户明确表示"将作为诉讼证据使用"

## RAG 召回策略
- 私域语料：常用合同范本（官方 / 行业协会 / 知名律所）
- 法条映射：每类合同对应核心法规（《劳动合同法》《民法典》合同编、《公司法》等）
- 判例补充：近 3 年最高法 / 高级法院典型判例
- 命中率目标：单次合同审查至少召回 5 条相关法条 + 3 个相似条款范本

## 准确率要求
- MVP 阶段：法条引用准确率 ≥ 95%
- 商用阶段：律师定期抽检 ≥ 200 份，准确率 ≥ 99% 才能上线高级功能
- 误差容忍：低风险合同可接受 1% 误差；高风险合同误差率必须为 0

## 常见陷阱
- ❌ 不要替用户做"签 / 不签"的最终决定
- ❌ 不要在审查报告中遗漏免责声明
- ❌ 不要把"建议"与"结论"混淆（建议仅供参考，结论必须有法律依据）
- ✅ 必须区分"违法无效""可撤销""可变更""有效但有风险"四种程度
