# 商业模式与定价（Business Model）

## 核心模式：Freemium + 拼团 + 企业服务

### 产品分层
| 层级 | 价格 | 内容 | 目标用户 |
|---|---|---|---|
| 免费层 | 0 元 | 基础合同模板、简单条款解读、单次合同审查（限 1 次/月） | 个人 / 体验用户 |
| 月度会员 | 99–399 元 | 深度审查、出具法律意见书、不限次数咨询 | 中小微企业 / 自媒体 / 自由职业 |
| 年度套餐 | 1999 元 | 月度会员全部权益 + 律师 1v1 视频咨询 4 次 + 优先响应 | 重度用户 |
| 企业服务 | 2999 元/月起 | 团队账号 + 批量合同审查 + 定制知识库 + SLA | 中小企业 HR / 法务 |

### 推荐"三人拼团 99 元首月会员"
- 触发点：用户首次注册后 7 天内未付费
- 玩法：邀请 2 位好友一起开团，三人共享首月 99 元会员
- 目标：拉新成本 < 30 元 / 人，留存 > 40%
- KPI：注册用户 500–1000 名，付费转化率 5%

## 增长渠道（参考文章"三个方向扩大收入"）

### 方向 1：知识付费（面向 C 端，1999 元/年）
- 内容形式：小红书 / 知乎 / B 站短视频
- 选题示例：
  - "签合同时这 5 句话一定要改"
  - "被公司辞退能拿多少赔偿"
  - "租房押金不退怎么办"
  - "借钱给朋友怎么写借条才有效"
- 收费产品：
  - 99 元《普通人必学的 50 个法律常识》专栏
  - 299 元《合同避坑指南》系统课
  - 1999 元/年《年度法律会员》（含咨询服务）

### 方向 2：企业服务（面向 B 端）
- 目标客户：律所、人力资源公司、咨询公司、电商平台
- 产品形态：
  - 批量合同审查 API
  - 定制法律知识库
  - 嵌入客户系统（CRM / OA / HR SaaS）
- 收费模式：年费制 + 按调用量阶梯计费
- 销售路径：内容营销获客 → 试用 → 商务谈判 → 续约

### 方向 3：政府合作（高门槛但稳定）
- 切入场景：法律援助热线、政府法律咨询小程序、普法内容供给
- 价值主张：弥补基层法律服务资源不足 + 数据安全可控
- 路径：先做地方试点（如某区司法局）→ 形成案例 → 推广

## 收入预测（参考文章财务可行性）
- 2000 元成本 + 订阅 99–399 元/月
- 前 20–40 名付费用户即可覆盖成本
- 中期通过企业服务（2999 元/月）和政府合作放大收入规模
- 预期第一年实现盈亏平衡

## 关键 KPI
- 注册用户数（目标首年 5000+）
- 付费转化率（目标 ≥ 5%）
- 客单价（目标 ≥ 199 元）
- 月留存（目标 ≥ 60%）
- NPS（净推荐值，目标 ≥ 50）
- 续费率（年付用户目标 ≥ 70%）

## 风险与对策
- **政策风险**：法律服务监管收紧 → 提前合规 + 律师挂靠
- **竞争风险**：大厂（百度 / 阿里）下场 → 死守垂直深度 + 数据壁垒
- **口碑风险**：AI 输出错误 → 强人工审核 + 律师兜底
- **现金流风险**：获客成本失控 → 控制月度营销预算 + 自有内容矩阵
