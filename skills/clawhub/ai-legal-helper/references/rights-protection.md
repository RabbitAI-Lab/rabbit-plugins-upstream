# 维权建议（Rights Protection）

## 适用场景
- 消费者维权（买到假货 / 消费欺诈 / 退款纠纷）
- 劳动维权（被欠薪 / 被违法解除 / 工伤认定）
- 租赁纠纷（房东不退押金 / 提前收房 / 随意涨租）
- 侵权维权（被抄袭 / 被造谣 / 名誉侵权 / 肖像权）
- 债权债务（借钱不还 / 货款拖欠）
- 家事纠纷（离婚 / 抚养 / 继承）
- 行政纠纷（被处罚 / 强拆 / 信息公开）

## 工作流（4 步法）

### Step 1：案情澄清
必问 4 要素（信息不足时必须问清，不能臆断）：
1. **当事人**：原告 / 被告是谁？身份关系？
2. **事件经过**：时间线 + 关键证据
3. **诉求**：用户想要什么？退款？赔偿？道歉？恢复原状？
4. **现状**：是否已协商？是否已报警？是否已投诉？

### Step 2：法律关系定性
根据事实归类到下列法律关系之一：
- 合同纠纷 / 侵权纠纷 / 不当得利 / 劳动争议 / 行政争议 / 家事纠纷 / 刑事控告

### Step 3：维权路径推荐
按"成本由低到高"给出 3-5 条可选路径：

| 路径 | 适用情形 | 成本 | 周期 | 胜诉率参考 |
|---|---|---|---|---|
| ① 协商谈判 | 对方态度尚可 / 标的小 | 0 | 1-7 天 | 高 |
| ② 平台投诉 | 电商 / 外卖 / 网约车等 | 0 | 3-15 天 | 中 |
| ③ 12345 / 行业调解 | 消费 / 物业 / 劳动 | 0 | 7-30 天 | 中 |
| ④ 人民调解委员会 | 邻里 / 家事 / 小额 | 0-100 | 7-30 天 | 中 |
| ⑤ 行政投诉举报 | 商家违法 / 行业违规 | 0 | 15-60 天 | 视情况 |
| ⑥ 劳动仲裁（前置） | 劳动争议 | 0 | 45-60 天 | 较高 |
| ⑦ 法院小额诉讼 | 标的 ≤ 5 万 | 50-200 | 3-6 月 | 较高 |
| ⑧ 法院普通诉讼 | 标的较大 | 200-1000+ | 6-18 月 | 视案情 |
| ⑨ 刑事控告 | 对方涉嫌犯罪 | 律师费 | 不定 | 视证据 |

### Step 4：证据清单 + 文书模板
- 列出本案必备证据（如借条 / 聊天记录 / 录音 / 转账记录 / 合同 / 证人）
- 提供可套用文书模板：
  - 律师函模板
  - 投诉信模板
  - 民事起诉状模板
  - 劳动仲裁申请书模板
  - 报警笔录要点

## 关键边界（必须转人工）
- 涉及金额 > 20 万
- 涉刑事案件（被刑事拘留 / 取保候审 / 即将出庭）
- 涉外（任一方为境外主体或标的在境外）
- 涉及不动产 / 股权
- 用户已准备起诉 / 已聘请律师
- 用户有心理危机或极端倾向（要先评估再回答，必要时引导至心理援助）

## 输出模板
```
【法律关系】本案属于 XX 纠纷
【维权路径】推荐路径：①②③…
【必备证据】1. … 2. … 3. …
【文书模板】可使用《XX 投诉信 / 律师函 / 起诉状》模板
【预估成本】协商：0 元 / 仲裁：约 X 元 / 诉讼：约 X 元
【预估周期】X-Y 个月
【温馨提示】本案涉及 [高风险 / 涉外 / 刑事]，强烈建议咨询专业律师
【免责声明】…
```
