# 法律法规 RAG 检索（Legal RAG）

## 适用场景
- 用户问"XX 行为是否合法"
- 用户问"遇到 XX 情况适用什么法"
- 用户问"XX 法规第 X 条具体怎么规定的"
- 用户问"行政处罚 / 刑事处罚的标准"

## RAG 知识库构建

### 数据源（私域语料）
- **法律法规库**：宪法 / 民法典 / 刑法 / 各单行法 / 行政法规 / 部门规章 / 地方性法规
- **司法解释库**：最高法 / 最高检发布的司法解释、指导案例
- **典型判例库**：最高法指导案例 + 公报案例 + 各高院典型案例
- **合同范本库**：官方 / 行业协会 / 知名律所发布的合同范本
- **地方政策库**：各地人社局 / 工商 / 税务 / 住建等口径
- **FAQ 库**：本平台累计的真实用户问答

### 数据清洗
- 必须结构化：每条法条带【法名 + 条款号 + 生效日期 + 是否有效】
- 标注修改记录：哪一条被哪部新法废止 / 修改
- 保留原文链接 / 出处，便于溯源
- 法规更新必须 ≤ 7 天内同步（法条库准确性是法律 AI 的命门）

### Embedding 与召回
- 中文法律 Embedding 模型推荐：
  - `BAAI/bge-large-zh-v1.5`（通用，召回率高）
  - `shibing624/text2vec-base-chinese-paraphrase`（语义匹配好）
  - `Qwen/Qwen3-Embedding`（最新，长文友好）
- 召回策略：稠密向量 + BM25 关键词混合召回
- 重排序：Cross-Encoder 重排（bge-reranker-large / Qwen3-Reranker）

## 质量保证

### 引用强制
- 每条法条引用必须可点击跳转原文
- 引用格式：`《XXX法》第 X 条（YYYY 年修订版）第 X 款`
- 模糊引用必须标"具体条款以官方公布为准"

### 时效性
- 检索时自动附加"本回答基于 YYYY-MM-DD 前的法律法规"
- 法条变更后 24 小时内更新知识库

### 不确定性处理
- 知识库未覆盖时必须说"未找到相关明确规定"
- 跨地区法规差异必须分地区呈现（如劳动仲裁管辖）
- 不要用"一般来说""通常情况下"等模糊措辞替代具体法条

## 技术栈推荐
- 向量数据库：Milvus / Qdrant / PGVector
- 文档加载：LangChain / LlamaIndex
- 微调：Qwen2.5-Instruct + LoRA（少量法律 QA 语料）
- 服务化：FastAPI + Docker + K8s
- 前端：Web (React/Vue) + 微信小程序（uni-app）

## 性能指标
- 单次响应 < 3 秒（P95）
- Top-5 召回准确率 ≥ 90%
- 引用准确率 ≥ 98%
- 月活用户 1000+ 时单节点 QPS ≥ 50
