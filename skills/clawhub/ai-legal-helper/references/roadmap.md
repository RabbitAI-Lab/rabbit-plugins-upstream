# 12 个月落地路线图

## 第 1 阶段：产品构建（第 1–3 个月）
**目标**：MVP 上线，单次响应 < 1 分钟

### 月 1：基础搭建
- [ ] 团队：1 名 AI 工程师 + 1 名产品 + 1 名法律顾问（兼职）
- [ ] 选型：Qwen2.5-Instruct 底座 + LoRA 微调框架
- [ ] 数据：整理 200–500 份常用合同范本 + 1000 条法条
- [ ] 基建：向量数据库 + RAG 管道 + 后端 API

### 月 2：核心功能
- [ ] 合同智能审查（覆盖率 ≥ 60% 常见合同类型）
- [ ] 条款解读
- [ ] 法规问答
- [ ] 基础 Web 端

### 月 3：联调与灰度
- [ ] 微信小程序开发
- [ ] 邀请 20–30 名真实用户内测
- [ ] 收集反馈 / 优化准确率
- [ ] **成本控制：1 万元以内**

## 第 2 阶段：冷启动与验证（第 4–6 个月）
**目标**：种子用户 500+，付费转化 5%

### 月 4：上线 Freemium
- [ ] 注册 / 登录 / 会员体系
- [ ] 付费墙设计
- [ ] 上线"三人拼团 99 元首月会员"活动

### 月 5：内容获客
- [ ] 公众号 / 小红书 / 知乎 / B 站内容矩阵
- [ ] 每周 ≥ 3 篇原创法律科普
- [ ] SEO 优化（百度 / 微信搜索）

### 月 6：转化与留存
- [ ] 邮件 / 短信召回
- [ ] 会员社群运营
- [ ] 收集 NPS 与改进建议

### 关键指标
- 注册用户 500–1000
- 付费用户 25–50
- 月留存 ≥ 40%
- 准确率 ≥ 95%

## 第 3 阶段：规模化增长（第 7–12 个月）
**目标**：从 5% 转化提升到盈亏平衡

### 月 7–8：知识付费
- [ ] 上线付费专栏（1999 元/年）
- [ ] 短视频矩阵扩量
- [ ] 与 KOL 合作分销

### 月 9–10：企业服务
- [ ] 推出 B 端套餐（2999 元/月起）
- [ ] 联系 10–20 家目标客户（律所 / HR / 电商）
- [ ] 试点合作 → 形成案例

### 月 11–12：政府合作
- [ ] 接触地方司法局 / 法律援助中心
- [ ] 提交试点方案
- [ ] 建立品牌公信力

### 第 12 月末目标
- 注册用户 ≥ 5000
- 付费用户 ≥ 250
- 月度收入 ≥ 10 万元
- 律师合作 ≥ 5 家
- 媒体曝光 ≥ 1 次行业级
