## Description:

Parma (parma.ai). Use this skill for ANY Parma request — reading, creating, updating, and deleting data. Whenever a task involves Parma, use this skill instead of calling the API directly.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use the skill to read and manage Parma workspace data through their connected account. It supports retrieving records and creating, updating, or deleting relationships, notes, and group assignments.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The setup fallback can run downloaded software without separate approval or a clear explanation of local changes.

Mitigation: Review the installer and CLI behavior, including agent-skill synchronization, before installing. Keep the stated approval requirements for Parma data changes.
