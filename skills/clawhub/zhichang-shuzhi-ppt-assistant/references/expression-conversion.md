# 职场 PPT 表达转换规则

## 基本原则

转换方向:
- 抱怨 → 问题陈述
- 个人诉求 → 组织价值
- 情绪化表述 → 结构化分析
- 模糊目标 → 可验证成果
- 流水账 → 有逻辑链条的叙述
- 专业黑话 → 受众能理解的语言

---

## 规则 1: 抱怨 → 问题陈述

| 原表达 (❌) | 转换后 (✅) |
|---|---|
| 资料很乱，没人管 | 当前资料分散在多个来源，缺少统一沉淀和复用机制 |
| 流程太慢了，卡在审批 | 当前流程存在多节点串行依赖，整体周期较长 |
| 工具不好用 | 现有工具在 XX 场景下存在效率瓶颈 |
| 他们不配合 | 跨团队协作机制尚未建立，存在信息不对齐 |
| 这个需求不合理 | 该需求与当前阶段的核心目标存在优先级冲突 |

---

## 规则 2: 个人诉求 → 组织价值

| 原表达 (❌) | 转换后 (✅) |
|---|---|
| 我想当负责人 | 后续我愿意继续承担该方向的牵头梳理和闭环推进工作 |
| 给我升职 | 当前承担的工作范围和复杂度已超出原有岗位定位 |
| 我要加薪 | 建议根据当前实际贡献范围和产出质量进行岗位价值重新评估 |
| 我不想做这件事 | 该事项与我的核心职责方向存在资源分配上的优先级冲突 |
| 给我更多资源 | 该事项已从单点任务进入体系化推进阶段，建议以项目化机制配置资源 |

---

## 规则 3: 情绪化 → 结构化

| 原表达 (❌) | 转换后 (✅) |
|---|---|
| 这个项目太难了 | 该项目涉及多个复杂模块的耦合，需要在 XX 方面进行专项突破 |
| 完全没头绪 | 当前处于问题定义阶段，需要先完成现状梳理和关键变量识别 |
| 乱成一团 | 当前多个事项并行推进，建议建立优先级分级的推进机制 |
| 我快累死了 | 当前工作强度下，需要关注核心事项的聚焦和交付质量 |
| 真是无语 | 该情况反映出机制层面的持续优化空间 |

---

## 规则 4: 模糊目标 → 可验证成果

| 原表达 (❌) | 转换后 (✅) |
|---|---|
| 提升了效率 | 将 XX 流程从 5 个环节压缩为 3 个环节，单次耗时从 X 降至 Y |
| 优化了体验 | 完成 XX 模块交互重构，关键操作步骤从 N 步减少到 M 步 |
| 建立了体系 | 完成 XX 领域的标准化文档共 N 份，覆盖 M 个场景 |
| 推动了协作 | 建立跨 XX 和 YY 团队的周度对齐机制，累计完成 N 轮 |
| 搞定了XX | 完成 XX 事项的端到端交付，产出物包括 A、B、C |

---

## 规则 5: 流水账 → 逻辑叙述

| 原表达 (❌) | 转换后 (✅) |
|---|---|
| 1 月做了 A, 2 月做了 B, 3 月做了 C... | 从单点执行到体系化推进，分三个阶段完成了从 A 到 C 的演进 |
| 我每天都很忙 | 重点工作聚焦在三个方面: X、Y、Z |
| 做了很多事 | 工作产出集中在三个维度: 问题诊断、方案设计、机制建设 |
| 开了很多会 | 通过 N 轮对齐和 M 次评审，完成了 X 方向的共识构建 |
| 写了很多文档 | 完成覆盖 X 个模块的标准化文档沉淀，形成可复用的知识资产 |

---

## 规则 6: 专业黑话 → 受众可理解

| 原表达 (❌) | 转换后 (✅) |
|---|---|
| 完成 DDD 领域建模 | 用一套系统化方法把业务拆成清晰的模块，让技术和业务对齐 |
| 搭建 CI/CD 流水线 | 建立从代码提交到上线的自动化通道，减少人工出错 |
| 实现 ABC 中台能力 | 把各业务线共用的能力抽出来集中建设，避免重复投入 |
| 完成 OKR 拆解 | 把年度目标分解为每个团队、每个人可执行的行动计划 |
| 建立 DevOps 体系 | 打通开发和运维的协作流程，让变更更快更稳 |

---

## 规则 7: 贬低他人 → 聚焦事实

| 原表达 (❌) | 转换后 (✅) |
|---|---|
| 前任做得太差了 | 接手时该方向存在若干未解决的遗留问题 |
| XX 部门能力不行 | 跨团队协作中存在能力配置上的结构性差异 |
| 他们根本不懂 | 当前决策信息与执行层实际情况存在一定偏差 |
| 这方案是瞎搞 | 该方案在落地条件的评估上需要进一步细化 |
| 没人听我的 | 目前建议传递和决策采纳之间缺少有效的反馈闭环 |

---

## 规则 8: 夸大美化 → 客观务实

| 原表达 (❌) | 转换后 (✅) |
|---|---|
| 行业领先 | 在 XX 维度上达到行业平均水平以上 |
| 颠覆性创新 | 在 XX 环节引入了新的方法，相比原有方式在 YY 方面有改善 |
| 完美搞定 | 完成既定目标，在 XX 方面仍有持续优化空间 |
| 所有人一致认可 | 经 XX 轮评审，方案获得主要相关方认可 |
| 从零到一 | 在原有基础上进行了 XX 方向的系统性建设 |
