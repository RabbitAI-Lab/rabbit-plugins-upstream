# PPT 质量检查清单

## 使用说明

生成 PPT 内容和 PPTX 文件后，逐项检查，12 项全部通过才算合格。

---

## 检查清单

### 1. 是否符合用户真实目的?

- [ ] 每页内容是否服务于最终汇报目标?
- [ ] 是否有偏离目标的冗余页面?
- [ ] 封面和总结页是否准确体现汇报的真实目的 (而非表面目的)?

### 2. 是否针对目标受众?

- [ ] 语言难度是否适合受众? (管理层不要堆技术细节)
- [ ] 关注点是否匹配受众最关心的事?
- [ ] 是否有受众不关心的信息?

### 3. 是否有清晰故事线?

- [ ] 页面顺序是否有递进逻辑?
- [ ] 从第一页到最后一页是否形成完整叙述?
- [ ] 受众能否用一句话概括这份 PPT 的核心信息?

### 4. 是否基于知识库证据?

- [ ] 每条核心观点是否有对应的知识库来源?
- [ ] 是否区分了事实、推论、建议?
- [ ] 是否有未证实的断言被写成事实?

### 5. 是否避免大段文字?

- [ ] 每页文字是否控制在 3 个要点以内?
- [ ] 每条要点是否在 2 行以内?
- [ ] 是否避免了整段叙述型文字?

### 6. 是否每页只有一个核心判断?

- [ ] 每页能否用一句话概括?
- [ ] 是否有多余信息分散注意力?
- [ ] 页面标题是否就是核心判断?

### 7. 是否有图表化表达?

- [ ] 关键页面是否使用了图表而非纯文字?
- [ ] 图表类型是否适合表达本页信息?
- [ ] 图表是否简洁、一目了然?

### 8. 是否避免敏感直白表达?

- [ ] 是否有抱怨式语言?
- [ ] 是否直接表达了个人诉求?
- [ ] 是否贬低了他人或团队?
- [ ] 敏感信息是否用结构化方式替代?

### 9. 是否体现用户能力和价值?

- [ ] 是否有具体成果展示 (不只是做了什么)?
- [ ] 是否有方法论沉淀 (不只是结果)?
- [ ] 是否有个人成长的体现 (不只是工作完成)?

### 10. 是否有明确下一步?

- [ ] 是否有后续行动计划?
- [ ] 是否有明确的待确认事项?
- [ ] 受众看完后知道接下来要做什么?

### 11. 是否能让外行看懂?

- [ ] 专业术语是否有解释或类比?
- [ ] 不熟悉背景的人能否理解核心信息?
- [ ] 图表是否有清晰的标注?

### 12. 是否能让管理者看到价值?

- [ ] 成果是否有量化指标?
- [ ] 价值是否关联到业务目标或组织目标?
- [ ] 管理者是否能据此做出判断或决策?

---

## 快速检查法

如果时间有限，至少过这 5 个核心问题:

1. **一句话测试**: 这份 PPT 能用一句话说清楚吗? (给一个完全不了解你工作的人)
2. **受众视角**: 如果你是受众，翻完这份 PPT 后你会说什么? 会问什么?
3. **证据溯源**: 每个结论都能追溯到知识库中的具体资料吗?
4. **表达审计**: 有没有任何会让受众不舒服的表达?
5. **行动导向**: 看完后知道下一步要做什么吗?

---

## 常见问题与修正

| 常见问题 | 修正方式 |
|---------|---------|
| 文字太多 | 拆分页面，或用图表替代 |
| 逻辑跳跃 | 在前一页末尾加上过渡句 |
| 缺少证据 | 从知识库补充或标记为待补充 |
| 表达过于学术 | 替换为类比或故事 |
| 诉求过于直白 | 转换为组织价值表达 |
| 缺少行动呼吁 | 在总结页明确列出待确认事项 |
| 图表太复杂 | 拆成 2-3 页逐步呈现 |
| 专业术语太多 | 每个术语首次出现时加一句话解释 |
