# PPT 图表建议库

## 使用原则

1. 首选图表而非文字列表
2. 每页最多一个主图表
3. 图表要与本页核心观点直接相关
4. 标注数据来源和口径
5. 对比型图表优先于陈述型图表

---

## 图表类型选择指南

### 按目的选择

| 目的 | 推荐图表 |
|------|---------|
| 展示结构/层级 | 问题树、三维结构图、金字塔图 |
| 展示流程/关系 | 价值闭环图、输入-过程-输出图、泳道图 |
| 展示时间/进展 | 时间轴、甘特图、项目路线图 |
| 展示对比/变化 | 现状-动作-结果表、对比柱状图、前后对比 |
| 展示量化/价值 | 价值映射表、KPI 仪表盘、收益瀑布图 |
| 展示风险/对策 | 风险-对策矩阵、影响-概率矩阵 |
| 展示能力/角色 | 能力矩阵、角色定位图、胜任力雷达图 |
| 展示逻辑/推导 | 金字塔推导图、因果链图、假设-验证表 |

## 图表 1: 问题树

用途: 展示复杂问题的结构化拆解

结构:
```
                          [核心问题]
                              │
          ┌───────────────────┼───────────────────┐
          │                   │                   │
    [子问题 A]           [子问题 B]           [子问题 C]
          │                   │                   │
    ┌─────┴─────┐       ┌─────┴─────┐       ┌─────┴─────┐
    │           │       │           │       │           │
  [根因1]    [根因2]  [根因3]    [根因4]  [根因5]    [根因6]
```

适用场景:
- 述职中展示「我对问题的结构化理解」
- 方案汇报中展示「当前痛点拆解」
- 复盘中的「原因拆解」


## 图表 2: 三维结构图

用途: 展示一个事物的三个关键维度

结构:
```
              [维度三: 机制保障]
                   ╱
                  ╱
                 ╱
  [维度一: 内容体系] ─────────── [维度二: 工具支撑]
```

适用场景:
- 展示系统性建设思路
- 展示能力模型的三个支柱
- 展示方案的三个核心要素


## 图表 3: 价值闭环图

用途: 展示一个有输入-输出-反馈的完整链路

结构:
```
   [问题识别] ──→ [方案设计] ──→ [落地执行]
        ↑                            │
        │                            ↓
   [持续优化] ←── [效果验证] ←── [成果产出]
```

适用场景:
- 述职中展示工作方法论
- 展示持续改进机制
- 项目汇报中展示完整闭环


## 图表 4: 时间轴

用途: 展示按时间顺序的关键事件或阶段

结构:
```
  Q1          Q2          Q3          Q4
  │           │           │           │
  ●───────────●───────────●───────────●
  │           │           │           │
  阶段一      阶段二      阶段三      阶段四
  ├─ 事项A    ├─ 事项C    ├─ 事项E    ├─ 事项G
  └─ 事项B    └─ 事项D    └─ 事项F    └─ 事项H
```

适用场景:
- 述职中展示工作节奏
- 项目规划中展示里程碑
- 复盘中展示关键节点


## 图表 5: 项目路线图

用途: 展示项目从现在到未来的演进路径

结构:
```
  [当前状态] ──→ [Phase 1] ──→ [Phase 2] ──→ [目标状态]
      │              │              │              │
   现状描述        做什么         做什么        目标描述
   关键瓶颈      产出什么       产出什么      达成标准
```

适用场景:
- 规划汇报
- 项目立项
- 晋升答辩中的未来规划


## 图表 6: 现状-动作-结果表

用途: 清晰展示做了什么、为什么做、结果如何

结构:
| 现状问题 | 采取动作 | 取得结果 | 量化指标 |
|---------|---------|---------|---------|
| ... | ... | ... | ... |

适用场景:
- 述职中展示工作成果
- 项目汇报中展示阶段性成果


## 图表 7: 价值映射表

用途: 把产出物映射到业务价值

结构:
| 产出物 | 解决什么问题 | 对业务价值 | 对组织价值 |
|-------|-------------|-----------|-----------|
| ... | ... | ... | ... |

适用场景:
- 述职中展示成果价值
- 方案汇报中展示预期收益


## 图表 8: 能力矩阵

用途: 展示能力覆盖度和深度

结构 (以技能 x 熟练度为例):
| 能力领域 | 入职前 | 当前 | 目标 | 证据 |
|---------|-------|------|------|------|
| ... | ●○○ | ●●○ | ●●● | ... |

适用场景:
- 述职中的能力成长展示
- 晋升答辩中的能力举证


## 图表 9: 风险-对策矩阵

用途: 展示风险识别和应对策略

结构:
| 风险描述 | 影响程度 | 发生概率 | 应对措施 | 责任人 |
|---------|---------|---------|---------|-------|
| ... | 高/中/低 | 高/中/低 | ... | ... |

适用场景:
- 项目汇报中的风险管理
- 方案汇报中的风险分析


## 图表 10: 输入-过程-输出图 (IPO)

用途: 展示一个工作过程的完整链路

结构:
```
  ┌──────────┐    ┌──────────────┐    ┌──────────┐
  │  输入     │ →  │   核心过程    │ →  │  输出     │
  │  Inputs  │    │   Process    │    │  Outputs │
  └──────────┘    └──────────────┘    └──────────┘
  资料/需求         方法/动作          成果/交付物
```

适用场景:
- 方法论展示
- 工作流程说明


## 图表 11: 角色定位图

用途: 展示个人或团队在组织中的定位

结构:
```
        [战略层]  ← 参与方向讨论
           │
        [规划层]  ← 主导方案设计
           │
        [执行层]  ← 带领落地
```

适用场景:
- 述职中的角色定位
- 晋升答辩中的职责范围展示


## 图表 12: 知识库资料提取图

用途: 展示从知识库到 PPT 内容的提取逻辑

结构:
```
  [知识库资料] ──提取──→ [核心观点] ──结构化──→ [PPT 内容]
       │                     │                    │
   原始来源             可追溯标记           面向受众表达
```

适用场景:
- 向用户展示内容来源
- 证据溯源


## 图表 13: 项目闭环图

用途: 展示项目的完整闭环管理

结构:
```
          [目标设定]
              │
      ┌───────┴───────┐
      ↓               ↓
  [计划制定]    [风险识别]
      │               │
      ↓               ↓
  [执行推进] ←── [风险应对]
      │
      ↓
  [成果验收]
      │
      ↓
  [复盘沉淀] ──→ 下一次做得更好
```

适用场景:
- 项目管理汇报
- 工作方法论展示
