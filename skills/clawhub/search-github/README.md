# search-github

A lightweight Brave browser skill for **GitHub**.

## What it does

Search GitHub for repositories, code, issues, or projects matching the user's query.

- Reuses an existing relevant tab/session
- Avoids unnecessary duplicate tabs
- Verifies the destination
- Never handles credentials

## Example triggers

- Search GitHub for MCP servers
- Find GitHub repositories about Python VAPT
