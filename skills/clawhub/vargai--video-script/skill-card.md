## Description:

Write the script for any video before anything is generated: what is said, shown and heard in every beat, sized to the clock and the video model.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators, marketers, and video teams use it to turn a brief and sourced facts into a timed script for ads, demos, reviews, social video, explainers, brand films, and short-form drama, then check pacing and claim sourcing before production.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The checker reads the facts file named in the script header, which could expose unintended project content to review.

Mitigation: Keep drafts, facts, and performance logs in the project folder, and point the facts header only at the file intended for the checker.

Risk: Proposed skill updates could introduce incorrect or misleading guidance.

Mitigation: Review proposed updates before adopting them.

## Skill Output:

**Output Type(s):** [Markdown, Text, Guidance]

**Output Format:** [A Markdown script with header fields, a timed table for spoken lines, on-screen text, visuals and sound, three hooks, and sources; plain-text checker results may accompany it.]

**Output Parameters:** [1D]

**Other Properties Related to Output:** [One script.md per brief; includes a beat-by-beat script and production checks.]
