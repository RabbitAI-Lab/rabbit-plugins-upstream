## Description:

Search Viator tours, activities, attractions, prices, and availability without booking or paying for trips.

This skill is ready for commercial/non-commercial use.

## Publisher:

[chrischall](https://clawhub.ai/user/chrischall)

### License/Terms of Use:

MIT-0

## Use Case:

Travel planners and agents use this skill to find tours and attractions, check product details, prices, and availability, and share booking links for travelers to use themselves.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installing an external package requires trusting its publisher.

Mitigation: Verify that you trust the @chrischall/viator-mcp package before installing it.

Risk: A Viator Partner API key is stored in MCP configuration.

Mitigation: Protect the configuration and avoid sharing or publishing the API key.
