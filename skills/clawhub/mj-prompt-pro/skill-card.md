This skill is ready for commercial/non-commercial use.

## Use Case:

Artists and creators use this skill to turn a theme or existing prompt into a structured Midjourney prompt with visual details, suggested parameters, and distinct variations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts are in English even when the surrounding conversation is in Chinese.

Mitigation: Explain or translate the prompt for the user when needed while keeping the Midjourney prompt in English.
