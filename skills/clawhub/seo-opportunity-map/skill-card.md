## Description:

Recommends five prioritized SEO actions, including which page to update or create and the reason for each.

This skill is ready for commercial/non-commercial use.

## Publisher:

[scrollport](https://clawhub.ai/user/scrollport)

### License/Terms of Use:

## Use Case:

Founders and small teams use this skill to choose practical SEO updates and new pages based on their website, competitor rankings, and optionally Search Console data.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Shortlisted Search Console queries may be shared with third-party services without clear disclosure.

Mitigation: Before using a Search Console export, ask which services receive query data and approve the transfer; exclude sensitive queries.

Risk: The security review is incomplete because some local path-like references could not be resolved.

Mitigation: Review the unresolved references and relevant skill behavior before installing or using the skill with private data.
