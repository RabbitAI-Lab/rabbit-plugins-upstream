## ⭐ 验收基准：`示例-真实翻车-20260912.md`

这是**真实翻过车的那一篇原文**，不是参照它复刻的用例。它已经写进 `selftest.sh`：

> **这篇必须回 `1`。回 `0` 就说明词库或解析被改坏了 —— 拦不住它，这个 skill 就没有存在理由。**

它的价值在于**它专杀修复前的旧版本**：旧脚本对这篇的两个 P0（`免费×2`、`答案+PDF+主页群`）
**一个都拦不住**，会报「✅ 通过」。所以它是防漂移最硬的一道锁。

## 为什么示例里没有手机号

发布前隐私闸门会把**任何 11 位手机号**判为敏感信息 —— 这是对的，哪怕是编的，
因为编的那个号也可能恰好是别人的真号。所以示例文件里不放手机号字面量。

手机号 / 邮箱这两条检查由 `scripts/selftest.sh` 用**字符串拼接**构造出来验证，
仓库文本里不会出现完整的号码：

```bash
FAKE_PHONE="138""0013""8000"      # 拼接，仓库里搜不到完整号码
python3 scripts/preflight.py --body "联系我 ${FAKE_PHONE}"
```
