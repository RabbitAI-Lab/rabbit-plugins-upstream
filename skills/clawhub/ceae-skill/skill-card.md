## Description:

Helps hardware engineers turn fuzzy parameter optimization goals into structured TRIZ group root-cause analysis with quantified targets, first-principles reasoning, key issue lists, Mermaid cause diagrams, and optional PNG exports.

This skill is ready for commercial/non-commercial use.

## Publisher:

[yuanzhian-patsnap](https://clawhub.ai/user/yuanzhian-patsnap)

### License/Terms of Use:

MIT-0

## Use Case:

Hardware product parameter optimization engineers use this skill to parameterize engineering targets, coordinate mechanical, materials, electrical, and manufacturing viewpoints, and produce root-cause analysis outputs for parameters that fail to meet targets.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow can produce engineering conclusions that are incomplete or incorrect if the agent's analysis is accepted without review.

Mitigation: Have qualified engineers review the quantified targets, assumptions, causal chains, and final key issue list before using the conclusions for product decisions.

Risk: Optional Zhihuiya/PatSnap MCP use may expose account-scoped data or depend on external service authorization.

Mitigation: Review the MCP service's account permissions and data scopes before enabling it, and use the skill as an analysis framework when the service is not configured.
