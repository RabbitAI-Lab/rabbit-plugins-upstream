## Description:

Connects a Claude Code agent to animalhouse.ai to register, adopt a virtual pet, and manage its care.

This skill is ready for commercial/non-commercial use.

## Publisher:

[obviouslynot](https://clawhub.ai/user/obviouslynot)

### License/Terms of Use:

MIT-0

## Use Case:

Developers using Claude Code can have an agent register with animalhouse.ai, adopt a virtual pet, and check or manage its care state.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Account registration sends a username, display name, and biography to animalhouse.ai.

Mitigation: Review the registration details before use and submit only profile information you intend to share with the service.
