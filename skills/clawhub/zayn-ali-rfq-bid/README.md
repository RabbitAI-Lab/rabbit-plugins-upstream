# ALI_RFQ_BID() 阿里 RFQ 报价

**Skill ID:** `zayn-ali-rfq-bid`  
**Display Name:** ALI_RFQ_BID()  
**中文名称：** 阿里 RFQ 报价

- 所属项目：WorkFn
- 当前版本：`0.2.0`
- 当前状态：Draft for testing

## 一句话用途

在已经决定参与 Alibaba RFQ 后，生成完整、可提交的平台报价内容，并检查价格、数量、成色、交期、贸易条款、保修和留言的一致性。

## 适用场景

1. 已决定参与某条 Alibaba RFQ
2. 需要生成平台报价字段
3. 需要检查字段和条款一致性
4. 需要判断报价内容是否可提交

## 不适用场景

1. 尚未判断 RFQ 是否值得参与
2. 产品、价格或关键条款无法确认
3. 只需要检查一般报价文件
4. 需要自动提交平台表单

## 输入要求

正式运行前必须检查必填参数，并使用“已命中、部分命中、缺失、冲突、待验证”输出参数状态表。关键参数缺失或冲突时，只能进入初步分析模式并停止正式分析。

## 输出结果

输出参数完整度结论、参数状态表、本 Skill 的专业判断、风险、停止条件和下一步。具体字段以 [SKILL.md](SKILL.md) 为准。
