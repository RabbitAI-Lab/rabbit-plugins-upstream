## Description:

Connect an agent to the separately installed VISTA Desktop MCP for Windows GUI interaction and retrieval of saved visual evidence. Use for desktop applications and system dialogs when a suitable application API is unavailable.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and other agent users can use this skill to guide an agent through Windows desktop applications and system dialogs when a suitable application API is unavailable, and to revisit saved visual evidence from that task.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Desktop control and saved screenshots or notes may expose sensitive on-screen information.

Mitigation: Review the separate MCP before granting desktop access, close sensitive windows, limit actions to the intended task, and manage saved screenshots and notes as potentially sensitive files.
