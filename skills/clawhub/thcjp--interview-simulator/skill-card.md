## Description:

This skill runs customizable mock interviews for different roles and experience levels, including technical, management, HR, and other practice scenarios.

This skill is ready for commercial/non-commercial use.

## Publisher:

[thcjp](https://clawhub.ai/user/thcjp)

## Use Case:

Job seekers, interview coaches, and hiring-practice users use this skill to rehearse role-specific interviews, generate interviewer prompts, and practice responses for different seniority levels.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The release asks for broad read, write, and command execution abilities that are not well scoped to mock interview practice.

Mitigation: Review before installing, run only in controlled environments, and prefer a version that removes exec/write access or requires explicit confirmation before those abilities are used.
