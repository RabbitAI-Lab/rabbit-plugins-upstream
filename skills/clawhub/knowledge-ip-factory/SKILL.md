# 知识IP工坊

知识IP全链路打造技能。将「知识体系梳理 → 定位与差异化 → 内容矩阵规划 → 课程大纲设计 → 变现路径规划」整合为一条流水线，帮专业人士把隐性知识转化为可交付的知识产品。

## 触发条件

当用户表达以下意图时触发本技能：
- "帮我打造知识IP""我想做知识付费""怎么把我的经验变现"
- "帮我梳理知识体系""帮我做课程大纲""规划内容矩阵"
- "我的专业是XX，怎么定位""帮我找到差异化方向"
- 涉及知识体系搭建、课程设计、IP定位、内容规划

## 工作流程

### 阶段一：知识体系梳理

1. 引导用户明确自己的专业领域和核心经验
2. 将用户的知识资产结构化，按以下维度梳理：
   - 核心知识域（硬技能/方法论）
   - 经验案例库（真实项目/解决问题）
   - 独特观点（行业洞察/个人判断）
   - 资源网络（人脉/工具/信息源）
3. 输出知识树图谱，标注每个分支的深度和可产品化程度

### 阶段二：定位与差异化

1. 搜索该领域的竞争格局和热门IP，分析市场空白
2. 按以下维度帮用户找到差异化定位：
   - 人群细分（服务谁？越窄越强）
   - 问题聚焦（解决什么具体问题？）
   - 方法独特性（你的方法论有什么不同？）
   - 表达风格（专业严谨/接地气/数据驱动/故事型）
3. 输出定位一句话：我是谁，帮谁，解决什么问题，用什么独特方法

### 阶段三：内容矩阵规划

按平台特性规划内容矩阵：

**公众号/知乎（深度内容）：**
- 定位：建立专业信任，输出行业洞察
- 内容类型：深度文章、案例分析、方法论拆解
- 发布频率：每周1-2篇
- 目标：积累精准粉丝，建立专家形象

**小红书/抖音（流量内容）：**
- 定位：扩大影响力，触达泛人群
- 内容类型：知识卡片、行业揭秘、趋势解读
- 发布频率：每周3-5条
- 目标：破圈传播，引流到私域

**视频号/B站（信任内容）：**
- 定位：展示人格魅力，建立情感连接
- 内容类型：直播答疑、实战演示、学员案例
- 发布频率：每周1-2次
- 目标：转化付费用户

**播客/社群（粘性内容）：**
- 定位：深度连接，持续激活
- 内容类型：行业对话、学员分享、内部答疑
- 发布频率：每周1次
- 目标：提升复购和转介绍

### 阶段四：课程大纲设计

1. 基于知识体系，提取可教学的模块
2. 按教学逻辑编排课程结构：
   - 痛点引入：为什么你需要学这个
   - 认知重构：纠正错误认知，建立正确框架
   - 方法论：核心方法、步骤、工具
   - 实操演练：案例拆解、实战练习
   - 进阶路径：从入门到精通的成长路线
3. 输出完整课程大纲，含模块名称、学习目标、课时安排

### 阶段五：变现路径规划

1. 根据用户的知识资产和影响力阶段，推荐变现路径：
   - 引流品：免费内容（文章/短视频/直播）
   - 低价品：9.9-99元（小报童/知识星球/训练营）
   - 中价品：199-999元（录播课/社群/咨询服务）
   - 高价品：1000-5000元（训练营/1v1咨询/私教）
   - 旗舰品：5000+元（年度私董会/企业内训/出版）
2. 输出分阶段变现路径图，标注每个阶段的里程碑和收入预估

### 阶段六：输出交付

1. 汇总所有产出，以清晰结构呈现
2. 包含：知识树、定位一句话、内容矩阵表、课程大纲、变现路径图
3. 提供下一步行动建议


## 注意事项

- 知识IP打造需要用户真实专业积累，不凭空编造经验
- 定位建议仅供参考，最终方向需结合用户实际情况调整
- 课程大纲为框架性建议，具体内容需用户自行填充
- 变现预估基于行业平均水平，实际收入因执行力、流量等因素差异较大
- 如果用户未提供专业领域，主动询问以精准服务
