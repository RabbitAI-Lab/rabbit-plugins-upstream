# 课程大纲模板

## 四层课程结构

本技能采用四层课程结构设计，覆盖从吸引到转化的完整链路：

```
试听课（免费/9.9元）→ 入门课（99-199元）→ 进阶课（399-999元）→ 大师课（1999-4999元）
```

## 各层课程定位

| 层级 | 价格 | 时长 | 目标 | 内容重点 |
|------|------|------|------|---------|
| 试听课 | 免费/9.9 | 30-60min | 建立信任，展示价值 | 解决一个具体小问题，给学员"原来如此"的顿悟感 |
| 入门课 | 99-199 | 2-3h | 让学员快速上手，看到效果 | 完整方法论框架，带练1-2个核心动作 |
| 进阶课 | 399-999 | 8-15h | 系统掌握，能独立操作 | 完整方法论+大量案例+实操项目 |
| 大师课 | 1999-4999 | 1-3个月 | 达到行业前20%水平 | 高级技巧+1v1辅导+实战项目+资源对接 |

## 五段式教学逻辑（每节课内部结构）

每节课遵循以下教学逻辑：

1. **痛点引入**（5%）：为什么你需要学这个？用一个真实场景或故事引入
2. **认知重构**（15%）：你之前的理解可能是错的，正确的框架是什么
3. **方法论**（40%）：核心方法、步骤、工具，可操作
4. **实操演练**（30%）：带练一个案例，即时反馈
5. **进阶路径**（10%）：这节课在整体学习路径中的位置，下节课预告
