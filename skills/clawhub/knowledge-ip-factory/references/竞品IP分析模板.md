# 竞品IP分析模板

## 使用说明

在阶段二"定位与差异化"中，使用此模板帮助用户分析竞品IP，找到差异化空间。

### 采集维度

选3-5个对标IP，采集以下信息：

| 维度 | 说明 |
|------|------|
| IP名称 | 账号名称/博主名 |
| 平台 | 主要在哪个平台 |
| 粉丝量 | 各平台粉丝数 |
| 定位一句话 | 他/她是怎么介绍自己的 |
| 内容策略 | 主要发什么类型的内容 |
| 更新频率 | 多久更新一次 |
| 变现方式 | 课程/咨询/社群/广告/带货 |
| 价格区间 | 课程/服务的价格 |
| 核心优势 | 他/她最厉害的地方是什么 |
| 可攻击弱点 | 他/她做得不好或没覆盖的地方 |

## 差异化定位四象限

```
        经验丰富（10年+）
              │
    象限二    │    象限一
   "老法师"   │   "全能王"
  有深度缺传播 │ 有深度有传播
              │
 ─────────────┼─────────────
              │
    象限三    │    象限四
   "小白"     │   "网红型"
  缺深度缺传播 │ 有传播缺深度
              │
        经验浅（<3年）
```

帮用户找到在四象限中的位置，并明确：
- 如果处于象限一：强化专业壁垒，扩大传播
- 如果处于象限二：补传播短板，做短视频/直播
- 如果处于象限三：先积累经验，选定细分赛道
- 如果处于象限四：补专业深度，做课程/案例

## 失败案例警示

### 案例1：定位过宽，谁都抓不住
某职场博主想覆盖"简历→面试→谈薪→职场关系→管理"，结果每个点都讲不深，粉丝觉得"谁都能替代你"。后来聚焦"面试话术"一个点，3个月涨粉5万。

### 案例2：和竞品正面硬刚，差异化不足
某理财博主做"基金定投——年化15%的秘密"，但这个赛道已有10+个同质化IP。后来转向"工资5000怎么攒下第一桶金"的冷启动理财，差异化明显。

### 案例3：只讲方法论，没案例
某产品经理博主输出大量方法论文章，但全是"应该怎么做"的框架，没有自己的真实案例。粉丝留言"你讲的对，但我还是不会做"。加入真实项目拆解后，互动率翻倍。

### 案例4：过早变现，消耗信任
某知识博主粉丝刚过5000就开始卖2999的课程，因内容积累不足，信任度不够，只卖出2份，账号口碑受损。

## 输出格式

完成竞品分析后，输出以下结构：

1. **竞品分析证据表**（3-5个对标IP）
2. **你的差异化定位四象限位置**
3. **定位一句话**（基于差异化分析优化）
4. **竞争壁垒建议**（3个你可以建立的护城河）
