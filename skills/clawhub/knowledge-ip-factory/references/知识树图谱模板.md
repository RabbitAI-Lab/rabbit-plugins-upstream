# 知识树图谱模板

## 输出格式

知识树图谱以三层树状结构呈现，每个节点标注深度和可产品化程度。

```
📚 知识树图谱：{用户专业领域}

├── 🏛 核心知识域（硬技能/方法论）⭐⭐⭐ 产品化潜力：高
│   ├── 子领域1：{具体技能}
│   │   ├── 知识点A → 可产品化：✅ 录播课/训练营
│   │   ├── 知识点B → 可产品化：✅ 1v1咨询
│   │   └── 知识点C → 可产品化：⚠️ 需补充案例
│   ├── 子领域2：{具体技能}
│   │   ├── 知识点D → 可产品化：✅ 知识星球
│   │   └── 知识点E → 可产品化：⚠️ 需实操验证
│   └── 子领域3：{具体技能}
│       └── 知识点F → 可产品化：✅ 小报童专栏
│
├── 📋 经验案例库（真实项目/解决问题）⭐⭐⭐ 产品化潜力：高
│   ├── 案例类型A：{行业/场景}
│   │   ├── 案例1：{简述} → 教学价值：✅ 可作为课程案例
│   │   ├── 案例2：{简述} → 教学价值：✅ 可做拆解视频
│   │   └── 案例3：{简述} → 教学价值：⚠️ 需脱敏处理
│   └── 案例类型B：{行业/场景}
│       ├── 案例4：{简述} → 教学价值：✅ 可做直播分享
│       └── 案例5：{简述} → 教学价值：⚠️ 时效性已过
│
├── 💡 独特观点（行业洞察/个人判断）⭐⭐ 产品化潜力：中
│   ├── 趋势判断：{观点} → 内容形式：深度文章/短视频
│   ├── 方法论创新：{观点} → 内容形式：课程核心模块
│   ├── 行业反思：{观点} → 内容形式：播客对话
│   └── 跨界洞察：{观点} → 内容形式：小红书爆款
│
└── 🌐 资源网络（人脉/工具/信息源）⭐ 产品化潜力：中
    ├── 行业人脉：{可链接的资源} → 变现方式：访谈/合作
    ├── 工具矩阵：{常用工具} → 变现方式：工具测评/教程
    └── 信息渠道：{信息源} → 变现方式：资讯简报/内参
```

## 可产品化程度标注说明

| 标注 | 含义 | 建议动作 |
|------|------|---------|
| ✅ 高 | 已有成熟内容，可直接产品化 | 优先开发为课程/服务 |
| ⚠️ 中 | 有基础但需补充 | 花1-2周整理案例或验证 |
| ❌ 低 | 暂不具备产品化条件 | 列入长期积累计划 |
