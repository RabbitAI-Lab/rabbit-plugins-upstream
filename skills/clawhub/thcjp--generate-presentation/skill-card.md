## Description:

Generates professional HTML and PDF presentations from Markdown, URLs, or topics for file processing, document conversion, and automation workflows.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, teams, and automation users use this skill to turn Markdown, web content, or topic prompts into HTML or PDF presentation outputs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad file, URL-processing, write, and command capabilities may expose sensitive materials or run unsafe local conversion commands.

Mitigation: Use with non-sensitive presentation materials, review commands before execution, restrict file scope, and require explicit approval for network or conversion steps.

Risk: Generated presentations may contain incorrect, outdated, or misleading content from source material or model output.

Mitigation: Review and validate generated slides, citations, and exported PDFs before sharing or using them in business workflows.
