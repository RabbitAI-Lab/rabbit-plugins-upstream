## Description:

Helps agents rewrite email, Slack messages, PR descriptions, review comments, commit messages, and issue replies so the ask comes first and important context remains.

This skill is ready for commercial/non-commercial use.

## Publisher:

[surefirestudios](https://clawhub.ai/user/surefirestudios)

### License/Terms of Use:

MIT-0

## Use Case:

Employees, external users, developers, and agents use this skill to tighten workplace messages while preserving the ask, deadline, blocker, caveat, credit, apology, bad news, cost, risk, and requested detail.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A concise rewrite can accidentally remove or soften facts that matter, such as exact dates, names, commitments, costs, risks, apologies, or bad news.

Mitigation: Review rewritten messages before sending and restore any material detail the recipient needs.
