## Description: <br>
A tool-agnostic workflow for turning video links/files, key frames, user stories, and optional reference posters into evidence-grounded video posters or editable memory journals while preserving provenance, editable structure, archive behavior, and semantic recall. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External users and creative agents use this skill to convert videos, key frames, stories, and optional layout references into evidence-grounded short-video posters, covers, editable memory journals, archive manifests, and recall plans. It is also useful for reference-safe poster adaptation, key-frame redraw planning, collection management, and adversarial quality review. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Archive and recall workflows may store source links, prompts, derived assets, searchable descriptions, and personal stories. <br>
Mitigation: Use only media and stories suitable for the active environment, keep provenance explicit, and rely on the workflow's confirmed deletion path for single or bulk removal. <br>
Risk: Poster or journal copy can become misleading if visual claims, numbers, dates, readable text, or transformation claims are not supported by source evidence. <br>
Mitigation: Use the evidence ledger, NarrativeBrief links, placed-asset checks, and adversarial review gates before treating an output as ready to share. <br>
Risk: The skill may default to Chinese-language outputs or mixed-language terminology when the user does not specify a language. <br>
Mitigation: Specify the desired output language at intake when a non-Chinese deliverable is needed. <br>
