## Description: <br>
拾光册记忆手帐 is a tool-agnostic workflow for turning key frames and source links into redrawn keepsake elements, editable story-led journals, provenance-preserving archives, and semantic recall paths back to the original source or next action. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External users, creators, and developers use this skill to plan, execute, or implement a reusable visual-memory workflow that turns source frames into editable journals, archive records, and recall results. It is useful when an agent must preserve provenance, separate content materials from layout references, and distinguish completed outputs from handoff specifications. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Personal photos, source links, archives, or search indexes may be stored by the current agent while using the workflow. <br>
Mitigation: Confirm storage location, retention, and access before processing private material, and disclose when durable storage or semantic indexing is only a plan. <br>
Risk: Confirmed single or bulk deletion can remove journal records and archive links. <br>
Mitigation: Use stable IDs, show the selected item count and expected archive effects before mutation, require explicit confirmation, and preserve shared assets that are still referenced. <br>
Risk: Optional layout references could be mistaken for approved content or copied too directly. <br>
Mitigation: Keep layout references structurally separate from content materials and transfer only reading path, relative scale, text zones, whitespace, overlap rhythm, and other allowed abstract structure. <br>
