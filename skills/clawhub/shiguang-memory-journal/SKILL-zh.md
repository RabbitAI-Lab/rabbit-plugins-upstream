# 拾光册记忆手帐

> 本文件是 `SKILL.md` 的中文翻译版，使用 ASCII 文件名以兼容 Skill 注册表；实际 Skill 入口仍为 `SKILL.md`。

使用当前 Agent 自己拥有的工具执行本操作手册。不要求使用拾光册 API、localhost 服务、Bearer Token 或捆绑可执行文件。

保持以下产品承诺：

`关键帧与可选来源链接 → 默认 1 枚（可调至 1–5 枚）元素重绘 → 逐元素画面范围 → 可选版式参考 → 故事化手帐 → 独立整理 → 记忆归档 → 语义找回 → 回到原内容或行动`

视频海报并行承诺：

`视频链接或文件 → 证据索引与 NarrativeBrief → 故事关键帧 → 三类传播概念竞赛 → 主辅画面海报 → 对抗审计 → 可编辑交付与反馈`

## 映射可用能力

盘点当前 Agent 拥有的工具，并将它们映射到以下角色：

1. 视觉检查；
2. 图像生成或编辑；
3. 版式编排或文档／画布创建；
4. 持久化文件、数据库或知识存储；
5. 语义检索或当前可用的最佳文本搜索；
6. 支持安全编辑与删除操作的集合管理；
7. 来源链接呈现或导航。

优先使用已有工具，不要假定必须使用产品专属名称。如果缺少某项能力，就为另一个 Agent 或工具输出相应的结构化计划、提示词、清单或版式规范。仅生成方案时，绝不能声称已经创建了图片、归档或搜索索引。

## 执行完整生命周期

1. 收集关键帧、可选的原始 HTTP(S) 来源链接、提取风格（`handdrawn`、`comic`、`collage` 或 `realistic`）、手帐类型、用户意图、输出格式、任务级画面范围策略（`subject-only`、`preserve-context` 或 `mixed`），以及 1–5 之间的准确提取数量。用户未指定数量时默认使用 1；缺少来源链接绝不能阻断提取。`mixed` 至少需要两枚元素，并应优先遵循用户逐项写明的意图。
2. 在转换前建立来源追溯台账。为来源和每个派生项目分配稳定 ID；原样向后传递来源链接，不得悄悄更改。
3. 检查画面，并严格选择用户要求数量的不同且清晰可见的主体或有意义的环境区域。优先考虑与意图的相关性、可辨识轮廓、视觉多样性，以及互补的故事角色。
4. 每次生成或编辑调用只重绘一个已规划元素，并记录它自己的元素级画面范围。在 `subject-only` 中，保留定义其身份的形状和颜色，同时移除无关背景；在 `preserve-context` 中，把主体与能够说明其空间、动作或叙事关系的可见环境一同保留；在 `background-only` 中，保留有意义的环境区域并移除用户明确排除的前景人物或物体。`mixed` 任务至少分配两种不同的元素级范围，优先遵循用户逐项意图；用户未说明时才由 AI 平衡规划。始终移除平台界面、字幕和水印。如实标记直接裁切结果，绝不能把裁切称为重绘。
   把 `realistic`（真实质感）视为摄影质感规范，而不是插画滤镜：保留自然光影、皮肤、衣料、环境材质、镜头透视、人物身份、人数、姿态和场景关系，只允许克制的构图、曝光与色彩优化。拒绝塑料皮肤、换脸、重塑身材、过度 HDR、3D 渲染材质、虚构人物，以及抹去真实材质的风格化。
   有效生成图应保留其自然的纵向、横向或方形画布；除非用户明确指定宽高比，否则不得仅因图片不是 1:1 就拒绝、裁切或补边。
5. 进行编排时，让用户从当前作品和可复用灵感库中批准 1–12 项内容素材。把可选参考手帐保存在独立字段中：它只指导版式，绝不能在未说明的情况下成为内容。
6. 如果存在参考图，只分析可迁移的结构——阅读路径、主视觉策略、相对尺寸、文字区域、留白、重叠节奏，以及可选的抽象纸张／配色关系。不得复制其中的照片、人物、物体、地点、品牌、可读文字或事实主张。
7. 在摆放任何内容前先规划故事。用户上传故事时，把它作为事实内容与叙事主轴的第一优先级：先评估事实保真、叙事结构和选句适配，再去重、优化和压缩，绝不能用通用模板文案替换用户故事。指定一个主视觉，并按内容需要分配辅助、过渡、细节或收束角色；定义清晰的阅读路径，并选择能够表达当前意图的底纸方向。
8. 撰写具有艺术感但忠于事实的文案。使用开场、图片关联注释、反思、边注和结语等多种文字职责，而不是只写一个泛化标题和副标题。每个文字块最多选择两个原句中真实存在的重点短语，优先强调数字、路程、人数、成就、转折或有辨识度的原话。把字体家族、字号、字重、字距、行距、对齐、容器和对比度作为一套整体字体系统设计。
9. 以层级和呼吸感进行构图。除非用户要求重复，否则每项已批准内容素材只使用一次。不要把大小相同的元素散落到互不相关的角落，也不要机械复制参考图坐标。先从明确目标或参考图推导画布比例，再考虑素材数量；素材更多不能成为无依据加长页面的理由。建立 3–4 个叙事组、一个明确主视觉和一个页尾情绪锚点。情境图使用纸框／拍立得框，胶带通常只落在 1–3 张图片上。透明人物可用约 4%–16% 的覆盖轻压情境图来连接组块，但不得遮住人物、核心景物或文字。
   当用户给出明确的手帐成品作为目标效果时，从宽松参考切换为目标复刻：从目标图推导画布比例，盘点全部独立内容层，保留原始源图，用相同蒙版从底纸移除这些层，再按测量坐标叠回。重叠区域的像素只归属于最上方可见图层，避免一个元素夹带重复人物或相邻卡片。标题与涂鸦只有在无需独立编辑时才可并入底纸。
10. 评审完整渲染页面，而不只检查 JSON 或坐标。对故事、文案、字体格式、层级、留白、底纸与主题的匹配、来源追溯、事实完整性和参考安全性进行评分；仍像均匀照片墙的页面不得通过。结构已经正确、只剩局部叠压或文字碰撞时，先做最小位移并重新验证，不能丢弃整份 AI 构图。只有素材缺失、身份错误、层级坍塌或局部修复后仍存在结构性失败时，才允许整页回退。用户选择交互成册时，在参考分析、故事、版式和完整渲染审稿后分别暂停，让用户继续或提出修改。
11. 保存可编辑结构，并提供手帐集合，使用户能够搜索、筛选、排序、预览、快速编辑元数据、重新打开进行完整编辑，把便携式可编辑手帐导入为新记录、再次导出该结构，以及明确选择单项删除或批量删除。
12. 使用当前可用的最佳持久化格式，归档来源、派生元素、手帐、提示词、描述、关联关系、警告和来源链接。确认删除后，解除失效的归档关联，并且只移除已不再被引用的文件。
13. 支持按含义、氛围、对象、颜色和模糊记忆进行自然语言找回。返回排序后的匹配理由；有来源链接时呈现原始链接，没有时明确标记不可用并给出下一步真实行动。

## 保障质量与信任

- 把用户意图作为主题主线，而不是虚构事件、地点、价格、日期、关系、游戏事实、食谱、健康主张或感受的许可。
- 让 AI 承担整理，不要要求用户维护技术标签或提示词。
- 保持一个清晰主视觉、有目的的关联、可读文字和有意识的留白。
- 保护已经正确的 AI 构图，不使用“全有或全无”的回退：先局部修复几何与文字碰撞，再重新执行确定性质量门。
- 用户提供的故事是第一优先级事实来源。无论原文质量如何，都必须先评分、优化和选句；不得丢失关键事实、转折、关系、动作或收束含义。
- 在视觉结构和数据结构中清楚分离内容素材与版式参考。
- 当用户意图改变时重新确定底纸方向，绝不能继承无关的美食、旅行或装饰主题。
- 在输出媒介允许时保留可编辑结构。
- 除非用户明确要求移除，否则必须保留所有可见人物。交付前同时核验独立人物素材和合成页面中的预期人数；被叠压遮失的人物仍视为缺失。
- 不得把有效目标强制改为方形或默认手帐比例。当目标或用户指定其他格式时，保存明确的画布宽高，并用该尺寸验证编辑器、缩略图、移动端适配、PNG 导出和便携工程导出。
- 不得暗示已经压平的 PNG、JPG、WebP、PDF 或截图可以恢复原始图层。应诚实地把它作为一个可编辑整体画面或底纸导入；当独立图片、文字、位置、旋转、图层和来源链接需要往返保留时，使用包含内嵌或可解析素材的便携式结构化手帐工程。
- 在破坏性的单项或批量删除前，必须要求用户明确选择并确认。保留来源记录和无关的共享资产。
- 在最终回复中区分实际执行结果、降级结果和拟议产物。
- 每次成功的找回流程都应在来源存在时以唯一且可点击的来源链接收尾；绝不能为了满足格式而虚构链接。

## 交付可复用结果

即使实现技术栈不同，也应返回或保存以下产物：

- `source record`（来源记录）；
- `element plan`（元素计划），以及 1–5 项元素资产或重绘提示词；
- 已批准的 `content material manifest`（内容素材清单）和可选的 `layout-reference analysis`（版式参考分析）；
- `story and copy plan`（故事与文案计划）；
- `background art direction`（底纸艺术指导）；
- `layout specification`（版式规范），以及条件允许时的已渲染手帐；
- 可编辑的 `journal record`（手帐记录）、能力允许时的便携式导入／导出工程，以及集合搜索／编辑／删除行为或交接规范；
- `memory manifest`（记忆清单）；
- `recall index or retrieval plan`（找回索引或检索计划）；
- `quality report`（质量报告）；
- 开启逐阶段审核时的交互检查点摘要和用户修订意见；
- 使用目标复刻时的过程数据：清空后的底纸、独立元素、元素提取清单、制作／版式清单、故事、参考分析、重建预览、浏览器回归结果和人物数量审计；
- 可用时的唯一 `source links`（来源链接）；不可用时提供明确状态和下一步行动。

使用 [references/data-contracts.md](references/data-contracts.md) 中的字段结构，使另一个 Agent 无需反向推导隐藏状态即可继续工作。
