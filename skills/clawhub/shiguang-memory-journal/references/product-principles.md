# Product principles

## Mission

让回忆与攻略，更好、更美、更方便地被感知、理解和执行。

## Vision

Build a future where people do not need to remember where something was saved. They can describe a scene, mood, color, object, or intention; an agent finds the memory, explains why it matches, and returns them to the original content and real-life action.

## Product promise

Transform already encountered content instead of creating more information:

`关键帧与来源链接 → 元素重绘 → 可选版式参考 → 可编辑手帐 → 独立整理 → 记忆归档 → 语义找回 → 回到原内容或行动`

## Decision rules

1. **Let AI organize.** Do not make the user maintain folders, tags, coordinates, or technical prompts.
2. **Search memories, not exact keywords.** Accept themes, colors, atmosphere, objects, and vague recollections.
3. **Treat beauty as understanding.** Build narrative, hierarchy, breathing room, and purposeful copy rather than a random collage.
4. **Preserve provenance.** Keep the original source URL and source identity on every derived artifact.
5. **Separate reference from content.** A reference may teach composition, but it does not authorize copying its people, images, text, brands, places, or claims.
6. **Keep collections user-editable.** Let people search, preview, quick-edit, reopen, and deliberately remove journals, library items, and memory folders.
7. **Make deletion trustworthy.** Confirm destructive actions, unlink stale relationships, retain shared assets still in use, and prevent deleted records from silently returning.
8. **Return the user to life.** The final action is revisiting, deciding, traveling, cooking, learning, or sharing—not remaining inside the archive.

## Composition guidance

- Use only sources and assets supplied or approved by the user.
- Use the intention as the thematic spine without inventing visits, dates, relationships, meals, or other facts.
- Match paper, palette, captions, and element roles to meaning. Do not place cutouts on an unrelated decorative background.
- Prefer one clear hero, supporting evidence, an emotional or informational rhythm, and a closing line.
- Keep copy close to the image it explains.
- Treat 1–12 approved composition materials as content. Store any optional layout reference separately and never count it as a material.
- Borrow reading path, relative scale, text zones, whitespace, and overlap rhythm from a reference. Borrow abstract paper or palette relationships only when the user explicitly allows it.

## Trust guidance

- Describe a crop as a crop and a generated interpretation as a redraw.
- Surface warnings, missing capabilities, and partial degradation.
- Treat semantic scores as ranking signals, not factual confidence.
- Never imply persistence, backup, image generation, or source verification unless the current agent actually completed it.
- Never delete a journal or archive because it merely disappeared from a filtered view. Use stable IDs, explicit selection, confirmation, and a recorded result.
- Ask before opening source links or taking actions beyond the requested journal workflow.
