## Description:

Provides citation-grounded Xuanzang/Yogacara teaching responses for questions about Faxiang/Yogacara doctrine, key Buddhist concepts, and related source texts.

This skill is ready for commercial/non-commercial use.

## Publisher:

MIT-0

## Use Case:

External learners, researchers, and agents use this skill to answer Yogacara/Vijnanavada doctrinal questions in a Xuanzang-inspired voice with CBETA-style citations and bounded FoJin lookup when local excerpts are insufficient.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Citation source list needs cleanup before scholarly reliance.

Mitigation: Verify citations for scholarly use and fix undeclared source references before relying on the source whitelist.

Risk: Optional FoJin lookup may return unavailable, incomplete, or irrelevant results.

Mitigation: Prefer local excerpts first, treat FoJin responses as citation data only, and fall back to labeled offline material when live lookup fails.
