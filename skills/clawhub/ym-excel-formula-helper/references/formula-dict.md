# 公式词条库 (formula-dict.md)

本库是 ym-excel-formula-helper 的核心资产。收到中文需求后，先按分类检索本库，命中即输出标准答案，保证多次回答一致。未命中再现场构造，并标注「库外场景」。

约定：
- 区域示意用 A2:A100、A:A 等形式，使用时按实际数据区域修改。
- 版本标注：WPS / Excel 2016 为默认兼容写法；365 独占函数（XLOOKUP、FILTER、UNIQUE、LET 等）会单独标注并给旧版替代。
- 本库所有公式均不含小于号字符；不等于类需求改用 `SUM-SUMIF` 减法或 `COUNTA`/`COUNTBLANK` 表达。

---

## 一、查找引用

### 1. 单条件精确查找（值在左、返回列在右）
公式：`=VLOOKUP(查找值, 表格区域, 返回列序号, 0)`
解释：在表格区域首列找查找值，找到后向右数第 N 列返回；末尾 0 表示精确匹配（写 FALSE 亦可）。
坑：返回列序号是相对表格区域从左数的第几列，不是工作表列号；首列必须含查找值，否则 #N/A。

### 2. 反向查找（查找值在右、返回值在左）
公式：`=INDEX(返回列, MATCH(查找值, 查找列, 0))`
解释：MATCH 在查找列定位行号，INDEX 按行号从返回列取数，不受左右顺序限制。
坑：INDEX 与 MATCH 的区域行数必须一致；MATCH 第三参数 0 为精确匹配。

### 3. 多条件查找（两个条件定位一行）
公式：`=INDEX(返回列, MATCH(1, (条件列1=值1)*(条件列2=值2), 0))`
解释：两个等号比较各自生成 TRUE/FALSE 数组，相乘得到仅目标行是 1 的数组，MATCH 找 1 的位置。
坑：这是数组公式，Excel 365 直接回车即可；旧版需 Ctrl+Shift+回车。旧版替代：`=LOOKUP(1,0/((条件列1=值1)*(条件列2=值2)),返回列)`。

### 4. 365 新查找（找不到给自定义提示）
公式：`=XLOOKUP(查找值, 查找列, 返回列, "未找到")`
解释：XLOOKUP 直接指定返回列与找不到时的兜底文本，不要求查找值在首列，也不限制方向。
坑：365 / WPS 新版才有。旧版替代：`=IFERROR(VLOOKUP(查找值, 表格区域, 列号, 0), "未找到")`。

### 5. 模糊区间匹配（按分数/金额档位取等级）
公式：`=VLOOKUP(分值, 档位表, 2, 1)`
解释：档位表首列升序排列，第四参数写 1（TRUE）走近似匹配，返回不大于分值的最大档对应的等级。
坑：档位表首列必须升序，否则结果错乱；精确匹配才用 0。

### 6. 查找不到返回空而非 #N/A
公式：`=IFERROR(VLOOKUP(查找值, 表格区域, 列号, 0), "")`
解释：IFERROR 捕获错误，把 #N/A 换成空文本，便于后续拼接不显示红字。
坑：空文本 "" 与真正的 0 不同，做算术时会把空当 0，做计数时 COUNT 不计入。

### 7. 跨表按表名查找
公式：`=VLOOKUP(查找值, INDIRECT(表名单元格&"!A:B"), 2, 0)`
解释：INDIRECT 把文本表名拼成合法区域引用，表名写在单元格里即可动态切换来源表。
坑：表名含空格或特殊字符时需写成 `'表 1'!A:B`；INDIRECT 是易失函数，大表会拖慢重算。

## 二、条件统计

### 8. 单条件求和
公式：`=SUMIF(条件列, 条件值, 求和列)`
解释：扫描条件列，对等于条件值的行，把对应求和列相加。
坑：条件值与单元格格式要一致，文本型数字匹配不上；条件列与求和列行数需相同。

### 9. 多条件求和
公式：`=SUMIFS(求和列, 条件列1, 值1, 条件列2, 值2)`
解释：多个条件同时满足才计入，参数顺序是「先求和列，后条件对」。
坑：与 SUMIF 参数顺序不同（SUMIF 先条件后求和），混用易填反。

### 10. 忽略空部门求全部门总额
公式：`=SUM(销售额列)-SUMIF(部门列, "", 销售额列)`
解释：先求总额，再减去部门为空的行金额，等价于「只统计有部门的行」。
坑：不要把空部门当成某个部门名；若空部门行本就不该有金额，直接用 `SUM(销售额列)` 即可。

### 11. 单条件计数
公式：`=COUNTIF(条件列, 条件值)`
解释：统计条件列中等于条件值的单元格个数（仅数值与文本，不含错误值）。
坑：统计文本个数时大小写不敏感；统计空单元格用 `COUNTBLANK`。

### 12. 多条件计数
公式：`=COUNTIFS(条件列1, 值1, 条件列2, 值2)`
解释：多个条件同时成立的单元格计数。
坑：各条件区域尺寸必须一致，否则 #VALUE!。

### 13. 统计非空单元格个数
公式：`=COUNTA(区域)`
解释：统计区域内不为空的单元格数量，文本、数字、公式结果都算。
坑：公式返回空文本 "" 也会被 COUNTA 计为「有内容」，造成虚高。

### 14. 统计空白单元格个数
公式：`=COUNTBLANK(区域)`
解释：统计区域内真正空白的单元格。
坑：含公式返回 "" 的单元格不算空白，COUNTBLANK 不计入。

### 15. 单条件求平均
公式：`=AVERAGEIF(条件列, 条件值, 求平均列)`
解释：只对满足条件的数据求平均。
坑：空单元格与文本在求平均时被忽略，不等于 0 计入。

### 16. 条件求最大值（多条件）
公式：`=MAXIFS(最大值列, 条件列1, 值1)`
解释：在满足条件的数据里取最大值；单条件也能用。
坑：MAXIFS 是 365 / 2019 起才有；旧版用 `=MAX(IF(条件列=值1, 最大值列))` 数组公式。

### 17. 统计不重复个数
公式：`=SUMPRODUCT(1/COUNTIF(区域, 区域))`
解释：每个值出现几次，其倒数之和并累加，得到去重计数。
坑：区域含空单元格会除零得 #DIV/0!，先用 `区域` 限定为非空，或外套 IFERROR。

### 18. 文本包含某关键字计数
公式：`=COUNTIF(区域, "*关键字*")`
解释：星号代表任意长度通配，前后都加星号即「包含」。
坑：星号本身要按字面统计时需用波浪号转义，写成 `~*`。

## 三、文本处理

### 19. 提取左侧 N 个字符
公式：`=LEFT(文本, N)`
解释：从文本最左取 N 个字符，汉字按个算。
坑：N 超过文本长度不会报错，只返回全部。

### 20. 提取右侧 N 个字符
公式：`=RIGHT(文本, N)`
解释：从文本最右取 N 个字符。
坑：从右取固定位数是常见需求，但手机号脱敏更适合用 REPLACE。

### 21. 从中间指定位置提取
公式：`=MID(文本, 起始位置, 长度)`
解释：从第几位开始，取固定长度。
坑：位置从 1 起算；位置超出长度返回空。

### 22. 按分隔符切出中间段
公式：`=MID(文本, FIND(":", 文本)+1, FIND("/", 文本)-FIND(":", 文本)-1)`
解释：FIND 定位两个分隔符位置，MID 取中间。
坑：FIND 区分大小写且找不到会 #VALUE!；找不到时外套 IFERROR 兜底。

### 23. 多段文本合并
公式：`=文本1 & 文本2` 或 `=TEXTJOIN("-", 1, A1, B1, C1)`
解释：& 直接拼接；TEXTJOIN 用指定分隔符批量拼，第二参数 1 表示忽略空。
坑：& 拼接时空文本会留下多余分隔；TEXTJOIN 是 365 / 2019 起函数。

### 24. 去除首尾多余空格
公式：`=TRIM(文本)`
解释：删掉首尾空格，并把中间连续空格压成单个。
坑：TRIM 不去除不间断空格（Char(160)），那种要用 SUBSTITUTE 清。

### 25. 清除不可见控制字符
公式：`=CLEAN(文本)`
解释：去掉文本里的换行、制表符等不可打印字符。
坑：CLEAN 不处理普通空格，常与 TRIM 叠加：`=TRIM(CLEAN(文本))`。

### 26. 文本型数字转真数字
公式：`=VALUE(文本)` 或 `=文本单元格*1`
解释：把「看起来像数字」的文本还原成可计算数值。
坑：含千分位逗号或币种符号时 VALUE 会错；先用 SUBSTITUTE 清掉符号。

### 27. 数字补零成固定位数
公式：`=TEXT(数字, "0000")`
解释：把数字格式化为 4 位，不足前面补零，结果为文本。
坑：TEXT 结果是文本，后续要参与运算需再 VALUE 转回。

### 28. 英文大小写与首字母大写
公式：`=UPPER(文本)` / `=LOWER(文本)` / `=PROPER(文本)`
解释：分别转全大写、全小写、每词首字母大写。
坑：PROPER 会把中文标点后的字母也当新词首字母，中文环境慎用。

### 29. 替换指定子串
公式：`=SUBSTITUTE(文本, "旧", "新", 第几次)`
解释：把文本中的旧串换成新串，省略第几次则全部替换。
坑：区分大小写；只换第 N 次时填第 4 参数。

### 30. 手机号/证件脱敏
公式：`=REPLACE(号码, 4, 4, "****")`
解释：从第 4 位起，把 4 个字符替换成星号，保留前后。
坑：REPLACE 按字符位置，位数变化时要先确认原长度。

### 31. 取分隔符前的内容
公式：`=LEFT(文本, FIND("-", 文本)-1)`
解释：FIND 定位分隔符，LEFT 取它之前的部分。
坑：文本没有该分隔符会 #VALUE!，需 IFERROR 处理。

## 四、日期计算

### 32. 两日期相差天数
公式：`=结束日期 - 开始日期`
解释：Excel 日期本质是序列号，直接相减得天数。
坑：结果是文本日期时相减得 0，先用 DATEVALUE 转真日期。

### 33. 计算周岁年龄
公式：`=DATEDIF(出生日期, TODAY(), "y")`
解释：DATEDIF 第三参数 "y" 取整年数，自动忽略不到一年的零头。
坑：DATEDIF 隐藏函数，参数顺序易错；"ym" 取忽略年的月差，"md" 取忽略月日差。

### 34. 取年份 / 月份
公式：`=YEAR(日期)` / `=MONTH(日期)`
解释：分别取出日期对应的年、月数字。
坑：参数是文本日期会 #VALUE!，先转真日期。

### 35. 取某月最后一天
公式：`=EOMONTH(日期, 0)`
解释：第二参数 0 表示当月最后一天，写 1 表示下月最后一天。
坑：常用于「截至月末」的区间判断上界。

### 36. 计算是当年第几周
公式：`=WEEKNUM(日期, 2)`
解释：第二参数 2 表示周一开始，返回该日期在年内的周序号。
坑：不同周起始设置会让同一天归属不同周，团队要统一参数。

### 37. 排除周末的工作日天数
公式：`=NETWORKDAYS(开始日期, 结束日期)`
解释：统计两日期间的工作日，自动剔除周六日。
坑：含法定节假日需传第三参数假期表，否则只排周末。

### 38. 日期加 N 个月
公式：`=EDATE(日期, N)`
解释：返回指定日期往后 N 个月的同日记。
坑：月末 31 号加月可能落到下月，EDATE 会取目标月最后一天。

### 39. 取今天的日期
公式：`=TODAY()`
解释：返回当前系统日期，随打开文件刷新。
坑：TODAY 是易失函数，需要固定值时应粘贴为数值。

### 40. 文本日期转真日期
公式：`=DATEVALUE(文本日期)`
解释：把 "2024-01-01" 这类文本转成可计算的日期序列。
坑：本机日期格式与文本不符会 #VALUE!，可用「分列」批量转换更稳。

### 41. 计算工龄年数
公式：`=DATEDIF(入职日期, TODAY(), "y")`
解释：以入职为起点算到今天整年，即工龄。
坑：TODAY 随系统变，正式档案建议用固定统计日。

## 五、去重排名

### 42. 标准排名（并列占名次）
公式：`=RANK(数值, 数值区域, 0)`
解释：0 表示降序排名，相同值并列同一名次，后续名次顺延。
坑：RANK 在新版建议写 RANK.EQ；升序把 0 改成 1。

### 43. 平均排名（并列不占名）
公式：`=RANK.AVG(数值, 数值区域, 0)`
解释：并列时取名次平均值，例如两个第 2 平均得 2.5。
坑：结果出现小数，展示时要不要小数看需求。

### 44. 中国式排名（并列不跳号）
公式：`=SUMPRODUCT((数值区域>当前值)/COUNTIF(数值区域, 数值区域))+1`
解释：统计严格大于当前值的去重个数再加 1，并列同号、后续不跳。
坑：区域含空或文本会出错，需先清洗。

### 45. 提取不重复列表
公式：`=UNIQUE(区域)`
解释：365 / WPS 新版返回区域内去重后的数组。
坑：旧版无此函数，替代做法用「数据→高级筛选→选择不重复记录」或辅助列标记。

### 46. 取最大值对应的姓名
公式：`=INDEX(姓名列, MATCH(MAX(数值列), 数值列, 0))`
解释：MAX 找最大数值，MATCH 定位行，INDEX 取同行的姓名。
坑：有多个并列最大时只取第一个出现的。

### 47. 取第 N 大值
公式：`=LARGE(数值区域, N)`
解释：返回区域内第 N 大的数，N=1 即最大值。
坑：与 SMALL 对称，别写反。

### 48. 取第 N 小值
公式：`=SMALL(数值区域, N)`
解释：返回区域内第 N 小的数。
坑：区域含文本或空会被忽略，不影响排序。

## 六、多表汇总

### 49. 同结构多表同位置求和
公式：`=SUM(Sheet1:Sheet3!B2)`
解释：三维引用把 Sheet1 到 Sheet3 之间所有表的 B2 相加。
坑：中间插入新表会自动纳入；表名顺序按标签排列不是按创建顺序。

### 50. 多表条件求和汇总
公式：`=SUMIFS(Sheet1!求和列, Sheet1!条件列, 值) + SUMIFS(Sheet2!求和列, Sheet2!条件列, 值)`
解释：逐表写 SUMIFS 再相加，适合表不多的固定汇总。
坑：表很多时公式冗长，可改用 Power Query 或辅助表。

### 51. 按表名动态汇总
公式：`=SUM(INDIRECT(表名单元格&"!B2"))`
解释：表名写在单元格，INDIRECT 拼出区域再求和，下拉可换表。
坑：INDIRECT 易失，数据量大时重算慢；表名带空格要加单引号。

### 52. 多表名称统一汇总到一个总表
公式：`=INDIRECT("'"&$A2&"'!B2")`
解释：A 列放各分表名，公式引用对应分表 B2，下拉逐表取数。
坑：分表结构变动（如 B 列移位）总表会取错，需约定模板固定。

- 用到 XLOOKUP / FILTER / UNIQUE / LET 时，必须附 VLOOKUP+IFERROR 或 INDEX+MATCH 旧版替代。
- 区域用 A2:A100 占位并注明「按实际数据区域修改」。
