# 提问清单（Phase 1：七步成诗 Step 1 陈述问题）

> 源自 `13Mckinsey-七+步+成+诗.ppt.txt` 的「清晰阐述问题的特点」与「问题背景情况 6 要素」。
> 客户上传材料后，先用以下问题锁死问题。**先问后写**，不要一上来就出方案。

---

## A. 主导问题 / 假设（清晰阐述问题的特点）

1. **你要解决的核心问题是什么？** —— 应当是一个具体、不笼统、行动性强的单一主导问题（或可靠性很高的假设），而不是问题的罗列，也不是「无可争议的主张」。
2. **这个问题的最终结论，要驱动决策者采取什么下一步行动？** —— 以决策者下一步所需行动为重点。

## B. 问题背景情况 6 要素（必问）

| # | 要素 | 提问话术 |
|---|---|---|
| 1 | 决策者 | 谁是决策者？还有哪些影响决策者的人？听众是谁？ |
| 2 | 影响决策者的主要因素 | 他们各自关心什么？有无互相冲突的安排会影响决策？ |
| 3 | 时间安排 | 需要多快的答案？关键节点（如「必须 X 月后改善，所以 Y 月前要解决」）？ |
| 4 | 成功努力的标准 | 改革/方案需符合什么使命？何时可实施、可衡量？谁必须支持？ |
| 5 | 主要衡量标准 | 哪些变量衡量成功？决策者如何判断问题被「可行地解决」？ |
| 6 | 所需准确度 | 要强有力的方向指导，还是要精确细致？预算/合规等硬约束是什么？ |

## C. 交付期望

7. **期望对方读完这份交付物做什么？**（批准 / 拨预算 / 调整方向 / 直接执行）
8. **受众与场景？**（董事会汇报 / 项目建议书 / 内部对齐 / 客户提案）——决定用逻辑论证（说服有抗拒心理的听众）还是逻辑组合（给注重措施的听众）。

## 客户答案 → 故事线落点 映射

| 客户回答 | 落到故事线哪里 |
|---|---|
| 主导问题/假设 | 引言「树立主题」+ 金字塔顶层结论句 |
| 决策者/听众 | 引言「说明对听众的重要性」；备注语气 |
| 时间安排/标准 | 结论「明确今后步骤」与衡量指标 |
| 成功标准/衡量 | 每页 So-what 与数据来源脚注 |
| 所需准确度 | 分析深度（Step5 估算数量级 vs 精确模型） |
| 行动号召 | 结论「提建议 + 今后步骤」 |
| 受众场景 | 选逻辑论证 or 逻辑组合；PPT 详略 |
