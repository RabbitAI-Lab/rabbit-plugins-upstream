# 可视化布局目录（50+ 模式 · 麦肯锡资料库顾问）

> 本文件是 PPT 生成的「布局武器库」。每次进入 Phase 3，先用 `layout_selection.md` 的**可解释选型协议**从本目录挑模式、写「布局计划表」，再调用 `assets/pptx_primitives.py` 落地。
> 目标：从「少量布局」升到 **50+ 模式**，对齐渲染派（likaku 65 模式 / AX Labs 40 模板）的版式丰富度，同时保持麦肯锡「一页一念 + 行动型标题 + 脚注来源」的纪律。
>
> 符号约定：SLIDE=13.333×7.5in；左栏 x≈0.55、右栏 x≈6.9、页脚 y≈7.18；正文区 y≈1.6~7.0；强调色默认 RED，主色 NAVY。

## 选型速查（意图 → 模式，供 layout_selection 调用）

- 想**比较谁多谁少** → C1/C2/C20
- 想**看构成/占比** → C6/C7/C8；占比里**再分层级** → **C9 Treemap**（非 Mekko）
- 想**看大类体量+各自结构** → **C10 Mekko**
- 想**看趋势/时序** → C3/C4
- 想**看拆解因果(到终值)** → C8 瀑布
- 想**定位/分类** → D1/D2
- 想**看层级/优先级** → D3 金字塔
- 想**看转化/流失** → D4 漏斗
- 想**MECE 分解问题** → D7/D8/D9
- 想**讲流程/机制** → D10/D11/D12/E8
- 想**对比方案/前后** → E1/D13
- 想**收束行动** → B3/F5/F1
- 想**一个震撼数字** → B1
- 想**一组指标** → B2/C15/C17/C18

> 选型铁律（源自 34 Treemap 案例）：**层级占比用 Treemap，横向大类对比用 Mekko，二者不可混**。任何图必须带「脚注：资料来源」，分项之和≠100% 时主动标 "Figures may not sum to totals, because of rounding"。
