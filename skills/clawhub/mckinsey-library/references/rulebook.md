# 麦肯锡合并文本规则集（守则 + 短语指引）

> 来源：用户提供的 33 份麦肯锡资料，**32 份内容已全量提炼进 skill**（22 运营效率提取失败待修复）
> 逐份应用账本与主题模块见 `functional_playbooks.md`；用途：咨询交付（提问 → 故事线 → PPT）速查守则，每条标 `〔来源〕`
> 读法：每条是一条「可执行的短语」，遇到对应场景直接调用。

## 〇、总纲（三条铁律）
- **以事实为基础、以假设为导向、严格结构化。** 〔08/13〕
- **MECE**：相互独立、完全穷尽，是切分一切议题的铁律。〔08/13/11〕
- **80/20**：先打穿最有杠杆的少数分析，再补其余。〔13/27〕

## 一、问题解决七步（主线）
- **七步成诗**：界定问题 → 分解议题(逻辑树) → 排定优先级(漏斗) → 工作计划 → 关键分析 → 金字塔综合 → 成文。〔13〕
- **逻辑树**：把问题拆成可验证的枝丫，每枝挂一个假设。〔11〕
- **假设驱动**：先有假设再验证，比纯收集快十倍。〔11/13〕
- **系统视角（补）**：动态复杂议题看反馈环与杠杆点，别只做线性拆解。〔21〕
- **企业层思考（补）**：盈利模式 / 产业结构性 / 价值转移 / 情景规划 / KSF。〔24〕

## 二、框架字典（遇到议题先查这张表）
- **战略**：5-Cs、7S、SCP、行业成本曲线、VDS 价值传递、业务系统、EVC、ROE 树。〔08/01〕
- **诊断五法**：价值评估 / 全身扫描(13 模块) / 序列分析 / 任务分析 / OVA-AVA。〔08〕
- **组织**：7S（硬件 Strategy/Structure/Systems，软件 Shared values/Style/Staff/Skills）。〔15doc/15pdf/02〕
- **变革**：Change Board（信念/勇气/承诺/个人能力/组织支持）、Transformation Triangle。〔14〕
- **新人速查**：7S/SWOT/五力/价值链/BCG/GE/情景规划/金字塔。〔05〕

## 三、故事线（SCQA + 金字塔）
- **先写 ghost**：顶层一句核心结论，下分 3–4 条 MECE 关键线，每条有论据。〔28/11〕
- **SCQA**：Situation → Complication → Question → Answer。〔11/28〕
- **行动型标题**：每页标题是「结论句」，不是标签。〔09/28〕
- **金字塔**：分组归类；自上而下(先结论)或自下而上(先数据)综合。〔09/11〕
- **So-what 测试**：每条论据都要能回答「那又怎样」，否则删。

## 四、演讲与沟通

- **交流四步**：设定目标 → 选形式 → 组织内容 → 预期变化。〔09〕

## 十、操作纪律
1. 客户未确认故事线 md，绝不进 PPT 阶段（编排模式除外，但须标注待确认）。
2. 每页行动型标题 + 脚注数据来源（含外部来源）。
3. 框架先用 08 字典，同名框架指向权威定义（7S→15、组织→14、战略→01）。
4. 图表模板优先套风格1/2，保证视觉一致。
5. 22 运营效率待源 PDF 重连后重抽(OCR/CID)补入；运营模块暂以 05(价值链/成本曲线)+21(系统改善) 替代。

## 十一、外部资料搜集与演讲稿（新增能力）
- **主动补证**：内部材料不足时，从逻辑树分支列「证据缺口」，用 08 的 5 类诊断方法（全身扫描/序列分析/OVA/价值评估）指派搜集策略。〔08/13〕
- **以无可争议的内容陈述**：外部证据须一手＞二手＞媒体，关键证据≥2 独立来源三角验证，标口径时点，估算值不伪装精确值。〔28〕
- **从专家处取数**：不轻信大线性计划、不轻信单一来源，联网取数优先一手。〔13〕
- **端到端编排**：获授权可一次性产出「故事线 md + PPT + 演讲稿」三件套，但仍严守故事线先行纪律。〔13/28〕
- **演讲稿**：开场钩子→逐页口播→收尾行动号召→Q&A 预案（预设外部证据口径/来源的应答）。〔28〕

## 十二、长尾职能模块补强（00/01/02/03/04/05/10/12/20/21/24/26/27）
- **思维公理质量门**：MECE 双问(独立？穷尽？) + 顶层 2–5 条(禁"其他事项") + 假设四问(最佳？全？驱动因素？可行可证？)。〔24〕
- **战略**：三轴(在哪/如何/何时竞争)；先诊断不确定性等级再选工具；75% 战略败在施行/能力。〔01/23〕
- **VBM 指标**：ROIC/WACC/EP/NOPLAT/FCF/DCF/NPV，价值树分解 KPI。〔00〕
- **组织变革**：7S 分清通俗版(15)与内部版(02)；HPO 六因素；变革板按人群分层撬动承诺。〔02/14/15〕
- **营销增长**：VDS 三段；有效细分 7 特征；定价三层次(涨价1%杠杆强于销量/成本)；销售力宏观/微观效率。〔03〕
- **大客户(KAM)**：0.06% 客户贡献 37% 利润→先分层再配资源；六步分析法循环往复；信息流前端须闭环。〔20〕
- **系统改善**：六步法PDCA；鱼刺+5why 用数据证伪；五维选型(控制/相关性/资源/回报/认同)；闭环标准化防反弹。〔21〕
- **人才测评**：评价中心效度最高(.65)，非行为面谈最低(.05–.19)；四力12特质。〔12〕
- **团队**：五要素 + 业绩曲线定位(工作组→绩优团队) + 8 条建队法则。〔04〕
- **售前**：RFP 七步(10 天完)、定价市场/成本法、谈判双赢明确禁区。〔10〕
- **工具总表**：BCG/GE/SWOT/五力/SCP/价值链/三层面/IFE-EFE-IE-SPACE-QSPM-CPM + 逻辑树/价值树/七步/Storyline。〔05〕
- **个人效能**：技能三档标尺(理解/特定场合/任何情况)；时间大盗10条对策11条(最重要之事先做/Quiet Hour/学会说不/文件一次处理)；16题自测。〔26/27〕
