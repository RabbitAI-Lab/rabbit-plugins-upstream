# 战略规划专题 Playbook（源自 23 战略规划制定及实施流程研讨会）

> 全部条目逐字核对自 `麦肯锡资料内容存档/23Mckinsey-战略规划制定及实施流程研讨会.ppt.txt`（源 P5–77）。
> 用途：当 engagement 涉及「制定/评审公司或业务单元战略」时，路由到此文件，与 `08` 框架字典、`13` 七步成诗、`28` 故事框架组合使用。

---

## 一、战略规划三步骤流程（P5–9）
1. **公司总部制定 / 确认公司战略**（自上而下定方向、目标、优先顺序）
2. **中心 / 业务部制定部门发展战略**（由负责实施的人主持起草）
3. **质询 / 批准 / 公布战略规划**
- 贯穿全程：**战略议题分析及解决**（发现新问题→组特别工作小组深入调查）

## 二、战略质询会（P45，可直接复用的会议机制）
- **定位**：公司年度最重要管理会议，对各中心/业务部战略逐一质询，确保严谨与可行。
- **时间**：九月上旬，三天，公司以外地点以避免干扰。
- **议程**：总裁介绍总体方向 → 战略发展 VP 介绍总体规划初稿 → 宣布规则 → 各中心呈报并接受质询 → 总结修正要点及时间表 → 总裁闭会。
- **会议规则（可原样写进客户交付物）**：
  - 呈报材料一律投影，按格式**不超过 10 页**；
  - 质询及应答**以事实及数据为基础**；
  - **对事，不对人**；
  - 各中心有质询权，总裁对修正要求有**终决权**。

## 三、三段战略分析法（P15，按规划环节选工具）
| 规划环节 | 分析方法 | 用途 |
|---|---|---|
| 市场环境分析 | **波特「五种力量」**（供应商/进入壁垒/买方/替代品/行业内竞争） | 评行业吸引力与盈利池 |
| 内部竞争力分析 | **SWOT**（优势/劣势/机会/威胁） | 内外结合定位 |
| 战略制订 | **基于价值链的业务模型**（选择价值/提供价值/宣传价值） | 定价值定位与竞争打法 |

## 四、业务单元战略及业务计划 8 节提纲（P19，写战略 PPT 的结构母板）
1. 市场及竞争环境（供应 / 进入壁垒 / 需求 / 替代品 / 竞争态势 / 政策）
2. 内部竞争力分析（SWOT）
3. 战略：
   - 3.1 使命和远景（为何）
   - 3.2 产品和服务组合（何种）
   - 3.3 价值定位
   - 3.4 战略举措优先排序
   - 3.5 成长阶段（何时）
   - 3.6 价值实现和能力获取（如何）
   - 3.7 实施计划
   - 3.8 机会及风险
4. 财务预测（损益 / 现金流 / 敏感性分析）
5. 组织结构要求

## 五、价值定位三环节（P18，价值链模型）
- **选择价值**：理解价值需求 → 选定目标客户群
- **提供价值**：产品与工艺设计 / 采购 / 制造 / 交货收费 / 服务
- **宣传价值**：广告 / 促销及公关

## 六、成长阶梯 / 三层面业务模型（P33–34，GE 模型）
- **第一层面**：核心业务——重点扶持，求高速增长与现金流。
- **第二层面**：新业务——人力财力大量投资，发展新业务。
- **第三层面**：未来机会——小规模投资，开创未来事业机会。
- 公司总体战略需在各层面投资与时间上**平衡、平滑**。

## 七、总部在战略规划中的 4 种角色模式（P13–14）
经营式 / 战略控制式 / 战略建筑师式 / 金融控股式。
- 文档建议：总部职责取决于其在公司管理中的角色；可据「决策重要性/风险/时间限制、机构成熟度、业务业绩、行业动态、相互关联程度」判定采用哪种。

## 八、成功的战略规划 7 要素（P49–58，验收清单）
1. 以经营单位为中心（明确市场定位、掌握关键职能、对利润负责）
2. 效益驱动（目标拔高、价值推动、分红与价值挂钩）
3. 高层领导重视（CEO 是主要推动与指导来源，亲自领导制定、亲自检查）
4. 由负责实施的人来领导制定流程（部门总裁亲自汇报演示）
5. 渗透到组织的各个级别（价值驱动手段推入基层）
6. 依靠完善的数据资料制订与评估（强信息流、年度业绩目标+竞争优势来源+重大举措）
7. 通过真正的对话来进行（质询环境、共同语言、上下对话）

## 九、战略举措优先排序矩阵（P32）
- 纵轴：**实施举措可能的收益**（价值创造 / 协同效应）
- 横轴：**实施难易程度**（技能要求 / 资金要求 / 人员要求）
- 用法：把候选举措放入四象限，优先推进「高收益 × 易实施」，充分关注「高收益 × 难」，最后考虑「低收益 × 易」，等待/放弃「低收益 × 难」。
