# 复盘模板（retrospective）

> 由 meeting-digest-skill 在 retrospective 模式下套用的结构。

```markdown
# 复盘报告 · {项目/周期}

## 进展
- {从各会议结论中提炼的已完成事项}

## 决策
- {本周期内拍板的关键决策}

## 行动项（去重）
- {跨会议合并后的待办，标注负责人/DDL}

## 风险与待决
- {未关闭的风险、需升级的事项，标注待确认}

## 经验沉淀
- {可复用的做法 / 应避免的坑}
```

> 复盘强调「事实-判断分离」：结论标注来源会议，缺失来源的论断标「待确认」，不臆造。
