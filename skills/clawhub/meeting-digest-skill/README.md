# 会议周报 / 复盘自动生成器（meeting-digest-skill）

> **参赛作品 · SkillHub 线上挑战赛（第 1 期）**
> 主题：**让开会更简单** ｜ 基于官方「腾讯会议 Skill（tmeet）」二创

把多场会议的智能纪要、转写稿，自动聚合成**可直接发出的周报**与**可供团队对齐的复盘报告**。让「会后 30 分钟的手工整理」变成「一句话触发、分钟级产出」。

---

## 为什么做这个（差异化）

参赛作品中已有不少「通用会议助手」，但普遍存在两个断层：

1. **有纪要、没人汇总**——单场纪要做得好，跨会议聚合（周报、复盘、行动项去重）仍是手工活；
2. **有结论、缺来源**——自动成文容易编造，本 Skill 强制「来源标注 + 待确认」机制。

本 Skill 聚焦「**会后聚合**」这一被低估的环节，正好命中赛事介绍中点名的「周报、复盘、面试、培训一气呵成」场景中的前两项，与最卷的「实时会议助手」形成错位。

---

## 特性

- ✅ 一句话触发：周报 / 复盘 / 行动项清单 三种形态
- ✅ 对接 tmeet：直接拉取会议列表、智能纪要、转写、会议报告
- ✅ 本地兜底：无 tmeet 时也能处理本地 .md/.txt 纪要素材
- ✅ 跨会议去重：同名行动项合并、重复议题识别、冲突标注
- ✅ 来源可信：缺失证据的结论一律标「待确认」，不臆造
- ✅ 可独立运行：附 `scripts/meeting_digest.py`，纯标准库、零依赖

---

## 环境要求

- 已安装并授权 **腾讯会议 Skill（tmeet）**：OAuth 登录后可使用会议查询、智能纪要、转写等能力（用于「在线模式」）。
- 仅用本地素材模式时：Python 3.8+，无需任何第三方包。

## 快速开始

**在线模式（接 tmeet）**

> 用户：把本周的三场项目会汇总成周报，重点看行动项和风险。
>
> 助手调用 tmeet 拉取纪要 → 提炼 → 跨会议聚合 → 输出周报（行动项按负责人分组，风险标「待确认」）。

**本地模式（无 tmeet）**

```bash
python scripts/meeting_digest.py --input-dir ./notes --mode weekly --output 周报.md
python scripts/meeting_digest.py --input-dir ./notes --mode retrospective --output 复盘.md
```

---

## 辅助脚本 `scripts/meeting_digest.py`

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--input-dir` | 纪要素材目录（.md/.txt） | 当前目录 |
| `--mode` | `weekly`（周报）/ `retrospective`（复盘）/ `actions`（行动项清单） | `weekly` |
| `--output` | 输出文件路径 | `digest.md` |
| `--title` | 报告标题 | 自动按模式生成 |

脚本仅用 Python 标准库，读取素材后按标题层级抽取「结论 / 决策 / 行动项 / 风险」，做简单去重与归并，输出 Markdown。它是 Skill 核心逻辑的**可离线演示实现**，也是「完成度」与「可独立运行」评分的支撑。
