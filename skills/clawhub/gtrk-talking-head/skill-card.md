## Description:

将一条或多条真人口播素材编排为完整视频制作流程，涵盖音轨对齐、粗剪、素材与字卡、音乐、字幕和成片导出。

This skill is ready for commercial/non-commercial use.

## Publisher:

[gitruck](https://clawhub.ai/user/gitruck)

### License/Terms of Use:

MIT-0

## Use Case:

面向视频创作者及其制作助手，用于把一条或多条真人口播毛片整理成可检查、可继续编辑并可导出的完整成片工程。流程根据用户确认选择音轨、B-roll 和包装步骤。

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Cloud processing uploads audio and may incur charges.

Mitigation: Confirm the recording language, use only the intended media folders, and check the quoted estimate before running paid cloud steps.

Risk: Removing source media can leave generated projects with offline files.

Mitigation: Retain the source files needed by the generated projects.
