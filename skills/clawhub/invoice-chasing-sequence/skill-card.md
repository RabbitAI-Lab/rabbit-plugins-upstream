## Description:

Helps US B2B businesses plan invoice follow-ups and prepare account-specific reminders.

This skill is ready for commercial/non-commercial use.

## Use Case:

US B2B service firms, agencies, trades, and wholesale sellers can use this skill to organize invoice follow-ups, review account details, and handle payment questions or disputes.

### Deployment Geography for Use:

United States

## Known Risks and Mitigations:

Risk: The bundled script produces a basic schedule rather than the documented customer-ready drafts and call script.

Mitigation: Prepare and review each customer-facing message separately; do not treat the schedule as a ready-to-send communication.

Risk: Running the script can replace plan.md in the selected output folder.

Mitigation: Choose an output folder where replacing plan.md is acceptable, or preserve any existing file before running.

Risk: The optional Windows toolkit is a separate download and is not covered by the skill's security verdict.

Mitigation: Treat it as a separate software decision and verify it independently before use.
