## Description: <br>
Write a CONTRIBUTING guide that helps people contribute to an open-source project without friction. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[mohitagw15856](https://clawhub.ai/user/mohitagw15856) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and maintainers use this skill to produce a welcoming CONTRIBUTING.md for open-source projects. It helps document setup, contribution workflow, coding standards, PR expectations, and support channels so new contributors can make a first pull request with less friction. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated contributor documentation may include inaccurate project-specific setup, testing, review, or Code of Conduct details. <br>
Mitigation: Review the generated CONTRIBUTING.md against the project before publication, especially commands, testing instructions, review expectations, and community links. <br>
