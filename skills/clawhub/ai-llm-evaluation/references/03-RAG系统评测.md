# 03 RAG 系统评测

> 适用：知识库问答/检索增强生成（RAG）系统的专项评测
> 核对基准日：2026-08

## 1. RAG 评测为什么特殊

RAG = 检索（Retrieval）+ 生成（Generation），质量取决于**两端**：
- 检索端：是否召回正确的知识片段
- 生成端：回答是否忠于召回内容（而非模型记忆/幻觉）

只测"回答好不好看"会漏掉检索问题；只测检索会漏掉生成幻觉。**必须两端一起测**。

## 2. RAGAS 四指标（业界主流框架）

| 指标 | 测什么 | 说明 |
|---|---|---|
| **忠实度 Faithfulness** | 回答是否忠于检索上下文 | 核心指标：回答中的每个论断都应在检索片段中有依据 |
| **答案相关性 Answer Relevance** | 回答是否切题 | 与问题的相关性，不评正确性 |
| **上下文精度 Context Precision** | 检索片段是否相关 | 检索质量：召回的片段有多大比例是必要的 |
| **上下文召回 Context Recall** | 关键信息是否被召回 | 检索完整性：黄金答案依据是否都在检索结果里 |

### 3. 指标优先级建议
- **上线门禁**：忠实度 + 答案相关性（生成端）
- **检索优化**：上下文召回 + 上下文精度（检索端）
- 诊断时先看检索端（召回/精度），再看生成端（忠实度）

## 4. RAG 专项评测集设计

| 用例类型 | 设计要点 |
|---|---|
| 标准问答 | 答案明确在文档中（测忠实度基线） |
| 跨文档问答 | 需要融合多篇文档（测召回完整度） |
| 文档外问题 | 答案不在知识库（测得体拒绝，防幻觉硬答） |
| 相似内容陷阱 | 多个相似文档（测精确召回，防张冠李戴） |
| 长文档深挖 | 答案在文档深处（测检索深度） |
| 时效性问题 | 知识库更新后（测时效与旧版污染） |

## 5. 常见失败模式与诊断

| 现象 | 可能根因 | 查什么指标 |
|---|---|---|
| 答非所问 | 检索召回差 | 上下文召回 |
| 张冠李戴 | 检索精度差/相似文档 | 上下文精度 |
| 一本正经胡说 | 生成没忠于上下文 | 忠实度 |
| 答不完整 | 召回不全/生成截断 | 上下文召回 + 覆盖率 |
| 知识库外硬答 | 拒答策略缺失 | 文档外用例通过率 |

## 6. 评测执行建议
1. **离线评测优先**：固定文档集 + 固定评测集，可重复对比
2. **版本对比**：知识库/Prompt/模型任一变更都跑全套回归
3. **线上补充**：用户反馈/低分会话回流补充评测集
