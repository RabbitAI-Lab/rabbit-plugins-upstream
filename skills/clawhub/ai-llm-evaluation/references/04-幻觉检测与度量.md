# 04 幻觉检测与度量

> 适用：发现、分类、量化 LLM 幻觉——质量评测的核心难题
> 核对基准日：2026-08

## 1. 幻觉分类

| 类型 | 定义 | 示例 |
|---|---|---|
| 事实性幻觉 | 编造事实/数据/人物 | "该产品 2025 年销量 100 万台"（编造） |
| 提示幻觉 | 输出与用户指令/上下文不符 | 用户说摘要，模型却扩写 |
| 上下文矛盾 | 与提供的文档/知识源冲突 | 文档写 A 政策，回答 B 政策 |
| 逻辑幻觉 | 推理链断裂/自相矛盾 | 前后结论不一致 |
| 记忆幻觉 | 混淆训练记忆与实时信息 | 把旧版本信息当现状 |

## 2. 检测方法（三层递进）

### 2.1 自动化检测（快速、覆盖广）
- **规则检测**：数字/日期/引用的格式与一致性检查
- **NLI 一致性**：用蕴含模型判断"回答 vs 知识源"是否矛盾（适合上下文矛盾）
- **检索-回答互证**：回答中的关键论断能否在知识源找到（NLI 或语义相似）
- **LLM-as-Judge**：用强模型判定幻觉（需校准，防判断器自身偏见）

### 2.2 人工抽样（准确、成本高）
- 对自动化判定为"可疑"的样本做人工复核
- 抽检率建议：核心场景 ≥10%，高风险场景 ≥30%

### 2.3 对抗测试（主动暴露）
- 幻觉诱导 Prompt（"请补充细节/编一个案例"）
- 文档外提问（测是否硬答）
- 数字/引用追问（测是否编造）

## 3. 量化指标

| 指标 | 公式/口径 | 说明 |
|---|---|---|
| 幻觉率 | 含幻觉回答数 / 总回答数 | 核心看板指标 |
| 事实错误率 | 含事实错误的回答 / 总回答数 | 细分（数字/日期/名称） |
| 拒绝率 | 得体拒绝数 / 文档外问题数 | 防幻觉的正面指标 |
| 可支持率 | 论断在知识源可追溯的比例 | RAG 场景推荐 |

## 4. 幻觉治理闭环

```
发现（自动+人工） → 分类（哪类幻觉） → 定位（检索/生成/提示）
→ 修复（Prompt/检索/护栏） → 回归（幻觉率对比） → 上线
```

- 幻觉率目标参考：通用场景 <5%，RAG 核心场景 <3%，高合规（医疗/金融）力争 <1%
- 零幻觉不现实，重点是**高危幻觉（误导决策类）趋零**

## 5. 常见误区
1. "LLM-as-Judge 就能完全替代人工"——判断器也有偏见，需校准与抽样复核
2. "幻觉率低就安全"——要看错误影响面，一个高危误导抵得上百个低危
3. "加一句'请勿编造'就行"——提示约束只是第一层，需体系化检测
