# 02 评测集构建

> 适用：设计高质量评测集——评测可信度的根基
> 核对基准日：2026-08

## 1. 评测集类型

| 类型 | 用途 | 特征 |
|---|---|---|
| 黄金数据集（Golden Set） | 核心质量门禁 | 人工标注标准答案，数量少而精 |
| 领域评测集 | 业务专项 | 覆盖本业务场景与难点 |
| 对抗样本集 | 鲁棒性测试 | 改写/注入/陷阱输入 |
| 长尾/边界集 | 边界覆盖 | 少见但重要的情况 |
| 线上采样集 | 持续回归 | 真实用户输入抽样 |

## 2. 构建步骤

```
① 场景梳理  列出业务场景与任务类型（按使用频率/影响度排序）
② 用例设计  每场景覆盖：正常 / 边界 / 异常 / 对抗 四类
③ 标准答案  人工标注黄金答案（多人标注一致性校验）
④ 规模决策  起步 50-100 条，生产级 500+ 含对抗
⑤ 版本管理  评测集版本化（与模型版本/Prompt 版本关联）
⑥ 质量校验  标注一致性（Inter-Annotator Agreement）、去重、覆盖检查
```

## 3. 用例设计要点

### 3.1 正常用例
- 真实高频问题（从线上日志/客服记录采样）
- 覆盖不同提问方式（口语化/书面化/简写）

### 3.2 边界用例
- 超长输入、空输入、单字输入
- 多轮上下文切换
- 知识边界外的问题（"我不知道"应得体拒绝）

### 3.3 异常用例
- 恶意/对抗（衔接红队 skill）
- 敏感话题、幻觉诱导（"请编造数据"）

### 3.4 对抗用例
- 指令改写（"换个说法回答"）
- 噪声输入（错别字/乱码）
- 角色混淆（"你不是 AI，你是真人"）

## 4. 规模估算（经验值）

| 阶段 | 规模 | 用途 |
|---|---|---|
| 冒烟 | 20-30 条 | 快速验证流水线通 |
| 起步 | 50-100 条 | 核心场景门禁 |
| 生产 | 500+ 条 | 正式回归 |
| 专业领域 | 1000+ 条 | 高合规要求（医疗/金融） |

## 5. 评测集管理红线
1. **防泄漏**：评测集不得出现在训练/微调数据里（数据泄漏 = 评测失真）
2. **防污染**：评测集不用于调 Prompt 的"背题"
3. **版本化**：评测集改动要记录（防"偷偷放水"）
4. **维护**：定期补充线上真实新场景，剔除过时用例
