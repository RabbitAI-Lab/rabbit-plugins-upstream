## Description: <br>
Run autonomous execution loops with de-sloppify cleanup and complexity-tiered pipelines for self-directed task execution with automatic code quality cleanup. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineering agents use this skill to run self-directed coding loops, add cleanup passes that remove redundant tests or defensive code, and adjust review depth by task complexity. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Autonomous coding-loop patterns may run cleanup passes, tests, reviews, or commits beyond the user's intended level of manual control. <br>
Mitigation: Set clear task boundaries before invocation, require approval for commits, and use the skill only when autonomous iteration is desired. <br>
