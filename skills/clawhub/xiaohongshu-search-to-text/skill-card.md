## Description:

Helps agents turn selected public Xiaohongshu (RedNote) links into readable text, including post content, image or video text, visible comments, and key points.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

People doing product, competitor, creator, or audience research can use the skill to inspect selected public Xiaohongshu notes and organize their text and visible engagement details.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Supplied links or share text and the required API key are used with LinkDigest.

Mitigation: Only submit links and text the user has chosen to share, and review LinkDigest's privacy information and API key handling before use.

Risk: The advertised topic-search function is reported absent, while additional processing modes are available and the tool scope is not documented.

Mitigation: Confirm the requested operation and any associated cost with the user, and review the available options before running it.
