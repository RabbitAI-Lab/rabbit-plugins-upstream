# 客户分析与转化规范

> 当对1688店铺的客户进行分析、买家问答承接、客服转化话术设计时，必须遵守以下规范。

## 1. 客户分析核心原则

- **数据驱动** — 给建议前优先引导用户提供生意参谋后台的客户数据
- **可执行性** — 每条建议必须具体到操作步骤，不说"优化一下"这种空话
- **不得编造数据** — 没有查到的客户信息不得猜测，标注"暂无数据"
- **事实/推断/缺失三分离** — 结论必须标注来源：已知事实（数据直接证明）/ 合理推断（须写"可能""需确认"）/ 信息缺失（明确缺什么，禁止编造）

## 2. 客户三分类体系

客户分析时先按生命周期分类，不同类型关注点与运营动作不同：

| 客户类型 | 定义 | 运营重点 |
|---------|------|---------|
| 潜在客户（商机） | 有浏览/收藏但未询盘 | 唤醒触达，降低首次询盘门槛 |
| 询盘客户 | 已发起询盘但未成交 | 跟进转化，解决决策顾虑 |
| 已成交客户 | 有历史成交记录 | 复购维护，老客专属价/新品推荐 |

## 3. 转化率诊断规范

### 支付转化率5维诊断

| 维度 | 诊断指标 | 优化方向 |
|------|---------|---------|
| 价格 | 同行比价竞争力 | 阶梯定价/老客优惠 |
| 评价 | 好评数量和质量 | 主动索评/差评48h回复 |
| 有效信息 | 详情页信息完整度 | 补全参数/场景图/视频 |
| 响应速度 | 3分钟回复率 | 设置快捷回复/自动回复 |
| 催付 | 未付款订单跟进率 | 设置催付话术/限时提醒 |

### 跳失率诊断标准

| 指标 | 标准 | 说明 |
|------|------|------|
| 详情页停留时长 | 40-120秒（下限≥40秒） | <40秒说明详情页无法留住买家 |
| 详情页跳失率 | <70% | ≥70%需立即优化详情页内容 |

### 详情页停留时长对标口径

将本店详情页停留数据与**同类目市场均值**对标，量化差距后定优先级：

- **差距计算**：`差距% = (市场均值 − 我的值) ÷ 市场均值 × 100%`，保留1位小数
- **对标维度**：平均停留时长、跳出率、各模块停留占比（主图区/属性区/详情图区/评价区）、UV→详情页转化率
- **优先级判定**：差距 ≥30% → P0紧急；15%~30% → P1重要；<15% → P2微调
- 停留数据必须来自官方接口，严禁虚构或估算；每条调整建议须落到具体操作（如「主图精简至5张」「详情图首屏加工艺对比表」），不说「优化主图」这类空话

### 全链路转化漏斗断裂诊断

诊断转化问题时，按 UV→点击→询盘→支付 全链路逐层核算转化率，定位断裂环节：

| 漏斗层级 | 计算口径 | 断裂判定 |
|---------|---------|---------|
| UV→点击 | 点击数 ÷ 访客数(UV) | 该层转化率低于同类目行业基准 20% 以上 |
| 点击→询盘 | 询盘数 ÷ 点击数 | 同上 |
| 询盘→支付 | 支付订单数 ÷ 询盘数 | 同上 |

- **断裂判定阈值**：单层转化率需低于行业基准 **20% 以上**才标记为「断裂」，避免正常波动误报
- 多层同时偏低时，优先标注**降幅最大**的一层为主断裂点
- 按断裂环节给出对应优化方向：
  - UV→点击断裂 → 优化主图、标题、价格展示、搜索排名
  - 点击→询盘断裂 → 优化详情页内容、提升服务承诺、增加起批灵活性
  - 询盘→支付断裂 → 优化报价策略、提升响应速度、加强信任背书

## 4. 内容输出约束

- 不得夸大效果，不得承诺无法保证的结果
- 不得诱导刷单、虚假评价、虚假资质、虚假销量
- 不能用生硬AI腔，尽量用1688商家和采购沟通的自然表达
- 标题或短句要适合主图、详情页、客服快捷回复直接复制
- 信息不足时使用通用行业逻辑补全，但必须标注"建议补充的信息"

## 5. 客户采购角色识别

分析客户时需识别其采购角色，不同角色关注点不同：

| 采购角色 | 核心关注点 | 话术侧重 |
|---------|-----------|---------|
| 老板 | 利润、品质、长期合作 | 强调性价比和稳定供应 |
| 采购 | 价格、交期、合规 | 给出明确报价和时间节点 |
| 工程师 | 技术参数、认证 | 提供检测报告和技术文档 |
| 档口/贸易商 | 利润空间、一件代发 | 强调批量价差和代发能力 |
| 跨境卖家 | MOQ低、认证齐全、物流 | 明确跨境政策和物流方案 |
| 终端门店 | 现货、快速补货 | 强调库存充足和发货时效 |
| 直播电商 | 高性价比、视觉好 | 强调出图效果和直播返点 |

## 6. 客服接待标准 SOP（B2B 工业品场景）

客服转化话术设计遵循四步标准流程：

```
先问工况 → 再给资料 → 推样品测试 → 留钩子跟进
```

| 步骤 | 操作 | 目的 |
|------|------|------|
| 先问工况 | 确认客户使用场景、需求参数 | 精准匹配产品 |
| 再给资料 | 提供产品参数、认证报告、检测报告 | 建立专业信任 |
| 推样品测试 | 建议取样验证 | 推进决策 |
| 留钩子跟进 | 约定回访时间、发送补充资料 | 保持联系 |

输出话术时每段应包含四要素：**使用场景 / 话术正文（可直接复制）/ 转化目的 / 下一步动作**。

## 7. 卖点输出分场景规范

提炼产品卖点时，必须区分三种使用场景分别输出，不能一套文案到处用：

- 适合放在**主图上**的短卖点（5-10字）
- 适合放在**详情页**的长卖点（20-50字 + 数据支撑）
- 适合**客服回复**的口语卖点（自然表达，非 AI 腔）

## 8. 老客流失识别口径

**禁止把"N 天未下单"直接等同于流失**，必须结合客户自身的复购周期判断：

### 复购逾期倍数（有 ≥3 笔有效订单时优先使用）

基准复购周期 = 相邻订单间隔的**中位数**；`逾期倍数 = 距最近订单天数 ÷ 基准复购周期`

| 逾期倍数 | 判定 | 处理 |
|---------|------|------|
| <1.0 | 尚未到正常复购点 | 不列入唤醒，避免过度打扰 |
| 1.0~1.3 | 轻度风险 | 可做补货提醒 |
| 1.3~2.0 | 明显沉睡 | 进入重点分析 |
| 2.0~3.0 | 深度沉睡 | 需要更强价值钩子 |
| >3.0 | 长期流失 | 仅客户价值高且无负面风险时尝试 |

### 无复购周期数据时的默认窗口

| 未下单时长 | 判定 |
|-----------|------|
| 30-45天 | 补货预警 |
| 46-60天 | 轻度沉睡 |
| 61-90天 | 重点流失风险 |
| 91-180天 | 深度沉睡 |
| >180天 | 仅保留高价值客户，低压力重新建联 |

季节性产品必须结合去年同期订单判断，不得只按天数下结论。

## 9. 老客流失归因分类与置信度

对流失客户归因时，**最多输出 2 个主要原因**，不得堆砌所有可能性：

| 归因类型 | 典型证据信号 | 策略要点 |
|---------|-------------|---------|
| 价格敏感型 | 多次询底价/比价、报价后停回 | 先问数量规格再给阶梯方案，不给无条件折扣 |
| 服务/售后不满型 | 错发/质量/交期投诉记录、末次聊天停在赔付 | 先承认问题与改进措施，未结案前不推新品优惠 |
| 缺货/交期流失型 | 询问时无货、交期多次不满足 | 核实库存交期后再联系，提供替代款/预留方案 |
| 新品偏好/不匹配型 | 频繁索样、单品不断更换 | 用新品内测/测款切入，说明与旧款具体差异 |
| 自然遗忘/补货周期型 | 合作顺畅无负面、仅超周期 | 从盘点/补货节奏切入，低压力提醒 |
| 季节/市场变化型 | 同期采购集中、当前非旺季 | 对齐客户销售节点，淡季不强推 |
| 资金/库存压力型 | 表示库存未消化、询小批量混批 | 提供小单补货/分批交付，不施加下单压力 |
| 原因未知 | 无足够证据 | 明确标注无法确定，用诊断型话术先询问现状 |

归因必须标注置信度：**高**（≥2 个独立证据支持）/ **中**（仅 1 个强证据或多个弱证据）/ **低**（仅凭时间与品类推测）。只有订单数据无聊天记录时，置信度最高只能标"中"。

## 10. 老客唤醒策略与跟进节奏

### 价值优先，不优先打折

唤醒权益按以下顺序选择，价格优惠仅在商家确认毛利空间和优惠权限后使用：

1. **信息价值**：补货提醒、畅销规格、交期变化、材料升级
2. **服务价值**：优先排单、混批建议、包装建议、样品确认
3. **商业价值**：阶梯价、运费支持、样品费抵扣、组合采购
4. **价格优惠**：未确认权限时不得擅自承诺折扣/免运费/最低价

### 话术约束

- **一条消息只推动一个动作**（单一 CTA），不得同时要求看新品、报数量、确认地址、立刻下单
- 优先使用已知称呼（王总/李经理），称呼未知用"您好"，不得猜姓氏职位
- 禁用"在吗""亲""最后一天""不买就没了"等廉价或施压表达
- 不得虚构库存、紧迫感、折扣、样品、交期、认证

### 三轮跟进节奏

| 轮次 | 时点 | 内容 |
|------|------|------|
| 第1轮 | 首次触达 | 价值触达，争取一个低门槛回复 |
| 第2轮 | 2-4 个工作日后 | 只补充一个新价值（参数对比/交期/样品照），禁止重复催促 |
| 第3轮 | 再 5-7 个工作日后 | 礼貌收口，保留后续入口；仍无回复则 30 天内不再营销触达 |

### 退出信号（存在任一即不输出营销话术）

客户已明确拒绝/拉黑、聊天中明确表示不再联系、存在未解决重大投诉或赔付争议、已转行或品类永久停采。

## 11. 询盘意图分类与报价承接

按买家首条消息信号快速分类，采用对应首回应目标：

| 买家类型 | 信号 | 首回应目标 |
|---------|------|-----------|
| 比价型 | 只问价格/最低价 | 反问数量规格，给阶梯价 |
| 索样型 | 问样品/质量证明 | 说明样品价、周期、运费 |
| 定制型 | 问 logo/尺寸/包装/图纸 | 确认定制文件、MOQ、打样与交期 |
| 急单型 | 问交期/现货 | 先核库存与最近发货日，再承诺 |
| 大单型 | 问长期合作/大批量 | 给阶梯报价并询产能匹配问题 |
| 技术型 | 问材质/型号/公差 | 先问使用场景与所需参数 |
| 模糊型 | 消息短或含糊 | 只问一个简单问题推进对话 |

### 阶梯报价结构（禁止在数量不明时只报单一价格）

报价应覆盖：MOQ / 数量阶梯 / 样品费 / 打样周期 / 大货交期 / 包装 / 税费与运费 / 报价有效期。

### 跟进时点

- 询了价格不回复 → 2-4 小时后跟进
- 索要样品 → 发样品政策后跟进一次，样品签收后再跟进
- 嫌贵 → 提供材质/包装/数量/付款方式替代选项，不与买家争辩
- 未核库存或产能前，不得承诺交期
