# 竞品分析规范

> 当对1688竞品店铺/商品进行分析、背景调查、对标研究时，必须遵守以下规范。

## 1. 竞品选择标准

竞品必须满足以下相似性条件，否则对比无意义：

- 价格段相近（±30%区间内）
- 风格相似
- 材质相近
- 主营类目一致

**禁止**将不同层级/不同品类的店铺作为竞品对标。

满足相似性条件的候选竞品较多时，按以下优先级选取：

| 优先级 | 选择条件 | 原因 |
|--------|---------|------|
| 1 | 评价好 + 销售额高 | 代表市场验证过的成功模式 |
| 2 | 同类目前 3 名 | 代表头部竞品水平 |
| 3 | 价格区间相近 | 确保定价参考有效 |
| 4 | 同规格/同材质 | 确保参数对比有效 |

## 2. 竞品8维分析框架

对每个确认的竞品，可以从以下8个维度完整分析：

| 维度 | 分析内容 | 数据来源 |
|------|---------|---------|
| SKU价格 | 价格带分布、起批量、阶梯价 | 竞品商品页 |
| 主图详情 | 首图构图、详情页结构、视觉风格 | 竞品商品页 |
| 评价 | 好评数量、差评痛点、评价质量 | 竞品评价页 |
| 物流 | 发货时效、包邮策略、物流合作方 | 竞品商品页 |
| 起批量 | MOQ设置、是否支持一件代发 | 竞品商品页 |
| 销量 | 月销/总销/成交笔数 | 竞品商品页 |
| 复购率 | 老客占比、回购周期 | 需推断或流量指数 |
| 活动 | 参与了哪些平台活动 | 竞品店铺首页 |

## 3. 竞品流量估算公式

```
竞品日均访客 ≈ 流量指数 × 对应倍数
```

| 流量指数区间 | 倍数 |
|-------------|------|
| >15万 | ×0.03 |
| 10-15万 | ×0.02 |
| 7-10万 | ×0.015 |
| <7万 | ×0.01 |

> 注意：此为估算值，实际误差可达±30%，仅用于量级判断。

## 4. 竞品背景调查（10维框架）

当需要深度竞品调查时，按以下10维框架执行：

| 维度 | 核心问题 | 输出 |
|------|---------|------|
| 企业身份核验 | 公司是否真实存在？ | 公司档案、经营状态 |
| 1688店铺画像 | 店铺在平台表现如何？ | 类型、主营、运营信号 |
| 产品与类目结构 | 卖什么？与我方匹配？ | 产品线、价格带、SKU结构 |
| 经营规模线索 | 公司大概什么规模？ | 员工、招聘、渠道信号 |
| 供应链/交付能力 | 有无真实交付能力？ | 工厂/贸易/仓储/认证 |
| 线上资产与流量 | 线上获客能力如何？ | 官网、社媒、平台矩阵 |
| 决策人/联系人 | 谁可能影响合作？ | 老板/采购/运营线索 |
| 信用与风险 | 有哪些风险？ | 异常、司法、投诉、舆情 |
| 合作价值评分 | 值不值得跟进？ | A/B/C/D分层 |
| 跟进策略 | 下一步怎么打？ | 话术、触达方式 |

## 5. 证据分级标准

竞品调查中的每项信息必须标注可信度等级：

| 等级 | 可信度 | 来源示例 | 报告写法 |
|------|--------|---------|---------|
| A | 高 | 企业官网、1688店铺公开页、官方认证 | `已核验` |
| B | 较高 | LinkedIn、招聘平台、主流媒体 | `平台公开信息显示` |
| C | 中 | 行业目录、第三方平台、社媒 | `第三方公开线索显示` |
| D | 待核验 | 单一网页、过期页面、用户转述 | `待人工核验` |

## 6. 竞品分析禁止事项

- **禁止编造**：未查到的信息写"暂未找到"，不得用经验填充
- **禁止猜测联系方式**：电话、微信、邮箱不得猜测
- **禁止伪造来源**：不能为了让报告好看而虚构数据
- **禁止把估算当事实**：营收、交易额等没有来源时不得写确定值
- **禁止把"没有查到"写成"没有风险"**

## 7. 竞品价值评分

| 总分区间 | 等级 | 结论 |
|---------|------|------|
| 85-100 | A级 | 强竞争对手，需重点关注和差异化 |
| 70-84 | B级 | 中等竞争，部分维度有借鉴价值 |
| 55-69 | C级 | 弱竞争，非直接对手 |
| 0-54 | D级 | 不构成实质竞争 |

## 8. 竞品分析输出要求

- 必须输出竞品对标表格，横向对比自身与竞品各维度数据
- 差距明显的维度标注为「机会点」或「威胁点」
- 输出可执行的差异化建议（≥3条）
- 禁止只输出数据不输出结论

## 9. 严禁侵权规则

- 竞品数据仅作为参数/规格/定价的**参考锚点**
- 主图、详情页素材**不得建议直接复制竞品图片**
- 竞品文案可作为结构参考，但不得照搬原文

## 10. 竞品数据不足时的处理

- 竞品无阶梯报价时：参考同类目 3 家以上均价取中位数
- 竞品无某维度数据时：可结合本店同类商品数据推算
- **数据缺失必须在报告中标注“竞品数据不足，以下为推算值”**，与第 6 节“禁止把估算当事实”配合执行

## 11. 竞争对象三级划分

建立竞争候选时，按**同类目 + 同定位关键词 + 相近采购场景**筛选，再分层：

| 竞争层级 | 定义 | 应对侧重 |
|---------|------|---------|
| 直接竞品 | 价格带、MOQ、规格、定制能力接近 | 逐维度对标，重点防御 |
| 流量竞品 | 抢占同一批定位关键词流量 | 关键词与内容层面对比 |
| 能力竞品 | 交期/服务/定制能力更强 | 能力补强或差异化定位 |

**禁止仅因标题包含同一个词就认定为直接竞争对手**；不得把不同类目、不同采购场景的商家列为直接竞品。

### 关键词定位分层

分析竞品/本店流量关键词时区分两类定位，**不得把高流量词自动等同于高价值定位**：

- **引流定位**：只有流量而无询盘/成交贡献的词
- **经营定位**：有询盘或成交贡献的词，才是真正的主定位词

## 12. 竞品动作归因与预警分级

监测到竞品变化时，先区分动作性质再下结论，**不得把一次变化当长期趋势**：

| 动作类型 | 特征 | 应对思路 |
|---------|------|---------|
| 短期促销 | 限时活动/节日优惠 | 观察为主，不盲目跟价 |
| 结构性降价 | 价格带持续下移 | 评估成本与定位影响，再定是否跟进 |
| 新品增长 | 新品流量/成交持续上升 | 分析其卖点差异化空间 |
| 能力升级 | 交期/定制/服务变强 | 评估自身承接能力差距 |
| 内容调整 | 主图/详情页/标题改版 | 仅借鉴结构，不抄素材 |

预警按**影响程度 × 紧迫度 × 可信度**分为红（立即应对）/ 黄（持续观察）/ 蓝（备案），每条预警须附证据来源。

应对动作只从五类中选：保持 / 跟进 / 差异化 / 测试 / 止损；**禁止建议自动降价跟价**，且单次分析只报告当前状态，不得声称已启动持续监控。

## 13. 市场同款对标样本规范

做同款市场价格/内容对标时，样本必须满足：

- **样本量**：候选 8~20 个，有效同款 5~10 个，最低 3 个；少于 3 个只输出“有限样本观察”，不得下确定性结论
- **有效同款条件**（至少符合 4 项）：用途相同 / 产品形态相同 / 材质接近 / 目标采购人群相同 / 规格相近 / 价格带相近 / MOQ 接近 / 定制能力接近 / 交付方式接近
- **必须排除**：不同用途/形态、只卖配件、不同规格造成的虚假低价、已下架失效、重复商品、明显零售款
- **价格标准化**：比较前必须对齐规格、数量、单位、材质、包装、含税情况、运费、样品价；无法标准化时不直接判断高低

对标结论必须回答：买家主要在比什么、主流同款在强调什么、本店商品遗漏了什么、哪些市场做法不值得跟随、哪些真实能力可以放大。
