# IEEE quick reference

## Text citations

| Situation | Form |
|---|---|
| Single | ... as shown in [1]. |
| Multiple | [1], [3]-[5] |
| Naming the authors | Smith et al. [2] showed ... |
| Before punctuation | ...network [2]. |

## References list templates (numbered in citation order)

| Type | Template |
|---|---|
| Journal | `[1] A. A. Author, "Title of paper," Journal Name, vol. x, no. x, pp. xx-xx, Month Year, doi: 10.xxxx/xxxxx.` |
| Book | `[2] A. A. Author, Title of Book, xth ed. Place: Publisher, Year.` |
| Chapter | `[3] A. A. Author, "Chapter title," in Book Title, E. Editor (Ed.). Place: Publisher, Year, pp. xx-xx.` |
| Conference | `[4] A. A. Author, "Title," in Proc. Conf. Name, City, Year, pp. xx-xx.` |
| Web | `[5] A. A. Author. "Page title." Site Name. URL (accessed Month Day, Year).` |
| Standard | `[6] IEEE Standard for X, IEEE Std 1234-2024, Year.` |

## Signature rules

- Authors: initials first, surname last: `A. A. Author`. No comma between initials and surname.
- 6+ authors: first author + `et al.`
- Paper/chapter titles: double quotation marks. Journal/book titles: italics.
- Abbreviations: `vol.`, `no.`, `pp.`, `ed.`, `Proc.`
- `doi: 10.xxxx/xxxxx` (lowercase, no https).
- Web access date: `(accessed Month Day, Year)`.
- List order: by first citation in the text, never alphabetical.
- Entries begin with the bracket number: `[1]`
