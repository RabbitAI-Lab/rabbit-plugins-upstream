## Description: <br>
Helps backend and platform teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, backend teams, developer-experience teams, and API maintainers use this skill to turn OpenAPI or Swagger documentation requests into practical workflows, checklists, validation steps, and implementation support. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad activation wording may invoke the skill for adjacent API documentation tasks where the fit is uncertain. <br>
Mitigation: Review when it is invoked and confirm the request is about OpenAPI, Swagger, REST API documentation, or related developer-experience work. <br>
Risk: Suggested code, commands, or documentation edits may be incomplete or inaccurate for the user's API implementation. <br>
Mitigation: Review generated changes and run the suggested validation steps before applying them to production documentation or code. <br>
