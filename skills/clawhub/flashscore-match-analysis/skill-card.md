## Description:

Build a sourced Flashscore match report from covered player statistics, lineups, absences, momentum, box scores, point-by-point or darts feeds, and editorial coverage. Use for detailed event analysis; use multi-sport-match-research for basic fixture and score checks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[crawlora-org](https://clawhub.ai/user/crawlora-org)

### License/Terms of Use:

MIT-0

## Use Case:

External users can create a source-grounded report about one Flashscore event, using covered match statistics, lineup or absence listings, scoring feeds, momentum, or editorial coverage.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Searches and event identifiers are sent to Crawlora, and requests may use account credits.

Mitigation: Avoid including sensitive information in searches and review Crawlora's usage information before making requests.
