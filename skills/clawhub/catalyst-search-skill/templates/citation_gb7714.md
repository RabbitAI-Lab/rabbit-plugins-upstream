# GB/T 7714 引用格式示例（模板） | GB/T 7714 citation format (template)

> 输出文献列表时，引用格式优先采用 GB/T 7714。DOI 优先于 URL。
> When outputting a reference list, prefer the GB/T 7714 format. DOI takes priority over URL.

## 期刊论文 | Journal article
```
[序号] 作者. 题名[J]. 刊名, 出版年, 卷(期): 起止页. DOI.
[No.] Authors. Title[J]. Journal, Year, Vol(Issue): pages. DOI.
```
例 | Example:
```
[1] Chen Y, Huang Z, Yu J, et al. Research progress of Pt-based catalysts toward cathodic oxygen reduction reactions for proton exchange membrane fuel cells[J]. Catalysts, 2024, 14(3): 1-20. https://doi.org/10.3390/catal14030150
```

## 会议 / 团体标准 | Conference / group standard
```
[序号] 标准编号 标准名称[S]. 发布年.
[No.] Standard No. Standard Name[S]. Year.
```
例 | Example:
```
[2] T/CASMES 400—2024 质子交换膜水电解制氢阳极催化剂 测试方法[S]. 2024.
[3] T/CRES 0030—2025 质子交换膜水电解制氢膜电极测试方法[S]. 2025.
```

## 专利 | Patent
```
[序号] 申请人. 专利名: 专利号[P]. 公告年.
[No.] Applicant. Patent name: Patent No.[P]. Year.
```
例 | Example:
```
[4] 中汽创智科技有限公司. 一种金属间化合物电催化剂的制备方法: CN117438602A[P]. 2024.
```

## 著录要点 | Key rules
- 作者超过 3 人，仅列前 3 人后加 "et al."
  - More than 3 authors: list first 3 then add "et al."
- 英文作者姓前名后（如 Chen Y）；中文作者全名
  - English authors: surname first (e.g., Chen Y); Chinese authors: full name
- DOI 优先于 URL；无 DOI 时给官方链接
  - DOI over URL; if no DOI, give the official link
- 期刊名用标准缩写或全称，全文保持一致
  - Use standard abbreviation or full name for journals consistently throughout
