## Description: <br>
Helps AI-agent users, skill authors, maintainers, and teams create ontology-style workflow plans, checklists, analyses, artifacts, code changes, and decision support for productivity work. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>

## Use Case: <br>
External agent users, skill authors, maintainers, and teams use this skill to turn requests about ontology-style productivity workflows into practical plans, templates, checklists, analyses, implementation support, or adjacent skill ideas. It emphasizes clear assumptions, local-hardware-friendly execution, and validation against the user's success criteria. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad implicit invocation and generic trigger keywords may cause the skill to handle unrelated knowledge, graph, workflow, creation, or bug-fix requests. <br>
Mitigation: Invoke the skill explicitly for ontology-style productivity workflow work, or narrow its triggers before deployment in environments where unrelated requests should be routed elsewhere. <br>
Risk: Generated plans, checklists, code changes, or implementation support can be incomplete or mismatched to the user's actual constraints. <br>
Mitigation: Review outputs against the stated success criteria, assumptions, limits, and remaining risks before using them for operational changes. <br>
