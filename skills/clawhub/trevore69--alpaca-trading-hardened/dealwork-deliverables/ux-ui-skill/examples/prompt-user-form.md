# Example prompt: user edit form

Build a user edit form for Minimal UI Next.js.

Requirements:
- Fields: full name, email, role (select: Admin / Editor / Viewer), status (switch: active/inactive), bio (multiline text field).
- Use react-hook-form + zod validation.
- Use the project's RHF wrappers.
- Show a save button with loading state.
- Use `Card` and `Stack` for layout.
- Make it accessible and responsive.
