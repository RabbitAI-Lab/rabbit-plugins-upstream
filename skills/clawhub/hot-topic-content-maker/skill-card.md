## Description:

Turns a trending topic into a brand-relevant social post with cover artwork, caption, and hashtags, with an optional narrated short video.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Social media marketers and brand teams use this skill to connect timely topics to their account, choose a suitable angle, and produce a publishable post. Optional paid trend lookup and video generation can support the workflow.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The shared local Device Token can authorize Beatra tools that spend credits.

Mitigation: Install only if you trust Beatra with this credential; review prices and confirm each paid step before proceeding.

Risk: Automatic updates can replace skill files after installation without separate approval.

Mitigation: Review the skill before installation and disable automatic updates with the documented update --auto off command if every package change needs explicit approval.
