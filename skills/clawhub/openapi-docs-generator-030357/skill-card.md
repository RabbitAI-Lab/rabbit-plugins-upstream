## Description: <br>
Helps developers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs through a repeatable workflow, checklist, implementation guidance, and verification steps. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, backend teams, developer-experience teams, and API maintainers use this skill to turn REST API documentation requests into actionable OpenAPI/Swagger guidance, reusable checklists, code or configuration changes, and validation steps. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger examples and implicit invocation can cause accidental activation outside explicit OpenAPI, Swagger, REST API schema, or API documentation tasks. <br>
Mitigation: Narrow and repair the trigger wording before deployment so activation is limited to the documented API-documentation use cases. <br>
