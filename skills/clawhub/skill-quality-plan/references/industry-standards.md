# 通用制造行业标准参考

## 概览

本文件汇总通用制造行业常用的质量管理标准体系及其关键条款，供智能体在生成质量计划时参考和映射。

## ISO 9001:2015 关键条款映射

### 条款4: 组织环境
- 4.1 理解组织及其环境
- 4.2 理解相关方的需求和期望
- 4.3 确定质量管理体系的范围
- 4.4 质量管理体系及其过程

**质量计划对应模块**: 1(产品概述)、3(组织结构与职责)

### 条款5: 领导作用
- 5.1 领导作用和承诺
- 5.2 质量方针
- 5.3 组织的角色、职责和权限

**质量计划对应模块**: 2(质量目标与KPI)、3(组织结构与职责)

### 条款6: 策划
- 6.1 应对风险和机遇的措施
- 6.2 质量目标及其实现的策划
- 6.3 变更的策划

**质量计划对应模块**: 2(质量目标与KPI)、7(风险评估与CAPA)、10(变更管理)

### 条款7: 支持
- 7.1 资源
- 7.2 能力
- 7.3 意识
- 7.4 沟通
- 7.5 文件化信息

**质量计划对应模块**: 3(组织结构与职责)、9(培训要求)

### 条款8: 运行
- 8.1 运行策划和控制
- 8.2 产品和服务的要求
- 8.3 产品和服务的设计和开发
- 8.4 外部提供过程、产品和服务的控制
- 8.5 生产和服务的提供
- 8.6 产品和服务的放行
- 8.7 不合格输出的控制

**质量计划对应模块**: 4(质量管控流程)、5(供应商质量管理)、6(检测标准与方法)

### 条款9: 绩效评价
- 9.1 监视、测量、分析和评价
- 9.2 内部审核
- 9.3 管理评审

**质量计划对应模块**: 8(审核计划)、11(反馈与持续改进)

### 条款10: 改进
- 10.1 总则
- 10.2 不合格和纠正措施
- 10.3 持续改进

**质量计划对应模块**: 7(风险评估与CAPA)、11(反馈与持续改进)

## 常用质量工具参考

### FMEA（失效模式与影响分析）
- 严重度(S): 1-10分，10为最严重
- 发生度(O): 1-10分，10为最频繁
- 探测度(D): 1-10分，10为最难探测
- RPN = S x O x D，通常RPN>100或S>=9时需采取措施

### SPC（统计过程控制）
- Cpk >= 1.33: 过程能力充分
- 1.0 <= Cpk < 1.33: 过程能力尚可，需改进
- Cpk < 1.0: 过程能力不足，需立即改进
