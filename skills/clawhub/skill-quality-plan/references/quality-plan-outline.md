# 质量计划大纲模板

## 概览

本文件定义了产品质量计划的12模块标准结构。智能体在阶段二生成大纲时，以此框架为基础，根据用户产品的具体特点进行裁剪和细化。

## 标准大纲结构

### 1. 产品概述

- 1.1 产品基本信息（名称、型号、图号）
- 1.2 产品描述与用途
- 1.3 关键特性与特殊特性
- 1.4 适用范围与限制条件
- 1.5 参考文件与标准清单
- 1.6 里程碑与时间节点

### 2. 质量目标与KPI

- 2.1 总体质量方针
- 2.2 具体质量目标（量化）
- 2.3 关键绩效指标(KPI)定义
- 2.4 度量方法与数据来源
- 2.5 目标评审频率与责任人

### 3. 组织结构与职责

- 3.1 质量团队组织架构
- 3.2 关键角色定义（质量经理/工艺工程师/检验员等）
- 3.3 RACI职责矩阵
- 3.4 权限与汇报关系
- 3.5 外部协作方（客户/第三方检测）

### 4. 质量管控流程

- 4.1 设计开发阶段质量控制
  - 4.1.1 设计评审
  - 4.1.2 FMEA（设计失效模式分析）
  - 4.1.3 设计验证与确认
- 4.2 采购阶段质量控制
  - 4.2.1 供应商选择与评估
  - 4.2.2 来料检验(IQC)
  - 4.2.3 采购物料质量协议
- 4.3 生产阶段质量控制
  - 4.3.1 首件检验(FAI)
  - 4.3.2 过程巡检(IPQC)
  - 4.3.3 关键工序控制点
  - 4.3.4 统计过程控制(SPC)
- 4.4 成品检验与交付
  - 4.4.1 最终检验(FQC)
  - 4.4.2 出货检验(OQC)
  - 4.4.3 包装与标识要求
  - 4.4.4 交付与运输防护

### 5. 供应商质量管理

- 5.1 供应商准入标准
- 5.2 供应商评估方法与评分准则
- 5.3 合格供应商清单
- 5.4 供应商绩效考核（交期/质量/服务）
- 5.5 供应商纠正与改进要求

### 6. 检测标准与方法

- 6.1 关键质量特性(CTQ)清单
- 6.2 检测设备与量具清单
- 6.3 检测方法与技术标准
- 6.4 检测频率与抽样方案
- 6.5 验收准则与判定标准
- 6.6 量具校准与管理

### 7. 风险评估与CAPA

- 7.1 风险识别（FMEA分析）
  - 7.1.1 失效模式识别
  - 7.1.2 严重度/发生度/探测度评分
  - 7.1.3 风险优先数(RPN)计算
- 7.2 高风险项应对措施
- 7.3 纠正措施(CA)流程
- 7.4 预防措施(PA)流程
- 7.5 CAPA跟踪与闭环管理

### 8. 审核计划

- 8.1 内部审核（过程审核/产品审核）
- 8.2 外部审核（供应商审核/客户审核/认证审核）
- 8.3 管理评审
- 8.4 审核发现与整改跟踪

### 9. 培训要求

- 9.1 岗位技能矩阵
- 9.2 新员工入职培训
- 9.3 在岗技能培训计划
- 9.4 特殊工序人员资质要求
- 9.5 培训效果评估

### 10. 变更管理

- 10.1 变更分类（重大/一般/微小）
- 10.2 变更申请流程
- 10.3 变更评审与批准
- 10.4 变更实施与验证
- 10.5 变更记录与通知

### 11. 反馈与持续改进

- 11.1 客户反馈收集渠道
- 11.2 内部质量数据分析
- 11.3 不合格品处理流程
- 11.4 客户投诉处理流程
- 11.5 PDCA持续改进循环
- 11.6 质量成本分析

### 12. 附录

- 12.1 参考标准与法规清单
- 12.2 相关记录表单清单
- 12.3 术语与缩略语
- 12.4 修订历史

## 裁剪指南

根据产品类型，以下模块可调整侧重点：

| 产品类型 | 重点模块 | 可简化模块 |
|----------|----------|------------|
| 机加工件 | 4.3(过程控制)、6(检测标准) | 9(培训) |
| 注塑件 | 4.3.3(关键工序)、7(风险评估) | 5(供应商) |
| 钣金件 | 4.2(采购)、6(检测) | 8(审核) |
| 装配件 | 4.4(成品检验)、3(职责) | 10(变更) |

## 示例

以"精密轴承座BK-200"为例的大纲裁剪：

```
1. 产品概述
   1.1 产品基本信息: 精密轴承座 BK-200，图号DT-BK200-001
   1.2 产品描述: 工业电机主承力结构件，材料GCr15
   1.3 关键特性: 外径精度IT5级，内孔圆柱度0.005mm，表面粗糙度Ra0.8
   ...
4. 质量管控流程
   4.3 生产阶段（重点展开）
     4.3.1 首件检验: 每班次/换刀后，检测全部关键尺寸
     4.3.2 过程巡检: 每2小时抽检外径/内孔/端面跳动
     4.3.3 关键工序: 磨削工序SPC控制，Cpk>=1.33
   ...
6. 检测标准（重点展开）
   6.1 CTQ清单: 外径φ65(-0.005/+0.015)、内孔φ32(+0/+0.010)...
   6.2 检测设备: 三坐标测量机、外径千分尺、粗糙度仪...
```
