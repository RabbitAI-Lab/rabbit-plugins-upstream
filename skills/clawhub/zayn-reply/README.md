# REPLY() 客户回复

**Skill ID:** `zayn-reply`  
**Display Name:** REPLY()  
**中文名称：** 客户回复

- 所属项目：WorkFn
- 当前版本：`0.2.0`
- 当前状态：Draft for testing

## 一句话用途

在事实、边界和沟通目标基本明确后，生成适合 Email、WhatsApp、WeChat 或其他渠道的客户回复。

## 适用场景

1. 客户原话或上下文已经明确
2. 已确认事实与待确认事项可以区分
3. 回复目标和不可承诺边界基本明确
4. 需要生成符合指定渠道和语言的最终表达

## 不适用场景

1. 客户意图仍需深度解读
2. 价格、责任或订单判断尚未完成
3. 关键事实和边界均不明确
4. 只需要内部分析而不需要客户回复

## 输入要求

正式运行前必须检查必填参数，并使用“已命中、部分命中、缺失、冲突、待验证”输出参数状态表。关键参数缺失或冲突时，只能进入初步分析模式并停止正式分析。

## 输出结果

输出参数完整度结论、参数状态表、本 Skill 的专业判断、风险、停止条件和下一步。具体字段以 [SKILL.md](SKILL.md) 为准。
