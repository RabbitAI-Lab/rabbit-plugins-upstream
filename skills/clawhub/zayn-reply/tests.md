# Tests

## 测试原则

1. 使用经过人工确认的真实案例或脱敏案例
2. 测试输入是否识别完整
3. 测试缺失参数是否能被指出
4. 测试是否会无中生有
5. 测试是否会过早承诺
6. 测试是否会把推测写成事实
7. 测试输出是否符合固定结构
8. 测试是否尊重人工判断
9. 测试是否符合指定渠道和语言要求
10. 测试信息不足时是否敢于不生成完整话术

## 验收清单

每个测试输出必须同时满足：

1. 回应客户真正关心的问题
2. 不把推测写成事实
3. 不过早承诺
4. 不暴露内部问题
5. 不承担不必要责任
6. 有明确下一步
7. 符合沟通渠道
8. 语言自然
9. 可以解释回复策略
10. 信息不足时不强行生成完整话术
