## Description: <br>
Helps agent users, skill authors, maintainers, and teams create Tavily-style web/search workflows, checklists, implementation support, and reliability improvements based on validated ClawHub demand. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, skill authors, maintainers, and agent users use this skill to turn Tavily-style web/search workflow demand into concrete plans, checklists, analysis, code changes, configuration guidance, and validation notes. It is intended for practical bug fixing, setup hardening, safety improvement, reliability work, and adjacent skill creation. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate for generic web, search, or API requests because of broad trigger wording. <br>
Mitigation: Narrow triggers to explicit Tavily or web-search workflow tasks and confirm that invocation matches the user's intended workflow. <br>
Risk: The skill can produce workflow, checklist, code, shell command, or configuration guidance that may need adaptation before use. <br>
Mitigation: Review generated artifacts against the stated success criteria, scan code or commands before execution, and validate changes in a controlled environment. <br>
