## 全行业职能群 — 任务清单与依赖拓扑（Catalog）

本文件是本技能的第一层结构：15 域 125 个能力单元的结构索引（每个任务对应一个能力单元）、依赖拓扑与 12 条预编排管线。单元说明列为任务类型的一句话说明，完整执行口径（必选/可选组件、组装顺序、约束、格式）见 AIO-requirements.md。首次使用必须读取本文件。

### 域间逻辑流声明

```
X0 路由编排域（任务路由→双校准→信息卡展示→管线编排）
  → 条件路由到 14 个职能域之一或多个：
     ├── 行业天然通用层（组织运转）：N1 人力资源 / N2 财务会计 / N3 行政办公 / N4 信息技术
     └── 业务泛化通用层（经营闭环）：B1 情报采集与监测（感知）→ B2 资质认证与监管（准入）
                       → B3 内容生产与传播（表达）→ B4 活动运营与执行（触达）
                       → B5 客户与伙伴运营（成交留存）→ B6 供应链与运营保障（交付保障）
                       → B7 数据分析与决策（度量）→ B8 流程协同与项目管理（协同）
                       → B9 合规审核与风控（风控）→ B10 知识管理与培训（沉淀）→ 回流 B1
  → 各域单元按依赖拓扑执行（域内依赖 + 跨域依赖）
  → X0-04 管线编排与执行通报 扇入整合交付
```

业务泛化通用层十域按**经营闭环**排序编号：感知（B1）→ 准入（B2）→ 表达（B3）→ 触达（B4）→ 成交留存（B5）→ 交付保障（B6）→ 度量（B7）→ 协同（B8）→ 风控（B9）→ 沉淀（B10）。ID 编号即闭环阶段序；执行顺序由依赖拓扑权威决定，编号不隐含执行先后。双层完备性：天然通用层（N1-N4，组织运转本身）+ 业务泛化通用层（B1-B10，业务经营闭环）的并集覆盖任何行业组织的全部核心职能；两层互相独立、通过跨域依赖互通。

### 单元索引（结构信息表，含身份叠加；说明列为任务类型的一句话说明，完整执行口径见 AIO-requirements.md）

列语义：说明列 = 任务类型的一句话说明（简述本单元做什么，不承载输入/处理/输出等执行口径）；元操作列 = 主元操作（中文含义括注）；身份叠加列 = 主领域身份 + 协同身份（本单元的多重领域身份，共同更好地完成本任务类型的具体任务；协同身份按任务自身性质设定（完成当前任务需兼任的角色视角），不与其它单元身份绑定）；自治度与P实现列 = AI自治度 + P实现合并呈现。

## 依赖拓扑摘要

- **域间逻辑流**：X0 →（双校准后条件路由）→ N1-N4 / B1-B10（单域执行或多域管线）→ X0-04 整合交付（扇入）
- **入口与终点**：依赖为"无（入口）"的单元是管线起点（含 X0-01 任务路由与单元匹配）；X0-04 为全部管线与单元的扇出整合终点（覆盖 124 单元 + 12 管线）
- **执行定序**：执行顺序由上文「完整依赖拓扑」权威决定——下游执行前其 DEPENDS_ON 上游产出必须就绪，缺失则先补执行；无依赖冲突的单元并行执行（‖）；回流依赖（REFINES，8 个闭环）达标后退出
- **跨域复用**：复合需求优先复用 12 条预编排管线（编排成员见知识图谱·图实例索引 COMPOSES 实例）；自愿消费依赖（FEEDS_VOLUNTARY）不强制执行、仅在输入清单中标注可用
