# 任务路由报告

**需求复述**：星澜智联（企业协作 SaaS，160 人编制，2029 ARR 预计达成 5,000 万）需要制定 2030 年度经营计划（目标：ARR 6,800 万、NRR 106%，承接 2029 基线口径），并同步完成 2030 年度预算编制。

**意图识别**：复合任务 = 年度业务计划制定 + 全面预算编制，且两者存在数据依赖（计划目标 → 预算科目）。

**候选筛查与匹配**：

| 候选 | 匹配判定 | 依据 |
|------|---------|------|
| B7-05 年度业务计划与目标分解 | ✅ 主匹配 | 需求核心是"年度经营计划+目标分解"，与该单元任务类型直接对应 |
| N2-04 全面预算编制 | ✅ 主匹配 | "预算也要一起排出来"明确指向年度预算编制 |
| B7-02 核心指标体系与看板 | ⛔ 排除 | 需求未含指标体系搭建，ARR/NRR 口径已存在 |
| B7-03 SWOT与机会评估 | ⛔ 排除 | 用户已给出目标值，非战略方向探索类需求 |

**管线建议**：命中预编排管线 **L2 年度经营计划闭环**（B7-05 →（N2-04 ‖ B7-02）→ B7-07 ↻）。本例 B7-02 已有口径可跳过，建议执行序列：B7-05 → N2-04 → B7-07（预算偏差动态调整）。

**匹配依据汇总**：任务关键词"经营计划/预算"→ 集群路由表命中 B7-05 与 N2-04；依赖拓扑显示 N2-04 必须消费 B7-05 的目标分解口径；无其他单元同时满足"年度"与"计划+预算"双语义。

**待确认项**：① 目标值是否已董事会锁定（影响 B7-05 的目标制定环节）？② 预算是否需要部门级分解到月度？

# 双校准报告

## 一、行业识别（推导过程）

**线索**：企业协作 SaaS、ARR、NRR、付费客户数 → 软件和信息技术服务业 / SaaS 企业服务。
**验证**：订阅制收入、客户成功部设置与 SaaS 经营模式一致，识别成立。

## 二、组织校准（推导过程）

**线索**：156 人、9 个部门、CEO 直接收敛汇报线 → 中型成长期企业。
**验证**：三级管理层级（总监→经理→专员），制度规范化建设中，审批链短（≤3 级）。

## 三、注入的执行口径（本次任务全程生效）

| 校准维度 | 注入口径 |
|---------|---------|
| 术语 | 收入用 ARR/NRR/CSAT 口径；客户分 KA/腰部/长尾 |
| 法规 | 收入确认按订阅制分摊；数据安全参照等保 2.0；高新企业 15% 税率口径（以最新法规为准） |
| 流程特征 | 经营计划按"目标→部门分解→月度跟踪"三级；预算按部门+科目双维 |
| 管理颗粒度 | 中型成长期：制度给到"表单+流程+责任人"级，不设集团级合并口径；审批链按 ≤3 级设计 |
| 风险红线 | 不得虚构市场规模与竞品数据；不确定标注"待验证" |

**请确认以上校准口径是否正确，确认后注入 B7-05、N2-04、B7-07 执行上下文。**
