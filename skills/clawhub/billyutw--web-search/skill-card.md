## Description: <br>
Searches the web with DuckDuckGo for web pages, news, images, and videos, returning clean text, Markdown, or JSON results. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[billyutw](https://clawhub.ai/user/billyutw) <br>

### License/Terms of Use: <br>


## Use Case: <br>
Developers and agents use this skill to gather current web, news, image, and video search results for research, fact-checking, and resource discovery. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Search queries are sent to DuckDuckGo as an external service. <br>
Mitigation: Avoid submitting sensitive, private, or regulated information in search queries. <br>
Risk: Search results can optionally be written to local files. <br>
Mitigation: Use explicit, non-sensitive output paths and confirm overwriting is acceptable before saving results. <br>
