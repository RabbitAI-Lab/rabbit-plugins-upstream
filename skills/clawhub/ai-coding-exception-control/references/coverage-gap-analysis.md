## 与 SOP 的联动关系

```
需求覆盖率缺口
    ├── 调研阶段缺口 → `requirements-design-sop.md` 调研方向补充
    ├── 需求阶段缺口 → `requirements-design-sop.md` 七维维度补充
    ├── 设计阶段缺口 → `requirements-design-sop.md` 五层设计补充
    ├── 编码阶段缺口 → `coding-sop.md` 检查清单补充
    ├── 测试阶段缺口 → `testing-sop.md` 六层框架补充
    └── 审查阶段缺口 → `audit-ledger-spec.md` 审查项补充
```

**关键原则：** 不是"补一个场景"，而是"补一个检查项，让AI之后自动覆盖同类场景"。
