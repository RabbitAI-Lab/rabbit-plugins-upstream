## Description:

An intellectual-property statistics workflow assistant that guides technology management teams through patent data collection, verification, classification, quality rating, summary reporting, and archival workflows using Zhihuiya/PatSnap MCP tools.

This skill is ready for commercial/non-commercial use.

## Publisher:

[yuanzhian-patsnap](https://clawhub.ai/user/yuanzhian-patsnap)

### License/Terms of Use:

MIT-0

## Use Case:

Technology management leaders, IP specialists, and R&D managers use this skill to run staged intellectual-property portfolio statistics workflows. It helps produce ledgers, discrepancy lists, quality-rating summaries, competitor comparisons, reporting-package summaries, archive naming guidance, and maintenance checklists.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can support querying and processing an organization's patent, project, and competitor data through Zhihuiya/PatSnap MCP tools.

Mitigation: Confirm authorization to access and process the relevant patent and project data before installing or using the skill.

Risk: Generated external reports may contain commercially sensitive portfolio, project, or IP strategy information.

Mitigation: Review and redact generated materials before sharing them outside the authorized audience.

Risk: If Zhihuiya/PatSnap MCP access is not configured, the skill cannot retrieve real-time database evidence for conclusions.

Mitigation: Treat outputs as workflow guidance until the account authorization and MCP tools are enabled.
