## 错误 1：500.com O/U 页面初盘/即时盘顺序搞反
**日期**: 2026-06-25  
**现象**: 把第一个内表当"初盘"，第二个当"即时盘"，导致 5 场大小球方向全反  
**原因**:  
- 欧赔页：Row 0=初盘(tr_bdb)，Row 1=即时盘  
- O/U 页：两个独立 table，Table 0=即时盘(有↑↓箭头)，Table 1=初盘(无箭头)  
- 两个页面结构不同，直接用欧赔逻辑套 O/U  
**修正**:  
- O/U 页：tables[0]=即时，tables[1]=初盘  
- 判断依据：第一个表有 class="ying"/"ping" 和箭头，第二个表无  
**下次**: 解析任何新页面先看原始 HTML 的 class 和箭头，不要假设和欧赔页一样

## 错误 2：水位和盘口割裂分析
**日期**: 2026-06-25  
**现象**: 只看盘口线移动不看水位，说"5 场升盘=大球"  
**原因**: 不懂盘口基础知识  
**正确规则**（已回测验证）:
| 盘口 | 上盘水位 | 含义 |
|------|---------|------|
| 升盘 | 降水 | 🟢 看好上盘（真升） |
| 升盘 | 升水 | ⚠️ 诱上盘（假升，实看下盘） |
| 降盘 | 升水 | 🔴 看好下盘（真降） |
| 降盘 | 降水 | ⚠️ 诱下盘（假降，实看上盘） |
**回测数据**: 大球降水+小球升水 = 63% 大球率（1752场五大联赛）  
**下次**: 盘口和水位必须同时看，矛盾时以水位为准

## 错误 3：亚盘上盘判断错误
**日期**: 2026-06-25  
**现象**: 用 line 正负号判断谁是上盘，而不是看谁是让球方  
**原因**: 不懂亚盘基本概念  
**正确**:  
- 上盘 = 让球方 = 强队  
- 强队在客场时 line 为正（主队受让），但上盘仍是客队  
- 上盘水位在 td[0]（主）还是 td[2]（客），取决于上盘是主还是客  
**下次**: 先确定谁是让球方（看 1X2 赔率谁最低），再分析水位

## 错误 4：亚盘方向术语用错
**日期**: 2026-06-25  
**现象**: 说"看好澳大利亚"和"看好平局"矛盾  
**正确**:  
- 巴拉圭 -0.25（让平半）= 巴拉圭是上盘  
- 平局 → 上盘输一半，下盘赢一半  
- "看好平局"和"下盘赢一半"是同一个方向  
**下次**: 先把盘口术语转成具体赛果再判断方向

## 错误 5：不看水位只看盘口
**日期**: 2026-06-25  
**现象**: O/U 分析只看 line_up/line_down，不看 over_drops/under_drops  
**修正**: 水位是真金白银，比盘口更重要。矛盾时以水位为准

## 错误 6：忽略 Pinnacle 反向信号
**日期**: 2026-06-25  
**现象**: 德国那场，Pinnacle Steam +0.10（冷却德国），Bet365 Steam -0.10（涌入德国），没第一时间警觉  
**正确**: Pinnacle 是全球最精准庄家。Pinnacle 和其他公司反向 = 重大警报

## 错误 7：500.com 搜索和 ID 扫描不可行
**日期**: 2026-06-25  
**现象**: 尝试搜索接口和扫描 fixture ID 范围来找历史比赛，全部失败

**下次**: 别浪费时间爬 500.com 历史数据，直接走 football-data.co.uk
