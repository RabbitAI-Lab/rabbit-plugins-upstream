## Description: <br>
Helps AI-agent users, skill authors, maintainers, and teams create ontology-style workflows, checklists, analyses, code changes, and decision support for work-productivity tasks. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, skill authors, maintainers, and AI-agent users use this skill to turn ontology-style productivity needs into practical workflows, templates, checklists, analyses, implementation support, and validation notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill has broad automatic activation wording, including generic terms such as workflow, knowledge, graph, memory, creating, and bug fix. <br>
Mitigation: Install it only when a general ontology-style workflow planning helper is desired, and review triggered outputs for relevance before acting on them. <br>
Risk: As a documentation-only workflow helper, it can still produce incorrect or misleading planning guidance. <br>
Mitigation: Check outputs against the stated success criteria and review any generated workflow, code, command, or configuration before deployment. <br>
