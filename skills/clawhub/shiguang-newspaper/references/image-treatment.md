# 素材提取与必要变化

每张原始素材保存原字节、稳定 ID 和内容摘要；内容素材与风格参考各自登记。派生元素记录父素材 ID、主体、风格、范围和实际变化，保持人物/地点可追溯。不得把背景里未经选择的人物带入新的故事。

## 先选处理方式

| 选择 | 执行 |
|---|---|
| 原照 | 直接用于版面，不因为残留的编辑文字而重新提取或重绘 |
| 抠图 | 默认提取所选主体，要求真实透明背景；保留身份、衣着、关键细节和原姿态 |
| 整张插画 | 将整张场景转为约定风格，保留内容与空间语义；不偷偷变成单人抠图 |
| 保留环境的元素 | 仅在计划中明确时保留有叙事作用的环境，说明取景范围 |

多个元素必须分别有主体描述。不要把“取出人物与建筑”当作可任意混合的一张结果。同一原图可以有多个合法视觉用途，但必须在策划中解释角色，不能误把多个变体当作多个独立人物。

## 提取与二次编辑分开

忠实提取/风格转换本身已经是一次图像处理。无需改变内容时，直接复用该结果，禁止仅因为 `creativeBrief` 非空就额外再生一次。

每个元素记录：

```json
{
  "id": "person-standing",
  "sourceId": "source-character",
  "subject": "戴绿色帽子的原创成年邮差",
  "treatment": "cutout",
  "style": "彩色线描插画",
  "changeRequired": false,
  "changeInstruction": ""
}
```

后续需要坐着看地图时，为同一来源创建另一个变体，明确 `changeRequired: true` 和动作描述。只编辑需要变化的元素：人物坐下不意味着旁边的树也必须再生成。

姿态/表情变化提示需要同时说出不变项与改动项：同一人物的脸、发型、衣着、饰物与身份保持；仅改变坐姿、视线或表情。原照用于身份依据，提取图用于既有风格，不得将两张参考解释成两个人。不以图片里的新姿态证明现实中发生过相同事件。

## 使用宿主工具

优先使用实际可用、能接收源图的图像编辑工具。源图与编辑目标应实际传入，文字描述不能冒充像素输入。宿主要求先查看本地图片时先查看。透明背景必须由支持透明输出的工具真实返回；棋盘格、白底和“看起来像抠图”不等于 alpha 通道。

每个元素或整版只进行一次生成后保存。需要多元素时可以分别调用，也可用工具明确支持的多结果模式；按工具真实粒度记录任务和输出，不伪造请求数。把完整返回但尚未后处理的图也先存下，避免后处理失败导致重复消费。

生成后的基础核对：源身份、所选主体数量、提取范围、衣着/地标关键特征、已批准的变化、实际透明度、图像是否能打开。来源错误或多出人物不能当作审美偏好略过；线条、构图等审美差异交给用户判断，不触发无限自动润色。

## 复用与失效

缓存视觉输入包括源图内容哈希、主体/范围、处理方式、风格、实际变化、模型、提示词版本。图注和解释性备注单独存放，不改变素材图像缓存；会改变识别目标的文字则必须纳入视觉输入。

同样输入且文件/hash有效才复用。不要只靠文件名，也不要扫描不相关目录挑一张“像是成功”的图片。每个成功元素立即保存和登记；如果工具只整组交回，未完整返回的散落文件不能被当成已经验证的成功组。
