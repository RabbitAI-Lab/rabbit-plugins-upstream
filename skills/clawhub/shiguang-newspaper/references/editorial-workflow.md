# 整期策划与视觉

## 简报与编辑分工

先使用用户已有材料和回答。只补问会改变结果的缺项；用户授权自行决定时，给出具体选择并记录，不以不断访谈代替制作。

| 决策 | 需要明确的内容 |
|---|---|
| 主题和读者 | 这期究竟讲什么，读者看完记住什么；旅行/校园/活动只是情境，不是固定模板 |
| 内容边界 | 用户事实、可核实事实、创作设定、不能出现的内容 |
| 物理规格 | 纸张尺寸、横版或竖版、单面或双面、版数；整期统一 |
| 印刷方式 | 普通逐页打印为默认；拼版、出血、折页、装订或专业印刷要求另行指定，不猜印厂参数 |
| 视觉方向 | 参考图的阅读路径、标题尺度、图文穿插、线条和材料感；明确内容素材与参考的区别 |
| 素材选择 | 必用与可选、原照/抠图/整张插画、逐元素范围与授权变化 |

每版计划至少有：稳定 ID、页码、编辑角色、标题/摘要、要印的文案、主视觉、辅助栏目、素材 ID、处理计划、视觉重点。头版提出全期主题；内页深入不同侧面，不把头版换标题重复一次。内容少时建议缩小版数或精简栏目，不靠重复文案填满。

例如两版可以是“主题与人物”＋“路线与实用信息”；四版可以是“头版”＋“人物/现场”＋“文化/故事”＋“地图/互动”。这只是选项，不能让校园纪念报也硬套旅游地图。

## 有报纸感，也有想象力

选择符合主题的编辑语言，而不是复制一种底纸：

- 报头、期号/日期、版名与页码建立期刊身份；虚构样报需清楚注明虚构，不假扮真实新闻。
- 一个明确的主视觉与主标题建立重心，辅助栏目以不同尺度回应主线。
- 栏线、双线、装饰线、边框、分隔符连接信息；装饰有主题来源，例如邮戳、票根、植物线描、手写边注。
- 可用抠图跨栏、插画穿插、漫画小格、圆形放大镜、路线图、清单、时间轴、对话或引语形成节奏；不是每版全部使用。
- 把有用信息补到空白处：图注、简短知识、路线标记、人物小传、编辑手记，而非无意义花纹或编造事实。
- 密集不等于微型文字。删减冗余文案、加大正文与行距，保护主体脸部和关键动作。大面积纯空白若无叙事目的，优先调整构图和内容分配。

跨版一致的是报刊身份、色彩家族、字体气质、线条语言和人物身份；变化的是叙事、布局、镜头、素材形态与阅读节奏。

## 文案与事实

整版生成前先把标题、正文、图注和服务信息校准。日期、数字、地名、专名、路线和用户给定原话优先检查。外部可变事实使用可用的查证工具，来源记录在工程里。信息不够时省略、注明待确认或使用明确的虚构设定，不能用模型常识填充可核查事实。

生成提示列明需要印出的准确文字；避免要求一张低分辨率图片容纳过量正文。先看真实生成效果再决定修复，不声称提示里写了“无错字”就已达成。整版图片上的中文要人工或视觉工具实际查看，OCR 可辅助但不能独自判定美观和语义。

## 确认与修改

1. 第一确认看整期计划及逐图处理，不是只看风格名称。
2. 第二确认看真实头版，包括中文、素材与装饰的综合表现。
3. 第三确认看所有版面及顺序；意见可以为空。

用户批准了某版后，以实际图片和最新要求为准，不能用早期草案把修改覆盖掉。用户只改文字时保留已完成的素材变体；用户只改某页动作时不重做全期。因模型整版绘制而无法保证像素级局部不变时要说清楚，不能把全页重生成说成无损局部编辑。

若用户已经授权自行决定或完整自动制作，记录这项授权并在相同检查点自行检查，不额外卡流程。测试中写明“测试委托确认”，不得将它报告为真实用户逐页验收。
