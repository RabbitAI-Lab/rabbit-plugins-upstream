# 拾光报 · Shiguang Newspaper

`shiguang-newspaper` · `1.0.0` · MIT-0

把故事、照片与视觉参考编成一期有栏目分工、有想象力的主题报纸。适合校园纪念报、活动特刊、文旅报和个人主题刊物。独立运行，不需要拾光册网站或手帐 Skill。

## 安装与调用

从 ClawHub 安装：

```sh
clawhub install @legithubhh/shiguang-newspaper
```

或把本目录完整复制到宿主 Agent 支持的 skills 目录。安装后让 Agent 使用 `$shiguang-newspaper`；不同宿主的发现方式以其自身说明为准。

> 使用 $shiguang-newspaper，把这些照片和故事制作成一期校园纪念报。A4 横版，双面，共四版，图文丰富、有线条和插画点缀。先给我整期策划和逐图处理方案，人物身份保持，必要动作变化逐项说明。

## 实际提供什么

- 整期策划 → 真实头版确认 → 内页制作 → 整期确认。满意可直接继续，修改意见选填；也支持用户明确委托自行决定。
- 原照、忠实抠图、整张插画及必要的逐元素姿态/内容变化，保留来源与角色关系。
- 最终版面图片、轻量打印 PDF、完整 `.newspaper.zip` 制作工程。整版文字属于图片，可通过 AI 修改，不宣称逐字可编辑。
- 离线工程脚本：输入指纹、有效缓存、任务中断记录、历史版本、物理尺寸导出与安全恢复。

## 需要什么能力

宿主需要读图与实际的图像生成/编辑能力，以及保存文件的能力。仅有文字模型时可以完成策划，不能声称已制作图片。脚本不会调用模型、不读取 API 密钥，也不是后台生成服务。

工程辅助脚本使用 Python 3.10+、Pillow、reportlab。它们仅用于文件检查与导出，不替代 AI 生图。完整参数与安装方式见 [工程工具](references/project-tools.md)。脚本和工程不依赖网站 Node 服务，也不声称兼容网站 `.shiguang.json` 格式。

## 内容与质量边界

用户原始事实、素材身份、最新批准内容优先。风格参考不自动授权复制其人物或正文。内部核查来源保留在工程，默认不印网址脚注。未知用量如实标记，不把任务尝试数当作完整账单；审美建议不触发反复自动生图。
