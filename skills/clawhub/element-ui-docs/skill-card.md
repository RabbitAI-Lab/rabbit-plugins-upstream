## Description:

Element UI Docs provides Chinese documentation for the Vue 2 Element UI desktop component library, including component APIs, usage examples, design guidance, installation, and quickstart material.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers building Vue 2 desktop web interfaces use this skill to look up Element UI component APIs, copy-ready examples, design guidance, and setup instructions. It is most useful for Element UI-specific implementation questions, especially component configuration, forms, tables, navigation, feedback components, theming, and internationalization.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Copied UI examples, especially upload and HTML-rendering snippets, may be unsafe if used unchanged in production.

Mitigation: Review and harden examples before production use, including server-side file validation and sanitization of user-controlled HTML.

Risk: Client-side Element UI form validation can be mistaken for an authorization or data-integrity control.

Mitigation: Use Element UI validation for user experience only and enforce validation, authorization, and sensitive operations on the server.
