# 医疗废物交接与暂存记录核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：财务、出纳等岗位在**每月结账 / 对账 / 盘点**这类固定节点上，
必须把这张表核一遍才能往下走。

**这张表会逐项核对什么**：医疗废物交接登记表的逐行算术、合计勾稽、重复与空缺检测。

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 常见错法（这张表最常见的 6 种填法问题）

| 常见错法 | 会发生什么 | 正确填法 |
|---|---|---|
| 只填交接日期、不填暂存/移交时间 | **暂存时限（≤48 小时）没法判**，工具会如实报「该项未执行」，**不会默认合规** | 暂存时间与移交时间按 `YYYY-MM-DD HH:MM` 填全，缺一个就判不出来 |
| 废物类别写简称（"感染"、"锐器"、"输液瓶"） | 不在五类规范名（感染性/损伤性/病理性/药物性/化学性）里，逐条点名 | 按《医疗废物分类目录》写规范类别名；一个袋子混了两类就拆两行 |
| 重量写成「约 2.5 公斤」「2.5kg」「半桶」 | 数值列认不出，判「数值非法」；不会替你换算单位 | 只填数值（单位统一 kg），别带单位词、别带"约" |
| 同一联单号抄两遍（转运单位分两次来、台账各记一行） | 判「同一联单号重复登记」——要么是重复计数，要么是联单号抄错 | 先核联单原件：真重复就合并计量，联单号抄错就改成原件上的号 |
| 科室列用合并单元格，导出后该列为空 | 分科室汇总会缺组，也判关键字段缺失 | Excel 里先取消合并、把科室名填满每一行，再复制成文本 |
| 空值用「/」「—」「无」占位 | 结算/汇总时被当字符串，判字段缺失或数值非法 | 空就留空（Tab 分隔时留一个空列），别放符号 |

> 一句话：**这张表的价值在"能逐条对上原件"**。凡是"看起来填了但机器读不出来"的写法，
> 工具一律如实报出来，不会替你猜——猜出来的合规比报错更危险。

## 边界（请务必知道）

本工具**不做**引擎 `CHECKS_OUT_OF_SCOPE` 里列的那些判断；
材料不足时**不给结论**，也不会输出「未发现问题」。
