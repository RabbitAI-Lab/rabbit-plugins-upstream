# Coupang 类目研究

1. 从根类目逐层下钻，或先用父链接口核验已有 `displayItemCategoryId`。
2. 区分导航 ID 与展示类目编码，按根、叶子或中间路径选择正确商品筛选字段。
3. 商品样本同时看近 28 日销量和浏览量、价格、评分、评论数、规格数、卖家数及配送展示标记。
4. 报告 `total`、实际读取数、页码和前 200 条访问上限；未完成分页时只描述当前样本。
5. 全量类目树不等于全量商品覆盖；商品样本少不能直接推导低竞争或市场容量小。
6. 当前没有官方类目 GMV、搜索量、广告、转化或卖家数，不输出虚构市场容量。

默认输出：类目路径和编码、样本口径、需求证据、价格带、头部和规格竞争、机会、风险与验证动作。
