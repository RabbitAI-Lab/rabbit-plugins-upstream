# 国央企常用报告模板框架

## 一、年度工作总结

```
一、主要工作及成效
    （一）[业务板块一]：成效概述 + 关键数据 + 典型案例
    （二）[业务板块二]：成效概述 + 关键数据 + 典型案例
    （三）[业务板块三]：成效概述 + 关键数据 + 典型案例

二、重点工作亮点
    （一）[亮点一]
    （二）[亮点二]
    （三）[亮点三]

三、存在的问题与不足
    （一）[问题一]：描述 + 原因分析
    （二）[问题二]：描述 + 原因分析
    （三）[问题三]：描述 + 原因分析

四、下一步工作计划
    （一）[目标一]：具体措施
    （二）[目标二]：具体措施
    （三）[目标三]：具体措施
```

### 写作要点
- 小标题对仗工整，多用动宾结构
- 数据具体化：增长率、完成率、同比增长等
- 问题分析不回避、不夸大、有对策
- 下一步计划要可量化、有时限、有责任人

## 二、述职报告

```
一、履职情况
    （一）政治理论学习方面
    （二）业务工作推进方面
    （三）团队建设管理方面
    （四）廉政建设方面

二、工作亮点与创新
    （一）[亮点一]
    （二）[亮点二]

三、问题与不足
    （一）理论学习深度不够
    （二）[业务方面不足]
    （三）[管理方面不足]

四、改进措施与努力方向
    （一）加强理论学习
    （二）提升业务能力
    （三）改进工作作风
```

### 写作要点
- 第一人称，语气谦逊务实
- 既不夸大成绩也不过分自贬
- 问题部分要体现反思深度
- 改进措施要具体可落实

## 三、党建/思想政治工作报告

```
一、主要工作开展情况
    （一）强化政治建设，把稳思想之舵
    （二）深化理论武装，筑牢信仰之基
    （三）夯实组织基础，打造坚强堡垒
    （四）正风肃纪反腐，涵养政治生态
    （五）党建引领发展，服务中心大局

二、存在问题
    （一）[问题一]
    （二）[问题二]
    （三）[问题三]

三、下一步工作思路
    （一）[措施一]
    （二）[措施二]
    （三）[措施三]
```

### 写作要点
- 政治站位高，语态庄重严肃
- 引用最新中央精神和政策文件
- 小标题多用四字短语对仗（如"把稳思想之舵""筑牢信仰之基"）
- 避免空话套话，结合具体工作谈党建

## 四、调研报告/课题研究

```
摘要（200字以内）

一、调研背景与目的
    1.1 政策背景
    1.2 调研目的
    1.3 调研方法（问卷/访谈/实地考察/数据采集）

二、现状分析
    2.1 基本情况
    2.2 主要特点
    2.3 数据呈现（可用表格）

三、存在的问题及原因分析
    3.1 [问题一]
        3.1.1 具体表现
        3.1.2 原因剖析
    3.2 [问题二]
    ...

四、对策建议
    4.1 [建议一]
    4.2 [建议二]
    4.3 [建议三]

五、结论与展望
```

### 写作要点
- 数据驱动，定性与定量结合
- 问题分析要有深度，不浮于表面
- 对策建议要可操作、有创新
- 引用权威数据源和政策文件
- 建议引用"十四五"规划、行业白皮书等权威依据

---

## 五、工作方案/实施方案

```
一、总体要求
    （一）指导思想
    （二）基本原则
    （三）工作目标（含量化指标）

二、主要任务
    （一）[任务一]
    （二）[任务二]
    （三）[任务三]

三、实施步骤
    （一）动员部署阶段（X月X日—X月X日）
    （二）全面推进阶段（X月X日—X月X日）
    （三）总结评估阶段（X月X日—X月X日）

四、责任分工
    （一）牵头部门：[XX部]，负责[XX]
    （二）配合部门：[XX部]，负责[XX]
    （三）监督部门：[XX部]，负责[XX]

五、保障措施
    （一）组织保障
    （二）经费保障
    （三）技术保障
    （四）制度保障

```

### 写作要点
- 目标要SMART（具体、可衡量、可达成、相关、有时限）
- 责任要落实到具体部门/个人
- 时间节点要明确
- 保障措施要具体，不说"加强领导"之类的空话

```
    2. [议题二]

二、会议内容
    （一）关于[议题一]
    [讨论要点和主要意见]
    （二）关于[议题二]
    ...
    （三）关于[议题三]
    ...

三、决议事项
    （一）[决议一]。（责任部门：XX部，完成时限：X月X日）
    （二）[决议二]。（责任部门：XX部，完成时限：X月X日）
    （三）[决议三]。（责任部门：XX部，完成时限：X月X日）

四、待办事项
    | 序号 | 事项 | 责任人 | 完成时限 | 备注 |
    |------|------|--------|----------|------|
    | 1    | ……   | ……     | ……       | ……   |
```

### 写作要点
- 实录不评论，客观记录讨论和决议
- 决议事项必须有责任人和时限
- 与议题无关内容不写入
- 涉及表决的需记录表决结果

## 七、通知/公告

```
[发文机关标志]
[发文字号]

[标题]

[主送机关]：

[正文：事由 + 具体内容 + 要求]

附件：[附件名称]

[发文机关署名]
[成文日期]
（印章）
```

### 写作要点
- 开门见山，一事一通知
- 时间、地点、对象三要素必须明确
- 语言准确无歧义
- 命令性通知用语：必须、务必、不得
- 告知性通知用语：请、望、希

---

## 八、汇报材料（向上级汇报）

```
一、基本情况
    [核心数据和关键背景]

二、主要做法
    （一）[做法一]
    （二）[做法二]
    （三）[做法三]

三、取得成效
    （一）[成效一]（附数据支撑）
    （二）[成效二]（附数据支撑）

四、经验体会
    （一）[经验一]
    （二）[经验二]

五、存在的问题和建议
    [问题] + [建议]
```

### 写作要点
- 开头用一句话概括核心成果
- 用数据说话，对比往年/同期数据
- 经验体会要提炼规律，不能只是简单重复做法
- 问题和建议要对应，不仅提问题还要给方案
