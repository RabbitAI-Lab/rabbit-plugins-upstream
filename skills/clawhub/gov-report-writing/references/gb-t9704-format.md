# 党政机关公文格式规范（GB/T 9704-2012）

## 一、页面设置

| 项目 | 规范 |
|------|------|
| 纸张 | A4（210mm × 297mm） |
| 上边距（天头） | 37mm ± 1mm |
| 下边距（地脚） | 35mm ± 1mm |
| 左边距（订口） | 28mm ± 1mm |
| 右边距（翻口） | 26mm ± 1mm |
| 版心尺寸 | 156mm × 225mm |

## 二、版头要素

### 份号
- 位置：版心左上角第一行
- 字体：3号仿宋_GB2312
- 格式：6位阿拉伯数字

### 密级和保密期限
- 位置：版心左上角第二行（如有份号则在份号下方）
- 字体：3号黑体
- 密级：绝密/机密/秘密
- 保密期限：如"机密★5年"

### 紧急程度
- 位置：版心左上角（密级下方）
- 字体：3号黑体
- 标注：特急/加急

### 发文机关标志
- 字体：小初号或一号红色小标宋体字（推荐方正小标宋简体）
- 位置：居中，上边缘至版心上边缘35mm
- 颜色：红色
- 格式：发文机关全称或规范化简称 + "文件"二字（可选）
- 联合行文时，主办机关名称在前

### 发文字号
- 位置：发文机关标志下空2行，居中
- 字体：3号仿宋_GB2312
- 格式：机关代字〔年份〕序号
- 示例：国发〔2025〕1号
- 年份用六角括号"〔〕"，不用方括号"[]"

### 签发人
- 仅上行文标注
- 位置：发文字号同行右侧
- 字体："签发人"用3号仿宋_GB2312，签发人姓名用3号楷体_GB2312

### 分隔线
- 发文字号下4mm处印一条红色分隔线（与版心等宽）
- 线高：0.35mm-0.5mm，推荐0.5mm

## 三、主体要素

### 标题
- 字体：2号方正小标宋简体（二号小标宋体）
- 位置：红色分隔线下空2行，居中
- 行距：30磅固定值
- 要求：一般不超过3行，分行时词意完整、排列对称

### 主送机关
- 位置：标题下空1行，左侧顶格
- 字体：3号仿宋_GB2312
- 多个主送机关时，按党、政、军、群顺序排列
- 最后一个主送机关名称后标全角冒号

### 正文
- 字体：3号仿宋_GB2312
- 行距：固定值28磅（约28.9磅）
- 每面排22行，每行28个字
- 首行缩进：2字符
- 数字：Times New Roman字体

### 正文层级标题
| 层级 | 序号格式 | 字体 | 字号 |
|------|----------|------|------|
| 一级标题 | 一、二、三、… | 黑体 | 3号 |
| 二级标题 | （一）（二）（三）… | 楷体_GB2312 | 3号 |
| 三级标题 | 1. 2. 3. … | 仿宋_GB2312（加粗） | 3号 |
| 四级标题 | （1）（2）（3）… | 仿宋_GB2312 | 3号 |

- 一级标题：居中排列，不缩进（独立成段）
- 二级标题：首行缩进2字符
- 三级、四级标题：首行缩进2字符，与正文混排时可后接句号

### 附件说明
- 位置：正文下空1行，左空2字
- 字体：3号仿宋_GB2312
- 格式："附件：" + 附件名称
- 多个附件用阿拉伯数字标注序号
- 附件名称后不加标点符号

### 发文机关署名
- 位置：正文（或附件说明）下空适当行，右空2字
- 字体：3号仿宋_GB2312
- 以成文日期为准居中编排

### 成文日期
- 位置：发文机关署名下方（无署名时在正文下方右空4字）
- 字体：3号仿宋_GB2312
- 格式：用阿拉伯数字标注年、月、日
- 示例：2025年7月24日

### 印章
- 位置：骑车盖月（印章上沿不压正文，下沿压成文日期）
- 居中下压发文机关署名和成文日期
- 印章端正、居中

### 附注
- 位置：成文日期下1行，左空2字加圆括号
- 字体：3号仿宋_GB2312
- 用于说明公文传达范围、是否公开等

## 四、版记要素

### 分隔线
- 版记中的分隔线与版心等宽
- 首条和末条用粗线（0.35mm），中间用细线（0.25mm）
- 末条分隔线与版心最后一行重合

### 抄送机关
- 位置：首条分隔线和第二条分隔线之间
- 字体：4号仿宋_GB2312
- 格式：左空1字"抄送：" + 机关名称
- 回行时与冒号后首字对齐

### 印发机关和印发日期
- 位置：末条分隔线之上
- 字体：4号仿宋_GB2312
- 左空1字印发机关，右空1字印发日期
- 印发日期用阿拉伯数字

## 五、Word 排版参数速查

| 参数 | 值 |
|------|-----|
| 页边距-上 | 3.7cm |
| 页边距-下 | 3.5cm |
| 页边距-左 | 2.8cm |
| 页边距-右 | 2.6cm |
| 标题字体 | 方正小标宋简体 |
| 标题字号 | 二号（22磅） |
| 标题行距 | 固定值30磅 |
| 正文字体 | 仿宋_GB2312 |
| 正文字号 | 三号（16磅） |
| 正文行距 | 固定值28磅 |
| 一级标题字体 | 黑体 |
| 二级标题字体 | 楷体_GB2312 |
| 首行缩进 | 2字符 |
| 页码字体 | 4号半角宋体阿拉伯数字 |

## 六、常见错误提醒

1. ❌ 用"[]"替代"〔〕"作为年份括号
2. ❌ 正文用"宋体"替代"仿宋_GB2312"
3. ❌ 标题行距用单倍行距替代固定值30磅
4. ❌ 一级标题用"一."替代"一、"（顿号非点号）
5. ❌ 数字未用 Times New Roman 字体
6. ❌ 多个附件序号未对齐
7. ❌ 印章位置不正确（应骑车盖月）
8. ❌ 版记页不规范
