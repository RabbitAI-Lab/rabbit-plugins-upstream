## Description: <br>
Workspace Manager helps ClawPad users set up and maintain organized workspaces with domain-specific folder structures, welcome documents, and reusable planning templates. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[falaky87](https://clawhub.ai/user/falaky87) <br>

### License/Terms of Use: <br>


## Use Case: <br>
External ClawPad users use this skill to create a first workspace structure, organize new projects, decide where content belongs, and generate starter markdown documents such as plans, tracking docs, and runbooks. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can add persistent workspace folders and markdown documents. <br>
Mitigation: Preview the proposed folder and file list before allowing changes in an existing or important workspace. <br>
