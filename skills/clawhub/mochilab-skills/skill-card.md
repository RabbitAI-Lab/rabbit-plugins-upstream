## Description:

Find, inspect, install and update Skills from the MochiLab catalogue. Use when someone asks what MochiLab Skills can do, wants a Skill for a task, or asks to install or update a MochiLab Skill. Supports Chinese and English.

This skill is ready for commercial/non-commercial use.

## Use Case:

OpenClaw users can use the assistant to find and compare MochiLab Skills, connect their MochiLab account, install requested Skills, and check or update Skills in the active workspace. It provides English and Simplified Chinese guidance and reports actual versions, paths, and check results.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Downloaded Skills may contain unsafe behavior; a matching checksum verifies package integrity, not safety.

Mitigation: Review each downloaded Skill separately before installation or execution.

Risk: An account access key could be exposed if shared in chat or command arguments.

Mitigation: Enter the key only at the hidden terminal login prompt or through the host secret environment; do not share it in chat or command arguments.
