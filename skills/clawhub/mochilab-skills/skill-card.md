## Description:

Find, inspect, install and update Skills from the MochiLab catalogue. Use when someone asks what MochiLab Skills can do, wants a Skill for a task, or asks to install or update a MochiLab Skill. Supports Chinese and English.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users can discover, compare, and inspect MochiLab Skills in Chinese or English, then connect an account to install a requested Skill or check and apply updates.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: An account access key could be exposed if shared in chat or entered somewhere other than the user's own terminal.

Mitigation: Enter the private mls_ key only in the user's own terminal; never paste it into chat.

Risk: A matching download checksum confirms integrity, not that a downloaded Skill is safe.

Mitigation: Review each selected Skill before installing or updating it.
