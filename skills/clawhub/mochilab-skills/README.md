# MochiLab Skills assistant

Slug: `mochilab-skills` · Version: `1.0.0` · License: MIT-0

Read [SKILL.md](SKILL.md) for the actual workflow, dependencies, permissions and examples.

Install this folder into the active OpenClaw workspace's `skills/` directory and start a fresh conversation. Use `openclaw skills info mochilab-skills` to check readiness.

This package is free; your configured model or external services may charge separately. No model subscription is included.

MochiLab: https://mochilab.bz/

This assistant itself is free and contains no paid Skill packages. Searching the MochiLab catalogue is anonymous; downloading from the MochiLab website requires your own account and private `mls_` connection. Subscriber-only catalogue items retain their website access requirements. Never send the key in chat. Registry-installed standalone free Skills do not need this account connection.
