## Description:

This skill explains Agiexa’s planned Facebook for Shopify integration, including Facebook Page publishing, messaging, comment, and insights workflows.

This skill is ready for commercial/non-commercial use.

## Publisher:

[devkrutik](https://clawhub.ai/user/devkrutik)

### License/Terms of Use:

MIT-0

## Use Case:

Shopify merchants can use this skill to understand Agiexa’s planned Facebook integration, its example marketing and customer support workflows, and how to request a waitlist signup. The Facebook tools are preview-only and cannot be called today.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Waitlist signup sends the details the user confirms to Agiexa.

Mitigation: Submit only after the user gives explicit permission, use details confirmed in the conversation, and omit optional URL or message fields when not provided.

Risk: Security assurances for the future integration are documented claims and are not guarantees established by this package.

Mitigation: Treat those assurances as unverified and review Agiexa’s current security information before connecting accounts.
