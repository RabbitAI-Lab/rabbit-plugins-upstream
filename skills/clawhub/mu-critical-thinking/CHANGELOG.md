# Changelog

## [2.0.0] - 2026-08-05

### What's New

- ✨ Open-source release based on the internal critical thinking coaching skill
- ✨ 12-dimension argument quality assessment framework (based on *Asking the Right Questions*)
- ✨ 12 logical fallacy quick-reference with identification patterns, workplace examples, and correction scripts
- ✨ Socratic questioning training with 5-layer progressive depth model (facts → reasons → assumptions → alternatives → action)
- ✨ Decision quality audit with 12-item checklist and Kill Switch mechanism
- ✨ 7 data traps identification guide with evidence hierarchy pyramid
- ✨ 8 workplace scenario mappings (proposal review, interview evaluation, data reporting, conflict mediation, strategic decision, report auditing, upward management, performance evaluation)
- ✨ 3 interaction modes: Quick scan, Guided Socratic dialogue, and Checklist output
- ✨ Debate preparation with balanced pro/con analysis
