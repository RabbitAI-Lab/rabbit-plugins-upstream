# Contributing to mu-critical-thinking

Thanks for your interest in contributing! 🧠

## How to Contribute

### Reporting Issues

Found a bug or have a feature idea? [Open an issue](https://github.com/muippt/mu-critical-thinking/issues/new/choose) and choose the appropriate template.

### Suggesting Enhancements

Critical thinking is a living discipline. If you have ideas for:
- New logical fallacies to add
- New workplace scenarios
- Improved diagnostic dimensions
- Better correction scripts

...we'd love to hear from you. Please open a Feature Request issue with as much detail as possible.

### Pull Requests

1. Fork the repo
2. Create your branch: `git checkout -b feature/your-feature-name`
3. Make your changes
4. Test with your AI assistant to make sure the skill still works
5. Commit with a clear message
6. Open a PR

### Guidelines

- **Content accuracy first**: Any methodology changes should be grounded in established critical thinking literature
- **Keep it practical**: Workplace examples and correction scripts should be immediately usable
- **No breaking changes without discussion**: Open an issue first if you want to change the 12-dimension framework or remove existing features
- **Respect the IRON LAW**: The skill's core operating rules (IRON LAW section in SKILL.md) exist for good reason — discuss before changing them
