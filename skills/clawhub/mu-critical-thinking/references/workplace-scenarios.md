# 职场场景批判性思维应用指南

将12维度框架映射到8大高频职场场景，每个场景提供：主攻维度、关键提问清单、常见陷阱、应对话术。

---

## 场景一：评审方案/提案

### 主攻维度
- ②理由充分 + ⑥推理逻辑 + ⑦证据可信

### 关键提问清单
1. "方案要解决的核心问题是什么？问题界定清楚了吗？"（维度①）
2. "为什么选方案A而不是B/C？比较过几个选项？"（维度②）
3. "支持这个方案的数据/证据是什么？来源可靠吗？"（维度⑦）
4. "从证据到结论的推理有没有跳步？"（维度⑥）
5. "方案的隐含假设是什么？在什么条件下假设不成立？"（维度⑤）
6. "最坏情况是什么？有没有Plan B？"（维度⑫）
7. "ROI怎么算的？成本有没有漏算？"（维度⑩）

### 常见陷阱
- **诉诸权威**："行业标杆/大厂都这么做"——追问适配性
- **以偏概全**："我们做过一次，有效/无效"——样本不足
- **错误二分**："要么做要么不做"——有没有折中/试点

### 应对话术
- "方案的核心假设是什么？如果假设不成立会怎样？"
- "有没有比较过其他方案？淘汰它们的理由是什么？"
- "证据层级够吗？是验证过的还是推测的？"

## 场景二：面试评估

### 主攻维度
- ⑥推理谬误 + ⑦证据可信 + ⑧替代原因

### 关键提问清单
1. "我的判断基于具体事实还是主观印象？"（维度⑦）
2. "有没有确认偏误——我是在找证据证实第一印象？"（维度⑥）
3. "候选人的成功是自己的能力还是平台/团队/时机？"（维度⑧）
4. "我对这类人/背景有没有刻板印象影响判断？"（维度⑥-人身攻击）
5. "如果换个人做面试官，会得出同样结论吗？"（维度⑪）

### 常见陷阱
- **光环效应**：名校/大厂背景 → 默认能力强（人身攻击的正面版）
- **近因效应**：最后回答的好/差 → 整体印象好/差
- **确认偏误**：第一印象好 → 之后的问题都往好处解读
- **以偏概全**："之前招的XX背景的人都不行"

### 应对话术
- "我能举出3个具体行为事例支撑我的判断吗？"
- "如果这个人来自不同背景，我的评分会变吗？"
- "他说的成绩，有没有其他解释？是不是整个行业都在涨？"

## 场景三：数据汇报

### 主攻维度
- ⑨数据陷阱 + ⑩省略信息 + ⑧替代原因

### 关键提问清单
1. "这个数字的基数是什么？绝对值是多少？"（维度⑨）
2. "为什么选这个时间窗口？换个起点结论一样吗？"（维度⑨）
3. "哪些指标没有展示？有没有不好的指标被省略？"（维度⑩）
4. "数据变好是因为我们做了什么，还是外部因素？"（维度⑧）
5. "用的是平均值还是中位数？分布是什么形状？"（维度⑨）
6. "口径和上次/去年/竞品一致吗？"（维度③）

### 常见陷阱
- **选择性呈现**：只报好的不报差的
- **虚假因果**：A之后B发生 → A导致B
- **基数谬误**：百分比好看但绝对值很小
- **幸存者偏差**：只分析还在的客户/用户

### 应对话术
- "能不能同时看同比和环比？只看一个可能有误导"
- "这个增长排除季节因素后还存在吗？"
- "有没有哪些指标在同期下降了？"

## 场景四：冲突调解

### 主攻维度
- ③歧义与模糊 + ④价值观假设 + ⑤描述性假设

### 关键提问清单
1. "双方说的是同一件事吗？对关键词的定义一致吗？"（维度③）
2. "各自的隐含价值排序是什么？效率vs质量？短期vs长期？"（维度④）
3. "各自假设了什么是理所当然的？这些假设对方认同吗？"（维度⑤）
4. "有没有双方都能接受的第三方案？"（维度⑪）
5. "如果立场互换，对方的选择你能理解吗？"（维度④）

### 常见陷阱
- **稻草人**：歪曲对方观点再攻击 → 先复述确认
- **错误二分**：只有我对/你错 → 寻找兼容方案
- **诉诸情感**：用愤怒/委屈替代论证 → 回到事实

### 应对话术
- "我先复述一下你的观点确认理解对不对..."
- "你们说的'公平'/'效率'是同一个意思吗？各自的定义是什么？"
- "你们的分歧到底是在事实层面还是价值层面？"

## 场景五：战略决策

### 主攻维度
- ⑪合理结论 + ⑫决策质量 + ⑩省略信息

### 关键提问清单
1. "基于同样的数据，还能得出什么不同的结论？"（维度⑪）
2. "最坏情况是什么？我们能承受吗？"（维度⑫）
3. "哪些关键信息是我们目前不知道的？"（维度⑩）
4. "这个决策可逆吗？如果错了能退回吗？"（维度⑫）
5. "一年后复盘，最可能后悔什么？"（维度⑫）
6. "如果我们是竞争对手，会怎么利用这个决策的弱点？"（维度⑧）
7. "做这个决策的人有没有利益偏向？"（维度④）

### 常见陷阱
- **滑坡谬误**："不做就死"——论证每一步因果
- **乐队花车**："趋势所向不做就落后"——追问适配性
- **诉诸权威**："顾问/投资人建议的"——他们了解你的具体情况吗？

### 应对话术
- "我们比较了至少3个替代方案吗？"
- "设一个kill switch——什么条件下放弃？"
- "做10次同样的决策，有几次会成功？概率可接受吗？"

## 场景六：汇报材料审查

### 主攻维度
- ①论题结论 + ②理由充分 + ⑥推理逻辑

### 关键提问清单
1. "读完这份材料，结论是什么？一句话能说清楚吗？"（维度①）
2. "支撑结论的理由有几个？每个都独立成立吗？"（维度②）
3. "理由到结论的逻辑链完整吗？有没有跳步？"（维度⑥）
4. "有没有用情感故事替代数据论证？"（维度⑥-诉诸情感）
5. "有没有'大厂这么做'式的权威引用？"（维度⑥-诉诸权威）

### 常见陷阱
- **结论不清**：洋洋洒洒但不知道要你做什么/信什么
- **理由稀薄**：只有一个理由反复说——换着说≠更有力
- **情感替代论证**：故事感人但缺乏数据支撑

### 应对话术
- "如果只能留一页，你的核心结论和最强论据是什么？"
- "去掉所有形容词和故事，剩下的骨架逻辑站不站得住？"
- "一个友善但严格的反对者会怎么质疑？"

## 场景七：向上管理/说服

### 主攻维度
- ②理由充分 + ⑦证据可信 + ④价值观假设

### 关键提问清单
1. "对方最看重什么？（效率/风险/成本/用户/竞争？）"（维度④）
2. "我的论据在对方的价值框架里有分量吗？"（维度④）
3. "我的证据够硬吗？能经得起追问吗？"（维度⑦）
4. "对方可能的反对意见是什么？我准备好应对了吗？"（维度⑥）
5. "我的请求/结论清晰吗？对方知道我要他做什么吗？"（维度①）

### 常见陷阱
- **自我中心**：用自己看重的理由说服对方（但对方看重的不同）
- **证据不足**：有观点无数据 → 对方秒驳
- **结论模糊**：铺垫太多不知道你要什么 → 对方没耐心

### 应对话术
- "先想清楚对方的决策逻辑是什么，再组织我的论据"
- "准备三个level的ask：理想/可接受/底线"
- "每个论据准备一个'如果被挑战'的备用数据"

## 场景八：绩效评价

### 主攻维度
- ⑦证据可信 + ⑥推理谬误 + ⑧替代原因

### 关键提问清单
1. "我的评价基于具体事实还是整体印象？"（维度⑦）
2. "有没有近因效应——最近的表现权重太大？"（维度⑥）
3. "有没有光环效应——一个优点覆盖所有维度？"（维度⑥）
4. "成绩归因合理吗？是个人能力还是外部因素？"（维度⑧）
5. "不足的判断有具体事例支撑吗？几个？"（维度⑦）
6. "如果这个人换到别的团队/项目，表现会一样吗？"（维度⑧）

### 常见陷阱
- **近因效应**：Q4表现好 → 全年评价好（忽视Q1-Q3）
- **光环效应**：沟通能力强 → 觉得什么都强
- **确认偏误**：先入为主的印象 → 只记得符合的证据
- **以偏概全**：一两个事件定性整年表现
- **虚假因果**：团队成绩好 = 个人表现好

### 应对话术
- "我能为每个评价维度各举至少2个具体事例吗？"
- "如果我把名字遮住，仅看事实描述，评价还一样吗？"
- "这个成绩有多少是个人贡献vs团队/环境贡献？"
- "我对这个人有没有'标签'？这个标签是事实还是印象？"

## 通用批判性思维检查清单

在任何场景中，遇到"有人想说服你什么"的情况，快速过一遍：

1. ☐ **他想让我相信/做什么？**（识别结论）
2. ☐ **为什么？给了什么理由？**（检查理由）
3. ☐ **关键词是否明确？**（排查歧义）
4. ☐ **他假设了什么我未必认同的？**（找假设）
5. ☐ **推理有没有逻辑跳步？**（查谬误）
6. ☐ **证据靠谱吗？**（评估证据）
7. ☐ **有没有其他解释？**（想替代）
8. ☐ **数据有没有坑？**（警惕陷阱）
9. ☐ **什么没说？**（找省略）
10. ☐ **还能得出什么别的结论？**（想替代结论）
