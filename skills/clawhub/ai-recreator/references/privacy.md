# 隐私与数据处理说明

## 数据流向总览

```
用户粘贴链接 → [yt-dlp下载] → [Whisper语音转写] → [LLM改写] → [TTS合成] → [视频输出]
                        ↓              ↓                    ↓
                  视频临时存储    转写文本临时存储    改写文本临时存储
                        ↓              ↓                    ↓
                  任务完成后     任务完成后            任务完成后
                  可选保留       自动清理（1h）       可选保留
```

## 本地优先原则

所有数据默认在你自己的机器上处理，不上传任何第三方服务（除非自配 LLM API）。

### ✅ 始终本地处理

| 步骤 | 隐私说明 |
|------|---------|
| 视频下载 (yt-dlp) | 本地下载，不从你的服务器离开 |
| 语音转写 (Whisper) | 本地 GPU/CPU 推理，不使用任何云端 ASR |
| TTS 合成 (edge-tts) | 使用 Microsoft Azure Edge TTS（需联网流式传输音频数据，微软 [隐私政策](https://privacy.microsoft.com/)） |
| TTS 合成 (MeloTTS) | 纯本地方案，不联网 |
| 数字人生成 (SadTalker) | 纯本地 GPU/CPU 推理，不联网 |

### 🔄 可选联网步骤

| 步骤 | 隐私说明 |
|------|---------|
| LLM 改写 | 使用你配置的 OpenAI 兼容 API。数据会发到你指定的 API 地址。自部署本地 LLM 可完全离线 |
| edge-tts | 微软流式 TTS，音频片段临时经微软服务器。切换为 MeloTTS 可完全离线 |

## 数据存储与清理

### 临时文件

| 目录 | 内容 | 清理策略 |
|------|------|---------|
| `data/temp/` | 下载、转写、合成的中间文件 | 任务完成后即时清理 |
| `data/downloads/` | 原始视频 + 提取音频 | 保留至任务完成，1 小时后清理 |
| `data/audio/` | TTS 合成音频 | 保留至任务完成，1 小时后清理 |
| `data/transcripts/` | 语音转写文本 | 保留至任务完成，1 小时后清理 |
| `data/output/` | 最终生成视频 | **默认不自动删除**，请手动清理不需要的结果 |

### 改写文本

`data/rewrites/` 中的改写结果会保留。如需删除，清除该目录即可。

## 用户上传素材

- **参考视频 / 数字人照片**：上传后存储在 `data/temp/{task_id}/`，任务完成后自动清理
- 仅作生成用途，不用于训练、分析或第三方共享

## API 密钥安全

- API Key 仅存储在 `backend/.env` 文件中
- 不写入日志、不暴露在 API 响应中
- 通过 pydantic-settings 安全管理，仅工具自身在运行时读取

## 建议

1. **处理敏感内容时**：建议本地部署 LLM（Ollama + 本地模型），确保所有数据不经过外网
2. **商用部署**：注意设置访问鉴权，防止他人未经授权使用你的实例
3. **定期清理**：`data/output/` 中的生成结果不会自动删除，建议定期清理或设置定时任务
4. **不保存凭据**：Web UI 不保存用户的 API Key，每次使用独立的 `backend/.env` 配置
