# 新手快速上手指南

## 10 秒开搞

> **你已经安装了 Python 3.9+ 和 FFmpeg**

```bash
cd ai-recreator

# 1. 装依赖
pip install -r backend/requirements.txt

# 2. 配环境（至少写 API Key）
echo 'OPENAI_API_KEY=sk-xxx' > backend/.env

# 3. 启动
cd backend && uvicorn main:app --host 0.0.0.0 --port 8080

# 4. 打开浏览器 → http://localhost:8080
```

## 3 句话会用

> 打开网页 → 粘贴抖音链接 → 点"开始创作" → 等 3 分钟看结果

## 第一次用，试哪个链接？

任何公开的抖音/TikTok 口播类短视频都可以。推荐：
- "产品介绍"类（信息密度高，改写效果明显）
- "知识分享"类（转写→改写后更口语化）
- **不推荐**：音乐/MV、无旁白的风景或美食视频（没有口播内容可改写）

## 怎么判断是不是正常在工作？

浏览器里能看到 5 步进度条一步步跑完：
① 下载 → ② 转写 → ③ 改写 → ④ 配音 → ⑤ 数字人

如果某一��卡住超过 2 分钟，刷新页面重新看看。

## 不想等 3 分钟？

- 视频越短处理越快（15-30 秒的视频约 1 分钟出结果）
- 无 GPU 时数字人步骤较慢，但你可以先关掉浏览器，回来再看任务结果
- 任务进度可通过 `GET /api/tasks/{task_id}` 随时查询
