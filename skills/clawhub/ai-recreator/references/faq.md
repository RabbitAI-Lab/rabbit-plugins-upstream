# FAQ — AI 二次创作 × 数字人口播

## 通用问题

### Q1: 这个工具是干什么的？
粘贴抖音/快手/短视频链接，等约 3 分钟，AI 会自动把视频里的口播文案提取出来 → 改写成"像你自己说的" → 合成你的声音 → 生成数字人视频。一条龙，全自动。

### Q2: 需要什么硬件条件？
- **最低配置**：任何有 Python 3.9+ 的机器，2GB 内存，无需 GPU（自动降级规则改写 + edge-tts）
- **推荐配置**：8GB 内存，有 CUDA 显卡（Whisper + SadTalker 加速）
- **云端运行**：服务器无需 GPU 也能跑核心流程，数字人部分可用 API 方案

### Q3: 需要 API Key 吗？
- AI 改写（LLM 改写）：需要 OpenAI 兼容的 API Key，不提供则自动用规则改写
- 其他步骤：都不需要 API Key

### Q4: 支持哪些短视频平台？
抖音（douyin.com、iesdouyin.com）、TikTok、快手（kuaishou.com）。其他平台（小红书、B站、视频号）通过 yt-dlp 可能也可用，但未专门测试。

### Q5: 处理一条视频要多久？
约 1-3 分钟。主要耗时在 Whisper 转写（30-60s）和 SadTalker 生成（60-90s）。短视频（< 1 分钟）更快。

### Q6: 支持什么语言？
中文为主。Whisper 支持 99 种语言转写，但 AI 改写和 TTS 默认针对中文优化。英文需要调整语音引擎。

### Q7: 生成的视频可以商用吗？
工具本身不限制。但请注意：原始视频内容可能受版权保护，请自行判断二次创作的合规性。

### Q8: 数字人效果怎么样？
- SadTalker：单张照片生成口型 + 头部动作，画质 256px，适合半身口播
- 无 GPU 时：自动降级为静态图 + 音频视频
- 如需更高质量，推荐部署完整版 SadTalker（支持 512px）或使用 D-ID/HeyGen API

### Q9: 怎么换数字人形象？
在 `.env` 中设置 `SADTALKER_REF_IMAGE=/path/to/your/photo.jpg`，或者通过 AI调用时传入 ref_image 参数。建议使用正面、光线均匀的半身照。

### Q10: 改写的效果能控制吗？
可以。在高级选项中填写"风格提示"，例如：
- "用更轻松幽默的语气"
- "像产品经理做发布会"
- "加入自己的经历"
- "用更正式严肃的语言"

## 边缘场景

### Q11: 视频链接打不开 / 下载失败
可能原因：链接失效、视频设为私密、平台反爬限制。解决方法：换一个公开链接试试。yt-dlp 有 3 次自动重试。

### Q12: 转写结果不准（方言 / 杂音）
更换更大的 Whisper 模型：在 `.env` 中设置 `WHISPER_MODEL=medium`（需要更多内存）。或者先人工修正转写结果再提交。

### Q13: 改写后内容偏离原意
可在高级选项中限制改写幅度，例如说"请尽量保留原文语气，只去掉网络用语"。

### Q14: TTS 合成的声音不像自己
当前默认使用 edge-tts 的标准中文声。要生成更像自己的声音，需要使用声音克隆引擎（CosyVoice/MeloTTS）并准备个人录音样本。未来版本将支持声音克隆。

### Q15: 数字人画面卡顿/表情僵硬
这是 SadTalker 的正常表现。要提高画质，可以：
1. 安装完整 SadTalker 到 `/opt/SadTalker`
2. 使用高清参考照片（500px 以上正面照）
3. 改用 Wav2Lip + 原视频做唇同步

### Q16: 可以批量处理多个视频吗？
当前为单任务模式。需要批量处理请多次调用 API，或在后台启动多个 worker。

### Q17: 生成的视频文件在哪里？
默认在 `data/output/` 目录下，以任务 ID 命名。通过 Web UI 可直接下载。文件每 1 小时自动清理。

### Q18: 支持 Docker 部署吗？
支持。可自行构建 Dockerfile，核心依赖为：Python 3.10 + ffmpeg + yt-dlp。GPU 版需额外配置 CUDA。

### Q19: 部署后怎么限制他人滥用？
建议：
1. 不对外暴露端口（仅绑定 127.0.0.1）
2. 在前端或 API 网关层加简单鉴权
3. 限制单个 IP 的任务频率

### Q20: 遇到 bug 或想提需求？
这是一个开源项目。可以提交 Issue 或 PR。
