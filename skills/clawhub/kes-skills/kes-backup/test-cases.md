# KingbaseES 备份恢复测试用例

## 测试用例 1: KRC 在线热备份

**场景**：生产库需要不停机做全量备份

**输入问题**："怎么对金仓数据库做在线热备份？"

**期望答案要点**：
- 使用 KRC 工具进行在线备份
- 配置归档模式
- 执行 `krc_backup` 命令
- 验证备份集完整性

**验证方法**：答案包含 KRC 工具和归档模式配置

## 测试用例 2: PITR 时间点恢复

**场景**：误删表，需要恢复到 10 分钟前的状态

**输入问题**："数据被误删了，怎么恢复到指定时间点？"

**期望答案要点**：
- 评估数据丢失范围，确定恢复时间点
- 准备恢复环境，隔离生产流量
- 全量备份恢复 + WAL 归档回放至目标时间点
- 验证数据完整性后切换流量

**验证方法**：答案包含 PITR 流程和 WAL 回放

## 测试用例 3: 逻辑备份与恢复

**场景**：需要迁移单个 schema 到另一台服务器

**输入问题**："怎么导出金仓数据库的一个 schema 并导入到另一台库？"

**期望答案要点**：
- 使用 `sys_dump` 工具进行逻辑备份
- 指定 schema 参数导出
- 在目标库执行导入
- 验证对象和数据完整性

**验证方法**：答案包含 sys_dump 的使用方法和参数
