# KingbaseES 数据库参数调优测试用例

## 测试用例 1: shared_buffers 调优

**场景**：服务器内存较大，需要调整 shared_buffers

**输入问题**："金仓数据库 shared_buffers 设多少合适？"

**期望答案要点**：
- 物理内存的 1/3 ~ 1/2
- 需要重启生效

**验证方法**：答案给出 1/3 ~ 1/2 的比例
