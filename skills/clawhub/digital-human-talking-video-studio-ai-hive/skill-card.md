## Description:

This skill helps merchants, knowledge creators, and enterprise content teams turn digital-human talking-video needs into reviewable scripts, shot and background plans, subtitle highlights, batch variable tables, AI-HIVE video tasks, and acceptance checks.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users, developers, and content operations teams use this skill to plan and run Chinese digital-human talking-video production for ecommerce, advertising, marketing, educational short videos, and social campaigns. It produces reviewable plans first, then can guide AI-HIVE API calls for media generation after parameters, routing, authorization, and possible costs are confirmed.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can submit AI-HIVE media generation jobs that may incur charges.

Mitigation: Review prompts, models, routing, pricing snapshots, and sample outputs before running paid or batch generation.

Risk: The skill handles API keys for AI-HIVE access.

Mitigation: Treat API keys as sensitive, prefer environment variables unless local persistence is intentional, and avoid exposing keys in files, logs, screenshots, or repositories.

Risk: The skill can upload reference media and download generated assets.

Mitigation: Upload only media the user is authorized to use and verify rights, privacy, brand, and platform constraints before publication.

Risk: Generated marketing or talking-video content can contain misleading claims or unsupported performance promises.

Mitigation: Keep factual claims tied to supplied evidence, do not promise sales, ranking, review approval, or return on investment, and require human review before publishing.
