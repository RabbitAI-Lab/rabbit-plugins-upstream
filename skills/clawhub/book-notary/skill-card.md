## Use Case: <br>
External users and agents use this skill to search for notary providers, check availability, and create a booking through Lokuli's MCP service. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill contacts Lokuli's external MCP service for notary search and booking tasks. <br>
Mitigation: Install it only when that external service is intended for the workflow. <br>
Risk: Booking creation sends customer name, email, and phone number to Lokuli. <br>
Mitigation: Before creating a booking, confirm the provider, time, service, and contact details with the user. <br>
