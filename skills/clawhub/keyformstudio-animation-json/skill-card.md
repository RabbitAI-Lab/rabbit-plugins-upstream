## Description:

Generate and validate VASF JSON animations for import into Keyform Studio. Use when asked to create an animation JSON, a "vasf" file, a Keyform Studio animation, or to fix a JSON rejected by the importer.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and animators use this skill to create and validate VASF animation JSON for import into Keyform Studio.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated animations may not match the intended motion or project requirements.

Mitigation: Review the generated animation and validate it with the bundled Python validator before importing it into Keyform Studio.
