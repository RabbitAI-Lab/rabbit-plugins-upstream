## Known Risks and Mitigations: <br>
Risk: The skill asks for and stores TikTok account-session cookies, which can grant account access if exposed. <br>
Mitigation: Use a non-primary TikTok account, treat cookies like passwords, restrict file permissions, and delete saved cookie files after use. <br>
Risk: The artifact uses hard-coded local storage paths for generated carousel data, metrics, and TikTok cookies. <br>
Mitigation: Review and change storage paths before running the scripts, especially in shared or production environments. <br>
Risk: Automated posting can publish incorrect, unwanted, or policy-sensitive content if prompts, captions, or generated images are not reviewed. <br>
Mitigation: Review carousel prompts, generated images, captions, and TikTok posting settings before any upload or publication. <br>
