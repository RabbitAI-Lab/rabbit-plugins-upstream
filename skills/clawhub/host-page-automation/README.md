# 宿主页面自动化 Skill：Agent 使用说明

## 安装

通用 Agent Skills 客户端：

```bash
npx skills add shenjie002/host-page-automation-skill
```

Claude Code Plugin Marketplace：

```text
/plugin install host-page-automation --marketplace shenjie002/host-page-automation-skill
```

本目录可交给任何支持读取文件、使用浏览器工具和多轮推理的 harness/Agent。它提供探索与验证方法，不绑定特定模型、Agent 产品、MCP 客户端或浏览器插件。

目标是让 Agent 像开发者使用控制台一样，逐步调查陌生页面的框架、元素、组件实例、状态绑定和业务交互，为后续开发提供可复现证据。不是只做 DOM 点击，也不默认建设通用填表引擎。

## 1. 使用前准备

### 文件

保持以下文件及相对路径完整：

```text
host-page-automation/
  SKILL.md
  README.md
  references/
    frameworks-and-controls.md
    validation.md
```

按 harness 的技能加载方式安装；不支持自动发现时，直接将 `SKILL.md` 的绝对路径交给 Agent，让它读取。文件存在不等于已经加载。

- 先读 `SKILL.md`；调查框架前读 `references/frameworks-and-controls.md`；提供脚本、记录结果或验收前读 `references/validation.md`。

### 浏览器能力

优先使用已有浏览器调试工具，例如 Chrome DevTools MCP，或具备等效能力的插件/调试连接。至少应能够：

- 列出并明确选择目标页面。
- 读取局部页面结构和元素引用。
- 在目标页面执行局部 JavaScript，以调查宿主运行时对象。
- 返回有界、可序列化的结果和错误信息。

交互工具、控制台和网络观察按任务需要使用。只有截图/点击能力时，不承诺能够调查框架内部实例；没有网页执行工具时提供最小控制台探针，请用户执行并回传脱敏摘要。

接入参数、工具名称、frame 选择方式以当前版本文档和工具 schema 为准。不要调用其他环境才有的工具，也不要向工具参数添加 schema 未声明的字段。MCP 服务连接成功不代表已经连到目标浏览器，须用最小页面读取验证。

调试连接权限可能覆盖整个浏览器 profile。优先使用测试 profile 和测试草稿，不读取无关页面。模型是否本地运行不决定数据是否外发，需核对实际服务与数据政策。

## 2. 可以直接交给 Agent 的任务说明

将下面的 Skill 路径和调查目标替换为实际内容：

```text
请读取 <Skill目录绝对路径>/SKILL.md，并按需读取其中的参考资料。

使用当前可用的浏览器工具，调查目标页面中的【具体字段/区域/弹窗】。
先列出页面让我确认目标，再核实 frame、宿主框架与组件库证据。

本次是页面运行时探索，不是只识别 DOM 或点击元素：
- 从目标元素追踪关联组件、父链、props、表单 prop、模型、候选和事件/方法。
- 自行编写小段局部探测代码，根据每轮结果选择下一步。
- 通过实际绑定配置、引用关系或前后观察建立关联；同值或名称相似不能单独证明绑定。
- 入口失败时尝试适用的框架线索；明确不可用时说明阻塞，不编造实例或方法。
- 不打印完整实例、store、全页 HTML、凭据或无关业务数据。
- 需要交互时先说明目的和影响，等我授权；我也可以手动操作后让你继续。
- 不修改项目代码，不选业务记录、不确认回填、不保存提交，除非另行授权。
- 页面变化后重新获取元素和实例；连续无新增证据时停止并汇报。

最终交付：框架证据、可复现获取代码、实例关系、状态绑定证据、
实际操作路径或待验证假设、限制及下一步最小验证。
```

普通局部只读步骤在已授权范围内自行推进，不需要每次都询问“是否继续”。涉及 getter、Proxy 或未知函数时，不把代码表面没有赋值当成无副作用保证。

## 3. Agent 的工作循环

```text
确认目标与授权范围
  → 观察页面和上下文
  → 提出一个局部调查假设
  → 执行最小探测
  → 检查结果并记录证据
  → 继续调查 / 请求人工协作 / 输出报告
```

重点规则：

1. **目标身份优先**：路由、业务区域、组件归属、prop、行身份共同限定作用域，检查唯一性，不取全页第一个匹配。
2. **运行时按事实调查**：框架与组件库分别判断，允许混合框架；内部入口不存在时标注不可用。
3. **有界输出**：限制遍历深度、属性数、数组项和文本长度；标注截断，不把截断列表当完整候选集。
4. **状态分层**：区分 DOM 展示、组件状态、内部表单、外部业务对象、业务 ID 和后台持久化。
5. **引用会失效**：弹窗、Tab、查询和联动后重新定位，不持久保存活对象或临时索引作为身份。
6. **发现不等于验证**：看到方法或事件绑定只能证明其存在，不能证明调用语义与业务效果。
7. **交互也属于探索**：允许在授权后打开必要区域，但不能借探索绕过只读/禁用、业务前置或权限。

React 函数组件不保证存在传统实例或可恢复的 Hook 变量名；Angular 生产构建可能没有调试接口；其他框架私有接口也不作为跨版本承诺。

## 4. 人工协作与 AFK

### 人工协作（HITL）

需要打开弹窗、切业务 Tab、查询数据或调用未知方法时，说明：目标入口、调查目的、可能影响、允许做什么和不做什么。用户可批准一次动作，也可手动完成后回复“继续”。

等待人工操作期间不并发控制页面；恢复后重新核对页面、业务身份与实例。批准打开弹窗不包含选择记录、确认或保存。

### 有限自主探索（AFK）

由用户在开始前明确站点、页面、目标、允许交互、禁止事项和停止条件。例如：

```text
允许在指定测试草稿中打开关联记录选择弹窗并读取其结构；
不查询、不选记录、不确认、不保存。遇到额外权限或目标不唯一时停止。
```

授权范围内自主推进，范围外暂停汇报。用户不在场不是默认授权。时间和次数预算只有工具/运行时强制执行时才是硬限制，不声称提示词具备可靠定时停止能力。

本 Skill 不实现权限隔离、持久无人值守、崩溃恢复或工具拦截。任意 JavaScript 工具可能改变页面；需要强制控制时应另设工具边界并限制旁路，而非只增加提示词。

## 5. 从探索进入操作验证

探索证据足够后，只在用户明确允许的测试字段/草稿中执行最小验证：

```text
记录必要原状态 → 执行一个动作 → 等待可观察变化
  → 核对显示、组件、业务身份/模型与关联结果 → 决定下一步
```

记录实际路径：正常 UI 输入/点击、脚本 DOM 赋值与合成事件、组件方法，或业务回调。不把“框架定位”写成“框架赋值”。未知方法不调用来试错，不能直接改私有状态制造成功。

查询、选中、确认分别设置检查点。重新按业务身份匹配候选，不沿用查询前的选中索引。无候选、多候选、加载未完成或身份不确定时停止。

超时不等于动作未发生，先回读再决定，不盲目重放。发生部分修改时说明停止位置和人工核对方式，不承诺回滚。确认回填与保存/提交分别授权，前者成功不代表后者完成。

## 6. 必须留下的交付物

使用 `references/validation.md` 的模板，至少保留：

- 环境、目标范围、框架及组件库证据。
- 可复现的局部获取代码，作用域和唯一性/有效性检查。
- 元素、组件、模型、候选、业务身份的关联证据。
- 实际使用过的探测和操作路径；未运行的骨架代码单独标注。
- 动作前、查询后、选中后、确认后的必要状态摘要。
- 等待条件、异常分支、部分结果和未验证项。
- 下一步最小验证建议。

只将经过审核的可复用经验沉淀到 Skill；不把测试记录、动态 ID、一次性权限或真实业务快照变成默认配置。业务标识的简单哈希不等于匿名化，交付他人前仍需审查。

## 7. 后续开发如何交接

探索和单项验证完成后，先整理最小脚本与调查记录，不默认创建插件或修改仓库。

只有用户明确要求产品化时，才分析目标仓库的桥接、权限、运行时与执行模块。浏览器调试工具下成功不等于插件注入环境成功，迁移后重新验证执行上下文、事件行为、联动和错误处理。

业务产品接口只接受白名单参数/动作，不接受任意脚本；这与开发辅助探索允许局部探测代码是两个不同阶段。

优先补实际缺口：方法不足改 Skill，重复探测沉淀脚本，工具能力不足再补工具。不要为了分层预建空模块或新平台。

## 8. 常见问题

| 现象 | 处理 |
| --- | --- |
| 只截图、点击，没有运行时调查 | 让 Agent 回到元素与组件关系，提交实际证据和获取代码 |
| 工具参数校验失败 | 检查当次 schema，移除未声明字段；不要靠重连掩盖参数问题 |
| 找不到内部实例 | 检查 frame/world、节点归属与适用入口，明确生产构建限制 |
| 显示更新但模型没变 | 停止写入，核对事件链、受控组件和业务绑定，不叠加事件试错 |
| 查询后仍有旧选中状态 | 重新按候选业务身份选择并核验，不复用旧索引 |
| 总结很好但无法开发复现 | 补实际运行代码、唯一性检查、等待条件和证据来源 |
| 用户只要求探索，Agent 开始改代码 | 停止实现，回到当前授权阶段；产品化不是默认下一步 |
