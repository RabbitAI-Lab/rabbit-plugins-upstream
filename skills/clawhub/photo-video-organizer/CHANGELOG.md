# 变更日志 / Changelog

## v2.0.0 (2026-10-28)

全球化重构版本。核心方法论不变，地区相关内容全部抽象为可切换的地区档案。

### 新增
- **地区档案机制**：`references/region_cn.md`（中国大陆）+ `references/region_global.md`（海外），SKILL.md Step 0 判定地区后动态加载；覆盖坐标系、行程表数据源、聊天工具文件名、云盘生态、手机导入路径、时区六大差异维度；各附一个完整用户验证用例。
- **`scripts/datum_convert.py`**：GCJ-02/BD-09↔WGS-84 离线坐标转换（纯标准库），含往返校验模式（偏差应为 0）、单点/CSV 批量转换。
- **多轮递进去重**（guide §12）：深度轮全局重聚类（0.88）+ 大组递归拆分（0.96）；宠物/特殊主题组单独 0.98 调参（实测保留率 20%→60–85%）；同姿势跨景别识别；最佳照片水平/垂直对齐评分。
- **GPS 来源审计**（guide §13）：区分"真实 GPS"与"行程表盖章 GPS"，各年月分布报告，总数 diff=0 校验。
- **覆盖度分析**（guide Phase 6.5）：月份断档清单 + 按 EXIF 年份归档（附回滚清单）。
- **受限沙箱执行注意**（guide §14）：mkdir/cp/heredoc/chmod 静默失败的替代方案。
- **阶段进度记录纪律**（guide §15）：每阶段完成度+验证数字+遗留+回滚清单。
- 双语 README（中/英）、LICENSE (MIT)、CHANGELOG。
