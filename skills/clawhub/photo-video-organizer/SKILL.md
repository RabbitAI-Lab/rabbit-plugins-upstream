# 时光梳理·照片视频梳理（v2.0 · 全球通用版）

## 概述
专为【跨多年、超大数量】照片视频资料库设计。当照片视频来自手机/网盘/聊天工具/无人机等多源、反复下载导致拍摄时间与 GPS 错乱、重复泛滥时，本 skill 把它们梳理成"时间正确、GPS 齐全、画质完整、重复较少、结构清楚"的长期资料库——便于后续在手机上生成"多年的回忆精选集"。方法论全球通用，地区差异通过**地区档案**动态适配。

## ⚠️ 使用前需人工准备（skill 不代劳）
1. 一份完全未处理的原始备份（动手前必留）。
2. 多年行程表（哪天在哪个城市）——需自行从交通/消费记录梳理（方法见 `references/guide.md` Phase 1.5，数据源按地区档案 §2）。这是写 GPS 的前提。
3. 运行环境：exiftool 13.x、Python 3.10+ 及 opencv/clip/torch 等。
4. 人工终判：去重候选由算法给出，需在对比 HTML 上核定后才移动。

## 总纲（不可让步）
> 先备份再去重；先隔离，不真删；先修时间，再导入图库；照片和视频分开处理；软件辅助，人工终判。
- 所有"删除"一律**可逆移入子文件夹**（保留 mtime + 回滚脚本），绝不直接 rm。
- 元数据硬要求：传输保 EXIF 时间/GPS，禁用会压缩剥离元数据的聊天工具传原件。
- 时间来源优先级：原生 EXIF > 可解析的文件名时间戳 > **绝不用 mtime**（网盘下载污染）。

## Step 0　判定地区并加载地区档案（每次都做）
问用户或在盘点中判断（文件名形态/云盘名/城市字段都是线索），然后**读对应档案并在全程遵循**：
- 中国大陆用户 → 读 `references/region_cn.md`（GCJ-02 坐标系⚠️、12306/微信/支付宝行程源、华为/百度网盘生态、北京时间）
- 海外用户 → 读 `references/region_global.md`（WGS-84 直用、Google Timeline/银行账单行程源、iCloud/Google Photos 生态、按拍摄地时区）
- 库里两地混合（如出境游）→ 两个档案都读，**逐文件按拍摄地判定**，不要一刀切。

## 完整流程（Phase 0–8，详见 `references/guide.md`）
```
Phase 0    盘点与平铺（判定地区在此步）
Phase 1    拍摄时间修复（EXIF/文件名时间戳；视频按拍摄地时区换算 UTC）
Phase 1.5  构建多年行程表（数据源按地区档案 §2）← GPS 前置
Phase 2    拍摄 GPS 写入（按拍摄时间查行程表；先转 WGS-84；保留已有真 GPS）
Phase 3    文件名统一（YYYYMMDD_HHMMSS_设备.ext）
Phase 4    完全相同去重（头尾 MD5 指纹 + 全量校验；LIVP 整包校验）
Phase 5    相似去重（CLIP + 日期分组；25% 保留；大组递归细分；深度轮 0.88 二次筛；
           宠物/特殊主题组单独 0.98；可交互 HTML 人工核定）
Phase 6    低质量/模糊隔离（三因子评分 + 防误伤抽检）
Phase 6.5  覆盖度分析（月份断档清单）+ 年份归档（可选）
Phase 7    哈希校验清单（MD5+SHA1，断点续传）
Phase 8    导入手机/云相册（方法按地区档案 §6）
```
每阶段结束**必须**按 `guide.md` §15 纪律写阶段进度记录（完成度+验证数字+遗留）+ 回滚清单。

## 如何使用本 skill
1. **先做 Step 0**（地区判定），再读 `references/guide.md`——每步的详细做法、命令、坑都在里面（§12 多轮去重、§13 GPS 来源审计、§14 沙箱执行、§15 进度纪律是 v2 新增）。
2. **元数据/文件名可信度规则**：`guide.md` §2（19/20 位聊天工具 ID 不可解、保存≠拍摄时间等，全球通用）。
3. **视频差异**（UTC/时区、AVI 限制、关键帧 CLIP、大文件前段抽帧、动态照片）见 §5。
4. **坑汇总表**见 §6（28 条，按频率排序）。
5. **脚本**在 `scripts/`（参数化，无硬编码路径）：
   - `exif_scan.py` EXIF 扫描 → `exact_dup.py` 字节级去重 → `similarity_embed.py` CLIP 嵌入 → `similarity_cluster.py` 聚类择优 → `interactive_review_html.py` 人工核定页 → `move_reversible.py` 可逆移动+回滚 → `hash_manifest.py` 哈希清单
   - `datum_convert.py` **GCJ-02/BD-09↔WGS-84 坐标转换 + 往返校验**（中国大陆用户写 GPS 前必用；境外坐标直接用，勿转换）

## 关键坑速记（详见 guide.md §6）
- 不用 mtime 推时间；聊天工具 19/20 位 ID 不含时间；保存时间≠拍摄时间（16% 跨日）。
- **国内地图坐标先转 WGS-84 再写 EXIF；境外坐标勿转换**（datum_convert.py）。
- exiftool 每批 ≤400（超 ARG_MAX）；`-r` 漏读大疆 UserData GPS → 单文件直扫。
- 视频 CreateDate 存 UTC，按**拍摄地时区**换算（不是固定减 8h）；部分华为设备偏 +1h 需按批还原；AVI 写不进 GPS。
- 禁用感知哈希判相似；CLIP + 日期；大组递归细分；每组 25% 保留（上限 5 下限 1）。
- LIVP 必须封面+视频都同才算整包重复；静态图与 LIVP 不判重复；动态照片配对视频别单独移走。
- 长任务断点续传 + 分批 + 可逆移动 + 回滚脚本；每阶段落盘进度记录。

## 最终结果
`07_最终保留/`（去重完+时间对+GPS 齐+命名统一）+ 若干 `待删除（...）/`（可逆）+ 完整追溯链（映射/日志/哈希/GPS 来源审计）+ 可安全导入苹果/安卓/云相册的长期资料库。
