## 能为你做什么（个人社保八大场景）

### 一、延迟退休年龄计算
- 📅 **精准计算**：根据性别和出生年月，按渐进式延迟规则计算法定退休时间
- 🔄 **弹性退休**：可提前3年或延迟3年，帮你判断哪种选择更优
- 📋 **最低缴费年限**：2029年前15年→2030年起逐步提高至20年，帮你确认是否达标

**典型问法：**
```
"我1975年出生什么时候退休？"
"延迟退休怎么算？"
"弹性提前退休划算吗？"
```

### 二、基本养老金测算
- 💰 **养老金组成**：基础养老金 + 个人账户养老金，帮你理解计算公式
- 📊 **缴费档次对比**：60%/80%/100%/200%/300%档位养老金差异测算
- ⚖️ **多缴多得 vs 长缴多得**：帮你在缴费档次和缴费年限之间做最优选择

**典型问法：**
```
"养老金能领多少？"
"按60%和100%交，退休差多少？"
"交30年60%和交15年100%哪个领得多？"
```

### 三、灵活就业参保选档
- 🏠 **参保指南**：养老20%（8%个人账户）+ 医保4.5%-10%可选
- 📈 **档次推荐**：按收入水平和年龄段推荐最优缴费档次
- 💡 **省钱技巧**：4050补贴叠加、按年缴纳避免断缴、每年调档策略

**典型问法：**
```
"灵活就业社保怎么交最划算？"
"灵活就业选哪个档次好？"
"灵活就业医保选哪种？"
```

### 四、4050社保补贴
- 🎯 **资格判定**：女≥40/男≥50，或低保/残疾/零就业等扩展人群
- 💵 **补贴测算**：50%-70%缴费补贴，年省3000-10000元
- 📝 **申请指引**：三登记→缴费→申请→审核全流程辅导

**典型问法：**
```
"4050补贴怎么申请？"
"我能领多少社保补贴？"
"4050补贴能领几年？"
```

### 五、社保转移接续
- 🔄 **跨省转移**：线上通办，向转入地申请即可
- 🏥 **医保转移**：个人账户随转，异地就医直接结算
- 📍 **待遇领取地判定**：帮你确定在哪里领养老金

**典型问法：**
```
"社保怎么转移？"
"多地缴的社保怎么合并？"
"在哪里领养老金？"
```

### 六、断缴影响与补救
- ⚠️ **影响评估**：购房落户、医保报销、养老金金额受影响程度
- 🔧 **补救方案**：当年补缴、医保3个月宽限期、企业漏缴仲裁
- 🛡️ **防骗提醒**：识别"一次性补缴多年"骗局

**典型问法：**
```
"社保断缴了怎么办？"
"医保断缴多久有影响？"
"社保能补缴吗？"
```

### 七、居民医保与职工医保
- 🏥 **对比选择**：居民医保vs职工医保的缴费、报销、退休待遇差异
- 🌐 **异地就医**：备案流程+直接结算+个人账户跨省共济
- 💊 **大病保障**：大病保险、医疗救助衔接

**典型问法：**
```
"居民医保和职工医保选哪个？"
"异地就医怎么报销？"
"医保个人账户能给家人用吗？"
```

### 八、个人养老金与失业保险

## 重要提示与边界声明

**重要提示**
1. **退休年龄以官方为准**：通过"电子社保卡"小程序"法定退休年龄计算器"查询个人确切退休时间

3. **缴费不断档**：当年断缴须在12月31日前补缴，医保断缴超3个月有等待期
4. **防骗牢记**：中介声称能"一次性补缴多年社保"的都是骗局

**边界（本技能不做的）**
- **不代办**：社保参保、缴费、转移等需登录操作的事项
- **不代理**：社保争议代理等需执业资质的事务
- **不担保**：养老金核定、退休审批等最终以经办机构为准

**服务说明**
- 每次提问都能获得完整闭环：智能问答 → 政策依据 → 计算工具 → 规划建议 → 风险提示 → 反馈评价

**隐私保护**
