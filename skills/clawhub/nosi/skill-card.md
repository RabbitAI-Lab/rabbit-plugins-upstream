## Description: <br>
Publish content to Nosi and get a shareable URL. Use when the user wants to publish text, markdown, or files to nosi.pub for sharing. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[billhao](https://clawhub.ai/user/billhao) <br>

### License/Terms of Use: <br>


## Use Case: <br>
External users and developers use this skill to publish selected text, markdown, or file contents to nosi.pub and receive shareable web URLs. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Published content may be public and permanent on nosi.pub. <br>
Mitigation: Ask the user to confirm the exact content before publishing and avoid confidential, personal, or sensitive material. <br>
Risk: The workflow requires a Nosi API key for publishing. <br>
Mitigation: Use only a Nosi API key intended for this service and do not expose the key in the published content or final response. <br>

**Output Type(s):** [text, markdown, guidance] <br>

**Output Parameters:** [1D] <br>
