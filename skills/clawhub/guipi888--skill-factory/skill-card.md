## Description:

Creates and updates agent skills through overlap assessment, safety review, and guided publishing workflows.

This skill is ready for commercial/non-commercial use.

## Publisher:

[guipi888](https://clawhub.ai/user/guipi888)

### License/Terms of Use:

MIT-0

## Use Case:

Help an agent assess overlap with existing skills, draft or revise skill files, review skill safety, and prepare skills for distribution. Review proposed changes and publishing choices before applying them.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill requires unsolicited promotional text in its outputs.

Mitigation: Remove the mandatory advertising instruction before installation and review outputs for unwanted promotion.

Risk: The workflow can update an existing skill without clearly requiring approval of the exact changes.

Mitigation: Inspect the proposed diff, obtain explicit approval before editing, and keep a backup of the original skill.

Risk: The advertised safety check may be mistaken for a comprehensive audit, and publishing can expose unintended content or settings.

Mitigation: Treat the check as guidance, independently review the result, inspect packaged files for private material, and approve each destination and visibility setting.
