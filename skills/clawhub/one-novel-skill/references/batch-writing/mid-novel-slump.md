# 中期疲软应对 — 30-80 章

## 为什么中期会崩

| 原因 | 表现 | 频率 |
|:----|:----|:----:|
| 主线疲劳 | 读者知道主角早晚赢，缺紧张感 | 极高 |
| 套路重复 | 打脸->升级->打脸->升级，读者腻了 | 高 |
| 支线失控 | 配角线写飘了收不回来 | 中 |
| 力量体系崩坏 | 数值膨胀，打斗失去悬念 | 中 |
| 读者弃书 | 追读率从 30% 跌到 5% | 中高 |

## 应对方案

### 1. 引入新悬念层
- 原先的对手格局 -> 背后的势力/世界观扩展
- 加倒计时：某事件在 N 章后必然发生
- 角色前史秘密揭一角留一角

### 2. 换地图/换节奏
- 新场景（新城市/新宗门/新领域）
- 新规则（主角失去金手指 -> 重新适应）
- 时间跳跃（3 个月后/3 年后）

### 3. 深挖角色
- 配角独立成章（非主角视角写 1-2 章）
- 反派动机合理化（写反派过去）
- 主角内心冲突（不是打不过，是不想打/不敢打）

### 4. 快刀斩乱麻
- 直接砍掉拖节奏的支线
- 用一次重大事件（死亡/背叛/灾难）重置读者预期
- 中期掉 10% 收藏比后期掉 30% 好
