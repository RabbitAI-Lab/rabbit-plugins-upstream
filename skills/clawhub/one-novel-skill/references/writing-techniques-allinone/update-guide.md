# 技能更新指南

> 本指南说明如何检测和同步技能更新，确保始终使用最新版本。

---

## 第一篇：更新机制概述

### 1.1 更新原理

技能更新通过以下机制实现：

1. **版本号检测**: 比较本地版本号与最新版本号
2. **文件哈希比对**: 使用SHA256检测文件是否被修改
3. **增量更新**: 只更新有差异的文件
4. **备份回滚**: 更新前自动备份，支持一键恢复

### 1.2 更新流程图

```
获取更新包 → 检查版本 → 检查文件是否被修改 →
├── 未修改 → 自动更新（增量同步）
└── 已修改 → 提示用户 → 
    ├── 强制更新（覆盖用户修改）
    └── 手动合并（保留用户修改）
更新完成 → 更新版本信息 → 生成更新报告
```

## 第二篇：更新方法

### 方法一：自动更新（推荐）

```bash
# 1. 检查更新
python auto_updater.py check

# 2. 如果有更新，执行更新
python auto_updater.py update
```

### 方法二：强制更新

当技能文件已被用户修改，但需要覆盖为新版本时：

```bash
python auto_updater.py force-update
```

**注意**: 此操作将覆盖所有用户修改，但更新前会自动创建备份。

### 方法三：手动更新

1. 将新的 `全能AI小说创作.zip` 放到项目根目录
2. 运行 `python auto_updater.py check` 确认检测到更新包
3. 运行 `python auto_updater.py update` 执行更新

## 第三篇：备份与恢复

### 3.1 创建备份

```bash
python auto_updater.py backup
```

### 3.2 查看备份

```bash
python auto_updater.py list-backups
```

### 3.3 恢复备份

```bash
python auto_updater.py restore backup_20260601_195700
```

## 第五篇：更新注意事项

1. **更新前会自动备份**: 即使强制更新，也会先创建备份
2. **用户修改的文件会被跳过**: 普通更新模式下，检测到被用户修改过的文件不会被覆盖
3. **版本号在 version.json 中**: 首次安装后运行一次更新脚本即可初始化版本记录
4. **更新后重启生效**: 更新完成后重新加载技能即可生效
