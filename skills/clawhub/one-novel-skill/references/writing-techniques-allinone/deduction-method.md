# 创作资料库与推衍方法论

## 一、创作资料库结构

在项目 `research/` 目录下维护以下文件：

```
research/
├── background.md          # 题材背景资料整理
├── deduction-log.md       # 推衍记录（设定→情节推导过程）
└── scene-inventory.md     # 场景清单（防复用）
```

### 1.1 background.md — 背景资料
整理与小说题材相关的背景知识：
- 历史/文化背景
- 专业知识（如涉及特定领域）
- 参考作品的关键信息
- 创作灵感和素材来源

### 1.2 deduction-log.md — 推衍记录
记录从设定到情节的推导过程：
- 每次创作前的思考链
- 角色行为逻辑推衍
- 情节发展的多种可能性推演
- 已排除的方案及原因

### 1.3 scene-inventory.md — 场景清单
与 `tracking/scene-usage.md` 配合使用：
- 已使用的场景类型列表
- 已使用的情节模式列表
- 已使用的情感表达方式列表

## 二、推衍方法论

### 2.1 设定→情节推导流程

```
Step 1: 明确设定
- 选定一个核心设定（如"主角有读心术"）

Step 2: 逻辑推衍
- 这个设定会导致什么后果？
  - 能听到别人的真实想法
  - 会听到不想听的秘密
  - 无法分辨真假（如果别人有意识地想假话）
  - 过度使用会导致精神疲惫

Step 3: 情节生成
- 基于后果设计具体场景：
  - 主角在谈判时听到对方的真实底价 → 成功拿下合同
  - 主角听到朋友心里在骂自己 → 友情出现裂痕
  - 主角被陷害，因为对方在心里想假话让他误会

Step 4: 冲突设计
- 设定带来的优势 → 引发他人嫉妒/觊觎
- 设定带来的代价 → 成为剧情障碍
- 设定的边界 → 制造困境
```

### 2.2 角色行为推衍

```
角色动机 → 在当前情境下的可能行为 → 选择最符合角色的行为 → 该行为导致的结果 → 结果引发的新情境
```

记录格式：
```
## 推衍记录 #{编号}

### 设定/情境
{描述}

### 推衍链
1. {前提} → {推论1}
2. {推论1} → {推论2}
3. {推论2} → {结论}

### 采纳方案
{最终选择的方案及理由}

### 排除方案
- {方案1}: {排除理由}
- {方案2}: {排除理由}
```

### 2.3 情节可能性推演

对关键剧情节点，推演多种发展方向：

```
## 节点: {关键事件描述}

### 可能性A: {方向描述}
- 前置条件:
- 后续发展:
- 情绪效果:
- 可行性: 高/中/低

### 可能性B: {方向描述}
- 前置条件:
- 后续发展:
- 情绪效果:
- 可行性: 高/中/低

### 推荐方案: {选择}
- 理由:
```

## 三、思考链记录规范

每次创作前记录思考链，确保创作逻辑可追溯：

```
## 创作前思考链

### 当前进度
- 卷: 
- 章: 
- 已推进的主线: 
- 已完成的支线: 

### 待推进内容
- 本章核心:
- 需要回收的伏笔:
- 需要埋设的伏笔:

### 逻辑推导
- 上章结尾状态:
- 本章应接续的状态:
- 角色在当前状态下的合理反应:
- 预计的剧情走向:

### 潜在问题
- 需要检查的一致性点:
- 需要避免的重复:
- 需要控制节奏的点:
```
