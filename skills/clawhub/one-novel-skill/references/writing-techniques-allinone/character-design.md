# 人物设计方法论（完整版）

> 人物设计没有绝对"规则"，但有被广泛验证的核心原则：逻辑自洽、动机清晰、反差立体、行为驱动，且始终服务于故事。
> 完整的人物塑造理论详见 `references/narrative-theory.md` 第十一篇。

---

## 第一章 人物设计核心公式

### 1.1 四维核心公式

```
身份标签 + 执念目标 + 致命弱点 + 反差秘密
```

| 维度 | 说明 | 示例 |
|------|------|------|
| **身份标签** | 角色最直观的定位 | 高冷剑仙、废柴赘婿、天才神医 |
| **执念目标** | 驱动角色行动的核心欲望 | 想重开轮回、想证明自己、想复仇 |
| **致命弱点** | 角色的软肋与限制 | 怕孤身一人、感情用事、过度自信 |
| **反差秘密** | 与表面形象形成反差的隐藏真相 | 其实是被流放的魔尊、其实是隐世强者 |

**公式套用示例**：

```
高冷剑仙（身份）想重开轮回（执念），
却怕孤身一人（弱点），
其实是被流放的魔尊（秘密）。
```

### 1.2 三维结构：过去—现在—未来

每个重要人物需有完整的三维结构：

| 维度 | 说明 | 创作要点 |
|------|------|---------|
| **过去创伤** | 塑造角色当前性格的关键经历 | 确定1-2个决定性事件，不贪多 |
| **现在准则** | 角色当前的行为逻辑和底线 | 从创伤中推导出现在的信条 |
| **未来弧光** | 角色在故事中的成长方向 | 明确起点→终点，中间设3-5个转折点 |

**示例**：
```
过去创伤：幼时被最信任的师兄背叛，全家被灭门
现在准则：绝不信任任何人，万事靠自己
未来弧光：从孤僻→逐渐信任同伴→最终为保护同伴牺牲
```

## 第二章 三大基石

### 2.1 动机合理

**原则**：行为必有因果。角色的每一个重大选择，都能从角色的经历、性格和当前处境中找到原因。

**检查方法**：
- 这个角色为什么这么做？→ 能否从人设中找到答案？
- 换一个性格的人会怎么做？→ 不同性格应有不同选择
- 如果找不到合理动机，说明动机设计需要修改

### 2.2 性格一致

**原则**：除非有铺垫的弧光，否则角色性格应保持一致。

**允许的变化**：
- ✅ 经历重大事件后的成长/堕落（需有过程和铺垫）
- ✅ 在极端压力下的反常表现（需合理解释）
- ✅ 隐藏性格的逐步暴露（需前期伏笔）

**禁止的行为**：
- ❌ 为推进剧情强行改变角色行为模式
- ❌ 无任何铺垫的性格反转
- ❌ 角色做"作者需要他做的事"而非"角色自己会做的事"

### 2.3 情感真实

**原则**：让读者能共情，不需要角色"讨喜"，但需要角色"可信"。

| 共情方式 | 说明 | 示例 |
|---------|------|------|
| 共同经历 | 唤起读者相似的经历体验 | 被误解、失去亲人、努力却失败 |
| 合理反应 | 角色在特定情境下的反应符合人性 | 恐惧时会颤抖、愤怒时会失控 |
| 内心挣扎 | 展示角色在做决定时的纠结 | 道德与利益的两难选择 |
| 弱点暴露 | 角色在脆弱时刻的真实表现 | 独自一人时的崩溃 |

## 第三章 塑造关键：Show, Don't Tell

### 3.1 四大塑造手段

| 手段 | 说明 | 示例（Tell→Show） |
|------|------|-------------------|
| **选择** | 角色在关键时刻的选择最能体现人设 | Tell:"他很勇敢"→ Show:面对必死的局面，他挡在同伴身前 |
| **小动作** | 习惯性动作反映性格 | Tell:"他很紧张"→ Show:他不停地转手中的笔，指节发白 |
| **对话** | 说话方式、用词习惯、语气 | Tell:"他很刻薄"→ Show:"就你这水平？还是回去再练十年吧。" |
| **冲突** | 压力下的反应最真实 | Tell:"他很善良"→ Show:明明可以独吞宝物，却分给了受伤的陌生人 |

### 3.2 避免的塑造方式

- ❌ 旁白直接说明性格（"张三是个善良的人"）
- ❌ 大段心理描写代替行动
- ❌ 通过其他角色之口做评价（"李四这人真不错"）

## 第四章 功能优先：配角设计原则

### 4.1 配角核心公式

```
配角 = 1个核心功能 + 1个记忆点
```

| 核心功能 | 记忆点示例 |
|---------|-----------|
| 映照主角 | 与主角性格相反的对照组、主角的镜子 |
| 推动情节 | 提供关键信息、制造转折、创造机会 |
| 承载主题 | 体现故事的核心价值观或反价值观 |
| 制造冲突 | 与主角理念冲突、争夺资源、情感纠葛 |

### 4.2 配角设计检查

- [ ] 这个配角有独立的动机吗？（即使只是简单动机）
- [ ] 去掉这个配角，故事是否受影响？
- [ ] 读者能否用一句话记住这个配角？
- [ ] 这个配角是否只是"信息传输工具"？

### 4.3 配角类型参考

| 类型 | 核心功能 | 记忆点设计 |
|------|---------|-----------|
| 导师 | 提供指导、推动成长 | 毒舌但真心、神秘但可靠 |
| 战友 | 并肩作战、情感支持 | 嘴硬心软、牺牲精神 |
| 对手 | 制造冲突、促使成长 | 可敬的敌人、扭曲的价值观 |
| 恋人 | 情感驱动、角色成长催化剂 | 欢喜冤家、命运羁绊 |

## 第五章 避坑红线

### 5.1 常见陷阱

| 陷阱 | 问题 | 解决方案 |
|------|------|---------|
| **脸谱化** | 善/恶非黑即白，缺乏深度 | 给反派合理动机，给正派真实缺陷 |
| **人设崩塌** | 无铺垫的行为反转 | 任何性格变化需有前兆和过程 |
| **过度解释** | 用心理描写代替行动 | 用行动展示性格，而非用文字说明 |
| **主角光环** | 吞噬他人能动性，所有角色围着主角转 | 让配角有自己的目标和行动线 |

### 5.2 网文 vs 纯文学侧重点

| 维度 | 网文 | 纯文学 |
|------|------|--------|
| 人设呈现 | 强靠"三章标签"快速立人设 | 更重隐晦动机与心理真实 |
| 典型手法 | 废柴/神医/赘婿 + 反差 | 细节堆砌、渐进揭示 |
| 共同底线 | **人物必须在故事中"做选择"**，每个选择都该让读者说"这人就该这么干" |

## 第七章 人物设计自审清单

### 设计完成后逐项检查

#### 核心自审
- [ ] 角色的执念目标是否清晰？（读者能否一句话说清他想要什么？）
- [ ] 角色的致命弱点是否真实？（不是"怕高"这种无关痛痒的弱点）
- [ ] 角色是否有反差秘密？（即使是配角，也要有让读者"哦？"的瞬间）
- [ ] 角色的行为是否都有动机支撑？

#### 三维结构检查
- [ ] 过去创伤：是否有1-2个决定性事件？
- [ ] 现在准则：创伤如何影响现在的行为？
- [ ] 未来弧光：起点到终点的路径是否清晰？

#### Show, Don't Tell 检查
- [ ] 是否有至少一个"选择"场景体现角色核心性格？
- [ ] 是否有标志性的小动作/口头禅？
- [ ] 对话风格是否与人设一致？
- [ ] 冲突中的反应是否符合角色性格？

#### 配角功能检查
- [ ] 每个配角都有1个核心功能？
- [ ] 每个配角都有1个记忆点？
- [ ] 去掉这个配角，故事会受影响吗？

#### 避坑检查
- [ ] 反派有合理动机（非纯粹邪恶）？
- [ ] 人设变化有铺垫和过程？
- [ ] 没有用大段心理描写代替行动？
- [ ] 配角有独立的目标和行动线？
