# 章纲设计规范

## 一、每章纲必须包含

```
## 第X章 - {标题}

### 本章核心
一句话概括本章内容。

### 主线推进
- 主线A: 推进到什么程度
- 主线B: 推进到什么程度（如有）

### 出场角色
- 主角: 状态/行为
- 角色A: 状态/行为
- ...

### 关键事件
1. 事件一（描述）
2. 事件二（描述）
3. ...

### 伏笔操作
- [埋设] 伏笔A: 内容描述
- [回收] 伏笔B: 对应伏笔ID
- [延续] 伏笔C: 新进展

### 情绪节奏
- 开头: 读者情绪状态
- 中间: 情绪变化
- 结尾: 情绪落点

### 结尾钩子
本章结尾的悬念/反转/推动力

### 字数目标（强制）
{2200-3500} 字（仅统计汉字，用户有特定要求则以用户为准）
```

## 二、章纲编写原则

1. **每章必须有推进**: 不能在原地打转，每章都要推动剧情
2. **钩子强制**: 每章结尾必须有钩子，让读者想看下一章
3. **出场角色控制**: 单章出场角色不超过5-7个（群像戏除外）
4. **视角一致性**: 尽量保持单章单一视角
5. **字数区间（强制）**: 章节正文{2200-3500}字，短故事小节{1500-2500}字。用户有特定要求则以用户为准。

## 三、章节取名规范

### 命名风格
- **二字标题**: 简洁有力（如"觉醒""危机""真相"）
- **四字标题**: 信息量大（如"天外来客""绝境逢生"）
- **七字标题**: 网文常用（如"一朝觉醒震惊天下"）
- **诗句式**: 文艺感（如"春风不度玉门关"）

### 命名原则
1. 有吸引力（制造悬念或情绪冲击）
2. 不剧透关键反转
3. 风格统一（全书标题风格一致）
4. 可辨识（不与其他章节标题雷同）
