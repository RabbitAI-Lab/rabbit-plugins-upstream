# 风格锚定指南（殿堂金番版）

## 一、核心语言风格规范

### 句式铁律
1. **段落不超过3行** — 任何段落超过3行必须拆分
2. **多用动词，少用形容词** — 动词驱动叙事，形容词精简
3. **句子简短有力** — 每句承载一个信息点，避免长复合句
4. **禁止繁复的修辞与静态描写** — 修辞服务于叙事，不为修辞而修辞
5. **语言干净凌厉有画面感** — 用最少的词传递最强的画面

### 动词优先原则
- "他是剑客" → "他握剑，剑光如匹练"
- "她长得很美" → "她推门而入，整个酒馆安静了三秒"
- "天很冷" → "呼出的白气在睫毛上结了霜"
- "他很生气" → "他捏碎了手里的茶杯，瓷片扎进掌心"

### 形容词精简原则
- 每个形容词自问：删掉是否影响理解？
- 能用动词+名词表达的，不用形容词+名词
- "寒冷的冬天" → "冬天，呼出的气结了冰"
- "美丽的风景" → "山风扑面，松涛如海"
- "愤怒的表情" → "他额头青筋暴起，嘴角抽搐"

### 画面感构建
- 用动作带画面：角色做什么，读者自然看到什么
- 用对话带画面：角色说什么，读者自然感受到什么
- 用感官细节：视觉+听觉+触觉+嗅觉，一次用两三种
- 避免抽象概括，用具体细节

## 二、叙事手法选择

### 2.1 叙事人称
- **第三人称有限视角**（推荐）: 以主角视角叙述，读者只知主角所知
- **第一人称**: 代入感最强，适用于悬疑/情感/自传体
- **第三人称全知**: 自由灵活，适用于史诗/群像小说
- **第二人称**: 极强代入感，适用于特殊效果

### 2.2 叙事顺序
- **顺叙为主**: 按时间顺序，条理清晰
- **倒叙开头**: 制造悬念，吸引读者（"他死了。事情要从三天前说起……"）
- **插叙补充**: 交代背景，丰富内容
- **分叙多线**: 多线索并行，条理清楚

### 2.3 叙事节奏
- **详叙**: 关键情节详细展开
- **略叙**: 过渡情节一笔带过
- 详略结合，疏密相间

## 三、叙事语气

- **轻松向**: 口语化、幽默、吐槽式旁白、短句、对话密度高
- **严肃向**: 正式、克制、留白、长句少、信息密度高
- **悲壮向**: 宏大、沉重、史诗感、节奏慢、留白多
- **诙谐向**: 荒诞、戏谑、反讽、反差感
- **温情向**: 细腻、温暖、治愈、日常细节
- **冷峻型**: 短句、克制、少修辞（类似海明威式）
- **华丽型**: 长句、繁复修辞、丰富的感官描写
- **诗化型**: 意象丰富、节奏感强、富有韵律

## 四、对话风格

- 符合角色身份（贵族/平民/学者/武者各有特色）
- 符合性格（直爽/含蓄/暴躁/温和）
- 符合情绪（愤怒时短句急促，悲伤时沉默迟疑）
- 符合关系（亲密/疏远/尊敬/蔑视）
- 增加犹豫词和个性化停顿
- 对话标签替换：多用动作替代"说/道"

## 五、禁用词表

### 绝对禁用
- "——"（全文取消，以其他标点替代）
- "毋庸置疑""不可否认""值得一提的是"
- "总而言之""从某种意义上说"
- "命运的齿轮""命运的转折"

### 尽量少用
- "然而""但是""不过"（避免过多转折词开头）
- "突然""忽然"（用场景展现替代）
- "仿佛""似乎""好像"（用确定性表达替代）
- "在...中""随着..."

## 六、修辞手法选用指南

| 写作目的 | 推荐修辞 | 示例 |
|---------|---------|------|
| 让描写更生动 | 比喻、拟人 | "月光如水""风在呜咽" |
| 增强情绪 | 夸张、反复 | "绝不！绝不！" |
| 突出对比 | 对比、对偶 | "生如夏花，死如秋叶" |
| 引发思考 | 反问、设问 | "难道不是吗？" |
| 含蓄表达 | 象征、双关 | "那只断线的风筝" |
| 创造新颖感 | 通感、借代 | "冰凉的月光""端起酒杯" |
| 增强气势 | 排比 | "忘了时间，忘了地点" |

## 七、表现手法选用指南

| 写作目的 | 推荐手法 | 说明 |
|---------|---------|------|
| 吸引读者 | 悬念、开门见山 | 设置悬而未决的问题 |
| 增强结构 | 首尾呼应、承上启下 | 形成闭环，自然过渡 |
| 制造反差 | 抑扬结合、对比衬托 | 先抑后扬增强冲击 |
| 渲染氛围 | 烘托渲染、情景交融 | 环境服务于情绪 |
| 深化内涵 | 借古讽今、托物寓意 | 含蓄表达深层主题 |
| 丰富层次 | 虚实相生、点面结合 | 宏观+微观结合 |
| 埋下伏笔 | 伏笔、铺垫 | 为后文做准备 |
| 画龙点睛 | 卒章显志 | 结尾点明主旨 |
| 表达生动 | 白描细描、正面侧面 | 简洁或细腻地刻画 |

## 八、AI文本规避对照表

| AI文本特征 | 人类文本特征 |
|-----------|------------|
| 句式规整、对称 | 句式长短不一、有断裂感 |
| 词汇精准但冰冷 | 词汇有温度、有情感倾向 |
| 逻辑完美无缺 | 允许留白和跳跃 |
| 情绪标签化 | 情绪通过行为展现 |
| 对话流畅完美 | 对话有停顿、犹豫、重复 |
| 结构过于规整 | 结构有变化、有意外 |
| 无个性痕迹 | 有个人经验、偏好痕迹 |
| 修辞套路化 | 修辞自然、不刻意 |
| 描写面面俱到 | 有详有略、重点突出 |
