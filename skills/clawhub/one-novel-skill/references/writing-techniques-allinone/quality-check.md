# 质量审查清单与标准（殿堂金番版）

## 一、章节级审查清单（完整版）

### 1.1 前置核对（生成前执行）
- [ ] 大纲比对 — 当前章纲与总纲/分卷大纲一致
- [ ] 前置剧情回顾 — 已逐章回顾前置剧情走向
- [ ] 事件重复检查 — 本章事件不与前置章节重复
- [ ] 逻辑连贯验证 — 本章逻辑与前置剧情无缝衔接
- [ ] 章节定位明确 — 明确本章在卷中的位置和作用

### 1.2 内容完整性
- [ ] 章节正文{2200-3500}字，短故事小节{1500-2500}字（用户有特定要求则以用户为准）
- [ ] 开篇如抛炸弹（首段3句内建立冲突或悬念）
- [ ] 中间有事件推进（非纯水字数）
- [ ] 结尾有钩子（悬念/反转/新线索）
- [ ] 推进了至少一条主线或支线
- [ ] 遵循"一章一核心"原则
- [ ] 主角目标体现明确
- [ ] 开篇聚焦主角、锁定主角视角

### 1.3 逻辑一致性
- [ ] 事件逻辑自洽（因果合理）
- [ ] 时间线无误（与前一章衔接自然）
- [ ] 空间位置连续（角色不会瞬移）
- [ ] 力量体系符合设定（不超纲/不缩水）
- [ ] 严丝合缝的前后衔接
- [ ] 剧情逻辑推衍统一自审

### 1.4 角色一致性
- [ ] 主角行为符合人物卡设定的性格
- [ ] 配角行为符合其动机和背景
- [ ] 对话风格符合角色身份
- [ ] 角色能力没有莫名增强/减弱
- [ ] 角色不OOC

### 1.5 语言质量
- [ ] 段落不超过3行
- [ ] 多用动词，少用形容词
- [ ] 语言干净凌厉有画面感
- [ ] 无AI高频词汇
- [ ] 无语法/标点错误
- [ ] 无繁复的修辞与静态描写
- [ ] 无重复性表达
- [ ] 首尾句式多样差异化
- [ ] 全文无"——"
- [ ] 场景高频词已替换

### 1.6 对话质量
- [ ] 对话自然（非书面化/完美化）
- [ ] 对话符合角色身份和性格
- [ ] 有真实语境中的犹豫词与个性化停顿
- [ ] 对话标签多样化（动作替代为主）
- [ ] 对话推进剧情或刻画角色
- [ ] 对话情绪描写充分

### 1.7 情绪质量
- [ ] 情绪铺垫充分
- [ ] 情绪转换自然
- [ ] 情感色彩丰富
- [ ] 情感浓度适中
- [ ] 有体个体经验痕迹
- [ ] 增强读者代入感
- [ ] 增强文章人情味
- [ ] 情感共鸣强烈

### 1.8 场景质量
- [ ] 无重复场景描写
- [ ] 场景描写有层次感
- [ ] 场景服务于角色塑造
- [ ] 场景使用频率受控
- [ ] 景物描写有层次感
- [ ] 细节描绘增强代入感

### 1.9 伏笔管理
- [ ] 本章埋设的伏笔已登记
- [ ] 本章回收的伏笔已更新状态
- [ ] 无超期未回收的伏笔

### 1.10 读者黏性
- [ ] 本章有悬念设计
- [ ] 章节钩子有效
- [ ] 读者代入感强
- [ ] 段落排序合理（不超过3行）
- [ ] 正文排版清晰
- [ ] 无需附加解释性前言或后记

### 1.11 设定管理
- [ ] 设定作为剧情燃料（非静态说明）
- [ ] 无新增无关设定
- [ ] 只按前文章节内容和剧情大纲细纲续写
- [ ] 将小说设定混进正文内容推进剧情

### 1.12 内容安全审查
- [ ] 敏感词扫描已执行（`scripts/sensitive_scanner.py`）
- [ ] 扫描结果中无红色高风险命中
- [ ] 扫描结果中无橙色中高风险命中
- [ ] 黄色平台限流词已人工复核
- [ ] 高风险模式命中已逐条确认
- [ ] 关键章节（涉政/涉军/涉黑/涉黄/涉毒/涉灵异）已重点复核

## 二、敏感词扫描与关键章节复核流程

### 2.1 扫描时机

| 扫描级别 | 时机 | 范围 | 工具 |
|---------|------|------|------|
| 单章扫描 | 每章写完后 | 本章内容 | `python sensitive_scanner.py chapters/vol-{n}/ch-{n}.md` |
| 批量扫描 | 每卷完成后 | 整卷所有章节 | `python sensitive_scanner.py chapters/vol-{n}/ --dir` |
| 全局扫描 | 每50章 | 全书所有章节 | `python sensitive_scanner.py chapters/ --dir` |
| 定向扫描 | 涉及敏感题材时 | 特定章节 | `python sensitive_scanner.py <文件路径>` |

### 2.2 扫描报告解读

敏感词扫描报告按以下方式解读：

**分类汇总表**:
| 类别 | 风险等级 | 处理方式 |
|------|---------|---------|
| 政治安全 | 🔴高 | 必须修改，零容忍 |
| 英烈/领导人 | 🔴高 | 必须修改，零容忍 |
| 未成年/乱伦 | 🔴高 | 必须修改，零容忍 |
| 低俗色情 | 🔴高 | 必须修改，零容忍 |
| 毒品/犯罪 | 🟠中高 | 必须修改 |
| 封建迷信 | 🟠中 | 视语境修改（奇幻虚构合规） |
| 侵权 | 🔴高 | 必须修改 |
| 平台限流 | 🟡中 | 建议修改或做架空化处理 |
| 高风险模式 | 🔴高 | 必须逐条人工复核 |

**按章节统计表**: 命中数≥3的章节标记为"🔴重点复核"，需逐句审核。

### 2.3 关键章节复核流程

关键章节指：涉及政治、历史、宗教、性、暴力、犯罪、灵异等敏感内容的章节。

```
识别关键章节 → 逐句阅读 → 对照红线清单 →
发现触线内容 → 修改 → 重新扫描 → 确认合规
```

**复核重点**:
1. 政治敏感: 是否有影射、丑化、歪曲的内容
2. 历史敏感: 是否歪曲历史事实
3. 色情敏感: 性描写是否超出含蓄尺度
4. 暴力敏感: 暴力描写是否过度、是否美化暴力
5. 犯罪敏感: 犯罪手法是否详细、是否美化犯罪
6. 灵异敏感: 是否以"真实灵异"为名

### 2.4 修改后复查

修改完成后，重新执行扫描，确认:
- 原命中词已全部删除或替换
- 高风险模式不再触发
- 修改后的内容不引入新的敏感词

## 四、节奏检测标准

- 连续3章以上纯对话 → 需要插入动作/环境/心理描写
- 连续3章以上纯战斗 → 需要插入文戏/情感/对话
- 连续5章以上无重要事件 → 需要增加冲突/反转
- 日常过渡章节占比 > 20% → 需要压缩或增加微冲突
- 单章内出现3个以上场景切换 → 需要检查是否跳跃
- 单章字数超过3500 → 超过上限，需拆分或精简
- 单章字数少于2200 → 未达下限，需充实内容
- 短故事小节字数超过2500 → 超过上限，需拆分
- 短故事小节字数少于1500 → 未达下限，需充实内容
