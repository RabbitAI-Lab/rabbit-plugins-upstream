# emotion-first-methodology.md — 情绪优先写作法

> 融合源: oh-story/story-long-write 的情绪优先方法论 + 题材-情绪映射
> 核心信条: 先定情绪，再定故事。每个场景都必须服务于一个明确的情绪目标。

## 核心方法

1. **先定情绪，再定故事**。说不清交付什么情绪的场景不该存在。
2. **从验证过的模式出发**。先问"什么被验证过有效，我如何重新交付"，少从"我想写什么"起步。
3. **用模块组装**。每个题材都有验证过的剧情模式——反转怎么铺、爽点怎么爆、感情怎么拉扯。
4. **只加载必需信息**。每章只加载"不知道就会写错"的信息。

## 题材-情绪映射表

| 题材 | 核心情绪 | 主题结构 | 章节节奏 |
|:----|:---------|:---------|:---------|
| 打脸/逆袭 | 爽感释放 | 被轻视→展示实力→众人震惊 | 1-2章小打脸，3-5章中打脸，8-12章大高潮 |
| 身份反转 | 震撼+痛快 | 身份隐藏→危机暴露→身份揭晓 | 前30%铺垫，中40%反转，后30%收尾 |
| 感情拉扯 | 意难平 | 相遇→误会→突破→甜蜜→波折→圆满 | 前30%暧昧，中40%波折，后30%甜蜜/决裂 |
| 悬疑紧张 | 紧张+好奇 | 谜题→线索→红鲱鱼→反转→真相 | 每章1新线索+1反转，最后大揭秘 |
| 日常装逼 | 期待感 | 铺垫→展现→震惊 | 每500字1个未解答疑问 |
| 热血燃 | 肾上腺素 | 开局困境→挣扎成长→爆发逆袭 | 每段有节奏推进，不要马拉松式高潮 |

## 对标书使用规范

1. 先问"对标哪本书" → 加载拆文库数据
2. 读 `剧情/情绪模块.md` 的"读者需求"和"情绪引擎与可复现模块"
3. 读 `剧情/节奏.md` 的"关键信息推进"和"情绪触动点"
4. 把对标书的具体角色看成功能位（对手/盟友/催化剂）→ 映射到你的角色

## 生成prompt情绪嵌入块

在每个章节的生成prompt中嵌入：

```
[情绪目标]
本章核心情绪: {emotion}
情绪曲线: 低开高走 / 层层递进 / 反转爆发
章末钩子类型: {hook_type}
每500字必须设1个未解答疑问
开头300字内必须有钩子
```
