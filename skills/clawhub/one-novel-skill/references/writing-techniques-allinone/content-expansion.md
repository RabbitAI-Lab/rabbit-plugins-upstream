# 内容扩展技法 (参考 chinese-novelist-skill content-expansion.md)

## 一、概述→场景扩展

### 1.1 识别可扩展点
- 含有"后来/然后/于是"等过渡词 → 拆成具体场景
- 含有"他感觉/他觉得" → 展开为具体感官描写
- 含有"过了几天/一段时间后" → 补充一个过渡场景

### 1.2 场景扩展模板
```
原句: 他去找了张三。
扩展: 
他穿过三条巷子，在第七根电线杆下停住。
张三靠在墙上，烟头在指间明灭。
"等了你二十分钟。"
"路上耽搁了。"他往张三手里塞了张纸条。
张三没看，直接揣进兜里。
"老地方，今晚。"
```

### 1.3 感官填充清单
每个场景至少包含: [视觉] + [听觉/触觉] + [氛围]
- 视觉: 光/暗、颜色、形状、动作
- 听觉: 声音/安静、说话语气、环境音
- 触觉: 温度、质地、气压
- 嗅觉/味觉: 特殊气味（可选，但很加分）

## 二、对话扩展法

### 2.1 对话三步法
与其: "你去哪？""我去买水。"
不如: "你去哪？"他抬头。"去对面买瓶水，要不要？"他晃了晃口袋里的零钱。"不用。"他又低下头，手机屏幕的光在脸上亮了亮。

### 2.2 对话分层
1. 表面层: 说的内容
2. 潜台词层: 想表达但没直说的
3. 关系层: 对话反映的权力/亲密/距离
4. 情绪层: 语气+肢体+环境衬托

## 三、情节扩展法

### 3.1 三段式扩展
任何简单情节点: 准备 → 执行 → 后果

### 3.2 因果链扩展
一句话事件可以扩展为: 原因 → 准备 → 阻碍 → 解决 → 新问题

### 3.3 冲突升级
对话冲突: 言语冲突 → 动作冲突 → 派系冲突 → 全面冲突
每个层级至少展开2-3个具体回合

## 四、节奏控制

### 4.1 高潮节奏
- 高潮前: 短句加速（2-5字/句）
- 高潮时: 动作交替（一方出击→另一方应对→反制→新变化）
- 高潮后: 长句减速（过渡/反思/铺垫）

### 4.2 段落长度分配
- 紧张场景: 1-2句/段
- 正常推进: 2-3句/段
- 说明/回忆: 3-5句/段
