# 写作前六大库建立指南

> 撰写正文前，必须先建立创作资料库、写作技能库、审查校验库、AI去痕库、写作要求库、铁律库等所有创作与质量保障体系相关库。六大库是正文写作的前提条件，未建立不得开始写作。
>
> **AIGC检测标准**：本技能所有AI去痕标准对标腾讯朱雀AI检测助手（https://matrix.tencent.com/ai-detect/ai_gen），朱雀AI检测准确率高达95%以上，是行业公认的权威AIGC检测工具。检测标准每日自动同步更新。

---

## 总则：六大库建立顺序

六大库必须在正文写作开始前全部建立完毕，按以下顺序执行：

```
Phase 0: 建立创作资料库
  ├── 题材背景资料（按 genre-research-guide.md 词条库匹配）
  ├── 设定参考资料
  ├── 同类作品分析（含各平台热门作品拆解）
  ├── 灵感素材库
  └── 专业领域知识库（历史/军事/行业等需专业知识的题材）

Phase 1: 建立写作技能库
  ├── 风格锚定
  ├── 句式模板（含多样化开头/对话/结尾模板）
  ├── 词汇表（含强动词表、场景高频词替换表）
  ├── 禁用词表
  └── 对话差异化模板（各角色说话风格区分）

Phase 2: 建立审查校验库
  ├── 审查清单（写前/写后/全卷三层）
  ├── 一致性标准（设定/角色/剧情/风格/伏笔/逻辑6维）
  ├── 节奏标准（紧张场景30-40%/过渡章节≤15%）
  ├── 质量门禁（章节/卷/全书三级门禁）
  └── 平台适配标准（各平台审核红线与安全阈值对照）

Phase 3: 建立AI去痕库
  ├── AI痕迹检测规则（29条规则+三大核心特征检测）
  ├── AIGC检测值标准（0-0.5人工/0.5-0.99疑似/0.99-1AI）
  ├── 替换词表
  ├── 禁用结构表
  ├── 去痕检查清单（12项特征评分60分制）
  ├── 对话AI检测专项（角色说话同质化检查/方言细节添加）
  └── 平台AI红线对照表（各平台AI检测机制与安全阈值）

Phase 4: 建立写作要求库
  ├── 平台写作要求（各平台文体/字数/更新频率规范）
  ├── 题材写作要求（各题材核心要素/禁忌/流行趋势）
  ├── 内容安全红线（政治/色情/暴力等审核红线）
  ├── 章节格式标准（标题/分段/标点规范）
  └── 发布流程规范（审核/修改/发布步骤）

Phase 5: 建立铁律库
  ├── 32条创作铁律（大纲/一致性/节奏/角色/去痕等）
  ├── 违规自动检测规则
  ├── 铁律违反修复流程
  └── 铁律更新记录
```

**强制规则**：六大库未全部建立完毕，不得开始正文写作。

## 第一章：创作资料库

### 1.1 资料库结构

```
research/
├── background.md              # 题材背景资料（核心）
├── setting-references/        # 设定参考资料
│   ├── core-setting.md        # 核心设定参考
│   ├── world-refs.md          # 世界观参考
│   └── character-refs.md      # 角色设定参考
├── similar-works/             # 同类作品分析
│   ├── novel-analysis.md      # 同类小说分析
│   └── reader-feedback.md     # 读者反馈整理
└── inspiration/               # 灵感素材库
    ├── plot-ideas.md          # 情节灵感
    └── quotes.md              # 金句/名言素材
```

### 1.2 资料库建立流程

```
Step 1: 收集题材背景资料
  ├── 搜索该题材的核心设定要素
  ├── 搜索相关历史文化背景
  ├── 搜索科学/技术/专业领域知识
  └── 输出到 research/background.md

Step 2: 整理设定参考资料
  ├── 列出所有核心设定条目
  ├── 标注每个设定的来源和可信度
  ├── 标注每个设定的创新点和注意事项
  └── 输出到 research/setting-references/

Step 3: 分析同类作品
  ├── 搜索同类题材热门作品
  ├── 分析其核心卖点和优缺点
  ├── 提取可借鉴元素和需避免的坑
  └── 输出到 research/similar-works/

Step 4: 收集灵感素材
  ├── 收集相关的情节灵感
  ├── 收集可用的金句/名言
  ├── 收集有趣的设定点子
  └── 输出到 research/inspiration/
```

### 1.3 资料库建立检查清单

- [ ] 题材背景资料已收集完毕（research/background.md）
- [ ] 核心设定参考已整理（research/setting-references/）
- [ ] 同类作品分析已完成（research/similar-works/）
- [ ] 灵感素材已收集（research/inspiration/）
- [ ] 所有资料已去重提炼
- [ ] 所有资料已标注来源

## 第二章：写作技能库

### 2.1 技能库结构

```
setting/
├── style-anchor.md            # 风格锚定（核心）
├── writing-templates/         # 句式模板
│   ├── opening-templates.md   # 开头句式模板
│   ├── dialogue-templates.md  # 对话句式模板
│   └── ending-templates.md    # 结尾句式模板
├── vocabulary/                # 词汇表
│   ├── strong-verbs.md        # 强动词表
│   └── scene-words.md         # 场景词汇表
└── banned-words.md            # 禁用词表
```

### 2.2 技能库建立流程

```
Step 1: 建立风格锚定
  ├── 确定叙事语气（轻松/沉重/诙谐/严肃）
  ├── 确定句式偏好（多用动词、少用形容词、段落不超过3行）
  ├── 确定特色修辞手法
  ├── 参考 references/style-anchor.md
  └── 输出到 setting/style-anchor.md

Step 2: 建立句式模板
  ├── 收集3-5种开头句式（动作开头/对话开头/环境开头/设问开头/悬念开头）
  ├── 收集3-5种对话句式
  ├── 收集3-5种结尾句式
  ├── 确保句式多样化，避免重复
  └── 输出到 setting/writing-templates/

Step 3: 建立词汇表
  ├── 收集强动词（替换弱动词"是/有/在/让/使"）
  ├── 收集场景相关词汇（战斗/情感/环境等场景的专用词汇）
  ├── 收集人物描写词汇
  └── 输出到 setting/vocabulary/

Step 4: 建立禁用词表
  ├── 列出AI高频词（随着/首先/其次/最后/因此/由此可见等）
  ├── 列出全程禁用套路起兴词（目的是/为了/从而/进而/让/使等）
  ├── 列出本题材特有的禁用词
  └── 输出到 setting/banned-words.md
```

### 2.3 技能库建立检查清单

- [ ] 风格锚定已建立（setting/style-anchor.md）
- [ ] 开头句式模板已建立（至少3种）
- [ ] 对话句式模板已建立（至少3种）
- [ ] 结尾句式模板已建立（至少3种）
- [ ] 强动词表已建立
- [ ] 场景词汇表已建立
- [ ] 禁用词表已建立（包含AI高频词+全程禁用词）

## 第三章：审查校验库

### 3.1 校验库结构

```
review/
├── checklists/                # 审查清单
│   ├── pre-write-checklist.md # 写前审查清单
│   ├── post-write-checklist.md# 写后审查清单
│   └── volume-checklist.md    # 卷审查清单
├── standards/                 # 质量标准
│   ├── consistency-standards.md # 一致性标准
│   ├── pacing-standards.md    # 节奏标准
│   └── quality-standards.md   # 质量标准
└── gates/                     # 质量门禁
    ├── chapter-gate.md        # 章节质量门禁
    ├── volume-gate.md         # 卷质量门禁
    └── book-gate.md           # 全书质量门禁
```

### 3.2 校验库建立流程

```
Step 1: 建立审查清单
  ├── 写前清单：大纲比对、前置剧情回顾、事件重复检查、逻辑连贯验证、一致性自检三问
  ├── 写后清单：一致性校验、节奏检测、伏笔扫描、对话审查、情绪审查、场景复用检测
  ├── 卷审查清单：卷内伏笔回收、角色成长弧线、卷高潮评估、卷间衔接
  └── 输出到 review/checklists/

Step 2: 建立质量标准
  ├── 一致性标准：设定/角色/剧情/风格/伏笔/逻辑六个维度的具体标准
  ├── 节奏标准：紧张场景占比30-40%、过渡章节不超过15%等
  ├── 质量标准：章节级/对话级/情绪级/场景级/全卷级质量标准
  └── 输出到 review/standards/

Step 3: 建立质量门禁
  ├── 章节门禁：每章完成后必须通过的检查项
  ├── 卷门禁：每卷完成后必须通过的检查项
  ├── 全书门禁：全书完成后必须通过的检查项
  └── 输出到 review/gates/
```

### 3.3 质量门禁标准

**章节质量门禁**（每章通过后才能进入下一章）：
- [ ] 字数在2200-3500字之间（仅统计汉字）
- [ ] 开头有钩子（前100字吸引读者）
- [ ] 结尾有钩子（悬念/反转/新线索）
- [ ] 有明确的事件推进（不灌水）
- [ ] 无AI痕迹（通过AI去痕检测）
- [ ] 无敏感词（通过敏感词扫描）
- [ ] 与大纲一致（不偏离主线）
- [ ] 与前置章节逻辑连贯

**卷质量门禁**（每卷通过后才能进入下一卷）：
- [ ] 卷内伏笔已回收或已安排预期回收位置
- [ ] 角色在卷内有成长弧线
- [ ] 卷尾高潮有足够的情绪冲击
- [ ] 卷间衔接已设计（钩子延续到下一卷）
- [ ] 卷级摘要已生成

**全书质量门禁**（完稿后必须通过）：
- [ ] 全设定库无矛盾
- [ ] 全部伏笔已回收
- [ ] 时间线无矛盾
- [ ] 风格一致
- [ ] 敏感词已全部处理

- [ ] 写后审查清单已建立
- [ ] 卷审查清单已建立
- [ ] 一致性标准已建立
- [ ] 节奏标准已建立
- [ ] 质量标准已建立
- [ ] 章节质量门禁已建立
- [ ] 卷质量门禁已建立
- [ ] 全书质量门禁已建立

## 第四章：AI去痕库

### 4.1 去痕库结构

```
review/
├── ai-removal/                  # AI去痕库
│   ├── detection-rules.md       # AI痕迹检测规则（含AI检测值标准/AI三大核心特征检测）
│   ├── ai-value-standards.md    # AI检测值标准（AIGC值三档判定/人工/AI/疑似AI示例范文）
│   ├── language-patterns.md     # 语言模式化检测（句式重复/连接词模式/开头模板化/修饰语/标点）
│   ├── structure-patterns.md    # 结构规整度检测（段落均匀性/功能固定/信息节奏/三段式/小标题）
│   ├── emotion-patterns.md      # 情感色彩检测（情感词汇密度/抽象标签/转折生硬/个体经验/共情）
│   ├── replacement-dict.md      # 替换词表
│   ├── banned-structures.md     # 禁用结构表
│   ├── removal-checklist.md     # 去痕检查清单（含AI检测值验证12项特征评分）
│   └── examples-db.json         # AI/人工示例数据库（自动搜索更新）
```

### 4.2 去痕库建立流程

```
Step 1: 建立AI痕迹检测规则
  ├── 列出所有AI高频句式（"随着"句式、"他感到"句式、"值得一提的是"等）
  ├── 列出所有AI高频连接词（首先/其次/最后/因此/此外/综上所述等）
  ├── 列出AI模板化结构（三段式、首先分析其次探讨最后总结等）
  ├── **引入AI检测值标准**：参考 `references/ai-removal.md` 第八部分 8.1 节
  │   ├── AIGC值 0-0.5 → 人工特征，合格
  │   ├── AIGC值 0.5-0.99 → 疑似AI，需去痕
  │   └── AIGC值 0.99-1 → AI特征，必须重写
  ├── **引入人工撰写示例作为比对基准**：参考 `references/ai-removal.md` 第八部分 8.2 节
  │   └── 中文技术论文范文（AIGC值 0-0.5），作为人工特征的语言风格基准
  ├── **引入AI撰写示例作为反面教材**：参考 `references/ai-removal.md` 第八部分 8.3-8.4 节
  │   ├── 中文文学散文AI示例（AI特征47.98%），识别AI文学模板化表达
  │   └── 英文Transformer论文AI示例（AIGC值0.99-1），识别AI学术模板化表达
  ├── **引入AI vs 人工对比分析作为检测依据**：参考 `references/ai-removal.md` 第八部分 8.5 节
  │   ├── 中文文学7维度对比表（句式/细节/情感/节奏/语言/结构/意象）
  │   ├── 英文论文7维度对比表（句式/逻辑/信息密度/术语/段落/结论）
  │   └── 人工撰写6大核心特征总结（节奏感/具体细节/情感真实/结构自然/语言个性/张弛有度）
  ├── **引入AI检测值标准（朱雀AI对标版）**：输出到 `review/ai-removal/ai-value-standards.md`
  │   ├── 对标腾讯朱雀AI检测助手（https://matrix.tencent.com/ai-detect/ai_gen）
  │   ├── AIGC值四档判定标准（0-0.2人工/0.2-0.5疑似/0.5-0.8高风险/0.8-1AI）
  │   ├── 朱雀AI检测值对标（0%-20%安全/20%-50%风险/50%-80%高风险/80%-100%AI）
  │   ├── 最低达标标准：朱雀AI检测值≤20%（对应AIGC值≤0.2）
  │   ├── 人工撰写范文（中文技术论文AIGC值0-0.2）
  │   ├── AI撰写示例（公众号热点文AIGC值1.0/文学散文AI特征47.98%）
  │   ├── 疑似AI示例（重生网文/都市系统文AIGC值0.5-0.99）
  │   ├── AI vs 人工对比分析（中文文学7维度/英文论文7维度）
  │   ├── 去痕效果验证流程（12项特征评分60分制）
  │   └── **每日自动同步**：python auto_updater.py sync-zhuque（每日6:00执行）
  ├── **引入语言模式化检测**：输出到 `review/ai-removal/language-patterns.md`
  │   ├── 句式重复率检测：相同句式结构在短篇幅内重复出现
  │   ├── 连接词模式检测："首先/其次/最后""一方面/另一方面"等固定组合
  │   ├── 开头模板化检测：段落开头使用相同结构（"随着……""在……中""通过……"）
  │   ├── 修饰语模式检测：每段出现"非常/很/十分/相当"等程度副词的频率
  │   └── 标点模式检测：破折号/分号/引号的使用频率和分布规律
  ├── **引入结构规整度检测**：输出到 `review/ai-removal/structure-patterns.md`
  │   ├── 段落长度均匀性：各段落字数差异小于20%
  │   ├── 段落功能固定：每段功能明确（引入→分析→举例→总结）
  │   ├── 信息释放节奏均匀：无信息密度突增或突降
  │   ├── 三/四段式结构：内容自然拆分为3-4个等长段落
  │   ├── 开头-正文-结尾比例固定：15%-70%-15%的标准分配
  │   └── 小标题对称：小标题长度和风格高度一致
  ├── **引入情感色彩检测**：输出到 `review/ai-removal/emotion-patterns.md`
  │   ├── 情感词汇密度：正面/负面情感词汇数量低于人工基准
  │   ├── 抽象情感标签：使用"感动/悲伤/愤怒"等抽象词替代具体描写
  │   ├── 情感转折生硬：从悲伤到喜悦缺少过渡铺垫
  │   ├── 缺乏个体经验：情感表达无个人化细节支撑
  │   ├── 情绪描写模板化："心里五味杂陈""百感交集"等通用模板
  │   └── 共情缺失：读者难以对角色产生情感共鸣
  ├── **启用自动搜索更新**：运行 `python scripts/example_updater.py` 自动搜索并增加AI/人工撰写示例
  │   ├── 自动分析语言表达特征（句长/连接词密度/被动语态等）
  │   ├── 自动分析思维逻辑特征（因果链/时间跳跃/视角切换等）
  │   ├── 自动分析细节把握特征（感官细节/具体物品/抽象词汇/重复意象等）
  │   ├── 自动分类示例类型（人工/AI/疑似AI）
  │   ├── 自动更新检测规则和替换词表
  │   └── 自动集成到 review/ai-removal/detection-rules.md
  └── 输出到 review/ai-removal/detection-rules.md

Step 2: 建立替换词表
  ├── 每个AI高频词对应2-3个替换方案
  ├── 每个AI句式对应2-3种改写方式
  ├── 每个禁用结构对应2-3种替代结构
  └── 输出到 review/ai-removal/replacement-dict.md

Step 3: 建立禁用结构表
  ├── 破折号"——" → 替换为逗号/句号/冒号/省略号
  ├── "首先……其次……最后" → 替换为直接叙述
  ├── 分句排比 → 替换为不规则表达
  ├── 三段式价值套话 → 替换为平铺直叙
  ├── 规整并列句式 → 替换为长短句交替
  ├── 书面官样八股文风 → 替换为叙事口吻
  └── 输出到 review/ai-removal/banned-structures.md

Step 4: 建立去痕检查清单
  ├── 空格清理（英文/数字左右无空格）
  ├── 破折号检查（全文无"——"）
  ├── AI高频词检查（无"随着/首先/其次/最后/因此"等）
  ├── 主语灵活性检查（非关键信息可省略主语）
  ├── 长短句交替检查（5-10字短句与20-25字长句交替）
  ├── 口语化连词检查（适当增加"然后/并且/但是/其实"等）
  ├── 打断叙述节奏检查（每500-800字1次反问/设问）
  ├── 句式段落自由组合检查（不同顺序可自由组合）
  ├── 规避模板化表达检查（段落开头不同结构轮换）
  ├── **AI检测值验证**：参考 `references/ai-removal.md` 第八部分 8.6 节
  │   ├── 对12项特征逐项打分（1-5分/项，共60分）
  │   ├── 总分≥48 → 去痕合格
  │   ├── 总分36-47 → 需进一步优化
  │   └── 总分<36 → 必须重写
  ├── **自动搜索更新检查**：运行 `python scripts/example_updater.py` 自动检查是否有新的AI/人工示例需要纳入
  │   ├── 每次写作前：运行 status 查看示例库状态
  │   ├── 每完成一卷：运行 integrate 将最新示例集成到AI去痕库
  │   ├── 发现新示例：运行 add <文件> [类型] 手动添加
  │   └── 示例更新后自动更新检测规则、替换词表和去痕清单
  └── 输出到 review/ai-removal/removal-checklist.md
```

### 6.2 铁律内容

| **角色** | 6, 26, 27 | 角色不可OOC、反派智商在线、主角不能碾压 |
| **AI与原创** | 7, 29, 30, 32 | 禁用词零容忍、零抄袭、AI辅助非代写、全自动检测 |
| **伏笔与审查** | 9, 24, 28, 31 | 伏笔必回收、内容安全第一、全维度审查、六大库先行 |
