# 06-platform-algorithms.md — 平台算法理解

## 一、番茄小说推荐机制深度分析

### 流量分发底层逻辑

番茄小说（字节跳动旗下免费阅读平台）的推荐系统建立在今日头条的算法基因上。与起点等付费平台的"编辑推荐制"不同，番茄的核心是**用户行为驱动的自动化分发**。

### 推荐漏斗模型

番茄的推荐不是一次性大规模推送，而是"层层过滤"的漏斗模型：

**第一层：冷启动（0-3万字）**
- 新书首发后，系统分配基础流量（约200-500个曝光）
- 考核指标：**第一章完读率**（核心）、点击转化率
- 如果第一章完读率＞60%，系统判定"内容质量合格" → 进入第二层
- 如果第一章完读率＜40%，内容被判定为"不符合读者预期" → 停止推荐
- 冷启动期大约3-7天，每天更新2000-4000字

**第二章：小流量测试（3-10万字）**
- 系统扩展流量至2000-5000曝光
- 考核指标：**前三章完读率**、追读率
- 前三章完读率＞50%：进入更大的流量池
- 前三章完读率＜35%：流量快速下降
- 编辑会人工介入评估"为什么完读率高/低"

**第三层：中流量池（10-30万字）**
- 流量扩大到1-5万曝光
- 考核指标：**全本完读率**、用户停留时长
- 系统开始记录用户的后线阅读行为——读到第几章离开
- 如果某个章节有大量用户跳出，系统会给该章节打"低质量标签"
- 黄金三章的完读率仍然是最重要的权重

**第四层：大流量池（30万字以上）**
- 流量可能达到10-100万级别
- 考核指标：**追读率**、分享率、收藏-阅读比
- 追读率=每日更新后24小时内已读用户/总活跃用户
- 追读率＞10% → 书城首页和分类推荐
- 追读率＞20% → 弹窗推荐，这是小说爆发的关键信号

**第五层：爆款推荐（50万字以上）**
- 日曝光百量级
- 优质小说会获得书城首页的Big Card推荐位
- 此阶段的完读率和追读率依然在考核
- 推荐位一旦效果下降，立即被替换

### 番茄算法的核心权重公式

```
推荐量 = f(完读率) × 追读率 × 用户停留时长 × 日更稳定性 × 内容标签匹配度
```

各权重的大约占比：
- 第一章完读率：25%
- 前三章完读率：15%
- 全本完读率：15%
- 追读率：20%
- 停留时长：10%
- 分享率：5%
- 收藏率：5%
- 更新频率：5%

**关键洞察**：完读率比收藏率重要3倍。这意味着在番茄写书，不要把精力花在让人"收藏"上，而要花在让人"读完当前段落"上。

### 番茄的"跳出点分析"

系统会在后台给每个章节标记"跳出点"——用户在这个位置停止了阅读。常见的跳出点：
- 2700-3000字处（番茄通常单章3000字，倒数300字如果不精彩就是致命跳出点）
- 世界观说明性段落（读者不关心设定，跳过）
- 战斗描写的过度细节（过于琐碎的动作描写）
- 情感描写过于冗长

**对抗策略**：
1. 每章在2000字处设置一个小钩子
2. 把最精彩的对话放在2500字之后
3. 最后一句话必须是"下一章钩子"
4. 避免整段环境描写超过200字

### 番茄的更新策略

| 数据维度 | 最优解 | 及格线 | 危险线 |
|---------|-------|-------|-------|
| 日更字数 | 4000-6000 | 2000+ | ＜1000 |
| 更新时间 | 固定时间 | 每日三次 | 随机时间 |
| 更新间隔 | 24h内 | 36h内 | ＞48h |
| 单章长度 | 2500-3500 | 2000-4000 | ＜1500或＞5000 |
| 断更频率 | 0 | 月≤1次 | 月≥3次 |

## 二、起点中文网签约和推荐机制

### 签约机制

起点中文网的签约流程是多层过滤制：

**第一层：自发投稿（审核期3-7天）**
- 后台提交全文或前三万字
- 编辑首次审阅（主要看黄金三章）
- 决定是否"内签"（编辑主动联系作者）

**第二层：签约评估（数据积累期）**
- 字数达到1-3万字，开始积累数据
- 编辑后台监控：追读率、收藏数、推荐票
- 达到"签约线"的指标会在后台显示
- 签约线因品类不同而异：
  - 玄幻/仙侠：追读率＞5%，收藏＞200
  - 都市/竞技：追读率＞8%，收藏＞150
  - 奇幻/科幻：追读率＞3%，收藏＞100

### 推荐位机制（签约后）

起点的推荐位是"阶梯式"的，每次上推荐都需要通过数据考核：

**1. 新书期推荐（签约后-10万字）**
- 新书入库推荐：基础曝光
- 分类新书推荐：同一品类的读者可见
- 数据要求：收藏增长量+追读率

**2. 试水推（约10万字）**
- 分类频道的小推荐位
- 考核：**追读率** 是最核心指标
- 追读率＞10% → 可以上下一级推荐
- 追读率＜5% → 试水推失败，推荐止步

**3. 分强推（约15-20万字）**
- 分类频道的强推推荐位
- 数据要求：追读率持续增长+月票/推荐票活跃
- 本月票榜前100可获得进一步推荐

**4. 首页推荐（重点推荐）**
- 起点App首页的分类推荐位
- 进入首页推荐后，数据要求进一步提高
- 收藏增长量：日增500+为合格

**5. VIP上架（约20-30万字）**
- 这是"挣钱"的门槛，正式进入付费环节
- 上架当天的**首订比**（首章订阅/收藏比）是最重要的数据
- 首订比＞15% → 大神级作品
- 首订比＞10% → 优秀作品
- 首订比＞5% → 及格
- 首订比＜3% → 上架失败

### 起点的追读率计算方式

起点的追读率与番茄不同：
- 同一章节：72小时内阅读记为一次有效追读
- 更新后24小时内阅读追加一倍的权重
- 追读=每日至少阅读1个新章节的用户数/收藏数

**追读率在起点的权重**：
- 新书期：追读率决定是否有编辑推荐
- 上架后：追读率决定是否持续获得推荐位
- 后期：追读率不够的作品会被降低推荐优先级

### 起点内容策略与番茄的差异

| 维度 | 起点（付费） | 番茄（免费） |
|------|-----------|------------|
| 核心指标 | 追读率 | 完读率 |
| 第一章重要性 | 高（锁定读者） | 极高（算法敲门砖） |
| 世界观铺垫 | 需要（有付费耐心） | 不需要（读者快速跳转） |
| 单章字数 | 3000-4500 | 2500-3500 |
| 感情线占比 | 10-15% | 5-8% |
| 群像要求 | 高 | 低 |
| 更新频率 | 日更4000-6000 | 日更4000-6000 |
| 适合类型 | 精品向、群像向、创意向 | 爽文向、数据流、系统流 |

## 三、完读率优化

### 完读率的数学本质

完读率 = 读完某章节的用户数 / 打开某章节的用户数

在番茄的算法中，完读率不是"读完的人/看到的人"，而是"看到最后一行的人/打开的人"。

**关键发现**：用户在打开章节的前3秒就决定了是否完读。这3秒的判断依据包括：
1. 上一章的结尾悬念是否被承接
2. 当前章节开头是否与前章衔接自然
3. 视觉密度——整段太密或太长会让读者直接退出

### 完读率优化策略清单

**策略1：首段爆炸法**
第一章正文的前3段决定了完读率的上限。前3段必须做到：
- 第一段：单句最多3行，极限压缩
- 第二段：展开到5-7行，把一个点说透
- 第三段：抛出一个让你想继续看的点

**策略2：段落即单位**
- 每个段落独立完成一个"信息单元"
- 段落之间用"递进"或"转折"连接，不能用平行关系
- 每个段落结尾都要有推动感

**反面案例**：
> 他修炼了三天三夜。这三天里他吃了很多苦。他每天只休息两个小时。

**正面案例**：
> 他修炼了三天三夜。第一天，手磨破了。第二天，腿站不住了。第三天——他突破了。

**策略3：黄金拐点法**
在每章50%和75%的位置设置两个"假性完结点"——读者看到这里可能以为可以放下，但下一段又抛出一个新信息，让人继续往下看。

**策略4：对话优化法**
- 每300字正文后，至少插入一次对话（不仅是主角与别人对话，也可以独白）
- 纯叙述段落超过500字 → 完读率暴跌
- 信息量密集的段落用对话包装

### 完读率测试方法论

**A/B测试**：在同一本书中，用两种不同的段落结构写相似的内容，对比完读率：

原始写法：
> 阿加塔城的守卫很严格。每个进出的商旅都必须接受检查。李明在队伍中等了两个小时，终于轮到他了。

改写：
> "站住。打开你的包裹。"
> 李明的手一紧。他现在离城门还有五十步，但身后已经排了十几个人。退已经来不及了。
> 守卫的目光落在了他腰间的布袋上。

**效果**：后者的完读率通常比前者高30-40%。

## 四、追读率提升

### 追读率的核心驱动因素

追读不是用户对书"忠诚"，而是"习惯"。追读率提升的本质是：将用户的阅读行为转化为习惯行为。

**习惯形成的三要素**：
1. 触发器（Trigger）——每日更新通知/稳定更新时间
2. 行为（Action）——打开App，点到本书
3. 奖励（Reward）——新的章节内容带来的满足感

### 追读率提升的具体策略

**策略1：稳定的更新时钟**
- 决定一个固定的更新时间（如每晚8点）并坚持
- 用户形成"8点去看更新了"的肌肉记忆
- 时差变化超过30分钟 → 追读率下降10-15%

**策略2：章节结尾的"明日预告"**
每章结尾加上类似"明天揭晓XX的秘密"的明日预告。这会将用户的预期锁定在"明天同一时间"。

**策略3：悬疑的分章技巧**
- 不要在自然段落结束处分章
- 在最紧张的时刻分章（"他的手已经按在了剑柄上——"）
- 分章后要立刻更新（不超过24h），否则追读率下降

**策略4：追读奖励**
在书中暗示"追读的读者知道得更多"——比如在章节末尾暗示"只有坚持看下去的人才会知道真相"，这种meta暗示会让追读率上升。

### 追读率的诊断工具

如果追读率出现下降，从以下维度排查：
1. **章节质量波动指数**：最近5章是否出现了水准下降？
2. **节奏停滞指数**：是否连续10章没有推进主线？
3. **情感投入指数**：主角最近的所作所为是否值得读者关心？
4. **目标模糊指数**：读者是否还知道主角的长期目标是什么？

## 五、各平台数据化运营策略

### 番茄小说的数据化运营

**数据管理工具**：番茄作家助手App

**关键数据指标看板**：
- 日曝光量：新书期200-500，起量期5000+
- 日点击量：曝光量的10-20%
- 日收藏量：点击量的5-10%
- 第一章完读率：目标＞65%
- 前五章完读率：目标＞40%

**数据异常的应对**：
- 曝光高但点击低 → 封面/书名/简介有问题
- 点击高但收藏低 → 前三章没有有效钩子
- 收藏高但完读低 → 后续章节质量下降
- 完读高但追读低 → 每日更新的钩子不够

### 起点的数据化运营

**追读率优化**：
- 新书期目标追读率＞8%
- 如果追读率＜5%，考虑重新开书
- 追读率下降时检查最近的剧情弧

**收藏比优化**：
- 收藏/阅读比目标：＞15%
- 收藏后阅读率：＞40%
- 收藏比下降 → 检查是否有大段"无趣的内容"

### 微信读书/QQ阅读

**特性**：依托于阅文集团社交链，推荐机制融合了社交推荐和算法推荐

**数据策略**：
- 互动率比纯内容平台更重要
- 评论区的活跃度会影响推荐
- 鼓励读者在评论区参与讨论

### 刺猬猫/B站

**特性**：Z世代用户为主，二次元/游戏/同人为核心品类

**数据策略**：
- 段子密度比完读率更重要
- 评论区二创（表情包、同人图）会提升曝光
- 适度的破壁表达（"这个作者有毒"类评论）是推荐的加分项

## 六、全网核心公式

最终，所有平台的数据化运营可以归结为一个公式：

> **收益 = 曝光量 × 完读率 × 追读率 × 付费转化率 × 单价**

- 曝光量 = 平台给你的流量入口
- 完读率 = 你的内容质量
- 追读率 = 你的内容吸引力
- 付费转化率 = 你的内容价值（仅在付费平台）
- 单价 = 你的书的市场定位

每一平台的侧重点不同，但核心逻辑是一致的：**好的内容天然自带数据**。算法不是敌人，而是最公正的读者代表——它只帮读者找到他们真正想读的内容。作为作者，写给读者看，而不是写给算法看——但理解算法能帮助你更好地服务于读者的阅读体验。
