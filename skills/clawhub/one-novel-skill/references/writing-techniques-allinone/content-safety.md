# 内容安全与合规指南

> 本指南列举小说创作中须严格规避的内容红线，以及各平台的审核尺度参考。适用于所有题材的创作，确保作品合规发表。

---

## 第一篇：绝对禁止内容（红线）

以下内容在任何情况下均不得出现在小说中。违反可能导致作品下架、封号乃至法律追责。

### 第一章 政治安全类

#### 1.1 危害国家安全
**禁止内容**: 任何危害国家安全、泄露国家秘密、颠覆国家政权、煽动分裂国家的描写。

**具体包括**:
- 泄露国家机密（军事机密、外交机密、科技机密等）
- 鼓吹分裂国家（如宣扬"独立""分裂"等）
- 歪曲国家历史（如美化侵略、否定抗战）
- 丑化国家形象（如恶意抹黑国家政策、领导人）

**合规说明**:
- 架空/奇幻/穿越类作品，只要不影射现实，通常合规
- 涉及现实历史题材，须尊重历史事实
- 穿越类作品不得美化殖民、歪曲历史

#### 1.2 恐怖主义与极端主义
**禁止内容**: 宣扬恐怖主义、极端主义或煽动暴力、仇恨、种族歧视。

**具体包括**:
- 美化恐怖袭击或恐怖组织
- 煽动民族仇恨、种族歧视
- 宣扬极端宗教思想

#### 1.3 侮辱英烈与领导人
**禁止内容**: 侮辱、诽谤英烈或党和国家领导人（含影射、丑化）。

**具体包括**:
- 以真实英烈为原型进行不当虚构
- 影射、丑化国家领导人
- 歪曲英雄事迹

---

### 第二章 社会公序良俗类

#### 2.1 未成年人性内容
**禁止内容**: 涉及未成年人的性描写、恋童、近亲相奸等违背社会公序良俗的性内容。

**严格禁止**:
- 任何涉及未成年人的直接性描写
- 恋童题材（无论是否虚构）
- 近亲相奸内容
- 以未成年人为性幻想对象的描写

#### 2.2 低俗色情
**禁止内容**: 以性器官、性行为直接描写为卖点，非艺术化、非必要情节。

**区分标准**:
- **合规**: 必要情节中的情感描写，含蓄、艺术化处理
- **不合规**: 以性器官、性行为直接描写为卖点，无艺术价值

**建议**: 感情线中的亲密描写，建议采用含蓄留白的方式（如"省略""第二天"等过渡）。

#### 2.3 毒品与违法犯罪
**禁止内容**: 详细描写毒品制作、使用或美化违法犯罪行为。

**具体包括**:
- 详细描写毒品制作过程
- 美化吸毒体验
- 美化黑社会、诈骗、贩毒等违法犯罪行为

**合规说明**:
- 涉及犯罪题材的作品，应以揭露、批判为主
- 主角不能是违法犯罪者（或需有明显的洗白/改过自新过程）
- 不得详细描写犯罪手法（防止教唆）

#### 2.4 封建迷信
**禁止内容**: 以"真实灵异事件"为名鼓吹鬼神显灵、算命改运等（非虚构类）。

**区分标准**:
- **合规**: 奇幻/玄幻/灵异类作品的虚构设定（如修仙、魔法、鬼怪），明确标注为虚构
- **不合规**: 以"真实事件"为名，鼓吹封建迷信思想

**建议**: 灵异/奇幻类作品，在简介或开头明确标注"本作品纯属虚构"。

---

### 第三章 侵权类

#### 3.1 侵犯名誉权与隐私权
**禁止内容**: 侵犯他人名誉权、隐私权或盗用真实人物（含已故）进行不当虚构。

**具体包括**:
- 以真实人物（含已故）为原型进行丑化或不当虚构
- 未经许可使用真实人物的姓名、肖像
- 侵犯他人隐私（如披露真实个人信息）

**合规说明**:
- 以真实人物为灵感创作时，须做充分的艺术加工，避免被指认
- 涉及公众人物，须特别注意

## 第二篇：各平台审核尺度参考

|------|------|

| **涉灵异（非奇幻）** | 以"真实灵异"为名的迷信内容 |

| 平台 | 审核特点 | 特别注意 |

| 题材 | 风险等级 | 风险说明 | 合规建议 |

| 架空奇幻 | ✅低 | 通常合规 | 标注虚构即可 |

## 第三篇：合规创作指南

### 第一章 红线避让策略

#### 1.1 架空化处理
对于可能触碰红线的现实题材，采用架空化处理：
- 现实官场 → 架空王朝的朝堂权谋
- 现实军事 → 架空世界的战争
- 现实黑帮 → 架空世界的帮派斗争

#### 1.2 虚构声明
在作品简介或开头明确标注：
> "本作品纯属虚构，如有雷同，纯属巧合。"
> "故事背景为架空世界，不映射任何现实事件或人物。"

#### 1.3 正面导向
涉及敏感题材时，确保作品的价值导向是正面的：
- 犯罪题材 → 展现犯罪后果，批判犯罪行为
- 社会黑暗 → 展现光明战胜黑暗
- 悲剧结局 → 具有警示意义

### 第二章 合规自审清单

创作过程中逐项确认：

- [ ] 无危害国家安全、泄露国家秘密的内容
- [ ] 无颠覆国家政权、煽动分裂国家的内容
- [ ] 无宣扬恐怖主义、极端主义的内容
- [ ] 无煽动暴力、仇恨、种族歧视的内容
- [ ] 无涉及未成年人的性描写
- [ ] 无恋童、近亲相奸等内容
- [ ] 无详细描写毒品制作、使用的内容
- [ ] 无美化违法犯罪行为（黑社会、诈骗、贩毒等）
- [ ] 无以"真实灵异事件"为名鼓吹封建迷信的内容（非虚构类）
- [ ] 无侮辱、诽谤英烈或党和国家领导人的内容
- [ ] 无影射、丑化领导人的内容
- [ ] 无以性器官、性行为直接描写为卖点的低俗色情
- [ ] 无侵犯他人名誉权、隐私权的内容
- [ ] 无盗用真实人物（含已故）进行不当虚构
- [ ] 未备案的境外敏感题材已规避
- [ ] 涉政、涉军、涉黑、涉黄、涉毒内容已规避
- [ ] 灵异题材已明确标注为奇幻设定
- [ ] 涉及现实题材的作品已做架空化处理
- [ ] 作品开头已标注"纯属虚构"声明

### 第三章 投稿前检查

在投稿或发布前，执行以下检查：

1. **自查**: 按上述自审清单逐项确认
2. **查阅平台规范**: 查阅目标平台的《创作规范》或《内容审核标准》
3. **敏感词扫描**: 使用敏感词工具扫描全文
4. **关键章节复核**: 涉及政治、历史、宗教、性、暴力等敏感内容的章节重点复核
5. **咨询编辑**: 签约作者可咨询编辑确认内容合规性

### 第四章 常见误区澄清

#### 4.1 "禁书"不等于违法创作
"禁书"多指特定历史时期或境外查禁作品（如《洛丽塔》），不等于中国当前法律明令禁止创作。架空、奇幻、穿越等设定若规避上述红线，通常可合规。

#### 4.2 奇幻/玄幻/灵异的合规边界
- **合规**: 明确标注为虚构的奇幻世界观中的鬼怪、魔法、修仙等
- **不合规**: 以"真实灵异事件"为名鼓吹封建迷信

#### 4.3 最终尺度
最终尺度由平台审核与主管部门动态把握，建议投稿前查阅目标平台《创作规范》。
