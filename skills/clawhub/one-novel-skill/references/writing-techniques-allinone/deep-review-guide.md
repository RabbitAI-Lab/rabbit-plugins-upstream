## 第二章：各维度审查细则

### 2.1 设定审查

**审查要点**：
- [ ] 设定内部是否自洽？（力量体系有无矛盾？规则有无前后不一？）
- [ ] 设定是否成为剧情燃料？（不是静态说明，而是通过冲突展现？）
- [ ] 设定是否有明确的边界和代价？（无敌必须有弱点，能力必须有消耗？）
- [ ] 设定是否足够支撑长篇连载？（是否有拓展空间？）
- [ ] 设定是否迎合对应平台读者？（是否容易理解？是否够爽？）

**对应平台读者偏好设定**（以当前平台为准）：
- 设定简单易懂，不在设定上花费大量解释文字
- 设定服务于"爽"，而不是束缚"爽"
- 力量体系清晰，读者能快速理解谁强谁弱
- 主角的设定优势明显，能让读者代入后获得满足感

**常见问题**：
| 问题 | 表现 | 修正方案 |
|------|------|---------|
| 设定过于复杂 | 大段说明文字，读者看不懂 | 通过剧情自然展现，分批次释放信息 |
| 设定过于平淡 | 缺乏创新，和同类作品雷同 | 在经典设定基础上加入1-2个原创元素 |
| 设定不服务于剧情 | 为设定而设定，和故事无关 | 删除或改造为剧情素材 |
| 设定前后矛盾 | 前面说不能，后面说能 | 统一规则，或在剧情中给出合理解释 |

### 2.2 世界观审查

**审查要点**：
- [ ] 世界观是否完整？（世界格局、势力分布、社会制度是否清晰？）
- [ ] 世界观是否一致？（有无违背世界基本规则的设定？）
- [ ] 世界观是否有探索空间？（是否有未开发的区域/势力/秘密？）
- [ ] 世界观是否让读者有探索欲？（是否有神秘感、未知感？）
- [ ] 世界观是否适合对应平台读者？（是否够宏大？是否够新奇？）

**对应平台读者偏好世界观**（以当前平台为准）：
- 开局清晰，不拖泥带水
- 有明确的升级阶梯和探索路线
- 世界足够大，让读者期待主角的成长空间
- 有神秘元素吸引读者追更（未解之谜、隐藏势力）

### 2.3 主线审查

**审查要点**：
- [ ] 主线是否清晰？（读者是否知道主角要做什么？）
- [ ] 主线是否有足够的推进力？（每章都在推进主线？）
- [ ] 主线是否有吸引力？（读者是否期待下一章？）
- [ ] 主线是否有足够的起伏？（不是平铺直叙？）
- [ ] 主线是否迎合对应平台读者？（是否够爽？是否有期待感？）

**对应平台读者偏好主线**（以当前平台为准）：
- 主线明确，主角目标清晰（变强/复仇/守护等）
- 每章都有主线推进，不跑偏
- 主线节奏紧凑，不拖沓
- 主线中有持续的小目标和小高潮

### 2.4 支线审查

**审查要点**：
- [ ] 支线是否必要？（删除后是否影响主线？）
- [ ] 支线是否与主线有关联？（是否服务于主线的推进？）
- [ ] 支线是否有独立的吸引力？（不是注水内容？）
- [ ] 支线的长度是否合理？（不会喧宾夺主？）
- [ ] 支线是否在合理范围内回收？（没有烂尾的支线？）

**对应平台读者偏好支线**（以当前平台为准）：
- 支线短平快，2-5章内解决
- 支线服务于主线（为主线提供资源/信息/成长）
- 支线中也有爽点（不是纯过渡）
- 不出现与主线无关的支线

### 2.5 人物审查

**审查要点**：
- [ ] 人物动机是否合理？（角色为什么这么做？）
- [ ] 人物性格是否一致？（是否有OOC？）
- [ ] 人物是否有成长弧线？（不是一成不变的？）
- [ ] 人物是否有辨识度？（读者能记住这个角色？）
- [ ] 人物关系是否有张力？（角色间的互动是否有趣？）

**对应平台读者偏好人物**（以当前平台为准）：
- 主角有强烈的代入感（读者能想象自己就是主角）
- 配角有辨识度（不需要刻意记忆也能记住）
- 反派有压迫感（让读者为主角捏一把汗）
- 女性角色有魅力（不是花瓶/工具人）

**常见问题**：
| 问题 | 表现 | 修正方案 |
|------|------|---------|
| 主角完美无缺 | 没有缺点，没有成长空间 | 给主角设计合理的弱点和成长障碍 |
| 配角工具人化 | 出场只为主角服务，没有独立人格 | 给配角设计自己的动机和目标 |
| 角色脸谱化 | 所有角色说话方式一样 | 设计每个角色的独特说话方式和习惯 |
| 角色前后不一致 | 前期谨慎后期莽撞，无过渡 | 添加性格变化的触发事件 |

### 2.6 伏笔审查

**审查要点**：
- [ ] 伏笔埋设是否自然？（不是生硬插入？）
- [ ] 伏笔回收是否及时？（不拖太久让读者忘记？）
- [ ] 伏笔回收是否有惊喜？（不是读者早就猜到的？）
- [ ] 伏笔的密度是否合理？（太多记不住，太少不够看？）
- [ ] 是否有未回收的伏笔？（烂尾伏笔？）

**对应平台读者偏好伏笔**（以当前平台为准）：
- 短期伏笔（3-5章内回收），制造持续的期待感
- 中期伏笔（一卷内回收），制造卷内高潮
- 长期伏笔（跨卷回收），制造追更的动力
- 伏笔回收时要有反转/惊喜，不能太平淡

### 2.7 剧情审查

**审查要点**：
- [ ] 剧情节奏是否合理？（紧张与舒缓交替？）
- [ ] 剧情冲突是否有层次？（小冲突→中冲突→大冲突？）
- [ ] 剧情逻辑是否自洽？（事件A→事件B的因果链完整？）
- [ ] 剧情是否有足够的爽点密度？（对应平台读者是否看得爽？）
- [ ] 剧情是否有反转？（读者是否能猜到后续？）

**对应平台读者偏好剧情**（以当前平台为准）：
- 快节奏开局，前3章必须抓住读者
- 持续有爽点，不出现超过3章的无爽点段落
- 剧情有反转，不要让读者觉得"我猜到了"
- 每章结尾有钩子，让读者想看下一章

**AI检测专项——对话同质化检查**（参考小说AI检测最新标准）：
- [ ] 各角色说话风格是否雷同？是否有区分度？
- [ ] 对话中是否缺少口语化表达和方言细节？
- [ ] 叙事节奏是否呈一条直线（冲突/回忆/转折段句式长度几乎一样）？
- [ ] 情绪起伏是否不足（缺少停顿和情感变化）？
- [ ] 断更后重新写作时，前后章角色语气是否一致？

### 2.8 主角审查（重点）

**审查要点**：
- [ ] 主角是否有代入感？（读者是否能把自己代入主角？）
- [ ] 主角的决策是否合理？（不愚蠢、不冲动、不圣母？）
- [ ] 主角是否有成长？（能力/心态/格局的提升？）
- [ ] 主角是否有弱点？（不是无敌的？）
- [ ] 主角的目标是否清晰？（读者知道主角要做什么？）
- [ ] 主角是否太强？（碾压一切导致失去悬念？）
- [ ] 主角是否太弱？（一直被虐导致读者憋屈？）

**对应平台读者偏好主角**（以当前平台为准）：
- 主角不圣母、不优柔寡断、不当老好人
- 主角有脑子，会思考策略，不是莽夫
- 主角有原则，但不是死板的道德楷模
- 主角有成长空间，让读者期待他的未来
- **主角可以赢，但不能赢得太轻松**（详见第四章）

**常见问题**：
| 问题 | 表现 | 修正方案 |
|------|------|---------|
| 主角光环过重 | 敌人全降智、运气逆天 | 让主角的胜利建立在合理策略和付出上 |
| 主角过于弱势 | 一直被虐，读者憋屈 | 给主角设计阶段性胜利，保持希望 |
| 主角决策降智 | 为了推动剧情让主角做蠢事 | 设计合理的决策逻辑，或者让主角在有限信息下做出最优选择 |
| 主角性格扁平 | 没有成长，从开头到结尾一个样 | 设计性格成长曲线，让挫折改变主角 |

### 2.9 反派审查（重点）

**审查要点**：
- [ ] 反派的智商是否在线？（不是降智反派？）
- [ ] 反派的动机是否合理？（不是纯粹的坏？）
- [ ] 反派是否给主角制造了真正的压力？（不是纸老虎？）
- [ ] 反派是否有自己的成长/变化？（不是一成不变的？）
- [ ] 反派是否有让读者记住的特点？（不是工具人？）

**对应平台读者偏好反派**（以当前平台为准）：
- 反派聪明且有谋略，让读者为主角担心
- 反派有合理的动机（复仇、野心、信念冲突）
- 反派有压迫感（实力/势力/智谋上的压制）
- 反派被打败的过程有悬念（不是一招秒杀）
- **反派必须高智商**：一个低智商的敌人无法衬托主角的强大。反派的智商决定了主角胜利的含金量。

**反派智商提升原则**：
1. **反派也有情报网**：反派会收集主角的信息，会分析主角的弱点
2. **反派会设局**：反派不会傻傻地正面硬刚，会设计陷阱、借刀杀人
3. **反派有底牌**：反派不会把所有实力一次性暴露，有隐藏手段
4. **反派会学习**：反派在第一次失败后会总结经验，调整策略
5. **反派有盟友**：反派不是孤军奋战，有自己的势力和人脉
6. **反派有B计划**：当A计划失败时，反派有备用方案

### 2.10 争斗审查（重点）

**审查要点**：
- [ ] 主角与反派的争斗是否有悬念？（读者是否不确定谁会赢？）
- [ ] 主角是否赢得太轻松？（碾压式胜利会导致爽感降低？）
- [ ] 主角是否输得太惨？（一直被虐会导致读者憋屈？）
- [ ] 争斗的过程是否有策略性？（不是单纯比数值？）
- [ ] 争斗的结果是否有代价？（赢得太轻松=价值低？）

**核心原则：主角不能碾压，必须勉强胜出**

**为什么要"勉强胜出"**：
- 碾压式胜利 → 读者觉得"就这？" → 爽感低、没悬念
- 勉强胜出 → 读者"好险！差一点就输了" → 爽感高、有回味
- 惨败后绝地反击 → 读者情绪起伏最大 → 记忆最深

**"勉强胜出"的设计方法**：

| 方法 | 说明 | 示例 |
|------|------|------|
| **实力接近** | 主角和反派实力在伯仲之间 | 主角比反派强一点，但反派有主场优势/帮手 |
| **以智取胜** | 主角不是靠实力碾压，而是靠策略 | 利用环境/规则/心理战获得胜利 |
| **惨胜** | 赢了但付出了代价 | 主角赢了但重伤/损失重要道具/牺牲队友 |
| **底牌对决** | 双方都使出最后手段 | 主角用最后的底牌险胜反派的底牌 |
| **外部因素** | 借助外部条件险胜 | 利用天时地利、临时突破、意外因素 |
| **时间限制** | 在限定时间内必须获胜 | 援军即将到达/毒发时间将至/目标即将消失 |

**对应平台读者偏好争斗**（以当前平台为准）：
- 争斗有悬念，读者猜不到结果
- 争斗有策略，不是纯数值对撞
- 争斗有反转，至少1-2个意料之外
- 争斗有代价，赢了但付出不小
- 争斗有成长，主角在争斗中获得突破

## 第三章：对应平台读者喜好深度分析

> 以下分析以番茄小说为例。实际审查时，根据当前扮演的平台身份切换为对应的平台读者喜好标准。

### 3.1 对应平台读者核心特征（以番茄为例）

| 特征 | 说明 | 创作影响 |
|------|------|---------|
| **碎片化阅读** | 读者利用碎片时间阅读，注意力分散 | 每章必须有钩子，信息密度要高 |
| **快速判断** | 读者在前3章决定是否继续看 | 前3章必须有冲突/悬念/爽点 |
| **情绪驱动** | 读者为情绪价值付费 | 每章必须有情绪起伏 |
| **代入感至上** | 读者把自己代入主角 | 主角不能做读者反感的事 |
| **追求爽感** | 读者追求"爽"而不是"深度" | 爽点密度要够，不追求文学性 |
| **容忍度低** | 不爽就弃书，没有耐心 | 不能出现超过3章的无爽点段落 |

### 3.2 对应平台读者喜好清单（以番茄为例）

| 喜欢 | 不喜欢 |
|------|--------|
| 主角开局有金手指 | 主角开局太弱、被虐太久 |
| 快节奏、前3章入戏 | 慢热、大段背景介绍 |

### 4.1 全维度审查流程

```
Step 1: 身份确认
  ├── 确认当前扮演的平台身份（番茄/起点/七猫/晋江/纵横）

  ├── 通读全书现有内容（大纲+已写正文）
  ├── 获得整体印象
  └── 标记明显问题

  ├── 设定审查 → 输出设定问题清单
  ├── 世界观审查 → 输出世界观问题清单
  ├── 主线审查 → 输出主线问题清单
  ├── 支线审查 → 输出支线问题清单
  ├── 人物审查 → 输出人物问题清单
  ├── 伏笔审查 → 输出伏笔问题清单
  ├── 剧情审查 → 输出剧情问题清单
  ├── 主角审查 → 输出主角问题清单（重点）
  ├── 反派审查 → 输出反派问题清单（重点）
  ├── 争斗审查 → 输出争斗问题清单（重点）
  └── 其他维度审查 → 输出其他问题清单

Step 4: 问题汇总与分级
  ├── 汇总所有维度的问题
  ├── 按P0/P1/P2/P3分级
  └── 标注每个问题的修改方向和修改方案

Step 5: 修改执行
  ├── P0问题优先处理
  ├── 每修改一处，检查是否影响其他维度

  ├── 更新设定文件（setting/ 目录）

  ├── 更新正文（chapters/ 目录）

  └── 记录修改日志到 setting-change-log.md
```

- 行业知识是否准确？（不能让内行看出破绽）
- 商战/职场冲突是否合理？
- 主角的资源和关系是否来得太容易？

### 5.3 科幻题材
- 科技设定是否自洽？（不能违背基本科学原理）
- 未来社会的描写是否有逻辑？
- 科技是否服务于剧情？（不是炫技）

### 5.4 悬疑题材
- 案件逻辑是否严密？（不能让读者找到漏洞）
- 反转是否出乎意料又在情理之中？
- 线索的释放节奏是否合理？

### 5.5 言情题材
- 感情发展是否有合理的铺垫？
- 男女主的互动是否有张力？
- 感情线是否影响了主线节奏？

### 5.6 网游题材
- 游戏设定是否符合基本游戏设计原理？
- 主角的成长速度是否合理？
- 游戏内的争斗是否有策略性？
