# 番茄短故事分类释义

## 女频类

| 分类       | 释义                                                                  |
| -------- | ------------------------------------------------------------------- |
| **婚姻家庭** | 现代背景，以女性视角，讲述婚姻或家庭生活，围绕伴侣、父母、公婆、子女、姑嫂、亲戚矛盾等关系展开的故事                  |
| **女生生活** | 现代背景，以女性视角，围绕真假千金、职场、寝室、同学、师生等关系展开的故事                               |
| **女性成长** | 现代或古代背景，以女性视角，主线非感情线，主要以女主主观意愿上的成长、女性间的互助、救赎等为主线的故事（不包含复仇、打脸、虐渣类故事） |
| **现言甜宠** | 现代背景，以女性视角，围绕校园、职场、婚恋等展开，讲述男主宠女主、男女主互相暗恋或明恋类的幸福美满类故事                |
| **青春虐恋** | 现代背景，以女性视角，讲述男女主恋爱、谈婚论嫁阶段的言情故事，情绪基调为虐恋、先虐后甜或先虐后爽                    |
| **虐心婚恋** | 现代背景，以女性视角，讲述男女主婚姻阶段的言情故事，情绪基调为虐恋、先虐后甜或先虐后爽                         |
| **宫斗宅斗** | 古代背景，以女性视角，背景发生在宫廷或后宅，情节上以宫斗、宅斗、女性权谋为主线推进的故事                        |
| **古风世情** | 古代背景，以女性视角，围绕家庭、朋友、师徒、姐妹等关系展开的故事，主线非感情线                             |
| **古言甜宠** | 古代背景，以女性视角，言情为主线，讲述男女主互相暗恋或明恋的幸福美满类故事                               |
| **古言虐恋** | 古代背景，以女性视角，讲述男女主两性情感的言情故事，情绪基调为虐恋、先虐后甜或先虐后爽                         |
| **女频脑洞** | 女性视角，背景非现实向，故事主线以系统、金手指、空间、弹幕、穿书等脑洞元素来推进剧情的故事                       |
| **女频衍生** | 明确游戏、动漫、影视作品、公版书籍等既有作品的女频二次创作故事                                     |
| **纯爱**   | 以双男主或双女主之间感情发展作为主线的故事                                               |

## 男频类

| 分类       | 释义                                             |
| -------- | ---------------------------------------------- |
| **男生生活** | 现代背景，以男性视角，围绕职场、家庭、朋友关系等展开的故事，主线非感情线           |
| **都市日常** | 现代背景，以男性视角，围绕都市生活、赘婿、逆袭、升级流、退婚流等元素展开的故事，主线非感情线 |
| **男生情感** | 现代背景，以男性视角，言情为主线，讲述两性情感的言情类故事                  |
| **历史古代** | 古代背景，以男性视角，围绕历史、武侠、权谋、言情展开的故事                  |
| **男频脑洞** | 男性视角，背景非现实向，故事主线以系统、金手指、空间、弹幕、穿书等脑洞元素来推进剧情的故事  |
| **男频衍生** | 明确游戏、动漫、影视作品、公版书籍等既有作品的男频二次创作故事                |

## 通用类

| 分类       | 释义                                          |
| -------- | ------------------------------------------- |
| **年代**   | 四五十年代到九十年代背景的文，且年代画风明显                      |
| **民国旧影** | 二十世纪初到新中国建国前的民国背景文，且民国画风明显                  |
| **玄幻仙侠** | 背景为东方玄幻、仙侠世界、西方奇幻，主线围绕非现实设定推进，世界观有虚构成分的故事   |
| **悬疑惊悚** | 围绕悬疑、推理、规则怪谈、校园怪谈、民俗、诡秘、奇闻、风水、灵异、惊悚类元素展开的故事 |
| **其他**   | 以上所有主分类无法囊括的故事，可以选择该分类                      |
