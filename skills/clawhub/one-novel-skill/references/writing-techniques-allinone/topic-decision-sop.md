# 选题决策SOP — 四步法流程

> 选题是网文创作的第一步，也是最关键的一步。好选题 = 50%的成功率。
> 本SOP提供从市场洞察到选题承诺的完整四步流程。

---

## 第一步：市场扫描 (选赛道)

### 1.1 平台排行榜分析

| 数据源 | 分析内容 | 频次 |
|:-------|:---------|:-----|
| 番茄热榜 | 分类前50题材分布 | 每周 |
| 起点月票榜 | 精品题材趋势 | 每月 |
| 七猫飙升榜 | 新书爆款特征 | 每旬 |
| 飞卢同人榜 | IP衍生方向 | 半月 |

### 1.2 题材热度判断

**热度四象限**:
```
             竞争激烈
              │
      红海    │    蓝海
  (都市/玄幻) │  (小众精品)
  ───────────┼──────────→ 受众规模
      蓝海    │    红海
  (新兴品类)  │  (细分龙头)
              │
             竞争少
```

### 1.3 竞争力评估公式

```
市场竞争力 = 题材热度 × 受众规模 / (竞争强度 + 2)
```

- 题材热度: 1-5 (含推荐算法偏好)
- 受众规模: 1-5 (目标读者基数)
- 竞争强度: 1-5 (该题材作品数)

**推荐阈值**: ≥3.0 可进入第二步

## 第二步：个人适配 (验能力)

### 2.1 能力四维评估

| 维度 | 自我评估 (1-5) | 说明 |
|:----|:--------------|:-----|
| 知识储备 | _____ | 对该题材的了解和积累 |
| 阅读量 | _____ | 该题材已读作品数量 |
| 创作经验 | _____ | 类似题材的写作经历 |
| 情感认同 | _____ | 是否有强烈创作欲望 |

**准入门槛**: 四项总分 ≥ 12

### 2.2 能力-市场矩阵

```
   能力高 │ 精品赛道    │ 舒适赛道
          │ (挑战但值)  │ (高成功率)
   能力低 │ 学习赛道    │ 风险赛道
          │ (需补课)    │ (建议避开)
          └─────────────────────
            市场小          市场大
```

### 2.3 自我问询清单

- [ ] 我能写出50个该题材的核心桥段吗？
- [ ] 我知道该题材读者最想看什么吗？
- [ ] 我是否有不同于现有作品的切入点？
- [ ] 我能否持续更新200章不磨蹭？
- [ ] 这个故事我非写不可吗？

## 第三步：差异化设计 (找杠杆)

### 3.1 差异化四要素

| 要素 | 定义 | 示例 |
|:----|:-----|:-----|
| 题材融合 | 两个热门题材结合 | 都市+修仙 |
| 视角创新 | 独特叙事角度 | 反派视角、路人视角 |
| 设定突破 | 打破现有套路 | 反传统金手指 |
| 风格独有 | 不可复制的文风 | 冷幽默、意识流 |

### 3.2 差异化得分卡

```
差异化强度 = 新颖性(1-5) × 可执行性(1-5)

新颖性: 该差异化在目标平台是否出现过
可执行性: 你是否有能力实现该差异化
```

**差异化杠杆**: 选择一个要素做到极致 (新颖性 ≥ 4)

### 3.3 差异化验证

**三问验证法**:
1. **一句话钩子**: 能用一句话说清你的差异化吗？
   - ✅ "都市打工人绑定修仙系统，996是修炼，加班是渡劫"
   - ❌ "一个普通人在都市遇到了一些不普通的事"

2. **对标作品差异**: 与同类作品的最大不同是什么？
   - 对标《XX至尊》: 我比他多了【反差感】
   - 对标《YY狂少》: 我比他多了【现实共鸣】

3. **读者GET点**: 读者看到简介后想点什么？
   - 我要看这个设定下会发生什么
   - 这个角度我没见过

## 第四步：选题承诺 (定方向)

### 4.1 选题卡片模板

```
题材: ___________
平台: ___________
一句话简介 (30字): 
_________________________________

差异化定位:
  - 题材融合: ___________
  - 核心设定: ___________
  - 目标读者: ___________

预期数据:
  - 首日收藏: _______
  - 完读率目标: _______
  - 日更字数量: _______

创作承诺:
  - 最少更新至: ______章
  - 大纲完成度: ______%
  - 存稿量: ______章

风险评估:
  - 最大风险: ___________
  - 应对方案: ___________
```

### 4.2 选题评审Checklist

**必过项** (全部通过才可启动):
- [ ] 市场扫描: 有足够受众 (D1确认)
- [ ] 个人适配: 能力总分 ≥ 12
- [ ] 差异化: 至少1个要素新颖性 ≥ 4
- [ ] 可持续性: 能构思200章以上内容
- [ ] 平台适配: 符合目标平台规则

**加分项** (≥3个建议启动):
- [ ] 有对标爆款可以参考
- [ ] 有独特的个人优势
- [ ] 有适合的推荐切入点
- [ ] 有一定的存稿基础
- [ ] 有明确的排期计划

### 4.3 选题决策树

```
市场扫描 → 不通过 → 放弃或储备
     ↓ 通过
个人适配 → 不通过 → 补课或调整
     ↓ 通过
差异化设计 → 无差异化 → 放弃
     ↓ 有差异化
选题承诺 → 承诺不足 → 完善准备
     ↓ 承诺完整
🚀 启动创作
```

## 附：快速选题模板 (15分钟版)

| 步骤 | 时间 | 任务 |
|:----|:----|:-----|
| 扫榜 | 5分钟 | 打开目标平台热榜，截图前20 |
| 归类 | 3分钟 | 标记题材、标签、标题模式 |
| 匹配 | 4分钟 | 找出3个热门题材+1个空白点 |
| 决策 | 3分钟 | 填写选题卡片、做选择题 |

> **核心原则**:
> 1. 不追风——追风者死在风停时
> 2. 不跟样——跟样者死在同质化
> 3. 不贪多——贪多者死在开局前
> 4. 不犹豫——犹豫者死在行动前
