# 大纲规划方法论（完整版）

> 剧情大纲没有唯一"规则"，但核心是：以清晰结构承载主题、冲突与人物成长，确保逻辑自洽与叙事节奏可控。
> 大纲本质是作者的备忘录+叙事引擎，不求完美模板，而求"能帮你写完且不自相矛盾"。

---

## 第一章 核心要素

### 1.1 大纲四问

在动笔写大纲之前，先回答四个核心问题：

| 问题 | 说明 | 示例答案 |
|------|------|---------|
| **主题** | 想表达什么？故事的内核 | "正义也许会迟到，但不会缺席" |
| **主线** | 主角的目标 + 核心冲突 | "一个被冤枉的少年踏上复仇之路，却发现真相比复仇更残酷" |
| **基调** | 故事的类型和情绪底色 | 悬疑推理 / 热血成长 / 虐心复仇 |
| **结局** | 闭合/开放/反转？ | 闭合式：正义得到伸张；开放式：主角走向远方 |

### 1.2 一句话梗概

将核心要素压缩成一句话：

```
[主角] + [核心目标] + [主要障碍] + [独特设定]
```

**示例**：
```
"一个被废去修为的少年（主角），
在宗门大比前夕发现师父就是灭门仇人（核心目标），
却在复仇过程中逐渐触及一个关于世界真相的巨大阴谋（独特设定）。"
```

## 第二章 叙事结构

### 2.1 三幕剧（标准叙事结构）

| 幕 | 占比 | 核心任务 | 关键节点 |
|----|------|---------|---------|
| **第一幕：开端** | 15-20% | 建立世界、引入主角、埋下冲突种子 | 激励事件（主角被迫进入主线） |
| **第二幕前半：发展** | 30-35% | 深化世界、发展关系、升级冲突 | 中点转折（获得关键信息/失去重要之物） |
| **第二幕后半：深化** | 30-35% | 角色蜕变、伏笔回收准备 | 黎明前的黑暗（看似无法挽回的绝境） |
| **第三幕：高潮与结局** | 15-20% | 伏笔回收、最终冲突解决、角色弧线完成 | 最终决战→结局 |

#### 三幕剧详细流程

**第一幕：开端**
- 日常世界 → 召唤冒险 → 拒绝召唤 → 导师出现 → 跨过门槛
- 第一幕高潮：不可逆转的事件发生（主角被迫进入故事主线）

**第二幕前半：发展**
- 适应新世界 → 结识盟友/树敌 → 第一次重大失败 → 获得关键成长
- 中点的转折：获得关键信息/失去重要之物/发现真相

**第二幕后半：深化**
- 从失败中崛起 → 训练/准备 → 接近最终目标 → 再次受挫
- 第三幕前低谷：看似无法挽回的绝境

**第三幕：高潮与结局**
- 绝境反击 → 最终决战 → 代价与牺牲 → 结局与新开始
- 结局：主角的新位置/新状态/新目标

### 2.2 七点结构（简化版）

适合中短篇或需要快速构建框架的场景：

| 序号 | 节点 | 说明 |
|------|------|------|
| 1 | **钩子** | 开篇吸引读者，展示主角/世界/冲突的冰山一角 |
| 2 | **第一转折** | 激励事件发生，主角被迫上路 |
| 3 | **中点** | 故事中段的重要转折，主角获得关键信息/遭遇重大失败 |
| 4 | **第二转折** | 主角从低谷中崛起，找到新方向/获得新力量 |
| 5 | **高潮** | 最终对决，所有矛盾集中爆发 |
| 6 | **结局** | 冲突解决，展示主角的新状态 |
| 7 | **余韵** | 收尾，留给读者回味空间 |

### 2.3 短篇简化结构

短篇/短故事可简化为"起因–发展–高潮–结局"：

```
起因（20%）→ 发展（40%）→ 高潮（30%）→ 结局（10%）
```

## 第三章 主角驱动原则

### 3.1 核心原则

**每场关键情节必须推动主角变化**，变化包括以下三个维度之一：

| 变化维度 | 说明 | 示例 |
|---------|------|------|
| **目标变化** | 主角的目标因剧情而调整/升级/改变 | 从"活下去"→"复仇"→"拯救世界" |
| **认知变化** | 主角对世界/他人/自我的认知被颠覆 | 发现师父就是仇人、发现世界是虚假的 |
| **关系变化** | 主角与他人的关系发生质变 | 从敌人变盟友、从信任变背叛 |

### 3.2 禁止做法

- ❌ 纯事件堆砌（主角只是"路过"所有事件）
- ❌ 配角替主角做关键决定
- ❌ 用巧合解决核心冲突（机械降神）

### 3.3 配角服务原则

配角服务于主线或主题，不可喧宾夺主：

```
每场配角的戏份 → 问自己：
"这场戏去掉，对主角的成长有影响吗？"
"没有" → 删掉或重写
"有" → 保留，但确保焦点在主角的反应上
```

## 第四章 分层细化流程

### 4.1 从粗到细的四层结构

```
一句话梗概 → 段落式主线 → 分卷细纲 → 章节大纲
```

#### 第一层：一句话梗概（已完成于第一章）

#### 第二层：段落式主线（5-10个关键情节点）

将故事拆解为5-10个关键情节点，每个点一句话：

```
1. 主角被废修为，逐出师门
2. 在逃亡途中获得神秘传承
3. 回到宗门参加大比，初露锋芒
4. 发现师父就是灭门仇人
5. 被师父追杀，坠入深渊
6. 在深渊中发现世界真相的线索
7. 联合被压迫的势力反攻
8. 与师父最终对决
9. 真相揭露：师父也是被操控的棋子
10. 主角选择原谅，走向新的人生
```

#### 第三层：分卷细纲

将主线拆分为分卷，每卷有独立的核心冲突和角色成长目标：

```markdown
## 第一卷：陨落与重生
- 核心冲突：被废修为后的生存挣扎
- 角色成长：从天才→废柴→重拾信心
- 关键事件：被逐→逃亡→获传承→初露锋芒
- 结尾钩子：发现仇人身份
- 字数预估：XXX字
```

#### 第四层：章节大纲

每个细纲段落包含：

| 字段 | 说明 | 示例 |
|------|------|------|
| 段落编号 | 卷号-序号 | V1-01 |
| 核心事件 | 发生了什么 | 主角在宗门大比中被当众废去修为 |
| 出场角色 | 谁出现了 | 主角、师父、反派师兄 |
| 冲突类型 | 什么冲突 | 人 vs 人（师徒反目） |
| 情绪目标 | 让读者感受到什么 | 愤怒、同情、期待反转 |
| 伏笔操作 | 埋设/回收/延续 | 埋设"师父的修为来源可疑" |
| 字数预估 | 精确到个位数 | 2500字 |

### 4.2 避坑提示

- 新手可从**1页纸主线**起步，边写边补
- 忌在前期过度填充人设/世界观设定而**延误剧情骨架搭建**
- 先搭骨架（主线情节），再填血肉（细节描写）

## 第五章 弹性与变更管理

### 5.1 大纲是地图，不是牢笼

- 写作中可根据灵感调整大纲
- 但每次调整需记录变更，确保前后一致
- 变更后检查：①伏笔是否还成立？②因果链是否断裂？③节奏是否被打乱？

### 5.2 变更记录模板

```markdown
## 大纲变更记录

| 日期 | 原内容 | 变更后 | 变更原因 | 受影响部分 |
|------|--------|--------|---------|-----------|
| XXXX | V3-05: 主角获得神器 | 改为获得关键信息 | 避免战力过早膨胀 | V4-02需要调整 |
```

### 5.3 关键检查项

每次变更后检查：
- [ ] 伏笔是否还成立？（若改写了相关情节）
- [ ] 因果链是否断裂？（A→B→C的逻辑是否还在）
- [ ] 节奏是否被打乱？（张弛是否还合理）
- [ ] 人物弧线是否一致？（角色的成长路径是否连贯）

## 第六章 类型适配

### 6.1 不同题材的侧重点

| 题材 | 核心关注点 | 节奏建议 |
|------|-----------|---------|
| **言情** | 关系转折（从陌生→好感→相爱→矛盾→和解） | 关系变化的每个阶段都需要足够铺垫 |
| **悬疑** | 线索铺设（真假线索交织，误导与揭秘） | 保持信息不对称，每3-5章一个小揭秘 |
| **奇幻** | 设定与规则内逻辑（力量体系自洽、世界观自洽） | 设定揭示需与剧情同步，避免大段说明 |
| **网文** | 钩子–爽点–爆点节奏 | 每3-5章一微型高潮，前10章密集爽点 |
| **都市** | 现实感与代入感 | 基于现实逻辑做微创新，避免脱离实际 |
| **历史** | 历史真实与虚构的平衡 | 重大历史事件不可篡改，细节可虚构 |
| **科幻** | 科技设定的逻辑自洽 | 以现实科学为基础做合理推演 |
| **恐怖** | 氛围营造与心理压迫 | 慢热型铺垫，信息逐步释放 |

### 6.2 网文节奏公式

```
前10章：密集爽点 + 强钩子（吸引读者留存）
中期：爽点与挫折交替（保持张力，每3-5章一微型高潮）
后期：大型爽点集中释放（高潮效果，伏笔集中回收）
```

### 6.3 伏笔类型与布局

| 类型 | 说明 | 布局建议 |
|------|------|---------|
| 短伏笔 | 本卷内回收 | 埋设后3-5章内回收 |
| 中伏笔 | 2-3卷后回收 | 埋设后明确标注，中间可提及1-2次 |
| 长伏笔 | 全书最终回收 | 贯穿始终，每次出现增加信息量 |
| 误导伏笔 | 引导读者错误推理 | 真假伏笔需同时存在，真相揭示时恍然大悟 |

## 附：大纲速查表

### 设计完成后逐项检查

- [ ] 主题是否清晰？（一句话能说清故事想表达什么？）
- [ ] 主线是否明确？（主角的目标+核心冲突是否明确？）
- [ ] 结构是否完整？（三幕剧/七点结构的关键节点是否都有？）
- [ ] 是否围绕主角驱动？（每场关键情节推动主角变化？）
- [ ] 配角是否服务于主线？（去掉配角，故事是否受影响？）
- [ ] 节奏是否合理？（张弛交替，无过长平缓期？）
- [ ] 伏笔是否标注？（短/中/长/误导伏笔的回收节点？）
- [ ] 类型适配是否到位？（针对题材做了专门的节奏设计？）
- [ ] 是否预留弹性？（大纲允许调整，不僵化？）
- [ ] 变更记录是否完整？（每次修改都有记录？）

### 一句话总结

> 大纲是**作者的备忘录+叙事引擎**，不求完美模板，而求"能帮你写完且不自相矛盾"。新手可从1页纸主线起步，边写边补，忌在前期过度填充人设/世界设定而延误剧情骨架搭建。
