# 世界观搭建方法论（完整版）

> 小说三要素：人物、环境、情节。世界观属于"环境"维度。
> 完整的人物塑造理论详见 `references/narrative-theory.md` 第十一篇。
> 地名命名规则详见本文第五章以及 `references/naming-guide.md` 第十篇。

---

## 第一章 世界观的核心定义与功能

世界观是贯穿故事始终且恒久不变的要素集合，它规定了角色能做什么、不能做什么，以及行为背后的代价。

### 1.1 核心功能

- **逻辑基石**：确保情节发展符合内在规律，避免机械降神或逻辑崩坏
- **冲突引擎**：通过规则的刚性限制与角色的主动性产生矛盾，推动剧情
- **情绪载体**：通过特定的规则设定（如"必须结婚否则死亡"）直接服务于核心情绪体验

### 1.2 世界观的底层逻辑

世界观并非单纯的背景板，而是故事运行的"物理定律"与"社会法则"的总和。一个优秀的世界观应当具备**自洽性**、**逻辑性**与**叙事驱动力**，让读者在沉浸中接受虚构世界的规则。

## 第二章 世界观的五大构成维度

### 2.1 核心理念与基调

这是世界观的灵魂，通常可用两三个字概括（如"逆袭"、"复仇"、"生存"）。它奠定了故事的底色，所有设定需围绕此核心展开，确保主基调统一。

**示例**：
- 修仙世界 → 核心理念"逆天改命"
- 末世世界 → 核心理念"生存挣扎"
- 权谋世界 → 核心理念"博弈算计"

### 2.2 时空背景与地理格局

#### 时间维度
确定时代背景（古代、现代、未来、架空）及故事期限（几天至几百年）。时间跨度影响人物成长弧光：
- **短期限**（几天~数月）：适合悬疑惊悚、紧张冲突类故事
- **中期限**（数年）：适合成长蜕变类故事
- **长期限**（数十年~数百年）：适合史诗成长、代际传承类故事

#### 空间维度
描绘地图范围、地域特色、气候资源。地理环境决定势力分布与种族习性：
- 高原民族 → 擅长耐寒、骑射、矿石冶炼
- 沿海族群 → 精通航海、渔业、贸易交流
- 森林部族 → 擅长狩猎、草药、自然魔法
- 沙漠文明 → 擅长商队、水利、星辰观测

### 2.3 力量体系与自然法则

这是奇幻、科幻题材的重中之重。

#### 能量来源
明确力量源头：
- 灵气（修仙）、魔法元素（奇幻）、科技能源（科幻）
- 信仰之力（神权体系）、血脉之力（血统体系）
- 精神意志（异能体系）、自然之力（德鲁伊体系）

#### 等级划分
建立清晰的晋升阶梯，并规定每一级的能力边界：
- 修仙：炼气→筑基→金丹→元婴→化神→大乘
- 魔法：学徒→初级→中级→高级→大法师→贤者
- 异能：D→C→B→A→S→SSS

#### 代价与限制
任何强大能力都需伴随代价，避免角色无敌化：
- 寿命消耗、精神污染、记忆丧失
- 资源枯竭、反噬伤害、情感封印
- 使用次数限制、冷却时间、副作用

#### 天道/物理规则
设定世界的基本运行逻辑：
- "因果反噬"：打破规则必遭天谴
- "元素守恒"：能量不灭，只转移形态
- "等价交换"：获得必有所失
- "相对论效应"：速度/力量/时间三者互斥

### 2.4 社会结构与文明形态

#### 政治制度
皇权、共和、宗门联盟、财阀统治等，决定权力运作方式：
- **集权制**：中央高度集权，效率高但腐败易滋生
- **联邦制**：多方势力平衡，内部博弈激烈
- **宗门制**：强者为尊，实力决定话语权
- **财阀制**：资本主导，利益驱动一切

#### 经济体系
通用货币、资源分配方式、贸易路线。经济基础决定阶级矛盾：
- 灵石/灵晶垄断 → 贵族与平民对立
- 稀有资源争夺 → 引发战争与冲突
- 货币贬值/通货膨胀 → 社会动荡

#### 文化宗教
信仰体系、道德观念、节日习俗、禁忌传说。文化细节赋予世界真实感：
- **信仰体系**：多神教、一神教、祖先崇拜、自然崇拜
- **禁忌传说**：不可提及的名字、禁止进入的区域、诅咒之地
- **节日习俗**：丰收祭、觉醒日、亡灵节、竞技大会

#### 种族与职业
不同种族的生理特性与社会分工，以及由此产生的种族关系：
- 矮人 → 锻造、采矿、建筑（与精灵关系紧张）
- 精灵 → 自然亲和、弓箭、魔法（歧视人类）
- 兽人 → 战斗、狩猎、萨满（与人类战争不断）
- 龙族 → 智慧传承、元素掌控（隐居不出）

### 2.5 势力分布与人际网络

#### 主要势力
国家、门派、组织、家族。明确其势力范围、核心理念及相互关系：

| 势力名称 | 类型 | 核心理念 | 盟友 | 敌对 |
|---------|------|---------|------|------|
| 青云宗 | 宗门 | 守护天下 | 天剑阁 | 魔渊教 |
| 天剑阁 | 宗门 | 以剑证道 | 青云宗 | 血影楼 |
| 魔渊教 | 教派 | 力量至上 | 血影楼 | 正道联盟 |

#### 交互关系
人物在势力中的位置及其与其他角色的羁绊。精彩的人物互动是世界观最直观的呈现方式。

## 第三章 新手构建世界观的实操步骤

### 第一步：确立"三个核心支柱"

不要急于绘制宏大地图，先抓住支撑故事成立的底层逻辑：

1. **生存规则**：世界里的人如何活下去？
   - 强者为尊、资源至上、利益交换？
   - 技能决定地位、血统决定命运？
   - 团结才能生存、独行必死？

2. **矛盾核心**：世界最大的冲突是什么？
   - 阶级对立、种族战争、正邪之争？
   - 资源争夺、信仰冲突、理念分歧？
   - 生存与道德的博弈？

3. **行为边界**：什么绝对不能做？
   - 禁忌（触碰者必死）、法律（违反者受罚）？
   - 天道惩罚（违背规则遭天谴）？
   - **限制产生张力，打破限制带来成长**

### 第二步：采用"冰山理论"进行分层设计

#### 表层呈现（冰山一角）
直接展现在读者面前的设定，如主角的日常、看到的建筑、使用的货币。这部分要**简洁、直观**，降低阅读门槛。

```
示例：主角走进客栈，用一枚银币买了间房。
→ 读者自然知道：①这个世界用银币 ②有客栈 ③物价水平
无需大段说明"本世界货币体系为金/银/铜三进制..."
```

#### 底层概述（水面之下）
支撑表层设定的深层逻辑，如历史渊源、复杂的社会结构、隐藏的法则漏洞。作者需心中有数，但不必全部写出，留白可增加神秘感。

```
作者知道但不需全部写出的内容：
- 银币的铸造工艺和发行机构
- 货币体系的历史演变
- 通货膨胀率和经济周期
- 黑市的汇率和地下钱庄
这些只在剧情需要时才揭示
```

### 第三步：从微观切入，逐步扩展

#### 起点聚焦
从主角所在的小环境（村庄、学校、宗门）开始构建。描写主角的饮食、衣着、恐惧与渴望。

**错误示范**：
```
这个世界有五大帝国、十八宗门、三十六洞天...
（一口气抛出一堆读者记不住的名词）
```

**正确示范**：
```
林北推开茅草门，冷风灌进脖子里。
他裹紧身上打了三块补丁的棉袄，
看了眼灶台上半碗发硬的杂粮粥——
今天是觉醒日，如果能通过试炼，
就能去青云宗吃上热乎的灵米了。
（从主角日常切入，自然带出世界信息）
```

#### 动态扩展
随着主角移动，逐步揭示更广阔的世界。通过旅途见闻、他人对话、历史遗迹等方式自然铺陈世界观，避免大段说明性文字。

| 揭示方式 | 示例 |
|---------|------|
| 旅途见闻 | 主角路过战场废墟，通过残骸了解历史战争 |
| 他人对话 | 路人闲聊透露某势力的最新动向 |
| 历史遗迹 | 进入古墓，通过壁画了解上古文明 |
| 矛盾冲突 | 与异族战斗时展现对方的生理特性和战斗方式 |
| 日常细节 | 购买物品时自然带出货币体系和物价 |

### 第四步：现实映射与创新融合

#### 基于现实微创新（推荐新手）
基于现实世界进行改良，降低构建难度：
- 科举 → 宗门试炼
- 职场斗争 → 宫廷权谋
- 股票市场 → 灵石交易所
- 社交媒体 → 传音符/千里传音阵

#### 单一奇观叠加（适合短篇/轻小说）
采用"熟悉现实 + 1个颠覆性设定"的模式，快速制造冲突与爽点：
- "读心术都市"：现实都市+人人拥有读心术
- "全员演技后宫"：现实校园+全员都是影帝级演员
- "时间循环小镇"：现实小镇+每天重置

## 第四章 常见误区与避坑指南

### 误区1：百科全书式设定

**问题**：读者不关心未参与剧情的遥远大陆历史。

**解决方案**：世界观应通过情节和人物经历自然流露，而非静态罗列。

```
❌ 错误：直接抛出设定
"天元大陆分为五域，东域有青云宗，西域有天剑阁，南域有..."

✅ 正确：通过剧情揭示
"林北站在青云宗的山门前，眺望远方的天际线。
师兄指着西边隐约的山影说：'那边是天剑阁的地盘，咱们两派世代交好。'
至于南边...师兄脸色一沉，'魔渊教的人最好别碰上。'"
```

### 误区2：逻辑自相矛盾

**问题**：力量体系、社会规则前后不一致。

**解决方案**：建立"规则检查表"，确保设定一致性。
- 若设定"杀人遭天谴"，则主角后期不能无理由逃脱惩罚
- 若设定"魔法消耗精神力"，则大战后角色应有疲惫表现
- 若设定"灵石稀有"，则平民不应随手使用灵石交易
- **如需突破规则，必须有合理的伏笔解释**

### 误区3：过度堆砌名词

**问题**：生造过多晦涩术语增加阅读障碍。

**解决方案**：用通俗语言解释复杂概念，或通过具体场景展示规则效果。

```
❌ 错误：术语轰炸
"林北运转九天玄黄诀，调动丹田中的混沌真元，冲击天罡三十六穴中的璇玑穴..."

✅ 正确：场景展示
"林北深吸一口气，感觉到丹田中那股温热的气流开始游走。
按照师父教的口诀，他引导气流冲向胸口某个位置——
砰！像是有什么东西被冲开了，浑身一轻。"
```

### 误区4：规则服务于剧情

**问题**：无用的设定即使再精彩也应删减。

**解决方案**：所有设定必须对以下至少一项有用：
1. 推动情节发展
2. 塑造人物形象
3. 强化主题表达

**检查方法**：如果一个设定删掉后不影响故事，说明它没有存在的必要。

### 误区5：忽视设定的代价

**问题**：只写能力有多强，不写代价有多大。

**解决方案**：任何强大能力都需伴随明确的代价，且代价要在剧情中体现。

| 能力 | 代价 |
|------|------|
| 时间暂停 | 消耗寿命（暂停1秒=1天寿命） |
| 读心术 | 每次使用后头痛欲裂 |
| 预知未来 | 看到的越远，失明的风险越大 |
| 复活他人 | 以自己的一部分记忆为代价 |

## 第五章 高阶思维：让规则成为叙事主体

### 5.1 规则拟人化

赋予规则以意志或性格，使其成为隐形的"角色"：
- **仁慈的治愈法则**：治疗魔法温和但缓慢，如同慈母
- **残酷的遗忘法则**：触碰禁忌必失记忆，如同冷酷的审判者
- **贪婪的交换法则**：等价交换从不吃亏，如同精明的商人

### 5.2 规则动态演化

设计法则的迭代事件，引发社会结构剧变：
- **纪元更替**：旧法则崩坏，新法则诞生
- **灵气枯竭**：强者陨落，科技兴起
- **神战遗留**：世界被撕裂，法则碎片散落各地

### 5.3 哲学解构

探讨规则的虚无性、人为性或相对性，提升作品的思想深度：
- "规则是高阶存在的实验场"
- "所谓天道，不过是强者制定的游戏规则"
- "束缚众生的法则，可能只是某个人的一念之差"

## 第六章 地点命名规则与随机化

> 地名是世界观的重要组成部分。一个合理、自洽、有辨识度的地名体系，能极大增强世界的真实感和沉浸感。
>
> 完整的地名取名规则（含东方/西方/古代地名体系）详见 `references/naming-guide.md` 第十篇。

### 6.1 地名的构成

地名由 **专名（特有部分）** 和 **通名（类别部分）** 组成。

```
专名 + 通名 = 完整地名
示例: 青云 + 市 = 青云市
      苍澜 + 江 = 苍澜江
      落霞 + 镇 = 落霞镇
      白鹿 + 原 = 白鹿原
      听风 + 巷 = 听风巷
```

**专名**: 地名的特有部分，体现独特性（青云、苍澜、落霞、白鹿、听风）
**通名**: 地名的类别部分，说明地理类型（市、江、镇、原、巷、山、河、湖、路、街、区、县、村）

### 6.2 八大命名铁律

#### 规则1：含义明确健康

**要求**: 地名含义必须明确、健康，不违背公序良俗。

**错误示例**:
- ❌ "鬼哭岭""尸山"（恐怖消极）
- ❌ "霸王乡""皇帝村"（封建意味过重）
- ❌ "富贵山""金山银海市"（俗气）

**正确示例**:
- ✅ "青云市"（寓意高远）
- ✅ "苍澜江"（气势磅礴）
- ✅ "落霞镇"（诗意优美）

#### 规则2：使用规范汉字

**要求**: 
- 使用国家通用语言文字（简体汉字）
- 避免生僻字、多音字或易混淆写法

**错误示例**:
- ❌ "灞镐区"（生僻字）
- ❌ "行乐乡"（"行"多音字，易混淆）
- ❌ "邋遢河"（消极+生僻）

**正确示例**:
- ✅ "白鹭洲"（常见字）
- ✅ "明月湖"（常见字）
- ✅ "清风镇"（常见字）

#### 规则3：禁止以人名作地名

**要求**: 一般不得以人名（含国家领导人）、外国人名地名、企业或商标名称作地名。

**错误示例**:
- ❌ "李强市"（人名）
- ❌ "华盛顿区"（外国人名地名）
- ❌ "华为路""阿里街"（企业名）
- ❌ "可口可乐广场"（商标名）

**正确示例**:
- ✅ "长风市"（意象）
- ✅ "青山区"（自然地理）
- ✅ "银杏路"（植物）

**小说例外**: 在小说设定中，如果某个角色确实重要到足以命名一个地点（如"英雄的故乡"），需在设定中明确说明命名缘由，且不得与现实人物冲突。

#### 规则4：避免重名与同音

**要求**: 
- 国内著名自然地理实体、全国性县级以上政区名不得重名或同音
- 同一省级/县级行政区内乡、村、街巷等也不得重名或同音

**错误示例**:
- ❌ "长江市"（与长江重名）
- ❌ "泰山镇"（与泰山重名）
- ❌ "黄河县"（与黄河同音）
- ❌ 同省出现"白云市"和"白云县"（重名）

**正确示例**:
- ✅ "沧澜江"（不与现实著名河流重名）
- ✅ "天衡山"（不与现实名山重名）

#### 规则5：不越界命名

**要求**: 不得以著名自然遗产、历史遗址或超出本辖区范围的地理实体作行政区划专名。

**错误示例**:
- ❌ 一个小镇叫"昆仑镇"（昆仑山是全国性著名山脉）
- ❌ 一个县叫"长城县"（长城是跨区域历史遗址）

**正确示例**:
- ✅ 小镇以当地小山川命名（"青石镇""枫林镇"）
- ✅ 县名取自本地特征（"临水县""平川县"）

#### 规则6：方位设施保持一致

**要求**: 具有重要方位意义的交通、水利、市政等设施名称，宜与所在地地名保持一致。

**示例**:
- 地点叫"青云市" → 高铁站叫"青云站"
- 地点叫"苍澜江" → 大桥叫"苍澜江大桥"
- 地点叫"白鹭洲" → 公园叫"白鹭洲公园"

#### 规则7：特殊情形审批

**要求**: 特殊情形（如纪念性、历史传承性命名）须经严格审批，且不得违反上述禁止性规定。

#### 规则8：方言地名标准化

**要求**: 地方如有特殊习惯（如方言地名），仍须依法备案并标准化为规范汉字与汉语拼音（依据《汉语拼音方案》）。

**示例**:
- 方言音"岬（ga1）" → 标准化为"岬（jia3）"
- 方言字"氹（dang4）" → 标准化为"氹（dang4）"

#### 6.3.3 随机组合方法

**方法一：专名+通名随机组合**
```
专名池随机取1-2字 + 通名池随机取1字 → 检查八大铁律 → 确认使用
```
示例: 苍(专名) + 澜(专名) + 江(通名) = 苍澜江
      白(专名) + 鹿(专名) + 原(通名) = 白鹿原

**方法二：按地域特征映射**
```
地域特征（地貌/气候/物产）→ 提取关键词 → 组合通名 → 检查 → 确认
```
- 多山地区: 云岭、翠峰、青崖、碧峦
- 临水地区: 临江、望湖、听涛、观澜
- 平原地区: 平川、广原、沃野、丰畴

**方法三：按文化风格映射**
```
文化风格（武侠/仙侠/科幻/都市）→ 选择对应用字 → 组合 → 检查 → 确认
```
- 武侠风: 侠、剑、武、义、风、云、江、湖
- 仙侠风: 灵、仙、玄、清、云、霄、天、道
- 科幻风: 星、光、能、源、新、极、远、深
- 都市风: 新、华、明、阳、安、顺、达、通

#### 6.3.4 随机化策略

1. **避免套路化**: 同一本书中，连续3个以上地名不要使用相同的专名风格
2. **区域一致性**: 同一地区的多个地名应保持风格一致（如同一国家内的城市名有相似的文化底蕴）
3. **层级差异化**: 大国/大城用大气字（天、云、苍），小村/小镇用质朴字（青、白、石）
4. **读者友好**: 避免过于生僻或复杂的组合，确保读者能记住
