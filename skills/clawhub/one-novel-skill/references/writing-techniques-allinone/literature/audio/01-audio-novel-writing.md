# 有声书/音频写作指南

> 摘要：音频平台（喜马拉雅、蜻蜓FM、Audible）的崛起要求作者掌握专门的有声写作技巧。本文提炼有声叙事的特殊规则：对话占比优化、耳朵友好的描写、声音标记系统及音频平台读者习惯。
> 来源：基于喜马拉雅FM热门节目分析、Audible畅销榜研究及播客叙事学文献

## 核心观点（5条可执行规则）

1. **对话占比不低于50% —— 听觉阈值的黄金比例** **[narration, dialogue]**: 视觉阅读可以快速扫过描述段，但听觉叙事中超过3句无对话的纯描写会导致听众注意力下降。规则：(1) 有声书的对话/叙述比例建议60:40，最低50:50；(2) 纯叙述段最长不超过150字（约40秒朗读时长），超过则需穿插一句人物感知或对话；(3) 独白（角色内心独白）可以替代对话，但应模拟"自言自语"的语气。审核时请跑narrator_ratio检测，标记"叙述时长>40秒"段落。

2. **耳朵友好的描写：听觉化的五感编码** **[human_lang, description]**: 视觉描写在阅读中有效，在听觉中容易变成"过耳即逝的形容词堆砌"。有声写作中，描写应做听觉编码：(1) 优先使用动作+声音的描写（"风把门吹得吱呀作响"优于"破旧的木门在风中摇晃"）；(2) 比喻的听觉化——用声音做本体或喻体（"他的声音像被砂纸磨过的铁"）；(3) 避免连续使用三个以上的形容词（中文听众无法消化"阴沉、潮湿、破败的地下室"这样的三重修饰）；(4) 方位词使用少而精——听众无法回头查找"左侧"指什么。

3. **声音标记系统：角色的声纹设计** **[character, emotion]**: 视觉阅读靠名字标签区分角色，听觉必须依靠声音特征。方法：(1) 每3页切换对话时，让角色的语言习惯（口头禅、句式偏好、语气词）成为"声音指纹"——比如角色A常以"话说"开头，角色B每句以"啊"结尾，角色C习惯用短促的祈使句；(2) 情绪状态通过朗读节奏暗示——紧张时短句密度增加，舒缓时长句比例上升；(3) 建议为主角设计1-2个独特的语速/语调模式记录在角色卡中，供有声书配音师参考。

4. **章节末的声音钩子（Cliffhanger 2.0）** **[tension_calibrator, emotion]**: 有声书的章末钩子与文字书不同——听众没有"翻页"动作，必须用听觉信号触发继续收听。有效钩子类型：(a) 未完成句（"他推开门，看到了……"）+ 环境音暗示；(b) 声音反转——角色用与之前完全不同的语气说一句话（"别说了……"突然变"开枪！"）；(c) 节奏骤变——在均匀的新叙述后突然加速或停顿时长>2秒。每章至少使用1个声音钩子，优先安排在章末最后3句。

5. **喜马拉雅/Audible算法与连载策略** **[factory, management]**: 音频平台的核心指标是"完播率"和"收听时长"。策略：(1) 每集时长15-25分钟为最优区间——太短触发率低，太长完播率下降；(2) 前3集免费，第4集解锁，免费集末尾是最高流失点，必须放置最强钩子；(3) 标题格式影响搜索权重——建议"【类型】主标题——副标题"格式（如"【悬疑】第七个死者——法医手记"）；(4) AI生成的有声书需在文本中加入朗读指示符（如{pause 2s}、{slow}）以模拟真人语调。

## 与引擎融合

| 引擎ID | 应用方式 |
|--------|---------|
| narration | 有声叙述时长控制、听觉段落分割 |
| dialogue | 对话占比优化、多角色声纹过滤 |
| human_lang | 听觉化五感编码、形容词密度检测 |
| description | 动作+声音描写优先、听觉比喻生成 |
| character | 声纹设计、语言习惯模板生成 |
| emotion | 声音反转情感标记、语调情绪映射 |
| tension_calibrator | 声音钩子类型选择、节奏骤变检测 |
| factory | 音频连载策略、完播率优化 |
| management | 标题SEO优化、更新节奏规划 |
