# 闪小说/微型小说

> 摘要：闪小说(Flash Fiction, <1000字)和微型小说(<300字)的写作技法。
> 来源：Flash Fiction Online编辑实践、Sudden Fiction系列选集

## 核心规则

1. **开门见山 [narration]**: 闪小说无铺垫空间。第一句(最多前50字)必须建立场景、角色和冲突中的至少两者。"从中间开始"是闪小说的黄金法则。

2. **一石二鸟 [writer]**: 闪小说中每个描述词和信息点必须承担双重功能——推进剧情的同时塑造角色或氛围。不能有任何"纯背景"描写。

3. **结尾反转或顿悟 [plot]**: 闪小说的高潮就在结尾。"最后一句改变一切"是最有效的模式。好的闪小说让人重读开头，因为结尾完全改变了前文的含义。

4. **字数精确控制 [management]**: 不同投稿渠道对闪小说有精确的字数上限(如100字/250字/500字/1000字)。投稿时须严格遵守——超字数的闪小说自动拒稿。每个单词/汉字都得"挣得自己的位置"。

## 引擎融合

| 引擎ID | 应用 |
|--------|------|
| narration | 开门见山的简约叙事 |
| writer | 一语双关的效率写作 |
| plot | 反转结尾结构设计 |
| management | 字数精确控制与渠道匹配 |
