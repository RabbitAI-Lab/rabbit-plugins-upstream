# 短篇结构

> 摘要：短篇小说五段式结构、冰山理论(海明威)、短篇的"一个瞬间"原则。
> 来源：海明威《短篇写作》、雷蒙德·卡佛访谈、爱伦·坡《写作哲学》

## 核心规则

1. **"一个瞬间"原则 [plot]**: 短篇只讲"一个瞬间"——角色生命中的一个关键时刻、一个决定性的选择、一个转折点。不要试图在短篇里讲述完整人生。

2. **五段式结构 [architecture]**: 引子(设境)→ 动荡(冲突出现)→ 发展(升级)→ 高潮(爆发)→ 余韵(回响)。短篇中各段篇幅分配：1:2:3:2:1。高潮必须在全篇50-70%处到来。

3. **冰山理论 [narration]**: 海明威的"冰山理论"——只写水面上的八分之一，隐藏的部分靠读者自行感受。对话中的潜台词 > 直白的心理描写。

4. **句末停留 [style]**: 短篇小说的每个句子、每个段落都承担更多分量。结尾句尤其重要——成功的短篇结尾应让读者合上页面后仍久久回味。

## 引擎融合

| 引擎ID | 应用 |
|--------|------|
| plot | 核心瞬间选择与聚焦 |
| architecture | 五段式篇幅分配 |
| narration | 冰山理论与潜台词 |
| style | 句末分量与回味值评估 |
