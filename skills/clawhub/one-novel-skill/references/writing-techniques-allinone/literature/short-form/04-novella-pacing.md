# 中篇节奏控制

> 摘要：中篇小说(1.5-4万字)的节奏控制、中篇与短篇/长篇的区别。
> 来源：中篇佳作分析(斯蒂芬·金《肖申克》、海明威《老人与海》)

## 核心规则

1. **中篇的黄金长度 [plot]**: 中篇的最佳长度区间为2-3万字。在此长度内作者有足够空间展开一个完整的故事弧，又不会因篇幅过长被迫引入支线。

2. **有限人物原则 [character]**: 中篇的核心角色不超过3-5人，重要配角不超过3人。超出此限会导致人物刻画深度不足。中篇是"深入挖掘少数人物"而非"广泛登场"。

3. **单主线+单副线 [architecture]**: 中篇只能容纳1条主线+最多1条副线。副线必须服务于主线(提供动机/揭示背景/引发转折)，不能独立存在。

4. **节奏密度递进 [tension_calibrator]**: 中篇的节奏不是匀速的——前半部分每章1-2个事件，后半部分每章2-3个事件。事件密度由低到高，直至高潮。

## 引擎融合

| 引擎ID | 应用 |
|--------|------|
| plot | 黄金长度与故事弧 |
| character | 有限人物管理与深度 |
| architecture | 单主线+单副线结构 |
| tension_calibrator | 事件密度递进控制 |
