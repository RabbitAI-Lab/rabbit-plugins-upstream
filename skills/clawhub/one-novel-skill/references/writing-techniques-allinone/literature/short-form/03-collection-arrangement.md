# 短篇集编排艺术

> 摘要：短篇小说集的排列逻辑、整体叙事弧、主题统一性。
> 来源：集合作品分析(博尔赫斯、卡尔维诺、雷蒙德·卡佛)

## 核心规则

1. **首篇定调 [reader_eval]**: 短篇集的第一篇至关重要——它定义了整部集的基调和读者的阅读预期。首篇应为"最具代表性"的作品，而非"最好"的作品。

2. **三幕编排 [architecture]**: 短篇集也需要类似三幕的结构——前1/3的篇章建立主题基调；中1/3深化并拓展；后1/3收束并升华。读者在按顺序阅读时会感受到整体的叙事弧。

3. **插曲篇章 [tension_calibrator]**: 在连续沉重的篇章之间安排至少1篇轻松的、或风格迥异的"插曲篇章"。这给读者呼吸的空间，也展示了作者的多样能力。

4. **末篇绕梁 [writer]**: 最后一篇的重要性仅次于第一篇。末篇应留下"回响"，让读者在合上书本后仍然沉浸其中。开放式结局或哲理升华在末篇中效果最佳。

## 引擎融合

| 引擎ID | 应用 |
|--------|------|
| reader_eval | 首篇选择与读者预期 |
| architecture | 三部式编排结构 |
| tension_calibrator | 插曲篇章节奏控制 |
| writer | 末篇余韵设计 |
