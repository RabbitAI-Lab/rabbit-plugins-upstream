# 网文成才21天

## 基本信息
- **作者**: 起点中文网编辑团队
- **出版年份**: 2018（网络汇编）
- **核心主题**: 网文基础技法、签约通关、新手晋级体系

## 核心观点摘要

1. **签约四要素**：开篇张力（前3章决定90%）、节奏掌控（爽点间隔掌握在3-5章内）、更新稳定性（日更4000+是底线）、题材风口（紧跟平台风向）
2. **书名与简介的转化率**：书名决定搜索曝光（包含核心关键词+悬念/反差），简介决定点击转化（包含看点清单+预期管理）
3. **大纲的保底价值**：大纲不是铁律而是保险——在迷失/卡文/成绩不佳时，大纲指明了回归主线的路标
4. **黄金开篇公式**：前500字抛出冲突/异常/悬念，前3000字构建完整小高潮，前10000字锁定核心爽点模式
5. **避雷指南**：大段设定说明（教条式植入）、开篇多人物（信息过载）、过度修饰（低信息密度）——是新手三大死因
