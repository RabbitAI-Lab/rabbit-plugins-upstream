# 描写实务

## 基本信息
- **作者**: 描写辞典体系（多作者汇编）
- **出版年份**: 2020（综合版）
- **核心主题**: 描写技巧体系、五感写作法、表情/动作/环境分类描写

## 核心观点摘要

1. **描写五感法则**：好的描写至少调用2种感官——视觉是基础，叠加听觉/触觉/嗅觉/味觉中至少一种。单一视觉描写的段落换面率（被跳过概率）高达60%+
2. **"动词优先"原则**：强动词胜过形容词堆砌。"他冲进去"＞"他以极快的速度进去"；"她瘫坐在地"＞"她很无力地坐在地上"
3. **环境描写的叙事功能**：环境不是背景板，而是情绪、氛围、情节的有机组成部分——战斗时的狂风、诀别时的暴雨、胜利后的阳光，环境应回应叙事需求
4. **表情描写的"失焦法则"**：人在强烈情绪中不会注意到对方的面部细节——第一人称视角下的表情描写应以"模糊印象"为主，第三人称则可以细致
5. **句式变化与阅读节奏**：紧张场景用短句（≤8字）→激烈动作用断裂句（碎片化）→抒情用长句（15-25字）→沉重用慢句（停顿多）——句式本身的节奏就是叙事语言
