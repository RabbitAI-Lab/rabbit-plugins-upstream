# 游戏叙事设计

> 摘要：分支叙事结构、环境叙事(Environmental Storytelling)、叙事节奏控制。
> 来源：亨利·詹金斯《游戏叙事设计》、Wendy Despain《游戏专业写作》

## 核心规则

1. **分支叙事三模型 [plot]**: 线性+分支(主线固定+分支选项)、辐射状(从中心事件向外发散)、网状(全自由选择匹配)。选择模型取决于：预算(分支越多成本越高)和叙事目标(注重主线深度or世界自由度)。

2. **环境叙事法则 [narration]**: 场景本身可以讲故事——墙上的涂鸦、散落的信件、场景布局。视觉细节比对话更有效。环境叙事的标准：每3个场景中至少有1个包含环境叙事线索。

3. **玩家的选择有意义 [logic]**: 分支叙事中，玩家的每个重要选择应有可感知的后果——不仅是结局不同，而是中期剧情走向就有明显差异。可追踪选择频率和分布来调整后续分支权重。

4. **叙事节奏四象 [tension_calibrator]**: 探索(低张)→冲突(高张)→解谜(中张)→爆发(最高张)。一轮完整的节奏循环应控制在30分钟-1小时游戏时长内。

## 引擎融合

| 引擎ID | 应用 |
|--------|------|
| plot | 分支叙事结构设计 |
| narration | 环境叙事线索嵌入 |
| logic | 选择→后果逻辑链 |
| tension_calibrator | 叙事节奏循环 |
