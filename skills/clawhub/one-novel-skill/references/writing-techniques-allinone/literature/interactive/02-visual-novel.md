# 视觉小说结构

> 摘要：视觉小说(VN)的叙事架构、选择支系统、好感度/参数系统、多结局设计。
> 来源：Key社/型月作品分析、《视觉小说写作论》

## 核心规则

1. **共同线→角色线→结局 [plot]**: 标准VN结构——共同线(约占40%)引入世界观和全角色，通过选择进入角色线(约占50%)，最后进入结局(约占10%)。共同线的选择需在前期就埋下角色倾向暗示。

2. **参数系统平衡 [analysis]**: 好感度/关键参数是隐藏的"记分牌"。参数影响触发的事件和结局。设计原则：参数种类不超过5个(否则玩家难以感知)，核心事件触发需至少2个参数同时达标。

3. **选择支伪装 [logic]**: 真正影响参数/结局的选择不应被玩家轻易识别("选A加好感"太明显)。应让20%的选择是"明显加好感"、30%是"看似无用但实际有影响"、50%是"氛围性选择"(仅影响对话内容不影响参数)。

4. **合理性多结局 [reader_eval]**: 多结局的每个结局应反映玩家在整个游戏过程中选择的累积结果。突然的"1个好结局1个坏结局"已过时。优秀VN应提供3-5个合理分支结局。

## 引擎融合

| 引擎ID | 应用 |
|--------|------|
| plot | 共同线→角色线→结局结构 |
| analysis | 参数系统与触发条件分析 |
| logic | 选择支伪装与参数映射 |
| reader_eval | 多结局合理性与玩家感知 |
