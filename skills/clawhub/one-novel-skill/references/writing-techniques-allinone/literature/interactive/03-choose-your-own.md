# 互动小说工具

> 摘要：Twine、Ink等互动小说工具的叙事逻辑和写作方式。
> 来源：Twine文档、Ink文档(inkle Studios)

## 核心规则

1. **Twine的故事节点 [plot]**: Twine使用节点(Passage)系统——每个节点是读者阅读的一小段文本，节点之间通过超链接连接。节点最佳规模：200-500字，超过500字应拆分。

2. **Ink的缝合线 [narration]**: Ink使用"缝合"(Stitch)和"转向"(Divert)控制流程。关键：逻辑分支用`~`(变量操作)配合条件判断`{}`实现，而非单纯的链接选择。

3. **变量驱动叙事 [analysis]**: 互动小说的核心——变量的累积影响后续事件。常见变量：flag(是否触发事件)、counter(累加型影响)、state(状态枚举)。建议变量总数控制在30个以内以避免逻辑失控。

4. **回溯与记忆 [consistency]**: 互动小说的一大难题是玩家可能跳跃回之前的选择点。需确保变量状态和时间线的一致性——避免"主角知道了他不该知道的事"或"忘记了他该知道的事"。

## 引擎融合

| 引擎ID | 应用 |
|--------|------|
| plot | 节点与分支结构设计 |
| narration | 流程控制与衔接 |
| analysis | 变量驱动的叙事逻辑 |
| consistency | 回溯与记忆一致性检查 |
