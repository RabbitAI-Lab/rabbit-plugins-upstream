# 跨作品融合技法

> 摘要：Crossover(跨界)写作的类型、规则与融合技巧，世界观碰撞的处理方法。
> 来源：同人写作社区分析、多部Crossover经典案例拆解

## 核心规则

1. **世界观等级平等原则 [world]**: 跨作品融合时，不同作品的世界观层级应保持大致平衡。不能把日常系角色放入龙傲天世界观而完全碾压，也不能相反。

2. **融合点选择 [plot]**: 选择两部作品的"接合点"——可以是相似的主题(都是魔法世界)、互补的设定(科幻+奇幻)、或时间上的错位(前传+正传)。强行拼接会让读者出戏。

3. **角色权利保留 [character]**: 跨界后每个角色保留其核心性格和能力，但需解释"为什么这个角色出现在另一个世界"。最差的Crossover是"该角色莫名其妙出现在异世界"。

4. **读者门槛控制 [reader_eval]**: 跨界作品的读者需了解至少其中一个原作。在引入另一个世界观时，应有引导性说明(3-5句世界观摘要)。不可假设读者了解全部原作。

## 引擎融合

| 引擎ID | 应用 |
|--------|------|
| world | 世界观等级平衡与融合 |
| plot | 融合点选择与接合设计 |
| character | 角色权利保留与动机合理性 |
| reader_eval | 读者门槛与引导设计 |
