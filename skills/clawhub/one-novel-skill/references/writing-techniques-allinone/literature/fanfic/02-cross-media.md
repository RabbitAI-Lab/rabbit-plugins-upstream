# 跨媒体叙事

> 摘要：亨利·詹金斯七原则、故事世界在不同媒体的延展、参与式文化。
> 来源：亨利·詹金斯《融合文化：新媒体与旧媒体的碰撞》

## 核心规则

1. **延展与深度 [world]**: 每增加一个媒体触点，应延展故事世界的广度(新角色/新地区/新历史)或加深其深度(已有角色的另一面)。不重复同一故事。

2. **连续性/多重性 [consistency]**: 跨媒体作品需在"保持连续性"和"允许平行版本"之间平衡。动画版、漫画版和游戏版的情节可不同，但核心设定(角色性格/世界规则)需一致。

3. **沉浸式体验 [narration]**: 好的跨媒体叙事让受众在故事世界"生活"——通过不同媒体获取不同层面的信息。传统媒体(小说/电影)提供主线剧情；新媒体(社交/游戏)提供补充线索。

4. **参与式设计 [reader_eval]**: 为粉丝留出参与空间——比如未填满的时间线、可拓展的世界设定。完全的确定性杀死参与感。

## 引擎融合

| 引擎ID | 应用 |
|--------|------|
| world | 故事世界延展与深度设计 |
| consistency | 跨媒体核心设定一致性 |
| narration | 沉浸式多入口叙事 |
| reader_eval | 参与度与留白设计 |
