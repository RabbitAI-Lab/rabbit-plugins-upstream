# 诗学

## 基本信息
- **作者**: 亚里士多德（Aristotle）
- **出版年份**: 约公元前335年
- **核心主题**: 悲剧艺术理论、情节结构、模仿论

## 核心观点摘要

1. **悲剧六要素**：情节（μύθος）、性格（ἦθος）、思想（διάνοια）、言辞（λέξις）、唱段（μέλος）、景观（ὄψις），按重要性排序，情节为悲剧灵魂
2. **情节整一性**：完整的情节需有开头、中间、结尾，事件间通过必然律或可然律连接，散漫的穿插是劣质结构的特征
3. **三一律雏形**：行动整一（一个主人公的一条完整行动线），时间上倾向于一天之内
4. **净化理论（Catharsis）**：悲剧通过引发怜悯与恐惧，使这些情感得到净化和升华
5. **发现与突转**：最佳悲剧包含"发现"（从不知到知）和"突转"（行动向对立面转化），二者同时发生效果最强

## 可执行规则（映射到引擎）

| 规则 | 适用引擎 | 应用方式 |
|:-----|:--------:|:---------|
| 检查情节的行动统一性：每个场景必须推动主线或副线发展，删除游离于主线之外的"装饰性"片段 | plot | 场景通过过滤器判定：该场景去掉后主线是否断裂？ |
| 确保每个章节包含至少一次"小突转"（预期→意外）或"小发现"（角色认知升级） | architecture | 每章结尾检查是否有认知/情势的转折点 |
| 情节事件链用"因为A所以B"（必然律）或"如果A那么可能B"（可然律）检验逻辑关联 | logic | 情节线生成后执行因果链验证，标记弱连接段落 |
| 编码"净化"时刻：高潮场景需同时唤起对主角的怜悯和对命运的恐惧，使读者获得情感宣泄 | emotion | 高潮段检测情感双通道（同情+恐惧）是否同时激活 |

## 与现有维度的融合建议

现有 `01-narrative-architectures.md` 已覆盖英雄之旅/救猫咪等结构，但缺乏亚里士多德对"因果必然性"的形式化分析。建议将诗学的"必然律/可然律"检验作为情节引擎的前置过滤步骤。
