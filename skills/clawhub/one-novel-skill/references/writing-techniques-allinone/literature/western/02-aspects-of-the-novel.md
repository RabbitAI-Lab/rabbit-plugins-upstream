# 小说面面观

## 基本信息
- **作者**: E.M.福斯特（E.M. Forster）
- **出版年份**: 1927
- **核心主题**: 小说七面向分析、人物类型、故事与情节区分

## 核心观点摘要

1. **圆形人物 vs 扁平人物**：扁平人物（Flat Character）围绕单一概念或品质构建，易识别记忆，适合喜剧/配角；圆形人物（Round Character）有复杂性、矛盾性和不可预测性，能令人信服地惊讶读者
2. **故事 vs 情节**：故事是"然后呢？然后呢？"（时间序列），情节是"为什么会这样？"（因果关系）。国王死了，然后王后也死了=故事；国王死了，王后因悲伤而死=情节
3. **幻想与预言**：幻想引入超自然元素却不破坏日常逻辑（需要读者签订"奇幻契约"）；预言指向超越个体的普遍价值
4. **模式与节奏**：模式指情节/意象在整体结构中的对称呼应；节奏指重复出现的主题元素在恰当间隔中重现，形成内部节律
5. **人物自主性**：当人物"活起来"后，作者应允许人物的行为符合其自身逻辑，而非强行塞入预定情节

## 可执行规则（映射到引擎）

| 规则 | 适用引擎 | 应用方式 |
|:-----|:--------:|:---------|
| 主角和关键反派必须为圆形人物：至少具备3个矛盾特质或2个深层心理动机，并能"令人信服地惊讶"读者 | character | 角色创建后执行圆形/扁平检测，圆形人物触发三维验证 |
| 扁平人物用于配角时，限定每章出现不超过2次且对话总字数不超过该章10% | character | 扁平人物出场频率和篇幅限制规则 |
| 核心情节节点必须回答"为什么会这样"而非仅仅"然后发生了什么" | plot | 生成每章情节摘要后，检查"为什么"链长度 >= 3 |
| 在长篇幅（>50章）中设计"节奏节拍器"：每10-15章重复一个主题变体，形成可感知的内部节奏 | architecture | 超长篇结构自动添加主题重复标记 |

## 与现有维度的融合建议

现有 `character-design.md` 侧重设定参数而忽略圆形/扁平的分类逻辑。建议引入福斯特的"令人信服地惊讶"标准作为角色引擎的质量检验指标。
