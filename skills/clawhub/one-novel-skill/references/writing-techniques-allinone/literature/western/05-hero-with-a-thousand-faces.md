# 千面英雄

## 基本信息
- **作者**: 约瑟夫·坎贝尔（Joseph Campbell）
- **出版年份**: 1949
- **核心主题**: 神话叙事结构、英雄之旅原型、跨文化叙事模式

## 核心观点摘要

1. **单一神话（Monomyth）**：所有文化的神话叙事共享同一个底层结构——"启程→启蒙→归来"的三段式旅程
2. **英雄之旅12阶段**：平凡世界→冒险召唤→拒绝召唤→遇见导师→跨越第一道门槛→试炼/盟友/敌人→深入龙潭→严峻考验→奖赏→返回之路→复活→带着灵药归来
3. **原型人物系统**：英雄、导师、守门人、使者、变形者、阴影、盟友、恶作剧者——每个原型承载独特的叙事功能
4. **英雄的双重性**：真正的英雄不是为了个人荣耀，而是为社群带回礼物（灵药）；自私的追求者不是英雄而是恶棍
5. **阈限空间（Liminality）**：跨越门槛后的冒险世界具有与现实世界不同的规则和逻辑，这个"阈限空间"是角色转变的关键场域

## 可执行规则（映射到引擎）

| 规则 | 适用引擎 | 应用方式 |
|:-----|:--------:|:---------|
| 长篇小说（>30章）的英雄旅程需完整覆盖"启程→启蒙→归来"三段，缺失任何一段则结构不完整 | plot | 小说结构完整性检查：确认三段式覆盖完整，标记缺失段 |
| 第4-8章之间必须出现"冒险召唤"，第20-40%处出现"严峻考验" | architecture | 关键里程碑的位置检查与偏移修正 |
| 8种原型人物系统作为角色创建的基线模板，确保叙事功能的完整性 | character | 角色创建时检查8种原型的覆盖率，缺失的重要原型（如导师、阴影）自动补全建议 |
| "灵药"定义：故事结尾主角带回的具体价值（技术/智慧/和平/爱），作为故事主题的显性化标记 | analysis | 结局评估时提取"灵药"类型，与小说主题一致性比对 |
