# 类型文学奖

> 摘要：国内类型文学奖(银河奖、星云奖(国内)、天马奖等)的评审标准和获奖规律。
> 来源：银河奖评审委员会、全球华语科幻星云奖章程

## 核心规则

1. **银河奖的硬科幻倾向 [world]**: 银河奖偏好有扎实科学基础的、核心设定新颖的科幻作品。技术设想的原创性和科学合理性是核心评审指标。

2. **星云奖(国内)的商业与文学平衡 [analysis]**: 与银河奖相比，星云奖更注重科幻的文学性、可读性和市场影响力。有影视改编潜力的作品额外加分。

3. **短篇奖项的存在感 [plot]**: 国内类型文学奖的中短篇奖项竞争激烈度低于长篇，但获奖后的行业曝光度更高。获奖短篇通常在3000-15000字之间。

4. **类型融合的加分 [development]**: 跨界融合(科幻+推理、奇幻+悬疑)越来越受欢迎。在传统类型基础上增加了其他类型的结构或元素，评委会给予创新加分。
