# 科幻设定

> 摘要：硬科幻与软科幻的区分标准、科技设定的一致性原则、科幻世界构建的核心框架。
> 来源：阿西莫夫《科幻写作》、刘慈欣访谈、本·博瓦《科幻设定手册》

## 核心规则

1. **硬科幻的物理约束 [logic]**: 硬科幻必须严格遵守已知物理定律，设定的技术突破点(One Big Lie/OBL)不超过1-2个。偏离现实越多→越接近奇幻，需附加解释。

2. **软科幻的社会焦点 [world]**: 软科幻以技术对社会的影响为核心，技术本身可简化处理。关键是"如果…会怎样？"的社会推演，而非技术细节。

3. **技术设定一致性 [consistency]**: 一旦设定某项技术的规则（如曲速引擎需多少能量/冷却时间），必须在全书中保持一致性。技术能力不能随剧情需要随意膨胀/收缩。

4. **外星智慧不可拟人化 [character]**: 外星生物的思维模式和价值观不应完全等同于人类。创造一个"可理解的不可预测"的异质智慧。

5. **科技树推演 [architecture]**: 建立一个简明的科技树——基础科学→应用技术→社会影响→伦理困境，每个层面有明确的因果逻辑链。

## 引擎融合

| 引擎ID | 应用 |
|--------|------|
| logic | 物理约束与OBL限制 |
| world | 社会推演与世界观构建 |
| consistency | 技术设定一致性扫描 |
| character | 外星智慧去拟人化检测 |
| architecture | 科技树推演与因果链 |
