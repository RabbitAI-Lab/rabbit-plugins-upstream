# 恐怖写作

> 摘要：恐怖写作的核心机制——洛夫克拉夫特公式（未知恐惧 > 已知威胁）、恐惧递进技巧、心理恐怖与惊悚的区别。
> 来源：H.P.洛夫克拉夫特《超自然恐怖文学》、史蒂芬·金《恐怖写作论》

## 核心规则

1. **未知恐惧公式 [tension_calibrator]**: 洛夫克拉夫特公式——最深的恐惧来自未知。保持怪物/真相的模糊性比完全揭示更有效。每揭示一层，恐惧感衰减30%。

2. **恐惧递进三阶段 [emotion]**: 不安（微妙细节异常）→ 焦虑（威胁渐明但不可控）→ 恐惧（直接面对）。每个阶段持续1-3章，不可跳跃。

3. **日常入侵法则 [narration]**: 恐怖最有效的是"熟悉场景的陌生化"——让日常物品/场所产生诡异感，而非完全架空的恐怖环境。

4. **克苏鲁的克制 [consistency]**: 描述不可名状之物时，不直接描写其形态，而是写"看到它的人的反应"——疯狂、失语、瞳孔放大。

5. **安全屋破坏 [plot]**: 建立安全空间后再破坏它，制造"无处可逃"的绝望感。安全屋至少维持3章后再被打破。

## 引擎融合

| 引擎ID | 应用 |
|--------|------|
| tension_calibrator | 恐惧曲线建模(不安→焦虑→恐惧的递进幅度控制) |
| emotion | 情绪铺垫与递进 |
| narration | 日常场景的陌生化叙事 |
| consistency | 不可名状之物的间接描写一致性 |
| plot | 安全屋→突破→绝境的三段结构 |
