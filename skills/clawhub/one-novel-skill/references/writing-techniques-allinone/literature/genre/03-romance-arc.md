# 爱情小说

> 摘要：浪漫弧线理论、推拉张力(Push-Pull)、情感曲线设计、相遇→冲突→和解的三幕式浪漫结构。
> 来源：格温·海耶斯《浪漫小说写作指南》、珍妮特·伯罗薇《写作的技艺》

## 核心规则

1. **浪漫弧线三段式 [plot]**: 相遇(30%) → 冲突与分离(50%) → 和解与成长(20%)。不可压缩第二阶段——冲突期是爱情最迷人的部分。

2. **推拉张力法则 [tension_calibrator]**: 每次"推"(冲突/误解/拒绝)后必须跟一次"拉"(暧昧/温暖/靠近)，但"拉"的幅度始终小于"推"，直到最后阶段反转。比例：推:拉 = 6:4。

3. **情感加速度 [emotion]**: 情感投入每阶段递增——从好感(10%)→吸引(30%)→依恋(50%)→深爱(70%)→羁绊(90%)。每次升级需有一个关键事件触发。

4. **OOC红线 [consistency]**: 浪漫关系中的角色可以成长，但不能OOC。如"冰山男主突然变话痨"违反角色一致性。成长是"冰山学会表达关心"而非"冰山变话痨"。

5. **磨砺与配得感 [character]**: 双方的成长是爱情成立的前提——每段浪漫弧线应包含至少一次"配得感确认"(Why does this person deserve love?)。

| 引擎ID | 应用 |

| plot | 三幕浪漫结构设计 |
