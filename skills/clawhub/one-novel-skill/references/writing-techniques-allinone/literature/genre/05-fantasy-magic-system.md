# 奇幻魔法体系

> 摘要：桑德森魔法法则(Sanderson's Laws)、魔法系统的软硬之分、代价原则。
> 来源：布兰登·桑德森《魔法系统设计》、L.E.莫德西特《幻想写作理论》

## 核心规则

1. **桑德森第一法则 [logic]**: 作者解决冲突的能力与魔法系统的规则清晰度成正比。魔法规则越清晰，读者越能理解主角用魔法解决问题的合理性。魔法不能成为"万能解药"。

2. **桑德森第二法则 [tension_calibrator]**: 魔法的局限性比魔法能力更有趣。限制(冷却时间/消耗/副作用)创造了张力；无限能力的魔法会杀死悬念。

3. **桑德森第三法则 [world]**: 先扩展已有系统的内涵，再引入新系统。增加新魔法类型之前，先深入挖掘已有魔法的使用边界和隐藏规则。

4. **代价原则 [plot]**: 强大的魔法必须付出对应代价。代价可以是物理的(寿命/体力)、心理的(记忆/情感)或社会的(禁忌/排斥)。代价越重→魔法使用越谨慎有策略。

5. **硬魔法/软魔法光谱 [analysis]**: 硬魔法(规则明确、读者可预测)适合推理感强的情节；软魔法(神秘、不可预测)适合冒险感和神秘感。一部作品中可混用但必须明确区分两者的边界。
