# 推理小说

> 摘要：推理小说的核心规则——诺克斯十诫、范达因二十法则、公平竞赛原则、红鲱鱼技巧。
> 来源：罗纳德·诺克斯《推理十诫》、S.S.范·戴恩《推理写作二十法则》、约翰·狄克森·卡尔

## 核心规则

1. **公平竞赛原则 [logic]**: 所有破案线索必须在揭晓答案前向读者展示。隐藏关键证据等于作弊。读者有资格与侦探站在同一起跑线。

2. **诺克斯十诫之凶手限制 [plot]**: 凶手必须是故事中出现过的角色，不能是主角的内心活动或超自然力量。这是推理小说的基本诚信。

3. **红鲱鱼法则 [foreshadow_watcher]**: 每次出现真线索时搭配1-2条误导线索。误导线索必须在真线索后1-2章内出现，且后续需被人为揭穿（而非被遗忘）。

4. **范戴因的节奏控制 [tension_calibrator]**: 前1/3埋线索，中1/3制造伪解答(False Solution)，后1/3给出真解答。伪解答必须"看似合理但终被推翻"。

5. **"Whodunit/Howdunit/Whydunit"三层 [analysis]**: 不只是"谁干的"，还需解答"怎么干的"（作案手法）和"为什么干的"（动机）。三层缺一则推理不完整。

## 引擎融合

| 引擎ID | 应用 |

| plot | 凶手限制与三幕结构 |
