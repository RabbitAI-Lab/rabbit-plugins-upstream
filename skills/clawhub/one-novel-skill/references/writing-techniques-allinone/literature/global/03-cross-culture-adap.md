# 跨文化改编

> 摘要：日漫改英、韩漫改中、中网文改英等跨文化改编的成功要素和失败陷阱。
> 来源：网飞国际内容策略分析、多种跨文化改编案例对比

## 核心规则

1. **保留核心DNA [consistency]**: 改编须保留原作的"核心DNA"——即原作品在最根本层面的吸引力(如《死亡笔记》的智斗核心、《三体》的科学图景)。去除了DNA的改编几乎必败。

2. **文化符号的本地化 [human_lang]**: 直接翻译文化符号(节日/习俗/成语)效果差。需找到目标文化的对应物——"清明节扫墓"可转化为目标文化中对应的"纪念逝者仪式"，而不是保留"清明节"加长注。

3. **叙事节奏的地域适配 [tension_calibrator]**: 不同文化对"慢节奏"的容忍度不同。改编时需重新调整节奏：日本慢热型→英语市场需前3章加大冲突密度；中文密集爽→韩式改编需适当增加情感铺垫。

4. **视觉风格的预期管理 [reader_eval]**: 受众对特定文化作品的视觉风格有预设期待(日本→日漫风、韩国→韩漫彩条风)。完全抛弃预期风格(如把日漫改成迪士尼风格)会导致核心受众流失。

## 引擎融合

| 引擎ID | 应用 |
|--------|------|
| consistency | 核心DNA保留检测 |
| human_lang | 文化符号本地化策略 |
| tension_calibrator | 节奏地域适配 |
| reader_eval | 视觉风格预期管理 |
