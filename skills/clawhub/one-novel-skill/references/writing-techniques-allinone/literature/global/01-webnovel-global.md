# 全球网文平台地图

> 摘要：俄罗斯(Litnet)、德国(Neobooks)、法国(Fyctia)、西班牙(Writing.com)等非英语国家网文平台生态。
> 来源：Litnet数据、Neobooks报告、国际数字出版观察

## 核心规则

1. **俄罗斯Litnet模型 [reader_eval]**: Litnet是俄语世界最大的网文平台，采用"免费试读+付费解锁"模式。热门类型：言情(55%)、奇幻(25%)、悬疑(15%)。典型的俄语网文篇幅为30-80万字。

2. **德国Neobooks的竞赛机制 [factory]**: Neobooks通过定期写作竞赛(每周主题)驱动创作。获奖作品有出版社签约机会。德语网文偏重奇幻和科幻，言情类相对较少。

3. **法国Fyctia的短篇偏好 [plot]**: 法语读者偏爱5-15万字的作品，长篇不受欢迎。Fyctia榜单上浪漫奇幻(Romantasy)和悬疑各占40%。

4. **非英语平台付费差异 [management]**: 非英语平台普遍比英语平台(直接订阅)更依赖"微支付/章节解锁"模式。作者稿酬水平为英语平台的40-70%。

## 引擎融合

| 引擎ID | 应用 |
|--------|------|
| reader_eval | 各国读者偏好分析 |
| factory | 竞赛驱动创作机制 |
| plot | 短篇偏好与节奏控制 |
| management | 付费模式与稿酬策略 |
