# 数据驱动的写作优化

> 摘要：利用数据分析指导写作决策——选题、节奏、章末钩子、读者留存预测。
> 来源：Data-Driven Content Strategy(网飞/字节跳动方法论)、番茄小说数据后台分析

## 核心规则

1. **A/B测试标题 [analysis]**: 同一内容准备2-3个标题初版，投入小范围测试(<1000曝光)，选择CTR最高的版本发布正式。标题测试的关键指标：点击率(CTR) > 转化后的互动率。

2. **留存曲线分析 [reader_eval]**: 网文/内容的典型留存曲线——第1章->第2章留存率最佳值>80%、第5章留存>60%、第10章留存>50%。使用LSTM或简单回归预测各章留存率，低于阈值时触发节奏调整。

3. **情绪曲线设计 [emotion]**: 基于读者情绪反馈(评论关键词/弃文时间点)反向设计情绪曲线。工具：采集章节评论的情感极性→绘制情绪曲线→与设计曲线对比→调整偏差>20%的章节。

4. **完读率优化 [tension_calibrator]**: 内容完读率(Complete Rate)是最重要的优化指标之一。低于30%的章节需分析：是否有长段落(>5句)、节奏断点(连续3章以上张力的回落)、信息密度骤降(连续2章以上无核心进展)。

## 引擎融合

| 引擎ID | 应用 |
|--------|------|
| analysis | 标题A/B测试与数据评估 |
| reader_eval | 留存曲线与弃文预测 |
| emotion | 情绪曲线设计与偏差检测 |
| tension_calibrator | 完读率优化与节奏调整 |
