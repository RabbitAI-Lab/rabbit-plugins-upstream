# 抖音推荐算法解析

> 摘要：抖音的推荐算法原理、流量池逐级推荐机制、完播率/互动率/关注率的权重。
> 来源：字节跳动技术博客、抖音创作者学院、行业逆向分析

## 核心规则

1. **流量池漏斗 [reader_eval]**: 抖音内容推荐机制是逐级流量池——初始池200-500人 → 5000-10000人 → 10万+ → 100万+。每一级的核心指标：完播率(>30%)、互动率(点赞/评论/转发的综合>5%)、关注转化率(>1%)。三项指标全部达标才能进入下一级池。

2. **三秒定生死 [analysis]**: 前3秒的内容决定用户是否划走。前3秒必须有"视觉钩子"(冲击性画面/悬念/冲突)。文本类内容前3秒的黄金法则：抛出问题或反常识观点。

3. **垂直领域标签 [world]**: 发布时需精确选择1-2级垂直标签(如"小说→玄幻"/"知识→金融")。泛标签(如"搞笑/日常")导致流量池用户画像模糊，推荐精度下降50%以上。

4. **黄金发布时间 [management]**: 不同内容类型的黄金发布时间不同——小说/故事类适合(20:00-23:00，用户活跃且停留时间长)；知识类适合(12:00-13:00，午休碎片时间)；情感类适合(22:00-00:00，深夜情绪敏感时段)。

## 引擎融合

| 引擎ID | 应用 |
|--------|------|
| reader_eval | 流量池晋级指标分析 |
| analysis | 前3秒钩子有效性评估 |
| world | 垂直标签选择策略 |
| management | 发布时间优化 |
