# 小红书爆文公式

> 摘要：小红书笔记爆文的标题公式、封面策略、内容结构和标签策略。
> 来源：小红书创作者学院、爆文拆解数据库、蒲公英平台数据

## 核心规则

1. **标题五公式 [reader_eval]**: 小红书爆款标题的五种高效公式——数字型("3个方法…")、反转型("千万别…否则…")、痛点型("如果你的…也…")、代入型("我花了…终于…")、秘密型("偷偷告诉你…")。爆文标题70%以上命中这五种之一。

2. **封面三要素 [analysis]**: 封面决定点击率。三要素——视觉冲击(高对比/主体突出)、文字提炼(2-4字高信息词)、情绪传递(情绪表达通过人物表情或色彩传递)。封面文字与正文主题偏差<10%。

3. **正文节奏三段式 [narration]**: 开头(50字内抓住注意力: 情绪共鸣/结果展示)→ 正文(分点式+emoji点缀，每段2-3句)→ 结尾(CTA: 点赞/收藏/关注)。正文中每150-200字插入一个换行+emoji断点。

4. **标签三圈层 [world]**: 笔记标签分三层——核心圈(1-3个精准标签: 对应细分领域)、拓展圈(3-5个关联标签: 上下游话题)、引流圈(2-3个热门标签: 大流量池但相关)。总标签数8-12个最优。

## 引擎融合

| 引擎ID | 应用 |
|--------|------|
| reader_eval | 标题公式匹配与有效性 |
| analysis | 封面视觉与点击率评估 |
| narration | 正文节奏三段式优化 |
| world | 三层标签体系设计 |
