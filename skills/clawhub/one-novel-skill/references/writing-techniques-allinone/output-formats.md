# 文档输出格式指南

> 本指南覆盖小说创作全流程中涉及的各种文档输出格式。
>
> **字数计算说明**: 全书总字数无上下限。章节正文内容需另行按规则计算：仅统计汉字，不包含标点、空格、英文、数字等。脚本中的字数计算使用 `len(re.findall(r'[\u4e00-\u9fff]', text))` 正则匹配中文字符。

---

## 第一篇：正文输出格式

### 第一章 小说正文标准格式

#### 1.1 Markdown格式（默认推荐）

```markdown
# 第X章 - {章节标题}

（正文内容）

---

**本章字数**: {字数}
```

**规范**:
- 章节标题用 `# 第X章 - {标题}`（一级标题）
- 段落之间空一行
- 对话独立成段
- 使用 `---` 分隔正文和尾部信息
- 尾部标注字数和修改记录
- **字数统计**: 仅统计中文字符

#### 1.2 TXT纯文本格式

```
第X章 {章节标题}

（正文内容）
```

**规范**:
- 章节标题单独一行，不加格式标记
- 每段首行缩进两个空格（或使用全角空格）
- 段落之间空一行
- 对话独立成段
- 文件编码: UTF-8

#### 1.3 EPUB电子书格式

**输出要求**:
- 使用标准XHTML结构
- CSS样式内联或外链
- 图片资源打包
- 元数据完整（书名、作者、ISBN等）

#### 1.4 DOCX/Word格式

**输出要求**:
- 标题样式: 标题1（章节标题）
- 正文字体: 宋体/微软雅黑，12pt
- 行距: 1.5倍行距
- 段落: 首行缩进2字符
- 页边距: 上下2.54cm，左右3.17cm

### 第二章 各平台投稿格式

#### 2.1 番茄小说投稿格式

```
书名: {书名}
作者: {笔名}
简介: 
{简介内容}

第一章 {章节标题}
{正文内容}

第二章 {章节标题}
{正文内容}
```

**规范**:
- 前3章必须完整
- 每章2000-3500中文字符
- 简介控制在200中文字符以内
- 正文中不能有作者的话

#### 2.2 起点中文网投稿格式

```
【书名】{书名}
【作者】{笔名}
【简介】
{简介内容}

【第一章 {章节标题}】
{正文内容}
```

**规范**:
- 开头3000中文字符为试读内容
- 需要提供完整大纲（3000中文字符以上）
- 简介控制在500中文字符以内

#### 2.3 晋江文学城投稿格式

```
文名：{书名}
作者：{笔名}
文案：
{简介内容}

第1章 {章节标题}
{正文内容}
```

**规范**:
- 文案（简介）要包含排雷和设定说明
- 标签要完整
- 第1章需有3000中文字符以上

#### 2.4 知乎盐选投稿格式

```
标题：{标题}
作者：{笔名}
来源：盐选专栏

（正文内容，第一人称叙事）
```

**规范**:
- 第一人称叙事
- 开篇要有钩子
- 3000-10000中文字符

## 第六篇：格式转换对照表

### 第一章 各格式使用场景

| 格式 | 使用场景 | 推荐工具 |
|------|---------|---------|
| Markdown (.md) | 默认格式、章节存储、大纲、设定 | Typora/VSCode |
| TXT (.txt) | 投稿、备份、阅读器导入 | 记事本 |
| EPUB (.epub) | 电子书分发 | Calibre/Sigil |
| DOCX (.docx) | Word编辑、打印 | Word/WPS |
| JSON (.json) | 状态文件、数据结构 | VSCode |
| HTML (.html) | 网页预览、EPUB内页 | 浏览器 |
| PDF (.pdf) | 打印、分享 | Word/WPS |

### 第二章 格式转换命令

**Markdown → EPUB**（使用Pandoc）:
```bash
pandoc input.md -o output.epub --metadata title="书名" --metadata author="作者"
```

**Markdown → DOCX**（使用Pandoc）:
```bash
pandoc input.md -o output.docx --reference-doc=template.docx
```

**Markdown → PDF**（使用Pandoc）:
```bash
pandoc input.md -o output.pdf --pdf-engine=xelatex
```

**Markdown → HTML**（使用Pandoc）:
```bash
pandoc input.md -o output.html -s --toc
```
