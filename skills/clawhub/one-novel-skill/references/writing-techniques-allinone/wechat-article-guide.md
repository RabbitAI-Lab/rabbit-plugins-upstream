# 微信公众号文章创作指南

> 针对微信公众号文章创作，提供完整的写作规范、排版格式、各分类资料搜索整合方法，自动搜索网上社会民生、科技/互联网、教育/职场、时尚丽人、餐饮美食、生活家居、体育健身、动物宠物、文学艺术、历史哲学、情感心理、政治时事、娱乐休闲、旅游摄影、产业行业、军武军迷、财政金融、健康医疗、法律司法、环境能源、农林牧渔、科学科普等分类的文章、资料、文献进行完善补充修改。

## 第一章：公众号文章基础知识

### 1.1 公众号文章核心特征

| 维度 | 特征 | 创作影响 |
|------|------|---------|
| **阅读场景** | 手机端碎片化阅读 | 段落短小、信息密度高、每段不超过3行 |
| **读者耐心** | 极低，前3秒决定是否继续 | 开头必须抓人，用悬念/痛点/冲突开场 |
| **传播方式** | 朋友圈转发、微信群分享 | 标题决定打开率，内容决定转发率 |
| **互动方式** | 留言区评论、在看/点赞 | 文章结尾引导互动，设置话题讨论 |
| **阅读时间** | 集中在晚8-10点、通勤时段 | 发文时间匹配读者活跃时段 |
| **完读率** | 核心指标，决定推荐量 | 每200-300字制造一个小钩子 |

### 1.2 公众号文章常见类型

| 类型 | 说明 | 字数建议 | 适合分类 |
|------|------|---------|---------|
| **热点解读** | 追踪社会热点，提供深度分析 | 2000-3000字 | 社会民生、政治时事 |
| **干货教程** | 提供实用知识/技能 | 1500-2500字 | 科技、教育、健康、法律 |
| **情感故事** | 以故事为载体传递情感 | 2000-4000字 | 情感心理、文学艺术 |
| **观点评论** | 针对话题发表独特见解 | 1500-2000字 | 历史哲学、产业行业 |
| **盘点汇总** | 列举式内容，信息量大 | 2000-3500字 | 娱乐休闲、旅游摄影 |
| **科普解读** | 将专业知识通俗化 | 2000-3000字 | 科学科普、环境能源 |
| **测评推荐** | 产品/服务体验分享 | 1500-2500字 | 时尚丽人、餐饮美食、生活家居 |
| **人物故事** | 讲述人物经历和感悟 | 2500-4000字 | 体育健身、军武军迷 |
| **案例分享** | 真实案例+分析解读 | 2000-3000字 | 法律司法、财政金融 |
| **行业分析** | 行业趋势/深度分析 | 2500-4000字 | 产业行业、农林牧渔 |

### 1.3 公众号文章结构模板

```markdown
# {标题}（吸引眼球，制造悬念或痛点）

> {引导语}（一句话概括文章价值，或制造情绪共鸣）

## 一、{开篇钩子}
{用痛点/热点/故事/数据/疑问开头，快速抓住读者注意力}

## 二、{正文展开1}
{核心内容，分点阐述}
- {要点1}：{展开说明}
- {要点2}：{展开说明}

## 三、{正文展开2}
{深入分析或案例展示}

## 四、{观点升华}
{总结观点，提炼金句}

## 结语
{回顾全文，引导互动}
{引导关注/在看/留言}
```

### 2.2 分类写作要点

**社会民生**：
- 紧跟热点，时效性第一
- 提供多角度分析，避免片面
- 关注普通人切身利益
- 语言通俗易懂，避免官腔

**科技/互联网**：
- 追踪最新技术动态
- 将专业术语通俗化
- 分析行业影响和趋势
- 提供实用建议和观点

**教育/职场**：
- 聚焦读者痛点（升学/求职/晋升）
- 提供可操作的方法论
- 结合真实案例
- 传递正能量和成长思维

**时尚丽人**：
- 注重视觉呈现（搭配图/效果图）
- 结合季节和流行趋势
- 提供实用穿搭/美妆技巧
- 品牌推荐需真实客观

**餐饮美食**：
- 色香味俱全的描写
- 提供详细的做法步骤
- 结合食材营养知识
- 探店类需真实体验

**生活家居**：
- 解决实际生活问题
- 提供可落地的改造方案
- 推荐性价比高的产品
- 图文并茂展示效果

**体育健身**：

## 第三章：资料搜索与整合流程

### 3.1 搜索执行流程

```
Step 1: 确定文章主题和分类
  ├── 确认文章所属分类（22个分类之一）
  ├── 确认文章类型（热点解读/干货教程/情感故事等）
  └── 确认核心观点或信息

Step 2: 搜索核心资料
  ├── 使用对应分类的搜索关键词模板
  ├── 搜索权威信源（官方数据/学术论文/行业报告）
  ├── 搜索同类爆款文章参考结构
  └── 搜索读者评论了解痛点和关注点

Step 3: 搜索背景资料
  ├── 搜索相关的政策/法规/标准
  ├── 搜索历史背景和上下文
  ├── 搜索数据和统计信息
  └── 搜索专家观点和权威解读

Step 4: 搜索案例素材
  ├── 搜索真实案例/故事
  ├── 搜索用户评论和反馈
  ├── 搜索图片/视频素材（注意版权）
  └── 搜索相关金句和名言

Step 5: 资料整合与文章生成
  ├── 按文章结构模板组织内容
  ├── 将搜索资料融入文章中
  ├── 注明数据来源（增强可信度）
  └── 原创化改写，避免抄袭
```

### 3.2 信源可信度评估

| 信源类型 | 可信度 | 使用建议 |
|---------|--------|---------|
| 官方政府网站 | 极高 | 政策类文章的权威来源 |
| 学术论文/期刊 | 高 | 科普/深度分析类 |
| 权威媒体（新华社/人民日报等） | 高 | 时政/社会热点类 |
| 行业研究报告 | 中高 | 产业/财经类 |
| 知名企业官网 | 中 | 科技/产品类 |

| 自媒体/个人博客 | 低 | 仅作参考，需交叉验证 |
| 论坛/社交媒体 | 极低 | 作为案例/观点参考，不作为事实依据 |

## 第四章：公众号文章写作规范

### 4.1 标题规范

| 类型 | 公式 | 示例 |
|------|------|------|
| **痛点型** | {痛点}+{解决方案} | "30岁后记忆力越来越差？这3个方法让你重回巅峰" |
| **悬念型** | {反常现象}+{原因} | "为什么越来越多的年轻人选择不婚？真相令人深思" |
| **热点型** | {热点事件}+{观点} | "XX事件刷屏的背后，我看到的是……" |
| **干货型** | {数字}+{价值承诺} | "5个让你效率翻倍的工作方法（建议收藏）" |
| **对比型** | {A} vs {B} + 结论 | "月薪3000和月薪30000的人，差距到底在哪？" |
| **故事型** | {人物}+{转折} | "从负债百万到年入千万，他只做对了一件事" |
| **反常识型** | {常识}+{真相} | "你以为是在养生？其实是在养病！" |

**标题原则**：
1. 字数控制在15-25字之间
2. 制造好奇/焦虑/共鸣
3. 包含关键词（便于搜索）
4. 不夸张不标题党（避免投诉）
5. 数字能提升打开率

### 4.2 排版规范

| 元素 | 规范 |
|------|------|
| **正文字号** | 15-17px（手机端） |
| **行间距** | 1.75-2.0倍 |
| **段间距** | 空一行 |
| **每段长度** | 不超过3行，2-3句最佳 |
| **重点加粗** | 核心观点/金句加粗 |
| **引用** | 使用引用格式（> ） |
| **列表** | 使用序号或圆点列表 |
| **图片** | 每500-800字配一张图 |
| **小标题** | 使用## 三级标题 |
| **对齐方式** | 左对齐（非两端对齐） |
| **颜色** | 主色不超过2种，正文黑色 |
| **首行缩进** | 不缩进（移动端阅读） |

### 4.3 正文写作规范

**开头规范**（前200字决定完读率）：

| 开头类型 | 方法 | 示例 |
|---------|------|------|
| **痛点开场** | 直击读者痛点 | "你是不是也这样：收藏了很多文章，却再也没有打开过？" |
| **故事开场** | 用故事带入 | "上周，我的朋友小王遇到了一件让他崩溃的事……" |
| **数据开场** | 用惊人数据吸引 | "根据最新统计，中国有超过3亿人存在睡眠问题。" |
| **疑问开场** | 引发读者思考 | "你有没有想过，为什么同样的工作，别人做得比你好？" |
| **热点开场** | 借热点引入 | "这两天刷屏的XX事件，背后藏着一个我们忽视的问题。" |
| **反常识开场** | 打破读者认知 | "你可能不相信，但这确实是真的：你每天都在做的这件事，正在毁掉你的健康。" |

**正文规范**：
- 每段2-3句，不超过3行
- 每200-300字制造一个小钩子
- 核心观点加粗
- 数据/引用标注来源
- 适当使用短句，增强节奏感
- 避免长难句和复杂结构

**结尾规范**：
- 总结全文，提炼金句
- 引导互动（提问/投票/话题讨论）
- 引导关注/在看/转发
- 预告下期内容（如有）

### 4.4 AI痕迹去除（公众号专项）

公众号文章尤其需要去除AI痕迹，因为读者对AI生成内容容忍度极低：

| 检查项 | 问题示例 | 修正方案 |
|-------|---------|---------|
| 模板化开头 | "随着……的发展"、"在……的背景下" | 直接切入主题，用故事/数据/痛点开场 |
| 完美句式 | 每句都工整对仗 | 加入口语化表达、短句、不完整句 |
| 缺乏个性 | 没有作者的个人观点和情感 | 加入"我"的视角和个人经历 |
| 过度引用 | 每段都引用名人名言 | 减少引用比例，用自己的话表达 |
| 结构死板 | 每段结构一样 | 轮换不同开头方式和段落结构 |
| 缺乏互动感 | 纯叙述，没有和读者对话 | 加入"你有没有……""你是不是……"等互动句式 |
| 过于理性 | 只有逻辑没有情感 | 加入情感色彩和个人感受 |
| 缺乏细节 | 泛泛而谈，没有具体案例 | 加入真实案例、具体数字、细节描写 |

## 第五章：内容安全与合规

### 5.1 公众号内容红线

| 红线类型 | 禁止内容 | 处理方式 |
|---------|---------|---------|
| 政治敏感 | 攻击国家政策、领导人、体制 | 完全避免 |
| 色情低俗 | 露骨描写、性暗示 | 完全避免 |
| 虚假信息 | 造谣、传谣、伪科学 | 核实来源，标注引用 |
| 侵权内容 | 抄袭、盗图、侵犯隐私 | 原创为主，引用需授权 |
| 诱导分享 | 强制转发、利诱分享 | 避免违规诱导 |
| 医疗广告 | 未经审批的医疗/药品宣传 | 注明"非医疗建议" |
| 金融违规 | 荐股、非法集资 | 完全避免 |

### 5.2 公众号合规提示

1. **原创声明**：所有文章必须标注原创
2. **图片来源**：使用无版权图片或自制图片
3. **数据引用**：标注数据来源和发布时间
4. **免责声明**：健康/法律/金融类文章需加免责声明
5. **避免标题党**：标题与内容一致，不夸大
6. **评论区管理**：及时处理违规评论

### 6.2 输出要求

1. 文章标题必须吸引眼球且不标题党
2. 开头200字必须抓住读者注意力
3. 正文每段不超过3行
4. 每500-800字配一张图（标注图片来源）
5. 核心观点和关键数据加粗
6. 数据/引用必须标注来源
7. 结尾必须引导互动和关注
8. 全文AI痕迹去除（参考第四章4.4节）
9. 输出文章时同时输出资料搜索整合报告
10. 标注文章分类和关键词（便于公众号标签化）
