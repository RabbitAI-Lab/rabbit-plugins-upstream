# 读者黏性设计指南

> 完整的吸引读者技法、期待管理、悬疑设计详见 `references/narrative-theory.md` 第五篇和第九篇。

## 一、读者黏性核心要素

### 1.1 开篇吸引力（首段3句内）
- 第一句建立冲突或悬念
- 第二句给出关键信息
- 第三句制造"不得不读下去"的驱动力
- 开篇如抛炸弹，拒绝铺垫式开头

**示例**:
- ❌ "这一天，阳光明媚，张三像往常一样起床……"
- ✅ "张三睁眼时，一把剑正抵在他喉咙上。"
- ✅ "'你被解雇了。'人事部主管面无表情地说。"
- ✅ "血从门缝里渗出来的时候，李四刚走到走廊尽头。"

### 1.2 章节钩子设计
每章结尾必须提供读者"翻页"的动力：

**钩子类型**:
- **悬念钩子**: "他推开门，看到了这辈子最不敢相信的一幕——"
- **反转钩子**: "原来，那个一直在帮他的人，才是真正的敌人。"
- **情感钩子**: "她笑了笑，眼泪却掉了下来。'再见，张三。'"
- **信息钩子**: "系统提示：您的真实身份为——"
- **威胁钩子**: "三天后，就是他的死期。"
- **疑问钩子**: "她到底是谁？为什么会在这种地方？"

**钩子原则**:
- 每个钩子必须在下一章有回应
- 大钩子（跨卷/跨多章）+ 小钩子（下一章回应）交替
- 章节末尾最后一句必须是钩子
- 钩子要具体，不要空泛（"一场风暴即将来临" → "三天后，那张暗杀令就会送到他手上"）

### 1.3 读者代入感

**增强代入感的技法**:
- **多感官描述**: 视觉+听觉+触觉+嗅觉，一次2-3种
- **细节描绘**: 一个精准的细节胜过一百句概括
- **情绪共鸣**: 让读者与角色共情（角色遭遇的困境具有普适性）
- **分段解构**: 复杂场景拆解为小段，逐步展开
- **分发好奇心**: 抛出问题，逐步揭示答案
- **适时幽默**: 调节情绪，增加人情味
- **使用对比**: 强弱对比/善恶对比/美丑对比增强张力
- **层层递进**: 信息逐步释放，不一次性倒完

**常见问题**:
- ❌ 角色说"我很害怕"，读者无感
- ✅ "他的腿在发抖。牙齿不受控制地磕碰。他想跑，但脚像钉在地上。"（读者感同身受）

## 二、情绪设计

### 2.1 情绪铺垫
- 重要情绪爆发前需要1-2章的铺垫
- 铺垫方式：细节积累、氛围营造、角色心理变化
- 不要"突然"悲伤/愤怒/感动

### 2.2 情绪转换
- 情绪转换必须有"触发事件"
- 转换过程要自然（悲伤→愤怒：需要一个触发点）
- 快速转换（一秒变脸）需要合理解释

### 2.3 情绪节奏
```
平静 → 微澜（微冲突） → 起伏（小高潮） → 回落（缓冲） → 汹涌（大高潮）
```
- 避免长时间处于同一情绪基调
- 紧张后要有舒缓，舒缓中埋下紧张种子

## 三、悬念管理

### 3.1 悬念层级
- **即时悬念**: 本章内解决（"这把钥匙开哪扇门？"）
- **短期悬念**: 2-5章内解决
- **中期悬念**: 一卷内解决
- **长期悬念**: 贯穿全文

### 3.2 悬念设计原则
- 大悬念套小悬念（俄罗斯套娃结构）
- 解决一个悬念的同时抛出新的
- 悬念要有具体问题（不是"会发生什么"而是"他会选A还是B？"）
- 悬念的答案不能太容易猜到

## 四、章节内容安排

### 4.1 每章内容密度
- 至少1个核心事件
- 至少1个微冲突（日常章节）
- 至少1个钩子（结尾）
- 至少推进1条主线或支线
- 信息量适度（不是越多越好，太多读者消化不了）

### 4.2 信息释放节奏
```
章开头: 回顾关键信息（1-2句）
章中间: 释放新信息（核心事件）
章结尾: 埋设新悬念（钩子）
```

### 4.3 读者心理节奏
- 前1/3章: 建立期待（"接下来会发生什么？"）
- 中1/3章: 满足期待+制造新期待
- 后1/3章: 设置下章期待（钩子）
