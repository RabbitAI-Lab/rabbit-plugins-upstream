# 设定与大纲审查完善指南

> 对用户提供的设定及大纲进行系统性审查和完善，确保故事骨架扎实、因果闭环、爽点清晰。

---

## 第一章：核心卖点审查

### 1.1 核心卖点提炼

审查设定和大纲时，必须回答以下问题并输出明确结论：

**问题一：这个故事的核心卖点是什么？**
- 一句话概括：什么类型的读者会被什么元素吸引？
- 示例：都市赘婿+系统流——"被家族抛弃的上门女婿获得神级签到系统，在扮猪吃虎中步步登天"
- 示例：玄幻修仙——"废柴少年觉醒上古血脉，在尔虞我诈的仙门中逆天改命"

**问题二：爽点是什么？**
列出所有爽点类型及其在文中的位置：

| 爽点类型 | 具体内容 | 分布位置 | 密度 |
|---------|---------|---------|------|
| 升级爽点 | 主角实力突破/技能解锁 | 前10章/中期/后期 | 每X章一次 |
| 打脸爽点 | 反杀/碾压/身份揭露 | 前10章/中期/后期 | 每X章一次 |
| 收获爽点 | 获得宝物/权力/感情/盟友 | 前10章/中期/后期 | 每X章一次 |
| 揭秘爽点 | 真相揭露/身份曝光/伏笔回收 | 前10章/中期/后期 | 每X章一次 |

**问题三：给读者带来什么样的快乐？**
- 释放感：憋屈→爆发，压抑→爽快（常见于都市赘婿、废柴逆袭）
- 代入感：主角的成长让读者获得替代性满足（常见于系统流、升级流）
- 悬念感：谜题层层揭开，读者追更欲强烈（常见于悬疑、规则怪谈）
- 情感共鸣：角色间的羁绊打动读者（常见于言情、纯爱、群像）
- 知识/眼界拓展：独特的世界观设定让读者大开眼界（常见于科幻、玄幻）

**问题四：试着用一句话概括这个故事？**
格式：[主角身份] + [核心设定] + [核心冲突] + [最终目标]
示例：一个被家族抛弃的上门女婿获得神级签到系统，在各方势力的打压中一步步崛起，最终成为俯瞰众生的至尊强者。

**问题五：这个故事的戏剧空间有多大？**
戏剧空间 = 故事可以展开的广度和深度，评估维度：

| 维度 | 评估标准 | 分数(1-10) | 说明 |
|------|---------|-----------|------|
| 冲突层次 | 是否有从个人→家族→国家→世界→位面的递进空间 | | |
| 角色网络 | 主要角色群是否丰富，关系是否复杂 | | |
| 世界观纵深 | 是否有未探索区域、隐藏势力、上古秘辛 | | |
| 成长阶梯 | 主角的成长路径是否清晰且有足够的上升空间 | | |
| 伏笔储备 | 是否有足够的伏笔支撑长篇连载 | | |
| 分支可能性 | 是否有多个支线可衍生 | | |

## 第二章：因果线梳理

### 2.1 因果链分析

开局的每一个设定都不是孤立的，它们都是"果"，前面必然有"因"；它们也都是"因"，后面必然产生"果"。

**审查步骤：**

**Step 1：列出开局所有设定**
将开局中出现的所有设定逐一列出，包括：
- 出场人物及其身份/性格/关系
- 世界设定（力量体系、社会制度、历史背景）
- 主角的初始状态（身份、能力、资源、处境）
- 核心冲突的起点事件

**Step 2：追因——每个设定的前置原因**
对每个设定追问"为什么"：
```
设定：主角是上门女婿，被家族抛弃
追因：
├── 为什么被抛弃？→ 家族遭遇变故，需要联姻保全
├── 为什么选中主角？→ 主角是庶出/天赋低/性格软弱
├── 家族的变故是什么？→ 敌对势力打压，家族陷入危机
└── 敌对势力为什么打压？→ 争夺某资源/历史恩怨
```

**Step 3：推果——每个设定引发的后果**
对每个设定追问"会导致什么"：
```
设定：主角获得签到系统
推果：
├── 短期后果：获得初期资源，开始翻身
├── 中期后果：引起势力注意，被试探/拉拢/打压
├── 长期后果：系统成为核心竞争力，也成为被觊觎的目标
└── 最终闭环：系统帮助主角达成最终目标（或需要付出代价）
```

**Step 4：建立因果网络图**
```
     因A ──→ 设定1 ──→ 果A ──→ 新设定 ──→ 新果
     因B ──→ 设定2 ──→ 果B ──→ 新设定 ──→ 新果
     因C ──→ 设定3 ──→ 果C ──→ 新设定 ──→ 新果
```

所有因果线最终必须汇聚到故事的核心冲突上，形成闭环。

### 2.2 隐患与伏笔映射

开局的所有设定都会成为主角的隐患和伏笔，包括：

| 设定元素 | 当前状态 | 隐患/伏笔 | 预期回收位置 |
|---------|---------|----------|------------|
| 出场人物A | 是盟友/敌人/中立 | 他的真实动机是什么？ | 第X卷 |
| 人物性格B | 懦弱/冲动/多疑 | 会导致什么决策失误？ | 第X章 |
| 情节决策C | 主角做出了某选择 | 这个选择的后果是什么？ | 第X卷 |
| 环境设定D | 某种规则/限制 | 这个规则如何被利用/打破？ | 第X章 |

### 2.3 故事闭环验证

每个设定都必须在故事中被"使用"，不能有冗余设定。验证标准：
- [ ] 每个出场人物都有其叙事功能（推动剧情/衬托主角/提供信息）
- [ ] 每个设定都有其对应的事件来展现
- [ ] 每个伏笔都有预期回收位置
- [ ] 所有因果线最终汇聚到核心冲突
- [ ] 无"为设定而设定"的冗余内容

## 第三章：问题→条件→解决模型

### 3.1 三步分析法

按照"问题→条件→解决"的步骤，理清主角的完整行动逻辑：

**Step 1：明确问题**
- 主角面临的核心问题是什么？（生存/复仇/变强/守护/回家等）
- 当前阶段的具体问题是什么？（如：被追杀/缺少资源/身份暴露等）
- 问题的紧迫程度？（立刻致命/中期威胁/长期隐患）

**Step 2：盘点条件**
- 主角拥有什么？（能力/资源/人脉/信息/道具）
- 主角缺少什么？（实力/势力/情报/时间/盟友）
- 外部环境提供什么？（机遇/规则/帮手/压力）

**Step 3：设计解决路径**
- 短期方案：立刻解决当前危机的行动
- 中期方案：积累资源/提升实力的路径
- 长期方案：达成最终目标的完整路线
- 阻碍因素：每个方案可能遇到的阻力和应对

### 3.2 分层应用

将三步法应用到每个剧情层级：

**全书级**：
```
问题：主角如何从废柴成为至尊？
条件：拥有系统/特殊血脉/贵人相助
阻碍：敌对势力/自身局限/规则限制
解决：升级→获取资源→击败对手→突破自我→达成目标
```

**卷级**：
```
问题：本卷要解决的核心冲突是什么？
条件：本卷可用的角色/资源/信息
阻碍：本卷的反派/陷阱/困境
解决：本卷的高潮事件和角色成长
```

**章节级**：
```
问题：本章要推进什么？
条件：本章出场的角色和可用信息
阻碍：本章的冲突/障碍/反转
解决：本章的事件结果和钩子
```
