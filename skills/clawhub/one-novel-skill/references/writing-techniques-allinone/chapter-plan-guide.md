# 章纲制定指南

> 根据细纲的情节概览，规划每一章的重点内容和目标，输出包含章节标题和每章主要内容的完整章纲。

---

## 第一章：章纲生成流程

### 1.1 前置条件

生成章纲前，必须确认以下材料已就绪：

- [ ] 总纲已审核通过（参考 `references/outline-review.md`）
- [ ] 细纲已生成（参考 `references/detailed-outline-guide.md`）
- [ ] 人物卡已就绪
- [ ] 伏笔规划已明确

### 1.2 细纲→章纲转化规则

每个细纲段落转化为1-3章，转化规则如下：

| 细纲段落类型 | 对应章节数 | 转化方法 |
|------------|-----------|---------|
| 单场景事件（1个核心冲突） | 1章 | 直接展开为该章全部内容 |
| 多场景事件（起承转合完整） | 2-3章 | 按起→承→转→合拆分为多章 |
| 重大转折/高潮 | 1-2章 | 高潮本身1章，前奏/余波1章 |
| 过渡/衔接 | 1章 | 合并过渡内容为一章 |

**字数换算**：
```
细纲段落字数预估 ÷ 2850(均值) = 章节数
例：细纲段落预估6000字 → 6000÷2850 ≈ 2章
```

### 1.3 章纲生成步骤

```
Step 1: 解析细纲段落
  ├── 确认本段的核心事件和情节定位
  ├── 确认出场角色
  ├── 确认字数预估
  └── 决定拆分为几章

Step 2: 拆分章节
  ├── 按事件发展顺序拆分
  ├── 确保每章都有独立的微冲突
  ├── 确保每章结尾有钩子
  └── 确保每章字数在2200-3500字之间

Step 3: 设计章节标题
  ├── 选择命名风格（二字/四字/七字/诗句式）
  ├── 标题要体现本章核心
  ├── 制造悬念或情绪冲击
  └── 连续3章不使用相同格式（轮换不同风格）

Step 4: 填充章纲内容
  ├── 本章核心（一句话概括）
  ├── 主线推进
  ├── 出场角色及状态
  ├── 关键事件（按顺序列出）
  ├── 伏笔操作
  ├── 情绪节奏
  └── 结尾钩子（强制）

Step 5: 跨章衔接检查
  ├── 本章开头与上章结尾的衔接
  ├── 本章结尾钩子与下章开头的衔接
  └── 角色状态在章间的一致性
```

## 第二章：章纲内容规范

### 2.1 每章纲必含内容

```markdown
## 第{N}章 - {标题}

### 本章核心
一句话概括本章内容。

### 主线推进
- 主线A（核心冲突线）: [推进到什么程度]
- 主线B（感情线/成长线）: [推进到什么程度]（如有）

### 出场角色
- {角色名}: [状态/行为/在本章中的作用]

### 关键事件
1. [事件一: 包含起因→经过→结果]
2. [事件二: ...]
3. ...

### 伏笔操作
- [埋设] 伏笔A: [内容] → 预期回收: [第X章]
- [回收] 伏笔B: ← [埋设于第X章]
- [延续] 伏笔C: [新进展]

### 情绪节奏
- 开头: [读者情绪起点]
- 中段: [情绪变化过程]
- 结尾: [情绪落点，需与钩子配合]

### 结尾钩子（强制）
[本章结尾的悬念/反转/新线索/待解之谜]

### 字数目标（强制）
{2200-3500} 字（仅统计汉字，用户有特定要求则以用户为准）
```

### 2.2 章纲示例

```markdown
## 第1章 - 废灵根

### 本章核心
主角林轩在家族灵根测试中被判为废灵根，从天才沦为笑柄，被贬为外门杂役。

### 主线推进
- 主线A（逆袭成长线）: 主角从家族核心跌入谷底，埋下逆袭的起点
- 主线B（感情线）: 青梅竹马林雪暗中关心，但不敢公开表态

### 出场角色
- 林轩（主角）: 16岁，测试前自信满满，测试后心灰意冷
- 林震天（家主）: 对结果失望，但暗中安排主角去外门而非驱逐
- 林啸天（大长老）: 借机打压主角一脉，极力主张驱逐
- 林雪（青梅）: 欲言又止，悄悄给主角送药

### 关键事件
1. 家族灵根测试大会，林轩被测出杂灵根，全场哗然
2. 大长老借题发挥，指责主角浪费家族资源，要求驱逐
3. 家主与长老争论后，折中处理：贬为外门杂役
4. 主角收拾行李离开内院，林雪暗中送来疗伤药
5. 主角在外门住处发现一封神秘信件，指引他去后山

### 伏笔操作
- [埋设] 大长老为何针对主角一脉 → 预期回收: 第2卷
- [埋设] 神秘信件是谁所留 → 预期回收: 第3章

### 情绪节奏
- 开头: 期待（测试前的紧张氛围）
- 中段: 震惊→憋屈（测试结果揭晓→被贬）
- 结尾: 希望→好奇（发现神秘信件）

### 结尾钩子
主角打开神秘信件，信上只有一行字："子时三刻，后山禁地，你的命运在那里。"

### 字数目标
3000字
```

## 第三章：章节分布与衔接

### 3.1 章节分布原则

| 分布要素 | 原则 | 说明 |
|---------|------|------|
| 总章数 | 无上限 | 根据细纲合理分布，不设上限 |
| 每卷章数 | 无强制 | 根据该卷剧情容量自由确定 |
| 每章字数 | 2200-3500字 | 仅统计汉字，用户有特定要求则以用户为准 |
| 卷间过渡 | 1-2章 | 新卷开头需承接上卷结尾的钩子 |
| 幕间过渡 | 1章 | 三幕之间的过渡章节 |

### 3.2 章节衔接设计

**衔接检查清单**（每章生成后检查）：
- [ ] 本章开头与上章结尾的钩子是否自然衔接
- [ ] 本章结尾的钩子是否为下一章提供了明确的起点
- [ ] 角色状态在章间是否有跳跃（如伤势突变、位置瞬移）
- [ ] 时间线在章间是否连续（没有无故跳过关键时间点）
- [ ] 情绪节奏在章间是否合理（没有从极度悲伤突然转为欢乐）

**跨卷衔接**：
- 上卷最后一章结尾 → 新卷第一章开头（直接回应上卷钩子）
- 新卷第一章需包含：上卷重要状态回顾（1-2段）、本卷新冲突引入、本卷核心钩子

## 第四章：章纲输出规范

### 4.1 全书章纲输出格式

```markdown
# 《{小说名}》全书章纲

## 第一卷：{卷名}（第1章 - 第{N}章）

### 卷概要
- **章节范围**: 第1章 - 第{N}章
- **卷核心冲突**: 
- **本卷角色成长**: 
- **卷尾高潮**: 

---

## 第1章 - {标题}

### 本章核心
[一句话概括]

### 关键事件
1. 
2. 

### 结尾钩子
[强制]

### 字数目标
{N}字

---

## 第2章 - {标题}
...
```

### 4.2 输出要求

1. 章纲必须覆盖细纲中规划的所有章节，不能有遗漏
2. 每章必须包含：核心、关键事件、结尾钩子、字数目标
3. 章节标题必须轮换风格（连续3章不使用相同格式）
4. 章纲中的伏笔操作必须与伏笔追踪表一致
5. 章纲输出后需与细纲核对，确保覆盖所有细纲段落
6. 章纲审核通过后方可开始正文写作
