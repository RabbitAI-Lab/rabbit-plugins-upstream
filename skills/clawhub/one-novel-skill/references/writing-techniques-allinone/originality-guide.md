# 原创性合规与账号安全指南

> 禁止抄袭、搬运等损害账号相关行为。所有创作内容必须为原创，引用他人内容必须规范标注，确保作品合规、账号安全。

---

## 第一章：禁止行为清单

### 1.1 绝对禁止行为

以下行为**严格禁止**，一旦触发将直接导致账号违规、封禁、法律纠纷：

| 禁止行为 | 定义 | 示例 | 后果 |
|---------|------|------|------|
| **抄袭** | 未经授权直接复制他人作品的全部或大部分内容 | 直接复制其他小说的段落、章节 | 封号、法律诉讼 |
| **搬运** | 将其他平台/作者的作品原封不动发布到本平台 | 将起点的小说搬运到番茄 | 封号、侵权赔偿 |
| **洗稿** | 对他人作品进行同义词替换、语序调整后发布 | 将A小说的情节换人物名发布 | 封号、被举报下架 |
| **融梗** | 系统性地拼凑多个作品的设定、情节、人设 | 综合多部小说的核心设定拼成一部 | 被读者举报、口碑崩塌 |
| **盗版** | 发布未经授权的版权作品 | 发布金庸、唐家三少等版权作品 | 法律诉讼、封号 |
| **AI代写冒充原创** | 使用AI生成内容但不标注，完全不做原创化改造 | 直接输出AI生成的正文不修改 | 被平台检测、标签降权 |

### 1.2 高风险行为（建议避免）

以下行为虽不直接违规，但会损害账号信誉和作品口碑：

| 高风险行为 | 说明 | 建议处理方式 |
|-----------|------|------------|
| **过度借鉴设定** | 设定框架与某知名作品高度相似 | 加入足够多的原创元素进行差异化 |
| **同人文侵权** | 未经授权使用他人IP角色和世界观 | 获取授权或完全原创化改造 |
| **跟风爆款套路** | 完全复制爆款作品的节奏和结构 | 在经典套路中加入个人特色 |
| **低质量内容** | 为了更新速度产出大量灌水内容 | 保持质量优先于数量 |

## 第二章：原创性保障措施

### 2.1 创作原创性自检

每次创作前和创作后，执行以下自检：

**创作前自检**：
- [ ] 故事的核心设定是否有明显的借鉴痕迹？
- [ ] 主角的人设是否与某知名角色高度相似？
- [ ] 开篇情节是否与某热门作品雷同？
- [ ] 如果读者同时看过参考作品，是否能明显看出"抄袭感"？

**创作后自检**：
- [ ] 本章是否有大段内容与参考来源相似？
- [ ] 人物对话风格是否有其他作品的影子？
- [ ] 情节发展是否与某已知作品撞车？
- [ ] 整体阅读体验是否有"既视感"？

### 2.2 原创化改造方法

当需要参考现有作品时，必须进行充分的原创化改造：

| 改造维度 | 方法 | 示例 |
|---------|------|------|
| **设定改造** | 保留核心概念，改变具体实现方式 | "签到系统"→"打卡系统"：触发条件不同、奖励机制不同 |
| **人设改造** | 保留角色定位，改变性格/背景/动机 | "废柴逆袭"→"天才陨落后重新崛起"：起点不同、成长路径不同 |
| **情节改造** | 保留冲突类型，改变具体事件和节奏 | "被退婚后觉醒"→"被家族抛弃后获得传承"：触发事件不同 |
| **世界观改造** | 保留核心规则，改变表现形式和风格 | "东方玄幻"→"西方奇幻+东方修炼"：融合创新 |
| **叙事改造** | 保留故事内核，改变叙事视角和结构 | "第三人称线性叙事"→"第一人称插叙+多视角" |

### 2.3 引用规范

当确实需要引用他人内容时，必须严格遵守以下规范：

| 引用类型 | 规范要求 | 示例 |
|---------|---------|------|
| **经典名句** | 标注出处，不超过原文10% | "正如《论语》中所说：'学而不思则罔'" |
| **数据引用** | 标注数据来源和发布时间 | "根据国家统计局2025年数据……" |
| **文献引用** | 标注作者、作品名、出版信息 | "王小波在《沉默的大多数》中写道……" |
| **灵感来源** | 在作品简介或后记中致谢 | "本书的XX设定灵感来源于《XXX》" |

## 第三章：账号安全保护

### 3.1 账号违规红线

| 违规类型 | 触发条件 | 处罚力度 | 恢复难度 |
|---------|---------|---------|---------|
| **抄袭** | 被权利人举报+平台核实 | 永久封号 | 几乎不可能 |
| **搬运** | 平台检测到内容重复 | 下架作品+警告/封号 | 极难 |
| **恶意刷量** | 数据异常波动 | 清空数据+降权 | 困难 |
| **违规内容** | 涉政/涉黄/涉暴 | 下架+封号 | 几乎不可能 |
| **恶意举报** | 被多人举报核实 | 作品下架调查 | 视情况 |

### 3.2 账号保护措施

1. **一稿一平台**：同一作品不要同时在多个平台发布相同内容（可首发一个平台，其他平台延后发布）
2. **保持更新频率**：稳定的更新频率有助于账号权重，避免长时间断更
3. **读者互动**：积极回复评论区，建立读者信任，降低被恶意举报风险
4. **保留创作记录**：保存草稿、大纲、修改记录，作为原创证据
5. **避免敏感题材**：严格遵守 `references/content-safety.md` 内容安全规范
6. **定期自查**：每完成一卷，检查是否有抄袭/搬运风险

### 3.3 被误判抄袭的应对

如果被平台或读者误判抄袭，按以下步骤处理：

```
Step 1: 冷静核实
  ├── 确认被指控的具体内容
  └── 对比原文，确认是否真的存在相似

Step 2: 收集证据
  ├── 保存创作时间记录（草稿/修改记录）
  ├── 保存大纲和设定文件
  └── 保存参考资料和灵感来源

Step 3: 申诉
  ├── 通过平台官方渠道提交申诉
  ├── 附上创作证据
  └── 说明创作过程和灵感来源

Step 4: 修改（如有必要）
  ├── 如确实有相似段落 → 立即修改
  └── 如完全无相似 → 坚持申诉
```

## 第四章：创作铁律（原创相关）

### 4.1 原创铁律

1. **零抄袭**：任何时候不得复制他人作品的内容
2. **零搬运**：不得将其他平台/作者的作品发布到本平台
3. **零洗稿**：不得对他人作品进行同义替换后发布
4. **引用必标注**：引用他人内容必须注明出处
5. **灵感非抄袭**：借鉴灵感不等于抄袭，但必须做充分原创化改造
6. **AI辅助非AI代写**：可使用AI辅助写作，但必须进行充分的原创化改造和AI去痕，不得直接输出AI内容冒充原创

### 4.2 原创性质量检查清单

- [ ] 核心设定无明显借鉴痕迹
- [ ] 主角人设非典型套路化
- [ ] 开篇情节无雷同
- [ ] 无大段与参考来源相似的内容
- [ ] 引用内容已标注出处
- [ ] 已做充分的原创化改造
- [ ] AI辅助内容已完成去痕和原创化改造
- [ ] 作品可安全发布到任何平台
