# 细纲生成指南

> 根据大纲和人物脸谱生成详细的细纲，合理规划章节数和情节分布，确保每章字数在2200-3500字之间。

---

## 第一章：细纲生成流程

### 1.1 前置准备

生成细纲前，必须确认以下材料已就绪：

- [ ] 总纲（故事主线、核心冲突、三幕结构）
- [ ] 分卷规划（每卷的核心冲突、起止范围）
- [ ] 人物卡（主角、重要配角、反派的人物设定）
- [ ] 风格锚定（叙事语气、句式偏好、禁用词）

### 1.2 章节数计算

根据大纲的剧情容量和字数要求，合理计算章节数：

**计算公式**：
```
预估总章节数 = 预估总字数(汉字) ÷ 平均每章字数(2850字)
```

**每章字数标准**：
- 标准：2200-3500汉字
- 建议均值：2850汉字
- 特殊章（高潮/转折）：可接近3500字
- 过渡章（衔接）：可接近2200字

**章节分布原则**：
- 每卷章节数根据该卷剧情容量自由确定，无强制上限
- 分卷最低4卷，按剧情大纲合理分布
- 卷内情节分布遵循：开端(15-20%) → 发展(30-35%) → 深化(30-35%) → 高潮结局(15-20%)

### 1.3 细纲段落划分

每个细纲段落对应1-3章的内容，按以下规则划分：

| 情节容量 | 对应章节数 | 适用场景 |
|---------|-----------|---------|
| 一个完整的小事件（起承转合完整） | 2-3章 | 重要冲突、转折事件 |
| 一个场景/对话/冲突 | 1章 | 普通推进章节 |
| 一个过渡/衔接 | 1章 | 卷间/幕间过渡 |

## 第二章：细纲内容规范

### 2.1 每段细纲必含内容

每个细纲段落必须包含以下信息：

```markdown
### 段落 V{X}-{Y}: {段落标题}

**对应章节**: 第{N}章 - 第{N+M}章
**核心事件**: [一句话概括本段发生的关键事件]
**情节定位**: [开端/发展/深化/高潮/结局/过渡]
**情绪目标**: [让读者感受到什么情绪]

**出场角色**:
- {角色名}: [在本段中的状态/作用]
- ...

**冲突类型**: [人vs人/人vs社会/人vs自然/人vs自我]
**冲突强度**: [低/中/高]

**关键事件链**:
1. [事件1描述]
2. [事件2描述]
3. ...

**伏笔操作**:
- 埋设: [伏笔内容] → 预期回收: [章节位置]
- 回收: [伏笔内容] ← 埋设位置: [章节位置]

**爽点/泪点/笑点**:
- [类型]: [具体内容]

**字数预估**: {N}字
```

### 2.2 细纲段落示例

```markdown
### 段落 V1-01: 废柴觉醒

**对应章节**: 第1章 - 第2章
**核心事件**: 主角在家族测试中觉醒废灵根，被家族抛弃后意外获得神秘传承
**情节定位**: 开端
**情绪目标**: 让读者感受到主角的憋屈和对未来的期待

**出场角色**:
- 林轩（主角）: 16岁，灵根测试结果为最低等的杂灵根，被族人嘲笑
- 林震天（家主）: 对主角失望，迫于长老压力将主角贬为外门
- 林雪（青梅）: 暗中关心主角，但不敢公开表态

**冲突类型**: 人vs社会（家族等级制度）
**冲突强度**: 中

**关键事件链**:
1. 家族灵根测试大会，主角被测出杂灵根
2. 族人嘲讽，长老提议将主角逐出家族
3. 家主迫于压力将主角贬为外门杂役
4. 主角独自在后山悲伤时，意外触发上古传承阵法
5. 传承告知主角：杂灵根实为万灵之体，可吞噬万物灵根成长

**伏笔操作**:
- 埋设: 长老林啸天为何极力主张驱逐主角 → 预期回收: 第2卷
- 埋设: 上古传承的来历和创造者 → 预期回收: 第5卷

**爽点**:
- 揭秘爽点: 杂灵根实为最强体质

**字数预估**: 6000字（2章，各3000字）
```

## 第三章：情节分布策略

### 3.1 卷内情节分布

每卷内部的情节分布遵循以下原则：

**开端段落（占本卷15-20%）**:
- 快速建立本卷的核心冲突
- 引入本卷的关键角色
- 设定本卷的情绪基调
- 建议1-3个细纲段落，对应2-6章

**发展段落（占本卷30-35%）**:
- 冲突逐步升级
- 角色在压力中成长
- 新信息和伏笔持续注入
- 建议3-5个细纲段落，对应6-12章

**深化段落（占本卷30-35%）**:
- 冲突达到高潮前的最高点
- 角色面临重大抉择
- 伏笔开始密集回收
- 建议3-5个细纲段落，对应6-12章

**高潮结局段落（占本卷15-20%）**:
- 卷内核心冲突解决
- 角色完成本卷成长目标
- 留下通往下卷的钩子
- 建议1-3个细纲段落，对应2-6章

### 3.2 节奏控制策略

| 节奏类型 | 连续出现上限 | 之后必须插入 |
|---------|------------|------------|
| 高强度战斗/冲突 | 不超过3章 | 舒缓/文戏章节 |
| 文戏/对话/情感 | 不超过3章 | 行动/冲突章节 |
| 过渡/铺垫 | 不超过2章 | 推进/高潮章节 |
| 连续高潮 | 不超过2章 | 缓冲/沉淀章节 |


### 4.2 输出要求

1. 细纲必须覆盖全书所有章节，不能有遗漏
2. 每个细纲段落必须标注字数预估，累计后与目标总字数核对
3. 章节分布必须合理，不能出现某卷只有1章或某卷超过100章等极端分布（除非剧情需要）
4. 细纲中的伏笔必须与伏笔追踪表对应
5. 细纲输出后需与大纲核对，确保不偏离主线
6. 如涉及多卷，每卷分别输出细纲
