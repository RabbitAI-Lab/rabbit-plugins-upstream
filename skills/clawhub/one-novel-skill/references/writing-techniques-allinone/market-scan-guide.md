## 二、番茄小说排行榜解析

### 2.1 番茄榜单体系

| 榜单类型 | 更新频率 | 核心算法 | 适用策略 |
|:---------|:---------|:---------|:---------|
| 飙升榜 | 每日 | 增速 | 新书测试期参考 |
| 热榜 | 每日 | 综合热度 | 主流题材判断 |
| 分类榜 | 每日 | 分类热度 | 细分赛道选择 |
| 新人榜 | 每周 | 新人效率 | 新作者入局参考 |

### 2.2 番茄数据解读

**热度公式**:
```
热度 = 在读人数 × 完读率 × 互动系数 + 新增读者
```

**健康度判断**:
| 完读率 | 健康度 | 说明 |
|:------|:------|:-----|
| > 30% | 优秀 | 节奏精准，钩子到位 |
| 15-30% | 良好 | 正常水平 |
| 5-15% | 预警 | 需要自查节奏 |
| < 5% | 危险 | 开篇/节奏问题严重 |

### 2.3 番茄扫榜流程

1. **打开番茄小说APP热榜**
2. **标记前30本书的**:
   - 题材分类
   - 标题模式 (关键词重复规律)
   - 简介结构 (是否包含爽点预告)
   - 封面风格 (漫画/真人/AI)
3. **抽取3本点开阅读**:
   - 前500字读完率判断
   - 章节结尾钩子设计
   - 爽点密度 (每章几个)
4. **记录**:
   - 热门题材TOP3
   - 标题关键词TOP5
   - 简介模板TOP2

## 三、起点中文网排行榜解析

### 3.1 起点榜单体系

| 榜单类型 | 权重 | 数据含义 |
|:---------|:----|:---------|
| 月票榜 | 最高 | 核心付费读者喜好 |
| 收藏榜 | 高 | 潜力作品筛选 |
| 畅销榜 | 高 | 商业价值判断 |
| 推荐票榜 | 中 | 读者主动投票 |
| 新书榜 | 中 | 新血发现 |

### 3.2 起点数据解读

**精品率判断**:
```
精品率 = 月票榜TOP100 / 总作品数 × 10000
```

**起点读者画像**:
- 年龄: 20-30岁为主
- 付费: 月均30-100元
- 忠诚: 同一作者追读率>40%
- 挑剔: 前3章决定追不追

### 3.3 起点扫榜方法

1. **月票榜TOP30分析**:
   - 题材分布 (都市/玄幻/仙侠占比)
   - 字数区间 (完本/连载)
   - 作者背景 (新/老/大神)
   - 更新频率 (日更/两天更)

2. **新书榜TOP20分析**:
   - 新题材趋势
   - 新作者突围路径
   - 开局策略差异

3. **分类冠军分析**:
   - 各分类TOP1的特征
   - 分类间的差距

### 3.4 起点数据指标解读

| 数据 | 优秀 | 正常 | 警示 |
|:----|:----|:----|:----|
| 追读率 | >25% | 10-25% | <10% |
| 收藏/字 | >0.5 | 0.1-0.5 | <0.1 |
| 月票/千读 | >5 | 1-5 | <1 |
| 推荐票/日 | >200 | 50-200 | <50 |

## 四、七猫排行榜解析

### 4.1 七猫榜单特点

| 特点 | 说明 |
|:----|:-----|
| 算法驱动 | 完读率权重高于起点 |
| 免费为主 | 广告收入模式 |
| 女频强势 | 女频作品数量多、热度高 |
| 新书友好 | 新人更容易获得推荐 |

### 4.2 七猫扫榜指标

| 指标 | 优秀 | 正常 | 警示 |
|:----|:----|:----|:----|
| 完读率 | >35% | 15-35% | <15% |
| 追读率 | >20% | 10-20% | <10% |
| 新增读者 | >1000/天 | 300-1000 | <300 |

### 4.3 七猫扫榜要点

1. **飙升榜 → 发现题材爆发点**
2. **热榜 → 确认主流题材**
3. **分类榜 → 细分赛道分析**
4. **关注完读率和追读率>30%的新书**

## 五、飞卢排行榜解析

### 5.1 飞卢榜单特点

- **同人为主**: IP衍生是主流
- **更新为王**: 日更量直接影响排名
- **短期爆发**: 新书前7天决定生死
- **标题党**: 标题直接影响点击率

### 5.2 飞卢扫榜方法

1. **同人榜 → IP热度判断** (动漫/游戏/小说)
2. **原创榜 → 新题材探索**
3. **热搜榜 → 实时热点捕捉**

### 5.3 飞卢关键数据

| 指标 | 说明 |
|:----|:-----|
| 收藏/天 | 新书期≥100为优秀 |
| 点击/天 | 直接关联推荐位 |
| 追读率 | ≥15%为正常 |
| 更新量 | 日更6000-10000字 |

## 六、跨平台对比分析

### 6.1 平台核心差异

| 维度 | 番茄 | 起点 | 七猫 | 飞卢 |
|:----|:----|:----|:----|:----|
| 主力读者 | 学生+新读者 | 白领+资深 | 女性+下沉 | 学生+二次元 |
| 核心模式 | 免费+广告 | 付费阅读 | 免费+广告 | 付费+同人 |
| 竞争门槛 | 低 | 高 | 中低 | 中 |
| 推荐周期 | 3-7天起量 | 1-3个月 | 1-2周 | 3-7天起量 |
| 字数要求 | 100-200章 | 200-500章 | 100-300章 | 100-300章 |

### 6.2 题材跨平台迁移

**从番茄到起点**: 节奏放慢、加入深度、增加付费钩
**从起点到番茄**: 节奏加快、减少铺垫、前500字加钩
**从七猫到番茄**: 男频策略共通、女频需要调整
**从番茄到飞卢**: 增加同人元素、标题更直白

## 七、扫榜数据分析工具

### 7.1 数据追踪表

```
┌────────┬────────┬────────┬────────┬────────┐
│ 日期   │ 平台   │ 题材1  │ 题材2  │ 题材3  │
├────────┼────────┼────────┼────────┼────────┤
│ 2026-07│ 番茄   │ 都市30%│ 玄幻25%│ 悬疑20%│
│ 2026-08│ 番茄   │ 都市28%│ 仙侠30%│ 悬疑18%│
└────────┴────────┴────────┴────────┴────────┘
```

### 7.2 趋势判断维度

1. **题材生命周期**:
   - 萌芽期: 出现但占比<5%
   - 增长期: 占比上升至5-15%
   - 成熟期: 占比15-30%
   - 衰退期: 占比持续下降

2. **竞争强度判断**:
   - 高竞争: 该题材占比>30%
   - 中竞争: 15-30%
   - 低竞争: 5-15%
   - 蓝海: <5%

### 7.3 数据解读警示

- ⚠️ 只看热榜容易陷入"幸存者偏差"
- ⚠️ 热门题材可能已饱和
- ⚠️ 榜单数据有3-7天滞后
- ⚠️ 排行榜不等于易创作
- ⚠️ 参考榜单但不盲从
