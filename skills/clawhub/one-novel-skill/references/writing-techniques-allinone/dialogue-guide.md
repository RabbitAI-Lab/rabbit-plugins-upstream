# 对话写作规范（殿堂金番版）

## 一、对话自然度标准

### 1.1 真实对话的特征
- 有犹豫词："呃……""那个……""就是说……"
- 有个性化停顿："这个嘛……""让我想想……"
- 有重复："我、我不是那个意思"
- 有打断："你听我说——""不，你先听我说！"
- 有省略："其实我……算了，不说了"

### 1.2 角色差异化对话
每个角色的说话方式必须有辨识度：
- **身份决定用词**: 贵族用雅词，平民用白话，学者用术语（但必须有案例支撑）
- **性格决定语气**: 直爽型说话短促有力，含蓄型说话迂回，暴躁型语气词多
- **情绪决定语速**: 愤怒时短句急促，悲伤时沉默迟疑，紧张时结巴重复
- **关系决定称呼**: 亲密用昵称，疏远用尊称，蔑视用外号

### 1.3 避免的对话问题
- **信息倾倒**: 不要通过对话一次性抛出大量设定
- **书面化**: "我对此深感遗憾" → "这事儿……唉，我真没想到会这样"
- **完美化**: 角色说话太流畅，像在念稿
- **同质化**: 所有角色说话方式一样

## 二、对话标签替换规则

### 2.1 推荐方式（按优先级）
1. **动作替代**（最推荐）：
   - "他点了根烟：'……'"
   - "她歪了歪头：'……'"
   - "他翻了个白眼：'……'"
   
2. **表情/神态替代**：
   - "他眉头皱起：'……'"
   - "她嘴角抽搐了一下：'……'"
   - "他脸色一沉：'……'"

3. **环境/动作交织**：
   - "茶杯在桌上轻轻磕了两下。'……'"
   - "窗外的雨声突然大了起来。'……'"

4. **省略标签**（通过上下文可判断时）：
   - "'你今天去哪了？'"
   - "'图书馆。'"（省略了"他说"）

### 2.2 减少使用的标签
- "XX说""XX道""XX问""XX答" — 尽量用动作/表情替代
- "XX怒吼道""XX咆哮道""XX哀嚎道" — 过于夸张
- "XX语重心长地说""XX饱含深情地说" — 过度修饰

### 2.3 标签位置
- **前标签**: "他说：'……'"（强调说话者）
- **中标签**: "'……'，他说，'……'"（分割长对话）
- **后标签**: "'……'，他说。"（对话先于说话者）
- **无标签**: 通过上下文判断说话者

## 三、对话情绪描写

### 3.1 情绪通过行动展现
- "我很生气" → "他猛地拍桌，茶杯跳起，茶水泼了一桌"
- "她很伤心" → "她转过身，肩膀微微颤抖"
- "他紧张" → "他攥了攥拳，手心全是汗"

### 3.2 情绪通过语气词展现
- 愤怒: "呵""哼""你——！"
- 悲伤: "……""唉""算了"
- 紧张: "呃""那个……""就是……"
- 惊喜: "啊！""真的？"
- 不屑: "切""呵""就这？"

### 3.3 情绪通过沉默展现
- 沉默本身也是一种回答
- 描写沉默中的细节：呼吸声、手指敲击声、远处的声音
- 沉默后接一个动作或环境变化

## 四、对话格式规范

1. 引号使用：中文全角引号 " "（或『』）
2. 每个说话者独立成段
3. 对话与动作描写在同一段时，动作在前
4. 多段对话属于同一人时，每段开头加前引号，末段结尾加后引号
5. 省略号（……）表示犹豫或中断
6. 破折号（——）**全文取消**，用省略号或逗号替代

## 五、对话自审清单

每段对话后自问：
- [ ] 这个角色会这样说话吗？（身份匹配）
- [ ] 这种情绪下会这样说话吗？（情绪匹配）
- [ ] 这段对话推进剧情了吗？
- [ ] 这段对话刻画角色了吗？
- [ ] 对话听起来像真人说话吗？（有犹豫/停顿/重复吗？）
- [ ] 对话标签合适吗？（是否用了动作替代？）
- [ ] 这段话会不会听起来像AI写的？（过于完美/流畅/书面化？）
