# 期待感技法 (参考 MuMuAINovel + chinese-novelist-skill)

## 一、读者期望值管理

### 1.1 痒的法则 (Itch Principle)
- 每章结尾必须是**新问题**而非旧答案
- 给读者一点满足，但留下更大的不满足
- 核心公式: 解决小问题 → 暴露大问题 → 解决 → 暴露更大

### 1.2 承诺-兑现周期
- 每一句"后面会用到"的描写都必须兑现
- 兑现周期: 小伏笔3-5章内回收，中伏笔10-20章，大伏笔50+章
- 如果设定被遗忘，读者会感到被欺骗

### 1.3 预期差管理
- 读者猜到A → 你给A+（在预期之上多给一点）
- 读者猜到A → 你给B（反转预期，但B要合理）
- 不要: 读者猜A → 你给出乎意料的C（不合逻辑的强行反转）

## 二、钩子系统

### 2.1 钩子类型
1. 信息钩子: "他到底是谁"（未知信息驱动）
2. 危机钩子: "他会被发现吗"（紧张感驱动）
3. 关系钩子: "他们会在一起吗"（情感驱动）
4. 能力钩子: "他能不能做到"（成长驱动）
5. 因果钩子: "这会带来什么后果"（连锁反应驱动）

### 2.2 钩子密度
- 番茄: 前300字1个钩子，每章至少2个
- 起点: 前1000字1个核心钩子，每章至少1个
- 每3-5章应该出现一次高强度钩子（读者必须追读）

## 三、反转设计

### 3.1 有效反转三要素
1. 铺垫够足（读者有预期的依据）
2. 反转够意外（超出读者常规推理）
3. 回看符合逻辑（反转后读者会觉得"原来如此"）

### 3.2 反转频率
- 番茄: 每3-5章一次小反转，10-15章一次中反转
- 起点: 每5-8章一次小反转，20-30章一次大反转

## 四、爽点制造

### 4.1 爽点层次
1. 初级: 打脸装逼（即时满足）
2. 中级: 实力碾压（掌控感）
3. 高级: 智取/逆转（智力满足）
4. 终极: 牺牲/代价（情感共鸣）

### 4.2 爽点间隔
- 番茄: 每章至少1个初级爽点
- 2500字内必须有一次情绪波动
- 不要连续3章没有爽点（弃坑信号）
