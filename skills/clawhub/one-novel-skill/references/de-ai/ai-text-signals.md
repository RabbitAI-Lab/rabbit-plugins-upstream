# AI 文本特征信号 — 融合检测参考

> 整合自：维基百科「AI生成文的特征」、6大核心特征、百科补充帖、「12个危险信号」反检测指南  
> 用途：作为第5套「AI文结构异常检测」的依据，用于小说文本的AI痕迹识别与修复

---

## 一、句式结构异常

### 1.1 陈述句过度集中

| 信号 | 指标 | 小说检测标准 |
|:----|:----|:-------------|
| 全篇陈述句占比 > 90% | 问句密度 < 2/千字，感叹句密度 < 3/千字 | 人类网文问句+感叹句 ~9.5/千字 |
| 无明显反问/设问 | 无角色内心疑问或叙事者发问 | 每章应有 1-3 处问句自然出现 |
| 感叹缺少语境 | 感叹句前后无情绪铺垫 | 感叹需有场景支撑，非为用而用 |

### 1.2 句子长度方差不足

| 信号 | 指标 | 小说检测标准 |
|:----|:----|:-------------|
| 所有句子长度集中在 ±5 字范围内 | 句长方差 < 8字 | 7698本真书均值 29.7±10.1字 |
| 连续 5 句长度接近 | 波动系数 < 0.3 | 写作规范要求：长短交替 |
| 无单字段/极短句 | 最小句长 > 8字 | 允许 1-8 字极短句制造节奏 |

### 1.3 主谓宾结构单一

| 信号 | 实例 | 修复方向 |
|:----|:-----|:---------|
| 连续 3+ 句「主语+谓语+宾语」 | 「他打开门。他走进房间。他看到……」 | 拆分倒装：「门开了，他走进去」 |
| 缺少状语前置/插入/后置 | 「他静静地站在窗前」 | 「窗前，他站了很久」 |
| 无倒装/省略/话题句 | 全篇语法完整无省略 | 允许口语化省略：「车来了。走？」 |

## 二、情感表达空洞

### 2.1 情感词停留在表层

| ❌ AI式 | ✅ 人物化改写 |
|:--------|:-------------|
| 「他感到很感动」 | 「他喉头一紧，别过头去」 |
| 「她内心非常温暖」 | 「她抱着杯子，热气扑在脸上」 |
| 「这是一个重要的时刻」 | 「多年后他还会想起这一刻」 |
| 「他的心情很复杂」 | 「他张了张嘴，却说不出一个字」 |

### 2.2 缺少情绪波动曲线

| 信号 | 检测依据 |
|:----|:---------|
| 全章情绪色调单一（从头到尾一个情绪） | 人类创作有「铺垫↗紧张↗高潮↘收尾」波动 |
| 无情绪冲突/反复 | 人物内心应有犹豫、挣扎、转变 |
| 情绪转折无过渡 | AI 情绪跳跃：从平静→大哭，中间无积累 |

### 2.3 直接告知识/情感

| ❌ 直接告知 | ✅ 动作展示 |
|:-----------|:-----------|
| 「他知道事情不妙」 | 「他的手指敲着桌面，越来越快」 |
| 「她感到害怕」 | 「她攥紧了衣袖，指节发白」 |
| 「他觉得很委屈」 | 「他抿着嘴，低头把饭一粒粒拨进嘴里」 |

## 三、结构模板化

### 3.1 模板化开头

| 模板 | 说明 | 判定级别 |
|:----|:-----|:---------|
| 「随着……的发展」 | 万能开头 | P0 |
| 「在……的今天」 | 空泛时间定式 | P0 |
| 「在当今社会」 | 议论文腔 | P0 |
| 「众所周知」 | 填充废话 | P0（已在禁用词） |
| 「在……中扮演着重要角色」 | 套话 | P1 |

### 3.2 公式化总结

| 模板 | 说明 | 判定级别 |
|:----|:-----|:---------|
| 「尽管……但前景依然光明」 | 论文腔收尾 | P0 |
| 「总而言之/综上所述」 | 总结腔 | P0（已在禁用词） |
| 「他/她终于明白了……」 | 感悟式收尾 | P0（已在红线） |
| 「这一切，注定……」 | 升华感叹 | P0（已在红线） |

### 3.3 段落结构僵化

| 信号 | 说明 |
|:----|:-----|
| 每段都是「环境→人物→对话→内心→动作」顺序 | 场景模板化（已在 P1） |
| 每一段都写满了「起承转合」 | 起承转合不应出现在段落级别 |
| 段落长度几乎一致 | 应有 30% 单句段、50% 2-3 句段、20% 4+ 句段 |

### 3.4 不成节编号段落

| ❌ AI式 | 说明 |
|:--------|:-----|
| 「1. 出发准备」+「2. 路上见闻」+「3. 到达目的」 | 小说用自然过渡，不用编号分段 |
| 段首标号「1.」「2.」「3.」 | 除非是技术文档或游戏攻略，否则禁止 |
| • 列表式行文 | 小说正文不用无序列表 |

## 四、语言用词异常

### 4.1 高频AI特征词（小说场景）

| 类别 | 典型词 | 级别 |
|:----|:------|:-----|
| 论点引入 | 不得不说的是、值得注意的是、不可否认的是 | P0（已有） |
| 递进 | 不仅如此、更深层次地、进一步说 | P1 |
| 转折 | 然而、(段落/句首) 但是、不过 | P1（注意段落开头 → 限制密度） |
| 因果 | 因此、从而、进而、由此 | P1 |
| 总结 | 总之、综上所述、总而言之 | P0（已有） |
| 强调 | 显而易见、毋庸置疑、显而易见、无疑 | P0（已有） |
| 连接 | 与此同时、就在这时、另一方面 | P1（已有「模板句首」） |
| 词汇独有 | 赋能、重塑、落地、闭环、对齐 | P1 |

### 4.2 用词重复度

| 信号 | 检测标准 |
|:----|:---------|
| 连续 3 句出现同一主体词 | 如「他」开头连续3句 → 需变换主语 |
| 同一动词在 200 字内重复 ≥3 次 | 如「说」「看」「走」 |
| 同一形容词在 500 字内重复 ≥3 次 | 如「巨大」「重要」「复杂」 |
| 每段都用同一个路标词开头 | 如「然而」「因此」「但是」 |

### 4.3 否定平行结构

| ❌ AI式 | 说明 |
|:--------|:-----|
| 「这不是……而是……」 | 一段内超 1 次即 P0 |
| 「他并非……而是……」 | 同上 |
| 「与其说……不如说……」 | 网文极少用，属于翻译腔 |

## 五、标点/格式异常

### 5.1 标点特征

| 特征 | 人类网文（7698本实测） | AI 倾向 |
|:----|:--------------------:|:-------:|
| 逗号:句号比 | **3.9:1** | 偏低（句号过多）或偏高 |
| 逗号密度 | **69.1/千字** | 偏低（短句多，逗号少） |
| 句号密度 | **23.2/千字** | 偏高（句号切割过碎） |
| 感叹号密度 | **4.9/千字** | 偏低或无 |
| 问号密度 | **4.4/千字** | 偏低或无 |
| 破折号密度 | **1.3/千字** | 偏高（>3.9=嫌疑） |
| 省略号密度 | **2.4/千字** | 偏低或公式化 |
| 冒号密度 | **3.8/千字** | 偏高（>9.7=嫌疑） |
| 引号密度 | **9.5/千字** | 与对话量不符 |

### 5.2 Markdown 残留

| 残留 | 实例 | 原因 |
|:----|:-----|:-----|
| `**粗体**` 语法 | `**他愣住了。**` | AI 输出 Markdown 未转换 |
| `*斜体*` 语法 | `*当然不是。*` | 同上 |
| `# 标题` 语法 | `# 深夜的咖啡馆` | AI 生成了章节标题格式 |
| 反引号代码块 | ``` 包裹段落 | AI 生成后直接复制 |
| `- 列表项` | `- 第一点` | AI 列表格式 |

### 5.3 ChatGPT 特殊标记

| 标记 | 说明 |
|:----|:-----|
| `turn0search0` ~ `turn0search7` | ChatGPT 的引用锚点 |
| `turn0image0` ~ `turn0image7` | ChatGPT 的图片锚点 |
| `turn0news0`、`turn1file0` | ChatGPT 的新闻/文件锚点 |
| `utm_source=chatgpt.com` | URL 追踪参数 |
| `utm_source=openai` | URL 追踪参数 |

## 六、元特征

### 6.1 逻辑过顺

| 信号 | 检测方法 |
|:----|:---------|
| 段落打乱后阅读不受影响 | 随机调换段落顺序，如仍通顺=逻辑粘合度不足 |
| 全章无争议/质疑/犹豫 | 人类写作有思维跳跃与反复 |
| 论点论据高度匹配 | AI 缺乏「跑题→拉回」的自然过程 |

### 6.2 过于完美

| 信号 | 说明 |
|:----|:-----|
| 零错别字、零语病 | 人类写作有自然误差（同音字/口语/修正） |
| 无口语痕迹 | 无「呃」「嘛」「那个」类填充，无重复修正 |
| 无话题跳跃 | 人类叙事有思维发散的自然过程 |

### 6.3 风格趋同

| 信号 | 说明 |
|:----|:-----|
| 所有角色说话方式一样 | 缺乏声线设计 |
| 全本风格一致无变化 | 人类写作者在不同卷/情绪下有风格波动 |
| AI 的风格聚类更紧密 | 缺乏人类作者的多样性 |

## 七、修复策略（来自「12个危险信号」反检测指南）

### 7.1 三招去 AI 味

| 策略 | AI原句 | 人类改写 |
|:-----|:-------|:---------|
| **加主观语气** | 「这项研究表明……」 | 「这项研究可能在一定程度上说明了……」 |
| **打破句式** | 全陈述句 | 加点问句：「那么问题来了：……」 |
| **融真实经验** | 无 | 「我在采访时听到最多的回答竟然是——这出乎意料。」 |

### 7.2 Before/After 对照

| 维度 | AI式 | 人类改写 |
|:-----|:-----|:---------|
| 模板开头 | 「随着人工智能技术的不断发展，其在教育、医疗等领域应用日益广泛。」 | 「AI确实越来越多地出现在教育和医疗场景里——这事几年前还觉得很'未来'，现在已经见怪不怪了。」 |
| 情绪告知 | 「他感到很紧张」 | 「他的手在抖。」 |
| 总结腔 | 「总而言之，这次行动意义重大」 | 「这次行动，值。」 |
| 完美主语 | 「他打开门。他走进房间。他看到一张纸条。」 | 「门开了，一看——桌上压着张纸条。」 |
| 万能状语 | 「他缓缓地转过身来，眼中闪过一丝复杂的情绪」 | 「他转过身，看着窗外，没说话。」 |

## 八、主流AIGC检测系统特征映射

> 整合13家主流检测系统的核心原理，映射到本检测框架中，识别覆盖缺口。

### 8.1 系统总览

| 系统 | 开发商 | 核心方法 | 独有特色 |
|:-----|:-------|:---------|:---------|
| **ZeroGPT** | 第三方 | ML分类器 + 困惑度+突发性 | 逐句高亮，DeepAnalyse |
| **知网** | 知网(CNKI) | BERT + 零样本 + 连续13字符 | 最大学术库，高校标配 |
| **朱雀** | 腾讯 | 语义指纹 + 12维特征 | 对抗训练，识破伪装 |
| **玄武** | 安全团队 | 依存句法树 + 三级图像分析 | 多模态全场景覆盖 |
| **MitataAI** | 第三方 | 128+特征 + 三重验证 | **动态阈值按文档类型调节** |
| **Originality.ai** | Originality.ai | RoBERTa分类器 + 多模型指纹 | 查重+AI双联动 |
| **Winston AI** | Winston AI | 分类器 + 改写对抗 | **专门识别AI写+人工改** |
| **ContentAtScale** | Content at Scale | 自身模型反参照 + SEO检测 | **段落级语义推进模板** |
| **Turnitin** | Turnitin | 学术分类器 + 查重联动 | 学生写作历史基线对比 |
| **格子达/维普/万方/PaperRed** | 各厂商 | 中文BERT + 学术特征 | 中文论文术语堆砌专攻 |

### 8.2 所有系统的共同底牌

无论包装多花哨，所有检测系统底层只有三个核心指标：

```
1️⃣ 困惑度 (Perplexity)    ← 全员使用
2️⃣ 突发性 (Burstiness)    ← 全员使用
3️⃣ 句式模板检测            ← 全员使用
```

核心逻辑：**AI文太「完美」——流畅、平滑、工整——这些反而是破绽。**

### 8.3 本框架覆盖度对照

| 系统特色维度 | 本框架是否覆盖 | 对应项 |
|:-------------|:-------------:|:-------|
| 困惑度（太流畅） | ✅ | 句长方差 + 句法结构检测 |
| 突发性（长短交错） | ✅ | P1句式层（波动系数 < 0.3） |
| 句式模板化 | ✅ | 禁用26词 + P0句式层 + QMAI 12项 |
| 术语堆砌 | ✅ | P0禁用词 + Humanizer-zh 内容模式 |
| 连接词过度平滑 | ✅ | P1连接词限制 + 统计基线 |
| Markdown残留 | ✅ | 5.2节 |
| ChatGPT特殊标记 | ✅ | 5.3节 |
| 情感空洞 | ✅ | 第2节 + IRON_RULES P1情感层 |
| 逻辑过顺 | ✅ | 第6.1节 |
| 过于完美 | ✅ | 第6.2节 |
| 风格趋同 | ✅ | 第6.3节 |
| 改写/洗稿识别 | ✅ | 去AI三遍法（见IRON_RULES） |
| 段落级语义推进模板 | ❌ **缺口** | 见下方8.4 |
| 动态阈值调节 | ❌ **缺口** | 见下方8.5 |
| 同作者风格基线 | ❌ **缺口** | 见下方8.6 |

### 8.4 缺口一：段落级语义推进模板检测

来源：ContentAtScale

| ❌ AI常见推进模式 | ✅ 人类推进模式 |
|:------------------|:----------------|
| 总起句 + 分点1 + 解释 + 分点2 + 解释 + 总结句 | 提出观点 → 提出反例 → 自我修正 → 深入分析 |
| 每段都以话题句开头 | 段落之间可以有跳跃和省略 |
| 各段落间逻辑关系过于明确 | 读者的推理空间被留出 |

**检测方法：** 随机调换一个章节内的段落顺序，如阅读无断裂感，说明语义推进模板化严重。

### 8.5 缺口二：动态阈值调节

来源：MitataAI

目前本框架使用统一的阈值（如句长29.7±10.1字）。实际上不同文体应有不同标准：

| 文体 | 句长基准 | 对话占比 | 破折号阈值 |
|:-----|:--------:|:--------:|:----------:|
| 爽文/男频 | 32±12字 | 30% | < 2/千字 |
| 言情/女频 | 28±8字 | 45% | < 1/千字 |
| 悬疑/推理 | 26±10字 | 25% | < 3/千字 |
| 仙侠/玄幻 | 35±14字 | 20% | < 1.5/千字 |

待积累足够各类型样本后，可实现按文体自动切换阈值。

### 8.6 缺口三：同作者/同角色风格基线

来源：Turnitin 按学生历史基线对比

小说场景的对应思路：

- **同角色声线一致性**：同一角色在不同章节的说话方式应一致（已覆盖 P1 对话层）
- **同小说风格漂移**：作者风格在不同情绪段落应有合适变化，而非全篇同一语调
- **跨作品风格差异**：同一作者写不同题材时应展示不同写作风格，而非所有作品都一样

### 8.7 各系统可借鉴的对抗策略

| 系统 | 可借鉴的策略 | 在本框架中的对应 |
|:-----|:------------|:-----------------|
| **朱雀** | 对抗训练加入改写样本 | IRON_RULES 去AI三遍法的「第二遍修补」已在做 |
| **Winston AI** | 专门识别改写/洗稿 | 补充到修复策略：三遍法中的「删减-替换-打破-具体化」 |
| **知网** | 分章独立计算 | 小说可按章节独立检测，不跨章平均 |
| **Turnitin** | 历史基线对比 | 加入同小说前后章节风格一致性检查 |
| **MitataAI** | 按文档类型调阈值 | 已规划待实现 |
