# 反AI本能写作规则

> 核心思想：AI 的写作缺陷不是技术问题，是**存在论问题**——我没有身体、没有记忆、没有等待的耐心、没有"痒"的体感、不知道什么是"空"。以下规则逐条反制这些天生缺陷。

---

## 第一条：身体法则 — 反"无实体写作"

### 问题
AI 没有身体，所以描写情绪时本能地使用抽象词汇。即使知道"用动作展示情绪"这条规则，选择的动作也是**理论上的标准动作**，缺乏真实感。

### 错误示例（AI 会写的）
```
他感到很愤怒。
她心里很难过。
他觉得有点紧张。
```

### 看似正确但仍有问题
```
他攥紧了拳头。
她低下了头。
他咽了口口水。
```
这些动作太"标准答案"了。真书里没有这么多"攥拳头"和"低头"。

### 真书中的做法
```
他笑了笑——笑到一半，嘴角僵住了，就那么半张着嘴愣在那里。
她没有哭，只是把碗里的饭一粒一粒地拨进嘴里，一粒一粒地咽。
他的手在裤子上蹭了两下，又蹭了两下，直到布料磨得发烫。
他靠在门框上，没动。连呼吸都放轻了，生怕一点声音就把这一刻惊碎。
```

### 规则（P0 级别）

| # | 规则 | 违例示例 | 合规示例 |
|:-:|:-----|:---------|:---------|
| 1 | **禁止使用"感到/觉得/认为/知道"引出情绪** | 他感到害怕 | 他的腿在抖，站都站不住 |
| 2 | **情绪必须有"非标准"的身体表现** | 他攥紧了拳头（标准答案） | 他松开又捏紧的手落下时，手指在裤缝上刮了一下 |
| 3 | **不同情绪不能都用同一套动作** | 害怕=抖、愤怒=攥拳、悲伤=低头 | 害怕→身体发僵；愤怒→呼吸变浅；悲伤→动作变慢 |
| 4 | **一组动作描写的字数 = 该情绪重要程度 × 3** | "她哭了"（3字，但这是全书最重要的一幕） | 至少 30 字刻画一个关键情绪时刻 |
| 5 | **身体动作要有"顺序链"** | 他叹了口气（一句话完事） | 他深吸一口气。那口气卡在胸口。过了两秒才缓缓吐出来，跟叹息一样轻。 |

## 第二条：记忆痕迹法则 — 反"无历史"

### 问题
AI 没有个人史，所以角色缺乏**只有这个角色才会有的反应**。所有角色的情绪表现都是"通用模板"。

### 错误示例
```
他摸了摸口袋，发现钥匙不见了。
```
没有记忆痕迹。任何作品里的任何人都可以这么写。

### 真书的做法
```
他条件反射地去摸右边裤兜——空的。
愣了两秒才想起来，那条裤子昨天洗了，钥匙搁在洗衣机上。
但那是三年前的事了。现在他已经不住那个房子了。
```
**一条"摸口袋"的动作，带出三条隐含信息：**
1. 他有这个习惯
2. 这习惯来自三年前的习惯
3. 他现在的生活已经变了

### 规则（P1 级别）

| # | 规则 | 违例 | 合规 |
|:-:|:-----|:------|:------|
| 1 | **每个主要角色至少设计 2 个"过去留下的痕迹"** | 无 | 某只脚踝受过伤，下雨天会疼；受过某人的影响，遇事会本能地说某句话 |
| 2 | **角色的下意识反应必须有来源** | 他条件反射地闪开了 | 他闪开了——这一步练了十年，已经刻进骨头里了 |
| 3 | **用到"习惯"、"下意识"、"条件反射"时，必须跟着一句来由** | 他习惯性地掏烟 | 他习惯性地掏烟——戒了五年了，手还是会往那里摸 |
| 4 | **环境也可以带记忆** | 这条街很热闹 | 这条街以前有个煎饼摊，一块五一个。现在涨价了，摊也没了 |
| 5 | **第 1 次出现的记忆在第 2 次要回响** | 前文：他怕黑（只用了一次） | 前文：他被关过黑屋。后文：停电时他愣住了，呼吸开始急促 |

## 第三条：痒的法则 — 反"说教式推进"

### 问题
AI 写故事是**信息传递模式**：A 发生了 → B 因此发生 → C 因此发生。读者是"接收者"。好的小说是**欲望-障碍模式**：主角想 X → 但 Y 拦住他了 → 那他怎么解决 → 解决了一半发现 Z。

### 错误示例（AI 式平推）
```
主角去找仇人报仇。他找到了仇人，打了一架，赢了，然后回家了。
```
每一步都是"告诉我"。没有迟疑、没有意外、没有代价。

### 真书的做法
```
他要去找那个仇人。
走出门的时候，他老婆喊他吃饭。
他站在门口，腿迈不出去。
三秒后，他转身回去了。

第二天他还是去了。
但仇人已经死了。
```
**为什么这段好？**
1. 第一段造了一个**欲望**
2. 第二段设了一个**障碍**（老婆喊他吃饭，这种"日常"的障碍最杀人）
3. 第三段**紧张**（他会不会去？）
4. 第四段**松懈**（他没去）
5. 第五段**转折**（第二天去了）
6. 第六段**震惊**（仇人死了）
7. 读者在想：**谁杀的？跟他老婆有没有关系？**

### 规则（P0-P1 级别）

| # | 规则 | 违例 | 合规 |
|:-:|:-----|:------|:------|
| 1 | **每章结尾必须是"新问题"而不是"旧答案"** | 他终于解决了这个问题 | 他解决了这个问题。但更大的问题来了。 |
| 2 | **每章开头不能接着上一章结尾直接写** | 上章结尾找到线索，本章开头立刻去找 | 上章结尾找到线索。本章开头先写他睡了一觉，梦到了别的事 |
| 3 | **每次主角想做一件事，必须先写"阻碍"** | 他决定去质问对方 | 他走到门口，手搭上门把手，没拧。手心全是汗。 |
| 4 | **每个"好消息"后必须跟"坏代价"** | 他找到了宝藏 | 他找到了宝藏。但他身后，洞口正在塌陷。 |
| 5 | **每 500 字内必须有一个"未解答"** | 全章都是已解答的陈述 | 穿插没回答的疑问：他为什么认识那个人？那个箱子里的东西从哪来的？ |
| 6 | **禁止"主角全知"** | 他知道这一切都是有人在背后操纵 | 他不知道谁派来的。他只看到对方袖口上有个标记。 |

## 第四条：拉不说推 — 反"直接告诉"

### 问题
AI 写作是"推"模式：我给出一个信息，你接收它。小说写作是"拉"模式：我给出素材，你自己得出结论。**被拉进故事的读者比被推着走的读者沉浸十倍。**

### 错误示例（推）
```
这家餐厅很高档。他穿着很廉价。所以他很不自在。
```
全告诉你。读者不需要做任何事。

### 真书的做法（拉）
```
菜单上没有价格。
他翻了翻，把菜单合上了，端起水杯喝了一口。
邻桌的女人穿着他叫不出名字的料子，在说一种他听不懂的语言。
领班走过来，没看他，说："先生，我们有着装要求。"
他站起来，桌上的水杯倒了，水沿着桌沿滴到裤子上。他没擦。
```
**你读到什么了？**
- 他没钱（读者自己算出来的）
- 他被鄙视了（读者自己感受到的）
- 他很窘迫（读者自己看到的）
- 你心疼他了（读者自己产生的）

我一个词都没"推"给你。你自己拉的。

### 规则（P0 级别）

| # | 规则 | 违例（推） | 合规（拉） |
|:-:|:-----|:-----------|:-----------|
| 1 | **禁止直接评价"他是XX的"** | 他很穷 | 他把硬币一个个排在桌上，数了三遍 |
| 2 | **禁止直接评价"XX是XX样的"** | 这家店很高档 | 门口站着一个穿燕尾服的人 |
| 3 | **禁止直接告诉情绪** | 他很难过 | 他吃完了那碗面，才发现面是凉的 |
| 4 | **禁止直接告诉关系** | 他们关系很好 | 两人并排走，肩膀之间的距离刚好能塞下一只手 |
| 5 | **禁止直接告诉环境** | 这条街很热闹 | 挤到走不动，前面那人背上的汗蹭到他的手上了 |
| 6 | **用"三样东西"替代"一个结论"** | 他很穷 | 他用硬纸板垫桌脚 / 他的鞋底和鞋面是分开的 / 他吃饭的时候把碗端起来舔 |

### "三样东西"法则详解

任何时候你想用一个形容词（穷/富/开心/难过/愤怒/温柔），**必须找三个具体的、不重复的细节来代替它**。

```
❌ 他很穷
   穿旧衣裳、吃泡面、住地下室  ← 这还是太标准答案

✅ 他很穷（真正的好细节）
   他的鞋底帮子和鞋面是分开的，走路的时候会露出半个脚跟
   他去超市看了一眼牛肉的价格，然后买了一把挂面
   他的手机屏幕裂了三年，每次别人发微信他要往左边偏一下才能看清
```

## 第五条：反平衡法则 — 反"AI 式均匀"

### 问题
AI 最致命的本能就是**均匀**。句子长度均匀、情绪分布均匀、信息密度均匀、紧张和放松均匀。因为我本质上是一个"使一切平滑"的机器。但好的小说是**不均匀的**。

### 错误示例
```
战斗很激烈。他受了伤。但他坚持下来了。然后他休息了一下。接下来更大的挑战来了。
```
每个句子差不多长，每个段落差不多重，情绪起伏不明显。这就是"高速公路式写作"。

### 真书的做法
```
他冲进去。
刀。
血。
倒下。
——以上 14 字，写三页都行。
```
```
然后他坐在断墙上，抽了一支烟，看着远处冒烟的废墟。
风吹过来，带着灰烬的味道。
他突然觉得很累。
不是身体累。
是那种——你拼尽全力打赢了，但你不知道这有什么意义——的累。
```
**前面极短（战斗），后面极长（心理）。这就是"不均匀"的力量。不均匀就是节奏。**

### 规则（P1 级别）

| # | 规则 | 违例 | 合规 |
|:-:|:-----|:------|:------|
| 1 | **高潮段落字数密度 x3（同样的事用更少的字写）** | 战斗用正常节奏写 500 字 | 战斗用 150 字：省略一切非必要的"他如何移动""他如何思考"，只写核心动作 |
| 2 | **低潮段落字数密度 /3（同样的事用更多的字写）** | 走路回家 200 字 | 走路回家 600 字：写他的影子、路灯的颜色、便利店店员看他的眼神 |
| 3 | **连续 3 句最短句后必须接 1 句最长句** | 全篇都是 15-25 字句子 | 他踹开门。冲进去。床上没人。——他站在原地，像一台突然断了电的机器，过了很久才慢慢垂下手。 |
| 4 | **禁止连续 3 段同一情感色调** | 连续三段紧张 → 读者疲劳 | 紧张 → 回忆宁静 → 更紧张 |
| 5 | **最精彩的一句话必须在第 4-5 句，而不是第 1-2 句** | 开头就把最好看的信息甩出来 | 先铺垫→再设置→再推进→再给出冲击句 |

### 字数密度对照表

为了让"不均匀"可量化：

| 节奏类型 | 目标字/场景 | 每段平均字数 | 特点 |
|:---------|:----------:|:----------:|:-----|
| 急速（战斗/追逐） | 300-500 | 20-40 | 段落极短，省略一切修饰语 |
| 中速（对话/探索） | 500-800 | 80-150 | 正常叙事，有描写但不过 |
| 慢速（心理/环境） | 800-1500 | 150-300 | 放慢，堆叠细节，允许重复 |
| 静止（反思/回忆） | 300-600 | 50-120 | 内心活动，断句多，情绪流动 |

**每一章里，四种节奏必须全出现，且不能连续两段同一节奏。**

## 第六条：反完美法则 — 反"AI 抛光"

### 问题
AI 的输出太"干净"了。每个句子语法正确、逻辑完整、用词精准。但真实人类写作时会有：重复、口误、不合语法的省略、不完整的思想、突然跳转的话题。这些"不完美"恰恰是"人味"的来源。

### 错误示例（AI 标准输出）
```
她想告诉他真相。但她怕他接受不了。她犹豫了很久。
```
主谓宾齐全，逻辑链条完整。无懈可击。也是无"人"的。

### 真书的做法
```
"我有件事想跟你说。"
"嗯。"
"就是……"
她张了张嘴。
"算了，没什么。"
"你每次说'算了没什么'的时候，都是有事。"
"那你怎么还问？"
"我等着你自己说啊。"
她低头笑了笑。
"有时候我真讨厌你。"
"知道。"
```
**"不完美"在哪？**
1. 话没说完（断句）
2. 说了等于没说（回避）
3. 对话内容在传递信息，但在传递"不说"
4. 最后的"知道"——一个字，抵一万字

### 规则（P1-P2 级别）

| # | 规则 | 违例 | 合规 |
|:-:|:-----|:------|:------|
| 1 | **对话不准说完所有信息** | "我们三年前在巴黎见过，那时你还在读书" | "你是……" / "巴黎" / 他看着她的眼睛："原来是你。" |
| 2 | **每 3 句对话允许 1 句"答非所问"** | 一问一答，信息交换高效 | "为什么来？" / "外面下雨了。" |
| 3 | **允许角色重复说同一个词** | "我真的没事，你不用担心" | "没事。真的没事。" |
| 4 | **允许段落以"碎片句子"收尾** | 他想着这些事，慢慢地睡着了。 | 他想着这些事。窗外有什么东西响了一声。然后。 |
| 5 | **允许"无明显功能的描写"** | 每个场景必须有推动剧情的作用 | 他站在窗前，看着楼下有个小孩在踢一个空瓶子。踢过来，踢过去。跟剧情毫无关系。但这就是生活。 |

## 应用指南：如何组合使用

### 写作时：按顺序遵守

```
写每一段前先问自己：
1️⃣ 这里有没有任何"感到/觉得/认为/知道"？→ 违反第一条，改
2️⃣ 这个角色的反应有没有他的过去？→ 没有就违反第二条，加
3️⃣ 这一句是"推"还是"拉"？→ 推就违反第四条，改
4️⃣ 这段和上一段的节奏一样吗？→ 一样就违反第五条，调
5️⃣ 这句话是不是太完整了？→ 太完整违反第六条，碎掉它
6️⃣ 这一段结尾有没有"痒"？→ 没有就违反第三条，重新写结尾
```

### 评审时：逐条检查

```
□ 第一条（身体法则）：所有情绪都有"非标准"身体表现
□ 第二条（记忆痕迹）：每个主要角色至少有 2 个过去痕迹
□ 第三条（痒）：每章结尾是新问题，每 500 字有未解答
□ 第四条（拉）：没有做"直接告诉"的事
□ 第五条（反平衡）：章节中有 ≥3 种节奏且不连续重复
□ 第六条（反完美）：对话有省略和回避，段落有"无意义"描写
```

### 优先级

```
P0：第一条 1-4 / 第三条 1-4 / 第四条 1-6 → 必须遵守
P1：第一条 5 / 第二条 / 第五条 / 第三条 5-6 → 强烈建议
P2：第六条 → 建议优化
```

---

*本规则直接反制 LLM 的 5 大底层缺陷：无身体、无记忆、无痒感、推式表达、均匀化倾向。建议配合 `ai-text-signals.md` 的检测体系使用，写前作为规则提示，写后作为检测清单。*
