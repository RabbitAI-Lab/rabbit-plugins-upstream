## 核心原则（融入 L3 的7招对抗prompt）

### 原则1：改味优先，不改错
AI味不是语法错误，是风格问题。去AI味的本质是把文字从过度工整拉回具体、自然、可读。
融入位置：L3第①招 对抗prompt 的约束清单中补充"非语法纠错，内容保真"。

### 原则2：改最少，效果最大
去AI味不等于重写。能改一个词就不改一句，能删一句就不重写一段。没有问题的句子保留原句。
**过度去AI味保护**：
- 不得整段删除正文内容
- 删除后破坏情节连贯性 → 改为"降AI重写"
- 删除比例上限分级：轻度≤15%，中度≤25%，重度≤35%
- 疑似AI味但不确定 → `[需复核]` 标记，不删除
- 字符差算法：每300字窗口按字符差/总字数计算删除比例

### 原则3：保留创作意图
只改"怎么说"，不改"说什么"。剧情、人设、情节走向一概不动。

### 原则4：保留有功能的语气
质问里的"？"、爆发峰值的少量"！"可以保留，不用全部清除。
`……`/`——` 清理后用动作/短句/换行替代，不做机械替换。

## AI味等级判定（融入检测输出）

| 等级 | 条件 | 删除上限 | 操作 |
|:----|:------|:--------|:-----|
| 🟢 自然 | 无禁用词命中, 段落方差正常, 对话标签率<40% | - | 直接通过 |
| 🟡 轻度AI味 | 1-2项轻微触发 | ≤15% | 修Top 3问题 |
| 🟠 中度AI味 | 3-4项触发含1项核心 | ≤25% | 逐项修复后重检 |
| 🔴 重度AI味 | 5+项触发含2项核心 | ≤35% | 分段重写+重跑全检 |

## 3阶段改写协议（融入Pipeline）

```
Phase 1: AI味扫描 → 标记位置 + 分类 + 等级评估
Phase 2: 分析定策 → 确定删除比例 + 保留项 + 替换方案
Phase 3: 逐级改写 → 按轻→中→重逐段修正，完成后回检
```

## 自然文本vs AI味对照表

| 维度 | 自然文本 | AI味文本 |
|:----|:---------|:---------|
| 段落长度 | 1-3句为主，偶尔1句独占1行 | 每段4-6句，整齐均匀 |
| 对话标签 | 60%+无标签，用动作替代"说" | 几乎每句"说道/问道" |
| 情绪表达 | 动作展示（"手在抖"） | 直接告诉（"很紧张"） |
| 比喻 | 生活化（"像哈士奇护食"） | 文学化（"如寒冰般"） |
| 语气词 | "嘤""嘶""靠""行吧" | 几乎没有 |
| 省略 | 大量省略，读者自己脑补 | 面面俱到，生怕读者不懂 |
| 排比 | 偶尔1-2个，从不连续3+ | 连续3+排比是标配 |
| 章末结尾 | 动作/对话收尾 | 总结/升华/感慨收尾 |
