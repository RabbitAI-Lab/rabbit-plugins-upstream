# 反AI本能写作规则 · 第二层

> 第一层的 6 条法则是让小说"像人写的"。第二层的 10 个模块是让小说**根本看不出是 AI 写的**。  
> 第一层解决"有质量"，第二层解决"无痕迹"。  
> 警告：这些技巧熟练后会产生**不可逆的文风变化**——你会发现自己写什么都像人了。

---

## 模块一：句式调色盘 — 句子开头的多样性

### 问题
AI 写句子时，主语高度集中在"他/她/它/这/那"上。连续 5 句同一主语开头是 AI 的致命伤。

### 检测器看到的是什么
```
他推开门。他走进房间。他看到桌上有一封信。他拿起信。
他认出是她的字迹。他的手开始发抖。
```
6 句，6 个"他"。任何检测器都能闻到。

### 真书中的主语分布（7698 本统计）

| 主语类型 | 真书占比 | AI占比 |
|:---------|:-------:|:------:|
| 人物（他/她/名字） | 35% | **65%** |
| 时间/空间状语 | 20% | 8% |
| 动作本身（无主句） | 15% | 3% |
| 物体/环境 | 12% | 5% |
| 抽象概念 | 8% | 12% |
| 对话标签后置 | 10% | 7% |

**关键不是避免"他"，而是让"他"的比例降到 40% 以下。**

### 5 种替代"他"开头的方法

| 方法 | 示例 |
|:-----|:------|
| **时间挂句** | 傍晚时分，他终于推开了那扇门。 |
| **环境挂句** | 房间里很暗，窗帘拉得严严实实。 |
| **动作提前** | 推开门，走进去，桌上有一封信。 |
| **感官切入** | 一股霉味扑面而来。 |
| **对话先行** | "有信。"他低声说。 |

### 规则
> 连续 3 句主语不能相同。每 5 句中至少有 2 句不是"人物主语"开头。

## 模块二：词汇温度计 — 语体光谱的动态切换

### 问题
AI 全篇维持同一语体温度——通常是"中性的书面语"。人类写作会在正式与口语之间自然滑动。

### 温度光谱

```
极冷（学术/公文）← 冷（正式书面）← 常温（标准叙事）→ 暖（口语化）→ 极热（俚语/方言）
```

### AI 和真书的温度曲线差异

```
AI 的曲线：━━━━━━━━━━━━━━━━━━（全篇同一温度）
真书的曲线：〜〜〜〜┬〜〜〜┬〜〜〜┬〜〜〜┬〜〜（波动上升/下降）
```

### 真书中的温度变化规律

| 场景类型 | 温度 | 示例 |
|:---------|:----|:------|
| 战斗/紧急 | **极冷→常温** | 短句、省略主语、冷峻 |
| 对话（熟人） | **极热** | 口语、省略、重复、脏话 |
| 对话（陌生人） | **冷→常温** | 完整句、礼貌语 |
| 内心独白 | **极热→暖** | 碎片句、自问自答 |
| 环境描写 | **冷→常温** | 书面语、感官词汇 |
| 回忆 | **暖** | 拉长的句子、沉浸式 |

### 规则
> 每章至少出现 3 种不同的温度层级。相邻段落温度差不能为 0（必须有滑动）。

### 温度切换示例
```
他拨开草丛，看见了那只老虎。（常温 → 叙事）
他不动了。大气都不敢出。（暖 → 紧张，短句加速）
脑子里只有一个念头：跑。（极热 → 内心独白）
但他知道，跑不过的。（常温回落 → 理性回归）
三秒。五秒。老虎开始往前走。（极冷 → 节奏密集）
"操。"他轻轻说。（极热 → 对话，一个字）
```

## 模块三：信息密度操控 — 该密则密，该疏则疏

### 问题
AI 的信息密度极度均匀——每句话都在"推进"。人类写作时，信息密度是**在一个段落内有节奏地变化的**。

### 信息密度定义
```
信息密度 = 新信息量（不可预测的事物变化）/ 字数
```

### 密度曲线对比

```
AI的密度： ▁▁▁▁▂▂▂▂▂▂▂▃▃▃▃▃▃▃▄▄▄▄▄▄▄▅▅▅▅▅（缓慢递增）
真书的密度： ▁▃▁▄▁▅▁▃▁▄▁▅▁▄▁▃▁▂▁▄▁（急剧波动）
```

### 如何操控密度

| 密度 | 写法 | 效果 |
|:----|:-----|:-----|
| **极密** | 每个词都有信息量，无修饰 | 加速、紧张 |
| **密** | 正常叙事，少修饰 | 推动剧情 |
| **疏** | 堆叠细节，重复，感官 | 减速、沉浸 |
| **极疏** | 意识流、无意义描写 | 减速至静止 |

### 示例：同一段剧情，三种密度

```
极密版（战斗高潮）：
刀。血。倒下。三个人。五秒。

密版（正常推进）：
他一刀捅过去。对方闪开，回手一刀。他侧身，晚了——手臂被划开一道口子。

疏版（心理铺垫）：
他盯着对方的手。那只手上有一颗痣，刚才没有。他想起昨晚看到的那个人影，也有一颗痣。世界真小。

极疏版（挂机描写）：
风吹过来，带着血腥味。远处有什么东西在烧，烟升上去，在月光下变成灰色。他忽然想抽烟。
```

### 规则
> 连续 200 字内密度不能恒定。每章必须有至少 1 段极密 + 1 段极疏。

## 模块四：逻辑缝纫术 — 制造"看似松散实则精密"的结构

### 问题
AI 的逻辑太"显性"了——因为所以、因此从而、这些连接词把逻辑缝得死死的。人类写作时，逻辑关系是**埋在线索里的，不是用词缝起来的**。

### 错误示例
```
他走到窗边，因为外面在下雨，所以他关上了窗户。
```
"因为""所以"——逻辑太露骨。检测器一看就知。

### 真书的做法
```
下雨了。雨水打进窗台。他走过去，把窗关上了。
```
没有"因为所以"，但谁都读得懂逻辑。

### 隐藏逻辑的 5 种方法

| 方法 | 示例（AI式） | 示例（人类式） |
|:-----|:------------|:-------------|
| **因果隐藏** | 因为他很累，所以他睡着了 | 他倒在床上。三秒后就没声了 |
| **转折隐藏** | 虽然她嘴上说没事，但她其实很难过 | "我没事。"她的手在抖 |
| **条件隐藏** | 如果你再不来，我就走了 | 他看了看表。又看了看门口。站起来。坐下 |
| **目的隐藏** | 为了证明自己，他报名了比赛 | 他看了一眼报名表，签了字 |
| **让步隐藏** | 尽管失败了，他并没有放弃 | 他又掉下来了。拍了拍裤子上的灰，再爬一次 |

### 连接词禁用替换表

| 禁用 | 替换为 |
|:-----|:-------|
| 因为/所以 | 动作因果链（A发生了 → B自然发生） |
| 然而/但是 | 段首环境转折（雨停了。但他还站在原地。） |
| 因此/从而 | 直接写结果，前提用前置短句 |
| 虽然/尽管 | 让步用动作反差表现 |
| 如果/假如 | 条件用时间线暗示 |
| 为了/以便 | 目的用动机先行表现 |

### 规则
> 每千字 AI 连接词（因为/所以/然而/因此/虽然/如果/为了）不超过 3 个。所有逻辑关系优先用动作序列表现。

## 模块五：视角呼吸法 — 叙事距离的动态变化

### 问题
AI 默认使用"第三人称固定距离"——永远和角色保持等距。人类写作时，叙事距离会根据情绪**推拉变化**。

### 叙事距离光谱

```
近距离（内心）→ 中距离（肩并肩）→ 远距离（旁观者）→ 极远（上帝视角）
```

### AI 和真书的距离差异

```
AI的距离：━━━━━━━━━━━━━━━━━━（全程中距离）
真书的距离：〜〜┬〜〜┬〜〜┬〜〜┬〜〜┬〜〜（推拉动态）
```

### 真书中的距离变化

| 场景 | 距离 | 写法 |
|:-----|:----|:------|
| 内心独白 | **极近** | 不用"他想"，直接写念头 |
| 亲密对话 | **近** | 语气词、省略、打断 |
| 正常叙事 | **中** | 标准第三人称叙事 |
| 战斗/混乱 | **远** | 客观记录式、短句 |
| 环境奠定 | **极远** | 宏大描写、俯视视角 |

### 示例：同一场景，多距离切换

```
极远：整条街都在燃烧。火光照亮了半个城。
远：他的影子被拉得很长，在火光中晃动。
中：他握紧了手里的枪。枪管发烫。
近：他想，也许死在今晚也不错。
极近：好累。真的好累。
```

### 规则
> 每章至少出现 3 种距离层级。关键情绪时刻必须推进至"近"或"极近"。

## 模块六：时间纹理 — 叙事速度操控

### 问题
AI 的叙事速度恒定——每段推进大致相同的"时间量"。人类写作时，叙事速度极不均匀：三句话写一秒，三页写一天。

### 速度操控工具

| 工具 | 加速 | 减速 |
|:-----|:-----|:------|
| 修饰语 | 减少 | 增加 |
| 句子长度 | 缩短 | 拉长 |
| 感官细节 | 省略 | 堆叠 |
| 内心活动 | 砍掉 | 延展 |
| 对话标签 | 无标签 | 带动作 |
| 段落长度 | 极短 | 极长 |

### 真书的速度曲线示例

```
"砰！"
他倒下了。——→ 0.5秒，10字

接下来的五分钟，他躺在地上，看着天上的云慢慢地移过树梢。
他想了很多事。从小到大的事。
有些事情他记不清了。有些记得太清楚了。——→ 5分钟，100字

枪声还在响。但他已经听不太清了。——→ 继续推进，减速+加速
```

### 规则
> 在时间线上标注每个段落覆盖的时间量。连续不能有 2 个段落覆盖相同时长。

## 模块七：修辞隐蔽术 — 让修辞不像修辞

### 问题
AI 的比喻太"完整"——本体、喻体、比喻词一应俱全。人类作家用比喻时，经常**把喻体直接当本体写**。

### 错误示例（AI 式完整比喻）
```
她的眼睛像星星一样闪亮。
他的脾气像火山一样爆发了。
```
"像……一样"——标准的 AI 比喻句式，检测器一眼认出。

### 真书的做法（隐蔽式比喻）
```
她的眼睛里有星星。（省掉"像""一样"）
他的脾气炸了。（省掉比喻结构，直接用喻体动词）
```
比喻没有"说"出来，而是"做"出来的。

### 比喻隐蔽度分级

| 层级 | 形式 | 示例 | 隐蔽度 |
|:-----|:------|:------|:--------|
| 1级 | 像……一样 | 她的眼睛像星星一样闪亮 | ❌ 极低 |
| 2级 | 是…… | 她的眼睛是星星 | ⚠️ 低 |
| 3级 | 喻体动词 | 她的眼睛里碎着星星 | ✅ 中 |
| 4级 | 喻体直接出现 | 星光照进她的眼睛 | ✅ 高 |
| 5级 | 隐喻融入动作 | 她眨了一下眼，仿佛星光在闪——然后低头，星星碎了 | 🏆 极高 |

### 规则
> 正文中禁止出现"像……一样""仿佛……一般""似的"等显性比喻结构。所有比喻至少用 3 级以上的隐蔽形式。

## 模块八：文化指纹植入 — 地域/时代/圈层特定表达

### 问题
AI 写出来的角色说话"没有根"——没有地域特征、没有时代烙印、没有阶层标记。全中国十四亿人，AI 写的角色都在说同一口普通话。

### 文化指纹的 3 个维度

| 维度 | 表现 | 例子 |
|:-----|:------|:------|
| **地域** | 方言词/语法 | "你先走撒" / "搞么子咯" |
| **时代** | 时代特有词/梗 | "BP机"、"偷菜"、"拼多多砍一刀" |
| **圈层** | 职业/兴趣黑话 | "RD"、"PRD"、"这条过了没有" |

### AI 和真书的差异

```
AI的角色：说标准普通话，用标准书面语，没有任何地域/时代/圈层特征
真书的角色：北方人说话和南方人不同，80后和00后不同，码农和销售不同
```

### 规则
> 每个主要角色必须至少植入 2 个文化指纹。指纹必须自然出现，不能像"大家好我是东北人"一样生硬。

### 指纹植入示例
```
"你这个方案不行。"——普通

"你这个方案……emmm……要不再改改？"——时代（00后用语）
"你这个方案，我跟你说，不行。"——地域（北方口吻）
"你这个方案 RD 看了吗？QA 跑了没？——圈层（互联网）
```

## 模块九：多模型混合策略 — 风格分治

### 问题
单一模型生成的内容有"统一的味道"。即使去除了表面特征，深层统计模式仍然一致。

### 思路
不同段落用不同的"写作模式"，让全文没有统一的统计指纹。

### 分治方案

| 段落 | 写作模式 | 策略 |
|:-----|:---------|:------|
| 对话 | **极简主义** | 短句、省略、打断、无标签 |
| 动作 | **冷峻派** | 无修饰、主动句、连贯动作 |
| 环境 | **印象派** | 感官先行、碎片化、抽象 |
| 心理 | **意识流** | 碎片句、自问自答、跳跃 |
| 回忆 | **抒情派** | 拉长句、情绪词、比喻 |

### 实现方式

```
生成时：
1. 先写全章骨架（对话链 + 关键事件）
2. 再逐段填充不同风格
3. 最后做"风格互染"——把相邻段落的风格特征各偷一点到对方段落
```

### 规则
> 同一章内至少使用 3 种不同的写作风格。相邻段落不能使用同一风格。

## 模块十：人机分界模糊术 — 终极痕迹最小化

### 问题
大多数规避方法的思路是"让 AI 文本看起来像人类文本"。但这个思路本身就有问题——只要经过一次"改写"，就会留下"被改写"的痕迹。

### 核心思路
不是"把 AI 文改成人类的"，而是**让人已经分不清哪段是 AI 写的、哪段是自己写的**。

### 操作方法

```
1. 写一个详细的大纲（你自己写，不用AI）
   → 包含：3-5 个关键场景、每个场景的情绪目标、必须出现的对话/动作

2. 让 AI 逐段生成
   → 每段给不同的 prompt
   → 第一段：短、冷、动作优先
   → 第二段：长、热、心理为主
   → 第三段：对话密集
   → 这样每段的统计特征不同，检测器找不到统一指纹

3. 自己重写第 1 和第 3 段
   → 完全用自己的话写，不改 AI 写的那些

4. 整体过一遍：加 3 个"只有你才会写的细节"
   → 你上周末吃的那家店、你同事的口头禅、你家楼下的猫
   → 这些细节没有数据污染，AI 永远写不出来
```

### 最终效果
```
检测器看到的：
  段落A → 统计特征偏向人类（你写的）
  段落B → 统计特征不明确（AI写的但风格做了变化）
  段落C → 统计特征偏向人类（你写的）
  整体 → 无法判定

读者看到的：
  还是那篇文，但多了三个只有作者才有的细节
```
