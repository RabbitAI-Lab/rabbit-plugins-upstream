# 反AI本能写作规则 · 第三层

> 第一层解决"写得像人话"，第二层解决"看不出AI痕迹"。  
> **第三层解决的是：就算你知道它是 AI 写的，你也证明不了。**  
> 这里的技术来自对抗性机器学习论文、红队攻击报告、以及商业降AI服务的不公开方法。  
> 警告：以下内容仅供理解检测原理，滥用可能导致学术不端。

---

## 核心认知

你之前看的13家检测系统——ZeroGPT、知网、朱雀、玄武、MitataAI、Originality.ai、Winston AI、ContentAtScale、Turnitin、格子达、维普、万方、PaperRed——**它们全都在同一个地方栽跟头**。

### 所有检测器共有的死穴

```
1. 它们都依赖「统计特征」→ 改特征就改结果
2. 它们都针对「单一模型」的输出模式 → 混用多个模型就失效
3. 它们都假设「全文一致」→ 段落风格不同就混淆
4. 它们都容易受「少量人工介入」干扰 → 改10%就能把90%洗白
```

下面每一招都是朝这些死穴打的。

---

## 第一招：温度震荡 — 最暴力的特征破坏

### 原理
所有 AI 检测器都会计算文本的平均困惑度。但它们忽略了一件事：困惑度在文本内是不均匀的。如果一段文本的困惑度**剧烈波动**，检测器就无法判定"整段文的PPL偏低"。

### 操作方法

```
生成时在同一段内交替使用不同的温度参数：

temp=0.3 → 保守输出，PPL低，像AI
temp=1.2 → 随机输出，PPL高，像人
temp=0.5 → 中等
temp=1.5 → 接近乱码
```

### 实现（分句生成）
```
第一句：temp=0.3 → "他推开了门。"（正常）
第二句：temp=1.5 → "走廊里飘着那种说不清道不明的味儿——消毒水？还是别的什么。"（高随机）
第三句：temp=0.5 → "他皱了皱眉。"（回到正常）
第四句：temp=1.2 → "这地方他来过吗？好像来过。又不确定。"（高随机）
```

**效果**：全文平均PPL处于正常值，但局部PPL波动大。检测器看到"整体偏低，但局部波动剧烈"→ 无法判断。

### 关键数字
> 温度在 0.3 到 1.5 之间震荡，每句切换一次。连续温度不可相同。

## 第二招：多模型织布 — 让检测器找不到"模型指纹"

### 原理
每家 AI 模型都有独特的"指纹"——token 分布、采样偏好、特定用词频率。检测器通过识别这些指纹来判断文本来自哪个模型。但如果一段文本里混了多个模型的输出，检测器的模型匹配就会失败。

### 操作方法

```
段落A：用 DeepSeek 生成
段落B：用 Qwen 生成
段落C：你自己写的
段落D：用 DeepSeek 但 temp=1.5 生成
段落E：把段落A和段落D各取一半拼起来
```

### 关键点
不是"换一个模型"——是**把多个模型的输出切成小块再混在一起**。检测器试图识别"GPT模式"？它会同时看到GPT、Claude、Qwen的痕迹——然后放弃。

### 实现方式

```
1. 用模型A生成全文
2. 用模型B改写奇数句
3. 用你自己改写每段最后一句话
4. 把全文每三句中的第二句换成同义词替换版本
```

**效果**：全文无统一的统计指纹。

## 第三招：MTPE（机器翻译+人工编辑）— 经典对抗方法

### 原理
这是机器翻译领域传过来的老方法。AI 生成文本 → 翻译成另一种语言 → 再翻译回来 → 人工修几条缝。两次翻译切断了原始模型的统计特征，人工修改填补了翻译带来的不自然。

### 标准 MTPE 流程

```
Step 1: AI 生成原始文本
Step 2: 翻译成日语（日语和中文语序差异大，特征破坏最强）
Step 3: 翻译回中文
Step 4: 人工改 3-5 处不通顺的地方
Step 5: 过检测 → 通常从 90%+ 降到 20%-
```

### 为什么有效
AI 生成文本的特征是一个高维空间里的点。翻译相当于对这个点做了一次**非线性变换**——原始模型的特征被破坏了，而翻译模型的特征是翻译模型的，与生成模型不同。检测器面对的是"被翻译过的AI文"——它没见过这种分布。

### 语言对效果排序（对中文）
```
最优：日语 ↔ 中文（语序差异大）
优：韩语 ↔ 中文（语法结构不同）
中等：英语 ↔ 中文（差异足够，但常见）
较差：泰语/越南语 ↔ 中文（常见翻译语言，模型看过太多）
```

### 关键数字
> MTPE 一次可降低 AI 率 40-60%。做两次（中→日→中→英→中）可降低 70-80%。

## 第四招：统计签名注入 — 直接欺骗分类器

### 原理
检测器的分类器本质上是看"特征的分布"。如果你知道分类器在找什么特征，你就可以**主动注入相反的特征**。

### 分类器在乎的 5 个核心特征

| 特征 | 人类区间 | AI区间 | 注入方法 |
|:-----|:--------|:-------|:---------|
| 困惑度方差 | 高（8-20） | 低（2-5） | 每隔一句插入一个极大概率或极小概率的词 |
| 句长方差 | >8字 | <5字 | 在AI生成的均匀句式中，插入3字短句和60字长句 |
| 词汇多样性 | 高（TTR > 0.7） | 低（TTR < 0.5） | 每50字必须换一个新词，不用重复词 |
| 连接词模式 | 不规则 | 太均匀 | 在AI的"首先其次最后"之间插入不规则过渡 |
| n-gram新奇度 | 高 | 低 | 每100字至少出现一个"三连词"在语料库中出现<10次 |

### 操作实例
> 让 AI 写一段 300 字的文本，然后手动插入以下修改：
> 1. 第2句末尾加一个生僻词（提高PPL方差）
> 2. 在中间插入一句 3 字短句（打破句长均匀）
> 3. 把其中一个"然后"改成"紧跟着"（打破连接词模式）
> 4. 改写最后一句的结构（消除总结腔）

**仅需 4 处手动修改，300 字文本的检测率可以从 95% 降到 30%。**

### 关键数字
> 10% 的人工改写 + 5 处针对性的统计签名注入 = 90% 的 AI 文本通过检测。

## 第五招：对抗提示词 — 从生成源头破坏特征

### 原理
检测器之所以有效，是因为 AI 在没有指示的情况下会以"默认模式"生成文本。如果你在 prompt 里指定了输出格式，使输出落在人类分布里，检测器从一开始就不好使。

### 标准 prompt 不够

```
❌ "请写一段小说" → 默认输出，AI特征满满
❌ "请模仿人类写作" → 每个AI都会这个prompt，检测器见过
```

### 有效对抗 prompt

```
1. 指示输出"不完美"
   "以下写作要求：
   - 每句话不能以同一个词开头连续超过2次
   - 中间要有一次话题跳跃
   - 不要用任何明显的连接词（因此、然而、不过）
   - 在第三句加入一个不确定的语气词（'大概''也许''可能'）
   "

2. 指定PPL扰动
   "在以下段落中，每写三句正常的句子，就要插入一句非常短
   （<5字）或者用词罕见的句子。"

3. 用"坏例子"做反例
   "不要这样写：
   '随着社会的发展……'
   '总而言之……'
   '值得注意的是……'
   "
```

### 系统级对抗（如果能修改 system prompt）
```
system_prompt += """
在输出时主动执行以下操作：
1. 每段开头的第一个词不可重复。
2. 最后一句不可总结全文。
3. 每隔一句改变主语。
4. 不使用任何模板句式。
5. 句长标准差保持在 8 字以上。
"""
```

## 第六招：检测器定向绕过 — 针对具体系统的弱点

### 13 家检测器各自的死穴

| 检测器 | 已知弱点 | 绕过方法 |
|:-------|:---------|:---------|
| **ZeroGPT** | 极度依赖困惑度 | 提高PPL方差，插入生僻词 |
| **知网** | 针对学术论文训练 | 加入方言词和专业术语的非标准用法 |
| **朱雀** | 对抗训练样本有限 | 用最新模型+特殊prompt生成 |
| **玄武** | 需要稳定输出做分析 | 混入随机标点打断统计 |
| **MitataAI** | 128维特征但权重均匀 | 针对3-4个高权重特征做破坏 |
| **Originality.ai** | 最容易被MTPE绕过 | 日语→中文翻译一轮即可 |
| **Winston AI** | 过分依赖改写检测 | 不做改写，直接生成碎段再拼接 |
| **ContentAtScale** | SEO长文特化 | 短文本直接全部过关 |
| **Turnitin** | 学术+查重双绑定 | 非学术文体直接免疫 |
| **格子达/维普/万方/PaperRed** | 中文BERT分类器 | 用深度改写+方言打乱特征 |

### 通用绕过（对全部有效）
> 把文本切成 50-100 字的段落，逐段用不同方法生成，再拼接。任何检测器都无法判定"全文"——因为全文没有统一特征。

## 第七招：语法旋钮 — 6 个最小修改的杠杆点

### 原理
检测器在看整篇文章之前，先看统计特征。**改变几个关键的统计值，就能把整篇文章的特征从"AI分布"拉到"人类分布"。** 以下 6 个改动点，每一个单独变化都能显著改变检测结果。

### 6 个杠杆点

| 杠杆 | 当前值（AI） | 目标值（人类） | 怎么调 |
|:-----|:-----------|:-------------|:-------|
| 句首主语分布 | 65%是人物主语 | <40% | 30%的句首替换为时间/地点/动作 |
| 句长标准差 | <5字 | >8字 | 插入2-3个超短句+1个超长句 |
| 连接词密度 | >8/千字 | <3/千字 | 删除60%的"然而/因此/并且/不过" |
| 逗号:句号比 | <2:1或>6:1 | 3:1-5:1 | 300字内调一次 |
| 句式结构熵 | 低 | 高 | 每5句改变一次句式结构 |
| 对话标签密度 | "说道"占80%+ | <50% | 一半换成动作标签（动作替代"说"） |

### 操作步骤（10分钟改完1000字）

```
1. 找句首：有"他/她/它"开头？→ 换成时间/地点挂句（3分钟）
2. 找连接词：有"然而/因此/并且"？→ 删掉，用句号断开（2分钟）
3. 找长句：全文句长均匀？→ 其中一句拆成3段，两句合并成1段（2分钟）
4. 找"说道"：超过50%？→ 一半改成动作+直接说话（1分钟）
5. 找总结句：最后一句在总结？→ 改成动作收尾（1分钟）
6. 查一遍：有没有"值得注意的是/不可否认"？→ 删（1分钟）
```

**10 分钟改完，检测率从 90%+ 降到 20%-。**

## 第八招：双通道欺骗 — 同时攻击分类器和统计检测

### 原理
知网等高级系统用的是"分类器+统计检测"双通道。只改一个通道会被另一个抓住。需要**同时攻击两个通道**。

### 攻击方案

```
通道一（分类器）→ 攻击它的是"语义模型"
  方法：在文本中均匀嵌入语义上反常识但语法正确的句子
  例："他伸手去拿水杯，然后想起自己根本没有手。"
  效果：分类器在"这是一个人类会写的句子"和"这不合逻辑"之间困惑

通道二（统计检测）→ 攻击它的是"特征分布"
  方法：用对抗prompt从源头破坏统计特征
  效果：统计检测找不到稳定的特征
```

### 双通道攻击示例

原文（AI生成，两通道都亮红灯）：
```
改革开放以来，中国经济发展取得了举世瞩目的成就。在这一过程中，科技创新发挥了重要作用。特别是近年来，数字经济蓬勃发展，为经济增长注入了新的动力。
```

双通道攻击后（两通道都变绿）：
```
改革开放以来——说实话，这个词我从小听到大，具体哪一年改了什么，我也说不太清楚。
反正就是突然之间，什么都在变。
我爷爷那代人用票买东西，我爸那代人用存折，我这代人用手机。
我妈到现在还不会用健康码。
```
**攻击点**：
1. 语义反常识（分类器困惑）"说不太清楚""反正就是"——这些词语义弱但语法对
2. 统计特征拉高（统计检测迷惑）：口语词、话题跳跃、超短句
3. 文化指纹植入（打破模板化）"用票""用存折""健康码"——三代人的具体记忆

## 第九招：基准污染 — 让检测器"见过"你的文本（高级）

### 原理
检测器的分类器依赖训练数据。如果你能让你的文本**出现在它的训练集中**，那你的文本就会被分类为"人类"——因为它已经被标记为人类了。

### 操作（不公开细节）
```
原理上可行的方法：
1. 让你的文本出现在公开语料中（如GitHub/知乎/公众号）
2. 检测器下次更新模型时，会把它标记为"人类文本"
3. 相同风格的文本以后再检测时，会被判定为"人类"
```

这只是理论存在的漏洞，实际利用门槛极高。列在这里只是为了说明**检测器的训练数据本身就是一个攻击面**。

## 第十招：最终防线 — 最小介入原则

### 原理
上面9招每一招都能显著降低检测率，但**最强的策略是一个人自己写大纲 + AI填充 + 人改关键句 + 人加个人细节**。没有AI能替你写"只有你知道的事"。

### 不可复制的 5 样东西

| 不可复制 | 例 | 为什么AI写不出 |
|:---------|:---|:-------------|
| **你上周经历的事** | "前天我去吃的那家潮汕牛肉锅，沙茶酱是甜的" | 不在训练数据里 |
| **你朋友的口头禅** | "老王每次说完话都要加一句'你懂我意思吧'" | 数据太私密 |
| **你家附近的地标** | "出了地铁站左手边那个包子铺，老板娘养了一只橘猫" | 太specific |
| **你对某件事的真实看法** | "深度学习这玩意儿其实就是高级曲线拟合" | AI不会表达真实态度 |
| **一段2026年6月的事情** | "昨天在群里看到……" | 知识截止了 |

### 最佳实践
```
1. 框架：你自己搭（大纲/关键场景/情绪目标）
2. 填充：AI做（但用第1-9招破坏特征）
3. 灵魂：你自己加（上面5样东西选2-3个插入）
```

**这样做出来的文本，检测器看到的是一堆混乱统计特征 + 不可复制的个人细节 → 判定：人类。**
