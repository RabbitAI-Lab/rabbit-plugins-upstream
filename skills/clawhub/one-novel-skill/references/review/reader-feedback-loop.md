# 读者反馈循环

## 追读率分析

| 追读率 | 健康度 | 措施 |
|:------|:------:|:-----|
| > 30% | 优秀 | 保持节奏 |
| 15-30% | 正常 | 观察趋势 |
| 5-15% | 预警 | 检查近 5 章节奏 |
| < 5% | 危险 | 大改或完结 |

## 评论分类处理

| 评论类型 | 处理 |
|:---------|:-----|
| "水/拖" | 加快节奏，砍支线 |
| "看不懂" | 加前情提要 |
| "主角太弱/太强" | 评估力量体系 |
| "配角写得好" | 多给戏份 |
| "什么时候更新" | 稳定日更恢复信任 |

## 控制原则

- 不因一条恶评改大纲
- 3 条同类型反馈才行动
- 追读率连续 5 章下降才调整
- 不改已发布的章节（番茄限定）
