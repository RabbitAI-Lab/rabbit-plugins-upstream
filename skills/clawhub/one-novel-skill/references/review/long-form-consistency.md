# 长篇一致性保证（>100 章）

核心问题：200 章的小说，LLM 的 context window 装不下全部前文。角色状态/地点/能力/关系会在感知中漂移。

## 应对策略

### 1. 每 10 章一次状态快照

在 `追踪/` 下维护 `状态快照.md`：

```markdown
## 第 10 章快照
- 主角: Lv.5 筑基期，京城，持有破天剑
- 女主: 昏迷中，京城医馆
- 未回收: 天道玉佩（第3章埋）
```

### 2. 写前必读清单
1. 上一章结尾主角在哪？
2. 本章涉及角色上次出现时什么状态？
3. 要回收的伏笔第几章埋的？
4. 时间线一致？

### 3. 自动校验
`python pipeline.py --book "小说目录"` 会检查追踪文件完整性。

### 4. 复核节奏
| 章节 | 重点 |
|:---:|:-----|
| 每 30 章 | 主角能力/装备/等级 |
| 每 50 章 | 所有角色状态 + 伏笔表 |
| 每 100 章 | 力量体系 + 世界观规则 |
