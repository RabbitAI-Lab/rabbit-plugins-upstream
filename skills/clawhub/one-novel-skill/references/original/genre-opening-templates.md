# 四大类开篇黄金模板

> 都市/玄幻/言情/悬疑 的开篇最佳实践
> 来源: 原创生成

---

## 一、都市类开篇模板

### 模板A：落魄逆袭型
```
第1章节奏:
  0-300字: 主角在最低谷 (失业/分手/负债) — 具体场景
  300-600字: 金手指出现 (系统/重生/传承) — 意外事件
  600-1500字: 验证金手指 — 小范围测试
  1500-2500字: 首次使用金手指改变处境 + 章末钩子
```

### 模板B：身份揭秘型
```
第1章节奏:
  0-300字: 主角被轻视/侮辱 — 具体场景
  300-800字: 旁人的反应 (不知天高地厚)
  800-1500字: 某个大人物/势力出现，暴露主角真实身份
  1500-2500字: 打脸开始 + 更大的阴谋浮出水面
```

---

## 二、玄幻类开篇模板

### 模板A：穿越/重生型
```
第1章节奏:
  0-300字: 死亡/穿越瞬间 (不写背景介绍)
  300-800字: 新身体/新世界的感知 (感官先行)
  800-1500字: 发现自己处于困境 + 金手指/记忆融合
  1500-2500字: 首次小冲突 + 展示与前世不同的应对
```

### 模板B：废柴逆袭型
```
第1章节奏:
  0-300字: 被嘲笑/被退婚/被驱逐 — 具体场景
  300-800字: 金手指觉醒/奇遇 (不要用系统提示)
  800-1500字: 第一次展示实力 (反差感)
  1500-2500字: 引起关注/埋下更大的冲突
```

---

## 三、言情类开篇模板

### 模板A：契约/替嫁型
```
第1章节奏:
  0-300字: 女主被逼到绝境 (家庭压力/债务) — 具体场景
  300-800字: 被迫接受契约/替嫁
  800-1500字: 第一次见面 (要有化学反应，不一定是好感)
  1500-2500字: 契约开始 + 第一个意外 (偏离预期)
```

### 模板B：重逢/破镜重圆型
```
第1章节奏:
  0-300字: 多年后的日常 — 已有新生活
  300-800字: 偶然重逢 (不刻意)
  800-1500字: 发现对方的变化/秘密
  1500-2500字: 不得不再次产生交集 + 当年的谜团
```

---

## 四、悬疑类开篇模板

### 模板A：案件开场型
```
第1章节奏:
  0-300字: 尸体/失踪/异常事件 — 具体细节
  300-800字: 主角介入 (警察/侦探/相关人士)
  800-1500字: 第一个异常细节 (看似正常但有破绽)
  1500-2500字: 发现更多线索 + 更大的谜团浮现
```

### 模板B：受害者视角型
```
第1章节奏:
  0-300字: 主角遭遇异常事件 — 具体感受
  300-800字: 发现这不是偶然
  800-1500字: 试图寻找答案/求助
  1500-2500字: 线索指向更大的阴谋 + 章末威胁升级
```
