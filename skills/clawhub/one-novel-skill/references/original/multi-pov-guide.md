# 多角色 POV 切换最佳实践

> 基于《冰与火之歌》《三体》等经典作品的多视角叙事技法
> 来源: 原创生成

---

## 一、POV 切换的原则

### 黄金法则：每个场景只有一个 POV 角色
- 场景 = 同一时间/同一地点/同一组角色的连续叙事
- 一个场景内不允许切换 POV
- POV 切换 = 场景切换 = 新的章节/小节/空行分隔

### 什么角色值得拥有 POV
1. **主角 POV**: 核心叙事视角，占比 60-80%
2. **反派 POV**: 展示反派计划/动机，占比 10-20%
3. **关键配角 POV**: 提供主角看不到的信息，占比 5-10%
4. **路人 POV**: 展示世界/事件的外部视角，占比 1-5%

---

## 二、POV 切换时机

### 必须切换的时机
1. 需要展示主角不知道的信息（反派计划/秘密对话）
2. 多线并行叙事（不同地点同时发生的关键事件）
3. 制造信息差（读者知道，主角不知道 → 悬疑感）
4. 节奏需要（主角线平缓时切换到冲突线）

### 禁止切换的时机
1. 高潮场景中 → 打断节奏
2. 信息量足够的情况下 → 冗余
3. 新 POV 角色没有独立故事线 → 工具人视角

---

## 三、POV 声线差异

每个 POV 角色必须有独特的"视角滤镜"：

| 维度 | 实现方式 |
|------|---------|
| 观察重点 | 战士注意武器和站位，商人注意价格和利润，学者注意细节和逻辑 |
| 感官偏好 | 厨师嗅觉敏感，乐师听觉敏感，画家视觉敏感 |
| 知识盲区 | 每个角色有自己不知道的事，不要全知全能 |
| 价值观滤镜 | 同一件事，不同角色有不同解读 |
| 语言风格 | 内心独白的词汇和句式因角色性格而异 |

---

## 四、网文场景的 POV 策略

### 番茄/飞卢（单 POV 为主）
- 主角 POV 占比 90%+
- 反派 POV 仅在关键转折点出现
- 每次 POV 切换要明确标注 "※※※" 或空行分隔

### 起点（多 POV 可接受）
- 主角 POV 占比 60-70%
- 反派 POV 每 5-10 章 1 次
- 配角 POV 在支线展开时使用
