# 悬疑文深度写作指导

> 来源: 基于大模型写作知识生成

---

## 一、谜题设计

### 核心谜题三要素
1. **What**：发生了什么？（案件/失踪/异常事件）
2. **Who**：谁做的？（凶手/幕后黑手）
3. **Why**：为什么？（动机/目的/更大的阴谋）

### 谜题层次
```
表层谜题（案件本身）→ 中层谜题（背后势力）→ 深层谜题（世界真相）
每解开一层，发现下一层更大谜团
```

### 红鲱鱼（False Lead）设计
- 每 5-10 章必须出现 1 个红鲱鱼
- 红鲱鱼必须合理——看起来像真凶，但揭穿后有合理解释
- 红鲱鱼不能是"巧合"，必须是有意设计的误导

## 二、线索释放节奏

### 标准节奏模板
```
第1-3章:   核心谜题建立 + 1个关键线索 + 1个红鲱鱼
第4-7章:   调查展开 + 2-3个线索 + 1个反转
第8-12章:  线索收敛 + 1个重大反转 + 新的谜团浮现
第13-15章: 真相逼近 + 最后红鲱鱼 + 最终反转
第16-20章: 真相揭露 + 未解之谜（为续作留空间）
```

### 线索类型
| 类型 | 说明 | 示例 |
|------|------|------|
| 物理线索 | 物证/痕迹 | 指纹/血迹/凶器 |
| 人证线索 | 目击者/相关人士 | 证词/不在场证明 |
| 逻辑线索 | 推理得出的结论 | 时间矛盾/动机分析 |
| 隐藏线索 | 需要特定条件才能发现的 | 密码/暗号/隐藏房间 |

## 三、反转设计

### 反转频率
- 短篇（20 章内）：至少 3 次反转
- 中篇（50 章内）：至少 5 次反转
- 长篇（100 章+）：每 10 章至少 1 次有效反转

### 反转类型
1. **身份反转**：A 不是 A，B 才是 A
2. **动机反转**：表面动机是假的，真实动机完全不同
3. **时间反转**：事件发生的时间线被篡改
4. **视角反转**：从另一个角度看，事件完全不同
5. **真相反转**：整个事件的真相和表面完全相反

## 四、节奏控制

```
平静收集线索 → 突然发现关键线索 → 紧张追逐/对峙 → 短暂喘息 → 更大危机
```

### 节奏公式
- 每 3 章必须有一个"心跳加速"点（新发现/新危险/新反转）
- 每 7 章必须有一个"呼吸"点（角色互动/日常片段/回顾）
- 高潮前 2 章开始加速，句长缩短，段落变短

---

## 五、悬疑常见错误

- ❌ 谜底靠巧合解开——必须是角色主动推理/调查得出的
- ❌ 凶手最后一章突然出现——凶手必须在前面章节出现过
- ❌ 所有线索一次性释放——必须分批，让读者有推理空间
- ❌ 结尾解释过多——真相揭露后留 10% 的想象空间
