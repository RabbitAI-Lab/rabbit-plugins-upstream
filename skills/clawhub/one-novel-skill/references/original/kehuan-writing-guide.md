# 科幻文深度写作指导

> 来源: 基于大模型写作知识生成

---

## 一、科幻分类与定位

### 硬科幻 vs 软科幻
| 维度 | 硬科幻 | 软科幻 |
|------|--------|--------|
| 科学基础 | 以现有科学理论为基础延伸 | 科学只是背景设定 |
| 技术描写 | 详细、可推敲 | 简略、一笔带过 |
| 读者期待 | 逻辑自洽、科学合理 | 故事精彩、脑洞大 |
| 代表作品 | 《三体》《火星救援》 | 《沙丘》《星际迷航》 |
| 网文定位 | 小众但付费率高 | 大众，适合番茄/起点 |

## 二、世界观设定

### 核心设定层次
```
基础设定（年代/科技水平/社会形态）
  → 核心技术（1-2个关键科技突破）
    → 衍生技术（核心技术的应用）
      → 社会影响（科技如何改变人类生活）
```

### 设定自检清单
- [ ] 核心技术是否符合已知物理定律？（硬科幻）
- [ ] 如果违反，有没有给出合理假设？（如"曲速引擎基于爱因斯坦-罗森桥"）
- [ ] 技术的能源来源是什么？
- [ ] 技术的代价/副作用是什么？
- [ ] 技术如何影响社会结构？
- [ ] 谁控制这项技术？为什么？

## 三、科幻题材分类

### 末世/废土
- **核心冲突**：生存 vs 人性
- **必备元素**：资源稀缺、秩序崩溃、新秩序建立
- **爽点**：从零重建文明、收小弟建基地
- **注意**：末世原因要合理（病毒/核战/气候/外星入侵）

### 星际/太空歌剧
- **核心冲突**：文明碰撞/资源争夺/探索未知
- **必备元素**：星际航行技术、外星文明、宇宙尺度
- **爽点**：舰队大战、发现新文明、科技碾压
- **注意**：距离尺度要合理（光年级别）

### 赛博朋克
- **核心冲突**：科技巨头 vs 底层人民
- **必备元素**：AI、义体改造、虚拟现实、巨型企业
- **爽点**：黑入系统、揭露阴谋、底层逆袭
- **注意**：世界观要有沉浸感（霓虹灯、酸雨、义体诊所）

### AI/机器人
- **核心冲突**：人类 vs AI、意识定义
- **必备元素**：AI 觉醒、图灵测试、伦理困境
- **爽点**：AI 帮助主角、AI 与人类合作/对抗
- **注意**：AI 的动机要合理（不是为了作恶而作恶）

## 四、科技描写原则

### 好的科技描写
- 用比喻让读者理解（"就像……一样"）
- 展示科技的效果而非原理
- 通过角色使用科技来展示

### 坏的科技描写
- ❌ 长篇大论解释技术原理（像教科书）
- ❌ 堆砌术语不解释
- ❌ 科技像魔法——没有限制和代价

## 五、网文科幻爽点设计

| 爽点类型 | 实现方式 | 适用题材 |
|---------|---------|---------|
| 科技碾压 | 低文明遇到高文明/低科技遇到高科技 | 星际/末世 |
| 系统流 | 科技系统/基因优化系统 | 末世/赛博 |
| 建设流 | 从零建设基地/城市/文明 | 末世 |
| 解谜流 | 探索未知科技/文明遗迹 | 星际 |
| 黑客流 | 黑客/潜行/揭露阴谋 | 赛博 |
