# 历史文深度写作指导

> 来源: 基于大模型写作知识生成

---

## 一、穿越开局设计

### 开局三要素
1. **身份确认**（首章）：我是谁？什么年代？什么身份？（士农工商/官宦/平民/贱籍）
2. **处境确认**（首章）：我现在面临什么困境？（贫困/追杀/政治斗争/生存危机）
3. **金手指确认**（第2章内）：我有什么优势？（现代知识/记忆融合/系统/预知）

### 身份设计原则
- 身份不能太高（直接是皇帝/王爷就没成长空间了）
- 身份不能太低（贱籍/奴隶翻身难度太大，爽感不足）
- **最优：中等身份 + 危机**（落魄书生/失势小官/破落商户）

## 二、历史考据清单

### 必须考据的维度
| 维度 | 内容 | 重要程度 |
|------|------|:--------:|
| 政治制度 | 官制/爵位/科举/法律 | 🔴 必考 |
| 经济体系 | 货币/税赋/贸易/物价 | 🟡 重点 |
| 社会阶层 | 士农工商/户籍/服饰等级 | 🟡 重点 |
| 军事制度 | 兵制/武器/战术/后勤 | 🟢 可略 |
| 文化习俗 | 礼仪/饮食/婚丧/节庆 | 🟡 重点 |
| 地理交通 | 行政区划/交通方式/路程 | 🟢 可略 |

### 考据红线
- ❌ 把宋朝的官制套在唐朝
- ❌ 让古代人说现代网络用语
- ❌ 让古人拥有现代价值观（除非是穿越者）
- ✅ 允许 10% 的艺术加工，但核心制度必须准确

## 三、现代知识应用

### 可应用的知识类型
| 类型 | 示例 | 注意事项 |
|------|------|---------|
| 技术类 | 制盐/炼钢/造纸/印刷/火药 | 需要原材料和技术条件，不能凭空变出来 |
| 制度类 | 税收改革/军事编制/教育体系 | 触动既得利益者，必有政治斗争 |
| 经济类 | 钱庄/股份/期货/物流 | 需要资本积累和社会基础 |
| 文化类 | 诗词/小说/戏曲/思想 | 不能过度剽窃，要有改编和创新 |
| 军事类 | 战术/训练/后勤/武器 | 需要实际条件，不能纸上谈兵 |

### 金手指限制原则
- 不能一步登天：知识→实践→推广，每步都有阻力
- 不能无人反对：任何变革都会触动利益集团
- 不能无视历史条件：有些东西古代就是做不出来

## 四、历史人物处理

### 原则
- 真实历史人物不能 OOC（脱离角色设定）
- 虚构人物不能影响重大历史事件的结果
- 蝴蝶效应要合理：小事件可以改，大事件不能改

### 历史人物出场要点
- 首次出场要有标志性细节（不是"他叫李白"就完了）
- 行为要符合历史记载的性格
- 和主角的互动要合理（一个平民不会随便见到皇帝）

## 五、政治斗争写作

### 斗争层次
```
个人恩怨 → 家族利益 → 派系斗争 → 路线之争 → 皇权博弈
```

### 政治斗争要点
- 每次斗争必须有明确的利益冲突
- 反派要有合理的动机和手段
- 主角不能靠运气赢，要靠谋略和布局
- 每次胜利都要付出代价（得罪人/失去盟友/埋下隐患）
