# 仙侠文深度写作指导

> 来源: 基于大模型写作知识生成
> 用途: 注入生成 prompt 的题材专属指导

---

## 一、境界体系设计

### 经典境界链
```
凡人 → 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 真仙
```

### 境界设计原则
- **每个境界必须有质变**：不是数值增长，而是能力/认知/生命形态的根本变化
- **突破必须有代价**：雷劫/心魔/资源耗尽/寿元燃烧
- **境界压制要合理**：高境界打低境界不是碾压，而是"看得更远、反应更快、手段更多"
- **瓶颈期要有内容**：卡在瓶颈时不要跳过，写成探索/寻找机缘/领悟法则的过程

### 常见错误
- ❌ 境界突破写成"喝水"——每突破必须有具体的困难和代价
- ❌ 战斗力完全由境界决定——引入功法/法宝/阵法/计谋等多维度
- ❌ 越级杀敌写成常态——越级战斗应该是极端情况，需要特殊条件

## 二、修炼体系设计

### 灵气/资源体系
- **灵气浓度**：不同区域灵气浓度不同（凡间<宗门<秘境<仙界）
- **修炼资源**：丹药/灵石/天材地宝/功法/传承
- **资源稀缺性**：好的资源一定有人抢，资源争夺是主要冲突来源

### 功法体系
- 功法分品级（黄/玄/地/天/圣/神），高品功法必有特殊来源和代价
- 主角的功法不能是"捡到的"，要有合理的获取过程和适配性
- 功法修炼要有过程：入门→小成→大成→圆满，每阶段有具体表现

## 三、斗法描写层次

### 标准斗法结构
```
起手式（试探）→ 招式碰撞（逐步升级）→ 底牌揭露（高潮）→ 胜负揭晓（代价）
```

### 斗法描写要点
- **视觉化**：读者要在脑中看到画面，不要只写"两人大战三百回合"
- **策略性**：不是拼蛮力，是用计谋/环境/克制关系
- **节奏感**：快攻→僵持→爆发→收尾，有张有弛
- **代价展示**：每次大战后必须有消耗（灵力枯竭/法宝损坏/受伤）

## 四、宗门与势力

### 势力层次
```
散修 → 小家族 → 中等宗门 → 大宗门 → 圣地/皇朝 → 仙界势力
```

### 势力描写要点
- 每个势力有明确的利益诉求和行为逻辑
- 宗门内部有派系斗争（长老会/真传弟子/外门弟子）
- 主角不能一直待在同一个势力，势力更替是成长线

---

## 五、天道/因果/劫数

### 进阶元素（增加深度）
- **天道**：世界的底层规则，突破境界必须感悟天道
- **因果**：主角的行为产生因果，后期必须还
- **劫数**：大境界突破必有天劫，天劫是考验也是机缘

## 六、仙侠爽点公式

| 爽点类型 | 实现方式 | 频率 |
|---------|---------|:----:|
| 突破爽 | 久困瓶颈→机缘→突破→实力暴涨→碾压 | 每 20-30 章 1 次 |
| 打脸爽 | 被轻视→展示实力→对方震惊 | 每 5-10 章 1 次 |
| 寻宝爽 | 发现秘境→破解机关→获得传承 | 每 10-20 章 1 次 |
| 收徒/收小弟爽 | 遇到天才→收服→培养→回报 | 每 30-50 章 1 次 |
| 装逼爽 | 低调入场→被挑衅→暴露实力→全场震惊 | 每 10-15 章 1 次 |
