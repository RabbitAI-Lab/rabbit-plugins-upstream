## Known Risks and Mitigations:

Risk: The security evidence flags broad read, shell command, and file-writing authority.

Mitigation: Keep file access, command execution, and edits under explicit user direction; limit access to private repositories and sensitive local data unless the task requires it.

Risk: UX analysis may use sensitive product, user-research, or behavior data.

Mitigation: Provide only the minimum data needed for the analysis and remove credentials, private user data, and unrelated proprietary details before use.
