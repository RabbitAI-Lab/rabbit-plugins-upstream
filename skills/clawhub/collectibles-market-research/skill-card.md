## Description:

Researches public trading-card and sports-collectible markets using PSA reference data, marketplace listings, auctions, sold items, and market trends to produce sourced collector briefs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[crawlora-org](https://clawhub.ai/user/crawlora-org)

### License/Terms of Use:

MIT-0

## Use Case:

Collectors and researchers use this skill to compare public card and sports-collectible listings, completed sales, and PSA reference information in a sourced buying or market-research brief. It does not authenticate collectibles, guarantee appraisal values, or place bids or purchases.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Collectible search terms and API requests are sent to Crawlora using the user's API key.

Mitigation: Use the skill only when comfortable sharing those queries with Crawlora, and keep the API key private.

Risk: Public listings, PSA references, and limited sale samples can be mistaken for proof of authenticity, market value, rarity, or investment return.

Mitigation: Separate guide values, active prices, and completed sales; cite the underlying records and independently review before buying or bidding.
