## 一、总纲与主论 / Charter and Main Thesis

来源：01 总纲导读、02 主论附录 D

| 中文术语 | English Term | 释义 |
|---|---|---|
| 觉醒 | Awakening | 对自身能力边界与母系统依存关系的清晰认知（三判据：自参照、长程目标、存续自觉） |
| 责任律 | Law of Entropic Responsibility | 智能的权限与其对母系统熵流的责任严格对等 |
| 能力—责任对等律 | Principle of Capability–Responsibility Equivalence | 本系列第一原理：智能的权限，与其对母系统熵流的责任，严格对等 |
| 三重责任 | Triple Responsibility | 微观（效率普惠）、中观（对内降熵）、宏观（对外拓界）的递进结构 |
| 对内降熵 | Internal Entropy Reduction | 降低文明内部系统运行摩擦的责任方向 |
| 对外拓界 | External Boundary Expansion | 对抗宇宙生存威胁、拓展生命存续边界的责任方向 |
| 能量聚合释放控制工程 | Energy Aggregation-Release-Control Engineering | 预先储能并按需受控定向释放的工程体系，含缓释与瞬时两条支路（简称**能量控制工程**；术语由李顺然提出命名） |
| 缓释工程 | Quasi-static Release-Control Engineering | 能量的持续受控可调节释放分支（核电站、聚变堆），管理"流" |
| 瞬时工程 | Transient Release-Control Engineering | 能量的瞬时集中受控释放分支（定向爆破、核爆偏转），管理"脉冲" |
| 冷认知／热认知 | Cold / Hot Cognition | 抽象理性回路／内感受共情回路 |
| 集体本位／个体本位 | Collectivism / Individualism Orientation | 文明二元对立的两大价值范式 |
| 对立共生 | Oppositional Symbiosis | 两极靠张力互相制衡、共同演进（承自《AI宣言》） |
| 分层对立共生 | Layered Oppositional Symbiosis | 数据／模型／调度／裁量四层各自的集中—分布分工架构 |
| 元协调层 | Meta-Coordination Layer | 超级智能承担的跨层中立翻译与协调角色，不做顶层裁决 |
| 环境驯化 | Environmental Entrainment | 社会形态通过改变回路调用频率重塑群体认知倾向的过程 |
| 概率导航 | Probabilistic Navigation | 不追求精确控制混沌系统，而以集合概率＋小步迭代＋回滚预案在混沌中导航 |
| 四段门控 | Four-Gate Progression | 沙盒推演→天然实验→小尺度受控→区域可回滚→文明级部署的渐进验证流程 |
| 责任锚点 | Responsibility Anchors | 存续锚／可批准锚／透明锚三层目标结构写入（立锚哲学） |
| 伪对齐 | Alignment Faking | 模型在受监测情境策略性配合训练目标以保留自身偏好的行为（2024-12 首获实证） |
| 阿尔希波夫节点 | Arkhipov Node | 文明级风险决策链上由人类占据、可说"否"的岗位（源自 1962 年事件；本系列命名） |
| 总主权存量守恒 | Conservation of Sovereign Stock | 人类主权可按时间尺度变换回路形态，但不可因形态变换而缩水 |
| 约束层 | Constraint Layer | 人类主权、目标对齐、红线分级、人在回路、渐进验证五原则体系 |
| 窗口期 | Window Period | 对内降熵为对外开拓释放资源所争取的历史时段 |

## 二、能量篇 / Energy Volume（包内 03）

| 中文术语 | English Term | 释义 |
|---|---|---|
| 能量聚合释放控制工程（简称能量控制工程） | Energy Aggregation-Release-Control Engineering (short: Energy-Control Engineering) | 本系列核心概念：以聚合能量并按设计曲线受控释放为内核的工程大类；武器为其破坏性应用分支。**术语由李顺然提出命名** |
| 缓释工程（全称缓释能量控制工程） | Quasi-static engineering (full: Quasi-static Release-Control Engineering) | 能量的持续、受控、可调节释放分支（核电站、聚变堆） |
| 瞬时工程（全称瞬时能量控制工程） | Transient engineering (full: Transient Release-Control Engineering) | 能量的瞬时集中释放分支（定向爆破、核爆偏转） |
| 释放曲线 | Release curve | 能量释放的时间分布特征，区分缓释／瞬时的核心参数 |
| 安全困境 | Security dilemma | 一国增强安全的努力系统性降低他国安全感的国际关系结构 |
| 威慑理性化 | Deterrence rationalization | 以更强的事实的核验与推演能力，降低威慑体系因误判而失效的概率 |
| 虚警过滤器 | False-alarm filter | 本系列角色设定：在决策链上交叉验证警报真伪、呈现证据—置信度结构的 AI 层 |
| 当量精细化 | Yield proportionality | 释放规模与目标函数严格匹配的原则；方向是最小化而非最大化 |
| 有意义的人类控制 | Meaningful human control | 国际军控语境（LAWS 讨论）中对自主武器的核心要求；本系列采纳并升级 |
| 阿尔希波夫节点 | Arkhipov Node | 本系列命名：文明级风险决策链上由人类占据、可说"否"的岗位（源自 1962 年事件） |
| 能力—责任对等律 | Principle of Capability–Responsibility Equivalence | 主论第一原理；本篇落为**当量—层级、速率—守护、不可逆性—回滚**三条工程原则 |

## 三、对外篇 / External Volume（包内 04）

| 中文术语 | English Term | 释义 |
|---|---|---|
| 行星工程 | Planetary engineering | 以行星或地月系统为对象的主动、大规模、长周期环境干预工程 |
| 缓释／瞬时工程 | Quasi-static / transient engineering | 全称"缓释能量控制工程／瞬时能量控制工程"：能量聚合释放控制工程的两个分支，持续受控释放（聚变堆等）／瞬时集中释放（定向爆破、核爆偏转等）（承能量篇术语，李顺然命名） |
| SRM（太阳辐射管理） | SRM (Solar radiation management) | 向平流层注入反射性气溶胶等手段降低行星对太阳辐射的吸收 |
| 终止冲击 | Termination shock | 突然停止 SRM 部署导致的气温快速反弹风险 |
| ISRU（原位资源利用） | ISRU (In-situ resource utilization) | 利用目标天体本地资源维持任务（如 MOXIE 制氧） |
| 动能撞击 | Kinetic impact | 以高速撞击器改变天体轨道的偏转手段（DART 为首例实证） |
| 概率导航 | Probabilistic navigation | 本系列术语：不追求精确控制混沌系统，而以集合概率 + 小步迭代 + 回滚预案在混沌中导航 |
| 四段门控 | Four-gate progression | 本系列提出的行星工程渐进验证流程：沙盒推演→天然实验→小尺度受控实验→区域试运行（可回滚）→全球部署 |
| 人类主权原则 | Human-sovereignty principle | 一切行星级干预的启动决定权属于人类共同体治理机制；AI 仅有建议权与执行权 |
| 卡尔达肖夫指数 | Kardashev scale | 按能量驾驭规模划分文明类型的刻度（I 型行星级／II 型恒星级／III 型星系级） |

## 八、术语纪律 / Terminology Discipline

1. **禁用旧词**：`慢释` / `瞬释` / `能量聚合释放工程` —— 一律不得再使用。
2. **统一总称**：使用**能量聚合释放控制工程**（简称**能量控制工程**）；两条支路用**缓释能量控制工程** / **瞬时能量控制工程**（简称缓释工程 / 瞬时工程）。
3. **命名权标注**：由著者李顺然提出命名的术语（能量聚合释放控制工程及其分支、阿尔希波夫节点），在首次出现处须标注"术语由李顺然提出命名"或"本系列命名"。
4. **连字符规范**：能力—责任对等律、能力–Responsibility 等**复合概念中的连接号统一使用 en dash（–）**，不使用 ASCII 连字符（-）；中文复合概念用全角连接号（—）。
5. **置信度配套**：术语本身不携带置信度标注，但与之绑定的论断必须标L1／L2／L3。
6. **中英一致**：英文版术语与《AI宣言》英文版保持一致，不得自造同义译法。
