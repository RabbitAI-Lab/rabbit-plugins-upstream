# 喂料包 · 模板（v1.0）

> 用途：给多智能体团队 / 蜂群 / RAG 喂料的标准容器。**喂料质量 = 团队产出质量**——AI 不会自动核实自己编的数字，凡喂料包没有的它就会自行编造填补。
> 沉淀自：多智能体产出核实铁律 + 喂料包防编造规范（2026-08-21 实战）

## 一、喂料包纪律（给谁喂都必须遵守）

1. **凡带具体数值/限值/条款的料，必须三要素齐全**：`出处`（官方来源+日期）+ `适用条件`（什么产品/什么市场/什么阶段）+ `归口标准`（哪个标准/法规体系管）
2. **喂料包没有的内容，团队不得输出**——派活 prompt 里写死："以下喂料包为唯一事实来源，包外数字一律标'待核实'，禁止推断填充"
3. **外部原文先原创化**（第三方内容不镜像、不标注第三方出处，只保留可公开客观事实，自有逻辑重组）
4. **产出必经运营者直读原始产出记录（如 history.jsonl）逐条核实**（不只看表面回复）
5. 喂料包命名：`喂料包_主题_YYYYMMDD_vN.md`

## 二、模板结构

```markdown
# 喂料包：〈主题〉（YYYY-MM-DD vX）

## 0. 任务口径
- 本次任务是什么 / 不做什么
- 输出格式与字数约束
- 禁编造声明（见纪律 #2）

## 1. 事实料区（唯一事实来源）
| 事实/数值/条款 | 出处（官方来源+日期） | 适用条件 | 归口标准 |
|---|---|---|---|
| 例：EO 残留限值 | GB/T 16886.7-2015 分级 | 环氧乙烷灭菌器械 | 生物相容性标准 |

## 2. 官方链接区
（仅官方/权威一手源：gov.cn / nmpa.gov.cn / ecfr.gov / eur-lex / iso.org / openFDA）

## 3. 边界与坑位提示
（本主题已知勘误/常见误区，团队不得踩）

## 4. 待核实区（明确标注，禁止团队自行"补全"）
```

## 三、历史实证

- 2026-08-21 多智能体联网改造后"喂料包打法"验证有效：先搜真料→喂它→产出结构化真货
- 实战踩坑：喂料没写三要素 → 团队自造"环氧乙烷残留≤10μg/g"（真实应为 GB/T 16886.7-2015 分级限值）
- 批量品类实证产出：子代理 prompt 首行硬指令"回复必须是文档本身" + 台账驱动回填
