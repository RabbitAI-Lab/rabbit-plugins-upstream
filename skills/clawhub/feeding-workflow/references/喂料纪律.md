# 喂料纪律（全局，任何喂料行为必须遵守）

## 五条铁律

1. **三要素**：数值/限值/条款必须带——出处 + 适用条件 + 归口标准（防 AI/多智能体编造）
2. **官方源优先**：gov.cn / nmpa.gov.cn / ecfr.gov / eur-lex / iso.org / openFDA
3. **查不到就标"待核实"，不编**
4. **第三方内容原创化改写后才入库**（不镜像原文、不标注第三方出处）
5. **每次喂料**：台账记一行 + 知会用户

## 分区规矩

- **公开区**（法规知识/通用路径/官方链接）：可入知识库、可随发布包分发
- **私密区**（客户项目/报价/供应商/在职公司资料/真名笔记）：只留本地，永不进发布包

## 外部动作红线

入库云端知识库、发布、外发 = 外部动作，执行前必须逐次征得用户授权。
