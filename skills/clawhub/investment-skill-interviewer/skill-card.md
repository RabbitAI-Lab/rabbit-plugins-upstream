## Description: <br>
投研Skill面试官 evaluates financial investment-research skills with a structured seven-dimension rubric and produces comparative scoring reports for skill selection decisions. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, reviewers, and teams selecting financial investment-research skills use this skill to inspect candidate skill materials, run structured checks, score seven evaluation dimensions, and produce hiring-style recommendations or comparison reports. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Actual-verification workflows may run the target skill being evaluated, so risk can come from the evaluated skill rather than this evaluator. <br>
Mitigation: Only run target skills that are trusted for the current agent environment, and review the target skill before execution. <br>
Risk: Investment-research skill evaluations can influence tool selection for financial workflows. <br>
Mitigation: Treat the output as a structured review aid and perform human review before relying on recommendations in financial or compliance-sensitive settings. <br>
