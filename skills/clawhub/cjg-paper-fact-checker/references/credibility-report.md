# 可信度报告模板 / Credibility report template

```
## 论文可信度报告

**论文**：{标题}（{作者}, {年}）· 分享人：{speaker}
**综合评级**：[高 / 中 / 低] · 置信度 [高/中/低]

### ① 引文真实性
- ✅ / ⚠️ / ❌ 核查 N 条参考文献
- 问题项：
  - <文献>：<差异类型，附验证链接>

### ② 可复现性
- 方法：✅ 完整 / ⚠️ 不全（缺 <步骤>）
- 数据：✅ 公开(<DOI>) / ❌ 未公开
- 代码：✅ 放出(<链接>) / ❌ 缺失
- 超参：✅ / ⚠️ 关键缺失

### ③ 图片查重
- ✅ 未发现问题 / ⚠️ 疑似复用（<图>, 比对来源 <链接>） / — 无图跳过

### 给组会的建议
- <先读方法再信结论 / 谨慎引用该结论 / 值得精读 / 建议换一篇>
```

## 评级规则

- **高**：三关全过，无红色项。
- **中**：有关卡但不致命（如代码缺失但方法详尽）。
- **低**：核心关未过（引文造假嫌疑 / 关键方法不可复现 / 图片疑似抄袭）。
