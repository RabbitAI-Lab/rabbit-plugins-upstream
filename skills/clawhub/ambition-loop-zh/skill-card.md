## Description:

Guides agents to deepen work tasks, set measurable stretch goals, seek approval for expanded actions, verify results independently, and report gaps honestly.

This skill is ready for commercial/non-commercial use.

## Publisher:

[linkxzhou](https://clawhub.ai/user/linkxzhou)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and other knowledge workers use this Chinese-language workflow to improve substantive work in code, data, research, and documents, then compare delivered outcomes against the original request and measurable stretch goals. It excludes personal and career planning and requests explicitly limited to minimal changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Stretch goals can expand cost, scope, or the systems affected beyond the original request.

Mitigation: Review the proposed actions, costs, affected files or systems, and alternatives; require explicit approval before any gated step.

Risk: An ambitious result may be presented as successful without sufficient independent evidence.

Mitigation: Check the stated baseline and external validation evidence, and mark unsupported claims as unverified in the gap report.
