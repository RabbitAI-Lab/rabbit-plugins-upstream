# 搬家清单模板

> 复制本文件填充内容。三张特殊清单（易碎贵重 / 随身必带 / 最后装最先拆）必须独立成节，不可并入普通装箱表。燃气电路拆机一律走专业人员。

```
## 一、前提与假设
- 搬家日期：[YYYY-MM-DD]（剩余 [X] 天）
- 规模：[两居室 / 三居室 / 有大家电 / 有宠物]
- 方式：[自行 / 搬家公司]
- 跨城：[是/否]
- 待确认：[缺哪些信息]

## 二、倒排时间轴表
| 时间节点 | 事项 | 建议完成日 |
|---|---|---|
| T-14 | [确定搬家公司/预约] | [日期] |
| T-7 | [开始非日常物品装箱] | [日期] |
| T-3 | [冰箱清库存、快递改址] | [日期] |
| T-1 | [装最后日常品、拆大件] | [日期] |
| 当天 | [易碎随身、跟车、旧房检查] | [日期] |
| T+1 | [拆必备袋、开通水电网络] | [日期] |
| T+7 | [余箱归位、地址变更收尾] | [日期] |

## 三、分区装箱方案（含编号规则）
- 编号规则：[房间-类别-序号]，如 主卧-衣物-1
- 标签写法：[内容物] + [房间] + [序号] + [易碎]
- 装箱顺序：先不常用（反季衣物、书、装饰）→ 后日常
| 箱号 | 房间 | 内容物 | 备注 |
|---|---|---|---|
| 主卧-衣物-1 | 主卧 | 冬季衣物 | 真空袋 |

## 四、三张特殊清单（不可合并）
### 4.1 易碎与贵重
- [花瓶：气泡膜+纸箱，保价；笔记本：随身]
### 4.2 随身必带（搬家当天自己拿）
- [身份证、房产证/合同、钥匙、充电器、常用药、现金、宠物用品]
### 4.3 最后装最先拆（新家第一天用）
- [床品、洗漱包、厨具 basics、拖鞋、纸巾、螺丝刀]

## 五、地址变更与过户表
| 事项 | 谁办 | 线上/线下 | 提前几天 |
|---|---|---|---|
| 快递改址 | 本人 | 线上 | 前 3 天 |
| 水电气 | 本人 | 线上/线下 | 前 5~7 天（燃气走专业人员） |
| 宽带 | 本人 | 线上 | 前 7~14 天 |
| 银行/运营商 | 本人 | 线上 | 后 1 周 |
| 社保/公积金 | 本人 | 线上 | 尽早（跨城转移） |
| 订阅服务 | 本人 | 线上 | 尽早退订 |
| 孩子学校 | 家长 | 线下 | 前 1~2 周 |

## 六、旧房交接验项
- [ ] 清空所有房间与角落、冰箱
- [ ] 清洁
- [ ] 水电表读数拍照
- [ ] 钥匙/门禁卡交接
- [ ] 押金凭据留存（仅动作，不评法律）

## 七、风险提示
- [搬家公司加价 / 大件进不了电梯 / 易碎未保价 / 宠物应激 / 退订遗漏继续扣费]
```

## 填写约束

1. 三张特殊清单必须独立成节（4.1/4.2/4.3），禁止并入第三节普通装箱表。
2. 每项过户必须带"线上/线下"与"提前几天"。
3. 燃气、电路、空调移机只写"联系专业人员/官方渠道"，不写自行拆机步骤。
4. 押金/违约只列动作与证据留存，不给法律意见。
5. 跨城必须在时间轴插入"长途与中转"事项并说明差异。
