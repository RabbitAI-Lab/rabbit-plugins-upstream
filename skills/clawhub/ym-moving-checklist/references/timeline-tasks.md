# 倒排时间轴事项库

SKILL.md 步骤 2 引用本库生成 T-14 到 T+7 的倒排时间轴。用户给的日期转换成相对节点（T=搬家当天），然后从本库选取适用事项填入，并补上"建议完成日"。

## T-14（搬家前两周）

| 事项 | 说明 | 适用情况 |
|---|---|---|
| 确定搬家方式 | 找搬家公司比价/约亲友/租货车 | 普遍 |
| 预约搬家车辆/人员 | 周末旺季需提前约 | 找公司/租车 |
| 盘点大件与异形物 | 钢琴、鱼缸、健身器材、超大衣柜，提前确认能否进电梯/门 | 有大件 |
| 处理不再带走的物品 | 二手转卖、捐赠、丢弃，减少搬运量 | 普遍 |
| 跨城：联系长途物流/托运 | 大件走物流，确认时效与保价 | 跨城 |

## T-7（搬家前一周）

| 事项 | 说明 | 适用情况 |
|---|---|---|
| 开始装非日常物品 | 反季衣物、书、装饰、储藏间 | 普遍 |
| 囤货暂停 | 不再大量买生鲜、耗材，避免搬时过期 | 普遍 |
| 预约水电燃气宽带退办/移机 | 见 `address-transfers.md` 时间要求 | 普遍 |
| 准备打包耗材 | 纸箱、气泡膜、胶带、记号笔、真空袋 | 普遍 |
| 宠物：确认托运/安置方案 | 航空箱、疫苗证、应激预案 | 有宠物 |
| 跨城：办中转仓储预约 | 若新家未就绪需临时存放 | 跨城 |

## T-3（搬家前三天）

| 事项 | 说明 | 适用情况 |
|---|---|---|
| 冰箱清库存 | 易坏食材尽快吃完，搬家当天清空断电除味 | 普遍 |
| 贵重与证件归拢 | 放入随身必带清单的包 | 普遍 |
| 快递改址/暂停 | 避免包裹送到旧地址 | 普遍 |
| 确认搬家公司到场时间 | 再核对一遍，防临时加价 | 找公司 |
| 孩子学校：告知搬家与转学手续 | 见 address-transfers | 有学龄子女 |

## T-1（搬家前一天）

| 事项 | 说明 | 适用情况 |
|---|---|---|
| 装最后一批日常用品 | 除"最后装最先拆"外的基本装完 | 普遍 |
|  disassemble 大件家具 | 床、桌拆装，螺丝装袋贴标签 | 普遍 |
| 厨房剩物处理 | 油盐酱醋能带的带走，开封易洒的先封好 | 普遍 |
| 给新家第一天物品单独装袋 | 对应"最后装最先拆"清单 | 普遍 |
| 旧房水电表读数拍照 | 留证，避免退租纠纷 | 租房 |

## T+7（搬家后一周）

| 事项 | 说明 | 适用情况 |
|---|---|---|

| 旧房押金结算（租房） | 按合同办退，凭证留存 | 租房 |
| 宠物适应观察 | 应激、食欲、排泄，必要时就医 | 有宠物 |

## 使用纪律

- 时间是"建议"，用户实际日期不同就换算成相对节点再填具体日历日。
- 跨城在 T-14、T-7、T-3 各插入"长途与中转"项（物流时效、保价、中转仓储、宠物托运）。
- 燃气、电路、空调移机相关事项，只写"联系专业人员办理"，不写自行拆机步骤。
