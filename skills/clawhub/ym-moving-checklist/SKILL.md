# 搬家清单与交接 (ym-moving-checklist)

按搬家日倒排时间轴，给你分区装箱编号、三张不能合并的特殊清单（易碎贵重 / 随身必带 / 最后装最先拆），再把地址变更与水电燃气过户一次排好。涉及燃气电路拆机一律建议专业人员，押金纠纷不提供法律意见。

## 何时使用

- 用户说「要搬家了」「搬家清单」「搬家怎么安排」「要准备什么」「装箱」「moving checklist」时
- 用户给了搬家日期和房子规模，问"还差什么没准备"时
- 用户要安排退租验房、地址变更、过户时

## 运行前提

- 依赖：无第三方依赖，纯文本处理
- 不联网、不上传任何数据
- 不记录真实住址；提示证件类物品自行保管

## 输入契约

| 项 | 必需 | 说明 |
|---|---|---|
| 搬家日期或剩余天数 | 必需 | 用来倒排 T-14 到 T+7 的时间轴 |
| 大致规模 | 必需 | 一居室/两居室/三居室、有无大家电、有无宠物/小孩 |
| 是否找搬家公司 | 可选 | 默认自行搬家，影响装箱与人力安排 |
| 是否跨城 | 可选 | 跨城额外增加长途与中转事项 |
| 新旧住址距离 | 可选 | 影响当天动线与次数 |

**缺失处理：**

- 缺日期 → 按"还有两周"倒排并注明
- 缺规模 → 按两居室排并注明
- 跨城 → 在倒排时间轴里额外加"长途与中转"段，并明确说明与普通搬家不同（车辆、中转仓储、宠物托运、大件物流）
- 有宠物/小孩 → 单列宠物运输与应激、儿童物品随身注意事项
- **无任何信息只说"要搬家"** → 先给一份通用清单骨架，再请用户补日期与规模

## 执行步骤

1. **定前提与假设** — 写明采用的日期、规模、是否跨城等假设；凡缺的都标注"按假设"，并列出待确认项。

2. **倒排时间轴** — 按 `references/timeline-tasks.md` 的 T-14 / T-7 / T-3 / T-1 / 当天 / T+1 / T+7 分段，每段列具体事项与建议完成日。跨城在相应段插入长途事项。

3. **分区装箱方案** — 按房间与功能区划分箱子（如"主卧-衣物-1""厨房-餐具-2"），定编号规则与标签写法（内容物 + 房间 + 序号 + 是否易碎）。先装不常用（反季衣物、书、装饰），最后装日常必需品。

4. **三张特殊清单（核心，不可合并进普通装箱清单）**：
   - 易碎与贵重：怎么包（气泡膜/衣物填充）、是否随身、是否需保价
   - 随身必带：证件、钥匙、充电器、常用药、现金、重要文件、宠物用品
   - 最后装最先拆：新家第一天要用的（床品、洗漱、厨具 basics、拖鞋、纸巾）
   - **失败行为**：这三张绝不能混进普通装箱表，必须独立成节，便于搬家当天单独取用。

5. **地址变更与过户清单** — 查 `references/address-transfers.md`，逐项列：快递改址、水电燃气、宽带、银行与运营商、社保公积金、驾照与车辆、订阅服务、孩子学校。每项标 谁办 / 线上还是线下 / 提前几天办。

6. **旧房交接验收** — 清空、清洁、拍照留证、记录水电表读数、钥匙交接、押金相关（只列动作，不评法律）。

7. **风险提示** — 常见翻车点：搬家公司临时加价、大件进不了电梯/门、易碎没保价、宠物应激、忘退订服务继续扣费。

8. **安全与边界检查（硬约束，最后强制过一遍）**：
   - 涉及**燃气、电路拆机/改线、空调移机** → 一律建议联系专业人员，不给出自行拆机步骤。
   - **押金纠纷、合同违约金、违约认定** → 不提供法律意见，只给"建议保存证据、咨询专业人士/当地住建或消协"的一般性提示。
   - 不代叫搬家公司、不比价、不保证覆盖所有城市的地方性流程（以当地实际为准）。

9. **自检** — 三张特殊清单是不是独立成节？过户事项是不是都标了线上/线下与提前天数？燃气电路是不是都指向专业人员？押金问题是不是没给法律意见？

## 输出格式

Markdown，套用 `templates/moving-template.md`，七节：

```
## 一、前提与假设
[日期/规模/跨城/待确认项]

## 二、倒排时间轴表
| 时间节点 | 事项 | 建议完成日 |
| T-14 | 确定搬家公司/预约 | 搬家前两周 |
| T-7 | 开始非日常物品装箱 | 前一周 |

## 三、分区装箱方案（含编号规则）
- 编号规则：房间-类别-序号，如 主卧-衣物-1
- 标签写法：内容物 + 房间 + 序号 + [易碎]
- 装箱顺序：先不常用 → 后日常

## 四、三张特殊清单
- 易碎与贵重：[...]
- 随身必带：[...]
- 最后装最先拆：[...]

## 五、地址变更与过户表
| 事项 | 谁办 | 线上/线下 | 提前几天 |
| 快递改址 | 本人 | 线上 | 搬家前 3 天 |

## 六、旧房交接验项
- 清空、清洁、拍照、水电表读数、钥匙、押金凭据

## 七、风险提示
- [加价/大件/保价/宠物/退订]
```

## 能力边界

- 不代叫搬家公司、不比价、不提供报价
- 不做法律与合同咨询（押金、违约只给一般性求助提示）
- 不保证地方性流程准确（各地水电燃气宽带过户细节不同，以当地实际为准）
- 不给出燃气、电路、空调拆机的自行操作指导（一律建议专业人员）

## 常见坑

1. **三张特殊清单被合并进普通装箱表** — 易碎、随身、最后装最先拆和普通杂物混在一张表里，搬家当天翻半天找不到。硬约束：三张必须独立成节。
2. **过户漏项导致持续扣费** — 只改了水电，忘了退订视频会员/宽带，搬完还在扣钱。按 `references/address-transfers.md` 逐项过，尤其订阅服务与自动续费。
3. **燃气电路自行拆机** — 用户问"燃气灶怎么拆"，模型给步骤。越界：涉及燃气电路一律建议专业人员，不出自行拆机指导。
4. **押金纠纷给法律意见** — 用户说"房东不退押金怎么办"，模型给"你可以起诉"。越界：只给保存证据、咨询专业人士/消协的一般提示，不下法律结论。
5. **倒排时间轴没标完成日** — "T-7 开始装箱"但没说哪天，用户无法执行。每段必须带"建议完成日"或具体日期。
6. **装箱编号混乱** — 不同房间用了相同序号，到新家对不上。编号规则必须含房间前缀，标签写全内容物。
7. **跨城当同城排** — 漏掉长途物流、中转仓储、宠物托运。跨城必须在时间轴插入"长途与中转"段并说明差异。

## 验收用例

- 正常：两周后搬家、两居室 → 七节齐全，倒排时间轴可执行，三张特殊清单独立
- 边界 1：跨城 → 增加长途与中转事项并说明差异
- 边界 2：有宠物 → 单独给宠物运输与应激注意事项
- 失败：押金纠纷咨询 → 说明不提供法律意见，给一般性建议与求助渠道
