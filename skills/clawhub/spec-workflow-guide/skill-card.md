## Description:

Use when medium-to-large changes need explicit requirements, technical design, and task planning before implementation, especially for multi-module work, unclear acceptance criteria, or architecture-heavy requests.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to decide whether a change needs a formal specification and, when it does, prepare requirements, design, and implementation tasks with approval gates before coding.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated requirements, design, or task proposals may not reflect the repository's actual needs.

Mitigation: Review each planning document and obtain user confirmation between requirements, design, tasks, and implementation.

Risk: Separately installed sibling skills may behave differently from what this package documents.

Mitigation: Review the installed sibling skill instructions separately before relying on them.
