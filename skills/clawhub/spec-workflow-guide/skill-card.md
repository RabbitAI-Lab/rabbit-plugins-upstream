## Description:

Use when medium-to-large changes need explicit requirements, technical design, and task planning before implementation, especially for multi-module work, unclear acceptance criteria, or architecture-heavy requests.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to turn medium-to-large or unclear implementation requests into explicit requirements, a technical design, and an implementation task plan before coding.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Planning documents may encode incomplete or incorrect requirements for larger changes.

Mitigation: Review and confirm requirements, design, and task plan before implementation, keeping generated specs visible under specs/.

Risk: The workflow may add planning overhead for small, precise tasks.

Mitigation: Apply it to medium-to-large or unclear work and skip the full workflow when scope and acceptance criteria are already clear.
