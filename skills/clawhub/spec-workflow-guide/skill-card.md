## Description:

Guides developers through requirements, technical design, and task planning before medium-to-large or ambiguous implementation work.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to turn complex or unclear change requests into confirmed requirements, a technical design, and traceable implementation tasks before coding.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Staged planning can slow larger requests before implementation begins.

Mitigation: Use the full workflow for substantial or unclear work, skip it for small clear changes, and confirm each phase with the user.
