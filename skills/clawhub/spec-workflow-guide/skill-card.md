## Description:

Use when medium-to-large changes need explicit requirements, technical design, and task planning before implementation, especially for multi-module work, unclear acceptance criteria, or architecture-heavy requests.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineering teams use this skill to decide when a larger change needs explicit requirements, design, and task planning before implementation. It guides agents through staged specification documents and confirmation points for multi-module, unclear, or architecture-heavy work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow can slow larger coding requests by requiring requirements, design, and task planning before implementation.

Mitigation: Use it for medium-to-large or unclear work, and skip the full workflow for small, low-risk changes with clear acceptance criteria.

Risk: The skill may create planning files in the repository.

Mitigation: Review the generated requirements, design, and task files before implementation and keep them scoped to the requested change.
