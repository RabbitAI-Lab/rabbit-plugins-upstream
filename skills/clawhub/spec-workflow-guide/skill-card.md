## Description:

Guides agents through explicit requirements, technical design, and task planning before medium-to-large software changes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT

## Use Case:

Developers use this skill to turn larger or ambiguous change requests into reviewable requirements, design decisions, and implementation tasks before writing code.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Unreviewed planning documents could steer later implementation toward incorrect requirements.

Mitigation: Review and confirm requirements, design, and tasks with the user before implementation.
