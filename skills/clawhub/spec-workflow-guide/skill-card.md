## Description:

Use when medium-to-large changes need explicit requirements, technical design, and task planning before implementation, especially for multi-module work, unclear acceptance criteria, or architecture-heavy requests.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering agents use this skill to structure medium-to-large implementation work into requirements, design, tasks, and confirmed execution steps before code changes begin.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow can add planning overhead to coding requests that are already small and well specified.

Mitigation: Use the skill's decision rule to skip the full workflow for small, low-risk, precise tasks.

Risk: The skill may create visible requirements, design, and task files in the project.

Mitigation: Confirm the intended spec name and review generated planning files before implementation begins.
