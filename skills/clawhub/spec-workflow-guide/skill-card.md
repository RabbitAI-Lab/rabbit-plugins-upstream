## Description:

Use when medium-to-large changes need explicit requirements, technical design, and task planning before implementation, especially for multi-module work, unclear acceptance criteria, or architecture-heavy requests.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT

## Use Case:

Developers use this workflow to clarify acceptance criteria and plan medium-to-large changes before implementation. It structures work into requirements, design, tasks, and a confirmed execution plan.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: When an optional planning dependency is missing, setup guidance may direct users to unrelated CloudBase setup.

Mitigation: Check whether the planning guidance and CloudBase setup apply to the task, and review setup instructions and configuration changes before following them.
