## Description:

Guides agents through requirements, design, and task planning before implementing medium-to-large development changes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT

## Use Case:

Developers and engineering teams use this skill to define testable requirements, design an approach, and agree on implementation tasks for complex or cross-module changes before coding.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The staged workflow can delay implementation and create planning documents in the project.

Mitigation: Use it for larger or unclear changes, confirm each planning phase, and review the proposed documents before implementation.
