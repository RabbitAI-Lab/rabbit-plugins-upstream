## Description:

Guides agents through requirements, technical design, and task planning before implementing medium-to-large software changes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT

## Use Case:

Developers and engineers use this skill to define acceptance criteria, review a technical design, and plan traceable implementation tasks for complex changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The staged workflow can slow larger coding tasks and add specification files to the workspace.

Mitigation: Use the full workflow only when the change warrants it, and review each document before moving to the next phase.
