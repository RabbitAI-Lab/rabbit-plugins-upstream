## Description:

Use when medium-to-large changes need explicit requirements, technical design, and task planning before implementation, especially for multi-module work, unclear acceptance criteria, or architecture-heavy requests.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers and engineering teams use this skill to structure medium-to-large implementation work into requirements, design notes, task plans, and confirmed execution steps before changing code.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill intentionally slows larger implementation requests into requirements, design, and task-confirmation phases.

Mitigation: Review the generated spec files and approve the task plan before allowing implementation.
