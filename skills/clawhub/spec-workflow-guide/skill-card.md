## Description:

Use when medium-to-large changes need explicit requirements, technical design, and task planning before implementation, especially for multi-module work, unclear acceptance criteria, or architecture-heavy requests.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

## Use Case:

Developers use this workflow to define requirements, design, and reviewable tasks for medium-to-large changes before implementation begins. It structures the work in phases and calls for confirmation of the task plan before execution.

Global
