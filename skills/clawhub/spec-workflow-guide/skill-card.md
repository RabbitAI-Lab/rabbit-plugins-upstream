## Description:

Guides agents through requirements, design, and task planning before implementing medium-to-large changes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to clarify acceptance criteria, agree on a technical design, and plan reviewable tasks before complex implementation work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Planning documents may capture incorrect requirements or an unsuitable design.

Mitigation: Review and confirm each planning phase before implementation.

Risk: The workflow writes planning files in the workspace.

Mitigation: Review the generated files and task plan before approving implementation.
