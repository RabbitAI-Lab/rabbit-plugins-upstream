## Description:

Guides agents through requirements, technical design, and task planning before medium-to-large code changes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agents use this workflow to agree on requirements, design, and actionable tasks for larger or unclear software changes before implementation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The staged workflow can slow larger implementation requests.

Mitigation: Use the full workflow for substantial or unclear changes; proceed directly when the request is small, low-risk, and already precise.
