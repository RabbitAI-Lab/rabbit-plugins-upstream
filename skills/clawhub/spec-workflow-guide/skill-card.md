## Description: <br>
Use when medium-to-large changes need explicit requirements, technical design, and task planning before implementation, especially for multi-module work, unclear acceptance criteria, or architecture-heavy requests. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[binggg](https://clawhub.ai/user/binggg) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineering teams use this skill to turn medium or large implementation requests into explicit requirements, technical designs, and traceable task plans before code changes begin. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The workflow can add planning overhead or produce requirements, design, and task documents that do not match the user's intended scope. <br>
Mitigation: Confirm requirements, design, and task breakdowns with the user before implementation, and keep generated planning documents concise and traceable. <br>
