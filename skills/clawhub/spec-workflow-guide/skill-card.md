## Description:

Guides developers through requirements, technical design, and task planning before implementing medium-to-large changes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT

## Use Case:

Developers use this skill to clarify acceptance criteria, review a technical design, and plan traceable tasks before implementing larger or cross-module changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Unreviewed requirements or design could misdirect subsequent implementation.

Mitigation: Confirm requirements, design, and task plan with the user before progressing to implementation.
