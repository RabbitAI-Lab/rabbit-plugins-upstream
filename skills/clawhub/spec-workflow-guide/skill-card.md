## Description:

Guides developers through requirements, technical design, and task planning before implementing medium-to-large software changes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[binggg](https://clawhub.ai/user/binggg)

### License/Terms of Use:

MIT

## Use Case:

Developers use this skill to turn complex or ambiguous feature requests into reviewable requirements, designs, and implementation tasks before coding.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The staged workflow can delay implementation on tasks that do not need extensive planning.

Mitigation: Use the full workflow only for larger or ambiguous changes; proceed directly when scope and acceptance criteria are already clear.

Risk: The workflow may create requirements, design, and task documents in the repository.

Mitigation: Confirm that spec files are wanted and review each phase before proceeding.
