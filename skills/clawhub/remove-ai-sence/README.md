# 去除 AI 味道 · UI 美化 Skill

> 自动扫描项目中的"AI 味道"——紫色配色、Emoji 图标、英文报错暴露——一键替换为专业品牌风格。

## 解决什么问题

用 AI 生成的网页/应用往往带着浓重的"AI 味道"：满屏紫色渐变、按钮上全是 emoji、用户看到的是英文技术报错。这个 Skill 自动检测这些问题并替换为专业的品牌设计风格。

## 快速使用

在 WorkBuddy 对话中输入：

```
帮我去掉这个项目的AI味道
```

或直接说：

```
/de-ai
```

Skill 会自动完成 5 个步骤：

| 步骤 | 动作 | 输出 |
|------|------|------|
| 1. 扫描检测 | 扫描所有前端文件（HTML/CSS/JS/Vue/React） | 检测结果清单 |
| 2. 生成报告 | 生成独立 HTML 检测报告 | `AI味道检测报告_{日期}.html` |
| 3. 一键替换 | 替换颜色、图标、报错处理 | 逐文件修改 |
| 4. 验证 | 语法检查 + 残留检测 | 验证报告 |
| 5. 生成规范 | 输出 UI 规范文件 | `.claude/ui-spec.md` |

## 检测维度

| 类别 | 检测内容 | 严重程度 |
|------|---------|---------|
| **AI 常用色** | 紫色系（`#6366f1` `#8b5cf6` `#a78bfa`等）、霓虹粉、彩虹渐变 | 高 |
| **Emoji 图标** | 按钮/标签/标题中使用彩色 emoji 代替专业图标 | 中 |
| **英文报错暴露** | `catch(e) { alert(e.message) }` 把英文错误直接抛给用户 | 高 |
| **AI 标签**（可选） | "AI 分析""AI 解读""重新AI分析"等表述 | 低 |

## 配色方案

替换时可选 4 种专业配色：

| 方案 | 主色 | 适用场景 |
|------|------|---------|
| **品牌蓝**（默认） | `#3b82f6` | 企业级产品 |
| **青色** | `#0891b2` | SaaS / 工具类 |
| **石板灰** | `#4b5563` | 数据看板 |
| **自定义** | 你指定 | 任意场景 |

## 检测报告示例

Skill 会生成一个精美的 HTML 报告，包含：

- 顶部汇总卡片（各维度检测数量和严重程度）
- 逐文件明细表格（文件、行号、当前值、建议替换值）
- Emoji 替换建议（每个 emoji 对应的 SVG 代码）
- 英文报错修复建议（统一的 `friendlyError()` 函数）
- 底部优先级排序（P0/P1/P2 修复建议和预估工作量）

## 安装方式

在 WorkBuddy 左侧导航栏 → 技能 → 技能市场 → 搜索"去除AI味道" → 安装

### 方式二：上传技能包安装
在 WorkBuddy 左侧导航栏 → 技能 → 添加技能 → 上传技能 → 选择 .zip 包

```bash
git clone https://github.com/moan19921019-code/remove-ai-sence.git
```
将 SKILL.md 放置到技能目录即可。

## 适用场景

- AI 生成的网页/应用需要"去 AI 化"
- 产品上线前做 UI 品牌统一
- 团队建立 UI 设计规范
- 前端项目代码审查中的配色/图标/报错检查

## 技术特点

- **先报告再动手**：扫描后生成报告，用户确认后才执行替换
- **不改变逻辑**：只替换颜色值和文本标签，不修改功能代码
- **逐文件替换**：每改完一个文件立即保存，可随时中断
- **保留语义**：class 名可保留（只改 CSS 值），不破坏 HTML 结构
- **图表特殊处理**：图表中保留 1-2 个紫色作为数据系列色是允许的
