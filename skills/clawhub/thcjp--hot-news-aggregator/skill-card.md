## Description:

Aggregates domestic and international news across society, technology, military, finance, sports, and related categories, then searches, filters, summarizes, deduplicates, and organizes key points for briefings and SEO-oriented workflows.

This skill is ready for commercial/non-commercial use.

## Publisher:

MIT-0

## Use Case:

External users, developers, and automation workflow owners use this skill to request news briefings, topic tracking, public-opinion summaries, industry updates, and structured news exports from user-provided themes, keywords, dates, categories, and language preferences.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may contact external news, social, and API sources using the user's query terms.

Mitigation: Avoid sensitive queries or API keys unless the external services being used are understood and acceptable.

Risk: The skill requests command execution authority broader than a normal news-summary task requires.

Mitigation: Review before installing and run only where shell access and possible file operations are restricted or acceptable.
