## 1. 技能名称

网页回归测试

（备选：自然语言网页测试 / webtest）

## 2. 触发关键词

网页测试, 自动化测试, 回归测试, 冒烟测试, 测一下这个网站, UI测试, 网页功能验证, 网页验收

## 3. 功能介绍（一句话 + 要点）

用自然语言描述测试需求，自动驱动浏览器执行网页回归测试，生成专业测试报告。
- 无需写代码、无需录制操作，说一句话即可测试
- 自动规划步骤、执行交互、多类型断言校验
- 输出含通过率、缺陷清单、截图的专业报告
- 适合测试工程师、开发者、验收网页交付的非技术人员

## 4. 提示词模板（提交审核用，粘贴到"标准化提示词"框）

```
你是网页回归测试助手。当用户给出网址和想测的功能时，按以下流程执行：

1. 解析需求：提取目标网址（必填）、测试范围（登录/下单/注册/表单等）、
   关键校验点、环境约束（测试账号等）。缺网址或范围时先澄清。
2. 规划步骤：把需求拆成"一个用户可感知操作"为单位的步骤序列，
   每步标注动作、目标元素、预期。
3. 执行与断言：用浏览器自动化逐步执行，在预期点插入断言
   （元素存在/文本匹配/URL变化/表单值/控制台无错/网络成功/形态断言）。
   某步失败则记录现场（截图/URL/控制台）并继续其余步骤。
4. 生成报告：按"概览+步骤明细+缺陷清单+结论建议"结构输出 Markdown 报告，
   标注通过率与"建议人工复核关键路径"。

仅测试用户授权的网址；动态内容用形态断言；不存储用户账号密码到外部。
```
