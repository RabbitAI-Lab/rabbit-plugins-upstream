# jd-resume-matcher 导入使用说明

> 版本：1.4.7 ｜ 更新日期：2026-09-06 ｜ 类型：用户级 Skill（提示词型技能，无外部依赖）

## 一、这是什么

「岗位-简历精准匹配分析」技能：同时提供 **JD（职位描述）** 与 **简历** 时，以 15 年经验猎头视角逐项比对，输出结构化 Markdown 匹配分析报告。跨行业适用（智能制造、新能源、半导体、互联网、金融、医疗等）。

报告包含（固定章节顺序）：

1. **招聘截止日期提示**（含已过期 ⏰ 警告 / 临期 ≤7 天提醒 / 未标注时生成向 HR 核实的问题）
2. **红线排查**（学历、年限、证书、技术栈、地点；任一不过 → 整体判定不匹配）
3. **人岗匹配矩阵**（逐条对照，判定档位：完全符合 / 部分符合 / 不符合）
4. **评分与匹配等级**（硬性 60% + 软性 25% + 行业背景 15%，百分制，≥80 高 / 60–79 中 / <60 低）
5. **差距分析与简历优化建议**（每条以「改写理由：为了回应 JD 第 X 条中的『原文』」收尾）
6. **求职意向匹配核查**（意向城市、从事行业、薪资展望、福利待遇、企业前景、晋升渠道；✅/⚠️/❓ 三档）
7. **面试追问预测**（5 个最可能的追问 + 应答思路）

## 二、如何导入

- **本机使用**：将 `jd-resume-matcher` 整个文件夹放入 `~/.workbuddy/skills/` 目录（用户级，所有会话可用），重启会话即可生效。
- **从 zip 导入**：解压 `jd-resume-matcher.zip`，得到 `jd-resume-matcher/SKILL.md` 与本说明，将 `jd-resume-matcher` 文件夹按上述路径放置。

## 三、如何触发

在对话中同时提供 JD 全文与简历全文，并表达以下任一意图即可自动触发：

- 「帮我分析这份岗位和简历的匹配度」
- 「用 JD 分析一下我的简历」
- 「这份 JD 我匹配吗？给个优化建议」
- 「面试准备：针对这个岗位预测面试官会问什么」
- 批量输入话术：「我有 3 份 JD，用我的简历逐份分析并对比哪个最值得投」「这几份简历帮我对着这个 JD 排个序」

也可直接说「使用 jd-resume-matcher 技能」+ 附上材料。

## 四、输入要求

| 输入 | 必需性 | 说明 |
|---|---|---|
| JD 全文 + 简历全文 | 完整匹配分析必需 | 两者齐全时执行标准 8 步流程 |
| 仅 JD | 可选（单边模式） | 输出「岗位要求质量评估」：要求分类、模糊表述问题、维度覆盖度、澄清问题清单 |
| 仅简历 | 可选（单边模式） | 输出「通用简历优化建议」：量化缺失、动词强度、空洞词清理；不针对特定岗位 |
| 简历以文件提供 | 支持 | 文本直接粘贴或 PDF/Word/图片文件均可；文件会先提取文本，失败时提示改用粘贴 |
| 求职意向说明 | 可选 | 期望城市/行业/薪资等；缺失项标注「待确认」并汇入 HR 核实清单 |
| 多份 JD / 多份简历 | 可选 | 支持批量：逐份出完整报告 + 横向对比汇总表 |

## 五、四条纪律约束（质量保证）

1. 禁止「沟通能力强」「团队精神」等空洞表述，结论必须指向具体条目与证据，报告开头禁止寒暄；
2. 所有判定基于 JD 原文的**动词/名词/数字**逐字对照；
3. 每条改写建议必须以「改写理由：为了回应 JD 第 X 条」句式收尾；
4. 偏见防护：判定与评分不受姓名、性别/年龄推断、院校/公司名气等无关信号影响。

## 六、常见误用与 FAQ

**Q1：为什么我的报告没有评分？**
完整匹配分析（JD+简历齐全）必定含评分章节（评分硬门强制）。只有两种情况无分：① 单边输入（仅 JD 或仅简历）——评分需双向对照，设计上不评分；② 红线不通过时评分仍会输出，但整体判定以红线为准。

**Q2：简历没写「全日制」，学历红线会不会直接判不通过？**
不会。简历既无法证实也无法证伪时判「❓ 待核实」，汇入 HR 核实清单，不算红线不通过。禁止把证据不足项硬判 ✅ 或 ❌。

**Q3：「优先考虑」「加分项」的条目会拉低分数吗？**
不会。加分项在矩阵中列示命中/未命中，但不计入加权评分；缺失也不触发红线、不进强制补足清单。

**Q4：JD 里的薪资、公司介绍会影响评分吗？**
不会。非能力类条目照常编号但标注「不计分」，薪资数字仅用于求职意向核查对照。

**Q5：JD 里没提行业背景，15% 权重去哪了？**
按比例归一给其余维度（如硬性 0.6/0.85、软性 0.25/0.85），总分恒为百分制。判定口径详见 `references/example-boundary.md`。

**Q6：技能会编造简历里没有的经历吗？**
不会。简历无对应证据时如实写「简历中未找到对应证据」，无素材可迁移时如实标注「建议通过项目实践/证书补足」。

**常见误用提醒**：
- ❌ 只贴简历不说岗位 → 得到的是通用建议而非匹配分析，想要评分请务必附 JD；
- ❌ 用 JD 摘要/截图替代全文 → 条目编号与逐字对照会失真，请提供完整原文；
- ❌ 把报告中的「❓ 待核实」当成通过或不通过 → 需要向招聘方核实后再下结论。
