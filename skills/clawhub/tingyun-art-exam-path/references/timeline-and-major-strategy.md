# 时间轴倒排、专业梯队策略与权重取舍

> 用途：把"选哪条路"落成"哪天之前必须做什么"，并给出专业与院校的准备策略、统考校考关系、选科覆盖率矩阵与课时分配方法。
> 各省各年规则会调整，节点日期与科目要求须以本省教育考试院当年公告与目标院校当年招生章程为准。

## 一、时间轴倒排方法

### 步骤一：先定终点与终点日期

| 赛道 | 终点 | 终点日期来源 |
|---|---|---|
| 艺考 | 目标省份/院校的专业考试日 | 本省当年专业考试安排与院校校考公告 |
| 体考 | 体育专项测试或体测窗口截止日 | 本省当年体育类考试安排 |
| 强基 | 目标高校校测日（出分后） | 目标高校当年强基招生简章 |

### 步骤二：从终点往回推，标三类节点

| 节点类型 | 定义 | 倒排规则 |
|---|---|---|
| 不可延误项 | 报名截止、资格审核截止、体检截止、专项测试报名截止 | 逐个标出，并额外预留 2 周缓冲 |
| 需前置项 | 集训启动、专项技术打磨、作品集/曲目成型、学科基础重建、面试表达训练 | 按"见效所需时长"倒推，通常 3~6 个月 |
| 可压缩项 | 文化课部分模块复习、部分刷题量、拓展阅读 | 压缩时先压提分效率低且孩子抗拒的部分 |

### 步骤三：算出"必须定赛道"的日期

```
必须定赛道的日期 = 各不可延误项日期中靠前的那个 − 所需前置时长 − 2 周缓冲
```

**示例结构**（日期需按当年实际填写）：

| 倒推顺序 | 节点 | 类型 | 距终点 |
|---|---|---|---|
| 终点 | 目标专业考试日 | — | 0 |
| ← | 打印准考证 / 准备证件材料 | 不可延误 | 约 2 周 |
| ← | 报名截止（资质材料齐备） | 不可延误 | 约 1 个月 |
| ← | 考纲与往届真题研究完成、方向校准 | 需前置 | 约 2~3 个月 |
| ← | 集训/训练启动、作品集成型 | 需前置 | 约 4~8 个月 |
| ← | 决定是否走这条赛道 | 决策点 | 约 5~9 个月 |

### 步骤四：各赛道的差异化节点清单

**艺考时间轴骨架**

| 阶段 | 任务 | 关键提醒 |
|---|---|---|
| 高一 | 硬条件验证期：确认是否有长期专项积累；不急于报长期班 | 这一年决定"是否有作品或成绩可打" |
| 高二上 | 选科与专业清单核对；了解统考科目与合格线 | 选科窗口与专业矩阵同期完成 |
| 高二下 | 若确定走艺考：启动集训或系统训练；建立作品集 | 集训启动时间决定专业课提分空间 |
| 高三上学期末~次年初 | 专业考试（省统考/校考）窗口 | 与高考复习节奏冲突，须提前排 |
| 专业考试后~高考前 | 文化课复课与守线冲刺 | 复课起点决定文化线安全余量 |
| 高考后 | 志愿填报（按各省批次与规则） | 核对投档规则与专业级差 |

**体考时间轴骨架**

| 阶段 | 任务 | 关键提醒 |
|---|---|---|
| 高一 | 专项训练打基础；建立体能与伤病预防体系 | 伤病管理从这天开始，不是从考前开始 |
| 高二 | 专项技术精细化；关注体测项目与规则变化 | 体测项目设置与计分规则各年可能调整 |
| 高三上学期 | 体测报名与资格审核；测试窗口 | 报名截止是不可延误项 |
| 测试窗口前后 | 专项冲刺与恢复调整；单招路径的院校与专业确认 | 恢复与训练的比例要排出来 |
| 测试后~高考 | 文化课主线 + 单招文化备考并行 | 单招文化考试组织方式各省不同 |

**强基时间轴骨架**

| 阶段 | 任务 | 关键提醒 |
|---|---|---|
| 高一~高二 | 学科基础建设；选科确定（强基相关专业对选科有要求） | 学科底子是校测与面试的底盘 |
| 高二下~高三上 | 竞赛与拓展阅读（若目标专业相关）；研究本省实施高校与规则 | 强基各省实施高校范围与名额不同 |
| 高考报名 | 完成高考报名，确认报考资格 | 缺报名即无后续 |
| 高考后出分 | 查目标高校强基简章：校测内容、形式、录取规则、限报要求 | 出分后时间窗很短，务必当天查 |
| 校测报名截止 | 完成报名 | 不可延误项 |
| 校测 | 笔试/面试/体测（按校方设定） | 面试考察学科兴趣与思维表达 |
| 志愿填报 | 按本省规则填报 | 与其他批次的时间关系需确认 |

### 步骤五：把节点落到每周

| 项目 | 设定 |
|---|---|
| 每周总学习时长 | 按孩子实际可支配时间估算，写出数字 |
| 专业课投入 | 集训/训练占多少小时，是否占用课内与晚自习 |
| 文化课投入 | 课内 + 每周固定自习时段 |
| 碎片时间 | 用于专业基础维持（素描、器乐、体能、阅读） |
| 每周复盘 | 固定时段复盘进度与计划偏差 |

**排课原则**：不可延误项永远不占用；文化课的"守线"时段不占用；专业课集中安排在提分效率高的阶段。

## 二、专业与院校梯队的准备策略

### 1. 梯队划分方式

| 梯队 | 含义 | 准备动作 | 风险处置 |
|---|---|---|---|
| 冲刺档 | 位次高于孩子当前较多，需专业表现明显突出 | 提前 6~12 个月启动集训；目标专业与院校的考核内容逐项研究 | 设定检验时点，达不到就降档 |
| 稳妥档 | 位次与当前水平接近，专业表现达标即可 | 正常推进节奏，重点做校考内容与素材准备 | 作为默认落点 |
| 保底档 | 位次要求低于当前较多，或该校该专业在本地招生规模小 | 重点确认招生规模与是否需要额外条件 | 确保基本条件满足（资格、专业限制） |

**注意**：梯队不是志愿顺序的机械排列，真正的依据是"位次 + 专业考核表现 + 该校该专业在本地是否有招生名额"。三者在不同省份、不同院校差异很大。

### 2. 院校梯队要看的四类信息

| 信息 | 为什么重要 |
|---|---|
| 该专业在本省的招生计划数与近年实际录取数 | 名额少则波动大，"进过"不代表"能进" |
| 该专业在本省的录取位次区间 | 判断自己与目标档位的真实差距 |
| 该专业的考核方式（统考折算/校考/综合分算法） | 决定分数之外还要准备什么 |
| 该专业的选科要求与校区地点 | 硬约束，不满足就没有讨论空间 |

### 3. 专业方向选择的三条约束

| 约束 | 说明 |
|---|---|
| 硬约束 | 选科要求、单科成绩要求、体检要求（视力、身高体重等）、招生类型限制 |
| 兴趣约束 | 四年读的是专业内容，不是校名；孩子对课程内容长期抵触是常见退学与转专业诱因 |
| 出口约束 | 该专业方向对应的岗位类型、地域分布、是否需要继续深造；这是外部信息，只能定性了解并注明不确定性 |

## 三、统考与校考的关系（速查）

| 问题 | 回答 |
|---|---|
| 统考是什么 | 省级统一组织的专业考试，多数省份已建立艺术类统考，成绩既用于合格判定，也用于部分院校的投档依据 |
| 校考是什么 | 高校自行或授权组织的专业考试，是部分院校（尤其专业特色强、单独招生）的主要通道 |
| 二者关系 | 多为先后关系而非替代关系：不少院校的校考报名要求提供统考成绩或统考合格证明 |
| 谁的权重更大 | 因省份、因院校、因专业而异；同一专业在不同省份可能按统考投档，也可能统考+校考综合排序 |
| 政策趋势 | 多省在推进艺术类统考覆盖与校考缩减，具体到本省本专业的口径必须查当年文件 |

**操作四步**：
1. 查本省当年艺术类专业统考科目与合格线要求
2. 查目标院校当年是否组织校考、考什么、录取怎么折算
3. 查该院校该专业在本省的近年录取数据（位次区间、录取人数）
4. 把三者合成一个准备策略：统考过线是门，校考是上行通道，志愿填报是收口

## 四、选科覆盖率矩阵（高一必做）

### 步骤

1. 列出意向专业清单 10~15 个（可先按学科方向粗筛）
2. 逐个查该专业在**本省**的选科要求
3. 标三档：能报 / 需调整选科 / 不能报
4. 反向统计：当前选科组合下能报的专业总数与层次分布
5. 算重合度：能报的专业中，有多少在孩子意向清单里

### 常见组合的覆盖倾向（以本省目录为准）

| 选科组合特征 | 覆盖倾向 | 典型受限方向 |
|---|---|---|
| 含物理且含化学 | 相对宽 | 医学临床类、部分工科、理科专业多集中于此 |
| 含物理但不含化学 | 收窄 | 部分工科、农医类专业 |
| 不含物理 | 理工农医类基本关闭 | 文科类、财经、传媒、语言、教育、法学等 |
| 含生物 | 增加医学类、生物类部分专业机会 | 具体以专业目录要求为准 |

**关键提醒**：选科窗口通常在高一结束前关闭，一旦定下改动成本很高。**做矩阵的时间点是高一，不是高三。**

## 五、文化课与专业课的权重取舍

### 1. 文化课目标的算法

```
文化课目标分 ≈ 目标院校该专业在本省近年录取位次区间的下限对应分数
             （按当年一分一段表换算，并按本省艺体类科目的录取规则调整）
```

**文化线是一票否决项**：多数省份对艺术类、体育类单列文化控制线（有的按普通类相应线的一定比例划定，有的单独划线），过不了线，专业成绩再高也进不了投档环节。

### 2. 专业投入的边际效率窗口

| 阶段 | 专业课提分效率 | 建议 |
|---|---|---|
| 前 3~6 个月集训期 | 上升较快 | 集中投入，打基础与突破 |
| 中期 | 趋稳 | 维持 + 针对性补短板 |
| 考前 1~2 个月 | 提升空间有限 | 转向稳定发挥、状态调整、文化课补漏 |

### 3. 每周课时分配模板（按孩子实际填写）

| 时段 | 周一至周五 | 周六 | 周日 | 每周合计 |
|---|---|---|---|---|
| 课内 | 正常上课 | — | — | — |
| 专业课集训/训练 | 每日 X 小时 | X 小时 | X 小时 | X 小时 |
| 文化课自习 | 每日 Y 小时 | Y 小时 | 休息或补弱 | Y 小时 |
| 碎片时间专业练习 | 每日 20 分钟 | — | — | — |
| 复盘 | 30 分钟 | — | 60 分钟 | — |
| 合计可支配学习时长 | | | | 与孩子确认后的实际可支配时长对比 |

**校验**：专业课时长不能挤压文化课守线时段；若挤压，先减少专业课而非文化课。
