# 成本估算、常见陷阱与决策清单

> 用途：把"走这条路要花多少、能得到什么、失败了怎么办"落成可以当场算、可以当场签字的表。
> 所有金额与比例均为估算口径，须以目标院校当年公开收费口径与本省当年公告为准。

## 一、学费与投入产出估算表

### 1. 前期投入（进考场之前）

| 项目 | 艺考 | 体考 | 说明 |
|---|---|---|---|
| 集训/训练课时费 | 通常是大头，按阶段与班型差异大 | 按训练队/俱乐部/体校口径差异大 | 问清楚是按课时、按期还是按学期 |
| 材料与耗材 | 颜料、画材、服装、道具、乐器配件 | 训练装备、护具、鞋服 | 美术耗材是长期消耗，容易被低估 |
| 器械与乐器 | 乐器购置与维护、琴弦与松香 | 专项装备更换 | 大件一次投入，按使用年限摊 |
| 考级与比赛报名 | 证书、比赛、考级费 | 赛事、等级证书 | 是否对报考有用需先确认 |
| 考试相关 | 统考/校考报名费、跨省差旅与住宿 | 体测与专项测试报名、体检费 | 校考跨省比例高时，差旅住宿可累积到数千至上万元 |
| 训练场地与器材 | 画室租用、模特写生 | 场地、器械、康复理疗 | 写生、集训场地费常被漏算 |
| 家长陪护与往返 | 集训期接送、跨省陪同 | 训练接送、比赛外出 | 误工成本按家庭实际估算 |

### 2. 在读阶段（四年总投入）

| 项目 | 说明 |
|---|---|
| 学费 | 目标院校该专业年学费 × 4；艺术类专业普遍高于普通专业 |
| 住宿费 | 住宿标准与实际住宿年限（大一到大四是否住校） |
| 生活费 | 按孩子所在城市与家庭实际水平估算 |
| 教材与专业耗材 | 美术材料、乐器耗材、训练装备更换等 |
| 证书与实习相关支出 | 部分方向需要额外投入 |

**四年总投入 = 前期投入 + （学费 + 住宿 + 生活费 + 其他）× 4 + 复读风险准备**

### 3. 三个决策问题（比"哪个专业赚"更有用）

| 问题 | 判断依据 |
|---|---|
| 家庭能否承受四年总投入，且不依赖某一笔将到期的收入？ | 把四年总账做成现金流，逐月对齐家庭收入节奏 |
| 孩子的能力与性格是否支持读完，而不只是考进去？ | 看课程内容兴趣、训练耐受度、过往长期投入的坚持情况 |
| 若这条路在第二年没走通，家庭有无 Plan B？ | 写出 Plan B 的具体路径与切换时点（转专业方向、转向普通类文化课、转向体考单招、延后一年） |

### 4. 投入产出比的三段式表达

```
投入产出比（自述口径，不用单一数字）：
  投入侧：前期投入 + 四年总投入 + 隐性成本（陪护误工、课内时间占用、伤病治疗）
  产出侧：录取概率区间 × 该专业在本省的录取层次分布 × 学制年限
  风险侧：失败后已沉没的投入占比、切换到 Plan B 所需额外时间
```

**表述纪律**：产出侧只能给区间与构成，**不给确定性结论**，也不做职业收入预测。涉及就业与收入的部分只做定性描述，并注明属于外部不确定信息。

## 二、常见陷阱清单

| 编号 | 陷阱 | 典型表现 | 识别方法 | 应对动作 |
|---|---|---|---|---|
| T1 | 报了考不上 | 按"通过率"宣传、口头承诺包过、只推热门专业 | 追问统计口径：分母是什么、是哪一年、哪个省、什么专业；要求近两年本省本专业实际录取数据 | 无口径的数据一律不作依据；只认公开录取数据 |
| T2 | 考上了读不起 | 只谈录取不谈收费、只讲首年学费 | 按目标院校公开收费口径算四年总账 + 前期投入 | 把四年总投入作为决策门槛，事先定上限 |
| T3 | 集训后文化课断档 | 集训占满一年，复课时知识点生疏 | 把"复课后提分效率"写进集训方案考核项 | 复课起点与文化线目标同步倒排 |
| T4 | 校考与统考两头落空 | 只准备校考内容，忽视统考合格线 | 查清本省统考科目与合格线要求 | 统考过线设为阶段性里程碑 |
| T5 | 选科没做矩阵 | 高三发现想报专业要求物理或化学 | 高一做完 10~15 个专业的选科覆盖矩阵 | 高一一次锁死，不拖到高三 |
| T6 | 体考伤病被当成小概率 | 加量训练无保护与恢复安排 | 把伤病与康复期写进成本表与时间轴 | 训练量阶梯化、预留恢复周期与康复预算 |
| T7 | 强基当降分捷径 | 只算降分幅度，不看校测竞争 | 查校测内容、形式与录取规则 | 把校测准备与面试表达训练排进高三上学期 |
| T8 | 孩子意愿与家庭期待错位 | 用"孩子想走"覆盖硬条件不成立 | 四证据逐条核对，输出三档结论 | 先做意愿对齐，再谈资源投入 |
| T9 | 名额型风险被忽视 | "这个专业年年都有人进" | 查该专业在本省招生计划数与实际录取数 | 名额少的专业不能作为稳妥档 |
| T10 | 只比院校层级，不比专业出口 | 冲高院校但专业内容完全不接受 | 查课程设置与该方向岗位类型 | 专业兴趣与出口约束列为硬条件之一 |
| T11 | 复读准备不足 | 前期投入全部押上，无备用 | 预算中预留复读准备项 | 预留额与家庭承受力一起核对 |
| T12 | 把机构话术当政策 | 用培训机构的口径解释招生规则 | 只认考试院公告与高校招生章程 | 政策口径来源分级：主管部门文件 > 高校章程 > 机构解读 |

### 3.4 家庭当场回答的决策项

1. 主攻哪条赛道？备选是哪条？
2. 若主攻赛道在某个日期前未达标，切到哪条？切换动作由谁执行？
3. 每月可投入的资金上限是多少？
4. 四年总投入的上限是多少？超出后怎么办？
5. 孩子本人是否认可这条路径？他/她担心什么？
6. 是否接受"专业优先于院校层级"的选择？边界在哪里？

8. 下一个复盘日期定在哪天？用什么指标判断继续还是切换？

## 四、执行与复盘机制

| 周期 | 动作 | 判据 |
|---|---|---|
| 每周 | 复盘课时执行、进度偏差、状态（体力与情绪） | 偏差超 20% 就要调整计划，而不是硬撑 |
| 每月 | 更新三赛道对比表与概率区间；检查不可延误项是否临近 | 临近的不可延误项立刻确认材料与状态 |
| 每阶段 | 检验时点评估（专业水平、位次、文化线安全余量） | 达标则升级路径；不达标则切换或降档 |
| 每学期 | 重算成本与投入产出；复核 Plan B 是否仍然可行 | Plan B 不可行时立即启动新方案设计 |

**复盘的纪律**：切换决策看的是"检验指标"，不是"情绪"。指标不动，情绪再焦虑也不改变路径；指标动了，就按预设的切换动作执行，不临时加码。
