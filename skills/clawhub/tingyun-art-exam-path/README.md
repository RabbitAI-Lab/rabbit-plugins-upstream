# 艺考体考强基路径规划顾问

> 为高三家庭选赛道做规划辅助：输出艺考、体考、强基三条赛道的适配判断、备考时间轴倒排、专业院校梯队策略、选科覆盖率、文化课与专业课权重取舍、学费投入产出估算与常见坑。不替代招生部门认定，需人工复核。技术触发词「赛道选择、备考时间轴倒排、专业院校梯队规划」。口语触发词「孩子文化课弱但美术有天赋。省统考和校考到底哪个决定能不能上、从现在到考试，文化课和专业课的时间怎么分、孩子想走强基，但理科成绩刚好压线。校测该准备什么」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

艺考体考与特殊招生路径规划顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 我孩子高一在读，理科中等偏上，钢琴十级、体育一般。我该现在定艺考、体考还是强基？请给我三条赛道的对比和时间轴倒排
- 孩子文化课弱但美术有天赋。省统考和校考到底哪个决定能不能上？各自筛的是什么？
- 新高考选科我家孩子选了物理化学生物。哪些专业还能报、哪些被卡住了？给我一张覆盖率对照
- 从现在到考试，文化课和专业课的时间怎么分？给我一份按周排的课时分配，不要泛泛而谈
