# 投标方案素材库

本目录用于存放投标技术方案编写过程中可复用的素材和参考资料。素材库不是必须的——没有素材时 Skill 也能正常工作，但提供素材可以显著提升生成内容的质量和一致性。

## 目录结构

```
material-lib/
├── README.md                    # 本文件
├── company-capabilities.md      # 公司技术能力描述（可选）
├── 浩程--年度安全运营服务方案-模板.docx  # ★ 浩程安全服务完整模板（原始Word）
├── 浩程--年度安全运营服务方案-模板.md    # ★ 浩程安全服务完整模板（Markdown）
├── 浩程--年度安全运营服务方案-模板.meta.json  # 模板元数据
├── past-projects/               # 历史项目技术方案节选（可选）
│   └── 示例-XX项目-安全服务方案.md
└── chapter-examples/            # 章节写作范例（可选）
    ├── 示例-需求分析范例.md
    ├── 示例-服务方案范例.md
    ├── 示例-技术方案范例.md
    ├── 示例-实施方案范例.md
    ├── 示例-培训方案范例.md
    └── 示例-售后服务方案范例.md
```

## 使用方式

### 1. 自动引用

AI 在生成每个章节时，会自动在素材库中搜索匹配的文件名，并将内容作为写作参考注入到生成提示词（prompt）中。

**匹配规则**：文件名包含章节关键词即可。例如：
- 生成"服务方案"章节 → 匹配 `*服务方案*范例*.md`
- 生成"技术方案"章节 → 匹配 `*技术方案*范例*.md`
- 生成"实施方案"章节 → 匹配 `*实施*范例*.md`

### 2. 手动导入

用户可以通过以下方式导入素材：

```
投标素材导入 <文件路径>
```

AI 会：
1. 读取文件内容
2. 识别文件类型（公司能力 / 历史方案 / 章节范例）
3. 存入对应的子目录
4. 确认导入成功

支持的格式：`.md`（推荐）、`.txt`

### 3. 公司能力描述

`company-capabilities.md` 是特殊文件，AI 会在所有章节生成时自动引用。建议包含：

- **公司概况**：公司简介、资质证书、行业地位
- **技术栈**：掌握的核心技术和产品
- **方法论**：项目管理和服务交付方法论
- **服务能力全景**：提供的安全服务范围
- **团队实力**：技术人员规模、认证情况

## 文件格式建议

### 章节范例文件

每个范例文件建议包含：

```markdown
# [章节名称] 范例

## 写作说明
简要说明该章节的写作要点和常见陷阱。

## 范例内容
以下是完整的章节范例内容（可节选关键部分）：

### [小节标题]
……

## 注意事项
- 不要照搬范例内容，需结合具体项目调整
- 注意替换公司名称、项目名称等特定信息
- 确保内容与评分标准对应
```

### 历史项目文件

```markdown
# [项目名称] - [方案类型]

## 项目信息
- 客户：XX集团
- 时间：2025年
- 类型：安全服务类
- 中标金额：XXX万元

## 方案亮点
- 亮点1
- 亮点2

## 技术方案节选
（在此粘贴方案中的关键技术描述部分）
```

## 注意事项

1. **脱敏处理**：导入历史方案前，请移除敏感信息（客户真实名称、具体金额、内部成本数据）
2. **版权注意**：仅导入本公司自有方案内容，不要导入竞品方案
3. **定期更新**：建议每个季度更新素材库，保持内容时效性
4. **不要依赖**：素材库是辅助工具，不是必需依赖。没有素材时 AI 仍能正常生成
