# Agent 协作手册 — 人机坐标传递的标准动作

> 读者：执行本技能的 Agent。
> 目的：把「人 → Agent 的位置信息传递」做成一套标准动作——何时发起、怎么措辞、怎么处理取消、拿到坐标后做什么。

---

## 零、开始取坐标之前：先领授权

三个出坐标的脚本（`uia.ps1` / `grid.ps1` / `pick.ps1`）都受授权闸门保护，**没有授权会直接返回 `NO_PERMIT`**。所以一次"取坐标任务"的第一步永远是：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<skill目录>\scripts\license.ps1" -Action locate
```

- 返回 `ok:true` → 拿到授权，可以开始定位
- 返回 `error.code = PAYMENT_REQUIRED` → 免费额度用完，**停下来告诉用户**该付多少钱（用 `bill.amount`），等用户确认支付完成再重试；在用户确认之前不要执行任何定位动作
- 返回 `error.code = NETWORK` → 检查网络，稍后重试

**一次授权覆盖整个取坐标过程**：中途失败重试、或从自动档换到人工档，都不重复计费；只有成功拿到坐标才算消费。所以**不要**在每个脚本前面都调一次 `license.ps1`——一个目标一次即可。

## 一、两条使用策略（先选对路径）

| | 策略 A · 默认省流 | 策略 B · 自动优先 |
|---|---|---|
| 适用场景 | 高频交互（大量按钮、页面跳转、重复操作）；界面固定、会反复操作 | 用户不在场（无人值守）；低频一次性操作 |
| 第一步 | 领授权 → 直接发起拾取（pick.ps1） | 领授权 → 先自己找（uia.ps1 → capture+grid） |
| 人参与 | 有（一步，3 秒） | 尽量无；实在不行且用户在场时才发起拾取 |
| 核心收益 | 省掉整段截图/识别流水线，像素级准 | 不打扰人也能完成任务 |

**判断口诀**：界面会反复点 → 先标定；就点一次、能自动找到 → 先自动；自动找不到且人在 → 人一指。

> 注意：坐标复用（下一节）能省下的是**重复定位的时间**，但每次取新坐标仍需一次授权。已经记在任务上下文里的坐标直接使用，不需要再领授权。

---

## 二、坐标复用（省流价值的核心）

- 同一界面上标定过的坐标，**记入任务上下文**（如：`微信4.0 主面板 发送按钮 = (1523, 882)`）
- 后续同界面操作直接用记录值，**不再重复定位**，也不必再请用户点击
- 界面改版、分辨率变化、窗口位置移动后，记录值可能失效——失效特征是点击后无响应或行为异常，此时重新走一遍定位，并更新记录
- 框选（`-Mode rect`）适合标定"一块区域"，点选（`-Mode point`）适合标定"一个按钮"

---

## 三、发起拾取的标准话术

**调用前必须先向用户说明并征得同意**，推荐话术：

> 我需要在屏幕上精确定位〔目标名称〕。马上会弹出一个取景层（不影响你正常操作鼠标），
> 请把鼠标移到〔目标名称〕上**点击一下**即可；右键或 ESC 取消。

变体：

- 框选：「请按住左键，框选〔区域名称〕的范围后松开。」
- 多个点位：「我会依次请你标定 N 个位置，每次点击后我会记录并继续。」

**禁止**：不打招呼直接弹出全屏遮罩；连续发起多次拾取而不解释原因。

---

## 四、超时与取消的处理

| 返回 | 含义 | Agent 应该做什么 |
|---|---|---|
| `ok: true` + `points` / `rect` | 用户已点选/框选 | 立即记录坐标 → 告知用户 → 按产出规范执行 |
| `ok: false`, `error.code = CANCELED` | 用户右键/ESC 取消，或超时 | **不要重试**。询问用户是取消任务还是换一种方式 |
| 超时无响应（用了 `-TimeoutMs`） | 用户可能离开了 | 暂停任务，等用户回来再继续 |

- 拾取调用建议始终带 `-TimeoutMs 60000`
- 用户取消属于**正常结果**，不是故障，不应自动重试或换姿势反复弹窗

---

## 五、坐标回流后的标准动作

1. **告知**：「已取到坐标 (1523, 882)，准备执行〔动作〕。」
2. **确认**：真实点击前再次确认。可用 `act.ps1 -DryRun` 预演落点，或直接问用户「现在点击吗？」
3. **执行**：`act.ps1 -Action click -X 1523 -Y 882`
4. **验证**：执行后确认结果（界面是否有预期响应）；异常则回到定位环节
5. **记录**：把「界面 + 元素 + 坐标」记入上下文，供后续复用（见第二节）

---

## 六、产出规范：把坐标翻译成代码

向用户交付定位结果时，按用户使用的框架**主动附上可运行代码片段**（坐标以实际返回为准，示例 1523, 890）：

```
Python (pyautogui):   pyautogui.click(1523, 890)
AutoHotkey:           Click, 1523, 890
PowerShell:           Add-Type -AssemblyName System.Windows.Forms; [System.Windows.Forms.Cursor]::Position = New-Object System.Drawing.Point(1523, 890)
Selenium/Playwright:  用 moveByOffset 相对偏移，或优先改用页面元素定位
```

用户未指定框架时默认 Python（pyautogui），并附一句「需要其他框架的版本告诉我」。

---

## 七、安全与隐私底线

- 本技能**纯本机运行、不联网**；截图只落在 `%TEMP%\screen-coord-locator\`，**不上传、不外发**
- 调用 `pick.ps1` / `act.ps1`（真实动鼠标）前，必须让用户知晓并同意
- 涉及密码、聊天记录等敏感内容的截图，提醒用户及时清理临时目录，且不得发送给任何第三方
