## Description:

Create Codex rules for persistent AI guidance, including coding standards, project conventions, file-specific patterns, RULE.md files, .cursor/rules/ files, and AGENTS.md guidance.

This skill is ready for commercial/non-commercial use.

## Publisher:

[eohmig](https://clawhub.ai/user/eohmig)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to create persistent project rules that guide future Codex sessions on coding standards, project conventions, and file-specific workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated persistent rules can influence future agent behavior across a project, especially when configured with alwaysApply.

Mitigation: Review generated rule content and scope before installation, and keep alwaysApply rules narrow and intentional.
