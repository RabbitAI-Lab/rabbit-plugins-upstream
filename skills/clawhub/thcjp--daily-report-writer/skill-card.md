## Use Case:

Employees, independent developers, and teams use this skill to turn daily work notes, dates, prompts, and style preferences into Markdown daily report drafts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may create local Markdown report files from user-provided content.

Mitigation: Confirm the target filename before writing and review generated reports before sharing or storing them.

Risk: Granting command execution can expand the skill's local effects beyond report drafting.

Mitigation: Avoid granting command execution unless a specific report workflow truly requires it.
