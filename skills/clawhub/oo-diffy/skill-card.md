## Description:

Diffy (diffy.website). Use this skill for ANY Diffy request — searching and reading data. Whenever a task involves Diffy, use this skill instead of calling the API directly.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and other Diffy users use an OOMOL-connected account to search and read visual testing projects, comparisons, and screenshot results through the oo CLI.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A missing dependency can trigger an unverified online installer without explicit user approval.

Mitigation: Install a verified oo CLI separately, or require approval before any downloaded installer runs.

Risk: Connecting Diffy gives OOMOL access to the connected account.

Mitigation: Use an account with appropriately limited access.
