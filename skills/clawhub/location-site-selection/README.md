# 餐饮选址决策与 ROI 分析系统 v3.0.0

> 资深商业地产数据分析师视角的餐饮商铺量化评估与决策工具。融合 Reilly 零售引力定律、Hotelling 区位模型、TQI 客流质量指数与 GIS 逻辑，**深度联动地图 MCP** 采集人流量代理、竞品分布、消费水平与商业密度，输出数据驱动的品类选址建议，以及**面向决策人的专业 Markdown 报告**（含可视化）。

- **类别**：商业地产 / 餐饮选址 / 投资测算 / 地图数据分析
- **作者**：WorkBuddy

## 核心能力

- **地图 MCP 数据采集（v3.0）**：调用地图 MCP（如腾讯地图 MCP）测量目标区域人流量代理、评估周边商圈价值（竞品分布 / 消费水平 / 商业密度）、获取路网可达性；未连接时降级为人工估算并明确标注。
- **Reilly 零售引力定律**：计算断裂点（Breaking Point）与核心商圈半径、有效捕获面积（Catchment Area）。
- **TQI 客流质量指数**：可视衰减因子（按门头角度）+ 阻抗因子（台阶/隔离带/挑高低/柱头/停车难），将"通过人流"折算为"进店人流"。
- **Hotelling 区位模型**：基于竞品距离与规模测算分流率，量化竞争影响。
- **三情景财务 + 蒙特卡洛简化**：乐观(+20%) / 中性 / 悲观（含竞争分流），输出回本周期**置信区间**与风险等级。
- **数据驱动品类推荐（v3.0）**：基于商圈类型 / 消费水平 / 商业密度 / 竞争强度 / TQI / 合规硬伤，输出餐饮品类评分排序与回避清单（绿/黄/红）。
- **Red Flag 终止**：命中消防 / 排烟 / 产权 / 排污硬伤直接判定 `Project Termination`。

## 输入

强制结构化 JSON（位置 / 客流 / 竞争 / 财务），详见 `SKILL.md`。也支持自然语言描述，由 AI 抽取为 JSON 后自动测算；`competition[]` 可由地图 MCP 周边搜索自动填充。

```json
{
  "project": "新店001",
  "category": "正餐",
  "location": {
    "scale_sqm": 150, "visibility_angle": 45,
    "foot_traffic": {"weekday_noon": 2500, "weekday_night": 800, "weekend_avg": 1800}
  },
  "competition": [{"name": "竞品A", "distance_m": 50, "scale_sqm": 150}],
  "financials": {
    "rent_monthly": 50000, "deposit_terms": "3押1付", "renovation_cost": 300000,
    "avg_check": 45, "cogs_ratio": 0.35, "opex_ratio": 0.25
  }
}
```

可选 `map_data.json`（地图 MCP 采集结果）配合 `report_generator.py --map-json` 注入商圈价值与竞品分布。

## 输出：决策人 Markdown 报告（七节）

1. **决策摘要**：综合裁定（红/黄/绿）+ KPI 卡 + 核心结论
2. **地图数据勘察**：商圈价值、竞品分布、消费水平、商业密度、可达性
3. **商圈与客流**：Reilly 断裂点、TQI、客流漏斗可视化
4. **竞争态势**：逐竞品分流表 + 综合分流率
5. **财务预测**：三情景表 + 回本区间条形（12 月安全线 / 24 月警戒线）
6. **品类选址建议**：评分排序 + 决策象限
7. **行动清单**：推进 / 签约前条件（谈判筹码）/ 否决项

## 安装 / 使用

- 本包解压后放入 `~/.workbuddy/skills/restaurant-site-selection-roi/` 即生效。
- 对话中提到"选址 / 雷利定律 / 商圈吸客力 / 置信区间 / 人流量 / 品类选择 / 选址决策报告"等关键词即触发。
- 连接地图 MCP 后可自动采集空间数据；未连接时按降级策略以人工数据推进。

## 安全与合规

- **地图 MCP 是唯一外部出境通道**：本 Skill 仅在调用地图 MCP（如腾讯地图 MCP）时会把信息发送至地图服务商；所有本地分析脚本仅依赖 Python 标准库，经静态分析确认无联网、无动态执行、无文件外泄代码。
- **出境前显式 opt-in**：首次调用任何地图 MCP 工具前，会明确告知"将把铺位地址/坐标发送至地图服务商"并征得同意；若你拒绝，系统直接进入纯本地降级模式，**不会静默外发**。
- **数据最小化**：仅 `地址 / 经纬度`（地理编码所需）会出境；`财务数据`（租金/装修/客单等）、`合规硬伤`（消防/产权等）、`拟选品类` 一律只在本地参与计算，绝不外发。地图返回的空间数据也仅用于本地分析。
- **宽泛触发不自动出境**：命中"选址 / 人流量 / 竞品"等宽泛词仅用于启动对话与本地分析，不会在取得授权前自动外发位置。

本测算基于行业平均值、空间经济模型与地图结构化数据，结果仅为数据推演，不构成投资承诺；具体经营结果取决于实际运营能力。存在消防 / 环保合规硬伤的商铺，本系统给出一票否决的强硬建议。
