# 选址分析基准库（references/benchmarks.md · Pro v2.0.0）

本文件为 `restaurant-site-selection-roi` (Pro) Skill 的底层数据与公式支撑。数值为全国主要城市
经验区间的**保守中值**，实际请结合城市/商圈能级微调。引擎 `scripts/roi_calculator.py` 直接引用此处常量。

---

## 一、可视衰减因子 Visibility Decay Factor

基于门头可视角度 `visibility_angle`（度），将"被看到的几率"折算为乘性系数：

| 角度 | 系数 | 说明 |
| :--- | :--- | :--- |
| ≤ 30° | 0.70 | 门头严重遮挡，需侧招/凸面镜补救 |
| 30°–60° | 0.70 → 1.00 线性 | 45° ≈ 0.85 |
| ≥ 60° | 1.00 | 主街全展示，可视性优秀 |

公式：`angle<=30 → 0.70；30<angle<60 → 0.70+(angle-30)/30×0.30；≥60 → 1.00`

| :--- | :--- | :--- |
| 台阶 step | 0.85 | 压价/设引流展架 |
| 隔离带 median | 0.70 | 压价/争取过街口 |
| 挑高低 low_ceiling | 0.90 | 压价/重做吊顶 |
| 柱头 pillar | 0.92 | 压价/包柱做展示 |
| 停车难 bad_parking | 0.85 | 压价/争取车位 |

未知标签保守取 ×0.95 并提示。

## 三、品类捕获率 Capture Rate 基准

foot-traffic（有效日客流）→ 进店客单的转化率：

| 品类 | 捕获率 | 备注 |
| :--- | :--- | :--- |
| 快餐 / quick_service | 3%–5% (取 4%) | 高频刚需 |
| 正餐 / dine_in | 1%–2% (取 1.5%) | 决策成本高 |
| 茶饮 / 奶茶 / 咖啡 | 5%–8% (取 6%) | 冲动型消费 |
| 火锅 / hotpot | 1%–2% (取 1.5%) | 目的性消费 |
| 烘焙 / 面包 | 4%–6% (取 5%) | 连带购买 |
| 其他 / 默认 | 2% | — |

中性情景用基准值；悲观情景按 `基准 × (1 − 0.5×综合分流率)` 折减。

## 四、Reilly 零售引力定律

断裂点（自本店 A 起算，km）：
`D_ab = d / (1 + √(S_b / S_a))`
- `d`：A、B 间距（m，引擎内转 km）
- `S_a`：本店吸引力（营业面积 `scale_sqm`）
- `S_b`：竞品吸引力（其 `scale_sqm`）

核心商圈半径 = 各竞品断裂点最小值（受最近强竞品约束）；无竞品默认 1.5 km。
有效捕获面积 = π × 半径²（km²，Buffer Zone）。

> 洞察：当竞品 50m 且规模相当时，断裂点仅约 25m——说明该点位已深陷竞品引力场，
> 自身商圈被极度压缩，是强竞争信号。

## 五、Hotelling 区位模型（竞争分流）

单竞品分流率：
- 距离 < 100m：`0.30 + 0.20×(相对规模−0.5)×2`，规模相当时 0.30，本店大→下探 0.20，竞品大→上探 0.40。
- 100m ≤ 距离 < 300m：由 0.30 线性衰减至 0.05。
- 距离 ≥ 300m：0（忽略）。

综合分流率 = `1 − Π(1 − 单竞品分流率)`，封顶 85%。

## 六、财务与情景模型

- 首期租金 = 月租 × (押 + 付)；解析 `deposit_terms`（如 "3押1付"→押3付1）。
- 总投资 = 装修设备 + 首期租金 + 转让费（可选）。
- 贡献毛利率 `CM = 1 − cogs_ratio − opex_ratio`（opex 已按营收比例计入变动成本）。
- 月固定成本 = 月租（其余随营收变动）。
- 盈亏平衡月营收 = 月固定成本 / CM。
- 三情景营收：
  - 乐观 = 中性 × 1.2（客流 +20%）
  - 中性 = 修正后有效日客流 × 基准捕获率 × 客单 × 30
  - 悲观 = 修正后有效日客流 × 悲观捕获率(含竞争分流) × 客单 × 30
- 月净利润 = 营收 × CM − 月固定成本；回本周期 = 总投资 / 月净利润。
- 置信区间 = [悲观回本, 乐观回本] 月。

**关键假设（透明披露）**：
1. **日曝光放大系数 = 4.0**：将峰期过点人数折算为全交易时段有效曝光人数。
2. **悲观情景竞品分流按 50% 实现**（半实现假设），避免极端化。
3. 中性捕获率不预扣竞争（竞争影响主要体现在悲观情景与谈判筹码）。

## 七、Red Flag 终止清单（一票否决）

`red_flags` 命中以下任一 → **"Red Flag: Project Termination"**，强硬否决：
`no_fume` / `no_vent`（无排烟）、`fire_hazard` / `fire`（消防隐患）、`no_sewage`（无排污）、
`unknow_title`（产权不明）、`illegal`（违建/禁餐）。涉及明火重油烟品类（快餐/火锅/烘焙）无排烟尤其致命。

## 十、消费水平分级（Consumption Tier）

由地图 MCP 业态构成 + 周边房价/租金 proxy + 平均客单估算，分三档：

| 等级 | 判定信号（地图 MCP / 人工） | 适配品类倾向 |
| :--- | :--- | :--- |
| **High** | 高端商场 / 甲级写字楼 / 豪宅区；周边客单通常 >¥80 | 正餐、火锅、烘焙（溢价空间大） |
| **Medium** | 普通商场 / 社区底商 / 综合街区；客单 ¥40–80 | 全品类均衡 |
| **Low** | 城中村 / 学校周边 / 低价街区；客单 <¥40 | 快餐、茶饮（低价高频刚需） |

> 溢价品类（正餐/火锅/烘焙）在 Low 档需折价；刚需品类（快餐/茶饮）对各档不敏感。

## 十一、商业密度分级（Commercial Density）

以本店为中心 **500m Buffer Zone** 内 POI 计数（地图 MCP 周边搜索可得）：

| 等级 | 阈值（POI 总数 / 餐饮数） | 含义 |
| :--- | :--- | :--- |
| **High** | 总 POI > 200 或 餐饮 > 80 | 曝光基数大，自然客流充足 |
| **Medium** | 总 POI 80–200 或 餐饮 30–80 | 中等曝光 |
| **Low** | 总 POI < 80 或 餐饮 < 30 | 自然客流不足，强依赖目的性消费 |

> 冲动型品类（茶饮/烘焙）对密度最敏感；目的性品类（火锅/正餐）敏感度较低。

## 十三、品类推荐评分矩阵（支撑 category_recommender）

`scripts/category_recommender.py` 的透明评分逻辑（0–100，绿≥70 / 黄 50–69 / 红<50）：

1. **基础适配**：商圈类型匹配 +50，次优 +30；消费水平匹配 +15，偏低 −5。
2. **商业密度**：High +6（冲动/低壁垒品类）或 +3（其他）；Low −6 / −3。
3. **竞争强度**（按品类竞争敏感度 `COMP_SENS` 加权）：
   `penalty = {High:14, Medium:7, Low:0}[competition] × COMP_SENS`
   `COMP_SENS = {茶饮咖啡:1.2, 烘焙面包:1.2, 轻食沙拉:1.0, 快餐:0.9, 正餐:0.8, 火锅:0.7}`
   → 红海中最脆弱的是冲动型低壁垒品类，最抗竞争的是高壁垒目的地品类。
4. **消费溢价**：High 档对 正餐/火锅/烘焙 +5；Low 档对 正餐/火锅 −10。
5. **TQI**：<0.7 −15；<0.8 −8。
6. **合规硬伤**：需排烟品类命中 `red_flags`（排烟/消防/产权等）→ 直接否决（分=5）。

输出：`ranked`（评分排序）、`best`（首选品类）、`avoid`（回避清单）。
