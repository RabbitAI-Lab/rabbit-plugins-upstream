# 净利润断层评分速查表（scoring-rubric）

供 SKILL.md 在执行评分时快速核对数字。所有阈值来自主文件「五、多维度判断框架」，本表为纯数值聚合，不重复叙述逻辑。

---

## 维度 0：时点门禁（前置，不计分，但决定能否打分）

### 0.1 状态机
| 状态 | 条件 | 技术面是否打分 | 能否给 S/A/B/C/D |
|---|---|---|---|
| PENDING | 当前 < T0，或 T0 未收盘 | ❌ 记 N/A | ❌ 禁止 |
| FORMED | T0 收盘且缺口成立，未满 3 日 | ✅ 可打 | ✅ 但须标注「未过 3 日验证」 |
| CONFIRMED | T0 后满 3 日未回补 | ✅ 可打 | ✅ |
| FAILED | T0 收盘无缺口，或 3 日内回补 | ✅ 可打（低分） | ✅ 判 D |

### 0.2 时点字段（必须全部采集）
| 字段 | 计算方式 |
|---|---|
| 披露时刻 | 精确到分钟 |
| 披露时段 | 盘前 <09:25 / 盘中 / 盘后 >15:00 / 非交易日 |
| T0 | 公告后首个交易日（盘后披露 → 次一交易日；盘前披露 → 当日） |
| 缺口判定基准线 | T0 前一交易日**最高价** |
| 形成缺口所需最低开盘涨幅 | (基准线 ÷ T0前一日收盘 − 1) × 100% |
| 涨停封板时的缺口幅度 | (T0涨停价 − 基准线) ÷ 基准线 × 100% |

### 0.3 分数填写禁令
- PENDING 状态下，技术面栏位只能填 **N/A**。
- **严禁**填 0 / 3 / 5 / 10 等任何占位数字。
- **严禁**在 PENDING 状态下输出综合总分。
- **严禁**在 PENDING 状态下使用「不构成净利润断层」「断层无效」等终局表述。

## 维度 1：基本面超预期验证（满分 40，优先级最高）

### 1.1 业绩类型可信度
- 预告：看区间中值 vs 一致预期；窄区间可信度更高。
- 快报：重点看扣非净利润。
- 正式财报：同时验证单季度与累计数据。

### 1.2 超预期量化标准
| 指标 | 合格 | 良好 | 优秀 |
|------|------|------|------|
| 扣非净利润同比增速 | ≥30% | ≥50% | ≥100% |
| 超预期幅度（vs 近90天一致预期） | ≥10% 有效 | ≥20% 显著 | ≥30% 大超预期 |
| 单季度扣非环比增速 | ≥20%（排除基数效应） | — | — |
| 营收增速 vs 净利润增速偏差 | ≤20 个百分点 | — | — |

### 1.3 必算字段（不得省略）
```
非经常性损益金额 = 归母净利润 − 扣非净利润
非经常性损益占比 = 该差额 ÷ 归母净利润 × 100%
扣非增速 vs 归母增速的差值 = 必须在结论中显式解释原因
```
> 媒体标题常用归母增速（如「同比+231%」「扭亏为盈」），但真实经营强度看扣非。两者差额必须自行拆解说明。

### 1.4 业绩质量一票否决（任一命中即判定低质量/伪断层）
- 非经常性损益占比 >30%（出售资产、大额补贴、理财/投资收益、股权处置收益等）。
- 上年同期基数极低（亏损或微利）致同比增速虚高。
- 会计政策变更、减值转回等非经营性因素主导。
- 认可：量价齐升、新品放量、景气上行、产能释放等可持续驱动。

### 1.5 现金流交叉验证（扣分项，非否决项）
- 经营现金流与净利润方向严重背离（净利润大增 + 现金流大额为负）= 质量扣分 + 写入风险提示。
- 扩张期设备/材料企业常见，故不适用一票否决，但必须在结论中显式披露。

## 维度 2：技术面断层确认（满分 30）

### 2.1 缺口形态（硬性条件）
- 缺口成立：**T0** 当日 最低价 > T0前一交易日最高价。
- 幅度分级：弱级 2%~3%｜中级 3%~5%｜强级 >5% 或涨停开盘。
- 类型优先级：连续两日涨停 > 单日涨停 > 大阳线缺口 > 普通高开。

### 2.2 量能配合
- T0 成交量 ≥ 前5日日均 ×1.5 合格；≥ ×2.0 强势。
- 突破后 3 个交易日持续放量；回调缩量 = 筹码稳定。

### 2.3 缺口支撑有效性
- 3 日法则：3 交易日内未回补＝初步有效。
- 5 日确认：5 交易日内未跌破缺口下沿＝正式有效。
- 10 日强化：10 交易日内始终构成支撑＝强有效。
- 回补后重新走强：强度降一级。

### 2.4 不计入缺口判定的因素（重要）
以下因素**不得**用于认定「无缺口」或「断层无效」，只能用于位置评估、赔率计算与仓位调整：
- 前期累计跌幅（深跌反而是底部反转型断层的前置条件）
- 当日收阴 / 下跌
- 板块暴跌、大盘系统性下跌
- 均线空头排列
- T0 之前（财报披露前）的任何 K 线走势

## 维度 3：大盘环境评估（满分 15）

### 3.1 大盘趋势
- 友好：沪深300 / 中证500 / 创业板指 上升或震荡上行，20 日均线向上。
- 中性：横盘震荡，无系统性风险。
- 恶劣：明确下降趋势，20 日均线向下，情绪低迷。
- 熊市折扣：恶劣环境下断层成功率下降 30%~50%，降预期仓位。**折扣只作用于仓位，不作用于缺口成立判定。**

### 3.2 情绪与流动性
- 成交量、涨跌家数比、连板高度。
- 北向资金流向、两融余额变化。
- 业绩线是否为当前市场主线。

---

## 维度 4：板块与行业景气度（满分 15）

### 4.1 板块行情
- 公告前后申万一级/二级行业指数同步走强。
- 同板块多家公司超预期＝板块性业绩浪。
- 板块内个股联动齐涨。

### 4.2 行业景气
- 上行 / 下行 / 平稳周期。
- 政策催化、产业趋势支撑。
- 供需变化（涨价、产能紧张、需求爆发）。

### 4.3 板块暴跌日
- 个股逆势跳空 = 强化信号。
- 个股跟随板块下跌 = 缺口难成立。
- **不得**因板块暴跌而事后否定已成立的缺口。

## 综合评级映射（满分 100 = 40+30+30）

**仅 FORMED / CONFIRMED / FAILED 状态可用此表。PENDING 状态禁止映射。**

| 评级 | 综合得分 | 预期收益空间 | 建议仓位 |
|------|----------|--------------|----------|
| S 顶级断层 | ≥90 | 30%~50%+ | 重仓 |
| A 强势断层 | 75~89 | 20%~30% | 中重仓 |
| B 普通断层 | 60~74 | 10%~20% | 中仓 |
| C 弱势断层 | 45~59 | 5%~10% | 轻仓试错 |
| D 无效断层 | <45 | 不建议参与 | 观望 |

## 输出前自查清单（8 项）

1. [ ] 是否已明确写出披露时刻与 T0 日期？
2. [ ] PENDING 状态下，技术面是否已标 N/A 而非填入数字？
3. [ ] PENDING 状态下，是否避免了「不构成断层 / 无效」等终局表述？
4. [ ] 是否自行计算了扣非增速与非经常性占比，而非直接引用媒体归母增速？
5. [ ] 是否把「下跌 / 板块暴跌 / 均线空头」误用为缺口证伪理由？
6. [ ] 单季数据与累计数据是否勾稽一致（H1 + Q3 = 前三季）？
7. [ ] 多标的时，是否使用了同一判定时点基准与同一套阈值？
8. [ ] 是否注明了下一次必须复核的时点（T0 / 3 日 / 5 日）？
