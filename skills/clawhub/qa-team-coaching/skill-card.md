## Description:

Helps QA teams coach new members and build testing capability through paired testing, reviews, checklists, templates, and tailored training plans.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kokxi](https://clawhub.ai/user/kokxi)

### License/Terms of Use:

MIT-0

## Use Case:

QA leads, mentors, and testing teams use this skill to assess skill gaps, onboard new testers, and create coaching plans with measurable follow-up.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Training examples could be mistaken for approved changes to QA or release processes.

Mitigation: Review proposed checklists and process changes with the team before adopting them.

Risk: The optional command to install an external skill set introduces a separate supply-chain trust decision.

Mitigation: Verify the package and source, and prefer a pinned commit or version before running the command.
