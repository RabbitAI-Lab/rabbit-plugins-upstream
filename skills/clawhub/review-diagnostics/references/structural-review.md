# 结构/洞察/传播力/反AI味分析

## 一、三问自检

| 检查项 | 标准 |
|--------|------|
| 钩子问题 | 开头30秒内抛出具体痛点，让听众代入 |
| 核心观点 | 至少1-2个鲜明观点，有人会不同意 |
| 真实经历 | 每个观点有亲身体验/具体案例支撑 |

## 二、主题聚焦检查（一句话定题）

通读全文后用一句话回答：**"这篇文章在讲什么？"**

| 答案特征 | 判定 |
|---------|------|
| 清晰一个主题 | ✅ 通过 |
| 出现"和/以及/同时" | 🔴 双核心，必须处理 |
| 模糊说不清 | 🔴 立意不明，需重新定调 |
| 勉强能说出但结尾偏离 | 🟡 尾巴多余，删掉偏离部分 |

## 三、风格一致性预检

标记 6 种偏离模式：

| # | 模式 | 判定 |
|---|------|------|
| 1 | 解释段过厚（从"我做"切到"……是……"） | 🔴 砍到1-2句 |
| 2 | 不必要升维（具体案例→"所有X都一样"） | 🟡 收回到个人场景 |
| 3 | 二元对立强推（"不是X而是Y"超频） | 🟡 砍到≤2次 |
| 4 | 结尾拔高（格言式升华） | 🔴 必须重写 |
| 5 | "不是……而是……"超频 | 🟡 砍到≤2次 |
| 6 | 结尾段叙事连贯性（引入前文无铺垫的新概念） | 🔴 多余 |

## 四、听众带走什么

| 维度 | 问什么 |
|------|--------|
| 一句话带走 | 听众能复述的核心观点是什么？ |
| 认知框架 | 带走可复用的框架，还是散点故事？ |
| 未解疑惑 | 留下什么问题？健康好奇？不安全怀疑？ |
| 离场情绪 | 被启发/焦虑/共鸣/将信将疑/被消费？ |
| 行动转化 | 听众会改变什么？还是"有道理"然后什么都没变？ |

## 五、金句评估

| 类型 | 传播力 |
|------|--------|
| 反直觉型（颠覆常识） | ⭐⭐⭐⭐⭐ |
| 共鸣型（戳中普遍痛点） | ⭐⭐⭐⭐ |
| 可迁移型（脱离原文仍成立） | ⭐⭐⭐⭐ |
| 画面型（有画面感） | ⭐⭐⭐ |
| 格言型（工整但偏口号） | ⭐⭐⭐ |

## 六、反AI味检测

- 过度工整的排比（A/B/C三段对称镜像）？
- 虚假的完美收束（首尾太完整）？
- 因果链太整齐（没有枝杈和犹豫）？
- "太完美"检查：内容讲的是混乱和挣扎，但文章本身是否被整理得一点都不混乱？

## 七、段落衔接检查

从第二段开始，对每个过渡问三个问题：
1. 读者需要自己脑补信息才能接上？→ 🔴 缺逻辑桥
2. 标题准确预告了内容？→ 🔴 标题-内容不一致
3. 这个信息刚刚说过了？→ 🟡 重复
