# 事实核查

## 6 类风险

| # | 风险类型 | 要问的问题 |
|---|---------|-----------|
| 1 | 数字精确性 | 这个数字能自证吗？有日志/截图支撑吗？ |
| 2 | 技术概念准确性 | 术语使用准确吗？会不会误导听众？ |
| 3 | 因果推断 | 因果关系真的成立，还是为了叙事流畅强行连接？ |
| 4 | 绝对化表述 | "从来不/根本/永远/所有/任何"有例外吗？ |
| 5 | 记忆模糊风险 | 这个细节是凭记忆写的吗？可能有偏差吗？ |
| 6 | 应然vs实然 | Agent 说它会做 vs 系统真的做了——能分清吗？ |

## 严重度标注

- 🔴 **严重**：事实错误、编造内容、误导性表述 → 不修复不能发布
- 🟡 **中等**：可能不准确，或缺少必要限定 → 标注并给出修改方向
- 🟢 **轻微**：模糊化表达但不影响核心论点 → 可选修改

## 素材对照流程（有素材文件时必做）

1. **读素材**：从 `sources/` 目录读取所有素材文件和 `index.md` 映射表
2. **建事实清单**：从素材提取 5 类信息——📊数字 📅事件 🔗因果 💬引用 🏷️概念
3. **逐句对照**：每句事实性陈述与素材清单对比 →

| 标记 | 含义 |
|------|------|
| ✅ | 草稿与素材一致 → 跳过 |
| ⚠️ | 有相关素材但细节/措辞有偏差 → 进入6类风险分析 |
| ❓ | 素材中没有对应内容 → 需向作者确认来源 |
| 🔴 | 与素材直接矛盾 → 必须修正 |

4. **对照要点**：数字精确化（"大约"→精确值）、因果强化（先后→因果）、细节脑补（素材没有的场景）、范围扩大（"某次"→"每次"）
5. **时效性检查**：素材日期到审稿日之间，功能名/流程/状态是否变化

## 核心原则

- **宁可模糊化，不能编造**。不确定的地方直接问作者。
- **应然≠实然**。Agent 描述的"我将会做"不等于它真的做了。
- **金句的事实风险最高**。传播力越强的句子，越可能是事实层面最危险的。
- 最常见的素材偏差：数字精确化（丢"大约"）、因果强化、细节脑补。
