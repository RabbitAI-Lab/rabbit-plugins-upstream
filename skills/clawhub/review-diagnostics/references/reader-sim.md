# 逐句读者反应模拟

逐句模拟"第一次听到"的脑内反应。不是真实听众数据，是结构化推测。

## 反应标记体系

| 标记 | 含义 |
|------|------|
| 🎯 钩住了 | 感兴趣，会继续听 |
| 😐 平的 | 无感，不会走神也不会留下印象 |
| 😴 走神 | 无聊，可能切出去 |
| ❓ 疑惑 | 不懂，想追问 |
| 💡 顿悟 | "哦原来是这样" |
| 🔥 共鸣 | 点头，想转发 |
| 🤔 质疑 | "真的吗？证据呢？" |
| ⚡ 雷点 | 反感，"太装了""像标题党" |

## 模拟前的概念频率检查

**先于逐句模拟执行。** 建立全文概念频率表：

```
概念：三步模型
  ├── 幕1（首次定义）
  ├── 幕2（再次展开） ← 🟡 第二次，关注
  └── 幕3（第三次）   ← 🔴 严重重复
```

| 频率 | 判定 |
|------|------|
| 1次 | 正常 |
| 2次（非相邻） | 🟡 检查是否是同一角度；同一角度则压缩 |
| 3次+ | 🔴 必须删减，除非是首尾呼应callback |

## 四类深层检测

### 1. 过度承诺
标记"确保/肯定/所有人/一定"等词 → 有条件限定吗？有例外吗？

### 2. 拟人化
标记"它理解/它偷懒/它学会了" → 能观察到内部状态吗？归因准确吗？

### 3. 概念混用
标记不同层级的东西塞进同一概念（如"记住经验"≠"修改系统"≠"改变模型能力"）

### 4. 解释段/不必要升维
标记从"我在做"切到"我在说"的句子（"……是什么""……意味着……"）→ 遮住这句子上下文是否通顺？通顺则多余。
