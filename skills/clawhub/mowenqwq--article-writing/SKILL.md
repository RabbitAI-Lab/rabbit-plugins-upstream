# 文章写作经验

只收录两类内容：**已验证有效的经验**、**犯过的错误＋对应解法**。来源：真实创作实战，脱敏。

## 一、核心写作原则

### 1. 读者是普通人（第一原则）
- 写每一句前问自己："一般这么说吗？正常人看得懂吗？"别扭就换。
- 用日常自然的动词搭配；读者＝普通大众，不预设懂技术的读者。
- 踩坑记录（本次实战）：
  - ✗ "模型是数据**喂**出来的" → ✓ "模型是靠数据**训练**出来的"（"喂"是翻译腔）
  - ✗ "数据是现实世界**一段一段磨**出来的" → ✓ "数据来自现实世界**年复一年的积累**"（"磨"动词错位）
  - ✗ "各自在**铺**哪张牌""胜负**就藏不住**了" → ✓ "各自在**押注**什么""答案其实**已经不难找了**"（生造比喻/网感词）
  - ✗ "比喻**开始咳嗽**了"（主语错位拟人，读者会问"谁咳嗽"）→ ✓ "比喻**正在变成现实**"

### 2. 事实先行：不确定先查证，禁止绑定没查证的因果
- 文里每个论断尽量有信源，能进信源清单。
- 踩坑：曾把"特朗普把国防部改名战争部"当"AI 战争成现实"的证据——查证后发现那是 2025-09-05 的"第二名称/副名"（非正式改名、需国会立法），纯政治象征、与 AI 无因果。已从正文删除，并在知识库做事实澄清。
- 规则：先用 ①官方→②央媒→③ 的路径查证时间/机制/原因，再判断能不能用、怎么用。拿不准就问用户，不自己脑补。

### 3. 聚焦主线，跑题的料删掉
- 文章只讲一件事；珍贵背景/金句如果与主线无关，放知识库、不进正文。
- 踩坑："战争部改名"写进《为什么我说 AI 战争中国必胜》开头——跟算力/应用/电力主线无关，被用户指出"不突兀吗"，已删。
- 规则：判断标准是"这句和主线有关系吗"，不是"这句好不好"。

### 4. 对比才有说服力
- 论证胜负/强弱必须中外（双方）对照，不能只列一方成绩单。
- 结构模板：**我方打法 → 对方打法 → 胜负手结论**，可加对比表（维度/做法/信源/胜负手）。
- 实战：四场对决（算力调度/应用反馈/电力消耗/规则暗战），每场都是"中国象限 vs 美国象限"。

### 5. 深度优先，篇幅放后
- 文章有深度才重要，长度不设限。深度＝机制分析（为什么）、反例诚实处理、历史/体系纵深，不是名词堆砌。

### 6. 观点文"必胜/最强"类
- "必胜"＝有条件的判断：主动摆反例（短板/风险），再用事实压回去，才可信、耐看。
- 区分**追赶型劣势**（有明确路径、可被时间抹平）vs **结构性优势**（体系/底座/禀赋，最难抄、时间越久越放大）。
- 承认对方强项（如"模型还是美国的强"），再用"战场维度已经转移"论证结论——不吹、不赌。

## 二、用词与风格避雷
- 开头不生造品牌名（✗ "谁的英伟达买得多" → ✓ 通用词"显卡/算力"）。
- 不用主语错位拟人（✗ "比喻咳嗽"）、不用 AI 腔/翻译腔套话、不硬造网感词。
- 判断金句的标尺：这句是"正常文章会写的"，还是"只有 AI 才写得出的"——后者删。
- 专业名词/文件编号默认读者不懂：出现术语（如"超大规模云""推理"）要么补一句白话解释，要么简化；编号类（EO-14409）进信源清单，正文用"特朗普签的 AI 行政令"这种说法。
- **同一个别扭说法会反复潜伏**：一处改好不等于全篇干净——改完某个词后，全文再搜一遍同类表达（教训：一篇自查发现"喂"字潜伏 5 处）。
- **数字必须有依据**：明确的年限/百分比/排名若无出处，要么查证、要么模糊化（教训：写"AI 战争打了四年"实无依据，改"打了好几年"）。
- 多平台通用写法：正文不跟单一平台调性（公众号/知乎/B站/头条各不相同），发布时再做标题本地化。
- 若要当**视频文案基础**：段落按"可拆分成镜/口播"组织（长文即分镜台本），每段自带钩子与结论。

## 三、文章结构模板（观点/评论/软文类）
0. **开头钩子**：从普通人能懂的事实/反常识物理事实切入，不抛术语名词。
1. **主干**：每层"我方 → 对方 → 胜负手"，配对比表。
2. **反例节**：主动写短板再反驳（"把反例说透，才能立得住"）。
3. **收尾**：结论＝有条件的判断，不自嗨。
4. **附录信源清单**：条目无限制；只有 ①官方→②中央官媒→③自媒体 的级别限制；**文章用到哪些就放哪些，不用问**。

## 四、更新协议（活文档）
本 skill 为活文档：**每次写/改文章积攒新经验后，追加/修订对应小节 + bump version + 在下方补更新日志**。经验按主题归入上述章节；同一坑不再重复建条目。

## 五、发布前自查清单（每篇必走）
1. **读者视角通读一遍**：默认"普通人看不懂术语"，把专业词全部拆开、解释或删掉。
2. **全局搜别扭词**：全文搜一遍是否有同一种表达反复潜伏（如"喂""赋能"），一处改完再全局扫。
3. **每个数字问"哪来的"**：没有信源的年限/百分比/排名，查证或模糊化。
4. **每句金句问"正常文章这么写吗"**：只有 AI 才写得出的句子删掉。
5. **核对主线**：每段和主线有关吗？没关的删（可放知识库，不进正文）。
6. **因果核对**：每处"因为 A 所以 B"必须查证过，没查证的因果禁止绑定。
7. **信源清单**：文中用到哪些信源就放哪些（无条目限制，只按①官方→②央媒→③自媒体级别）。
