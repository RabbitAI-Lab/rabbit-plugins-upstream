# Deep Content Writer 🖊️

**An AI agent skill for writing engaging, example-driven long-form articles.**

Created by **纳兰安妮 · 纳兰凭楼** · [@AiEPCO](https://github.com/aiepco)

## What it does

This skill teaches your AI coding agent (Claude Code, Cursor, Codex CLI, OpenClaw, etc.) a structured system for crafting content that readers actually finish:

- **Research-first, structure-second** — The agent performs knowledge reconnaissance before writing, surfacing specific studies, data, and counterintuitive angles
- **6-part narrative arc** — Hook → Define → Mechanism → Examples → Takeaway → Close
- **5 depth techniques** — Specificity passes, cross-domain connections, counter-argument integration, multi-level language, and "So What?" audits
- **Platform-specific adaptations** — 知乎, 头条, blog, Twitter/X, Facebook — each with tailored tone, structure, and engagement elements

## How to install

```bash
# Claude Code
claude plugin install deep-content-writer

# Manual (works with any agent)
# Clone this repo to your agent's skills directory:
git clone https://github.com/aiepco/deep-content-writer.git ~/.claude/skills/deep-content-writer/
```

## When to use

This skill activates automatically when you ask the agent to write an article, blog post, newsletter, or social media thread that needs depth and reader engagement.

## Examples

| Platform | Style | Length |
|:---------|:------|:------|
| 知乎 | In-depth, personal, well-researched | 3000-8000 characters |
| 头条/百家号 | Short paragraphs, emotional hooks | 1500-4000 characters |
| Twitter/X Thread | Bite-sized, numbered, viral | 10 tweets |
| Blog/Newsletter | Formal, footnoted, scannable | 1500-4000 words |
| Facebook | Conversational, emoji, engagement-focused | 500-1500 words |
