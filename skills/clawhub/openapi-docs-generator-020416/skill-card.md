## Description: <br>
Helps backend, platform, and developer-experience teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to turn API documentation requests into practical OpenAPI or Swagger artifacts, workflows, checklists, analysis, code changes, and validation guidance. It is aimed at backend, platform, developer-experience, and maintainer teams that need REST APIs to be understandable to other engineers. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad API and developer-experience trigger wording may activate the skill for requests that are not specifically about OpenAPI or Swagger documentation. <br>
Mitigation: Use explicit OpenAPI or Swagger documentation requests when invoking the skill and verify that the response matches the intended API documentation task. <br>
Risk: Generated documentation guidance can introduce incorrect or misleading API details if the source API behavior is incomplete or outdated. <br>
Mitigation: Review generated artifacts against implementation, tests, and API consumers before publication. <br>
