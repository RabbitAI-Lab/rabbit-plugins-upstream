## Description:

Pick a domain name and ending, check if it can be registered, and find where it is cheapest to register and renew, using tld.expert's free live data (no key). Use when a user is naming a product or business, asks which TLD to use (.com vs .io vs .ai), asks if a domain is available or taken, or asks what a domain costs.

This skill is ready for commercial/non-commercial use.

## Use Case:

People naming a product or business can use this skill to compare domain endings, check whether specific domains are confirmed available, and find dated registration and renewal prices. It also helps review basic brand-name records while making clear that a search result is not legal clearance.
