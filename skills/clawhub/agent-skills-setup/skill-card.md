## Use Case:

Developers and engineers use this skill to inventory, plan, preview, apply, verify, and roll back local agent-skill, instruction, and MCP migrations across supported IDEs and agent products.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The authoritative security summary reports a suspicious finding: snapshot output can replace or delete an existing output path even though snapshot is described as read-only.

Mitigation: Review generated plans before applying migrations and choose a fresh or dedicated .acb output path for snapshots.

Risk: Broad local scanning may inspect more installed IDE configurations than intended.

Mitigation: Avoid --all-installed unless broad local IDE scanning is intended, and limit source, target, objects, scope, and workspace before filesystem inspection.
