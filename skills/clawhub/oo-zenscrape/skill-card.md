## Description:

Zenscrape helps an agent fetch public web pages through the OOMOL oo CLI connector using a connected Zenscrape account.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

## Use Case:

Developers and agents use this skill to fetch public URLs through Zenscrape with optional rendering, proxy, header, and wait controls while relying on OOMOL-connected credentials.

### Deployment Geography for Use:

Global
