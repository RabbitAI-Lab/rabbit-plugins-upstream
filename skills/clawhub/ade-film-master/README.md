# 阿德影视制作大师(ade-film-master)

专业级影视制作全流程助手:把小说 / 故事 / 文章改编为影视剧本,生成 AI 绘画资产提示词(场景四视图、人物全身像),再生成 AI 视频分镜提示词,支持脱敏改编与 PDF 输出。

## 功能概览

- **阶段一 · 剧本改编**:扩写 / 保持两种模式,可选脱敏处理(附对照表),输出标准影视剧本格式
- **阶段二 · 资产提示词生成**:场景四视图(16:9)、人物全身像(9:16),整理为 `@` 资产清单
- **阶段三 · 分镜提示词生成**:每 15 秒一个批次,引用资产清单,统一视觉基调 / 景别 / 运镜 / 时长

适用于专业短剧、电影预告片、AI 视频生成(Seedance、即梦、Midjourney、Stable Diffusion 等)。

## 安装

### 方式一:WorkBuddy 技能市场(推荐)

1. 打开 WorkBuddy 桌面端
2. 进入「技能市场」
3. 搜索「阿德影视制作大师」或「ade-film-master」
4. 点击「安装」即可一键部署

### 方式二:手动安装

1. 下载本仓库(Skill → Download ZIP)并解压,得到 `ade-film-master` 文件夹
2. 将整个文件夹放入 WorkBuddy 用户技能目录:
   - Windows:`C:\Users\<用户名>\.workbuddy\skills\`
   - macOS / Linux:`~/.workbuddy/skills/`
3. 确认最终路径为 `<技能目录>\ade-film-master\SKILL.md`
4. 重启 WorkBuddy 对话窗口

### 方式三:marketplace-skill-installer

在 WorkBuddy 对话中输入「帮我安装阿德影视制作大师技能」,按提示从远端市场安装。

## 使用

安装完成后,任选其一:

- 在对话中描述任务(如「把这篇故事改成短剧分镜」),Skill 会按 description 自动触发
- 在对话中直接说「使用阿德影视制作大师」/「启用阿德影视制作大师」,显式调用

典型流程示例:

1. 把要改编的小说 / 故事 / 大纲贴进对话
2. Skill 询问处理模式(扩写 / 保持)与脱敏选择
3. 输出改编剧本(可导出 PDF)
4. 确认后进入资产提示词阶段
5. 确认后进入分镜提示词阶段

## 质量要求(继承自 SKILL.md)

- **写实风格**:严格真人写实 / 照片级超写实,严禁卡通、动漫、插画
- **画幅比例**:场景四视图 16:9,人物全身像 9:16
- **画质标准**:2K 或 8K 分辨率
- **格式统一**:严格遵循 SKILL.md 规定的所有格式模板
- **素材复用**:分镜阶段强制引用资产清单中的 `@` 标记,确保一致性
