Provides a Chinese-language game-theory analysis framework for crypto protocols, DeFi mechanisms, and governance systems, including Nash equilibrium, MEV, incentive alignment, and governance-risk analysis.

## Use Case:

External developers, protocol designers, auditors, and governance reviewers use this skill to structure qualitative game-theory reviews of crypto protocols, tokenomics, MEV exposure, staking incentives, oracle incentives, and DAO governance mechanisms. It helps produce structured analysis and recommendations, but does not replace formal security review.
