# 标准贷后分析报告模板规范

> 基于斯米克、鑫曜节能、金叶包装、山金金控四份实际模板提炼而成。

## 一、模板来源分析

| 模板 | 类型 | 主要财务表 | 表格行数 | 比率板块 | 多年度对比 |
|------|------|-----------|---------|---------|-----------|
| 斯米克.docx | 贷后分析报告 | Table 6(资产负债) + Table 7(利润表) | 32+11行 | 有(5项) | 4年(2022-2025) |
| 鑫曜.docx | 贷后分析报告 | Table 5(资产负债) + Table 6(利润表) + Table 7(比率) | 35+19+6行 | 有(6项) | 4年 |
| 金叶包装V6.docx | 调查报告 | Table 11(三表合一) | 66行×7列 | 有(9项) | 5年(2022-2025.12) |
| 山金金控.doc | 大额报告 | 类似结构 | - | 有 | 多年 |

**共性特征**：
1. 均含资产负债表+利润表数据（现金流量表可选）
2. 均采用多年度横向对比（至少2年，通常3-5年）
3. 均含财务比率板块（5-9项不等）
4. 均含财务分析文字段落（基于数据的定性分析）
5. 金额单位统一为万元
6. 均涉及贷款/投资场景的财务评估

## 三、各章节详细规范

### 标题页

```
[企业名称]贷后分析报告          ← 黑体18pt 居中加粗

报告期间：2025年12月             ← 宋体11pt 居中
编制日期：2026年7月24日          ← 宋体11pt 居中
```

### 一、企业基本情况

#### （一）企业概况

| 字段 | 说明 | 是否必填 |

| 字段 | 说明 | 是否必填 |

### 二、财务状况分析

#### （一）资产负债分析

**数据表格**：

| 项目 | 本期末(万元) | 占比 | 上期末(万元) | 同比变动 |
|------|------------|------|------------|---------|

表格分为三段：
1. **资产段**（18-20行）：货币资金→流动资产合计→固定资产→非流动资产合计→资产总计
2. **负债段**（8-10行）：短期借款→流动负债合计→长期借款→非流动负债合计→负债合计
3. **权益段**（5-7行）：实收资本→资本公积→盈余公积→未分配利润→所有者权益合计

> 合计/总计行加粗+灰色底纹。有上期数据时增加"上期末"列和"同比变动"列。

**分析文字**（3段）：

1. **资产分析**：
   > 截至2025年12月末，公司资产总额为62,320万元，其中流动资产43,983万元，占资产总额的70.58%；非流动资产18,337万元，占资产总额的29.42%。流动资产中，货币资金3,568万元，应收账款21,914万元，存货15,934万元，是流动资产的主要构成部分。与上期末相比，资产总额增加了X万元，增幅为X%。

2. **负债分析**：
   > 截至2025年12月末，公司负债总额为23,712万元，其中流动负债22,292万元，占负债总额的94.00%；非流动负债1,420万元，占负债总额的6.00%。流动负债中，短期借款5,000万元，应付账款8,000万元。资产负债率为38.05%。

3. **权益分析**：
   > 截至2025年12月末，公司所有者权益为38,608万元。其中，实收资本6,000万元，盈余公积7,685万元，未分配利润24,733万元。与上期末相比，所有者权益增加了X万元，增幅为X%。

## 四、格式规范

| 元素 | 字体 | 字号 | 颜色 | 对齐 |
|------|------|------|------|------|
| 报告标题 | 黑体 | 18pt | 黑色 | 居中加粗 |
| 章节标题(一、二、) | 黑体 | 14pt | 黑色 | 左对齐加粗 |
| 二级标题(（一）（二）) | 宋体 | 12pt | 黑色 | 左对齐加粗 |
| 正文 | 宋体 | 10.5pt(五号) | 蓝色(0,0,255) | 首行缩进2字符, 1.5倍行距 |
| 表格表头 | 宋体 | 9pt | 黑色 | 居中加粗, 蓝灰底色(#D9E2F3) |
| 表格数据 | 宋体 | 9pt | 蓝色(0,0,255) | 数值右对齐, 文字左对齐 |
| 合计/总计行 | 宋体 | 9pt | 蓝色加粗 | 灰色底色(#F2F2F2) |
| 占位符 | 宋体 | 10.5pt | 红色(255,0,0) | - |

**页面设置**：A4纵向，上下左右边距2.5cm。

## 五、标蓝规则

- 所有自动生成的分析文字 → 蓝色
- 所有从财报填入的数据 → 蓝色
- 用户提供的模板原有文字 → 保持原色
- 占位符（待用户补充的信息）→ 红色提示
