# 企业报表合并技能 (Enterprise Report Merger)

将多个 Excel/PDF 格式的企业报表（财务三大表、部门预算表、业务数据表等）按指定模式合并为统一报表，并可将合并结果填入 Word 模板生成最终报告。

## 功能特性

- 读取 Excel（.xlsx/.xls）和 PDF 文件中的表格数据
- 三种合并模式：
  - **简单拼接**：多个来源纵向堆叠
  - **按关键字合并**：按科目代码/部门等键值横向匹配
  - **合并报表+抵销分录**：母子公司集团合并，含内部交易抵销处理
- 将合并结果写入格式化 Excel 文件
- 将合并数据填入 Word（.docx）模板，生成最终报告
- **无模板时自动生成完整分析报告**（如贷后分析报告）
- **18 项财务比率自动计算**（4 类：偿债 7 项 / 营运效率 3 项 / 盈利 5 项 / 发展 3 项，支持上期数据平均余额与增长率）

## 安装方式

```
npx clawhub@latest install enterprise-report-merger
```

或通过 WorkBuddy 导入 .zip 技能包：技能 → 添加技能 → 上传技能。

## 依赖

```
pip install openpyxl pdfplumber python-docx xlrd PyMuPDF
```

| 依赖 | 用途 |
|---|---|
| openpyxl | Excel 输入输出 |
| xlrd | 旧版 .xls 文件 |
| pdfplumber | PDF 表格提取 |
| PyMuPDF | 图片型 PDF 检测 |
| python-docx | Word 模板填充 |

## 使用方式

在对话中用自然语言描述任务即可触发：

- "合并这些 Excel 报表"
- "把子公司财务报表合并成集团合并报表"
- "把数据填到 Word 模板里"
- "没有模板，自动生成贷后分析报告"

## 合并模式说明

| 模式 | 适用场景 |
|---|---|
| 简单拼接 | 多个来源结构相同，纵向堆叠 |
| 按关键字合并 | 按键值列（如科目代码、部门名称）横向匹配 |
| 合并报表+抵销分录 | 母子公司集团合并，含内部交易抵销 |
