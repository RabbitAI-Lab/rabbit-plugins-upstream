## 1. 电子电气产品

| 产品类型 | HS 编码区间 | 备注 |
|---------|-----------|------|
| 电线电缆 | 8544.xxxx | 导体材质（铜/铝）影响归类 |
| PCB 电路板 | 8534.xxxx | 已装配/未装配有区分 |
| 连接器/插头插座 | 8536.xxxx | 电流规格/用途影响归类 |
| 开关/继电器 | 8536/8537 | 控制电压影响子类划分 |
| 电池（锂电池） | 8507.60 (锂离子) / 8506 (其他) | 锂电池出口需 UN38.3 测试 |
| 变压器/电源适配器 | 8504.xxxx | 功率/是否为UPS有区分 |
| LED 灯具 | 9405.39 (其他灯具) | 注意与传统灯具区分 |
| 手机/平板/电脑 | 8517.12 / 8471.30 | 通讯功能 vs 计算功能 |
| 耳机/音箱 | 8518.xxxx | 有线 vs 无线有区分 |
| 监控摄像头 | 8525.80 / 8523.49 | 模拟 vs 数字/是否含存储 |
| 路由器/交换机 | 8517.62 | 网络设备 |
| 显示器 | 8528.xxxx | 尺寸/分辨率影响 |
| 电动工具 | 8467.xxxx (手持) / 8508 (家用) | 手持 vs 家用电动工具 |
| 家用电器（白电） | 8415 (空调) / 8418 (冰箱) / 8450 (洗衣机) | 功率/制冷量细分 |

### 电子产品 HS 归类风险点
- **同一产品有多个可能编码**：多功能设备需按"主要功能"归类
- **零部件 vs 整机**：单独出口零部件（如 PCB）按零件归类，税率不同
- **锂电池特殊要求**：UN38.3 + 危包证，HS 归类同时影响危货判定

## 2. 纺织服装

| 产品类型 | HS 编码区间 | 备注 |
|---------|-----------|------|
| 棉纱线 | 5205.xxxx | 精梳 vs 非精梳；支数 |
| 棉布 | 5208/5209.xxxx | 平方米克重影响子类 |
| 棉质服装（成人） | 6109.xxxx (T恤) / 6103.xxxx (男裤) | 针织 vs 机织；棉含量 |
| 化纤服装 | 6104.xxxx / 6204.xxxx | 合成纤维含量 |
| 运动服/户外服装 | 6112/6211 | 含功能性面料更复杂 |
| 内衣/袜子 | 6107-6115 | 针织品类 |
| 围巾/披肩 | 6117 / 6214 | 材质+工艺组合归类 |
| 鞋类 | 6401-6406 | 材质（皮鞋/布鞋/塑料鞋/橡胶鞋）大类分开 |
| 皮革服装 | 4203.xxxx | 动物种类（牛皮/羊皮）|
| 箱包 | 4202.xxxx | 材料/用途细分 |

### 纺织服装 HS 归类风险点
- **混纺面料**：按主要纤维含量归类，需提供成分检测报告
- **功能服装**：如防水/防紫外线，需明确是否具有医疗功能（医疗服装 HS 编码不同）
- **鞋类材质组合**：主材质决定大类，组合材质时以主材质为准

## 3. 机械及零部件

| 产品类型 | HS 编码区间 | 备注 |
|---------|-----------|------|
| 通用机械零部件 | 8481-8487 | 阀门/轴承/齿轮等 |
| 泵类 | 8413.xxxx | 容积式/动力式/液体泵 |
| 轴承 | 8482.xxxx | 滚珠/滚柱/轴承座 |
| 阀门 | 8481.xxxx | 种类（球阀/闸阀/截止阀） |
| 电机/发电机 | 8501.xxxx | 功率/交流直流 |
| 机床 | 8458-8463 | 数控 vs 非数控；车/铣/钻 |
| 工程机械 | 8429.xxxx | 推土机/挖掘机/压路机 |
| 农业机械 | 8432-8434 | 收割机/播种机/农机具 |
| 空压机 | 8414.30 / 8414.80 | 功率/类型 |

### 机械 HS 归类风险点
- **多功能机械**：按"主要功能"归类，若无法判断优先功能则归入 8479（多功能机器）
- **整机 vs 零件**：已装配成整机的组件按整机归类，拆散后按零件归类
- **二手设备**：二手设备归类与新机相同，但需额外海关审价材料

## 4. 塑料/橡胶制品

| 产品类型 | HS 编码区间 | 备注 |
|---------|-----------|------|
| 塑料粒子（通用） | 3901-3914 | 材质（PE/PP/PS/ABS/PVC）|
| 塑料包装容器 | 3923.xxxx | 材质+用途细分 |
| 塑料日用品 | 3924.xxxx | 餐具/厨具/家居用品 |
| 塑料管材 | 3917.xxxx | 材质/是否加强/夹层 |
| 橡胶密封件/垫片 | 4016.xxxx | 平板硫化橡胶 |
| 橡胶输送带/传动带 | 4010.xxxx | 是否含金属/纤维骨架 |
| 乳胶手套 | 4015.xxxx | 医用 vs 非医用有区分 |
| 轮胎 | 4011 (轿车) / 4012 (卡车) | 充气 vs 实心；规格 |

### 塑料 HS 归类风险点
- **再生塑料**：归入 3915（废物料），与新料 3901-3914 税率差异极大
- **共聚物 vs 均聚物**：PP 共聚物 vs 均聚物归类不同
- **一次性塑料**：部分国家限制进口（如 EU SUP 指令），归类同时影响目的国合规

## 5. 化工产品

| 产品类型 | HS 编码区间 | 备注 |
|---------|-----------|------|
| 工业化学品（有机） | 2901-2942 | 按化学结构细分 |
| 工业化学品（无机） | 2801-2853 | 按元素/化合物分类 |
| 涂料/油漆/固化剂 | 3208-3210 | 水性 vs 油性；颜料含量 |
| 胶粘剂/密封胶 | 3506.xxxx | 组分/用途细分 |
| 清洁剂/洗涤剂 | 3402.xxxx | 家用 vs 工业用 |
| 香料/香精 | 3301-3307 | 天然 vs 合成 |
| 化妆品（护肤品） | 3304.xxxx | 是否含药用成分 |
| 化妆品（彩妆） | 3303-3307 | 按品类细分 |

### 化工产品 HS 归类风险点
- ⚠️ **化工品归类最复杂**：同一产品可能因成分比例/用途不同归入完全不同编码
- ⚠️ **混合物归类**：需确定主要成分，混合物归类优先看混合物整体特征
- ⚠️ **CAS号核查**：化学名相同但 CAS 号不同的物质必须分别归类
- ⚠️ **危险化学品**：涉及 UN 编号，HS 归类同时影响危货包装/运输

- **复合材料**：多层复合材料按主要材质归类，但可能需要额外说明

- **含电子功能**：玩具含电子功能（如发声/发光/遥控）仍按玩具归类，不归入电子产品

## HS编码归类常见错误与风险提示

### 常见错误

| 错误类型 | 后果 | 防范措施 |
|---------|------|---------|
| 高报低税率（故意错归） | 走私违规，追缴税款，处罚，刑事风险 | 不得故意错归 |
| 归类依据不足 | 海关质疑，补征税款，查验延误 | 准备归类依据（技术文件/成分说明） |
| 归类决定 (Ruling) 未申请 | 争议时无依据 | 大额货物可申请海关预归类 |
| HS 版本更新未更新 | 编码已废止或变更 | 每年核实海关进出口税则版本 |
| 多品名合并归类 | 税率就高不就低，额外缴税 | 逐品名分别归类 |

### HS 归类优先级原则

1. **类注/章注/子目注释优先**：先看税则中的注释说明
2. **列名优先**：最具体列名的编码优先
3. **功能/用途优先**：混合物或多功能产品看主要用途
4. **材质优先**：无具体列名时按主要材质归类
5. **从后归类**：以上均无法判断时归入最后一个可行编码

### 归类建议流程

```
产品描述 → 查章注/类注 → 查子目注释 → 锁定候选编码 → 确认税率/监管条件 → 预归类（如需）
```

---

> ⚠️ **重要提示**：HS 编码直接影响关税税率、监管条件（3C/法检/进口许可）和出口管制筛查结果。涉及金额较大或新产品时，建议委托专业报关行或申请海关预归类决定。
