## 1. 中国出口管制

### 出口管制法核心框架

| 法规 | 生效时间 | 核心内容 |
|------|---------|---------|
| 《中华人民共和国出口管制法》 | 2020.12.01 | 管制物项（货物/技术/服务）+ 管制清单 + 许可制度 |
| 《两用物项出口管制清单》 | 持续更新 | 核/生物/化学导弹相关；监控化学品；部分高性能材料 |
| 《军品出口管制清单》 | — | 武器装备及相关物项 |

### 常见受限物项（外贸高频）

| 物项 | 受限原因 | 建议 |
|------|---------|------|
| 无人机（整机和散件） | 商用无人机含高性能导航/图传，可能涉军品 | 确认是否需军品出口许可 |
| 密码技术/加密产品 | 商用加密分普通/商用密码/涉密，涉密须许可 | 确认加密强度是否超限 |
| 高性能计算机 | 单机算力超限可能受限 | 出口前申请出口许可 |
| 石墨材料（高纯度） | 两用物项清单 | 确认纯度规格 |
| 稀土相关材料 | 部分稀土及化合物受控 | 查两用物项清单 |

## 2. 美国 EAR / ITAR

### 核心法规

| 法规 | 管辖范围 | 违规后果 |
|------|---------|---------|
| **EAR (Export Administration Regulations)** | 商业/两用物项；由 BIS 管理 | 民事罚款最高 $364,992/次或2倍利益；刑事最高20年监禁 |
| **ITAR (International Traffic in Arms Regulations)** |  defense articles/defense services；由 DDTC 管理 | 刑事最高20年监禁 + 罚款 |
| **OFAC 制裁** | 特定国家/实体/个人；由 OFAC 管理 | 民事/刑事处罚；资产冻结 |

### 关键清单

| 清单 | 全称 | 含义 |
|------|------|------|
| **CCL (Commerce Control List)** | 商业管制清单 | 受 EAR 管的物项清单 |
| **ECCN (Export Control Classification Number)** | 出口分类编码 | 5位字母数字，如 3A001（电子）、7A103（导航） |
| **Entity List** | 实体清单 | 与特定国家政府相关的受限方 |
| **Denied Parties List** | 被拒实体清单 | 禁止交易方 |
| **Specially Designated Nationals (SDN)** | 特别指定国民 | OFAC 制裁个人/实体 |
| **ITAR USML** | 美国防务物项清单 | ITAR 管的军品清单 |

### 常见出口商最易触雷的 ECCN

| ECCN | 物项类型 | 常见触发条件 |
|------|---------|------------|
| **3A001** | 电子元器件（集成电路等） | 特定频率/功率/性能参数超限 |
| **3A002** | 通用电子测试设备 | 采样率/带宽超限 |
| **5A002** | 信息安全设备（加密） | 特定加密算法/强度 |
| **7A103** | 惯性测量单元/导航系统 | 精度超限 |
| **3E001** | 生产 ECCN 3A 产品的技术 | 知悉用于受限物项生产 |

### ⚠️ 特别注意：实体清单

中国在 Entity List 上的实体（如华为及关联实体、部分科研机构）：
- 向其出口 EAR 管制的物项需要 BIS 许可
- 即使是民用产品，也需要审查
- **如对买方是否在清单上有任何疑问，立即暂停交易并咨询律师**

## 3. 欧盟出口管制

### 核心法规

| 法规 | 核心内容 |
|------|---------|
| **EU Dual-Use Regulation (EU 2021/821)** | 两用物项出口管制，替代旧Regulation (EC) 428/2009 |
| **EU Consolidated List of Dual-Use Items** | 两用物项清单（与 Wassenaar 体系同步）|

### EU 两用物项主要类别

| 类别 | 示例 |
|------|------|
| 1. 材料/化学品/微生物 | 特定合金、化学前体 |
| 2. 材料加工 | 特殊机床、轧机 |
| 3. 电子 | 集成电路、微处理器 |
| 4. 计算机 | 高性能计算设备 |
| 5. 通信/信息安全 | 加密设备（强度≥56-bit）|
| 6. 传感器/激光 | 精度超限的陀螺仪/激光器 |
| 7. 导航/航空电子 | 惯性导航、飞行控制系统 |
| 8. 船舶 | 特定潜水器/推进系统 |
| 9. 航空航天/推进 | 航空航天器、火箭发动机 |

## 4. 联合国制裁清单

| 制裁对象 | 主要内容 | 涉及国家/实体 |
|---------|---------|-------------|
| **朝鲜 (DPRK)** | 全面禁运（武器/奢侈品/部分工业品/煤炭/铁矿/纺织品/石油精炼产品/食品/机械/电气设备/煤炭/铁矿/海产/劳务收入）| 禁止与朝贸易（部分豁免食品/医疗） |
| **伊朗** | 武器禁运（部分解除中）；特定物项限制 | 导弹相关物项；核相关物项 |
| **苏丹** | 武器禁运 | — |
| **利比亚** | 武器禁运；原油出口限制 | — |
| **也门** | 武器禁运 | — |
| **阿富汗（塔利班）** | 资产冻结；武器禁运 | — |
| **索马里** | 武器禁运；木炭/渔类禁令 | — |

⚠️ **联合国安理会制裁决议具有强制性**，中国作为常任理事国有义务执行。

## 5. 主要目的地国特殊要求

### 沙特阿拉伯（SABER/SASO）

| 要求 | 内容 |
|------|------|
| **SABER 系统** | 所有进口产品须在 SABER 平台注册，获取 PC（产品证书）+ SC（装运证书） |
| **SASO IECEE** | 特定电气产品（如手机/灯具/电视等）须先取得 CB 报告再申请 SASO CoC |
| **能效标签** | 空调/冰箱/洗衣机等须满足 SASO 能效标准 |

### 尼日利亚（SONCAP）

| 要求 | 内容 |
|------|------|
| **SONCAP 证书** | 出口前须在尼日利亚标准局 (SON) 认可实验室检测，获得 CoP（产品证书）+ SC（装运证书） |
| **标准** | 须符合尼日利亚工业标准 (NIS) 或等效国际标准 |

### 肯尼亚（PVoC）

| 要求 | 内容 |
|------|------|
| **PVoC** | 出口前符合性验证，获得 CoC（符合性证书） |
| **标准** | KS 标准或等效国际标准；检验机构：SGS/Bureau Veritas/Cotecna 等 |

### 欧盟（通用）

| 要求 | 内容 |
|------|------|
| **CE 标志** | 适用产品必须加贴 CE 标志方可进入 |
| **EPR（生产者责任延伸）** | 包装/电子电气/电池等产品须在欧盟 appointed representative 注册 |
| **EU Deforestation Regulation (EUDR)** | 木材/皮革/大豆/棕榈油等须证明无毁林才可进入（2025年执行）|

### 日本

| 要求 | 内容 |
|------|------|
| **PSE 标志** | 电气用品须通过 DENAN 测试并加贴 PSE 标志 |
| **食品接触** | 须符合食品卫生法肯定列表制度 |
| **化审法 (CSCL)** | 新化学物质须申报 |

### 韩国

| 要求 | 内容 |
|------|------|
| **KC 认证** | 电气产品/儿童产品须 KC 认证 |
| **K-REACH** | 化学品年产量≥1吨须注册；SVHC 通报 |

## 快速筛查三步法

```
第一步：查清单
  ↓ 买方是否在 OFAC SDN / BIS Entity List / BIS Denied Parties List？
     → 命中 → 立即停止，咨询律师

第二步：查物项
  ↓ 你的产品 ECCN / HS 编码是否在管制清单？
     → 管制 + 目的地受限 → 申请出口许可

第三步：查目的国特殊要求
  ↓ 目的国是否有 SABER / SONCAP / PVoC 等特殊准入要求？
     → 未完成 → 无法清关
```
