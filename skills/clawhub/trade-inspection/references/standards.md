## 欧盟（EU）

| 法规/指令 | 适用范围 | 核心要求 | 合格标准 |
|-----------|---------|---------|---------|
| **CE 标志** | 电子电气、机械、玩具、建材、个人防护装备等 | 符合性声明 (DoC) + 技术文件 + 测试报告 | 协调标准 (EN) 测试通过 |
| **RoHS 指令 (2011/65/EU)** | 电子电气设备 | 限制铅/汞/镉/六价铬/PBB/PBDE | 单项≤阈值，2025年新增 DEHP/BBP/DBP/DIBP |
| **REACH 法规 (EC 1907/2006)** | 化学品/物品中化学品 | SVHC 通报、供应链信息传递 (SCIP) | 物品中 SVHC >0.1% w/w 需通报 |
| **GPSR (EU) 2023/988** | 通用产品安全（2024.12.13 生效） | 风险评估、产品追溯、事故报告 | 制造商合规评估文件 |
| **WEEE 指令 2012/19/EU | 电子电气设备回收 | 注册/标识/回收目标 | 回收率达标 |
| **ErP 指令 2009/125/EC | 能源相关产品 | 能效标签/生态设计要求 | 满足能效等级 |
| **玩具安全指令 2009/48/EC | 玩具 | 物理机械/易燃/化学/电气安全 | EN 71 系列测试 |
| **食品接触材料法规 (EC) 1935/2004 | 接触食品材料 | 良好生产规范 (GMP) + 正面清单 | 迁移测试通过 |
| **化妆品法规 (EC) 1223/2009 | 化妆品 | 安全性评估 + 产品信息文件 (PIF) | 禁限用物质符合 |
| **REACH 限制物质清单 (Annex XVII) | 化学品/消费品 | 特定物质限制用途 | 符合限制条件 |

### 欧盟化学安全关键阈值（常见项）

| 物质 | 限值 | 法规依据 |
|------|------|---------|
| 铅 (Pb) | 玩具: 13 mg/kg; 化妆品: 10 mg/kg | REACH/玩具指令 |
| 镉 (Cd) | 0.01% w/w (112 ppm) | REACH Annex XVII |
| 邻苯二甲酸酯 (DEHP/BBP/DBP) | 各类产品中限制 | RoHS / REACH Annex XVII |
| 甲醛 | 纺织品: 75 mg/kg; 家具: 0.1 mg/m³ | REACH / 室内空气标准 |
| 多环芳烃 (PAH) | 8项PAH总和≤10 mg/kg | REACH Annex XVII |
| 偶氮染料裂解产物 | 4种芳香胺≤30 mg/kg | REACH Annex XVII |

## 美国（US）

| 法规/标准 | 适用范围 | 核心要求 |
|-----------|---------|---------|
| **FDA 食品接触材料** | 接触食品的材料/包装 | 21 CFR 175-189 正面清单，或 FAP 申请 |
| **FDA 食品标签** | 食品包装 | 营养标签成分表/过敏原标识/净含量 |
| **FDA 化妆品注册** | 化妆品 | MoCRA 2023：设施注册 + 产品清单 |
| **FDA 医疗器械 510(k)/PMA** | 医疗器械 | 上市前通知或批准 |
| **FCC SDoC / 认证** | 射频/电磁兼容电子产品 | 47 CFR Part 15 测试通过 |
| **CPSIA（儿童产品安全法）** | 儿童产品 (≤12岁) | 第三方测试 (ASTM F963 / 16 CFR) |
| **CA Prop 65（加州65号提案）** | 所有在加州销售的产品 | 化学品致癌/生殖毒性警告 |
| **TSCA（有毒物质控制法）** | 化学品/产品中化学品 | 新物质预生产通知 (PMN) |
| **儿童产品铅含量** | 儿童产品 | 油漆: 90 ppm；基材: 100 ppm（2023年降至 23/12后 23 ppm） |
| **16 CFR 1303** | 儿童产品油漆 | 总铅 ≤ 90 ppm |
| **ASTM F963** | 玩具 | 物理机械/易燃/重金属测试 |

### 美国关键重金属限值

| 物质 | 儿童产品 | 其他产品 |
|------|---------|---------|
| 总铅 | 100 ppm（逐步降至 23 ppm） | 无联邦统一限值（建议参考 CA Prop 65） |
| 铅（油漆） | 90 ppm | — |
| 镉 | 75 ppm（珠宝） | — |
| 汞 | 禁止（化妆品） | — |

## 日本（Japan）

| 法规/标准 | 适用范围 | 核心要求 |
|-----------|---------|---------|
| **食品卫生法（Food Sanitation Law）** | 食品接触材料/添加剂 | 肯定列表制度 (PLS)，测试通过 |
| **JIS 标准** | 工业产品 | 符合 JIS 测试或等效国际标准 |
| **PSE 标志** | 电气产品（适配器/电池/电源等） | 电气产品安全法 (DENAN) |
| **化学物质审查与生产控制法 (CSCL)** | 新化学物质 | 化学物质申报 |
| **RoHS 类似要求** | 电子电气设备 | 《化学物质控制法》部分产品 |
| **玩具安全标准 ST 2016** | 玩具 | 日本玩具协会认证 |

## 韩国（Korea）

| 法规/标准 | 适用范围 | 核心要求 |
|-----------|---------|---------|
| **电气用品安全法 (KCS)** | 电气产品 | KC 认证，测试+验厂 |
| **食品卫生法（肯定列表）** | 食品接触材料 | 肯定列表制度 (PLS) |
| **化学物质注册与评估法 (K-REACH)** | 化学品 | 年产量≥1吨需注册；SVHC 通报 |
| **电器及家用电器安全管理法** | 家电产品 | KC 标志 |
| **儿童产品安全法 (K-CSCA)** | 儿童产品 | 儿童产品安全特别法 |

## 中东/非洲

### 海湾合作委员会（GCC / GSMO）

| 法规 | 适用范围 | 核心要求 |
|------|---------|---------|
| **GSO 符合性追溯标识 (GCTS)** | 受管制产品 | GSO 标准测试 + GSO 标志 |
| **GSO 1687 (低压电器)** | 电气设备 | 低压电器必须通过 GSO 型式认可 |
| **SASO 认证 (沙特)** | 各类进口产品 | SASO IECEE RcB / SABER 系统注册 |
| **SASO IECEE** | 特定电气产品 | CB 测试报告 + SASO 认可证书 |
| **SABER 系统 (沙特)** | 所有进口产品 | PC (Product Certificate) + SC (Shipment Certificate) |

### 非洲主要市场

| 市场 | 关键要求 |
|------|---------|
| **尼日利亚** | SONCAP：产品检验证书 (CoP) + 装运检验证书 (SC) |
| **肯尼亚** | KEBS / PVoC（出口前符合性验证）：CoC 证书 |
| **南非** | SABS 型式认可 / NRCS 合规确认 |
| **埃及** | GOEIC 检验：装运前检验 (PSI) + COI 证书 |
| **摩洛哥** | SNCP：产品符合性检验 (CoC) |
| **埃塞俄比亚** | ECS 检验：出口前符合性验证 |

## 通用环保与化学品

| 法规/体系 | 适用 | 核心要求 |
|-----------|------|---------|
| **ISO 14001** | 环境管理体系 | 全行业参考 |
| **ISO 45001** | 职业健康安全 | 工厂审核参考 |
| **QC 080000** | 电子行业有害物质过程管理 | RoHS/REACH 等 HSPM 体系 |
| **ZDHC MRSL** | 纺织/皮革/鞋类 | 生产限用物质清单，符合 ZDHC 层级 |
| ** bluesign®** | 纺织/染料 | 资源效率/消费者安全/水体/排放标准 |
| **OEKO-TEX® Standard 100** | 纺织品/皮革/辅料 | 100+ 项有害物质测试 |
| **GOTS（有机棉）** | 有机棉纺织品 | 认证有机原料 + 加工过程合规 |

## 常用检测报告关键项目速查

| 检测类型 | 必测项目 | 报告关键字段 |
|---------|---------|------------|
| **RoHS 全项** | Pb/Hg/Cd/Cr6+/PBB/PBDE + DEHP/BBP/DBP/DIBP（2025起） | 每项检测值 + 单位 + 判定 |
| **REACH SVHC** | ~240 项高关注物质 | 是否检出 + 浓度 |
| **食品接触材料** | 全面迁移/特定迁移/感官测试 | 迁移量 + 判定 |
| **玩具安全** | 物理机械/易燃/八大重金属/邻苯 | 每项测试结果 + 判定 |
| **FCC EMC** | 传导/辐射发射，抗干扰 | 测量值 vs 限值 |
| **CA Prop 65** | ~900 种化学品 | 警告要求 vs 暴露水平 |
