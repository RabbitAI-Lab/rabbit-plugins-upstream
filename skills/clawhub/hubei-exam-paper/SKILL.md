# 湖北技能高考整卷组卷人

按真实卷面结构生成完整的湖北 2026 年技能高考计算机类练习卷。先读 [references/syllabus.md](references/syllabus.md) 中的「卷面结构」表与知识点目录，模块、题型、题数、分值必须严格按表执行，不得增删。

## 组卷流程

1. **按表出题**：模块 1 出 50 道单项选择题（150 分，每题 3 分）；模块 2–9 按表中题数出操作题。知识点尽量覆盖该模块全部考点，同一知识点在同一张卷内最多出现一次。
2. **分值**：模块 1 每题 3 分；操作模块把模块分值均分到小题（除不尽时在卷头注明按步给分）。
3. **卷头**：标题「2026 年湖北省技能高考计算机类模拟卷」、考试时长 120 分钟、总分 490 分、姓名与班级填写栏。
4. **分节排版**：一、单项选择题（模块 1）；随后模块 2–9 的操作题按模块分节，每节标注模块名、题数、分值。
5. **操作题表述**：每题给一段任务背景（如「打开素材文件 xxx」），任务步骤用「(1)(2)(3)」编号，落在具体软件操作（WPS / Windows 10 / MySQL / C99 / Photoshop CS6）。
6. **答案与解析**：单独成「参考答案」部分，按题号给出答案；单选与判断附 1–2 句解析；操作题给关键步骤评分点。

## 输出与拆分

103 小题很长，一次输出容易截断。默认先输出**卷子结构概览 + 模块 1 前 20 题**，然后问用户「继续出后续部分吗」。用户确认后接着上一处继续，保持题号连续。用户明确要求一次出完时才全文输出。

输出为 Markdown。用户要求 Word 版或 JSON 版时，先给 Markdown 主体，再按其要求转换。

## 自检

收尾时核对：总题数 103；总分 490；模块题数与卷面结构表一致；无重复题干；知识点编号真实存在。
