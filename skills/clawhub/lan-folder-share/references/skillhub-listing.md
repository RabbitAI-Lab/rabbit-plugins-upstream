# SkillHub 发布信息模板（网页发布用）

在 https://www.skillhub.cn 登录后进入「发布个人 Skill」，可复制以下内容到对应表单。若使用 CLI 发布（`skillhub init --name lan-knowledge-share`），本页的「功能说明」「示例」可写入 SKILL.md 正文或仓库 README。

## 技能名称（name）

lan-knowledge-share

## 一句话简介（description）

一键将本地文件目录部署为局域网可访问的 Web 知识库并开启 HTTP 服务，让局域网所有用户直接浏览 Markdown 文档、Excel 表格、HTML 报告与图片画廊，实现知识共享；文件改动刷新即生效，无需建库与预生成。

## 分类（category）

知识管理 / 效率工具

## 详细功能说明

- 一键启动：`node deploy.js <内容目录> [-n 站名] [-p 端口]`，零第三方依赖
- 任意目录即知识库：md / xlsx / csv / html / pdf / 图片 / 音视频混合目录开箱即用
- 动态侧边栏 + 自动目录页 + 图片画廊（键盘 ←/→/↑/↓ 切换）
- Excel/CSV 表格页面内在线预览与搜索；站内 .md / .html 报告点击就地展开查看
- 全站全文搜索（md 正文 + 表格单元格），实时扫描文件系统，改动刷新即生效
- 自动识别两种形态：任意纯内容目录（前端运行时内置注入，不污染内容目录）/ 自包含知识库（已有 index.html+assets 直接托管）
- 自动探测并输出局域网访问地址；端口冲突自动换用

## 示例

```
# 把 D:\团队资料 分享到局域网，站名「团队资料」
node deploy.js "D:\团队资料" -n "团队资料"

# 指定端口 9000，启动后自动打开浏览器
node deploy.js "D:\共享文档" -p 9000 --open
```

启动后终端输出本机与局域网地址（如 http://192.168.1.100:8089），局域网内其他电脑浏览器打开即可访问。

## 安全与合规要点（可写进详情）

- 面向可信局域网内容共享，无账号/权限体系，请勿用于需鉴权的敏感内容
- 服务仅绑定用户指定地址，默认 0.0.0.0；目录中 .git、node_modules 等噪音目录自动排除
- 页面渲染库来自公共 CDN，需服务器与外网可达
