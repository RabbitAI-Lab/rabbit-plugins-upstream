## Description: <br>
An interactive PESTEL macro-environment analysis guide that asks users to provide real inputs across political, economic, social, technological, environmental, and legal dimensions, then organizes the confirmed material into Markdown and HTML reports. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

MIT-0 <br>


## Use Case: <br>
Strategy, planning, and business analysis users use this skill to run a structured PESTEL interview for a specific company, market, product line, or project. The skill is intended to preserve user control over source facts and final judgments while organizing the results into presentation-ready reports. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill depends on user-provided business context and may produce weak or misleading analysis if required PESTEL inputs are skipped or treated as confirmed without review. <br>
Mitigation: Require substantive user input for each PESTEL dimension and clearly label skipped or provisional content as pending confirmation. <br>
Risk: Some helper files referenced by the artifact are not included, so report generation may depend on the agent's available tools or fallback behavior. <br>
Mitigation: Confirm generated report structure with the user and review outputs before using them for strategic decisions or presentations. <br>
