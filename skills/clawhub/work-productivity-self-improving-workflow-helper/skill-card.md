## Description: <br>
Helps AI-agent users, skill authors, maintainers, and teams create practical self-improving and proactive-agent workflows for bug fixing, setup hardening, reliability improvement, and adjacent skill development. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

### License/Terms of Use: <br>

## Use Case: <br>
Developers, skill authors, maintainers, and agent users use this skill to turn a self-improving or proactive-agent request into a concise plan, checklist, automation outline, code change, or decision aid. It is intended for practical workflow support that keeps assumptions, constraints, validation steps, and follow-up risks visible. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad productivity and self-improvement triggers may cause accidental invocation in unrelated conversations. <br>
Mitigation: Prefer explicit invocation or narrow trigger wording before deploying in shared environments. <br>
Risk: Workflow, code, shell command, or configuration guidance may be incorrect for a user's local environment. <br>
Mitigation: Review proposed changes and commands before execution, then validate outputs against the stated success criteria. <br>
