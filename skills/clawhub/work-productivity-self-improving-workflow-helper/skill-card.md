## Description:

Helps agent users, skill authors, maintainers, and teams turn self-improving and proactive-agent workflow needs into practical plans, checklists, analysis, code changes, or decision support.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, agent users, skill authors, maintainers, and teams use this skill to clarify productivity workflow goals, produce practical artifacts, and validate outputs against explicit success criteria. It is aimed at local-hardware-friendly workflow improvement rather than model training.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill allows implicit invocation and uses broad triggers such as self, improving, proactive, learning, organizing, and bug fix, so it may activate for unrelated requests.

Mitigation: Review before installation if automatic routing is enabled; prefer explicit invocation or narrow the trigger terms before enabling implicit use.
