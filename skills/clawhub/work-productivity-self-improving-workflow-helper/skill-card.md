## Description:

Helps AI-agent users, skill authors, maintainers, and teams turn self-improving and proactive agent workflow needs into practical plans, checklists, artifacts, analysis, code changes, or decision support.

This skill is ready for commercial/non-commercial use.

## Use Case:

AI-agent users, skill authors, maintainers, and teams use this skill to structure self-improving or proactive agent workflow work into clear outcomes, assumptions, implementation steps, and verification notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill uses broad self-improvement and productivity triggers with implicit invocation enabled, so it may be selected when the user did not specifically ask for proactive agent workflow support.

Mitigation: Before deployment, review trigger wording and consider narrowing or disabling implicit invocation in environments that auto-select skills aggressively.
