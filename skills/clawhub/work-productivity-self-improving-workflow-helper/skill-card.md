## Description:

Helps AI-agent users, skill authors, maintainers, and teams create self-improving or proactive-agent workflows for bug fixing, setup hardening, reliability improvement, and adjacent skill design.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

AI-agent users, skill authors, maintainers, and teams use this skill to turn demand for self-improving and proactive-agent patterns into practical workflows, checklists, analyses, code changes, or decision support. It is aimed at local-hardware-friendly improvements that clarify outcomes, surface assumptions, and validate the result against success criteria.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may trigger the skill for generic productivity or self-improvement requests.

Mitigation: Use explicit invocation when the task is specifically about designing, hardening, or improving self-improving/proactive agent workflows.

Risk: Generated workflow, code, shell, or configuration suggestions may introduce incorrect guidance or unsafe changes if applied without review.

Mitigation: Review proposed artifacts and commands before applying them, and validate outputs against the stated success criteria.
