## Description:

Use an OOMOL-connected Framejet account to capture public web pages as images and create signed capture URLs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

## Use Case:

Developers and other Framejet users can capture public web pages as PNG or JPEG images and generate signed capture URLs through their connected account.

### Deployment Geography for Use:

Global
