## Core Rules

- Read existing docs before changing code or project structure.
- Use evidence before diagnosis or implementation.
- Keep scope explicit.
- Distinguish local, test/staging, production, and external systems.
- Keep code changes and documentation synchronized.
- Update existing memory when it is useful for continuity.
- Record reusable findings once in existing documentation or optional `.learnings/` notes.
