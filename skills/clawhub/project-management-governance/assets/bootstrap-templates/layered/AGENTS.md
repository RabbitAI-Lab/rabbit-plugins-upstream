This file is the lightweight entry point for project collaboration rules. Keep stable, high-level rules here. Put detailed topic rules under `AGENTS/`.

## Core Rules

- Use a document-first, evidence-first workflow.
- Read existing project docs before changing code or project structure.
- Keep scope explicit and avoid silently widening tasks.
- Distinguish local development, test/staging, production, and external systems.
- Do not guess root causes from incomplete context.
- Keep implementation, documentation, and project learnings synchronized.
- Update current context when useful for continuity; retain details only when they have future value.
