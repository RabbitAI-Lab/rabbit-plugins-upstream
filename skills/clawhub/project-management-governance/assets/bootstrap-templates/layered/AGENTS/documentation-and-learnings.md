## Documentation Sync

When code behavior, structure, commands, interfaces, workflows, assumptions, or operating instructions change, update the matching documentation in the same work cycle.

## Learning Layers

- `tmp.md`: current context and links to relevant detail.
- `tmp/YYYYMMDDtmp.md`: dated details for project changes, evidence, validation, and handoff.
- `.learnings/`: staging area for candidates, errors, preferences, and reusable findings.
- `AGENTS/`: durable collaboration rules.
- `README/`: durable project context and navigation.
- `code/`: durable code contracts, commands, and runtime notes.

Distinguish confirmed conclusions from hypotheses; maintain each finding in the most relevant place.

Update current context when it affects the next task; dated notes are optional.
