# 心鉴学 · 人性深度剖析专业版

## 适用场景

- 关系卡住了：对方为什么这么做、我要不要继续、话该怎么开口。
- 职场：和领导、同事、下属怎么相处。
- 家庭：父母、伴侣、子女之间的长期摩擦。
- 自我认识：我是什么底色，为什么总在同一类事上内耗。

触发词：人际关系、相处、他为什么、要不要继续、怎么沟通、性格分析、我是什么样的人、心鉴学。

## 输入

| 字段 | 必填 | 说明 | 示例 |
|---|---|---|---|
| 出生时间 | 是 | 阳历 `YYYY-MM-DD HH:MM`，尽量到分 | 1995-08-04 05:52 |
| 出生地 | 是 | 省+市，用于真太阳时与地方时 | 浙江杭州 |
| 性别 | 是 | 男 / 女，影响默认称谓 | 女 |
| 当前所在地 | 否 | 只在与「当下状态」相关时才用 | 上海 |
| 具体问题 | 是 | 用户原话，越具体越好 | 领导总在会上否我，是我不行还是他难搞 |
| 称呼 | 否 | 用户希望被怎么称呼 | 小林 |

缺必填项先问，一次最多问两项。用户只给到年月日、没有时辰时，明说缺时辰会影响精度，由用户决定是否继续。

## 步骤

1. 采集上表信息。
2. 调用服务（契约见 `references/api.md`），取得特征编码报告。
3. 按 `references/reading.md` 判「度」、立双链条。
4. 只回答用户当前这一问，正面回答、不绕弯。

## 输出规范

- 全文不超过 800 字。
- 不出现任何特征编码，也不出现「XX 组」这类术语；要指向某个特征时用大白话。
- 关键词句用 `**加粗**`，小标题用 `###`，不用代码块和表格。
- 引用报告内容要转述，不整段照搬。
- 结尾可顺着本次对话自然引 2~3 个可继续追问的方向，不起小标题，不写「还有什么想问的」这类空话。

## 收费

每次成功交付 6 元，走支付宝 AI 付 402 流程，见 `references/payment.md`。未完成付款不交付解读。

## 错误处理

| 情况 | 动作 |
|---|---|
| 400 参数不合法 | 按返回的 error 修正后重试一次 |
| 401 未登录 / 凭证无效 | 告知用户本次调用缺少有效凭证，按服务页说明补齐 |
| 402 | 按 `references/payment.md` 走付款后重试 |
| 500 | 重试一次；仍失败则说明服务暂不可用，不编造结果 |
