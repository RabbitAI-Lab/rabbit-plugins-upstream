## Description:

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and teams use this skill to manage Courier profiles, lists, subscriptions, and messages through an OOMOL-connected account.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Automatic setup may execute unverified remote code and make broader agent changes.

Mitigation: Review and install a verified CLI release yourself, check its automatic agent-skill installation and synchronization settings, connect only needed Courier permissions, and retain confirmations for message, write, and delete actions.
