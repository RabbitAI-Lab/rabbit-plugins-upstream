# 保险计划书分析大师 · 安装说明

面向消费者/投保人的保险产品分析器。分析保险计划书与产品说明书，算 **IRR / 回本年限 / 总利益 / 翻倍年数**，
做单品深析与多品横向对比，输出报告与图表，并附消费者避坑清单。
含分红型理财险的**分红实现率压力测试**（0/25/50/75/100% 情景下的 IRR 与本金翻倍年份）。

- 版本：**v1.5.3**
- 支持形态：增额终身寿、年金、分红、两全、万能、投连；健康险/财产险走条款分析
- 支持输入：PDF / DOCX / XLSX 计划书与说明书，或直接粘贴参数
- 零依赖能力：只算 IRR / 出图 / 压力测试不需要装任何第三方库

## 三种安装方式（任选其一）

### 方式 1 · 手动拷贝（最稳妥，推荐）

把本压缩包解压后的 **`保险计划书分析大师`** 整个文件夹，复制到：

```
C:\Users\<你的用户名>\.workbuddypro\skills\
```

复制完长这样（**注意是两层：`skills\保险计划书分析大师\SKILL.md`**）：

```
C:\Users\<用户名>\.workbuddypro\skills\保险计划书分析大师\
└── SKILL.md          ← 这个文件必须在这一层
```

然后**重启 WorkBuddy**。技能无注册表，靠启动时扫描该目录加载。

### 方式 2 · 一键脚本（Windows）

双击同目录下的 **`install.bat`**，会自动把技能文件夹装到当前用户的 skills 目录。
装完同样需要重启 WorkBuddy。

想装到别的位置，可以在命令行里指定：

```
install.bat "D:\some\other\skills"
```

### 方式 3 · 技能管理页导入

WorkBuddy → 技能管理 → 导入/安装，选择
`保险计划书分析大师-v1.5.3-安装包.zip`。

## 装完怎么验证

在 WorkBuddy 里直接说：

> 用保险计划书分析大师分析这份计划书，并附上文件路径

能正常读取文件、输出 IRR 表、双轴图和压力测试表，就说明装好了。

也可以直接跑脚本验证三个引擎：

```
python scripts/classify_policy.py --name "XX年金保险(分红型)" --columns "保单年度,现金价值,生存保险金,累积红利,万能账户价值"
python scripts/irr.py --input examples/example_年金附万能.json --years 10,20,30,60
python scripts/irr.py --input examples/example_年金分红_累积生息.json --years 10 --out irr_tmp.csv
python scripts/make_chart.py --input irr_tmp.csv --out chart_tmp.svg --mode both
python scripts/stress_test.py --input examples/example_年金分红_累积生息.json --years 10 --times 1.05
```

最后三条应分别输出 `1.168%（保证）/ 2.261%（演示）`、一张 SVG 图、以及 0/25/50/75/100% 五档实现率表。
第一条会打印五道判断题的逐层结论 + 建议字段映射 + 总利益公式（零依赖，**装完第一个就跑它**）。
自检锚点：**压力测试的 0% 档 IRR 必须等于 `irr.py` 的保证口径、100% 档等于演示口径**。

> 示例产品只有 10 年期，10 年内总利益达不到保费的 2 倍，所以上面用 `--times 1.05` 演示
> 「达标年份随实现率从第 10 年前移到第 8 年」的效果。真实长年期产品直接用默认 `--times 2`。
