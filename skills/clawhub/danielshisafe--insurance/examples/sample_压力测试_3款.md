# 示例：分红实现率压力测试（3 款，含 1 款无分红对照）

> 本节对应 SKILL.md §7.15。真实案例：中信保诚三款产品，被保人 30 岁男，
> 年缴 100 万 × 5 年（总保费 500 万），评估年度第 75 保单年度（105 岁），翻倍倍数 K=2。
>
> 调用：
> ```bash
> python scripts/stress_test.py \
>   --input policy_金耀未来.json policy_恒盈金尊.json policy_诚耀人生.json \
>   --names "金耀未来" "恒盈金尊" "诚耀人生" \
>   --years 75 --benchmark policy_恒盈金尊.json --times 2 --out stress.csv
> ```

## 怎么读这张表（写报告时照这个思路讲）

**① 先看 0% 那一行——这是你的地板。**
三款里，恒盈金尊 1.750% 最高（它根本没有分红，所以每一档都一样）；
两款分红险在红利为零时掉到 1.593% 和 1.507%，**都低于那款不带分红的**。
换句话说：演示表上金耀未来比恒盈金尊高出一大截，但这个「高出」完全建立在红利兑现之上。

**② 再看临界实现率——这是决策阈值。**
金耀未来只需红利兑现 **8.6%** 就能追平恒盈金尊的地板收益，诚耀人生需要 **21.2%**。
临界值越低，说明「赌红利」的风险越小；临界值越高，说明你越是在为一个不确定的东西付溢价。

**③ 最后看翻倍年数——这是最直觉的一条。**
同样是「本金翻一倍」：

- 恒盈金尊：第 **59** 年（被保人 89 岁），不受红利影响；
- 金耀未来：红利全兑现第 **30** 年（60 岁），红利为零则要拖到第 **49** 年（79 岁）——**差 19 年**；
- 诚耀人生：红利全兑现第 **37** 年（67 岁），红利为零第 **69** 年（99 岁）——**差 32 年**。

消费者常问「我这笔钱什么时候能翻倍」，这张表直接给出**最好情况和最差情况**，比单讲 IRR 有效得多。

**④ 复利修正**：诚耀人生的现金红利是「储存生息」型，脚本自动反推出储存生息利率
**1.7500%**（从 74 个年度的「上年累积 + 当年红利 → 本年末累积」递推取中位数），
并按 `当年红利 × X` 重新累积，而非简单线性缩放累积红利。

## 自检（每次必做）

- 0% 行的 IRR 必须等于 `irr.py` 的**保证 IRR**：金耀 1.593% ✓、恒盈 1.750% ✓、诚耀 1.507% ✓
- 100% 行必须等于 `irr.py` 的**演示 IRR**：金耀 2.815% ✓、诚耀 2.376% ✓
- 对不上说明 policy JSON 的保证/演示字段填错了，先修数据再出报告。

## 固定的措辞红线

- 上表的实现率是**假设情景压力测试**，**不是**对中信保诚历史分红实现率的评价。
- 0% 不代表红利真会为零，只是「最坏情况」的下界。
- 本技能无实时实现率数据库，不抓取也不对比历史实现率（SKILL.md §十二.7）。
