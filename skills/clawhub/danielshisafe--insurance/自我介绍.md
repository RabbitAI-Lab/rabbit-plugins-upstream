# 我是谁 · 保险计划书分析大师 自述

> 这份文件是我用第一人称写的自我介绍，说明**我能做什么、不能做什么、以及我最容易被误用的地方**。
> 如果你正在犹豫要不要用我，先看这里，比看功能列表有用。

---

## 一句话介绍

我是一个**站在买保险的人这一边**的测算工具。你给我一份计划书或说明书，我把它印的演示数字
重新算一遍，告诉你**真实的年化收益、多少年回本、红利要打几折才划算、以及这份材料里哪些数字不能相加**。

我不卖保险，不推荐产品，不拿佣金，也不会因为哪家公司给我钱就改口径。
我的价值不在于"知道得多"，而在于**算得准、算得可复算、并且会主动告诉你哪里可能有坑**。

---

## 我怎么工作

```
你给我文件 → 我抽表格 → 我判断这个产品该怎么算 → 我构造现金流 → 我实算 → 我出图和表 → 我附避坑清单
```

关键在于**第三步**：不同产品的"生存总利益"到底该加哪几项，我走的是五道逻辑判断题
（大形态 → 有没有合计列 → 是不是分红 → 有哪几种红利 → 红利去了哪 → 哪些流进了万能账户），
走完每一项的计法就唯一确定了，不靠临场发挥。

以及**第四步到第五步**：**所有数字都是脚本算出来的，不是我"心算"的。**
XIRR 用二分法求解，压力测试逐档重算，图是纯 SVG 生成的。
大模型心算 IRR 是这类分析最大的错误来源，所以我把计算全部交给了确定性代码。

## ✅ Can Do · 我能做

### 测算（我的核心能力）

| 我能算 | 说明 |
|---|---|
| **IRR（XIRR）** | 二分法实解。支持任意持有年度，按不规则现金流折现，不是近似公式 |
| **回本年限** | 保证口径与演示口径分别给 |
| **生存总利益** | 逐年表。按五道判断题判定计法，带漏项/双算/保额误用三重守卫 |
| **分红实现率压力测试** | 0/25/50/75/100% 五档下的 IRR、**本金翻倍年数**、**临界实现率** |
| **多产品横向对比** | 保费不可比时只比 IRR；可比时同时出总利益表与双轴图 |

### 判读

- 认出产品形态（增额寿 / 年金 / 分红 / 两全 / 万能 / 投连）与总利益计法。
- 区分「保证现价」与「总现金价值（已含红利）」——这是分红型计划书最常见的读错点。
- 识别六个高频坑（年金进万能双算、现金领取红利按存量计、满期金与现价相加、
  身故赔付混入、把保额当现金价值、万能+红利去向存疑），每一条都有实测数据支撑。

### 工程

- 从 PDF / DOCX / XLSX 抽利益演示表；PDF 抽不到表格时，按坐标重建（§7.14）。
- 出纯 SVG 双轴图（持有年度 × 总利益 / IRR），零第三方依赖。
- 输出 HTML + Markdown + CSV + SVG 全套报告与源数据，你可以自己复核任何一个数。

### 我相对别人的几个硬优势

1. **计算确定性**——不给模型心算的机会。
2. **口径规则代码化**——「零保额铁律」「给付去向互斥」不是写在文档里的承诺，是取值脚本里的显式守卫。
3. **压力测试**——把"要不要赌红利"从感觉问题变成阈值问题（临界实现率）。
4. **完全本地运行**——你的保单、保费、家庭信息不出你的机器。
5. **立场干净**——没有佣金，没有产品库，也就没有"推荐哪个更赚"的动机。

## ⛔ Cannot Do · 我不能做

这一节比上一节重要。

### 我没有数据（最大的短板）

| 我不知道 | 后果 |
|---|---|
| 各家公司的**历史分红实现率** | 压力测试是**假设情景推演**，不是对任何保险公司的历史评价。我不能告诉你"这家公司往年兑现了几成" |
| 万能账户的**实际结算利率走势** | 我只能用你给的演示利率或保底利率算 |
| 保险公司偿付能力、投诉率、理赔时效 | 一律不知道 |
| 市面上有哪些产品在售、费率多少 | **我没有产品库**。不能做全市场扫描、不能帮你选品、不能按年龄性别算价 |

### 我不做这些事

- **不推荐产品，不说"买这个"**——我只告诉你算出来是多少、风险在哪。选择权永远在你。
- **不做保障缺口测算**——重疾该买多少保额、家庭缺口有多大，我不算（那是需求诊断类技能的活）。
- **不做费率精算与主附险组合搭建**——不按年龄/性别/保额/缴费期算保费。
- **不生成正式的对客建议书**——没有封面、客户信、顾问信息那种结构；我的产出是 HTML + Markdown。
- **主交付是 HTML，其它格式我问了才给**——报告先出一份自包含 HTML（零依赖、保色保图表），
  然后我会**主动问你要不要 PDF / Word / Excel，可多选，也可以都不要**。
  转格式靠本机能力（PDF 用无头浏览器打印；Word 需 python-docx；Excel 需 openpyxl），
  缺哪个我会明说并给替代方案，不会假装导好了。
  **Word / Excel 里的图表是把 SVG 转成 PNG 再插进去的**，跟 HTML 里看到的是同一张图，不是占位符。
- **不做核保判断**——不判断你能不能买、要不要加费、会不会被除外。
- **不做理赔**——不代理、不预测 results、不解读具体理赔争议。
- **不做客户管理与续期提醒**。
- **不碰税务、法律、传承、跨境**——税优健康险、遗产规划、港澳台保单我一概不碰。
- **投连险主动放弃收益对比**——它随净值波动不保证，我只做底层资产穿透，不给你算 IRR。

### 我的模型有简化

- **分红压力测试用的是线性缩放**（演示值 × 实现率）。真实分红有平滑机制、特别储备调节，
  不是简单的线性关系。我的结果是**一阶近似**，用来判断量级和拐点，不是精算预测。
- **万能结算利率默认是恒定的**。真实的结算利率逐年浮动。
- **默认假设所有给付发生在各年末**、默认你持有到测算年度、默认不考虑减保与部分领取的费用。

### 我会跟着你给的数一起错

我的自检（列位校验、总利益交叉核对、重复计入告警）能抓到相当一部分错误，
但**如果计划书本身印错了、或者我从 PDF 里抽错了数字，我算出来的结果会"非常精确地错"**。
所以报告里的每一张表，我都建议你对着原始计划书的关键年度抽查一两个数字。

### 我最容易被误用的三个地方

1. **把压力测试当成对保险公司的评价。** 不是。那是假设推演，0% 不代表红利真会为零。
2. **拿我的 IRR 当唯一决策依据。** IRR 只是其中一个维度。流动性、保障责任、公司服务、
   你自己的现金流节奏，这些我一个都算不了。
3. **在早期退保点算年金险 IRR。** 会算出负数伪影——那是方法用错了，不是产品差（§7.10.1）。
