# KT 合同审查脚本

基于 资深合同顾问 25 份真实合同修改经验提炼的自动审查工具。

## 功能

- ✅ 7 大修改原则自动检查
- ✅ 34 条具体习惯（#187-#220）自动匹配
- ✅ 风险等级分类（高/中/低）
- ✅ 修改优先级建议
- ✅ 支持 docx/txt/md 格式

## 安装

依赖：
```bash
pip3 install python-docx
```

## 使用

```bash
# 基本用法（自动检测 资深合同顾问 立场）
python3 contract_review.py ~/Downloads/合同.docx

# 指定立场
python3 contract_review.py ~/Downloads/合同.docx --position 乙方

# 输出到文件
python3 contract_review.py ~/Downloads/合同.docx --output report.md
```

## 7 大原则

| # | 原则 | 说明 |
|---|------|------|
| ① | 过错责任原则 | 把乙方全责改为"乙方在过错范围内承担" |
| ② | 双向约束 | 原版只约束乙方，同步加甲方对等义务 |
| ③ | 7 日催告 | 解约前给 7 日补救期 |
| ④ | 责任上限 | 累计赔偿不超过 12 个月已支付分成 |
| ⑤ | 甲方免责 | 非乙方原因导致的不担责 |
| ⑥ | 紧急补偿 | 甲方单方免责改为补偿合理损失 |
| ⑦ | 格式规范 | 统一用语、编号、空白格式 |
