# 换皮细则：六件事的执行标准

SKILL.md 给了六件事的清单。这份文件给**能直接复制的 token 模板、迁移顺序、对比度标准、和反例集**。

---

## 一、迁移顺序（顺序错了会反复返工）

```
① 先定底色 ─────────── 决定了一切对比关系的基准
② 重算所有对比度 ───── 底色变了，原来的字色全部失效
③ 改分层手段 ───────── 投影 → 描边 + 明度差
④ 调表面色 ─────────── 卡片与底色的差值
⑤ 调圆角 ───────────── 跟着明度走
⑥ 反相主按钮 ───────── 最后做，它是全场唯一的亮块
⑦ 加色相到材质 ─────── 半透明元素
```

**为什么不能颠倒**：底色是所有颜色的参照。先改字色再改底色，等于算两次。

## 二、完整 token 模板

### 模板 A · 浅色（纸面反射）

```css
:root {
  /* 底与面 */
  --bg:            #F7F3EC;   /* 奶油底，不用纯白 */
  --surface:       #FFFFFF;   /* 卡片 */
  --surface-alt:   #F1EBE0;   /* 次级面/输入框 */

  /* 字 */
  --text:          #2A2620;   /* 暖黑，不用纯黑 */
  --text-2:        #6B6357;   /* 次级 */
  --text-3:        #9C9285;   /* 弱化/占位 */

  /* 主色（仅三处：可点击/选中/金额） */
  --primary:       #3E5647;
  --primary-dark:  #2E4034;   /* hover/渐变暗端 */
  --on-primary:    #F7F3EC;   /* 主色上的字 */

  /* 功能标记色（不可为统一色调砍掉） */
  --mark-a:        #B87A6C;   /* 干枯玫瑰 - 主项 */
  --mark-b:        #8EA87A;   /* 苔绿 - 次项 */
  --mark-c:        #BE9A55;   /* 米金 - 点缀 */

  /* 分隔 */
  --line:          rgba(42,38,32,.10);
  --shadow:        0 2px 8px rgba(42,38,32,.07);  /* 浅色靠投影分层 */

  /* 形 */
  --radius:        16px;
  --radius-sm:     10px;
}
```

### 模板 B · 深色（桌面聚光）

```css
:root {
  /* 底与面 */
  --bg:            #141110;   /* 暖黑，绝不用 #000 */
  --surface:       #1E1A17;   /* 卡片，靠明度差分层 */
  --surface-alt:   #262019;   /* 次级面 */

  /* 字 */
  --text:          #F4EEE2;   /* 暖白，冷白在暖底上会发灰 */
  --text-2:        #A79D8E;   /* 次级 */
  --text-3:        #6E655A;   /* 弱化/占位 */

  /* 主色（仅三处） */
  --primary:       #E0B266;   /* 金铜 */
  --primary-dark:  #C79A4E;   /* hover/渐变暗端 */
  --on-primary:    #141110;   /* 主按钮上用近黑字 —— 反相 */

  /* 功能标记色（提高亮度以适配暗底） */
  --mark-a:        #D98B86;
  --mark-b:        #8EA87A;
  --mark-c:        #C79A4E;

  /* 分隔 —— 深色靠描边，不靠投影 */
  --line:          rgba(255,255,255,.07);
  --shadow:        none;

  /* 形 */
  --radius:        13px;      /* 比浅色小 3px */
  --radius-sm:     9px;

  /* 光 */
  --glow:          radial-gradient(ellipse at 50% 35%, rgba(224,178,102,.10), transparent 62%);
}
```

**两套模板的差值就是"换皮六件事"的量化形态。** 别自己重新发明。

## 三、对比度标准（必须算，不许目测）

| 元素对 | 最低比 | 说明 |
|---|---|---|
| 主文字 vs 底色 | **10:1** | 深色界面里这条最容易达标，反而常被过度调亮 |
| 次级文字 vs 底色 | **4.5:1** | 深色界面最常见失误：把次级字调到 3:1 以下，看着"高级"，实际读不了 |
| 弱化文字 vs 底色 | 3:1 | 仅用于占位符、禁用态 |
| 主色 vs 底色 | 3:1 | 主色要能当边框/图标用 |
| 按钮字 vs 按钮底 | **4.5:1** | 反相按钮特别容易踩：亮金底 + 纯白字只有 2:1 |
| 描边 vs 表面 | 1.2:1 就够 | 描边是暗示，不是分隔线，别做太重 |

**深色界面的通病**：所有颜色都比浅色版暗一点，结果次级文字集体掉到 3:1 以下，整屏"糊成一片但有氛围"。**氛围感正是这样来的，可读性也是这样丢的。**

修正手段：不要提亮所有颜色，只提亮**需要被读的**那一层。层级差靠"提亮重要层"建立，不靠"压暗次要层"。

## 四、六件事的代码级做法

### ① 光源

浅色版：无方向，靠投影和留白建立层次。

深色版：**加一层固定光晕**，让内容"被照亮"而不是"被贴上去"。

```css
.hero-image::after {
  content: "";
  position: absolute; inset: 0;
  background: radial-gradient(ellipse at 50% 35%, rgba(224,178,102,.10), transparent 62%);
  pointer-events: none;
}
```

配套：图片容器内部四周加 `inset box-shadow`，模拟边缘压暗。

```css
.stage { box-shadow: inset 0 0 60px 20px rgba(10,8,7,.55); }
```

### ② 底色

规则：**冷色底配冷字，暖色底配暖字。** 混搭会让整屏"发脏"，而这种脏很难定位到具体元素。

深色底色取值区间：`#12~#1A` 区间内，R > G > B（暖）。例：`#141110`、`#171412`、`#1A1613`。

避开的：`#000000`（发灰）、`#111` 纯灰（发死）、`#1E1E1E`（无温度）。

### ③ 分层手段

```css
/* 浅色：靠投影 */
.card { background: #fff; box-shadow: 0 2px 8px rgba(42,38,32,.07); }

/* 深色：靠描边 + 明度差 */
.card {
  background: var(--surface);          /* 比底色亮 2 个明度级 */
  border: 1px solid var(--line);       /* 1px 半透明白 */
  box-shadow: none;
}
```

**判断有没有做对**：把截图转灰度，浅色版的卡片边界仍然清晰（投影起作用），深色版的卡片边界也清晰（描边起作用）。两者都糊 → 分层手段错了。

### ④ 圆角

| 底色亮度 | 圆角 |
|---|---|
| 浅（L > 90%） | 16–18px |
| 中 | 14–16px |
| 深（L < 20%） | 13–14px |

**原理**：圆角处的抗锯齿过渡在低对比背景下会被感知为"晕开"。曲率越大，晕开面积越大。

### ⑤ 主按钮反相

```css
/* 浅色：主色填充 + 浅字 */
.btn-primary { background: var(--primary); color: var(--on-primary); }

/* 深色：亮色填充 + 近黑字（反相） */
.btn-primary {
  background: linear-gradient(135deg, #E0B266, #C79A4E);
  color: #141110;
  box-shadow: 0 4px 16px rgba(224,178,102,.18);
}
```

**一条纪律**：整屏只允许**一个**这样的高饱和实心块。出现第二个，视线就散了。

### ⑥ 材质

| 元素 | 浅色做法 | 深色做法 |
|---|---|---|
| 玻璃/瓶体 | `rgba(255,255,255,.45)` + 白边 | `rgba(224,178,102,.08)` + `rgba(224,178,102,.40)` 边 |
| 半透明遮罩 | `rgba(255,255,255,.7)` | `rgba(20,17,16,.75)` |
| 毛玻璃 | `backdrop-filter: blur(12px)` + 白 | 同 + 暖黑底 |

**深色里的透明必须带色相**，否则就是一块灰。

## 五、反例集（出现即返工）

| # | 反例 | 为什么错 | 改法 |
|---|---|---|---|
| 1 | 深色底用 `#000` | 内容发灰，字边缘发毛 | 暖黑 `#141110` |
| 2 | 深色界面还在加投影 | 阴影看不见，白做功 | 改 1px 描边 + 明度差 |
| 3 | 浅色界面靠描边分层 | 线太多显脏，像表格 | 改投影 + 留白 |
| 4 | 深色界面圆角 18px | 边缘晕开，像没对齐 | 收到 13–14px |
| 5 | 半透明白玻璃放暗底 | 是一块灰，没有厚度 | 加暖色相 8% + 40% 亮边 |
| 6 | 主色用了 5 种 | 花屏，失去焦点 | 收回三种用途 |
| 7 | 主按钮亮底 + 白字 | 对比只有 2:1，看不清 | 亮底 + 近黑字 |
| 8 | 次级文字压到 3:1 以下 | 有氛围但不能读 | ≥ 4.5:1 |
| 9 | 为了统一色调砍掉功能标记色 | 用户分不清主次项 | 改成低饱和同色系，保留区分 |
| 10 | 整屏两个高饱和实心块 | 视线分散，不知道点哪个 | 只留一个 |
| 11 | 换皮后还留着原版阴影角度 | 光源方向矛盾，假 | 统一到一个光源 |
| 12 | 只换配色不改间距 | 密度还是原版的，气质不变 | 深色通常需要加 2–4px 呼吸 |

第 12 条最容易被忽略：**深色界面在同等间距下显得更挤**。视觉重量大，需要更多空气。

## 六、换皮验收三道闸

```
闸 1  灰度测试
      截图转灰度，层级是否仍然清楚？
      └─ 糊 → 分层手段错了，回 ③

闸 2  遮标测试
      遮住 logo，还认得出原版吗？
      └─ 认得出 → 没换干净，回 ①

闸 3  首屏测试
      给一个没见过原版的人看 5 秒，问"这是做什么的"
      └─ 答不出核心用途 → 信息层级有问题，不是配色问题
```

第 3 闸常被跳过，但它最有用：**好看的换皮经常把功能说糊了**。
