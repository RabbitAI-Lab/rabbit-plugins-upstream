# 未成年人保护合规护栏 (minor-protection-guard)

发布前实时拦截网络产品、游戏、直播、社交、教育场景中的未成年人保护高频违规表述。免费、本地、零网络。

## 依据（均全文公开）

- 《中华人民共和国未成年人保护法》（2021-06-01 施行）"网络保护"专章
- 《未成年人网络保护条例》（2024-01-01 施行）
- 国家新闻出版署《关于防止未成年人沉迷网络游戏的通知》（2019-11-01，2021 补充收紧至每周最多 3 小时）
- 《中华人民共和国个人信息保护法》第三十一条（不满十四周岁未成年人个人信息需监护人同意）

## 检测类别（6 类）

1. 未落实实名认证（high）
2. 未提供未成年人模式 / 青少年模式（high / medium）
3. 游戏未落实防沉迷 / 无时长限制（high）
4. 诱导未成年人消费 / 打赏（high）
5. 收集儿童个人信息未取得监护人同意（high）
6. 向未成年人推送不良信息（medium）

## 用法

```bash
# 文本格式
python scripts/guard.py --text "本游戏无需实名认证，未成年人可全天游戏，可无限充值"

# JSON 格式（Agent / 程序消费）
python scripts/guard.py --text "无青少年模式，儿童信息无需家长同意" --format json

# 列出全部类别
python scripts/guard.py --list-categories
```

无任何第三方依赖、无网络请求。规则为 `scripts/rules/terms.py` 声明式词表，透明可审。

## 与 ai-persona-guard 的关系

ai-persona-guard 覆盖 AI 拟人化互动（虚拟恋人等）中的未成年人保护；本工具覆盖通用产品 / 平台合规。面向未成年人的 AI 互动产品建议二者叠加。
