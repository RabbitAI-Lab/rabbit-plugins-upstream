# 公文文种选择速查

仅在用户未明确文种时使用。

- 请示：向上级请求批准或指示；一事一请；结尾用 `妥否，请批示。`
- 报告：向上级汇报工作、情况或结果；不提批准请求；补全结构时以 `特此报告。` 结尾。
- 函：不相隶属机关之间商洽、询问、请求协助、答复或反馈意见；无意见答复通常用函。
- 通知：布置工作、转发文件、公布事项、要求执行。
- 批复：上级答复下级请示。
- 意见：提出指导意见、实施办法、政策或工作建议。
- 纪要：会议记录，含议定事项、参会单位、后续跟进。

判断参考：

- 用户明确说请示/函/报告，从其意。
- “征求意见/无意见/函复” → 通常为函。
- “请批准/请审定/提请研究” → 通常为请示。
- “汇报/报送情况/说明进展” → 通常为报告。
- “请各单位落实/转发” → 通常为通知。
