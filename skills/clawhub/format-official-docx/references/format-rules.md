# 党政机关公文格式规则

本规则提炼自本地公文格式规范。若与通用 GB/T 9704 知识冲突，以本规则为准。

## 页面

- 用 A4 纸；标准页边距：上 3.7 厘米、下 3.5 厘米、左 2.8 厘米、右 2.6 厘米。
- 部分本地函模板首页用上 5.1 厘米、下 2.1 厘米；仅在明确要求时使用。
- 固定行距 28.9 磅。默认文字颜色为黑色。
- 双面打印，左侧装订。

## 字体

- 红头 / 主标题：方正小标宋简体。
- 主标题：二号，居中。
- 正文：三号仿宋_GB2312；数字及拉丁文字用 Times New Roman。
- 一级标题（一、）：三号黑体。
- 二级标题（（一））：三号楷体_GB2312。
- 三级/四级标题（1． / （1））：三号仿宋_GB2312。
- 页码：四号宋体，格式为 — 1 —。
- 版记：四号仿宋_GB2312。

## 函

正式函应包含：

- 红色机关头，如 `某单位`，用大号红色方正小标宋简体。
- 机关头下方红色分隔线。
- 分隔线下方为发文字号，通常右对齐，如 `某字〔XXXX〕XX号`。
- 文种标题在文号下方居中。
- 正式标题通常包含发文机关行与事由行。
- 主送机关以 `：` 结尾。
- 正文简洁；复函/无意见函可用：“贵单位关于征求某事项意见的来函收悉。经研究，我单位无意见。特此函复。”
- 署名/日期右对齐并留出适当右空；可加联系人行与披露说明，如 `（此件不公开）`。
- 使用套印红头纸时，底部加红色结束线。

## 请示 / 上行文

正式请示/上行文应包含：

- 红色“发文机关名称+文件”红头，如 `某单位文件`，方正小标宋简体。
- 发文字号居左、签发人居右，同处一行；下方红色分隔线。
- 标题通常分为发文机关行与事由行。
- 主送机关以 `：` 结尾。
- 正文以 `妥否，请批示。` 结尾，除非用户禁止或正文已含此句。
- 署名与日期保持在一起。
- 多页/上行文加页码。
- 版记落偶数页：含印发机关与日期，并加分隔线。

## 报告

- 含标题、主送机关、正文、署名/日期。
- 仅在补全结构且正文缺失时，以 `特此报告。` 结尾。
- 上行报告可在日期下方加联系人行。

## 附件

- 正文之后空一行。
- 单个附件：`附件：XXX`。
- 多个附件：`附件：1．XXX`，换行后 `      2．XXX`。
- 附件名换行时与名称首字对齐。
- 每个附件首页左上角以三号仿宋_GB2312 标注 `附件1` / `附件2`。

## 署名 / 日期 / 版记

- 署名/日期前空约三行。
- 发文机关署名居中排版；成文日期右空四字（右对齐，右边距留约 2.26 厘米）。
- 署名与日期保持在一起；不要用“此页无正文”。
- 版记含抄送、印发机关、印发日期；抄送单位以 `。` 结尾。
- 主送/抄送标点：同一系统用 `、`；不同系统用 `，`。

## 文字规范

- 使用规范标点：《》、嵌套〈〉、〔〕；不要用 `< >` 代替 `〈〉`。
- 涉密文件：左上角三号黑体标注 `密级★保密期限`。
