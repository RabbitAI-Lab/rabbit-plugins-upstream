## Description: <br>
Build, redesign, and critique clean, presentation-grade slide decks (.pptx) for audiences such as research meetings, work updates, conference talks, stakeholder readouts, thesis defenses, teaching, and webinars. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Employees, external users, and developers use this skill to plan, build, redesign, review, and hand off presentation-grade PowerPoint decks from user-provided material, templates, documents, figures, or research needs. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill runs local deck-building code and processes user-provided source files, templates, scripts, SVGs, PDFs, and direction JSON. <br>
Mitigation: Install and run it only when the skill and input files are trusted, and review generated outputs before sharing or reusing them. <br>
Risk: Generated HTML previews, remote assets, broad web research, and paid image-generation calls can expand the trust boundary or incur external effects. <br>
Mitigation: Avoid opening generated HTML previews from untrusted motif content, and confirm before updates, paid API image generation, broad web research, or downloading remote assets. <br>
Risk: The skill can persist and write deck artifacts in user-accessible locations such as Downloads or registry files. <br>
Mitigation: Review Downloads outputs and registry taste files before treating the generated deck or preferences as final. <br>
