# 安全边界与本地兼容功能

本说明区分输出质量验收、脚本信任和操作系统隔离。通过结构/视觉验收不代表脚本安全，也不代表平台安全审核通过。

## 输出目录与旧合同

- `scripts/package_delivery.py` 与 `scripts/build_public_bundle.py` 首次输出使用不存在的专用目录。已有目录即使为空，也不默认为工具所有；不要选择原资料目录、工作目录、仓库根目录或它们的祖先。
- 重建必须显式传 `--overwrite`，且目标须有匹配该工具和目标路径的所有权标记。没有标记的旧输出不自动接管；选择新的空闲路径，并由用户自行检查和保留旧文件。
- 相互重叠的输入/输出、符号链接和未拥有的外置 ZIP/清单禁止覆盖。构建、验证或发布失败时保留先前产物；只清理本次独占创建的随机临时目录。多文件替换可回滚，但不是断电原子事务；同一路径不支持并发写入。
- 原 `profile`、`--manifest`、可选 `--zip` 与交付状态合同继续有效。所有权标记是本地误删保护，不是对恶意本机用户的权限隔离；它不进入交付 ZIP。

## contribution 本地导出

`engine.autonomy.contribution_bundle(traces, store, shared_export=True)` 仅在用户明确同意分享结构统计后调用。默认不授权就拒绝，不读取待导出的本地记录；函数不上传任何内容。

仅保留受限角色、行列结构、已知决策枚举和有界数值；不复制正文、任意 evidence/候选说明、私密标识、路径或记录扩展字段。版本 1 的 `bundle_version`、`local_archetypes`、`decisions` 顶层合同不变。结构统计仍可能暴露工作模式，分享前必须人工检查；这不是匿名性保证。

## 高级兼容代码：受信任的宿主执行

Bespoke、旧 Template 模型组件及 `refine-code` 会执行用户/模型作者提供的 Python，保留此正常高级能力，但默认拒绝执行。操作者必须先审阅脚本及其导入，再在**单次进程环境**同时设置：

```sh
PPTSMITH_ALLOW_HOST_CODE=1 \
PPTSMITH_TRUSTED_SCRIPT_SHA256=<reviewed-script-sha256> \
python3 -m engine refine-code --script reviewed.py --source doc:markdown:source.md --ir ir.json --output-dir dedicated-output
```

用本机 `shasum -a 256 reviewed.py` 或等效工具获得待审脚本哈希。哈希不是用户授权的替代，不能从 IR、manifest 或模型输出自动接受授权；脚本变更后必须重新审阅并授权对应哈希。不要在 shell 启动配置中永久导出这些变量。

授权后以当前用户权限执行；验证过的脚本可导入其他代码、访问文件或联网，**不是 Python 沙箱**。精确校验只覆盖入口脚本字节，不覆盖所有依赖或转导入。不要把未知作者代码视为普通资料；需要处理不可信代码时应另用适当的外部隔离环境，不能通过质量门禁或授权开关冒称隔离。动态加载仍存在且可供审查，不以改名或删除检测规避。

正常 create/recreate 的声明式 scene、原生 Template 的受限操作与上述高级代码入口不同；不为消除扫描关键字而删除原生能力。`--require-os-isolation` 仍须遵守：隔离不可用就拒绝，不能以宿主授权降级替代。

## 安全依赖与安装兼容性

当前锁定 Pillow 13.0.0，最低 Python 3.11；可选 PptxGenJS 运行时将传递依赖 image-size 固定覆盖为 2.0.4，需要 Node.js 18 或更新版本。使用独立虚拟环境和 `npm ci` 安装，不修改全局依赖，也不要静默降级到旧的不安全锁定版本。固定原生模板工具不因可选 Node 运行时升级而新增 Node 依赖。

这不等于所有格式、所有平台或所有官方公告均已证明安全。部分 image-size 公告的受影响范围与修复版本元数据相互矛盾，应结合公告正文、实际版本源码及受限回归证据判断，提交平台复核时如实披露。

## Office 会话与诊断

Windows 兼容渲染器可能连接已有 PowerPoint；不能把 `Dispatch` 或 `DispatchEx` 当作进程所有权凭证。只关闭本次打开的只读临时文档，不退出用户应用；可能留下空的应用进程，安全清理由用户执行。可用性探测不启动应用，版本读取不退出应用。真实 Windows/Office 行为仍需在目标环境验收。

隔离诊断显式运行时只对自己创建的 sentinel、任务内 Unix socket 和回环 TCP 做验证；它不是网络上传功能。环境变量复制用于启动本地子进程，不足以证明窃密或外传。打包规则里的凭据文件名是**禁止进入发行包的排除项**；普通 `token` 变量也不是凭据读取。不能由这些词法匹配直接得出恶意行为结论。
