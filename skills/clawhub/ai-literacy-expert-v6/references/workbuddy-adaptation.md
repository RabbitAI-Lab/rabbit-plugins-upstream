# WorkBuddy 运行环境深度适配总纲（V5 全面升级 · V5.5 加固）

> 本文件定义「AI 通识课资深专家 V5.5」在 **WorkBuddy**（腾讯云 CodeBuddy 旗下的全场景 AI 办公工作台 / 桌面 Agent）中运行时的**全面适配规则**。它是 A→G 七模块 + E·N 院校子模块 + 六大能力在 WorkBuddy 环境下的「落地宪法」，所有能力在 WorkBuddy 内触发时，须先对齐本总纲，再回落到通用规则。
>
> **为什么需要本总纲**：技能原设计假设"生成 HTML 文件让用户下载""素材指向外部 IMA 分享链接""协作需自建 OT 服务器"。而 WorkBuddy 是**原生集成资料库 + 设备侧能力**的 AI 执行者——它可以直接读写 IMA 知识库与腾讯文档、调用设备侧的日程/备忘录/分享。本总纲把上述假设升级为 WorkBuddy 原生能力落地，避免"让用户去别处打开"的低效路径。

---

## 1. WorkBuddy 能力边界（技能必须对齐）

| 能力域 | WorkBuddy 原生能力 | 技能对应用法 |
|--------|-------------------|--------------|
| 资料库（知识库） | **原生集成 IMA 知识库 / 腾讯文档 / 乐享知识库**，左侧「资料库」入口 OAuth 授权后可直接读写 | 课程素材落库 IMA；备课包/评估/协作文档直接存腾讯文档 |
| 文件与分享 | 系统分享面板（分享文本/文件/图片）、保存到 IMA、保存到腾讯文档 | 课件/游戏/备课包一键落库与分发 |
| 设备侧（MCP） | 闹钟、日历事件、备忘录、剪贴板、打开页面 | 学习提醒、课程表、备课笔记、快捷复制 |
| 运行沙箱 | HTML 预览在浏览器沙箱运行，支持 p5.js / JS | 课件与游戏在 WorkBuddy 预览面板直接打开 |
| 账号与权限 | 用户已登录账号，资料库需授权 | 涉及 IMA/腾讯文档读写前确认授权状态 |
| 智能体协作 | 可调用子 Agent / 多 Agent 编排 | C4 多 Agent、协作备课室、G2 Agent 设计师直接复用 |

> ⚠️ **关键约束**：所有写入 IMA 知识库 / 腾讯文档的操作，必须先确认用户已授权对应资料库；未授权时提示用户先完成 OAuth 授权，不得静默失败或编造落库成功。

## 2. 六大能力在 WorkBuddy 的落地映射

| 能力 | WorkBuddy 内交付方式 | 与原设计的差异 |
|------|---------------------|----------------|
| 能力一 课件 | p5.js 单 HTML → 在 WorkBuddy 预览面板打开；可"保存到 IMA 知识库"或"分享" | 不再只让用户下载文件 |
| 能力二 游戏 | p5.js 单 HTML → 预览面板打开；可保存到 IMA / 分享 | 同上 |
| 能力三 备课 | 4 格式文档（excel/word/ppt/pdf）→ **直接保存到腾讯文档**（可多人协作编辑）；或本地 HTML 预览 + 一键分享 | 文档云端化、可协作 |
| 能力四 评估 | 测评单 HTML → 预览；学习报告可存 IMA / 腾讯文档 | 报告可沉淀复用 |
| 能力五 推荐 | 课程路径 JSON/HTML → 预览；可"写入备忘录"做学习计划 | 路径变可执行计划 |
| 能力六 协作 | **腾讯文档**作为协作文档载体 + IMA 知识库作为共享素材库 + WorkBuddy 分享/日程做分发 | 不再要求自建 OT 服务器 |

## 3. 课程素材：从"外部链接"升级为"IMA 原生落库"

- **原方式**：`kb-asset-index.md` 指向 `ima.qq.com` 外部分享链接，要求用户"去 IMA 客户端打开"。
- **WorkBuddy 方式**：IMA 知识库是 WorkBuddy **资料库原生来源之一**，技能可直接：
  1. **检索**：用户问"有没有 A1 的课件" → 先在 IMA 知识库检索，命中则直接引用/预览，而非只给链接；
  2. **落库**：技能新生成的课件/备课包/评估报告 → 经用户授权后**保存到 IMA 知识库**（用 WorkBuddy 保存工具），形成机构/班级专属课程库；
  3. **分发**：用 WorkBuddy 分享工具把链接/文件发给学员群。
- 详见 `references/kb-asset-index.md` 的「WorkBuddy 落库指引」补丁。

## 4. 协作备课室：从"自建 Web App"升级为"腾讯文档 + IMA 原生协作"

- **原方式**：`collaboration-guide.md` 设计自建实时协作 Web App（OT 算法、自建服务器）。
- **WorkBuddy 方式**（更高效、零运维）：
  1. **协作文档** → 用**腾讯文档**创建备课文档，天然支持多人实时编辑、评论、版本历史；
  2. **共享素材** → IMA 知识库存课程素材，备课组共享检索；
  3. **分发与提醒** → WorkBuddy 分享工具发文档链接 + 日历事件排备课会 + 备忘录记待办；
  4. **角色分工** → 在腾讯文档内用不同作者/批注者身份体现主讲/助教/审核，无需自建权限系统。
- 见 `references/collaboration-guide.md` 的「WorkBuddy 原生协作」补丁。

---

## 5. 备课包交付：从"浏览器下载"升级为"云端生成 + 可协作"

- **原方式**：`interactive-lesson-builder-guide.md` 生成单 HTML，老师浏览器填表 → 下载 4 格式。
- **WorkBuddy 方式**：
  1. 生成的 Excel/Word/PPT/PDF → **直接保存到腾讯文档**（云端、可分享、可协作编辑）；
  2. 同步在 WorkBuddy 预览面板给出 HTML 交互版；
  3. 用分享工具把文档/链接发给教研组的腾讯文档协作者；
  4. 用日历工具排"备课评审会"、备忘录记"发布前待办"。
- 见 `references/interactive-lesson-builder-guide.md` 的「WorkBuddy 交付」补丁。

## 6. 离线支持：对齐 WorkBuddy 沙箱边界

- 课件/游戏 HTML 在 WorkBuddy **预览面板（浏览器沙箱）** 运行，Service Worker + IndexedDB 方案基本可用；
- **边界声明**：部分沙箱对 Service Worker 注册、持久化存储有限制，交付时须：
  1. 在「强制测试门控结果块」中标注 SW/IndexedDB 在 WorkBuddy 预览下的实测情况（可用/受限/需用户实测）；
  2. 受限时降级为"已生成内容本地存储于对话上下文 + 可重新生成"，不阻塞主功能；
- 见 `references/offline-support-guide.md` 的「WorkBuddy 沙箱边界」补丁。

## 9. 权限与安全（WorkBuddy 强化）

- IMA / 腾讯文档写入前**必须确认授权**，未授权先引导授权；
- 不把学生姓名/教师联系方式等敏感信息写入可分享的云端文档（回扣 F2 隐私）；
- API Key 等凭据不进入课件/游戏 HTML，不写入知识库（回扣商用标准 §6）；
- 分享范围遵循最小必要原则（班级/备课组而非全网）。
