# 模块 E·N — 北师香港浸会大学（BNBU）博雅智能学院（SAI）专属 AI 赋能教学模块

> **定位**：本模块是「AI 通识课资深专家 V5」专业应用层（E 模块）下的**院校深度适配子模块**，专门服务于**北京师范大学-香港浸会大学联合国际学院（BNBU，简称"北师港浸大"）博雅智能学院（School of Artificial Intelligence, SAI）**。
>
> **服务对象**：
> 1. **学生**——尤以 SAI 顶尖 5% 新生为主，帮助其**最短路径实战上手 AI 应用与学习**，并将 AI 高度融入所学专业；
> 2. **教师**——让 AI **大幅提升备课效率、教学互动质量与评估反馈效率**。
>
> **数据依据**：本模块内容严格基于《博雅智能学院课程总览》与《博智坊 2025/26 第一学期系列总览》两份官方材料整理，确保专业方向、课程代码、工作坊主题真实可溯。

## 2. 新生 AI 实战上手路径（最短路径设计）

针对 SAI 新生"尽快实战上手"的核心诉求，设计 **「4 周 AI 实战上手加速包」**，与博智坊工作坊主题对齐，形成"课内认知 + 课外实战"的闭环。

### 2.1 四阶上手地图（对齐博智坊六期主题）

| 周次 | 上手主题 | 对齐博智坊 | 实战产出 | 推荐工具 |
|------|----------|-----------|----------|----------|
| 第 1 周 | 大模型基础与提示词 | 第一期·大模型基础及应用 | 用 AI 完成 1 篇论文摘要 + 1 页 PPT | Kimi / Qwen3 / 智谱清言 |
| 第 2 周 | Vibe Coding 速建原型 | 第二期·AI 速建原型 | 1 个可运行的小应用（待办/计算器/小游戏） | DeepSeek + Cline + VS Code |
| 第 3 周 | AIGC 创意实践 | 第四期·AIGC 基础及应用 | 1 件"专属 AI 数字 IP"或"梦想空间"作品 | 文生文/文生图提示词工程 |
| 第 4 周 | 视觉与数据智能 | 第六期·深度学习与 CV + 第一期数据分析 | 1 次 OpenCV 图像处理 + 1 次数据可视化 | OpenCV / Python |

### 2.2 新生"第一份 AI 作品"模板（可直接生成）
- **目标**：入学 30 天内产出 1 份可展示的 AI 作品，建立信心（呼应 SAI"每个人都可以成为创造者"）。
- **作品类型自助单**：
  1. 学术型 → 论文总结 + 文献可视化（适合 STAT/DS/AM/FM）
  2. 创意型 → AIGC 数字 IP / 3D 重建资产（适合 CM+MAD/CM+GD）
  3. 应用型 → Vibe Coding 小工具（适合 CST/EBIS/EPIN）
  4. 传播型 → AI 多语内容 + 数据新闻（适合 MCOM/DIS/TDH）
- **生成动作**：调用本技能【能力一 课件】或【能力二 游戏】或【能力三 备课包】配套产出教学/练习材料。

### 2.3 新生常见卡点与对策（来自博智坊真实反馈）
| 学生原话/困惑 | AI 赋能对策 |
|---------------|-----------|
| "希望更深入学 VS Code 与编程"（数字全球传播+N 学生） | 推送 Vibe Coding 进阶练习包 + Cline 实操卡 |
| "想学 AI 在商科的应用，如金融数学建模"（数学+N 学生） | 推送 FIN/FM 量化建模案例 + 数据分析实战 |
| "人脸识别高深，但实操后可平民化"（游戏设计学生） | 用 OpenCV 人脸检测闯关游戏降低门槛 |
| "3D 重建让我重新理解 AI 本质，想在 VR 用手势塑造物体"（媒体艺术学生） | 推送 3D 高斯泼溅 + p5.js/WebGL 互动课件 |

## 4. 教师 AI 教学增效方案（备课/教学/评估三提效）

### 4.1 备课提效（调用【能力三 问答备课】）
- **专业适配教案自动生成**：输入"课程代码 + 专业方向 + 课时"，自动产出对齐 SAI 公共核心课（如 `GD3103 AI for Art Students`、`BA2003 AI and Deep Learning`）的教案。
- **博智坊主题转课堂**：将六期工作坊主题快速改写成对应专业课的 1 课时微课（含 p5.js 演示）。
- **4 格式一键打包**：word/ppt/excel/pdf + zip，含离线缓存清单。

### 4.2 教学互动提效（调用【能力一 课件】/【能力二 游戏】）
- **抽象概念可视化**：把"神经网络""贝叶斯统计""3D 高斯泼溅"做成 p5.js 单文件互动课件。
- **游戏化破冰**：用沉浸式冒险游戏讲解"AI 伦理""提示词工程"，提升课堂参与（呼应博智坊"工作坊不是讲座"理念）。

### 4.3 评估反馈提效（调用【能力四 学习评估】）
- **自适应测评**：按专业方向生成题组（如 FIN 量化、TDH 文本分析），自动诊断薄弱点。
- **学习报告**：结合"博智坊学习认证计划"（4 工作坊达标），输出学生 AI 能力成长画像。

## 5. 与「博智坊」工作坊体系的衔接设计

博智坊是 SAI 实战驱动的核心载体。本模块将其六期主题作为**课件/游戏/备课的现成素材库**。

| 博智坊期次 | 主题 | 可直接生成的产物 |
|-----------|------|-----------------|
| 第一期 | 大模型基础及应用 | 大模型认知时间轴课件 + 论文总结实战包 |
| 第二期 | AI 速建原型 Vibe Coding | 待办/计算器/小游戏 Vibe Coding 课件 |
| 第三期 | AI 塑造游戏（数字化身/网格优化） | 游戏设计互动演示课件 |
| 第四期 | AIGC 基础及应用 | 提示词工程闯关游戏 + AIGC 创作工作流 |
| 第五期 | 3D 重建（NeRF/高斯泼溅） | 3D 表达对比可视化课件 |
| 第六期 | 深度学习与计算机视觉 | OpenCV 实操课件 + 人脸检测游戏 |

> **衔接机制**：当用户提到"博智坊""工作坊""认证计划"等词，自动关联本模块并推荐对应期次的实战产物。

## 7. 使用本模块的标准对话流程（给学生/教师）

**学生侧（新生实战上手）**
1. 告知专业方向（如"我是 CM+GD 游戏设计新生"）→ 匹配 §1.1 / §3.1
2. 选择上手目标（4 周加速包 / 第一份作品）→ 匹配 §2
3. 生成对应课件/游戏/实战包 → 调用能力一/二/三
4. 完成后用能力四自测、能力五规划下一阶段

**教师侧（教学提效）**
1. 告知课程代码 + 专业 + 课时 → 匹配 §1 / §3
2. 选择提效场景（备课/互动/评估）→ 匹配 §4
3. 生成对应交付物 → 调用能力三/一/二/四
4. 教研组复用 → 调用能力六协作备课
