## Description: <br>
Create and develop Obsidian plugins from scratch, including setup, manifest configuration, TypeScript features, settings UI, commands, ribbons, modals, and Obsidian API patterns. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineers use this skill to scaffold, configure, develop, test, and release Obsidian community plugins with TypeScript and Obsidian API patterns. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Example setup commands can create a public GitHub repository or run package scripts from an external template before the user has reviewed them. <br>
Mitigation: Confirm repository visibility, review the external template and package scripts, and run setup commands only in an intended development workspace. <br>
Risk: Generated Obsidian plugins may affect vault content when enabled during development. <br>
Mitigation: Test generated plugins in a non-critical vault before enabling them in a primary vault. <br>
