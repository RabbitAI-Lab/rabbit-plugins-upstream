# 山径夜灯 · 剧本

本例只演示 `parallax-scroll` 的层级契约。视觉方向是一次中性选择，不是默认模板。

受众：夜游读者。语气：短句、可独自走路时读。format：3D视差多层滑动。

默认视口 700。背景容器是一整段暖米色；远景慢、内容层承托正文、近景灯笼更快并带 0.036° 的轻微侧转。

## 四层职责

1. **背景容器** `background`：390×840 的纯色画布，盖住内容层的总高度。
2. **远景** `far`：`translateZ=-0.2`，一块 600 高的薄雾色块，不写转角。
3. **内容层** `content`：`translateZ=0`，800 高的开场加 40 高的 AI 声明，总高 840，高于远景和近景。
4. **近景** `near`：`translateZ=0.18`，`rotate3d="0.1 -1 0 0.036"`，500 高的透明灯笼。

## 叙事路径

1. 背景先铺暖米色，滑动时一直在透明处露出来。
2. 远景的雾带移动更慢，停在画面左侧。
3. 内容层写出标题和一句可独立成立的收口，最后是 AI 声明。
4. 近景灯笼靠右，只占局部，并有一点立体侧转。
