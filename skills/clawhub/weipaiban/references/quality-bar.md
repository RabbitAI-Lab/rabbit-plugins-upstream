# 交付水准（落盘前必过）

本页是所有 format 共享的最低交付标准。先满足所选 format 的专属质量闸门，再逐条过本页。

## 一、平庸的十个症状与修法

绝大多数不合格的产出都能对上其中几条。

| 症状                           | 为什么平庸                        | 怎么修                                                                                                 |
| ------------------------------ | --------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 封面标题细而软                 | `<text>` 字重恒 400，粗体流派全废 | `titleCarrier=foreignObject` 就必须走富文本加粗；细体流派改用大字距 + 大字号撑气质                     |
| 每屏都是「图 + 标题 + 一段字」 | 版式没有变化，读者三屏后就滑走    | 3–5 屏至少三种版式：满幅图屏 / 纯文字金句屏 / 数字或对比屏                                             |
| 所有卡片都是浅灰圆角矩形       | 卡片是默认值，不是设计            | 卡片形态跟流派走：直角流派（瑞士网格、报纸社论、黑白高对比、奢侈品）用**栏线与色条**分区，根本不用卡片 |
| 元素全部居中堆叠               | 居中是最省事也最没主张的构图      | 根据内容主动选择构图；用非对称留白、尺度差或稳定对齐线建立主张                                         |
| 颜色多而杂                     | 每屏各来一个新颜色                | 一篇最多 1 主 + 1 辅 + 1 强调；强调色面积控制在 10% 以内                                               |
| 文案是说明文                   | 「本文介绍了……」没有钩子          | 标题给具体名词或数字；金句要能被单独截图转发                                                           |
| 动效全是「渐现」               | 无节奏                            | 一篇一个主动效方案，同屏错峰 delay，循环强调只用于确有需要的位置                                       |
| hint 写「点击查看」            | 读者不知道点了会得到什么          | 动词 + 结果：「点开看夜里的样子 ›」                                                                    |
| 图片风格不统一                 | 同一介质不等于同一视觉世界        | 全篇共用 `imageMedium` + `lightingHint`，并写进每条 `visual`                                           |
| 屏与屏之间互不相干             | 像四张单图拼在一起                | 用一条连续线索串：序号、同位置的色条、贯穿的地平线、同一个人物                                         |

## 二、三秒测试

把整篇想象成缩到手机屏幕的截图，问三个问题。任何一个答不上就回去改：

1. **三秒内能读出主题吗？** 封面主标题必须是全篇最大的东西，且不被图片抢走。
2. **一眼能看出哪里可以点吗？** 引导胶囊要有色块或描边，不能只是一行小字。
3. **滑到最后记住了什么？** 收口必须给一件能带走的东西：一句金句、一份清单、一个日期。

## 三、结构

- [ ] 结构满足所选 format 的层级与节奏要求，每层职责清楚
- [ ] 高潮机制服务内容，没有为了使用某个组件而硬加交互
- [ ] 核心信息在未点击状态就能看到；到达核心信息最多 1 次点击。`quiz` 的题干和操作说明始终可见，结果允许逐题选择后点击触发区揭晓；`scene-transition` 的主题和当前幕提示点前可见，后续情节允许逐幕点击到达
- [ ] 每个可点的面都有点前可见的 `hint`，且 `hint` 不在点击出现的动画组里
- [ ] `layered-scroll` 的 clickPopup 位于 `foregroundContent`，并在 `backgroundContent` 有同高透明 spacer 保持滚动对齐
- [ ] `parallax-scroll` 根下先是 elevated 背景容器，再是纵向 parallax；恰好一个 `translateZ=0` 的内容层，其画布总高大于其他深度层，且不超过背景画布高度
- [ ] `parallax-scroll` 的远景和内容层不写 `rotate3d`；至少一层近景使用绝对值不超过 0.08 度的轻微转角；不写 `perspective`，也不做横向视差
- [ ] `coloring-scroll` 根下先是后层上色板，再是纵向 scroller；色板高度不小于视口，上半是附色，下半与滑动内容纸色相同
- [ ] `coloring-scroll` 要上色的区域是透明镂空；滑动层没有整屏不透明底，色板不接点击
- [ ] clickPopup 的 open 是清楚可见的图片按钮，不是小字号文本；按钮图不烘字，hint 字号至少 14px
- [ ] 收口内容全部可见，没有再套一层 `details`
- [ ] 最后一块是 `ai-credit`，文案一字不改

- [ ] `quiz` 每题至少两个选项且恰好一个正确项，说明每题只能选一次；题干在题组选项编组外
- [ ] `quiz` 各选项点击区域不重叠，选中态不遮挡其他点击区域；前态保留，后态叠加
- [ ] `quiz` 提交触发区明确，结果分数不重复且含 0 分，使用向下档位匹配
- [ ] `choice-expand` 数量是 2、4 或 6；同一行左右封面同高，左右展开同高且不小于封面高度
- [ ] `choice-expand` 封面未点击就能看懂选项和展开提示，展开稿有返回；文案不承诺展开一行会收起其它行
- [ ] `choice-expand` 热区盖住可见按钮；插画来自素材池，按钮和底色用 SVG

- [ ] `scene-transition` 外层占位与所有场景等高；场景层不占流式高度，根层裁剪后续场景
- [ ] `scene-transition` 每个非末幕点击后才播放；画布归零延迟等于该幕时间轴终点，尺寸动效挂在画布本身
- [ ] `scene-transition` 只有触发热区接收事件，末幕静态收场，相邻场景有明确承接关系

## 四、版面

重点检查：

- [ ] 同一阅读路径上的文字使用稳定对齐线
- [ ] 字号不超过 6 档，相邻档差 ≥ 1.4 倍
- [ ] 每屏一个焦点，元素 6–12 个

## 五、色彩

- [ ] 整篇只走一条 `colorRoute`，没有半途换路线
- [ ] `chromatic-dark`：深底有彩色（饱和 ≥25%），深底上的字也是有彩色浅色（饱和 ≥30%），无灰阶深底、无纯白字
- [ ] `photo-led`：图上压字用了净空区 / 半透明有彩色垫底 / 通栏色带三法之一
- [ ] 无 `#000000`、无 `#FFFFFF`、无白底卡片
- [ ] 正文与其所在底对比度 ≥ 4.5:1

## 六、素材

- [ ] 图片来自确认过的一个 tag 素材池、用户提供的文件，或用户点名的生图技能
- [ ] 素材池为空或某个槽位没有对应类型时，该槽位使用 dialect 占位图，并写进摘要
- [ ] 循环背景只用 `orientation=background`；没有则该槽位占位，不用竖图顶替，也不拼接
- [ ] 透明槽只用 `transparent=true` 的库图，`cropMode=contain`；库图不跑 rembg
- [ ] `layered-scroll` 的背景 overlay 直接纵向排列同一 URL 的 `<image>`，无 SVG 包裹，显示总高度不小于背景内容层高度
- [ ] `parallax-scroll` 的背景只在背景容器里，要么是一块纯色画布，要么是一张素材池里的图
- [ ] `coloring-scroll` 的纯色上色板直接写 SVG；波浪或笔触只在有场景图时用一张，不循环拼接，没有就改回 SVG
- [ ] logo / 二维码没有进清单

## 七、文案

- [ ] 封面主标题 ≤ 12 字，且过了框宽估算
- [ ] 每段 3–5 行，每句 15–25 字
- [ ] 收口金句能独立成立（脱离上下文也读得通）
- [ ] 每个 `hint` 都是「动词 + 结果」
- [ ] 没有「本文」「接下来」「让我们一起」这类过渡废话

## 八、动效

- [ ] 一个主动效方案；若使用可选方向脚本，可吸收其 `motion` 建议
- [ ] 同屏多元素错峰：后一层 `delay` ≈ 前一层 `delay + duration`，`duration` 不全相同
- [ ] 自动播放入场（`load` + 从透明开始）已注明「制作时透明度 0、编辑画布可见」
- [ ] 循环动效不超过两处，且不压过 `hint`
- [ ] 没有规划路径运动、描绘线、动画组内的宽高拉伸

## 九、一致性

全篇统一，不要一屏一个样：

- [ ] 字体（`titleFont`）、边距（`safeMargin`）、圆角（`cornerRadius`）、图片处理（`imageTreatment`）
- [ ] 强调色的用法（比如「只用在数字上」，就全篇只用在数字上）
- [ ] 有一条贯穿全篇的视觉线索

## 十、反默认

- [ ] 没有套用「清新手账 + 满版封面 + 日夜切换 + 浅灰清单」等安全模板
- [ ] 视觉与交互选择能从主题、受众或 format 体验中得到解释
- [ ] 若使用可选方向脚本，吸收的是可用灵感，没有机械照抄全部输出
