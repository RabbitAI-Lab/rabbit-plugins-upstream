## Use Case: <br>
Developers and engineers use this skill to prepare Polsia apps for Render deployment by adding the required health check, package scripts, migration timing, frontend build setup, and persistent file-storage approach. <br>

### Deployment Geography for Use: <br>

## Known Risks and Mitigations: <br>
Risk: Production deployment guidance could affect service availability if applied incorrectly. <br>
Mitigation: Review proposed changes before deployment and confirm the /health endpoint, build/start scripts, migration startup behavior, and file-storage approach in the target app. <br>
Risk: The skill gives repo-local operator guidance for Render deployment workflows. <br>
Mitigation: Use it in the intended project repository with normal authorization controls and review steps before applying writes or deployment changes. <br>
