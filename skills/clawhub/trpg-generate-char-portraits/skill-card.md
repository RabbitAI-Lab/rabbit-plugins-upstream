## Description: <br>
Generates character portraits for TRPG character sheets and embeds them into Excel files. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[ice26985850](https://clawhub.ai/user/ice26985850) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
External TRPG creators and game masters use this skill to create consistent portraits for sample player characters, main NPCs, and key enemies, then place the PNGs into Excel character sheets. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Image generation can spend credits for each portrait. <br>
Mitigation: Confirm the character count and expected generation cost before creating images. <br>
Risk: Embedding portraits can modify Excel character sheet layout. <br>
Mitigation: Use copies or version-controlled sheets when preserving the original layout matters. <br>
Risk: Incomplete character descriptions can lead to inaccurate visual details. <br>
Mitigation: Use existing setting details to fill minor appearance gaps and avoid adding unsupported core traits. <br>
