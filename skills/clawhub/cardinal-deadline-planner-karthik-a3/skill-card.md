## Description:

Turn synthetic deadlines and calendar commitments into practical daytime work blocks without changing the calendar.

This skill is ready for commercial/non-commercial use.

## Publisher:

[karthikvenugopal](https://clawhub.ai/user/karthikvenugopal)

### License/Terms of Use:

MIT-0

## Use Case:

People planning work around deadlines and meetings use this skill to find feasible daytime work blocks from actual task durations, deadlines, and calendar commitments.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Suggested work times may not fit the user's real availability or priorities.

Mitigation: Review each suggested time against the actual deadline and calendar before acting.

Risk: Task or calendar details may contain sensitive information.

Mitigation: Use synthetic, non-sensitive inputs as the security guidance specifies.

Risk: Optional Cardinal integrations depend on external tools.

Mitigation: Use those integrations only when they are separately trusted; the portable planner can run locally.
