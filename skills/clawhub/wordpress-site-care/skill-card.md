## Description:

Care for a WordPress site: check versions, plugins, themes, updates, error log and health; plan updates in order; verify a backup first; dry run, approval, verify.

This skill is ready for commercial/non-commercial use.

## Use Case:

Site owners and WordPress maintainers use this skill to inspect site health and available updates, plan maintenance, and carry out individually approved changes with backup checks and verification.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Optional Cloudflare capabilities can make DNS or zone-wide settings changes beyond routine WordPress maintenance.

Mitigation: Use Cloudflare only when the owner confirms it applies to the named site, and obtain approval for the exact DNS record or zone setting before changing it.
