## Description:

This skill is ready for commercial/non-commercial use.

## Use Case:

Agents and developers use this onboarding guide to configure SentiSense access and select the right skill for read-only stock-market research.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: An API key or temporary-key keep link could be exposed.

Mitigation: Keep keys and keep links private; exclude them from logs, commits, and shared screenshots.

Risk: Market research output could be mistaken for financial advice.

Mitigation: Present findings as educational research, not investment recommendations.
