## Description:

Helps authorized novel and short-drama teams turn Chinese source material into adaptation plans, episode beats, character and scene boards, storyboards, generation tasks, runnable AI-HIVE commands, and review checklists.

This skill is ready for commercial/non-commercial use.

## Use Case:

External creators, rights holders, scriptwriters, and production teams use this skill to convert authorized Chinese novel material into short-drama planning artifacts and optional AI-HIVE image/video generation tasks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow can submit paid AI-HIVE image or video generation tasks.

Mitigation: Review the final prompt, model, route, and price snapshot before running generation, and start with a small sample before batch jobs.

Risk: Uploaded novels, images, videos, logos, or reference materials may include content the user is not authorized to process.

Mitigation: Confirm rights to source text and media before upload, and use only abstract structure guidance when authorization is uncertain.

Risk: API keys or generated task records could expose private credentials, costs, or local media paths.

Mitigation: Keep API keys in environment variables or private config, avoid pasting real keys into prompts or logs, and review generated commands before execution.
