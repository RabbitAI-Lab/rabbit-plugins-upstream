# 综述综合与结构

## 选择主结构

### 时间脉络

用于回答“该领域如何发展”。按关键转折组织，不要按年份流水账罗列。

### 主题综合

用于回答“该领域围绕哪些科学问题形成了哪些证据”。每个主题包含问题、代表性证据、共识、争议和局限。

### 方法比较

用于比较数据、任务、模型、训练策略、评价指标和验证设计。结果不可比时说明原因，不做强行排名。

### 问题—方案

用于将现有瓶颈与解决方案配对。说明方案解决了什么、尚未解决什么以及证据是否充分。

### 证据—不足—方向

用于形成批判性综述。未来方向必须由具体证据缺口推出。

## 默认正文结构

1. 引言：重要性、现状、缺口、综述问题、范围和结构。
2. 研究发展脉络：关键阶段和转折。
3. 主要主题：按科学问题综合证据。
4. 方法与证据比较：数据、方法、评价与可比性。
5. 现有不足：文献内部局限和跨文献共同问题。
6. 未来方向：与不足逐项对应的可验证方向。
7. 结论：总结已被文献支持的认识，不引入新证据。

## 段落模板

每个综合段落依次考虑：

1. 主题句：提出本段中心判断。
2. 证据：组合引用相关研究。
3. 比较：说明一致、互补、差异或冲突。
4. 批判：解释证据边界、方法限制或可比性问题。
5. 小结：形成综合判断并引向下一段。

## 避免的写法

- 每句话只介绍一篇文献。
- 只总结方法，不回答综述问题。
- 用“效果更好”描述不可比较的研究。
- 只列局限，不解释局限造成的科学影响。
- 未来方向与前文证据缺口无关。
