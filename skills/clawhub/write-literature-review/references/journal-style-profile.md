# 目标期刊风格画像

## 样本筛选

优先选择：

- 与拟投稿文章类型相同或相近的文章
- 同一目标期刊的近期全文文章
- 普通期次中的代表性论文
- 主题或方法与拟写综述相近的文章

单篇样本只能提供个别范例。少于 3 篇时，将画像标记为“暂定”；5–10 篇通常可形成较稳定的观察。

## 分析维度

### 文章层面

- 标题结构和长度
- 摘要是否结构化
- 关键词数量和形式
- 章节名称、顺序和层级
- 各章节相对篇幅
- 局限和未来方向的位置
- 结论的长度与功能

### 段落层面

- 典型段落长度
- 主题句位置
- 证据密度
- 单篇引用与组合引用比例
- 比较、转折和小结方式
- 段落之间的衔接方式

### 语言层面

- 正式程度
- 谨慎或确定语气
- 主动与被动语态
- 第一人称使用
- 常见报告动词
- 情态词和模糊限制语
- 句子长度和复杂度
- 术语和缩写习惯

### 批判与综合

- 如何呈现共识
- 如何处理争议
- 如何评价方法限制
- 如何引出研究缺口
- 如何提出未来方向

### 图表层面

- 比较表、分类表和证据表的使用
- 时间线、概念框架和方法分类图的使用
- 图题、表题和正文引用方式

## 风格画像表

| 维度 | 共同特征 | 支持样本 | 例外样本 | 置信度 | 写作策略 |
|---|---|---:|---:|---|---|

置信度建议：

- 高：大多数同类型样本一致
- 中：超过一半样本出现，但存在明显变体
- 低：少量样本出现或可能属于作者个人风格

## 适配规则

- 只应用由多篇样本支持的模式。
- 区分官方要求、期刊共同惯例和单篇作者偏好。
- 官方要求与样本惯例冲突时，以当前官方要求为准。
- 不复制原句、独特搭配、标题或段落结构。
- 不把与综述主题无关的范文内容移入正文。
- 先保证证据准确，再做风格适配。
