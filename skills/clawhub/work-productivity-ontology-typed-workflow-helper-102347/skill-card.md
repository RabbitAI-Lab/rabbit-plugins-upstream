## Description: <br>
Helps agent users and skill authors turn ontology-style workflow demand into practical plans, checklists, analyses, code changes, and decision support for bug fixing, safety hardening, reliability improvements, or adjacent skill creation. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, skill authors, maintainers, and AI-agent users use this skill to convert ontology-style workflow needs into actionable local-friendly artifacts. It supports bug fixing, safety hardening, reliability improvement, workflow adaptation, and adjacent skill planning. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad activation wording may trigger the skill for general workflow or knowledge-graph requests where the user did not intend to use it. <br>
Mitigation: Prefer explicit invocation or tighter trigger wording for predictable activation. <br>
Risk: Generated workflow, code, shell command, or configuration guidance may be incorrect for a specific environment. <br>
Mitigation: Review proposed outputs against the user's stated success criteria and scan skill changes before deployment. <br>
