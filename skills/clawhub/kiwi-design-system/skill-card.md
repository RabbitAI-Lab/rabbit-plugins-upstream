## Description:

Apply PIP and contribute shared design-system improvements.

This skill is ready for commercial/non-commercial use.

## Publisher:

[whitekiwi](https://clawhub.ai/user/whitekiwi)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to apply the PIP design system in a product, review its design contracts, and carry authorized shared improvements through consumer verification and adoption.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A shared design-system change may not match the consuming app's installed package version or interaction behavior.

Mitigation: Check the installed package version and current package documentation, then verify the change in the consumer's relevant themes, states, and layouts.
