# WeChat Viral Topic Alchemy / 微信爆款选题炼金炉

## English

A pure-rule content-planning pipeline (no code execution) that turns material into actionable viral topics. Core: four viral genes (emotion / information gap / identity / action) + 12 planning principles + 8-dimension scoring card (total 40) + 12 title formulas + 10-category risk self-check. For Official-Account editors, short-video/Xiaohongshu creators, comic and H5 planners. Entry point is `SKILL.md`; detailed logic in `references/`, output skeleton in `templates/output-template.md`.
