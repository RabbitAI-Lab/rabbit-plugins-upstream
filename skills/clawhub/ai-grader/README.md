# ai-grader

## English

AI Grader — automated grading and quality-gate statistics for agent skills. Zero-dependency (Python stdlib), computes pass/fail rates, per-gate breakdowns and evidence inventory from grade logs. See `SKILL.md` for the full bilingual procedure (English-first, Chinese-after) and `grade_stats.py --help`.
