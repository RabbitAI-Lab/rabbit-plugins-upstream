# 内容源处理策略

## 支持的内容类型

### 1. 微信公众号文章 ⭐ 最常用

**URL 特征**:
```
https://mp.weixin.qq.com/s/xxxxxxxx
https://mp.weixin.qq.com/s?__biz=xxx&mid=xxx
```

**抓取方式**:
- ❌ curl/wget：只能拿到"请用微信打开"引导页
- ✅ Playwright：模拟真实浏览器访问，绕过反爬

**注意事项**:
- 微信有反爬机制，需设置合理 User-Agent 和延时
- 部分文章有访问权限限制（付费/原创声明）
- 抓取后提取 `<div id="js_content">` 内的正文

**版权风险**: 🟡 中低风险（用户主动提供链接 = 个人使用）

---

### 2. 知乎回答/文章

**URL 特征**:
```
https://www.zhihu.com/question/xxx/answer/xxx
https://zhuanlan.zhihu.com/p/xxx
```

**抓取方式**:
- 优先使用知乎公开 API（如可用）
- 回退到页面抓取，提取 `RichContent` 区域

**注意事项**:
- 知乎有反爬，需控制频率
- 部分回答需要登录才能看全文

**版权风险**: 🟡 中低风险

---

### 3. 普通网页

**URL 特征**: 任意 `http://` / `https://` 链接

**抓取方式**:
- 通用网页抓取
- 正文提取算法（如 readability-lxml、trafilatura）

**注意事项**:
- 动态渲染页面需要 Playwright
- 部分网站有 robots.txt 限制

**版权风险**: 🟡 中低风险

---

### 4. 纯文本输入

**识别方式**: 用户直接输入文本，不以 `http://` 开头

**处理方式**:
- 无需抓取，直接使用用户输入
- 可询问用户是否需要补充标题/作者信息

**版权风险**: 🟢 极低风险（用户原创内容或已获授权）

---

## 抓取失败处理

当内容抓取失败时，按以下顺序回退：

1. **重试一次**（网络抖动）
2. **切换抓取方式**（curl → Playwright）
3. **提示用户手动粘贴正文**
   > "该链接暂时无法自动抓取，请手动粘贴文章正文，我一样可以为你生成播客"

---

## 内容清洗规则

抓取后统一执行：

1. **去除噪音**: 广告、导航栏、评论区、相关推荐
2. **提取正文**: 使用 DOM 分析或正文提取库
3. **保留元信息**: 标题、作者、来源 URL（用于归因）
4. **长度限制**: 超长文章（>2万字）提示用户是否分段处理

---

## 版权合规总结

| 模式 | 风险等级 | 说明 |
|------|---------|------|
| 用户粘贴链接，单次处理 | 🟢 低 | 用户主动行为，个人使用 |
| 用户订阅源，平台定时抓取推送 | 🔴 中高 | 平台主动行为，需授权 |
| 只接官方 RSS + 明确归因 | 🟡 中 | 相对安全，但仍需关注 |
| 用户主动分享至小程序 | 🟢 极低 | 微信官方"用小程序打开"功能 |

**核心原则**: 让用户做主动方，平台只做工具。
