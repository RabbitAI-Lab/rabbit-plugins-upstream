This skill is ready for commercial/non-commercial use.

## Use Case:

Marketing and SEO analysts use this skill to research keyword demand, domain performance, competitors, ad history, and SpyFu usage.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: First-time setup may run an unverified remote CLI installer.

Mitigation: Verify the CLI release and installer before setup, and review any requested changes to other agent skills.

Risk: SpyFu requests through OOMOL may consume service credit.

Mitigation: Check expected usage and review monthly usage before large research runs.
