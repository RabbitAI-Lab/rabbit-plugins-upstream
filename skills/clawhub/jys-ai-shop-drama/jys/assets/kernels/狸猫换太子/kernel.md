# 狸猫换太子

## 内核简介
弱者被有权势的人冒名顶替劳动成果/身份，被贵人发现真相后揭露、处置反派、为受害者正名。

## 情绪节奏
委屈（被冒名被压制）→ 愤怒（冒名者嚣张得意）→ 爽快（真相揭露产品验证）→ 温暖（受害者获正名+补偿）

## 变体

| 变体名 | 简介 | 核心剧情段落 | 剧本 |
|--------|------|------------|------|
| 冒名方案被揭露 | 清洁工/应届毕业生被主管或亲戚冒名方案，老板通过让冒名者介绍产品验证真伪 | 1.受害者被压制做苦力 2.老板发现疑点 3.冒名者嚣张领奖 4.当众质问+产品验证 5.处置反派+为受害者正名 | 清洁工女青年被冒名方案老板揭露（1w）、清北毕业生被亲戚骗去拖地方案被盗（2.5k） |

## 可替换去重元素

| 元素 | 说明 | 变体间差异 |
|------|------|-----------|
| 受害者身份 | 被冒名者的背景 | 清洁工女青年（清北设计系，被安排做保洁）；清北应届毕业生（高级运营策划岗，被亲戚骗去做保洁） |
| 冒名者身份 | 冒名方案的人 | 厂长媳妇（主管）；主管的弟弟（草包） |
| 冒名者与受害者关系 | 双方关系 | 上司与下属（面试时歧视农村人）；亲戚（打着"帮你"旗号利用） |
| 被冒名的成果 | 被偷的劳动成果 | 去老人味洗衣凝珠全案（爆卖12万单）；薄荷油全渠道营销案（单场破千万） |
| 贵人身份 | 揭露真相的人 | 公司老板（林总）；公司老板（沈总） |
| 揭露方式 | 真相如何被揭开 | 召开董事会让冒名者现场介绍产品验证；表彰大会上查后台记录+让冒名者讲卖点 |
| 受害者额外困境 | 受害者除了被冒名还有什么难处 | 父亲住院等医药费+腿被打断；父亲住院等医药费+弟妹学费 |
| 处置方式 | 反派被如何处置 | 开除+追究责任+赔偿医疗费；开除+追回奖金 |
| 补偿方式 | 受害者获得什么 | 设计总监月薪3万+10万奖金；调入运营部+20万奖金 |
| 产品引入方式 | 产品如何植入剧情 | 受害者现场详述产品卖点+定价（产品即被冒名的方案成果）；受害者现场详述产品卖点+定价权（产品即被冒名的方案成果） |
