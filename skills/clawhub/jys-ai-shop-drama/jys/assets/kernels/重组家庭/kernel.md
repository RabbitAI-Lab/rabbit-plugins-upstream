# 重组家庭

## 内核简介
现任配偶在街头、家门口或高档场合遇到伴侣隐瞒的前婚子女或落魄父母。冲突爆发后，现任配偶非但不嫌弃，反而先解决家人的现实危机，再长期接纳伴侣的全部过去。

## 情绪节奏
偶遇（意外）→ 相认（震惊）→ 隐瞒暴露（冲突）→ 现任发怒（误解：以为嫌弃）→ 反转（怒的是不信任）→ 霸气接纳+100万现金 → 产品植入 → 团圆收尾

## 可替换去重元素

| 元素 | 说明 | 变体间差异 |
|------|------|-----------|
| 触发场景 | 隐瞒关系暴露的具体场景 | 接纳继子女：大雨天外卖闯红灯、小孩蹲别墅门口、工地出口差点撞人、重点工地搬水泥、街头发传单，或在山庄宴会门口被狗拦住；接纳父母：清洁工扫地碰到孕妇、收破烂绊倒孕妇 |
| 落魄方身份 | 被偶遇的是谁 | 接纳继子女：伴侣前婚子女（后妈方向：丈夫前妻子女；后爸方向：妻子前夫子女）；接纳父母：伴侣的父亲/母亲 |
| 落魄原因 | 孩子或长辈为什么必须寻找隐瞒方 | 接纳继子女：生活费或抚养费被侵占、被亲属赶出、赔偿金被拿走、赌鬼父亲抛弃，或抚养自己的奶奶骨折急需手术费；接纳父母：住房被卖、亲属网赌逼迫卖房等 |
| 隐瞒方 | 谁在隐瞒过去 | 接纳继子女：后妈方向丈夫隐瞒，后爸方向妻子隐瞒；接纳父母：妻子隐瞒父亲/母亲被赶出 |
| 冲突触发 | 隐瞒如何暴露 | 孩子喊"爸"/"妈"被现任配偶听到 |
| 现任初始反应 | 发现真相后的第一反应 | 统一：生气——但气的不是有过去，而是不信任、偷偷摸摸 |
| 现实危机处理 | 现任如何先解决眼前困难 | 可一次性提供较大金额，也可先核验住院单、直接支付手术押金、安排护工和住所，不固定金额 |
| 产品引入方式 | 产品如何植入 | 秘书/助理汇报产品定价，或接到家中老人摔倒电话后由孩子介绍（艾草防臭鞋垫/猴头菇牛奶燕麦片/山珍海味复合调料/叶黄素蒸汽眼罩/元气四宝茶/沐浴露/花香马桶清洁块） |
| 收尾台词 | 结尾点题金句 | 围绕"跨越血缘的爱"/"担当"/"接住全部"等主题 |
