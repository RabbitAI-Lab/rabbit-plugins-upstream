# 母亲卖果园偏袒弟弟后大哥亮明8亿断亲

## 元数据
- 参考价值：优
- 所属套路：被偏心家人榨干后隐藏实力断亲
- 所属变体：替弟背锅落魄后实力揭晓断亲
- 带货产品：粘性耳朵清洁棒

## 人物表
| 角色 | 身份 |
|------|------|
| 傅砚辞 | 男主，曾经的商界人物，替弟背锅后忍辱负重并暗中布局翻身 |
| 沈念微 | 傅砚辞的妻子，贤惠、有担当，始终陪伴男主 |
| 傅老太太 | 傅砚辞与傅子轩的母亲，极度偏心、势利 |

| 小周 | 傅砚辞的特助 |

## 剧情与台词

### 农家院落：卖果园与老宅

傅砚辞与沈念微在院中吃面。傅老太太带傅子轩和林曼曼闯入，宣布已将傅砚辞三年经营出的300亩果园及老宅卖给村长，共得2000万元；其中1999万元给傅子轩购买大平层和首饰，余款自己打牌，只扔给傅砚辞夫妻1000元并要求当晚搬走。

沈念微揭露往事：三年前傅子轩经营皮包公司、做阴阳合同，捅出商业欺诈窟窿；傅砚辞为保弟弟签下认罪文件、承担巨额债务并遭行业封杀。傅老太太却认为大哥替弟弟背锅理所应当。傅子轩踢开椅子，辱骂傅砚辞是种地的废物和底层垃圾，并把钱扫进污水。

沈念微表示不要钱和宅子，只要傅砚辞还在，住草棚也愿意跟随。傅砚辞宣布以果园和老宅偿清生恩养恩，从此两清、生死不复相见。傅老太太放话，即使他们以后有金山银山，自己饿死要饭也绝不踏进他们家门。

### 隐藏实力揭晓与产品植入

特助小周赶到，恭敬称傅砚辞为董事长，汇报其三年来在海外布局的资本反击战已经获胜，8亿元并购尾款已进入私人账户。傅老太太等人震惊，傅子轩瘫倒。

小周同时请傅砚辞为集团新品“粘性耳朵清洁棒”确定价格。原稿介绍其材质柔软、自带粘性、可清洗复用；规格为24个一盒，活动价7.9元一盒、11.9元两盒。原稿中有关耳道清洁效果及适用于成人儿童等说法仅按来源台词归档，不作为经验证的医疗或安全事实。

傅砚辞让小周安排全网上架。

### 变脸求和与断亲

傅老太太立刻变脸，声称过去的狠心是在磨炼傅砚辞，并要求跟他进城享福，还要傅砚辞再拿几千万元给弟弟换别墅。沈念微引用傅老太太刚才“即使有金山银山也不进家门”的原话反击。

傅砚辞清算旧账：从小好东西都属于弟弟，自己只有背锅吃苦；为弟弟承担天价债务后，母亲仍落井下石卖掉他最后的家底。他宣布从此傅老太太的生老病死都与自己无关。傅子轩试图下跪，被傅砚辞拒绝。

傅砚辞牵起沈念微离开，乘豪车车队驶离老宅，留下傅老太太、傅子轩和林曼曼在原地崩溃。
