# 穷母坐上宾

## 内核简介
贫穷长辈在成功晚辈的重要场合遭到嫌弃和藏匿，晚辈发现后公开维护长辈、讲述养育恩情并请其坐上主桌，最终与嫌贫爱富的一方决裂。

## 情绪节奏
长辈受辱（愤怒）→ 长辈隐忍（心酸）→ 晚辈发现真相（爆发）→ 公开感恩并请上主桌（感动与爽感）→ 产品展示 → 与势利方决裂（价值升华）

| 变体名 | 简介 | 核心剧情段落 | 剧本 |

## 可替换去重元素

| 元素 | 说明 | 剧本间差异 |
|------|------|-----------|
| 被嫌弃的长辈 | 与成功晚辈的关系和养育身份 | 裁缝母亲版：亲生母亲独自供儿子读到博士；厨师姑姑版：姑姑终身未婚，将父母离异的侄子养大 |
| 重要场合 | 反派追求体面的公开活动 | 裁缝母亲版：博士毕业与品牌庆功宴；厨师姑姑版：新品发布会与订婚活动 |
| 长辈职业和贫穷痕迹 | 被反派嫌弃的外在原因 | 裁缝母亲版：县城缝补工、衣服有旧布头和潮味；厨师姑姑版：厨师和卤味摊主、旧厨师服有油烟味 |
| 藏匿长辈的地点 | 反派安排长辈离开主会场的地方 | 裁缝母亲版：负一楼员工更衣室；厨师姑姑版：负一楼员工备餐间/杂物间 |
| 真相暴露方式 | 晚辈如何发现长辈受辱 | 裁缝母亲版：亲眼看见母亲被安排并与准岳母交锋；厨师姑姑版：服务员说出姑姑被送到员工备餐间吃工作餐 |
| 感恩表达方式 | 晚辈公开维护长辈的动作 | 裁缝母亲版：撤掉准岳母名牌、让母亲坐主桌、上台递博士证书；厨师姑姑版：到备餐间下跪、牵姑姑回主桌、公开讲述养育经历 |
| 外部反转 | 长辈身份或恩情带来的额外结果 | 裁缝母亲版：全场起立鼓掌；厨师姑姑版：投资人认出姑姑是旧日恩人并追加投资 |
| 产品 | 剧情中展示的带货产品 | 裁缝母亲版：花香樟脑丸；厨师姑姑版：潮汕卤汁（黑名单，不入产品库） |
| 产品切入 | 产品与长辈经历的连接 | 裁缝母亲版：产品灵感来自母亲潮湿的缝补铺；厨师姑姑版：姑姑现场教学，用卤汁制作家常卤味 |
| 决裂结果 | 晚辈如何处理亲密关系 | 裁缝母亲版：取消婚事并带母亲回家；厨师姑姑版：暂停订婚并带姑姑回家 |
