# 小事助人，大事得好报

## 内核简介
好人为陌生人解决眼前的小困难或紧急危险，后来自己遭遇困境时，被帮助的人恰好有能力出手相助，最终善意得到回报。

## 情绪节奏
善举（温暖）→ 遭遇不公或困境（愤怒/揪心）→ 被救者认出恩人（惊喜）→ 出手撑腰或报答（爽感）→ 产品 → 善有善报收尾

## 变体

| 变体名 | 简介 | 核心剧情段落 | 剧本 |
|--------|------|------------|------|
| 孩子拒食遇美味 | 富家孩子拒食或晕倒，被好心人用家常美味安抚，随后在富豪家做菜证明善举的价值 | 1.孩子拒食/晕倒 2.好心人用美食帮助 3.被反派刁难 4.厨艺证明价值 5.贵人留用 | 少爷出走遇阿姨做蒸蛋.md、女孩晕倒遇小伙做美味.md、雨夜饿肚子富家女遇维修工嫩肉饭.md |
| 救人反被讹赔 | 好人救下遇险孩子，反被家属索赔或要求开除，董事长/老板到场主持公道 | 1.孩子遇险 2.好人奋不顾身救人 3.反被索赔或追责 4.贵人到场撑腰 5.奖励+产品 | 保安砸窗救锁车孩子.md、保安砸窗救闷车孩子（妈乱停车）.md、退伍兵砸车救锁车孩子.md |
| 救人后获报答 | 好人救助陌生人后离开，后来陷入学费被骗或家人急需手术费等困境，被救者认出或找到恩人并出手相助 | 1.陌生人遇险 2.好人救助后离开 3.好人遭遇困境 4.被救者认出/找到恩人 5.撑腰、给钱或提供机会+产品收尾 | 外卖员救中暑老板后获报答.md、摆摊人夜市救中暑老板后获报答.md、女青年雨中救董事长后讨回被骗学费.md |

## 可替换去重元素

| 元素 | 说明 | 变体间差异 |
|------|------|-----------|
| 善举形式 | 好人做了什么 | 孩子拒食遇美味：用家常食物安抚孩子；救人反被讹赔：砸车窗救被困孩子；救人后获报答：雨中扶人、救治中暑或酒精过敏者 |
| 善举方法 | 使用的物品或技能 | 孩子拒食遇美味：蒸蛋/红烧酱；救人反被讹赔：消防锤/工具砸窗+清凉油；救人后获报答：扶人并打120/清凉油物理降温+联系急救 |
| 好人身份 | 恩人的职业或背景 | 孩子拒食遇美味：路边摊阿姨/年轻小伙/前饭馆老板兼油烟机维修工；救人反被讹赔：退伍保安/退伍侦察兵；救人后获报答：准大学生/外卖员/工地小工兼夜市摊主 |
| 被帮助者身份 | 善举受益者 | 孩子拒食遇美味：富家孩子；救人反被讹赔：被困车内的孩子；救人后获报答：董事长、亿万富翁或公司老板 |
| 好人后续困境 | 善举后遭遇什么难题 | 孩子拒食遇美味：被质疑和刁难；救人反被讹赔：被索赔、追责或要求开除；救人后获报答：学费被骗、妻子手术费不足或被冷漠围观者羞辱 |
| 认出恩人的方式 | 被救者如何再次发现好人 | 孩子拒食遇美味：家长在做菜现场确认；救人反被讹赔：董事长/老板到现场得知真相；救人后获报答：追踪到医院或调查找到恩人 |
| 报答方式 | 贵人如何回报 | 孩子拒食遇美味：认可厨艺并留用；救人反被讹赔：训斥反派、升职或录用；救人后获报答：给手术费、追回学费或切断反派合作 |
| 反派表现 | 反派如何制造不公 | 孩子拒食遇美味：管家/厨师刁难，或保姆用难嚼食物虐待孩子并轻视好心人；救人反被讹赔：家属索赔并要求开除救人者；救人后获报答：亲属吞钱、围观者冷漠羞辱 |
| 产品植入 | 产品如何出现 | 孩子拒食遇美味：做菜时使用调味料；救人反被讹赔：救人后使用清凉油；救人后获报答：救人时使用清凉油，或贵人出场后由家中长辈的健康电话转入产品介绍 |
