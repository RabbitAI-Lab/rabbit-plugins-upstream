# 被帮助多年后报恩

## 内核简介
落难者被好心人救助（施饭施钱或收养抚养），多年后落难者功成名就，回来寻找恩人，发现恩人陷入困境，遂全力报恩。

## 情绪节奏
落难（同情）→ 救助（温暖）→ 时间跳转成功（爽感铺垫）→ 发现恩人困境（心疼愤怒）→ 报恩（爽感爆发）→ 产品植入 → 感恩收尾

| 元素 | 说明 | 变体间差异 |

| 救助的形式 | 好心人如何救助落难者 | 施饭施钱救助后报恩：给面/包子等热食并资助学费、看病钱或启动资金；给热汤面+5000块看病钱+旧手机；危难救助后报恩：雪地/暴雨/黄土高原等极端环境救助（给食物+衣物+留宿/给路费），雨中救流浪少女版为暴雨中把刚捡到的钱全给受助者+赠半枚平安扣信物+鼓励；收养弃婴长大后报恩：收养弃婴并抚养成人 |
| 落难者的身份 | 被救助者的背景 | 施饭施钱：18岁女孩或落难学生，考上大学没钱交学费；讨饭兄妹（哥哥背着生病妹妹）；落魄失学青年或名校毕业生饿到吃泔水/馊饭；危难救助：雪地/暴雨/黄土高原遇困的落难者或被拐逃出的女子，雨中版为暴雨中蜷缩路边的流浪孤儿少女（后逆袭为女总裁）；收养弃婴：被遗弃的婴儿（男女不限） |
| 好心人的身份 | 救助者的职业/背景 | 施饭施钱：饭店老板、工地大叔、早餐摊主、包工头或面馆老板；危难救助：农村妇女/农村青年，雨中版为破产搬运工父亲（独自抚养三子女，被前妻抛弃）；收养弃婴：垃圾场环卫工/修鞋匠 |
| 时间跨度 | 救助到报恩的时间间隔 | 10年/多年/20年/从婴儿到成年，雨中版为八年 |
| 恩人的困境 | 恩人多年后遭遇了什么 | 母亲肺病卖店扛货/妹妹眼睛恶化码头扛货/被包工头欠薪+拖欠房租+弟弟学费无着；为资助落难者导致女儿失学、家庭破产并在工地扛水泥；为资助落难者耽误妻子治病、抵押房屋并在砖厂搬砖；老伴重病50万手术费儿女不管；女儿重度肾病需换肾200万+弟妹拒绝借钱；雨中版为翻旧铁盒找不到子女入学证件（轻度生活困境，非重病/欠薪） |
| 报恩的方式 | 落难者如何回报恩人 | 安排治病+合伙开饭店/送房+安排治疗/报恩者传授老方子+安置恩人；补偿子女学业、还债并接回养老；赠送住房和终身医疗保障；给200万治病+接回家养老；给500万治病+买别墅接恩人养老；雨中版为赠副卡（无额度限制）+市中心别墅+过户合同+感情线 |
| 恩人的心愿 | 恩人最大的心愿 | 给母亲治病/给妹妹治眼睛/开最大的饭店/一家人安稳过日子/给弟弟交学费；老伴病好+安享晚年；女儿换肾手术成功；雨中版为孩子们安稳读书的家 |
| 产品引入方式 | 产品如何植入剧情 | 报恩环节自然引出（饭店开业卖调味料/给恩人用眼罩/给养母用薄荷精油/给爷爷喝姜粉/报恩者传授老方子引出牙粉/报恩后给恩人送豆浆粉），雨中版为家中证件乱塞受潮痛点→赠“全家证件收纳本” |
