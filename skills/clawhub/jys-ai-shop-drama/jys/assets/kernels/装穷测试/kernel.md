# 套路内核：装穷测试

## 内核简介
富豪假装贫穷、患病、破产或利用真实危机设局，测试身边人的真心与人品；嫌贫、算计或趁火打劫者暴露，真心相待者得到回报，真实暗算者还会被当场钓出并清算。

## 情绪节奏
制造困境或发现危机（悬念）→ 测试失败者暴露（愤怒）→ 真心者出现（温暖）→ 身份或真相揭晓（爽感）→ 恶人受罚、好人得报

## 可替换去重元素

| 元素 | 说明 | 变体间差异 |
|------|------|-----------|
| 伪装方式 | 富豪如何制造困境 | 子女：装破产、装病或宣布需要手术费；相亲：富妈摆摊装穷，或装破产失明逐个登门；暗算事故：发现刹车油管被割后装深度昏迷钓凶手；朋友：装税务危机、巨额赔偿或资金缺口；本子（下直升机）：下直升机坐破轮椅装疯+宣布投资爆雷欠2亿 |
| 被测试对象 | 测试谁 | 子女：亲生子女或养女；相亲与暗算事故：贵公子身边的三名交往对象、未婚妻或爱慕者；朋友：高端闺蜜、生意伙伴与穷朋友；本子（下直升机）：养女+徒弟（含非亲属的徒弟） |
| 测试对象数量 | 同时比较多少人 | 子女、相亲和朋友剧本以三组对象对比为主；本子（下直升机）仅测2名白眼狼（养女+徒弟），对比1名陌生善意摊主 |
| 失败者表现 | 人品如何暴露 | 子女：嫌弃、推脱养老或拒绝出钱；相亲：嫌脏嫌丢人、把婚姻当利益交换，或因破产和债务立即离开；暗算事故：图谋保险金、要求停救、强夺股权或承认暗算；朋友：拒绝借钱、让保安送客或趁火打劫；本子（下直升机）：扔糕点辱骂并命保安消杀轰走、谈投资回报率踢纸箱赶去桥洞 |
| 通过者善举 | 真心者做了什么 | 子女：接回家、承诺养老或筹钱；相亲：收留落难者并主动承担；暗算事故：冲进病房护人，拿儿女学费、经营手续和房产救命；朋友：转让摊位或菊园、拿出全部积蓄或四处借钱；本子（下直升机）：泥水里擦脸、电饭煲红烧肉喂饭（产品为核心善意载体）、掏空18万积蓄救急 |
| 通过者身份 | 真心者的背景 | 子女：最穷或最不起眼的子女；相亲：摆摊卖油的普通姑娘；朋友：卖鱼人、货车司机、送水工或菊农；本子（下直升机）：路边摊陌生摊主，被认作亲孙女 |
| 真相揭晓 | 如何公开身份或危机真相 | 子女：律师宣布资产或遗产安排；相亲：管家送来投资协议或男主摘下蒙眼纱布；暗算事故：男主苏醒，警方带口供和转账证据进场；朋友：老板说明破产是测试；本子（下直升机）：保镖列队围住小吃摊，老夫人起身揭穿 |
| 回报方式 | 通过者得到什么 | 子女：获得家产或养老安排；相亲：获得投资、婚房或事业平台并被认可为儿媳；暗算事故：获得公开项目机会，并由男主重新追求；朋友：获得长期合作与事业机会；本子（下直升机）：认作亲孙女，收回白眼狼房产豪车、冻结卡、清算徒弟资产 |
| 失败者结局 | 未通过者的下场 | 子女：取消继承资格；相亲：失去婚姻和机会，部分爽剧版本还会被行业封杀；暗算事故：觊觎保险者被揭穿，幕后凶手因暗算、挪款和夺股被警方抓捕；朋友：失去信任和合作；本子（下直升机）：收回房产豪车冻结银行卡、全面清算资产、底层苦力5年 |
| 真实危险程度 | 测试前是否已经发生真实伤害或犯罪 | 普通装穷测试只制造虚假困境；暗算事故变体先发生真实车辆破坏，再以装昏迷完成钓凶和真心测试 |
| 产品植入 | 产品出现位置 | 子女：家庭生活场景；相亲：真心者接纳落难者时；朋友：测试等待或真相揭晓阶段；本子（下直升机）：陌生摊主喂饭救急的核心善意载体，电饭煲+半袋鲍汁红烧酱 |
