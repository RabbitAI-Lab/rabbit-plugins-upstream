# 套路内核：失散亲人重团聚

## 内核简介
因走失、离乡或家庭变故分开的亲人，在多年后重新相遇；主角确认身份或真心后，弥补亏欠、消除隔阂并让一家人重新团聚。

## 情绪节奏
多年失散（心酸）→ 意外重逢或主动寻亲（悬念）→ 身份/真心确认（震惊与感动）→ 弥补亏欠（释放）→ 一家团聚（温暖）

## 可替换去重元素

| 元素 | 说明 | 剧本间差异 |
|------|------|-----------|
| 失散亲人关系 | 重新寻找或相认的是谁 | 岳母版：丈夫帮助妻子找回母亲；前妻版：男人寻找前妻和亲生女儿 |
| 分离原因 | 亲人为什么多年未见 | 岳母版：女儿幼年走失，母亲流浪寻女；前妻版：男主离乡发展，前妻独自抚养女儿十年 |
| 重逢方式 | 双方如何再次相遇 | 岳母版：桥下或小区门口偶遇；前妻版：男主主动回乡寻找 |
| 身份或真心确认 | 如何确认对方身份/感情 | 岳母版：姓名、胎记、酒窝和旧衣物；前妻版：男主装穷，确认前妻即使困难仍愿意卖房相助 |
| 失散者处境 | 被寻找亲人的生活状态 | 岳母版：住桥洞、废弃仓库或漏水地下室；前妻版：靠打零工还债并独自供女儿上学 |
| 主角身份 | 推动团聚的人 | 岳母版：大老板/企业副总；前妻版：离乡十年后致富的老板 |
| 情感阻力 | 团聚前最大的隔阂 | 岳母版：多年寻女造成的创伤；前妻版：女儿怨恨父亲缺席童年，前妻质问其不负责任 |
| 弥补方式 | 主角如何修复关系 | 岳母版：安排住房、医疗并通知妻子相认；前妻版：亮明身份、解释离开原因并承诺补偿母女 |
| 产品植入 | 产品如何进入剧情 | 岳母版：安排新住处时使用花香樟脑丸；前妻版：弟弟卖艾草防臭鞋垫，借产品暗示男主真实身份 |
| 团圆结果 | 最终如何收尾 | 岳母版：母女相认并接回家；前妻版：前妻和女儿接纳男主，一家重新生活 |
