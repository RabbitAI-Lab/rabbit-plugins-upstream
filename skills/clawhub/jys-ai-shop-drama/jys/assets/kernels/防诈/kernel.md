# 防诈

## 内核简介
骗子通过偷拍、套话、近距离读取、AI伪造或冒充机构取得信任，逐步完成信息窃取、刷脸贷款、盗刷、诱骗转账或人身控制；剧情完整呈现诈骗链条，再通过主人公识破、受骗后果或口播复盘揭露风险。

## 情绪节奏
骗子锁定目标（隐患）→ 获取初始信息（紧张）→ 伪装身份并持续施压（恐惧）→ 受害者配合或察觉异常（悬念）→ 骗局后果/识破反转（后怕）→ 全链路复盘 → 防护警示

## 可替换去重元素

| 元素 | 说明 | 各变体中的表现 |
|---|---|---|
| 易受骗人设 | 优先考虑容易被骗子选中、利用信任或制造慌乱的人物 | 年轻女性、宝妈与小孩、老太太、暑假工学生、独自出行并携带学费的学生、在人流密集场所长期经营的摊贩群体 |
| 诈骗发生场所 | 骗子在哪里接近目标 | 交通与出游场景：机场候机厅、酒店前台、高铁站、地铁站等；日常街头：住宅走廊、家门口、普通马路或街边；批量贴片场景：菜市场、商场、展会、社区活动等多人持续停留的公共场所 |
| 初始信息入口 | 骗子如何取得第一批真实信息 | 偷拍裸露证件、借手机拨号、假求助时贴近包袋、公开行程信息、熟人资料泄露、趁目标不注意把黑色磁力小贴片附着到卡包或随身物品外侧 |
| 骗子伪装身份 | 骗子用什么身份降低戒心或制造恐惧 | 普通旅客、热心阿姨、弱势求助者、假安检、假车站复检人员、假警察、银行风控人员、金融专案组、AI合成熟人或丈夫同事 |
| 二次信息套取 | 骗子如何补齐实施诈骗所需的信息 | 索要证件照片、拍摄身份证正反面、诱导张嘴抬头完成人脸识别、控制手机或诱导打开小程序 |
| 技术与道具载体 | 技术工具藏在哪里或怎样出现 | 改装登机箱、袖口读卡器、藏有读取设备的斜挎包、藏在假孕肚夹层里的读卡设备、伪装成手持检测棒的读取设备、黑色磁力小贴片与场外车辆接收设备、鼓囊双肩包、偷拍手机、病毒程序、AI换脸视频、假制服和假登记程序 |
| 核验破绽 | 主人公从什么细节发现异常 | 对方说不出账户后四位、要求去酒店、禁止报警、生活习惯不符；也可不当场识破，以损失结果完成警示 |
| 独立核验方式 | 不沿用骗子提供的渠道进行确认 | 挂断来电、拒绝提供信息、直接进入派出所、向真正车站工作人员求证、用自己的手机联系真实亲属；未核验时展示贷款、盗刷或绑架后果 |
| 骗局后果 | 骗子企图造成什么损失 | 窃取身份和账户信息、刷脸网贷、盗刷银行卡、诱导转账、索要保证金、骗至指定地点或实施绑架 |
| 产品形态 | 防盗刷卡套如何呈现 | 交通与出游场景：可放多张重要卡片的薄型金属卡套；日常街头：根据剧情事实使用单卡不锈钢保护套或多卡金属卡套 |
| 产品引出 | 如何从剧情过渡到产品 | 交通与出游场景：警方询问为何设备始终读取失败；日常街头：主人公复盘骗子近距离读取设备后展示防护方法；批量贴片场景：场外设备显示多目标全部失败，群众同时拿出此前获赠的金属卡包 |
| S2路径触发 | 当前产品功能是否与诈骗动作形成直接因果 | 使用防NFC盗刷卡套时，完整诈骗链必须包含设备近距离靠近钱包、包袋或卡片并尝试读取的动作；主对标只偷拍视频、套取证件照片或刷脸时，触发S2路径C，先重构诈骗全流程 |
| 高价值参考边界 | 如何借鉴产品机制不同的优质剧本 | 可借鉴开头钩子、目标人设、骗子伪装、施压方式和揭晓节奏；不得因沿用原稿段落而保留与当前产品无关的诈骗因果链 |
| 叙事起点 | 从诈骗发生前、诈骗进行中、损失结果还是警方抓捕后开始 | 可从骗子夸张挑衅开始，可从ATM屏幕显示余额0.00后倒查，也可从群众抠下黑色贴片并立即封锁现场开始，或以警方突入窝点和受害者认人为开头 |
