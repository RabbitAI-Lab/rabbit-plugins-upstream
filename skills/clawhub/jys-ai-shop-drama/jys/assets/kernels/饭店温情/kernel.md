# 饭店温情

## 内核简介
饭店经营者长期用免费供餐、特殊价格或高价收购等方式照顾处境困难的固定食客，善举被其他顾客偶然看见并追问，真相揭晓后引发善意接力，再从招牌食物自然过渡到配方或调料产品。

## 情绪节奏
店内出现反常待遇（疑惑）→ 顾客追问或产生冲突（拉扯）→ 困难身世与长期善举揭晓（感动）→ 善意获得理解和回报（温暖）→ 招牌食物引出配方与产品（转化）

## 变体

| 变体名 | 简介 | 核心剧情段落 | 剧本 |
|---|---|---|---|
| 店主长期照顾困难老人 | 店主以高价收菜、免费供餐或收下特殊支付物等方式长期照顾遭遇家庭变故的老人，旁观顾客得知真相后出手帮助店主 | 1.困难老人到店 2.店主给予反常照顾 3.顾客发现并追问 4.多年善举与老人身世揭晓 5.顾客资助或替店主解困 6.店主拒绝后以购买配方过渡 7.食品调料植入 | 高价收菜送牛肉汤照顾患难老夫妻.md、收手绘假钱照顾环卫老人并获顾客付房租.md |
| 店主长期照顾烈士遗孤 | 店主为烈士遗孤保留长期低价供餐，先以贪便宜顾客制造冲突，再由善良顾客理解并接力帮助 | 1.遗孤按专属低价用餐 2.贪便宜者强求同等待遇 3.店主揭露身份并维护遗孤 4.旁观顾客得知多年善举 5.遗孤告别形成情绪高潮 6.顾客提出资助 7.食品调料植入与好人有好报 | 一元刷脸牛肉汤长期照顾烈士孤女.md |

## 可替换去重元素

| 元素 | 说明 | 各变体中的表现 |
|---|---|---|
| 饭店品类 | 温情故事发生在哪类餐饮门店 | 牛肉汤馆、馄饨店、牛肉面馆或其他小餐馆 |
| 受助者身份 | 店主长期照顾谁 | 遭遇家庭变故的种菜老人、环卫老人、烈士遗孤 |
| 反常待遇 | 最先引起旁观顾客注意的动作 | 高价收菜并送汤、优先上餐并收手绘假钱、一元专属供餐 |
| 善举持续方式 | 店主长期如何提供帮助 | 每天收菜、每日供餐、固定打包食物、保留专属活动 |
| 身世揭晓 | 什么经历让受助者陷入困境 | 家人救人牺牲、交通事故与丧亲打击、父母因公牺牲或离世 |
| 追问或冲突者 | 谁推动善举真相被说出 | 好奇顾客主动追问，或贪便宜顾客先制造冲突再由善良顾客追问 |
| 情绪象征物 | 用什么具体食物或动作承载长期情感 | 给患病老伴的一碗汤、代表曾经一家五口的五个茶叶蛋、一元刷脸活动 |
| 店主自身困境 | 是否在善举揭晓后增加店主面临的现实压力 | 无额外危机、房东上门催租、经营成本被顾客追问 |
| 善意回报 | 旁观顾客如何接力 | 直接资助、替店主支付房租、以购买配方为名留下钱 |
| 店主拒绝理由 | 店主为什么不接受直接捐助 | 帮助出于本心、只是多双筷子、把老人当长辈、自己挣钱更容易 |
| 产品过渡 | 如何由剧情进入食品产品 | 顾客称赞招牌菜并请教秘方，店主公开教学后用预配料包解决配比麻烦 |
| 食品产品 | 最终植入什么调料 | 炖肉汤料包、五香茶叶蛋卤料包或与招牌菜直接相关的复合调料 |
