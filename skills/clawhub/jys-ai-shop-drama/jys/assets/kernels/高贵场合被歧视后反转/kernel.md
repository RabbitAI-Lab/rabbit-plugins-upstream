# 高贵场合被歧视后反转

## 内核简介
弱势群体或微服私访的董事长在高档消费场所被势利眼员工歧视驱赶，好心人挺身相助，最终老板出面或身份揭露，势利眼被开除惩罚，好心人获报答。

## 情绪节奏
被歧视驱赶（愤怒）→ 好心人相助（温暖）→ 老板出面/身份揭露（爽感爆发）→ 悬念未解时切入产品 → 惩恶扬善收尾

| 变体名 | 简介 | 核心剧情段落 | 剧本 |

## 可替换去重元素

| 元素 | 说明 | 变体间差异 |
|------|------|-----------|
| 被歧视者的身份 | 谁被歧视 | 弱势客户：退伍女兵/蹬三轮供儿上学的老父亲；微服私访：老人（实为董事长） |
| 歧视发生的场所 | 在什么场所 | 4S店/高档餐厅/养老用品店/高端养老社区/私人停机坪 |
| 势利眼的身份 | 谁在歧视 | 4S店销售经理/餐厅店长/养老店店长/高端门店店长/前台接待+秘书 |
| 好心人的身份 | 谁帮助了被歧视者 | 弱势客户变体：合作方老板（卓总）；微服私访变体：好心顾客/洗车工兄妹/店员 |
| 好心人的付出 | 好心人做了什么 | 给老人暖腿贴护膝宝/替老人付饭钱/给水给饭给路费/给水给面包给打车钱/给水给饭让休息 |
| 老板出面的方式 | 老板如何揭露身份 | 弱势客户变体：合作方老板叫停（卓总）；微服私访变体：从楼上下来/助理到场认出/自己揭露身份 |
| 惩罚方式 | 势利眼受到什么惩罚 | 开除+全行业通报/开除+查账追责/取消合作+处理（不认父的儿子） |
| 报答方式 | 好心人获得什么 | 弱势客户变体：无明确报答（正义伸张即满足）；微服私访变体：升职加薪/巨额奖金+学费承担/干股赠送 |
| 产品引入方式 | 产品如何植入剧情 | 被歧视者的专业知识引出/老板的产品推介/好心人的随身物品引出（艾草护膝宝） |
| 被歧视者与被惩罚者的关系 | 被歧视者与受惩罚者是否有亲属关系 | 无关系（陌生人）/父子关系（被歧视者是受惩罚者的父亲） |
