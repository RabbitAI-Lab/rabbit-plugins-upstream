## v1.2.0 (2026-10-17) — 对齐 2026-07-25 官方文档

- 📞 **联系信息更新**：联系电话更新为 `089836692518/18689850608`，新增官网 `www.yzlkj.com`。
- 🚨 **新增《请求频率限制与封 IP 风险》必读说明**：请求频率必须低于平台限速、并发 ≤2；同一 IP 短时间内频繁返回非 0 状态码（400/401/403/429 等）会被**永久封禁**；失败重试需指数退避，禁止高频重试。
- ⚡ **历史数据限速更新**：`GET /open/history` 限速由 `2 次/10 秒` 调整为 `6 次/30 秒`。
- 📄 **设备列表分页上限更新**：`GET /open/device/list` 的 `MaxResultCount` 上限由 `50` 调整为 `200`。
- 🔍 **获取所有设备新增参数**：`GET /open/device/all` 支持 `PollingTag`（轮询标记）。
- 🧩 **补充数据模型与枚举**：`DeviceStatus`、`CommandStatus`、`CommandType`、`FacilityValueType`；补充设备/设施/历史返回字段说明。
- 📝 **指令约束确认**：`args` 最多 5 个，`waitTimeout` 范围 5~20 秒；当前支持远程控制的型号为 `WANCD1`；补充开关设施 `kk1` 与 `identifying = IoT.FAC.CTRL.SWITCH` 说明。
- 🧭 **补充设备同步建议**：先用 `/open/device/all` 比对 `latestModificationTime` 做增量，再按需拉取详情；轮询间隔建议 5/10/30 分钟。
- 🛡️ **tool.py 安全性增强**：
  - 限速器改为请求前排队等待，避免超过平台阈值；
  - 不做自动重试，避免重试风暴；
  - 连续 5 次返回非 0 状态码自动中止本次运行；
  - 对 `429` / `401` / `403` 给出明确的降险提示；
  - `args` 超过 5 个时本地直接拒绝；`MaxResultCount` 按 200 截断。
