## Known Risks and Mitigations:

Risk: Terraform workflows generated by the skill may include infrastructure-changing commands or CI/CD apply steps.

Mitigation: Require human review of every Terraform plan and prohibit production apply or state changes unless explicitly approved.

Risk: Terraform execution can affect cloud resources and sensitive state when credentials are available.

Mitigation: Use least-privilege cloud credentials, protect CI/CD production environments with manual approval gates, and keep Terraform state and secrets protected.
