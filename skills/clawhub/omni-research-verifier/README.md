# OMNI Research Verifier (OpenClaw Skill)

Professional-grade research and verification skill for autonomous agents.

## Installation
`claw install omni-research-verifier`

## Features
- **Heuristic Credibility Scoring:** Filters out low-quality web data.
- **Contradiction Detection:** Alerts you if sources disagree.
- **Citation-Ready:** APA-style references generated automatically.
- **Async-Ready:** Designed for high-performance multi-source queries.

## Usage
Provide any factual claim. OMNI will return a JSON report containing evidence, confidence scores, and potential conflicts.
