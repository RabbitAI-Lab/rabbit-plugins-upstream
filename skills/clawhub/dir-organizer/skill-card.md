## Description:

Organizes files in a selected directory by extension into category folders, previewing moves by default and applying them only when requested.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zhaoxinghua09-cell](https://clawhub.ai/user/zhaoxinghua09-cell)

### License/Terms of Use:

MIT (Python code only); documentation and theoretical text: all rights reserved

## Use Case:

People and agents organizing cluttered local folders can preview file classification by extension and then move files into category subfolders with explicit approval.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Applying the plan moves files within the selected directory and may disrupt existing workflows.

Mitigation: Review the default dry-run preview and back up important directories before using --apply.
