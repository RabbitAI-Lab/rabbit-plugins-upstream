# 公文用语规范速查

本文件供 `gongwen-optimize` skill 在优化公文时按需参考，覆盖常见病句、称呼规范、
行文关系与文种惯例，以及政务案例/申报材料的对仗小标题、摘要与成效框架。

---

## 一、常见病句与修正

| 原文问题 | 问题说明 | 修正建议 |
|---|---|---|
| 主持召开……落地研究 | 缺宾语，"研究"不可作"召开"的宾语 | 主持召开……落地**专题会 / 专题研究会** |
| 建议由贵部另行建设 | 推脱感强，易产生"事不关己"观感 | 改为"建议结合……另行统筹建设"，并补充我方配合事项 |
| 领导是否要进群？ | 口语化、生硬，未交代背景 | 目前群内已有相关领导在群指导，请问您是否也方便进群指导工作？如需要，我马上邀请您。 |
| 不属于面向社会公众开放的网络直播系统 | 训诫式，像在纠正对方 | 未纳入面向社会公众开放的规划 / 暂不具备……功能属性 |
| 经研究，现答复如下（紧接大段拒绝） | 直接拒绝显生硬 | 经**认真**研究，现答复如下（加"认真"缓和）；先陈述客观定位再引出限制 |
| 双轮驱动，，实现 | 重复逗号笔误 | 双轮驱动，实现 |
| 与……有融合 | 口语化、搭配不当 | 与……**有机融合** |
| 区城规划融合 / 区城壁垒 | "区城"为"区域"笔误 | **区域**规划融合 / **区域**壁垒 |

## 二、称呼与简称规范

- **自然资源和规划局**：规范简称"**资规局**"（非"自规局"）。
- **发展和改革委员会**："发改委"。
- **区委宣传部**：党委部门，可称"贵部"。
- 平行文对受文机关："贵部 / 贵单位 / 贵委 / 贵局"。
- 上行文对领导："领导 / 您"（正式场合不用"你"）。

## 三、行文关系与称谓对照

| 行文方向 | 文种举例 | 对受文方称谓 | 典型结尾 |
|---|---|---|---|
| 上行文 | 请示、报告、汇报 | 领导 / 您 | 妥否，请指示。 / 特此汇报。 |
| 平行文 | 函、复函、答复函 | 贵部 / 贵单位 | 此复。 / 特此函复。 |
| 下行文 | 通知、批复、意见 | 各有关单位 / 你单位 | 特此通知。 / 此复。 |

## 四、复函 / 答复函结构模板

```
XX（受文机关）：

贵单位《关于……的函》收悉。经研究，现答复如下：

一、关于……（系统定位 / 事实陈述，客观中性）
二、关于……（技术 / 客观限制，转化为"为对方着想 + 为大局着想"双向风险）
三、关于……（建议与替代配合，展现协同）

此复。
```

要点：先立客观事实，再讲限制时绑定双向风险，结尾给配合而非甩锅。

## 五、汇报 / 报告结构模板（上行文）

书面/备忘录版：
```
关于……的汇报

X月X日，XX主持召开……专题会。现将会议精神及下一步安排汇报如下：

一、强化服务保障。……
二、加快推进选址。……
三、落实协议签订。……

特此汇报。
（注：……请示事项）
```

微信/工作群版：
```
领导您好，现将……相关情况汇报如下：

X月X日，XX主持召开……专题会，明确以下安排：
建立沟通机制：……
明确选址牵头：……
推进协议签订：……

妥否，请指示。
另请示：……（委婉给出背景与选择余地）
```

要点：并列要点加四字小标题；请示事项语气委婉、给领导选择空间。

## 六、政务案例 / 申报材料增强（对仗小标题、摘要、成效框架）

本部分供优化"优秀案例申报、经验交流、改革试点总结"类材料时参考，目标是政务高度与可读性。

### 1. 主标题范式
- 结构：**金句/对仗主标题 + 实题副标题**。
- 主标题点精神："聚焦增值赋能 打造智办标杆"。
- 副标题写实："——某地区依托政务智能辅助工具构建政务服务新生态"。

### 2. 小标题对仗模板
- **动宾+动宾**：`夯实数据底座，破解"政策壁垒"`；`聚焦实战需求，实现"精准画像"`。
- **四字排比（痛点/要点）**：`破除信息孤岛，提升尽调效率` / `弥补专业短板，精准匹配政策` /
  `重塑服务链条，实现全域贯通` / `减轻案头负担，释放核心运力`。
- **成效三维（量/质/面）**：`服务效率实现"量"的飞跃` / `决策质量实现"质"的提升` /
  `营商环境实现"面"的优化`。
- **创新三维**：`模式创新：构建"工具+改革+机制"增值化路径` / `协同创新：打破区域壁垒，实现"同频联动"` /
  `技术创新：多维融合攻克"大模型痛点"`。

### 3. 【摘要】范式
置于标题之下，150 字内概括：背景痛点 → 做法（双轮驱动/机制） → 核心成效（数据） → 价值。
例："针对基层政务服务中普遍存在的政策匹配难……本案例以'数字工具赋能+服务机制重塑'双轮驱动，
推动政务服务从人工检索向智能研判转变……单家企业办理时间由数小时缩短至数分钟以内，效率显著提升……"

### 4. 长段拆维度
原文把多点在一段（如"创新点"）时，拆为"模式创新 / 协同创新 / 技术创新"并列维度，各配金词小标题。

### 5. 注意事项
- 对仗化时**复查原文错字与事实**（如"区城"→"区域"），勿把 typo 一并"升华"。
- 可保留生动比喻（"秒变""保姆式"）但须纳入对仗/引号框架；优先消除第一人称"我们"。
