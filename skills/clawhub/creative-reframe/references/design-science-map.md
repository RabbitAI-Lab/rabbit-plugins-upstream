# 学科地图

信号表都不匹配时读这份。作用是给检索结构：从六条提问方式里挑一条，再回 method-index 找具体方法。

## 两个源流

**工程科学源**：1962 年伦敦设计方法会议起，Simon 1969 提出设计科学，主张设计过程可形式化、可讲授。

**人文实践源**：Schön 1983 反驳，认为设计知识是默会的，核心是与情境对话、在行动中反思。

这两条至今没合流。方法论在"规范化"和"守住手艺"之间反复摆，根源在这。

## 六条主线

| 主线 | 关心什么 | 挂着的方法 |
|---|---|---|
| 规范化 | 怎么做得更可靠 | Pahl & Beitz 四阶段、VDI 2221、双钻、形态分析法、Design Sprint |
| 描述性 | 设计师实际怎么想 | Schön 反思实践、Cross 设计师式认知、溯因推理、Lawson 行为观察 |
| 形式化 | 设计的逻辑结构 | Simon 人工科学、Suh 公理化设计、C-K 理论、FBS 模型、一般设计理论 |
| 批判性 | 设计在为谁服务 | Rittel 邪恶问题、Dunne & Raby 批判与推测设计、去殖民设计、过渡设计、设计正义 |
| 实证性 | 什么真的有效 | RtD、建构性设计研究、中间层知识、感性工学、Norman 情感三层 |
| 商业性 | 怎么变成竞争优势 | 颠覆式创新、开放式创新、意义创新、JTBD、精益创业 |

六条不是六个学派，是六种提问方式。同一个项目可以被六种方式同时审视。

## 遇到什么挑哪条

| 情况 | 挑 | 理由 |
|---|---|---|
| 不知道从哪下手，问题太大 | 规范化 | 给一条可走的流程，先把动作做起来 |
| 流程走完了，方案不对味 | 描述性 | 问题在理解情境，不在执行方法 |
| 改一处动全身，方案耦合 | 形式化 | 只有形式化工具能判耦合 |
| 方案做出来没人质疑，也没人在意 | 批判性 | 可能只是肯定性设计，强化了现状 |
| 说不清方案凭什么成立 | 实证性 | 缺证据与中间层知识，不缺口号 |
| 方案好但推不动 | 商业性 | 缺转化路径 |

## 五场未决的争论

1. 设计是科学还是技艺。Simon 对 Schön，表现为工程院系与艺术院系的方法差异。
2. 规范化是否压抑创造力。范式提高下限也压低上限，Alexander 与 Jones 晚年都反悔过自己早期的理性主义。
3. 设计思维是否被稀释。从 IDEO 到企业培训，方法被简化成语录卡。
4. 批判性设计是否有效。挑衅之后呢，展览能改变什么。
5. 谁受益。去殖民设计与设计正义的核心质问。

争论本身对 agent 没用，但它解释了为什么同一件事会看到互相矛盾的权威说法。

## 已接入的四条

- **公理化设计的耦合判定**。写进验收：改一处动全身即为耦合，需重构而非局部调整。
- **C-K 的疯狂概念机制**。写进重读：允许发散到荒谬，荒谬的价值在产出知识，不在走通它。
- **RtD 的中间层知识**。写进推进节奏：交付分作品、中间层、理论三层，中间层最易漏也最可复用。
- **肯定性设计作为反面判据**。写进验收第一条：只强化现状的方案没人反对，也没人在意。
