# 五层推演法

来源：比亚迪复盘实践改造
用途：多对手博弈分析（市场/政策/军事对抗）

## 五层结构

| 层 | 内容 | 纪律 |
|:--:|:------|:------|
| **L1 信息层** | 谁做了什么？公开信息搜集 | 这一层集中获取，后续不补搜 |
| **L2 意图层** | 他为什么这么做？真实意图？ | 区分"说的"和"做的" |
| **L3 对手模型层** | 对手怎么看我？他以为我怎么想？ | 至少建两个对手视角 |
| **L4 博弈约束层** | 资源/时间/政策等硬约束 | 找"不可能变"的约束 |
| **L4.5 趋势层（可选）** | 基于硬约束推导系统的演化方向 | 判断可能路径的集合和概率分布，不是预测结果 |
| **L5 棋盘尺度层** | 这盘棋在更大的局里是什么位置？ | 从大尺度回看，避免过度聚焦 |

## 使用提醒
- 最容易跳的是 L5——分析到一半容易钻进去，忘了退一步看看更大的棋盘
- 趋势层（L4.5）仅在复杂情境中拆出，简单博弈放L5足够
- 不适用范围：信息极度对称的简单问题、不需要多轮博弈的一次性决策

## 起源
原版四层，实战发现缺L5（棋盘尺度）后加入。后又在L4和L5之间加入可选趋势层（L4.5）。

## 配合使用
- 五层推演找博弈格局 → 矛盾分析找内部主要矛盾
- L4硬约束 + L4.5趋势 → 政策信号解读法验证方向
