# OCGS六维系统诊断

来源：钱学森开放复杂巨系统论
用途：分析任何系统的结构短板（企业/组织/战略/产业趋势）

## 六维轴

| 轴 | 每轴问什么 | 诊断方向 |
|:--:|:-----------|:---------|
| **开放度** | 信息通道够不够？有没有封闭盲区？ | 信息流动 |
| **多样性** | 有没有Plan B？方案库够不够？ | 抗风险能力 |
| **耦合度** | 依赖紧不紧？一个崩了会连锁炸吗？ | 脆弱性 |
| **冗余度** | 备份够不够？容错能力？ | 可靠性 |
| **自适应** | 系统能自己调整吗？还是死板的？ | 灵活度 |
| **响应速度** | 系统从感知变化到做出有效反应需要多久？比环境变化的速度快还是慢？ | 时效性 |

## 使用纪律
1. 一次只填一个维度，不要贪多
2. 第六维（响应速度）与时间标度相关，建议在完成前五维的结构快照后单独审视
3. 每个维度分析完后，问：**这个维度给的是静态快照还是动态趋势？**
4. 不适用范围：单因单果的线性问题、信息极度明确的简单问题

## 输出示例
```markdown
### OCGS诊断：XX系统
| 维度 | 评估 | 关键发现 |
|:----|:-----|:---------|
| 开放度 | 🟡 | 内部信息充足，但对外部信源有盲区（缺XX渠道） |
| 多样性 | 🟢 | 有3套备选方案，覆盖主要风险 |
| 耦合度 | 🔴 | 核心模块单点依赖，一旦XX故障全线停摆 |
| 冗余度 | 🟡 | 数据有备份但冷备恢复需4小时 |
| 自适应 | 🔴 | 缺乏自动调整机制，每次变更需人工干预 |
| 响应速度 | 🟡 | 感知周期1天，响应周期3天，而环境变化周期约1天 |
```

## 配合使用
- OCGS找短板 → 矛盾分析定位主要矛盾（哪个短板最致命）
- OCGS找系统结构 → 五层推演分析外部博弈
