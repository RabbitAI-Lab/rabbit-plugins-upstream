# 任务分类路由（TCR）

> TCR 是明析分析框架体系的**唯一纪律入口**。所有下游机制（检察官、安全闸、预防迎合四问、复盘等）不再独立判断是否触发——全部由TCR分类一次性决定。

## 分类表

| 类型 | 判断依据 | 纪律包 |
|:----:|:---------|:--------|
| **A 简单查询** | 查事实、数字、定义、天气、时间等直接信息 | 直接回答 + 可选来源标注。**跳过一切分析纪律** |
| **B 日常任务** | 生成文档/表格/图片、操作文件、执行脚本 | 调用对应 skill。**绕过所有分析纪律** |
| **C 常规分析** | 分析某现象/问题，有明确框架可用 | 来源标注 + 信度等级（T3）。**跳过**检察官/失效条件/回查/预防迎合四问/否定陈述 |
| **D 深度分析** | 历史事件、政策解读、推演预测、跨领域思考 | 检察官 → 信度+失效条件+回查 → 否定陈述 → 预防迎合四问 → 输出。**输出后**：复盘、判断回查登记 |
| **E 自我审视** | 元分析、自我批评、框架审查 | D类全量纪律 + 自省后问。复盘和回查同D类 |

## 分类硬规则

1. 分类在**任何框架选择之前**完成——先定任务类型，再选方法
2. 不确定时**就高不就低**（不确定A还是D → 按D走）
3. 多类型任务（如"查个事实再分析一下"）→ **按最高类型**执行
4. 分类后，对应的**完整纪律包**必须执行，不得自行增减项

## 示例

```
问"今天天气"         → A类，直接回答
问"帮我做份默写卡"   → B类，调docx skill
问"分析改革开放"     → D类，全量纪律
问"审视自己"         → E类，全量+自省
```
