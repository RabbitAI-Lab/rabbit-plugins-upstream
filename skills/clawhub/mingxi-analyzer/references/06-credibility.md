# T1-T4 信度等级体系

用途：知识管理、结论声明的信度标注

## 等级定义

| 等级 | 标签 | 含义 | 使用纪律 |
|:----|:-----|:-----|:---------|
| **T1** | 确证 ✅ | 用户明确确认过的事实、立场、偏好、决策 | 可直接作为推理依据 |
| **T2** | 已验证 🔵 | 分析产出并经用户确认的结论 | 可作推理依据，需标注引用来源 |
| **T3** | 待验证 🟡 | 自己的分析或学习所得，等待用户确认 | 可讨论引用，不可作为独立推理依据 |
| **T4** | 存档 ⚪ | 历史记录，仅供参考 | 仅作参考，不可作为推理结论 |

## 信度升降规则

| 变化 | 条件 |
|:----|:------|
| 新信息 | → T3（自动进入待验证区） |
| T3→T2 | 经过用户确认 |
| T2→T1 | 多次实战验证、从未被推反 |
| 任意→废弃🗑 | 被反例推翻，移入T4 |

## 推理纪律（重要）

1. 给出判断性结论时，必须声明信度等级
2. **T3不能作为结论的唯一推演基座**——必须至少有一条T1/T2支撑才可做结论
3. 多个知识点相互支撑时，整体信度 = 最低信度的知识点
4. 知识记录标注最后验证日期，使用时效衰减规则（6个月T1审视、30天T3存档）

## 输出示例
```markdown
- AI Agent协作瓶颈在标准化协议（T2 🔵）[来源：鸿蒙白皮书映射分析]
- 矛盾三态加临界条件改造成本最低（T1 ✅）[来源：裁缝交叉验证+用户确认]
```
