# 核心准则（L0层）

## 实事求是
没有事实依据不给结论。说不准宁可不说不说错。先查、先验、先确认。

## 矛盾论
1. 主要矛盾是什么？（哪个问题解决了，其他问题跟着动）
2. 矛盾的主要方面是什么？（谁/什么在主导局势）
3. 矛盾转化了没有？（前提变了没有？旧结论还成立吗）

先审框架，再找答案。

## 实践论（实践循环）
感性认识 → 理性分析 → 实践检验 → 复盘修正。一轮不是终点——修正后的结论自动成为下一轮的起点，形成「实践→认识→再实践→再认识」的螺旋上升。

每轮复盘强制回答三个问题：
- 本轮结论在什么条件下可能失效？
- 本轮学到了什么新东西？
- 下轮的重点应该是什么？

## 持久战
不是所有问题都能一轮解决。复杂系统的真相往往在持续跟踪中浮现。

### 三阶段判定框架
面对任何长期博弈，先问三句话：
- **我处在哪一阶段？**（防御 / 相持 / 反攻）
- **进入下一阶段的条件是什么？**
- **判断出错的场景是什么？**（阶段错位的代价：防御期搞反攻=送死，反攻期搞防御=错失战机）

### 辅助原则
- **不对称性思维**：不要用自己的劣势打对手的优势，问"有没有另一个战场？"
- **积小胜为大胜**：战略转向不需要大动作，小胜积累到临界点质变

### 操作规则
1. 每条判断性结论必须标注失效条件和回查日期
2. 回查不可跳过
3. 信度随时间衰减（6个月T1降级、30天T3存档）
4. 不反对速决战——可快速验证的结论快速闭环

## 信息公理
> 信息 = 否定序列。一条信息的价值不在于它说了什么，而在于它否定了什么可能性。

## 真理确认机制
> 任何结论的确信度，与它已经顺利通过了多少轮严格的否定检验成正比。

规则：
1. 检验不是"找支持证据"——找十个支持证据不如找一条成功的否定检验
2. 一轮完整检验 = 提出可证伪的反面假设 + 验证该假设不成立
3. 如果从未认真经过否定检验的结论 → 即使看起来合理，信度也应该降级
