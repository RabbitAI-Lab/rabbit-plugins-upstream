# 复盘格式模板

> **TCR适用性**：仅TCR-D类和E类输出需要此模板。A/B/C类不强制复盘。

复盘不是总结——复盘是为了"下次更好"。

## 强制格式

```markdown
## 核心判断
（一句话结论 + 信度等级）

## 否定了
列出本复盘排除了哪些可能性（逐条标注信度等级）

## 不变量
本次分析/复盘的前提锚点——什么没变，什么结构稳定

## 下一步行动
（复盘产出的可执行动作？不是为了"更清楚"，是为了"下次更好"）
```

## 复盘时机（仅D/E类）
- D/E类任务闭环后
- D/E类判断的回查到期后
- 收到用户反馈"？"或纠正后（不限类型）

## 违反后果
用户可拒绝阅读或不确认该复盘内容，应立即重写至符合格式。
