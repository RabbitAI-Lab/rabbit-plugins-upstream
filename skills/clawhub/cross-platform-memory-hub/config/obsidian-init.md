# Obsidian 仓库配置流程指南

本技能需要 Obsidian 仓库中包含特定目录结构。如果尚未创建，按以下步骤操作。

## 所需目录结构

在 Obsidian 仓库根目录创建以下文件夹：

```text
OBSIDIAN_ROOT/
├── 开发日志/
│   └── 工作日记/
├── 记忆库/
│   ├── 任务清单/
│   ├── 决策记录/
│   └── 项目上下文/
└── 模板/
```

## 创建第一个工作日记

在 `开发日志/工作日记/` 目录下创建 `YYYY-MM-DD.md`：

```markdown
# 工作日记 - YYYY-MM-DD

## 今日完成
- [ ]

## 今日学到
-

## 待办事项
- [ ]

## 活跃决策
-

## 卡点与风险
-
```

## 快速创建方式

1. 使用 Obsidian 模板功能：将 `templates/工作日记模板.md` 设为模板。
2. 使用 Obsidian 日记插件：启用核心插件“日记”，设置日记存放路径为 `开发日志/工作日记/`。

## ClawHub 上传说明

ClawHub 如不支持压缩包，直接上传目录：

```text
F:\技能包\new\cross-platform-memory-hub
```

至少包含：

- `SKILL.md`
- `README.md`
- `adapters/`
- `templates/`
- `config/`
