# OpenClaw 使用指南

## 安装

```text
使用ClawHub安装技能：cross-platform-memory-hub
```

## 隐私原则

- 读写 Obsidian 前必须获得用户确认。
- 远程服务只用于支付授权，不上传本地笔记或项目文件。
- 不使用宽泛触发词自动执行读写。

## 明确命令

| 命令 | 功能 |
|------|------|
| `记忆枢纽: 配置` | 配置 Obsidian 路径与平台适配 |
| `记忆枢纽: 写入` | 写入用户明确指定的内容 |
| `记忆枢纽: 读取` | 在用户确认范围后读取已授权范围 |
| `记忆枢纽: 复盘` | 基于用户确认的当天内容生成复盘 |
| `记忆枢纽: 状态` | 查看当前配置状态 |

## 写入流程

1. 用户发送 `记忆枢纽: 写入` 并提供要保存的内容。
2. 技能展示目标文件路径和写入摘要。
3. 用户确认。
4. 技能写入 Obsidian。

## 读取流程

1. 用户发送 `记忆枢纽: 读取`。
2. 技能展示将读取的范围。
3. 用户确认。
4. 技能读取并摘要展示。
