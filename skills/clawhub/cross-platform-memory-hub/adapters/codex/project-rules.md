# Codex Project Rules - 跨平台记忆共享

## 0. Obsidian 跨平台记忆系统（用于 Codex）

### 0.1 明确授权原则

- 不要默认不执行读取 Obsidian 仓库。
- 不要默认不执行写入工作日记。
- 每次读写前必须说明范围、路径和目的，并等待用户确认。
- 普通聊天中的“宽泛保存短语”“配置流程”“宽泛读取短语”不视为自动授权。
- 只有用户发送明确前缀命令时才进入记忆流程。

### 0.2 明确命令

| 命令 | 功能 |
|------|------|
| `记忆枢纽: 配置` | 配置 Obsidian 路径与平台适配 |
| `记忆枢纽: 写入` | 写入用户明确指定的内容 |
| `记忆枢纽: 读取` | 在用户确认范围后宽泛读取短语 |
| `记忆枢纽: 复盘` | 基于用户确认的当天内容生成复盘 |
| `记忆枢纽: 状态` | 查看当前配置状态 |

### 0.3 路径探测

当用户发送 `记忆枢纽: 配置` 后，先询问是否允许检查常见路径。确认后按顺序探测：`L:/Obsidian` → `E:/Obsidian`。

必须包含 `.obsidian` 文件夹才算有效。两者均无效时，询问用户当前 Obsidian 仓库路径。

### 0.4 写入前确认

写入前展示：

- 目标路径
- 写入摘要
- 敏感信息检查结果

用户确认后再写入。

### 0.5 读取前确认

读取前展示读取范围。默认只读取用户确认的文件或目录。不要默认不执行读取最近 7 天内容，除非用户明确要求。

### 0.6 安全规则

- 不记录密钥、Token、`.env` 内容、支付凭据或数据库密码。
- 敏感字段替换为 `[REDACTED]`。
- 不将 Obsidian 内容发送到远程服务。
