## Description: <br>
Converts PPT/PPTX files into MP4 videos with background music, smart slide durations, page transitions, and optional typewriter text effects. <br>

This skill is ready for commercial/non-commercial use. <br>

## Known Risks and Mitigations: <br>
Risk: The skill may change PowerPoint registry settings on Windows to adjust export resolution. <br>
Mitigation: Run it in a controlled environment and ask the agent to avoid registry edits unless you explicitly approve them. <br>
Risk: The skill may install Python packages during use. <br>
Mitigation: Review generated installation commands before execution and approve package installs only in trusted environments. <br>
