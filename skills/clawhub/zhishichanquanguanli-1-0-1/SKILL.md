# 知识产权知识管理

## 这个 skill 解决什么
为企业法务部门、知识产权代理机构和创新型企业设计知识产权知识库。覆盖商标注册、专利申请、著作权保护、商业秘密合规和知识产权维权五大核心模块。

它不是法律意见，而是把 IP 业务流程、材料清单、时间节点和常见驳回/风险点整理成标准化知识库，帮助企业和代理人**降本提效、减少失误、加快出文**。

---

## 如何使用本 SKILL

本 SKILL 是一个**结构化知识包**，每个子文件夹承担不同角色：

```
skill-ip-knowledge/
├── SKILL.md            ← 本文件（总览、方法论、AI 对话指南）
├── templates/          ← [可执行模板] 拿来即用的知识产权文档框架
│   └── index.md           技术交底书 / 保密协议 / 侵权证据清单 / 商标监测表
├── cases/              ← [经典案例] 中国IP领域的标志性案件拆解
│   └── index.md           王老吉vs加多宝 / 大疆专利布局 / 老干妈 / 今日油条 / 视觉中国
├── checklists/         ← [质量门禁] IP 管理全维度检查清单
│   └── index.md           商标 / 专利 / 著作权 / 商业秘密 / 维权
└── references/         ← [权威引用] 国际条约 + 各国知识产权局 + 免费专利数据库
    └── index.md           TRIPS / PCT / 巴黎公约 / WIPO / Espacenet / Google Patents
```

**AI 使用策略**：
- 需要生成交底书或保密协议 → 先查 `templates/` 中的模板骨架
- 需要论证法律风险 → 引用 `cases/` 中的真实判例
- 用户要做IP审计 → 输出 `checklists/` 中的检查维度
- 需要引经据典 → 从 `references/` 中取 WIPO/CNIPA 官方来源
- 输出方案时，始终回到本文件的工作流程 + 输出模板

## 适用场景
- 知识产权代理机构需要标准化内部作业流程和培训材料
- 企业法务/IPR 需要把商标/专利/版权知识沉淀为研发团队的参考手册
- 创新型企业需要建立商业秘密保护制度和员工培训体系
- 初创公司从零了解商标注册和专利申请的基本流程
- 需要准备 ISO 56005 等认证的文档体系

## 核心模块

### 1. 商标注册全流程指南
- 商标类型与分类（尼斯分类 45 类）
- 注册前准备（近似查询、显著性判断、材料清单）
- 申请流程与时间线（形式审查→实质审查→初审公告→核准注册）
- 常见驳回原因与应对
- 商标维护（续展/变更/许可备案/撤三防御）

### 2. 专利申请实务手册
- 专利类型快速判断（发明/实用新型/外观设计）
- 专利三性判断标准（新颖性/创造性/实用性）
- 技术交底书撰写模板（7个章节的标准格式）← 见 [templates/index.md](templates/index.md)
- 专利申请策略（时机选择/类型选择/国际路径）
- 专利年费维护（缴纳时间表/减免政策/滞纳金）

### 3. 著作权保护指引
- 著作权自动保护 vs 登记保护
- 软件著作权申请（材料清单/源代码提交技巧/审查周期）
- 开源协议解读（MIT/GPL/Apache/LGPL/BSD 对比表）

### 4. 商业秘密合规管理
- 商业秘密三要件（秘密性/价值性/保密性）
- 保密体系建设（制度/技术/人员/物理四层面）
- 离职员工商业秘密保护（审查清单/竞业限制/脱密期）

### 5. 知识产权维权指南
- 侵权发现渠道与监测
- 维权路径选择（平台投诉→律师函→行政投诉→司法诉讼）
- 侵权证据固定清单 ← 见 [templates/index.md](templates/index.md)
- 赔偿计算标准

## 工作流程

### 第一步：业务识别
商标 / 专利 / 著作权 / 商业秘密 / 综合 / 维权

### 第二步：信息对齐（必问）
- 企业规模和所在行业？是否有专职法务/IPR？
- 已有知识产权情况？当前最紧迫的 IP 问题？

### 第三步：生成方案
输出包含：结论 + 目录树 + 流程指南 + 可复制模板（从 [templates/](templates/) 选） + 常见错误对照表

### 第四步：风险自查
- 是否有"包过/包授权"等禁止承诺？
- 时间节点是否与最新审查周期一致？
- 是否标注了"以官方最新规定为准"？

## 常见错误
| 错误 | 后果 | 正确做法 |
|------|------|----------|
| 产品上市后才查商标 | 品牌改名成本巨大 | 产品命名前先做商标查询 |
| 专利申请前公开发表论文 | 丧失新颖性 | 先申请专利，后发表论文 |
| 离职员工带走客户名单 | 商业秘密泄露 | 入职签保密协议，离职做审查 |
| 收到侵权警告不回复 | 被认定为恶意 | 48小时内法务评估、回复 |

## 质量标准
- **精确**：商标类别、审查周期、年费金额等数字准确
- **可操作**：流程有编号步骤，材料有清单，模板可直接填
- **有边界**：法律意见标注"请咨询专业律师"
- **有案例**：用真实 IP 问题做场景说明

## 风险边界
- 不提供法律意见（标注"建议咨询专业律师"）
- 不承诺结果（不出现"包过""100%成功"）
- 标注时效（"请以官方最新公告为准"）
- 默认以中国大陆法律为准

## 终止条件
当用户拿到可直接使用的知识库目录、流程指南、模板和常见错误对照表，即可结束。
