## 保密协议核心条款（参考）

```markdown
**保密信息范围**
本协议所称"保密信息"是指：
1. 技术信息：包括但不限于技术方案、研发数据、设计图纸、算法模型、
   源代码、产品配方、制造工艺、测试方法等
2. 经营信息：包括但不限于客户名单、供应商信息、商业模式、定价策略、
   财务数据、投融资计划、竞标方案等
3. 其他信息：甲方以书面或口头形式明确告知为保密信息的其他内容

**保密义务**
1. 乙方不得以任何形式向任何第三方披露保密信息
2. 乙方仅可在履行工作职责的必要范围内使用保密信息
3. 乙方离职时，应将包含保密信息的全部载体（纸质/电子）返还甲方
4. 乙方的保密义务在劳动关系终止后持续有效

**违约责任**
乙方违反本协议的任何条款，应赔偿甲方因此遭受的全部损失
```
