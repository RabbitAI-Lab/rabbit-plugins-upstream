# 知识产权管理质量检查清单

## 商标管理自查
- [ ] 所有在用品牌已注册商标（含核心类别+关联类别）
- [ ] 产品/品牌命名前完成商标近似查询
- [ ] 商标续展提醒机制已建立（到期前12个月触发）
- [ ] 商标许可合同有期限和到期过渡条款
- [ ] 商标使用证据定期保存（应对撤三）
- [ ] 每月商标公告监控（发现近似商标及时异议）

## 专利管理自查
- [ ] 核心技术在研发阶段即启动专利预检索
- [ ] 研发成果在论文/展会公开前已完成专利申请
- [ ] 技术交底书格式规范（7个章节完整）
- [ ] 专利年费缴纳无遗漏（设提醒日历）
- [ ] 专利许可/转让有书面合同和备案
- [ ] 竞品专利定期监控（季度一次）

## 著作权管理自查
- [ ] 核心软件已完成著作权登记
- [ ] 使用的开源协议已审查合规性（GPL 传染性风险等）
- [ ] 员工创作的职务作品权属明确
- [ ] 对外授权使用的字体/图片/音乐有合法来源

## 商业秘密管理自查
- [ ] 全员签署保密协议（入职时+离职时重申）
- [ ] 核心岗位签署竞业限制协议
- [ ] 数据分级管理（公开/内部/机密/绝密）
- [ ] 离职前数据审查流程完善
- [ ] 保密培训纳入年度必修课
- [ ] 物理安防措施到位（门禁/访客/碎纸）

## 维权管理自查
- [ ] 侵权监测渠道覆盖（平台/搜索引擎/展会）
- [ ] 证据固定流程标准化（截图+公证+律师见证）
- [ ] 维权路径选择有理有据（优先低成本路径）
- [ ] 侵权处理时效有SOP（发现→固定→评估→行动）
- [ ] 维权成本与预期收益有评估
