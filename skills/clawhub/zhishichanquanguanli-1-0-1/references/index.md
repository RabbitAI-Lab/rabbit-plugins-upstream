# 知识产权权威引用与开源资源

## 国际法律与条约

### TRIPS 协定（与贸易有关的知识产权协定）
- **维护方**：WTO（世界贸易组织）
- **简介**：TRIPS 是 WTO 框架下最全面的知识产权多边协定，设定各成员国知识产权保护的最低标准。中国于 2001 年入世后全面执行 TRIPS。
- **覆盖范围**：版权及相关权利、商标、地理标志、工业设计、专利、集成电路布图设计、未披露信息（商业秘密）
- **适用场景**：国际贸易中的知识产权保护、跨境 IP 合规

### 巴黎公约（保护工业产权巴黎公约）
- **维护方**：WIPO（世界知识产权组织）
- **核心原则**：国民待遇原则（外国人在成员国享有与本国人同等的保护）；优先权原则（在第一个成员国申请后12个月内到其他成员国申请，享有原申请日的优先权）
- **适用场景**：跨国专利/商标申请策略

### PCT 体系（专利合作条约）
- **维护方**：WIPO
- **简介**：PCT 允许申请人通过一份国际申请，在 157 个缔约国中同时寻求专利保护。不代表"国际专利"（不存在"国际专利"），而是在各国分别审查。
- **关键时间线**：
  - 优先权日起 12 个月内提交 PCT 申请
  - 国际检索报告（16 个月内）
  - 国际公布（18 个月）
  - 进入国家阶段（30/31 个月）
- **适用场景**：需要多国专利保护的企业

### 马德里体系（商标国际注册）
- **维护方**：WIPO
- **简介**：通过一份申请、一种语言、一套费用，在 130+ 个缔约国中注册商标。
- **适用场景**：品牌出海、跨境电商的商标保护
