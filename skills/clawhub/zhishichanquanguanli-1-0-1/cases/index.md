# 知识产权经典案例

## 案例一：王老吉 vs 加多宝 商标之争

### 背景
广药集团拥有"王老吉"商标所有权，鸿道集团（加多宝母公司）通过商标许可使用该品牌。许可到期后，双方就商标续约发生纠纷，最终演变为持续近10年的"中国商标第一案"。

### 核心过程
1. **1995-2010**：加多宝通过商标许可使用"王老吉"品牌，将凉茶从地域饮品做到全国 200 亿市场规模
2. **2010**：许可到期，广药集团不再续约，加多宝被迫改用自建品牌"加多宝"
3. **2012-2019**：双方展开多场诉讼，包括商标侵权、包装装潢、广告语（"怕上火喝XXX"）等
4. **最终结果**：加多宝被判赔偿广药集团 14.4 亿元，丧失"王老吉"商标使用权

### 可学的三点
1. 商标许可合同必须约定到期后的品牌过渡方案（如"到期前X年开始品牌切换"）
2. 自建品牌虽然前期投入大，但比租用他人品牌更安全——加多宝花10年才让消费者接受"加多宝"品牌
3. 商标许可期间的品牌投入可能"为他人做嫁衣"——加多宝花 200 亿打广告帮助了王老吉品牌升值

## 案例二：大疆"无人机"专利布局

### 背景
大疆在全球持有超过 1.5 万件专利，覆盖飞行控制、图像传输、避障、云台、电池管理等全链路。其专利布局策略不是"有一两个核心专利就行"，而是"让竞品无论从哪个方向切入都会碰到大疆的专利墙"。

### 核心做法
1. **地毯式布局**：一个产品的核心功能可能被十几项专利保护，从不同角度阻止模仿
2. **围绕核心专利构建外围专利**：核心专利保护基本原理，外围专利保护具体实现，层层设防
3. **全球同步申请**：在主要市场（中美欧日韩）同时提交申请
4. **专利组合运营**：部分非核心专利对外授权许可，形成行业标准

### 可学的三点
1. 专利不是"有一个就行"，而是围绕核心技术做地毯式布局
2. 核心专利 + 外围专利的组合拳，让竞品规避设计的成本极高
3. 专利是可以运营的资产——授权许可收入可能超过产品本身利润

## 案例三：老干妈商业秘密维权

### 背景
老干妈前员工离职后，将老干妈的辣椒酱配方和制作工艺泄露给竞争对手，老干妈通过刑事报案+民事诉讼双路径维权。

### 核心做法
1. **保密协议入职即签**：老干妈对所有接触核心配方的员工签署严格的保密协议
2. **配方拆分管理**：核心配方由 3 人分别掌握不同部分，任何单人都无法复刻完整配方
3. **离职保密审查**：核心岗位员工离职前进行保密审查和离职面谈
4. **刑事立案**：发现泄露后第一时间报案，最终泄密者被刑事处罚

### 可学的三点
1. 保密协议必须在入职时签署，离职后持续有效
2. 核心机密应拆分由多人分别掌握（"不能把鸡蛋放在一个篮子里"）
3. 商业秘密泄露后刑事报案比单纯民事起诉更有威慑力

## 案例四："今日油条"商标被无效

### 背景
河南一家早餐店注册"今日油条"商标并开设连锁店，字节跳动以恶意攀附"今日头条"驰名商标为由提出异议。

### 核心过程
1. 早餐店老板认为"油条"和"头条"是不同品类，不构成近似
2. 字节跳动举证"今日头条"是驰名商标，即便跨类别也应受到保护
3. 商标局认定"今日油条"与"今日头条"构成近似，且注册具有攀附驰名商标的主观恶意
4. "今日油条"商标被宣告无效，后续门店的装潢设计还被认定构成不正当竞争

### 可学的三点
1. 驰名商标享受跨类别保护——不是"不同品类就不侵权"
2. "蹭名牌"即使侥幸注册，也可能因恶意注册被宣告无效
3. 商标+包装装潢+店招设计是关联的，一个输了全盘皆崩

## 案例五：视觉中国"黑洞照片"著作权争议

### 背景
2019年，视觉中国将首张黑洞照片标注为"视觉中国版权所有"并要求付费使用，但事实上这张照片由全球科研合作组织发布，视觉中国并不拥有版权。此事被共青团中央微博点名后，全网声讨，视觉中国被短暂关闭整改。

### 核心过程
1. 视觉中国将黑洞照片打上自家水印并标注付费使用
2. 网友发现大量公共领域图片（国旗、国徽等）也被标注版权
3. 共青团中央发微博质疑，引发全网讨伐
4. 视觉中国被天津网信办约谈，官网暂停服务整改
5. 事件后视觉中国修改了版权审核机制，但品牌声誉已严重受损

### 可学的三点
1. 版权声明必须真实有据——虚报版权可能引发严重舆情危机
2. 平台需要建立版权来源审核机制，不能"谁先上传就算谁的"
3. 声誉修复成本远高于合规成本——一朝失信，十年难修
