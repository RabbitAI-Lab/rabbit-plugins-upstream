This skill is ready for commercial/non-commercial use.

## Use Case:

Support maintainers and agents use this skill to triage CI Tools GitLab support requests and answer eligible issues using public sources.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Support replies could expose customer details or private logs in a public issue.

Mitigation: Check issue confidentiality and do not quote private logs in public replies.

Risk: Support could be given to an ineligible requester if trusted domains are misconfigured.

Mitigation: Configure SUPPORT_TRUSTED_DOMAINS correctly and verify requester eligibility before replying.
