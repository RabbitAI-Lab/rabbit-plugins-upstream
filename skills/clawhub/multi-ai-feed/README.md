# 多平台AI信息源 / multi-ai-feed

---

## 简介

一句话查遍快手、公众号、B站、视频号、小红书五大平台的 AI 爆款内容，自动聚类话题、跨平台对比，生成一份统一的可视化日报，并对每个平台的热门话题给出可直接执行的情报调查指引。

**核心价值**

- **五个平台一次查完**：不用再一个个平台单独提问、再手工把结果拼到一起，一次描述需求就拿到全域结果。
- **看清全域热点还是单平台热点**：同一个话题在各平台分别有多少内容、覆盖了几个平台，一眼就能分辨是真全网刷屏还是只在某个圈子火。
- **热度口径贴合平台特性**：B站按点赞排，快手、公众号、视频号、小红书按互动量（点赞+分享+评论）排，不会用一个不存在的指标误判热度。
- **话题自动归类**：AI教程、大模型、AI绘画这些方向由当天内容自动决定，不需要提前设定分类。
- **情报调查给到可执行动作**：每个平台的 TOP 话题都配好了调查模式、搜索引擎组合与可信度标注，拿着就能去核实。
- **一份报告长期留存**：日报按日期命名存在本地，可以随时回看历史某一天的全域 AI 热点。

**适用对象**

- 🤖 **AI 内容研究者** — 每天用一次提问掌握五大平台的 AI 热点全貌，省去逐平台刷内容的时间。
- 📊 **行业情报分析师** — 通过跨平台话题覆盖度判断热度真实性，配合调查指引快速核实关键信息。
- 🎬 **内容创作者 / 运营** — 发现正在起量的选题方向，并判断该方向适合投放到哪个平台。
- 📈 **品牌 / 市场负责人** — 追踪某个话题在不同平台的表现差异，为内容与投放策略提供依据。

## 功能特性

### 核心功能

- **多平台自由组合**：可查全部五个平台，也可只查其中一个或任意几个，用中文平台名即可指定。
- **爆款内容发现**：按各平台的主指标筛选高热度内容，每个分类展示排名靠前的作品。
- **话题智能聚类**：自动识别当日热门话题方向并分类，分类结果完全由实际内容动态生成。
- **跨平台话题对比**：统计同一话题在各平台的内容量与覆盖平台数，快速识别全域热点。
- **AI 情报调查**：为每个平台的 TOP 话题匹配调查模式与搜索引擎组合，输出带可信度标注的结构化调查指引。
- **自定义关键词定向查询**：支持全局统一关键词，也支持给不同平台分别指定关键词，精准覆盖细分方向。
- **可视化日报**：单份页面内含跨平台总览、跨平台话题对比与各平台分区，支持按平台筛选切换，每个平台保留自己的品牌配色。
- **封面图正常显示**：内置本地图片代理服务，解决部分平台封面的防盗链限制。
- **每日订阅**：开启后每天 17:00 自动产出日报，平台范围与关键词沿用你订阅时的选择。

## 重要数据说明

- **数据更新时刻按平台不同**：快手与 B站每日 15:00 更新前一天内容；公众号、视频号与小红书每日 16:00 更新前一天内容。
- **当天数据查不到**：更新时刻之前，最新可查日期为前天；更新时刻之后，最新可查日期为昨天。查询尚未更新的日期时，会先告知你当前可查的最新日期并等你确认，不会自动消耗额度去查一个没有数据的日期。
- **多平台同时查询取共同日期**：由于各平台更新时刻不同，同时查询多个平台时会取所有平台都已更新的最新日期，避免部分平台返回空结果。
- **公众号不按日期过滤**：公众号数据服务不支持时间过滤，返回的是当前收录的最新文章，指定日期只影响日报上的日期标注，不影响返回内容。
- **视频号无站外链接**：视频号作品不支持跳转到站外播放，报告中标题以纯文本呈现，不提供详情链接。
- **仅收录 AI 相关内容**：五个平台的数据服务都只收录 AI 相关内容，不是平台全量数据。
- **订阅执行时间**：每日 17:00 执行，晚于全部平台的更新时刻，保证五个平台当天都已出数。
