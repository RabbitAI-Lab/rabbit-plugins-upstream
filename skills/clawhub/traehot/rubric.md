## 当前版本: v0 (cold-start 等权公式)

```
composite = (ER + HP + QL + NA + AB + SR + SAT) / 7 × 2.0
```

每个维度 0-5 整数分。综合分范围 0-10。

## 7 个维度

### ER — Emotional Resonance（情感共鸣）
*稿子能否在前 30 秒让观众产生一种具体的、能命名的情感？*

- **0** — 纯信息传递；没有情感钩子
- **3** — 一般共鸣（"嗯，我也有过这种感觉"）
- **5** — 锐利、具体、让人不太愿意承认的自我识别

### SR — Social Resonance（社会议题共振）
*稿子触及一个当下的、有争议的、或结构性重要的社会模式吗？*

- **0** — 纯个人 / 人际层面
- **3** — 触到一个公认的社会现象，但没加新视角
- **5** — 命名了一个观众认识但没有语言形容的结构性模式

### HP — Hook Potential（钩子强度）
*前 3 秒能不能逼观众看下去 30 秒？*

- **0** — 通用开场（"大家好，今天聊一聊..."）
- **3** — 具体的承诺或反直觉断言
- **5** — 一个具体生动的场景或断言，观众无法停止处理

### QL — Quotable Lines（金句密度）
*稿子里至少 2-3 行能被截图、能作为独立文字单独传播吗？*

- **0** — 全是叙述；没有警句
- **3** — 结尾有一句令人记住的
- **5** — 多句独立可用、分布在稿子不同位置

### NA — Narrativity（叙事性）
*有没有一个可辨识的弧线——铺垫、升级、收束？*

- **0** — 列表式结构
- **3** — 松散的主线
- **5** — 紧凑的三幕结构，结尾 payoff 在开场就已埋好

### AB — Audience Breadth（受众广度）
*这个议题的潜在受众有多广？*

- **0** — 极小众（专业圈 / 单一兴趣）
- **3** — 中等（一类人群）
- **5** — 普世（暗恋 / 家庭 / 工作）

> 注意："广"不等于"愿意传播"。AB 是参考维度，不是决定性因素。

### SAT — Satire Depth（讽刺深度）
*稿子用了多层反讽 / 戏仿格式 / 自指嘲讽吗？*

- **0** — 真诚直陈
- **3** — 一层反讽
- **5** — 嵌套或自指反讽

> 如果你的频道走真诚路线，SAT 给 2-3 当占位，不要让它在排序中占主导。

## 三原则预检（打分前必过）

- **稀缺性**：搜不到同类内容？独家视角/产品/数据？
- **利他性**：观众能带走什么？知识/工具/情绪/共鸣？
- **高密度**：废话≤2句？信息/情绪密度高？

三条全部通过才进入维度打分。未通过直接返回 composite=5 以下。

## Bucket 预测方案

> 新人使用比率桶，基于账号 baseline：

| Bucket | 倍数范围 | 说明 |
|--------|----------|------|
| 退步 | <0.3× baseline | 显著低于平均水平 |
| 持平 | 0.3-1× baseline | 正常波动范围 |
| 命中 | 1-3× baseline | 达到预期 |
| 小爆 | 3-10× baseline | 超出预期 |
| 大爆 | >10× baseline | 现象级传播 |

## 打分速度

- 每个维度 30 秒
- 相信第一个整数
- 先盲打，再对比锚点
