## Description: <br>
A prompt-engineering skill for creating structured system prompts, linear task decompositions, Agent Loop selection guidance, and output schema checks. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, prompt engineers, and independent builders use this skill to draft structured system prompts, break agent tasks into linear steps, choose ReAct or CoT patterns, and define structured output schemas for lightweight agent workflows. <br>
