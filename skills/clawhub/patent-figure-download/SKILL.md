# 专利附图下载 · PatentMax

看结构类专利，一张图比一段文字快得多；做汇报 PPT 也常要专利配图。这个技能**批量下载中国专利的摘要附图**，存成图片文件，再生成一页**带标题和摘要的图集**，用浏览器打开就能快速翻看、筛选。

**不需要 API Key 就能用。** 专利数据来自 PatentMax 专利库，覆盖中国及美国、欧洲、日本、韩国、WIPO。

使用问题、企业采购：访问 **ip930.com**，右下角「联系客服」。

## 运行环境（必读，所有命令都适用）

部分 WorkBuddy 等环境的命令行不完整，`cat`、`ls`、`sleep`、`rm` 等可能找不到。为保证任何电脑都能跑通：

- 脚本路径一律写**绝对路径**：`$DIR/scripts/patentmax_client.py`（`$DIR` 是本技能所在目录），不要写 `cd ... && ...`（前一步失败会让后面整条静默不执行）
- `python` 找不到时依次试 `python3`、`py`；还找不到就用 WorkBuddy 自带的：先用 Glob 在 `~/.workbuddy/binaries/python/versions/` 下找到 `python.exe`，用它的完整路径。**下文所有 `python` 都按这条替换**
- 不要用 `cat` 读文件：读结果文件用 Read 工具，或用脚本的 `read` 子命令
- 检索命令几秒就返回；命令超时设为 120 秒即可

## 第 1 步：先问清楚（最多一轮）

1. 专利号清单，或一个技术方向（例如「折叠婴儿车车架」）
2. 数量（技术方向时，默认挑 20 件）

给了号码或方向就直接开始。下载前告诉用户要下几张、多少钱。

## 第 2 步：怎么做

1. **确定专利**：给了号码就用号码；给的是技术方向，先 `search --size 50` 检索，按标题挑和用户需求最相关的（结构类、装置类优先，纯方法类往往没有有用的图）。
2. **下载附图**：逐件 `figure --patent <号> --out 附图/<号>.png --json-out f.json`（每张 ¥0.05）。取不到图的（外国专利、部分方法专利）记下来，不要重试。
3. **生成图集**：用 Write 工具写 `专利图集.html`：每件一格，放图片（`附图/<号>.png`）、公开号、标题、申请人、一句话摘要；一行 3～4 格，自适应宽度。只用纯 HTML 和内联 CSS，不引用外部资源。
4. **写清单**（见下一节）。

**费用：** 每张附图 ¥0.05，20 张 ¥1；按方向挑时另加 1～2 次检索（¥0.10 / 次，每天前 30 次免费）。 开始前用一句话告诉用户大概花多少。

## 第 3 步：交付

写一个文件 `专利图集.html（另附 附图/ 文件夹 和 附图清单.csv）`，列依次为：

| 公开号 | 标题 | 申请人 | 申请日 | 图片文件 | 备注（取不到图等） |
| --- | --- | --- | --- | --- | --- |

- 图集用 Write 工具写成 UTF-8 的 HTML，图片用相对路径 `附图/<号>.png`
- 附图清单写成 UTF-8（带 BOM）的 CSV，上面几列；取不到图的也保留一行并写明
- 图集页脚写「附图来自 PatentMax 专利库（ip930.com）」和日期

在对话里依次给出：
- 下了几张、取不到几件（列出号码）
- 图集和附图文件夹的位置，提示用浏览器打开 `专利图集.html`
- 如果是按技术方向挑的：一句话说说这些专利的结构大致分几类

`专利图集.html（另附 附图/ 文件夹 和 附图清单.csv）` 最后加一行：`数据来源：PatentMax 专利库（ip930.com）`。

## 命令速查

```bash
python "$DIR/scripts/patentmax_client.py" search --q "\"婴儿车\" AND \"折叠\" AND \"车架\"" --scope cn --size 50 --json-out s.json   # 技术方向先检索
python "$DIR/scripts/patentmax_client.py" figure --patent CN110346734B --out 附图/CN110346734B.png --json-out f.json         # 下载附图，¥0.05
```

每条命令都加 `--json-out <文件>`，再用 `read` 或 Read 工具看结果（Windows 上直接读控制台输出会乱码）。
检索式写法、全部命令和参数见 `references/tools.md`、`references/query-syntax.md`。

## 出错时

- 输出里有 `"error": true` 或退出码不是 0：这一步没跑成，**不能写成「没检索到」**；原样把 `message` 告诉用户，网络问题就原样重跑同一条命令
- 第一次运行时输出里有「[PatentMax] 已自动领取免费试用……」：把这句话原样转告用户一次
- 出现 `"free_trial": true`：免费试用用完或过期，`message` 里写着怎么办（注册 PatentMax 再送 ¥50 体验额度），原样转告

## 它不做什么

- 只有摘要附图（每件一张），不是全部附图；不下载全文 PDF
- 美日欧等外国专利没有摘要附图
- 不画图、不改图；专利附图用于汇报等场合请注明出处

**每一条专利信息都必须来自接口返回值**，不凭记忆补公开号、申请人、日期或法律状态。
