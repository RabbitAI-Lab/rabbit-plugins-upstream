# 高性价比人生指南（决策框架）

把《高性价比人生指南》的核心方法论，变成你评估**任何人生决策**时的"会计口径"：先拆成本、再算收益、查证据硬不硬、最后给性价比档。不替你拍板，但让你算得清。

## 何时用

- "系安全带/装烟雾报警器/换低钠盐值不值？"
- "戒烟、运动、买保险、做体检，性价比怎么排？"
- "遇到心脏骤停、老人摔倒、租房被坑、账号被盗，先做什么？"
- "写代码接私单、开公司、做网站，有哪些法律红线？"
- "这笔钱/这段时间花得值不值，证据靠不靠谱？"

## 怎么套用（6 步，详见 references/high-value-life.md）

1. **拆成本**：钱 / 时间 / 精力 / 毅力，逐项标"有/无 + 量级"（毅力是最贵的隐性成本）
2. **拆收益**：落到四资源之一 —— 寿命 / 金钱 / 时间精力 / 人身自由，并标量级与"落在谁身上"（自己 > 直系亲属 > 互惠 > 陌生人，不合并算）
3. **定证据等级**：A（荟萃分析/RCT/大队列，有确切数字）· B（有研究但无确切数）· C（经验/公认做法）
4. **算性价比档**：极高 = 好处大且成本全零；高 = 好处大成本不高或好处中成本零；一般 = 其余
5. **查边界与争议**：看备注里的人群限定、反方证据、标"争议/待核实"的数字不引用
6. **给回执**：按模板输出（结论/成本/收益/证据/边界/指路）

## 输出模板

```
【结论】建议做 / 不建议 / 看你情况
【成本】钱___ 时间___ 精力___ 毅力___
【收益】换回（寿命/钱/时间/自由）___（量级）
【证据】A/B/C —— 关键数字 HR/RR=___，95%CI ___，来源类型 ___
【边界】适用___ 慎做/不适用___
【指路】原书第 X 节（领域：___）
```

## 边界

- 这是**框架**不是数据库：具体百分比以原书/原始文献为准，**绝不编造数字**；标"争议"的列出反方，不替你下结论。
- 全书 33 节领域地图与术语速查（HR/RR/OR/95%CI/RCT/混杂/反向因果等）见 `references/high-value-life.md`。
