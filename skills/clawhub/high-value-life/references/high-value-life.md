# 高性价比人生指南 — distilled

> 来源：eternity4719《高性价比人生指南》（GitHub: HowToLiveBetter，842 页，603 条建议，33 节）。
> 本文件是把书中"怎么评估一件事值不值得做"的方法论，蒸馏成可套用的决策程序，而非 603 条原文的搬运。读完后应能独立按书的口径给出"该不该做、证据多硬、性价比几档"的判断，无需回查原书。

## 一、心智模型（先建立这个视角）

书的核心不是"给你一份清单"，而是一套**资源会计**视角：

人一辈子只有四样可损耗/可保全的资源，任何决定都在这四样里算账，彼此不折算：
1. **寿命** —— 活得更久，少死于可避免的事
2. **时间与精力** —— 注意力/体力不被白耗
3. **金钱** —— 少花冤枉钱，花在收益确定的地方
4. **人身自由** —— 不因踩一条红线被拘留/看守所

**结论先行**：绝大多数内容天生为"让你信/让你买"设计，不是为"让你算清"设计。面对任何"这件事该不该做"的问题，先拆成这四样资源，再逐项问：花掉什么、换回什么、证据多硬。

## 二、核心程序：如何评估任何一条建议/决策

遇到"XX 该不该做、XX 性价比高吗、遇到 XX 怎么办"时，按 6 步套：

**Step 1 — 拆成本（四项，逐项标"有/无 + 量级"）**
- 钱：一次花多少、要不要持续投入
- 时间：一次性还是每天/每周占多少
- 精力：要不要动脑子盯
- 毅力：要不要长期"反人性"坚持（这是最贵的隐性成本）

**Step 2 — 拆收益（落到四资源之一，标量级）**
- 换寿命：总死亡率降百分之多少（≥20% 大，10–20% 中，<10% 或只量到中间指标为小）
- 换钱：金额（万元级大，数百–数千中，几十元小）
- 换人身自由：避免刑事责任（大）/ 拘留或行政处罚（中）/ 民事纠纷（小）
- 换时间精力：每天省出小时级（大）/ 每周小时级（中）/ 只省一次（小）
- 收益"落在谁身上"分四档，不合并计算：①自己 ②配偶及直系亲属 ③朋友同事等互惠关系 ④陌生人（最低档，且带被讹/被反咬风险）

**Step 3 — 定证据等级（只回答"数字可信不可信"，不回答"值不值"）**
- **A**：有具体数字，出自荟萃分析 / 长期大队列 / 随机分组试验（RCT），能量化降了多少（HR、RR、百分比）
- **B**：有研究支持但说不出确切数字，或仅小样本、单项研究
- **C**：作者经验或公认做法，无直接研究文献

**Step 4 — 算性价比档（A/B/C 与性价比互相独立）**
- **极高**：好处大 + 三项成本全为零
- **高**：好处大、成本不高，或好处中等、成本为零
- **一般**：其余（"一般"≠不该做，只是得自己掂量花销；全书条目都是建议做的）

**Step 5 — 查适用边界与争议**
- 看"备注"：人群限定（如肾功能不全者换盐先问医生）、是否只对健康老人有效、有无反方证据
- 标"争议"的条目：作者列出反方证据，不替你下结论
- 标"待核实(TODO)"的：数字未定，不引用

**Step 6 — 给结构化回执**（见第六节模板）

## 三、决策规则（IF → THEN）

- IF 一条建议"成本全零 + 收益大" → **优先做**（全书 104 条"极高"档，如系安全带、装烟雾报警器、换低钠盐）
- IF 证据是 A 但性价比一般 → 有效力但贵/麻烦，自行权衡（如带状疱疹疫苗：97.2% 效力 RCT，但两针三四千、且很少致命）
- IF 证据仅 C 但性价比极高 → 值得做（如出境前把行程发给家人）
- IF 涉及人身自由红线 → 先问"厂商/平台/公司会不会报案"，默认对方会追究（技术人尤甚）
- IF 遇到紧急情况 → 先保自己（自保动作与免责写在前），再救家人/熟人，对陌生人量力
- IF 看到"不要 XX"开头的节标题 → 那是"想防住的结果"，具体做不做以该节**条目标题**为准（条目标题一律动词开头，自己写清做/不做）

## 四、证据术语速查（解读研究数字用）

| 术语 | 读法 |
|---|---|
| HR / RR | 风险比。做了的那组出事快慢 ÷ 没做的组。0.87=低13%，1.21=高21% |
| OR | 比值比。少见事件上≈RR；常见事件上会夸大差距 |
| 95% CI | 95%置信区间。范围跨过 1（倍数类）或 0（加减类）= 差别可能只是巧合，文中写"无统计学意义" |
| RCT | 随机对照试验，证明因果最有说服力 |
| 荟萃分析 | 多项研究合并重算的总数字 |
| 队列/观察性 | 只记录不分组，能看相关，不足以证因果 |
| 混杂 / 反向因果 | 第三个因素同时牵动前后件；或因果方向反了（不是睡多致死，是病重才睡多） |
| 效应量 d/g | 差距大小：0.2 小、0.5 中、0.8 大 |
| GRADE | 证据可靠度评级：高/中/低/极低 |

**关键提醒**：观察性研究的 HR/RR 混着两样杂质——人群本就不同、有人先病了才这么做。读成"方向和大概多大"，别当"照做就能拿到的折扣"。

## 六、输出模板（分析任何"该不该做/怎么办"时套用）

```
【结论】建议做 / 不建议 / 看你情况（一句话）
【成本】钱：___ 时间：___ 精力：___ 毅力：___
【收益】换回（寿命/钱/时间/自由）：___（量级）
【证据】A/B/C —— （关键数字：HR/RR=___，95%CI ___；来源类型 ___）
【边界】适用：___ 不适用/慎做：___
【指路】详见原书第 X 节（领域：___）；标"争议"的见备注反方证据
```

## 七、反模式（避免这些读法）

- ❌ 把"性价比档"当证据等级 —— 两回事，互不抵消
- ❌ 把观察性研究的 HR/RR 当"照做就能拿到的折扣" —— 只信方向和量级
- ❌ 被"免费/省钱"标题骗 —— 看全文成本四项，尤其隐性毅力成本
- ❌ 忽略"备注/争议/待核实" —— 这些是适用边界，漏看会误用（如肾功能不全者换低钠盐先看医生）
- ❌ 对陌生人见义勇为不计风险 —— 书把自保动作和免责写在前，救人先护己
- ❌ 用全书 842 页当 RAG 检索 —— 本技能是框架，具体数字以原书/原始文献为准，不编造百分比
