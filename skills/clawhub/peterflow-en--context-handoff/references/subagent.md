# Sync an assigned subtask

Use the coordinator's existing dispatch or message channel. On first assignment send the minimum task context. During work send just the new or missing information, naming any earlier decision it supersedes. Include goal, source paths, decisions, relevant evidence, allowed actions and writes, ownership of shared files, completion condition and expected receipt.

Give a short packet inline or use the absolute path of a longer temporary one. Retain the existing agent, progress and collaboration settings. Context sync does not expand the assignment.

Give implementers the goal, predecessor outputs and permitted files. Give reviewers the frozen change, requirements and applicable current rules. Give testers the version to test, user entry point, inputs and acceptance criteria.

A recipient with an authorized task applies the update within its scope and reports results, actual edits, verification and remaining work. An information-only recipient without an active task acknowledges and waits. Confirm delivery from the existing receipt or subsequent work. Report task completion separately from receipt of context.
