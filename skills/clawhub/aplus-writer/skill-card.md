## Description:

结合 Amazon 商品详情与评论证据，规划 A+ 内容模块、信息层次和买家疑问回应。

This skill is ready for commercial/non-commercial use.

## Use Case:

Amazon sellers and product marketers use this skill to plan A+ content from product details and review evidence, organize module priorities, and address buyer questions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: This release has broader account controls and a documented quote-only workflow that can spend credits.

Mitigation: Set billing to ask every time and keep requests within the A+ planning workflow.

Risk: Recurring monitoring can trigger ongoing collection charges.

Mitigation: Explicitly decline recurring monitoring unless it is wanted.
