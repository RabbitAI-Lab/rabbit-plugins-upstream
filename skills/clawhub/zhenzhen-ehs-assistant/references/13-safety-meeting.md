# 13-安全会议组织与管理 — 操作SOP

> EHS专员组织各类安全会议的操作标准。从周例会到年度总结，从会议准备到事项跟踪。

---

## 先判断：你要开什么会

| 会议类型 | 频率 | 时长 | 参会人员 | 主要内容 |
|:--------|:----|:----|:--------|:--------|
| **安全周例会** | 每周1次 | 30-40分钟 | 项目管理人员+班组长 | 上周总结+本周计划+问题通报 |
| **月度安全分析会** | 每月1次 | 60分钟 | 全员 | 月度数据分析+趋势通报+下月重点 |
| **季度安委会** | 每季度1次 | 60-90分钟 | 管理层+各部门负责人 | 季度总结+制度审议+目标考核 |
| **年度总结会** | 每年1次 | 120分钟 | 全员 | 全年复盘+评优+下年计划 |
| **安全专题会** | 按需 | 30-60分钟 | 相关责任人 | 专项问题研讨/事故分析/新规学习 |
| **班前会** | 每日 | 5-10分钟 | 当班工人 | 当日作业风险提示+防护要求 |

## Step 2：会议组织

📋 **操作要点**

**安全周例会标准议程：**

```
1. 上周隐患整改情况通报（5分钟）
  - 上周发现XX条隐患，已整改XX条，整改率XX%
  - 逾期未整改的逐项说明原因
2. 本周重点工作部署（10分钟）
  - 本周高风险作业/重点区域
  - 专项检查安排
3. 各班组/部门反馈（10分钟）
  - 各班组轮流发言
  - 需要协调解决的问题
4. 领导讲话/总结（10-15分钟）
  - 点评上周工作
  - 强调本周重点
```

**月度安全分析会议程：**

```
1. 月度安全数据通报（15分钟）
  - 隐患统计：总数/分类/整改率/趋势
  - 教育培训：培训场次/人次/覆盖率
  - 特种设备/人员：检验/持证情况
2. 典型问题分析（15分钟）
  - 本月典型隐患/违章案例
  - 原因分析+改进建议
3. 下月工作计划（10分钟）
  - 季节性风险提示（如夏季防汛/冬季防火）
  - 下月检查重点
  - 培训计划
4. 自由讨论/交流（10分钟）
5. 领导总结（10分钟）
```

💡 **实例参考**：该EHS专员在某大型铁路项目时，每周五下午组织安全周例会。会前花30分钟整理本周隐患数据，把重点问题截图/照片放进PPT。会上先通报数据，再让各班组轮流说问题。哪个班组这周被查到3次以上违章，直接点名但不骂人，说"下周注意"就过去了。会后当天出会议纪要，24小时内发到群里。一年50+次安全例会，没有一次断档。

⚠️ **注意事项**
- 会议**不要只读PPT**，要有数据、有案例、有照片
- 会前把数据准备好，**不要会上现场统计**
- 每次会议**必须有纪要**，纪要**必须有跟踪事项**
- 会议时间控制好，不要开成"马拉松会议"

✅ **完成标志**
- 会议按时召开
- 签到表收集完毕
- 纪要已发出

## Step 3：会议纪要撰写与跟踪

📋 **操作要点**

**会议纪要标准模板：**

```
某项目公司
安全周例会会议纪要

时间：____年__月__日 __:__-__:__
地点：____________
主持人：____________ 记录人：____________
参会人员：____________（共__人）
缺席人员：____________（共__人）

一、上周工作总结
1. 隐患排查：上周发现__条，已整改__条，整改率__%
2. 教育培训：开展__场，覆盖__人次
3. 主要问题：
  （1）____________
  （2）____________

二、本周工作重点
1. ____________
2. ____________

三、跟踪事项
│ 序号 │ 事项内容 │ 责任人 │ 完成时限 │ 状态 │
│:----:|:--------|:------|:--------:|:----:|
│ 1  │ 整改XX隐患 │ 王XX │ 06-25  │ 进行 │
│ 2  │ 组织消防培训│ 张XX │ 06-28  │ 未开始│

四、其他事项

-------------------------------
本纪要发送：全体参会人员
抄送：项目负责人
```

**跟踪事项管理：**

```
会议结束 → 当天发出纪要 → 跟踪事项列入台账
 → 下次会议前核对跟踪事项完成情况
 → 未完成事项说明原因 → 更新完成时限
 → 完成事项标注闭合 → 归档
```

💡 **实例参考**：该EHS专员每次会议后当天出纪要，24小时内发出。会议提出的跟踪事项列在文末，下周开会前先看跟踪事项完成进度。没完成的让责任人说明原因，更新时限。这样每件事都有交代、不落空。

⚠️ **注意事项**
- 纪要**24小时内**发出，超过48小时就没意义了
- 跟踪事项必须有**责任人+完成时限**
- 下次会议第一件事就是**回头看**上期跟踪事项
- 连续2次未完成的事项升级汇报领导

✅ **完成标志**
- 纪要已发出
- 跟踪事项已列入台账
- 责任人确认知悉

## Step 4：安全月活动策划

📋 **操作要点**

**安全月活动方案框架：**

```
一、活动主题
 例："人人讲安全、个个会应急"

二、活动时间
 20__年6月1日-6月30日

三、活动内容
 1. 启动仪式（6月1日）：安全宣誓+签名墙
 2. 安全知识竞赛（6月上旬）：线上/线下答题
 3. 应急演练周（6月中旬）：消防/防汛专项演练
 4. 隐患排查周（6月下旬）：全员参与排查活动
 5. 安全培训讲座（6月下旬）：专家授课/案例学习
 6. 闭幕总结（6月30日）：优秀表彰+经验总结

四、奖项设置
 安全之星（个人）：__名，奖金__元
 优秀班组：__名，奖金__元
 知识竞赛优胜：__名，奖品__元

五、预算
 总计__元
```

💡 **实例参考**：该EHS专员在某大型铁路项目时组织了安全月活动，内容包括全员安全宣誓、消防安全培训、隐患排查竞赛等。安全月期间工人的安全意识明显提升，6月的隐患发现量比平时多但严重程度下降。

⚠️ **注意事项**
- 安全月不是"搞形式"，要**让工人真的有收获**
- 活动需要**提前1个月**策划，临时搞效果差
- 活动结束后**写总结报告**，作为下年改进依据
- 预算提前申报，别等活动开始再要钱

✅ **完成标志**
- 活动方案已审批
- 各项活动已按计划完成
- 活动总结报告已归档
