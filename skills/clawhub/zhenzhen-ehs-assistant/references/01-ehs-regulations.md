# 01-EHS核心法规速查 — 操作SOP

> EHS专员日常工作需要用到的核心法规速查手册。按领域分类，查法规翻这本就够了。

---

## 先判断：我要查什么

| 场景 | 查哪类法规 |
|:----|:----------|
| 施工现场安全管理 | 《安全生产法》+建设工程条例 |
| 消防检查 | 《消防法》+消防管理规定 |
| 职业健康 | 《职业病防治法》 |
| 环境保护 | 《环境保护法》+环保条例 |
| 特种设备 | 《特种设备安全法》 |
| 事故处理 | 《生产安全事故报告和调查处理条例》 |

---

## Step 1：核心法规速查

**📋 操作要点**

**EHS专员必须熟记的7部法律**（按重要程度排序）：

| 序号 | 法律名称 | 文号/施行日期 | 核心内容 | 工作对应 |
|:---:|:---------|:-------------|:--------|:--------|
| ① | **《安全生产法》** | 2021年修正版，2021年9月1日施行 | 安全责任制、主要负责人职责、双重预防机制、三同时 | ⭐ 所有工作的法律根本 |
| ② | **《消防法》** | 2021年修正版 | 消防安全责任制、消防设施配置、动火作业管理、疏散要求 | ⭐ 消防检查的依据 |
| ③ | **《职业病防治法》** | 2018年修正版 | 职业健康检查、防护用品、危害告知、职业病诊断 | 涉及粉尘/噪音/化学品场景 |
| ④ | **《环境保护法》** | 2014年修订版，2015年1月1日施行 | 环评、排污许可、环保三同时、按日计罚 | 涉及排污/废弃物/扬尘 |
| ⑤ | **《特种设备安全法》** | 2014年1月1日施行 | 特种设备定义、使用登记、定期检验、操作人员持证 | ⭐ 汽车吊/叉车/压力容器管理 |
| ⑥ | **《生产安全事故报告和调查处理条例》** | 国务院令第493号，2007年6月1日施行 | 事故等级划分、报告时限（1小时）、调查程序 | ⭐ 事故处理依据 |
| ⑦ | **《工伤保险条例》** | 2010年修订版 | 工伤认定、劳动能力鉴定、待遇标准 | 工伤事故处理 |

**📄 其他常用法规清单**：

| 法规名称 | 适用场景 |
|:---------|:--------|
| 《建设工程安全生产管理条例》（国务院令第393号） | 工程现场安全管理 |
| 《建筑施工企业主要负责人、项目负责人和专职安全生产管理人员安全生产管理规定》（住建部令第17号） | 三类人员安全考核管理 |
| 《生产安全事故应急预案管理办法》（应急管理部令第2号） | 应急预案编制与备案 |
| 《建设项目安全设施"三同时"监督管理办法》（安监总局令第36号） | 新建/改建项目安全设施 |
| 《用人单位劳动防护用品管理规范》（安监总厅安健〔2015〕124号） | 劳动防护用品配置 |
| 《危险化学品安全管理条例》（国务院令第591号） | 涉及危化品使用/存储 |

**💡 实例参考**：该EHS专员在某大型铁路项目上每天巡检时，最常用的是《安全生产法》——查到临时用电隐患时引用"第39条：生产经营单位应当对安全设备进行经常性维护、保养"，要求施工队立即整改。每次写隐患整改通知单时都会标注"违反XX法第X条"。

**⚠️ 注意事项**
- 法规会更新，每年初检查一次是否有新版本
- 工作中优先用**住建部/应急管理部**发布的部门规章（比法律条文更细）
- 写整改单时引用具体条款（第X条），不要只写"违反了安全生产法"

**✅ 完成标志**：能记住7部核心法的名称和适用范围，工作中知道去哪个法规找依据。
