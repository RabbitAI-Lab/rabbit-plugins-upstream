# 06-特种设备管理 — 操作SOP

> EHS专员对特种设备全生命周期管理的操作标准。从进场报验到定期检验到档案归档，确保设备合规运行。

---

## 先判断：你管理的设备类型

| 设备类型 | 常见设备 | 检验周期 |
|:--------|:--------|:--------|
| **起重机械** | 汽车吊、塔吊、施工升降机、门式起重机 | 每1年（汽车吊）或每2年（塔吊/施工升降机） |
| **厂内机动车辆** | 叉车、观光车 | 每1年 |
| **锅炉** | 蒸汽锅炉、热水锅炉 | 外部检验每1年，内部检验每2年 |
| **压力容器** | 储气罐、反应釜 | 每3-6年（视等级） |
| **电梯** | 客梯、货梯 | 每1年 |
| **压力管道** | 蒸汽管道、燃气管道 | 每3-6年（视等级） |

## Step 1：特种设备进场报验

📜 **法规依据**
- 《特种设备安全法》第25条：特种设备安装、改造、修理的施工单位应当在施工前将拟进行的特种设备情况书面告知特种设备安全监督管理部门
- 《特种设备使用管理规则》（TSG 08-2017）：使用单位应当在特种设备投入使用前或者投入使用后30日内办理使用登记

📋 **操作要点**

**设备进场必须核验的资料（5项）：**

| 序号 | 资料名称 | 核验要点 |
|:---:|:--------|:---------|
| 1 | **设备出厂合格证** | 设备型号、出厂编号、制造日期与铭牌一致 |
| 2 | **型式试验报告/监督检验证书** | 确认设备已通过型式试验，证书在有效期内 |
| 3 | **制造许可证** | 制造单位是否具备相应资质（A级/B级等） |
| 4 | **安装告知书** | 安装单位是否已向当地市场监管局告知 |
| 5 | **安装单位资质** | 安装单位是否具备相应安装许可 |

**报验流程：**

```
设备入场 → 核验5项资料 → 安装单位安装
 → 安装自检 → 报当地特检院监督检验
 → 取得《监督检验证书》→ 办理使用登记
 → 取得《特种设备使用登记证》→ 投入使用
```

📄 **特种设备信息登记表模板**：

```
设备信息登记表

设备名称：________  设备类别：________
设备型号：________  出厂编号：________
制造单位：________  制造日期：________
额定起重量/参数：________
使用登记证号：________  登记日期：________
下次检验日期：________
安装位置：________
操作人员：________（姓名/持证号）
备注：________
```

💡 **实例参考**：某大型铁路项目施工高峰期有汽车吊3-5台。每台汽车吊进场后，先核对出厂合格证、型式试验报告、制造许可证三证，确认安装单位有相应资质，安装完成后报当地特检院监督检验，取得监督检验证书后办理使用登记。整个过程约5-7个工作日，不办完不允许投入使用。

⚠️ **注意事项**
- 设备**未办理使用登记**前严禁投入使用，违者可处3万-30万罚款
- 汽车吊属于流动式起重机，每台设备的**注册地与使用地可能不同**，跨省使用需确认当地要求
- 安装告知需提前7天向当地市场监管局提交
- 所有资料原件留存备查，复印件随设备存档

✅ **完成标志**
- 设备已取得《特种设备使用登记证》
- 设备铭牌与登记信息一致
- 5项报验资料已归档

## Step 2：特种设备台账管理

📜 **法规依据**
- 《特种设备使用管理规则》（TSG 08-2017）第2.5条：使用单位应当建立特种设备台账，逐台建立安全技术档案

📋 **操作要点**

**台账应包括的内容：**

| 栏目 | 内容 | 更新频率 |
|:----|:----|:--------|
| 设备基本信息 | 名称/型号/出厂编号/制造日期 | 设备进场时录入 |
| 使用登记信息 | 登记证号/登记机关/登记日期 | 取得使用登记后 |
| 检验信息 | 上次检验日期/检验结论/下次检验日期 | 每次检验后 |
| 维保记录 | 维保单位/维保日期/维保内容 | 每次维保后 |
| 操作人员 | 操作人员姓名/持证号/有效期 | 人员变动时 |
| 运行记录 | 每日运行时间/作业内容/异常情况 | 每日 |
| 故障/事故记录 | 故障时间/原因/处理方式 | 发生时 |

💡 **实例参考**：该EHS专员在某大型铁路项目时建立了一本《特种设备管理台账》，每台汽车吊一页，记录设备型号、检验有效期、操作人员等信息。每月初翻一遍台账，看哪些设备的下次检验快到期了，提前一个月联系检测机构预约。这样不会出现设备超期未检的情况。

⚠️ **注意事项**
- 台账**每月至少更新一次**（核验设备运行状态和检验有效期）
- 建议用Excel/在线表格管理，设置有效期提醒（提前30天）
- 设备转场/退场时在台账中标注并归档

✅ **完成标志**
- 所有在册特种设备已录入台账
- 下次检验日期已标注
- 检验到期预警已设置

---

## Step 3：定期检验与维保

📜 **法规依据**
- 《特种设备安全法》第40条：特种设备使用单位应当按照安全技术规范的要求，在检验合格有效期届满前一个月向特种设备检验机构提出定期检验要求

📋 **操作要点**

**各类设备检验周期：**

| 设备类型 | 检验周期 | 检验机构 | 检验合格标志位置 |
|:--------|:--------|:--------|:--------------|
| 汽车吊 | 每年1次 | 当地特检院 | 驾驶室/操作室 |
| 塔吊 | 每2年1次 | 当地特检院 | 塔身底部 |
| 施工升降机 | 每2年1次 | 当地特检院 | 轿厢内 |
| 叉车 | 每年1次 | 当地特检院 | 车身显眼处 |
| 储气罐 | 每3-6年 | 当地特检院 | 罐体铭牌旁 |

**检验前准备：**

```
距有效期30天 → 预约检验
 → 准备待检资料（使用登记证/上次检验报告/维保记录）
 → 设备自检（确认设备状态正常/安全装置完好）
 → 配合检验（提供资料/现场配合/操作演示）
 → 取得检验报告 → 更新台账 → 粘贴检验合格标志
```

📄 **检验到期预警登记表**：

```
┌────────┬──────────┬──────────┬──────────┬──────────┐
│ 设备名 │ 上次检验 │ 下次检验 │ 预警日期 │ 预警状态 │
│    │ 日期   │ 日期   │ (提前30天)│     │
├────────┼──────────┼──────────┼──────────┼──────────┤
│ 汽车吊1│ 2025-05 │ 2026-05 │ 2026-04 │ 已处理  │
│ 汽车吊2│ 2025-08 │ 2026-08 │ 2026-07 │ 未到期  │
│ 叉车  │ 2025-03 │ 2026-03 │ 2026-02 │ 已预约  │
└────────┴──────────┴──────────┴──────────┴──────────┘
```

💡 **实例参考**：某大型铁路项目每个月进行一次特种设备专项检查，该EHS专员拿着设备台账逐个核对：设备是否在检验有效期内、操作人员是否持证、安全装置是否完好。配合安监站和监理的专项检查一年4-6次，每次都提前准备好设备档案资料。

⚠️ **注意事项**
- 设备**超期未检**继续使用，可处3万-30万罚款，出了事故从重处罚
- 检验合格标志必须**粘贴在设备显眼位置**，方便检查人员查看
- 检验不合格的设备**立即停止使用**，整改后重新检验
- 日常维保记录也要保存好，检验时可能需要查阅

✅ **完成标志**
- 所有设备均在检验有效期内
- 检验合格标志粘贴到位
- 维保记录完整

## Step 4：特种设备档案管理

📋 **操作要点**

**每台设备应建立的档案包含：**

| 序号 | 档案内容 | 来源 |
|:---:|:--------|:----|
| 1 | 设计文件/制造许可证/出厂合格证 | 制造单位提供 |
| 2 | 型式试验报告/监督检验证书 | 制造/检验单位 |
| 3 | 安装告知书/安装质量证明 | 安装单位 |
| 4 | 使用登记证 | 市场监管局 |
| 5 | 定期检验报告 | 特检院 |
| 6 | 日常维保记录 | 维保单位 |
| 7 | 运行记录/故障记录 | 使用单位自建 |
| 8 | 操作人员资质证书复印件 | 操作人员提供 |

💡 **实例参考**：该EHS专员每台汽车吊建立一个档案袋，封面贴设备信息标签，所有资料按顺序放入。设备转场时档案随设备一起走，设备退场时档案归档保存至少5年。

⚠️ **注意事项**
- 档案**一机一档**，不得混放
- 设备退场后档案至少保存5年（《特种设备安全法》第26条要求）
- 电子版+纸质版双重存档

✅ **完成标志**
- 每台设备均有独立档案
- 档案内容齐全（8项全）
- 电子版已备份
