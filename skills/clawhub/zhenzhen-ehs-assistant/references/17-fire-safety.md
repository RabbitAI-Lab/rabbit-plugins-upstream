## Step 1：消防设施配置与管理

📜 **法规依据**
- 《消防法》第16条：机关、团体、企业、事业等单位应当履行消防安全职责，按照国家标准、行业标准配置消防设施、器材
- 《建筑灭火器配置设计规范》（GB 50140）：灭火器配置类型和数量的设计标准

📋 **操作要点**

**灭火器配置标准：**

| 场所类型 | 灭火器类型 | 保护距离 | 配置密度 |
|:--------|:---------|:--------|:--------|
| 办公区 | ABC干粉灭火器4kg | 20米 | 每75平方米1具 |
| 施工区 | ABC干粉灭火器4kg | 15米 | 每50平方米1具 |
| 仓库 | ABC干粉灭火器4kg | 15米 | 每80平方米1具 |
| 食堂 | ABC干粉灭火器4kg+灭火毯 | 20米 | 每50平方米1具 |
| 配电室 | CO2灭火器或ABC干粉 | 20米 | 不少于2具 |

**消防设施检查频次：**

| 设施 | 检查频次 | 检查要点 |
|:----|:--------|:--------|
| 灭火器 | 每月1次 | 压力表指针在绿区、喷管无堵塞、外观完好 |
| 消火栓 | 每月1次 | 阀门启闭正常、水带/水枪完好、无遮挡 |
| 应急照明 | 每月1次 | 断电后自动点亮、亮度达标 |
| 疏散指示 | 每月1次 | 指示灯亮、方向正确、无破损 |
| 消防通道 | 每周1次 | 畅通无堵塞 |

## Step 2：动火作业消防安全

📋 **操作要点**

**动火作业要求：**

```
作业前 → 办理动火许可证 → 清理现场易燃物（半径5米内）
 → 配备灭火器（不少于2具4kg干粉）
 → 设动火监护人（全程在场）
 → 作业中 → 监护人不得离岗
 → 作业后 → 检查无遗留火种（30分钟观察）
 → 动火证归档
```

**重点管控：**

| 要点 | 具体要求 |
|:----|:--------|
| 无证不动火 | 动火许可证必须在有效期内 |
| 监护人不在不动火 | 监护人离开作业立即停止 |
| 现场不清不动火 | 5米内易燃物必须清理完毕 |
| 设施不全不动火 | 灭火器、防火毯等必须到位 |

## Step 3：消防演练组织

📜 **法规依据**
- 《消防法》第16条：单位应当制定灭火和应急疏散预案，定期组织消防演练

📋 **操作要点**

**演练方案编制：**

```
一、演练目的
二、演练时间地点
三、参与人员
四、演练场景设定
 例：办公区起火，火势蔓延
五、演练流程
 1. 发现火情（角色人员模拟）
 2. 报警（模拟拨打119）
 3. 初期灭火（灭火器实操）
 4. 疏散（沿疏散通道有序撤离）
 5. 集合清点人数
 6. 总结点评
六、安全措施（防止演练中真实受伤）
七、物资准备（烟雾弹/灭火器/担架等）
```

**演练后复盘：**

```
演练结束 → 组织复盘会议
 → 记录发现的问题（如：疏散用时过长/灭火器使用不熟练）
 → 制定改进措施
 → 修订应急预案
 → 下次演练重点验证改进项
```

💡 **实例参考**：该EHS专员在某大型铁路项目时，上半年组织消防演练1次，下半年组织防汛演练1次。消防演练前一周出方案、准备物资、培训参与人员。演练当天按方案执行，结束后立即组织复盘，发现3项改进点（疏散指示不够清晰、部分人员灭火器使用不熟练、集合点标识不明显）。根据复盘结果修订了应急预案，把改进项纳入下次演练重点验证。

⚠️ **注意事项**
- 演练**不是走过场**，要让参与人员真正掌握技能
- 演练中发现的问题**一定要整改**，否则下次还是同样的问题
- 演练记录**留照片+签到+总结报告**，迎检时要查

✅ **完成标志**
- 演练按计划完成
- 复盘总结已出具
- 改进措施已落实
