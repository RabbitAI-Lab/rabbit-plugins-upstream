# 20-季节性安全管理 — 操作SOP

> EHS专员季节性安全管理的操作标准。根据不同季节的气候特点，提前做好风险防范和应急准备。

---

## 先判断：当前是什么季节

| 季节 | 月份 | 主要风险 | 防范重点 |
|:----|:----|:--------|:--------|
| **春季** | 3-5月 | 风大/春困/雷雨 | 防风/防滑/防雷 |
| **夏季** | 6-9月 | 高温/暴雨/雷电 | 防暑/防汛/防雷 |
| **秋季** | 10-11月 | 秋燥/雾天 | 防火/防雾 |
| **冬季** | 12-2月 | 低温/冰雪/取暖 | 防滑/防冻/防火/防煤气中毒 |

---

## Step 1：夏季安全管理（6-9月）

📋 **操作要点**

**防暑降温：**

| 措施 | 具体要求 |
|:----|:--------|
| 调整作业时间 | 高温时段（11:00-15:00）停止露天作业或轮换作业 |
| 设置休息点 | 作业区设置遮阳休息棚，配备风扇/空调 |
| 供应饮水 | 作业区设置饮水点，供应淡盐水/绿豆汤 |
| 配备防暑药品 | 藿香正气水/十滴水/风油精等 |
| 高温预警响应 | 气温≥35℃减少露天作业，≥38℃停止露天作业 |

**防汛准备：**

| 措施 | 具体要求 |
|:----|:--------|
| 排水系统检查 | 清理排水沟/下水道，确保畅通 |
| 物资准备 | 沙袋/水泵/雨衣/手电筒/应急照明 |
| 临时设施加固 | 工棚/围挡/脚手架检查加固 |
| 基坑/低洼区 | 设置围挡+排水泵，防止雨水倒灌 |
| 应急响应 | 暴雨预警时停止室外作业，人员撤离至安全地带 |

## Step 2：冬季安全管理（12-2月）

📋 **操作要点**

**防滑防冻：**

| 措施 | 具体要求 |
|:----|:--------|
| 路面除冰 | 雨雪后及时清理作业面和通道积雪/冰层 |
| 铺设防滑垫 | 出入口/坡道/楼梯铺设防滑垫 |
| 设备防冻 | 水管/消防管道保温，设备启动前预热 |
| 防寒用品 | 配备防寒服/手套/保暖鞋 |

**冬季防火：**

| 措施 | 具体要求 |
|:----|:--------|
| 取暖设备管理 | 严禁使用电炉/明火取暖，使用正规取暖设备 |
| 宿舍用电 | 严禁私拉乱接，人走断电 |
| 消防设施 | 灭火器防冻（干粉灭火器可正常使用） |
| 动火作业 | 冬季风大物燥，动火作业加大检查力度 |

**防煤气中毒：**

| 措施 | 具体要求 |
|:----|:--------|
| 严禁室内烧炭 | 宿舍/办公室严禁使用炭火取暖 |
| 燃气设备检查 | 食堂燃气设备定期检查，安装一氧化碳报警器 |
| 通风要求 | 使用燃气场所保持通风 |
| 热水器管理 | 燃气热水器必须安装在室外或通风处 |

---

## Step 3：春秋季安全管理

📋 **操作要点**

**春季（3-5月）：**

| 风险 | 防范措施 |
|:----|:--------|
| 大风 | 检查围挡/广告牌/脚手架加固，5级以上停止高处作业 |
| 春困 | 加强班前会安全教育，调整作息时间 |
| 雷雨 | 检查防雷接地，雷雨时停止室外作业 |
| 复工 | 节后复工全面安全检查+全员安全教育 |

**秋季（10-11月）：**

| 风险 | 防范措施 |
|:----|:--------|
| 秋燥 | 加强防火检查，清理枯草落叶 |
| 大雾 | 雾天停止吊装和高处作业，车辆减速慢行 |
| 换季 | 更换冬季劳保用品，检修取暖设备 |

💡 **实例参考**：该EHS专员在某大型铁路项目时，每年6月前完成防汛物资准备（沙袋/水泵/雨衣等），11月前完成冬季防寒防冻物资准备。夏季高温时段调整作业时间，上午早开工、下午晚开工，中午休息时间延长。冬季重点检查宿舍用电，发现电热毯、小太阳等大功率电器一律收缴。季节性管理的关键是"提前一个月"——6月防汛的事5月就要开始准备，12月防冻的事11月就要开始准备。

⚠️ **注意事项**
- 季节性安全管理的核心是**提前准备**，不要等天气变了再买物资
- 高温/暴雨/寒潮预警发布时**立即启动响应**
- 季节性物资**每年检查一次**，过期的及时更换
