# 05-应急管理与事故处理 — 操作SOP

> EHS专员的"底线工作"——平时做预案搞演练，万一出事按流程走。

---

## 先判断：你现在是什么状态

| 场景 | 该做的事 | 优先级 |
|:----|:--------|:------|
| **没有应急预案** | 立即编制 | ⭐⭐⭐ 高 |
| **有预案但没演练过** | 组织演练 | ⭐⭐⭐ 高 |
| **已经发生事故** | 按事故处理流程走 | 🔴 紧急 |
| **事故善后中** | 整改+报告+预防 | ⭐⭐ 中 |

---

## Step 1：应急预案编制

**📜 法规依据**
- 《生产安全事故应急预案管理办法》（应急管理部令第2号，2019年修正）：应急预案分综合预案、专项预案、现场处置方案

**📋 操作要点**

**企业至少要有哪些预案**：

| 预案类型 | 网络科技公司 | 施工单位 |
|:--------|:------------|:--------|
| **综合应急预案** | ✅ ✅ | ✅ ✅ |
| **消防专项预案** | ✅ ✅ | ✅ ✅ |
| **防汛专项预案** | 看地区 | ✅（雨季项目）|
| **触电现场处置方案** | ✅ | ✅ ✅ |
| **机械伤害处置方案** | ⬜ 有设备的话 | ✅ ✅ |
| **高处坠落处置方案** | ⬜ | ✅ ✅ |

**📄 应急预案编制模板（目录）**：

```
1. 总则（编制目的、依据、适用范围）
2. 风险描述（可能发生的事故类型）
3. 组织机构及职责（总指挥、副总指挥、各小组）
  - 抢险救援组
  - 医疗救护组
  - 疏散引导组
  - 后勤保障组
4. 预警与信息报告
5. 应急响应（分级响应、处置措施）
6. 应急保障（物资、通信、经费）
7. 培训与演练
8. 附则（管理、更新）
附录：
 A. 应急物资清单
 B. 应急联络电话
 C. 疏散路线图
```

**⚠️ 注意事项**
- 预案写了要发到每个人手上（不是写完了锁抽屉里）
- 应急电话清单要每季度更新一次（人员可能有变动）
- 小公司至少要有消防预案+应急疏散图

**✅ 完成标志**：应急预案编制完成，已全员培训

## Step 2：应急演练

**📜 法规依据**
- 《安全生产法》第78条：生产经营单位应当定期组织应急演练
- 《消防法》第16条：消防安全重点单位至少每半年一次消防演练

**📋 操作要点**

**演练流程**：

```
方案编制 → 方案审批 → 物资准备 → 人员通知 → 演练实施 → 总结复盘 → 预案修订
```

**📄 演练方案模板（消防演练）**：

```
消防应急演练方案

时间：___年__月__日 下午14:00-15:00
地点：____
参加人员：____（约__人）

日程：
14:00-14:10 集合，宣布演练开始
14:10-14:25 疏散演练（拉响警报→人员沿疏散通道撤离→清点人数）
14:25-14:45 灭火器实操（讲解干粉灭火器使用方法→每个人实际操作）
14:45-14:55 总结讲评

物资清单：
□ 烟雾弹/发烟罐 2个
□ 干粉灭火器 5具（可实操的）
□ 急救箱 1个
□ 扩音器 1个
□ 警戒线
□ 担架（可选）
```

**💡 实例参考**：该EHS专员在某大型铁路项目组织了消防和防汛各1次演练。消防演练时先用烟雾弹制造烟雾场景，拉响应急警报后人员按路线疏散，再到空地上培训干粉灭火器使用（每个人的实操了）。总结复盘时发现3个问题：①有人不知道最近的安全出口 ②灭火器位置有2个点被材料堵了 ③部分工人不会拔插销。

**⚠️ 注意事项**
- 演练不是演戏——要真实测试应急能力，找出问题才是目的
- 每次演练后必须复盘改进，不然白练了
- 留影像资料（照片/视频），作为合规备查

**✅ 完成标志**：演练完成+复盘报告+影像资料存档

## Step 3：事故处理

**📜 法规依据**
- 《生产安全事故报告和调查处理条例》（国务院令第493号）第9条：事故发生后1小时内上报

**📋 操作要点**

**事故处理十步流程**：

```
① 立即停止作业（保护现场）
② 救助伤员（打120）
③ 报告上级（1小时内逐级上报）
④ 事故现场保护（拉警戒线，除救援人员外不得进入）
⑤ 配合事故调查（如实陈述）
⑥ 事故原因分析
⑦ 制定整改措施
⑧ 全员警示教育
⑨ 事故报告归档
⑩ 保险理赔（工伤/安全责任险）
```

**事故上报时限**：

| 事故等级 | 上报时限 | 上报层级 |
|:--------|:--------|:--------|
| 一般事故（1-2人死亡/重伤） | 1小时 | 县级应急管理部门 |
| 较大事故（3-9人死亡） | 1小时 | 市级应急管理部门 |
| 重大以上 | 1小时 | 省级以上 |

**📄 事故报告模板**：

```
事故快报

报告单位：________
报告时间：____年__月__日__时__分

一、事故发生时间：____年__月__日__时__分
二、地点：________
三、事故类型：________（高处坠落/触电/机械伤害等）
四、伤亡情况：亡__人，伤__人
五、简要经过：
________________________
六、初步原因分析：
________________________
七、已采取的措施：
________________________

报告人：______  电话：______
```

**⚠️ 注意事项**
- 事故发生后**第一时间救人**，不是先写报告
- 保护现场（拉警戒线）——调查组到之前，任何人不能动现场
- 不要私自处理尸体或隐瞒不报——刑事责任

**✅ 完成标志**：事故已按流程处理，报告已提交
