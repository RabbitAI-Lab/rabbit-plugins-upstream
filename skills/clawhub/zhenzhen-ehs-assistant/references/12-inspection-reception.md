# 12-安全检查与迎检 — 操作SOP

> EHS专员应对各级安全检查的操作标准。从迎检准备到现场配合到整改闭环，确保每次检查顺利通过。

---

## 先判断：谁来检查

| 检查层级 | 检查频次 | 特点 | 应对重点 |
|:--------|:--------|:----|:--------|
| **业主（北京铁路局）** | 每季度1次 | 标准高、规格高、问题通报层级高 | 资料完整+现场规范 |
| **公司（某施工单位）** | 每月1次 | 熟悉内部标准，检查细致 | 日常工作留痕 |
| **集团** | 每半年1次 | 宏观检查，重点看制度体系 | 制度完善+体系运行 |
| **安监站** | 不定期，约2-3次/年 | 法规执法，发现问题处罚 | 合规性+整改闭环 |
| **监理** | 日常巡查，约2-3次/月 | 日常监督，问题直接发监理通知单 | 日常管理到位 |

---

## Step 1：迎检准备（检查前2-3天）

📜 **法规依据**
- 《安全生产法》第62条：负有安全生产监督管理职责的部门依法开展安全生产行政执法工作，被检查单位应当予以配合

📋 **操作要点**

**迎检准备流程：**

```
接到检查通知 → 制定迎检计划 → 召开迎检部署会
 → 梳理备查资料（8大类） → 现场全面巡查整改
 → 资料归档整理 → 检查前一天复查
 → 当天提前到场准备
```

**备查资料清单（8大类50+项）：**

| 类别 | 主要资料 | 准备要点 |
|:----|:--------|:--------|
| **安全台账类** | 隐患排查台账、整改通知单、复查记录 | 闭环率100%，时间线完整 |
| **教育培训类** | 三级教育记录、班前会记录、专项交底记录 | 签字完整，未漏培 |
| **专项方案类** | 危大工程方案、安全技术措施 | 审批签字齐全 |
| **应急预案类** | 综合预案、专项预案、演练记录 | 在有效期内，演练有照片 |
| **设备管理类** | 设备台账、检验报告、使用登记证 | 均在有效期内 |
| **人员资质类** | 特种作业人员台账、证件复印件 | 人证对应，证件有效 |
| **会议纪要类** | 安全例会纪要、专题会纪要 | 会议频次符合要求 |
| **行政批文类** | 施工许可证、安全监督备案、开工报告 | 齐全到位 |

💡 **实例参考**：该EHS专员在某大型铁路项目时，每次迎检前2-3天制定《迎检准备计划表》，列出50+项备查内容，逐一核对。检查前一天组织相关人员走一遍现场，把80+处风险点过一遍。检查当天提前到现场，安排好陪同人员、资料调取人员，确保检查时随时能拿出需要的资料。一年15+次检查全部一次性通过。

⚠️ **注意事项**
- 迎检准备**不要临时抱佛脚**，日常工作做扎实了迎检自然轻松
- 资料分类存放，**贴上标签**，检查时1分钟内能拿出来
- 现场问题**提前整改完再迎检**，不要等检查发现了再说
- 提前了解检查组的侧重点，针对性准备

✅ **完成标志**
- 备查资料全部整理到位
- 现场隐患已全部整改
- 迎检人员分工明确

## Step 2：现场迎检配合

📋 **操作要点**

**迎检当天流程：**

```
检查组到场 → 首次会议（汇报+PPT）
 → 现场检查（全程陪同+记录问题）
 → 资料检查（按类别调取）
 → 末次会议（检查组通报问题）
 → 签字确认检查记录
```

**陪同检查要点：**

| 场景 | 怎么做 |
|:----|:------|
| 检查组提问 | 实事求是回答，不知道的不乱说，"这个情况我核实后补充" |
| 检查组指出问题 | 当场认领，记录"我们会立即整改" |
| 检查组拍照 | 同步拍照，记住拍照位置和问题 |
| 检查组查看资料 | 分类快速调取，提前安排专人负责 |
| 检查组要求说明 | 准备好项目概况PPT+安全管理体系介绍 |

**常见问题应对话术：**

| 检查组说 | 你该回 |
|:--------|:------|
| "这个隐患怎么没整改完？" | "我们已经下发了整改通知单，施工队正在整改中，计划XX日完成，我每天跟踪进度" |
| "这个培训记录签字不全" | "确实是我们工作疏忽，我们马上补签并加强管理" |
| "你这个制度过期了" | "我们已经更新了新版，在OA系统走审批流程中，我先提供旧版和更新稿" |

💡 **实例参考**：该EHS专员在迎检时总结的经验是：检查组指出问题，不辩解、不推卸、不找理由。简单说一句"确实是我们做得不到位，马上整改"，然后记录下来。检查组走后该整改的整改、该完善的完善。下次检查时，上次发现的问题都已经闭合了，检查组反而会觉得你执行力强。

⚠️ **注意事项**
- **不要跟检查组争辩**，争赢了对你没好处
- 所有检查发现的问题**逐条记录**，防止整改时遗漏
- 检查组走之前确认**整改反馈时限**和**提报方式**
- 陪同人员不要太多，2-3人足够（项目负责人+安全负责人+资料员）

✅ **完成标志**
- 检查组通报问题已记录
- 整改反馈时限已确认
- 检查记录已签字

## Step 3：检查后整改与闭环

📋 **操作要点**

**整改闭环流程：**

```
检查结束 → 整理问题清单 → 召开整改部署会
 → 下发整改通知 → 限期整改（3-7天）
 → 整改完成后复查 → 拍照对比
 → 编制整改报告 → 报检查组/业主
 → 资料归档 → 纳入问题库
```

📄 **检查问题整改记录表**：

```
│ 序号 │ 问题描述 │ 检查类型 │ 责任单位 │ 整改措施 │ 完成时限 │ 复查结果 │ 复查人 │
│:----:|:--------|:--------:|:--------:|:--------|:--------:|:--------:|:------:|
│ 001 │ 配电箱门未锁 │ 业主检查 │ 劳务1队 │ 加锁+教育 │ 当日  │ 已整改  │ 张XX  │
│ 002 │ 培训记录不全 │ 公司检查 │ 项目部  │ 补记录+归档│ 3日   │ 已整改  │ 张XX  │
```

**建立"迎检问题库"：**

```
检查结束后汇总所有发现的问题 → 分类统计
 → 识别高频问题（如临时用电/高处作业）
 → 纳入日常管控重点
 → 下次迎检前重点核查高频问题
```

💡 **实例参考**：该EHS专员在某大型铁路项目建立了"迎检问题库"，收录了6大类高频问题。每次迎检前除了准备常规资料外，额外重点核查这6类问题。随着时间推移，高频问题的出现频率逐月下降，检查评分也逐步提高。

⚠️ **注意事项**
- 整改报告**附整改前后对比照片**，更有说服力
- 整改反馈不要超期，逾期会被通报
- 同一问题**反复出现**说明管理上出了漏洞，要从制度层面解决
- 整改完成不代表事情结束，**纳入日常管控**防止复发

✅ **完成标志**
- 所有问题已整改闭环
- 整改报告已报检查组
- 高频问题已纳入日常管控
