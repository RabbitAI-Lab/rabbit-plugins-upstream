# 18-职业健康管理 — 操作SOP

> EHS专员职业健康管理的操作标准。覆盖职业病危害因素识别、职业健康检查、劳动防护用品配置等全流程。

---

## 先判断：你的现场存在什么职业病危害因素

| 危害因素 | 常见产生环节 | 可能导致的职业病 |
|:--------|:-----------|:---------------|
| **粉尘** | 切割/打磨/破碎/拌料/清扫 | 尘肺病 |
| **噪声** | 机械运转/切割/冲压/空压机 | 噪声聋 |
| **高温** | 露天作业/锅炉房/热处理 | 中暑 |
| **化学品** | 油漆/胶水/清洗剂/焊接烟尘 | 职业中毒/皮肤病 |
| **工频电场** | 配电室/高压线路 | 长期影响待研究 |
| **振动** | 手持振动工具/破碎锤 | 手臂振动病 |

## Step 1：职业病危害因素识别与检测

📜 **法规依据**
- 《职业病防治法》第26条：用人单位应当实施由专人负责的职业病危害因素日常监测，并确保监测系统处于正常运行状态

📋 **操作要点**

**识别与检测流程：**

```
识别现场存在的危害因素（看工艺/查MSDS/问工人）
 → 委托有资质机构进行现场检测
 → 取得检测报告
 → 对照GBZ 2.1《工作场所有害因素职业接触限值》判断是否超标
 → 超标点制定整改措施
 → 整改后复测确认
 → 检测结果公示告知工人
```

**检测周期：**

| 类型 | 检测频率 | 说明 |
|:----|:--------|:----|
| 首次检测 | 新项目投产时 | 全面检测所有危害因素 |
| 日常监测 | 持续进行 | 企业可自行使用简易设备 |
| 定期检测 | 每年1次 | 委托有资质机构检测 |
| 变更检测 | 工艺/设备改变时 | 变更后重新检测 |

## Step 2：职业健康检查

📜 **法规依据**
- 《职业病防治法》第35条：对从事接触职业病危害的作业的劳动者，用人单位应当按照规定组织职业健康检查

📋 **操作要点**

**三种体检类型：**

| 类型 | 时间 | 检查内容 | 法律要求 |
|:----|:----|:--------|:--------|
| **上岗前** | 入职前 | 基础健康状况+职业禁忌筛查 | ❗必须做，不做不得上岗 |
| **在岗期间** | 每年或每2年 | 针对接触的危害因素专项检查 | ❗必须做 |
| **离岗时** | 离职时 | 确认离职时健康状况 | ❗必须做 |

**体检后处理：**

```
收到体检报告 → 逐人查看检查结论
 → 未见异常 → 存档
 → 有职业禁忌 → 调离原岗位
 → 疑似职业病 → 安排复查+上报
 → 确诊职业病 → 走工伤认定程序
 → 体检结果书面告知本人
```

## Step 3：劳动防护用品（PPE）管理

📜 **法规依据**
- 《用人单位劳动防护用品管理规范》（安监总厅安健〔2015〕124号）：用人单位应当根据工作场所中的职业病危害因素及其危害程度，为劳动者配备符合标准的劳动防护用品

📋 **操作要点**

**PPE配置标准：**

| 危害类型 | 防护用品 | 更换周期 |
|:--------|:--------|:--------|
| 粉尘 | 防尘口罩（KN95及以上） | 脏污即换/最长1天 |
| 噪声 | 耳塞/耳罩（SNR≥28dB） | 耳塞3-5天/耳罩6个月 |
| 化学品 | 防毒面具+滤毒盒/防护手套/护目镜 | 滤毒盒按说明书/手套破损即换 |
| 高处作业 | 安全带/安全绳/安全网 | 安全带按厂家/外观异常即换 |
| 电焊作业 | 焊接面罩/防护手套/防护服 | 面罩滤片按说明书/防护服破损即换 |
| 一般作业 | 安全帽（有效期30个月）、劳保鞋 | 到期更换/损坏即换 |

**PPE管理流程：**

```
采购（确认有LA标志/合格证）
 → 入库验收（规格/数量/有效期）
 → 发放登记（领用人签字）
 → 使用培训（教工人正确使用和保养）
 → 日常检查（巡检时查看佩戴情况）
 → 报废更新（过期/损坏及时更换）
```

💡 **实例参考**：该EHS专员在某大型铁路项目时，每天巡检看工人的PPE佩戴情况。最常见的问题：安全帽没系下颏带、高温天气工人不戴安全帽、电焊工不戴防护面罩。发现后当场纠正，第一次教育、第二次通报。劳保用品建立了发放台账，每人领了什么、什么时候领的都登记清楚。

⚠️ **注意事项**
- PPE **不能替代工程防护措施**，优先从源头消除危害
- 安全帽有**30个月有效期**，到期必须报废
- 防尘口罩**不能洗了再用**，一次性口罩每天更换
- 工人不戴PPE，**首先反思是不是发的PPE戴着不舒服**，再谈纪律

✅ **完成标志**
- 职业病危害因素已识别
- 职业健康体检已按周期完成
- PPE发放到位，工人正确佩戴
- 职业卫生档案完整
