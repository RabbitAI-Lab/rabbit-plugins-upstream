## Step 1：安全生产费用管理

📜 **法规依据**
- 《企业安全生产费用提取和使用管理办法》（财资〔2022〕136号）：明确了各行业安全生产费用的提取比例和使用范围

📋 **操作要点**

**各行业提取比例：**

| 行业类型 | 提取标准 | 依据 |
|:--------|:--------|:----|
| 建筑施工 | 按工程造价1.5%-2.5% | 财资〔2022〕136号 |
| 交通运输 | 按营业收入0.5%-1.5% | 同上 |
| 电力生产 | 按营业收入0.5%-2% | 同上 |
| 机械制造 | 按营业收入0.5%-1% | 同上 |
| 信息技术服务 | 按营业收入0.5% | 同上 |

**安全费用使用范围：**

| 类别 | 具体用途 |
|:----|:--------|
| 安全设施 | 防护装置/报警系统/监控系统/消防设施 |
| 安全培训 | 三级教育/专项培训/培训教材/师资费用 |
| 劳动防护 | PPE采购/检测/更换 |
| 应急管理 | 应急预案编制/演练/应急物资 |
| 隐患整改 | 隐患整改所需材料和人工 |
| 安全评价 | 安全预评价/验收评价/现状评价 |
| 设备检测 | 特种设备检验/防雷检测/环境检测 |
| 安全奖励 | 安全考核奖金/安全活动经费 |

## Step 2：工伤保险管理

📜 **法规依据**
- 《工伤保险条例》（国务院令第586号）：工伤认定、劳动能力鉴定、待遇标准

📋 **操作要点**

**工伤保险缴费：**

| 项目 | 说明 |
|:----|:-----|
| 缴费主体 | 用人单位全额承担，个人不缴费 |
| 缴费比例 | 0.5%-2%（行业差别费率+浮动费率） |
| 基数 | 本单位职工工资总额 |
| 强制要求 | 必须参保，不参保可处欠缴金额1-3倍罚款 |

**工伤认定标准：**

| 情形 | 认定结论 | 说明 |
|:----|:--------|:----|
| 工作时间和场所内，因工作原因受到事故伤害 | 认定工伤 | 最常见情况 |
| 工作时间前后在工作场所内，从事与工作有关的预备性或收尾性工作受伤 | 认定工伤 | 提前上班/加班也属于 |
| 在工作时间和工作场所内，因履行工作职责受到暴力等意外伤害 | 认定工伤 | 被人打伤也算 |
| 患职业病 | 认定工伤 | 需有职业病诊断 |
| 因工外出期间，由于工作原因受到伤害 | 认定工伤 | 出差途中算 |
| 非本人主要责任的交通事故受伤 | 认定工伤 | 上下班途中 |
| **故意犯罪/醉酒/自残** | **不认定工伤** | 明确排除 |

**工伤处理流程：**

```
发生事故 → 救治伤员（第一时间送医）
 → 报告（单位24小时内报人社局）
 → 收集证据（现场照片/目击证言/病历）
 → 申请工伤认定（单位30日内，个人1年内）
 → 人社局出具认定决定书
 → 劳动能力鉴定（伤情稳定后）
 → 根据鉴定结果享受工伤待遇
 → 费用报销/伤残补助/医疗待遇
```

## Step 3：安全生产责任保险

📋 **操作要点**

**安责险与工伤保险的区别：**

| 对比项 | 工伤保险 | 安责险 |
|:------|:--------|:------|
| 性质 | 强制社保 | 商业保险 |
| 保障范围 | 本单位员工 | 本单位员工+第三方 |
| 赔偿内容 | 工伤待遇（医疗/伤残/工亡） | 补充赔偿+事故处理费用 |
| 费率 | 行业差别费率 | 浮动费率（与安全记录挂钩） |
| 法律要求 | 必须参保 | 高危行业强制，其他鼓励 |

💡 **实例参考**：安全费用管理最重要的是"账目清晰、专款专用"。每月整理安全费用使用情况，列清楚每笔钱花在了什么地方：买了灭火器、做了培训、修了安全设施。年底汇总全年安全费用使用情况，作为安全工作总结的一部分。

⚠️ **注意事项**
- 安全费用**专款专用**，不能挪用于其他支出
- 安全费用台账**每月更新**，备查
- 工伤保险**必须全员参保**，不能只给正式工参保
- 事故发生后**24小时内报告**，晚了可能影响工伤认定

✅ **完成标志**
- 安全费用专款专用，账目清晰
- 工伤保险全员参保
- 安责险已投保（如适用）
