## Step 1：作业审批与票证管理

📜 **法规依据**
- 《安全生产法》第43条：生产经营单位进行爆破、吊装、动火、临时用电以及国务院应急管理部门会同国务院有关部门规定的其他危险作业，应当安排专门人员进行现场安全管理

📋 **操作要点**

**高风险作业审批流程：**

```
作业申请（作业方填写申请表）
 → 现场确认（EHS专员核查安全条件）
 → 审批签字（EHS负责人/项目经理）
 → 作业前交底（所有作业人员签字确认）
 → 作业中监管（EHS专员现场监督）
 → 作业结束确认（清理现场/恢复安全措施）
 → 票证归档
```

**作业票证标准格式：**

```
┌──────────────────────────────────────┐
│     动火作业许可证        │
├──────────────────────────────────────┤
│ 申请单位：________  作业地点：________  │
│ 作业内容：________  作业时间：________  │
├──────────────────────────────────────┤
│ 安全措施确认：              │
│ □ 动火点周围易燃物已清理         │
│ □ 灭火器已配备（__具）          │
│ □ 动火监护人已到位           │
│ □ 焊接设备完好             │
│ □ 作业人员持证作业           │
├──────────────────────────────────────┤
│ 申请人：________ 监护人：________    │
│ 审批人：________ 批准时间：________   │
│ 作业结束确认：现场已清理，无遗留火种   │
│ 确认人：________ 时间：________     │
└──────────────────────────────────────┘
```

## Step 2：各高风险作业安全管控要点

📋 **操作要点**

**2.1 高处作业**

| 管控要点 | 具体要求 |
|:--------|:--------|
| 作业高度分级 | 2-5米（一级）/5-15米（二级）/15-30米（三级）/30米以上（特级） |
| 防护要求 | 安全带"高挂低用"，可靠锚点，临边防护栏杆 |
| 作业条件 | 六级以上大风/暴雨/大雾禁止高处作业 |
| 工具管理 | 工具放入工具袋，禁止上下抛掷 |

**2.2 动火作业**

| 管控要点 | 具体要求 |
|:--------|:--------|
| 动火分级 | 一级（禁火区）/二级（固定动火区外）/三级（固定动火区内） |
| 现场准备 | 清理易燃物、配备灭火器、设监护人 |
| 作业要求 | 监护人全程在场，作业结束后检查30分钟确认无火种 |

**2.3 临时用电**

| 管控要点 | 具体要求 |
|:--------|:--------|
| 三级配电 | 总配电箱→分配电箱→开关箱，逐级保护 |
| 两级保护 | 总漏电保护器+开关箱漏电保护器 |
| 接地要求 | TN-S系统（三相五线制），重复接地 |
| 电缆要求 | 绝缘良好，过路有保护，不得拖地浸泡 |

**2.4 吊装作业**

| 管控要点 | 具体要求 |
|:--------|:--------|
| 设备检查 | 汽车吊支腿稳固，安全装置完好 |
| 人员要求 | 司机+信号工双人持证 |
| 作业条件 | 六级以上大风禁止吊装，视线不清禁止吊装 |
| 警戒区域 | 吊装半径内禁止人员进入 |

💡 **实例参考**：该EHS专员在某大型铁路项目时，临时用电占比总隐患35%、高处作业占25%。每天巡检的重点就是配电箱门有没有锁、电缆有没有破损、高处作业人员有没有系安全带。焊机电线磨损是高频问题，月均发现8-12次。每周五下午专项检查配电系统，逐一测试漏电保护器。发现问题当场制止，不让工人有"这次算了"的侥幸心理。

⚠️ **注意事项**
- 高风险作业**没有审批不准作业**，这是铁律
- 监护人必须**全程在场**，不能中途离开
- 作业结束后**必须确认安全状态**后才能离开
- 同一作业区域有多项高风险作业同时进行时，评估交叉作业风险

✅ **完成标志**
- 作业票证审批齐全
- 安全措施全部落实
- 作业过程安全可控
- 作业结束确认已完成

## Step 3：高风险作业日常巡查重点

📋 **操作要点**

**日巡查高风险作业要点：**

| 检查项 | 检查方法 | 频次 |
|:------|:--------|:----|
| 高处作业防护 | 看临边防护/安全带/作业平台 | 每次经过 |
| 动火作业 | 看审批单/灭火器/监护人 | 动火期间 |
| 临时用电 | 看配电箱/电缆/漏保 | 每日巡查 |
| 吊装作业 | 看成绳/支腿/警戒区/持证 | 吊装期间 |

💡 **实例参考**：该EHS专员每天巡检时对高风险作业区域重点关注。发现高处作业工人安全带没挂好，当场喊下来重新挂好再上去。发现焊机电源线磨损了，当场让电工换线。不走过场，发现问题就处理，处理不掉的升级汇报。

⚠️ **注意事项**
- 高风险作业**巡检不是走过场**，发现问题必须当场处理
- 无法立即整改的**停止作业**，整改完成后再恢复
- 每次巡检结果**记录在案**，作为隐患管理依据

✅ **完成标志**
- 高风险作业全部审批
- 现场安全措施到位
- 无违规作业情况
