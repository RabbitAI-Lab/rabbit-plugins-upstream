# 07-特种作业人员管理 — 操作SOP

> EHS专员对特种作业人员全流程管理的操作标准。覆盖6大工种从入场核验到证件到期预警。

---

## 先判断：你要管理什么工种

| 工种 | 常见岗位 | 证件发证机关 | 复审周期 |
|:----|:--------|:-----------|:--------|
| **电工** | 安装电工、维修电工、运行电工 | 应急管理局（原安监局） | 每3年 |
| **焊工** | 电焊工、气焊工、氩弧焊工 | 应急管理局 | 每3年 |

| **架子工** | 普通架子工、附着升降脚手架工 | 住建部 | 每2年 |

| **司索工** | 吊装司索、挂钩工 | 住建部 | 每2年 |

## Step 1：人员入场核验

📜 **法规依据**
- 《特种作业人员安全技术培训考核管理规定》（国家安全监管总局令第30号）第5条：特种作业人员必须经专门的安全技术培训并考核合格，取得特种作业操作证后方可上岗作业

📋 **操作要点**

**入场核验流程：**

```
新工人到场 → 查验身份证原件
 → 查验特种作业操作证原件
 → 核对人证是否一致（照片+姓名）
 → 查询证书真伪（应急管理局官网或住建部官网）
 → 确认证书在有效期内
 → 登记入册 → 安排岗位
```

**证书真伪查询渠道：**

| 证书类型 | 查询平台 | 网址 |
|:--------|:--------|:----|
| 应急管理局发证 | 应急管理部官网 | cx.mem.gov.cn |
| 住建部发证 | 住建部全国工程质量安全监管信息平台 | 各省住建厅官网 |
| 市场监管局发证 | 全国特种设备公示信息查询平台 | cnse.e-cqs.cn |

📄 **特种作业人员登记表**：

```
│ 序号 │ 姓名 │ 工种 │ 证件号 │ 发证机关 │ 有效期至 │ 复审情况 │ 备注 │
│:----:|:----:|:----:|:------:|:--------:|:--------:|:--------:|:----:|
│ 001 │ 张三 │ 电工 │ T210...│ 应急局  │ 2027-05 │ 已复审  │ 熟练工 │
│ 002 │ 李四 │ 焊工 │ T410...│ 应急局  │ 2026-11 │ 未到复审 │ 新进场 │
```

💡 **实例参考**：该EHS专员在某大型铁路项目时，每个新进场的特种作业人员必须先核证。拿着身份证和操作证原件，在应急管理部官网查询证书真伪，核对照片、姓名、有效期。发现过有人拿假证来报名，当场拒收并告知负责人。核验通过后登记入册，安排上岗。这是"先核证后上岗"的铁律。

⚠️ **注意事项**
- 证书原件必须查验，**不接受复印件**
- **人证不一致**（证书照片不是本人）立即拒收
- 电子证可接受，但必须现场联网查询真伪
- 证书过期1天也不允许上岗

✅ **完成标志**
- 人员已核验通过
- 证书真伪已查询确认
- 登记入册

## Step 2：证件台账与有效期管理

📜 **法规依据**
- 《特种作业人员安全技术培训考核管理规定》第21条：特种作业操作证每3年复审1次

📋 **操作要点**

**台账内容：**

| 栏目 | 填写要求 |
|:----|:--------|
| 姓名 | 与身份证一致 |
| 工种 | 按发证机关核定工种填写 |
| 证件编号 | 完整抄录 |
| 发证机关 | 应急管理局/住建部/市场监管局 |
| 初次领证日期 | 证件上的发证日期 |
| 有效期至 | **过期前1个月预警** |
| 复审日期 | 最近一次复审日期 |
| 复审状态 | 已复审/待复审/超期未复审 |
| 入场日期 | 核验通过日期 |
| 离场日期 | 退场时填写 |

**预警机制（提前30天）：**

```
每月1日 → 调取台账中下月到期的名单
 → 通知本人：你的证还有30天到期
 → 通知班组长：安排该人员去复审/换证
 → 到期前15天 → 再次催促确认
 → 到期前7天 → 仍未处理的停止上岗
 → 证件过期 → 禁止上岗，直至取得新证
```

💡 **实例参考**：该EHS专员在册管理特种作业人员15-20人，每月初用Excel筛选出下月证件到期的名单。提前30天通知本人去复审/换证，同时通知班组长调整工作安排。有些工人拖着不去复审，到到期前一周直接跟他说"明天你的证过期了，后天不能上班"，他马上就去了。一年下来零证件过期上岗。

⚠️ **注意事项**
- 台账**每月至少更新1次**（录入新进场人员/更新复审状态/标注离场）
- 证件到期预警要**书面+口头**双重通知（留痕保护自己）
- 不同工种的复审周期不同，台账必须标注清楚
- 人员流动频繁时，每周核验1次新进场人员

✅ **完成标志**
- 所有在册人员证件有效
- 台账完整，下次复审日期已标注
- 无人持过期证件上岗

## Step 3：日常管理与检查

📋 **操作要点**

**日常管理要点：**

| 频率 | 工作内容 |
|:----|:--------|
| **每日** | 巡检时查看特种作业人员是否持证上岗 |
| **每周** | 抽查人证是否一致 |
| **每月** | 逐人核验证件有效期，更新台账 |
| **每季度** | 统计持证率，排查无证上岗情况 |
| **年度** | 汇总全年培训复审情况，制定下年计划 |

**现场检查要点：**
- 操作人员是否主动佩戴证件/随身携带电子证
- 设备操作人员是否与设备登记的操作人员一致
- 特种作业区域是否有明显的持证上岗标识
- 人证不符时当场制止，记录并通报

💡 **实例参考**：该EHS专员在巡检时发现过电工没带证、焊工让别人代班的情况。当场制止作业，要求电工回宿舍拿证拍照存档才让继续干活；焊工代班的直接通报班组长，要求该焊工本人回来才能作业。当天在台账备注栏记录，并在周例会上通报。

⚠️ **注意事项**
- 发现无证上岗**立即停止作业**，通报项目经理
- 无证上岗出了事故，EHS专员也要追责
- 对于流动性大的工人，入场一周内必须补齐证件

✅ **完成标志**
- 现场抽查人证一致率100%
- 无无证上岗情况
- 台账与现场人员一致
