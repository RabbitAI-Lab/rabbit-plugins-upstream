# 09-简历写作与面试 — 操作SOP

> EHS专员/安全员岗位的简历怎么写、面试怎么答。从该EHS专员某施工单位实战经验提炼。

---

## Step 1：简历写作要点

**📋 操作要点**

**EHS/安全员简历核心原则**：

```
1. 数字说话（不要写"负责安全管理"→ 写"管理300+隐患，闭环率100%"）
2. 法规意识（写"依据《安全生产法》建立隐患排查台账"比写"认真负责"有用）
3. 项目规模（写"管理人员30+人，劳务人员上百人"体现管理范围）
4. 证书优先（安全员C证放在最显眼位置）
```

**📄 简历模板（安全员/EHS专员方向）**：

```
姓名：XXX
电话：XXX
邮箱：XXX

【求职意向】EHS专员 / 安全员

【教育背景】
XX理工大学 安全工程 本科

【证书资质】
• 四川省住建厅安全员C证
• （消防设施操作员证，如有）

【工作经历】
XXX公司 | 安全管理员 | 2024.09-2025.11

核心职责：协助安全部长管理项目整体安全工作，涵盖现场
巡检排查、教育培训、资料编制、特种设备与人员管理、
应急管理等全流程。

主要成果：
• 累计排查并督促整改300+条登记隐患，500+处即改项
• 组织550+场安全培训/交底，覆盖1200+人次
• 维护8大类安全内业资料，编制800+份文件
• 经历15+次业主/公司/集团检查，通过率100%
• 负责范围内实现安全零事故

【项目经验】
某大型铁路项目（）— 安全管理员
项目规模：管理人员30余人，高峰期劳务上百人
• 制定每日巡检计划，日均排查50+个点位
• 负责4个劳务班组的安全管理
• 组织消防/防汛应急演练各1次，参演150+人次

【专业技能】
• 熟悉《安全生产法》《消防法》《职业病防治法》等核心法规
• 熟练使用WPS Office、CAD、OA管理系统
• 掌握隐患排查、三级教育、应急预案编制全流程
```

**⚠️ 注意事项**
- 数字一定要准确——面试时HR会问"你说的300条在哪里"
- 项目经验写具体结果（"零事故""100%通过"比写"认真负责"有用）
- 没有消防操作员证就先写上"正在考"

**✅ 完成标志**：简历写完，数字准确，一页纸

## Step 2：面试问答库

**📋 操作要点**

**高频问题与回答要点**：

**Q1：请做一下自我介绍（1分钟版）**
```
"我叫XXX，安全工程本科毕业，持有安全员C证。
此前在XX项目担任安全管理员，负责现场巡检、安全培训、
资料管理全流程。累计排查整改300多条隐患，
组织了550多场培训，实现了零事故。
我个人比较擅长隐患排查和资料体系建设。
"
```
**要点**：1分钟、数字、结果、不用背流水账

**Q2：你发现现场有工人不戴安全帽，怎么办？**
```
"三步走：
第一步，当场制止——走过去让工人把安全帽戴上，
同时拍照片留底。
第二步，告知班组长——让他知道本班组有工人违章了，
让他去加强管理。
第三步，记录到隐患排查台账——如果同一班组反复出现，
就要约谈班组长，甚至上报处罚。
总之——安全员在现场就是'看门'的，看见违章不制止，
等于没看见。
"
```
**要点**：制止→告知→记录→闭环，体现执行力

**Q3：如果有工人不配合整改怎么办？**
```
"首先——不配合时不能硬来（不能和工人打架）。
先找班组长沟通，告诉他这是你的安全责任。
如果班组长也不管，书面下发整改通知单。
如果下发后还不改，书面报告安全部长，
由部长去约谈施工队负责人或者扣款。
我经历过——大部分工人嘴上不配合，你站在旁边看着他，
他就配合了。
"
```
**要点**：循级上报、书面留痕、不激化矛盾

**Q4：你对安全生产法的了解？**
```
"《安全生产法》2021年修订版，2021年9月1日起施行。
核心变化：一是明确了三管三必须（管行业管安全、
管业务管安全、管生产经营管安全），
二是加大了处罚力度——事故罚款从2000万提高到1亿，
三是建立了双重预防机制（风险分级管控+隐患排查治理）。
日常工作中最常用的是第39条（安全设备维护保养）
和第41条（隐患排查治理）。
"
```
**要点**：说出具体条款、最新版本时间、实际应用场景

**Q5：你为什么从上一家公司离职？**
```
"在某大型铁路项目干了一年多，项目接近收尾阶段。
公司要调我去其他项目，距离比较远。
正好想回老家发展，所以就离职了。
之前积累的安全管理经验我希望能在家乡的企业继续做。
"
```
**要点**：正面（项目收尾/回老家）、不抱怨

**Q6：你对加班怎么看？**
```
"安全这个岗位——现场有活就有我的事。
工人早上6点上班，班前会就得5点半到。
晚上加班施工，我就得在现场盯着。
加班的觉悟我是有的，但前提是工作强度合理，
不是天天无效加班。
"
```
**要点**：体现"对这个岗位的认知"（知道安全员就是现场跟着走的工种）

**⚠️ 注意事项**
- 面试时带1份纸质简历+证书复印件
- 问期望薪资时：先问"贵司这个岗位的薪资范围是多少"再报自己的
- 该地区安全员薪资区间：3000-6000元/月，结合自己经验和证书要价

**✅ 完成标志**：面试题库已熟悉，能流畅回答Q1-Q6
