# 14-安全资料内业管理 — 操作SOP

> EHS专员安全内业资料归档管理的操作标准。从分类体系到编制标准到迎检自查，确保资料完整可查。

## Step 1：资料编制标准

📜 **法规依据**
- 《安全生产法》第41条：生产经营单位应当建立安全风险分级管控制度，按照安全风险分级采取相应的管控措施
- 《企业安全生产标准化基本规范》（GB/T 33000-2016）：企业应建立安全生产管理档案

📋 **操作要点**

**资料编制通用要求：**

| 要求 | 说明 |
|:----|:-----|
| **格式统一** | 同一类别资料使用统一模板，字体/字号/页边距一致 |
| **编号规范** | 统一编号规则（如：ZJ-2025-安全-001号） |
| **签字完整** | 编制人/审核人/审批人签字齐全，不可代签 |
| **日期准确** | 填写当天日期，**不要倒签** |
| **电子备份** | 所有纸质资料同步扫描存电子档 |

**常见资料问题清单（6类）：**

| 类别 | 常见问题 | 整改要求 |
|:----|:--------|:--------|
| 台账类 | 更新不及时、数据断层 | 每周至少更新1次，时间线连续 |
| 方案类 | 审批签字不全、过期未修订 | 使用前审批完成，每年评审1次 |
| 培训类 | 签到代签、未附照片 | 现场拍照+本人签名，不接受代签 |
| 整改类 | 无复查记录、照片缺失 | 整改前后对比照片必须留存 |
| 会议类 | 纪要未发出、跟踪事项不闭环 | 24小时内发出纪要，事项跟踪到闭 |
| 报表类 | 数据不准确、逻辑不一致 | 上报前双人核对 |

💡 **实例参考**：该EHS专员在某大型铁路项目时，建立了8大类资料分类体系。每份资料统一编号，编制人签完字找安全部长审核，重要资料还要项目经理审批。每次编制完自查一遍"常见问题清单"，确认签字齐全、日期正确、照片有说明。迎检时8大类资料装在8个文件夹里，标签清晰，检查组要什么1分钟内能拿出来。

⚠️ **注意事项**
- 资料**不要造假**，日期、签字、数据必须真实
- 签字**不接受代签**，出了事代签的人也要负责任
- 电子档和纸质档**同步更新**，不要各存各的
- 资料归档后不要随意修改，修改要有痕迹

✅ **完成标志**
- 资料格式统一、编号规范
- 签字完整、日期准确
- 电子档已备份

## Step 2：资料归档与存档

📋 **操作要点**

**归档方式：**

```
纸质版：
 按8大类分类 → 装入档案盒 → 盒脊标注类别+时间段
 → 按时间顺序排列 → 定期移交档案室

电子版：
 按8大类建文件夹 → 扫描件命名规则：日期-内容-编制人
 → 每月打包一次 → 本地+云端双备份
```

**档案盒标签格式：**

```
┌──────────────────────┐
│ XX工程有限公司      │
│ 安全管理档案      │
├──────────────────────┤
│ 类别：隐患排查档案   │
│ 期间：____年01-06月  │
│ 编号：YH-2026-001   │
│ 保管人：________   │
└──────────────────────┘
```

**电子档命名规则：**

```
YYYYMMDD-内容摘要-编制人
示例：20260601-月度安全分析报告-张XX.pdf
   20260520-隐患整改通知单（配电箱）-张XX.pdf
   20260515-三级安全教育记录（王XX等8人）-张XX.pdf
```

💡 **实例参考**：该EHS专员的做法是：每天填完台账、写完整改单后，当场扫描成PDF，按"日期-内容"命名存到"EHS资料库"文件夹。每月底把当月所有资料打包成"202X年X月安全资料汇总.rar"，存一份到本地电脑、一份到云盘。纸质版装盒归档。这样不管谁要什么资料，3分钟内能找出来。公司、集团、业主10+次检查全部一次性通过，资料方面从没出过问题。

⚠️ **注意事项**
- 纸质资料**防潮防虫**，不要堆在地上
- 电子档**至少双备份**（本地+云端）
- 归档后**设立借阅登记**，借出要签字
- 资料保管期限按法规要求执行（一般5-10年）

✅ **完成标志**
- 资料已按8大类分类归档
- 电子档已双备份
- 借阅登记制度已建立

## Step 3：迎检前资料自查

📋 **操作要点**

**迎检前资料自查清单：**

| 检查项 | 检查要点 | 结果 |
|:------|:--------|:----:|
| 隐患排查台账 | 时间线完整，闭环率100% | □ |
| 教育培训记录 | 签字完整，三级教育全覆盖 | □ |
| 设备档案 | 检验有效期在有效期内 | □ |
| 特种人员台账 | 证件有效期，人证对应 | □ |
| 应急预案 | 在有效期内，有演练记录 | □ |
| 安全会议纪要 | 频次正常，跟踪事项闭环 | □ |
| 整改通知单 | 整改前/后对比照片完整 | □ |
| 专项方案 | 审批签字齐全 | □ |

💡 **实例参考**：该EHS专员每次迎检前对着清单逐项自查，发现哪个方面有遗漏就抓紧补。最常发现的是培训记录签字不全、整改照片缺失这些"小问题"。建立自查习惯后，这些问题越来越少。

⚠️ **注意事项**
- 自查要**提前2-3天**做，不要把补资料的时间压缩到迎检前一天
- 发现遗漏**如实补记**，不要造假编日期

✅ **完成标志**
- 自检清单全部通过
- 发现问题已整改
