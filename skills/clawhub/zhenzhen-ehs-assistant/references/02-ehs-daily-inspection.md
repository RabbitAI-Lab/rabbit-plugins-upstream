# 02-EHS日常巡检 — 操作SOP

> EHS专员日/周/月巡检的操作标准和检查清单。按频次组织，每天该查什么都写在上面了。

---

## 先判断：你的巡检场景

| 场景 | 巡检频次 | 适合阶段 |
|:----|:--------|:--------|
| **现场有施工/生产活动** | 每日上下午各1次 | ⭐ 正常生产时 |
| **现场停工/停产** | 每天1次外围检查即可 | 停产期 |
| **有大型设备作业** | 每日+设备启动前专项检查 | 有吊装/大型机械时 |
| **季节性特殊风险** | 按季节调整频次（夏季防汛、冬季防火） | 6-9月/11-2月 |

> **经验**：该EHS专员在某大型铁路项目时每天走1.5小时全覆盖巡检，日均排查50个以上点位。

---

## Step 1：日巡检（每日必做，约1小时）

**📜 法规依据**
- 《安全生产法》第39条：安全设备应当经常性维护、保养
- 第41条：生产经营单位应当建立安全风险分级管控制度

**📋 操作要点**

**日巡检路线**（按区域走，不走回头路）：

```
入场口 → 施工区（各作业面）→ 材料堆放区 → 加工区 → 生活区 → 出口
```

**📄 日巡检检查清单（8大类50+点位）**：

| 检查类别 | 检查项 | 结果 |
|:--------|:------|:----:|
| **临时用电** | 配电箱门是否关闭上锁 | □ |
| | 电缆有无破损/拖地 | □ |
| | 漏电保护器是否有效 | □ |
| | 接地线是否连接 | □ |
| **高处作业** | 临边防护是否到位 | □ |
| | 安全带是否悬挂在可靠锚点 | □ |
| | 脚手架是否稳定（支撑+连墙件） | □ |
| | 作业平台有无跳板固定 | □ |
| **机械设备** | 操作人员是否持证 | □ |
| | 设备铭牌/检验合格标志是否有效 | □ |
| | 安全防护装置是否完好 | □ |
| **动火作业** | 有无动火审批 | □ |
| | 灭火器是否在作业现场 | □ |
| | 动火点周围有无易燃物 | □ |
| **消防设施** | 灭火器压力是否在绿区 | □ |
| | 疏散通道是否畅通 | □ |
| | 消防栓前有无堵塞 | □ |
| **文明施工** | 材料是否堆放整齐 | □ |
| | 垃圾是否及时清理 | □ |
| | 安全警示标识是否完好 | □ |
| **个人防护** | 工人是否佩戴安全帽 | □ |
| | 高处作业是否有安全带 | □ |
| | 特殊工种是否穿防护服 | □ |
| **生活区** | 宿舍用电有无私拉乱接 | □ |
| | 食堂卫生是否达标 | □ |
| | 消防通道是否畅通 | □ |

**💡 实例参考**：该EHS专员每天上下午各走1次巡检路线，上午重点是施工区域（检查作业面安全），下午重点是加工区+生活区（检查用电和消防）。发现配电箱门没锁、焊机电源线磨损这类问题几乎每天都有，当场让工人整改。带一本检查表边走边勾，当天登记到隐患排查台账。

**⚠️ 注意事项**
- 巡检不是走过场，**发现问题当场制止**（有隐患不停工就是你的责任）
- 带手机拍照，每条隐患留照片作为整改对比依据
- 工人在场时当面指出问题，不要背后写报告（现场教育效果好）

**✅ 完成标志**：当日巡检完成，填写了《日安全巡检记录表》

## Step 2：周/月专项检查

**📋 操作要点**

**周检重点**（每周五下午）：

| 检查项 | 检查方法 |
|:------|:--------|
| 特种设备运行状态 | 逐台核对设备运转记录 |
| 教育培训台账 | 检查本周培训记录是否完整 |
| 隐患整改复查 | 本周发现的隐患是否全部整改 |
| 配电系统专项 | 逐一试漏电保护器（每月1次） |

**月检重点**（每月底）：

| 检查项 | 说明 |
|:------|:-----|
| 隐患排查台账汇总 | 统计本月隐患总数、整改率、分类分布 |
| 应急物资盘点 | 灭火器/沙袋/应急灯等是否完好 |
| 安全资料完整度 | 教育/交底/检查/整改记录是否全部归档 |
| 下月风险预判 | 下月有什么高风险作业，提前准备 |

**📄 月度统计模板**：

```
本月隐患总数：XX条
 已整改：XX条（整改率XX%）
 未到期：XX条
 逾期未改：XX条

隐患类型分布：
 临时用电：XX条（XX%）
 高处作业：XX条（XX%）
 消防安全：XX条（XX%）
 机械设备：XX条（XX%）
 文明施工：XX条（XX%）
 其他：XX条（XX%）

主要问题分析：
 1. 焊机电线破损仍是最频繁问题（本月X起）
 2. 建议：将电缆防护纳入每日必查项
```

**💡 实例参考**：该EHS专员每月写安全隐患统计分析，发现临时用电问题占35%、高处作业占25%。根据这个数据向领导建议把临时用电作为下月专项检查重点，领导采纳了。

**⚠️ 注意事项**
- 周检/月检的**核心不是检查数量，而是趋势分析**
- 反复出现的同类隐患，说明不是工人问题，是制度问题——需要从管理上解决

**✅ 完成标志**：月度安全隐患统计分析报告完成
