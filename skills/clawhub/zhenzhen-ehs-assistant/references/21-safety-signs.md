# 21-安全标志与目视化 — 操作SOP

> EHS专员现场安全标志与目视化管理的操作标准。覆盖安全标志四大类、设置规范、现场目视化标准等。

---

## 先判断：你要设置什么标志

| 场景 | 需要的标志类型 | 目的 |
|:----|:-------------|:----|
| 禁止行为 | 禁止标志（红色圆圈斜杠） | 禁止吸烟/禁止通行/禁止烟火 |
| 风险警告 | 警告标志（黄色三角形） | 当心触电/当心坠落/当心吊物 |
| 强制行为 | 指令标志（蓝色圆形） | 必须戴安全帽/必须系安全带 |
| 安全信息 | 提示标志（绿色方形） | 安全通道/紧急出口/急救点 |

---

## Step 1：安全标志四大类

📜 **法规依据**
- 《安全标志及其使用导则》（GB 2894-2008）：安全标志的分类、设计、设置和使用要求
- 《安全色》（GB 2893-2008）：安全色的使用规范

📋 **操作要点**

**四大类标志：**

| 类别 | 颜色 | 形状 | 含义 | 示例 |
|:----|:----|:----|:----|:----|
| **禁止标志** | 红色+白底 | 圆形+斜杠 | 禁止做某事 | 禁止吸烟/禁止烟火 |
| **警告标志** | 黑+黄底 | 正三角形 | 提醒有危险 | 当心触电/当心坠落 |
| **指令标志** | 白+蓝底 | 圆形 | 必须做某事 | 必须戴安全帽/必须系安全带 |
| **提示标志** | 白+绿底 | 方形 | 提供安全信息 | 紧急出口/安全通道 |

---

## Step 2：标志设置规范

📋 **操作要点**

**设置位置要求：**

| 标志类型 | 推荐位置 | 设置高度 |
|:--------|:--------|:--------|
| 禁止标志 | 作业区入口/危险区域外围 | 1.5-2.0米 |
| 警告标志 | 危险区域前/设备上 | 1.5-2.0米 |
| 指令标志 | 作业区入口/劳保用品领取处 | 1.5-2.0米 |
| 提示标志 | 通道拐角/出口上方 | 1.5-2.0米（出口标志在门上方） |

**设置密度要求：**

| 场景 | 设置密度 |
|:----|:--------|
| 施工区入口 | 安全须知牌+禁止非施工人员进入+必须戴安全帽 |
| 配电箱 | 当心触电+禁止私拉乱接 |
| 高处作业区 | 必须系安全带+当心坠落+禁止抛物 |
| 吊装作业区 | 禁止入内+当心吊物+必须戴安全帽 |
| 仓库 | 禁止烟火+当心火灾+消防通道禁止堵塞 |
| 化学品存储区 | 禁止烟火+当心中毒+必须戴防护手套 |

**日常维护：**

| 维护项 | 频次 | 检查要点 |
|:------|:----|:--------|
| 外观检查 | 每月1次 | 是否褪色/破损/遮挡 |
| 清洁 | 每季度1次 | 清理灰尘/污垢 |
| 更换 | 发现时 | 褪色严重/破损/内容过时及时更换 |
| 增补 | 作业区变动时 | 新增风险区域及时补充标志 |

## Step 3：施工现场目视化标准

📋 **操作要点**

**目视化色标管理：**

| 颜色 | 用途 | 示例 |
|:----|:----|:----|
| 红色 | 禁止/危险/消防 | 消防管道/禁止区域/危险围挡 |
| 橙色 | 警示/危险设备 | 运动部件/机械设备危险区域 |
| 黄色 | 警告/注意 | 临时围挡/警戒线/注意安全 |
| 绿色 | 安全/允许/紧急 | 安全通道/急救点/紧急出口 |
| 蓝色 | 指令/要求 | 必须佩戴PPE区域 |
| 白色 | 通道/区域划分 | 人行通道线/物料区划线 |

**现场目视化要求：**

| 区域 | 目视化要求 |
|:----|:--------|
| 材料堆放区 | 划区域线，标识"XX材料堆放区"，堆高≤2米 |
| 渣土/垃圾区 | 划区域线，标识"垃圾堆放点"，定期清运 |
| 加工区 | 划区域线，设备操作规程上墙 |
| 安全通道 | 绿色划线，标识"安全通道"，保持畅通 |
| 消防通道 | 黄色网线+红色标识，严禁占用 |
| 危险区域 | 红色/黄色围挡+警告标志，非作业人员禁止进入 |

💡 **实例参考**：施工现场安全标志最容易被忽视的是"当心触电"和"禁止抛物"这两类。该EHS专员在巡检时看到配电箱上的"当心触电"标志被灰尘遮住了、或者被材料挡住了，当场清理遮挡物。每个月检查一次标志完好情况，破损褪色的及时更换。

⚠️ **注意事项**
- 安全标志**不是摆样子**，要设置在真正有风险的位置
- 标志**不能被遮挡**，周围不能堆放材料
- 同一区域有多类标志时，按"禁止→警告→指令→提示"顺序排列
- 标志内容要与实际风险一致，不要"有标无险"或"有险无标"

✅ **完成标志**
- 所有风险区域标志覆盖到位
- 标志设置位置/高度/密度符合规范
- 标志完好无损，内容清晰
- 现场目视化划线清晰

- [ ] 标志类型正确（禁止/警告/指令/提示）
- [ ] 标志无破损/褪色/遮挡
- [ ] 现场目视化划线清晰
- [ ] 安全通道畅通
- [ ] 消防通道无堵塞
