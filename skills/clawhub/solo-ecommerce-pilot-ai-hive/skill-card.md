## Description:

Helps solo ecommerce operators turn product facts, budget, platform, available assets, and weekly goals into prioritized tasks, daily content plans, low-cost media plans, AI-HIVE generation commands, and review checklists.

This skill is ready for commercial/non-commercial use.

## Use Case:

External solo sellers, small ecommerce teams, independent store operators, and side-business founders use this skill to plan and execute ecommerce content workflows. It produces business goal breakdowns, content strategy, media-generation tasks, platform variants, executable commands, and acceptance checks before any potentially billable generation call.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: AI-HIVE media generation may incur charges when users submit image or video generation jobs.

Mitigation: Review prompts, routing mode, batch size, model choice, and pricing before generation, and start with a small sample before batch work.

Risk: The init flow can store an AI-HIVE API key locally.

Mitigation: Use environment variables when possible, keep local config files private, and never paste real API keys into prompts, logs, screenshots, or committed files.

Risk: User-selected uploads may include materials the user is not authorized to use.

Mitigation: Upload only files the user has rights to use, and use abstract structure guidance instead of close copying when authorization is unclear.

Risk: Generated ecommerce claims, prices, availability, or performance expectations can be inaccurate or misleading.

Mitigation: Validate factual claims against source materials and avoid guarantees about sales, rankings, platform approval, traffic, or return on investment.
