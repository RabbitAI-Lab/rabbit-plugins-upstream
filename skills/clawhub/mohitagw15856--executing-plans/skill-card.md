## Description:

Execute a written plan with discipline — verify each step before advancing, surface deviations instead of improvising around them, and keep a visible execution log.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users, developers, and agents use this skill to execute written plans step by step, run and log per-step verification, classify deviations, and produce plan feedback at completion.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A written plan may include destructive commands, account changes, or other high-impact actions.

Mitigation: Review the plan before execution and treat stop conditions and deviations as visible decisions before proceeding.

Risk: Skipping verification can let earlier step failures affect later work.

Mitigation: Run and record each step's verification outcome before advancing.
