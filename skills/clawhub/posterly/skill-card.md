## Description:

Helps agents draft, validate, schedule, and publish social posts across connected platforms through Posterly MCP.

This skill is ready for commercial/non-commercial use.

## Publisher:

[awpthorp](https://clawhub.ai/user/awpthorp)

### License/Terms of Use:

MIT-0

## Use Case:

Social media managers and teams use this skill to review connected accounts, validate drafts, and schedule or publish posts with explicit approval.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Approved actions can publish, delete, or moderate content and affect billing or API settings.

Mitigation: Confirm the exact account, content, schedule, and action with the user before any write.

Risk: The API key grants access to connected social accounts.

Mitigation: Protect the API key and use the integration only if you trust Posterly with those accounts.
