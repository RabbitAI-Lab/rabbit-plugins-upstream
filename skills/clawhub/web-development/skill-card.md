## Description:

Guides agents through implementing, debugging, building, deploying, and validating web frontends, especially React, Vue, Vite, browser flows, and CloudBase Web integration.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers and engineers use this skill to build and troubleshoot web frontends after the design direction is set, check browser behavior, and integrate or deploy with CloudBase when needed.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Protected-route examples may accept unverified tokens and expose data.

Mitigation: Do not copy the examples as-is; validate tokens on the server and use safer session handling, such as server-issued HttpOnly, Secure, SameSite cookies or a documented CloudBase verification backend.

Risk: Deployment or hosting changes may affect a live site.

Mitigation: Get user approval before changes and keep a reversible deployment plan.
