## Known Risks and Mitigations:

Risk: Authentication examples may lead to client-readable access tokens or incomplete login protection.

Mitigation: Use real server-side token validation and HttpOnly, Secure, SameSite session cookies before adapting authentication guidance for production.

Risk: Generated frontend changes can affect routing, forms, auth flows, build output, or deployment behavior.

Mitigation: Run type checks, linting, builds, and browser-level validation for affected routes and interactions before release.
