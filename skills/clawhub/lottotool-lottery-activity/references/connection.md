# 连接抽奖工具 MCP

仅在用户需要真实操作且连接缺失时使用本参考。草稿整理不依赖连接；用户已授权的配置保留在当前任务中。查询需要 `lottery:read`，创建需要 `lottery:write`，导出需要 `lottery:export`；旧连接缺少导出范围时通过宿主重新授权。

优先使用宿主实际提供的连接/授权入口。用户要求安装或修复连接时，可在已授权范围内完成配置；不要仅因文件可写就修改 MCP 配置，也不要虚构安装工具或要求粘贴 token。

若需要手工配置，先确认宿主支持的格式及配置位置，再读取和合并必要部分。连接器模板见 [connectors/default/mcp.json](../connectors/default/mcp.json)，它用于 WorkBuddy；不能假定所有宿主都读取 `mcp.json` 或 `.mcp.json`。只修改抽奖工具条目，保留其他连接器，不输出已有配置中的凭证。

用户可提供给支持该安装方式的客户端：

```text
帮我安装抽奖工具 MCP：
服务地址：https://api.52choujiang.cn/lotto/mcp/v1
认证方式：OAuth
用途：预览和创建抽奖活动，查询本人活动及数据，导出本人活动的参与人、中奖人和兑奖表单。
```

授权由用户在宿主界面完成。对提供该界面的 WorkBuddy，提示进入连接器管理、信任自定义连接器，再微信扫码允许连接；其他宿主使用其实际入口。完成后重新检查工具可用性，接着处理原任务。

若宿主不支持安装或授权，说明所缺能力；查询和导出不可用时不能编造活动、数据或文件。仅用户需要手工配置时展示模板。连续相同连接错误且没有新信息时停止重试。
