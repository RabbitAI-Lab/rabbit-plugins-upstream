## Description:

Helps developers plan software implementations and optionally preserve decisions and next steps in local planning files.

This skill is ready for commercial/non-commercial use.

## Publisher:

[iliaal](https://clawhub.ai/user/iliaal)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to break software work into verifiable phases, record unresolved decisions, and maintain recovery state for multi-phase implementation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: An unfinished local plan may be mistaken for the current task or displaced by new planning work.

Mitigation: Review an existing .plan/task_plan.md before starting unrelated work and resolve which plan to continue before replacing it.
