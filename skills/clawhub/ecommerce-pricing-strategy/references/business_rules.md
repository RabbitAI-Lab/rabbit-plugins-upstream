# 业务规则 - ecommerce-pricing-strategy

> 电商定价策略生成器，输出定价模型选择、利润优化方案、大促定价公式、多平台差异化定价。

## 规则列表

### 四大定价模型 (来源: 01手册§十二A16)

- 成本加成法: 售价 = 成本 × (1 + 加成率)，适用标准品/有明确成本
- 竞争导向法: 售价 = 竞品均价 × (1±浮动%)，适用竞品明确的红海市场
- 价值定价法: 售价 = 客户感知价值 × 折扣，适用品牌品/差异化产品
- 渗透定价法: 售价 = 成本 × (1 + 微利率)，适用新品抢占市场

### 加成率参考 (来源: 01手册§十二A16)

- 虚拟商品(充值/会员): 50-200%，成本极低主要时间成本
- 数码3C: 10-25%，价格透明竞争激烈
- 服饰鞋包: 40-80%，季节性强库存风险
- 美妆护肤: 50-100%，品牌溢价高
- 食品生鲜: 20-40%，毛利低走量为主
- 家居日用: 30-60%，中等毛利

### 毛利率目标 (来源: 01手册§十二A16)

- 健康毛利率: ≥30%
- 警戒毛利率: 20-30%(需优化)
- 危险毛利率: <20%(需提价或降本)
- 暴利毛利率: >80%(检查是否虚高)
- 毛利率公式: (售价-成本) / 售价 × 100%

### 动态调价策略 (来源: 01手册§十二A16)

- 库存维度: 库存>安全库存×2→降价10-15% / 库存<安全库存→涨价5-10%
- 销量维度: 近7天销量环比下降>30%→降价5-10% / 上升>50%→涨价3-8%
- 竞品维度: 竞品降价>10%→跟进降价 / 竞品涨价→观察后跟进

### 捆绑销售策略 (来源: 01手册§十二A16)

- 买A送B: 套餐价 = A价 / (A+B)成本比，适用关联品/清库存
- A+B套餐: 套餐价 = (A+B) × 0.85，适用提升客单价
- 阶梯满减: 满100减10/满200减30/满500减80，适用刺激凑单
- 第二件半价: 均价 = (首件+半件) / 2 = 0.75首件，适用快速走量

### 满减策略设计 (来源: 01手册§十二A16)

- 门槛设计: 满减门槛 = 平均客单价 × 1.3-1.5(刺激凑单)
- 力度设计: 满减力度 = 门槛金额 × 10-15%(吸引力足够)
- 层级设计: 2-3级满减(如满99减10/满199减30/满299减60)

### 大促定价公式 (来源: 01手册§十二A16)

- 到手价 = 原价 × 折扣率 - 平台券 - 店铺券 - 补贴
- 折扣率: 618/双11常规5-8折 / 秒杀3-5折
- 平台券: 跨店满减(如满300减50)
- 预售定金: 预售价 × 10-20%，定金翻倍抵扣(如10元定金抵20元)
- 预售优惠: 预售价 < 正式价(低5-15%)
- 价保周期: 大促期间15-30天，价保成本预估2-5%订单需退差

### 多平台定价矩阵 (来源: 01手册§十二A16)

- 闲鱼: 成本×1.1-1.3，低价引流/清库存/测款
- 抖音: 成本×1.5-2.5，GPM优化/内容带货
- 淘宝: 成本×1.8-3.0，搜索权重/稳定销售
- 拼多多: 成本×1.2-1.6，拼团价/社交裂变
- 京东: 成本×2.0-3.5，品质溢价/PLUS会员
- 快手: 成本×1.3-2.0，性价比/老铁经济

### 多平台定价注意事项

- 最低价管控: 避免某平台价格过低影响其他平台(建议最低价差≤15%)
- 平台佣金差异: 淘宝3-5% / 拼多多0.6% / 抖音5%

### 数据指标

- 转化率健康值: ≥3%，公式: 订单数 / 访客数 × 100%
- 利润率健康值: ≥15%，公式: (营收-成本-费用) / 营收 × 100%
- 价格弹性: 销量变化率 / 价格变化率
