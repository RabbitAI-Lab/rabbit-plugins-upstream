## Use Case:

Creators and developers use this skill to create and refine images, short videos, and music with Gemini-powered tools.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected images, video, audio, or clipboard content may be sent to Gemini or hosted storage.

Mitigation: Share only intended content; avoid sensitive media unless its transmission is approved.

Risk: Local file inputs and deletions may affect files or expose their contents.

Mitigation: Review local file confirmation settings and approve the preview before sending files or deleting uploads.

Risk: Installing the MCP package and supplying a Gemini API key grants the server access to that credential.

Mitigation: Install only if comfortable granting this access, and consider pinning or auditing the npm package.
