## Known Risks and Mitigations: <br>
Risk: Local files, clipboard images, and uploaded media may contain private or sensitive content. <br>
Mitigation: Use the skill only with media suitable for Gemini processing or temporary Files API upload, confirm clipboard contents before using clipboard input, and delete uploaded files when early removal is needed. <br>
