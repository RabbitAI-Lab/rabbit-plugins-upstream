### 4.3 典型布局模式

```
┌──────────────┬──────────────────────┬──────────────┐
│   左面板     │      中央主视图        │   右面板      │
```

- 中央区域展示核心数据/地图/主图表
- 左右侧面板用辅助信息，宽度约 25% each
- 顶部通常为标题栏 + 时间/状态栏

### 8.3 性能建议
