# 自进化协议：让本 skill 越用越厚

> SKILL.md Phase 6 的展开。本 skill 不是一次性教程——**每接入一个系统，就把那个系统的使用说明回写进来**。下次（哪怕换个会话）再碰同一系统，agent 直接读注册表，不用重新勘察。

## 为什么

- 勘察有成本：API 面、状态枚举、签名算法、坑，都是花时间摸出来的。不沉淀 = 下次从零再来。
- 使用说明散在聊天记录/README 各处 = 等于没沉淀。集中到注册表，一处查全。
- 注册表本身就是「这个工作台接入了哪些系统」的账本。

## 回写时机（触发器）

| 时机 | 动作 |
|------|------|
| 一个系统的 CLI **首次交付并通过验收** | 新建 `registry/<system>.md` + 更新 SKILL.md 索引 |
| 已接入系统的 CLI **新增/修改命令** | 合并更新对应条目（保留历史坑，新增新坑） |
| 使用中 **踩了新坑 / 发现接口语义误读** | 立即追加到条目的「已知坑」节（不等大版本） |
| 系统改版导致 **枚举/接口变化** | 更新条目并在条目顶部记变更日期 |
| 用户要求「沉淀使用说明 / 更新注册表 / 自进化」 | 按本协议执行最近完成的 CLI |

## registry/<system>.md 条目结构（模板见 [../registry/_template.md](../registry/_template.md)）

1. **系统档案**：名称、入口 URL、认证方式（怎么拿 token、缓存位置、有效期）
2. **命令索引**：每条命令一行「什么时候用」+ 可直接抄的示例
3. **状态机/枚举表**：从前端源码核对过的映射 + 常见误读提醒
4. **写操作清单**：哪些命令走守卫、不可逆项标注
5. **已知坑**：踩过的全记，带日期（过时的坑标注「已失效」不删，避免再踩）
6. **实战记录**：每次批量操作的数字复盘（如「12 条待处理 → 9 处理 3 打回」）
7. **关联文件**：CLI 代码位置（`cli/<system>/`）、对应 agent skill 位置
8. **API 速查**：勘察摸清的端点/方法/关键字段/签名算法位置（见模板）
9. **跨系统关联**：与其他系统的 ID/URL 映射 + 联动命令示例
10. **产物落地规范**：批处理输出目录结构、`--outdir` 约束

## 可沉淀资产的三种类型（别只沉淀使用说明）

| 类型 | 例子 | 放哪 |
|------|------|------|
| **使用说明** | 命令索引、认证、坑 | `registry/<system>.md` |
| **判定标准** | 定级矩阵、金额档位、模板结构 | `references/<system>-*.md`，条目里只留链接 |
| **API 速查** | 端点表、字段表、签名算法 | registry 条目的「API 速查」节 |

**判定标准会过期，按周期命名**：标准随时间演进时，新文件带周期标识（如 `rating-standard-9月.md`），旧版保留不删（历史决策要能对上当时的标准）；条目里写清「当前生效版本」指向哪个文件。

## 渐进描述原则（信息分层，别把 SKILL.md 撑爆）

```
SKILL.md            # 只留索引：每系统一行（系统名 | 一句话 | 条目链接 | 状态）
registry/<system>.md # 常用层：命令索引 + 认证 + 坑（目标 ≤ 200 行）
references/*.md      # 深层：方法论、协议、长篇复盘（条目里只放链接）
```

- 条目超过 ~200 行时，把长内容（大段复盘、完整枚举推导过程）拆到 `references/<system>-*.md`，条目里留摘要 + 链接。
- SKILL.md 的索引表永远只有 N 行（N = 接入系统数），读入口零负担。

## 脚本组织约定（与注册表对应）

```
<工作区>/cli/
├── _guard/                  # 全局守卫客户端（全机共享一份；绝不在各系统目录里复制）
├── <system>/                # 与 registry/<system>.md 一一对应
└── README.md                # 索引：系统 → 目录 → 注册表条目
```

- 守卫客户端升级（如新增 result_channel 字段）只改 `_guard/` 一处，所有 CLI 下次运行自动生效。
- 某系统废弃：条目标「已停用」+ 日期，不删（历史坑仍有价值）；脚本目录移到 `cli/_archived/`。

## 回写质量自检

- [ ] 新会话里只读 registry 条目，能否直接用起这个系统的 CLI？（不能 = 条目缺关键信息）
- [ ] 每条命令有「什么时候用」注释？
- [ ] 写操作清单与守卫拦截范围一致？
- [ ] 已知坑带日期？
- [ ] SKILL.md 索引已更新？
