## Description:

Helps agents find hotels, restaurants, and attractions and retrieve TripAdvisor ratings, reviews, photos, and nearby places.

This skill is ready for commercial/non-commercial use.

## Use Case:

Travelers and travel-planning assistants use this skill to discover places and compare TripAdvisor listings, ratings, reviews, and photos.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The optional Terra integration sends an API key to a third-party MCP server for requests.

Mitigation: Confirm you trust the @chrischall/tripadvisor-mcp package before installing it or supplying a Terra API key.
