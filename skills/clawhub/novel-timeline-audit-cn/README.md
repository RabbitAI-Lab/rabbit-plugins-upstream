# 小说时间线约束核对

把小说的章节或场景事件与已有时间依据交给本 Skill，即可核对事件时间约束，并得到可追溯的故事时间排序与冲突证据。它只审时间线，不评分、续写或重规划全书。

## 你将得到什么

适合检查章节改稿、人物年龄衔接和跨城行程是否自洽：输出按故事时间排列的事件表，标出时序、年龄与行程冲突的位置和算式，并给出最小修订选项。

## 需要提供什么

**输入：** 最多 20 个场景或 100 条事件，包含章节/场景编号，以及已知日期、时刻、先后关系、年龄、行程时长和闪回标记。

**结果：** 按故事时间排列的事件表、时序/年龄/行程冲突位置与算式、最小修订选项；没有时间或顺序依据的内容会明确列为缺项或“未定”，绝不按章节号伪造日期。

## 能力与用法

它会按明确时间和 `after` 关系排序事件，核对行程间隔与年龄变化，并保留闪回。提供事件清单和已有时间依据即可开始；时间不完整时会列出缺项，不会替你补日期。

## 使用方法

提供按场景列出的事件及已知时间、顺序和行程分钟数，调用 Skill 后查看排序表、冲突和需补充的依据；也可以把 JSON 保存后运行 `python3 scripts/audit_timeline.py input.json`。

![小说时间线约束核对推广图](assets/promo-1600x900.png)

## 输入与结果

输入为最多 20 个场景或 100 条事件，可包含章节/场景编号、`HH:MM`、完整日期时间或 `{"after":"E1","minutes":30}` 相对时间对象、行程分钟数和 `flashback: true`。结果包括按可比较故事时间排列的事件表、冲突位置和算式、最小修订选项，以及缺项与“未定”区间。没有时间或顺序依据时不会用章节号伪造日期。

安装：

```bash
npx skills add xxjrq/novel-timeline-audit-cn
```

本仓库附带可复制的 [成功输入](fixtures/success-input.json) 与 [对应交付](fixtures/success-delivery.md)，以及 [缺料输入](fixtures/failure-input.json) 与 [缺料交付](fixtures/failure-delivery.md)。成功样例会识别 A 地到 B 地的明确时刻仅间隔 30 分钟而资料要求 120 分钟，指出必须复核一个时刻或有来源地更正时长；同时保留明确闪回。缺料样例只请求补充依据。

## 本地运行

无需第三方依赖：

```bash
python3 scripts/audit_timeline.py fixtures/success-input.json
python3 scripts/self_test.py
```

此 Skill 只审事件时间约束，不评分、续写或重规划小说。复杂日期、年龄和多段行程应以输出的原始证据为依据人工复核。
