# 🌐 GEO 品牌诊断

诊断品牌在**豆包 / 元宝 / 通义千问**三大 AI 平台上的推荐覆盖情况，生成诊断报告。

---

## 使用方法

```
node scripts/collect.js <品牌> <行业> <城市> [场景数]

参数：
  品牌      必填，要诊断的品牌名
  行业      必填，餐饮|装修|智能家居|医疗|科技|酒店|教育|旅游
  城市      必填，品牌所在城市
  场景数    选填，默认5个问题，最多10个

示例：
  node scripts/collect.js 漳州客家宴 餐饮 漳州 5
  node scripts/collect.js 牙博士口腔 医疗 漳州 5
  node scripts/collect.js 三星装饰 装修 漳州 7
```

---

## 工作流程

### 首次运行（需要登录一次）

```
1. 脚本自动打开 Chrome 浏览器 + 3个平台标签页
2. 用户在浏览器中手动登录各平台（只需一次）
   - 🫘 豆包：https://www.doubao.com
   - 💎 元宝：https://yuanbao.tencent.com
   - 🌤️ 通义千问：https://tongyi.aliyun.com
3. 登录后在此终端按 Enter
4. 脚本全自动采集 → 生成诊断报告
```

### 后续运行（自动复用登录态）

```
node scripts/collect.js <品牌> <行业> <城市> [场景数]
→ 直接开始采集，无需手动登录
```

## 诊断指标说明

| 状态 | 含义 |
|------|------|
| ✅ 推荐 | AI 回复中明确推荐了品牌 |
| ⚠️ 模糊 | 回复中提及品牌但无明确推荐 |
| ❌ 未推 | 回复中完全没有提及品牌 |

覆盖率 = ✅推荐数 / 总场景数

---

## 诊断维度

1. **通用搜索覆盖**：用户搜索"城市+行业"类问题时品牌是否出现
2. **品牌词搜索**：用户直接搜索品牌名时是否获得推荐
3. **竞品对比**：品牌与竞品的比较中是否占优

---

## 优化建议参考

根据覆盖率评级给出建议：

- **0-20%**：紧急优化，AI 平台完全被竞品占据
- **21-40%**：亟需优化，多数场景缺失
- **41-60%**：中等优化，部分核心场景已覆盖
- **61-80%**：良好，保持优化
- **81-100%**：优秀，维持监控
