## Description:

Reviews concept and application designs for purpose fitness, independence, composition, product subsets, and implementation drift when code is available.

This skill is ready for commercial/non-commercial use.

## Publisher:

[agenticweb4](https://clawhub.ai/user/agenticweb4)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and architects use this read-only review to test whether concept and application designs fulfill their purposes and, when code is available, whether the implementation follows confirmed specifications. Findings identify evidence, coverage gaps, severity, and suggested fix routes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Incomplete specifications or missing code can make design and drift conclusions unreliable.

Mitigation: Mark unsupported conclusions unverified and limit implementation findings to inspected code and confirmed contracts.
