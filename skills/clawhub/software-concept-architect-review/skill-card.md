## Description:

Reviews concept and application designs for purpose fitness, independence, composition, and product-subset gaps, and checks code for drift when available.

This skill is ready for commercial/non-commercial use.

## Publisher:

[agenticweb4](https://clawhub.ai/user/agenticweb4)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and architects use this read-only skill to audit concept and application specifications, identify design gaps, and compare implementation against confirmed contracts when code is available.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The review may expose sensitive project specifications or code to the agent.

Mitigation: Provide only materials approved for review and limit access to the relevant project scope.

Risk: Incomplete project evidence can lead to misleading design or drift findings.

Mitigation: Verify findings against current specifications and code; treat unsupported conclusions as unverified.
