# open-semantic-scholar

A lightweight Brave browser skill for **Semantic Scholar**.

## What it does

Open Semantic Scholar in Brave for academic research and paper discovery.

- Reuses an existing relevant tab/session
- Avoids unnecessary duplicate tabs
- Verifies the destination
- Never handles credentials

## Example triggers

- Open Semantic Scholar
- Take me to Semantic Scholar
