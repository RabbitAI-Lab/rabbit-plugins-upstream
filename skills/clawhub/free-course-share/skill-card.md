## Description:

Verify whether a course is truly free, screen or compare free courses, build a shortlist, or draft accurate share copy. Use when the user requests any one of these free-course tasks; combine them only when requested.

This skill is ready for commercial/non-commercial use.

## Publisher:

[bonniegeng-max](https://clawhub.ai/user/bonniegeng-max)

### License/Terms of Use:

MIT

## Use Case:

Learners and creators use this skill to verify whether course access and certificates are free, find or compare suitable options, and prepare evidence-based sharing copy. It supports Chinese and English requests and keeps public research read-only.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Course prices, access terms, and certificate costs can change or vary by region, which may make a course summary outdated.

Mitigation: Check current official course pages, distinguish free access from certificate costs, and include the verification date and any unresolved restrictions.

Risk: Searches use public web services, so sensitive details included in a query could be exposed to those services.

Mitigation: Use course titles and other public details for searches; keep private or account-specific information out of queries.

Risk: Sharing copy could repeat an inaccurate or incomplete course claim if it is published without review.

Mitigation: Review the source links, free-access scope, restrictions, and evidence labels before using the draft.
