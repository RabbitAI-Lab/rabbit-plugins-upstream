## Description:

Demonstrates the end-to-end collaboration between a business process workflow and the ClawHub CLI, from preparing a publishable artifact to ingesting it into the ClawHub resource center.

This skill is for demonstration purposes and not for production usage.

## Use Case:

Developers and skill authors use this demo to follow a repeatable pattern for preparing, validating, and publishing a ClawHub-skill-shaped asset.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Publishing an unintended folder could make unwanted asset contents discoverable through ClawHub.

Mitigation: Review the folder contents, run the ClawHub dry-run command first, and publish only assets intended for discovery.
