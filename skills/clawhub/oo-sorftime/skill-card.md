## Description:

Sorftime helps agents query Sorftime ecommerce research data for Amazon and Walmart US through OOMOL's oo CLI connector.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External users and developers use this skill to search Sorftime data, retrieve keyword and product metrics, review Amazon and Walmart US category trends, and inspect Sorftime account usage through connected OOMOL credentials.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: First-time setup includes unverified remote installer commands that can execute changing code on the user's machine.

Mitigation: Review the oo CLI installation path before installing and prefer an official package, pinned release, or checksum/signature-verified installer.
