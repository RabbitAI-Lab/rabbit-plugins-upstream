# 数据质量闸门与证据规范

## 闸门

| 状态 | 可交付内容 | 禁止内容 |
|---|---|---|
| PASS | 经营归因、方案、行动和图表化报告 | 无证据的因果断言 |
| WARN | 带限制的分析和方案 | 把受影响指标写成确定事实 |
| BLOCKED | 数据质量报告、已确认事实、补数清单 | 利润结论、预算承诺、增长承诺 |

## 证据层级

平台官方后台原始导出 > 规范化数据文件 > 截图 > 人工转述。每条核心结论带来源、期间、口径、证据 ID 和置信度；相关性不足以单独证明因果。

## 交付前检查

- 当前客户和文件范围唯一；重复导出已排除并记录原因。
- GMV、退款、SKU、流量来源等可相互对账，差额和无法对账项明示。
- 任何缺失成本、毛利、退款或库存都不填默认值。
- 闸门、禁止结论和待补数据同步出现在 PDF 与 Markdown 中。
