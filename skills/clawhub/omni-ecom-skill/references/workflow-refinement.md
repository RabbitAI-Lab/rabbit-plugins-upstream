# 当前流程修整

维护批次 20261014-r2（专家团仍为 v2.0.3）：恢复任务卡最后一次装配时遗漏的按需读取规则；六题同时核对原编号和问题原文；相同或缺失发现编号不再导致 PDF 漏项；完整保留长反证、验收、停止和补数条件。长行动允许跨页，正文长度纳入页数闸门。前部摘要和窄表导航可以节选，完整正文不按字数截断。

回执成功输出机械装配的短消息参数，岗位与复核员原样发送，不重复长贡献或全文；这不更改任何独立判断或回执正文。无客户机制事实因混写结构数字和经营字段名而被拦时，finish_command 返回准确字段、原文节选和本人未封存文件的位置，提示保留数字证据登记并修正机制表述；仍需本人核查和重跑原检查，程序不自动改答案或放行。

周报可接入用户明确提供的上期反馈：build_report_package.py --previous-action-review 本次反馈.json。原文件须保留在本次运行目录；文件包含本次 run_id/client_scope/team_version、previous_period、provided_by 和 actions（每项 action_id、status、feedback）；status 使用 reported_done/in_progress/not_done/unknown。来源文件指纹进入报告、PDF、独立复核冻结清单和构建复用检查；改写反馈、伪造投影或跨客户引用均阻断。reported_done 只呈现“反馈已做（未独立验收）”，不自动变成验收通过；未提供仍明确列缺口。反馈中的经营数字仍须过数字来源闸门，不能借反馈编造效果。

完整扫描授权报表，形成共有口径和来源索引；任务卡把全量紧凑索引与本岗章节分开，原始资料保留可定位引用。紧凑视图的导航字段不属于原件，原件字段或状态须直接查原件。常规抽取、格式和指纹由程序执行，未知字段才由专家核实。本次新增复用仅针对输入和产物指纹、客户、期间、公式及程序版本完全一致的报告构建；结束前的来源复核仍保留。

四位分析专家真实并发。卡片列出六个固定问题 ID，亲自填写 expert_analysis_template 后执行 finish_command；程序装配固定身份，不预填事实、答案和通过状态。机制验收的六题只用于无客户测试，不能用于业务任务。存在缺口时有依据的 BLOCKED 降级可以完成核查，不能删题或把缺费用补零。

岗位通用规则见 expert-working-contract.md，岗位卡仅保留独有职责。原生派工用 launch-manifest 的 dispatch_parameters（含真实 team_name）和逐字 launch_prompt；Codex 仍用自己的真实子代理工具。简短回传指向完整分析文件，不在聊天中复述全文。

报告先展示经营摘要、任务重点、核心指标和图表，完整报表覆盖、数字来源及真实岗位记录进入同一 PDF 附录。facts/judgments/hypotheses/actions 全量保留；发现的 chapter_ids 决定实际章节，未明确绑定的发现进入跨章节汇总，不伪造章节关系。周报列明上期执行反馈是否提供；月报关注结构和资源，诊断关注短板和改善路径，年报与大促采用自身任务重点及可比口径。

相同报告输入及全部产物指纹一致时，构建入口复用原产物，不变更生成时间、不重新排版。来源、口径、专家交接、裁决、模板或程序变更都会失效。冻结稿不可原地重建，修正稿使用新修订目录并重新冻结/真实复核；构建复用没有正式交付权限。

普通报告与验收共用复核格式和导航。复核员亲自写精简复核分析，程序装配真实结果及指纹。必须核对所有相关材料、数字来源、独立专家与最终 PDF 每页，不把程序的一致性结果当作独立放行。排版修正只回到报告构建与复核，业务或来源改变才返回受影响分析环节及其下游；已成功岗位不全团重派。

真实复核返回 conditional_pass/rejected 或必改项时，由团长正常登记 start/accept；host_runtime 保留真实 completed 观测并登记 member_rejected，而非伪标宿主失败。仅报告呈现有误、四岗分析仍有效时，用 prepare_report_revision.py --run-dir 原目录 --revision R2 生成同一运行的延续目录；原 R1 保持冻结历史，原四专家及来源逐文件验指纹，不重派。旧目录有 successor 标记后不能再写账本，R2 是唯一当前目录。重新生成 R2、冻结新清单并真实独立复核；不能继承旧批准，不能修改原分析。该入口不处理已正式完成报告或业务来源变化。

耗时和 token 使用真实宿主日志衡量，分清累计输入、缓存输入、输出及未知用量，不推算未核实的费用。单次无客户验收与真实经营任务分别说明，不从任务卡字符数推导周报提速百分比。
