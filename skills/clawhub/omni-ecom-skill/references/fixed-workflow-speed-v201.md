# v2.0.3 固定流程提速

适用店铺诊断、周报、月报、年报、大促复盘和专题分析；不改变用户选择的模型，不需要平台 API。

## 本次改变

- 同一轮数字复算共用短期读表结果，避免同一张表为每个指标反复打开。数字、单位、期间、平台和店铺检查仍全部执行；结束前重新核对原文件指纹。每轮重新读取，不把上次结果当成本次凭证；跨文件共用内存上限，超限退回流式读取。
- 团长说明集中保留工作顺序与不可省略规则，专项规则按实际问题读取。四分析专家与独立复核均保留，不能用总监代替岗位回传。
- 岗位任务卡集中提供身份、实际来源指纹、共享资料和固定格式。`finish_agent_handoff.py` 一次执行输入检查、交接格式/分析深度校验和唯一正式回传。失败仍阻断；已回传不覆盖。Windows 中文输出与子进程统一 UTF-8。
- 复核任务卡给出默认 rejected 的空白结果格式。`check_review_inputs.py` 批量核对冻结输入，但没有复核决定或完成权限，真实复核员仍须独立判断、逐页看 PDF。
- `runtime_timing.py` 从真实宿主轨迹读取耗时、工具次数和文件指纹；计时记录不是完成凭证，也不修改报告或客户数据。

## 不允许以提速为由省略

完整授权资料清单与归类、口径锁定和数字复算、当前四位专家独立回传、必要的交叉检验与冲突裁决、默认图表 PDF、冻结后真实独立复核、公域检查、最终完成检查。

缺推广成本时不能填写花费、ROI 或利润；缺数不能补为零。候选流水线通过不等于正式经营报告交付。无客户验收稿须明确标注固定测试值、机制与经营范围，来源指标图不能被过程状态图替代。

## 如何判断实际效果

分开记录读表复算、专家分析、等待、复核与 PDF 生成。只比较同一模型选择、相近资料范围和同等质量要求下的真实新任务；单次测试不承诺所有周报能减少相同比例的时间。失败、修复和恢复运行不能包装成一次无错误的速度测试。

模型选择、网络/排队和资料复杂程度仍会影响总用时。本补丁只减少固定步骤重复读取、格式探索及回传往返，不降低分析深度。
