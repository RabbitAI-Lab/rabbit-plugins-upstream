# 版本更新

## v2.0.3（维护批次 20261014-r2，ClawHub 分发 2026-10-15）

从本条目的 v1.5.11 同步至当前专家团 v2.0.3：

- 覆盖店铺诊断、周报/月报/季报/年报、大促复盘和专项分析；以用户导出报表工作，不依赖电商平台 API。
- 全量识别、归类并检查报表覆盖，未知、空表、缺数均须说明，不只挑核心报表。
- 保留四位真实分析专家与独立复核，绑定真实任务、回传和完成状态；成员未齐或复核未过，主任务不得提前完成。
- 逐项复算数字来源、公式、口径和归因；未知花费和成本不造数，区分买家转化率、访客价值、ROAS 与利润 ROI。
- 默认图表 PDF；版本、维护批次、报告修订号分别展示。行动、反证、风险和停止条件完整呈现。
- 使用紧凑岗位任务卡与程序装配固定字段，减少重复格式检查和长消息；支持安全续跑、未变底稿复用与上期行动反馈。
- 明确 ClawHub 是分发渠道，不自动赋予宿主原生多专家能力；尚未适配的宿主明确阻断，不伪造协作。

本版不启用 API/后台操作，不更改模型选择，不承诺未经验证的耗时、token 或费用改善。沿用本条目已有 MIT-0 分发方式。
