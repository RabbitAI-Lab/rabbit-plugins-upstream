# omni-ecom SkillHub 版本记录

## 1.5.10（2026-08-24）

- 修正分发结构：ZIP 根目录直接包含 `SKILL.md`，可用于 SkillHub/ClawHub 上传。
- 正式交付继续显示 `omni-ecom v1.5.10` 与报告修订号 `R1/R2`。
- 增加团队启动 90 秒超时和真实 `team_name` 记录；超时不得继续读数据或编造专家回传。
- 增加中断后安全续跑规则：仅允许同一 `run_id`、同一版本和已有真实团队记录的运行继续。

## 1.5.8（2026-08-13）

- 保留 v1.0.0 的 `omni-ecom` slug 与“主理人 + 五位专家”可见角色结构。
- 新增专家团版本与报告修订号分离，正式交付首屏必须显示 `omni-ecom v1.5.8`。
- 新增真实协作模式与 SkillHub 兼容模式，禁止虚构 Agent、task ID、回传或复核凭证。
- 新增 `PASS / WARN / BLOCKED` 数据质量闸门、N0/N1/N2 异常订单情景和证据分层。
- 周报、月报、年报、店铺诊断、经营复盘默认要求图表化 PDF；无法生成时必须诚实返回阻断状态。
- 新增六岗位参与状态、报告冻结/修订、复核放行和迟到回执隔离规则。
- 新增 `client_scope` 公域隔离，禁止沿用历史客户名称、数据和案例署名。

## 1.0.0（2026-08-02）

- 初版 SkillHub 技能包：主理人、数据、平台、内容、投流、交付六个角色的分区块协作框架。
