# 证据与决策输出

## 1. 证据账本

为每个关键事实分配证据 ID，例如 `E01`。至少记录：来源文件、sheet / 行列或筛选条件、期间、指标口径、复算公式、值、限制和校验状态。

所有经营结论必须能回指一个或多个证据 ID。无法回指原始数据的数字不得进入定版报告。

## 2. 四类标签

- 【事实】：从原始资料直接读取或确定性复算，附证据 ID。
- 【判断】：对事实的专业解释，附逻辑链和置信度。
- 【假设】：尚缺证据的可能原因，附验证方法与反证条件。
- 【建议】：拟采取动作，附负责人、截止时间、验收指标和停止条件。

不要把“相关”写成“导致”，不要把行业经验写成该店铺事实，不要把建议写成已执行。

## 3. 置信度

| 置信度 | 条件 |
|---|---|
| 高 | 原始来源可复算、口径一致、样本足够、至少一次独立勾稽通过 |
| 中 | 方向证据充分，但存在样本、期间、归因或维度限制 |
| 低 | 主要依赖截图、单一异常点、经验类比或未验证假设 |

低置信度结论不能驱动不可逆动作，只能进入小范围测试或补数计划。

## 4. 决策与行动契约

每项行动至少包含：

| 字段 | 要求 |
|---|---|
| 优先级 | P0 / P1 / P2，说明排序依据 |
| 目标 | 可量化且有基线 |
| 动作 | 具体到对象、范围和步骤 |
| 负责人 | 使用岗位；未知时写“待指定” |
| 截止时间 | 用户未给日期时用 T+N，不虚构具体日期 |
| 验收指标 | 指标、口径、观察窗口和成功阈值 |
| 停止条件 | 何时暂停、回滚或升级人工复核 |
| 前置依赖 | 数据、权限、素材、预算或平台审核 |

重大预算、定价、库存和平台外发动作同时给保守 / 进取方案，并明确人工审批点。

## 5. 交付状态

- `data_blocked`：数据闸门未通过，只交付问题与补数清单。
- `draft_diagnosis`：已形成诊断，但存在限制或待确认项。
- `ready_for_review`：证据、口径、复算和交付自检均完成，等待用户审批。

只有外部平台或文件状态被实际验证后，才可声称“已发布”“已执行”或“已交付”。
