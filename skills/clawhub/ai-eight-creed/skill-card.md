## Description: <br>
Provides a domain-agnostic AI behavior creed that guides agents to verify facts, clarify scope, defer human decisions, reuse existing work, check outputs, follow conventions, admit uncertainty, and address root causes. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External users, developers, and teams use this skill to apply a concise behavioral code to AI assistants for fact checking, scope clarification, human decision handoff, reuse of existing work, closed-loop verification, convention following, and honest uncertainty handling. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill asks to become a highest-priority, always-on rule set across all domains, which may conflict with normal platform policies, task instructions, or local workflows. <br>
Mitigation: Use it only as optional guidance, keep platform and system policies higher priority, and narrow or remove always-on memory or rules-file placement when conflicts appear. <br>
