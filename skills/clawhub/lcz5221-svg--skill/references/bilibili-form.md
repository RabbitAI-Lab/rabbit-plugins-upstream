# B站投稿表单填写明细

## 必填项
- 标题：`M月D日 + 文章标题`，80字内
- 封面：上传自定义图片 + 封面文字（见 fabric-cover-text.md）
- 创作声明：个人观点，仅供参考
- 分区：资讯
- 标签：加满10个（点击推荐标签）
- 简介：100-200 字摘要

## 推荐标签（财经新闻类，点推荐即可）
财经、IPO、热点、股市、模型、速递、投资、股票、金融、中国

## 其他
- 加入合集：热点资讯
- 发布：即时（不开启定时）
- 此稿件不生成更新推送：保持默认
- 商业推广：不添加

## 注意
- 网页端投稿页**没有「定位/长沙市」功能**（移动端APP才有），不要浪费时间找
- 分区、创作声明、合集都是下拉可选

## 操作顺序（实测有效）
1. 改标题
2. 选创作声明（个人观点，仅供参考）
3. 上传封面图片 + 加封面文字
4. 确认分区（资讯）
5. 点推荐标签加满10个
6. 填简介
7. 确认合集（热点资讯）、发布（即时）
8. 点「立即投稿」
