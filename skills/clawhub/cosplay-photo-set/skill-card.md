## Description:

通用模板：用本机 ComfyUI（z-image-turbo）把任意二次元角色做成「真人 cosplay 套图」——角色检索与确认 → 真人基准图确认 → 同角色卡多姿势成片 → 去油光去反光 → 唯美纯色/渐变影棚背景（按角色配色，无实景、无亮斑、无摄影灯）→ 导出 1–2MB 竖版 JPEG → 附标题、正文与标签。适用于任何角色与平台（视频号/小红书/图集）。

This skill is ready for commercial/non-commercial use.
