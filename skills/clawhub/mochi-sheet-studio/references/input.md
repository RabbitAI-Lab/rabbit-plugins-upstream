# Job contract

Every JSON job is <=1 MiB and includes requestId (1..80 ASCII letters, numbers, hyphens or underscores). Identical retries reuse verified results. A changed job/source needs a fresh requestId.

action: inspect|analyze|reconcile. sources: 1..20 objects with file (workspace-relative CSV/XLSX), optional sheet, encoding utf-8-sig|utf-8|gb18030 and delimiter comma/semicolon/tab. Each sheet <=50000 data rows, <=200 columns; combined <=100000 rows; file <=25 MiB, expanded XLSX <=150 MiB. Headers must be nonempty/unique. mapping maps semantic field names to actual headers. analyze needs id,date,currency,category,amount; optional kind. recipe sales (sale/refund) or expenses (expense/refund). Missing kind defaults to sale/expense. id/currency/kind identifies a transaction line. Amounts are positive plain decimal strings with up to 4 decimal places, <1 trillion; no grouping separators, symbols or implicit locale. Dates ISO YYYY-MM-DD; currency explicit three-letter code. period optional YYYY-MM compares that month against the preceding month. reconcile needs exactly two sources, mapping id/currency/amount. Same key must be unique on each side. inspect does not need mapping. Formula cells are listed; mapped formulas are issues until exported as values. report.json stores exact decimals; XLSX summary display has two decimal places. Output report.xlsx, report.json, recipe.json, preview.html; inspect outputs inspection.json.
