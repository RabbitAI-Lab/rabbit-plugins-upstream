## Use Case: <br>
Developers and automation engineers use this skill to connect Python Playwright scripts to Scrapfly Cloud Browser for remote browser automation, JavaScript-heavy scraping, login flows, screenshots, geo-targeted proxy sessions, and persistent browser sessions. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill includes instructions to install and run a BYOP proxy connector inside customer-controlled networks using an unverifiable shell one-liner. <br>
Mitigation: Install only when this internal-network proxy capability is intentionally required; verify the installer and binary, use least-privilege hosts, document approvals for internal or PHI workflows, and revoke API keys or connector certificates when no longer needed. <br>
