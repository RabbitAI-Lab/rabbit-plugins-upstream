## Description:

Guides an agent through gathering requirements, planning and refining brochure layouts, and producing folded and lifestyle mock-ups after layout approval.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Marketing teams, designers, and content creators use this skill to turn a brief into a brochure layout and, after approval, a consistent set of folded and lifestyle mock-ups.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security scan reported an undeclared CLI authentication operation and could not inspect some references; its benign verdict has medium confidence.

Mitigation: Review the current CLI authentication behavior and installation source before logging in; use a dedicated API key and revoke it if exposed.

Risk: Prompts and supplied media are sent to dLazy's hosted API and media service, so submitted material may leave the local environment.

Mitigation: Avoid sending confidential or personal material unless its use with the service is authorized; use sanitized inputs when possible.
