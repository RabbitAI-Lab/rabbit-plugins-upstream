## Description:

Guides marketing brochure design from requirements and fold selection through approved layouts to folded and lifestyle mock-ups.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Marketing teams and designers use this skill to plan brochure panels, develop layouts, and produce folded and lifestyle mock-ups after approving the layout.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and uploaded media may be sent to dLazy's cloud service.

Mitigation: Confirm that sharing the intended content with dLazy is acceptable before using the skill.

Risk: A dLazy API key may be stored in the user's local CLI configuration.

Mitigation: Protect the local configuration and rotate or revoke the key in the dLazy dashboard when no longer needed.

Risk: Installing the CLI globally keeps it on the system after use.

Mitigation: Use the documented npx option if a global installation is unwanted; review the CLI source before installation if needed.
