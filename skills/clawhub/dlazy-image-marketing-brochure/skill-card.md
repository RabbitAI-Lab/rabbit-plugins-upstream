## Description:

Guides marketing brochure creation from requirements and unfolded layouts through approved folded and lifestyle mock-ups.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Marketing teams and designers use this skill to plan brochures, review unfolded layouts, and generate consistent folded and lifestyle mock-ups after approval.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Brochure prompts and selected media are sent to dLazy for generation.

Mitigation: Confirm the provider is acceptable and share only content approved for external processing.

Risk: CLI installation and saved API keys may create unwanted local persistence; the skill's version wording is inconsistent.

Mitigation: Confirm the npm package version before use, and prefer npx or an environment-variable API key if persistence is unwanted.
