## Description:

Guides marketing brochure design from requirements and fold selection through approved layouts and realistic mock-ups.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Marketing teams and designers use this skill to plan and generate brand, product, and event brochures, then create folded and lifestyle mock-ups after approving the layout.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and referenced media may be sent to dLazy's hosted service.

Mitigation: Avoid sensitive assets and confirm that third-party processing is acceptable before generating images.

Risk: The CLI requires an API key and may store it locally; global installation persists the CLI.

Mitigation: Protect the local API key, use npx to avoid a persistent global install, and check the intended CLI version before installation.
