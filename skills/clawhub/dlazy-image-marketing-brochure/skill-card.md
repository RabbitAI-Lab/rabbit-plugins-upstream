## Description:

Guides marketing brochure creation from requirements and layout through user-approved folded and lifestyle mock-ups.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Marketing teams and designers use this skill to plan brochures, generate unfolded layouts, and create consistent folded and lifestyle mock-ups after approving the layout.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Brochure prompts and uploaded reference media are sent to dLazy cloud services.

Mitigation: Submit only materials approved for cloud processing.

Risk: Installing a third-party CLI or storing an API key may create ongoing software and credential exposure.

Mitigation: Review the CLI package before installation; use npx and an environment-variable API key if a global install or stored key is not wanted.
