## Description:

Guides marketing brochure design from requirements and layout planning through user-approved layouts and realistic mock-ups.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Marketers and designers use this skill to plan brochure content and folds, review an unfolded layout, and create consistent folded and lifestyle mock-ups after approval.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and supplied media may be sent to a third-party cloud image service.

Mitigation: Avoid submitting confidential content unless you trust dLazy; review media before uploading.

Risk: CLI login stores an API key in the user's configuration.

Mitigation: Protect local credentials and prefer one-off CLI execution when persistent installation is unnecessary.
