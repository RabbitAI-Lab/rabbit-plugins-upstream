## Description:

Guides agents through planning marketing brochures, designing the unfolded layout, and creating folded and lifestyle mockups after approval.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

External marketers and design teams use this skill to plan brochures for brands, products, services, and events, then create layouts and presentation mockups.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and reference media provided for generation are sent to dLazy-hosted services.

Mitigation: Use only brochure content and reference images you are comfortable sharing with dLazy.

Risk: Image generation may incur charges.

Mitigation: Consider generation charges before requesting images.

Risk: The CLI saves the API key in local configuration.

Mitigation: Protect the saved API key and revoke it when it is no longer needed.

Risk: The documentation includes a stale 1.0.9 package version reference alongside 1.2.3 installation commands.

Mitigation: Use the version-pinned 1.2.3 installation commands described in the skill metadata.
