This skill is ready for commercial/non-commercial use.

## Use Case:

Marketing teams and creative agents use this skill to plan brochure content, design layouts, and prepare folded or lifestyle mock-ups after user approval.

### Deployment Geography for Use:

Mitigation: Review the CLI and its credential handling before logging in; rotate or revoke the key if needed.

Risk: The security scan is partial and could not review some referenced items.

Mitigation: Review the CLI and referenced components before installation or authentication.
