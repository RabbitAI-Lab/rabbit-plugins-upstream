## Description:

Guides marketing brochure creation from requirements and layout design through approved folded and lifestyle mock-ups.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Marketing teams and designers use this skill to plan brochure content and folds, generate layouts, obtain approval, and produce consistent folded and lifestyle mock-ups.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Brochure prompts and referenced media are sent to dLazy-hosted services.

Mitigation: Share only content and media approved for third-party processing.

Risk: Using the dLazy CLI requires an API key and may install third-party software.

Mitigation: Protect or rotate the key, and use the on-demand CLI path if a persistent global installation is not wanted.
