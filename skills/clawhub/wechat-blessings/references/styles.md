# Blessing style guide

## Inputs that materially improve the greeting

- Occasion: birthday, holiday, wedding, opening, graduation, recovery, customer care.
- Relationship: family, friend, colleague, leader, customer, group.
- Tone: warm, formal, playful, restrained, traditional, modern.
- Length and language.
- One verified personal detail, when available.

## Default candidates

1. Warm: natural emotion and one concrete wish.
2. Concise: one or two sentences suitable for direct messaging.
3. Expressive: more imagery, rhythm, or traditional phrasing without becoming ornate.

## Batch personalization

Use a shared core message only when appropriate. Personalize salutations from verified recipient data. Never imply a close relationship or personal knowledge that the sender does not have. For customers, avoid manipulative urgency and unsupported benefits.

## Delivery rules

- Preserve the user-approved wording exactly when invoking the send script.
- Preview the exact recipient list and normalized schedule.
- Require an explicit confirmation code before sending.
- A change to punctuation or salutation changes the operation and requires a new preview.
- Scheduled blessings use the Windows service time zone, currently Asia/Shanghai by default.
