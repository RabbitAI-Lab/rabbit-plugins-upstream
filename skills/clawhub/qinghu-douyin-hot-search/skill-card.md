### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installing or upgrading qhkit and Node tooling may persistently change the user's environment.

Mitigation: Prefer user-approved, preinstalled and version-pinned tooling; avoid unreviewed npx or latest-version execution.

Risk: The skill requires a Qinghu API token and can incur variable credit charges for paid queries.

Mitigation: Confirm token setup with the user and obtain consent after showing an estimated credit cost before paid calls.
