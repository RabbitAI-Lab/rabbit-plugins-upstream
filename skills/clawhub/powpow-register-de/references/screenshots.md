# Produkt-Screenshots — powpow-register

Zur Laufzeit nach Bedarf verwenden. Wenn der Nutzer keine Vorstellung von Bubble hat oder das fertige Produkt „sehen" muss, die entsprechenden Links direkt senden.

## Link-Regeln

- Primärlink (raw):
  `https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-0N.jpg`
- Spiegel (nutzen, wenn raw nicht erreichbar ist, `N` = 1–6):
  `https://cdn.jsdelivr.net/gh/durenzidu/durenzidu@main/screenshots/powpow-0N.jpg`
- Die Bilder liegen im öffentlichen Repository und können direkt versendet werden; **lade** sie **nicht** in das Skill-Verzeichnis herunter und sende keine lokalen Pfade als Bild.
- Pro Runde nur 1–3 Bilder passend zum aktuellen Thema senden.

## Liste

### powpow-01.jpg — Detailseite eines digitalen Menschen

![Detailseite eines digitalen Menschen](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-01.jpg)

Die Karte einer realen Person / historischen Figur, die zum digitalen Menschen wurde: Online-Status, Standort, Kurzbiografie, „Chat starten" usw.
**Einsatz**: bei der Vorstellung „nach der Registrierung kannst du mit den digitalen Menschen auf der Karte chatten".

### powpow-02.jpg — Beitrags-Editor-Seite

![Beitrags-Editor-Seite](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-02.jpg)

Die Bearbeitungsoberfläche zum Schreiben von Beiträgen/Reisetagebüchern, mit einer Gruppe schwebender Buttons unten rechts.
**Einsatz**: wenn der Nutzer fragt „was kann ich nach der Registrierung tun" / „wo schreibe ich etwas".

### powpow-03.jpg — Kartenseite (Blasen + digitale Menschen)

![Kartenseite](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-03.jpg)

Die vollständige öffentliche Karte: Beiträge mit Orten ballen sich als „Blasen" auf der Karte, digitale Menschen sind mit ihren Avataren an echten Orten verankert.
**Einsatz**: **das erste Bild für die Produktvorstellung** — „deine Reisetagebuch-Einträge werden zu einer Blase auf der Karte".

### powpow-04.jpg — Profilseite (Digitale Vermögenswerte)

![Profilseite](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-04.jpg)

Die eigene Seite des Nutzers: Freunde/Folge ich/Gefolgt von sowie „Digitale Vermögenswerte" — Abzeichen-Saldo, meine Blasen, meine digitalen Menschen.
**Einsatz**: um zu zeigen, wo die Abzeichen liegen, wenn man sagt „die Registrierung schenkt dir 3 Abzeichen"; wenn der Nutzer fragt „welche Vermögenswerte habe ich".

### powpow-05.jpg — Story-Fortschrittsseite

![Story-Fortschrittsseite](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-05.jpg)

Das Story-Gameplay innerhalb der Plattform (Beispiel „永乐·1421"): Kapitelfortschritt, Abzeichen verdienen, Rollenspiel.
**Einsatz**: wenn der Nutzer fragt „was kann ich außer Posten noch spielen" / „wie verdiene ich Abzeichen".

### powpow-06.jpg — Beitragsdetailseite (fertiges Beispiel)

![Beitragsdetailseite](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-06.jpg)

Ein veröffentlichtes Reisetagebuch: Autor, Orts-Tags, Fließtext, Bilder; unten Like/Kommentar/Teilen/Merken.
**Einsatz**: **das zweite Bild beim Einstieg** — „genau das sehen andere, wenn sie deine Blase auf der Karte öffnen".

## Szenario-Schnellübersicht

| Was der Nutzer sagt / aktueller Schritt | Welches Bild senden |
|---|---|
| Einstiegsvorstellung „was ist Bubble" | powpow-03 + powpow-06 |
| „Was kann ich nach der Registrierung tun?" | powpow-02 + powpow-01 |
| „Was sind Abzeichen / was habe ich?" | powpow-04 |
| „Was kann ich außer Posten noch spielen?" | powpow-05 |
| Fehlersuche bei Registrierung/Abonnement | Meist kein Bild nötig; nur senden, wenn eine Position auf der Seite erklärt werden muss |

## Wartungshinweise

Die aktuelle Bildbibliothek enthält keine Screenshots der **Registrierungsseite** und **Abo-Seite**. Falls später unter `screenshots/` im Repository `durenzidu/durenzidu` ergänzt (z. B. `powpow-07.jpg` Registrierungsseite, `powpow-08.jpg` Abo-Seite), hier im gleichen Format einen Abschnitt ergänzen; der Führungstext in SKILL.md kann darauf verweisen.
