# 监护与监督人服务顾问

> 协助梳理监护监督安排，提供履职清单、财产监管要点与监督报告模板；不出具法律意见、不代理案件，需人工复核。适用需监护监督的家庭与个人。技术触发词「监护监督、履职记录、财产监管」。口语触发词「监护监督人的职责清单有哪些、履职记录怎么做才规范、监护中的财产监管要点有哪些」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

监护监督顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 监护监督人的职责清单有哪些？给我一份可执行的清单。
- 履职记录怎么做才规范？给我一个记录模板。
- 监护中的财产监管要点有哪些？给我一份要点清单。
- 监护监督和意定监护怎么衔接？分别管什么？
