# 财产监管与监督报告模板（规划辅助用）

> 以下为财产监管要点与报告模板，不构成法律意见，具体以属地规定及持证专业人士意见为准。

## 一、财产监管要点清单

- [ ] 建立被监护人财产台账：账户、房产、养老金、保单、投资
- [ ] 监护人专户管理，收支分离，避免与自有财产混同
- [ ] 设定大额支出阈值（如超过 X 元须报备/双签）
- [ ] 按月对账：银行流水、票据与台账核对
- [ ] 禁止自我交易与不当转移（如无偿转给监护人关联方）
- [ ] 重大处分（出售房产、提取大额）须留书面依据与监督人意见
- [ ] 财产变动异常情况 24 小时内记录并反映

## 二、对账机制（示例）

| 周期 | 动作 | 责任人 | 产出 |
| --- | --- | --- | --- |
| 每月 | 流水与票据核对 | 监护人 | 月度对账表 |
| 每季 | 台账盘点 | 监督人 | 季度监督记录 |
| 每年 | 年度财产报告 | 监督人 | 年度监督报告 |

## 三、监督报告模板（可照抄）

```
监督报告（YYYY年第X期）
被监护人：___  监护人：___  监督人：___
报告周期：YYYY-MM-DD 至 YYYY-MM-DD

一、人身照护情况
- 健康状况：___
- 照护落实：___
- 异常：有/无（如有，说明及处置：___）

二、财产监管情况
- 期初财产：___
- 本期收支：收入___ 支出___
- 大额支出（超阈值）：___ 用途___ 凭证___
- 异常：有/无（如有，说明及处置：___）

三、重大事项
- 医疗决定：___
- 资产处分：___

四、监督结论
- 监护人履职评价：合规/需关注/异常
- 下一步建议：___

监督人（签字/记录）：___  日期：___
附件：流水、票据、照片等凭证清单
```

## 四、报告提交与归档

- 固定节奏提交（月度简报/季度/年度报告）
- 报告与凭证一并归档，保存期建议覆盖监护全程及后续可能的争议期
- 发现异常时，除记录外应同步提示相关方并视情况反映至民政/法院

## 五、需立即转人工的情形

- 财产被大额转移或存在混同；
- 监护人拒不提供凭证；
- 需凭报告申请撤销或变更监护。
