# 60㎡清爽LOFT，一个人住就挺美

公寓式loft对于年轻人来说，非常有吸引力，格局灵活，上下分层，动静分离，而且非常符合年轻人的好动性。本套入住一位美女，风格上符合美女喜好即可。
▲原始一楼图纸，进门右手就是楼梯，左手一个大开间，一个封闭的卫生间，厨房管道与卫生间并列，而且厨房刚好在唯一采光最好的窗户位置

▲原始二楼空间，两间卧室带一个卫生间，与一楼厨房相对的地方是挑空区域；两间卧室之间有墙体分割，导致一间次卧完全没有任何光线
▲一楼重新规划，改变原有楼梯的位置，移动到进门左手角落，让进门口更宽敞，成就动线以及更多收纳；原有一楼卫生间牺牲，改变入门位置，做成了厨房空间，原有厨房刚好布局成小的就餐空间；沙发居中布局，让四周动线更加合理.一楼完全作为活动区域布局
▲二楼改变楼梯位置以后，同样位置成就了收纳柜定制，打掉了两间卧室的隔墙，让光线通透，同时原有次卧位置刚好作为办公区域布局
▲一楼进门看到的全景，楼梯改动到左手拐角，成就进门右手的收纳定制，分别成就了鞋柜以及收纳柜储物布局；沙发采用居中设计，让四周动线更加通畅
▲进门左手依次是楼梯以及电视墙，靠窗户布局岛台餐桌，同时就餐和办公都实现了；楼梯下方做了开放式的收纳储物柜，悬空的石材定制电视柜，灯光点缀，轻巧又高级
▲改变位置以后的楼梯采用玻璃扶手以及悬空木质设计，视觉上通透轻盈，让小空间不仅更宽敞，而且增加空间高级感
▲因为公寓楼住户较多，为了很好的保证进门隐私，防盗门采用可爱的半帘装饰，可以挡住进门一览无余的视线
▲与鞋柜一体打造的收纳柜，不仅有封闭的储物，同时还有开放的展示功能，灯光点缀温馨；一扇门镜面设计，刚好满足美女的全身镜功能
▲利用楼梯下方定制了半开放的收纳格子，可以作为展示用，也可以收纳小的零碎
▲原有卫生间改变入门方向以后，把厨房内移，成就厨房空间；外面刚好布局冰箱以及水吧台，满足电器以及杯子的放置
▲一楼厨房全景，空间非常小，开放布局，L型白色橱柜定制；地面木纹砖铺贴，墙面是素雅灰色瓷砖
▲原来厨房位置布置了岛台餐厅，岛台下方镶嵌洗烘一体机，一边刚好是就餐空间
▲二楼主卧，挑空处玻璃护栏围挡，满足整个空间的光线需求；原有二楼卫生间做了干湿分离布局；床对面整体收纳柜，预留了一个化妆台空间
▲床头一边落地灯布局，满足晚上阅读，同时也是装饰
▲为了保证主卧的睡眠安全感，同时又不影响整体光线；利用玻璃移门分割了主卧和其他区域
▲原有楼梯改动位置以后，二楼一面墙定制了超级大的收纳柜，作为美女的衣帽间使用；打掉原有主次卧的墙体，满足采光需求；围绕楼梯刚好定制办公书桌，满足美女的办公需求
▲办公空间围绕楼梯布局，刚好占用满足书桌和书籍的收纳。一个人住一间卧室满足功能，同时还满足一个单独书房的功能
▲二楼卫生间利用拆改墙体，实现了干湿分离，虽然不大，但是完美实现浴柜的外置
