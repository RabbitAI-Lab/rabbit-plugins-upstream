# 基础用法示例

## 示例 1：生成 2% 极速预览版

```
/zhihu-research-page 执行2%版本
主题：什么是 Harness Engineering？
```

**输出**：
- 自动搜索 ≥10 次
- 生成 3 章节知乎风 HTML（约 2,000 字）
- 目录：`v{N}_2pct/index.html`
- 耗时约 2 分钟

## 示例 2：生成 5% 快速验证版

```
/zhihu-research-page 执行5%版本
主题：React Hooks 入门指南
```

**输出**：
- 自动搜索 ≥25 次
- 生成 3 章节（约 5,000 字）
- 适合快速浏览内容框架

## 示例 3：生成 100% 完整版

```
/zhihu-research-page 执行100%版本
主题：国际象棋怎么学？代数记谱法、西西里、西班牙主流开局这些是什么？
```

**输出**：
- 自动搜索 ≥500 次，7+ 搜索代理并行
- 生成 10 章节完整深度网页（≥100,000 字）
- 每章独立答主身份和 DiceBear 头像
- 含侧栏导航、操作条、页脚
- 耗时约 100 分钟
