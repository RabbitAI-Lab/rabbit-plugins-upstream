# 高级用法示例

## 示例 1：深度加量 200% 版本

```
/zhihu-research-page 执行200%的v2版本
主题：各种调式的流行歌曲都有什么特点，它们各有什么代表作？
```

**输出**：
- 自动搜索 ≥1,000 次
- 生成 20 章节超深度网页（≥200,000 字）
- 耗时约 200 分钟
- 注意：token/时间预算远超常规

## 示例 2：教程模式（自动启用）

```
/zhihu-research-page 执行50%版本
主题：Python 入门指南 - 从零基础到能写爬虫
```

**输出**：
- 自动识别"入门指南"关键词，启用教程模式
- 每章含前置知识标注、动手操作步骤
- 预期结果截图描述、常见报错及解决方案
- 面向零基础，跟着做就能上手

## 示例 3：多版本迭代

```
/zhihu-research-page 执行2%版本
主题：机器学习入门

# 检验效果后，在同一目录下继续：
/zhihu-research-page 执行100%版本
主题：机器学习入门
```

**输出**：
- 2% 版本在 `v2_2pct/` 目录
- 100% 版本在 `v3_100pct/` 目录（版本号自动递增）
- 两版本主题相同，比例不同

## 示例 4：特定领域深度研究

```
/zhihu-research-page 执行100%版本
主题：2025年AI芯片产业格局：NVIDIA、AMD、Intel、华为昇腾、寒武纪各有什么优势？
```

**输出**：
- 10 章节深度对比分析
- 涵盖技术参数、市场份额、生态建设、定价策略
- 所有数据附可点击来源链接
- 争议点如实标注（如不同机构市场份额数据差异）
