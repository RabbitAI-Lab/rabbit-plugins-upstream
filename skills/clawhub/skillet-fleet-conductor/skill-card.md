## Description:

Use when conducting a large backlog or multi-repository campaign across several worker lanes, especially when work needs bounded ownership, held dependencies, collision control, draft pull request gates, and evidence-based landing.

This skill is ready for commercial/non-commercial use.

## Publisher:

[escoffier-labs](https://clawhub.ai/user/escoffier-labs)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use Fleet Conductor to coordinate multi-repository work across bounded worker lanes, manage dependencies and collisions, gate pull requests on checks and independent reviews, and verify merges against GitHub evidence.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Repository code and issue content, including private-project content, may be shared with both review providers; campaign records may also be retained.

Mitigation: Use the skill only for repositories you are authorized to change, confirm both providers may receive the repository content, and account for retained campaign records.
