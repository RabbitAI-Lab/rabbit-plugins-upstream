# ClawHub — A股财报结构化拆解系统

> 基于 Hermes Agent Skill 架构，对A股上市公司季报/年报进行一手数据提取、自算核验、跨季度可比的结构化分析。

## 功能

- **16节固定模板**：统一财报拆解结构（营收结构→盈利扣非→资产负债→现金流→股东回报→筹码变化→估值→风险→核心判断），跨季度跨公司可比
- **多数据源支持**：Tushare MCP（主）→ akshare → baostock → 东方财富datacenter API（兜底），自动降级
- **8条核验纪律**：FCF自算、股数反推自洽、扣非偏差审查、现金含金量预警、应收-营收增速对比等，逐条执行不可跳过
- **报告类型适配**：年报/半年报全量分析，三季报/一季报简化报表自动标注缺失项
- **实战Pitfalls**：Tushare free_cashflow字段不可信、API权限降级处理、单季数据计算方法等

## 目录结构

```
clawhub/
├── SKILL.md                                  # 主技能文档（16节模板+工作流+核验纪律+接口映射）
├── references/
│   ├── a-share-earnings-template.md          # 财报拆解空白模板
│   └── case-study-tengjing-2025.md           # 腾景科技2025年报实战案例
```

## 使用方式

1. 将 `SKILL.md` 加载为 Hermes Agent Skill
2. 告诉 Agent 股票代码和报告期（如"拆解德方纳米2025年年报"）
3. Agent 自动拉取三表数据、填充16节模板、执行8条核验纪律
4. 输出结构化财报拆解报告
