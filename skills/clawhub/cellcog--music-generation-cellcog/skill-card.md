## Description:

AI music generation powered by CellCog for original instrumental and vocal tracks from 5 seconds to 10 minutes, including scores, background tracks, jingles, lo-fi beats, orchestral compositions, and songs with lyrics.

This skill is ready for commercial/non-commercial use.

## Publisher:

[cellcog](https://clawhub.ai/user/cellcog)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to ask an agent to create royalty-free music through CellCog, including instrumental tracks, vocal songs, podcast intros, game soundtracks, ambient soundscapes, and jingles.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill requires a CellCog API key and sends music prompts to an external service.

Mitigation: Install and use it only when CellCog is intended for the workflow, and avoid sending sensitive prompt content unless approved for that service.

Risk: Commercial use depends on CellCog pricing and generated-music licensing terms.

Mitigation: Review current CellCog pricing and licensing terms before using generated tracks commercially.
