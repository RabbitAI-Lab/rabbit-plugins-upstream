## Description:

Write documentation first, code second, for any non-trivial change to a codebase.

This skill is ready for commercial/non-commercial use.

## Publisher:

[blueriverlhr](https://clawhub.ai/user/blueriverlhr)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering agents use this skill to create reviewable planning, decision, task, and manual documentation before implementing non-trivial codebase changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Planning documents may contain sensitive discussion details or decisions if the workspace includes private project context.

Mitigation: Review generated documentation before sharing, publishing, or committing it, and avoid recording secrets or unnecessary sensitive details.

Risk: Documentation-first workflows can cause stale guidance if implementation reality diverges from the plan.

Mitigation: Update the relevant docs before coding when plans change, and verify manual and task documents before marking work done.
