## Description:

Marketstack (marketstack.com). Use this skill for searching and reading Marketstack financial market data through the OOMOL connector rather than calling the API directly.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to retrieve Marketstack end-of-day data, ticker profiles, available tickers, supported currencies, and stock exchanges through an authenticated OOMOL-connected account.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Mitigation: Review the skill before installing and prefer a pinned, verified, manually reviewed oo CLI installation method.
