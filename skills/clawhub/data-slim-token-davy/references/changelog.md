本文件是该技能唯一的版本演进记录。日常调用不需要读它，只在排查「装到的是哪个版本 / 某条行为从哪一版开始」时按需查阅。

## v1.0.14（2026-11-16）· 双渠道对齐版

首次让「平台版本号 = 包内版本号 = 实际内容」三者一致。功能代码未改。

文字层修正：

- 命令路径全部补全为 `python3 scripts/slim.py <子命令>`。此前正文表格里存在裸 `slim.py`，会被平台当作包内根目录文件去校验，导致上传报「资源不存在或无权访问」。
- 去除裸文件名（摘要索引、示例中的表格与 JSON 产物名等），统一改成不含扩展名的自然描述；用户路径示例不再出现具体绝对路径。
- 简介（WorkBuddy 的 `description_zh` / SkillHub 的 `summary`）修正四处不成立的表述：四层由旧口径「上传前瘦身 / 按需加载 / 上下文纪律 / 前缀缓存」改为空白压缩、结构化、规则去客套、语义压缩；「文件瘦身层无损」改为「规则压缩在前、语义提炼按需启用」（L2 默认去重会删合法重复行，不能承诺无损）；「最高省 78%、普遍省 50%+」改为区间「70%–80% / 约 68%」；「一键导出对比报告」改为「累计用量随时可查」（导出报告属 Pro 批量功能）。同时保留「默认关闭，需显式说启用瘦身才生效」。
- 四层口径统一：废弃 1.0.4 时代「上传前瘦身 / 按需加载 / 上下文纪律 / 前缀缓存」的旧表述。`references/context_rules.md` 的规则内容不变。
- 「免费 / Pro 规划」章节的版本标注由 1.0.5 更新为 1.0.14。

发布层：

- 新增本文件，作为唯一版本演进记录（此前进度只存在于对话与旧仓库文档中）。
- WorkBuddy 开放平台（name `data-slim`）与 SkillHub（slug `data-slim-token-davy`）改为同一份正文，逐字节一致。
