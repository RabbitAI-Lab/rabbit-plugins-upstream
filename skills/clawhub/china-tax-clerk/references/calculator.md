# 本地计算接口

Python 3.10+标准库，无安装依赖、联网、登录或外部提交。命令相对skill目录：

```bash
python3 scripts/calculate.py assets/examples.json
python3 scripts/calculate.py /绝对路径/本期输入.json > /绝对路径/本期计算.json
```

支持单个请求或数组。整个数组验证成功才输出结果；失败返回JSON错误和退出码2，不输出部分结果。金额为人民币元，可用十进制字符串（推荐），最多两位小数；比例用 `"0.01"`，不用 `1` 表示1%。必填数值不能省略；确认没有才填0。

## 公共字段

```json
{
  "id": "可选的底稿编号",
  "mode": "small_vat",
  "period_start": "2026-07-01",
  "period_end": "2026-09-30",
  "scope_confirmed": true,
  "data": {
    "cycle": "quarter",
    "sales": [{"net_sales": "250000.00", "rate": "0.01", "waive_exemption": false}],
    "prepaid": "0.00"
  }
}
```

`scope_confirmed=true` 表示操作者已经按以下适用条件完成业务范围/输入口径审核；不能在未问明事实时为通过校验擅自填true。它不代表在线政策核验或申报授权。当前代码是2026-10-10快照，只接受2026—2027同年所属期；过期拒算，不能只改日期绕过。

所有输出固定为草稿，回显输入、公式、规则编号、政策索引及快照日期；必须另记本次实际政策核验。金额按十进制四舍五入到分，输入不含税金额及票面税额要先对账。脚本按税率组汇总计税，可能与逐票舍入有分差，单独调节并以当期官方表规则核验。不会自动制造调整数。

## 模式与适用范围

### small_vat：普通按期小规模

`data` 必填：`cycle`（month/quarter）、`sales`数组、`prepaid`（同所属期合法已预缴）。每行 `net_sales` 为**不含税**销售额，`rate`为0.01或0.03，`waive_exemption`为是否放弃该交易免税。

仅已确认的小规模单位/个体普通境内交易；完整自然月/季，主体资格全期不变，全部收入（含未开票）已纳入。不得夹带不动产/土地、自然人按次、差额、旧货/固定资产特别优惠、其他免税或跨期红字项目。含税价须先按该笔实际征收率换算/按票面分离，再送入；免税交易收款与销售额口径按官方规则确认。

**2026门槛使用严格小于**：月10万、季30万；等于门槛全额计税。专票/放弃免税行即使未达也征税，仍并入门槛；3%行的放弃减征及票据处理也须有事实依据。不减采购成本。

### general_vat：普通一般计税

必填 `sales`数组（每行`net_sales`,`rate`，仅0.13/0.09/0.06）、`deductible_input`（已审核可抵扣、尚未扣本字段外的转出）、`input_transfer_out`、`opening_credit`、`prepaid`。

仅普通境内一般计税，所有交易分类及抵扣资格已确认；不含简易计税、免/退税、差额、税额抵减等特殊项。不可抵扣发票从输入排除，已经排除的金额不能再转出一次。输出留抵与预缴余额分开；留抵不是自动退税。

### cit：普通居民企业所得税

必填 `assessment`（annual/prepayment）、`tax_base`、`employees_average`、`assets_average`、`industry_allowed`（非限制/禁止行业）、`prepaid`。

`tax_base` 是完成账税调整/优惠/亏损核验后的年度应纳税所得额，或本年累计预缴实际利润额，不能直接填未调整净利润。人数/资产输入对应期间规定平均数，人数可有小数；资产单位元。常规25%或符合小型微利5%判断，其他优惠/抵免、非居民、汇总纳税、个人独资/合伙不适用。

annual要求完整年度；prepayment从1月1日起累计，`prepaid`为此前累计实缴，不是当前季度计算税额。年度多缴是退税候选；预缴多缴如何处理需按官方系统核验，不当期自动退款。短纳税年度另作底稿。

### payroll：居民工资累计预扣

必填：`income_ytd`、`exempt_income_ytd`、`basic_deduction_ytd`、`social_deductions_ytd`、`additional_deductions_ytd`、`other_deductions_ytd`、`relief_ytd`、`withheld_ytd`。

均为本单位本年度累计；起日填1月1日、止日为当前月末。基本费用数额按实际任职月数和适用预扣规则确定，不能自动拿当前月份数代替；6万元简便预扣等适用时先查专项政策。其他扣除含依法核定捐赠等，不含前面已扣项目。`withheld_ytd`仅截至上期已实际扣缴，不能把本期再次扣入。负差额本期不退。非居民、劳务按次预扣及股权激励不适用。

### iit_annual：居民综合所得汇算复算

完整年度；必填 `wages`（工资含选择并入的奖金）、`labor`（劳务）、`author_fees`（稿酬）、`royalties`（特许权）、`deductions`、`relief`、`withheld`。

前四项为已去除免税部分的相应全年收入（劳务等尚未作20%费用折算）；`deductions`仅6万元以外的合法专项/附加/其他扣除及准予扣除捐赠，不包含重复扣除。只涵盖境内居民普通综合所得，无境外抵免/特殊分项计税。年度最终税额减已缴得到差额；**正差额仍需审核12万元/400元等免办汇算条件和例外**，字段不叫最终应缴款。退税需官方受理，不代表已经退款。

### bonus_compare：单笔合格奖金方案比较

完整年度；必填 `annual_net_before_bonus`（**未截零**的全年综合所得收入额减6万元及合法扣除，尚不含本笔奖金，可负）、`bonus`、`eligible_once`。

仅单笔符合条件全年一次性奖金，年度单独计税机会可用且居民身份确认；无特殊减免/境外抵免。比较两种全年名义税额，不计算本月扣款或自动决定汇算豁免。多笔奖金需另作合法选择比较；不能每笔独立选最低再相加。

### surcharges：普通境内附加

必填 `cycle`、`period_sales`（符合教育附加门槛定义的全期不含税销售额/营业额）、`city_base`、`education_base`、`local_education_base`、`city_rate`（0.07/0.05/0.01）、`six_taxes_eligible`。

完整月/季；三项基数分别完成进口/境外、免抵、留抵退税等调整，不能直接复制主营收入或增值税销项。不处理跨地区分配和其他专项减免；本地费率/免征适用均已确认。教育附加门槛是**≤10万/30万**，城建税不随该门槛免征；符合六税两费资格再减半，资格与当期所得税小微预判不直接互抄。

### stamp：两种常见印花税

必填 `item`（goods_contract / capital_books）、`taxable_amount`、`six_taxes_eligible`。

动产买卖合同仅普通应税企业合同；计税金额只扣单列增值税，无单列则不能自行按税率除。资金账簿仅实收资本/股本与资本公积的尚未缴税增加额。其他合同、产权、证券交易或其他专项免税另算。减半按净应缴额四舍五入，减免额由原税额与净税额之差给出；仍须核对正式表舍入。

## 输入之外必须保留

公司和资料来源、政策本次核验、税种认定/资格证据、调整明细、申报表版本和差额说明。JSON计算成功只能证明输入满足已实现算法，不能证明原始账务完整、政策适用或已申报。
