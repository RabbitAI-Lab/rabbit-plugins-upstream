# 办税流程

## 建档和对账

沿用已知信息，补齐：名称/税号（可脱敏）、法律主体、省市区/主管局、行业、成立时间、会计准则、征收方式、纳税资格生效日、逐税种周期、优惠证据。明确首次/预缴/汇算/更正及所属期。

收集销项/进项/红字清单、未开票收入、合同履约、银行/支付流水、科目余额/利润表、费用/资产、实际发放工资及扣除、上期申报/缴款/留抵/亏损台账。仅收必要敏感信息。

1. 票号/主体/金额查重，关联合同、支付、记账；OCR不清及金额不平待核实。
2. 核对“开票+未开票+视同交易±跨期调整”与申报销售额，解释和会计收入的差异。流水入账不等于收入，资本金/借款/往来款须区分。
3. 核实可抵进项、用途、所属期、转出、留抵；不能全部采购税额直接抵扣。
4. 所得税列账税差异、亏损年度及期限、优惠、抵免；人数资产用规定平均值，不用年末值替代。
5. 工资税核对居民身份、实际支付、任职月数、累计扣除及已扣、入离职/跨单位；有工资凭证不直接等于已支付，扣除不重复。
6. 免税、亏损、留抵、无应补税不等于零申报或无需申报。零申报判断需完整资料。

## 计税与映射

按税种建底稿，区分当期/累计/年度；输入口径见calculator.md。输出JSON不是官方导入格式。

| 税种 | 常见入口/表单 | 核对内容 |
|---|---|---|
| 增值税及附加 | 当前一般/小规模申报表 | 分税率销售额、免减、进销项/转出、留抵/预缴、附加基数/优惠 |
| 所得税预缴 | A200000等当期表 | 累计实际利润额及调整、小微指标、减免、已预缴 |
| 所得税汇算 | A100000及相关附表 | 调整、亏损、优惠、抵免及已预缴 |
| 工资/奖金 | 自然人电子税务局扣缴申报 | 人员、所得类、累计扣除/预扣、奖金选择 |
| 个税汇算 | 综合所得年度自行申报 | 全年收入额、扣除、减免、已缴及奖金选项 |
| 印花税 | 财产行为税税源及综合申报 | 税目、凭证日期、计税额、税率、减免 |

不固定旧表行号。取当前官方模板/页面，记录表版本、字段标签、来源单元格、公式、底稿值、预填值、差额及处理。缺模板先交通用底稿，不造“官方导入文件”。

## 政策与期限

本次policy_review列文号、条款、URL、访问日期、有效期、适用性，检索修改/废止/当地补充。无法在线核验区分缓存与本次查证；影响税额的冲突先查清，同时继续其他资料。

期限依据法定周期、年度征期通知、当地延期及税局待办；所属期与申报月不同，年度汇算/清算/按次另查。仅在用户要求提醒时再用日程或自动化功能，技能不自行建立监控。

## 提交与归档

先备齐可审阅的主体、所属期、表单、税额、优惠、差异及版本。真实提交须符合用户明确授权，用真实官方渠道/已授权软件，复核页面主体/期别/金额。已有授权不重复询问；新差异先说明。提交结果不明先查状态，再决定是否重试。

保存申报前快照、授权范围、回执编号/时间/状态、缴款状态。缴款/退款须有对应授权。生成≠填报≠受理≠缴款。按主体/所属期归档原件副本、标准化数据、输入/输出JSON、政策核验、表单、差异及回执；更正保留版本与前后差异。
