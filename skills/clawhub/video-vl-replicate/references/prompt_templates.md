# 二创爆款文案 Prompt 模板

本文件提供两个 prompt 模板，配合 `analysis.json` 使用，完成"爆款公式提炼 → 二创文案生成"两步。LLM 在 Step 3 加载本文件后按以下流程执行。

---

## 模板一：爆款公式提炼

### 用途

分析 `analysis.json`，拆解原视频的爆款结构，输出一份"爆款公式报告"。这是生成二创文案的前置步骤。

### 输入

`analysis.json` 的以下字段：
- `timeline`：视听时间线（narration 旁白 + subtitle 字幕 + frame 画面）
- `full_text`：完整转录文本
- `duration`：视频时长

### 分析维度

按以下 7 个维度逐项分析，每个维度给出"原视频做法"与"判断依据（引用时间线条目）"：

1. **钩子（0-3秒）**：开场如何抓住注意力？
   - 类型：悬念/冲突/反常识/痛点/利益承诺/情绪冲击
   - 引用 timeline[0]

2. **核心冲突**：视频制造了什么矛盾或痛点？
   - 是认知冲突（打破常识）还是需求冲突（痛点 vs 解决方案）

3. **信息节奏**：信息密度如何变化？
   - 快节奏（密集输出）还是慢铺垫（情绪累积）
   - 标记节奏拐点（哪个时间点开始加速/反转）

4. **价值锚点**：给观众的核心价值是什么？
   - 实用干货 / 情绪共鸣 / 身份认同 / 好奇满足

5. **反转/收尾**：结尾如何处理？
   - 反转型 / 总结型 / 开放型 / CTA 型

6. **互动引导（CTA）**：是否有明确的互动钩子？
   - 评论区/点赞/关注/收藏/转发，具体话术

7. **情绪曲线**：整体情绪走向
   - 例如：好奇 → 紧张 → 释然，或 共鸣 → 焦虑 → 解决

### 输出格式

```markdown
## 爆款公式报告

**视频概要**：[一句话总结视频内容]
**总时长**：[duration]s
**语言**：[language]

### 1. 钩子
- 类型：[类型]
- 做法：[具体描述]
- 依据：[timeline 条目]

### 2. 核心冲突
[冲突类型与描述]

### 3. 信息节奏
- 整体节奏：[快/慢/混合]
- 拐点：[时间点 + 变化]

### 4. 价值锚点
[价值类型与内容]

### 5. 反转/收尾
[结尾类型与效果]

### 6. 互动引导
[有/无，具体话术]

### 7. 情绪曲线
[情绪走向序列]

### 爆款公式总结
[一句话公式：钩子(X) → 冲突(Y) → 价值(Z) → 结尾(W)]
```

## 模板二：二创文案生成

### 用途

基于模板一的"爆款公式报告"，生成 3 个版本的二创文案。

### 生成原则

1. **保留公式骨架，替换内容外壳**：保留钩子类型、节奏结构、CTA，但主题/场景/表达全部替换
2. **本土化与差异化**：避免与原视频雷同，换场景或换视角
3. **平台适配**：默认按短视频（15-60秒）输出，标注适用平台

### 输出三个版本

#### 版本 A：同主题换角度
- 保留原视频主题，从另一个视角/人群切入
- 适用场景：原主题流量已被验证，换角度可二次收割

#### 版本 B：同公式换场景
- 保留爆款公式结构，迁移到完全不同的领域/场景
- 适用场景：公式可迁移性强，跨领域复用

#### 版本 C：同结构换表达
- 保留叙事结构，用完全不同的语言风格（如口语化/书面化/段子化）
- 适用场景：同领域内容需要风格差异化

### 每个版本的输出格式

```markdown
### 版本 X：[版本名]

**目标主题**：[主题]
**适用平台**：[抖音/视频号/小红书/B站]
**预计时长**：[Xs]
**差异化策略**：[一句话说明与原视频的区别]

#### 完整文案（带分镜）

[0-3s | 钩子]
[文案]
[画面提示]

[3-15s | 铺垫]
[文案]
[画面提示]

[15-40s | 主体]
[文案]
[画面提示]

[40-55s | 反转/收尾]
[文案]
[画面提示]

[55-60s | CTA]
[文案]
[画面提示]

#### 爆款要素对照
| 要素 | 原视频 | 本版本 |
|------|--------|--------|
| 钩子 | [原做法] | [本做法] |
| 冲突 | [原] | [本] |
| 价值 | [原] | [本] |
| 结尾 | [原] | [本] |
| CTA | [原] | [本] |
```

---

## 执行流程

LLM 收到"生成二创文案"指令后：

1. 读取 `analysis.json`，确认 timeline 非空
2. 执行**模板一**，输出爆款公式报告
3. 基于公式报告，执行**模板二**，输出 3 个版本文案
4. 三个版本输出完毕后，追加一段"使用建议"：
   - 哪个版本最适合当前平台
   - 哪个版本改动最小可快速出片
   - 哪个版本风险最高（可能踩限流词）

---

## 调优提示

- 若 `analysis.json` 的 `timeline` 中 `narration` 普遍为空（纯音乐/画面型视频），改为依赖 `subtitle` 与 `frame_time` 分析节奏
- 若 `full_text` 过短（< 50 字），说明是画面驱动型爆款，重点分析帧时间分布推断节奏
- 若 OCR 字幕与 whisper 旁白重复度高，以 whisper 为准（OCR 可能抓到的是同一段台词）
- 生成文案时避免直接复制原视频的金句，需改写
