## Description:

Wan3.0 视频生成与编辑 helps creators generate or edit videos from text, images, video, or audio through AI Hive, with support for task submission, progress checks, and downloading completed media.

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: Broad activation text may surface the skill during general tool comparisons, ecommerce planning, or ad-platform questions where the user did not intend to generate video.

Mitigation: Confirm the user wants to run Wan 3.0 video generation before uploading media or submitting a task.

Risk: The workflow uses an AI Hive API key, uploads selected local media, saves outputs locally, and may incur AI Hive charges.

Mitigation: Confirm the media files, output location, task count, routing choice, and expected cost before execution.
