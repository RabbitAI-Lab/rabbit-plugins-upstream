## Description:

Creates, inspects, and edits Microsoft PowerPoint PPTX presentations with layout-focused automation support.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, automation users, and business teams use this skill to create, inspect, and edit PowerPoint decks while checking layout and execution status.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may read and modify presentation-related files and run local commands during PPTX work.

Mitigation: Use it in a limited project folder with only the files needed for the task.

Risk: Generated or edited decks may contain layout, content, or formatting mistakes.

Mitigation: Review generated decks and edited files before sharing or publishing them.
