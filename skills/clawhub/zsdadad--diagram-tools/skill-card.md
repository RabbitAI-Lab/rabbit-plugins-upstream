## Known Risks and Mitigations:

Risk: Generated Mermaid, Graphviz, or related render commands may be adapted to write files into a project directory.

Mitigation: Review generated diagram code and commands before running them, especially when output paths or project files are involved.

Risk: The skill documentation is primarily Chinese-language guidance.

Mitigation: Use it when Chinese-language diagram guidance is acceptable for the workflow, or review translations before relying on generated content.
