# 极鲸云 Shopee 店铺研究 Skill

按站点和店铺 ID 查询 Shopee 店铺详情，并结合店铺商品样本分析销量、销售额、粉丝、商品规模、跨境属性和类目。

当前不支持按店铺名称搜索，也不提供订单、广告、佣金、履约指标或 Seller Centre 操作。

## 安装 / 更新

```text
安装这个Skill: https://github.com/geekbi/geekbi-shopee-shop-search-skill
```

## 示例

```text
分析这个 Shopee 菲律宾站店铺的销售表现、商品结构和跨境属性。
```

```text
查询该店铺的前 100 个商品样本，分析价格带和头部商品贡献。
```
