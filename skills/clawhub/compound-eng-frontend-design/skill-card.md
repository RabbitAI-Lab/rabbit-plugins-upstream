## Description: <br>
Visual design and aesthetic direction for frontend interfaces, including web pages, landing pages, dashboards, Next.js server components, and applications where visual identity matters. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineers use this skill to plan, implement, and verify distinctive frontend interfaces while respecting existing design systems, mobile behavior, interaction states, and performance constraints. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Opinionated frontend design guidance can conflict with localized products or strict existing design systems. <br>
Mitigation: Give project language, i18n keys, accessibility requirements, and established design-system conventions priority over the skill's default preferences. <br>
Risk: Source inspection alone can miss visual layout, responsive, and interaction-state defects. <br>
Mitigation: Verify changed interfaces in a rendered browser at narrow and wide viewports and exercise loading, empty, error, and active states before completion. <br>
