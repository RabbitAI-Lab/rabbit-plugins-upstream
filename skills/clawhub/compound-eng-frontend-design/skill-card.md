## Description:

Provides visual design and aesthetic direction for frontend interfaces, including web pages, landing pages, dashboards, and applications.

This skill is ready for commercial/non-commercial use.

## Publisher:

[iliaal](https://clawhub.ai/user/iliaal)

### License/Terms of Use:

MIT-0

## Use Case:

Frontend developers and designers use this skill to choose a visual direction, build or redesign interfaces, and check responsive layout, interaction states, and accessibility considerations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Suggested frontend changes or dependencies may not fit the project's design system or requirements.

Mitigation: Review proposed code and installation commands against existing project conventions before applying them.

Risk: Visual or accessibility claims may be unverified when browser checks are unavailable.

Mitigation: Check narrow and wide rendered views, interaction states, keyboard focus, and motion preferences; clearly flag checks that could not be performed.
