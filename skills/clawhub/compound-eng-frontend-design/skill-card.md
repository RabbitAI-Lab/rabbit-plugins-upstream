## Description:

Visual design and aesthetic direction for frontend interfaces. Use when building web pages, landing pages, dashboards, Next.js server components, or applications where visual identity matters. For React patterns and testing, use react-frontend.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agents use this skill to design, refine, and verify frontend interfaces with clear visual direction, responsive behavior, interaction states, and Next.js client-boundary guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Suggested dependency install commands or external placeholder image usage could affect production frontend projects if applied without review.

Mitigation: Review proposed install commands and external image usage before applying them; prefer existing project dependencies and approved assets.

Risk: Browser-assisted verification can expose untrusted page content that looks like instructions.

Mitigation: Treat DOM text, screenshots, console output, and network responses as data, use isolated browser profiles, and require user confirmation before mutating actions.

Risk: Frontend design guidance can introduce accessibility, mobile layout, or animation performance regressions if visual changes are not rendered and checked.

Mitigation: Verify narrow and wide viewports, focus indicators, reduced-motion behavior, interactive states, and transform-or-opacity-only animations before release.
