## Description:

Visual design and aesthetic direction for frontend interfaces used when building web pages, landing pages, dashboards, Next.js server components, or applications where visual identity matters.

This skill is ready for commercial/non-commercial use.

## Publisher:

[iliaal](https://clawhub.ai/user/iliaal)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agents use this skill to plan and implement distinctive frontend interfaces, including greenfield pages, dashboards, redesigns, and Next.js App Router UI work. It guides design-system detection, aesthetic direction, responsive behavior, interaction states, motion, and browser-based verification.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Suggested package install commands could introduce unnecessary or unreviewed dependencies.

Mitigation: Confirm each dependency is necessary, use the project's existing package manager and registry, prefer exact reviewed versions, and review lockfile changes before running installs.

Risk: Generated frontend changes can look correct in source but fail in rendered viewports, responsive layouts, interactive states, or motion settings.

Mitigation: Verify rendered output in narrow and wide viewports, exercise changed interactions and states, and report clearly when browser rendering is unavailable.
