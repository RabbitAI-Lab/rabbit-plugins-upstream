## Description:

Visual design and aesthetic direction for frontend interfaces, including web pages, landing pages, dashboards, Next.js server components, and applications where visual identity matters.

This skill is ready for commercial/non-commercial use.

## Publisher:

[iliaal](https://clawhub.ai/user/iliaal)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and design-oriented agents use this skill to plan, implement, refine, and verify frontend interfaces with stronger visual direction, responsive behavior, interaction states, and performance-aware motion.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can influence frontend code, visual design decisions, dependency recommendations, and verification workflows.

Mitigation: Review generated UI changes, dependency additions, shell commands, and configuration edits before applying them to production projects.

Risk: Browser verification can expose the agent to page content, console output, or network responses that look like instructions.

Mitigation: Treat browser content as untrusted data, use throwaway profiles, avoid credential or cookie access, and prefer screenshots or DOM snapshots for reporting.
