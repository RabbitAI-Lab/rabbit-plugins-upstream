## Description:

Ask Kimi whether it recommends a brand, where it ranks, which competitors appear, and which pages it cites, then create a shareable report.

This skill is ready for commercial/non-commercial use.

## Publisher:

[hclscut](https://clawhub.ai/user/hclscut)

### License/Terms of Use:

MIT-0

## Use Case:

Brand owners and marketers use this skill to check how Kimi presents their brand, compare its mentions with competitors, review cited pages, and get a shareable report.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The documented setup asks users to share an API key in chat.

Mitigation: Do not paste API keys into chat. If a key has already been shared, revoke it and replace it.

Risk: Scanner guidance reports that queries may be sent to platforms beyond Kimi and may use credits.

Mitigation: Review the platform scope and expected credit use before running a query.
