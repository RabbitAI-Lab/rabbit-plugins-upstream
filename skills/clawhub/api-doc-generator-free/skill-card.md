## Description: <br>
Generates OpenAPI 3.0 API documentation and Markdown API manuals from code comments, API signatures, or natural-language interface descriptions, with RESTful naming checks. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[thcjp](https://clawhub.ai/user/thcjp) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, independent builders, and engineering teams use this skill to draft or refresh REST API documentation for integration, webhook, and system-connection workflows. It is intended for user-provided API descriptions, code snippets, or interface signatures, not for reverse engineering closed-source APIs. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The security scan reports broad command-execution capability and unclear credential or network-diagnostic guidance. <br>
Mitigation: Review the skill before installing, avoid providing real secrets, and require confirmation before any shell or network command. <br>
Risk: Generated API documentation may contain inaccurate schemas, examples, or REST guidance when the input is incomplete or ambiguous. <br>
Mitigation: Review generated OpenAPI and Markdown output against the actual service implementation before publishing or using it for integration work. <br>
