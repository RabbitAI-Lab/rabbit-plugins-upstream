# Ozon 商品研究

1. 先按关键词或可信类目 ID 宽筛，明确使用 SKU 还是 SPU 口径。
2. 需求至少交叉销量、销售额、评论、趋势和更新时间；竞争至少看店铺、跟卖报价、同款数、品牌和上架时间。
3. 对候选查详情，核验价格、库存、履约、包装、佣金带、历史和数据来源。
4. 使用 7/28 天 Seller Analytics 字段时，必须确认对应窗口与来源；未返回的指标显示 `-`。
5. 新品、热销、五星和增长榜只代表预设条件，不等于低竞争或可盈利。
6. 只有响应提供 `goodsUrl` 时才把商品名做成链接，不拼接地址。

输出：结论、站点/币种、筛选与排序、总命中、实际样本、关键候选、风险、置信度和验证动作。
