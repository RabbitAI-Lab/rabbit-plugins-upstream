## Description:

Generates or edits Seedream 5.0 Lite commercial images with short Chinese or English text, using character budgets, manual proofreading, and fallback layout guidance to improve text accuracy.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and marketing image-production teams use this skill to generate or edit short-copy posters, product cards, packaging concepts, invitations, and social covers, then manually proofread generated text before use.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected reference images are sent to AI Hive for generation or editing.

Mitigation: Use only prompts and reference images that are approved for that service, and avoid uploading sensitive or restricted content unless authorized.

Risk: Generated image text can contain wrong, extra, mirrored, or obscured characters.

Mitigation: Transcribe and compare every character against the approved text; for accuracy-sensitive text, generate a text-free base image and add approved copy in a layout tool.

Risk: API keys may be stored locally for repeated use.

Mitigation: Protect AI Hive credentials like other secrets; the helper stores keys in a 0600 config file and also supports environment variables or one-time command-line keys.

Risk: Regulated, legal, pricing, ingredient, date, model, packaging, or promotional claims may be misleading if generated by the model.

Mitigation: Treat approved copy as the sole source of truth and require human final review before using those claims.
