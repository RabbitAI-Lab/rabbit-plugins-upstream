## Use Case:

Developers, site operators, and SEO teams use this skill to inspect Bing link data, compare registered Bing properties, submit fresh URLs through IndexNow, and verify IndexNow configuration for Bing-index visibility.

## Known Risks and Mitigations:

Risk: Credential exposure or overbroad API access could affect sites managed through Bing Webmaster Tools or IndexNow.

Mitigation: Use API keys limited to the sites intended for management and avoid sharing keys across unrelated properties.

Risk: Installer behavior could configure unexpected environment values for Bing or IndexNow.

Mitigation: Review any referenced installer script before use and confirm it only sets the expected Bing and IndexNow environment values.
