## Known Risks and Mitigations: <br>
Risk: The skill requests broad command and file permissions despite being mostly a workflow guidance skill. <br>
Mitigation: Install and run it only where command execution and file writes are expected, and inspect any proposed command or file change before execution. <br>
Risk: The artifact describes create, export, callback, invoice, account-connection, and external automation behavior without clear operational boundaries. <br>
Mitigation: Require explicit user approval and review exact targets before creating records, exporting data, posting content, connecting accounts, creating invoices, or enabling callbacks. <br>
