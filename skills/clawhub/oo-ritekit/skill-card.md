## Description:

RiteKit lets an agent run OOMOL-connected RiteKit hashtag operations through the oo CLI.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

Marketing, social media, and developer users can use this skill to enrich post text with hashtags, inspect hashtag engagement, find trending hashtags, clean blocked Instagram hashtags, and request hashtag suggestions from text, public image URLs, or public webpage URLs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup guidance includes remote installer commands that execute downloaded code.

Mitigation: Review the official installer or use a verified package or release path before running first-time installation commands.

Risk: RiteKit actions depend on an OOMOL-connected account and server-side credentials.

Mitigation: Install only when use of OOMOL's oo CLI with the connected RiteKit account is acceptable for the deployment environment.
