# 优稿技能：安装与使用

Skill 让 AI 助手调用你的优稿账户完成文章任务。把技能交给支持技能的 AI 工具安装，运行环境检查和连接准备由助手处理；你无需提前安装 Python 或操作命令行。

## 选一个适合你的技能

| 目录 | 用途 | 输入 | 结果 | Key 权限 |
| --- | --- | --- | --- | --- |
| yougao-write | 文章生成 | 主题、风格、参考资料 | 文章与新稿件 | generation |
| yougao-rewrite | 文章改写 | 原稿、改写要求 | 独立候选稿 | rewriting |
| yougao-detect | AI 率检测 | 原文 | 真实检测报告 | detection |
| yougao-format | 智能排版 | 正文或稿件、主题 | HTML / TXT | formatting |
| yougao-workflow | 创作流程 | 保存的流程、主题/原文/链接 | 分步结果与稿件 | 已启用步骤的全部权限 |
| yougao-publish | 发布接续 | 稿件版本、平台账号和方式 | 发布任务及真实状态 | publishing |

可以只安装需要的技能。每个目录自带同版本客户端与 API 手册，不依赖其他技能。

## 安装与连接

1. 将单个技能 ZIP 导入你使用的 AI 工具，或让助手安装。建议先试公众号排版，再装检测、改写或工作流。总包需解压后分别安装，不能把六个目录当成一个技能。例如 WorkBuddy 可从「专家·技能·连接器」→「技能」→「添加技能」→「上传技能」导入。
2. 在优稿「AI 接入」或「我的 API Keys」点击「复制给 AI」，直接粘贴给你信任的助手。新用户注册自动获得默认永久密钥，可随时再次复制或撤销；也可以新建其他权限的密钥，有效天数留空就是永久。不需要额外寻找凭据设置，请勿公开分享含密钥的内容。
3. 直接提供主题、原稿或链接，说明要完成的任务。例如：

> 使用 $yougao-format，将以下正文排成暖调风格并导出 HTML。

> 使用 $yougao-workflow，列出我的已保存流程；按我选定的流程和保存预算处理这段内容。

每个技能的 `SKILL.md` 中都有专属输入、输出、权限和调用示例。

六个技能在同一电脑、同一系统用户下共用一次连接，无需重复填 Key。助手会交付文章/HTML/检测报告等实际文件和优稿编辑链接。中断后沿原任务接续，下载已有结果不再次扣点。更换电脑或独立沙箱需重新连接。

本下载提供可导入的自定义技能包，不表示已经在 WorkBuddy/SkillHub 市场公开上架。排版在优稿的服务费以实际预览为准，AI 工具自身的费用另计。

默认不设单次费用和会员额度上限，按账户实际余额及权益结算。如需限制，可在流程费用设置中填写上限，或直接告诉助手；填 0 表示不使用对应余额或额度。

## 常见问题

- 找不到技能：检查目录层级、助手的技能目录配置，再重新加载。
- 提示尚未连接：让助手检查已绑定的站点和 Key。本机地址只适用于当前电脑，远程助手需要可访问的 HTTPS 站点。
- 401：Key 错误、已过期或撤销；403：缺少所需工具权限；429：按 Retry-After 等待。
- 计划不可执行：读取 issues；检查输入、工具开放状态及预算。预览不扣费，执行按授权预算结算。
- 任务等待或结果未知：查询原运行，保留编号，不新建任务绕过问题。
- 发布停在等待设备：保持对应 PC 客户端运行，并登录目标平台。流程开启自动提交且设备、账号就绪时会继续，无需逐篇确认。API 不唤醒离线设备；已提交不代表已公开。

API、网页和技能共用账户、余额及会员权益。安装更多技能或创建更多 Key 不增加账户额度。
