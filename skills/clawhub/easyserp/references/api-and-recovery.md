# API and recovery reference

The service endpoint is `https://serp.skyvora.cc`; search is `POST /api/v1/search` with a bearer API key. The console root is the only verified onboarding URL: open it, select registration, then use API keys. Do not invent a registration deep link.

Inputs: `q` is 1–200 characters; `engine` is `google|bing`; `region` is one of `US|GB|CA|AU|DE|JP|BR|CN` and defaults to US; `device` is `desktop|mobile` and defaults to desktop. Idempotency keys are 8–128 characters. `wait_ms` is 0–30000 (omitted means 30 seconds), `max_attempts` is 1–3, and optional `channel` is at most 64 bytes. Both engines support `count` (10–50, default 10), `start` (0–10000), and `cursor`. Google cursor is a zero-based next-page start (0–10000); Bing cursor is the next-page first value (1–10001). The API JSON field is a string; the SDK accepts an integer and normalizes it to a string. When `start > 0`, Google requires `cursor == start`, while Bing requires `cursor == start + 1`. `resolve_urls` is Google-only. `gl` and `hl` are supported by both engines; locale values are limited to 16 bytes. Bing `mkt` uses `language-country` such as `zh-CN`, `hl` is a 2–3 letter language code such as `zh`, and `cc`/`gl` must match `region`. The SDK/CLI rejects Google `mkt`/`cc` and Bing `resolve_urls`. Batch size is at most 100; concurrency is 1–32.

HTTP 200 contains `request_id`, `status: succeeded`, organic results and other returned result fields, `charged`, `server_duration_ms`, and `search_parameters`. Preserve returned results as-is. HTTP 202 or 504 with `error.code: request_pending` and `status: queued|running` is pending, not a terminal result.

Identical payload + identical idempotency key resolves to the same request. Reusing a key with a changed payload returns 409. A transport timeout alone does not reveal settlement. Successful searches are charged once; failed searches release the reservation. `GET /api/v1/requests/{id}` requires requests scope. There is no balance endpoint. The low-level SDK `.search()` does not poll or retry automatically; the user-facing CLI uses a bounded recovery workflow (up to three attempts by default) and preserves request/recovery history. It does not treat a pending receipt as a settled failure or silently create a fresh request.

The product supports 2000 QPS. Registration grants 1000 searches once, not monthly; subsequent usage is ¥2 per 1000 searches. Do not state benchmark results or SLA terms that have not been supplied.
