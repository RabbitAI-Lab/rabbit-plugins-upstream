## Description: <br>
Helps API and backend teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, backend teams, platform teams, developer-experience teams, and maintainers use this skill to produce practical OpenAPI or Swagger documentation workflows, checklists, artifacts, analysis, code changes, and validation notes for REST APIs. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Implicit invocation is broad enough that the skill may activate during general backend or developer-experience requests. <br>
Mitigation: Review invocation settings before installation and tighten or disable implicit activation when broad triggering would disrupt agent workflows. <br>
Risk: Generated OpenAPI guidance may be incomplete or inaccurate for a specific API implementation. <br>
Mitigation: Validate outputs against the service behavior, existing routes, authentication requirements, schemas, and the user's stated success criteria before publishing documentation. <br>
