## Description: <br>
Creates distinctive production frontend interfaces by guiding agents through three visual directions, font pairing, CSS variable color systems, and CSS-only motion. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[thcjp](https://clawhub.ai/user/thcjp) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and designers use this skill to prompt an agent to create distinctive HTML/CSS frontend interfaces while avoiding generic AI-looking layouts, fonts, and palettes. It is intended for quick interface generation using three supported aesthetics: brutally minimal, editorial or magazine, and brutalist or raw. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can be used by an agent with file-writing or command-execution tools. <br>
Mitigation: Review proposed file changes and shell commands before allowing execution. <br>
Risk: Callback URLs or API keys may be requested when a workflow intends asynchronous callbacks or external service access. <br>
Mitigation: Provide credentials or callback URLs only when that behavior is intended, and keep secrets out of version control. <br>
