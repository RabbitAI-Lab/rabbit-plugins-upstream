# 视频对口型

> 调用方式及异步轮询见 SKILL.md「调用方式」「异步任务轮询」

## 参数

```json
{
  "url": "https://cdn.example.com/ref_video.mp4",  // 必填：对口型参考视频，公网URL
  "text": "今天给大家分享一款...",                    // 必填：口播文案
  "gender": "男"                                     // 可选，默认 "男"："男" | "女" — 声音性别
}
```

## 关键约束

- ⚠️ `text` 不能含特殊字符和 emoji（如 `#`、`@`、表情符号），用户原文需先清理
