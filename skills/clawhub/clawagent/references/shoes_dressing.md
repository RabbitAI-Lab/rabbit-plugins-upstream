# 鞋靴试穿

> 调用方式及异步轮询见 SKILL.md「调用方式」「异步任务轮询」

## 参数

```json
{
  "url": "https://cdn.example.com/shoes.jpg", // 必填：鞋靴商品图，公网URL
  "type": "室外", // 可选，默认 null：室内 | 室外
  "scene": "高跟鞋", // 可选，默认 null：高跟鞋 | 高跟凉鞋 | 中跟鞋 | 马丁靴 | 运动鞋 | 罗马鞋 | 小白鞋 | 短靴 | 中筒靴 | 帆布鞋
  "prompt": "阳光明媚的街道" // 可选，默认 null：画面背景和氛围描述
}
```

## 关键约束

- `type` 和 `scene` 语义完全不同，容易搞反：
  - `type` = 场景类型（室内 / 室外）
  - `scene` = 鞋子类型（高跟鞋、运动鞋...）
