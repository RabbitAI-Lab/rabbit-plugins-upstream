# 商品场景图

> 调用方式及异步轮询见 SKILL.md「调用方式」「异步任务轮询」

## 参数

```json
{
  "url": "https://cdn.example.com/product.jpg",  // 必填：商品图，公网URL
  "type": "美妆护理",                              // 可选，默认 null：大型家电 | 厨房小电 | 生活电器 | 美妆护理 | 家居日用 | 母婴用品 | 数码产品 | 户外装备 | 家居家具 | 潮流配饰
  "scene": "手持",                                 // 可选，默认 null，必须与 type 匹配（见下方映射）
  "ratio": "3:4",                                  // 可选，默认 3:4：21:9 | 16:9 | 4:3 | 1:1 | 3:4 | 9:16 | 9:21
  "prompt": ""                                     // 可选，默认 null：自定义生成描述
}
```

## type × scene 映射

不同商品类型只支持特定场景，传错组合会失败：

| type | scene 可选值 |
|------|-------------|
| 大型家电、家居家具 | 厨房、阳台、客厅 |
| 美妆护理、户外装备 | 手持、户外 |
| 生活电器、厨房小电 | 小家电 |
| 家居日用 | 装饰品、置物架、茶具 |
| 母婴用品 | 婴幼用品、玩具 |
| 潮流配饰 | 皮包、挎包、手提包 |
| 数码产品 | 手持、小家电 |

## 关键约束

- `type` 和 `scene` 都是可选，但一旦传了就必须匹配。建议两个都传以获得最佳效果
