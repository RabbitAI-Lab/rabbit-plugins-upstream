# 生产管理周报格式规范（HTML版）

## 概述
本规范定义生产管理周报的HTML网页格式，用于智能体生成统一结构的周报输出。

## 周报结构（6章节）

### 1. 本周概况
- 一句话总结本周整体情况
- 核心指标卡片（产量/良率/OEE/交付率）
- 状态标识（达标/接近/未达）

### 2. 生产数据
- 各产线产出表格
- 数据分析说明

### 3. 完成事项
- 已完成事项清单（带勾选图标）
- 进行中项目清单（带进度说明）

### 4. 异常与问题
- 本周新增异常卡片
- 遗留问题追踪区域

### 5. 下周计划
- 待办事项清单
- 预计产出指标

### 6. 需协调事项
- 协调事项表格
- 优先级标识

## 数据要求

### 最低门槛（必须满足）
1. **核心指标**: 至少1项（产量/良率/OEE/交付率等）
2. **完成事项**: 至少1条
3. **下周计划**: 至少1条

### 禁止行为
- 禁止编造任何数据
- 禁止填充模糊占位内容（如"待补充"）
- 数据不足时必须拒绝生成

## 输出路径
- 周报保存至：`./weekly_reports/{YYYY}-W{周次}.html`
- 历史归档：`./weekly_reports/history/{YYYY}-W{周次}.html`

## HTML特性
- 样式内嵌，无需外部资源
- 响应式布局，支持移动端查看
- 支持浏览器打印为PDF
- 渐变色头部设计
- 状态标签颜色区分
