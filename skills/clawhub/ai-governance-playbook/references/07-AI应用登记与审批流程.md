# 07 AI 应用登记与审批流程

> 用途：回答「AI 应用怎么登记」「审批流程怎么走」「供应商 AI 能力怎么评估」。配套本地工具 `registry` 命令生成登记表。
> 核对基准日：2026-08-27

## 1. 为什么要有登记台账

没有台账 = 不知道公司在用什么 AI。影子 AI（Shadow AI）是最大治理盲区：员工私自接入的工具没有经过数据合规、安全、合同条款评估。登记台账让 AI 使用"看得见、管得住、可审计"。

## 2. AI 应用登记表（字段清单）

工具 `registry` 命令可一键生成 CSV 模板，字段如下：

| 字段 | 说明 | 必填 |
|---|---|---|
| 应用编号 | 如 AI-2026-001 | ✅ |
| 应用名称 | 工具/系统名称 | ✅ |
| 使用部门 | 申请部门 | ✅ |
| 使用场景 | 一句话描述用途 | ✅ |
| 使用方式 | 员工工具/嵌入业务系统/对外服务 | ✅ |
| 涉及数据级别 | 公开/内部/机密/个人信息（见 02 模块分级） | ✅ |
| 风险等级 | 低/中/高/禁止（见 03 模块） | ✅ |
| 供应商/产品 | 供应商名称、版本 | ✅ |
| 数据流向 | 数据是否出境、是否用于训练 | ✅ |
| 人工复核机制 | 是否有复核环节 | ✅ |
| 责任人 | 业务负责人 | ✅ |
| 审批状态 | 草稿/审批中/已批准/已驳回/已停用 | ✅ |
| 审批人 | 审批链上各节点 | ✅ |
| 内容标识 | 是否生成对外内容、是否做标识 | 涉生成时必填 |
| 备案/评估状态 | 是否需要算法备案/大模型备案/安全评估 | 涉对外时必填 |
| 复审日期 | 下次风险评估日期 | ✅ |

## 3. 审批流程（按风险等级分路）

```
申请提交（业务部门填写登记表）
      │
      ▼
合规初筛（合规/信息安全：数据级别、供应商条款、法规触发）
      │
      ├── 低风险 → 登记即用（台账记录，年度复审）
      │
      ├── 中风险 → 部门负责人审批 + 合规备案（半年度复审）
      │
      ├── 高风险 → AI 治理委员会审批 + 专项评估（季度复审）
      │
      └── 禁止级 → 直接驳回并记录
```

**审批要点**：
- 高风险应用必须附"风险评估表 + 数据合规核查 + 人工监督方案"三件套；
- 涉及个人信息/出境的：额外过数据合规审查（个保法、数据出境要求）；
- 审批记录留档，作为审计证据（至少保存与监管要求匹配的年限）。

## 4. 供应商 AI 能力评估表

当采购第三方 AI 工具/服务时，除常规采购评审外，增加以下 AI 专项评估：

| 评估项 | 关注点 | 通过标准（示例） |
|---|---|---|
| 数据处理 | 是否拿输入数据训练模型？存储在哪国？ | 明确不用客户数据训练（或合同限定） |
| 数据出境 | 是否跨境传输 | 符合数据出境合规要求 |
| 内容安全 | 生成内容是否合规、有无过滤 | 有内容安全策略与违规处置 |
| 标识能力 | 是否支持内容标识（中国/欧盟要求） | 支持显式+隐式标识 |
| 模型治理 | 供应商自身 AI 治理/安全测试 | 有安全测试与红队实践（如适用） |
| 合规认证 | 是否持 ISO 42001/27001 等 | 持证或可提供等效证据 |
| 审计支持 | 是否提供日志、可审计性 | 提供运行日志与审计接口 |
| 合同条款 | 责任分配、赔偿、数据权利 | 条款明确，含 AI 相关责任条款 |
| 退出机制 | 数据导出、迁移、删除 | 支持完整导出与删除（可验证） |
| 持续监控 | 供应商安全事件通报机制 | 有 SLA 与事件通报义务 |

## 5. 登记台账运营规范

- **入库**：新应用审批通过即入台账；
- **更新**：应用变更（版本、场景、数据）触发更新与复审；
- **盘点**：每半年全量盘点一次，清理停用应用；
- **报告**：台账 + 风险汇总进入 AI 治理季报；
- **审计**：台账、审批记录、风险记录作为合规审计证据统一归档。

## 6. 常见问题

- **Q：员工自己注册个免费 AI 工具算影子 AI 吗？** 算。治理重点不是"禁"，是"引导走登记通道"——把登记做成 5 分钟低门槛动作。
- **Q：登记了就不管了吗？** 登记只是入口，后续按风险等级复审 + 监控（见 03 模块义务矩阵）。
- **Q：SaaS 版 AI 和自建模型都要登记吗？** 都要。自建模型按系统全生命周期治理（01 模块 §3），SaaS 按供应商评估 + 数据流向评估。
