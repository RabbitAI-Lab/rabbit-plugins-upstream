# 09 常见问题 FAQ

> 用途：高频疑问速查 + 常见误区纠偏。回答「XX 情况怎么办」类问题时的首选入口。

## 1. 治理范围与定位

**Q：我们不是 AI 公司，也要做 AI 治理吗？**
看三个条件：员工是否大量使用生成式 AI、是否对外提供 AI 功能、是否处理敏感/个人数据。满足其一建议建立最小治理包（政策 + 登记 + 分级，见 08 模块）。即便都不满足，也建议给员工一份"一页使用守则"。

**Q：AI 治理和网络安全、数据合规是什么关系？**
三者有交集但不等同：网络安全管"系统不被攻破"，数据合规管"数据怎么合法处理"，AI 治理额外覆盖算法风险、内容标识、伦理责任、AI 特定决策影响。成熟企业把 AI 治理挂接在既有治理体系上（共享制度、组织、审计），而不是另起炉灶。

**Q：治理会不会拖慢业务、增加负担？**
设计得当的治理是"分级"的：低风险登记即用（5 分钟），只有高风险才走重流程。治理的价值是让创新在安全边界内快跑，而不是刹车。

## 2. 制度与执行

**Q：员工用个人手机上的 AI 应用处理工作，管得了吗？**
管得了也管不住：政策上明确"公司数据不得进未经批准工具"，执行上靠数据分级（02 模块 §4）+ 培训 + 登记引导。技术上可通过 DLP 监控公司设备/网络出口。

**Q：政策发布后员工不看怎么办？**
签署回执 + 入职/年度培训 + 抽查考试。最有效的是"出事案例复盘"——用真实（脱敏）事件讲清楚违规后果。

**Q：AI 生成的内容要标识吗？谁标识？**
中国：2025-09-01 起强制，服务提供者加显式+隐式标识，平台核验，用户发布时主动声明（04 模块 §3）。欧盟：2026-08-02 起透明度义务（05 模块）。企业内部使用一般无需对外标识，但对外发布必须标。

## 3. 风险评估

**Q：用 AI 写代码算高风险吗？**
分场景：辅助编码、人工 review → 低/中风险（关注代码机密性，别把私有代码库喂给公共工具）；AI 自动生成并直接上线的关键代码 → 高风险（需人工复核 + 测试）。

**Q：AI 客服算高风险吗？**
一般中风险：面向客户 + 可能出错，需人工审核兜底 + 内容安全过滤 + 明确告知"是 AI"。若客服涉及医疗、金融等专业建议，升级高风险。

**Q：什么情况必须上报/停用 AI 应用？**
出现数据泄露、生成违法/有害内容、歧视性结果、供应商安全事件、监管问询时，立即按事件流程处置（停用 + 上报 + 复盘）。

## 4. 合规速查

**Q：我们公司在中国，只做国内业务，要看欧盟 AI Act 吗？**
只看国内业务、不向欧盟提供 AI 服务/产品、不在欧盟部署 → 不受 AI Act 管辖。但若未来出海欧盟，管辖触发点很低（05 模块 §2），建议提前把治理体系建起来。

**Q：算法备案和大模型备案是一个东西吗？**
不是。算法备案针对算法推荐/深度合成/生成式服务（按服务类别备案）；大模型备案（上线备案）针对对外提供服务的生成式大模型；安全评估针对有舆论属性/社会动员能力的服务（04 模块 §4）。是否触发以"是否对外提供服务"为界。

**Q：用开源大模型本地部署，要备案吗？**
内部使用一般不触发备案；对外提供服务（含以 API 形式对外）则按生成式 AI 服务管理，需评估备案义务。

**Q：ISO 42001 认证贵吗？值得做吗？**
成本取决于公司规模和体系基础（有 ISO 27001 的企业成本最低）。是否值得看外部是否需要：客户/采购要求治理证据、投标加分、出海证明能力 → 值得；纯内部用 → 先用 NIST AI RMF 方法论，等需要时再认证（06 模块 §6）。

## 5. 工具使用

**Q：工具脚本安全吗？会联网吗？**
本地运行、零网络、零数据采集，只用 Python 标准库。输入（场景描述、公司名、评分）只在本机处理，不产生任何输出文件以外的数据。

**Q：工具生成的模板能直接用吗？**
能，但发布前请按公司实际情况修改（公司名、组织架构、数据分级清单、审批链），并由合规/法务复核——模板是起点不是终点。

**Q：命令报错怎么办？**
确认 Python 3.8+ 且路径正确（在 skill 根目录运行 `python tools/ai_governance_toolkit.py --help`）。任何输出为英文报错信息均可照抄反馈。

## 6. 内容时效

**Q：法规速查多久更新一次？**
随版本更新。中国/欧盟/美国法规变化频繁（尤其欧盟 Digital Omnibus 时间线、中国 2026 新规），引用关键结论前请以官方原文复核（各速查表头部已标注核对基准日）。

**Q：怎么跟踪法规变化？**
建立季度法规跟踪机制：中国（网信办、工信部、国标委官网）、欧盟（AI Act 官方实施时间线页、AI Office）、美国（NIST、各州立法）。把变化记入合规义务台账（08 模块）。
