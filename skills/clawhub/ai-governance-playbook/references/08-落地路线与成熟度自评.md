# 08 落地路线与成熟度自评

> 用途：回答「AI 治理 90 天怎么落地」「第一步做什么」「我们治理水平打几分」。配套本地工具 `maturity` 命令自动计分、`checklist` 命令输出行动清单。
> 核对基准日：2026-08-27

## 1. 90 天落地路线（最小可行治理 MVP）

> 面向"从零开始"的企业。已有体系的可跳过对应阶段。

### 第 1 阶段：摸底与立项（第 1-2 周）
- [ ] 盘点现有 AI 使用：员工问卷 + IT 侧扫描（哪些工具/服务在用）
- [ ] 识别"不能停的业务"与"高风险使用"（对照 03 模块场景库）
- [ ] 确定治理责任人（1 名）与跨部门支持小组（合规/IT/法务）
- [ ] 向管理层汇报风险现状，取得授权（一页纸报告即可）

**产出**：AI 使用摸底清单 + 治理立项决定

### 第 2 阶段：建制度与工具（第 3-5 周）
- [ ] 发布《员工 AI 使用政策》（用 02 模块模板，按公司情况修改）
- [ ] 建立 AI 应用登记台账（用 07 模块字段，Excel/系统均可）
- [ ] 建立风险分级标准（用 03 模块，先定公司自己的红线清单）
- [ ] 明确审批链（谁批低/中/高风险）

**产出**：政策已发布 + 登记台账已运行 + 审批链已生效

### 第 3 阶段：试点与清存量（第 6-8 周）
- [ ] 存量 AI 应用分批补登记（按风险从高到低）
- [ ] 高风险存量应用优先补评估：数据合规核查 + 人工监督方案
- [ ] 处理"影子 AI"：白名单 + 禁入清单 + 引导登记
- [ ] 全员培训（30 分钟，讲守则 + 数据分级 + 上报渠道）

**产出**：存量台账完整 + 高风险应用已管控 + 全员知晓守则

### 第 4 阶段：运转与固化（第 9-13 周）
- [ ] 首次治理季报（台账统计 + 风险分布 + 事件报告）
- [ ] 首次成熟度自评（本模块 §3），定下季度改进目标
- [ ] 建立法规跟踪机制（中国/欧盟/美国，随 04/05/06 速查更新）
- [ ] 复盘制度执行情况，修订政策（版本 v1.1）

**产出**：治理闭环运转 + 首份季报 + 下季度改进计划

## 2. 里程碑判断标准

| 里程碑 | 达成标志 |
|---|---|
| MVP 建成 | 政策 + 台账 + 审批链三件套齐全并运行 |
| 风险受控 | 全部存量应用已分级，高风险应用有专项评估 |
| 体系化运转 | 季度 PDCA 闭环 + 自评 ≥ 24 分（见下） |
| 认证级（可选） | 启动 ISO 42001 差距分析（对照 06 模块） |

## 3. 成熟度自评表（6 维度，1-5 分）

| 维度 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|
| **组织**：治理责任与决策机制 | 无责任人 | 有责任人，委员会季度例会 | 委员会+授权机制+资源保障 |
| **制度**：政策与流程 | 无政策 | 有使用政策，审批流运转 | 政策版本化，年度评审，与业务联动 |
| **风险**：登记与评估 | 无台账 | 有台账，按级审批 | 全量登记+动态复审+风险评估标准化 |
| **合规**：法规义务跟踪 | 未跟踪 | 核心义务已识别（备案/标识） | 义务台账+定期更新+证据归档 |
| **技术**：安全与监控 | 无 | 有基础安全（权限/审计日志） | 监控告警+事件响应+持续评估 |
| **文化**：培训与上报 | 未培训 | 年度培训，有上报渠道 | 入职+年度培训，上报有闭环 |

**计分与解读**（工具 `maturity` 自动计分）：
- 总分 6-12：起步期——先做 90 天 MVP 的第 1-2 阶段
- 13-23：建设期——补短板维度，优先政策+台账
- 24-29：成型期——体系已运转，向认证级看齐
- 30-30：体系化——保持季度闭环，关注新规与新技术风险

## 4. 不同规模的落地策略

| 规模 | 策略 | 投入 |
|---|---|---|
| 小（<50 人） | 最小包：一页政策 + 登记表 + 责任人 | 1 人 × 2 周 |
| 中（50-500 人） | 标准包：完整政策 + 分级审批 + 季度复盘 | 1 专人 + 跨部门小组 |
| 大（>500 人） | 体系包：治理委员会 + ISO 42001 差距分析 + 工具化台账 | 专项团队 |

## 5. 常见失败模式（避坑）

1. **完美主义拖延**：想一步到位建完整体系，结果 6 个月没动——先从一页政策 + 一张登记表开始；
2. **只做制度不做台账**：政策挂在墙上，实际不知道谁在用 AI；
3. **合规与业务对立**：治理一刀切禁掉所有工具，业务反弹转入地下——给白名单 + 引导通道；
4. **忘记法规跟踪**：法规季度一变，速查表不更新等于裸奔（本技能速查表随版本更新，落地时请以官方原文复核）；
5. **自评自嗨**：自评要配证据（台账截图、审批记录），否则分数无意义。
