## Description:

Helps polish Chinese web fiction by identifying formulaic AI-style phrasing and revising it while preserving the author's plot and voice.

This skill is ready for commercial/non-commercial use.

## Publisher:

[worldwonderer](https://clawhub.ai/user/worldwonderer)

### License/Terms of Use:

MIT

## Use Case:

Authors and editors use this skill to check Chinese web-fiction drafts for formulaic language, revise prose without changing the story, and review suggested changes. It can also provide a detection-only report when requested.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: File-mode editing may change manuscript text or punctuation in ways the author did not intend.

Mitigation: Review changes against the original draft and keep a recoverable copy before editing files.

Risk: Optional author-preference memory retains writing preferences in local project files.

Mitigation: Use memory features only when intended and review the local .story/作者记忆 files periodically.
