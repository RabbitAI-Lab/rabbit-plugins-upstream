## Description:

诊断并修订网文中的表达、叙事用笔与故事因果问题，同时保留作者文风和已定剧情。

This skill is ready for commercial/non-commercial use.

## Publisher:

[worldwonderer](https://clawhub.ai/user/worldwonderer)

### License/Terms of Use:

MIT

## Use Case:

Chinese web fiction authors use the skill to identify and revise formulaic prose, scene pacing, and unsupported story transitions while preserving established plot and voice. It can return diagnosis only or edit manuscript text according to the requested scope.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Editing can change punctuation or remove passages judged redundant.

Mitigation: Choose detection-only mode for suggestions without edits, and retain the original manuscript backup before editing.

Risk: Optional delegated writing uses an agent outside this package's review, and host integration was not runtime-tested.

Mitigation: Review delegated changes in the host before accepting them into the manuscript.
