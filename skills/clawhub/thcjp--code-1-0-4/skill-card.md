## Known Risks and Mitigations: <br>
Risk: This broad coding-helper skill may read project files and propose or run shell commands. <br>
Mitigation: Review commands before execution and apply normal least-privilege controls for local project access. <br>
Risk: Development and deployment tasks can involve credentials or sensitive configuration. <br>
Mitigation: Do not place real API keys in project files or chat unless needed, and keep secrets out of version control. <br>
