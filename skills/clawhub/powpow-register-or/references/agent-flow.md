# Agent ସହାୟତା ପ୍ରବାହ ଓ ସ୍କ୍ରିପ୍ଟ ଚୁକ୍ତି — powpow-register

SKILL.md ର ପ୍ରତ୍ୟେକ ପଦକ୍ଷେପର କାର୍ଯ୍ୟକାରୀ ବିବରଣୀ। ସମସ୍ତ କମାଣ୍ଡ `node scripts/powpow-register.mjs <ସବ-କମାଣ୍ଡ> [ପାରାମିଟର]`,
ସ୍କ୍ରିପ୍ଟ **କୌଣସି ନିର୍ଭରତା ନାହିଁ**, **Node >= 18** ଆବଶ୍ୟକ, ସମସ୍ତ ଅନୁରୋଧ କେବଳ `https://global.powpow.online` କୁ ଯାଏ।

## ନିରାପତ୍ତା ଡିଜାଇନ୍ (କାହିଁକି ଏମିତି ଡିଜାଇନ୍)

## ଦୁଇ ଲିଙ୍କ ଯନ୍ତ୍ର (ମୂଳ ଡିଜାଇନ୍)

ପ୍ଲାଟଫର୍ମ ଲଗଇନ୍ ଅବସ୍ଥା HttpOnly cookie, agent ସିଧା ବ୍ରାଉଜରରେ cookie ବସାଇପାରିବେ ନାହିଁ; ବ୍ରିଜ୍ ଅଧିକାରୀ
`/api/auth/me?token=<JWT>&redirect=<ଭିତର ପାଥ>` ଏଣ୍ଡପଏଣ୍ଟ: ସିଗ୍ନେଚର ଯାଞ୍ଚ → pending ଉପଭୋକ୍ତାଙ୍କୁ ସ୍ୱୟଂ
session ତିଆରି → `Set-Cookie: powpow_token` (HttpOnly / SameSite=Lax / 7 ଦିନ) → redirect ଯାଞ୍ଚ
(କେବଳ ଗୋଟିଏ ସ୍ଲାସ୍ ରୁ ଆରମ୍ଭ, `//` ଓ backslash ନିଷେଧ, ପାର୍ସ ପରେ ସମ ଉତ୍ସ ହେବା ଆବଶ୍ୟକ) → 307 ଅସ୍ଥାୟୀ ରିଡାଇରେକ୍ଟ ଲକ୍ଷ୍ୟ ପୃଷ୍ଠାକୁ।

- **ଲିଙ୍କ 1 (ପଞ୍ଜୀକରଣ ସଫଳ ମାତ୍ରେ ଦିଅନ୍ତୁ)**: `--target pending` → `/subscription` ରେ ପହଞ୍ଚେ।
  ଉପଭୋକ୍ତା ବ୍ରାଉଜର "ଅର୍ଧ-ଲଗଇନ୍" ଅବସ୍ଥାରେ: ସବସ୍କ୍ରିପସନ୍ ପୃଷ୍ଠା, Alipay ରିଟର୍ନ ପୃଷ୍ଠା ଦେଖାଯାଏ ଓ ବ୍ୟବହାର ହୁଏ; ବିଷୟବସ୍ତୁ ପୃଷ୍ଠା ଏବଂ ମଧ୍ୟ ପେଓ୍ୱାଲର ଦ୍ୱାରା ସବସ୍କ୍ରିପସନ୍ ପୃଷ୍ଠାକୁ ଫେରାଯାଏ (ତିନି ସ୍ତର ରକ୍ଷା: JWT claims ଗେଟ୍‌ୱେ ଯାଞ୍ଚ → DB ପୁନଃ ଯାଞ୍ଚ → ମୂଳ API ଯାଞ୍ଚ, ଏହା ସାଧାରଣ ଆଚରଣ)।
- **ଲିଙ୍କ 2 (paid ନିଶ୍ଚିତ ପରେ ଦିଅନ୍ତୁ)**: ପ୍ରଥମେ `refresh-login` ନୂଆ JWT ବଦଳାନ୍ତୁ (ପେମେଣ୍ଟ କେବଳ DB ଅପଡେଟ୍ କରେ, ପୂର୍ବରୁ ଜାରି JWT ର claims ବଦଳାଏ ନାହିଁ, ନବଦଳାଇଲେ "ପେମେଣ୍ଟ କରିଛି ତଥାପି ସଦସ୍ୟ ନାହିଁ" ଦେଖାଏ), ତା'ପରେ `--target home` → ଘର ପୃଷ୍ଠାରେ ପହଞ୍ଚେ,
  ସମ୍ପୂର୍ଣ୍ଣ ସଦସ୍ୟତା ଅବସ୍ଥା।

## ସମ୍ପୂର୍ଣ୍ଣ କ୍ରମ (ସାଧାରଣ ପଥ)

```
1.  status                          # ପରିବେଶ ଆତ୍ମ-ଯାଞ୍ଚ
2.  (ପଦକ୍ଷେପ 2 ରେ କଥାବାର୍ତ୍ତା ସୂଚନା ନିଶ୍ଚିତ, ପାସୱାର୍ଡ ଦୁଇରୁ ଗୋଟିଏ; ସୃଷ୍ଟି ମୋଡ: gen-password → ଉପଭୋକ୍ତାଙ୍କୁ ତୁରନ୍ତ ସେଭ୍ କରିବାକୁ କୁହନ୍ତୁ)
3.  prepare-suggest --username U --nickname N --email E
4.  send-code --email E             # → ଉପଭୋକ୍ତା ଇମେଲରେ କୋଡ୍ ଦେଖନ୍ତି (କଥାବାର୍ତ୍ତା ଛାଡ଼ିବା ପାଦ ①)
5.  POWPOW_REGISTER_PASSWORD=*** register --code 123456 [--avatar pic.jpg]
6.  login-link --target pending     # → ଲିଙ୍କ 1 ଉପଭୋକ୍ତାଙ୍କୁ
7.  (ଉପଭୋକ୍ତା ପ୍ୟାକେଜ ବାଛନ୍ତି) create-order --package monthly
8.  start <ପେମେଣ୍ଟ ପୃଷ୍ଠା ଫାଇଲ୍>              # Windows; macOS ରେ open, Linux ରେ xdg-open
    # → ଉପଭୋକ୍ତା Alipay କାଉଣ୍ଟରରେ ପେମେଣ୍ଟ କରନ୍ତି (କଥାବାର୍ତ୍ତା ଛାଡ଼ିବା ପାଦ ②)
9.  query (ପ୍ରତି 10–15s) ଯେତେବେଳେ paid
10. refresh-login                   # ACTIVE ଘୋଷଣା ଥିବା ନୂଆ JWT ବଦଳାନ୍ତୁ
11. login-link --target home        # → ଲିଙ୍କ 2 ଉପଭୋକ୍ତାଙ୍କୁ
12. whoami                          # subscriptionStatus: ACTIVE ନିଶ୍ଚିତ କରନ୍ତୁ (ଇଚ୍ଛାଧୀନ)
13. cleanup                         # ଷ୍ଟେଟ୍ ଫାଇଲ୍ ସଫା କରନ୍ତୁ
```

## କମାଣ୍ଡ → ପ୍ଲାଟଫର୍ମ API ମ୍ୟାପିଂ

| ସ୍କ୍ରିପ୍ଟ କମାଣ୍ଡ | ପ୍ଲାଟଫର୍ମ ଇଣ୍ଟରଫେସ୍ |
|---|---|
| `send-code` | `POST /api/auth/register/send-code` |
| `register` | `POST /api/auth/register` (multipart, ପ୍ରୋଫାଇଲ୍ ଫଟୋ ସିଧା ଅପଲୋଡ୍) |
| `login-link` | `GET /api/auth/me?token=…&redirect=…` (ଲିଙ୍କ ନିଜେ, ଉପଭୋକ୍ତା କ୍ଲିକ୍ କଲାବେଳେ କାର୍ଯ୍ୟ କରେ) |
| `create-order` | `POST /api/payment/alipay/create-order` (Bearer) |
| `query` | `GET /api/payment/alipay/query?outTradeNo=…` (Bearer) |
| `refresh-login` | `POST /api/auth/login` (`{step:1, username, password}`) |
| `whoami` | `GET /api/auth/me?token=…` |

ନିୟମ ଉତ୍ସ: ପଞ୍ଜୀକରଣ ଫିଲ୍ଡ ଓ ରେଟ ଲିମିଟ `registration-flow.md` ରେ; ପ୍ୟାକେଜ ଓ ସକ୍ରିୟତା ପ୍ରବାହ

## ପଛକୁ ଫେରିବା ମୋଡ (ବିଶୁଦ୍ଧ ନିର୍ଦ୍ଦେଶ)

ନିମ୍ନଲିଖିତ ଯେକୌଣସି ପରିସ୍ଥିତିରେ ତୁରନ୍ତ v1 ଶୈଳୀର ବିଶୁଦ୍ଧ ନିର୍ଦ୍ଦେଶ ମୋଡକୁ ଫେରନ୍ତୁ, ସ୍କ୍ରିପ୍ଟ ବାରମ୍ବାର ଚଲାନ୍ତୁ ନାହିଁ:

- Node >= 18 ନାହିଁ କିମ୍ବା ସ୍କ୍ରିପ୍ଟ ଏକାଧାରେ ଦୁଇଥର ସମାନ ପ୍ରକାର ଫେଲ;
- ଉପଭୋକ୍ତା ସ୍ପଷ୍ଟ କହିଲେ "ମୁଁ ନିଜେ ୱେବ ରେ କରିବି";
- କମ୍ପାନୀ/ଡିଭାଇସ୍ ନୀତି ସ୍କ୍ରିପ୍ଟ ଇଣ୍ଟରନେଟ୍ ସଂଯୋଗ ଅଟକାଏ।

ଫେରିବା ପରେ: ପଞ୍ଜୀକରଣ ପୃଷ୍ଠା https://global.powpow.online/register ଓ ସବସ୍କ୍ରିପସନ୍ ପୃଷ୍ଠା
https://global.powpow.online/subscription ଦିଅନ୍ତୁ, `registration-flow.md` ର ନିୟମ ଅନୁସାରେ ତ୍ରୁଟି ନିବାରଣରେ ସହ କରନ୍ତୁ,
ସ୍ୱର ସମାନ ରହେ, ପ୍ରତି ରାଉଣ୍ଡ ଏବଂ ମଧ୍ୟ "ପରବର୍ତ୍ତୀ ପଦକ୍ଷେପ" ବ୍ଲକ ସହିତ ସମାପ୍ତ।
