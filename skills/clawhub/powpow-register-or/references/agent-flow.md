  ACTIVE ଦାବି ସହିତ ନୂଆ JWT ପାଇଁ `refresh-login` ଚଳାନ୍ତୁ, ତାପରେ ସମ୍ପୂର୍ଣ୍ଣ ସଦସ୍ୟତା ସ୍ଥିତି ପାଇଁ ହୋମ୍ ଲିଙ୍କ୍ ପୁଣି ପଠାନ୍ତୁ।

### ପେମେଣ୍ଟ ପଥ (ଉପଯୋଗକର୍ତା ସଦସ୍ୟତା ଚାହୁଁଥିବା ବେଳେ, କିମ୍ବା ମାଗଣା ପରୀକ୍ଷଣ ଅଵଧି ସମାପ୍ତ ହୋଇଛି)

```
1–5. ଦ୍ରୁତ ପଥ ସହିତ ସମାନ (ରେଜିଷ୍ଟର୍ ସଫଳ ହେବା ପରେ ଷ୍ଟେଟରେ ପୂର୍ବରୁ ଟୋକେନ୍ ଅଛି)
6.  login-link --target pending     # → ଅର୍ଧ-ଲଗଇନ୍ ଲିଙ୍କ୍, ପେମେଣ୍ଟ ରିଟର୍ଣ୍ ପୃଷ୍ଠା କାମ କରେ
7.  (ଉପଯୋଗକର୍ତା ପେମେଣ୍ଟ ପଦ୍ଧତି ବାଛନ୍ତି)
    # Alipay: create-order --package monthly|quarterly|yearly
    # PayPal: create-order --provider paypal
8.  start <ପେମେଣ୍ଟ ପୃଷ୍ଠା ଫାଇଲ୍>       # Windows; macOS open ବ୍ୟବହାର କରେ, Linux xdg-open
    # → ଉପଯୋଗକର୍ତା Alipay/PayPal କ୍ୟାଶିର୍‌ରେ ପେମେଣ୍ଟ/ଅଧିକାର ସମାପ୍ତ କରନ୍ତି (ସଂଳାପ ଛାଡିବେ)
9.  query (ପ୍ରତି 10–15s) paid / ACTIVE ପର୍ଯ୍ୟନ୍ତ
10. refresh-login                   # ACTIVE ଦାବି ସହିତ ନୂଆ JWT ବଦଳ
11. login-link --target home        # → ଉପଯୋଗକର୍ତାଙ୍କୁ ସମ୍ପୂର୍ଣ୍ଣ ସଦସ୍ୟତା ଲିଙ୍କ୍ ପଠାନ୍ତୁ
12. whoami                          # subscriptionStatus: ACTIVE ନିଶ୍ଚିତ (ଇଚ୍ଛାଧୀନ)
13. cleanup                         # ଷ୍ଟେଟ୍ ଫାଇଲ୍ ସଫା
```
## କମାଣ୍ଡ → ପ୍ଲାଟଫର୍ମ API ମ୍ୟାପିଂ

| ସ୍କ୍ରିପ୍ଟ କମାଣ୍ଡ | ପ୍ଲାଟଫର୍ମ ଇଣ୍ଟରଫେସ୍ |
|---|---|
| `send-code` | `POST /api/auth/register/send-code` |
| `register` | `POST /api/auth/register` (multipart, ପ୍ରୋଫାଇଲ୍ ଫଟୋ ସିଧା ଅପଲୋଡ୍) |
| `login-link` | `GET /api/auth/me?token=…&redirect=…` (ଲିଙ୍କ ନିଜେ, ଉପଭୋକ୍ତା କ୍ଲିକ୍ କଲାବେଳେ କାର୍ଯ୍ୟ କରେ) |
| `create-order` | `POST /api/payment/alipay/create-order` (Bearer, Alipay)<br>`GET /api/subscription/plans` + `POST /api/subscription/create` (Bearer, PayPal) |
| `query` | `GET /api/payment/alipay/query?outTradeNo=…` (Bearer, Alipay)<br>`GET /api/subscription/create` (Bearer, PayPal) |
| `refresh-login` | `POST /api/auth/login` (`{step:1, username, password}`) |
| `whoami` | `GET /api/auth/me?token=…` |

ନିୟମ ଉତ୍ସ: ପଞ୍ଜୀକରଣ ଫିଲ୍ଡ ଓ ରେଟ ଲିମିଟ `registration-flow.md` ରେ; ପ୍ୟାକେଜ ଓ ସକ୍ରିୟତା ପ୍ରବାହ
`payment-and-activation.md` ରେ (ପ୍ଲାଟଫର୍ମ ସୋର୍ସ ଫାଇଲ୍ ଉଲ୍ଲେଖ ସହିତ)।

## ପଛକୁ ଫେରିବା ମୋଡ (ବିଶୁଦ୍ଧ ନିର୍ଦ୍ଦେଶ)

ନିମ୍ନଲିଖିତ ଯେକୌଣସି ପରିସ୍ଥିତିରେ ତୁରନ୍ତ v1 ଶୈଳୀର ବିଶୁଦ୍ଧ ନିର୍ଦ୍ଦେଶ ମୋଡକୁ ଫେରନ୍ତୁ, ସ୍କ୍ରିପ୍ଟ ବାରମ୍ବାର ଚଲାନ୍ତୁ ନାହିଁ:

- Node >= 18 ନାହିଁ କିମ୍ବା ସ୍କ୍ରିପ୍ଟ ଏକାଧାରେ ଦୁଇଥର ସମାନ ପ୍ରକାର ଫେଲ;
- ଉପଭୋକ୍ତା ସ୍ପଷ୍ଟ କହିଲେ "ମୁଁ ନିଜେ ୱେବ ରେ କରିବି";
- କମ୍ପାନୀ/ଡିଭାଇସ୍ ନୀତି ସ୍କ୍ରିପ୍ଟ ଇଣ୍ଟରନେଟ୍ ସଂଯୋଗ ଅଟକାଏ।

ଫେରିବା ପରେ — ରେଜିଷ୍ଟ୍ରେଶନ ପୃଷ୍ଠା https://global.powpow.online/register ଦିଅନ୍ତୁ (ମାଗଣା ପରୀକ୍ଷଣ ଅଵଧିରେ ୱେବ୍ ରେଜିଷ୍ଟ୍ରେଶନ୍ ସମାନ ଭାବରେ ତ୍ୱରିତ; ସବସ୍କ୍ରିପଶନ୍ ଆବଶ୍ୟକ ହେଲେ ସବସ୍କ୍ରିପଶନ ପୃଷ୍ଠା https://global.powpow.online/subscription ମଧ୍ୟ ଦିଅନ୍ତୁ), `registration-flow.md` ନିୟମ ଅନୁସାରେ ପାଖରେ ତ୍ରୁଟି ନିବାରଣ କରନ୍ତୁ, ସମାନ ସ୍ୱର ରଖନ୍ତୁ, ଆଉ ପ୍ରତ୍ୟେକ ପାଳି "ପରବର୍ତ୍ତୀ ଚରଣ" ବ୍ଲକ୍ ସହିତ ଶେଷ କରନ୍ତୁ।
https://global.powpow.online/subscription ଦିଅନ୍ତୁ, `registration-flow.md` ର ନିୟମ ଅନୁସାରେ ତ୍ରୁଟି ନିବାରଣରେ ସହ କରନ୍ତୁ,
ସ୍ୱର ସମାନ ରହେ, ପ୍ରତି ରାଉଣ୍ଡ ଏବଂ ମଧ୍ୟ "ପରବର୍ତ୍ତୀ ପଦକ୍ଷେପ" ବ୍ଲକ ସହିତ ସମାପ୍ତ।
