# ପଞ୍ଜୀକରଣ ପ୍ରବାହ ବିସ୍ତୃତ ବିବରଣୀ — powpow-register

ତ୍ରୁଟି ନିବାରଣ ସମୟରେ ଦେଖିବା ପାଇଁ। ସମସ୍ତ ନିୟମ ପ୍ଲାଟଫର୍ମ ସୋର୍ସ କୋଡ୍ ଠାରୁ (Next.js ଫ୍ରଣ୍ଟ ଓ ବ୍ୟାକ୍ ଏକତା ଯାଞ୍ଚ), ଉଲ୍ଲେଖ ଦିଆଯାଇଛି।
ପ୍ଲାଟଫର୍ମ ଅପଡେଟ୍ ହେଲେ ଅନଲାଇନ୍ ପ୍ରକୃତ ଆଚରଣ ପ୍ରାଧାନ୍ୟ ପାଏ।

## ପ୍ରବେଶ

- ପଞ୍ଜୀକରଣ ପୃଷ୍ଠା: https://global.powpow.online/register
- ଲଗଇନ୍ ପୃଷ୍ଠା: https://global.powpow.online/login
- ସବସ୍କ୍ରିପସନ୍ ପୃଷ୍ଠା: https://global.powpow.online/subscription
- ଶେୟାର ଲିଙ୍କ ଆଦିରୁ `?next=...` ସହିତ ପ୍ରବେଶ କଲେ, ପଞ୍ଜୀକରଣ+ପେମେଣ୍ଟ ସମ୍ପୂର୍ଣ୍ଣ ହେବା ପରେ ସ୍ୱୟଂଚାଳିତ ଭାବେ ମୂଳ ପୃଷ୍ଠାକୁ ଫେରିଯିବ।

## agent ସହାୟତା ମୋଡ ଓ ୱେବ ପଞ୍ଜୀକରଣର ସମତୁଲ୍ୟତା

skill ସ୍କ୍ରିପ୍ଟ **ସମାନ ପବ୍ଲିକ୍ API ସେଟ୍** କୁ କଲ୍ କରେ (`/api/auth/register`, `send-code`, `login`,
`/api/auth/me`), ପଞ୍ଜୀକରଣ ପୃଷ୍ଠା ଫର୍ମ ଦାଖଲ ସହିତ ସମ୍ପୂର୍ଣ୍ଣ ସମାନ ଯାଞ୍ଚ, ରେଟ ଲିମିଟ ଓ ତ୍ରୁଟି ପଥ ବ୍ୟବହାର କରେ — ଏହି ଫାଇଲର
ସମସ୍ତ ନିୟମ ଉଭୟ ମୋଡ ପାଇଁ ସମାନ। ସ୍କ୍ରିପ୍ଟ କ୍ରମ ଓ କମାଣ୍ଡ ଚୁକ୍ତି `references/agent-flow.md` ରେ ଦେଖନ୍ତୁ।

## ପଞ୍ଜୀକରଣ ସଫଳ ପରେ ଅବସ୍ଥା ପରିବର୍ତ୍ତନ

1. ଉପଭୋକ୍ତା `accountStatus: 'pending'` ସହିତ DB ରେ ରହେ, ପ୍ରାରମ୍ଭିକ **3 ଟି ବ୍ୟାଜ୍** (register route)।
2. ସର୍ଭର ଏକଠି ଦୁଇଟି HttpOnly cookie ବସାଏ: JWT (ସିଧା `/subscription` ପ୍ରବେଶ କରିପାରିବେ) ଓ
   pendingUserToken (ସବସ୍କ୍ରିପସନ୍ ପ୍ରବାହ ପରିଚୟ କ୍ରେଡେନସିଆଲ୍)।
3. ପଞ୍ଜୀକରଣ ପୃଷ୍ଠା `pending_payment` ଚିହ୍ନଟ କଲେ → `/subscription` କୁ ଯାଏ (`next` ରିଟର୍ନ ପାରାମିଟର ରଖେ);
   agent ସହାୟତା ମୋଡରେ `me?token=…&redirect=/subscription` ଦ୍ୱାରା ସମାନ ଫଳ ମିଳେ।
4. ପେମେଣ୍ଟ ସମ୍ପୂର୍ଣ୍ଣ → `accountStatus` `active` ହୁଏ (**Alipay notify ମାଧ୍ୟମରେ ସର୍ଭର ସ୍ୱୟଂଚାଳିତ ସକ୍ରିୟ କରେ**;
   PayPal Webhook ମାଧ୍ୟମରେ ସ୍ୱୟଂଚାଳିତ ସକ୍ରିୟ; WeChat QR ମାନବ ନିଶ୍ଚିତକରଣ; Huawei IAP `activate-huawei` ମାଧ୍ୟମରେ)।
   ବିସ୍ତୃତ `payment-and-activation.md` ରେ ଦେଖନ୍ତୁ।

ସକ୍ରିୟ ନହୋଇଥିବା (pending) ଉପଭୋକ୍ତା ମୂଳ API କଲ୍ କଲେ (ଫିଡ୍, ମାନଚିତ୍ର, ଡିଜିଟାଲ୍ ମାନବ କଥାବାର୍ତ୍ତା, ଚେକଇନ୍ ଆଦି) ସବୁ ସମୟ 403;
ଶେୟାର ପୋଷ୍ଟ ଲିଙ୍କ ବ୍ୟତୀତ (ପବ୍ଲିକ୍ ପ୍ରବେଶ ରହେ)।

| ପଞ୍ଜୀକରଣ ସଫଳ କିନ୍ତୁ ଲଗଇନ୍ 403「请完成订阅以激活账户」 | ଆକାଉଣ୍ଟ ଏବଂ ମଧ୍ୟ pending (ପେମେଣ୍ଟ ପୂର୍ବର ପ୍ରତ୍ୟାଶିତ ଅବସ୍ଥା) | ପେମେଣ୍ଟ ପୂର୍ବରେ: ଏହା ସାଧାରଣ, ପ୍ରଥମେ ସବସ୍କ୍ରିପସନ୍ ସମ୍ପୂର୍ଣ୍ଣ କରନ୍ତୁ; ପେମେଣ୍ଟ ପରେ ମଧ୍ୟ 403: ପୁରୁଣା JWT ବ୍ୟବହାର ହୋଇଛି, ସ୍କ୍ରିପ୍ଟ ମୋଡରେ ପ୍ରଥମେ `refresh-login` ନୂଆ ଲଗଇନ୍ ଅବସ୍ଥା ବଦଳାନ୍ତୁ |
| ଲଗଇନ୍ 423「账户已锁定」 | ପାସୱାର୍ଡ ଏକାଧାରେ 5 ଥର ଭୁଲ | 30 ମିନିଟ ଅପେକ୍ଷା କରନ୍ତୁ |
| ଲଗଇନ୍ 401「还剩 N 次尝试机会」 | ପାସୱାର୍ଡ ଭୁଲ, ଲକ୍ ପାଖରେ | ଭାବି ପୁଣି ଚେଷ୍ଟା କରନ୍ତୁ, କିମ୍ବା ସିଧା「忘记密码」ପଥ ନିଅନ୍ତୁ |

| 「该账号已注销」 | ଆକାଉଣ୍ଟ deactivate ହୋଇଛି | ପୁଣି ପଞ୍ଜୀକରଣ କରିବା ଆବଶ୍ୟକ |

## ଲଗଇନ୍ ଛୋଟ ତଥ୍ୟ (ନିବାରଣ କାମରେ ଉପଯୋଗୀ)

ଲଗଇନ୍ **ଉପଭୋକ୍ତା ନାମ / ଇମେଲ / ମୋବାଇଲ୍ ନମ୍ବର** ତିନି ଏକତ୍ର ଇନପୁଟ୍ ସପୋର୍ଟ କରେ (ତିନିରୁ ଯେକୌଣସି ଆକାଉଣ୍ଟ ନାମ ଭାବେ ବ୍ୟବହାର ହୁଏ)।
ପାସୱାର୍ଡ ଭୁଲିଗଲେ: ଲଗଇନ୍ ପୃଷ୍ଠା →「忘记密码」→ ପଞ୍ଜୀକୃତ ଇମେଲ ଦିଅନ୍ତୁ 6 ଅଙ୍କ ଯାଞ୍ଚ କୋଡ୍ ପାଆନ୍ତୁ → ରିସେଟ୍ କରନ୍ତୁ।
