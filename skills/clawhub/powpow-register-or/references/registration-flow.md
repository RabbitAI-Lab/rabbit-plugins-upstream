# ରେଜିଷ୍ଟ୍ରେସନ ପ୍ରକ୍ରିୟା ବିସ୍ତାରିତ ବର୍ଣ୍ଣନା — powpow-register

ସମସ୍ୟା ସମାଧାନ ସମୟରେ ଦେଖିବା ପାଇଁ। ସମସ୍ତ ନିୟମ ପ୍ଲାଟଫର୍ମ ସୋର୍ସ କୋଡ୍‌ରୁ ଆସେ (Next.js ଫ୍ରଣ୍ଟ-ଏଣ୍ଡ/ବ୍ୟାକ୍-ଏଣ୍ଡ ସ୍ଥିରତା ଯାଞ୍ଚ), ଉତ୍ସ ଲେଖାଯାଇଛି।
ପ୍ଲାଟଫର୍ମ ଅଦ୍ୟତନ ହେଲେ ଅନଲାଇନ୍ ପ୍ରକୃତ ବ୍ୟବହାର ପ୍ରାମାଣିକ।

## ପ୍ରବେଶ ପଥ

- ରେଜିଷ୍ଟ୍ରେସନ ପୃଷ୍ଠା: https://global.powpow.online/register
- ଲଗ୍‌ଇନ୍ ପୃଷ୍ଠା: https://global.powpow.online/login
- ସବସ୍କ୍ରିପସନ୍ ପୃଷ୍ଠା: https://global.powpow.online/subscription
- ଶେୟାର ଲିଙ୍କ୍ ଆଦିରୁ `?next=...` ସହିତ ଆସିଲେ, ରେଜିଷ୍ଟ୍ରେସନ+ପେମେଣ୍ଟ ସମ୍ପୂର୍ଣ୍ଣ ହେବା ପରେ ଆପେ ଆପେ ମୂଳ ପୃଷ୍ଠାକୁ ଫେରିଯାଏ।

## ରେଜିଷ୍ଟ୍ରେସନ ସଫଳ ପରେ ଅବସ୍ଥା ପରିବର୍ତ୍ତନ

1. ବ୍ୟବହାରକାରୀ `accountStatus: 'pending'` ସହିତ ଡାଟାବେସରେ ସଂରକ୍ଷିତ ହୁଏ, ଆରମ୍ଭରେ **3 ବ୍ୟାଜ୍** (register route)।
2. ସର୍ଭର ଏକାସାଙ୍ଗରେ ଦୁଇଟି HttpOnly କୁକି ସେଟ୍ କରେ: JWT (`/subscription` ସିଧା ଆକ୍ସେସ୍ କରିପାରେ) ଓ
   pendingUserToken (ସବସ୍କ୍ରିପସନ୍ ପ୍ରକ୍ରିୟାର ପରିଚୟ ପ୍ରମାଣପତ୍ର)।
3. ରେଜିଷ୍ଟ୍ରେସନ ପୃଷ୍ଠା `pending_payment` ଦେଖିଲେ → `/subscription` କୁ ଯାଏ (`next` ଫେରିବା ପାରାମିଟର ରଖେ)।
4. ପେମେଣ୍ଟ ସମ୍ପୂର୍ଣ୍ଣ ହେଲେ → `accountStatus` `active` ହୁଏ (PayPal Webhook ଆପେ ଆପେ ସକ୍ରିୟ କରେ; WeChat ସ୍କାନ
   ମାନୁଆଲ ନିଶ୍ଚିତକରଣ; Huawei IAP `activate-huawei` ମାଧ୍ୟମରେ)। ବିସ୍ତାରିତ ବିବରଣୀ `payment-and-activation.md` ରେ।

ସକ୍ରିୟ ହୋଇନଥିବା (pending) ବ୍ୟବହାରକାରୀ ମୁଖ୍ୟ API (ଫିଡ୍, ମାନଚିତ୍ର, ଡିଜିଟାଲ୍ ମଣିଷ କଥାବାର୍ତ୍ତା, ଚେକ୍-ଇନ୍ ଆଦି) କଲେ ସବୁବେଳେ 403;
ପୋଷ୍ଟ ଲିଙ୍କ୍ ଶେୟାର ଛଡ଼ା (ସାର୍ବଜନୀନ ଆକ୍ସେସ୍ ରହେ)।

## ଲଗ୍‌ଇନ୍ ଛୋଟ ତଥ୍ୟ (ସମାଧାନରେ ମଧ୍ୟ ବ୍ୟବହାର୍ୟ)

ଲଗ୍‌ଇନ୍‌ରେ **ଉପଯୋଗକର୍ତ୍ତା ନାମ / ଇମେଲ୍ / ଫୋନ୍ ନମ୍ବର** ତିନୋଟି ଏକାଠି ଇନପୁଟ୍ ହୋଇପାରେ (ଯେକୌଣସି ଗୋଟିଏ ଆକାଉଣ୍ଟ ନାମ ଭାବେ ଚଳିବ)।
ପାସୱାର୍ଡ ଭୁଲିଲେ: ଲଗ୍‌ଇନ୍ ପୃଷ୍ଠା → 「ପାସୱାର୍ଡ ଭୁଲିଗଲି」→ ରେଜିଷ୍ଟର ଇମେଲ୍ ଦେଇ 6 ଅଙ୍କ କୋଡ୍ ପାଆନ୍ତୁ → ରିସେଟ୍ କରନ୍ତୁ।
