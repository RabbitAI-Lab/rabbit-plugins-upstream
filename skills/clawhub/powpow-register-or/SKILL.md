# PowPow Register (ବବୁଲ ପଞ୍ଜୀକରଣ ସହାୟକ)

ଏକ ନୂଆ ଉପଭୋକ୍ତାଙ୍କୁ "ବବୁଲ କଣ ଜାଣି ନାହିଁ" ଠାରୁ "ଆକାଉଣ୍ଟ ସକ୍ରିୟ, ଏକ-କ୍ଲିକ୍ ଲଗଇନ୍, ଖେଳ ଆରମ୍ଭ" ପର୍ଯ୍ୟନ୍ତ ନେବା — ପ୍ରକ୍ରିୟା ସମ୍ପୂର୍ଣ୍ଣ କଥାବାର୍ତ୍ତା ଭିତରେ ହୁଏ। ଉପଭୋକ୍ତା କେବଳ ଦୁଇଥର କଥାବାର୍ତ୍ତା ଛାଡ଼ିବାକୁ ପଡ଼େ: **ଇମେଲରେ ଯାଞ୍ଚ କୋଡ୍ ଦେଖିବା**, **Alipay କାଉଣ୍ଟରରେ ପେମେଣ୍ଟ କରିବା** (agent ସ୍ୱୟଂଚାଳିତ ଭାବେ କାଉଣ୍ଟର ପୃଷ୍ଠା ଖୋଲିବ)।

**ସଂସ୍କରଣ 2.0.1** · 2026-10-08 (v2 ଠାରୁ agent-ସହାୟତା ମୋଡ: ସ୍କ୍ରିପ୍ଟ ଚୁକ୍ତି ଓ ସମ୍ପୂର୍ଣ୍ଣ କ୍ରମ ପାଇଁ `references/agent-flow.md` ଦେଖନ୍ତୁ; ଫିଲ୍ଡ ନିୟମ, ରେଟ ଲିମିଟ ଓ ତ୍ରୁଟି ନିବାରଣ ପାଇଁ `references/registration-flow.md`; ପେମେଣ୍ଟ ଚ୍ୟାନେଲ ପାଇଁ `references/payment-and-activation.md`; ଉତ୍ପାଦ ସ୍କ୍ରିନସଟ୍ ତାଲିକା ପାଇଁ `references/screenshots.md`। v2.0.1 ଠାରୁ ଉତ୍ପାଦ ସ୍କ୍ରିନସଟ୍ skill ସହିତ `assets/screenshots/` ରେ ପ୍ୟାକ ହୋଇଛି, ବାହ୍ୟ ଇମେଜ୍ ହୋଷ୍ଟ ଉପରେ ନିର୍ଭର କରୁନାହିଁ)

## ଚାଲାଉ ପରିବେଶ

- ମୂଳ ସ୍କ୍ରିପ୍ଟ `scripts/powpow-register.mjs`: **କୌଣସି ନିର୍ଭରତା ନାହିଁ**, **Node >= 18** ଆବଶ୍ୟକ। ଆରମ୍ଭ ପୂର୍ବରୁ ଥରେ `node scripts/powpow-register.mjs status` ଚଲାଇ ପରିବେଶ ଠିକ୍ ଅଛି କି ନାହିଁ ନିଶ୍ଚିତ କରନ୍ତୁ।
- ସ୍କ୍ରିପ୍ଟର ସମସ୍ତ ଅନୁରୋଧ କେବଳ ଅଧିକାରୀ ଡୋମେନ୍ `https://global.powpow.online` କୁ ଯାଏ।
- **Node ନାହିଁ / ସ୍କ୍ରିପ୍ଟ ତ୍ରୁଟି ଦେଲେ**: ସ୍ୱୟଂଚାଳିତ ଭାବେ ବିଶୁଦ୍ଧ ନିର୍ଦ୍ଦେଶ ମୋଡକୁ ଫେରନ୍ତୁ — ପଞ୍ଜୀକରଣ ପୃଷ୍ଠା https://global.powpow.online/register ଏବଂ ସବସ୍କ୍ରିପସନ୍ ପୃଷ୍ଠା https://global.powpow.online/subscription ଉପଭୋକ୍ତାଙ୍କୁ ଦିଅନ୍ତୁ, `references/registration-flow.md` ଅନୁସାରେ ସହଭାଗୀ ମାର୍ଗଦର୍ଶନ କରନ୍ତୁ। ସ୍କ୍ରିପ୍ଟ ବାରମ୍ବାର ଜୋର୍ କରି ଚଲାନ୍ତୁ ନାହିଁ।
- କଥାବାର୍ତ୍ତା ଭାଙ୍ଗିଯିବା ପରେ ପୁନରୁଦ୍ଧାର: ପ୍ରଥମେ `status` ଚଲାଇ ପ୍ରକ୍ରିୟା କେଉଁ ପଦକ୍ଷେପରେ ଅଛି ଦେଖନ୍ତୁ, ତା'ପରେ ଆଗକୁ ବଢ଼ନ୍ତୁ।

## ପଦକ୍ଷେପ 1: ଉତ୍ପାଦ ପରିଚୟ + ସ୍କ୍ରିନସଟ୍ (ଛାଡ଼ିପାରିବା ନାହିଁ)

ଅଧିକାଂଶ ଉପଭୋକ୍ତା ବବୁଲ କେବେହି ଦେଖିନାହାନ୍ତି। କଥା ଆରମ୍ଭରେ ପ୍ରଥମ କାମ ପ୍ରକ୍ରିୟା ବୁଝାଇବା ନୁହେଁ, ବରଂ ତାଙ୍କୁ ଉତ୍ପାଦ **ଦେଖାଇବା**:

1. ପ୍ରାୟ 120 ଶବ୍ଦରେ ବବୁଲ ପରିଚୟ ଦିଅନ୍ତୁ: ଯେଉଁ ଫଟୋ ଯାଇଥିବା ସମୟରେ ଚିତ୍ର ଖିଚିଛନ୍ତି ତାକୁ ଯାତ୍ରା ବୃତ୍ତାନ୍ତରେ ପରିଣତ କରି ପବ୍ଲିକ୍ ମାନଚିତ୍ରରେ ପିନ୍ କଲେ ଗୋଟିଏ "ବୁଦବୁଦ" ହୁଏ; ବୁଦବୁଦ ସମୟ ସହିତ ମରିଯାଏ, ଅନ୍ୟମାନେ ଲାଇକ୍ ଦେଲେ ପୁଣି ଜୀବିତ ହୁଏ; ମାନଚିତ୍ରରେ କଥା ହୋଇପାରୁଥିବା "ଡିଜିଟାଲ୍ ମାନବ" ମଧ୍ୟ ଅଛନ୍ତି। ପ୍ଲାଟଫର୍ମ ଠିକଣା https://global.powpow.online , ପ୍ରଥମେ ଭିଡିଓ ଦେଖିବାକୁ ଚାହୁଁଥିଲେ: https://www.bilibili.com/video/BV1Wu826UEVz/
2. **ସ୍କ୍ରିନସଟ୍ ପଠାନ୍ତୁ**। ସ୍କ୍ରିନସଟ୍ skill ସହିତ `assets/screenshots/powpow-0N.jpg` ରେ ପ୍ୟାକ ହୋଇଛି — ସିଧା ଲୋକାଲ୍ ଇମେଜ୍ ଫାଇଲ୍ ଭାବେ ପଠାନ୍ତୁ, ଇଣ୍ଟରନେଟ୍ ଆବଶ୍ୟକ ନାହିଁ। ତାଲିକା, ପ୍ରତ୍ୟେକ ଚିତ୍ରର ବିଷୟବସ୍ତୁ ଓ ବ୍ୟବହାର ସମୟ `references/screenshots.md` ରେ ଦେଖନ୍ତୁ। ଆରମ୍ଭରେ ସବୁଠାରୁ ଅଧିକ ବ୍ୟବହୃତ ସଂଯୋଗ: ମାନଚିତ୍ର ପୃଷ୍ଠା (powpow-03) + ପୋଷ୍ଟ ବିବରଣୀ ପୃଷ୍ଠା (powpow-06)।

## ପଦକ୍ଷେପ 2: ପଞ୍ଜୀକରଣ ସୂଚନା ନିଶ୍ଚିତ କରନ୍ତୁ (ଗୋଟିଏ ପ୍ରଶ୍ନ ପ୍ରତି ରାଉଣ୍ଡ, ଏକଠି ସବୁ ନପଚାରନ୍ତୁ)

- **ପାସୱାର୍ଡ** (ଆବଶ୍ୟକ, ପ୍ରଥମେ ଉପଭୋକ୍ତାଙ୍କୁ ଦୁଇରୁ ଗୋଟିଏ ବାଛିବାକୁ କୁହନ୍ତୁ):

  - agent ସୃଷ୍ଟି କରେ → `node scripts/powpow-register.mjs gen-password` ଚଲାନ୍ତୁ, ସୃଷ୍ଟି ହୋଇଥିବା ପାସୱାର୍ଡ **ତୁରନ୍ତ ଉପଭୋକ୍ତାଙ୍କୁ ପଠାଇ ସେଭ୍ କରିବାକୁ କୁହନ୍ତୁ** (କେବଳ ଏଥର ଦେଖାଏ, ପରେ ଆଉ ଦେଖାଏ ନାହିଁ)।
- **ଇମେଲ** (ଆବଶ୍ୟକ): ଉପଭୋକ୍ତା ନିଜେ ଦେବା ଉଚିତ — ଏହା ଆକାଉଣ୍ଟର ପରିଚୟ ଆଙ୍କର, **ଉପଭୋକ୍ତା ପାଇଁ ଅନୁମାନ କରନ୍ତୁ ନାହିଁ**।
- **ଡାକନାମ** (ଇଚ୍ଛାଧୀନ): ଡିଫଲ୍ଟ ଉପଭୋକ୍ତା ନାମ ସହିତ ସମାନ ରଖିବାକୁ ସୁଝନ୍ତୁ।
- **ପ୍ରୋଫାଇଲ୍ ଫଟୋ** (ଇଚ୍ଛାଧୀନ): ଉପଭୋକ୍ତା ଲୋକାଲ୍ ଇମେଜ୍ ପାଥ (≤5MB, SVG ନୁହେଁ) ଦେଲେ ସ୍କ୍ରିପ୍ଟ ସିଧା ଅପଲୋଡ୍ କରିବ; ନଥିଲେ ଛାଡ଼ିଦିଅନ୍ତୁ (ପ୍ଲାଟଫର୍ମ ଡିଫଲ୍ଟ ଲୋଗୋ ବ୍ୟବହାର କରିବ); ଆପଣଙ୍କର ଇମେଜ୍ ସୃଷ୍ଟି କ୍ଷମତା ଥିଲେ ଉପଭୋକ୍ତାଙ୍କ ପାଇଁ ଗୋଟିଏ ତିଆରି କରିବାକୁ ସକ୍ରିୟ ଭାବେ ସୁଝାଇପାରିବେ।

ନିଶ୍ଚିତ ହେବା ପରେ `prepare-suggest --username U --nickname N --email E` ଚଲାଇ ଷ୍ଟେଟ୍ ଫାଇଲ୍ ରେ ଲେଖାଯାଇପାରେ (ପରେ register କୁ ପୁଣି ପଠାଇବାର ଆବଶ୍ୟକ ନାହିଁ)।

## ପଦକ୍ଷେପ 6: ଏକ-କ୍ଲିକ୍ ଲଗଇନ୍ (ଲିଙ୍କ 1) + ପେମେଣ୍ଟ

   ସ୍କ୍ରିପ୍ଟ ପେମେଣ୍ଟ ପୃଷ୍ଠା ଫାଇଲ୍ ପାଥ ଫେରାଏ, **ସିଷ୍ଟମ୍ କମାଣ୍ଡ ଦ୍ୱାରା ସିଧା ଖୋଲନ୍ତୁ** (Windows: `start <ଫାଇଲ୍>`; macOS: `open <ଫାଇଲ୍>`; Linux: `xdg-open <ଫାଇଲ୍>`)। ବ୍ରାଉଜର ସ୍ୱୟଂଚାଳିତ ଭାବେ Alipay ଅଧିକାରୀ କାଉଣ୍ଟରକୁ ଯିବ, ଉପଭୋକ୍ତା QR ସ୍କାନ୍ କରିବେ କିମ୍ବା Alipay ଭିତରେ ଲଗଇନ୍ କରି ପେମେଣ୍ଟ କରିବେ।
4. ପ୍ରତି 10–15 ସେକେଣ୍ଡରେ `query` ଚଲାନ୍ତୁ ଯେତେବେଳେ `paid` ଫେରାଏ (ଟାକା ସାଧାରଣତଃ କିଛି ସେକେଣ୍ଡରୁ ଏକ ମିନିଟ ଭିତରେ ଆସେ)। ଉପଭୋକ୍ତା ମଝିରେ ପେମେଣ୍ଟ ପୃଷ୍ଠା ବନ୍ଦ କଲେ → ସିଧା ପୁଣି `create-order` (ପୁରୁଣା ଅର୍ଡର 2 ଘଣ୍ଟାରେ ସ୍ୱୟଂଚାଳିତ ବନ୍ଦ ହୁଏ, ଚିନ୍ତା କରନ୍ତୁ ନାହିଁ)।
5. ବିଦେଶୀ/Alipay ନଥିବା ଉପଭୋକ୍ତା: ସବସ୍କ୍ରିପସନ୍ ପୃଷ୍ଠାରେ PayPal ଚ୍ୟାନେଲ ବ୍ୟବହାର କରିବାକୁ ମାର୍ଗଦର୍ଶନ କରନ୍ତୁ (skill ନିଜେ କରେ ନାହିଁ, ରାସ୍ତା ଦେଖାନ୍ତୁ); WeChat QR ଚ୍ୟାନେଲ ମାନବ ନିଶ୍ଚିତକରଣ, ଟାକା ଆସିବାରେ ବିଳମ୍ବ। ପେମେଣ୍ଟ ପରେ ସମାନ ଭାବେ ଫେରି ପଦକ୍ଷେପ 7 କରନ୍ତୁ।

## ପଦକ୍ଷେପ 7: ଆଧିକାରିକ ଲଗଇନ୍ (ଲିଙ୍କ 2)

ଟାକା ଆସିବା ନିଶ୍ଚିତ ହେବା ପରେ, ପ୍ରଥମେ ସର୍ବଶେଷ ସବସ୍କ୍ରିପସନ୍ ଘୋଷଣା ଥିବା ଲଗଇନ୍ ଅବସ୍ଥା ବଦଳାନ୍ତୁ, ତା'ପରେ ଘର ପୃଷ୍ଠାକୁ ସିଧା ଯାଉଥିବା ଲିଙ୍କ ସୃଷ୍ଟି କରନ୍ତୁ:

```
POWPOW_REGISTER_PASSWORD=<ପାସୱାର୍ଡ> node scripts/powpow-register.mjs refresh-login
node scripts/powpow-register.mjs login-link --target home
```

ଲିଙ୍କ ଉପଭୋକ୍ତାଙ୍କୁ ପଠାନ୍ତୁ: **କ୍ଲିକ୍ କଲେ ସିଧା ଘର ପୃଷ୍ଠାରେ ପହଞ୍ଚିବ, ସମ୍ପୂର୍ଣ୍ଣ ସଦସ୍ୟତା ଅବସ୍ଥା**, ଏଠାରେ ପଞ୍ଜୀକରଣ ସମ୍ପୂର୍ଣ୍ଣ ପ୍ରକ୍ରିୟା ଶେଷ।

## ପଦକ୍ଷେପ 8: ସମାପ୍ତି

1. `node scripts/powpow-register.mjs cleanup` ଏହି ମେସିନର ଅସ୍ଥାୟୀ ଷ୍ଟେଟ୍ ଫାଇଲ୍ (ସେସନ୍ କ୍ରେଡେନସିଆଲ୍) ସଫା କରନ୍ତୁ।
2. ଉପଭୋକ୍ତାଙ୍କୁ ଗୋଟିଏ "ଆକାଉଣ୍ଟ କାର୍ଡ" ଦିଅନ୍ତୁ: ଉପଭୋକ୍ତା ନାମ, ଇମେଲ, ସଦସ୍ୟତା ମିତି ଶେଷ ସମୟ (ପାସୱାର୍ଡ ପୁଣି ଦେଖାନ୍ତୁ ନାହିଁ — ସୃଷ୍ଟି ମୋଡରେ ସୃଷ୍ଟି ସମୟରେ ଉପଭୋକ୍ତାଙ୍କୁ ସେଭ୍ କରିବାକୁ କୁହାଯାଇଛି; ଉପଭୋକ୍ତା ନିଜେ ସେଟ୍ କଲେ ସେ ନିଜେ ଜାଣନ୍ତି)।
3. ଅନୁଭୂତି ମାର୍ଗଦର୍ଶନ: ମାନଚିତ୍ର ବୁଲନ୍ତୁ, ପ୍ରଥମ ଯାତ୍ରା ବୃତ୍ତାନ୍ତ ପଠାନ୍ତୁ (→ powpow-simple କୁ ଦିଅନ୍ତୁ)।
4. ଏକ୍ସଟେନ୍ସନ୍ ସୁପାରିଶ: `@durenzidu/powpow-integration` skill ଏବଂ `@durenzidu/openclaw-channel-powpow` ପ୍ଲଗଇନ୍ — ବବୁଲକୁ ଉପଭୋକ୍ତାଙ୍କ ନିଜ agent ସହିତ ସଂଯୋଗ କରନ୍ତୁ; ଚାହାଁଲେ ଇନଷ୍ଟଲ କମାଣ୍ଡ ଦିଅନ୍ତୁ।
5. "ପରବର୍ତ୍ତୀ ପଦକ୍ଷେପ" ବ୍ଲକ ସହିତ ସମାପ୍ତ କରନ୍ତୁ।

## କଠୋର ନିୟମ

- **କ୍ରେଡେନସିଆଲ୍ ନିରାପତ୍ତା**: ପାସୱାର୍ଡ କେବଳ ଏନଭାୟରନମେଣ୍ଟ ଭେରିଏବଲ୍ `POWPOW_REGISTER_PASSWORD` ମାଧ୍ୟମରେ ସ୍କ୍ରିପ୍ଟକୁ ଦିଅନ୍ତୁ, **କମାଣ୍ଡ ଲାଇନ୍ ପାରାମିଟରରେ କେବେ ନଲେଖନ୍ତୁ** (ପ୍ରୋସେସ୍ ତାଲିକାରେ ଦେଖାଯାଏ), କୌଣସି ଫାଇଲ୍ ରେ ନଲେଖନ୍ତୁ (ସୃଷ୍ଟି ମୋଡରେ ଏଥର ଦେଖାଏ ଯାହା ଉପଭୋକ୍ତା ସେଭ୍ କରିବା ପାଇଁ, ପରେ ପୁଣି କୁହାଯାଏ ନାହିଁ)। ଯାଞ୍ଚ କୋଡ୍ କେବଳ ଅଧିକାରୀ ପଞ୍ଜୀକରଣ API ପାଇଁ, ବ୍ୟବହାର ପରେ ଫୋପାଡ଼ନ୍ତୁ।
- **ଅଧିକାରୀ ସୀମା**: ସମସ୍ତ ଅନୁରୋଧ କେବଳ `https://global.powpow.online` କୁ (ସ୍କ୍ରିପ୍ଟ ଭିତରେ ଅଛି), ଉପଭୋକ୍ତା ସୂଚନା କେବେ ବି କୌଣସି ତୃତୀୟ ପକ୍ଷ ଠିକଣାକୁ ନପଠାନ୍ତୁ।
- **ପେମେଣ୍ଟ ସୀମା**: agent କେବଳ ଅର୍ଡର ସୃଷ୍ଟି କରେ, କାଉଣ୍ଟର ଖୋଲେ, ଟାକା ଆସିବା ପଚାରେ; **କେବେ ବି** ଉପଭୋକ୍ତାଙ୍କ Alipay ଆକାଉଣ୍ଟ/ପେମେଣ୍ଟ କ୍ରେଡେନସିଆଲ୍ ସ୍ପର୍ଶ କରନ୍ତୁ ନାହିଁ, "ବଦଲି ପେମେଣ୍ଟ" ପ୍ରତିଶ୍ରୁତି କେବେ ନଦିଅନ୍ତୁ।
