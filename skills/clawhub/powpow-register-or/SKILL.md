# PowPow Register (ବବୁଲ ପଞ୍ଜୀକରଣ ସହାୟକ)

ନୂଆ ଉପଯୋଗକର୍ତାଙ୍କୁ "ମୁଁ ଜାଣିନାହିଁ Bubble କଣ" ରୁ "ଏକ କ୍ଲିକରେ ଲଗଇନ୍, ଖେଳିବାକୁ ପ୍ରସ୍ତୁତ" ପର୍ଯ୍ୟନ୍ତ ନେଇଯାଏ — ସଂଳାପ ଭିତରେ ସମ୍ପୂର୍ଣ୍ଣ। ଉପଯୋଗକର୍ତା ସଂଳାପ ଛାଡିବେ ଥରେ ମାତ୍ର: **ଇନବକ୍ସରେ ଭେରିଫିକେଶନ କୋଡ୍ ଦେଖିବାକୁ**। ପ୍ଲାଟଫର୍ମ ବର୍ତ୍ତମାନ ମାଗଣା ପରୀକ୍ଷଣ ଅବଧିରେ ଅଛି: ରେଜିଷ୍ଟର୍ ହେବା ପରେ ସବୁ ବୈଶିଷ୍ଟ୍ୟ ବ୍ୟବହାରଯୋଗ୍ୟ, ପେମେଣ୍ଟ ଆବଶ୍ୟକ ନୁହେଁ; ସବସ୍କ୍ରିପଶନ ପେମେଣ୍ଟ ହେଉଛି ଇଚ୍ଛାଧୀନ ସଦସ୍ୟତା ଅପଗ୍ରେଡ୍ (ଏଜେଣ୍ଟ କ୍ୟାଶିର୍ ଖୋଲିବା ଏବଂ ଆଗମନ ଟ୍ରାକ୍ ମଧ୍ୟ କରେ)।

**ସଂସ୍କରଣ 2.2.0** · 2026-10-18 (v2 ଠାରୁ ଏହା ଏଜେଣ୍ଟ-ସହାୟକ ମୋଡ୍: ସ୍କ୍ରିପ୍ଟ ଚୁକ୍ତି ଏବଂ ପୂର୍ଣ୍ଣ କ୍ରମ `references/agent-flow.md` ରେ; ଫିଲ୍ଡ ନିୟମ, ହାର ସୀମା ଏବଂ ତ୍ରୁଟି ନିବାରଣ `references/registration-flow.md` ରେ; ପେମେଣ୍ଟ ଚ୍ୟାନେଲ୍ `references/payment-and-activation.md` ରେ; ଉତ୍ପାଦ ସ୍କ୍ରିନଶଟ୍ ତାଲିକା `references/screenshots.md` ରେ। v2.1.0 ଠାରୁ ଏଜେଣ୍ଟ PayPal ସବସ୍କ୍ରିପଶନ ମଧ୍ୟ Alipay ସହିତ ବିକଳ୍ପ ଭାବରେ ପରିଚାଳନା କରିପାରିବ। v2.2.0 ଠାରୁ ପ୍ଲାଟଫର୍ମ ମାଗଣା ପରୀକ୍ଷଣ ଅବଧିରେ ଅଛି: ରେଜିଷ୍ଟର୍ କରି ଏକ କ୍ଲିକରେ ଲଗଇନ୍ କରି ବ୍ୟବହାର ଆରମ୍ଭ କରନ୍ତୁ; ପେମେଣ୍ଟ ଇଚ୍ଛାଧୀନ ଅପଗ୍ରେଡ୍ ହୋଇଯାଏ — ଉପଯୋଗକର୍ତା ଲିଙ୍କ୍ ଦବାଇ ସବସ୍କ୍ରିପଶନ ପୃଷ୍ଠାରେ ଅବତରଣ କଲେ, ପରୀକ୍ଷଣ ଅବଧି ସମାପ୍ତ, ଚରଣ 7 ପେମେଣ୍ଟ ପ୍ରବାହ ଅନୁସରଣ କରନ୍ତୁ; ପ୍ରବାହ ନିଜେ ନିଜେ ଅନୁକୂଳ ହୁଏ, ସ୍କ୍ରିପ୍ଟ ପରିବର୍ତ୍ତନ ଆବଶ୍ୟକ ନୁହେଁ)

## ଚାଲାଉ ପରିବେଶ

- ମୂଳ ସ୍କ୍ରିପ୍ଟ `scripts/powpow-register.mjs`: **କୌଣସି ନିର୍ଭରତା ନାହିଁ**, **Node >= 18** ଆବଶ୍ୟକ। ଆରମ୍ଭ ପୂର୍ବରୁ ଥରେ `node scripts/powpow-register.mjs status` ଚଲାଇ ପରିବେଶ ଠିକ୍ ଅଛି କି ନାହିଁ ନିଶ୍ଚିତ କରନ୍ତୁ।

- **Node ନାହିଁ / ସ୍କ୍ରିପ୍ଟ ତ୍ରୁଟି** — ସ୍ୱତଃ ଶୁଦ୍ଧ ମାର୍ଗଦର୍ଶନ ମୋଡକୁ ଫେରେ — ଉପଯୋଗକର୍ତାଙ୍କୁ ରେଜିଷ୍ଟ୍ରେଶନ ପୃଷ୍ଠା https://global.powpow.online/register ଦିଅନ୍ତୁ ଏବଂ `references/registration-flow.md` ଅନୁସାରେ ପାଖରେ ମାର୍ଗଦର୍ଶନ କରନ୍ତୁ (ମାଗଣା ପରୀକ୍ଷଣ ଅବଧିରେ ୱେବ୍ ରେଜିଷ୍ଟ୍ରେଶନ୍ ସମାନ ଭାବରେ ତ୍ୱରିତ)। ସ୍କ୍ରିପ୍ଟକୁ ବାରମ୍ବାର ଠେଲନ୍ତୁ ନାହିଁ।
- କଥାବାର୍ତ୍ତା ଭାଙ୍ଗିଯିବା ପରେ ପୁନରୁଦ୍ଧାର: ପ୍ରଥମେ `status` ଚଲାଇ ପ୍ରକ୍ରିୟା କେଉଁ ପଦକ୍ଷେପରେ ଅଛି ଦେଖନ୍ତୁ, ତା'ପରେ ଆଗକୁ ବଢ଼ନ୍ତୁ।

## ପଦକ୍ଷେପ 1: ଉତ୍ପାଦ ପରିଚୟ + ସ୍କ୍ରିନସଟ୍ (ଛାଡ଼ିପାରିବା ନାହିଁ)

ଅଧିକାଂଶ ଉପଭୋକ୍ତା ବବୁଲ କେବେହି ଦେଖିନାହାନ୍ତି। କଥା ଆରମ୍ଭରେ ପ୍ରଥମ କାମ ପ୍ରକ୍ରିୟା ବୁଝାଇବା ନୁହେଁ, ବରଂ ତାଙ୍କୁ ଉତ୍ପାଦ **ଦେଖାଇବା**:

1. ପ୍ରାୟ 120 ଶବ୍ଦରେ ବବୁଲ ପରିଚୟ ଦିଅନ୍ତୁ: ଯେଉଁ ଫଟୋ ଯାଇଥିବା ସମୟରେ ଚିତ୍ର ଖିଚିଛନ୍ତି ତାକୁ ଯାତ୍ରା ବୃତ୍ତାନ୍ତରେ ପରିଣତ କରି ପବ୍ଲିକ୍ ମାନଚିତ୍ରରେ ପିନ୍ କଲେ ଗୋଟିଏ "ବୁଦବୁଦ" ହୁଏ; ବୁଦବୁଦ ସମୟ ସହିତ ମରିଯାଏ, ଅନ୍ୟମାନେ ଲାଇକ୍ ଦେଲେ ପୁଣି ଜୀବିତ ହୁଏ; ମାନଚିତ୍ରରେ କଥା ହୋଇପାରୁଥିବା "ଡିଜିଟାଲ୍ ମାନବ" ମଧ୍ୟ ଅଛନ୍ତି। ପ୍ଲାଟଫର୍ମ ଠିକଣା https://global.powpow.online , ପ୍ରଥମେ ଭିଡିଓ ଦେଖିବାକୁ ଚାହୁଁଥିଲେ: https://www.bilibili.com/video/BV1Wu826UEVz/
2. **ସ୍କ୍ରିନସଟ୍ ପଠାନ୍ତୁ**। ସ୍କ୍ରିନସଟ୍ skill ସହିତ `assets/screenshots/powpow-0N.jpg` ରେ ପ୍ୟାକ ହୋଇଛି — ସିଧା ଲୋକାଲ୍ ଇମେଜ୍ ଫାଇଲ୍ ଭାବେ ପଠାନ୍ତୁ, ଇଣ୍ଟରନେଟ୍ ଆବଶ୍ୟକ ନାହିଁ। ତାଲିକା, ପ୍ରତ୍ୟେକ ଚିତ୍ରର ବିଷୟବସ୍ତୁ ଓ ବ୍ୟବହାର ସମୟ `references/screenshots.md` ରେ ଦେଖନ୍ତୁ। ଆରମ୍ଭରେ ସବୁଠାରୁ ଅଧିକ ବ୍ୟବହୃତ ସଂଯୋଗ: ମାନଚିତ୍ର ପୃଷ୍ଠା (powpow-03) + ପୋଷ୍ଟ ବିବରଣୀ ପୃଷ୍ଠା (powpow-06)।

ସ୍କ୍ରିନସଟ୍ ନିୟମ (କଠୋର ନିୟମ):

- ସ୍କ୍ରିନସଟ୍ **skill ସହିତ ପ୍ୟାକ ହୋଇଛି** `assets/screenshots/` ରେ (`powpow-0N.jpg`) — ସିଧା ଲୋକାଲ୍ ଇମେଜ୍ ଫାଇଲ୍ ପଠାନ୍ତୁ; ଯେକୌଣସି ପରିବେଶରେ କାମ କରେ, GitHub ଖୋଲି ନପାରୁଥିବା ପରିବେଶ ସହିତ।
- ପ୍ରତିଥର କେବଳ ବର୍ତ୍ତମାନ ବିଷୟ ସହିତ ସମ୍ବନ୍ଧିତ 1–3 ଟି ଚିତ୍ର ପଠାନ୍ତୁ, ଏକଠି ସବୁ ନପଠାନ୍ତୁ।
- ପ୍ୟାକେଜ୍ ଭିତରର ଫାଇଲ୍ ଅକସ୍ମାତ ଅନୁପସ୍ଥିତ ହେଲେ, `references/screenshots.md` ରେ ତାଲିକାଭୁକ୍ତ ହୋଷ୍ଟ ଲିଙ୍କକୁ ଫେରନ୍ତୁ (ଧ୍ୟାନ: ଚୀନରେ ଖୋଲି ନପାରେ)।

ପରିଚୟ ସମାପ୍ତ ହେଲେ, ପସନ୍ଦ ଉପଭୋକ୍ତାଙ୍କୁ ଦିଅନ୍ତୁ: **"ପଞ୍ଜୀକରଣ କରିବାକୁ ଚାହୁଁଥିଲେ, ଆମେ ତିନି ମିନିଟରେ କଥାବାର୍ତ୍ତା ଭିତରେ ଆକାଉଣ୍ଟ ତିଆରି କରିଦେବା, ଆପଣ କେବଳ ଥରେ ଇମେଲ ଯାଞ୍ଚ କୋଡ୍ ଦେଖିବାକୁ ହେବ।"**

## ପଦକ୍ଷେପ 2: ପଞ୍ଜୀକରଣ ସୂଚନା ନିଶ୍ଚିତ କରନ୍ତୁ (ଗୋଟିଏ ପ୍ରଶ୍ନ ପ୍ରତି ରାଉଣ୍ଡ, ଏକଠି ସବୁ ନପଚାରନ୍ତୁ)

- **ଉପଭୋକ୍ତା ନାମ** (ଆବଶ୍ୟକ): କଥାବାର୍ତ୍ତା ପ୍ରସଙ୍ଗ/ସିଷ୍ଟମ୍ ଉପଭୋକ୍ତା ନାମ ଠାରୁ **ସକ୍ରିୟ ଭାବେ ଗୋଟିଏ ସୁଝନ୍ତୁ** (2~50 ଅକ୍ଷର, ବଡ଼ ଛୋଟ ଅକ୍ଷର ପାର୍ଥକ୍ୟ ନାହିଁ), ଉପଭୋକ୍ତା ରାଜି ହେଲେ ବ୍ୟବହାର କରନ୍ତୁ, ବଦଳାଇବାକୁ ଚାହିଁଲେ ବଦଳାନ୍ତୁ।
- **ପାସୱାର୍ଡ** (ଆବଶ୍ୟକ, ପ୍ରଥମେ ଉପଭୋକ୍ତାଙ୍କୁ ଦୁଇରୁ ଗୋଟିଏ ବାଛିବାକୁ କୁହନ୍ତୁ):
  - ଉପଭୋକ୍ତା ନିଜେ ଦେଲେ → ପରେ ଏନଭାୟରନମେଣ୍ଟ ଭେରିଏବଲ୍ ମାଧ୍ୟମରେ ସ୍କ୍ରିପ୍ଟକୁ ଦିଅନ୍ତୁ, **କମାଣ୍ଡ ଲାଇନ୍ ପାରାମିଟରରେ କେବେ ନଲେଖନ୍ତୁ**;
  - agent ସୃଷ୍ଟି କରେ → `node scripts/powpow-register.mjs gen-password` ଚଲାନ୍ତୁ, ସୃଷ୍ଟି ହୋଇଥିବା ପାସୱାର୍ଡ **ତୁରନ୍ତ ଉପଭୋକ୍ତାଙ୍କୁ ପଠାଇ ସେଭ୍ କରିବାକୁ କୁହନ୍ତୁ** (କେବଳ ଏଥର ଦେଖାଏ, ପରେ ଆଉ ଦେଖାଏ ନାହିଁ)।
- **ଇମେଲ** (ଆବଶ୍ୟକ): ଉପଭୋକ୍ତା ନିଜେ ଦେବା ଉଚିତ — ଏହା ଆକାଉଣ୍ଟର ପରିଚୟ ଆଙ୍କର, **ଉପଭୋକ୍ତା ପାଇଁ ଅନୁମାନ କରନ୍ତୁ ନାହିଁ**।
- **ଡାକନାମ** (ଇଚ୍ଛାଧୀନ): ଡିଫଲ୍ଟ ଉପଭୋକ୍ତା ନାମ ସହିତ ସମାନ ରଖିବାକୁ ସୁଝନ୍ତୁ।
- **ପ୍ରୋଫାଇଲ୍ ଫଟୋ** (ଇଚ୍ଛାଧୀନ): ଉପଭୋକ୍ତା ଲୋକାଲ୍ ଇମେଜ୍ ପାଥ (≤5MB, SVG ନୁହେଁ) ଦେଲେ ସ୍କ୍ରିପ୍ଟ ସିଧା ଅପଲୋଡ୍ କରିବ; ନଥିଲେ ଛାଡ଼ିଦିଅନ୍ତୁ (ପ୍ଲାଟଫର୍ମ ଡିଫଲ୍ଟ ଲୋଗୋ ବ୍ୟବହାର କରିବ); ଆପଣଙ୍କର ଇମେଜ୍ ସୃଷ୍ଟି କ୍ଷମତା ଥିଲେ ଉପଭୋକ୍ତାଙ୍କ ପାଇଁ ଗୋଟିଏ ତିଆରି କରିବାକୁ ସକ୍ରିୟ ଭାବେ ସୁଝାଇପାରିବେ।
- **ମୋବାଇଲ୍ ନମ୍ବର** (ଇଚ୍ଛାଧୀନ, ମୁଖ୍ୟଭୂମି ନମ୍ବର): ଡିଫଲ୍ଟ ଛାଡ଼ିଦିଅନ୍ତୁ, ଉପଭୋକ୍ତା ନିଜେ ବାନ୍ଧିବାକୁ ଚାହିଁଲେ ମାଗନ୍ତୁ।

ନିଶ୍ଚିତ ହେବା ପରେ `prepare-suggest --username U --nickname N --email E` ଚଲାଇ ଷ୍ଟେଟ୍ ଫାଇଲ୍ ରେ ଲେଖାଯାଇପାରେ (ପରେ register କୁ ପୁଣି ପଠାଇବାର ଆବଶ୍ୟକ ନାହିଁ)।

## ପଦକ୍ଷେପ 3–4: ଇମେଲ ଯାଞ୍ଚ କୋଡ୍ (କଥାବାର୍ତ୍ତା ଛାଡ଼ିବା ଆବଶ୍ୟକ ହେଉଥିବା ଏକମାତ୍ର ପାଦ)

```
node scripts/powpow-register.mjs send-code --email <ଇମେଲ>
```

ତା'ପରେ ଉପଭୋକ୍ତାଙ୍କୁ ସ୍ପଷ୍ଟ କରି କୁହନ୍ତୁ: **ଇମେଲକୁ ଯାଇ 6 ଅଙ୍କର ଯାଞ୍ଚ କୋଡ୍ ଖୋଜନ୍ତୁ, 10 ମିନିଟ ପର୍ଯ୍ୟନ୍ତ ମାନ୍ୟ, ସ୍ପାମ/ବିଜ୍ଞାପନ ମେଲ୍ ଫୋଲ୍ଡର ମଧ୍ୟ ଦେଖନ୍ତୁ ବୋଲି ମନେ ରଖନ୍ତୁ**, ମିଳିଲେ ଫେରି କୋଡ୍ ପଠାନ୍ତୁ। ପଠାଇବାରେ 60 ସେକେଣ୍ଡ କୁଲଡାଉନ୍ ଅଛି, ବାରମ୍ବାର କ୍ଲିକ୍ କରନ୍ତୁ ନାହିଁ।

## ଚରଣ 6 — ଏକ-କ୍ଲିକ୍ ଲଗଇନ୍ (ରେଜିଷ୍ଟ୍ରେଶନ ପରେ ସିଧା ହୋମ୍ ପୃଷ୍ଠାରେ)

## ଚରଣ 8 — କାର୍ଯ୍ୟ ଶେଷ

2. ଉପଯୋଗକର୍ତାଙ୍କୁ "ଏକାଉଣ୍ଟ କାର୍ଡ୍" ଦିଅନ୍ତୁ — ୟୁଜରନେମ୍, ଇମେଲ୍ (ପାସୱାର୍ଡ ପୁଣି ଦେଖାଯାଏ ନାହିଁ — ସୃଷ୍ଟି ମୋଡରେ ୟୁଜରନେମ୍ ସୃଷ୍ଟି ହେବା ବେଳେ ସଂରକ୍ଷଣ କରିବାକୁ କୁହାଯାଇଥିଲା; ଉପଯୋଗକର୍ତା ନିଜେ ସେଟ୍ କଲେ, ସେମାନେ ଜାଣନ୍ତି)।

- **ପାସୱାର୍ଡ ବିଷୟରେ ନିଜୁଆଁ ଉପଦେଶ ନଦିଅନ୍ତୁ**; ଆଭ୍ୟନ୍ତରୀଣ ଯନ୍ତ୍ର, ରେଟ ଲିମିଟ କିମ୍ବା ନିରାପତ୍ତା ଡିଜାଇନ୍ ବୁଝାନ୍ତୁ ନାହିଁ, ଉପଭୋକ୍ତା ପଚାରିଲେ ଛଡ଼ା।

## କଠୋର ନିୟମ

- **କ୍ରେଡେନସିଆଲ୍ ନିରାପତ୍ତା**: ପାସୱାର୍ଡ କେବଳ ଏନଭାୟରନମେଣ୍ଟ ଭେରିଏବଲ୍ `POWPOW_REGISTER_PASSWORD` ମାଧ୍ୟମରେ ସ୍କ୍ରିପ୍ଟକୁ ଦିଅନ୍ତୁ, **କମାଣ୍ଡ ଲାଇନ୍ ପାରାମିଟରରେ କେବେ ନଲେଖନ୍ତୁ** (ପ୍ରୋସେସ୍ ତାଲିକାରେ ଦେଖାଯାଏ), କୌଣସି ଫାଇଲ୍ ରେ ନଲେଖନ୍ତୁ (ସୃଷ୍ଟି ମୋଡରେ ଏଥର ଦେଖାଏ ଯାହା ଉପଭୋକ୍ତା ସେଭ୍ କରିବା ପାଇଁ, ପରେ ପୁଣି କୁହାଯାଏ ନାହିଁ)। ଯାଞ୍ଚ କୋଡ୍ କେବଳ ଅଧିକାରୀ ପଞ୍ଜୀକରଣ API ପାଇଁ, ବ୍ୟବହାର ପରେ ଫୋପାଡ଼ନ୍ତୁ।
- **ଅଧିକାରୀ ସୀମା**: ସମସ୍ତ ଅନୁରୋଧ କେବଳ `https://global.powpow.online` କୁ (ସ୍କ୍ରିପ୍ଟ ଭିତରେ ଅଛି), ଉପଭୋକ୍ତା ସୂଚନା କେବେ ବି କୌଣସି ତୃତୀୟ ପକ୍ଷ ଠିକଣାକୁ ନପଠାନ୍ତୁ।
- **ପେମେଣ୍ଟ ସୀମା**: agent କେବଳ ଅର୍ଡର ସୃଷ୍ଟି କରେ, କାଉଣ୍ଟର ଖୋଲେ, ଟାକା ଆସିବା ପଚାରେ; **କେବେ ବି** ଉପଭୋକ୍ତାଙ୍କ Alipay/PayPal ଆକାଉଣ୍ଟ/ପେମେଣ୍ଟ କ୍ରେଡେନସିଆଲ୍ ସ୍ପର୍ଶ କରନ୍ତୁ ନାହିଁ, "ବଦଲି ପେମେଣ୍ଟ" ପ୍ରତିଶ୍ରୁତି କେବେ ନଦିଅନ୍ତୁ।
- **ପେୱାଲ୍ ଏକ ବଗ୍ ନୁହେଁ** — ବର୍ତ୍ତମାନ ମାଗଣା ପରୀକ୍ଷଣ ଅଵଧିରେ ସବୁ ବିଷୟବସ୍ତୁ ପୃଷ୍ଠା ଖୋଲା ଅଛି; ଉପଯୋଗକର୍ତା ହୋମ୍ ପୃଷ୍ଠା ଲିଙ୍କ୍ ଦବାଇଲେ ମଧ୍ୟ ସବସ୍କ୍ରିପଶନ ପୃଷ୍ଠାରେ ଅଵତରଣ କଲେ, ପରୀକ୍ଷଣ ଅଵଧି ସମାପ୍ତ — ଚରଣ 7 ମାଧ୍ୟମରେ ସବସ୍କ୍ରାଇବ୍ କରିବାକୁ ମାର୍ଗଦର୍ଶନ କରନ୍ତୁ। ପେୱାଲ୍ ବାଇପାସ୍ କରିବାକୁ ଚେଷ୍ଟା କରନ୍ତୁ ନାହିଁ, ଆଉ ଉପଯୋଗକର୍ତାଙ୍କୁ ଆଭ୍ୟନ୍ତରୀଣ ମେକାନିଜମ୍ ବୁଝାନ୍ତୁ ନାହିଁ।
