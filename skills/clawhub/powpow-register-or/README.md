# powpow-register

PowPow ବବୁଲ ପଞ୍ଜୀକରଣ ସହାୟକ (OpenClaw ସଂସ୍କରଣ): ଏକ ନୂଆ ଉପଭୋକ୍ତାଙ୍କୁ "ବବୁଲ କଣ ଜାଣି ନାହିଁ" ଠାରୁ "ଆକାଉଣ୍ଟ ସକ୍ରିୟ, ଏକ-କ୍ଲିକ୍ ଲଗଇନ୍, ଖେଳ ଆରମ୍ଭ" ପର୍ଯ୍ୟନ୍ତ ନେବା — ଉତ୍ପାଦ ପରିଚୟ (ଇଣ୍ଟରଫେସ୍ ସ୍କ୍ରିନସଟ୍ ସହିତ), agent-ସହାୟତା ପଞ୍ଜୀକରଣ (ପ୍ରୋଫାଇଲ୍ ଫଟୋ ଅପଲୋଡ୍ ସହିତ), Alipay/PayPal ସବସ୍କ୍ରିପସନ୍ ଅର୍ଡର ଓ ପେମେଣ୍ଟ ଟ୍ରାକିଂ, ଦୁଇ ଲିଙ୍କ ଏକ-କ୍ଲିକ୍ ଲଗଇନ୍, ତ୍ରୁଟି ନିବାରଣ।

**v2.0.0 ଠାରୁ ଏହା ଏଜେଣ୍ଟ-ସହାୟକ ମୋଡ୍, ଆଉ v2.2.0 ଠାରୁ ପ୍ଲାଟଫର୍ମ ମାଗଣା ପରୀକ୍ଷଣ ଅଵଧି ସହିତ ଅନୁକୂଳ** — ମୂଳ ସ୍କ୍ରିପ୍ଟ `scripts/powpow-register.mjs` ଶୂନ୍ୟ-ନିର୍ଭରଶୀଳତା
(Node ≥ 18); ଉପଯୋଗକର୍ତା ସଂଳାପ ଛାଡିବେ ଥରେ ମାତ୍ର — ଇନବକ୍ସରେ ଭେରିଫିକେଶନ କୋଡ୍ ଦେଖିବାକୁ। ବର୍ତ୍ତମାନ ମାଗଣା ପରୀକ୍ଷଣ ଅଵଧିରେ ରେଜିଷ୍ଟର୍ ହୋଇଥିବା ଏକାଉଣ୍ଟ ସବୁ ବୈଶିଷ୍ଟ୍ୟ ତକେ ବ୍ୟବହାର କରିପାରିବ — ସବସ୍କ୍ରିପଶନ ପେମେଣ୍ଟ ଇଚ୍ଛାଧୀନ ଅପଗ୍ରେଡ୍; ପରୀକ୍ଷଣ ଅଵଧି ସମାପ୍ତ ହୋଇ ଉପଯୋଗକର୍ତା ସବସ୍କ୍ରିପଶନ ପୃଷ୍ଠାରେ ଅଵତରଣ କଲେ, ପ୍ରବାହ ସ୍ୱତଃ ପେମେଣ୍ଟ ପଥକୁ ଯାଏ। Node ବିନା, କିମ୍ବା ଉପଯୋଗକର୍ତା ନିଜେ କରିବା ଚାହିଁଲେ, ସ୍ୱତଃ ଶୁଦ୍ଧ ମାର୍ଗଦର୍ଶନ ମୋଡକୁ ଫେରେ।

## ବିଶେଷତ୍ୱ

1. **ଉତ୍ପାଦ ପରିଚୟ**: ପ୍ରାୟ 120 ଶବ୍ଦର ପରିଚୟ + ପ୍ୟାକେଜ ସହିତ ଅନ୍ତର୍ନିହିତ ଇଣ୍ଟରଫେସ୍ ସ୍କ୍ରିନସଟ୍ (`assets/screenshots/` ଭିତରେ 6 ଟି: ମାନଚିତ୍ର ପୃଷ୍ଠା, ପୋଷ୍ଟ ବିବରଣୀ ପୃଷ୍ଠା ଇତ୍ୟାଦି, ପରିସ୍ଥିତି ଅନୁସାରେ 1–3 ଟି ପଠାନ୍ତୁ; ବାହ୍ୟ ଇମେଜ୍ ହୋଷ୍ଟ ଆବଶ୍ୟକ ନାହିଁ, ଅଫଲାଇନ୍ କାମ କରେ)।
2. **ସହାୟତା ପଞ୍ଜୀକରଣ**: agent ସକ୍ରିୟ ଭାବେ ଉପଭୋକ୍ତା ନାମ/ଡାକନାମ ସୁଝାଏ, ପାସୱାର୍ଡ ଦୁଇରୁ ଗୋଟିଏ (ଉପଭୋକ୍ତା ଦିଏ କିମ୍ବା agent ସୃଷ୍ଟି କରେ), ଯାଞ୍ଚ କୋଡ୍ ପଠାଏ ଓ ଦାଖଲ କରେ, ପ୍ରୋଫାଇଲ୍ ଫଟୋ ସିଧା ଅପଲୋଡ୍ (≤5MB, SVG ନୁହେଁ), ସାଧାରଣ ତ୍ରୁଟି ସ୍ୱୟଂ ସମ୍ଭାଳେ (ଅଧିକୃତ/ମିତି ପାର/ରେଟ ଲିମିଟ)।
3. **ଏକ-କ୍ଲିକ୍ ଲଗଇନ୍ (ଦ୍ୱି ଲିଙ୍କ୍)** — ସଫଳ ରେଜିଷ୍ଟ୍ରେଶନ ପରେ ତକେ, ଲଗଇନ୍ ଲିଙ୍କ୍ ଉପଯୋଗକର୍ତାଙ୍କୁ ସିଧା ହୋମ୍ ପୃଷ୍ଠାରେ ଅଵତରଣ କରାଏ (ମାଗଣା ପରୀକ୍ଷଣ ଅଵଧିରେ, ଏକ କ୍ଲିକରେ ବ୍ୟବହାରଯୋଗ୍ୟ),
   ସବସ୍କ୍ରିପଶନ ପୃଷ୍ଠାରେ ଅଵତରଣ କଲେ (ପରୀକ୍ଷଣ ଅଵଧି ସମାପ୍ତ) କିମ୍ବା ଉପଯୋଗକର୍ତା ଅପଗ୍ରେଡ୍ ଚାହିଁଲେ, ସବସ୍କ୍ରିପଶନ ପ୍ରବାହ ଅନୁସରଣ କରନ୍ତୁ — ପେମେଣ୍ଟ ପହଞ୍ଚିବା ପରେ ନୂଆ ଲଗଇନ୍ ସ୍ଥିତି ବଦଳି ସମ୍ପୂର୍ଣ୍ଣ ସଦସ୍ୟତା ଲିଙ୍କ୍ ହୋମ୍ ପୃଷ୍ଠାରେ ଅଵତରଣ କରାଏ
   (ପ୍ଲାଟଫର୍ମର ଆଧିକାରିକ `me?token=` ସେତୁ ମାଧ୍ୟମରେ, ଯାହା ସ୍ୱତଃ HttpOnly କୁକି ରଖେ)।
4. **ସବସ୍କ୍ରିପସନ୍ ପେମେଣ୍ଟ**: Alipay (ମାସ ¥6.99 / ତ୍ରୈମାସ ¥19.99 / ବର୍ଷ ¥69.99, ଥରେ କିଣା ସ୍ୱୟଂଚାଳିତ ନବୀକରଣ ନାହିଁ) ଓ PayPal (Premium Monthly, ପ୍ରାୟ $1/ମାସ, ସ୍ୱୟଂଚାଳିତ ନବୀକରଣ, ଯେକୌଣସି ସମୟ ବାତିଲ କରାଯାଇପାରେ) ଉଭୟକୁ ମଧ୍ୟ agent ଅର୍ଡର କରେ + ପେମେଣ୍ଟ ପୋଲିଂ; ବିଦେଶୀ ଉପଭୋକ୍ତା PayPal କୁ ଫେରନ୍ତି; WeChat QR / Huawei IAP ରାସ୍ତା ଦେଖାଏ।
5. **ତ୍ରୁଟି ନିବାରଣ**: ଯାଞ୍ଚ କୋଡ୍ ଆସୁନାହିଁ, ଉପଭୋକ୍ତା ନାମ/ଇମେଲ ଅଧିକୃତ, 403 ସକ୍ରିୟ ନାହିଁ, ଆକାଉଣ୍ଟ ଲକ୍ ଆଦି ସାଧାରଣ ସମସ୍ୟା, ସବୁ ପ୍ଲାଟଫର୍ମ ସୋର୍ସ କୋଡ୍ ଠାରୁ ଓ ଉଲ୍ଲେଖ ସହିତ।

## ନିରାପତ୍ତା

- **ପାସୱାର୍ଡ** କେବଳ ଏନଭାୟରନମେଣ୍ଟ ଭେରିଏବଲ୍ ମାଧ୍ୟମରେ ସ୍କ୍ରିପ୍ଟ ପ୍ରୋସେସରେ ଯାଏ, କମାଣ୍ଡ ଲାଇନ୍ ପାରାମିଟରରେ କେବେ ନଲେଖାଏ, ଡିସ୍କରେ ନରହେ, ଷ୍ଟେଟ୍ ଫାଇଲ୍ ରେ ନଯାଏ; agent ସୃଷ୍ଟି କରିଥିବା ପାସୱାର୍ଡ କେବଳ ଥରେ ଦେଖାଏ ଯାହା ଉପଭୋକ୍ତା ସେଭ୍ କରିବେ।
- **ଯାଞ୍ଚ କୋଡ୍** କେବଳ ଅଧିକାରୀ ପଞ୍ଜୀକରଣ API ପାଇଁ, ବ୍ୟବହାର ପରେ ଫୋପାଡ଼ାଯାଏ; ଷ୍ଟେଟ୍ ଫାଇଲ୍ (ଇମେଲ/ଉପଭୋକ୍ତା ନାମ/token/ଅର୍ଡର ନମ୍ବର) ସିଷ୍ଟମ୍ ଅସ୍ଥାୟୀ ଡିରେକ୍ଟୋରୀରେ ରହେ, ପ୍ରବାହ ଶେଷରେ `cleanup` ଏକ କ୍ଲିକ୍ ରେ ସଫା।
- **ପେମେଣ୍ଟ**: agent କେବଳ ଅର୍ଡର ସୃଷ୍ଟି କରେ, କାଉଣ୍ଟର ଖୋଲେ, ପେମେଣ୍ଟ ପଚାରେ; ଉପଭୋକ୍ତାଙ୍କ Alipay/PayPal ଆକାଉଣ୍ଟ କିମ୍ବା ପେମେଣ୍ଟ କ୍ରେଡେନସିଆଲ୍ କେବେ ସ୍ପର୍ଶ କରେ ନାହିଁ, ବଦଲି ପେମେଣ୍ଟ କେବେ କରେ ନାହିଁ। ପେମେଣ୍ଟ ସବୁସମୟ ଉପଭୋକ୍ତା ଓ ଅଧିକାରୀ କାଉଣ୍ଟର ମଧ୍ୟରେ ହୁଏ।
- ସମସ୍ତ ଅନୁରୋଧ କେବଳ ଅଧିକାରୀ ଡୋମେନ୍ `https://global.powpow.online` କୁ; କୌଣସି କି ନାହିଁ।
