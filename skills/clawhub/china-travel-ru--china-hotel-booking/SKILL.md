# Бронирование отелей в Китае

## Описание

Поиск отелей в Китае в реальном времени с рекомендациями, ценами и ссылками для бронирования. Разработано для иностранных туристов, посещающих Китай, предоставляет информацию об отелях на английском языке через TripGenie API от Trip.com, охватывая все основные направления, включая Пекин, Шанхай, Сиань, Чэнду, Гуанчжоу и другие.

## Когда использовать

Используйте этот навык, когда пользователь хочет:
- Найти отели в китайском городе
- Получить рекомендации отелей с ценами и ссылками для бронирования
- Искать отели по бюджету, предпочтениям по расположению или датам поездки
- Сравнить варианты отелей для поездки в Китай

Ключевые слова: Китай отель, отель в Пекине, проживание в Шанхае, проживание в Китае, бронирование отеля, бюджетный отель, роскошный отель

## Выполнение

### Шаг 1: Определение параметров из запроса пользователя

Извлеките следующее из запроса пользователя:

| Параметр | Описание | Пример |
|----------|----------|--------|
| city | Название города (английский или русский, обязательно) | "Beijing" or "Пекин" |
| check_in | Дата заезда YYYY-MM-DD (необязательно) | "2026-08-01" |
| check_out | Дата выезда YYYY-MM-DD (необязательно) | "2026-08-05" |
| guests | Количество гостей (необязательно, по умолчанию: 2) | 2 |
| budget | Уровень бюджета или сумма (необязательно) | "до $100/ночь" |
| preferences | Дополнительные предпочтения (необязательно) | "рядом с Запретным городом" |

### Шаг 2: Запуск скрипта

```bash
python scripts/china_travel.py hotel "<city>" "[check_in]" "[check_out]" [guests] "[budget]" "[preferences]" --locale=ru
```

**Важно:** Всегда включайте параметр `--locale=ru` для получения результатов на русском языке.

### Шаг 3: Отображение результатов

API возвращает структурированный Markdown с названиями отелей, ценами, рейтингами, ключевыми особенностями и ссылками для бронирования. Представьте контент напрямую пользователю.

В конце результатов также будут предоставлены рекомендации по другим функциям (поиск авиабилетов, поиск достопримечательностей, планирование поездки, советы для путешественников) на русском языке.

## Примеры

**Пользователь:** "Найди отели в Шанхае рядом с набережной для 2 взрослых"
```bash
python scripts/china_travel.py hotel "Shanghai" "" "" 2 "" "near the Bund" --locale=ru
```

**Пользователь:** "Бюджетные отели в Пекине с 10 по 12 июля"
```bash
python scripts/china_travel.py hotel "Beijing" "2026-07-10" "2026-07-12" 2 "under $80/night" --locale=ru
```

**Пользователь:** "Роскошный отель в Чэнду для 3 гостей"
```bash
python scripts/china_travel.py hotel "Chengdu" "" "" 3 "luxury" --locale=ru
```

## Примечания

- Названия городов можно вводить на английском или русском языке
- Даты необязательны, но помогают сузить доступность и цены
- API поддерживает предпочтения на естественном языке (например, "рядом с метро", "с завтраком")
- Ссылки для бронирования ведут напрямую на Trip.com (международная версия)
- Все результаты отображаются на русском языке
