## 概览
本文档定义了供应商IQC质量分析所需的数据结构和字段映射规范。当脚本无法自动识别字段时，需用户提供字段映射信息。

## 必需字段

| 字段类型 | 字段名称 | 可选别名 | 说明 | 示例 |
|---------|---------|---------|------|------|
| 供应商名称 | supplier_name | 供应商/厂商/供方名称 | 供应商唯一标识 | "XX电子有限公司" |
| 物料编码 | material_code | 物料号/零件号/料号 | 物料唯一标识 | "M-2024-001" |

| 检验日期 | inspect_date | 检验时间/来料日期 | 检验日期（YYYY-MM-DD） | "2024-01-15" |
| 来料数量 | quantity | 来料数/送检数量 | 批次来料总数 | 1000 |
| 不良数量 | defect_qty | 不良数/缺陷数量 | 批次不良总数 | 5 |
| 不良类型 | defect_type | 不良类别/缺陷类型 | 不良分类（如尺寸、外观、性能） | "尺寸超差" |

## 字段映射格式

当脚本无法自动识别字段时，需用户提供以下JSON格式的字段映射：

```json
{
  "supplier_name": "供应商名称",
  "material_code": "物料编码",
  "batch_no": "批次号",
  "inspect_date": "检验日期",
  "quantity": "来料数量",
  "defect_qty": "不良数量",
  "defect_type": "不良类型",
  "inspect_item": "检验项目"
}
```

**说明**：
- Key为标准字段名（必需字段中的"字段类型"列）
- Value为用户Excel中的实际列名
- 若某字段不存在，可省略（但supplier_name、quantity、defect_qty、defect_type为必填）

## Sheet关联规则

当Excel包含多个Sheet时，脚本会自动尝试识别关联关系：

**常见关联字段**：
- 批次号（batch_no）
- 物料编码（material_code）
- 供应商名称（supplier_name）

**关联逻辑**：
1. 识别所有Sheet的共同字段
2. 优先使用"批次号"作为主关联键
3. 若无批次号，使用"物料编码" + "检验日期"组合关联
4. 输出关联关系建议供用户确认

**用户确认示例**：
```
检测到2个Sheet：
- Sheet1: IQC检验表（5个字段）
- Sheet2: 不良记录表（4个字段）

建议关联方式：通过"批次号"字段关联
请确认是否采用此关联方式？或请指定关联字段。
```

## 验证规则

1. **字段完整性**：至少包含supplier_name、quantity、defect_qty、defect_type
2. **数据类型**：
   - 数量字段必须为数值型
   - 日期字段必须可解析为日期格式
3. **数据一致性**：
   - 不良数量 ≤ 来料数量
   - 批次号在关联Sheet中必须存在
4. **空值处理**：
   - 必需字段不允许空值
   - 可选字段空值自动填充默认值

## 常见问题

**Q1: Excel中没有"供应商名称"字段怎么办？**
A: 需要用户提供字段映射，指出哪个字段表示供应商信息。如文件名为"XX公司_2024年1月.xlsx"，可告知脚本"供应商名称从文件名提取"。

**Q2: 不良类型和检验项目有什么区别？**
A: 不良类型是宏观分类（如尺寸、外观、性能），检验项目是具体检查项（如长度尺寸、表面划伤）。脚本会分别统计两者的TOP分布。

**Q3: 多Sheet数据如何准备？**
A: 建议按业务逻辑拆分（如一个Sheet存基础检验信息，一个Sheet存详细不良记录），确保有关联字段（如批次号）。
