# 术语铁律与纠正规则

## 术语定义对照表

以下术语在国企采购场景中有严格定义——招标方式适用招标投标法体系术语，非招标方式适用国企采购自身术语体系。

### 招标方式术语

| 术语 | 正确定义 | 禁止用法 |
|------|---------|---------|
| **否决投标** | 投标文件因不符合法定条件或招标文件实质性要求而被评标委员会拒绝（《实施条例》第五十一条） | 不可笼统称为"废标"；不可混同政府采购法的"无效投标" |
| **废标** | 整个招标项目因法定情形终止（有效投标人不足三家、所有投标均被否决等） | 不可用于描述对单个投标人的否决 |
| **澄清** | 评标委员会/评审委员会要求投标人/供应商对文件中含义不明确的内容、同类问题表述不一致或明显文字和计算错误作出书面说明——不得超出文件范围或改变实质性内容 | 不可混同于"答疑" |
| **答疑** | 招标人/采购人或代理机构对潜在投标人/供应商在获取文件后提出的疑问进行解答（发生在投标/响应截止前） | 不可混同于"澄清" |
| **异议** | 《招标投标法》体系中投标人或利害关系人的法定救济程序——向招标人提出（知道或应当知道之日起3日内） | **严禁**混同于政府采购法的"质疑"；两者法律基础、时限、受理部门完全不同 |
| **投诉** | 对异议答复不满或逾期未答复，向行政监督部门（住建/发改/工信等）提出的后续救济申请（知道或应当知道之日起10日内） | 严格区分政府采购投诉（受理部门为财政部门） |

### 非招标方式术语

| 术语 | 正确定义 | 禁止用法 |
|------|---------|---------|
| **竞争性谈判** | 谈判小组与符合资格条件的供应商就采购事宜进行谈判，供应商提交最后报价，从谈判小组提出的成交候选人中确定成交供应商 | 不可与政府采购法的竞争性谈判混同（程序和控制要求不同） |
| **询价** | 询价小组向符合资格条件的供应商发出询价通知书要求一次性报价，从符合要求且报价最低的供应商中确定成交供应商 | — |
| **单一来源** | 从某一特定供应商处采购（需符合企业内部制度规定的特定情形并履行审批程序） | 不可因"图方便"而滥用——国企须严格论证唯一性并内部审批 |
| **框架协议** | 与供应商签订在一定期限内多次采购的框架协议（适用于频次高、单次金额小的采购） | — |
| **竞价采购** | 通过电子平台进行多轮公开报价竞争确定成交供应商 | — |

## 术语纠正执行规则

当用户使用错误术语时，必须先纠正再回答。

**示例**：用户说"这个标被废了，我们提了质疑"，应回复：
> "需先明确两处术语——第一，如果是指某一家投标人的投标文件被评标委员会否决，正确术语是'否决投标'而非'废标'（废标指整个项目终止）。第二，在《招标投标法》体系中，救济程序称为'异议'而非'质疑'——'质疑'是《政府采购法》体系的术语，两者法律基础和时限完全不同。根据您的情况，假设您是指……"

**示例**：用户说"我们单位这个项目怎么走竞争性磋商"，应回复：
> "需要先确认贵单位的性质——如果是国有企业采购，《招标投标法》体系下的标准术语是'竞争性谈判'；'竞争性磋商'是《政府采购法》体系特有的采购方式（依据《政府采购竞争性磋商采购方式管理暂行办法》财库〔2014〕214号）。国企采购实务中，非招标方式通常参照竞争性谈判程序，但可在企业内部制度框架下灵活设计评审程序……"

## 三体系术语对照表

| 招标投标法体系（国企招标） | 政府采购法体系 | 国企非招标采购 | 说明 |
|:---|:---|:---|:---|
| 招标人 | 采购人 | 采购人 | 国企招标方式统一用"招标人" |
| 投标人 | 供应商 | 供应商 | 招标方式中称"投标人" |
| 评标委员会 | 评审委员会 | 评审委员会 | 招标方式中称"评标委员会"，非招标称"评审委员会" |
| 评标专家 | 评审专家 | 评审专家 | 不可混用 |
| 否决投标 | 无效投标 | 不适用 | 体系不同，不可混用 |
| 异议 | 质疑 | 异议/申诉 | 招标投标法"异议"≠政府采购法"质疑" |
| 投诉（行政监督部门） | 投诉（财政部门） | 内部申诉/上级报告 | 受理部门完全不同 |
| 经评审的最低投标价法 | 最低评标价法 | 最低价法 | 名称有细微差异但实质相近 |
| 综合评估法 | 综合评分法 | 综合评分法 | 招标投标法称"综合评估法" |
| 招标文件 | 采购文件 | 采购文件 | 招标方式中称"招标文件" |

## 评标方法术语

| 术语 | 定义 |
|------|------|
| **经评审的最低投标价法** | 满足招标文件实质性要求，经评审的投标价最低者中标（适用于技术简单、标准统一的项目） |
| **综合评估法** | 对投标文件的技术、商务、价格等因素进行综合量化评审，得分最高者中标 |
| **符合性审查** | 评标委员会对投标文件是否满足招标文件实质性要求进行审查 |
| **实质性要求和条件** | 招标文件中以醒目的方式标明的、不允许偏离的要求和条件 |

## 否决投标与废标的区分要点

- **否决投标**：针对**个别**投标人的投标文件，评标委员会依据《实施条例》第五十一条规定的7种法定情形作出的否定结论。该投标人退出竞争，不影响其他投标人的评审。
- **废标**（重新招标）：整个招标项目终止——评标委员会经评审认为所有投标都不符合招标文件要求（《招标投标法》第四十二条）；或有效投标人不足三家且缺乏竞争性。

**执行规则**：当用户说"××被废标了"，须先纠正为"该投标人被否决投标"，而非"该标段被废标"。

## 异议与投诉的区分要点

| 维度 | 异议 | 投诉 |
|------|------|------|
| 提出主体 | 投标人或其他利害关系人 | 同异议主体 |
| 向谁提出 | 招标人 | 行政监督部门（住建/发改/工信等） |
| 提出时限 | 知道或应当知道之日起 **3日内** | 知道或应当知道之日起 **10日内** |
| 答复/处理时限 | 收到异议之日起 **3日内** | 收到投诉书 **3个工作日内** 决定受理，受理后 **30个工作日内** 作出处理决定 |
| 前置条件 | 无（可直接提出，但部分事项为投诉前置条件） | 对资格预审文件、招标文件、开标、评标结果的投诉须以提出异议为前提（《实施条例》第六十条第二款） |
| 法律依据 | 《招标投标法实施条例》第六十条、第六十一条 | 《招标投标法实施条例》第六十条；七部委11号令 |
