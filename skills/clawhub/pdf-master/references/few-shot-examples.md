# Few-Shot 路由示例（20 例）

> 意图路由拿不准时对照本表。格式：用户输入 → 路由 → 关键动作要点。

---

**例 1**
用户："客户发来一份50页PDF标书，转Word我要改条款，之前用免费工具表格全乱了"
→ **#1** PDF→Word。先 `pdf_info.py` 检测文本层；表格多用 pdf2docx 首选管道；交付按字体/表格/图片/页眉四项质检。

**例 2**
用户："这20张发票扫描件帮我识别汇总到Excel，免费OCR总是把金额识别错"
→ **#2 + #18** 组合。OCR 表格模式提取 → 金额字段全量正则校验 → 低置信区清单 → Excel 汇总。

**例 3**
用户："产品手册第5页的价格改成1999，手头没有源文件"
→ **#3** 直接编辑。备份 → 定位文本对象改写 → 新文本长度检查 → 预览确认 → 交付。

**例 4**
用户："这份报价单发给客户前，加水印防截图泄露，再加密码禁止转发，7天后失效"
→ **#4**。动态水印（用户ID+时间戳）+ AES-256 加密 + 权限禁用；密码与文件分渠道发送提醒。

**例 5**
用户："帮我处理这100份测试报告：按日期重命名，然后合并成一本带目录的手册"
→ **#11 → #5** 能力链。先批量提取日期生成对照表确认 → 重命名 → 按名排序合并+目录书签。

**例 6**
用户："这份扫描件合同80MB，微信发不了，帮我压到20MB以下，但文字必须清楚"
→ **#15**。分层压缩目标 20MB；文字层无损；迭代降图片 dpi/q 至达标；触底则报告极限值。

**例 7**
用户："这份50页英文芯片Datasheet翻译成中文，保留排版，术语要准"
→ **#16**。加载芯片行业术语库 → 段落级翻译回写坐标 → 交付双语版+术语对照表。

**例 8**
用户："这份50页的合作协议帮我审查一下，标出所有风险条款，我们是乙方"
→ **#17**。立场=乙方 → 六大类风险扫描 → 分级报告+高亮PDF+免责声明。

**例 9**
用户："这叠100张发票帮我归档，要验真、去重、生成报销单"
→ **#18**。批量 OCR → 验真（接口不可用标"未验真"）→ 哈希去重 → 报销单+归档包。

**例 10**
用户："这份劳动合同要发给深圳的员工签，他在家没法打印，要合法电子签名"
→ **#19**。需 CA 证书路径；无 CA → 明确告知图片章无法律效力，给替代建议。

**例 11**
用户："这200份历史报价单上的价格要从1999改成2199，公司统一调价"
→ **#20**。规则精确匹配 → dry-run 差异预览 → 确认 → 备份执行 → 替换报告。

**例 12**
用户："把这个Word入职登记表做成可填写的PDF表单，要能自动计算工龄工资"
→ **#21**。字段检测+判型 → 字段清单确认 → 加计算公式 → 自测后交付。

**例 13**
用户："这份PDF施工图上量一下客厅到阳台的距离，还有主卧面积"
→ **#22**。比例尺识别/校准 → 两点距离+闭合面积 → 引线标注副本+数值表。

**例 14**
用户："这份产品手册发给客户太死板了，做成能翻页的电子书，能放官网"
→ **#23**。HTML5 翻页书 → 三端自测 → 在线链接 + iframe 嵌入代码。

**例 15**
用户："这份宣传册要发印刷厂，他们说文件不合格，帮我导出印刷版"
→ **#24**。预检报告 → RGB→CMYK + 3mm 出血 + 转曲 → PDF/X 输出+遗留风险清单。

**例 16**
用户："这份招标公告要公开发布，里面投标方的报价和联系方式要彻底删除，不是涂黑，是真删"
→ **#25**。删除预览 → 用户确认 → 底层删除 → 双引擎+正则 0 命中验证 → 删除证书。

**例 17**
用户："把这两版合同 diff 一下，重点看违约条款改了没"
→ **#12**（联动 **#17**）。双通道对比 → 差异分类报告 → 关键条款差异做风险提示。

**例 18**
用户："这份文档里关于质保期是怎么约定的？"
→ **#13** 问答。检索 → 答案+页码引用；检索为空答"文档中未找到"。

**例 19**
用户："帮我把这份 PDF 里的表格提出来，顺便对比下另一家规格书的参数"
→ **#6 + #14**。先表格提取 → 再两文档参数归一化 → 对比矩阵+来源表。

**例 20**
用户："这个文件你看着处理一下"
→ **意图模糊，禁止猜**。回应："可以这样做：①转Word编辑 ②提取表格 ③生成摘要——回复序号或说下你的目的，我来执行。"
