## #6 表格精准提取

### 执行步骤

1. `pdf_info.py` 判文本层：文本型 → pdfplumber 坐标提取；扫描型 → 先 #2 OCR 表格模式
2. 运行 `scripts/pdf_extract_tables.py`，逐页检测表格区域
3. 难点对策（按 `tech-spec.md` 表格识别章）：合并单元格 → 形态学+语义判断；无框线 → 坐标聚类；跨页表 → 表头重复模式自动拼接；嵌套表 → 递归子区域
4. 输出：CSV（单表）/ xlsx（多表多 sheet）/ 飞书多维表格（用户指定时，流程见 `feishu-setup.md`）
5. **数值列校验**：金额/数量列做正则与合计勾稽，异常值标黄并报告

### 验收标准

- 表格检出：逐页目检无遗漏（漏检是最大事故）
- 行列结构与原表一致，合并单元格还原正确
- 数值与原文件逐列抽核 ≥10% 行数，零误差

## #7 图文混排解析

### 执行步骤

1. 版面分析：识别标题/正文/列表/表格/图片/图注/页眉页脚区域与阅读顺序（多栏文档按栏序）
2. 输出 Markdown：标题层级、列表、加粗等语义保留；图片提取为文件并在文中原位引用；表格转 Markdown 或 CSV 引用
3. 图表（chart）类图片：附一句内容描述（"图3：2021-2025 出货量柱状图，峰值在 2024"）

### 验收标准

- 阅读顺序正确（多栏不错序、跨页段落正确衔接）
- 图片零丢失，引用位置与原版面一致
- 页眉页脚/页码已剥离，不混入正文

## #8 智能摘要

### 执行步骤

1. 确认摘要形态：要点式（默认）/ 段落式 / 一页纸；确认长度（默认 ≤500 字或全文 5%）
2. 长文（>100 页）分章摘要再归并，避免截断 bias
3. 输出结构：`核心结论（3 条以内）→ 分章要点 → 关键数据/日期/人名清单`
4. 每个要点标注来源页码

### 验收标准

- 关键数据（金额、日期、比例）与原文逐一核对零误差
- 无原文之外的推断；推断性内容必须标注"（推断）"
- 页码引用可跳转核验

## #9 自动脱敏

> ⚠️ 脱敏 = 遮盖，底层可恢复。用户要"彻底/永久删除"→ 路由 #25。两者的区别必须在交付时说清。涉密任务前读 `security-compliance.md`。

### 执行步骤

1. 识别敏感项：身份证 / 手机 / 银行卡 / 邮箱 / 姓名 / 地址 / 自定义关键词（用户可提供清单）
2. 生成《脱敏预览报告》：每处敏感项的类型、页码、遮蔽前后对照 → **用户确认后执行**
3. 执行遮盖（黑色矩形覆盖+同步移除可见文本，但底层对象保留）
4. 交付脱敏文件 + 预览报告存档

### 验收标准

- 规则覆盖项 0 漏网（二次正则全文扫描验证）
- 遮盖不越界（不伤及相邻非敏感文字）

## #10 元数据清洗

### 执行步骤

1. `scripts/pdf_info.py --meta` 导出全部元数据与 XML 扩展信息，列给用户看有什么
2. 清洗项：作者 / 最后修改者 / 创建工具 / 修改历史 / 缩略图 / 嵌入文件 / JavaScript / 审阅批注
3. 执行 `scripts/pdf_info.py --scrub`，清洗后再次导出元数据对比验证

### 验收标准

- 清洗后元数据字段为空或默认值；XMP 包、嵌入附件、隐藏图层同步清除
- 正文内容零改动

## #11 名称/编号自动化

### 执行步骤

1. 与用户确认命名模板：`{date}_{title}_{no}` 之类；可用变量：文档标题/首页日期/检测到的编号/原文件名/序号
2. 逐文件提取变量 → 生成《新旧文件名对照表》→ **确认后批量重命名**
3. 非法字符（`\/:*?"<>|`）自动替换为 `-`；重名自动加 `(2)` `(3)`

### 验收标准

- 对照表 100% 覆盖所有文件，变量提取失败的文件单独列出人工命名
- 无重名、无非法字符

## #12 两版差异对比

### 执行步骤

1. 双通道对比：文本 diff（逐段对齐）+ 视觉 diff（页面渲染图像素级比对）
2. 差异分类：新增 / 删除 / 修改 / 格式变化 / 图片变化 / 页面增删
3. 输出《差异报告》：差异清单（页码+原文→新文+分类）+ 高亮标注版 PDF（新增绿、删除红、修改黄）
4. 合同场景联动：差异落在关键条款（价格/期限/违约/知识产权）时，额外风险提示（对接 #17 规则）

### 验收标准

- 文本差异 0 漏报（随机抽 3 处未标记区域复核无差异）
- 差异分类准确；纯格式变化与实质内容变化分开统计

## #13 文档即问即答

### 执行步骤

1. 建索引：解析 → 按语义切片（300-500 字/片，保留页码元数据）→ Embedding → 向量库（Chroma/FAISS）
2. 回答：检索 Top-K 片段 → 生成答案 → **每条结论附页码引用**
3. 检索无结果 → 明确说"文档中未找到相关信息"，不得编造
4. 多轮追问保持会话内索引复用；涉密文档走本地模型（见 `security-compliance.md`）

### 验收标准

- 答案每个事实点都有页码；页码真实可核
- 数值类答案与原文一致（金额、参数、日期）

## #14 规格参数对比矩阵

### 执行步骤

1. 逐文档提取规格区块（参数表、特性列表、技术指标），扫描件先 OCR
2. 参数归一化：同义参数合并（"亮度/Brightness/ cd/m² 亮度"）、单位统一（ms=毫秒、inch=英寸换算标注）、缺失标 `—`
3. 输出对比矩阵：行=参数项，列=各文档；差异显著项（数值差 >20% 或有无差异）高亮
4. 附《参数来源表》：每个单元格值标注来源文档+页码

### 验收标准

- 参数归一化无张冠李戴（抽查每列 5 个参数回原文核对）
- 矩阵覆盖所有文档的全部规格项，无静默丢弃
