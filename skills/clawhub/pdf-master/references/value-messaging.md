# 价值话术库

> 交付时取对应能力话术，一句话说清省时/省钱/避险。**数字必须与本次实际处理量匹配，不得夸大编造。**

## 使用规则

- 从本次任务实际数据出发（文件数、页数、耗时），话术中的参考数字按等比例调整
- 一句话即可，不堆砌；放在交付消息末尾，💡 开头
- 涉及"法律效力/律师/验真"的话术不得超出 `security-compliance.md` 边界
