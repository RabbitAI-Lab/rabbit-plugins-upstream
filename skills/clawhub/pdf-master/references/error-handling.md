# 错误处理与降级策略

> 任何环节失败时阅读。**三条铁律：不静默失败、不伪造结果、原件不受损。**

## 总原则

1. **不静默失败**：失败必须显式告知，含原因、影响范围、建议动作
2. **不伪造结果**：外部接口（验真/CA/翻译）不可用 → 标注"未完成该步"，绝不编造
3. **原件不受损**：所有写操作在副本进行；批量任务失败文件单独隔离，不混入成功批次
4. **降级优于终止**：有降级路径先降级并告知质量差异，无降级才终止

## 通用降级链

```
首选方案失败
  ↓ 记录失败原因
降级方案执行（质量差异必须告知）
  ↓ 仍失败
部分交付：已完成部分先给 + 失败清单 + 重试建议
  ↓ 完全无法执行
明确终止：原因 + 用户可采取的替代动作
```

## 分场景处理

### 输入类
| 场景 | 处理 |
|------|------|
| 文件损坏/打不开 | 尝试修复（pikepdf/qpdf 修复模式）→ 失败则告知重发 |
| 加密无密码 | 索要密码（"回复 密码:xxx"）；明确密码不留存 |
| 超限（100MB/200页） | 给出具体瘦身路径（先压缩/指定页范围），不只说"太大" |
| 非 PDF 文件 | 说明支持范围；Word/图片可引导先转 PDF |
| 扫描件质量过差（<100dpi） | 告知识别率上限，请用户提供更清晰版本 |

### 处理类
| 场景 | 处理 |
|------|------|
| PaddleOCR 环境异常 | 降级 Tesseract，告知中文识别率下降（ocr-config.md 决策树） |
| pdf2docx 转换排版崩 | 降级 LibreOffice 重建管道 → 再降级渲染图+文本层流式 docx |
| 压缩触底仍超标 | 报告极限值（"已压到 23MB，继续将损伤文字"），用户裁决 |
| 表格检出疑似遗漏 | 二次检测（换检测算法）；仍有疑区列入人工核对清单 |
| 翻译后排版溢出 | 缩字号(→80%)→换行扩框→双语对照改上下式，逐级处理 |
| 批量替换部分失败 | 成功批次先交付+失败清单；备份完整可回滚 |

### 外部依赖类
| 场景 | 处理 |
|------|------|
| 发票验真接口不可用 | 逐张标"未验真"+接口状态说明+稍后重验指引 |
| CA 签名服务不可用 | 改图片章方案必须声明无法律效力，用户确认才执行 |
| 翻译接口超时 | 分段重试 → 仍失败交付已译部分+未译页清单 |
| 飞书上传失败 | 本地保留结果，重试 3 次；失败给备用取件方式 |
| 本地模型不可用（涉密任务） | **终止并说明**，不得为完成任务转云端 |

## 熔断与超时

- 单任务 5 分钟硬熔断：保存中间结果 → 报告"已完成 X/Y"+续作方式（"回复'继续'从断点续作"）
- OCR 单批 50 页限：批间检查点持久化，熔断后从最近检查点恢复
- 并发 3 满：新任务排队，告知位次与预计等待

## 失败报告模板

```
🔴 部分完成 / ⚠️ 已降级 / ❌ 失败

任务：{能力# + 指令摘要}
结果：成功 {n} / 失败 {m} / 跳过 {k}

失败清单：
| 文件/页 | 原因 | 建议 |
| xx.pdf | 加密未提供密码 | 回复"密码:xxx"后重试 |

降级说明：{用了什么降级方案，质量差异是什么}
原件状态：未受影响 / 已备份于 {路径}
```
