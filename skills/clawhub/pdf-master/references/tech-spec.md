## PDF 解析层

### 文本型 PDF
| 组件 | 用途 |
|------|------|
| PyMuPDF (fitz) | 文本/图片/矢量图/超链接提取；页面渲染；内容流编辑；密文删除 |
| pdfplumber | 字符级坐标、表格边界检测、删除验证扫描 |
| Unstructured | 版面分析（标题/正文/列表/表格区域） |

### 扫描型 PDF
| 组件 | 用途 |
|------|------|
| PaddleOCR | 中文/中英混排首选（PP-OCRv4）；手写体模型 |
| Tesseract | 纯英文备选；PaddleOCR 不可用时的兜底 |
| OpenCV | 预处理：纠偏→去噪→二值化→边框检测 |

### 检测逻辑（pdf_info.py 实现）
- 文本层判定：全文提取字符数 / 页数 > 50 字符/页 → 文本型
- 图像占比：页面渲染后文字区域占比 <10% 且含大图 → 扫描型
- 混合：逐页判定，分页路由

## 转换管线与降级链

### PDF→Word
```
首选：pdf2docx 直接转换
  ↓ 复杂版面（多栏/嵌套表/文本框密集）质量不达标
降级1：PyMuPDF 提取元素 → 版面分析 → LibreOffice 生成原生 docx
  ↓ 仍不达标
降级2：逐页渲染图 + OCR 文本层 → 流式 docx（保内容牺牲排版），交付时声明
```

### PDF→Excel
纯表格需求 → #6 表格提取管道（pdfplumber→pandas→xlsx），不做整页还原。

### 可搜索 PDF（OCR）
```
首选：PaddleOCR → hOCR/文本层 → PyMuPDF 叠加隐形文本层
  ↓ PaddleOCR 环境不可用
降级：Tesseract（tessdata chi_sim+eng）→ 同样叠层；告知中文识别率下降
```

### 智能压缩
```
分层策略：文字/矢量无损 → 图片降采样(150dpi/q70) → 字体子集化 → 对象流清理
目标大小模式：迭代降参（dpi: 150→120→96，q: 70→55→40）
质量地板：dpi≥96 且 q≥40；触底仍超标 → 报告极限值，用户裁决
```

### 密文删除
```
定位 → redact 注解标记 → apply_redactions() 移除内容流指令
→ 清理字体引用/编码映射 → 图片区 inpainting
→ 双引擎（pdfplumber+PyMuPDF）验证扫描 → 正则二次扫描 → 出证
```

## AI 模型调用

### 云端模型（常规文档）
- 摘要、问答、翻译、合同审查、版面语义分析
- Function Calling 强制 JSON 输出 → 结构化交付物（多维表格/审查报告）
- 多模态理解：图表内容描述、扫描件版面语义

### 本地 27B 模型（保密文档）
- 触发条件：用户声明涉密 / 检测到密级标记（"机密""秘密""内部资料 注意保密"页眉水印）
- 承担：摘要、问答、脱敏检测；不上云

### RAG 流程（#13 问答）
```
PDF解析 → 语义切片(300-500字, 带页码元数据) → Embedding → Chroma/FAISS
提问 → 检索Top-K → 拼入Prompt → 生成答案 + 页码引用
检索为空 → 明确回答"文档中未找到"，禁止编造
```

## 异步任务队列

- 并发 ≤3（防 Token/内存耗尽）；超出排队并回报位次
- 单任务 5 分钟超时熔断：**熔断时保留中间结果**，报告已完成部分与续作方式
- 批量任务粒度化进度推送（每 10 文件或每 20 页一档）
- 临时文件：任务结束后立即清理；异常退出由看门狗定时清理

## 安全约束

- 涉密文档全程本地模型，详细分级见 `security-compliance.md`
- 脱敏（#9）/删除（#25）必须预览确认；删除后必须验证扫描
- 加密 PDF 处理需用户提供密码；密码不落地存储，用后即焚
- 元数据清洗（#10）须含 XMP、嵌入附件、隐藏图层、缩略图
- 外部接口（验真/CA/翻译）结果不得伪造；接口不可用如实标注
