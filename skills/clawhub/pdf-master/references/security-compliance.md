## 文档密级与模型路由

| 密级 | 判定 | 模型路由 |
|------|------|---------|
| 公开/内部一般 | 默认 | 云端模型 |
| 内部敏感 | 用户声明"敏感/涉密" | 本地 27B，禁上云 |
| 密级文档 | 检测到"机密/秘密/绝密"字样或密级水印 | 本地 27B，禁上云；任务结束即焚临时文件 |

- 检测在 `pdf_info.py` 阶段完成，命中即提示用户确认路由
- 本地模型不可用时：**终止任务并说明**，不得转云端完成

## 脱敏 #9 vs 密文删除 #25

| 维度 | #9 脱敏 | #25 密文删除 |
|------|---------|-------------|
| 本质 | 遮盖（黑框覆盖） | 删除底层文本对象/图像修复 |
| 可恢复性 | 专业工具可恢复 | 不可恢复（双引擎验证） |
| 适用 | 内部流转、低风险 | 对外公开、法律合规、隐私抹除 |
| 交付物 | 脱敏文件 | 删除文件+验证报告+删除证书 |

- 用户说"涂黑/打码/隐藏"→ #9；说"彻底/永久/真删/抹除"→ #25
- 意图不明时必须澄清，并说明两者可恢复性差异
- #9 交付时必须提示"底层数据仍可恢复，对外公开请用彻底删除"

## 电子签名法律效力边界

| 方案 | 法律效力 | 表述要求 |
|------|---------|---------|
| CA 数字证书签名 | 符合《电子签名法》第十三条，司法实践认可 | 可表述"具有法律效力" |
| 图片章+留痕 | 无法律效力，仅示意 | **必须明确告知无法律效力** |

- 劳动/合同场景用户要求"合法电子签"→ 无 CA 环境时不得用图片章冒充
- 批量盖章执行前落章位置预览确认率 100%
- 审计日志要素：时间/IP/设备/证书编号/文件哈希，逐步完整

## 合同审查免责边界

- 每份审查报告结尾固定附：
  > "本报告为 AI 辅助初筛结果，不构成法律意见，不替代执业律师审查。🔴 高危条款建议提交法务/律师复核后决策。"
- 不输出"这份合同可以签/不能签"的结论性判断，只输出风险与建议
- 法律依据引用须注明法条名称与条款号；不确定的法条不引用

## 数据生命周期

| 数据 | 规则 |
|------|------|
| 用户上传文件 | 处理期存临时目录，任务结束（成功/失败/超时）即清理 |
| 用户密码 | 仅内存使用，不落盘、不日志、任务结束即焚 |
| 备份文件（#3/#20） | 保留至用户确认结果无误或 7 天，先到期先清理 |
| 删除证书/审计日志 | 按用户指定位置交付，服务端不留副本（用户要求托管除外） |
| 对话中的敏感内容 | 不主动复述完整敏感号码（身份证/银行卡），引用时遮蔽中间位 |

## 红线清单

1. 涉密文档上云 —— 禁止
2. 伪造验真/签名/审查结果 —— 禁止
3. 涂黑冒充彻底删除 —— 禁止
4. 图片章冒充法律有效签名 —— 禁止
5. 未预览确认执行不可逆操作（#3/#20/#25） —— 禁止
6. 密码落盘/进日志 —— 禁止
7. 本地模型不可用时转云端处理涉密任务 —— 禁止
