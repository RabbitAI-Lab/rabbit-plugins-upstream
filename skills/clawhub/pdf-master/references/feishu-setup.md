## 前置要求

1. 飞书机器人已创建并获取 `app_id` / `app_secret`
2. 机器人已加入目标群聊 / 已开通单聊权限
3. 开通以下权限：

| 权限 | 用途 |
|------|------|
| `im:message:send` | 发送结果消息 |
| `im:message` | 读取用户指令 |
| `im:file:read` | 下载用户上传的 PDF |
| `im:file:write` | 回传结果文件 |
| `drive:file:read` | 读取云文档附件 |
| `bitable:app:create` | 创建多维表格 |
| `bitable:app:read` / `bitable:app:write` | 写入提取数据 |

## 事件订阅配置

- `im.message.receive_v1` — 收到消息（含文件），唯一必需事件
- 可选：`im.message.message_read_v1`（进度卡片已读回执）

## 文件处理流程

```
用户上传PDF → 飞书消息事件（含 file_key + message_id）
    ↓
Bot 下载文件（file_key → 临时路径）
    ↓
pdf_info.py 检测（类型/页数/加密）
    ↓
解析用户指令 → 路由能力（SKILL.md 路由表）
    ↓
执行处理（进度实时推送）→ 生成结果
    ↓
上传飞书（消息/文件/多维表格）
    ↓
清理临时文件（成功/失败都清理）
```

## 进度反馈消息格式

进度卡片（interactive）：

```json
{
  "msg_type": "interactive",
  "card": {
    "config": { "wide_screen_mode": true },
    "header": { "title": { "tag": "plain_text", "content": "⏳ 正在处理 PDF" }, "template": "blue" },
    "elements": [
      { "tag": "markdown", "content": "已解析：8/20 页\n预计剩余：30 秒" }
    ]
  }
}
```

交付卡片模板（header.template 按结果变色：成功 green / 部分失败 orange / 失败 red）：

```json
{
  "msg_type": "interactive",
  "card": {
    "header": { "title": { "tag": "plain_text", "content": "✅ 转换完成" }, "template": "green" },
    "elements": [
      { "tag": "markdown", "content": "**质检**：表格 12 个全部原生可编辑，图片偏移 <5px\n**异常**：无\n💡 手动重排约需 2-3 小时，本次耗时 48 秒" }
    ]
  }
}
```

## 多维表格输出

表格提取/发票归档结果写入多维表格：

1. `feishu_bitable_app` 创建 App（命名：`PDF提取_{文件名}_{日期}`）
2. `feishu_bitable_app_table` 创建数据表（字段类型映射：金额→数字、日期→日期、其余→文本）
3. `feishu_bitable_app_table_record` 批量写入（单批 ≤500 条，分批提交）
4. 返回表格链接 + 字段说明给用户

## 单聊 vs 群聊

- **单聊**：直接处理并返回结果
- **群聊**：@机器人时处理，普通消息忽略；结果默认群里回复，涉密内容提示"已私聊发送"

## 幂等与临时文件

- 以 `message_id + file_key` 为幂等键：同一文件同一指令重复触发 → 直接返回缓存结果，不重复执行
- 临时文件生命周期：任务结束（成功/失败/超时）即清理；看门狗每 30 分钟清扫孤儿文件
- 用户密码：仅存内存，任务结束即焚，不落盘不日志

## 错误处理

| 错误场景 | 回复 |
|---------|------|
| 文件超过 100MB | "文件太大，请压缩或拆分后重试（可先发我压缩：指令'压缩到80MB'）" |
| 超过 200 页 | "页数超限，请指定页范围（如 1-50页）" |
| 加密 PDF 无密码 | "请提供PDF密码：回复 '密码:xxx'（密码仅用于本次处理，不留存）" |
| OCR 超时 | "识别超时，建议：①降精度重试 ②指定页范围，回复序号选择" |
| 无文本层且 OCR 失败 | "无法识别内容，请检查文件清晰度，或发原图重试" |
| 批量部分失败 | 成功结果先交付 + 失败清单（文件名+原因+建议），原件不受影响 |
| 外部接口不可用（验真/翻译） | "xx接口暂不可用，结果已标注'未验真/未翻译'，可稍后重试" |

> 通用降级链与熔断策略见 `error-handling.md`。
