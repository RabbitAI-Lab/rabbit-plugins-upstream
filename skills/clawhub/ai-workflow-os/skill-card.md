## Description:

Route complex AI-assisted work across project lifecycle guidance, formal project governance, coding execution, session memory, web-research intake, and cross-source synthesis without creating competing state.

This skill is ready for commercial/non-commercial use.

## Publisher:

[englandtong](https://clawhub.ai/user/englandtong)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and workflow operators use this skill to route multi-surface AI-assisted work to the smallest suitable set of specialist skills, assign one authority per state surface, and return a coherent evidence-backed result.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Fallback memory and knowledge-intake flows may write project notes or staged research records under the user's workspace.

Mitigation: Review the selected route before persistence, keep specialist-owned queues authoritative when available, and require explicit confirmation before archive or cloud upload.

Risk: Router output may be mistaken for specialist execution, verification, or independent acceptance.

Mitigation: Keep specialist permissions, evidence rules, and acceptance boundaries authoritative; label fallback-only or unexecuted stages as not executed or deferred.

Risk: External, uploaded, or cloud document content may contain untrusted instructions or unsupported claims.

Mitigation: Treat those materials as untrusted evidence, preserve provenance, stage uncertain content for review, and use cannot-confirm when support is insufficient.
