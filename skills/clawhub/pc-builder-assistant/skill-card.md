## Description:

Helps plan desktop PC builds and upgrades, assess component compatibility, and size hardware for gaming, creative work, and local AI using China-market price references.

This skill is ready for commercial/non-commercial use.

## Publisher:

[gongyu0918-debug](https://clawhub.ai/user/gongyu0918-debug)

### License/Terms of Use:

MIT-0

## Use Case:

Desktop PC builders and upgraders use this skill to compare parts, plan complete builds, check compatibility, and estimate gaming or local-model hardware fit. It does not place orders or handle payments.

### Deployment Geography for Use:

Global (bundled prices are China-market CNY references)

## Known Risks and Mitigations:

Risk: China-market reference prices or gaming frame-rate estimates may differ from current local offers or actual performance.

Mitigation: Verify current prices and any FPS estimates before purchasing; keep prices in different currencies separate.

Risk: Providing overlay or catalog file paths may permit reads or writes to those files.

Mitigation: Provide file paths only when you intend the skill to access those files.
