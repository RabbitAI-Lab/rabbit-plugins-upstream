## Use Case:

Developers, PC builders, and hardware buyers use this skill to plan desktop builds, upgrades, compatibility checks, gaming and creator configurations, and local LLM GPU or memory sizing with China-market catalog prices.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Bundled prices are China-market references and may be stale or unsuitable for a buyer's local market.

Mitigation: Verify current retailer prices, exact SKUs, and currency-specific user overlays before making purchasing decisions.

Risk: Compatibility-critical fields such as physical clearances, power cabling, display outputs, fan positions, and exact model variants can affect whether a recommended build is purchasable.

Mitigation: Confirm exact SKUs, case clearances, motherboard outputs, power connectors, and other compatibility-critical details before ordering.

Risk: FPS estimates and local model fit outputs are guidance based on available reference samples rather than purchase guarantees.

Mitigation: Treat performance estimates as planning references and verify with current benchmarks or model requirements for the specific configuration.

Risk: The skill is scoped to desktop PC builds and is not intended for server or NAS procurement.

Mitigation: Use a dedicated server or NAS procurement workflow when the request involves enterprise storage, server hardware, or always-on infrastructure.
