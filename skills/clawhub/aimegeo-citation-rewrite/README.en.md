# Citation-oriented article revision and structural checks

This skill uses the user’s questions and verifiable sources to make article answers clearer and their evidence traceable. It helps revise a user-provided Markdown article within explicitly authorized sections, preserve the rest, and deliver a change note. Its Python checker validates a limited set of structure and scope constraints. It does not write prose, verify factual truth, or measure GEO outcomes.

See [SKILL.md](SKILL.md), [check-plan format](references/check-format.md), and synthetic fixtures under `examples/`. Run `python3 scripts/self_test.py` for local tests.

Version 1.0.2, MIT-0; see [LICENSE](LICENSE). Provenance for the preserved earlier package is recorded in [SOURCE-ORIGIN.md](SOURCE-ORIGIN.md).
