# 失败样例

[不合格增强稿](不合格增强稿.md) 是故意构造的编辑反例，不是产品事实或用户案例。它在完整成品上做了三类违规修改：改原标题、改非目标“我的建议”段落、在目标段落加入无来源的效果数字。

```sh
python3 scripts/check_rewrite.py --original examples/input/原稿.md --revised examples/failure/不合格增强稿.md --plan examples/input/check-plan.json
```

预期退出码为 `1`；代码集合应等于 [expected-errors.json](expected-errors.json)。标题改变还会引起前言区域不一致，因此有多条 `out_of_scope_change`。自测会检查这些业务结果，并分别验证每一种单独违规。

修复方式：恢复原标题与未授权段落；删除没有来源支持的效果数字，保留原稿可支持的操作建议。不能为让校验通过而扩大可编辑范围、伪造资料摘录或给无依据数字补无关链接。
