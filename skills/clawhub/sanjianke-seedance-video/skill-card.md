## Description:

三剪客 · Seedance 2.0 helps agents use the a7w Seedance API to generate videos from text, image, video, and audio inputs, manage media assets, submit generation jobs, and query results with a user-provided API key.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users, developers, and automation agents use this skill to call Seedance video-generation workflows through api.a7w.cn, including creating asset groups, uploading source media, submitting asynchronous video jobs, and checking results. It is suited for video generation and media automation workflows where the user already controls an a7w API key and account billing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The bundled client can use the configured a7w API key beyond the Seedance plugin if the same key has access to other marketplace APIs.

Mitigation: Use a scoped or dedicated a7w key where possible, review account permissions before installation, and monitor a7w usage and billing after calls.

Risk: Changing the client host can send credentials and media-related requests to a service other than api.a7w.cn.

Mitigation: Keep the host set to api.a7w.cn unless the user intentionally trusts the replacement endpoint.

Risk: Prompts, media URLs, callback URLs, and uploaded assets may expose sensitive information to the external video-generation service.

Mitigation: Avoid secrets, private media, and confidential callback data in requests unless the destination service and account controls are approved for that data.

Risk: Asset deletion is supported and can remove media needed by later generation workflows.

Mitigation: Confirm asset IDs and project names before deleteAsset calls, especially in automated workflows.
