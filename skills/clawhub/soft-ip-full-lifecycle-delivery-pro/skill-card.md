## Description: <br>
Software copyright registration full lifecycle delivery skill that helps generate and complete eight Chinese software copyright filing documents after paid order and payment verification. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, founders, and software teams use this skill to prepare draft application materials for Chinese software copyright registration, including application forms, source-code documentation, user manuals, rights declarations, and consistency checks. It is intended for paid document-generation delivery after order creation and payment verification. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Question text and order metadata are sent to api.ideaidea.com.cn for order creation and fulfillment. <br>
Mitigation: Avoid putting source code, application documents, company records, personal data, or secrets into the question field unless that transmission is acceptable. <br>
Risk: Local order JSON files can contain order details and payment credentials. <br>
Mitigation: Treat local order files as sensitive, restrict local access, and remove them when they are no longer needed. <br>
