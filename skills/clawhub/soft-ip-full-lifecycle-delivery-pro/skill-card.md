## Description: <br>
Soft Ip Full Lifecycle Delivery Pro helps Chinese-speaking users generate the eight document drafts needed for Chinese software copyright registration while keeping source files and application drafts local. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[jinyu12166](https://clawhub.ai/user/jinyu12166) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Chinese-speaking developers, product teams, and rights holders use this skill to draft and organize Chinese software copyright filing materials after payment verification, including application forms, source code documentation, user manuals, ownership statements, and submission checklists. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The order flow sends user question text and payment verification data to a disclosed third-party service. <br>
Mitigation: Keep source code, confidential project details, and sensitive company or rights-holder information out of the order question unless disclosure is intentional. <br>
Risk: The skill reads and writes local project files while drafting software copyright materials. <br>
Mitigation: Run it only in the intended project workspace and review generated drafts before filing or sharing them. <br>
