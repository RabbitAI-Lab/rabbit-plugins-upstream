## Description: <br>
Book Lawyer helps users search for and book lawyer services through Lokuli MCP. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

### License/Terms of Use: <br>


## Use Case: <br>
External users can use this skill to search for lawyer services, check availability, and create bookings through Lokuli when they intend to schedule legal services. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may send sensitive legal-service booking details and contact information to an external service. <br>
Mitigation: Confirm what information will be sent before creating a booking, share only necessary details, and use the skill only when the user intends to search for availability or schedule a lawyer. <br>
Risk: The release is published by a third-party booking provider rather than NVIDIA. <br>
Mitigation: Install only if the user is comfortable using Lokuli as a third-party booking provider. <br>
