## What is included

- React + Vite storefront, Tailwind CSS 3
- 7 routes: home / shop / product detail / cart / checkout / wishlist / admin
- Two Zustand stores (cart and wishlist), both with `persist` enabled
- Slide-out CartDrawer with quantity controls, removal and a free-shipping nudge
- Three-step checkout (shipping → payment → review) with a stepper and a sticky order summary
- ProductCard with grid and list layouts, image swap on hover, and quick add to cart
- AI shopping assistant: 10 keyword scenarios, embedded product cards and quick prompts
- Primary and secondary product images differ, so the hover swap is visible
- Responsive layout, including a mobile menu
- EdgeOne Pages deployment config

## Images

Demo images live in `static/images/` (Vite `publicDir` points at `static`) and are referenced
as `/images/<file>.jpg`; the build copies them to `dist/images/`.

When you swap in real product photos, keep at least two entries in the `images` array, and make
sure entry 1 and entry 2 differ — entry 2 is what the hover swap shows.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build      # tsc --noEmit && vite build
npm run typecheck  # types only
```

`dist/` deploys as-is to EdgeOne Pages or any static host.

## Notes

- Single source of product data: `src/data/products.ts` (TypeScript, not JSON)
- All money goes through `formatPrice()` in `src/utils/format.ts` — never hard-code a currency symbol in a component
- The assistant is a keyword mock; see the header comment in `functions/api/assistant.ts` to wire a real model
- Payment is a mock flow by default; switching to Stripe needs `STRIPE_SECRET_KEY` and `STRIPE_WEBHOOK_SECRET`
- Some backend handlers are placeholders and need a real service before production
