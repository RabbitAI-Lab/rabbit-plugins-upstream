## 已知短板（诚实边界，v2.0.0）

1. **会中捕获依赖授权**：腾讯会议智能纪要需用户授权该场会议数据；未授权降级为「用户实时口述→追加记录」。
2. **知识库蒸馏为辅助级**：组织/归档信息，不做观点真伪自动核验（需配合 cjg-paper-fact-checker 把关）。
3. **非多人实时协作白板**：单人 Agent 编排，无 Axy 式多人实时注释看板。
4. **冷启动依赖画像质量**：首次需填课题组方向；空画像时推荐偏通用。
5. **文献覆盖受底座约束**：全球文献（API4）仅元数据、部分无全文；中文期刊（API1）可下载全文是相对优势。

## 与同系列技能边界

- 单篇文献真实性把关 → `cjg-paper-fact-checker`
- 想法新颖性判断 → `novelty-validator`
- 答辩演练 → `defense-rehearsal`
- paper-club-pilot 只做「组会编排层」，不替上述职责做决定。
