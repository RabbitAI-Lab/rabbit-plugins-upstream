## Known Risks and Mitigations:

Risk: Advanced Git workflows such as rebase, cherry-pick, worktree removal, and reset --hard can disrupt local work.

Mitigation: Review commands before execution, run git status first, preserve uncommitted work, and treat reset --hard as destructive unless recovery intent is clear.

Risk: The security summary flags the activation scope as broader than the Git workflows described by the skill.

Mitigation: Use this skill only for advanced Git workflow assistance and avoid unrelated AI, agent-orchestration, medical, legal, or other critical decision tasks.
