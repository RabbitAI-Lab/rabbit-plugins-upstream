## Description:

Organizes Chinese-language short-drama projects across creation stages, with local project tracking, a dashboard, and export tools.

This skill is ready for commercial/non-commercial use.

## Publisher:

[worldwonderer](https://clawhub.ai/user/worldwonderer)

### License/Terms of Use:

MIT

## Use Case:

Creators and production teams use this skill to initialize or resume short-drama projects, route work to companion skills, track progress, and export current project materials.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Project operations can create or edit files within the selected workspace.

Mitigation: Choose a dedicated short-drama workspace without unrelated private material and review proposed changes.

Risk: The optional dashboard runs as a background localhost service.

Mitigation: Start it only when needed, check its status, and stop it when finished.
