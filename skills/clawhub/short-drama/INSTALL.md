# Exact companion skills

```sh
clawhub install @worldwonderer/short-drama-assets --version 1.0.27
clawhub install @worldwonderer/short-drama-develop --version 1.0.27
clawhub install @worldwonderer/short-drama-edit --version 1.0.8
clawhub install @worldwonderer/short-drama-image-prompts --version 1.0.7
clawhub install @worldwonderer/short-drama-novel-analyze --version 1.0.27
clawhub install @worldwonderer/short-drama-produce --version 1.0.3

clawhub install @worldwonderer/short-drama-storyboard --version 1.0.10
clawhub install @worldwonderer/short-drama-video-prompts --version 1.0.9
clawhub install @worldwonderer/short-drama-write --version 1.0.10
```
