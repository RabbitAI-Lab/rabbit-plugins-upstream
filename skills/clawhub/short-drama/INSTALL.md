# Exact companion skills

ClawHub does not auto-install these dependencies. Install all into the same skills root:

```sh
clawhub install @worldwonderer/short-drama-assets --version 1.0.12
clawhub install @worldwonderer/short-drama-develop --version 1.0.12
clawhub install @worldwonderer/short-drama-edit --version 1.0.1
clawhub install @worldwonderer/short-drama-image-prompts --version 1.0.2
clawhub install @worldwonderer/short-drama-novel-analyze --version 1.0.12
clawhub install @worldwonderer/short-drama-produce --version 1.0.2
clawhub install @worldwonderer/short-drama-review --version 1.0.1
clawhub install @worldwonderer/short-drama-storyboard --version 1.0.2
clawhub install @worldwonderer/short-drama-video-prompts --version 1.0.2
clawhub install @worldwonderer/short-drama-write --version 1.0.2
```
