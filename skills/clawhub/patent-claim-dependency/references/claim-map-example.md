# 合成示例（不是实际专利）
1. 一种包括传感器的装置。
2. 根据权利要求1的装置，其中还包括控制器。
3. 根据权利要求1或2的装置，其中还包括显示器。

图必须包括C1、C2、C3；C1→C2；C1→C3和C2→C3都标“任一”，不能理解为C3同时需要两条路径。文字引用不自动证明法律意义上的从属关系。无引用的C1标“未见明确引用”，原文缺项或跨类别引用需核对。图箭头代表被引用项到引用项。
