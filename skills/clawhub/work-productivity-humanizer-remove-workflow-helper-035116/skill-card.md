## Use Case: <br>
External agent users, skill authors, maintainers, and teams use this skill to turn Humanizer-style workflow needs into concise plans, checklists, implementation support, and validation notes. It is suited for practical productivity work such as bug fixing, setup hardening, reliability improvement, and adjacent skill creation. <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger language may cause the skill to activate for generic writing, editing, reviewing, or bug-fix requests. <br>
Mitigation: Use explicit invocation or tighten trigger wording when installing it in a crowded skill set. <br>
Risk: Generated workflow advice or code-change guidance may not match the user's actual project constraints. <br>
Mitigation: Review the proposed plan, checklist, or implementation against the stated success criteria before applying it. <br>
