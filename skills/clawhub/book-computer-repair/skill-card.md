## Description: <br>
Book computer-repair services through Lokuli MCP for users who need to find and book computer-repair appointments. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

### License/Terms of Use: <br>


## Use Case: <br>
External users use this skill to search for nearby computer-repair providers, check availability, and create repair bookings through Lokuli. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can send customer contact details to Lokuli. <br>
Mitigation: Use it only when the user is comfortable sharing the required search and booking details with Lokuli. <br>
Risk: The skill can create a real repair appointment without documented consent or confirmation safeguards. <br>
Mitigation: Before creating a booking, confirm the provider, service, time, cost or fees if available, cancellation terms, and exact contact information with the user. <br>
