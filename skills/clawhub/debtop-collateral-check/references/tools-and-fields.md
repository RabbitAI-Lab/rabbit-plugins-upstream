# 工具参数与返回字段

> 4 个工具均为**只读**。排查流程见 SKILL.md §四；错误码与处置见 `@references/errors.md`。

## 通用参数约定

入参统一 **下划线（snake_case）**：`page_size`、`notice_id`、`enterprise_id`。为兼容历史调用，旧的驼峰写法（`pageSize` / `noticeId` / `enterpriseId`）仍可被接受，但**新代码请一律用下划线**（驼峰仅作过渡，后续可能移除）。ID 参数**整数与字符串都可传**（搜索结果里是整数，直接回传即可）；`page_size` 默认 10，**工具接受 1–100，但上游后端按 20 截断**（传更大值只会拿到 20 条，响应里 `page_size` 回显 20）。

## 1. `search_debt_notice` — 公告全文检索（**本 Skill 主入口：抵押物线索直接搜公告**）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| keyword | string | **是** | **全文**关键词：小区 / 楼盘 / 地块 / 门牌、资产类型词（`商铺` / `工业用地` / `采矿权` / `机器设备`）、企业名、出让方、债务人均可；空值报 `PARAM_INVALID: keyword 不能为空` |
| page | integer | 否 | 页码，默认 1 |
| page_size | integer | 否 | 每页条数，默认 10；工具接受 1–100，**上游按 20 截断** |

返回 `total` / `page` / `page_size` / `items[]`。

`items[]` 字段（实测完整键集合）：

| 字段 | 说明 |
|------|------|
| `notice_id` | 公告 ID（整数 int64），回传给 `get_debt_notice_detail` |
| `title` | 公告标题（**部分公告把抵押物写进标题**，如「【抵押物：…A2地块江岸林语花园二期】张*海债权」） |
| `notice_type` / `notice_type_name` | 类型枚举 / 中文名 |
| `source` | 公告来源（报纸名、交易所、平台等） |
| `notice_date` | 公告日期 `yyyy-MM-dd` |
| `creditor` | 债权人 / 出让方 |
| `debtor` | 债务人，**逗号分隔的多主体串** |
| `debtor_num` | 债务人主体个数 |
| `area` | 公告地区（省级）；**条件字段**，多数公告有、少数缺失 |
| `principal_amount_yuan` / `_text` | 本金：`_yuan` 精确值、`_text` 展示文本 |
| `total_amount_yuan` / `_text` | 总额：同上口径 |
| `detail_url` | 公告详情页链接（**输出时务必原样附上**，见 SKILL.md §五） |

> **列表项不含 `collateral`**：抵押物原文只能从 `get_debt_notice_detail` 取；列表项只能告诉你"这条公告与线索相关"。
>
> **`total` 可能被截断**：资产类型词命中量很大（实测 `土地使用权`、`商铺`、`工业用地` 均返回 `10000`），会撞上 `10000` 上限，**不要当作全量**。具体标的词命中量小（实测 `锦绣东方` 14 条、`万合广场` 2 条）。
>
> **实测命中量级（供收窄参考）**：`煤矿` 2398、`采矿权` 1698、`商铺` 9298、`萤石矿` 45。

### 检索收窄技巧

- **类词 + 地名**叠加（如 `工业用地` + 地区名）分两轮搜，再取交集；
- 换同义写法（`工业用地` / `土地使用权` / `土地`）提高召回；
- 命中多时优先按 `notice_date` 倒序取前若干条拉详情，而不是盲目翻页。

## 2. `get_debt_notice_detail` — 公告详情（**抵押物原文的唯一来源**）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| notice_id | integer \| string | **是** | 取自 `search_debt_notice` 的 `notice_id` |

返回列表项全部字段，并额外包含下列**条件字段**——仅在公告披露时才出现，**可能整体缺失**（不是 `null`，`key` 不存在）：

| 条件字段 | 说明 | 是否有抵押物 |
|---|---|---|
| `collateral` | **抵押物（自由文本）**：常含坐落、小区 / 地块名、面积 | ✅ 本条 |
| `guarantor` | 保证人（可能多个，逗号分隔） | — |
| `original_creditor` | 原债权人（转让类公告常见） | — |

> **字段差异（务必判空）**：催收类公告通常有 `guarantor` 而无 `collateral`；转让类公告两者都可能缺失、但常多出 `original_creditor`。**取值前先判断 key 是否存在**；某条公告没有 `collateral` 是**正常现象**，记为「公告未披露抵押物」，不要换成别的公告。
>
> 详情同样返回 `detail_url`（公告详情页链接）——引用该公告时一并附上。

### `collateral` 原文样例（真实形态）

```text
国有土地使用权面积20,592平方米，坐落：鹤岗市昌南路；1.土地：新华农场场部南哈萝公路东22,814.74平方米土地使用权
2.房屋：87号、88号、89号房产
3.在建工程：火车站东侧2,180.00平方米
4.车辆8台、机器设备18台（套）、1.5吨原煤；位于鹤岗市向阳区光明路59号38委1组一栋六层小楼，建筑面积1,170平方米
```

```text
①位于瑞金市象湖镇万合广场、锦绣东方的商铺19649.02㎡
②位于瑞金市象湖镇红都达到西段锦绣望族的商铺54.11㎡、车库及储物间901.12㎡
③位于瑞金市象湖镇金龙工业园的工业用地9275.75㎡，厂房3454.87㎡
④位于瑞金市象湖镇金龙工业园主要用于生产烤鳗鱼及酱油的机器设备
⑤…股权质押；位于赣州市章贡区水西镇横江村的萤石矿采矿权；抵押物已为新都食品债权、清泉矿业债权设立第一顺位抵押
```

### 抵押物解析规则（本地解析，工具不提供面积字段）

1. **切条目**：按**换行、分号（`;` `；`）、圈号（`①②③④⑤`…）、顿号**切分成独立条目；一条公告的 `collateral` 常含多个标的。
2. **抽要素**：每条尽力抽取
   - **资产类型**：土地 / 工业用地 / 房产 / 商铺 / 厂房 / 住宅 / 车库 / 在建工程 / 采矿权 / 股权 / 机器设备 / 车辆
   - **坐落 / 小区名**：常见「位于 {行政区划} {街道 / 镇} {小区名 / 地块名}」「坐落：{…}」
   - **面积**：紧跟数值与单位（见下）
   - **权利状态（如有）**：如「第一顺位抵押」「质押」
3. **面积识别**：单位只认 `㎡`、`m²`、`平方米`；**先去掉千分位逗号**（`19,649.02㎡` → `19649.02`）再转数值；`亩` **不换算**，原样保留并注明未换算。
4. **面积过滤**：用户给面积区间时，用**解析出的数值**比较（闭区间）；**解析不出面积的条目单列**，不要跳过、不要猜、不要用其它条目的面积顶替。
5. **线索核对**：用户给的是具体小区 / 门牌时，核对解析出的坐落是否**真的包含**该线索；同名词（同名小区 / 地块）必须标注「需人工核对坐落」。

## 3. `search_debt_enterprise` — 债务企业搜索（**反查维度**：哪些企业主体名下有此线索）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| keyword | string | **是** | **单一**名称（一个名称；**不要传逗号分隔的多主体串**）；**过宽的词会被拒**（`PARAM_INVALID: 搜索内容过于宽泛`） |
| page / page_size | integer | 否 | 同上 |

返回 `items[]`：`enterprise_id`、`enterprise_name`、`detail_url`（**企业详情页链接，输出时务必原样附上——见 SKILL.md §五**）。

> **两个维度的覆盖差异（实测，很重要）**：
>
> | 关键词 | 公告维度 `search_debt_notice` | 企业维度 `search_debt_enterprise` |
> |---|---|---|
> | `锦绣东方`（小区） | 14 条 | 1 家 |
> | `万合广场`（小区） | 2 条 | 3 家 |
> | `工业用地`（类词） | 10000（截断） | 2 家 |
> | `商铺`（类词） | 9298 | 8 家 |
> | `采矿权`（类词） | 1698 | **0 家** |
>
> 结论：**企业维度也对抵押物线索有覆盖，但远窄于公告维度**（同词常只有个位数甚至 0）。因此**以公告维度为主入口**，企业维度只用于"这条线索牵涉到哪些企业主体"的补充反查；企业维度返回的是**主体**（没有金额、没有 `area`、没有 `collateral`），不能替代公告维度。

## 4. `get_debt_enterprise_debt_summary` — 企业债务概要（补充主体规模）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| enterprise_id | integer \| string | **是** | 取自上一步的 `enterprise_id` |

关键返回字段：

| 字段 | 说明 |
|------|------|
| transfer_notice_count | 转让公告数量 |
| transfer_principal_total_yuan / _text | 转让类本金合计 |
| transfer_interest_total_yuan / _text | 转让类利息合计 |
| disposal_notice_count | 处置/招商公告数量 |
| disposal_principal_total_yuan / _text | 处置类本金合计 |
| disposal_interest_total_yuan / _text | 处置类利息合计 |
| related_creditors[] / related_creditor_count | 相关债权人（**仅返回前 3**，总数看 count） |
| related_debtors[] / related_debtor_count | 相关债务人（**仅返回前 3**，总数看 count） |
| related_sources | 相关公告来源（最多 2 个，超出以「等」结尾） |
| related_notice_period | 相关公告时段 `yyyy-MM-dd ～ yyyy-MM-dd` |
| detail_url | 企业详情页链接（**输出时务必原样附上**，见 SKILL.md §五） |

> 上述字段由后台服务定义、本服务仅透传；首次接入或后台升级后，建议用一次真实调用确认字段未变。
