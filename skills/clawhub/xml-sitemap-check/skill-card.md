## Description:

Validate your XML sitemaps against the pages that should actually be indexed, and generate a clean one from a page inventory.

This skill is ready for commercial/non-commercial use.

## Publisher:

[romeoseo](https://clawhub.ai/user/romeoseo)

### License/Terms of Use:

MIT-0

## Use Case:

Site owners, SEO practitioners, and developers use this skill to compare sitemap URLs with canonical, indexable pages that return 200, identify missing or invalid entries, and review sitemap reporting. When requested, it can provide a clean sitemap specification based on a page inventory.

### Deployment Geography for Use:

Global
