# 艺术方向

术流派不是拿来「贴风格」的，是拿来**约束决策**的。选定一个方向后，字体、栅格、圆角、动效节奏都该被它推出来——否则就是素材拼贴。

这一章的作用：把「我想要有点艺术感」翻译成「用哪套栅格、哪些字重、什么缓动」。

## 1. 十个可执行的方向

### 1.1 瑞士国际主义 Swiss / International Typographic

上世纪 50 年代 Zurich 与 Basel 的产物。核心不是「性冷淡」，是**信息优先**。

| 维度 | 规格 |
| --- | --- |
| 栅格 | 严格 12 栏，栏间距 = 一个基准单位，所有元素贴栏线 |
| 字体 | 无衬线（Helvetica / Inter / Neue Haas），只用 2 档字重 |
| 字号 | 大跨度对比：极大标题 + 极小正文，中间层很少 |
| 对齐 | 一律左对齐、上对齐（ragged right），不居中 |
| 色彩 | 黑 / 白 / 一个高饱和强调色（红或蓝） |
| 留白 | 大面积、不对称，负空间承担构图 |
| 动效 | 极慢、几乎是「淡入 + 位移 8px」，200–300ms |

**容易做错**：把它做成「全是灰字」。瑞士风格靠的是**字号对比**，不是低对比度。

### 1.2 包豪斯 Bauhaus

几何原语 + 三原色 + 功能即形式。

| 维度 | 规格 |
| --- | --- |
| 形状 | 只用圆、方、三角；圆角只用 0 与全圆两种 |
| 色彩 | 红 `#D62828`、黄 `#F4B400`、蓝 `#1B4F9C`，配黑与米白 |
| 构图 | 对角线与圆形轨道，元素允许互相穿插 |
| 字体 | 几何无衬线（Futura / Poppins / Space Grotesk），可用全大写 |
| 动效 | 元素沿几何路径进入（旋转、弧线位移），300–500ms |

**风险**：三个原色 + 三个形状很容易做成幼教风格。加点印刷质感（颗粒、错版）拉回来。

### 1.3 构成主义 Constructivism

比包豪斯更激烈：斜向、红黑、巨大字、强对比。

| 维度 | 规格 |
| --- | --- |
| 构图 | 30°–45° 斜轴，元素冲出边界 |
| 色彩 | 红 `#C1121F` + 黑 + 米白，最多三色 |
| 字体 | 超粗压缩体（大标题可拉到 120px 以上），全大写 |
| 动效 | 硬切入（`steps()`）、快速位移，200ms 以内 |

**风险**：可读性。正文必须退回常规字体与正轴。

### 1.4 装饰艺术 Art Deco

对称、几何金线、纵深。做「贵气」最直接的一派。

| 维度 | 规格 |
| --- | --- |
| 构图 | 严格中轴对称，阶梯状收束（stepped form） |
| 线条 | 细金线（1px，`#C8A35E`），扇形与放射纹 |
| 字体 | 高对比衬线（Didot / Playfair）或几何全大写（Futura）配宽字距 `0.2em` |
| 色彩 | 墨绿 `#1B3A2E` / 午夜蓝 + 古铜金 + 象牙白 |
| 动效 | 缓慢展开（金线生长、遮罩上推），400–600ms，`power2.inOut` |

**容易做错**：金色用太多。金是点缀，占比不超过 5%。

### 1.5 编辑排版 Editorial

杂志感：大标题、跨栏图、引文、页码。信息密度高但不乱。

| 维度 | 规格 |
| --- | --- |
| 栅格 | 12 栏，正文 6–8 栏宽，图可跨 12 栏 |
| 字体 | 衬线正文（Georgia / Source Serif）+ 无衬线小标 |
| 字号 | 标题 48–96px，正文 17–19px，行高 1.6–1.8 |
| 细节 | 首字下沉、引文缩进、脚注、细分割线 |
| 动效 | 几乎不动；图片视差 20–40px，滚动显现 200ms |

**最容易出「高级感」也最容易做假**：没有真实内容支撑的编辑排版会立刻暴露。

### 1.6 粗野主义 Web Brutalism

故意暴露结构：系统字体、原生边框、生硬色块、无圆角。

| 维度 | 规格 |
| --- | --- |
| 边框 | 2–3px 实线黑边，直角，无阴影 |
| 字体 | 系统字体或等宽（`ui-monospace`），可用全大写 |
| 色彩 | 高饱和撞色（荧光绿 / 亮黄 / 纯蓝）配纯黑 |
| 布局 | 允许溢出、允许滚动条可见、拒绝居中 |
| 动效 | 无，或极硬的瞬时切换（`steps(1)`） |

**风险**：可访问性。粗野 ≠ 不可读，正文对比度仍要 ≥ 4.5:1。

### 1.7 极简与「間」Ma

不是「少放东西」，是**每个元素都有存在的理由**，且留白是有形状的。

| 维度 | 规格 |
| --- | --- |
| 留白 | 至少 40% 面积为空，且空白成块不成缝 |
| 元素 | 一屏一个视觉焦点，最多两个 |
| 字体 | 细字重（300–400），字距略放大 `0.02em`，行高 1.8 |
| 色彩 | 单色系 + 一个材质色（纸白、亚麻、炭黑） |
| 动效 | 几乎不可察觉：透明度 0→1，600ms；位移不超过 6px |

**容易做错**：留白均匀分配。真正的「間」是**不对称留白**，空白也要有主次。

### 1.8 孟菲斯 Memphis

80 年代反叛：几何图形、撞色、无规律。

| 维度 | 规格 |
| --- | --- |
| 图形 | 波浪线、圆点、锯齿，作为独立装饰层 |
| 色彩 | 4–6 个高饱和色并用，允许冲突 |
| 字体 | 圆润几何体或手写体混排 |
| 动效 | 弹跳（`back.out(1.8)`）、摇摆、随机延迟 |

**限制**：只适合活动页、儿童产品、创意工作室。放进 B 端产品会显得不专业。

### 1.9 Y2K / 液态金属

千禧年科技乐观主义：镀铬、气泡、像素与渐变并存。

| 维度 | 规格 |
| --- | --- |
| 材质 | 液态金属渐变（`conic-gradient` + 高光）、玻璃拟态 |
| 字体 | 窄体科技字（Eurostile 类）或像素字 |
| 色彩 | 银灰 + 荧光蓝 / 酸性绿，允许全息渐变 |
| 动效 | 光泽扫过（`background-position` 位移）、缓慢旋转 |

**风险**：极易过时。当作一次性营销主题，别做进设计系统。

### 1.10 印刷与胶片质感

不是独立流派，是**给任何流派加可信度**的一层。

| 质感 | 实现 | 用量 |
| --- | --- | --- |
| 颗粒 Grain | SVG `feTurbulence` 叠层，`opacity: .04–.08` | 全站 |
| 纸张 Paper | 米白底 + 极轻噪点，不用纯白 | 全站 |
| 色差 Chromatic | 文字阴影 `1px` 青 + `-1px` 品红，`opacity: .3` | 标题局部 |
| 扫描线 Scanline | 3px 重复线性渐变，`opacity: .05` | 屏幕/复古主题 |
| 错版 Misprint | 元素位移 1–2px 叠色 | 海报、封面 |

颗粒是**最便宜的「高级感」**：0.05 的不透明度就能把纯色块的数码感消掉。

## 2. 构图语言

| 手法 | 规则 | 用在哪 |
| --- | --- | --- |
| 三分法 | 主体放在 1/3 交点上，不留正中 | 首屏主视觉 |
| 黄金比 | 主副区块宽度 1.618 : 1 | 图文混排 |
| 对角线 | 元素沿对角线排布产生动势 | 需要「有力」的页面 |
| 负空间 | 空白成块，且比元素更「重」 | 极简、编辑、Deco |
| 层叠 | 元素有意重叠 8–24px，产生纵深 | 拼贴、杂志风 |
| 出血 | 图片/色块冲出容器边界 | 打破「模板感」最有效的一招 |

**破模板最快的三个动作**：把一个元素做出血、把标题挪离正中、把留白做成不对称。

## 3. 色彩关系

用 OKLCH 思考，不要用 HSL 调。HSL 的亮度不是感知亮度，同一 L 值的黄和蓝看起来差很多。

| 关系 | 取法 | 气质 |
| --- | --- | --- |
| 单色 | 同 H，C 与 L 变化 | 克制、专业 |
| 类似 | H 相差 20–40° | 柔和、自然 |
| 互补 | H 相差 180° | 强对比，慎用大面积 |
| 分裂互补 | H 相差 150° / 210° | 有对比但不刺眼，最实用 |
| 三角 | H 相差 120° | 活泼、儿童、活动页 |

**配比公式**：60% 主色（背景）/ 30% 次色（结构）/ 10% 强调色。强调色超过 10% 就不再是强调。

**深色模式**不是反色：背景 `#12110F`（暖黑）、文字 `#EDE8DF`（暖白），层级靠「叠加更亮的层」而不是阴影。

## 4. 字体作为图形

| 手法 | 参数 | 注意 |
| --- | --- | --- |
| 巨型标题 | `clamp(3rem, 10vw, 9rem)`，行高 0.9 | 中文要 1.15，0.9 会压字 |
| 描边字 | `-webkit-text-stroke: 1px` + 透明填充 | 只用于 ≥ 48px |
| 遮罩填充 | 文字作 `mask`，图片作底 | 对比度必须验 |
| 字距拉开 | `letter-spacing: .2em` + 全大写 | 仅英文与数字，中文禁用 |
| 可变字重动画 | `font-variation-settings: 'wght' 200→800` | 需变量字体，回退要写 |

**中文排版的四条硬规则**：行高 ≥ 1.6；不要加字距；不要伪粗体（用真字重）；标点不要出现在行首。

## 5. 流派 → 动效映射

选定流派后，动效节奏基本被决定。混搭会露馅。

| 流派 | 时长 | 缓动 | 位移 | 禁用 |
| --- | --- | --- | --- | --- |
| 瑞士 | 200–300ms | `power2.out` | ≤ 8px | 弹跳、旋转 |
| 包豪斯 | 300–500ms | `power3.out` | 沿几何路径 | 随机抖动 |
| 构成主义 | 120–200ms | `steps()` / `expo.out` | 大位移斜切 | 慢速淡入 |
| Art Deco | 400–600ms | `power2.inOut` | 遮罩展开 | 快速切换 |
| 编辑 | 150–250ms | `power1.out` | ≤ 12px | 花哨转场 |
| 粗野主义 | 0–80ms | 无 / `steps(1)` | 瞬时 | 任何缓动 |
| 极简 | 500–800ms | `power1.inOut` | ≤ 6px | 位移、旋转 |
| 孟菲斯 | 300–500ms | `back.out(1.8)` | 大位移 + 旋转 | 严肃感 |
| Y2K | 600–1200ms | `sine.inOut` | 光泽扫过 | 直角硬切 |

**一致性检查**：把全站动效的 duration 列出来，如果有 0.12 / 0.3 / 0.55 三种且说不出理由，就是不统一。

## 6. 五条判断标准

1. **能不能用一句话说清这套视觉在干什么？** 说不清就是拼贴。
2. **去掉装饰后，信息层级还成立吗？** 不成立说明层级没做，靠装饰撑着。
3. **正文能不能舒服读完 500 字？** 读不完，风格就是失败的。
4. **低端机与深色模式下还好看吗？** 只在截图里成立的设计不是设计。
5. **换一批文案会崩吗？** 会崩说明是「为文案定制的图」，不是可复用的语言。
