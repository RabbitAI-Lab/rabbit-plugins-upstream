# 动效评审量表

交付前打分。目的不是拿满分，是**把「我觉得还行」变成可争论的具体项**。

## 六个维度（每项 0–4 分）

| 维度 | 看什么 | 0 分 | 2 分 | 4 分 |
| --- | --- | --- | --- | --- |
| **意图对齐** Intent fit | 效果是否等于用户要的感觉 | 用了与调性相反的效果 | 大致对，但偏花或偏闷 | 每个效果都能说出对应哪句诉求 |
| **层级与节奏** Hierarchy & rhythm | 主次、数量、编排顺序 | 全屏都在动 | 有主效果，但次要的抢戏 | 两个主效果 + 微交互，视线有明确动线 |
| **参数一致性** Token consistency | 时长/缓动/幅度是否同一套 | 每个组件自己写一套 | 大体统一，个别例外 | 全部走 token，同类动作时长完全相同 |
| **性能** Performance | 属性选择与元素数量 | 动 width/height，肉眼可见卡 | 属性对，但动画元素过多 | 只动合成属性，降速 4x 仍顺 |
| **降级与无障碍** Degradation | hover / focus / reduced-motion / 触屏 | 只做 hover，键盘与触屏失能 | 有 hover，缺 reduced-motion | 三条全有，且降级后信息不丢 |
| **工艺细节** Craft | 收尾、残留、打断、边界 | 结束停在半路、反复触发堆积 | 基本收得住 | 可打断、无残留、连点 10 次不崩 |

## 判定

| 总分（满分 24） | 结论 |
| --- | --- |
| ≥ 18 | 可交付 |
| 12–17 | 修完再交，优先修「降级」和「性能」 |
| < 12 | 重做，别在细节上打磨 |

单维度 **0 分** 一票否决，无论总分多少。

## 常见扣分项

| 扣分 | 项 |
| --- | --- |
| −2 | 用动效掩盖静态层级问题（判定：静态层三项以上不合格） |
| −2 | 一页三个以上主效果 |
| −2 | `transition: all` |
| −2 | 动布局属性且无法说明理由 |
| −2 | hover 是唯一反馈，无 focus-visible |
| −1 | 同类动作两种时长（如按钮 0.3s、卡片 0.25s） |
| −1 | 缺 `prefers-reduced-motion` |
| −1 | 动画结束元素停在非整数像素或残留 `transform` |
| −1 | 无限循环装饰动画，无暂停方式 |
| −1 | 弹簧 overshoot 用在表单/列表等高频操作 |
| −1 | 阴影用纯黑 `rgba(0,0,0,.5)` 且范围 > 30px |

## 十分钟诊断流程

1. **眯眼三秒**：能分出主次吗？不能 → 静态层问题，停止评审动效，先修层级。
2. **逐个交互走一遍**：hover → 点击 → Tab → 触屏模拟，哪一步没有反馈？
3. **打开「减少动态效果」**：信息还在吗？整块消失 → 降级失败。
4. **4x CPU 降速 + 滚动**：抖不抖？抖 → 查属性与元素数量。
5. **连点十次**：有残留中间态、有动画排队 → 可打断没做好。
6. **记录三处最刺眼的地方**，只修这三处。全修反而会破坏一致性。

## 输出格式

```
【评审】<页面 / 组件名>
意图对齐 3/4  说明…
层级节奏 2/4  说明…
参数一致 4/4  …
性能     2/4  …
降级     1/4  …
工艺     3/4  …
总分 15/24 → 修完再交
优先修：① 补 focus-visible ② 卡片 hover 改 transform ③ 统一 0.25s
```
