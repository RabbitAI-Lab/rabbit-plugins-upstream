# 高级交互组件

这 24 个组件的共同点：**样式先定，交互后配**。先想清楚静止形态长什么样，再设计状态怎么变——反过来做，会得到一堆「能动但不知道停在哪」的组件。

每个组件给出：静止样式 → 状态机 → 关键参数 → 降级 → 验收 → 常见做错。

| 类别 | 组件 |
| --- | --- |
| 容器与空间（1–8 之外见 16–18） | 撕线面板、照片抽屉、折叠卡片、图片对比、表格行展开 |
| 输入与选择 | 双头滑块、拖动选时段、日期条、命令面板 |
| 反馈 | 保存进度环、点赞爆发、复制变对勾、Toast 堆叠、长按删除 |
| 导航 | 轮播指示点、标签页指示器、阅读进度 |
| 数据 | 数字滚动、分步进度、骨架屏 |

## 通用的三条前置

1. **静止态必须好看**。动效只在切换瞬间存在，用户 95% 时间看到的是静止态。
2. **一个组件只允许一个主运动**。撕线面板就只做下拉，别再叠一个弹性缩放。
3. **所有拖拽类组件都必须回答「松手后停在哪」**：吸附位置、阈值、回弹目标，三个都要明确。

## 1. 撕线弹出面板 Tear Reveal Panel

底部一条虚线撕口，下拉露出内容，松手按阈值决定展开或回弹。

**静止样式**

| 项 | 值 |
| --- | --- |
| 面板 | 圆角 16px（顶部），底部直角 |
| 撕口 | `repeating-linear-gradient(90deg, #C8C2B6 0 8px, transparent 8px 16px)`，1.5px 高 |
| 撕口区高 | 28px，居中一个 40×3 的把手条（`#C8C2B6`, 圆角 2px） |
| 阴影 | `0 -8px 24px rgba(44,44,42,.08)`，只在展开时出现 |

**状态机**

```
closed ──拖拽(向下)──> dragging ──松手──> 距离 ≥ 72px 或 速度 > 0.45px/ms → open
                                     └──否则──> closed（回弹 320ms）
open ──拖拽(向上)──> dragging ──松手──> 距离 ≥ 48px → closed
```

**关键参数**

| 参数 | 值 | 理由 |
| --- | --- | --- |
| 跟手阻尼 | `dy * 0.55` | 全程 1:1 会让面板「跑得比手快」 |
| 展开阈值 | 面板高度的 22%，最小 72px | 太低误触，太高拉不开 |
| 速度阈值 | 0.45px/ms | 快速轻扫也能展开，符合直觉 |
| 回弹 | `cubic-bezier(.34,1.4,.64,1)` 320ms | 轻微过冲，像有皮筋 |
| 内容淡入 | 展开进度 60% 后才开始，180ms | 一开始就淡入会糊成一团 |

**降级**：`reduced-motion` 时去掉回弹与跟手阻尼，改 180ms 线性展开；触屏与鼠标同一套 Pointer Events。

**验收**：拖到一半松手必须回到 closed（不能卡在中间）；连续快速拉三次不累积位移；展开状态下滚轮不被劫持。

**常见做错**：用 `scroll` 事件模拟下拉（与页面滚动打架）；松手不做阈值判断，任何拖动都直接展开；撕口用 `border-bottom: dashed`（虚线间隔由浏览器决定，间距不可控）。

## 2. 保存按钮变进度环 Save → Progress Ring

点击后按钮横向收缩成圆环，环上走进度，完成后展开回文字。

**静止样式**

| 状态 | 形态 |
| --- | --- |
| idle | 高 44px，宽自适应（最小 112px），圆角 8px，深林绿底，暖白字 |
| working | 44×44 圆形，内部 SVG 环，环宽 3px，底色 `rgba(255,255,255,.18)`，进度 `#C8A35E` |
| done | 展开回胶囊，文字「已保存」+ 对勾，底色调到稍浅一档 |

**状态机**

```
idle ──click──> collapsing(220ms，宽度→44) ──> working(进度 0→100)
working ──>=100──> expanding(220ms，宽度回原值) ──> done
done ──1800ms──> idle（文本复位）
```

**关键参数**

| 参数 | 值 |
| --- | --- |
| 收缩 | `width` 用 `max-width` 过渡，220ms `cubic-bezier(.2,0,0,1)` |
| 环 | `stroke-dasharray = 2πr`，`stroke-dashoffset` 从 r→0 |
| 进度 | 每 40ms 增加 2–6%（有快慢，不要匀速） |
| 完成对勾 | `stroke-dashoffset` 画线 200ms，延迟 80ms |
| 复位 | 1800ms 后回到 idle |

**注意**：收缩会改 `width`，属于布局属性。组件内部锁死 `height` 与 `flex-shrink: 0`，并把容器 `contain: layout`，可以把重排限制在按钮自身。

**降级**：`reduced-motion` 时不收缩，直接在按钮内换成进度文字「保存中 42%」。

**验收**：连点五次不出现两个环；进度到 100 时环闭合无缺口；完成后 1.8s 复位且不闪。

**常见做错**：进度用 `setInterval` 但组件卸载没清（内存泄漏）；环起点不在 12 点方向（忘了 `transform: rotate(-90deg)`）；完成态没给对勾，用户不确定成功。

## 3. 双头范围滑块 Dual Range Slider

两个把手，中间填充随拖动伸缩，拖动时显示数值，松手隐藏。

**静止样式**

| 项 | 值 |
| --- | --- |
| 轨道 | 高 4px，圆角 999，`#E6E1D8` |
| 填充 | 深林绿，两端跟随把手 |
| 把手 | 20px 圆，白底 + 1px 描边 + `0 1px 3px rgba(0,0,0,.12)`；拖动时放大到 24px |
| 数值气泡 | 把手正上方 8px，深色胶囊，`tabular-nums` |

**状态机**

```
idle ──pointerdown(handl)──> dragging(显示气泡, 把手放大)
dragging ──pointerup──> settling(气泡 400ms 后淡出) ──> idle
```

**关键参数**

| 参数 | 值 |
| --- | --- |
| 最小间隔 | 总量的 4%，或一个明确的业务下限 |
| 拖动时 | 把手 `scale(1.2)`，120ms |
| 气泡出现 | 立即（拖动中不允许延迟） |
| 气泡消失 | 松手后 400ms，`opacity` 过渡 160ms |
| 吸附 | 步进 1 单位；不吸附到刻度点会「看起来卡住」 |

**降级**：键盘方向键每次移动 1 单位，`Shift+方向键` 移动 10；把手 `role="slider"` + `aria-valuemin/max/now`。

**验收**：两个把手交叉时互相推开而不重叠；拖动中不选中页面文字（`user-select: none`）；松手后数值不再跳动。

**常见做错**：用两个 `<input type="range">` 叠加且没处理 `z-index`，导致上层把手永远吃掉下层点击；气泡跟着手指数值抖动（没做取整）。

## 4. 轮播指示点 Indicator Dots

当前点拉长成条，随滑动连续过渡，而不是到点后突变。

**静止样式**

| 项 | 值 |
| --- | --- |
| 点 | 6px 圆，`#CFC8BB` |
| 活动 | 20px × 6px 圆角条，深林绿 |
| 间距 | 8px |
| 过渡 | `width 320ms cubic-bezier(.2,0,0,1)` |

**关键参数**

| 参数 | 值 |
| --- | --- |
| 连续过渡 | 跟手进度 `t` 映射：当前点宽 6→20，下一点 20→6 |
| 过渡时长 | 松手后 320ms；跟手时 `transition: none` |
| 超过 5 个 | 分组（如 1–5 / 6–10），否则点比内容还宽 |

**降级**：`reduced-motion` 时只切换颜色，不做宽度变化。

**验收**：快速连划三次，指示条不出现两个同时拉长；拖到中间松手回弹时，指示条同步回退。

**常见做错**：用 `active` 类切换 + CSS transition（只能突变，做不出跟手）；点数固定 5 个但内容 12 页（点到第 6 页就没指示了）。

## 5. 照片抽屉面板 Photo Drawer

照片铺满上半屏，面板从底部升起；上拖面板时照片被压缩。

**静止样式**

| 项 | 值 |
| --- | --- |
| 照片区 | 56vh，`object-fit: cover`，底部盖一层 `linear-gradient(transparent, rgba(0,0,0,.35))` |
| 面板 | 顶部圆角 20px，负 margin 24px 叠在照片上，白色 |
| 面板把手 | 36×4，`#D6D0C4`，圆角 2 |

**联动规则**（这是组件的核心）

| 面板位移 | 照片变化 |
| --- | --- |
| 上移 0 → 40% | 高度 `56vh → 40vh`，同时 `scale(1.06)` 补偿比例 |
| 上移 40% → 100% | 照片不再压缩，只做 `opacity .35` 压暗 |
| 下拉超过 30% | 关闭抽屉，照片恢复 |

**关键参数**

| 参数 | 值 |
| --- | --- |
| 跟手 | `dy * 0.8`（面板要跟得紧，阻尼比撕线面板小） |
| 吸附点 | 0 / 45% / 100% 三档 |
| 关闭阈值 | 下拖 > 30% 或速度 > 0.6px/ms |
| 照片压缩 | 用 `height` + `scale` 同步，**不要只改 height**（会变形） |

**降级**：`reduced-motion` 时取消联动压缩，只做抽屉位移。

**验收**：拖到 45% 松手必须吸附；照片在压缩过程中不变形（宽高比保持）；关闭后再次打开状态复位。

**常见做错**：只改照片高度不改 scale，人物被拉扁；面板与照片各自独立动画，出现「照片先到、面板后到」的错位。

## 6. 拖动选时间段 Drag Select Time Slots

按住连选格子，松开后合并成一条，两端把手可继续调整。

**静止样式**

| 项 | 值 |
| --- | --- |
| 格子 | 高 36px，`#F4F1EA` 底，1px `#E6E1D8` 边，圆角 6 |
| 正在选 | `rgba(27,58,46,.12)` |
| 已选区 | 深林绿，左端圆角 6、右端圆角 6，中间无圆角 |
| 把手 | 两端 4px 竖条，`#C8A35E`，抓取时变宽到 6px |

**状态机**

```
idle ──pointerdown(cell)──> selecting(anchor = cell)
selecting ──pointermove──> selecting(范围 = anchor..current，可反向)
selecting ──pointerup──> committed(两端出现把手)
committed ──拖动把手──> adjusting ──pointerup──> committed
```

**关键参数**

| 参数 | 值 |
| --- | --- |
| 反向选择 | 支持（从右往左拖），但归一化后渲染 |
| 最小区间 | 1 格 |
| 合并渲染 | 用绝对定位条覆盖，而不是给每格单独上色（后者圆角会错） |
| 拖动中 | 不做 transition，`transition: none` |

**降级**：键盘 `Shift + 方向键` 扩展选区，`Enter` 提交。

**验收**：拖到一半移出网格再回来，选区不丢；把手拖到交叉时互相阻挡；选区跨行时视觉是连续一条。

**常见做错**：给每个选中格加圆角（变成一串药丸）；`pointermove` 绑在格子上（快速拖动会跳过格子，应该绑在容器上用 `elementFromPoint` 或坐标计算）。

## 7. 吸边悬浮球 Edge Snapping Ball

随手拖拽，松手吸附最近边缘，滚动时半隐藏。

**静止样式**

| 项 | 值 |
| --- | --- |
| 球 | 48px 圆，深林绿，白色图标，`0 6px 18px rgba(27,58,46,.24)` |
| 贴边 | 距边缘 12px |
| 半隐藏 | 移出 60% 宽度，`opacity .75` |

**关键参数**

| 参数 | 值 |
| --- | --- |
| 拖动 | 全 1:1 跟手（悬浮球必须跟得紧） |
| 吸附 | 松手时比较到左右（或上下）边缘的距离，取近者 |
| 吸附时长 | 260ms `cubic-bezier(.34,1.3,.64,1)` |
| 滚动半隐藏 | 向下滚 40px 后触发，回滚恢复；过渡 200ms |
| 拖动阈值 | 位移 < 6px 视为点击，不触发吸附 |

**注意**：`position: fixed` 的球在 iOS 上要处理安全区 `env(safe-area-inset-*)`；用 `transform` 移动，不要改 `left/top`。

**降级**：`reduced-motion` 时吸附用 120ms 线性；半隐藏改为降低不透明度，不移出屏幕。

**验收**：拖到屏幕中间松手，必须落到左或右边缘之一；快速甩动不越界；滚动时不与页面滚动抢事件。

**常见做错**：松手后球停在原地（没做吸附）；用 `mousedown` 不兼容触屏；滚动监听没有 `passive: true`。

## 8. 横向日期条 Horizontal Date Strip

选中底色滑动切换，左右划翻周，月份同步。

**静止样式**

| 项 | 值 |
| --- | --- |
| 日期项 | 44×56，圆角 12，数字 15px，星期 10px |
| 选中 | 深林绿底，白字，`0 4px 12px rgba(27,58,46,.18)` |
| 选中块 | **一个绝对定位的滑块**，不是给每个日期单独上色 |
| 月份标题 | 11px，`letter-spacing .14em`，随周切换淡入淡出 160ms |

**关键参数**

| 参数 | 值 |
| --- | --- |
| 滑块移动 | `transform: translateX`，280ms `cubic-bezier(.2,0,0,1)` |
| 翻周 | 滚动吸附 `scroll-snap-type: x mandatory`，每屏 7 项 |
| 月份同步 | 以周的第一天所属月份为准；跨月时不显示「8月-9月」，只显示当前周起始月 |
| 点击非当前周日期 | 先滚动到该周，再移动滑块 |

**降级**：`reduced-motion` 时滑块直接跳转，不做过渡。

**验收**：连续点击不同日期，滑块不出现残影；翻到下一周后点位正确；月份标签不闪烁。

**常见做错**：每个日期自己带背景色（切换时是「两个色块交换」，做不到滑动）；用 `scrollLeft` 算位置但没考虑 padding。

## 9. 点赞爆发 Like Burst

点击后爱心放大回弹，同时溅出 8–12 个粒子。

| 项 | 值 |
| --- | --- |
| 静止 | 24px 描边心形，`#C9C1B4` |
| 选中 | 填充 `#C1121F`，`scale 1 → 1.35 → 1` |
| 粒子 | 8–12 个 4–6px 圆，半径 26–34px，随机角度 |

**常见做错**：粒子和心形同参数（应该更快更散）；`animationend` 后不移除节点，DOM 越堆越多。

## 10. 复制变对勾 Copy Check

点击复制，图标从「剪贴板」变成「对勾」，1.6s 后复原。

| 项 | 值 |
| --- | --- |
| 静止 | 16px 剪贴板图标 + 文案「复制」 |
| 过渡 | 两个图标叠放，`opacity` + `scale(.8→1)` 交叉 180ms |
| 对勾绘制 | `stroke-dashoffset` 从全长到 0，260ms，延迟 80ms |
| 复原 | 1600ms 后；hover 时提前复原 |
| 失败 | 图标变感叹号 + 文案「复制失败」，1200ms 复原 |

**验收**：快速点五次不会出现两个对勾；复制失败有明确反馈而不是静默。

**常见做错**：只换文字不换图标（用户扫一眼看不到变化）；成功后立刻复原（来不及看清）。

## 11. Toast 堆叠 Toast Stack

多条提示自下而上堆叠，超过 3 条时后面的压缩成薄片。

| 项 | 值 |
| --- | --- |
| 位置 | 底部居中，距底 24px + 安全区 |
| 单条 | 高 48px，圆角 12，深色 90% 不透明，`backdrop-filter: blur(8px)` |
| 入场 | `translateY(16px) + opacity 0` → 位置，240ms `back ease` |
| 堆叠 | 第 2、3 条 `scale(.96/.92)` + `translateY(-6/-12px)` |
| 超时 | 4000ms（错误 6000ms，带关闭按钮） |
| 退出 | 240ms，其余条目上移补位 |

**验收**：同时来 5 条不遮挡页面主要内容；滑动手势可单独划掉；同内容去重不叠三条。

**常见做错**：toast 挡住底部操作栏；错误与成功同一个颜色；自动消失的错误不提供日志入口。

## 12. 长按删除 Long Press Delete

按住 500ms 后项目抖动进入删除态，松手取消，继续按住则删除。

| 项 | 值 |
| --- | --- |
| 长按阈值 | 500ms（列表项）/ 800ms（危险操作） |
| 过程反馈 | 环形进度描边，从 0 到 100%，线性 |
| 进入删除态 | 本项目 `scale(.98)` + 轻微旋转 `±0.6deg` 抖动 |
| 取消 | 手指移动 > 8px 即取消（防误触） |
| 触觉 | 移动端 `navigator.vibrate(10)` |

**验收**：长按后滑动不触发删除；与页面滚动不冲突（`touch-action: manipulation`）。

**常见做错**：用 `setTimeout` 但 `pointerup` 没清；删除不可撤销且无二次确认。

## 13. 标签页滑动指示器 Tab Indicator

## 目录之外：怎么补一个新组件

24 个只是起点。网页与产品里的组件数量没有上限，真正可迁移的是**拆解方式**。遇到目录里没有的组件，按这六格填一遍，就能得到同等级的规格：

| 格 | 要回答的问题 | 填不出来的后果 |
| --- | --- | --- |
| 1 静止态 | 不动的时候长什么样？尺寸、圆角、色彩、阴影分别是多少？ | 动起来好看，停下来难看 |
| 2 触发 | 什么动作开始？点击 / 长按 / 拖拽 / 滚动 / 进入视口 | 用户不知道能不能操作 |
| 3 状态机 | 有哪几个状态？每个状态之间怎么流转？ | 卡在中间态，没法退出 |
| 4 参数 | 时长、缓动、位移、阈值、阻尼各是多少？ | 每个页面手感都不一样 |
| 5 降级 | 触屏没有 hover 怎么办？reduced-motion 怎么保留信息？ | 手机与键盘用户直接失能 |
| 6 验收 | 什么条件算做完？能不能一条条勾？ | 「差不多了」变成验收标准 |

**三个通用套路**，八成组件都能套：

1. **拖拽类** = 跟手系数 + 阈值 + 吸附点 + 回弹曲线。缺一个就会出现「松手不知道停哪」。
2. **形变类** = 首末两个静止形态 + 中间只动合成属性（`transform` / `opacity`）+ 内容在 60% 时交叉淡入。
3. **序列类** = 主时间轴 + 逐项延迟（30–80ms）+ 总时长封顶（感知上限 300ms）。

新组件写完后，回填到本文件的分类表里，并同步 `examples/premium-components.html` 加一个可操作样本——文档与可运行样本必须配对，否则规格会随时间失真。

## 组件之间的一致性

八个组件放在一起时，靠这四条保持统一：

1. **同一套 token**：时长只用 120 / 160 / 220 / 280 / 320ms，缓动只用 `standard` 与 `back-out` 两支
2. **同一套圆角**：容器 16–20，控件 8–12，胶囊 999
3. **同一套反馈优先级**：位移 > 颜色 > 阴影，不要三个同时上
4. **同一套降级策略**：全部组件在 `prefers-reduced-motion` 下保留「状态可见」，只去掉运动

把这四条写进设计系统，比记住八个组件更重要。
