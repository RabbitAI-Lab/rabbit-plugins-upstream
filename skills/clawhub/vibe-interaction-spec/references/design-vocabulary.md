# 静态设计词汇

动效救不了排版。这一层出问题时，加动画只会更乱。以下术语用于**诊断和描述静态问题**，让「不好看」变成可执行的修改项。

## 1. 视觉层级（Visual Hierarchy）

一屏之内，眼睛应该按什么顺序看。层级不是「设计感」，是信息优先级。

| 手段 | 强度 | 用法 |
| --- | --- | --- |
| 尺寸 | 最强 | 主标题是正文的 2–2.5 倍；超过 3 倍会散架 |
| 字重 | 强 | 同字号下 400 → 600 就够；全站只用两档 |
| 颜色对比 | 强 | 主信息近黑、次要信息 60% 灰、辅助 40% 灰 |
| 留白 | 中 | 分组靠间距，不靠分割线；组间距至少是组内间距的 2 倍 |
| 位置 | 中 | 左上优先（中文阅读动线）；F 型或 Z 型 |

**三秒测试**：眯眼到看不清字，只剩色块。这时还能分出主次，层级就成立；全是均匀的灰块，层级不成立。

## 2. 栅格与间距（Grid & Spacing）

| 术语 | 英文 | 定义 | 常见错误 |
| --- | --- | --- | --- |
| 8pt 栅格 | 8-point grid | 所有间距、尺寸取 8 的倍数（4 作最小单位） | 出现 13px、22px 这类随意值 |
| 间距阶梯 | spacing scale | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 | 阶梯太长，出现 20、28、36 这种中间值 |
| 栏格 | columns | 桌面 12 栏、平板 8 栏、手机 4 栏 | 用固定像素宽度硬怼，响应式必崩 |
| 槽宽 | gutter | 栏与栏之间的空隙，桌面 24–32px，手机 16px | gutter 大于卡片间距，视觉上并成一栏 |
| 内外边距 | margin / padding | 容器外留白与容器内留白要区分 | 同一层级两种边距混用 |
| 基线网格 | baseline grid | 正文行高对齐到固定基线（如 4px 的倍数） | 多栏文本行基线错位 |

**邻近性原则**：相关的东西靠近。用户分不清哪些是一组，九成是间距（而非视觉样式）没分级。

## 3. 字体（Typography）

| 术语 | 英文 | 取值 | 说明 |
| --- | --- | --- | --- |
| 字阶 | type scale | 比例 1.125（克制）/ 1.25（常用）/ 1.333（大反差） | 从小到大乘同一个比例，不要手写一堆字号 |
| 行高 | line-height | 西文 1.4–1.6；**中文 1.6–1.8** | 中文汉字方框满，行高比西文要大一档 |
| 行宽 | measure | 西文 45–75 字符；中文 25–40 字 | 超过就分栏或加 max-width |
| 字重 | weight | 只用 2 档（如 400 + 600） | 三档以上会散；中文伪粗体很难看 |
| 字距 | letter-spacing | 大字号收紧 -0.01em；小字号全大写放宽 +0.08em | 中文正文不要加字距 |
| 等宽数字 | tabular-nums | `font-variant-numeric: tabular-nums` | 数字滚动、计时器、表格必加，否则宽度跳动 |
| 标点悬挂 | hanging punctuation | 引号、括号超出边界 0.5em | 精细排版才需要 |

## 4. 色彩（Color）

| 术语 | 英文 | 关键数值 |
| --- | --- | --- |
| 对比度 | contrast ratio | 正文 ≥ 4.5:1（AA）；大字（≥24px 或 ≥18.66px 加粗）≥ 3:1；AAA 要 7:1 |
| 非文本对比 | non-text contrast | 控件边框、图标、焦点框 ≥ 3:1（WCAG 1.4.11） |
| 语义色 | semantic color | `surface` / `on-surface` / `outline` / `primary` / `error`，不写 `gray-300` |
| 中性色阶 | neutral ramp | 至少 9 档（50→900），正文用 800/900，边框用 200 |
| 高度叠加 | elevation overlay | 深色模式靠「叠一层浅色」表达层级，不靠阴影 |
| 感知均匀色 | OKLCH | 渐变插值用 oklch，避免 sRGB 中间穿过灰色死区 |

**纯黑纯白是廉价的头号来源**：正文用 `#2C2C2A` 一类的近黑，背景用象牙白 `#FAF8F5`，比 `#000` / `#FFF` 高级一大截。

## 5. 格式塔（Gestalt）

| 原则 | 英文 | 一句话 |
| --- | --- | --- |
| 接近 | Proximity | 靠得近 = 一组，比任何边框都管用 |
| 相似 | Similarity | 长得像 = 同类，样式必须成体系 |
| 连续 | Continuity | 眼睛会沿着线走，对齐线要连续 |
| 闭合 | Closure | 大脑会补全不完整的形状，不需要画满边框 |
| 共同区域 | Common Region | 有了背景色块，边框可以省掉 |
| 图底关系 | Figure / Ground | 主体与背景必须有明度差，模糊/半透明要慎用 |

## 6. 状态矩阵（State Matrix）

动效是状态之间的过渡。**状态没定义，动效无从谈起。** 每个可交互元素至少要有：

| 状态 | 触发 | 必须可见 |
| --- | --- | --- |
| default | 常态 | — |
| hover | 指针悬停（仅桌面） | 底色/阴影/位移，三选一 |
| focus-visible | 键盘 Tab 聚焦 | **必须有不依赖颜色的焦点环**（2px，对比 ≥3:1） |
| active / pressed | 按下瞬间 | 缩放 0.97–0.98 或加深 |
| selected | 选中且持续 | 底色 + 文字双通道，不能只靠颜色 |
| disabled | 不可用 | 降低不透明度，且**不加 hover** |
| loading | 异步进行中 | 按钮内转圈或骨架，禁止重复提交 |
| error | 校验失败 | 边框 + 图标 + 文案，三重冗余 |

额外整页态：**空状态**（说明 + 一个明确动作）、**骨架屏**（与真实布局同构，不要用转圈）。

## 7. 组件解剖（Component Anatomy）

| 项 | 建议值 | 说明 |
| --- | --- | --- |
| 圆角 | 4 / 8 / 12 / 16 / 9999 五档 | 全站混用 6、10、14 立刻显乱 |
| 阴影 | 5 级，越高级越淡越散 | `0 1px 2px rgba(0,0,0,.06)` 起步；禁止 `0 0 20px rgba(0,0,0,.5)` |
| 描边 | 1px，颜色比背景深 8–12% | 深色模式用浅 12% |
| 点击区 | ≥ 44×44px（iOS）/ 48×48dp（Android） | 视觉可以小，热区必须够 |
| 图标 | 线性或面性二选一，线宽统一 | 混用是最常见的廉价信号 |

## 8. 廉价感诊断清单

按命中数量判断严重程度。命中 3 条以上，先别谈动效。

- [ ] 三个以上区块字号、间距完全一致，没有主次
- [ ] 正文用纯黑 `#000`，边框用纯灰 `#CCC`，背景纯白
- [ ] 圆角出现 6px、10px、14px 这种非体系值
- [ ] 阴影又大又黑，像浮在黑雾上
- [ ] 全站只有一种字重，标题靠加大字号硬撑
- [ ] 线性图标和面性图标混着用
- [ ] 所有内容都居中，没有对齐轴
- [ ] 渐变从蓝到紫中间发灰
- [ ] 卡片四边等距、等宽、等高，像排表格
- [ ] 深色模式只是把白底改成黑底，没有重算层级
