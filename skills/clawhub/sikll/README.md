# 佛学讲评助手

佛教讲说 / 复讲 / 授课 / 演讲的自动评测与评分工具（通用版）。上传音频或视频，输出图表化专业评价报告。

## 能做什么

- **仅需音视频**：上传 mp3/wav/m4a/mp4 等即可，自动转写。不需要、也不采用预转写文字稿。
- **双轨评估**：讲说风格轴（通俗开示型 → 学院专业型）+ 内容分类轴（教义教理 / 叙事陈述 / 实践修证）。
- **六维评分**：教义准确、结构逻辑、语言表达、契机应变、感悟感染、自主发挥，带进度条可视化。
- **结构大纲**：主旨 / 大纲 / 核心三要素表格呈现，一眼看清讲说骨架。
- **来源核验为底座**：所有教义、名相、表法、判教断言逐条比对大藏经 CBETA 与天台藏，标注原典出处或"约机施设"；命中 CBETA 出处者附**路径式行级深链**（精确到页栏行）。
- **音频维度分析**：语速、语速均匀度、填充词密度、重复、停顿分布等特征分析；可选接入语音评测 API。

## 评分校准

宁低勿高（优秀线 ≥8.0）；拉开区分度；照本宣科压分；ASR 识别错字不计入扣分；永不满分。

## 使用方法

1. 调用本技能（触发词：讲经评测、讲评分析、佛教演讲评分、复讲评价、授课评估、佛学讲说打分）。
2. 上传音频或视频文件。
3. 获取含结构大纲、双轨评估、六维评分、来源核验、亮点、待改进、提升建议的完整报告。

## 平台与依赖

- 同时适配 WorkBuddy、IMA 与其他大模型平台。
- 教证核验依赖大藏经 CBETA、天台藏类知识库（经 MCP 检索）；不可用时降级为联网检索并标注置信度。
- 可选：语音评测 API（凭证走环境变量，不硬编码）。
