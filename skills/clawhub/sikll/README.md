# 佛学讲评助手

复讲 / 讲经 的 AI 评分与评价助手，专为天台宗实修教学场景设计。

## 能做什么
- **输入灵活**：复讲文本、音频（先 ASR 转写）、视频（抽音频转写）均可。
- **零资料也能评**：只上传录音、无任何参考原文时，自动检索「天台藏全集2026」「大藏经CBETA2026」或联网比对所讲内容的原始出处，再作评价。
- **内容自动分类**：义理类 / 历史类 / 仪轨戒律类 / 故事叙述类，不同类评价侧重不同。
- **两类 × 三阶 × 十项评分**：初级复讲（<30min 复习功课）与专业讲经（≥1h 科判讲授）；复述→讲述→演述综述三阶；基本内容5+拓展延伸3.5+综合素养1.5。
- **统一评分带**：及格 6.0；平均 6.5–9.5；软上限 9.7；永不 10 分；与原资料差距大可 <6 但须附详细依据。
- **鼓励灵活讲法**：自动识别比喻 / 公案 / 故事 / 生活举例 / 个人体悟，着重点评、酌情加分。
- **给出具体指导**：逻辑散乱、重点不清、层次混乱时，给出可操作的修改意见（如先立五重玄义、分段安科判）。
- **音频维度（选修）**：若接入第三方语音评测（腾讯口语评测 / Fish Speech），在表达项补充语速 / 韵律 / 流利度评价。

## 评价标准锚点
- 教证核验溯源天台藏三层结构与智者大师《法华玄义》五重玄义 / 七番共解。
- 参照中国佛教讲经交流会通则（契理契机、解经准确、结合自身、语言表达、威仪），以当年官方 rubric 为准。

## 使用方法
1. 在 WorkBuddy 中调用本技能（触发词如"讲评""复讲评分""帮我评一下这段讲经"）。
2. 粘贴复讲文本 / 上传音频视频，选填类别与参考原文（强烈建议提供以提升准确度）。
3. 获取带评分依据、亮点、待改进、提升建议的专业评价报告。

## 依赖
- ima「天台藏全集2026」「大藏经CBETA2026简体版」知识库（教证核验）。
- 可选：「天台研究」专家（后台教证核验引擎）。
- 选修：第三方语音评测 API（音频语气分析）。
