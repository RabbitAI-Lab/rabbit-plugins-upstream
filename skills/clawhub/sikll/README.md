# 佛学讲评助手

佛教讲说 / 复讲 / 授课 / 演讲的自动评测与评分工具。上传音频或视频，输出图表化专业评价报告。

## 能做什么

- **仅需音视频**：上传 mp3/wav/m4a/mp4 等即可，自动转写。不需要、也不采用预转写文字稿。
- **自动判定类型与级别**：叙事陈述型 / 教义教理型 / 实证行修型 × 初级 / 中级 / 专业级 = 九宫格评分卡，选卡后按对应标尺打分。
- **六维评分**：教义准确、结构逻辑、语言表达、契机应变、感悟感染、自主发挥，带进度条可视化。
- **结构大纲**：主旨 / 大纲 / 核心三要素紧凑双列表格呈现，一眼看清讲说骨架。
- **来源核验为底座**：所有教义、名相、表法、判教断言逐条比对大藏经 CBETA 与天台藏，标注原典出处或"约机施设"。
- **音频维度分析**：语速、语速均匀度、填充词密度、重复、停顿分布等特征分析；可选接入讯飞 ISE 语音评测。

## 评分校准

宁低勿高（优秀线 ≥8.8）；拉开区分度；照本宣科压分；ASR 识别错字不计入扣分；永不满分。

## 使用方法

1. 调用本技能（触发词：讲经评测、讲评分析、佛教演讲评分、复讲评价、授课评估、佛学讲说打分）。
2. 上传音频或视频文件。
3. 获取含结构大纲、六维评分卡、亮点、待改进、提升建议的完整报告。

## 平台与依赖

- 同时适配 WorkBuddy 与 IMA。
- 教证核验依赖大藏经 CBETA、天台藏类知识库（经 MCP 检索）；不可用时降级为联网检索并标注置信度。
- 可选：语音评测 API（凭证走环境变量，不硬编码）。
