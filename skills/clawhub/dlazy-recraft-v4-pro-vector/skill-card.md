## Description:

Generates detailed vector-style illustrations from text prompts using the dLazy-hosted Recraft V4 Pro Vector model.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Designers, developers, and other creators use this skill to generate detailed vector-style artwork from text prompts for illustrations and visual assets.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and any files explicitly supplied to the CLI may be sent to dLazy's cloud service.

Mitigation: Submit only prompts and files you are comfortable sharing with dLazy.

Risk: Logging in stores a dLazy API key locally.

Mitigation: Protect local credentials and rotate or revoke the key through dLazy if needed.
