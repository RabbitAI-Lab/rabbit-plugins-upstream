## Description:

Generates high-fidelity text-to-vector artwork suited to production-grade SVG assets and detailed illustrations.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and designers use this skill to turn text prompts into detailed vector-style artwork for design and production workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected local media are sent to dLazy's hosted service; generation requires an API key and credits.

Mitigation: Avoid sensitive inputs, upload only intended files, protect or rotate the API key, and review the external CLI before installing it.

## Reference(s):

- [dLazy service](https://dlazy.com)
- [dLazy CLI package (@dlazy/cli)](https://www.npmjs.com/package/@dlazy/cli)
