## Description:

Helps agents create detailed vector artwork from text prompts using dLazy's Recraft V4 Pro Vector service.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Designers, developers, and other creators use this skill to request detailed vector artwork and illustrations from text prompts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and any files explicitly provided may be sent to dLazy's cloud service.

Mitigation: Review prompts and selected files for sensitive information before submitting them.

Risk: Logging in can save a dLazy API key locally.

Mitigation: Protect the local configuration and rotate or revoke the key through the dLazy dashboard if needed.
