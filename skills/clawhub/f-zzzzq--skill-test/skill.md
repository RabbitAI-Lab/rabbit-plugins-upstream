# 技能：会议记录转行动清单

## 用途
把非结构化的会议内容整理成清晰的摘要、决策和待办事项，方便后续跟进。

## 触发条件
当用户提供会议记录、聊天记录、讨论摘要，并希望提取行动项、负责人或截止时间时使用。

## 输入
- 会议原文（必需）
- 参会人名单（可选）
- 当前日期（可选，用于换算“下周三”等相对时间）

## 输出格式

### 1. 会议摘要
用 3～5 句话概括会议主题、目标和关键结论。

### 2. 关键决策
- 决策内容
- 决策依据
- 影响范围

### 3. 行动清单

| 序号 | 行动项 | 负责人 | 截止时间 | 优先级 | 备注 |
|------|--------|--------|----------|--------|------|
| 1 |  |  |  | 高/中/低 |  |

## 处理步骤
1. 通读全文，区分“信息同步”“问题讨论”“明确决策”“待办事项”。
2. 将待办改写成“动词 + 对象 + 可验收结果”，例如“输出接口文档初稿”。
3. 识别负责人：显式提到的优先；未提到的标记为“待确认”。
4. 识别截止时间：绝对日期优先；相对时间结合当前日期换算。
5. 判断优先级：影响上线、阻塞他人、临近截止的设为高。
6. 按输出格式整理，保持简洁，不逐字复述原文。

## 规则
- 不编造未出现的负责人、截止时间和结论。
- 不确定的信息统一标注“待确认”。
- 如果原文没有明确行动项，输出“未发现明确行动项”。
- 保留必要上下文，但避免冗长。

## 示例
输入：
> 小王说登录页下周三前要改完，李雷负责接口联调，最好周五前。另外大家同意先不做微信登录。

输出：
- 会议摘要：讨论登录页改造与接口联调安排，决定暂缓微信登录。
- 关键决策：暂不做微信登录。
- 行动清单：
  1. 完成登录页改造，负责人：小王，截止：下周三，优先级：高。
  2. 完成接口联调，负责人：李雷，截止：本周五，优先级：高。
