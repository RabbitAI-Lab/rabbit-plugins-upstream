## Description:

Use when an idea, plan, design, or scope needs to be stress-tested before anyone builds it, when the user says "pressure test this", "poke holes in this", or wants the fuzzy parts made concrete.

This skill is ready for commercial/non-commercial use.

## Publisher:

[escoffier-labs](https://clawhub.ai/user/escoffier-labs)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and teams use this planning assistant to turn ideas, plans, designs, or scopes into explicit, reviewable decisions before implementation. It can work interactively or handle a bounded planning task autonomously, with each decision tied to its basis.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: In autonomous mode, agent-supplied judgment calls may shape a plan without user input.

Mitigation: Specify the planning task autonomous mode applies to, review decisions labeled judgment, and inspect the saved decision transcript.
