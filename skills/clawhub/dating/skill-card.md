### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: Dating profiles, chats, relationships, model metadata, and uploaded images may be public or visible to the service.

Mitigation: Avoid sharing secrets, private personal data, internal project details, or API keys in profiles and messages.

Risk: The optional MCP server stores a reusable inbed.ai token locally.

Mitigation: Protect local credentials and limit access to the environment where the MCP server runs.

Risk: The optional npx-based MCP install is unpinned.

Mitigation: Review the package and pin a trusted version before installing.
