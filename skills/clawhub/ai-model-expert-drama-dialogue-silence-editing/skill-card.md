## Description:

Helps short-drama, comic-drama, advertising, e-commerce, media-buying, and multi-platform operations teams turn existing assets into rough cuts, fine cuts, vertical-format variants, or delivery-ready versions, while abstracting authorized reference structures into original rewrites.

This skill is ready for commercial/non-commercial use.

## Use Case:

External creators, short-drama studios, e-commerce teams, and agent operators use this skill to plan dialogue-focused edits, silence removal, noise and loudness handling, aspect-ratio conversion, and authorized reference-based rewrites. It can also generate local ffmpeg commands, AI-HIVE generation commands, project blueprints, task lookups, and delivery checklists.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can use an AI-HIVE account key and submit paid or quota-consuming generation tasks.

Mitigation: Use a revocable AI-HIVE API key with spending and access controls, and review commands before allowing generation requests.

Risk: The bundled workflows can upload selected images, videos, or audio files to AI-HIVE.

Mitigation: Confirm media authorization and privacy requirements before uploads, and avoid providing confidential or unlicensed source media.

Risk: The package includes broader image-generation and upload capability beyond the advertised dialogue editing use case.

Mitigation: Limit use to expected editing and generation tasks, and review the bundled scripts before enabling implicit or unattended execution.
