# 深知可信工作台MCP介绍

## 一、产品简介

深知可信工作台面向政策、法律、标准和公共服务场景，提供可信问答、权威检索、深度研究和材料整理能力。它可以帮助用户查询政策原文、办事条件、申报材料、补贴资质、法律法规和行业标准，梳理多地区、多时间范围的信息，并基于可追溯的权威来源形成清晰、可核验的结果。

## 二、接入方案

深知可信工作台以标准MCP（Model Context Protocol，模型上下文协议）形式接入WorkBuddy，配套提供Skill说明文件，指导AI正确选择和调用工具。整体接入信息如下。

## 三、核心能力

当前MCP Server提供3个工具，按查询任务的轻重与复杂度分层使用。

### （一）credible_chat：可信问答

用于一般性的政策、法律、标准或办事咨询，直接回答用户问题。适用于政策问答、办事咨询、材料清单说明等场景，回答可附带可信溯源报告链接。

### （二）trusted_search：可信搜索

用于搜索权威材料、政策文件、法律法规、行业标准、事项和知识专库，返回原文链接与参考材料。适合用户要求查找原文、列出政策依据、返回知识专库链接等场景。

### （三）deep_query：深度搜索

用于用户明确要求的复杂政策研究、跨地区材料梳理和较长链路查证，可输出研究基础材料。该工具耗时较长，仅按用户明确要求使用，不作为默认工具。

## 四、能力特点

深知可信工作台优先基于权威来源和知识专库进行检索与回答，不依赖模型自行发挥。服务保留原文链接、溯源报告和参考材料，便于复核和继续阅读；支持按地区、时间和问题范围缩小检索，减少无关结果；支持从单点问答扩展到跨政策、跨地区的深度研究。未检索到材料时如实说明，不编造结论；调用失败时给出明确提示。

## 五、适用场景

深知可信工作台适用于查询法律法规、政策文件、行业标准和官方办事指南，了解税务、社保、公积金、证照、补贴、资质、养老、教育和就业等公共服务事项，检索政策原文、申报条件、办理材料、适用地区和有效时间，开展多地区政策对比、政策变化梳理和复杂问题的证据研究，以及基于权威资料整理汇报材料、调研基础材料和可核验的结论。

## 六、使用示例

### （一）可信问答示例

用户提问：深圳公积金租房提取需要哪些材料？MCP工具返回政策依据与办理材料清单，AI据此给出可直接使用的回答，并附溯源链接。

### （二）可信搜索示例

用户提问：搜索重庆市智能化改造技改补贴政策，给我政策材料和原文链接。MCP工具按地区、时间检索权威政策材料，返回原文链接和参考材料清单。

### （三）深度研究示例

用户提问：请深度研究并对比北京市、上海市和深圳市的人才引进政策，梳理适用人群、核心条件和主要差异。MCP工具进行跨地区政策研究，输出研究基础材料，供后续整理成调研报告或对比结论。
