# cn-blog-writing

写中文技术博客时用的 skill，主要解决一个问题：写出来的东西别一股 AI 味。

## 这个 skill 干什么

- 写博客文章时按一套节奏规则组织句子，少句号断句，多逗号连
- 检查草稿里的 AI 痕迹（"本文将介绍"、"值得注意的是"、破折号堆叠、一句一段的排版）
- 规划下一篇写什么，基于已有内容找空白话题
- 首次使用时会问你的博客地址，分析现有风格和 SEO 情况，后续直接复用

## 安装

```bash
clawhub install cn-blog-writing
```

## 怎么用

装完之后，让 AI 帮你写文章、改草稿、查 AI 味，都会自动走这套规则。

支持的触发场景：

- "帮我写一篇关于 XX 的博客"
- "检查这篇文章有没有 AI 味"
- "下一篇写什么"
- "调整下这篇文章的语气"

## 规则速览

详细的对比示范见 [references/examples.md](references/examples.md)，核心就几条：

- 标点：同一件事的不同侧面用逗号连，话题切换才用句号
- 段落：2-5 句一段，不要一句一段
- 语气：直接给判断，不替读者推逻辑
- 结构：从痛点切入，不要"本文将介绍"
- 结尾：自然收尾，不要"总结"章节复述全文
