## Description: <br>
Helps agents generate local XML and JSON conversion scripts for bidirectional format conversion, attribute handling, namespaces, CDATA, and single-file workflows. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[thcjp](https://clawhub.ai/user/thcjp) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to ask an agent for XML-to-JSON and JSON-to-XML conversion guidance, reusable scripts, shell commands, and configuration choices for local document or data-format conversion. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated conversion scripts or shell commands may behave incorrectly or touch unintended local files. <br>
Mitigation: Review generated code and commands before execution, and limit use to intended XML and JSON files. <br>
Risk: Local conversion can expose sensitive document contents to the agent session. <br>
Mitigation: Avoid processing sensitive files unless the agent environment and data handling policy are appropriate. <br>
