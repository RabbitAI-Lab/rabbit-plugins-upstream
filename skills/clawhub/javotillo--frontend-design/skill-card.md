## Description:

Create distinctive, production-grade frontend interfaces for web components, pages, and apps with strong aesthetics, purposeful motion, semantic structure, and accessibility.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and designers use this skill to plan, implement, refine, and QA distinctive frontend interfaces in HTML, CSS, JavaScript, React, or similar web stacks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated frontend work may include third-party assets such as externally loaded fonts when the starter patterns are copied unchanged.

Mitigation: Review generated projects for privacy and asset-loading preferences, and replace external font or asset links with approved local or self-hosted alternatives when required.

Risk: Frontend design guidance can still produce accessibility, localization, or user-experience issues if accepted without review.

Mitigation: Run the generated interface through project QA, including accessibility, responsive layout, contrast, localization, and content review before release.
