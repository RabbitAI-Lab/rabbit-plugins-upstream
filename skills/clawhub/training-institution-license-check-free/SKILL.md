# 校外培训机构资质与教师备案核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：校外培训机构（学科类 / 非学科类）的**校区负责人、教务、财务**，
在**每月自查**与**教育局年检**这两个固定节点上必须把这张台账核一遍才能往上交。
"双减"之后，机构要同时满足四件事才敢开门：**证照齐全**（办学许可证 / 营业执照）、
**教师持证并备案**、**收费进监管账户**、**培训时段合规**；缺一项就是停业整改。

**这本台账里最容易出事的地方**：

1. **办学许可证 / 营业执照到期**：到期未换发就是无证办学，超期天数要能一眼看出来；
2. **教师资格证缺失、过期或未备案**：无证上岗、未备案排课都是直接处罚项，必须**点人**而不是看平均；
3. **收费没进监管账户**：收款账户与备案的监管账户不一致，等于账外收费（年检直接扣分）；
4. **同一教师重复登记 / 同一个资格证号挂在两个人名下**：谁在教、教几节就算不清，课时与收费都会翻倍；
5. **合计行与明细对不上**：教师数、班级数、课时数的合计必须等于明细逐列加总。

**这条最容易被年检抓住**：**证照或教师资格证已超期**。免费版会按整天数点名超了多少天，
并把"是哪张证、哪个教师、哪个班级"一起写在结论里，可以直接拿去整改。

**这张表会逐项核对什么**：上面这本台账的逐行算术、证照与证件的到期覆盖、账户字面一致性、重复与合法性检测。

每条结论都带**原文行号与行内容**（校区、教师、班级、日期、金额都在结论里），可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 这个免费版查什么（6 项）

1. **证照有效期覆盖** —— 核对基准日 ≤ 办学许可证到期日、且 ≤ 营业执照到期日；超期逐条给出已超期天数。
2. **教师持证与备案覆盖** —— 缺教师资格证号 / 资格证过期 / 备案状态为「未备案」逐人点名。
3. **收费是否进监管账户** —— 收款账户与备案监管账户归一化后逐字比较，不一致即报「收费未进监管账户」。
4. **同一教师重复登记 / 同一教师资格证号出现在两个主体** —— 同一节课重复登记、一个证号挂在两个姓名下都点名。
5. **合计行逐列复核** —— 数量类列（教师数、班级数、课时数）的合计行必须等于明细行加总。
6. **空白占位符与字段合法性** —— 必需字段缺失、日期格式非法、课时为负或为零、备案状态 / 科目类别取值非法、培训时段格式非法。

**必需列**（缺任何一列都只报「材料不足」，**绝不给结论**）：
校区名称、办学许可证号、许可证到期日、营业执照号、营业执照到期日、教师姓名、教师资格证号、
备案状态、任教科目、班级名称、报名人数、班额上限、收费标准、收费金额、课时数、培训时段、
收款账户、监管账户、核对基准日。**（19 列，另有 教师数 / 班级数 / 科目类别 / 教师资格证到期日 / 备注 等辅助列）**

**这个免费版不查**（完整档才查，跑 `--sample` 会如实列出）：
培训时段与"双减"时段限制冲突、收费期与课时消耗不匹配、班级备案人数与实际报名人数超限（超班额）、
跨校区教师共用冲突、分校区 × 分学科汇总清单。

## 怎么用

```bash
node scripts/run.mjs --sample                 # 先看样例
node scripts/run.mjs --input 你的台账.json     # 跑自己的材料
```

入参就一张表：把 Excel 里的**表头 + 数据行**一起复制成文本粘进 `{"text": "…"}`（Tab 分隔最稳）。
表里可以有 `合计` 行（合计行只参与「合计行逐列复核」，不参与逐行检查）。
台账后面还可以跟一段 `--- 排课与收费记录 ---`（完整档用来做跨表核对）；免费版会跳过这一段，不会因此报错。

## 常见错法（每月核这张表最容易栽的 5 个坑）

1. **把「许可证到期日」抄成发证日期或上一次年检日期**。办学许可证与营业执照是两张不同的证、
   有效期也各不相同，很多台账只填一个日期就当成"证照齐全"。正确做法：两张证的到期日各占一列，
   都要与核对基准日比；超期的天数要能算出来（本工具直接给天数，不写"已过期"三个字了事）。
2. **只写教师姓名，不写教师资格证号与到期日**。这一项就永远核不了 —— 那属于**材料不足**，不是没问题。
   无证上岗、资格证过期、未备案排课在"双减"后都是直接处罚项，台账里必须能逐人点到证号与到期日。
3. **收款账户写实际收款渠道（个人微信、平台代收），监管账户那一列空着或抄备案回执**。
   两列字面不一致就是账外收费。**不要**为了让工具"过"而把监管账户那列改成实际收款账户 ——
   改台账不会让钱进监管账户，只会把问题藏起来。正确做法是把收款账户改回备案监管专户，已收的按规定划转。
4. **同一位教师因为换了班级或改过姓名，就在台账里登记成两行**。重复登记最坑：
   课时数与收费金额会被算两遍，合计行跟着错，某个班到底谁在上也说不清。同一节课只能有一行。
5. **合计行的"课时数"用公式算但把合并单元格算漏了，或者手填一个"差不多"的数**。
   合计行必须等于明细逐列加总：本工具会把声明值、实际值与差额一起报出来，
   先看有没有明细行被隐藏 / 筛选掉了，再看公式有没有漏行。

## 需要完整档时（可选）

本免费版是**完整可用的核心产出**，本版本**不包含**下面这些项：

- 培训时段与"双减"时段限制冲突（学科类不得在法定节假日 / 休息日 / 寒暑假窗口开展，按排课表逐条判）
- 收费期与课时消耗不匹配（一次收费超 3 个月或超 60 课时、消课数超过收费课时、收费课时与台账课时不符，跨表比对）
- 班级备案人数与实际报名人数超限（超班额；同一班级的班额口径不一致也点名）
- 跨校区教师共用冲突（同一教师同一时段在两个校区排课）
- 分校区 × 分学科的汇总清单（按问题数降序 + 每组一条可整改动作，落在 result.rollup）

同名工具的**完整档**是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别**就是上面这些，没有别的**。

## 边界（请务必知道）

本工具**不做**这些判断（引擎 `CHECKS_OUT_OF_SCOPE` 里逐条列了）：

- 不判定这家机构该不该办学、该办哪类许可、办学许可证与营业执照该不该换发 —— 那是教育行政部门与市场监管部门的认定权；
- 不判定教师资格证本身的真伪、教师是否具备相应学科的任教资格 —— 那是发证机关与教育局的认定权；
- 不判定"双减"口径下某个具体日期在当地算不算寒暑假 / 节假日、要不要调休 —— 以当地教育局公告与校历为准；
- 不判定收费金额本身是否合理、监管账户里的钱有没有被挪用 —— 本工具只核台账与排课 / 收费记录的字面一致性；
- 不读 .xlsx / .pdf 原件、核对过程不联网核验办学许可证 / 营业执照 / 教师资格证 / 监管账户的真伪。

**材料不足时不给结论**（连「未发现问题」也不输出），会明确列出缺什么 —— 宁可什么都不说，也不说错话。
