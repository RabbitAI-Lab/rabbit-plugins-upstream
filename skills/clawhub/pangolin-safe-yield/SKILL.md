## 核心投资哲学

### 防御式进攻铁律

| 原则 | 内容 |
|------|------|
| 大盘铁律 | 下跌通道不操作，仅横盘/上升通道操作 |
| 共振原则 | 进攻必须基本面+技术面+资金面三者共振 |
| 安全边际 | 绝不追高，PE/PB历史低位，必有止损位 |
| 能力圈 | TMT内做个股，TMT外仅做ETF |
| 仓位管理 | 防御3-6成 + 进攻0-4成 + 现金保留 |
| 容错机制 | 分散持仓，严格止损，破位必须走 |

### 价值派心法（第一性原理）

- **格雷厄姆（安全边际）**：40 美分买 1 美元。高位跌 10% 就走，破解断头杀。
- **巴菲特（四原则）**：①不亏钱/不追高/不加杠杆（单只25%）②护城河好公司③不频繁交易④长期持有10年。
- **段永平（2年一次决策）**：好公司好买点，长期持有。
- **芒格（留在牌桌）**：留在牌桌比一年10倍强。

### Serenity 瓶颈理论（进攻选股武器）

**紫苏叶理论**：市场都在盯金枪鱼大腹（英伟达/龙头），暴利藏在紫苏叶（上游冷门寡头）。缺了紫苏叶，整家店停摆。

**瓶颈三步法**：
1. **拆链**：从不可逆终端趋势逐层向下追问"下一层什么不可替代"，直到追到市值最小、名字最陌生的公司
2. **数人头**：全球供应商三家以上 PASS、两家盯住、一家垄断就是它
3. **用骂声验证**：出手前把分析公开出去等人反驳，堵上漏洞后由使用者自行决定是否行动

**碎片拼图法**：不看 PE/K线，看专利数据库、学术论文、GitHub趋势、海关数据——信息源跟别人不一样，判断才可能不一样。

## 全量风险面（个股研究必查红线）

> **定位**：风险面是五面共振里权重 15% 但**杀伤力最大**的一维。任何一项命中「一票否决（❌）」清单，直接判定回避，不再进入加权汇总；命中「降级（⚠️）」清单则强制降一档共振等级。本清单力求全方位覆盖，做个股研究时**逐条打钩**，宁可错过不可踩雷。

### 一票否决红线（命中任意一条 → ❌ 坚决回避）

- [ ] **财务造假 / 监管立案**：被证监会立案调查、财务洗澡（一次性大额计提）、存贷双高、审计非标意见（保留/否定）、频繁更换会计师事务所、监管函明确指向财务不实
- [ ] **超级天量出货**：单日换手率 > 20%，或成交量创历史天量（> 历史均量 3 倍），伴随高位滞涨 → 主力对倒/出货信号
- [ ] **大股东 / 实控人清仓式减持**：近 1 年内实控人、持股 5% 以上股东或高管大额减持且未披露合理用途，或质押比例 > 60% 触发平仓风险
- [ ] **被踢出核心供应链**：被果链（Apple）、T 链（Tesla）、SpaceX 链、华为链、英伟达链、比亚迪链等核心客户剔除、份额腰斩或认证失效 → 收入基本盘坍塌
- [ ] **被监管重罚 / 重大违法**：证监会/交易所行政处罚、市场禁入、环保/安监/税务重大处罚、涉嫌犯罪被移送司法
- [ ] **实控人私德与治理崩塌**：实控人桃色丑闻、离婚分割股权引发控制权动荡、被列为失信被执行人（限高）、失联、涉重大诉讼
- [ ] **退市风险**：已披星戴帽（*ST / ST）、股价持续低于 1 元面值、净资产为负、审计无法表示意见
- [ ] **重大商誉暴雷**：商誉占净资产 > 40% 且被并购方业绩对赌失败，存在一次性减值风险
- [ ] **可转债 / 信用违约**：债券违约、展期、评级下调至投机级以下

### 降级警示清单（命中任意一条 → ⚠️ 强制降一档）

- [ ] **大股东常规减持**：有减持计划或已小幅减持但未达清仓级，需评估减持动机与承接力度
- [ ] **毛利率极低且无改善**：制造业毛利率 < 10%（或同比下滑 > 5pct）、消费品 < 20%，且无定价权/成本改善逻辑 → 盈利质量差
- [ ] **十大股东恶化**：机构（公募/北向/社保）连续两季净减持、股东户数短期暴增（散户化）、持股比例高度分散
- [ ] **高比例质押**：大股东质押率 30%–60%，股价接近平仓线
- [ ] **解禁洪峰**：未来 3 个月内解禁股数占总股本 > 10%
- [ ] **问询函 / 监管关注**：交易所年报/重组问询函、澄清公告频发，但尚非立案
- [ ] **关联交易疑点**：大额关联交易、资金被关联方占用、其他应收款畸高
- [ ] **存货 / 应收畸高**：存货周转、应收周转显著恶化，存在跌价/坏账计提不足
- [ ] **业绩变脸**：预告盈利却最终亏损、或单季净利环比断崖式下滑
- [ ] **行业政策利空**：被纳入集采/限价/反垄断调查，或补贴退坡且无替代盈利点

| 命中情况 | 风险面评分 | 处置 |
|---------|-----------|------|
| 命中任一「一票否决」 | 0–20 | ❌ 坚决回避，无需再看其他面 |

### 风险面取证清单（每条红线对应怎么查）

| 红线类别 | 主要取证来源 | 交叉验证方式 | 存疑时处置 |
|---------|------------|------------|-----------|
| 财务造假 | 定期报告、审计意见、监管函件 | 经营现金流与净利润是否长期背离 | 按命中「一票否决」处理 |
| 超级天量 | 日线量价、换手率 | 对照历史均量与股价位置 | 缓 3 个交易日观察 |
| 减持与质押 | 减持公告、质押公告 | 公告披露的用途与实际动作是否一致 | 按「降级警示」处理 |
| 供应链出局 | 客户集中度披露、行业订单线索 | 上下游公开表态、替代供应商动向 | 直接降级，等待证据澄清 |
| 监管处罚 | 行政处罚决定、交易所纪律处分 | 是否涉及主营业务资质 | 按命中严重程度分级 |
| 治理与私德 | 公司公告、司法公开信息 | 是否影响控制权稳定性 | 涉及控制权即一票否决 |
| 退市风险 | 财务指标、审计意见类型 | 净资产与营收组合指标 | 一票否决 |
| 商誉与减值 | 商誉占净资产比重、对赌进度 | 被并购方业绩完成情况 | 超阈值即降级 |

**一票否决与降级的分界原则**：只要该事项**动摇收入基本盘或控制权稳定性**，按一票否决；只**削弱当期盈利质量但不改变长期竞争力**，按降级警示。

### 市场环境观察（截至 2026-09-15）

> 以下为**方法论层面的观察**，用于校准清单本身的适用性，不构成对任何标的或指数的判断；涉及具体数据请以官方与权威渠道最新发布为准。

1. **检查清单的价值在震荡市更明显**：单边行情中纪律容易被"错过感"冲淡，而清单的作用正是在这种时候拦人。
2. **风险面取证成本上升**：公开信息更碎片化，同一事件在不同来源的表述可能不一致；坚持"多源交叉 + 存疑降级"比追求结论更重要。
3. **供应链类红线的时效性要求提高**：客户结构与份额变化的公开披露往往滞后，需结合上下游公开线索提前判断。
4. **复盘口径要稳定**：如果打分标准每季度都在变，成功率统计就失去可比性；建议标准年度内保持不变，改动只在年度复盘时进行。

## 纪律清单（8条铁律）

1. **主力反向思维**：买在别人不要的低位，80%垃圾时间播种，20%主升浪收货。
2. **防御风险收益比是一**：本金安全，睡得稳。
3. **选股五面共振**：政治高度+行业预期+基本面+技术面+资金面。
4. **年度时机**：跨年1-2月 + 金九银十，避开3-4月、5穷6绝、8月底、10月底。
5. **总仓位控制**：绝对学会空仓休息，每年2次重仓，其他1-2成。
6. **买入**：追高是大敌，追涨10%会死人，买在别人不要时。
7. **持有**：达到目标即可，耐心资本，唯有低入才敢长拿。
8. **卖出**：做波段，不赚最后一子，严格10%止损。

## 使用流程

### 场景1：出手前检查（最常用）

**输入**："我想买/卖 XX" 或 "帮我看看 XX 能不能买"

**步骤**：
1. 先判断标的类型（ETF/个股），走对应路径
2. ETF → 5 关检查（跳过巴菲特选股），主要靠五面共振
3. 个股 → 6 关检查（含巴菲特/Serenity 选股分流），实操导向
4. 任一关不过，明确喊停
5. 全过 → 走六阶段五面共振深度分析 → 输出决策草案（非交易指令）
6. 由使用者记入其复盘记录

### 场景2：个股实操（选股+买卖）

**输入**：某只个股

**步骤**：
1. 判断类型：防御价值股（巴菲特）还是进攻成长股（Serenity）
2. 用对应选股逻辑深度分析
3. 给出买点/卖点判断与决策草案（建议仓位/参考买入区间/参考止损位/参考目标位，均非交易指令）
4. 由使用者记入其复盘记录，用于追踪成功率

### 场景3：复盘迭代

**输入**："帮我复盘本月成功率"

**步骤**：由使用者提供其复盘记录内容（本技能不自行读取文件），据此统计各维度命中率并给出体系迭代建议。

### 场景4：ETF 波段实操（主战场）

**输入**：某只 ETF 或"现在能不能加仓 XX"

**步骤**：
1. 走 ETF 路径 5 关（合规时机 → 五面共振 → 风险收益比 → 反向思维 → 贪念复检）

3. 给出买入价 / 止损价 / 目标价与本次仓位
4. 由使用者记入复盘记录，下次复评时标出哪一面发生了变化

**关键提醒**：ETF 自带分散，**跳过巴菲特选股**；但风险面红线排查同样适用（行业政策、成分股重大风险事件）。
