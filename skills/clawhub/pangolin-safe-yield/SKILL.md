## 核心投资哲学

### 防御式进攻铁律

| 原则 | 内容 | 违反时的典型后果 |
|------|------|---|
| 大盘铁律 | 下跌通道不操作，仅横盘/上升通道操作 | 下跌通道越跌越买，本金快速损耗 |
| 共振原则 | 进攻必须基本面+技术面+资金面三者共振 | 单面驱动追高，买在情绪高点 |
| 安全边际 | 绝不追高，PE/PB历史低位，必有止损位 | 高位无安全垫，一次回调即深套 |
| 能力圈 | TMT内做个股，TMT外仅做ETF | 超出能力圈的个股研究失真 |
| 仓位管理 | 防御3-6成 + 进攻0-4成 + 现金保留 | 无现金可加，被迫在最差时点卖出 |
| 容错机制 | 分散持仓，严格止损，破位必须走 | 单点风险暴露，一次黑天鹅出局 |

### 价值派心法（第一性原理）

- **格雷厄姆（安全边际）**：40 美分买 1 美元。高位跌 10% 就走，破解断头杀。
- **巴菲特（四原则）**：①不亏钱/不追高/不加杠杆（单只25%）②护城河好公司③不频繁交易④长期持有10年。
- **段永平（2年一次决策）**：好公司好买点，长期持有。
- **芒格（留在牌桌）**：留在牌桌比一年10倍强。

### Serenity 瓶颈理论（进攻选股武器）

**紫苏叶理论**：市场都在盯金枪鱼大腹（英伟达/龙头），暴利藏在紫苏叶（上游冷门寡头）。缺了紫苏叶，整家店停摆。

**瓶颈三步法**：
1. **拆链**：从不可逆终端趋势逐层向下追问"下一层什么不可替代"，直到追到市值最小、名字最陌生的公司
2. **数人头**：全球供应商三家以上 PASS、两家盯住、一家垄断就是它
3. **用骂声验证**：出手前把分析公开出去等人反驳，堵上漏洞后由使用者自行决定是否行动

**碎片拼图法**：不看 PE/K线，看专利数据库、学术论文、GitHub趋势、海关数据——信息源跟别人不一样，判断才可能不一样。

| ① 债务与货币周期 | 债务能否可持续、以什么方式出清？ | 债务/GDP、财政赤字率、利息支出/收入、长债拍卖投标倍数 | 像血管里慢慢沉积的血栓，以几十年为单位；出清方式=重组/违约/通胀，殊途同归 |
| ② 贫富差距与价值观分裂 | 财富集中是否越过临界点？ | 基尼系数、政治极化、对程序/制度的信任度 | 越过临界 → 分歧"不可调和" → 制度机制失灵，转向更直接的方式 |
| ③ 大国博弈与秩序更替 | 旧秩序是否瓦解、新秩序未立？ | 多边机制约束力、关键航道控制、储备币种构成 | 旧秩序瓦解到新秩序确立之间从无平稳过渡，只有力量博弈的动荡期 |
| ④ 自然冲击 | 旱灾/洪水/疫病是否打断其他力量？ | 疫病、极端气候、能源与粮食安全 | 独立变量，会加速或打断其他力量的节奏，当背景看必吃大亏 |
| ⑤ 人类创造力 | 唯一单向向上的力量是否仍主导？ | 技术进步、生产率、AI 实际落地率 | 长期向上不可逆；但 AI 造成的财富集中会反噬 ②（技术力量外溢为政治力量） |

**五大力量与六轮检索的分工**：五大力量是**顶层框架**（定方向、定阶段、定主导力量），六轮检索是**执行层数据**（验证与打分）。先用框架判断"现在是什么阶段、什么在主导"，再用数据给宏观面打分——两条都要做，缺一不可。

**当前坐标参考（达利欧 2026 判断，属观点而非事实）**：美国处"债务螺旋临界（债务/GDP>130%、利息支出/收入约 18%）+ 政治撕裂高位 + 秩序重组 + AI 泡沫三重共振"，主线收敛到"财政 × 利率"。**中美周期不同步**——做跨境判断须分别定位，不可用同一相位套两个市场。

#### 泡沫测量仪（估值温度计）

> 达利欧"泡沫测量仪"回答的不是"拐点何时来"，而是"我们现在在哪里"——这正是宏观面需要的"估值温度"。

- **读数口径**：当前市场估值在 1900 年以来历史坐标的分位。达利欧 2026 年最新读数约为 1929 大崩盘与 2000 互联网泡沫水平的 **75%**；1990 年日本泡沫破裂前，读数爬得比两者更高，之后日股约 20 年才收复失地。
- **用法**：读数越高 → 宏观面"安全边际"分越低 → 越要收紧仓位、强化下行保护。达利欧原话："以这个估值水平长期持有，大概率不会有好结果。"
- **刺破泡沫的典型触发**：货币政策收紧（利率上行 → 持现金比持资产划算 → "变现需求"激增 → 出清开始）＞ 财富税等突然冲击。

#### 下行保护优先（达利欧圣杯 × Pangolin 铁律）

> 达利欧："先把下行保护做扎实，才有资格去追求上行空间。"

- 这是 Pangolin「防御式进攻 · 安全边际第一」在宏观层面的同源表达——**先保证不亏大钱，再谈赚多少**。
- 落地到操作：宏观面任何一项越线（尤其债务不可持续、估值温度过高），即便其他四面满分，也强制降档或空仓——这就是 Pangolin 的「宏观面一票否决」。
- 配套仓位纪律（同源）：先构建一个不依赖任何预测、足够分散不相关的**战略组合**，再据此做适度**战术调整**；不要等"最好时机"才入场，也不要因高位就全部换成现金坐等崩盘。

**六轮检索**：
1. 美国货币政策（权重25%）：Fed决策、点阵图、FedWatch、美债收益率、实际利率、缩表、信用利差、金融条件、SOFR
2. 中国货币政策（权重25%）：MLF/LPR/降准、OMO、10Y国债、信用利差、社融M2、DR007、信贷脉冲
3. 汇率与跨境资本（权重15%）：美元指数、人民币汇率、北向资金、南向资金、外汇储备
4. 中美经济周期（权重20%）：PMI/CPI/GDP，中美周期差（中国复苏+美国软着陆=最强）
5. 行业景气盈利（权重10%）：A股/美股盈利增速、库存周期
6. 全球风险事件（权重10%）：美伊局势（三情景：协议40%/僵持40%/升级20%）、中美、俄乌、台海、黑天鹅

**大盘信号灯**：
```
IF 美伊全面升级(海峡封锁/交火)    → 🔴 强制避险
IF 宏观总分 ≥ 75 AND 大盘非下跌    → 🟢 绿灯（可全面进攻）
IF 宏观总分 ≥ 60 AND 大盘横盘      → 🟡 黄灯（谨慎，防御为主）

IF 油价 > 100美元 持续超一周        → 🟠 强制降一级
IF 泡沫测量仪读数 ≥ 历史高分位(达利欧口径≥75%阈值) → 🟠 强制降一级（估值无安全边际）
```



**信号灯读数示例（示意）**

```text
情形：宏观总分 74.75，大盘横盘，泡沫测量仪读数处于历史偏高区间
判定：
  宏观 < 75 → 不满足绿灯
  大盘非下跌且宏观 ≥ 60 → 🟡 黄灯（防御为主）

```

## 全量风险面（个股研究必查红线）

> **定位**：风险面是五面共振里权重 15% 但**杀伤力最大**的一维。任何一项命中「一票否决（❌）」清单，直接判定回避，不再进入加权汇总；命中「降级（⚠️）」清单则强制降一档共振等级。本清单力求全方位覆盖，做个股研究时**逐条打钩**，宁可错过不可踩雷。

### 一票否决红线（命中任意一条 → ❌ 坚决回避）


**红线判定示例（示意）**

| 事项 | 判断 | 依据 |
|-----|------|------|
| 交易所发出年报问询函，未涉及立案 | 降级警示 | 尚未动摇收入基本盘 |
| 实控人离婚导致股权分割，控制权存在不确定性 | 一票否决 | 动摇控制权稳定性 |
| 单一客户份额腰斩，但该客户仅占收入 8% | 降级警示 | 削弱当期盈利，未坍塌基本盘 |
| 核心客户认证失效且该客户占收入 45% | 一票否决 | 收入基本盘坍塌 |

- [ ] **财务造假 / 监管立案**：被证监会立案调查、财务洗澡（一次性大额计提）、存贷双高、审计非标意见（保留/否定）、频繁更换会计师事务所、监管函明确指向财务不实
- [ ] **超级天量出货**：单日换手率 > 20%，或成交量创历史天量（> 历史均量 3 倍），伴随高位滞涨 → 主力对倒/出货信号
- [ ] **大股东 / 实控人清仓式减持**：近 1 年内实控人、持股 5% 以上股东或高管大额减持且未披露合理用途，或质押比例 > 60% 触发平仓风险
- [ ] **被踢出核心供应链**：被果链（Apple）、T 链（Tesla）、SpaceX 链、华为链、英伟达链、比亚迪链等核心客户剔除、份额腰斩或认证失效 → 收入基本盘坍塌
- [ ] **被监管重罚 / 重大违法**：证监会/交易所行政处罚、市场禁入、环保/安监/税务重大处罚、涉嫌犯罪被移送司法
- [ ] **实控人私德与治理崩塌**：实控人桃色丑闻、离婚分割股权引发控制权动荡、被列为失信被执行人（限高）、失联、涉重大诉讼
- [ ] **退市风险**：已披星戴帽（*ST / ST）、股价持续低于 1 元面值、净资产为负、审计无法表示意见
- [ ] **重大商誉暴雷**：商誉占净资产 > 40% 且被并购方业绩对赌失败，存在一次性减值风险
- [ ] **可转债 / 信用违约**：债券违约、展期、评级下调至投机级以下

### 降级警示清单（命中任意一条 → ⚠️ 强制降一档）

- [ ] **大股东常规减持**：有减持计划或已小幅减持但未达清仓级，需评估减持动机与承接力度
- [ ] **毛利率极低且无改善**：制造业毛利率 < 10%（或同比下滑 > 5pct）、消费品 < 20%，且无定价权/成本改善逻辑 → 盈利质量差
- [ ] **十大股东恶化**：机构（公募/北向/社保）连续两季净减持、股东户数短期暴增（散户化）、持股比例高度分散
- [ ] **高比例质押**：大股东质押率 30%–60%，股价接近平仓线
- [ ] **解禁洪峰**：未来 3 个月内解禁股数占总股本 > 10%
- [ ] **问询函 / 监管关注**：交易所年报/重组问询函、澄清公告频发，但尚非立案
- [ ] **关联交易疑点**：大额关联交易、资金被关联方占用、其他应收款畸高
- [ ] **存货 / 应收畸高**：存货周转、应收周转显著恶化，存在跌价/坏账计提不足
- [ ] **业绩变脸**：预告盈利却最终亏损、或单季净利环比断崖式下滑
- [ ] **行业政策利空**：被纳入集采/限价/反垄断调查，或补贴退坡且无替代盈利点

### 常见误判与纠偏

| 误判 | 表现 | 纠偏动作 |
|-----|------|---------|
| 把"跌得多"当"便宜" | 只看跌幅不看估值分位与基本面 | 回看 PE/PB 历史分位与盈利趋势 |
| 把"政策提过"当"政策支持" | 引用模糊表述当作依据 | 找到明确的支持性文件或资金安排 |
| 技术面单独定买卖 | 只看图形不看资金与基本面 | 至少三面共振才动手 |
| 风险面"应该没事" | 不做取证，凭印象判断 | 按取证清单逐条查，存疑即降级 |
| 追高后倒推理由 | 先买后找逻辑 | 买点必须来自清单，不能事后补 |
| 复盘只记结论 | 不记当时的评分与理由 | 按建议字段完整记录 |
| 用宏观判断替代个股研究 | 大盘好就认为标的没问题 | 宏观只定仓位节奏，个股仍需五面各自打分 |
| 把「存疑」写成「无」 | 取证没做就默认干净 | 逐条标注有/无/存疑，存疑按降级处理 |
| 只看单次评分不看变化 | 复评时不对比上次的面 | 复评必须标出哪一面变了、为什么 |

> 以下为**方法论层面的观察**，用于校准清单本身的适用性，不构成对任何标的或指数的判断；涉及具体数据请以官方与权威渠道最新发布为准。

1. **检查清单的价值在震荡市更明显**：单边行情中纪律容易被"错过感"冲淡，而清单的作用正是在这种时候拦人。
2. **风险面取证成本上升**：公开信息更碎片化，同一事件在不同来源的表述可能不一致；坚持"多源交叉 + 存疑降级"比追求结论更重要。
3. **供应链类红线的时效性要求提高**：客户结构与份额变化的公开披露往往滞后，需结合上下游公开线索提前判断。
4. **复盘口径要稳定**：如果打分标准每季度都在变，成功率统计就失去可比性；建议标准年度内保持不变，改动只在年度复盘时进行。

5. **估值温度应作为仓位节奏的先行变量**：泡沫测量仪一类读数偏高时，正确的动作是降低节奏与提高防御比重，而不是寻找「这次不一样」的理由。
6. **供应链类信息需双源以上**：客户结构与份额变化披露滞后，单一来源的「被踢出/被导入」消息应按存疑处理，等到定期报告或双方公开表态印证后再调整评级。

## 纪律清单（8条铁律）

1. **主力反向思维**：买在别人不要的低位，80%垃圾时间播种，20%主升浪收货。
2. **防御风险收益比是一**：本金安全，睡得稳。
3. **选股五面共振**：政治高度+行业预期+基本面+技术面+资金面。
4. **年度时机**：跨年1-2月 + 金九银十，避开3-4月、5穷6绝、8月底、10月底。
5. **总仓位控制**：绝对学会空仓休息，每年2次重仓，其他1-2成。
6. **买入**：追高是大敌，追涨10%会死人，买在别人不要时。
7. **持有**：达到目标即可，耐心资本，唯有低入才敢长拿。
8. **卖出**：做波段，不赚最后一子，严格10%止损。



**铁律 → 常见违反情形 → 纠偏**

| 铁律 | 常见违反情形 | 纠偏动作 |
|-----|------------|---------|
| 主力反向思维 | 看到连续上涨才想买 | 回到二买定义：回踩不破 + 缩量 + 筹码密集 |
| 风险收益比是一 | 只看上涨空间 | 先写下止损位，再算下跌空间，不满足 1:2 不出手 |
| 五面共振 | 技术面单独定买卖 | 至少三面共振才动手 |
| 年度时机 | 在回避窗口加大动作 | 回到年度窗口表，非窗口期只做观察 |
| 总仓位控制 | 连续出手导致满仓 | 每月出手次数上限与现金比例双约束 |
| 买入不追高 | 涨幅超 50% 仍在加 | 按涨幅分档硬约束回落 |
| 持有耐心 | 刚回本就卖 | 以目标位与逻辑是否证伪为准，不以浮盈浮亏为准 |
| 卖出纪律 | 破位不舍得走 | 止损位事先写下并承诺执行 |

## 使用流程

### 场景1：出手前检查（最常用）

**输入**："我想买/卖 XX" 或 "帮我看看 XX 能不能买"

**步骤**：

3. 个股 → 6 关检查（含巴菲特/Serenity 选股分流），实操导向
4. 任一关不过，明确喊停
5. 全过 → 走六阶段五面共振深度分析 → 输出决策草案（非交易指令）
6. 由使用者记入其复盘记录

### 场景2：个股实操（选股+买卖）

**输入**：某只个股

**步骤**：

3. 给出买点/卖点判断与决策草案（建议仓位/参考买入区间/参考止损位/参考目标位，均非交易指令）

**输入**："帮我复盘本月成功率"

### 场景4：ETF 波段实操（主战场）

## 注意事项

1. **宏观面一票否决**：大盘下跌通道，任何标的都不买

4. **止损必设**：破位必须走

9. **复评必须对比上次**：同一标的再次分析时，先标出哪一面发生变化及原因，再给新的共振等级。
