## Description:

Discuss Before Begin guides an agent to challenge plans, clarify requirements, expose conflicts, and wait for explicit consensus before implementation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[blueriverlhr](https://clawhub.ai/user/blueriverlhr)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, planners, and product teams use this skill to pressure-test ideas, requirements, refactors, proposals, articles, or startup concepts before committing to implementation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may cause the skill to take over general planning requests.

Mitigation: Install it only where pre-implementation critique is desired, and review trigger fit before deployment.

Risk: The skill intentionally delays implementation until explicit consensus is confirmed.

Mitigation: Set user expectations for a discussion-first workflow and require explicit consensus before implementation handoff.
