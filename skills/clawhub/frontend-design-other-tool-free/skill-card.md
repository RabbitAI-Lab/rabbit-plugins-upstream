## Description: <br>
Frontend Design Tool helps individual developers generate color, typography, layout, and signature-element design tokens for distinctive frontend pages, with anti-template checks and baseline quality guidance. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[thcjp](https://clawhub.ai/user/thcjp) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
External developers and independent designers use this skill to turn a product positioning brief into frontend design tokens, HTML/CSS direction, and checks for responsive, accessible, low-motion single-page or component designs. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger language plus read, exec, and write authority could lead the agent to modify frontend files or run local commands outside the intended UI design task. <br>
Mitigation: Use only for explicit UI/design tasks, specify target files and command limits, and review proposed commands and file changes before execution. <br>
