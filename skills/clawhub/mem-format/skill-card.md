## Use Case:

Developers and engineers use this skill to reformat memory-bank Markdown files so they conform to established templates while preserving existing task, session, and registry content.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Running the workflow across all memory-bank files or a whole category can modify important hand-written notes.

Mitigation: Confirm the target files first, start with one or two files for important memory banks, and review or keep the generated backups.
