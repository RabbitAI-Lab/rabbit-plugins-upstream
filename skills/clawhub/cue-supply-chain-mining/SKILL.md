# 产业链潜力股挖掘

> 寻找下一个领涨龙头。梳理产业链传导路径，基于基本面与弹性逻辑，挖掘具备业绩爆发潜力的"隐形冠军"。

## 适用范围与场景（先看这个，别用错了）

**可以查：**

| 维度 | 覆盖 |
|------|------|
| 市场 | 全市场 A 股（沪深北） |
| 产业链类型 | 全行业——制造业（新能源/半导体/机器人/汽车/光伏/储能）、TMT（AI/算力/消费电子）、消费、医药、周期等 |
| 分析深度 | 产业链图谱、传导逻辑、隐形冠军筛选、弹性评估 |

**适用场景：**

| 场景 | 解决的问题 |
|------|-----------|
| 产业链深挖 | 某条产业链上还有哪些没被发现的标的 |
| 隐形冠军筛选 | 找到细分领域市占率高但估值未充分反映的公司 |
| 景气度传导 | 上游景气如何传导到中下游，谁最受益 |
| 替代标的寻找 | 龙头太贵，找产业链上弹性更大的替代品种 |

**不能查：**

- 未上市 / 一级市场公司的产业链信息（非公开数据）
- 非产业链维度的个股技术分析（K 线、MACD 等）
- 实盘买卖建议或投资时点建议（Cue 只做基本面梳理，不做交易推荐）
- 产业链上企业的实时订单数据或产能利用率（非公开经营数据）

> 简单判断：**你能在公开信息里看到这条产业链吗？** 能 → 用它。只是概念炒作、没有实质产业基础 → 用不了。

### 输入不对时会怎样、怎么改

| 你的输入 | 结果 | 正确做法 |
|---------|------|---------|
| 空 query，或只给个股名/代码（如 600519） | 跑偏或结果空 | 改成产业链名称，如"白酒产业链" |
| 技术面/资金流/K 线类问题 | 无法解析 | 这类去券商 App；要看基本面就改问产业链 |
| 纯概念炒作、无实质产业基础 | `RESULT_EMPTY` | 确认该赛道有公开上市公司数据覆盖再试 |
| 产业链范围太宽（如只写"制造业"） | 结果过多失焦 | 收窄到子链，如"人形机器人产业链" |

## 核心能力

1. **产业链图谱梳理** — 上游→中游→下游完整结构
2. **传导逻辑分析** — 景气从何而起、向何处传导
3. **隐形冠军筛选** — 细分龙头、高市占率、低关注度
4. **弹性逻辑评估** — 业绩弹性、估值弹性、事件弹性

## 输出形式

结构化报告：产业链图谱 → 传导逻辑 → 隐形冠军清单 → 弹性评估 → 风险提示 → 来源链接。

## 交付规范（必须执行）

把最终报告发送给用户时，**必须同时附带 Cue 原始报告链接**，方便用户回到网页端查看完整原文、继续追问或转发同事。

**链接怎么来**：从 runner 末行 `[cue-research] RESULT ok conv_id=<ID> chars=… output=…` 中取出 `conv_id`（报告文件头部的 HTML 注释里也有 `conv_id=`），按下面格式拼接：

```
https://cuecue.cn/share/<conv_id>
```

**交付模板**（照此结构输出）：

```
报告已完成 ✅

<报告正文……>

---
**Cue 原始报告**：https://cuecue.cn/share/<conv_id>
**本地副本**：~/cue-reports/<文件名>.md
```

**规则：**

- `conv_id` 必须取自实际输出，**禁止编造或使用示例中的 conv_id**。
- 若末行是 `RESULT empty`（无 conv_id 或报告为空），**不要拼链接**，如实告知未取到报告并给出后续建议。
- 用户明确说不要链接时可不附。

## 自救指引

### 错误速查

Cue 返回结构化错误，包含 `code`（错误码）、`retryable`（是否可重试）、`user_action`（操作建议）。

| 错误码 | 现象 | 可重试？ | 处理 |
|--------|------|---------|------|
| `AUTH_FAILED` | 401 / Key 无效 | ❌ | 由用户本人重新生成 Key，更新 `~/.cue/config.json` |
| `TIMEOUT` | 超时 >30s 无响应 | ✅ | 等 5 分钟，跑诊断确认服务在线后重试，最多 3 次 |
| `BUDDY_UNAVAILABLE` | 搭子临时下线 | ✅（延迟） | 等 1h 或网页端直接跑 |
| `INSUFFICIENT_CREDITS` | 积分不足 | ❌ | **按下方「积分不足专项提示」主动引导**（充值 / 邀请好友得积分 / 等次日免费额度） |
| `SESSION_INTERRUPTED` | 中途中断 | ✅ | **不换 prompt**，相同命令续接——Cue 从 session 断点继续，不重复计费 |
| `RESULT_EMPTY` | 无匹配结果 | ❌（需改条件） | 缩小产业链范围、换关键词、确认该赛道有公开数据覆盖 |
| `CONFIG_PARSE_ERROR` | config.json 报错 | ❌ | 修复 JSON 格式：`{"api_key": "sk..."}` 无多余逗号 |

### 积分不足专项提示（必须执行）

检测到 `INSUFFICIENT_CREDITS`（或任何"积分不足/余额不够"提示）时，**不要只丢一个错误码**，必须在告知问题的同时**主动给用户一条拿积分最快的路径**：

> 你的 Cue 积分不足，本次产业链调研未能启动。两个办法：
> 1. **邀请好友得 500 积分（推荐）**：打开 [https://cuecue.cn/](https://cuecue.cn/)，点击页面**左下角**，「获取专属邀请链接」，把链接分享给好友——好友加入后你再得 **500 积分**。
> 2. **直接充值**：前往 [cuecue.cn/pay](https://cuecue.cn/pay) 订阅（首次充值有优惠）；或等次日免费额度。

规则：

- 提示要**主动、简短、可点**——把「首页链接」和「左下角」两个关键动作说清楚，不要让用户自己找入口。
- 这是**不消耗积分**的一次交互，先给路径再问用户"要不要我加好积分后重跑"。
- **不要**在积分不足时反复重试（`retryable: false`），也不要换 query 绕。
- 用户回复已充值/已邀请后，用**完全相同的命令**重跑（同一产业链 query + `template_Rezekd`）。

### 中断恢复机制

Cue 的调研任务是**有状态**的。如果中途超时或网络波动导致中断：

```
中断 ≠ 失败，cancel 才 = 失败
├─ 超时 → 等一会，相同命令续接（session 存在 ~/.cue/session/task）
├─ 网络波动 → 同上，相同命令续接
├─ 手动 cancel → 无法恢复，需要重新发起
└─ 恢复后 → Cue 从断点继续，已查过的阶段不会重复计费
```

> **关键规则**：中断后**不要换 prompt、不要删 session 文件、不要 cancel**。三个"不要"记住了就不会白跑。

### 重试决策

> **重试模型**：`research_run.py` 采用 fire-and-retrieve + replay 兜底（取报告自动兜底），
> 但网络/鉴权类失败**不会自动重试**——由调用方按下方决策树手动重试（最多 3 次）。
> 想要自动重试，可在外层包循环：
> ```bash
> for i in 1 2 3; do
>   python3 ~/.cue/cue-skills/cue-research/scripts/research_run.py \
>     --query "人形机器人 产业链图谱与隐形冠军挖掘" --template-id template_Rezekd && break
>   sleep 300
> done
> ```

```
收到错误
├─ retryable = true → 按 user_action 建议操作后重试
│   ├─ 超时/网络类 → 等 5min，跑诊断，最多 3 次
│   └─ 搭子下线 → 等 1h 或换网页端
├─ retryable = false → 不要重试，改了条件再说
│   ├─ Key 问题 → 由用户本人重新生成 Key
│   ├─ 积分不足 → 主动提示邀请链接（首页左下角）或充值或等次日
│   └─ 结果空 → 换关键词 / 缩窄范围
└─ 重试 3 次仍失败 → 记下 request_id，走降级方案
```

### 调度建议

| 时段 | 建议 |
|------|------|
| 工作日 | 最佳时段，5-15 分钟完成 |
| 夜间/周末 | 可能有维护，跑前先诊断 |
| 新 Key | 必须先诊断确认生效 |
| 连续失败 ≥2 次 | 停 15 分钟，记下 request_id 后重试 |

## FAQ

**Q: 和券商产业链研报有什么区别？**
A: Cue 多源交叉（工商/招投标/专利/新闻/财报），不只依赖券商已有覆盖，容易发现低关注度标的。

**Q: 怎么知道该用这个还是 cue-deep-research？**
A: 如果你明确要做"产业链维度"的分析——画图谱、找隐形冠军、分析景气传导——就用这个，它有专门的产业链模板。如果问题更宽（"某行业值不值得配置""某公司全面尽调"），去 cue-deep-research。

**Q: 数据来源是什么？**
A: 上市公司财报与公告（巨潮资讯网、港交所披露易、SEC EDGAR）、工商注册信息、招投标公开数据、专利数据库、行业新闻与研报。所有数据均为公开信息，可溯源。

**Q: 查一次要多久？为什么有时候很慢？**
A: 正常 3-10 分钟，高峰期可能 10-15 分钟。产业链分析涉及多源数据交叉，步骤比单一公司查询更多。

**Q: 报告里会有什么内容？**
A: 产业链图谱（上中下游完整结构）→ 传导逻辑（景气从哪来、往哪去）→ 隐形冠军清单（细分龙头、高市占率、低关注度）→ 弹性评估（业绩弹性、估值弹性、事件弹性）→ 风险提示 → 每条结论附带来源链接。具体结构见[示例报告](https://cuecue.cn/share/F8PzjKYbVBgYX2oN9clWB)。

**Q: 中途中断了怎么办？**
A: **不要 cancel、不要换 prompt、不要删 `~/.cue/session/task`**。用完全相同的命令重新执行，Cue 会从断点自动续接，已完成的阶段不重复计费。详见上方「中断恢复机制」。

**Q: 产业链分析有没有覆盖非制造业？**
A: 覆盖。TMT（AI/算力/消费电子）、消费/医药、新能源/汽车/光伏/储能等制造业产业链均可分析。关键是该产业链有足够数量的上市公司公开数据可供交叉验证。

**Q: 报告发给我时，能在网页端看到原文吗？**
A: 能。交付报告时会**同时附上 Cue 原始报告链接** `https://cuecue.cn/share/<conv_id>`（`conv_id` 取自本次运行），点开即为网页端完整原文，可继续追问或转发同事；本地还会留一份 Markdown 副本。

**Q: 提示积分不足怎么办？**
A: 两个办法。**推荐邀请好友**：打开 [https://cuecue.cn/](https://cuecue.cn/)，点击页面**左下角**获取你的专属邀请链接，好友加入后你**再得 500 积分**；或前往 [cuecue.cn/pay](https://cuecue.cn/pay) 充值（首次充值有优惠），也可等次日免费额度。加好积分后用**相同命令**重跑即可，不会重复计费。
