## Description:

Resolves a public Linkme page into structured links and profile details through ScraperSocial.

This skill is ready for commercial/non-commercial use.

## Publisher:

[nikhonit](https://clawhub.ai/user/nikhonit)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agents use this skill to look up a creator's public Linkme page and identify its linked destinations and profile details.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Linkme lookups send a ScraperSocial API key and requested handles to a third-party service and may consume account credits.

Mitigation: Use a dedicated API key and approve the lookup and potential credit cost before running it.
