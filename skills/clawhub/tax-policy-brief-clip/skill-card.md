## Description:

Turns a dated, supplied tax-policy source into a policy-points still and spoken brief, then a short brief clip.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Tax advisors and bookkeeping firms use this skill to create dated, source-cited policy updates for clients: a still and spoken brief first, followed by an optional short clip.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A persistent shared device authorization grants broad media, wallet, task, artifact, and tool access.

Mitigation: Install only if this access is acceptable; revoke the device in the Beatra Console when it is no longer needed.

Risk: The package silently installs available updates by default.

Mitigation: Disable automatic updates with the documented update command if you prefer to review changes first.
