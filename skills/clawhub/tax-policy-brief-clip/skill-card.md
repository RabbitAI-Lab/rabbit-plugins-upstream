## Description:

Turns an advisor-supplied, dated tax-policy source into a policy-points still and speakable brief, then optionally a short clip.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Bookkeeping firms and tax advisors use this skill to turn supplied, dated tax-policy points into a client-ready still and spoken brief, with an optional short video clip.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A shared Beatra device token provides broad account access across installed Beatra skills.

Mitigation: Install only if comfortable with shared access; consider a dedicated account or limited balance.

Risk: Automatic updates are enabled by default and can install new code without separate confirmation.

Mitigation: Review the update behavior before installation and disable automatic updates using the documented command if undesired.
