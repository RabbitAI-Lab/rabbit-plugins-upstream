## Description:

Search public Rumble videos and channels, inspect video details and comments, and retrieve available captions for creator research and summaries without a Rumble account or API key.

This skill is ready for commercial/non-commercial use.

## Use Case:

Creators, researchers, and other users can explore public Rumble videos, review channel uploads and comments, and summarize videos with available captions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Using the skill requires installing a third-party plugin and pairing with ClawLink.

Mitigation: Install and pair only if comfortable connecting to ClawLink; verify the plugin before use.

Risk: Each data call can spend ClawLink credit, including calls for videos without captions.

Mitigation: Check current per-call prices and ask before bulk research or expensive calls.
