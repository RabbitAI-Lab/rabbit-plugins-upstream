## Description:

Turn a book's key ideas into publication-style visual reading notes, with HTML, PDF, PPTX, and long-image export options.

This skill is ready for commercial/non-commercial use.

## Use Case:

Readers and creators use the skill to organize supplied book material into concise, chart-led reading notes and exportable visual documents.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Some helper workflows weaken browser security or may overwrite or delete files.

Mitigation: Review steps before running them; use a disposable project folder and isolated renderer, and preserve existing PBM files and delivery outputs.

Risk: A YAML pipeline's --dry-run may not reveal its effects, and external engines or downloaded dependencies are outside this inspection.

Mitigation: Review YAML changes manually before execution and inspect external dependencies; use local image analysis for confidential material.
