# 通用问题标签树 v1.0

用于对客服会话中的客户问题/需求归类。一通会话可命中多个标签。用户所在行业有特殊分类时，可定制企业专属标签树（见 SKILL.md 文末）。

## 一级标签与释义

| 标签 | 涵盖内容 |
|---|---|
| 售前咨询 | 商品参数、功能、适用性、库存、是否有货 |
| 价格与优惠 | 价格咨询、优惠券、活动规则、比价、能否更便宜 |
| 下单与支付 | 下单流程、支付失败、优惠叠加、改地址改单 |
| 物流与配送 | 发货时效、物流进度、未收到、配送损坏、配送费 |
| 商品质量 | 质量问题、与描述不符、瑕疵、假货质疑 |
| 售后与退换 | 退货、换货、退款、维修、售后政策 |
| 使用与操作 | 怎么用、安装、故障排查、教程 |
| 发票与账务 | 开票、报销、账单、发票类型 |
| 服务态度 | 对客服态度的评价（正面或负面） |
| 功能与需求建议 | 客户主动提出的改进建议、期望功能 |
| 其他 | 无法归入以上的 |

## 情绪判定

- **正面**：满意、表扬、感谢、复购意愿
- **中性**：普通咨询、事务性沟通，无明显情绪
- **负面**：不满、投诉、抱怨、威胁差评/退款、情绪激烈

## 流失/风险信号（独立于问题标签，单独识别）

- 比价后未表达购买意愿 / 明确说"再看看"
- 明确表达不满、扬言差评或投诉
- 提及竞品（"别家""某某平台更便宜"）
- 犹豫放弃（多次咨询未下单、加购未付）
- 重复催促同一问题未解决（潜在流失高危）

## 归类纪律

- 一通会话可含多个问题标签，按实际命中全部记，占比口径在报告中说明（按"提及该标签的会话数 / 总会话数"）。
- 情绪按整通会话的主基调判定；一通会话内前后情绪变化大的，以结束时的情绪为主并可备注。
- 拿不准的归类标注"倾向性判断"，不强行定性。
