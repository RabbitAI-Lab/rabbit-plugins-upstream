# 客户声音(VOC)会话分析 (voc-conversation)

丢一批客服会话进来，帮你看清**客户整体在关心什么、不满什么、想要什么**——输出高频问题榜、情绪分布、真实原声、流失信号和改进建议。质检看"客服做得怎么样"，VOC 看"客户在说什么"，同一份会话数据，另一个视角。

## 它能做什么

- 输入：一批客服会话导出文件（Excel/CSV/文本，逐条式或整段式，企业微信/千牛/美洽等系统均可）
- 输出：一份面向决策层的 VOC 洞察报告——一页结论、问题分布、情绪分布、高频问题 Top 榜（带真实原声）、流失风险信号、改进建议
- 内置通用问题标签体系，自动归类

## 设计定位

- **洞察向**：给结论和行动方向，不是逐条流水账，读者是运营/产品/客服负责人
- **有依据**：每个结论都附占比或真实原声支撑
- **单次快照**：分析你这一批数据，给一份当下的客户声音全景
- 数据本地处理、原声引用自动脱敏、结论供决策参考

## 进阶能力（定制）

免费版做"单次、通用标签"的洞察报告。如果你需要——

- **企业专属标签体系**：按你的业务定制问题分类，归类更准
- **按月趋势追踪**：Top 问题环比、情绪趋势曲线
- **多渠道自动汇聚**：对接客服/评价/工单系统自动拉取
- **深度下钻归因**：从"物流负面 30%"追到具体是哪些会话、哪个时段/区域导致
