# 电影级长剧类型规范

当视频类型标签为 `【电影级长剧】` 时加载此规范。

## 适用场景
电影级叙事长剧、4K院线标准剧集、末世/科幻/动作大制作、IP改编长剧、高规格定制剧集

> 与短剧区别：短剧追求快节奏高密度爽点（9:16竖屏），长剧追求戏剧张力与情绪留白（16:9院线横屏）

## 核心技术参数

| 参数 | 规格 | 说明 |
|------|------|------|
| **画幅** | 16:9 横屏 | 院线标准，固定不可更改 |
| **分辨率** | 4K（3840×2160） | 超高清，非降级 |
| **色彩深度** | 10-bit 或以上 | 零色阶断层，暗部细节丰富 |
| **编码** | ProRes 422 HQ（MOV 母带） + H.265（MP4 预览） | 双格式交付 |
| **音频** | 全景声 / 多维立体声 | 音轨分离交付（混音轨/对白轨/音乐轨/音效轨） |
| **纯度** | 纯净画面，无水印标记 | 去除所有 AI 生成工具的原生水印 |

## 视频生成建议

### 生成策略
- **不建议使用当前 720p 流水线**：现有 agnes-ai-video / 小云雀 的免费视频生成能力（720p 级别）无法满足 4K 输出需求
- **两条技术路径**：
  1. **高质量图生图 → 图生视频**：先用高质量图片模型生成 4K 级首帧图 + 关键帧，再使用支持 4K 输出的视频生成工具
  2. **超分辨率后处理**：标准分辨率生成后，使用 Real-ESRGAN / Topaz Video AI 等工具放大到 4K
- **分批分段策略**：长剧建议按场景/篇章分批生成，每批 3-5 个镜头，确保单批质量可控

### 交付检查
- [ ] 无 AI 水印
- [ ] 16:9 4K 分辨率
- [ ] HDR/PQ 或 10-bit 色彩
- [ ] 音轨分离（4轨：混音/对白/音乐/音效）

## 质量标准（电影工业级）

### S级 — 角色精密度（零容忍指标）
| 要求 | 说明 | 检查方法 |
|------|------|---------|
| **肤质真实** | 具有电影级皮肤纹理（毛孔、微血管、汗毛、真实光泽） | 4K 大特写下逐帧检查 |
| **动态眼神光** | 眼神光自然，随视角变化 | 连续镜头验证一致性 |
| **微表情自然** | 面部肌肉运动真实，不僵硬 | 逐镜观察皱眉/抿唇/眼周变化 |
| **零畸变** | 严禁多指/少指/断肢/反关节/六齿/牙齿黏连 | 每镜逐帧检查 |
| **全景别一致性** | 远景到特写下容貌特征、身材比例严格一致 | 跨镜对比五官/瞳色/肤色 |
| **三维透视稳定** | 多角色同框时物理距离、方位、阴影保持稳定 | 动态运镜中验证 |
| **服化道延续性** | 服装材质、发丝形态、妆容细节无缝顺接 | 相邻镜头对比纽扣/纹理/发丝 |

### A级 — 场景与空间稳定性
| 要求 | 说明 | 检查方法 |
|------|------|---------|
| **背景零闪烁** | 角色移动时后景无AI闪烁/扭曲/机械变异 | 动态镜头逐帧验证 |
| **机位变换稳定** | 不同机位下场景陈设位置固定，不变形/消失 | 正反打镜头对比背景 |
| **自然物理逻辑** | 天气、光影变化符合物理世界时间轴 | 检查雨滴/树叶/光线一致性 |

### AA级 — 道具与交互真实感
| 要求 | 说明 | 检查方法 |
|------|------|---------|
| **材质真实** | 金属/玻璃/木质反光折射符合物理规律 | 大特写下检查反光 |
| **状态接戏** | 道具状态变化后（喝一半的水等）在所有机位精准顺接 | 跨镜对比道具状态 |
| **手部交互** | 角色接触道具时严丝合缝，无漂浮/穿模 | 逐帧检查接触点 |

### AAA级 — 视听工业标准
| 要求 | 说明 | 检查方法 |
|------|------|---------|
| **30度规则** | 相邻同主体镜头机位角度变化 > 30度 | 运镜设计检查 |
| **景别跳级** | 相邻镜头景别至少差两级（不得全景→稍近全景） | 分镜表预检 |
| **轴线原则** | 对话/对峙机位保持在关系轴线同一侧 | 运镜设计检查 |
| **视线匹配** | 正反打视线方向完美匹配 | 镜头对比检查 |
| **长镜头流畅** | 推拉摇移运镜稳定，Rack Focus 自然 | 逐帧检查运动模糊和焦点 |
| **固定光效** | 主光源位置固定，三点式光影随走位实时匹配 | 跨镜对比光影位置 |

## 长剧节奏指南

与短剧的高频紧凑不同，长剧注重"戏剧张力与情绪留白"：

| 阶段 | 节奏特征 | 时长占比 | 情绪任务 |
|------|---------|---------|---------|
| **建置**（铺垫） | 舒缓，长镜头建立世界观 | 15-20% | 制造悬疑，建立人物关系 |
| **发展**（冲突酝酿） | 中速，对话推动 | 25-30% | 情绪积累，矛盾升级 |
| **转折**（事件触发） | 加快，短镜头交替 | 10-15% | 打破平衡，推动变化 |
| **高潮**（情绪爆发） | 最紧凑，特写密集+复杂运镜 | 15-20% | 冲突顶点，情绪释放 |
| **余韵**（收尾） | 舒缓，镜头拉远/定格 | 10-15% | 留白思考，情感沉淀 |

**关键差异对比例表**：

| 要素 | 短剧 | 长剧（本规范） |
|------|------|---------------|
| 开场钩子时间 | 前3秒必须出 | 前5-10秒建置氛围再出 |
| 对话节奏 | 高速对白，信息密集 | 有停顿和呼吸，情绪递进 |
| 情绪空间 | 不给留白时间 | 允许沉默镜头和情绪沉淀 |
| 高潮处理 | 快速释放爽点 | 延长高潮，用运镜和配乐积累 |
| 结尾 | 钩子指向下一集 | 情绪收束或有深意的余味 |

## 镜头规范

### 景别策略
| 阶段 | 主导景别 | 目的 |
|------|---------|------|
| 建置 | 远景、全景 | 建立世界观、空间关系 |
| 发展 | 中景、近景 | 对话叙事、情绪递进 |
| 转折 | 中景、特写 | 放大关键瞬间 |
| 高潮 | 近景、大特写 | 情绪爆发、冲击力 |
| 余韵 | 全景、远景 | 拉开距离、余味留白 |

### 运镜指导
电影级长剧鼓励展现AI对复杂镜头语言的驾驭能力：

| 运镜类型 | 适用场景 | 稳定性要求 |
|---------|---------|-----------|
| **推镜头**（Dolly In） | 情绪聚焦、关键揭示 | 缓慢匀速，无抖动 |
| **拉镜头**（Pull Back） | 展现场景格局、离别升华 | 匀速平滑 |
| **摇镜头**（Pan） | 场景建立、环境揭示 | 匀速，不可卡顿 |
| **移镜头**（Track） | 跟拍移动、行走对话 | 与主体同步 |
| **环绕**（Orbit/Arc） | 仪式感、对峙、情绪高潮 | 圆心稳定，不可漂移 |
| **Rack Focus** | 焦点虚实转换，引导注意力 | 顺滑自然，不可突变 |
| **固定镜头** | 对话正反打、静态情绪 | 画面稳定，无呼吸感抖动 |

### 30度规则与景别跳级

**强制性要求（不可违反）**：

1. 相邻两个同主体镜头，机位角度变化必须 > 30度
2. 相邻两个镜头，景别必须至少差两级
   - ✅ 正确：全景 → 特写（差3级）
   - ✅ 正确：中景 → 大特写（差2级）
   - ❌ 错误：全景 → 稍近的全景（差不到1级）
3. 对话正反打必须保持在 180度轴线 同一侧
4. 视线方向必须匹配（A看右→B看左）

### 组件分类

| 组类型 | 镜头数 | 景别序列 | 作用 |
|--------|--------|---------|------|
| **场景建立组** | 2-3 | 远景→全景→中景 | 长剧允许更慢的建立节奏，可用长镜头徐徐展开 |
| **对话互动组** | 2-4 | 过肩（A）→近景（A）→过肩（B）→近景（B） | 正反打 + 情绪话话特写 |
| **动作序列组** | 3-5 | 特写（触发）→中景（行动）→全景（结果）→特写（反应） | 动作闭环，可插入慢镜头 |
| **情绪递进组** | 2-3 | 中景→近景→大特写 | 从观察到感受，允许更长停留 |
| **悬念/余韵组** | 2-3 | 中景→全景→远景（拉远） | 拉开距离，情感沉淀 |

## 声音设计规范

长剧的声音设计标准远高于短剧：

### 音频轨分离
| 音轨 | 内容 | 交付格式 |
|------|------|---------|
| **混音轨**（Full Mix） | 所有声音的最终混音 | WAV 48kHz 24-bit |
| **对白轨**（Dialogue） | 纯对白+旁白，无背景音 | WAV 48kHz 24-bit |
| **音乐轨**（Music） | 纯配乐，无对白无音效 | WAV 48kHz 24-bit |
| **音效轨**（SFX） | 纯环境音+拟音，无其他 | WAV 48kHz 24-bit |

### 听觉层次
| 层次 | 内容 | 作用 |
|------|------|------|
| **环境底噪**（Ambience） | 场景环境音（风声/虫鸣/城市底噪） | 建立空间感，打底 |
| **Foley 拟音** | 脚步声/衣物摩擦/器具碰撞 | 增强真实感 |
| **对白** | 角色台词/旁白 | 叙事核心 |
| **配乐** | 电影级OST配乐 | 推动情绪，叙事陪衬 |
