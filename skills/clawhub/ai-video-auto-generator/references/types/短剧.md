# 短剧类型规范

当视频类型标签为 `【短剧】` 时加载此规范。

## 适用场景
故事类短视频、情感剧情、微电影、网文改编、漫剧、商单短剧

## 短剧分类与制作要点

| 分类 | 视觉特征 | 制作难点 | 适用工具 |
|------|---------|---------|---------|
| **AI仿真人** | 写实风格，真人质感，注重面部细节和光影真实 | 人物一致性、表情自然、手部细节 | ImageGen/SD真人模型 |
| **AI漫剧** | 漫画/插画风格，线条感强，色彩鲜明 | 风格统一、分镜漫画感、动态表现 | ImageGen/SD动漫模型 |

**选择原则**：根据目标受众和题材选择分类。女频甜宠适合仿真人，男频玄幻可考虑漫剧。

## 通用设置
- **默认画幅**: 9:16竖屏（抖音/快手/视频号等短视频平台，除非甲方另有要求）
- **默认分辨率**: 720×1280（9:16 竖屏标准）
- **画幅指定规则**: 飞书文档中写「横屏」「16:9」「大屏规格」→ 用 16:9；写「竖屏」「9:16」「抖音规格」→ 用 9:16；未指定 → 按默认
- **叙事驱动**: 以角色对白为主，旁白为辅；旁白仅限于开场建置和结尾升华
- **声画关系**: 声音提前画面0.5秒嵌入（音频先入），增强连贯性

## 1. 人物设定框架（必备）

### 1.1 人物设定维度表

| 维度 | 分类 | 说明 |
|------|------|------|
| **冲突立场** | 正面、反面、穿线人、反英雄 | 每部剧必须有明确的立场对立 |
| **结构戏份** | 男主、女主、男配、女配、龙套 | 明确角色主次关系 |
| **功能层面** | 推动型、衬托型、视角型 | 角色在叙事中的功能 |
| **纬度层面** | 单一性格、复杂性格 | 角色是否需要成长弧光 |
| **弧光层面** | 静态（始终如一）、动态（变化） | 角色是否在故事中成长改变 |
| **关系层面** | 亲情、爱情、友情 | 角色之间的情感纽带 |

### 1.2 九型人格参考（角色塑造）

| 类型 | 特点 | 角色示例 |
|------|------|---------|
| 1完美型 | 理性自律，追求完美，是非分明 | 包公、董明珠 |
| 2助人型 | 乐于付出，渴望被需要，共情力强 | 雷锋 |
| 3成就型 | 目标感强，渴望成功，注重形象 | 撒贝宁、武则天 |
| 4自我型 | 感性独特，追求真实，富有创造力 | 林黛玉、王菲 |
| 5理智型 | 理性思考，渴求知识，善于观察 | 柯南、秦明 |
| 6疑惑型 | 谨慎负责，寻求安全，忠诚可靠 | 曹操 |
| 7活跃型 | 乐观开朗，追求新鲜，多才多艺 | 黄蓉、华晨宇 |
| 8领袖型 | 果断强势，保护他人，挑战权威 | 李云龙 |
| 9和平型 | 随和包容，避免冲突，善于调和 | 武大郎 |

### 1.3 人物描述模板

**欧美成熟风格（商单标准）：**
```
写实超高清8K，电影级人像光影，全身拍摄，欧美白人/韩系审美，[性别/年龄]，骨相[特征]，眼神[特征]，身材[特征]，身着[服装详细描述]，真实皮肤纹理，面部细节精致，全身构图，[风格关键词]
```

**古风/女频风格（漫剧标准）：**
```
写实8K超高清，电影柔光人像，全身拍摄，[时代/风格]人物，[性别]，[外貌特征]，[服装详细描述]，[发饰描述]，[气质描述]，保持[统一特征词汇]
```

- **戏份**: 男主/女主/男配
- **性格类型**: 多血质/胆汁质/粘液质/抑郁质
- **九型人格**: X型

## 2. 分镜描述格式（sd2.0 公式）

### 2.1 基础公式
```
（@主体+表情+动作+@场景+镜头+风格+细节时间+限制）+ 复合片段
```

### 2.2 动作描述规范

每个分镜中的动作必须包含：

| 要素 | 说明 | 示例 |
|------|------|------|
| **主体状态** | @主体+表情+动作 | @女主眼冒红心，兴奋地蹦跳 |
| **时间控制** | （时间控制）标记动作时长 | 害羞低头（时间控制） |
| **动作连贯性** | 动作之间的因果关系 | 先_，然后_，最后_ |
| **细节补充** | 括号补充动作风格 | （细节补充：_） |
| **禁止词** | 避免低质量描述 | （注意：禁止出现扭曲、混乱、动态模糊） |

### 2.3 分镜完整格式

每个分镜必须包含以下三要素：

```
画面 X：[动作描述] [对白/台词] [运镜/景别]
```

**示例（来自课程案例）：**
```
画面 1：女主提裙在街上兴奋奔跑，仆人在远处追赶。女主开心兴奋的说："今天谁也别想抓我回去！" 摄像机从女主前方跟拍，中景。

画面 2：女主继续奔跑，笑容灿烂，仆人在后方焦急追。仆人焦急的说："小姐！您慢点！" 摄像机从侧面拍摄女主，近景。

画面 3：女主回头调皮一笑，没有看前方。仆人一边追赶一边急忙大喊："小姐！看前面！" 摄像机从女主正面偏侧拍摄，近景，捕捉调皮表情。

画面 4：前方男主逆光出现，女主来不及停下。摄像机从女主后方拍摄，中景。

画面 5：女主撞进男主怀里，男主稳稳扶住她。女主先是低头懵住，眉头轻皱。 女主边抬头边气愤的说："谁啊，走路不看——" 摄像机从侧面拍摄两人，全景。

画面 6：女主先微恼，抬头看清男主后瞬间愣住。 男主低声温柔："姑娘，可有伤到？" 摄像机从女主正前方拍摄，近景。

画面 7：男主清冷俊美特写，轮廓光极强。女主结巴的说："没、没有……" 摄像机从男主正前方拍摄，近景，强调颜值冲击。

画面 8：女主脸红害羞，满脸花痴，偷偷看男主。 仆人小声提醒："小姐……您没事吧？" 摄像机从侧后方拍摄女主，近景。

画面 9：仆人追到远处，女主后退半步又偷看男主，男主淡淡笑。女主礼貌的说："我……我不是故意撞你的。" 男主台词，淡淡一笑："我知道。" 摄像机从正前方拍摄两人，中景，甜宠收尾。
```

## 3. 镜头等级质量体系（L1-L4）

每个分镜必须按以下等级评估：

| 等级 | 定位 | 必查要点 | 优先级 |
|------|------|---------|--------|
| **L1 核心叙事** | 剧情骨架 | 主角/动作/道具清晰；转折有镜头；逻辑连贯；人物场景不崩坏 | **必须100%** |
| **L2 情绪支撑** | 血肉感染力 | 情绪有特写；转场自然；节奏匹配剧情；市场适配；无无效镜头 | **≥80%** |
| **L3 氛围质感** | 氛围加分 | 首尾/高潮有氛围；色调统一；细节清晰 | 可选 |
| **L4 风格美学** | 调性门面 | 运镜顺滑服务剧情；风格统一；不炫技不抢情绪 | 慎加 |

**实战建议**：新手期先把 L1-L2 做扎实，L3-L4 后期再优化。

## 4. 组镜头与连续性（核心要求）

### 4.1 组镜头规则

短剧的每个情节段落必须用 **组镜头（Shot Group）** 表达。每组镜头至少包含 **2-3个镜头**，形成完整的叙事链。

```
【错误】一个场景只有一个镜头 → 画面单调，缺乏节奏
【正确】一个场景用2-3个镜头组表达 → 建立→聚焦→反应
```

### 4.2 组镜头类型

| 组类型 | 镜头数 | 景别序列 | 作用 |
|--------|--------|---------|------|
| **场景建立组** | 2-3 | 远景→中景→近景 | 交代环境→引入角色→聚焦细节 |
| **对话互动组** | 2-3 | 全景（双人）→中景（A说）→近景（B反应） | 正反打覆盖对话，确保看不到全貌的留白感 |
| **动作序列组** | 3-4 | 特写（触发）→中景（行动）→全景（结果）→远景（格局） | 一个完整的动作闭环 |
| **情绪递进组** | 2-3 | 中景→近景→特写 | 从观察到感受，层层推进 |
| **悬念收尾组** | 2-3 | 中景→全景→远景（拉远） | 拉开距离制造余韵 |

### 4.3 连续性铁律

1. **景别交替**：同一组内相邻两个镜头**禁止使用相同景别**
2. **视线匹配**：对话组中，说话者和反应者的视线方向必须匹配
3. **动作连贯**：跨镜头的动作应在下一镜头的起始位置延续（动作衔接剪辑）
4. **色调统一**：同一组内色调必须一致（可在组间变化）
5. **音画先行**：下一个镜头的音效/对白提前0.5秒嵌入当前镜头尾部

### 4.4 组间衔接

- 相邻两组之间用**叠化**或**声音先入**过渡
- 每组开头的第一个镜头用**稍宽的景别**重新确立空间关系
- 每组结尾留0.5秒"气口"再切到下一组

## 5. 情节设计原则

### 5.1 观众距离金字塔（情绪节奏框架）

观众的沉浸感按以下层级递进，剧本设计必须逐层推进：

```
        ▲ 爽点（情绪爆发/满足/反转）
       ╱ ╲
      ╱ 共鸣 ╲（与角色共情，代入情感）
     ╱─────────╲
    ╱   代入    ╲（进入角色视角，关心命运）
   ╱───────────────╲
  ╱     悬念        ╲（产生好奇心，想知道后续）
 ╱─────────────────────╲
```

**应用规则**：
- 开场必须制造**悬念**（问题/冲突/反常）
- 前1/3让观众**代入**角色处境
- 中1/3建立**共鸣**，让观众与角色共情
- 高潮和结尾提供**爽点**（反转/满足/释放）

### 5.2 三幕式结构

> 三幕式的完整占比、功能、核心任务 → **详见 `references/pacing-narrative.md#叙事结构指南`**

| 幕 | 占比 | 功能 |
|---|------|------|
| **第一幕：建置** | ~25% | 建立世界、引入角色、制造悬念 |
| **第二幕：对抗** | ~50% | 冲突升级、角色挣扎、情绪积累 |
| **第三幕：解决** | ~25% | 高潮爆发、反转揭晓、余韵留白 |

### 5.3 悬念推进机制

> 悬念推进的完整五步法 → **详见 `references/pacing-narrative.md#悬念推进机制`**

悬念不是一次性抛出，而是**层层递进**：

1. **设悬** → 2. **布疑** → 3. **加深** → 4. **揭晓** → 5. **余波**

### 5.4 情节 vs 故事
- **故事**：按时间顺序（然后…然后…）
- **情节**：按因果逻辑（因为…所以…）

### 5.5 情节构成
| 维度 | 定义 |
|------|------|
| 构成元素 | 由一系列事件（动作）组成 |
| 组织逻辑 | 事件之间有因果关系，而非时间顺序 |
| 推动力量 | 人物的欲望、冲突、行动 |
| 最终效果 | 引发观众情感反应和思考 |

### 5.6 开场钩子规则
- 开场前3秒必须有"钩子"：冲突爆发、反常事件、高能对话
- 不能用空镜头或环境描写开场

## 6. 拍摄规范与运镜语言

### 6.1 景别策略
| 阶段 | 主导景别 | L1要求 | L2要求 |
|-----|---------|--------|--------|
| 建置 | 全景、中景 | 角色清晰可见 | 背景不崩坏 |
| 冲突 | 中景、近景 | 表情可见 | 情绪传递到位 |
| 高潮 | 特写、近景 | 动作完整 | 情感爆发点有冲击力 |
| 解决 | 中景、远景 | 逻辑闭环 | 留有回味 |

### 6.2 运镜类型参考

> 运镜的完整类型表（推/拉/摇/移/环绕/俯拍/仰拍/固定）+ 效果说明 → **详见 `references/shot-scales.md#运镜类型参考`**

短剧推荐运镜组合：对话场景用固定/正反打，情感爆发用推镜头，悬疑时刻用侧面/低角度，反转桥段用俯拍。

### 6.3 角度建议
- 对话场景：正反打（过肩镜头）
- 情感爆发：正面近景
- 悬疑时刻：侧面/低角度
- 反转桥段：俯拍/高角度

### 6.4 灯光氛围
- 甜宠剧：暖白轮廓光+浅金背光，让人物发丝/肩线/衣袖/脸部边缘明显发亮
- 虐恋剧：冷调为主，明暗对比强
- 悬疑剧：侧光/顶光，制造阴影
- 动作剧：动态光影，冲突烈

## 7. 节奏控制曲线

> 短剧的情绪节奏应遵循标准曲线。情绪曲线可视化 + 阶段时长指南 + 应用规则 → **详见 `references/pacing-narrative.md#节奏控制曲线`**

短剧节奏摘要：

| 阶段 | 镜头节奏 | 情绪任务 | 时长占比 |
|------|---------|---------|---------|
| **铺垫** | 舒缓，稍长镜头 | 建立世界，制造悬念 | 15-20% |
| **转折** | 加快，短镜头交替 | 引入冲突，推动变化 | 10-15% |
| **高潮** | 最紧凑，特写密集 | 情绪爆发，爽点释放 | 20-25% |
| **留钩子** | 突然放缓/定格 | 制造好奇，引导续看 | 5-10% |
| **收尾** | 舒缓收尾 | 情绪缓冲，余韵留白 | 5-10% |

## 8. 剪辑包装规范

> 完整规范（字幕参数表/转场类型及时长/片头片尾参数）→ **详见 `references/editing-specs.md`**

### 8.1 字幕规范（简要）
- 对白字幕：底部居中，不遮挡人物表情
- 情绪字幕（如"三年后"）：可用艺术字，配合转场
- 字幕停留时间 ≥ 朗读时间 + 0.5秒

### 8.2 音效与转场（简要）
- **硬切**：标准叙事过渡，占90%以上
- **叠化**：时间跳转或情绪过渡
- **闪白**：强烈情绪冲击或回忆
- **黑场**：悬念停顿，留给观众思考

### 8.3 片头片尾（简要）
- 片头：3秒内出现核心冲突或钩子，不铺陈
- 片尾：留钩子或情绪余韵，引导续看/互动

### 8.4 成片自查
- 画面是否连贯，无跳帧或闪烁
- 音频是否清晰，对白与背景音乐平衡
- 色调是否统一（同一场景）
- 是否有"出戏"镜头（崩坏/不一致）

## 9. 避坑原则

> 避坑原则完整版 → **详见 `references/pacing-narrative.md#避坑原则`**（或主 SKILL.md §1.1）

短剧创作特别警惕：
- 短剧节奏更快，信息过载风险更高
- 多角色同框场景一致性更难保证
- 高潮爽点的情绪铺垫不能跳过

## 10. 总字数控制与分镜规划

| 时长 | 分镜数 | 总台词量 | 说明 |
|------|--------|---------|------|
| 15秒 | 3个画面 | 30-50字 | 适合抖音女频/男频切片 |
| 30秒 | 6个画面 | 80-120字 | 标准短剧单集长度 |
| 60秒 | 12个画面 | 150-250字 | 叙事完整的微剧 |

## 11. 质量自查清单

生成脚本后，逐项检查：

### 结构层
- [ ] L1：每个分镜的主角/动作/道具是否清晰
- [ ] L1：关键转折点是否有对应的镜头
- [ ] L1：情节是否有因果逻辑（不是时间顺序）
- [ ] L1：角色外观是否在所有分镜中保持一致
- [ ] 是否遵循三幕式结构（建置/对抗/解决）
- [ ] 悬念推进是否层层递进（设悬→布疑→加深→揭晓→余波）

### 情绪层
- [ ] L2：情绪关键点是否有近景/特写
- [ ] L2：转场是否自然，节奏是否匹配剧情
- [ ] L2：是否有无效镜头（可删除不影响理解）
- [ ] 是否遵循观众距离金字塔（悬念→代入→共鸣→爽点）
- [ ] 高潮是否有足够的情绪爆发力

### 视听层
- [ ] L3：首尾/高潮是否有氛围感
- [ ] L3：色调是否统一
- [ ] L4：如果用了特殊运镜，是否服务于剧情
- [ ] 开场前3秒是否有钩子
- [ ] 每个分镜是否包含：动作 + 对白 + 运镜/景别

### 组镜头与连续性
- [ ] **组镜头**：每组至少2-3个镜头
