# 剪辑与包装规范

本文件提供字幕、转场、片头片尾的完整规范，由主 SKILL §8 抽取而来。

---

## 字幕规范

| 参数 | 默认值 | 说明 |
|------|--------|------|
| **字体大小** | 36px（9:16竖屏）/ 28px（16:9横屏） | 对白主体，保证可读性 |
| **情绪/标题字号** | 48px | 情绪字幕（如"三年后""三日后"） |
| **底部留白** | 距底部 60px | 不遮挡人物面部或关键视觉区域 |
| **字体** | 思源黑体 / Noto Sans SC（粗体） | 中文字体，清晰无衬线 |
| **字体颜色** | 白色 #FFFFFF | 带 0.3 透明度黑色描边保证在任何背景可读 |
| **停留时间** | 朗读时间 + 0.5秒（缓冲） | 确保读完不抢切 |
| **行数限制** | ≤ 2行（9:16竖屏）；≤ 3行（16:9横屏） | 避免画面被字幕遮挡过多 |
| **最长单行** | ≤ 18字（9:16竖屏）；≤ 30字（16:9横屏） | 保证单行阅读舒适度 |

- **对白字幕**：底部居中，不得遮挡面部表情
- **情绪字幕**（如"三年后"）：可用艺术字，配合转场
- **字幕入场动画**：淡入（默认 0.2s）→ 停留 → 淡出（默认 0.2s）

## 音效与转场

| 转场 | 默认时长 | 用法 | 适用场景 |
|------|---------|------|---------|
| **硬切** | 0s | 标准叙事过渡 | 90%以上的转场 |
| **叠化** | 0.3s（叙事）/ 0.5s（情绪过渡） | 时间跳转或情绪过渡 | 场景变换、记忆/闪回 |
| **闪白** | 0.15s（闪回）/ 0.3s（强烈冲击） | 强烈情绪冲击或记忆 | 惊讶、顿悟、回忆切入 |
| **黑场** | 0.5-1.0s | 悬念停顿 | 留给观众思考的空间 |

**音画先行规则**：下一个镜头的音效/对白应提前 0.5s 进入当前镜头的尾部。

**转场混合建议：**

| 场景类型 | 推荐转场 | 备注 |
|----------|---------|------|
| 同场景同组间 | 硬切（0s） | 保持连续性 |
| 场景切换 | 叠化（0.3s） | 让观众感知空间变化 |
| 时间跳转 | 叠化（0.5s） | 较长的叠化暗示时间流逝 |
| 记忆/梦境切入 | 闪白（0.15s） | 快速鲜明地切换语境 |
| 悬念/高潮后 | 黑场（0.5s） | 给观众呼吸空间 |

## 片头/片尾

| 参数 | 默认值 | 说明 |
|------|--------|------|
| **钩子出现时间** | 前 3s 内 | 片头必须在此时间内出现核心冲突/反差/高能对白 |
| **片头标题停留** | 1.5s | 标题字幕或LOGO动画的展示时间 |
| **片头缓冲** | 0.3s（淡入） | 视频起始从黑场淡入到第一帧 |
| **片尾停留** | 2.0s | 最后镜头结束后停留画面，叠加片尾字幕 |
| **片尾缓冲** | 0.5s（淡出） | 画面淡出到黑场 |
| **片尾钩子** | "关注/续看引导" 2.0s | 引导语或预告画面的停留时间 |

- **片头**：3秒内出现核心冲突或钩子，不铺陈。建议用硬切入画或淡入+音效甩入
- **片尾**：埋下钩子或情绪余韵，引导续看/互动。建议用叠化+尾声音乐淡出
