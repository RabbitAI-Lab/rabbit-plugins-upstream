# 节奏控制与叙事结构参考

本文件提供节奏曲线和叙事结构的完整参考，由主 SKILL §7.8-§7.9 抽取而来。

---

## 节奏控制曲线

所有叙事类视频应遵循情绪节奏曲线。平淡、单调的节奏是常见的质量陷阱。

**情绪曲线模板：**
```
情绪强度
   ▲
高 │      ╱╲  高潮/释放
   │     ╱  ╲
中 │────╱    ╲────  转折/冲突
   │   ╱      ╲
低 │──╱        ╲──  建置/解决
   └──────────────────▶ 时间
      建置  冲突  高潮  收尾
```

**阶段时长指南：**

| 阶段 | 镜头节奏 | 情绪任务 | 时长占比 |
|------|---------|---------|---------|
| **建置/铺垫** | 舒缓，稍长镜头 | 建立世界，制造好奇/悬念 | 15-20% |
| **转折/冲突** | 加快，短镜头交替 | 引入冲突，推动变化 | 10-15% |
| **高潮** | 最紧凑，特写密集 | 情绪爆发，爽点/释放 | 20-25% |
| **钩子** | 突然放缓/定格 | 制造好奇，引导续看 | 5-10% |
| **收尾** | 舒缓收尾 | 情绪缓冲，余韵留白 | 5-10% |

**应用曲线：**
- 在 `script.json` 中，规划镜头时长以匹配曲线（不是所有5秒都相等）
- 用 `"is_climax": true` 标记高情绪镜头
- 在情绪峰值后插入0.5秒填充（`"padding_after": 0.5`）
- 对于多组脚本，每组应有自己的迷你曲线

## 叙事结构指南

不同视频类型使用不同的叙事结构。一般原则是**因果逻辑**（因为→所以）而不是**时间顺序**（然后→然后）。

### 三幕式结构（适用于大多数叙事视频）

| 幕 | 占比 | 功能 | 核心任务 |
|---|------|------|---------|
| **第一幕：建置** | ~25% | 建立世界、引入角色、埋下钩子 | 让观众"想知道" |
| **第二幕：对抗** | ~50% | 升级冲突、角色挣扎、情绪积累 | 让观众"感同身受" |
| **第三幕：解决** | ~25% | 高潮、反转、余韵 | 让观众"意犹未尽" |

### 四幕式结构（适用于文旅/纪录片）

| 幕 | 功能 | 节奏 |
|----|------|------|
| **开篇** | 引人入胜的建立，激发兴趣 | 舒缓 |
| **展开** | 深入展示，旁白叙事驱动 | 中速 |
| **体验** | 沉浸式展示，视听高潮 | 紧凑 |
| **升华** | 情感升华，留有余韵 | 舒缓 |

### 观众距离金字塔（情绪节奏框架）

观众的沉浸感按以下层级递进：
```
        ▲ 爽点（情绪爆发/满足/反转）
       ╱ ╲
      ╱ 共鸣 ╲（与角色共情，代入情感）
     ╱─────────╲
    ╱   代入    ╲（进入角色视角，关心命运）
   ╱───────────────╲
  ╱     悬念        ╲（产生好奇心，想知道后续）
 ╱─────────────────────╲
```

**应用规则**：
- 开场必须制造**悬念**（问题/冲突/反常）
- 前1/3让观众**代入**角色处境
- 中1/3建立**共鸣**，让观众与角色共情
- 高潮和结尾提供**爽点**（反转/满足/释放）

### 悬念推进机制

悬念应层层递进，而不是一次性抛出：

1. **设悬** — 提出问题或展示反常（"她为什么哭？"）
2. **布疑** — 给出线索但引向歧途（"看起来是他伤害了她"）
3. **加深** — 增加压力或时间限制（"她发现真相后必须在两者之间抉择"）
4. **揭晓** — 反转或真相揭示（"原来一切都是为保护她"）
5. **余波** — 释放后的情绪缓冲（0.5-1秒填充）

## 避坑原则（通用）

| 坑 | 说明 | 避免方法 |
|---|------|---------|
| **工具人陷阱** | 只执行技术生成，不做审美判断 | 每个镜头问：这服务于什么情绪？ |
| **信息过载** | 一个镜头塞入太多信息 | 一个镜头只传达一个核心信息 |
| **节奏平铺** | 从头到尾一个速度 | 必须有快-慢-快的节奏变化 |
| **景别单一** | 全是中景或全是特写 | 强制使用景别交替 |
| **忽略留白** | 镜头之间没有气口 | 情绪高点后留0.5-1秒缓冲 |
| **为了炫技** | 运镜花哨但干扰叙事 | 运镜必须服务于剧情，不抢戏 |
