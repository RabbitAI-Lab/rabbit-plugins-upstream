#### 5.4.2 角色资产生成（强制）

> 📌 本节较长（~200 行），覆盖 8 类必须资产的完整生成策略（标准共 11 个文件，见 §5.4.2 资产类别表）。
> 新手建议先读概要（策略一~五），熟悉后按需查阅具体资产类型。

对于视频中出现的每个角色：

**⚠️ 角色/兵种一致性核心规则（Critical）**

图片生成工具（agnes-ai）每次调用完全独立，**模型不认识任何自定义名字**。如果提示词里只写名字（如 `墨雪` / `墨将` / `明军` / `蛮兵`），每次生成都会随机出不同的人或装束。

**规则：所有图片提示词中，涉及角色的名字必须替换为 `character_cards[].base_prompt_cn` 中的完整外观描述；涉及兵种的名字必须替换为 `troop_cards[].base_prompt_cn` 中的完整装束描述。**

> ⚠️ **完整描述包括三项**：`base_prompt_cn`（外观）+ `color_scheme`（配色）+ `style_keywords`（风格词），三者缺一不可。仅用 `base_prompt_cn` 会导致铠甲颜色/纹理在不同镜头间漂移。

反例（只写名字，模型不认识）：
```
"明军与蛮兵激战，明军士兵接连倒地"
```

正例（嵌入外观描述，模型有参照）：
```
"明军士兵身着制式铁甲外罩暗红战袍持长枪腰刀制式头盔，蛮兵身着兽皮皮甲骨甲部分上身裸露可见战纹纹身持弯刀狼牙棒，两军激战刀剑交错"
```

> `generation.reference_images` 字段标明该镜头引用了哪些卡，生成 prompt 时应从中提取对应描述注入。

**五个关键优化策略，必须全部执行：**

---

**策略一：关闭提示词自动改写（agnes-ai 无此参数，提示词原样发送）** ⭐

agnes-ai 的图片模型不会自动改写提示词，无需特殊设置。

```yaml
# agnes-ai 调用（首选）— 不需要 revise 参数
tool: agnes-ai
params:
  prompt: "国风古典美人，鹅蛋脸型，丹凤眼冷冽锐利，剑眉英气，樱唇微抿，墨黑长发束成高马尾..."
  output_name: "墨雪_front.png"
  output_dir: "$HOME/WorkBuddy/锈甲天凤/images/characters"
```

---

**策略二：提示词结构化分层（核心锚定优先）**

所有角色资产的提示词必须以 `character_cards.appearance` 的完整描述作为前缀，但按**资产类型**调整核心锚定的内容，避免过度联想：

| 资产类型 | 🔴 核心锚定（必须） | 🟡 可选补充 | Framing 限制词 |
|---------|-------------------|-----------|---------------|
| **全身照** (front/3quarter/side/back) | 发型 + 完整铠甲/服装 + 脸型 | 气场+纹样+披风 | `full body from head to toe including boots` |
| **面部特写** (face) | **发型 + 脸型/眉目 only**（**去掉铠甲**） | 眼神+表情 | `face only, tight face crop, no body, no armor visible, only face from forehead to chin` |
| **头部多角度** (head_angles) | 发型 + 脸型（铠甲边缘隐约可见即可） | 眼神 | `head and neck only, shoulders barely visible` |
| **五官特写** (face_details) | **发型 + 脸型 only**（**去掉铠甲**），用方案F生成4张独立部位特写+脚本拼接（详见第6条） | 皮肤质感+五官细节 | `face detail close-up, [specific feature] area only, no armor visible, no clothing` |
| **表情研究** (expressions) | 发型 + 脸型（铠甲边缘隐约可见） | 多种表情 | `face and upper shoulders, headshot framing` |
| **手脚姿态** (hands_feet_gestures) | 完整铠甲/服装 + 体型 | 武器/配饰 | `hand and foot poses, body partial visible` |
| **参考板** (reference) | 完整全部 | 全部 | 无（全身到特写都有） |
| **配饰道具** (props) | 标志性纹样 + 武器特征 | 材质光照 | `props isolated on neutral background` |

> 以上 8 个类别覆盖 **11 个文件**（标准基数）：全身照类别产出 4 个文件（front/side/back/3quarter），其余类别各产出 1 个文件。含动态持械/动作视图时，每个角色产出的文件数会更多。详见 §5.4.5 资产库目录结构。

⚠️ **关键原则**：
- 全身照/参考板：**不能省略铠甲**，否则模型可能脑补不同服装
- **面部特写/五官特写：必须去掉铠甲描述**，否则混元会将"女武将"身份与"全身铠甲"强关联，导致脸周围出现肩甲胸甲
- 面部特写保留**发型+脸型**已足够锚定身份，发型比铠甲更具辨识度
- **审美风格由项目决定**：读取 `script.json` 的 `aesthetic_style` 字段——`"eastern"` 选中文古典审美词汇，`"western"` 选英文词汇。**不可写死某一种审美，由 target_audience 决定**

提示词结构模板：
```
# 全身照
[🔴核心锚定：发型+完整铠甲+脸型], [🟡重要：气场+纹样], [🟢增强：光照+质量], [具体资产类型要求]

# 面部特写（⚠️ 去掉铠甲，只留发型+脸型）
[🔴核心锚定：发型+脸型], [🟡重要：眼神+表情], [🟢增强：光照+质量], [framing限制：face only no body no armor], [具体资产类型要求]
```

**策略三：使用固定 seed 保持跨图片一致性** ⭐

`generate_image.py` 支持 `--seed <int>` 参数固定随机种子。同一角色在同一次会话中多次生成时，使用相同 seed 可显著提高面容一致性。

```yaml
# 同一角色的多张资产使用相同 seed
tool: agnes-ai generate_image.py
params:
  prompt: "国风古典美人，鹅蛋脸型，丹凤眼冷冽锐利..."
  seed: 42  # 固定种子，确保多次生成的面容一致
  output_name: "墨雪_front.png"
```

建议：每个角色分配一个固定 seed（如墨雪=42，墨将=43），该角色的所有资产图都使用这个 seed 生成。

---

**策略四：提示词语言策略（按 `aesthetic_style` 选择，覆盖全部资产类型）**

所有资产类型（角色、场景、道具、分镜图）的提示词语言由 `script.json` 的 `aesthetic_style` 决定：

- `"eastern"` → **纯中文**（不加英文），使用 `image_prompt_cn` / `scene_prompt_cn`
- `"western"` → **英文**（古风词可保留中文），使用 `image_prompt` / 自写英文

> 详见主 SKILL.md §5.5（审美风格配置）和 §6.2-§6.4（完整示例）。

---

**策略五：冗余生成 + 选优（针对高不一致资产）**

对于最容易出现不一致的资产类型（面部特写/头部多角度/表情研究），一次生成 **2 张候选图**，选最接近的一张保留，另一张删除或重命名加 `_candidate` 后缀。

---


#### 5.4.3 场景资产生成（强制）

对于视频中的每个关键场景：

1. **画幅规则**：场景空镜头必须是 **16:9 横版**（1792x1024 或 1920x1080），展现环境广度。9:16 竖屏只用于角色全身照和分镜图。
2. **内容规则**：场景空镜头中**不得出现任何人物**（包括小兵、路人）。可包含道具（旗帜、兵器、家具等）。如需士兵的三视图，单独生成。
   - **实现方式**：`agnes_provider.py` 的 `generate_scene()` 已自动注入 `negative_prompt="人物, 人, 行人, 角色, 人类, 人群, 面部, 身体, 人体, 人物剪影, 生物, 动物, 活物, 多余的物体"`，API 层面强制禁止人物出现。
     仅靠 prompt 正文写"画面中不应该有任何人物"不够——AI 模型容易在长 prompt 中忽略正面描述，必须通过 `negative_prompt` 独立参数约束。
   - **根因与修复**（2026-06-30）：`negative_prompt` 还不够——场景名/描述中的人物暗示词（如"播客录音室"→暗示有人播客、"谈话氛围"→暗示有人交谈、"主播"→暗示主持人）会**压倒 negative_prompt**，模型训练数据中这些词与人物强关联。
     - `generate_scene()` 在构建 prompt 前**自动净化**场景描述：去掉"播客"、"谈话"、"主播"等暗示人物的词
     - prompt 结构改为：**开头**强约束「室内空镜无人物」→ **中间**净化后的场景描述 → **结尾**再次约束「绝对不能出现人物」
     - `negative_prompt` 增加"主播、主持人、演讲者、人像、肖像"等术语
     - **重要**：不修改 `script.json` 的场景卡数据，只在 prompt 构建层做词法净化
   - **验证**：`project_generate.py verify-scenes` 命令使用 Haar Cascade 人脸检测验证场景图是否含人物。

3. **跨镜头角色一致性（强制）**（2026-06-30 新增）：
   - **问题**：参考图（如 `小段_front.png`）有围巾/眼镜/发型等标志性特征，但 `character_cards` 的 `distinctive_mark`/`armor/clothing` 没写 → 后续 shot 的 prompt 不提这些特征 → AI 忽视参考图的标志性细节 → 角色一致性丢失（典型症状：shot_01 有围巾、shot_02 没有）
   - **根因**：手动在某个 shot 的 prompt 临时加的"橙色围巾"没存回 `character_cards`，导致只有该 shot 的 prompt 有围巾
   - **实现方式**（已编码到 `_generate_prompt_template`）：
     - 自动从 `script.character_cards[]` 提取每个角色的 `distinctive_mark` + `style_keywords`
     - 拼接到每个 shot 的 `[目标风格/场景]` 段末尾（用逗号分隔）
     - 效果：修改 `character_cards[].distinctive_mark` 后，`build-first-frames --force` 一键同步所有 shot 的 prompt
   - **强制规则**：
     - **标志性特征（围巾、眼镜、发型、配饰）必须写入 `character_cards[].distinctive_mark`**
     - 不能只在某个 shot 的 prompt 里手动加
     - 任何"参考图有但 prompt 没"的特征都会被 AI 忽略
   - **示例**：
     ```json
     "character_cards": [{
       "name": "小段",
       "distinctive_mark": "戴一副圆框眼镜，佩戴一条橙色围巾，笑容有感染力，微卷短发",
       "appearance": {
         "armor/clothing": "米白色针织毛衣外套浅棕色休闲开衫，领口搭一条橙色围巾"
       }
     }]
     ```
4. **单角色 shot 防双人脑补（强制）**（2026-06-30 新增）：
   - **问题**：单角色镜头的参考图只有 `小段_front.png`，但 `agnes-image-2.0-flash` 的编辑指令写"在场景中加入**各角色**"（复数），AI 会脑补出第二个人（如 shot_05/07 出现两人）
   - **修复**：`_generate_prompt_template` 根据角色参考图数量动态生成指令
     - 单角色参考图 → "加入**该角色**" + "只出现一位角色，禁止出现第二个人或倒影"
     - 多角色参考图 → "加入**各角色**" + 空间关系约束
   - **强制规则**：所有单角色 shot 的 `[编辑指令]` 段必须显式禁止出现第二人
5. **定义场景卡** — 在 `script.json` 的 `scene_cards` 中为每个场景定义光照、氛围、配色、关键元素等属性，与 `character_cards` 形成对称
   - `scene_cards[].style_keywords` 自动注入到场景 `image_prompt` / `video_prompt` 中
   - 场景角度由生成流程统一约定（使用中文命名）：`广角建立` / `中景细节` / `特写元素`
   - 光照变体由生成流程统一约定（使用中文命名）：`白天` / `黄金时刻`，至少生成 2 个变体

4. **多角度场景图** - 从不同景别生成同一场景
   - 至少生成2-3个角度：远景建立、中景细节、特写元素
   - 保存为：`images/scenes/<场景名>_广角.png`, `<场景名>_中景.png`, `<场景名>_特写.png`

5. **场景光照变体** - 生成不同光照条件下的同一场景
   - 默认：白天 + 黄金时刻（至少2个变体）
   - 保存为：`images/scenes/<场景名>_白天.png`, `<场景名>_黄金时刻.png`

**场景资产提示词示例**（按 `aesthetic_style` 选择语言，以下示 eastern 用纯中文）：

```
"龙南客家围屋远景，黄金时刻阳光，雄伟山脉背景，文化遗产，高度细致，电影感，4K"
"龙南客家围屋中景，主入口，精美石雕可见，温暖光线，建筑细节，4K"
"龙南客家围屋特写，风化墙面纹理，苔藓和石头细节，微距镜头，历史质感，4K"
```

western 风格时用英文，如 `"Ancient Chinese courtyard house, golden hour sunlight, majestic mountain background..."`

#### 5.4.4 风格一致性规则

所有生成的资产必须共享统一的视觉风格：

1. **色彩统一** - 所有角色和场景资产使用相同的调色板
   - 参考：脚本JSON中的 `asset_inventory.style_reference`
   - 一致地应用色彩关键词（如"温暖复古"、"电影感"、"纪录片风格"）

2. **光照统一** - 保持每个场景组的光照情绪一致
   - 历史场景："温暖复古胶片颗粒光照"
   - 现代场景："锐利自然光，略微饱和"

3. **质感统一** - 使用一致的质量关键词
   - 基础："高度细致，照片级真实，电影感，4K"
   - 风格化："艺术感，插画风格，一致的线条工作，[特定风格]"

4. **角色一致性** - 当同一角色出现在多个镜头中
   - 在每个提示词中始终包含识别特征（面部特征、服装、关键道具）
   - 对该角色的所有提示词使用相同的风格关键词

#### 5.4.5 资产库组织

所有资产放入 **$HOME/WorkBuddy/\<项目名\>/** 的 `images/` 子文件夹，结构如下：

```
$HOME/WorkBuddy/<项目名>/
├── script.json
├── images/
│   ├── characters/
│   │   ├── 名称_front.png           (正面全身照，白色纯色背景无环境元素)
│   │   ├── 名称_side.png            (侧面全身照，白色纯色背景无环境元素)
│   │   ├── 名称_back.png            (背面全身照，白色纯色背景无环境元素)
│   │   ├── 名称_3quarter.png        (3/4侧面全身照，白色纯色背景无环境元素)
│   │   ├── 名称_face.png            (面部极致特写)
│   │   ├── 名称_head_angles.png     (头部多角度参考)
│   │   ├── 名称_hands_feet_gestures.png  (手脚姿态研究)
│   │   ├── 名称_reference.png       (角色设定参考板)
│   │   ├── 名称_expressions.png     (表情研究表)
│   │   ├── 名称_props.png           (配饰与道具特写)
│   │   └── 名称_face_details.png    (面部五官特写)
│   ├── scenes/
│   │   ├── 场景名_广角.png   (广角空镜头，16:9，无人物)
│   │   ├── 场景名_中景.png    (中景空镜头，16:9，无人物)
│   │   ├── 场景名_特写.png (细节空镜头，16:9，无人物)
│   │   ├── 场景名_白天.png   (白天光照变体)
│   │   ├── 场景名_黄金时刻.png (黄金时刻光照变体)
│   │   └── ...
│   ├── props/
│   │   ├── 道具名_01.png      (道具多角度)
│   │   └── ...
│   ├── style/
│   │   ├── color_palette.png   (调色板参考卡)
│   │   └── first_frame.png    (视频首帧合成图，含人物+场景+道具)
│   └── storyboard/            ← 分镜首帧参考图，用于图生视频
│       ├── shot_01_first_frame.png  (分镜1)
│       ├── shot_02_first_frame.png  (分镜2)
│       └── ...
├── videos/
├── output/
└── ...
```

**关键规则**：

1. **角色资产**（共11种必须生成）：

   **基础全身照（4种，必须生成）**：
   - `名称_front.png` - **正面全身照**（9:16或3:4），**白色纯色背景**，**必须从头到脚完整（含靴子）**
   - `名称_side.png` - **侧面全身照**（9:16或3:4），**白色纯色背景**，**必须从头到脚完整（含靴子）**
   - `名称_back.png` - **背面全身照**（9:16或3:4），**白色纯色背景**，**必须从头到脚完整（含靴子）**
   - `名称_3quarter.png` - **3/4侧面全身照**（介于正面和侧面之间），**白色纯色背景**，**必须从头到脚完整（含靴子）**，展示角色立体感

   **面部与细节（3种，必须生成）**
   - `名称_face.png` - **面部极致特写**，展示五官细节（9:16），表情需符合角色性格
   - `名称_head_angles.png` - **头部多角度参考**（方形或16:9），展示6个角度（正面、3/4、侧面、背面、仰视、俯视），确保3D建模/AI生成一致性
   - `名称_hands_feet_gestures.png` - **手脚姿态研究**（方形或16:9），展示10种手部姿态和8种脚部/走路姿态，确保角色动作一致性

   **角色设定与扩展（4种，必须生成）**：
   - `名称_reference.png` - **角色设定参考板**（16:9或方形），**不透明背景**，参考专业角色设计参考板（含全身视图、头部多角度、表情研究、面部特写、服饰细节、配饰道具、手脚姿态），**一次性生成，用于角色一致性参考**
   - `名称_expressions.png` - **表情研究表**（方形或16:9），展示10种表情（开心、惊讶、愤怒、悲伤、困惑、大笑、皱眉、思考、痛苦、疑惑）
   - `名称_props.png` - **配饰与道具特写**（方形或16:9），展示武器、发簪、披风扣、腰带、靴子等道具细节
   - `名称_face_details.png` - **面部五官特写**（方形，1024×1024），展示眼部/鼻部/唇部/耳部四部位特写拼图。用方案F生成（4张独立部位特写→PIL脚本拼接）

   **全身照关键规则**：prompt中必须包含 `from head to toe` / `complete full body including feet` 等关键词，确保构图完整；表情需符合角色性格定位（如"冷艳中带温情"而非"愤怒"）

2. **场景资产**（必须是空镜头，无人物）：
   - 生成**多角度场景图**（广角/中景/特写）
   - 可以是 **16:9 横向**，突出环境细节和空间感
   - 每个场景至少生成 2-3 张（广角/中景/特写）
   - 光照变体至少 2 种（白天/黄金时刻）
   - 文件命名：`images/scenes/<场景名>_广角.png`、`<场景名>_中景.png`、`<场景名>_白天.png` 等

3. **辅助资产**（当脚本需要除了主角之外的批量/群体角色时，为其生成三视图作为参考）：
   - 典型场景：**两军对垒**（明军vs蛮兵）、**卫兵/随从**、**特定道具/装备**等
   - 每类辅助资产生成 front / side / back 三视角，白色纯色背景，768×768
   - 生成方式：**文生图**（无参考图，纯文字提示词）
   - 提示词结构：`[时代] [类别] [视图] 全身视图，[装备描述]，[姿态]，完整全身从头到脚包括靴子，白色纯色背景，古风写实`
   - 文件命名：`images/troops/<类别名>_front.png`、`<类别名>_side.png`、`<类别名>_back.png`
   - 在 `script.json` 中增加相应的 `xxx_cards` 字段（如 `troop_cards`）描述特征和提示词
   - 分镜首帧图涉及辅助资产时，将其与场景图、角色图合并为一张参考板使用

4. **首帧合成图（全局风格参考）**：
   - 视频的**首帧合成图**（first frame）是人物、场景、道具的合成图
   - 用于确定整体视觉风格和色调
   - 保存在 `images/style/first_frame.png`

5. **分镜首帧图（分镜级，用于图生视频）**：
   - **每个镜头**生成一张独立的**分镜首帧图**，作为该镜头视频生成的参考图
   - 分镜图 = **场景 + 主要人物 + 次要人物 + 道具**的合成图，构图与 `image_prompt` 一致
   - **比例**：由 `script.json` 的 `aspect_ratio` 和项目需求决定（如竖屏 9:16 对应 720×1280，横屏 16:9 对应 1280×720 等），匹配视频输出尺寸
   - **参考图策略**（⚠️ 重要：不要只传角色 front 照做 ref-image）：
     - 以**场景图**为主要 `--ref-image`（保证场景氛围/色调/光照不被白色背景覆盖）
     - 角色一致性通过 **拼图参考板法** 或 prompt 文字描述实现
   - **拼图参考板法**（多张参考图时的标准方案）：
     - 当镜头需要参考**场景 + 多角色 + 辅助资产**时，先用 Python PIL 将所有参考图合并为一张
     - 布局示例：场景图占左侧 2/3，角色/辅助资产图排列在右侧
     - 合并后的单张图约 3-4MB，GitHub raw 上传不受限制
     - 参考脚本：`scripts/make_ref_board.py`（通用模板，改路径即可复用）
   - **多角色同框 Prompt 技巧**：
     - 每个角色名称后紧跟 `(角色特征括号注释)`，如 `女性将军墨雪(国风古典美人鹅蛋脸丹凤眼鸳鸯暗纹玄铁铠甲)`
     - 次要角色描述比主要角色简短，放在动作描述中自然带出
     - ⚠️ **武器、装备、动作细节不要放进括号内**，括号内容容易被模型视为弱权重注释。应该写成自然语句：✅ `"明军士兵持长枪突刺、拔腰刀近身格斗"` ❌ `"明军士兵（持长枪腰刀）"`
   - 生成方式：**图生图**，以合并后的单张参考板为 `--ref-image`
   - 提示词中用 `image_prompt_cn`（eastern）或 `image_prompt`（western），并补充角色特征描述
   - 命名规则：`images/storyboard/shot_<镜头编号>_first_frame.png`
   - 示例：`images/storyboard/shot_01_first_frame.png`（分镜1）
   - 该镜头后续视频生成时，以 storyboard 图为第一帧参考 + `video_prompt` 图生视频

> `scripts/` 目录下提供辅助工具脚本：`make_ref_board.py`（合成参考板）、`stitch_face_details.py`（拼接面部细节图）。

6. **风格统一**：
   - 所有资产（角色、场景、道具）必须**风格统一**
   - 遵循 `script.json` 中的 `tone` 和 `visual_thread` 设定
   - 调色板参考 `images/style/color_palette.png`

7. **文件位置**：
   - 角色图、场景图必须保存在**项目文件夹下的 `images/`**，不要保存到 `generated-images/` 或其他全局文件夹
   - 每个视频项目有独立的资产库，确保资产和脚本的对应关系清晰

8. **生成顺序（优先图生图策略）**：
   - 第一步：生成**全身照4种**（front / side / back / 3quarter）
     - 使用 **文生图**（白色纯色背景，全身从头到脚含靴子）
     - 优先用 Agnes AI
   - 第二步：以4种全身照为参考图，**图生图**生成剩余7种资产：
     - **face / face_details**：用 text-only 生成（img2img 会继承参考图背景/铠甲，纯脸图不适合）
     - **head_angles / expressions**：以 front 图为参考，图生图
     - **hands_feet / props**：以 front + side 图为参考，图生图
     - **reference**：以全部4张为参考，图生图
   - 第三步：生成场景空镜头（多角度）
   - 第四步：生成首帧合成图（确定整体风格）
   - 第五步：为**每个镜头**生成分镜首帧图，保存到 `images/storyboard/`
   - 第六步：以 storyboard 图为参考图 + `video_prompt`，逐镜头图生视频

   > 图生图使用 `project-generate` skill 自动上传到 GitHub raw 获取公网直链。
