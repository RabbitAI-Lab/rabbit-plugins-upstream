## 核心原则变更
上一轮方案引入了 `AI_VIDEO_*` 全局环境变量作为 Layer 2 的路径来源。
本轮修订完全废除 env 方案，改为 **"执行路径即身份"**：

> 不靠 env 区分平台，靠「哪个 Python 文件被 invoke」；
> 配置跟 skill 副本和 project 目录走，不跟宿主平台目录名走。
>
> WorkBuddy 调用 → .../workbuddy/skills/xxx/scripts/pipeline.py
> Codex 调用     → .../codex/skills/xxx/scripts/pipeline.py
> 三份 skill 同时跑、互不干扰，因为 __file__ 不同 → skill_root 不同 → 配置天然隔离。
