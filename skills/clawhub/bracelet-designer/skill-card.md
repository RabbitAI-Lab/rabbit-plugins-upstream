## Description:

Helps create bracelet and other jewelry design drafts and hand-drawn sketches from prompts and reference images using the Craftsman jewelry-design service.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ai-hub-admin](https://clawhub.ai/user/ai-hub-admin)

### License/Terms of Use:

MIT-0

## Use Case:

Designers and other users can describe jewelry ideas, supply reference image URLs, and use the provided API examples to request design sheets, sketches, and shareable viewing sessions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Jewelry prompts, reference image URLs, and design or session metadata are sent to an external service.

Mitigation: Avoid confidential designs, private images, and regulated data unless the provider's privacy and retention terms are acceptable.
