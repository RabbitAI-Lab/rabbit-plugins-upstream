# 快递公司编码表

> 注意：单号特征仅供**向用户求证或人工判断**，不要据此自动选定公司——纯数字单号多家重叠（如 14-15 位数字同时符合顺丰和京东，8-10 位数字同时符合德邦和申通）。自动识别只使用 `query_tracking.py` 内置的高置信度规则（SF/JD/YT/EMS/JT 前缀），其余情况应询问用户。

## 常用快递

| 快递公司 | 编码 | 单号特征 |
|---------|------|---------|
| 顺丰速运 | `SF` | SF 开头 + 13 位数字，或 14-15 位纯数字 |
| 中通快递 | `ZTO` | 77 开头或 6 位数字 + 字母 |
| 圆通速递 | `YTO` | YT/YK 开头 + 10-14 位数字 |
| 申通快递 | `STO` | 66 开头或 8-12 位数字 |
| 韵达速递 | `YD` | 13-15 位数字，常以 3/4/5 开头 |
| 邮政 EMS | `EMS` | E 开头 + 9 位数字 + E，或 13 位数字 |
| 京东物流 | `JD` | JD 开头 + 11-13 位数字 |
| 德邦快递 | `DBL` | 8-10 位数字 |
| 极兔速递 | `JTSD` | JT 开头 + 11-13 位数字 |
| 百世快递 | `HTKY` | 15-16 位数字 |
