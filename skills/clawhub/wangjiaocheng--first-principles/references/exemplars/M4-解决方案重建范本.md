# M4 解决方案重建域范本

## M4-01 方案设计

### 输入示例
事实：电池技术、充电基础设施、政策支持、市场需求
假设：电池技术假设、充电假设、市场假设

### 处理过程
1. 设计策略：基于事实设计解决方案
2. 设计方法：排除假设，仅从事实出发
3. 设计方案：电动汽车发展方案
4. 设计验证：验证方案的可行性

### 输出示例
```markdown
## 方案设计报告

### 设计策略
- **策略**：基于事实设计解决方案
- **原则**：排除假设，仅从事实出发

### 设计方法
- **方法**：排除假设，仅从事实出发
- **排除**：市场假设、充电假设
- **保留**：电池技术事实、充电基础设施事实

### 设计方案
| 方案组成部分 | 基于事实 | 说明 |
|--------------|----------|------|
| 电池技术研发 | 电池技术事实 | 持续提升电池性能 |
| 充电网络建设 | 充电基础设施事实 | 扩大充电覆盖 |
| 政策利用 | 政策支持事实 | 争取政策支持 |
| 市场拓展 | 市场需求事实 | 满足市场需求 |

### 设计验证
- **验证方法**：检查方案的可行性
- **验证结果**：方案可行
```

## M4-04 方案对比

### 输入示例
新方案：基于事实的电动汽车发展方案
传统方案：基于假设的电动汽车发展方案

### 处理过程
1. 对比标准：可行性、有效性、风险性
2. 对比方法：多维度对比
3. 对比结果：每个方案的对比结果
4. 对比结论：对比结论

### 输出示例
```markdown
## 方案对比报告

### 对比标准
| 标准 | 描述 | 权重 |
|------|------|------|
| 可行性 | 方案是否可行 | 40% |
| 有效性 | 方案是否有效 | 30% |
| 风险性 | 方案的风险程度 | 30% |

### 对比结果
| 方案 | 可行性 | 有效性 | 风险性 | 综合 |
|------|--------|--------|--------|------|
| 基于事实的方案 | 高 | 高 | 低 | 优 |
| 基于假设的方案 | 中 | 中 | 高 | 中 |

### 对比结论
- **基于事实的方案**：更优
- **基于假设的方案**：风险较高
```
