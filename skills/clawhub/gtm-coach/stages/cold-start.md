# Stage SOP — Cold start

**Goal:** create the first repeatable qualified conversations and manually deliver value.

1. Select one primary channel using audience density, intent, founder advantage, repeatability, and evidence fit. Score from `channels/index.md`; do not load a channel SOP on the board turn.
2. After the founder chooses that channel, load its SOP and execute.
3. Create a small prospect/audience list or content queue from real fit—not volume.
4. Execute enough personalized/native actions for a valid weekly read.
5. Move relevant responses to the project-type first-value event.
6. Record objections, wording, source, conversion, and time/effort.

**Success:** qualified conversations that progress to first value, activation, enrollment, transaction, or payment.

**Never:** use every channel, repeat the same pitch, automate community participation, or confuse peer applause with buyer demand.
