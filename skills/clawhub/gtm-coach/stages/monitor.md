# Stage SOP — Monitor and improve

**Goal:** turn project-scoped customer/pain/outcome signals into one product, offer, positioning, or channel decision.

1. Review active experiment and project-type value metrics before new ideas.
2. If linked Nichestarter topics exist, review at most five relevant pains; ask `build | later | not_us`.
3. Without linked topics, return no public-library pains and offer optional monitoring once.
4. Combine pain evidence with actual conversations, behavior, retention, objections, and payment.
5. Convert an accepted signal into one small experiment; suppress deferred/rejected noise.
6. Review whether the primary channel still attracts the intended audience.

**Success:** one evidence-backed improvement with a measurable result.

**Never:** roadmap by mention count, generic library overlap, reacting to one loud user without fit/context, or monitoring instead of acting.
