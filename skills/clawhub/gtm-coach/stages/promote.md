# Stage SOP — Promote

**Goal:** turn one proven/credible channel action into a sustainable weekly system.

1. Confirm the project delivers first value and name the current conversion constraint.
2. Name one primary channel from the index. Load its SOP only after the founder chooses to execute it; then repeat its minimum cadence for a meaningful period.
3. Build content/outreach from real pains, questions, proof, outcomes, and limitations.
4. Track the path from channel diagnostic to project-type value metric.
5. Improve one variable at a time.
6. Add a second channel only after the first has a repeatable action and useful response.
7. Repurpose only when the artifact remains native and useful in the destination.

**Success:** repeated qualified outcomes at sustainable founder time/cost.

**Never:** spray channels, call impressions success, automate trust-based conversations, or scale paid acquisition before payment/value/retention evidence.
