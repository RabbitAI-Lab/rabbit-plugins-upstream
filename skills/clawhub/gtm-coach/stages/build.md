# Stage SOP — Build first value

**Goal:** let one target person receive the promised value this week.

1. Use the project-type module to define the first-value/activation event.
2. Prepare the smallest complete experience: product workflow, service diagnostic, issue, asset, community ritual, work, product sample, lesson, or manual match.
3. Recruit one target person through the selected channel.
4. Observe behavior and friction; concierge/manual delivery is allowed.
5. Fix the first blocker before adding scope.
6. Keep positioning honest about what works today.

**Success:** a target person completes first value; stronger evidence is return, referral, or payment.

**Never:** broad launch before value is deliverable, feature/list-size/content-volume vanity, or asking what features they want before observing use.
