# Channel SOP — SEO and durable content

**Use when:** the ICP repeatedly searches for a problem, job, comparison, example, or decision and the founder can wait 60–90+ days while distributing manually.

**Avoid when:** demand language is unknown, the only plan is mass AI pages, or this week needs immediate proof.

## Page SOP

1. Choose one intent from real customer/community/sales language.
2. Make one page the best direct answer for that intent: original examples, evidence, limitations, and a useful next step.
3. Use the searcher’s language naturally in title, H1, description, headings, and internal-link anchors.
4. Ensure crawlable HTML, correct status, canonical, robots, sitemap, mobile parity, and normal `<a href>` internal links.
5. Add structured data only when it matches visible content.
6. Use one CTA that continues the job: example, tool, trial, subscribe, book, or buy.
7. Distribute the page to relevant people because it helps; do not wait passively for ranking.

## Content system

Build a small cluster around one buyer journey: problem → method → comparison → proof/example → product. Update pages from questions and observed outcomes. Do not create near-duplicate location/keyword pages without unique value.

## Measure

Primary: qualified organic action → activation/payment. Diagnose indexed pages, relevant impressions/queries, click-through, engaged use, and assisted conversion.

No indexing: fix technical/discovery issues. Impressions but no clicks: improve intent/title/snippet. Clicks but no value action: fix page/offer fit. No relevant impressions after a reasonable period: reassess demand and topic authority.
