# Project SOP — Digital product

## Value and proof

- **Promise:** a template, guide, asset, toolkit, or download helps a named buyer complete a job.
- **Activation:** buyer downloads/opens it and uses the key asset.
- **Evidence ladder:** pain story → preview/demo consumed → checkout → use → outcome → referral/related purchase.
- **Primary CTA:** preview the useful artifact or buy/get the clearly scoped resource.

## Stage priorities

1. Validate the job and existing workaround before producing a large bundle.
2. Build the smallest complete artifact plus a preview that proves quality.
3. Sell manually to the first buyers and observe where setup/use fails.
4. Use problem-led content, demonstrations, creator/community distribution, and aligned bundles.
5. Add affiliates or paid traffic only after checkout and use are proven.

## Useful metrics

Qualified page visits → preview engagement → checkout conversion → download/open → use/outcome → refunds → referrals/upsells. Downloads alone do not prove value.

## Common traps

- Competing on file count.
- Discounting before the promise is clear.
- A freebie audience that never wants the paid job.
- Marketplace traffic with no owned audience capture or product usage signal.

## Coach must ask

“What will the buyer accomplish in the first 15 minutes, and how will we know they used the product rather than only downloaded it?”
