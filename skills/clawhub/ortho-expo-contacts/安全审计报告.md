### 📝 信息性提醒（非风险项）

#### I-1　索引库写入 `src_root`（源目录绝对路径）到 meta 表

- **位置**：`scripts/build_index.py:565`
- **说明**：构建时把源目录的绝对路径写入 `data/contacts.db` 的 `meta` 表。该库含个人联系信息，SKILL.md 已明令禁止进入任何发布包/云盘/外部服务（红线），故正常情况下不外泄；一旦违规分发库文件会连带泄露本机目录结构。
- **建议**：把该值改为源目录名的哈希摘要或直接删除，做到库文件即便外流也不含本机路径。

#### I-2　查询库以普通连接打开（非只读 URI），行为上全为 SELECT

- **位置**：`scripts/query.py:236`、`scripts/build_index.py:545`、`scripts/debug_null.py`（后两者为自身库构建/诊断，属预期写路径）
- **说明**：`query.py` 对 `data/contacts.db` 使用普通连接但**全代码仅执行 SELECT**（全文检索与计数），未检出任何 INSERT/UPDATE/DELETE/DDL；构建器是唯一合法写路径（重建自身索引）。属工程语义固化问题，非行为缺陷。
- **建议**：查询路径可改为 `mode=ro` 只读 URI，与姊妹技能对跨库访问的处理对齐。

#### I-3　JSONL 整文件重写，无原子写

- **位置**：`scripts/gate.py:289-294`（签署承诺）、`342-348`（移出拒访名单）
- **说明**：以写模式全量重写文件，中断可能损坏该文件。属本地健壮性问题，非安全行为。

#### I-4　承诺签署含交互式确认输入

- **位置**：`scripts/gate.py:283`（`input()`，未带 `--yes` 时询问 y/N）
- **说明**：常规 CLI 交互确认，无敏感输入、无回显处理需求，输入仅与字面「y」比较。不构成风险。

#### I-5　LIKE 通配符不作转义 + SKILL.md 含一条家目录相对 Python 路径提示

- **位置**：`scripts/query.py:180-190`；`SKILL.md:64`
- **说明**：① 用户输入中 `%` 通配符会放宽本地匹配范围，参数仍全部占位符绑定，仅影响召回量，无注入无外泄。② SKILL.md 第 64 行 `PY="python"` 之后的注释给出「Windows 用家目录下 Python 环境路径」的目录结构提示，形式为波浪号开头、**不含系统账户名与盘符**，无真实本机路径泄露；但该目录层级形态偏环境特有。
- **建议**：① 如需精确语义可转义通配符；② 注释可仿姊妹技能改为「按本机 Python 安装位置调整」的中性写法。
