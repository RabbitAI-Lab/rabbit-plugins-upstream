# 回归用例与预期结果

> 版本 2.0.0：题库 → **试卷库**（随机抽卷），并新增**麻瓜词典**页面注释与校验。
> 本文所有实测数字取自 `data/questions.json`(33 题) + `data/papers.json`(33 卷, 种子 20260915) + `data/glossary.json`(73 条)。

跑法（Windows / macOS / Linux 通用）：

```bash
python scripts/sorting_hat.py --audit
python scripts/sorting_hat.py --selftest
python scripts/build_quiz_html.py --verify --node <node 路径>
```

`--selftest` 一次覆盖 **19 项**：配置自检（主配置 + alt 配置）、四院可达、四种结局、
跨卷确定性、换卷编号改变、`--random` 种子复现、空/非法输入、缺答补默认项、
默认项随选项搬移、六种答案格式一致、`#N` 卷号前缀、缺卷号时的三种错因分流、
选项顺序确实被打乱、卡片版心宽度。

| # | 用例 | 命令 | 预期 |

| 2 | 同一卷同一答案跑两次结果一致 | `--card "#1 AAAAAAAAAAA"` 连跑两次 | 卡片逐字节一致，编号都是 `019022B8` |
| 3 | 随机可复现 | `--random --seed 20260911` 连跑两次 | 卷号、答案串与卡片完全一致 |

## 2. 答案格式宽容度（六种写法必须等价）

```
1A 2B 3C 4A 5B 6C 7A 8B 9C 10A 11B
1a2b3c4a5b6c7a8b9c10a11b
1.A 2.B 3.C 4.A 5.B 6.C 7.A 8.B 9.C 10.A 11.B
A B C A B C A B C A B
ABCABCABCAB
A,B,C,A,B,C,A,B,C,A,B
```

六者解析出的答案序列必须完全相同（`--selftest` 断言 set 长度为 1）。
全角 ＡＢＣ／１２３、中文顿号、各种分隔符都在归一化阶段处理掉。

**卷号前缀**：`#7 1A 2B 3C` 里的 `#7`（也认 `＃7`、`#7:`）会被剥出来当卷号，
剩余部分才交给答案解析。剥不出来时才要求 `--paper`。

## 3. 四种结局的具体触发串（实测，均在 01 号卷上）

| 结局 | 命令 | 实测表现 |
| --- | --- | --- |
| 正常判定 | `--card "#1 AAAAAAAAAAA"` | 分差 0.181818 > 0.12，第 2 轮直接出卡（赫奇帕奇） |
| 第 3 轮触发 | `--card "#1 AAAAAAAAABA"` | 分差 0.060606 ≤ 0.12 → 输出「这是个艰难的决定」「你自己说吧。你想去哪？」+ A/B/C/D 映射表，exit 0 |
| 犹豫后出结果 | `--card "#1 AAAAAAAAABA" --will "赫奇帕奇"` | 头名即用户所选，出卡无「自己挑的」标注 |
| 帽子让步 | `--card "#1 AAAAAAAAABA" --will "格兰芬多"` | 先吐槽「行吧。帽子再老，也得听戴帽子的人说话。」，卡片学院行追加「（这是你自己挑的）」 |
| 用户弃权 | `--card "#1 AAAAAAAAABA" --will "随便"` | 取归一化最高者，判词后追加「「随便」？一千年来，说随便的人最后都有意见。我替你定了。」 |
| 最低分学院也认 | 同上，`--will` 换最低分院 | 该院归一化分最低仍然让步，同上标注 |

> 卷号不同，同一串字母的结局可能不同——**计分与编号都依赖卷号**，这是设计如此。
> `--will` 同时接受学院名、简称（狮院/蛇院/鹰院/獾院）、A–D 字母（按 `meta.houses` 顺序映射）。

## 4. 试卷库：随机但不失控

设计前提是「**每次打开都不一样，但每张卷都公平**」。落地方式：

| 环节 | 做法 |
| --- | --- |
| 题池 | 33 道，每题四院峰值权重都是 3 → 任取 11 道，cap 必然 33 |
| 生成 | `make_papers.py`，多种子打乱 + 换位修补，保证 **每道题恰好被抽中 11 次** |
| 出卷 | 33 张 × 11 题，任意两张最多重合 7 题（不重样） |
| 选项 | 每题三个选项的顺序逐卷打乱（实测 299/363 个槽位非字母序） |
| 运行时 | 页面加载时随机取卷号，**卷号印在封面与卡片上** → 想复现就照抄卷号 |

```bash
python scripts/make_papers.py --check          # 只校验，不重生成
python scripts/make_papers.py --seed 20260915  # 重生成（同种子完全一致）
python scripts/sorting_hat.py --list-papers --limit 4
```

```

  文本模式下帽子开头就会报「卷号 NN」，照抄给我：
    python sorting_hat.py --card "1A 2B 3C …" --paper 7
```

## 6. 页面注释（麻瓜词典）

| 项 | 规则 |
| --- | --- |
| 词条数 | canon 73 条；alt 27 条 |
| 数据 | `data/glossary.json` / `glossary.alt.json`，`meta.title / intro / scope_note / empty` |
| 标法 | 正文里命中的词加下划线点线，hover/点击弹出释义；长度降序匹配，长词优先 |
| 不泄底 | 带 `"house": true` 的 19 条（四院名、创始人、遗物、幽灵…）**只**在封面与结果页标注；题干与选项里一律不标 |
| 开关 | 页面右上「注释」按钮可整体关掉；「麻瓜词典」按钮开出抽屉看全表 |
| 离线 | 词典随 HTML 内联，无网络请求 |

## 7. UI 模式（点选式答题页）回归

```bash
python scripts/build_quiz_html.py --out out.html
python scripts/build_quiz_html.py --verify --verify-papers 3 --node <node 路径>
python scripts/build_quiz_html.py --config alt --verify --node <node 路径>
```

`--verify` 分四段，任何一段不过即 exit 1：

| 段 | 内容 | 实测 |
| --- | --- | --- |
| ① 编译对拍 | 33 张卷，Python 编译结果 vs JS `compilePaper()` 签名 | 全部一致 |
| ② 计分对拍 | 抽 3 张卷各跑满 3¹¹ = 177147 组，比计分签名 | 全部一致 |
| ③ 文字卡对拍 | 33 张卷 × 4 种结局 + 缺答补默认项 1 例 = 133 张，逐字节比 | 全部一致 |
| ④ 界面链路 | DOM 桩驱动页面脚本：2 张卷 × 3 条作答路径（正常/让步/弃权） | 6/6 通过 |

`--verify-all` 把 ② 扩到全部 33 张卷（≈70 秒），发版前跑。

| # | 用例 | 预期 |
| --- | --- | --- |
| 1 | 生成物是单文件 | 无 `<link href>`、无 `<script src>`、无 http(s) 外链；双击可开（实测 89.5 KB） |
| 2 | 打开即随机 | 每次刷新抽到不同卷号，卷号显示在封面与结果卡上 |
| 3 | 交互链路 | 开始 → 逐题点选 → 最后一题按钮变「提交判定」→ 未答完时禁用并提示剩几题 → 提交出卡 |
| 4 | 答案被记住 | 点过的选项在回到该题时仍为选中态；顶部进度点标出已答/当前 |
| 5 | 第三轮由按钮承接 | 触发犹豫时给出四院按钮 + 「你替我定」；选非头名学院出现「这是你自己挑的」 |
| 6 | 编号跨通道一致 | 同一卷同一答案：页面里的编号 == `sorting_hat.py --card "#N …"` 的编号 |
| 7 | 复制文字版 | 复制出来的字符串 == 文本模式那张卡（含帽子评语与让步吐槽） |
| 8 | 注释不泄底 | 题干里检索不到任何 `house: true` 词条；结果页能检索到 |
| 9 | 注释开关可用 | 关掉后正文不再有下划线注标；词典抽屉仍能打开看全表 |
| 10 | 去 IP 化可用 | `--config alt` 生成与对拍同样全通过，配色仍按 house key 取色 |

## 8. 改动配置后的回归清单

| 改了什么 | 必须重跑 |
| --- | --- |
| `threshold` / `tie_break_priority` | `--selftest`（用例 2、4 依赖）+ `build_quiz_html.py --verify` |
| 题库 `questions.json` | `make_papers.py` 重生成 → `--audit` 看 cap 是否仍配平 → `--verify` |
| 试卷库 `papers.json` | `make_papers.py --check` → `--audit` → `--verify` |
| 词典 `glossary.json` | `--audit`（查空文案与 `house` 标记）→ `--verify`（第 ④ 段查题干） |
| 学院文案 `houses.json` | `--audit` 看字段完整性与禁词、引号、枚举值格式；文案只在这里改，页面自动跟着变 |
| alt 配置 | `--config alt --audit` + `build_quiz_html.py --config alt --verify` |
| `build_quiz_html.py` 里的 JS 芯 | **必须** `--verify`——这是唯一能发现两份实现分叉的手段 |
| `sorting_hat.py` 的解析/计分 | `--selftest` + `--verify`（两边都要过，防单边走偏） |

## 9. 已知缺口

**alt（去 IP 化）配置仍共用 canon 的题库。** `questions.json` 里的场景与题干都是原著场景
（禁林、魔药课、霍格莫德…），`--config alt` 只换了四院名称与卡片文案，题干没跟着去 IP 化。
要真正可用，需要单独出一份 alt 题库（`questions.alt.json`）+ 对应 `papers.alt.json`。
在补上之前，alt 只能当作「换皮演示」，不要对外当去 IP 化版本发。
