# 十维拓客 · 默认分析维度

用户**未指定** HTML 展示维度时，使用下列 **10 个维度**（顺序固定）。每个维度用「关键词命中」在 ASR 转写文本中统计覆盖率与摘录；命中规则见 [SKILL.md](SKILL.md) 中「维度分析规则」。

| # | 维度名称 | 默认关键词（可扩展） | 典型标签（摘录展示） |
|---|----------|----------------------|----------------------|
| 1 | 拓客场景 | 陌拜、上门、网点、电话营销、进社区、路演、扫楼 | 陌拜、网点 |
| 2 | 触达人群 | 老板、客户、王总、李总、朱总、经理、主任、厂长 | 老板、客户 |
| 3 | 开口获客话术 | 您好、你好、打扰、请问、方便、拜访 | 您好 |
| 4 | 客户需求 | 额度、利率、期限、还款、资金、周转、采购 | 额度 |
| 5 | 客户拒绝原因 | 不需要、考虑一下、没兴趣、太忙、再说、不行 | 不需要 |
| 6 | 有效意向分类 | 有意向、高意向、再联系、签约、办手续、尽快 | 有意向 |
| 7 | 产品匹配 | 产品、贷款、信贷、快贷、杭信贷、经营贷 | 产品 |
| 8 | 成交阻碍痛点 | 材料、抵押、担保、审批、流程、麻烦、慢 | 材料 |
| 9 | 跟进动作 | 回访、再约、发资料、加微信、明天、下周 | 回访 |
| 10 | 拓客成效数据 | 放款、到账、批复、审批通过、额度批复 | 放款 |

## 用户选择维度（子集）

用户可**只分析其中若干维**，名称须与上表「维度名称」列**完全一致**（如「客户需求」「跟进动作」）。HTML 中**仅保留**所选维度：统计表、图表、分维度卡片都不再出现未选维度。

示例话术 → 脚本参数：

| 用户说法 | Agent 执行 |
|----------|------------|
| 只看客户需求、跟进动作 | `--only 客户需求 --only 跟进动作` |
| 分析触达人群和开口获客话术 | `--only "触达人群,开口获客话术"` |

```bash
python3 scripts/generate_asr_insight_html.py \
  -i /tmp/asr_completed.json \
  --only 客户需求 --only 跟进动作 \
  -o /tmp/asr_insight.html
```

页眉标题在非 10 维时为「N维分析 · 录音转写洞察报告」；摘要中说明本次为选定的 N 个维度。

若用户提到的名称不在上表，应先对照本表澄清或给出可选维度列表，**不要**静默忽略。

## 用户自定义维度（全新维度）

若用户给出**不在默认十维内**的维度（名称 ± 关键词），则**完全替换**上表，仍保持与 [asr_insight_template.html](asr_insight_template.html) 相同的页面结构（统计表、图表、分维度卡片），仅维度名称与关键词集合按用户定义。此时用 `--dimensions`，**不要**用 `--only`。

自定义示例（JSON，供脚本 `--dimensions` 使用）：

```json
[
  {"name": "竞品提及", "keywords": ["宁波银行", "工行", "农行"]},
  {"name": "利率对比", "keywords": ["年化", "利率", "4.2", "4.35"]}
]
```

## 与参考 HTML 的对应关系

参考样例 [`asr_insight_template.html`](asr_insight_template.html) 中：

- 页眉标题：**十维拓客 · 录音转写洞察报告**
- **各维度统计一览** 表：维度 / 覆盖率 / 命中条数
- **图表**：录音样本量按日、各维度覆盖率雷达/柱状、Top 维度命中趋势
- **分维度卡片**：findings、命中录音数、覆盖率、典型摘录（带 tag）、建议

生成报告时样式与区块顺序以该文件为准；数据来自接口 `records` 与上述关键词统计，而非硬编码样例数值。
