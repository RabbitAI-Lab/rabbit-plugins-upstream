## Use Case: <br>
Developers use this skill to design, review, and normalize JSON payloads for APIs, configuration files, frontend/backend exchange, and third-party integrations. It is most useful when an agent needs concise guidance for validation contracts, field naming, null semantics, date formats, numeric IDs, and response envelopes. <br>
