## Known Risks and Mitigations:

Risk: SEO requests are paid per call, with charges that can increase as result depth or row count grows.

Mitigation: Set a spending limit and request only the depth and number of rows needed.

Risk: The API key and submitted query or domain data are sent to the service provider.

Mitigation: Keep the API key in a secret environment variable and submit only information you intend to share with the provider.

Risk: Optional MCP access may expose more workspace capabilities than the SEO facet URL alone suggests.

Mitigation: Review the MCP server's actual tool list and permissions before enabling access.
