# 03-3年路线图制定

## 触发条件
- 战略和目标架构确认后，制定分阶段实施路线图

## 使用模板

使用 `templates/数字化转型路线图模板.md` 作为标准格式。

## 路线图制定指引

### 阶段划分原则

```
Phase 1（0-6月）：基础夯实 — "不打地基就盖不了楼"
  → 只做1-3件最重要的事
  → 目标：稳定、可用、有人用
  → 预算：占3年总预算的25-35%

Phase 2（7-18月）：能力提升 — "地基好了，开始扩建"
  → 系统互联互通、数据开始产生价值
  → 目标：效率提升可见、数据驱动决策
  → 预算：占3年总预算的35-45%

Phase 3（19-36月）：智能升级 — "有数据了，可以玩AI了"
  → AI场景落地、组织数字化
  → 目标：AI创造可测量的业务价值
  → 预算：占3年总预算的25-35%
```

### 每个Phase的规划模板

对于每个Phase中的每个项目：

```
项目名称：[XX]
目标：[一句话]
范围：[覆盖哪些门店/部门]
前置条件：[必须先完成什么]
投入：[人/钱/时间]
产出：[交付物+KPI改善]
依赖：[依赖什么系统/团队/外部因素]
风险：[Top 3风险+缓解措施]
退出标准：[什么算"完成"？]
```

### 快赢项目优先原则

Phase 1的第一个月就应该有"快赢"：
- **快赢的定义**：<30天实施、<5万投入、效果可见（数字说话）
- **快赢的目的**：给团队信心、给老板回报、给后续项目铺路
- **快赢的典型**：扫码点餐上线（高峰期省1个人）、外卖数据自动对账（店长每天省30分钟）

### 加盟商推广节奏（连锁品牌特殊考虑）

| 阶段 | 推广策略 | 目标加盟商覆盖率 |
|------|---------|:---:|
| M1-M3 | 5-10家标杆加盟商（自愿） | 3-5% |
| M4-M6 | 效果说话，吸引第二波 | 15-25% |
| M7-M12 | 供应链系统柔性捆绑（新店直接接入） | 40-60% |
| M13-M24 | 老加盟商逐步过渡 | 80%+ |
| M25+ | 全部加盟商统一平台 | 95%+ |

## 产出
- 3年分阶段路线图
- 每阶段详细项目清单（含投入/产出/依赖/风险）
- 里程碑定义
- 投资总估算

## 质量检查
- [ ] Phase 1的项目<3个（宁少勿多）
- [ ] 每个项目有明确的退出标准
- [ ] 考虑了加盟商（如适用）的推广节奏
- [ ] 有至少1个快赢项目在M1内上线
- [ ] 投资估算有依据（不是拍脑袋）
