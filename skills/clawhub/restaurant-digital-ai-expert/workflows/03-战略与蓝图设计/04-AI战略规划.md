# 04-AI战略规划

## 触发条件
- 客户明确说要"做AI" / "上AI"
- 或客户的数字化基础已达到L3+（系统打通、数据可用），AI成为自然下一步

## AI战略规划流程

### Step 1: AI准备度检查

**以下5个条件缺1个就先别做AI**：
- [ ] 核心系统（POS+会员+至少1个运营系统）已统一并稳定运行>6个月
- [ ] 数据质量基础达标（订单数据准确率>95%、菜品/门店主数据标准建立）
- [ ] 至少有1个可量化的AI场景（不是"想要AI"，而是"AI具体解决XX问题，预期降本/增效XX"）
- [ ] 老板/决策层亲自推动（AI不是IT项目，是业务变革）
- [ ] 有能力承接（可以是用SaaS厂商的AI，不一定需要自己建团队）

**如果3个以上不满足**，建议先做完基础数字化，再考虑AI。

### Step 2: AI场景盘点

使用RICE+评分卡对以下15个场景逐一评估：
1. AI语音点餐
2. AI需求预测
3. AI智能排班
4. AI视觉识别(后厨品质)
5. AI个性化推荐
6. AI动态定价
7. AI智能客服
8. AI后厨品质检测
9. AI食安合规巡检
10. AI营销自动化
11. AI供应链优化
12. AI能耗优化
13. AI舆情分析
14. AI选址模型
15. AI配方优化

### Step 3: 场景优先级排序

详见 `tools/AI场景优先级评分卡.md` 和 `templates/AI场景优先级评分卡模板.md`

### Step 4: 每个P0场景的ROI测算

对每个P0（立即启动）场景，做1页的ROI估算：
- 投入：软件/硬件/数据标注/集成/组织成本
- 收益：降本/增效/增收的量化估算
- 风险：数据质量、技术可行性、组织接受度

### Step 5: AI技术策略

| 客户规模 | 推荐AI技术策略 |
|---------|--------------|
| <10店 | 使用SaaS厂商集成的AI功能（不要自建） |
| 10-100店 | 公有云API（通义/DeepSeek/文心）+ 轻量RAG |
| 100-1000店 | 混合架构（公有云API+私有化部署）+ 领域微调 |
| >1000店 | 多模型网关 + 自研Agent + 私有大模型 |

### Step 6: AI组织建设

| 阶段 | AI组织形态 |
|------|----------|
| 启动期 | 1-2个"AI Champion"（兼职，但对AI有热情） |
| 成长期 | 3-5人AI小组（数据工程师+ML工程师+业务分析师） |
| 成熟期 | AI卓越中心 + 各业务线AI Ambassador |

## 产出
- AI准备度检查结果
- AI场景优先级矩阵（RICE+评分卡）
- P0场景的ROI详细测算
- AI技术策略建议
- AI实施路线图（3-4个季度）

## 质量检查
- [ ] 没准备好做AI的客户，明确说"先做好基础数字化"
- [ ] AI场景选择基于ROI，而非"AI很酷"
- [ ] 技术策略与客户规模匹配
- [ ] 考虑了AI伦理和合规（数据隐私、算法偏见、食品安全）
