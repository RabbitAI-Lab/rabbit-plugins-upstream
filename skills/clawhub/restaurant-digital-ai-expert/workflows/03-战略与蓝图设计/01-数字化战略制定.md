# 01-数字化战略制定

## 触发条件
- 诊断完成后，客户需要制定数字化战略

## 战略制定框架

### Step 1: 愿景对齐（与管理层）

**核心问题**："3年后，你希望你的餐厅'数字化'到什么程度？"

引导客户回答的方式：
- 不要问"数字化愿景是什么"，中小老板听不懂
- 问："3年后，你打开手机想看餐厅的什么信息？" → 引导出数据需求
- 问："3年后，你的店长最不需要操心什么？" → 引导出自动化需求
- 问："3年后，你的顾客用什么方式点餐？" → 引导出客户体验需求

### Step 2: 战略目标量化

| 目标维度 | 示例指标 | 当前基线 | 3年目标 |
|---------|---------|:---:|:---:|
| 数字化覆盖 | 统一系统的门店占比 | | |
| 效率提升 | 人效(万元/人/年) | | |
| 成本降低 | 食材成本率 | | |
| 客户增长 | 会员数/数字订单占比 | | |
| 管理透明度 | 数据实时可见的门店占比 | | |

### Step 3: 设计原则

**必须选择适合客户阶段的原则**，而非直接套用通用原则：

| 客户阶段 | 推荐设计原则 |
|---------|------------|
| L1-L2 | 移动优先、简单至上、渐进式、先SaaS后自研 |
| L2-L3 | 数据打通优先、API优先、统一标准、敏捷迭代 |
| L3-L4 | AI原生、平台化、数据驱动、安全合规 |
| L4-L5 | 全球一致+本地智能、开放生态、持续演进 |

### Step 4: Run/Grow/Transform投资分配

| 客户阶段 | Run(%) | Grow(%) | Transform(%) | 说明 |
|:---:|:---:|:---:|:---:|------|
| L1-L2 | 80 | 15 | 5 | 几乎全部投入在基础系统 |
| L2-L3 | 60 | 30 | 10 | 基础稳定后开始增长型投资 |
| L3-L4 | 40 | 35 | 25 | 较大比例投入到AI和自动化 |
| L4-L5 | 30 | 35 | 35 | 三均衡，但Grow和Transform主导 |

## 产出
- 数字化愿景声明（1句话+1段话）
- 3年战略目标（SMART格式，3-5个）
- 设计原则（8-10条）
- IT投资组合分配

## 质量检查
- [ ] 愿景能一句话说清楚
- [ ] 目标符合SMART（具体的、可衡量的、可达成的、相关的、有时限的）
- [ ] 设计原则适合客户阶段
- [ ] 投资分配与客户阶段匹配
