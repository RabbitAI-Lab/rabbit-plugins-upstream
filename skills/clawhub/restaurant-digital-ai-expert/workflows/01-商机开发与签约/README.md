# 01-商机开发与签约

本阶段覆盖从初次接触餐饮客户到签订合同的完整流程。

## 子流程

| # | 流程 | 产出 | 时长 |
|---|------|------|:---:|
| 01 | 初次客户沟通 | 客户画像+痛点初筛 | 1-2小时 |
| 02 | 需求澄清与问题诊断 | 问题诊断摘要 | 1-3天 |
| 03 | 项目建议书 | Proposal(Word/PPT) | 3-5天 |
| 04 | SOW与合同 | SOW+合同技术附件 | 3-5天 |

## 关键原则

- **餐饮客户分三类**：懂数字化想要方案的 / 不懂但知道有问题的 / 完全没概念的
- **第一类**直接出方案，**第二类**先帮他厘清问题，**第三类**先做数字化意识唤醒
- **不管哪类**，第一次沟通必须搞清楚：业态、门店数、营收范围、当前用什么系统、最痛的点是什么
