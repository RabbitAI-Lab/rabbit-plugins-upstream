# 02-现状诊断与评估

本阶段对餐饮企业进行全面数字化诊断，输出R-DMM五维评估和差距分析。

## 子流程

| # | 流程 | 产出 | 周期 |
|---|------|------|:---:|
| 01 | 调研准备与执行 | 调研计划+访谈提纲 | 2-3天 |
| 02 | 五维R-DMM评估 | 评估报告（含雷达图） | 3-5天 |
| 03 | 诊断报告撰写 | 发现→洞察→建议 | 2-3天 |

## 关键原则

- **实地走访必做**：至少走3-5家门店（不同商圈、不同业绩的都要看）
- **多角色访谈**：老板→店长→厨师长→前厅员工→加盟商（如适用）
- **数据交叉验证**：客户说的 vs 系统里的数据 vs 实地看到的——三方对照
- **不只访谈IT**：数字化评估不是IT审计，要聊业务、聊运营、聊人
