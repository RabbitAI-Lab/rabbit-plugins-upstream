# 01-调研准备与执行

## 触发条件
- 项目启动后，进入正式诊断阶段
- 或客户说"帮我们全面看看数字化水平"

## 调研准备

### 第一步：制定调研计划（1天）

| 项目 | 内容 |
|------|------|
| 调研范围 | [全部门店/抽样XX家/总部] |
| 调研时间 | [共X天] |
| 访谈对象 | [列表] |
| 走访门店 | [列表：不同城市/商圈/业绩的门店都要有] |

### 第二步：准备访谈提纲

**老板/创始人（60分钟）**：
1. 生意总体怎么样？过去3年和未来3年的变化？
2. 数字化在你心里排第几？（vs 开店/人才/产品/营销/供应链）
3. 你觉得你们现在数字化到什么程度了？
4. 用数字化最想解决什么问题？（只选Top 3）
5. 预算和决策流程是怎样的？
6. 以前上过系统吗？顺利吗？踩过什么坑？

**店长（30分钟，每家店选1-2个）**：
1. 你每天花最多时间的3件事是什么？
2. 现在用的系统好用吗？最烦的是什么？
3. 高峰期最头疼的是什么？（排班/出餐/对账/催菜？）
4. 如果明天能实现一个数字化功能，你最想要什么？
5. 你们店的数字化对新员工要培训多久？难吗？

**厨师长/后厨负责人（30分钟）**：
1. 现在的出餐流程是怎样的？从接单到出品平均多久？
2. 食材备餐怎么备？备多了怎么办？备少了怎么办？
3. 怎么管理的食材效期？有没有浪费/过期的？
4. 有没有食品安全方面的系统或流程？
5. 如果让后厨更高效，你最想改变什么？

**前厅员工（15分钟，每家店找1-2个不同年龄段的）**：
1. 你会用现在的收银系统吗？学了多久？
2. 高峰期会不会手忙脚乱？
3. 你觉得客人最常抱怨的是什么？
4. 如果给你一个"数字化工具"让工作更轻松，你希望它做什么？

**加盟商（如适用，30分钟，选3-5个配合度高和配合度低的都要）**：
1. 你用的总部系统吗？用得怎么样？
2. 不想用的原因是什么？（太难/不信任/没用/太贵）
3. 你的门店目前最赚钱的是什么？最亏钱的是什么？
4. 你觉得总部在数字化方面最应该帮你解决什么？
5. 你觉得自己是"总部合伙人"还是觉得"被总部管着"？

### 第三步：材料收集清单

向客户索要：
- [ ] 现有系统清单（POS/KDS/会员/进销存/排班/BI/...）
- [ ] 最近3个月的营收/成本/客流数据（如果能导出）
- [ ] 组织架构图
- [ ] 现有SOP/操作手册
- [ ] 已有数据报表样例
- [ ] 门店WiFi网络情况
- [ ] 加盟商花名册（如适用）

### 第四步：实地走访

走访时关注5个维度：
1. **前厅**：高峰期收银/点餐的实际效率、客户排队情况
2. **后厨**：出餐流程、厨房显示方式、人员配置
3. **网络**：WiFi信号强度（用手机实测）、断网应急方案
4. **数据**：实际在用哪些报表？贴在墙上的、记在本子上的
5. **人员**：不同年龄/岗位的员工对系统的态度和使用情况

## 产出
- 调研计划
- 完整访谈记录
- 材料收集清单（已收/待补）
- 门店走访记录（含照片）

## 常见陷阱
- ❌ 只听老板的（老板说的和店长说的经常不一样）
- ❌ 只看旗舰店（最好的店不能代表全部门店）
- ❌ 只在会议室谈（一定要去门店看真实操作）
- ❌ 不问加盟商（连锁品牌的加盟商视角最重要）
