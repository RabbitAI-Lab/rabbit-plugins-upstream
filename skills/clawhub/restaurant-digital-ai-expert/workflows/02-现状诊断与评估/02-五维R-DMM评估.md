# 02-五维R-DMM评估

## 触发条件
- 调研完成后，进行正式的五维成熟度评估

## 执行指引

使用 `tools/餐饮数字化成熟度评估工具.md` 进行完整评估。

### 评估流程

```
Step 1: 技术力评估（系统清单+集成度+基础设施）
  → 产出：技术力得分[1-5] + 评分依据

Step 2: 运营力评估（SOP+排班+品质+巡检+能耗）
  → 产出：运营力得分[1-5] + 评分依据

Step 3: 数据力评估（采集+质量+报表+决策+治理）
  → 产出：数据力得分[1-5] + 评分依据

Step 4: 组织力评估（IT团队+认知+素养+培训+文化）
  → 产出：组织力得分[1-5] + 评分依据

Step 5: 客户力评估（线上渠道+会员+私域+个性化+反馈）
  → 产出：客户力得分[1-5] + 评分依据

Step 6: 综合评级
  → 产出：R-DMM综合级别L[X].[X] + 雷达图

Step 7: 业态对标
  → 产出：与同业态均值/领先水平的差距分析
```

### 评分务必遵循的原则
- **看证据不是看印象**："老板说数据很好"不算，"看了最近3个月的POS数据，完整率98%"才算
- **严一点比松一点好**：评分低一点不会伤害客户，高估了才会
- **与其打3.5分，不如打3分然后说明"某些方面有4分的潜质"**
