# 03-诊断报告撰写

## 触发条件
- R-DMM评估完成后，撰写正式诊断报告

## 使用模板

使用 `templates/数字化成熟度评估报告模板.md` 作为标准格式。

## 报告撰写指引

### 核心原则：从"发现"到"洞察"到"建议"

```
发现(What) → 洞察(So What) → 建议(Now What)

✗ "系统不互通"（只有发现）
✓ "POS、会员、进销存三套系统不互通，导致店长每天需花1小时手工对账=年损失3.6万人工成本+15%的对账误差风险（洞察）→ 建议3个月内完成POS-会员-进销存三方对接（建议）"
```

### 报告结构（按模板）

| 章节 | 核心内容 | 给老板读的 | 给技术读的 |
|------|---------|:---:|:---:|
| 执行摘要 | 1页：综合评分+Top3发现+Top3行动 | ★★★★★ | ★★★ |
| 业务现状 | 门店概况+系统清单+数据资产 | ★★★★ | ★★★★ |
| 五维评估 | 每维评分+证据+差距分析 | ★★★ | ★★★★★ |
| 对标分析 | 你 vs 同业态均值 vs 领先 | ★★★★★ | ★★★ |
| 快赢机会 | 0-3个月能做的、投入小见效快 | ★★★★★ | ★★★★ |
| 建议与下一步 | 分阶段行动路线 | ★★★★★ | ★★★★ |

### 报告长度指引

| 客户规模 | 总页数 | 执行摘要 | 详细分析 |
|---------|:---:|:---:|:---:|
| 1-10门店 | 8-12页 | 1页 | 尽量精简 |
| 10-100门店 | 15-25页 | 1页 | 配图表 |
| 100+门店 | 25-40页 | 1-2页 | 充分展开 |

### 必须避开的雷区
1. **不要用"贵司"这种称呼**——中小餐饮老板看着别扭，用"你们"自然得多
2. **数字不能拍脑袋**——不是100%确定的数据标注"预估，±15%"
3. **不要惊艳老板**——老板比你更懂他的生意，不要教他做餐饮
4. **不要只讲问题不讲解决方案**——诊断报告的核心价值在"然后呢？"

## 质量检查
- [ ] 每个发现都有数据支撑
- [ ] 每条建议都指明了"谁来做、做什么、多久见效"
- [ ] 报告有"看一页就懂"的执行摘要
- [ ] 排版整洁统一（宋体/等线、1.5倍行距）
- [ ] 非技术人员能看懂80%以上的内容
- [ ] 没有建议跨阶段的跳跃式方案
