# 03-投资决策与预算审批

## 触发条件
- ROI分析完成，需要形成正式的投资建议供管理层审批

---

## 餐饮数字化投资决策的特殊性

### 为什么餐饮老板犹豫？

| 老板顾虑 | 真实原因 | 应对策略 |
|---------|---------|---------|
| "太贵了" | 只看到了首期投入，没看到长期回报 | 把3年TCO和收益摆在桌上对比 |
| "我们不需要这么复杂" | 之前有失败的IT项目，心理阴影 | 先做一个小试点（1家店），让数据说话 |
| "万一供应商倒闭怎么办" | 餐饮SaaS倒闭率30%/年 | 选财务健康的供应商+数据不锁定 |
| "等我们规模大了再上" | 认为数字化是"有了规模才能做" | 错了：数字化是用来做大做强的工具，不是做大了才买的奢侈品 |
| "我认识XX老板，他们上了系统也没用" | 只看到投入，没看到执行差异 | 同系统不同结果：差在执行力，不是差在系统 |

## Step 1: 投资建议书

### 标准结构（10页PPT或5页文档）

**使用场景**：给CEO/董事会的投资建议书

```
1. 封面 + 一句话结论（"建议投入XX万在X个季度内完成XX数字化建设"）

2. 问题与机会
   - 当前最大痛点（不超过3个，用数据说话，如"店长每天浪费30分钟在做表"）
   - 竞争对手在做什么（"XX竞对已经用AI排班把人力成本压到16%，我们是22%"）
   - 不做数字化的机会成本

3. 数字化愿景
   - 3年后是什么样子（1句话+1段话）

4. 投资方案
   - 总体方案概览（架构图+核心系统清单）
   - 分阶段投入（Phased investment）
   - 3年TCO总表

5. 预期收益
   - ROI分析（含保守/基线/乐观3情景）
   - 投资回收期
   - 非量化战略价值

6. 风险与缓解
   - Top 5风险 + 缓解措施（诚实、不要画大饼）

7. 实施路线图
   - Phase 1: 0-6月 → 做什么、花多少钱、能看到什么效果
   - Phase 2: 7-18月 → ...
   - Phase 3: 19-36月 → ...

8. 同行案例
   - 2-3个同规模/同业态餐饮企业的数字化投入和效果

9. 资源需求
   - 需要老板做什么决策
   - 需要什么内部资源
   - 需要什么样的外部合作伙伴

10. 下一步行动
    - 批准后前30天的具体行动计划
```

## Step 2: 分阶段预算

### 为什么必须分阶段？

> "一次性要300万老板会吓死，但要30万做第一个月试点没什么压力"

### 分阶段预算表模板

| 阶段 | 时间 | 投入(万) | 占比 | 关键验收标准 |
|------|------|:---:|:---:|------|
| P1-基础 | M1-M6 | XX | 25-35% | XX系统覆盖XX店，XX指标达到XX |
| P2-提升 | M7-M18 | XX | 35-45% | 数据打通，XX效率提升XX% |
| P3-智能 | M19-M36 | XX | 25-35% | AI场景落地，ROI转正 |
| **合计** | **36月** | **XXX** | **100%** | |

### 预算审批节奏

| 审批节点 | 审批内容 | 金额 | 决策人 |
|---------|---------|:---:|------|
| 第1次 | Phase 1预算 | 小 | 运营总监+CEO |
| 第2次（P1通过后） | Phase 2预算 | 中 | CEO+董事会 |
| 第3次（P2通过后） | Phase 3预算 | 大 | 董事会 |

> 核心原则：**用P1的成绩为P2的预算背书，用P2的数据为P3的投入证明。**
> 不要一次性要3年的钱，而是在每个阶段证明了这个阶段的ROI后再要下一阶段的钱。

```

```

## Step 4: 管理层沟通指南

### 给不同角色的沟通重点

| 角色 | 他们关心什么 | 怎么讲 |
|------|------------|--------|
| CEO/老板 | 投多少钱、什么时候能赚回来、有没有风险 | "投XX万，X个月回本，风险可控" |
| CFO | 现金流、TCO、ROI、税收影响 | "3年TCO=XX万，保守情景ROI=XX%，回收期=XX月" |
| COO | 运营影响、门店配合、过渡期 | "每个店需要XX小时培训，过渡期XX周内效率只会下降XX%" |
| CTO/CIO | 技术可行性、集成复杂度、团队能力 | "技术成熟度XX，集成接口XX个，团队需要补XX能力" |

### 沟通黄金法则

```
1. 先说结论，再讲证据
   老板不想听1小时汇报，只想知道"要不要投、投多少、什么时候能看到效果"

2. 用钱说话，不要用技术术语
   不是说："我们要上云端微服务架构"
   而是说："投30万，每家店每年省1个人=5万，6家店×5万=30万，1年回本"

3. 准备"电梯演讲"
   如果你只有2分钟跟CEO在电梯里说这件事，你说什么？
   → "我们的店长每天花40分钟对账。上线外���自动对账系统后，每家店每天省30分钟，
      老板你可以在手机上实时看到每家店的营收、成本、利润。项目投入30万，6个月回本。"

4. 主动讲风险，不要回避
   老板最怕的不是风险，而是"你们故意不说风险"
   诚实列出Top 5风险+每个风险的缓解措施，反而增加信任度

5. 给老板"后悔的机会"
   方案设计为可分步执行的模块，随时可以叫停或调整
   "我们先在5家店试2个月，数据好了再推广" — 老板更容易同意
```

## 常见反对意见及应对

| 反对意见 | 应对策略 |
|---------|---------|
| "太贵了，我们预算不够" | "不是一次性花300万，是先花30万把最痛的解决掉" |
| "我们店少，不值得搞" | "数字化不是花钱，是投资。10家店用系统，人效能提升到15家店的水平" |
| "现在生意不好，不是时候" | "生意好的时候没时间，生意差的时候更需要效率" |
| "我们有IT在做" | "内部IT能做很好，顾问带来的是同行的经验和踩过的坑" |
| "等竞争对手做了我们再做" | "等到那时候，竞对已经在成本优势上了。先做的人用效率碾压后做的人" |

## 质量检查
- [ ] 投资建议书第1页就有"一句话结论"
- [ ] 用钱说话，不是用技术术语
- [ ] 保守情景ROI仍为正
- [ ] Top 5风险每一项都有缓解措施
- [ ] 有"小试→推广→全面"的渐进路径，给管理层退出空间
- [ ] 包含了同行对标（同规模企业的数字化投入和效果对比）
