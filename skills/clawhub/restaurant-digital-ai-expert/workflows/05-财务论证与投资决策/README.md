# 05-财务论证与投资决策

数字化不是"花钱"而是"投资"。本阶段帮助客户建立严谨的财务论证，让预算审批有理有据。

## 子流程

| # | 流程 | 产出 |
|---|------|------|
| 01 | TCO总拥有成本建模 | 3-5年TCO模型（含隐性成本） |
| 02 | ROI与商业论证 | ROI分析+敏感度分析+投资回收期 |
| 03 | 投资决策与预算审批 | 投资建议书+分阶段预算+审批材料 |

## 关键原则

- **TCO看5年，不要看1年**：SaaS的"低价首年+高价续费"模式意味着只看首年是灾难
- **隐性成本占TCO的30-40%**：培训、运维、集成、数据迁移、组织变革成本
- **ROI要"保守"**：收益估算取低值、投入估算取高值，宁可保守达标也不要乐观翻车
- **数字化投资有"反直觉"的回报曲线**：前6-12个月投入大回报小（基础建设期），12个月后才进入收获期
