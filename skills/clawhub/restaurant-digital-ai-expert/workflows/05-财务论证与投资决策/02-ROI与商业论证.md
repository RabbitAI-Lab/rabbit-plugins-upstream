# 02-ROI与商业论证

## 触发条件
- TCO模型建立后，需要建立ROI分析为投资决策提供依据

---

## 餐饮数字化ROI分析框架

### 收益全景图（5大类）

```
ROI = (降本收益 + 增效收益 + 增收收益 + 风险规避收益 + 战略价值)
     ÷ TCO总投入
```

---

## Step 1: 收益量化

### 收益类别1：降本收益（最容易量化）

| 降本项目 | 量化方法 | 按什么单位算 |
|---------|---------|------------|
| 减少服务员 | (原人数-现人数)×年薪 | 按门店 |
| 减少收银员 | 扫码点餐后收银岗减半×年薪 | 按门店 |
| 降低食材损耗 | (原损耗率-现损耗率)×月采购额×12 | 按门店/按月度 |
| 降低外卖佣金 | 私域订单占比提升×(美团费率-私域费率) | 按订单 |
| 降低对账时间 | (原耗时-现耗时)×店长时薪×店数×365 | 按门店 |
| 降低打印/物料 | 数字化菜单代替纸质×安全库存×12 | 按门店 |

### 收益类别2：增效收益

| 增效项目 | 量化方法 | 备注 |
|---------|---------|------|
| 翻台率提升 | 日均翻台增加×客单价×座位数×365 | 更易量化 |
| 出餐速度提升 | 高峰出餐量增加×客单价×高峰期 | KDS效果 |
| 人效提升 | 营收÷人数 的变化 | 综合指标 |
| 库存周转加速 | 周转天数减少×日均库存价值 | 减少资金占用 |

### 收益类别3：增收收益

| 增收项目 | 量化方法 | 备注 |
|---------|---------|------|
| 会员消费提升 | 会员月消费额提升×会员数×12 | CRM效果 |
| 复购率提升 | 复购次数增加×客单价×活跃客户数 | 精准营销 |
| 客单价提升 | (新客单价-旧客单价)×月订单数×12 | 推荐算法 |
| 私域订单增长 | 私域新增订单×客单价×12 | 降佣+增收 |
| 新店盈利加速 | 新店提前盈利月数×月均利润×年新店数 | 选址+标准化 |

### 收益类别4：风险规避收益

| 风险 | 规避收益量化 | 概率 |
|------|------------|:---:|
| 食安事故 | 降低食安事件概率×(单次平均赔偿+品牌损失) | 年度概率 |
| 数据丢失 | (1-恢复概率)×重建数据成本 | 年度概率 |
| 加盟商跑路 | 减少坏账×概率 | — |
| 采购舞弊 | 降低异常采购金额×概率 | — |

### 收益类别5：战略价值（定性→定量转���）

| 战略价值 | 量化思路 |
|---------|---------|
| 品牌数字化形象 | "对加盟商吸引力提升→加盟费可上浮X%" |
| 数据资产 | "数据驱动决策减少重大失误=年均省Y万" |
| 组织能力 | "IT团队自研能力→减少外购=年均省Z万" |

## Step 2: ROI核心计算

### 基础公式

```
年度ROI = (年度数字化收益 - 年度数字化成本) ÷ 年度数字化成本 × 100%

投资回收期 = 累计投入 ÷ 年化净收益

NPV(3年) = Σ[(年收益-年成本)÷(1+折现率)^n] - 初始投资
```

### 折现率建议

| 企业类型 | 建议折现率 | 理由 |
|---------|:---:|------|
| 个体户/小餐饮 | 8-10% | 对标银行小微贷款 |
| 区域连锁 | 10-12% | 对标餐饮行业平均资本成本 |
| 全国连锁 | 10-15% | 考虑更高的机会成本 |
| VC投资品牌 | 15-25% | 风险投资级别 |

## Step 3: 敏感度分析

### 必须测试3个情景

| 情景 | 投入假设 | 收益假设 | 用途 |
|------|---------|---------|------|
| 乐观 | 投入控制在预算内 | 收益达到预期 | 目标情景 |
| 基线 | 投入超支15% | 收益达到预期的80% | 最有参考价值 |
| 悲观 | 投入超支30% | 收益达到预期的50% | 决策底线 |

### 敏感度测试变量

测试以下变量对ROI的影响：

| 变量 | 测试区间 |
|------|------|
| 软件订阅费上涨 | +10%/+20%/+30% |
| 门店推广速度慢 | 每月少上线1-3家 |
| 员工学习曲线长 | 效率恢复时间+50% |
| 收益延迟 | 收益到账延迟3-6个月 |
| 关键员工离职 | IT经理/数据师离职=3个月空窗 |

## Step 4: ROI报告结构

### 标准ROI报告（5页）

```
第1页：执行摘要（1页）
  - 总投资：XX万元（3年）
  - 年化收益：XX万元
  - 3年ROI：XX%
  - 投资回收期：XX个月
  - 核心结论+关键假设

第2页：TCO投入明细（1页）
  - 按年度/按类别的投入分解
  - 饼图+柱状图

第3页：收益分析（1页）
  - 按5类收益的分解
  - 每个收益项目的量化依据和假设

第4页：敏感度分析（1页）
  - 3个情景的ROI结果
  - 最关键变量识别

第5页：建议与下一步（1页）
  - 是否建议投资
  - 风险缓解措施
  - 如何追踪实际ROI
```

## 餐饮数字化ROI行业基准

| 项目类型 | 典型ROI | 典型回收期 | 参考 |
|---------|:---:|:---:|------|
| POS/KDS上线 | 150-250% | 6-12个月 | 最确定 |
| 扫码点餐 | 200-400% | 3-6个月 | ROI最高 |
| 会员CRM | 100-200% | 12-18个月 | 中期见效 |
| 供应链系统 | 80-150% | 18-24个月 | 慢但可持续 |
| BI/数据分析 | 50-100% | 12-24个月 | 难量化但价值大 |
| AI需求预测 | 100-200% | 12-18个月 | 数据质量决定成败 |
| 私域运营 | 150-300% | 6-12个月 | 关键是执行力 |

> 数据来源：中国餐饮数字化协会2024年行业调研 + 各SaaS厂商案例汇总
