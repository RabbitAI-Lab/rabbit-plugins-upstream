# 04-技术选型与供应商评估

基于战略目标和技术架构，进行结构化技术选型和供应商评估，确保"选对系统、选对合作伙伴"。

## 关键原则

- **杜绝"关系型采购"**：选择基于数据而非关系，用评分矩阵说话
- **杜绝"镀金"**：10家店不需要微服务架构，选适合客户当前和未来18个月的方案
- **证明概念(PoC)先行**：关键系统必须先PoC再决策，不要只看Demo
- **供应商稳定性 > 功能丰富度**：餐饮SaaS厂商倒闭率高达30%/年，选择"活得过3年"的供应商比选择功能多的更重要
