# 02-数字化组织设计

## 触发条件
- 数字化战略确定，需要设计配套的数字化组织和人才体系

---

## 核心问题

> "谁对数字化负责？谁对数据负责？谁对系统运行负责？"

大部分餐饮企业的数字化失败，不是因为系统不好，而是因为"没人真正负责"。

---

## Step 1: 数字化组织演化路径

### 按企业规模的数字化组织

| 阶段 | 门店数 | 数字化负责人 | 团队配置 | 月成本(万) |
|------|:---:|------------|---------|:---:|
| 萌芽期 | 1-5 | 老板自己 | 无专职、找SaaS厂商支持 | 0 |
| 启动期 | 5-20 | 运营经理兼任 | 0-1个IT专员 | 0-1 |
| 建设期 | 20-100 | 专职IT经理 | 2-4人(IT+数据+运维) | 2-6 |
| 发展期 | 100-500 | CIO/数字化VP | 8-15人(产研+数据+运维+PMO) | 8-25 |
| 成熟期 | 500-2000 | CIO/CTO | 30-80人(完整IT组织) | 25-100 |
| 引领期 | 2000+ | 集团CTO/CDO | 100-300人+AI卓越中心 | 100-500+ |

## Step 2: 数字化组织架构设计

### 两种基本架构模式

**模式A：IT嵌入业务（适合10-200店）**

```
          CEO
           │
    ┌──────┴──────┐
    │             │
  运营VP        IT经理(5-10人)
    │             │
    ├─ 门店运营   ├─ 基础设施(2人)
    ├─ 营销      ├─ 应用系统(2人)
    └─ 供应链    ├─ 数据分析(1人)
                └─ 运维支持(2人)

优势：IT直接服务业务，沟通成本低
劣势：IT只做"需求响应"，缺乏前瞻性
```

**模式B：独立数字化中心（适合200+店）**

```
              CEO
               │
    ┌──────┬───┴───┬──────┐
    │      │       │      │
  运营VP  CIO     CFO    CMO
          │
   ┌──────┴──────┐
   │             │
  数字化委员会    │
   │             │
   ├─ 产品与架构(5-10人)
   ├─ 数据与AI(8-15人)
   ├─ 基础运维(5-10人)
   ├─ PMO与实施(3-5人)
   ├─ 信息安全(2-3人)
   └─ 业务伙伴(每业务线1人)

优势：独立决策、专业分工、前瞻性规划
劣势：可能与业务脱节（需要用业务伙伴角色来弥补）
```

## Step 3: 关键岗位定义

### 餐饮行业特有的数字化关键岗位

#### 1. 数字化业务伙伴（Digital BP）

这是最容易被忽略但最重要的岗位。

| 维度 | 说明 |
|------|------|
| 职责 | 不写代码。深入业务一线（门店+供应链），把业务的"痛"翻译成IT的"需求" |
| 汇报给 | 双线汇报：实线→CIO，虚线→业务VP |
| 要求 | 懂业务>懂技术。做过餐饮门店运营的比纯IT出身的好10倍 |
| 配置 | 每1-2个业务线配1人 |
| 典型任务 | "区域经理说外卖单接不过来，我去门店看了3天发现是高峰期打印机卡纸→不是系统问题是硬件问题" |

#### 2. 餐饮数据分析师

| 维度 | 说明 |
|------|------|
| 职责 | 从POS/CRM/外卖/进销存数据中找到"什么菜品该下架""哪个门店有异常" |
| 要求 | SQL+Excel+BI工具+餐饮业务sense |
| 典型产出 | "过去30天销量Top10和利润率Top10交叉对比→发现3个高销量低利润菜品→建议提价或减量" |

#### 3. 连锁系统实施经理

| 维度 | 说明 |
|------|------|
| 职责 | 负责新系统在门店的推广实施——不是"技术部署"，是"教店长用好系统" |
| 要求 | 做过门店运营管理+会用系统+有耐心 |
| 典型任务 | "本周我要去西南区5家店做系统上线培训，带着3个问题回来优化" |

## Step 4: 激励机制设计

### 把数字化纳入KPI

| 角色 | 数字化相关KPI | 权重 |
|------|-------------|:---:|
| 店长 | "系统操作准确率"、"每日数据录入完整度" | 5-10% |
| 区域经理 | "区域系统活跃度"、"数据质量评分" | 10-15% |
| 运营总监 | "数字化覆盖率"、"系统使用率"、"人效提升" | 15-20% |
| CIO/数字化负责人 | "数字化项目ROI"、"系统可用率"、"门店数字化满意度" | 核心KPI |

### 激励方式

| 方式 | 适用对象 | 具体做法 |
|------|---------|---------|
| 正向奖金 | 全体 | "数字化标杆门店"月奖500-2000元 |
| 技能工资 | 店长/厨师长 | 通过系统操作考核后→工资+200元/月 |
| 晋升关联 | 区域经理 | 系统推广成绩好的区域经理优先晋升 |
| 荣誉激励 | 全体 | "数字化先锋"在全公司通报表扬 |
| 负向约束 | 反复不配合的 | 连续3个月数据质量不达标→影响绩效评分 |

> 关键原则：**先奖后罚**。第一年只用正向激励，等大多数人都接受了再引入负向约束。

## Step 5: AI组织建设

### AI组织成熟度阶梯

| 阶段 | AI组织形态 | 适用规模 | 说明 |
|------|-----------|:---:|------|
| 认知期 | 无组织，个人兴趣驱动 | 1-50店 | 老板自己刷AI新闻 |
| 探索期 | 1-2个"AI Champion"（兼职） | 10-100店 | 对AI有热情的运营/IT人员兼职探索 |
| 应用期 | 3-5人AI小组（专职）| 50-500店 | 数据工程师+ML工程师+业务分析师各一 |
| 平台期 | 10-20人AI团队（独立部门）| 200-2000店 | AI负责人+算法+数据+工程+产品 |
| 原生期 | AI卓越中心+业务线AI Ambassador | 500-10000+店 | 集中平台+分布应用 |

### AI Champion画像

选谁当AI Champion？

- ✅ 对新技术有好奇心（自己会用ChatGPT/DeepSeek/Kimi）
- ✅ 懂业务（知道门店痛点在哪里）
- ✅ 在公司有2年以上经验（了解公司文化）
- ❌ 不一定是技术背景
- ❌ 不一定是学历最高的

## Step 6: 数字化人才培养

### 培养路径

| 阶段 | 培养内容 | 方式 | 周期 |
|------|---------|------|:---:|
| 新手 | 餐饮业务基础+系统操作 | 轮岗(门店1个月) | 1-3月 |
| 合格 | 需求分析+数据建模+系统选型 | 跟项目+认证 | 6-12月 |
| 骨干 | 架构设计+项目管理+供应商管理 | 独立带项目 | 1-3年 |
| 专家 | 数字化战略+组织变革+AI应用 | 跨行业学习+行业交流 | 3-5年 |

### 人才来源

| 来源 | 优势 | 劣势 | 适合什么 |
|------|------|------|---------|
| 从运营/门店提拔 | 最懂业务 | 需要补技术 | 需求分析、项目实施 |
| 从互联网公司招聘 | 技术强 | 不懂餐饮"大排档文化" | 研发、架构 |
| 从同行挖 | 最对口 | 贵、可能带的经验不适用 | 快速建立 |
| 从咨询公司招聘 | 方法论强 | 缺一线手感 | 战略、PMO |
