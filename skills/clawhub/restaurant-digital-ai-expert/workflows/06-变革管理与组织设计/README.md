# 06-变革管理与组织设计

数字化成功的最大障碍不是技术，是人和组织。项目失败70%的原因在变革管理。

## 子流程

| # | 流程 | 产出 |
|---|------|------|
| 01 | 变革管理策略 | ADKAR分析+沟通计划+利益相关者地图 |
| 02 | 数字化组织设计 | 数字化组织架构+岗位+激励机制 |

## 关键原则

- **变革不是培训**：教会人用系统是培训，让人愿意用系统是变革管理 — 两者完全不同
- **让店长赚到钱**：店长不用系统，90%是因为"用了系统不增加收入只增加工作量"
- **组织能力先于技术能力**：先解决"谁负责"的问题，再解决"用什么系统"的问题
- **老板必须冲在最前面**：如果老板不用系统看报表，店长为什么要用系统填数据？
