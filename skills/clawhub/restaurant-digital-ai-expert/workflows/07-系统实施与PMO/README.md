# 07-系统实施与PMO

从规划到落地。实施阶段是数字化项目"见真章"的时刻。

## 子流程

| # | 流程 | 产出 |
|---|------|------|
| 01 | 实施方法论与PMO | 项目章程+治理结构+风险管理 |
| 02 | 系统上线与验收 | 上线Checklist+UAT+验收报告 |

## 关键原则

- **上线≠成功，验收≠结束**：系统上线只是开始，真正要看到的是"店长每天在用、数据每天在跑"
- **分批上线，绝不一刀切**：不管多少家店先上1家，验证了再上10家，验证了再铺开
- **高峰时段不动系统**：午市(11:00-14:00)和晚市(17:00-21:00)绝对不做系统变更
- **永远有回滚方案**：任何时候系统变更都要有"30分钟内回滚到上一个版本"的能力
