# 餐饮科技选型决策矩阵

## 使用说明

1. 先确定你需要的品类（POS/会员/外卖/排班/...）
2. 列出你的核心需求清单
3. 圈定3-5家候选供应商
4. 用本矩阵逐个评分
5. 重点考察：业态匹配度+TCO+API开放性

## 决策检查清单（最终确认前必做）

- [ ] 至少看了2家供应商的演示
- [ ] 至少给1家做过PoC（真实门店测试2周+）
- [ ] 至少与2个已使用该供应商的同业态客户交流过
- [ ] 合同中明确了数据所有权（归你）
- [ ] 合同中明确了退出条款和数据迁移支持
- [ ] 合同中明确了续费涨幅上限
- [ ] 店长和一线员工参与了评估（不是老板一个人拍板）
- [ ] 计算了5年TCO（而非只看首年价格）
