## 第二步：RICE+评分

每个维度1-5分：

| 分数 | R 覆盖范围 | I 业务影响 | C 可行性 | E 难度(越低越好) | +AI适配 |
|:---:|------|------|------|------|------|
| 1 | 个别岗位 | 年化<5万 | 技术不成熟 | >12月/>200万 | 不用AI更好 |
| 2 | 1-2门店 | <1%改善 | 少量案例 | 6-12月/50-200万 | AI有帮助 |
| 3 | 30-60%门店 | 1-5%改善 | 多个案例 | 3-6月/20-50万 | AI最优之一 |
| 4 | 60-90%门店 | 5-15%改善 | 技术成熟 | 1-3月/5-20万 | AI最佳方案 |
| 5 | 全部门店 | >15%改善 | 有现成产品 | <1月/<5万 | 非AI不可 |

评分：

| 场景 | R(25%) | I(30%) | C(20%) | E(15%) | +AI(10%) | **总分** | 排序 |
|------|:---:|:---:|:---:|:---:|:---:|------|:---:|
| | | | | | | | |
| | | | | | | | |
| | | | | | | | |
| | | | | | | | |

> E分越高表示越难，总分中应取(6-E)或类似方式转换为正向。

## 第四步：实施路线建议

### 如果选了1个P0场景：
```
Week 1-2: 数据准备+供应商/团队确定
Week 3-6: MVP开发+内部测试
Week 7-8: 1-2家门店灰度
Week 9-12: 效果评估→优化→扩店
```

### 如果选了2-3个P0场景：
```
Month 1-2: 场景1（最快见效果的）→跑通→产出
Month 2-4: 场景2（复用场景1的经验和方法论）
Month 3-6: 场景3
```

> **Golden Rule**：宁可1个场景做到极致（使用率>80%、ROI跑正），不要3个场景都做60分。

## 典型产出

完成评分后，输出：
1. **优先级矩阵**（P0/P1/P2/P3）
2. **每个P0场景的1页ROI估算**
3. **3个月实施计划**
4. **成功度量指标定义**

---

> **提醒**：AI不是目的，ROI才是。评分再高的AI场景，如果ROI算不过来，也不值得做。反过来，ROI高的场景哪怕评分一般，也值得认真评估。
