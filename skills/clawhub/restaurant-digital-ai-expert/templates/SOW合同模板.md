## 7. 双方责任

### 甲方责任
- [ ] 指定项目经理（唯一接口人）
- [ ] 提供必要的工作环境（门店WiFi/设备/场地）
- [ ] 按时完成数据准备（菜品/会员/供应商主数据）
- [ ] 组织相关人员参加培训和UAT
- [ ] 推动门店执行上线计划
- [ ] 按时付款

### 乙方责任
- [ ] 指定项目经理（唯一接口人，项目期间不更换）
- [ ] 按合同时间和质量标准交付
- [ ] 保证核心项目人员稳定（更换须甲方同意）
- [ ] 完成培训并确保考核通过
- [ ] 按SLA响应和解决问题
- [ ] 数据安全：不得泄露/出售甲方数据

## 8. 数据与知识产权

### 8.1 数据归属

| 条款 | 说明 |
|------|------|
| 数据所有权 | 甲方业务数据(会员/订单/菜品/门店等)归甲方所有 |
| 数据使用权 | 乙方仅在提供服务范围内使用甲方数据 |
| 数据导出 | 甲方可随时导出完整数据（合同期内+合同到期后30天内） |
| 数据删除 | 合同终止后，乙方应在30天内删除所有甲方数据（并提供删除确认） |

### 8.2 知识产权

| 条款 | 说明 |
|------|------|
| 乙方标准产品 | 知识产权归乙方 |
| 甲方定制开发 | 知识产权归甲方（源代码交付） |
| 联合开发 | 共同拥有，使用不受限 |

---

## 9. 保密条款

- 甲乙双方对合同金额、商业秘密、技术资料负有保密义务
- 保密期：合同期内+合同终止后3年
- 乙方不得将甲方的运营数据用于任何非本合同目的（包括不做乙方PR案例甲方未同意）

---

## 10. 合同期限与终止

| 条款 | 说明 |
|------|------|
| 合同生效 | 双方签字盖章之日起 |
| 合同期限 | XX年（从生效日起） |
| 提前解约 | 任意一方提前90天书面通知 |
| 甲方发起解约 | 按交付完成进度结算，乙方配合数据迁移 |
| 乙方违约解约 | 甲方有权立即解约+要求全额退款或等额赔偿 |
| 合同到期 | 如需续约，期满前60天协商 |

---

## 11. 不可抗力

- 自然灾害/战争/政策/疫情等不可预见的客观情况
- 受影响方需7天内通知对方
- 双方协商延期或调整

## 13. 违约责任

| 违约情形 | 责任 |
|---------|------|
| 乙方未能按期交付 | 每延迟1周，扣合同额0.5%，最高扣10% |
| 乙方交付质量不达标 | 限期修复，3次未通过→甲方可解约+退款 |
| 甲方未能按期付款 | 每延迟1周，追加0.5%滞纳金 |
| 乙方数据泄露 | 全额退款+赔偿甲方实际损失+甲方有权立即解约 |
| 乙方随意更换核心人员 | 每换1人扣合同额2% |
