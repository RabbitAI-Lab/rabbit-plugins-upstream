# AI场景优先级评分卡

## 使用说明

对每个候选AI场景，按5个维度打分（1-5分），加权得出总分。总分用于优先级排序。

## 各维度评分标准

### R - Reach 覆盖范围（1-5）
| 分数 | 标准 |
|:---:|------|
| 1 | 仅影响个别岗位/偶尔使用 |
| 2 | 影响1-2个门店/部门 |
| 3 | 影响30-60%门店 |
| 4 | 影响60-90%门店 |
| 5 | 影响所有门店/顾客/员工 |

### I - Impact 业务影响（1-5）
| 分数 | 标准 |
|:---:|------|
| 1 | 无显著财务影响 |
| 2 | 年化收益<5万或<1%成本节省 |
| 3 | 年化收益5-30万或1-5%改善 |
| 4 | 年化收益30-100万或5-15%改善 |
| 5 | 年化收益>100万或>15%改善 |

### C - Confidence 可行性（1-5）
| 分数 | 标准 |
|:---:|------|
| 1 | 技术不成熟、无成功案例 |
| 2 | 有少量案例，但行业不确定 |
| 3 | 行业有多个成功案例 |
| 4 | 技术成熟、数据就绪、团队有能力 |
| 5 | 已有SaaS产品可直接购买使用 |

### E - Effort 实施难度（1-5，越低越好）
| 分数 | 标准 |
|:---:|------|
| 1 | 1个月内、<5万元、无阻力 |
| 2 | 1-3个月、5-20万元 |
| 3 | 3-6个月、20-50万元 |
| 4 | 6-12个月、50-200万元 |
| 5 | >12个月、>200万元、变革阻力大 |

### +AI适配度（1-5）
| 分数 | 标准 |
|:---:|------|
| 1 | 规则引擎/人工更合适 |
| 2 | AI有帮助但不是最强方案 |
| 3 | AI是最优方案之一 |
| 4 | AI是明显最佳方案 |
| 5 | 非AI不可，传统方法完全不行 |

---

## 优先级建议

| 总分 | 优先级 | 行动 |
|:---:|:---:|------|
| >4.0 | **P0 立即启动** | 本周立项，下月MVP |
| 3.5-4.0 | **P1 短期优先** | 1-3个月内启动 |
| 3.0-3.5 | **P2 中期布局** | 3-12个月内评估 |
| <3.0 | **P3 观望/放弃** | 不定期重新评估 |
