# 项目实施计划模板

## 使用说明
本模板用于制定餐饮数字化项目的详细实施计划。适用于合同金额>50万或涉及>10家门店的项目。

## 8. 变更控制

### 变更请求流程

```
任何人提出变更请求 → 填写《变更申请表》
  → PM评估（影响：范围/时间/成本/质量）
    → 变更金额/时间影响 < 预算×5%且影响 < 1周
      → PM可自主决定
    → 变更金额/时间影响 > 预算×5%或影响 > 1周
      → 提交指导委员会审批
```
