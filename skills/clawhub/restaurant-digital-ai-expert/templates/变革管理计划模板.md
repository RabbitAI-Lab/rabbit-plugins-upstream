# 变革管理计划模板

## 使用说明
适用于数字化系统上线时的人员变革管理。填写本模板前请先完成利益相关者分析。

## 5. 阻力管理

### 典型阻力预判与应对

| 可能出现的阻力 | 谁会这么说 | 应对策略 | 谁来沟通 |
|-------------|-----------|---------|---------|
| "我太忙了，没时间学" | 店长/厨师长 | “正因为你忙，才需要用系统省时间。学会了每天反而不忙。” | 运营总监 |
| "我年纪大了，学不会" | 老店长/老厨师 | “只用学3个你每天都要做的事，手机点两下就行” | 超级用户(同龄) |
| "系统老卡，不好用" | 各种（借口+实际）| 立即查原因——是网络/硬件/还是系统问题 | IT |
| "用了系统也没多赚钱" | 店长 | “XX店用了以后人效提升了15%，省出来的就是赚的” | 标杆店长 |
| "我们原来不是挺好的" | 业绩好的店长 | “没有否定原来的做法，只是让好的变得更好” | 运营总监 |
| "这是总部来监视我们的" | 店长/厨师长 | 1对1：“真不是。你看老板现在开会还骂你吗？他要的是数，不是盯着你。” | 运营总监 |

### 阻力升级路径

```
轻度抵触（口头抱怨）
  → 同伴说服 + 标杆案例 + 给台阶下
  → 1-2周内关注

中度抵触（不参加培训/不用系统）
  → 1对1谈话 + 了解真实原因 + 解决实际问题
  → 如果是不合理要求 → 明确"这是工作的一部分"

重度抵触（煽动他人抵制/故意破坏）
  → 区域经理/运营总监出面谈话
  → 屡教不改 → 按公司制度处理（但这是最后的选择，99%不会到这里）
```
