# 案例3：茶饮连锁品牌的供应链数字化

## 背景

| 项目 | 内容 |
|------|------|
| **品牌** | 茶X（化名） |
| **类型** | 茶饮连锁/加盟为主 |
| **规模** | 200+加盟店，12家直营 |
| **定位** | 中端茶饮，二三四线城市为主 |
| **单店月均营收** | 8-15万 |
| **年营收(品牌方)** | ~2亿（含供应链收入） |

## 数字化前的痛点

### 场景1：加盟商偷偷外采
核心原料（茶叶/奶盖粉/珍珠）应该总部统一供应，但总有加盟商找便宜替代品——口味不一致→顾客差评→品牌受损。总部发现不了，发现时已经坏了几十单点评。

### 场景2：库存要么多要么缺
加盟商每次订货靠"拍脑袋"——旺季怕断货囤多了过期，淡季不敢订但促销时又不够卖。总部仓库同样——备货太多占资金、备货少了被加盟商骂。

### 场景3：新品上市像打仗
出一款新品：总部定价格→通知200个加盟商→寄样品→等反馈→确定配方→统一配送——全程靠微信群+Excel，一次新品上市从决定到门店开卖至少1个月。竞品半个月就上了。

### 场景4：食品安全风险看不见
加盟商后厨的食材效期、冷藏温度？总部完全不知道。食安一直是老板最大的焦虑。

## 数字化方案

### 核心策略：供应链优先于门店数字化

**为什么供应链优先？**
- 加盟商最愿意用的数字化是帮他"省钱"的（供应链比POS更得人心）
- 供应链是品牌的生命线（口味一致性+食品安全）
- 总部能从供应链赚钱（这是商业模式的根基）

### 系统架构

```
供应商 → 总部仓(自建+租用) → 区域中转仓 → 门店
  │            │                   │          │
  └────────────┴────供应链系统(SCM)────────────┘
               │
               ├── 采购管理：供应商比价+自动下单+品质追溯
               ├── 仓储管理：WMS（总仓+区域仓）
               ├── 订货平台：加盟商APP/小程序一键订货
               ├── 配送管理：TMS冷链物流跟踪
               ├── 效期管理：IoT温度标签+效期预警
               └── 数据中心：采购分析+需求预测+加盟商订货行为分析
```

### 实施分步

| 阶段 | 时间 | 动作 | 投入 |
|------|:---:|------|------|
| **1. 订货平台** | M1-M3 | 加盟商订货APP上线，替代微信群订货 | 30万 |
| **2. WMS仓库** | M2-M4 | 总仓WMS上线，出入库条码化 | 25万 |
| **3. 效期IoT** | M4-M6 | 冷藏设备温度传感器+效期标签（50家试点） | 40万 |
| **4. TMS配送** | M5-M7 | 冷链配送实时追踪+签收 | 30万 |
| **5. AI预测** | M7-M12 | AI需求预测（总仓+TOP 50加盟商） | 35万 |

## 效果

### 18个月后的数据

| 指标 | 之前 | 之后 | 变化 |
|------|:---:|:---:|:---:|
| 核心原料外采率 | ~15%（估算） | <3%（系统追踪） | **-80%** |
| 加盟商订货效率 | 微信群几小时回复 | APP 2分钟 | **-95%时间** |
| 总仓库存周转天数 | 45天 | 28天 | **-38%** |
| 门店缺货率 | 12% | 3% | **-75%** |
| 新品上市周期 | 4-6周 | 1-2周 | **-67%** |
| 食材浪费率 | 8% | 3.5% | **-56%** |
| 食安违规（抽查发现） | 8起/年 | 1起/年 | **-87%** |
| 加盟商续约率 | 72% | 88% | **+16pp** |
| 总部供应链收入 | 1.2亿 | 1.6亿 | **+33%**（多卖核心原料） |

### 加盟商感知
- "订货就像在淘宝买东西，方便" —— 加盟商
- "以前订货靠猜，现在APP告诉我建议订多少" —— 加盟商
- "我们家的货效期快到了APP会自动提醒" —— 加盟商

## 经验教训

### 做得对的
1. **供应链优先于POS**：加盟商最愿意用供应链（帮他省钱），从这切入无阻力
2. **用IoT管食安**：传感器比人可靠，而且24小时不偷懒
3. **数据对加盟商开放**：加盟商能看到自己的订货历史、同区对比、建议订货量
4. **AI预测分阶段上**：先在TOP 50店跑稳了再全量

### 如果能重来
1. 应该更早建区域中转仓——总仓到加盟商直达冷链成本高
2. 效期IoT应该先做温度再做完备的标签追溯（一步到位太贵）

## 通用启示

> 对于靠供应链赚钱的连锁品牌，**供应链数字化不是IT项目，是商业模式升级**。先让加盟商"用供应链能省钱"，再去推其他系统时阻力就小得多。总部最核心的数字化第一个系统不一定是POS——可能是供应链。
