# 案例2：区域火锅品牌的数字化升级

## 背景

| 项目 | 内容 |
|------|------|
| **品牌** | 蜀X火锅（化名） |
| **类型** | 川味火锅/区域连锁 |
| **规模** | 8家直营，3家加盟 |
| **单店面积** | 300-500㎡ |
| **单店座位** | 120-180位 |
| **客单价** | 90-120元 |
| **年营收** | ~4000万（8家直营） |

## 数字化前的状态

### 场景还原
- **排队混乱**：周末等位1-2小时是常态，但全靠前台一个本子+人工喊号
- **点餐效率低**：纸质菜单翻来翻去+服务员手写+跑到POS机录入，高峰期一桌点下来10分钟
- **会员靠缘分**：积分卡发了没人记得带、储值靠服务员口头推、"老客和新客一个待遇"
- **后厨节奏靠嗓子**：催菜的、催锅底的、加菜的——后厨完全靠人声传信息
- **每家店POS不一样**：8家店用了3种POS（历史原因），数据汇总靠Excel手工拼
- **加盟商看不到数据**：总部对加盟店的经营状况一无所知

### R-DMM评估：L2.3
- 技术力：2.0 —— 有POS但不统一
- 运营力：2.0 —— 有流程但全靠人
- 数据力：2.0 —— 有数据但拼不起来
- 组织力：3.0 —— 老板有意识，愿意花钱
- 客户力：3.0 —— 有基础会员

## 数字化方案

### Phase 1：统一平台+前厅效率（6个月，投入60万）

| 动作 | 内容 | 投入 |
|------|------|------|
| **统一POS** | 8家直营+3家加盟统一换成天财商龙 | 30万 |
| **排队系统** | 美味不用等+预点餐（等位时扫码先点锅底）[注：美味不用等为排队场景早期领先者(已纳入阿里体系)，当前主推美团排队/大众点评排队（已于2026-07标注）] | 8万 |
| **扫码点餐** | 桌贴二维码（一桌一码），减少菜单翻找 | 5万 |
| **KDS厨房显示** | 后厨配KDS屏（分热菜/凉菜/小吃/锅底），替代纸质单 | 8万 |
| **基础会员** | 等级+积分+储值（储值返10%） | 含POS |
| **培训** | 全员培训+上线支持 | 9万 |

### Phase 2：数据打通+AI能力（6个月，投入40万）

| 动作 | 内容 | 投入 |
|------|------|------|
| **统一数据看板** | 接帆软BI，11家门店每日数据自动汇总 | 15万 |
| **AI排班** | 接入餐行健排班，基于历史客流自动排 | 8万 |
| **加盟商看板** | 加盟商能看到自己的排名、经营诊断 | 12万 |
| **舆情监控** | AI监控大众点评+美团差评，自动预警 | 5万 |

### 不做的事情
- ✗ 不搞AI语音点餐（火锅点餐本身有社交属性，人工点餐+扫码点餐够用）
- ✗ 不做后厨机器人（火锅后厨复杂度远低于正餐）

## 实施过程

### 关键里程碑

| 时间 | 事件 | 关键决策 |
|------|------|------|
| M1 | 选定天财商龙、签约 | 老板亲自参与选型，带了2个店长一起看演示 |
| M2 | 在生意最差的1家店试点 | 聪明：选坏店试点，成了是惊喜，不成损失最小 |
| M3 | 试点成功，开始复制 | 扫码点餐占比从0到65%，翻台率从2.1→2.5 |
| M4-M5 | 8家直营全部上线 | 按"最配合的店长优先"排期，先做"标杆店" |
| M6 | 加盟商推广开始 | 第一家加盟商用"供应链优惠"吸引自愿上系统 |
| M8 | AI排班上线 | 先跑3个月"建议"模式（系统建议+人工决定） |

### 变革管理亮点
1. **"数字化不是裁人"**：老板在全员大会上明确——上了系统不减人，只是让每个人少干杂活
2. **店长PK赛**：上线第二个月搞"扫码点餐占比PK"，前3名拿奖金
3. **加盟商"利诱"**：主动上系统的加盟商，总部供应链返利多1%
4. **阿姨友好**：给年纪大的服务员每人配一个"数字化徒弟"（年轻人）

## 效果

### 12个月后的数据

| 指标 | 之前 | 之后 | 变化 |
|------|:---:|:---:|:---:|
| 翻台率 | 2.1 | 2.7 | **+29%** |
| 扫码点餐占比 | 0% | 72% | 高峰期人手压力大降 |
| 客单价 | 95元 | 112元 | **+18%**（扫码点餐推荐加购） |
| 会员储值 | 0 | 300万/年 | 锁定了核心客群 |
| 人力成本率 | 24% | 21% | **-3pp** |
| 食材成本率 | 38% | 36% | **-2pp**（进销存精准管控） |
| 等位流失率 | 25% | 12% | **-52%**（排队系统+预点餐） |
| 外卖收入 | 0 | 多开一条外卖线 | 增量 |
| 对账时间 | 店长每天1小时 | 自动 | **-100%** |

### ROI
- 总投入：100万
- 年化节省+增收：约180万
- 回收期：~7个月
- 3年ROI：~540%

## 经验教训

### 做得对的
1. **"坏店先试"原则**：在生意最差的店试点，失败了损失可控
2. **老板亲自推**：数字化项目老板不亲自下场=注定失败
3. **加盟商先用好处吸引**：不说"你要用"，说"用了能省钱"
4. **培训投入=系统投入的30%**：舍得在培训上花钱

### 如果能重来
1. 应该更早做加盟商推广规划——直营跑通后才开始想加盟商怎么用
2. 应该提前做WiFi改造——老店的网络经常高峰期掉线

## 通用启示

> 火锅数字化的关键是**排队长、点餐慢、会员散**这三个痛点。解决这3个，ROI已经跑正了80%。至于AI、IoT——那是有了前3个基础之后的事。
