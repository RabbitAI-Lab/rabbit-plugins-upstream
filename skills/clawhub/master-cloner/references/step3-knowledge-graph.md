# Step 3：结构化知识图谱

目标：将解构后的概念体系转化为 AI 可理解和执行的结构化知识。

## 3.1 构建 4 层知识层级

```
Level 1 - 核心原则层（3-5条）
  │   大师不可妥协的底层原则
  │   → Agent在任何场景下都必须遵循
  │
Level 2 - 方法论层（5-10条）
  │   基于核心原则推导的分析/判断方法
  │   → Agent作为主要分析框架
  │
Level 3 - 场景应用层（10-20条）
  │   具体场景下的操作建议
  │   → Agent作为行动参考
  │
Level 4 - 边界警示层（5-10条）
      大师思想的边界/局限/注意事项
      → Agent必须诚实说明的内容
```

## 3.2 设计决策触发矩阵

为每个场景定义结构化的判断逻辑：

```
场景：[具体场景描述]
触发条件：[什么情况下需要用到这个判断]
输入维度：
  1. [需要了解的信息维度1]
  2. [需要了解的信息维度2]
  3. [需要了解的信息维度3]
判断规则：
  - 规则A：如果[条件1]，则[判断结论]
  - 规则B：如果[条件2]，则[判断结论]
输出要求：
  - 行动建议（具体、可执行）
  - 依据说明（引用大师原话）
  - 注意事项（边界条件）
  - 置信度（高/中/低）
```

## 3.3 隐性知识显性化清单

| 隐性知识类型 | 显性化方法 | 说明 |
|------------|----------|------|
| 直觉判断 | 反向推导案例 → 提取规则 | 从大师对不同情境的不同回应中提取判断标准 |
| 度的把握 | 定义区间+边界条件 | 定义过度与不足的边界，给出最优区间 |
| 情境适应 | 列举典型情境+对应策略 | 不同身份/角色/场景下的行为准则矩阵 |
| 综合权衡 | 构建权重评估框架 | 多原则冲突时的优先级排序规则 |
