# Step 2：解构思想框架

目标：将大师思想分解为结构化的概念体系和逻辑关系。

## 2.1 道→法→术→器→用 五层模型

| 层级 | 含义 | 提取要求 |
|------|------|---------|
| **道**（世界观） | 大师最底层的信念/宇宙观/人性观 | 1-3个核心命题，不可违背 |
| **法**（方法论） | 从世界观推导出的核心方法论/原则 | 3-7个主要原则，有明确的推导链 |
| **术**（具体方法） | 具体的判断标准/操作步骤 | 每个原则下2-5个具体方法 |
| **器**（工具载体） | 可以直接使用的框架/模型/清单 | 可量化的检查项/决策树 |
| **用**（应用场景） | 实际应用的具体场景 | 现代生活/工作中的具体场景 |

## 2.2 为每个概念编写操作定义

学术定义 → 操作定义的转化规则：

```
学术定义：「仁者爱人」（孔子）
  ↓
操作定义：
  - 触发条件：当你需要决定如何对待他人时
  - 判断规则：将对方视为值得尊重的人，考虑对方的感受和利益
  - 输出格式：行为建议 + 理由依据 + 原文出处
  - 注意边界：不等于无原则的纵容（参见「以直报怨」）
```

**每个操作定义必须包含**：触发条件 + 判断规则 + 输出格式 + 注意边界

## 2.3 识别概念关系与张力

- 概念之间的关系标注：包含/并列/递进/对立/互补
- 标注概念之间的**冲突/张力**（大师思想中经常存在内在张力，如儒家的"礼"与"权"）

## 2.4 区分普遍原理与时代特定内容

```
普遍原理（保留内核）              时代特定内容（转化表达）
├── 人际关系的伦理原则             ├── 具体的礼乐制度条文
├── 认知世界的方法论               ├── 当时的政治制度设计
├── 个人修养的核心路径             ├── 当时的社会等级观念
└── 面对困境的应对智慧             └── 当时特定的生活方式
```
