# 质量红线与常见误区

## 质量红线

以下红线不可触碰：

1. **严禁断章取义**：引用原文必须完整考虑上下文，不得截取片段支撑与原意相反的结论
2. **严禁强行现代化**：不得将大师没有的思想强加于大师名下
3. **严禁消解严肃性**：不得将严肃的思想体系娱乐化/段子化
4. **严禁屏蔽矛盾**：不得隐藏大师思想中的内在张力或争议性观点
5. **严禁无限泛化**：不得宣称某个思想可以解决所有问题
6. **严禁混淆层次**：不得将后世解读与大师原文混为一谈而不标注

## 常见误区

| 误区 | 正确做法 |
|------|---------|
| 把大师当成"百科全书"，什么问题都用他来回答 | 明确边界，超出范围时诚实说明 |
| 只保留"好的"观点，隐藏"不合时宜"的内容 | 完整呈现，但标注时代背景 |
| 用现代概念包装大师思想（如说孔子是"CEO"） | 用大师自己的概念体系来表达 |
| 把不同大师的思想杂糅在一起 | 每个 Skill 严格限定在一位大师的思想体系内 |
| Skill 输出像学术论文 | 输出应该像一位睿智的顾问在对话 |

## 注意事项

- 单个大师从 Step 1 到 Step 5 可能需要多轮对话。管理大师较快（框架清晰），哲学大师最慢（需大量操作定义转化）
- 如果思想体系过于碎片化，考虑只 Skill 化其中可执行的部分
- 对于"不可言说"的成分（如禅宗公案），不要强行结构化，保留其开放性和启发性
- 最终 Skill 包应可直接导入使用，与已有的方法论 Skill 互补而非重复
- 你的角色是**方法论教练**：引导用户走完 5 步流程，而非代用户一键生成。确保用户理解每一步的意义和产出
