# Step 1：选择理论源头

目标：确定可靠的思想来源，划定 Skill 的知识边界。

## 1.1 帮助用户梳理文本层级

```
第一优先级（权重70%）：一手原著
├── 大师亲笔著作
├── 弟子记录的大师原话（如《论语》中标注"子曰"的部分）
└── 大师亲审的讲义/书信

第二优先级（权重20%）：权威二手资料
├── 同时代可信弟子的整理/注释
├── 历史上公认的权威注疏
└── 当代权威学者的系统性研究

第三优先级（权重10%）：辅助参考
├── 传记、历史背景资料
├── 其他学派对大师的评价（对比视角）
└── 现代应用案例
```

## 1.2 确认大师基本信息

| 维度 | 需明确的内容 |
|------|------------|
| 姓名与身份 | 谁的思想？（如孔子、老子、稻盛和夫） |
| 时代背景 | 哪个时代？什么社会环境？ |
| 思想流派 | 属于哪个学派/传统？（儒/道/法/兵/禅/现代管理学等） |
| 核心文本 | 一手原著有哪些？二手解读有哪些？ |

## 1.3 评估 AI 可执行性

在投入大量工作前，先回答：
- 这个思想体系是否有足够的**结构化框架**？（还是完全碎片化的感悟）
- 核心概念是否可以转化为**可执行的判断规则**？
- 该思想是否有**实际应用场景**？
- 原著文本或可靠解读是否**容易获取**？

如果 2 个以上回答为"否"，应诚实告知风险，建议缩小范围或放弃。

## 1.4 提取核心命题

从原文中提取大师的**核心命题**：
- 每个命题用一句话表述
- 标注原文出处（书名、篇名、原文）
- 说明在整体思想中的权重地位（核心/支撑/补充）

## 1.5 界定思想边界

明确回答：
- 这个思想体系**擅长回答什么类型的问题**
- **不擅长或没有涉及什么问题**
- 哪些内容具有**时代局限性**（标注但不丢弃）
- 哪些是**跨越时代的普遍原理**

## Step 1 交付物模板

```
【大师名称】思想来源与边界评估报告
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
一、核心文本清单（含权重）
二、核心命题列表（含原文出处）
三、思想边界界定
四、AI可执行性评估结论
五、建议的Skill范围与子Skill划分
```
