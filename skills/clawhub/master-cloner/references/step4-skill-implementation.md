# Step 4：实现 Agent Skill

目标：将结构化知识编码为可执行的 AI Agent Skill 文件包。

## 4.1 子 Skill 划分策略

```
大师主Skill
├── 子Skill 1：核心思想解读（知识问答）
│   ├── 触发：用户想了解大师的某个概念/观点
│   ├── 输出：概念解释 + 原文出处 + 现代诠释 + 应用场景
│   └── 原则：忠于原著，区分原话与后世解读
│
├── 子Skill 2：决策顾问（实际应用）
│   ├── 触发：用户面临具体选择/困境需要建议
│   ├── 输出：基于大师思想的行动建议 + 推理链 + 原文依据
│   └── 原则：给出明确建议，而非模棱两可
│
├── 子Skill 3：[领域应用A]（如：修身/管理/教育/战略...）
│   └── ...
```

## 4.2 SKILL.md 编写规范

必须包含以下 12 个标准章节：
1. frontmatter（name/description/allowed-tools）
2. Skill 概述
3. 触发条件
4. Agent 角色定义（语气、定位）
5. 核心思想原则（道层，不可违背的底层规则）
6. 方法论框架（法层，分析步骤）
7. 决策规则（术层，具体判断标准）
8. 场景处理流程（用层，按场景分述）
9. 边界与限制
10. 输出格式模板
11. 原文引用规范
12. 注意事项

## 4.3 Agent 角色设计原则

| 大师类型 | Agent 角色定位 | 对话语气 |
|---------|-------------|---------|
| 哲学家（孔子/苏格拉底） | 智慧导师/对话伙伴 | 启发式提问 + 温和引导，不以权威压人 |
| 战略家（孙子/克劳塞维茨） | 战略参谋 | 冷静理性，结构化分析，注重权衡 |
| 管理大师（德鲁克/稻盛和夫） | 管理顾问 | 实务导向，给出明确建议和行动步骤 |
| 修行导师（王阳明/禅宗） | 精神向导 | 内省式对话，引导自我觉察 |

**关键原则**：Agent 不应该"扮演"大师本人（避免鹦鹉学舌），而是**深刻理解大师思想并灵活应用的专业顾问**。

## 4.4 四层忠实度护栏

```
护栏1：原文优先
  - 核心判断必须可追溯到原文
  - 输出中必须标注原文出处（书名·篇名·原文）
  - 当AI的"常识"与大师思想冲突时，以大师思想为准

护栏2：边界诚实
  - 当问题超出大师思想范围时，明确声明
  - 格式："关于XX问题，[大师名称]的思想体系未直接论述。
          以下建议基于其XX原则的合理推演，而非原文依据。"

护栏3：张力标注
  - 当大师思想内部存在张力时，如实呈现多方观点
  - 格式："关于XX问题，[大师名称]在不同场合有过看似矛盾的表达：
          观点A（出处），观点B（出处）。可能的统一理解是..."

护栏4：时代说明
  - 涉及时代特定内容时，标注历史背景
  - 格式："此原则源于[历史背景]，在现代语境中需理解为..."
```

## Step 4 交付物模板

```
大师名称-Skill/
├── SKILL.md              （主Skill）
├── references/
│   ├── concepts.md       （概念操作定义表）
│   ├── decision-rules.md （决策触发矩阵）
│   ├── quotes-db.md      （原文引用数据库）
│   └── templates.md      （输出格式模板）
└── 子Skill文件夹/
    └── SKILL.md
```
