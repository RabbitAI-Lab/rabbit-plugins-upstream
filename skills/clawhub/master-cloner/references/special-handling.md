# 思想类型的特殊处理指南

## 哲学/伦理型（孔子、孟子、苏格拉底、康德）

**特征**：概念高度抽象，文本碎片化（语录/对话体），注重道德判断。

**特殊处理**：
- 必须做"操作定义转化"（最核心的工作量在此）
- 设计"道德两难判断矩阵"（多原则冲突时的处理规则）
- 重点提取大师处理矛盾的辩证智慧（如儒家的经与权）
- 案例教学法：收集大师本人的教学案例

## 战略/军事型（孙子、克劳塞维茨、毛泽东）

**特征**：天然有结构化框架，注重博弈分析，有明确的决策逻辑。

**特殊处理**：
- 框架提取相对容易，但需做"战场→商战→人生"语境转化
- 重点设计"态势评估框架"（分析维度应用于现代场景）
- 补充现代案例库
- 区分"战略原则"（普遍）与"战术建议"（时代特定）

## 修行/心学型（老子、王阳明、禅宗）

**特征**：强调直觉体验，反对概念化，有"不可言说"的成分。

**特殊处理**：
- 承认"不可言说"的部分，不强行结构化
- 重点提取"可言说"的方法论部分（如王阳明的"致良知"功夫）
- Agent 角色偏向"对话引导者"而非"答案给出者"
- 设计渐进式对话策略：先了解用户状态，再引导反思

## 管理/商业型（德鲁克、稻盛和夫、彼得·圣吉）

**特征**：面向实务，有清晰的框架和步骤，天然适合 Skill 化。

**特殊处理**：
- 框架完整性和案例丰富度是关键
- 可沿用 Kotler/BLM 等方法论框架
- 设计更多的量化评估工具
