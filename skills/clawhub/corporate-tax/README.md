# 企业财税 - corporate-tax

面向企业财务和税务人员的全栈财税工作平台。覆盖凭证编制、月结关账、财务报表、税务申报、预算分析和内部审计，支撑从日常核算到年度汇算的完整财务闭环。

## 子技能列表

| 子技能 | 功能 | 触发关键词 |
|--------|------|-----------|
| 做凭证 | 上传银行流水或费用单据，自动生成记账凭证 | 做凭证, 凭证编制, 记账, 会计分录 |
| 内部审计 | 按中国内部审计准则输出审计计划和底稿 | 内部审计, 内审, 审计底稿, 内控评价 |
| 凭证编制参考 | 常用会计分录模板和凭证编制规范，内部参考 | 分录参考, 凭证参考, 会计处理 |
| 增值税管理 | 上传进销项数据，输出税负测算和异常预警 | 增值税管理, 增值税, 进销项, 留抵退税 |
| 月结检查清单 | 生成月末关账10步检查清单 | 月末关账, 月结, 关账, 对账 |
| 汇算清缴 | 上传科目余额表，输出纳税调整明细 | 汇算清缴, 所得税, 纳税调整 |
| 财务分析 | 上传财务报表，输出五维分析报告 | 财务分析, 杜邦分析, 比率分析 |
| 财务报表编制 | 按CAS编制资产负债表、利润表和现金流量表 | 财务报表编制, 财务报表, 三张表 |
| 预算分析 | 上传预算和实际数据，输出差异分解和归因分析 | 预算分析, 预算, 预算执行, 预实对比 |

## 使用方法
