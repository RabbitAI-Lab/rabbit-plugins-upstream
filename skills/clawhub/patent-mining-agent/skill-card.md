## Description:

Patent Mining Agent helps enterprise R&D engineers turn a technical domain and mining objective into a structured patent-mining report using a four-block, ten-step workflow, with fast and deep modes that combine PatSnap patent data and web search across nine mining scenarios.

This skill is ready for commercial/non-commercial use.

## Use Case:

Enterprise R&D engineers, technical leads, and intellectual-property engineers use this skill to identify patentable ideas, evaluate invention concepts, and produce structured patent-mining reports from a stated technology domain and mining objective.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill asks users to confirm project details and requires those details to be retained and reproduced in final reports.

Mitigation: Do not provide secrets, unreleased invention details, sensitive company strategy, personal data, or confidential competitor assessments unless those details are approved for inclusion in generated reports.

Risk: Patent-mining outputs may depend on external patent and web search tools and can be incomplete if those tools are not configured.

Mitigation: Confirm PatSnap MCP and web-search access before relying on search-backed conclusions; otherwise treat the output as an analysis framework and mark missing evidence for follow-up.
