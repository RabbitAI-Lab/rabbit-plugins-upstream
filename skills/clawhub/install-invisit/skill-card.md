## Description:

Add invisit cookieless web analytics to a website or web app with the script tag or the @invisitdev/web npm package, then check that visits arrive. Use when asked to add invisit, privacy-friendly analytics, or a cookie-free Google Analytics alternative to a project.

This skill is ready for commercial/non-commercial use.

## Publisher:

[berkinory](https://clawhub.ai/user/berkinory)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to add invisit analytics to a website or web app, optionally track custom events, and verify that visits arrive in the dashboard.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installing the tracker changes a website and sends visitor and event data to the analytics service.

Mitigation: Review the package and proposed project changes, and confirm that the data sharing fits the site's privacy and consent requirements.
