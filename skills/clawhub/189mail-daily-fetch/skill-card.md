## Description:

Automatically log in to 189.cn mailbox, fetch the latest email, and save it as an .eml file to the desktop.

This skill is ready for commercial/non-commercial use.

## Publisher:

[xizhima](https://clawhub.ai/user/xizhima)

### License/Terms of Use:

MIT-0

## Use Case:

External users use this skill to download and archive the newest message from a 189.cn mailbox, including scheduled daily retrieval when appropriate.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Mailbox credentials and exported .eml files may expose sensitive personal or business information.

Mitigation: Use the skill only in a trusted session, provide credentials only when needed, confirm any scheduled run, and save exported email files in a private folder.
