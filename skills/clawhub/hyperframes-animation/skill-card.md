## Description:

Guides HyperFrames animation authoring with motion rules, scene blueprints, transitions, runtime adapters, and choreography audits.

This skill is ready for commercial/non-commercial use.

## Publisher:

[heygen-com](https://clawhub.ai/user/heygen-com)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and motion designers use this skill to compose deterministic, seek-safe HyperFrames animations across supported runtimes and audit existing compositions for choreography issues.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Running the animation audit may launch local browser or capture tools and temporarily install missing HyperFrames packages from npm.

Mitigation: Review the audit command before running it, and pin HYPERFRAMES_SKILL_PKG_VERSION when reproducible dependency selection is needed.
