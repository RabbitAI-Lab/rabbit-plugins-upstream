## Description:

Helps developers design and audit deterministic HyperFrames animations using motion rules, scene blueprints, transitions, and runtime-specific guidance.

This skill is ready for commercial/non-commercial use.

## Publisher:

[heygen-com](https://clawhub.ai/user/heygen-com)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and motion designers use this skill to compose seek-safe HyperFrames animations, choose appropriate browser animation runtimes, and audit composition choreography.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The optional animation-map audit may offer to bootstrap a dependency and analyze a local composition directory.

Mitigation: Review the bootstrap prompt, pin the HyperFrames package version when running outside a bundled install, and analyze only directories you intend to inspect.
