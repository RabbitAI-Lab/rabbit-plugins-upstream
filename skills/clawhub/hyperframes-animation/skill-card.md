## Description:

Guides agents in creating seek-safe HyperFrames animations using motion rules, scene blueprints, transitions, and runtime-specific patterns.

This skill is ready for commercial/non-commercial use.

## Publisher:

[heygen-com](https://clawhub.ai/user/heygen-com)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and creative teams use this skill to compose HyperFrames motion scenes, select animation patterns and runtime adapters, and audit existing choreography.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The optional animation analyzer may install temporary npm helper packages when dependencies are missing.

Mitigation: Review the packages before running the analyzer and pin HYPERFRAMES_SKILL_PKG_VERSION to control the fallback version.
