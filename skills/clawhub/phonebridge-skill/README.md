# 技能市场上架信息表（照此填写提交）

> 用途：在 WorkBuddy「技能」→「创建技能/发布到技能市场」界面，按以下字段填写提交。
> 审核通过后：普通技能 2000 积分，垂直模板 5000-10000 积分，他人使用持续分成。

## 基本信息

| 字段 | 填写内容 |
|---|---|
| **技能名称** | WorkBuddy PhoneBridge · 手机数据桥 |
| **触发关键词** | 手机数据桥、USB调试、开发者模式、手机连电脑、手机数据导出、元宝导出、微信备份、ADB抓屏 |
| **功能介绍** | 查询各种手机（小米/红米、华为/荣耀、OPPO/一加、vivo/iQOO、三星等）开启开发者模式/USB调试教程，以及元宝AI记录导出、微信聊天记录备份、通用ADB抓屏等数据导出方法，小白友好分步讲解，全部免root |
| **分类建议** | 办公效率 / 工具 |
| **适用场景** | 帮小白用户连接手机到电脑、导出手机数据、备份聊天记录 |

## 提示词模板（SKILL.md 核心内容）

技能文件：`~/.workbuddy/skills/phonebridge/SKILL.md`（已按市场标准格式写好）
核心逻辑：
1. 确认手机品牌（未说则让用户选）
2. 从站点/数据取该品牌步骤（开发者模式 → USB调试 → 品牌特有坑）
3. 按需给应用导出教程（元宝/微信/ADB）
4. 小白友好输出：路径条 + 常见问题 + 备份提醒

## 测试用例（提交前自测）

| 测试输入 | 期望输出 |
|---|---|

## 提交流程

1. WorkBuddy 打开「技能」面板 → 创建技能/我的技能 → 发布到市场
2. 按上表填写 → 上传 SKILL.md 与截图 → 提交审核
3. 审核通常 1-2 个工作日；通过后可在技能市场被搜索安装，获得积分与分成

## 注意事项

- 登录账号必须与 WorkBuddy 客户端一致（积分才入账）
- 若技能界面无「发布到市场」入口，可先在本机使用验证，再走开源仓库分发
