# powpow-register

PowPow বাবল রেজিস্ট্রেশন সহায়ক (OpenClaw সংস্করণ): একজন নতুন ব্যবহারকারীকে «বাবল কী» না জানা থেকে
«অ্যাকাউন্ট অ্যাক্টিভেট ও ব্যবহারের জন্য প্রস্তুত» পর্যন্ত পৌঁছে দিন — পণ্য পরিচিতি (ইন্টারফেস স্ক্রিনশটসহ),
ধাপে ধাপে রেজিস্ট্রেশন গাইড, ত্রুটি সমাধান, সাবস্ক্রিপশন অ্যাক্টিভেশনের বিবরণ।

সম্পূর্ণ গাইড-ধরনের skill, কোনো স্ক্রিপ্ট নেই, কোনো ডিপেন্ডেন্সি নেই; সব রেজিস্ট্রেশন কাজ ব্যবহারকারী ব্রাউজার/অ্যাপে
নিজেই সম্পন্ন করেন।

## ইনস্টলেশন

```
openclaw skills install @durenzidu/powpow-register
```

## বৈশিষ্ট্য

1. **পণ্য পরিচিতি**: প্রায় 120 শব্দের পরিচিতি + GitHub পাবলিক রিপোজিটরিতে হোস্ট করা ইন্টারফেস স্ক্রিনশটের লিংক
   (মানচিত্র পেজ, পোস্ট ডিটেইল পেজ ইত্যাদি 6টি ছবি, পরিস্থিতি অনুযায়ী 1–3টি পাঠান)।
2. **রেজিস্ট্রেশন গাইড**: ফিল্ড নিয়ম (ইউজারনেম/পাসওয়ার্ড/ইমেইল ভেরিফিকেশন কোড/মোবাইল নম্বর/প্রোফাইল ছবি),
   থার্ড-পার্টি লগইন (Google/Watcha/হুয়াওয়ে), রেট-লিমিট প্যারামিটার, সব প্ল্যাটফর্ম সোর্স কোড থেকে নেওয়া ও সোর্স উল্লেখ করা।
3. **ত্রুটি সমাধান**: ভেরিফিকেশন কোড না পাওয়া, ইউজারনেম/ইমেইল আগে থেকেই ব্যবহৃত, 403 অ্যাক্টিভেট হয়নি, অ্যাকাউন্ট
   লক ইত্যাদি 13টি সাধারণ সমস্যা।
4. **সাবস্ক্রিপশন অ্যাক্টিভেশন**: PayPal (ওয়েব) / WeChat স্ক্যান (ম্যানুয়াল নিশ্চিতকরণ) / হুয়াওয়ে IAP (HarmonyOS) তিনটি
   চ্যানেলের বিবরণ ও সমাধান; বর্তমান পেমেন্ট চেইন সরাসরি পুনরায় ব্যবহারযোগ্য, skill শুধু পথ দেখায়।

## নিরাপত্তা

- কোনো চাবি (key) থাকে না; কোনো স্ক্রিপ্ট নেই, ব্যবহারকারীর পরিচয়পত্র (credentials) স্পর্শ করে না।
- **কখনই চায় না** ব্যবহারকারীর পাসওয়ার্ড, ভেরিফিকেশন কোড বা পেমেন্ট প্রমাণ; রেজিস্ট্রেশন ও পেমেন্ট সব প্ল্যাটফর্ম
  পেজেই হয়।
