# powpow-register

PowPow বুদবুদ রেজিস্ট্রেশন সহকারী (OpenClaw skill): একজন নতুন ব্যবহারকারীকে "বুদবুদ জিনিসটা কী জানি না" অবস্থা থেকে
"অ্যাকাউন্ট অ্যাক্টিভ, ওয়ান-ক্লিক লগইন, খেলা শুরু" পর্যন্ত এগিয়ে নেয় — পণ্য পরিচিতি (ইন্টারফেস স্ক্রিনশটসহ), হয়ে করে দেওয়া
রেজিস্ট্রেশন (প্রোফাইল ছবি আপলোডসহ), অ্যালিপে/PayPal সাবস্ক্রিপশন অর্ডার তৈরি ও টাকা পৌঁছানো ট্র্যাকিং, ডুয়েল লিংকে ওয়ান-ক্লিক লগইন, এরর ট্রাবলশুটিং।

**v2.0.0 থেকে এটি একটি হয়ে-করে-দেওয়া (agent-executed) মোড, এবং v2.1.0 থেকে PayPal-ও হয়ে করা যায়**: মূল স্ক্রিপ্ট `scripts/powpow-register.mjs` জিরো-ডিপেন্ডেন্সি
(Node ≥ 18), ব্যবহারকারী সবকিছু কথোপকথনের মধ্যেই করে, মাত্র দুবার সাময়িকভাবে বাইরে যেতে হয়: ইমেইলে গিয়ে ভেরিফিকেশন কোড দেখতে,
অ্যালিপে/PayPal পেমেন্ট পেজে পেমেন্ট করতে। Node না থাকলে বা ব্যবহারকারী নিজে হাতে করতে চাইলে স্বয়ংক্রিয়ভাবে পিওর গাইড মোডে ফিরে যায়।

## ইনস্টল

```
openclaw skills install @durenzidu/powpow-register
```

## ফিচার

1. **পণ্য পরিচিতি**: ~120 শব্দের ওপেনার + স্কিলের সাথে প্যাক করা ইন্টারফেস স্ক্রিনশট (`assets/screenshots/`-এ ৬টি ছবি:
   মানচিত্র পেজ, পোস্ট ডিটেইল পেজ ইত্যাদি; প্রসঙ্গ অনুযায়ী ১–৩টি বেছে নিন; বাইরের ইমেজ হোস্ট বা ইন্টারনেট লাগে না)।
2. **হয়ে করে দেওয়া রেজিস্ট্রেশন**: agent নিজে থেকে ইউজারনেম/ডাকনাম সাজেস্ট করে, পাসওয়ার্ড দুটোর একটা বেছে নেয় (ব্যবহারকারী দেয় বা
   agent বানায়), ভেরিফিকেশন কোড পাঠায় ও জমা দেয়, প্রোফাইল ছবি সরাসরি আপলোড করে (≤5MB, SVG নয়), পরিচিত এরর স্বয়ংক্রিয়ভাবে সামলায় (দখল/মেয়াদ/লিমিট)।
3. **ওয়ান-ক্লিক লগইন (ডুয়েল লিংক)**: রেজিস্ট্রেশন সফল হলে "হালফ-লগইন" লিংক সাথে সাথে সোজা সাবস্ক্রিপশন পেজে নামায়; পেমেন্ট টাকা
   পৌঁছালে লগইন স্টেট নতুন করে নিয়ে পূর্ণাঙ্গ সদস্যপদের লিংক সোজা হোমপেজে নামায় (প্ল্যাটফর্মের পাবলিক `me?token=` ব্রিজ, HttpOnly cookie
   স্বয়ংক্রিয়ভাবে বসে যায়)।
4. **সাবস্ক্রিপশন পেমেন্ট**: অ্যালিপে (মাসিক ¥6.99 / কোয়ার্টারলি ¥19.99 / বার্ষিক ¥69.99,
   একবার কিনলে উল্লিখিত মেয়াদ, অটো-রিনিউ হয় না) ও PayPal (Premium Monthly, প্রায় $1/মাস,
   অটো-রিনিউ, যেকোনো সময় বাতিল) — দুটোতেই agent হয়ে করে অর্ডার তৈরি + টাকা পৌঁছানো পোল;
   ওয়েচ্যাট QR/হুয়াওয়ে IAP চ্যানেল দেখিয়ে দেওয়া।
5. **এরর ট্রাবলশুটিং**: ভেরিফিকেশন কোড না আসা, ইউজারনেম/ইমেইল দখলে থাকা, 403 অ্যাক্টিভ হয়নি, অ্যাকাউন্ট লক হওয়ার মতো
   পরিচিত সমস্যা — সবই প্ল্যাটফর্মের সোর্স কোড থেকে নেওয়া, উৎস চিহ্নিত করা।

## সিকিউরিটি

- **পাসওয়ার্ড** শুধু এনভায়রনমেন্ট ভ্যারিয়েবলের মাধ্যমে স্ক্রিপ্ট প্রসেসে যায়, কমান্ড-লাইন আর্গুমেন্টে কখনোই লেখা হয় না, ডিস্কে জমা থাকে না,
  স্টেট ফাইলেও ঢোকে না; agent-বানানো পাসওয়ার্ড ব্যবহারকারীকে সেভ করার জন্য ঠিক একবারই দেখানো হয়।
- **ভেরিফিকেশন কোড** শুধু পাবলিক রেজিস্ট্রেশন API-তে ব্যবহার হয়, কাজ শেষে ফেলে দেওয়া হয়; স্টেট ফাইল (ইমেইল/ইউজারনেম/token/অর্ডার নম্বর)
  সিস্টেম টেম্প ডিরেক্টরিতে থাকে, প্রসেস শেষে `cleanup` এক কমান্ডে মুছে দেয়।
- **পেমেন্ট**: agent শুধু অর্ডার তৈরি করে, পেমেন্ট পেজ খোলে, টাকা পৌঁছালো কি না চেক করে; ব্যবহারকারীর অ্যালিপে অ্যাকাউন্ট
  বা পেমেন্ট ক্রেডেনশিয়াল কখনোই স্পর্শ করে না, পেমেন্টও করে দেয় না। পেমেন্ট সবসময় ব্যবহারকারী ও অফিসিয়াল পেমেন্ট পেজের মধ্যেই হয়।
- সব রিকোয়েস্ট শুধু পাবলিক ডোমেইন `https://global.powpow.online`-এ যায়; কোনো API কী পাঠানো হয় না।
