# mifu-chemistry-lesson-prep 米赋化学专题细化课程备课 Skill

> v1.0.0 | 米赋AI教育 | MIT-0 License
> 状态：生产可用（已用「硫及其重要化合物」3课时 +「氮及其重要化合物」3课时双模块验证）

## 一句话定位

帮AI学习力教练针对**任意学段 + 任意地区 + 任意化学专题**，生产高质量的**备课教案（教练用）+ 导学案（学生用）**双产物，方法论来自8位化学名师视频逐字稿萃取。

## 解决什么问题

- 化学备课范式与数学（纯推导）、语文（概括审美）有**本质差异**，通用备课skill套不上
- 化学是**解释性学科**（先看现象→回头"编"解释）、**半文半理**（事实记忆+原理迁移）、**以方程式为轴心**
- 名师方法论散落在视频里，教练水平参差——本skill把方法论固化成流水线，人人可产出名师级教案

## Skill架构（4层）

```
第1层 设计哲学（不可变）
  化学第一性原理 + 8名师方法论（解释性学科/双笔记/方程式轴心/动态追踪/错题五分类/标准表达即分数）
第2层 化学版5步流程SOP（不可变）
  知识建构 → 方程式精研（四过关） → 专项训练（错题五分类） → 陌生情境拔高 → 验收输出
第3层 地区适配器（可替换）
  上海高考（已细化：60min/100分/2024起5道主题式综合题/沪科技版）/ 北京 / 初中（骨架）
第4层 双产物模板（统一）
  备课教案9模块 + 导学案7模块
```

## 铁律（内置，不可绕过）

1. **AI方程式三重验证**：原子守恒+电子守恒+电荷守恒，未验证的方程式禁止进教案
2. **强制手写**：转化网络空骨架策略——教练只画价态轴，边由学生课上补全
3. **模块验收**：方程式盲默100%+限时小测≥90%才算模块通关
