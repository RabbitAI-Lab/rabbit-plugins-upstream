# 学段+地区适配器

## 一、chem-gaokao-shanghai（上海高考化学）✅ 已细化

> 来源：《上海高考化学全方位调研报告》（基于上海市教育考试院官方文件/点评）

### 1.1 考试基本信息

| 项目 | 内容 |
|------|------|
| 性质 | 学业水平等级性考试（选考科目） |
| 卷面满分 | 100分，赋分后满分70分计入高考（660分制） |
| 考试时间 | **60分钟**（时间压力极大） |
| 赋分制 | 5等11级，40-70分，相邻等级差3分（A+前5%=70） |

### 1.2 试卷结构（2024年重大改革！）

| 时期 | 结构 |
|------|------|
| 2023年及以前 | 20道选择题（40分）+ 4道综合题（60分） |
| **2024年起** | **5道主题式综合题**（每题围绕一个主题：如"氟及其化合物""珊瑚礁""瑞格列奈合成"），题内混合选择/填空/简答/计算 |

**备考含义：**
- 不再有独立选择题板块——题型边界消失，元素化合物必须按"主题式"复习
- 必修约40%+选择性必修约60%
- 主题式命题=元素化合物模块的地位上升（2025年主题：锗提取/碳酸丙烯酯/福辛普利/铁探究/钨酸钙）

### 1.3 教材：沪科技版（2020版），非人教版

| 册次 | 内容 |
|------|------|
| 必修第一册 | 物质分类、原子结构、周期律、化学键、常见无机物 |
| 必修第二册 | 反应与能量、速率与平衡、有机初步、化学与可持续发展 |
| 选择性必修一 | 化学反应原理（热效应/方向限度/速率/水溶液/电化学） |
| 选择性必修二 | 物质结构与性质（原子/分子/晶体/配位） |
| 选择性必修三 | 有机化学基础 |

### 1.4 上海特色备课要点

1. **主题式教学**：模块备课以真实主题包装（如硫模块→"酸雨治理与硫酸工业"主题）
2. **实验探究贯穿**：设计方案+评价方案是高频考点，融入每个主题
3. **绿色化学评价**：对工艺路线的环保性评价是上海特色题型
4. **信息提取+迁移应用+科学评价**是三大能力侧重（定量计算要求中等）
5. **60分钟100分**：速度训练必须前置，限时训练从Step3就开始
6. **陌生情境常态**：锗、钨酸钙等陌生物质是命题载体——Step4必须有陌生情境题
7. 真实情境素材：脱硫工艺（硫模块）/珊瑚礁水体（碳酸盐/平衡）/药物合成（有机）
