# 化学版5步流程详细SOP

> 每个知识模块按5步执行。与数学5步流程同构，但每一步的内容化学化：以方程式为轴心、以字典/转化网络为工具、以动态追踪为能力目标。

## 流程总览

```
Step1 知识建构 → Step2 方程式精研 → Step3 专项训练 → Step4 拔高挑战 → Step5 验收输出
（字典+网络）    （逐条过关）      （限时+五分类）   （陌生情境迁移）  （默写100%+讲解）
```

**时间框架（以2-3课时模块为例）：**
- 课前（24h前）：Step1预习部分
- 第1次课：Step1完成+Step2主体
- 第2次课：Step2收尾+Step3
- 第3次课：Step4+Step5
- 课后（48h内）：错题回流+字典补条目

## Step1 知识建构（建字典 + 画转化网络）

**目标：** 建立"是什么+为什么"，产出v1.0笔记。

**任务：**
1. 学生按教材+教辅通读本模块，**手写**字典条目（文科型知识）或原理模型页（理科型知识）
2. 手绘本模块转化网络图（点→线→面→网），标注每条边的：方程式/条件/现象/价态变化
3. 用教材附录名词清单当检查表，逐条自查定义（三大基础能力之一：清晰描述定义）

**交付物：**
- 字典条目（手写，含课本知识+预留"题目补充"区）
- 转化网络v1.0（手绘）

**验收标准：**
- 核心概念能用自己话完整说出（不看书）
- 转化网络主干无遗漏（价态轴线完整）

## Step2 方程式精研（化学的灵魂环节）

**目标：** 本模块核心方程式逐条过关。

**任务（每条方程式四过关）：**
1. **写得出**：不看资料默写
2. **条件对**：反应条件（加热/催化剂/点燃/高温）不漏不错
3. **配平准**：原子守恒+电子守恒+电荷守恒三重检查
4. **注现象**：反应现象+特殊点（颜色变化/沉淀/气体/可逆号）

**教练动作：**
- 逐条过关，错一条重写一条，直到连续2轮全对
- 讲清每条方程式"为什么要记"还是"可以推出来"（记和推分开）
- 易错点当场做表格对比（如浓硫酸vs稀硫酸与Cu反应）

**交付物：** 方程式过关清单（学生手写+教练签字）

**验收标准：** 连续2轮默写全对（100%），条件/配平/现象零失误。

## Step3 专项训练（限时 + 错题五分类）

**目标：** 暴露漏洞+训练模型+沉淀表达。

**任务：**
1. 限时完成15-20题（真题+模拟题，按题型分组），记录每题用时
2. 每道错题按**化学五分类**归档：知识缺口/模型不会/表达不准/审题失误/速度问题
3. 错题回流：知识缺口→补进字典对应条目；模型不会→补进原理模型页；表达不准→抄进标准表达积累卡

**交付物：** 限时训练记录+错题五分类台账+字典/模型页更新

**验收标准：** 每道错题都有分类+回流去向（不允许"做过就算"）。

## Step4 拔高挑战（陌生情境迁移）

**目标：** 训练"陌生情境使用原理的能力"（五项核心能力之一，上海/北京卷都重点考）。

**任务：**
1. 2-5道综合题：含新物质、新信息、新情境
2. **一题多变**：教练改编条件（少量→过量、稀→浓、常温→加热），学生追踪产物变化（动态追踪流水线）
3. **一题多问**：同一情境从选择题问到简答题，训练表达精度

**交付物：** 变式追踪记录（每变一次，写清"谁反应了→生成什么→还剩什么→下一步怎样"）

**验收标准：** 能独立说清陌生情境的分析入口（从哪个信息入手→调用哪条原理）。

## Step5 验收输出（化学专属铁律）

**目标：** 证明"学会了"而不只是"学过了"。

**任务（四件全过才算通过模块）：**
1. **方程式默写**：本模块全部核心方程式盲默，正确率100%
2. **转化网络讲解**：对着v2.0网络图独立讲解3-5分钟（每条边：谁→谁，条件，现象，为什么），录像或现场，无知识性错误
3. **标准表达过关**：本模块得分句抽背，能准确默写
4. **限时小测**：15-20题综合小测，正确率≥90%

**未通过的补救：**
- 默写不过→回Step2重过关
- 讲解卡壳→回Step1补字典
- 小测<90%→错题五分类后针对性回炉对应Step

**通过后奖励：** 教练签字+家长群报喜+积分兑现（与米赋激励体系挂钩）。

## 5步流程的课时分配建议

| 模块类型 | 举例 | 建议课时 | 5步分配 |
|---------|------|---------|--------|
| 文科型（元素化合物） | 硫及其重要化合物、氮、氯 | 2-3课时 | Step1/2占1.5课时，Step3占0.5，Step4/5占0.5-1 |
| 理科型（原理） | 电离水解、化学平衡 | 3-4课时 | Step1占0.5，Step2/3占2，Step4/5占1 |
| 混合型 | 电化学、工业流程综合 | 3-4课时 | 文科段用字典、理科段用模型，5步照走 |
