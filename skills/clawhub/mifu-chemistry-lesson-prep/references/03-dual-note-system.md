# 双笔记系统 + 转化网络 + 四大进阶方法

## 一、双笔记系统（化学独有，替代数学的单一思维导图）

化学知识天然分两类，笔记格式必须分开，不能混在一个本子里。

### 1.1 化学字典（文科型知识）

**装什么：**
- 元素及其化合物：钠、铝、铁、铜、氮、硫、氯……的性质、用途、现象、方程式
- 典型物质：常见沉淀、气体、氧化剂、还原剂、指示剂、干燥剂
- 实验事实：颜色、气味、现象、装置用途、注意事项
- 答题语言：标准得分句

**格式（每条目固定结构）：**
```
【物质名】
├─ 物理性质（色/态/味/溶解性）
├─ 化学性质（按价态或类别分组，每条配方程式）
├─ 检验方法（现象+方程式）
├─ 用途
└─ 题目补充区（做题遇到课本外考点，随时补进来）
```

**三条原则：**
1. 课本上的知识全都写下来（第一次建条目要完整）
2. 随时补充做题中遇到的课本外知识点（动态更新，笔记不是一劳永逸）
3. 按元素/物质/反应类型归档，**不按"今天错题"堆在一起**

### 1.2 原理错题模型（理科型知识）

**装什么：** 氧化还原、电离水解、平衡与速率、有机反应类型、实验与工业流程分析框架。

**格式（每专题一页）：**
```
┌─ 上半区：核心原理（定义/公式/守恒关系/判断流程）
├─ 下半区：3-5道代表题（典型题/错因/题眼/标准表达）
└─ 旁边区：同类题变式和易混点
```

**目标不是"好看"，而是下次遇到同类题时能立刻调用。**

## 二、转化网络：点→线→面→网

零碎知识系统化的核心工具，化学版"思维导图"但结构化程度更高——**按价态立体展开**。

### 2.1 建网规则

1. **横轴**：同价态的物质（如+4价：SO₂、H₂SO₃、SO₃²⁻、HSO₃⁻）
2. **纵轴**：价态变化（-2 → 0 → +4 → +6），标注每条边的氧化剂/还原剂
3. **每条边**必须标注：方程式+条件+现象+价态升降（升失氧/降得还）
4. 用两种颜色区分：氧化生成的边（价态升）vs 还原生成的边（价态降）

### 2.2 验收分级

| 版本 | 时机 | 标准 |
|------|------|------|
| v1.0 | Step1 | 主干边完整，价态轴线正确 |
| v2.0 | Step3后 | 每条边方程式+条件+现象齐全，补入做题遇到的"冷门边" |
| v3.0 | Step5 | 能脱离笔记讲解，附学生自己的问题清单（哪些边记不牢+AI解决结果） |

**强制手绘**：v1.0必须手绘，不许直接用软件（强制手写原则——用笔写，AI才不会替你思考）。

## 三、四大进阶方法（备课四件套）

### 3.1 零碎知识系统化 → 转化网络
见上。备课时的动作：为每个模块设计转化网络骨架（学生课前只给空骨架，课上一起补全）。

### 3.2 相似内容表格化对比 → 对比表设计
易混知识点备课必须出对比表。经典组合：
- 原电池 vs 电解池
- SO₂漂白 vs 氯水漂白 vs 活性炭吸附
- 浓硫酸 vs 稀硫酸 vs 亚硫酸
- 水解 vs 电离
- 同位素/同素异形体/同分异构体

**表格维度模板：** 名称 | 组成/结构 | 关键性质 | 检验方法 | 典型方程式 | 易错点

### 3.3 高频考点口诀化 → 口诀共创
- 教练给示范口诀，学生**自创**记忆最牢
- 抽象内容生活化：萃取→"两个男孩抢一个女孩，谁吸引力强谁抢走"
- 备课动作：每个模块预留"口诀共创"环节（5分钟），把最难记的1-2个点编成口诀

### 3.4 复杂难点流程化 → 固定步骤卡
复杂操作拆成固定流程，千篇一律：
- **氧化还原方程式配平三步**：①标化合价变化→求最小公倍数定系数 ②补溶剂分子 ③看环境补水/用H⁺/OH⁻，最后检查守恒
- **电极方程式书写**：与配平同流程
- **离子共存判断六维度**：颜色/酸碱性/复分解/水解/氧化还原/络合
- **K值计算流程**：写表达式→三段式→代入求值→检验单位

## 四、三遍法刷题（刷后变强，不是刷得多）

| 遍次 | 动作 | 目标 |
|------|------|------|
| 第一遍 | 独立做，标出卡住点 | 暴露漏洞 |
| 第二遍 | 对答案，写清"答案为什么这样想" | 训练模型 |
| 第三遍 | 隔3-7天重做或口述解题路径 | 确认脱离答案 |

**每道错题必问一句：这道题下次靠什么更快做对？靠背、靠模型、靠审题标记、还是靠计算套路？**

## 五、错题本≠题目坟场 → 错题索引

错题本的价值是"索引"功能：告诉你哪个知识点、哪个题型、哪种表达还没过关。

**化学五分类回流去向：**
| 分类 | 回流 |
|------|------|
| 知识缺口 | 化学字典对应条目 |
| 模型不会 | 原理模型专题页 |
| 表达不准 | 标准表达积累卡 |
| 审题失误 | 审题提醒清单 |
| 速度问题 | 限时训练记录 |
