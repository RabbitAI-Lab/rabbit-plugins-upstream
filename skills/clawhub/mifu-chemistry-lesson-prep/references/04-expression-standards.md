# 标准表达语言库 + 审题规范

> 化学大题"知道意思但写不出得分句"是最高频的失分原因之一。表达即分数——标准得分句要像英语单词一样背。

## 一、标准表达语言库（按场景分类，持续积累）

### 1.1 工业流程/操作目的类

| 操作/条件 | 标准得分句 |
|----------|-----------|
| 粉碎/研磨矿石 | 增大接触面积，加快反应速率，提高浸出率 |
| 加入过量试剂 | 使目标离子充分反应（或沉淀完全） |
| 调节pH | 促进XX离子水解沉淀，同时避免目标离子沉淀 |
| 过滤 | 分离固体与液体 |
| 洗涤沉淀 | 除去沉淀表面可溶性杂质 |
| 检验沉淀是否洗净 | 取最后一次洗涤液，滴加XX，若无XX现象则已洗净 |
| 蒸发浓缩、冷却结晶 | 降低溶解度使晶体析出（适用于溶解度随温度变化大的物质） |
| 趁热过滤 | 防止降温时杂质结晶析出 |
| 灼烧 | 除去可挥发性杂质/使XX分解 |
| 控制温度在XX℃ | 防止XX分解（或：使反应速率适中/防止副反应） |
| 先通气后加热 | 排尽装置内空气，防止XX被氧化 |
| 尾气处理 | 防止污染空气（有毒气体必须处理） |
| 防倒吸 | 导管口接近液面/使用倒扣漏斗/干燥管 |

### 1.2 现象描述类（按"关键词+程度词"规范）

| 类型 | 规范表述 | 常见错误 |
|------|---------|---------|
| 生成白色沉淀 | "产生白色沉淀" | 写"变白" |
| 沉淀部分溶解 | "沉淀部分溶解，有无色气泡产生" | 漏写气泡 |
| 焰色试验 | "焰色呈黄色（需透过蓝色钴玻璃观察紫色）" | 混淆钾钠 |
| 使品红褪色 | "品红溶液褪色，加热后恢复红色"（SO₂特性） | 与氯水漂白混淆 |
| 气体检验 | 先描述操作→现象→结论 | 直接写结论 |

### 1.3 实验方案设计类（四要素模板）

**目的-装置-操作-现象-结论**链条：
- 设计方案 = 目的 + 原理（方程式）+ 操作（取樣/加入/观察）+ 现象 + 结论
- 评价方案 = 可行性（原理对不对）+ 严谨性（有没有干扰）+ 安全性 + 绿色化学

### 1.4 平衡/原理解释类

| 问题类型 | 标准句式 |
|---------|---------|
| 为什么使用催化剂 | 降低活化能，加快反应速率，缩短达到平衡的时间（不改变平衡） |
| 为什么升高温度速率加快 | 活化分子百分数增大，有效碰撞频率增加 |
| 平衡移动方向 | 该反应正反应气体分子数减小（放热），增大压强（降温）平衡正向移动 |
| 使用过量空气的原因 | 使SO₂充分氧化，提高转化率 |

## 二、审题规范（李政"考前20条"精华版）

### 2.1 审题铁律（考场上先圈再答）

1. **看清写什么方程式**：离子方程式还是化学方程式？——不心存侥幸，问什么写什么
2. **圈"过量/少量"**：产物跟着量走（CO₂+NaOH案例）
3. **圈"无色/酸性/碱性"**：排除有色离子（Cu²⁺/Fe³⁺/MnO₄⁻）、限定共存条件
4. **圈"标准状况"**：22.4L/mol只适用于标况气体
5. **圈"可逆反应"**：⇌不能写成→，产率不到100%
6. **圈单位**：mol/L还是mol？g还是mL？
7. **圈"由大到小/由小到大"**：排序题方向反了全错
8. **电子守恒优先**：氧化还原计算先用电子守恒，不用死算

### 2.2 答题规范

1. 方程式没写条件/没配平/没写↑↓符号 = 白写
2. 简答题"三段式"：因为（原理）→所以（推理）→故（结论）
3. 不要口语化："跑得快"→"速率快"；"反应完了"→"反应完全"
4. 选择题设时间上限，到时间能做就做，做不出来就蒙，**不纠结**

## 三、备课使用方法

1. **每个模块备课必须列出**：本模块涉及的得分句清单（Step5抽背用）
2. **标准表达积累卡**（学生持有）：每次做题遇到新得分句→抄进卡片→按场景归类
3. **AI对比验收**：学生写完简答题→AI按评分标准对比→找出"意思对了但表达不得分"的地方→抄标准句进积累卡
4. **Step5验收**：得分句抽背+默写，表达不准 = 未过关
