# 化学专属质量体系：备课自评6维度 + 验收铁律

## 一、备课自评6维度（100分制，≥80分方可上课）

| 维度 | 权重 | 检查要点 |
|------|------|---------|
| 知识类型判定准确 | 15% | 文科型/理科型/混合型判定正确，笔记工具选择匹配（字典 vs 模型） |
| 方程式过关设计 | 20% | 核心方程式清单完整、四过关（写出/条件/配平/现象）流程可执行、教练已亲自三重验证 |
| 转化网络设计质量 | 15% | 价态轴线正确、主干边完整、每条边信息齐全、有空骨架供学生补全 |
| 动态追踪案例质量 | 15% | 至少1道流水线案例、变式设计合理（量比/浓度/温度）、追踪记录模板清晰 |
| 化学三件套完备 | 15% | 对比表（易混点）+口诀共创环节+标准得分句清单，三者缺一不可 |
| 验收与预案 | 20% | 方程式默写100%标准明确、Plan B含AI故障降级方案、时间分配考虑考试时限 |

**自评方式：** 教练逐维度打分并写依据，<80分的维度必须改进后重评。

## 二、模块验收铁律（学生端，四件全过才算通过）

1. **方程式默写100%**（化学的生命线，比数学的90%更严）
2. **转化网络独立讲解**无知识性错误（3-5分钟，录像或现场）
3. **标准表达抽背过关**（得分句能准确默写）
4. **限时小测≥90%**（15-20题，限时按考试节奏折算）

未通过的补救路径：
- 默写不过→回Step2
- 讲解卡壳→回Step1补字典
- 表达不准→回标准表达积累卡+AI对比验收
- 小测<90%→错题五分类→针对性回炉

## 三、三层防线

| 防线 | 机制 |
|------|------|
| 备课防线 | 6维度自评≥80分+教练亲自验证所有方程式 |
| 课堂防线 | 顺序原则（学生先写AI后介入）+强制手写+方程式即时三重验证 |
| 课后防线 | 错题五分类回流（不允许"做过就算"）+字典动态更新+3天/7天三遍法重做 |

## 四、双视角反馈（课后迭代）

- **教练视角**：5步流程哪一步卡壳最多？方程式过关用了多久？哪些环节超时？
- **学生视角**：字典/网络/追踪哪个工具最有用？AI追问是否帮助思考（还是觉得被打断）？
- 反馈按P0（必须改）/P1（应该改）/P2（可以改）分级，P0当周修教案，P1下个模块改进，P2记录待议。

## 五、质量红线（一票否决项）

1. 教案中出现AI生成但未验证的方程式 → 退回重备
2. 知识类型误判（元素化合物用纯原理模型教/原理用死记硬背教）→ 退回重备
3. 缺少陌生情境迁移题（上海/北京备课）→ 退回补题
4. 核心方程式默写验收标准低于100% → 验收标准不合法
