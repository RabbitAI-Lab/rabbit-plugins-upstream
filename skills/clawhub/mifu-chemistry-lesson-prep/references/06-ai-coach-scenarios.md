# 化学AI教练场景 + 方程式三重验证

> 基于chem-coach skill + 名师方法论，为化学课堂定制的AI使用规范。原则与v2.0课堂设计一致：学生先想/先写→AI再介入（防认知卸载）。

## 一、7大AI场景

| 场景 | 代号 | 核心功能 | 使用时机 | 强制约束 |
|------|------|---------|---------|---------|
| 方程式陪写校验 | S1 | 学生先手写→AI逐条校验（守恒/条件/现象） | Step2方程式精研 | 学生必须先写完，AI只校验不代写 |
| 现象解释追问 | S2 | AI描述现象/给信息→学生先猜解释→AI追问依据 | Step1知识建构+Step4 | "解释"导向：现象→可能的解释 |
| 陌生信息拆解 | S3 | 帮学生拆解题干新信息（哪些是新知识/哪些能用旧原理） | Step4陌生情境迁移 | 拆解后学生自己说分析入口 |
| 一题多变 | S4 | AI改编条件（量比/浓度/温度），生成变式链 | Step4拔高挑战 | 每变一次学生先预判再做 |
| 动态追踪陪跑 | S5 | AI扮演"流程图"，逐步暴露条件，学生每步预判 | Step4/工业流程 | AI每次只给一步，学生写追踪记录 |
| 诊错五分类 | S6 | AI对错题逐行批注，按五分类（知识/模型/表达/审题/速度）归档 | Step3错题分析 | 学生先自分类，AI复核 |
| 苏格拉底引导 | S7 | 追问式启发，不给答案 | 贯穿全程（配合教练） | 5层追问，30秒卡壳才给提示 |

**必选组合：S1 + S6 + S7**（每节课至少这三个）。

## 二、AI方程式三重验证（S1的核心规范）

化学AI最容易在方程式上出错，任何AI生成的方程式必须三重验证后才允许进入教案/导学案：

1. **原子守恒**：每种元素原子数左右相等（逐一数）
2. **电子守恒**：氧化剂得电子总数=还原剂失电子总数（标价态变化验证）
3. **电荷守恒**：离子方程式左右两边总电荷相等

**+条件与符号检查：** 反应条件（点燃/加热Δ/高温/催化剂）、可逆号⇌、↑↓符号、浓/稀标注。

**教练铁律：教案里的每条方程式，教练必须亲自过一遍三重验证——AI方程式不许直接上课堂。**

## 三、IMA提示词库（化学场景，可直接复制）

### 提示词1：方程式过关校验（S1，Step2用）
```
你是上海高考化学阅卷专家。我会给你我手写的化学方程式（拍照/抄写），请逐条校验：
1. 原子守恒（列出每种元素左右原子数）
2. 电子守恒（标出氧化剂/还原剂，得失电子总数）
3. 电荷守恒（离子方程式）
4. 反应条件、可逆号、↑↓符号、浓/稀标注是否正确
【输出格式】每条方程式：✅通过 / ❌错误（指出具体错误+正确写法+易错提醒）
最后汇总：我错得最多的是哪一类（守恒/条件/符号），给我1条针对性记忆建议。
```

### 提示词2：动态追踪陪跑（S5，Step4用）
```
你是米赋化学教练。我们在做"XX通入XX溶液"的动态追踪训练。
规则：你每次只给出下一步的条件（如"继续通入过量XX"），等我先写出追踪记录
（谁反应了→生成什么→还剩什么→下一步预判），你再判断对错并给下一步。
不许一次性给出全部答案。如果我预判错误，先追问"你觉得为什么不是XX？"，我两次
答不出来再解释。
```

### 提示词3：简答题标准表达对比（S6+S2，Step3/5用）
```
你是上海高考化学阅卷老师。这是简答题原题+评分标准+我的答案。
请对比：
1. 我的答案能得几分（按评分标准逐点给分）
2. "意思对了但表达不得分"的地方——给出标准得分句原文
3. 知识性错误（如果有）——指出原理
【输出】得分表 + 我该背进"标准表达积累卡"的句子清单
```

### 提示词4：陌生信息拆解训练（S3，Step4用）
```
你是米赋化学教练。给我一道含陌生信息的综合题（主题：XX），但分两步：
第一步只给题干信息，让我圈出"新知识"并回答："这道题的本质是我们学过的哪个原理？"
等我回答后再给题目，让我独立完成。
```

## 四、chem-viz可视化调用（课堂增强）

需要在微观/动态可视化时调用chem-viz skill：
- 3D分子结构展示（如SO₂的V形结构、键角）
- 动态反应过程（如接触法制硫酸三阶段流程动画）
- 晶胞结构旋转观察

**使用约束：** 可视化是"解释现象的工具"，看完必须回到"现象→解释→方程式"，不能替代手绘转化网络。

## 五、AI使用的防依赖设计

1. **顺序原则**：学生先写/先猜/先预判→AI再介入
2. **强制手写**：字典条目、转化网络、方程式默写必须手写
3. **AI故障Plan B**：S1→教练人工对照过关清单；S5→教练口头给条件学生写记录；S6→对照评分标准人工批注
