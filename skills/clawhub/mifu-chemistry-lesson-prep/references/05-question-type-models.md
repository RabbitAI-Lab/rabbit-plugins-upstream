# 四大题型模型 + 动态追踪流水线

## 一、四大题型模型（每个都要有固定分析路径）

### 1.1 选择题：快、准、稳

**训练三阶段：**
1. 基础期不限时：重点看每个选项为什么对、为什么错
2. 提速期按题组训练：记录"慢在哪里"
3. 冲刺期完整限时：准确率不掉的前提下压时间

**错因四分类：**
| 错因 | 典型表现 |
|------|---------|
| 知识缺口 | 某性质/现象/方程式不知道 |
| 概念混淆 | 氧化性/还原性、水解/电离、强弱电解质 |
| 审题失误 | 忽略过量/少量/无色/酸性/标况 |
| 计算慢 | 物质的量、守恒、差量、极值不熟 |

**每道错题只问一句：下次靠什么更快做对？（靠背/靠模型/靠审题标记/靠计算套路）**

### 1.2 工业流程题：跟着"物质流"走（动态追踪的典型应用）

**读题四步：**
1. 圈原料、目标产物、副产物
2. 每一步写清：加入什么→除去什么→生成什么→保留什么
3. 标出价态变化、沉淀转化、pH控制、过滤/洗涤/灼烧的目的
4. 问答优先用标准表达句

**核心能力：** 不是记住某一道流程，而是看到新流程能判断"它在分离、转化、除杂、富集还是制备"。

### 1.3 实验题：目的-装置-操作-现象-结论

**分析路径：**
- 实验目的：验证什么/制备什么/测定什么/除去什么
- 装置作用：发生/除杂/干燥/收集/尾气处理/防倒吸/防氧化
- 操作原因：为什么加热/冷却/控温/先通气后停止
- 现象解释：颜色/沉淀/气体/溶液变化背后的反应
- 结论表达：由控制变量或现象推出结论

**核心认知：** 实验题不是背装置，而是理解"每个装置为什么存在"。

### 1.4 有机化学：官能团主线 + 反应网络

**学习顺序：** 认识有机物（命名/结构/官能团）→ 理解反应类型（取代/加成/消去/氧化/酯化/水解/聚合）→ 转化网络（烃↔卤代烃↔醇↔醛↔酸↔酯）→ 推断训练。

**高分关键四看：**
- 看到条件→想到反应类型
- 看到官能团→想到性质和检验
- 看到合成路线→能逆推目标产物
- 不把反应当孤立知识点，连成图

## 二、动态追踪流水线思维（化学最核心的解题能力）

### 2.1 三原则

1. 反应不是发生一次就结束，条件变了产物还会继续变化
2. 做题必须跟着反应走，追踪每一种物质的去向
3. **上一步的产物就是下一步的反应物**——在脑子里跑流水线

### 2.2 流水线记录格式（课堂交付物模板）

```
步骤n：加入XX（过量/少量）
  → 谁反应了：（方程式）
  → 生成了什么：
  → 还剩什么：
  → 下一步会怎样：（预判）
```

### 2.3 经典追踪案例库（备课选用）

| 案例 | 追踪要点 |
|------|---------|
| CO₂通入NaOH溶液 | 少量→Na₂CO₃；过量→NaHCO₃（过量的CO₂把Na₂CO₃转化了） |
| Cl₂通入FeBr₂溶液 | 还原性Fe²⁺>Br⁻，先氧化Fe²⁺再氧化Br⁻（顺序追踪） |
| SO₂通入Ba(OH)₂ | 少量SO₂→BaSO₃↓；过量SO₂→Ba(HSO₃)₂（沉淀溶解） |
| SO₂通入氯水/酸性KMnO₄ | 褪色的原因是还原性，不是漂白性（易错！） |
| 浓硫酸与Cu加热 | 先浓硫酸反应生成SO₂，随反应进行变稀硫酸后停止（动态浓度变化） |
| 铁与稀硝酸 | 先生成Fe³⁺，Fe过量时继续反应生成Fe²⁺（量比追踪） |

**备课要求：每个元素化合物模块至少设计1道流水线追踪案例（一题多变，条件改变→产物改变）。**

## 三、陌生情境迁移（Step4拔高的题型设计法）

**设计公式：** 熟悉原理 × 陌生载体 = 拔高题

- 熟悉原理：氧化还原/平衡/守恒/周期律
- 陌生载体：新物质（如锗、钨酸钙）、新信息（题干给出的新反应）、新图表（流程图/晶胞图/历程图）

**训练法：**
1. 先给信息阅读时间，圈出"新知识"（哪些是题干给的，必须用）
2. 学生说"这道题的本质是我们学过的哪个原理？"
3. 用熟悉的分析路径走一遍（方程式→守恒→表达）

**上海卷特色：** 2024年起5道主题式综合题，陌生情境是常态（锗提取/珊瑚礁/瑞格列奈合成）——元素化合物模块备课必须配陌生情境题。
