## Description:

Game architecture design using system dependency mapping, Architecture Decision Records (ADRs), and technical design documents to produce a navigable architecture that scales with the project.

This skill is ready for commercial/non-commercial use.

## Publisher:

[toilanguyen2910](https://clawhub.ai/user/toilanguyen2910)

### License/Terms of Use:

MIT-0

## Use Case:

Game developers and technical leads use this skill to design game system architecture, document system dependencies and data flows, and write ADRs and technical design documents for a game project.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated architecture notes or code stubs may conflict with an existing game project's design or implementation.

Mitigation: Review suggested files and stubs before applying them to an existing game project.
