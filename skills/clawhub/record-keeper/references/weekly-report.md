# 周报模板

**用途**：每周工作内容汇总，梳理本周成果、进展、风险和下周计划。

**工作流**：系统基于本周 records 出具草稿 → 用户审阅补充（重点是心得）→ 用户正式提交

**适用**：每周六由系统出具草稿，手动触发。

**不适用**：单次任务记录（→ `task`）、单次会议记录（→ `meeting`）、复盘分析（→ `report`）。

**报告人**：系统

**标签**：#周报 #weekly #W{周数}

---

---

**结构要点**：
1. 先概览后细节，一屏能看完（核心项目进展 + 风险）
2. 推进事项表格化，标注状态和相关人
3. 下周计划标注 @负责人，方便分发
4. 心得为周报核心章节，由用户亲自撰写，系统提供方向提示
5. 数据指标为可选项——有则填，无则不填

**视角说明**：
- 系统出具草稿时用第三人称记录（基于 records 的事实陈述）
- 用户审阅后，心得和战略内容切换为第一人称
- 最终提交版为用户第一人称周报
