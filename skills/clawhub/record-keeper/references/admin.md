# 行政/运营事务模板

**用途**：值班、人事、团队档案、培训记录、成本工时等行政/运营类事务。

**适用**：值班排班、人员档案、培训记录、工时统计、成本记录。

**不适用**：以上五类之外的所有运营类事务。

---

```markdown
# [事务名称]

**记录时间**：YYYY-MM-DD
**记录人**：系统
**标签**：#行政 #xxx

---

## 一、说明

这个记录是做什么用的？

## 二、[具体内容区]

（根据事务类型自定义，如值班人员表、团队成员表、培训记录等）

| 字段 | 字段 | 字段 |
|------|------|------|
|      |      |      |

## 三、历史/补充

（可选，如值班历史、变更记录等）
```

---

**结构要点**：
1. 结构最灵活，但必须包含"说明"区块
2. 数据密集型（如值班表）可附加统计表
3. 跨年度维护的记录需包含历史数据区
