# 分析/复盘/总结模板

**用途**：对已有事物的分析、复盘、总结、评审报告。

**适用**：项目复盘、事故分析、季度总结、评审报告。

**不适用**：会议过程记录（→ `meeting`）。

---

```markdown
# [报告名称]

**报告时间**：YYYY-MM-DD
**报告人**：
**报告类型**：复盘 / 分析 / 总结 / 评审
**标签**：#报告 #xxx

---

## 一、概述

报告背景、时间范围、涉及对象。

## 二、事实/数据

客观陈述发生了什么，列出关键数据。

## 三、分析

对事实的分析，原因、影响、关联因素。

## 四、结论

基于分析得出的结论。

## 五、改进措施 / 建议

| 序号 | 措施 | 负责人 | 计划时间 |
|------|------|--------|---------|
|      |      |        |         |

## 六、BADCASE（如适用）

| 案例 | 问题 | 原因 | 影响 |
|------|------|------|------|
|      |      |      |      |
```

---

**结构要点**：
1. 事实→分析→结论 三段论
2. 强调客观数据和事实
3. BADCASE 表用于复盘场景
