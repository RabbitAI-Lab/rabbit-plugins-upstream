# 会议记录模板

**用途**：记录有明确开会行为、多人参与的会议过程、决议和待办。

**适用**：需求讨论会、评审会、双周会、复盘会、临时讨论等。

**不适用**：会议后产出的需求文档（→ `requirement`）、规划文档（→ `plan`）。

---

```markdown
# [会议名称]

**日期**：YYYY-MM-DD | HH:MM ~ HH:MM (GMT+8)
**地点**：
**参会人员**：
**记录人**：系统
**会议类型**：
**标签**：#会议 #xxx

---

### 讨论要点
-

-

| 事项 | 负责人 | 截止时间 |

|------|---------|------|
|      |         |      |

### 待办汇总
| 序号 | 事项 | 负责人 | 截止时间 |
|------|------|--------|---------|
|      |      |        |         |
```

---

**结构要点**：
1. 顶部元信息（日期/参会人/类型）
2. 按议题分段，每段含"讨论→决议→待办"
3. 末尾汇总所有决议和待办
