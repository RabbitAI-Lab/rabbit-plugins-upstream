# 备忘录

## 模板

```markdown
# {主题}

**日期**：YYYY-MM-DD
**记录人**：系统
**类别**：memo
**标签**：#备忘

---

## 概述

{一句话说明备忘的核心内容}

## 正文

{自由记录，可以是条目、表格、要点等}

## 备注

{补充说明、关联文档、待确认事项等}

---

_记录完毕。_ 📋
```

## 使用说明

### 适用场景

- 日常工作总结（如某天的工作内容记录）
- 技术决策备忘
- 会议后的简要记录（非正式会议记录）
- 经验总结、方法论记录
- 待确认事项的临时记录
- 某个主题的零散笔记

### 与 meeting 的区别

- **meeting**：有明确开会行为、多人参与、产生讨论/决议/待办的正式会议
- **memo**：个人或少数人的零散记录，非正式，不需要模板化

### 与 report 的区别

- **report**：结构化的分析/复盘/总结报告，有深度
- **memo**：轻量级备忘，内容自由，不求深度

### 与 task 的区别

- **task**：有明确截止时间和待办事项
- **memo**：记录性质的内容，不一定有明确的待办

### 状态流转

```
open → done
```

memo 类文档创建即归档，通常直接设为 `done`。
