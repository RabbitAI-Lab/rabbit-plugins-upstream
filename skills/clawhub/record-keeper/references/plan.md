# 计划/规划模板

**用途**：记录项目计划、季度规划、排期、里程碑、路线图。

**适用**：季度 OKR、项目计划、排期文档、路线图。

**不适用**：具体需求定义（→ `requirement`）、会议讨论（→ `meeting`）。

---

```markdown
# [计划名称]

**编制时间**：YYYY-MM-DD
**编制人**：
**周期**：YYYY-MM ~ YYYY-MM
**状态**：草稿 / 进行中 / 已完成 / 已调整
**标签**：#计划 #xxx

---

## 一、目标

本计划要达成什么？

## 二、范围

覆盖哪些方面？不覆盖哪些？

## 三、任务分解

| 序号 | 任务 | 负责人 | 计划时间 | 状态 | 备注 |
|:---:|------|--------|---------|------|------|
| 1    |      |        |         |      |      |

## 四、里程碑

| 里程碑 | 计划日期 | 状态 |
|--------|---------|------|
|        |         |      |

## 五、风险

| 风险 | 影响 | 应对措施 |
|------|------|---------|
|      |      |         |

## 六、主线/总结

（可选）用几句话总结核心方向和优先级。
```

---

**结构要点**：
1. 顶部含编制时间和周期
2. 任务分解表 + 里程碑表 + 风险表
3. 强调可追踪，每个任务有负责人和状态
