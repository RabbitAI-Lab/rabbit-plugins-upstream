# 公开 · 运营 · 定位建议（GTM）

## 一句话定位（不是纯吸粉）

> **Chat → Insight**：把你**已经拥有**的群聊/私聊记录，变成一页可执行情报。
> 给社群主理人、知识博主、顾问、研究员 —— 不是给「偷群爬虫」。

**不要**定位成：

- 「抖音群一键导出」
- 「无感监听粉群」
- 纯工具党灰产

**要**定位成：

- 会话情报 / 社群语音矿（需求原话墙）
- Creator Insight 的**平行兄弟**（作品 vs 会话）
- Local-first、可审计、可公开安装的 Agent Skill

---

## 值不值得公开？

**值得**，若坚持边界：

| 条件 | 原因 |
|------|------|
| 分析与采集分离 | 过 ClawHub / 信任 / 维护成本 |
| 和 creator-insight 同一品牌语言 | 复用已有公开作品受众 |
| 演示可用 fixture + 用户自备数据 | 降低「装完不能用」差评 |
| MIT + 无强制云 Key | 安装转化高 |

**不值得**公开的形态：打包 session 爬取、承诺任意群全量。

## 获客：不是纯吸粉，是「样本驱动」

### 推荐模型：**演示样本 → Skill 安装 → 自带数据出报告**

1. **公开内容（吸关注，但是带货 skill）**
   - 发「我把 XX 粉丝群 1800 条消息压成一页」前后对比（脱敏）
   - 固定结构截图：4 块单页
   - 标题模板：《群公告发了 10 遍仍被问》→ 需求墙实锤

2. **钩子不是软件本身，是「原话墙」**
   - 人会对着真实用户原话转发
   - 避免只发 CLI 截图（开发者向过窄）

3. **分发渠道优先级**
   - 你自己的抖音/公众号/社群（最高信任）
   - GitHub/Gitee Release + 中文 README
   - ClawHub（Agent 用户）
   - 即刻/V2EX/少数派：强调 local-first 与隐私，不讲逆向细节

4. **不做什么**
   - 不买量推「破解群聊」
   - 不在演示里教绕过验证码/盗 session
   - 不把未脱敏私聊当营销素材

### 北极星指标（别只看粉）

| 指标 | 说明 |
|------|------|
| 干净安装成功率 | 新机器 clone → unittest → fixture 报告 |
| 首次出报告时间 | &lt; 10 分钟（有导出的前提下） |
| GitHub star → install | 看转化不是虚荣 |
| 复购式使用 | 同一用户第二次丢新导出 |
| 合规投诉 | 应为 0 |

吸粉只是漏斗顶；**安装并跑出第一份自己的报告**才是激活。

## 发布节奏（建议）

### Phase 0 — 本机就绪（现在）

- [x] Skill 目录 + 测试 + INSTALL/GTM
- [x] 本机 link 到 `~/.shared/skills`
- [ ] 用真实自备导出跑 1 份**脱敏**样例报告（可进 `docs/examples/`）

### Phase 1 — 静默开源

- GitHub 私有→公开，中文 README 最短路径
- Gitee 镜像
- SECURITY.md + 边界写进 description
- **不上**「一键爬群」字样

### Phase 2 — ClawHub

- `publish-agent-skill` 预检
- clawscan 说明：仅本地读用户指定文件，无强制网络
- 验收：全新目录 install + fixture

### Phase 3 — 内容运营

- 每周 1 条「原话墙」脱敏案例（配 skill 链接）
- 双月 1 次与 creator-insight 联合案例：「主页承诺 vs 群里问题」

## 风险清单

| 风险 | 缓解 |
|------|------|
| 用户以为能一键爬群 | README/SKILL 红线 + Agent 拒词 |
| 隐私事故 | 本地默认；示例脱敏；SECURITY 禁止上传完整私聊到第三方 |
| 启发式报告被当成真理 | meta.note 标明草稿；清单终审 |
| 与灰产项目联想 | 永不 bundling 导出器；文档只「可选第三方」 |

---

## 结论

- **定位**：样本驱动的社群/会话研究 Skill，不是纯吸粉玩具，也不是爬虫。
- **公开**：值得，且应尽快以「分析器」身份公开。
- **运营**：用脱敏原话墙做内容，用干净安装做口碑，用咨询/体检做收入。
- **吸粉**：只作为漏斗顶，激活指标是「自己的导出 → 第一份报告」。
