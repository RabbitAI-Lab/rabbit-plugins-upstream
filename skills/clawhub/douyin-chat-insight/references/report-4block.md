# 单页四块报告规范

## 结构

1. **硬事实** — 仅带原话出处；视频播放量等外部数字若引用须脚注
2. **未闭合矛盾** — 比复读「结论」更有信息量；未知标未知
3. **需求侧原话墙** — 非主理人、非纯分享卡片
4. **动作** — 每条能指回 1–3；禁止正确的废话

## 反模式

- 分享文案/视频卡片刷高「有价值」分
- 把群主营销话术当需求
- 多页 PPT 把同一成本叙事写三遍
- 未点选会话就对最大群深挖
- 把启发式草稿包装成「已人工访谈验证」
