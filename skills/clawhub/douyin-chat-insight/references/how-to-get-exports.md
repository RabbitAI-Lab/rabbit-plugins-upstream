# 如何自备导出（可选外部工具）

> **重要：** 下列工具**不是**本 skill 的依赖。
> 安装本 skill **不**需要安装它们。
> 它们只是「你如何得到 JSONL」的可选途径。

## 原则

1. 只导出**你有权访问**的会话（自己的号、自己管理的群）。
2. 不要把 cookie 发给陌生人 / 贴进公开 Issue。
3. 导出后，把**文件路径**给 `douyin-chat-insight`。

## 路径 0：已经有文件

若已有 ChatLab JSONL / 聊天备份，直接：

```bash
python3 scripts/run.py --input /path/to/file.jsonl
```

## 路径 1：第三方开源导出器（高级用户）

社区存在面向抖音网页 IM 的导出项目（例如 GitHub 上的 `douyin-chat-export` 一类）。

- 用途：在你本机登录**自己的**账号，导出会话为 ChatLab JSONL
- 安装、扫码、Docker、cookie：一律以**该项目自己的 README** 为准
- 本 skill 不 vendor、不启动、不代维这些工具
- 接口变更、账号风控、ToS 风险由用户自行判断

导出完成后：

```bash
python3 scripts/run.py --input /path/to/export.jsonl --conv 1
```

## 路径 2：复制粘贴纪要

运营活动后把精华问答贴进 `.txt`：

```
用户A: 请问 Windows 怎么装？
主理人: 看置顶第二段
```

适合小样本，不需要任何爬虫。

## 路径 3：合规降级（推荐对外叙事）

有价值发言 → 用户**转发到微信收藏** → 走收藏/知识库类 skill（若已安装）→ 或再导出文本给本 skill。

对外主推这条，而不是「静默拉群」。

## 路径 4：企业/官方能力

官方粉丝群管理、客服导出、飞书/企微会话归档（需企业权限）。导出为 CSV/JSON 后可转简易 JSON。
