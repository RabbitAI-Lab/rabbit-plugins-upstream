# Security Policy

## 数据边界

- 默认只读用户**显式传入**的本地路径。
- 不要求、不上传 cookie / sessionid / 密码。
- 不要把完整私聊导出提交到公共 Issue 或第三方「帮你看」服务。

## 报告

- 示例与文档使用脱敏 fixture。
- 对外发报告前删除真实手机号、地址、未成年人信息。

## 漏洞报告

请私信维护者；勿公开 PoC 涉及真实用户数据。

## 依赖

核心路径仅 Python 标准库，降低供应链风险。

## 发布前

运行 `python3 scripts/doctor.py`，确认 JSON 输出无私人绝对路径。
