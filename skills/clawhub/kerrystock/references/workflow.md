## 一、季节性判定规则（步骤3）

输入：标的自身月度 close-to-close 收益的统计 `n / 均值 / 中位数 / 胜率`。

| 类别 | 规则（默认阈值，可经 `--win`/`--lose` 调） | 含义 |
|---|---|---|
| **做多月份** | 胜率 ≥ 0.55 **且** 均值 > 0 | 历史上"涨多且常涨"，适合左侧布局 |
| **回避月份** | 胜率 ≤ 0.45 **且** 均值 < 0 | 历史上"跌多且常跌"，提前降仓 |
| 中性 | 其余 | 不机械操作，看技术/事件 |

**重要修正逻辑**：均值高但胜率低（如 2/3 月）属"少数大年拉高均值、中位数为负"，
**不构成做多信号**——必须胜率与均值同向才采纳。

**置信度**：报告须标注每个月的样本数 `n`。`n ≤ 3` 的结论置信度低，须显式提示。

**禁止**：直接套用 `seasonality.py` 的 A股默认月份 `[1,2,3,11,12]` 多 / `[5,6,7,8,9]` 空。
本技能强制用标的自身数据重算。

## 二、trade-plan 买卖点模板（步骤4）

按顺序产出，禁止跳步：

1. **位置判断**：超卖区 / 趋势中 / 高位区 / 筑底区（依据技术截面 + 距高点回撤%）。
2. **分仓**：试错仓（左侧超卖区 10–15%）→ 确认加仓（放量站上 BOLL 中轨 + MACD 金叉，加至 30–50%）。
3. **止盈**：第一目标 BOLL 中轨；强趋势看前高区域分批兑现。
4. **止损**：有效跌破 BOLL 下轨且放量 → 反弹失效离场。
5. **失效条件**：破位且 MACD 未金叉 / 业绩或行业逻辑证伪 → 放弃计划转观望。
6. **事件窗口**：财报披露日、行业旺季起点、宏观关键时点（作为催化/减仓点）。

## 三、中国配色规范（强制）

- **涨 = 红 `#d4380d`**，**跌 = 绿 `#18940f`**（与欧美相反）。
- 图表柱/折线、买卖信号一律遵守。
- "买入/持有窗口"用**绿**（操作建议色，区别于价格涨跌色）；"减仓/回避窗口"用**红**。
  报告内须加图例说明，避免与价格涨跌色混淆。

## 四、报告规范

- 必含：月度效应图、年度收益图、买卖日历热力图、当前技术面板、买卖策略表、月度统计明细（含 n）、风险提示。
- 风险条款固定：季节性是辅助规律非主信号；强趋势标的以业绩+趋势+事件为主；不构成投资建议；历史不代表未来。
- 数据区间、前复权、工具链来源须在页眉/页脚标注。

## 五、步骤5 复合选股（westock-tool）

日历效应时段 + 技术指标信号结合。常用：

```
# 1) 取策略信号池（如 MACD 金叉）
westock-tool strategy macd_golden
# 2) 在信号池内按估值二次排序（"金叉 + 低估值"）
westock-tool ranking fin_valuation --within-strategy macd_golden
# 3) 自定义条件精选
westock-tool filter "intersect([PE_TTM>0, PE_TTM<20, ROETTM>15])"
# 4) 列出可用策略/标签/事件，勿凭记忆
westock-tool strategy --list
westock-tool label --list
westock-tool event --list
```

选股命令须经 `westock-tool` 技能加载后执行。

## 六、ETF / 基金适配

### 1) 场内 ETF / LOF
- K 线格式与股票一致（open/high/low/last/volume），`export_kline.py` 直接可用。
- **代码归一化**：纯数字自动补前缀（沪 5/6/9→`sh`，深 0/1/2/3→`sz`）；歧义用 `--market sh|sz` 覆盖。
  - 例：`--code 161725` → `sz161725`；`--code 510300` → `sh510300`。
- 报告价格标签用 `--label 价`（默认"收盘"）。

### 2) 场外基金（仅单位净值）
- westock-data 无 K 线，改从 neodata 拉净值序列，存为 CSV：**至少含 `Date,close` 两列**。
- 脚本降级兼容：缺 `open/high/low` 自动用 `close` 填充，`volume` 补 0；故纯净值序列也能算季节性与技术截面（KDJ 高低用 close 近似）。
- 报告价格标签用 `--label 净值`。

### 3) 分析要点
- 基金的日历效应 ≈ **所跟踪标的的季节性**（白酒LOF≈白酒板块、沪深300ETF≈大盘），结论须结合跟踪标的基本面解读，不可孤立看净值波动。
- 场外基金无盘中高低，BOLL/KDJ 带宽仅反映净值日波动，技术性弱于场内 ETF，买卖点以"月度季节性 + 跟踪标的趋势"为主。
