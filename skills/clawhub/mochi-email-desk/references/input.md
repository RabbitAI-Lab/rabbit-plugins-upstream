# JSON actions

Actions: sync(profile,folder default INBOX,limit 1..200); folders(profile); search(query,account optional,limit 1..500); read(messageId); attachments(messageId,output default exports/mail); prepare(profile,draftId,to:[addresses],cc,bcc,subject,body,attachments:[workspace-relative paths],replyToMessage optional); send(profile,draftId,sha256); flag(profile,folder,uid,uidValidity,flag seen|unseen|starred|unstarred); notifications; ack(noticeIds). Profile is an explicit absolute user-private JSON file, account and username required; incoming {protocol:imap|pop3,host,port,security:ssl|starttls}, smtp {host,port,security}. auth password uses passwordEnv. auth oauth2 uses accessTokenEnv or oauth {provider:google|microsoft,clientId,refreshTokenEnv,clientSecretEnv optional,tenant optional,scope optional,rotatedTokenFile}. The rotated token file must be private; later refreshes prefer it. Message <=8MiB; attachments total<=6MiB. No IMAP delete/expunge; POP3 never DELE. State/cache/drafts are private .mochilab/email-desk under the current agent workspace.

IMAP remote-search(profile,folder,query,field TEXT|SUBJECT|FROM|TO|BODY,limit 1..500) returns matching UIDs and UIDVALIDITY. fetch(profile,folder,uid,uidValidity) caches a selected server message without marking it seen or emitting a new-mail notice.
