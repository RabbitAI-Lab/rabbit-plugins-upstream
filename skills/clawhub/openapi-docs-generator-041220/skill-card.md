## Description: <br>
Helps API developers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs using practical workflows, checklists, and verification steps. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, backend teams, platform teams, and developer-experience maintainers use this skill to produce or review OpenAPI/Swagger documentation for REST APIs. It helps clarify requirements, generate actionable documentation workflows or artifacts, and identify verification steps. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad API or software-documentation phrasing may activate the skill for unrelated backend work. <br>
Mitigation: Use it specifically for OpenAPI, Swagger, REST endpoint documentation, schema review, and validation tasks; route unrelated backend implementation requests to a more specific skill. <br>
Risk: Generated documentation or validation advice can be incomplete or mismatched to the actual service behavior. <br>
Mitigation: Review generated artifacts against the source API implementation, run schema validation where available, and keep assumptions visible in the final output. <br>
