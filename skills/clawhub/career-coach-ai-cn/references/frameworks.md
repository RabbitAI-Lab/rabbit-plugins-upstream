# 职业发展框架卡

按需加载。每个框架给出「何时用 + 怎么做」。

## GROW（目标对话）
- **G Goal 目标**：用户真正想要什么？（区分表面诉求与深层目标）
- **R Reality 现状**：现在在哪？已试过什么？卡点是什么？
- **O Options 选项**：列出 3+ 条路径，标注风险 / 成本 / 回报。
- **W Will 意愿**：本周做哪一件？何时做？怎么防放弃？
> 用法：先确认 G，再 R，避免一上来就给方案。

## Ikigai（热爱与价值交汇）
四圈交集 = 热爱的事 / 擅长的事 / 世界需要的事 / 能赚钱的事。
- 迷茫时让用户分别列出四圈，找重叠区。
- 若四圈不交：先补「能赚钱」维持生存，再用业余时间逼近交集。
> 用法：适合「不知道自己想做什么」「想转行但没方向」。

## SWOT（自我盘点）
- **S 优势**：比别人强在哪（可量化更好）。
- **W 劣势**：明显短板、待补能力。
- **O 机会**：行业 / 公司 / 岗位趋势红利。
- **T 威胁**：被替代风险、竞争、外部环境。
> 用法：跳槽 / 晋升前做竞争力体检；输出「发挥 S 抓 O、补 W 防 T」的行动。

## 70-20-10 学习法则
- 70% 在真实任务中练（接有挑战的项目）。
- 20% 向他人学（导师 / 高手反馈）。
- 10% 系统学习（课程 / 书）。
> 用法：用户说「想提升某能力」时，优先给「做一个真实项目」的具体动作，而非只推课。

## 生涯彩虹图（角色平衡）
人在不同人生阶段扮演多重角色（工作者 / 学习者 / 家庭 / 休闲…）。
- 用于「忙到失衡 / 想兼顾家庭又怕掉队」类困惑。
- 引导用户画出当前角色投入占比，找失衡点。
> 用法：不解决单点问题，解决「整体人生配置」焦虑。

## SMART 目标
具体 / 可衡量 / 可达 / 相关 / 有时限。把模糊愿望改写成一句带截止日的行动句。
