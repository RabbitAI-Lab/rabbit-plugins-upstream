## Description:

Guides formatting and template structure for Tencent-style open-source repository documentation, including README, contribution, license, security, conduct, and GitHub issue and pull-request files.

This skill is ready for commercial/non-commercial use.

## Publisher:

[qikairo7](https://clawhub.ai/user/qikairo7)

### License/Terms of Use:

MIT-0

## Use Case:

Open-source maintainers and developers use this skill to format repository documentation and choose consistent skeletons for contribution guides, governance files, and GitHub issue and pull-request templates. It addresses layout rather than the substantive content of those documents.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Suggested license, security, conduct, or GitHub template changes may not match a project's governance and language policies.

Mitigation: Review these changes against the project's policies before committing or publishing.
