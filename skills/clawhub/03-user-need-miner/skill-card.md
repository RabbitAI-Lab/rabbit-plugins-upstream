## Description:

User Need Miner extracts authentic user needs from interviews, social media discussions, reviews, and forum posts, then produces structured personas and prioritized need lists.

This skill is ready for commercial/non-commercial use.

## Publisher:

[shiyan521](https://clawhub.ai/user/shiyan521)

### License/Terms of Use:

MIT-0

## Use Case:

Product managers, founders, user researchers, and builders use this skill to turn user interviews, public comments, reviews, and forum discussions into personas, explicit and implicit needs, emotional signals, and prioritized requirement tables.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: If no source data is provided, the skill may direct the agent to search public websites and summarize public user comments.

Mitigation: Confirm that public web data collection is appropriate for the product, jurisdiction, and research purpose before using web-sourced comments.

Risk: Interview notes, support records, or user feedback may contain private, sensitive, or regulated personal data.

Mitigation: Remove or anonymize sensitive personal data before providing source material unless that data is intentionally in scope for the analysis.
