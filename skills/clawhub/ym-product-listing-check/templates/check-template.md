# 商品信息检查模板

> 复制本文件填充内容。先填检查范围与假设，再按缺漏、矛盾、风险三张表填，最后分必改项与建议项两档。风险词只提示不判定合规，详见 `references/risk-words.md`。

```
## 检查范围与假设
- 已查字段：[标题 / 参数表 / 详情描述 / 规格 / 价格 / 库存]
- 未提供：[详情描述 / 品类]
- 假设：[按通用商品检查；未覆盖平台专属规则]

## 缺漏清单
| 位置 | 缺的项 | 风险 |
| --- | --- | --- |
| 参数表 | 材质/成分 | 高 |

## 一致性矛盾
| 位置 | 矛盾点 | 建议 |
| --- | --- | --- |
| 标题 vs 参数 | 标题500ml / 参数500g | 统一为体积或质量，给出准确值 |

## 描述风险
| 位置 | 风险词 | 风险 |
| --- | --- | --- |
| 详情第2段 | 「第一」「永久」 | 高（绝对化，仅提示不判定） |

## 上架前必改项
1. [补材质字段]
2. [修正标题与参数单位矛盾]
3. [删除无依据划线价]

## 建议优化项
1. [「高效」改为可量化表述]
2. [补充尺寸与是否含配件信息]
```

## 填写约束

1. 开头必须写明检查范围与假设，未查的字段不能假装查过
2. 缺漏清单对照 12 项必填逐条核对，缺的写「缺」或「未提供」
3. 一致性矛盾必须给可直接替换的修改建议文字
4. 风险词只标位置与等级，不写「违规」结论
5. 必改项与建议项严格分档：必改=缺必填项/参数矛盾/高风险词；建议=可理解性/表达优化/中低风险
