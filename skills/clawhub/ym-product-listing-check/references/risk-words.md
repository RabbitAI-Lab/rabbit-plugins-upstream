# 描述风险词库

本词库只用于**提示风险**，不判定是否违反广告法。是否违规由用户或法务按平台与法律判定。命中词不等于一定违规，但应引起注意并给出更稳妥的改写方向。

## 一、绝对化与夸大用语

| 风险词 | 类型 | 改写方向 |
|---|---|---|
| 最、最佳、最好、最优、顶级、极品、第一、唯一、首家、全国领先、世界领先 | 绝对化用语 | 改为可量化或相对表述，如「销量靠前」需有依据 |
| 100%、永久、永远、绝不、百分百、 guaranteed | 无例外承诺 | 限定条件，如「质保期内」 |
| 特效、神效、奇效、立竿见影、瞬间、立即见效 | 夸大功效 | 改为客观描述使用感受 |
| 顶级工艺、极致、完美、绝无仅有 | 主观绝对 | 改为具体工艺说明 |

## 二、功效与敏感承诺

| 风险领域 | 典型表述 | 注意点 |
|---|---|---|
| 医疗 | 治疗、治愈、消炎、杀菌、抗病、防癌 | 非医疗器械/药品不得宣称 |
| 保健 | 增强免疫力、调理、排毒、降三高 | 需有相应资质与依据 |
| 美白/祛斑 | 美白、淡斑、祛斑、提亮 | 化妆品限「美白」特殊用途备案 |
| 减肥 | 减肥、瘦身、燃脂、月瘦十斤 | 食品不得宣称减肥功效 |
| 防脱发/生发 | 防脱、生发、密发 | 属特殊用途或医疗表述 |

## 三、虚假促销与价格误导

| 风险表述 | 类型 | 改写方向 |
|---|---|---|
| 划线价无依据（原价划掉但无真实成交） | 虚假促销 | 保留真实成交价，不虚构原价 |
| 限时无限循环（「仅今天」长期挂） | 虚假紧迫 | 标明真实活动周期 |
| 全网最低、史上最便宜 | 无法证实 | 删除或给可证实口径 |
| 假一罚十（无明确执行机制） | 承诺不可执行 | 写清赔付条件与渠道 |
| 免费送但高额邮费 | 诱导 | 如实标注费用 |

## 四、使用提示

1. 命中词只列位置与风险等级，不下「违规」结论
2. 改写建议给可替换文字，但用户需自行确认是否符合平台与法规
3. 不同平台对敏感词尺度不同，缺平台信息时只做通用提示
4. 食品、保健品、医疗器械、化妆品为高风险品类，相关词优先标高等级
