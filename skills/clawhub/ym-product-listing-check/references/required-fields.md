# 必填项清单与一致性口径规则

## 一、12 项必填清单

逐项核对，缺一项列一项。带 * 的为按品类可能调整的派生项。

| 序 | 必填项 | 说明 | 常见缺失后果 |
|---|---|---|---|
| 1 | 名称 | 商品名，含核心品类词 | 搜索不到、用户不知卖什么 |
| 2 | 品类 | 所属类目 | 影响其余必填项与违规点 |
| 3 | 品牌 | 品牌或「无品牌」 | 售后与搜索信任度 |
| 4 | 规格与单位 | 如 500g、30cm，单位须明确 | 单位缺失导致无法比价 |
| 5 | 材质或成分 | 食品写成分、服饰写材质、电器写材质 | 缺则涉虚假宣传风险 |
| 6 | 数量 | 件数/ pairs/ 套数 | 与规格混淆易错 |
| 7 | 价格 | 售价，多规格标全 | 缺价无法成交 |
| 8 | 库存 | 可售数量 | 超卖或显示无货 |
| 9 | 产地 | 生产地或品牌国 | 部分品类强制 |
| 10 | 保质期或有效期 | 食品/美妆/药品必填 | 缺则违规高风险 |
| 11 | 适用场景 | 谁用、在哪用、怎么用 | 决策信息缺失 |
| 12 | 售后 | 退换、保修、七天无理由 | 缺则信任与合规风险 |

**品类派生项示例：** 食品补「储存条件」、电器补「功率/电压」、服饰补「尺码表」、美妆补「肤质适用」。未提供品类时这些不强制，但要在输出注明「品类相关项未覆盖」。

## 二、一致性口径规则

同一属性在 标题 / 参数表 / 详情描述 三处必须一致。判定要点：

### 1. 同属性同值
- 标题「500g」、参数「0.5kg」、详情「一斤装」→ 数值等价，可接受
- 标题「500ml」、参数「500g」→ 体积与质量混用，矛盾，必改
- 标题「大容量」、参数「300ml」→ 主观词与精确值冲突，建议量化统一

### 2. 单位统一且合理
- 重量：g / kg；长度：cm / m；体积：ml / L
- 不混用不同量纲（ml 与 g、cm 与 g）
- 同一商品内同一属性全程用同一单位，不在段落间跳

### 3. 价格与规格匹配
- 多规格价格梯度应合理：大规格单价通常不高于小规格（防倒挂）
- 划线价（原价）须有真实成交依据，否则标虚假促销风险
- 规格与价格一一对应，无「同价不同规格却无说明」

### 4. 库存口径
- 总库存 = 各规格库存之和（或明确说明口径）
- 总库存与各规格库存对不上 → 矛盾，必改
- 「现货」「预售」混发须注明，否则标一致性风险

## 三、风险等级口径

- 高：缺必填硬项 / 参数矛盾会被用户直接识破 / 命中高敏感违规词（医疗、绝对化）
- 中：可理解性缺失、中风险词、单位不统一但不矛盾
- 低：表达优化、非敏感词建议
