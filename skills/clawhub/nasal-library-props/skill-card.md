## Description:

Explains the Nasal property tree library (`props`), including property node wrapper instantiation, path navigation, attribute controls, direct data binding utilities, and tree condition evaluation.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and FlightGear add-on authors use this skill to get concise guidance and examples for working with the Nasal `props` API, including property tree navigation, value mutation, attributes, aliases, conditions, and runtime bindings.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Examples involving global properties, attribute changes, removals, aliases, or `runBinding` can change live FlightGear simulator state when adapted into real code.

Mitigation: Review generated Nasal snippets before use and test with isolated property trees before applying them to `props.globals` or runtime bindings.
