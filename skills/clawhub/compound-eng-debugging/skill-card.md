## Description:

Systematic root-cause debugging with verification for errors, stack traces, broken tests, flaky tests, regressions, and other unexpected behavior.

This skill is ready for commercial/non-commercial use.

## Publisher:

[iliaal](https://clawhub.ai/user/iliaal)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to investigate failures systematically, reproduce symptoms, form evidence-backed hypotheses, trace root causes, implement focused fixes, and verify the result.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Diagnostic reports can expose local repository or machine metadata if shared without review.

Mitigation: Review and redact usernames, absolute paths, private repository names, git remote URLs, tokens, hostnames, and environment values before sharing reports.
