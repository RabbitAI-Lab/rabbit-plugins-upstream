# Docker Installation

## 何时读取

当用户的问题涉及 n8n 文档 `hosting/installation/docker.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- n8n recommends using Docker for most self-hosting needs. It provides a clean, isolated environment, avoids operating system and tooling incompatibilities, and makes database and environment management simpler. You can also use n8n in Docker with Docker Compose. You can find Docker Compose configurations for various architectures in the n8n-hosting repository.
