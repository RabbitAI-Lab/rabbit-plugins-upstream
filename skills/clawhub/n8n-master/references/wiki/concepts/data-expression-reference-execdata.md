# ExecData

## 何时读取

当用户的问题涉及 n8n 文档 `data/expression-reference/execdata.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- **Description:** Set and get custom execution data (e.g. to filter executions by). You can also do this with the ‘Execution Data’ node. More info **Syntax:** `$exec`.`$exec`.**`customData`**

## 快速定位

- `$exec`.**`customData`**
- `$exec`.**`id`**
- `$exec`.**`mode`**
- `$exec`.**`resumeFormUrl`**
- `$exec`.**`resumeUrl`**
