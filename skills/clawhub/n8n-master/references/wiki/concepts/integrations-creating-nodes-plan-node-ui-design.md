# Design your node's user interface

## 何时读取

当用户的问题涉及 n8n 文档 `integrations/creating-nodes/plan/node-ui-design.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- Most nodes are a GUI (graphical user interface) representation of an API. Designing the interface means finding a user-friendly way to represent API endpoints and parameters. Directly translating an entire API into form fields in a node may not result in a good user experience. This document provides design guidance and standards to follow. These guidelines are the same as those used by n8n. This helps provide a smooth and consistent user experience for users mixing community and built-in nodes.
