# Install private nodes

## 何时读取

当用户的问题涉及 n8n 文档 `integrations/creating-nodes/deploy/install-private-nodes.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- You can build your own nodes and install them in your n8n instance without publishing them on npm. This is useful for nodes that you create for internal use only at your company. If you're running n8n using Docker, you need to create a Docker image with the node installed in n8n.

## 快速定位

- Install your node in a Docker n8n instance
- Install your node in a global n8n instance
