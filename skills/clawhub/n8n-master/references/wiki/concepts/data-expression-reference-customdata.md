# CustomData

## 何时读取

当用户的问题涉及 n8n 文档 `data/expression-reference/customdata.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- **Description:** Returns the custom execution data stored under the given key. More info **Syntax:** `$execution.customData`.get(key)

## 快速定位

- `$execution.customData`.**`get()`**
- `$execution.customData`.**`getAll()`**
- `$execution.customData`.**`set()`**
- `$execution.customData`.**`setAll()`**
