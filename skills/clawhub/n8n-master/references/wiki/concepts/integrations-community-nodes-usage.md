# Using community nodes

## 何时读取

当用户的问题涉及 n8n 文档 `integrations/community-nodes/usage.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- To use community nodes, you first need to install them. After installing a community node, you can use it like any other node. n8n displays the node in search results in the **Nodes** panel. n8n marks community nodes with a **Package** !Package icon icon in the nodes panel.

## 快速定位

- Adding community nodes to your workflow
- Community nodes with duplicate names
