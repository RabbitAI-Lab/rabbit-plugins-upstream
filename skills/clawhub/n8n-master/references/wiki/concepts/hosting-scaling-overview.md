# Scaling n8n

## 何时读取

当用户的问题涉及 n8n 文档 `hosting/scaling/overview.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- When running n8n at scale, with a large number of users, workflows, or executions, you need to change your n8n configuration to ensure good performance. n8n can run in different modes depending on your needs. The `queue` mode provides the best scalability. Refer to Queue mode for configuration details.
