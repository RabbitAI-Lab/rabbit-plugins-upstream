# Built-in integrations

## 何时读取

当用户的问题涉及 n8n 文档 `integrations/builtin/node-types.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- This section contains the node library: reference documentation for every built-in node in n8n, and their credentials. Core nodes can be actions or triggers. Whereas most nodes connect to a specific external service, core nodes provide functionality such as logic, scheduling, or generic API calls.

## 快速定位

- Core nodes
- Cluster nodes
- Credentials
- Community nodes
