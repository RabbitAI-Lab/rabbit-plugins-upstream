# Approaches for transforming data

## 何时读取

当用户的问题涉及 n8n 文档 `data/transforming-data.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- Data transformation in n8n involves modifying, restructuring, or enriching data as it moves through your workflow. This includes changing data formats, filtering or aggregating values, adding computed fields, and converting data structures to work with different nodes. n8n uses a predefined data structure that allows all nodes to process incoming data correctly. When your data doesn't match this structure, or when you need to modify it for your use case, you'll need to transform it.
