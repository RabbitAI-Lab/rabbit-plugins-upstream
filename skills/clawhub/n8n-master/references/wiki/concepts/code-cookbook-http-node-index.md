# Examples using n8n's HTTP Request node

## 何时读取

当用户的问题涉及 n8n 文档 `code/cookbook/http-node/index.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- The HTTP Request node is one of the most versatile nodes in n8n. Use this node to make HTTP requests to query data from any app or service with a REST API. Refer to HTTP Request for information on node settings.
