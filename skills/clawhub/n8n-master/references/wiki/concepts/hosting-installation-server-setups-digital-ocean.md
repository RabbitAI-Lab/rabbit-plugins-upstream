# Hosting n8n on DigitalOcean

## 何时读取

当用户的问题涉及 n8n 文档 `hosting/installation/server-setups/digital-ocean.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- This hosting guide shows you how to self-host n8n on a DigitalOcean droplet. It uses: 1. Log in to DigitalOcean. 2. Select the project to host the Droplet, or create a new project. 3. In your project, select **Droplets** from the **Manage** menu. 4. Create a new Droplet using the Docker image available on the **Marketplace** tab.
