# Pre-configure Microsoft OAuth credentials

## 何时读取

当用户的问题涉及 n8n 文档 `hosting/configuration/configuration-examples/microsoft-oauth-credential-overwrites.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- Use credential overwrites to pre-configure Microsoft OAuth2 credentials in n8n so users can connect without their own app registration.

## 快速定位

- Create the credentials file
- Docker Compose
- Verify the overwrite is applied
- Kubernetes
- Plain Kubernetes Secret (EKS / AKS / GKE)
- AWS Secrets Manager (EKS)
- Azure Key Vault (AKS)
- Google Secret Manager (GKE)
