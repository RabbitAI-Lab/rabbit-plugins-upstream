# Referencing data in the UI

## 何时读取

当用户的问题涉及 n8n 文档 `data/data-mapping/data-mapping-ui.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- Data mapping means referencing data from previous nodes. It doesn't include changing (transforming) data, just referencing it. When you need data from a particular node in your workflow, you can reference nodes by name. This is useful when your workflow has multiple branches or when you need to access data from several steps back.
