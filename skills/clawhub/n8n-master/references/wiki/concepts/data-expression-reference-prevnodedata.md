# PrevNodeData

## 何时读取

当用户的问题涉及 n8n 文档 `data/expression-reference/prevnodedata.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- **Description:** The name of the node that the current input came from. Always uses the current node’s first input connector if there is more than one (e.g. in the ‘Merge’ node).

## 快速定位

- **`name`**
- **`outputIndex`**
- **`runIndex`**
