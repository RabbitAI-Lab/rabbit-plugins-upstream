# Branch patterns

## 何时读取

当用户的问题涉及 n8n 文档 `source-control-environments/understand/patterns.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- Understand the different relationships between n8n instances and Git branches that are possible with source control.

## 快速定位

- Multiple instances, multiple branches
- Multiple instances, one branch
- One instance, multiple branches
- One instance, one branch
