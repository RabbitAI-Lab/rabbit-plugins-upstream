# OpenTelemetry tracing

## 何时读取

当用户的问题涉及 n8n 文档 `hosting/logging-monitoring/opentelemetry.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- Send workflow and node execution traces from n8n to an OpenTelemetry collector.

## 快速定位

- What you get
- Enable tracing
- Sampling
- Reduce span volume
- Add custom attributes to node spans
- Try it out with Jaeger
- Span attributes
- Workflow span (`workflow.execute`)
- Node span (`node.execute`)
- Troubleshooting
- No traces appear in your backend
- Worker traces are missing parent context
- Related resources
