# Using the n8n-node tool

## 何时读取

当用户的问题涉及 n8n 文档 `integrations/creating-nodes/build/n8n-node.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- The `n8n-node` tool is the official CLI for developing community nodes for n8n. You can use it to scaffold out new nodes, build your projects, and run your node as you develop it. Using `n8n-node`, you can create nodes that adhere to the guidelines for verified community nodes.
