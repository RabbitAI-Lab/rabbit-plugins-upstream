# Hosting n8n on Hetzner cloud

## 何时读取

当用户的问题涉及 n8n 文档 `hosting/installation/server-setups/hetzner.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- This hosting guide shows you how to self-host n8n on a Hetzner cloud server. It uses: 1. Log in to the Hetzner Cloud Console. 2. Select the project to host the server, or create a new project by selecting **+ NEW PROJECT**. 3. Select **+ CREATE SERVER** on the project tile you want to add it to.
