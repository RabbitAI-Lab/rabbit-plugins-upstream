# Hosting n8n on Azure

## 何时读取

当用户的问题涉及 n8n 文档 `hosting/installation/server-setups/azure.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- This hosting guide shows you how to self-host n8n on Azure. It uses n8n with Postgres as a database backend using Kubernetes to manage the necessary resources and reverse proxy. You need The Azure command line tool
