# Deprecated and versioned nodes

## 何时读取

当用户的问题涉及 n8n 文档 `integrations/builtin/deprecated-and-versioned-nodes.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- n8n improves its node library over time. This page lists removed nodes (fully removed), deprecated nodes (retired but still functional), and versioned nodes (active with multiple versions available). n8n won't release further updates or bug fixes for deprecated nodes. Existing workflows that use them continue to run, but you should migrate to a supported alternative.

## 快速定位

- Deprecated nodes
- Removed nodes
- Versioned nodes
