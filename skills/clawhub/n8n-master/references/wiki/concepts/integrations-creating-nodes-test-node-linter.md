# n8n node linter

## 何时读取

当用户的问题涉及 n8n 文档 `integrations/creating-nodes/test/node-linter.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- n8n's node linter, `@n8n/eslint-plugin-community-nodes`, statically analyzes ("lints") the source code of n8n nodes and credentials in community packages. The linter detects issues and automatically fixes them to help you follow best practices. `@n8n/eslint-plugin-community-nodes` contains a collection of rules for node files (`*.node.ts`), credential files (`*.credentials.ts`), and the `package.json` of a community package.
