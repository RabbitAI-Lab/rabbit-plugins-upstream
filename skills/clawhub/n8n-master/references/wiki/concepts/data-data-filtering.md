# Filtering data

## 何时读取

当用户的问题涉及 n8n 文档 `data/data-filtering.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- Filtering in n8n can mean different things depending on what you want to accomplish. This guide covers both visual filtering in the UI and data filtering during workflow execution. Search and filter data in the node **INPUT** and **OUTPUT** panels. Use this to check your node's data and find specific items.

## 快速定位

- Filter data visually in the UI
- Filter data during workflow execution
- Filter out items
- Filter out fields
- Filter array elements
- Filter out duplicate items from previous executions
