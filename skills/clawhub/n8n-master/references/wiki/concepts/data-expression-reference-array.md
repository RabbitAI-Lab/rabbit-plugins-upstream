# Array

## 何时读取

## 核心要点

- **Description:** Adds new elements to the end of the array. Similar to push(), but returns the modified array. Consider using spread syntax instead (see examples). **Syntax:** _`Array`_.append(elem1, elem2?, ..., elemN?)
