# Hardening task runners

## 何时读取

当用户的问题涉及 n8n 文档 `hosting/securing/hardening-task-runners.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- Harden task runners for better isolation for your self-hosted n8n instance.

## 快速定位

- Run task runners as sidecars in external mode
- Use the distroless image
- Run as the nobody user
- Configure read-only root filesystem
