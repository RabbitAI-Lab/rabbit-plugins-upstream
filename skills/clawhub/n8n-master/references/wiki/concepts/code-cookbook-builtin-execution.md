# `execution`

## 何时读取

当用户的问题涉及 n8n 文档 `code/cookbook/builtin/execution.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- Contains the unique ID of the current workflow execution. === "JavaScript" ```js let executionId = $execution.id; ``` === "Python" ```python executionId = _execution.id ```

## 快速定位

- `execution.id`
- `execution.resumeUrl`
- `execution.customData`
