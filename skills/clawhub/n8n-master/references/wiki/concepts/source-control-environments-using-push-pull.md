# Push and pull

## 何时读取

当用户的问题涉及 n8n 文档 `source-control-environments/using/push-pull.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- Send work to Git, and fetch work from Git to your instance.

## 快速定位

- Fetch other people's work
- Workflow and credential owner may change on pull
- Auto publish workflows on pull
- Pulling may cause brief service interruption
- Send your work to Git
- What gets committed
- Merge behaviors and conflicts
- Workflows
- Credentials, variables and workflow tags
- Data tables
