# Referencing data

## 何时读取

当用户的问题涉及 n8n 文档 `data/data-mapping/index.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- Referencing data, or data mapping, means accessing information from previous nodes in your workflow. This allows you to use output from earlier steps as input for later nodes, creating dynamic workflows that pass data through multiple operations. When you reference data, you're not changing it. You're pointing to values that already exist so you can use them in node parameters, expressions, or custom code.
