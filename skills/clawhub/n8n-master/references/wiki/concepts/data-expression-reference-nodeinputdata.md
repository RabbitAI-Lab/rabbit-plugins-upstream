# NodeInputData

## 何时读取

当用户的问题涉及 n8n 文档 `data/expression-reference/nodeinputdata.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- **Description:** Returns an array of the current node’s input items **Syntax:** `$input`.all(branchIndex?, runIndex?)

## 快速定位

- `$input`.**`all()`**
- `$input`.**`first()`**
- `$input`.**`item`**
- `$input`.**`last()`**
- `$input`.**`params`**
