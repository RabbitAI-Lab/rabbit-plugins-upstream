# Alibaba Cloud Model Studio node

## 何时读取

当用户要在 n8n 中使用、配置、排查或替代 `Alibaba Cloud Model Studio node` 时读取。该卡片由官方节点文档编译，完整细节以 source 为准。

## 节点标识

- n8n node id: `n8n-nodes-langchain.alibabacloud`
- node group: `app-nodes`

## 核心要点

- Interact with Alibaba Cloud Qwen models via Model Studio. This page explains how to use the node in n8n workflows to generate text completions, analyze or generate images, and create videos from text or images.
