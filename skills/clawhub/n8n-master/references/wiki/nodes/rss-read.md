# RSS Read

## 何时读取

当用户要在 n8n 中使用、配置、排查或替代 `RSS Read` 时读取。该卡片由官方节点文档编译，完整细节以 source 为准。

## 节点标识

- n8n node id: `n8n-nodes-base.rssfeedread`
- node group: `core-nodes`

## 核心要点

- Documentation for the RSS Read node in n8n, a workflow automation platform. Includes guidance on usage, and links to examples.

## 关键操作 / 参数线索

- **URL**: Enter the URL for the RSS publication you want to read.

## 常用选项线索

- **Ignore SSL Issues**: Choose whether n8n should ignore SSL/TLS verification (turned on) or not (turned off).
