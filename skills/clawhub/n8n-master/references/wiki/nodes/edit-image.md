# Edit Image

## 何时读取

当用户要在 n8n 中使用、配置、排查或替代 `Edit Image` 时读取。该卡片由官方节点文档编译，完整细节以 source 为准。

## 节点标识

- n8n node id: `n8n-nodes-base.editimage`
- node group: `core-nodes`

## 核心要点

- Documentation for the Edit Image node in n8n, a workflow automation platform. Includes guidance on usage, and links to examples.

## 关键操作 / 参数线索

- Add a **Blur** to the image to reduce sharpness
- Add a **Border** to the image
- **Composite** an image on top of another image
- **Create** a new image
- **Crop** the image
- **Draw** on an image
- **Get Information** about the image
- **Multi Step** perform multiple operations on the image
- **Resize**: Change the size of the image
- **Rotate** the image
- **Shear** image along the X or Y axis
- Add **Text** to the image
- Make a color in image **Transparent**

## 常用选项线索

- **File Name**: Enter the filename of the output file.
- **Format**: Enter the image format of the output file. Choose from:
- **bmp**
- **gif**
- **jpeg**
- **png**
- **tiff**
- **WebP**
