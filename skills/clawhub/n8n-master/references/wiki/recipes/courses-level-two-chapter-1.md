## 核心要点

- In this chapter, you will learn about the data structure of n8n and how to use the Code node to transform data and simulate node outputs. In a basic sense, n8n nodes function as an Extract, Transform, Load (ETL) tool. The nodes allow you to access (extract) data from multiple disparate sources, modify (transform) that data in a particular way, and pass (load) it along to where it needs to be.
