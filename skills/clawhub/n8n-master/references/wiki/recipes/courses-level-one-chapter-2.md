# Building a Mini-workflow

## 何时读取

当用户的问题涉及 n8n 文档 `courses/level-one/chapter-2.md` 的主题、配置、概念或操作步骤时读取。

## 核心要点

- In this lesson, you will build a small workflow that gets 10 articles about automation from Hacker News. The process consists of five steps: 1. Add a Manual Trigger node 2. Add the Hacker News node 3. Configure the Hacker News node 4. Execute the node 5. Save the workflow
