# 8. Publishing and Examining the Workflow

## 何时读取

## 核心要点

- In this step of the workflow, you will learn how to publish your workflow and change the default workflow settings. Publishing a workflow means that it will run automatically every time a trigger node receives input or meets a condition. By default, newly created workflows are not published.
