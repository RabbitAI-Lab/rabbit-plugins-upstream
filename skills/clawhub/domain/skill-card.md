## Description: <br>
DomainKits helps agents check domain availability, search domains across registration lifecycle stages, and analyze keyword value and trends. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[abtdomain](https://clawhub.ai/user/abtdomain) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
External users and developers use DomainKits to power domain search, availability checks, DNS/WHOIS lookup, domain intelligence, and monitoring workflows from an agent or MCP client. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Domain searches, analyzed domains, and any optional API key are sent to DomainKits. <br>
Mitigation: Install only if this data sharing is acceptable, avoid submitting sensitive domain research, and manage API keys with normal rotation and access controls. <br>
Risk: Memory and monitoring features can store preferences, strategy text, and domain monitoring configuration. <br>
Mitigation: Enable memory deliberately, review stored preferences and monitors, and delete stored data when it is no longer needed. <br>
