## Description:

KeyboardHero is a zero-dependency offline web typing game for beginners, with touch-typing lessons, rhythm play, racing, bomb defusal, tower defense, hero collection, and rank progression.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and agents use this skill to launch or guide a self-contained typing-practice game for keyboard beginners. It supports offline touch-typing practice through progressive lessons and game modes that reinforce characters, words, and short sentences.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Progress and preferences are stored only in the local browser profile.

Mitigation: Tell users that clearing site data, changing browser profiles, or using the in-game clear button can remove saved progress.
