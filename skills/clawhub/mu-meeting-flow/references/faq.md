# 常见问题速查表

| 问题 | 解法 |
|---|---|
| 适配器未配置 | 该步骤自动降级为手动模式，流程不中断，最终汇报中标注降级项。 |
| 日历 API 认证失败 | 检查 OAuth 凭证是否过期并重新授权；使用 Cal.com 时检查 API Key。 |
| 转写质量差 | 检查音频质量；尝试更大的 Whisper 模型（`large > medium > small > base`）；标注低置信度并提示用户校对。 |
| 查不到会议记录 | 确认时间范围是否正确；检查会议平台 API 权限；扩大时间范围 ±1 天后重试。 |
| 纪要/转写为空 | 会议可能未开启录制或转写；提示用户手动补充笔记，并基于笔记提取 TODO。 |
| 参会人标识不明确 | Agent 列出候选让用户选择，不猜测。 |
| 不支持循环日程 | 大部分日历 API 不支持批量循环日程创建，需手动创建多个日程，或使用 API 的 `recurrence` 规则。 |
| 跨时区会议 | 用户必须明确指定时区，Agent 按指定时区处理。 |
| 会议室适配器不支持借用 | 降级为输出联系方式和话术模板，由用户自行联系。 |
