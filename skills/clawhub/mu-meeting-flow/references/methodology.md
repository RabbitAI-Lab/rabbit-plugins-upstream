# 方法论精要

## 灵魂三问（开会前必做）
1. **为什么开这个会？** → 答不上来就不开
2. **不开会能解决吗？** → 邮件/IM/1v1能解决就别开
3. **为什么需要TA？** → 须满足：拍板权/信息权/贡献权/责任权之一。不邀请只做笔记或"感受氛围"的人

## 会议类型识别
| 类型 | 核心目标 | 资料 |
|------|---------|------|
| 决策会（方案评审/立项） | 做决定 | 6页纸 |
| 进度会（周会/月会） | 检查进展排障碍 | 1页纸 |
| 创意会（头脑风暴） | 发散方案 | 白板 |
| 传达会（宣贯/公告） | 对齐信息 | **尽量改书面通知** |

## 会前必做清单
- **T-48h**：确认目标(3W) → 确认参会人(灵魂三问) → 查忙闲 → 订室
- **T-24h**：准备资料(1/6页纸) → 创建日程发邀请(memo附资料+会议链接) → 告知角色
- **T-15min**：确认会议室/链接 → 准备白板/计时器 → 提醒开录制+转写

## 资料标准（亚马逊原则）
**1页纸**：目标(一句话) → 背景(2-3句) → 核心议题(问题+数据+建议) → 期望决策 → 下一步(主R+Deadline)
**6页纸**：结论先行 → 现状分析+方案对比+风险 → 建议方案 → 资源+KPI+里程碑
**原则**：结论先行 + 多用句号

## 会中主持（60分钟标准流程）
[00-02] 开场：到齐确认+录制转写+宣布目标议程
[02-17] 默读：全员静默阅读资料
[17-45] 讨论：逐项推进，主动邀请沉默者，严禁"各有利弊"
[45-55] 决策：总结观点→明确决策→确认TODO(主R+时间)
[55-60] 收尾：复述结论→确认纪要发出时间→散会

## 三大控场工具
| 工具 | 场景 | 话术示例 |
|------|------|---------|
| **转述** | 引导沉默者 | "我理解XX的意思是…你觉得准确吗？" |
| **搁置区** | 拉回跑题 | "这个问题记在搁置区，先聚焦主议题" |
| **抽离** | 处理分歧 | "先把各方观点列出来，看分歧核心是什么" |

## 常见控场场景
- **迟到**：不等，旁边人简要同步
- **跑题**：搁置区工具
- **僵局**：举手表态或指定XX补充信息后再决策
- **沉默**：直接点名邀请
- **从众**：追问"最大风险是什么？失败最可能原因？"

## 会后必做
- **T+2h**：发纪要(标准模板)给所有参会人+相关方
- **T+Deadline-1天**：提醒主R进展
- **下次会议前**：复盘上次TODO完成情况(高光+暗光)

## 会议瘦身七招
1. **减次数**：能文档/邮件解决不开会
2. **减人数**：两张比萨原则(6-8人)，决策者不在不开
3. **缩时间**：默认45min，资料提前发，硬截止
4. **减频次**：委托代参，每季度review例会必要性
5. **提资料**：文字代PPT，结论先行，≤1页(重大≤6页)
6. **默读开场**：15min静默阅读
7. **PDCA复盘**：高光+暗光，记入团队知识库

## 十二字口诀
**有目标、有议题、有产出。准时开、准时结、有跟进。**

## 会议模板化
| 模板 | 时长 | 资料 | 议程 | 特殊处理 |
|------|------|------|------|---------|
| **周会** | 45min | 1页纸(KPI+问题) | TODO复盘10→KPI检查15→本周重点15→收尾5 | 自动搜上周纪要复盘TODO |
| **1on1** | 30min | 无需，准备3个问题 | 近况10→核心议题15→下一步5 | 不强制订会议室 |
| **BR** | 90min | 6页纸(现状+数据+分析) | 默读20→数据Review30→根因25→Action15 | 会前准备数据包 |
| **立项** | 60min | 6页纸+PR/FAQ | 默读15→讲解15→质疑20→决策10 | 会前准备立项材料 |

**周会自动流程**：搜索上周同名会议纪要 → 读取提取未完成TODO → 查忙闲 → 订室 → 创建日程（备注附TODO复盘）
**周期性会议自动带入机制**：创建周会/双周会日程时，备注自动附带"上期遗留TODO"区块。找不到上次会议记录则跳过。
**1on1自动流程**：查双方忙闲 → 创建日程（备注写"请准备最近思考和问题"）

## 远程会议专属要点
- **时区处理**：跨时区会议必须明确标注各参会者时区，选重叠工作时段
- **异步参会者**：无法实时参加的人，会前发材料要求书面反馈，会上宣读
- **网络质量预案**：主链接+备用链接，关键参会者准备电话接入
- **屏幕共享规范**：提前测试，避免现场调试浪费时间
- **录制同意**：远程会议须提前获得参会者录制同意

## 异步会议模式（不开会也能达成目标）
- **适用场景**：信息传达、方案评审（非实时讨论）、状态更新
- **流程**：发材料（1/6页纸）→ 设定反馈截止时间 → 收集书面意见 → 汇总决策 → 书面通知结果
- **优势**：无时间协调成本，参会者深度思考，留痕完整
- **不适用**：需要实时头脑风暴、情感沟通、复杂冲突调解

## 会议ROI评估
- **时间成本** = 参会人数 × 时长 × 平均时薪
- **判断标准**：会议产出价值 > 时间成本 → 值得开；否则考虑异步替代
- **简化公式**：5人×1小时会议 ≈ 5个工时，产出是否等值5个工时的成果？
- **每季度审查**：哪些例会的ROI持续偏低 → 降频/取消/改异步
