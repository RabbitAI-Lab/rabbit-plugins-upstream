# 适配器接口契约与降级规则

## 设计理念

所有外部服务均通过“能力描述 + 接口约定 + 推荐工具 + 降级方案”对接，不写死任何特定工具。用户在 `config/adapters.json` 中声明工具，Agent 按配置调用；未配置的模块自动降级为手动模式。

## 适配器接口契约

### 1. 日历适配器（`calendar`）

- **能力名称**：查忙闲、创建日程、搜索日程、更新日程、删除日程。
- **接口约定**：
  - 查忙闲：输入（用户标识列表、时间范围）→ 输出（每人忙闲时段列表）。
  - 创建日程：输入（标题、参会人、起止时间、地点、备注）→ 输出（日程 ID）。
  - 搜索日程：输入（用户标识、时间范围）→ 输出（日程列表）。
  - 更新日程：输入（日程 ID、更新字段）→ 输出（成功/失败）。
  - 删除日程：输入（日程 ID）→ 输出（成功/失败）。
- **推荐实现**：Google Calendar API（`freebusy.query`、`events.insert/list/patch/delete`）、Cal.com API、CalDAV。
- **配置字段**：`{ "provider": "google|calcom|ics|none", "credentials": "path" }`
- **降级路径**：未配置时跳过忙闲校验，并标注“未校验冲突”；创建日程降级为输出日程信息文本。

### 2. 转写适配器（`transcription`）

- **能力名称**：将会议音频/视频转为结构化转写文本。
- **接口约定**：输入（音频/视频文件路径，或会议平台录制链接）→ 输出（结构化文本，含说话人、时间戳、内容）。
- **推荐实现**：Whisper.cpp（本地、隐私优先）、faster-whisper（Python）、会议平台自带字幕（Zoom/Meet/Teams API）。
- **配置字段**：`{ "provider": "whisper|faster-whisper|platform|none", "model": "base|small|medium|large", "language": "auto|zh|en" }`
- **降级路径**：未配置时提示用户手动记录或上传笔记；AI 提取改为基于用户笔记，而非转写内容。

### 3. 文档适配器（`knowledge`）

- **能力名称**：创建文档、读取文档、更新文档。
- **接口约定**：
  - 创建：输入（标题、内容、父级 ID〔可选〕）→ 输出（文档链接/路径）。
  - 读取：输入（文档 ID/路径）→ 输出（文档内容）。
  - 更新：输入（文档 ID/路径、新内容）→ 输出（成功/失败）。
- **推荐实现**：Notion API、Obsidian（本地文件）、本地 Markdown 文件。
- **配置字段**：`{ "provider": "notion|obsidian|markdown|none", "token": "API token (notion)", "base_path": "本地路径 (obsidian/markdown)" }`
- **降级路径**：未配置时直接在对话中输出文档内容。

### 4. 通知适配器（`messaging`）

- **能力名称**：向指定人员或群组发送消息。
- **接口约定**：输入（接收人标识、消息内容、可选附件链接）→ 输出（发送成功/失败）。
- **推荐实现**：Slack Webhook、Email（SMTP）、自定义 Webhook。
- **配置字段**：`{ "provider": "slack|email|webhook|none", "webhook_url": "Slack webhook URL", "smtp_config": "SMTP配置 (email)" }`
- **降级路径**：未配置时输出消息文本，供用户自行复制发送。

### 5. 会议室适配器（`room`）

- **能力名称**：查询空闲会议室、预订会议室、取消预订。
- **接口约定**：
  - 查询：输入（人数、时间范围、地点偏好〔可选〕）→ 输出（可用会议室列表）。
  - 预订：输入（会议室 ID、时间范围）→ 输出（预订确认）。
  - 取消：输入（预订 ID）→ 输出（成功/失败）。
- **推荐实现**：Google Workspace Rooms API、Microsoft Office365、可选跳过。
- **配置字段**：`{ "provider": "google|office365|none", "credentials": "path" }`
- **降级路径**：未配置时跳过该步骤，并标注"需用户自行安排场地"。

### 6. 会议平台适配器（`meeting`）

- **能力名称**：查询历史会议记录、获取会议录制/字幕。
- **接口约定**：
  - 查询会议：输入（时间范围，参会人标识〔可选〕）→ 输出（会议列表，含会议ID/标题/时间/录制链接/字幕链接）。
  - 获取录制：输入（会议ID）→ 输出（录制文件URL或本地路径）。
  - 获取字幕：输入（会议ID）→ 输出（字幕文本，含时间戳）。
- **推荐实现**：Zoom API（`/report/meetings`）、Google Meet API（Meet recordings via Drive API）、Microsoft Teams API（Graph API `/me/onlineMeetings`）。
- **配置字段**：`{ "provider": "zoom|meet|teams|none", "api_key": "", "api_secret": "" }`
- **降级路径**：未配置时提示用户手动提供会议笔记或转写文本；Agent 基于用户提供的笔记进行后续提取。

## 统一降级规则

### 设计原则

每个外部调用都必须具备明确的降级路径。降级分两层：**未配置降级**（用户未配置工具）和**失败降级**（调用出错）。

### 降级路由表

| 能力 | 主方案 | 失败降级 1 | 失败降级 2 | 未配置降级 |
|---|---|---|---|---|
| 忙闲查询 | 日历适配器查忙闲 | 按重试规则重试一次 | 跳过校验并标注“未校验冲突” | 跳过校验并标注“未校验冲突” |
| 创建/更新/删除日程 | 日历适配器 | 按重试规则重试一次 | 输出可手动执行的日程信息或操作指引 | 输出日程信息文本供手动创建/更新/删除 |
| 获取转写 | 转写适配器 | 按重试规则重试一次 | 请求用户提供会议笔记并据此提取 | 提示用户手动记录或上传笔记 |
| 创建/读取/更新文档 | 文档适配器 | 按重试规则重试一次 | 在对话中输出完整文档内容 | 在对话中输出完整文档内容 |
| 推送通知 | 通知适配器 | 按重试规则重试一次 | 输出可复制的消息文本 | 输出可复制的消息文本 |
| 查询/预订/取消会议室 | 会议室适配器 | 查询周边会议室或按重试规则重试一次 | 标注"需用户自行安排场地" | 标注"需用户自行安排场地" |
| 查询会议记录/录制 | 会议平台适配器 | 按重试规则重试一次 | 提示用户手动提供笔记或转写文本 | 提示用户手动提供笔记或转写文本 |

### 降级执行规则

- 自动执行降级，不询问用户。
- 降级时在最终汇报中标注，例如“⚠️ 忙闲未校验，建议确认”。
- 只有降级链全部穷尽时，才暂停并通知用户。
- 重试间隔：首次失败后 5 秒，第二次失败后 10 秒；最多重试 1 次。

## 借会议室流程

当会议室全满时，按以下流程处理：

1. 查询周边可用会议室（更换楼层或建筑）。
2. 如平台允许且用户具备权限，可显示可联系的预订信息；否则仅展示可用替代方案。
3. 提供借用话术模板。
4. 等待用户确认后，通过通知适配器发送借用请求。
5. 未配置通知适配器时，输出话术文本，让用户自行联系。

**借用话术模板：**

> 你好，我计划在 [日期/时间] 组织 [会议主题]，目前附近会议室已满。请问 [会议室名称] 在该时段是否可能提前结束或可以协调借用？我们预计使用 [时长]，参会约 [人数] 人。如方便，非常感谢。
