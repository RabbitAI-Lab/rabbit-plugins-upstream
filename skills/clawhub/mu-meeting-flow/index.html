核心亮点

只做会议流该做的事

🔄 三阶段连续流程

会前自动化、会中提示与主持、会后自动化不是孤立任务，而是同一条会议节奏。

🧩 六类可选适配器

日历、转写、文档、通知、会议室和会议平台都以能力约定接入，不绑定特定服务。

🧭 不阻断的首次引导

首次使用可逐项配置，也能全部跳过；配置结束后会直接接续原始会议需求。

🧠 内置会议方法论

先判断是否真的需要开会，再用会前阅读、时间盒讨论和明确决策提升会议质量。

🔔 五层 TODO 闭环

即时推送、到期提醒、每日巡检、下次会议带入和完成验证，让行动项不止停在纪要里。

📦 纯 Markdown 开箱即用

无需安装服务或额外依赖，克隆到 Skill 目录即可被任何兼容 AI Agent 读取使用。

💡 这不是要替代日历、转写或文档工具，而是将它们与人工操作组织成一条连续会议流程；外部服务可按你的现有工作方式接入或跳过。

工作流

会前 · 会中 · 会后

每一阶段都有明确产出；适配器未配置或调用失败时，流程继续，而不是中断。

第一阶段 · 7 步

会前自动化

  1. 提取会议信息
  2. 查忙闲并选时段
  3. 订会议室与创建日程
  4. 准备会前材料并汇报

手动路径：输出候选时间、可复制日程信息和会前材料；清晰标注未校验项。

第二阶段 · 5 步

会中提示与主持

  1. 确认目标、议程与记录方式
  2. 默读与结构化讨论
  3. 逐项确认决策与 TODO
  4. 复盘产出并准时收尾

手动路径：提示参会人记录笔记，维护搁置问题清单，并在会后发送可复制回顾。

第三阶段 · 6 步

会后自动化

  1. 定位记录、纪要与转写
  2. 提取结论、TODO 与风险
  3. 更新 TODO 池与会议纪要
  4. 推送纪要与行动摘要

手动路径：只基于用户提供的笔记处理；缺少信息时追问，绝不编造讨论结果。
