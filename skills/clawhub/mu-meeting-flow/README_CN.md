### 💡 使用场景示例

- 📅 **安排决策会** — 将议题、参会人和时间偏好整理为可检查冲突的会议方案与待发日程信息。
- 🧭 **筹备周会** — 自动带入未完成行动项，生成聚焦议程与一页式讨论材料。
- 🗂️ **组织项目评审** — 用会前阅读、结构化讨论和明确责任人的流程推动项目决策。
- 🎙️ **现场主持会议** — 获得开场、默读、讨论、决策、收尾五个环节的时间盒提示。
- 📝 **将笔记整理为纪要** — 从用户提供的转写或会议笔记中提取结论、待办、责任人、截止日期和风险。
- ✅ **闭环会议行动项** — 通过提醒、下次同类会议回顾与完成证据验证持续跟进待办。

### ✨ 核心亮点

#### 🔄 三阶段会议流
将一次会议串为**会前自动化**、**会中提示与主持**、**会后自动化**三段连续流程。它帮助 AI Agent 把约会、主持和跟进连接为可重复执行的会议节奏，而非彼此孤立的任务。

#### 🧩 六类适配器与手动降级
Skill 为日历、转写、文档、通知、会议室、会议平台定义可选适配器。它们是能力约定，不是内置集成；适配器未配置或不可用时，流程会继续输出日程信息、可复制消息或笔记请求等手动操作内容。

#### 🧭 首次使用引导不阻断任务
首次使用时，Agent 可逐项询问可用的外部工具。用户可以跳过任意或全部适配器；系统将保留手动降级路径，并直接接续原始会议需求，无需用户重新描述。

#### 🧠 内置会议方法论
流程先回答三个问题：为什么要开、能否异步解决、为什么需要每位参会人。随后按会议类型提供模板、会前阅读、时间盒主持、明确决策和会议规模控制建议。

#### 🔔 TODO 五层提醒与闭环
行动项可进入统一 TODO 池，并通过会后即时推送、到期提醒、每日巡检、下次同类会议带入、完成证据验证五层机制跟进。定时提醒取决于宿主 Agent 是否具备调度能力；不具备时会降级为对话中的临期提示。

> 这不是要替代日历、转写或文档工具。它的角色是把这些可选能力与人工操作组织成一条连续会议流程；每个外部工具仍可按你的现有工作方式接入或跳过。

### 🚀 核心工作流

#### 会前自动化

| 步骤 | 流程引导内容 | 降级路径 |
|---|---|---|
| 1. 提取会议信息 | 提取主题、参会人、时间偏好、时长与地点偏好。 | 仅在关键信息不明确时追问。 |
| 2. 查忙闲 | 通过日历适配器查看参会人的可用时间。 | 标注“未校验冲突”。 |
| 3. 选时段 | 对照时间偏好与忙碌时段，推荐最佳空闲窗口。 | 输出候选时段供手动确认。 |
| 4. 订会议室 | 按参会人数请求适合的会议室。 | 标注“需自行安排场地”；满房时提供借用话术。 |
| 5. 创建日程 | 组织标题、参会人、时间、地点和备注，创建日程。 | 输出可直接复制的日程信息供手动创建。 |
| 6. 准备会前材料 | 按会议类型匹配议程或一页纸/六页纸材料。 | 直接在对话中输出材料。 |
| 7. 一次性汇报 | 一次汇总时间、参会人、地点和会前材料。 | 清晰标出所有手动项与未校验项。 |

#### 会中提示与主持

| 步骤 | 流程引导内容 | 降级路径 |
|---|---|---|
| 1. 开场 | 确认到场、录制/转写状态、目标与议程。 | 录制或转写不可用时，提示参会人记录笔记。 |
| 2. 默读 | 预留时间让全员阅读会前材料。 | 在聊天中分享材料，或口头说明关键内容。 |
| 3. 结构化讨论 | 逐项推进，邀请沉默者发言，并将跑题问题放入搁置区。 | 手动维护搁置问题清单。 |
| 4. 确认决策与 TODO | 每个议题结束前明确结论、主 R 和截止日期。 | 在笔记中记录，待会后确认。 |
| 5. 收尾 | 复述产出、确认纪要发送时间并准时结束。 | 会后输出可复制的会议回顾消息。 |

#### 会后自动化

| 步骤 | 流程引导内容 | 降级路径 |
|---|---|---|
| 1. 查会议记录 | 定位会议、录制或已有笔记。 | 请用户提供笔记或转写文本。 |
| 2. 读取纪要与转写 | 汇集已有纪要和结构化转写内容。 | 仅基于用户提供的笔记处理。 |
| 3. 提取结论 | 提取决策、带主 R 与日期的 TODO，以及风险项。 | 缺少信息时请求补充，不编造未发生的讨论。 |
| 4. 更新 TODO 池 | 将确认后的行动项写入跟进清单。 | 返回结构化行动项供用户手动追踪。 |
| 5. 写会议纪要 | 输出包含背景、结论、行动项和风险的可读纪要。 | 直接在对话中返回完整纪要。 |
| 6. 推送会后通知 | 向参会人发送纪要链接与 TODO 摘要。 | 输出可复制发送的通知文本。 |

### 🛠️ 快速开始

1. **安装**
   ```bash
   git clone https://github.com/muippt/mu-meeting-flow.git ~/.claude/skills/mu-meeting-flow
   ```
   > 其他 AI Agent 可使用各自约定的 Skill 目录或项目级 Skill 目录。

2. **加载 Skill** — 重启或重新加载 AI Agent 后，输入：
   ```text
   列出我的可用 Skills
   ```

3. **开始使用**
   ```text
   帮我安排下周的项目决策会：准备议程、协助排期，并设计会后跟进。
   ```
   也可以直接进入指定工作流：
   ```text
   帮我准备周会，并带入上次会议尚未完成的行动项。
   ```
   ```text
   请把这些会议笔记整理成纪要，提取决策、主R、截止日期和风险。
   ```

### 🔒 安全与隐私

- 本项目仅包含 Markdown 与 JSON 配置，不含可执行服务代码或遥测。
