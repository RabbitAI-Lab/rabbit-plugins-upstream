# 电影级图片制作（风格库驱动）

**一句话定位**：把「一个主体」放进「一个风格」，产出一条**电影级 14 节提示词**，并可直接出图。

```
主体 / 主题  +  风格卡（styles/NN-*.md）  ──►  14 节电影级提示词  ──►  出图落盘  ──►  样图库 index.html
                         ▲
                  固定节逐字照抄（保证同风格成系列）
```

- **默认交付是提示词，不是图**。图通常拿到即梦 / Midjourney / 可灵等工具出；只有用户明确说「出图」才调接口。
- **风格是第一公民**，可无限扩展；**一风格一卡一文件**。

## 二、工作流

### 2.1 取源（主体是什么）
- 用户给了主体词、一句话、一段场景或文件 → 直接取用。
- 只给风格没给主体 → **给 3 个带【推荐】的候选主体**，一次问清，不臆造。
- 涉及**真人 / 真实品牌 / 真实地标** → 一律虚构化 / 脱敏（见第五节）。

### 2.2 选风格
- 点名了风格 → 直接读对应卡。
- 没点名 → 按主体性质**推荐一张**（说明理由），可再给第二选择。
- 不在库里 → 走 2.5 新增风格。
- 要多风格对比 → 同一主体 × 多张卡，各出一条提示词、各出一张图，用于横向比稿。

### 2.3 写提示词（核心动作）
1. **读风格卡**，把标了「★固定节」的字段**原样取出**；
2. **写逐图可变节**：【主体】【次要元素·近/中/远】【全局】【构图】【镜头】——具体、可拍摄、禁泛称；
3. 按第三节骨架拼装：固定节**逐字照抄**，可变节**逐图重写**；
4. **【负向】= 通用负向词库 + 该卡专属负向**（合并去重）；
5. 按第七节自检后落盘。

> **细致度硬指标**：**【主体】≥8 个可拍摄的具体细节**（确切名 + 尺寸 / 材质 / 颜色 / 新旧状态）；
> 禁写「一只神兽」「一片山水」「一个古人」这类泛称；禁连续两句无可拍摄物。

> **装配器**：`scripts/build_prompts.py` 可从「风格卡 + 变量 json」自动拼 14 节提示词并写进 `提示词.json`，
> 固定节与负向自动抽取，避免手抄走样。

### 2.4 出图（**例外动作**，用户明确要图才做）

> **两条硬规则**（本项目为「出图太费钱」专门加的闸门）：
> 1. **一次只出一张**；脚本拒绝批量，并把待出队列交回，出完再跑下一次。
> 2. **必须显式 `--yes`**；不加只预览，绝不调付费接口。

```bash
# ⓪ 合并库（默认）：项目名写 "."，读根目录 提示词.json、写入 图片/
python3 scripts/generate.py --project . --dry-run
# ① 免费预览：看下一张要出什么（不调接口、不花钱）
python3 scripts/generate.py --project "<项目目录名>" --dry-run
# ② 出 1 张（只出待出队列第一张）
python3 scripts/generate.py --project "<项目目录名>" --yes
# ③ 指定某一张 / 更省
python3 scripts/generate.py --project "<项目目录名>" --id "<id>" --yes
python3 scripts/generate.py --project "<项目目录名>" --quality medium --size 1024x1024 --yes
# ④ 换渠道出图（newapi=OpenAI兼容中转 / ark=火山方舟 Seedream / auto=有 NewAPI key 用 newapi 否则 ark）
python3 scripts/generate.py --project . --channel ark --id "<id>" --yes
```

- **渠道**：`--channel newapi | ark | auto`（默认 auto）。`ark` 走 `doubao-seedream-5-0-pro-260628`，
  尺寸自动映射到 2K 档（`16:9 → 2048x1152`，`9:16 → 1152x2048`），且不传 `quality`。
- 配置读**本 skill 自带** `config.json`；也可 `--base-url/--key/--model` 或环境变量
  （`NEWAPI_IMAGE_*` / `ARK_API_KEY`）。**非交互 shell 读不到环境变量时，脚本会回落读 `~/.zshrc` 等配置文件的 export 行。**
  > 首次使用先把 `config.json` 的 `newapi_image_base_url` 换成你自己的 OpenAI 兼容网关（或 export `NEWAPI_IMAGE_BASE_URL`），
  > `newapi_image_key` 填你的 key；仓库内所有 key 字段默认为空，不会带任何真实凭据。
- **出图 API 标签（自动回写）**：每出一张，脚本把 `api`（`ark` / `newapi` / `tool`）、`model`、`api_size`、
  `api_at` 写回 `提示词.json` 对应行。`gallery.py` 据此在**缩略图左下角**打角标
  （`● ARK · seedream-5-0-pro` / `● NewAPI · …` / `● 宿主工具` / `● 未标注` 历史图），
  顶部另有 **「全部 API」下拉**可按渠道筛选；详情页显示具体模型与出图时间；`提示词.md` 每条也带出图渠道。
  > 已知坑：角标**不能加 `backdrop-filter`** —— WebKit 下多列分段里贴底边的绝对定位元素带 backdrop-filter 会整块不绘制。
- **历史图回填**：早期出图没写标签 → 跑 `python3 scripts/backfill_api.py`（默认只预览，`--apply` 写盘）。
  按图片尺寸规格反推渠道（`1536x1024`/`1024x1536` → newapi·gpt-image-2-c，`1152x2048`/`2048x1152` → ark·seedream-5-0-pro），
  写入 `api_estimated: true`，界面用**虚线边角标 + 详情「（推定）」**表示不是原始调用记录；尺寸对不上的不猜，保留「未标注」。
- **尺寸对照**：`16:9 → 1536x1024`，`9:16 → 1024x1536`。**本 skill 只出这两种取向**。
- **省钱旋钮**：`--quality medium`、`--size 1024x1024`（默认 `high` + `1536x1024` 最贵）。
- **出完必做**：立刻本地核验（可数特征用 `scripts/count_features.py`），不要连出多张再回头挑。

**出图通道（API 优先 · 工具兜底）**

| 通道 | 触发 | 怎么做 |
|---|---|---|
| **A 本地 API**（默认） | 有 key 且网关可达 | `generate.py` 直出（一次一张 + `--yes`） |
| **B 宿主工具**（兜底） | 没 key / 接口不通 / 失败 | 脚本写 `图片/generate_image参数.json` 并返回**退出码 6**：无 `refs` 用 `generate_image`，有 `refs` 用 `edit_image`；出完 `--adopt` 收位 |

```bash
python3 scripts/generate.py --project "<项目>" --probe        # 免费探通道：0=API / 6=工具
python3 scripts/generate.py --project "<项目>" --tool-json    # 只写工具参数
python3 scripts/generate.py --project "<项目>" --adopt <图片…> # 工具出图后收位
```

> 工具通道不花钱、不需要 `--yes`；「一次一张」只约束付费 API。
> `--probe` 也会打印当前渠道（`[渠道] ark · <base> · <model>`），换渠道前先探一下。
> 收位落点：合并库为 `图片/<id>.png`，旧项目布局为 `图片/<风格卡名>/<id>.png`。只想强制走 A：`--api-only`。

### 2.5 新增风格（不在库里）
1. 问清：**风格名 + 一句话定位 + 参考作品 / 画种 / 关键词**（≤3 组，一次问完）；
2. 按 `references/风格卡规范.md` 写全卡（固定节口径 + 专属负向 + 易翻车点）；
3. 存 `styles/NN-{风格名}.md`（NN 接续 76、77…），**更新 `_索引.md` 与 `_测试主体.md`**，并同步 `SKILL.md` 第一节分组表；
4. 用新卡出一条提示词；要试出图仍守 2.4 的两条硬规则。

### 2.6 全库出图（「一个风格出一张」，常用模式）
1. 读 `_测试主体.md`，给每个待测风格配主体；
2. 依各卡固定节逐风格写提示词，**汇总进同一项目的 `提示词.json` 的 `rows`**（一风格一行）；
3. **一次一张**：反复跑 `generate.py --project "<项目>" --yes`，已存在的自动跳过；
4. 出图落 `assets/output/图片/`（平铺，文件名 = id）；**不以「看效果」为由连出多张**。
5. 出完跑 **2.7** 刷新样图库。

### 2.7 输出整理（每次出图后 / 用户说「整理输出」时）
```bash
python3 scripts/export_md.py                 # 提示词.json → 提示词.md（合并库一份）
python3 scripts/normalize_output.py          # 旧项目布局的命名规范化（合并库通常 0 变更）
python3 scripts/gallery.py                   # 重建 图片/_缩略图 + index.html + README.md
```
- `gallery.py` 会读 `提示词.json` + 风格卡 + `_索引.md`，生成**样图库浏览页**：
  列表显示风格名 / 一句话定位 / 主体 / 画幅，**点击看原图与完整提示词**。
- `assets/output/README.md` 是项目索引（项目 / 行数 / 图数 / 待出 / 说明），由 `gallery.py` 一并刷新。

## 三、14 节标准骨架（固定顺序、缺一不可、空层写「无」）

```
【主体】          唯一视觉主体：是什么 + 确切相貌/体征 + 尺寸材质颜色状态 + 姿态朝向 + 神态
【次要元素·近景】 最前层（可作前景框），写「无」不删节
【次要元素·中景】 中层
【次要元素·远景】 背景层，朦胧含蓄
【全局】          满屏介质（雨丝 / 云雾 / 浮尘 / 花瓣 / 光束）—— 与【镜头】景深自洽

【构图】          机位高低 + 主体站位 + 纵深 + 留白（不写焦距 / 景深）
【光影】          ★固定节：光位 · 光比 · 轮廓光 · 色温
【色彩】          ★固定节：主调 + 点缀色 + 饱和度 + 留白占比
【影像质感】      ★固定节：介质 + 颗粒 + 调色（调色只在此节写一次）

【背景】          ★固定节：背景性质
【镜头】          景别 + 机位角度 + 等效焦距 + 光圈/景深 + 焦点
【风格】          ★固定节：风格句（逐字照抄风格卡）
【画幅】          ★固定节：16:9 或 9:16（54–57 的 3:4 只由 MV 侧消费）

【负向】          通用负向 + 风格专属负向（合并去重）
```
★ = 风格卡**固定节**，同一风格跨图**逐字一致**；其余为**逐图可变节**。

> `03-中式美学` 另有一个 **`【装饰】` 可选节**（唐卡装饰 / 描金纹样），位置在【影像质感】之后；
> 其余卡不写此节。`build_prompts.py` 已按「卡里有就输出、没有就跳过」处理。

- **合并库是默认布局**：图片**全部平铺在 `assets/output/图片/`**，不再按项目 / 风格分目录；
  出图用 `--project .`（读根目录 `提示词.json`，写入 `图片/`）。
- **批次**：每条提示词带 `project` 字段（如 `01-全库样图` / `02-厚涂52-53`），页面按它筛选；
  想开新批次就往 `rows` 里追加并写 `project`，不再需要建目录。
- **旧的项目目录布局仍兼容**：`--project <目录名>` 会读 `<项目>/提示词.json` 并把图写进 `<项目>/图片/`。
- **命名铁律**：`kind` = 风格卡文件名去 `.md`；`id` = `kind-主体`；图片名 = `id`（全库唯一）。
- **待出**：`提示词.json` 里有行、`图片/` 里没同名图 → 视为「待出」，`index.html` 与 `README.md` 标 ⏳。

## 五、硬性合规（不可放宽）

1. 主体**默认虚构化**；**当代真人一律不出现**；史载 / 典籍人物写「虚构的东方古代XX（无历史原型）」。
2. **零可读文字 / 数字 / 字母 / Logo / 水印 / 二维码**（含水墨题款 / 印章 / 落款）。
3. **不渲染血腥暴力**：伤口 / 刑罚 / 战争只写氛围、光影、姿态。
4. 无政治宗教敏感；无可辨认品牌 / 商家 / 地标。
5. 不涉色情 / 低俗 / 歧视 / 自伤引导。
6. 正向**无否定词**（禁 `no / not / without / 不要 / 无`）；排除项**只进【负向】**。
7. **画幅**：本 skill 出图只 `16:9` / `9:16`；`54–57` 的 `3:4` 属 MV 外部消费，不在本 skill 出图。
8. **宗教题材**（观音 / 神祇 / 圣像）按「庄重文化向、非传教」处理：不劝信、不许诺、不诱导供奉。
