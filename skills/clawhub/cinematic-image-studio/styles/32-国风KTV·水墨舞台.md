# 风格卡 · 国风KTV·水墨舞台

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `国风KTV·水墨舞台` |
| **一句话定位** | 像站在一幅会呼吸的水墨长卷前演唱，雅正、婉转、有东方仪式感 |
| **媒介本质** | 水墨写意 + 雅正舞台（宣纸肌理 + 晕染留白）；**非**西式油画、**非**3D/CG |
| **与最近似风格的区别** | 与「中式国风·水墨写意」不同：本档**演唱者可见面部口型、舞台演唱**；与水墨写意档不同：舞台与人物演唱 |
| **电影级从哪来** | ① 单一雅正主光 ② 水墨晕染虚光（非物理体积光）③ 薄雾烟岚介质 ④ 笔触墨韵呼吸感 |

## 二、★固定节（逐字照抄）

```
【光影】单一主光（月光/烛火/灯笼/水影/天光）雅正、宁暖勿冷；水墨晕染的虚光而非物理体积光；薄雾/水汽/烟岚作介质
【色彩】赭石/朱砂/墨青/月白/藤黄为调、强调色不超过两种、雅正不艳俗；少量重彩点醒目
【影像质感】水墨写意：宣纸肌理与晕染留白造境；笔触可见、墨韵流动；演唱者可见面部与口型、字腔讲究地开口演唱，身段含蓄婉转
【背景】东方舞台（水榭/月下/竹林/戏台/画舫/云雾山巅），前景中景至少两层纵深；无可读文字、题款/印章文字
【风格】国风 KTV·水墨舞台：水墨写意与雅正舞台结合；演唱者可见面部与口型、字腔讲究地开口演唱，身段含蓄婉转，演唱者为虚构原创形象、不影射任何真实人物；整体雅正、婉转、有东方仪式感
【画幅】{9:16 或 16:9}   ← 只此两种
```

**★固定节填写要求**：命门词「**雅正水墨（宣纸肌理 + 晕染留白）**」「**可见面部口型、身段含蓄、字腔讲究**」「**虚构原创不影射真人**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 演唱者可见面部与口型、字腔讲究；身段含蓄婉转（水袖/折扇/兰花指择一为主）；虚构原创形象。 |
| 【次要元素·近/中/远】 | 前景水袖/折扇/器物 → 中景演唱者 → 远层东方舞台。空层写「无」。 |

1. **画成西式油画/3D** → 负向含「西式油画画风、3D 渲染、体积光」。
2. **俗艳大红大绿** → 负向含「高饱和荧光色、俗艳大红大绿」。
3. **题款/印章出字** → 负向含「题款文字、印章文字」，【背景】写「无题款/印章文字」。
4. **露真人脸/影射** → 负向含「可辨认的真实歌手面孔、影射在世公众人物」。
