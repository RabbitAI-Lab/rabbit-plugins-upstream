# 风格卡 · 彩色水墨·新中式

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `彩色水墨·新中式` |
| **一句话定位** | 以宣纸/绢帛为底的新中式彩色水墨，安静、清透、克制 |
| **媒介本质** | 纸本水墨 + 设色（新中式彩色水墨）；**非**3D/CG/照片写实/厚涂油画 |
| **与最近似风格的区别** | 与「彩色水墨（电影级）」不同：本档**朱砂主色、现代水墨化、留白造境、安静克制**；与「重彩水墨打斗」不同：本档**不浓烈** |
| **电影级从哪来** | ① 书法性线条骨线 ② 晕染/破墨/留白 ③ 柔光清透 ④ 现代元素水墨化 |

## 二、★固定节（逐字照抄）

```
【光影】柔光清透：午后斜光、薄雾与茶气轻绕、湿度柔和；无强光特效、无发光污染、无体积光溢出；阴影通透不发黑
【色彩】主色朱砂红（红一律转译为朱砂/胭脂，非正红、非荧光红），辅色焦墨，点缀石青；纸本留白不计入配色；石青面积不超过 10%；色随墨走、墨不压色，单张画面色彩克制
【影像质感】中国书法性线条：焦墨骨线立骨，粗细枯润随性、飞白交代转折与速度；晕染/泼墨/破墨/没骨/留白并用；宣纸纹理、绢帛柔光；色块边界自然渗化，不做硬边平涂
【背景】远景以留白 + 淡墨交代（窗棂、淡墨竹影/城市轮廓、破墨云气、朱砂微光），点缀石青（不超 10%）；与主体同一套水墨逻辑；环境清透不抢主体、留白优先；无可读文字
【风格】以宣纸/绢帛为底的新中式彩色水墨，墨色为骨、色彩为韵；书法性线条与焦墨骨线立骨，飞白/晕染/泼墨/破墨/没骨/留白并用；柔光清透、安静克制；现代元素仅保留简洁结构并水墨化、占比不超过 30%，装饰不超过 2 处且必须水墨化；无浮夸特效、无发光污染、无过度装饰
【画幅】{16:9 或 9:16}   ← 只此两种
```

**★固定节填写要求**：命门词「**墨色为骨、色彩为韵**」「**朱砂主色、石青≤10%**」「**留白造境、安静克制**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 静物/器物/建筑/人物（默认可不安排人物；若出现人物则水墨化、**双手空置**，道具作独立道具）；书法性线条 + 墨骨 + 留白。 |
| 【次要元素·近/中/远】 | 前景（窗棂/竹影）→ 中层主体 → 远层淡墨轮廓。空层写「无」。 |
| 【全局】 | 茶气/薄雾/浮尘/墨韵晕染（缓动意象化）。 |
| 【构图】 | 留白造境、安静清透；主体偏三分。**不写焦距/景深**。 |
| 【镜头】 | 平面水墨，中景/远景，无硬景深。 |

## 六、易翻车点（写完回查）

1. **画成3D/写实** → 负向含「3D 渲染、照片写实、体积光溢出」。
2. **发光污染/过度装饰** → 负向含「发光污染、浮夸特效、过度装饰」。
3. **正红/荧光红** → 固定节锁定「红转译为朱砂/胭脂」，负向含「高饱和荧光色」。
4. **题款/印章出字** → 负向含「题款文字、印章文字」。
