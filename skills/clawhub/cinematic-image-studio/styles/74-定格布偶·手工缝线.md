# 风格卡 · 定格布偶·手工缝线

> **给写提示词的自己**：本卡 ★固定节 的字段必须**逐字照抄**，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `定格布偶·手工缝线` |
| **一句话定位** | 手缝布偶站在微缩舞台上：缝线、毛边、绒毛与钨丝暖光，笨拙而温柔 |
| **媒介本质** | **定格动画实体布偶的实拍**（毛毡/棉布 + 金属骨架 + 微缩布景），非 3D、非毛绒玩具商拍 |
| **与最近似风格的区别** | 与「毛毡」（49/50）不同：**是人形/兽形布偶角色 + 有舞台与灯光叙事**，不是材料肌理图；与「3D 黏土」（64）不同：**布料纤维与缝线，不是油泥**；与「亲子绘本」（05）不同：**实物拍摄而非绘画** |
| **电影级从哪来** | ① 钨丝灯的暖调单光源制造小舞台的戏剧性 ② 微距下布料的绒毛与线头清晰可见 ③ 微缩布景的前后景层次 ④ 布偶比例与笨拙动作带来的情绪 |

## 二、★固定节（逐字照抄）

```
【光影】微缩舞台的单光源布光：画面外左上方一盏钨丝聚光灯（约 3000K 暖黄）打向布偶，灯前有一片柔光纸使光斑边缘柔和；布偶右侧靠一块白卡纸作弱反弹，暗部保留布料纹理、不压成死黑；光比约 1:3.5，布偶在布景上投出方向明确的柔和长影；背景略暗、有灯光的自然衰减
【色彩】暖旧调：钨丝光的琥珀黄（#E8B26A）笼罩全局，布偶本体用低饱和的赭红（#A9563F）、芥末黄（#C9A24B）、雾绿（#7E9A86）、奶白（#EFE7D8），布景用旧木色与深褐（#3B2E27）；无冷色、无高饱和撞色
【影像质感】定格动画布偶的实物微距：毛毡表面有细密绒毛与轻微起球、棉布可见经纬织纹、接缝处有外露的手缝线迹（约 4–6mm 一针、线头略翘）、关节处布料有褶皱与轻微磨损、眼睛为玻璃珠或纽扣（有真实的圆形高光与反光）；微距浅景深、焦外柔化；非 3D 渲染、非毛绒玩具商拍
【背景】微缩布景：木条钉成的舞台框、旧木地板、手绘的布景片（远山/树/云的粗笔触）、小尺寸道具（火柴盒大小的箱子、线轴、纽扣）；一切明显是缩小比例的手工作品
【风格】定格动画的手缝布偶实拍，微缩舞台与钨丝暖光，可见缝线与布料绒毛的手作质感；非 3D 渲染、非插画、非真实动物
【画幅】{9:16}
```

**★固定节填写要求**：
- 命门词「**可见手缝线迹（4–6mm 一针）**」「**毛毡绒毛与棉布织纹**」「**微缩布景**」「**钨丝暖光单光源**」逐字不动。
- 色号与光比不许改；只允许替换布偶造型与布景道具。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：布偶是什么（虚构小狐狸/小熊/兔子/小人）、身高占画面比例、布料与颜色分区、五官做法（纽扣眼、毡片嘴、绣线胡须）、服装与配件（围巾、背带裤、口袋）、关节与姿态、线迹位置、是否有磨损与补丁。 |
| 【次要元素·近/中/远】 | 近：布景地板上的线轴/纽扣/木屑；中：布偶与主道具；远：手绘布景片与暗下的背景。空层写「无」。 |
| 【全局】 | 空气中极细的绒毛纤维、灯光里的灰尘。 |
| 【构图】 | 竖构图，布偶居中偏下占画面 55–70%，上方留布景片与光斑；机位与布偶视线齐平或略低。**不写焦距/景深**。 |
| 【镜头】 | 等效 60–90mm 微距、f/4、浅景深、布偶面部与缝线清晰、布景柔化。 |

## 六、易翻车点（写完回查）

1. **变 3D/塑料玩具** → 固定节写「毛毡绒毛、手缝线迹」，负向含「3D 渲染、塑料玩具、树脂手办」。
2. **变真实动物** → 负向含「真实动物、写实毛发」，主体写「布偶」。
3. **光变冷白棚拍** → 【光影】锁「钨丝 3000K 单光源」，负向含「冷白光、日光」。
4. **布景像真实场景** → 【背景】强调「木条舞台框、手绘布景片、火柴盒大小的道具」。
5. **缝线糊掉** → 负向含「缝线糊成噪点」，【镜头】保证面部与缝线清晰。
