# 风格卡 · 橡皮泥·黏土定格（手捏黏土 · 指纹压痕 · 微缩布景）

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `橡皮泥·黏土定格` |
| **一句话定位** | 像一段黏土定格动画——手捏的黏土人偶在微缩布景里起舞 |
| **媒介本质** | 塑胶黏土手捏造型 + 定格动画质感（微缩布景、布景灯）；**非**3D、**非**搪胶手办、**非**写实照片 |
| **与最近似风格的区别** | 与「09 Q版公牛」（搪胶手办）不同：本档表面是**黏土的指纹压痕与轻微不平整**、边缘圆钝、微缩布景，非光滑塑料；与3D卡通不同：本档有**手工捏塑的不完美**。 |
| **童趣从哪来** | ① 指纹压痕与圆钝造型 ② 明快纯色 ③ 微缩布景的短投影 ④ 定格布光 |

## 二、★固定节（逐字照抄）

```
【光影】微缩定格布光：柔和的布景灯从侧上方打来，光比柔和、投影清晰而短；黏土表面有细微高光与指纹压痕的柔和凹凸；色温暖
【色彩】彩色橡皮泥的明快纯色：红黄蓝绿粉的饱和度中等偏高、像童年彩泥盒；背景为简化的黏土搭建布景，色调统一柔和、明度低于主体
【影像质感】定格动画黏土质感：手捏的塑胶黏土表面有指纹压痕与轻微不平整、边缘圆钝、颜色微微不均；微缩场景与布景光；非3D渲染、非光滑塑料、非写实照片
【背景】黏土搭建的天宫布景：圆钝的宫阙柱子、云朵、台阶，简化造型，明度低于主体；无可读文字
【风格】橡皮泥黏土定格动画：手捏黏土造型、指纹压痕质感、微缩布景、定格布光；童趣、温暖、手工感；非3D、非光滑塑料、非写实照片、非二维动画
【画幅】16:9
```

**★固定节填写要求**：命门词「**手捏黏土 + 指纹压痕 + 边缘圆钝**」「**微缩布景 + 柔和定格布光**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 黏土捏塑的主仙（虚构，圆钝简化造型、大头小身、手工手感）+ 颜色 + 姿态朝向；群仙以黏土小偶分列；末尾「是画面唯一视觉主体」 |
| 【次要元素·近/中/远】 | 近：黏土小道具/云朵；中：群仙小偶与黏土宫柱；远：黏土台阶与云；空层写「无」 |
| 【全局】 | 少量黏土碎屑/粉末/微尘 —— 与微缩布光自洽 |
| 【构图】 | 主体占视觉中心；微缩场景层次；留白/布景收边；**不写焦距/景深** |
| 【镜头】 | 微缩景深感：中景/全景，可写微距浅景深（f/4–f/8） |

## 六、易翻车点（写完回查）

1. **变光滑塑料手办** → 负向含「CG光滑塑料、树脂手办、搪胶」；【影像质感】写「指纹压痕、边缘圆钝、颜色不均」。
2. **变写实真人** → 负向含「写实照片、写实人脸」；【主体】写「圆钝简化、大头小身、手心感」。
3. **黏土变纸片/二维** → 负向含「纸片、二维动画」；【影像质感】写「立体手捏、微缩布景」。
4. **颜色脏/糊成一团** → 负向含「脏旧、糊成一团」；【色彩】写「明快纯色」。
