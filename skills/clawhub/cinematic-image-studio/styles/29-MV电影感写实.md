# 风格卡 · MV电影感写实

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `MV电影感写实` |
| **一句话定位** | 像一支被好好拍出来的 MV，情绪从真实演唱与光影里自己渗出来 |
| **媒介本质** | MV 写实影像（电影级布光 + 浅景深）；**非**摆拍/广告、**非**卡通/3D |
| **与最近似风格的区别** | 与「温情治愈·电影感写实」不同：本档**可见面部与口型、开口演唱**（温情档不露正脸） |
| **电影级从哪来** | ① 单一电影级主光（可解释）② 柔和高光滚降 + 浅景深 ③ 光随情绪在同镜头内变化 ④ 真实演唱空间 |

## 二、★固定节（逐字照抄）

```
【光影】单一电影级主光（追光/窗光/路灯/台灯/落日/月光，光源在画面内可解释）；柔和高光滚降、浅景深、背景自然虚化；暗部保留细节；光随情绪在同一镜头内变化；色温中性偏暖
【色彩】中性偏暖基底 + 强调色不超过两种；情绪色随段落微调但全片统一色调；轻微胶片颗粒与柔光，不要干净数码感
【影像质感】电影级写实影像：微距级真实质感（织物、皮肤、麦克风金属、空气浮尘）；真实、克制、不摆拍不广告感
【背景】真实演唱空间（空荡舞台/窗边房间/天台/地下车库/雨夜街头/海边/livehouse），前景中景至少两层纵深；环境永远比主体低一档亮；无可读文字
【风格】MV电影感写实：电影级写实影像与布光、单一主光且光源可解释、柔和高光滚降 + 浅景深；演唱者可见面部与口型、以真实情感开口演唱，气息与表情自然可信，演唱者为虚构原创形象、不影射任何真实人物；光与景别随情绪在同一镜头内变化
【画幅】{9:16 或 16:9}   ← 只此两种
```

**★固定节填写要求**：命门词「**可见面部与口型、开口演唱**」「**演唱者为虚构原创、不影射真人**」「**单一电影级主光**」逐字不动。

## 三、★专属负向（必须并入【负向】）

```
可辨认的真实歌手面孔、明星脸、肖像相似、影射在世公众人物、
摆拍感、广告感、婚纱影楼风、
冷硬打光、棚拍平光、大爆闪过曝、暗部糊成死黑、
高饱和荧光色、赛博霓虹、
卡通、动漫、3D塑料感、油画厚涂、
英文文字、字幕、水印、标志、歌名文字、
畸形的手、多余手指、多余肢体、畸变、主体出框
```

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 演唱者可见面部与口型、开口演唱；虚构原创形象（不影射真人）；气息、眼神、肩线、手势自然可信。 |
| 【次要元素·近/中/远】 | 前景（麦架/窗框/器物）→ 中景演唱者 → 远层演唱空间。空层写「无」。 |
| 【全局】 | 浮尘/薄雾/光斑空气介质。 |
| 【构图】 | 至少两层纵深；主体偏三分；环境低一档亮。**不写焦距/景深**。 |
| 【镜头】 | 中景/近景；浅景深（f/2.8 虚化背景）。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|
| 竖屏唱歌视频 | `9:16` 竖 | `1024x1536` | 演唱者居中、环境虚化 |
| 横版 | `16:9` 横 | `1536x1024` | 两层纵深、留白 |

## 六、易翻车点（写完回查）

1. **露真人脸/影射** → 负向含「可辨认的真实歌手面孔、明星脸、影射在世公众人物」。
2. **闭口无口型** → 固定节锁定「可见面部与口型、开口演唱」。
3. **摆拍/广告感** → 负向含「摆拍感、广告感」。
4. **打光冷硬** → 负向含「冷硬打光、棚拍平光」。
