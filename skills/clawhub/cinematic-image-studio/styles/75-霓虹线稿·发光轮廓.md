# 风格卡 · 霓虹线稿·发光轮廓

> **给写提示词的自己**：本卡 ★固定节 的字段必须**逐字照抄**，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `霓虹线稿·发光轮廓` |
| **一句话定位** | 纯黑底上只有发光线条构成的物体：轮廓、结构、透视，像一台只亮灯管的线框雕塑 |
| **媒介本质** | **长曝光霓虹灯管 / 发光线条装置**的影像（发光线条 + 辉光），非插画线稿、非 3D 线框渲染 |
| **与最近似风格的区别** | 与「赛博霓虹」（33）不同：**没有真实场景与人物，只有黑底与线条**；与「故障艺术」（67）不同：**线条连续完整、无错位损坏**；与「霓虹招牌」不同：**不是文字招牌，是物体结构** |
| **电影级从哪来** | ① 纯黑把发光线条的辉光衬到极致 ② 线条承担全部结构与透视，不许有面 ③ 亮度的呼吸层次（主线最亮、结构线次之） ④ 线条在镜头里带轻微光晕与拖尾，产生真实灯管感 |

## 二、★固定节（逐字照抄）

```
【光影】自发光线条布光：画面唯一光源是灯管本身，主线亮度最高并在空气中形成 2–4mm 的柔光晕，结构线略暗、辉光更窄；灯管在近处地面上留下一小片彩色反射（地面为湿黑或镜面黑）；没有任何其他光源，暗部为纯黑
【色彩】纯黑（#050507）占 70% 以上，只允许一到两种霓虹色：主色为电光青（#25F4EE）或品红（#FF2E88），辅色最多再补一个柠檬黄（#FFE05C）或紫罗兰（#8B5CF6）；线条颜色纯度高、辉光边缘由亮到暗自然衰减
【影像质感】长曝光霓虹灯管实拍：灯管本体为均匀发光的实心亮线（中心白、边缘着色）、辉光向两侧衰减约 3mm、拐角处有轻微的亮度堆积、个别转角有极短的灯管接头结构；画面有极细的传感器噪点、黑场纯净无灰雾；非手绘线条、非 3D 线框、非矢量图形
【背景】纯黑虚空，只在画面下方保留一小片湿黑或镜面黑地面（倒映线条的彩色光），其余无任何环境元素
【风格】霓虹线稿，纯黑背景上由发光灯管构成的物体线框，电光青与品红的辉光线条，夜间电子氛围；非插画线稿、非 3D 线框、非霓虹招牌文字
【画幅】{16:9}
```

**★固定节填写要求**：
- 命门词「**纯黑占 70% 以上**」「**灯管是唯一光源**」「**主线亮 + 结构线次亮**」「**2–4mm 柔光晕**」逐字不动。
- 色号与「无其他光源」不许改；只允许替换物体结构与线条走向。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：物体是什么（摩托车/跑车/相机/耳机/机械手/建筑剖面/乐器）、线框构成（外轮廓主线 + 内部结构线 + 透视辅助线）、线条数量层级、关键结构（轮辐、齿轮、按键、弦）、体量与在画面中的位置、朝向与倾斜角、哪几条线是主色、哪几条是辅色。 |
| 【次要元素·近/中/远】 | 近：地面倒映的一段彩色光带；中：主体线框；远：纯黑。空层写「无」。 |
| 【全局】 | 极细传感器噪点、线条辉光在黑暗中的空气感。 |
| 【构图】 | 主体居中或三分线、占画面 55–75%，四周大面积黑；可加一条细长的水平辅助线穿过画面。**不写焦距/景深**。 |
| 【镜头】 | 平视或 3/4 侧视、等效 35–50mm、全画面等清晰、无景深虚化（黑场无虚化对象）。 |

## 五、画幅与题材取向

## 六、易翻车点（写完回查）

1. **画成手绘线稿** → 固定节写「灯管实心亮线 + 辉光衰减」，负向含「手绘线稿、矢量插画、3D 线框」。
2. **线条变细弱断掉** → 强调「主线最亮、辉光 2–4mm」，负向含「线条断裂模糊」。
3. **出现霓虹招牌文字** → 负向含「霓虹灯招牌、可读文字灯管、招牌字」。
4. **黑场发灰/有雾** → 负向含「雾气弥漫」，写「黑场纯净无灰雾」。
5. **加了面和渐变** → 负向含「面材质、渐变填充」，只允许线。
