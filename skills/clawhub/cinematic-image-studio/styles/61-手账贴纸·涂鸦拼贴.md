# 风格卡 · 手账贴纸·涂鸦拼贴

> **给写提示词的自己**：本卡 ★固定节 的字段必须**逐字照抄**，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `手账贴纸·涂鸦拼贴` |
| **一句话定位** | 俯拍纸手账：拍立得 + 模切贴纸 + 胶带 + 马克笔抖线，层叠出真实纸感 |
| **媒介本质** | **桌面俯拍的真实纸质拼贴**（纸、胶带、贴纸、相纸的实物照片），非数字排版、非插画 |
| **与最近似风格的区别** | 与「ins 奶油极简」（62）不同：**信息密集、层叠拼贴**而非大留白；与「像素/酸性海报」（59/60）不同：**全部为实物纸张**，不是平面设计稿；与「亲子绘本」（05）不同：**不是绘画** |
| **电影级从哪来** | ① 单向窗光形成纸张厚度与贴纸投影 ② 俯拍平铺的严密版式（层与层之间有呼吸） ③ 纸纤维、胶带反光等物理细节 ④ 奶油纸底压住高饱和涂鸦 |

## 二、★固定节（逐字照抄）

```
【光影】顶部偏左约 30° 的单向柔和窗光：纸张与贴纸产生 1–2mm 的软边投影，胶带边缘出现一道细窄高光；整体明亮通透、无强反差，最深处不超过中度灰；不出现彩色环境光
【色彩】纸底为奶油白（#F6F1E7）与米黄（#EFE4CE），涂鸦用马克笔高饱和色——樱粉（#FF7BA9）、柠檬黄（#FFD84D）、天蓝（#6EC6FF）、薄荷绿（#7BE0B0），颜色有笔触叠色的深浅不匀；整体明度高、饱和度中高
【影像质感】俯拍实物纸感：纸面纤维与轻微起伏可见、胶带为半透明磨砂带细反光、拍立得相纸有白边与轻微卷翘、贴纸为模切白边且边缘厚度可见、马克笔笔触边缘有洇色、圆珠笔线条有压力深浅；轻微数码噪点，无塑料感
【背景】桌面俯视：浅色木纹桌面或亚麻桌布，边角可露出咖啡杯、耳机、剪刀、胶带座的一小角；背景始终为配角、不抢画面中心
【风格】手账贴纸拼贴实拍，俯拍纸面与层叠贴纸，马克笔抖线涂鸦与拍立得，手作温度与生活记录感；非数字排版、非矢量插画、非 3D
【画幅】{9:16}
```

**★固定节填写要求**：
- 命门词「**俯拍纸感**」「**模切贴纸白边**」「**马克笔抖线**」「**1–2mm 软边投影**」逐字不动。
- 纸底色号与投影量不许改；只允许替换拼贴内容与涂鸦符号。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：手账页的排版（左页/右页、横向/纵向）、纸张类型（横线/方格/牛皮纸）、3–5 张拍立得的内容与倾斜角度、贴纸的主题与形状（猫、胶囊、星星、云、票根）、胶带位置与颜色、马克笔涂鸦符号（箭头、圈、点点、波浪、写字块但不出现可读文字）、圆珠笔线条、整体层叠顺序。 |
| 【次要元素·近/中/远】 | 近：笔、胶带座、剪刀的一角；中：手账本与拼贴；远：木纹桌面/亚麻布。空层写「无」。 |
| 【全局】 | 细碎纸屑、胶带碎边、笔帽阴影、轻噪点。 |
| 【构图】 | 正俯拍平铺（top-down），手账本居中占 60–80%，允许轻微 5–10° 倾斜；元素之间留出手指宽的呼吸位。**不写焦距/景深**。 |
| 【镜头】 | 正俯视 90°、等效 35–50mm、f/8 大景深、全页清晰、无透视畸变。 |

## 五、画幅与题材取向

## 六、易翻车点（写完回查）

1. **变成数字排版模板** → 固定节写「俯拍实物纸感」，负向含「数字排版、矢量插画」。
2. **出现可读手写字** → 负向含「手写汉字、英文单词、字母、数字」，涂鸦只写「符号与色块」。
3. **元素糊成一堆** → 【构图】强制留「手指宽的呼吸位」与层叠顺序。
4. **太干净的印刷品** → 强调「笔触叠色不匀、纸张起伏、胶带细反光」。
5. **整页发灰** → 【光影】限定「最深不超过中度灰」，负向加「模糊失焦」。
