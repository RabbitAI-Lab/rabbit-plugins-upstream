# 风格卡 · 天庭仙境·大场面（凌霄宝殿 · 群仙起舞 · v1.0）

> **给写提示词的自己**：本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `天庭仙境·大场面` |
| **一句话定位** | 把东方天庭拍成一场**气势磅礴的群仙大场面**——金阙巍峨、群仙起舞，一眼"仙乐飘飘、天家气象" |
| **媒介本质** | 现代东方奇幻 **3D 渲染**（PBR 写实材质 + 卡通夸张造型）；**非**二维手绘/赛璐璐、**非**照片写实真人、**非**壁画平面 |
| **与最近似风格的区别** | 与「东方奇幻·3D新国风」（16）不同：16 锚定**单主体**异兽/漫剧角色，本卡锚定**大场面群像 + 凌霄宝殿**；与「3D新国风神祇」（21）不同：21 是**单尊神祇法界奇观**，本卡是**多位仙女同台**；与「敦煌金彩」（18）不同：本卡是**立体 3D**、非壁画平面。 |
| **大场面从哪来** | ① 尺度参照物（渺小仙官/群鹤）② 低机位广角仰拍 ③ 纵深 ≥4 层 ④ 天光柱/巨柱包夹 |

## 二、★固定节（逐字照抄）

```
【光影】PBR 写实材质光照：真实物理光照与反射；三道光源自成体系——高天倾泻的天光、金阙宫灯的暖金、仙光法术的自发光；主体受光侧通透、背光侧以天光勾出柔和轮廓光；低饱和基底衬托高饱和仙光；体积光穿透云海显形
【色彩】天庭极乐色：以鎏金与朱红为主华彩、白玉与琉璃青为底、天青作天际；环境偏云白与低饱和金褐，仙光与法术用高亮度艳色（仙青/鎏金/品红点缀）；金=权柄、青蓝=仙气、朱=庆典；统一于鎏金主调
【影像质感】3D 渲染：PBR 写实质感 + 卡通夸张造型；鎏金反光、琉璃次表面散射、玉石温润、云锦流光的绸缎微光；人物比例写实偏修饰、飘带与衣袂以卡通夸张的弧线延长；轮廓具雕塑感与符号感
【背景】凌霄宝殿：高耸的鎏金蟠龙云柱、穹顶藻井与云雷纹、层层金阙玉宇与翻涌云海；纵深至少四层（前景云台→主仙→中景群仙与宫柱→远景殿顶与天光）；亮度永远低于主体；无可读文字
【风格】现代东方奇幻 3D 天庭仙境：把东方天庭符号（蟠龙云柱、藻井云雷纹、卷云、金阙、飘带花雨）用 3D 解构再造；PBR 写实质感 × 卡通夸张造型；气势磅礴的群仙大场面；非二维手绘、非扁平插画、非照片写实真人、非西式天堂、非赛博朋克
【画幅】16:9
```

**★固定节填写要求**：命门词「**PBR 写实材质 × 卡通夸张造型**」「**鎏金朱红主华彩、低饱和基底衬高饱和仙光**」「**东方天庭符号（蟠龙云柱/藻井云雷纹/卷云/金阙/飘带）**」逐字不动。主光方位每图可换，但「三道光源各自成立、低饱和基底衬高饱和仙光」内核必须保留。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：主仙（虚构的东方天界仙女，无真实原型）——确切的髻饰（鎏金步摇/珠翠/花钿）、衣裙（云锦、霓裳、广袖）、飘带（数条、颜色）、舞姿与朝向、神态；群仙写「分层环绕、大小递减、姿态各异」；末尾写「是画面唯一视觉主体」 |
| 【次要元素·近/中/远】 | 近：前景云台/金阙栏杆/渺小仙官或群鹤（作尺度参照物）；中：群仙与鎏金蟠龙云柱；远：穹顶藻井与翻涌云海、殿顶没入天光；空层写「无」 |
| 【全局】 | 满屏介质：少量花雨/飘带/云气/仙光粒子 —— **与【镜头】景深自洽** |
| 【构图】 | 机位高低 + 主仙站位（中轴/三分）+ **纵深 ≥4 层** + 尺度参照物 + 留白作天光；**不写焦距/景深** |
| 【镜头】 | 大场面用**低机位仰拍 + 24mm 广角 + f/5.6–f/8 大景深**（让前景云台、主仙、群仙、殿顶全清晰）；只有特写主仙才用中焦中景深 |

## 六、易翻车点（写完回查）

1. **画成西式天堂** → 负向含「西式天堂、天使翅膀、天使光环」；【背景】写「凌霄宝殿：鎏金蟠龙云柱、藻井云雷纹」。
2. **仙女变日式动漫/二次元** → 负向含「二维手绘、扁平插画、赛璐璐」；【影像质感】坚持「PBR 写实质感 + 卡通夸张造型（夸张在飘带弧线，不在五官）」。
3. **人多糊成一团、比例崩坏** → 【构图】分主次与层次（主仙清晰、群仙压后）；群仙写「分层环绕、大小递减、姿态各异」；负向含「人多糊成一团、比例崩坏、漂浮无重力」。
4. **主体过小、场面散** → 【构图】写「主仙占视觉中心」+ 尺度参照物（渺小仙官/群鹤，写明相对大小）；【镜头】低机位 24mm 仰拍。
5. **飘带花雨塞满、脏乱** → 【全局】写「少量」花雨飘带；负向含「脏色、基底过饱和」。
