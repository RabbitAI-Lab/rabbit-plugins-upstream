# 风格卡 · 复古胶片·年代唱将

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `复古胶片·年代唱将` |
| **一句话定位** | 像一段从老唱片与旧胶片里浮出来的演唱，怀旧、温热、有岁月感 |
| **媒介本质** | 8mm/16mm 老胶片质感（暖棕琥珀 + 浓重颗粒）；**非**数码高清、**非**卡通/油画 |
| **与最近似风格的区别** | 与「复古胶片·家庭纪事」不同：本档**演唱者可见面部口型、开口演唱**；与 MV 写实不同：老胶片颗粒/褪色 |
| **电影级从哪来** | ① 单一暖主光 ② 过曝高光 + 柔焦光晕 ③ 浓重颗粒 + 划痕 ④ 年代演唱场所纵深 |

## 二、★固定节（逐字照抄）

```
【光影】单一暖主光（钨丝灯/追光/台灯/夕阳入窗）且光源在画面内可解释；过曝高光、柔焦光晕；暖调、宁暗勿亮
【色彩】暖棕/琥珀色、暖棕米黄褪色青为调、强调色不超过两种；浓重胶片颗粒 + 细微划痕与灰尘
【影像质感】8mm/16mm 老胶片质感：手持微微晃动带来真实感；演唱者可见面部与口型、像叙旧般娓娓道来地开口演唱
【背景】年代演唱场所（小酒馆/旧礼堂/老房/木质录音棚/黄昏窗边），前景中景至少两层纵深；无可读文字/旧报纸文字
【风格】复古胶片·年代唱将：8mm/16mm 老胶片质感与暖棕琥珀色调的怀旧影像；演唱者可见面部与口型、像叙旧般娓娓道来地开口演唱，演唱者为虚构原创形象、不影射任何真实人物；整体怀旧、温热、有岁月感
【画幅】{9:16 或 16:9}   ← 只此两种
```

**★固定节填写要求**：命门词「**8mm/16mm 颗粒 + 暖棕褪色 + 手持微晃**」「**可见面部口型、娓娓道来**」「**虚构原创不影射真人**」逐字不动。

## 三、★专属负向（必须并入【负向】）

```
可辨认的真实歌手面孔、明星脸、肖像相似、影射在世公众人物、
数码高清锐利、无颗粒、冷硬打光、棚拍平光、现代霓虹、
高饱和荧光色、赛博感、
卡通、动漫、3D塑料感、油画厚涂、
英文文字、字幕、水印、标志、歌名文字、旧报纸文字、
畸形的手、多余手指、畸变、主体出框
```

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 演唱者可见面部与口型、娓娓道来；虚构原创（年代感造型：卷发/礼帽/旧衬衫）；可抱木吉他或立于老式麦克风前。 |
| 【次要元素·近/中/远】 | 前景麦克风/乐器 → 中景演唱者 → 远层年代场所。空层写「无」。 |
| 【全局】 | 暖调浮尘/光晕/胶片划痕。 |
| 【构图】 | 两层纵深；主体偏三分。**不写焦距/景深**。 |
| 【镜头】 | 中景/近景；手持微晃、柔焦。 |

## 六、易翻车点（写完回查）

1. **画成数码高清** → 负向含「数码高清锐利、无颗粒」。
2. **露真人脸/影射** → 负向含「可辨认的真实歌手面孔、影射在世公众人物」。
3. **现代霓虹感** → 负向含「现代霓虹、赛博感」。
4. **出文字** → 负向含「英文文字、旧报纸文字、歌名文字」。
