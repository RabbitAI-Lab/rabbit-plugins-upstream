# 风格卡 · 皮影戏

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `皮影戏` |
| **一句话定位** | 中国传统皮影戏（灯影戏）质感的手绘插画：暖黄灯火透过半透明影窗，镂刻影人在幕上成影 |
| **媒介本质** | 皮影戏手绘插画（幕布舞台 + 镂刻皮质影人）；**非**写实、**非**现代实景、**非**二次元 |
| **与最近似风格的区别** | 与「剪纸插画」不同：**必有暖灯透幕与影窗舞台**，光源在幕布后方；与水墨不同：镂刻+关节分节+透光亮边 |
| **电影级从哪来** | ① 幕后灯火逆光 ② 台前暗场/台后幽暗的明暗呼吸 ③ 台前—台后两层空间 ④ 光晕晕染 |

## 二、★固定节（逐字照抄）

```
【光影】光源一律来自影窗后方的油灯/灯火（逆光透幕），暖金色调（琥珀、暖黄、朱砂）；幕布上形成柔和光晕与晕染；台前暗场、台后幽暗，亮暗对比即呼吸；色温暖
【色彩】暖金灯火 + 幕布米白（#F7EED8 / #F2E4C6）≥50%，琥珀皮色（#E8A55C / #D98C3F）20–30%，石青靛蓝暗场（#16243D / #1E3A5F）10–20%，朱砂红（#C0392B）／玉绿（#2E8B6D）≤10%；暖而不脏、暗而不死
【影像质感】半透明镂刻皮质影人：侧身剪影、关节分节、镂空雕花纹样（云纹/水纹/缠枝）；轮廓边缘有灯光透出的亮线；影窗幕布纤维微光；无写实照片感、无厚重3D
【背景】台后深靛夜色暗场、雕花木框戏台、油灯、竹签牵线、角落锣鼓；无现代实景；无文字
【风格】中国传统皮影戏（灯影戏）插画，暖金灯火透过透亮的影窗幕布演出主要画面，镂刻影人侧身剪影；主体大、占据画面视觉中心，干净精致留白充足；非写实照片、非写实人脸、非厚重3D、非脏旧
【画幅】{16:9 或 9:16}   ← 只此两种
```

**★固定节填写要求**：命门词「**暖灯透幕（光源在幕布后方）**」「**镂刻侧身影人 + 关节分节**」「**影窗亮子是主舞台**」逐字不动。

## 三、★专属负向（必须并入【负向】）

```
写实照片感、写实人脸、写实皮肤、写实实景（办公室/电脑/街景）、厚涂、3D 塑料感、脏旧纹理、
现代场景、科幻城市、赛博霓虹、地标、品牌门店、二次元大眼、动漫风、
冷白平光、现代灯光、镜面反光、
文字、水印、Logo、二维码、英文、字母、拼音、乱码、错字
```

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 细节**：影窗上的镂刻影人或其道具（戏牌/长卷/门/船/棋盘/天平/阶梯）；"台后/牵线"类用掌灯操线人 + 竹签细线作主体。现代概念一律转译为皮影道具。 |
| 【次要元素·近/中/远】 | 近：台下观众剪影（抽象）；中：影窗主体；远：台后暗场/锣鼓。空层写「无」。 |
| 【全局】 | 幕布上的光晕晕染、浮尘、灯焰微光。 |
| 【构图】 | 主体大、占影窗视觉中心；台前/台后两层空间；留白充足。**不写焦距/景深**。 |
| 【镜头】 | 中景/全景，正对影窗视角（或幕后视角）；可写平视。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|
| 影窗全台/横版 | `16:9` 横 | `1536x1024` | 影窗居中，台框环绕 |
| 影人立绘/竖版 | `9:16` 竖 | `1024x1536` | 影人居中，上下幕布 |

## 六、易翻车点（写完回查）

1. **画成现代实景** → 【背景】写「不得出现现代实景」，负向含「写实实景、办公室、街景」。
2. **光源方向错（前面打光）** → 固定节锁定「光源来自影窗后方」。
3. **影人画成二次元/写实** → 负向加「二次元大眼、写实人脸」。
4. **暖光变脏黄** → 负向加「脏旧纹理、高饱和乱闪」，保持暖而不脏。
