# 风格卡 · 韩系柔和全彩

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `韩系柔和全彩` |
| **一句话定位** | 保留完整色彩的柔光人像，像韩剧/韩博主那样干净又有点甜 |
| **媒介本质** | 全彩柔光人像/写真后期方向；**非**黑白灰调、**非**硬光高对比 |
| **与最近似风格的区别** | 与「日系赛璐璐」不同：本档**柔光低对比、真人质感**；与写实大片不同：**对比压柔、透亮微甜** |
| **电影级从哪来** | ① 柔光低对比 ② 阴影通透不发黑 ③ 肤色粉白奶油 ④ 环境色统一低饱和 |

## 二、★固定节（逐字照抄）

```
【光影】对比压柔、低对比；阴影通透不发黑，高光柔和不溢出；柔光
【色彩】保留完整色彩，不做黑白或极简灰调；肤色呈粉白/奶油感、干净透亮；环境色统一、低饱和、统一色温，不抢主体
【影像质感】如韩剧/韩博主写真般干净微甜、透亮自然；真人质感
【背景】都市/甜宠/职场/家庭等实景，环境色统一低饱和、不抢主体；无可读文字
【风格】整幅画面的画风严格与「韩系柔和全彩」一致：保留完整色彩，不做黑白或极简灰调；对比压柔、低对比，阴影通透不发黑，高光柔和不溢出；肤色粉白/奶油感、干净透亮；环境色统一、低饱和、统一色温；整体干净微甜、透亮自然
【画幅】{9:16 或 16:9}   ← 只此两种
```

**★固定节填写要求**：命门词「**全彩（不做黑白/灰调）**」「**柔光低对比、阴影通透不发黑**」「**粉白奶油肤色**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 人像：粉白/奶油肤色、干净透亮；服饰与环境色统一低饱和；表情干净微甜。 |
| 【次要元素·近/中/远】 | 实景分层，环境色统一；空层写「无」。 |
| 【全局】 | 柔光光晕/浮尘（克制）。 |
| 【构图】 | 人像居中或三分；背景退让。**不写焦距/景深**。 |
| 【镜头】 | 中景/近景；浅景深柔焦（f/1.8 柔和虚化）。 |

## 六、易翻车点（写完回查）

1. **出黑白/灰调** → 负向含「黑白、单色、灰阶」。
2. **硬光高对比死黑** → 负向含「高对比、硬光死黑」。
3. **肤色发黄/发灰/塑料** → 负向含「橙色皮肤、灰暗肤色、塑料皮肤」。
4. **环境色抢主体** → 负向含「冷暖色冲突、过饱和」。
