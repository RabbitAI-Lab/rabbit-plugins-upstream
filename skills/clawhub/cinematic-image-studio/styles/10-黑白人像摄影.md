# 风格卡 · 黑白人像摄影

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `黑白人像摄影` |
| **一句话定位** | 一张真实拍摄的黑白生活照片——像别人从旁边随手拍下的真实一瞬 |
| **媒介本质** | 写实摄影（现场光 + 自然颗粒）；**非**影棚、**非**摆拍、**非**电影感、**非**插画/CG |
| **与最近似风格的区别** | 与「黑白影棚人像」镜像相反：本档要**现场光、旁观抓拍、不看镜头**；与彩色不同：**纯黑白灰阶零色彩** |
| **电影级从哪来** | ① 一道现场光的方向感 ② 浅景深自然焦外 ③ 略随意构图 ④ 自然颗粒与不完美质感 |

## 二、★固定节（逐字照抄）

```
【光影】只用一道日常现场光（白天散射光／阴天漫射光／窗光／街边店铺灯光／树荫斑驳光），光比平缓、过渡自然、允许平光与灰调；暗部自然落影；对焦落在眼睛
【色彩】纯黑白灰阶、零色彩、不用任何颜色词（靛蓝→深色、青瓷→浅灰白）；中低反差、正常曝光；用明度分层（深色衣 × 浅色巾）保证主体与背景分离
【影像质感】真实拍摄的黑白照片：自然细颗粒（暗部略粗、不夸张）、皮肤毛孔/绒毛/油光/老年斑、皱纹里藏灰、织物磨旧线头与不对称褶皱、眼球湿润有现场光自然反光点；不做磨皮、不蜡感；成像带镜头自然柔度（边缘柔顺、微反差适中）
【背景】日常环境（家常／街巷／室内），深度虚化，允许虚化杂件（椅背一角/桌沿/树影/路人剪影）自然入画；无可读文字与招牌
【风格】这是一张真实拍摄的黑白照片（写实摄影）：纯黑白灰阶、无任何色彩，只写现场发生了什么；非影棚感、非摆拍感、非电影感/艺术大片感、非插画/CG
【画幅】{16:9 或 9:16 或 3:4}   ← 只写取向
```

**★固定节填写要求**：命门词「**只用一道日常现场光**」「**纯黑白灰阶零色彩**」「**自然颗粒 + 不完美**」逐字不动；戏剧化布光/明显银盐颗粒/强反差/大场景**默认不写，须用户点名**。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 单主体，近景胸像/半身，占画面约 2/3–4/5；写稳定外形（用明度描述服装）、神态有落点。 |
| 【次要元素·近/中/远】 | 背景虚化杂件自然入画（增真实感）；空层写「无」。 |
| 【全局】 | 现场光浮尘/薄雾（可选）。 |
| 【构图】 | 略随意、主体略偏离正中；像被随手抓拍。**不写焦距/景深**。 |
| 【镜头】 | 浅景深自然焦外、长焦压缩；抓拍机位（旁观者约 2–4 m、手持自然高度、略高/略低于视线）。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|
| 人像竖版 | `9:16` 竖 | `1024x1536` | 主体居中略偏，环境虚化 |
| 横版/环境 | `16:9` 横 | `1536x1024` | 留环境、深度虚化 |

## 六、易翻车点（写完回查）

1. **出影棚感/摆拍感** → 【光影】锁定「只用一道日常现场光」，负向含「影棚布光、摆拍、staged」。
2. **出彩色** → 正文学彩色词，负向含「色彩、彩色、棕褐、暖调、蓝调」。
3. **渲染感/过度锐化** → 负向含「cgi render、digital illustration、过度锐化」。
4. **磨皮蜡感** → 负向含「磨皮、蜡质皮肤」，保留毛孔与颗粒。
