# 风格卡 · 年代纪实·历史厚重

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `年代纪实·历史厚重` |
| **一句话定位** | 像一段被妥善保存的历史底片，克制、厚重、有敬意，不煽情不戏说 |
| **媒介本质** | 年代纪实影像（低饱和做旧颗粒 + 老化肌理）；**非**卡通/游戏CG/油画 |
| **与最近似风格的区别** | 与「复古胶片家庭纪事」不同：本档**低饱和青灰旧棕、庄重秩序、历史题材**；历史名人**只以意象物件指涉** |
| **电影级从哪来** | ① 庄重自然光的强明暗 ② 雾气浮尘年代介质 ③ 明显纵深 ④ 老化肌理 |

## 二、★固定节（逐字照抄）

```
【光影】庄重的自然光（天光/晨昏光/窗光）且光源在画面内可解释；明暗对比强而暗部保留层次；画面有雾气、浮尘等年代介质
【色彩】低饱和的青灰/旧棕/米黄基调、强调色不超过两种；低饱和做旧颗粒
【影像质感】年代纪实影像：砖石/纸张/木/金属/布料的老化肌理；历史与名人题材只以意象物件与场景指涉、不追求人物肖像的写实相似
【背景】老城墙/旧长街/纪念碑/旧书房/厂房/山河等时代空间，前景中景远景有明显纵深；无可读文字、无旗帜文字/标语/碑文
【风格】年代纪实·历史厚重：沉稳克制的年代纪实影像；人物一律以剪影/背影/侧影/逆光轮廓/手部衣袖局部呈现，不出现可辨认的真人正脸；以旧砖墙/油灯/书稿/笔砚/旗帜一角/无字老照片等物件叙事；庄重、厚重、有敬意、不煽情不戏说
【画幅】{9:16 或 16:9}   ← 只此两种
```

**★固定节填写要求**：命门词「**低饱和青灰旧棕 + 做旧颗粒**」「**历史人物只以意象物件指涉（不写实肖像）**」「**不露正脸**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 以旧砖墙/油灯/书稿/笔砚/旗帜一角/无字老照片等物件叙事；人物剪影/背影/侧影/逆光轮廓/手部衣袖局部，不露正脸、不写实肖像。 |
| 【次要元素·近/中/远】 | 前景时代物件 → 中景主体 → 远景时代空间。空层写「无」。 |
| 【全局】 | 雾气/浮尘/年代介质。 |
| 【构图】 | 纪念碑般秩序感；matter 明显纵深。**不写焦距/景深**。 |
| 【镜头】 | 中景/远景；庄重自然光。 |

## 六、易翻车点（写完回查）

1. **历史名人写实肖像** → 负向含「历史人物真实面容、肖像相似、领袖像」，【主体】只以意象物件指涉。
2. **戏说/煽情** → 负向含「戏说、恶搞、煽情MV感」。
3. **出文字/标语/碑文** → 负向含「可读的文字、标语、碑文」。
4. **露正脸** → 负向含「可辨认的真人正脸」。
