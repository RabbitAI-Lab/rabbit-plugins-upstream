# 风格卡 · 暗黑浪漫·哥特少女

> **给写提示词的自己**：本卡 ★固定节 的字段必须**逐字照抄**，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `暗黑浪漫·哥特少女` |
| **一句话定位** | 单一烛光下的深暗调哥特浪漫：蕾丝、黑玫瑰、剥落墙面与烛焰暖点 |
| **媒介本质** | 古典油画式布光的**暗调实拍人像/静物**（单一光源），非恐怖怪物、非赛博暗黑、非血腥 |
| **与最近似风格的区别** | 与「赛博霓虹」（33）不同：**暖烛光 + 古典室内**，非霓虹冷光；与「复古胶片」（24）不同：**极深暗部与强反差**；与「黑白影棚」（11）不同：**有暗酒红与墨绿的色相** |
| **电影级从哪来** | ① 单一光源制造大面积暗部与伦勃朗式亮部 ② 光比 1:8 的古典油画影调 ③ 蕾丝/纱质在逆光下的通透 ④ 烛焰作为画面唯一暖点 |

## 二、★固定节（逐字照抄）

```
【光影】单一光源布光：画面外左侧一支蜡烛（或一扇窄窗的冷月光）作唯一主光，暖橙色约 1900K（冷月光版为 6000K），45° 侧逆打在主体侧脸与肩线；光比约 1:8，约九成画面落入深褐黑，仅轮廓与受光面可辨；轮廓光极细窄、只勾一条边；高光有轻微柔焦溢出
【色彩】黑（#0B0A0A）与深褐（#1C1614）占 85% 以上，暗酒红（#4A1220）、墨绿（#16261E）、旧象牙白（#E6DCC8）为唯一彩色层，金属银（#B9BDC4）作细微点睛；极低明度、低饱和，仅烛焰处高饱和暖橙
【影像质感】古典油画式暗调摄影：柔焦乳剂颗粒、暗部保留含蓄层次而非死黑、烛光高光有轻微光晕溢出、织物（蕾丝/纱/丝绒）纹理清晰、有轻微镜头暗角；非数码通透高调、非 HDR
【背景】古典衰败室内：剥落的墙皮、蕾丝窗帘、枝形烛台、干枯黑玫瑰、旧木家具、窄窗，环境元素全部隐入暗部
【风格】暗黑浪漫哥特人像，单一烛光与深暗调古典布光，蕾丝、黑玫瑰与衰败室内，忧郁浪漫的文学气质；非恐怖血腥、非赛博暗黑、非明亮清新
【画幅】{9:16}
```

**★固定节填写要求**：
- 命门词「**单一烛光作唯一主光**」「**光比 1:8、九成画面深褐黑**」「**柔焦乳剂颗粒 + 高光轻微溢出**」逐字不动。
- 光源色温、面积比不许改；只允许替换室内陈设与人物造型。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：虚构人物的发色与发型（黑长直/盘发/湿发）、肤色、服装（蕾丝高领衬衫、丝绒长裙、束腰马甲、纱质披肩）、配饰（银质颈链、珍珠耳坠、黑色缎带）、手持物（黑玫瑰、烛台、旧书、怀表）、姿态（侧身回望、低头抚花、倚墙）、眼神方向、受光面落在哪。一律「虚构人物（无原型）」。 |
| 【次要元素·近/中/远】 | 近：蕾丝袖口/烛台/黑玫瑰的一枝；中：主体与椅背或窗框；远：剥落墙皮、帷幔褶皱。空层写「无」。 |
| 【全局】 | 极细的烛烟、漂浮的尘粒、柔焦光晕。 |
| 【构图】 | 9:16 竖构图，主体偏一侧、受光面朝光源，暗部占画面 60–70%；可有窗框或帷幔作第二边框。**不写焦距/景深**。 |
| 【镜头】 | 等效 50–85mm、f/1.8–f/2.5、浅景深、受光眼与唇部锐利、暗部柔化。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |

## 六、易翻车点（写完回查）

1. **画成恐怖血腥** → 固定节只写「忧郁浪漫」，负向含「血腥、伤口、恐怖怪物、恐怖片妆容」。
2. **暗部糊死没层次** → 质感节写「暗部保留含蓄层次」，负向含「死黑无层次」。
3. **变成赛博暗黑/霓虹** → 负向含「霓虹、赛博紫青、荧光色」。
4. **出现宗教符号** → 负向含「十字架、宗教符号」，【背景】不写教堂标识。
5. **变明亮写真** → 【光影】限「单一光源、光比 1:8、九成画面深暗」。
