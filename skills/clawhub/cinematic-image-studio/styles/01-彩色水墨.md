# 风格卡 · 彩色水墨

> **给写提示词的自己**：本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `彩色水墨` |
| **一句话定位** | 水墨为骨、矿物色为肉，宣纸上的电影感彩墨画 |
| **媒介本质** | 中国画 · 彩墨（写意为主、局部工笔），**不是**水彩、**不是**油画、**不是**数字插画 |
| **与黑白水墨的区别** | 有明确的彩色层：矿物色沉淀 + 水色洇染；但**黑与白仍是画面骨架**，彩色只作气韵与光 |
| **与「国风插画」的区别** | **保留真实毛笔笔触、宣纸纤维、墨色洇开的水痕毛边**；国风插画是矢量 / 平涂 / 数码感，**必须排除** |
| **电影级从哪来** | ① 单一主光方向 → 落在墨色浓淡上做明暗；② 虚实＝景深；③ 宽银幕构图 + 负空间；④ 胶片颗粒 + 电影一级调色 |

## 二、★固定节（逐字照抄）

```
【光影】{主光方位}，单一主光、方向明确；以墨色浓淡与色层厚薄塑形（近处浓重、远处淡逸），
       光比柔和、不出现硬边阴影；主体背光侧以留白的蛤白或极淡藤黄勾出轮廓光；{色温}
【色彩】墨分五色为骨架，辅以{矿物色清单：石青 / 石绿 / 朱砂 / 赭石 / 藤黄 / 蛤白}；
       {主调}为主，{点缀色}作点睛；整体{饱和度}；画面留白约占{留白占比}，留白处即为云雾与水面的"气"
【影像质感】宣纸纤维质地，墨色自然洇开、边缘有毛涩水痕与飞白；矿物颜料沉淀颗粒清晰可见；
           叠加 35mm 胶片细腻颗粒与轻微暗角；{调色}一级调色，暗部不堵、亮部不曝，整体通透
【背景】{背景内容}，以淡墨至无墨层层退远，边缘没入留白与云雾；无题款、无印章、无任何文字
【风格】彩色水墨（彩墨），写意为主、{局部工笔}为辅，中国画笔墨气韵，
       院线东方美学电影剧照质感，非数码插画、非水彩、非油画
【画幅】{16:9 或 9:16}   ← 只此两种，16:9（横 · 山水/群像）或 9:16（竖 · 立轴人物/器物）
```

**★固定节填写要求**：
- 【光影】里的 `{主光方位}` / `{色温}` **每张图可换**（顺光晨雾 / 侧逆光夕照 / 散射天光），但**句式与"墨色塑形"内核必须保留**。
- 【色彩】里的 `{矿物色清单}` / `{主调}` / `{点缀色}` **随主体换**，但**"墨分五色为骨架"这句永远保留**（这是本风格不跑偏的锚）。
- 【影像质感】的 `35mm 胶片细腻颗粒 + 轻微暗角 + 一级调色` **逐字不动**。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：是什么 + 确切名 + 尺寸/数量 + 材质 + 颜色（用**传统色名**：石青 / 石绿 / 朱砂 / 赭石 / 藤黄 / 蛤白 / 花青 / 胭脂 / 墨）+ 姿态朝向 + 神态。人物写「虚构的东方古代XX（无历史原型）」。 |
| 【次要元素·近/中/远】 | 按前景（可作前景框，如探入的松枝 / 芦苇）→ 中层 → 远层分层写；空层写「无」。 |
| 【全局】 | 满屏介质：斜雨丝 / 云雾 / 浮尘 / 落瓣 / 光束 —— **与【镜头】景深自洽**。 |
| 【构图】 | 机位高低 + 主体站位（三分法 / 对角线 / 中轴）+ 纵深 + **大面积留白的位置**。**不写焦距 / 景深**。 |
| 【镜头】 | 景别 + 机位角度 + 等效焦距 + 光圈/景深 + 焦点。大远景 24mm f/8；中景 50mm f/4；近景 85mm f/2.8。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|
| 山水 / 群像 / 大场面 | `16:9` 横 | `1536x1024` | 宽银幕，主体偏三分线，**留白四成以上**作云雾水面 |
| 人物 / 立轴 / 器物 | `9:16` 竖 | `1024x1536` | 立轴式，上留天、下留地，主体居中略偏 |

## 六、易翻车点（写完回查）

1. **画成水彩 / 油画** → 检查【影像质感】的"宣纸纤维 / 墨色洇开 / 毛涩水痕"与专属负向是否都在。
2. **色把墨压死，变成平涂彩块** → 「墨分五色为骨架」必须保留，且【光影】要写"以墨色浓淡塑形"。
3. **出现题款印章文字** → 合规红线要求零可读文字。**做法**：正向写「无题款、无印章、无任何文字」，负向含「题款、落款、书法文字、印章、篆刻」。**代价**：会少了传统画的题款气，用**大面积留白**补足。
4. **数码插画感（无笔触、太干净）** → 负向补「平涂、无笔触、无纸纹、描边、勾线平涂」。
5. **留白不足、画面塞满** → 【构图】明确写留白位置与占比。
