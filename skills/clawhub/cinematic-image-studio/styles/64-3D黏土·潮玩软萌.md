| 项 | 内容 |

| **媒介本质** | **实体黏土/软陶公仔的微距摄影**（定格动画道具感），非塑料 3D 渲染、非毛绒 |

## 二、★固定节（逐字照抄）

```
【光影】柔光棚拍：45° 主光来自大面积柔光箱、右侧一块反光板补光、顶部一道细窄轮廓光勾出边缘；光比约 1:3，过渡圆润无硬边，公仔底部有柔和的接触阴影；无彩色环境光、无闪光直打
【色彩】奶油马卡龙同族配色：薄荷绿（#A8DFC7）、奶粉（#F3C6C6）、奶油黄（#F5E3A8）、雾蓝（#AECBE8）任选 2–3 色作主体，背景为同族更深或更浅一个色阶的单色；高明度、低饱和、无撞色
【影像质感】手捏黏土（油泥/软陶）实物微距：表面是哑光油润的黏土肌理——密集的指腹螺旋纹、指甲刮出的细划痕、工具压出的浅凹坑、拼接处可见轻微缝隙与细小裂纹、边缘为手工搓揉的圆钝不规整；高光极柔、只有一层薄薄的油润反光，没有任何镜面塑料光泽；表面浮着极细的黏土粉末与两三颗微小气泡；微距浅景深、焦外柔化成奶油状；非塑料 CG、非 3D 渲染
【背景】单色无缝背景纸（同族色的深一档或浅一档）+ 一到两件简单几何道具（木质积木块、亚克力圆球、纸筒），道具全部纯色无图案
【风格】黏土定格动画质感的潮玩公仔实拍，手捏油泥微距棚拍，软萌比例与马卡龙配色，治愈系周边感；非塑料 3D 渲染、非毛绒、非写实
【画幅】{16:9}
```

## 六、易翻车点（写完回查）

1. **变成塑料 3D 渲染** → 固定节写「指纹、工具痕、哑光」，负向含「塑料 3D 渲染、CG 光泽、亮面乙烯基」。
2. **配色花掉** → 【色彩】限「同族 2–3 色 + 单色背景」，负向含「高饱和撞色」。
3. **比例崩坏/多手多脚** → 主体段写清头身比与肢体数量，负向含「畸形肢体、多余手脚」。
4. **棚拍变平光** → 强调「45° 柔光箱 + 右侧反光板 + 顶部轮廓光」三段布光。
5. **背景杂乱** → 【背景】限「单色无缝纸 + 1–2 件纯色道具」。
