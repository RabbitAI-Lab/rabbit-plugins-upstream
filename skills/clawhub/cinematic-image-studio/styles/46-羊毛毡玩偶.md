# 风格卡 · 羊毛毡玩偶（绒毛纤维 · 软萌圆润）

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `羊毛毡玩偶` |
| **一句话定位** | 像一组羊毛毡戳戳乐玩偶——毛茸茸的群仙在软软的毡制天宫里起舞 |
| **媒介本质** | 羊毛毡（戳制/毡化羊毛纤维、圆润造型）；**非**3D、**非**塑料、**非**写实 |
| **与最近似风格的区别** | 与「橡皮泥·黏土定格」（42）不同：本档是**绒毛纤维感、戳制不匀、纤维末梢**，非黏土光滑；与3D毛绒渲染不同：本档有**手工毡化的不完美与纤维。** |
| **软萌从哪来** | ① 绒毛纤维 ② 圆润短圆造型 ③ 柔和低饱和色 ④ 无明显硬影的柔光 |

## 二、★固定节（逐字照抄）

```
【光影】柔和均匀的摄影棚布光、无明显硬影；绒毛表面呈柔和高光与淡淡绒影；整体暖调、温润
【色彩】羊毛毡的柔和低饱和色：奶油白、藕粉、雾霾蓝、抹茶绿、焦糖棕；背景为纯色或浅色毡面；柔和、干净、莫兰迪感
【影像质感】羊毛毡玩偶质感：羊毛纤维的绒毛感、毡制表面不匀、圆润软糯造型、纤维末梢与戳痕可见；非3D渲染、非塑料、非照片写实
【背景】羊毛毡搭的简化天宫：毡制云朵、柱子、台阶，圆润造型；纯色毡底、明度低于主体；无可读文字
【风格】羊毛毡戳戳乐玩偶：绒毛纤维质感、圆润软萌、手工温润、莫兰迪柔色；非3D、非塑料、非写实照片、非二维动画
【画幅】16:9
```

**★固定节填写要求**：命门词「**羊毛纤维绒毛 + 戳制不匀 + 纤维末梢**」「**圆润软萌造型**」「**柔和无硬影布光**」逐字不动。

## 六、易翻车点（写完回查）

1. **变塑料/3D** → 负向含「3D渲染、光滑塑料、树脂」；【影像质感】写「绒毛纤维、戳制不匀、纤维末梢」。
2. **变写实真人** → 负向含「写实照片、写实人脸、写实毛发」；【主体】写「圆润短圆、豆豆眼、毡偶」。
3. **绒毛糊成一团/毛球** → 负向含「绒毛糊成一团、绒毛变毛球」；【影像质感】写「纤维末梢清晰、戳痕可见」。
4. **颜色脏/太艳** → 负向含「脏色」；【色彩】写「柔和莫兰迪柔色」。
