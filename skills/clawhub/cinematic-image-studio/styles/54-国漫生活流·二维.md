```
【光影】日间露天舞台的现场光：暖白追光 + 地排灯自下而上 + 自然阳光；平涂色块，亮部通透、暗部不糊；整体暖调；不用体积光、辉光、镜头光晕
【色彩】自然生活色：黑或深棕发色、自然肤色、米白 / 浅灰 / 浅蓝 / 卡其 / 水洗蓝；正红是画面唯一高饱和强调色；不用粉紫、不用荧光色、不做大面积渐变

【画幅】{4:3 或 16:9 或 9:16}
```

## 六、易翻车点（写完回查）

1. **画成日系 / 像日本人** → 负向含「日系动画脸、番剧脸、大眼萌、大眼睛、锥子脸、尖下巴、欧式双眼皮、混血脸、日系碎刘海、动漫高光、星瞳」；主体必须写「中国人的骨相：脸型偏宽、颧骨略平、鼻梁不高、鼻翼略宽、单眼皮或内双、眼裂窄、下颌线不尖」。
2. **画成 3D / CG / 写实** → 负向含「3D 渲染、CG 渲染、写实真人、照片质感、厚涂」。
3. **人物僵硬、像立牌** → 【主体】必须写「重心落在单腿 / 肩胯反向 / 手不贴身 / 一个具体动作 / 一个具体表情」，禁用「自然站立」。
4. **六个人像同一个人 / 缺特点** → 每人必须写「脸型 + 眼型 + 发型 + 年龄感 + 体型 + 白色标志单品 + 一个动作习惯」；六人的脸型、身高、体型必须有断层。
5. **出现可读文字 / 品牌** → 负向含「英文文字、拉丁字母、乱码文字、水印、标志、歌名文字、乐器品牌 logo」。
