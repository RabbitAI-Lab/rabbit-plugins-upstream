## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `Y2K·千禧数码闪光` |
| **一句话定位** | 2000 年代 CCD 卡片机直闪审美：正面硬闪光 + 金属银果冻撞色 + 数码噪点 |
| **媒介本质** | 消费级数码卡片机（CCD）**机顶直闪**的直出照片；非胶片、非现代全画幅、非棚拍柔光 |

| **电影级从哪来** | ① 单一硬闪作为明确主光、影调干脆 ② 高光过曝控制在一小块、不糊整脸 ③ 主体与暗场的明暗切割 ④ CCD 质感的噪点与色散，非滤镜涂抹 |

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：人物的肤色/发色（银灰/黑直发）、发夹/挑染、上衣材质（亮面尼龙、银色羽绒、短款夹克）、裤型、厚底鞋、金属项链/耳环、手持物（一次性相机、翻盖手机、冰饮）、姿态朝向与表情。一律写「虚构人物（无原型）」。 |
| 【次要元素·近/中/远】 | 近：被闪光打亮的地砖/门框/冰柜玻璃反光；中：主体与随身物；远：压暗的便利店招牌光斑/车库柱/街机灯箱。空层写「无」。 |
| 【全局】 | 闪光带起的空气微尘、镜头轻微眩光、细小雨点或冰柜冷雾（择一，勿堆）。 |
| 【构图】 | 竖构图、主体占画面 55–75%；正面略低机位（胸口高度）或侧面 3/4；留白少、压迫感强。**不写焦距/景深**。 |
| 【镜头】 | 等效 28–35mm 广角近摄（手机/卡片机观感），f/2.8–f/4，闪光决定性曝光，主体全清晰、背景靠距离衰减。 |

## 六、易翻车点（写完回查）

1. **画成胶片复古暖黄** → 固定节必须是「冷白直闪 + 青暗部」，负向已含「胶片颗粒、暖黄复古调」。
2. **闪光把脸打过曝** → 主体段写「过曝只落在鼻尖/颧骨/金属饰件小块高光」，负向加「面部过曝全白」。
3. **变成霓虹赛博** → 环境只作为压暗的背景，负向含「霓虹自发光主体、赛博朋克紫青」。
4. **皮肤被磨成 AI 蜡像** → 负向含「磨皮过度、AI 完美皮肤、塑料 CG 皮肤」，质感节强调「CCD 噪点」。
5. **出现招牌文字** → 【背景】写「无可读文字」，负向含「文字、英文字母、乱码」。
