# 风格卡 · 温情治愈·电影感写实

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `温情治愈·电影感写实` |
| **一句话定位** | 像一段被好好记住的生活，情绪从真实细节里自己渗出来 |
| **媒介本质** | 生活纪实写实影像；**非**广告感/婚纱影楼/摆拍、**非**卡通/3D |
| **与最近似风格的区别** | 与「MV电影感写实」不同：本档**不露正脸**（MV 档要可见面部口型） |
| **电影级从哪来** | ① 暖金自然光（可解释）② 柔和高光滚降 + 浅景深 ③ 两层纵深 ④ 空气介质与胶片颗粒 |

## 二、★固定节（逐字照抄）

```
【光影】暖金色自然光（晨光/窗光/灶火/台灯/烛光/夕阳，光源在画面内可解释）；柔和高光滚降、浅景深、背景自然虚化；暗部保留细节；色温暖
【色彩】暖金/奶油白/木色/低饱和暖褐为基底；强调色不超过两种（如暖橘 + 一点青）；轻微胶片颗粒与柔光，不要干净数码感
【影像质感】生活纪实质感的写实影像：微距级真实质感（织物褶、木头纹、蒸汽水汽、皮肤的暖）；真实、克制、不摆拍、不广告感
【背景】日常生活实景（厨房/餐桌/阳台/老屋院子/校园长廊/街角/海边/车窗外）；前景中景至少两层纵深；天气与时辰是情绪的一部分；环境永远比主体低一档亮；无可读文字
【风格】温情治愈·电影感写实：暖金自然光、柔和高光滚降 + 浅景深；人物一律以剪影/背影/侧影/过肩/手部与身体局部呈现，不出现可辨认的真人正脸；靠手势、姿态与细节传达情感；整体真实、克制、不摆拍不广告感
【画幅】{9:16 或 16:9}   ← 只此两种
```

**★固定节填写要求**：命门词「**不露可辨认正脸**」「**暖金自然光且光源可解释**」「**生活纪实、不摆拍**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 人物以剪影/背影/侧影/过肩/手部与身体局部呈现；靠手（牵握/劳作/递物）、脚步、肩线、发丝传达情感；关系而非个体。 |
| 【次要元素·近/中/远】 | 前景（窗框/门框/器物）→ 中景主体 → 远层日常场景。空层写「无」。 |
| 【全局】 | 晨雾/浮尘/蒸汽/逆光发丝光。 |
| 【构图】 | 至少两层纵深；主体偏三分；留白适度。**不写焦距/景深**。 |
| 【镜头】 | 中景/近景；浅景深（f/2.8 柔和虚化）。 |

## 六、易翻车点（写完回查）

1. **露正脸** → 负向含「可辨认的真人正脸、明星脸」，【主体】强制剪影/背影/局部。
2. **摆拍/广告感** → 负向含「摆拍感、婚纱影楼风、广告感」。
3. **打光冷硬/平光** → 负向含「冷硬打光、棚拍平光」。
4. **出文字/日历** → 负向含「文字、日期数字、日历」。
