# 风格卡 · 景泰蓝·掐丝珐琅（金丝掐线 · 珐琅填彩 · 鎏金铜胎）

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `景泰蓝·掐丝珐琅` |
| **一句话定位** | 像一件景泰蓝大缸/大盘上的画面——金丝掐线、珐琅填彩，端庄华贵 |
| **媒介本质** | 掐丝珐琅（金铜丝抬出线格 + 格内填珐琅彩釉 + 铜胎鎏金）；**非**绘画、**非**陶瓷青花、**非**3D |
| **与最近似风格的区别** | 与「青花瓷」（40）不同：青花是**釉下单色钴蓝手绘**；本档是**金丝抬线 + 多色珐琅填彩 + 鎏金**；与绘画不同：本档是**线格填釉**的工艺质感。 |
| **华贵从哪来** | ① 金丝抬线的线格 ② 高饱和珐琅彩 ③ 鎏金铜胎 ④ 釉面温润反光 |

## 二、★固定节（逐字照抄）

```
【光影】珐琅釉面的柔亮反光与鎏金铜丝的金属高光；布光柔和、釉面各处泛起温润亮光；暗部保留细节、不出现硬边死黑
【色彩】珐琅填彩：孔雀蓝、宝石蓝、松石绿、朱红、藤黄、藕荷等高饱和珐琅色，金丝分隔；鎏金作边框与抬线；华贵富丽、色块纯正干净
【影像质感】掐丝珐琅（景泰蓝）质感：金铜丝抬出的纹样线格、格内填珐琅彩釉、釉面光亮温润、金丝微凸反光、铜胎鎏金边；非绘画、非陶瓷青花、非3D、非塑料
【背景】掐丝珐琅的天宫纹样：卷草缠枝、云纹、宫阙以金丝线格填彩；底色多为孔雀蓝或宝石蓝；无可读文字
【风格】中国景泰蓝掐丝珐琅工艺：金丝掐线 + 珐琅填彩 + 铜胎鎏金；端庄华贵、装饰性强；非绘画、非陶瓷青花、非3D、非照片
【画幅】16:9
```

**★固定节填写要求**：命门词「**金丝抬出的线格 + 格内填珐琅彩**」「**鎏金铜胎**」「**釉面温润流光**」逐字不动。
