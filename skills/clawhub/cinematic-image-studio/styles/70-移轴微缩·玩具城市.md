# 风格卡 · 移轴微缩·玩具城市

> **给写提示词的自己**：本卡 ★固定节 的字段必须**逐字照抄**，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `移轴微缩·玩具城市` |
| **一句话定位** | 高机位俯拍 + 移轴浅景深，把真实城市拍成一座玩具模型 |
| **媒介本质** | **真实场景的移轴摄影**（光学浅景深造成微缩错觉），非 3D 模型渲染、非微缩实物摆拍 |
| **与最近似风格的区别** | 与「立体纸雕」（47）、「积木」（49）不同：**是真实世界的照片**，只是景深制造错觉；与「蓝调夜行」（63）不同：**白天高饱和、俯拍**；与「奶油极简」（62）不同：**信息密集、非留白** |
| **电影级从哪来** | ① 单一水平合焦带制造「模型感」的唯一机关 ② 高机位俯视带来上帝视角 ③ 干净强光让色彩变得像塑料玩具 ④ 大量重复的几何元素（屋顶、集装箱、车流）成为纹理 |

## 二、★固定节（逐字照抄）

```
【光影】晴天上午的硬质直射日光：光从右上约 50° 打下，物体投出短而清晰的硬边阴影（约等于物体高度的三分之一），亮部通透、暗部蓝灰但保留细节；空气极其干净、无明显雾霾；整体光比约 1:3
【色彩】玩具级高饱和：屋顶的砖红（#C2412D）与赭黄（#E0A93B）、植被的翠绿（#3E9B57）、水面的青蓝（#2E7FA8）、车漆的高饱和红黄蓝散点；白平衡偏中性，整体明度高、饱和度高、对比干净
【影像质感】真实场景的移轴摄影：画面只有一条约占总高 18–25% 的水平合焦带锐利，其上下迅速过渡为奶油状虚化（焦外光斑为圆形、边缘柔化）、虚化程度随距离线性加深；轻微镜头呼吸感、极细锐化边缘、无胶片颗粒；非微缩实物摆拍、非 3D 渲染
【背景】俯视的城市/工地/港口/集市肌理：重复的屋顶、集装箱、车流、树冠、轨道线与斑马线，向画面深处层层铺开；所有招牌与标识全部虚化或不可辨认
【风格】移轴微缩摄影，真实城市被浅景深拍成玩具模型，高机位俯视与高饱和干净影调；非 3D 模型、非微缩实物、非航拍大景深
【画幅】{16:9}
```

**★固定节填写要求**：
- 命门词「**水平合焦带占 18–25%**」「**上下奶油虚化**」「**硬质直射日光 + 短硬影**」「**玩具级高饱和**」逐字不动。
- 合焦带比例与色号不许改；只允许替换俯拍场景与主体活动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：场景类型（十字路口/工地/港口/菜市场/球场）、主体活动的具体物（一辆红色巴士、三台挖掘机、一排集装箱、两辆送货车）、数量与位置、颜色、尺寸比例、姿态与动向、与合焦带的关系（必须落在合焦带内）。人物只写背影或远景小人。 |
| 【次要元素·近/中/远】 | 近：被虚化的屋顶或树冠（画面上缘）；中：合焦带内的主体活动；远：继续虚化的街肌理与地平线。空层写「无」。 |
| 【全局】 | 干净空气中的强光、车顶反光、水面碎光。 |
| 【构图】 | 高机位俯视 45–70°、地平线压在画面上缘或完全不出画；合焦带水平贯穿画面中段，主体落在其中。**不写焦距/景深数值**。 |
| 【镜头】 | 移轴镜头俯拍、等效 45–85mm、极浅景深（合焦带 18–25%）、上下奶油虚化。 |

## 六、易翻车点（写完回查）

1. **景深不够浅，没有模型感** → 固定节写「合焦带 18–25%、上下线性加深虚化」，负向含「全画面清晰、大景深」。
2. **变成 3D/实物模型** → 负向含「3D 模型渲染、塑料玩具实物摆拍」。
3. **出现真实招牌与车牌** → 【背景】写「招牌全部虚化或不可辨认」，负向含「车牌、门店文字」。
4. **颜色发灰不像玩具** → 【色彩】锁高饱和色号，负向含「阴天灰调、低饱和莫兰迪」。
5. **房屋倾倒/结构畸变** → 负向含「房屋倾倒、畸形结构」。
