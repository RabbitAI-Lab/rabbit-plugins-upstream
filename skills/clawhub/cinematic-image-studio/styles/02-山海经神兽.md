## 二、★气派四件套（本风格的命门 · 缺一不可）

> 这四条是 v1「不够气派」的根因，**每张图都必须逐条落实**，缺任何一条即判不合格。

### ① 尺度参照物（最重要）
画面里**必须有一个能让人反推尺寸的参照物**，否则巨兽与小猫看起来一样大：
- **拇指大的人形剪影**（祭师 / 猎手 / 仰望的旅人，只作剪影、不求面容）——**首选**
- **群飞的鸟**（在神兽身侧如蚊蚋般小）
- **数十米高的祭坛巨柱 / 崖壁 / 青铜神树**（柱身只见中段、柱顶出画，暗示更高）
- **倾覆的巨型兽骨 / 沉没的巨型石像**

> **写法**：在【次要元素·近景】或【次要元素·中景】里明确写出参照物**与神兽的相对大小**
> （例："崖边一名身披麻衣的祭师剪影，高不及神兽前爪，只作逆光小黑点"）。

### ② 低机位广角仰拍
- **视平线压到神兽胸线以下**（甚至齐前爪），机身**向上仰**，让神兽"压向"观众；
- **等效焦距 24mm 及更广**（广角的透视夸张是体量感的物理来源）；**禁用 50mm 以上的中长焦作为主镜**（那是动物肖像的语言）。

### ③ 天光柱（神性来源）
- 云隙间**喷薄的丁达尔光柱**斜扫而下，光柱在翻涌的云气与浮尘中**显形为可见的光锥**；
- 光柱是"神性"的唯一来源 —— 没有天光柱，就只是"阴天拍的野兽"。

### ④ 四层巨物纵深（场面规模）
**至少四层**，层层推远，把画面撑到万丈之外：
```
前景（巨岩 / 残柱中段 / 兽骨，虚化、压住画面下缘）
  → 神兽（主体，占据画面主体）
    → 中景（翻涌云海 / 断裂的巨型祭坛 / 倾颓的石像群）
      → 远景（层叠到天际的洪荒山峦 / 万丈深渊 / 破云的山巅）
```

## 七、易翻车点（写完回查）

1. **画成动物肖像 / 宠物照（头号翻车）** → 【镜头】必须 24mm 广角 + 低机位仰拍（**不要 50mm**）；【风格】保留"非野生动物摄影、非动物肖像"；专属负向的"动物肖像、野生动物摄影、近景特写肖像、中长焦压缩感"必须在。
2. **没有尺度参照物，巨兽变小猫** → 【次要元素·近景】必须有拇指大人形剪影 / 群飞鸟 / 巨柱中段，并**写明相对大小**。
3. **画面发灰、不够华丽（v1 病根）** → 【色彩】用"矿物重彩 + 鎏金"口径，**不再是"低饱和"**；提饱和、提对比，但统一于玄青主调。负向含"画面发灰、褪色、无对比"。
4. **背景空洞、撑不开场面** → 逐条落实**四层纵深**，尤其第 3、4 层（云海、倾颓石像、万丈远山）不能省。
5. **尾巴 / 头 / 角数量画错（本风格最高频、最难修）** → **只写数字没用，必须给空间布局**：
   【主体】写成"以脊线为轴、**左侧四条右侧五条**，相邻两尾**留出可见空隙**，每条尾**自尾根到尖端轮廓完整可辨、互不遮挡**"；
   **删掉一切招致遮挡的措辞**（"遮住半边天""层层叠叠""交错"）；
   **不要把"尾巴数量错误""多头多尾错乱"写进【负向】**——本网关无 negative 通道，那只是普通提示词文本，纯属自我污染；
   **标识色独占（零成本、最有效）**：让尾尖独占朱红，**面部 / 耳内 / 脊线一律玉白霜银**，
   并显式写"九条尾尖是画面中唯一的朱红色元素"——既帮模型，也让 `scripts/count_features.py` 能客观计数；
   **核验用 `scripts/count_features.py`（本地、零成本）**，配 `--roi` 排背景假阳性、`--dump-mask` 目视复核，
   且**阈值须用已知真值的图校准**；
   **成本纪律**：先改提示词（0 成本）→ 本地核验（0 成本）→ 需要新样张时**一次出 1 张**；
   **不要**盲目开 8 张批量 best-of-N（本项目实测 8 张里 0 张是 9 条，纯烧钱）。
   > 实证：原写法尾数糊成一团、数不清（6~8 条）；改空间布局后**尾与尾分离、可逐条点数**，
   > 但**实测仍出现 8 / 9 / 10 条，并不稳定命中 9**。
   > **结论：空间布局解决「可数性」，不解决「计数准确性」——精确计数只能靠 best-of-N + 全分辨率逐条核。**
   > 详见 `references/电影级画面规范.md` 第七节（尾数实验为历史产物，已归档）。
6. **变成西式龙** → 负向含"西式龙、欧美奇幻、龙翼、盔甲"；【风格】保留"东方"。
7. **浅景深把巨物纵深糊掉** → 气派场面用 `f/5.6–f/8`，**不要 f/2.8**；千万级场景要"近处岩、神兽、远处山"都清晰。
8. **血腥越线** → 只写氛围与姿态；负向含"血腥、内脏、伤口特写"。

【次要元素·近景】画面下缘是崩裂的湿黑玄武岩崖顶（表面水膜反光与青苔斑，石缝里插着三根断裂的青铜戈），右下角一名身披麻衣、手持火把的祭师剪影背向镜头仰立，高不及神兽前爪膝部，只作拇指大的逆光小黑点
【次要元素·中景】崖下万丈翻涌的云海，云中探出三根高逾十丈的赭褐色祭坛残柱（柱面有风化的云雷纹浮雕残迹，柱顶出画、无文字），另有一具倾颓的巨型石兽头颅半沉在云里
【次要元素·远景】层叠到天际线的洪荒山峦，山体玄青与赭褐，最高峰破云而出，天际线压至画面上缘五分之一
