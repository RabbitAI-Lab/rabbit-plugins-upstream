# 风格卡 · 蓝调时刻·城市夜行

> **给写提示词的自己**：本卡 ★固定节 的字段必须**逐字照抄**，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `蓝调时刻·城市夜行` |
| **一句话定位** | 日落后 20 分钟的蓝调时刻，冷蓝天光压场、暖霓虹点缀、湿地面反光，人物成剪影 |
| **媒介本质** | 全画幅电影镜头实拍的**蓝调时刻**外景照片；非深夜黑场、非白昼、非赛博调色 |
| **与最近似风格的区别** | 与「赛博霓虹」（33）不同：**有真实的天光层次与自然渐变的天空**，不是纯夜色霓虹；与「Y2K 直闪」（58）不同：**无直闪硬光、无人物面部打光**；与「复古胶片夜景」不同：**冷蓝主调、无暖黄** |
| **电影级从哪来** | ① 天空作为巨型柔光源、主体靠轮廓光成型 ② 冷暖对撞（冷蓝天光 × 暖霓虹） ③ 湿地面镜面反射延展纵深 ④ 剪影留白与画外暗示 |

## 二、★固定节（逐字照抄）

```
【光影】日落后约 20 分钟的蓝调时刻：天空为均匀的冷蓝天光作唯一环境主光，无太阳直射、无硬阴影；城市霓虹、车灯、橱窗灯为少量暖色点光源，形成冷暖对撞；人物多为逆光剪影或侧逆光轮廓，面部细节保留约两成；地面湿滑，反射出成条的灯带
【色彩】深靛蓝（#1B2A4A）与青蓝（#3E6A8F）的天空占 40–60%，冷灰蓝的街道占 25%，暖橙（#FF9A4D）与品红（#E0538C）的霓虹合计 ≤15%，肤色偏冷；整体中低饱和，霓虹处高饱和但不溢出
【影像质感】全画幅电影镜头实拍：高光滚降柔和、轻微光晕与眩光横向拉丝、细密胶片颗粒、暗部保留细节不堵死；雨后空气通透、远景带轻微空气透视
【背景】城市街道、过街天桥、十字路口、便利店外的霓虹招牌带、写字楼玻璃幕墙，招牌与文字全部虚化成光斑
【风格】蓝调时刻电影感城市夜景，冷蓝天光与暖霓虹点光，湿地面反光与剪影构图，当代都市夜行氛围；非白天、非纯黑夜、非赛博紫绿
【画幅】{16:9}
```

**★固定节填写要求**：
- 命门词「**日落后 20 分钟均匀冷蓝天光**」「**暖霓虹点光 ≤15%**」「**湿地面成条反光**」「**剪影/侧逆光**」逐字不动。
- 色号面积比与「无太阳直射」不许改；只允许替换街道场景与人物动作。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：人物的年龄段与虚构身份、发型轮廓（被逆光勾出毛边）、外套材质与长度、裤型与鞋、背包/雨伞/耳机等随身物、姿态（驻足/回望/走过斑马线/扶栏杆）、与光源的相对位置、轮廓光落在哪一侧。一律「虚构人物（无原型）」。 |
| 【次要元素·近/中/远】 | 近：湿漉的护栏/斑马线/水洼倒影；中：主体与路灯柱；远：虚化的霓虹光斑、玻璃幕墙、车流灯带。空层写「无」。 |
| 【全局】 | 雨后空气的水汽、镜头轻微眩光、远处车灯拉出的横向光带。 |
| 【构图】 | 16:9 宽银幕，主体偏三分线（约 1/3 或 2/3），天空占上方 40%，街道透视线向画面深处收；留白给光斑。**不写焦距/景深**。 |
| 【镜头】 | 等效 35mm 或 50mm、f/2.0–f/2.8、浅至中景深、主体成剪影仍可辨轮廓、远景霓虹虚化成光斑。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|
| 街拍 / 氛围片 | `16:9` 横 | `1536x1024` | 主体偏一侧，天空与街道双向留白 |
| 竖屏短视频首帧 | `9:16` 竖 | `1024x1536` | 主体居中偏下，上方天空与霓虹光斑 |

## 六、易翻车点（写完回查）

1. **画成纯黑夜/赛博** → 固定节必须写清「均匀冷蓝天光 + 有层次的天空」，负向含「纯黑夜空、赛博朋克紫绿」。
2. **人物脸被打亮变棚拍** → 【光影】写「逆光剪影、面部保留两成」，负向含「机顶直闪、影棚布光」。
3. **霓虹抢过天空** → 【色彩】限「霓虹 ≤15%」。
4. **出现真实招牌文字** → 【背景】写「招牌全部虚化成光斑」，负向含「门店文字、广告屏文字」。
5. **暗部糊死** → 负向含「暗部死黑、噪点糊成一片」，质感节强调「暗部保留细节」。
