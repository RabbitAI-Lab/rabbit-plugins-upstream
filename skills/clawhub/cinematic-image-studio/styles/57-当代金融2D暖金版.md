# 风格卡 · 当代金融2D·暖金版

> **给写提示词的自己**：本卡标 ★固定节 的字段**必须逐字照抄**，不许改写。
> **与 56 的区别**：56 是冷白中性；本卡是**暖金晨光 + 深蓝**，但**年代仍是 2026**，不做怀旧泛黄。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `当代金融2D·暖金版` |
| **一句话定位** | 2026 年的清晨，金色侧光落在玻璃幕墙上，天空是深蓝的，人很克制 |
| **媒介本质** | 二维动画质感（细腻描线 + 干净平涂）+ **纪实构图**（真实机位、不摆拍、不广告感） |
| **年代基准** | **2026 当代**：超薄全面屏、玻璃幕墙、阳极铝、自动化设备、新建社区；**不出现任何旧年代道具** |
| **色调骨架** | **暖金晨光 + 深蓝基底 + 一处极淡品牌红**（红只做点缀，不铺面） |

## 二、★固定节（逐字照抄）

```
【光影】清晨的暖金侧光作单一主光（日出方向可解释：斜射入窗/打在幕墙上/穿过楼间），光比明确但暗部保留细节；背景浅景深柔化；金色只落在受光面，阴影侧保持干净的深蓝；不用暗角、不用浓雾、不用大爆闪
【色彩】深蓝与暖白为基底，受光面呈暖金色，阴影侧偏冷蓝；只在画面里保留一处极淡的品牌红作为点缀（面积不超过画面的百分之三）；低饱和、克制、不要高饱和荧光色
【影像质感】二维动画质感：手绘感细腻描线配干净平涂，色块边界清楚，表面干净、没有胶片颗粒与脏噪；构图是纪实摄影的机位语言（真实视角、不摆拍、不做广告式仰拍），不是广告海报
【背景】2026 年的当代场景（金融区玻璃幕墙/开放式投研区/客户洽谈区/自动化码头与产线/新建社区/当代住宅客厅），前景中景至少两层纵深；环境比主体低一档亮；无可读文字
【风格】当代金融2D·暖金版：二维动画质感配纪实构图，清晨暖金侧光与深蓝阴影，中性克制的高明度色调，一处极淡品牌红点缀；场景、设备与人物造型一律为 2026 年当代形态，不使用任何怀旧或旧年代元素；人物为虚构原创形象，不影射任何真实人物；画面传达稳健、专业、长期、信任、同行；不模仿任何现有影视作品或角色
【画幅】3:4
```

## 六、易翻车点

1. **出炫富/暴富符号** → 负向必含「金币、金条、暴涨K线、收益数字、奢侈品」
2. **出怀旧泛黄** → 正向锁「2026 当代」，负向含「泛黄、九十年代、胶片颗粒」
3. **红铺满画面** → 正向锁「一处极淡品牌红，面积不超过百分之三」
4. **广告摆拍感** → 正向锁「纪实构图、不摆拍」，负向含「摆拍感、广告感」
5. **画面有字** → 负向含「英文文字、字幕、水印、标志」，主体里写明纸张屏幕一律无字
