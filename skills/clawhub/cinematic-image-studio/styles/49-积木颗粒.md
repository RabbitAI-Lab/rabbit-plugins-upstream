# 风格卡 · 积木颗粒（拼搭玩具砖 · 颗粒凹凸 · 微缩玩具摄影）

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `积木颗粒` |
| **一句话定位** | 像用拼搭积木砖搭出的天庭——颗粒凹凸、整齐几何、微缩玩具摄影 |
| **媒介本质** | 拼搭积木（ABS 颗粒砖 + 圆柱凸点 + 拼缝）；**非**3D渲染、**非**绘画、**非**写实照片 |
| **与最近似风格的区别** | 与「09 Q版公牛」（搪胶手办）不同：本档由**几何颗粒砖拼搭**、表面有**圆柱凸点与拼缝**、方正造型；与3D不同：本档是**真实玩具的微缩摄影**质感。 |
| **玩具感从哪来** | ① 圆柱凸点与拼缝 ② 方正几何造型 ③ 标准砖的饱和色 ④ 玩具摄影布光 |

## 二、★固定节（逐字照抄）

```
【光影】玩具摄影布光：柔和主光 + 环境补光，颗粒上出现塑料微高光与回合短影；暖白或白棚光；暗部保留细节
【色彩】积木颗粒的饱和纯色：红、黄、蓝、绿、白、灰等标准砖色；背景为纯色台面或白棚；干净明快
【影像质感】拼搭积木质感：颗粒的圆柱凸点（stud）+ 圆角 + 塑料微光、砖块拼接的缝、颗粒整齐排列；真实玩具微缩摄影；非3D渲染、非绘画、非照片写实真人
【背景】积木拼的天宫：以积木砖拼出宫阙柱、云、台阶，颗粒清晰；纯色台面；无可读文字
【风格】积木颗粒玩具微缩：拼搭砖颗粒凹凸、塑料微光、整齐几何、玩具摄影；非3D、非绘画、非写实照片
【画幅】16:9
```

**★固定节填写要求**：命门词「**拼搭积木颗粒 + 圆柱凸点 + 拼缝**」「**方正几何造型**」「**玩具摄影布光**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 积木拼搭的主仙（虚构，由圆角积木砖拼成、可见圆柱凸点、宽袖长裙以砖块叠出、居中略大、姿态起舞）；群仙积木小偶分列；末尾「是画面唯一视觉主体」 |
| 【次要元素·近/中/远】 | 近：积木小物件/积木云；中：积木群仙与积木宫柱；远：积木台阶与云；空层写「无」 |
| 【全局】 | 少量积木小零件/浮尘 —— 与玩具摄影自洽 |
| 【构图】 | 主仙居中、群偶环绕；微缩台面收边；**不写焦距/景深** |
| 【镜头】 | 中景，微缩浅景深 f/5.6 |

## 六、易翻车点（写完回查）

1. **颗粒不清/非拼搭** → 负向含「颗粒糊掉、非拼搭、光滑无颗粒」；【影像质感】写「圆柱凸点 + 拼缝 + 整齐排列」。
2. **变3D/塑料光滑** → 负向含「3D渲染、CG光滑塑料」；【影像质感】写「真实玩具微缩摄影、塑料微光」。
3. **变写实真人** → 负向含「照片写实真人、写实人脸」；【主体】写「圆角积木砖拼成」。
4. **糊成一团/脏色** → 负向含「脏色、糊成一团」；【色彩】写「饱和纯色、颗粒分明」。
