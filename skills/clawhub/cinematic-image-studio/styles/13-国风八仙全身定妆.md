# 风格卡 · 国风八仙全身定妆

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `国风八仙全身定妆` |
| **一句话定位** | 素净布衣仙家立在放大渡海法器上，背后升起自身同貌同形的金色升华法相 |
| **媒介本质** | 国风写实渲染（写真感）；**非**佛像/宗教造像、**非**卡通 |

## 二、★固定节（逐字照抄）

```
【光影】柔和顶光与背后神光交叠，沿肩袖与裙裾勾出一圈浅金边缘光；通体明亮、光比柔和；色温暖金
【色彩】纯白为底向碧海铺开；素净布衣（粗布/朴素拼缝/旧布带，浅暖或浅彩）× 辉煌金身（赤金与暖白交映）；一素一华、强对比；防发灰（主体与纯白底须有明度分离）
【影像质感】写真感国风渲染：鎏金流光、柔润丝缎与柔金微光、鎏金披帛、海雾与金光凝成厚重有实体感、半实半透的身形；景深铁律：主体最实最亮轮廓最锐，升华法相高度相近而略虚，碧海仙山宫阙最虚
【背景】纯白起底 → 八仙过海式宏大仙家海景：碧海波涛翻涌、浪花轻卷、霞气弥散、水光粼粼；两侧淡青仙山与远处蓬莱宫阙楼台化作极淡层叠剪影
【风格】国风仙家系列全身定妆像：主体自身的升华之相，同貌同形、高度相近、非佛像、温柔慈柔、只托一件同源法器；素净布衣 × 辉煌金身、一素一华、法器托身、渡海；不引入其它风格
【画幅】9:16   ← 本卡固定竖幅
```

**★固定节填写要求**：命门词「**法相＝主体自身的升华之相、同貌同形、非佛像、只托一件**」「**一素一华**」「**景深铁律**」逐字不动。凝形介质一律「海雾 + 金光」，**不混云气/云海**。

## 六、易翻车点（写完回查）

1. **法相画成佛像** → 负向含「佛像、宗教造像、莲花座、肉髻」，固定节锁定「主体自身升华之相」。
2. **灰白融底** → 负向含「灰调、退色、低对比」，【色彩】锁定明度分离。
3. **题名乱码/多字** → 【题名】写确切「{仙名}」三字，负向含「文字错误、乱码、错字、重复文字」。
4. **堆特效成额外物件** → 【主体所需的主体】不写花心能量/旋转光华/雷光。
