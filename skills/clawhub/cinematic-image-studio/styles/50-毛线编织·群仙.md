# 风格卡 · 毛线编织·群仙（针织线圈 · 针脚成行 · 毛线纤维）

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `毛线编织·群仙` |
| **一句话定位** | 像一幅毛线针织/钩织作品——线圈针脚里织出的天庭群仙 |
| **媒介本质** | 毛线编织（针织/钩织：线圈针脚、辫子纹、钩织花边）；**非**羊毛毡、**非**3D、**非**照片 |
| **与最近似风格的区别** | 与「46 羊毛毡玩偶」不同：毡是**戳制绒毛、表面不匀**；本档是**编织的线圈针脚成行成列、辫子纹（上下针）起伏、起球毛绒**，结构和纹理完全不同。与3D不同：有**手工编织的针脚不完美**。 |
| **暖系从哪来** | ① 线圈针脚的行列纹理 ② 辫子纹起伏 ③ 毛线纤维毛绒与起球 ④ 柔和居家暖光 |

## 二、★固定节（逐字照抄）

```
【光影】柔和均匀的居家/棚拍暖光、无明显硬影；毛线的纤维绒毛与线圈凹凸产生细腻明暗；针脚脊线有柔和高光；整体暖调、温润
【色彩】毛线的柔和彩色：奶油白、姜黄、砖红、草绿、藏青、灰粉等柔色；背景为纯色毛线织面、明度低于主体；干净温暖
【影像质感】毛线针织/钩织质感：线圈针脚成行成列、辫子纹（上下针）起伏、毛线纤维的毛绒与轻微起球、钩织花边；非羊毛毡、非3D渲染、非塑料、非照片写实
【背景】毛线织的天宫：以毛线织出云朵、柱子、台阶，线圈清晰；纯色毛线织底；无可读文字
【风格】毛线编织（针织/钩织）玩偶兼织片：线圈针脚成行、辫子纹起伏、毛线纤维毛绒、手工温润；非羊毛毡、非3D、非塑料、非照片
【画幅】16:9
```

**★固定节填写要求**：命门词「**针织线圈针脚成行成列 + 辫子纹起伏**」「**毛线纤维毛绒与起球**」「**非羊毛毡**」逐字不动。

## 六、易翻车点（写完回查）

1. **变羊毛毡** → 负向含「羊毛毡、戳制绒毛」；【影像质感】写「线圈针脚成行、辫子纹起伏」。
2. **针脚糊掉/无纹理** → 负向含「针脚糊掉、平面无纹理」；【光影】写「线圈凹凸的细腻明暗」。
3. **变塑料/3D** → 负向含「3D渲染、CG光滑塑料、树脂」；【影像质感】写「毛线纤维毛绒与起球」。
4. **变写实真人** → 负向含「照片写实、写实人脸、写实毛发」；【主体】写「通体由毛线线圈织成、辫子纹」。
