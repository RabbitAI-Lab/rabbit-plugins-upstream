# 风格卡 · 扁平化科技金融商业插画

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `扁平化科技金融商业插画` |
| **一句话定位** | 带干净克制数字未来主义科技感的扁平化科技金融商业插画 |
| **媒介本质** | 扁平矢量插画（纯色块 + 几何图形 + 细线描边）；**非**写实照片、**非**厚重 3D、**非**厚涂油画 |
| **与最近似风格的区别** | 与「写实科技感 / 赛博朋克霓虹」不同：本风格**扁平、干净、克制**，霓虹只作点缀不做满屏大乱闪；与「日式动漫」不同：**无赛璐璐大眼与描边动画感** |
| **电影级从哪来** | ① 主体巨大、占视觉中心 ② 信息图式分区与留白 ③ 青色发光线条引导视线 ④ 深蓝底 + 高对焦点缀色 |

## 二、★固定节（逐字照抄）

```
【光影】扁平化色块分区光影：以纯色块的明度差与几何分区表达体积，弱对比；青色发光线条与柔和体积辉光作高光；无写实投影、无硬边阴影；色温偏冷
【色彩】深蓝科技底（#0A1A2F / #0D1B2A）≥50%、电光青（#00E5FF / #2DD4BF）20–30%、紫／品红（#7C3AED / #E040FB）10–15%、暖金（#F5C451）≤8%、白／浅灰（#F8FAFC / #94A3B8）点缀；扁平少渐变
【影像质感】扁平矢量插画：纯色块 + 几何图形 + 纤细发光描边；数据流粒子、全息网格底纹、扫描光线；无照片质感、无厚重3D、无脏旧纹理、无渐变糊感
【背景】抽象化科技场景（数据中台／全息仪表盘／网络拓扑／城市天际线剪影），几何化、简洁，亮度永远低于主体；无文字
【风格】扁平化科技金融商业插画，带干净克制的数字未来主义科技感；矢量感纯色块与几何造型，主体大、占据画面视觉中心，干净专业克制；非写实照片、非厚重3D、非脏旧
【画幅】{16:9 或 9:16}   ← 只此两种
```

**★固定节填写要求**：
- 命门词「**扁平矢量纯色块 + 几何造型**」「**主体大、占据画面视觉中心**」「**深蓝科技底 + 青色发光**」逐字不动。
- `{画幅}` 每图换；主光方位可换（顶部辉光 / 中心辐散），但「扁平化色块分区、无写实投影」内核保留。

```
写实照片感、真实人脸、写实皮肤、厚涂、油画、平涂糊感、3D 塑料感、亮面树脂、脏旧纹理、噪点、

```

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：事物/二次元几何人物/场景 + 确切名 + 形状材质 + 颜色 + 姿态朝向。人物与主题强相关（金融→分析师/投资者；医药→科研/医生）。真实人物面孔禁止。 |
| 【次要元素·近/中/远】 | 近：数据小图标/几何前景；中：次要节点；远：城天际线剪影/网格。空层写「无」。 |
| 【全局】 | 数据流粒子 / 全息网格底纹 / 扫描光线 —— 与扁平无景深自洽。 |
| 【构图】 | 主体大、居中或三分；轴对称或斜向动势；信息图式分区；留白充足。**不写焦距/景深**。 |
| 【镜头】 | 扁平插画**无景深**：写「平视角 / 等距视角 / 正视角」，不写光圈。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|
| 横版 B-roll / 信息图 / 封面 | `16:9` 横 | `1536x1024` | 主体巨大居中，两侧留信息图分区 |
| 竖屏短视频 | `9:16` 竖 | `1024x1536` | 主体占中上部，底部留分区 |

## 六、易翻车点（写完回查）

1. **画成写实/3D/厚涂** → 检查【影像质感】「扁平矢量纯色块」与专属负向是否都在。
2. **主体过小、元素碎散** → 【构图】强制「主体大、占据视觉中心」，负向加「主体过小、元素堆满」。
3. **出现英文/乱码** → 【背景】写「无文字」，负向含「英文/字母/乱码」。
4. **霓虹过曝、脏乱** → 负向加「赛博朋克霓虹大乱闪、霓虹过曝」，色彩保持面积比。
5. **渐变糊感** → 【影像质感】写「扁平少渐变」，负向加「渐变糊感」。
