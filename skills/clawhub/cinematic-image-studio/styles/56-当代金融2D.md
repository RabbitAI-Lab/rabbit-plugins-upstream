# 风格卡 · 当代金融2D（2026）

> **给写提示词的自己**：本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。
> **本卡的存在理由**：`55-真实电影2D韩版` 的「色温偏暖 + 胶片颗粒 + 奶油调」会把画面拉成怀旧/黄昏年代感；本卡把这些全部换掉。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `当代金融2D` |
| **一句话定位** | 拍在 2026 年的二维动画：冷白清晨、玻璃与铝、干净到没有一粒灰的年代感 |
| **媒介本质** | 二维动画电影质感（细腻描线 + 干净平涂）；**非**真人摄影、**非**三维渲染 |
| **年代基准** | **2026 当代**：超薄全面屏、玻璃隔断、阳极铝、浅灰石材、自动化码头、无尘产线、新建社区 |
| **明暗基调** | 冷白清晨、高调明亮；暗部抬亮、无暗角、无泛黄 |
| **与 55 的区别** | 55 是「暖调柔光 + 胶片颗粒」；本卡是「冷白中性 + 数码级干净」。同一题材，年代感完全不同 |

## 二、★固定节（逐字照抄）

```
【光影】清晨七点到九点的冷白中性天光作单一主光（落地窗日光/天窗天光/幕墙反射光，光源在画面内可解释）；整体高调明亮，暗部抬亮保留细节；浅景深轻微柔化背景；光线干净通透，没有暖橘夕照、没有暗角、没有浓重体积光
【色彩】中性偏冷的当代色调：浅灰、冷白、雾蓝为基底，玻璃反青、金属反冷白；点缀只用一处极淡的暖色；低饱和、高明度、色温统一偏冷；不要泛黄、不要褐调、不要奶油暖调
【影像质感】二维动画电影质感：手绘感细腻描线配干净平涂，色块边界清楚、表面干净；数码级清晰、没有胶片颗粒、没有脏噪、没有褪色感；人物与场景均为 2026 年的当代形态
【背景】2026 年的当代空间（玻璃幕墙写字楼/超薄全面屏工位/玻璃门资料室/自动化码头/无尘自动化产线/新建社区/当代家居），前景中景至少两层纵深；环境与主体同亮或更亮；无可读文字
【风格】当代金融2D：二维动画电影质感，手绘感细腻描线配干净平涂，清晨冷白中性天光，浅景深，中性偏冷的高明度色调，真实人体比例与克制微表情；场景、设备与人物造型一律为 2026 年当代形态，不使用任何怀旧或旧年代元素；人物为虚构原创形象，不影射任何真实人物；不模仿任何现有影视作品、角色或画风
【画幅】3:4
```

**★固定节填写要求**：命门词「**清晨冷白中性天光**」「**2026 年当代形态**」「**数码级清晰、没有胶片颗粒**」「**中性偏冷的高明度色调**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |

| 【主体】 | 当代物件与场所：超薄全面屏、玻璃隔断、阳极铝型材、浅灰石材台面、自动化设备；人物 7 头身、当代素色穿着 |
| 【次要元素·近/中/远】 | 前景（玻璃边/铝型材/台面）→ 中景主体 → 远层明亮空间；空层写「无」 |

| 【镜头】 | 景别 + 角度 + 焦点 + 背景轻微柔化 |

## 六、易翻车点（写完回查）

1. **出怀旧/黄昏** → 正向锁「清晨冷白中性天光」，负向必含「泛黄、暖橘夕照、胶片颗粒、复古」。
2. **设备过时** → 负向必含「厚边框显示器、CRT、机箱塔式电脑、灰色办公隔断」。
3. **旧工业感** → 负向必含「旧厂房、旧砖墙、工业遗址、老式吊机」。
4. **变回照片/3D** → 负向必含「照片质感、3D 渲染」。
5. **画面有字** → 负向必含「英文文字、字幕、水印、标志」，且【主体】里写明纸张/屏幕一律无字。
