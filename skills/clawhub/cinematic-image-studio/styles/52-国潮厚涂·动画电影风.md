# 风格卡 · 国潮厚涂·动画电影风

> **给写提示词的自己**：本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `国潮厚涂·动画电影风` |
| **一句话定位** | 一眼是"国潮厚涂"——看得见笔触的颜料块面，却像动画电影的分镜一样打光、造景、讲故事 |
| **媒介本质** | **数字厚涂绘画**（可见笔触 + 颜料堆叠 + 块面塑造）；**非**三维渲染、**非**平涂赛璐璐、**非**照片写实、**非**水墨洇染 |
| **与最近似风格的区别** | 与「日系赛璐璐动画」不同：本档**厚涂块面**（笔触可见、形体靠色块塑造），不是均匀描线 + 平涂 + 硬边二分阴影；与「东方奇幻·3D新国风」不同：本档是**二维绘画**，不是 PBR 3D 渲染；与「彩色水墨 / 重彩水墨」不同：本档是**油画/丙烯般的厚涂块面**，不是水墨洇染与飞白；与「油画画布写实」不同：本档是**动画电影式夸张造型与打光**，不是写实肖像 |
| **电影级从哪来** | ① 单一主光、方向明确、光比强烈 ② 彩色轮廓光把主体从背景里拉出来 ③ 体积光/丁达尔光柱 + 大气透视层层退远 ④ 高饱和重彩与统一调色 |

## 二、★固定节（逐字照抄）

```
【光影】动画电影级打光：单一主光、方向明确、光比强烈，光源在画面内可解释；主体背光侧以一道彩色轮廓光勾出边缘、与背景分离；体积光/丁达尔光柱穿过云气或火星显形；大气透视随纵深渐次转淡；高光落在厚涂块面之上，形成明确的亮暗二分与暖冷分区
【色彩】国潮高饱和重彩：以朱红、丹霞橙与鎏金为主调、以石青与夜蓝作冷调对冲；点缀月白与玄黑；色彩浓郁厚重、明快不脏、冷暖分区清楚；强调色集中、不超过三种
【影像质感】数字厚涂绘画：可见的厚涂笔触、颜料堆叠与刮刀痕；块面塑造形体、湿笔边缘自然交融；画面带油画/丙烯般的颜料肌理与亚麻画布纹理；动画电影级的合成与大气透视
【背景】国潮东方场景（山海/宫阙/云海/古建/自然奇景），纵深至少四层（前景→主体→中景→远景），大气透视层层退远；亮度永远低于主体；无可读文字
【风格】国潮厚涂 · 动画电影风：东方国潮题材 + 数字厚涂绘制，可见厚涂笔触与颜料堆叠；动画电影级的构图、打光与大气透视；高饱和国风重彩、朱红石青冷暖对冲、鎏金点缀；非三维渲染、非平涂赛璐璐、非照片写实、非水墨洇染、非矢量扁平
【画幅】{16:9 或 9:16}   ← 只此两种
```

**★固定节填写要求**：
- 命门词「**数字厚涂绘画（可见笔触/颜料堆叠/刮刀痕，块面塑造形体）**」「**动画电影级打光（单主光 + 彩色轮廓光 + 体积光 + 大气透视）**」「**朱红石青冷暖对冲的国潮重彩**」逐字不动。
- 主光**方位**每图可换（顺光/侧光/侧逆光/逆光皆可），但「单一主光、方向明确、光比强烈」的内核必须保留；轮廓光的**颜色**可随主调微调（暖调场景用青蓝轮廓光，冷调场景用暖金轮廓光）。
- 【背景】的**层数**是本卡唯一允许上浮的地方：想场面更大，可把「纵深至少四层」按需扩写为「五层/六层」。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：本风格下主体要写**发丝以粗犷笔触成束、服饰纹样、甲胄/器物的材质与鎏金高光、肤色、瞳色、姿态朝向、神态**；造型可动画电影式夸张（飘带弧线延长、动势饱满）；**末尾必须写「是画面唯一视觉主体」+ 位置/朝向**。不写写实皮肤毛孔。 |
| 【次要元素·近/中/远】 | 近：厚涂笔触粗犷的前景框（火岩/云浪/草木/残戟），虚化处理；中：主体身后的山崖/宫墙/云海/器物（笔触概括、退后一层）；远：层叠远山/巨构/天光，没入霞雾；空层写「无」。 |
| 【全局】 | 满屏介质写**火星/灰烬/雨丝/云气/浮尘/光尘/花瓣**之一二 —— **与【镜头】景深自洽**。 |
| 【构图】 | 机位高低 + 主体站位（三分/中轴/对角线）+ 多层纵深 + 留白位置与占比。**不写焦距/景深**。 |
| 【镜头】 | 动画电影式镜头语言：中景偏中近景用 **35mm + f/5.6**（主体清晰、背景适度虚化）；大场面用 **24mm 广角 + f/5.6**；特写用 **50mm + f/2.8**。 |

## 六、易翻车点（写完回查）

1. **画成 3D/CG 渲染** → 负向含「三维渲染、3D建模、CG塑料感、默认材质、无贴图模型」；【影像质感】写死「可见厚涂笔触、颜料堆叠与刮刀痕」。
2. **画成平涂赛璐璐/日系动画** → 负向含「平涂、赛璐璐、均匀描线、硬边二分阴影块、线条勾边」；【风格】写「非平涂赛璐璐」。
3. **笔触糊成一团、形体丢了** → 【影像质感】写「块面塑造形体、湿笔边缘自然交融」；负向含「笔触糊成一团、色块粘连、形体外轮廓不清」。
4. **掉回水墨/彩墨洇染** → 负向含「水墨洇染、宣纸飞白、墨分五色、工笔白描」；【风格】写「非水墨洇染」。
5. **色彩发灰发脏** → 【色彩】写「高饱和、浓郁厚重、明快不脏」；负向含「低饱和灰调、脏色、浑浊、褪色」。
6. **出英文/水印** → 负向含「英文文字、拉丁字母、拼音、水印、标志、字幕」。
