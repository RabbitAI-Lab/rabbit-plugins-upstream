# 风格卡 · 沙画（沙粒堆抹 · 背光透亮 · 单色暖调）

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `沙画` |
| **一句话定位** | 像一张背光沙台上的沙画——沙的厚薄透出明暗，群仙在光里起舞 |
| **媒介本质** | 沙画（背光沙台：细沙堆抹 + 漏沙成线 + 手指/工具作画）；**非**绘画、**非**3D、**非**照片 |
| **与最近似风格的区别** | 与「彩墨/水墨」不同：本档是**沙粒堆抹**、单色暖调、背光明暗；与黑白摄影不同：有**沙的颗粒与漏沙线**。 |
| **光影从哪来** | ① 背光沙台 ② 沙厚则暗、沙薄则透亮 ③ 漏沙成线 ④ 高反差单色 |

## 二、★固定节（逐字照抄）

```
【光影】背光沙台：光从下方沙台透过，沙的厚薄决定明暗（沙厚则暗、沙薄则透亮）；发光的沙台光；高反差
【色彩】单色暖沙：暖褐或金褐的沙，在背光下呈明暗层次；可极少量彩沙点缀；整体单色暖调、通透高反差
【影像质感】沙画质感：沙粒的颗粒与堆积、手指/工具抹出的笔触与漏沙线条、背光透亮的层次、沙台边缘的散沙；非绘画、非3D、非塑料、非照片
【背景】沙画天宫：以沙的厚薄抹出云海、宫阙、群仙剪影、背光透亮；无可读文字
【风格】背光沙画：沙粒堆抹、漏沙成线、背光明暗层次、单色暖调；非绘画、非3D、非照片
【画幅】16:9
```

**★固定节填写要求**：命门词「**背光沙台：沙厚则暗、沙薄则透亮**」「**沙粒堆抹 + 漏沙成线**」「**单色暖调高反差**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 主仙（虚构，以沙堆/漏沙线抹出，居中略大、姿态起舞、背光透亮）；群仙以沙剪影分列；末尾「是画面唯一视觉主体」 |
| 【次要元素·近/中/远】 | 近：沙台边缘的散沙与漏沙线；中：群仙沙影与沙抹宫柱；远：沙抹云海渐暗；空层写「无」 |
| 【全局】 | 少量飞扬的沙尘 —— 与背光自洽 |
| 【构图】 | 主仙居中、群仙环绕；沙台式满构图；**不写焦距/景深** |
| 【镜头】 | 俯视沙台或正视，平面沙台感，无强烈景深 |

## 六、易翻车点（写完回查）

1. **变绘画** → 负向含「绘画颜料、油画、水彩、彩墨、笔触堆叠」；【影像质感】锁「沙粒堆抹、漏沙线」。
2. **加太多彩/荧光** → 负向含「彩色斑斓、荧光色」；【色彩】锁「单色暖沙」。
3. **沙糊成一团** → 负向含「沙糊成一团、糊」；【光影】写「沙厚薄分明暗」。
4. **变照片/3D** → 负向含「照片写实、3D渲染」；【影像质感】写「沙粒颗粒与散沙」。
