# 风格卡 · 重彩水墨（打斗）

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `重彩水墨（打斗）` |
| **一句话定位** | 像一幅现代重彩彩墨长卷在眼前泼开、又以电影级镜头收束 |
| **媒介本质** | 现代重彩彩墨写意（宣纸肌理 + 矿物重彩大块浓泼）；**非**水墨单色、**非**3D/写实 |
| **与最近似风格的区别** | 与「彩色水墨·新中式」不同：本档**重彩浓艳、色压过墨、泼彩动势、电影级纵深**；与新中式不同：不安静留白、浓烈爆发 |
| **电影级从哪来** | ① 浓艳重彩与冷暖拉开前中后景深 ② 大气透视推远山海 ③ 视觉焦点处重彩聚光 ④ 细腻胶片颗粒与暗角 |

## 二、★固定节（逐字照抄）

```
【光影】一切光影皆为彩墨晕染的图案化呈现（非物理体积光）；视觉焦点处重彩聚光；暗部以同色系重彩压重而非浓墨；亮部重彩饱和爆色；覆细腻胶片颗粒与轻微暗角
【色彩】以重彩为绝对主调、浓艳夺目：朱砂红、石青蓝、石绿、藤黄、胭脂等矿物重彩大块浓泼、层层叠加、渗化交融；色彩饱和拉满、鲜艳明亮、色压过墨；仅极少量留白透气
【影像质感】现代重彩彩墨写意：宣纸生涩肌理上，矿物重彩大块浓泼、层层叠加、渗化交融；墨色只作轻辅（细线勾形、飞白与极少量点醒），不走大块浓墨、不以墨压彩；人物写意笔线勾形，衣发随动势拉出飞白与彩丝；笔触可见、彩墨流动、泼彩动势与呼吸感
【背景】宽银幕构图，以浓艳重彩与冷暖拉开前中后景深，大气透视推远山海；无可读文字、题款/印章文字
【风格】整幅画面的画风严格与「彩色水墨（重彩轻墨）」一致：现代重彩彩墨写意，以重彩为绝对主调、浓艳夺目；墨色只作轻辅，不以墨压彩、墨色不主导画面；追求泼彩动势与呼吸感，兼具电影级纵深，不用西式明暗造型与强投影
【画幅】16:9   ← 本卡默认宽银幕
```

**★固定节填写要求**：命门词「**重彩浓艳、色压过墨**」「**墨色只作轻辅（无大块浓墨）**」「**一切光影皆彩墨晕染、非物理体积光**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 人物写意笔线勾形、衣发随动势拉出飞白与彩丝；拳脚/兵刃化作重彩团块炸裂、彩雾弥散、水痕迸溅；有来有回。 |
| 【次要元素·近/中/远】 | 前中后景以浓艳重彩与冷暖拉开景深；空层写「无」。 |
| 【全局】 | 彩雾/彩丝/水痕/飞白迸溅。 |
| 【构图】 | 宽银幕、视觉焦点重彩聚光。**不写焦距/景深**。 |
| 【镜头】 | 电影级镜头语言；动势。 |

## 六、易翻车点（写完回查）

1. **画成水墨单色/以墨压彩** → 负向含「大面积浓墨、以墨压彩、水墨单色主导」。
2. **灰暗褪色寡淡** → 负向含「灰暗、褪色、低饱和灰调、色彩寡淡」。
3. **物理体积光/强投影** → 负向含「真实光照、体积光、强投影」，锁定「彩墨晕染图案化」。
4. **出文字** → 负向含「英文文字、题款文字、印章文字」。
