# 风格卡 · 粗野主义·建筑光影

> **给写提示词的自己**：本卡 ★固定节 的字段必须**逐字照抄**，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `粗野主义·建筑光影` |
| **一句话定位** | 清水混凝土的巨型几何 + 一道硬光切线，安静、冷峻、无人的建筑空间 |
| **媒介本质** | **建筑摄影**（真实混凝土结构的自然光拍摄），非 3D 场景、非插画 |
| **与最近似风格的区别** | 与「奶油极简」（62）不同：**冷灰混凝土、体量巨大、无软装**；与「蓝调夜行」（63）不同：**白天硬光、无人**；与「黑白影棚」（11）不同：**有材料的暖灰与天空的蓝** |
| **电影级从哪来** | ① 一道锐利的光切线把体量切成明暗两半 ② 极端透视带来压迫与秩序 ③ 混凝土的模板缝、气孔与泛碱痕迹提供物质感 ④ 完全无人的空场制造叙事悬念 |

## 二、★固定节（逐字照抄）

```
【光影】单一硬质日光：太阳以 30–45° 侧向射入，在混凝土表面切出一道锐利的光影分界（边界清晰、过渡仅 2–5cm），受光面为暖白、背光面为冷灰并保留模板细节；不补光、不反光板，阴影处只有天空的漫反射；整体光比约 1:4
【色彩】极克制的冷灰体系：混凝土浅灰（#B8B6B1）、中灰（#8C8A86）、阴影冷灰（#4C5054）、天空的浅蓝（#A9C0D4）；唯一暖色来源是日照下的混凝土暖白（#DCD6CB）；饱和度极低、明度层次丰富
【影像质感】大画幅建筑摄影：线条笔直无畸变、混凝土表面可见模板拼缝、圆形气孔、泛碱白痕与轻微雨痕；锐利到边缘、极细颗粒、暗部层次干净；非 3D 渲染、非插画、非手机广角畸变
【背景】天空占画面一部分，为干净的浅蓝或薄云；周边只有同类的混凝土体量、无装饰构件、无绿植堆叠
【风格】粗野主义（Brutalism）建筑摄影，清水混凝土巨型几何与单一硬光切线，无人空场与冷灰影调；非 3D 场景、非插画、非豪华精装空间
【画幅】{16:9}
```

**★固定节填写要求**：
- 命门词「**清水混凝土模板缝与气孔**」「**一道 2–5cm 过渡的硬光切线**」「**无人空场**」「**冷灰 + 暖白**」逐字不动。
- 色号与光比不许改；只允许替换建筑体量与拍摄角度。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：建筑构件是什么（旋转楼梯、悬挑平台、连廊、双柱、天井、巨型梁、坡道）、体量尺度（几层高/多少级台阶）、混凝土的表面状态（模板缝方向、气孔密度、泛碱痕、边角崩缺）、几何构成（对称/偏置/交叠）、光线落点、透视消失点、天空占比。 |
| 【次要元素·近/中/远】 | 近：一段前景混凝土矮墙或栏杆；中：主构件与光切线；远：天空或远处同类体量。空层写「无」。 |
| 【全局】 | 空气中干净的尘土、混凝土表面的细碎反光。 |
| 【构图】 | 低机位或半高机位、强烈的单点透视或对称中轴；主体占据画面 60% 以上，天空留 20–35%。**不写焦距/景深**。 |
| 【镜头】 | 等效 24–35mm（保持线条笔直、无畸变）、f/8–f/11、大景深、全画面清晰。 |

## 六、易翻车点（写完回查）

1. **光切线不锐利** → 固定节写「过渡仅 2–5cm」，负向含「柔和过渡」类词（可并入「插画、扁平色块」）。
2. **变精装空间** → 负向含「豪华精装、软装家具、吊灯」，【背景】限「只有混凝土体量与天空」。
3. **出现人物破坏空场** → 负向含「人物、人群、车流」。
4. **广角畸变** → 【镜头】限「线条笔直无畸变」，负向含「手机广角畸变、鱼眼」。
5. **混凝土像塑料** → 强调「模板缝、气孔、泛碱、崩缺」，负向含「塑料光泽、3D 渲染」。
