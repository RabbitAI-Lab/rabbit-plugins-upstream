# 风格卡 · 高速摄影·液体飞溅

> **给写提示词的自己**：本卡 ★固定节 的字段必须**逐字照抄**，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `高速摄影·液体飞溅` |
| **一句话定位** | 闪光冻结的一瞬：皇冠水花停在半空，液滴悬停、光泽通透 |
| **媒介本质** | **高速闪光摄影（strobe 冻结）** 的实物拍摄，非 3D 渲染、非 CG 液体 |
| **与最近似风格的区别** | 与「奶油极简」（62）不同：**瞬间冻结、动作剧烈、信息密度高**；与「3D 黏土」（64）不同：**真实材质与真实折射**；与「Y2K 直闪」（58）不同：**无人像、纯棚拍静物** |
| **电影级从哪来** | ① 闪光把运动完全冻成雕塑般的形态 ② 逆光穿透液体形成通透的辉光 ③ 纯色底把主体边缘切得极干净 ④ 液滴与碎屑的层次（大滴小滴）构成节奏 |

## 二、★固定节（逐字照抄）

```
【光影】高速闪光棚拍布光：左后 45° 一支带蜂巢的硬质闪光为主光（勾勒液体边缘）、右前一支大面积柔光照亮主体正面、主体正后方一支逆光闪光穿透液体；配比为 主光:辅光:逆光 = 1:0.6:1.5，背景与主体分离，液体边缘出现明亮的透明辉光；无环境光污染、无投影杂乱
【色彩】纯色背景与主体强对比：背景为单色（奶粉 #F6D9C8 / 天蓝 #A8CDE8 / 深墨绿 #12362B / 纯白 #F7F7F5 任选其一），主体为食品或液体的本色（奶白、莓红、柑橘橙、青柠绿）；无渐变底、无彩色环境反光
【影像质感】高速闪光冻结的实拍：1/8000s 以上的瞬间冻结，液滴边缘锐利到能看清单颗水珠的球形高光、水花表面有细密气泡与不规则薄膜撕裂、飞散的碎屑带极短的动态拖影（不超过 2px）；微距级细节、焦外奶油化、极轻锐化；非 3D 渲染、非 CG 流体模拟
【背景】纯色无缝背景纸或纯色渐变墙，与主体保持 1–2 档明度差；可有同色系的轻微光晕，不出现场景、不出现台面纹理
【风格】高速摄影的液体飞溅瞬间，闪光冻结与纯色硬光，通透液滴与精细飞溅形态，广告级食品静物；非 3D 渲染、非 CG 液体、非插画
【画幅】{9:16}
```

**★固定节填写要求**：
- 命门词「**1/8000s 瞬间冻结**」「**三灯闪光配比 1:0.6:1.5**」「**纯色底 + 通透辉光**」「**球形高光的单颗液滴**」逐字不动。
- 色号与配比不许改；只允许替换主体食物/液体与飞溅形态。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：主体是什么（玻璃杯/易拉罐/香水瓶/水果/叶片）、容器尺寸与材质（厚壁玻璃杯、磨砂、透明）、液体的颜色与透明度、飞溅形态（皇冠、皇冠状水柱、侧向喷溅、环状薄膜）、飞散碎屑（果肉、冰晶、花瓣、气泡）、数量、悬停位置、落点水面状态。 |
| 【次要元素·近/中/远】 | 近：画面外缘飞散的极小液滴；中：主体与主水花；远：纯色背景与逆光辉光。空层写「无」。 |
| 【全局】 | 悬浮的细密水雾、气泡、逆光下的光斑。 |
| 【构图】 | 竖构图，主体居中、水花向上或侧向展开占画面上半；底部留一小段纯色倒影区。**不写焦距/景深**。 |
| 【镜头】 | 等效 90–100mm 微距、f/8–f/11（微距下仍有足够景深）、主体与水花核心全清晰、背景纯色不着细节。 |

## 六、易翻车点（写完回查）

1. **液体糊成拉丝** → 固定节写「1/8000s 冻结、边缘锐利」，负向含「运动模糊拖影、慢速快门」。
2. **像 3D 渲染** → 负向含「3D 渲染、CG 流体、塑料光泽」，强调「真实折射与气泡」。
3. **背景出现场景/台面** → 【背景】限「纯色无缝」，负向含「台面纹理、真实厨房背景」。
4. **出现品牌包装** → 负向含「可辨认品牌包装、瓶贴文字」。
5. **画面脏乱** → 负向含「道具堆叠杂乱、脏污、指纹」。
