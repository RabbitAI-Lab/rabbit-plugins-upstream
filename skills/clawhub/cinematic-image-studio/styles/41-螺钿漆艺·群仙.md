# 风格卡 · 螺钿漆艺·群仙（黑漆螺钿镶嵌 · 虹彩流光 · 金银描线）

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `螺钿漆艺·群仙` |
| **一句话定位** | 把天庭群仙做成一件螺钿漆画——黑漆地上贝壳流光、金银勾线，幽深华贵 |
| **媒介本质** | 东方**螺钿漆艺**（黑漆地 + 贝壳螺钿镶嵌 + 金银泥描线 + 罩漆打磨）；**非**绘画、**非**3D、**非**照片 |
| **与最近似风格的区别** | 与「皮影戏」不同：本卡是**漆面镶嵌**、无暖灯透幕、非剪纸；与「彩墨/水墨」不同：本卡**非绘画笔触**、以螺钿片与漆面构成；与「3D/赛博霓虹」不同：本卡是**手工漆艺的幽深华贵**，非发光塑料。 |
| **气质从哪来** | ① 近黑的漆地为底 ② 螺钿片随角度泛青紫绿虹彩 ③ 金银细线描出轮廓 ④ 高光只落在螺钿、其余沉入漆暗 |

## 二、★固定节（逐字照抄）

```
【光影】幽深暗场为主，光落之处只在螺钿片与金银线；贝壳螺钿薄片随角度泛出青、紫、绿的虹彩流光；金银泥描线微微反光；黑漆地保持深暗温润、非纯死黑；无写实体积光、无彩色光污染
【色彩】黑漆地（近黑、带暖褐）为主体色；螺钿虹彩（青、紫、绿、银白的虹光）作华彩；金银线勾轮廓与纹样；点缀少量朱砂与石青；整体幽深华贵、暗而流光
【影像质感】螺钿漆艺质感：贝壳薄片镶嵌拼接的虹彩流光、金银泥描线的细亮、黑漆面的镜面微反光与温润、漆层打磨的细腻；非绘画笔触、非3D、非塑料、非照片
【背景】天宫以螺钿与金银线嵌出：云纹、缠枝、宫阙门柱与夜云，随螺钿虹彩隐显；漆面暗场为主；无可读文字
【风格】东方螺钿漆艺：黑漆地为底、贝壳螺钿镶嵌 + 金银描线、虹彩流光、幽深华贵、暗而华彩；非绘画、非油画、非照片、非3D、非赛博霓虹
【画幅】16:9
```

**★固定节填写要求**：命门词「**黑漆地为底、非纯死黑**」「**贝壳螺钿片的虹彩流光**」「**金银泥描线**」逐字不动。

## 六、易翻车点（写完回查）

1. **画成绘画/彩墨** → 负向含「绘画笔触、油画、水彩、彩墨」；【影像质感】锁定「贝壳薄片镶嵌 + 金银描线 + 漆面」。
2. **底色不黑/发亮白** → 负向含「亮白地、纯白背景、过曝」；【色彩】锁定「黑漆地为底、非纯死黑」。
3. **螺钿变塑料亮片/霓虹** → 负向含「荧光塑料亮片、夜店霓虹、赛博朋克」；【光影】写「贝壳虹彩流光」。
4. **糊成一团** → 负向含「糊成一团、脏色糊色」；【主体】写清主仙与群仙层次。
