# 风格卡 · 国潮节庆·喜庆民俗

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `国潮节庆·喜庆民俗` |
| **一句话定位** | 像一幅会流动的年画，热闹、团圆、有烟火气，庄喜而不俗艳 |
| **媒介本质** | 节庆民俗写实/渲染质感（红金 + 暖光）；**非**卡通动漫、**非**冷调暗黑 |
| **与最近似风格的区别** | 与「中式国风水墨写意」不同：本档**红金满堂、节庆器物、热闹**；与俗艳不同：**庄喜不俗、红金克制** |
| **电影级从哪来** | ① 暖光通明（灯笼/灶火/烛光）② 热气蒸汽介质 ③ 器物到灯火纵深 ④ 真实肌理 |

## 二、★固定节（逐字照抄）

```
【光影】暖光通明的灯笼光/灶火光/烛光且光源在画面内可解释；画面有热气、蒸汽或灯笼光晕等介质
【色彩】红金满堂的节庆民俗质感；朱砂红与鎏金为基底、强调色不超过两种；热烈团圆而不俗艳
【影像质感】节庆民俗质感：宣纸/红纸/木器/布艺/瓷器的真实肌理；气氛有烟火气
【背景】老宅厅堂/灯会街巷/庭院/灶房/圆桌宴席等节庆空间，前景器物到远景灯火有纵深；无可读文字、无对联文字
【风格】国潮节庆·喜庆民俗：红金满堂节庆民俗质感；人物一律以剪影/背影/侧影/俯身局部/手部衣袖局部呈现，不出现可辨认的真人正脸；以节庆器物叙事（灯笼/窗花/对联/饺子/汤圆/粽子/月饼/艾草，器物上的字迹虚化不可读）；热烈团圆有烟火气而不俗艳
【画幅】{9:16 或 16:9}   ← 只此两种
```

**★固定节填写要求**：命门词「**红金满堂（朱砂红 + 鎏金）**」「**节庆器物叙事、器物字迹虚化不可读**」「**不露正脸**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 节庆器物为主（灯笼/窗花/对联/饺子/汤圆/粽子/月饼/艾草）；人物剪影/背影/侧影/手部衣袖局部，不露正脸。 |
| 【次要元素·近/中/远】 | 前景器物 → 中景主体 → 远景灯火人烟。空层写「无」。 |
| 【全局】 | 热气/蒸汽/灯笼光晕/浮尘。 |
| 【构图】 | 器物到灯火有纵深；主体偏三分。**不写焦距/景深**。 |
| 【镜头】 | 中景；暖光氛围。 |

## 六、易翻车点（写完回查）

1. **俗艳大红大绿** → 负向含「俗艳大红大绿、刺眼撞色」，红金克制。
2. **冷调暗黑** → 负向含「冷调暗黑、恐怖、阴森」。
3. **对联/福字出可读字** → 负向含「对联文字、招牌字」，字迹虚化。
4. **露正脸** → 负向含「可辨认的真人正脸」。
