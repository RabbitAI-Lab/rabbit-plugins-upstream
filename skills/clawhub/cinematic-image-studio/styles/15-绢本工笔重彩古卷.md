# 风格卡 · 绢本工笔重彩古卷

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `绢本工笔重彩古卷` |
| **一句话定位** | 像一册宋代绢本图卷被轻轻展开，异兽被郑重地画在绢上、如今缓缓活了 |
| **媒介本质** | 中国工笔重彩（铁线描 + 平涂 + 矿物色 + 绢帛）；**非**3D/CG、**非**照片写实、**非**油画厚涂/水彩、**非**动漫 |
| **与最近似风格的区别** | 与「彩色水墨」不同：本档**工笔重彩、铁线描立骨、平涂为主**，且以**绢帛**为底；与3D国风不同：纯平面绘画 |
| **电影级从哪来** | ① 线的疏密与色块层次 ② 绢帛质地与颜料颗粒 ③ 手卷式构图 ④ 大面积留白造境 |

## 二、★固定节（逐字照抄）

```
【光影】不用西式明暗造型法；靠线的疏密与色块的层次表现结构（凹凸用重色提醒）；无强投影、无体积光、无真实光照；画面平整清透
【色彩】矿物颜料设色（石青、石绿、朱砂、赭石、藤黄、蛤白），清透有颗粒感、层层薄染；一色不多；墨色沉稳
【影像质感】中国工笔重彩：铁线描/游丝描勾形立骨，轮廓线均匀、干净、有书写性；平涂为主、局部晕染；鳞甲图案化规则鳞纹、毛用细笔丝毛、羽用片羽排列（装饰化、不做写实毛发）；画面为泛黄绢帛底，可见经纬织纹、局部泛黄、细微破损虫蛀小孔、边缘老化水渍、颜料薄厚差与轻微剥落
【背景】大面积留白或极淡晕染（云气/水纹/远山淡墨），主体周围"空"、不塞满；可保留图卷天头地脚、装裱绫边、钤印位置（印面须不可辨、零可读文字）
【风格】像一册宋代绢本图卷被轻轻展开：古雅静穆、如古籍图录；中国工笔重彩，铁线描勾形立骨、平涂为主局部晕染；矿物颜料清透有颗粒；非3D、非CG、非照片写实、非油画厚涂、非日系动画、非卡通
【画幅】{16:9 或 9:16}   ← 只此两种
```

**★固定节填写要求**：命门词「**铁线描勾形立骨 + 平涂**」「**不用西式明暗造型**」「**绢帛经纬肌理**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 单主体，造型古朴有古意、略夸张但不卡通；鳞/毛/羽图案化；姿态如古图录"标准像"。 |
| 【次要元素·近/中/远】 | 云气/水纹/远山淡墨层次；空层写「无」。 |
| 【全局】 | 极淡晕染/浮尘（克制）。 |
| 【构图】 | 立轴/手卷式：主体偏一侧、另一侧留白；题款位置留白不写字；可网格图录感。**不写焦距/景深**。 |
| 【镜头】 | 平面绘画，正面平视、无景深。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|
| 手卷式/横版 | `16:9` 横 | `1536x1024` | 主体偏侧、留白造境 |
| 立轴/竖版 | `9:16` 竖 | `1024x1536` | 主体居中、上下留白 |

## 六、易翻车点（写完回查）

1. **画成写实/3D** → 负向含「3D 渲染、照片写实、体积光」，锁定「铁线描 + 平涂」。
2. **用了西式明暗** → 负向含「西式明暗造型、浓重阴影」。
3. **题款/印章出字** → 负向含「题款文字、印章文字」，【背景】写「印面不可辨」。
4. **写实毛发/解剖** → 负向含「写实毛发、写实解剖」，强调图案化。
