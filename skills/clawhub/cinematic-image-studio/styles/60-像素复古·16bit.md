# 风格卡 · 像素复古·16bit

> **给写提示词的自己**：本卡 ★固定节 的字段必须**逐字照抄**，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `像素复古·16bit` |
| **一句话定位** | 16bit 时代的像素游戏画面：可见像素块 + 受限调色板 + 抖动渐变 + CRT 扫描线 |
| **媒介本质** | 低分辨率像素画（pixel art）在 CRT 显示器上的成像；不是矢量插画、不是高清插画加滤镜 |
| **与最近似风格的区别** | 与「Y2K 数码闪光」（58）不同：**画面由像素块构成，无真实摄影**；与「日系赛璐璐」（34）不同：**无平滑线稿与渐变，颜色数量受限**；与「Q版霓虹」（09）不同：**无亮面手办质感** |
| **电影级从哪来** | ① 像素级硬边明暗（每个像素单一颜色，靠抖动过渡） ② 分层地面/中景/远景构成纵深 ③ 屏幕荧光照亮前景、形成明确光源方向 ④ 色板克制带来的统一影调 |

## 二、★固定节（逐字照抄）

```
【光影】像素级硬边光照：光只表现为像素块的明暗分级，无平滑渐变；主光源为前景的屏幕荧光（像素化的锥形光斑）或斜上方 45° 顶光；亮部用抖动的两级色阶过渡、暗部直接跳到最深的 2–3 个色阶；高光为纯白单像素点阵
【色彩】受限调色板 ≤32 色：主调为深靛蓝（#1B1B3A）与青紫（#3A2E6E）的夜色，辅以荧光绿（#7CFC5A）、品红（#FF4FA3）、暖黄（#FFD45E）作光源与点缀；暗部偏冷紫，亮部偏青白；高饱和、无灰调
【影像质感】低分辨率像素艺术：每个像素块清晰可辨、边缘为硬直角、抖动网点（dithering）承担所有过渡、无抗锯齿与模糊；叠加 CRT 显示质感——水平扫描线、轻微曲面桶形、荧光辉光溢出、屏幕边角暗角；非矢量、非高清插画
【背景】16bit 游戏场景分层构成：像素化的天空色带、方块云、星点、砖墙/地砖 tile、远景山体剪影；层次分明、无摄影景深
【风格】16bit 像素艺术游戏画面，受限调色板与抖动渐变，CRT 扫描线荧光质感，复古电玩与独立游戏美学；非矢量插画、非高清渲染、非照片
【画幅】{16:9}
```

**★固定节填写要求**：
- 命门词「**可见像素块**」「**受限调色板 ≤32 色**」「**抖动 dithering**」「**CRT 扫描线**」逐字不动。
- 色号面积比与「无抗锯齿」不许改；只允许替换 tiled 场景元素与主体形态。

## 三、★专属负向（必须并入【负向】）

```
平滑渐变、抗锯齿、柔边、模糊、景深虚化、厚涂笔触、写实照片、3D 渲染、塑料光泽、
矢量扁平插画、日系赛璐璐、卡通描边、高清细节、超采样、

```

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：主体是什么（角色/载具/物件）、像素块体量（约占画面高度几分之几）、色板内的具体颜色、轮廓形状与朝向、动作姿态、表情（用 2–3 个像素点表达）、装备细节、投影与脚下接触面。角色写「虚构」。 |
| 【次要元素·近/中/远】 | 近：像素化的地砖/tile、屏幕荧光、道具箱；中：主体与动作；远：方块云/山体剪影/星点。空层写「无」。 |
| 【全局】 | 抖动网点、星点、荧光辉光、扫描线。 |
| 【构图】 | 游戏中景/横版侧视为主，主体偏一侧、留出可通行空间；三分法或对称；**不写焦距/景深**。 |
| 【镜头】 | 横版侧视或 3/4 俯视的固定机位，等效 24–35mm 视野，全画面等清晰度，屏幕级平坦透视。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|
| 场景/关卡 | `16:9` 横 | `1536x1024` | 横版侧视，前景地面 + 远景双分层 |
| 竖屏短片首帧 | `9:16` 竖 | `1024x1536` | 主体居中，上方留天空色带，下方地面占三成 |

## 六、易翻车点（写完回查）

1. **加滤镜的高清插画** → 固定节必须写「像素块清晰可辨、无抗锯齿」，负向含「平滑渐变、抗锯齿、高清细节」。
2. **颜色太多变花** → 【色彩】写死「≤32 色」与具体色号，负向加「色板脏灰」。
3. **没有层次变贴纸** → 【镜头】给 3/4 俯视或横版侧视，【背景】强制三分层。
4. **出现计分板/提示语文字** → 负向含「计分板数字、UI 界面文字、英文提示语」。
5. **糊成马赛克乱纹** → 负向含「噪点糊成一片、马赛克乱纹」，并强调「硬直角边缘」。
