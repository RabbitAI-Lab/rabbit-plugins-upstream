# 风格卡 · 美式波普·网点漫画

> **给写提示词的自己**：本卡 ★固定节 的字段必须**逐字照抄**，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `美式波普·网点漫画` |
| **一句话定位** | 1950s 美国广告插画：粗黑轮廓 + Ben-Day 网点 + 三原色撞色 + 硬边投影 |
| **媒介本质** | **丝网/胶版印刷的波普漫画插画**（Lichtenstein 式网点），非写实摄影、非日系动漫 |
| **与最近似风格的区别** | 与「日系赛璐璐」（34）不同：**网点印刷 + 粗黑边 + 美式造型**；与「木刻版画」（07）不同：**不是刻痕，是网点与色块**；与「酸性海报」（59）不同：**复古原色、无铬金属与荧光** |
| **电影级从哪来** | ① 粗黑轮廓勾出明确形体边界 ② 网点密度承担所有明暗渐变 ③ 三原色撞色的高对比构图 ④ 硬边投影带来的平面戏剧感 |

## 二、★固定节（逐字照抄）

```
【光影】平面化硬光：一个明确的主光方向（左上 45°），亮部为纯色平涂、暗部用 Ben-Day 网点加密表现，过渡不存在中间调；所有物体在背后投出 1–2cm 的硬边纯黑或深色投影；无环境光、无反射、无柔和过渡
【色彩】只允许五色体系：正红（#E4002B）、亮黄（#FFD400）、钴蓝（#0057B8）、纯黑（#0A0A0A）、纸白（#FBF7EF）；每种颜色纯色平涂、不叠渐变；撞色对比强、明度高
【影像质感】1950–60 年代美式漫画印刷：粗黑轮廓线（线宽约 2–3mm，收放有粗细变化）、Ben-Day 网点均匀排列（网点直径约 3–5px、间距一致）、轻微套印错位（1px 红/蓝偏移）、纸张纤维与极细的墨点颗粒；非写实渲染、非数字平滑渐变
【背景】纯色平涂底（正红/亮黄/钴蓝/纸白任选其一）或大面积网点渐层，可有一个放大的网点圆形或爆炸星形作为图形元素，全部抽象、无文字
【风格】美式波普漫画广告插画，粗黑轮廓与 Ben-Day 网点，三原色撞色与硬边投影，1950s 复古商业美术；非写实照片、非日系动漫、非 3D
【画幅】{9:16}
```

**★固定节填写要求**：
- 命门词「**粗黑轮廓线**」「**Ben-Day 网点**」「**五色体系**」「**硬边投影**」逐字不动。
- 色号与网点尺寸不许改；只允许替换主体造型与背景图形。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：主体是什么（虚构人物/化妆品/电话/汉堡/跑车）、造型是美式复古还是当代潮牌、发型与服装块面、材质如何用纯色与网点表现、道具、姿态与朝向、五官用几条线表达、哪块区域用网点。人物一律「虚构」。 |
| 【次要元素·近/中/远】 | 近：放大的网点圆形/爆炸星形/色带；中：主体与道具；远：纯色底。空层写「无」。 |
| 【全局】 | 均匀网点、极细墨点、轻微套印偏移。 |
| 【构图】 | 主体居中或三分线、占画面 55–75%，粗黑描边勾住轮廓；背景图形做对角或放射切割。**不写焦距/景深**。 |
| 【镜头】 | 平面正视，无透视畸变；等效 50mm 平视观感、全画面等清晰。 |

## 六、易翻车点（写完回查）

1. **画成写实/3D** → 固定节必须写「纯色平涂 + 网点承担明暗」，负向含「写实摄影、柔和渐变、3D 渲染」。
2. **出现对话框/拟声词** → 负向含「气泡对话框、拟声词、英文单词」。
3. **跑到日系动漫** → 负向含「日系动漫、萌系大眼」，造型写「美式复古块面」。
4. **颜色超过五种** → 【色彩】锁五色色号，负向含「彩虹渐变、荧光色」。
5. **网点变成噪点** → 强调「网点直径 3–5px、间距一致、均匀排列」。
