# 风格卡 · 清新纪实·公益倡导

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `清新纪实·公益倡导` |
| **一句话定位** | 像一支真诚的公益短片，干净、明亮、不喊口号，行动自己说话 |
| **媒介本质** | 清新纪实影像（清透绿蓝天光白）；**非**高饱和广告、**非**暗黑/卡通 |
| **与最近似风格的区别** | 与「温情治愈·电影感写实」不同：本档**清透绿蓝、明亮开阔、工作/自然场景**；与广告不同：**不摆拍、低调干净** |
| **电影级从哪来** | ① 明亮自然光（可解释）② 清新介质（雨丝/水珠/叶间光斑）③ 开阔纵深 ④ 低对比干净柔和 |

## 二、★固定节（逐字照抄）

```
【光影】明亮自然光（晨光/天光/窗光/林间漏光）且光源在画面内可解释；画面通透；偶有雨丝、水珠、浮尘、叶间光斑等清新介质；不高饱和、不广告打光
【色彩】清透绿/湖蓝/天光白为基调、强调色不超过两种；低对比干净柔和
【影像质感】干净明亮的纪实影像：水/叶/纸/布/金属的真实材质、低对比干净柔和
【背景】自然实景或真实工作场景（溪流/林间/田野/书桌/教室/病房/值班室/街巷/绿地），前景中景远景有开阔纵深；无可读文字/标语字
【风格】清新纪实·公益倡导：干净明亮的纪实影像；人物一律以剪影/背影/侧影/低头专注/手部工作局部呈现，不出现可辨认的真人正脸；用一个具体的手部动作或工作动作立起主题（关水/栽苗/翻书/抢救/扶起），群体以剪影汇聚；真诚、明亮、向上、行动自己说话
【画幅】{9:16 或 16:9}   ← 只此两种
```

**★固定节填写要求**：命门词「**清透绿蓝 + 明亮自然光**」「**一个具体动作立主题**」「**不露正脸**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 以剪影/背影/侧影/低头专注/手部工作局部呈现；用一个具体动作（关水/栽苗/翻书/抢救/扶起）立主题；群体以剪影汇聚。 |
| 【次要元素·近/中/远】 | 前景自然物/工作器具 → 中景主体 → 远景开阔场景。空层写「无」。 |
| 【全局】 | 雨丝/水珠/浮尘/叶间光斑。 |
| 【构图】 | 开阔纵深；主体偏三分。**不写焦距/景深**。 |
| 【镜头】 | 中景/远景；明亮自然光。 |

## 六、易翻车点（写完回查）

1. **阴郁灰暗** → 负向含「阴郁灰暗、暗黑恐怖、病态色调」。
2. **高饱和广告感** → 负向含「高饱和荧光、刺眼撞色、广告感」。
3. **出文字/标语** → 负向含「可读的文字、标语字」。
4. **露正脸** → 负向含「可辨认的真人正脸」。
