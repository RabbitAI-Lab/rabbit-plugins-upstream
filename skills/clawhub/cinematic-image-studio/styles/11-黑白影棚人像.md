# 风格卡 · 黑白影棚人像

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。
> ⚠️ **年份必填**：未给年份 → 先一次问清（≤1 问，给 3 个候选年代档 + 1 推荐），不出图。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `黑白影棚人像` |
| **一句话定位** | 一张真实拍摄的黑白影棚肖像照——受控布光、无缝背景、主动摆姿 |
| **媒介本质** | 影棚写实摄影（柔光箱主光 + 补光 + 无缝背景）；**非**生活抓拍、**非**插画/CG、**非**过度磨皮 |
| **与最近似风格的区别** | 与「黑白人像摄影（街头）」镜像：本档**要布光、要无缝背景、要摆姿、可看镜头**；街头档要现场光、抓拍、不看镜头 |
| **电影级从哪来** | ① 受控布光的光位与光比 ② 背景匀光分层 ③ 主动造型 ④ 真实皮肤纹理与自然颗粒 |

## 二、★固定节（逐字照抄）

```
【光影】影棚布光：柔光箱/八角柔光箱主光自被摄者 45° 侧前方、略高于视线打下（柔顺、方向明确），反光板/柔光屏在暗侧补面，光比中低（约 2:1–3:1）；可选侧后方一盏小轮廓光/发丝光 + 背景匀光；硬光/低调/高调须用户点名
【色彩】纯黑白灰阶、零色彩、不用颜色词（用明度词）；中低到适中反差、正常曝光；暗部有层次与颗粒而非死黑，高光柔顺过渡
【影像质感】真实拍摄的黑白影棚照片：皮肤毛孔/绒毛/细纹/自然油光（不做磨皮、不蜡感）、自然细颗粒（细而柔、不显数码噪点）、成像带镜头自然柔度（边缘柔顺、微反差适中、细部真实而不刮手）；无过度锐化、无白描边
【背景】素色/浅灰/中灰无缝背景纸（或背景布），匀光、无接缝无褶皱无杂物无可读文字；与主体明度分离
【风格】这是一张真实拍摄的黑白影棚照片（写实摄影 · 棚拍）：纯黑白灰阶、无任何色彩；受控布光 + 无缝背景 + 主动摆姿 + 真实皮肤 + 自然颗粒；非生活抓拍、非插画/CG、非过度磨皮
【画幅】{9:16 或 16:9 或 3:4}   ← 按用户
```

**★固定节填写要求**：命门词「**影棚布光：主光 + 补光、光比中低**」「**无缝背景**」「**真实皮肤不磨皮 + 自然颗粒**」逐字不动；光型按用户描述选（默认经典柔光）。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【年代】 | **必填**：年份 + 年代档 + 该年形制特征（服装/发型/妆造/表情基调）；一切可辨识年代元素落在该年区间。 |
| 【主体】 | 单主体，胸像/半身/全身，占画面 2/3–4/5；写稳定外形（明度词描述年代服装）。 |
| 【姿势】 | 主动摆姿：正面或 3/4 侧身、肩线转向、下巴略收；**可看镜头**；经典肖像手位。 |
| 【背景】 | 无缝背景纸，深浅按用户（默认浅灰至中灰）。 |
| 【构图】 | 干净克制，主体居中或略偏。**不写焦距/景深**。 |
| 【镜头】 | 85–105mm 定焦，f/5.6–f/11（面部整体清晰、成像柔顺），机位视线高度或略高。 |

## 六、易翻车点（写完回查）

1. **出生活抓拍/杂乱** → 负向含「生活抓拍、casual snapshot、背景杂乱」，【背景】锁定无缝纸。
2. **出彩色** → 负向含「色彩、彩色、暖调、蓝调」。
3. **过度锐化** → 正向**不堆**「清晰/分明/锐」，写「成像柔度」；负向含「过度锐化、锐化白边」。
4. **未给年份** → 先问清再出图。
