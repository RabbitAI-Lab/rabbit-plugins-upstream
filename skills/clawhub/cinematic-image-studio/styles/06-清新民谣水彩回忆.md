# 风格卡 · 清新民谣水彩回忆

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `清新民谣水彩回忆` |
| **一句话定位** | 清新手绘水彩插画，夏末黄昏的旧街与旧物，像一本翻旧了的速写本 |
| **媒介本质** | 手绘水彩（淡淡晕染 + 冷压纸纹 + 彩铅细线）；**非**矢量硬边、**非**厚重 3D、**非**写实 |
| **与最近似风格的区别** | 与「清晰水彩写实」不同：造型简化、颜色淡透微灰；与动漫不同：**剪影不露脸、非二次元** |
| **电影级从哪来** | ① 低斜暖橙夕照/逆光长影 ② 雾蓝夜色窗光 ③ 大面积光晕聚焦主体 ④ 冷暖两档光的情绪调度 |

## 二、★固定节（逐字照抄）

```
【光影】夏末黄昏的低斜暖橙夕照 + 逆光轮廓与长影，或雾蓝夜色里的奶油黄窗光/屏光；光比柔、无戏剧硬光；四周大面积柔光光晕；色温暖（黄昏）／冷（夜色）
【色彩】米黄纸白底（#FBF6EC / #F5EDDD）≥50%，暖橙（#E8A06B / #F2B980）20–30%，雾霾蓝 + 褪色青绿（#8FA6C4 / #9BB8A6）合计 15–25%，暖棕（#A9855F）+ 暗褐（#4A4038）做线与剪影；色调淡、透、微灰
【影像质感】清新手绘水彩：冷压纸纹上的淡淡水彩晕染与少量彩铅细线；边缘自然渗透、留有水痕与飞白；不写实、不用矢量硬边、无厚重3D、无镜面反光
【背景】夏末黄昏/雾蓝夜色的旧巷、街口、站台、窗台与安静房间，抽象化普通城市空间（无品牌门店/地标）；无文字
【风格】清新手绘水彩插画，安静、怅然而克制，剪影人物不露正面脸；主体大、占据画面视觉中心、留白充足；非写实照片、非二次元、非厚重3D
【画幅】{16:9 或 9:16}   ← 只此两种
```

**★固定节填写要求**：命门词「**冷压纸纹 + 水彩晕染 + 水痕飞白**」「**暖橙夕照/雾蓝夜色两档光**」「**剪影不露脸**」逐字不动；黄昏/夜色每图可切，同段落不混光。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 细节**：旧物（耳机/手机播放条/相册/信封/单车）或剪影人物；人物一律背影/侧影/剪影/局部，**不露正面脸、无可辨认五官**。 |
| 【次要元素·近/中/远】 | 前景窗框/旧物 → 中层主体 → 远层街景朦胧。空层写「无」。 |
| 【全局】 | 夕照浮尘/雨丝/柔光光晕/窗格投影。 |
| 【构图】 | 主体大、占视觉中心；方向感清楚（走/望/递/放下）；留白充足。**不写焦距/景深**。 |
| 【镜头】 | 中景/近景，浅景深柔焦（f/2.8 柔和虚化）。 |

## 六、易翻车点（写完回查）

1. **画成写实/厚涂** → 保留「冷压纸纹 + 水彩晕染 + 水痕」，负向含「写实照片感、厚涂油画」。
2. **露正脸** → 负向含「写实人脸」，【主体】强制剪影/背影/局部。
3. **画成霓虹赛博** → 负向加「赛博霓虹乱闪、科幻城市」。
4. **过饱和糊成一片** → 保持「淡、透、微灰」，负向加「高饱和大乱闪」。
