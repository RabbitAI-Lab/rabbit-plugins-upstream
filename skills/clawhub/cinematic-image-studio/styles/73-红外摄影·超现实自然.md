# 风格卡 · 红外摄影·超现实自然

> **给写提示词的自己**：本卡 ★固定节 的字段必须**逐字照抄**，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `红外摄影·超现实自然` |
| **一句话定位** | 红外视角下的自然：植被白如落雪、天空压成深蓝、高光泛粉，像一场清醒的梦 |
| **媒介本质** | **红外（IR）摄影**的直出/伪彩后期，非普通风景照、非插画 |
| **与最近似风格的区别** | 与「水墨写意」（23）不同：**有真实植被结构与光学质感**；与「蓝调夜行」（63）不同：**白昼强光、植被发白**；与「奶油极简」（62）不同：**信息量大、超现实色相** |
| **电影级从哪来** | ① 白色植被与深蓝天形成极端而干净的色相对比 ② 红外强反射让亮部呈现通透的白色颗粒感 ③ 真实景物的结构与这片假色形成错位感 ④ 水面与阴影变成近墨色，压缩出层次 |

## 二、★固定节（逐字照抄）

```
【光影】正午前后的直射日光：红外波段下植被与草地强烈反射光线，成为画面中最亮的部分（近乎高光溢出但仍有层次）；天空因红外散射少而压成深蓝；阴影短而硬、落在近墨色的地面上；整体光比约 1:5，亮部通透、暗部沉稳
【色彩】红外假色体系：植被为雪白（#F2F0EA）至浅粉（#E8C9CF）、天空为深青蓝（#1B3A5C）至墨蓝（#0E2138）、水面与阴影为近墨绿黑（#152A26）、石头与泥土为暖棕（#8A7358）；高光泛粉、整体色相极不自然但干净
【影像质感】红外数码摄影：植被呈现细微的白色绒状颗粒与半透明叶脉、天空极干净无噪点、暗部有轻微热噪、边缘锐度中等偏高；轻微光晕与亮部柔化；非彩色风景照、非黑白、非插画
【背景】自然风景层次：白色树冠层、深蓝天空、墨色水面或岩壁，远景层层退去并带轻微空气透视
【风格】红外摄影的超现实自然，白色植被与深蓝天空的假色对比，静谧梦幻的风景质感；非普通风景照、非黑白摄影、非插画
【画幅】{16:9}
```

**★固定节填写要求**：
- 命门词「**植被雪白/浅粉**」「**天空深青蓝**」「**水面与阴影近墨**」「**高光泛粉**」逐字不动。
- 色号与光比不许改；只允许替换地貌与主体（树/草/人）。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：主体是什么（白桦林/草坡/芦苇荡/湖面/孤树/石屋）、数量与位置、体量与前景占比、白化程度（叶片的雪白与半透明叶脉）、树干纹理、与水面或天空的关系、是否有远景人物剪影、构图落点。 |
| 【次要元素·近/中/远】 | 近：白色草丛/石块的边缘；中：主体树木或水面；远：层层白化的树冠与深蓝天空。空层写「无」。 |
| 【全局】 | 空气中漂浮的白色绒絮/花粉颗粒、亮部柔化光晕。 |
| 【构图】 | 横构图，地平线在画面下三分之一或中段，主体偏侧、留出大片天空；可有人物剪影（虚构）点缀比例。**不写焦距/景深**。 |
| 【镜头】 | 等效 24–35mm、f/8、大景深、远近都清晰但远景带空气透视。 |

## 六、易翻车点（写完回查）

1. **植被还是绿的** → 固定节锁「雪白/浅粉」，负向含「普通绿色植被、秋色暖黄」。
2. **变成黑白照** → 负向含「黑白摄影、单色去色」，保留「深青蓝天空 + 粉色高光」。
3. **变日常风景** → 负向含「寻常蓝天白云」，强调「不自然但干净的假色」。
4. **高光糊成一片** → 写「近乎高光溢出但仍有层次」，负向含「死白过曝成一片」。
5. **出现真实地标** → 负向含「可辨认地标、真实建筑招牌」。
