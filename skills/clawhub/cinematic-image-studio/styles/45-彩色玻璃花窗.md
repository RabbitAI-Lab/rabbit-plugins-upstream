# 风格卡 · 彩色玻璃花窗（铅条分格 · 宝石色透光）

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `彩色玻璃花窗` |
| **一句话定位** | 像一面教堂彩色玻璃花窗——铅条分割的宝石色玻璃里，群仙发光起舞 |
| **媒介本质** | 彩色玻璃花窗（stained glass：玻璃块 + 铅条分格 + 逆光透射）；**非**绘画、**非**3D、**非**照片 |
| **与最近似风格的区别** | 与「螺钿漆艺」（41）不同：螺钿是**黑漆地不透明虹彩**；本档是**玻璃透光**、铅条暗线分格、整面自发光。与绘画不同：以**色块玻璃+铅条线**构成。 |
| **璀璨从哪来** | ① 逆光透射的自发光 ② 铅条暗线勾轮廓 ③ 宝石饱和色 ④ 玻璃气泡与微凸 |

## 二、★固定节（逐字照抄）

```
【光影】逆光透射：光从背面穿透彩色玻璃、每块玻璃自发光般透亮；铅条为暗线；暗部与亮部对比强；可落在台面上投出彩色光斑
【色彩】彩色玻璃：宝石红、钴蓝、祖母绿、金黄、紫等饱和玻璃色，由黑铅条分隔；整体璀璨、饱和透亮、通透
【影像质感】彩色玻璃花窗（stained glass）质感：玻璃块由铅条/黑线分割、表面有玻璃气泡与微凸、逆光下色块发光、铅条为暗线；非绘画、非3D、非塑料
【背景】花窗式天宫：拱形/玫瑰窗式窗格内以铅条分割出群仙与云纹；暗石墙窗框；无可读文字
【风格】彩色玻璃花窗（stained glass）：铅条分格、玻璃透光、宝石色块、窗格式构图；璀璨神圣；非绘画、非3D、非照片
【画幅】16:9
```

**★固定节填写要求**：命门词「**铅条分格 + 玻璃块逆光透亮**」「**宝石饱和色**」「**整面自发光**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 主仙（虚构，以彩色玻璃块拼成、铅条勾轮廓，居中略大、姿态起舞；发光透亮）；群仙分列；末尾「是画面唯一视觉主体」 |
| 【次要元素·近/中/远】 | 近：铅条几何边饰/拱券；中：群仙玻璃块与云纹窗格；远：分格背景玻璃；空层写「无」 |
| 【全局】 | 少量透光彩色光斑 —— 与逆光自洽 |
| 【构图】 | 窗格式：主仙居中、群仙环绕/分列、外圈拱券；玫瑰窗式放射或对称；**不写焦距/景深** |
| 【镜头】 | 正面对窗平视，无强烈景深 |

## 六、易翻车点（写完回查）

1. **没有铅条分隔** → 负向含「没有铅条分隔」；【影像质感】写「铅条/黑线分割玻璃块」。
2. **变绘画** → 负向含「绘画笔触、油画、水彩」；【影像质感】锁「玻璃块 + 铅条 + 透光」。
3. **玻璃不透明/死板** → 负向含「玻璃不透明死板」；【光影】写「逆光透射、自发光般透亮」。
4. **色块糊成一团** → 负向含「色块糊在一起、糊成一团」；【色彩】写「色块由黑铅条清晰分隔」。
