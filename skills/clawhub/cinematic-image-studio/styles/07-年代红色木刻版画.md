# 风格卡 · 年代红色木刻版画

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `年代红色木刻版画` |
| **一句话定位** | 年代红色木刻版画风格，带有暗调史诗的纪念感 |
| **媒介本质** | 木刻/凸版版画（以刀代笔、雕版排线、可见刀痕毛边、纯色块强对比）；**非**写实照片、**非**平滑数码 |
| **与最近似风格的区别** | 与「国潮插画」不同：**有真实版画压印感与刀痕毛边**；与写实不同：几何化剪影、无渐变 |
| **电影级从哪来** | ① 硬侧光 + 深雕刻阴影 ② 光束切分（探照灯/破晓金线） ③ 端正对称构图 ④ 刀刻质感与老纸颗粒 |

## 二、★固定节（逐字照抄）

```
【光影】硬侧光与深雕刻阴影，光束切分（探照灯、破晓金线），余烬微光；高对比、无柔和渐变；色温偏冷（深炭夜幕）
【色彩】深炭夜幕（#1A1512 / #221C17）≥50%，牛血红（#7A1F1F / #8E2A24）20–30%，暗金（#B8912F）≤10%，冷灰（#8C877D / #5B564E）收边，老纸米白（#E8E0CE / #D9CFBA）作版画留白；沉、重、静，不艳不闹不亮
【影像质感】雕版排线与可见刀痕、粗黑轮廓、毛边断口，纯色块强对比、老纸颗粒与印痕（克制微斑驳）、版画压印感；无渐变、无写实照片质感、无现代光面
【背景】城郭天际线、铁轨与枕木、屋脊、冰封江面、纪念墙、家门——皆几何化剪影（历史处所不写实复刻）；无文字
【风格】年代红色木刻版画风格，庄重肃穆的纪念感；雕版排线与可见刀痕、纯色块强对比，主体大、占据画面视觉中心，构图端正、留白充足；非写实照片、非写实人脸、非厚重3D、非现代光面
【画幅】{16:9 或 9:16}   ← 只此两种
```

**★固定节填写要求**：命门词「**雕版排线 + 可见刀痕 + 毛边断口**」「**深炭夜幕 + 牛血红**」「**匿名无面孔剪影**」逐字不动。

```
写实照片感、真实人脸、写实皮肤、厚涂、3D 塑料感、现代光面、高饱和乱色、大爆闪、

文字、水印、Logo、二维码、英文、字母、拼音、阿拉伯数字、乱码、错字
```

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 细节**：器物为主（唢呐/铁轨/停摆的钟/火种），或匿名无面孔几何化木刻剪影（无五官、无身份特征，只作情绪承载）。 |
| 【次要元素·近/中/远】 | 前景版画留白/刻纹 → 中层主体 → 远层几何化天际线/江面。空层写「无」。 |
| 【全局】 | 破晓金线/余烬微光/雪粒 —— 与硬侧光自洽。 |
| 【构图】 | 主体大、占视觉中心；端正对称或斜向动势；留白充足（版画留白即白纸）。**不写焦距/景深**。 |
| 【镜头】 | 中景/远景，硬光高对比；不追求浅景深（版画平面感），可写正面平视。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|
| 横版 B-roll / 封面 | `16:9` 横 | `1536x1024` | 端正对称、主体突出 |
| 竖屏短视频 | `9:16` 竖 | `1024x1536` | 主体居中、上下留白 |

## 六、易翻车点（写完回查）

1. **画成写实/厚涂** → 保留「雕版排线 + 刀痕毛边」，负向含「写实照片感、厚涂」。
2. **出现政治符号/血腥** → 负向强制含「政治符号、旗帜、徽章、血腥、开火武器」；武器只作静态剪影。
3. **做旧过度脏乱** → 【影像质感】写「克制微斑驳」，负向加「脏旧污渍、做旧过度」。
4. **牛血红变正红/荧光** → 固定节锁定色值，负向加「高饱和乱色」。
