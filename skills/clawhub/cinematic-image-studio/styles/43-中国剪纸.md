# 风格卡 · 中国剪纸（红纸镂刻 · 层叠纸雕拼贴）

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `中国剪纸` |
| **一句话定位** | 像一张大红剪纸/多层纸雕拼贴——镂空纹样里的天庭群仙 |
| **媒介本质** | 剪纸/刻纸 + 层叠纸雕拼贴（纸纤维、刀口、纸层薄影）；**非**皮影、**非**绘画、**非**3D |
| **与最近似风格的区别** | 与「08 皮影戏」不同：皮影是**透光兽皮影人 + 暖灯透幕**；本档是**不透明的红纸镂刻/彩色层叠剪纸**、纸的纤维与刀口、层间薄投影，非演出。与绘画不同：本档是**纸的镂空与叠层**。 |
| **装饰美从哪来** | ① 镂空纹样的通透 ② 纸层叠出的薄影 ③ 正红＋金的民俗色 ④ 平面装饰构图 |

## 二、★固定节（逐字照抄）

```
【光影】平面镂刻纸面的弱光影；以多层纸张叠加的薄投影表现层次（每层纸自带淡淡投影）；底色干净明亮；无写实体积光、无暖灯透幕
【色彩】中国剪纸：正红纸为主，金纸/黑纸作点缀；或层叠彩色剪纸（红、金、石青、靛蓝）；色块纯正、饱和鲜明；白底（或红底）留白充足
【影像质感】剪纸与纸雕拼贴质感：纸的纤维与刀口毛边、镂空的纹样、层叠纸张之间的薄投影、纸面微糙；非3D、非塑料、非绘画、非透光兽皮
【背景】剪纸式天宫：以镂空云纹、缠枝、宫阙门柱的剪纸纹样层层叠叠排布；干净底色；无文字
【风格】中国传统剪纸（剪/刻纸）与层叠纸雕拼贴：红纸镂刻纹样、刀口纤维、多层纸影、平面装饰美；非皮影戏、非绘画、非3D、非写实照片
【画幅】16:9
```

**★固定节填写要求**：命门词「**红纸镂刻 + 刀口纸纤维**」「**多层纸张叠加的薄投影**」「**非皮影、非绘画**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 主仙（虚构，由红纸/彩纸镂刻或层叠而成，可加金纸勾边），居中略大、姿态起舞；群仙以剪纸小样分列；末尾「是画面唯一视觉主体」 |
| 【次要元素·近/中/远】 | 近：剪纸云纹/缠枝边饰；中：群仙剪纸与镂空宫柱；远：分层云纹；空层写「无」 |
| 【全局】 | 少量纸屑/镂空碎影 —— 与平面弱光自洽 |
| 【构图】 | 平面装饰构图：对称/环绕；主仙居中、群仙分列、外圈纹样；**不写焦距/景深** |
| 【镜头】 | 平面正视，无强烈景深 |

## 六、易翻车点（写完回查）

1. **变皮影** → 负向含「皮影戏、透光兽皮、暖灯透幕」；【光影】写「纸面弱光、非透幕」。
2. **变绘画/有笔触** → 负向含「绘画笔触、油画、水彩」；【影像质感】锁「纸纤维、刀口、镂空」。
3. **纸变塑料/无镂空** → 负向含「纸变塑料片」；【影像质感】写「刀口毛边、镂空纹样」。
4. **层叠糊成一团** → 负向含「镂空糊成一团」；【光影】写「多层纸张的薄投影分层次」。
