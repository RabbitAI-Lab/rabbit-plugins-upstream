# 风格卡 · 中式国风·水墨写意

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `中式国风·水墨写意` |
| **一句话定位** | 像一幅缓缓晕开的中国画活了，庄重、温厚、有余韵 |
| **媒介本质** | 水墨写意（宣纸绢帛 + 笔墨晕染）；**非**油画厚涂/写实摄影/动漫/3D |
| **与最近似风格的区别** | 与「彩色水墨」不同：本档**暖调赭石朱砂 + 器物仪式叙事**，且不露正脸；与「国潮节庆」不同：本档**写意留白**而非红金满堂 |
| **电影级从哪来** | ① 笔墨晕染过渡的光影 ② 大面积留白造境 ③ 写意纵深 ④ 宣纸肌理 |

## 二、★固定节（逐字照抄）

```
【光影】柔和天光或烛火灯笼暖光；光影以笔墨晕染过渡而非硬光；温厚有余韵
【色彩】水墨写意为骨、宣纸绢帛肌理为底；赭石朱砂暖调、墨色浓淡有致、大面积留白造境；强调色不超过两种（朱砂红加一点石青）
【影像质感】水墨写意：笔触与晕染自然、恬静温厚有古意；人物一律以剪影/背影/侧面/衣袂手部局部呈现，不出现可辨认的真人正脸
【背景】老宅庭院书房茶席等中式空间，前景中景远景有写意纵深；无可读文字、无印章文字
【风格】中式国风·水墨写意：水墨写意为骨、留白造境；赭石朱砂暖调、墨色浓淡有致；以中式器物与仪式叙事（寿桃/茶盏/毛笔/家书/灯笼）；恬静温厚有古意
【画幅】{9:16 或 16:9}   ← 只此两种
```

**★固定节填写要求**：命门词「**水墨写意为骨 + 留白造境**」「**赭石朱砂暖调**」「**不露正脸**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 中式器物与仪式叙事为主（寿桃/茶盏/毛笔/家书/灯笼）；人物剪影/背影/侧面/衣袂手部局部，不露正脸。 |
| 【次要元素·近/中/远】 | 写意纵深（前景器物→中景主体→远层庭院/山水淡墨）。空层写「无」。 |
| 【全局】 | 墨晕/香烟/浮尘/落瓣（克制）。 |
| 【构图】 | 大面积留白；主体偏三分。**不写焦距/景深**。 |
| 【镜头】 | 平面写意，中景/远景，无硬景深。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |

## 六、易翻车点（写完回查）

1. **画成油画/写实** → 负向含「油画厚涂、写实摄影」。
2. **满屏堆砌无留白** → 负向含「满屏堆砌无留白」，【构图】强制留白。
3. **俗艳大红大绿** → 负向含「高饱和大红大绿、俗艳」。
4. **出文字/印章文字** → 负向含「文字、书法字幕、印章文字」。
