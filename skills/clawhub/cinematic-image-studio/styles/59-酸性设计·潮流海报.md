# 风格卡 · 酸性设计·潮流海报

> **给写提示词的自己**：本卡 ★固定节 的字段必须**逐字照抄**，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `酸性设计·潮流海报` |
| **一句话定位** | 液态铬金属 + 荧光撞色 + 网点错版的酸性平面海报，潮牌与派对语境 |
| **媒介本质** | **平面设计海报**（丝网印刷 / 数码印刷的平面成品），不是摄影、不是 3D 场景 |
| **与最近似风格的区别** | 与「Y2K 数码闪光」（58）不同：**没有机顶直闪与真实空间**，是平面版式；与「赛博霓虹」（33）不同：**不用霓虹灯管和暗夜场景**，用印刷撞色与铬金属；与「国潮厚涂」不同：**非绘画笔触** |
| **电影级从哪来** | ① 明确的视觉层级（主体铬物件 > 色带 > 网格底） ② 印刷品的物理质感（网点/套印偏移） ③ 克制的留白，撞色集中在两三块 ④ 高光只落在铬面，形成金属镜面切割 |

## 二、★固定节（逐字照抄）

```
【光影】平面海报式伪光照，无真实场景光源：铬金属主体由三条窄长的镜面高光带切出体积，高光为纯白硬边、反射中带有环境色的青紫渐变；背景色块之间存在 1–2px 的错位硬投影（模拟套印偏移）；整体保持印刷品的平坦感，暗部不加深、不出现真实投影层次
【色彩】酸性撞色三主色：电光紫（#7A3CFF）、酸性荧光绿（#C6FF2E）、荧光粉（#FF3D8B）面积 60–75%；铬银（#D9DDE3）作主体金属色；辅助柠檬黄（#FFE45C）与纯白（#FFFFFF）作锐利色带；全部高饱和、无灰调过渡，色块边界干净
【影像质感】丝网印刷 + 数码印刷混合质感：细密网点（halftone）在色块过渡处可见、局部 CMYK 错版（青/品红/黄三层偏移 1–2mm）、细颗粒噪点、铬金属表面为液态镜面反射、边缘有轻微胶片色差；非写实摄影、非 3D 渲染
【背景】纯色或双色渐变的平面底 + 网格/同心圆/放射线/条形色块等几何版式元素，元素一律为抽象图形、不可读；留白区保持大面积纯色
【风格】酸性设计（Acid Graphic）潮流海报，液态铬金属与高饱和荧光撞色，网点错版印刷质感，几何色块承担版式骨架，街头潮流与派对文化气质；非摄影、非写实渲染、非国潮插画
【画幅】{9:16}
```

**★固定节填写要求**：
- 命门词「**液态铬金属**」「**酸性撞色三主色**」「**网点 + CMYK 错版**」「**几何色块版式**」逐字不动。
- 色号与面积比不许改；只允许替换主体形态与几何元素组合。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：主体的材质（液态铬 / 镜面不锈钢 / 镭射 PVC / 半透明树脂）、形态（扭曲的花、蝶、心形、眼睛、星形、链条、手）、表面起伏与高光走向、反光里映出的色块颜色、大小与画面占比、朝向与倾斜角度、是否悬浮。主体为抽象物件或虚构符号，不画真人。 |
| 【次要元素·近/中/远】 | 近：几何色带/网点圆点/镭射碎片；中：主体；远：网格底纹/放射线/大面积纯色块。空层写「无」。 |
| 【全局】 | 细噪点、网点、微小光斑、印刷墨点。 |
| 【构图】 | 版式化：主体压在视觉中心或三分线，色带横切或斜切画面，四周留出大面积纯色边距（≥15%）。**不写焦距/景深**。 |
| 【镜头】 | 平面正视、无透视压缩、无景深虚化（海报是平面），等效 50mm 正投影观感、全画面等清晰度。 |

## 五、画幅与题材取向

## 六、易翻车点（写完回查）

1. **画成写实摄影或 3D** → 固定节强调「平面海报式伪光照 / 印刷品平坦感」，负向含「照片写实、3D 渲染」。
2. **冒出文字** → 负向含「字母、数字、汉字、标语」，【背景】写「不可读」。
3. **撞色糊成一团脏色** → 【色彩】必须给面积比与「色块边界干净」，负向加「柔和渐变过渡」。
4. **铬金属变塑料** → 强调「液态镜面反射 + 三条窄长高光带」，负向含「塑料材质、CG 光泽」。
5. **变成赛博夜景** → 负向含「霓虹灯管、赛博朋克街景」，且不写夜景光源。
