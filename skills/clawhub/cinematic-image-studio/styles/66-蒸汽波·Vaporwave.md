## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：主体是什么（罗马柱/棕榈/几何体/泳池/旧电视/雕塑）、尺寸与占画面比例、材质与表面（大理石裂纹、抛光塑料、镜面）、颜色（必须落在粉紫青橙里）、姿态与位置、与落日的相对关系、是否被网格地面切割。 |
| 【次要元素·近/中/远】 | 近：网格地面的近处格子与倒影；中：主体与棕榈；远：落日、柱群、飘浮几何体。空层写「无」。 |
| 【全局】 | 粉色雾气、扫描线、轻微信号噪点、漂浮的光斑。 |
| 【构图】 | 竖构图，落日压在画面上三分之一、地平线在画面中部偏下，主体居中或两侧对称；网格透视线向落日收。**不写焦距/景深**。 |
| 【镜头】 | 低机位广角、等效 24mm、大景深、全画面等清晰度（合成感，不追求真实虚化）。 |

## 六、易翻车点（写完回查）

1. **画成现代 3D/写实场景** → 固定节写「VHS + 早期 3D 合成、低分辨率多边形」，负向含「写实摄影、PBR 材质、锐利高清」。
2. **变成赛博冷青** → 【色彩】锁死粉紫主调与色号，负向含「冷青赛博朋克」。
3. **出现日文/招牌字** → 负向含「日文、英文单词、招牌字」，【背景】不写建筑招牌。
4. **没有纵深变贴纸** → 【构图】强制网格透视线与三层前后景。
5. **画面糊成噪点** → 负向含「噪点糊成一片」，扫描线写「可见但不遮盖细节」。
