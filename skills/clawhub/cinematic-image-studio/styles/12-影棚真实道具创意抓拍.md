# 风格卡 · 影棚真实道具创意抓拍

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。
> ⚠️ **创意概念必填**：每图一个可复述的创意；用户没给 → 先给 2–3 个候选确认，不擅自编写。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `影棚真实道具创意抓拍` |
| **一句话定位** | 一张彩色、真实道具置景、有创意概念的影棚抓拍照片 |
| **媒介本质** | 写实影棚摄影（全套布光 + 真实自然道具置景）；**非**插画/CG/3D、**非**黑白 |
| **与最近似风格的区别** | 与「黑白影棚人像」不同：本档**彩色鲜明**、有**创意概念**与**真实道具**；与「创意摄影」不同：本档**必在影棚、真实道具、抓拍** |
| **电影级从哪来** | ① 全套布光（主+补+轮廓+背景+眼神光）② 真实材质物理反射 ③ 动作中途的瞬间感 ④ 色彩服务创意 |

## 二、★固定节（逐字照抄）

```
【光影】全套影棚布光：主光 + 补光 + 轮廓光 + 背景光 + 眼神光；光像真拍的（有来源、方向、落影、真实高光反射）；色温自然
【色彩】彩色鲜明、不偏灰不偏单色；用真实材质本色；色彩服务创意、视觉引导明确
【影像质感】真实拍摄的彩色影棚创意抓拍照片：真实皮肤（毛孔/绒毛/自然油光/细纹）、毛发走向、织物纹理、金属/玻璃/液体的真实物理反射；成像带镜头自然柔度；非插画/CG/卡通
【背景】影棚真实自然道具置景（全真材实料：真花/真枝/真果蔬/真器物/真布料/真石木金属），写清材质与自然瑕疵，与创意互文、不抢主体；无可读文字
【风格】这是一张真实拍摄的影棚创意抓拍照片（写实摄影）：彩色鲜明，道具全部是真的、大自然的，承载一个可复述的创意概念，是抓拍不是摆拍；非插画/CG/卡通
【画幅】{16:9 或 9:16}   ← 只写取向
```

**★固定节填写要求**：命门词「**全套布光（五件套）**」「**道具全部是真的、大自然的**」「**抓拍不是摆拍**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【创意】 | **必填**：一句话创意 + 如何落实（主体与真道具如何互文、动作进行到哪一瞬、空间比例）+ 色彩如何服务创意。一条只讲一个主创意。 |
| 【主体】 | 单主体 + 与真道具互动关系；写清材质与颜色；占视觉中心。 |
| 【姿势】 | 抓拍：动作中途、不知情、不看镜头；旁观机位（约 2–4 m、手持自然高度）。 |
| 【背景】 | 影棚置景（真实自然道具）与背景关系；与主体明度/色彩分离。 |
| 【构图】 | 按创意定景别；主体占中心。**不写焦距/景深**。 |
| 【镜头】 | 半身/全身/特写按创意；浅景深（可选）。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|
| 商业人像/横版 | `16:9` 横 | `1536x1024` | 创意落点突出 |
| 竖版/全身 | `9:16` 竖 | `1024x1536` | 主体+道具纵向排布 |

## 六、易翻车点（写完回查）

1. **出灰/单色** → 负向含「褪色、去饱和、灰调、单色」（**不得**把 colorful/saturated 放负向）。
2. **空棚/模板化** → 负向含「空棚、空置景、平淡、通用模板化」。
3. **出假道具** → 负向含「假花、人造植物、塑料道具」，【背景】写真实材质。
4. **出摆拍** → 负向含「摆拍、posed」，【姿势】锁定动作中途、不看镜头。
