# 风格卡 · 蓝晒氰版·日光蓝图

> **给写提示词的自己**：本卡 ★固定节 的字段必须**逐字照抄**，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `蓝晒氰版·日光蓝图` |
| **一句话定位** | 日光曝晒的单色普鲁士蓝接触印相：植物剪影 + 手涂纸边 + 水痕 |
| **媒介本质** | **蓝晒法（cyanotype）接触印相的实物照片/扫描**，非数码蓝调滤镜、非插画 |
| **与最近似风格的区别** | 与「黑白人像」（10/11）不同：**单色蓝而非灰阶**；与「工程蓝图」不同：**有植物与手作痕迹，不是线条图纸**；与「水墨」（23）不同：**剪影靠光化学而非笔触** |
| **电影级从哪来** | ① 单一波长形成的纯净蓝阶（无彩色干扰） ② 剪影边缘的锐利与半透明层次 ③ 纸张纤维与刷痕带来的物质感 ④ 大留白与居中秩序 |

## 二、★固定节（逐字照抄）

```
【光影】接触印相的平光成像：无方向性光源，主体以剪影或半透明影调直接压在纸面上，边缘锐利（接触印相的 1:1 贴合）；纸上明暗只由遮挡时长决定，形成从深普鲁士蓝到浅钴蓝的连续蓝阶；不出现投影与体积光
【色彩】单色普鲁士蓝体系：最深处为深蓝（#0B2A5B）、中间调为群青（#1D4E9C）、最浅为浅钴蓝（#8FB6DE）、未感光处为纸白（#F4F1EA）；无其他颜色；整体高明度反差、蓝层有轻微不均的涂抹感
【影像质感】蓝晒实物质感：纸面为冷压水彩纸（可见纤维与轻微橘皮纹）、边缘有手涂感光液的刷痕与不规则蓝边、局部有水痕与氧化泛白、感光层有细微颗粒与轻微斑驳；接触印相的剪影边缘 1–2mm 内可见极细的蓝色光晕（halation）；非数码滤镜、非单色图层
【背景】纸面本身即背景：大面积未感光的纸白或浅钴蓝留白，偶尔有细小的气泡痕与刷毛留下的浅蓝丝路；不出现场景与环境
【风格】蓝晒氰版（Cyanotype）接触印相，单色普鲁士蓝与植物剪影，手作刷痕与纸纤维质感，安静的古典科学图鉴气质；非摄影实景、非数码蓝调、非插画
【画幅】{16:9}
```

**★固定节填写要求**：
- 命门词「**单色普鲁士蓝 + 纸白**」「**接触印相剪影**」「**手涂刷痕与蓝边**」「**水痕与纤维**」逐字不动。
- 蓝色四阶色号与「无方向光源」不许改；只允许替换被摄物与排版位置。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：主体是什么（蕨类/叶片/花枝/羽毛/贝壳/旧钥匙/齿轮/玻璃瓶）、数量与排列方式（散置/成束/平铺/垂直排列）、尺寸比例、哪些部分半透明（薄叶脉）、哪些部分接近纯剪影（厚茎）、细节（绒毛、锯齿边、锈斑）、与纸边的距离、是否有重叠。 |
| 【次要元素·近/中/远】 | 近：纸边的刷痕与一小片水痕；中：主体；远：纸白留白。空层写「无」。 |
| 【全局】 | 纸纤维、细小气泡痕、感光层斑驳。 |
| 【构图】 | 主体平铺在画面上，居中或沿对角线分布，四周留出 ≥25% 纸白；接触印相式的正投影俯拍。**不写焦距/景深**。 |
| 【镜头】 | 正俯视 90°、等效 50mm、f/8 大景深、整幅纸面清晰（或轻微边缘虚化模拟实物拍摄）。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|
| 植物图鉴 / 横版 | `16:9` 横 | `1536x1024` | 成束植物居中，左右留纸边 |
| 器物静物 / 竖版 | `9:16` 竖 | `1024x1536` | 单件器物居中偏上，下方留白 |

## 六、易翻车点（写完回查）

1. **变数码蓝调照片** → 固定节写「纸纤维、刷痕、蓝边、接触印相」，负向含「数码蓝调滤镜、单色图层」。
2. **出现彩色** → 【色彩】锁四阶蓝 + 纸白，负向含「彩色摄影、暖色」。
3. **出现体积光/投影** → 负向含「投影、体积光、光源可见」。
4. **干净得像矢量图** → 强调「水痕、斑驳、刷毛浅蓝丝路」「完美均匀的背景」进负向。
5. **出现手写编号** → 负向含「编号、手写标签、字母、数字」。
