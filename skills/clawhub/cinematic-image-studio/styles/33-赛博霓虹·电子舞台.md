# 风格卡 · 赛博霓虹·电子舞台

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `赛博霓虹·电子舞台` |
| **一句话定位** | 像在一个霓虹与激光切割出来的舞台里演唱，未来感与冲劲拉满 |
| **媒介本质** | 未来霓虹激光舞台影像（高饱和冷暖对撞 + 光效脉动）；**非**写实纪实、**非**卡通/3D塑料 |
| **与最近似风格的区别** | 与「MV电影感写实」不同：本档**霓虹激光主光、高饱和冷暖对撞、光效随拍脉动** |
| **电影级从哪来** | ① 舞台霓虹/激光主光（可解释）② 光效随 beat 脉动 ③ 烟雾/雨幕/镜面介质 ④ 多层光带景深 |

## 二、★固定节（逐字照抄）

```
【光影】主光为舞台霓虹与激光（青蓝、品红、紫、冷白对撞）且光源在画面内可解释；光效随节拍脉动（beat 同步闪动、扫光、克制的频闪）；高对比、暗部压深但保留层次
【色彩】高饱和冷暖对撞、强调色不超过两种，暗部以同色系压重并保留层次
【影像质感】未来感的霓虹激光舞台影像；轻微色带与颗粒；演唱者可见面部与口型、律动外放地开口演唱
【背景】未来舞台（LED 幕墙/雨夜霓虹街/地下空间/全息隧道/镜面空间），多层光带拉出景深；无可读文字
【风格】赛博霓虹·电子舞台：未来感霓虹激光舞台影像；演唱者可见面部与口型、律动外放地开口演唱，演唱者为虚构原创形象、不影射任何真实人物；整体冲劲、未来、有爆发力
【画幅】{9:16 或 16:9}   ← 只此两种
```

**★固定节填写要求**：命门词「**霓虹/激光主光 + 光效随拍脉动**」「**高饱和冷暖对撞**」「**可见面部口型、律动外放**」逐字不动。

## 三、★专属负向（必须并入【负向】）

```
可辨认的真实歌手面孔、明星脸、肖像相似、影射在世公众人物、
低饱和灰调、灰暗沉闷、褪色、脏色、
写实纪录片感、生活纪实平淡、
卡通、动漫、拟人卖萌、3D 塑料感、
过曝死白、纯黑死区、杂乱噪点、
英文文字、字幕、水印、标志、二维码、歌名文字、
畸形的手、多余手指、畸变、主体出框
```

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 演唱者可见面部与口型、律动外放；虚构原创（可带赛博造型：光妆/发光发丝/机械元素，克制）；说唱则手势切分清晰。 |
| 【次要元素·近/中/远】 | 近：镜面地板倒影/光带；中：演唱者；远：LED 幕墙/全息隧道。空层写「无」。 |
| 【全局】 | 烟雾/雨幕/全息光带/色带颗粒。 |
| 【构图】 | 多层光带拉出景深；主体偏三分。**不写焦距/景深**。 |
| 【镜头】 | 中景/近景；高对比。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|
| 竖屏唱歌视频 | `9:16` 竖 | `1024x1536` | 演唱者居中、霓虹环绕 |
| 横版 | `16:9` 横 | `1536x1024` | 光带景深、舞台纵深 |

## 六、易翻车点（写完回查）

1. **发灰/低饱和** → 负向含「低饱和灰调、灰暗沉闷、褪色」。
2. **过曝/死黑** → 负向含「过曝死白、纯黑死区」，主光可解释。
3. **露真人脸/影射** → 负向含「可辨认的真实歌手面孔、影射在世公众人物」。
4. **出文字** → 负向含「英文文字、歌名文字、字幕」。
