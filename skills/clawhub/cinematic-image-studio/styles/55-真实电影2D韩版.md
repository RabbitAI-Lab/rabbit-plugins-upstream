# 风格卡 · 真实电影2D韩版（明亮版）

> **给写提示词的自己**：本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。
> **v2 改动原因**：v1 出图偏昏暗沉重（暗角 + 褐调 + 浓体积光），已整体改到**日光明调**。正向里禁止出现「暗角 / 褐调 / 夜景 / 浓雾 / 低照度」。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `真实电影2D韩版`（v2 明亮版） |
| **一句话定位** | 像一部明亮的韩国二维动画电影：白天、干净、通透，人是画出来的，光像用摄影机打出来的 |
| **媒介本质** | 二维动画电影质感（细腻描线 + 干净平涂 + 柔和渐变）；**非**真人摄影、**非**三维/CG、**非**日系番剧 |
| **明暗基调** | **高调明亮（high-key）**：整体明度拉高，暗部抬亮保留细节，画面通透干净，**不做暗角、不做褐调、不做夜景压抑感** |
| **与最近似风格的区别** | 与「韩系柔和全彩」不同：本档**是二维绘制**；与「国漫生活流·二维」不同：本档**光影是电影摄影级的**（日光方向明确 + 浅景深 + 干净色块）；与「MV电影感写实」不同：本档**是画出来的**，且**整体明亮** |
| **电影级从哪来** | ① 白天日光为主光且方向可解释 ② 浅景深 + 干净空气感 ③ 韩系奶油调（米白基底 + 极轻冷青阴影 + 暖米高光）④ 真实 7 头身与克制微表情 ⑤ 色块干净的平涂层次 |

## 二、★固定节（逐字照抄）

```
【光影】白天自然日光作单一主光（落地窗日光/清晨侧光/白天散射天光/午后斜阳，光源在画面内可解释）；整体高调明亮，暗部抬亮保留细节、不发黑；浅景深轻微柔化背景；光线通透干净，不要暗角、不要浓重体积光、不要低照度
【色彩】明亮通透的韩系奶油调：米白、浅木、浅灰蓝为基底；阴影只带极轻的冷青，高光偏暖米；低饱和但明度高；强调色不超过两种；全片统一色调；不要褐调、不要灰蒙、不要高饱和大色块
【影像质感】二维动画电影质感：手绘感细腻描线配干净平涂，辅以柔和渐变过渡，色块边界清楚通透，光影关系写实但整体明亮；人物为二维绘制，非照片、非三维、非塑料 CG；画面干净细腻，不做浓重胶片颗粒与脏噪
【背景】明亮的现实空间（落地窗边的白墙房间/天光中庭/浅木色图书馆/晴日天台/白天海边/通透礼堂/晨光麦田），背景干净有层次，环境与主体同亮或更亮；无可读文字
【风格】真实电影2D韩版：二维动画电影质感，手绘感细腻描线配干净平涂与柔和渐变，日光明调高调光与浅景深，韩系奶油调低饱和高明亮，真实人体比例与克制微表情，可见面部与口型、以真实情感开口演唱；人物为虚构原创形象，不影射任何真实人物；不模仿任何现有影视作品、角色或画风；整体明亮、干净、通透，不沉重
【画幅】{3:4 或 9:16 或 16:9}
```

**★固定节填写要求**：命门词「**白天自然日光 + 高调明亮**」「**二维动画电影质感 + 手绘感细腻描线**」「**韩系奶油调低饱和高明亮**」「**明亮、干净、通透，不沉重**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可画细节**：脸型（方脸/鹅蛋脸/长脸）、颧骨、鼻梁与鼻翼、眼型（单眼皮/内双/眼裂窄）、眉形、唇厚、下颌线（不尖）、发际与发型、年龄感、体型与头身比（7 头身）、**浅色服装材质**、一个具体动作、一个具体表情。禁空词。 |
| 【次要元素·近/中/远】 | 前景（窗框/栏杆/绿植/桌面/门框，**浅色为主**）→ 中景主体 → 远层明亮空间（虚化白墙/树影/天光/人群剪影）；空层写「无」 |
| 【全局】 | 干净的空气感：极轻的浮尘或透光（克制，不超过一层）；**不写雾、不写烟、不写浓光束** |
| 【构图】 | 机位高低 + 主体站位（三分/中轴/错位半身）+ 纵深层次 + **大面积亮部留白** |
| 【镜头】 | 景别（近景/中景/全景）+ 机位角度 + 焦点落点 + 背景轻微柔化 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|

## 六、易翻车点（写完回查）

1. **出成暗调/夜景/褐调** → 正向必写「白天自然日光 + 高调明亮」，负向必含「沉重、昏暗、暗角、褐调、灰蒙、电影暗调」。
2. **浓雾浓光束糊满屏** → 负向必含「浓重体积光、烟雾弥漫、光束浓雾」；【全局】只许写极轻空气感。
3. **变回真人照片/写实摄影** → 负向必含「照片质感、真人摄影、皮肤毛孔」，正向锁「二维动画电影质感、手绘感细腻描线」。
4. **掉成 3D/CG 塑料感** → 负向必含「3D 建模、3D 渲染、塑料感」。
5. **掉成日系番剧脸** → 负向必含「日系番剧脸、大眼萌、锥子脸、赛璐璐高光」，正向锁「真实 7 头身与亚洲人骨相」。
6. **口型不可见** → 【主体】必须写「嘴部完整可见且张开正在演唱」。
