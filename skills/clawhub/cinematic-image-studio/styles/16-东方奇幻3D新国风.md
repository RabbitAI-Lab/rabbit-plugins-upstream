# 风格卡 · 东方奇幻·3D新国风

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `东方奇幻·3D新国风` |

```
【光影】PBR 写实材质光照：真实物理光照与反射；法术/神性以高亮度特效光表现；低饱和基底衬托高饱和特效
【色彩】朱砂红（火/躁动）× 石青蓝（冰/克制）两大主色冷暖对冲；辅以鎏金/墨黑/玉白；环境偏灰土/墨色低饱和，法术与特效用高亮度艳色；色彩带情绪（红=暴烈威压，青蓝=幽远神性，金=上古王权）
```

**★固定节填写要求**：命门词「**PBR 写实材质 × 卡通夸张造型**」「**朱砂红 × 石青蓝冷暖对冲**」「**东方意象化特效（非西式魔法）**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 单主体（异兽/神祇/人物）；**数量特征**（多首多目多尾）必须结构清楚地数得出来、各首各尾姿态不同；纹样取材青铜饕餮/云雷/卷云（重组非临摹）；眼睛高饱和发光虹膜。 |
| 【次要元素·近/中/远】 | 云气/星象/祭坛/山水留白分层；空层写「无」。 |
| 【全局】 | 云气盘旋/法术粒子/浮尘（东方意象化）。 |
| 【构图】 | 主体占视觉中心；雕塑感；留白或云气造境。**不写焦距/景深**。 |
| 【镜头】 | 中景/远景；可环绕感。 |

### 变体区别
- **异兽版**：相柳九首/三足乌/九尾狐等数量特征；火浪/冰棱/卷云气流特效。
- **神祇版**：宝相庄严 + 神通法术奇观（见 `styles/21-东方奇幻3D新国风神祇.md`）。
- **漫剧版**：神话/仙侠/封神/西游；角色驱动叙事。

## 六、易翻车点（写完回查）

1. **画成二维/水墨** → 负向含「二维手绘、扁平插画、赛璐璐、水墨单色」。
2. **西式奇幻味** → 负向含「西式魔法光球、魔法阵、西方巨龙、哥特、赛博朋克」。
3. **数量特征崩坏** → 负向含「结构糊成一团、多首粘连、多尾融合」。
4. **恐怖谷/真人写实** → 负向含「照片写实人脸、恐怖谷、真人皮肤」。
