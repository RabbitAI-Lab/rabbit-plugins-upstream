## 四、逐图可变节（每次重写）

| 节 | 怎么写 |

| 【主体】 | **≥8 个可拍摄细节**：主仙（虚构的东方天界仙女，无真实原型）——确切的髻饰（点翠/鎏金步摇/珠翠花钿/额心朱砂）、衣裙（宝青与朱红云锦、广袖、缎面流光）、飘带（数条、朱红与月白）、舞姿与朝向、神态；**末尾必须写「身形占画面高度约三分之二，是画面唯一视觉主体，位于近景前景层」**（近景大主体是本卡的命门）。 |
| 【次要元素·近/中/远】 | 近：主仙脚下与两侧的白玉云台 + 鎏金雕栏 + 极小的捧盘仙官或白鹤（高不及主仙膝部，作尺度锚点）；中：主仙身后的白玉天阶与层叠云台、分层沿阶散开的群仙（数十~数百，大小递减）；远：巍峨天门 + 白玉盘龙巨柱 + 层层宫阙玉宇与浮空仙山悬于云海、没入天光；空层写「无」。 |
| 【全局】 | 满屏翻涌云海 + 少量飘落花瓣 + 仙光光尘（**少量**，别塞满）—— **与【镜头】景深自洽**。 |
| 【构图】 | 近景主体 + 宏大背景：机位与主仙胸线齐平、略低仰拍（想更大可略升高、后拉取广角）；主仙居中轴或三分、占画面高约 2/3；其身后天阶群仙向纵深推开、巨柱天门次第耸立、云海宫阙退至极远地平线；**五层起步纵深，想更大就加到六~七层**（主仙→近景云台→群仙→天阶→巨柱与天门→浮空宫阙仙山→云海天际线）；上缘留白作天光；**不写焦距/景深**。 |
| 【镜头】 | 默认中景 **35mm + f/5.6 中景深**（近景主体清晰、背景适度虚化）；**要更大场面**改用 **24mm 广角 + f/5.6**，让近景主体与极远背景同框；只有纯特写才用 50mm + f/2.8。 |

## 六、易翻车点（写完回查）

1. **太白、寡淡** → 【色彩】坚持「高饱和、浓郁厚重、不发白」；负向含「苍白、灰白、褪色、色彩寡淡、低饱和、整体发白」。
2. **主体太远、太小** → 【主体】写死「占画面高度约三分之二、位于近景前景层」；【构图】写「机位与主仙胸线齐平」；负向含「主体过小、主体离镜头过远、主体不清晰」。
3. **金色又泛滥** → 【色彩】写「鎏金作中量描边与柱头宫灯点缀（不再满屏鎏金）」；负向含「过量金色、满屏鎏金、金碧辉煌、金色泛滥」。
4. **场面局促、背景单薄** → 【构图】把纵深写到五层以上；负向含「场面局促、视野狭窄、背景单薄、缺乏纵深、格局小、取景太近、缺少远景」。
5. **画成西式天堂 / 仙女变真人** → 负向含「西式天堂、天使翅膀、天使光环、照片写实人脸、仙女变写实真人」；【背景】写「凌霄宝殿：白玉蟠龙云柱、藻井云雷纹」。
6. **人多糊成一团、比例崩坏** → 群仙写「分层、大小递减、姿态各异」；主仙清晰锐利、群仙压后；负向含「人多糊成一团、比例崩坏、漂浮无重力」。
