# 风格卡 · 青花瓷绘·群仙（白地青花 · 分水渲染 · 釉面）

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `青花瓷绘·群仙` |
| **一句话定位** | 把天庭群仙画在一件青花瓷器上——白地青花、分水浓淡、釉面泛光 |
| **媒介本质** | 青花**瓷绘**（钴蓝料在瓷胚上勾线 + 分水渲染 + 罩釉烧成）；**非**纸面水墨、**非**油画、**非**3D |
| **与最近似风格的区别** | 与「水墨写意/彩色水墨」不同：本卡是**瓷面**、单色**钴蓝**、层次靠「分水浓淡（头浓/正浓/二浓/正淡/影淡）」而非墨色；有**釉面细光泽与开片**；与「螺钿/漆艺」不同：本卡是**白地青花**。 |
| **质感从哪来** | ① 白釉地留白 ② 钴蓝发色 + 分水渐层 ③ 釉面细亮高光与开片 ④ 缠枝卷草边饰 |

## 二、★固定节（逐字照抄）

```
【光影】瓷面柔光；以钴蓝分水浓淡表现层次与体积（非写实体积光）；釉面细亮高光、边缘有轻微开片与窑变；无强投影、无彩色光
【色彩】单色钴蓝（青花）为主、白釉地子大量留白；以「分水五色」——头浓、正浓、二浓、正淡、影淡——分出深浅层次；可极淡釉里红作点缀；整体清雅、蓝白两色、无彩
【影像质感】青花瓷绘质感：白釉地、钴蓝发色、勾线后分水的手绘笔触与轻微晕散、釉面细光泽与开片冰裂；非纸面、非油画、非3D、非塑料
【背景】天宫以青花线描与分水写出：缠枝莲、卷草、云纹、宫阙门柱作纹样式排布，边饰成圈；无文字
【风格】中国青花瓷绘：白地青花、分水浓淡、缠枝卷草边饰、釉面泛光；东方瓷器美学、清雅规整；非纸面水墨、非彩色、非油画、非3D、非写实照片
【画幅】16:9
```

**★固定节填写要求**：命门词「**白釉地 + 单色钴蓝**」「**分水五色（头浓/正浓/二浓/正淡/影淡）**」「**釉面细光泽与开片**」逐字不动。

| 【次要元素·近/中/远】 | 近：缠枝莲/蕉叶纹边饰；中：群仙与天宫门柱；远：卷草云纹分层；空层写「无」 |

## 六、易翻车点（写完回查）

1. **画成纸面水墨（有墨色/笔触）** → 负向含「纸面水墨、宣纸、墨色」；【影像质感】锁定「白釉地 + 钴蓝分水 + 釉面开片」。
2. **加彩/五彩** → 负向含「彩色、五彩、大红大绿」；【色彩】锁定「单色钴蓝 + 白地」。
3. **青花糊成黑团/浓淡不分** → 负向含「钴蓝糊成黑团、浓淡不分」；【光影】写「分水五色分层次」。
4. **变照片/3D** → 负向含「照片写实、3D渲染、CG塑料感」；【影像质感】锁「瓷绘手绘笔触」。
