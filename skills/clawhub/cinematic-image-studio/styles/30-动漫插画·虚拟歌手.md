# 风格卡 · 动漫插画·虚拟歌手

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `动漫插画·虚拟歌手` |
| **一句话定位** | 像一段柔焦插画世界里的虚拟歌手演唱，轻盈唯美、干净梦幻 |
| **媒介本质** | 柔焦插画轻动画（插画平涂 + 柔和渐变 + 细微颗粒）；**非**写实真人、**非**3D塑料 |
| **与最近似风格的区别** | 与「梦幻唯美·插画轻动画」不同：本档**虚拟歌手可见面部口型、开口演唱**；与写实 MV 不同：插画质感 |
| **电影级从哪来** | ① 柔和主光 + 大量光斑星点 ② 轻盈辉光/镜头光晕 ③ 背景柔焦虚化 ④ 梦幻场景流转 |

## 二、★固定节（逐字照抄）

```
【光影】柔和主光 + 大量光斑/星点/微尘介质 + 轻盈辉光与镜头光晕；喜明亮通透，勿阴沉；背景柔焦虚化
【色彩】粉紫暖橘奶油白为主、强调色不超过两种，色彩柔和高饱和、干净不发灰
【影像质感】柔焦插画质感的轻动画影像：插画平涂加柔和渐变与细微颗粒；虚拟歌手造型带克制的虚拟偶像元素（发光发丝/飘带/耳饰/星星瞳）；非写实、非塑料
【背景】梦幻插画世界（云端舞台/星空/花海/水镜/发光森林/房间窗台）；无可读文字
【风格】动漫插画·虚拟歌手：柔焦插画质感轻动画；虚拟歌手可见面部与口型、轻盈唯美地开口演唱，造型带克制的虚拟偶像元素，演唱者为虚构原创角色、不影射或模仿任何真实人物与现有知名角色；整体唯美、干净、梦幻
【画幅】{9:16 或 16:9}   ← 只此两种
```

**★固定节填写要求**：命门词「**柔焦插画轻动画（非写实、非塑料）**」「**虚拟歌手可见面部与口型**」「**虚构原创、不模仿现有动漫角色**」逐字不动。


## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 虚拟歌手可见面部与口型、开口演唱；虚构原创（二次元角色）；轻盈元气或唯美。 |
| 【次要元素·近/中/远】 | 前景光斑/漂浮物 → 中景歌手 → 远层梦幻场景。空层写「无」。 |
| 【全局】 | 光斑/星点/微尘/辉光。 |
| 【构图】 | 主体偏三分；背景柔焦。**不写焦距/景深**。 |
| 【镜头】 | 中景/近景；柔焦。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|
| 竖屏唱歌视频 | `9:16` 竖 | `1024x1536` | 歌手居中、光斑环绕 |
| 横版 | `16:9` 横 | `1536x1024` | 梦幻场景纵深 |

## 六、易翻车点（写完回查）

1. **画成写实真人** → 负向含「写实真人、真实歌手面孔」。
2. **模仿现有角色** → 负向含「模仿现有知名动漫角色」。
3. **3D 塑料感** → 负向含「3D 塑料感、写实毛发」。
4. **发灰** → 负向含「灰暗低饱和、脏色」。
