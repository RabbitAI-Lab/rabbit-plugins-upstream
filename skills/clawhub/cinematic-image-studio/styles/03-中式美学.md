# 风格卡 · 中式美学 × 唐卡 × 水墨（新中式东方意境 · 电影级 · v3.0）

> **给写提示词的自己**：本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `中式美学` |
| **一句话定位** | 用电影语言拍出的东方意境 × 唐卡装饰 × 水墨墨韵——**静、雅、华、空、润** |
| **媒介本质** | **电影级东方美学影像**（photoreal cinematic Chinese aesthetic）+ **唐卡装饰层** + **水墨氛围层**，**不是**绘画、**不是**动漫、**不是**游戏原画 |
| **与「彩色水墨」的区别** | 彩墨是**中国画·彩墨**的绘画媒介（通幅笔触、宣纸纤维）；本卡是**影像介质**——真实材质与布光，**水墨只作远景、云气与留白边缘的氛围层**，绝不把主体画成墨稿。 |
| **与「纯平唐卡绘画」的区别** | 唐卡是**平涂重彩的布面宗教画卷**（无景深、无真实光影）；本卡只借唐卡的**描金细线、圆形头光、宝相花纹样**，其余仍是电影级摄影。 |
| **与「纯水墨画」的区别** | 水墨画是**黑白/彩墨的绘画**；本卡**主体保持真实材质**，只把水墨的**淡墨晕染、飞白、计白当黑**作为**背景与空气感**。 |
| **电影级从哪来** | ① 单一主光 + 柔和光比 + 轮廓光 + **头光/背光**；② 虚实＝景深；③ 宽银幕 + 大面积负空间（计白当黑）+ **曼陀罗式对称**；④ 唐卡矿物色 + 水墨墨韵 + 胶片颗粒 + 一级调色 |

## 二、★风格元素清单（唐卡 + 水墨，本风格的辨识度所在）

> 「加唐卡 + 加水墨」= 把下列元素**克制地**用在画面里，**不是**把画面画成唐卡或水墨画。**推荐一次用 2–3 样，宁少勿多**。

### 唐卡元素

| 元素 | 怎么写 | 落在哪一节 |
|---|---|---|
| **描金细线** | 衣饰、甲胄、器物、纹样的边缘走一道**唐卡式的极细描金线** | 【影像质感】 |
| **圆形头光 / 背光** | 主体身后一轮**外缘描金、内里石青石绿渐次晕染**的圆光，透出神性 | 【光影】 |
| **宝相花 / 卷草纹 / 祥云纹** | 作边饰与背景纹样，**只作装饰、不出现任何文字** | 【装饰】【背景】 |
| **曼陀罗式对称** | 纹样与场景排布遵循**中心对称 / 四向均衡** | 【装饰】【构图】 |
| **矿物重彩点缀** | 石青、石绿、朱砂、雄黄、蛤白、藏金，**集中于纹样与描金处** | 【色彩】 |
| **宝石镶嵌微光** | 冠、璎珞、法器的**青金石 / 珊瑚 / 松石镶嵌**，反射一点微光 | 【影像质感】 |

### 水墨元素

| 元素 | 怎么写 | 落在哪一节 |
|---|---|---|
| **淡墨晕染** | 远山、云气、雾霭以**淡墨层层晕染、浓淡分明** | 【背景】【色彩】 |
| **飞白与墨色洇痕** | 留白与远雾的边缘见**少量枯笔飞白与墨色洇开** | 【影像质感】【全局】 |
| **计白当黑** | 水墨式的**留白经营**——留白即气，绝不塞满 | 【构图】 |

> **⚠️ 水墨的边界（命门）**：水墨**只做"氛围层"**——用在**远山、云气、雾霭、留白边缘**。
> **主体（人、甲、器物、神兽）一律保持真实材质与电影光影，不得画成墨稿、不得通幅毛笔笔触。**

## 七、易翻车点（写完回查）

1. **画成纯平唐卡布面画** → 【影像质感】的"电影级摄影质感 + 真实材质反射 + 景深"必须在；【风格】保留"非纯平唐卡布面画"；专属负向的"纯平唐卡布面画、布本唐卡、无光影平涂"必须在。
2. **水墨加太多，整张变水墨画 / 主体变墨稿（本版头号翻车）** → 水墨**只用于远山云气与留白边缘**；【主体】写真实材质（丝绸/青铜/玉）；负向含"纯水墨画、黑白水墨画、通幅毛笔笔触、墨稿、墨色压满主体"。
3. **纹样塞满、宝相花抢戏** → 【装饰】【背景】写"只作装饰、边饰、背景纹样"，**宁少勿多**；负向含"纹样塞满、花纹喧宾夺主、描金糊成金块"。
4. **饱和艳俗 / 全身重彩** → 【色彩】"唐卡矿物色作点睛、低饱和雅致"必须保留；负向含"色彩艳俗、饱和艳俗"。
5. **唐卡咒文 / 经文 / 藏文混进来** → 红线：零可读文字。【背景】【装饰】明写"不出现任何文字"；负向含"咒文、经文、藏文、可读文字"。
6. **画面塞满、无留白** → 【构图】明确写留白位置与占比（四成以上，计白当黑）。
7. **塑料感 / 廉价 3D** → 负向补"3D 渲染、CG 塑料感、塑料反光"；【影像质感】写"真实纹理纤毫可见、哑光反射"。
8. **头光画成僵硬的光圈 / 广告光效** → 【光影】写"圆形头光/背光，外缘描金、内里由石青石绿渐次晕染、透出神性辉光"，与真实主光**并存不冲突**。
