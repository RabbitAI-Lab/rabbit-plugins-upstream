# 风格卡 · 永乐宫·朝元图（元代道教群仙壁画 · 工笔重彩 · 沥粉贴金）

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `永乐宫·朝元图` |
| **一句话定位** | 把天庭群仙画成一幅元代道教壁画——群仙分列朝拜、肃穆宏大、工笔重彩沥粉贴金 |
| **媒介本质** | 元代道释**壁画**（工笔重彩 + 沥粉贴金 + 墙面质感）；**非**敦煌西域经变、**非**3D、**非**动画 |
| **与最近似风格的区别** | 与「敦煌金彩」（18）不同：18 是**西域经变、斑驳残壁、矿物艳色散涂**；本卡是**中原道观壁画、铁线描挺劲、色块平涂规整、沥粉金线突起、群像成列**；与「绢本工笔」（15）不同：本卡是**墙面重彩大场面**、非绢上白描雅致。 |
| **气势从哪来** | ① 群像分列纵深、队列规整 ② 主仙居上大小有别 ③ 大色块排布 + 沥粉金线 ④ 低机位仰视、天花云气 |

## 二、★固定节（逐字照抄）

```
【光影】平涂为主、弱体积光影；以铁线描与色块分面，不追求写实体积光；沥粉金线在暗部微微凸起发亮、贴金处随光反光；无强投影、无戏剧性光比
【色彩】中原工笔重彩：石青、石绿、朱砂、赭石、藤黄、蛤白六大色，配大量沥粉贴金（明亮非哑旧金）；色相庄重饱和、以大色块平涂排布；金线与朱砂作华彩；统一于青绿与朱红
【影像质感】元代道观壁画质感：凹凸沥粉勾线、金箔贴附、矿物色层层平涂、墙面细纹与轻微剥落；工笔挺劲铁线描；线条清晰、色块干净；非3D、非塑料、非数码插画
【背景】天庭朝会道场：幡幢、华盖、瑞兽、宫阙门柱与云气成列并列；群像分列纵深、层层退后；无可读文字
【风格】元代道教「朝元图」壁画：群仙分列朝拜、大场面规整排布、工笔重彩 + 沥粉贴金、肃穆庄严；非敦煌西域经变、非3D、非日式动漫、非扁平插画、非写实照片
【画幅】16:9
```

**★固定节填写要求**：命门词「**中原工笔重彩、铁线描挺劲**」「**群像分列成列（朝元图队列）**」「**沥粉贴金金线突起**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 主仙与群仙：主仙居视觉中心、身形略大（虚构的东方天界仙女，无原型）——高髻饰珠、朱红石青重彩礼服、璎珞、广袖；群仙分两侧成列、姿态各异、身形递减；末尾「是画面唯一视觉主体」 |
| 【次要元素·近/中/远】 | 近：幡幢/华盖/香炉；中：群仙列队与宫阙门柱；远：云气与庑殿顶；空层写「无」 |
| 【全局】 | 云气/幡带/落花（少量）——与平涂光影自洽 |
| 【构图】 | 中轴或对称分列，主仙居中偏上、群仙左右成列向纵深排开；**不写焦距/景深** |
| 【镜头】 | 全景/大远景，低机位仰视，平板块面无强烈景深 |

## 六、易翻车点（写完回查）

1. **画成敦煌风** → 负向含「敦煌经变、西域凹凸花、斑驳残破」；【影像质感】写「线条清晰、色块干净、沥粉金线突起」。
2. **3D/动漫感** → 负向含「3D渲染、CG塑料感、卡通、日系动画」；【影像质感】锁定「工笔铁线描 + 平涂色块」。
3. **人物糊成一团/写实真人** → 负向含「糊成一团、写实人脸」；【主体】写「主仙居中心、群仙成列身形递减、姿态各异」。
4. **画面脏暗发灰** → 负向含「脏色、发灰、昏暗」；【色彩】锁定「色块平涂、金线明亮」。
