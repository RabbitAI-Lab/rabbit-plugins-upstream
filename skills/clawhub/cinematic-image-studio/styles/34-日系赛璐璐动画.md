# 风格卡 · 日系赛璐璐动画

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `日系赛璐璐动画` |
| **一句话定位** | 一眼就是"动画番剧"，不是 3D、不是 CG、不是真人照片 |
| **媒介本质** | 二维日系赛璐璐动画（描线 + 平涂 + 硬边二分阴影）；**非**三维/CG/写实/厚涂 |
| **与最近似风格的区别** | 与「韩系柔和全彩」不同：本档**描线平涂硬边**，韩系是柔光低对比人像；与3D国风不同：纯二维 |
| **电影级从哪来** | ① 均匀描线勾边 ② 硬边二分阴影块 ③ 干净高光形状块 ④ 冷暖分区 |

## 二、★固定节（逐字照抄）

```
【光影】高饱和平涂 + 硬边二分阴影块；高光为干净形状块；可加网点与排线；色彩明快干净、冷暖分区清楚；动画感特效（速度线/集中线/网点/闪白）
【色彩】高饱和平涂为主；硬边阴影块；冷暖分区清楚
【影像质感】纯正二维日系动画番剧质感：均匀清晰的描线勾边、发丝分组成束；平涂 + 硬边二分阴影；可加网点与排线；明确为 2D 动画
【背景】动画场景（线稿 + 平涂）；无可读文字（画面文字只可能是规范简体中文，最好零文字）
【风格】整幅画面的画风严格与「日系赛璐璐动画」一致：纯正二维日系动画番剧质感，均匀清晰的描线勾边、发丝分组成束；高饱和平涂为主，硬边二分阴影块，高光为干净形状块；明确为 2D 动画，非三维、非 CG、非真人写实；全画面同一套赛璐璐美术
【画幅】{9:16 或 16:9}   ← 只此两种
```

**★固定节填写要求**：命门词「**均匀描线 + 平涂 + 硬边二分阴影**」「**明确 2D 动画**」逐字不动。

## 三、★专属负向（必须并入【负向】）

```
三维渲染、3D 建模、CG 渲染、写实照片、真人写实、照片质感、厚涂、半厚涂、
柔光、体积光、电影级柔焦、低对比、灰调、脏色、糊、塑料感、恐怖谷、
英文文字、拉丁字母、拼音、乱码文字、水印、标志、
畸形的手、多余手指、造型不一致、面部模糊、背景杂乱
```

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 动画角色：发丝分组成束、平涂、硬边二分阴影、高光形状块；服饰平涂；不写写实皮肤纹理。 |
| 【次要元素·近/中/远】 | 动画场景分层（线稿+平涂）；空层写「无」。 |
| 【全局】 | 速度线/集中线/网点/闪白（动画感特效）。 |
| 【构图】 | 番剧式构图。**不写焦距/景深**。 |
| 【镜头】 | 动画镜头；无写实景深。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|
| 竖屏漫剧/番剧 | `9:16` 竖 | `1024x1536` | 角色居中、动势 |
| 横版 | `16:9` 横 | `1536x1024` | 场景全景 |

## 六、易翻车点（写完回查）

1. **落成 3D/CG/写实** → 负向含「三维渲染、CG 渲染、写实照片、真人写实」。
2. **柔光低对比** → 负向含「柔光、体积光、低对比」，锁定硬边二分阴影。
3. **造型不一致/手崩** → 负向含「造型不一致、多余手指、畸形的手」。
4. **出英文** → 负向含「英文文字、拉丁字母、拼音」。
