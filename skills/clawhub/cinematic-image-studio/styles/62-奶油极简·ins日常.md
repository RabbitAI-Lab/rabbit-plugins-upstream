# 风格卡 · 奶油极简·ins 日常

> **给写提示词的自己**：本卡 ★固定节 的字段必须**逐字照抄**，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `奶油极简·ins 日常` |
| **一句话定位** | 奶油白空间 + 单侧窗光 + 大留白的当代生活美学，干净、松弛、不摆拍 |
| **媒介本质** | 现代数码中画幅**室内实拍**（自然光），非复古胶片、非插画、非 3D |
| **与最近似风格的区别** | 与「复古胶片」（24）不同：**画面干净、无暖黄颗粒、无做旧**；与「手账拼贴」（61）不同：**信息极简、单主体、大留白**；与「韩系柔和」（35）不同：**不是人物动画，硬光窗影更明确** |
| **电影级从哪来** | ① 单侧硬光形成有边界的窗棂投影 ② 低饱和高明度的统一影调 ③ 留白经营出呼吸与秩序 ④ 材质（亚麻、陶土、藤编）的真实细节 |

## 二、★固定节（逐字照抄）

```
【光影】左或右侧 45° 单向自然窗光为唯一主光，窗棂投影清晰地落在墙面与织物上，边缘略软；室内以大面积白墙作天然反光板，暗部提亮至浅灰、光比约 1:3；无补光灯、无彩色环境光；色温约 4800–5200K 的中性偏暖
【色彩】奶油白（#F7F3EC）、燕麦（#E8DFD1）、浅灰（#D9D6D0）铺满 80% 以上，雾粉（#E7C9C2）作第二层，焦糖/陶土色（#B5825C）只作一处点睛；饱和度低、明度高、对比柔和
【影像质感】现代数码中画幅室内实拍：细节清洁锐利、过渡柔和、极轻的胶片颗粒；墙面可见细微乳胶漆纹理、亚麻织物有清晰经纬、陶瓷有哑光釉面反射；不做旧、不压暗、不加滤色
【背景】极简室内：奶油色墙面、亚麻床品或桌布、藤编/原木家具、白瓷与陶土器皿、一株细叶绿植；墙面留白 ≥40%
【风格】奶油极简 ins 生活美学，单侧窗光与清晰窗影，低饱和暖白调与大留白，松弛干净的当代日常；非复古胶片、非高饱和、非繁复堆叠
【画幅】{9:16}
```

**★固定节填写要求**：
- 命门词「**单侧 45° 窗光 + 清晰窗棂投影**」「**奶油白 + 燕麦 + 一处焦糖点睛**」「**留白 ≥40%**」逐字不动。
- 色号、光比、颗粒量不许改；只允许替换室内陈设与主体物件。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：物件/场景的确切名称与状态（如亚麻床单的褶皱走向、白瓷杯的釉面与杯沿厚度、托盘的原木纹理、面包的裂纹）、颜色与材质、摆放位置与朝向、数量、光影落在哪、是否有手部入镜（虚构人物仅露手）。 |
| 【次要元素·近/中/远】 | 近：织物边缘/托盘一角；中：主体物件组；远：奶油墙面与窗框。空层写「无」。 |
| 【全局】 | 空气里极淡的浮尘、窗影中的细微光斑。 |
| 【构图】 | 竖构图、主体偏下三分之一或右侧三分线，上方留出大片墙面（≥40%）；正对或被摄物的 15° 侧向。**不写焦距/景深**。 |
| 【镜头】 | 等效 35–50mm、f/4、中等景深、主体清晰、背景墙面保持干净不虚化过度。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|
| 早餐/床景 | `9:16` 竖 | `1024x1536` | 物件在下三分之一，上方墙面留白 |
| 穿搭/家居 | `9:16` 竖 | `1024x1536` | 主体偏右三分线，窗影斜切左上 |
| 探店空镜 | `16:9` 横 | `1536x1024` | 主体偏左，右侧留白与窗 |

## 六、易翻车点（写完回查）

1. **变成复古胶片** → 固定节必须是「中性偏暖 4800–5200K、干净、极轻颗粒」，负向含「复古胶片暖黄、做旧」。
2. **窗影没有形状** → 强调「窗棂投影清晰落在墙面与织物上」。
3. **画面塞满变杂乱** → 【构图】强制「留白 ≥40%」，负向含「杂物凌乱、繁复堆叠」。
4. **高饱和破坏奶油调** → 【色彩】给面积比与「一处焦糖点睛」，负向含「高饱和撞色、荧光色」。
5. **太假白像 CG** → 负向含「过度修图假白、3D 渲染、塑料 CG」。
