# 风格卡 · 温馨亲子绘本

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `温馨亲子绘本` |
| **一句话定位** | 暖色手绘儿童绘本插画，柔和光线下的居家日常，像睡前故事书里被翻到的那一页 |
| **媒介本质** | 手绘绘本（水彩晕染 + 彩铅颗粒 + 蜡笔涂痕）；**非**写实、**非**厚重 3D、**非**塑料感高光 |
| **与最近似风格的区别** | 与「动漫插画」不同：**圆润软糯的绘本人形、豆豆眼，非二次元夸张大眼**；与水彩写实不同：造型大头小身、简化五官 |
| **电影级从哪来** | ① 大面积柔光光晕而非锐利高光 ② 清晰的眼神/动作方向 ③ 留白充足 ④ 奶油纸纹质感 |

## 二、★固定节（逐字照抄）

```
【光影】柔和光线：清晨窗帘缝斜光／午后落地灯暖黄／夜里小夜灯微光；大面积柔和渐变光晕代替锐利高光；光比极柔、无硬边阴影；色温暖
【色彩】暖米白纸纹底（#FFF8EE / #FDF3E3）≥50%，柔暖橙 + 奶油黄（#F6A96B / #FFD98E）20–30%，藕粉／薄荷绿／雾霾蓝合计 15–25%，浅木棕 + 暖灰做结构线与文字；暖而不腻、靠留白透气
【影像质感】奶油纸纹底上的水彩晕染与彩铅颗粒、蜡笔涂痕；造型圆润简化、大头小身、豆豆眼与红脸蛋、轻微抖动的手绘轮廓线；无写实照片感、无厚重3D、无塑料高光、无脏旧纹理
【背景】暖色居家日常场景（客厅地垫／沙发／餐桌／卧室小床／玩具角），抽象化、简洁，亮度永远低于主体；无文字
【风格】温馨手绘儿童绘本插画，柔光治愈、暖而不腻，圆润软糯的绘本人形（非二次元、非写实）；主体大、占据画面视觉中心，留白充足；非写实照片、非厚重3D
【画幅】{16:9 或 9:16}   ← 只此两种
```

**★固定节填写要求**：命门词「**奶油纸纹底 + 水彩晕染彩铅颗粒**」「**圆润简化大头小身**」「**柔光光晕**」逐字不动；光线档（晨/午/夜）每图可换，同段落不混光。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 细节**：绘本人形（大头小身、豆豆眼、红脸蛋、简化五官，宝宝约 1:2.5 头身）+ 姿态动作方向 + 居家物件。人物与主题强相关，真实面孔禁止。 |
| 【次要元素·近/中/远】 | 按前景（地垫/玩具）→ 中层主体 → 远层墙面/窗。空层写「无」。 |
| 【全局】 | 晨雾/浮尘/柔光光斑、窗影 —— 与柔焦自洽。 |
| 【构图】 | 主体大、占视觉中心；眼神/动作方向清楚；留白充足。**不写焦距/景深**。 |
| 【镜头】 | 中景/近景为主，浅景深柔焦（可写 f/2.8 柔和虚化）。 |

## 六、易翻车点（写完回查）

1. **画成写实/3D** → 【影像质感】保留「水彩晕染 + 彩铅颗粒 + 奶油纸纹」，负向含「写实照片感、3D 塑料感」。
2. **画成二次元大眼** → 负向加「二次元夸张大眼、动漫风」，强调「豆豆眼」。
3. **暖成一团橘黄** → 控制橙色饱和、靠留白纸纹透气；负向加「高饱和大乱闪」。
4. **出现文字/说教** → 负向含「文字、说教与育儿结论」。
