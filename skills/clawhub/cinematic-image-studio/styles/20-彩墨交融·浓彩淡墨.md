# 风格卡 · 彩墨交融·浓彩淡墨

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `彩墨交融·浓彩淡墨` |
| **一句话定位** | 以浓彩为骨、薄墨为线，把圣像画成一幅浓艳饱和、通透明亮的彩墨画 |
| **媒介本质** | 彩墨画（矿物彩 + 植物彩，宣纸/绢面晕染交融、破彩）；**非**纯水墨、**非**淡粉彩 |
| **与最近似风格的区别** | 与「彩色水墨」不同：本档**色彩是绝对主角、墨只作细线配角**；与「敦煌壁画」不同：本档**纸面彩墨晕染**而非斑驳壁面 |
| **电影级从哪来** | ① 色相纯正、饱和度极高 ② 浓墨重彩晕染交融 ③ 上重下轻 ④ 亮彩光晕背光 |

## 二、★固定节（逐字照抄）

```
【光影】低机位仰视，光自圣像身后与上方洒落；背光化作亮彩光晕；色浓度高、薄彩层叠提亮；高光克制、亮部保留彩墨内层次
【色彩】高饱和浓艳彩色基调：朱砂（红）、石青（蓝）、石绿、藤黄、胭脂、群青、赭石、翠绿提亮、金为点睛——色相纯正、饱和度极高、浓郁饱满、鲜艳夺目、通透明丽；墨色从简（只作淡墨细线勾骨 + 轻墨点景）；禁止大面积焦墨/浓墨/死黑；留白只作"气口"、不得把彩色冲淡成粉彩/水彩淡色；主体的彩度永远最高
【影像质感】彩墨交融：高饱和矿物彩与植物彩在宣纸/绢面上晕染交融、彼此破彩；淡墨细线勾骨；通透明丽、薄彩层叠；非3D、非塑料感
【背景】道场即神圣地：灵山/净土宝台/莲池/云海/石窟洞口/寺塔之前/须弥座上；纵深至少三层；道场以淡彩与留白处理、彩度与细节永远低于圣像；无可读文字
【风格】彩墨交融、浓墨重彩：色彩是画面绝对主体；淡墨细线勾骨、轻墨点景、留白只作气口；圣像宝相以浓艳饱和的彩墨写出、身后头光身光呈亮彩光晕；低机位仰视、圣像居上、众生渺小如尘；明快华美、响亮明艳；非黑白水墨、非单色水墨、非纯墨无彩
【画幅】{16:9 或 9:16}   ← 只此两种
```

**★固定节填写要求**：命门词「**色彩是绝对主角、墨只作淡墨细线**」「**高饱和浓艳（色相纯正、饱和度极高）**」「**无大面积焦墨死黑**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 圣像宝相以浓艳饱和彩墨写出、璎珞天衣彩墨淋漓；主色彩度最高最亮最饱和；不拟人化卖萌。 |
| 【次要元素·近/中/远】 | 上方圣像/彩云 → 中景道场云气 → 下方众生（极小、退后靠淡彩+留白明度差）。空层写「无」。 |
| 【全局】 | 彩云/花雨/香烟/浮尘。 |
| 【构图】 | 恒"上重下轻"；圣像占上部、众生压底。**不写焦距/景深**。 |
| 【镜头】 | 低机位仰视；中远景/大远景。 |

## 六、易翻车点（写完回查）

4. **真人面孔/性化** → 负向含「真人面孔、明星脸、性化、暴露」。
