# 风格卡 · 敦煌金彩·壁画圣像

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `敦煌金彩·壁画圣像` |
| **一句话定位** | 把佛教圣像放回敦煌经变画里，一眼"神在浓彩金光中俯视人间" |
| **媒介本质** | 敦煌经变壁画（矿物颜料 + 金箔 + 千年斑驳壁面）；**非**卡通/插画/3D |
| **与最近似风格的区别** | 与「彩墨交融」不同：本档**壁画质感 + 斑驳壁面 + 金箔**；与「石窟造像」不同：本档**平面壁画**而非石刻 |
| **电影级从哪来** | ① 低机位仰视、上重下轻 ② 背光（头光+身光）洒落 ③ 明暗对比大而不碎 ④ 矿物颗粒与金箔肌理 |

## 二、★固定节（逐字照抄）

```
【光影】低机位仰视，光自圣像身后与上方洒落；背光（头光 + 身光）圆轮；尘世暗而圣像亮、圣像为画面最亮处；明暗对比大而不碎；高光克制、亮部保留金箔内细节
【色彩】高饱和鲜亮矿物颜料：石青（蓝）、石绿、石黄、朱砂（红）、赭石、蛤白——色相纯正、饱和度高、浓艳响亮；金身与金光为高光强调，金箔明亮富丽（非哑灰旧金）；强调色不超过两种；尘世可压暗但不得整体降饱和、不得褪色发灰
【影像质感】敦煌经变壁画质感：壁面千年斑驳、颜料剥落、金箔磨损、烟熏痕；矿物颜料颗粒肌理；花雨/天乐/祥云/飞天/璎珞垂串作神圣空气介质；非3D、非塑料感
【背景】道场即神圣地：灵山/净土宝台/莲池/云海/敦煌洞窟/石窟崖壁/寺塔之前/须弥座上；纵深至少三层（右上圣像高悬→中景道场云气→下方众生极小）；无可读文字
【风格】敦煌经变壁画质感：圣像金身宝相庄严、璎珞天衣垂落、身后头光身光圆轮；低机位仰视、圣像居上、众生渺小如尘；色彩浓艳响亮、庄严静穆；非卡通、非日系动画、非扁平插画、非玩具感、非塑料感
【画幅】{16:9 或 9:16}   ← 只此两种
```

**★固定节填写要求**：命门词「**矿物颜料高饱和鲜亮 + 明亮金箔**」「**圣像居上、众生渺小如尘（上重下轻）**」「**头光身光背光**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 圣像：依法相（面如满月、眉如新月、双目低垂、耳垂厚长）；依神祇落实手印/法器/坐骑；金身贴金、璎珞华饰、天衣帛带；不拟人化卖萌。 |
| 【次要元素·近/中/远】 | 上方（圣像/祥云/飞天）→ 中景道场云气 → 下方众生（极小、不可辨面容）。空层写「无」。 |
| 【全局】 | 花雨/天乐/香云/璎珞垂串。 |
| 【构图】 | 恒"上重下轻"：圣像占上部、众生压底；环境亮度低于圣像。**不写焦距/景深**。 |
| 【镜头】 | 低机位仰视；中远景/大远景。 |

## 六、易翻车点（写完回查）

1. **整体发灰/低饱和** → 负向含「褪色、发灰、莫兰迪低饱和、洗白」，锁定矿物高饱和。
2. **恐怖/邪典/血污** → 负向含「恐怖、邪典、血污、骷髅」（宗教题材第一红线）。
3. **真人面孔/性化** → 负向含「真人面孔、明星脸、性化、暴露」。
4. **打光均匀/棚拍感** → 负向含「明亮均匀打光、棚拍平光」，锁定背光仰视。
