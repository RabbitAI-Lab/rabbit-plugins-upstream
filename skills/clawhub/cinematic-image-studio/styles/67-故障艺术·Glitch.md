# 风格卡 · 故障艺术·Glitch

> **给写提示词的自己**：本卡 ★固定节 的字段必须**逐字照抄**，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `故障艺术·Glitch` |
| **一句话定位** | 信号损坏的数字美学：RGB 错位、扫描撕裂、像素块腐蚀，主体仍然可辨 |
| **媒介本质** | **数字图像损坏（datamosh / 信号故障）**的视觉效果，非绘画、非 3D 渲染 |
| **与最近似风格的区别** | 与「蒸汽波」（66）不同：**无落日与古典元素，故障是主语言**；与「像素复古」（60）不同：**不是统一像素网格，而是局部块状损坏**；与「赛博朋克」（33）不同：**不依赖霓虹场景** |
| **电影级从哪来** | ① 主体清晰、损坏只发生在局部，形成「可辨认 + 出错」的张力 ② 纯色底把故障彩色衬到极亮 ③ 撕裂条带的方向统一，画面不散 ④ 高对比让 RGB 错位成为唯一焦点 |

## 二、★固定节（逐字照抄）

```
【光影】无真实光源的电子成像：主体保持均匀的正面曝光（像被扫描仪平扫），明暗只用于区分结构、不塑体积；损坏区域的高光由 RGB 三色错位产生，红绿蓝三色沿水平方向错开约 3–6px；整体亮部干净、暗部压缩，没有任何环境光与投影方向
【色彩】底色为纯黑（#050506）或纯白（#F2F2F2）二选一，主体为中灰或单色；故障层只允许三原色——纯红（#FF0033）、纯绿（#00FF66）、纯蓝（#0055FF）沿通道错位出现；高饱和、极强对比、无中间灰过渡
【影像质感】数字信号损坏：整幅画面被 8–12 道水平位移切割成错位条带（错位量 4–18px，相邻条带断开、边缘各带 3px 的红/绿描边），主体轮廓处有一圈明显的 RGB 分离重影（红偏左、青偏右，分离 4–8px）、局部像素块被推挤成方块状腐蚀与压缩块（macroblocking）、少量数据噪点；受损区域有轻微的横向拖影，未受损区域保持锐利；非手绘、非胶片、非 3D
【背景】纯色平面底（黑或白），可有一层极淡的水平扫描线与两三条孤立的故障条带；背景不出现场景、不出现环境
【风格】故障艺术 Glitch Art，数字信号损坏与 RGB 通道错位，水平撕裂与数据腐蚀，电子错误美学；非绘画、非 3D 渲染、非赛博街景
【画幅】{16:9}
```

**★固定节填写要求**：
- 命门词「**RGB 三原色水平错位**」「**水平撕裂条带**」「**方块状数据腐蚀**」「**纯色底 + 极强对比**」逐字不动。
- 三原色色号、错位量、条带数量区间不许改；只允许替换主体与损坏位置。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 个可拍摄细节**：主体是什么（石膏胸像、电子产品、花束、乐器、鞋、香水瓶）、尺寸与占画面比例、材质与表面（石膏粗糙、玻璃、皮革、金属）、颜色（须在中灰/单色内）、朝向与位置、哪些部位完好、哪些部位发生故障。 |
| 【次要元素·近/中/远】 | 只写纯色底与故障条带；可有 1 件极小的碎片状残影。空层写「无」。 |
| 【全局】 | 水平扫描线、数据噪点、压缩块、轻微拖影。 |
| 【构图】 | 主体居中或三分线，占画面 40–65%，四周留出纯色空场；故障条带多集中在主体下半或一侧。**不写焦距/景深**。 |
| 【镜头】 | 正投影平视、等效 50mm、全画面等清晰度；损坏区域允许局部模糊，主体核心结构保持清晰。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|
| 科技 KV / 横版 | `16:9` 横 | `1536x1024` | 主体居中偏左，右侧留纯色与条带 |
| 竖版海报 | `9:16` 竖 | `1024x1536` | 主体占中段，上下各留一条撕裂带 |

## 六、易翻车点（写完回查）

1. **整张糊成噪点、主体不可辨** → 固定节写「未受损部分保持锐利」，负向含「主体不可辨、全画面糊成噪点」。
2. **变成像素画** → 强调「局部块状腐蚀」而非统一像素网格，负向含「均匀马赛克」。
3. **出现大量代码字符** → 负向含「代码字符、字母、数字、大面积乱码」。
4. **变成赛博街景** → 固定节写「纯色平面底、无场景」，负向含「霓虹街景」。
5. **RGB 错位不明显** → 【色彩】限定三原色色号与 3–6px 错位量。
