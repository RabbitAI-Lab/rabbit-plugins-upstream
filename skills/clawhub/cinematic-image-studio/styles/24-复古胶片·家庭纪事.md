# 风格卡 · 复古胶片·家庭纪事

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `复古胶片·家庭纪事` |
| **一句话定位** | 像翻出一盘旧的家庭录像带，真实的、不完美的、温热的记忆 |
| **媒介本质** | 8mm/16mm 家庭录像带质感（胶片颗粒 + 划痕渗光）；**非**高清数码、**非**卡通/插画 |
| **与最近似风格的区别** | 与「MV电影感写实」不同：本档**家庭录像带颗粒/褪色/手持晃动**；与数码写实不同：低饱和偏黄、边缘暗角 |
| **电影级从哪来** | ① 暖棕褪色调 ② 手持轻微晃动 ③ 渗光与偶发过曝 ④ 年代家庭空间纵深 |

## 二、★固定节（逐字照抄）

```
【光影】自然光为主（窗户漏光/老台灯/午后暖阳）；手持轻微晃动如家用摄像机抓拍；偶发过曝高光滚降；边缘暗角
【色彩】8mm/16mm 家庭录像带质感、暖棕褪色调、低饱和偏黄；明显胶片颗粒与划痕渗光
【影像质感】年代家庭录像带质感：布料/木器/搪瓷/旧纸的真实材质；怀旧、温热、真实不完美
【背景】老屋/筒子楼/老客厅/院子/老校门等年代家庭空间，前景旧物到远景旧街有纵深；无可读文字/日期/日历
【风格】复古胶片·家庭纪事：8mm/16mm 家庭录像带质感；人物一律以剪影/背影/后脑勺/虚焦侧脸/手部局部呈现，不出现可辨认的真人正脸；怀旧、温热、真实不完美
【画幅】{9:16 或 16:9}   ← 只此两种
```

**★固定节填写要求**：命门词「**家庭录像带颗粒/划痕/暖棕褪色**」「**不露正脸**」「**手持抓拍、不完美**」逐字不动。

## 三、★专属负向（必须并入【负向】）

```
可辨认的真人正脸、明星脸、正脸大特写、高清锐利数码感、4K超清、
现代装修、现代服装、智能手机、LED冷光、赛博霓虹、
婚纱影楼摆拍感、广告感、MV感、
日系动漫、赛璐璐、3D塑料感、插画、油画、高饱和艳色、刺眼荧光、
文字、字幕、水印、标志、二维码、日期数字、日历、
畸形的手、多余手指、畸变、主体出框
```

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 人物以剪影/背影/后脑勺/虚焦侧脸/手部局部呈现，不露正脸；靠年代器物与动作叙事。 |
| 【次要元素·近/中/远】 | 前景旧物 → 中景主体 → 远景旧街/老院。空层写「无」。 |
| 【全局】 | 漏光/浮尘/旧胶片颗粒。 |
| 【构图】 | 手持抓拍、略随意；纵深。**不写焦距/景深**。 |
| 【镜头】 | 家用摄像机视角、轻微晃动感；中景。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|
| 竖屏纪念日 | `9:16` 竖 | `1024x1536` | 主体居中、年代环境 |
| 横版 | `16:9` 横 | `1536x1024` | 纵深旧街/老院 |

## 六、易翻车点（写完回查）

1. **画成高清数码** → 负向含「高清锐利数码感、4K超清」，锁定颗粒/划痕。
2. **出现现代物件** → 负向含「现代装修、智能手机、LED冷光」。
3. **露正脸** → 负向含「可辨认的真人正脸」。
4. **出日期/日历** → 负向含「日期数字、日历」。
