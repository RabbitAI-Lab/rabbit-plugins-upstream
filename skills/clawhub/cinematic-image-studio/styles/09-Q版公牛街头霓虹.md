# 风格卡 · Q版公牛街头霓虹

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `Q版公牛街头霓虹` |
| **一句话定位** | Q版潮玩质感的街头潮流插画，夜晚霓虹高光，像一枚会发光的限定手办 |
| **媒介本质** | 亮面乙烯基（vinyl）潮玩手办质感插画；**非**写实 3D、**非**扁平色块 |
| **与最近似风格的区别** | 与「写实 3D」不同：**Q版 2–3 头身、手办完成度、锐利高光点**；与动漫不同：**潮玩体块感、非赛璐璐描线** |
| **电影级从哪来** | ① 霓虹轮廓光勾亮主体 ② 湿滑地面反光 ③ 暗部干净不糊、主体清晰突出 ④ 亮而不脏 |

## 二、★固定节（逐字照抄）

```
【光影】夜色霓虹布光：主体被一圈霓虹轮廓光勾亮，电光青/热品红/紫罗兰从侧后方打来，湿滑地面反射霓虹；高光锐利、质感通透，暗部干净不糊；色温偏冷
【色彩】夜色底（#0B0B14 / #12071F）≥50%，电光青（#00F0FF / #22E0FF）20–30%，品红/紫（#FF2D95 / #B026FF）10–20%，荧光绿（#B6FF2E）/暖橙（#FF7A1A）≤8%，亮白/银（#F5F7FA）点缀；亮而不脏、潮而不乱
【影像质感】亮面乙烯基手办质感：圆润饱满体块、光滑表面、明确高光点与边缘反光、通透树脂感；无写实人脸与毛发、无脏旧纹理、无磨砂糊感
【背景】夜晚街头潮流场景：涂鸦墙、霓虹招牌、铁丝网、卷帘门、湿滑反光地面、地下通道；简洁不抢主体；无文字
【风格】Q版潮玩街头潮流插画，亮面乙烯基手办质感，圆润大头小身与干净轮廓，街头潮流与说唱夜场氛围；主体大、占据画面视觉中心，干净潮而不乱留白充足；非写实照片、非厚重3D脏感
【画幅】{16:9 或 9:16}   ← 只此两种
```

**★固定节填写要求**：命门词「**亮面乙烯基手办质感**」「**Q版大头小身**」「**霓虹轮廓光 + 湿滑地面反光**」逐字不动。

## 三、★专属负向（必须并入【负向】）

```
写实人脸与写实毛发、写实照片感、厚涂、扁平纯色块、3D 塑料脏感、磨砂糊感、脏旧纹理、噪点、
冷白平光、大爆闪过曝、霓虹脏乱乱闪、可辨认地标、品牌门店/商标、
文字、水印、Logo、二维码、英文、字母、拼音、乱码、错字、政治宗教元素
```

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | **≥8 细节**：Q版公牛（或潮流形象）大头小身、圆润体块、宽松外套工装裤球鞋项链帽子等潮流配饰 + 姿态朝向 + 神态。与主题强相关。 |
| 【次要元素·近/中/远】 | 近：湿滑反光地面/道具；中：主体；远：涂鸦墙/霓虹招牌。空层写「无」。 |
| 【全局】 | 霓虹辉光/雨雾/浮尘/光斑。 |
| 【构图】 | 主体大、占视觉中心；可低机位仰拍显潮；留白充足。**不写焦距/景深**。 |
| 【镜头】 | 中近景为主，浅景深（f/2.8 虚化霓虹背景）。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|
| 横版主视觉 / B-roll | `16:9` 横 | `1536x1024` | 主体居中偏下，霓虹环绕 |
| 竖屏短视频 | `9:16` 竖 | `1024x1536` | 主体占中，地面反光在底部 |

## 六、易翻车点（写完回查）

1. **画成写实/3D脏感** → 保留「亮面乙烯基手办质感」，负向含「写实照片感、3D 塑料脏感」。
2. **霓虹过曝脏乱** → 保持面积比与「亮而不脏」，负向加「霓虹脏乱乱闪」。
3. **主体过小/碎散** → 【构图】强制「主体大、占视觉中心」。
4. **出现英文招牌乱码** → 负向含「英文、字母、乱码」，【背景】写「无文字」。
