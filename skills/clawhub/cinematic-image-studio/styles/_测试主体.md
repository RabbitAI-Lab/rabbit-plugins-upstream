> **用途**：本 skill 要「**一个风格出一张图**」时，读本表给每张风格卡配一个**贴合的测试主体**，
> 保证出图既能看出风格调性、又不让「题材专属」风格（神兽 / 神祇 / 圣像 / 演唱 / 打斗）用错主体而失真。
> **通用场景类**若要做横向比稿，可统一换成同一个中性主体（历史统一主体：`雨夜·青石拱桥上撑伞回望的东方古代行路人（虚构，无历史原型）`）。
> **合规**：主体一律虚构化 / 脱敏；当代真人、真实品牌、真实地标一律不出现；史载人物写「虚构的东方古代XX（无历史原型）」。

图幅取向按各风格卡默认：`16:9 → 1536x1024`，`9:16 → 1024x1536`；
`54–57` 为 MV 导入卡（默认 `3:4`），由 `08-MV制作/mv-production-skill` 消费，本 skill 不出 `3:4` 图。
