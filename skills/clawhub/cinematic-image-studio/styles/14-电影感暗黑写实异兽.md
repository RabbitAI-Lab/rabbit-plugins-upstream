# 风格卡 · 电影感暗黑写实异兽

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `电影感暗黑写实异兽` |
| **一句话定位** | 像纪录片摄制组在暗夜拍到一头从未被记录的上古巨兽，而不是画出来的一只怪兽 |
| **媒介本质** | 写实生物概念设计（creature realism，院线怪兽片质感）；**非**卡通/动漫/插画/玩具/塑料 |
| **与最近似风格的区别** | 与「3D新国风」不同：本档**写实解剖、暗调、非卡通夸张**；与「动物摄影」不同：上古异兽、体量奇观 |
| **电影级从哪来** | ① 单一主光（光源可解释）② 体积光穿尘 ③ 轮廓光勾背脊 ④ 低饱和暗调 + 胶片颗粒 |

## 二、★固定节（逐字照抄）

```
【光影】单一主光（月光/火光/熔岩/闪电/荧光生物光，光源必须在画面里可解释）；体积光柱穿过雾气/浮尘/烟、可见光路；轮廓光勾出背脊、角、翼膜；环境反射（湿地/水洼/鳞甲映环境光色）；暗部保留细节不糊成黑；明暗对比大但不碎
【色彩】低饱和暗调；主体与环境共享同一套光（冷月/暖火）；主体区域亮、背景压暗退后；禁止到处都在闪
【影像质感】写实生物：能看出骨骼支撑/肌肉走向/关节结构、体重与重力成立；皮肤鳞甲湿润反光、边缘有脱落旧鳞与伤痕；微距级细节（鳞缝积尘、眼周细纹、齿面裂纹、翼膜血管透光）；轻微胶片颗粒 + 暗角 + 柔和高光滚降；不做干净数码感
【背景】《山海经》地理：幽暗山渊／云海断崖／火山裂谷／死水沼地／风雪荒原／深海幽渊／青铜祭坛遗迹；纵深至少三层（前景遮挡→中景主体→远景地貌）；无可读文字
【风格】院线怪兽片质感的写实生物概念设计：真实解剖与体量可信、湿润鳞甲反光、体积光穿尘、湿气浮尘弥漫、浅景深、低饱和暗调单一主光；非卡通、非日系动画、非扁平插画、非玩具感、非塑料感
【画幅】{16:9 或 9:16}   ← 只此两种
```

**★固定节填写要求**：命门词「**单一主光且光源可解释**」「**写实解剖结构可信**」「**不完美=真实**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 单主体异兽，**≥8 细节**：角/翼/目/尾/鳞/足/体色/体长逐项落实原文；皮肤材质、口部与牙、眼睛有虹膜与湿润感、不拟人化；姿态朝向。 |
| 【次要元素·近/中/远】 | 前景遮挡（岩石/枯枝/雾）→ 中景主体 → 远景地貌（山脊/月/火山）。空层写「无」。 |
| 【全局】 | 浮尘颗粒/水汽/细雨/飞灰/萤火 —— 与浅景深自洽。 |
| 【构图】 | 主体占满画面却仍有环境；纵深、留白克制。**不写焦距/景深**。 |
| 【镜头】 | 大远景/中景；浅景深；长焦压缩感。 |

## 五、画幅与题材取向

| 题材 | 推荐画幅 | 尺寸 | 构图要点 |
|---|---|---|---|
| 巨兽全貌/横版 | `16:9` 横 | `1536x1024` | 主体占满，环境可辨比例 |

## 六、易翻车点（写完回查）

1. **画成卡通/塑料怪兽** → 负向含「卡通、日系动画、扁平插画、塑料感」。
2. **拼贴/解剖崩坏（AI 最易崩）** → 负向含「对称拼贴怪兽、解剖结构错误、多余肢体」。
3. **打光均匀/棚拍感** → 负向含「明亮均匀打光、棚拍平光」，锁定「单一主光」。
4. **表面太干净** → 负向含「干净无瑕的表面、完美对称」，强调旧伤/脱鳞/泥污。
