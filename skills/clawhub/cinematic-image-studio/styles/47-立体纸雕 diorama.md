# 风格卡 · 立体纸雕 diorama（多层纸板 · 层叠纵深 · 层间投影）

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `立体纸雕 diorama` |
| **一句话定位** | 像一个多层纸雕盒子——一层层切纸叠出天庭群仙的纵深 |
| **媒介本质** | 立体纸雕 diorama（多层切割纸板层叠 + 镂空窗洞 + 层间投影）；**非**3D、**非**绘画、**非**照片 |
| **与最近似风格的区别** | 与「中国剪纸」（43）不同：剪纸是**平面镂刻/贴层**；本档是**多层纸板向纵深盒子层层叠起**、层间有明显投影与纵深。与3D不同：以**纸的厚度与层叠**成形。 |
| **纵深从哪来** | ① 多层纸板叠出盒子 ② 层间投影 ③ 镂空窗洞 ④ 纸的厚度毛边 |

## 二、★固定节（逐字照抄）

```
【光影】多光源柔光，让每一层纸板投下清晰层次投影；暖白布光；投影是本风格的核心；纸的毛边在光下有细亮边
【色彩】纸的素雅色：米白、浅灰、莫兰迪蓝绿、牛皮纸棕；可用单色或少量点缀色（如朱砂红）；干净克制
【影像质感】立体纸雕 diorama 质感：多层切割纸板层叠、纸的厚度与毛边、层间投影、镂空窗洞、纸面微糙；非3D渲染、非绘画、非塑料、非照片
【背景】纸雕天宫：多层纸板切成云层、宫阙、柱子，前面留镂空框；层叠向纵深；无可读文字
【风格】多层立体纸雕 diorama：切割纸板层叠、纸边毛茬、层间投影、纵深盒子；手工干净；非3D、非绘画、非照片
【画幅】16:9
```

**★固定节填写要求**：命门词「**多层切割纸板层叠 + 纸边毛茬**」「**层间清晰投影**」「**纵深盒子**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 主仙（虚构，由多层纸板剪影/镂空叠成，居中略大、姿态起舞；纸边毛茬、层间投影）；群仙以纸板小样分列纵深；末尾「是画面唯一视觉主体」 |
| 【次要元素·近/中/远】 | 近：镂空纸框/云层；中：纸板群仙与宫柱；远：层叠纸云窗洞；空层写「无」 |
| 【全局】 | 少量纸屑/浮尘 —— 与柔光自洽 |
| 【构图】 | 盒子式纵深：前框—主仙—中景纸板—远景纸云；主仙居中；**不写焦距/景深** |
| 【镜头】 | 正面盒景平视，中景深 f/5.6 |

## 六、易翻车点（写完回查）

1. **变3D/塑料** → 负向含「3D渲染、CG光滑塑料、树脂」；【影像质感】锁「纸板层叠、纸边毛茬」。
2. **平面无纵深** → 负向含「平面无纵深、层糊在一起、没有层间投影」；【光影】写「层间清晰投影」。
3. **变绘画** → 负向含「绘画笔触、油画、水彩」；【影像质感】写「切割纸板、镂空窗洞」。
4. **纸变塑料** → 负向含「纸变塑料片」；【影像质感】写「纸的厚度与毛边」。
