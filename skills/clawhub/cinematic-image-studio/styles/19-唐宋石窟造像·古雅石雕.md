# 风格卡 · 唐宋石窟造像·古雅石雕

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `唐宋石窟造像·古雅石雕` |
| **一句话定位** | 把圣像拍成一座千年石窟里的造像，如云冈、龙门、敦煌彩塑 |
| **媒介本质** | 唐宋石窟摩崖与彩塑石胎造像质感；**非**平面壁画、**非**卡通/3D/塑料 |
| **与最近似风格的区别** | 与「敦煌金彩壁画」不同：本档**石刻石质 + 洞窟侧光**，残彩残金作点缀而非满壁壁画 |
| **电影级从哪来** | ① 洞窟侧光/天窗顶光斜切 ② 明暗厚重 ③ 低机位仰视 ④ 风化石痕与刀痕质感 |

## 二、★固定节（逐字照抄）

```
【光影】洞窟侧光或天窗顶光斜切、明暗厚重；低机位仰视，圣像高踞须弥座俯临、众生渺小入暗；暗部保留石纹
【色彩】石质基调：青灰、砂黄、赭石、苔绿；但石上残留彩塑彩绘与残金须鲜亮饱和（朱砂红、石青蓝、石绿、明亮残金），不褪成灰；残金残彩为强调（最多两种）、明亮不暗哑；不得整体降饱和、不得把彩色洗白
【影像质感】唐宋石窟摩崖与彩塑石胎造像质感：青灰砂岩、汉白玉与彩塑石面；风化剥落、开凿刀痕与残留彩绘残金斑驳、彩塑原色鲜亮饱和；衣纹如"曹衣出水"般贴体；非3D、非光滑CG手感
【背景】道场：石窟壁龛/摩崖大佛/洞窟主尊/彩塑殿堂/崖壁群像；纵深：龛外天窗光（上）→圣像（中）→洞窟地面与朝拜众生（下）；洞壁/飞天/伎乐浮雕作环境注脚；无可读文字
【风格】唐宋石窟摩崖与彩塑石胎造像质感：圣像法度圆融、面如满月、眉目低垂、衣纹曹衣出水般贴体；低机位仰视、圣像高踞须弥座俯临、众生渺小入暗；古雅沉静；非卡通、非日系动画、非扁平插画、非玩具感、非塑料感
【画幅】{16:9 或 9:16}   ← 只此两种
```

**★固定节填写要求**：命门词「**石质青灰但残彩残金鲜亮饱和**」「**曹衣出水贴体衣纹**」「**洞窟侧光斜切 + 低机位仰视**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 圣像石胎：法度圆融、面如满月、眉目低垂、衣纹贴体；依神祇落实手印/法器；石质可素、残留彩绘残金鲜亮；不瞪不媚不卖萌。 |
| 【次要元素·近/中/远】 | 上：龛外天窗光/飞天浮雕；中：圣像；下：洞窟地面朝拜众生（渺小）。空层写「无」。 |
| 【全局】 | 石屑微尘/香烟/光斑在石面移动。 |
| 【构图】 | 圣像高踞、众生入暗；上重下轻。**不写焦距/景深**。 |
| 【镜头】 | 低机位仰视；中远景。 |

## 六、易翻车点（写完回查）

1. **石质太干净/光滑** → 负向含「光滑 CG 手感、塑料感」，强调风化刀痕。
2. **残彩也被洗灰** → 负向含「褪色、发灰」，锁定「残金残彩须鲜亮饱和」。
3. **恐怖/邪典** → 负向含「恐怖、邪典、血污、骷髅」。
4. **打光均匀/过曝** → 负向含「明亮均匀打光、过曝死白」。
