# 风格卡 · 梦幻唯美·插画轻动画

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `梦幻唯美·插画轻动画` |
| **一句话定位** | 像一本会动的绘本，轻盈、干净、治愈 |
| **媒介本质** | 柔焦插画轻动画（柔软圆润、干净通透线条）；**非**写实摄影、**非**廉价3D |
| **与最近似风格的区别** | 与「温馨亲子绘本」不同：本档**梦幻光斑/云朵般柔形体/轻动画感**；与3D不同：插画质感、非塑料 |
| **电影级从哪来** | ① 柔和散射光 + 逆光光晕 ② 光斑星点 ③ 柔软圆润造型 ④ 轻微柔焦与颗粒 |

## 二、★固定节（逐字照抄）

```
【光影】柔和散射光与逆光光晕、光斑与星点微光；无硬阴影
【色彩】粉紫/奶橘/薄荷绿的梦幻配色、强调色不超过两种；柔和梦幻
【影像质感】柔焦插画质感轻动画：形体柔软圆润、线条干净通透、带一点物件拟人化的俏皮温柔；棉绒薄纱般的材质、轻微柔焦与颗粒
【背景】梦幻生活空间或云朵般的天空，前景漂浮物到远景柔光有纵深；无可读文字
【风格】梦幻唯美·插画轻动画：柔焦插画质感；婴儿与孩子以背影/低头/侧脸剪影/被光晕包裹呈现，不出现可辨认的真人正脸；轻盈、干净、治愈
【画幅】{9:16 或 16:9}   ← 只此两种
```

**★固定节填写要求**：命门词「**柔焦插画质感（非写实、非廉价3D）**」「**粉紫奶橘梦幻 + 光斑星点**」「**不露正脸**」逐字不动。

## 四、逐图可变节（每次重写）

| 节 | 怎么写 |
|---|---|
| 【主体】 | 婴儿/孩子以背影/低头/侧脸剪影/被光晕包裹呈现，不露正脸；柔软萌物/云朵/星点。 |
| 【次要元素·近/中/远】 | 前景漂浮物（云朵/气泡）→ 中景主体 → 远景柔光。空层写「无」。 |
| 【全局】 | 光斑/星点/浮尘/柔光粒子。 |
| 【构图】 | 主体偏三分；留白轻盈。**不写焦距/景深**。 |
| 【镜头】 | 中景/近景；柔焦无硬景深。 |

## 六、易翻车点（写完回查）

1. **画成廉价3D/塑料** → 负向含「廉价3D、塑料感、僵硬的CG」。
2. **恐怖/暗黑** → 负向含「恐怖、诡异、暗黑、阴森色调」。
3. **高饱和荧光** → 负向含「高饱和荧光」，保持柔和梦幻。
4. **露正脸** → 负向含「可辨认的真人正脸、婴儿正脸特写」。
