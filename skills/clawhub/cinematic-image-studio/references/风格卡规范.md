# 风格卡规范（怎么新增一个风格）

> 配套 `SKILL.md` 第 2.5 节。用户说「加一个 XX 风格」时按本文件走。
> 模板：`styles/_模板-风格卡.md`。已有范例：`styles/01-彩色水墨.md`、`styles/02-山海经神兽.md`。

---

## 一、为什么要有「风格卡」

**问题**：同一个风格出十张图，如果每次都由模型现场自由发挥风格描述，十张图的色调、光位、质感会各说各话，**成不了系列**。

**解法**：把风格**固化成卡**——卡里的一部分字段（★固定节）是**逐字照抄的口径**，任何主体都不许改；另一部分（【主体】【构图】【镜头】等）才是逐图可变的。

```
风格卡 = ★固定节（跨图逐字一致）  +  逐图可变节的「怎么写」指南  +  专属负向  +  易翻车点
```

这样：**换主体不换风格，成系列；换风格卡不换主体，可横向比稿。**

---

## 二、新增风格卡的标准流程

### 第一步：问清三件事（≤3 组，一次问完）

| 问什么 | 为什么问 |
|---|---|
| **风格名叫什么** | 决定 `styleId` 与文件名 |
| **一句话定位 / 参考作品** | "像什么"比"是什么"更快对齐预期（例："像《卧虎藏龙》的竹林打斗那种绿"） |
| **媒介 / 画种 / 关键词** | **媒介是防跑偏的第一道闸**——是国画？油画？摄影？3D？定格？ |

若用户答不上来，给 **3 个带【推荐】的候选定位**让用户挑，不要自己拍脑袋。

### 第二步：定位「最近似的风格」并写出区别

**这一步最容易被跳过，但最重要。** 每个风格都有一个"模型默认会画成的样子"：

- 说「水墨」→ 模型默认画成**黑白水墨**或**国风数码插画**
- 说「山海经神兽」→ 模型默认画成**日式动漫**或**西式龙**
- 说「赛博朋克」→ 模型默认画成**霓虹紫蓝大杂烩**

所以风格卡里必须有一段 **「与最近似风格的区别」**，并把那个错误答案**写进专属负向**。一个风格卡的质量，八成取决于这段。

### 第三步：设计 ★固定节

按 `SKILL.md` 第三节的 14 节骨架，挑出这个风格里**跨图必须一致**的节：

| 通常是固定节 | 通常是可变节 |
|---|---|
| 【光影】【色彩】【影像质感】【背景】【风格】【画幅】 | 【主体】【次要元素·近/中/远】【全局】【构图】【镜头】 |

> 可选节 **`【装饰】`**：只有需要跨图固定装饰母题时（如 `03-中式美学` 的唐卡描金 / 宝相花）才写，
> 位置在【影像质感】之后；其余卡不写，`build_prompts.py` 会自动跳过。

**固定节的写法要求**：
1. **写成一句话模板**，用 `{占位符}` 标出允许每图替换的部分；
2. **明确标注哪些词是命门、逐字不动**（例：彩色水墨的"墨分五色为骨架"、山海经神兽的"逆光 + 边缘光勾毛"）；
3. **占位符的替换边界要写清**（例："主光方位可换顺光/侧逆光，但'单一主光、方向明确'必须保留"）。

> **判断标准**：把模板拿给另一个人，他填出来的固定节应当和你填的**逐字一致**。做不到 → 模板写得不够死。

### 第四步：写专属负向

列出**这个风格最容易被画成的错误风格** + **这个风格特有的畸形**：

```
<错误风格1>、<错误风格2>、<错误媒介>、
<该风格特有畸形，如"尾巴数量错误">、
文字、水印、Logo
```

### 第五步：写「易翻车点」

列 **3–6 条**，每条格式：**翻车现象 → 在提示词哪一节、加什么词堵住**。
这一节是风格卡的**实战价值所在**，写空话没用，要写你实际踩过的坑。

### 第六步：落盘 + 试出图

1. 存为 `styles/0N-{风格名}.md`（`0N` 接现有编号递增）；
2. **更新 `SKILL.md` 第一节的风格库表**（加一行）；
3. 用新风格卡写一条提示词、**出一张样图给用户看**，确认风格对味后再批量。

## 三、质量自检（新风格卡写完逐条过）

- [ ] **媒介明确**：第一眼能看出这是国画 / 摄影 / 3D / 版画中的哪一种，不含糊
- [ ] **写了「与最近似风格的区别」**，且那个错误答案进了专属负向
- [ ] **★固定节是模板句**，占位符有明确替换边界，命门词已标注
- [ ] **专属负向 ≥8 项**，且至少一半是**风格性错误**（不是通用质量词）
- [ ] **易翻车点 ≥3 条**，每条都给出了具体堵法（不是"注意画面质量"这类空话）
- [ ] **画幅只写 16:9 / 9:16**，无其它比例（`54–57` 的 `3:4` 属 MV 外部卡，不在此列）
- [ ] **含一条完整的 14 节示范提示词**，且**已实际出图验证过**
- [ ] **`SKILL.md` 风格库表已同步更新**

## 四、命名与编号约定

| 项 | 约定 |
|---|---|
| 文件 | `styles/0N-{风格名}.md`（两位数字，递增；`_模板-风格卡.md` 不占号） |
| front-matter `name` | `style-{英文 kebab-case id}` |
| front-matter `styleId` | **风格中文名**（不带编号；与文件名去掉编号后一致） |
| front-matter `defaultRatio` | `16:9` 或 `9:16`（MV 导入卡 `54–57` 为 `3:4`） |
| 产物目录 | `assets/output/{风格名}-{主体}/`（单张）或 `assets/output/NN-{主题}/`（多风格样图）；去标点、不含空格 |
| 命名 | `kind` = 风格卡文件名去 `.md`；`id` = `kind-主体`；图片落点 `图片/<kind>/<id>.png` |

## 五、现有风格的「命门词」速查

新增风格时避免与下列命门冲突：

| 风格 | 命门词（逐字不动） |
|---|---|
| 彩色水墨 | 「墨分五色为骨架」·「宣纸纤维质地，墨色自然洇开、边缘有毛涩水痕与飞白」·「非数码插画、非水彩、非油画」 |
| 山海经神兽 | 「身后云隙一道冷白体积光（逆光）作单一主光，勾出毛发边缘光」·「ARRI Alexa 65 大画幅质感」·「可怖而不血腥，具压迫感与野性」 |
