# 十神、月令取格与用神忌神

> 命局分析的核心资料。分三块：①十神定义（排主星/副星用）；②月令取格（定格局、看清纯与破格）；③取用神忌神（**扶抑为主、调候为辅**）。判日主强弱是取用神的前提，详见本文第三节。

## 一、十神定义

以日干（日主）为基准，看其余干支与日主的生克、阴阳关系。

### 生克关系类型

| 关系 | 十神 |
| --- | --- |
| 生我者 | 印（正印、偏印） |
| 我生者 | 食伤（食神、伤官） |
| 克我者 | 官杀（正官、七杀） |
| 我克者 | 财（正财、偏财） |
| 同我者 | 比劫（比肩、劫财） |

### 阴阳同异定正偏

| 十神 | 与日主阴阳 | 关系 | 大致象征 |
| --- | --- | --- | --- |
| 正印 | 异 | 生我 | 学业、母亲、庇荫、名誉、长辈 |
| 偏印（枭神） | 同 | 生我 | 偏门学问、直觉、孤独、继母 |
| 食神 | 同 | 我生 | 才华、口福、温和、子息 |
| 伤官 | 异 | 我生 | 才华外露、叛逆、口才、变动 |
| 正官 | 异 | 克我 | 事业、地位、纪律、丈夫（女命）、上司 |
| 七杀（偏官） | 同 | 克我 | 压力、魄力、竞争、武职、风险 |
| 正财 | 异 | 我克 | 正当收入、妻子（男命）、勤俭 |
| 偏财 | 同 | 我克 | 意外之财、父亲、慷慨、社交 |
| 比肩 | 同 | 同我 | 兄弟、朋友、自我、竞争 |
| 劫财 | 异 | 同我 | 同辈、破财、强势、合作与争夺 |

**快速判断口诀**：
- 克我者为官杀：阴阳异 = 正官；阴阳同 = 七杀。
- 我克者为财：阴阳异 = 正财；阴阳同 = 偏财。
- 生我者为印：阴阳异 = 正印；阴阳同 = 偏印。
- 我生者为食伤：阴阳同 = 食神；阴阳异 = 伤官。
- 同我者为比劫：阴阳同 = 比肩；阴阳异 = 劫财。

### 主星 / 副星

- **主星**＝四柱**天干**本身的十神（如时干辛＝伤官）。
- **副星**＝四柱**地支藏干**对应的十神（一个地支藏几个干，就有几个副星，本气为主、中气余气为辅）。
- 藏干以 `基础知识.md` 的地支藏干表为准：子独藏癸、卯独藏乙、酉独藏辛；申藏庚壬戊、寅藏甲丙戊、亥藏壬甲。

## 二、月令取格法（定格局）

格局以**月令（月支）**为核心来定，是命局分析的"总纲"。

### 1. 取格步骤

1. 看月支所藏天干（本气、中气、余气）哪一位**透出天干**（出现在年干、月干或时干）。
2. 取透出者为格：透正官→正官格；七杀→七杀格；正财/偏财→财格；正印/偏印→印格；食神→食神格；伤官→伤官格。即传统"八格"。
3. 优先取**本气透出**；本气不透再看中气、余气。
4. 月令本气为比劫且无它神透出：日主在月令为临官→建禄格；为羊刃→月刃格（不入八格）。
5. 月令为辰戌丑未四库时称"杂气/库格"，同样看库中所藏透出何神定格局。
6. 无透出时，可取月令本气所对应者定名，但注明"不透干，格弱"。

### 2. 成格三要素：有格、清纯、得用

月令透出成格只是"有格"，还须看**是否清纯、用神是否得力**，三者俱全才是真正"成格"。

- **清纯**：同类格神只透一种、不与他神混杂。如正官格只见正官、不再见七杀。
- **主要混杂与破格情形**：

| 情形 | 说明 |
| --- | --- |
| 官杀混杂 | 正官与七杀同透，主是非反复，须合去、克去或制化其一，方为清 |
| 财被劫夺 | 财格比劫并透，财被分夺，喜官杀制劫护财 |
| 印被财破 | 印格见财星旺透，喜比劫制财护印 |
| 枭印夺食 | 食神格见偏印透出，夺其食神，喜财星制枭或比劫化枭 |
| 伤官见官 | 伤官格见正官，喜财星通关或印星制伤护官 |

- **取清之法**：合、克、制、化，去掉混杂或克制的"病神"，使格局回复清纯。
- 格局不清时，定名仍按月令所透主气，但要点明"混杂/破格"及其去病方式。

### 3. 常见格局

- **身强用财**：日主强，以财星为用（泄身兼生官）。
- **身弱用印**：日主弱，以印星为用（生身扶弱）。
- **食神生财**：食神旺而生财，才华转化为财富。
- **官印相生**：正官与正印相生，事业与名声。
- **羊刃驾杀**：羊刃配七杀，敢闯、扛压。
- **伤官伤尽**：伤官旺而正官不显，才华尽泄，主技艺、名气。
- **伤官佩印**：身弱而伤官旺泄身，靠印星制伤生身。

## 三、取用神忌神（扶抑为主、调候为辅）

用神 = 对命局最有利、最能治"病"的那个字/五行；忌神 = 最不利、加重"病"的那个字/五行。

### 1. 先判日主强弱（前提）

以"得令、得地、得生、得助"四看判旺衰：

| 项目 | 内容 | 判断 |
| --- | --- | --- |
| 得令 | 日主在月支处于旺相（长生、临官、帝旺、冠带，见 `扩展知识.md` 十二长生） | 得令则旺 |
| 得地 | 日主（或比劫同气）在地支藏干通根 | 通根则强 |
| 得生 | 正印/偏印透干、有根、有力生身 | 有印则扶 |
| 得助 | 比肩/劫财帮扶 | 有比劫则助 |

综合四看定：**身强 / 身弱 / 中和**。结论后必须列出依据，不写无据的"身强"或"身弱"。

### 2. 扶抑取用（主线）

- **身强** → 喜**克、泄、耗**：官杀（克）、食伤（泄）、财（耗）。
- **身弱** → 喜**生、扶**：印（生）、比劫（扶）。
- **中和** → 以调候、格局之病为主定用神。

### 3. 调候取用（辅线）

按《穷通宝鉴》十二月调候（见 `日主分析.md`）看气候寒暖燥湿：冬生喜火暖、夏生喜水润、燥土喜润、湿局喜晒。调候所喜与扶抑所喜一致时，该字为**第一用神**。

### 4. 综合定用神、喜神、忌神

把扶抑与调候并看：

- **用神**：对治命局最重之病、最有利的字。要写明"它治的是哪个病、为什么不可替代"。
- **喜神**：能生扶用神、或对命局次利的字。
- **忌神**：助长命局之病、或克用神的字。

> 例：丑月戊土，寒土喜丙火暖（调候）＋若身弱喜火土生扶（扶抑），则火为第一用神、土为喜神，金水为忌。若两角度指向不同（如身强却生于冬月），要说明分歧与取舍：以命局最重之病为准定主线，其余作辅助。

## 四、使用方法提示

1. 先排全主星/副星（十神），再定格局、判旺衰。
2. 定格局后必看"清纯/破格"，不能只看名字。
3. 取用神以扶抑为主线、调候为辅，**每条结论回扣"病在何处、用神治什么、为何得用"三点**。
4. 十神只是象征，结合格局、旺衰、调候综合判断，不单看一个十神下结论。
