## 二、五行生克

### 相生（滋养、促进）

木生火 → 火生土 → 土生金 → 金生水 → 水生木（循环）。

### 相克（制约、克制）

木克土 → 土克水 → 水克火 → 火克金 → 金克木（循环）。

### 生克直觉

- 日主旺则宜"泄"（生他人）或"克"（被克制以泄其气），喜克泄耗。
- 日主弱则宜"生"（受生）或"扶"（同类帮扶），忌克泄耗。

## 三、地支藏干（地支中藏的天干）

排十神和看根气需要用到地支藏干，常用"本气、中气、余气"：

| 地支 | 本气 | 中气 | 余气 |
| --- | --- | --- | --- |
| 子 | 癸 | — | — |
| 丑 | 己 | 癸 | 辛 |
| 寅 | 甲 | 丙 | 戊 |
| 卯 | 乙 | — | — |
| 辰 | 戊 | 乙 | 癸 |
| 巳 | 丙 | 戊 | 庚 |
| 午 | 丁 | 己 | — |
| 未 | 己 | 丁 | 乙 |
| 申 | 庚 | 壬 | 戊 |
| 酉 | 辛 | — | — |
| 戌 | 戊 | 辛 | 丁 |
| 亥 | 壬 | 甲 | — |

**记忆锚点（务必记牢，防排错十神）**：
- 子、卯、酉 为"纯藏"，各只藏一个本气：**子独藏癸、卯独藏乙、酉独藏辛**。
- 申藏「庚壬戊」、寅藏「甲丙戊」、亥藏「壬甲」。
- 以日主戊土为例：**申中之戊＝比肩、庚＝食神；酉中之辛只有伤官、无食神**。
- 各派藏干"中气/余气"顺序偶有差异（如巳或作丙庚戊），排十神以本气为主、中余气为辅，遇争议以常用排盘软件为准。

### 主星与副星（十神分层）

排盘软件常把十神分两层，理解后可快速核对副星：

- **主星**：四柱**天干**本身的十神（如时干辛＝伤官）。
- **副星**：四柱**地支藏干**对应的十神（一个地支藏几个干，就有几个副星）。

以"甲申｜丁丑｜戊申｜辛酉"（日主戊土）为例：

| 柱 | 干支 | 主星（天干） | 副星（地支藏干） |
| --- | --- | --- | --- |
| 年 | 甲申 | 甲＝七杀 | 庚＝食神、壬＝偏财、戊＝比肩 |
| 月 | 丁丑 | 丁＝正印 | 己＝劫财、癸＝正财、辛＝伤官 |
| 日 | 戊申 | 戊＝日主 | 庚＝食神、壬＝偏财、戊＝比肩 |
| 时 | 辛酉 | 辛＝伤官 | 辛＝伤官（仅此一个） |

## 四、排四柱（核心规则）

四柱 = 年柱 + 月柱 + 日柱 + 时柱，每柱一个天干一个地支。

### 1. 年柱

- 以立春为界（不是正月初一）：立春前属上一年，立春后属当年。
- 年柱地支即生肖年，年柱天干按"年上起月"关系推出（一般查万年历更快准确）。

### 2. 月柱（月柱地支 = 节令月）

- 一年 12 月以节气划分：立春为寅月、惊蛰为卯月、清明为辰月、立夏为巳月、芒种为午月、小暑为未月、立秋为申月、白露为酉月、寒露为戌月、立冬为亥月、大雪为子月、小寒为丑月。
- 月柱天干用"五虎遁"口诀：甲己之年丙作首，乙庚之年戊为头，丙辛之年寻庚上，丁壬壬寅顺水流，戊癸之年起甲寅。

示例：甲年正月（寅月）天干为丙，即"丙寅"；顺推二月为"丁卯"，依此类推。

### 3. 日柱（必须精确，用儒略日法，禁止心算）

日柱天干即"日主/日元"，代表"我"本人。日柱一错，日主、时柱、十神、大运全错，务必按下面算法计算并自检。

**算法（任选其一）**

法一（代码求儒略日数，最可靠）：

- JDN = Math.floor(Date.UTC(年, 月 − 1, 日) / 86400000) + 2440588
- 锚点：**2000 年 1 月 7 日 = 甲子日（JDN 2451551）**，甲子序号记 0。
- 序号 = (JDN − 2451551) mod 60（余数取非负整数）。

法二（数天数）：算出目标日距 2000-01-07 的天数 n，序号 = n mod 60。

**序号→干支对照表（0–59）**：

甲子0 乙丑1 丙寅2 丁卯3 戊辰4 己巳5 庚午6 辛未7 壬申8 癸酉9 甲戌10 乙亥11 丙子12 丁丑13 戊寅14 己卯15 庚辰16 辛巳17 壬午18 癸未19 甲申20 乙酉21 丙戌22 丁亥23 戊子24 己丑25 庚寅26 辛卯27 壬辰28 癸巳29 甲午30 乙未31 丙申32 丁酉33 戊戌34 己亥35 庚子36 辛丑37 壬寅38 癸卯39 甲辰40 乙巳41 丙午42 丁未43 戊申44 己酉45 庚戌46 辛亥47 壬子48 癸丑49 甲寅50 乙卯51 丙辰52 丁巳53 戊午54 己未55 庚申56 辛酉57 壬戌58 癸亥59

**必用自检锚点**：2005 年 1 月 24 日。

- JDN = 2453395（= 2451545 + 1850 天）
- 序号 = (2453395 − 2451551) mod 60 = 1844 mod 60 = 44 → **戊申**

所以 2005-01-24 日柱 = **戊申**。凡排盘先算这个锚点：若算得不是"戊申"，说明日柱算错，立即重算，算对后再排目标日期。

### 4. 时柱（时柱地支 = 时辰）

十二时辰对应地支：

| 时辰 | 时间段 | 地支 |
| --- | --- | --- |
| 子时 | 23:00–01:00 | 子 |
| 丑时 | 01:00–03:00 | 丑 |
| 寅时 | 03:00–05:00 | 寅 |
| 卯时 | 05:00–07:00 | 卯 |
| 辰时 | 07:00–09:00 | 辰 |
| 巳时 | 09:00–11:00 | 巳 |
| 午时 | 11:00–13:00 | 午 |
| 未时 | 13:00–15:00 | 未 |
| 申时 | 15:00–17:00 | 申 |
| 酉时 | 17:00–19:00 | 酉 |
| 戌时 | 19:00–21:00 | 戌 |
| 亥时 | 21:00–23:00 | 亥 |

时柱天干用"五鼠遁"口诀：甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸起壬子（从"子时"起算）。

起法：先按日干定"子时"的天干，之后每个时辰天干顺推一位（子→丑→寅→卯→辰→巳→午→未→申→酉→戌→亥）。

- 甲/己日：子时甲子
- 乙/庚日：子时丙子
- 丙/辛日：子时戊子
- 丁/壬日：子时庚子
- 戊/癸日：子时壬子 → 丑癸丑 → 寅甲寅 → 卯乙卯 → 辰丙辰 → 巳丁巳 → 午戊午 → 未己未 → 申庚申 → **酉辛酉**

自检锚点：**戊日酉时 = 辛酉**。如 2005-01-24 为戊申日，18:00 属酉时，故时柱 = 辛酉。

## 五、排盘示例

假设排出四柱为"甲子 丙寅 戊午 己未"：

- 日主：**戊土**（日柱天干）。
- 四柱地支：子(水)、寅(木)、午(火)、未(土)。
- 天干：甲(木)、丙(火)、戊(土)、己(土)。

五行统计（粗略看天干 + 地支本气）：木 2、火 2、土 3、水 1、金 0。金明显偏弱（缺金）。在此基础上再看日主旺衰与十神，进而取用神。

## 六、真太阳时说明

- 中国统一用东八区北京时间，但排盘讲究"真太阳时"：需按出生地经度对北京时间作时差校正（每 1 度约差 4 分钟）。
- 若出生时刻恰在时辰交界附近，校正后可能落在相邻时辰，会改变时柱甚至日柱（子时交界）。此时应提示用户该边界情况，以专业排盘工具为准。
