# 日主分析：滴天髓十干性情 + 穷通宝鉴十二月调候

> 这是看日主"本性"与"调候"的核心资料。先看日干本性（滴天髓），再结合出生月的调候需要（穷通宝鉴）判断日主是否得配、最缺什么气。调候是"自然气候"层面的需求，与扶抑（强弱）是两回事，两者都要看，不能互相替代。

## 二、《穷通宝鉴》十二月调候（按月取调候用神）

### 常用日干调候简要说明

- **甲木**：冬春（子丑寅）喜丙火暖局、癸水生扶；夏木喜水滋；秋木喜庚金雕琢成材。
- **丙火**：火性猛烈，四时基本喜壬水相济；冬月火弱更需甲木生火、戊土制水。
- **戊土**：厚土喜甲木疏土、癸水润泽、丙火温暖；冬季寒土尤需丙火暖局。
- **庚金**：顽金喜丁火锻炼；冬月金寒喜丙丁暖；夏月金过燥喜壬癸水淬。
- **壬水**：水性奔流，喜戊土筑堤、庚金发源、丙火调候防寒。

### 调候与扶抑的区别

| | 调候 | 扶抑 |
| --- | --- | --- |
| 看什么 | 寒暖燥湿（自然气候） | 强弱旺衰（力量大小） |
| 原则 | 冬喜火、夏喜水、燥喜润、湿喜燥 | 旺则克泄耗、弱则生扶 |
| 取用 | 如丑月戊土，寒，故喜丙火 | 如身强，喜食伤财官杀 |
| 关系 | 气候上的需求 | 力量上的需求 |

> 例：丑月戊土，寒土喜丙暖，这是**调候**；若八字火土成势而身强，又需金水**扶抑**（泄耗）。两者可能指向不同五行，要同时列出、交叉判断，不互相取代。

## 三、使用方法提示

1. 先按日干查"滴天髓本性"，用一两句说清日主底色。
2. 再按出生月查"调候用神"，判断该月日主最缺什么气候之气、局中是否已备。
3. 调候所喜与格局/扶抑所喜一致时，该命"顺而成局"可能性大；不一致时说明局中有矛盾（如既寒又无火、既燥又无水），要在综合解读中点明。
4. 调候用神**以天干透出、坐下有根、不被克破**为"得力"；浮而无根或被克，为"调候失力"。
