# 大运、流年与分主题解读

> 本文件服务论命的第四、五、六步：①大运起法与排法；②流年看法；③分主题解读（事业、财运、感情婚姻、健康、学业）。每条结论都要回扣"干支/十神/格局/旺衰/用神"依据。

## 一、大运的起法

### 1. 起运岁数

- 由出生日到最近节气的天数，按"三天折一年"（约 3 天 = 1 岁）估算起运岁数。
- 阳年男、阴年女：顺排（生日起顺数至下一节气）；阴年男、阳年女：逆排（生日起逆数至上一节气）。
- "阳年"＝年干为甲丙戊庚壬；"阴年"＝年干为乙丁己辛癸。

### 2. 大运干支

- 顺排：从月柱干支顺次下排一位（月柱"丙寅"→"丁卯"→"戊辰"…）。
- 逆排：从月柱干支逆次上排一位（月柱"丙寅"→"乙丑"→"甲子"…）。
- 每步十年，排 8 步左右即可。

### 3. 示例

阳年男命，月柱"丙寅"，顺排大运：丁卯、戊辰、己巳、庚午……每步十年。

## 二、大运分析方法

大运定十年大方向。每步大运的干支代入命局，看它与日主、用神、忌神、格局的关系：

- **大运助用神、制忌神** → 这十年整体较顺，所主领域（印主学业、财主财运、官杀主事业压力与地位等）有起色。
- **大运助忌神、克用神** → 这十年多波折，相关领域吃力。
- **大运干支与四柱发生合冲刑害** → 应事最明显（如运冲日支夫妻宫，感情易波动；运合用神，机遇转好）。
- 天干管前五年、地支管后五年的传统分法，可作为年代切分参考，但以整柱综合看为主。

**输出**：列出大运表格（大运、年龄、干支、简析），再分段概述早年、中年、晚年的总趋势，以及当前所走大运。

## 三、流年分析方法

流年＝当年干支（如 2024 甲辰、2025 乙巳），看其五行十神代入命局后，与**大运、命局**的作用：

- **助用神、制忌神** → 该年较顺。
- **助忌神、克用神** → 该年多波折。
- **引动合、冲、刑、害**（尤其冲夫妻宫、冲用神、合化成势）→ 应事最明显。
- 流年十神所在宫位与六亲：如流年冲年柱多应祖上家庭、冲日支多应婚姻内心、冲时柱多应子女晚年。

**原则**：大运定十年大方向，流年定当年具体吉凶重点；先讲大运，再逐年落到人事（学业、事业、财运、感情、健康、迁徙、是非）。

## 四、分主题解读（内容框架）

把命局分析、十神、大运流年综合后，落到以下具体层面，**越具体越好**，每条结论回扣"干支/十神/格局/旺衰/用神"依据。

### 1. 事业

- 由格局 + 用神 + 十神结构，定"靠什么吃饭、做什么最顺"。
- 给行业/角色方向（如技术、文书、经营、武职、表达/创意等），精确到方向，不铁断具体职位。
- 看官杀（事业地位、纪律、压力）、食伤（才华技艺）、印（学识文凭）的旺衰与配合。

### 2. 财运

- 看财星（正财/偏财）旺衰、透干与通根情况、被劫还是得护。
- 求财路径：食伤生财（技艺/才华生财）、财格身强（经营理财）、身弱财旺（财多身弱难担财）等。
- 判断财富层级倾向与"正财/偏财/技艺/经营"哪种路径更顺。

### 3. 感情婚姻

- 男命看财（财为妻星）、女命看官杀（官杀为夫星）。
- 结合日支（夫妻宫）的藏干、十神、是否被冲刑害，以及全局桃花/红鸾/合冲。
- 讲缘分早晚、配偶特质、相处模式、宜早婚或晚婚的倾向。

### 4. 健康倾向

- 五行偏枯、被冲克、受刑对应脏腑（如金旺克木→肝胆筋骨；水寒湿土→脾胃；火弱→阳气心血等）。
- 仅作倾向性提醒，不点名具体疾病。

### 5. 学业

- 看印星（正印/偏印）旺衰与是否得力，文昌贵人是否出现。
- 看官杀（考试压力、进取心）与食伤（悟性、发挥）的配合。
- 结合印星被克（财坏印、枭印夺食）的年份，判断学业波动。

## 六、使用提示

- 起运岁数与日柱换算繁琐，若用户未提供精确时间/地点，应说明假定、以专业排盘工具为准。
- 所有结论与用神/格局/旺衰挂钩，形成"五行→十神/格局→人事"的连贯逻辑。
- 保持克制：负面信息用"需留意/宜谨慎"，禁用恐吓词；不制造焦虑。
