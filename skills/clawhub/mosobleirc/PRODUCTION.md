# Развёртывание

Это публичная инструкция, не описание частной инфраструктуры.
Runtime хранится вне skill; настройка описана в README. Поддерживаются direct и private yandex-relay.

Версия исходника relay: `1.0.1`. Наличие исходника в репозитории не означает, что функция где-либо развёрнута.

Перед обновлением сделайте защищённую резервную копию runtime. Обновление bundle не заменяет runtime. Локальный status не обращается к провайдеру; live smoke требует отдельного намерения пользователя и не входит в release checks.
