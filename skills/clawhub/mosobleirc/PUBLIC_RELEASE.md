# Публичный релиз 1.0.1

Bundle содержит `scripts/`, опциональный `relay/yandex/`, `config/*.example.json` и документацию. Direct и Yandex relay являются независимыми transport-адаптерами поверх одного write-flow. Runtime создаётся `setup` вне каталога skill. Пользовательский пример inventory минимальный и полностью синтетический; расширенный test fixture также не содержит реальных идентификаторов.

Перед публикацией выполните четыре проверки из README и проверьте состав архива с учётом .clawhubignore. release_check проверяет рабочее дерево, но не Git history и не доказывает отсутствие всех персональных данных. Публикация и deployment выполняются отдельно; тесты не требуют сети.
