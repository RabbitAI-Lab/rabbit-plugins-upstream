## Description:

Set up a durable local SEO workspace: working folder, site scope, goals, positioning, MCP and project check, and Search Console intake.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users, SEO practitioners, and operators use this skill at the start of a website SEO project to establish a local workspace, collect site scope, goals, positioning context, Search Console inputs, and Conqueror MCP project status before choosing the next workflow.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may guide an agent to organize local project notes, Search Console exports, and Conqueror MCP project data.

Mitigation: Use it only with the intended SEO website or project, and avoid adding sensitive files unrelated to SEO work.

Risk: Incorrect setup details could lead later SEO workflows to use the wrong website scope, goals, project, or Search Console data.

Mitigation: Confirm the working folder, site scope, Conqueror MCP project, and Search Console connection or exports before continuing to downstream workflows.
