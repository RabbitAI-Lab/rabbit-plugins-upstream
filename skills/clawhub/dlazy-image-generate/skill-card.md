## Description:

Selects dLazy models to generate and edit images from prompts and optional reference media.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to select dLazy models for image generation and editing from text and optional reference media. The bundled instructions also describe video and audio generation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected local media may be sent to dLazy services.

Mitigation: Review submitted content and confirm that the dLazy service is trusted before use.

Risk: Installing the CLI and generating media can expose account data or consume credits.

Mitigation: Prefer the pinned on-demand CLI if a persistent install is unnecessary; protect API keys and monitor credit usage.
