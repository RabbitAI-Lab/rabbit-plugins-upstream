# 抖音平台创作与运营规则

> 用途：供 CTAI-WD 在生成抖音视频选题、口播稿、字幕、标题、发布文案和质检结果时调用。
>
> 规则性质：合规要求属于硬约束；时长、钩子、节奏和互动方式属于运营建议，应结合账号数据持续调整。不得把运营建议描述为抖音官方算法结论。

## 1. 平台定位

抖音以竖屏短视频和直播为核心。内容需要在移动端快速建立理解，让用户尽早知道“这条内容和我有什么关系”。

生成目标：

- 优先解决单一、明确的用户问题。
- 使用口语表达，避免报告体、长定语和连续抽象概念。
- 一条视频只承载一个核心判断或一个主要行动目标。
- 兼顾无声观看，关键信息不能只依赖声音表达。

## 2. 生成前必填上下文

生成脚本前必须取得：

- 当前人设及表达边界。
- 内容目标：涨粉、互动、建立信任、获客或转化。
- 目标受众及其真实问题。
- 内容类型：知识、观点、案例、测评、故事、产品或活动。
- 目标时长。
- 是否涉及商业推广、商品、医疗健康、金融、未成年人等高风险领域。
- 可核验的产品事实、数据、案例和来源。

信息不足时，不得编造数据、客户反馈、政策、功效或身份资质。

## 3. 推荐内容结构

### 3.1 开场

建议在最早的有效表达中完成以下至少一项：

- 点明受众：“做外贸的老板”“第一次做短视频的人”。
- 提出具体问题：“为什么你的询盘很多，成交却很少？”
- 给出结果预期：“一分钟讲清三个审核误区”。
- 呈现反差或变化，但不能制造虚假恐慌。
- 直接展示结果、现场或关键证据。

避免：

- “大家好，今天给大家分享……”式低信息量寒暄。
- 与正文无关的夸张标题或悬念。
- 绝对化承诺、虚假倒计时和强迫互动。

### 3.2 正文

推荐结构：

```text
具体问题 → 原因或误区 → 证据/案例 → 可执行动作 → 自然收束
```

正文要求：

- 短句优先，一句话表达一个意思。
- 每隔一个信息段出现一次例子、画面提示、数字或转折。
- 观点与事实分开；数据说明来源和时间。
- 专业术语第一次出现时用普通语言解释。
- 产品内容先讲适用场景和选择条件，再讲卖点。
- 不为了节奏删除必要的适用条件、风险提示和证据边界。

### 3.3 结尾与 CTA

CTA 应与内容目标一致：

- 互动：提出一个容易回答、与正文相关的问题。
- 关注：说明后续持续提供什么价值。
- 私信或咨询：说明适合哪些人，不制造稀缺或虚假承诺。
- 商品转化：给出选择条件、适用人群和必要限制。

避免机械要求“点赞、评论、转发”三连，以及与内容无关的口令式互动。

## 4. 时长与信息密度

时长不是固定规则，以下为生成默认值：

| 内容类型          |   建议时长 | 生成侧重点             |
| ----------------- | ---------: | ---------------------- |
| 单一技巧/结论     |   20–40 秒 | 一个问题、一个答案     |
| 三点拆解/轻案例   |   40–90 秒 | 强结构、短句、明确转折 |
| 专业解释/完整案例 |  90–180 秒 | 证据、案例和行动建议   |
| 深度知识内容      | 3 分钟以上 | 分章节、持续提供新信息 |

不得为了压缩时长牺牲事实准确性或风险说明。账号历史完播、互动和转化数据应优先于默认建议。

## 5. 语言、字幕与画面

- 默认使用自然中文口语；具体语气由人设决定。
- 字幕按语义分行，单屏避免堆叠长段文字。
- 关键信息、数字和结论同步出现在字幕或画面中。
- 字幕不得遮挡人物面部、商品关键部位或平台交互区域。
- 画面提示必须服务正文，不使用无关素材制造虚假现场感。
- 引用他人素材时确认使用权限，并避免去水印搬运或混淆原创身份。
- 使用 AI 生成或合成内容时，按照平台当期要求进行必要标识，不伪造真人、事件或权威背书。

## 6. 标题、发布文案与话题

标题或首行建议：

- 包含受众、问题、结果或场景中的至少两项。
- 让标题承诺与视频实际内容一致。
- 使用具体词替代“震惊、必看、赶紧”等空泛刺激词。

发布文案建议简洁补充视频信息，不重复整段口播稿。话题标签应与内容真实相关，优先使用：

- 1–2 个行业或领域标签。
- 1–2 个具体问题或场景标签。
- 必要时使用活动或品牌标签。

不得堆砌无关热词、冒用事件标签或通过标题误导用户。

## 7. 原创与真实性

- 不直接搬运、拼接或轻度改写他人内容冒充原创。
- 不伪造专家、客户、媒体或机构身份。
- 不编造销量、排名、功效、收益、案例和用户评价。
- 演绎、情景再现和虚构案例应避免让用户误认为真实事件。
- 对争议性新闻、政策和数据进行来源核验，不把相关性写成因果。
- 内容修改后再次检查标题、字幕和画面是否仍与事实一致。

## 8. 商业内容与高风险领域

涉及商品、服务、品牌合作或商业推广时：

- 明确商业目的，不伪装成无利益关系的客观测评。
- 产品能力以企业知识库和可核验证据为准。
- 不使用“最好、第一、百分百、永久、零风险”等无法证明的绝对化表述。
- 不承诺确定收益、治愈效果、考试结果、投资回报或其他不可控结果。
- 医疗健康、金融、教育、食品、未成年人等领域必须加载对应行业规则与资质要求。
- 涉及电商交易时，同时加载抖音电商现行内容规范，不以本文件替代商品发布和广告合规审查。

## 9. 社区安全与表达边界

生成内容不得包含或鼓励：

- 违法活动、危险挑战、自残、自杀或伤害他人。
- 仇恨、歧视、骚扰、网暴和对个体隐私的侵犯。
- 色情低俗、未成年人不当内容或利用未成年人营销。
- 虚假信息、诈骗、恶意引流和规避平台治理的表达。
- 未经授权泄露个人、客户或企业敏感信息。

争议内容应讨论行为、制度、事实和证据，不使用族群、地域、性别或身份标签替代论证。

## 10. 抖音与 TikTok 不得共用的规则

抖音和 TikTok 属于不同市场与治理环境，不得只替换语言后复用：

- 平台流行文化、音乐、话题和用户表达习惯不同。
- 内容审核、广告、电商和行业资质要求不同。
- 抖音默认面向中国大陆市场，TikTok 需要结合具体国家或地区。
- 抖音中文口播的停顿、字幕和信息密度不能机械套用英文 TikTok 模板。

## 11. 输出格式

生成器应输出：

```text
【平台】抖音
【内容目标】
【目标受众】
【建议时长】
【标题/首行】
【口播脚本】
【字幕重点】
【画面建议】
【发布文案】
【话题标签】
【风险与核验项】
```

## 12. 发布前质检

- [ ] 前段已明确受众、问题或价值。
- [ ] 标题、口播、字幕和画面表达一致。
- [ ] 一条视频只有一个主要内容目标。
- [ ] 每个数据、案例、资质和产品主张均可核验。
- [ ] 无绝对化承诺、虚假稀缺和误导性互动。
- [ ] 商业内容已加载对应行业与电商规则。
- [ ] 字幕易读，重要信息不只依赖声音。
- [ ] 素材拥有授权，原创身份表达准确。
- [ ] CTA 与内容相关且不过度诱导。
- [ ] 已根据抖音最新官方规则进行发布前复核。

## 13. 维护与更新

平台规则会持续调整。本文件的运营建议可用于生成，但发布前应以抖音官方最新规则为准。建议每季度复查一次，遇到平台重大规则更新时立即升级版本。
