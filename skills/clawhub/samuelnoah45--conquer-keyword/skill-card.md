## Description:

Conquer a keyword: rewrite the connected WordPress site's best-matching page for it and propose the change as a reviewable diff with a before/after summary.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, marketers, and site operators use this skill to turn a target keyword into a reviewable WordPress page revision based on existing content, search intent, and competitor SERP context.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated revisions may introduce factual inaccuracies, unsupported claims, or wording that does not match the site's brand voice.

Mitigation: Review the generated diff for factual accuracy, brand voice, and suitability before applying it to the live site.

Risk: WordPress editor structure may be damaged if Gutenberg block comments or shortcodes are not preserved in the proposed revision.

Mitigation: Check the proposed revision for preserved block comments, shortcodes, links, and images before approval.

Risk: The skill reads WordPress posts and draft content through Conqueror for the selected project.

Mitigation: Install and use it only for projects where agent access to WordPress post and draft content is acceptable.
