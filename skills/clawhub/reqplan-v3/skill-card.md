## Description:

Guides multi-step software engineering work through a seven-stage workflow with reviewed artifacts and resumable state.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers use ReqPlan-v3 to plan and carry out multi-step feature work, bug fixes, code reviews, refactors, testing, and documentation. It produces staged analysis, design, implementation, verification, and quality review artifacts, with saved state for resuming work across sessions.
