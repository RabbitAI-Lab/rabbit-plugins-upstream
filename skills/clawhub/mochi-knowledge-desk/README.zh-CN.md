# 本地知识资料库

[English](README.md)

给本地文档建立可增量更新的资料库，支持中英文检索、原文片段和来源定位。

## 功能

给本地文档建立可增量更新的资料库，支持中英文检索、原文片段和来源定位。

在当前助手的工作区运行，输出处理结果和报告，原文件保留。

## 用法示例

安装后，把任意一条发给 AI，并附上相关文件或网址。

```text
把我提供的 docs 文件夹建成资料库，以后新增文件只更新有变化的部分。
```

```text
查找资料库里与“退款条件”有关的内容，给我原文片段和文件出处。
```

```text
检查这些搜索结果对应的原文件有没有变化，导出一份资料清单。
```
