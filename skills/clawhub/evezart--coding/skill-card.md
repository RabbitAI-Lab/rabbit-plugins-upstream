## Description: <br>
Coding style memory that adapts to your preferences, conventions, and patterns for consistent coding. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[evezart](https://clawhub.ai/user/evezart) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and coding agents use this skill to remember explicitly confirmed coding preferences and apply them consistently in future code output. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Preference memory can influence future coding output if incorrect or stale entries are stored. <br>
Mitigation: Store only explicitly confirmed preferences and review the local memory periodically. <br>
Risk: One reference file has confusing wording about updating SKILL.md for preferences. <br>
Mitigation: Keep preference updates in ~/coding/memory.md or ~/coding/history.md and do not modify the skill files for user preferences. <br>
