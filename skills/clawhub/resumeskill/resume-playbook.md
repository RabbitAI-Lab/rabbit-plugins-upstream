# 简历改写手册

## 一、目标定位：简历是写给岗位看的

同一段经历，面向不同岗位要有不同讲法。改简历前必须明确：

- 这个岗位最核心的 3-5 个能力项是什么？
- 岗位偏爱什么样的候选人画像？
- 面试官最想看到的经历和证据是什么？

简历的每一句话都应服务于上述问题。无关信息能删则删。

## 二、能力迁移翻译表

把"学生语言"翻译成"岗位语言"。

| 原始表述 | 岗位语言（示例） | 适用岗位方向 |
|---|---|---|
| 参加了社团活动 | 策划并执行 3 场 200+ 人线下活动，负责宣传、嘉宾对接、现场统筹 | 运营 / 市场 / 项目管理 |
| 写过课程论文 | 独立完成 8000 字行业研究报告，基于 XX 数据/案例得出结论 | 研究 / 战略 / 产品 |
| 做过小组作业组长 | 担任 5 人项目组长，拆解任务、协调进度、汇总成果 | 产品 / 项目管理 |
| 用过 Excel 整理数据 | 搭建数据汇总表，支持 10+ 个维度交叉分析 | 数据分析 / 运营 |
| 帮老师做过公众号 | 负责公众号选题、排版与发布，单篇最高阅读量 XXX | 内容 / 新媒体 |
| 自学过 Python | 使用 Python 完成 XX 任务（数据清洗 / 爬虫 / 自动化） | 技术 / 数据 / 产品 |

注意：翻译不能夸大。原始经历支撑不了的程度，不要写。

## 三、STAR 法则实操

每段经历建议按 STAR 结构改写：

- **S (Situation)**：背景一句话，交代项目/业务场景
- **T (Task)**：你的任务/目标是什么
- **A (Action)**：你具体做了什么（重点）
- **R (Result)**：取得了什么结果，尽量量化

### 改写示例

**原表述**：
> 在校园媒体中心负责公众号运营，发布过多篇文章。

**改写后**：
> 负责校园媒体中心微信公众号运营，独立完成选题策划、采访撰稿、排版发布全流程；任职期间产出原创内容 12 篇，累计阅读量 3.2 万，其中 2 篇进入当周校园热文榜前 10。

## 四、量化技巧

量化能大幅提升简历可信度，但不可捏造。常见可量化维度：

- **规模**：用户数、数据量、覆盖人群、团队人数
- **效率**：提升了多少百分比、缩短了多少时间
- **成果**：阅读量、转化率、GMV、留存率、评分
- **过程**：访谈场次、测试次数、文档页数、迭代版本

如果原始经历中没有明确数字，可以这样处理：

1. 优先让用户补充真实数字。
2. 无法补充时，用范围或相对描述（如"数百条用户反馈"、"显著降低"）。
3. 绝对不编造。

## 五、模块优先级

根据岗位不同，简历各模块的权重可调整：

| 岗位类型 | 最看重的模块 | 次看重的模块 |
|---|---|---|
| 技术岗 | 项目经历、技能栈 | 实习经历、开源贡献 |
| 产品岗 | 项目经历、实习经历 | 产品分析、校园经历 |
| 运营岗 | 实习经历、项目/活动经历 | 数据成果、内容作品 |
| 咨询/战略 | 研究经历、实习经历 | 案例分析、学术成果 |
| 设计岗 | 作品集（可附链接）、项目经历 | 实习经历、竞赛获奖 |

## 六、常见错误

| 错误 | 修改方向 |
|---|---|
| 岗位通用型简历 | 一份简历对应一个岗位，差异化改写 |
| 只写职责不写成果 | 用 STAR + 量化替代职责罗列 |
| 经历太碎、重点不突出 | 合并同类项，突出最相关的 3-4 段经历 |
| 空话套话多 | 删掉"认真负责、沟通能力强"，用经历证明 |
| 排版花哨、信息密度低 | 一页优先，结构清晰，重点前置 |
| 编造经历/数据 | 绝不编造，风险极高 |

## 七、一页 vs 两页

- 应届生/实习生：**一页**优先。
- 工作 3 年以上/经历非常丰富：可适当两页，但需确保第二页有足够含金量。
- 博士/学术型岗位：按领域惯例，可两页以上。
