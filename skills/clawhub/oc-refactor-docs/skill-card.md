## Description:

Refactor an existing OpenClaw docs page with source-audited preservation, restructuring, and verification.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers use this skill to refactor OpenClaw documentation while preserving and checking behavior-sensitive facts against authoritative sources.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Referenced source material may be outside the scan, leaving some claims incompletely evidenced.

Mitigation: Review the referenced documentation and authoritative source files before relying on behavior-sensitive claims.

Risk: A documentation rewrite could omit or misstate behavior-sensitive details.

Mitigation: Compare the original and revised page against authoritative sources, and preserve, move, or explicitly retire each fact.
