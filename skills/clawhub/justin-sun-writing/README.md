# Justin Sun Writing

## Compatibility

This is a portable `SKILL.md` package. ClawHub's install panel displays the native OpenClaw command because ClawHub is the OpenClaw registry; that UI does not describe the full compatibility surface.

The same instructions are compatible with Codex, Claude Code, and Hermes because each can load a skill from a folder containing `SKILL.md` with YAML frontmatter.

| Platform | Installation |
|---|---|
| OpenClaw | `openclaw skills install @0xcjl/justin-sun-writing` |
| Codex | Copy `SKILL.md` to `~/.codex/skills/justin-sun-writing/SKILL.md`. |
| Claude Code | Copy `SKILL.md` to `~/.claude/skills/justin-sun-writing/SKILL.md`, or the equivalent project `.claude/skills/` path. |
| Hermes | `hermes skills install https://raw.githubusercontent.com/0xcjl/justin-sun-writing/main/SKILL.md --name justin-sun-writing` |

## Scope

Create or revise restrained Chinese first-person narratives using credible concrete details, narrator blind spots, recurring objects, and relationship-driven tension. It is for original fiction or user-supplied material, not impersonation or claims about real people.
