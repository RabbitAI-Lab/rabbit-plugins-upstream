## Description:

Guides agents through creating, editing, validating, and rendering HyperFrames video projects from briefs, existing media, and project files.

This skill is ready for commercial/non-commercial use.

## Publisher:

[heygen-com](https://clawhub.ai/user/heygen-com)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to plan, produce, revise, and render videos and motion graphics in HyperFrames, or to inspect and maintain existing projects.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Standalone workflows may install or refresh remote skills and upgrade a project's pinned dependency.

Mitigation: Prefer the plugin installation; for standalone use, request approval before updates or upgrades and review dependency changes.

Risk: Project commands can modify files or trigger publishing, capture, or external-provider actions.

Mitigation: Review proposed actions and require approval before publishing, capturing, or using external providers.
