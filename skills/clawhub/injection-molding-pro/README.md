# 注塑模具专业助手 (injection-molding-pro)

> 注塑成型全流程技术支持技能，覆盖从材料选型到成本估算的完整链路。

[![Platform](https://img.shields.io/badge/platform-WorkBuddy-green)](https://www.codebuddy.cn)

## 功能模块

| # | 模块 | 说明 |
|---|------|------|
| 1 | **材料选型** | 26 种常用注塑材料物性数据，含 Cross-WLF + Tait PVT 参数 |
| 2 | **工艺优化** | 注塑工艺参数推荐与调机指南 |
| 3 | **缺陷诊断** | 27 种常见缺陷原因分析与对策，含嵌件成型、水辅/气辅 |
| 4 | **DFM 审查** | 可制造性设计规则清单化审查 |
| 5 | **模具结构** | 浇口、流道、冷却、顶出设计指南 |
| 6 | **仿真规范** | Moldflow / Moldex3D 分析规范，含嵌件成型开裂分析 |
| 7 | **公差分析** | 收缩率与尺寸公差分析 |
| 8 | **成本估算** | 模具成本与单件成本快速估算 |

## 快速开始

### 安装到 WorkBuddy

1. 下载本仓库所有文件
2. 放入 WorkBuddy skills 目录：`~/.workbuddy/skills/injection-molding-pro/`
3. 在对话中通过 `@skill:injection-molding-pro` 调用

### 使用示例

```
@skill:injection-molding-pro PEEK 材料在新能源汽车连接器上怎么设工艺参数？
@skill:injection-molding-pro 产品缩水了，壁厚3mm，材料ABS，怎么解决？
@skill:injection-molding-pro 帮我审查这个DFM，壁厚最薄处1.2mm
```
