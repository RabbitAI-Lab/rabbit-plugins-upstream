## 1. 水辅成型 (Water-Assisted Injection Molding, WIT)

**原理**：先注一段熔胶 → 高压水经活塞喷嘴注入已充模腔 → 水压推动熔胶形成空腔 → 冷却成型。同源气辅，但介质为水。

**相对气辅优势**：水的热导率比氮气高 ~40 倍、热容大 ~4 倍 → 厚壁件冷却时间比气辅减少 30–75%；管壁更薄更均匀、内壁更光滑；适合内径 10–50mm 异型管件。

**工艺类型**：
- 水气共注法（co-injection）：省料+水芯部冷却快；缺点：出水口表面缺陷、低压水可能渗入制品-模具间隙。
- 炮弹法（projectile）：同质内径、适合导管；壁厚可至 3mm、内径公差 ±0.5mm；限制：必须固定内径。

**关键参数**：注水前无需保压冷却，注水后用水压保压冷却；注水器压力/水流速、延迟时间、流体保压时间。

**适用材料**：结晶/非结晶均可，关注填充物种类含量、粘度、水分含量。

**应用**：汽车冷却水管、中冷器管、节温器壳体、散热器水室、水管接头（以塑代钢，减重最高 50%）。

## 2. 包覆成型 Overmolding（塑料+金属带连续进料）

**定义**：塑料包覆金属带（metal strip）成型；与嵌件成型区别：嵌件是单个放入，包覆是金属带连续进料+专用定位装置。

**设计准则（通用）**：
- 注射点：优先单点；两点时距离 20/25/30/35mm（Manner 双喷嘴标准），且必须同高；金属嵌件开孔（≥Ø1.2mm）与注射点同位；对侧做"蘑菇头"锚固。
- 封胶边（shut off）：最小宽 0.50mm；固定半尽量少放产品形状；金属嵌件法兰（形状不定）上不做封胶；避免 R 形交叉。
- 金属嵌件支撑：足够支撑防弯曲，上下半模具支撑点同位。
- 定位：靠侧边外形（in/out）或足够精确的孔定位。
- 拔模/圆角：与常规塑件无差；包覆搭接处（lap）在分型面必须做成 R 形曲面。
- 塑件最小壁厚 0.30mm（临界薄壁需特别注意浇口位置/排气防缺料）。

**案例 Zeus LCD shield**：硅胶+金属片包覆；Manner 热流道针阀浇口，每腔1阀针；2腔模；70T Engel。优先选 Manner 热流道针阀（软材+金属片结合工况苛刻）。

**标准模架**：Perlos PHM3530/PHM4030（含料带导向、连续进料机构、气动单元）。

**料带连续进给补充要点（reel-to-reel / 卷对卷）**：
- 金属带从放料卷 → 步进(indexing)进给 → 进模包覆 → 收料卷，全程不停；进给精度 ±0.05mm 级，进给装置磨损/定位销松动直接废件。
- 动模用带拔模角的球头销(ball-end pins)定位金属带，易于就位。
- 顶出板由注塑机驱动，**同时**推动顶针 + 进给装置完成脱模与步进。
- 金属带下方走流道通道 → 可免剪浇口(needn't gate cutting)。
- 软材+金属片组合工况苛刻 → 热流道优先 Manner 针阀系统；冷却能力要足。

**与 Insert Moulding（离散嵌件，常被叫 "intermod"）的区别**：

| 维度 | Overmolding（料带连续，Perlos 定义） | Insert Moulding（离散嵌件） |
|---|---|---|
| 嵌件形态 | 连续金属料带 carrier strip | 单个预制嵌件（金属/已成型塑件） |
| 进给方式 | 放料卷→步进→模具→收料卷，连续不停 | 机器人/人工单件放入模腔 |
| 设备 | 立式/专用 overmolding 机 + 连续进给装置 | 立式机 + 转台/机械手/六轴 |
| 定位 | 料带定位孔/侧边形状 + 进给装置定位销 | 模内定位针/套、定位圆孔≥1.5mm |
| 结合 | 机械咬合为主（孔/蘑菇头/开槽） | 机械咬合为主（嵌件与塑料无化学结合） |
| 典型产品 | 屏蔽罩、端子、连接器外壳 | PPA+GF 金属嵌件件、带金属轴齿轮、螺母预埋 |
| 模具标准 | Perlos PHM3530/PHM4030 标准模架 | 常规模架 + 嵌件定位机构 |
| 优势 | 效率高、自动化强、适合大批量薄壁 | 适合复杂单件、异形嵌件 |

> 注：Perlos 原文明确 "Overmolding ... Different from insert molding, plastic + metal strip molding, ... metal strip continuous feeding"。二者最大分界是**连续料带进给 vs 单件放入**。行业里 overmolding 还广义指 2K 软硬双射包覆（见第 9 节）。

**典型失效速查表**：

| 现象 | Overmolding（料带）优先查 | 2K 软硬包覆优先查 |
|---|---|---|
| 飞边 | 封胶边 <0.5 mm / flange 误封胶 / r 形交叉 | 第一射吸瘪 / 封胶面刮伤亮斑 |
| 欠注 | 薄壁区浇口/排气 / 注射点位置 | 第二射壁厚不均 / 收缩大 |
| 脱粘/结合差 | 料带定位偏 / 支撑不足弯曲 | 材料对未验证 / 第一材温度低 / 收缩差大 |
| 困气/亮斑 | 薄壁排气 | 第二射排气难（封胶面夹第一射） |
| 翘曲 | 料带支撑不均 | 第二组分收缩过大 |

**风险提示**：
- 金属料带 overmolding：进给精度 ±0.05 mm 级，进给装置磨损/定位销松动直接废件，需定期维护。
- 2K 软硬：第一材温度直接决定结合强度（"第一材越热 gripping 越好"），但软胶（TPE/TPU）不耐高温，需平衡。
- 硅胶 overmolding（如 Zeus 案例）用热流道针阀，注意硅胶硫化与停机清理，防死料。

## 3. ICM 注塑压缩成型 (Injection Compression Moulding)

**原理**：充填之初模具不完全锁闭（型腔留较小初始间隙），部分熔体注入后，锁模机构闭合、由模芯/模壁对熔胶施加压缩完成充填与保压。压力主要来自**模具运动**而非保压，仅需足够保压消除缩水。

> ⚠️ **修正（2026-07-13）**：初始间隙**按制件尺寸/厚度设定，非固定值**（文献：gap size 须先固定以获得目标注射速率曲线），常见为 sub-mm 至数 mm 不等。**不可写成 "0.1–0.2mm" 通用定值**。

**设备**：专用液压机或 Fanuc+附加软件（Fanuc 为 Perlos 标准机）。

**用途**：光学窗口（手机镜窗等）控制双折射（birefringence），表面质量极高；亦广泛用于菲涅尔透镜、DVD/CD-ROM、反射罩、导光板、微透镜阵列、车灯等精密光学件。

**核心收益（8 项）**：降射出压力 / 降残余应力 / 减分子定向 / 均匀保压减不均收缩 / 克服凹陷翘曲 / 减双折射 / 缓比容积变化 / 增进尺寸精度。

**定量佐证**：Moldex3D 导光板案例——ICM 使型腔应力由 **48 MPa 降至 12 MPa**；残余应力、翘曲、双折射显著下降。

**变体**：
- 全型腔压缩（标准，光学透镜）
- 局部/分区压缩（特定区域）
- Coining（完全充填后再压缩）
- 微压缩 In-mould microcompression（微米级，微透镜阵列，常配 variotherm 变温）

**Nokia 光学规格**：表面粗糙度 Rq<10nm；平面度<5µm/25mm；透光率>92%（450–650nm）；雾度<1%；双折射<λ/16（600nm 波长即 retardation<37.5nm）。

**双折射控制**：最大值通常在浇口处 → 浇口保压压力越低越好；需专用双折射测量机（约 6万€）。

**模具结构**：可动型芯覆盖光学区（William 模用 10 吨弹簧保持合模线）；IMD-ICM 模动件需在固定半+主流道/热流道。

## 4. E-Mold 电加热模具（消除熔接痕/高光）

**目的**：开模时加热型腔表面使塑料保持熔融 → 消除熔接痕、提高表面质量（高光/哑光/耐化）。

**原理**：类三板模动作——A0/A1先开模 → 到5mm时A0/B0开模 → 对C101加热型芯加热；合模停止加热，C102冷却水冷却制品。加热与冷却分离，效率高于蒸汽模。

**结构**：C101加热型芯(正面装，S136S，厚~50mm，四周比C102大30–35mm)；C102冷却板(小尺寸用铜/大尺寸用铝，距制品边25–30mm)；A0前模板(通腔板，单边避空1mm)；A1顶板(C102镶深15mm)；顶板上加电木绝热板。

**加热元件**：NADA标准加热棒 EMH-Ø4.9/Ø5.9，模具孔Ø5.0/Ø6.0(+0.1)；加热区必须伸入C101内≥5mm（防爆炸危险）；加热棒距胶位3mm、距冷却板1.9mm；加热棒孔单边避空0.5mm。

**测温**：NADA热电偶 EMT-Ø2.4/Ø3.2；伸入加热区才准确；不放在加强筋上方。

**效果**：熔接痕/流痕/浇口痕消失；高光钢琴黑；哑光纹理一次成型；金属镀后尺寸稳定、附着力提升3倍；耐热；玻纤填充料外观改善（PA+GF40%模温200°C、PP碳纤75%模温280°C）。

## 5. RHCM 急冷急热（高光/无熔接痕）

**原理**：电磁感应或电阻加热模具到树脂熔融温度(~200°C)约10s，再约10s冷却到80–90°C（开模加热、合模冷却）。

**效果**：非结晶玻纤料表面光泽提升、壁厚可减0.1mm、消除熔接痕；评估中：减少铣削应力开裂。

**技术对比（来源表）**：
- 感应加热(Roctool)：3–7s(8°C/s)，license 45k€/项目+3% royalty
- 电阻加热(E-Mold/Nada)：3–5s(12°C/s)，license 25k€/工厂
- 蒸汽/热水：成熟但周期长(30–60s)

**玻璃嵌件成型 GIM**：玻璃+PC+GF20–30%结合，玻璃收缩0%；玻璃与型芯间隙0.05mm（不接触）；胶合推荐热敏/UV胶。

**适用**：Unibody、GIM、玻纤料外壳（手机高光盖、LCD边框、DVD面板）。

## 6. LDS 激光直接成型 (Laser Direct Structuring)

**定义**：在注塑成型塑件表面，用激光“书写”电路图形并活化，再化学镀铜/镍形成导电结构（MID 三维模塑互联器件）。与 **IME**（膜片电路一体成型）、**2K-MID**（双射+电镀）同属 MID 三大路线；LDS 是其中 **“一回成形法”**——只需单组份注塑一次，激光按 CAD 图形直接走线，无需二次成型或膜片。

**四步工艺链（LPKF-LDS / MID 标准流程）**：
1. **注塑 (Injection)**：用含激光活化添加剂的 LDS 专用料一次注塑成型。添加剂为有机金属络合物（常用铜系，如 Cu2(OH)PO4 类），均匀分散于树脂基体。
2. **激光活化 (Laser Activation)**：激光按电路 CAD 图形扫描，局部分解添加剂形成金属核（Cu 核），同时在塑料浅表微蚀出粗糙面（Ra 增大）为镀层提供锚固点。激光像“笔”把线路写到 3D 表面。
3. **金属化 (Metallization)**：化学镀（Electroless，无需通电）。先清洗再沉铜——镀速 8–12 µm/h（LPKF）；铜厚通常 5–8 µm（金发 Vismid 规范）或 12–15 µm（KYOCERA AVX，适用 >400 MHz RF，防趋肤效应）；再化学镀镍 1–2 µm 防腐，可选闪金 0.1 µm 改善焊接/接触。
4. **组装 (Assembly)**：SMT 贴装元件（点胶焊膏，因焊点高度不一）、3D 组装、汽相焊/导电胶/键合等。

**激光参数（参考）**：扫描速度 ~4 m/s；网格间距（hatch）55 µm；频率 60–100 kHz；功率 4–7 W。

**材料体系（须含活化添加剂，不可普通料替代）**：
- **PC/ABS 系**：Xantar LDS 3710（通用）、金发 Vismid® 3200/3201LDS（V-1，韧性与尺寸稳定）
- **PC 系**：Xantar LDS 3720/3730（改性 PC，耐热/高要求）、Vismid® 2100/2102LDS（V-0）
- **高温尼龙/PA 系**：Vismid® SOL 6360LDS（PA10T 30%GF，极低吸水、适无铅回流焊）、SOL 65250LDS（PA 35%GF/矿物）
- **LCP 系**：Vismid® SOL 8365LDS（LCP 30%GF，高流动薄壁）、SOL 8485LDS（LCP 40%矿物，低翘曲）——LCP/PPA 耐典型回流焊温度，汽车级首选（如 Vectra E840i 经 85°C/85%RH 1000h 零缺陷）
- **PBT/PET 共混**：亦可选，耐回流焊兼容 SMT

**设计准则（DFM）**：
- 走线宽 ≥150 µm（保守 DFM；量产极限约 75 µm，先进设备可达 40 µm）；走线间隙 ≥200 µm；通孔孔径 Φ80–100 µm
- 走线面拔模角 25–30°，保证脱模与激光可达
- **严禁激光阴影**：顶针、熔接线、分型线、深腔死角若落在走线区，激光照不到 → 断路。复杂 3D 形状需评估激光可达性（LDS 相对 IME 的硬约束）
- 镀层附着力 >9 N/cm（剥离强度）
- 材料须 LDS 专用料；非激光活化料无法金属化

**失效模式**：
| 现象 | 主因 | 对策 |
|------|------|------|
| 走线断路 | 激光阴影/未活化/功率不足 | 优化激光路径、避阴影、校功率 |
| 镀层剥落 | 表面粗糙不足/附着力差/污染 | 控激光参数增锚固、清洗 |
| 线宽不均/短路 | 激光抖动/图形重叠 | 校 hatch、间距 |
| 焊盘虚焊 | 镀层氧化/金层薄 | 加闪金、控储存 |
| 翘曲变形 | GF 料收缩/壁厚不均 | 选低翘曲牌号（矿物增强）|

**与 IME / 2K-MID 选型（NISSHA 三工法对比）**：
- **二回成形法（双射+电镀）**：深/复杂 3D 形状 OK，但细线/复杂电路不行，需 2 次成型，工程重
- **一回成形法（LDS，即本工艺）**：比二回成形线更细，仅需一次注塑；但**只能用特殊树脂**、激光死角处加工不了
- **IME（膜片电路一体成型）**：大型件 OK，膜片需 preform 拉伸，可用一般/透明树脂，精密电子件+装饰同成型；但形状受膜片拉伸限制
- **选哪条**：任意 3D 走线 + 小型件 → LDS；装饰+功能平面电路、成本敏感 → IME；深腔复杂 3D + 高可靠 → 2K-MID

**应用与趋势**：手机天线（约占 LDS 用量 75%）、汽车（转向盘毂、刹车/位置传感器、雷达罩）、医疗（助听器、血糖仪、牙科笔，案例装配时间 20→6 s、零件 8→3、成本降 78%）、IoT/穿戴。设备如 LPKF Fusion3D 1100/1200/1500。
**LDS 固有局限（IDTechEx）**：仅单层金属化（无 crossover，电路复杂度受限）；量产分辨率约 75 µm；两步法需送外电镀（IP 暴露风险）；仅限注塑塑料。新一代数字沉积（气溶胶/挤出导电浆）正补这些短板。
**库内延伸**：双射 MID 天线设计见知识库《2K-MID Antenna Design Guideline V02》；IME 详见 §8.4；与 IME 对标见 outputs/ime-detailed-guide.html。

## 7. 嵌件成型 Insert Moulding（金属/非金属预埋）

**结合本质**：嵌件与塑料之间**无化学结合**，须靠孔/筋做机械咬合（mechanical adhesion）。

**嵌件受力**：嵌件须抵抗塑料收缩；成型中模具须将其**固定在位**直至填充完成。

**定位 (Positioning)**：推荐用一个圆孔便于定位，最小直径 1.5mm；定位销与嵌件间隙 0.02mm；嵌件开始接触型腔处与型腔间隙推荐 0.05mm。

**封胶避曲线 (Shut off in curve)**：避免把封胶面落在嵌件的曲面区（飞边与碰伤风险高）。

**支撑针 (Support pins)**：嵌件须包在塑料内部时必用；表面无处下支撑孔时用可动支撑针（末端呈顶针印状）。

**塑料流动**：嵌件两侧料流不均会使其弯曲 → 把嵌件设计在塑料中点或给薄侧加支撑。

**飞边控制**：嵌件尖角若无机械封胶易进胶飞边，外观件应避免此类结构。

**螺丝嵌件自动化**：夹爪上设传感器孔检嵌件；顶针带真空/气孔；可动顶针把嵌件推入型腔。

**生产单元**：①单六轴机器人（最便宜、+1s 周期）；②双机器人；③三轴+六轴；④立式机+转台（成本最高、嵌件只能放动模侧）。

**建议**：嵌件模强烈推荐先做预生产模（pre-production tools）。

## 8. IMD 家族（模内装饰总览：IML / IMR / INS / IME）

**IMD = 模内装饰的总称（umbrella），并非单一工艺。** 行业内"IMD"有**两义**：(A) 总称；(B) 特指"卷对卷转印"那一支（≈IMR）。为避免歧义，交流须落到以下无歧义子名。**判别主轴：膜片是否留在制件上。**

| 子工艺 | 膜片处理 | 拉伸能力 | 典型应用 |
|---|---|---|---|
| **IML**（In-Mold Labeling / Lamination） | 膜片**留件上**（可单片放入或热成型后放入；Western durable-goods 语境常与 FIM 同义） | 较深（比 IMD 卷膜支深） | 装饰/视窗/按键、家电面板 |
| **IMR**（In-Mold Roller / Rolling） | 卷对卷热转印，**载体剥离**、仅图形转印到件 | 浅（罕见 >6mm） | 3C、家电、汽车外饰/功能面板 |
| **INS / IMF**（Insert / In-Mold Forming） | 厚膜（~0.5mm ABS+PMMA）热吸塑/高压成型→裁切→嵌入注塑 | 高拉伸（汽车内饰） | 仪表板饰条、门饰条、扶手、名牌 |
| **IME**（In-Mold Electronics） | IMD 升级：膜片集成导电线路/LED/触控/天线 | 继承 IML/INS | 汽车智能表面、家电控制面板（"电子皮肤"） |

> 注：INS 可视为"高拉伸版 IML"；IMF 在高拉伸语境常与 INS 同义。IME 多为 IML 工艺执行（Plastics Decorating）。

### 8.1 IML 模内贴标（留膜支，主用）

**适用判断**：IML 适合很多应用但非万能；仅当自然契合产品驱动力/几何/装饰时才用；把 IML 推过极限会拖垮项目。

**优点**：印刷阶段一次性集成大量装饰、比 IMD 卷膜支（≈IMR）可成型更深、可集成视窗/按键、图样灵活、可多层材料（皮革/合成织物）。

**局限**：不适复杂几何（仅为成型 2D 膜片）；材料选定后成型/裁切/注塑须作为**整体工艺**设计，后期难改。

**几何设计准则**：
- 完全平面标与 2.5D 标（视窗）需在型腔内固定、用立式机；开放 C/H 形或软 O 形难处理易变形；多折弯复杂形不可工业化。
- 成型比（forming ratio）保持合理：比 IMD 卷膜支深，但比值越大图质与量产可行性越差（印刷变形、成型应力回弹、裁切不可靠）。
- 3D 切口须简洁：侧切增加模具/维护成本与工艺不稳定。
- 膜片与分型线留 0.2–0.3mm 开口间隙（防飞边、防剥离，皮革尤甚）；足够圆角、不用尖角凹形；对称利于注塑中定型；用孔框等细节定型；避免小孔（厚膜难裁）。

**膜材**：PC（最常见，耐磨差，适结构件非光学，配 PC/ABS）；PMMA（视窗/镜片，光学与耐磨好，不适结构件与复杂件，配 PMMA）；PET（印刷/光学/耐磨好，难成型易回弹"IML 钛"，适结构件，配 PC/PET）。

**模具**：印刷/成型/裁切/注塑互为影响→整体设计；1 家供应商统包；浇口位置/形状须压住膜片防冲蚀(wash out)；型腔全抛光以增加膜片-型腔摩擦、避免表面粗糙度差。

**验证**：须打样验证整体设计；膜片注塑中被拉伸变形 → 量产前定准裁切尺寸；印刷变形在网版补偿；模具结构功能经 ≥5000 件试跑验证。

**IML 留膜件结构（三层）**：透明硬化层(top, 耐刮, 可 3H+) → 印刷油墨层(middle, 夹心) → 基膜(back, PC/PET/PMMA, 成为件一部分)。油墨夹中间 → 耐刮、不变色。

### 8.2 IMR 模内转印（转印支）

卷对卷（roll-to-roll）热转印：印刷薄膜经送膜机穿过模具分型面 → 真空吸附贴模 → 注塑时仅装饰油墨层转印到树脂 → 开模载体膜自动剥离、**不留件上**。适用 3C、家电、汽车外饰/功能面板。几何受限：拉伸深度浅（行业经验罕见 >6mm）。

### 8.3 INS / IMF 厚膜高拉伸

~0.5mm ABS+PMMA 膜（PMMA 约 25%）经热吸塑/高压成型做 3D 拉伸 → 按制件外形裁切嵌片 → 准确置入型腔注塑。设计自由度高（深拉伸、复杂型面）、失真小；汽车内饰主流（仪表板饰条、门饰条、扶手、后扶手、名牌）。可视为"高拉伸版 IML"。

### 8.4 IME 模内电子（功能延伸，技术门槛最高的一支）

**定义**：IMD 家族的"电子化"升级——在装饰膜（多为 PC）上用**可热成型导电油墨**印刷电路，并集成 LED / IC / 电容触控 / 天线，再与塑件一体注塑成型，使装饰件同时具备**触控 / 照明 / 传感**功能（行业称"电子皮肤 / smart surface"）。多经 IML 工艺执行（Plastics Decorating）。

**工艺链（四步，CIDETEC 框架）**：
1. **印刷 Print**：在平板膜（PC/PET）上丝印/凹版印刷导电银浆 + 介电层 + 元器件焊盘。
2. **热成型 Thermoform**：膜片加热→真空/高压拉伸到 3D 形状。⚠️ 此步是 IME 与 IML 的本质分水岭：导电油墨须**抗拉伸不裂**（银浆拉伸率有限，过拉伸→断线）。
3. **贴装 Assemble**：在成型膜上 SMT 贴 LED/IC（或预置连接器）。
4. **注塑 Inject**：将带电路的膜片置入型腔，注塑背衬树脂（多为 PC/PC-ABS），一体成型。

**材料体系（以供应商 TDS 为准，下同）**：
- **基膜**：聚碳酸酯 PC 为主（耐热、透明、与导电油墨粘结好）；部分用 PET（但难深拉伸、易回弹）。
- **导电油墨**：银浆（方阻最低，主流，如 NAMICS XE181 / Dycotec DM-SIP-1006）；碳浆（低成本、阻值高，如 NAMICS XE182）；铜浆（成本/导电折中，抗氧化难）；可拉伸银浆（生物基，30% 应变不断、5000 次弯曲电阻 +8%，前沿）。
- **介电层**：印刷绝缘油墨（如 NAMICS XE185），做交叉走线/覆盖保护。
- **导电胶**：SMD 器件贴装用各向异性/各向同性导电胶（如 NAMICS H9230）。

**设计准则（区别于普通 IML）**：
- **拉伸率限制**：导电线路区拉伸率须严控（银浆经验上限约 10–15%，过限断线）；线路布局避开高拉伸区（R 角、深拉顶部）。
- **线宽/间距**：量产稳健线宽 ≥150µm、间距 ≥150µm（细至 100µm 需评估良率）；细线 + 深拉伸 = 高风险组合。
- **器件布局**：SMD 器件避开浇口正对区与高剪切流道末端；LED/IC 须耐注塑热（背衬料温 + 模具温度，短时），不耐热的用后装或选耐温器件。
- **热成型窗口**：膜片加热温度 / 拉伸深度须与油墨耐热匹配；过度加热→油墨氧化/脱层。
- **接地/屏蔽**：天线、触控需考虑膜内接地与 EMC，设计阶段就定。

**失效模式**：
| 失效 | 根因 | 对策 |
|---|---|---|
| 线路断裂 | 过拉伸 / 油墨不耐形变 | 限拉伸率、线路避 R 角、换可拉伸银浆 |
| 银迁移 / 短路 | 湿热下银离子迁移 | 介电层覆盖、控湿度等级 |
| 膜片剥离 / 脱层 | 油墨-背衬粘结不足 | 等离子体处理、粘结层、控模温 |
| 器件损坏 | 注塑热/剪切超限 | 选耐温器件、浇口避器件、降剪切 |
| 触控失灵 | 银浆方阻漂移 / EMC | 走线加粗、屏蔽设计 |

**可靠性标准（汽车级为重点）**：
- **温度循环 TCT**：-40 / +85°C（Grade 3, AEC-Q100）→ 行业"torture test"基准；门把手/中控件须过。
- **高温老化 HTOL / 湿热 Damp-Heat**：85°C/85%RH 等；评估银迁移、粘结退化。
- **附着力**：百格 ASTM D3359 **5B**（0% 脱落）为车规目标。
- **行业规格**：GMW16717（薄膜嵌件成型，Type E 车规要求）；成型件耐候 QUV 1500h 级别。
- **降本/提可靠**：浇口优化可降剪切 ~60%（cncprotolabs 案例）；凹版胶印电路已达 AEC-Q100 Grade 3（ASME InterPACK 2025）。

**应用与趋势**：
- 主力：汽车智能表面（门饰板触控、中控台、方向盘、隐藏式出风口/阅读灯）、家电控制面板、白家电"无按键化"。
- 市场：IDTechEx 口径 2033 年约 **$2B**（含 SMD 部件；早期 2032 口径 $1.5B 已更新）。减重可达 70%、零件数显著下降。
- 对标工艺：**LDS 激光直接成型**（本库有专文）——3D 电路另一路线，IME 胜在"装饰+功能一次成型、平面电路成本更低"，LDS 胜在"任意 3D 走线、无需膜片"。选哪条看产品几何与批量。

> 完整版（含工艺链图示、油墨参数表、可靠性验证清单、与 LDS 选型矩阵）见 outputs/ime-detailed-guide.html。

### 8.5 膜结构（功能分层，非固定层数）

- **IMR 转印箔（载体剥离）**：载体 PET（剥离基材）→ 离型层 → 装饰层（油墨/金属化/纹理）→ 粘结/活化层（受热与树脂结合）。件上不留载体。
- **IML 留膜件**：透明硬化层(top) → 印刷油墨层(middle) → 基膜(back, 成为件一部分)。

> ⚠️ 行业常把 IMD 箔统称"多层/五层"，但精确层数随供应商（Kurz、Nissha 等）TDS 不同而变化；**"五层"为泛指，非标准定数**，引用时以供应商 TDS 为准，不写死层数。

### 8.6 选型判据：IMD 卷膜支 vs IML 放入膜片

- **IMD（卷膜过分型面，≈IMR）**：拉伸浅（<6mm 常见）、装饰可做到分型线边缘；但几何受限。
- **IML（放入膜片）**：拉伸深、设计自由度高；但**分型线处膜片易被压溃**、装饰难到边。
- → 选 IMD 还是 IML 的工程主轴：**拉伸深度 + 分型线可达性**。

### 8.7 组合工艺矩阵（装饰 × 成型）

| 成型 ＼ 装饰 | 无 | IML（留膜） | IMR（转印） | INS/IMF | IME |
|---|---|---|---|---|---|
| 标准注塑 CIM | 常规 | ✓ | ✓ | ✓ | ✓（多经 IML） |
| ICM 压缩 | 光学件 | ✓ 光学装饰件 | – | – | – |
| 2K 双射 | 双色 | ✓ | ✓ | ✓ | ✓ |
| Overmolding | 包覆 | – | – | – | – |

> ICM 可叠加在 IMD/IML 上（正交维度）→ "ICM IMD" / "ICM+IML"，用于光学装饰件（如手机窗口盖 Cindy window 类）。

## 9. 双色/双射成型 2K（旋转台/转送/退芯/转盘/滑块）

**五种 2K 技术**：旋转台(Rotation table)、转送法(Transfer)、退芯法(Core back)、转盘(Index table)、滑块技术(Slide)；可组合。
- 旋转台：动模接独立转台，开模转 180° 到二工位；仅定模两侧可异形；两工位产品定位须极准。
- 转送法：各工位于不同模/机台，机械手转送；两侧均可异形；成本最高（两套模+机）。
- 退芯法：液压/机械可动芯在一二射间移动；不适复杂几何（如异形密封）；抗注射压力有限。
- 转盘法：零件留转盘上，转后拉回；可做芯侧与腔侧 2K。
- 滑块法：缸驱动型腔在一二射间移动；适小件单腔样模/预生产模。

**选型矩阵**：二射在腔侧→旋转台/滑块优；在芯侧→转送/退芯/转盘优；两侧都要→转送/转盘；包覆类→旋转台；多腔→旋转台/退芯/转盘/滑块；价格：退芯/滑块低，旋转台/转盘高，组合极高。

**材料配对**：供应商是否实测过粘接？无测试结果 → 用试模或其他项目模确认粘接与其他性能。

**注射顺序**：第二射时第一射已冻结料承受第二射热/压 → **硬料先、软料后**；两料会混合 → **透明先、深色后**。

**注射点**：第一射可见点可被第二料遮盖；第二射点按单料件设计；所有浇口位规则同常规；浇到最厚处；做模流选位查气穴/熔接线；硬料注射点位于软料下方；软料注射点可见。

**壁厚**：尽量均等；**经验值 1.6mm ⇒ 2mm**（2K 设计经验）。

**收缩**：第二料收缩不可过大 → 高应力 → 翘曲/弯 → 粘接力差；第二料受压应力，第一料刚 → 第二料受高拉应力（脆料易裂）；第一料弹性 → 大翘曲。

**分型线/封胶**：第二射分型线可见，须精心设计防飞边；最好在两料间做凹槽淡化边界、吸收飞边与弱粘。

**外观缺陷**：钢与一射封胶不良 → 二射飞边；一射缩凹 → 二射飞边；封胶面过紧 → 刮伤/发亮；边界不清、粘接力差、气穴、熔接线。

**排气**：第二射排气更难（封胶在钢与一射塑件间），无法开气道 → 须模流定位气穴，必要时加排气芯（接受少量外观痕）。

**化学咬合**：配对正确即足够；**第一料越热咬合越好**；熔点尽量接近；料清洁重要；不同 2K 法带来良率波动（转送法两面自由收缩>旋转台）。

**机械咬合**：化学咬合足够时，用孔/筋把两料机械结合。

**案例**：Funky A/B-Shell：PA12 + TPU，旋转台，热咀针阀。

## 10. 微型注塑与 Babyplast 设备要点

**微型注塑（Micro-injection molding）**：成型质量常 <1g（亚毫米级尺寸）的精密注塑，用于医疗、光学、电子、钟表微小件。难点不在"小"，而在**计量精度 + 温度/排气控制 + 微型浇口**。

**Babyplast（西班牙 Cronoplast）**：全球微型注塑领导者（1990 至今，5000+ 台、15+ 机型、20+ 经销商）。**模块化三形态**：卧式 / 立式 / 独立注射单元（UAI，可嫁接到任何常规机变多组分系统）。

### 10.1 核心设备特征
- **柱塞式注射 + 预塑化（piston + pre-plasticization）**：非往复螺杆——先独立塑化、再柱塞高压注射。这是它能稳定打微量、高重复精度的根。
- **机模板即模架（platens = mould bolsters）**：机器模板直接当模架用，微型模具无需大模板 → **模具成本与尺寸大幅下降**（Babyplast 一大卖点）。
- **立式专长嵌件（inserts specialist）**：立式机专为嵌件包覆设计，可选电动转台 / V 型台（V-table），放件人机工效好。
- **UAI 嫁接变 2K**：独立注射单元嫁接到常规注塑机 → 多组分/双色，免购专用双色机。
- **特种版本**：LSR 液态硅胶版（医疗/光学，可不锈钢洁净室版）、Cleanroom 洁净室版（ISO 级，医疗/制药）。

### 10.2 关键参数（两主力系列，柱塞机特性：活塞越小注射压力越高）

| 项 | 6/10P（训练/工业） | 10/12（主流标准） |
|---|---|---|
| 锁模力 | 62.5 kN（≈6.4 t） | **10 t（≈98 kN）** |
| 活塞直径 | Ø10 / 12 / 14 / 16 / 18 mm | Ø10–24 mm |
| 注射压力 | 815–2650 **bar**（Ø10 最高） | 650–815 bar |
| 注射量 | 3–15 cc 级（按活塞） | 4.7–36 cm³ |
| 空循环 | 2.4 s | — |
| 占地 | — | **<0.6 m²** |
| 装机功率 | 2.95 kW | 3.5 kW |
| 温控 | — | PID 最高 420°C / 4 温区（可加第 5） |
| 能耗 | — | 整机含周边 **0.2 kWh/kg** |
| 重量/尺寸 | 125 kg，1100×500×700 mm | — |

### 10.3 微型件 DFM 注意
- **浇口极小**（针点/热咀微浇口），剪切高 → 材料须低粘度易流动；PPA/PEEK 等高温料注意热降解，料温上限从严。
- **模温精度要求高**：微型件对温度敏感，建议油温机 ±1°C；PPA 类见 §2/§7 模温要求（>120°C）。
- **排气极关键**：料流前沿细，易困气 → 排气深度按料 TDS 保守取，微型件常需真空排气。
- **计量重复性**：柱塞机靠位移闭环，料温/料垫/止逆稳定是重复性的前提；建议干燥充分（见材料库含水率要求）。
- **嵌件包覆**：立式机放金属嵌件，参考 §2/§7 嵌件准则（预热、圆角 R≥0.5mm、壁厚≥嵌件径 1/3）；PPA+GF 类见开裂排查逻辑。

## 11. 2K-MID 双射三维电路（双射+电镀 / Double-Shot MID）

**定位**：MID 三大路线中的"二回成形法"（另两路为 LDS 一回成形、IME 膜片成形）。电路图形靠两次注塑的塑料本身区分可镀/不可镀区——图形在注塑时即成型，电镀只"填空"，故**工艺链最短、图形再现性最高**，但模具最复杂、线宽最粗（≥300µm，LDS 可到 ~80–150µm）。

**工艺链（四步）**：
1. **双射注塑**：第一射成型非电镀区基体（PC/LCP 等），转台/旋转→第二射填入可镀料（ABS/Pd-ABS）界定电路图形；自动化去浇口。
2. **化学镀**：粗化/蚀刻（湿化学活化可镀表面微粗糙）→（标准 ABS 需 Pd 活化；Pd 掺杂 ABS 可省）→ 沉铜 6–15µm → Pd 引发 → 化学镍 1–3µm（防腐屏障）→ 接触区可选闪金 → 工业甩干。
3. **100% RF 测试**：谐振特性，网络分析仪判废隔离。
4. 包装（防表面污染/损伤）。

**材料体系（Perlos LOM 实测）**：
- 第一射：Thermocomp AX06472 **PC**（不可镀），GF≤30%（过高影响天线性能）。
- 第二射：**Pd 掺杂 ABS**（蚀刻后直镀，省活化）或 Cycolac MG37EP 标准 ABS（需蚀刻+Pd 活化+镀）。
- 通用：PC(不可镀)+ABS(可镀) 经典配对；或催化 LCP(第一射含图形)+不可镀热塑(第二射包覆，耐回流焊)。两料熔点尽量接近，**第一射热变形温度须高于第二射**。

**结合（Gripping）**：材料对选对即化学结合足够；第一料越热结合越好；料与模清洁重要。⚠ **若结合太差致两射间有间隙，机械互锁也救不了——电镀液渗入间隙→短路/天线不连续**。

**设计准则（Perlos 7 条）**：
- 天线图形槽：槽宽/槽高/壁厚 **最小 0.6mm**；更小尺寸第二射需更多注射点；第二射壁厚用模流分析防注射高压。
- 边缘：不允许电镀翻过边缘则槽周留 **≥0.6mm** 壁。
- 收缩：第二射收缩不可过大→热镀液中应力显现、表面裂纹、两射间隙（会被镀）、第一射翘曲。
- 浇口：模流定注射点/数量；第二射点可置图形外（侧/背），但须接受未遮蔽**会被镀上**。
- 分型线：封胶防第二射飞边/溢料（天线区**不允许飞边**，否则镀区不符设计）。
- 电镀：铜+镍（+接触区金）；⚠ **镍禁用于与皮肤直接接触面**（含电池盖取下后露出的面，即使非长时间接触）。
- 结合：见上条。

**典型失效**：断路（两射间隙/槽未填饱/收缩裂）→ 保结合无隙、槽≥0.6mm；短路（镀液渗间隙）→ 材料对+第一料够热、杜绝飞边；翘曲（热镀液中第一射被拉弯）→ 两料收缩/熔点匹配；性能漂移（第一射 GF 过高/两射对位）→ GF≤30%、对位精度管控。

**选型矩阵（2K-MID / LDS / IME）**：深 3D + 大批量(≥1M/年) + 高再现→**2K-MID**；细线(~80–150µm)+灵活改版+中小量→**LDS**；平面/大尺寸+装饰+功能一体（可嵌有源件）→**IME**。

**资料**：Perlos《2K-MID Antenna Design Guideline V02》(2010)；TE Connectivity 2-Shot MID 镀线（青岛，铜 6–15µm/镍 1–3µm/闪金/100% RF）；Hahn-Schickard（催化 LCP 第一射+湿化学粗化+Cu/ENIG/Ag）；NISSHA 三工法对比；Cicor/newmaker（线宽≥300µm）。

> 完整版（工艺图/材料对照/7 条准则/失效表/三路线选型）见 outputs/2k-mid-detailed-guide.html。

## 12. MuCell 微发泡（物理发泡减重）

**定义**：Trexel 公司商品化（MIT 1980s 提出），将氮气/二氧化碳加热加压至超临界态注入料筒，与熔体形成单相溶液；入模降压后气体膨胀成 5-50 微米闭孔，靠气孔膨胀填模、在低压下成型。

**核心价值**：
- 减重 5-40%（通常 10-20%），料耗省 8-20%
- 成型周期缩短 15-50%（常见 20-30%）：免保压 + 加速冷却
- 锁模力需求降 30-80%（可小机打大件、增腔、用铝模）
- 内应力小、翘曲降 50-75%、无缩水、尺寸稳定
- 超临界气体降熔体黏度达 60%，可降料温、助难加工料填充

**工艺要点**：
- 需 MuCell 螺杆 + SCF（超临界流体）计量单元（Trexel 发生器，N2/CO2）
- 注射：短射(short shot) + 气体膨胀填模，阀针浇口控料
- 去除保压阶段（或极低），免保压保时
- 排气加大 25-50%（填充末端、薄筋、顶针/镶件排气）
- 模温可比实体注塑低，利于缩短冷却

**设计与材料注意**：
- 表面气纹/流痕（银纹状 swirl marks）：高外观件需配变模温(E-Mold/RHCM)或皮纹/咬花掩饰
- 不适用 PC（抗冲击降）；厚薄突变处发泡不均
- 肋/壁厚比可达 1:1（突破传统限制）

**典型失效**：表面气纹→调注射曲线/配变模温；减重不达标→薄区困气挤泡，加大排气/改浇口；翘曲反弹→保压曲线优化。

**资料**：Trexel MuCell；PTonline；SMARTMolding 模具设计；百度百科微发泡注塑。

## 13. 随形冷却 / 3D 打印异形水路（Conformal Cooling）

**定义**：DMLS/SLM 金属 3D 打印模具镶件，冷却水路沿型腔轮廓均匀偏移（1-2×直径），克服传统直线钻孔无法贴合曲面的局限。

**核心价值**：
- 周期降 25-40%（案例达 48%）：冷却段占周期 60-80%，是最大优化点
- 模温均匀度 ±5-8°C（传统 ±15-25°C）
- 翘曲/缩痕降 60-75%，尺寸稳定

**设计规则**：
- 通道直径 4-8mm（<4mm 压降>3-4bar 需增压；>8mm 湍流度降、传热降 30-40%）
- 距型腔面 ≥2×直径（≥3mm）
- 螺旋包柱/型芯 ROI 最高（消热节缩痕）
- 总长>2m 需 AFM 抛光降 Ra 8-15→3-5 微米 控压降

**材料**：
- Maraging steel MS1(1.2709) 主导：490°C/6h 时效 50-52 HRC，导热 15-20 W/mK（约 P20 的 60%，需多 30-40% 通道表面积）
- H13 DMLS 高寿命需 HIP(1100°C/100MPa) 消孔

**成本/ROI**：镶件 8k-15k USD vs 传统 2k-4k USD；年 8 万-12 万件回本（8-14 月）。

**局限**：粉末/打印成本高、导热略低需更大表面积、需 CAE(Moldflow/Moldex3D) 仿真设计、增材后处理。

**与业务**：高光外壳、深腔件、热节缩痕件降本提质首选；可 retrofitting 现有模。

↔ 模具结构见 mold-structure-design.md §2.2。

**资料**：tstar-mold；SSPrecision；ChanHonTech 案例(冷却-48%)；Cimatron；PTI(2025)。

## 14. LSR 液态硅胶注塑（Liquid Silicone Rubber）

**定义**：双组份铂催化热固性，A:B=1:1 精确计量混合，高温 140-220°C 交联固化（非物理冷却）。

**核心工艺**：
- 计量：高精度齿轮泵/柱塞泵，A:B 严格 1:1（失调→不固化/软胶）
- 冷流道 + 针阀：零废料、精确计量、短周期；无针阀冷流道因硅胶热膨胀难保尺寸→推荐针阀
- 模温 170-200°C（±1°C 精度），固化温度 140-220°C
- 收缩率 2-4%（固化时），压缩变形
- 注射"慢-快-慢"多段：初慢排气、快填防过早硫化、末降速排气
- 保压补偿固化收缩；固化时间实验定

**三大难题（低粘度如水）**：
- 飞边（溢料）：合模力/分型面/注射压管控，飞边控制 <0.02-0.05mm
- 困气/烧焦（气泡）：排气槽 Ra<20 微米 迷宫效应 + 真空系统，料流末端/分型面/顶针
- 浇口预固化（死料）：冷流道温控、防局部过热、定期清螺杆/静态混配管

**缺陷速查**：不完全固化(温低/时短/污染/非1:1)、表面不干(空气污染/脱模剂)、气泡(排气/回温/真空)、白斑(湍流→改层流)、飞边(合模/磨损/压高)、缺料缩水(供料/温高/锁模)。

**脱模**：顶针/气推，固化硅胶易粘金属。

**材料/设备**：A:B 冷藏 5-25°C、用前回温 23±3°C 防凝水；螺杆密封防固化；忌含阻聚剂防锈油（甲苯/二甲苯擦模）。

**应用**：三电密封件（电池盖密封圈、充电枪）、医疗、汽车（耐候）。

↔ 与 Babyplast LSR 版衔接（§10）。

**资料**：cncprotolabs；jzsilicone；simcone；anysiliconerubber；siparts。

## 15. 气辅注塑成型（Gas-Assisted Injection Molding, GAIM）

**定义**：在部分填充（短射/欠注）的型腔中注入高压氮气（N₂），气体沿阻力最小路径穿透熔体核心形成中空通道，由内压完成保压补缩。适用于厚壁、厚薄不均、长管/把手/板棒类制件，可消缩水、降锁模力、省料。

**工艺流程**：
1. 熔体短射填充 60-95% 型腔（预留气体空间）
2. 气针注入高压 N₂（经喷嘴或模具气针）
3. 气体穿透熔体核心，将熔体推向型腔末端（掏空厚壁）
4. 气体保压补缩直至冷却定型
5. 泄压、排气、顶出

**结构/设计要点**：
- 气道（Gas Channel）：置于厚壁处，截面尽量近圆形；长宽比约 2:1~4:1；气体沿厚壁走，薄壁区不进气
- 气道壁厚 : 制件壁厚 ≈ 1.5~2 : 1（过薄气体不进，过厚指形效应）
- 气针位置：厚壁末端或易困气处；单针 vs 多针按流程定
- 溢料腔/溢流包：制件末端或气道终点设溢料包，捕集冷料与气体末端，避免吹穿与表面气印
- 短射量：70-98%（太满无空间→吹穿；太少→欠注）
- 浇口：尽量单一、近气针，避免多浇口气体乱窜

**与水辅（WAIM）对比**：
| 维度 | 气辅 GAIM | 水辅 WAIM |
|------|-----------|-----------|
| 介质 | N₂ 气体（可压缩） | 高压水（不可压缩） |
| 内壁质量 | 较粗糙（空气可压缩） | 光滑（水贴壁推净） |
| 掏空率 | 中（气体选择性穿透） | 高（水填满推净） |
| 适用 | 把手/厚壁/板棒/家电件 | 长管/以塑代钢/高内壁要求 |
| 周期 | 较短 | 需排水，略长 |

**关键控制**：注气延迟 0.3-1s、气压 50-250 bar 逐级升、注气时间 3-20s、保压气时间=冷却时间。详见缺陷库 §27。

**应用**：家电把手、卫浴/管件、汽车内饰厚壁件、打印机/复印机框架。

**资料**：gas-assist 成型综述；BASF/Siemens 气辅应用；Moldflow GAIM 求解器文档。
