# 成本估算指南

> 本文件包含注塑模具和注塑件的成本估算方法，用于报价和成本控制参考。

> ⚠️ 本指南为估算性质，实际成本受地区、供应商、加工难度、交期等因素影响。

---

## 一、模具成本估算

### 1.1 模具成本构成

```
模具总成本 = 材料费 + 加工费 + 标准件费 + 热处理费 + 表面处理费 + 设计费 + 试模费 + 管理费
```

| 成本项 | 占比 | 说明 |
|-------|:---:|------|
| 模仁材料 | 10-15% | 取决于材料和大小 |
| 模架 | 5-10% | 标准模架或定制 |
| 加工费（CNC/EDM/WEDM）| 35-45% | 最大成本项 |
| 标准件（顶针/导柱/弹簧等）| 3-5% | |
| 热处理 | 5-8% | 淬火/氮化 |
| 表面处理 | 3-5% | 镀铬/咬花/抛光 |
| 设计费 | 5-8% | |
| 试模费 | 3-5% | 试模材料+机时 |
| 管理费/利润 | 10-15% | |

### 1.2 模具成本经验估算法

**方法 A：按投影面积估算**

| 复杂度 | 单价 (元/cm²) | 说明 |
|:---:|:---:|------|
| 简单件（平面、少筋）| 15-25 | |
| 中等件（有筋/柱/孔）| 25-40 | |
| 复杂件（多滑块/精密）| 40-60 | |
| 高精密件（光学/医疗）| 60-100+ | |

**估算示例：**
制品投影面积 200cm²，中等复杂度，1出2：
```
模具成本 ≈ 200 × 30 × 2 × 1.5(系数) ≈ 18,000 元
```

**方法 B：按重量估算**

| 模具重量 (kg) | 简单价 (元/kg) | 适用 |
|:---:|:---:|------|
| <100 | 200-350 | 小模具 |
| 100-500 | 180-300 | 中模具 |
| 500-2000 | 150-250 | 大模具 |
| >2000 | 120-200 | 超大模具 |

### 1.3 影响模具成本的关键因素

| 因素 | 影响程度 | 说明 |
|------|:---:|------|
| 型腔数量 | 高 | 多腔增加材料+加工，但分摊单件成本低 |
| 模具材料 | 中高 | P20→718H→NAK80→S136 递增 |
| 表面要求 | 中 | 抛光等级、咬花面积 |
| 滑块/斜顶数量 | 高 | 每个滑块增加5-15%成本 |
| 精度等级 | 高 | 精密模具加工费翻倍 |
| 热流道系统 | 中 | 增加2-5万/腔 |
| 模具寿命要求 | 中 | 长寿命需硬钢+热处理 |

### 1.4 模具寿命参考

| 模具等级 | 模仁材料 | 预期寿命 (模次) | 适用场景 |
|---------|---------|:---:|---------|
| 经济级 | P20 | 10-30万 | 小批量/打样 |
| 标准级 | 718H/P20 | 30-50万 | 中批量 |
| 长寿命级 | NAK80/S136 | 50-100万 | 大批量 |
| 超长寿命 | S136淬火/H13 | 100-300万 | 超大批量 |
| 玻纤专用 | H13+硬质合金 | 30-50万 | GF增强材料 |

## 二、单件成本估算

### 2.1 单件成本构成

```
单件成本 = 材料费 + 加工费 + 辅助材料费 + 废品损耗
```

| 成本项 | 公式 | 说明 |
|-------|------|------|
| 材料费 | 单件重量 × 材料单价 / 合格率 | 含浇口废料 |
| 加工费 | 机时费 / 每模件数 / 合格率 | 机时费=设备折旧+人工+能耗 |
| 辅助材料 | 包装/脱模剂/干燥能耗等 | 通常占5-10% |
| 废品损耗 | 总成本 × 废品率/(1-废品率) | |

### 2.2 材料单价参考

| 材料 | 参考单价 (元/kg) | 说明 |
|------|:---:|------|
| PP | 8-12 | 通用 |
| ABS | 12-18 | |
| PC | 25-35 | |
| PA66 | 25-35 | |
| PA66-GF30 | 35-50 | |
| PPS | 50-80 | |
| PPS-GF40 | 70-120 | |
| POM | 18-25 | |
| PC/ABS | 20-30 | |
| PMMA | 20-30 | |

### 2.3 机时费参考

| 注塑机吨位 (吨) | 机时费 (元/h) | 说明 |
|:---:|:---:|------|
| 50-100 | 30-50 | 小机 |
| 100-200 | 50-80 | |
| 200-300 | 80-120 | |
| 300-500 | 120-180 | |
| 500-800 | 180-280 | |
| 800-1200 | 280-400 | |
| >1200 | 400-600+ | 大机 |

### 2.4 单件成本估算示例

**条件：**
- 材料：ABS，15元/kg
- 制品重量：50g
- 浇口废料：10g
- 注塑机：150吨，机时费65元/h
- 型腔数：1出2
- 循环时间：30秒
- 合格率：95%

**计算：**

```
每模材料 = (50 + 10) × 2 = 120g = 0.12kg
每模材料费 = 0.12 × 15 = 1.80元
每模机时费 = 65 / (3600/30) = 65 / 120 = 0.54元
每模总成本 = (1.80 + 0.54) / 0.95 = 2.46元
单件成本 = 2.46 / 2 = 1.23元/件
```

### 2.5 循环时间估算

循环时间 = 注射时间 + 保压时间 + 冷却时间 + 开合模时间 + 顶出时间

| 阶段 | 估算 | 说明 |
|------|:---:|------|
| 注射 | 1-5s | 取决于体积和速度 |
| 保压 | 2-10s | 取决于壁厚和浇口 |
| 冷却 | 5-60s+ | 主要时间（见工艺指南）|
| 开合模 | 3-8s | 取决于模具大小 |
| 顶出 | 1-3s | |

> 冷却时间通常占循环时间的 50-70%，是成本优化的关键。

## 三、成本优化方向

### 3.1 降低单件成本的途径

| 方向 | 方法 | 效果 |
|------|------|:---:|
| 增加型腔数 | 1出1→1出2→1出4 | ★★★ |
| 缩短冷却时间 | 优化水路/降模温 | ★★★ |
| 减少废料 | 热流道/小浇口 | ★★ |
| 提高合格率 | 工艺优化 | ★★★ |
| 降低材料成本 | 换替代材料/加填充 | ★★ |
| 自动化取件 | 机械手/传送带 | ★ |

### 3.2 模具投资回报分析

```
模具投资额 = 模具成本
单件节约 = 单件成本(旧方案) - 单件成本(新方案)
盈亏平衡点 = 模具投资额 / 单件节约
```

**决策原则：**
- 盈亏平衡点 < 年产量 → 值得投
- 盈亏平衡点 > 2年产量 → 需评估
- 盈亏平衡点 > 3年产量 → 不划算
