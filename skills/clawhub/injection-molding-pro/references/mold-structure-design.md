# 模具结构设计指导

> 本文件包含注塑模具结构设计的指导原则，覆盖浇注系统、冷却系统、顶出系统、分型面等核心模块。

---

## 一、浇注系统设计

### 1.1 主流道

**设计要点：**
- 锥度：2-4°（小端取大值）
- 入口直径：比喷嘴孔大 0.5-1.0mm
- 出口直径：根据制品体积和流道系统确定
- 球面R：比喷嘴球面R大 0.5-1.0mm
- 长度：尽量短（<60mm 为佳）

### 1.2 分流道

**流道截面形状对比：**

| 形状 | 效率 | 加工难度 | 应用 | 备注 |
|------|:---:|:---:|------|------|
| 圆形 | 最高（100%）| 高 | 两板模/热流道 | 需两半模加工 |
| 梯形 | 较高（85%）| 低 | 三板模/标准应用 | 最常用 |
| U形 | 较高（80%）| 低 | 通用 | |
| 半圆 | 低（50%）| 低 | 不推荐 | 热损失大 |
| 矩形 | 低 | 低 | 不推荐 | 脱模困难 |

**流道直径推荐：**

| 制品重量 (g) | 流道直径 (mm) | 说明 |
|:---:|:---:|------|
| <10 | 3-4 | 小件 |
| 10-50 | 4-6 | 中小件 |
| 50-200 | 6-8 | 中件 |
| 200-500 | 8-10 | 大件 |
| >500 | 10-12 | 大件 |

**流道长度原则：**
- 尽量短（减少压力损失和废料）
- 多型腔：等长布置（平衡流道），确保各腔同时填充

### 1.3 浇口设计

**浇口类型选择：**

| 浇口类型 | 适用场景 | 优点 | 缺点 |
|---------|---------|------|------|
| 直浇口 | 大件、单腔 | 压力损失小、保压好 | 浇口痕迹大、需后处理 |
| 侧浇口 | 通用、多腔 | 简单灵活 | 需人工剪切 |
| 潜伏浇口 | 外观件、自动断 | 自动断浇口、痕迹小 | 加工难、压力损失大 |
| 点浇口 | 三板模、外观件 | 痕迹小、自动断 | 模具复杂、压力损失大 |
| 扇形浇口 | 扁平件、透明件 | 流动均匀、减少取向 | 去浇口困难 |
| 薄膜浇口 | 平板件 | 减少翘曲 | 去浇口困难 |
| 多浇口 | 大件、薄壁长件 | 缩短流长比 | 熔接线问题 |

**浇口尺寸经验公式：**

```
浇口深度 d = n × t

其中：
t = 制品壁厚 (mm)
n = 系数

| 材料 | n值 |
|------|:---:|
| ABS, PS | 0.6-0.7 |
| PP, PE | 0.6 |
| PC | 0.7-0.8 |
| PA66 | 0.5-0.6 |
| POM | 0.6 |
| PPS | 0.5-0.6 |

浇口宽度 w = (1.5 ~ 2.0) × d
浇口长度 L = 0.8-1.2mm（越短压力损失越小）
```

**浇口位置原则：**
1. 设在最厚截面（从厚→薄流动，保压效果好）
2. 避开外观面和受力区
3. 远离精密孔和薄壁区
4. 对称布置，保持流动平衡
5. 熔接线避开受力区和外观面
6. 避免熔体直接冲击型芯（防止喷射纹和型芯偏心）

## 二、冷却系统设计

### 2.1 冷却水路布局

**设计原则：**
- 水路到型腔壁距离 = 1.5-2.0 × 水路直径
- 水路间距 = 3-5 × 水路直径
- 动定模温差 < 5°C
- 热节区域（厚截面、柱子、筋根）加强冷却

**水路直径选择：**

| 模具尺寸 | 水路直径 (mm) | 水流量要求 |
|---------|:---:|:---:|
| 小型模具 (<300mm) | 6-8 | >3 L/min |
| 中型模具 (300-600mm) | 8-10 | >5 L/min |
| 大型模具 (>600mm) | 10-14 | >8 L/min |

### 2.2 冷却水路类型

| 类型 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| 直线型 | 简平板件 | 加工简单 | 冷却不均匀 |
| 折线型 | 复杂轮廓 | 贴合型面 | 加工较复杂 |
| 螺旋型 | 圆柱型芯 | 冷却均匀 | 加工复杂 |
| 隔板型 | 深型芯 | 可深入 | 效率较低 |
| 喷淋型 | 细长型芯 | 可深入细孔 | 流量小 |
| 铍铜镶件 | 热节区域 | 导热极好 | 成本高 |

> **随形冷却（Conformal Cooling）**：见先进成型工艺 advanced-processes.md §13——DMLS/SLM 金属3D打印异形水路，沿型腔轮廓均距布置，周期-25~40%、翘曲-60~75%，是降本提质第一热点。

### 2.3 冷却时间优化

- 模温每降低10°C，冷却时间约减少10-15%
- 但模温过低可能影响结晶度和表面质量
- 优化目标：在保证质量的前提下找到最低可行模温

## 三、顶出系统设计

### 3.1 顶出方式选择

| 方式 | 适用场景 | 特点 |
|------|---------|------|
| 顶针 | 通用 | 最常用，适合大多数结构 |
| 顶管 | 环形柱状结构 | 均匀顶出空心柱 |
| 顶板 | 薄壁容器、杯形件 | 整圈接触，均匀 |
| 顶块 | 加强筋、深沟 | 面接触，减少变形 |
| 气顶 | 薄壁深腔 | 利用压缩空气辅助 |
| 斜顶 | 内侧倒扣 | 侧向抽芯+顶出 |

### 3.2 顶针布局原则

- 均匀分布，顶出力平衡
- 优先布置在结构强度高的位置（筋交叉处、柱子附近）
- 避开外观面和精密孔
- 顶针直径：φ3-φ8（常用），φ1.5以下慎用
- 顶针面积总和 ≥ 制品投影面积的 5-10%

### 3.3 顶出行程

- 顶出行程 ≥ 制品最大高度 + 5-10mm 余量
- 必要时加限位装置

## 四、分型面设计

### 4.1 分型面选择原则

1. **设在制品最大轮廓处** — 确保脱模不干涉
2. **避免设在外观面** — 分型面会留痕迹
3. **有利于排气** — 分型面是最好的排气面
4. **简化模具结构** — 减少侧抽芯和滑块
5. **便于加工** — 尽量用平面，少用曲面

### 4.2 分型面类型

| 类型 | 适用场景 | 特点 |
|------|---------|------|
| 平面分型面 | 简单制品 | 最常用，加工简单 |
| 阶梯分型面 | 高度差大的制品 | 减少拔模角需求 |
| 斜面分型面 | 斜壁制品 | 避免侧抽 |
| 曲面分型面 | 复杂外观件 | 加工复杂，需精确配合 |
| 穿插分型面 | 带倒扣制品 | 配合滑块使用 |

### 4.3 排气设计

**排气位置：**
- 分型面（最优先）
- 填充末端
- 熔接线汇合处
- 深筋底部
- 盲孔底部

**排气尺寸（深度 × 宽度）：**

| 材料 | 排气深度 (mm) | 排气宽度 (mm) | 说明 |
|------|:---:|:---:|------|
| PP | 0.02-0.03 | 5-10 | 结晶材料，偏深 |
| ABS | 0.03-0.05 | 5-10 | 非结晶，可深 |
| PC | 0.03-0.05 | 5-10 | |
| PA66 | 0.01-0.02 | 5-8 | 结晶+低粘度，易飞边 |
| PPS | 0.01-0.02 | 5-8 | 同PA66 |
| POM | 0.01-0.02 | 5-8 | 同PA66 |

> **排气过深 → 飞边**（结晶材料尤其敏感）
> **排气不足 → 烧焦、短射**

## 五、模具材料选择

### 5.1 模仁材料

| 材料 | 硬度 (HRC) | 适用场景 | 特点 |
|------|:---:|---------|------|
| P20 | 28-32 | 通用模具（<50万模次）| 预硬钢，加工性好 |
| 718H | 33-38 | 外观件模具 | 预硬钢，抛光好 |
| NAK80 | 38-42 | 高光泽模具 | 预硬钢，镜面抛光 |
| S136 | 50-52 | 透明件/防锈模具 | 淬火钢，耐腐蚀 |
| H13 | 48-52 | 玻纤增强材料 | 耐磨，淬火钢 |
| 硬质合金 | >60 | 浇口/流道（GF材料）| 极耐磨 |

### 5.2 玻纤增强材料的模具要求

- 模仁：H13 或 S136（硬度≥50HRC）
- 浇口区域：镶嵌硬质合金
- 流道：镀硬铬
- 顶针：氮化处理
- 模具寿命：GF30材料约为普通材料的 1/3-1/2

## 六、模具结构设计快速参考

### 新模设计检查清单

```
□ 分型面位置是否合理（最大轮廓、不在外观面）
□ 浇口类型/位置/尺寸是否合适
□ 流道是否平衡（多腔模）
□ 排气位置和深度是否正确
□ 冷却水路是否覆盖热节区域
□ 动定模温差是否能控制<5°C
□ 顶出方案是否均匀、面积够
□ 顶针位置是否避开外观面
□ 拔模角是否足够
□ 模仁材料是否匹配材料和产量要求
□ 玻纤增强材料是否有耐磨处理
□ 滑块/斜顶行程是否足够
□ 模具是否有足够的刚性（防变形）
```
