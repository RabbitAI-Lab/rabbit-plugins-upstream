# 工艺参数优化指南

> 本文件包含注塑工艺参数的推荐逻辑和验证规则，帮助用户设定和优化注塑工艺。

---

## 一、工艺参数设定流程

```
1. 确定材料 → 查材料数据库获取加工窗口
2. 设定料温 → 在推荐范围内选中间值起步
3. 设定模温 → 在推荐范围内选中间值起步
4. 设定注射速度 → 按壁厚和材料特性
5. 设定保压 → 按注射压力百分比
6. 设定冷却时间 → 按壁厚计算
7. 试模 → 根据缺陷调整
```

---

## 二、料温设定

### 设定原则

- 起步值取推荐范围中间值
- 流动性不足（短射）→ 提高料温
- 材料降解（变色/银纹）→ 降低料温
- 每次调整幅度：5-10°C

### 常见材料料温参考

| 材料 | 最低 (°C) | 推荐 (°C) | 最高 (°C) | 备注 |
|------|:---:|:---:|:---:|------|
| PP | 180 | 210 | 230 | 流动性好，料温可低 |
| ABS | 200 | 230 | 260 | |
| PC | 280 | 300 | 320 | 粘度高需高温 |
| PA66 | 270 | 285 | 300 | 超过300°C降解 |
| PA66-GF30 | 275 | 290 | 310 | |
| PPS | 300 | 320 | 340 | |
| POM | 170 | 190 | 210 | 超过210°C分解产甲醛 |
| PMMA | 220 | 240 | 260 | |

### 验证规则

- 料温 > 材料最高温度 → ❌ 降解风险
- 料温 < 材料最低温度 → ❌ 未熔透/短射风险
- 料温在范围内 → ✅ 可接受

---

## 三、模温设定

### 设定原则

- 高模温：改善外观、减少内应力、提高结晶度（结晶材料）
- 低模温：缩短冷却时间、减少缩水

### 模温对材料的影响

| 材料 | 低温效果 | 高温效果 | 推荐范围 (°C) |
|------|---------|---------|:---:|
| PP | 结晶度低、发脆 | 结晶度高、收缩大 | 20-60 |
| ABS | 表面差、内应力高 | 表面好、内应力低 | 40-80 |
| PC | 内应力大、易开裂 | 内应力小 | 80-120 |
| PA66 | 结晶不全 | 结晶完全、强度好 | 70-110 |
| PPS | 结晶不全（必须>120°C）| 结晶完全 | 120-160 |
| POM | 表面差 | 收缩大 | 60-90 |

### 验证规则

- 模温 < 材料最低模温 → ❌ 结晶不全/表面差/内应力
- 模温 > 材料最高模温 → ❌ 冷却慢、收缩大
- 动定模温差 > 5°C → ⚠️ 翘曲风险

---

## 四、注射速度

### 设定原则

- 多级注射：慢→快→慢（防止喷射纹 + 保证末端填充）
- 薄壁件：高速度（防止过早凝固）
- 厚壁件：低速度（减少剪切和取向）

### 多级注射速度曲线推荐

```
行程%  速度%
0-10   20-30  (慢速充填浇口附近，防止喷射纹)
10-80  60-80  (快速充填主体)
80-95  40-50  (减速接近末端，防止烧焦/飞边)
95-100 20-30  (末端慢速，V/P切换前)
```

### 剪切速率验证

- 实际剪切速率 > 材料最大剪切速率 → ❌ 降解风险
- 浇口处剪切速率最关键，需计算或仿真获取

## 五、保压参数

### 保压压力

- 起始保压压力 = 50-80% × 注射压力
- 外观件取高值（减少缩水）
- 精密件取高值（稳定尺寸）
- 防飞边取低值

### 保压时间

- 保压时间 = 浇口冻结时间 + 余量（0.5-1s）
- 浇口冻结时间可通过"重量法"确定：
  1. 逐步增加保压时间
  2. 每次称重
  3. 重量不再增加的时间 = 浇口冻结时间

### 分段保压曲线

**推荐方案（3段保压）：**

| 段次 | 压力 (% 注射压力) | 时间 (s) | 目的 |
|------|:---:|:---:|------|
| 第1段 | 70-80% | 1-2s | 补缩主体 |
| 第2段 | 50-60% | 2-4s | 维持压力 |
| 第3段 | 30-40% | 1-2s | 逐步释放，减少残余应力 |

## 六、冷却时间

### 估算公式

冷却时间主要由最大壁厚决定：

```
t_cool ≈ (h / (π × α))² × ln[(4/π) × (T_melt - T_mold)/(T_eject - T_mold)]
```

其中：
- h = 壁厚 (m)
- α = 热扩散系数 = k/(ρ×Cp)
- T_melt = 熔体温度
- T_mold = 模温
- T_eject = 脱模温度

### 简化估算表（ABS为例，模温60°C，料温230°C）

| 壁厚 (mm) | 冷却时间 (s) | 说明 |
|:---:|:---:|------|
| 1.0 | 3-5 | |
| 1.5 | 6-10 | |
| 2.0 | 10-15 | |
| 2.5 | 15-22 | |
| 3.0 | 22-32 | |
| 4.0 | 40-55 | |
| 5.0 | 60-80 | |

### 注意事项

- PA66/PPS等高温材料的冷却时间更长（脱模温度高）
- 结晶材料需要确保中心温度低于结晶温度才能脱模
- 冷却时间 + 注射时间 + 保压时间 + 开合模时间 = 循环时间

## 七、锁模力估算

### 估算公式

```
F = P × A × n × k
```

其中：
- F = 锁模力 (吨)
- P = 型腔内平均压力 (kgf/cm²)，通常取 300-500 kgf/cm²
- A = 制品投影面积 (cm²)
- n = 型腔数量
- k = 安全系数 (1.1-1.2)

### 材料压力系数参考

| 材料类型 | 推荐型腔压力 (kgf/cm²) | 说明 |
|---------|:---:|------|
| PP/PE | 300-350 | 流动性好，压力低 |
| ABS | 350-400 | |
| PC | 400-500 | 粘度高，压力高 |
| PA66 | 350-400 | |
| PPS | 350-400 | 流动性好但凝固快 |

### 估算示例

制品投影面积 200cm²，ABS材料，1出2：

```
F = 400 × 200 × 2 × 1.2 = 192,000 kgf = 192 吨
→ 选择 200-250 吨注塑机
```

## 八、干燥条件

| 材料 | 干燥温度 (°C) | 干燥时间 (h) | 含水率要求 (%) | 干燥方式 |
|------|:---:|:---:|:---:|------|
| PP | — | — | <0.2 | 通常不需要 |
| ABS | 80 | 2-3 | <0.1 | 除湿干燥 |
| PC | 120 | 3-4 | <0.02 | 除湿干燥（严格）|
| PA66 | 80 | 6 | <0.1 | 除湿干燥 |
| PPS | 150 | 3 | <0.05 | 除湿干燥 |
| POM | — | — | <0.2 | 通常不需要 |
| PMMA | 80 | 3-4 | <0.05 | 除湿干燥 |

### 干燥验证

- 含水率超标 → ❌ 必须重新干燥
- 检查方法：对空注射——如果料条表面光滑无气泡则含水率合格
