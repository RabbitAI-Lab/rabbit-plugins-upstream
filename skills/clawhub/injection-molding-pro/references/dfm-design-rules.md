# DFM 可制造性设计规则

> 本文件包含注塑件设计审查的规则集，按设计要素分类。每条规则包含：规则描述、推荐值、违反后果、修正建议。

## 规则分类

1. 壁厚设计规则
2. 拔模角规则
3. 加强筋规则
4. 圆角与过渡规则
5. 孔与柱设计规则
6. 扣位设计规则
7. 表面与纹理规则
8. 公差规则

## 一、壁厚设计规则

### 1.1 基本壁厚

**规则：** 壁厚应在材料推荐范围内。

| 材料类型 | 推荐壁厚 (mm) | 最小壁厚 (mm) | 最大壁厚 (mm) |
|---------|:---:|:---:|:---:|
| PP | 0.8-3.0 | 0.6 | 5.0 |
| ABS | 1.0-3.0 | 0.8 | 5.0 |
| PC | 1.2-3.5 | 0.8 | 6.0 |
| PA66 | 0.8-3.0 | 0.6 | 4.0 |
| PA66-GF30 | 1.0-3.0 | 0.8 | 4.0 |
| PPS | 0.8-3.0 | 0.5 | 4.0 |
| POM | 0.8-3.0 | 0.6 | 4.0 |
| PC/ABS | 1.0-3.0 | 0.8 | 5.0 |
| PMMA | 1.5-4.0 | 1.0 | 6.0 |
| HDPE | 0.8-3.0 | 0.6 | 5.0 |

**违反后果：** 壁厚过薄→短射、保压不足；壁厚过厚→缩水、缩孔、冷却时间过长。

### 1.2 壁厚均匀性

**规则：** 尽量保持壁厚均匀。如必须变化，用渐变过渡。

- 壁厚变化不超过基准壁厚的 **±20%**
- 过渡区采用 **3:1 锥度比** 渐变
- 避免突变台阶（容易产生应力集中和缩水）

**违反后果：** 差异冷却→差异收缩→翘曲。

### 1.3 流长比

**规则：** 流长比（L/t）不超过材料允许值。

| 材料 | 最大流长比 (L/t) | 说明 |
|------|:---:|------|
| PP | 300:1 | 流动性好 |
| ABS | 150:1 | 中等 |
| PC | 100:1 | 粘度高，流长比小 |
| PA66 | 150:1 | 中等 |
| PPS | 200:1 | 流动性好 |
| POM | 150:1 | 中等 |

**违反后果：** 超出流长比→短射、压力不足。

**修正建议：** 增加浇口数量、加大壁厚、改用流动性更好的材料。

## 二、拔模角规则

### 2.1 标准拔模角

**规则：** 所有垂直于分型面的表面必须有拔模角。

| 表面类型 | 最小拔模角 | 推荐拔模角 | 说明 |
|---------|:---:|:---:|------|
| 光面（抛光）| 0.5° | 1-2° | |
| 细纹面（咬花）| 1.5° | 2-3° | 每0.025mm纹深加1° |
| 粗纹面（深咬花）| 3° | 3-5° | |
| 型芯（内表面）| 1° | 1.5-3° | 内表面收缩抱紧，需更大角 |
| 型腔（外表面）| 0.5° | 1-2° | 外表面收缩脱离，可小一些 |

**违反后果：** 拔模困难→顶白、顶变形、拉伤表面、延长周期。

### 2.2 特殊情况

**深腔体：**
- 深度>50mm的型芯，拔模角≥2°
- 深度>100mm的型芯，拔模角≥3°
- 超深腔体考虑侧抽或对开模

**透明件：**
- PC/PMMA透明件拔模角≥1.5°（避免拉痕影响透明度）

## 三、加强筋规则

### 3.1 筋厚度

**规则：** 筋根部厚度不超过壁厚的60%。

| 壁厚 (mm) | 外观面筋厚 (mm) | 非外观面筋厚 (mm) |
|:---:|:---:|:---:|
| 1.0 | 0.5 | 0.6 |
| 1.5 | 0.75 | 0.9 |
| 2.0 | 1.0 | 1.2 |
| 2.5 | 1.25 | 1.5 |
| 3.0 | 1.5 | 1.8 |

**违反后果：** 筋过厚→筋对面缩水。

### 3.2 筋高度与间距

**规则：**
- 筋高度 ≤ 3 × 壁厚（高度过大影响强度和脱模）
- 筋间距 ≥ 2 × 壁厚
- 多条平行筋：间距 ≥ 3 × 壁厚

### 3.3 筋根圆角

**规则：** 筋根圆角半径 R = 0.3-0.5 × 壁厚。

- R太小 → 应力集中
- R太大 → 筋根增厚导致缩水

### 3.4 筋脱模角

**规则：** 筋两侧拔模角 ≥ 0.5°（单边），推荐1°。

## 四、圆角与过渡规则

### 4.1 内角圆角

**规则：** 所有内角必须有圆角，避免尖角应力集中。

| 圆角/壁厚比 (R/T) | 应力集中系数 |
|:---:|:---:|
| 0 (尖角) | 3.0 |
| 0.1 | 2.3 |
| 0.2 | 1.8 |
| 0.3 | 1.5 |
| 0.5 | 1.2 |
| 0.6 | 1.1 (推荐) |
| 0.8 | 1.0 |

**推荐：** 内角R/T = 0.5-0.6，应力集中降至1.1-1.2倍。

### 4.2 外角

**规则：** 外角保持尖角或小圆角，与内角圆角配合保持壁厚均匀。

### 4.3 壁厚过渡

**规则：** 壁厚变化处用3:1锥度渐变。

```
厚截面 ────╲
            ╲ 3:1锥度过渡
             ╲──── 薄截面
```

## 五、孔与柱设计规则

### 5.1 孔

**规则：**
- 盲孔深度 ≤ 3 × 孔径（成型针强度限制）
- 通孔深度 ≤ 5 × 孔径
- 孔间距 ≥ 2 × 孔径（或2 × 壁厚，取大值）
- 孔到边缘 ≥ 1.5 × 孔径
- 孔周围壁厚应与基体一致（避免缩水）

**违反后果：** 成型针弯曲/折断、孔周围缩水。

### 5.2 盲孔端部

**规则：** 盲孔底部不要做成尖底，用圆底或平底。

### 5.3 螺丝柱

**规则：**
- 柱外径 = 螺丝公称直径 × 2.0-2.5
- 柱内径 = 螺丝公称直径 × 0.8（自攻螺丝）
- 柱壁厚 ≤ 0.6 × 基体壁厚（防缩水）
- 柱高度 ≤ 3 × 柱外径
- 柱根加R0.3-0.5圆角
- 高柱建议加加强筋

**常见螺丝柱参数：**

| 螺丝规格 | 柱外径 (mm) | 柱内径 (mm) | 推荐壁厚 (mm) |
|---------|:---:|:---:|:---:|
| M2.0 | 4.0-5.0 | 1.6-1.7 | 1.0-1.2 |
| M2.5 | 5.0-6.0 | 2.0-2.1 | 1.0-1.2 |
| M3.0 | 6.0-7.0 | 2.4-2.5 | 1.0-1.5 |
| M3.5 | 7.0-8.0 | 2.8-2.9 | 1.2-1.5 |
| M4.0 | 8.0-9.0 | 3.2-3.3 | 1.2-1.5 |

## 六、扣位设计规则

### 6.1 悬臂扣

**规则：**
- 扣合量 = 0.5-1.5mm（视材料和扣臂长度）
- 扣臂根部厚度 = 0.6-0.8 × 壁厚
- 扣臂长度 ≥ 5 × 扣臂厚度
- 扣臂根圆角 R ≥ 0.3 × 壁厚
- 拔模角 ≥ 1°

**材料允许变形量参考：**

| 材料 | 允许应变 (%) | 说明 |
|------|:---:|------|
| PP | 8-10 | 柔韧，适合扣位 |
| ABS | 1.5-2.0 | 适中 |
| PC | 3-4 | 较好 |
| PA66 | 2-3 | 适中 |
| PA66-GF30 | 0.5-1.0 | 脆，不适合频繁拆装 |
| POM | 2-3 | 弹性好，适合扣位 |

### 6.2 扣位脱模

**规则：** 扣位倒扣部分必须有脱模方案：
- 斜顶（内侧倒扣）
- 滑块（外侧倒扣）
- 强制脱模（PP/PE软材料，倒扣量<0.5mm）

## 七、公差规则

### 7.1 模具精度等级

| 精度等级 | 适用场景 | 壁厚公差 | 尺寸公差(100mm) | 模具成本 |
|---------|---------|:---:|:---:|:---:|
| 普通级 | 通用消费品 | ±0.1mm | ±0.2mm | 低 |
| 精密级 | 电子/家电 | ±0.05mm | ±0.1mm | 中 |
| 高精密级 | 光学/医疗 | ±0.02mm | ±0.05mm | 高 |
| 超精密级 | 特殊应用 | ±0.01mm | ±0.02mm | 极高 |

### 7.2 公差分配原则

- 收缩率大的材料（PP/PA）公差放大20-50%
- 远离分型面的尺寸公差放宽（分型面影响）
- 垂直分型面方向的尺寸注意毛边余量（0.02-0.05mm）
- 玻纤增强材料注意各向异性（流动方向/垂直方向公差不同）

## DFM 审查清单模板

当用户请求DFM审查时，按此清单逐项检查：

```
制品名称：___          材料：___
壁厚基准：___mm        拔模面类型：___

[壁厚]
□ 基准壁厚是否在材料推荐范围内
□ 壁厚变化是否在±20%以内
□ 过渡区是否有3:1锥度
□ 流长比是否在材料允许范围内

[拔模角]
□ 所有竖直面是否有拔模角
□ 光面≥0.5°，咬花面是否按纹深补偿
□ 型芯面拔模角是否≥型腔面
□ 深腔体是否有足够拔模角

[加强筋]
□ 筋厚≤60%壁厚（外观面50%）
□ 筋高≤3×壁厚
□ 筋根圆角R=0.3-0.5×壁厚
□ 筋两侧拔模角≥0.5°

[圆角]
□ 所有内角是否有圆角
□ 内角R/T=0.5-0.6
□ 壁厚变化处是否有锥度过渡

[孔与柱]
□ 盲孔深度≤3×孔径
□ 螺丝柱壁厚≤0.6×基体壁厚
□ 孔间距≥2×孔径

[扣位]
□ 扣臂厚度0.6-0.8×壁厚
□ 扣臂根有圆角
□ 材料允许应变是否匹配扣合量
□ 倒扣有脱模方案

[其他]
□ 分型面位置是否合理
□ 浇口位置是否影响外观
□ 顶针位置是否影响外观
□ 是否有可制造的纹理要求
```
