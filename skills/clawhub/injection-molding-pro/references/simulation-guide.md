# 仿真分析指南

> 本文件包含注塑仿真分析（Moldflow/Moldex3D 等）的规范设定和结果解读指南。

---

## 一、仿真分析类型

| 分析类型 | 目的 | 何时使用 |
|---------|------|---------|
| 填充分析 | 检查充填模式、压力、气陷、熔接线 | 所有新模必做 |
| 保压分析 | 检查体积收缩、缩水、缩孔风险 | 外观件/厚壁件必做 |
| 冷却分析 | 检查冷却均匀性、动定模温差 | 大件/精密件必做 |
| 翘曲分析 | 预测变形量和方向 | 所有结构件必做 |
| 纤维取向 | 预测玻纤分布和各向异性 | GF增强材料必做 |
| 应力分析 | 预测残余应力分布 | 透明件/高应力件 |
| 收缩分析 | 预测实际收缩量，指导模具补偿 | 精密件必做 |

## 二、网格要求

### 2.1 网格类型选择

| 网格类型 | 适用场景 | 精度 | 计算时间 |
|---------|---------|:---:|:---:|
| 中面网格 | 薄壁件（t<3mm，均匀壁厚）| 中 | 快 |
| 双层面 | 大多数注塑件 | 中高 | 中 |
| 3D实体网格 | 厚壁/壁厚变化大/精密分析 | 高 | 慢 |

### 2.2 网格质量要求

**双层面网格：**

| 指标 | 要求 | 说明 |
|------|:---:|------|
| 匹配率 | >85% | 影响厚度方向精度 |
| 纵横比 | <20 | 越小越好 |
| 单元尺寸 | 1-3mm | 薄壁取小值 |
| 壁厚方向层数 | ≥4 | 影响温度梯度精度 |
| 自由边 | 0 | 不允许 |
| 交叉边 | 0 | 不允许 |

**3D实体网格：**

| 指标 | 要求 | 说明 |
|------|:---:|------|
| 壁厚方向层数 | ≥8 | 精密分析≥10 |
| 纵横比 | <10 | |
| 单元尺寸 | 0.5-2mm | |

### 2.3 网格密度控制

- 浇口附近加密
- 壁厚变化处加密
- 熔接线预期位置加密
- 圆角/特征细节处加密
- 大平面区域可适当放大

## 五、结果解读

### 5.1 填充分析

| 输出结果 | 合格标准 | 不合格处理 |
|---------|---------|-----------|
| 填充时间 | 末端填充均匀 | 调整浇口位置/数量 |
| 压力分布 | 末端压力 > 20MPa | 增大浇口/流道 |
| 流动前沿温度 | 温差 < 10°C | 提高料温/模温/速度 |
| 气陷位置 | 在可排气区域 | 加排气/改浇口 |
| 熔接线位置 | 不在受力/外观区 | 改浇口位置 |
| 剪切速率 | < 材料最大值 | 增大浇口/降速度 |
| 剪切应力 | < 0.5MPa | 降速度/增大浇口 |

### 5.2 保压分析

| 输出结果 | 合格标准 | 不合格处理 |
|---------|---------|-----------|
| 体积收缩率 | 外观面 <6%, 非外观 <8% | 增保压/延长时间 |
| 凝固时间 | 浇口最后凝固 | 检查浇口尺寸 |
| 缩水指数 | < 1% | 增保压/掏料 |
| 缩孔风险 | 内部 <10% | 增保压 |

### 5.3 冷却分析

| 输出结果 | 合格标准 | 不合格处理 |
|---------|---------|-----------|
| 动定模温差 | <5°C | 调整水路流量 |
| 冷却时间 | 各区域差异<20% | 加密热区水路 |
| 模温分布 | 均匀 | 优化水路布局 |

### 5.4 翘曲分析

**关键：分离三个贡献因素**

| 因素 | 特征 | 对策 |
|------|------|------|
| 差异收缩 | 壁厚不均处变形大 | 统一壁厚 |
| 取向效应 | 沿流动方向变形 | 调整浇口位置 |
| 冷却不均 | 动定模温差导致 | 优化冷却 |

**翘曲合格标准：**

| 应用场景 | 允许翘曲量 | 说明 |
|---------|:---:|------|
| 精密配合件 | <0.1mm | 需修模补偿 |
| 普通结构件 | <0.3mm | |
| 外观件 | <0.5mm | 视外观要求 |
| 通用件 | <1.0mm | |

### 5.5 纤维取向分析（GF材料）

**关键输出：**
- a11（流动方向分量）→ 越接近1表示纤维越沿流动方向取向
- a22（垂直方向分量）
- a33（厚度方向分量）

**解读：**
- 表层：a11高（流动方向）→ 沿流动方向强度高
- 芯层：取向较随机 → 各方向强度接近
- 熔接线处：纤维垂直于结合面 → 强度大幅下降

**GF材料翘曲特征：**
- 流动方向收缩小（纤维约束）
- 垂直方向收缩大
- 差异→翘曲（必须仿真预测）

## 六、仿真分析工作流程

```
1. 导入3D模型 → 检查壁厚 → 确定分析类型
2. 划分网格 → 质量检查 → 修复
3. 设定材料 → 检查参数完整性
4. 设定浇注系统（浇口/流道）
5. 设定冷却系统（水路）
6. 设定工艺条件
7. 运行填充分析 → 检查 → 调整浇口
8. 运行保压分析 → 检查 → 调整保压
9. 运行冷却分析 → 检查 → 调整水路
10. 运行翘曲分析 → 评估 → 优化方案
11. （GF材料）运行纤维取向分析
12. 生成报告 → 与设计/工艺团队评审
```

## 八、Insert Molding 嵌件成型仿真分析

### 8.1 分析概述

嵌件成型（Insert Molding）仿真需要热-结构耦合分析，因为金属嵌件和塑料之间存在巨大的物性差异：

- **热膨胀系数(CTE)**：金属 10-17 ppm/°C vs 塑料 40-140 ppm/°C
- **导热系数**：金属 15-50 W/(m·K) vs 塑料 0.15-0.4 W/(m·K)
- **弹性模量**：金属 200 GPa vs 塑料 1-15 GPa

### 8.2 嵌件成型仿真特殊设定

| 设定项 | 要求 | 说明 |
|--------|------|------|
| 嵌件材料属性 | 必须输入完整热-力学参数 | CTE、导热系数、比热、密度、弹性模量 |
| 初始嵌件温度 | 设定预热温度（通常100-150°C）| 如未预热，设室温25°C |
| 嵌件-塑料界面 | 定义接触/粘结条件 | 摩擦系数、热传导系数 |
| 嵌件网格 | 独立划分，与塑料网格耦合 | 界面处网格匹配 |
| 冷却分析 | 嵌件散热效应必须计入 | 嵌件作热沉加速局部冷却 |

### 8.3 关键分析步骤

```
1. 导入嵌件3D模型 + 塑料制品3D模型
2. 分别设定嵌件和塑料的完整材料属性
3. 设定初始条件：
   - 嵌件初始温度（预热温度）
   - 模具温度
   - 熔体温度
4. 划分网格并耦合（界面接触条件）
5. 运行填充+保压分析（嵌件作为热边界）
6. 运行冷却分析（含嵌件热沉效应）
7. 运行翘曲分析（含嵌件约束效应）
8. 后处理：提取嵌件周围的应力分布
```

### 8.4 嵌件周围应力分析（开裂预测）

**关键评估指标：**

| 指标 | 限值 | 说明 |
|------|:---:|------|
| 最大主应力 | < 材料拉伸强度的60% | 安全余量 |
| 嵌件-塑料界面剪应力 | < 界面剪切强度 | 界面脱粘判据 |
| 冷却速率梯度 | < 50°C/s（嵌件附近）| 急冷导致的高应力 |
| 体积收缩率 | < 3%（嵌件附近区域）| 收缩+约束=开裂 |

**开裂风险评估：**

| 风险等级 | 判据 | 措施 |
|:---:|------|------|
| 低 | 最大主应力 < 拉伸强度40% | 可接受 |
| 中 | 最大主应力 40-60% 拉伸强度 | 建议嵌件预热/圆角优化 |
| 高 | 最大主应力 > 60% 拉伸强度 | 必须重新设计嵌件或换材料 |

### 8.5 结果解读重点

1. **应力集中区域** — 嵌件尖角处、壁厚突变处
   - 对策：嵌件倒圆角R≥0.5mm，局部加厚塑料

2. **冷却速度分布** — 嵌件附近冷却速度远高于远离嵌件区
   - 对策：嵌件预热至120-150°C，提高模温

3. **收缩率分布** — 嵌件约束导致非均匀收缩
   - 对策：选用收缩率更接近金属的材料（GF增强），嵌件设计减薄

4. **X/Y/Z各方向变形** — 不对称嵌件导致各向异性变形
   - 对策：嵌件尽量对称布局，预留补偿量

### 8.6 软件实现对照

| 功能 | Moldflow | Moldex3D |
|------|:---:|:---:|
| 嵌件模型导入 | ✅ Insert Part | ✅ Insert |
| 热-结构耦合 | ✅ Core Shift + Warp | ✅ Warp with Insert |
| 界面接触定义 | 摩擦系数/热阻 | 摩擦系数/热传导率 |
| 应力可视化 | ✅ | ✅ |

## 九、Moldflow 结果解读要点（深化）

> 来源：Moldflow 官方结果解读文档（可公开提炼）。本节聚焦日常判读中最常被误读、误用的结果项。

### 9.1 屏幕输出 / 结果概要

- 概览含：压力、锁模力、流率、控制类型。
- 充模阶段：`V` = 速度控制、`P` = 压力控制、`V/P` = 切换点。
- **V/P 切换压力常为全周期最高值**，是检查平衡的基准点。

### 9.2 充填时间（Fill Time）

- 用**等值线（云纹）图**比云图更易读：线间距相等 = 流动前沿等速。
- **平衡充模 = 各远端同时充满**，这是最重要的合格判据。

### 9.3 压力（Pressure）

| 判据 | 限值 | 说明 |
|------|------|------|
| 最大压力（含浇注系统）| < 机台极限的 70%（约 100 MPa）| 多数机台极限 ≈140 MPa(20000 psi)；模具设计压力极限取 70% |
| 最大压力（不含浇注系统）| < 机台极限的 50% | 分析未含流道/浇口时取此值 |
| 压力分布 vs 充模时间 | 应相似 | 相似=无潜流；充模结束压力、V/P 切换压力用于查平衡 |
| 注射位置压力 XY 图尖峰 | 不应出现 | 充模末出现尖峰 = 未平衡充模 |

### 9.4 温度类结果

- **体积温度（Bulk temperature）**：速度加权平均温度，反映剪切热。
  - 充模阶段应很均匀：**理想 <5°C，允许至 20°C**；过保压 → 体积温度显著下降。
  - **缩短注射时间是减小温域的最佳手段**。
- **流动前沿温度**：与熔接线结合看——熔接线形成时温度高 → 质量好。
- **截面温度**：最高点不应超材料数据库熔体最高温。
- **壁面剪切应力**：应低于材料库极限；把绘图下限设为材料极限，仅显超标单元；关闭节点平均看小单元。
- **剪切速率（bulk）**：与材料库极限比，通常保持 <20,000 1/s（浇口处常高）。

### 9.5 缺陷指示结果

| 结果 | 形成机制 | 判读要点 |
|------|---------|---------|
| 熔接线 Weld lines | 流动前沿汇合或绕孔分流 | 对网格密度极敏感（可能误显/漏显）；与充模时间同显确认；减少浇口数/改浇口位/改壁厚可消除或移位 |
| 气穴 Air traps | 材料从各方向汇流节点 | 应消除；改壁厚/浇口位/注射时间 |
| 冻结时间 / 冻结层厚度 | 冻结层=1 全冻 | 充模结束冻结层若 >0.20–0.25 → 保压困难，需缩短注射时间；近浇口早冻 → 远端高收缩 |
| 体积收缩率 | 保压越高收缩越小 | 顶出时收缩应均匀（调保压曲线） |
| 缩痕指数 Sink Index | 综合体积收缩率+壁厚 | 给出缩痕相对可能性，方案对比有用 |

### 9.6 锁模力与平衡

- 锁模力对**平衡 / 保压 / V-P 切换**极敏感。
- 投影重叠 → 高估（可排除重叠单元）。
- **锁模力中心不在机台中心 → 拉杆受力不均、有效锁模力下降，须修正。**

### 9.7 冷却结果判读

| 结果 | 合格/参考值 | 说明 |
|------|------------|------|
| 制件顶/底面温 | 模具表面一周期平均温 | 关注动定模温差 |
| 两温差 | 仅中层面模型有（FUSION 无）| |
| 冷却液雷诺数 | >2200 过渡、>4000 湍流 | 默认 10000，湍流换热效率高 |
| 冷却液温升 | 一般 <3°C | |
| 管道金属温 | 不应高于液温 5°C 以上 | 过高 → 该处需加强冷却 |

### 9.8 实用判读技巧

1. **推荐注射速度 XY 图**：使流动前沿更均匀、消压力尖峰、改善表面。
2. **充模起点（Grow from）**：多浇口时显示各单元由哪浇口填充 → 利于平衡判断。
3. **优先看"平衡"而非单值**：充模时间、压力、锁模力三者耦合，单看压力合格但充模不平衡仍会缺陷。

## 十、翘曲（Warpage）专项分析与对策

> 来源：塑料件翘曲原因和解决方案（CAD-IT / Moldflow）。翘曲是多因素耦合结果，量化定位主导因素是优化前提。

### 10.1 翘曲成因的两个维度

**因果维度（四大成因）：**

| 维度 | 具体因素 |
|------|---------|
| ①产品结构 | 壁厚变化、弯曲/不对称几何、筋/Boss 不合理 |
| ②塑胶材料 | 有无填充、收缩率 |
| ③模具结构 | 浇注/冷却/顶出系统 |
| ④生产工艺 | 未冷透即顶出、注射/保压曲线不合理 |

**Moldflow 量化维度（四项贡献）：** 冷却不均匀 / 收缩不均匀 / 纤维取向不均匀（含纤料）/ 角落效应。

### 10.2 四大成因专项对策

#### ① 冷却不均匀

- 脱模时各处温差 **>10°C → 大翘曲**。
- **水路直径经验准则：**
  | 件厚 | 水路直径 |
  |------|---------|
  | <2mm | Ø8–10mm |
  | <4mm | Ø10–12mm |
  | <6mm | Ø12–15mm |
- **案例**：PC+10%GF 盖板 1.9mm 壁，动定模温差 20°C → 优化至 10°C，Y 向变形 0.98 → 0.49mm。

#### ② 收缩不均匀

- 诱因：壁厚差 >1.5–2 倍、筋不合理、浇口数/位不当、保压曲线不当。
- 对策与案例（变形优化量）：
  | 对策 | 具体操作 | 变形改善 |
  |------|---------|---------|
  | 改结构 | 侧壁 3.0→2.5mm，X 向 1.83→0.67mm（ABS 温控板）| — |
  | 换材料 | PP Lupol→PP RR93（水壶底座）| Z 向 2mm→≈0 |
  | 改浇口 | 3 点潜伏→外圈 4 点潜伏（PC+ABS 音响面板）| Y 0.44→0.09mm、Z 0.4→0.25mm |
  | 优保压 | 140/3s→90/3s（PC 0.3mm 壁电池盖）| Z 0.49→0.15mm |

#### ③ 纤维取向不均匀

- 含纤料（如 PA6 GF15%）取向不均 → 翘曲。
- **对策**：优化浇口（1 侧浇 → 中间 3 点浇，流动平衡），变形 2.25 → 1.4mm（螺旋叶片）。

#### ④ 角落效应

- 深盒状件角落散热难、热量集中 → 变形。
- **对策**：加强角落冷却（挡板/喷泉冷却），角落温差 43°C → 4°C，变形 0.90 → 0.43mm（PA66 GF30 盖子）。

### 10.3 翘曲优化工作法

1. 先跑 Moldflow 翘曲分析，读取四项贡献占比 → **定位主导因素**。
2. 针对主导因素选对策（冷却/收缩/取向/角落）。
3. 改一处重跑，对比变形量；避免多变量同时改导致无法归因。
4. 翘曲源于结构/模具/材料/工艺不合理，对策即从这四方面入手。

## 十一、网格质量与 CAD Doctor（深化）

> 来源：提高 Moldflow 分析准确度之网格模型要求及 CAD Doctor 应用（CAD-IT）。以 FUSION（双层面）为例，MIDPLANE / 3D 稍不同。

### 11.1 合格网格的统计量目标

| 统计指标 | 目标值 | 说明 |
|---------|--------|------|
| 连接区域 Connectivity regions | = 1 | 整个模型须为一个连通体 |
| 自由边 Free edges | 0 | 不允许 |
| 非流行边 Non-manifold edges | 0 | 不允许 |
| 取向问题 Elements not oriented | 0 | 用 Orient All 修复 |
| 单元相交 Element intersections | 0 | |
| 完全重叠 | 0 | |

- **纵横比 Aspect ratio（AR=b/a）**：教材最大 <6，一般 <15（或 10）；**平均 AR <3**。
- **网格匹配率 Match percentage ≥ 85%**（双面对应率）。
- **网格厚度须与 CAD 模型一致**。
- **壁厚变化区至少三排网格**，方能精确预测滞流；熔接线常生于孔周与两股料流相碰处（对网格密度敏感）；薄壁区网格不足 → 困气无法准确预测。

### 11.2 网格修复顺序（推荐流程）

```
① CAD 中修复 / 简化模型
② 调整网格边长（起始边长 = 软件推荐值 2/3，依匹配率与平均 AR 迭代）
③ 修复连接性（Connectivity）
④ 修复自由边 / 多重边（Free / Multi edges）
⑤ 修复重叠三角形（Overlapping）
⑥ 修复纵横比（最大 <15，平均 <3）
⑦ Orient All 修复取向
⑧ Purge nodes 清离散节点
⑨ 检查壁厚一致性
```

### 11.3 CAD Doctor 自动简化

- 自动修复 Short curve / Sliver face / Free edge / Gap / Intersecting loops 等（约 30s）。
- 可一键去除小字体、去除 R0.3 以下小圆角。
- **效果示例**：简化后匹配率 74.3% → 92.2%、最大 AR 60.9 → 41.6，建模+分析耗时大幅缩短。
- 适用：几何导入后先做 CAD Doctor 简化，再进入 Moldflow 网格划分，可显著提升首轮网格质量与迭代效率。
