# 模具设计规范与企业标准（通用原则）

## 1. NST 模具设计指南（NOKIA/NRT，通用原则）

来源：Standard-Training_Design.pdf（NST Confidential，仅提炼通用原则）

### 1.0 分型面 Parting
- 主分型面尽量不在产品边缘（可能时高出轮廓 0.05mm，避免锐边、可后加工不伤模仁轮廓）；倒扣<0.1mm。
- 型芯分型相对本体边缘偏移 0.2mm。
- 滑块外分：为实现开模需取消偏移；滑块内分：优先水平分隔；滑块 recess 必须释放到滑块上表面。
- 密封面宽约 20mm；比密封面深约 4mm 做避空；密封面外接触区 FH≈30×30mm。
- 产品内所有密封面偏移 min 0.1mm（分型面可与产品面分开加工）。
- Core 高度(L-Dim in FH-Cavity)：26mm(下限)~46mm(上限)；MH-Core(斜顶专用) 56mm(下限)。

### 2.0 排气 Ventilation
- 参考 ESI/Moldflow 报告标熔接痕位置，排气布置在合适点（顶针/镶件/活动件自清洁）。
- Core Top 周围必须排气，几何定义明确；动件区不排气（飞边风险）；Radius 上不排气。
- 圆形 Core/Cavity 排气槽距轮廓 2–3mm，向外有排气通道。
- 玻纤材料：必须加排气芯（如4个），可拆洗。
- 定位销下必须排气；避免 Ø<1.2mm 顶针/小芯下排气；滑块密封面>5mm 必须加排气槽。

### 3.0 顶出 Ejector
- 只用标准顶针库；顶针距相邻几何最小距离：凸起 0.2–0.3mm，凹陷 0.7–0.9mm（极端 0.55mm）。
- 头部重叠的顶针需修剪匹配；避免滑块下顶针，不可避免则加滑块安全装置。
- Accelerator（加速顶出）在顶出末端附加运动，使件脱离顶针；可用 Straight/Shouldered/Blade Pin。

### 4.0 冷却 Cooling
- 水路直径：可能时 ≥8mm；框架/型腔两至三层冷却回路。
- 型腔两路冷却；浇口套/热流道阀针区必须单独冷却。
- 冷却通道距其他特征 3.0mm；滑块冷却孔预钻，不用则堵。

### 5.0 模架 Moldbase
- 两孔间隙<0.5mm 应合并为一孔，取可加工尺寸（如 20.5 而非 20.36）。
- 型腔压力传感器：装在浇口附近（压力最高）、最厚截面（最后凝固）；**不可正对浇口**（会测得额外动态力扭曲信号）；大件远离浇口加第二传感器。

### 7.0 浇口 Gating
- 冷流道：主流道比分流道大 20%；高粘度材料(PC/PMMA)流道截面大 25%；流道长 min 20mm；方向变需圆弧。
- 隧道浇口：优先 30°，位置角<45°；香蕉浇口用于 Core 侧。
- 膜片浇口(Film gate)：b=n√A/3，h=n·s（s=壁厚，A=表面积）；优点无变形注射，缺点需去浇口机。

### 8.0 斜顶 Lifter
- 个体差异化（厚度差 min 0.2mm、加不同 R）以便互换识别。
- 角度斜顶旁必须配平行斜顶(Parallel Lifter)锁住产品防跟随。
- 斜顶伸入框架/型芯底每侧留 0.2mm 间隙；Core Top 下加倒角供斜顶装入。

## 2. 企业模具设计规范（第二组 · 通用原则）

来源：企业模具设计制造规范（内部，仅提炼通用工程原则并注明来源）

### 2.1 流道/浇口 (3.2)
- 冷流道与浇口必须平衡（注塑成型敏感性研究的前提）。
- 不允许偏心入水口（off-center sprue）。流道上刻材料号+模穴号。
- 浇口尽量研磨成型、避免 EDM；流道所有尖锐边角倒圆至最小 R0.5mm。
- 流道末端必须做冷料井；尽量模内自动脱水口。
- 热流道：必须用平衡式、外加热全流道歧管；配线入线槽不外露；热咀线从顶部引出、不穿定位环孔；接线盒装模具顶侧或操作员对侧。

### 2.2 前后模仁 (3.3)
- 严禁用垫片（shim）补偿尺寸；烧焊须经书面批准且供应商仍担责。
- 钢料选择、热处理须按规格并经模具工程师核准。
- 所有模具必须做前后模边锁（core-cavity side interlock）锁住分型面。
- 模仁与 A/B 板分型面刻对应位置号；小镶件底面刻号防错装；侧面凹位刻零件号+钢种+硬度(HRC)。
- 分型面刻蚀纹号；>25kg 模仁做吊环孔。

### 2.3 抽芯 (3.4)
- 滑块六阶段（合模夹紧/注塑/开模/行程末端/合模/维护）各有要求；封胶面须斜向接触（少摩擦=少飞边）；支撑面面积足以保封胶。
- 前后模双边锁锁紧楔防变形；滑块须有正向定位（弹簧-止付螺丝为标准，圆球定位销 A 类模禁用）。
- 弹簧用 Associated/Misumi（优先 Associated），不可割短；设计寿命≥30 万次；滑块不得因自重脱落。
- 耐磨板：模温>90°C 用石墨合金铜板（Hasco Z186w）；否则 DIN1.2510(54–56HRC)。
- 斜顶（lifter）：封胶面与支撑面应分开（Type3/4 优）；当斜角α≥8°、行程 S>5t、长度 L≥25t、或导向长 H<2w/H<L/4 时，B 板后加铜导块防磨损。

### 2.4 模温控制 (3.5)
- 介质水/油/气/加热棒；接咀用 DME（<90°C 用 N6-1/4"A，>90°C 用 PCS 6-14-A），全部沉入模板。
- 接咀优先级：背面→底面→操作员侧→顶面；标 IN/OUT 编号。
- 冷却水路直径 Ø6/Ø8/Ø10mm；装配图独立画冷却回路；中途堵用 Hasco Z942 螺纹塞。
- 隔片/喷管须铜材；单边>4 进出水口用铝集散器；热流道浇口区（尤其针阀）须良好冷却。
- O 形圈 Hasco 标准（Z98 Viton）：藏槽三面包围、镶件微移不松脱、圆镶件做台阶（一层一台阶一圈圈）。除方铁外每板应有冷却；模温>90°C 顶针板加热。

### 2.5 排气 (3.6)
- 设计阶段彻底研究、制造时小心实施；排气深度按树脂特性定。
- 所有排气至少 0.20mm 释放槽，渐深至距型腔 1.0–1.5mm，并通大气。
- 每个模穴浇口正对面必放排气并尽量多布；料流末端与流向变化处（流道+型腔）排气。
- 必要时做镶件排气；困气镶针加环状排气；导套底、主导柱做排气方台（深=油槽深）；前后模板间导柱侧去钢 0.5mm。

### 2.6 顶出 (3.7)
- 顶针必氮化：>3mm 用 DIN1.2842/1.2067（面 HV950、芯 HRC35–45）；≤3mm 用 1.2344（杆 HRC65–74、头 HRC40–50）；司筒 1.2343。
- 顶针支承面≥1.5×直径；异形顶针板内直面防转（禁用销钉）；<2.0mm 必用有台顶针，2–3mm 优先有台。
- 顶针印痕凹 0.05–0.1mm；滑块下避免顶针，必要时用先复位机构（Hasco Z163/Z164）。
- 顶出弹簧标准件（Associated/Misumi），最大压缩率≤40%；加正向限位块限行程；顶针室用≥4mm 透明 PC 板防护。
- 顶针板推荐 4 套导柱导套；导套用滚珠导套（Hasco Z13w）；板后加垃圾钉（高吨位用大直径）；顶出过程保持产品/水口方向。

### 2.7 钢料优选 (3.9.1，通用钢种对照)
- 模板：DIN1.2312(=AISI P20+S)；流道板/多冷却水道分别用 1.2767 / Ramaxll(420 不锈)。
- 主模仁：Stavax E.S.R.(=S136) 50–52HRC；玻纤>50% 用 Elmax 56–59HRC。
- 小镶件/封胶：Orvar Supreme(=H13) 48–54HRC；玻纤>50% 用 Vanadis 10。
- 耐磨板：DIN1.2510(=DF-2) 55HRC；压板模温>90°C 用石墨合金铜(2.0492)。
- 高光面钢料须 S136 SUP。

### 2.8 公差 (3.9.2/3.9.3，通用)
- 主模仁尺寸公差 ±0.01mm；边锁位置 ±0.005mm；导柱/导套位置 ±0.01mm。
- 产品公差→制模控制公差：±0.20→±0.05；±0.10→±0.025；±0.05→±0.013；±0.02→±0.005。

## 3. 企业模具设计规范（第三组 · 通用原则）

来源：企业制模规范手册（内部，仅提炼通用工程原则并注明来源）

### 3.1 SPI 模具等级（按寿命分级，SPI-SPE 标准）
- ①百万模次级（1,000,000+ shots）：模板/模仁用硬料 ~48–52 HRC（如 420/1.2083、4140/DME#2）。
- ②50 万模次级；③10 万模次级：P20（28–32HRC）或 1040；④500 模次级（试制/样板模）。
- 模具等级决定选材硬度与结构冗余，是报价与寿命评估的通用基准。

### 3.2 钢材牌号对照（AISI / DIN / JIS 通用）
- H13=1.2344；420=1.2083；P20=1.2311；D2=1.2739；1.2767(=LKM2767)；JIS NAK55/NAK80(对应 P5 类预硬钢)。
- 与 NST 钢种体系一致。

### 3.3 模具基本类型
- 二板模(2-plate)、三板模/点浇口(3-plate pin-point gate)、热流道歧管(hot runner manifold)。

### 3.4 镶件(insert)通用设计
- 介子腳（定位台阶）做在镶件平直长边；避免利角，做 ≥0.30mm 圆角；宽高比 H:W≈3:2；不便做台阶时镶件四周做 1°–2° 斜度（最小 1/4°）以利线割/打磨。
- 内模件侧面先锣低 0.5mm 再雕刻字嘜（3/16" 字高），内容含钢材名/硬度/模号序号；需见硬者先刻后硬。

### 3.5 行位(滑块)
- 手册设专章（详述导向/耐磨/封胶，与企业通用规范一致：封胶面斜向接触减飞边）。

## 设计评审检查表（跨标准通用）

| 维度 | 关键检查项 |
|------|-----------|
| 分型面 | 主分型高出轮廓0.05mm、倒扣<0.1mm、密封面宽~20mm、边锁锁分型面 |
| 排气 | 浇口正对面必排气、玻纤加排气芯、排气深≥0.20mm、导柱侧去钢0.5mm |
| 顶出 | 顶针氮化、支承面≥1.5×d、<2mm用有台顶针、滑块下加先复位 |
