## 散文体 4 不妥协

### 1. 句长 35-50 字 / 句

```python
# 验证脚本
sentences = [s for s in re.split(r'[。！？]', text) if s.strip()]
avg_len = sum(len(s) for s in sentences) / len(sentences)
assert 35 <= avg_len <= 50, f"句长 {avg_len:.1f} 偏离 35-50"
```

### 2. 短句（<20 字）占比 < 20%

```python
short_count = sum(1 for s in sentences if len(s) < 20)
short_ratio = short_count / len(sentences)
assert short_ratio < 0.20, f"短句占比 {short_ratio:.1%} 超 20%"
```

### 3. 字数 800-3500（老板号调性）

**老板号 ≠ v7 铁律 8,500-9,500 字（深度分析类）。**

- 散文体一致性 > 字数硬指标
- 17 篇原创（2026-07-01）按 R3-R5 同款风格

核心概念每万字至少出现 50 次（保证主题密度）。
