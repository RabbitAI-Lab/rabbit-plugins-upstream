## 4 个真实样本（双真实案例开篇法）

### 案例 1：董宇辉 + 新东方

```
2021-7 双减 → 2021-12-28 东方甄选开播 → 2022-6 双语带货爆红 → 2024-7-25 离职
```

**互构点：**
- 员工借平台（东方甄选）爆红
- 平台借员工（董宇辉）转型
- 双方塑造 1+1=1，互构体
- 离职是互构破裂（价值观不合 / 利益分配）

### 案例 2：张一鸣 + 字节

```
2012 创办 → 2017-12 源码资本年会 Context, not Control → 2024 全球 10 万人
```

**互构点：**
- 字节借张一鸣的「Context, not Control」理念设计组织
- 张一鸣借字节的产品（今日头条 / 抖音）放大方法论
- 双方塑造：互构的「自上而下」机制

### 案例 3：丰田 / 广汽丰田

```
1912 大野耐一 → 1973 蓝绬褒章 → 1978 钻石出版社 → 2024 利润率 10%+
```

**互构点：**
- 丰田借大野耐一的 TPS（丰田生产方式）
- 大野耐一借丰田的工厂验证 TPS
- 互构 100+ 年，形成「造车先育人」文化
- 互构的最长期样本

### 案例 4：华为

```
1996 市场部集体辞职 → 2007 7000 中高层辞职门 → 2017 奋斗者协议
```

**互构点：**
- 华为借市场部集体辞职重塑文化（从销售导向到客户导向）
- 7000 中高层辞职门：互构的「自下而上」机制
- 奋斗者协议：互构的「利益绑定」机制

### 案例 5：阿里巴巴

```
2001-1-13 关明生 → 2004 独孤九剑 → 2017 六脉神剑
```

**互构点：**
- 阿里借关明生的通用电气经验
- 阿里借独孤九剑 / 六脉神剑价值观筛选员工
- 互构的「价值观塑造」机制

## 3 大新概念（已沉淀）

### 1. 互构谐变

> 双向塑造的结构和状态

员工塑造企业 + 企业塑造员工 = 互构谐变

### 2. 造车先育人 / Context, not Control

> 两种互构的「自上而下」机制

- 造车先育人（丰田）
- Context, not Control（字节）

### 3. 1 + 1 = 1

> 互构体的反直觉算式

互构体不是 1+1=2，而是 1+1=1（双方融为一体）
