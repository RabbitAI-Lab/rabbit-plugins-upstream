# 06. 端到端工作流（老板 3 问 → 草稿箱）

> 来源：MEMORY.md「公众号图文生成端到端工作流（v7 master + 配图修正版）」

## 9 步流水线

```
┌──────────────────────────────────────────────────────┐
│ 1. 老板定调（3 问）                                     │
│    写给谁？什么语气？目的？                              │
└──────────────────────────────────────────────────────┘
                       ↓
┌──────────────────────────────────────────────────────┐
│ 2. 头脑风暴 + 信息检索                                  │
│    基于三问的答案，分析核心矛盾 / 可切入角度 / 读者追问       │
└──────────────────────────────────────────────────────┘
                       ↓
┌──────────────────────────────────────────────────────┐
│ 3. 知识库沉淀                                           │
│    knowledge/topics/<主题>_知识库_<YYYYMMDD>.md          │
└──────────────────────────────────────────────────────┘
                       ↓
┌──────────────────────────────────────────────────────┐
│ 4. v* 草稿（散文体 v7 master + 8 铁律）                  │
│    句长 35-50 / 短句<20% / 字数 800-3500 / 关键词>50/万字  │
└──────────────────────────────────────────────────────┘
                       ↓
┌──────────────────────────────────────────────────────┐
│ 5. 渲染脚本（必须用 *_localimg.py 输出相对路径）           │
│    ⚠️ 不用 _localimg = 草稿箱无图                        │
└──────────────────────────────────────────────────────┘
                       ↓
┌──────────────────────────────────────────────────────┐
│ 6. 配图生成（PIL，21:9，1260×540）                       │
│    封面 900×383，正文每节一图，5 张 + 1 张封面            │
└──────────────────────────────────────────────────────┘
                       ↓
┌──────────────────────────────────────────────────────┐
│ 7. dry-run 验证凭据                                     │
│    python publish_wechat.py article.html --dry-run     │
└──────────────────────────────────────────────────────┘
                       ↓
┌──────────────────────────────────────────────────────┐
│ 8. publish_wechat.py 真实入草稿箱                        │
│    python publish_wechat.py article.html \             │
│      --cover-image cover.png \                         │
│      --author "老板" --title "..."                     │
└──────────────────────────────────────────────────────┘
                       ↓
┌──────────────────────────────────────────────────────┐
│ 9. 老板人工群发（订阅号无 freepublish API）              │
└──────────────────────────────────────────────────────┘
```

## 关键修正（2026-06-29）

**步骤 5 必须用 `*_localimg` 渲染脚本输出相对路径**，否则草稿箱无图。

| 错误做法 | 后果 |
|---|---|
| 用 `render_互构谐变_v8.py`（输出 base64 内联） | 草稿箱无图 |
| 用 `render_互构谐变_v8_localimg.py`（输出相对路径） | 5 张图全上传 CDN ✅ |

## 端到端示例（《互构谐变》v8）

```bash
# 1. 老板定调
"写一篇关于企业塑造员工 / 员工塑造企业的深度文章，散文体"

# 2. 头脑风暴 + 信息检索
# → 互构谐变 / Context not Control / 造车先育人 / 1+1=1

# 3. 知识库
# → knowledge/topics/互构谐变_知识库_20260629.md

# 4. 草稿
# → output/preview/企业塑造员工_员工塑造企业_图文草稿v8.md

# 5. 渲染（关键：用 _localimg）
python render_互构谐变_v8_localimg.py

# 6. 配图（5 张 + 1 封面）
python generate_互构谐变_v8_images.py

# 7. dry-run
python publish_wechat.py article.html --dry-run

# 8. 真实入草稿箱
python publish_wechat.py article.html \
  --cover-image imgs/v5_cover_900x383.png \
  --author "老板" \
  --title "互构谐变：企业塑造员工 / 员工塑造企业"

# 9. 老板去微信后台手动群发
```
