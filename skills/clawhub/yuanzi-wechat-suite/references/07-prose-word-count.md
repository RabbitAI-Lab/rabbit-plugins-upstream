# 07. 散文体字数沉淀（800-3500 老板号调性）

> 来源：MEMORY.md「公众号散文体字数（2026-07-01 沉淀）」

## 核心结论

**老板号调性 2,000-3,500 字 / 篇**（不是 v7 铁律 8,500-9,500）

## v7 铁律 vs 老板号调性

| 类型 | 字数 | 适合 |
|---|---|---|
| v7 铁律 | 8,500-9,500 | 深度分析类（如《互构谐变》） |
| **老板号调性** | **800-3,500** | 案例 + 行动建议类（17 篇原创） |

## 关键教训

> **散文体一致性 > 字数硬指标**

老板号优先散文体节奏感，宁可少写也要保持句长 35-50 + 短句<20% + 关键词密度 > 50/万字。

## 17 篇原创（2026-07-01）

按 R3-R5 同款风格：
- 平均字数：~2,500
- 字数范围：1,800-3,200
- 句长均值：42 字
- 短句占比：12%

## Excel 表格踩坑

**踩坑教训：** Excel 表格 R 行 ≠ 序号列。R3 = 序号 1（首行被表头占）。

**处理：** 后续读 xlsx 表格先确认 R 行 ↔ 序号映射，**不凭印象**。

## 字数 vs 散文化平衡

```
字数 < 800          → 太薄，立不住
字数 800-3,500      → 老板号主区间（推荐）⭐
字数 3,500-8,500    → 长文（适合深度分析）
字数 > 8,500        → 过长，读者易疲劳
字数 > 10,000       → 必须分篇
```

## 老板反馈

> 字数不是关键，散文化的节奏感才是 — 老板 2026-07-01
