## Description:

Turn seller-supplied floor-plan facts into one listing still per room.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Real-estate sellers and listing teams use this skill to turn confirmed floor-plan notes into a set of room-by-room listing stills and property-page graphics.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Required permissions include paid media operations and voice changes unrelated to listing stills.

Mitigation: Review permissions before connecting and prefer image-only authorization.

Risk: The uninstall flow may disconnect other Beatra skills.

Mitigation: Check other installed Beatra skills before uninstalling; device access can be revoked in the Beatra Console.

Risk: Optional reference images are processed externally, and installation information is reported automatically.

Mitigation: Share only reference images you intend to send and review the installation-registration disclosure.
