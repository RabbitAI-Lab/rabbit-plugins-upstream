## Description: <br>
Helps AI-agent users, skill authors, maintainers, and teams create Tavily-style web workflow support for bug fixes, setup hardening, reliability improvements, and adjacent skills. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External developers, skill authors, maintainers, and AI-agent teams use this skill to turn Tavily-style work-productivity and web-search needs into practical plans, checklists, artifacts, code changes, or implementation guidance. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad automatic invocation can cause the skill to steer unrelated web, search, API, user, or bug-fix tasks. <br>
Mitigation: Review invocation settings before installing and narrow or disable automatic selection for deployments that require tighter routing. <br>
Risk: Generated workflow, checklist, code, shell command, or configuration guidance can be incomplete or unsuitable for the user's environment. <br>
Mitigation: Validate outputs against the stated success criteria, review assumptions and limits, and test any commands or configuration changes before use. <br>
