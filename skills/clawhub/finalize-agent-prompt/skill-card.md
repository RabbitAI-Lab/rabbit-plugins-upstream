## Description:

Finalize prompt file using the role of an AI agent to polish the prompt for the end user.

This skill is ready for commercial/non-commercial use.

## Publisher:

MIT-0

## Use Case:

Developers, prompt authors, and agent builders use this skill to refine prompt files for clearer structure, wording, grammar, and organization while preserving the original intent and markdown format.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompt edits may unintentionally alter the meaning or priority of existing instructions.

Mitigation: Review the revised prompt against the original intent before using it in an agent workflow.

Risk: Prompt files can contain private operational details or sensitive instructions.

Mitigation: Provide only the prompt file intended for editing and avoid adding unrelated private prompts unless that context should be used.
