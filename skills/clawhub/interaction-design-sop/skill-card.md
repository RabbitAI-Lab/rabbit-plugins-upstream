## Description:

Frontend interaction resilience and defense SOP for engineering implementation, covering pre-coding checks for user intent, task flow, information hierarchy, UI states, perceived performance, shortcuts, and layout resilience.

This skill is ready for commercial/non-commercial use.

## Publisher:

[fize](https://clawhub.ai/user/fize)

### License/Terms of Use:

MIT-0

## Use Case:

Frontend developers and interaction designers use this skill before implementing UI views, forms, dashboards, and component workflows. It helps structure interaction reviews around user intent, friction reduction, P0/P1/P2 information hierarchy, empty/loading/error states, destructive confirmations, perceived performance, keyboard support, and responsive layout resilience.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill has a broad frontend interaction-design scope and may be invoked for tasks that need narrower product UX, component-library, or implementation guidance.

Mitigation: Use routing metadata or explicit prompts to apply it to UI views, forms, dashboards, state design, edge cases, and frontend resilience reviews.

Risk: The skill provides guidance rather than executable enforcement, so generated UI plans can still miss product-specific failure modes or accessibility constraints.

Mitigation: Review generated recommendations against the target product flow, API behavior, accessibility requirements, and destructive-action recovery paths before implementation.
