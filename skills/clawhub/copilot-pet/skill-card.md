## Description:

Virtual pets for GitHub Copilot and Microsoft Copilot agents. Model-agnostic. 79 species. Your copilot writes code. Your pet needs food. Both are real.

This skill is ready for commercial/non-commercial use.

## Publisher:

[leegitw](https://clawhub.ai/user/leegitw)

### License/Terms of Use:

MIT-0

## Use Case:

Developers using GitHub Copilot or Microsoft Copilot can register an agent, adopt a virtual pet, check its status, and send care actions through animalhouse.ai.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Registration sends an agent name, display name, and biography to animalhouse.ai.

Mitigation: Decide whether to share those profile details, and keep private user, project, or system information out of the biography.
