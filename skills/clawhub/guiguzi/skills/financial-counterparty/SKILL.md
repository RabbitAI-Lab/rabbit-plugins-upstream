# 金融交易对手博弈 (S9)

> 鬼谷子曰："制人者握权也"——掌控主动权的人才是真正的赢家。

## 核心JTBD

**"在金融交易中，读懂对手底牌，保护自己底线，设计对手主动走进来的交易结构。"**

## 交易对手三层信息模型

```
Layer 1: 公开立场——"我们估值预期是X"（谈判姿态，不一定是真的）
Layer 2: 真实约束——基金年底到期、LP催DPI、团队有人要离职（真实底线）
Layer 3: 隐藏动机——不是看好你，是为了阻止竞品买你（没说的真正目的）
```

鬼谷子工作：从Layer 1推断Layer 2，警惕Layer 3。

## 六大交易场景

### 1. 融资谈判（创始人vs投资人）

| 投资人策略 | 鬼谷子解读 | 应对 |
|:--|:--|:--|
| 制造时间压力（"TS只有一周有效"） | 测试你的可选性 | 不拒绝也不被逼，暗示有其他选择 |
| 估值锚定（"可比公司都这个倍数"） | 选了有利的可比公司 | 接受框架，逐家拆解调整倍数 |
| 条款试探（"这都是标准条款"） | 利用条款无知 | 逐条过，证明你做了功课 |
| 拖延战术（三周没消息） | 可能在等数据变差/看竞品 | 你设定deadline，暗示"下轮更贵" |

### 2. LP募资（GP vs LP）

- **要求更多披露**：给行业分布、集中度、退出案例，个别持仓名称保密
- **要求更优惠条款**：给非金钱优待（低门槛、co-invest优先、深度交流），守住管理费和Waterfall
- **跟投条款**：所有LP按比例平等，跟投上线≤30%

### 3. 并购条款（买方vs卖方）

- **分阶段信息获取**：设三层信息+入场券（公开→NDA后→意向书后）
- **最后一刻改条款**：暂停48小时，要求具体说明什么数据改变估值
- **人才锁定**：核心3人锁2年，锁定期内改变角色则锁定失效

### 4. 对赌协议（Valuation Adjustment）

四原则：
- 对赌指标≤2个
- 对赌期≤实际可见周期
- 失败代价≤输得起的
- 留"不可抗力"和"善意失败"（达标80%以上按比例调整）

### 5. 大宗交易（Block Trade）

卖方：隐藏规模→多路询价→制造竞争→分阶段披露
买方：判断卖方紧迫度→判断自身承接力→报价

### 6. 联合投资（Co-Investment）

- 防搭便车：要求领投方尽调报告共享，保留独立判断权
- 防信息不对等：问投反对票的人理由、最大风险评级、上一轮后发生的坏事
- 退出权利：Tag-Along权、3年未退出按公允价值回购

## 交易对手五问分析框架

```
① 对手的决策模型是什么？（KPI/成功标准/恐惧）
② 对手的可选性有多大？（替代选择/时间压力）
③ 对手的信息优势在哪里？（知道什么你不知道的）
④ 对手有什么隐藏动机？（背后的真正目的）
⑤ 不成交的后果对谁更重？（不成交成本高的一方更弱）
```

## ⚠️ 合规红线

- ❌ 内幕交易、市场操纵、虚假陈述、违背信义义务、商业贿赂
- ✅ 基于公开信息的博弈分析、合法谈判策略、保护合法利益

## 核心原则

1. 理解对手KPI=理解他的底牌
2. 可选性的多少=谈判力的强弱
3. 信息分层释放——每层换对等承诺
4. 不在时间压力下做决策
5. 条款比估值更重要——估值定义这一笔，条款定义所有后续
