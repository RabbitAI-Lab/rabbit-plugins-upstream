# 鬼谷子七十二术 · 完整参考

> 每术包含：原文引用 | 白话转译 | 现代博弈论等价概念 | 适用场景 | 风险警示

---

## 第一计 阳谋阴谋
- **原文**: "智略计谋，各有形容，或圆或方，或阴或阳，圣人谋之于阴故曰'神'，成之于阳故曰'明'"
- **转译**: 决策与执行分离。暗中筹划，公开收网。
- **博弈等价**: 信息隐藏 → 信号博弈中的混合策略
- **适用**: 任何需要"准备期"的战略行动
- **风险**: 过度保密导致内部不信任

## 第二计 扭转乾坤
- **原文**: "故静固志意，神归其舍，则威覆盛矣，威覆盛，则内实坚，内实坚，则莫当"
- **转译**: 劣势时先凝聚内在精神力量，由内而外改变力量对比。
- **博弈等价**: 先改变内部 payoff 结构，再改变外部均衡
- **适用**: 危机时刻、士气低落时的领导力
- **风险**: 只修内功不行动，变为自我安慰

## 第三计 各个击破
- **原文**: "分威法伏熊，分威者，神之覆也"
- **转译**: 分散对手的威势，像伏熊一样伺机各个击破。
- **博弈等价**: 将多人博弈拆解为多个二人博弈
- **适用**: 面对联盟型对手、多线竞争
- **风险**: 拆分不彻底反而让自己力量分散

## 第四计 如闭如卦
- **原文**: "环转因化，莫之所为，退为尤仪"
- **转译**: 像圆环一样随机应变，让对方无法预判你的真实状态。
- **博弈等价**: 随机化策略，使对手无法形成稳定预期
- **适用**: 被对手研究透了的时候、需要打破对方预判
- **风险**: 过度随机 → 自己团队也无法执行

## 第五计 盗尽天机
- **原文**: "是以圣人居天地之间，立身、御击、施教、扬声、明名也，必因事物之会，观天象之宜"
- **转译**: 抓住事物转化的时机，在最佳时刻行动。
- **博弈等价**: 时机选择 → 期权价值最大化
- **适用**: 市场时机判断、项目启动节点
- **风险**: 永远在等"最好时机"，永远不行动

## 第六计 一言兴邦
- **原文**: "圣人所贵道微妙者，诚以其可以转危为安，救亡使存也"
- **转译**: 关键人物的一句话可以翻转局势。
- **博弈等价**: 廉价谈话 → 在关键节点可以改变均衡
- **适用**: 影响关键决策者、危机公关
- **风险**: 言语操控过度 → 信用破产

## 第七计 众不敌寡
- **原文**: "将枢，谓春生、夏长、秋收、冬藏，天之正也，不可逆之，逆之，虽盛必衰"
- **转译**: 违背规律，即使势大也必败；顺应规律，势单也可胜众。
- **博弈等价**: 顺应系统动力学 → 借力打力
- **适用**: 面对强大但逆势的对手
- **风险**: "顺势"变成借口，实际是逃避

## 第八计 计中诡计
- **原文**: "凡趋合倍反，计有造合，化转环属，各有形势，反复相求，因事为制"
- **转译**: 准备多套方案应对变化，方案之间可以无缝切换。
- **博弈等价**: 条件策略 → 对每种可能状态都有预案
- **适用**: 高度不确定性的决策场景
- **风险**: 方案太多 → 决策瘫痪

## 第九计 天地无常
- **原文**: "天地所变换，既有变换，岂能长久乎？"
- **转译**: 没有不变的格局，不革新就被淘汰。
- **博弈等价**: 动态博弈 → 均衡是暂时的
- **适用**: 行业变革期、组织转型
- **风险**: 为变而变，失去定力

## 第十计 推陈出新
- **原文**: "曲则全，枉则过，满则盈，敝则新，少则得，多则惑"
- **转译**: 创新必须建立在传统基础上，新旧非对立而是延续。
- **博弈等价**: 路径依赖 + 创新 → 在现有均衡上寻找帕累托改进
- **适用**: 产品迭代、业务升级
- **风险**: 完全抛弃旧基础 → 失去立足点

## 第十一计 高瞻远瞩
- **原文**: "智用于众人之所不能知，亦能用于众人之所不能见"
- **转译**: 智者能看到众人看不到的东西。
- **博弈等价**: 信息优势 → 高阶信念
- **适用**: 战略规划、趋势判断
- **风险**: 变成"众人皆醉我独醒"的傲慢

## 第十二计 翻手为背
- **原文**: (无直接原文，方法论表述为)变是万物发展的规律
- **转译**: 用灵活而非机械的方法应对变化，胜不骄败不馁。
- **博弈等价**: 策略灵活性 → 适应性预期
- **适用**: 原计划失效时的快速调整
- **风险**: 灵活变成没有原则

## 第十三计 忤合深谋
- **原文**: (方法论)一条计策不能通用于两个不同场景
- **转译**: 每个场景需要量身定制的策略。
- **博弈等价**: 情境依赖策略 → 不存在一劳永逸的均衡
- **适用**: 进入新市场、面对新对手
- **风险**: 每次都重造轮子 → 效率低

## 第十四计 暗度陈仓
- **原文**: "圣人之道阳，愚人之道阴，圣人之制道，在隐与匿"
- **转译**: 制造假象迷惑对手，暗中执行真正的行动。
- **博弈等价**: 信号干扰 → 让对手在错误信息上做决策
- **适用**: 竞争激烈的市场进入、商业秘密保护
- **风险**: 假象被识破 → 信誉崩塌

## 第十五计 一点突破
- **原文**: "从外制内，事有因，由而随也"
- **转译**: 抓住关键环节突破，一切迎刃而解。
- **博弈等价**: 关键节点策略 → 找到博弈中的 choke point
- **适用**: 复杂问题的简化处理
- **风险**: 找错关键点 → 白费力气

## 第十六计 视微成巨
- **原文**: "察其事，论万物，别雌雄，虽非其事，见微知类"
- **转译**: 从细微征兆推知潜在的重大事件。
- **博弈等价**: 贝叶斯更新 → 从小样本推断全局
- **适用**: 竞品分析、风险预警
- **风险**: 过度解读 → 把噪声当信号

## 第十七计 主客互变
- **原文**: "故为强者积于弱也，为有者积于曲也，有余者积于不定也，此其道不行也，柔弱胜于刚强，故积弱可以为强"
- **转译**: 主客之势可以互换，强弱可以转化。
- **博弈等价**: 动态优势 → 先动优势 vs 后动优势的转化
- **适用**: 攻守转换、市场格局变化
- **风险**: 转换时机判断失误

## 第十八计 纳叛招降
- **原文**: "勿坚而拒之，许之则防守，拒之则闭塞"
- **转译**: 不拒绝任何愿意归附的人，保持开放。
- **博弈等价**: 扩大联盟 → 改变博弈参与者集合
- **适用**: 招聘、合作伙伴拓展
- **风险**: 来者不拒 → 质量失控

## 第十九计 应敌而动
- **原文**: (方法论)不轻举妄动，锻炼到能克敌制胜时才行动
- **转译**: 不争强好胜消耗自己，积蓄力量到能必胜。
- **博弈等价**: 战略耐心 → 等待 dominant strategy 出现的时机
- **适用**: 后发制人、跟随策略
- **风险**: 永远在准备 → 错过窗口

## 第二十计 三教九流
- **原文**: "凡度权量能，所以征远求近，其有隐括，乃可挣，乃可求，乃可用"
- **转译**: 广泛吸纳各方面人才，不拘一格。
- **博弈等价**: 多元化团队 → 更全面的信息集
- **适用**: 团队建设、人才战略
- **风险**: 多元但无凝聚力 → 内部协调成本过高

## 第二十一计 散纵连横
- **原文**: "用分威散众之权，以见其兑威"
- **转译**: 破坏敌人的联盟，增强自己的联盟。
- **博弈等价**: 联盟博弈 → 改变联盟结构改变均衡
- **适用**: 行业联盟、生态竞争
- **风险**: 自己也可能被同样策略瓦解

## 第二十二计 飞钳破敌
- **原文**: (方法论)运用各种手段制造对方无法摆脱的局势
- **转译**: 制造一种形势，使对方"缀而不失"——被钳住无法摆脱。
- **博弈等价**: 承诺策略 → 让对方进入没有更好选择的境地
- **适用**: 谈判锁定、客户绑定
- **风险**: 钳制过度 → 对方宁可自损也要挣脱

## 第二十三计 料敌如神
- **原文**: "寂然不动，感而遂能天下之敌，能知于知，见于不见"
- **转译**: 透过复杂现象，掌握对手的真实动向。
- **博弈等价**: 类型推断 → 从行动反推对手的 private information
- **适用**: 竞品战略判断、对手意图分析
- **风险**: 过度自信 → 误判

## 第二十四计 间不能人
- **原文**: "筹措万类之始终，达人心之理，见变化之朕焉"
- **转译**: 从微小细节中捕捉重大事情的征兆，识破阴谋。
- **博弈等价**: 信号甄别 → 区分真实信号和欺骗信号
- **适用**: 尽职调查、欺诈识别
- **风险**: 多疑 → 信任成本过高

## 第二十五计 弱可攻强
- **原文**: "故为强者积于弱也，也有者积于曲也，有余者积于不定也，此其道术行也，柔胜于刚强，故积弱可以为强"
- **转译**: 弱和强是相对的，弱可以胜强。
- **博弈等价**: 非对称博弈 → 弱者可以在特定维度获得局部优势
- **适用**: 小公司对大公司、弱势谈判方
- **风险**: 低估对手 → 自取灭亡

## 第二十六计 无中生有
- **原文**: "神道混沌为一，以变论万义类，说义无穷"
- **转译**: 从混沌中推论万物变化，从"无"中创造出"有"。
- **博弈等价**: 创新 → 创造新的博弈维度
- **适用**: 商业模式创新、蓝海战略
- **风险**: 创造的东西没有真实需求

## 第二十七计 空中楼阁
- **原文**: "饰言者，假之也，假之者，益损也"
- **转译**: 利用言语构筑愿景，调动己方积极性，引诱对方。
- **博弈等价**: 廉价谈话 → 预期管理 → 自我实现的预言
- **适用**: 愿景领导、融资路演、团队激励
- **风险**: 画饼过度 → 信任崩盘

## 第二十八计 带兵带心
- **原文**: "摄心者，人系其心于己"
- **转译**: 带兵必须以带心为最高原则。
- **博弈等价**: 内在动机 → 激励相容
- **适用**: 团队管理、领导力
- **风险**: 情感绑架 → 反噬

## 第二十九计 一石二鸟
- **原文**: "或因此，或因彼；或以事上，或以敌下"
- **转译**: 一个计谋能收到多种效果为最佳。
- **博弈等价**: 策略的外部性 → 一个动作影响多个博弈
- **适用**: 资源有限时的效率最大化
- **风险**: 目标太多 → 哪个都没达到

## 第三十计 四两千斤
- **原文**: "何谓量权？曰：度于大小，谋于众寡"
- **转译**: 知己知彼，以四两巧力胜千斤。
- **博弈等价**: 杠杆策略 → 找到最小的支点撬动最大
- **适用**: 资源匮乏时的竞争策略
- **风险**: 找错支点 → 费力无效

## 第三十一计 万金间敌
- **原文**: "事皆有内捷，索使本捷或结以财货，或结以采邑"
- **转译**: 用金钱利益去瓦解对方内部。
- **博弈等价**: 贿赂/激励 → 改变对方内部 payoff 结构
- **适用**: 商业竞争中的关键人争取
- **风险**: 法律风险 + 对方也可以同样对你

## 第三十二计 制人行权
- **原文**: (方法论)能牵制别人的人是掌握主动权的人
- **转译**: 掌握主动权，不被别人牵着走。
- **博弈等价**: 先动优势 → 设定博弈规则
- **适用**: 谈判中的议程设置
- **风险**: 控制欲过强 → 对方反弹

## 第三十三计 谋泄无功
- **原文**: "欲说者务隐度，计事者务循顺"
- **转译**: 谋略泄露则一切白费，严守秘密。
- **博弈等价**: 信息保密 → 维持信息不对称
- **适用**: 未公开的战略、商业机密
- **风险**: 过度保密 → 执行层无法配合

## 第三十四计 怒倾帝王
- **原文**: "其摩者，有以平，有以正，有以喜，有以怒，怒者，动也"
- **转译**: 激怒对方使其失去判断力，或用情绪力量推动决策者。
- **博弈等价**: 情绪博弈 → 改变对手的理性计算基础
- **适用**: 打破僵局、推动犹豫不决的决策者
- **风险**: 情绪失控 → 关系破裂

## 第三十五计 万年大计
- **原文**: "远而可知者，反往以验来"
- **转译**: 目光长远，不因小利损大计。
- **博弈等价**: 无限次重复博弈 → 长期收益最大化
- **适用**: 战略规划、品牌建设
- **风险**: 长期主义变成拖延借口

## 第三十六计 无形之势
- **原文**: "势者，利害之决，权变之威，势败者，不以神肃察也"
- **转译**: 在众人未留意时悄悄布局，等时机一鸣惊人。
- **博弈等价**: 隐性优势积累 → 关键时刻一次性释放
- **适用**: 秘密项目、低调布局
- **风险**: 一直"低调" → 错过展示时机

## 第三十七计 不战为勇
- **原文**: "主兵日胜者，常战于不争不费，而民不知所以服，不知所以畏，而天下比之，神明也"
- **转译**: 不消耗资源、不打仗就让对方罢手，这是最高境界。
- **博弈等价**: 威慑 → 不需要实际冲突就能改变对方行为
- **适用**: 展示实力而不使用、威慑策略
- **风险**: 威慑失效 → 对方试探底线

## 第三十八计 霸者之资
- **原文**: "诸侯相抵，不可胜数，当此之时，能抵为右"
- **转译**: 危机时刻挺身而出，建立霸业。
- **博弈等价**: 危机中的机会 → 系统崩溃时的先发优势
- **适用**: 行业洗牌期、市场危机
- **风险**: 冒险失败 → 全军覆没

## 第三十九计 无百年敌
- **原文**: "世无常贵，事无常师，反于是，杵于彼，其术也"
- **转译**: 没有永远的朋友也没有永远的敌人。
- **博弈等价**: 动态联盟 → 博弈参与者的可变性
- **适用**: 竞争合作关系管理
- **风险**: 反复无常 → 没有人信任你

## 第四十计 降人引路
- **原文**: "情合者听，故物归类，抱薪趋火，燥者易燃，平地注水，湿者先濡，此物类相应"
- **转译**: 投其所好，让对方产生感恩心理，从而愿意为你所用。
- **博弈等价**: 互惠策略 → 建立正向反馈循环
- **适用**: 关键关系建立
- **风险**: 变成讨好 → 失去尊重

## 第四十一计 招贤攉奇
- **原文**: "计谋之用，公不如私，私不如结，结而无隙者也"
- **转译**: 公开不如私下，私下不如结盟。
- **博弈等价**: 联盟形成 → 从非合作博弈转向合作博弈
- **适用**: 人才招募、战略合作
- **风险**: 小圈子 → 排外

## 第四十二计 推己及人
- **原文**: "无以人之近所不欲，而强之于人，无以人之所不知，而教之于人"
- **转译**: 不要强迫别人接受他们不想要的东西。
- **博弈等价**: 参与约束 → 对方必须自愿
- **适用**: 产品设计、团队激励
- **风险**: 过度迁就 → 失去方向

## 第四十三计 反有所得
- **原文**: "欲强反剑，欲高反下，欲取反予，此言反听之道，有以致诱之"
- **转译**: 想要得到反而先给予。反向操作往往效果更好。
- **博弈等价**: 逆向归纳 → 从终点往回推
- **适用**: 以退为进的策略
- **风险**: 对方接受你的"退"但不给你"进"的机会

## 第四十四计 退避观战
- **原文**: "郄无极大，御无强大，则背可胁而并"
- **转译**: 退一步观察变化，强弱是可以转化的。
- **博弈等价**: 等待策略 → 让对手先暴露信息
- **适用**: 多方混战时
- **风险**: 退太多 → 被边缘化

## 第四十五计 脱困之法
- **原文**: "中经，谓振穷趋急"
- **转译**: 无论什么环境都坚持信念，能吃别人吃不了的苦。
- **博弈等价**: 韧性策略 → 在极端参数下仍然存活
- **适用**: 个人逆境、组织危机
- **风险**: 苦熬但方向错误
