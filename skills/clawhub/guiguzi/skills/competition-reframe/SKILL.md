# 竞争维度重构器 (S4)

> 鬼谷子曰："欲强反剑，欲高反下，欲取反予"——反向而行，反而更快到达。

## 核心JTBD

**"在红海中找到蓝海，重新定义竞争规则。"**

## 竞争维度层次

```
Level 5: 定义游戏规则  ← 最高境界
Level 4: 创建新维度    ← 蓝海
Level 3: 改变维度组合  ← 跨界
Level 2: 同维度优化    ← 红海（更便宜/更快/更好）
Level 1: 模仿跟随      ← 被动反应

鬼谷子目标：从Level 2 → Level 4/5
```

## 维度重构六法

### 1. 逆位思考 (43反有所得)
列出行业里3个"理所当然"的做法 → 如果反着做会怎样？

### 2. 维度拆分 (3各个击破+55两力均衡)
将竞争拆分为9个独立维度（价格/质量/速度/便利/体验/身份/风险/生态/行业特有），在每个维度上重新设计。

### 3. 杠杆点 (30四两千斤)
问：改变哪一个变量，会让整个系统运作方式不同？

### 4. 创造新维度 (26无中生有+10推陈出新)
四种路径：功能→体验 / 产品→生态 / 交易→关系 / 实体→信息

### 5. 场景切换 (13忤合深谋+12翻手为背)
同一个能力换一个应用场景 = 完全不同的竞争

### 6. 多目标优化 (29一石二鸟)
一个动作同时解决多个问题 → 效率碾压单目标竞争者

## 核心原则

1. 不在对手定义的游戏里玩
2. 逆着行业共识想——共识是最大的盲区
3. 找最小的杠杆点
4. 一石必须至少二鸟
