### 金融特有话术模板

**LP募资场景:**
```
普通做法: "我们IRR行业前四分之一，团队来自高盛"
→ LP听过100遍了

鬼谷子做法:
"张总，这次基金我们只开放给15个LP，而且已经有8个确认了。
不是因为故意做稀缺——是因为我们策略的容量有限。
超过X亿，策略的超额收益会被容量吃掉。

我宁愿规模小一点，也要保证每个LP的回报。"

→ 策略: 64欲将取之（先予后取的反向）
  不是"求你投我们"，是"我只接受懂这个策略的钱"
→ 鬼谷子曰: "欲强反剑，欲高反下"
  想抬高自己 → 反而把门槛设高
```

**抢项目场景（说服创始人选你而非红杉）:**
```
普通做法: "我们除了钱还能给你资源"

鬼谷子做法:
"我不跟你画饼说我们有'生态赋能'——你知道那些大多数是虚的。
我就说三件真事:
1. 去年被投企业XX遇到YY问题，我凌晨三点接的电话
2. 我不投董事会席位——因为我不需要靠席位证明我参与了
3. 如果下一轮需要对接，我的LP里有三位是产业方，
   我可以安排你跟其中一位聊30分钟——在投资之前。
   
你选谁是你的自由。我唯一的请求是: 做决定前，
跟我们的被投企业创始人聊一次。只听他们怎么说。"

→ 策略: 40降人引路 + 42推己及人
  不是"证明自己好"，是"让你自己去验证"
→ 提供"跟被投聊"这个动作 = 把判断权还给创始人
  （真正好的被投关系会帮你说话）
```

| 金融场景 | 鬼谷子战术 | 具体操作 |
|:--|:--|:--|
| **Term Sheet谈判** | 48兼弱攻昧 + 64欲将取之 | 找到对方条款中"最想保护的点"，在那个点上让步，在别的点上拿回来 |
| **估值谈判** | 4如闭如卦 + 30四两千斤 | 不先出价，先问"这个估值你是怎么算出来的"→ 拆解对方的估值逻辑 |
| **并购条款** | 22飞钳破敌 + 14暗度陈仓 | 在对方真正在意的问题上让步，换取关键条款 |

| **退出谈判** | 59强而避之 + 43反有所得 | 二级市场老股转让的定价博弈 |

### 金融特有战术

**战术: 估值框架拆解（专用于融资谈判）**

```
投资人: "我们估1亿，因为可比公司都是这个倍数"

你:
"好，我们先对齐可比公司。

你提到的三家公司——
A公司: 你的对标逻辑是行业相同。但A的增速是15%，我们是60%。
B公司: 产品形态类似。但B是SaaS，我们是AI驱动的SaaS，
       毛利高12个点。
C公司: 规模相近。但C上一轮是三年前的数据，那个时代的倍数
       不能用在今天。

如果我们把这三个调整因素放进去——
增速溢价+2x，毛利溢价+1.5x，时间调整+1x——
合理的倍数就不是你们说的X，而是X+4.5。

我们可以在这个基础上谈。"

→ 关键: 不是在"价格"上讨价还价，是在"定价逻辑"上重构
→ 你接受他的倍数为起点，这让他觉得被尊重了
→ 但你调整了倍数的计算方式，最终结果变了
→ 鬼谷子: "欲高反下"——先接受对方的框架，再在框架内翻盘
```

**战术: 信息差利用（专用于交易谈判）**

```
场景: 你知道对方基金面临"退出压力"——LP在催DPI

不直接挑明，而是:

"我理解你们的估值预期。但我好奇一件事——

如果这轮我们不看估值，而是看'确定性和速度'，
你们能接受到什么程度？

比如说，我们能在30天内close，
不需要外部尽调（用你们去年的尽调数据更新），
全部走现金，不做对赌。

在这个条件下，估值的弹性有多大？"

→ 你没有说"我知道你们急着退出"
→ 你把"速度"作为价值交换（你给速度，他们给价格）
→ 双方各取所需，而且不失面子
```

### ⚠️ 金融边界

```
✅ 适用: PE/VC条款、并购、融资、基金条款
⚠️ 谨慎: 在与散户/公众的交易中（信息不对称有法律风险）
❌ 不适用: 证券欺诈、虚假披露、操纵定价
```

### 金融特有信号识别

**信号: 财报之外的真相**

```
标准化数据（所有人都在看的）:
  → 收入、利润、毛利率、EBITDA...
  → 这些已经price in了

非标准化信号（鬼谷子帮你找的）:

  1. 管理层措辞变化:
     "充满信心" → "谨慎乐观" = 红牌警告
     "我们在投资未来" → "短期利润承压" = 接下来要出坏消息

  2. 招聘网站动态:
     公司突然大量招聘某个方向的人才 = 新业务方向
     公司停止招聘某个方向 = 该业务被放弃
     财务岗大量招聘 → 可能在准备IPO或被收购

  3. 供应商/客户动态:
     去LinkedIn看这家公司的供应商销售在抱怨什么
     去看这家公司的客户的评价（公开渠道）
     → 第三方的话比公司自己说的真实

  4. 沉默信号:
     财报里没提到的往年重点业务 = 可能在萎缩
     高管离职没发公告 = 可能有冲突
     投资人减持但不在前十大股东名单里显示 = 正在悄悄退出

  5. 信用与法律信号:
     看公司有无新增仲裁/诉讼（裁判文书网/企查查）
     看社保缴纳人数的月度变化（人力外包的信号）
```

**信号: 市场叙事生命周期**

```
用70耳食传谣 + 63主观大害判断市场情绪阶段:

  Phase 1: 萌芽期（少数人开始讲这个故事）
    信号: 行业KOL开始讨论，但主流不关注
    策略: ✅ 深入研究，可能是机会

  Phase 2: 扩散期（故事开始传播）
    信号: 卖方开始出报告，媒体开始报道
    策略: ✅ 如果基本面对，这是最佳入场期

  Phase 3: 共识期（所有人都相信了）
    信号: 散户开始讨论，微信群疯转，头条报道
    策略: ⚠️ 故事可能已经price in甚至过度price in
    → 70耳食传谣: "众口能烁之"= 当所有人都信的时候，就是危险的时候

  Phase 4: 拥挤期（没有人质疑了）
    信号: 反对声音被嘲笑，共识变成"信仰"
    策略: ❌ 不管基本面多好，这个位置风险回报比已经恶化
    → 63主观大害: 小心你自己也变成了"信众"
```

### ⚠️ 金融边界

```
✅ 适用: 基本面研究、尽调、管理层分析、行业研究
✅ 适用: 基于公开信息的信号提取
⚠️ 谨慎: 宏观判断/资产配置（必须配合量化框架）
❌ 不适用: 内幕信息获取、技术分析、量化信号生成
```

| **基金募资困难** | 17主客互变 + 7众不敌寡 | 改变募资策略，从劣势中找优势 |
| **被竞争对手狙击** | 52退兵制兵 + 36无形之势 | 不被拖入对方的节奏 |

### 金融特有翻盘路径

**场景: 基金连续两个季度跑输基准**

```
错误做法: 加大仓位追回来 → 越输越多
鬼谷子做法:

Step 1: 止损（59强而避之）
  "把仓位降到让你晚上能睡着的水平"
  → 减仓 ≠ 认输。减仓 = 恢复冷静的前提
  → 亏损的大脑做的决策 = 最差的决策

Step 2: 收缩（44退避观战）
  "暂时不碰让你亏损的那个策略类型"
  → 回到你最熟悉的、确定性最高的策略
  → 不要求"马上赚回来"，只要求"不再继续亏"

Step 3: 积蓄（2扭转乾坤）
  "重新研究，但这次不急着下注"
  → 用"旁观者"的视角重新审视市场
  → 不是你在交易，让"冷静的你"在交易

Step 4: 释放（36无形之势）
  "等你真的看到了一个'高确信'的机会，再出手"
  → 不要求"每个机会都抓住"
  → 只抓"你看得懂、你等得起、你错得起的"
```

### ⚠️ 金融边界

```
✅ 适用: 投资心理管理、风险纪律、被投企业危机辅导
⚠️ 谨慎: 具体仓位的"翻盘"操作必须配合风险管理框架
❌ 不适用: 保证金爆仓等极端情况（需要专业风控，不是鬼谷子能救的）
```

## 金融场景三大红线（不可逾越）

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  红线1: 不用于择时预测                                       │
│  ────────────────────                                       │
│  鬼谷子不能帮你"判断市场顶底"、"预测明天涨跌"。              │
│  原因: 市场是涌现现象，不是人格化的对手。                    │
│  违反后果: 在"策略"的美名下赌博。                           │
│                                                             │
│  红线2: 不触碰非公开信息                                     │
│  ────────────────────                                       │
│  鬼谷子的"情报收集"仅限于公开信息的深度解读，                │
│  不包括内幕交易、商业间谍。                                  │
│  违反后果: 法律后果 + 职业生涯终结。                        │
│                                                             │
│  红线3: 不违反信义义务                                       │
│  ────────────────────                                       │
│  基金管理者对LP的信义义务高于一切策略考量。                  │
│  任何"策略"不能成为违反fiduciary duty的借口。               │
│  违反后果: 法律+信誉双重毁灭。                              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
