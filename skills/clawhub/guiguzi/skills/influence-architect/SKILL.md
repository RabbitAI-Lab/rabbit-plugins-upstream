# 影响力架构师 (S3)

> 鬼谷子曰："情合者听"——先让对方感觉你理解他。

## 核心JTBD

**"当我要影响/说服关键人物时，设计让对方无法拒绝的方案。"**

## 分析框架：四步解局

### Step 1: 画像——理解目标人物的"决策模型"

必须搞清楚：
- 核心驱动力（他想要什么）
- 核心恐惧（他怕什么）
- 决策标准（他如何判断对错好坏）
- 信息来源（他听谁的）
- 当前压力（什么让他夜不能寐）

### Step 2: 映射——匹配鬼谷子策略

| 策略 | 适用场景 | 核心方法 |
|:--|:--|:--|
| **利害绑定** (67) | 目标人物理性、计算导向 | 把你的诉求设计成"符合他自身利益" |
| **愿景构筑** (27+6) | 目标需要"意义感"驱动 | 构建让他认同的未来图景 |
| **先予后取** (64+40) | 没有信任基础 | 先提供价值，建立互惠 |
| **飞钳锁定** (22) | 需要让对方无法退出 | 创造退出成本，公开承诺锁定 |
| **借势施压** (32) | 对方关注外部评价 | 借用第三方力量推动 |
| **推己及人** (42) | 对方产生抵触情绪 | 先完全站到对方立场理解 |

### Step 3: 序列——设计行动时间线

```
T-2周: 信息收集 → 确认KPI/痛点/决策标准
T-1周: 关系建立 → 非正式接触，只问不推
T-0:   正式推动 → 主策略执行，目标获得"小承诺"
T+1周: 跟进锁定 → 利用小承诺扩大战果
```

### Step 4: 预判——准备三种预案

- ✅ 同意 → 锁定 + 扩大
- ⚠️ 犹豫 → 降低门槛 + 分阶段承诺
- ❌ 拒绝 → 退回理解 + 先予，不退场

## 核心原则

1. **先理解，后推动**——不了解决策模型就推，失败率>80%
2. **先给予，后索取**——互惠是人类行为底层代码
3. **先分步，后扩大**——要到一个小的"是"比被拒绝一个大的"是"好一万倍
4. **不攻击，只重构**——不否定对方立场，帮他看到新维度
5. **永远留退路**——今天不行不代表明天不行

## 伦理边界

- ❌ 欺骗、操纵、伤害他人
- ✅ 正常商业谈判、职场影响、关系协调
