# 长期博弈战略家 (S6)

> 鬼谷子曰："圣人谋之于阴故曰'神'，成之于阳故曰'明'"——决策与执行分离，暗中筹划，公开收网。

## 长期vs短期博弈者

| 维度 | 短期博弈者 | 长期博弈者 |
|:--|:--|:--|
| 目标 | 赢这一局 | 赢最后一局 |
| 策略 | 最大化当前收益 | 最大化累计收益 |
| 对对手 | 打倒对手 | 保持生态（有时帮对手活下来） |
| 对失败 | 不可接受 | 失败=信息获取(69以敌为师) |
| 时间偏好 | 高折现率 | 低折现率（能等） |

## 长期博弈六律

### 律一：阳谋阴谋——决策与执行分离 (1+36+56)
隐藏准备，聚集势能，关键时刻一次性释放。

### 律二：万年大计——无限游戏视角 (35+51)
每个决策问三问：
- 这个选择让未来选项变多还是变少？（变多=好）
- 如果玩100轮，这策略还对吗？
- 我死后这个布局还能运转吗？

### 律三：无形之势——沉默中积累 (36+56)
四种势能：位置势能（网络中的位置）/ 信息势能（你知道别人不知道的）/ 关系势能（信任和人情）/ 能力势能（T型技能栈）

### 律四：计中诡计——多套方案 (8+9)
每个重要目标准备Plan A（最优）/ B（次优）/ C（替代）/ D（止损），切换条件预设。

### 律五：制造敌人+以敌为师 (68+69)
设定对标对手激励团队，同时向敌人学习所有弱点诊断。

### 律六：霸者之资——危机中出手 (38+54)
大多数时候积累，极少数时候全力出手。出手时机：行业危机 / 对手犯错 / 新拐点 / 有安全垫。

## 核心原则

1. 打100局，不是1局——每局为下一局创造更好条件
2. 让未来选项变多——最好的决策扩大可选空间
3. 在沉默中积累——真正的势能别人看不到
4. 危机=机会——长期博弈者喜欢重新洗牌
5. 耐心是最大武器——大多数人输在等不起
