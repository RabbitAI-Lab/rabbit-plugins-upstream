# 联盟与人才操盘手 (S5)

> 鬼谷子曰："摄心者，人系其心于己"——带兵以带心为最高原则。

## 核心JTBD

**"建立和管理高质量的人际联盟网络和人才体系。"**

## 人际力量四象限

```
              关系深度
  浅关系 ┌──────┼──────┐ 深关系
         │ 合作者│ 盟友  │
   ──────┼──────┼──────┼── 利益一致性
         │ 路人  │ 对手  │
         └──────┼──────┘
```

鬼谷子核心：把路人和对手往合作者/盟友转化，把对手的盟友往路人转化。

## 五大操作模块

### A. 人才吸引 (41+50+20)
三个层次：利益吸引（基础）→ 意义吸引（中级）→ 关系吸引（高级）
按目标人物类型匹配：能力型→挑战 / 资源型→枢纽地位 / 成长型→成长空间 / 稳定型→信任

### B. 人心凝聚 (28+49)
四步：看见（具体肯定）→ 托付（交重要的事）→ 兜底（犯错时替他扛）→ 格局（让他看到更大的事业）

### C. 联盟构建 (21+41)
构建：识别共同利益者 → 让他们互相连接（网状>星形）→ 创造共享沉没成本
瓦解：找最不满意的成员 → 给更好选择 → 等联盟自然松动

### D. 对手转化 (65+18+39)
直接转化（不拒绝归附者）/ 间接利用（利用对方内部矛盾）/ 等待转化（环境变，利益自然重排）

### E. 信号投资 (47)
用高成本的公开行动证明诚意。如：给第一个人远超市场价的待遇 = 信号自己传播。

## 核心原则

1. 心在人在——利益买时间，心才能买忠诚
2. 不让门关——永远不拒绝任何愿意靠近的人
3. 敌人是暂时的——不把关系做绝
4. 网状>星形——让盟友互相连接
5. 信号要贵——廉价承诺没人信，昂贵行为自己传播
