## 核心模型：长期博弈 vs 短期博弈

```
                短期博弈者              长期博弈者
               ───────────            ───────────
目标:          赢这一局                赢最后一局
策略:          最大化当前收益          最大化累计收益
对对手:        打倒对手                有时帮对手活下来（保持生态）
对盟友:        用完即弃                持续投资关系
对信息:        公开炫耀                隐藏实力(56以隐为显)
对失败:        不可接受                失败 = 信息获取(69以敌为师)
对时间:        时间是敌人              时间是朋友(35万年大计)
时间偏好:      高折现率                低折现率（能等）

核心区别:
  短期博弈者的每一个动作都在"消费"自己的未来可能性
  长期博弈者的每一个动作都在"投资"自己的未来可能性
```

## 长期博弈六律

### 律一: 阳谋阴谋 —— 决策与执行分离

> 映射: 1阳谋阴谋 · 36无形之势 · 56以隐为显

```
"圣人谋之于阴故曰'神'，成之于阳故曰'明'"

长期布局者从不公开自己的全部意图:

  谋划阶段 (阴):
  · 在别人看不见的地方做准备
  · 不声张、不预告、不解释
  · 让对手在你的"不在场"时放松警惕
  
  执行阶段 (阳):
  · 时机到 → 一次性释放积累的优势
  · 对手反应过来时，局面已经变了
  · 人们看到的是"突然的成功"，看不到背后的布局

  现代应用:
  · 公司: 秘密研发 → 发布日一击制胜
  · 个人: 低调积累能力 → 关键时刻出手
  · 投资: 研究期沉默 → 时机到了果断出手

  警示: 阳谋阴谋 ≠ 欺骗。是"在正确的时间披露正确的信息量"。
```

### 律二: 万年大计 —— 用无限游戏的眼光

> 映射: 35万年大计 · 51身后之计

```
"远而可知者，反往以验来"

无限游戏 vs 有限游戏:
  有限游戏: 有明确的终局和时间边界 → 最大化终局收益
  无限游戏: 没有终局 → 目标是"继续玩下去并越来越好"

长期博弈者每一个决策都问:
  1. 这个选择会让我的未来选项变多还是变少？
     → 变多 = 好选择（即使短期收益低）
     → 变少 = 坏选择（即使短期收益高）

  2. 如果这个游戏玩100轮，我现在的策略还对吗？
     → 如果100轮后就错了 → 现在的策略不可持续
     → 如果100轮后仍然对 → 这是好策略

  3. 我死后，这个布局还能运转吗？（51身后之计）
     → 如果能 → 这是真正的大布局
     → 如果不能 → 你只是在给自己打工

"万年大计"的日常应用:
  · 今天多学一个技能 → 选项空间 +1%（复利）
  · 今天多交一个靠谱的朋友 → 关系资本 +1%（复利）
  · 今天多积累一个案例 → 信任资产 +1%（复利）
  
  这些+1%在每一局单独看都不重要
  但100局之后，差距是指数级的
```

### 律三: 无形之势 —— 在沉默中积累

> 映射: 36无形之势 · 56以隐为显

```
"势者，利害之决，权变之威"

势 ≠ 力
  力 = 你现在能做什么（存量）
  势 = 你即将能做什么（势能 → 动能的转化）

势的积累方式:
  1. 位置势能: 你在网络中的位置
     → 你是不是多个信息流的交汇点？
     → 你是不是不同圈子之间的"桥"？

  2. 信息势能: 你知道但别人不知道的
     → 持续学习 + 跨领域连接 = 信息优势
     → 这个优势会自己增长（知道越多越容易知道更多）

  3. 关系势能: 你积累的信任和人情
     → 每一笔"给予"都是存进将来的势能
     → 不见得马上兑换，但关键时刻可以

  4. 能力势能: 你的技能栈
     → 技能不是越多越好 → 是越"不可替代"越好
     → T型: 一纵(深度) + 一横(广度) = 最大势能

  "无形"的意思是:
  · 在你的势释放之前，没有人能看到它
  · 当它释放的时候，人们看到的是结果，不是过程
```

### 律四: 计中诡计 —— 永远有多套方案

> 映射: 8计中诡计 · 9天地无常

```
"凡趋合倍反，计有造合，化转环属，各有形势"

长期博弈中最大的风险不是"对手太强"
而是"唯一方案失效了就没有退路"

多方案设计:
  对于每一个重要目标，准备:
  ├─ Plan A: 最优路径（假设一切顺利）
  ├─ Plan B: 次优路径（如果A遇到阻力）
  ├─ Plan C: 替代路径（从另一个方向绕过去）
  └─ Plan D: 止损路径（放弃这个目标，转投其他的）

  方案切换的触发条件必须预先设定:
  "如果X发生 → 从A切换到B"
  不要在惊慌中做切换决策

  9天地无常的应用:
  定期审视: 你的Plan A还成立吗？
  → 环境一直在变，去年最优的路径今年可能已经过时了
  → 每季度做一次"方案体检"
```

### 律五: 制造敌人与以敌为师

> 映射: 68制造敌人 · 69以敌为师 · 38霸者之资

```
"斗郄者，斗强也" (68制造敌人)
"效之于人，验去乱之前，吾归于诚已" (69以敌为师)

这组策略表面矛盾，实则互补:

68制造敌人 — 内部凝聚力工具:
  · 有一个"假想敌"让团队保持紧迫感
  · 不是真的要攻击谁，是设定一个"对标目标"
  · "我们要成为X领域的谁谁谁"→ 这就是假想敌
  ⚠️ 风险: 假想敌过度 → 四面树敌 + 方向性偏离

69以敌为师 — 学习工具:
  · 敌人是最诚实的老师
  · 敌人会找到你所有的弱点 → 这是免费的诊断
  · 敌人的强项 → 就是你的能力缺口
  ⚠️ 条件: 必须有自信和格局，才能从敌人那里学东西

两者结合:
  68 + 69 = 设定一个"对标对手"，既用它激励团队，又向它学习
  这是最健康的"制造敌人"方式
```

### 律六: 霸者之资 —— 危机中出手

> 映射: 38霸者之资 · 54攻国攻敌

```
"诸侯相抵，不可胜数，当此之时，能抵为右"

长期博弈者需要: 耐心 + 关键时刻的果断

大多数时候: 积累（36无形之势）
极少数时候: 出手（38霸者之资）

出手时机判断:
  ✓ 行业发生重大危机 → 别人恐惧时你贪婪
  ✓ 竞争对手犯了重大错误 → 窗口期有限
  ✓ 出现了新的技术/政策/需求拐点 → 先发优势
  ✓ 你积累了足够6个月的"安全垫" → 出的起手

  ✗ 只是因为等不及了
  ✗ 只是因为看到别人在动
  ✗ 没有安全垫的冒险

出手的方式:
  · 54攻国攻敌: 不是消灭对手，是整合对手的资源
  · 兼并 > 消灭: 把对手的人/资源/客户变成你的
  · 全力以赴: 一旦出手，不留余地，不能在关键时刻犹豫
```

## 核心原则

1. **打100局，不是1局** — 每一局的策略必须为下一局创造更好的条件
2. **让未来选项变多** — 最好的决策是扩大可选空间
3. **在沉默中积累** — 真正的势能是别人看不到的
4. **危机 = 机会** — 长期博弈者喜欢危机，因为它在重新洗牌
5. **向敌人学习** — 敌人比你更了解你的弱点
6. **耐心是最大的武器** — 大多数人输在等不起，不是打不赢
