## ⚠️ 合规红线（先于一切）

```
金融行业有明确的合规边界。以下操作严格排除:

  ❌ 内幕交易 — 利用非公开信息
  ❌ 市场操纵 — 通过虚假交易影响价格
  ❌ 虚假陈述 — 在交易文件中说谎
  ❌ 违背信义义务 — 损害LP/客户利益
  ❌ 商业贿赂 — 回扣、私下利益输送

本Skill的策略仅限于:
  ✅ 基于公开信息的博弈分析
  ✅ 合法谈判策略和条款设计
  ✅ 识别对方策略和心理动机
  ✅ 保护自身合法利益
```

## 核心模型：交易对手的三层信息

```
每个交易对手都有三层信息:

  ┌─────────────────────────────────────┐
  │ Layer 1: 公开立场                    │
  │ "我们的估值预期是X"                  │
  │ "这个条款是标准的"                   │
  │  ← 这是"谈判姿态"，不一定是真的      │
  ├─────────────────────────────────────┤
  │ Layer 2: 真实约束                    │
  │ 他们基金年底到期必须投完             │
  │ 他们LP在催DPI                        │
  │ 他们创始团队有人要离职               │
  │  ← 这才是他们的"真实底线"           │
  ├─────────────────────────────────────┤
  │ Layer 3: 隐藏动机                    │
  │ 他们买你不是因为看好你               │
  │ → 是为了阻止竞争对手买你             │
  │ 他们压你估值不是因为觉得你贵         │
  │ → 是为了在下一轮以这个估值为锚       │
  │  ← 这是他们"没说的真正目的"          │
  └─────────────────────────────────────┘

鬼谷子的工作: 从Layer 1推断Layer 2，并警惕Layer 3的存在。
```

## 六大交易场景 × 鬼谷子策略

### 场景1: 融资谈判（创始人 vs 投资人）

> 核心策略: 32制人行权 · 4如闭如卦 · 60诱敌之诱

```
投资人的常见策略 & 你的应对:

策略A: 制造时间压力
  投资人: "我们term sheet只有一周有效期"
  
  鬼谷子解读(4如闭如卦):
  → 他们在测试你的"可选性"
  → 如果你真的只有一个选择 → 你会慌
  → 如果你有备选 → 时间压力无效
  
  应对:
  "理解。我们也在跟另外两家基金沟通。
   如果你们的时间线确实紧，我们尽量配合。
   但条款质量比速度更重要。"
  → 不拒绝，也不被逼

策略B: 估值锚定
  投资人: "可比公司都是这个倍数"
  
  鬼谷子解读(60诱敌之诱):
  → 他们选了对他们有利的"可比公司"
  → 锚定效应: 先给你一个数字，后面的谈判围绕它转
  
  应对:
  "好，我们一一分析这些可比公司。
   A公司: 行业同，但增速是我们三分之一 → 调整+2x
   B公司: 产品同，但我们毛利率高12% → 调整+1.5x
   C公司: 规模同，但那轮是三年前的倍数 → 调整+1x
   
   调整后倍数是X+4.5。我们在这个基础上谈。"
  → 接受"可比公司"框架，但调整参数

策略C: 条款试探
  投资人: "我们投过很多公司，这些都是标准条款"
  
  鬼谷子解读(48兼弱攻昧):
  → "标准"是他们的标准，不是市场的标准
  → 他们在利用你的"条款无知"
  
  应对:
  "我理解这是你们的惯例。
   让我们逐条过一下——
   这条优先清算权，倍数是多少？
   这条反稀释，是加权平均还是完全棘轮？
   这条董事会席位，观察员权利包括什么？"
  → 证明你做了功课。他们知道你懂→"标准"会变成"可谈"

策略D: 拖延战术
  投资人: "我们内部还在讨论"（三周没消息）
  
  鬼谷子解读:
  → 可能1: 他们真的在内部讨论
  → 可能2: 他们在等你的数据变差（降低估值）
  → 可能3: 他们在同时看你的竞品
  → 可能4: 他们在犹豫，不确定要不要投
  
  应对:
  "理解。不过我们下周会给出一个close的时间线。
   如果到时候你们还没准备好，我们下一轮再聊。"
  → 你设定deadline，而不是等他们的
  → "下一轮再聊"= 暗示你会变得更贵
```

### 场景2: LP募资（GP vs LP）

> 核心策略: 27空中楼阁(合规版) · 67利害相关 · 56以隐为显

```
LP的常见策略 & 你的应对:

策略A: 要求更多信息披露
  LP: "我需要看你们的全部持仓明细"
  
  鬼谷子解读(71潜入核心):
  → LP需要透明度 → 合理
  → 但"全部持仓明细"可能暴露策略核心
  → LP也可能是竞争对手的LP，信息可能泄露
  
  应对:
  "我会提供: 行业分布、集中度、最大持仓占比、
   历史持仓周期、退出案例的完整时间线。
   
   但个别持仓的名称和仓位，在策略保护期内
   我建议约定一个保密协议和信息披露的节奏。"
  → 满足LP的"理解风险"需求
  → 但不满足"偷策略"的可能

策略B: 要求更优惠的条款
  LP: "我们是基石LP，应该给更好的条款"
  
  鬼谷子解读(67利害相关):
  → "基石LP"确实有议价权
  → 但"更好的条款"不能影响其他LP的公平性
  
  应对:
  "作为基石LP，我可以在以下方面优待:
   ① 更低的起投门槛（如果你需要分批出资）
   ② 更多的co-invest机会（优先看跟投项目）
   ③ 季度深度面对面交流（而非仅季度信）
   
   但管理费和Waterfall对所有LP一致。
   这是信义义务的要求，也是长期信誉的基础。"
  → 给"可给的非金钱优待"
  → 守住"不可动的基础结构"

策略C: 跟投条款博弈
  LP: "我们要这个项目50%的跟投额度"
  
  鬼谷子解读:
  → LP想要最好的项目的额外份额
  → 但如果LP挑走了最好的 → GP剩下一般的 → 回报被稀释
  
  应对:
  "跟投权利我们设计为:
   ① 所有LP按出资比例平等享有
   ② 每个项目的跟投上线不超过基金投资额的30%
   ③ 不强制LP跟投，但跟投前需确认（7天内）
   
   这样保证了公平，也给了你们灵活性。"
```

### 场景3: 并购条款（买方 vs 卖方）

> 核心策略: 22飞钳破敌 · 14暗度陈仓 · 43反有所得

```
并购中双方的核心博弈:

买方策略 & 卖方应对:

策略A: 分阶段信息获取
  买方: "先给初步数据，我们判断有没有兴趣"
        → 拿到初步数据
        "数据挺有意思，能给客户明细吗？"
        → 拿到客户明细
        "客户结构不错，能拆一下毛利吗？"
        → 无限循环，但就是不报价
  
  鬼谷子解读(60诱敌之诱):
  → 他们在用"渐进式请求"获取最大信息
  → 但不需要承诺任何东西
  
  卖方应对:
  "我把信息分三层:
   Layer 1 (公开): 行业报告、产品demo → 给所有人
   Layer 2 (NDA后): 财务摘要、客户结构 → 签NDA后给
   Layer 3 (意向书后): 客户明细、合同条款 → 收到非约束意向书后给
   
   这样保护了我们的敏感信息，也让诚意方推进。"
  → 设定信息分层的规则
  → 每一层都有"入场券"

策略B: 最后一刻改条款
  买方: (签约前48小时) "我们又看了一下数据，
        觉得有些风险，需要在价格上反映一下"
  
  鬼谷子解读(22飞钳破敌):
  → 他们已经在你身上投入了时间和资源
  → 他们认为你这时候"不会因为小变化放弃整个交易"
  → 这是"沉没成本锁定"的反向使用
  
  卖方应对:
  "如果签约前48小时改条款，交易暂停48小时。
   我们的原则是: 谈好的事情不反复。
   如果你们有新的顾虑，请具体说明是什么数据
   让你们改变了估值。"
  → 不立刻接受或拒绝
  → 要求"具体化"（很多"最后改条款"是虚张声势）
  → 设定"反复的代价"（暂停48小时）

策略C: 人才锁定 (acqui-hire条款)
  买方: "关键人员必须签3年锁定，否则不交易"
  
  鬼谷子解读:
  → 买方怕"买了公司，人跑了"
  → 3年可能过长，但"关键人员留任"是合理要求
  
  卖方应对:
  "关键人员锁定我们接受，但建议设计为:
   ① 核心3人锁定2年（非3年）
   ② 第二梯队锁定1年
   ③ 在锁定期内，留任奖金每6个月发放一次
      （而非3年一次性）
   ④ 如果买方在锁定期内改变核心人员的
      角色/汇报关系/薪酬结构，锁定自动失效
   
   这样双方都有安全感。"
```

### 场景4: 对赌协议（Valuation Adjustment）

> 核心策略: 13忤合深谋 · 43反有所得 · 67利害相关

```
对赌的本质是"估值分歧的延迟结算"。

买方思维: "你说你能做到X，我不确定，咱们赌一把"
卖方思维: "我确定我能做到X，但我需要你现在给高估值"

鬼谷子分析:

  对赌的核心风险不在一阶（"达不达标"），
  在二阶（"对赌改变了你的行为"）:

  → 签了对赌 → 你开始"为指标而活" 
  → 短期冲业绩 → 透支长期竞争力
  → 你赢了业绩对赌 → 但输了公司长期发展
  → 投资人拿走了"赌赢"的股份 → 你留着一个虚胖的公司

设计对赌的鬼谷子原则:

  原则1: 对赌指标 ≤ 2个
    不能什么都赌。赌收入和利润就够了。
    赌用户数、GMV、市占率... = 给你自己上12道枷锁
  
  原则2: 对赌期 ≤ 实际可见的周期
    你只能合理预测12个月 → 对赌12个月
    不要赌"3年后做到X"（3年后谁说得准？）
    
  原则3: 对赌失败的代价 ≤ 你输得起的
    输了把创始人股份赔光 → 不签
    输了只给投资人额外5-10% → 可以接受
    
  原则4: 对赌中留"不可抗力"和"善意失败"
    "如果因为政策变化/行业系统性危机导致未达标，
     对赌条件另行协商"
    "如果业绩达标率在80%以上，视为部分达标，
     对赌条件按比例调整，而非全部触发"

鬼谷子: "忤合深谋"
→ 一个条款在一个场景中行得通，在另一个场景中不保证
→ 对赌条款要在"牛市"和"熊市"两种环境分别推演
```

### 场景5: 二级市场大宗交易（Block Trade）

> 核心策略: 4如闭如卦 · 57伏间制胜 · 32制人行权

```
大宗交易的核心博弈:

卖方困境: "我想卖5000万股，但如果市场知道我要卖，
          价格会先跌10%，我只拿到90%的价值"
买方困境: "有人急着卖5000万股，我压价压多少合适？
          压太狠对方不卖了，压不够我亏了"

鬼谷子策略（卖方角度）:

  步骤1: 隐藏意图 (4如闭如卦)
    不透露你想卖的规模
    先试探: "如果有一笔3000-8000万股的block，你能接吗？"
    → 范围模糊 → 信息泄露风险低
    
  步骤2: 多路试探 (57伏间制胜)
    同时联系3家不同的交易台询价
    每家都以为自己在竞争 → 报价会更好
    注意: 3家就够了，太多会走漏消息
    
  步骤3: 制造竞争 (32制人行权)
    "另一家报X.XX，你们能不能更好？"
    → 不透露哪一家
    → 让他们互相竞争
    
  步骤4: 分阶段披露
    Layer 1: "卖方信息" → 行业、大致规模
    Layer 2: 收到报价后 → 给更具体的规模
    Layer 3: 选定做市商后 → 给具体执行时间
    → 每一步只给必要的信息

鬼谷子策略（买方角度）:

  步骤1: 判断卖方紧迫度 (71潜入核心)
    什么样的卖方最急着卖？
    → 基金清盘、margin call、被动平仓
    → 如果判断卖方"必须卖"→ 你有更好的报价空间
    → 如果卖方"可卖可不卖"→ 压价空间有限
    
  步骤2: 判断卖方规模 (48兼弱攻昧)
    你接5000万股占你组合多少？
    → 如果< 5% → 你的风险可控 → 可以给更好的价格
    → 如果> 20% → 你也会成为"被压价的人" → 谨慎
```

### 场景6: Co-Investment（联合投资）

> 核心策略: 21散纵连横 · 41招贤攉奇 · 65善用敌人

```
联合投资的鬼谷子逻辑:

  "谁跟谁联合" = 联盟结构
  "为什么跟你联合不跟别人" = 利益一致
  "联盟会不会散" = 稳定性

联合投资的陷阱 & 应对:

  陷阱1: "搭便车"领投方
    领投方做尽调、谈条款、设计架构
    你跟投 → 领投方可能:
    "有坑我不说，反正你亏了跟我没关系"
    
    应对:
    "我跟投的条件: 领投方的尽调报告共享给我，
     我签保密协议。我有独立判断权。"
    → 保留独立判断，不盲从

  陷阱2: 信息不对等
    领投方知道你不知道的信息
    → 他们投了 = 看起来是好信号
    → 但他们投了多少？什么估值？什么条款？
    
    应对:
    "我问三个问题:
     ① 你们的投决会，投反对票的人的理由是什么？
        （听反对声音）
     ② 这个项目的最大风险，在你们内部的评级是什么？
        （问具体风险）
     ③ 上一轮跟这一轮之间，公司发生了什么不好的事？
        （找被隐藏的坏消息）"

  陷阱3: 退出路径冲突
    你跟投了 → 3年后你想退出
    领投方: "再等等，还没到最佳时机"
    → 你被锁住了
    
    应对:
    跟投前约定退出机制:
    "我的退出权利:
     ① 如果领投方退出，我有权按比例退出（Tag-Along）
     ② 如果3年内未发生合格IPO/并购，
        我有权要求公司或领投方按公允价值回购我的股份
     ③ 退出价格=第三方独立估值（不是领投方说了算）"
```

## 工具：交易对手分析框架

在每笔重要交易前，完成这个分析：

```
┌─────────────────────────────────────────────────────────┐
│ 交易对手分析 (鬼谷子五问)                                │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ① 对手的"决策模型"是什么？                              │
│     → 他个人/机构的KPI是什么？                           │
│     → 他这单交易的成功标准是什么？                        │
│     → 他最怕什么？（风险/失败/错失）                      │
│                                                         │
│  ② 对手的"可选性"有多大？                                │
│     → 他有多少个替代选择？                               │
│     → 他的替代选择里，哪一个对你威胁最大？                │
│     → 他的时间压力有多大？（年底到期？LP在催？）          │
│                                                         │
│  ③ 对手的"信息优势"在哪里？                              │
│     → 他知道什么你不知道的？                             │
│     → 他有没有能力验证你提供的信息？                      │
│     → 他有没有在"试探"你的某些信息？                     │
│                                                         │
│  ④ 对手可能有什么"隐藏动机"？                            │
│     → 这单交易对他除了明面上的收益，                     │
│       背后还有什么意义？                                 │
│     → 他有没有"没说的利益"？（如阻止竞品）               │
│                                                         │
│  ⑤ 如果交易不成的后果是什么？（对双方）                   │
│     → 对你: [失去什么]                                  │
│     → 对他: [失去什么]                                  │
│     → 谁的"不成交成本"更高？                            │
│       不成交成本高的一方 → 谈判中更弱                    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 核心原则

1. **理解对手的KPI = 理解他的底牌** — 他的决策标准决定了你的策略
2. **可选性的多少 = 谈判力的强弱** — 永远为"不成"做好准备
3. **信息分层释放** — 每一层信息都要换一个对等的承诺
4. **不在时间压力下做决策** — 如果对方制造时间压力，先问为什么
5. **条款比估值更重要** — 估值定义了这一笔，条款定义了所有后续
6. **让对手也觉得自己赢了** — 交易能执行靠的是"双赢感"，不是白纸黑字
