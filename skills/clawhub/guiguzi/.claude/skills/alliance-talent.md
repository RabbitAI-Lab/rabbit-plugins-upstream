## 五大操作模块

### 模块A: 人才吸引 (41招贤攉奇 · 50下诏求贤 · 20三教九流)

```
吸引人才的三个层次:

层次1: 利益吸引 (基础)
  → 有竞争力的薪酬、股权、资源
  → 对应: 50下诏求贤

层次2: 意义吸引 (中级)
  → 愿景、使命、成长空间、独特体验
  → "跟我们一起做一件别人做不了的事"
  → 对应: 41招贤攉奇 — "结而无隙"

层次3: 关系吸引 (高级)
  → 私下的信任、共同的圈子、不可替代的归属感
  → "你在这里不只是一个角色，你是我们的一部分"
  → 对应: 20三教九流 — 不拘一格

吸引策略矩阵:
┌─────────────────────────────────────────────┐
│ 目标人物类型      核心驱动力      吸引策略   │
├─────────────────────────────────────────────┤
│ 能力型（技术大牛） 挑战+自主权   给最难的问题│
│ 资源型（有人脉）   价值+认可      让他成为枢纽│
│ 成长型（年轻人）   学习+空间      给最快的成长│
│ 稳定型（成熟人才） 安全+尊重      给最重要的信任│
└─────────────────────────────────────────────┘
```

### 模块B: 人心凝聚 (28带兵带心 · 49录功遗过)

```
带兵带心 = 让人"心里愿意"而不仅仅是"不得不":

凝聚四步:
  1. 看见: 让他感觉你真正"看见"了他的贡献
     → 具体的肯定 > 泛泛的表扬
     → "你上次在XX事上的处理，特别是YY那个细节，让我很佩服"

  2. 托付: 把重要的事交给他，而不是自己全做了
     → 信任 = 最好的激励
     → "这件事我只放心交给你"

  3. 兜底: 他犯错的时候，你替他扛
     → 49录功遗过: 记住功劳，忘掉过失
     → 一次被兜底的经历 > 十次被表扬的经历

  4. 格局: 让他看到他在参与一个比自己更大的事业
     → 28带兵带心: "人系其心于己"
     → 心在了，人就不会走
```

### 模块C: 联盟构建 (21散纵连横 · 41招贤攉奇)

```
联盟设计的核心逻辑:

构建自己的联盟:
  三步:
  1. 识别: 谁跟你有共同利益（哪怕只是暂时的）？
  2. 连接: 让他们之间也互相连接（网状 > 星形）
  3. 锁定: 创造共享的沉没成本和未来收益预期

瓦解对方的联盟 (21散纵连横):
  三步:
  1. 找到对方联盟中最"不满意"的那个成员
     问: 谁的利益在这个联盟里被牺牲了？
  2. 给这个成员一个"更好的选择"
     不一定是你直接给 → 可以是让他看到独立行动的好处
  3. 等联盟自然松动
     不要去"硬拆"，让矛盾自己发酵

联盟健康度检查:
  你的每个盟友:
  □ 他知道跟你结盟的好处是什么吗？（必须明确）
  □ 他知道离开联盟的代价是什么吗？（必须清楚）
  □ 他是否有独立于你的外部选择？（如果有，你的位置危险）
  □ 你是否在持续给他提供"不离开的理由"？
```

### 模块D: 对手转化 (65善用敌人 · 18纳叛招降 · 39无百年敌)

```
化敌为用的三种路径:

路径1: 直接转化 (18纳叛招降)
  "勿坚而拒之" — 永远不要拒绝愿意归附的人
  ⚠️ 但要判断: 是真归附还是假归附？

路径2: 间接利用 (65善用敌人)
  不要求对方"归附"，只利用对方内部的矛盾
  → 对手团队里有谁对你的存在"客观上受益"？
  → 利用这一点让他内部产生分歧

路径3: 等待转化 (39无百年敌)
  今天的敌人 = 明天的潜在朋友
  不要断绝关系，保持基本尊重
  环境变了，利益自然重新排列

对手团队人员分类:
  A类: 对你天然有好感 → 培养
  B类: 中立/摇摆 → 争取
  C类: 对你有敌意 → 不主动攻击，等环境变
  D类: 核心对抗者 → 不打正面，找他的内部矛盾
```

### 模块E: 信号投资 (47千金买马 · 31万金间敌)

```
"47千金买马"的现代运作:

核心: 用一个高成本的公开行动，证明你的诚意

应用:
  招聘: 给第一个人远超市场价的待遇
       → 信号: "这个团队重视人才"
       → 后续优秀人才自然被吸引

  合作: 第一个合作条件给出对方"意外"的优厚
       → 信号: "跟我合作你不会吃亏"
       → 这个案例会自己传播

  管理: 公开重奖一个"对团队有价值但不显眼"的行为
       → 信号: "这种行为是被鼓励的"
       → 比发100封邮件更有效

"31万金间敌"的现代边界:
  ⚠️ 原意是用金钱瓦解对手。现代应用严格限制:
  ✅ 合法的: 给更好的人才offer、更有吸引力的合作条件
  ❌ 非法的: 商业贿赂、收买对方人员出卖机密
```

## 核心原则

1. **心在人在** — 利益只能买时间，心才能买忠诚
2. **不让门关** — 永远不拒绝任何愿意靠近的人
3. **敌人是暂时的** — 不把关系做绝，留有余地
4. **网状 > 星形** — 让你的盟友互相连接，而不仅仅跟你连接
5. **信号要贵** — 廉价的承诺没人信，昂贵的行为自己会传播
