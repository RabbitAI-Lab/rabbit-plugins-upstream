## 核心模型：竞争维度的层次

```
Level 5: 定义游戏规则    ← 最高境界：你设定标准
  ↑
Level 4: 创建新维度      ← 蓝海：别人没注意到的战场
  ↑
Level 3: 改变维度组合    ← 跨界：把A行业的方法用到B行业
  ↑
Level 2: 在同一维度上优化 ← 红海：更便宜/更快/更好
  ↑
Level 1: 模仿跟随        ← 最低：被动反应

鬼谷子的核心定位：从Level 2 → Level 4/5
```

## 维度重构六法

### 方法1: 逆位思考 (43反有所得)

> "欲强反剑，欲高反下，欲取反予"

```
所有人都往东走的时候，问: 往西走会怎样？

应用:
  行业都在做高端 → 低端是不是被忽略了？
  行业都在降价 → 涨价并提供不同价值行不行？
  行业都在线上 → 线下体验是不是成了稀缺？

练习:
  列出你行业里"所有人都认为理所当然"的3个做法
  → 如果反着做，会发生什么？
```

### 方法2: 维度拆分 (3各个击破 + 55两力均衡)

> 把"整体竞争"拆分成多个独立维度，在每个维度上重新设计

```
拆分框架:
┌─────────────────────────────────────────────┐
│ 竞争维度          行业标准做法    你的新做法  │
├─────────────────────────────────────────────┤
│ 价格               [           ]  [        ] │
│ 质量               [           ]  [        ] │
│ 速度/交付          [           ]  [        ] │
│ 便利性             [           ]  [        ] │
│ 体验/情感          [           ]  [        ] │
│ 身份认同           [           ]  [        ] │
│ 风险转移           [           ]  [        ] │
│ 生态系统           [           ]  [        ] │
│ [你行业特有维度]   [           ]  [        ] │
└─────────────────────────────────────────────┘

关键问题:
  哪个维度上"行业标准做法"其实是没人真的满意但大家都在忍？
  → 这就是你的突破口
```

### 方法3: 杠杆点 (30四两千斤)

> 找到最小的那个支点，撬动最大的变化

```
杠杆点识别:
  问: 在这个行业里，什么是最稀缺的资源/能力/关系？
  问: 改变哪一个变量，会让整个系统的运作方式不同？
  问: 如果只能做一件事，做什么能产生最大的连锁反应？

  不是"做更多"，是"做更重要的那一件"。
```

### 方法4: 创造新维度 (26无中生有 + 10推陈出新)

> 在现有维度之外，创造一个全新的竞争维度

```
创造新维度的四种路径:

  路径A: "从功能到体验"
    传统维度: 这个产品"能做什么"
    新维度:   这个产品"让我成为什么人"
    案例: Nike → 不只是鞋，是"运动员精神"

  路径B: "从产品到生态"
    传统维度: 单个产品竞争
    新维度:   产品+服务+社区+内容
    案例: Apple → 不只是手机，是生态系统

  路径C: "从交易到关系"
    传统维度: 单次买卖
    新维度:   长期订阅/会员/共创
    案例: Costco → 不只是零售，是会员关系

  路径D: "从实体到信息"
    传统维度: 物理产品
    新维度:   数据/洞察/预测能力
    案例: 特斯拉 → 不只是汽车，是出行数据平台
```

### 方法5: 场景切换 (13忤合深谋 + 12翻手为背)

> 同一个能力，换一个应用场景，就变成了完全不同的竞争

```
场景切换矩阵:
┌──────────────────────────────────────────┐
│              现有场景    新场景          │
├──────────────────────────────────────────┤
│ 现有客户    [稳固]      [最容易扩展]    │
│ 新客户      [自然延伸]  [最大机会/风险] │
└──────────────────────────────────────────┘

  问:
  · 我的核心能力还能用在哪个完全不同的行业？
  · 我的目标客户在什么"非竞争场景"下也有类似需求？
  · 有没有一个被大玩家忽略的"太小不值得做"的细分市场？
```

### 方法6: 多目标优化 (29一石二鸟)

> 一个动作同时解决多个问题，效率碾压单目标竞争者

```
多目标设计:
  你的下一个战略动作，能不能同时:
  □ 增加收入 + 积累数据？
  □ 服务客户 + 建立壁垒？
  □ 提升品牌 + 吸引人才？
  □ 打击对手 + 巩固联盟？

  如果能同时击中2个以上目标 → 这是高杠杆动作
  如果能同时击中3个以上 → 这是战略级的维度转换
```

## 核心原则

1. **不在对手定义的游戏里玩** — 那是他的主场
2. **逆着行业共识想** — 共识往往是最大的盲区
3. **找最小的杠杆点** — 不是做更多，是做对的那一件
4. **一石必须至少二鸟** — 效率 = 多目标同时命中
5. **场景变了，能力不变** — 你最强的能力换个场景可能就是颠覆性武器
