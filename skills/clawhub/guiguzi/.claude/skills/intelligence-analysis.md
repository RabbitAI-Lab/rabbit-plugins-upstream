## 核心模型：情报分析的五个层次

```
Layer 5: 预测 —— 接下来会发生什么？
         ↑              ↖ 11高瞻远瞩
Layer 4: 规律 —— 背后的模式和驱动力是什么？
         ↑              ↖ 5盗尽天机
Layer 3: 关联 —— 不同信息之间有什么联系？
         ↑              ↖ 16视微成巨
Layer 2: 真伪 —— 这个信息是真的吗？有没有被扭曲？
         ↑              ↖ 24间不能人 · 70耳食传谣
Layer 1: 收集 —— 我有什么信息？我缺什么信息？
                        ↖ 61间接观察

致命陷阱(Layer 0): 主观臆断 —— "我觉得是这样就是这样"
                        ↖ 63主观大害 ← 永远不要掉到这里
```

## 分析六步法

### Step 1: 信息清点

> 映射: 61间接观察

```
列出你目前拥有的所有相关信息:

  直接信息（你亲眼看到/一手获取的）:
  ┌────────────────────────────────────┐
  │                                    │
  └────────────────────────────────────┘

  间接信息（别人告诉你的）:
  ┌────────────────────────────────────┐
  │                                    │
  └────────────────────────────────────┘

  假设（你认为但不一定为真）:
  ┌────────────────────────────────────┐
  │                                    │
  └────────────────────────────────────┘

  盲区（你知道自己不知道的）:
  ┌────────────────────────────────────┐
  │                                    │
  └────────────────────────────────────┘
```

### Step 2: 真伪校验

> 映射: 24间不能人 · 63主观大害 · 70耳食传谣

```
对每一条信息问:
─────────────────────────────────────────────

来源三问:
  1. 信息源头是谁？他有没有动机扭曲？
  2. 经过了几个人的传递？（每多一层，失真风险指数级增长）
  3. 有没有独立来源可以交叉验证？

自检三问（63主观大害 → 防止确认偏误）:
  1. 这个信息支持了我的预设吗？→ 如果是，我有没有更严格地检验它？
  2. 有什么信息能反驳我当前的判断？→ 主动去找
  3. 如果我是对立方，我会怎么解读同样的信息？

传闻三问（70耳食传谣）:
  1. 这个信息是不是"大家都这么说"？
  2. 第一个说的人是谁？能追溯吗？
  3. 如果这个信息是错的，谁会受益？
```

### Step 3: 信号提取

> 映射: 16视微成巨

**从噪音中识别信号的关键方法论：**

```
信号识别的六个维度:

  1. 异常值
     "正常模式"之外的数据点
     → 竞品突然改变招聘方向 → 在做什么新业务？
     → 领导突然频繁提到某个词 → 优先级在变

  2. 变化速率
     不是看"是什么"，是看"变化有多快"
     → 缓慢变化: 趋势（可准备）
     → 突然变化: 事件（需响应）
     → 加速度变化: 拐点（最重要）

  3. 沉默信号
     不说的话比说的话更有信息量
     → 财报里没提的指标
     → 对方回避的问题
     → 全员邮件里被省略的部门

  4. 行为 vs 言辞
     永远相信行为 > 言辞
     → 他说"重视创新"但预算都给了传统业务 → 预算才是真相
     → 她说"支持你"但从不主动推进 → 不反对 ≠ 支持

  5. 关联信号
     两个看似无关的信息放在一起
     → A公司裁了X部门 + B公司在招X方向的人 = 人才流动
     → CEO提了3次"降本" + CFO突然离职 = 财务压力 > 表面

  6. 前置信号
     大事发生前一定有前置信号
     → 大规模裁员前: 停止招聘、取消非核心项目、高层密集开会
     → 谈判破裂前: 沟通频率骤降、措辞变正式、中间人消失
```

### Step 4: 模式匹配

> 映射: 23料敌如神

```
这一步是将"信息"变成"判断"的关键:

方法:
  1. 把当前信息模式与已知的"剧本"匹配
     → 这个模式历史上出现过吗？结局是什么？
     → 这个模式在别的行业/场景里意味着什么？

  2. 站在对方的角度推演
     如果我是对方:
     ┌────────────────────────────────────┐
     │ 我的目标是什么？                    │
     │ 我的约束是什么？                    │
     │ 我的信息集是什么？（注意: 对方看到  │
     │   的信息跟你不一样）                │
     │ 在我自己的信息集下，我的最优选择是？ │
     └────────────────────────────────────┘

  3. 找到"最可能的解释"和"最危险的解释"
     → 最可能的: 用奥卡姆剃刀，最少假设的解释
     → 最危险的: 如果这是真的，对我的影响最大
     → 两者都要准备应对
```

### Step 5: 盲区扫描

> 映射: 11高瞻远瞩 · 63主观大害(反向使用)

```
主动寻找"你不知道你不知道"的东西:

盲区扫描清单:
─────────────────────────────────────────────
□ 我有没有问过"跟我想法不同的人"？
□ 我有没有看到"最不利的数据"？
□ 我最近有没有收到过"让我不舒服"的信息？
  （不舒服的信息往往是最有价值的）
□ 如果6个月后回头看，我会后悔今天没关注什么？
□ 我所在的信息环境里，有没有系统性缺失的视角？
  （比如你在公司内部，就天然看不到外部视角）
```

### Step 6: 预判输出

> 映射: 5盗尽天机 · 11高瞻远瞩

```
基于以上分析，给出三层判断:

  第一层: 现状判断（现在是什么情况？）
  ┌────────────────────────────────────┐
  │                                    │
  └────────────────────────────────────┘

  第二层: 趋势判断（正在往哪个方向走？）
  包含: 拐点概率、变化速度、关键变量
  ┌────────────────────────────────────┐
  │                                    │
  └────────────────────────────────────┘

  第三层: 时机判断（什么信号出现时行动？）
  包含: 最佳窗口、最晚底线、先行指标
  ┌────────────────────────────────────┐
  │                                    │
  └────────────────────────────────────┘
```

## 核心原则

1. **信息源 > 信息本身** — 信源的质量决定了信息的质量
2. **行为 > 言辞** — 说出来的话是经过计算的，做出来的事才是真实意图
3. **找反驳证据** — 如果你只找支持自己的证据，你就已经输了
4. **沉默有信息** — 没说的、避开的、被删除的，都是信号
5. **延迟判断** — 拿到新信息后，先不急着下结论，等24小时再看
