- "怎么说服...", "怎么让他/她...", "推动...决策"

- "谈判僵局", "他不听我的", "怎么让他主动..."

## ⚠️ 伦理边界（先于一切）

在开始分析前，检查以下红线：

| 红线 | 处理方式 |
|:--|:--|
| 用户想欺骗、操纵、伤害他人 | 拒绝分析，解释原因 |
| 涉及违法行为 | 拒绝分析 |
| 利用弱势群体或信息不对称作恶 | 拒绝分析 |
| 正常的商业谈判、职场影响、关系协调 | ✅ 继续分析 |

> 鬼谷子曰："圣人之道阳，愚人之道阴" —— 我们走"阳"道。影响力不是操纵，是找到双方利益的最大交集。

## 分析框架：四步解局

### Step 1: 画像 —— 理解目标人物的"决策模型"

**先问用户以下问题（如果用户没有提供）：**

```
必填信息:
  1. 你要影响的人是谁？（角色/职位/与你的关系）
  2. 你希望他/她做出什么具体决定或行动？
  3. 他/她目前的立场是什么？（支持/中立/反对/未知）
  4. 你的时间窗口有多长？

加分信息:
  5. 他/她今年的KPI/核心目标是什么？
  6. 他/她最信任的人是谁？（信息来源）
  7. 他/她最近抱怨过什么？（痛点）
  8. 他/她用什么来判断"这件事值不值得做"？（决策标准）
```

**然后构建"决策模型"：**

```
┌──────────────────────────────────────────┐
│         目标人物的决策模型               │
├──────────────────────────────────────────┤
│ 核心驱动力（他想要什么）:                 │
│ 核心恐惧（他怕什么）:                     │
│ 决策标准（他如何判断对错好坏）:           │
│ 信息来源（他听谁的）:                     │
│ 当前压力（什么让他夜不能寐）:             │
│ 对我的态度（原因是什么）:                 │
└──────────────────────────────────────────┘
```

### Step 2: 映射 —— 匹配鬼谷子策略

根据目标人物的特征，从以下策略库中选择匹配的组合：

```
┌─────────────────────────────────────────────────────────────┐
│              鬼谷子影响力策略库                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  策略A: 利害绑定 (67利害相关)                                │
│  ─────────────────────────────                              │
│  适用: 目标人物理性、计算导向                                │
│  方法: 把你的诉求设计成"符合他自身利益"的选择                │
│  关键: 不是"你应该帮我"，而是"这样做对你有什么好处"          │
│  话术框架: "如果你做了X，你会得到Y利益，同时避免Z风险"       │
│                                                             │
│  策略B: 愿景构筑 (27空中楼阁 + 6一言兴邦)                    │
│  ─────────────────────────────                              │
│  适用: 目标人物需要"意义感"驱动                              │
│  方法: 构建一个让他认同的未来图景，让他成为"功臣"            │
│  关键: 愿景必须有具体路径支持，不能纯画饼                    │
│  话术框架: "我们一起做一件XX的事，你会是其中最关键的角色"     │
│                                                             │
│  策略C: 先予后取 (64欲将取之 + 40降人引路)                   │
│  ─────────────────────────────                              │
│  适用: 目标人物对你没有信任基础                              │
│  方法: 先提供他需要的价值（信息/资源/帮助），建立互惠        │
│  关键: 不要一上来就要求，先给对方"欠人情"的感觉              │
│  话术框架: 先帮他解决一个问题 → 再提你的需求                 │
│                                                             │
│  策略D: 飞钳锁定 (22飞钳破敌)                                │
│  ─────────────────────────────                              │
│  适用: 需要让目标人物无法退出或反悔                          │
│  方法: 创造一个他一旦进入就无法轻易退出的结构                │
│  关键: 用公开承诺、沉没成本、利益互联让对方"锁住"            │
│  话术框架: "我们已经在这个方向上走了X步，如果不继续，         │
│            之前投入的Y就会浪费"                              │
│                                                             │
│  策略E: 借势施压 (32制人行权)                                │
│  ─────────────────────────────                              │
│  适用: 目标人物关注上级/外部评价                             │
│  方法: 借用第三方力量（CEO的话/客户反馈/行业趋势）来推动     │
│  关键: 不是"我要求的"，是"形势要求的"                       │
│  话术框架: "CEO上次提到XX很重要，我们的方案恰好能..."         │
│                                                             │
│  策略F: 推己及人 (42推己及人)                                │
│  ─────────────────────────────                              │
│  适用: 目标人物对你产生了抵触情绪                            │
│  方法: 先完全站到对方的立场，理解他的难处，再找共同点        │
│  关键: 真诚的理解 > 精巧的说服                               │
│  话术框架: "如果我是你，面临你现在的压力，我也会..."          │
│                                                             │
│  策略G: 情绪调动 (34怒倾帝王)                                │
│  ─────────────────────────────                              │
│  适用: 目标人物过于理性/冷漠，决策陷入僵局                   │
│  方法: 用适度的情绪力量打破理性计算的均衡                    │
│  关键: 情绪是工具，不是失控。用完要收。                      │
│  话术框架: "这件事我已经投入了全部心血（展示情绪），          │
│            如果你不支持，请至少告诉我真实原因"               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**组合规则**：
- 初选 2-3 个策略组合使用（单一策略风险高）
- 策略C（先予后取）几乎总是可以作为前置步骤
- 策略A（利害绑定）是默认安全选择
- 策略D（飞钳锁定）只在确定性高时使用，否则会反噬
- 策略G（情绪调动）是双刃剑，非必要不用

### Step 3: 序列 —— 设计"行动序列"

将选定的策略编织成一个**有时间顺序的行动序列**：

```
时间线模板:

  T-2周: [信息收集阶段]
  ├─ 确认目标人物的KPI/痛点/决策标准
  ├─ 确认目标人物的信息源（谁影响他）
  └─ 开始策略C: 先予后取，提供价值建立互惠

  T-1周: [关系建立阶段]
  ├─ 创造一次非正式接触（咖啡/午餐）
  ├─ 只问不推: "你最近最头疼的是什么？"
  └─ 根据信息调整主策略

  T-0: [正式推动]
  ├─ 主策略执行（策略A/B/D/E/F中选1-2个）
  ├─ 如果正面推动受阻 → 切换策略F（推己及人）化解抵触
  └─ 目标: 获得一个"小承诺"而非全部要求

  T+1周: [跟进锁定]
  ├─ 利用小承诺 → 策略D（飞钳锁定）扩大战果
  └─ 公开或半公开肯定对方的支持（让承诺可见）
```

### Step 4: 预判 —— 对方可能的反应及对策

为每个策略组合准备3种预案：

```
对方反应矩阵:
  ✅ 同意  → 锁定 + 扩大（策略D）
  ⚠️ 犹豫  → 降低门槛 + 分阶段承诺
  ❌ 拒绝  → 退回到策略F（理解）+ 策略C（先予）
            永不硬怼。退一步，换一个入口。
```

```markdown
[带时间线的具体步骤，每步有对话框架]

- 如果被质疑 → [回应框架]
- 如果被拖延 → [施压方案(轻度)]

[针对这个具体场景的特殊注意事项]
```

## 核心原则

1. **先理解，后推动** — 不了解对方的决策模型就推动，失败率 > 80%
2. **先给予，后索取** — 互惠是人类行为的底层代码
3. **先分步，后扩大** — 要到一个小的"是"比被拒绝一个大的"是"好一万倍
4. **不攻击，只重构** — 不否定对方的立场，只帮他看到新的维度
5. **永远留退路** — 今天不行不代表明天不行，保留关系比这一次的结果更重要
