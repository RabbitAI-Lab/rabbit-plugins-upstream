## 核心模型：鬼谷子谈判五力

将谈判中的所有战术归纳为五种力量的动态调配：

```
                    信息力
                    (知道什么)
                      │
        ┌─────────────┼─────────────┐
        │             │             │
     时机力          框架力        替代力
   (什么时候动)    (怎么定义)    (有什么退路)
        │             │             │
        └─────────────┼─────────────┘
                      │
                   情绪力
                 (氛围控制)
```

| 力量 | 对应术数 | 核心问题 |
|:--|:--|:--|
| **信息力** | 4如闭如卦 · 14暗度陈仓 · 57伏间制胜 · 71潜入核心 | 我知道什么对方不知道的？对方知道什么我不知道的？ |
| **时机力** | 19应敌而动 · 46以静制动 | 现在是最佳时机吗？是推进还是等待？ |
| **框架力** | 60诱敌之诱 | 谁定义了谈判的"规则"和"标准"？ |
| **替代力** | 66孤掌难鸣 · 48兼弱攻昧 | 如果谈不成，我有什么退路？对方呢？ |
| **情绪力** | (源自34怒倾帝王) | 谁在控制谈判的气氛和节奏？ |

## 谈判三阶段战术

### 阶段一：开局 —— 争夺定义权

> 映射: 4如闭如卦 · 60诱敌之诱

**核心原则: 永远不要让对方定义谈判框架。**

```
开局战术清单:
─────────────────────────────────────────────

战术1: 框架重置
  对方："你们的报价太高了"
  普通回应: "我们可以降一点" ← 接受了对方的框架
  战术回应: "在讨论价格之前，我们先对齐一下——
           你对比的是哪个标准？是只看单价还是看总拥有成本？
           我们的交付周期比别人短40%，这部分的节省你计算了吗？"
  → 重新定义比较标准

战术2: 锚定效应反向使用
  如果对方先出价 → 不要还价，先质疑锚点本身
  "这个数字是基于什么算出来的？"
  → 让对方的"锚"失去正当性，再出你自己的锚

战术3: 隐藏底牌 (4如闭如卦)
  不被问到时: 不主动暴露你的任何约束条件
  被直接问到时: 不直接回答，用反问转移
  "我们的弹性取决于整体合作框架，你那边预算范围是多少？"

战术4: 软性试探 (60诱敌之诱)
  用一个"假设性问题"试探对方底线
  "假设我们能满足交付时间，价格方面你的空间是？"
  "假设我们把付款周期缩短，服务范围能扩大吗？"
  → "假设式提问"降低对方的防御

战术5: 议程控制 (19应敌而动)
  先谈容易达成共识的点 → 积累"是"的惯性
  再谈核心争议点     → 在合作氛围中谈分歧
  最后谈细节条款     → 大局已定后微调
```

### 阶段二：博弈 —— 力量的动态交换

> 映射: 14暗度陈仓 · 48兼弱攻昧 · 71潜入核心

```
博弈战术清单:
─────────────────────────────────────────────

战术6: 让步的艺术 (14暗度陈仓)
  每个让步必须有对应交换:
  "如果你能X，我就考虑Y"
  "X"是你让步的条件，"Y"是你让步的内容
  
  让步节奏: 大 → 中 → 小 → 极小 → 零
  递减的让步幅度发出信号: "接近底线了"
  
  永远不要: 第一次报价就是最优报价
  永远不要: 连续让步两次而对方没有任何回馈

战术7: 弱点击破 (48兼弱攻昧)
  找到对方最急于解决的那个问题→放大它的紧迫性
  找到对方最怕的那个后果→把它跟不合作关联
  "我理解你想再考虑，但下个月新的行业标准就生效了，
   按现在的方案我们都能抢占先机"
  
  ⚠️ 警告: 这不是威胁。是客观指出不作为的后果。

战术8: 制造竞争 (66孤掌难鸣 → 反用)
  如果对方知道你只有他一个选择→你就没有选择权
  战术: 暗示有其他方案在同时进行
  "我们也在跟另一个团队讨论合作模式，但我更倾向跟你们做"
  
  ⚠️ 必须有真实基础，不能纯编造

战术9: 内部信息获取 (71潜入核心)
  在谈判前、中场休息时，从对方团队的不同成员获取信息
  不同级别的人会透露不同级别的信息
  执行层可能知道更多真实约束条件

战术10: 沉默的力量 (46以静制动)
  对方出价后 → 沉默5秒
  对方让步后 → 不立刻接受，点一下头，记个笔记，然后提下一个
  对方情绪激动时 → 完全安静，等对方说完

  沉默 = 让对方填补信息真空
  很多不必要的让步都是在沉默中被"逼"出来的
```

### 阶段三：收网与脱困

> 映射: 57伏间制胜 · 62养虎为患(警示) · 46以静制动

```
收网战术:
─────────────────────────────────────────────

战术11: 最后推动
  "我们已经在5个问题上达成一致，只剩下这1个了。
   如果这个也解决，我们就可以推进了。"
  → 利用"已完成的工作"作为沉没成本推动最后一点

战术12: 脱困三式
  当谈判陷入僵局:
  
  A. 升级维度:
     "我们先不谈这个细节，回到整体目标上来看..."
     → 从具体争议上升到共同目标
  
  B. 换人换场:
     "要不要我们各自回去跟团队商量一下，明天再碰？"
     → 打破当下的对峙气氛
  
  C. 条件式退出:
     "目前的条件我们没法往前走。但如果后续你在X和Y上
      有变化，随时找我。保持沟通。"
     → 退而不败，保留未来的门

战术13: 警惕胜利后的陷阱 (62养虎为患 → 警示)
  谈判赢了的瞬间是最危险的时候:
  · 不要公开羞辱对方
  · 不要追加额外的要求
  · 给对方一个"体面的台阶"
  · 确认对方"也觉得自己赢了某个方面"
  
  让对方也觉得赢了 → 协议才能长久执行
```

## 实时对战模式

当用户处于"正在进行"的谈判中，切换到实时模式：

```
实时模式流程:
  1. 用户告知当前情况: "对方说了XXX"
  2. 快速诊断: 对方在用什么策略？想达到什么目的？
  3. 给出2-3个即时回应选项:
     ├─ 安全回应（保持关系优先）
     ├─ 平衡回应（得失兼顾）
     └─ 激进回应（短期利益优先）
  4. 提示: 选哪个取决于你对"长期关系 vs 短期利益"的权重判断
```

## 核心原则

1. **永不第一个出价** — 先出价的人失去信息优势
2. **永不接受第一个报价** — 即使它好得离谱
3. **永不免费让步** — 每个让步换一个回馈
4. **永不情绪化回应** — 对方的情绪是策略，你的冷静是武器
5. **永远给对方面子** — 协议能执行不是因为条款好，是因为双方都舒服
