# 投资认知博弈 (Investment Cognition)

## 元数据
- **编号**: S8（金融专属）
- **优先级**: P0（金融场景 · 高频使用 · 最大痛点）
- **覆盖术数**: 16视微成巨 · 24间不能人 · 46以静制动 · 63主观大害(核心) · 70耳食传谣(核心) · 59强而避之 · 44退避观战 · 62养虎为患(核心警示) · 5盗尽天机 · 11高瞻远瞩 · 35万年大计 · 69以敌为师 · 9天地无常
- **定位**: 投资决策中最大的敌人不是市场，是你自己的认知偏误。鬼谷子是你脑内的"第二层监控系统"。
- **核心JTBD**: "在市场噪音中保持认知清醒，不被贪婪/恐惧/从众/确认偏误劫持判断力"

- "大家都在买/卖", "这次不一样", "我不能再错过"
- "回撤太大了", "赚太多了要不要止盈"
- "这个信息是真的吗", "我会不会太乐观了"
- "@invest-psych" 或 "/investment-psychology"

## 核心模型：投资决策的双层认知

```
Layer 1: 你的分析脑（"我觉得应该..."）
         ↓ 63主观大害 → 分析脑充满了偏误
         ↓              只看到支持自己的证据
         ↓
Layer 2: 你的监控脑（鬼谷子层——"等一下，你确定吗？"）
         ↓ 24间不能人 → 识别信息的真伪
         ↓ 70耳食传谣 → 识别"所有人都在说"的危险
         ↓ 62养虎为患 → 识别"赢太多了不想停"的危险
         ↓
决策输出: 经过双层校验的投资决策
```

## 七大认知偏误 × 鬼谷子对抗策略

### 偏误1: 确认偏误（只看支持自己的证据）

> 63主观大害: "合而不结者，阳亲而阴疏"

```
症状: 买了一只股票后，只看得多的分析，拉黑看空的人
      看到利空消息自动解释为"市场误解了"
      账户在亏但告诉自己"基本面没问题，还会涨回来"

鬼谷子对抗:
  □ 每周强制找一个看空你持仓的人的观点，认真读
  □ 问自己: "如果我的判断是错的，最可能的原因是什么？"
  □ 把你的投资逻辑写下来，找一个不认同的朋友逐条反驳
  □ 如果不能在3分钟内解释清楚"空头的核心逻辑"，
    说明你对这只股票的了解不完整

鬼谷子: "事有不合者，圣人不为谋也"
→ 圣人不跟"不合逻辑的事"较劲。如果你的判断每次都被市场打脸，
  不是市场错了，是你错了。
```

### 偏误2: 从众效应（看到大家都在买就想买）

> 70耳食传谣: "金门空物，众口能烁之，则以众口有私曲故也"

```
症状: "比特币3万的时候我没买，现在10万了"
      "同事都在讨论这个，我是不是也该买点"
      "所有研报都在推荐这个板块"

鬼谷子对抗:
  □ 问自己: "如果没人讨论这个资产，我还会买吗？"
    → 如果答案是不 → 你是在跟风，不是在投资

  □ 追踪"叙事生命周期"（见下文工具）
    → 当理发师都在讨论股票时 = 共识期 = 危险

  □ 区分三种"大家都这么说":
    A. 大家都这么说 + 有独立证据 = 可以关注
    B. 大家都这么说 + 没有独立证据 = 信息级联
    C. 大家都这么说 + 没人敢反驳 = 泡沫信号

鬼谷子: "众口能烁之" = 众口一词可以熔化金属
→ 当所有人的观点一致时，这个观点本身就是最大的风险
→ 不是因为大家都错，是因为"所有人都已经买了"
   → 还有谁没买？没有新买家 = 价格没法再涨
```

### 偏误3: 损失厌恶（亏了不肯卖）

> 59强而避之 · 44退避观战

```
症状: "已经跌了30%了，现在卖太亏了"
      "我成本是X，至少回到X我才卖"
      "只要我不卖，就不算亏"

鬼谷子对抗:
  □ 残酷问题: "如果今天你手上没有这只股票，
    只有等额的现金，你会用现金买它吗？"
    → 如果答案是"不会"→ 你已经在错误的位置了
    → 成本跟你未来的决策没有关系（沉没成本谬误）

  □ 设定"买入理由失效"止损线，而不是"价格止损"
    → 你买它的3条理由，任何一条不再成立→卖出
    → 跟价格无关，跟逻辑有关

  □ "这股跌了30%但我相信基本面" → 加仓的信号
    vs "这股跌了30%我已经慌了" → 砍仓的信号
    区分: 你的"相信"是基于数据，还是基于"不愿承认错误"

鬼谷子: "强而避之"
→ 不要在市场强势碾压你的时候硬扛
→ 承认错误，退出战斗，保存实力，下次再打
```

### 偏误4: 过度自信（赢了几次就觉得自己是天才）

> 62养虎为患: "故胜者斗其攻势，苟进而不知退"

```
症状: "我已经连续对了5次，这次也一定对"
      "我比市场更聪明，别人还没看到"
      "这次赚了就该加大仓位"

鬼谷子对抗:
  □ 记录你的决策，事后复盘:
    你赚的哪些是"能力"，哪些是"运气"？
    → 牛市里赚的钱，大概率是运气
    → 如果分不清，全部当成运气

  □ 仓位失控 = 认知失控
    连续对3次之后 → 强制性降低仓位到平时的70%
    → "惩罚"自己的连续正确
    → 如果第4次还是对的 → 少赚一点没关系
    → 如果第4次是错的 → 你保护了自己

  □ 问自己: "这个决策，如果错了，我能不能承受？"
    → "能" = 继续
    → "能但会很痛" = 降低仓位
    → "不能" = 不开仓

鬼谷子: "苟进而不知退，弱者闻衷其负，见其伤，则强大力倍，死而是也"
→ 只知道进攻不知道撤退的人，最终会激发对方的强力反弹而死
→ 市场就是那个"对方"
```

### 偏误5: 恐慌（市场暴跌时想全部清仓）

> 46以静制动: "天下之牝，常以静胜牝"

```
症状: "卖卖卖！全部清仓！"
      "这次真的完了，跟以前不一样"
      "我先出来躲一躲，等稳了再进来"

鬼谷子对抗:
  □ 暴跌时不做任何决策。24小时冷静期。
    → 恐慌中的决策，事后看90%是错的
    → 除非你设了止损线被触发（那是规则，不是情绪）

  □ 区分"市场暴跌"和"你的持仓基本面恶化"
    → 市场暴跌 + 持仓基本面没变 = 不要动（或是加仓机会）
    → 市场暴跌 + 持仓基本面恶化 = 该卖就卖
    → 关键是: 暴跌让你恐慌了吗？如果是 → 先不动

  □ 回看历史上最大的10次暴跌
    → 每次当时都有人说"这次不一样"
    → 每次后来看都是机会（前提: 你买的不是垃圾）

鬼谷子: "以静为下"
→ 安静地待在低位，让纷扰在上面飘过
→ 在市场噪音最大的时候，最冷静的人赢
```

### 偏误6: 贪婪（涨了还想涨更多）

> 62养虎为患（同偏误4，但方向相反）

```
症状: "再涨10%我就卖"→涨了10%→
      "再涨10%就卖"→无限循环
      "这次不一样，可以更高"

鬼谷子对抗:
  □ 买入时设定"卖出条件"，写下来
    → 不是"涨到X卖出"（价格目标）
    → 是"估值达到X"或"增长逻辑出现Y变化"时卖出
    → 条件触发 → 执行。不触发 → 持有。

  □ 分批止盈:
    涨30% → 卖20%
    涨50% → 再卖30%
    涨100% → 剩下的50%当"免费彩票"
    → 你永远不会卖在最高点
    → 但你也不会因为"等最高点"而错过整个上涨

  □ "卖飞了"的痛苦 vs "没卖亏回去"的痛苦
    → 前者是"少赚了"（遗憾）
    → 后者是"该赚的没了"（自责）
    → 自责的杀伤力是遗憾的10倍
    → 选择承受遗憾
```

### 偏误7: 锚定效应（被某个数字锁住了）

> 12翻手为背 · 43反有所得

```
症状: "这股之前到过100，现在60太便宜了"
      "我之前在这个价格买过，再等回到那个价格"
      "这个估值倍数跟历史均值比..."

鬼谷子对抗:
  □ 问: "如果历史没有发生过，只看现在，这个价格合理吗？"
    → "它到过100"跟"它现在值多少钱"没有因果关系

  □ 反向锚定:
    投资者被"历史最高价"锚定 → 你觉得60便宜
    你试试被"历史最低价"锚定 → 你觉得60贵不贵？
    → 两边都试一下，找到"不被任何锚影响"的独立判断

  □ 估值不是"跟过去比"，是"跟未来比"
    → "PE 30倍，历史均值20，太贵了" ← 锚定
    → "如果未来三年利润翻倍，30倍PE = PEG 0.5，便宜" ← 独立判断
```

```

  ✅ 暴露你的认知偏误
```

## 核心原则

1. **不跟"所有人都说"的事** — 当共识形成，超额收益消失
2. **恐慌时不做决策** — 24小时冷静是所有投资决策的前提
3. **赢的时候降仓位** — 这反人性，这是最有效的风控
4. **卖出的理由 ≠ 亏了多少** — 沉没成本不是决策依据
5. **主动找反对观点** — 如果你找不到，说明你在逃避
6. **"长期主义"≠"不止损"** — 基本面变了就要走
