# 鬼谷子七十二术 · 现代博弈认知工具

> 将古老博弈智慧编译为可执行的现代认知工具。不做"知识库"，做"认知维度的健身房"。
> 
> **商业 + 金融双轨体系**，9个Skill互联互通。

## 核心公理

| 公理 | 内容 |
|:--|:--|
| **信息不对称定理** | 博弈胜负取决于双方信息差的方向和大小 |
| **可选性定理** | 拥有更多选择权的一方最终胜出 |
| **间接路径定理** | 直接对抗消耗最大，间接路径效率最高 |

## 设计铁律（所有Skill必须遵守）

1. **场景锚定** — 每个skill绑定一个高频具体场景
2. **输出可执行** — 输出必须是"下一步做什么"
3. **认知升维** — 必须让用户看到之前没看到的维度
4. **反常识性** — 必须包含逆直觉但正确的洞察
5. **伦理边界** — 内置伦理检查，拒绝恶意使用
