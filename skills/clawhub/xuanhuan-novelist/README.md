## ✨ 为什么用这个？

通用小说 Skill 写玄幻总是差点意思——修炼体系混乱、爽点节奏不对、战斗描写千篇一律。这个 Skill 专为解决这些痛点而生：

- **修炼体系设计** — 境界划分、金手指设计、力量边界，告别体系崩坏
- **爽点节奏编排** — 每 3-5 章小爽点，每 10-15 章大爽点，打脸→升级→获宝→越级波浪递进
- **战斗描写规范** — 6 种战斗类型模板，境界压制感、越级艰难感、策略博弈感
- **初稿文风学习** — 自动分析已有章节的文风和设定，续写风格一致
- **可配置规则** — 13 条创作规则可自定义，跳过即使用推荐配置
- **自动校验修复** — 完成后自动检查字数和质量，不合格自动重写

## 🎯 核心特性详解

### 四大玄幻支柱

| 支柱 | 说明 | 参考指南 |
|------|------|---------|
| **修炼体系** | 清晰的境界划分、金手指设计、力量边界 | `cultivation-system.md` |
| **世界观架构** | 地图递进、势力体系、宗门组织 | `xuanhuan-worldbuilding.md` |
| **爽点节奏** | 打脸→升级→获宝→越级→势力扩张波浪递进 | `xuanhuan-plot-patterns.md` |
| **战斗描写** | 境界压制感、越级艰难感、策略博弈感 | `battle-writing.md` |

### 初稿分析与文风学习

当你已有小说初稿时，Skill 会自动检测并提供分析：

- **文风分析** — 句式结构、词汇偏好、修辞手法、段落节奏、对话风格、描写密度、情感表达、叙述视角等 8 大维度
- **设定提取** — 自动提取修炼体系、世界观、势力、人物、剧情脉络
- **结构化建档** — 生成文风档案、设定档案、人物档案、剧情档案

支持三种使用场景：
1. **续写已有小说** — 分析初稿 → 跳过已覆盖的问答 → 直接续写
2. **学习文风写新作品** — 提取文风指纹 → 正常问答新设定 → 用你的风格写新故事
3. **补写/扩展初稿** — 分析初稿 → 指定补写范围 → 风格一致地补写

### 可配置创作规则

13 条创作规则分为 3 组，支持推荐/宽松/严格/关闭/自定义方案：

| 组别 | 包含规则 | 默认方案 |
|------|---------|---------|
| **A组：内容量** | 字数范围、对话比例、张力波峰、无冲突上限、意外转折 | 3000-5000字、30%对话、2个波峰 |
| **B组：风格** | 强开头、文风禁区、对话潜台词 | 全部开启 |
| **C组：体系** | 金手指出现时机/限制、境界碾压、爽点/钩子 | 前3章、≥2种限制、全部开启 |

> **跳过即默认**：直接说"跳过"或"下一步"即可使用全部推荐配置，无需逐项选择。

### 三大黄金法则

| 法则 | 说明 |
|------|------|
| **展示而非讲述** | 修炼突破要写出身体感受，不要说"他变强了" |
| **爽点驱动剧情** | 每章必须有爽点或爽点铺垫 |
| **悬念承上启下** | 每章结尾必须留下钩子 |

## 🛠️ 安装

将 `xuanhuan-novelist/` 目录放入你使用的 Agent 的 Skills 目录即可。例如：

```
# Qoder
.qoder/skills/xuanhuan-novelist/

# Claude Code
.claude/skills/xuanhuan-novelist/

# 其他 Agent 框架
skills/xuanhuan-novelist/
```

或通过对应 Agent 的技能管理界面安装。

### 环境依赖

本 Skill 内置 Python 脚本（`check_chapter_wordcount.py`），用于章节字数检查。请确保运行环境满足：

- **Python 3.6+**（使用 `pathlib`、f-string 等标准库特性，无需安装第三方包）

**验证命令**（Agent 安装 Skill 后应自动执行，用户也可手动检查）：

```bash
python --version
# 或
python3 --version
```

如果输出版本号 ≥ 3.6 即满足要求。如果未安装 Python：
- **Windows**：`winget install Python.Python.3.12` 或从 [python.org](https://www.python.org/downloads/) 下载
- **macOS**：`brew install python3`
- **Linux**：`sudo apt install python3` 或对应包管理器

> **无 Python 时的降级行为**：如果环境中没有 Python，字数检查步骤会被跳过，Skill 仍能正常创作，仅无法自动校验章节字数。
