# 玄幻世界观构建指南

世界观是玄幻小说的舞台。好的世界观不是百科词条，而是角色行动的背景板——读者通过角色的经历来认识这个世界。

---

## 第一部分：地图架构

### 地图递进模型

玄幻小说的地图应该像剥洋葱一样层层展开，每次换地图都是一次视野的跃升。

**标准递进层级**：

| 层级 | 规模 | 对应境界 | 特征 |
|------|------|---------|------|
| 起始地 | 小镇/小城/小宗门 | 最低境界 | 封闭、资源匮乏、规则简单 |
| 区域地图 | 王国/中型宗门 | 第二层级 | 势力交错、竞争加剧 |
| 大陆地图 | 帝国/大型宗门联盟 | 第三层级 | 群雄争霸、大势力博弈 |
| 超级地图 | 大陆群/海域 | 第四层级 | 跨域战争、上古秘密浮现 |
| 终极地图 | 位面/神界 | 最高层级 | 天地法则、终极对决 |

### 地图设计原则

#### 1. 每张地图必须有三要素

- **独特的地理特征**：不要每张地图都是"城+宗门+山脉+秘境"的复制品
- **独特的资源特产**：某些宝物/材料只在特定地图产出
- **独特的势力格局**：每张地图的权力结构应该不同

#### 2. 地图间的关联

- 低级地图和高级地图之间要有**通道**（传送阵、古路、飞升）
- 低级地图的某些线索应该**指向**高级地图（上古遗迹、神秘传承的出处）
- 高级地图的存在应该在低级地图中有所**暗示**（传说中的上界、神秘强者的来历）

#### 3. 初始地图的设计

起始地是整个故事的起点，必须满足：

- **封闭性**：有明确的限制阻止主角过早离开（结界/修为限制/地理隔绝）
- **自给自足**：有完整的小社会（家族/宗门/小镇的人际关系网）
- **暗藏线索**：至少一条通往更大世界的线索（上古传送阵、神秘老人的来历、家族隐藏的秘密）
- **压迫感**：主角在起始地受到压制或限制，产生"我要出去"的动力

### 地图切换时机

切换地图需要满足以下条件中的至少两个：

1. 主角修为突破到新的层级
2. 当前地图的最大威胁/冲突已经解决
3. 获得了指向新地图的线索或通行手段
4. 当前地图已经无法提供足够的成长资源

**切换时的情感处理**：
- 不要冷酷切换，要有告别、回忆、不舍
- 留下一些未解的线头（后续可以回来收）
- 新地图的第一印象要震撼（视野跃升感）

## 第二部分：势力体系

### 势力层级模型

| 层级 | 规模 | 代表 | 特征 |
|------|------|------|------|
| 家族 | 数十到数百人 | 主角的出身 | 血缘关系、内部争斗、资源有限 |
| 小型宗门 | 数百人 | 起步阶段的舞台 | 外门/内门之分、资源竞争 |
| 中型宗门 | 数千到上万人 | 成长阶段 | 派系之争、附属势力、对外扩张 |
| 大型宗门/王国 | 数万到数十万 | 争霸阶段 | 长老会、圣地级别的底蕴 |
| 圣地/帝国 | 百万+ | 巅峰阶段 | 传承万年、掌控规则 |
| 超脱势力 | 不限 | 终极阶段 | 隐世家族、上古传承、天道意志 |

### 宗门内部架构

一个完整的宗门应该包含：

```
掌门/宗主（最高决策者）
├── 长老会（多位长老，各管一摊）
│   ├── 大长老（地位仅次于掌门）
│   ├── 执法长老（门规执行）
│   ├── 丹堂长老（炼丹）
│   ├── 器堂长老（炼器）
│   └── 外务长老（对外事务）
├── 内门弟子（核心力量）
│   ├── 亲传弟子（长老/掌门的弟子）
│   ├── 内门精英
│   └── 普通内门弟子
├── 外门弟子（底层）
│   ├── 外门排名前十
│   └── 普通外门弟子
└── 杂役/仆从（最底层）
```

**冲突来源**：
- 内门外门之争（资源分配不公）
- 长老派系之争（权力博弈）
- 继承人之争（掌门位置）
- 宗门间竞争（弟子争锋/资源争夺/秘境争夺）

### 中立势力

除了正邪两大阵营外，应设计一些中立势力丰富世界：

| 势力类型 | 功能 | 冲突潜力 |
|---------|------|---------|
| 拍卖行 | 宝物交易、信息交流 | 竞价冲突、宝物争夺 |
| 佣兵团/散修联盟 | 任务系统、冒险组队 | 利益冲突、背叛 |
| 炼器师/药师公会 | 专业技能服务 | 拉拢、垄断 |
| 情报组织 | 消息买卖 | 信息泄露、被利用 |
| 上古遗迹守卫 | 秘境准入 | 争夺探索权 |

## 第三部分：社会结构

### 修为决定地位

玄幻世界的基本法则：**强者为尊**。

| 修为层级 | 社会地位 | 特权 |
|---------|---------|------|
| 最低境界 | 普通修士 | 无特权，受规则约束 |
| 第二层级 | 有名有姓 | 可在城池中飞行、进入高级区域 |
| 第三层级 | 一方豪强 | 开辟洞府、收徒建派 |
| 第四层级 | 天下知名 | 不受普通规则约束 |
| 最高层级 | 超然物外 | 一言可定天下大势 |

### 经济体系

- **通用货币**：灵石（下品/中品/上品/极品，1:100 换算）
- **资源等级**：对应修为等级，高阶资源低阶修士用不了
- **交易场所**：坊市（小型）、拍卖行（大型）、黑市（违禁品）
- **稀缺性**：越是高级资源越稀缺，争夺越激烈

### 规则与秩序

- **城池规则**：禁止飞行（低阶修士）、禁止动手（有执法队）
- **宗门门规**：不得欺师灭祖、不得泄露宗门秘密、定期任务考核
- **强者特权**：高阶修士在低阶区域可以无视规则（这就是冲突来源）
- **潜规则**：弱肉强食、杀人夺宝在野外无人管

## 第四部分：世界观展示规范

### 核心原则：通过行动展示，不写百科词条

**错误示范**（百科式）：
> 天玄大陆分为东西南北四大域，每个域有数十个王国，修炼等级分为凝气、筑基、金丹、元婴、化神五个大境界，灵石是这个世界的通用货币……

**正确示范**（行动式）：
> 林尘从怀里摸出仅有的三块下品灵石，在坊市的摊位前犹豫了半天。三块灵石，在落霞城连一顿像样的灵食都买不起。据说内门弟子每月光是修炼资源就有五十块灵石，而外门弟子辛苦完成一个月的宗门任务，报酬只有可怜的两块。

### 信息释放节奏

世界观信息必须**分批释放**，每次只展示当前地图和当前境界相关的设定：

| 章节范围 | 释放的世界观信息 |
|---------|----------------|
| 第1-3章 | 起始地的基本情况、最低层级的修炼常识 |
| 第4-10章 | 起始地的势力格局、第二层级的存在 |
| 第11-20章 | 区域地图的概况、宗门体系、更高层次的修炼知识 |
| 第21章+ | 更大的世界、更复杂的势力、上古秘辛 |

### 通过冲突展示世界观

让角色**遭遇**世界规则的压迫或便利，比任何解释都有效：

- 主角因为修为低被城门守卫拦住 → 读者自然知道修为决定通行权
- 主角在拍卖会上被人用高价碾压 → 读者自然理解经济体系
- 主角在宗门里被内门弟子欺负 → 读者自然感受等级制度

## 第五部分：世界观检查清单

### 地图检查

- [ ] 地图层级递进清晰（至少 3 层）
- [ ] 每张地图有独特的地理特征和资源
- [ ] 地图间有关联和通道
- [ ] 起始地有封闭性和暗藏线索
- [ ] 地图切换有情感处理（不是冷酷跳转）

### 势力检查

- [ ] 势力层级分明（至少 3 个层级）
- [ ] 宗门内部架构完整
- [ ] 有中立势力丰富世界
- [ ] 势力间有明确的冲突模式

### 社会结构检查

- [ ] 修为与社会地位对应
- [ ] 有经济体系（货币/交易/稀缺性）
- [ ] 有规则和秩序（明规则和潜规则）

### 展示方式检查

- [ ] 世界观信息通过行动展示，非百科词条
- [ ] 信息分批释放，不一次性倾倒
- [ ] 通过冲突展示世界规则
- [ ] 每次只展示当前地图相关的设定
