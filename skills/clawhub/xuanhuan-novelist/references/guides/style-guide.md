# 文风分析与模仿指南

文风是一个作者最独特的指纹。本指南定义如何从已有文本中提取文风特征，并在后续创作中精确模仿。

---

## 第一部分：文风分析维度

### 1. 句式结构分析

#### 分析要点

| 维度 | 具体指标 | 分析方法 |
|------|---------|---------|
| 平均句长 | 每句平均字数 | 随机抽取 5 段，统计每句字数，求平均 |
| 长短句比例 | 短句（≤15字）vs 长句（≥40字）的占比 | 统计连续 3 章的数据 |
| 句式偏好 | 是否偏好特定句式 | 找出重复出现的句式模式 |
| 特殊句式 | 倒装/省略/排比/对偶的使用频率 | 标记每种特殊句式的出现次数 |

#### 示例分析

**长句铺排型作者**：
> 自那闪耀着神光的眸子猛然射出两道几近透明的光芒，几乎洞穿整个由字符和纹理形成的小型曜日。

特征：单句 40+ 字，多层修饰嵌套，节奏舒缓。

**短句节奏型作者**：
> 他侧身。刀锋擦着鼻尖过去。左脚蹬地，身体旋转，刀尖刺出。

特征：单句 ≤15 字，动作分解，节奏紧凑。

### 2. 词汇偏好分析

#### 分析要点

- **高频词汇**：统计出现频率最高的 30 个非通用词汇（排除"的""了""是"等功能词）
- **特色用词**：作者独创的术语、古语词汇、方言词汇
- **形容词密度**：每百字中形容词的数量
- **动词风格**：偏好精确动词（"攥""掐""蹭"）还是通用动词（"拿""抓""碰"）
- **副词使用**：是否频繁使用副词修饰（"猛然""骤然""缓缓""渐渐"）

#### 示例

**古雅词汇型**：
- 高频词：源力、源法、源魂、神念、罡风、鸿蒙
- 特征：自创修炼术语体系，使用古风词汇

**口语化型**：
- 高频词：哥们、搞、整、弄、得嘞
- 特征：对话口语化，叙述偏白话

### 3. 修辞手法分析

| 修辞类型 | 分析指标 |
|---------|---------|
| 比喻 | 频率、喻体偏好（自然物/人造物/抽象概念） |
| 拟人 | 频率、拟人对象（自然现象/器物/力量） |
| 排比 | 频率、排比项数、排比内容（动作/描写/情感） |
| 对偶 | 频率、对偶工整度 |
| 夸张 | 频率、夸张程度（适度/极端） |
| 通感 | 频率、感官交叉方式 |

### 4. 段落节奏分析

- **段落平均长度**：每段平均句数
- **段落变化模式**：是否有明显的长段-短段交替
- **场景切换方式**：空行分隔/时间标记/空间标记/直接切换
- **独段使用**：是否经常使用单句成段来强调

### 5. 对话风格分析

| 维度 | 分析方法 |
|------|---------|
| 对话占比 | 统计连续 3 章中对话文字占总文字的比例 |
| 对话长度 | 单次发言的平均字数（短句对白 vs 长篇独白） |
| 对话标签 | "说道"频率、是否使用动作替代标签、是否有创意标签 |
| 角色差异度 | 不同角色的说话方式是否有明显区别 |
| 潜台词密度 | 对话中"话里有话"的比例 |
| 敬语/称谓 | 是否有系统的称谓体系（前辈/道友/阁下等） |

### 6. 描写密度分析

统计每千字中各类描写的占比：

| 描写类型 | 统计方法 |
|---------|---------|
| 环境描写 | 每千字中环境描写段落占比 |
| 动作描写 | 每千字中动作描写段落占比 |
| 心理描写 | 每千字中内心独白/心理活动占比 |
| 感官描写 | 视觉/听觉/触觉/嗅觉/味觉各占比 |

### 7. 情感表达分析

- **直接表达**：直接写出情感词汇（"他愤怒""她伤心"）的频率
- **间接表达**：通过动作/表情/环境映射情感的频率
- **克制程度**：情感高潮时的描写篇幅（浓墨重彩 vs 轻描淡写）
- **情感词汇偏好**：常用哪些情感词汇

## 第二部分：文风指纹生成

### 生成规则

从以上分析中，提取最具辨识度的特征，生成 **文风指纹文档**：

1. **每个维度**提取 3-5 个最突出的特征
2. **每个特征**必须附带 1-2 个原文示例
3. **文风指纹总长度**控制在 300-500 字
4. **新增"文风禁区"**：列出用户风格中**不存在或极少使用**的写法，后续创作中必须避免

### 文风指纹模板

```markdown
## 文风指纹

### 句式特征
- [特征描述]。示例："[原文句子]"
- [特征描述]。示例："[原文句子]"

### 词汇风格
- 高频特色词：[词汇列表]
- [词汇特征描述]

### 修辞偏好
- [修辞特征描述]。示例："[原文段落]"

### 节奏模式
- [节奏特征描述]

### 对话风格
- [对话特征描述]。示例："[原文对话]"
- 称谓体系：[称谓列表]

### 描写偏好
- [描写特征描述]

### 情感表达
- [情感表达特征描述]

### 开篇习惯
- [开篇模式描述]

### 结尾习惯
- [结尾模式描述]

### 文风禁区
- [不应出现的写法1]
- [不应出现的写法2]
- [不应出现的写法3]
```

## 第三部分：文风模仿原则

### 核心原则

1. **形似不如神似**：不要机械复制句式，要抓住文风的"感觉"
2. **优先匹配高频特征**：文风指纹中排在前面的特征最重要
3. **禁区比模仿更重要**：避免文风禁区比模仿某个特征更能保持一致性
4. **允许微调**：在保持核心文风的前提下，可以根据场景类型（战斗/修炼/对话）微调节奏
5. **术语一致性**：修炼术语、地名、人名必须与设定档案完全一致，这是文风一致的基础

### 模仿优先级

| 优先级 | 维度 | 说明 |
|--------|------|------|
| 1 | 术语一致性 | 修炼术语、地名、人名必须精确 |
| 2 | 句式结构 | 句长、句式偏好是最明显的文风标志 |
| 3 | 词汇风格 | 高频词和特色用词决定文本的"味道" |
| 4 | 对话风格 | 称谓体系和对话方式直接影响阅读感受 |
| 5 | 描写密度 | 描写的详略程度影响阅读节奏 |
| 6 | 情感表达 | 直接/间接的偏好 |
| 7 | 修辞手法 | 锦上添花的维度 |

### 文风偏移检测

每写完一章后，对照文风指纹进行自查：

1. 随机抽取 3 段，与初稿中的 3 段并列阅读，感受是否"像同一个人写的"
2. 检查文风禁区中的写法是否出现
3. 检查术语是否与设定档案一致
4. 检查句式长度分布是否与初稿接近

如果发现明显偏移，在润色步骤中修正。

## 第四部分：常见问题

### 问题：初稿风格本身不够统一

**解决**：
- 如果初稿跨越多卷/长时间创作，作者风格可能演变
- 以**最近的章节**为主要参照（风格最成熟、最稳定）
- 早期章节仅作设定参照，不作为文风主要参照

### 问题：初稿中有明显的 AI 痕迹

**解决**：
- 在分析时标注哪些段落疑似 AI 生成（四字成语堆砌、过度修饰、句式单一）
- 文风指纹中排除这些段落
- 文风禁区中加入"避免 AI 常见写法"

### 问题：续写时需要引入新的设定/角色

**解决**：
- 新设定/角色的命名风格必须与已有体系一致
- 新角色的说话方式必须在文风指纹的框架内设计
- 新地点/新法宝的描述方式要符合已有的描写密度
