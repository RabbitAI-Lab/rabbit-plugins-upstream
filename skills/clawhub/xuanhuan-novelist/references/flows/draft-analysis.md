# 初稿分析与文风学习

> 本阶段在 Phase 0 检测到用户有已有初稿时触发，或由用户主动提供初稿文件/目录时触发。
> 目标：学习用户的写作风格，提取已有的世界设定、人物信息和剧情脉络，生成结构化的参考档案，确保后续续写与初稿风格一致、设定连贯。

---

## 触发条件

以下任一条件满足即进入本阶段：

1. **Phase 0 自动检测**：用户工作目录下存在小说章节文件（`.txt`/`.md`），且数量 ≥ 3 章
2. **用户主动提供**：用户明确说"我有初稿""帮我分析现有章节""续写我的小说"
3. **用户指向目录**：用户提供了一个包含已有章节的目录路径

---

## 分析流程概览

```
Step 1: 初稿采集与预处理
Step 2: 文风分析（语言风格、叙事习惯、修辞偏好）
Step 3: 设定提取（修炼体系、世界观、势力、地理）
Step 4: 人物提取（角色清单、关系网络、性格特征、修炼境界）
Step 5: 剧情提取（已发生事件、未解悬念、人物弧线）
Step 6: 生成结构化档案
Step 7: 用户确认与修正
```

---

## Step 1: 初稿采集与预处理

### 1.1 定位初稿文件

> **跳过条件**：如果 Phase 0 初稿检测已经确定了初稿位置（用户选择了"是的，分析初稿后续写"或"分析初稿文风，但写新故事"），直接使用 Phase 0 已确定的文件路径，跳过下方询问。

如果初稿位置尚未确定，使用 `AskUserQuestion` 确认：

```
Question: 检测到您的工作目录下有已有章节，请确认初稿位置：
Options:
- 自动扫描工作目录下的所有章节文件
- 我来指定具体的文件或目录路径
- 跳过初稿分析，从零开始创作
```

### 1.2 文件排序与采样

- 按文件名中的章节编号排序
- **全文阅读**（如果总字数 ≤ 20万字）：逐章阅读所有章节
- **采样阅读**（如果总字数 > 20万字）：
  - 必读：第 1 章（开篇风格）、最后 3 章（当前进度和悬念）
  - 采样：每 5 章取 1 章（中间风格校验）
  - 随机抽取 3 章中的战斗场景（如有）
  - 随机抽取 2 章中的对话密集段落

### 1.3 预处理

- 统计每章字数，生成字数分布
- 标记每章的大致类型（修炼章/战斗章/剧情章/过渡章）
- 识别章首/章尾的钩子和悬念

---

## Step 2: 文风分析

> 详见 [style-guide.md](../guides/style-guide.md) 获取完整的文风分析维度。

### 2.1 语言层分析

逐一分析以下维度，每个维度提取 **3-5 个具体特征** + **原文示例**：

| 维度 | 分析要点 |
|------|---------|
| **句式结构** | 平均句长、长短句比例、是否偏好长句铺排或短句节奏、特殊句式（倒装、省略、排比） |
| **词汇偏好** | 高频词汇、特色用词（古语/口语/自创术语）、形容词密度、动词风格 |
| **修辞手法** | 常用修辞（比喻/拟人/排比/对偶）、修辞密度、修辞风格偏好 |
| **段落节奏** | 段落平均长度、段落变化模式、场景切换方式 |
| **对话风格** | 对话占比、对话标签用法、角色说话差异、潜台词密度 |
| **叙述视角** | 视角切换频率、内心独白比例、全知/限制程度 |
| **描写密度** | 环境描写篇幅、动作描写细致度、感官描写偏好（视觉/听觉/触觉/嗅觉） |
| **情感表达** | 直接表达 vs 间接表达、情感词汇偏好、克制度 |

### 2.2 叙事层分析

| 维度 | 分析要点 |
|------|---------|
| **开篇模式** | 如何开始每一章（对话/场景/行动/回忆/悬念） |
| **结尾模式** | 如何结束每一章（钩子类型、悬念强度、过渡方式） |
| **节奏模式** | 全章的节奏曲线（张弛规律、高潮分布） |
| **信息释放** | 世界观/设定信息的释放方式（叙述/对话/行动中展示） |
| **时间处理** | 时间跳跃方式、回忆插入方式、并行叙事处理 |

### 2.3 生成文风指纹

将分析结果浓缩为一段 **300-500 字的文风指纹描述**，作为后续写作的核心参照。文风指纹格式：

```markdown
## 文风指纹

**句式特征**：[描述] + 原文示例 2-3 句
**词汇风格**：[描述] + 高频词/特色词列表
**修辞偏好**：[描述] + 原文示例 1-2 个
**节奏模式**：[描述]
**对话风格**：[描述] + 原文示例 1-2 段
**描写偏好**：[描述]
**情感表达**：[描述]
**开篇习惯**：[描述]
**结尾习惯**：[描述]

### 文风禁区（用户风格中不存在或极少使用的）
- [列出不符合用户风格的写法，后续写作中避免]
```

## Step 4: 人物提取

### 4.1 角色清单

为每个出场过的角色生成档案：

```markdown
## 角色：[姓名]

- **首次出场**：第X章
- **身份**：[身份/职业]
- **境界**：[修炼境界]
- **外貌特征**：[原文中的外貌描写]
- **性格特征**：[从行为和对话中推断]
- **说话风格**：[原文对话示例 2-3 句]
- **关键行为**：[列出影响剧情的关键行为]
- **关系网络**：[与其他角色的关系]
- **当前状态**：[最新一章中的状态]
- **未解线索**：[关于此角色的未解悬念]
```

### 4.2 关系图谱

用文字描述角色之间的关系网络：
- 敌对/同盟/师徒/亲族/恋人
- 关系的变化轨迹（从A到B）

## Step 5: 剧情提取

### 5.1 事件时间线

按章节顺序列出所有重大事件：

```markdown
| 章节 | 事件 | 影响 | 未解悬念 |
|------|------|------|---------|
| 第1章 | | | |
```

### 5.2 悬念追踪

列出所有已埋下但尚未解答的悬念/伏笔：

```markdown
| 悬念 | 埋设章节 | 当前状态 | 重要性 |
|------|---------|---------|--------|
| [悬念描述] | 第X章 | 未解/部分揭示/已解 | 高/中/低 |
```

### 5.3 人物弧线

追踪主要角色的成长轨迹：

```markdown
### [角色名] 的成长弧线
- 第X章：[初始状态]
- 第Y章：[关键转变]
- 第Z章：[当前状态]
- 预期方向：[基于已有信息的推测]
```

## Step 6: 生成结构化档案

将以上所有分析结果整合为以下文件：

### 输出文件

1. **`03-文风档案.md`**：文风指纹 + 写作规范（参照 [style-profile-template.md](../guides/style-profile-template.md) 模板）
2. **`04-设定档案.md`**：修炼体系 + 世界观 + 势力（从 Step 3 整合）
3. **`05-人物档案.md`**：角色清单 + 关系网络（从 Step 4 整合）
4. **`06-剧情档案.md`**：事件时间线 + 悬念追踪 + 人物弧线（从 Step 5 整合）

所有文件存入项目目录。

## Step 7: 用户确认与修正

向用户展示分析摘要：

```markdown
## 初稿分析完成

📊 **初稿规模**：[X] 章，约 [X] 万字
✍️ **文风特征**：[一句话概括核心文风]
⚔️ **修炼体系**：已提取 [X] 个境界、[X] 个术语
🌍 **世界观**：已提取 [X] 个地点、[X] 个势力
👤 **角色**：已提取 [X] 个角色
📖 **剧情**：已提取 [X] 个事件、[X] 条未解悬念

### 已生成文件
- `03-文风档案.md` — 写作风格参照
- `04-设定档案.md` — 世界设定参照
- `05-人物档案.md` — 角色信息参照
- `06-剧情档案.md` — 剧情脉络参照
```

使用 `AskUserQuestion` 请求确认：

```
Question: 请检查以上分析结果，是否准确？
Options:
- 准确，直接基于这些信息续写
- 大体准确，但我需要修正一些细节（指出需要修改的部分）
- 不够准确，请重新分析（指出哪些地方有误）
- 跳过分析，我自己提供设定
```

用户确认后：
- 将分析档案作为后续创作的**强制参照**
- Phase 3 创作每章时必须读取这些档案
- 进入正常创作流程（Phase 1 问答可跳过已有信息的部分）

---

## 与正常流程的衔接

### 场景一：续写已有小说

```
初稿分析 → 用户确认 → 跳过 Phase 1 中已覆盖的问题
→ Phase 2 中基于已有档案生成续写大纲 → Phase 3 续写
```

### 场景二：基于初稿风格写新作品

```
初稿分析 → 提取文风指纹 → 进入 Phase 1 正常问答（新故事设定）
→ Phase 3 创作时应用文风指纹
```

### 场景三：补充/扩展初稿

```
初稿分析 → 用户指定需要补充的部分（如"帮我补写第15-20章"）
→ 基于已有档案直接生成大纲 → 创作
```

---

## 文风一致性检查

Phase 3 创作每章时，除了原有的检查清单，还需增加文风一致性检查：

1. **句式检查**：是否符合用户偏好的句式结构
2. **词汇检查**：是否使用了用户常用的词汇风格，是否避免了文风禁区
3. **对话检查**：角色说话方式是否与初稿中的风格一致
4. **描写检查**：描写密度和感官偏好是否与初稿匹配
5. **术语检查**：修炼术语、地名、人名是否与设定档案一致
6. **节奏检查**：全章节奏曲线是否与初稿的节奏模式一致
