## Q1：玄幻子类型与创意概要

使用 `AskUserQuestion` 工具询问：

```
Question: 你想创作什么类型的玄幻小说？
Options:
- 废柴流（主角起点极低，获金手指后一路逆袭打脸）
- 强者归来流（前世至尊重生/陨落，凭经验重回巅峰）
- 系统流（穿越绑定系统，靠系统升级开挂）
- 天才流（主角本就是天才，重点是巅峰之路）
- 宗门流（以宗门发展为核心，兼顾个人修炼和势力扩张）
- 自由描述（我有自己的想法）
- 🎲 随机生成
```

> **偏好集成**：如果 `favoriteSubGenres` 中有匹配项，将对应选项排在最前面并标记⭐。

**记录**：`子类型 = [用户选择]`
**记录**：`创意概要 = [用户在"自由描述"中已包含的信息]`
