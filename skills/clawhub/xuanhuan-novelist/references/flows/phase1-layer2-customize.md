## Q4：世界观架构与修炼体系

```
Question A: 故事的世界观架构？
Options:
- 单一大陆（一块大陆，多个国家和宗门）
- 多大陆/多海域（多个大陆板块，海域分隔）
- 位面体系（下位面→上位面→神界，层级递进）
- 小世界嵌入大世界（秘境、洞天福地、独立空间）
- 自由描述（我已有详细设定）
- 🎲 随机生成
```

**智能推荐**：
- 子类型 = 强者归来流/巅峰之路 → 推荐"位面体系"
- 子类型 = 宗门流 → 推荐"多大陆/多海域"

**追问 — 修炼体系核心设计**（必答）：
```
Question B: 修炼体系的核心设计方向？
Options:
- 经典修仙体系（练气→筑基→金丹→元婴→化神...）
- 斗气/源力体系（斗者→斗师→大斗师→斗灵...）
- 体修为主（淬体→开脉→凝骨→换血→金身...）
- 混合体系（修炼+炼器+阵法+丹药多线并行）
- 我来设计自己的体系（请简述方向）
- 🎲 随机生成
```

> **偏好集成**：如果 `cultivationPreference` 有值，标记对应选项为⭐。

**记录**：`世界观架构 = [用户选择]`，`修炼体系方向 = [用户选择]`

## Q9：创作规则定制（可选）

> 以下规则控制创作时的约束强度。每组有推荐方案，你可以直接接受推荐，也可以选择"自定义"逐项调整。
> **直接说"跳过"或"下一步"即可使用全部默认推荐配置，无需逐项选择。**

```
Question: 创作规则的约束强度？（分3组，每组可选推荐/宽松/严格/关闭/自定义）
Options:
- 全部使用推荐方案（推荐，适合大多数情况）⭐
- 逐组选择（A组内容量 / B组风格 / C组体系）
- 全部关闭（不强制任何规则，完全自由创作）
```

如果用户选择"逐组选择"，依次展示以下三组：

### A组：内容量规则
```
Question: 每章内容的量化要求？
Options:
- 推荐方案（3000-5000字、30%对话、2个张力波峰、500字无冲突上限、1个意外转折）⭐
- 宽松方案（2000-6000字、20%对话、1个张力波峰、不强制无冲突上限、不强制意外转折）
- 严格方案（3000-5000字、40%对话、3个张力波峰、300字无冲突上限、1个意外转折）
- 全部关闭（不强制量化指标，自由创作）
- 自定义（逐项调整）
```

### B组：风格与结构规则
```
Question: 风格和结构方面的约束？
Options:
- 推荐方案（强开头、文风禁区检查、对话潜台词要求）⭐
- 全部关闭（不做风格硬性约束）
- 自定义（逐项调整）
```

### C组：体系与爽点规则
```
Question: 修炼体系和爽点节奏的约束？
Options:
- 推荐方案（金手指前3章+≥2种限制、境界碾压铁律、每章爽点+钩子）⭐
- 宽松方案（金手指前5章+≥1种限制、碾压可灵活处理、爽点和钩子不强制）
- 全部关闭（不强制体系规则）
- 自定义（逐项调整）
```

**选择"自定义"时的追问**（仅展示用户选择自定义的那组）：

A组自定义：
1. 每章字数范围？ → 2000-4000 / 3000-5000（默认）/ 4000-6000 / 自由输入
2. 对话比例下限？ → 关闭 / 20% / 30%（默认）/ 40%
3. 张力波峰数量？ → 关闭 / 1个 / 2个（默认）/ 3个
4. 无冲突字数上限？ → 关闭 / 500字（默认）/ 800字 / 1000字
5. 意外转折要求？ → 关闭 / 开启（默认）

B组自定义：
1. 强开头技巧？ → 关闭 / 开启（默认）
2. 文风禁区检查？ → 关闭 / 开启（默认）
3. 对话潜台词要求？ → 关闭 / 开启（默认）

C组自定义：
1. 金手指早期出现？ → 关闭 / 前3章（默认）/ 前5章
2. 金手指限制数量？ → 关闭 / 1种 / 2种（默认）/ 3种
3. 境界碾压铁律？ → 关闭 / 开启（默认）
4. 每章爽点/铺垫？ → 关闭 / 开启（默认）
5. 每章结尾钩子？ → 关闭 / 开启（默认）

**记录**：`规则配置 = [A组选择] [B组选择] [C组选择]`

> **跳过处理**：如果用户说"跳过""下一步""不用选了"等，自动将三组均设为"推荐方案"，不追问。
