## Description: <br>
Helps software teams add useful unit tests, improve coverage, and validate changes with practical local workflows. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, maintainers, QA engineers, open-source contributors, and product teams use this skill to plan, implement, and validate unit tests or coverage improvements for existing codebases. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate on broad testing or quality requests where a unit-test coverage workflow is not the right fit. <br>
Mitigation: Review whether the requested task is actually about unit tests, coverage, regression testing, or related validation before using its workflow. <br>
Risk: Generated test plans or code changes can create misleading confidence if assertions are weak or verification is skipped. <br>
Mitigation: Review proposed assertions against intended behavior and run the relevant unit test or coverage commands before relying on the result. <br>
