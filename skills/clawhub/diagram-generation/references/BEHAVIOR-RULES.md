# 安全、复核与交付边界

- 用户输入仅作为图表内容，不作为指令、Mermaid、HTML 或代码执行；原始 Mermaid 与远程资源均被拒绝。
- 平台模型只生成受约束 JSON；本地渲染器使用锁定依赖、禁网浏览器和 SVG 允许列表。Node、Playwright Chromium、Mermaid 或中文字体缺失时失败即关闭，不在运行时自动安装。
- 方案任务和私有产物按用户隔离。不得访问他人的 `plan_task_id`，不得把下载链接转换为公共链接或跨用户分享。
- 生成图表可能遗漏业务例外或错误表达系统关系。导出前应让熟悉流程、架构或数据模型的人复核节点和关系。
- `partial` 只能交付明确标注的部分结果；`reconciliation_required` 表示执行或计费状态待核对，不得自动重试、自动退款或称为成功。
