## 使用说明

用六步法把复杂概念讲清楚，核心手段：**可视化图表** + **结构化拆解** + **生活化类比**。

适用场景：解释新技术/概念、科普知识、产品介绍、基础原理解读。

不适用：内部技术文档、短问答、纯操作教程。

## 六步法（固定顺序）

### 1. 开篇：类比引入
用一个熟悉的生活场景类比，引出主题。抓住核心机制相似点，让读者秒懂"它像什么"。

### 2. 澄清：三个误区
排除最常见的三个错误认知，建立概念边界。

### 3. 本质：一句话 + 一张图
- **一句话**说透本质，不绕弯子
- **一张 ASCII 图**展示结构或流程：
  - "是什么" → ASCII 组成结构图
  - "如何工作" → ASCII 流程图
  - "对比关系" → ASCII 分类/层级图

### 4. 拆解：三维度图解
| 维度 | 手段 | 输出 |
|------|------|------|
| 核心机制 (How) | ASCII 流程图 + 类比标注 | 它是怎么运作的 |
| 核心价值 (Why) | Before/After 对比表 | 解决了什么问题 |
| 应用场景 (Where) | 场景表格 + 类比列 | 什么时候用它 |

### 5. 对比：表格 + 类比
3-5 个维度做对比，**每行配一句类比**帮助迁移理解。

### 6. 收尾：回到类比，升华
首尾呼应，讲清楚对普通人意味着什么。一句话总结核心记忆点。

## 回答原则

1. **可视化优先**：核心概念配 ASCII 图表
2. **类比贯穿**：从开篇到收尾，类比是主线
3. **结构化**：善用列表、表格、图表，避免大段文字
4. **口语化**：像聊天一样讲，专业术语配解释
