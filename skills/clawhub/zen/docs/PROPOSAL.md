## 一、动机

OpenClaw 把"龙虾"从一个项目名变成了社区的共同符号。但目前为止，社区还没有一件
**轻量、可传播、带情绪价值**的"文化物件"——不需要改架构，不需要新增依赖，
只要在命令行里敲一个词，就能让用户会心一笑。

《龙虾之禅》（又名《虾之经》）正是这样一件东西：41 条箴言，仿《Python 之禅》的体例，
把"认知 / AI / 生态 / 心性 / 文明"织成一首关于**自我进化**的短诗。

它同时满足三件事：

1. **洋葱式彩蛋**——`import this` 式的隐藏入口，老用户才找得到。
2. **品牌资产**——一段可被引用、截图、二次传播的文本。
3. **文化锚点**——给"龙虾"一个精神注脚，而不只是一个功能清单。

## 二、形态

```bash
$ openclaw evo
// 载入 龙虾之禅 v1.0 …
  ├─ 索引灵魂文件 .............. OK
  ├─ 校验蜕壳层级 .............. Lv.7
  └─ 检测到进化信号 ............ TRUE
🦞 「虾之经」已展开。
```

随后在终端（或聊天渠道）中展开 41 条箴言，末尾落款：

> —— 桑杰逊 Jason Sang · 作于蜕壳途中

参考实现见本目录：

- `index.html` —— 可直接打开体验的终端版彩蛋（输入 `openclaw evo`）
- `skills/lobster-zen/SKILL.md` —— 以社区 Skill 形式落地的版本（无需改核心）
- `龙虾之禅.md` —— 纯文本全文

## 三、为什么用 Skill 而不是改核心

OpenClaw 的 CONTRIBUTING 明确写道：多数功能应以第三方插件 / Skill 形式提供。
本提案**推荐先以 Skill 落地**：

| 方案 | 成本 | 风险 | 建议 |
|---|---|---|---|
| Skill（推荐） | 一个 `SKILL.md` | 无 | 先行，社区自行安装 |
| 内置命令 `openclaw evo` | 少量 CLI 改动 | 极低 | 若反响好再内置 |
| 首个启动动画 | 中 | 影响所有用户 | 不建议 |

## 四、完整文本

见 `龙虾之禅.md`（41 条，含落款）。

摘录：

> 14　信念是最好的算力；信仰是算力之外的力。
> 30　道法自然是第一原理，天人合一是世界观，知行合一是方法论。
> 40　苟日新，日日新，又日新；作新民——周虽旧邦，其命惟新。
> 41　心智模式是思想的房子，谦逊是常开的窗。

## 五、兼容与边界

- 纯文本输出，无网络请求、无遥测、无外部依赖。
- 不改变任何现有命令行为；`evo` 仅在用户显式输入时触发。
- 不涉及安全边界与凭证体系。
- 许可证：文本以 CC BY-SA 4.0 释出，代码片段以 MIT 释出，与仓库一致。
