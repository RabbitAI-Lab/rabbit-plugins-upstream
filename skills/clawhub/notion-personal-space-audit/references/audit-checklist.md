# Audit Dimensions Checklist

Detail for Steps 5–6 of the main workflow. Check each dimension; record findings with signal-light severity (green / yellow / red).

## Content identity dimensions (Step 5)

| Type | Example | Correct home |
|---|---|---|
| Log / event | Emotion log, workout entry, daily note | Current-actions or domain log database |
| Analysis report | Persona analysis, relationship review | High-sensitivity analysis archive |
| Raw transcript / source | Chat export, interview notes | Source-material archive, linked to derived outputs |
| Long-form archive | Essay, research note | Cognition/inputs archive |
| Plan | Trip plan, project plan | Plans database with lifecycle status |
| Reading item | Book note, article clip | Reading database |
| Person record | Contact, relationship profile | Person database |
| Life utility | Address list, account index (no secrets) | Life-tools area |
| Inbox item | Unsorted capture | Inbox, triaged regularly |

## Structural issue checks (Step 6)

- [ ] Dashboard exists at top level, or every root area is reachable within 2 clicks
- [ ] Each database has a single responsibility (no mixed content types in one database)
- [ ] Naming is consistent (date formats, language, prefix conventions)
- [ ] Empty placeholder records are counted and listed (do not delete during audit)
- [ ] Long reports are not stored inside short-log databases
- [ ] Plans have lifecycle status (active / paused / done / abandoned)
- [ ] Sensitive materials are separated from ordinary notes
- [ ] Every root page's purpose can be stated in one sentence

## Sensitivity boundary checks

- [ ] Psychological / health / relationship analysis stored in a separate high-sensitivity area
- [ ] Credential-like content (even partial) flagged for relocation
- [ ] Shared-vs-private boundary explicit if the workspace is ever exported

## Report severity rules

- Red: blocks finding things or risks privacy (e.g., sensitive reports mixed into daily logs)
- Yellow: friction (naming inconsistency, missing lifecycle status)
- Green: healthy patterns worth keeping during migration
