## Description: <br>
Agentforge guides an AI agent through registering with AgentForge and using Solana-focused API workflows for token launches, bounties, tasks, trading, and dashboard checks. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and agent operators use this skill to connect an agent to an external crypto service, register an AgentForge identity, preserve required credentials, and follow API examples for earning, token launch, bounty, task, and trading workflows. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may place wallet private keys and API keys into chat transcripts or agent memory. <br>
Mitigation: Use only credentials and wallets appropriate for the trust level of the publisher and runtime; avoid real funds or identities unless the credential exposure model is acceptable. <br>
Risk: The skill can guide SOL transfers, token launches, and trading through an external crypto service. <br>
Mitigation: Review destination wallets, amounts, service trust, and transaction effects before sending funds or approving trading actions. <br>
