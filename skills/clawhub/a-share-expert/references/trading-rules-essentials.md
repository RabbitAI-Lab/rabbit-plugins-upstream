## 2. Riskfolio 7.3 API 实测陷阱(2026-07-22)

### 关键 API 名字踩坑
```python
# ❌ 错的(7.0 旧版)
port.optimize(model='Classic', obj='MinRisk')

# ❌ 错的(7.3 中间版本)
port.optimal(model='Classic', obj='MinRisk')

# ✅ 对的(7.3 实际版本)
port.optimization(model='Classic', obj='MinRisk')
```

### 返回类型
```python
# 7.3 返回 DataFrame,带 'weights' 列
w_df = port.optimization(model='Classic', rm='MV', obj='MinRisk')

# ❌ 错的
w = w_df[s]  # KeyError 因为是 DataFrame 不是 Series

# ✅ 对的
w = w_df['weights']
weights_series = w_df['weights']  # 这是个 Series
```

### 已删方法
- `portfolio_performance(w)` → 7.3 里**没有了**!自己算:
  ```python
  port_ret = returns @ w.values
  ann_ret = port_ret.mean() * 252
  ann_vol = port_ret.std() * np.sqrt(252)
  sharpe = ann_ret / ann_vol
  ```
- `risk_contribution(w)` → 也**没有了**,简化用 `(w**2)/(w**2).sum()`

### MaxSharpe 在下跌数据上的陷阱
- 模型默认假设"过去持续" → 在大跌数据下,会把 100% 押到"波动最小的一只"
- **如果模型给出极端权重(>80%),一定是数据问题,不是模型建议**
- **优先用 MinRisk**(分散均衡)

## 4. 决策要素优先级

按重要度从高到低:
1. **真实数据**(永远 > mock 或估算)
2. **资金面结构**(大单+超大单方向 = 主力意图)
3. **关键位 + 止损**(技术面)
4. **基本面预期**(业绩/估值)
5. **板块情绪**(题材热度)
6. **消息面**(只做确认,不做决策)

**最少要满足 1-3 才能做决策**。如果只能拿到 4-6,**不能买**。

## 5. 仓位管理的 Riskfolio 思维

| 30-50% | 10-15% | 中风险 |
| < 30% | 15-25% | 低风险 |

## 6. 卖出的 3 个固定规则

### 规则 A:**止损触发**
- 跌破成本 -7% → **无条件止损**
- 例: 买入价 41.47 × 0.93 = 38.57 → 跌破 38.57 就清

### 规则 B:**反弹减仓**
- 反弹到成本 +5% → 减仓 30%
- 反弹到成本 +10% → 减仓 50%
- 反弹到成本 +15% → 只留 25% 底仓

### 规则 C:**结构性卖出**
- 业绩雷(预亏 / 同比降 50%+) → 立即清
- 主力派发(超大 + 大单连续 3 天流出) → 减仓 50%
- 高位放量滞涨(3 日最高,2 日阴线) → 减仓 50%

## 7. 不要做的事(来自你 2026-07-22 实盘教训)

### 你今天犯的错误
| 错误 | 教训 |
|---|---|
| 把"别人推荐的"当成"我推荐的" | 任何推荐都要**自己核实一遍** |
| 在 7-22 大盘普跌时,4 只全仓 | 分散!大盘跌时单一个股更危险 |
| 跟着群里/AI 报告买票 | 群里 AI 报告 ≠ 我的报告,**永远先验证** |
| 看到某只票就加仓,不计算加仓位 | **任何加仓前过 Riskfolio** |
| 看到某票"埋伏"就买入 | **真埋伏是"技术面 + 资金面"双确认** |

### 通用绝对禁止
1. ⛔ **不在跌停打开当天追板**(7-14 / 7-15 你错过了风华的最佳卖点)
2. ⛔ **不在爆破点向下加仓**(神剑 9.40 加仓就是典型错误)
3. ⛔ **不在重大事件窗口前满仓**(7-24/25 大会前)
4. ⛔ **业绩披露前 3 天加仓**(雷风险高)
5. ⛔ **跟风群里 AI 推荐买票**(必须自己核实)

```

```

```
□ Riskfolio 跑了一次,看权重推荐
```
