## 一、核心认知(你赚不到钱的真相)

### 1.1 你选股其实不差

```
你最近做的:
- 示例个股A(事件驱动 + 涨价):买对了(虽然今天才涨)
- 示例个股D(商业航天题材):买对了逻辑(虽然被套)
- 示例个股B/示例个股C:方向对

结论:你**不是选股差,是纪律差**
```

### 1.2 散户的两大恶性循环

#### 恶性循环 1:盈利时贪婪

```
买入 10 元 → 涨到 11 元(+10%)
  "还能涨更高" → 涨到 12 元(+20%)
  "再等等" → 跌回 11 元(+10%)
  "至少赚点吧" → 跌回 10.5 元(+5%)
  "算了,回本就走" → 跌回 9.5 元(-5%)
  "完了,亏损了" → 死扛 → 跌回 9 元(-10%)

结果:赚 10% 没走,亏 10% 死扛
```

#### 恶性循环 2:亏损时不甘心

```
买入 10 元 → 跌到 9.5 元
  "没事,洗盘" → 跌到 9 元
  "快到止损了,但等反弹" → 跌到 8.5 元
  "完了,认亏出局" → 卖出后涨回 10 元
  "早知道不卖" → 重新追进去 → 又被套

结果:亏 10% 割肉,卖后涨 10% 又追进去
```

### 1.3 真实数据(A 股散户统计)

```
80% 的散户盈利区间:5-15%
90% 的散户在盈利 5-10% 时卖出
50% 的散户亏损区间:10-30%
70% 的散户在亏损 15%+ 时割肉

结论:**你赚小钱,亏大钱**,长期下来亏多赚少
```

## 二、核心解法:预设规则 + 强制执行

### 2.1 4 个卖出位(买入当天就设)

**这是本框架的核心**:

```
买入价:10 元
├─ 卖点 1 强止盈位:12 元(+20%)
│   └─ 减仓 50%(锁一半利润)
│
├─ 卖点 2 移动止盈位:跌破 5 日均线
│   └─ 减仓 30%(跟趋势走)
│
├─ 卖点 3 题材兑现位:事件兑现/涨价见顶
│   └─ 减仓 50%(催化兑现就走)
│
└─ 卖点 4 硬止损位:9 元(-10%)
    └─ 清仓(无论任何理由)
```

### 2.2 4 个卖出位的逻辑

| 卖点 | 触发条件 | 减仓幅度 | 核心目的 |
|---|---|---|---|
| **强止盈** | 浮盈 +20% | 50% | **锁住一半利润**,防止"涨了又跌回去" |
| **移动止盈** | 跌破 5 日均线 | 30% | **跟趋势走**,趋势破就走 |
| **题材兑现** | 事件兑现/涨价见顶 | 50% | **催化结束就走**,不等"二波" |
| **硬止损** | 亏损 -10% | 100% | **避免大亏**,承认判断错误 |

### 2.3 时间止损(防止"温水煮青蛙")

```
买入 5 个交易日不涨 → 减仓 50%(说明判断错了)
买入 10 个交易日没创新高 → 清仓(题材已死)
```

**为什么需要时间止损**:
- A 股题材股,通常 3-5 天内必须见效
- 5 天不涨 = 大概率判断错误
- 10 天不涨 = 题材已死,不要浪费时间

### 3.1 为什么你靠不住自觉

```
盘中你看到的:
- 涨 5% → 想要不要卖
- 涨 8% → 想再等等
- 涨 10% → 想拿到 15%
- 涨 15% → 想拿到 20%
- 涨 20% → 想拿到 30%
- 跌回 15% → 想等等回本
- 跌回 10% → 想等等回本
- 跌回 5% → 想等等回本
- 跌回 0% → 想等反弹
- 跌 -5% → 完了,扛着
- 跌 -10% → 终于割肉

盘中情绪会让你违反任何规则
```

**唯一解法**:**不靠盘中判断,靠规则推送**

## 四、按"场景 8 题材"分类的卖出策略

### 4.1 政策催化票(持续 1-3 周)

```
入场后 7 天内:只要政策没兑现,就持有
政策兑现当天:减仓 50%(催化已兑现)
后续:看是否"二波",没有就清仓
```

### 4.2 事件催化票(持续 1-3 天)

```
入场当天:打板
次日:高开不板就减仓 50%
第三天:不板就清仓
事件已兑现:无理由持有
```

### 4.3 涨价催化票(持续 1-3 月)

```
入场后:每涨 20% 减仓 30%
涨价见顶信号(下游开始压价):减仓 50%
价格回撤 10%:再减 30%
```

### 4.4 数据催化票(持续 1-5 天)

```
数据公布当天:不板就减仓 50%
次日:不板就清仓
数据已被市场消化,无理由持有
```

```
- 买入价:14.74

  ├─ 强止盈位:N/A(已亏损)
```
