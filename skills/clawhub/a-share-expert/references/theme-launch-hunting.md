# 题材刚启动识别框架 / Theme-Launch Hunting

> **场景 8 详细方法论** — 解决"A 股怎么抓到刚启动的票"
> 核心认知:**A 股真正赚钱的是题材炒作**(亏损股/概念股一波涨 30-40%),基本面好的票反而涨得少

---

## 一、核心认知(A 股真相)

### 1.1 你必须接受的 4 个事实

| 事实 | 解释 |
|---|---|
| A 股 90% 赚钱机会来自题材炒作 | 散户占比 60%+,追涨杀跌形成正反馈 |
| 真正能涨的票大多是亏损股/微利股 | 机构不参与,游资主导,弹性最大 |
| 基本面好的票反而涨得少 | 估值锚定,缺乏情绪催化剂 |
| "刚启动"是事后才知道 | 买入时已涨 5-10%,目标定 20-30% |

**心态校正**:如果你抗拒"买亏损股",你就已经输了 A 股 90% 的赚钱机会。

### 1.2 为什么"刚启动"难识别

```
事后看:启动期 → 高潮期 → 退潮期(清晰)
盘中看:每一秒都像启动期,每一秒都像高潮期

核心难点:
- 你买入时已经涨 5-10%
- 你不知道还会不会再涨 20%
- 你不知道是不是已经到高潮期
```

**唯一解法**:**用规则过滤,不用直觉判断**

## 二、题材生命周期(必背)

### 2.1 四个阶段的核心特征

| 阶段 | 时间 | 龙头表现 | 成交量 | 买点 | 卖点 |
|---|---|---|---|---|---|
| **潜伏期** | 1-3 天 | 横盘/小阴小阳 | 5000 万-1 亿 | **最佳**(无人关注) | 涨幅 20% |
| **启动期** | 1-2 天 | 首个涨停板 | 1-1.5 亿(温和放量) | **次佳**(易识别) | 涨幅 15-20% |
| **高潮期** | 3-5 天 | 一字板/连续板 | 5 亿+(天量) | **危险**(不追) | 立即清仓 |
| **退潮期** | 3-7 天 | 放量下跌 | 缩量 | **不买** | 已走 |

### 2.2 用 3 个数据定位"阶段"

#### (a) 封单额 / 流通盘 = 阶段定位

```
公式:封单额(元) / 流通市值(元)

1-3%  → 启动期(可买)
3-5%  → 高潮初期(谨慎)
5%+   → 高潮期(不追)

实战例子(示例个股A 7/23 涨停):
- 封单 33 亿 / 流通市值 185 亿 = 17.8% = 极强势高潮期
- 但这是反包涨停,不是"刚启动",已经晚了 1 周
```

#### (b) 题材新鲜度 = 阶段定位

```
题材时间 ≤ 3 天  → 启动期/潜伏期(可买)
题材时间 3-7 天  → 高潮期(不追)
题材时间 > 7 天  → 末期(清仓)
```

#### (c) 涨停板首次封板时间 = 阶段定位

```
首次封板 < 10:30  → 高潮期特征(主力志在高远)
首次封板 10:30-13:00 → 启动期特征(温和)
首次封板 > 13:00  → 启动末期/分歧
```

## 三、5 个"启动信号"(核心干货)

### 信号 1:量能温和放大(2-3 倍)

**这是最核心的信号**:
```
平时日成交 5000 万 → 启动期 1-1.5 亿(2-3 倍)
平时日成交 1 亿   → 启动期 2-3 亿(2-3 倍)
平时日成交 5 亿   → 启动期 10-15 亿(2-3 倍)

❌ 错:成交量是平时的 5 倍+(这是高潮期)
✅ 对:成交量是平时的 2-3 倍(这是启动期)

原理:启动期是"先知先觉者"买入,量能放大但不是天量
      高潮期是"后知后觉者"买入,量能是平时的 5-10 倍
```

**工具调用**:
```python
mcp__wudao_a_stock__stock_screener(
    volumeRatioMin=2,  # 放量 2 倍以上
    volumeRatioMax=4,  # 但不超过 4 倍(避免高潮期)
    market="main"      # 主板过滤
)
```

### 信号 2:价格突破 MA20

```
20 日均线是"中期趋势分水岭"
- 站稳 MA20 + 量能配合 = 启动期
- 跌破 MA20 + 量能放大 = 退潮期

工具调用:
mcp__wudao_a_stock__kline(code="XXX", days=30)
  → 计算 close vs MA20
```

### 信号 3:板块梯队结构

```
主线确立 = 同题材 ≥ 3 只涨停 + 龙头是换手板(非一字)

工具调用:
mcp__wudao_a_stock__limitup_filter(date="20260723", conceptKeywords=["商业航天"])
  → 找出涨停的同题材票数量
```

### 信号 4:主力资金净流入转正

```
启动期特征:主力资金单日净流入 > 5000 万,且持续 2 天以上
高潮期特征:主力资金开始净流出

工具调用:
mcp__wudao_a_stock__intraday_main_flow(codes="XXX,YYY,ZZZ")
```

### 信号 5:分时图"早盘冲高回落 + 午后拉升"

```
✅ 启动期分时:
- 早盘小幅高开 1-3%
- 10:00 前冲高回落(洗盘)
- 午后 13:30 后拉升
- 14:30 后封板

❌ 高潮期分时:
- 一字板(开盘就涨停,排队也买不到)
- 高开 5%+ 直接秒板
- 买盘持续,一波拉完

工具调用:
mcp__wudao_a_stock__minute_data(code="XXX")
```

## 四、4 类题材的具体玩法

### 4.1 政策催化(最猛)

**识别方法**:
- 国务院/央行/发改委文件
- 行业新政策落地
- 国家重大会议(两会/中央经济工作会议)

**案例**:7/22 上海推进千帆星座建设 → 引力一号海上发射 → 商业航天板块
**特征**:政策 → 资金 → 标的,传导快

**工具调用**:
```python

mcp__hexin_ifind_ds_news_mcp__search_news(query="政策 落地", time_start="2026-07-20")
```

### 4.2 事件催化(最快)

**识别方法**:
- 火箭发射成功
- 大订单签订
- 技术突破
- 重大资产重组

**案例**:7/10 长征十号乙海上网系回收(全球首次)
**特征**:事件 → 概念股联动,持续 1-3 天

**工具调用**:
```python

```

### 4.3 涨价催化(最稳)

**识别方法**:
- 产品涨价(MLCC、存储、稀土)
- 供给收缩(停产、检修)
- 需求暴增(AI、新能源)

**案例**:MLCC 涨价 20% → 示例个股A涨停
**特征**:涨价 → 业绩 → 估值,持续 1-3 月

**工具调用**:


### 4.4 数据催化(最难)

**识别方法**:
- 财报超预期
- 销量数据
- 出口数据

**案例**:示例个股A 7/11 中报预增 60%
**特征**:数据 → 预期差,持续 1-5 天

**工具调用**:

## 六、"刚启动"识别清单(实操版)

### 6.1 早盘 9:25 集合竞价后做的事

```bash
1. 看板块涨幅榜(前 10 名)
   - 某板块从无名冲到前 10 = 启动信号
   - 工具:mx_stocks_screener / sector_analysis

2. 看涨停板(找首板)
   - 找"今天第一次涨停"的票
   - 看是否有题材支撑
   - 工具:limit_up_filter(date="今天", changeTag="FIRST_LIMIT")

3. 看异动榜(找量比 > 3 的)
   - 量比 = 启动前最重要指标
   - 工具:stock_screener(volumeRatioMin=3)
```

### 6.2 9:30-10:00 看分时图

```bash
1. 找"早盘冲高回落 + 午后拉升"的票
   - 典型启动期分时
   - 工具:minute_data

2. 看"成交明细"(找大单)
   - 单笔 100 万以上的连续买入 = 主力建仓
   - 工具:capital_flow(flowType="stock")

3. 看"板块联动"
   - 同板块多只票同步异动 = 主线确立
   - 工具:sector_analysis
```

### 6.3 10:00-11:30 找买点

```bash
1. 找"第一波回踩不破均线"的票
   - 比如早盘冲到 10.5 元,回踩到 10.2 元(MA10)不破
   - 这就是买点

2. 找"量价配合"的票
   - 涨时放量 + 跌时缩量 = 健康
   - 涨时缩量 + 跌时放量 = 危险

3. 找"题材新鲜度"
   - 题材时间 ≤ 3 天 = 还能买
   - 题材时间 ≥ 7 天 = 危险
```

## 七、过滤器(去除"高位接盘")

### 7.1 硬过滤器(直接 PASS)

| 条件 | 操作 |
|---|---|
| 近 20 日累计涨幅 > 30% | 大概率已涨完,**不买** |
| 题材时间 > 7 天 | 已进入高潮期,**不买** |
| 流通市值 < 30 亿 | 流动性差,**小仓位或不买** |
| 流通市值 > 500 亿 | 弹性差,**小仓位或不买** |
| ST 股 | **不买** |
| 主板 10% 涨停后单日 | **次日不追**(铁律) |

### 7.2 软过滤器(减仓或控仓)

| 条件 | 操作 |
|---|---|
| PE > 200 倍 | 警惕,纯题材票常见,**接受但控仓 ≤ 20%** |
| Q1 同比 -50% | 题材股典型,**小心证伪** |
| 当日成交 > 平时 5 倍 | **次日不追**(大概率高潮) |
| 封单额/流通盘 > 5% | 高潮初期,**次日看情况** |

## 八、实战案例分析

### 案例 1:示例个股A(7/23 涨停)

**真实情况**:
- 题材:MLCC 涨价 + AI 服务器
- 时间节点:7/11 中报预增 60%(已发酵 12 天)
- 涨停时成交 11.8 亿,平时约 6-7 亿(仅 1.5-2 倍,温和)
- 封单 33 亿 / 流通市值 185 亿 = 17.8%(极强,但这是反包不是启动)

**判断**:
- ❌ **不是"刚启动"** — 题材已发酵 12 天
- ✅ **是"超跌反弹 + 板块跟风"** — 风华从 79.62 跌到 41.30,今天涨停反包
- ⚠️ **明天不要追** — 已经晚了 1 周,容易高位接盘

### 案例 2:示例个股D(7/23 涨 3.27%)

**真实情况**:
- 题材:商业航天
- 时间节点:7/22 引力一号上海发射,7/10 长征十号乙回收
- **但这些都是"老题材"**(10 天前和 1 天前的不同催化)
- 神剑从 14.74 跌到 9.48(-35%),今天只是技术性反弹

**判断**:
- ❌ **不是"刚启动"** — 题材已多次发酵
- ✅ **是"超跌反弹"** — 7/21 长下影确认底部
- ⚠️ **真正的"刚启动"是 6/8**(SpaceX IPO + 千帆卫星利好),你错过了

### 案例 3:今天应该怎么找"刚启动"

**实操方法**(假设今天是 7/23):
```bash
1. 早上 9:25 看板块涨幅榜
   → 找到今天突然冲到前 10 的板块
   → 找出该板块的"龙头"(涨 5%+ 但未涨停)
   
2. 看量比
   → 量比 2-3 倍 + 涨幅 3-5% + 题材 ≤ 3 天
   → 这就是"刚启动"

3. 看分时
   → 早盘冲高回落 + 午后拉升
   → 这就是"启动分时"

4. 找买点
   → 回踩 MA5/MA10 不破
   → 量能温和(2-3 倍平时)
   → 板块有 3 只以上联动涨停
```

**今天的"神剑"应该是什么样**:
- 题材新鲜 ≤ 3 天(7/22 引力一号是昨天,新鲜度 OK)
- 板块龙头:引力一号海上发射利好 → 板块龙头应该是**首次涨停的票**(不是已经涨停过的)
- **你找到的话:上海+海上发射+首次涨停+主板+市值 30-200 亿 = 这就是"刚启动"**
