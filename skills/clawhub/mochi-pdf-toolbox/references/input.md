# Input contract

action inspect|merge|extract|reorder|split|rotate|compress|render|images-to-pdf|remove-blank. PDF inputs <=50 MiB and1..500pages. For a single PDF use file; optional pages:"1-3,5" uses one-based page numbers. merge: documents:[{file,pages?}] (2..30files, <=500outputpages). extract/reorder require pages. rotate: degrees +/-90,+/-180,+/-270 and optional pages; unselected pages retained. split: groups:["1-2","3-4"] or pagesPerFile (default1), <=100outputfiles/1000totalpages. inspect findBlank:true scans at most100pages. remove-blank confirmedPages:[2,4] verifies rendered blankness and rejects text/annotations. compress is lossless stream compression. render supports <=40selectedpages and scale0.5..3. images-to-pdf images:[paths] supports1..20images <=20 MiB/25megapixels each. Interactive fields/signed forms are inspect/render only; input PDF must be unlocked. Output manifest, PDF/PNG results and preview for PDF outputs; multiple files get results.zip.

JSON input is a workspace file up to 1 MiB. Successful exports return files [{path,bytes,sha256}]. All processing stays under the active workspace; writes use new export directories and retain source files. For image/PDF operations, requestId is 1..80 ASCII letters, numbers, _ or -. An identical retry verifies saved source/output hashes.
