## Description:

Reviews code changes for bugs, security risks, load issues, missing tests, performance problems, and unnecessary complexity, with actionable findings.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dietrichgebert](https://clawhub.ai/user/dietrichgebert)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to review a diff, branch, pull request, or files and receive prioritized, concrete findings without changing code.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Review findings may be incomplete or incorrect.

Mitigation: Check the cited code and proposed fixes before acting on the report.
