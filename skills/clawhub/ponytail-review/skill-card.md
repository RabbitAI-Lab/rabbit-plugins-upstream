## Description:

Reviews code changes for bugs, security risks, load issues, missing tests, performance problems, and unnecessary code, with concrete fixes for each finding.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dietrichgebert](https://clawhub.ai/user/dietrichgebert)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to review code changes and receive prioritized, actionable findings before shipping.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A review can miss issues or suggest an incorrect fix.

Mitigation: Check findings against the cited code and tests before acting on them.
