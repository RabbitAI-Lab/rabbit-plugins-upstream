# Support

This document describes where to get help with k12-teacher.

## Support Channels

| Channel | Use For |
|---|---|
| GitHub Issues | Bug reports and feature requests (use the provided issue forms) |
| GitHub Discussions | Usage questions, methodology questions, and community help |
| Pull Requests | Contributed fixes and improvements (see CONTRIBUTING.md) |
| SECURITY.md process | Suspected security vulnerabilities -- never report these in public issues |

## Documentation

| Document | Contents |
|---|---|
| README.md | Project overview, features, and quick start |
| SKILL.md | Agent-facing index, capability tiers, and workflow quick reference |
| README_FOR_AI.md | Complete build specification, file contracts, and quality gates |
| CONTRIBUTING.md | Branch naming, commit format, PR process, and review checklist |
| GOVERNANCE.md | Roles, decision process, and release policy |
| SECURITY.md | Vulnerability reporting and disclosure timeline |

## Response Expectations

This is a community-maintained project. Issues and discussions are reviewed on a best-effort basis. Security reports follow the acknowledgment and remediation timeline defined in SECURITY.md.

## Scope Note

k12-teacher provides instructional methodology for K-12 subjects. It does not provide medical, psychological, or legal advice, and it does not issue official certifications or diplomas. See the boundary conditions in SKILL.md.
