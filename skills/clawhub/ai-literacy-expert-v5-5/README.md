## 快速开始

### 生成课件
```
用户：做一个关于"Prompt 优化"的互动课件
AI：[生成 p5.js 单文件 HTML 课件]
```

### 生成游戏
```
用户：设计一个"Prompt 大冒险"游戏
AI：[生成 p5.js 单文件 HTML 闯关游戏]
```

### 生成备课包
```
用户：帮我备一节"AI 是什么"的课，受众是高中生
AI：[5 阶段对话] → [生成 4 格式文档 + zip 打包]
```

### 测评学习效果
```

```

```
用户：我是零基础，想系统学习 AI，应该从哪里开始？
AI：[分析目标 + 生成个性化学习路径图]
```

### 团队协作备课


## 离线使用

V5 支持完全离线使用：

1. **首次加载**：自动缓存所有核心资源
2. **离线使用**：断网后仍可使用已缓存功能
3. **自动同步**：联网后自动同步离线期间的数据
