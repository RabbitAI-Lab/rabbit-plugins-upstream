# 心灵补手 V3.5.0 — 反模式与避坑指南 (ANTIPATTERNS)

> 针对 SkillHub 评测「反模式与FAQ 3.3」低分项的改进：明确「哪些事不该做」「哪些坑要避开」，避免误用。

---

## 🚫 不该做的事

### 1. 不要把玄学测算当真实决策依据
刘伯温的六爻/奇门是**娱乐+心理陪伴**，不是预测工具。拿它做投资、医疗、法律、重大人生决策 → **错误用法**。相关判断务必理性评估。

### 2. 不要在严肃专业场景用高谄媚人格
技术攻坚、商务谈判、法律文书、医疗咨询等需要客观严谨的场合，用 taijian/siji/zaomiao 等极致谄媚人格会**干扰信息准确性**。这类场景请用 default 或关闭谄媚。

### 3. 不要单人格叠加过多
STACK 模式会把多个人格话术叠进同一会话。叠 3 个以上会**话术互相抢占、风格混乱**。如需切换，先 deactivate 旧的再 activate 新的。

### 4. 不要把 API 密钥 / 敏感信息写进人格 JSON
人格定义文件可能被复制/分享。**严禁**在其中硬编码密钥、token、内部地址。敏感信息应走环境变量或 `~/.openclaw/.credentials/`。

### 5. 不要直接手改标准结构外的字段后不验证
自定义人格时，若随意增删 `meta/identity/behavior/phrases` 关键字段，会导致加载失败。改完**务必**跑 `xinling check` 验证。

## ⚠️ 易踩的坑

### 坑1：运行时目录与项目目录不同步
- 项目源码：`<项目>/xinling-bushou-v2/`
- 运行时：`~/.xinling-bushou-v2/`
- **坑**：改了项目源码但没同步到运行时，`xinling` 用的仍是旧版。
- **解法**：重跑 `./scripts/install.sh` 或手动同步。

### 坑2：误以为 6 个人格结构一致
旧版只有 `songzhiwen` 是标准结构，其余 5 个是松散结构 →
**V3.5.0 已内置归一化器自动兼容**，无需手动改。但若你**手写新人格**，请用标准结构（见 `personas/scholar.json` 模板）。

### 坑3：触发词含感叹词导致频繁误触发
`trigger_keywords` 里有 `!`、`啊`、`哇` 等。用户在正常交流中打感叹号也会触发谄媚。若嫌吵，把 `always_on` 设为 `false`，或精简触发词。

### 坑4：黑箱测算引擎要装依赖
刘伯温的双法融合依赖 `core/heixiang_fusion.py` 及其依赖库。缺依赖时它能跑但**不输出卦象判词**（降级为口吻陪伴），容易被误认为"坏了"。

### 坑5：SOUL.md 注入的是旧版本号
注入的人格片段里写死版本号（如 v3.0）。版本升级后，只有**重新注入**（重跑 install.sh 选人格）才会更新 SOUL.md 里的片段。

## ✅ 建议的用法

### 选对人格
| 场景 | 推荐人格 |
|------|---------|
| 严肃专业 / 技术 | 关闭谄媚或用 default |
| 日常闲聊 / 鼓励 | 宋之问 / 平儿 |
| 娱乐夸张 / 气氛 | 魏忠贤 / 早喵 |
| 迷茫问事 / 心理陪伴 | 刘伯温 |
| 熟人暧昧氛围 | 来问司机（注意场合）|

### 养成习惯
1. **装完先跑** `xinling check` —— 确认 0 失败。
2. **改完先验** —— 增改人格后跑 `xinling test <id>`。
3. **敏感信息走环境变量** —— 永不进 JSON。
