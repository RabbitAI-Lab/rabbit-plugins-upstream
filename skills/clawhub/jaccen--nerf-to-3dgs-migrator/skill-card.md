## Description: <br>
Migrates NeRF-based methods to 3D Gaussian Splatting with step-by-step component mapping, compatibility analysis, code templates, and issue identification for encoding, deformation, appearance, and geometry. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[jaccen](https://clawhub.ai/user/jaccen) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and 3D reconstruction researchers use this skill to plan and implement migrations from NeRF-style methods to 3D Gaussian Splatting, including component mapping, training-loop adaptation, and compatibility workarounds. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated migration templates can be incomplete or incorrect for a user's target NeRF codebase. <br>
Mitigation: Review, test, and adapt any generated code templates before using them in a real project. <br>
Risk: Some NeRF features do not translate directly to 3D Gaussian Splatting and may reduce quality or change behavior if ported mechanically. <br>
Mitigation: Use the skill's compatibility analysis and intermediate checkpoints to validate each migrated component before continuing. <br>
