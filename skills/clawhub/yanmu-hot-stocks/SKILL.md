# 研木 · 热门股票推荐 (yanmu-hot-stocks)
> **⚠️ 数据来源与限制（重要披露）：**
> 本Skill为课程教学演示而设计：优先尝试从公开财经源获取热门股票（网络可用时），网络不可用或接口受限时自动回退到**内置样例股票列表**（覆盖A股/港股/美股各3只示例标的），并在输出中标注数据来源（实时/内置样例）。
> 所有输出仅用于课程教学演示，不构成任何投资建议。



## 功能
根据用户选择的市场类型（A股/港股/美股），动态获取该市场当前热门的3只股票（公司名+股票代码），供用户选择研究标的。

## 工作流程

### 1. 用户选择市场
让用户从以下三个市场中选择：
- **A股** — 上海/深圳交易所
- **港股** — 香港交易所
- **美股** — 纽约交易所/纳斯达克

### 2. 调用脚本获取热门股票
使用 `exec` 工具运行 Python 脚本，脚本会自动从金融网站获取热门股并格式化输出。

```bash
python3 {baseDir}/scripts/fetch_hot_stocks.py --market <a-share|hk|us>
```

### 3. 展示结果给用户
脚本返回格式化的热门股票列表，包括：
- 公司中文名称
- 股票代码（含交易所后缀）
- 简要描述（行业/热门原因）

### 4. 用户确认
让用户从推荐列表中选择，或输入自定义股票代码。

## 数据源说明
脚本按优先级自动尝试以下数据源：
1. **A股**: 新浪财经 → 东方财富 → 内置样例数据
2. **港股**: 新浪财经港股 → Yahoo Finance HK → 内置样例数据
3. **美股**: Yahoo Finance → 内置样例数据

## 输出格式
```
📊 【热门股票推荐 - {{市场名}}】

1. 🥇 公司名 (代码) — 简要说明
2. 🥈 公司名 (代码) — 简要说明
3. 🥉 公司名 (代码) — 简要说明

请选择您想研究的标的（输入序号或股票代码）：
```

## 调用说明
本Skill由研木智能体自动调用，用户无需手动触发。
