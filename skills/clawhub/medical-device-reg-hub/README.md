# medical-device-reg-hub

All-in-one hub for medical device registration engineers — global pathways & classification (CN NMPA / US FDA / EU MDR / JP PMDA / ASEAN·LATAM), plus 8 topic hubs (UDI, STED, biocompatibility ISO 10993, GMP, post-market, labeling & IFU, supplier compliance, cycle-cost) with verified official links. From feasibility to certificate, no more scattered searching.

## Usage

- Entry point: `SKILL.md` — read its frontmatter `name` / `description` to decide applicability, then follow the steps.
- No `scripts/` directory: this skill ships documentation only.
