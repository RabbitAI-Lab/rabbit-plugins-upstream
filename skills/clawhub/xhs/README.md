# Xiaohongshu Operations Assistant — xhs

> **About language:** This skill does **not force any specific language**. It follows the language the user actually uses in the current conversation (Chinese / English / other). If you write in English, your drafts, captions, titles, and topic chips will be generated in English; if you write in Chinese, they will be in Chinese. The Chinese version of this README is at [中文](./README.zh-cn.md).

A one-stop content creation and operations assistant for Xiaohongshu (小红书 / RED) creators — covers everything from note preparation to post-publish daily management. The workflow is browser-based via the official Creator Center; final publish always requires your explicit confirmation.

## Features

### Content creation

- Generate note titles and captions from a topic brief
- Support both image-text notes and long-form notes
- Upload cover and body images
- Adapt expression style and reading experience to your content positioning

### Publishing

- Publish immediately or save as draft
- Final confirmation step before publish (no surprise posts)
- Format Xiaohongshu topic chips so tags become clickable
- Fits personal accounts, knowledge IPs, coach/training creators, product reviews, and similar scenarios

### Content management

- View and organize drafts
- Edit existing notes
- Continue working on unfinished drafts
- Support public publishing and scheduled publishing

### Community engagement

- View comments and feedback
- Reply to comments and direct messages
- Likes, favorites, and other daily interactions
- Help creators maintain a steady community presence

### Analytics

- View Creator Center metrics (within visible range)
- Inspect last 7 days, last 30 days, and other time windows
- Use data to review content performance and posting rhythm

## Who this is for

- Individual creators who want to publish high-quality content consistently
- Teams building a knowledge IP or professional brand
- Operators who need to unify topic selection, writing, publishing, and engagement
- Studios or agencies that want to improve Xiaohongshu content efficiency

## How to use

Describe your goal directly. Examples:

- "Draft a Xiaohongshu post about my morning routine and save it as a draft."
- "Publish this note to Xiaohongshu (小红书)."
- "Add relevant topic chips to this post and publish."
- "Show me my last 7 days of content performance."
- "Reply to yesterday's comments."

**Chinese trigger phrases:**

- "帮我写一篇关于教练对话的小红书笔记，并保存为草稿。"
- "把这篇笔记发布到小红书。"
- "帮我给这篇笔记添加相关话题并发布。"
- "查看我最近 7 天的内容表现。"
- "回复昨天收到的评论。"

## Operating principles

- Respect the user's account login and authorization state
- Do not bypass captchas, SMS verification, or platform risk control
- Publish actions require explicit user confirmation
- Comply with Xiaohongshu platform rules and applicable laws
- **Use the language the user inputs — do not force any specific language (no locale is hard-coded)**
