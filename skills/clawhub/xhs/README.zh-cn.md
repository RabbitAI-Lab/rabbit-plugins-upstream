# 小红书运营助手 — xhs

> **关于语言：** 本技能**不强制任何特定语言**——它会跟随用户在当轮对话中实际使用的语言（中文 / 英文 / 其他）。本 README 默认用中文撰写，仅为方便主要用户阅读；下方"使用方式"已附英文触发短语示例。完整英文版见 [EN](./README.md)。

面向小红书 (xiaohongshu) 创作者的一站式内容创作与运营助手，覆盖从笔记准备到发布后的日常管理。

## 功能特色

### 内容创作

- 根据主题生成笔记标题与正文
- 支持图文笔记和长文内容
- 支持上传封面与配图
- 可结合内容定位，优化表达风格和阅读体验

### 笔记发布

- 支持立即发布或保存为草稿
- 发布前保留最终确认环节
- 支持格式化小红书话题，让相关标签具备可点击性
- 适合个人账号、知识 IP、教练培训、产品分享等内容场景

### 内容管理

- 查看和管理草稿
- 编辑已有笔记
- 继续完善未完成的内容
- 支持公开发布和定时发布等内容安排

### 社区互动

- 查看评论与用户反馈
- 回复评论和私信
- 点赞、收藏等日常互动
- 帮助创作者保持稳定的社区沟通

### 数据查看

- 查看创作者中心可见的数据指标
- 支持了解近 7 天、近 30 天等阶段表现
- 辅助复盘内容效果和运营节奏

## 适合谁使用

- 想持续发布高质量内容的个人创作者
- 正在打造知识 IP 或专业品牌的团队
- 需要统一管理选题、写作、发布和互动的运营人员
- 希望提高小红书内容工作效率的机构或工作室

## 使用方式

直接描述你的目标即可，例如：

- "帮我写一篇关于教练对话的小红书笔记，并保存为草稿。"
- "把这篇笔记发布到小红书。"
- "帮我给这篇笔记添加相关话题并发布。"
- "查看我最近 7 天的内容表现。"
- "回复昨天收到的评论。"

**英文触发短语示例：**

- "Draft a Xiaohongshu post about my morning routine and save it as a draft."
- "Publish this note to Xiaohongshu (小红书)."
- "Add relevant topic chips to this post and publish."
- "Show me my last 7 days of content performance."
- "Reply to yesterday's comments."

## 使用原则

- 尊重用户账号的登录与授权状态
- 不绕过验证码、短信验证或平台风控
- 发布动作需要用户明确确认
- 遵守小红书平台规则及相关法律法规
- **使用用户输入的语言，不强制中文或任何特定语言**

仅供个人学习与运营使用。
