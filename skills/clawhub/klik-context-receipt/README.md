# Klik Context Receipt

An educational, non-executing skill for creating a compact receipt when work moves between Sessions, people, or agents.

It records the source, freshness, Context, permitted preparation, open questions, and the exact point where a person must take back control. It does not access accounts, run tools, send messages, make commitments, or authorize execution.

## Use

Provide a short, redacted work update. The skill returns a structured Context Receipt that distinguishes verified current facts from stale or missing context.

Use it after an interruption, before handoff, or when a proposed next step depends on prior conversation and authority.
