# 身高管理师 · 内容与表达合规红线

本文件是「身高管理师」Skill 生成一切对**外可见内容**（科普文案、社群回答、方案文档、短视频脚本）时的硬性约束。
违反任一条都会导致限流、投诉甚至违规下架。**所有对外输出必须先过本红线再发布。**

---

## 一、医疗安全边界（全域适用，不分平台）

1. **不诊断、不开方**：本 Skill 只提供生活方式科普与育儿建议，不替代医生。涉及疾病判断、用药（含生长激素/抑制针等）、剂量，一律不输出，只提示"建议至儿科内分泌科就诊"。
2. **不承诺效果**：禁止使用" guaranteed 长高 X cm""包长高""逆袭"等绝对化承诺。身高受遗传、营养、睡眠、运动、骨龄多重因素影响。
3. **必须带免责声明**：任何评估报告/方案末尾加一句：
   > 以上内容由 AI 辅助生成，仅供参考，不构成医疗诊断或治疗建议；如有疑虑请咨询专业医师。

## 二、抖音平台绝对红线（医疗类）

以下词**一个都不能出现**：

| 类别 | 禁用词 |
|------|--------|
| 器官名称 | 脑垂体、肝脏、骨骼、生长板、软骨 |
| 激素名称 | 生长激素(GH)、IGF-1、皮质醇 |
| 医学术语 | 分泌、代谢、内分泌、信号通路 |
| 动作/状态词 | 增高、减肥、壮阳、发育 |
| 中医术语 | 肾阴虚、火旺、滋阴、祛湿 |
| 来源标注 | **禁止写"协和教授说""XX 医生说"等任何专家来源标注** |

**替换规则（抖音）**：
- 发育 → 用「成长」「变化」
- 增高 → 用「长个儿」「助长」
- 不提任何器官/激素，用生活化表达（"吃好睡好多跳跳，帮孩子把生长潜力发挥出来"）

---

## 三、小红书平台注意事项

- 科学术语**允许出现**，但**必须带来源标注**，格式严格为：
  > 来源：协和潘慧教授 ｜ 精准营养培训教材
- 中医可谨慎使用「体质角度」「虚火偏旺」等弱表述，不展开论证。
- 同样禁用：增高（用「促长个儿」）、发育（用「成长」）、减肥、壮阳。
- 客服 SOP / 内部话术**不可**作为引用来源。

## 五、来源标注规范

- 抖音：**不标任何专家/机构来源**。
- 小红书：**凡引科学结论必标**「来源：协和潘慧教授 ｜ 精准营养培训教材」，可补充中华05标准。
- 数据型论断（如各年龄段睡眠时长、年生长速度）须有出处；无出处不写具体数字，改用区间或"通常建议"。
