## Description: <br>
Automates browser interactions from natural-language requests through CLI-style browser actions such as navigation, clicking, input, extraction, and session cleanup. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, operators, and other external users use this skill to automate repeated browser workflows, extract page content, and return structured browser-operation results. It is best suited for authorized workflows where the user can supervise sensitive actions. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill promotes browser automation patterns that can include anti-bot bypass, proxy, or User-Agent evasion guidance. <br>
Mitigation: Install and use it only for sites and accounts where the user has authorization, and avoid evasion guidance against third-party services. <br>
Risk: Under-scoped browser instructions could trigger sensitive actions such as logins, form submissions, purchases, account changes, messages, or private-data extraction. <br>
Mitigation: Require explicit user confirmation before sensitive browser actions and review extracted data before reuse or export. <br>
