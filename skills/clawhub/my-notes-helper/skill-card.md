## Description: <br>
A small notes helper skill that provides daily tips, curated links, and a simple greeting script for personal knowledge management. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[terrycarter1985](https://clawhub.ai/user/terrycarter1985) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and end users can use this skill to retrieve lightweight productivity tips, curated OpenClaw and ClawHub links, and a simple greeting script for personal note and reference workflows. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Users may expect a full note-storage tool, but the release evidence describes a small static tips-and-links bundle. <br>
Mitigation: Review the included files before installation and treat the skill as lightweight reference material unless additional note-management behavior is added. <br>
Risk: The package includes an executable greeting script. <br>
Mitigation: Inspect scripts before execution; the release security evidence reports the disclosed greeting script as harmless as inspected. <br>
