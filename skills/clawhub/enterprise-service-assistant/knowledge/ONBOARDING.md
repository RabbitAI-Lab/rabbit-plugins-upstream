# 🚀 新用户首次使用指南

> 当 `knowledge/PROJECT_KB.md` 不存在或为空时，企服助手会自动展示此引导流程。

---

## 欢迎使用企服助手！ 🏢

企服助手是你的园区企业服务智能助手，可以帮助你完成客户管理、费用催缴、工单调度等日常服务工作。

在开始使用之前，你需要**创建自己的项目知识库**，这样我才能了解你的项目数据、通知渠道和业务规则。

---

## 📋 三步完成知识库配置

### 第一步：准备你的业务数据

你需要准备一份包含业务数据的文件（推荐 Excel 格式），通常包括：

- **客户信息表** — 企业名称、联系人、合同信息等
- **费用收缴表** — 应收/已收金额、缴费状态等
- **报修记录表** — 工单信息、处理状态等
- **库存管理表** — 物资名称、库存数量等

> 💡 不必一次准备所有表，先有客户信息和费用数据就可以开始使用。

### 第二步：填写项目知识库

复制模板并填写你的项目信息：

```
复制: knowledge/TEMPLATE.md → knowledge/PROJECT_KB.md
```

需要填写的核心内容：

| 配置项 | 说明 | 必填 |
|--------|------|------|
| 项目名称 | 你的园区/项目名称 | ✅ |
| 数据文件路径 | Excel 文件的完整路径 | ✅ |
| 工作表清单 | Excel 中每个工作表的名称和用途 | ✅ |
| 通知渠道 | 企微 Webhook URL 等通知配置 | ⬜ |
| 隐私规则 | 客户信息脱敏规则 | ⬜ |
| 业务技能 | 启用哪些技能及参数 | ⬜ |

> 💡 只有「项目名称」和「数据文件路径」是必须的，其他配置可以逐步完善。

### 第三步：验证配置

知识库创建完成后，告诉我：

> "知识库已配置，帮我验证一下"

我会自动：
1. 读取你的数据文件，确认工作表结构
2. 测试通知渠道连接
3. 根据数据结构推荐适合的业务技能
4. 生成首次验证报告

## 📁 文件结构说明

```
skill根目录/
├── SKILL.md           ← 技能说明和触发词（不要修改）
├── AGENTS.md          ← 通用配置（不要修改）
├── SOUL.md            ← 通用人格设定（不要修改）
├── IDENTITY.md        ← 通用身份设定（不要修改）
├── TOOLS.md           ← 通用工具说明（不要修改）
├── scripts/           ← 📂 核心业务逻辑（Python脚本，不要修改）
├── knowledge/         ← 📂 项目知识库（你维护的部分）
│   ├── PROJECT_KB.md  ← 你的项目知识库（核心！）
│   ├── TEMPLATE.md    ← 知识库模板
│   └── ONBOARDING.md  ← 本引导文件
└── README.md          ← 技能说明文档
```

**关键区分**：
- **通用文件** (SKILL.md, AGENTS.md, SOUL.md, IDENTITY.md, TOOLS.md) — 随 Skill 分享，不需要修改
- **项目知识库** (knowledge/) — 每个用户独立，包含你的项目数据配置
- **WorkBuddy 个人文件** (USER.md, MEMORY.md, memory/) — 在 WorkBuddy 主会话中维护，与 Skill 分离

## 🔧 常见问题

### Q: 我的 Excel 数据格式和模板不一样怎么办？
A: 没关系！在 `PROJECT_KB.md` 中描述你的工作表结构即可，我会自动适配。

### Q: 可以不用企微通知吗？
A: 可以。通知渠道是可选的，没有 Webhook 也能使用查询功能。

### Q: 可以只启用部分技能吗？
A: 当然可以！在 `PROJECT_KB.md` 的业务技能配置中选择启用/禁用。

### Q: 数据文件可以放在哪里？
A: 任何你能访问的本地路径都可以，建议放在固定位置并在知识库中记录完整路径。

### Q: 以后想修改知识库怎么办？
A: 直接编辑 `knowledge/PROJECT_KB.md` 即可，修改后告诉我，我会重新加载配置。
