## Description: <br>
Autonomous Learning Assistant Free Edition helps an agent search the web, fetch pages, use browser interaction, and synthesize online information for personal knowledge gathering. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External personal users, students, and researchers use this skill to gather recent web information, fetch page content, inspect complex pages through browser interaction, and synthesize findings into concise answers. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill requests broad local file, search, write, and command execution authority for a web-learning workflow. <br>
Mitigation: Use it only in constrained environments, prefer a version scoped to web search, fetch, and browser tools, and avoid sensitive prompts, authenticated browser sessions, private files, or API keys unless the authority has been reviewed and constrained. <br>
