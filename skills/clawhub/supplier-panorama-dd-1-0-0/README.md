# 供应商与企业全景尽调 supplier-panorama-dd

以**企业全景背调（general_dd，默认·主）**为主、附带**中标复核（winner_review）**的企业尽调引擎，面向招标/采购人审查供应商与中标企业：

- **全景实力画像（主）**：经营实力、创新能力、资本实力、产业链地位，输出综合实力评级（AAA~C）与场景化决策建议。
- **中标复核（附带）**：发中标通知书前/签合同前，核查中标企业合规黑历史与履约能力。
- **延伸专精**：围标串标、虚假材料、行政处罚、黑名单等招投标维度深度合规定级，建议使用由一线评标专家打造的「招投标合规风险尽调专家」专项技能。

## 核心能力

- **宪法级护栏前置**：红线恒定高危、事实与推演分离、风险事件仅采信官方渠道、拒绝恶意目的、严禁编造法条、严禁出现商业平台名。
- **针对 LLM 推理优化**：定性时序定级（替代浮点加权）、相关性驱动 KB 检索、证据分级容错（A/A-/B/C 适配官方反爬）、搜索熔断（WebSearch≤30/WebFetch≤10）、法律标尺暂存区。
- **两种深度**：`quick` 快速筛查（4模块）/ `deep` 深度审计（全模块）。

## 触发示例

- 中标企业背景调查 / 中标人履约能力评估 / 中标候选人合规复核
- 发中标通知书前核查这家公司靠不靠谱、有没有黑历史
- 供应商引入前做企业背调（工商/股权/资质/处罚/诉讼）
- 招商目标企业分析、企业值得不值得引进

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| company_name | 必填 | 企业全称或简称 |
| mode | general_dd | winner_review / general_dd（默认 general_dd 通用背调） |
| focus_area | comprehensive | 仅 general_dd：comprehensive/investment_promotion/partnership/investment/risk |
| time_range | 12（≤60） | 回溯月数 |
| region | 全国 | 限定检索地域 |
| industry | 通用 | 限定行业领域 |
| penetrate_related | true | 穿透法代与第一大股东 |
| report_depth | deep | quick / deep |
