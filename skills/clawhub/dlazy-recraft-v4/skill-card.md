## Description:

Generates 1MP raster images for everyday creative work and rapid iteration.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and creative users use this skill to generate 1MP raster images from prompts and choose an aspect ratio. They can preview the request and estimated service cost before submitting it.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and supplied local media are sent to dLazy's hosted service.

Mitigation: Review prompts and files before use; share only content you are comfortable sending to dLazy.

Risk: The CLI uses an API key and image generation consumes service credits.

Mitigation: Keep the API key private and use --dry-run to preview the request and estimated cost.
