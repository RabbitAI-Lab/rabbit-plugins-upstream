## Description:

1MP raster image generation with refined design judgment. Suitable for everyday creative work and fast iteration.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creative professionals and developers use this skill to generate 1 MP raster images from prompts, iterate on creative concepts, choose an aspect ratio, and optionally save results locally.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and supplied media are sent to dLazy-hosted services for generation.

Mitigation: Avoid submitting sensitive content unless you are comfortable with the service and its handling terms.

Risk: Using the skill requires a dLazy API key, which the CLI can save in the local user configuration.

Mitigation: Protect access to the local account and configuration, and rotate or revoke the organization key if needed.
