## DI2 材料获取域范本

### 一、领域知识要点

- 来源分级：原始凭证 > 监管披露/权威数据库 > 行业报告 > 媒体转述 > 未署名信息
- 完整性四维：时间覆盖（几个期间）、科目覆盖（关键项是否齐全）、对象覆盖（对标对象是否齐）、口径覆盖（是否含调整说明）
- 时效衰减：财报按季衰减、行情按分钟衰减、政策按版本衰减、病历按就诊次数衰减
- 冲突材料处理原则：并列呈现 + 标注差异来源，不择一隐去
- 缺口分两类：可替代缺口（换来源可得）与硬缺口（客观无法获得，须声明盲区）

### 二、判定标准

- 材料清单须标明来源与取得时间
- 硬缺口必须在结论中体现为盲区，不得沉默
- 冲突材料不得择一呈现
- 时效超期材料须降级使用并标注

### 三、范本结构

1. 材料清单（来源/时间/覆盖维度）
2. 来源可靠性分级表
3. 完整性缺口清单（含硬缺口）
4. 冲突材料对照表
5. 盲区声明

### 四、常见失范

- 缺数据就用行业均值填补
- 只找支持自己判断的材料
- 不同来源冲突时取对自己有利的
- 不标取得时间导致时效误判

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 材料台账（名称/来源/取得时间/覆盖维度）、初步分类 |
| 本域产出 | 材料台账；来源分级表；完整性缺口清单；时效核验表；交叉验证记录 |
| 下游可用 | 交叉验证记录 |

### 六、交付自检

交付前逐项打勾，任一项不成立即返工：

- [ ] 材料清单须标明来源与取得时间
- [ ] 硬缺口必须在结论中体现为盲区，不得沉默
- [ ] 冲突材料不得择一呈现
- [ ] 时效超期材料须降级使用并标注

同时排除以下失范：

- [ ] 已排除：缺数据就用行业均值填补
- [ ] 已排除：只找支持自己判断的材料
- [ ] 已排除：不同来源冲突时取对自己有利的
- [ ] 已排除：不标取得时间导致时效误判

### 七、执行卡（以「材料清单编制」为例）

**开工前备齐**：材料台账（名称/来源/取得时间/覆盖维度）、初步分类

**可选补充**：子问题清单、可用渠道

**按序执行**：

1. 按子问题列需求
2. 采集
3. 登记台账
4. 分类
5. 核对覆盖

**交付前核对**：每条材料须标来源与时间；不得收录无法溯源的二手转述

**成品须符合**：材料台账

### 八、成品骨架

按「材料台账」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 材料台账

## 1. 材料清单（来源/时间/覆盖维度）
## 2. 来源可靠性分级表
## 3. 完整性缺口清单（含硬缺口）
## 4. 冲突材料对照表
## 5. 盲区声明
```

**齐备要求**：必选组件「材料台账（名称/来源/取得时间/覆盖维度）、初步分类」须全部落位；约束「每条材料须标来源与时间；不得收录无法溯源的二手转述」须逐条成立；可选「子问题清单、可用渠道」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
