## DI1 委托界定域范本

### 一、领域知识要点

- 研判问题三要素：研究对象（谁/哪份材料）、判断维度（看什么）、时间窗（看哪一段）
- 证据标准四级：一手凭证（原始合同/报表/日志）> 权威二手（监管披露/数据库）> 媒体转述 > 未署名推断
- 误判代价与复核强度成正比：高代价场景强制第二来源交叉验证
- 交付形态三档：速判卡（≤1页）、标准报告（5-15页）、深度报告（不限）
- 能力边界声明：医疗、法律、投资类研判须在开工前声明不替代持证专业意见

### 二、判定标准

- 对象、判断维度、时间窗三项未确认不得开工
- 每份研判须先声明证据标准，后续不得低于该标准
- 高风险域须在任务书阶段写入免责与复核要求
- 交付形态须与误判代价匹配，速判卡不得用于高代价决策

### 三、范本结构

1. 研判任务书（对象/问题/口径/证据标准/交付形态/时限）
2. 问题拆解树
3. 证据标准声明
4. 能力边界与免责
5. 交付清单

### 四、常见失范

- 拿到材料就开始分析，不问用途与决策场景
- 默认口径，不确认对方要的是同比还是环比
- 把速判当深度做，或把深度压成速判
- 高风险域不声明边界

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 研究对象、判断维度、时间窗、决策场景、交付形态、时限 |
| 本域产出 | 研判任务书；问题拆解树；证据标准声明；交付规格；边界与免责声明 |
| 下游可用 | 边界与免责声明 |

### 六、交付自检

交付前逐项打勾，任一项不成立即返工：

- [ ] 对象、判断维度、时间窗三项未确认不得开工
- [ ] 每份研判须先声明证据标准，后续不得低于该标准
- [ ] 高风险域须在任务书阶段写入免责与复核要求
- [ ] 交付形态须与误判代价匹配，速判卡不得用于高代价决策

同时排除以下失范：

- [ ] 已排除：拿到材料就开始分析，不问用途与决策场景
- [ ] 已排除：默认口径，不确认对方要的是同比还是环比
- [ ] 已排除：把速判当深度做，或把深度压成速判
- [ ] 已排除：高风险域不声明边界

### 七、执行卡（以「研判委托受理」为例）

**开工前备齐**：研究对象、判断维度、时间窗、决策场景、交付形态、时限

**可选补充**：委托背景、既有材料清单

**按序执行**：

1. 问场景
2. 定对象
3. 定维度
4. 定时间窗
5. 定交付
6. 成任务书

**交付前核对**：对象与维度未确认不得推进；须记录委托原话

**成品须符合**：研判任务书

### 八、成品骨架

按「研判任务书」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 研判任务书

## 1. 研判任务书（对象/问题/口径/证据标准/交付形态/时限）
## 2. 问题拆解树
## 3. 证据标准声明
## 4. 能力边界与免责
## 5. 交付清单
```

**齐备要求**：必选组件「研究对象、判断维度、时间窗、决策场景、交付形态、时限」须全部落位；约束「对象与维度未确认不得推进；须记录委托原话」须逐条成立；可选「委托背景、既有材料清单」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
