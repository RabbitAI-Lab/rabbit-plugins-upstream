## 决策研判任务清单与依赖拓扑

决策研判按"域 → 任务"组织的任务清单，附价值链、场景管线与依赖关系。

**价值链**：委托界定 → 材料获取 → 结构化解析 → 口径统一 → 指标加工 → 对标识别 → 归因定性 → 结论合成 → 预警追踪

**域划分判据**：域 = 价值链**阶段**。十二种材料在这些阶段上的动作完全同构，故材料类型不改阶段划分，下沉为管线维度。

**互斥约束**：一个任务只属于一个域；同一工作不会在两个域中同时出现。

**域间逻辑流**：DI1 委托界定 → DI2 材料获取 → DI3 结构化解析 → DI4 口径统一 → DI5 指标加工 → DI6 对标识别 → DI7 归因定性 → DI8 结论合成 → DI9 预警追踪

**域内基线规则**：每个域的首个任务为该域基线任务，同域其余任务一律以其产出为参照，不得跳步执行。

## 知识图谱

将依赖拓扑扩展为知识图谱，支持跨任务的关系推理。

**实体节点类型**

| 类型 | 数量 | 说明 |
|------|------|------|
| 任务节点 | 54 | 形如 `DI1-01`、`DI9-05` 的可执行单元 |
| 域节点 | 9 | 任务的分组边界 |
| 元操作节点 | 11 | S/C/A/O/I/G 及组合 |
| 产出物节点 | 54 | 各任务声明的交付格式；与任务近 1:1，故不单独建模归并 |
| 场景节点 | 19 | 场景管线中的入口场景 |

**关系边类型**

| 边 | 方向 | 含义 |
|----|------|------|
| 包含边 | 域 → 任务 | 域包含其下所有任务 |
| 依赖边 | 任务 → 任务 | 前置产出是后继输入，见各域链路 |
| 产出边 | 任务 → 产出物 | 任务声明的 `格式` 即其产出节点 |
| 路由边 | 场景 → 任务 | 场景管线的链首即入口任务 |
| 反向边 | 产出物 → 任务 | 由交付格式反查产出它的任务 |

**推理能力**

- **路径推导**：给定起止任务，沿依赖边求最短可行链
- **任务推荐**：给定已完成任务，取其后继中依赖已满足者
- **依赖分析**：给定任务，回溯全部前置与受影响的下游
- **并行识别**：同域内无依赖边的任务可并行执行
- **产出反查**：给定交付格式，定位产出它的任务
- **形态归并**：本负载物全部产出物归入「研判报告」这一产物形态，跨负载物可再归并

更多组合根据具体任务动态推导。
