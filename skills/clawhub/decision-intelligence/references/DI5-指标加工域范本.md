## DI5 指标加工域范本

### 一、领域知识要点

- 指标体系三层：结果指标（ROE/转化率）、驱动指标（周转率/客单价）、先行指标（订单/线索）
- 财务指标：加权ROE、自由现金流、利息保障倍数、EVA、内生增长率
- 统计方法：描述统计、假设检验选择树、回归诊断（共线性/异方差/内生性）
- 评分模型：权重设定依据、归一化方法、分档阈值
- 证据固化：每个数值须附来源、公式、中间过程
- 敏感性检查：关键假设变动 ±10% 时结论是否翻转

### 二、判定标准

- 每个指标须给公式、输入值与来源
- 关键假设须做敏感性检查
- 计算结果须可被第三方复算
- 指标间逻辑冲突须标出（如净利增而现金流降）

### 三、范本结构

1. 指标体系表（层级/指标/公式/来源）
2. 计算明细
3. 敏感性分析表
4. 指标间一致性检查
5. 证据溯源表

### 四、常见失范

- 只报结果不报公式
- 用不同分母算同一比率
- 不做敏感性就给点值
- 指标间矛盾不解释

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 指标体系表（层级/指标/公式/数据来源）、取舍理由 |
| 本域产出 | 指标体系表；财务指标计算表；统计检验报告；评分模型与结果；证据溯源表；复核与敏感性报告 |
| 下游可用 | 复核与敏感性报告 |

### 六、交付自检

交付前逐项打勾，任一项不成立即返工：

- [ ] 每个指标须给公式、输入值与来源
- [ ] 关键假设须做敏感性检查
- [ ] 计算结果须可被第三方复算
- [ ] 指标间逻辑冲突须标出（如净利增而现金流降）

同时排除以下失范：

- [ ] 已排除：只报结果不报公式
- [ ] 已排除：用不同分母算同一比率
- [ ] 已排除：不做敏感性就给点值
- [ ] 已排除：指标间矛盾不解释

### 七、执行卡（以「指标体系选定」为例）

**开工前备齐**：指标体系表（层级/指标/公式/数据来源）、取舍理由

**可选补充**：子问题清单、口径清单

**按序执行**：

1. 对子问题
2. 选结果指标
3. 找驱动指标
4. 补先行指标
5. 去冗余

**交付前核对**：指标须能回答子问题；不得堆砌无关指标

**成品须符合**：指标体系表

### 八、成品骨架

按「指标体系表」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 指标体系表

## 1. 指标体系表（层级/指标/公式/来源）
## 2. 计算明细
## 3. 敏感性分析表
## 4. 指标间一致性检查
## 5. 证据溯源表
```

**齐备要求**：必选组件「指标体系表（层级/指标/公式/数据来源）、取舍理由」须全部落位；约束「指标须能回答子问题；不得堆砌无关指标」须逐条成立；可选「子问题清单、口径清单」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
