## DI9 预警追踪域范本

### 一、领域知识要点

- 预警指标设计：领先指标优先于滞后指标，可观测优先于需调研
- 阈值三型：绝对阈值、相对阈值（偏离基线N倍）、趋势阈值（连续N期恶化）
- 观察台账：指标、频率、责任人、触发后动作
- 复盘节点：固定周期（月/季）+ 事件触发（结论失效条件命中）
- 预警分级：提示/关注/告警，对应不同响应时效
- 规则衰减：市场变化后旧阈值失效，须定期重校准

### 二、判定标准

- 每个预警须有明确阈值与触发动作
- 指标须可自动或低成本获取
- 复盘节点须写进台账
- 规则须有重校准机制

### 三、范本结构

1. 预警指标表（指标/阈值/频率/来源）
2. 分级与响应规则
3. 观察台账
4. 复盘节点与校准机制

### 四、常见失范

- 设了一堆指标但没人看
- 阈值凭感觉定且从不校准
- 预警无对应动作
- 只设滞后指标

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 指标表（名称/类型/领先滞后/数据来源/获取成本）、筛选理由 |
| 本域产出 | 预警指标表；阈值与规则表；观察台账；复盘与校准计划；预警响应手册 |
| 下游可用 | 预警响应手册 |

### 六、交付自检

交付前逐项打勾，任一项不成立即返工：

- [ ] 每个预警须有明确阈值与触发动作
- [ ] 指标须可自动或低成本获取
- [ ] 复盘节点须写进台账
- [ ] 规则须有重校准机制

同时排除以下失范：

- [ ] 已排除：设了一堆指标但没人看
- [ ] 已排除：阈值凭感觉定且从不校准
- [ ] 已排除：预警无对应动作
- [ ] 已排除：只设滞后指标

### 七、执行卡（以「预警指标设计」为例）

**开工前备齐**：指标表（名称/类型/领先滞后/数据来源/获取成本）、筛选理由

**可选补充**：失效条件清单、盲区清单

**按序执行**：

1. 取失效条件
2. 反推指标
3. 判领先性
4. 评获取成本
5. 定表

**交付前核对**：须优先领先指标；获取成本过高须说明替代

**成品须符合**：预警指标表

### 八、成品骨架

按「预警指标表」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 预警指标表

## 1. 预警指标表（指标/阈值/频率/来源）
## 2. 分级与响应规则
## 3. 观察台账
## 4. 复盘节点与校准机制
```

**齐备要求**：必选组件「指标表（名称/类型/领先滞后/数据来源/获取成本）、筛选理由」须全部落位；约束「须优先领先指标；获取成本过高须说明替代」须逐条成立；可选「失效条件清单、盲区清单」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
