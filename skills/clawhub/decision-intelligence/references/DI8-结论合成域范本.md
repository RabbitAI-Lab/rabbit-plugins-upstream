## DI8 结论合成域范本

### 一、领域知识要点

- 结论三要素：判断（是什么）、依据（凭什么）、边界（什么时候不成立）
- 置信度分级：高（多来源一致+反证未推翻）、中（单来源或反证未验）、低（推断为主）
- 结论区间优于点值：估值给区间、预测给区间、风险给等级
- 失效条件：列出会推翻该结论的具体观察
- 结论先行结构：先给判断，再给证据，最后给边界
- 盲区声明：硬缺口必须在结论中体现

### 二、判定标准

- 结论须可被一句话复述
- 每条结论须挂证据编号
- 置信度须显式标注
- 盲区与失效条件不得省略

### 三、范本结构

1. 核心结论摘要（≤500字）
2. 结论清单（判断/依据/置信度/失效条件）
3. 证据索引
4. 盲区与局限
5. 建议关注项

### 四、常见失范

- 结论一大堆但没有主判断
- 结论与证据脱节
- 不给置信度，把推断说得和事实一样硬
- 隐藏盲区

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 结论清单（判断/依据/置信度/边界）、主结论排序 |
| 本域产出 | 结论清单；置信度评级表；区间与边界说明；失效与盲区清单；研判报告 |
| 下游可用 | 研判报告 |

### 六、交付自检

交付前逐项打勾，任一项不成立即返工：

- [ ] 结论须可被一句话复述
- [ ] 每条结论须挂证据编号
- [ ] 置信度须显式标注
- [ ] 盲区与失效条件不得省略

同时排除以下失范：

- [ ] 已排除：结论一大堆但没有主判断
- [ ] 已排除：结论与证据脱节
- [ ] 已排除：不给置信度，把推断说得和事实一样硬
- [ ] 已排除：隐藏盲区

### 七、执行卡（以「结论结构化」为例）

**开工前备齐**：结论清单（判断/依据/置信度/边界）、主结论排序

**可选补充**：归因结果、证据表

**按序执行**：

1. 提主判断
2. 列支撑结论
3. 挂证据
4. 标置信度
5. 排优先级

**交付前核对**：每条结论须挂证据编号；主结论须唯一

**成品须符合**：结论清单

### 八、成品骨架

按「结论清单」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 结论清单

## 1. 核心结论摘要（≤500字）
## 2. 结论清单（判断/依据/置信度/失效条件）
## 3. 证据索引
## 4. 盲区与局限
## 5. 建议关注项
```

**齐备要求**：必选组件「结论清单（判断/依据/置信度/边界）、主结论排序」须全部落位；约束「每条结论须挂证据编号；主结论须唯一」须逐条成立；可选「归因结果、证据表」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
