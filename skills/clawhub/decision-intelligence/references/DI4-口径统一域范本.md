## DI4 口径统一域范本

### 一、领域知识要点

- 口径清单三要素：指标定义、计算公式、数据边界（含/不含什么）
- 会计政策调整四项：折旧方法、存货计价、研发资本化、收入确认
- 统计定义对齐：分母口径、样本范围、时间粒度、去重规则
- 期间可比化：会计年度差异、季节性、并购导致的并表范围变化
- 不可比事项处理：能调整则调整并留痕，不能调整则降级为"趋势参考"并声明

### 二、判定标准

- 每个跨来源比较的指标须有唯一定义
- 调整过程须留痕，可被复算
- 不可比事项不得强行比较
- 调整后须回验关键指标是否仍在合理区间

### 三、范本结构

1. 口径清单（指标/定义/公式/边界）
2. 调整说明表（原值/调整项/调整后）
3. 不可比事项清单
4. 复验结果

### 四、常见失范

- 直接拿两家的毛利率比，不看收入确认政策
- 同比跨了并表范围变化却不调整
- 分母口径不同还做比率对比
- 调整完不复验

- [ ] 不可比事项不得强行比较
- [ ] 调整后须回验关键指标是否仍在合理区间

- [ ] 已排除：直接拿两家的毛利率比，不看收入确认政策
- [ ] 已排除：同比跨了并表范围变化却不调整
- [ ] 已排除：分母口径不同还做比率对比
- [ ] 已排除：调整完不复验

### 七、执行卡（以「口径清单建立」为例）

**开工前备齐**：口径清单（指标/定义/公式/数据边界/单位）

**可选补充**：指标使用场景、行业惯例

**按序执行**：

1. 列指标
2. 定定义
3. 写公式
4. 划边界
5. 统一单位

**交付前核对**：每个指标只能有一个定义；跨来源差异须单列

**成品须符合**：口径清单

### 八、成品骨架

按「口径清单」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 口径清单

## 1. 口径清单（指标/定义/公式/边界）
## 2. 调整说明表（原值/调整项/调整后）
## 3. 不可比事项清单
## 4. 复验结果
```

**齐备要求**：必选组件「口径清单（指标/定义/公式/数据边界/单位）」须全部落位；约束「每个指标只能有一个定义；跨来源差异须单列」须逐条成立；可选「指标使用场景、行业惯例」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
