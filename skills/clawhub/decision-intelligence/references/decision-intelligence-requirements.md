## 决策研判任务要求清单

决策研判每种任务类型的零件清单——必选组件、可选组件、组装顺序、领域约束。按清单逐项产出。

---

### DI1 委托界定

#### 域级说明

**域定位**：把一句模糊的诉求转成可回答、可验收的研判任务书。这是唯一能决定"后面全部工作是否值得做"的阶段。

| 维度 | 内容 |
|------|------|
| 价值链形态 | 问题→证据标准→交付形态 |
| 独立成域的理由 | 价值链起点。此阶段不成立则后续全部偏离——问错问题的研判再严谨也无价值。 |
| 穷尽性 | 「问题→证据标准→交付形态」共 3 个环节，由 5 个任务展开（部分环节拆为多任务）；按输入物、失败模式、验收标准三条判据互不重叠，无未覆盖环节 |
| 知识要点 | 研判问题三要素：研究对象（谁/哪份材料）、判断维度（看什么）、时间窗（看哪一段）；证据标准四级：一手凭证（原始合同/报表/日志）> 权威二手（监管披露/数据库）> 媒体转述 > 未署名推断；误判代价与复核强度成正比：高代价场景强制第二来源交叉验证；交付形态三档：速判卡（≤1页）、标准报告（5-15页）、深度报告（不限）；能力边界声明：医疗、法律、投资类研判须在开工前声明不替代持证专业意见 |
| 判定标准 | 对象、判断维度、时间窗三项未确认不得开工；每份研判须先声明证据标准，后续不得低于该标准；高风险域须在任务书阶段写入免责与复核要求；交付形态须与误判代价匹配，速判卡不得用于高代价决策 |
| 常见失范 | 拿到材料就开始分析，不问用途与决策场景；默认口径，不确认对方要的是同比还是环比；把速判当深度做，或把深度压成速判；高风险域不声明边界 |
| 范本结构 | 研判任务书（对象/问题/口径/证据标准/交付形态/时限） → 问题拆解树 → 证据标准声明 → 能力边界与免责 → 交付清单 |

#### DI1-01 研判委托受理
- **必选组件**: 研究对象、判断维度、时间窗、决策场景、交付形态、时限
- **可选组件**: 委托背景、既有材料清单
- **组装顺序**: 问场景→定对象→定维度→定时间窗→定交付→成任务书
- **约束**: 对象与维度未确认不得推进；须记录委托原话
- **格式**: 研判任务书

#### DI1-02 研判问题拆解
- **必选组件**: 子问题清单（含优先级）、每个子问题的判断标准、依赖关系
- **可选组件**: 决策场景、可用材料
- **组装顺序**: 识别主问题→拆子问题→定判断标准→排优先级
- **约束**: 子问题须可被材料回答；不得拆出无法验证的问题
- **格式**: 问题拆解树

#### DI1-03 证据标准设定
- **必选组件**: 证据等级要求、必采一手材料清单、交叉验证规则、缺口容忍度
- **可选组件**: 子问题清单、误判代价评估
- **组装顺序**: 评误判代价→定证据等级→列必采材料→设交叉验证
- **约束**: 高代价场景不得接受单一来源；缺口超容忍度须中止
- **格式**: 证据标准声明

#### DI1-04 交付形态约定
- **必选组件**: 交付形态、篇幅上限、必备章节、图表清单、呈现顺序
- **可选组件**: 受众层级、决策节奏
- **组装顺序**: 判受众→选形态→定章节→定图表→定呈现顺序
- **约束**: 形态须匹配决策节奏；速判卡须能一屏读完
- **格式**: 交付规格

#### DI1-05 高风险领域前置约束
- **必选组件**: 能力边界声明、须复核事项清单、免责措辞、转介路径
- **可选组件**: 领域监管要求、机构政策
- **组装顺序**: 判是否高风险→列不可为事项→写免责→给转介
- **约束**: 不得省略免责；不得给出确诊或法律结论
- **格式**: 边界与免责声明

### DI2 材料获取

#### 域级说明

**域定位**：把散落的信息收拢为可用的材料集，并把"缺什么"显式说出来。这一阶段的价值不在拿到多少，而在知道少了什么。

| 维度 | 内容 |
|------|------|
| 价值链形态 | 清单→分级→缺口→时效→校验 |
| 独立成域的理由 | 域划分依据：材料不进则研判无据。此阶段产出的是"可信材料集+缺口清单"，形态与后续解析完全不同。 |
| 穷尽性 | 「清单→分级→缺口→时效→校验」共 5 个环节，由 5 个任务展开（部分环节拆为多任务）；按输入物、失败模式、验收标准三条判据互不重叠，无未覆盖环节 |
| 知识要点 | 来源分级：原始凭证 > 监管披露/权威数据库 > 行业报告 > 媒体转述 > 未署名信息；完整性四维：时间覆盖（几个期间）、科目覆盖（关键项是否齐全）、对象覆盖（对标对象是否齐）、口径覆盖（是否含调整说明）；时效衰减：财报按季衰减、行情按分钟衰减、政策按版本衰减、病历按就诊次数衰减；冲突材料处理原则：并列呈现 + 标注差异来源，不择一隐去；缺口分两类：可替代缺口（换来源可得）与硬缺口（客观无法获得，须声明盲区） |
| 判定标准 | 材料清单须标明来源与取得时间；硬缺口必须在结论中体现为盲区，不得沉默；冲突材料不得择一呈现；时效超期材料须降级使用并标注 |
| 常见失范 | 缺数据就用行业均值填补；只找支持自己判断的材料；不同来源冲突时取对自己有利的；不标取得时间导致时效误判 |
| 范本结构 | 材料清单（来源/时间/覆盖维度） → 来源可靠性分级表 → 完整性缺口清单（含硬缺口） → 冲突材料对照表 → 盲区声明 |

#### DI2-01 材料清单编制
- **必选组件**: 材料台账（名称/来源/取得时间/覆盖维度）、初步分类
- **可选组件**: 子问题清单、可用渠道
- **组装顺序**: 按子问题列需求→采集→登记台账→分类→核对覆盖
- **约束**: 每条材料须标来源与时间；不得收录无法溯源的二手转述
- **格式**: 材料台账

#### DI2-02 来源可靠性分级
- **必选组件**: 分级表（材料/等级/理由）、交叉验证清单
- **可选组件**: 来源性质、发布主体
- **组装顺序**: 判来源性质→定等级→标需交叉项→列补充要求
- **约束**: 一手凭证不得降级使用；未署名来源须标"待验证"
- **格式**: 来源分级表

#### DI2-03 完整性缺口识别
- **必选组件**: 完整性矩阵（维度×覆盖情况）、缺口清单、可替代方案、盲区列表
- **可选组件**: 子问题清单、材料台账
- **组装顺序**: 逐维比对→标缺口→判可替代性→定补采方案→列盲区
- **约束**: 硬缺口须进结论盲区；不得用推测补缺
- **格式**: 完整性缺口清单

#### DI2-04 时效与版本核验
- **必选组件**: 时效核验表、版本沿革、超期标记、替代材料建议
- **可选组件**: 发布日历、版本记录
- **组装顺序**: 查发布日期→比对当前时点→查是否修订→标超期→给替代
- **约束**: 超期材料须降级并标注；旧版法规不得直接引用
- **格式**: 时效核验表

#### DI2-05 冲突材料交叉验证
- **必选组件**: 冲突清单、差异定位、验证方法、采信结论、保留意见
- **可选组件**: 第三方数据、原始凭证
- **组装顺序**: 列冲突→找差异源→选验证法→交叉核对→定采信→留意见
- **约束**: 差异无法消解时须并列呈现；不得单方采信
- **格式**: 交叉验证记录

### DI3 结构化解析

#### 域级说明

**域定位**：把材料拆成字段，且拆得可回溯。解析的质量决定后面每一步的上限——字段错位，指标、对标、归因全部作废。

| 维度 | 内容 |
|------|------|
| 价值链形态 | 字段设计→逐材解析→缺失标注 |
| 独立成域的理由 | 域划分依据：把非结构化材料转为可比对的字段，是本领域唯一"形态发生质变"的阶段——材料进去，表格出来。该动作在 12 种材料上完全同构，故合并为一域、按材料分任务。 |
| 穷尽性 | 「字段设计→逐材解析→缺失标注」共 3 个环节，由 12 个任务展开（部分环节拆为多任务）；按输入物、失败模式、验收标准三条判据互不重叠，无未覆盖环节 |
| 知识要点 | 解析四要求：字段化、保位置（可回溯到原文行/页/条款号）、标缺失（没有就写没有）、不改写（保留原始表述）；各材料族字段体系：财报（三表科目+附注）、合同（当事人/标的/价款/履行/违约/争议解决）、病历（SOAP）、代码（模块/调用链/依赖）、评论（情感/意图/场景）、简历（教育/经历/项目/成果）、试卷（知识点/认知层级/错因）、法规（效力层级/条款号/生效日）、论文（IMRaD/样本/结论）、数据集（字段类型/缺失率/分布）；解析粒度原则：只解析后续会用到的字段，避免全量转录；表格化输出：一行一条记录，一列一个字段，便于后续机器处理 |
| 判定标准 | 每个字段须能回溯到原文位置；缺失字段须显式标空，不得留白或用推断填；不得改写原文表述，改写须单列"释义"字段；解析结果须可被下游任务直接消费（结构化表格） |
| 常见失范 | 解析时顺手"解读"，污染原始字段；缺字段用推断补齐；全量转录导致噪声过载；不留位置信息导致无法回溯 |
| 范本结构 | 字段设计表 → 解析结果表（含原文位置） → 缺失字段清单 → 异常表述备注 |

#### DI3-01 解析字段设计
- **必选组件**: 字段字典（名称/类型/取值/来源位置）、解析规则、示例
- **可选组件**: 子问题清单、材料样本
- **组装顺序**: 列下游用途→反推字段→定类型→定取值规则→试解析校验
- **约束**: 字段须服务于子问题，不得全量转录；须标来源位置
- **格式**: 字段字典

#### DI3-02 财务报表解析
- **必选组件**: 三表科目表、关键附注、会计政策摘要、勾稽校验结果
- **可选组件**: 财报原文、上年同期
- **组装顺序**: 定位三表→抽科目→抽附注→记政策→勾稽校验
- **约束**: 须保留科目原名称与金额单位；勾稽不符须标出
- **格式**: 财务解析表

#### DI3-03 市场与竞品材料解析
- **必选组件**: 市场规模表、竞品功能矩阵、价格带分布、渠道结构
- **可选组件**: 行业报告、平台数据、竞品页面
- **组装顺序**: 抽取口径→建功能矩阵→录价格→记渠道→标注数据时点
- **约束**: 须标数据来源与时点；估算值与实测值须分列
- **格式**: 市场解析表

#### DI3-04 评论与用户语料解析
- **必选组件**: 语料表（原文/情感/意图/场景/指向）、样本量与时间范围
- **可选组件**: 多平台评论、客服记录
- **组装顺序**: 取样→清洗→标注维度→统计→记样本边界
- **约束**: 须保留原文可回溯；须标样本量与时间范围
- **格式**: 语料解析表

#### DI3-05 合同条款解析
- **必选组件**: 条款表（类型/条款号/原文/要点）、主体信息表、缺失条款清单
- **可选组件**: 合同全文、附件
- **组装顺序**: 定位条款→分类→摘原文→记要点→标缺失
- **约束**: 须保留条款号与原文；不得改写法律表述
- **格式**: 合同解析表

#### DI3-06 法规与判例解析
- **必选组件**: 法规表（名称/条款/效力层级/生效日）、判例表（案号/法院/要旨）
- **可选组件**: 法规库、裁判文书
- **组装顺序**: 定效力层级→摘条款→记生效日→提裁判要旨
- **约束**: 须核验现行有效；判例须给案号
- **格式**: 法规判例解析表

#### DI3-07 简历与人事材料解析
- **必选组件**: 候选人字段表（含原文位置）、成果量化项、缺失项
- **可选组件**: 简历原文、附加材料
- **组装顺序**: 分段抽取→字段归位→量化成果→标缺失
- **约束**: 须保留原文位置；不得推断未写明信息
- **格式**: 简历解析表

#### DI3-08 试卷与学习材料解析
- **必选组件**: 题目表（知识点/层级/得分/错因）、知识点分布
- **可选组件**: 试卷、评分标准、答题卡
- **组装顺序**: 逐题标注→对评分标准→判错因→统计分布
- **约束**: 错因分类须互斥；须给原题与正确答案
- **格式**: 试卷解析表

#### DI3-09 代码与日志解析
- **必选组件**: 模块图、调用链、依赖清单、日志事件表（时间/级别/来源）
- **可选组件**: 源码仓库、日志文件
- **组装顺序**: 定位入口→追调用→抽依赖→解析日志→对齐时间线
- **约束**: 须给文件与行号；日志时区须统一
- **格式**: 代码日志解析表

#### DI3-10 医疗健康材料解析
- **必选组件**: 病历字段表、检验表（项目/值/参考区间/异常标记）、影像描述
- **可选组件**: 病历、检验报告、影像报告
- **组装顺序**: 分段抽取→字段归位→比对参考区间→标异常
- **约束**: 须保留原文；不得改写临床描述；须标参考区间来源
- **格式**: 医疗解析表

#### DI3-11 论文与文献结构解析
- **必选组件**: 十二要素表、关键数据、可复现性评估
- **可选组件**: 论文全文、补充材料
- **组装顺序**: 通读→逐要素提取→核对数据→评估可复现性
- **约束**: 须区分作者结论与数据支持范围
- **格式**: 论文解析卡

#### DI3-12 原始数据集解析
- **必选组件**: 字段概览表、缺失率表、分布特征、异常值清单
- **可选组件**: 数据字典、采集说明
- **组装顺序**: 读数据→判类型→算缺失→看分布→标异常
- **约束**: 异常值判定规则须说明；缺失处理方式须记录
- **格式**: 数据集概览表

### DI4 口径统一

#### 域级说明

**域定位**：让不同来源的数字变得可以放在一起看。这是研判中最容易被跳过、也最容易导致全盘结论错误的一步。

| 维度 | 内容 |
|------|------|
| 价值链形态 | 清单→政策调整→定义对齐→可比化→降级声明 |
| 独立成域的理由 | 域划分依据：口径不统一时所有对标无效。此阶段不产生新数据，只产生"调整说明"——形态与前后阶段都不同。 |
| 穷尽性 | 「清单→政策调整→定义对齐→可比化→降级声明」共 5 个环节，由 5 个任务展开（部分环节拆为多任务）；按输入物、失败模式、验收标准三条判据互不重叠，无未覆盖环节 |
| 知识要点 | 口径清单三要素：指标定义、计算公式、数据边界（含/不含什么）；会计政策调整四项：折旧方法、存货计价、研发资本化、收入确认；统计定义对齐：分母口径、样本范围、时间粒度、去重规则；期间可比化：会计年度差异、季节性、并购导致的并表范围变化；不可比事项处理：能调整则调整并留痕，不能调整则降级为"趋势参考"并声明 |
| 判定标准 | 每个跨来源比较的指标须有唯一定义；调整过程须留痕，可被复算；不可比事项不得强行比较；调整后须回验关键指标是否仍在合理区间 |
| 常见失范 | 直接拿两家的毛利率比，不看收入确认政策；同比跨了并表范围变化却不调整；分母口径不同还做比率对比；调整完不复验 |
| 范本结构 | 口径清单（指标/定义/公式/边界） → 调整说明表（原值/调整项/调整后） → 不可比事项清单 → 复验结果 |

#### DI4-01 口径清单建立
- **必选组件**: 口径清单（指标/定义/公式/数据边界/单位）
- **可选组件**: 指标使用场景、行业惯例
- **组装顺序**: 列指标→定定义→写公式→划边界→统一单位
- **约束**: 每个指标只能有一个定义；跨来源差异须单列
- **格式**: 口径清单

#### DI4-02 会计政策与计量调整

- **可选组件**: 附注中的政策说明、可比公司政策
- **组装顺序**: 识别差异→定调整规则→逐项调整→算影响→留痕

- **格式**: 会计调整表

#### DI4-03 统计定义对齐

- **可选组件**: 原始统计口径、采集说明

### DI5 指标加工

#### 域级说明

**域定位**：把字段算成能说明问题的数字，并让每个数字都能追溯到原材料。算错的指标比没有指标更危险。

| 维度 | 内容 |
|------|------|
| 价值链形态 | 选指标→计算→建模→固化→复核 |
| 独立成域的理由 | 域划分依据：口径定好后才能算。此阶段产出的是"数值与证据"，与解析阶段的"字段"、对标阶段的"偏离度"形态不同。 |
| 穷尽性 | 「选指标→计算→建模→固化→复核」共 5 个环节，由 6 个任务展开（部分环节拆为多任务）；按输入物、失败模式、验收标准三条判据互不重叠，无未覆盖环节 |
| 知识要点 | 指标体系三层：结果指标（ROE/转化率）、驱动指标（周转率/客单价）、先行指标（订单/线索）；财务指标：加权ROE、自由现金流、利息保障倍数、EVA、内生增长率；统计方法：描述统计、假设检验选择树、回归诊断（共线性/异方差/内生性）；评分模型：权重设定依据、归一化方法、分档阈值；证据固化：每个数值须附来源、公式、中间过程；敏感性检查：关键假设变动 ±10% 时结论是否翻转 |
| 判定标准 | 每个指标须给公式、输入值与来源；关键假设须做敏感性检查；计算结果须可被第三方复算；指标间逻辑冲突须标出（如净利增而现金流降） |
| 常见失范 | 只报结果不报公式；用不同分母算同一比率；不做敏感性就给点值；指标间矛盾不解释 |
| 范本结构 | 指标体系表（层级/指标/公式/来源） → 计算明细 → 敏感性分析表 → 指标间一致性检查 → 证据溯源表 |

- **格式**: 财务指标计算表

### DI6 对标识别

#### 域级说明

**域定位**：找出"哪里不对"。对标的价值不在比出高低，而在比出"不该这样"的地方。

| 维度 | 内容 |
|------|------|
| 价值链形态 | 定基准→时序→分位→阈值→量化 |
| 独立成域的理由 | 域划分依据：有数不等于有问题，须通过与基准比较才能识别异常。此阶段产出"偏离度"，是归因的输入。 |
| 穷尽性 | 「定基准→时序→分位→阈值→量化」共 5 个环节，由 6 个任务展开（部分环节拆为多任务）；按输入物、失败模式、验收标准三条判据互不重叠，无未覆盖环节 |
| 知识要点 | 三类基准：自身历史（同比环比）、同业（均值/分位）、绝对阈值（监管线/风控线）；分位法优于均值法：均值易被极值扭曲，分位能定位相对位置；红旗扫描：造假七项、合规红线、医疗危急值、代码安全漏洞；异常模式：单点突变、持续偏离、结构性变化（分布形态改变）；偏离度量化：标准差倍数、分位差、阈值超出幅度；假阳性控制：先排除口径差异与一次性因素再定性 |
| 判定标准 | 对标组须同口径同规模同细分；异常须给偏离量化值而非"偏高/偏低"；阈值须有来源（监管/行业/统计）；排除一次性因素后才可上升为异常 |
| 常见失范 | 拿不同规模公司直接比；只比一年不看趋势；阈值凭感觉定；把一次性收益当异常 |
| 范本结构 | 基准选定说明 → 三线对标表（历史/同业/阈值） → 异常清单（含偏离度） → 假阳性排除记录 → 异常排序 |

#### DI6-01 对标基准选定
- **必选组件**: 基准表（类型/对象/数据来源/可比性论证）
- **可选组件**: 口径清单、行业分类
- **组装顺序**: 定目的→选基准类型→选对标对象→论证可比性
- **约束**: 同业基准须同细分同规模；须说明可比性
- **格式**: 基准选定表

#### DI6-02 时间序列对比
- **必选组件**: 时序对比表、趋势线、季节性分解、拐点标记
- **可选组件**: 历史数据、口径清单
- **组装顺序**: 取序列→算同比环比→分解趋势→标拐点
- **约束**: 至少三年序列；拐点须标出原因
- **格式**: 时序对比表

#### DI6-03 同业分位与横向对标
- **必选组件**: 分位表（指标/自身值/行业分位/差距）、对标结论
- **可选组件**: 同业数据、分位数据
- **组装顺序**: 取同业样本→算分位→定位→算差距→结论
- **约束**: 须给样本量与分位来源；极值须剔除
- **格式**: 分位对标表

#### DI6-04 阈值与红旗扫描
- **必选组件**: 阈值表（项目/阈值/来源）、扫描结果、命中项清单
- **可选组件**: 监管线、风控规则、临床危急值
- **组装顺序**: 定阈值→逐项扫→记命中→标来源
- **约束**: 阈值须有出处；命中须给具体数值
- **格式**: 阈值扫描表

#### DI6-05 异常聚集与模式识别
- **必选组件**: 模式清单（类型/位置/证据）、聚集分析
- **可选组件**: 时序与分布数据
- **组装顺序**: 看单点→看持续性→看分布形态→归类模式
- **约束**: 须区分噪声与信号；模式须有统计支撑
- **格式**: 异常模式清单

#### DI6-06 偏离度量化与排序
- **必选组件**: 偏离度表（项目/基准值/实际值/偏离量/标准差倍数）、排序
- **可选组件**: 对标结果
- **组装顺序**: 算偏离量→标准化→排序→标最需关注项
- **约束**: 偏离度须同量纲可比；排序须说明依据
- **格式**: 偏离度排序表

### DI7 归因定性

#### 域级说明

**域定位**：回答"为什么会这样"。归因不到业务层，研判就只是报数；但归因过猛，又会把推测当结论。

| 维度 | 内容 |
|------|------|
| 价值链形态 | 假设→业务归因→反证检验→分级→并列 |
| 独立成域的理由 | 域划分依据：识别异常后必须解释成因，否则无法行动。此阶段产出"解释与等级"，与对标的"偏离度"不同。 |
| 穷尽性 | 「假设→业务归因→反证检验→分级→并列」共 5 个环节，由 5 个任务展开（部分环节拆为多任务）；按输入物、失败模式、验收标准三条判据互不重叠，无未覆盖环节 |
| 知识要点 | 归因三层：数据层（口径/录入/缺失）、业务层（量价/结构/效率）、环境层（行业/政策/季节）；归因假设生成法：差异分解（量价拆解）、同类对照、时间对齐、反事实推演；反证条件：每个归因须能说出"若成立，应还能观察到什么"；风险分级：高（影响决策且证据充分）/中（影响决策但证据不足）/低（不影响决策）；矛盾证据处理：并列呈现 + 标注各自支持度，不择一；相关与因果的区分：仅有共变不得称因果 |
| 判定标准 | 归因须落到业务动作，不得停在"管理不善"；每个归因须给反证条件；证据不足的归因须降级为"假设"；矛盾证据不得隐去 |
| 常见失范 | 把所有异常归因为"行业下行"；不做量价拆解直接下结论；把相关当因果；归因后不给验证方式 |
| 范本结构 | 归因假设清单 → 差异分解表（量/价/结构） → 证据支持度评估 → 反证条件与验证方式 → 风险分级结论 → 矛盾证据说明 |

#### DI7-01 归因假设生成
- **必选组件**: 假设清单（层次/内容/可验证性）、优先级
- **可选组件**: 异常清单、业务背景
- **组装顺序**: 列异常→按三层生成假设→评可验证性→排优先级
- **约束**: 假设须可验证；不得只给结论性解释
- **格式**: 归因假设清单

#### DI7-02 业务层归因
- **必选组件**: 量价拆解表、结构变化分析、效率指标对比、归因结论
- **可选组件**: 业务数据、口径清单
- **组装顺序**: 选分解法→拆量价→看结构→比效率→定成因
- **约束**: 须拆到可行动的业务动作；分解须闭合（加总等于总差异）
- **格式**: 业务归因表

#### DI7-03 反证条件检验
- **必选组件**: 反证条件表（归因/应观察到/实际观察到/是否成立）、结论调整
- **可选组件**: 验证数据
- **组装顺序**: 写反证条件→找验证数据→核对→定成立与否→调整结论
- **约束**: 无法验证的归因须标"未验证"；被推翻须撤回
- **格式**: 反证检验表

#### DI7-04 风险分级
- **必选组件**: 分级矩阵（影响×证据）、等级结论、处置建议
- **可选组件**: 风险偏好、监管要求
- **组装顺序**: 评影响→评证据→矩阵定位→定级→给处置
- **约束**: 高等级须给具体触发条件；不得只给定性形容词
- **格式**: 风险分级结论

#### DI7-05 矛盾证据并列呈现
- **必选组件**: 证据对照表（归因/支持证据/反对证据/强度）、未决说明
- **可选组件**: 全部验证记录
- **组装顺序**: 列支持→列反对→评强度→标未决
- **约束**: 不得择一隐去；未决项须显式保留
- **格式**: 证据对照表

### DI8 结论合成

#### 域级说明

**域定位**：把一堆分析收束成一句能被决策者直接使用的话，并说清这句话在什么条件下不成立。

| 维度 | 内容 |
|------|------|
| 价值链形态 | 结构化→置信度→区间→失效条件→成文 |
| 独立成域的理由 | 域划分依据：归因之后才能下判断。此阶段产出"判断+不确定性"，是全链唯一的对外交付物。 |
| 穷尽性 | 「结构化→置信度→区间→失效条件→成文」共 5 个环节，由 5 个任务展开（部分环节拆为多任务）；按输入物、失败模式、验收标准三条判据互不重叠，无未覆盖环节 |
| 知识要点 | 结论三要素：判断（是什么）、依据（凭什么）、边界（什么时候不成立）；置信度分级：高（多来源一致+反证未推翻）、中（单来源或反证未验）、低（推断为主）；结论区间优于点值：估值给区间、预测给区间、风险给等级；失效条件：列出会推翻该结论的具体观察；结论先行结构：先给判断，再给证据，最后给边界；盲区声明：硬缺口必须在结论中体现 |
| 判定标准 | 结论须可被一句话复述；每条结论须挂证据编号；置信度须显式标注；盲区与失效条件不得省略 |
| 常见失范 | 结论一大堆但没有主判断；结论与证据脱节；不给置信度，把推断说得和事实一样硬；隐藏盲区 |
| 范本结构 | 核心结论摘要（≤500字） → 结论清单（判断/依据/置信度/失效条件） → 证据索引 → 盲区与局限 → 建议关注项 |

#### DI8-01 结论结构化
- **必选组件**: 结论清单（判断/依据/置信度/边界）、主结论排序
- **可选组件**: 归因结果、证据表
- **组装顺序**: 提主判断→列支撑结论→挂证据→标置信度→排优先级
- **约束**: 每条结论须挂证据编号；主结论须唯一
- **格式**: 结论清单

#### DI8-02 置信度评估
- **必选组件**: 置信度表（结论/来源一致性/反证状态/等级）、降级说明
- **可选组件**: 交叉验证记录、反证检验表
- **组装顺序**: 查来源一致性→查反证状态→定等级→写降级理由
- **约束**: 推断类结论不得标"高"；降级须说明原因
- **格式**: 置信度评级表

#### DI8-03 结论区间与适用边界
- **必选组件**: 区间表（结论/下限/上限/依据）、适用边界、不适用情形
- **可选组件**: 敏感性分析、阈值表
- **组装顺序**: 定区间→给依据→写适用条件→列不适用情形
- **约束**: 不得给虚假精度；边界须可判定
- **格式**: 区间与边界说明

#### DI8-04 失效条件与盲区清单
- **必选组件**: 失效条件清单、盲区清单、监控建议
- **可选组件**: 完整性缺口、反证条件
- **组装顺序**: 列失效观察→列盲区→给监控方式
- **约束**: 失效条件须具体可观察；盲区不得省略
- **格式**: 失效与盲区清单

#### DI8-05 研判报告成文
- **必选组件**: 报告全文（摘要/结论/证据/归因/风险/盲区/附件）
- **可选组件**: 全部前序产出
- **组装顺序**: 写摘要→排结论→挂证据→述归因→列风险→标盲区
- **约束**: 结论须前置；证据须可回溯；图表须标来源
- **格式**: 研判报告

### DI9 预警追踪

#### 域级说明

**域定位**：把一次性结论变成可持续观察的规则，让研判在交付之后仍然有效。

| 维度 | 内容 |
|------|------|
| 价值链形态 | 指标→阈值→台账→复盘→响应 |
| 独立成域的理由 | 域划分依据：研判不止于交付，结论须被持续验证。此阶段产出"规则与台账"，是可运维的部分。 |
| 穷尽性 | 「指标→阈值→台账→复盘→响应」共 5 个环节，由 5 个任务展开（部分环节拆为多任务）；按输入物、失败模式、验收标准三条判据互不重叠，无未覆盖环节 |
| 知识要点 | 预警指标设计：领先指标优先于滞后指标，可观测优先于需调研；阈值三型：绝对阈值、相对阈值（偏离基线N倍）、趋势阈值（连续N期恶化）；观察台账：指标、频率、责任人、触发后动作；复盘节点：固定周期（月/季）+ 事件触发（结论失效条件命中）；预警分级：提示/关注/告警，对应不同响应时效；规则衰减：市场变化后旧阈值失效，须定期重校准 |
| 判定标准 | 每个预警须有明确阈值与触发动作；指标须可自动或低成本获取；复盘节点须写进台账；规则须有重校准机制 |
| 常见失范 | 设了一堆指标但没人看；阈值凭感觉定且从不校准；预警无对应动作；只设滞后指标 |
| 范本结构 | 预警指标表（指标/阈值/频率/来源） → 分级与响应规则 → 观察台账 → 复盘节点与校准机制 |

#### DI9-01 预警指标设计
- **必选组件**: 指标表（名称/类型/领先滞后/数据来源/获取成本）、筛选理由
- **可选组件**: 失效条件清单、盲区清单
- **组装顺序**: 取失效条件→反推指标→判领先性→评获取成本→定表
- **约束**: 须优先领先指标；获取成本过高须说明替代
- **格式**: 预警指标表

#### DI9-02 阈值与触发规则
- **必选组件**: 阈值表（指标/类型/阈值/依据）、触发规则、误报控制
- **可选组件**: 历史分布、监管线
- **组装顺序**: 定阈值类型→取历史分布→定阈值→写触发规则→设误报控制
- **约束**: 阈值须有依据；须设误报抑制
- **格式**: 阈值与规则表

#### DI9-03 观察台账建立
- **必选组件**: 台账模板（日期/指标/实测值/状态/动作）、责任人、更新频率
- **可选组件**: 团队分工
- **组装顺序**: 定字段→定频率→定责任人→建台账→试填
- **约束**: 每个指标须有责任人；更新频率须可执行
- **格式**: 观察台账

#### DI9-04 复盘节点与校准
- **必选组件**: 复盘计划（周期/触发条件/参与人/输出）、校准记录
- **可选组件**: 历史误报率
- **组装顺序**: 定周期→定事件触发→定输出→建校准记录
- **约束**: 须含阈值重校准；误报率高须调整规则
- **格式**: 复盘与校准计划

#### DI9-05 预警分级与响应
- **必选组件**: 分级表（级别/条件/响应动作/时效/责任人）、升级路径
- **可选组件**: 风险偏好、应急流程
- **组装顺序**: 定级别→定条件→配动作→定时效→定升级路径
- **约束**: 每级须有明确动作；告警级须有人工确认
- **格式**: 预警响应手册
