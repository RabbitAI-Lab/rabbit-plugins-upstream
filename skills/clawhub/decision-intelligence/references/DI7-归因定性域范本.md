## DI7 归因定性域范本

### 一、领域知识要点

- 归因三层：数据层（口径/录入/缺失）、业务层（量价/结构/效率）、环境层（行业/政策/季节）
- 归因假设生成法：差异分解（量价拆解）、同类对照、时间对齐、反事实推演
- 反证条件：每个归因须能说出"若成立，应还能观察到什么"
- 风险分级：高（影响决策且证据充分）/中（影响决策但证据不足）/低（不影响决策）
- 矛盾证据处理：并列呈现 + 标注各自支持度，不择一
- 相关与因果的区分：仅有共变不得称因果

### 二、判定标准

- 归因须落到业务动作，不得停在"管理不善"
- 每个归因须给反证条件
- 证据不足的归因须降级为"假设"
- 矛盾证据不得隐去

### 三、范本结构

1. 归因假设清单
2. 差异分解表（量/价/结构）
3. 证据支持度评估
4. 反证条件与验证方式
5. 风险分级结论
6. 矛盾证据说明

### 四、常见失范

- 把所有异常归因为"行业下行"
- 不做量价拆解直接下结论
- 把相关当因果
- 归因后不给验证方式

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 假设清单（层次/内容/可验证性）、优先级 |
| 本域产出 | 归因假设清单；业务归因表；反证检验表；风险分级结论；证据对照表 |
| 下游可用 | 证据对照表 |

### 六、交付自检

交付前逐项打勾，任一项不成立即返工：

- [ ] 归因须落到业务动作，不得停在"管理不善"
- [ ] 每个归因须给反证条件
- [ ] 证据不足的归因须降级为"假设"
- [ ] 矛盾证据不得隐去

同时排除以下失范：

- [ ] 已排除：把所有异常归因为"行业下行"
- [ ] 已排除：不做量价拆解直接下结论
- [ ] 已排除：把相关当因果
- [ ] 已排除：归因后不给验证方式

### 七、执行卡（以「归因假设生成」为例）

**开工前备齐**：假设清单（层次/内容/可验证性）、优先级

**可选补充**：异常清单、业务背景

**按序执行**：

1. 列异常
2. 按三层生成假设
3. 评可验证性
4. 排优先级

**交付前核对**：假设须可验证；不得只给结论性解释

**成品须符合**：归因假设清单

### 八、成品骨架

按「归因假设清单」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 归因假设清单

## 1. 归因假设清单
## 2. 差异分解表（量/价/结构）
## 3. 证据支持度评估
## 4. 反证条件与验证方式
## 5. 风险分级结论
## 6. 矛盾证据说明
```

**齐备要求**：必选组件「假设清单（层次/内容/可验证性）、优先级」须全部落位；约束「假设须可验证；不得只给结论性解释」须逐条成立；可选「异常清单、业务背景」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
