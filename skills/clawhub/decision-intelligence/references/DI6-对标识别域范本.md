## DI6 对标识别域范本

### 一、领域知识要点

- 三类基准：自身历史（同比环比）、同业（均值/分位）、绝对阈值（监管线/风控线）
- 分位法优于均值法：均值易被极值扭曲，分位能定位相对位置
- 红旗扫描：造假七项、合规红线、医疗危急值、代码安全漏洞
- 异常模式：单点突变、持续偏离、结构性变化（分布形态改变）
- 偏离度量化：标准差倍数、分位差、阈值超出幅度
- 假阳性控制：先排除口径差异与一次性因素再定性

### 二、判定标准

- 对标组须同口径同规模同细分
- 异常须给偏离量化值而非"偏高/偏低"
- 阈值须有来源（监管/行业/统计）
- 排除一次性因素后才可上升为异常

### 三、范本结构

1. 基准选定说明
2. 三线对标表（历史/同业/阈值）
3. 异常清单（含偏离度）
4. 假阳性排除记录
5. 异常排序

### 四、常见失范

- 拿不同规模公司直接比
- 只比一年不看趋势
- 阈值凭感觉定
- 把一次性收益当异常

### 七、执行卡（以「对标基准选定」为例）

**开工前备齐**：基准表（类型/对象/数据来源/可比性论证）

**可选补充**：口径清单、行业分类

**按序执行**：

1. 定目的
2. 选基准类型
3. 选对标对象
4. 论证可比性

**交付前核对**：同业基准须同细分同规模；须说明可比性

**成品须符合**：基准选定表

### 八、成品骨架

按「基准选定表」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 基准选定表

## 1. 基准选定说明
## 2. 三线对标表（历史/同业/阈值）
## 3. 异常清单（含偏离度）
## 4. 假阳性排除记录
## 5. 异常排序
```

**齐备要求**：必选组件「基准表（类型/对象/数据来源/可比性论证）」须全部落位；约束「同业基准须同细分同规模；须说明可比性」须逐条成立；可选「口径清单、行业分类」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
