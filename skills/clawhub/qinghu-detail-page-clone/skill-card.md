## Description:

Helps sellers create product-detail images inspired by a reference page's layout and visual style using their own product photos and copy.

This skill is ready for commercial/non-commercial use.

## Publisher:

[autoagc](https://clawhub.ai/user/autoagc)

### License/Terms of Use:

MIT-0

## Use Case:

Sellers and designers use reference screenshots and their own product images and copy to generate similarly styled e-commerce detail-page images, one screen at a time or as a quick set.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installing a third-party tool and supplying an API token exposes the user to package and credential risks.

Mitigation: Install qhkit only if you trust its npm package; obtain the token from the intended service and keep it private.

Risk: Product and reference images are uploaded to an external image-generation service.

Mitigation: Upload only images you have permission to share with the service.

Risk: Imitating a competitor's design can reproduce protected branding, artwork, or distinctive trade dress.

Mitigation: Borrow general layout and style only; replace copy and exclude the reference seller's logos, branding, and protected artwork.
