# 法律合同风险点核查

## Overview

对合同文本做系统性风险扫描：必备条款有没有、现有条款有没有坑、怎么改。输出可直接拿去谈判的核查表。

**免责声明**：本技能提供的是通用商业合同审查辅助，不构成法律意见。涉及重大金额、跨境、强监管或诉讼风险的合同，务必在结尾提示用户交由执业律师复核。

## When to use

- 用户贴合同文本要审条款、找风险。
- 用户问「这份合同能不能签」「有什么坑」「对方给的合同怎么改」。
- 用户要查漏必备条款。

## Workflow

1. **识别合同类型与角色**：买卖 / 服务 / 租赁 / 劳动 / 技术开发 / 保密协议等，并确认用户是甲方还是乙方（风险立场完全不同）。
2. **通读全文**，按下方必备条款清单逐项核对是否覆盖。
3. **标注缺失条款**：没写的直接进「缺失清单」，说明缺了会怎样。
4. **风险分级**：存在风险的条款按 高 / 中 / 低 分级，每条写明原条款位置与主要问题。
5. **给出可落地的修改建议**：不只说「不利」，要给出可替换的规范表述。
6. **输出核查表 + 谈判优先级建议**。

## 必备条款核查清单

- 合同主体：全称、统一社会信用代码、地址、授权代表（主体写错可能导致追责落空）
- 标的条款：品名 / 服务内容、规格、数量、质量标准（写不清就认定对你不利）
- 金额与支付：单价、总价、币种、税率、发票类型、付款节点与账期
- 交付与验收：交付时间地点方式、验收标准与期限、逾期未验收视为通过的条款
- 履行期限：起止时间、延期处理
- 违约责任：违约情形、违约金比例、损失赔偿上限、定金 / 迟延履行条款
- 知识产权：成果归属、背景知识产权、第三方侵权兜底
- 保密条款：范围、期限、例外情形、违约救济
- 不可抗力：范围界定、通知义务、后果（延期 / 解除）
- 反商业贿赂与合规（视情形）
- 争议解决：管辖法院 / 仲裁机构（仲裁一裁终局、成本更高）
- 合同变更与解除：条件、程序、提前通知期
- 终止后义务：结算、资料返还、保密延续

## 高风险信号（重点扫）

- 违约责任严重不对等，或只约束己方
- 违约金过高（可能被调低）或过低（无威慑），缺乏损失赔偿衔接
- 验收标准主观化，如「达到甲方满意」「视甲方需求」
- 付款节点与交付节点脱节，如全款预付或验收后超长账期
- 争议管辖约定在对方所在地且明显不便
- 知识产权归属模糊，委托开发成果默认归对方
- 保密期限过长或范围无限扩张
- 自动续约且未设退出窗口
- 免责条款过宽，覆盖对方故意或重大过失
- 关键义务缺乏时间约束（无「X 日内」）
- 允许对方单方变更条款而无对等机制

## 输出模板

```
## 合同概览
- 类型：…  我方身份：甲方 / 乙方  金额量级：…

## 风险总评
- 总体建议：可直接签 / 建议修改后签 / 强烈建议律师介入
- 高风险 X 条｜中风险 Y 条｜缺失条款 Z 项

## 风险条款清单
| # | 条款位置 | 原文摘要 | 风险等级 | 问题 | 修改建议 |
|---|----------|----------|----------|------|----------|

## 缺失必备条款
| # | 缺失条款 | 潜在风险 | 建议补上的表述 |
|---|----------|----------|----------------|

## 谈判优先级
1. 必争：…
2. 争取：…
3. 可接受：…

## 免责说明
本核查为通用商业审查辅助，不构成法律意见…
```

## 关键规则

- **先定立场**：同一条款对甲方是保护、对乙方可能是风险，务必先确认用户角色。
- **引用原文位置**：每条风险要能定位到原文（条款号 / 段落），便于用户核对。
- **给可执行表述**：修改建议要写成可以直接替换的句子，不要只说「建议明确约定」。
- **标注不确定**：文本不全、扫描缺页、引用附件未提供的，明确说无法判断，不猜测。
- **结尾必提醒**：重大金额 / 跨境 / 特殊行业合同建议执业律师复核。
