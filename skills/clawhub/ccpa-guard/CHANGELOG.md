# 更新日志

本项目遵循语义化版本（SemVer）。

## [1.0.0] - 2026-07-29

首个版本。CCPA 护栏系列。

### 新增
- CCPA 规则包 `ccpa`（自包含，不继承 common）：US SSN、加州驾照、加州 ID、US 电话（NANPA）、信用卡（Luhn）等 US/CA 个人数据格式
- 关键词线索覆盖 CCPA 全部 11 类个人信息分类（CCPA § 1798.140）及 CPRA 敏感个人信息
- 三种动作：detect / mask / block，重叠命中去重
- 纯本地运行，零网络、零动态执行、零外部依赖

### 安全
- 无 eval / exec / 动态 import，规则通过显式映射加载
- 检测结果不回传敏感原文，仅提供脱敏预览
