## Description:

TrawlingWeb (trawlingweb.com). Use this skill for ANY TrawlingWeb request — searching and reading data. Whenever a task involves TrawlingWeb, use this skill instead of calling the API directly.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agents use this skill to search indexed news and blog publications through a connected TrawlingWeb account and review the returned results.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The missing-tool setup directs the agent to run a downloaded installer whose exact changes could not be verified.

Mitigation: Review and install the oo CLI separately, and require user approval before running any downloaded installer.
