## Description:

Guides creators and marketing teams in drafting TikTok video scripts with spoken hooks, timed beats, on-screen text, captions, and disclosure or licensing flags.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External creators, US consumer brands, and agencies use this skill to shape campaign briefs into TikTok script outlines with hooks, timed beats, on-screen copy, captions, and reminders about disclosures, music rights, and releases.

### Deployment Geography for Use:

United States

## Known Risks and Mitigations:

Risk: The workflow does not automatically verify caption length, disclosures, or other platform requirements.

Mitigation: Manually check the finished script against current platform limits and disclosure requirements before publishing.

Risk: Running the script overwrites an existing digest.md in the chosen output directory.

Mitigation: Choose a fresh output directory or back up any existing digest.md first.

Risk: The optional Windows toolkit is an unsigned executable and its safety is not established by this skill review.

Mitigation: Treat it as a separate software decision; independently verify its source and hash, and run it only if you trust it.
