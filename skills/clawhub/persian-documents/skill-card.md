## Description:

Generate production-quality Persian documents with correct RTL layout, bidirectional text handling, and professional typography.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ehsanghaffar](https://clawhub.ai/user/ehsanghaffar)

### License/Terms of Use:

MIT-0

## Use Case:

Writers and developers use this skill to create Persian reports, letters, and technical documents in DOCX, PDF, or Markdown while preserving right-to-left layout and mixed Persian/English text.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Mixed-direction text, tables, or fonts may render incorrectly in the final document.

Mitigation: Inspect the generated document and check RTL flow, English text, numbers, tables, and glyphs before sharing.

Risk: Users may expect automatic repair of arbitrary existing documents.

Mitigation: Use the skill for generation and validation; review source content and regenerate documents when correction is needed.
