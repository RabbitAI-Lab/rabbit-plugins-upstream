## Description: <br>
Master the JMPY.me ecosystem for professional URL shortening, advanced QR code generation, branded domain management, and deep marketing analytics. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External marketing teams, analysts, and developers use this skill to manage JMPY.me short links, QR codes, branded domains, campaigns, subscriptions, and analytics through an AI agent connected to their JMPY.me account. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill requires a JMPY API key and can access account-linked marketing data. <br>
Mitigation: Install it only for intended JMPY.me account use, store the API key as a secret, and rotate it if exposure is suspected. <br>
Risk: Deleting URLs, QR codes, or campaigns can remove marketing assets. <br>
Mitigation: Require explicit user confirmation before destructive actions. <br>
Risk: Changing aliases, subdomains, or branded domains can break already shared links. <br>
Mitigation: Warn users that existing shared links may stop working and proceed only after clear consent. <br>
