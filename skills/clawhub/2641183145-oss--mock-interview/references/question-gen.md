# 出题

**默认深挖用户自己的经历,不出通用题。** "讲讲你怎么跟同事相处"这类题在这里是失败输出 —— 只在 `sparse` 档兜底时才允许。

出题标准和评分标准同源:题目要往 rubric 拿高分需要的地方戳。

## 五个考察点

从 rubric 反推出来的,一题一个:

| competency | 问什么 | 对应维度 |
|---|---|---|
| `决策点` | 为什么选 A 不选 B,当时还有什么选项 | Substance / Differentiation |
| `量化口径` | 效果怎么衡量的,数字怎么来的 | Substance |
| `贡献边界` | 团队做的这件事,你具体哪部分 | Credibility |
| `返工点` | 哪一步判断错了,怎么发现,怎么改 | Credibility / Structure |
| `技术细节` | 具体怎么实现的(防简历注水) | Credibility |

`rich` 档尽量五个考察点各一题,雷达图才有区分度,瓶颈诊断才不是瞎猜。

## 按密度分配

**`rich`** — 主线经历(最有料的那段)出 3 题,次线出 2 题。

**`moderate`** — 唯一那段实质经历出 3 题,项目出 1 题,动机题 1 题(为什么这个岗位/方向,`competency` 记 `动机`)。

**`sparse`** — 最好的项目挖 2 题(优先 `贡献边界` 和 `技术细节`,这两个课程项目也答得出来),另外 3 题用通用题,`is_generic: true`。

通用题也别用最烂的那种。可以用:
- 讲一次你判断错了、后来改过来的事
- 你做过的哪件事,是你觉得别人接手会做得不一样的
- 你最近主动学的东西是什么,为什么学它

比"你的优缺点是什么"强得多,而且仍然能打 5 个维度。

## 三个硬要求

**1. `source_quote` 必须是用户原话。** 从 `raw_material` 里摘,不能改写、不能润色。用户看到自己的话被引用,才会觉得这题是针对他的。

通用题 `source_quote` 填 `null`。

**2. 题干里要带上引用。** 

好:
> 你说独立负责了订单服务的缓存层重构。当时为什么要重构,不重构会怎样?

坏:
> 请讲述一次你进行技术重构的经历。

后者把深挖题退化成了题库题。

**3. `probes` 给 2-3 条,指向 rubric 的加分点。**

probes 不是子问题,是提示。用户照着说,自然就把量化和权衡说出来了 —— 不至于答完发现全是 2 分,那样出的分对他没帮助。

```json
"probes": [
  "重构前具体是什么问题,怎么发现的",
  "考虑过哪些方案,最后为什么选这个",
  "效果怎么衡量的,有数据吗"
]
```

第二条对应 Substance 4→5 分,第三条对应 3→4 分。**每条 probe 都该有它想撬动的维度**,别写"请详细说明"这种空话。

## 别做的事

**别问用户没提过的东西。** 他没说过做性能优化,就不能问"你怎么做性能优化的"。题目只能从 `raw_material` 里长出来。

**别在一题里塞两个问题。** "为什么重构,以及效果怎么样" —— 用户会只答一半,然后 Relevance 被扣分,冤。想要第二问就放 probes。

**别按简历顺序出题。** 挑最有深挖价值的,不是最近的。

**五题别全砸在一段经历上**(除非只有一段)。全砸一处的话,用户在那段上的短板会重复扣分五次,瓶颈诊断就失真了。

## 输出

生成后写进 `data/session.json`,`status` 置 `awaiting_answers`:

```json
{
  "session_id": "20260827-143022",
  "status": "awaiting_answers",
  "context": {
    "target_role": "后端开发实习",
    "seniority": "本科应届",
    "experience_density": "rich",
    "density_note": null
  },
  "questions": [
    {
      "id": "q1",
      "text": "你说独立负责了订单服务的缓存层重构。当时为什么要重构,不重构会怎样?",
      "competency": "决策点",
      "source_quote": "独立负责订单服务的缓存层重构",
      "probes": ["...", "...", "..."],
      "is_generic": false
    }
  ],
  "answers": [],
  "scores": null,
  "raw_material": { }
}
```

`id` 固定 `q1`-`q5`。写完告诉用户去开页面,并说明"答完 5 题页面会自己结束,然后回来找我看分"。
