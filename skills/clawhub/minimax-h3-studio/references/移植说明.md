# 移植说明

把 minimax-h3-studio 整个目录放入目标智能体的技能目录，或让支持本地文件的智能体读取 SKILL.md。不得只复制入口而遗漏 references/。所有内部引用均相对路径，目录名保持不变。

- 必需：可读取 Markdown 和文本文件的智能体。提示词编写不需网络、Python、Codex、MiniMax Hub 或其他 Skill。
- 可选：agents/openai.yaml 是 Codex 界面元数据，不是运行依赖。
- 图片、视频、配乐与剪辑：按目标环境检查工具并映射原版能力，缺少服务不影响纯提示词输出。
- 输出：中文正文、中文结构、独立角色块。官方原文仅供核验，不作为额外独立 Skill 自动安装。
- 接口：保留用户可编辑中文稿；仅在确有接口要求时生成提交适配稿。中文标题不是接口 JSON 参数，不能据此承诺生成兼容性。
- 字幕：如需识别优先使用 DashScope Paraformer；缺少工具时说明，不自行改用 Whisper。

旧 minimax-h3-video-prompt 和 3d-animation-short-generator 兼容入口不属于迁移必需文件，统一包可独立使用。
