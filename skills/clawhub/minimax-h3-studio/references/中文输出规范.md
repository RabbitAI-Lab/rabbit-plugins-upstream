# 中文输出规范与模板

## 来源与命名边界

2026-09-07 核对 MiniMax 官方 [GitHub 提示词 Skill](https://github.com/MiniMax-AI/MiniMax-H3/blob/main/skills/h3-prompt-writing/SKILL.md) 及 [Hugging Face 官方指南目录](https://huggingface.co/MiniMaxAI/MiniMax-H3/tree/main/docs)。核对范围内仅找到英文基础与全能参考指南；未找到官方中文字段规范。以下为本 Skill 依据官方含义采用的中文译名，并非官方发布的中文协议。尚未进行中英标题的模型效果对照测试。

| 官方原字段 | 本 Skill 中文标题 | 内容 |
| --- | --- | --- |
| integrated_multimodal_description | 综合多模态描述 | 按时间顺序组织画面、动作、运镜、对白与同步声音 |
| overall_soundscape | 整体声景 | 环境声、物理动作声及非语言发声 |
| non_diegetic_music | 画外配乐 | 仅观众听到、角色听不到的配乐 |
| subject_definitions | 参考内容定义 | 实际参考素材及其可复用内容、来源和用途 |
| summary | 任务概述 | 目标视频及实际参考关系 |
| retention_analysis | 参考内容保留说明 | 参考内容保留、修改、转移或复用的方式 |
| detailed_description | 详细分镜描述 | 全能参考任务的逐镜音画执行描述 |

「画外配乐」不包括画外人物说话，也不包括场景里的收音机或角色演奏；这些写进当前镜头。无配乐写「无」。角色不说话时不要编造台词。正文、标题、切镜句和运镜语言均为中文；用户锁定的外语原文、品牌专名和指定语言除外。

## 独立角色块

输出一个角色设定块和一个视频提示词块，两者一起构成完整提示词。每个角色一项，使用稳定名称；多人不共享一段模糊设定。角色已由用户命名时沿用其名称。没有角色的产品、场景任务省略角色块。

```yaml
角色设定:
  角色一（小女孩）: |
    约7岁，栗棕色短卷发，黄色蝴蝶结，暖棕色眼睛。
    浅黄色背带裙、白色短袖、红色运动鞋，身形小巧，活泼好奇。
  角色二（小怪兽）: |
    比小女孩矮半个头，淡紫色短绒毛，奶油色椭圆肚皮。
    两只奶油色圆钝短角，短腿圆脚，短翘尾巴，温柔憨厚。
```

不重复在每镜粘贴整套外形，只在必要时补充当前可见特征、位置、动作和状态；不得出现与角色块冲突的服装、毛色或体型。修改角色块后检查镜头中的手部互动、相对身高、道具使用和声音是否仍成立。

## 基础文生视频模板

```yaml
综合多模态描述: |
  【镜头一】温暖的三维卡通动画，16:9横屏，总时长8秒。
  沿用前面独立角色设定，全片保持身份、服装、毛色和体型比例一致。
  小女孩在画面左侧，小怪兽在右侧，坐在相邻的旋转木马上。
  镜头平稳侧向跟拍，两人随木马上下起伏，相视而笑。
  【镜头二】在第4秒，镜头切换至旋转茶杯内的双人近景。
  两人稳坐在同一只茶杯里，握住中央转盘一起推转，随着茶杯旋转笑起来。
整体声景: |
  轻柔的人群声、设施机械声和两位角色自然的笑声。
画外配乐: |
  轻快木管与拨弦弦乐，结尾落在明亮和弦上。
```

首镜不加切点，后续时间递增且小于总时长。写明镜头间道具、姿态、空间和声音的衔接。只要提示词就交付角色块与视频块，不强制生成角色图或执行完整制作流程。

## 首帧、尾帧与全能参考

关键帧任务在中文正文前写独立的「关键帧对应关系」，说明实际图片与首帧、尾帧及精确时刻的关系。例如「图片一对应0.00秒首帧；图片二对应8.00秒尾帧」。不把身份参考图误当首帧。需机器提交时由适配层恢复官方对齐句式。

全能参考仅用于确有图片、视频或音频素材的任务。角色块仍独立；然后按顺序输出：

```yaml
参考内容定义: |
  按实际素材逐项定义角色、场景、关键帧、源视频或音轨的来源与用途。
任务概述: |
  说明目标成片及实际参考关系，例如参考生成、视频编辑或音频复用。
参考内容保留说明: |
  按素材说明完全保留、部分保留、属性迁移、弱参考或音频复制范围。
详细分镜描述: |
  先描述风格，再按【镜头一】及后续中文切点描述音画。
整体声景: |
  环境声音与音效；涉及原音轨时明确复用范围。
画外配乐: |
  乐器、节奏和动态变化；没有则写无。
```

中文阅读稿可用「角色一」「图片一」「视频一」「音频一」，来源映射保持唯一一致。实际接口若要求 `<Subject 1>`、`<Picture 1>`、`<Video 1>`、`<Audio 1>`、`<d>` 等标签，仅在提交适配层根据已核实的接口转换，不伪造资产。原始语法详见同包内 H3 提示词模块的英文参考。
