# H3 提示词编写

先读 [统一中文规范](../中文输出规范.md)。所有用户可见提示词使用中文结构和正文；有角色时逐个输出独立角色设定，再写视频提示词。用户锁定的原文和指定语言保留。

## 判断模式

- 无参考素材：文生视频（T2VA）。独立角色描述不改变模式。
- 指定首帧：首帧图生视频（I2VA）。
- 指定首尾帧：首尾帧生成（FL2VA）。
- 仅指定尾帧：尾帧生成（L2VA）。
- 图片、视频或音频提供身份、风格、动作、编辑或复用依据：全能参考（Ref2VA）。

基础模式按「综合多模态描述、整体声景、画外配乐」组织。全能参考按「参考内容定义、任务概述、参考内容保留说明、详细分镜描述、整体声景、画外配乐」组织。完整模板、关键帧对应关系与角色块见统一中文规范。

## 内容检查

逐镜写清构图、主体、环境、动作、运镜、声音和状态变化。保留对白原文；不擅自转为字幕或新增品牌、情节和文字。首镜不加切点，后续切点递增且不超时长。环境声音与仅观众听到的配乐分开。

角色设定与分镜分别维护，镜头通过稳定角色名称引用。交付时说明角色块和视频块一起复制；已提供角色图时只描述有证据的特征，并按用户要求改编。

## 官方语法资料

[官方基础指南](references/base-en.txt) 与 [官方全能参考指南](references/ref-en.txt) 用于核查语义、字段顺序、素材标签和机器提交格式。其英文输出要求不覆盖本 Skill 的中文交付约定。若实际接口需要英文字段或标签，只在提交层转换，不把中文译名说成官方 API。

只要提示词时给出简短中文模式说明和可复制的角色块、视频块；无角色则只给视频块。不擅自扩展为图片或视频生成。
