## Description:

MiniMax H3 Studio is a Chinese-first creative workflow pack for H3 prompt writing, 3D animation shorts, product and brand videos, music videos, game intros, explainer styles, and hand-drawn live-action fusion.

This skill is ready for commercial/non-commercial use.

## Use Case:

External creators, developers, and agent users use this skill to draft Chinese MiniMax H3 prompts, production plans, shot structures, role descriptions, and delivery checks for multiple video-creation workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill defaults to Chinese-facing MiniMax H3 workflows, which may not match every target language, model, or interface requirement.

Mitigation: Confirm the intended model, language, interface constraints, and whether Chinese prompt titles need adaptation before submitting prompts to a service.

Risk: Media generation can involve external providers, uploaded assets, and cost-bearing actions outside the skill package.

Mitigation: Confirm the provider, budget, source assets, and available image, video, audio, or editing tools before attempting generation or composition.

Risk: Broad replies such as continue can be mistaken for approval during multi-step creative workflows.

Mitigation: Use explicit approval gates for high-impact steps and clarify whether general continuation responses authorize generation, retries, or paid calls.

Risk: Installing the skill does not install models, create API access, or guarantee generated media output.

Mitigation: When tools or services are missing, provide prompts, plans, shot tables, and asset lists, and clearly state which generation or composition steps were not executed.
