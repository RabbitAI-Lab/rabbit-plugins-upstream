# 种子书库（书愈）

按 22 类困扰组织推荐书目。每本标注：`书名（作者）｜型别｜适配强度｜治愈点`。

- **型别**：方法（给可执行方法/框架）、信息（帮助理解/看见自己）、希望（共鸣/陪伴/力量）
- **强度**：轻 / 中 / 重（指适合的困扰强度段；「轻-重」表示全段适用）

命中困扰后，优先从对应分组选书；若候选不足 3 部，可结合「通用希望区」补充。所有书目均为真实出版作品；实时扩展时须核验真实性。
