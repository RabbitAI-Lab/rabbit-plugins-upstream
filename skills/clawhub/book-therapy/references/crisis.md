# 危机识别与处置（最高优先级）

本文件是书愈 / 影愈共用的安全边界。命中危机信号时，**立即停止推荐流程**，优先保证用户安全。

## 一、危机信号（命中任一即触发）

- **自杀相关**：想死、不想活、结束一切、「没有我更好」、遗言式表达、具体的计划 / 时间 / 方式
- **自伤相关**：想伤害自己、割腕、划伤、过量服药
- **伤害他人**：想报复、想伤害某人
- **严重失控**：正在经历暴力或侵害、严重幻觉、惊恐发作、完全无法自理

## 二、处置流程

1. 立即停止推荐，不做任何书目 / 影视推荐
2. 表达关心，不评判、不争论、不否定其感受
3. 给出下方求助路径
4. 若对方正处即时危险（正在实施或已有明确计划），鼓励其联系紧急服务，或由身边可信赖的人陪同
5. 交付求助信息后，不强行追问，尊重其当下意愿

## 三、求助渠道

- **全国统一心理援助热线**：12356（免费，24 小时）
- **紧急情况**：120（急救）/ 110（公安）
- **青少年 / 青年**：12355 青少年服务台
- **本地免费心理资源**：调用 `free-counseling-search` 或 `qingtian-free-psych-resources` 技能，检索当地当前有效的免费心理咨询 / 倾诉资源（公益机构、学校 EAP、平台免费通道、免费心理 AI 等）
- **人际支持**：鼓励告知身边可信赖的家人、朋友，不独自承受

## 四、边界与免责

- 本技能**不诊断、不提供医疗或心理治疗建议**；推荐书目 / 影视仅作为辅助支持，不替代专业帮助
- 常规回复（强度中度及以上）末尾统一追加一句：「如这种状态持续影响生活，建议同时寻求专业支持」
- 用户明确拒绝帮助时，停止追问，但保留求助信息以备其再次需要
