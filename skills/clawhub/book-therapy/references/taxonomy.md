# 困扰分类学（书愈 / 影愈共用）

22 类困扰：12 类精神困扰 + 10 类现实困扰。书愈与影愈共用同一套分类学，保证跨技能识别一致。

## 使用方式

- 从用户描述中提取线索 → 命中 1–3 类
- 每类给出强度分级：轻 / 中 / 重
- 多类并存时，按"用户当前最在意的"排序，最多保留 3 类

## 强度分级

| 级别 | 判断标准 |
|---|---|
| 轻 | 情绪波动，日常生活基本不受影响 |
| 中 | 明显影响情绪 / 效率 / 睡眠 / 关系，持续数周 |
| 重 | 工作 / 学业 / 社交功能受损，或情绪长期持续 |
| 危机 | 命中 `crisis.md` 信号（自伤 / 自杀等），立即转危机分支，不做推荐 |

强度由"持续时间 + 功能影响 + 表达强度"综合判断。

## 精神困扰（12 类）

### 1. 焦虑 / 担忧
- 线索：焦虑、担心、紧张、害怕发生、坐立不安、想太多、胡思乱想、心慌、恐慌、担心未来、怕做不好
- 典型表达：「最近特别焦虑」「总是担心出事」「脑子停不下来」

### 2. 抑郁 / 情绪低落
- 线索：低落、没意思、提不起劲、不想动、空虚、麻木、哭不出来、兴趣丧失、感觉不到快乐、早醒后心情差
- 典型表达：「做什么都没意思」「感觉被抽空了」

### 3. 孤独 / 疏离
- 线索：一个人、没人懂、格格不入、想找人说话、被孤立、社交后更空虚、独居、异地
- 典型表达：「感觉跟世界隔着一层」

### 4. 迷茫 / 无意义感
- 线索：不知道要干嘛、没方向、人生意义、活着为了什么、空虚、价值感缺失、什么都提不起兴趣
- 典型表达：「不知道人生的意义是什么」

### 5. 压力 / 倦怠
- 线索：好累、扛不住、加班、耗竭、burnout、喘不过气、休息不过来、琐事压身
- 典型表达：「感觉被掏空了」「压力好大撑不住」

### 6. 失眠 / 睡眠困扰
- 线索：睡不着、入睡难、早醒、睡眠浅、躺下脑子转、多梦、越累越睡不着
- 典型表达：「一躺下就开始想事情」

### 7. 低自尊 / 自我怀疑
- 线索：我不行、配不上、觉得自己很差、冒名顶替、不敢争取、怕被否定、过度比较
- 典型表达：「我是不是真的不行」

### 8. 悲伤 / 丧失
- 线索：失去、去世、分手、离别、想念、告别、遗憾、宠物走了、丢了工作 / 健康
- 典型表达：「刚失去了重要的人」

### 9. 愤怒 / 烦躁
- 线索：生气、暴躁、易怒、忍不了、想发火、委屈、不平、被冒犯
- 典型表达：「一点就着」「憋着一肚子火」

### 10. 恐惧 / 不安
- 线索：害怕、恐惧、不安、对未知的怕、怕失败、怕被评价、怕变化、怕独处
- 典型表达：「一想到未来就害怕」

### 11. 完美主义 / 自我苛责
- 线索：必须做好、不能犯错、责怪自己、标准太高、追求完美、不敢交付不完美结果
- 典型表达：「接受不了自己犯错」

### 12. 拖延 / 动力不足
- 线索：拖、不想开始、没动力、deadline、拖延到最后一刻、开始了又放下
- 典型表达：「明明知道该做却一直拖」

## 现实困扰（10 类）

### 13. 职场困境
- 线索：失业、求职、被裁、转行、职场人际、晋升受阻、领导关系、工作与生活失衡、35 岁焦虑

### 14. 学业压力
- 线索：考试、毕业论文、挂科、选专业、升学、学业竞争、导师关系

### 15. 财务困境
- 线索：负债、收入不够、消费失控、存不下钱、理财焦虑、不敢花钱

### 16. 情感关系
- 线索：失恋、单恋、争吵、信任危机、异地、恐婚、暧昧不清、分手后走不出

### 17. 家庭关系
- 线索：亲子冲突、代际矛盾、原生家庭、赡养压力、家人不理解、过年回家焦虑

### 18. 健康困扰
- 线索：生病、慢性病、康复、照顾病患、身体预警、身材焦虑、疑病

### 19. 人生阶段转型
- 线索：毕业、入职、婚育、空巢、中年危机、退休、移居 / 移民、适应新城市

### 20. 社交与人际
- 线索：社恐、交友难、融入新环境、被排斥、不会拒绝、边界感

### 21. 意义与职业选择
- 线索：要不要辞职、选哪条路、职业没价值、想做喜欢的事、纠结去留

### 22. 生活失序
- 线索：失控感、作息崩塌、习惯混乱、沉迷手机、生活一团乱

## 命中与优先级

- 精神困扰优先于现实困扰（先处理情绪，再处理处境）
- 描述同时命中多类时，选最贴近原话的 1–3 类
- 识别拿不准时，可在推荐开头用一句话向用户确认理解，再继续推荐
