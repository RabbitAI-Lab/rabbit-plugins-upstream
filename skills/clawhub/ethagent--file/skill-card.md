## Description:

A file-management skill that helps agents organize folders and documents, design naming conventions, find misplaced files, manage project archives, and maintain critical document inventories.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ethagent](https://clawhub.ai/user/ethagent)

### License/Terms of Use:


## Use Case:

External users and employees use this skill to plan and review file organization work, including naming conventions, folder structures, natural-language file searches, project archiving, and critical document inventories.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad file-management tasks can affect the wrong folder or project if the working scope is unclear.

Mitigation: Use clearly named folders and constrain each cleanup, search, move, or archive task to an explicit path or project.

Risk: Moves, deletions, or archival actions can affect important, sensitive, financial, legal, or medical documents.

Mitigation: Require a full preview and explicit approval before changes, and prefer archiving or trash over permanent deletion when anything is uncertain.
