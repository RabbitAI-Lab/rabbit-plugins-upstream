## Description:

Collaborate with developers in TrailMark to find project Markdown, understand the document in view, read shared notes, and address inline review comments.

This skill is ready for commercial/non-commercial use.

## Publisher:

[edelmarschneider](https://clawhub.ai/user/edelmarschneider)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill while working in TrailMark to locate specifications, interpret the current document selection, review shared notes and comments, and guide document updates.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The agent may see project documentation and notes shared through TrailMark.

Mitigation: Enable the connection only for projects whose documentation and shared notes the agent is authorized to access.
