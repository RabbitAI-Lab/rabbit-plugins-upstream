# MochiLab 随手记与待办 · Quick Notes and Tasks

`mochi-quick-notes` · v1.0.0 · MIT-0

随时收集想法、资料和待办，保存原话与关键词，按需查找、完成或归档。

Capture ideas, reference notes and tasks with searchable text and tags, then complete or archive them.

## 安装 / Install

将本目录放到当前 OpenClaw 助手工作区的 `skills/` 目录，运行 `openclaw skills info mochi-quick-notes`，再开始新对话。

Copy this folder into the active OpenClaw agent workspace's `skills/` directory, check readiness, then start a fresh conversation.

Node.js 24.16+ is required. Use the model already connected to your agent; this standalone Skill needs no MochiLab account key.

## 使用 / Use

Read [SKILL.md](SKILL.md), [input contract](references/input.md), and the samples before running the helper. Local records stay in the active agent workspace.

OpenClaw、已连接的模型、Node.js 24.16+、当前助手工作区的读写权限。

OpenClaw, a connected model, Node.js 24.16+, and read/write access to the current agent workspace. 

## 示例 / Examples

## 能帮你做什么

将零散消息分成记录、想法和待办，保留关键原话；支持文字检索、截止日期、完成状态与归档。

## 直接这样说

```text
记一下，周末买滤芯，型号是 ABC-200。
```

```text
上周说的那个装修想法，帮我找出来。
```

```text
列出还没做的事情，把买滤芯标成完成。
```

## 保存与继续使用

结果保存在当前助手的工作区，后续可以按记录编号查找和继续处理。


## What it does

Separate reference notes, ideas and actionable tasks, preserve key wording, and manage text search, due dates, completion and archiving.

## Try it

```text
Remember to buy an ABC-200 filter this weekend.
```

```text
Find the renovation idea I recorded last week.
```

```text
List my open tasks and mark the filter purchase complete.
```

## Save and continue

Records stay in the active agent workspace and can be retrieved by their IDs.
