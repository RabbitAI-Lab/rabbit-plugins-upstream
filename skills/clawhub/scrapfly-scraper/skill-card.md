## Use Case: <br>
Developers and agents use this skill to generate Scrapfly Python SDK scraping workflows for collecting HTML, JSON, markdown, or text from authorized web targets with proxy rotation, JavaScript rendering, sessions, and extraction options. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Scraping targets, request headers, cookies, bodies, and browser actions may be routed through Scrapfly as a third-party service. <br>
Mitigation: Use only authorized targets, avoid personal data and privileged credentials, and keep the Scrapfly API key in an environment variable or secret manager. <br>
