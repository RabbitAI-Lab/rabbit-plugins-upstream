# 优化算法库

## 一、元启发式算法

### WOA (鲸鱼优化)
- 作者：Seyedali Mirjalili (2016)
- 原理：模拟鲸鱼螺旋气泡网捕食
- 适用：连续全局优化、多峰函数
- 优点：参数少、全局搜索强

### GWO (灰狼优化)
- 作者：Seyedali Mirjalili (2014)
- 原理：模拟灰狼等级制度 (alpha/beta/delta)
- 适用：连续优化、多目标
- 优点：收敛快、平衡性好

### SOA (海鸥优化)
- 作者：Gaurav Dhiman (2019)
- 原理：模拟海鸥迁徙和攻击
- 适用：连续优化、多峰函数
- 优点：全局搜索强

### GOA (蝗虫优化)
- 作者：Seyedali Mirjalili (2017)
- 原理：模拟蝗虫社交互动
- 适用：多目标优化
- 优点：探索能力强

### MFO (蛾焰优化)
- 作者：Seyedali Mirjalili (2015)
- 原理：模拟蛾子螺旋飞行
- 适用：多峰函数、全局优化
- 优点：平衡性好

### FireWorks (烟花算法)
- 原理：模拟烟花爆炸
- 适用：组合优化、多模态
- 优点：多样性好

### BAS (细菌觅食)
- 原理：模拟触角搜索
- 适用：神经网络参数优化
- 优点：一维搜索高效

## 二、凸优化

### CVX
- 类型：MATLAB 凸优化建模
- 适用：SDP/SOCP/LP/QP
- 优点：建模简洁、求解可靠

## 三、阵列信号处理

- **Capon/MVDR**: 高分辨率 DOA
- **LCMV**: 多约束波束形成
- **LMS**: 实时自适应（简单）
- **RLS**: 快速收敛
- **SMI**: 块自适应

## 四、选择指南

| 问题 | 推荐 |
|------|------|
| 连续全局 | WOA, GWO |
| 多峰函数 | MFO, FireWorks |
| 神经网络 | BAS |
| 凸优化 | CVX |
| 阵列 DOA | Capon |
| 实时 | RLS, LMS |
| 高维 | GOA, FireWorks |
