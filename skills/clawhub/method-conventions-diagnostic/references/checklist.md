# 心理学实证论文 Method 部分「学术规范维度」检查清单

> **诊断对象**：心理学顶刊实证论文 Method 章节（Participants / Measures / Procedure / Analysis / Transparency & Openness）
> **依据**：《Science Research Writing》(2nd ed.) Unit 2 §2.4.2（Option 1/2/3 现有方法标注三档 + 引用位置规则 + 主动/被动语态归属判定）、§2.2.3 Generic Methods Model 六模块、§2.5.1 Ownership/Voice；JARS（Appelbaum et al., 2018）报告标准；JPSP / JEP:G / Developmental Psychology / PSPB / OBHDP 等顶刊正例的规范用法
> **使用方式**：逐项 `- [ ]` 勾选；不命中即在 rubric 中对应位置扣分

---

## 一、引用格式与标注规范性（Citation Format & Attribution）

### 1.1 引用位置与归属清晰（教材 §2.4.2 + p.11–13）
- [ ] Method 节中每条引用 reference 都紧跟所归属的语句 / 工具 / 程序，不堆放句末或段落末（教材 p.11 "Remember that citation references do not automatically go at the end of a sentence"）
- [ ] 引用位置明确，不会让读者误把前人的工作当作本研究的工作（avoid "accidentally credit someone with work they have not done"，教材 p.85）
- [ ] 既有方法描述后引用紧跟：adapted from X et al. (Year) / following X et al. (Year) / according to X et al. (Year) 直接接在被引用语句旁
- [ ] 数据来源 / 样本来源 / 设备来源的引用紧跟其出处（如"obtained from X et al., Year"），不放在段落最末
- [ ] 同一句子内出现多个引用时，引用的顺序与研究叙述的时间顺序一致（先基础研究 → 后本研究）
- [ ] 多引用编号列表（[1, 2, 7]）按期刊格式编号正确，无重复或漏引
- [ ] Option 1 完全相同表述（as described by/in / following / identical to）后引用位置正确
- [ ] Option 2 相似表述（adapted from / a modified version of / with some modifications）后引用位置正确
- [ ] Option 3 显著不同表述（unlike / instead of / with the following modifications）后引用位置正确
- [ ] 引用的内容与所引用文献的实际内容一致（不对未做的工作做引用，避免"虚假引用"）

### 1.2 引用格式与期刊一致性
- [ ] 引用格式与目标期刊的 Guide for Authors 一致（APA 作者-年份制 vs Elsevier 编号制 vs Nature 编号上标）
- [ ] 作者-年份制引用格式正确：单作者 (Smith, 2020)、双作者 (Smith & Jones, 2020)、三作者及以上 (Smith et al., 2020)
- [ ] 同一文献全文引用格式一致，不混用 APA / Vancouver / Harvard 等
- [ ] 年份均为发表年份（in press / under review 状态按目标期刊规范处理）
- [ ] 期刊名缩写符合 ISO 4 标准（JPSP = Journal of Personality and Social Psychology；JEP:G = Journal of Experimental Psychology: General）
- [ ] DOI / 期刊链接（如有）按目标期刊规范附上
- [ ] 二次引用（secondary citation：Smith, 1995, as cited in Jones, 2020）按目标期刊规范处理（多数 APA 期刊反对二次引用，应回到原始文献）
- [ ] 个人通讯（personal communication）的引用方式符合规范（APA：不进入参考文献列表，正文中标注日期）
- [ ] 数据已发表 / 未发表的标准引用方式（unpublished data / unpublished manuscript）使用正确

### 1.3 Option 1/2/3 现有方法标注的语法正确性（教材 §2.4.2 p.109–110）
- [ ] Option 1（完全相同）使用 by/in 介词搭配正确：by 引导研究者（as described by Ross），in 引导研究（as described in Ross et al., 2020）（教材 p.109 注释）
- [ ] Option 1 短语选词正确：according to / as described by/in / as reported by/in / identical to / following / using the method of / same as
- [ ] Option 2（相似）使用准确的「改编」短语：adapted from / a (modified) version of / based on / with some modifications / except for/that / essentially the same as
- [ ] Option 2 形容词比较级正确（essentially / largely / more or less / virtually / practically the same）
- [ ] Option 3（显著不同）使用「差异」短语：unlike / instead of / loosely based on / although similar to / with the following modifications
- [ ] Option 3 差异点显式陈述（"the difference may represent the key contribution of your study"，教材 p.84）
- [ ] CONTRAST 连接词（however / whereas / by contrast）作为 Option 3 的辅助手段使用正确
- [ ] 同一方法既引用前人又呈现本研究的「相同 + 差异」并存时，Option 1 与 Option 3 不混用同一短语

### 1.4 引用与缩写的全称展开
- [ ] 首次出现的机构缩写（IRB / APA / OSF / TOP / JARS）展开全称（Institutional Review Board / American Psychological Association / Open Science Framework / Transparency and Openness Promotion / Journal Article Reporting Standards）
- [ ] 首次出现的量表 / 任务 / 软件缩写给出全称与原始文献（PANAS = Positive and Negative Affect Schedule, Watson et al., 1988）
- [ ] 后续段落直接使用缩写，不重复展开（一致性规则）
- [ ] 自创缩写（如多研究内的程序名）首次出现给完整命名（Asaba "Experiment 4"；Abramson "Study 1"）
- [ ] 术语首次出现给定义或同位语，避免读者需要回查其他文献
- [ ] 拉丁语术语（如 et al. / in vitro / per capita / a priori / post hoc）斜体或不斜体按目标期刊规范

## 二、现有方法改编说明准确性（Adapted Method Documentation）

### 2.1 改编透明性（教材 p.84 + JARS）
- [ ] 改编后的方法明确标注改编来源（adapted from / a modified version of）
- [ ] 改编的具体差异点逐条列出（First... Second... Third... 或 (a)(b)(c)）
- [ ] 改编动机 / 理由被显式交代（why adapted: to suit the present sample / to avoid X / to control for Y）
- [ ] 改编是否经过原作者许可 / 是否为开源范式（如 Inquisit scripts / OSF 上的公开材料）被标注
- [ ] 改编是否在 OSF / 期刊补充材料公开（如改编后的脚本 / 完整刺激）
- [ ] 改编后方法的预注册版本与最终使用版本是否一致被标注

### 2.2 Option 2 改编差异点呈现（教材 p.110）
- [ ] with some modifications / with some changes / with some adjustments / with some alterations 短语使用正确
- [ ] 改编差异点单条不超 1–2 句，便于审稿人快速识别
- [ ] 改编差异点按重要程度排序（最关键差异最先列出）
- [ ] 改编差异点未与原始方法原文混在一起（区分"原文方法描述"与"本研究改编后方法描述"）
- [ ] 改编后的测量参数（题目数 / 锚点 / 计分方向）单独交代
- [ ] 改编后的刺激（图片 / 视频 / 文本）来源 + 改编内容明确
- [ ] 改编后的程序时序与原始方法差异被标注

### 2.3 Option 3 显著不同的差异论证（教材 p.84, p.110）
- [ ] 与现有方法的差异被识别为本研究的关键贡献（教材 p.84 "the difference may represent the key contribution of your study"）
- [ ] 差异的具体表征（材料 / 程序 / 测量 / 理论模型）逐条说明
- [ ] 差异的方法学意义 / 优势 / 改进点被论证（in order to / with the aim of / thereby）
- [ ] 差异点的取舍权衡（如放弃原方法的某功能以获得本研究需要的某特性）被显式说明
- [ ] 差异未被夸大（avoid claiming novelty when difference is minor）

### 2.4 工具 / 设备 / 材料来源标注
- [ ] 商品化试剂 / 耗材给出供应商与产地（如 "FBS was purchased from Gibco, UK"；教材 p.100 正例）
- [ ] 自制设备 / 材料说明构造规格（型号 / 尺寸 / 参数）
- [ ] 礼赠来源标注（"a kind gift from Dr. X at Institution Y"，教材 p.100 正例）
- [ ] 学术来源的样本 / 数据集标注来源（"obtained from X et al., Year"）
- [ ] 数据库引用给出数据库名称 + 访问链接（如 TEDS / SOEP / Add Health / HRS）
- [ ] 公开刺激库的引用（IAPS / OASIS / Nencki / CASO / etc.）按目标期刊规范标注
- [ ] 商业软件版本号完整（"SPSS 26.0" / "R Version 4.3, R Core Team, 2024"，教材正例）

### 2.5 系列实验的方法继承—修改表达
- [ ] 多研究论文中，Study 2/3 引用 Study 1 的方法时使用 "identical to Study 1, with the following changes" 句式
- [ ] 差异清单以 First / Second / Third 编号，便于读者快速定位
- [ ] 每条差异附带改动动机（neutralize gender cues / add a control condition / shorten the survey）
- [ ] 跨研究复用元素（刺激 / 量表 / 程序）显式回指（on similar 11-point scales as in Experiments 1a–1c）
- [ ] 跨研究样本口径一致（the final sample of Study 3 / as in Studies 1–c）
- [ ] 跨研究的变量命名、缩写、量表锚点完全一致
- [ ] 跨研究分析策略保持家族相似性，不为每个研究重新定义

## 三、伦理与透明声明完整性（Ethics & Transparency Statements）

### 3.1 伦理批准与知情同意
- [ ] IRB / 伦理委员会名称 + 批准编号完整给出（如 "approved by the University Ethics Committee (CIPI/2024(611))"；"IRB#15–001476"）
- [ ] 知情同意程序被描述（"Informed consent was obtained from all participants" / "All participants provided written informed consent"）
- [ ] 弱势群体（儿童 / 老年人 / 病患）的特殊同意程序被说明（监护人同意 + 儿童口头/书面同意 + assent）
- [ ] 报酬 / 补偿金额范围被报告（"M = $X, range = $X–$X"），与目标期刊规范一致
- [ ] 报酬与数据完整性的挂钩机制被描述（如 "T2 participation had a higher financial incentive to reduce dropout rates"，Costin 正例）
- [ ] 报酬与预注册标准的挂钩被透明化（如 "missing less than two evening questionnaires per week was also the criterion for being paid"，Buttner 正例）
- [ ] 伦理豁免说明（如使用公开数据 / 档案数据："we are exempt from an Institutional Review Board approval"，Entringer 正例）
- [ ] 伦理准则声明（Helsinki Declaration / APA Ethics Code / Belmont Report）按目标期刊要求

### 3.2 Transparency & Openness Promotion (TOP) 声明（教材 JARS + 顶刊规范）
- [ ] 单独"Transparency and Openness"段落存在，明确按 JARS（Appelbaum et al., 2018）声明（Altgassen 正例）
- [ ] 样本量确定方式（a priori power / sequential BF / resource constraints）被声明
- [ ] 所有数据排除（all data exclusions）被声明（"we report...all data exclusions"）
- [ ] 所有操纵（all manipulations）被声明
- [ ] 所有测量（all measures）被声明
- [ ] 数据（data）公开声明：OSF 链接 / 期刊补充材料 / 第三方数据库
- [ ] 分析代码（analysis code）公开声明：OSF 链接 / GitHub / 期刊补充材料
- [ ] 研究材料（research materials）公开声明：刺激 / 量表 / 任务脚本的获取途径
- [ ] 预注册状态如实声明：preregistered / not preregistered / preregistered with deviations
- [ ] 预注册链接给出（如 AsPredicted # / OSF 项目链接），与 AsPredicted.org / OSF 平台规范一致
- [ ] 修订预注册（如有）的透明处理：原始版本与修订版本都公开，分析偏差预先声明（Entringer 正例）
- [ ] 数据 / 代码 / 材料链接的有效性（DOI / view-only 链接 / 永久 URL）

### 3.3 预注册（Preregistration）的规范表述
- [ ] 预注册内容明确（hypotheses / design / analysis plan / sample size plan）
- [ ] 预注册平台引用规范（AsPredicted.org / OSF / ClinicalTrials.gov / 其他）
- [ ] 预注册编号 / 链接完整（如 "https://aspredicted.org/b536-d3w8.pdf"）
- [ ] "As preregistered, ..." 句式锚定预注册承诺（Buttner / Costin 正例）
- [ ] 与预注册的偏离被显式说明（deviations from preregistration），并在文中以 footnote / 单独段落呈现
- [ ] 偏离原因被合理说明（"during the review process, we decided to change these labels" / "in response to reviewer requests"，Alves / Entringer 正例）
- [ ] 预注册标签 / 术语修订的脚注式说明（Alves 正例）
- [ ] 序贯分析设计透明（起始样本 / 评估间隔 / 停止规则，Asaba 正例）

### 3.4 数据与材料可用性声明（Data & Materials Availability）
- [ ] 数据可用性段落或注释（"Data Availability Statement"）
- [ ] 数据 + 代码 + 材料三层公开声明（Damian 正例："All the measures, data analysis scripts, and de-identified data...are publicly available at..."）
- [ ] 输出文件（如完整 p 值 / 效应量表）是否公开被声明
- [ ] 可复现性声明（"necessary to reproduce the results" 用语，Damian 正例）
- [ ] 数据库访问政策与申请流程（如 TEDS / SOEP 的申请方式，Haider 正例）
- [ ] 二手数据 / 公开数据的访问途径清晰
- [ ] 数据限制声明（如伦理限制 / 法律限制 / 隐私保护导致的匿名化要求）

### 3.5 排除 / 筛选 / 样本流程的规范报告
- [ ] 排除流程按时间漏斗顺序呈现：起始样本 → 各排除环节 → 每步人数与理由 → 最终样本
- [ ] 排除规则逐条标注理由（attention check failure / consent withdrawal / incomplete responses / Mahalanobis distance outliers）
- [ ] 排除规则与预注册的对应被说明（"As preregistered, we excluded..." / "As specified in our preregistration, we removed..."）
- [ ] 排除率合理（避免过度排除 / 数据窥探）
- [ ] 选择效应自查（van Scheppingen 正例：识别偏差来源 → 推断后果 → 引出对照检验 → 量化比较）
- [ ] 最终样本的人口学完整报告（年龄 M(SD) range / 性别 / 种族 / 教育 / 国家）
- [ ] 样本代表性与同质化局限性被显式声明（Abramson 正例："race/ethnicity inconsistent"）
- [ ] 流失分析（保留者 vs 流失者差异检验）纵向研究必须报告

### 3.6 功效分析报告（教材 §2.4.2 + 顶刊规范）
- [ ] 先验功效分析要素齐全：目标效应量 + α + 功效 + df / 条件数 + 工具（Gaesser 正例：d = .25, G*Power, Faul et al., 2007）
- [ ] 效应量来源（前实验 / 文献 / 保守估计）被交代
- [ ] G*Power / Soper / simr / BUCCS 等工具引用规范
- [ ] 功效分析结果与实际样本量对应（"recommended a sample of X participants"，Georgeac 正例）
- [ ] 后验 / 敏感性分析（如不适用先验功效）被说明
- [ ] Monte Carlo 模拟 / 序贯 BF 设计（如 Asaba）透明报告
- [ ] 功效不足 / 效应方向明朗时的最小可检效应量被报告

## 四、术语与格式一致性（Terminology & Formatting Consistency）

### 4.1 学术术语的精确使用（教材 p.103–112）
- [ ] 心理测量学术语精确（Cronbach's alpha / McDonald's omega / intraclass correlation / composite reliability）
- [ ] 统计术语精确（mean / standard deviation / confidence interval / effect size / p-value）
- [ ] 测量单位统一（ms vs milliseconds / s vs seconds / min vs minutes / hr vs hours），不混用
- [ ] 量尺锚点统一（1 = strongly disagree, 7 = strongly agree），不跨段落更换锚点
- [ ] 抽样术语精确（simple random sampling / stratified sampling / convenience sampling / purposive sampling）
- [ ] 研究设计术语精确（between-subjects / within-subjects / mixed design / cross-sectional / longitudinal）
- [ ] 样本术语精确（participants / subjects / respondents / patients / dyads / triads），不混用
- [ ] 因果语言谨慎使用（"associated with" / "predicts" vs "caused" / "resulted in"），与设计类型对应

### 4.2 缩略语与符号体系一致性
- [ ] 缩略语首次出现给全称 + 缩写，后续段落直接使用缩写
- [ ] 同一概念全文使用同一缩写，不中途切换为同义缩写
- [ ] 数学 / 统计符号全文一致（X / M / Y / λ / β / Δ / α / ω / η² / Cohen's d）
- [ ] 路径图符号与文字描述双向对应（X / M / Y 角色清晰，Baron & Kenny (a)(b)(c) 一致）
- [ ] Greek 字母大小写正确（α vs Alpha；β vs Beta；ω vs Omega）
- [ ] 斜体规则正确（统计符号斜体：t / F / M / SD / N；缩写与拉丁语斜体：et al. / i.e. / e.g.）
- [ ] 引号使用规范（直引号 vs 弯引号；双引号 vs 单引号）
- [ ] 大小写规则一致（标题大小写 / 专有名词 / 量表名称首字母大小写）

### 4.3 数字、时间、单位的格式
- [ ] 数字格式统一（阿拉伯数字 vs 中文数字；小数点 vs 逗号）
- [ ] 千位分隔符按目标期刊规范（APA：1,000 / European：1.000）
- [ ] 样本量 N = 大写斜体（按 APA 规范）
- [ ] 百分比格式一致（N = 50 (20%) / 20% (n = 10)）
- [ ] 时间格式统一（11 s / 11 sec / 11 seconds），全文一致
- [ ] 日期格式按目标期刊规范（2020-01-15 / January 15, 2020 / 15 January 2020）
- [ ] 货币格式与目标地区一致（USD / RMB / EUR + 符号位置 + 千位分隔符）
- [ ] 温度单位一致（°C / °F），全文不混用
- [ ] 测量单位前后无多余空格（11s ✓ / 11 s ✓ / 11  s ✗）

### 4.4 表格 / 图 / 公式格式一致性
- [ ] 表格格式符合目标期刊（Table 1 / Table 2 编号连续；列标题明确；脚注完整）
- [ ] 表格内变量名与正文叙述使用同一缩写 / 全称
- [ ] 图编号连续（图 1 / 图 2 / Figure 1 / Figure 2），按目标期刊规范
- [ ] 公式编号连续（Eq. 1 / Equation 1），按目标期刊规范
- [ ] 图 / 表 / 公式在正文中的引用顺序与编号顺序一致（图 1 在图 2 之前被引用）
- [ ] 图 / 表的脚注 / 标注完整（*p < .05 / **p < .01 / ***p < .001 阈值被显式标注）
- [ ] 补充材料（Supplemental Materials）的引用与正文标注一致

### 4.5 标题 / 子标题 / 段落格式
- [ ] Method 节一级标题与目标期刊一致（METHOD / Method / Methods / MATERIALS AND METHODS）
- [ ] 子标题命名规范（Participants / Design / Measures / Procedure / Analysis / Transparency & Openness）
- [ ] 子标题大小写规范（APA title case vs sentence case）
- [ ] 段落起首缩进 / 不缩进按目标期刊规范
- [ ] 段落之间空行 / 不空行按目标期刊规范
- [ ] 段落长度合理（避免一段超过 200 字造成堆砌；教材建议每段聚焦一个主题）

### 4.6 目标期刊规范符合性
- [ ] 全文体例（passive vs active）符合目标期刊主流风格（JPSP 偏 passive；部分 OBHDP / JEP 接受 active）
- [ ] 参考文献列表格式与目标期刊一致（APA 7th vs APA 6th vs AMA vs Vancouver）
- [ ] 引用顺序与目标期刊规范一致（alphabetical vs order of appearance）
- [ ] 附录 / 补充材料格式与目标期刊一致
- [ ] 全文作者署名 + 通讯作者 + ORCID iD 标注符合目标期刊
- [ ] 关键词（keywords）数量与格式符合目标期刊（APA 通常 3–5 个）

## 五、附录：完整性自检

诊断完成后，回顾以下 5 项以确认覆盖完整：
- [ ] 引用位置规则（紧跟所归属语句 vs 句末堆叠）逐条核验
- [ ] Option 1/2/3 现有方法标注三档分类正确，无混用
- [ ] 伦理批准 + 知情同意 + 报酬 + IRB 编号完整
- [ ] Transparency & Openness 段落含数据 / 代码 / 材料 / 预注册四要素
