# 心理学实证论文 Method 部分「学术规范维度」评分细则

> 满分 **100 分**。问题分为 **严重 / 中等 / 轻微** 三档，按对应检查清单逐项扣分。本细则的所有扣分点与 `checklist.md` 的检查项一一对应，不另立条款。

## 扣分档位定义

| 等级 | 单项扣分 | 适用情形 |
|---|---|---|
| **严重** | 10–15 分 | 缺失伦理审查声明；引用标注错误导致学术诚信风险（如虚假引用、引用错位让他人背负本研究工作）；方法来源标注不实（method 不属于所引用文献）；预注册与实际偏离未声明 |
| **中等** | 5–9 分 | 引用格式不统一（同一文献多种格式）；方法改编未说明（差异点缺失）；格式前后不一致（数字、单位、缩写跨段不一致）；TOP 声明要素缺失 |
| **轻微** | 1–4 分 | 个别标注细节可优化（首次缩写未给全称、Option 短语用词欠精确）；格式小瑕疵（空格外不一致、单位前后空格不统一） |

## 一、引用格式与标注规范性（共 38 项）

### 1.1 引用位置与归属清晰 —— 10 项

| 检查项 | 等级 | 扣分 |
|---|---|---|
| Method 节中每条引用 reference 都紧跟所归属的语句 / 工具 / 程序，不堆放句末或段落末（教材 p.11） | 严重 | 11 |
| 引用位置明确，不会让读者误把前人的工作当作本研究的工作（避免 "accidentally credit someone with work they have not done"，教材 p.85） | 严重 | 13 |
| 既有方法描述后引用紧跟：adapted from X et al. (Year) / following X et al. (Year) / according to X et al. (Year) 直接接在被引用语句旁 | 中等 | 7 |
| 数据来源 / 样本来源 / 设备来源的引用紧跟其出处（如"obtained from X et al., Year"），不放在段落最末 | 中等 | 6 |
| 同一句子内出现多个引用时，引用的顺序与研究叙述的时间顺序一致（先基础研究 → 后本研究） | 轻微 | 4 |
| 多引用编号列表（[1, 2, 7]）按期刊格式编号正确，无重复或漏引 | 中等 | 5 |
| Option 1 完全相同表述（as described by/in / following / identical to）后引用位置正确 | 中等 | 6 |
| Option 2 相似表述（adapted from / a modified version of / with some modifications）后引用位置正确 | 中等 | 6 |
| Option 3 显著不同表述（unlike / instead of / with the following modifications）后引用位置正确 | 中等 | 6 |
| 引用的内容与所引用文献的实际内容一致（不对未做的工作做引用，避免"虚假引用"） | 严重 | 15 |

### 1.2 引用格式与期刊一致性 —— 9 项

| 检查项 | 等级 | 扣分 |
|---|---|---|
| 引用格式与目标期刊的 Guide for Authors 一致（APA 作者-年份制 vs Elsevier 编号制 vs Nature 编号上标） | 中等 | 7 |
| 作者-年份制引用格式正确：单作者 (Smith, 2020)、双作者 (Smith & Jones, 2020)、三作者及以上 (Smith et al., 2020) | 中等 | 6 |
| 同一文献全文引用格式一致，不混用 APA / Vancouver / Harvard 等 | 中等 | 6 |
| 年份均为发表年份（in press / under review 状态按目标期刊规范处理） | 轻微 | 3 |
| 期刊名缩写符合 ISO 4 标准（JPSP = Journal of Personality and Social Psychology；JEP:G = Journal of Experimental Psychology: General） | 轻微 | 4 |
| DOI / 期刊链接（如有）按目标期刊规范附上 | 轻微 | 2 |
| 二次引用（secondary citation：Smith, 1995, as cited in Jones, 2020）按目标期刊规范处理（多数 APA 期刊反对二次引用，应回到原始文献） | 中等 | 5 |
| 个人通讯（personal communication）的引用方式符合规范（APA：不进入参考文献列表，正文中标注日期） | 轻微 | 3 |
| 数据已发表 / 未发表的标准引用方式（unpublished data / unpublished manuscript）使用正确 | 轻微 | 3 |

### 1.3 Option 1/2/3 现有方法标注的语法正确性 —— 8 项

| 检查项 | 等级 | 扣分 |
|---|---|---|
| Option 1（完全相同）使用 by/in 介词搭配正确：by 引导研究者（as described by Ross），in 引导研究（as described in Ross et al., 2020）（教材 p.109 注释） | 中等 | 7 |
| Option 1 短语选词正确：according to / as described by/in / as reported by/in / identical to / following / using the method of / same as | 中等 | 6 |
| Option 2（相似）使用准确的「改编」短语：adapted from / a (modified) version of / based on / with some modifications / except for/that / essentially the same as | 中等 | 7 |
| Option 2 形容词比较级正确（essentially / largely / more or less / virtually / practically the same） | 轻微 | 3 |
| Option 3（显著不同）使用「差异」短语：unlike / instead of / loosely based on / although similar to / with the following modifications | 中等 | 7 |
| Option 3 差异点显式陈述（"the difference may represent the key contribution of your study"，教材 p.84） | 中等 | 8 |
| CONTRAST 连接词（however / whereas / by contrast）作为 Option 3 的辅助手段使用正确 | 轻微 | 3 |
| 同一方法既引用前人又呈现本研究的「相同 + 差异」并存时，Option 1 与 Option 3 不混用同一短语 | 中等 | 6 |

### 1.4 引用与缩写的全称展开 —— 6 项

| 检查项 | 等级 | 扣分 |
|---|---|---|
| 首次出现的机构缩写（IRB / APA / OSF / TOP / JARS）展开全称 | 轻微 | 3 |
| 首次出现的量表 / 任务 / 软件缩写给出全称与原始文献（PANAS = Positive and Negative Affect Schedule, Watson et al., 1988） | 轻微 | 4 |
| 后续段落直接使用缩写，不重复展开（一致性规则） | 轻微 | 1 |
| 自创缩写（如多研究内的程序名）首次出现给完整命名（Asaba "Experiment 4"；Abramson "Study 1"） | 轻微 | 2 |
| 术语首次出现给定义或同位语，避免读者需要回查其他文献 | 轻微 | 3 |
| 拉丁语术语（如 et al. / in vitro / per capita / a priori / post hoc）斜体或不斜体按目标期刊规范 | 轻微 | 2 |

## 二、现有方法改编说明准确性（共 27 项）

### 2.1 改编透明性 —— 6 项

| 检查项 | 等级 | 扣分 |
|---|---|---|
| 改编后的方法明确标注改编来源（adapted from / a modified version of） | 严重 | 10 |
| 改编的具体差异点逐条列出（First... Second... Third... 或 (a)(b)(c)） | 中等 | 7 |
| 改编动机 / 理由被显式交代（why adapted: to suit the present sample / to avoid X / to control for Y） | 中等 | 6 |
| 改编是否经过原作者许可 / 是否为开源范式（如 Inquisit scripts / OSF 上的公开材料）被标注 | 中等 | 5 |
| 改编是否在 OSF / 期刊补充材料公开（如改编后的脚本 / 完整刺激） | 中等 | 6 |
| 改编后方法的预注册版本与最终使用版本是否一致被标注 | 中等 | 7 |

### 2.2 Option 2 改编差异点呈现 —— 7 项

| 检查项 | 等级 | 扣分 |
|---|---|---|
| with some modifications / with some changes / with some adjustments / with some alterations 短语使用正确 | 中等 | 6 |
| 改编差异点单条不超 1–2 句，便于审稿人快速识别 | 轻微 | 3 |
| 改编差异点按重要程度排序（最关键差异最先列出） | 轻微 | 3 |
| 改编差异点未与原始方法原文混在一起（区分"原文方法描述"与"本研究改编后方法描述"） | 中等 | 6 |
| 改编后的测量参数（题目数 / 锚点 / 计分方向）单独交代 | 中等 | 6 |
| 改编后的刺激（图片 / 视频 / 文本）来源 + 改编内容明确 | 中等 | 6 |
| 改编后的程序时序与原始方法差异被标注 | 中等 | 5 |

### 2.3 Option 3 显著不同的差异论证 —— 5 项

| 检查项 | 等级 | 扣分 |
|---|---|---|
| 与现有方法的差异被识别为本研究的关键贡献（教材 p.84 "the difference may represent the key contribution of your study"） | 严重 | 10 |
| 差异的具体表征（材料 / 程序 / 测量 / 理论模型）逐条说明 | 中等 | 7 |
| 差异的方法学意义 / 优势 / 改进点被论证（in order to / with the aim of / thereby） | 中等 | 7 |
| 差异点的取舍权衡（如放弃原方法的某功能以获得本研究需要的某特性）被显式说明 | 中等 | 6 |
| 差异未被夸大（avoid claiming novelty when difference is minor） | 中等 | 5 |

### 2.4 工具 / 设备 / 材料来源标注 —— 7 项

| 检查项 | 等级 | 扣分 |
|---|---|---|
| 商品化试剂 / 耗材给出供应商与产地（如 "FBS was purchased from Gibco, UK"；教材 p.100 正例） | 中等 | 5 |
| 自制设备 / 材料说明构造规格（型号 / 尺寸 / 参数） | 轻微 | 3 |
| 礼赠来源标注（"a kind gift from Dr. X at Institution Y"，教材 p.100 正例） | 严重 | 10 |
| 学术来源的样本 / 数据集标注来源（"obtained from X et al., Year"） | 中等 | 6 |
| 数据库引用给出数据库名称 + 访问链接（如 TEDS / SOEP / Add Health / HRS） | 中等 | 6 |
| 公开刺激库的引用（IAPS / OASIS / Nencki / CASO / etc.）按目标期刊规范标注 | 中等 | 5 |
| 商业软件版本号完整（"SPSS 26.0" / "R Version 4.3, R Core Team, 2024"，教材正例） | 中等 | 6 |

### 2.5 系列实验的方法继承—修改表达 —— 7 项

| 检查项 | 等级 | 扣分 |
|---|---|---|
| 多研究论文中，Study 2/3 引用 Study 1 的方法时使用 "identical to Study 1, with the following changes" 句式 | 严重 | 11 |
| 差异清单以 First / Second / Third 编号，便于读者快速定位 | 中等 | 6 |
| 每条差异附带改动动机（neutralize gender cues / add a control condition / shorten the survey） | 中等 | 5 |
| 跨研究复用元素（刺激 / 量表 / 程序）显式回指（on similar 11-point scales as in Experiments 1a–1c） | 中等 | 6 |
| 跨研究样本口径一致（the final sample of Study 3 / as in Studies 1–c） | 中等 | 5 |
| 跨研究的变量命名、缩写、量表锚点完全一致 | 中等 | 6 |
| 跨研究分析策略保持家族相似性，不为每个研究重新定义 | 中等 | 5 |

## 三、伦理与透明声明完整性（共 37 项）

### 3.1 伦理批准与知情同意 —— 8 项

| 检查项 | 等级 | 扣分 |

## 七、评分使用提示

1. **逐项检查**：按本细则逐条对照 Method 段，每条不符合即按对应档位扣分。
2. **累加扣分**：从 100 分起算，累加所有命中项的扣分；最终得分 = 100 − Σ扣分，最低为 0。
3. **同档叠加**：同一档内的多项同时不达标时累加扣分；如三项轻微问题各扣 3 分，合计扣 9 分，已达到中等问题的总体影响。
4. **严重问题优先**：若一项严重问题与其他问题同时存在，优先处理严重问题；学术诚信类问题（虚假引用、引用错位让前人背负本研究工作、伦理声明缺失、预注册与数据完全不符）是顶刊审稿人最敏感的信号，**强制降档**：
   - 1 处严重问题 → 最高 B 档
   - 2 处严重问题 → 最高 C 档
   - 3 处及以上严重问题 → 强制 D 档
   - 总分 < 60 → 强制 F 档
5. **诚信优先于美观**：本维度的严重问题与其他维度（逻辑、结构、衔接）不同，属于学术规范底线，**不能以"先投稿后修订"为由搁置**。任何一条严重问题命中（如伦理审查缺失）即应在投稿前解决。
6. **示例**：某研究"引用位置错位让他人背负本研究工作"（−13）、"虚假引用（引用未做的工作）"（−15）、"伦理委员会批准编号缺失"（−12）、"未声明与预注册的偏离"（−11），共扣 51 分，剩 49 分，归入 F 档，且严重问题 ≥ 3 处强制 D 档；提示需对引用归属、伦理声明、预注册偏离三项做学术诚信整改后方可重新提交。
