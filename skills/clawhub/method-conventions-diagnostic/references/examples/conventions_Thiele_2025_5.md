## 原文片段

First, we fitted three generalized linear mixed models with beta-distributed error structure to model the novelty preference score [0,1] as a function of interpersonal "touch" and "eye contact": a full model, a reduced model, and a null model. In deviation from the preregistered plan, we decided to use a beta distribution instead of a gamma distribution, as the beta distribution is more suitable for analyzing proportion scores (Chen et al., 2017). We fitted the models using the R package glmmTMB Version 1.1.9 (Brooks et al., 2017). To visualize the data in Figure 2, we used the ggplot2 R package Version 3.5.1 (Wickham, 2016).

## 来源文献

Thiele, M., Gredebäck, G., & Haun, D. B. M. (2025). Social connectedness without eye contact. Developmental Psychology.
