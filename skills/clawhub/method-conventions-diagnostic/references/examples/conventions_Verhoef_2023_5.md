## 原文片段

We had substantial missing data on all latent profile indicators at each wave (16.8% at Wave 1, 25.8% at Wave 2, and 27.0% at Wave 3). Additionally, missing data on predictors ranged from 3.3% to 22.1% (M = 13.0%, SD = 5.6%). Little's MCAR test (Little, 1988) demonstrated missing data on the latent profile indicators and predictors were completely at random (χ² = 1,533.228, df = 1,464, p = .102). ... To handle missing values on latent profile indicators and predictors, we therefore generated 15 imputed data sets using Bayesian analysis (Rubin, 1987; Schafer, 1997). ... The number of imputed data sets was based on the fraction of missing information (Von Hippel, 2020).

## 来源文献

Verhoef, R. E. J., et al. (2023). Stability and change in maternal parenting profiles across infancy and toddlerhood. Developmental Psychology.

## 适配诊断点

缺失率按波次/变量类型分别报告 → MCAR 检验（完整 χ²/df/p）→ 为何弃 FIML 改多重插补 → 插补次数依据（fraction of missing information）的完整决策链，是缺失数据处理报告的规范样板。
