## 原文片段

We report how we determined our sample size, all data exclusions, and all manipulations. All data and analysis code are publicly available at: osf.io/8tjmn. Data were analyzed using RStudio, version 2022.12.0. This experiment's design and its analysis were not pre-registered.

## 来源文献

Radovanovic et al., 2023, Developmental Psychology
