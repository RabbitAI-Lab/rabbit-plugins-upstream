## Description: <br>
Researches GitHub repositories as products to discover open-source markets, compare competitors, validate product ideas, analyze repository and issue signals, and recommend opportunities for product managers or indie builders. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

## Use Case: <br>
Product managers, indie builders, and developers use this skill to research GitHub repositories as products, compare open-source markets, validate product ideas, and identify credible product opportunities from repository, issue, and documentation evidence. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may use web and GitHub research tools to read repository metadata, issues, discussions, and documentation, including private repositories if credentials allow access. <br>
Mitigation: Scope GitHub credentials or app access to the repositories and visibility level approved for the product research task. <br>
Risk: Product recommendations can be misleading when GitHub evidence is incomplete, inaccessible, or time-sensitive. <br>
Mitigation: Review cited sources, observation dates, confidence labels, and stated limitations before using the report for product decisions. <br>
