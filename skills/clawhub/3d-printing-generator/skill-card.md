## Description:

AI 3D Printing Toy Generator Toy Multi View Sheets and 3D Models Generator using SOTA 3D APIs such as Tripo/Meshy/etc served on OneKey Agent Gateway by Craftsman Agent, useful for AI Figurine, Stuffed Toy, 3D Printing, Game Asset and Architecture Toy Generation

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and creators use this skill to draft toy concept sheets and manage 3D toy model generation tasks from text prompts, image references, and multi-view inputs. It supports figurine, stuffed toy, 3D printing, game asset, and architecture toy workflows through OneKey Agent Gateway APIs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts, image references, task metadata, and generated model assets may be sent to the OneKey Agent Gateway and downstream 3D generation providers.

Mitigation: Use only inputs approved for external processing; do not submit confidential, regulated, proprietary, or personal images unless that processing is approved for the use case.

Risk: Generated model files and previews may require review before use in fabrication, game assets, or public distribution.

Mitigation: Review generated assets for suitability, rights, and safety before publishing, printing, or incorporating them into downstream products.
