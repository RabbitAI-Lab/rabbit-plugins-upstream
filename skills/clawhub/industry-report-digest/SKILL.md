# 行业报告核心拆解

## Overview

把几十上百页的行业研究报告压缩成一份能快速读完、又能直接拿去做决策参考的拆解卡片。核心是两件事：**观点要提炼观点本身而不是摘句子**，**数据必须带口径和单位**，否则后续没法用。

## When to use

- 用户丢来长篇报告、研报 PDF、白皮书、 Leolette / 券商 / 咨询报告要提炼。
- 用户说「这份报告重点是什么」「帮我拆一下」「提取关键数据」。

## Workflow

1. **定位报告元信息**：发布机构、发布时间、覆盖范围（地域 / 细分赛道 / 统计口径年份）。这决定了结论的可信度和时效性，必须先说。
2. **提炼核心观点（3-5 条）**：每条写成一句独立成立的判断句，不要「报告提到…」这种转述。
3. **抽取关键数据**：市场规模、增速、渗透率、集中度、头部玩家份额、用户规模、单价等。每条必须带：数值 + 单位 + 统计口径 + 时间点 + 来源页码/章节。
4. **归纳趋势驱动因素**：为什么会发生这些变化（技术、政策、需求、成本、渠道）。
5. **提炼机会与风险**：面向谁的机会、进入壁垒在哪、什么条件下不成立。
6. **标注存疑点**：样本量小、口径突变、预测假设激进、数据与其他来源冲突的地方，显式列出。

## 输出模板

```
## 报告速览
- 标题 / 发布机构 / 发布时间 / 覆盖范围
- 一句话结论：…

## 核心观点
1. …
2. …
3. …

## 关键数据看板
| 指标 | 数值 | 单位 | 口径 / 时间 | 来源位置 |
|------|------|------|-------------|----------|

## 趋势驱动因素
- 驱动一：…（对行业的影响）
- 驱动二：…

## 机会点
- …（面向谁 / 前提条件）

## 风险与不确定性
- …

## 存疑 / 需注意
- …
```

## 关键规则

- **数据必须带口径**：只有「市场规模 500 亿」没用，必须写清是哪一年、什么统计范围、含不含什么。缺口径就标 `[口径未说明]`。
- **区分事实与观点**：哪些是报告给出的数据事实，哪些是作者推断/预测，必须分开标示。
- **不臆造数据**：报告没给的指标不要补，缺失就写「报告未披露」。
- **保留相对关系**：增速也好、份额也好，尽量同时给绝对值与相对值（如份额 12%，同比 +2pct）。
- **单位统一**：注意「亿元 vs 亿美元」「出货量 vs 装机量」等易混口径，跨表引用时要换算并说明。
- **预测要标年份区间**：CAGR 要写清起止年份与计算基数。

## 自检清单

- [ ] 报告元信息与覆盖范围已说明
- [ ] 核心观点是独立判断句，不是摘抄
- [ ] 每条数据带单位、口径、时间、来源
- [ ] 事实与预测已区分
- [ ] 有机会点和风险两面
- [ ] 存疑点已显式列出，没有脑补数据
