# mifu-chem-mindmap 米赋化学知识体系思维导图 Skill

> v1.0.0 | 米赋AI教育 | MIT-0 License
> 状态：生产可用（硫36/36、氮24/24条方程式自动校验全绿）

## 一句话定位

与 `mifu-chemistry-lesson-prep` 配合，把备课教案的"转化网络设计"升级为**完整知识体系三层思维导图**（招贴本式HTML，方程式直接嵌入节点），用"数据→渲染→校验"流水线保证内容完整、方程式正确、展现形式合理。

## 解决什么问题

- 手写HTML思维导图：方程式易写错、维度易漏、改一次重画一遍——不可维护
- 本skill把**内容（JSON）与视图（HTML）分离**：改内容只改JSON重新渲染，数据和视图永远一致

## 三层结构标准

```
中心主题（模块名+价态轴SVG横幅）
 ├─ 一级分支：物质类别（6±1个，如 单质/氢化物/氧化物/含氧酸/盐/检验与制备）
 │   ├─ 二级分支：性质维度（物理性质/化学性质/制备/用途）
 │   │   └─ 三级节点：方程式直接嵌入 + 条件 + 现象 + 四色标签
 └─ 完整度7维度强制清单：价态转化/物理性质/化学方程式/制备/检验/用途/污染治理（≥85%覆盖才算过）
```

## 流水线（铁律：不允许手写HTML直接交付）

```
1. 内容整理 → mindmap-data.json（结构化数据，方程式进 equations_bank）
2. 渲染     → python scripts/mindmap_tools.py render data.json out.html
3. 校验     → python scripts/mindmap_tools.py validate data.json
   ├─ V1 方程式原子守恒自动校验（含变量如X₂的转人工核对）
   ├─ V2 完整度7维度对照（≥85%）
   └─ V3 渲染一致性（节点数=数据节点数）
4. 人工兜底：条件/现象标注、超纲判断、与教案一致性
```

## 快速上手

```bash
# 校验+渲染一步完成
python scripts/mindmap_tools.py all mindmap-sulfur.json mindmap-sulfur.html
```

数据文件参考实现：见配套验证产物 `mindmap-sulfur.json`（6分支×65节点×36方程式）、`mindmap-nitrogen.json`（6分支×56节点×24方程式）。

## 设计规范要点

- 招贴本式双栏卡片 + 价态轴SVG + **四色标签**：常考红 / 易错黄 / 可推绿 / 必须记灰（对应名师"记和推分开"方法论）
- 零外部依赖（无CDN），可直接打印A3

## 已知边界（诚实声明）

- 脚本自动校验覆盖**原子守恒**；电子守恒/电荷守恒/条件标注仍需AI生成时三重验证+教练抽查（写在references/03-verification.md人工兜底清单）
