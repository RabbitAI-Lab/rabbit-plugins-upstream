# 结构标准：三层结构与7维度完整度清单

## 一、三层结构定义（招贴本形态）

```
第0层 中心主题：模块名+元素+主题式包装（横幅，含价态轴SVG）
第1层 一级分支（6±1个）：按物质类别划分——单质/氢化物/低价氧化物/高价氧化物与含氧酸/盐/转化网络
第2层 二级维度（每分支4-6个）：存在价态/物理性质/化学性质/制备/检验/用途/污染治理（按物质类型取舍）
第3层 三级节点：具体知识点一行式——描述+方程式（嵌入）+标签（常考/易错/可推）
```

### 一级分支的划分原则
1. **以物质类别为主线**（与铝范本一致），不以课时划分——思维导图是知识体系，不是课程进度
2. 最后一个分支固定为"**价态转化网络**"（价类二维图+归中歧化+动态追踪+工业流程链）——这是化学模块的收口
3. 分支数量6±1：超过8个说明应拆成两张图（单模块过载）

### 二级维度的选取（按物质类型）
| 物质类型 | 必选维度 | 可选维度 |
|---------|---------|---------|
| 单质 | 存在价态/物理性质/化学性质 | 用途 |
| 气态氢化物 | 物理性质/化学性质/检验 | 制备 |
| 氧化物 | 物理性质/酸性碱性通性/特性/制备/污染治理 | 鉴别 |
| 含氧酸 | 物理性质/酸的通性/特性（浓酸三特性等）/工业制备 | 用途 |
| 盐与离子检验 | 俗名与存在/检验操作/易错禁忌 | 用途 |

## 二、7维度完整度清单（V2校验依据）

产出的导图必须覆盖以下7个维度（在对应分支的二级section中体现）：

| # | 维度 | 检查点 | 缺失后果 |
|---|------|--------|---------|
| 1 | 价态轴 | 全部常见价态+代表性物质，标注归中/歧化 | 转化网络失去骨架 |
| 2 | 物理性质 | 颜色/状态/气味/溶解性/密度（气体类） | 选择题高频丢分 |
| 3 | 化学性质方程式 | 与教案方程式银行100%一致+讲义补充方程式 | 核心丢分 |
| 4 | 制备 | 实验室制法（原料/条件/收集/干燥"四问"）+工业制法 | 实验题丢分 |
| 5 | 检验 | 离子检验标准表述+三大禁忌/易错 | 表达题丢分 |
| 6 | 用途 | 至少3条真实用途（联系生产生活） | 情境题丢分 |
| 7 | 污染与治理 | 环境影响+治理方程式（上海卷绿色化学评价高频） | 素养题丢分 |

**打分口径：** 每维度"有且正确"=满分；"有但浅"（如用途只写1条）=半分；缺失=0。总分<85%必须补齐再交付。

## 三、方程式嵌入规范

1. **格式**：`反应物 → 条件 生成物`，用Unicode上下标（SO₂、Fe³⁺、⇌、Δ、↑、↓），条件写在箭头上方括号内如 `→(点燃)`、`⇌(催化剂,Δ)`
2. **必注现象**：现象不是可选项——关键现象用括号跟在方程式后，如"（淡蓝色火焰）""（红棕色）"
3. **量变双版本**：产物跟量走的必须并列写两版（如SO₂+NaOH少量/足量），并标注"★产物跟着量走"
4. **记推标签**：每条方程式打标签——`必须记`（条件/系数实验事实）或`可推`（价态+守恒可推导），对应备课教案的"记和推分开"
5. **equations_bank**：所有嵌入方程式必须同时平铺登记在JSON的`equations_bank`数组中（校验对象），与branches内保持字面一致

## 四、内容来源优先级（防编造铁律）

```
1. 教案方程式银行（备课已三重验证）——最高优先，字面一致
2. IMA一轮复习讲义解析版（考点目录+方程式+得分速记）
3. 沪科技版教材（上海教材文件夹）
4. 教辅资料文件夹
5. AI自有知识——仅补漏，且必须过V1守恒校验+人工核对
```
