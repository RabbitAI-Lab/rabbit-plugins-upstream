# 设计规范：招贴本式HTML渲染

## 一、总体布局（自上而下）

```
┌─────────────────────────────────────────────┐
│ 横幅：模块名｜三层思维导图（主题式包装副标题）      │
│ 价态轴SVG：各价态→代表物质→归中/歧化标注          │
├──────────────┬──────────────────────────────┤
│ 分支1卡片     │ 分支2卡片                      │
├──────────────┼──────────────────────────────┤
│ 分支3卡片     │ 分支4卡片                      │
├──────────────┼──────────────────────────────┤
│ 分支5卡片     │ 分支6卡片（价态转化网络，可加宽）  │
└──────────────┴──────────────────────────────┘
页脚：validate状态+来源+版本+日期
```

## 二、视觉层级

| 层级 | 样式 |
|------|------|
| 中心横幅 | 深色底（元素主色）+白字大标题+副标题 |
| 价态轴SVG | 横向箭头轴，价态刻度，物质框按价态分区，归中=双向汇聚箭头/歧化=双向发散 |
| 一级分支卡 | 白底+左侧6px彩色边条+分支编号圆标+分支标题（各分支固定专属色） |
| 二级维度标题 | 浅灰底色块+加粗，前缀"▸" |
| 三级节点 | 普通行文，方程式独立成行：等宽字体+浅色底纹圆角块 |
| 标签 | `常考`=红底白字小圆角 / `易错`=黄底深字 / `可推`=绿底白字 / `必须记`=灰底 |

## 三、配色（每个模块固定一套分支色，打印友好）

- 基底：白底，深灰文字（#1a1a1a）
- 分支色板（循环使用）：蓝#2563eb / 绿#059669 / 橙#d97706 / 紫#7c3aed / 红#dc2626 / 青#0891b2
- 浅色底纹（方程式块）：#f3f4f6；卡片浅底：对应分支色5%透明度
- **禁止**：深色背景大面积使用（打印浪费墨+light主题不可读）

## 四、技术约束（硬性）

1. **零外部依赖**：不用CDN、不用外部字体、不用JS框架——纯HTML+内联CSS+内联SVG（file://预览可靠性铁律）
2. **可打印**：@media print规则（去阴影、A3横向适配）、卡片break-inside:avoid
3. **响应式**：桌面双栏，窄屏单栏（媒体查询）
4. **方程式渲染**：Unicode上下标字符直接写（SO₂/Fe³⁺/⇌/Δ），不用MathJax/KaTeX
5. **由脚本渲染**：HTML必须由`mindmap_tools.py render`从JSON生成——**禁止手写HTML交付**（保证数据↔视图一致）

## 五、渲染后人工检查（V3补充）

- [ ] 价态轴SVG中归中/歧化箭头方向正确
- [ ] 长方程式未溢出卡片（换行正常）
- [ ] 标签颜色语义正确（常考≠易错）
- [ ] 页脚版本/日期/validate状态正确
- [ ] 打印预览（A3横向）无断卡
