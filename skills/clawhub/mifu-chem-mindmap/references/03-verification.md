# 校验规范：三重校验 + 人工兜底

## V1 方程式守恒校验（脚本自动）

`mindmap_tools.py validate <data.json>` 内置化学式解析器：

1. **解析范围**：`equations_bank`中每条方程式（`→`/`⇌`/`=`连接，`+`分隔物种）
2. **化学式识别**：支持嵌套括号/水合结晶水（CaSO₄·2H₂O）/离子（Fe³⁺按电荷守恒不计原子数时跳过电荷项，只查原子）/电子e⁻
3. **检查项**：
   - 原子守恒：左右两侧每种元素原子总数相等
   - 忽略项：条件标注（点燃/催化剂/Δ）、状态符号（↑↓）、系数为分数时先通分
   - ⇌可逆反应同样要求两侧守恒
4. **输出**：逐条`✅/❌+错在哪侧缺什么元素`；❌>0则**禁止渲染交付**，改JSON后重来
5. **已知局限（必须人工兜底）**：离子方程式电荷守恒、氧化还原电子守恒、有机结构简式——脚本只保原子守恒，这三项靠AI三重验证习惯+人工复核

## V2 完整度校验（脚本统计+人工对照）

脚本自动统计并输出：
- 分支数（应在5-8）
- 每分支的二级维度名列表 → 对照7维度清单（价态/物理/化学方程式/制备/检验/用途/污染治理），报告缺失维度
- 方程式总数、带`常考/易错`标签节点数、`可推`标签占比（健康区间20%-40%，过高说明记忆负担没分流）

人工对照（不可省）：
- [ ] 与一轮复习讲义考点目录逐考点对照——每个考点在导图中有着落
- [ ] 与教案方程式银行逐条对照——字面一致
- [ ] 沪科技版范围核对——超纲内容删除或标注"等级考拓展"

## V3 渲染一致性校验（脚本自检）

render完成后自动输出：
- 生成的HTML文件大小（异常小=模板错误）
- 节点数/方程式数/分支数与JSON统计一致
- 无`{{placeholder}}`或`None`残留字符串

## 交付门槛（全过才算完成）

```
V1: 0条方程式报错
V2: 7维度覆盖≥85% + 讲义考点全覆盖 + 教案银行字面一致
V3: 渲染统计一致无残留
人工: 条件现象标注抽查≥10条 + 教材超纲核对 + 价态轴箭头方向
```

## 迭代纪律

- 任何内容修改→改JSON→重新render→重新validate（三步必须重跑）
- validate报告保存为`<模块名>-validate-report.txt`与导图同目录交付（可追溯）
- 方程式银行更新时（教案改了），导图必须同步重生成——单一事实源在JSON
