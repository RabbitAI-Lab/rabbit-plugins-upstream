## Use Case:

Developers and engineers use this skill for guidance on embedding Rez in Python, inspecting resolved packages and environments, persisting contexts, and choosing when to execute commands within them.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Following examples can execute commands in a resolved Rez environment or write .rxt context files.

Mitigation: Review package requests and output paths before running examples; inspect a context before executing commands.
