# 核心规则

> 以下规则由本框架基于达人合作的一线决策场景自行提炼，属于框架自身的分析约束，不依赖任何外部文档。每条规则均针对一个可复现的失效模式。

## 规则列表

| # | 规则 |
|---|------|
| R1 | 开工前必须先填完整分析任务定义句（含平台要素）；填不出来，就不许翻作品 |
| R2 | 先读作品，不要先读评论；更不要拿到账号就开始刷作品 |
| R3 | 不看平均值，看最低值、中位数和最高值；日常水平由中位数近似 |
| R4 | 不给达人贴标签（"时尚""生活""美妆"），要归纳他反复在讲的内容母题 |
| R5 | 母题/做法只有在数据好的作品里反复出现、在数据差的作品里明显少见，才算候选规律 |
| R6 | 只挑爆款看会掉进幸存者偏差：爆款是结果，不是原因；十条爆款里可复用的也许只有四条 |
| R7 | 评论分析先定义观察维度，再统计；每类都要看到实际数量，有数才有判断 |
| R8 | 播放/点赞/评论总数只回答"有没有被看见"；内容+评论对照才回答"有没有被听懂" |
| R9 | 活动型评论（直播时间、抽奖口令、求链接、价格问询）不能等同于内容认同，更不能等同于购买意愿 |
| R10 | 收藏显著高于账号日常水平是使用意图信号，但不能直接等同于购买意愿 |
| R11 | 报告不能只给"适合/不适合"，必须回答五个标准问题（见 collaboration-judgment.md） |
| R12 | 结论能下多深，只由证据的覆盖决定；公开数据支持不了的结论不能下；商业结果由品牌自有数据（花费、曝光、点击、成交、退款）回答 |
| R13 | 达人想表达什么，和用户实际接收到什么，是两件事；后者才决定商品会不会被记住 |
| R14 | 账号分析只是合作 Brief 的一半输入，另一半是商品价值分析（真实产品价值、适用人群、使用动作、可用证据、合规边界） |
| R15 | 平台决定信号权重：同一信号在不同平台含义不同（小红书收藏重于点赞，视频号转发优先），报告必须标注平台口径（见 platform-context.md） |
| R16 | 达人有生命周期：上升/成熟/衰退决定合作策略与议价位置；看时间斜率，不看单点；单一爆款 ≠ 上升期（见 works-analysis.md 3.3） |
| R17 | 爆款要归因：区分可复制的（选题/结构）与不可复制的（时机/热点）；候选规律只能来自可复制要素（见 works-analysis.md 3.5） |
| R18 | 分析结论必须落到合作形态建议（种草植入/定制内容/直播/信息流/长期合作），不能停在"适合/不适合"（见 collaboration-judgment.md） |
| R19 | 合作前必须过风险清单：舆情历史、立场敏感、粉丝画像冲突、水军痕迹、内容合规史（见 collaboration-judgment.md） |

## 规则来源与演进

- v1.x 规则（R1-R14）为基础分析纪律；v2.0 新增 R15-R19，均由资深达人营销专家视角补充，覆盖平台差异、生命周期、爆款归因、合作形态与风险排查五类一线决策场景。
- 标注"推断"的规则为框架内的待验证假设，使用时须以实际证据校验。
