# 诚实边界

## 不处理什么（out of scope）

- **批量筛选排序**：按粉丝量、报价、CPM、预期播放量、画像匹配度、完播率生成候选名单——那是筛选流程，交付候选名单；本 skill 交付账号理解。筛选与深度分析样本量不可混用。
- **投放效果预测/归因**：GMV、ROI、转化率等商业结果必须由品牌自有数据（花费、曝光、点击、成交、退款）回答，公开数据支持不了这类结论。生命周期"上升/衰退"是对内容数据趋势的阶段判断，不是对投放效果的预测。
- **商品价值分析**：合作 Brief 的另一半输入（产品价值、适用人群、使用动作、可用证据、合规边界），需另行完成。
- **刷量/数据造假鉴定**：本 skill 基于公开数据做内容与接收分析，不做数据真实性鉴定。风险清单中的"水军痕迹"只能标注"疑似"，不能下鉴定结论。
- **合规审查本身**：内容合规史（医疗/金融/功效宣称违规）只做风险提示，合规边界由品牌法务把关。

## 已知局限

1. **数据依赖**：本 skill 不内置采集工具。作品与评论数据按 📍 references/data-sources.md 的证据质量分层获取（T1 官方后台 → T2 开放 API → T3 第三方工具 → T4 公开页面采集 → T5 人工导出）；数据不全时执行数据缺口降级协议，在报告中声明。
2. **评论可见性偏差**：平台通常只展示部分评论（排序、折叠、删除），计数为"可见评论"口径的近似值，且评论者不足观看者的 1%（自选样本）——占比须用参与结构比率校准，不得外推为受众观点分布（见 comments-analysis.md）。
3. **平台差异**：同一信号在不同平台含义不同（见 platform-context.md）。跨平台比较必须标注平台口径；达人跨平台时信任不能自动迁移。
4. **推断标注**：Step 5 的"四种情况"表格为框架设计定义；流量池异常剔除、生命周期判定、母题趋势、外因剔除、信任可迁移性、参与结构比率、爆款归因、硬广割裂度、信任资产信号、合作形态矩阵、风险清单等扩展项均为框架内的待验证假设，使用时须以实际证据校验。
5. **场景适用性**：本框架针对短视频/图文内容型达人场景设计；纯直播带货型账号需调整样本口径（直播回放、弹幕、成交场记）。
6. **第三方数据口径**：T3 工具的预估销量/播放为推算值，与实测存在偏差，证据等级降一级标注。

## 失败模式

- 把活动型评论当内容认同（R9）
- 只看爆款总结"方法"，掉进幸存者偏差（R6）
- 拿快速排除的样本量下深度分析结论
- 拿抖音的标准判断小红书账号（R15）
- 把单一爆款当成上升期（R16）
- 把公开数据支持的判断，说成它支持不了的结论——这是分析中最容易失控的地方

## 框架来源说明

- 本框架为原创方法论，围绕"作品层 + 评论层 + 合作判断"的自有分析结构展开，规则与流程均由本 skill 自行定义，不依赖任何外部文档。
- 标注"推断"的条目为框架内的待验证假设，使用时须以实际证据校验。
