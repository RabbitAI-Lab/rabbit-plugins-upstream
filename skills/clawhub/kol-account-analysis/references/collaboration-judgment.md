# Step 5 — 合作判断：商品以什么身份进入

## 内容 × 评论对照

把同一条作品的内容和评论放在一起看：

- 播放、点赞和评论总数，回答的是**内容有没有被看见**
- 内容和评论放在一起看，回答的是**内容有没有被听懂**

第二个问题，才是内容优化和合作设计真正的入口。

内容 × 评论对照后通常出现四种典型情况。以下为本框架的设计定义，使用时须以实际证据校验：

| 情况 | 内容层 | 评论层 | 下一步动作方向 |
|------|--------|--------|----------------------|
| A | 讲了商品 | 用户接收到 | 直接设计进入场景，放大已有认知 |
| B | 讲了商品 | 用户没接收到 | 重设进入方式：换母题、换叙事位置 |
| C | 没讲商品 | 用户自发讨论商品 | 高势能信号，顺势而为 |
| D | 没讲商品 | 用户也不讨论 | 商品认知必须由内容从零主动建立 |

四种情况需要的下一步动作完全不同，但只看播放、点赞和评论总量时，可能长得很像。

## 信任可迁移性检验（推断）

达人合作的本质是购买「该达人对特定人群的特定信任」的使用权。四段公式的第四段（商品能以什么身份进入）隐含一个必须显式检验的假设：**用户信他的 A 品类推荐，不等于信他的 B 品类推荐。**

| 检验项 | 怎么判 | 证据来源 |
|--------|--------|---------|
| 信任品类边界 | 七维计数中「商品关注」类评论集中出现在哪些品类 + 信任资产信号中的记忆残留品类 | Step 4 |
| 历史商单品类 | 过往带货/商单中，什么品类互动不掉、什么品类明显掉 | T1/T3 数据源 |
| 专业人格 vs 生活人格 | 用户信的是他的专业判断（可迁移到强决策品类）还是他的生活方式（可迁移到低决策品类） | Step 3 母题 × Step 4 人物关注占比 |

跨品类迁移（如从运动装备到护肤）默认按"需要从零建立认知"处理，除非历史商单数据或记忆残留证明不掉互动。

## 合作形态建议（资深专家补充 v2.0，推断）

"适合/不适合"不是可交付的结论，**具体怎么合作**才是。基于 Step 3/4 的证据，给出可执行的合作形态建议：

| 合作形态 | 判断依据 | 前置条件 |
|---------|---------|---------|
| 内容种草植入 | 母题与商品场景匹配，融合度检查（3.7）通过 | 商品能自然进入某个稳定母题 |
| 品牌定制内容 | 内容深度强 + 用户信任高 + 母题可塑性强 | 信任可迁移性检验通过，割裂度低 |
| 直播助播 / 专场 | 需直播能力证据（口播、临场、历史直播数据） | 本 skill 默认无直播数据，缺则标注"需另行验证" |
| 信息流 / 效果投放 | 数据稳定 + 互动结构健康 + 素材可复用性高 | 与内容信任无关，按素材质量判断 |
| 长期内容合作 | 上升期 + 融合度高 + 无风险信号 | 生命周期判定为上升期或成熟期 |

**合作形态矩阵的定位：** 它把 Step 1 的内容任务翻译成可执行的合作方式，但仍不涉及报价、排期与效果承诺（品牌自有数据回答）。

## 风险清单（资深专家补充 v2.0，推断）

合作决策的另一半是风险排查。Step 1-4 全部完成后，逐项核查以下风险，发现任一命中即写入报告并给出规避建议：

| 风险项 | 怎么查 | 说明 |
|--------|--------|------|
| 舆情历史 | 历史争议、翻车事件、道歉声明 | 公开可查，属于本 skill 证据范围 |
| 立场敏感 | 政治/社会议题站队史 | 与品牌价值观冲突的立场 = 一票否决级风险 |
| 粉丝画像冲突 | 画像与品牌目标人群错位 | T1 官方画像 + 评论区结构交叉验证 |
| 水军痕迹 | 互动结构异常：赞多评少且评论空泛、点赞时间集中 | 只能标注"疑似"，不做刷量鉴定（见 honest-boundaries.md） |
| 内容合规史 | 医疗/金融/功效宣称类违规史 | 平台处罚记录、争议内容；合规边界本身由品牌法务把关 |

## 五问验收标准

一份完成的达人账号分析，不能只给出"适合"或"不适合"，至少要回答：

1. 这个达人**最适合承担什么内容任务**，又不适合承担什么任务；
2. 哪些**内容母题和表达方式是稳定的**，哪些只是偶发爆款；
3. 商品最自然的**进入场景、使用动作和叙事位置**是什么；
4. **用户已经认可他什么**，品牌又必须主动建立什么新的商品认知；
5. 哪些**人物梗、关系话题或意外细节**，最可能盖过商品记忆。

## 账号分析只是合作 Brief 的一半输入

- 达人账号分析解决的是"**这个人能怎样讲**"（本 skill）
- 商品价值分析解决的是"**这个商品值得讲什么**"——真实的产品价值、适用人群、使用动作、可用证据和合规边界（不在本 skill 范围内）
- 两边放在一起，合作 Brief 才真正成立

## 跨达人同口径对比卡（推断）

本 skill 单次只分析一个达人，但达人合作决策几乎总在多个候选人之间做。每次分析按统一字段输出「对比卡」，多次分析即可横向比较，避免"每份报告字段各说各话"：

| 字段 | 取值来源 | 说明 |
|------|---------|------|
| 内容任务适配结论 | 五问之 1 | 适合 / 不适合 / 条件适合 |
| 日常互动水平 | Step 3 中位数 | 同一统计口径（含异常剔除规则） |
| 生命周期阶段 | Step 3.3 | 上升 / 成熟 / 衰退 / 无法判定 |
| 稳定母题数 + 衰减标记 | Step 3 母题趋势表 | 如「6 条母题，2 条衰减中」 |
| 参与结构比率 | Step 4 | 评论/点赞、收藏/点赞 |
| 信任品类边界 | 信任可迁移性 + 记忆残留 | 用户已信任的品类清单 |
| 商品进入难度 | 五问之 3+4 | 从零建立 / 顺势放大 / 需重设计 |
| 合作形态建议 | 合作形态矩阵 | 主建议 + 备选 |
| 风险清单命中 | 风险清单 | 命中项 + 严重度 |
| 记忆盖过风险 | 五问之 5 | 高 / 中 / 低 + 主要风险源 |
| 证据覆盖等级 | 证据边界 | T1-T5 数据层 × 各层完整度 |

对比卡只做同口径沉淀，不替代多达人排序（那是筛选流程，超出本 skill 边界）。

## 三层选达人模型（本 skill 的定位）

1. **第一层：榜单和数据**——粉丝量、报价、CPM、预期播放量（大多数团队已做完）
2. **第二层：账号内容和用户评论**——本 skill 的主战场
3. **第三层：账号理解 × 商品价值**——判断商品应该怎样进入

真正决定一次合作能不能变成可复用能力的，是后面两层。

## 证据边界（强制章节）

- 结论能下多深，只由证据的覆盖决定。
- 真实的商业结果，必须由品牌自己的花费、曝光、点击、成交和退款数据来回答。
- 本 skill 的结论止步于"公开数据能够支持的判断"；工具/分析把证据备齐，判断由使用者自己下。
