# Step 3 — 读作品：他稳定在讲什么

这一步要回答的不是"他最火的是什么"，而是"他稳定在讲什么、现在处在什么阶段"。后者才是合作时真正能指望的东西。先读作品，不要先读评论。

## 3.1 先看置顶

置顶是达人自己认为的名片。

- 置顶与近期内容是一路的 → 账号方向相对稳定
- 明显对不上 → 账号可能正在转型，或定位还没有完全定下来（合作风险信号，写入报告）

## 3.2 按数据好坏分开看，不要只按时间顺序

把近期作品的点赞数导出来，要看的不是平均值，而是**最低值、中位数和最高值**。

> 示例：某账号日常内容点赞中位数四万出头，最高一条超过三十万，平均值被拉到七万以上。拿平均值去承诺效果，合作大概率被判定"没达标"；四万左右才更接近它的日常水平。

**双峰分布与异常样本剔除（推断）：** 平台推荐机制会造成流量池跳跃——同水平内容的数据呈双峰（进大流量池的爆、没进的平），中位数在双峰下也会失真。计算分布前先目检样本：远离主群的孤立高点/低点单独标注为「疑似流量池异常」，不入中位数计算，但保留在清单中供 Step 5 参考。

## 3.3 生命周期判定（资深专家补充 v2.0，推断）

达人是会过期的资产。合作的策略、报价位置、议价空间，都取决于他处在生命周期的哪个阶段。看**时间斜率**，不看单点：

| 阶段 | 判定特征 | 合作含义 |
|------|---------|---------|
| 上升期 | 近 3-6 个月互动率斜率向上，粉丝稳定增长 | 增长红利 + 报价洼地，适合谈长期合作；但要承担"能不能持续"的不确定性 |
| 成熟期 | 数据稳定在平台区间内波动，无趋势 | 可预测性强，适合稳定交付；议价能力强，难拿独家 |
| 衰退期 | 互动率斜率向下，或靠单一爆款撑数据 | 慎投或只做一次性；需判断是内容疲劳（可转型）还是平台流量流失（不可逆） |

**判定要点：**
- 单一爆款 ≠ 上升期——一次大爆可能只是流量池偶然，要看连续斜率与频率。
- 衰退期先归因：母题讲疲了（可救）vs 平台大盘下行（非达人问题）vs 内容劣化（不可逆）。
- 阶段判定必须基于 Step 2 的时间序列数据，无时间序列时标注"无法判定"。

## 3.4 归纳内容母题，不是贴标签

标签是"时尚""生活""美妆"。真正要找的，是这个账号翻来覆去一直在讲的**内容母题**。

> 示例：某头部男性生活方式账号反复在讲六件事——专业判断、年龄与状态、运动与学习、旅行体验、老友关系、日常自我管理。六件事都可能出爆款，但能帮品牌完成的任务完全不同：有的适合认真讲清楚产品价值，有的只适合让商品自然进入生活画面，还有的很容易被人物关系和公众记忆接管。

**时间趋势列（推断）：** 数据分布表增加按发布时间排列的互动率走势。横截面分布回答"水平多高"，趋势回答"母题还有没有生命力"——同一母题的互动率逐月下滑时，数据上依然"稳定"，但已经讲疲了；置顶 vs 近期只是粗糙的两点时间序列，月度趋势才能看到衰减斜率。

## 3.5 爆款归因：区分可复制与不可复制（资深专家补充 v2.0，推断）

只总结"爆款做了什么"不够，要拆出**到底是哪个要素让它爆的**。归因错了，方法论就错了：

| 归因要素 | 可复制性 | 说明 |
|---------|---------|------|
| 选题 | ✅ 可复制 | 话题本身有流量势能，可以设计复现 |
| 结构 | ✅ 可复制 | 开头钩子/节奏/收尾手法，可沉淀为模板 |
| 情绪 | 🟡 部分可复制 | 达人的表达感染力难模仿，但情绪类型可设计 |
| 时机 / 热点 | ❌ 不可复制 | 蹭中热点是概率事件，不能当能力写进 Brief |

每条爆款逐项标注主要归因要素。报告中的"候选规律"只能来自可复制要素；不可复制要素导致的爆款，明确标注"不可作为合作预期"。

## 3.6 拿数据差的作品反向验证

把从爆款里总结出来的做法，放到低数据作品里对照：

- 同样的开头、结构、场景在低数据作品里也大量存在 → 它不一定是规律，可能只是达人的习惯动作
- 一个做法，只有在**数据好的作品里反复出现、在数据差的作品里明显少见**，才更有资格被视为候选规律

**外因样本剔除（推断）：** "数据差"不全是内容问题——蹭热点失败（热点已褪色）、发布时间差、平台活动期挤压、疑似限流都会压低数据。反向验证前先剔除带明显外因标记的样本，否则会把"时机不对"误判为"手法无效"，错杀真规律。

这一步能筛掉大半"看起来有效、实际未必"的假经验。

## 3.7 硬广密度与内容割裂度（资深专家补充 v2.0，推断）

检查近期作品的商单占比与融合方式，直接决定账号还能承接多少品牌任务：

| 检查项 | 怎么判 |
|--------|--------|
| 商单密度 | 近期样本中商业内容占比：过高（>30%）说明信任库存被消耗，过低则需查证其商业变现路径 |
| 割裂度 | 商单是否沿用母题与惯用结构：突兀硬广多 → 粉丝对广告的防御强，植入成本高；融合自然 → 可承接更多品牌任务 |
| 评论区商单反应 | 商单作品下评论是"又来打广告"还是正常讨论 → 前者是信任受损信号 |

## Step 3 产出

1. **数据分布表**：最低 / 中位数 / 最高（附样本量 N，剔除疑似流量池异常后），注明"日常水平由中位数近似"
2. **生命周期判定**：上升 / 成熟 / 衰退 / 无法判定（附判定依据与时间斜率）
3. **母题趋势表**：每条母题按月的互动率走势（识别"讲疲了"的衰减母题）
4. **母题清单**：每条母题 + 支撑作品数 + 稳定性判定（稳定母题 / 偶发爆款专属 / 衰减中）+ 各母题能帮品牌完成的任务类型
5. **爆款归因表**：主要爆款各自的归因要素（可复制 / 不可复制）
6. **候选规律清单**：经反向验证（含外因剔除）幸存的表达手法（开头/结构/场景）
7. **硬广密度与割裂度结论**
8. **账号方向稳定性**：置顶 vs 近期的一致性结论
