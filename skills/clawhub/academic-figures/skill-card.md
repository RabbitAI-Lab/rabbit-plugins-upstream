## Description:

Generates publication-ready scientific figures from JSON, CSV, or Excel data using local Python scripts, with chart templates, journal presets, validation checks, and multi-format export.

This skill is ready for commercial/non-commercial use.

## Publisher:

[docsor1212](https://clawhub.ai/user/docsor1212)

### License/Terms of Use:

MIT-0

## Use Case:

Researchers, students, clinicians, and technical users use this skill to turn tabular study data into journal-ready charts, statistical figures, composite panels, PRISMA diagrams, legends, and export files. It is useful when an agent needs to select chart types, generate commands, prepare input schemas, or run local scripts that create figures and verification sidecars.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Local scripts read user-provided data files and write figures, reports, and optional sidecar files.

Mitigation: Run the skill only in a trusted local environment, review file paths before execution, and avoid exposing sensitive research or clinical data unnecessarily.

Risk: The artifact mentions a separate cloud Pro service, which has a different data-handling posture from the local tool.

Mitigation: Treat local execution and the cloud service separately; review data sensitivity and service terms before uploading data to any external service.

Risk: Some messages and examples are Chinese-first, which may affect review clarity for non-Chinese readers.

Mitigation: Have generated commands, diagnostics, and outputs reviewed by someone who can confirm the language-specific messages before relying on them in a publication workflow.
