## Description:

Generate publication-ready scientific figures from data with a command-line workflow, a broad set of chart types, journal presets, and static export formats.

This skill is ready for commercial/non-commercial use.

## Publisher:

[docsor1212](https://clawhub.ai/user/docsor1212)

### License/Terms of Use:

MIT-0

## Use Case:

Researchers and data analysts can turn JSON, CSV, or Excel datasets into publication figures for papers, journal submissions, and repeatable batch rendering. The skill covers statistical and scientific charts, with journal presets and export options for common figure formats.

### Deployment Geography for Use:

Global
