## Description:

Creates publication-ready scientific figures from data, with journal presets and static image or document exports.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Researchers and developers use the skill to turn study data into figures for papers and journal submissions, including batch figure generation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security assessment reports unpinned install sources and optional network-based dependency repair.

Mitigation: Review setup behavior and dependency sources before installation; check package versions and network access against your environment's requirements.

Risk: The security assessment reports scientific-output concerns.

Mitigation: Check the statistical assumptions, input data, and rendered figures before relying on them in a publication.

Risk: Some portions were only partially inspected, so the assessment does not establish that uninspected behavior is safe.

Mitigation: Review the skill before installation, particularly before using it with sensitive research data or where fully local operation is required.
