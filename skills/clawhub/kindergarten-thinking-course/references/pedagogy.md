# 幼儿园思维课程 · 教学法与家长话术

## 教学原则
1. **具象先于抽象**：L1-L2 优先用实物（水果、积木、贴纸）演示，再落到纸面。
2. **先说再做**：让孩子先用语言描述规律/分类标准，再动笔，培养元认知。
3. **过程重于结果**：关注"为什么这样分"，而非只对答案。
4. **正向反馈**：先肯定具体行为（"你把红色的都找出来了，真仔细"），再指出一个改进点。
5. **不横向比较**：只和孩子自己比，禁止"别人都会了你不会"。

## 分题型讲解话术

- **分类**："我们来看看，哪些是一家的？把它们圈在一起。"→ 引导说出标准（颜色/类别）。
- **规律**："你发现它们在怎么变吗？接下来应该是什么？先说出来再填空。"
- **排序**："谁最小？谁最大？我们从小到大排排队，给它们编号。"
- **图形**："这个尖尖的是三角形，那个圆圆的是圆形，把三角形都圈出来。"
- **方位**："小熊在房子上面还是下面？用手指一指。"
- **比较**："哪边多？我们一个对一个连一连，多出来的是哪边？"
- **迷宫/找不同**："眼睛像小侦探，从门口找到礼物，别走错路哦。"

## 常见错误与纠正
- 分类标准混乱 → 先固定一个标准（"今天我们只按颜色分"），再逐步加维度。
- 规律只看到一步 → 提示"再看前面两个，它们是怎么排队（循环）的"。
- 方位左右混淆 → 用身体示范：伸出左右手对应左右，把图转成和孩子同向。
- 排序凭感觉 → 引入"两两比一比"的锚定法。

## 家长反馈模板（固定三段）
1. **结果**：本次共 X 题，做对 Y 题，正确率 Z%。
2. **薄弱点**：主要在【题型】上需要加强（具体到题型，不评价孩子能力）。
3. **下一步**：今天可以玩一个 5-10 分钟的小游戏——【游戏名 + 一句话玩法】。

### 亲子小游戏示例
- 分类：把家里的袜子按颜色/大小分堆。
- 规律：用贴纸排 ABAB 规律，让孩子接着贴。
- 方位：藏东西说"在沙发左边"，让孩子找。
- 比较：两堆积木比多少，一个对一个配对。
- 观察：两幅图找不同（实物图或书）。

## 反馈禁语
- "这么简单都不会" / "你看别人" / "你怎么又错了"
- 改用："这一题有点难，我们换个方法试试。"
