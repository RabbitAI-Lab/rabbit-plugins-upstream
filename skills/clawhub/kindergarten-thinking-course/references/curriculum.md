# 幼儿园思维课程体系 · 课程大纲（L1-L4）

本文件定义各等级的知识点、题型映射、晋级与补练标准、诊断定位规则。脚本 `scripts/generate_worksheet.py` 的题型名（topic）已与下表对齐。

## 等级对照

| 等级 | 年龄段 | 主要能力目标 | 典型题型（topic） |
|---|---|---|---|
| L1 | 小班 3-4 岁 | 基础分类、一一对应、初步观察 | classify, match, same, diff, compare, position, maze |
| L2 | 中班 4-5 岁 | 排序序列、规律补全、图形辨识、完整方位、对应巩固 | classify, match, order, pattern, shape, position, compare, diff, maze |
| L3 | 大班 5-6 岁 | 模式推理、等量代换思维、空间想象、观察力 | pattern, shape, position, compare, diff, maze, order |
| L4 | 幼小衔接 6-7 岁 | 综合逻辑思维、图形规律、空间综合、等量代换 | pattern, shape, position, compare, maze, order, swap |

## 知识点明细

### L1 基础分类与对应
- 分类：按颜色 / 按类别（水果·动物·交通工具）圈出同类
- 找相同：在一组图中找出两个相同的
- 找不同：在一组相同图中找出一个不同的
- 比较：两组数量比多少
- 方位：上 / 下 两个方向
- 迷宫：5×5 简单连通迷宫

### L2 排序 · 规律 · 方位
- 排序：按大小 / 长短 / 高矮排成序列并编号
- 规律：AB、ABB、AAB 模式的补全
- 图形：辨识并圈出指定形状（圆/方/三角/长方/星/心）
- 方位：上 / 下 / 左 / 右 / 前 / 后 / 里 / 外（本生成器覆盖上下左右）
- 比较：比高矮（柱子图）
- 找不同：9 格中找不同

### L3 模式推理 · 等量代换
- 规律：ABC 模式、更长序列的 1-2 处空缺
- 图形：多形状混合中按条件筛选
- 方位：任意两图相对方向推理
- 比较：多对象排序（如 3 根柱子从高到矮）
- 迷宫：7×7 进阶迷宫
- 观察：9 格找不同

### L4 综合逻辑思维
- 规律：ABCA、ABCB 等复杂循环
- 图形：形状组合与对称意识
- 方位：多对象空间排位推理
- 比较：等量关系初步（可结合配对题型引申"几个换几个"）
- 迷宫：7×7 迷宫

## 晋级标准
- 单份练习正确率 ≥ 90% → 可升下一级
- 60%-89% → 同级加练，错题题型占比提到 50%
- < 60% → 降一级，先实物操作再回到抽象题
- 每级至少完成 3 份练习才考虑晋级；连续两次 ≥ 90% 才允许跳级

## 诊断定位规则（起点未知时）
1. 生成诊断卷（`--preset diagnostic`，覆盖全部题型的 10 题，每题标注等级）。
2. 家长回传结果后，按"某等级 2 题全对即视为掌握"判断。
3. 从最低未掌握等级开始正式练习。
4. 若诊断显示 L1 也大量错误，先回到实物操作（如真实水果分类、积木配对），再回到纸面。

## 错题库与补练
- 同一题型错 ≥ 2 题 → 触发错题重练（见 SKILL.md Step 4）。
- 错题重练配方：读旧 JSON → 按错题题型生成同型新题，每错题配 2 道。
