## 初衷

> **专利数据本身不产生洞察，行业语境才产生洞察。**

同一批专利，不知道这家公司在做什么产品、不知道行业有哪几条技术路线、不知道你自己在评估什么决策——分析出来的只能是「该公司专利数量较多，涵盖正极、负极、电解液」这种谁都会说的话。

所以这个 Skill 把重心放在**素材**上：你喂进去多少行业背景，它才能往前走多远。它要的不是一个公司名，是你手里那些招股书片段、发布会通稿、调研笔记、以及你自己对格局的判断。

有了这些，它去全球专利库里验证、补全、找出你没注意到的动作，再输出一份**每条判断都能追到公开号**的报告。

专利申请比产品发布早一到两年——对手两年前的申请，往往就是明年的产品。这是专利情报真正的价值所在，而它需要有人把行业语境喂进去才能被读出来。

## 能做什么

给一个分析主题和一批素材，异步生成**企业技术专利竞争分析报告**：

- **竞争格局** — 谁是主要玩家、各自占什么位置、技术路线趋同还是分化
- **对手动作** — 近期申请集中在哪、和公开产品路线是否对得上、有没有卡位意图
- **我方位置** — 空档在哪、哪些方向已经拥挤、绕不开的核心专利是哪几件
- **可交付文档** — 直接导出 Word，拿去开会

数据来自 iprdb 全球专利库（自建数据源），并可把**论文、网页、新闻、标准、诉讼**一并计入分析来源——做前沿判断时论文比专利早，做应诉准备时诉讼信息不能少。

支持指定目标市场、竞争对手名单、时间范围、排除方向。

## 怎么用

在 [api.ip930.com](https://api.ip930.com/features/api-platform) 创建密钥，设成环境变量：

```bash
export PATENTMAX_API_KEY="pm_live_你的密钥"
```

```bash
python scripts/patentmax_competitive.py create \
  --subject "宁德时代在钠离子电池方向的专利布局" \
  --materials-file ./materials.md \
  --objective "评估我方在钠电正极材料方向立项的竞争环境与专利风险" \
  --competitors "比亚迪股份有限公司,中创新航科技股份有限公司" \
  --markets "CN,US,EP" --time-range "近五年" \
  --wait --yes
```

跑几十分钟，进度会实时打出来（`[35%] 正在检索竞争对手专利`）。完成后：

```bash
python scripts/patentmax_competitive.py download --report-id <report_id> --out 竞争分析报告.docx
```

只用 Python 标准库，不需要 `pip install`。没有 Python 就直接发 HTTP 请求，示例在 `references/faq.md`。

新用户注册即送 ¥50 体验额度。

## 素材决定一切

这是整件事里最重要的部分，`references/materials-guide.md` 里有三个颗粒度的真实对照：

**❌ 「分析宁德时代的电池专利」** — 出来的是常识复述，你不需要花钱知道这个

**✅ 写清楚三块** — 分析对象是谁（工商全称、集团下属主体、已知产品）、你关心什么（技术路线 / 空档 / 侵权风险 / 资产估值）、你已经知道什么（竞争格局、行业共识、对方近期动作）

素材上限 10 万字。招股书片段、技术白皮书、行业报告、调研笔记直接贴，不用先总结。**准备素材花的十分钟，直接换成报告的质量。**

脚本会在素材少于 200 字时拦下来——那个长度写不出有用的分析。

## 它不做什么

**不出保证性结论。** 不写「该企业在此方向无专利布局」「不存在专利风险」。正确表述是「截至某日期、在所列范围内未检索到……，本结果不排除未公开申请、名称未归一化的关联主体、数据库缺口造成的漏检」。

**18 个月公开窗口。** 专利从申请到公开有约一年半，对手最新的动作大概率不在数据里，这一点每次都要讲明白。

**申请人名称未做集团归一化。** 同一集团可能以中文名、英文名、子公司名分散，查跨国集团要分主体再合并——所以素材里写明集团结构很重要。

**不替代法律意见。** 侵权、无效、许可的判断以各国专利局官方登记簿和代理人意见为准。

**不给布局建议。** 这个 Skill 讲现状——格局是什么、对手在哪。「我们下一步该往哪走」是技术路线分析要回答的问题。
