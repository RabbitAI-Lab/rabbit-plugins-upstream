# 素材怎么准备

素材（`materials`）是这个任务里唯一由你控制、且直接决定产出质量的输入。专利数据是死的，素材是活的——同一批专利，给不同的行业语境，能得出完全不同的结论。

字段上限 10 万字。**宁可长，不要空。**

## 三块必须有的内容

### 一、分析对象是谁

只给一个公司名，模型只能从专利数据反推它是干什么的——行业语境、业务重心、近期动作全丢了。

至少写清楚：

- **工商全称**（不是简称。简称在专利库里匹配不准，也容易和同名个人混淆）
- 主营业务、在这个技术方向上的位置
- 已知的相关产品、产线、公开发布的技术路线
- 如果是集团，旗下哪些主体会以自己的名义申请专利

### 二、你关心什么

同一批数据，问题不同，报告完全不同。明确写出来：

- 想知道对方的**技术路线**（他往哪走）
- 还是想找自己的**空档**（哪里没人占）
- 还是要评估**侵权风险**（我做这个会不会撞上）
- 还是做**并购尽调**（这家公司的专利资产值多少）

### 三、你已经知道什么

这一块最容易被跳过，但决定了报告是"告诉你新东西"还是"重复你早就知道的常识"。

- 已知的竞争格局，谁强谁弱
- 行业公认的技术路线分支
- 对方近期的公开动作：发布会、招股书、专利诉讼、人事变动
- 你自己的技术方案（如果涉及对比）

把这些写进去，报告才能在你已知的基础上往前走。

---

## 三个颗粒度对照

### ❌ 太短，跑出来是常识复述

```
分析宁德时代的电池专利。
```

模型只能给你一份"宁德时代是动力电池龙头、专利很多、涵盖正极负极电解液"的报告。你不需要花钱知道这个。

### ⚠️ 中等，能用但不够锋利

```
宁德时代新能源科技股份有限公司，动力电池行业龙头，我们关注它在钠离子
电池方向的布局。我们公司做正极材料，打算立项钠电正极。
```

有主体、有方向、有目的，报告会围绕钠电正极展开。但缺少"已知什么"，模型会把行业常识也写进来占篇幅。

### ✅ 够用，能出有决策价值的分析

```
分析对象：宁德时代新能源科技股份有限公司（含子公司时代上汽、时代广汽等
以独立主体申请的部分）。动力电池全球出货第一，2021 年发布第一代钠离子
电池，宣称能量密度 160Wh/kg，采用普鲁士白正极 + 硬碳负极路线，2023 年后
公开信息减少。

我们关注：钠离子电池正极材料方向。我们是正极材料厂商，现有产线做磷酸铁锂，
正在评估是否立项钠电正极，候选路线是层状氧化物（成本低、但循环性差）
和聚阴离子（稳定但能量密度低）。

已知格局：普鲁士类化合物专利多在宁德时代和中科海钠手里；层状氧化物国内
多家在做，专利较分散；聚阴离子路线海外（法国 Tiamat）起步早。我们判断
普鲁士类已经很拥挤。

分析目标：确认宁德时代在层状氧化物和聚阴离子两条路线上是否有布局、
布局到什么程度，以及我们如果走层状氧化物，会不会撞上它的核心专利。
```

这份素材里，模型能拿到：主体边界（含子公司）、技术路线的具体分支、时间线、你的判断、明确的决策问题。出来的报告才可能回答"该不该立项"，而不是"宁德时代很厉害"。

## 几个提高质量的做法

**把技术术语的多种写法都列上。** 钠离子电池 / 钠电 / Na-ion，层状氧化物 / 层状过渡金属氧化物。专利文献里用词不统一，你给的词越全，召回越准。

**集团要列出子公司。** 申请人名称没有做集团归一化，同一集团以中文名、英文名、子公司名分散在不同记录里。你知道哪些主体属于同一集团，就在素材里写明，否则报告会严重低估对方的专利量。

**把你的判断也写进去，并标明是判断。** 「我们判断普鲁士类已经很拥挤」——模型会去验证这个判断对不对，这比它自己漫无目的地扫一遍有价值。

**贴原文比转述好。** 招股书片段、发布会通稿、产品手册、财报里的技术章节，直接贴进去，不用你先总结。10 万字的空间足够。

**不相关的方向明确排除。** 用 `--excluded` 参数或在素材里写明，避免报告被无关分支稀释篇幅。

## 素材从哪来

- **企业官网 / 产品页** — 技术路线的官方表述
- **招股书、年报、财报** — 技术章节通常写得比新闻稿实在
- **发布会通稿、技术白皮书** — 有具体参数
- **行业研究报告** — 竞争格局的现成梳理
- **专利诉讼公开信息** — 对方真正在意什么，看它为什么打官司
- **标准提案** — 参与标准制定说明技术路线已经定型
- **你自己团队的调研笔记** — 往往是最有价值的那部分

准备素材花的时间，直接换成报告的质量。这个任务是付费的，**多花十分钟整理素材，比跑两次划算**。
