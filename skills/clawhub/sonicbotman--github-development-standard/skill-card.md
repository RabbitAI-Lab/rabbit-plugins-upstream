## Known Risks and Mitigations:

Risk: GitHub CLI examples can comment on or close issues in a repository.

Mitigation: Review each command, repository target, issue number, and body text before running it.

Risk: The workflow guide is written in Chinese and may be misread by users who are not comfortable with that language.

Mitigation: Use the skill only when the operator can accurately understand the checklist and command guidance.
