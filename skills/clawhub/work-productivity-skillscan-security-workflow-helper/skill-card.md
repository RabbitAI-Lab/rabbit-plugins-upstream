## Known Risks and Mitigations: <br>
Risk: Broad automatic activation wording could route unrelated security, bug-fix, or workflow requests to this skill. <br>
Mitigation: Narrow implicit invocation and triggers to explicit SkillScan-style security workflow requests before relying on automatic activation. <br>
Risk: Generated workflows, code changes, or checklists may affect security or reliability decisions if accepted without review. <br>
Mitigation: Review and scan any proposed workflow, configuration, or code change before deployment. <br>
