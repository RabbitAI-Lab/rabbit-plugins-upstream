## Description:

Helps agent users, skill authors, maintainers, and teams create practical SkillScan-style workflows for bug fixing, safety hardening, reliability checks, and adjacent skill planning.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, skill authors, maintainers, and agent teams use this skill to turn SkillScan-style security and reliability needs into actionable plans, checklists, code changes, or review workflows. It is suited for local, CPU-friendly workflow assistance rather than hidden automation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may be selected for unrelated prompts because its trigger wording is broad and generic.

Mitigation: Use it for explicit SkillScan-style security workflow, hardening, reliability, or bug-fix gating tasks, and narrow trigger metadata before broad deployment.
