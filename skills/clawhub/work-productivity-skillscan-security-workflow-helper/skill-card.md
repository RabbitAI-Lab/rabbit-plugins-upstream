## Description:

Helps AI-agent users, skill authors, maintainers, and teams create practical workflows, checklists, analysis, or implementation support for SkillScan-style security, hardening, reliability, and adjacent workflow tasks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

AI-agent users, skill authors, maintainers, and teams use this skill to turn security, hardening, bug-fix, reliability, and workflow-improvement requests into concise plans, reusable checklists, analysis, code changes, or decision support.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger language and implicit invocation may cause the skill to be selected for generic security or productivity requests where a narrower skill would be more appropriate.

Mitigation: Review activation behavior before deployment and narrow trigger terms if precise routing matters.
