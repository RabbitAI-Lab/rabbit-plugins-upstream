## Description:

Helps AI-agent users and skill authors turn SkillScan-style security workflow needs into actionable plans, checklists, analyses, code changes, and verification notes.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, skill authors, maintainers, and AI-agent teams use this skill to structure security-adjacent workflow assistance, including bug fixes, setup hardening, reliability improvements, and adjacent skill planning.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may be selected automatically for unrelated prompts because its implicit invocation triggers include broad common words such as security, every, must, and bug fix.

Mitigation: Review before installation and prefer disabling implicit invocation or narrowing triggers to explicit SkillScan-style workflow assistance.
