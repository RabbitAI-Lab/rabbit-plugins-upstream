## Description: <br>
Design original 2D browser plane-shooter prototypes with continuous movement, readable threat waves, a route-and-resource decision, clear terminal states, and fast retry. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[opengameapp](https://clawhub.ai/user/opengameapp) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and designers use this skill to create or revise small browser-based plane shooter prototypes for mobile portrait or desktop play. It supports either a design-only handoff or generated local game files with clear states, route-and-resource decisions, and testable game state. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated game prototypes may accidentally introduce unlicensed assets, copied game identity, remote dependencies, analytics, or hidden outbound requests. <br>
Mitigation: Review generated files before use, prefer original or procedurally generated assets, and verify that the output avoids remote scripts, credentials, analytics, and unexpected network requests. <br>
Risk: A runnable prototype can still need human review for accessibility, visual quality, gameplay feel, licensing, and IP concerns. <br>
Mitigation: Treat test evidence as functional evidence only and complete human review before presenting the prototype as production-ready or release-ready. <br>
