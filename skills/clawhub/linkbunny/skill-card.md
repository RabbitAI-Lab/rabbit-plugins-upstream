## Description:

Builds backlinks by linking backlinks to other sites. Use when user says "build backlinks" or "linkbunny"

This skill is ready for commercial/non-commercial use.

## Publisher:

[linkbunny](https://clawhub.ai/user/linkbunny)

### License/Terms of Use:

MIT-0

## Use Case:

External site owners use this skill to manage LinkBunny profiles, review backlink assignments, and coordinate relevant nofollow link placements through their site's normal publishing workflow. An eligible paid subscription and explicit owner authorization are required for consequential account, site, and publication actions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Using the paid service involves sharing site and placement details with LinkBunny, and a proposed link could be unsuitable for the site.

Mitigation: Use the service only if that information sharing is acceptable, keep the API token in an ignored private file or secret store, and review each proposed placement before explicitly authorizing publication.
