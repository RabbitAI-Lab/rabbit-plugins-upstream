## Description:

Researches major agent harness, runtime, coding-agent, skills, subagent, and plugin releases, producing verified facts, architecture explanations, layered impact analysis, and a source register that separates judgment from evidence.

This skill is ready for commercial/non-commercial use.

## Publisher:

[haiyangchenbj](https://clawhub.ai/user/haiyangchenbj)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and platform teams use this skill to assess what an agent runtime or harness release changes, how it works, and what it may mean for coding agents, skills, plugins, evaluation, and enterprise adoption.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill's report is designed to be written concisely in Chinese, which may not suit every user.

Mitigation: Confirm that Chinese output is appropriate for the intended audience before using the report.

Risk: The security review reports that a local reference could not be resolved, leaving its scan evidence incomplete.

Mitigation: Check referenced material and verify release-specific claims against current primary sources.
