## Description:

Researches major agent harness, runtime, coding-agent, skills, subagent, and plugin releases with verified facts, architecture explanation, ecosystem impact, and separated judgment and evidence.

This skill is ready for commercial/non-commercial use.

## Publisher:

[haiyangchenbj](https://clawhub.ai/user/haiyangchenbj)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, engineers, and agent platform teams use this skill to analyze major agent runtime and plugin ecosystem releases, including architecture, facts, impacts, comparisons, uncertainties, and source quality.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Release claims can become stale or misleading if current source searches are skipped.

Mitigation: Require current first-party or reliable secondary sources for dates, versions, licenses, benchmark claims, and architecture facts.

Risk: The skill defaults to concise Chinese writing, which may not match every user's expected language.

Mitigation: Ask for another language when needed and keep evidence boundaries explicit in the requested language.
