## Description:

Plans knowledge-base placement paths and writes workspace export files.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wxt-ai](https://clawhub.ai/user/wxt-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Knowledge-base publishers use this skill to plan a placement path for a note, report, or article and record the selected workspace export path.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: An export could target the wrong workspace path or overwrite an existing file.

Mitigation: Confirm the intended workspace path and whether an existing file may be overwritten before exporting.
