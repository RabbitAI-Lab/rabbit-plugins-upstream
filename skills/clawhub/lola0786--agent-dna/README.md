# PrivateVault Agent DNA

Agent DNA creates a cryptographically verifiable behavioral identity for AI agents.

Instead of trusting every action equally, Agent DNA continuously evaluates runtime behavior, trust, receipts, and policy evidence before execution.

Part of the **PrivateVault Decision Security Control Plane**.

---

## Features

- Behavioral Identity
- Runtime Trust Score
- Receipt Verification
- Behavioral Fingerprint (SHA-256)
- Allow / Review / Block Decisions
- Enterprise Policy Ready

---

## CLI

```bash
privatevault dna inspect
```

Inspect runtime behavioral identity.

```bash
privatevault dna fingerprint
```

Generate a deterministic Agent DNA fingerprint.
