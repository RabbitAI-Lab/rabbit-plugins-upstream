# 继承纠纷举证质证要点

根据案情和诉讼角色生成继承纠纷举证质证及证据补强清单。

## 功能概述

本技能为中国大陆继承纠纷案件提供系统化的举证质证指引，覆盖以下争议模块：

- 法定继承与继承人资格
- 代位继承与转继承
- 遗嘱效力确认
- 遗嘱解释与执行
- 遗产范围确认与分割
- 被继承人债务清偿
- 遗赠
- 遗赠扶养协议
- 遗产管理人
- 非继承人适当分得遗产
- 继承权丧失与恢复
- 诉讼程序、时效与新旧法衔接

## 工作流

1. 建立案件画像（当事人关系、继承方式、程序阶段等）
2. 选择争议模块
3. 检索参考框架与原始资料
4. 构建证据矩阵（证据名称、待证事实、举证责任、质证意见、风险等级、补强动作、法律依据）
5. 检查证据链完整性
6. 输出结果（案件画像、证据清单、质证矩阵、证据缺口、庭审提纲、法律依据、风险提示）
