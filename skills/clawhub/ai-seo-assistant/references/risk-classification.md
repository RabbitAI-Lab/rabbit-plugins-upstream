# 修改风险分级与执行规则

SKILL.md 第 13–14 步依赖本分级：脚本在 `suggestions[].risk` 标记 `low` / `high`，据此决定**自动执行**还是**请求确认**。

## 低风险（low-risk）：可直接执行

特征：只改页面元信息/附加结构化数据，不改动页面结构、URL、内容语义，不影响已有收录与外链。

| 建议类型 | 动作 | 风险点 |
| --- | --- | --- |
| 补充/修正 `meta description` | 写 description | 仅文本，不改结构 |
| 补充 `meta keywords` | 写 keywords | 仅文本 |
| 修正 title 长度/前置关键词 | 改 title 文本 | 不改 URL，不改结构 |
| 补充图片 `alt` | 写 alt 属性 | 仅属性 |
| 补充 `viewport` / `lang` | 写元标签 | 仅元信息 |
| 补充 `canonical` | 写 link 标签 | 指向自身 |
| 注入 JSON-LD 结构化数据 | 追加 script | 仅附加，不影响渲染 |

> **MCP 写操作注意**：即便低风险，凡涉及 MCP 写操作（如改写页面源码）仍须先展示目标+影响并取得用户确认（见对应建站/CMS 技能的写操作确认基线）。脚本只负责产出「应做的事」，真正落盘由 Agent 在确认后执行。

## 高风险（high-risk）：必须请求确认

特征：改动标题层级/内容结构/索引指令/全站基础设施，可能导致收录波动、布局错乱或排名下降。

| 建议类型 | 动作 | 风险 |
| --- | --- | --- |
| 新增/合并 H1、调整 heading 层级 | 改结构 | 布局与语义变化 |
| 正文内容扩充/重写（薄内容） | 改内容 | 内容策略风险 |
| 移除 `noindex` / 改 `robots.txt` | 改索引指令 | 收录范围变化 |
| 启用 HTTPS / 全站协议迁移 | 基础设施 | 需 301 + 混合内容排查 |
| 内部链接结构重构（解决孤岛页） | 改结构 | 权重传递变化 |
| 关键词注入到标题/H1 | 改标题层级 | 影响语义与排名 |

## 确认话术模板（高风险）

> ⚠️ 以下为**高风险修改**，执行前需你确认：
> 1. [维度] [页面] — [具体问题] — 计划：[动作] — 影响：[外链/收录/布局]
> 2. …
> 确认执行 / 跳过 / 调整后执行？

确认后记录在报告中（建议追加 `applied: true/false` 字段），再进入「重新检查」。
