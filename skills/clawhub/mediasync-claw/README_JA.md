## 📖 概要とコアバリュー

**MediaSync-Claw** は、個人の動画・音声ファイルをリモートから安全にストリーミングするために設計された **OpenClaw Skill** および **P2Pメディアサーバー** です。

OpenClaw を介して WhatsApp と連携することで、外出先からいつでも自宅PC内のメディアライブラリを検索・取得できます。生成されたメディアリストは、**AIpollo Player** による高速P2P通信でスムーズに再生可能です。

---

## ⚙️ 前提条件

* **OpenClaw**: ローカル環境に OpenClaw が正常にデプロイされていること。
* **セキュリティソフトの例外設定**: Windows Defender などのセキュリティソフトで `frpc.exe` を信頼（除外設定）に追加してください。*本プロジェクトの `frpc.exe` は改ざんのない安全なバイナリです。*

---

## 🚀 インストールと利用手順

1. **ダウンロードと配置**: 本リポジトリをダウンロードし、OpenClaw の skills ディレクトリに配置します。
2. **動画フォルダの作成**: 本スキルフォルダ内に `videos` ディレクトリを作成し、リモート再生したい MP4 ファイルを保存します。
3. **WhatsApp の連携設定**: OpenClaw 上で WhatsApp 連携を設定します。
4. **スキルの起動**: OpenClaw で MediaSync-Claw スキルを実行します。
5. **WhatsApp からリモート操作**: WhatsApp チャット上で「動画一覧を見せて」「動画を再生」などのメッセージを送信すると、本スキルが呼び出され、メディアリストが返信されます。
6. **ワンタップ再生**: リスト内のリンクをクリックし、AIpollo Player で動画をストリーミング再生します。

## 🔒 セキュリティとリスク開示

### リスク 1: FRPリバースプロキシによるパブリックアクセス
NAT越えおよびリモートアクセスを実現するため、FRP（Fast Reverse Proxy）クライアント（`frpc`）を使用してリレーサーバー（`frps`）へのアウトバウンドトンネルを確立します。これにより、ローカルのメディアサービスが `*.yunfrp.net` 経由でルーティングされます。

### リスク 2: HTTP平文通信とP2Pストリーミング
実際の動画データ転送には **P2P（ピアツーピア）直接通信** を使用します。HTTP 通信は軽量な制御コマンドの送受信のみに限定されており、ユーザーの機密情報が含まれることはありません。

### リスク 3: `frpc.exe` バイナリの自動取得
安全性を最大限確保するため、ネットワーク越えに必要な `frpc.exe` は公式の GitHub Releases から直接取得されます。
