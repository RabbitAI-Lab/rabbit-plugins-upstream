## Description:

A collection of Flyelep AI agent skills for creating e-commerce posters, AI-generated videos, and edited images through Flyelep APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[flyelepai](https://clawhub.ai/user/flyelepai)

### License/Terms of Use:

MIT-0

## Use Case:

External developers can use these skills with OpenClaw, Claude Code, or other agents to submit Flyelep API requests for media generation and image editing. The skills can also upload local media to obtain temporary public links for those requests.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: ClawScan marks this listing suspicious because workflows may send local media to third-party storage that can provide publicly accessible links; two referenced skill contents were only partly inspected.

Mitigation: Review the referenced skill content before installation, and avoid uploading sensitive media unless you understand and accept the public-link exposure. Treat returned upload links as temporary and use them only for the intended operation.
