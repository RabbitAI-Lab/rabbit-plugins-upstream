**动态解读示例（两类高频场景）**

- **场景A｜生成方式未标识**：一条由人工智能生成画面与配音的产品科普短视频直接投放，画面与简介均未作生成方式说明 → 被认定为标识义务履行不足。**改进动作**：在片头固定 1.5 秒角标 + 简介首行说明"本视频部分内容由人工智能技术生成"，并把该要求写入模板。
- **场景B｜风险提示与产品信息不同屏**：产品介绍长文中，收益相关信息置于开头，风险提示折叠在文末"展开阅读全文"内 → 虽已提示但被认定为弱化风险。**改进动作**：核心产品信息区与风险提示同屏出现，风险提示字号不小于正文字号的 80%，且不做折叠。

#### 1.1 Compliance Rewrite Reference / 合规改写对照（下表均为禁止使用的示例）

| 禁止使用的示例 | 命中问题 | 合规改写方向 | 适用渠道 |
|-------------|---------|-----------|---------|
| "稳赚不赔，年化 X%" | 保本保收益承诺 + 绝对化用语 | 改为"该产品为净值型，业绩比较基准为 X%（不构成收益承诺），详见产品说明书" | 全渠道 |
| "最后 3 个名额，错过再等一年" | 虚假紧迫感 | 改为"本期额度售完即止，下期安排以官方公告为准" | 短信、APP |
| "收益是定期存款的 3 倍" | 违规比较收益 | 改为"与同期限产品业绩比较基准存在差异，具体详见说明书" | 海报、朋友圈 |
| "闭眼买，跟着我赚" | 无依据推荐 + 承诺收益 | 改为"以上为公开信息梳理，不构成投资建议，请结合自身风险承受能力判断" | 直播、社媒 |
| "内部消息，下周必涨" | 虚假信息 + 承诺收益 | 删除该表述，改述为"市场存在不确定性，请注意风险" | 全渠道 |

> **使用说明**：本表仅用于合规培训与内部自查对照，禁止在对外内容中原样出现左侧表述。

### 3. Production Workflow / 内容生产流程

| 环节 | 动作 | 输出物 | 责任岗 | 卡点 |
|-----|------|-------|-------|------|
| 1 选题 | 结合产品节奏与用户关注点 | 选题清单 | 内容运营 | 避开敏感时点与不确定信息 |
| 2 初稿 | 套用模板撰写 | 初稿文档 | 内容作者 | 数据须标注来源 |
| 3 合规审查 | 违禁词校验、适当性核对、标识检查 | 审查意见 | 合规 | 不通过则退回 |
| 4 业务确认 | 核实产品要点与费用口径 | 确认记录 | 业务条线 | 口径以产品说明书为准 |
| 5 定稿与发布 | 版本登记、标识添加 | 定稿版本号 | 内容负责人 | 人工确认后方可对外发布 |
| 6 归档 | 留存审定版本与发布时间 | 素材版本库记录 | 内容运营 | 保留备查 |

### 4. Compliance Review Checklist / 内容合规审查清单

| 检查项 | 判定标准 | 常见缺陷 |
|-------|---------|---------|
| 收益类表述 | 使用"业绩比较基准"，附不构成承诺说明 | 直接写"预期收益""年化最高" |
| 绝对化用语 | 无"最""第一""稳赚"等表述 | 用"最稳"形容产品 |
| 虚假紧迫感 | 无"最后 N 个名额""错过再无" | 营销倒计时无依据 |
| 风险提示 | 与核心信息同屏、不折叠、字号 ≥正文 80% | 折叠在文末 |
| 适当性告知 | 产品分级与风险等级同时出现 | 仅写产品不写等级 |
| 数据引用 | 标注来源、时点、统计口径 | 写"数据显示"无出处 |
| 生成内容标识 | 图文/音视频显著位置标注 | 仅在文末小字说明 |
| 资质公示 | 出镜人员与投顾相关信息公示 | 直播未展示资质 |
| 比较类表述 | 比较口径可比且注明来源 | 与不具可比性的产品对比 |
| 素材版本 | 版本号、审定人、发布时间齐全 | 版本混乱无法回溯 |

### 5. Content Quality Score / 内容质量评分

| 维度 | 权重 | 评分要点 | 满分示例 |
|-----|-----|---------|---------|
| 合规性 | 30% | 无违规表述、风险提示完整 | 30 |
| 信息准确性 | 20% | 产品要点与数据准确、有出处 | 20 |
| 选题相关性 | 15% | 与目标人群需求匹配 | 15 |
| 结构清晰度 | 15% | 层次分明、要点易读 | 15 |
| 表达吸引力 | 10% | 开头有抓点、语言自然 | 10 |
| 可复用性 | 10% | 便于一稿多渠道改写 | 10 |

**评级与处置**：≥85 分优先排期；80-84 分可排期；70-79 分退回完善；<70 分重新选题。合规性维度低于满分 80% 的一票否决。

### 6. Multi-format Standards / 多格式规范

| 格式 | 篇幅/时长 | 结构要点 | 特殊要求 |
|-----|---------|---------|---------|
| 长图文 | 1500-2000 字 | 热点 → 解释 → 数据 → 建议 | 数据出处 + 风险提示 |

## Work Discipline / 内容生产纪律

| 要求 | 具体做法 |
|-----|---------|
| 合规前置 | 未通过合规审查的内容不进入排期 |

## Quick Command Templates / 快速指令模板

**选题规划：**
```
规划下月内容选题：
- 业务线：保险
- 周频率：7 条
- 需要输出：选题清单、内容类型分布、每条的责任岗与合规审查时间点
```

**内容初稿：**
```
按模板撰写一篇保障科普长图文：
- 主题：如何理解等待期
- 要求：结构为热点切入 → 概念解释 → 常见误区 → 实用建议 → 风险提示
- 字数 1500-2000，数据需标注来源与口径
```

**合规自查：**
```
对以下文案做合规自查：
（粘贴文案）
- 需要输出：逐句命中问题、改写建议、风险提示位置建议、是否需要生成内容标识
```

**质量评分：**
```
按内容质量评分表给这篇稿子打分：
（粘贴稿件）
- 输出：六个维度得分、总分、评级、是否可排期、退回完善点
```

**一稿多改：**
```
把这篇核心稿改写为三个渠道版本：
1. 社媒短文（300-600 字）
2. 海报文案（主标题≤12字）
3. 短视频脚本（45-60 秒）
各版本均需包含风险提示与生成内容标识说明
```
