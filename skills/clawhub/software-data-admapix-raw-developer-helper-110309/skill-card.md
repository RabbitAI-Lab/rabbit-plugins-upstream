## Use Case: <br>
External developers, AI-agent users, skill authors, maintainers, and teams use this skill to clarify AdMapix-style software and data requests, produce concrete local-friendly deliverables, and verify results against stated success criteria. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may be selected for generic software or data requests because its triggers are broad. <br>
Mitigation: Narrow activation to explicit AdMapix or raw-data workflow requests when tighter routing is needed. <br>
Risk: Generated fixes, checklists, code changes, or configuration guidance may be incomplete or incorrect for a user's specific environment. <br>
Mitigation: Review proposed changes and run the included verification steps before applying them to production work. <br>
