## Description: <br>
Helps AI-agent users, skill authors, maintainers, and teams create practical SkillScan-style workflows, checklists, analyses, code changes, and decision support for fixing bugs, hardening setup and safety, improving reliability, or building adjacent skills. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
AI-agent users, skill authors, maintainers, and teams use this skill to turn broad SkillScan-style security and productivity needs into concrete local workflows, checklists, analyses, code changes, and verification notes. It is intended for practical workflow support around bug fixing, setup hardening, reliability improvement, and adjacent skill creation. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can be implicitly invoked by broad security and productivity wording beyond its stated purpose. <br>
Mitigation: Review before installing in environments that auto-select skills; narrow trigger wording or disable implicit invocation for ordinary security and productivity requests. <br>
Risk: The skill provides workflow and implementation guidance that may be mistaken for complete security remediation. <br>
Mitigation: Review outputs against the stated success criteria and scan or test any generated code, configuration, or process changes before deployment. <br>
