## Description: <br>
Helps agent users, skill authors, maintainers, and teams create practical workflows, checklists, analysis, code changes, and decision support for self-improving and proactive agent-style productivity tasks. <br>

This skill is ready for commercial/non-commercial use. <br>

Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate too broadly because its trigger words include generic terms such as self, improving, and proactive. <br>
Mitigation: Prefer explicit invocation or route it only for self-improving or proactive-agent workflow requests when strict routing is required. <br>
Risk: The skill produces guidance and workflow artifacts that may be incomplete or unsuitable for a specific project context. <br>
Mitigation: Review generated plans, checklists, commands, and code changes against the user stated constraints before applying them. <br>
