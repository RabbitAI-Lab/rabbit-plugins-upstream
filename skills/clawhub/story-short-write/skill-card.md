## Description:

Helps writers plan, draft, and revise Chinese short-form web fiction with attention to emotional impact and pacing.

This skill is ready for commercial/non-commercial use.

## Publisher:

[worldwonderer](https://clawhub.ai/user/worldwonderer)

### License/Terms of Use:

MIT

## Use Case:

Writers and editors use this skill to develop Chinese short web fiction from story concept and outline through a finished, revised draft.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Drafting can create or change files in the writing workspace.

Mitigation: Use a dedicated writing workspace and review file changes before relying on the result.

Risk: Optional author-preference memory can retain an incorrect preference.

Mitigation: Review saved memory receipts and use the documented forget or replace flow to correct them.
