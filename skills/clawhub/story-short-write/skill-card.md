## Description:

Helps an agent plan, draft, revise, and quality-check Chinese short web-fiction manuscripts from concept through finished story, with emphasis on emotional pacing, reversals, platform formatting, and local project files.

This skill is ready for commercial/non-commercial use.

## Publisher:

[worldwonderer](https://clawhub.ai/user/worldwonderer)

### License/Terms of Use:

MIT-0

## Use Case:

Writers, editors, and agent operators use this skill to develop Chinese short web-fiction projects, including ideation, outline creation, scene drafting, revision, formatting checks, and manuscript quality review. The skill works with local story files such as settings, outlines, comparison notes, and the final manuscript.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill reads and writes local story project files, including manuscript and outline files, so existing drafts can be overwritten or substantially rewritten.

Mitigation: Run it inside a dedicated writing project, review existing story files before use, and keep backups or version control for drafts that should not be lost.

Risk: The workflow can use reference novels and analysis outputs for technique recall, which creates a copyright or close-imitation risk if concrete plot, dialogue, or wording is copied.

Mitigation: Use references only for high-level structure, pacing, and craft techniques, then review the manuscript for originality before publication.
