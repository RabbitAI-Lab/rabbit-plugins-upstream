## Description:

短篇网文写作。辅助短篇小说创作，从构思到成稿，聚焦情绪拉扯与节奏把控。

This skill is ready for commercial/non-commercial use.

## Publisher:

[worldwonderer](https://clawhub.ai/user/worldwonderer)

### License/Terms of Use:

MIT-0

## Use Case:

External writers and writing agents use this skill to plan, draft, revise, and quality-check Chinese short-form web fiction, including genre-specific structure, emotional pacing, hooks, reversals, and platform-oriented formatting.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can create or edit local story drafts, outlines, and reference folders.

Mitigation: Review generated changes before using it on valuable drafts, and keep backups or version control for active writing projects.

Risk: One included utility rewrites punctuation in specified files.

Mitigation: Run punctuation normalization only on intended files and inspect diffs afterward.

Risk: Some supported genres can involve revenge, abuse, or conflict-heavy fictional prompts.

Mitigation: Keep those prompts fictional and non-instructional, and avoid turning story content into real-world harm guidance.
