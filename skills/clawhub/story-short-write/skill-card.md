## Description:

短篇网文写作。辅助短篇小说创作，从构思到成稿，聚焦情绪拉扯与节奏把控。触发方式：/story-short-write、/写短篇、「帮我写一篇短篇」「写个盐言故事」。

This skill is ready for commercial/non-commercial use.

## Use Case:

短篇网文作者可用它从目标情绪与题材构思故事，设计人物、反转和章节节奏，再逐场景起草并精修成稿。

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can retain author preferences and quotations across writing tasks.

Mitigation: Review what is saved and use the author-memory management flow to remove entries you no longer want retained.

Risk: The security assessment is partial and notes shell capability that is not declared in the skill description.

Mitigation: Review the components and commands before use, and enable shell access only if you accept it.
