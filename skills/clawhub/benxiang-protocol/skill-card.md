## Description:

Benxiang Protocol helps agents persist project state in .origin packages through semantic transactions, deterministic validation, and evidence-backed object records.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agent operators use this skill to persist, recover, audit, and update project state across new sessions or multi-agent collaboration. It is intended for workflows that need semantic transaction records, deterministic consistency checks, and provenance for stored decisions, tasks, risks, facts, and modules.
