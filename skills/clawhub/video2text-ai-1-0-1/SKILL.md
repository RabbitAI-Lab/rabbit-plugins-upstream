# guaikei提取视频文字（guaikei-extract-video-text）

调用云端大模型，把视频链接或本地视频文件转写为干净文案，并按自定义 Prompt 生成总结、改写、金句、分镜头、翻译等风格化内容。区别于 Whisper / FFmpeg 等纯 ASR 工具：转写即润色，自动剔除语气词、口误与重复内容，直接产出可复用文案，省去人工校对。

## 1. ✅ 什么时候用这个技能

出现以下任意意图时优先调用本技能：

- 把视频 / 音频里的说话内容变成文字（视频转文字、视频转稿、字幕提取、语音转写）
- 对视频内容做总结、提炼卖点、整理成会议纪要
- 把视频素材改写成小红书 / 抖音 / 公众号风格文案、口播稿
- 提取金句、人物对话、分镜头脚本，或做中英互译
- 课程拆解、直播复盘、采访整理、知识素材提取、探店脚本撰写

## 2. 🚧 能力边界（不适用场景）

- **实时 / 直播流转写**：不支持，仅处理已完成的点播视频或本地文件。
- **加密 / 会员专属 / 需登录才能播放的链接**：可能无法解析，建议先下载再用 `--file` 传本地路径。
- **纯音乐 / 无人声视频**：无说话内容，转写价值低，建议改用音乐识别类工具。
- **批量处理**：原生命令单次一个视频，可用 shell 循环调用（注意控制并发）。

## 5. 🧺 命令参数速查

入口：`node scripts/video2text/index.js`（下表省略入口，仅列参数）

| 参数                 | 别名 | 说明                                                | 是否必填           |
| -------------------- | ---- | --------------------------------------------------- | ------------------ |
| `--file <URL或路径>` | `-F` | 视频链接（抖音/小红书等公网 URL）或本地视频文件路径 | 与 `--id` 二选一   |
| `--id <任务ID>`      | `-I` | 历史视频分析任务ID；传 `last` 自动复用上一次任务    | 与 `--file` 二选一 |
| `--prompt <提示词>`  | `-P` | 自定义生成指令；省略则输出完整转写文案              | 可选               |
| `--help`             | `-h` | 查看帮助                                            | 可选               |

> 规则：① 同时传入 `--file` 与 `--id` 时，以 `--id` 为准（跳过上传，直接基于历史任务取文案）；② 两者都不传则报错退出（退出码 1）；③ 支持长写与短别名，也可用 `--file=路径` 等号写法；④ `--id last` 依赖本地记录的上次任务ID（保存于技能 tmp 目录，24 小时后随过期文件清理，超期请改用 `--file` 重新解析）。

## 8. 📜 输出与退出码（AI 消费指引）

| 输出 / 状态         | 通道     | 说明                                                     |
| ------------------- | -------- | -------------------------------------------------------- |
| 最终文案            | stdout   | 已剔除语气词 / 口误 / 重复；可直接 `> result.txt` 或管道 |
| 进度 / 日志 / 错误  | stderr   | 不污染 stdout，便于程序化消费                            |
| 成功                | 退出码 0 | 文案输出完成                                             |
| 参数错误 / 任务失败 | 退出码 1 | stderr 打印明确错误信息                                  |
| TOKEN 未配置        | 退出码 3 | 不产生费用                                               |

**AI 读取规则**：只把 **stdout** 当作最终文案呈现给用户；stderr 是进度与日志，不要当作文案输出。

## 9. 🛡️ 异常与边界处理

- **TOKEN 未配置 / 无效**：立即退出并提示配置方式，**不产生费用**。
- **链接失效 / 文件损坏 / 解析超时**：任务失败不计费，返回明确错误。
- **`--id` 任务不存在**：返回明确业务错误（如「任务ID不存在」），**不无限重试**，立即失败。
- **长视频**：进入轮询等待，进度输出到 stderr；请耐心等待，或之后用 `--id last` 取结果。
- **网络视频**：先自动下载到技能 tmp 目录再上传，过期临时文件每次运行自动清理。
