# 报告生成规范

## 一、工作分布分析报告

### 必须包含的模块

1. **概览区**
   - 报告标题：`[角色名] — 工作内容分析与分布报告`
   - 摘要卡片：工作大类数、各年份样本数、总笔记数
   - 数据来源说明 + 分析时间

2. **各年度饼图**（Chart.js doughnut）
   - 每年度一个饼图，并排展示
   - 颜色使用固定色板（10色），保证年度之间颜色一致
   - 图例放在底部，使用圆点样式

3. **年对比柱状图**（Chart.js bar）
   - X轴：10个分类
   - 两组柱子：各年度
   - Y轴：百分比，max设为最高值+4

4. **分类明细表**
   - 列：分类名、典型工作内容、各年度占比（带进度条）、变化趋势
   - 变化趋势显示箭头+差值+趋势说明

5. **深度洞察分析**
   - 3-5个数据驱动的洞察点
   - 每个洞察有标题+解释
   - 必须引用具体百分比变化
   - 包含角色演进分析
   - 包含风险提示

6. **分类详细说明**
   - 每个分类一段说明
   - 包含颜色标识点、分类名、占比、具体工作举例

7. **优化建议**
   - 基于数据发现的具体建议
   - 每条建议可执行、有指向性

### 技术要求
- 使用 Chart.js 4.x CDN：`https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js`
- 移动端响应式：grid-template-columns 在 <=768px 时变为 1fr
- 配色方案可自定义，但需保持一致性

## 二、时间分配规划报告

### 必须包含的模块

1. **当前 vs 建议分配对比**
   - 两个并排饼图（doughnut）
   - 一个雷达图（radar）：当前 vs 建议两条线

2. **四象限优先级矩阵**
   - 四个象限：重要紧急 / 重要不紧急 / 紧急不重要 / 不重要不紧急
   - 用CSS grid布局
   - 每象限列出具体工作内容
   - 标注目标占比变化

3. **年度关键节点时间线**
   - 使用CSS timeline样式（左侧竖线+圆点）
   - 按每2-3个月划分阶段
   - 每阶段包含：时间段、标题、核心工作列表、标签
   - 财政年度周期示例：
     - **Q3（7-9月）**：技术治理窗口 — 债务清理、信创攻坚、架构升级
     - **Q4（10-12月）**：年结高峰期 — 年结保障、新年度初始化
     - **Q1（1-3月）**：规划启动期 — 新年度初始化、全年规划、需求确认
     - **Q2（4-6月）**：版本交付期 — 需求上线、测试考核、年中总结
   - 对于非财政行业，按自然季度或OKR周期划分

4. **季度时间分配热力图**
   - 表格形式：行=分类，列=季度
   - 用颜色深浅表示投入力度（红色=高>15%、橙色=中10-15%、绿色=低<10%）

5. **具体行动建议**
   - 分三个层次：立即执行（本月）、近期推进（3-6月）、中长期（6-18月）
   - 每条建议含标题、具体做法、预估时间投入

6. **优化效果预期表**
   - 列：优化项、当前状态、目标状态、关键举措、预期见效时间

### 技术要求
- 同分析报告
- 额外：热力图表格需用class控制颜色

## 三、通用设计规范

- 字体：-apple-system, BlinkMacSystemFont, "Segoe UI", "Microsoft YaHei", sans-serif
- 主色调：#1a5276 / #2980b9（深蓝渐变）
- 卡片圆角：10-12px
- 阴影：0 2px 8px rgba(0,0,0,0.06)
- 标签样式：圆角12px，小号字体
- 所有图表需设置 `responsive: true, maintainAspectRatio: false`
