## Description:

Maintain a consistent visual style and cast across Phantra episodes by carrying forward a shared project, references, style, duration, and model.

This skill is ready for commercial/non-commercial use.

## Use Case:

Phantra creators use the skill to plan and write follow-on episodes that preserve a series’ cast, visual style, framing, duration, and model. It guides them through checking continuity and obtaining approval before paid rendering.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Rendering can spend credits, and saved studio defaults affect the quote.

Mitigation: Check saved rendering defaults, show the quoted credit cost, and wait for explicit approval before rendering.

Risk: The security review reports a frontmatter parsing gap and does not cover connected studio tools.

Mitigation: Correct the skill header before installation, and review connected studio permissions separately.

Risk: References sent to the studio may contain material the user did not intend to process there.

Mitigation: Use only references intended for studio processing.
