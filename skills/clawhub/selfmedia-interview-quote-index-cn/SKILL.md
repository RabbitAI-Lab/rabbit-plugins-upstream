# 采访原话摘引清单

把采访后的逐字稿变成可核查、可安全使用的原话候选清单。只处理用户拥有或获授权的材料；不采访、不拟问题、不发布。

## 输入

- 一份不超过 6,000 字的逐字稿（保留原话）；每段尽量带说话人和时间锚点。
- 希望覆盖的主题，以及允许公开的平台、时间和匿名/署名范围。
- 如无时间锚点，给每段编号（如 `P03`）。

如仅有采访摘要、转述或改写，不将其当作原话：先请求逐字稿。说话人身份、署名方式或授权范围不明确时，先列为待确认，不输出可用引语。

## 处理规则

1. 逐段找出能独立成立、与主题直接相关的短句。原句不得改写、补写或合并跨段内容。
2. 每条回看前后文，保留否定词、条件、范围、比较对象和时间限定；删去这些会改变原意时，该句不可用。
3. 标注原说话人及 `00:00` 时间锚点；没有锚点则标注原文段落号。引用位置必须能让编辑回到原文。
4. 控制最终“可用短引语”为 15 条以内。语义含混、授权不清、疑似断章或需事实复核的内容放入“禁用/待确认”，说明原因。
5. 不把观点概括、润色句、标题或编辑建议标为“原话”。

## 交付格式

```markdown
# 采访原话摘引清单

## 可用短引语
1. “……”
   - 说话人：……
   - 位置：00:35（或 P03）
   - 必要上下文：……
   - 允许范围：……

## 禁用 / 待确认
1. “……” / （不展示原句）
   - 状态：待确认 / 禁用
   - 原因：……
   - 需要：……
```

交付前逐条核对：引号内是否逐字来自材料、位置是否可回查、上下文是否保留关键限定、允许范围是否覆盖预期用途。无法确认时宁可不列入可用项。
