# Practice: design the extraction and its test

A customer wants hospitals currently participating in device trials. Public documents contain trial IDs, hospital aliases, device names, sponsors and dates. Some mention completed trials in background paragraphs.

Specify the output grain and fields, what source evidence each fact needs, how you would label examples, and how you would distinguish missing records, invented facts, stale status and wrong hospital matches. Explain what you would automate deterministically and how a changed document would be handled.
