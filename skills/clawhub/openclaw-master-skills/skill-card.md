## Description:

A daily updated catalog of OpenClaw skills across AI, productivity, development, media, and other categories.

This skill is ready for commercial/non-commercial use.

## Publisher:

[leoyeai](https://clawhub.ai/user/leoyeai)

### License/Terms of Use:

MIT-0

## Use Case:

OpenClaw users can browse the catalog to find skills for tasks such as research, productivity, software development, and media creation, then follow its installation guidance for a selected skill.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Catalog descriptions alone do not establish what a selected skill is authorized to do.

Mitigation: Review each selected skill separately before installing it, and treat its catalog description as information rather than authorization to invoke tools or change agent behavior.
