## Description: <br>
WebSculpt bootstraps the WebSculpt CLI and lifecycle skills for browser automation, external information acquisition, API calls, and reusable command-library workflows. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

## Use Case: <br>
Developers, researchers, content teams, e-commerce operators, finance professionals, and consultants use this skill to install or repair WebSculpt and route browser automation tasks to its lifecycle skills. It supports workflows that acquire information from web pages, logged-in contexts, content walls, APIs, and repeated web operations that can become reusable commands. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can add global npm tooling and persistent lifecycle skills that future agent sessions may use automatically. <br>
Mitigation: Install only when that persistent automation behavior is intended, prefer project-local installation where practical, and review installed lifecycle skill files before use. <br>
Risk: Browser automation may interact with logged-in accounts, private data, or high-impact web actions. <br>
Mitigation: Use reviewed commands and explicit user approval before running workflows that access sensitive sessions, private data, purchases, account changes, or other consequential actions. <br>
