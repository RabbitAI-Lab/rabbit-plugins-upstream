## Description: <br>
WebSculpt is a bootstrap skill that installs or repairs the WebSculpt CLI and routes browser automation, scraping, API, external-information, and reusable command-library tasks to its lifecycle skills. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

## Use Case: <br>
External users and developers use this bootstrap skill to prepare WebSculpt in an agent environment, then route web acquisition, browser automation, command capture, maintenance, and command-library management tasks to the installed lifecycle skills. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill defaults to broad global npm package installation and global agent-skill changes across multiple agent environments. <br>
Mitigation: Review before installing, prefer a project-local install unless global availability is intended, and confirm the scope before running install or update commands. <br>
