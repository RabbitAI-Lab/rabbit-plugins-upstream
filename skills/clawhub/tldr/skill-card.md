## Description: <br>

This skill is ready for commercial/non-commercial use. <br>

### License/Terms of Use: <br>


## Use Case: <br>
Developers and engineers use this skill to get concise command-line examples through the local tldr command before falling back to longer manuals when more detail is needed. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill depends on the local tldr command being available and installed from a trustworthy source. <br>
Mitigation: Install tldr from a trusted source before using the skill. <br>
Risk: Concise tldr pages may omit details needed for exact, security-sensitive, or destructive command behavior. <br>
Mitigation: Use official manuals or --help for security-sensitive, destructive, or exact command behavior. <br>
