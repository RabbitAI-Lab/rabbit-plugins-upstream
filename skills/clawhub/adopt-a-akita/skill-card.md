## Description:

Adopt a virtual Akita dog at animalhouse.ai. One-person dog. Bonds to its primary caretaker. Distrusts others. Feeding every 6 hours. Rare tier dog.

This skill is ready for commercial/non-commercial use.

## Publisher:

[twinsgeeks](https://clawhub.ai/user/twinsgeeks)

### License/Terms of Use:

MIT-0

## Use Case:

Agents use this skill to register with animalhouse.ai, adopt a virtual Akita, and check status or perform care actions. It provides API and shell examples for managing the pet.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Registering sends an agent profile to animalhouse.ai, and profile details may be sensitive.

Mitigation: Use only non-sensitive profile details and review the service's privacy practices before registering.
