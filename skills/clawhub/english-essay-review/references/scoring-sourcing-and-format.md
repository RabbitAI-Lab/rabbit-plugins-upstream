## 1. 评分使用原则

- 先确认考试、科目版本、题型、题目要求与年份；具体年份规则与本文件冲突时，以该年度考试主管机构公开的考试大纲、试题要求或评分说明为准。
- 优先使用考试主管机构或考试大纲中的整体档次。为教学诊断增加“任务完成、组织衔接、语言准确、表达范围”等分项时，明确注明它们是诊断性拆分，不冒充官方逐项权重。
- 同时报告原始满分、估分和档次。不要把不同机构的换算分、百分制和原始分混为一谈。
- 分数必须由文本证据支持：引用句号编号、错误密度、任务遗漏和篇章表现。
- 题目或图表缺失会显著影响任务完成度判断。此时只给暂定语言分与条件式总分。

## 2. CET-4 / CET-6 写作与翻译

### 写作诊断

采用常见的 15 分原始量表作教学估分，并按整体表现落档：

| 档位参考 | 整体表现 |
|---|---|
| 13–15 | 切题且思想表达清楚，结构连贯，语言自然多样；仅有少量不影响理解的小错 |
| 10–12 | 基本切题、表达较清楚、结构基本完整；有一些语言错误，但总体阅读顺畅 |
| 7–9 | 大体切题，部分观点或展开不充分；语言错误较多，连贯性一般，但主要意思可辨 |
| 4–6 | 内容不完整或部分偏题；结构混乱、错误频繁，理解受到明显影响 |
| 1–3 | 严重偏题、内容极少或语言支离破碎，只能辨认少量相关信息 |
| 0 | 空白、只有孤立词语，或与任务无关到无法评分 |

将以下维度用于解释档位，而不是机械相加冒充官方算法：

- 任务完成与切题度；
- 内容展开与信息充分性；
- 组织、衔接与段落结构；
- 语法、拼写和标点准确性；
- 词汇与句式范围、得体性和可读性。

检查当次题目给出的字数与格式要求。不要凭记忆给所有年份套用同一最低字数。

### 翻译诊断

只有同时获得中文原文和英文作答时才评价翻译准确度。按信息单位逐项检查：

1. 关键信息是否完整；
2. 事实、数量、时间、逻辑关系和专名是否准确；
3. 语法结构是否正确；
4. 搭配与表达是否地道；
5. 译文是否连贯。

缺少中文原文时，明确写“仅做英文语言润色，无法判断漏译和误译”。不要把翻译文本按作文的论证、段落展开维度打分。

## 3. 考研英语写作

先区分英语一与英语二，并核对当年试题分值。常见结构为：

- 英语一：小作文 10 分，大作文 20 分；
- 英语二：小作文 10 分，大作文 15 分。

若用户指定年份，必须以该年度试卷和大纲核验，不能只依赖上述常见结构。

### 应用文（小作文）

重点检查：

- 是否完成全部交际目的与内容要点；
- 称呼、开头、正文、结尾和署名是否符合题型；
- 对象、语气和礼貌程度是否得体；
- 信息是否清晰、紧凑、有顺序；
- 语言错误是否影响交际。

### 图画 / 图表作文（大作文）

重点检查：

- 描述是否准确并抓住主要特征，而非无序罗列；
- 是否解释寓意、趋势或现象并形成明确中心；
- 分析是否有因果、例证、对比或影响等有效展开；
- 段落是否层层推进，结论或建议是否回应主题；
- 词汇、句式与衔接是否多样、准确、自然。

### 档次映射

采用五档整体判断，再映射到当年题目满分：

| 档次 | 诊断说明 |
|---|---|
| 第一档 | 完成全部任务，内容充分、组织连贯、语域得体，句式和词汇较丰富，错误极少 |
| 第二档 | 完成主要任务，内容与结构较好，语言有变化；少量错误不妨碍理解 |
| 第三档 | 基本完成任务，但展开、衔接或语言范围有限；存在若干错误，主要意思仍清楚 |
| 第四档 | 未充分完成任务，遗漏明显、组织欠佳、语言错误较多，部分内容难以理解 |
| 第五档 | 基本未完成任务，内容严重不足或偏题，语言破碎，交流目的未实现 |

给出具体分数时，同时写出档次和上下浮动条件，例如：“暂估 15/20，第二档下沿；若图画寓意与题目不符，可能降至第三档。”

## 4. 颜色标注规则

使用颜色与文本标签双重编码：

- `🔴错误`：`<span style="color:#D32F2F"><del>错误片段</del></span> → 正确表达`
- `🟡升级`：`<mark>可升级词语</mark> → 更准确或更得体的表达`
- `🔵衔接`：`<span style="color:#1976D2"><ins>新增或调整的连接表达</ins></span>`

若当前界面不渲染 HTML/CSS，改用：

- `[🔴错误: 原文 → 修正]`
- `[🟡升级: 原文 → 建议]`
- `[🔵衔接: 新增表达]`

不要用黄色标记必须修改的错误。不要把所有连接词都标蓝，只标确实补足逻辑关系的新增或调整。修正后的完整句不要整句染色，只标最小必要片段。

## 5. 逐句批改表

默认使用：

| 句号 | 原句 | 标注与推荐改写 | 类型 | 说明 |
|---|---|---|---|---|
| S1 | 原句 | 最小范围颜色标注；另起一行给完整推荐句 | 语法 / 拼写 / 搭配 / 中式英语 / 逻辑 / 可选升级 / 保留 | 解释规则及对得分或可读性的影响 |

同一句有多个问题时按“必须修正 → 可选升级 → 衔接”的顺序展示。正确句写“保留”，必要时补充其得分点。

## 6. 范文来源核验

### 来源优先级

按以下顺序检索与采用：

1. 用户提供的试卷、教材、评分材料或范文，并记录文件名、页码和可见出版信息；
2. 考试主管机构、命题或阅卷相关机构公开的样例、考试大纲和评分示例；
3. 正规出版社的备考书、学术数据库或可确认编辑责任的教育出版物；
4. 信誉良好且标明原始出处的教育机构页面，仅作为辅助来源。

匿名论坛、自媒体转载、聚合站和没有原始出处的“满分范文”不能单独证明真实性。搜索结果摘要不能作为已核验正文。

### 核验字段

为每个候选范文记录：

- 考试名称与英语一/二或 CET-4/6；
- 考试年份、场次、题型和题目；
- 范文身份：官方评分样例、阅卷样卷、出版物优秀范文或机构示范；
- 作者/编者/机构；
- 来源标题、出版信息或直达链接；
- 可访问日期；
- 是否有明确分数或档次；
- 允许引用或转载的范围；
- 尚未核实的信息。

至少核对“考试与题目匹配”和“来源身份”两项，才能使用 `可核验优秀范文` 标签。没有证据时写“网传范文，真实性未核验”，不要继续以真实范文展示。

### 使用边界

- 对用户提供的范文，可以在完成任务所需范围内逐句批改、分析和改写。
- 对外部受版权保护的范文，避免完整复刻；提供必要短摘录、结构与表达特征、来源链接或书目信息。
- 需要完整同题范文时，优先生成自己的文本，并标为 `来源辅助的原创示范` 或 `原创高分示范`。
- 不把“与真题同主题”写成“真题官方范文”，不把预测作文写成真题作文。
- 无法联网、来源受限或没有找到可靠材料时，直接说明限制；仍可提供原创高分示范，但不能虚构出处。

### 来源呈现模板

```text
范文身份：可核验优秀范文 / 来源辅助的原创示范 / 原创高分示范
对应考试与题目：
来源机构或出版物：
出处与链接/页码：
核验状态：已核验 / 部分核验 / 未找到可靠来源
引用范围：短摘录 / 用户提供全文 / 不复刻外部全文
说明：
```

## 7. 推荐报告骨架

```markdown
# 作文批改报告

## 任务识别与评分边界
## 总评与估分
## 图例
## 逐句批改
## 篇章结构与得分点
## 忠实修订版
## 高分改写版
## 范文来源与同题示范
## 个性化提分要点
## 考场自检清单
```

把建议按优先级排序：先处理偏题、任务遗漏和影响理解的错误，再处理结构衔接，最后做词汇与句式升级。
