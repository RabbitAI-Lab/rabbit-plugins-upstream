## 1. 半结构化访谈提纲模板（对齐课程作业要求）

课程作业常见要求：访谈主题自拟；内容包括访谈背景、访谈目的、访谈对象、设计思路、访谈题目（**明确标注题目类型**，15-20 题左右）；完成至少一次访谈并提交记录与反思。模板如下：

```
一、访谈主题
（一句话：研究对象 + 现象 + 情境，如“大学生线上与线下社会互动中社会连接感的形成过程”）

二、访谈背景
（为什么研究这个？文献/现象依据是什么？现有研究缺什么？）

三、访谈目的
（研究要回答什么？列出 3-5 条具体目标）

四、访谈对象
（年龄/身份范围 + 筛选条件：如“18-25 岁本科生，有日常社交媒体使用经验”）

五、设计思路
（采用半结构式访谈；说明题目如何覆盖研究目的；问题类型分布）

六、访谈题目（15-20 题，标注类型）

【开场寒暄】
1.（行为事实）最近一周你主要通过哪些方式与朋友/家人保持联系？
2.（故事经历）最近一次印象最深的线上互动是怎样的？……

【行为事实 / 行为流程】
3. 你一般怎么开始使用它？从想到做到真正做，中间会经过哪些步骤？……

【感官体验】
5. 第一次接触它时，你最先注意到什么？……

【情绪感受】
7. 那一刻你是什么感觉？身体上有什么反应？后来情绪有变化吗？……

【知识认知】
9. 你一开始以为它是什么？后来是怎么改观的？……

【态度价值】
11. 你觉得什么样的才算“好”？你的判断标准是什么？……

【动机需求】
13. 是什么让你决定继续用下去？（追问：这对你来说为什么重要？）……

【结束语】
15. 今天聊到这里，还有没有我们没想到、但你觉得很重要的？

（注：每类问题后附 1-2 条追问备选；追问不写进正式题目数）

七、访谈记录（格式）
背景（时间/地点/情境）｜ 正文（录音转写）｜ 附注（气氛、非语言信息）
```

**六类问题速查**：行为事实 · 故事经历 · 行为流程 · 感官体验 · 情绪感受 · 知识认知 · 态度价值 · 动机需求（提纲尽量都覆盖，别只问态度）。
**提问顺序**：由易到难、开放到半开放、非敏感到敏感；先行为事实/故事，后态度/动机。

## 2. 问卷逐题审查清单（10 项）

| # | 检查项 | 问题示例 ❌ | 改写 ✅ |
|---|---|---|---|
| 1 | 双重否定 | 我不觉得它不好用 | 我觉得它好用 |
| 2 | 一题多义 | 界面好看且好用 | 拆成两题 |
| 3 | 诱导/夸张 | 是否同意该功能极大提升效率 | 该功能对我的效率有影响 |
| 4 | 术语行话 | 信息架构是否清晰 | 我总能找到我要找的东西 |
| 5 | 社会赞许 | 你每天学习几小时 | 给出具体区间选项 |
| 6 | 同意偏差 | 全正向题 | 每个构念加 1 题反向 |
| 7 | 模糊程度词 | 经常 / 有时 | 每周 1-2 次 |
| 8 | 选项不穷尽/不互斥 | 漏"其他"或选项重叠 | 补全 + 加"其他__" |
| 9 | 选项内塞两个意思 | 方便且安全 | 拆开 |
| 10 | 锚点缺失/不一致 | 有的 5 点有的 7 点 | 统一，端点加文字 |

## 3. SUS 量表（可用性评分，Brooke 1996）

10 题，5 点（1 非常不同意 – 5 非常同意）。

| # | 题目 | 1-5 |
|---|---|---|
| 1 | 我想我会经常使用这个产品 | |
| 2 | 我觉得这个产品没必要这么复杂 | |
| 3 | 我认为这个产品用起来很简单 | |
| 4 | 我觉得我需要技术支持才能使用它 | |
| 5 | 我觉得这个产品的各种功能整合得很好 | |
| 6 | 我觉得这个产品不一致的地方太多了 | |
| 7 | 我觉得大多数人都能很快学会使用它 | |
| 8 | 我觉得这个产品用起来很麻烦 | |
| 9 | 使用这个产品我感觉很自信 | |
| 10 | 使用之前我需要先学习很多东西 | |

**计分**：奇数题得分 = 选项值 − 1；偶数题得分 = 5 − 选项值；10 题总分 × 2.5 = SUS 分（0-100）。
**参照**：均值约 68；70+ 可用性良好；60 以下需重点改进。

## 4. 亲和图流程卡（KJ 法）

1. 每条访谈笔记/便利贴写一张卡片（一条信息一张，用用户原话优先）；
2. 静默分组：每人独立把卡片分组（不讨论）；
3. 小组讨论归并，每组命名（组名尽量用用户原话）；
4. 层级化：组 → 主题 → 大主题；
5. 成图 + 每组标注证据条数；
6. 每条洞察 = 证据（原话）→ 解读 → 建议。

## 5. 研究报告大纲

```
一、背景与研究问题
    1.1 研究背景与动机
    1.2 研究问题（一句话）+ 研究目标
二、方法
    2.1 研究设计（定性/定量/混合）
    2.2 参与者与抽样方式（样本量、招募途径、偏差声明）
    2.3 研究工具（访谈提纲/问卷/测试脚本，附附录）
    2.4 数据收集流程
    2.5 数据分析方法（编码/主题分析/统计检验）
三、结果
    3.1 定性结果（按主题，每条附用户原话证据）
    3.2 定量结果（描述统计、信度、检验结果 + 效应量）
四、洞察与建议
    4.1 每条洞察 = 证据 → 解读 → 建议
五、局限
    5.1 样本、方法、偏差、可推广性
附录：访谈提纲 / 问卷 / SUS 计分 / 编码手册
```

## 6. 样本量速查

| 场景 | 经验值 | 备注 |
|---|---|---|
| 深度访谈（同质样本） | 约 12 人，9-17 人区间 | 以"饱和"为准，不是死数 |
| 可用性测试（定性发现） | 5 人/轮 | 迭代多轮优于一轮 15 人 |
| 可用性测试（定量指标） | 15-20+ 人 | 否则置信区间太宽 |
| 问卷（比例估计，5% 误差） | ≈ 385 份 | 公式 n = z²pq/e²，z=1.96，p=0.5 |
| 量表验证（因子分析） | 条目数 ×10 且 ≥300 | Comrey & Lee 经验法则 |
| 日记法 | 10-20 人 × 1-2 周 | 注意流失率 |

> 所有经验值都是估算；正式研究用 G*Power 等做 priori power analysis。
