Article-to-Video Skill - Assets Directory
==========================================

Place the following assets in this directory:

1. bgm.mp3
   Background music track for video.
   Requirements:
   - Format: MP3
   - Duration: Long enough to cover the entire video (or it will loop)
   - Volume: Will be attenuated to -15dB automatically
   - License: Ensure you have the right to use the music
   Suggested sources:
   - YouTube Audio Library (free)
   - Free Music Archive (free, check license)
   - Bensound (free with attribution)

2. fonts/ (optional)
   Custom font files if system fonts are unavailable.
   Default subtitle font: C:/Windows/Fonts/msyh.ttc (Microsoft YaHei)
   Alternative: Noto Sans CJK SC (download from Google Fonts)

3. intro.mp4 / outro.mp4 (optional)
   Intro and outro video clips to prepend/append to the final video.

Note:
- This directory is created by the skill and can be customized.
- The config.py file references these paths.
- All assets should be royalty-free or properly licensed.
