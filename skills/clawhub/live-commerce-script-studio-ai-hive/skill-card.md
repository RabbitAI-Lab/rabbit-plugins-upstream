## Description:

Helps live-commerce teams turn product facts, pricing rules, inventory constraints, audience questions, and show length into reviewable livestream scripts, objection handling, closing sequences, short-video plans, runnable AI-HIVE commands, and delivery checklists.

This skill is ready for commercial/non-commercial use.

## Use Case:

External live-commerce operators, brand merchants, hosts, and production teams use this skill to plan Chinese livestream selling scripts and reusable short-video assets from verified product, channel, budget, and authorization inputs. Developers and operators can also use the bundled scripts to create project blueprints, submit AI-HIVE image or video generation tasks, and perform deterministic video edits.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow uses user-provided AI-HIVE credentials and can submit billable generation tasks.

Mitigation: Keep API keys out of shared files and logs, review prompts and routing before submission, and run a small sample before any batch job.

Risk: Uploaded reference media may include content the user is not authorized to use.

Mitigation: Use only authorized images, videos, logos, copy, and references; when authorization is unclear, limit output to abstract structure and new creative direction.

Risk: Commercial livestream scripts can contain unsupported product, pricing, inventory, or performance claims.

Mitigation: Ground claims in supplied facts or verifiable evidence and avoid promises about sales, ranking, platform approval, or return on investment.
