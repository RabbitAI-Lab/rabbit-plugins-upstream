## Description: <br>
Helps developers, QA engineers, maintainers, and product teams add useful unit tests, improve coverage, and validate changes against existing behavior. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, QA engineers, maintainers, open-source contributors, and product teams use this skill to turn a unit-testing or coverage goal into practical implementation steps, checklists, code changes, shell commands, and verification notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad activation wording may cause this skill to trigger when a more specific developer skill would be a better fit. <br>
Mitigation: Narrow the trigger wording or disable implicit invocation in environments with many overlapping developer skills. <br>
Risk: Generated test plans or code changes can encode incorrect assumptions about the existing system behavior. <br>
Mitigation: Review proposed tests and run the project's normal test and coverage commands before merging changes. <br>
