## Known Risks and Mitigations:

Risk: Installing and running a third-party CLI can introduce supply-chain exposure.

Mitigation: Review the linked dLazy CLI project when needed and prefer npx or a local install when avoiding a persistent global binary.

Risk: The skill requires a dLazy API key for SaaS access.

Mitigation: Use a revocable dLazy API key, provide it only through the documented CLI authentication flow or environment variable, and rotate or revoke it from the dLazy dashboard when needed.

Risk: Files attached with the CLI are uploaded to dLazy media storage.

Mitigation: Attach only files intended for upload and avoid sending confidential or unnecessary local files.
