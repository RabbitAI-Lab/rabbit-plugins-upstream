## Description:

Helps creators produce code-driven motion graphics, kinetic typography, and animated infographics with Remotion rather than AI-generated footage.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to plan and build Remotion-based animated text, graphics, and explainer visuals through dLazy's project-based assistant.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and attached files are sent to dLazy for hosted processing.

Mitigation: Use the service only if its data handling is acceptable, and attach only files intended for upload.

Risk: The CLI may persist an API key locally.

Mitigation: Use a per-invocation API key environment variable or the on-demand npx path when less local persistence is desired.
