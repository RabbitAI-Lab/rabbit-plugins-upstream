## Description:

Motion graphics, kinetic typography, animated text video, animated infographic, and explainer animation authored as Remotion code for text, shapes, data, logos, and transitions, then polished and exported.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

MIT-0

## Use Case:

Developers and creators use this skill to start or continue dLazy motion-graphics projects through the pinned dLazy CLI workflow. It is intended for code-driven animated graphics rather than AI-generated footage.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected file attachments may be sent to dLazy's hosted service.

Mitigation: Avoid attaching sensitive local files unless upload to dLazy is intended.

Risk: The dLazy API key may be stored in the local CLI configuration.

Mitigation: Use the documented authentication flow, rotate or revoke keys from the dLazy dashboard when needed, and prefer per-invocation credentials where local persistence is not desired.

Risk: Global CLI installation persists the dLazy binary on the user's system.

Mitigation: Use the pinned npx command when a non-persistent CLI invocation is preferred.
