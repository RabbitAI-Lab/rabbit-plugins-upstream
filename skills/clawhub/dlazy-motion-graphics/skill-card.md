## Description:

Helps create code-driven motion graphics, kinetic typography, animated infographics, and explainer videos using Remotion rather than generated footage.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators, designers, and developers use this skill to plan and produce Remotion-based animated text, graphics, infographics, and explainer videos through dLazy's hosted agent.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and attached files may be sent to dLazy's hosted service.

Mitigation: Review prompts and attachments before sharing; only submit content approved for the service.

Risk: Authentication may save an API key locally, and a global CLI installation persists on the machine.

Mitigation: Prefer one-off npx use if a global install is unnecessary; protect the local key and rotate or revoke it in the dLazy dashboard when needed.
