## Description:

Helps create code-driven motion graphics, kinetic typography, and animated infographics with Remotion rather than AI-generated footage.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to plan, create, refine, and export code-driven animated graphics and explainer videos through dLazy.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and optionally attached local files are sent to the dLazy service.

Mitigation: Review prompts and attachments for sensitive information before submitting them.

Risk: The CLI may store an API key locally, and installing it requires trusting the dLazy CLI and service.

Mitigation: Confirm the CLI and service are trusted, protect the saved key, and use the pinned npx command to avoid a persistent global installation.
