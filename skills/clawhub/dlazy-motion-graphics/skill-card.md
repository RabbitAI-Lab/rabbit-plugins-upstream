## Description:

Helps create code-driven motion graphics, kinetic typography, and animated infographics with Remotion, then refine and export them.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to direct a hosted assistant in building and refining Remotion-based animated text, graphics, and explainer videos across project sessions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Using the pinned dLazy CLI requires installing or running third-party software and authenticating with a dLazy API key.

Mitigation: Review the pinned CLI before use and authenticate only if comfortable with dLazy's hosted service.

Risk: Prompts go to dLazy's hosted API, and files attached with --files are uploaded to dLazy storage.

Mitigation: Avoid sensitive prompts and attach only files you intend to upload.
