## Description:

Helps create code-driven motion graphics, kinetic typography, and animated infographics with Remotion rather than AI-generated footage.

This skill is ready for commercial/non-commercial use.

## Use Case:

Creators and developers use the dLazy motion-graphics assistant to create, refine, and export code-driven animated videos.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installing or running a third-party CLI grants it access to the local execution environment.

Mitigation: Review the linked CLI repository and confirm the pinned package version before installation or use.

Risk: Prompts are sent to dLazy's hosted service and an API key is needed for access.

Mitigation: Share only appropriate prompt content and protect the API key; rotate or revoke it if exposed.

Risk: Files explicitly attached to a request are uploaded to dLazy's media storage.

Mitigation: Attach only files you intend to upload.
