## Description:

Helps creators develop code-driven motion graphics, kinetic typography, and animated infographics with Remotion through the dLazy service.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to plan, create, refine, and export code-driven animated graphics through a project-based dLazy assistant.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Files attached to a task are uploaded to dLazy's service.

Mitigation: Attach only files you are comfortable uploading.

Risk: The dLazy CLI can store an API key locally.

Mitigation: Protect local credentials and rotate or revoke the key in the dLazy dashboard if needed.

Risk: Installing a third-party CLI may be unsuitable for sensitive environments.

Mitigation: Review the CLI source and package before installation; use the on-demand npx option if a global install is undesirable.
