## Description:

Creates motion graphics, kinetic typography, animated text videos, infographics, and explainer animations as Remotion code for polishing and export.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

## Use Case:

Developers, designers, and content creators use this skill to plan and produce code-driven animated graphics, including kinetic typography and explainer videos, through a dLazy motion-graphics project.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security review notes that use may involve dLazy login, saved API credentials, organization project listing, and sending prompts or attached files to dLazy services.

Mitigation: Review what you plan to share and the requested account and project access before authenticating; rotate or revoke the API key if needed.

Risk: The security review reports that login, authentication setup, and organization project listing were not declared alongside the animation-focused description; its evidence is incomplete.

Mitigation: Check that these account and project actions are expected for your use before installing or running the skill.
