## Description:

Creates code-driven motion graphics, kinetic typography, animated infographics, and explainer animations with Remotion through the dLazy hosted agent.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators, designers, and developers use this skill to build and refine code-driven motion graphics videos, including animated text, shapes, data, logos, and transitions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and attached files may be sent to the dLazy hosted service.

Mitigation: Share only prompts and attachments approved for upload to dLazy.

Risk: Authentication stores a dLazy API key in the local user configuration.

Mitigation: Protect the user configuration and rotate or revoke the key if exposed; use the pinned npx command to avoid a persistent global CLI install.
