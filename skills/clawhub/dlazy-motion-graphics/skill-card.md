### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: Prompts and attached files may be sent to dLazy's hosted service.

Mitigation: Use the service only if its data handling is acceptable, and attach only files you intend to upload.

Risk: The CLI may store an API key locally and a global installation persists.

Mitigation: Protect the local key and prefer the documented npx invocation if a persistent global install is unwanted.

Risk: The supplied skill files describe an idea-to-video workflow rather than the advertised motion-graphics workflow.

Mitigation: Confirm the released skill contents and intended workflow before relying on its instructions.
