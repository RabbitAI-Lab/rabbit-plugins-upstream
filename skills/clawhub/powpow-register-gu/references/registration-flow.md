# રજિસ્ટ્રેશન પ્રક્રિયાની વિગતો — powpow-register

સમસ્યા શોધતી વખતે જોવા માટે. બધા નિયમો પ્લેટફોર્મ સોર્સ કોડમાંથી (Next.js ફ્રન્ટ-એન્ડ/બેક-એન્ડ સર્વસંમત
વેલિડેશન) લેવામાં આવ્યા છે, સ્રોત નોંધેલ છે.
પ્લેટફોર્મ અપડેટ થાય તો ઓનલાઈન વાસ્તવિક વર્તન જ લાગુ.

## પ્રવેશ

- રજિસ્ટ્રેશન પેજ: https://global.powpow.online/register
- લૉગિન પેજ: https://global.powpow.online/login
- સબ્સ્ક્રિપ્શન પેજ: https://global.powpow.online/subscription
- શેર લિંક વગેરેમાંથી `?next=...` લઈને આવ્યા હોય તો, રજિસ્ટ્રેશન + ચુકવણી પૂરી થતાં જ આપમેળે મૂળ પેજ પર પાછા જશે.

| ઈમેલ | **ફરજિયાત** | માન્ય ઈમેલ ફોર્મેટ, ≤255 અક્ષરો; એક ઈમેલ પર ફક્ત એક જ ખાતું રજિસ્ટર થઈ શકે | register route |
| ઈમેલ વેરિફિકેશન કોડ | **ફરજિયાત** | 6 અંક; **10 મિનિટમાં માન્ય**; સફળ ઉપયોગ પછી રદ; ફરી મોકલો તો જૂનો કોડ વપરાયેલો ગણાય | `src/lib/email-verification.ts` |
| મોબાઈલ નંબર | વૈકલ્પિક | મેઇનલેન્ડ (ચાઈના) મોબાઈલ નંબર `1[3-9]` થી શરૂ, કુલ 11 અંક; એક મોબાઈલ નંબર ફક્ત એક જ ખાતા સાથે જોડાય | register route |

પેજ પર વધુ ત્રણ થર્ડ-પાર્ટી લૉગિન બટન છે: **Google, Watcha, હુઆવેઈ ખાતું** (`GoogleSignInButton` /
`WatchaLoginButton` / `HuaweiLoginButton`)। થર્ડ-પાર્ટી ખાતામાં લોકલ પાસવર્ડ હોતો નથી, પછી પાસવર્ડથી લૉગિન
કરો તો «该账号未设置密码，请使用其他方式登录» (આ ખાતા માટે પાસવર્ડ સેટ નથી, કૃપા કરીને બીજી રીતે લૉગિન કરો) મળશે.

## રેટ-લિમિટ અને એન્ટી-બ્રૂટ-ફોર્સ પેરામીટર

| વર્તન | મર્યાદા | સ્રોત |
|---|---|---|
| રજિસ્ટ્રેશન સબમિટ | **પ્રતિ IP 3 વખત/મિનિટ**, મર્યાદા ઓળંગો તો 429 | `src/lib/rate-limit.ts` `REGISTER_RATE_LIMIT` |
| વેરિફિકેશન કોડ મોકલવો | એક જ IP થી 1 વખત/મિનિટ **અને** એક જ ઈમેલ પર 1 વખત/મિનિટ, મર્યાદા ઓળંગો તો 429; ફ્રન્ટ-એન્ડ બટન પર 60 સેકન્ડ કાઉન્ટડાઉન | `src/app/api/auth/register/send-code/route.ts` |
| વેરિફિકેશન કોડ તપાસ | દરેક ઈમેલ માટે 10 મિનિટમાં વધુમાં વધુ **5 વખત** પ્રયાસ, મર્યાદા પૂરી થાય તો સાચો કોડ પણ નકારાય, ફરી કોડ મોકલવો પડે | `src/lib/email-verification.ts` |
| પાસવર્ડ ભૂલી જવાય તો કોડ મોકલવો | 1 વખત/મિનિટ/IP | `src/app/api/auth/forgot-password/route.ts` |
| લૉગિન | 5 વખત/મિનિટ/IP; એક જ ખાતા પર સળંગ **5 વખત નિષ્ફળ થાય તો 30 મિનિટ લોક** (423), આ સમય દરમિયાન બાકી પ્રયાસો ઘટતા દેખાય | `src/app/api/auth/login/route.ts`、`rate-limit.ts` |

**ગોપનીયતા સંરક્ષણ વર્તન**: વેરિફિકેશન કોડ મોકલતી વખતે / પાસવર્ડ ભૂલી જાય ત્યારે, ઈમેલ પહેલેથી રજિસ્ટર હોય કે ન હોય,
ઇન્ટરફેસ હંમેશા એક જ સફળતાનો સંદેશ આપે છે, ઈમેલ રજિસ્ટર છે કે નહીં તે ઉઘાડું કરતું નથી.

## રજિસ્ટ્રેશન સફળ પછી સ્ટેટસનો પ્રવાહ

1. વપરાશકર્તા `accountStatus: 'pending'` સાથે ડેટાબેઝમાં સેવ થાય છે, શરૂઆતમાં **3 બેજ** (register route).
2. સર્વર તે જ સમયે બે HttpOnly કૂકી સેટ કરે છે: JWT (સીધું `/subscription` પર જઈ શકે) અને
   pendingUserToken (સબ્સ્ક્રિપ્શન પ્રક્રિયાનું ઓળખપત્ર).
3. રજિસ્ટ્રેશન પેજ `pending_payment` ઓળખી → `/subscription` પર જાય છે (`next` પરત પેરામીટર જાળવી રાખે છે).
4. ચુકવણી પૂરી → `accountStatus` `active` થાય છે (PayPal Webhook થી આપમેળે એક્ટિવેટ; WeChat સ્કેન પર
   મેન્યુઅલ પુષ્ટિ; હુઆવેઈ IAP પર `activate-huawei`). વિગત `payment-and-activation.md` માં જુઓ.

એક્ટિવેટ ન થયેલા (pending) વપરાશકર્તા કોર API (ફીડ, નકશો, ડિજિટલ હ્યુમન ચેટ, ચેક-ઇન વગેરે) કૉલ કરે તો હંમેશા
403 મળે છે; પોસ્ટ શેર લિંક સિવાય (તે જાહેરમાં ખુલ્લી રહે છે).

## સામાન્ય ભૂલ શોધ કોષ્ટક

| લક્ષણ | કારણ | શું કરવું |
|---|---|---|
| «用户名已存在» (યુઝરનેમ પહેલેથી અસ્તિત્વમાં છે) | યુઝરનેમ પહેલેથી લેવાયેલું (કેસ-ઇનસેન્સિટિવ) | બીજું યુઝરનેમ પસંદ કરો |

| «邮箱验证码错误或已过期» (ઈમેલ વેરિફિકેશન કોડ ખોટો અથવા સમાપ્ત) | કોડ ખોટો / 10 મિનિટ વીતી ગઈ / 5 થી વધુ ખોટા પ્રયાસથી નકારાયો | «ફરી મોકલો» પર ક્લિક કરો, **સૌથી નવી** ઈમેલનો કોડ વાપરો |
| વેરિફિકેશન કોડ મળતો નથી | 60 સેકન્ડની રેટ-લિમિટ; અથવા સ્પામ/પ્રમો ફોલ્ડરમાં ગયો | કાઉન્ટડાઉન પૂરું થાય પછી ફરી મોકલો; સ્પામ મેલ ફોલ્ડર તપાસો |
| «手机号已被使用» (મોબાઈલ નંબર પહેલેથી વપરાશમાં) | મોબાઈલ નંબર બીજા ખાતા સાથે જોડાયેલ | મોબાઈલ નંબર દૂર કરો (વૈકલ્પિક) અથવા નંબર બદલો |
| «注册请求过于频繁»/ 429 (રજિસ્ટ્રેશન વિનંતી ખૂબ વારંવાર) | રજિસ્ટ્રેશન 3 વખત/મિનિટ/IP મર્યાદા ઓળંગી | થોડી મિનિટો પછી ફરી પ્રયાસ કરો |
| 409«用户名或邮箱已被注册» (યુઝરનેમ અથવા ઈમેલ પહેલેથી રજિસ્ટર) | સબમિટ કરતી ક્ષણે બીજા સાથે નામ અથડામણ (કન્કરન્સી ફોલબેક) | યુઝરનેમ કે ઈમેલ બદલી ફરી પ્રયાસ કરો |
| «图片大小不能超过5MB»/«不支持 SVG» (ઈમેજ 5MB થી મોટી / SVG સપોર્ટ નથી) | પ્રોફાઇલ ફોટો નિયમ પ્રમાણે નથી | ફોટો બદલો અથવા પ્રોફાઇલ ફોટો છોડી દો |
| રજિસ્ટ્રેશન સફળ પણ લૉગિન 403«请完成订阅以激活账户» (ખાતું એક્ટિવેટ કરવા કૃપા કરી સબ્સ્ક્રિપ્શન પૂરું કરો) | ખાતું હજુ pending છે | લૉગિન કરી પેજની સૂચના પ્રમાણે `/subscription` પર સબ્સ્ક્રિપ્શન પૂરું કરો |
| લૉગિન 423«账户已锁定» (ખાતું લોક થયેલું) | પાસવર્ડ સળંગ 5 વખત ખોટો | 30 મિનિટ રાહ જુઓ |
| લૉગિન 401«还剩 N 次尝试机会» (N પ્રયાસની તક બાકી) | પાસવર્ડ ખોટો, લોક થવાની નજીક | વિચારીને પ્રયાસ કરો, અથવા સીધું «પાસવર્ડ ભૂલી ગયા» પસંદ કરો |
| «该账号未设置密码，请使用其他方式登录» (આ ખાતા માટે પાસવર્ડ સેટ નથી, કૃપા કરીને બીજી રીતે લૉગિન કરો) | થર્ડ-પાર્ટી (Google/Watcha/હુઆવેઈ) ખાતું | મૂળ થર્ડ-પાર્ટી બટનથી લૉગિન કરો |
| «该账号已注销» (ખાતું બંધ કરેલું) | ખાતું deactivate થયેલું | ફરી રજિસ્ટર કરવું પડશે |

## લૉગિનની નાની વિગત (શોધ માટે પણ ઉપયોગી)

લૉગિન **યુઝરનેમ / ઈમેલ / મોબાઈલ નંબર** ત્રણેય એકસાથે સ્વીકારે છે (ત્રણમાંથી ગમે તે ખાતાનું નામ તરીકે).
પાસવર્ડ ભૂલી ગયા: લૉગિન પેજ → «પાસવર્ડ ભૂલી ગયા» → રજિસ્ટર કરેલો ઈમેલ નાખો, 6 અંકનો વેરિફિકેશન કોડ લો → રીસેટ કરો.
