# powpow-register

PowPow બબલ રજિસ્ટ્રેશન સહાયક (OpenClaw આવૃત્તિ): નવા વપરાશકર્તાને «બબલ એટલે શું» ન ખબર હોય તેવી સ્થિતિથી
«ખાતું એક્ટિવેટ થઈને ઉપયોગ માટે તૈયાર» સુધી લઈ જાઓ — ઉત્પાદન પરિચય (ઇન્ટરફેસ સ્ક્રીનશોટ સાથે),
પગલાંબદ્ધ રજિસ્ટ્રેશન માર્ગદર્શન, ભૂલ શોધ, સબ્સ્ક્રિપ્શન એક્ટિવેશનનું વર્ણન.

સંપૂર્ણપણે માર્ગદર્શક-પ્રકારનું skill, કોઈ સ્ક્રિપ્ટ નથી, કોઈ ડિપેન્ડન્સી નથી; બધી રજિસ્ટ્રેશન ક્રિયાઓ વપરાશકર્તા
બ્રાઉઝર/એપમાં જાતે પૂર્ણ કરે છે.

## ઇન્સ્ટોલેશન

```
openclaw skills install @durenzidu/powpow-register
```

## લક્ષણો

1. **ઉત્પાદન પરિચય**: ~120 શબ્દોનો પરિચય + GitHub જાહેર રિપોઝિટરીમાં હોસ્ટેડ ઇન્ટરફેસ સ્ક્રીનશોટની લિંક
   (નકશો પેજ, પોસ્ટ ડિટેલ પેજ વગેરે 6 ફોટા, પરિસ્થિતિ પ્રમાણે 1–3 મોકલો).
2. **રજિસ્ટ્રેશન માર્ગદર્શન**: ફીલ્ડ નિયમો (યુઝરનેમ/પાસવર્ડ/ઈમેલ વેરિફિકેશન કોડ/મોબાઈલ નંબર/પ્રોફાઇલ ફોટો),
   થર્ડ-પાર્ટી લૉગિન (Google/Watcha/હુઆવેઈ), રેટ-લિમિટ પેરામીટર્સ, બધા પ્લેટફોર્મ સોર્સ કોડમાંથી લઈ સ્રોત નોંધેલ.
3. **ભૂલ શોધ**: વેરિફિકેશન કોડ ન મળવો, યુઝરનેમ/ઈમેલ પહેલેથી વપરાશમાં હોવું, 403 એક્ટિવેટ ન થવું, ખાતું લોક
   વગેરે 13 સામાન્ય સમસ્યાઓ.
4. **સબ્સ્ક્રિપ્શન એક્ટિવેશન**: PayPal (વેબ) / WeChat સ્કેન (મેન્યુઅલ પુષ્ટિ) / હુઆવેઈ IAP (HarmonyOS) ત્રણ
   માર્ગોનું વર્ણન અને સમાધાન; હાલની ચુકવણી ચેન સીધી ફરી વાપરી શકાય, skill ફક્ત માર્ગ બતાવે છે.

## સુરક્ષા

- કોઈ કી (key) નો સમાવેશ નથી; સ્ક્રિપ્ટ નથી, વપરાશકર્તાના ઓળખપત્રો (credentials) સાથે સંપર્ક નથી.
- **ક્યારેય માંગતું નથી** વપરાશકર્તાનો પાસવર્ડ, વેરિફિકેશન કોડ કે ચુકવણી પુરાવો; રજિસ્ટ્રેશન અને ચુકવણી બધું
  પ્લેટફોર્મ પેજ પર થાય છે.
