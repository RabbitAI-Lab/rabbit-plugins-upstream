# powpow-register

PowPow પરપોટો નોંધણી સહાયક (OpenClaw આવૃત્તિ): એક નવા વપરાશકર્તાને "પરપોટો શું છે એ પણ નથી ખબર" થી "એકાઉન્ટ સક્રિય, વન-ક્લિક લોગિન, રમવાનું શરૂ" સુધી લઈ જાય છે — પ્રોડક્ટ પરિચય (ઇન્ટરફેસ સ્ક્રીનશૉટ સહિત), agent-સહાયિત નોંધણી (પ્રોફાઇલ ફોટો અપલોડ સહિત), Alipay સબ્સ્ક્રિપ્શન ઓર્ડર અને પેમેન્ટ ટ્રૅકિંગ, ડબલ-લિંક વન-ક્લિક લોગિન, એરર ટ્રબલશૂટિંગ.

**v2.0.0 થી agent-સહાયિત મોડ**: મુખ્ય સ્ક્રિપ્ટ `scripts/powpow-register.mjs` ઝીરો ડિપેન્ડન્સી (Node >= 18), વપરાશકર્તા વાતચીતની બહાર નથી જતો, ફક્ત બે વાર થોડો સમય બહાર જાય છે: ઇમેઇલમાં વેરિફિકેશન કોડ જોવા, Alipay કેશિયરમાં ચૂકવણી. Node ન હોય અથવા વપરાશકર્તા પોતે કરવા માંગે તો, આપમેળે શુદ્ધ માર્ગદર્શન મોડમાં પાછા ફરે છે.

## ઇન્સ્ટોલેશન

```
openclaw skills install @durenzidu/powpow-register
```

## ફીચર્સ

1. **પ્રોડક્ટ પરિચય**: ~120 શબ્દોની શરૂઆત + સ્કિલ સાથે બિલ્ટ-ઇન ઇન્ટરફેસ સ્ક્રીનશૉટ્સ (`assets/screenshots/` નીચે 6 ઇમેજ: નકશો પેજ, પોસ્ટ ડિટેલ પેજ, વગેરે; પ્રસંગ મુજબ 1–3 મોકલો; બાહ્ય ઇમેજ હોસ્ટ નહીં, ઓફલાઇન કામ કરે).
2. **સહાયિત નોંધણી**: agent યુઝરનેમ/નિકનેમ પ્રસ્તાવિત કરે છે, પાસવર્ડ બેમાંથી એક (વપરાશકર્તા આપે અથવા agent બનાવે), વેરિફિકેશન કોડ મોકલવો અને સબમિટ કરવો, પ્રોફાઇલ ફોટો સીધો અપલોડ (≤5MB અને SVG નહીં), સામાન્ય એરર આપમેળે સંભાળે છે (વપરાયેલ/સમાપ્ત/રેટ-લિમિટ).
3. **વન-ક્લિક લોગિન (ડબલ લિંક)**: નોંધણી સફળ થાય ત્યારે તરત "અડધું-લોગિન" લિંક સબ્સ્ક્રિપ્શન પેજ સુધી આપે છે; પેમેન્ટ પહોંચ્યા પછી નવી લોગિન સ્થિતિ બદલીને પૂર્ણ મેમ્બર લિંક હોમપેજ સુધી આપે છે (પ્લેટફોર્મના સત્તાવાર `me?token=` બ્રિજથી, આપમેળે HttpOnly cookie સેટ કરે છે).
4. **સબ્સ્ક્રિપ્શન પેમેન્ટ**: Alipay ચેનલ agent-સહાયિત ઓર્ડર બનાવે છે (માસિક ¥6.99 / ત્રિમાસિક ¥19.99 / વાર્ષિક ¥69.99, એકવારની ખરીદી ઓટો-રિન્યુ નહીં) + પેમેન્ટ પોલ; વિદેશી વપરાશકર્તા PayPal પર પાછા ફરે; વીચેટ QR સ્કેન/હુવાવે IAP રસ્તો બતાવે.
5. **એરર ટ્રબલશૂટિંગ**: વેરિફિકેશન કોડ ન મળે, યુઝરનેમ/ઇમેઇલ વપરાયેલ, 403 ઇનેક્ટિવ, એકાઉન્ટ લૉક વગેરે સામાન્ય સમસ્યાઓ, બધી પ્લેટફોર્મ સોર્સ કોડમાંથી અને સ્થાન સાથે.

## સુરક્ષા

- **પાસવર્ડ** ફક્ત એન્વાયર્નમેન્ટ વેરિએબલ દ્વારા સ્ક્રિપ્ટ પ્રોસેસમાં જાય છે, કદી કમાન્ડ લાઇન આર્ગ્યુમેન્ટમાં નહીં, ડિસ્ક પર નહીં, સ્ટેટસ ફાઇલમાં નહીં; agent દ્વારા બનેલો પાસવર્ડ ફક્ત એક વાર સાચવવા દેખાય છે.
- **વેરિફિકેશન કોડ** ફક્ત સત્તાવાર નોંધણી ઇન્ટરફેસ માટે, વપરાયા પછી કાઢી નાખો; સ્ટેટસ ફાઇલ (ઇમેઇલ/યુઝરનેમ/ટોકન/ઓર્ડર નંબર) સિસ્ટમ કામચલાઉ ડિરેક્ટરીમાં, પ્રવાહ પૂરો થાય ત્યારે `cleanup` એક ક્લિકમાં સાફ કરે છે.
- **પેમેન્ટ**: agent ફક્ત ઓર્ડર બનાવે છે, કેશિયર ખોલે છે, પેમેન્ટ ટ્રેક કરે છે; કદી વપરાશકર્તાના Alipay એકાઉન્ટ અથવા પેમેન્ટ ક્રેડેન્શિયલને સ્પર્શતું નથી, કદી બદલામાં ચૂકવતું નથી. ચૂકવણી હંમેશા વપરાશકર્તા અને Alipay સત્તાવાર કેશિયર વચ્ચે થાય છે.
- બધી વિનંતીઓ ફક્ત સત્તાવાર ડોમેન `https://global.powpow.online` પર જાય છે; કોઈ ચાવી નથી.
