## 1. 表格格式说明

### 11 列标准格式

本 Skill 采用 11 列扩展格式，兼容 Codex 标准和中国 GB/T 27341 要求：

| 列序号 | 列名 | 含义 | 必填 |
|--------|------|------|------|
| 1 | NO | 序号，参考工艺流程编号 | 是 |
| 2 | 过程名称 | 工序名称，可包含编号如"KPR7" | 是 |
| 3 | 危害类型 | 该 CCP 控制的显著危害及类型 | 是 |
| 4 | 关键限值 | 可量化的控制标准 | 是 |
| 5 | 控制措施 | 预防危害的具体方法 | 是 |
| 6 | 监控对象 | 监控什么参数 | 是 |
| 7 | 监控方法 | 怎么监控 | 是 |
| 8 | 监控频率 | 多久监控一次 | 是 |
| 9 | 监控人员 | 谁来监控 | 是 |
| 10 | 纠偏行动 | 失控时的纠正措施 | 是 |
| 11 | 验证 | 确认 CCP 有效性的验证活动 | 是 |
| 12 | 记录 | 需保存的记录文件名称 | 是 |

## 2. 填写指南

### 2.1 NO（序号）

- 按工艺流程顺序编号
- 非 CCP 工序也需列出（标注为"受控工序"）
- 便于追溯和沟通

**示例**：`2` `3` `7`

### 2.2 过程名称

- 使用企业标准工序编号
- 包含足够识别的工序名称
- 与流程图保持一致

**示例**：`KPR2：备料复核` `CCP-1：巴氏杀菌` `8：金属检测`

### 2.3 危害类型

- 明确危害名称和类别
- 格式：`类别（具体危害）`

**类别代码**：
- B：生物性危害
- C：化学性危害
- P：物理性危害

**示例**：
- `B（沙门氏菌）`
- `C（农残）`
- `P（金属异物）`
- `B（细菌增殖）、P（异物）`

### 2.4 关键限值

- 必须可测量、可量化
- 包含具体数值和单位
- 不得使用模糊描述

**正确示例**：
- `温度≥75℃`
- `时间≤12h`
- `pH≤4.6`
- `磁力≥8000高斯`

**错误示例**：
- `温度足够高`（模糊）
- `时间不要太长`（无法判定）

### 2.5 控制措施

- 描述为预防危害采取的具体行动
- 可包含设备参数要求
- 避免与关键限值混淆

**示例**：
- `双人复核制度，过磅确认原料`
- `磁网吸附，磁力强度≥8000高斯`
- `按标准作业指导书操作`

### 2.6 监控对象

- 明确监控的具体参数
- 通常与关键限值对应

**示例**：
- `中心温度`
- `解冻时间和温度`
- `产品金属异物`

### 2.7 监控方法

- 描述具体的监控手段
- 包含设备/工具名称

**示例**：
- `温度探针插入测量`
- `目视检查+磁力计检测`
- `X光机自动检测`

### 2.8 监控频率

- 明确时间或批次间隔
- 使用可操作的表述

**示例**：
- `每批/每包装`
- `每2小时一次`
- `连续监控`
- `每日开机前检查`

### 2.9 监控人员

- 明确具体岗位
- 可列出多个岗位

**示例**：
- `配料作业员`
- `包装作业员、班长`
- `品管员`

### 2.10 纠偏行动

- 包含产品处理措施
- 包含原因分析和改进措施
- 符合法规和企业程序

**纠偏行动要素**：
1. 隔离/标识不合格品
2. 分析失控原因
3. 采取纠正措施
4. 防止再发
5. 记录

**示例**：
```
1. 立即停机，隔离可疑产品
2. 检测设备原因
3. 维修或更换磁网
4. 对隔离产品进行评估处理
5. 记录纠偏过程
```

### 2.11 验证

- 描述确认 CCP 有效性的活动
- 可包含校准、抽检、审核等

**示例**：
- `每日校准温度探针`
- `每周微生物检测`
- `品管员每月审核监控记录`
- `季度第三方检测`

### 2.12 记录

- 列出需保存的具体记录文件
- 便于后续追溯

**示例**：
- `温度监控记录表`
- `磁网检查记录表`
- `纠偏措施记录表`

## 4. 格式模板

### Excel 模板结构

```
A列  B列      C列     D列      E列     F列     G列     H列     I列     J列     K列     L列
NO  过程名称  危害类型 关键限值 控制措施 监控对象 监控方法 监控频率 监控人员 纠偏行动 验证    记录
```

### 格式要求

- 表头行：加粗、背景色填充（建议蓝色或灰色）
- 合并单元格：同一 CCP 的多行可合并
- 文字换行：允许自动换行
- 列宽：建议 F-I 列（监控部分）适当加宽
- 字体：建议宋体/微软雅黑

### 标注规范

当使用默认值或待确认内容时：

| 场景 | 标注方式 | 位置 |
|------|---------|------|
| 行业通用默认值 | `[默认值]` | 内容末尾 |
| 需用户/企业确认 | `[待确认]` | 内容末尾 |
| 未提供的信息 | `[未提供]` | 内容位置 |

**示例**：
```
关键限值：≤4℃ [默认值]
纠偏行动：按企业程序处理 [待确认]
```

## 附录：常见错误及避免

| 错误类型 | 示例 | 正确做法 |
|---------|------|---------|
| 关键限值不可测量 | "温度足够高" | "中心温度≥75℃" |
| 控制措施与关键限值混淆 | 把限值写在控制措施列 | 限值写在 D 列，措施写在 E 列 |
| 监控频率不明确 | "定期检查" | "每2小时一次" |
| 纠偏措施不完整 | 只写"隔离产品" | 包含隔离、分析原因、纠正、记录 |
| 验证活动缺失 | 无验证内容 | 添加校准、抽检、审核等验证 |
