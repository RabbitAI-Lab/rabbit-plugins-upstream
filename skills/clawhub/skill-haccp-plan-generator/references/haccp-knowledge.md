## 1. HACCP 概述

HACCP（Hazard Analysis and Critical Control Point）是国际公认的食品安全预防性管理体系，通过系统识别食品生产过程中的潜在危害，建立关键控制点进行预防控制。

**适用范围**：各类食品生产、餐饮、流通环节

**核心思想**：预防优于检测，而非最终产品检验

## 2. 7 大原理

### 原理 1：危害分析（Hazard Analysis）

识别生产过程中可能引入、消除或降低的可接受水平的生物、化学、物理危害。

**分析内容**：
- 列出所有潜在危害（按原料、工艺、设施）
- 评估每种危害的显著性（发生概率 + 严重程度）
- 确定需要控制的显著危害

### 原理 2：确定关键控制点（Identify CCPs）

确定能实施控制从而预防、消除或降低危害至可接受水平的点、步骤或工序。

**CCP 判定问题**：
1. 该危害是否可能存在且显著？
2. 是否有控制措施可以预防/消除该危害？
3. 是否可以监控该控制措施？
4. 失控后是否有纠偏措施？

### 原理 3：建立关键限值（Establish Critical Limits）

为每个关键控制点设定可接受的标准值（最大/最小值）。

**关键限值特性**：
- 必须是可测量的（温度、时间、pH、水分活度等）
- 代表可接受与不可接受的边界
- 不能与操作限值混淆

### 原理 4：建立监控措施（Establish Monitoring Procedures）

建立监控程序，确保每个 CCP 处于受控状态。

**监控 4 要素**：
| 要素 | 说明 | 示例 |
|------|------|------|
| 对象 | 监控什么 | 温度、时间、感官 |
| 方法 | 怎么监控 | 温度计、目视、探针 |
| 频率 | 多长时间监控一次 | 每小时、每批、连续 |
| 人员 | 谁来监控 | 作业员、班长、品管 |

### 原理 5：建立纠偏措施（Establish Corrective Actions）

当监控显示某个 CCP 失控时，采取预先制定的纠正措施。

**纠偏措施要求**：
- 消除或隔离不合格产品
- 确定并纠正失控原因
- 记录纠偏过程
- 防止问题再次发生

### 原理 6：建立验证程序（Establish Verification Procedures）

建立验证活动，确认 HACCP 计划是否有效运行。

**验证方式**：
- CCP 校准（温度计校准）
- 成品检验
- 微生物检测
- 记录审核
- 体系审计

### 原理 7：建立记录和文件（Establish Documentation）

建立与 HACCP 计划相关的记录和文件。

**文件类型**：
- HACCP 计划书
- CCP 监控记录
- 纠偏措施记录
- 验证记录
- 培训记录

## 3. 12 步骤实施路径

### 预备步骤（Step 1-5）

**Step 1：组建 HACCP 小组**
- 应包含多学科专业人员
- 至少包括：生产、技术、质量管理人员
- 明确职责和权限

**Step 2：描述产品**
- 产品名称、规格
- 配方/成分
- 加工方式
- 包装、储存条件
- 销售方式

**Step 3：确定预期用途**
- 目标消费群体
- 食用方式（直接食用/需加热）
- 特殊人群（婴幼儿、老年人）

**Step 4：绘制流程图**
- 从原料到成品的完整流程
- 包括所有加工步骤
- 标注添加的配料
- 标注返工/再利用环节

**Step 5：现场验证流程图**
- 实际生产现场确认
- 与流程图对比
- 补充遗漏细节

### 原理实施步骤（Step 6-12）

**Step 6：列出所有潜在危害，进行危害分析**

**Step 7：确定关键控制点（CCP）**

**Step 8：为每个 CCP 建立关键限值**

**Step 9：建立监控系统**

**Step 10：建立纠偏措施**

**Step 11：建立验证程序**

**Step 12：建立记录和文件**

## 4. 危害分析指南

### 4.1 三类危害

**生物性危害**

| 类型 | 常见危害 | 典型来源 |
|------|---------|---------|
| 细菌 | 沙门氏菌、大肠杆菌、金葡菌 | 原料、人员、不洁设备 |
| 病毒 | 诺如病毒、甲肝病毒 | 人为污染、水源 |
| 寄生虫 | 弓形虫、旋毛虫 | 原料、交叉污染 |

**化学性危害**

| 类型 | 常见危害 | 典型来源 |
|------|---------|---------|
| 农残/兽残 | 农药、瘦肉精 | 原料带入 |
| 生物毒素 | 黄曲霉毒素 | 原料霉变 |
| 添加剂 | 亚硝酸盐超标 | 配料错误 |
| 金属异物 | 金属碎屑 | 设备磨损 |

**物理性危害**

| 类型 | 常见危害 | 典型来源 |
|------|---------|---------|
| 异物 | 玻璃碎屑、塑料片 | 容器破损、包装材料 |
| 异物 | 头发、指甲 | 人员操作 |
| 异物 | 石头、金属 | 原料带入 |

### 4.2 危害显著性判断

**判断矩阵**：

| 发生概率 | 严重程度 | 结论 |
|---------|---------|------|
| 高 | 高 | 显著危害，必须控制 |
| 高 | 低 | 显著危害，考虑控制 |
| 低 | 高 | 显著危害，考虑控制 |
| 低 | 低 | 非显著危害 |

### 4.3 常见产品危害分析要点

**烘焙食品**
- 生物：细菌增殖（冷却阶段）、霉菌（储存）
- 化学：添加剂过量、油脂氧化
- 物理：金属异物（设备）、异物（原料）

**肉制品**
- 生物：沙门氏菌（原料）、肉毒杆菌（腌制）
- 化学：亚硝酸盐、兽药残留
- 物理：金属异物、骨头碎片

**乳制品**
- 生物：布鲁氏菌、李斯特菌（巴氏消毒不充分）
- 化学：抗生素、三聚氰胺
- 物理：金属异物（挤奶/加工设备）

## 5. CCP 判断决策树

```
问题 1：该危害在本工序是否存在且显著？
│
├─ 否 → 该危害不需要在此工序控制
│        （可能在前序或后续工序控制）
│
└─ 是 ↓

问题 2：是否有专门的控制措施可以预防/消除该危害？
│
├─ 否 → 不是 CCP
│        （需重新评估：改变工艺/增加控制措施）
│
└─ 是 ↓

问题 3：该控制措施是否可以监控？
│
├─ 否 → 不是 CCP
│        （需增加可监控的控制措施）
│
└─ 是 ↓

问题 4：失控后是否能保证产品安全？
│
├─ 否 → 不是 CCP
│        （需增加后续控制）
│
└─ 是 → 确定为 CCP
```

## 6. 关键限值参考

### 温度类

| 监控对象 | 关键限值 | 适用范围 |
|---------|---------|---------|
| 加热中心温度 | ≥75℃（15秒） | 肉类、禽类烹饪 |
| 巴氏杀菌 | ≥72℃（15秒）或等效 | 乳制品、果汁 |
| 高温杀菌 | ≥121℃（压力） | 罐头食品 |
| 冷藏储存 | 0-4℃ | 生鲜食品 |
| 冷冻储存 | ≤-18℃ | 冷冻食品 |
| 解冻 | ≤4℃ / ≤12h | 冷冻原料解冻 |
| 冷却 | 2h内降至21℃以下 | 热制食品冷却 |

### 时间温度组合

| 监控对象 | 关键限值 |
|---------|---------|
| 危险温度带停留 | ≤2h（总计） |
| 冷却（全过程） | ≤6h达到0-4℃ |

### 化学类

| 监控对象 | 关键限值 |
|---------|---------|
| 消毒剂余氯 | 50-100ppm（次氯酸钠） |
| 消毒剂接触时间 | ≥30秒 |
| pH（酸性食品） | ≤4.6 |
| 水分活度（Aw） | ≤0.85（干燥食品） |

### 感官类

| 监控对象 | 关键限值 |
|---------|---------|
| 外观 | 无异物、无变色 |
| 气味 | 无异味 |
| 组织状态 | 无异常 |

## 7. 常用术语表

| 术语 | 英文 | 定义 |
|------|------|------|
| HACCP | Hazard Analysis and Critical Control Points | 危害分析关键控制点 |
| CCP | Critical Control Point | 关键控制点 |
| CL | Critical Limit | 关键限值 |
| OL | Operating Limit | 操作限值（比 CL 更严格的内部标准） |
| 显著危害 | Significant Hazard | 可能发生且后果严重的危害 |
| 纠偏措施 | Corrective Action | CCP 失控时采取的措施 |
| 验证 | Verification | 确认 HACCP 计划有效的活动 |
| 监控 | Monitoring | 观察或测量 CCP 以评估是否受控 |
