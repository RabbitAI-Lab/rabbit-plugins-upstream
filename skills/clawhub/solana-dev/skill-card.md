## Description: <br>
Helps agents build and review Solana dApps, wallet flows, transactions, on-chain programs, testing plans, and security practices. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[playdadev](https://clawhub.ai/user/playdadev) <br>

### License/Terms of Use: <br>


## Use Case: <br>
Developers and engineers use this skill for Solana dApp UI work, wallet connection and signing flows, transaction handling, program development with Anchor or Pinocchio, and testing or security review planning. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can suggest wallet, signing, fee, transfer, or on-chain program changes that may affect real funds. <br>
Mitigation: Review suggested npm, cargo, and code changes before use, and test wallet, signing, fee, and transfer flows on devnet or testnet before touching real funds. <br>
Risk: Publisher-provided Solana Foundation wording and POLT-specific notes may be mistaken for official authority or project-specific requirements. <br>
Mitigation: Treat those notes as publisher-provided context, verify project requirements independently, and do not infer official provenance when server evidence marks provenance as unavailable. <br>
