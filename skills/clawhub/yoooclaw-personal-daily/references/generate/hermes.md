# Hermes 日报生成

仅在 `runtime=hermes` 且当前任务是生成日报时读取本文件。

## 关注配置

读取：

```text
~/.hermes/个性化日报/interests.md
```

配置不存在、不可读或解析后为空时，将“未取得有效话题”返回主流程处理。

## 选择联网能力

1. 检查当前 Agent 实际提供且可调用的工具，从中识别具备互联网搜索或网页访问能力的候选。不得预设工具名称或固定优先级，也不通过本机安装目录或命令推断工具可用性。
2. 综合候选工具的当前可用状态，以及是否能提交关键词、返回来源链接并打开候选原文，选择最适合新闻检索与核验的一个。状态无法直接确认时，用该候选提交一次查询 `OpenAI`、最多返回 1 条结果的探测；探测失败时继续检查其他候选。
3. 找到可用候选时，设置 `acquisition=search`、`search_tool=<实际选择的工具>` 和 `search_failure_message=当前 Hermes 没有可用的联网工具，个性化日报未运行`。根据所选工具的实际能力提交查询并打开候选原文；支持日期、时效或结果数量参数时，将范围限制到宿主时区当天，并将单次结果限制为 5 条。
4. 全部候选均不存在、不可调用或探测失败时，设置 `acquisition=rss`，不设置 `search_tool` 或 `search_failure_message`。

探测失败包括鉴权、配置、网络和响应解析错误。丢弃探测结果，不把它作为日报候选；探测查询计入 15 次查询提交总预算。不要读取、打印或转述任何凭据原值。不要安装、升级、启用或配置联网 Skill 或工具；业务查询开始后不切换获取方式。

**完成条件：** 已确定 Hermes 配置路径，并且 `acquisition` 已且仅已取 `search` 或 `rss` 中的一个值；搜索方式设置唯一的 `search_tool` 和 `search_failure_message`，RSS 方式不设置这两个值。候选获取由任务路由选择的 acquisition reference 负责。
