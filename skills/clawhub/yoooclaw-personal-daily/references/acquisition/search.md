# 搜索获取

仅在所选平台生成 reference 已设置 `acquisition=search` 和唯一 `search_tool` 时读取本文件。

## 执行有界搜索

使用当前时间及宿主时区确定 `YYYY-MM-DD` 和当日时间窗。为每组构造两个查询：

- 中文：`{关键词} {YYYY年M月D日}`。
- 英文：`{英文关键词} {Month Day, Year}`。

使用 `search_tool` 为每组先提交中文和英文查询，每个查询最多检查前 5 个相关结果。初始业务查询最多提交 12 次；用剩余预算修复结果稀薄的高优先级组，每组至多重试一次，改用更具体的公司、产品、人物或事件词。包含所选平台生成 reference 已提交的联网能力探测查询在内，查询提交总数上限为 15。

打开搜索结果页或候选原文不计为新的查询提交；每个搜索组最多打开 3 篇候选原文核验。`search_tool` 不可用时，回复对应平台生成 reference 设置的 `search_failure_message`，然后停止，不切换到另一种联网能力。

必需的中文或英文查询遇到工具、网络或响应解析错误时，在总预算内重试一次；仍失败时回复“联网搜索失败，请检查网络后重试”，然后停止，不输出空日报。查询成功但返回 0 个结果属于有效响应，可以继续并最终形成空日报。

**完成条件：** 每个搜索组的必需中文和英文查询都返回可解析响应，允许结果数为 0；查询提交总数不超过 15，没有未处理的查询错误，并为每个候选记录所属搜索组、来源、链接和发布时间。
