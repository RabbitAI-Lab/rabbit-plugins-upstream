## Description:

Deterministic plot architecture tool with built-in Second Perspective causal reasoning, logic vulnerability detection, automatic worldbuilding generation, narrative presentation layer audit, foreshadowing ledger, spacetime consistency check, hash-chained audit reports, incremental diff-only audit, multi-branch deduction with audit-shape defence, and lexicon-driven event extraction with four deterministic logic validators.

This skill is for research and development only.

## Use Case:

Authors and game or screenwriting developers use the engine to plan fictional narratives, maintain world and character continuity, generate alternative plot branches, and review stories for logical inconsistencies. The skill documentation limits use to personal, non-commercial research unless written authorization is obtained.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Accepting a suggested repair can change dialogue that was rejected.

Mitigation: Keep manuscript backups and inspect the complete diff before adopting repairs.

Risk: Audit hashes can overlook changes to report content.

Mitigation: Do not rely on hashes alone as proof that report content is unchanged.

Risk: An enabled external provider receives story content and settings at its endpoint.

Mitigation: Enable an external provider only when you approve sending that content and those settings.
