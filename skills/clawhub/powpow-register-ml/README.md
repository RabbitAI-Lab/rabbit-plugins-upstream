# powpow-register

PowPow കുമിള രജിസ്ട്രേഷൻ അസിസ്റ്റന്റ് (OpenClaw പതിപ്പ്): ഒരു പുതിയ ഉപയോക്താവിനെ "കുമിള എന്നാൽ എന്താണെന്ന് അറിയില്ല" എന്ന നിലയിൽ നിന്ന് "അക്കൗണ്ട് ആക്റ്റിവേറ്റ് ചെയ്ത്, വൺ-ക്ലിക്ക് ലോഗിൻ ചെയ്ത്, കളിക്കാൻ തുടങ്ങുന്ന" നിലയിലേക്ക് നയിക്കുന്നു — ഉൽപ്പന്ന പരിചയപ്പെടുത്തൽ (യൂസർ ഇന്റർഫേസ് സ്ക്രീൻഷോട്ടുകൾ ഉൾപ്പെടെ), ഏജന്റ്-സഹായ രജിസ്ട്രേഷൻ (പ്രൊഫൈൽ ചിത്രം അപ്‌ലോഡ് ഉൾപ്പെടെ), Alipay/PayPal സബ്സ്ക്രിപ്ഷൻ ഓർഡർ നിർമ്മാണവും അക്കൗണ്ടിൽ വരുന്നത് ട്രാക്ക് ചെയ്യലും, ഡബിൾ-ലിങ്ക് വൺ-ക്ലിക്ക് ലോഗിൻ, എറർ ട്രബിൾഷൂട്ടിംഗ്.

**v2.0.0 മുതൽ ഇത് ഏജന്റ്-സഹായ മോഡാണ്, v2.2.0 മുതൽ പ്ലാറ്റ്ഫോമിന്റെ സൗജന്യ പരീക്ഷണ കാലയളവുമായും അനുസരിച്ച് നടക്കും**: കോർ സ്ക്രിപ്റ്റ് `scripts/powpow-register.mjs` ആശ്രിതമല്ലാത്തതാണ്
(Node ≥ 18); ഉപയോക്താവ് സംഭാഷണം വിടുന്നത് ഒരിക്കൽ മാത്രം: ഇൻബോക്സിൽ വെരിഫിക്കേഷൻ കോഡ് കാണാൻ. നിലവിലെ സൗജന്യ പരീക്ഷണ കാലയളവിൽ രജിസ്റ്റർ ചെയ്ത അക്കൗണ്ട് ഉടനെ എല്ലാ ഫീച്ചറുകളും ഉപയോഗിക്കാം — സബ്സ്ക്രിപ്ഷൻ പേയ്‌മെന്റ് ഓപ്ഷണൽ; പരീക്ഷണ കാലയളവ് അവസാനിച്ച് ഉപയോക്താവ് സബ്സ്ക്രിപ്ഷൻ പേജിൽ ഇറങ്ങിയാൽ ഫ്ലോ സ്വയമേവ പേയ്‌മെന്റ് വഴിയിലേക്ക് മാറും. Node ഇല്ലാതെ, അല്ലെങ്കിൽ ഉപയോക്താവ് സ്വയം ചെയ്യാൻ ആഗ്രഹിക്കുമ്പോൾ, സ്വയമേവ ശുദ്ധ മാർഗ്ഗനിർദേശ മോഡിലേക്ക് തിരികെ.

## ഇൻസ്റ്റാളേഷൻ

```
openclaw skills install @durenzidu/powpow-register
```

## സവിശേഷതകൾ

1. **ഉൽപ്പന്ന പരിചയപ്പെടുത്തൽ**: ഏകദേശം 120 വാക്കുകളുടെ ആമുഖം + സ്കില്ലിനൊപ്പം പാക്ക് ചെയ്ത യൂസർ ഇന്റർഫേസ് സ്ക്രീൻഷോട്ടുകൾ (`assets/screenshots/` ൽ 6 ചിത്രങ്ങൾ: മാപ്പ് പേജ്, പോസ്റ്റ് വിശദാംശ പേജ് മുതലായവ, സാഹചര്യം അനുസരിച്ച് 1–3 അയയ്ക്കുക; ബാഹ്യ ഇമേജ് ഹോസ്റ്റിംഗ് ആവശ്യമില്ല, ഓഫ്‌ലൈനിൽ പ്രവർത്തിക്കും).
2. **സഹായ രജിസ്ട്രേഷൻ**: ഏജന്റ് യൂസർനേം/നിക്ക്‌നേം നിർദ്ദേശിക്കുന്നു, പാസ്‌വേഡ് രണ്ടിൽ ഒന്ന് തിരഞ്ഞെടുക്കുന്നു (ഉപയോക്താവ് നൽകുക അല്ലെങ്കിൽ ഏജന്റ് ജനറേറ്റ് ചെയ്യുക), വെരിഫിക്കേഷൻ കോഡ് അയയ്ക്കലും സമർപ്പണവും, പ്രൊഫൈൽ ചിത്രം നേരിട്ട് അപ്‌ലോഡ് (≤5MB SVG അല്ല), സാധാരണ എററുകൾ സ്വയം കൈകാര്യം ചെയ്യൽ (എടുത്തിരിക്കുന്നു/കാലഹരണപ്പെട്ടത്/റേറ്റ്-ലിമിറ്റ്).
3. **ഒറ്റക്ക്ലിക്ക് ലോഗിൻ (രണ്ട് ലിങ്കുകൾ)**: വിജയകരമായ രജിസ്ട്രേഷന് ഉടനടി, ലോഗിൻ ലിങ്ക് ഉപയോക്താവിനെ നേരിട്ട് ഹോം പേജിലേക്ക് എത്തിക്കുന്നു (സൗജന്യ പരീക്ഷണ കാലയളവിൽ ഒരു ക്ലിക്കിൽ ഉപയോഗിക്കാം);
   സബ്സ്ക്രിപ്ഷൻ പേജിൽ ഇറങ്ങിയാൽ (പരീക്ഷണ കാലയളവ് അവസാനിച്ചു) അല്ലെങ്കിൽ ഉപയോക്താവ് അപ്‌ഗ്രേഡ് ആഗ്രഹിക്കുകയാണെങ്കിൽ സബ്സ്ക്രിപ്ഷൻ ഫ്ലോ പിന്തുടരുക — പണം വന്ന ശേഷം പുതിയ ലോഗിൻ സ്ഥിതിയിലേക്ക് മാറുകയും പൂർണ്ണ അംഗത്വ ലിങ്ക് ഹോം പേജിലേക്ക് എത്തിക്കുകയും ചെയ്യും
   (പ്ലാറ്റ്ഫോമിന്റെ ഔദ്യോഗിക `me?token=` പൽ വഴി, അത് സ്വയമേവ HttpOnly കുക്കി ബച്ചിക്കുന്നു).
4. **സബ്സ്ക്രിപ്ഷൻ പേയ്മെന്റ്**: Alipay (മാസം ¥6.99 / പാദം ¥19.99 / വർഷം ¥69.99, ഒറ്റത്തവണ വാങ്ങൽ ഓട്ടോ-റെന്യൂ ഇല്ല) ഉം PayPal (Premium Monthly, ഏകദേശം $1/മാസം, ഓട്ടോ-റെന്യൂ, എപ്പോൾ വേണമെങ്കിലും റദ്ദാക്കാം) ഉം — രണ്ടിലും ഏജന്റ് ഓർഡർ സൃഷ്ടിച്ച് അക്കൗണ്ടിൽ വരുന്നത് പോളിംഗ് ചെയ്യുന്നു; വെച്ചാറ്റ് QR സ്കാൻ / Huawei IAP വഴി കാണിക്കുന്നു.
5. **എറർ ട്രബിൾഷൂട്ടിംഗ്**: വെരിഫിക്കേഷൻ കോഡ് കിട്ടാത്തത്, യൂസർനേം/ഇമെയിൽ എടുത്തിരിക്കുന്നത്, 403 ആക്റ്റിവേറ്റ് ചെയ്തില്ല, അക്കൗണ്ട് ലോക്ക് ചെയ്തത് തുടങ്ങിയ പൊതു പ്രശ്നങ്ങൾ, എല്ലാം പ്ലാറ്റ്ഫോം സോഴ്സ് കോഡിൽ നിന്നും ഉറവിടം അടയാളപ്പെടുത്തി.

## സെക്യൂരിറ്റി

- **പാസ്‌വേഡ്** എൻവയോൺമെന്റ് വേരിയബിൾ വഴി മാത്രം സ്ക്രിപ്റ്റ് പ്രോസസ്സിലേക്ക് കടന്നുപോകുന്നു, ഒരിക്കലും കമാൻഡ് ലൈൻ ആർഗ്യുമെന്റായി എഴുതരുത്, ഡിസ്കിൽ സൂക്ഷിക്കരുത്, സ്റ്റേറ്റ് ഫയലിൽ ഇടരുത്; ഏജന്റ് ജനറേറ്റ് ചെയ്ത പാസ്‌വേഡ് സൂക്ഷിക്കാൻ വേണ്ടി ഒരിക്കൽ മാത്രം കാണിക്കുന്നു.
- **വെരിഫിക്കേഷൻ കോഡ്** ഔദ്യോഗിക രജിസ്ട്രേഷൻ ഇന്റർഫേസിന് മാത്രം ഉപയോഗിക്കുന്നു, ഉപയോഗിച്ചാൽ ഉപേക്ഷിക്കുന്നു; സ്റ്റേറ്റ് ഫയൽ (ഇമെയിൽ / യൂസർനേം / token / ഓർഡർ നമ്പർ) സിസ്റ്റം ടെംപ് ഡയറക്ടറിയിൽ സൂക്ഷിക്കുന്നു, പ്രക്രിയ അവസാനം `cleanup` ഒറ്റയടിക്ക് നീക്കം ചെയ്യുന്നു.
- **പേയ്മെന്റ്**: ഏജന്റ് ഓർഡർ സൃഷ്ടിക്കുക, കാഷ്യർ തുറക്കുക, അക്കൗണ്ടിൽ വരുന്നത് ചോദിക്കുക മാത്രം; ഒരിക്കലും ഉപയോക്താവിന്റെ Alipay/PayPal അക്കൗണ്ട് അല്ലെങ്കിൽ പേയ്മെന്റ് ക്രെഡൻഷ്യലുകളിൽ സ്പർശിക്കരുത്, ഒരിക്കലും പകരം പേയ് ചെയ്യില്ല. പേയ്മെന്റ് എപ്പോഴും ഉപയോക്താവും ഔദ്യോഗിക കാഷ്യറും തമ്മിൽ തന്നെ നടക്കുന്നു.
- എല്ലാ അഭ്യർത്ഥനകളും ഔദ്യോഗിക ഡൊമെയിനായ `https://global.powpow.online` ലേക്ക് മാത്രം; കീകളൊന്നുമില്ല.
