# powpow-register

PowPow ബബിൾ രജിസ്ട്രേഷൻ സഹായി (OpenClaw പതിപ്പ്): ഒരു പുതിയ ഉപയോക്താവിനെ "ബബിൾ എന്താണ്" എന്നറിയാത്ത അവസ്ഥയിൽ നിന്ന്
"അക്കൗണ്ട് സജീവമാക്കപ്പെട്ടു, സാധാരണ ഉപയോഗിക്കാം" എന്ന അവസ്ഥയിലേക്ക് കൊണ്ടുപോകുന്നു — ഉൽപ്പന്ന അവതരണം (ഇന്റർഫേസ് സ്ക്രീൻഷോട്ടുകൾ ഉൾപ്പെടെ), ഘട്ടം ഘട്ടമായുള്ള രജിസ്ട്രേഷൻ വഴികാട്ടൽ, പിശക് പരിശോധന,
സബ്സ്ക്രിപ്ഷൻ ആക്ടിവേഷൻ വിശദീകരണം.

പൂർണമായും മാർഗനിർദ്ദേശം മാത്രം നൽകുന്ന skill, സ്ക്രിപ്റ്റോ ആശ്രിതത്വങ്ങളോ ഇല്ല; എല്ലാ രജിസ്ട്രേഷൻ പ്രവർത്തനങ്ങളും ഉപയോക്താവ് ബ്രൗസറിലോ ആപ്പിലോ ചെയ്യുന്നതാണ്.

## ഇൻസ്റ്റലേഷൻ

```
openclaw skills install @durenzidu/powpow-register
```

## സവിശേഷതകൾ

1. **ഉൽപ്പന്ന അവതരണം**: ~120 വാക്ക് ഓപ്പണിംഗ് + GitHub പൊതു റിപ്പോസിറ്ററിയിൽ ഹോസ്റ്റ് ചെയ്ത ഇന്റർഫേസ് സ്ക്രീൻഷോട്ട് ലിങ്കുകൾ
   (മാപ്പ് പേജ്, പോസ്റ്റ് വിശദാംശ പേജ് മുതലായ 6 ചിത്രങ്ങൾ, സാഹചര്യം അനുസരിച്ച് 1–3 എണ്ണം തിരഞ്ഞെടുത്ത് അയയ്ക്കുക).
2. **രജിസ്ട്രേഷൻ വഴികാട്ടൽ**: ഫീൽഡ് നിയമങ്ങൾ (യൂസർനെയിം/പാസ്വേഡ്/ഇമെയിൽ വെരിഫിക്കേഷൻ കോഡ്/ഫോൺ നമ്പർ/പ്രൊഫൈൽ ചിത്രം), തേർഡ്-പാർട്ടി ലോഗിൻ
   (Google/Watcha/Huawei), റേറ്റ് ലിമിറ്റ് പാരാമീറ്ററുകൾ, എല്ലാം പ്ലാറ്റ്ഫോം സോഴ്സ് കോഡിൽ നിന്ന് എടുത്ത് ഉറവിടം രേഖപ്പെടുത്തിയത്.
3. **പിശക് പരിശോധന**: വെരിഫിക്കേഷൻ കോഡ് കിട്ടാതിരിക്കൽ, യൂസർനെയിം/ഇമെയിൽ എടുത്തിരിക്കൽ, 403 സജീവമല്ല, അക്കൗണ്ട് ലോക്ക് മുതലായ
    13 സാധാരണ പ്രശ്നങ്ങൾ.
4. **സബ്സ്ക്രിപ്ഷൻ ആക്ടിവേഷൻ**: PayPal (വെബ്) / WeChat QR സ്കാൻ (മാനുവൽ സ്ഥിരീകരണം) / Huawei IAP (HarmonyOS) എന്നീ മൂന്ന്
    ചാനലുകളുടെ വിശദീകരണവും പരിശോധനയും; നിലവിലുള്ള പേയ്മെന്റ് ശൃംഖല നേരിട്ട് വീണ്ടും ഉപയോഗിക്കാം, skill വഴികാട്ടൽ മാത്രം ചെയ്യുന്നു.

## സുരക്ഷ

- ഒരു രഹസ്യ കീയും ഇല്ല; സ്ക്രിപ്റ്റില്ല, ഉപയോക്തൃ ക്രെഡൻഷ്യലുകളുമായി ബന്ധപ്പെടുന്നില്ല.
- **ഒരിക്കലും** ഉപയോക്താവിന്റെ പാസ്വേഡ്, വെരിഫിക്കേഷൻ കോഡ്, പേയ്മെന്റ് ക്രെഡൻഷ്യലുകൾ എന്നിവ ചോദിച്ച് വാങ്ങരുത്; രജിസ്ട്രേഷനും പേയ്മെന്റും എല്ലാം പ്ലാറ്റ്ഫോം പേജുകളിൽ പൂർത്തിയാകും.
