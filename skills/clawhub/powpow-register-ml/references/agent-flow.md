# ഏജന്റ്-സഹായ ഫ്ലോ വും സ്ക്രിപ്റ്റ് കരാറും — powpow-register

SKILL.md ലെ ഘട്ടങ്ങളുടെ എക്സിക്യൂഷൻ വിശദാംശങ്ങൾ. എല്ലാ കമാൻഡുകളും `node scripts/powpow-register.mjs <സബ്-കമാൻഡ്> [ആർഗ്യുമെന്റുകൾ]` ആണ്, സ്ക്രിപ്റ്റ് **ഡിപൻഡൻസി ഇല്ല**, **Node >= 18** ആവശ്യം, എല്ലാ അഭ്യർത്ഥനകളും `https://global.powpow.online` ലേക്ക് മാത്രം.

## സെക്യൂരിറ്റി ഡിസൈൻ (എന്തുകൊണ്ട് ഇങ്ങനെ)

| ഡിസൈൻ | കാരണം |
|---|---|
| പാസ്‌വേഡ് എൻവയോൺമെന്റ് വേരിയബിൾ `POWPOW_REGISTER_PASSWORD` വഴി മാത്രം കടത്തുക | പ്രോസസ് കമാൻഡ് ലൈൻ ആർഗ്യുമെന്റുകൾ ഈ മെഷീനിലെ മറ്റ് പ്രോസസുകൾക്ക് ദൃശ്യമാണ് (argv ലീക്ക് സാധ്യത), എൻവയോൺമെന്റ് വേരിയബിൾ സ്ക്രിപ്റ്റിനുള്ളിൽ വായിച്ച് ഉടൻ ഉപയോഗിക്കുന്നു |
| പാസ്‌വേഡ് **ഒരിക്കലും സ്റ്റേറ്റ് ഫയലിൽ എഴുതരുത്**, ലോഗിൽ പ്രത്യക്ഷപ്പെടരുത് | സ്റ്റേറ്റ് ഫയൽ ഡിസ്കിൽ നിലനിൽക്കാം; സംഭാഷണത്തിൽ ജനറേറ്റ് മോഡ് ഒരിക്കൽ മാത്രം കാണിക്കുന്നത് ഉപയോക്താവ് സൂക്ഷിക്കാൻ വേണ്ടിയാണ് |
| സ്റ്റേറ്റ് ഫയൽ സിസ്റ്റം ടെംപ് ഡയറക്ടറിയിൽ (`os.tmpdir()/powpow-register-state.json`, 0600) | email / username / nickname / token / outTradeNo എന്നീ അഞ്ച് ഫീൽഡുകൾ മാത്രം, `cleanup` ഒറ്റയടിക്ക് നീക്കം ചെയ്യുന്നു |
| ഏജന്റ് നേടുന്ന JWT ഔദ്യോഗിക `me?token=` എൻഡ്‌പോയിന്റ് വഴി ബ്രൗസർ cookie ആക്കി മാറ്റുന്നു | പ്ലാറ്റ്ഫോം Harmony WebView ന് വേണ്ടി രൂപകൽപ്പനം ചെയ്ത ഔദ്യോഗിക ബ്രിഡ്ജ്; സിഗ്നേച്ചർ പരിശോധന സിഗ്നേച്ചർ + വാലിഡിറ്റി മാത്രം പരിശോധിക്കുന്നു, ഡിവൈസ് ഫിംഗർപ്രിന്റ് ബൈൻഡ് ചെയ്യില്ല, ഉപയോക്താവിന്റെ ബ്രൗസർ ഉപയോഗിക്കാം |
| പേയ്മെന്റ് create-order / query / കാഷ്യർ തുറക്കൽ മാത്രം ചെയ്യുന്നു | പേയ്മെന്റ് ആക്ഷൻ ഉം പേയ്മെന്റ് ക്രെഡൻഷ്യലുകളും എപ്പോഴും ഉപയോക്താവും Alipay ഔദ്യോഗിക കാഷ്യറും തമ്മിൽ, ഏജന്റ് കൈകാര്യം ചെയ്യില്ല |

## ഡബിൾ-ലിങ്ക് യന്ത്രം (കോർ ഡിസൈൻ)

പ്ലാറ്റ്ഫോം ലോഗിൻ സ്റ്റേറ്റ് HttpOnly cookie ആണ്, ഏജന്റിന് നേരിട്ട് ബ്രൗസറിനായി cookie സൃഷ്ടിക്കാൻ കഴിയില്ല; ബ്രിഡ്ജ് ഔദ്യോഗിക
`/api/auth/me?token=<JWT>&redirect=<സൈറ്റിനുള്ളിലെ പാത>` എൻഡ്‌പോയിന്റാണ്: സിഗ്നേച്ചർ പരിശോധന → pending ഉപയോക്താവിന് സ്വയം session നിർമ്മിക്കുന്നു → `Set-Cookie: powpow_token` (HttpOnly / SameSite=Lax / 7 ദിവസം) →
redirect പരിശോധിക്കുന്നു (ഒറ്റ സ്ലാഷ് കൊണ്ട് തുടങ്ങണം, `//` ഉം ബാക്ക്സ്ലാഷ് ഉം നിരോധിച്ചിരിക്കുന്നു, പരിഹരിച്ച ശേഷം ഒരേ ഒറിജിനായിരിക്കണം) → 307 താൽക്കാലിക റീഡയറക്റ്റ് ലക്ഷ്യപേജിലേക്ക്.

- **ലിങ്ക് 1 (രജിസ്ട്രേഷൻ വിജയിച്ച ഉടൻ നൽകുന്നു)**: `--target pending` → `/subscription` ലേക്ക് പോകുന്നു.
  ഉപയോക്താവിന്റെ ബ്രൗസർ "അർദ്ധ-ലോഗിൻ" സ്റ്റേറ്റിലാകുന്നു: സബ്സ്ക്രിപ്ഷൻ പേജ്, Alipay റീഡയറക്റ്റ് പേജ് ദൃശ്യമാണ്, പ്രവർത്തിപ്പിക്കാം; ഉള്ളടക്ക പേജുകൾ ഇപ്പോഴും പേയ്-വാൾ കാരണം
  സബ്സ്ക്രിപ്ഷൻ പേജിലേക്ക് തടയപ്പെടുന്നു (മൂന്ന് പാളികളുള്ള സംരക്ഷണം: JWT claims ഗേറ്റ്വേ ചെക്ക് → DB റീചെക്ക് → കോർ API ചെക്ക്, സാധാരണ പെരുമാറ്റം).
- **ലിങ്ക് 2 (paid സ്ഥിരീകരിച്ച ശേഷം നൽകുന്നു)**: ആദ്യം `refresh-login` പുതിയ JWT കൈമാറുന്നു (പേയ്മെന്റ് DB മാത്രം അപ്ഡേറ്റ് ചെയ്യുന്നു, ഇതിനകം ഇഷ്യൂ ചെയ്ത JWT ന്റെ claims മാറ്റില്ല, പുതുക്കിയില്ലെങ്കിൽ "പേയ് ചെയ്തിട്ടും മെംബർഷിപ്പ് ഇല്ല" എന്ന് പ്രത്യക്ഷപ്പെടും), പിന്നെ `--target home` → ഹോംപേജിലേക്ക് പോകുന്നു,
  പൂർണ്ണ മെംബർ സ്റ്റേറ്റസ്.

## പൂർണ്ണ സീക്വൻസ് (സാധാരണ പാത)

```
1.  status                          # ചുറ്റുപാട് സ്വയം പരിശോധന
2.  (ഘട്ടം 2 സംഭാഷണത്തിൽ വിവരങ്ങൾ സ്ഥിരീകരിക്കുന്നു, പാസ്‌വേഡ് രണ്ടിൽ ഒന്ന്; ജനറേറ്റ് മോഡ്: gen-password → ഉപയോക്താവ് ഉടൻ സൂക്ഷിക്കാൻ പറയുക)
3.  prepare-suggest --username U --nickname N --email E
4.  send-code --email E             # → ഉപയോക്താവ് ഇമെയിലിൽ പോയി കോഡ് നോക്കുക (സംഭാഷണം വിട്ടു പോകുന്ന ഏക ഘട്ടം①)
5.  POWPOW_REGISTER_PASSWORD=*** register --code 123456 [--avatar pic.jpg]
6.  login-link --target pending     # → ലിങ്ക് 1 ഉപയോക്താവിന്
7.  (ഉപയോക്താവ് പാക്കേജ് തിരഞ്ഞെടുക്കുന്നു) create-order --package monthly
8.  start <പേയ്മെന്റ് പേജ് ഫയൽ>              # Windows; macOS open, Linux xdg-open
    # → ഉപയോക്താവ് Alipay കാഷ്യറിൽ പേയ് ചെയ്യുന്നു (സംഭാഷണം വിട്ടു പോകുന്ന ഘട്ടം②)
9.  query (ഓരോ 10–15s ഇടവേളയിലും) paid വരെ
10. refresh-login                   # ACTIVE ഡിക്ലറേഷനുള്ള പുതിയ JWT കൈമാറുന്നു
11. login-link --target home        # → ലിങ്ക് 2 ഉപയോക്താവിന്
12. whoami                          # subscriptionStatus: ACTIVE സ്ഥിരീകരിക്കുന്നു (ഓപ്ഷണൽ)
13. cleanup                         # സ്റ്റേറ്റ് ഫയൽ നീക്കം ചെയ്യുന്നു
```

## കമാൻഡ് → പ്ലാറ്റ്ഫോം API മാപ്പിംഗ്

| സ്ക്രിപ്റ്റ് കമാൻഡ് | പ്ലാറ്റ്ഫോം ഇന്റർഫേസ് |
|---|---|
| `send-code` | `POST /api/auth/register/send-code` |
| `register` | `POST /api/auth/register` (multipart, പ്രൊഫൈൽ ചിത്രം നേരിട്ട് അപ്‌ലോഡ്) |
| `login-link` | `GET /api/auth/me?token=…&redirect=…` (ലിങ്ക് തന്നെ, ബ്രൗസർ ക്ലിക്ക് ചെയ്യുമ്പോൾ പ്രവർത്തിക്കുന്നു) |
| `create-order` | `POST /api/payment/alipay/create-order` (Bearer) |
| `query` | `GET /api/payment/alipay/query?outTradeNo=…` (Bearer) |
| `refresh-login` | `POST /api/auth/login` (`{step:1, username, password}`) |
| `whoami` | `GET /api/auth/me?token=…` |

നിയമ ഉറവിടം: രജിസ്ട്രേഷൻ ഫീൽഡ് ഉം റേറ്റ്-ലിമിറ്റും `registration-flow.md` കാണുക; പാക്കേജും ആക്റ്റിവേഷൻ ലിങ്കും `payment-and-activation.md` കാണുക (രണ്ടും പ്ലാറ്റ്ഫോം സോഴ്സ് കോഡ് ഫയൽ അടയാളപ്പെടുത്തിയിരിക്കുന്നു).

## ഫാൾബാക്ക് മോഡ് (പ്യൂർ ഗൈഡൻസ്)

താഴെ പറയുന്ന ഏതെങ്കിലും സാഹചര്യത്തിൽ ഉടൻ v1 ശൈലിയിലുള്ള പ്യൂർ ഗൈഡൻസ് മോഡിലേക്ക് മടങ്ങുക, സ്ക്രിപ്റ്റ് കൊണ്ട് വിഷമിക്കരുത്:

- Node >= 18 ഇല്ല അല്ലെങ്കിൽ സ്ക്രിപ്റ്റ് തുടർച്ചയായി രണ്ടുതവണ അതേ തരം പരാജയപ്പെടുന്നു;
- ഉപയോക്താവ് വ്യക്തമായി "ഞാൻ വെബിൽ സ്വയം പ്രവർത്തിക്കും" എന്ന് പറയുന്നു;
- കമ്പനി / ഡിവൈസ് നയം സ്ക്രിപ്റ്റ് നെറ്റ്‌വർക്കിനെ നിരോധിക്കുന്നു.

മടങ്ങിയ ശേഷം: രജിസ്ട്രേഷൻ പേജ് https://global.powpow.online/register ഉം സബ്സ്ക്രിപ്ഷൻ പേജ്
https://global.powpow.online/subscription ഉം നൽകുക, `registration-flow.md` ന്റെ നിയമങ്ങൾ പിന്തുടർന്ന് കൂടെയുണ്ടായി ട്രബിൾഷൂട്ട് ചെയ്യുക,
ടോൺ മാറ്റരുത്, ഓരോ റൗണ്ടിലും "അടുത്ത ഘട്ടം" ബ്ലോക്കോടെ സമാപിക്കുക.
