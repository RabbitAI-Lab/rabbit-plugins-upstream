# ഏജന്റ്-സഹായ ഫ്ലോ വും സ്ക്രിപ്റ്റ് കരാറും — powpow-register

SKILL.md ലെ ഘട്ടങ്ങളുടെ എക്സിക്യൂഷൻ വിശദാംശങ്ങൾ. എല്ലാ കമാൻഡുകളും `node scripts/powpow-register.mjs <സബ്-കമാൻഡ്> [ആർഗ്യുമെന്റുകൾ]` ആണ്, സ്ക്രിപ്റ്റ് **ഡിപൻഡൻസി ഇല്ല**, **Node >= 18** ആവശ്യം, എല്ലാ അഭ്യർത്ഥനകളും `https://global.powpow.online` ലേക്ക് മാത്രം.

## സെക്യൂരിറ്റി ഡിസൈൻ (എന്തുകൊണ്ട് ഇങ്ങനെ)

| ഏജന്റ് നേടുന്ന JWT ഔദ്യോഗിക `me?token=` എൻഡ്‌പോയിന്റ് വഴി ബ്രൗസർ cookie ആക്കി മാറ്റുന്നു | പ്ലാറ്റ്ഫോം Harmony WebView ന് വേണ്ടി രൂപകൽപ്പനം ചെയ്ത ഔദ്യോഗിക ബ്രിഡ്ജ്; സിഗ്നേച്ചർ പരിശോധന സിഗ്നേച്ചർ + വാലിഡിറ്റി മാത്രം പരിശോധിക്കുന്നു, ഡിവൈസ് ഫിംഗർപ്രിന്റ് ബൈൻഡ് ചെയ്യില്ല, ഉപയോക്താവിന്റെ ബ്രൗസർ ഉപയോഗിക്കാം |

## ഇരട്ട-ലിങ്ക് സങ്കേതം (കോർ ഡിസൈൻ)

പ്ലാറ്റ്ഫോമിന്റെ ലോഗിൻ സ്ഥിതി ഒരു HttpOnly കുക്കിയാണ്, അത് ഏജന്റ് നേരിട്ട് ബ്രൗസറിൽ നൽകാൻ കഴിയില്ല; പൽ ഔദ്യോഗിക
`/api/auth/me?token=<JWT>&redirect=<സൈറ്റിനുള്ളിലെ പാത്>` എൻഡ്‌പോയിന്റാണ്: ഒപ്പ് പരിശോധിക്കുക → സ്വയമേവ സെഷൻ
സൃഷ്ടിക്കുക → `Set-Cookie: powpow_token` (HttpOnly / SameSite=Lax / 7 ദിവസം) → റീഡയറക്ട് പരിശോധന
(ഒറ്റ സ്ലാഷിൽ തുടങ്ങണം, `//` ബാക്ക്സ്ലാഷുകൾ വിലക്കം, പാർസ് ചെയ്ത ശേഷം same-origin ആയിരിക്കണം) → ലക്ഷ്യ പേജിലേക്ക് 307 താൽക്കാലിക റീഡയറക്ട്.

ലിങ്കിന് രണ്ട് ലക്ഷ്യങ്ങളുണ്ട്, **ആദ്യം home സൃഷ്ടിക്കുക, പിന്നെ ഉപയോക്താവ് എവിടെ ഇറങ്ങി എന്നതിനനുസരിച്ച് pending വഴി പോകണമോ എന്ന് തീരുമാനിക്കുക**:

- **home ലിങ്ക് (സ്ഥിരമായി അയയ്ക്കുന്നു, `--target home` → `/`-ൽ ഇറങ്ങും)**: വിജയകരമായ രജിസ്ട്രേഷന് ഉടനടി സൃഷ്ടിച്ച് ഉപയോക്താവിന് അയയ്ക്കുന്നു.
  സൗജന്യ പരീക്ഷണ കാലയളവിൽ ഉപയോക്താവ് നേരിട്ട് ഹോം പേജിലേക്ക് പോകും, എല്ലാം ഉപയോഗിക്കാം; **ലിങ്ക് ക്ലിക്ക് ചെയ്ത് സബ്സ്ക്രിപ്ഷൻ പേജിൽ ഇറങ്ങിയാൽ സൗജന്യ പരീക്ഷണ കാലയളവ് അവസാനിച്ചു** — പേയ്‌മെന്റ് ഫ്ലോയിലേക്ക് മാറുക (താഴെ കാണുക); സ്ക്രിപ്റ്റ് മാറ്റമോ വീണ്ടും രജിസ്ട്രേഷനോ വേണ്ട.
- **pending ലിങ്ക് (പേയ്‌മെന്റ് ഫ്ലോയിൽ ഉപയോഗിക്കുന്നു, `--target pending` → `/subscription`-ൽ ഇറങ്ങും)**:
  ഉപയോക്താവിന്റെ ബ്രൗസർ "അർധ-ലോഗിൻ" സ്ഥിതിയിൽ പ്രവേശിക്കും: സബ്സ്ക്രിപ്ഷൻ പേജും പേയ്‌മെന്റിന് ശേഷം മടങ്ങി വരാനുള്ള പേജും കാണാനും നിയന്ത്രിക്കാനും കഴിയും. പണം വന്ന ശേഷം,
  ACTIVE ക്ലെയിമുള്ള പുതിയ JWT-ലേക്ക് മാറാൻ `refresh-login` പ്രവർത്തിപ്പിക്കുക, പിന്നെ പൂർണ്ണ അംഗത്വ സ്ഥിതിക്ക് home ലിങ്ക് വീണ്ടും അയയ്ക്കുക.

## പൂർണ്ണ ക്രമം

### വേഗത്തിലുള്ള വഴി (സൗജന്യ പരീക്ഷണ കാലയളവിൽ — മിക്ക കേസുകളും)

```
1.  status                          # പരിസര സ്വയം-പരിശോധന
2.  (ഘട്ടം 2: വിവരങ്ങൾ ഉറപ്പിക്കാൻ സംഭാഷണം, പാസ്‌വേഡ് ഇഷ്ടം; ജനറേറ്റ് മോഡ്: gen-password → ഉപയോക്താവിന് ഉടനെ സംരക്ഷിക്കാൻ പറയുക)
3.  prepare-suggest --username U --nickname N --email E
4.  send-code --email E             # → ഉപയോക്താവ് ഇൻബോക്സിൽ കോഡ് പരിശോധിക്കും (സംഭാഷണം വിടുന്ന ഒരേഒരു സമയം)
5.  POWPOW_REGISTER_PASSWORD=*** register --code 123456 [--avatar pic.jpg]
6.  login-link --target home        # → ലിങ്ക് ഉപയോക്താവിന് അയയ്ക്കുക; ഒരു ക്ലിക്കിൽ ഹോം പേജിൽ
7.  (ഉപയോക്താവ് ഉള്ളിൽ കയറിയെന്ന് ഉറപ്പിക്കുന്നു) → ഉടനെ അവസാനിപ്പിക്കുക: cleanup + അക്കൗണ്ട് കാർഡ് + ആദ്യ പടികളിലേക്ക് നിർദേശം
```

### പേയ്‌മെന്റ് വഴി (ഉപയോക്താവ് അംഗത്വം ആഗ്രഹിക്കുമ്പോൾ, അല്ലെങ്കിൽ സൗജന്യ കാലയളവ് അവസാനിച്ചുവെങ്കിൽ)

```
1–5. വേഗത്തിലുള്ള വഴി പോലെ (register വിജയിച്ച ശേഷം സ്ഥിതിയിൽ ടോക്കൺ ഇതിനകം ഉണ്ട്)
6.  login-link --target pending     # → അർധ-ലോഗിൻ ലിങ്ക്, പേയ്‌മെന്റ് തിരികെ വരാനുള്ള പേജ് പ്രവർത്തിക്കുന്നു
7.  (ഉപയോക്താവ് പേയ്‌മെന്റ് രീതി തിരഞ്ഞെടുക്കുന്നു)
    # Alipay: create-order --package monthly|quarterly|yearly
    # PayPal: create-order --provider paypal
8.  start <പേയ്‌മെന്റ് പേജ് ഫയൽ>   # Windows; macOS open, Linux xdg-open
    # → ഉപയോക്താവ് Alipay/PayPal കാശിയറിൽ പേയ്‌മെന്റ്/അനുമതി പൂർത്തിയാക്കും (സംഭാഷണം വിടും)
9.  query (എല്ലാ 10–15 സെക്കൻഡിനും) paid / ACTIVE വരെ
10. refresh-login                   # ACTIVE ക്ലെയിമുള്ള പുതിയ JWT-ലേക്ക് മാറ്റം
11. login-link --target home        # → ഉപയോക്താവിന് പൂർണ്ണ അംഗത്വ ലിങ്ക് അയയ്ക്കുക
12. whoami                          # subscriptionStatus: ACTIVE ഉറപ്പിക്കുക (ഓപ്ഷണൽ)
13. cleanup                         # സ്ഥിതി ഫയൽ ശുദ്ധീകരിക്കുക
```
## കമാൻഡ് → പ്ലാറ്റ്ഫോം API മാപ്പിംഗ്

| സ്ക്രിപ്റ്റ് കമാൻഡ് | പ്ലാറ്റ്ഫോം ഇന്റർഫേസ് |
|---|---|
| `send-code` | `POST /api/auth/register/send-code` |
| `register` | `POST /api/auth/register` (multipart, പ്രൊഫൈൽ ചിത്രം നേരിട്ട് അപ്‌ലോഡ്) |
| `login-link` | `GET /api/auth/me?token=…&redirect=…` (ലിങ്ക് തന്നെ, ബ്രൗസർ ക്ലിക്ക് ചെയ്യുമ്പോൾ പ്രവർത്തിക്കുന്നു) |
| `create-order` | `POST /api/payment/alipay/create-order` (Bearer, Alipay)<br>`GET /api/subscription/plans` + `POST /api/subscription/create` (Bearer, PayPal) |
| `query` | `GET /api/payment/alipay/query?outTradeNo=…` (Bearer, Alipay)<br>`GET /api/subscription/create` (Bearer, PayPal) |
| `refresh-login` | `POST /api/auth/login` (`{step:1, username, password}`) |
| `whoami` | `GET /api/auth/me?token=…` |

നിയമ ഉറവിടം: രജിസ്ട്രേഷൻ ഫീൽഡ് ഉം റേറ്റ്-ലിമിറ്റും `registration-flow.md` കാണുക; പാക്കേജും ആക്റ്റിവേഷൻ ലിങ്കും `payment-and-activation.md` കാണുക (രണ്ടും പ്ലാറ്റ്ഫോം സോഴ്സ് കോഡ് ഫയൽ അടയാളപ്പെടുത്തിയിരിക്കുന്നു).

## ഫാൾബാക്ക് മോഡ് (പ്യൂർ ഗൈഡൻസ്)

താഴെ പറയുന്ന ഏതെങ്കിലും സാഹചര്യത്തിൽ ഉടൻ v1 ശൈലിയിലുള്ള പ്യൂർ ഗൈഡൻസ് മോഡിലേക്ക് മടങ്ങുക, സ്ക്രിപ്റ്റ് കൊണ്ട് വിഷമിക്കരുത്:

- Node >= 18 ഇല്ല അല്ലെങ്കിൽ സ്ക്രിപ്റ്റ് തുടർച്ചയായി രണ്ടുതവണ അതേ തരം പരാജയപ്പെടുന്നു;
- ഉപയോക്താവ് വ്യക്തമായി "ഞാൻ വെബിൽ സ്വയം പ്രവർത്തിക്കും" എന്ന് പറയുന്നു;
- കമ്പനി / ഡിവൈസ് നയം സ്ക്രിപ്റ്റ് നെറ്റ്‌വർക്കിനെ നിരോധിക്കുന്നു.

തിരികെ പോയ ശേഷം: രജിസ്ട്രേഷൻ പേജ് https://global.powpow.online/register നൽകുക (സൗജന്യ പരീക്ഷണ കാലയളവിൽ വെബ് രജിസ്ട്രേഷനും അതേപടി ഉടനടി; സബ്സ്ക്രിപ്ഷൻ ആവശ്യമെങ്കിൽ സബ്സ്ക്രിപ്ഷൻ പേജ് https://global.powpow.online/subscription നൽകുക), `registration-flow.md`-ലെ നിയമങ്ങൾ പ്രകാരം അരികിൽ പ്രശ്നങ്ങൾ പരിഹരിക്കുക, അതേ ശൈലി നിലനിർത്തുക, എല്ലാ റൗണ്ടും "അടുത്ത പടി" ബ്ലോക്കോട് അവസാനിപ്പിക്കുക.
