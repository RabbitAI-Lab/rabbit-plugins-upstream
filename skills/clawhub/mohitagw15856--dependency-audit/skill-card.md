## Description: <br>
Audits project dependencies for security vulnerabilities, license compliance issues, outdated packages, and transitive dependency risk. Use when asked to audit dependencies, review package security, check license compliance, assess dependency health, or produce a vulnerability report. Produces a vulnerability findings table, license compliance matrix, update priority matrix, dependency health score, and 30-day remediation plan. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineering teams use this skill to turn project dependency manifests or audit-tool output into a prioritized dependency audit covering vulnerabilities, license compliance, outdated packages, transitive risk, and remediation planning. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Suggested dependency update commands, especially force-based fixes, can introduce breaking changes. <br>
Mitigation: Review proposed update commands before execution and test dependency changes against the project before merging. <br>
