# Zrzuty ekranu produktu — powpow-register

Używane w razie potrzeby w trakcie działania. Gdy użytkownik nie zna PowPow lub potrzebuje „zobaczyć", jak wygląda finalny produkt, wyślij odpowiedni link.

## Zasady linków

- Główny link (raw): `https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-0N.jpg`
- Mirror (gdy raw nie działa, `N` = 1–6): `https://cdn.jsdelivr.net/gh/durenzidu/durenzidu@main/screenshots/powpow-0N.jpg`
- Obrazy są w publicznym repozytorium, można je wysyłać na zewnątrz; **nie** pobieraj ich do katalogu skillu i nie wysyłaj lokalnych ścieżek.
- Za każdym razem wysyłaj tylko 1–3 obrazy związane z bieżącym tematem.

## Lista

### powpow-01.jpg — Strona szczegółów cyfrowego człowieka

![Strona szczegółów cyfrowego człowieka](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-01.jpg)

Karta cyfrowego człowieka stworzonego z prawdziwej osoby / postaci historycznej: status online, lokalizacja, opis, „rozpocznij rozmowę" itp.
**Gdzie użyć**: prezentacja „po rejestracji możesz rozmawiać z cyfrowymi ludźmi na mapie".

### powpow-02.jpg — Strona edycji posta

![Strona edytora postów](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-02.jpg)

Interfejs edycji posta / dziennika podróży, z grupą pływających przycisków w prawym dolnym rogu.
**Gdzie użyć**: gdy użytkownik pyta „co mogę robić po zarejestrowaniu się" / „gdzie mogę pisać".

### powpow-03.jpg — Strona mapy (bąbelki + cyfrowi ludzie)

![Strona mapy](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-03.jpg)

Pełny widok publicznej mapy: posty z lokalizacjami skupiają się na mapie jako „bąbelki", cyfrowi ludzie są przypięci awatarami w rzeczywistych miejscach.
**Gdzie użyć**: **pierwszy wybór przy prezentacji produktu** — „twoje dzienniki podróży staną się bąbelkiem na mapie".

### powpow-04.jpg — Profil (zasoby cyfrowe)

![Strona profilu](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-04.jpg)

Strona użytkownika: znajomi / obserwowani / obserwujący oraz „zasoby cyfrowe" — saldo odznak, moje bąbelki, moi cyfrowi ludzie.
**Gdzie użyć**: przy „rejestracja daje 3 odznaki" pokaż, gdzie znajdują się odznaki; gdy użytkownik pyta „jakie mam zasoby".

### powpow-05.jpg — Strona postępu fabuły

![Strona postępu fabuły](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-05.jpg)

Rozgrywka fabularna platformy (przykład „永乐·1421"): postęp rozdziałów, zdobywanie odznak, odgrywanie ról.
**Gdzie użyć**: „co jeszcze mogę robić oprócz publikowania" / „jak zdobywać odznaki".

### powpow-06.jpg — Strona szczegółów posta (przykład finalny)

![Strona szczegółów posta](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-06.jpg)

Opublikowany dziennik podróży: autor, tag lokalizacji, treść, ilustracje; na dole polubienie / komentarz / udostępnienie / zapisanie.
**Gdzie użyć**: **drugi obraz na start** — „to zobaczysz, gdy ktoś otworzy twój bąbelek na mapie".

## Szybki przegląd scen

| Co mówi użytkownik / bieżący etap | Który obraz wysłać |

| Otwarcie: „czym jest PowPow" | powpow-03 + powpow-06 |
| „Co mogę robić po rejestracji?" | powpow-02 + powpow-01 |
| „Czym są odznaki / co mam?" | powpow-04 |
| „Co mogę robić oprócz publikowania postów?" | powpow-05 |
| Rozwiązywanie błędu rejestracji / subskrypcji | zwykle nie trzeba obrazu; wyślij dopiero, gdy trzeba pokazać położenie strony |

## Notatki serwisowe

Obecna galeria nie zawiera zrzutów **strony rejestracji** ani **strony subskrypcji**. Gdyby w przyszłości dodano je do `screenshots/` w repozytorium `durenzidu/durenzidu` (np. `powpow-07.jpg` — strona rejestracji, `powpow-08.jpg` — strona subskrypcji), dodaj sekcję w tym dokumencie według tego samego formatu, a tekst prowadzący w SKILL.md można zaktualizować.
