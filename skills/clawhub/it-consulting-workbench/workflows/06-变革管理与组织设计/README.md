# 阶段5: 变革管理与组织设计

## 本阶段目标
确保技术方案能在组织内顺利落地。再好的技术方案，如果人不接受、组织不支撑，都会失败。这是横切所有阶段的支撑能力。

## 使用场景
- 大型IT项目启动前需要变革管理计划
- IT组织重组/转型
- 新系统上线需要用户采纳策略
- 数字化转型中发现组织是瓶颈

## 前置条件
- 技术/战略方案已有初步结论
- 了解客户组织现状(可从诊断报告获取)
- 识别了关键变革阻力来源

## 本阶段产出物
| 产出物 | 说明 | 交付对象 |
|--------|------|---------|
| 变革管理计划 | 含: 利益相关者分析/变革影响评估/沟通计划/培训计划/阻力管理 | CIO/变革负责人 |
| IT组织设计建议 | 目标组织架构/角色定义/能力模型/人才路线图 | CIO/CHRO |
| 变革准备度评估 | 5维评分 + 改进建议 | 项目发起人 |

## 关键成功因素
- **变革管理不是PPT，是日常**: 每个项目会议都应该有变革管理的议程
- **找对你的变革推动者(Change Champions)**: 不在职位高低，在影响力
- **Kotter + ADKAR双管齐下**: 组织层面用Kotter 8步，个体层面用ADKAR
- **衡量采纳率，不止上线率**: 系统上线≠用户使用≠业务价值
