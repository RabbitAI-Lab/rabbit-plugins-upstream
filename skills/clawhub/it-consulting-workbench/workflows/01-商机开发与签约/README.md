# 阶段0: 商机开发与签约

## 本阶段目标
从第一次和潜在客户接触，到签署项目合同的全过程。

## 完整流程
```
初次客户沟通 → 需求澄清与问题诊断 → 项目建议书(Proposal) → SOW合同与谈判 → 签约
```

## 前置条件
- 客户主动联系或通过商务渠道获得商机
- 大致了解客户所在行业和企业规模

## 本阶段产出物
| 产出物 | 说明 | 使用者 |
|--------|------|--------|
| 客户会议纪要 | 首次/后续沟通结构化记录 | 内部团队 |
| 问题诊断摘要 | Problem Statement + 初步假设 | 内部+客户 |
| 项目建议书(Proposal) | 正式商业提案 | 客户决策层 |
| 工作说明书(SOW) | 合同附件，定义范围/交付/时间/费用 | 签约双方 |

## 子文件指引

| 场景 | 进入文件 | 何时使用 |
|------|---------|---------|
| 第一次见客户，不知道聊什么 | [01-初次客户沟通.md](01-初次客户沟通.md) | 所有初次会议前 |
| 客户需求模糊，"帮我们看看有什么问题" | [02-需求澄清与问题诊断.md](02-需求澄清与问题诊断.md) | 需求不明确时 |
| 客户要求出方案和报价 | [03-项目建议书Proposal.md](03-项目建议书Proposal.md) | 准备Proposal时 |
| 客户要签合同，需要SOW | [04-SOW合同与谈判.md](04-SOW合同与谈判.md) | 签约前 |

## 关键成功因素
- **前3次沟通就建立信任**: 用结构化提问展示专业性，绝不空谈方法论
- **快:** 初次会议后48小时内出会议纪要和问题诊断摘要
- **不急于报价**: 充分理解需求前不讨论价格
- **不夸大**: 明确说明哪些能做哪些不能做，专业边界清晰
