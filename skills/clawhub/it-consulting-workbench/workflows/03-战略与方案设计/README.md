# 阶段2: 战略与方案设计

## 本阶段目标
基于诊断发现，设计目标蓝图和分阶段实施路径。这是咨询项目的核心价值创造阶段。

## 完整流程
```
诊断报告输入 → 根据客户核心诉求选择专题 → 目标蓝图设计 → 差距分析 → 路线图 → 商业论证
```

## 前置条件
- 诊断报告已完成并获得客户确认
- 客户战略文档/业务计划已获取
- 客户决策层对项目方向有初步共识

## 关键成功因素
- **选取3-5个核心举措，不是30个**: 80/20法则，聚焦最高价值的少数
- **每项举措必须有明确Owner和KPI**: 没有责任人的战略只是愿望清单
- **分3波推动**: Quick Wins(0-6月)→Core Transformation(6-18月)→Innovation(18-36月)
- **商业论证是战略的脊梁**: 没有ROI验证的战略不会被董事会批准
