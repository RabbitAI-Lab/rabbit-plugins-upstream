# 风格 06：机器人背影构图风

## 适用场景

启发、反思、趋势预判、面向未来或面向宏大工程场景的内容。

## 构图描述

2.35:1 横版。机器人 IP 背对镜头，位于画面下半部分或左下角，约占画面高度 50%-60%，面向远处的「工程场景」——可以是数据大屏、汽车轮廓、工厂剪影、城市天际线或抽象的技术网格。

背景占画面 2/3 以上，颜色从近景 Primary-900 向远处渐淡至 Primary-700 / Primary-500，营造纵深感和想象空间。只允许单色深浅过渡，禁止蓝紫渐变或彩虹渐变。

标题放在画面上方，思源黑体 Heavy，白色，文字直接表达主题。可在画面底部或远处加入淡淡 FRF 曲线作为品牌符号。

## 必须包含元素

- 2.35:1 横版构图
- 机器人 IP 背影朝向远方
- 宏大的工程/数据/城市远景背景
- 纵深光影（仅限品牌蓝色系深浅过渡）
- 标题（思源黑体 Heavy，白色）
- 淡淡 FRF 曲线品牌符号

## 提示词模板第一行

2.35:1 横版构图，公众号封面，机器人背影构图风格。
