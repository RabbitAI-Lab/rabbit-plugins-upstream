# 风格 04：对比波形风

## 适用场景

前后对比、新旧对比、案例复盘、正确 vs 错误、AI 工具前后效果对比类文章。

## 构图描述

2.35:1 横版。画面以左右或上下对比结构为主。背景为深色工程蓝，左右两侧各有一条 FRF 频率响应曲线，分别用不同颜色区分（例如左侧灰色/淡蓝表示 Before，右侧 Accent-Cyan 表示 After）。

可在左右两侧叠加半透明对比卡片或数据框，标注关键差异点（如峰值降低、共振消除）。

机器人 IP 位于画面中央或偏向一侧，手指向其中一条曲线或差异区域，做出讲解/对比姿态。表情根据内容选择：困惑、得意、推荐、思考均可。

标题横跨画面上方，思源黑体 Heavy，白色，文字直接表达对比主题。关键词可用 Accent-Orange 标签框出。

## 必须包含元素

- 2.35:1 横版构图
- 左右/上下对比结构
- 两条 FRF 波形（Before / After）
- 机器人 IP 居中指明差异
- 对比数据标签或关键词
- 思源黑体 Heavy 标题
