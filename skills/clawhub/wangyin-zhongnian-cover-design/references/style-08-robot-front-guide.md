# 风格 08：机器人正面指引风

## 适用场景

教程、方法论、经验分享、步骤清单、「我来讲清楚」类内容。

## 构图描述

2.35:1 横版。机器人 IP 位于画面左侧或中央偏左，正面朝向镜头，表情自信或推荐感，一只手或双手指向画面右侧的标题或关键信息。机器人约占画面高度 55%-70%。

画面右侧放置巨大标题，思源黑体 Heavy，白色，占据画面右侧 40%-50% 空间。标题旁边可有 1-2 个 Accent-Orange 或 Accent-Cyan 小标签，标注步骤编号或关键词。

背景为深色工程蓝，带有淡 FRF 曲线或数据网格，营造工程师讲解的氛围。可在机器人身边或标题下方加入小图标/数字步骤（1、2、3），使用 Roboto Mono 等宽字体。

## 必须包含元素

- 2.35:1 横版构图
- 机器人 IP 正面朝向镜头，做指引手势
- 标题位于画面右侧，字号巨大
- 可选步骤编号或关键词标签
- 深色工程背景 + 淡 FRF 曲线

## 提示词模板第一行

2.35:1 横版构图，公众号封面，机器人正面指引风格。
