# 风格 02：极简深蓝留白风

## 适用场景

观点类、行业观察、深度长文、需要克制高级感的封面。

## 构图描述

2.35:1 横版。大面积 Primary-900 `#001A33` 或 Primary-700 `#003A73` 纯色背景，几乎无装饰，仅保留少量若隐若现的淡蓝色坐标网格线或一条极简 FRF 曲线作为品牌符号。

标题是唯一绝对主视觉，使用思源黑体 Heavy，纯白色，占据画面左侧或中央，字号极大，字距略拉，形成强烈呼吸感。机器人 IP 小比例出镜（约占画面高度 20%-30%），位于画面右下角或左下角，不抢标题。

画面留白 ≥ 40%，信息极度克制。

## 必须包含元素

- 2.35:1 横版构图
- 大面积纯色深蓝背景
- 一条极简 FRF 曲线或淡网格作为品牌符号
- 主标题（白色思源黑体 Heavy，字号巨大）
- 机器人 IP 小比例压角或不出镜
- 无多余装饰、无渐变、无特效

## 提示词模板第一行

2.35:1 横版构图，公众号封面，极简深蓝留白风格。
