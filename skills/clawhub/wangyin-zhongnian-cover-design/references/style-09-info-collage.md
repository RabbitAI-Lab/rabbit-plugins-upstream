# 风格 09：信息拼贴风

## 适用场景

多工具盘点、多案例、信息密度较高的清单类、年终总结、资源合集类文章。

## 构图描述

2.35:1 横版。画面由多个小图、截图、图标、数据卡片、FRF 曲线片段拼贴成层次，背景为深色 Primary-900，前景和中景错落分布 3-5 个小元素。

机器人 IP 位于画面左下角或右下角，约占画面高度 30%-40%，作为「压角」品牌符号，表情推荐或思考。

标题放在画面上方，思源黑体 Heavy，白色，字号大，横跨画面。副标题或关键词用 Accent-Cyan / Accent-Orange 小标签分布在拼贴元素之间。

每个小元素之间有清晰边界，避免杂乱；整体色调统一在蓝色系，仅点缀橙色和青色。

## 必须包含元素

- 2.35:1 横版构图
- 3-5 个拼贴元素（图2 起）
- 机器人 IP 压角
- 统一蓝色系色调，仅点缀橙/青
- 标题（思源黑体 Heavy）
- 无杂乱彩虹色

## 提示词模板第一行

2.35:1 横版构图，公众号封面，信息拼贴风格。
