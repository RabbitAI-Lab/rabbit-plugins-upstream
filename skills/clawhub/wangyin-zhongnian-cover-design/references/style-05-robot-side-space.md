# 风格 05：机器人侧置留白风

## 适用场景

战略判断、行业观察、管理思考、需要稳重大气感的封面。

## 构图描述

2.35:1 横版。机器人 IP 位于画面左侧或右侧 1/3 处，约占画面高度 50%-65%，正面或 3/4 侧面朝向镜头，姿态稳重，表情克制。

另一侧大面积留白给标题。标题使用思源黑体 Heavy，纯白色或 Accent-Cyan，字号巨大，占据画面留白区域的中心或上方。标题可分两行排列，行距紧凑。

背景为纯色 Primary-900 或 Primary-700，仅在边缘或角落有极淡的 FRF 曲线装饰，不抢主体。

## 必须包含元素

- 2.35:1 横版构图
- 机器人 IP 侧置占 1/3 画面
- 另一侧大面积留白
- 巨大标题（思源黑体 Heavy）
- 深色纯色背景 + 极淡品牌符号

## 提示词模板第一行

2.35:1 横版构图，公众号封面，机器人侧置留白风格。
