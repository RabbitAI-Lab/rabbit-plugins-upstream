# 风格 03：数据仪表盘风

## 适用场景

工具教程、软件测评、数据解读、AI 产品界面分析、工程软件实操类文章。

## 构图描述

2.35:1 横版。背景为深色数据界面或仪表盘质感，主色 Primary-900 / Primary-700，辅以青色网格线和数据图表。画面中央或右侧放置 UI 截图、软件界面、数据可视化图表，占据画面 40%-60% 面积。

机器人 IP 位于画面左侧或右下角，做指引手势：手指向屏幕、手持平板展示界面、或站在屏幕旁边。机器人约占画面高度 40%-55%，作为「讲解员」存在。

标题放在画面上方或左侧，思源黑体 Heavy，白色，字号大但不超过主视觉截图。关键数据或关键词可用 Accent-Cyan 或 Accent-Orange 小标签突出。

数字字体使用 Roboto Mono，等宽，清晰可读。

## 必须包含元素

- 2.35:1 横版构图
- 深色数据仪表盘背景
- UI 截图/软件界面/数据图表作为主体（图2 起）
- 机器人 IP 做指引或讲解姿态
- 思源黑体 Heavy 标题 + Roboto Mono 数据
- 无蓝紫渐变、无粉彩

## 提示词模板第一行

2.35:1 横版构图，公众号封面，深色数据仪表盘风格。
