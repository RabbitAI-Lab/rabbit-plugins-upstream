## 示例 1：深色工程图纸风

**标题**：AI 会抢走工程师吗  
**风格**：01 深色工程图纸风  
**表情**：思考  
**场景**：观点类长文，讨论 AI 对工程师岗位的影响

```
2.35:1 横版构图，公众号封面，深色工程图纸风格。
参考图1：一个圆润的蓝色机器人工程师，戴蓝色工程安全帽，两侧有耳机，胸口有橙色圆形仪表徽章，眼屏发出青色光，保持该形象一致。
背景为 Primary-900 #001A33 深海蓝，铺满淡蓝色坐标网格和发光的青色 NVH 频率响应曲线（FRF 波形），曲线有清晰的峰值标记点和共振点，像高精度工程测试报告界面。
机器人位于画面中央偏右，正面朝向镜头，单手托下巴，眼屏呈现思考神态，头顶上方浮现半透明 FRF 波形曲线。
画面左侧大标题使用思源黑体 Heavy，纯白色，文字为「AI 会抢走工程师吗」，占画面上半部分，字号巨大，字距略拉，行距紧凑，无衬线，无描边。
标题下方用 Accent-Cyan #00C8FF 等宽数字字体 Roboto Mono 小字标注「12 年 NVH 工程师 · 300+ 检测报告」。
画面整体冷色调，工程图纸质感，克制，有深度，无蓝紫渐变，无粉彩色，无卡通元素，无彩虹光效。
```

## 使用说明

生成新提示词时，从本文件选取最接近目标风格的示例，参照其：
- 第一句固定格式
- 图1 描述方式（保持机器人 IP 一致性）
- 标题字体和颜色处理
- 背景与品牌符号（FRF 曲线）的结合方式
- 避免出现的禁用元素描述

不要直接复制示例，而是根据用户文章内容和第三轮选择填空改写。
