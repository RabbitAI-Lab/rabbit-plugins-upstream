# 风格 07：局部道具风

## 适用场景

工具测评、产品开箱、功能拆解、小配件/小工具介绍，产品是绝对主角。

## 构图描述

2.35:1 横版。画面主体是产品、工具、UI 截图或数据卡片，占据画面 50%-70%，清晰锐利。机器人 IP 只露出手、半身或头部局部，作为「展示者」存在：手托产品、手指向屏幕、手持平板等。

背景为深色工程蓝（Primary-900 / Primary-700），有淡网格或 FRF 曲线做底纹。产品周围可有少量 Accent-Cyan 或 Accent-Orange 高亮线条框出重点区域。

标题放在画面上方或产品旁边，思源黑体 Heavy，白色。关键词可用 Accent-Orange 矩形标签突出。

## 必须包含元素

- 2.35:1 横版构图
- 产品/工具/截图作为主体（图2 起）
- 机器人 IP 局部出镜（手、半身、头部）
- 深色工程背景 + 淡 FRF 网格
- 思源黑体 Heavy 标题 + 可选关键词标签
