# 网瘾中年 品牌视觉硬约束速查

本文件供 skill 生成提示词时调用。所有封面提示词必须遵守以下约束，否则视为违规输出。

## 色彩

| 用途 | 色名 | HEX | 使用比例 | 说明 |
|------|------|-----|----------|------|
| 深色背景 | Primary-900 | `#001A33` | 大面积 | 沉浸式封面底色 |
| 次级背景 | Primary-700 | `#003A73` | 大面积 | 常用封面底色 |
| 品牌主色 | Primary-500 | `#005BAC` | 中面积 | 按钮、重点色块、图表主线 |
| 辅助蓝 | Primary-300 | `#4A90D9` | 小面积 | 次要数据线、悬停态 |
| 浅蓝背景 | Primary-100 | `#CCE5FF` | 小面积 | 标签、信息框 |
| CTA/高亮 | Accent-Orange | `#F56C2D` | ≤10% | 重要标注、数据高亮、关键词标签 |
| 科技点缀 | Accent-Cyan | `#00C8FF` | ≤8% | FRF 曲线高亮、线条强调 |
| 深色文字 | Neutral-900 | `#1C1C2E` | 浅色背景用 | 正文/标题 |
| 浅色文字 | White | `#FFFFFF` | 深色背景用 | 标题、正文 |

**禁用色**：蓝紫渐变（#8B5CF6 等）、粉彩暖粉、彩虹多色渐变、高饱和暖黄/金色（#FFD700 等）、纯黑大面积 `#000000`。

## 字体

- 中文标题：**思源黑体 Heavy / Source Han Sans CN Heavy**（首选）或 **HarmonyOS Sans SC Heavy**（鸿蒙场景）
- 英文/数字：**Roboto Regular** / **Roboto Mono**（代码、数据、频率参数）
- 正文备选：PingFang SC / Microsoft YaHei（仅系统渲染场景，非设计稿）

**禁用字体**：宋体、楷体、仿宋、华文行楷、毛笔书法字、Comic Sans、Papyrus、任何衬线体，以及未授权商业字体。

## 品牌核心符号

**NVH 频率响应曲线（FRF）**：
- 坐标网格 + 精确刻度
- 连续波形曲线，有峰值和共振点
- 深蓝底色 + 发光青色曲线（Accent-Cyan `#00C8FF`）
- 可用作背景底纹、装饰区、主视觉元素

## IP 形象规范

机器人 IP 必备特征：
- **身形（最高优先级，不可违背）**：圆润、矮胖、Q 版比例——头大（占身高约 1/3）、圆鼓肚子、短手短腿、重心低、憨厚稳重，像不倒翁。**严禁修长、瘦高、纤细四肢、人形成人比例。** 实测：提示词不显式写这条时，文生图模型会擅自生成瘦高机器人，与 IP 参考图差距极大，必须重生成
- 圆润蓝色机身（Primary-700 `#003A73` 附近哑光金属蓝）
- 蓝色工程安全帽（带一条橙色 Accent-Orange 装饰线）
- 两侧耳机
- 胸口橙色圆形仪表徽章（内部有白色指针/刻度）
- 眼屏发出青色光（Accent-Cyan `#00C8FF`）
- 整体造型偏工程、稳重、可信赖，不萌化、不卡通夸张

**禁止**：改变 IP 主色、拉伸旋转、添加额外发光/阴影/描边、与其他品牌 Logo 并列等大、生成瘦高身形。

## 公众号封面比例

- **比例**：2.35:1 横版（公众号首图裁切安全区）
- **推荐尺寸**：900 × 383 px（安全区）/ 900 × 500 px（首图展示）
- **安全边距**：关键元素（标题、IP 主体）距左右边缘 ≥ 10% 画面宽度，避免信息流裁切

## 风格禁忌

| 禁止 | 原因 |
|------|------|
| 蓝紫/粉紫渐变 | 消费娱乐调性，与理性工程感冲突 |
| 衬线体/书法字体 | 传统文化/小资情调，与工程科技调性冲突 |
| 粉彩色系 | 与目标受众（理工男性为主）视觉预期错位 |
| 卡通萌化/Q 版 | 消解工程师专业背书 |
| 过度美颜/暖调摄影 | 与品牌冷色调、理性气质冲突 |
| 无来源网络 Logo/截图 | 版权风险与质量参差 |
| 彩虹多色渐变 | 破坏品牌克制感 |
| 高饱和暖黄/金色 | 成功学/营销号气息 |

## 构图原则

- 信息密度克制：公众号封面在小屏呈现，文字不宜超过 1 主标题 + 1 副标题/关键词标签
- 主视觉锚定：IP 形象或 FRF 曲线必须至少出现一个，保持品牌识别
- 对比度：深色背景上文字用 White；浅色背景上文字用 Neutral-900
- 层次感：前景（IP/标题）→ 中景（关键数据/截图）→ 背景（FRF 网格/工业场景）
