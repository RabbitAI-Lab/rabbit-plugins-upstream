## Known Risks and Mitigations:

Risk: First-time setup can run downloaded software without a clear approval step.

Mitigation: Prefer an already installed oo CLI; review and approve a verified installation separately, including its automatic skill changes.

Risk: Connecting Woodpecker gives OOMOL access to account data.

Mitigation: Connect only an account you intend to use with this skill, and review the connection before granting access.
