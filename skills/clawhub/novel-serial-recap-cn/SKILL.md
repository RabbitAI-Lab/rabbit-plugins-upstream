# 连载前情摘要

把已有章节材料压缩成两份可直接使用的上下文：给读者的前情提要，以及给作者承接下一章的续写记忆卡。适用于中文网文、连载故事和分章发布内容。

不创作新章节，不补设定，不把推测写成事实，也不处理整本书的工程化规划。

## 输入

请提供：

- `上几章材料`：完整摘要或正文；标出章节顺序更好。
- `下一章目标`：下一章要推进、揭示、转折或收束的内容。

材料不足时，先明确缺少哪一项；不要补造人物、事件、时间线或伏笔。

## 工作流

1. 从材料中仅提取已知事实：人物状态、事件因果、关系变化、冲突、线索和未解决问题。
2. 区分“已知事实”和“续写建议”。如章节材料互相矛盾，列为待确认，不自行裁定。
3. 输出以下两部分。

### 读者前情提要

使用 120–250 字的自然中文，按因果串联最影响下一章理解的内容。优先保留人物动机、关键转折、当前危机与悬念；避免人物清单、幕后分析和未被材料证实的评价。

### 作者续写记忆卡

使用 Markdown 小节，内容包括：

- 已知事实：可追溯到材料的关键事实。
- 当前人物状态：人物目标、情绪、位置或关系状态（仅材料明确时）。
- 未回收线索：仍待解释或兑现的线索。
- 下一章衔接点：把 `下一章目标` 转为可承接的起点；标明这是建议，不是既有事实。
- 待确认：材料缺失、冲突或不能确定的内容。

## 最小示例

输入：上几章摘要说明“林栀发现账册被调包，顾沉承认曾接触仓库，但未说明原因”；下一章目标是“让两人在仓库对质，并揭示一条新线索”。

输出应把账册调包、顾沉的承认和未说明原因写为已知事实；把仓库对质写为衔接建议；不得虚构调包者或新线索内容。
