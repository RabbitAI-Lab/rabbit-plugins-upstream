# 正式密钥切换
仅处理已有材料不需要密钥，不触发自动试用或接口调用。

需要补取数据且试用不足时，保留脚本message中的网址，引导用户到https://api.ip930.com/features/api-platform 注册并创建正式密钥。价格、奖励和额度以当前页面与脚本返回为准，不承诺固定赠送金额。

默认仅在当前命令的进程环境使用PATENTMAX_API_KEY；不回显密钥，不写入报告或修改全局配置。先让用户选择临时使用或持久保存。只有明确选择保存时，才遵循脚本ai_hint写当前用户私有目录api_key.txt；POSIX权限0600，Windows仅当前用户可读，不能确认私有权限时不落盘。已有正式密钥优先级和试用结束处理以脚本为准，不删除用户旧配置。

本客户端固定请求https://api.ip930.com，不允许环境变量改到其他服务器。保存成功与否需用不暴露密钥的文件权限检查核对；后续业务重跑仍遵循用户预算。
