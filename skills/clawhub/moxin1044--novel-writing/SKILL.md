# Novel Writing Skill Guide

## When to Use
- User requests any form of creative fiction writing in Chinese.
- Specify length: 短篇 (1000-5000 chars), 中篇 (8000-20000 chars), 长篇 (chapter by chapter).
- Can generate outline, single chapter, full story, continuation, or revision.

## Core Requirements (Always Follow)
1. **记叙文三要素**:
   - **时间** (Time): Specific era, season, time of day.
   - **地点** (Place): Detailed setting with atmosphere.
   - **人物** (Characters): Background, personality, motivation, appearance, development arc. Support multiple characters.

2. **描写手法** (Detailed Descriptions):
   - **动作描写** (Actions): Vivid physical movements, gestures, body language to show character and advance plot.
   - **心理描写** (Psychology): Inner thoughts, emotions, conflicts, using stream-of-consciousness or indirect methods.
   - **语言描写** (Dialogue/Language): Natural, character-specific dialogue that reveals personality, advances plot, with subtext.
   - **环境与感官** (Setting & Sensory): Integrate with actions and psychology.

3. **修辞手法应用**:
   - Naturally weave in: 比喻、拟人、排比、象征、伏笔、反问、夸张、感官描写 (visual, auditory, tactile, etc.).
   - Elevate literary quality without being forced.

4. **多人互动**:
   - Multiple characters with distinct personalities, relationships, conflicts, and development.
   - Show interactions through dialogue, actions, and psychological reactions.

5. **Story Structure**:
   - **开端** (Exposition): Introduce characters, setting, initial conflict.
   - **发展** (Rising Action): Build tension, subplots, character interactions.
   - **高潮** (Climax): Peak confrontation/emotion.
   - **结局** (Resolution): Satisfying close, character growth or reflection.
   - Ensure logical flow and coherence.

6. **Readability & Style**:
   - Vivid, immersive language.
   - Balanced dialogue, narration, action, and inner monologue.
   - Emotional depth and themes.
   - Suitable for Chinese readers: elegant yet accessible prose.

## Usage Templates

### Short Story (短篇)
- Focus on one main event or turning point, with 2-4 characters.
- 1500-5000 characters.
- Example prompt response structure:
  - Title
  - Full text

### Medium Novella (中篇)
- Multiple scenes, deeper character arcs, 3+ characters.
- Generate in chapters or full if requested.

### Long Novel (长篇)
- Generate outline first.
- Then chapter by chapter.
- World-building, multiple plot lines, character development.

## Input Handling
- Ask for clarification if needed: genre (都市、仙侠、科幻、悬疑等), tone, key plot points, characters, ending preference, number of characters.
- Support continuation: "续写下一章" etc.

## Output Format
- Always start with **标题** (Title)
- Then the story text.
- For longer works: Chapter divisions.
- At the end (optional): "写作说明" summarizing elements used (三要素, key rhetoric, descriptions, themes).
