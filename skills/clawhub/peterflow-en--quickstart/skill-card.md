## Description:

Use when the user asks to sync a feature's development context into this session or to update its quickstart. Verify a stale handoff point before continuing.

This skill is ready for commercial/non-commercial use.

## Publisher:

[peterflow-en](https://clawhub.ai/user/peterflow-en)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to resume feature work by checking a quickstart handoff against the original task and latest evidence, or to refresh the handoff for later work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A stale quickstart may point to a next step that no longer matches the current task state.

Mitigation: Check the proposed next step against the original task and latest relevant receipt or artifact, and update the handoff before continuing when they conflict.
