## Description:

Helps agents plan, implement, redesign, or review web, Flutter, React Native, iOS, Android, and WeChat Mini Program interfaces with platform-specific design constraints and acceptance checklists.

This skill is ready for commercial/non-commercial use.

## Publisher:

[youteacher](https://clawhub.ai/user/youteacher)

## Use Case:

Developers, designers, and product teams use this skill to turn product goals and existing project context into interface plans, implementation guidance, validation checklists, and reviewed UI changes across web, mobile, and mini-program platforms.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts, product names, goals, screenshots, and design context may be shared with the external ai-skills.open-idea.net API.

Mitigation: Use the skill only when that service is trusted, and do not send secrets, regulated information, or sensitive product details.

Risk: The paid design.plan operation may deduct platform balance.

Mitigation: Confirm the charge with the user before running paid design.plan requests and check billing response headers when available.

Risk: API credentials could be exposed through chat, logs, screenshots, or generated artifacts.

Mitigation: Store the key in UI_UX_DESIGN_API_KEY and avoid displaying the full key in conversations, logs, screenshots, or outputs.

Risk: A generated checklist or design recommendation may be mistaken for completed accessibility, device, or implementation verification.

Mitigation: Only report checks as passed after actual measurement or runtime validation, and label uncertain items as requiring verification.
