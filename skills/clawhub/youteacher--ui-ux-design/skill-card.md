## Description:

Helps users plan, implement, revise, or review UI/UX for web, Flutter, React Native, iOS, Android, and mini-program interfaces with platform-specific design constraints and acceptance checklists.

This skill is ready for commercial/non-commercial use.

## Publisher:

[youteacher](https://clawhub.ai/user/youteacher)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, designers, and product teams use this skill to turn product goals into actionable interface plans, acceptance criteria, and implementation guidance across web, mobile, and mini-program platforms. It can also review supplied projects, screenshots, component libraries, or brand rules before recommending changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can send product plans, screenshots, project details, or other user-provided context to the AI Skills platform endpoint.

Mitigation: Confirm the endpoint is trusted and that users are authorized to send any confidential, personal, or proprietary information before submitting requests.

Risk: The skill requires an API key for authenticated requests.

Mitigation: Store UI_UX_DESIGN_API_KEY securely and avoid exposing it in logs, screenshots, commits, chat, or generated artifacts.

Risk: The design.plan operation may charge the user's AI Skills platform balance.

Mitigation: Tell the user before running paid operations and review billing response headers when available.
