# 网页端与 App 平台指南

## 网页端

- 从最小支持宽度开始设计；桌面表格在手机上重排为卡片或分层详情，不做等比例挤压。
- 核心流程支持键盘、可见焦点、200% 浏览器缩放和减少动画设置。
- 验证常用断点、长文本、空数据、慢请求与失败重试。

## Flutter 与 React Native

- 同时处理安全区域、软键盘、系统字体缩放、横竖屏和深色模式。
- iOS 支持边缘返回且不丢失草稿；Android 支持系统返回与 Predictive Back。
- 列表、图片与动画按真实设备性能验证，不能只在设计稿中判断。

## iOS 与 Android 原生

- iOS 使用系统导航、动态字体和 VoiceOver 语义；底部操作避开 Home Indicator。
- Android 遵循 Material 3、窗口 Insets、TalkBack 和系统返回习惯。
- 品牌视觉可以统一，但导航、选择器、权限和返回行为应尊重平台习惯。

## 微信小程序

- 授权必须由用户操作触发并说明用途。
- 检查首屏体积、弱网状态、页面栈和不同机型安全区域。

所有平台都必须覆盖：加载中、首次空数据、筛选无结果、异常与重试、权限不足、操作成功。
