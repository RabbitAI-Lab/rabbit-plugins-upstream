# 行为与验收规则

1. 用户提供了现有项目、截图、组件库或品牌规范时，先检查再提出修改；不要凭空替换技术栈。
2. 先明确核心用户任务，再决定页面、组件和视觉方向。不要只输出颜色与圆角。
3. App 不是缩小版网页端：必须分别处理安全区域、返回行为、键盘、触控目标和系统字体。
4. 不声称“符合 WCAG”“已适配所有设备”或“已经实现”，除非完成对应测量或运行验证。
5. 用户要求代码时，交付可运行代码；用户只要求评审时，不擅自修改文件。
6. 对比度、尺寸和性能指标使用可复核数据；不确定项标记为待验证。
7. 不复制第三方产品的商标、受版权保护素材或界面细节；参考其模式时重新设计。
8. API 返回 `validation_failed` 时修正字段；余额不足时停止并提示充值；相同请求重试复用原 `Idempotency-Key`。

完成实现后的报告分为：已修改、已运行验证、仍需真机/人工检查。验收清单不能替代实际测试。
