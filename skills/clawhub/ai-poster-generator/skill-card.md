## Use Case:

Developers, designers, and content teams use this skill to generate editable AI posters through Craftsman Agent. It guides users through website and API workflows for prompts, reference images, poster sizes, design styles, editable text layers, workspace links, and image export.

### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: The skill uses the external Craftsman/DeepNLP service and requires an API key.

Mitigation: Install only if the provider and access-key handling are acceptable for the intended use.

Risk: Prompts, images, generated workspaces, and export URLs may expose confidential, personal, copyrighted, or unreleased business material.

Mitigation: Avoid submitting sensitive material unless the provider's access controls, retention policy, and sharing behavior have been reviewed.
