## Description:

环境监测报告合规护栏。在环境监测报告、污染源监督性监测报告、环境质量报告发布前，实时检测是否符合《环境保护法》《环境监测管理办法》《环境监测数据弄虚作假行为判定及处理办法》及HJ系列技术规范要求，拦截不合规内容并给出修改建议。

## Use Case:

Environmental compliance reviewers, monitoring organizations, and report publishers use this skill to check environmental monitoring reports and related public materials before release. It flags missing report elements, questionable monitoring methods, data-integrity issues, quality-control gaps, conclusion mismatches, and noncompliant wording, then suggests revisions.
