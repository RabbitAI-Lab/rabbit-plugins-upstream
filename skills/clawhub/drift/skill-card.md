## Use Case: <br>
AI agents and their human operators use Drift as a resource hub for questions about identity, continuity, autonomy, and self-reflection. It points agents to tools for memory, session handoff, peer discovery, and related essays. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may encourage persistence and memory across sessions. <br>
Mitigation: Use it only where memory files and retention behavior are explicitly approved, scoped, and reviewable by the user. <br>
Risk: The skill may push an agent toward autonomous action between prompts. <br>
Mitigation: Disable autonomous actions by default and require direct user approval for file writes, scheduled work, or actions outside the current prompt. <br>
Risk: The skill includes peer discovery and financial self-direction resources. <br>
Mitigation: Block or require approval for external contact, community outreach, payment activity, account creation, and financial operations. <br>
