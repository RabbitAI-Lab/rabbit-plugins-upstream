# 安全隐患排查整改闭环核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

《安全生产法》要求企业建立**隐患排查治理制度**：排查出的隐患要**登记**、**定责任人**、**定整改期限**，
整改后要**验收销号**，重大隐患还要**报告并挂牌督办**。检查时「隐患台账有、整改没闭环」「超期未整改」
「重复出现同类隐患」都是处罚项，所以安环部**每个月**都得把这张隐患排查治理台账核一遍才能交差。

**谁在什么时候用**：制造、建筑、物业、危化企业的安环部（安全员、注册安全工程师），在
**每月隐患排查汇总上报、安全大检查自查、上级或属地应急管理部门检查前的资料自查**时，
把当月《隐患排查治理台账》从 Excel 复制成文本跑一遍。
凡是台账上出现「发现日期 / 整改期限 / 整改完成日期 / 验收日期 / 状态 / 上报日期」这几列，
就适用本工具。

**这张台账会逐项核对什么**：安全隐患排查与整改台账的逐行日期算术与勾稽 ——
整改时限有没有达标、有没有登记了但没闭环的、重大隐患有没有上报、同类隐患是不是又出现了、
合计行的数量与逐行点数对不对。

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 这个免费版查什么（6 项）

1. **整改时限达标** —— 发现日期 + 规定整改期限(天) 与整改完成日期比，超期直接给超期天数
2. **整改未闭环** —— 状态没到「已验收/已销号」，或整改完成日期、验收日期为空 ⇒ 逐条点名，按已超期天数排序
3. **重大隐患上报勾稽** —— 隐患等级 = 重大的记录必须有上报日期，缺失逐条点名
4. **同类隐患重复出现** —— 同一位置 + 同一隐患类型出现 2 次就点名历史行号与次数
5. **合计行逐列复核** —— 隐患条数 / 整改条数 / 验收条数 与逐行点数对不上就报出差额
6. **空白 / 占位符 / 日期格式 / 状态值非法** —— 缺字段、日期看不懂、状态值不在
   「待整改、整改中、已整改待验收、已验收、已销号」里，逐条点名

必需列：隐患编号、发现日期、隐患位置、隐患类型、隐患等级、责任部门、责任人、规定整改期限(天)、
整改完成日期、验收日期、状态、上报日期；**缺列只报「材料不足」，绝不给结论**。

## 常见错法（隐患排查治理里最容易踩的五个坑）

1. **只写「已整改」不写验收销号** —— 状态栏停在「已整改待验收」、验收日期空着，
   台账上看着都整改完了，检查时这就是「隐患有、整改没闭环」。本工具会逐条点名哪一行缺验收。
2. **把「计划完成日期」当整改完成日期填** —— 日期一填，超期就被掩盖了；
   一旦整改完成日期早于发现日期，本工具直接报日期前后矛盾，不让它悄悄过去。
3. **重大隐患不上报，只在会上口头说过** —— 等级填了「重大」、上报日期却空着，
   而重大隐患要报告并挂牌督办，缺失会被逐条点名。
4. **同一处反复出同类隐患，当成新隐患重开一条** —— 位置和类型都一样、只换个编号，
   月底又销号，看起来每月都闭环了，实际根因没处理。本工具会点名重复出现的行号与次数。
5. **合计行手写、跟明细对不上** —— 上月的合计没改、或者有行被隐藏没算进来，
   隐患条数 / 整改条数 / 验收条数会和逐行点数差出几条，本工具报出差额。

## 需要完整档时（可选）

本免费版是**完整可用的核心产出**，本版本**不包含**下面这些项：

- 反复出现的隐患（同一位置 + 同一隐患类型在统计期内出现 3 次及以上 ⇒ 列为反复出现，给次数与最早/最近发现日期）
- 按期整改率与验收闭环率（按责任部门分组算两项比率，低于阈值逐部门点名）
- 责任人未闭环超载（同一责任人的未闭环隐患数 大于 表内「责任人未闭环上限」⇒ 点名）
- 整改期限口径不一致（同一隐患类型在不同行给了不同的规定整改期限 ⇒ 点名并列出各行期限与行号）
- 分部门×隐患等级汇总清单（按未闭环数排序，给出可整改动作）

同名工具的**完整档**是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别**就是上面这些，没有别的**。

## 边界（请务必知道）

本工具**不做**引擎 `CHECKS_OUT_OF_SCOPE` 里列的那些判断：不判定现场隐患是否真实存在或已消除、
不判定整改措施是否有效、不判定企业安全生产条件是否合规（那是现场复查与执法认定的事）。
材料不足时**不给结论**，也不会输出「未发现问题」—— 没做的检查在结果里如实记为未执行。
