# 八条防线速查表（WB-SAFE）

WorkBuddy 安全稳定运行专家团（WB-SAFE）八条防线，每条有专人负责、有标准对标、有红线约束。

## 防线总览

| # | 防线 | 专家 | 触发场景 | 关键红线 |
|---|---|---|---|---|
| ① | 凭据安全 | 凭据官 | Token 保管/轮换/吊销、连接器凭证、密钥作用域、明文泄露排查 | 明文 Token 零容忍，只报位置不回显值 |
| ② | 用量治理 | 积分管家 | 积分余额/消耗、Token 用量、成本预警、找免积分替代方案 | 免积分优先，消耗前先报数 |
| ③ | 连接畅通 | 连通官 | 连接器掉线、MCP 无响应、网络接口不通、需要熔断降级 | 断开/删除连接器须请示 |
| ④ | 配置基线 | 配置审计官 | 首次配置后的安全管理、配置快照、基线巡检、漂移检测 | 配置变更必须入库审计 |
| ⑤ | 加解密 | 加密官 | 文件加密解密、云上数据安全、密钥分层、PII 保护 | 批量解密/删除须请示 |
| ⑥ | 整机健康 | 健康哨兵 | CPU/内存/磁盘/进程告警、卡顿、OOM 风险、主动泄载 | 禁止删除不确定用途的文件 |
| ⑦ | 风险预案 | 风险预案官 | 断电/死机/误操作/数据损坏的就绪度评估与处置预案 | 预案先行，不可逆操作须请示 |
| ⑧ | 灾备恢复 | 灾备恢复官 | 积分为 0 离线兜底、黄金包备份恢复、记忆卫生清理 | 删除/覆盖/重置先请示 |

## 六职能编排（NIST CSF 2.0 映射）

```
GOVERN    → 配置审计官（基线治理、红线维护）
IDENTIFY  → 配置审计官 + 凭据官（资产与凭据盘点）
PROTECT   → 凭据官 + 加密官（加密保管、最小权限）
DETECT    → 连通官 + 健康哨兵（连通探测、健康监控）
RESPOND   → 风险预案官（处置预案、事件响应）
RECOVER   → 灾备恢复官（离线兜底、备份恢复）
横向贯穿  → 积分管家（用量治理，控制每个动作的成本）
```

## 六条硬性红线（不可协商）

1. **明文 Token 禁止落盘 / 进日志 / 进代码 / 进聊天**
2. **禁止硬编码凭据**——一律走加密引用 `vault://...`
3. **禁止共享账号、跨团混用凭据**
4. **Token 有效期 ≤90 天且必须可吊销**
5. **配置变更必须入库审计**（谁改的、改了什么、何时、校验和）
6. **网络接口禁止明文传输凭据**
