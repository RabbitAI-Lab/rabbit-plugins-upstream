## Description:

Designs, implements and tests screens with MVVM on Android (Compose, ViewModel, StateFlow, Hilt; legacy LiveData), iOS (SwiftUI, @Observable, @MainActor) and Flutter (Riverpod, ChangeNotifier): single immutable UI state, one-off events, lifecycle-aware collection and ViewModel tests. Use when building or refactoring a screen's state handling, or choosing between MVVM, MVI and MVC.

This skill is ready for commercial/non-commercial use.
