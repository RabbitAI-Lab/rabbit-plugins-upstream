## Use Case: <br>
Developers, product planners, and planning agents use this skill to turn roadmap, architecture, and Azure DevOps backlog work into durable handoff artifacts before implementation. It helps preserve scope, rationale, assumptions, risks, acceptance criteria, and routing boundaries for later implementers. <br>
