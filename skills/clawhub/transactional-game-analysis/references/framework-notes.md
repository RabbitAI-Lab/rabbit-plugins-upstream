# Framework Notes

Distilled from a local copy of Eric Berne's Games People Play for use as brief operational guidance, not as a reproduction of the book.

## Minimal Theory

Transactional analysis treats social exchange as sequences of transactions: one person's stimulus and another person's response. Each move can be read as coming from or targeting Parent, Adult, or Child ego states. Adult-to-Adult exchanges tend to handle reality, facts, choices, and explicit agreements. Parent and Child exchanges can be caring, playful, rebellious, compliant, punitive, rescuing, or shaming depending on the context.

Transactions can be complementary, crossed, or ulterior. Complementary transactions fit the invitation and can continue. Crossed transactions interrupt the expected channel and often produce conflict or silence. Ulterior transactions run on two levels at once: an overt social level and a covert psychological level. Berne treats repeated ulterior transactions that end in predictable payoffs as games.

A game is not merely conflict, a personality flaw, or ordinary play. It is a recurring patterned sequence with plausible moves, a hidden angle, and a payoff. The payoff may be painful but familiar: attention, vindication, excuse, superiority, avoidance, control, proof of an old belief, or protection from direct intimacy.

Antithesis means refusing the game invitation or undercutting the payoff. It should be tested carefully: when a game is important to someone's stability, changing the pattern can intensify the person's attempts to continue it or produce distress. In everyday advice, antithesis should therefore be practical, respectful, and scaled to safety.

The positive exit direction is autonomy: awareness, spontaneity, and intimacy. In applied conversation analysis, translate that as seeing what is happening now, choosing a different response, and speaking more candidly without trying to win the game.

## Formal Analysis Fields

Use these fields when a game hypothesis is plausible:

- Name or descriptive label
- Roles/players
- Aim
- Dynamics or driver, stated cautiously
- Childhood/script origin only if provided by user; do not invent it
- Social-level transaction
- Psychological-level transaction
- Moves
- Payoff or advantages
- Degree/intensity
- Antithesis
- Confidence and falsifying evidence

## Practical Exit Moves

Useful antithesis families:

- Shift to Adult-to-Adult: ask for facts, decisions, requests, options, or agreements.
- Name the process lightly: "We seem to be moving from solving this to proving who caused it."
- Refuse rescue: "I can listen, but I don't want to keep offering ideas if the goal is to show none can work."
- Refuse persecution: "I'll discuss the specific issue, but not insults or global accusations."
- Refuse victim fixation: "That sounds hard. What choice is still available?"
- Return agency: "What would you like to do next?"
- Slow the tempo: pause, summarize, ask whether to continue later.
- Set repair terms: for repeated harm, require changed behavior, restitution, or distance.
- Exit safely: if unsafe or coercive, end the interaction and seek support rather than analyze further.
