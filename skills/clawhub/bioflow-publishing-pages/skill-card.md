## Description:

Publishes or schedules a BioFlow page draft after previewing the changes and obtaining explicit user confirmation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[devino](https://clawhub.ai/user/devino)

### License/Terms of Use:

MIT-0

## Use Case:

BioFlow page owners use this skill to review draft changes and publish or schedule their page to go live with their explicit approval.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Draft page changes may become publicly visible before the owner intends.

Mitigation: Review the preview and publish only after the user explicitly confirms the proposed changes.

Risk: A scheduled page update may go live at the wrong time.

Mitigation: Confirm the full scheduled date, time, and timezone with the user before scheduling.
