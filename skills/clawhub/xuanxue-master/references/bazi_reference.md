## 二、十神体系

十神以日干（日主）为基准，根据其他天干地支藏干与日干的五行生克关系确定。

### 十神含义

| 十神 | 关系 | 含义 |
|------|------|------|
| 比肩 | 同我（同五行同阴阳） | 兄弟朋友、竞争者、独立自主、刚健 |
| 劫财 | 同我（同五行异阴阳） | 争夺、破财、合作、社交、慷慨 |
| 食神 | 我生（同阴阳） | 才华、口福、子女（女命）、福寿、温和 |
| 伤官 | 我生（异阴阳） | 才艺、叛逆、口舌、子息（女命）、聪明 |
| 偏财 | 我克（异阴阳） | 偏门财、横财、父亲（男命）、情人、慷慨 |
| 正财 | 我克（同阴阳） | 正当收入、妻子（男命）、节俭、务实 |
| 偏官(七杀) | 克我（异阴阳） | 权力、压力、魄力、丈夫（女命偏夫）、风险 |
| 正官 | 克我（同阴阳） | 名望、地位、丈夫（女命）、守法、责任感 |
| 偏印(枭神) | 生我（异阴阳） | 偏门学问、孤独、继母、怪异、直觉 |
| 正印 | 生我（同阴阳） | 学业、母亲、庇护、仁慈、文书 |

### 十神喜忌判断
- **身旺**（日主强）：喜财、官、食伤；忌印、比劫
- **身弱**（日主弱）：喜印、比劫；忌财、官、食伤
- **身旺财旺**：富贵之命
- **身弱财旺**：富屋贫人，有财难守
- **身旺官旺**：贵显之命
- **身弱官旺**：压力重重，易受压制

## 三、五行生克

### 相生
木生火 → 火生土 → 土生金 → 金生水 → 水生木

### 相克
木克土 → 土克水 → 水克火 → 火克金 → 金克木

### 五行强弱判断
统计四柱天干地支藏干的五行数量，计算各五行占比：
- 占比 > 30%：该五行偏旺
- 占比 < 10%：该五行偏弱
- 日主五行占比决定身旺身弱

## 五、大运流年

### 大运
- 起运：阳男阴女顺排，阴男阳女逆排
- 起运年龄：出生日到最近节气的天数 ÷ 3（3天=1年，1天=4个月，1时辰=10天）
- 每步大运管10年
- 大运与日主的关系决定该十年运势基调

### 流年
- 每年一干支，管一年运势
- 流年与命局、大运的互动关系决定当年吉凶
- 重点看流年天干地支与日主的十神关系

### 大运流年断法
1. 大运为环境，流年为引动
2. 大运好+流年好=大吉
3. 大运好+流年差=小有不顺
4. 大运差+流年好=暂得喘息
5. 大运差+流年差=大凶
6. 注意冲合刑害：流年冲命局=变动，合命局=好事来

## 七、合婚

### 合婚要点
1. **生肖配对**：六合（子丑、寅亥、卯戌、辰酉、巳申、午未）为吉；三合（申子辰、寅午戌、巳酉丑、亥卯未）为吉；六冲（子午、丑未、寅申、卯酉、辰戌、巳亥）为忌
2. **五行互补**：一方所喜之五行恰为另一方所旺之五行，互补为佳
3. **日柱关系**：日干相生相合为吉，相克为忌；日支相合为吉，相冲为忌
4. **大运同步**：双方大运走势是否同步，同步则共同进退

### 合婚评分参考
- 生肖配对：20分
- 五行互补：30分
- 日柱关系：30分
- 大运同步：20分
- 80分以上：大吉；60-80：中吉；40-60：一般；40以下：需谨慎
