# 取名命名参考库

姓名学综合八字五行、五格数理、三才配置、音韵字义等要素，为新生儿或改名提供参考。本文档提供取名命名的完整规则体系。

## 一、取名基本原则

### 八字补益（最优先）
1. 排出新生儿八字，分析五行旺衰
2. 确定喜用神（命局所需五行）
3. 名字用字五行以喜用神为主
4. 忌用忌神五行（过旺/无用之五行）

### 数理吉祥
选用笔画数理吉利的字组合，避免凶数

### 音韵和谐
- 读音响亮、顺口、悦耳
- 避免谐音不雅（如"史珍香""范统"）
- 声调平仄搭配有节奏

### 字义美好
- 寓意积极向上、吉祥美好
- 与姓氏搭配语义通顺
- 避免生僻字、多音字

## 二、五行判断用字

### 常见五行偏旁
- **木**：木、艹、禾、林、竹、松、梅
- **火**：火、日、灬、光、炎、明
- **土**：土、山、田、石、垚、坤
- **金**：金、钅、刂、西、玉、剑
- **水**：氵、水、雨、冫、江、海

### 用字五行参考（常用字）
- 木：梓、桐、楠、楷、林、森、荣、彤
- 火：煜、烨、炜、昕、晴、昱、晨、晟
- 土：坤、垚、培、城、宇、安、允、坦
- 金：铭、锐、锋、锦、钧、鑫、铮、瑞
- 水：涵、泽、润、洁、澜、清、沐、泓

## 三、五格数理

### 五格计算
1. **天格**：姓氏笔画+1（单姓）/ 复姓两字笔画相加
2. **人格**：姓氏末字笔画+名字首字笔画
3. **地格**：名字两字笔画相加（单字名+1）
4. **外格**：总格-人格+1（单姓单名外格为2）
5. **总格**：姓氏与名字所有笔画相加

### 笔画吉凶数（常用参考）
- **大吉数**：1、3、5、6、7、8、11、13、15、16、17、18、21、23、24、25、29、31、32、33、35、37、39、41、45、47、48、52、57、61、63、65、67、68、81
- **次吉数**：2、9、10、12、14、19、20、22、26、27、30、36、40、42、43、44、46、49、50、51、53、55、56、58、59、60、62、64、66、69-80
- 常用凶数：4、34、38、54、70、71、72、73、74、75、76、77、78、79、80（需避开）

### 五行配置
- 1、2为木；3、4为火；5、6为土；7、8为金；9、10为水
- 天格→人格→地格形成三才配置
- 三才配置相生为吉（如木火土、火土金等）

## 四、三才配置

三才：天格（父）、人格（自身）、地格（基础）

## 六、取名流程（完整）

1. **排八字**：确认出生年月日时，排四柱
2. **分析五行**：统计五行分布，定日主强弱
3. **定喜用神**：确定补救五行
4. **选字范围**：按喜用神选五行相符的字
5. **数理筛选**：计算五格，避开凶数，选吉数组合
6. **音韵检查**：读顺口、无谐音不雅
7. **字义筛选**：寓意好、与姓搭配佳
8. **三才验证**：确认三才配置相生
9. **生肖验证**：结合生肖喜忌微调
10. **综合定名**：推荐3-5个备选，说明优劣

## 八、改名要点

1. 改名需以新名实际使用为准（证件、社交）
2. 重点看八字喜用神与五格数理
3. 改名目的明确：事业/健康/婚姻各有侧重
4. 推荐新旧名对比说明，供自行决定

## 九、注意事项

1. 名字以父母意愿为最终依据，命理仅供参考
2. 避免为了数理牺牲字义与音韵
3. 避免过度奇特的生僻字影响社交
4. 不迷信：好名字是锦上添花，非决定命运
