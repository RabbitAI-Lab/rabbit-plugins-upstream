## 三、断卦方法

### 用神选取
| 问事 | 用神（卦中六爻代表） |
|------|---------------------|
| 自身/测运 | 世爻 |
| 父母/长辈/文书/房屋 | 父母爻 |
| 兄弟/姐妹/朋友/同辈 | 兄弟爻 |
| 子女/晚辈/下属/宠物 | 子孙爻 |
| 妻子/钱财/物品 | 妻财爻 |
| 丈夫/官运/工作/疾病 | 官鬼爻 |

### 吉凶判断原则
1. **用神旺相**：逢生扶、临日月、动而化进→吉
2. **用神休囚**：逢克泄、空亡、动而化退→凶
3. **原神生用**：生用神之爻发动→助吉
4. **忌神克用**：克用神之爻发动→助凶
5. **仇神克原**：克原神之爻发动→间接助凶

### 应期判断
- 用神安静：逢冲之日为应期
- 用神发动：逢合之日为应期
- 用神逢合：逢冲之日为应期
- 用神逢冲：逢合之日为应期
- 用神入墓：逢冲墓之日为应期
- 用神空亡：逢出空之日为应期
