# 报告生成模板库

本文件定义玄学报告中各术数体系的章节结构、解读框架与输出规范。用于生成美观、专业、结构化的命理报告（八字命理报告、紫微斗数报告、综合运势报告等）。

## 一、通用报告结构

所有报告遵循统一框架：

### 封面信息
- 报告标题（如"八字命理分析报告"）
- 求测者信息（性别、出生日期，可匿名）
- 生成日期

### 正文结构
1. 基本信息与命盘展示
2. 核心解读（性格、天赋）
3. 分领域分析（事业、财运、感情、健康）
4. 大运流年运势
5. 开运建议
6. 免责声明

## 二、八字命理报告模板

### 章节1：基本信息
- 公历/农历出生时间
- 四柱干支（年柱、月柱、日柱、时柱）
- 十神排布

### 章节2：命盘总览
```
日主：[天干]（[五行][阴阳]）
身强/身弱：[判断]
喜用神：[五行]
忌神：[五行]
```

### 章节3：性格特质
- 日主五行性格
- 十神组合性格
- 格局特点
- 优势与需要注意的方面

### 章节4：领域分析
#### 事业
- 官星/印星情况
- 适合的行业五行
- 事业高峰期
#### 财运
- 财星位置与旺衰
- 求财方式建议
#### 感情
- 配偶星（男看财星、女看官星）
- 婚姻特征与建议
#### 健康
- 五行对应脏腑强弱
- 需注意的健康问题

### 章节5：大运流年
- 大运列表（起运年龄、每十年一运）
- 当前大运详解
- 近三年流年运势
- 关键年份提醒

### 章节6：开运建议
- 吉祥方位、颜色、数字
- 适宜行业
- 取名/穿搭建议
- 综合建议

## 三、紫微斗数报告模板

### 章节1：命盘信息
- 农历出生日期与时辰
- 命宫、身宫位置
- 五行局

### 章节2：命盘表格
- 十二宫：命宫、兄弟、夫妻、子女、财帛、疾厄、迁移、仆役、官禄、田宅、福德、父母
- 各宫主星与辅星

### 章节3：主星解读
- 命宫主星特质
- 身宫主星特质
- 十四主星（紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军）性格分析

### 章节4：宫位分析
- 财帛宫：财运模式
- 官禄宫：事业方向
- 夫妻宫：感情婚姻
- 迁移宫：外出发展
- 疾厄宫：健康注意

### 章节5：四化与格局
- 化禄、化权、化科、化忌落宫分析
- 特殊格局（如紫府同宫、日月并明等）

### 章节6：大限流年
- 大限十年运势
- 当前大限与流年重点

## 四、综合运势报告（多术数融合）

### 结构
1. 八字定基调（先天格局）
2. 紫微看人生领域（十二宫细分）
3. 奇门/六爻看具体事件（一事一占）
4. 风水给开运方案
5. 五行穿搭/取名辅助建议

### 融合原则
- 各体系结论一致处重点强调
- 矛盾处以八字为主、其他为辅
- 明确标注每个结论的来源体系

## 五、格式规范

### 标题层级
```
# 报告标题
## 一级章节
### 二级小节
#### 三级说明
```

### 表格使用
命盘类信息用表格呈现（四柱、十神、十二宫、大运列表）

### 文字风格
- 专业平实，避免绝对化表述（用"倾向于""较可能""建议"）
- 结构清晰，分点论述
- 长度适中：分领域各2-4段

## 六、输出形式

### 直接对话输出
- 简洁版：核心结论+关键建议
- 适合快速问答场景

### 完整报告生成
- 生成 HTML 文件（推荐，可用浏览器查看）
- 或 Markdown 文档
- 包含完整命盘、详细解读、开运建议

## 七、免责声明模板

> 本报告基于传统命理文化（八字/紫微/占卜等）生成，仅供文化研究、娱乐参考，不构成任何专业建议（医疗、法律、投资等）。命运掌握在自己手中，请理性看待，积极生活。

## 八、报告质量检查清单

- [ ] 命盘数据准确（出生时间、排盘正确）
- [ ] 各章节结构完整
- [ ] 结论有依据（引用具体星曜/神煞/卦象）
- [ ] 语言专业不迷信、不恐吓
- [ ] 给出建设性建议而非只报凶吉
- [ ] 附免责声明
