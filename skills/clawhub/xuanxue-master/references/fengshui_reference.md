# 风水参考库

风水学（堪舆学）研究人居环境与自然的和谐关系，通过方位、布局、形理结合来调整气场、趋吉避凶。本文档提供风水学的核心理论、实用布局与化煞方法。

## 一、基础理论

### 形势派 vs 理气派
- **形势派（峦头）**：重山水形貌、龙砂穴水，看"形"
- **理气派**：重方位卦理、九宫飞星，看"气"
- 现代应用多两派结合：形理兼顾

### 风水三要素
1. **藏风**：避强风直冲，聚气
2. **得水**：近水而活，水主财
3. **乘气**：坐向合宜，气场流通

## 二、住宅基本概念

### 坐向
- 坐：宅后所靠方向；向：宅前所对方向
- 如"坐北朝南"：坐坎向离，冬暖夏凉
- 现代楼房以阳台/采光面为"向"

### 明堂
- 屋前空地/阳台为明堂，宜开阔明亮
- 明堂开阔则前途光明、聚财

### 青龙白虎
- 左青龙、右白虎
- 青龙宜高、白虎宜低（宁肯青龙高万丈，不可白虎高一寸）
- 住宅左右宜平衡，右高左低防小人

## 三、九宫飞星（理气核心）

### 九星
| 星 | 五行 | 吉凶 | 主管 |
|----|------|------|------|
| 一白贪狼 | 水 | 吉 | 桃花、人缘、事业 |
| 二黑巨门 | 土 | 凶 | 病符、疾病 |
| 三碧禄存 | 木 | 凶 | 是非、官非、口舌 |
| 四绿文曲 | 木 | 吉 | 文昌、学业、考试 |
| 五黄廉贞 | 土 | 大凶 | 灾祸、血光（煞星之首） |
| 六白武曲 | 金 | 吉 | 偏财、武职、贵人 |
| 七赤破军 | 金 | 凶 | 破财、口舌、盗贼 |
| 八白左辅 | 土 | 大吉 | 正财、置业、喜庆 |
| 九紫右弼 | 火 | 吉 | 喜庆、桃花、事业 |

### 流年飞星
每年九星飞临不同方位，如2024年二黑在东南、五黄在正西（示例，需按年推算）。判断当年各方位吉凶，吉方动土、凶方化煞。

## 四、居家布局宜忌

### 大门
- 大门为"纳气之口"，宜明亮整洁
- 忌大门对电梯、对楼梯、对厕所
- 忌开门见灶（漏财）、开门见厕（污秽）、开门见镜（财气反射）

### 客厅
- 宜方正明亮，主位（沙发）靠实墙
- 沙发忌背对门（无靠山）
- 财位（进门对角线位置）宜放绿植/聚财物，忌放垃圾桶

### 卧室
- 床头宜靠实墙，忌对门、对镜、对窗
- 床忌横梁压顶（压力、头痛）
- 卧室宜小不宜大（气聚）
- 忌镜对床（影响睡眠、感情）

### 厨房
- 厨房属火，宜在凶位（以火制煞）
- 炉灶忌对门、对水槽（水火相冲）
- 冰箱不宜对灶

### 卫生间
- 属水，宜隐蔽，门忌对大门、对床、对灶
- 保持干燥通风，防秽气扩散

### 书房
- 书桌宜"背实面虚"或"面壁而学"
- 文昌位（按宅命或流年推算）宜放书桌
- 座位忌背后空旷、靠窗

## 五、办公室风水

- 座位背后宜有靠（墙/柜），忌背门背窗
- 忌座位正对门（受冲）、横梁压顶
- 老板位宜在西北（乾位）或本命财位
- 文件柜宜左不宜右（左青龙高）

## 六、常见形煞与化解

| 形煞 | 表现 | 化解 |
|------|------|------|
| 路冲 | 道路直冲宅门 | 石敢当、屏风、植物 |
| 天斩煞 | 两楼间缝隙正对 | 麒麟、山海镇 |
| 尖角煞 | 墙角/尖物正对 | 凸镜、植物、窗帘 |
| 反弓煞 | 道路弯弓反背 | 石敢当、葫芦 |
| 镰刀煞 | 弧形路如镰刀 | 麒麟、铜钱 |
| 穿堂煞 | 门窗一线通 | 屏风、柜子、玄关 |
| 白虎煞 | 右方建筑高/动土 | 麒麟、龙龟 |
| 顶心煞 | 灯柱/大树正对门 | 凸镜、泰山石敢当 |
| 味煞 | 垃圾场/臭味 | 开窗通风、空气净化 |
| 光煞 | 强光反射入宅 | 厚帘、植物 |

## 七、植物与摆件

### 招财植物
发财树、金钱树、富贵竹、招财树、绿萝（攀爬需绑红绳）

### 化煞植物
仙人掌（放凶位）、龙骨、金琥

### 吉祥摆件
- 貔貅：招财（头朝外）
- 金蟾：旺财（嘴朝内）
- 五帝钱：化煞挡煞（挂门内）
- 葫芦：化病保平安
- 水晶：聚气增能
- 鱼缸：催财（放财位，水为财，忌放卧室）

## 八、二十四山与坐向吉凶

将圆周360°分为24山（每山15°），以罗盘测量精确坐向。常用坐向：
- 子山午向（坐北朝南）、午山子向（坐南朝北）
- 卯山西向（坐东朝西）、酉山卯向（坐西朝东）
- 壬山丙向、癸山丁向、丑山未向等

### 八宅派坐向（简易参考）
以宅坐的八卦方位分东西四宅，人按年命分东西四命，东四命居东四宅、西四命居西四宅为吉。

## 九、风水勘察流程

1. 测量坐向（罗盘/指南针，避开金属干扰）
2. 观察外局（周围建筑、道路、水景）
3. 判断形煞（对冲、尖角、压迫等）
4. 排九宫飞星（流年+流月+宅命）
5. 确定吉凶方位与财位、文昌位
6. 提出布局调整与化解方案
7. 择吉时动工/入住

## 十、注意事项

1. 风水讲求整体平衡，避免过度迷信单点布局
2. 现代城市环境需结合实际（采光、通风、安全优先）
3. 化煞用品以自然和谐为主，避免堆砌
4. 尊重居住者舒适感，实用为先
