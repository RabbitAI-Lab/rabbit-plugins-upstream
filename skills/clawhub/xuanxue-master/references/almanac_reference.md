# 黄历择吉参考库

黄历（老黄历、通书）记载每日干支、宜忌、神煞、节气等信息，用于指导日常生活与重要活动的择吉。本文档提供黄历的解读规则与择吉方法。

## 一、黄历基本信息

### 每日信息构成
1. **公历/农历日期**：双历对照
2. **干支纪日**：六十甲子循环
3. **十二值日**（建除十二神）
4. **二十八星宿**（值日星宿）
5. **宜忌**：当日适宜与不宜之事
6. **吉神凶煞**：值日神煞
7. **冲煞**：冲什么生肖、煞什么方位

## 二、建除十二值日

十二值日（建除满平定执破危成收开闭）按当月节气的月支与日支关系排列：

| 值日 | 含义 | 宜事 |
|------|------|------|
| 建日 | 万物建立 | 建基、上任，忌动土 |
| 除日 | 除旧迎新 | 扫舍、求医、祭祀 |
| 满日 | 圆满丰盈 | 祈福、嫁娶、开市 |
| 平日 | 平常平稳 | 修屋、造桥、安葬 |
| 定日 | 安定不动 | 嫁娶、签约、入宅 |
| 执日 | 执持事物 | 捕捉、建房、安床 |
| 破日 | 破败损坏 | 破屋、求医，忌大事 |
| 危日 | 危险不安 | 静守、祭祀，忌远行 |
| 成日 | 成就圆满 | 开业、嫁娶、入学（大吉） |
| 收日 | 收获收藏 | 纳财、收账、安葬 |
| 开日 | 开敞顺利 | 开业、出行、嫁娶（吉） |
| 闭日 | 闭塞不通 | 安葬、砌墙，忌开市 |

### 吉日参考
成日、开日、定日、除日为吉日偏多；破日、危日、闭日多忌大事。

## 三、二十八星宿

二十八宿分四方七宿，每宿有吉凶属性：

| 方位 | 七宿 |
|------|------|
| 东方青龙 | 角亢氐房心尾箕 |
| 北方玄武 | 斗牛女虚危室壁 |
| 西方白虎 | 奎娄胃昴毕觜参 |
| 南方朱雀 | 井鬼柳星张翼轸 |

### 吉凶速查（常用）
- **吉宿**：角、房、尾、箕、斗、室、壁、娄、胃、毕、参、井、张、翼
- **平宿**：氐、心、牛、虚、昴、觜、鬼、星
- **凶宿**：亢、女、危、奎、柳、轸

## 四、天干地支与六十甲子

### 六十甲子
甲子、乙丑、丙寅…循环一周60天。每日一干支。

### 纳音五行
六十甲子各有纳音五行（海中金、炉中火、大林木等），用于命理分析。

### 十二生肖冲合
- **六冲**：子午、丑未、寅申、卯酉、辰戌、巳亥（当日冲此生肖者需谨慎）
- **六合**：子丑、寅亥、卯戌、辰酉、巳申、午未（与当日相合生肖者吉）

## 五、神煞

### 吉神
- **天德**：大吉之星，百事可为
- **月德**：大吉之星
- **天恩**：普施恩泽，修造嫁娶皆宜
- **母仓**：宜纳财、畜牧
- **三合**：宜合作、签约
- **六合**：宜合婚、合作
- **天喜**：宜嫁娶、喜庆

### 凶煞
- **月破**：当月所冲之支，诸事不宜
- **劫煞**：防偷盗、抢劫
- **灾煞**：防意外灾祸
- **五虚**：防破耗虚损
- **大耗**：防大破财
- **四穷**：宜静不宜动
- **九空**：防财物流失
- **阴错阳差**：男女之事不吉
- **杨公忌**：正月十三、二月十一等十三日，忌远行、嫁娶

## 六、择吉基本原则

### 择吉流程
1. 确定事项（嫁娶/开业/搬家/动土…）
2. 选定月份（避开冲月）
3. 查每日宜忌，选宜该项之日
4. 核对值日、星宿、神煞
5. 检查冲煞（避开本人生肖被冲之日）
6. 结合时辰（选吉时）

### 各事项择吉要点
- **嫁娶**：选天德/月德/天喜/六合日，忌冲新娘新郎生肖
- **开业**：选成日、开日，财星旺之日
- **搬家**：选成日、定日，忌破日
- **动土**：选建日、执日，忌五虚、月破
- **出行**：选开日、成日，忌危日
- **祭祀**：选除日、满日
- **安葬**：选平日、收日

### 择时
十二时辰吉凶：
- **吉时**：子(23-1)、丑(1-3)、辰(7-9)、巳(9-11)、未(13-15)、戌(19-21)
- **平**：寅(3-5)、午(11-13)、酉(17-19)、亥(21-23)
- **凶**：卯(5-7)、申(15-17)
（此为简化参考，具体需结合日辰）

## 七、冲煞解读

- **冲**：当日地支与某生肖相冲。如子日冲马（午）
- **煞**：当日凶煞所在方位，如"煞北"则当日不宜向北方动工
- 择吉时：本人生肖不被冲，所行方向不犯煞

## 八、黄历应用示例

以2026年8月17日为例（示例解读流程）：
1. 公历2026年8月17日 → 农历丙午年七月初五
2. 查看干支日、值日、星宿、宜忌
3. 若当日宜"嫁娶"，且不冲求测者生肖 → 可选用
4. 结合时辰与方位最终定夺

## 九、注意事项

1. 黄历宜忌因版本不同略有差异，以主流通书为准
2. 择吉需结合个人生辰（八字）更精准
3. 现代社会应用以参考为主，重大事项综合判断
4. 避免"百无禁忌"的绝对化思维
