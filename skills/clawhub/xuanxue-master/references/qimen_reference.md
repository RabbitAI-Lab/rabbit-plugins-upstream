# 奇门遁甲参考库

奇门遁甲为"三式"之首（太乙、奇门、六壬），号称"帝王之学"。以九宫八卦为框架，结合九星、八门、八神、三奇六仪，用于预测、择吉与运筹。本文档提供奇门遁甲的核心理论体系。

## 六、阴遁与阳遁

- **阳遁**：冬至后到夏至前，阳气上升，顺布六仪三奇
- **阴遁**：夏至后到冬至前，阴气下降，逆布六仪三奇
- 分九局（一至九局），共十八局（阳九局+阴九局）

### 定局方法（节气定局）
- 冬至、惊蛰一七四；小寒二八五；大寒三九六
- 夏至、白露九三六；小暑八二五；大暑七一四
- 春分、秋分三九六（阳遁）；立春八五二；清明四一七
- 雨水九六三；谷雨五二八；立夏四一七；小满五二八；芒种六三九
- 立秋二五八；处暑一四七；寒露六九三；霜降五八二；立冬六九三；小雪五八二；大雪四七一

## 七、排盘流程

1. **定局**：按节气定阴阳遁与局数
2. **布三奇六仪**：按局数顺/逆布九宫
3. **找值符值使**：时干所在宫之星为值符，门为值使
4. **排九星**：值符随时干转，其余八星随转
5. **排八门**：值使随时宫，其余八门随转
6. **排八神**：值符神随值符星转
7. **定旬首与用神**：分析各宫符号组合

## 九、格局吉凶

### 吉格
- **三奇得使**：乙丙丁临吉门吉星，百事可为
- **青龙回首**：乙+丙、丙+乙，大吉
- **飞鸟跌穴**：丙+戊、戊+丙，大吉
- **玉女守门**：丁奇临值使之门，吉
- **门宫相合**：门生宫、宫生门，吉
- **星门相生**：主星生门或门生星，吉

### 凶格
- **伏吟**：星门伏本位，诸事宜守不宜攻
- **反吟**：星门冲本宫，主反复无常
- **六仪击刑**：六仪临刑地，主刑伤
- **白虎猖狂**：庚+丙，主凶灾
- **青龙逃走**：乙+辛，主逃遁
- **朱雀投江**：丁+癸，主文书破财
- **螣蛇夭矫**：癸+丁，主怪异虚惊
- **太白入荧**：庚+丙，主盗贼兵灾
- **五不遇时**：时干克日干，诸事不利

## 十、择吉应用

### 出行择吉
- 查当日时盘，选开门、休门、生门方位
- 避开死门、惊门、伤门方位
- 三奇（乙丙丁）临旺相之地为佳

### 求财择吉
- 生门临旺相之方
- 戊（资本）生旺、临吉门
- 值符生用神为吉

### 开业择吉
- 开门（事业）临吉门吉星
- 日干与开门相生
- 避开五不遇时、伏吟反吟

## 十一、运筹化解

- **趋吉**：在吉时前往吉门方位办事（如开门方位求职）
- **避凶**：避开凶格方位与时辰
- **改方**：用神受制时，改从吉方行动
- **借力**：借值符（贵人）方位行事

## 十二、注意事项

1. 奇门重在"时"与"向"，时空结合判断
2. 天时（年命）、地利（方位）、人和（用神）综合
3. 同一时辰全球相同，但方位按本地计算
4. 现代应用：谈判方位、办公布局、择日出行均可参考
