# 测字参考库

测字（拆字、相字）通过分析汉字的字形、结构、笔画、字义、谐音等，来推断所问之事。测字起源甚早，盛行于唐宋，是民间占卜的重要形式。本文档提供测字的核心规则与解读方法。

## 一、测字基本方法

### 取字途径
1. 求测者随口报一个字
2. 求测者随手写一个字
3. 占者根据环境取字（物名、地名、店名）
4. 指定页码、笔画数选字

### 核心原则
- 字随意出，意随字断——第一反应最准
- 无心之字最灵——刻意为之反而失真
- 结合当时情景（时、地、人、事）综合断

## 二、字形分析法

### 拆字
将字拆成偏旁部首：
- 如"谢"拆为"言身寸"，寸土必争→主计较或有所得
- 如"聪"拆为"耳总"——耳听总明，主听取意见则明
- 如"愁"拆为"秋心"——秋心为愁，主季节或心绪相关

### 合字
将多字合并看：
- 如"明白"合看，"日月"之象，主光明事成
- 合字看整体意象与格局

### 增字
在字上添笔/添旁另断：
- 如"人"加一笔成"大"、"个"，主有人助或格局变大

### 减字
去笔画看变体：
- 如"贵"减一笔为"贯"，主破财或虚名

## 三、字义解读法

按字的本义、引申义断事：
- **财**：贝才相合，主得财需才能
- **安**：宀下有女，主居家平安
- **家**：豕居屋下，主安定丰足
- **吉**：士口相加，主口福、有靠

## 四、谐音法

利用谐音联想：
- **发**（fa）：发财之发，大吉
- **梨**：谐"离"，主分离（问婚不利）
- **枣**：谐"早"，主早成
- **伞**：谐"散"，主分散（问事不利）
- **蝠**：谐"福"，主福气
- **鱼**：谐"余"，主富余

## 五、笔画数理法

### 笔画定数
单字笔画数配合五行：
- 1、2画属木；3、4画属火；5、6画属土；7、8画属金；9、10画属水
（此为简配，另有五格数理体系）

### 笔画断事
- 奇数主阳、主动、主成；偶数主阴、主静、主守
- 笔画多少与事体轻重、过程快慢相关

## 六、五行法

按字的结构、偏旁、颜色属五行：
- 金：金、刂、钅、西 → 坚硬、决断
- 木：木、艹、竹 → 生长、上升
- 水：氵、雨、冫 → 流动、财源
- 火：火、灬、日 → 光明、急切
- 土：土、山、田 → 稳定、不动产

结合所问之事与求测者五行喜忌断吉凶。

## 七、测字断事范例

### 问事业
- 得"升"字：升腾之象，主升职有进
- 得"困"字：木困于口，主当前受制，需寻出口
- 得"腾"字：马加月，主快马加鞭、进展迅速

### 问感情
- 得"双"字：两又相叠，主好事成双
- 得"愁"字：秋心，主季节变化影响心情
- 得"缘"字：丝缘相系，主有缘分牵引

### 问财运
- 得"富"字：宀下有田一口，主有房有产
- 得"钱"字：金戋，主钱财多从微小处积累
- 得"穷"字：穴中力少，主当前受限需努力

## 八、环境外应

测字结合当时环境：
- 问字时见花开：事将成且悦
- 问字时见叶落：事将败或属秋
- 问字时闻钟鸣：主警醒或有贵人提醒
- 问字时有鸟飞过：主消息快、有信至

## 九、测字注意事项

1. 一字一断，多字反而难精
2. 以第一直觉为准，忌反复换字
3. 断语宜留有余地，忌铁口直断
4. 结合求测者具体情况，避免刻板套用
5. 娱乐参考为主，重大决策需理性综合判断
