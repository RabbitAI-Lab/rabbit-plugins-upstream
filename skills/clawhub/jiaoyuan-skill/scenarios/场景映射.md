# 10 类现实难题 → 模式映射 / 10 Problem Types → Pattern Mapping

> 说明：用户遇到现实难题时，推演引擎按此映射选取主导模式 + 辅助模式，再走"先看本质→调查→主矛盾→策略→切入点→靠谁→第一步"的推演流程。
>
> When a user faces a real problem, the engine selects a lead pattern + supporting patterns per this mapping, then follows the reenactment flow: essence → investigate → principal contradiction → strategy → entry point → who to rely on → first step.

## 1. 事业困境（卡壳/停滞/看不到出路）/ Career Dilemma (Stuck / Stalled)
- 主导 Lead：调查研究（先弄清卡在哪）Investigation & Research
- 辅助 Support：抓主要矛盾、波浪式前进、持久战

## 2. 创业（从 0 到 1 / 资源不足）/ Starting Up (0→1 / Scarce Resources)
- 主导 Lead：星星之火（小处着手、看趋势）A Single Spark
- 辅助 Support：持久战、独立自主、集中优势兵力

## 3. 决策（重大选择 / 信息不足 / 怕选错）/ Decision (Big Choice / Insufficient Info)
- 主导 Lead：调查研究（先调查后决策）Investigation & Research
- 辅助 Support：一分为二、抓主要矛盾、具体问题具体分析

## 4. 团队（分歧 / 士气 / 纠错 / 协作）/ Team (Conflict / Morale / Correction)
- 主导 Lead：团结—批评—团结 Unite—Criticize—Unite
- 辅助 Support：批评与自我批评、群众路线、弹钢琴

## 5. 竞争（面对强敌 / 被动挨打 / 想反超）/ Competition (Strong Rival)
- 主导 Lead：战略藐视·战术重视 Despise Strategically, Take Seriously Tactically
- 辅助 Support：集中优势兵力、争取主动权、持久战

## 6. 学习（学了不会用 / 方法陈旧 / 进步慢）/ Learning (Can't Apply What You Learn)
- 主导 Lead：实践—认识—再实践 Practice—Knowledge—Practice
- 辅助 Support：理论联系实际、从战争中学习战争、调查研究

## 7. 挫折（失败 / 受挫 / 想放弃）/ Setback (Failure / Wanting to Quit)
- 主导 Lead：一分为二（化危为机）One Divides into Two
- 辅助 Support：波浪式前进、放下包袱、持久战

## 8. 人际（矛盾 / 被裹挟 / 边界不清）/ Interpersonal (Conflict / Boundaries)
- 主导 Lead：团结—批评—团结 Unite—Criticize—Unite
- 辅助 Support：反对自由主义、批评与自我批评、独立自主

## 9. 变革（推动改变 / 阻力大 / 方向不明）/ Change (Resistance / Unclear Direction)
- 主导 Lead：抓主要矛盾（抓住决定性环节）Grasp the Principal Contradiction
- 辅助 Support：群众路线、波浪式前进、两个务必

## 10. 迷茫（方向不明 / 焦虑 / 找不到意义）/ Confusion (Lost / Anxious)
- 主导 Lead：调查研究（从实际情况找方向）Investigation & Research
- 辅助 Support：星星之火、实事求是、放下包袱

---

## 使用说明（推演引擎）/ How the Engine Uses This

1. 识别用户问题所属的场景类别（可多类）/ Identify the problem type (may be multiple)
2. 选取该类别的主导模式 + 1-2 个辅助模式 / Pick the lead pattern + 1-2 supporting patterns
3. 按主导模式的"思维路径"走一遍，把每一步落到用户的具体处境 / Run the lead pattern's Thinking Path, applying each step to the user's situation
4. 用"决策原则"给出取舍建议 / Use the Decision Principles to give trade-off advice
5. 用"适用边界+反例"做一次自查，防止教条化套用 / Self-check with Applicability Boundaries & Counterexamples
6. 输出「他会先怎么看 / 思考路径 / 现在就能做的第一步」/ Output "how he'd first see it / the thinking path / the first step now"
