## 三、处理方式说明 / Processing Notes

1. **军事文集为竖排逐字提取**：原 PDF 为竖排版，提取后每字一行（未做横向重排合并）。如需深度引用，可自行编写合并脚本；本仓库如实保留原提取格式。
2. **原始 PDF 不入库**：为控制体积，原始 PDF（约数百 MB）与 `raw/` 中间产物均不进入本仓库，仅保留结构化/转码后的文本。
3. **早期文稿 / 诗词 / 政治经济学批注**：源文件为 GB18030 编码，已统一转码为 UTF-8 入库，正文未做改动。
4. **诗词品读（赏析文）**：非原著，不收录。
5. **农村调查文集**：源为扫描版 PDF（371 页，无文本层），暂无法提供可检索文本，标记为「待补」。
