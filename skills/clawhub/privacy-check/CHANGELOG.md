# Privacy Check — 更新日志

## [1.0.1] - 2026-07-19

### Added
- **6 种新 PII 模式**: 信用卡号(Luhn独立校验)、SSN(美国社会安全号)、
  港澳护照号、台湾护照号、驾驶证号、微信号、支付宝账号
- **CSV 输出格式** (`--format csv`)
- **HTML 报告** (`--format html`)
- **白名单忽略** (`--ignore PATTERN`)
- **文件类型过滤** (`--ext .txt,.csv`)
- **ASCII 条形图摘要** — 终端输出时按类型分布显示

### Security
- **上下文默认关闭**：`include_context=False`，`--context` 参数开启（减少敏感数据聚合风险）
- **上下文行脱敏**：`_get_context()` 对 PII 模式做脱敏处理
- **安全警告**：报告输出头部和 JSON 数据中均添加安全提醒，提示用户妥善保管扫描结果
- **报告新增 recommendation 字段**：建议使用默认模式（不包含上下文）

### Changed
- Luhn 校验拆分为独立函数，银行卡号和信用卡号分别检测
- 护照号拆分为中国/港澳/台湾三种模式
- 安全评估：移除 `--no-context`，改为 `--context` 主动开启

## [1.0.0] - 2026-07-19

### 新增
- 首次发布
- 10 种 PII 模式检测（身份证、手机号、邮箱、银行卡、护照、IP、邮编、API密钥）
- JSON 报告输出
- 递归目录扫描
- 自动脱敏显示
- Luhn 算法校验银行卡号
