## Known Risks and Mitigations:

Risk: Setup instructions include direct execution of remote installer scripts in a shell.

Mitigation: Review the oo CLI installation path first and prefer an official package-manager or verified download flow when available.

Risk: The connected Lingxing account can expose operational, advertising, account, inventory, shipment, and profit data.

Mitigation: Connect a Lingxing account with only the scopes needed for the intended workflow and review access before use.
