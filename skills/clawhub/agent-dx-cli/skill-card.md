## Description:

Helps developers design, review, and refactor agent-facing CLIs for predictable behavior, defense in depth, and context efficiency.

This skill is ready for commercial/non-commercial use.

## Publisher:

[agenticweb4](https://clawhub.ai/user/agenticweb4)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to assess CLI contracts, recommend improvements, and implement authorized refactors with evidence-backed checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: CLI inspection and authorized refactoring may run commands or change project files.

Mitigation: Use in projects where review and refactoring are intended; require authorization for changes and review results before adoption.
