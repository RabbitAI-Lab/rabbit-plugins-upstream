# 阶段5 · 文末模板引擎 + 风格主题系统

目标：**文末内容可配置（二维码/介绍/过往文章/社群），全文风格可选主题**，一次配置反复使用。

## 5.1 文末模板引擎

文末是私域转化的核心位，按块组装（顺序可配，见 `config.json → footer.order`）：

| 块 | 内容 | 配置项 |
|---|---|---|
| recommend | 推荐阅读（同主题过往文章 2-3 篇） | 标题+链接，可从 past_articles 自动匹配主题 |
| about | 个人介绍（100字内） | bio + 头像 |
| community | 社群/企微 CTA | 二维码图路径 + 一句诱因（「回复关键词领XX」） |
| cta | 行动号召 | 关注引导 / 回复关键词 / 加企微 |
| signature | 金句收尾 | 九力体系相关金句（每篇可选不同） |

**占位符机制**：`config.json` 中二维码等为路径，若文件不存在则输出占位框（`[在此放置企微二维码]`），用户后续替换图片即可，模板结构不变。

## 5.2 风格主题系统

内置 3 款（`themes/`），每款定义：适用场景、配色、字体、标题风格、段落节奏、金句风格、图表风格、文末口吻。

| 主题 | 文件名 | 适用 | 一句话风格 |
|---|---|---|---|
| xinming-lab | xinming-lab.yaml | 默认，行业深度内容/调研报告 | 紫绿蓝品牌色（#534AB7/#639922/#2196F3），ABBB 结构，专业可信 |
| xinming-minimal | xinming-minimal.yaml | 随笔/短文/思考 | 极简黑白灰，内容至上，无色彩干扰 |
| xinming-warm | xinming-warm.yaml | 成长故事/案例拆解/人物 | 暖橙古铜（#C0392B/#8B5E3C），温润叙事感 |

**选择规则**：按内容类型自动推荐 + 用户可覆盖；同一篇文不允许混搭两套配色体系。

## 5.3 风格应用检查表

- [ ] 全篇使用主题定义的强调色（仅限 2-3 个主色，不彩虹）
- [ ] 标题层级一致（H2 用绿，金句用紫，数据用蓝——专业风）
- [ ] 段落长度符合主题节奏
- [ ] 文末块顺序与 config 一致，二维码已替换或占位明确
- [ ] 全篇无主题外字体/颜色残留
