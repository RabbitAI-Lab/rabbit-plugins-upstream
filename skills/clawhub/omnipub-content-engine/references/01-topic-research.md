# 阶段1 · 选题讨论方法论

目标：**找到「热度高 × 爆款潜力大 × 与心明IP契合」的选题，并与人达成共识。** 选题是内容成败的第一因，本阶段不允许跳过。

## 1.1 热点信号搜集（多源并行）

| 信号源 | 工具/方法 | 提取什么 |
|---|---|---|
| 公众号热文 | wechat-write（红狐爆款雷达）、微信搜一搜 | 同领域10w+标题规律、评论区情绪 |
| 头条热榜 | WebSearch「今日头条热榜 健康/AI/职场」 | 正在上升的话题词 |
| 抖音热点 | douyin-hot-trend | 年轻用户情绪入口 |
| 跨平台舆情 | cn-last30days | 小红书/抖音/公众号30天真实讨论 |
| 行业资讯 | WebSearch 卫健委/行业协会/权威媒体 | 政策变化、新规、数据报告发布 |
| 用户反馈 | 私域社群聊天记录（若有） | 真实痛点提问（最佳选题源） |

搜索要点：每个候选话题至少 2 个关键词变体搜索（如「AI健康管理」+「AI问诊 监管」），避免信息茧房。

## 1.2 爆款潜力评分卡（HCTFD 五维）

对每个候选选题打分，满分 100：

| 维度 | 分值 | 打分依据 | 判定标准 |
|---|---|---|---|
| H 热度 | 30 | 当前搜索/讨论量、上升趋势 | 25-30 正在爆的话题；15-24 稳定热门；<15 冷门 |
| C 冲突度 | 25 | 是否存在对立观点 | 高：颠覆常识/有争议（如「体检无用论」）；低：无争议常识 |
| T 时效窗口 | 20 | 红利期剩余 | 即将到来的节点（节气/政策生效日）窗口大 |
| F 人设契合 | 15 | 与「大健康老兵/九力体系/IP教练」匹配度 | 高：能自然输出专业+体系；低：蹭热点但违和 |
| D 数据支撑 | 10 | 是否有公开可查证数据 | 有权威数据可引=爆款素材；纯观点=易空洞 |

**判定规则**：
- ≥75 分：直接入选，进入候选池
- 60-74 分：可入选，但需说明弥补策略（如补数据、找冲突点）
- <60 分：淘汰，记录淘汰原因（供后续复盘对照）

## 1.3 人设匹配矩阵（防止「火但不属于你」）

选题必须满足：**这个选题只有「心明」能写，或者写出来比别人强。**

| 匹配问题 | 通过标准 |
|---|---|
| 能调用哪段经历？ | 新浪/健康160/创业慧康/16年行业/10年产品，至少一段 |
| 能挂靠哪个体系？ | 九力体系（命力~场力）至少一力 |
| 差异化视角？ | 行业老兵视角/产品人拆解视角/教练陪跑视角 |
| 目标读者是谁？ | 大健康从业者 / 想转型IP的普通人 / 关注健康的职场人，至少一类清晰 |

不满足 2 条以上 → 该选题即使热度再高也降级或弃用。

## 1.4 输出格式（供用户确认）

对每个候选选题输出：

```
【候选1】标题方向：XXX
- 一句话逻辑：为什么现在写这个（热度证据）
- 目标读者：XXX，痛点：XXX
- 爆款路径：冲突点/情绪点/实用价值点是什么
- 评分：H28 + C22 + T18 + F14 + D8 = 90
- 可用数据源：XXX（列出1-3个可查证来源）
- 标题候选（3个，20-28字，痛点/悬念/数字型）
```

**必须等待用户确认或给出调整意见后，才进入阶段2。** 用户确认记录写入 `01-选题确认.md`。
