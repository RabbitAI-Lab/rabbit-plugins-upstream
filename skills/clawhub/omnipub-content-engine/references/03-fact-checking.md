# 阶段3 · 数据源查证核实（用户红线，强制）

**原则：只取真实观察和公开数据，拒绝空洞鸡汤与编造数据。查证不通过的内容不得发布。**

## 3.1 三源交叉验证法

文中每个**数据、政策、案例、专家观点**，必须满足：

1. **找到一手来源**：原始报告、官方公告、机构官网，优先于二手转述
2. **至少 2 个独立来源交叉一致**：两个以上互不相关的来源（不同机构/媒体）数据一致，才可标注采用
3. **来源可回溯**：记录机构名 + 发布时间 + 标题 + URL（或可定位的出处名）

**判定表**：

| 情况 | 处理 |
|---|---|
| 三源一致 | 采用，标注最权威来源 |
| 两源一致，一源出入大 | 采用两源一致值，在来源清单中标注差异 |
| 仅一源 | 降级为「据XXX（机构）数据」限定表述，不做绝对断言 |
| 零来源 / 仅AI生成 | **删除该数据**，改为定性描述或换用可查证数据 |
| 来源互相矛盾 | 在文中呈现矛盾本身（反而成为内容亮点），不强行取一 |

## 3.2 常用权威数据源（大健康领域）

- 国家卫健委官网及统计公报、国家统计局年鉴
- WHO 世界卫生组织报告、柳叶刀/JAMA 等期刊（注意标注发表年份）
- 行业协会：中国健康管理协会、中国医师协会等
- 上市公司年报/招股书（如佛慈制药等医药企业，数据以公告为准）
- 头部咨询报告：艾瑞、亿欧、动脉网（标注为「第三方机构数据」）
- 政策文件：以 gov.cn 及部委官网发布为准，引用原文条款

## 3.3 数据引用格式（文中标注）

正文中数据一律带来源锚点，格式：

- 文章内：`据国家卫健委《2025中国卫生健康统计年鉴》，我国每千人拥有执业医师X人（蓝 #2196F3 锚点）`
- 来源清单：`数据点 | 数值 | 来源1（机构+年份+链接） | 来源2 | 结论`

## 3.4 事实核查清单（发布前逐项过）

- [ ] 所有数字都有来源标注
- [ ] 所有「第一/最大/唯一/领先」类极端词都有权威依据
- [ ] 政策表述与原文一致（不曲解、不夸大）
- [ ] 案例真实可查（自己经历 / 公开报道）
- [ ] 未使用禁用词（赚钱/月入/躺赚等）
- [ ] 医学健康类内容不含具体诊疗建议（个体差异，规避风险）
- [ ] 图片非AI幻觉图冒充实拍；AI生成图已标注

## 3.5 查证工具

- WebSearch：多关键词交叉搜索（话题词 + 数据/报告/年份）
- WebFetch：直接抓取权威页面核对原文
- 优先 gov.cn / 机构官网 / 原始报告 PDF
