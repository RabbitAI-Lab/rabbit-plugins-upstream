# 阶段2 · 内容生成方法论（双平台双版本）

目标：一套选题产出**公众号版 + 头条版**两份内容，各自适配平台规则。

## 2.1 公众号版（主稿）

### 结构：ABBB（心明增长实验室标准）

- **A - Attention（痛点开头）**：前 2-3 段击中读者，不用「在当今社会」式废话。直接场景化：一个具体的人、一个具体的瞬间、一句具体的抱怨。
- **B - Break down（案例拆解）**：用真实案例/数据拆解问题本质。案例必须是可查证的真实事件，禁止虚构。
- **B - Build up（方法工具）**：给出可复用的方法/框架/清单，这是「关注你」的理由。九力体系是天然的方法论武器库。
- **B - Behavior（行动引导）**：引导一个极小的行动（评论区回答一个问题 / 转发给一个人 / 关注回复关键词），不要大而空的「赶紧收藏」。

### 排版规范（公众号标准）

- 段落 3-5 行/段，行距 1.75，段后距 16-24px
- 配色体系（浅色主题内使用）：
  - 绿 #639922：维度标记/小标题
  - 紫 #534AB7：金句/标题强调
  - 蓝 #2196F3：关键数据锚点
- 金句单独成段，用紫色强调；数据单独成行，用蓝色锚点
- 全文 3000-5000 字为宜；配图 900×506（16:9）或 900×450（2:1）
- 文末按阶段5套用模板

### 标题规范

- 20-28 字，痛点/悬念/数字型
- 公式：热点×干货×情绪（三个元素至少占两个）
- 给出 3 个候选，按「稳妥型/冲突型/悬念型」分类供选

## 2.2 头条版（派生稿）

公众号稿**不能直接复制粘贴**到头条，必须适配：

| 维度 | 公众号 | 头条 |
|---|---|---|
| 标题 | 20-28字，含蓄 | 可到30字，直白给信息量，含关键词 |
| 首段 | 场景化铺垫 | 第一句话就要给核心结论（头条用户3秒流失） |
| 段落 | 3-5行 | 1-3行，多短段，多空行 |
| 小标题 | 意境化 | 必须含关键词（利于搜索推荐） |
| 导语 | 可选 | 必须（头条有导语位，写清「本文讲什么、谁该看」） |
| 关键词 | 自然 | 标题+首段+小标题埋词（头条SEO核心） |
| 图片 | 900×506 | 头条封面3:2（900×600），正文图9:16兼容 |
| 语气 | 陪伴式 | 更直接，信息密度更高 |

### 头条标题公式

`核心关键词 + 结果/冲突 + 数字或人群限定`，例：「大健康行业8年，我总结出IP变现的3个真实教训」。

## 2.3 内容真实性自检（写作时同步做）

- 每个数字必须能说出来源（记入阶段3清单）
- 每个案例必须真实（自己经历 or 公开报道可查）
- 每个断言必须有依据，无法验证的改用「据XXX报道」「部分从业者反馈」等限定
- 禁用词全程自查（config.forbidden_words）

## 2.4 交付物

```
02-文章-公众号.md    # 主稿：标题3候选 + 正文（含排版标记）+ 摘要
02-文章-头条.md      # 派生稿：标题3候选 + 导语 + 正文（头条优化）
```
