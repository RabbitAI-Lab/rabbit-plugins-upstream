🔄 更新与数据迁移

💡 关于数据持久性
你的所有数据都安全地保存在手机浏览器本地，不会丢失。

Teacher M console 部署在 CloudStudio 上，每次更新会换一个新网址。 旧网址仍然可以访问，数据也还在——只是不会自动同步到新版。
📋 更新步骤（只需 30 秒）
① 在当前版本中：我的 → 导出数据，下载 JSON 备份文件
② 打开新版本的网址
③ 新版会自动检测到你需要迁移数据，弹出导入提示
④ 选择刚才下载的 JSON 文件 → 数据全部恢复
⑤ 重新添加到主屏幕

🔗 从 WorkBuddy 导入计划

在 MacBook 上用 WorkBuddy 生成计划后，告诉它「导出为 Teacher M 导入格式」，它会生成一个 JSON 文件。

JSON 格式要求：

{
  "project": "搞七搞八",
  "planName": "社群运营7天计划",
  "tasks": [
    { "title": "Day 1: 建立社群规则", "deadline": "2026-08-01", "nextAction": "发布群公告" },
    { "title": "Day 2: 发布自我介绍模板", "deadline": "2026-08-02" }
  ]
}

导入后所有任务会自动创建到「搞七搞八」项目，状态为「待处理」。
