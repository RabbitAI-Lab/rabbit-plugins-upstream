## Description:

Travel Assistant helps Chinese-speaking users organize trip details and proactively check visas, weather, cultural norms, packing needs, emergency contacts, and other travel-preparation details.

This skill is ready for commercial/non-commercial use.

## Publisher:

[heidi1998](https://clawhub.ai/user/heidi1998)

### License/Terms of Use:

MIT-0

## Use Case:

External users use this skill as a Chinese-language travel planning assistant for building itinerary summaries, travel to-do lists, packing checklists, and destination-specific reminders.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Travel guidance may depend on current visa, entry, weather, safety, or local-policy information that can change.

Mitigation: Verify visas, entry rules, weather, and safety information through official sources before travel.

Risk: Using the skill may involve sharing trip details with the agent and using web search for current travel information.

Mitigation: Share only the trip details needed for planning and avoid unnecessary sensitive personal information.
