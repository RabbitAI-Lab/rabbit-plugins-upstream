## Description:

Helps teams design continuous testing for CI/CD pipelines, including staged test gates, tool integration strategies, and quality gate configuration.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kokxi](https://clawhub.ai/user/kokxi)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, QA engineers, and DevOps teams use this skill to add effective test stages to CI/CD pipelines, define quality gates, and improve feedback speed without overloading pipelines with slow UI tests.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: CI/CD and deployment examples may lead to unintended release, deployment, or production-setting changes if run without review.

Mitigation: Review generated pipeline guidance and commands before execution, confirm authorization, and verify rollback or canary strategy before applying changes.
