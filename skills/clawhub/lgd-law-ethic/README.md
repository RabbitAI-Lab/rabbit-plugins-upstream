# 法律AI伦理守门 / Legal AI Ethics Guard

The first cross-domain landing piece of the LGD three laws — translating "registered · evidenced · gated" into the compliance language of the "legal / law-firm and legal-department AI (research · drafting · opinion assistance)" domain.

## English

### Pain point
Legal AI easily oversteps into issuing formal legal opinions, cites unverifiable sources and lacks lawyer review — yet no tool maps the three laws onto the legal-ethics context.

### Quick start
```bash
python law_ethic.py --rubric
python law_ethic.py --system "your system description"
python law_ethic.py --answers '{...}' --json
```

### How the three laws map in this domain
- Registered → identity / version / source / responsible-party registration (this domain's terminology)
- Evidenced → six evidence artifact types (this domain's evidence types)
- Gated → trigger / review / release / retro four gates (this domain's thresholds)

### Competitive positioning
This skill is the **first-claim definition piece** of the "凡自治之物" standard in the legal / law-firm AI domain — others can copy the features, but not the definition power of the standard.

## 中文

LGD 三律跨域首占件 · 把"有籍·有证·有门禁"翻译进「法律 / 律所与法务 AI 应用（检索·起草·意见辅助）」本域合规语言。

### 痛点
法律AI易越界出具正式法律意见、引用不可核验、缺律师复核；市面无把三律映射到法律伦理语境的工具。

### 快速开始
```bash
python law_ethic.py --rubric
python law_ethic.py --system "你的系统描述"
python law_ethic.py --answers '{...}' --json
```

### 三律本域映射
- 有籍 → 身份/版本/来源/责任主体登记（本域术语）
- 有证 → 六类证据工件（本域证据类型）
- 有门禁 → 触发/评审/放行/复盘四道门禁（本域阈值）

### 竞争优势定位
本技能是"凡自治之物"标准在法律 / 律所与法务 AI 应用（检索·起草·意见辅助）域的**首占定义件**——别人可抄功能，抄不走标准定义权。
