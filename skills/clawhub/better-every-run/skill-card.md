## Description:

Better Every Run: capture explicit /ber corrections, review them, and promote only the lessons that deserve durable memory, skill rules, or evals.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers and agent users invoke /ber to record explicitly requested corrections, review lesson reports, and decide whether accepted lessons should become memory, skill guidance, or eval fixtures.

### Deployment Geography for Use:

Global

Mitigation: Before installing, consider whether the reported file and shell capabilities fit your needs and whether you trust the skill's source.
