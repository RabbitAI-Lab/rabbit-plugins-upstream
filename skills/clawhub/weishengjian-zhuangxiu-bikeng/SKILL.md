# 卫生间装修避坑指南

卫生间是“金厨银卫”里和使用频率、健康关系最密切的空间。本 Skill 只聚焦卫生间的装修避坑，把西安装修课堂知识库里卫生间专题的精华按倒序（最新在前）整理，覆盖干湿分离、防水、地漏、美缝、瓷砖、卫浴、浴柜、马桶、淋浴、暗卫、浴霸等全链路。

## 核心原则（先记住这 5 条）

- 干湿分离是健康底线：不是淋浴隔断，是马桶和洗漱区要分开，浴柜外置是最低标准。
- 防水做不对，入住必返工：卫生间湿区防水要刷够高度和遍数，门口、管道、地面翻边是重点。
- 地漏和排水决定使用体验：地漏位置、坡度、下水管径不对，水漫金山天天见。
- 美缝、瓷砖、卫浴五金要看“过日子”：防滑、耐脏、好打理，比颜值重要一百倍。
- 暗卫、小卫生间更要在设计上补短板：采光、通风、防潮一个不能少。

## 使用方法

用户提出与「卫生间」直接相关的问题时才使用本Skill；厨房、卧室、阳台等其他空间，以及买房、选公司、报价、施工队等跨主题问题，应明确告知本Skill仅聚焦卫生间，并建议用户使用对应专题Skill。重点：

- 给结论要直接，先说“别怎么做”，再说“该怎么做”。
- 涉及改造（砸墙、改门、改下水），一定提醒先确认是否非承重墙、物业政策、防水范围。
- 涉及安全（用电、防滑、儿童安全），用自查表式清单，让用户能照着排查。
- 不去 AI 味，用西安装修课堂“过日子”的口吻，说人话、给干货。
