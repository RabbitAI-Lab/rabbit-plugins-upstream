## Description:

按文字描述或参考图生成商业电商图片，并支持多种生成模型。

This skill is ready for commercial/non-commercial use.

## Publisher:

[autoagc](https://clawhub.ai/user/autoagc)

### License/Terms of Use:

MIT-0

## Use Case:

电商运营者、设计师和内容创作者可用文字提示词或参考图生成商品图、场景图和概念图，并按需求选择生成模型。

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Reference images are uploaded to the generation service.

Mitigation: Upload only images you intend to share with that service.

Risk: Image generation can consume account credits.

Mitigation: Check the estimate and available balance before generating images.

Risk: CLI updates can change the installed software.

Mitigation: Pin a reviewed CLI version and review update commands before executing them.
