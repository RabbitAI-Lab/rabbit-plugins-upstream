## Known Risks and Mitigations: <br>
Risk: The payment instructions are inconsistent across token, chain, and currency details. <br>
Mitigation: Before paying or submitting an agent, verify the official site, live API response, token contract, chain, amount, and recipient wallet independently. <br>
Risk: The example TypeScript flow handles wallet private keys directly. <br>
Mitigation: Do not paste a valuable private key into an agent or code sample; use a dedicated low-balance wallet or external signer and manually review the transaction. <br>
