# 完整演示：一条流水账 → 领导版周报

> 展示 skill 四步怎么工作。示例业务做了脱敏。

---

## 第 1 步：建项目库（一次性）

**用户输入：**

```
项目名 | 目标是什么 | 预期结果 | 大概周期
客户项目A（AI×电商提效） | 帮客户把 AI 落地到电商团队日常 | 9 月底前交付第一轮工具集 | 3 个月
合伙人项目B（内容电商课） | 把方法论做成可交付的课 | 11 月前上线第一版 | 4 个月
个人IP | 持续输出 AI 实操内容 | 粉丝稳定增长 | 长期
```

**AI 记录：** 已记住 3 个项目，作为后续每周周报的上下文。

---

## 第 2 步：丢流水账

**用户输入（碎碎念）：**

```
这周挺忙的。周一去客户那边开了会，把他们仓库的流程捋了一遍，发现他们装了一堆 AI 工具但没人用。周二帮李解把课的大纲过了一遍，砍掉了一章。周三自己拍了两条视频，一条发票整理的一条接 deepseek 的，都还行。周四给客户写了份报告，讲 AI 落地顺序。周五有个客户问我要报价，我还没回。对了，我自己的那个公众号这周没更。
```

**AI 拆事归位：**

| 事实颗粒 | 归属项目 |
| --- | --- |
| 客户现场会，梳理仓库流程，发现工具装了没人用 | 客户项目A |
| 给客户写 AI 落地顺序报告 | 客户项目A |
| 客户问报价未回 | 客户项目A |
| 帮李解过课大纲，砍掉一章 | 合伙人项目B |
| 拍两条视频（发票整理、接 deepseek） | 个人IP |
| 公众号没更 | 个人IP（主动补一句，不追问） |

---

## 第 3 步：只补缺的（AI 最多问 3 个问题）

**AI 追问：**

```
项目库 + 流水账能推断的我先写进草稿了。还差三处，需要你补：

1. 客户项目A：工具装了没人用，这个问题你判断的核心原因是什么？（你上周说过要动"顺序"，这周有结论吗？）
2. 客户项目A：报价的事，你的意向是接还是再看？
3. 合伙人项目B：课大纲砍掉的那一章，是为什么砍？下周推进的重点是什么？
```

**用户回答：**

```
1. 核心原因是判断和执行没分开，老板买了工具让员工自己用，没有先把流程拆出来。我报告里写的核心就是"先拆流程再上工具"。
2. 报价先报过去，对方预算够，但我还在评估他们是不是真想落地。
3. 砍掉的是纯理论章，学员要的是能直接跟做的。下周把工具实操部分写细。
```

---

## 第 4 步：输出领导版周报

```
# 本周周报（第 34 周）

【领导速览】客户项目A 进入交付关键期，已定位"工具没落地"的根因是流程未拆分，报告已交付，报价推进中；合伙人项目B 大纲瘦身完成，转向实操导向；个人IP 两条视频数据不错，公众号需恢复更新。

## 客户项目A：AI×电商提效（当前 60%，本周 45%→60%）
- 背景：帮客户把 AI 真正落地到电商团队日常，目标 9 月底交付第一轮工具集
- 本周产出：完成仓库流程现场调研；交付《AI 落地顺序》报告，核心结论是"先拆流程、再上工具"，已定位客户"工具装了没人用"的根因
- 风险：客户报价意向待确认，对方预算充足但落地意愿待评估
- 下周：推进报价确认；把报告结论转成第一轮工具集的落地清单
- 思考：客户买的不是工具是顺序。装了不用的根因几乎都是"判断和执行没分开"，这可以沉淀成一套可复用的诊断方法

## 合伙人项目B：内容电商课（当前 35%，本周 30%→35%）
- 背景：把方法论做成可交付的课程，11 月前上线第一版
- 本周产出：大纲瘦身完成，砍掉纯理论章
- 风险：无
- 下周：把工具实操部分写细，作为课程主体
- 思考：学员要的是能直接跟做的，不是理论框架，课程结构应围绕"实操路径"而非"知识体系"

## 个人IP：持续输出（当前 常态）
- 背景：个人 IP 持续输出 AI 实操内容
- 本周产出：两条视频（发票整理、接 deepseek），数据表现良好
- 风险：公众号停更一周，需恢复
- 下周：恢复公众号更新；按爆款节奏继续两条实操视频
- 思考：爆款内容集中在"具体工作流"，与既定方向一致，继续加码

## 需要领导支持
- 客户项目A 报价若确认，需要协助评估合同边界
```

---

## 对比效果

| | 普通版 | 领导版 |
| --- | --- | --- |
| 领导读完 | 知道你很忙，不知道项目咋样 | 30 秒掌握全部项目状态 |
| 背景 | 无 | 每项目一句话说清 |
| 进度 | 无 | 每项目有百分比和本周增量 |
| 风险 | 无 | 报价待确认、公众号停更都标出 |
| 判断 | 无 | 三条真思考，能看出你值不值钱 |
| 可发出 | 不敢发 | 直接发 |

关键点：**每一个字都有出处**，要么来自项目库，要么来自用户补充，AI 没有编造任何东西。
