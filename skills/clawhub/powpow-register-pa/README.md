# powpow-register

PowPow ਬਬਲ ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਮਦਦਗਾਰ (OpenClaw ਵਰਜਨ): ਨਵੇਂ ਵਰਤੋਂਕਾਰ ਨੂੰ «ਬਬਲ ਕੀ ਹੈ» ਨਾ ਜਾਣਨ ਤੋਂ
«ਖਾਤਾ ਸਰਗਰਮ, ਠੀਕ ਨਾਲ ਵਰਤ ਸਕਦੇ ਹੋ» ਤੱਕ ਲੈ ਜਾਂਦਾ ਹੈ — ਪ੍ਰੋਡਕਟ ਜਾਣ-ਪਛਾਣ (ਇੰਟਰਫੇਸ ਸਕ੍ਰੀਨਸ਼ਾਟਾਂ ਸਮੇਤ), ਕਦਮ-ਦਰ-ਕਦਮ ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਰਹਿਨੁਮਾ, ਗਲਤੀ ਜਾਂਚ,
ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਐਕਟੀਵੇਸ਼ਨ ਦੀ ਵਿਆਖਿਆ।

ਪੂਰੀ ਗਾਈਡੈਂਸ ਵਾਲੀ skill, ਕੋਈ ਸਕ੍ਰਿਪਟ ਜਾਂ ਨਿਰਭਰਤਾ ਨਹੀਂ; ਸਾਰੇ ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਕੰਮ ਵਰਤੋਂਕਾਰ ਬ੍ਰਾਊਜ਼ਰ/ਐਪ ਵਿੱਚ ਕਰਦਾ ਹੈ।

## ਇੰਸਟਾਲ

```
openclaw skills install @durenzidu/powpow-register
```

## ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ

1. **ਪ੍ਰੋਡਕਟ ਜਾਣ-ਪਛਾਣ**: ~120 ਸ਼ਬਦਾਂ ਦਾ ਆਰੰਭ + GitHub ਜਨਤਕ ਰਿਪੋਜ਼ਟਰੀ ਵਿੱਚ ਹੋਸਟਡ ਇੰਟਰਫੇਸ ਸਕ੍ਰੀਨਸ਼ਾਟ ਲਿੰਕ
   (ਨਕਸ਼ਾ ਪੰਨਾ, ਪੋਸਟ ਵੇਰਵਾ ਪੰਨਾ ਆਦਿ 6 ਫੋਟੋ, ਸਥਿਤੀ ਅਨੁਸਾਰ 1–3 ਚੁਣ ਕੇ ਭੇਜੋ)।
2. **ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਰਹਿਨੁਮਾ**: ਫੀਲਡ ਨਿਯਮ (ਯੂਜ਼ਰਨੇਮ/ਪਾਸਵਰਡ/ਈਮੇਲ ਤਸਦੀਕੀ ਕੋਡ/ਫ਼ੋਨ ਨੰਬਰ/ਪ੍ਰੋਫਾਈਲ ਫੋਟੋ), ਤੀਜੀ ਧਿਰ ਲਾਗਇਨ
   (Google/Watcha/Huawei), ਰੇਟ ਲਿਮਿਟ ਪੈਰਾਮੀਟਰ, ਸਾਰੇ ਪਲੇਟਫਾਰਮ ਸਰੋਤ ਕੋਡ ਤੋਂ ਲਏ ਗਏ ਅਤੇ ਸਰੋਤ ਲਿਖਿਆ ਹੋਇਆ।
3. **ਗਲਤੀ ਜਾਂਚ**: ਤਸਦੀਕੀ ਕੋਡ ਨਾ ਆਉਣਾ, ਯੂਜ਼ਰਨੇਮ/ਈਮੇਲ ਵਰਤੇ ਗਏ, 403 ਸਰਗਰਮ ਨਹੀਂ, ਖਾਤਾ ਲਾਕ ਆਦਿ
   13 ਆਮ ਸਮੱਸਿਆਵਾਂ।
4. **ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਐਕਟੀਵੇਸ਼ਨ**: PayPal (ਵੈੱਬ) / WeChat ਸਕੈਨ (ਦਸਤੀ ਤਸਦੀਕ) / Huawei IAP (HarmonyOS) ਤਿੰਨ
   ਚੈਨਲਾਂ ਦੀ ਵਿਆਖਿਆ ਅਤੇ ਜਾਂਚ; ਮੌਜੂਦਾ ਭੁਗਤਾਨ ਦਾ ਕ੍ਰਮ ਸਿੱਧਾ ਮੁੜ ਵਰਤਿਆ ਜਾ ਸਕਦਾ ਹੈ, skill ਸਿਰਫ਼ ਰਸਤਾ ਦਿਖਾਉਂਦੀ ਹੈ।

## ਸੁਰੱਖਿਆ

- ਕੋਈ ਰਾਜ਼ ਦੀ ਕੁੰਜੀ ਨਹੀਂ; ਸਕ੍ਰਿਪਟ ਨਹੀਂ, ਵਰਤੋਂਕਾਰ ਦੀ ਪਛਾਣ ਨਾਲ ਕੋਈ ਸਬੰਧ ਨਹੀਂ।
- **ਕਦੇ ਵੀ** ਵਰਤੋਂਕਾਰ ਦਾ ਪਾਸਵਰਡ, ਕੋਡ ਜਾਂ ਭੁਗਤਾਨ ਦੀ ਪਛਾਣ ਨਾ ਮੰਗੋ; ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਅਤੇ ਭੁਗਤਾਨ ਸਾਰੇ ਪਲੇਟਫਾਰਮ ਪੰਨੇ ਉੱਤੇ ਪੂਰੇ ਹੁੰਦੇ ਹਨ।
