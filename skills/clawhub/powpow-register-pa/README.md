# powpow-register

PowPow ਬੁਲਬੁਲਾ ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਸਹਾਇਕ (OpenClaw ਵਰਜ਼ਨ): ਇੱਕ ਨਵੇਂ ਯੂਜ਼ਰ ਨੂੰ "ਬੁਲਬੁਲਾ ਕੀ ਹੈ, ਪਤਾ ਨਹੀਂ" ਤੋਂ "ਖਾਤਾ ਐਕਟੀਵੇਟ, ਇੱਕ-ਕਲਿੱਕ ਲੌਗਿਨ, ਖੇਡਣਾ ਸ਼ੁਰੂ" ਤੱਕ ਲਿਜਾਂਦਾ ਹੈ — ਪ੍ਰੋਡਕਟ ਜਾਣ-ਪਛਾਣ (ਇੰਟਰਫੇਸ ਸਕਰੀਨਸ਼ਾਟ ਸਮੇਤ), agent ਡੈਲੀਗੇਸ਼ਨ ਰਜਿਸਟ੍ਰੇਸ਼ਨ (ਅਵਤਾਰ ਅੱਪਲੋਡ ਸਮੇਤ), Alipay/PayPal ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਆਰਡਰ ਅਤੇ ਪੈਸੇ ਆਉਣ ਦੀ ਨਿਗਰਾਨੀ, ਦੋ ਲਿੰਕਾਂ ਵਾਲਾ ਇੱਕ-ਕਲਿੱਕ ਲੌਗਿਨ, ਗਲਤੀ-ਨਿਪਟਾਰਾ।

**v2.0.0 ਤੋਂ ਇਹ ਏਜੰਟ-ਸਹਾਇਕ ਮੋਡ ਹੈ, ਅਤੇ v2.2.0 ਤੋਂ ਪਲੇਟਫਾਰਮ ਦੀ ਮੁਫਤ ਪਰੀਖਣ ਅਵਧੀ ਨਾਲ ਅਨੁਕੂਲ ਬਣਦਾ ਹੈ**: ਕੋਰ ਸਕ੍ਰਿਪਟ `scripts/powpow-register.mjs` ਸਿਫ਼ਰ-ਨਿਰਭਰਤਾ ਵਾਲੀ ਹੈ
(Node ≥ 18); ਵਰਤੋਂਕਾਰ ਗੱਲਬਾਤ ਸਿਰਫ਼ ਇੱਕ ਵਾਰ ਛੱਡਦਾ ਹੈ: ਇਨਬੌਕਸ ਵਿੱਚ ਤਸਦੀਕ ਕੋਡ ਦੇਖਣ ਲਈ। ਮੌਜੂਦਾ ਮੁਫਤ ਪਰੀਖਣ ਅਵਧੀ ਵਿੱਚ, ਰਜਿਸਟਰ ਹੋਇਆ ਖਾਤਾ ਸਾਰੀਆਂ ਸੁਵਿਧਾਵਾਂ ਤੁਰੰਤ ਵਰਤ ਸਕਦਾ ਹੈ — ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਭੁਗਤਾਨ ਵਿਕਲਪਿਕ ਅੱਪਗ੍ਰੇਡ ਹੈ; ਜੇ ਪਰੀਖਣ ਅਵਧੀ ਖ਼ਤਮ ਹੋਵੇ ਅਤੇ ਵਰਤੋਂਕਾਰ ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਪੇਜ ਉੱਤੇ ਉਤਰੇ, ਪ੍ਰਵਾਹ ਸਵੈ-ਸੰਚਾਲਿਤ ਢੰਗ ਨਾਲ ਭੁਗਤਾਨ ਪਾਥ ਉੱਤੇ ਸਵਿੱਚ ਹੋ ਜਾਂਦਾ ਹੈ. Node ਤੋਂ ਬਿਨਾਂ, ਜਾਂ ਵਰਤੋਂਕਾਰ ਖੁਦ ਕਰਨਾ ਚਾਹੇ, ਤਾਂ ਸਵੈ-ਸੰਚਾਲਿਤ ਢੰਗ ਨਾਲ ਸ਼ੁੱਧ ਮਾਰਗਦਰਸ਼ਨ ਮੋਡ ਉੱਤੇ ਵਾਪਸ ਆ ਜਾਂਦਾ ਹੈ।

## ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ

1. **ਪ੍ਰੋਡਕਟ ਜਾਣ-ਪਛਾਣ**: ~120 ਸ਼ਬਦਾਂ ਦੀ ਸ਼ੁਰੂਆਤ + ਸਕਿਲ ਨਾਲ ਪੈਕ ਇੰਟਰਫੇਸ ਸਕਰੀਨਸ਼ਾਟ (`assets/screenshots/` ਵਿੱਚ 6 ਤਸਵੀਰਾਂ: ਨਕਸ਼ਾ ਪੰਨਾ, ਪੋਸਟ ਵੇਰਵਾ ਪੰਨਾ ਆਦਿ, ਹਾਲਤ ਮੁਤਾਬਕ 1–3 ਭੇਜੋ; ਬਾਹਰੀ ਇਮੇਜ਼-ਹੋਸਟ ਦੀ ਲੋੜ ਨਹੀਂ, ਆਫ਼ਲਾਈਨ ਵੀ ਕੰਮ ਕਰਦੀਆਂ ਹਨ)।
2. **ਡੈਲੀਗੇਸ਼ਨ ਰਜਿਸਟ੍ਰੇਸ਼ਨ**: agent ਯੂਜ਼ਰਨੇਮ/ਉਪਨਾਮ ਆਪ ਸੁਝਾਉਂਦਾ ਹੈ, ਪਾਸਵਰਡ ਦੋ-ਵਿਕਲਪ (ਯੂਜ਼ਰ ਦੇਵੇ ਜਾਂ agent ਬਣਾਵੇ), ਪੁਸ਼ਟੀਕਰਨ ਕੋਡ ਭੇਜਣ ਅਤੇ ਜਮ੍ਹਾਂ ਕਰਨ, ਅਵਤਾਰ ਡਾਇਰੈਕਟ ਅੱਪਲੋਡ (≤5MB ਗ਼ੈਰ-SVG), ਆਮ ਗਲਤੀਆਂ ਆਪਣੇ-ਆਪ ਸੰਭਾਲਣਾ (ਵਿਅਸਤ/ਮਿਆਦ ਪੁੱਗੀ/ਰੇਟ-ਲਿਮਿਟ)।
3. **ਇੱਕ-ਕਲਿਕ ਲੌਗਇਨ (ਦੋ ਲਿੰਕ)**: ਸਫਲ ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਤੋਂ ਤੁਰੰਤ ਬਾਅਦ, ਲੌਗਇਨ ਲਿੰਕ ਵਰਤੋਂਕਾਰ ਨੂੰ ਸਿੱਧਾ ਹੋਮ ਪੇਜ ਉੱਤੇ ਲੈ ਜਾਂਦਾ ਹੈ (ਮੁਫਤ ਪਰੀਖਣ ਅਵਧੀ ਵਿੱਚ, ਇੱਕ ਕਲਿਕ ਵਿੱਚ ਵਰਤਿਆ ਜਾ ਸਕਦਾ ਹੈ);
   ਜੇ ਉਹ ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਪੇਜ ਉੱਤੇ ਉਤਰਦਾ ਹੈ (ਪਰੀਖਣ ਅਵਧੀ ਖ਼ਤਮ) ਜਾਂ ਵਰਤੋਂਕਾਰ ਅੱਪਗ੍ਰੇਡ ਕਰਨਾ ਚਾਹੇ, ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਪ੍ਰਵਾਹ ਫੋਲੋ ਕਰੋ — ਭੁਗਤਾਨ ਆਉਣ ਤੋਂ ਬਾਅਦ, ਤਾਜ਼ੀ ਲੌਗਇਨ ਸਥਿਤੀ ਬਦਲੀ ਜਾਂਦੀ ਹੈ ਅਤੇ ਪੂਰਾ-ਮੈਂਬਰਸ਼ਿਪ ਲਿੰਕ ਹੋਮ ਪੇਜ ਉੱਤੇ ਲੈ ਜਾਂਦਾ ਹੈ
   (ਪਲੇਟਫਾਰਮ ਦੇ ਔਪਚਾਰਿਕ `me?token=` ਪੁਲ ਰਾਹੀਂ, ਜੋ HttpOnly ਕੂਕੀ ਸਵੈ-ਸੰਚਾਲਿਤ ਢੰਗ ਨਾਲ ਪਲਾਂਟ ਕਰਦਾ ਹੈ)।
4. **ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਪੇਮੈਂਟ**: Alipay (ਮਾਸਿਕ ¥6.99 / ਤਿਮਾਹੀ ¥19.99 / ਸਾਲਾਨਾ ¥69.99, ਇੱਕ ਵਾਰੀ ਦੀ ਖਰੀਦ, ਆਪਣੇ-ਆਪ ਨਵਿਆਉਣ ਨਹੀਂ) ਅਤੇ PayPal (Premium Monthly, ਲਗਭਗ $1/ਮਹੀਨਾ, ਆਪਣੇ-ਆਪ ਨਵਿਆਉਣ, ਕਦੇ ਵੀ ਰੱਦ) ਦੋਵਾਂ ਤੇ agent ਆਰਡਰ ਬਣਾਉਂਦਾ ਹੈ + ਪੈਸੇ ਆਉਣ ਦੀ ਪੋਲਿੰਗ; WeChat QR / Huawei IAP ਲਈ ਰਾਹ ਦਿਖਾਉਣਾ।
5. **ਗਲਤੀ-ਨਿਪਟਾਰਾ**: ਪੁਸ਼ਟੀਕਰਨ ਕੋਡ ਨਾ ਮਿਲਣਾ, ਯੂਜ਼ਰਨੇਮ/ਈਮੇਲ ਵਿਅਸਤ ਹੋਣਾ, 403 ਐਕਟੀਵੇਟ ਨਾ ਹੋਣਾ, ਖਾਤਾ ਲੌਕ ਹੋਣਾ ਆਦਿ ਆਮ ਸਮੱਸਿਆਵਾਂ, ਸਭ ਪਲੇਟਫਾਰਮ ਸਰੋਤ ਕੋਡ ਤੋਂ ਅਤੇ ਹਵਾਲੇ ਸਮੇਤ।

## ਸੁਰੱਖਿਆ

- **ਪਾਸਵਰਡ** ਸਿਰਫ਼ ਵਾਤਾਵਰਣ ਵੇਰੀਏਬਲ ਰਾਹੀਂ ਸਕ੍ਰਿਪਟ ਪ੍ਰੋਸੈਸ ਵਿੱਚ ਜਾਂਦਾ ਹੈ, ਕਦੇ ਕਮਾਂਡ-ਲਾਈਨ ਆਰਗੂਮੈਂਟ ਵਿੱਚ ਨਹੀਂ ਲਿਖਿਆ ਜਾਂਦਾ, ਡਿਸਕ ਤੇ ਨਹੀਂ ਲਿਖਿਆ ਜਾਂਦਾ, ਸਟੇਟ ਫਾਈਲ ਵਿੱਚ ਨਹੀਂ ਜਾਂਦਾ; agent ਵੱਲੋਂ ਬਣਾਇਆ ਪਾਸਵਰਡ ਸਿਰਫ਼ ਇੱਕ ਵਾਰ ਦਿਖਾਇਆ ਜਾਂਦਾ ਹੈ ਤਾਂ ਜੋ ਯੂਜ਼ਰ ਸੰਭਾਲ ਲਵੇ।
- **ਪੁਸ਼ਟੀਕਰਨ ਕੋਡ** ਸਿਰਫ਼ ਅਧਿਕਾਰਤ ਰਜਿਸਟ੍ਰੇਸ਼ਨ API ਲਈ ਹੈ, ਵਰਤੋਂ ਤੋਂ ਬਾਅਦ ਸੁੱਟ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ; ਸਟੇਟ ਫਾਈਲ (ਈਮੇਲ/ਯੂਜ਼ਰਨੇਮ/token/ਆਰਡਰ ਨੰਬਰ) ਸਿਸਟਮ ਆਰਜ਼ੀ ਡਾਇਰੈਕਟਰੀ ਵਿੱਚ ਰਹਿੰਦੀ ਹੈ, ਪ੍ਰਕਿਰਿਆ ਖਤਮ ਹੋਣ ਤੇ `cleanup` ਇੱਕ ਕਲਿੱਕ ਵਿੱਚ ਮਿਟਾ ਦਿੰਦਾ ਹੈ।
- **ਪੇਮੈਂਟ**: agent ਸਿਰਫ਼ ਆਰਡਰ ਬਣਾਉਂਦਾ ਹੈ, ਕੈਸ਼ੀਅਰ ਖੋਲ੍ਹਦਾ ਹੈ, ਪੈਸੇ ਆਉਣ ਦੀ ਪੁੱਛਗਿੱਛ ਕਰਦਾ ਹੈ; ਯੂਜ਼ਰ ਦੇ Alipay/PayPal ਖਾਤੇ ਜਾਂ ਪੇਮੈਂਟ ਪ੍ਰਮਾਣ ਨੂੰ ਕਦੇ ਨਹੀਂ ਛੂਹਦਾ, ਕਦੇ ਤੇਰੀ ਥਾਂ ਪੈਸੇ ਨਹੀਂ ਦੇਂਦਾ। ਪੇਮੈਂਟ ਹਮੇਸ਼ਾ ਯੂਜ਼ਰ ਅਤੇ ਅਧਿਕਾਰਤ ਕੈਸ਼ੀਅਰ ਵਿਚਕਾਰ ਹੁੰਦੀ ਹੈ।
- ਸਾਰੀਆਂ ਬੇਨਤੀਆਂ ਸਿਰਫ਼ ਅਧਿਕਾਰਤ ਡੋਮੇਨ `https://global.powpow.online` ਨੂੰ ਜਾਂਦੀਆਂ ਹਨ; ਕੋਈ ਗੁਪਤ ਕੁੰਜੀ ਸ਼ਾਮਲ ਨਹੀਂ।
