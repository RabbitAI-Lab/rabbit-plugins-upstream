# Agent ਡੈਲੀਗੇਸ਼ਨ ਪ੍ਰਕਿਰਿਆ ਅਤੇ ਸਕ੍ਰਿਪਟ ਕੰਟਰੈਕਟ — powpow-register

SKILL.md ਦੇ ਹਰ ਕਦਮ ਦੇ ਲਾਗੂ ਕਰਨ ਦੇ ਵੇਰਵੇ। ਸਾਰੀਆਂ ਕਮਾਂਡਾਂ ਇਹ ਹਨ: `node scripts/powpow-register.mjs <ਉਪ-ਕਮਾਂਡ> [ਪੈਰਾਮੀਟਰ]`, ਸਕ੍ਰਿਪਟ **ਜ਼ੀਰੋ-ਡਿਪੈਂਡੈਂਸੀ** ਹੈ, **Node ≥ 18** ਚਾਹੀਦਾ ਹੈ, ਸਾਰੀਆਂ ਬੇਨਤੀਆਂ ਸਿਰਫ਼ `https://global.powpow.online` ਨੂੰ ਜਾਂਦੀਆਂ ਹਨ।

## ਦੋ-ਲਿੰਕ ਮਕੈਨਿਜ਼ਮ (ਕੋਰ ਡਿਜ਼ਾਈਨ)

ਪਲੇਟਫਾਰਮ ਦੀ ਲੌਗਇਨ ਸਥਿਤੀ ਇੱਕ HttpOnly ਕੂਕੀ ਹੈ, ਜੋ ਏਜੰਟ ਸਿੱਧਾ ਬ੍ਰਾਊਜ਼ਰ ਵਿੱਚ ਪਲਾਂਟ ਨਹੀਂ ਕਰ ਸਕਦਾ; ਪੁਲ ਔਪਚਾਰਿਕ
`/api/auth/me?token=<JWT>&redirect=<ਸਾਈਟ-ਅੰਦਰਨਾ ਪਾਥ>` ਐਂਡਪੌਇੰਟ ਹੈ: ਦਸਤਖਤ ਚੈੱਕ ਕਰੋ → ਆਟੋ-ਕਰੀਏਟ
ਸੈਸ਼ਨ → `Set-Cookie: powpow_token` (HttpOnly / SameSite=Lax / 7 ਦਿਨ) → ਰੀਡਾਇਰੈਕਟ
ਵੈਧ ਕਰੋ (ਇੱਕਲੇ ਸਲੈਸ਼ ਨਾਲ ਸ਼ੁਰੂ ਹੋਣਾ ਚਾਹੀਦਾ ਹੈ, `//` ਅਤੇ ਬੈਕਸਲੈਸ਼ ਮਨਾਈ ਹਨ, ਪਾਰਸ ਕਰਨ ਤੋਂ ਬਾਅਦ same-origin ਹੋਣਾ ਚਾਹੀਦਾ ਹੈ) → ਟੀਚਾ ਪੇਜ ਉੱਤੇ 307 ਆਰਜ਼ੀ ਰੀਡਾਇਰੈਕਟ।

ਲਿੰਕ ਦੇ ਦੋ ਟੀਚੇ ਹਨ, **ਪਹਿਲਾਂ home ਜਨਰੇਟ ਕਰੋ, ਫਿਰ ਵਰਤੋਂਕਾਰ ਕਿੱਥੇ ਉਤਰਿਆ ਉੱਤੇ ਆਧਾਰਿਤ pending ਤੋਂ ਜਾਣ ਦਾ ਫ਼ੈਸਲਾ ਕਰੋ**:

- **home ਲਿੰਕ (ਡਿਫ਼ਾਲਟ ਰੂਪ ਵਿੱਚ ਭੇਜਿਆ ਜਾਂਦਾ ਹੈ, `--target home` → `/` ਉੱਤੇ ਉਤਰਦਾ ਹੈ)**: ਸਫਲ ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਤੋਂ ਤੁਰੰਤ ਬਾਅਦ ਜਨਰੇਟ ਹੋ ਕੇ ਵਰਤੋਂਕਾਰ ਨੂੰ ਭੇਜਿਆ ਜਾਂਦਾ ਹੈ।
  ਮੁਫਤ ਪਰੀਖਣ ਅਵਧੀ ਵਿੱਚ ਵਰਤੋਂਕਾਰ ਸਿੱਧਾ ਹੋਮ ਪੇਜ ਉੱਤੇ ਜਾਂਦਾ ਹੈ, ਪੂਰਾ ਉਪਯੋਗੀ; **ਜੇ ਉਹ ਲਿੰਕ ਕਲਿਕ ਕਰਦਾ ਹੈ ਪਰ ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਪੇਜ ਉੱਤੇ ਉਤਰਦਾ ਹੈ — ਮੁਫਤ ਪਰੀਖਣ ਅਵਧੀ ਖ਼ਤਮ ਹੋ ਗਈ** — ਭੁਗਤਾਨ ਪ੍ਰਵਾਹ ਉੱਤੇ ਸਵਿੱਚ ਕਰੋ (ਹੇਠਾਂ ਦੇਖੋ); ਸਕ੍ਰਿਪਟ ਬਦਲਣ ਅਤੇ ਦੁਬਾਰਾ ਰਜਿਸਟਰ ਕਰਨ ਦੀ ਲੋੜ ਨਹੀਂ।
- **pending ਲਿੰਕ (ਭੁਗਤਾਨ ਪ੍ਰਵਾਹ ਵਿੱਚ ਵਰਤਿਆ ਜਾਂਦਾ ਹੈ, `--target pending` → `/subscription` ਉੱਤੇ ਉਤਰਦਾ ਹੈ)**:
  ਵਰਤੋਂਕਾਰ ਦਾ ਬ੍ਰਾਊਜ਼ਰ "ਅੱਧਾ-ਲੌਗਇਨ" ਸਥਿਤੀ ਵਿੱਚ ਦਾਖਲ ਹੁੰਦਾ ਹੈ: ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਪੇਜ ਅਤੇ ਭੁਗਤਾਨ ਵਾਪਸੀ ਪੇਜ ਦ੍ਰਿਸ਼ਮਾਨ ਅਤੇ ਓਪਰੇਬਲ। ਭੁਗਤਾਨ ਆਉਣ ਤੋਂ ਬਾਅਦ,
  ACTIVE ਕਲੇਮ ਨਾਲ ਨਵੇਂ JWT ਲਈ `refresh-login` ਚਲਾਓ, ਫਿਰ ਪੂਰੀ ਮੈਂਬਰਸ਼ਿਪ ਸਥਿਤੀ ਲਈ home ਲਿੰਕ ਫਿਰ ਭੇਜੋ।

## ਪੂਰਾ ਕ੍ਰਮ

### ਫਾਸਟ ਪਾਥ (ਮੁਫਤ ਪਰੀਖਣ ਅਵਧੀ ਵਿੱਚ — ਵੱਡੇ ਹਿੱਸੇ ਦੇ ਕੇਸ)

```
1.  status                          # ਪਰਿਆਵਰਣ ਸੈਲਫ-ਚੈੱਕ
2.  (ਕਦਮ 2 ਗੱਲਬਾਤ ਜਾਣਕਾਰੀ ਦੀ ਪੁਸ਼ਟੀ, ਪਾਸਵਰਡ ਕਿਸੇ ਵੀ; ਜਨਰੇਸ਼ਨ ਮੋਡ: gen-password → ਵਰਤੋਂਕਾਰ ਨੂੰ ਤੁਰੰਤ ਸੇਵ ਕਰਨ ਲਈ ਕਹੋ)
3.  prepare-suggest --username U --nickname N --email E
4.  send-code --email E             # → ਵਰਤੋਂਕਾਰ ਇਨਬੌਕਸ ਵਿੱਚ ਕੋਡ ਚੈੱਕ ਕਰੇ (ਗੱਲਬਾਤ ਛੱਡਣ ਦਾ ਇੱਕੋ-ਇੱਕ ਸਮਾਂ)
5.  POWPOW_REGISTER_PASSWORD=*** register --code 123456 [--avatar pic.jpg]
6.  login-link --target home        # → ਲਿੰਕ ਵਰਤੋਂਕਾਰ ਨੂੰ ਭੇਜੋ; ਇੱਕ ਕਲਿਕ ਵਿੱਚ ਹੋਮ ਪੇਜ ਉੱਤੇ
7.  (ਵਰਤੋਂਕਾਰ ਪੁਸ਼ਟੀ ਕਰਦਾ ਹੈ ਕਿ ਅੰਦਰ ਹੈ) → ਸਿੱਧਾ ਸਮਾਪਨ: cleanup + ਖਾਤਾ ਕਾਰਡ + ਪਹਿਲੇ ਕਦਮ ਦਿਖਾਓ
```

### ਭੁਗਤਾਨ ਪਾਥ (ਜਦੋਂ ਵਰਤੋਂਕਾਰ ਮੈਂਬਰਸ਼ਿਪ ਚਾਹੇ, ਜਾਂ ਮੁਫਤ ਪਰੀਖਣ ਅਵਧੀ ਖ਼ਤਮ ਹੋਵੇ)

```
1–5. ਫਾਸਟ ਪਾਥ ਵਰਗਾ ਹੀ (register ਸਫਲ ਹੋਣ ਤੋਂ ਬਾਅਦ ਸਥਿਤੀ ਵਿੱਚ ਪਹਿਲਾਂ ਹੀ ਟੋਕਨ ਹੁੰਦਾ ਹੈ)
6.  login-link --target pending     # → ਅੱਧਾ-ਲੌਗਇਨ ਲਿੰਕ, ਭੁਗਤਾਨ ਵਾਪਸੀ ਪੇਜ ਨੂੰ ਕੰਮ ਕਰਦਾ ਰੱਖਦਾ ਹੈ
7.  (ਵਰਤੋਂਕਾਰ ਭੁਗਤਾਨ ਦਾ ਢੰਗ ਚੁਣਦਾ ਹੈ)
    # Alipay: create-order --package monthly|quarterly|yearly
    # PayPal: create-order --provider paypal
8.  start <ਭੁਗਤਾਨ ਪੇਜ ਫਾਈਲ>       # Windows; macOS ਉੱਤੇ open, Linux ਉੱਤੇ xdg-open
    # → ਵਰਤੋਂਕਾਰ Alipay/PayPal ਕੈਸ਼ੀਅਰ ਉੱਤੇ ਭੁਗਤਾਨ/ਪ੍ਰਮਾਣੀਕਰਨ ਪੂਰਾ ਕਰਦਾ ਹੈ (ਗੱਲਬਾਤ ਛੱਡਦਾ ਹੈ)
9.  query (ਹਰ 10–15s) ਜਦੋਂ ਤੱਕ paid / ACTIVE
10. refresh-login                   # ACTIVE ਕਲੇਮ ਨਾਲ ਨਵੇਂ JWT ਲਈ ਬਦਲੋ
11. login-link --target home        # → ਪੂਰਾ-ਮੈਂਬਰਸ਼ਿਪ ਲਿੰਕ ਵਰਤੋਂਕਾਰ ਨੂੰ ਭੇਜੋ
12. whoami                          # ਪੁਸ਼ਟੀ ਕਰੋ subscriptionStatus: ACTIVE (ਵਿਕਲਪਿਕ)
13. cleanup                         # ਸਥਿਤੀ ਫਾਈਲ ਸਾਫ਼ ਕਰੋ
```
## ਕਮਾਂਡ → ਪਲੇਟਫਾਰਮ API ਨਕਸ਼ਾ

| ਸਕ੍ਰਿਪਟ ਕਮਾਂਡ | ਪਲੇਟਫਾਰਮ ਐਂਡਪੁਆਇੰਟ |
|---|---|
| `send-code` | `POST /api/auth/register/send-code` |
| `register` | `POST /api/auth/register` (multipart, ਅਵਤਾਰ ਡਾਇਰੈਕਟ ਅੱਪਲੋਡ) |
| `login-link` | `GET /api/auth/me?token=…&redirect=…` (ਲਿੰਕ ਖੁਦ, ਯੂਜ਼ਰ ਕਲਿੱਕ ਕਰਨ ਤੇ ਲਾਗੂ ਹੁੰਦਾ ਹੈ) |
| `create-order` | `POST /api/payment/alipay/create-order` (Bearer, Alipay)<br>`GET /api/subscription/plans` + `POST /api/subscription/create` (Bearer, PayPal) |
| `query` | `GET /api/payment/alipay/query?outTradeNo=…` (Bearer, Alipay)<br>`GET /api/subscription/create` (Bearer, PayPal) |
| `refresh-login` | `POST /api/auth/login` (`{step:1, username, password}`) |
| `whoami` | `GET /api/auth/me?token=…` |

ਨਿਯਮਾਂ ਦਾ ਸਰੋਤ: ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਫੀਲਡ ਅਤੇ ਰੇਟ-ਲਿਮਿਟ ਲਈ `registration-flow.md` ਵੇਖੋ; ਪੈਕੇਜ ਅਤੇ ਐਕਟੀਵੇਸ਼ਨ ਲੜੀ ਲਈ
`payment-and-activation.md` ਵੇਖੋ (ਦੋਵਾਂ ਤੇ ਪਲੇਟਫਾਰਮ ਸਰੋਤ ਫਾਈਲਾਂ ਦੇ ਹਵਾਲੇ ਹਨ)।

## ਸਕ੍ਰਿਪਟ-ਪੱਧਰੀ ਗਲਤੀ ਨਿਪਟਾਰਾ

| ਨੈੱਟਵਰਕ ਗਲਤੀ / ਟਾਈਮਆਉਟ | ਇੱਕ ਵਾਰ ਦੁਬਾਰਾ ਕੋਸ਼ਿਸ਼; ਫਿਰ ਵੀ ਫੇਲ ਹੋਵੇ ਤਾਂ ਯੂਜ਼ਰ ਤੋਂ ਨੈੱਟਵਰਕ ਚੈੱਕ ਕਰਵਾਓ ਅਤੇ ਅੱਗੇ ਵਧੋ (ਸਟੇਟ ਫਾਈਲ ਅਜੇ ਵੀ ਹੈ, ਸ਼ੁਰੂ ਤੋਂ `status` ਚਲਾ ਕੇ ਮੁੜ-ਸ਼ੁਰੂ ਕਰੋ) |
| register ਕਾਰੋਬਾਰੀ ਗਲਤੀ ਦੇਵੇ (用户名已存在 ਆਦਿ) | SKILL.md ਕਦਮ 5 ਦੇ ਟੇਬਲ ਮੁਤਾਬਕ ਸੰਭਾਲੋ, **ਪੁਸ਼ਟੀਕਰਨ ਕੋਡ ਦੁਬਾਰਾ ਭੇਜਣ ਦੀ ਲੋੜ ਨਹੀਂ** (10 ਮਿੰਟ ਦੇ ਅੰਦਰ ਅਜੇ ਵੈਧ) |
| register 「邮箱验证码错误或已过期」ਦੇਵੇ | ਸਮਾਂ ਪਾਰ → ਦੁਬਾਰਾ `send-code` |
| `create-order` ਤੋਂ ਬਾਅਦ ਯੂਜ਼ਰ ਪੇਮੈਂਟ ਪੰਨਾ ਬੰਦ ਕਰ ਦੇਵੇ | ਸਿੱਧੇ ਦੁਬਾਰਾ `create-order` (ਪੁਰਾਣਾ ਆਰਡਰ 2h ਵਿੱਚ ਆਪ ਬੰਦ ਹੋ ਜਾਂਦਾ ਹੈ; PayPal PENDING ਸਬਸਕ੍ਰਿਪਸ਼ਨ 1h ਵਿੱਚ ਮਿਆਦ ਪੁੱਗ ਜਾਂਦੀ ਹੈ) |
| `create-order --provider paypal` 409 ਦਿੰਦਾ ਹੈ | ਇੱਕ ਅਧੂਰੀ PayPal ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਹੈ; 1h ਉਡੀਕੋ, ਜਾਂ ਪੁਰਾਣੀ ਮਨਜ਼ੂਰੀ ਬ੍ਰਾਊਜ਼ਰ ਵਿੱਚ ਪੂਰੀ ਕਰੋ |
| `query` ਲਗਾਤਾਰ pending / PENDING | ਸ਼ਾਇਦ ਯੂਜ਼ਰ ਨੇ ਪੈਸੇ ਨਹੀਂ ਦਿੱਤੇ; ਇੱਕ ਵਾਰ ਪੁੱਛੋ। ਸੱਚਮੁੱਚ ਦਿੱਤੇ ਹੋਣ → payment-and-activation.md ਦੇ ਨਿਪਟਾਰਾ ਟੇਬਲ ਮੁਤਾਬਕ ਚੱਲੋ |
| ਵਰਤੋਂਕਾਰ home ਲਿੰਕ ਕਲਿਕ ਕਰਦਾ ਹੈ ਪਰ ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਪੇਜ ਉੱਤੇ ਉਤਰਦਾ ਹੈ | ਮੁਫਤ ਪਰੀਖਣ ਅਵਧੀ ਖ਼ਤਮ ਹੋ ਗਈ → ਭੁਗਤਾਨ ਪ੍ਰਵਾਹ ਉੱਤੇ ਜਾਓ: `login-link --target pending` → ਭੁਗਤਾਨ ਦਾ ਢੰਗ ਚੁਣੋ → `create-order` |
| `refresh-login` 403 `pending_payment` | ਮੁਫਤ ਪਰੀਖਣ ਅਵਧੀ ਖ਼ਤਮ ਹੋ ਗਈ ਅਤੇ ਭੁਗਤਾਨ ਨਹੀਂ ਆਇਆ; ਕਦਮ 9 ਉੱਤੇ ਵਾਪਸ ਜਾ ਕੇ ਪੋਲਿੰਗ ਜਾਰੀ ਰੱਖੋ, ਜਾਂ ਪੁਸ਼ਟੀ ਕਰੋ ਕਿ ਵਰਤੋਂਕਾਰ ਨੇ ਭੁਗਤਾਨ ਪੂਰਾ ਕੀਤਾ |
| ਸਟੇਟ ਫਾਈਲ ਗੁੰਮ (ਗ਼ਲਤੀ ਨਾਲ ਮਿਟ ਗਈ / ਮਸ਼ੀਨ ਬਦਲੀ) | `whoami`/`refresh-login` ਵਰਤੇ ਨਹੀਂ ਜਾ ਸਕਦੇ; ਯੂਜ਼ਰ ਤੋਂ ਕਹੋ ਕਿ ਲਿੰਕ 1 ਖੋਲ੍ਹਣ ਵਾਲੇ ਬ੍ਰਾਊਜ਼ਰ ਵਿੱਚ ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਪੰਨਾ ਰੀਫਰੈਸ਼ ਕਰਕੇ ਸਥਿਤੀ ਪੱਕੀ ਕਰੇ, ਜਾਂ ਦੁਬਾਰਾ ਲੌਗਿਨ ਕਰੇ (ਵੈੱਬ ਮੋਡ) |

## ਵਾਪਸੀ ਮੋਡ (ਸਿਰਫ਼-ਹਦਾਇਤ)

ਹੇਠਾਂ ਦਿੱਤੀ ਕੋਈ ਵੀ ਹਾਲਤ ਹੋਵੇ ਤਾਂ ਫ਼ੌਰਨ v1 ਵਾਲੇ ਸਿਰਫ਼-ਹਦਾਇਤ ਮੋਡ ਵਿੱਚ ਵਾਪਸ ਜਾਓ, ਸਕ੍ਰਿਪਟ ਨਾਲ ਜੰਗਾਲ ਨਾ ਕਰੋ:

- Node ≥ 18 ਨਹੀਂ ਹੈ ਜਾਂ ਸਕ੍ਰਿਪਟ ਲਗਾਤਾਰ ਦੋ ਵਾਰ ਇੱਕੋ ਤਰ੍ਹਾਂ ਦੀ ਗਲਤੀ ਦੇਵੇ;
- ਯੂਜ਼ਰ ਸਪਸ਼ਟ ਕਹੇ "ਮੈਂ ਆਪ ਵੈੱਬ ਤੇ ਕਰਾਂਗਾ";
- ਕੰਪਨੀ/ਡਿਵਾਈਸ ਪਾਲਿਸੀ ਸਕ੍ਰਿਪਟ ਦੇ ਨੈੱਟਵਰਕ ਤੇ ਪਹੁੰਚ ਨੂੰ ਰੋਕਦੀ ਹੈ।

ਵਾਪਸ ਆਉਣ ਤੋਂ ਬਾਅਦ: ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਪੇਜ https://global.powpow.online/register ਦਿਓ (ਮੁਫਤ ਪਰੀਖਣ ਅਵਧੀ ਵਿੱਚ ਵੈੱਬ ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਵੀ ਉਤਨੀ ਹੀ ਤੁਰੰਤ ਹੈ; ਜਦੋਂ ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਲੋੜੀਂਦੀ ਹੋਵੇ, ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਪੇਜ ਵੀ ਦਿਓ https://global.powpow.online/subscription ), `registration-flow.md` ਦੇ ਨਿਯਮਾਂ ਅਨੁਸਾਰ ਨਾਲ ਨਿਪਟਾਰਾ ਕਰੋ, ਉਹੀ ਟੋਨ ਰੱਖੋ, ਅਤੇ ਹਰ ਵਾਰ "ਅਗਲਾ ਕਦਮ" ਬਲਾਕ ਨਾਲ ਖ਼ਤਮ ਕਰੋ।
https://global.powpow.online/subscription ਦਿਓ, `registration-flow.md` ਦੇ ਨਿਯਮਾਂ ਮੁਤਾਬਕ ਗਲਤੀ-ਨਿਪਟਾਰੇ ਵਿੱਚ ਸਾਥ ਦਿਓ,
ਲਹਿਜ਼ਾ ਉਹੀ ਰਹਿੰਦਾ ਹੈ, ਹਰ ਗੇੜ ਫਿਰ ਵੀ "ਅਗਲਾ ਕਦਮ" ਬਲਾਕ ਨਾਲ ਸਮਾਪਤ ਕਰੋ।
