# ALI_RFQ_SCAN() 阿里 RFQ 市场筛选

**Skill ID:** `zayn-ali-rfq-scan`  
**Display Name:** ALI_RFQ_SCAN()  
**中文名称：** 阿里 RFQ 市场筛选

- 所属项目：WorkFn
- 当前版本：`0.2.0`
- 当前状态：Draft for testing

## 一句话用途

在 Alibaba 采购直达市场中判断 RFQ 是否值得点开、报价和消耗报价权益，并决定快速响应、继续核实或跳过。

## 适用场景

1. 批量查看 Alibaba 采购直达市场机会
2. 判断 RFQ 是否值得点开
3. 判断是否值得消耗报价权益
4. 决定快速响应、继续核实或跳过

## 不适用场景

1. 已决定参与并需要填写平台报价字段
2. 需要分析平台外的一般询价
3. RFQ 基本信息完全不可识别
4. 需要自动提交报价

## 输入要求

正式运行前必须检查必填参数，并使用“已命中、部分命中、缺失、冲突、待验证”输出参数状态表。关键参数缺失或冲突时，只能进入初步分析模式并停止正式分析。

## 输出结果

输出参数完整度结论、参数状态表、本 Skill 的专业判断、风险、停止条件和下一步。具体字段以 [SKILL.md](SKILL.md) 为准。
