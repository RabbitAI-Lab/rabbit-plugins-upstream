# 主题任务

目标与计划：填写现有来源位置；引用已有编号或章节，不复制整篇需求。

按实际目标增删 Phase 与 Task。每项的“依赖”只填编号（多个用顿号隔开）或“无”。Task 自动继承所属阶段的前置。依赖产物的用途写入动作或验收。

## Phase P001：第一项可验收能力

- 目标：本阶段交付的具体结果。
- 依据：需求或方案的编号、章节。
- 依赖：无。
- 阶段验收：本阶段目标成立的可观察结果。

### Task

- [ ] T001 在具体路径交付可调用的行为，并完成直接自检。
  - 依赖：无。
  - 验收：给出一个已知输入，从实际入口能得到什么结果。
- [ ] T002 使用 T001 交付的入口完成独立验收（确有单列需要时保留）。
  - 依赖：T001。
  - 验收：执行位置、命令或操作及预期。

## Phase P002：后继能力与整体接通

- 目标：本阶段交付的后继结果及累计效果。
- 依据：剩余目标及整体验收要求。
- 依赖：P001。
- 阶段验收：后继行为成立，累计结果覆盖本轮目标。

### Task

- [ ] T003 在具体路径实现后继行为。
  - 依赖：无。
  - 验收：该行为的检查方法及预期。
- [ ] T004 检查累计结果和必要回归。
  - 依赖：T003。
  - 验收：执行位置、命令或操作及预期。

## 验证与剩余工作

按 Phase、Task 编号记录实际命令、结果和覆盖范围。缺环境、失败或未运行分别写明；Task 完成勾选须有适用证据，所属任务及阶段验收成立才算 Phase 完成。新缺口补回所属 Phase 的原任务，不建立另一份清单。
