## 六、求和 / 积分 / 极限（用大运算符）

| 字符 | LaTeX | 用法 |
|---|---|---|
| ∑ | `\sum` | `\sum_{i=1}^{n}` |
| ∏ | `\prod` | `\prod_{i=1}^{n}` |
| ∫ | `\int` | `\int_{a}^{b}`；二重 `\iint`、三重 `\iiint`、环路 `\oint` |
| ∮ | `\oint` | 环路积分 |
| ∐ | `\bigsqcup` | 不相交并 |
| ∨ | `\bigvee` | 大或 |
| ∧ | `\bigwedge` | 大与 |
| lim | `\lim` | `\lim_{n \to \infty}` |
| sup | `\sup` | 上确界 |
| inf | `\inf` | 下确界 |
| max | `\max` | 最大值 |
| min | `\min` | 最小值 |

> 上下限位置：独立公式（`$$...$$` 或 `\displaystyle`）默认上下限在上下；行内公式（`$...$`）默认在右上右下。强制统一用 `\sum\limits_{i=1}^{n}` 或 `\sum\nolimits_{i=1}^{n}`。

## 七、常用结构

| 结构 | LaTeX |
|---|---|
| 分式 | `\frac{分子}{分母}` |
| 行内小分式 | 不推荐；用 `/` 或 `a/b` |
| 根号 | `\sqrt{x}`；n 次根 `\sqrt[n]{x}` |
| 上下标 | `x^2`、`x_i`、`x_i^2`、`x_{i+1}^{2n}` |
| 重音（向量 / 帽子） | `\vec{x}`、`\hat{x}`、`\bar{x}`、`\tilde{x}`、`\dot{x}`、`\ddot{x}` |
| 圆括号自动放大 | `\left( \frac{a}{b} \right)` |
| 绝对值 | 推荐 `|x|`；变长用 `\left| \frac{a}{b} \right|` |
| 矩阵 | `\begin{pmatrix} a & b \\ c & d \end{pmatrix}`；方括号换 `bmatrix`，竖线 `vmatrix` |
| 多行对齐 | `\begin{aligned} ... \end{aligned}`（需 amsmath 宏包） |
| 分情况 | `\begin{cases} x, & \text{if } x \geq 0 \\ -x, & \text{if } x < 0 \end{cases}` |
| 文本插入公式 | `\text{内容}`（需 amsmath） |
| 空格 | `\,` 小、`:` 中、`\;` 大、`\quad` 巨、`\!` 负 |
| 省略号 | `\ldots`（基线）/ `\cdots`（居中）/ `\vdots`（竖）/ `\ddots`（斜） |

## 八、常见 OCR / 乱码字符对照（实用自检表）

| 看到 / OCR 出来 | 几乎都是 | LaTeX |
|---|---|---|
| `Sum` / `SUM` / `∑`（手写） | 求和 | `\sum` |
| `Int` / `∫` | 积分 | `\int` |
| `infinity` / `oo` / `∞` | 无穷 | `\infty` |
| `sqrt(...)` | 根号 | `\sqrt{...}` |
| `a/b` 在复杂结构中 | 真分式 | `\frac{a}{b}` |
| `x^2` / `x2`（OCR 丢上标） | 平方 | `x^2` |
| `0` vs `O` vs `Θ` | 取决于上下文（数字 / 字母 / 希腊大写 Θ） | `0` / `O` / `\Theta` |
| `1` vs `l` vs `|` | 数字 / 小写 L / 竖线 | `1` / `l` / `|` |
| `=` 位置错的箭头 | 偏等号箭头 | `\to` / `\mapsto` |
| `>=` / `=>` | 大于等于 | `\geq` |
| `<=` / `=<` | 小于等于 | `\leq` |
| `!=` / `<>` | 不等 | `\neq` |
| `inf` | 下确界 | `\inf` |
| `hbar` / `h-bar` / `ℏ` | 约化普朗克常数 | `\hbar` |
| `del` / `∂` | 偏微分 | `\partial` |
| `grad` / `∇` | 梯度 | `\nabla` |
| `epsilon` | 极小 | `\epsilon`（标准）；有时 `\varepsilon`（手写体） |
| `theta` | 角 | `\theta`（有时 `\vartheta`） |
| `phi` | 相位 | `\phi`（有时 `\varphi`） |
| `AA` / `Angstrom` | 埃 | `\text{Å}`（直接用 Unicode：`\AA` 在某些包下可用） |

> OCR 不确定时**优先视觉 read 二次确认**，并在交付清单里标注"已假设"。

## 九、宏包与写法约束（本 skill 链路）

本 skill 的转换链路（LaTeX→MathML→OMML→docx）**不依赖 LaTeX 编译器和宏包**，但只认 amsmath / amssymb 通用语法：

| 写法 | 本链路 | 替代写法 |
|---|---|---|
| `\pdv{f}{x}`（physics） | ❌ 触发降级 | `\frac{\partial f}{\partial x}` |
| `\dv{f}{x}`（physics） | ❌ | `\frac{df}{dx}` |
| `\braket{\phi\|\psi}`（physics） | ❌ | `\langle \phi \| \psi \rangle` |
| `\expval{A}`（physics） | ❌ | `\langle A \rangle` |
| `\cancel{x}`（cancel） | ❌ | 无等价，走降级 |
| `\bm{v}`（bm） | ❌ | `\boldsymbol{v}` |
| `\mathbb{R}`（amssymb） | ✅ | —— |
| `\boldsymbol{x}` | ✅ | —— |

> 查表原则不变：所有特殊字符先查本表写 LaTeX；**physics 等扩展包命令一律换成上表替代写法**再进主链路。
