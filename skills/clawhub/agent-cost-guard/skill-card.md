## Description:

Audit agent cost, Curator and background work; cap it.

This skill is ready for commercial/non-commercial use.

## Publisher:

[33ai-wq](https://clawhub.ai/user/33ai-wq)

### License/Terms of Use:

MIT-0

## Use Case:

Agent owners and operators use this checklist to find model-backed background work, estimate its cost, and make approved, reversible changes to limit spending.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Incorrect configuration changes could disrupt background work or make it harder to restore prior behavior.

Mitigation: Make changes only with the owner's approval and record the restore step for each change.

Risk: Provider price changes can make estimates inaccurate.

Mitigation: Verify current rates with the provider and treat its invoice as authoritative.

Risk: Reports or optional paid services could expose credentials or usage data.

Mitigation: Keep credentials out of reports and review any paid service before sharing usage data or paying.
