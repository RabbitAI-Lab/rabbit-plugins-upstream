## Description:

为短剧人物、造型、地点、道具和状态编写或修改可直接复制的图片提示词 Markdown。

This skill is ready for commercial/non-commercial use.

## Publisher:

[worldwonderer](https://clawhub.ai/user/worldwonderer)

### License/Terms of Use:

MIT

## Use Case:

短剧创作者和制作团队可用此技能，将已确定的人物、造型、地点、道具与状态整理成可复用、可修改、可直接复制的图片提示词 Markdown。

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Proposed prompt revisions may introduce inaccurate or misleading visual guidance into project documents.

Mitigation: Review proposed revisions against accepted visual facts and the stated reference boundaries before using them.

Risk: A prompt document could be mistaken for an image-generation action.

Mitigation: Image generation uses a separate skill and requires explicit confirmation.
