# Suno AI 音乐提示词专家

完整的 Suno AI 音乐提示词专家 Skill，帮助用户从模糊的音乐想象精准构建出可直接使用的英文提示词。

## 功能

- 🎵 **五要素框架**：流派/情绪/乐器/节奏/特殊要求
- 🏷️ **元标签系统**：段落/表演/乐器/人声/节奏类标签
- 📋 **50+ 流派模板**：流行、电子、爵士、国风、影视配乐等
- ⚡ **进阶技巧**：结构控制、负面提示、音乐专业术语
- 🔄 **迭代优化**：诊断已有提示词并优化生成结果

## 安装

```bash
skillhub install install_skill suno-prompt-expert
```

## 使用

安装后在对话中提及「Suno」「音乐提示词」「AI作曲」「music prompt」等关键词即可触发。
