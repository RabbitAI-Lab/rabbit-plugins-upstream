# 保险销售合规自查顾问

> 按监管处罚案例逐条体检保险销售全流程合规状况，输出风险分级与整改台账

## 这个 Skill 解决什么

监管处罚不是抽象的。近十八个月公开的处罚公示里，双录不合规、销售误导、给予合同外利益、虚列费用、未如实告知、委托无资格机构展业这六类反复出现，单笔机构罚款从 0.5 万元到 70.5 万元不等，个人同步单罚。

问题是：**大部分中小机构不知道该查哪几项，也不知道自己已经踩了哪几条。** 现有材料要么是几万到几十万的合规 SaaS（买不起），要么是律师普法讲座（听完不知道怎么落到自己的台账上）。

这个技能把公开处罚案例拆成可执行的自查动作——每一项都写清楚「怎么查、常见什么表现、依据是哪条、风险多高」，配一个本地脚本自动生成风险分级和整改台账。

**核心用法**：先跑脚本拿风险分，再对着检查项逐项人工核。

## 你会拿到什么

- 36 项自查表，分十组，每项写明怎么查、常见表现、依据条款与风险等级（高 29 · 中 7）
- 一个纯标准库脚本：按分支机构数、销售渠道数、从业人数算出风险分，输出十组暴露度分布与 Top 10 优先整改项
- 整改台账 CSV（13 列），前 8 列脚本填好，留出结论 / 整改动作 / 责任人 / 完成日期 / 复核人 5 列空白
- 26 例真实行政处罚案例，含机构名、案号、违规事实、罚款金额、依据条款
- 22 条现行有效监管依据，核对过 2025 年第 4 号修改决定与第 5 号废止决定
- 三个引用陷阱，避免你在写内部制度时引错规章
- 一份 30 分钟上手执行手册：四步流程、参数怎么填、表格怎么填

## 什么时候用

- 「我们支公司双录怎么做才不会被罚」
- 「销售适当性要留哪些东西」
- 「有哪些保险销售的红线不能碰」
- 「下周要迎监管检查，他们一般查什么」
- 「帮我按处罚案例排个整改优先级」

## 怎么用

```bash
# 1. 跑脚本拿风险基线
python scripts/compliance_audit.py --scale 8 --channels 3 --staff 12

# 2. 只看某一组
python scripts/compliance_audit.py --list-group A

# 3. 导出整改台账 CSV
python scripts/compliance_audit.py --scale 8 --channels 3 --staff 12 --export-todo
```

只依赖 Python 3.8+ 标准库，不联网、不上传、不需要 API key 或账号。

## 输出

- 总分、风险等级、十组暴露度分布

## 边界

- 不做违规认定，不判断"你这算不算违法"
- 不出具法律意见，不代替机构合规负责人签字
- 不推荐产品、不评价保险公司优劣
- 不替代内审与外部审计
- 不保证不会被处罚，也不代替属地监管口径（地方细则可能严于上位法）
- 单次购买、单人授权使用；不可转售或再分发
