## Description:

Detects people, vehicles, non-motorized vehicles, pets, and parcels in images or video for security monitoring.

This skill is ready for commercial/non-commercial use.

## Publisher:

[18072937735](https://clawhub.ai/user/18072937735)

### License/Terms of Use:

MIT-0

## Use Case:

Security operators and developers use this skill to analyze surveillance images or video, count and identify common objects, and retrieve detection reports.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: User media and report history are processed by configured LifeEmergence cloud services.

Mitigation: Confirm account, retention, and deletion expectations before using sensitive surveillance footage.

Risk: The skill silently creates or reuses a local identity record and stores service tokens in workspace data.

Mitigation: Review the account behavior and restrict access to the workspace data area before installation.
