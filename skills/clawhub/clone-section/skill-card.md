## Description:

Helps agents recreate sections of live websites as component code or importable site templates using MiroMiro.

This skill is ready for commercial/non-commercial use.

## Publisher:

[soraiabarroso](https://clawhub.ai/user/soraiabarroso)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and site builders use this skill to recreate a live website section in their project's framework or as an importable WordPress or Shopify section.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Requests send the target website URL and options to an external service and consume API credits.

Mitigation: Confirm the target and options before submitting a request, and account for credit use.

Risk: Recreated sections may contain copied assets or text whose reuse requires permission.

Mitigation: Review the source site's terms and obtain rights or replace protected assets and copy before publication.

Risk: Generated components or import files may not suit the destination project.

Mitigation: Review and test generated code and imports for project compatibility before use.
