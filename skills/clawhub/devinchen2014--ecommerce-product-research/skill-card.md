## Description:

提供商品类目或已有商品资料，整理电商选品候选清单，列出可见价格、匹配条件、入选理由和待核实事项。预算与受众有则提供；已有资料可直接分析，无需 API Key。在线商品查询支持抖音与小红书。来自 SocialDataX 社媒数据助手。

This skill is ready for commercial/non-commercial use.

## Use Case:

电商卖家、运营人员和选品研究者可用它按类目、预算及受众初筛商品，并整理候选商品的可见信息、匹配理由和待核实事项。

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Online product searches may consume paid SocialDataX credits.

Mitigation: Check available credits before querying; analyze supplied product information without an API key when possible.

Risk: The documented CLI uses an unpinned latest version.

Mitigation: Use a reviewed fixed CLI version and limit its access to unrelated files and secrets.
