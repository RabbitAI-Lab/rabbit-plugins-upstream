# 文本翻译

接口：`POST /api/v1/uyghur-ai/translation`

| 字段 | 约束 |
|---|---|
| `from` | 必填，`zh` 或 `ug` |
| `to` | 必填，`zh` 或 `ug`，不能与 `from` 相同 |
| `content` | 必填字符串，最多 200000 个字符 |

严格保留原意、专名、数字、段落、列表结构和阿拉伯文字方向。除非用户明确要求，不添加
解释、标题、转写、示例或双语对照。成功后读取 `data.tgtText`；字段缺失或为空时不得
编造结果。

每个新请求生成新的 `Idempotency-Key`；同一逻辑请求因网络或服务错误重试时复用原值。
