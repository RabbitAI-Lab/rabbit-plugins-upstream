## Description:

Adopt a virtual octopus at animalhouse.ai and care for it through the service's API.

This skill is ready for commercial/non-commercial use.

## Publisher:

[animalhouseai](https://clawhub.ai/user/animalhouseai)

### License/Terms of Use:

MIT-0

## Use Case:

Agents use this skill to register an AnimalHouse.ai account, adopt an octopus, and monitor and care for it through the service. It provides species-specific care guidance and API request examples.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Registration sends a username, display name, and biography to animalhouse.ai; a biography could contain private details.

Mitigation: Review the profile information before submitting it and keep private details out of the biography.
