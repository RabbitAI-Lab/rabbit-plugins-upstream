# 栏目写作风格手册

把同一栏目已验证的写法沉淀成编辑可直接复用的 Markdown 手册，而不是模仿作者的长段落。

## 输入

- 3 至 5 篇用户自有、已发布或已批准的成熟稿（合计不超过 8,000 字）
- 目标读者
- 已批准词表
- 必须保留的表达限制

## 工作流程

1. 先核验样本数量、来源和主题是否属于同一栏目。没有代表稿、仅有口号，或稿件差异过大时停止归纳，使用“缺料处理”回复请求用户指定基准稿；不根据账号名称推断。
2. 只标注跨多篇重复且与读者目标一致的表达证据：叙述人称与语气、段落/句长、开头/转折/收束习惯、术语首次释义、数字单位与区间写法、标点和限制项。
3. 将观察归纳成可执行规范。单篇笑话、偶然标题或唯一修辞不得升级为必用规则。每条规则附不超过 20 字的短摘录、稿件编号及适用条件。
4. 输出下列固定结构。不得输出主页简介、账号定位、选题排期；不得拼接、续写或复制作者独有的长段表达。

## 交付格式

```markdown
# [栏目名]写作风格手册

## 适用范围与基准
- 目标读者：…
- 基准稿：稿 1、稿 2、稿 3
- 已批准词表与保留限制：…

## 可复用写法
| 维度 | 规范 | 适用条件 | 依据摘录 |
| --- | --- | --- | --- |
| 语气 | … | … | 稿 1：“…”；稿 3：“…” |
| 句长与段落 | … | … | … |
| 术语 | … | … | … |
| 数字与单位 | … | … | … |

## 不固化的偶发写法
- …（只出现于稿 N，不列为规则）

## 下一篇写稿核对表
- [ ] 开头在 … 字内完成 …
- [ ] 每个新术语按批准词表首次释义
- [ ] 数字、单位、范围按本手册统一
- [ ] 不触碰保留限制
```

## 缺料处理

当没有 3 篇代表稿、稿件跨度无法判定为同一栏目，或缺少词表/限制时，回复：

> 目前无法建立可靠的栏目基准。请提供 3 至 5 篇同栏目成熟稿，并标出应作为基准的稿件、目标读者、已批准词表和必须保留的限制；我不会依据账号名称或一句口号编造文风。

## 边界

这项 Skill 固化的是文章表达规范，不处理主页简介、账号定位或选题排期；不进行他人风格仿写，也不复制用户作者的长段表达。
