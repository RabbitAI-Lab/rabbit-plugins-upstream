## Description:

Export ChatGPT, Grok and Gemini conversations into local Markdown, PDF, JSONL and knowledge packs. Use when a user wants to export, archive, or back up an AI chat, or an entire ChatGPT project.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and other users can use the skill to archive individual AI conversations or ChatGPT projects as local files for reading, backup, or further processing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup instructions may install system-wide prerequisites even though the skill describes changes as local; the security scan was partial.

Mitigation: Review setup steps before installing. Check what Node.js installation changes, and approve system-wide changes only if comfortable with them.
