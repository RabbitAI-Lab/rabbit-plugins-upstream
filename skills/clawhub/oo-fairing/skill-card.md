## Description:

Use the oo CLI to list and read Fairing survey responses.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

Fairing users and analysts can list survey responses through their connected Fairing account, optionally filtering by time, cursor, or question.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup can execute unverified remote installers without a clear user approval step.

Mitigation: Review setup before enabling the skill, install a verified CLI release yourself, and review its automatic skill-synchronization settings. Limit the Fairing connection to the data needed.
