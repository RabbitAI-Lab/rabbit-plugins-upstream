## Description:

Guides creators through using video references and character images to create and review AI scene recasts.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to plan short AI video recasts from reference clips and character images, preserve motion and timing, check results, and create stacked comparisons.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Reference clips, photos, and prompts may contain identifiable or private material shared with external services.

Mitigation: Review each provider's data-handling terms before sharing identifiable people or private material.

Risk: The documented install command is not pinned to a release.

Mitigation: Review the source and select a verified version before installing.

Risk: Provider refusals may be routed around instead of respected.

Mitigation: Treat a provider block as a refusal; change the concept or input rather than trying another route to bypass it.
