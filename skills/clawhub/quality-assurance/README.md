# Quality Assurance Skill

The skill gatekeeper. Validates, tests, and certifies all other skills.

## Usage
Activate when you need to:
- Validate a new skill before shipping
- Test an upgraded skill
- Audit skill quality
- Certify skill tier

## Features
- 10-dimension quality audit
- 5-type stress testing
- Regression testing
- Automated QA reports

## Certification Tiers
- Legendary (97-100): Gold seal
- Elite (90-96): Silver seal
- Excellent (80-89): Bronze seal
- Below 80: Not certified
