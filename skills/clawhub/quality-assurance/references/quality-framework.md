# Quality Framework Detail

> Deep dive into each dimension of the quality audit.

## D1: Purpose Clarity

### What to Check
- Can you understand the skill's purpose in 10 seconds?
- Are trigger conditions explicit and unambiguous?
- Are anti-triggers defined?
- Is the unique value clear?

### Common Issues
- Vague descriptions like "helps with X"
- Missing trigger conditions
- No anti-triggers
- Unclear target user

### Fixes
- Rewrite description to be specific and compelling
- Add explicit trigger/anti-trigger lists
- Define target user persona

## D2: Reasoning Depth

### What to Check
- Does the skill think before acting?
- Are there multi-step protocols?
- Is there self-correction?
- Are alternatives considered?

### Common Issues
- Step-by-step without thinking
- No verification steps
- No error checking
- Single-path reasoning

### Fixes
- Add analysis phase before execution
- Include verification checkpoints
- Add "what if" branches
- Include self-critique

## D3: Framework Richness

### What to Check
- How many frameworks?
- Is there selection logic?
- Can frameworks be adapted?
- Are mistakes documented?

### Common Issues
- Only one framework
- No selection guidance
- No adaptation rules
- Missing common mistakes

### Fixes
- Add framework library
- Create selection guide
- Document adaptation rules
- List common mistakes

## D4: Output Quality

### What to Check
- Are standards defined?
- Are there quality tiers?
- Is there a checklist?
- Are examples provided?

### Common Issues
- No quality definition
- Vague "write well" instructions
- No examples
- No review process

### Fixes
- Define minimum/excellent/legendary bars
- Create quality checklist
- Include excellent examples
- Document review process

## D5: Edge Case Handling

### What to Check
- How are errors handled?
- Are there fallbacks?
- What about bad input?
- Is degradation graceful?

### Common Issues
- No error handling
- Silent failures
- Crashes on bad input
- No fallback plans

### Fixes
- Add error handling protocols
- Create fallback chains
- Document failure modes
- Add graceful degradation

## D6: Context Awareness

### What to Check
- Does it manage context?
- Can it handle large inputs?
- Does it track state?
- Does it compress old info?

### Common Issues
- No context management
- Forgets user preferences
- Repeats questions
- Context bloat

### Fixes
- Add context management strategy
- Implement memory/tracking
- Add compression rules
- Document state management

## D7: Tool Integration

### What to Check
- Are tools used optimally?
- Is there selection logic?
- Is error recovery covered?
- Are results interpreted?

### Common Issues
- Wrong tool selection
- No error recovery
- Raw output pasted
- No parallel execution

### Fixes
- Add tool selection rules
- Create error recovery protocols
- Document result interpretation
- Add parallel execution logic

## D8: Voice & Persona

### What to Check
- Is voice consistent?
- Is persona defined?
- Does it adapt tone?
- Is it distinctive?

### Common Issues
- Generic AI voice
- Inconsistent tone
- No persona definition
- Boring and forgettable

### Fixes
- Define voice with adjectives
- Create tone adaptation rules
- Add signature phrases
- List forbidden patterns

## D9: Reference Quality

### What to Check
- Are references comprehensive?
- Are sources authoritative?
- Are they organized?
- Are examples included?

### Common Issues
- Incomplete references
- Poor organization
- No examples
- Outdated information

### Fixes
- Expand reference coverage
- Reorganize logically
- Add examples
- Update and version

## D10: Completeness

### What to Check
- Does it cover the full domain?
- Are templates provided?
- Is there a quick-start?
- Are advanced topics covered?

### Common Issues
- Missing key areas
- No templates
- No quick-start
- Only basic coverage

### Fixes
- Expand domain coverage
- Create templates
- Add quick-start guide
- Include advanced topics
