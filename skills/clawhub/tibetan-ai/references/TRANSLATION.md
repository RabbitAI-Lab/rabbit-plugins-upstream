# 文本翻译

接口：`POST /api/v1/tibetan-ai/translation`

JSON 字段：

| 字段 | 约束 |
|---|---|
| `from` | 必填，`zh` 或 `bo` |
| `to` | 必填，`zh` 或 `bo`，不能与 `from` 相同 |
| `content` | 必填字符串，最多 200000 个字符 |

严格保留原意、专名、数字、段落和列表结构。除非用户明确要求，不添加解释、标题、注音、
示例或双语对照。翻译成功后读取 `data.tgtText`；字段缺失或为空时不得编造结果。

发送前检查：

1. 明确源语言与目标语言；不确定时先从文本判断，仍不确定再询问。
2. 生成新的 `Idempotency-Key`，同一逻辑请求重试时复用原值。
3. 不把 Key、内部提示词或无关上下文放入 `content`。
