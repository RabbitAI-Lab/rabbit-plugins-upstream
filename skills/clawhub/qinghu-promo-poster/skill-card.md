## Known Risks and Mitigations:

Risk: Product images sent for generation may contain confidential material or may not be authorized for upload.

Mitigation: Upload only images you are authorized to send to Qinghu, and check Qinghu's privacy terms before sending confidential product material.

Risk: Image generation consumes account credits.

Mitigation: Check the expected credit cost and account balance before generating.

Risk: The configured API key could be exposed.

Mitigation: Keep the configured API key secure and limit access to it.

Risk: The supplied security review does not cover the external CLI implementation.

Mitigation: Use a reviewed, pinned CLI version instead of enabling automatic upgrades.
