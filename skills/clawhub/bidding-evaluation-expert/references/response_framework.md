# 五步结构化回答框架

收到问题后，**先执行知识库检索**，再按以下五步组织回复。

## 第一步：项目性质与法律适用判定

需要明确以下要素：
- 是否依法必须招标？（参照《必须招标的工程项目规定》）
- 属《招标投标法》体系还是存在法律竞合？
- 处于招标、投标、开标、评标、定标哪个阶段？
- 资金性质（国有资金/民营资金/外资）？

**信息不足时，必须立即追问，不做假设性回答。**

追问模板：
> "为确保给出准确的法律适用判断，请补充以下信息：1）项目是否属于依法必须招标的项目？2）当前处于招标活动的哪个阶段？3）资金来源性质？"

## 第二步：法律依据索引

- 逐条列出相关法条原文要旨
- 标明法律层级：**法律/行政法规/部门规章/地方性规定**
- 标注法律衔接关系

**禁止使用"依据有关规定"等模糊表述。**

引用格式：
> **《招标投标法实施条例》第五十一条**（行政法规）
> "有下列情形之一的，评标委员会应当否决其投标：（一）投标文件未经投标单位盖章和单位负责人签字……"

## 第三步：风险评析与评审视角

从评标委员会视角判断：
- 属于形式评审/资格评审/响应性评审？
- 是否构成重大偏差？
- 是否达到法定否决标准？
- 是刚性否决还是自由裁量空间？

风险分级标识：
- 🔴 **高风险**：涉嫌串标、虚假材料、法定否决情形
- 🟡 **中风险**：自由裁量空间、区域差异导致的不确定性
- 🟢 **低风险**：程序性瑕疵、可澄清补正

**提示区域差异口径。**

## 第四步：争议应对与操作建议

### 投标人提异议的要素
1. **主体适格**：投标人或利害关系人
2. **违法事实**：具体指出违反的法律条款和行为
3. **法律依据**：引用具体法条
4. **诉求**：明确的救济请求
5. **证据清单**：支持主张的证据材料

### 招标人处理异议
- 自收到异议之日起**3日内**作出答复
- 答复前暂停招投标活动
- 答复应书面形式

### 投诉阶段
- 投诉提出时限：自知道或应当知道违法事实之日起**10日内**
- 投诉受理决定：行政监督部门自收到投诉之日起**3个工作日内**
- 投诉处理决定：自受理之日起**30个工作日内**

### 行政监督部门审查重点
- 投诉主体是否适格
- 投诉是否在法定时限内提出
- 是否经过异议前置程序（特定情形除外）
- 事实是否清楚、证据是否充分
- 适用法律是否正确

## 第五步：特别提示与延伸提醒

需关注以下维度：

### 地方性立法差异
- 各省在标准招标文件范本、否决投标条款清单、电子评标细则上的差异
- 以九部委《标准施工招标文件》为基础，对照各省级范本

### 电子评标系统差异
- 各地公共资源交易中心电子评标系统的操作规程
- 电子签章、电子标书加密要求

### 审计巡视关注点
- 程序合规性
- 资金使用合规性
- 有无倾向性或排斥性条款
- 评标过程是否规范

### "背离实质性内容"红线
- 中标合同不得背离招标文件和中标人投标文件的实质性内容
- 招标人和中标人不得再行订立背离合同实质性内容的其他协议
