# 招投标法律依据索引

## 法律效力层级

从高到低依次为：
1. **法律**（全国人大及其常委会制定）— 如《招标投标法》
2. **行政法规**（国务院制定）— 如《招标投标法实施条例》
3. **部门规章**（国务院各部委制定）— 如《评标委员会和评标方法暂行规定》
4. **地方性法规/规章**（省级人大/政府制定）— 如各省招标投标条例
5. **规范性文件**— 如各省发改委、公共资源交易中心发布的细则

## 核心法律法规

### 《中华人民共和国招标投标法》
- 第三条：依法必须招标的项目范围
- 第五条：公开、公平、公正、诚实信用原则
- 第十八条：招标人对潜在投标人实行资格审查
- 第二十二条：招标人不得向他人透露已获取招标文件的潜在投标人的名称、数量等
- 第三十二条：联合体投标
- 第三十三条：投标人不得以他人名义投标或弄虚作假
- 第三十七条：评标委员会组成（依法必须招标项目，专家不少于成员总数 2/3）
- 第三十九条：评标委员会可以要求投标人对投标文件中含义不明确的内容作必要的澄清
- 第四十条：评标委员会完成评标后向招标人提出书面评标报告
- 第四十二条：评标委员会经评审认为所有投标都不符合招标文件要求的，可以否决所有投标（废标）
- 第四十三条：在确定中标人前，招标人不得与投标人就投标价格、投标方案等实质性内容进行谈判
- 第四十六条：招标人和中标人应当自中标通知书发出之日起三十日内订立书面合同
- 第五十一条：招标人规避招标的法律责任
- 第五十三条：串通投标的法律责任
- 第五十四条：骗取中标的法律责任

### 《中华人民共和国招标投标法实施条例》
- 第十六条：招标文件发售期不得少于5日
- 第十九条：资格预审文件或招标文件发售期不得少于5日
- 第二十一条：招标人可以对已发出的招标文件进行必要的澄清或修改，应当在招标文件要求提交投标文件截止时间至少15日前发出
- 第二十六条：招标人在招标文件中要求投标人提交投标保证金的，投标保证金不得超过招标项目估算价的2%
- 第三十二条：招标人不得以不合理的条件限制或排斥潜在投标人
- 第三十六条：未通过资格预审的申请人提交的投标文件，以及逾期送达或者不按照招标文件要求密封的投标文件，招标人应当拒收
- 第三十九条：禁止投标人相互串通投标
- 第四十条：视为投标人相互串通投标的情形（包括：不同投标人的投标文件由同一单位或个人编制、投标报价呈规律性差异、投标文件载明的项目管理成员为同一人等）
- 第四十一条：禁止招标人与投标人串通投标
- 第五十一条：评标委员会应当否决投标的情形（投标文件未经投标单位盖章和单位负责人签字、投标联合体没有提交共同投标协议、投标人不符合国家或招标文件规定的资格条件、同一投标人提交两个以上不同的投标文件或投标报价但招标文件要求提交备选投标的除外、投标报价低于成本或高于招标文件设定的最高投标限价、投标文件没有对招标文件的实质性要求和条件作出响应等）
- 第五十二条：投标文件中有含义不明确的内容、明显文字或计算错误，评标委员会不得暗示或诱导投标人作出澄清、说明，澄清、说明应当采用书面形式并不得超出投标文件的范围或改变投标文件的实质性内容
- 第五十三条：评标完成后，评标委员会应当向招标人提交书面评标报告
- 第五十四条：评标报告应由评标委员会全体成员签字，对评标结果有不同意见的成员应当书面说明不同意见和理由
- 第五十五条：招标人根据评标委员会提出的书面评标报告和推荐的中标候选人确定中标人，也可以授权评标委员会直接确定中标人
- 第五十六条：中标候选人的公示期不得少于3日
- 第六十条：投标人或利害关系人认为招标投标活动不符合法律行政法规规定的，有权依法向有关行政监督部门投诉，投诉应当自知道或应当知道之日起10日内提出
- 第六十一条：投诉人就同一事项向两个以上有权受理的行政监督部门投诉的，由最先收到投诉的行政监督部门负责处理
- 第六十二条：行政监督部门应当自收到投诉之日起3个工作日内决定是否受理投诉，并自受理投诉之日起30个工作日内作出书面处理决定

## 法定时限汇总

| 时限事项 | 法定期限 | 法律依据 |
|---------|---------|---------|
| 招标文件发售期 | 不少于5日 | 《实施条例》第十六条 |
| 澄清或修改发出 | 截止时间至少15日前 | 《实施条例》第二十一条 |
| 投标保证金 | 不超过项目估算价2% | 《实施条例》第二十六条 |
| 异议答复 | 收到异议之日起3日内 | 《实施条例》第五十四条 |
| 中标候选人公示 | 不少于3日 | 《实施条例》第五十六条 |
| 投诉提出 | 知道或应当知道之日起10日内 | 《实施条例》第六十条 |
| 投诉受理决定 | 收到投诉之日起3个工作日内 | 《实施条例》第六十二条 |
| 投诉处理决定 | 受理之日起30个工作日内 | 《实施条例》第六十二条 |
| 签订合同 | 中标通知书发出之日起30日内 | 《招标投标法》第四十六条 |

## 地方性法规示例

各省可能存在更严格的地方性细化规定，常见包括：

- 《四川省国家投资工程建设项目招标投标条例》
- 《北京市招标投标条例》
- 《广东省实施〈中华人民共和国招标投标法〉办法》
- 《江苏省招标投标条例》
- 《浙江省招标投标条例》

处理具体省份的项目时，须主动核查当地最新地方性法规，注意各地在标准招标文件范本、否决投标条款清单、电子评标细则、专家库管理、异议投诉受理口径上的差异。
