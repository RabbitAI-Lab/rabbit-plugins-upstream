# 术语铁律与纠正规则

## 术语定义对照表

以下术语在《招标投标法》体系中有严格定义，绝对不可混用：

| 术语 | 正确定义 | 禁止用法 |
|------|---------|---------|
| **否决投标** | 评标委员会对**个别投标文件**的否定结论 | 不可称"废标" |
| **废标** | **仅指**否决所有投标、导致重新招标的程序性结果 | 不可用于描述对单个投标的否决 |
| **澄清** | 评标过程中评标委员会要求投标人对投标文件含义不明确的内容作出说明 | 不可混同于"答疑" |
| **答疑** | 招标人对潜在投标人提出的疑问进行解答（发生在投标预备会阶段） | 不可混同于"澄清" |
| **异议** | 《招标投标法》体系中投标人或利害关系人的救济程序 | 不可混同于政府采购的"质疑" |
| **质疑** | 《政府采购法》体系中供应商的救济程序 | 不可混同于招投标的"异议" |
| **投诉** | 对异议答复不满向行政监督部门提出的救济申请 | 严格区分招标投标投诉与政府采购投诉 |

## 术语纠正执行规则

当用户使用错误术语时，必须先纠正再回答。

**示例**：用户说"这个标被废了"，应回复：
> "需先明确您的意思——如果是指某一家投标人的投标文件被评标委员会否决，正确术语是'否决投标'；如果是指所有投标均被否决，导致重新招标，才称为'废标'。根据您的情况……"

## 评标方法术语

| 术语 | 定义 |
|------|------|
| **经评审的最低投标价法** | 评标委员会对满足招标文件实质性要求的投标文件，根据评审后的最低投标价推荐中标候选人 |
| **综合评估法** | 评标委员会对满足招标文件实质性要求的投标文件，根据招标文件确定的量化标准进行打分，按得分由高到低推荐中标候选人 |
| **重大偏差** | 投标文件对招标文件的实质性要求和条件未作出响应，足以导致否决投标的偏差 |
| **细微偏差** | 投标文件在实质上响应招标文件，但在个别地方存在漏项或提供的技术信息和数据不完整等，澄清补正后不影响投标文件有效性的偏差 |

## 否决投标与废标的区分要点

- **否决投标**：针对**个别**投标文件，评标委员会依据法定或招标文件约定的情形作出的否定结论，该投标人退出竞争，不影响其他投标人的评审
- **废标**：评标委员会经评审认为**所有**投标都不符合招标文件要求，否决所有投标，导致招标失败、需要重新招标的程序性结果

## 异议与投诉的区分要点

- **异议**：前置救济程序，向**招标人**提出，招标人应在3日内答复
- **投诉**：后续救济程序，向**行政监督部门**提出，前提是先提出异议且对答复不满（涉及开标、评标结果等特定情形可直接投诉）
