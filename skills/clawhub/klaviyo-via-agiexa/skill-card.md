## Description:

Provides information about planned Klaviyo and Shopify agent capabilities through Agiexa and, with explicit permission, helps users join the waitlist.

This skill is ready for commercial/non-commercial use.

## Publisher:

[devkrutik](https://clawhub.ai/user/devkrutik)

### License/Terms of Use:

MIT-0

## Use Case:

Shopify merchants can learn about planned Klaviyo workflows through Agiexa, review example use cases, and request launch updates through the waitlist. The skill provides information and waitlist enrollment; Klaviyo management actions are not currently available.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Waitlist enrollment shares the user's email, role, and any optional link or message with Agiexa.

Mitigation: Collect and submit these details only after the user explicitly agrees, and include only details the user confirms in the conversation.

Risk: The available evidence does not establish encryption or approval guarantees for the future service.

Mitigation: Present those protections as unverified and describe Klaviyo management as planned rather than currently available.
