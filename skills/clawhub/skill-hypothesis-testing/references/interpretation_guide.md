## p值的基本含义

### 什么是p值
p值是在原假设为真的条件下，观测到当前结果或更极端结果的概率。

### 解读原则
| p值范围 | 传统解读 | 现代建议表述 |
|---------|----------|--------------|
| p < 0.001 | 极强显著 | "有非常强的证据拒绝原假设" |
| 0.001 ≤ p < 0.01 | 强显著 | "有强证据拒绝原假设" |
| 0.01 ≤ p < 0.05 | 显著 | "有证据拒绝原假设" |
| p ≥ 0.05 | 不显著 | "没有足够证据拒绝原假设" |

### 重要提醒
- p值不是"原假设为真的概率"
- p值不是"发现真实效应的概率"
- p值不能衡量效应大小或实际重要性

## 各检验方法的适用场景

### 正态性检验

#### Shapiro-Wilk检验
- **适用场景**: 小样本(n < 5000)正态性判断
- **优势**: 统计功效高，是正态性检验的首选
- **样本量注意**: n > 5000时结果可能不稳定

#### Kolmogorov-Smirnov检验
- **适用场景**: 大样本正态性判断
- **局限**: 对正态分布的中心区域敏感，对尾部不敏感

### t检验

#### 单样本t检验
- **用途**: 比较样本均值与已知总体均值
- **示例**: 检验某班级平均成绩是否达到年级平均

#### 独立样本t检验
- **用途**: 比较两组独立样本的均值差异
- **示例**: 比较新药组与安慰剂组的疗效差异
- **前提**: 两组数据独立、正态、方差齐性

#### 配对样本t检验
- **用途**: 比较配对样本的均值差异
- **示例**: 同一患者治疗前后的血压变化
- **优势**: 消除个体差异，统计功效更高

### 卡方检验

#### 拟合优度检验
- **用途**: 检验观测频数是否符合期望分布
- **示例**: 检验骰子是否公平

#### 独立性检验
- **用途**: 检验两个分类变量是否相关
- **示例**: 检验性别与职业选择是否相关

### 方差分析(ANOVA)

#### 单因素ANOVA
- **用途**: 比较三组及以上样本的均值差异
- **示例**: 比较三种教学方法的效果差异
- **注意**: 仅能判断"至少有一组不同"，不能指出具体是哪些组

### 非参数检验

#### Mann-Whitney U检验
- **用途**: 两组独立样本的比较，不要求正态分布
- **替代**: 独立样本t检验的非参数替代

#### Levene检验
- **用途**: 检验多组数据的方差齐性
- **重要性**: t检验和ANOVA的前提条件

## 结论的正确表述方式

### 接受 vs 拒绝

| 检验结论 | 正确表述 | 错误表述 |
|----------|----------|----------|
| p < α | "拒绝原假设" | "接受备择假设" |
| p ≥ α | "不拒绝原假设" | "接受原假设" |

### 原因
统计检验不能"证明"原假设为真，只能判断"没有足够证据拒绝"。

### 示例

**场景**: 两组学生成绩比较
- **正确**: "在α=0.05水平下，两组成绩存在显著差异(t=2.5, p=0.015)"
- **错误**: "实验组成绩显著高于对照组"

## 效应量解读

### 为什么要报告效应量
p值受样本量影响，大样本时微小差异也可能显著。效应量反映实际差异大小。

### 常用效应量

#### Cohen's d (t检验)
| 绝对值 | 解读 |
|--------|------|
| d < 0.2 | 可忽略 |
| 0.2 ≤ d < 0.5 | 小效应 |
| 0.5 ≤ d < 0.8 | 中等效应 |
| d ≥ 0.8 | 大效应 |

#### Cohen's f² (ANOVA)
| 值 | 解读 |
|----|------|
| f² < 0.02 | 可忽略 |
| 0.02 ≤ f² < 0.15 | 小效应 |
| 0.15 ≤ f² < 0.35 | 中等效应 |
| f² ≥ 0.35 | 大效应 |

## 常见误区与局限性

### 1. p值不是一切
- p < 0.05 ≠ 有意义
- 需要结合效应量、置信区间、研究背景综合判断

### 2. 样本量影响
- 大样本: 小差异也可能显著
- 小样本: 大差异可能不显著

### 3. 多重比较问题
- 多次检验会增加I类错误率
- 解决: Bonferroni校正、 Tukey HSD等

### 4. 检验前提不可忽视
- t检验要求: 正态性、方差齐性、独立性
- 违反前提时考虑: 非参数检验、数据转换

### 5. 因果关系陷阱
- 假设检验只能判断差异，不能证明因果
- 相关≠因果

### 6. 报告完整性要求
建议报告内容:
- 检验方法与统计量
- 自由度
- p值
- 效应量
- 置信区间
- 样本描述统计

## 置信区间解读

### 与p值的关系
- 置信区间包含原假设值 → p > α
- 置信区间不包含原假设值 → p < α

### 优势
- 提供效应大小的估计范围
- 显示估计精度
- 更直观反映实际意义

### 示例
"两组差异的95%置信区间为[2.3, 8.7]，区间不包含0，说明差异显著"
