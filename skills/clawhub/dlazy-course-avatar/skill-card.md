This skill is ready for commercial/non-commercial use.

## Use Case:

Course creators, trainers, and educators use this skill to plan and produce paid lessons, training modules, and knowledge-sharing videos with a consistent digital lecturer and slide-based teaching segments.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installing the dLazy CLI and storing a local API key exposes users to third-party package and credential handling risks.

Mitigation: Confirm the CLI package is trusted before installation and handle the API key securely.

Risk: Course documents, audio, and video provided to the workflow are uploaded to an external service.

Mitigation: Only upload material approved for external processing.

Risk: Generated lessons could include unsupported educational claims or omit required AI-generated-content disclosures.

Mitigation: Review course content against applicable advertising, education, and AI-generated-content disclosure requirements before publication.
