## Known Risks and Mitigations:

Risk: Course materials and generated media are sent to dLazy services.

Mitigation: Review the provider's data handling terms and avoid uploading materials that cannot be shared externally.

Risk: A dLazy API key may be used to access paid services.

Mitigation: Keep API keys private and review expected usage and credits before running batch jobs.
