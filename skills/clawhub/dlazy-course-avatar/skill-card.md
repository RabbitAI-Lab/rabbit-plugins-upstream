## Description:

Guides creators through producing slide-first course videos with a consistent digital lecturer, using portrait recipes, narration, short avatar segments, and video assembly.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Course creators and training teams use this skill to plan and produce paid lessons or internal training videos that pair a reusable digital lecturer with narrated slides.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Course documents, prompts, audio, and generated media may be uploaded to dLazy services.

Mitigation: Use the workflow only when those data transfers are acceptable for the project.

Risk: The dLazy CLI may save an API key locally, and a global npm install may introduce third-party package risk.

Mitigation: Protect local credentials and review the CLI package provenance before installation where required.

Risk: Digital lecturers can imply unverified qualifications or obscure that a presenter is AI-generated.

Mitigation: Review course claims and visuals for invented credentials and disclose AI-generated content as appropriate before publication.
