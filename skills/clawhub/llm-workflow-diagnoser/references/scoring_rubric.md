# 5 维度难度评级 + 改造建议触发表

## 5 维度难度评级（xx/10，仅做解释，不做硬阈值）

每个维度给 0-10 的"难度值"，让用户看懂 LLM 的判断逻辑，不要硬卡阈值。

### 输入多样性

- 难度 0-3：输入高度结构化（数据库表、字段固定、模板填空）。
- 难度 4-6：输入半结构化（部分字段固定 + 部分自由文本）。
- 难度 7-10：输入是自由文本 / 多模态 / 来源多样。

### 输出一致性要求

- 难度 0-3：允许多版本 / 多风格输出。
- 难度 4-6：允许部分字段变化，主结构稳定。
- 难度 7-10：必须严格统一（如合同条款、合规文本、像素级输出）。

### 容错率

- 难度 0-3：错误可以批量回滚 / 重新生成。
- 难度 4-6：错误可被人工复核 / 兜底，但成本高。
- 难度 7-10：错误直接进生产路径或高价值资产（财务报表、医疗诊断）。

### 决策密度

- 难度 0-3：流程主要做机械转换（提取、搬运、格式化）。
- 难度 4-6：需要少量主观判断（分类、命名、摘要）。
- 难度 7-10：需要多步推理 / 多条件权衡 / 创造性方案。

### 可验证性

- 难度 0-3：指标体系完整、可对比、可追溯。
- 难度 4-6：有少量指标但口径不统一。
- 难度 7-10：没有可量化指标。

## 改造建议触发表

按以下规则决定最终建议：

| 建议 | 触发条件 |
|---|---|
| **全量改造** | 5 维度难度均值 ≤ 4 + 没有命中任何「不适合」硬护栏 + ROI 分数 ≥ 7 |
| **部分改造** | 命中 1-2 个硬护栏，或难度均值 5-7，或 ROI 分数 4-6 |
| **不适合** | 命中 ≥ 3 个硬护栏，或 ROI 分数 ≤ 3，或难度均值 ≥ 8 |

### 「不适合」硬护栏

任意一项命中即计入硬护栏计数：

- 监管 / 合规要求严格（医疗诊断、财务报表、司法结论）。
- 实时性硬要求（毫秒级决策、高频交易、运动控制）。
- 高精度 / 严格一致性（像素级比对、精确数值计算、零容错生产路径）。

### 「可改造」强信号

任意一项命中即增强改造信心：

- 输入高度结构化 / 输出允许多样。
- 决策步骤多 / 现有规则瓶颈明显。
- 有可量化指标衡量改造前后。
- 错误可被人工兜底或批量回滚。

## ROI 分数（xx/10）映射

| 分数 | 定性 | 含义 |
|---|---|---|
| 9-10 | 极高 | 投入低、收益高、立即回收 |
| 7-8 | 高 | 投入低-中、收益中-高、月级回收 |
| 5-6 | 中 | 投入中、收益中、季级回收 |
| 3-4 | 低 | 投入高、收益低、年级回收 |
| 1-2 | 极低 | 投入高、收益微、不可回收 |
| 0 | 信息不足 | 关键信息缺失，无法判断 |
