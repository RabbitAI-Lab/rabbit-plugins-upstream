## Description: <br>
Helps API developers and backend teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, backend teams, developer-experience teams, and maintainers use this skill to turn API documentation requests into practical workflows, checklists, code or configuration guidance, and validation steps for REST API OpenAPI or Swagger documentation. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger wording may activate the skill during general backend or API conversations that are not documentation tasks. <br>
Mitigation: Invoke it explicitly for OpenAPI or Swagger documentation work and ignore it when the request is unrelated. <br>
Risk: Generated documentation guidance can become inaccurate if it is not checked against the actual API behavior. <br>
Mitigation: Validate generated OpenAPI or Swagger artifacts against source routes, schemas, examples, and the stated success criteria before relying on them. <br>
