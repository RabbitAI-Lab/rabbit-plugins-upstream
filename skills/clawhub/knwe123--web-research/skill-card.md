## Description:

Guides an agent through structured web research with source prioritization, freshness checks, cross-source verification, and confidence reporting.

This skill is ready for commercial/non-commercial use.

## Publisher:

[knwe123](https://clawhub.ai/user/knwe123)

### License/Terms of Use:

MIT-0

## Use Case:

Agents use this skill when users request online search, current information, or feasibility checks. It helps structure search strategy, source validation, cross-checking, and concise reporting.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad feasibility-verification requests may trigger research beyond the user's intended scope.

Mitigation: Confirm the research goal and keep searches focused on the user's stated decision.

Risk: The skill prefers Chinese-language sources unless the user asks otherwise, which may miss more authoritative sources in other languages.

Mitigation: Prioritize official sources and adjust source language to the topic, jurisdiction, and user need.
