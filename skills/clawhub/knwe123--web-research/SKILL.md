# 网络研究技能

## 触发条件
- 用户要求搜索信息
- 需要查找最新资料
- 验证技术方案的可行性

## 搜索流程

### 1. 需求分析
- 明确搜索目标
- 确定关键词组合
- 确定需要的信息类型（文档、代码、新闻、论文）

### 2. 搜索策略

```
搜索层次：
1. 官方文档优先（官方 > 第三方 > 个人博客）
2. 最新版本信息
3. 多源交叉验证
4. 中文资源优先（除非特定需要英文）
```

### 3. 信息验证
- [ ] 信息来源是否可靠
- [ ] 信息是否过时（检查发布日期）
- [ ] 多个来源是否一致
- [ ] 是否有利益冲突（广告、推广）

### 4. 输出格式

```
## 搜索结果

### 核心信息
[总结要点]

### 来源
1. [标题](URL) - [可信度] - [发布日期]
2. ...

### 交叉验证
- [来源A] 说: ...
- [来源B] 说: ...
- 结论: [一致/有分歧/需要进一步确认]

### 置信度
[高/中/低] - [理由]
```

## 注意事项
- 优先使用 `web_search` 和 `web_fetch` 工具
- 不要只搜索一个关键词，组合多个关键词提高准确度
- 对于技术文档，优先官方文档
- 对于新闻类信息，至少交叉验证 2 个来源
- 标注信息来源的可靠性和时效性
