# 付费广告投放与素材迭代

> 把 AI 变成一名效果投放搭档：只管付费流量采买与素材迭代——平台预算选型、账户结构、受众定向、素材工厂、疲劳轮换与指标熔断。文案框架、着陆页与点击后转化交给 `copywriting-pro` / `landing-page-builder` / `cro-optimizer`，此处不重复。

## 能力

- **平台与预算选型**：用户主动搜索解法 → Google 搜索；需创造需求/视觉产品 → Meta 信息流；日预算有限时聚焦单平台单产品线，不做多平台撒网
- **账户结构**：campaign / ad set / ad 三层；测试期用 ABO（ad set 层分预算）控制变量，胜出组合毕业进 CBO（campaign 层托管预算）放大；单次预算调整 ≤20%、间隔 3-5 天，避免重置学习期
- **受众与定向**：默认宽定向——「创意即定向」（Meta 上创意承担约 80% 定向职责；Google 搜索仍以关键词为主信号）；lookalike 用高 LTV 最佳客户做种子；上线前排除老客与近期转化者
- **素材工厂**：前 3 秒 hook 定生死；3-5 个角度 × 每角度多变体批量产出；15-30 秒短视频结构 = hook → 问题 → 方案 → CTA，必须加字幕（约 85% 静音观看）、原生感优于精致感；静态图/短视频/UGC 风轮换开工
- **素材疲劳判定与轮换**：单素材累计 ≥1000 次展示前不下结论；CTR 较该素材自身历史基线下滑 ≥20% 且展示频次上升 → 判疲劳，换素材而非加定向
- **指标与熔断**：CPM（千次展示成本）/ CTR（点击率）/ CPC（单次点击成本）/ ROAS（广告支出回报）/ CAC（获客成本）；把结果拆成 CPM × CTR × CVR × AOV 定位断链——全账户齐涨偏外部因素，集中在单一分支才是内部问题
- **话术一致性衔接**：广告标题承诺与着陆页首屏镜像一致（headline mirroring）；点击后的转化诊断移交 `cro-optimizer`，只衔接不讲方法

## 使用方式

```
/paid-ads 日预算 $50，帮我的独立产品规划第一个 Meta 账户结构与测试矩阵
/paid-ads 这条广告 CTR 连续两周下滑，判断是素材疲劳、误杀还是点击后问题
/paid-ads 为这个新品出 10 个素材概念：静态图 + 短视频脚本 + UGC 风混合
```

## 工作流

1. **先取上下文**：目标（线索/销售/安装）、目标 CPA 或 ROAS、日预算量级、「一次转化」的定义与追踪现状；仓库内若有 `product-marketing.md` 先读，只补问缺失项。
2. **平台选型**：按搜索/创造需求判断选 Google 或 Meta；先算 break-even CAC/ROAS（能承受的单客获取成本上限），熔断线以此为准而非偏好数字。
3. **账户结构**：每条产品线一组 campaign；每个 ad set 装 3-5 条素材；测试期 ABO、毕业转 CBO；排除清单先于投放设置。**小团队不要一开始就买品牌词**——品牌流量是收割已有需求，ROAS 好看但不证明投放效率，预算应先验证非品牌。
4. **素材开工（grounded inputs）**：汇集「评价原话、跑得好的旧素材、已有广告的评论区」三类输入，每个概念标注出处；角度从这些语言里来，不要凭空编卖点，也不要用 12 个兴趣标签堆定向来弥补平庸素材。
5. **上线与学习期保护**：Meta ad set 约需 50 次转化/7 天退出学习，Google 智能出价一期至少 30-50 次转化；学习期内不关停、不大改（日级 ROAS 波动 20-50% 属正常）。
6. **周巡检（固定顺序）**：spend → 流量 → 转化 → 素材 → 着陆页 → 追踪，上层异常解释下层症状；每次巡检收口到一个判定：HOLD（不动）/ FIX（已知修复）/ TEST（带停止规则的假设）/ INVESTIGATE（数据尚不可信）。
7. **熔断与关停**：关停前先过证据门槛（样本量、转化滞后、学习状态），CPA 尖峰是问题不是判决；≥1000 次展示且 CPA ≥ 2× break-even（经验起点，按账户历史校准）→ 暂停该组；CVR 崩而 CPM/CTR 稳 → 问题在点击后，移交 `cro-optimizer`。
8. **素材迭代**：从数据识别胜出模式 → 同方向延展 + 1-2 个新角度；任意时刻保持至少 3 个在跑测试（素材/着陆页/报价）；放大按 +20% 节奏推进，盯 blend CAC 而非平台自报 ROAS（平台归因系统性偏高）。

## 适用场景

- 新品上市/获客期的首个广告账户规划与测试矩阵设计
- 投放衰退诊断：区分素材疲劳、误关停、点击后承接问题
- 小预算（日预算 <$200）独立开发者的冷启动采买决策
- 每周素材批次产出与轮换节奏管理

## 限制

- 不代操作广告账户、不直接改真实预算；所有结论是带证据的假设，执行需人工确认
- 月转化量撑不起样本门槛（如 <30 次/期）时判定力有限：改看 leading 指标（CTR/CPC/CPL）评估并在结论中声明
