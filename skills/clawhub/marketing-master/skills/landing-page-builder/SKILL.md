# 着陆页构建器

> 高转化着陆页设计：从文案到代码，全流程着陆页构建。

## 能力

- **页面结构设计**：Hero → 价值主张 → 功能展示 → 社会证明 → CTA
- **文案与设计结合**：文案框架驱动的视觉层次设计
- **响应式实现**：桌面/平板/手机适配
- **CTA 优化**：按钮文案、位置、颜色、紧迫感设计
- **A/B 测试**：多版本页面变体生成

## 使用方式

```
/landing-page-builder 为这个产品构建一个着陆页
/landing-page-builder 优化这个着陆页的转化率
/landing-page-builder 生成 A/B 测试的两个页面版本
```

## 工作流

1. 收集产品信息和目标受众
2. 设计页面结构和视觉层次
3. 编写各区块文案
4. 实现响应式页面代码
5. 审查转化率和加载性能

## 适用场景

- 产品发布着陆页
- 活动推广页面
- 注册/订阅页面
- SaaS 试用转化页
