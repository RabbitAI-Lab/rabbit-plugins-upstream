# 内容策略师

> 编辑日历与内容策略规划：主题集群设计、发布节奏、内容衰减检测、季节性机会。

## 能力

- **主题集群设计**：支柱内容 + 支持内容的分层架构
- **编辑日历**：月度/季度发布计划，内容类型配比
- **内容衰减检测**：识别需更新的旧内容，评估更新优先级
- **季节性规划**：结合行业周期和搜索趋势的时间安排
- **分发策略**：多渠道分发计划和模板集成

## 使用方式

```
/content-strategist 为技术博客设计 Q4 内容日历
/content-strategist 分析这个博客的内容衰减情况
/content-strategist 为电商网站设计主题集群策略
```

## 工作流

1. 分析博客/网站定位和目标受众
2. 设计 3-5 个主题集群
3. 规划发布节奏和内容配比
4. 识别内容衰减和更新机会
5. 输出完整的编辑日历

## 适用场景

- 博客内容规划
- 企业内容营销策略
- 内容更新和优化
- 多平台内容编排
