# 政采投诉胜诉率预判（类案判例法·攻向）

> 供应商/投诉人攻向的政采投诉"胜诉率"预判模型。输入自身遭遇的不公情形，通过投诉事项结构化拆解 + 5万+ 真实投诉处理决定类案相似度比对，以**真实检索样本计数**给出投诉成功率（成立率）预测，并按"证据充分性"做条件分层，输出证据收集与补强路线图。

## 能做什么
- 将你描述的不公情形归类为标准化投诉事项（参数设置-倾向性、评分错误-客观分不一致、未通过符合性审查、技术参数-实质不达标、程序违法-应回避/串通排斥 等）。
- 从「政府采购投诉AI知识库」（5万+ 真实投诉处理决定）匹配高度相似类案，逐篇标注处理结果（成立/驳回/部分成立）与投诉人证据强度（强证据/弱证据）。
- 以真实样本计数给出**整体成立率**与**证据条件成立率**（强证据层 vs 弱证据层），并附样本量 N 与 Wilson 95% 置信区间。
- 对照"弱证据层高驳回率"规律，给出法定、合法的取证路线图与时限警示。

## 典型场景
> 供应商："中标产品参数不满足招标★实质性要求，我只有官网宣传页和招标文件截图，没有检测报告。"
> 系统：归为「技术参数-实质不达标（虚假应标）」→ 落在**弱证据层** → 该层历史驳回率高（以真实样本计数佐证，附 N 与置信）→ 建议：在法定质疑期（7 工作日）内，向采购人申请公开中标产品详细规格型号，并送样机至第三方检测机构出具检测报告；补齐前不宜以该事项为主诉。

## 核心纪律（为什么可信）
1. **胜率必基于真实样本计数**：任何成立率/驳回率数字都来自本次检索并成功标注的样本，禁止凭直觉给"90%"。
2. **查询禁含结果词**：检索式不出现"驳回/成立/胜诉"，避免污染分布。
3. **排除法规噪声与港澳台**：法规文档不计入样本；港澳台案例因法域不同排除。
4. **证据充分性分层**：强证据层（官方检测报告/注册证/第三方证明/实物）与弱证据层分别计数、分别给率。
5. **类案非判例**：中国系成文法国家，类案仅作参考、非约束性先例；胜率为统计估计、非法律承诺。
