# 胜诉率计算方法论文档（winrate-methodology）

> 本文件定义 `gp-complaint-winrate` 的胜率计算规则。核心原则：**胜率必须来自本次检索并成功标注的真实样本计数，禁止模型凭直觉给出百分比**（SKILL 铁律2）。本文件是公式与边界条件的权威来源。

---

## 一、为什么不能"拍脑袋给 90%"
用户原例"被驳回概率超90%"是**条件概率**：P(驳回 | 参数不达标 & 仅公开资料 & 缺官方检测报告)。该数字只能从历史类案的"该证据分层"样本中统计得出，模型无法凭空保证。任何百分比须可溯源到（a）检索式、（b）命中样本、（c）逐篇标注的结果与证据强度。

---

## 二、样本来源与清洗
1. **检索**：`search_knowledge(knowledge_base_id=7450416392468005, query=<类别+事实词,禁结果词>)`，`min_relevance≥0.82`。
2. **去法规噪声**（铁律5）：剔除标题含 `办法/通知/规范/财政部令/国务院部门文件/管理条例/关于印发` 的文档——这些是第7463496212028405的法源，不是案例。
3. **去港澳台**（铁律6）：剔除中国香港/澳门/台湾案例。
4. **挑候选**：按相关度取 Top-N（目标 12–18）高度相似候选。
5. **拉全文**：对候选调 `fetch_media_content(media_id)` 抽取"投诉事项/事实认定/三、处理决定/证据形式"。
6. **容错**：拉取失败/仅元数据 → 标【信息待补】，不计入分母（SKILL 三段式·单篇获取容错）。

---

## 三、结果标签抽取
每篇全文抽取一个 `outcome ∈ {成立, 驳回, 部分成立}`：
- 定位"三、处理决定"段：`驳回投诉`/`缺乏事实依据，驳回` → 驳回；`投诉成立`/`部分成立`/`责令重新采购`等 → 成立/部分成立。
- 快捷判定：`title` 为"驳回投诉处理决定书"可直接判驳回（省一次 fetch）；其余标题格式（投诉处理结果公告/投诉事项的处理决定/行政裁决）**必须拉全文判定**。

---

## 四、证据强度分层（第四步核心）
对每篇已拉全文的样本，额外标注 `evidence ∈ {强, 弱}`：
- **强证据**：投诉人提供了官方检测报告 / 行政许可注册证公开比对 / 第三方认证 / 实物样机 / 合法取得的客观材料 / 评审报告与评分明细横向对比。
- **弱证据**：仅公开资料（官网宣传页、招标截图）/ 自我推测 / 书面承诺 / 非法取得的材料（偷拍窃录、侵入系统）。

> 证据分层是胜率预判的价值核心：同一投诉事项类别，强证据层与弱证据层的历史成立率可能相差极大（用户原例即弱证据层高驳回）。

---

## 五、计算公式
设样本有效标注数 `N = a + b + c`：
- `a` = 成立数，`b` = 驳回数，`c` = 部分成立数。

**整体成立率**（第三步）：
```
rate_overall = (a + 0.5·c) / N
```

**证据分层成立率**（第四步）：在强/弱子样本内分别套用：
```
rate_strong = (a1 + 0.5·c1) / (a1 + b1 + c1)    # 强证据层
rate_weak   = (a2 + 0.5·c2) / (a2 + b2 + c2)    # 弱证据层
```
其中 (a1,b1,c1) 为强证据层计数，(a2,b2,c2) 为弱证据层计数，a1+a2=a 等。

---

## 六、置信度与区间
- **置信等级**：N≥20 较高 / 10≤N<20 中等 / N<10 低（须显式标注"低置信"）。
- **Wilson 95% 置信区间**（小样本更稳，z=1.96）：
```
中心 p̃ = (x + z²/2) / (N + z²)                # x = a + 0.5c（或分层内对应值）
半宽 h = z·√[ x(N−x)/N + z²/4 ] / (N + z²)
区间 = [p̃ − h, p̃ + h]
```
- 输出时一律给出 `[下限%, 上限%]`，避免单点数字误导。

---

## 七、预测映射（第五步）
将"我方现有证据"映射到强/弱层，给出：
- **整体口径** `rate_overall`（历史总体参考）；
- **条件口径** `rate_strong` 或 `rate_weak`（与我方证据现状对应的分层率）——这是用户最关心的"本案胜率"。
- 若我方证据为弱层且 `rate_weak` 低 → 触发第六步取证路线图，警示"补齐__前不宜以该事项为主诉"。

---

## 八、降级与容错
- 案例库不可检索 → 整体降级【依据待核】，不得伪称算率。
- 某层 N<10 → 标注低置信，建议用 `cursor` 翻页扩样后重算。
- 【信息待补】篇不计入分母，输出注明"有效 N=X，Y 篇待补未计"。
- 检索为空 → 【依据待核】，不幻觉。

---

## 九、反模式（禁止）
1. ❌ 直接输出"被驳回概率超90%"而无样本计数与 N。
2. ❌ 查询含"驳回/成立"导致分布污染。
3. ❌ 把法规文档计入样本。
4. ❌ 凭标题"投诉处理结果公告"臆断结果（须拉全文）。
5. ❌ 只给整体率、不做证据分层。
6. ❌ N<10 仍声称"高置信"。
