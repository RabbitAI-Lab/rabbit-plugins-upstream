## Description:

Guides agents through creating and editing Unity games, sourcing licensed assets, automating the editor, and verifying WebGL builds.

This skill is ready for commercial/non-commercial use.

## Publisher:

[deepseekoracle](https://clawhub.ai/user/deepseekoracle)

### License/Terms of Use:

MIT No Attribution

## Use Case:

Game developers and agents use this skill to build and revise Unity 2D and 3D projects, select reusable art, and deliver browser-playable WebGL builds with verification.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Unity setup and asset sourcing can involve large downloads and local project changes.

Mitigation: Confirm installation and download scope with the user, and check each asset's licence before use.

Risk: Editor automation can require credentials, pausing other processes, or publishing a build.

Mitigation: Leave credential entry, process pausing, and publishing under explicit user control.
