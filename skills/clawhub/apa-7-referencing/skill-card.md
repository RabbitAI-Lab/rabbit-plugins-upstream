## Description:

Clean generic APA 7 referencing (English conventions): reference lists, in-text citations, DOIs, secondary sources, quotes, tables. Use for any paper requiring APA 7 style.

This skill is ready for commercial/non-commercial use.

## Use Case:

Students, researchers, editors, and writing assistants use this skill to format English-language APA 7 reference lists and in-text citations, including DOI handling, secondary sources, quotations, and consistency checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Institution-specific or locale-specific APA requirements may differ from generic English APA 7 conventions.

Mitigation: Verify local requirements and use a locale-specific or institution-specific skill when required.

Risk: Citation-formatting guidance can still produce incorrect or mismatched references if source metadata is incomplete or inaccurate.

Mitigation: Check each in-text citation against the reference list and verify source metadata before submission.
