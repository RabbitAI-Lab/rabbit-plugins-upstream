## 能为你做什么（四大优惠场景）
---

### 一、高新技术企业认定
- 📋 **认定条件梳理**：注册年限、知识产权、技术领域、科技人员占比、研发费用占比、高新收入占比、创新能力评价等逐项核验
- 🧮 **指标测算**：研发费用占比（按收入分档阈值）、高新收入占比、创新能力得分（达标线）测算
- 🏢 **优惠衔接**：减按优惠税率、亏损结转延长等优惠的适用与衔接
- ⚠️ **风险预警**：研发费用归集不实、高新收入混淆、资格撤销补税、未按要求年报

**典型问法：**
```
"高新技术企业认定条件有哪些？"
"研发费用占比怎么计算？"
"高新收入占比怎么认定？"
"高新企业能享受什么税收优惠？"
"高新资格被撤销要补税吗？"
```
---

### 二、研发费用加计扣除
- 🧮 **加计测算**：费用化按规定比例加计、无形资产按规定比例摊销（部分行业更高）的加计额测算
- 📚 **归集范围**：人员人工、直接投入、折旧、无形资产摊销、其他相关费用限额等归集边界
- 🔍 **特殊情形**：委托研发（按实际额80%计入）、合作研发、集中研发的归集与分摊
- ⚠️ **风险预警**：负面清单行业不得加计、虚列研发费用、分摊不清、辅助账缺失
- 🧾 **人员人工费用归集**：研发人员范围（直接从事研发）、工时分配、工资归集期间、五险一金与外聘劳务费口径、留存备查资料，规避归集六大易错点被调减补税

**典型问法：**
```
"研发费用加计扣除比例是多少？"
"哪些行业不能享受研发加计？"
"委托研发怎么加计扣除？"
"其他相关费用10%限额怎么算？"
"研发辅助账怎么设置？"
"研发人员人工费用归集有哪些易错点？"
```

### 三、税收优惠匹配
- 🔎 **全税种速查**：增值税、企业所得税、小税种、地方税费、社保费等优惠政策的适用条件与享受方式
- 🎯 **资质规划**：结合企业行业、规模、研发活动，匹配可适用的优惠组合与申报节奏
- 📋 **留存备查**：优惠享受的资料留存与备查清单，降低后续核查风险
- 🌍 **离境退税优化**：境外旅客购物离境退税无纸化、"即买即退"异地通办、小额抽检（税总货劳发〔2026〕37号）

**典型问法：**
```
"企业能享受哪些税收优惠？"
"小微企业有哪些所得税优惠？"
"先进制造业有什么增值税优惠？"
"环保税有哪些免征减征？"
```
---

### 四、西部大开发优惠与专精特新
- 🏔️ **西部大开发优惠**：注册在西部地区的鼓励类产业企业减按 15% 税率征收企业所得税，政策执行至 2030 年 12 月 31 日
- 📑 **鼓励类产业判定**：主营收入占比（鼓励类产业收入占收入总额）须按规定比例，以《西部地区鼓励类产业目录（2025 年本）》（564 条）为准
- 🧭 **总分机构规则**：总分机构所处地区不同、优惠资格不同的，按各自适用税率就地缴纳，不可一刀切适用 15%
- 🌟 **专精特新支持**：专精特新"小巨人"企业可叠加享受研发加计、固定资产加速折旧、先进制造业增值税加计抵减等优惠，并享梯度培育财政奖补
- ⚠️ **风险预警**：主营收入占比不达标、目录外业务混入、与高新 15% 优惠叠加边界不清、小巨人资格复核不通过

**典型问法：**
```
"西部大开发税收优惠怎么享受？"

"西部地区总分机构怎么交企业所得税？"
"专精特新小巨人有什么税收优惠？"
"西开优惠和高新优惠能同时享受吗？"
```
