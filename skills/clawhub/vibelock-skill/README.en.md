## FAQ

**Q: Do I need to install any tools?**
A: The Skill itself has zero local dependencies and bundles no tool scripts. When executing a plan, the AI guides you to install the corresponding open-source tools (such as PyArmor, garble, etc.) based on your tech stack.

**Q: Is my code safe? Will it be uploaded to a server?**
A: Code obfuscation and AES-256 encryption are **done entirely locally — source code is never uploaded to any server**. The platform only stores your encrypted artifacts and license data.

**Q: Can a complete beginner really use it?**
A: Yes. Plan A is copy-paste commands, done in 30 minutes; Plan D has the AI Agent auto-generate C code — just follow the guidance, no professional security background needed.

**Q: Can your solution block all attackers?**
A: Pure software protection has no absolute security. Plans A/B/C block 95% of automated attacks, script kiddies, and beginner reverse engineers; Plan D blocks most professional reverse engineers through 7-layer defense-in-depth. The goal is "make the cost of cracking > software value × 3".

**Q: How does the pricing work?**
A: A one-time ¥99 unlocks merchant identity (includes the Skill + 5-year license credit allowance); afterwards you top up Credits by usage (¥20 = 365 Credit); marketplace transactions are charged a 10% fee, renewals are fee-free.
