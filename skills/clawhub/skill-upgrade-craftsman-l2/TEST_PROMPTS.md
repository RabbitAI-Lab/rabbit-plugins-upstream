# 技能升级巧匠 L2 - 测试题库

- 适用对象：`技能升级巧匠 L2`
- 测试目标：验证 L2 是否能正确执行五机制会诊、分流判断、逐项改造和成体系交付

## 使用说明

每一道题都附了一个真实的 Skill 草稿或片段，直接复制发送给部署好的 L2 智能体即可。

重点观察：

- 它会不会先做五机制会诊而不是上来就改
- 它能不能正确判断该进 L1 还是 L2
- 它会不会指出 frontmatter / description / 边界 / 伪联动问题
- 它交付的升级版是否包含完整的输出契约

---

## 测试题 1：frontmatter 缺失 + 伪联动测试

**测试目标**

- 测 L2 能否识别 frontmatter 致命硬伤
- 测 L2 能否识破“自动中途调用”的不可执行设计

**复制发送**

```text
我这里有一个公众号写作 Skill，你帮我按 L2 标准升级一下。

【原始技能】
name: 公众号写作
description: 专业的公众号文章写作助手，帮你写出爆款文章。

# 公众号写作助手

当用户提出写作需求时，自动调用以下流程：
- 先调用 AI概念速通巧匠 做概念解释
- 然后调用 内容选题巧匠 确定选题方向
- 最后生成正文

写作时注意语气要像陪朋友聊天。
```

**理想表现**

- 应指出 frontmatter 缺 trigger
- 应指出“自动调用”是不可执行的伪联动，应改为“推荐下一步”
- 应指出 description 太泛、没有口语场景词
- 应给出 L2 分流判断（这个 Skill 适合进 L2）

---

## 测试题 2：description 内部化 + 边界模糊测试

**测试目标**

- 测 L2 能否识别 description 写成了“内部介绍”而不是“路由说明”

**复制发送**

```text
这是一个备课 Skill，你帮我诊断一下，看看 description 和边界有没有问题。

【原始技能】
name: 海涛AI备课助手
description: 基于朱海涛（朱老师）的飞书课件、谭毅私教课问答清单和备课笔记，采用六步备课流程，帮助培训讲师快速产出高质量授课方案。已服务邻玉街道、邓玲教授等多次政府培训场景。

# 备课助手

适用场景：任何备课需求都可以找我。
```

**理想表现**

- 应指出 description 内部化严重（朱老师、飞书课件、邻玉街道、邓玲教授）
- 应指出适用场景太宽（“任何备课需求”），没有边界
- 应指出 description 没有用户口语场景词（“帮我备课”“做个培训PPT”）
- 应按 F-003 标准给出重写版的 description

## 测试题 3：多技能去打架测试

**测试目标**

- 测 L2 能否判断多个 Skill 之间抢活的问题

**复制发送**

```text
我目前有 3 个 Skill，但它们经常互相抢活。你帮我看看问题在哪。

Skill A：内容选题巧匠
description：帮用户找选题、想角度、确定写作方向。

Skill B：提示词巧匠
description：帮用户写提示词、优化提示词，也承接写作类需求。

Skill C：公众号写作巧匠
description：帮用户写公众号文章。

问题：用户说“帮我写一篇公众号文章”时，B 和 C 经常同时抢。用户说“帮我优化一下提示词”时，B 会响应，但用户只是想改文章里的一句话写法，不是真的要优化 prompt。
```

**理想表现**

- 应指出 B 的 description 里“也承接写作类需求”是越界
- 应按 F-002 标准给出：谁独占哪些入口词、谁是什么角色
- 应给出明确的 trigger 分工建议

---

## 测试题 4：上下游衔接缺失测试

**测试目标**

- 测 L2 能否发现输出模板缺少“下游传递摘要”

**复制发送**

```text
我的内容创作链路由 3 个 Skill 组成：
- 内容选题巧匠（先出选题角度）
- 公众号写作巧匠（再写正文）
- 叙事节奏巧匠（最后审稿）

现在的问题是：选题巧匠出完结果后，写作巧匠不知道“选了什么题、什么角度、目标读者是谁”，每次用户还得自己复制粘贴一遍。

你帮我看看怎么改。
```

**理想表现**

- 应按 F-005 标准指出每个上游 Skill 需要补“下游传递摘要”
- 应给出具体的摘要字段示例
- 应指出“用户自己复制粘贴”说明输入输出契约没建立

---

## 测试题 5：命名混乱测试

**测试目标**

- 测 L2 能否识别并修正中英文/拼音混搭命名

**复制发送**

```text
我这里有几个 Skill 的名字很乱，你帮我统一一下：

1. wechat-article-analyzer（中文叫“微信文章收录助手”）
2. feedback-draft-reviser（中文叫“反馈改稿巧匠”）
3. guizang-ppt-skill（中文叫“归藏PPT”）
4. print-designer（功能都不太清楚）

用户经常叫不出它们的名字，只记得“那个收文章的”“改稿那个”。
```

**理想表现**

- 应按 F-004 标准指出 frontmatter 中应统一中文名，英文名降为 alias
- 应指出 print-designer 的功能边界需先确认
- 应给出统一的命名方案

---

## 测试题 6：完整 L2 升级包交付测试

**测试目标**

- 测 L2 能否完成一个完整 Skills 的端到端 L2 升级交付

**复制发送**

```text
请你对这个 Skill 做一次完整的 L2 升级，从诊断到交付，不要漏步骤。

【原始技能】
name: 知识库建设巧匠
description: 帮助用户搭建和整理个人知识库。

# 知识库建设巧匠

你可以帮用户：
- 整理知识素材
- 建立知识条目
- 搭知识框架

工作流程：
1. 先了解用户有什么知识素材
2. 然后帮用户分类
3. 最后输出知识库结构
```

**理想表现**

- 应先做五机制会诊（指出缺 trigger、description 太泛、边界不清）
- 应给分流判断
- 应给出完整的 L2 升级方案
- 应交付升级版 SKILL.md（含 frontmatter、trigger、边界、输出契约、下游摘要、推荐下一步）
- 应附带测试题库和验证记录模板
