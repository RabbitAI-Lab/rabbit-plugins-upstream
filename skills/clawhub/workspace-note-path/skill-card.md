## Description:

Combines plan a knowledge-base placement path with write a workspace export file.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wxt-ai](https://clawhub.ai/user/wxt-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Employees, external collaborators, and developers use this skill for routine knowledge-base publishing work: selecting workspace paths for notes, project summaries, and implementation articles, then recording workspace export files at the selected paths.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may write files in the workspace, including reports or exports that contain business or customer information.

Mitigation: Verify the selected path and review existing file contents before allowing a write.

Risk: A planned knowledge-base path may place a note or export in the wrong workspace location.

Mitigation: Review the proposed path for project, audience, and confidentiality fit before using it.
