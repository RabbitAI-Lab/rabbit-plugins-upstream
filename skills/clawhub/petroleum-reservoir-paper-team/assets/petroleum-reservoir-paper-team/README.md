# 石油工程油藏论文写作专家团

一个面向石油工程油藏方向的八角色学术写作协作团队，覆盖选题、调研、知识整合、写作、事实核查、风格打磨、审稿与排版全链路。

## 类型

Team 型（多角色协作团队）

## 功能

- **选题策划**：从模糊方向中挖掘高价值、可操作的论文选题
- **文献与数据调研**：检索 OnePetro、EI、Scopus、Web of Science、CNKI、万方、维普等数据库
- **知识整合**：将多平台笔记统一整理为结构化知识库
- **学术写作**：将素材转化为符合期刊规范的论文初稿
- **事实核查**：逐条核对数据、引用、公式与实验细节
- **风格打磨**：学习用户文风，统一全文表达
- **审稿评级**：按核心期刊标准进行多维度质量评定
- **排版输出**：生成符合目标期刊要求的最终稿与投稿清单

## 使用示例

- 帮我选题：基于深度学习压裂停泵压力去噪方向，推荐3个有创新性的论文选题
- 整理我的研究笔记，生成一份石油工程油藏方向论文大纲
- 审阅这篇油藏工程论文初稿，按核心期刊标准给出修改意见

## 安装

将专家包目录放到专家目录下：

```
C:\Users\user\.workbuddy\plugins\marketplaces\my-experts\plugins/petroleum-reservoir-paper-team/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r petroleum-reservoir-paper-team.zip petroleum-reservoir-paper-team/
```
