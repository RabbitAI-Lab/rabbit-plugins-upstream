# 版权与使用边界（元案 yotta-lesson）

## 一、不含教材与题目原文

- 映射包只记录结构性元数据：课题 id / 名称、单元、知识点名称、重难点、易错点、课标条目标识；
- 本技能不内置、不下载、不缓存教材课文、课标正文、教辅题目与考试真题；
- 教案骨架中的环节要点为通用教学动作描述，不含具体题目内容；例题与练习的具体内容由教师自行编写或引用合法来源。

## 二、课标与来源引用

- `standard` 字段要求填写可核对的课标来源标识（如「义务教育数学课程标准（2022 年版）· 方程与不等式」）；
- 引用标注用于**可追溯**，不代表本技能对课标内容作出解释；解读与适用以官方文本和教研判断为准；
- 若学校对来源写法有规范（如校内编号），可在 `standard` 中按规范书写，`check` 会按该文本核对。

## 三、教师责任与免责

- 本技能输出的是教案骨架与结构性缺口清单，属于**备课辅助**；
- 教学目标设定、环节设计、时间取舍、作业布置的最终决定由教师负责；
- 发布或提交教案前，请教师自行核对知识点表述、来源标注与本校规范；
- 固定免责声明：本文件由元案（yotta-lesson）基于本地映射包与结构配置的确定性计算生成，
  仅作备课辅助；教学设计与时间安排的最终决定由教师负责，课标引用请以官方文本为准。

## 四、数据边界

- 本地运行：核心路径零网络、零模型调用；教案草稿、映射包与结构配置只在本机流转；
- 不产生遥测、不上报、不建远程副本；
- 若将教研组映射包用于共享，请确认其中不含不宜外传的校本信息（如班级、教师姓名）。

## 五、与其他技能的分工

- 组卷与试卷结构校验：属元题 yotta-item（从题库选题，不生成题面）；
- 学情数据分析：属元镜 yotta-mirror；
- 含个人信息的材料合规审查：属元规 yotta-compliance；
- 对外呈现与去 AI 味：属元呈 / 元真。
