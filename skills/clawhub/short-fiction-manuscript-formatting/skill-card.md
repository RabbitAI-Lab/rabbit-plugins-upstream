## Description:

Formats a single short story as a submission-ready Courier New DOCX manuscript using modern short-fiction conventions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ryubyss](https://clawhub.ai/user/ryubyss)

### License/Terms of Use:

MIT-0

## Use Case:

Writers and their assistants use this skill to turn one short story into a submission-ready DOCX with contact details, title, byline, rounded word count, scene breaks, and a running header. It does not format novels or Shunn Classic manuscripts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The requested output path may already contain a file that the formatter overwrites.

Mitigation: Choose and confirm an output path before running the formatter; keep a copy of any existing file.

Risk: The finished manuscript can include the writer's legal name and contact information.

Mitigation: Provide only contact details intended for the submission, and review the DOCX before sharing it.
