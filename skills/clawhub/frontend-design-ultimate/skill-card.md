## Description:

Create distinctive, production-grade static sites with React, Tailwind CSS, and shadcn/ui from plain text requirements, with anti-generic design guidance, mobile-first responsive patterns, single-file bundling, and Vite or Next.js workflows.

This skill is ready for commercial/non-commercial use.

[aiepco](https://clawhub.ai/user/aiepco)

### License/Terms of Use:

Apache 2.0

## Use Case:

Developers and frontend builders use this skill to generate production-ready static web interfaces, landing pages, marketing sites, portfolios, and dashboards from text requirements. It helps choose a bold visual direction, scaffold React/Tailwind/shadcn projects, apply responsive design patterns, and optionally bundle Vite output into one HTML file.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill includes workflows that run npm and npx commands and create or modify frontend project files.

Mitigation: Review the proposed commands before execution and run them in a fresh project directory with Node.js and npm available.

Risk: Broad frontend and marketing-site aliases may cause the skill to activate for general web UI requests.

Mitigation: Confirm that a React/Tailwind/shadcn static-site workflow is intended before following the generated scaffolding guidance.
