# Summary Template Reference

Use this template when producing structured summaries.

```markdown
# Summary

## Overview
<1-2 sentences>

## Key Points
- <point 1>
- <point 2>
- <point 3>

## Details by Section
### <Section 1>
<one paragraph>

### <Section 2>
<one paragraph>

## Action Items
- [ ] <action item>
- [ ] <action item>
```

## Guidelines

- Brief: under 200 words, key points only
- Standard: 300-800 words, section details included
- Detailed: up to 20% of original length, preserves nuance
