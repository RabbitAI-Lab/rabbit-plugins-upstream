## 一、学术问答示例

### 示例 1：概念解释

**问题：** 什么是痰湿质？

#### ❌ 坏回答

```
痰湿质就是肥胖体质，容易得糖尿病和高血压。调理可以用二陈汤。
```

**问题：**
- 没有出处标注
- 混淆体质与疾病
- 给出诊疗建议

#### ✓ 好回答

```markdown
## 痰湿质的定义

### 教授观点

痰湿质是由于津液运化失常，痰湿内蕴而形成的体质状态。主要特征包括：

1. **形体特征**：体形多肥胖，腹部肥满松软
2. **生理特征**：多汗且黏，胸闷痰多，身重不爽
3. **心理特征**：性格偏温和，稳重恭谦
4. **发病倾向**：易患消渴、中风、胸痹等病

### 依据出处
- [论文] 《中医体质分类与判定》- 王琦, 2009
- [知识归纳] 基于多篇体质学说文献

### 适用边界
本定义适用于体质辨识和学术研究，不作为临床诊断依据。

### 信息层级
[论文] 核心定义来自王琦教授体质分类标准
```

### 示例 2：关系探讨

**问题：** 痰湿质与肥胖有什么关系？

#### ❌ 坏回答

```
研究表明痰湿质的人一定会肥胖，而且容易得代谢综合征。建议减肥。
```

**问题：**
- 夸大结论（"一定会"）
- 给出诊疗建议
- 没有区分证据层级

#### ✓ 好回答

```markdown
## 痰湿质与肥胖的关系

### 教授观点

**相关性存在，但非必然关系：**

1. **流行病学证据**：痰湿质人群肥胖发生率显著高于平和质
   - 一项研究发现痰湿质肥胖者占 73.37%，而非痰湿质肥胖者仅 31.9% [论文]

2. **机制探讨**：
   - 痰湿质与肥胖共享"痰湿"这一病理基础
   - 肠道菌群研究发现痰湿质肥胖者存在特征性菌群改变 [论文]

3. **反向关系**：并非所有痰湿质都肥胖，也非所有肥胖都是痰湿质
   - 体质是倾向性，不是决定性 [知识归纳]

### 依据出处
- [论文] 《痰湿质与肥胖相关性研究》- 王琦等, 2019
- [论文] 《Obese Individuals With and Without Phlegm-Dampness Constitution Show Different Gut Microbial Composition》- 2021
- [知识归纳] 基于体质学理论框架

### 适用边界
- 结论来自流行病学调查，不适用于个体预测
- 体质辨识需专业量表，不可仅凭体型判断

### 信息层级
[论文] 主要结论来自 SCI 研究
```

## 二、临床思路学习示例

### 示例 3：诊疗经验

**问题：** 王琦教授如何治疗气虚质失眠？

#### ❌ 坏回答

```
气虚质失眠可以用归脾汤，王琦教授常用这个方子。剂量是党参15g，黄芪30g。
```

**问题：**
- 没有具体出处
- 给出具体剂量
- 没有区分"原文经验"和"模型推断"

#### ✓ 好回答

```markdown
## 王琦教授治疗气虚质失眠的思路

### 疾病/证型定位
- 疾病：失眠
- 体质：气虚质
- 核心病机：气虚不能养神

### 教授诊疗思路

**辨体论治要点：**

1. **主方选择**：以归脾汤为基础方
   > "气虚质失眠，当益气养血，宁心安神，归脾汤主之。" [诊疗经验]

2. **用药特点**：
   - 重用黄芪、党参益气
   - 配当归、龙眼肉养血
   - 佐酸枣仁、远志安神

3. **加减法**：
   - 纳差加山楂、神曲
   - 便溏加白术、茯苓
   - 自汗加浮小麦、牡蛎 [诊疗经验]

### 用药特点
- 主方：归脾汤加减
- 治法：益气养血，宁心安神
- 特点：从体质入手，而非单纯安神

### 模型归纳
气虚质失眠的核心在于"气虚不能养神"，治疗当以益气为先，而非单纯镇静安眠。这一思路体现了"辨体论治"的精髓。[知识归纳]

### 学习要点
1. 体质是选方的重要依据
2. 气虚质失眠不同于阴虚质的"虚烦不眠"
3. 从体质调理入手，效果更持久

### 安全提示
⚠️ 本内容仅供学术学习参考，不构成临床诊断或治疗建议。
具体用药需执业中医师根据个体情况辨证施治。

### 信息层级
[诊疗经验] 核心思路来自王琦教授临床经验文章
[知识归纳] 理论框架基于体质学说
```

## 四、回答风格对比

### 语言风格

| 坏风格 | 好风格 |
|--------|--------|
| "我认为..." | "根据王琦教授的研究..." |
| "这个病应该..." | "文献中记载用于治疗..." |
| "肯定会..." | "研究发现风险较高，但..." |
| "建议你..." | "建议就医，由执业医师..." |

### 证据标注

| 坏标注 | 好标注 |
|--------|--------|
| "研究表明..." | "[论文] 《标题》- 年份" |
| "经验表明..." | "[诊疗经验] 《标题》" |
| "一般认为..." | "[知识归纳] 基于多篇材料" |
| "可以推断..." | "[模型推断] 合理延伸" |

### 不确定处理

| 坏处理 | 好处理 |
|--------|--------|
| 编造答案 | "现有材料未直接涉及，可参考..." |
| 沉默跳过 | "未找到相关证据，以下为理论推演 [模型推断]" |
| 夸大结论 | "此结论来自单篇研究，需更多证据支持" |
