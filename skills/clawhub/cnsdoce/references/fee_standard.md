# 取费标准（山东省建设工程全专业）

> **适用标准**：
> - 国标：《建设工程工程量清单计价标准》GB/T 50500-**2024**（2025年9月1日起山东实施）
> - 省级：《山东省建设工程费用项目组成及计算规则》（**2025年版**，2025年11月1日起施行）
> - 市级：《济南市价目表(2026版)》
>
> **数据源**：`quota_reference.db` → `fee_rates` 表（34条，覆盖16个工程专业类型）
> 
> 本文件为权威取费依据，组价计算时必须引用本章参数。

---

## 0. 重大变化：规费科目取消（GB/T 50500-2024）

> ⚠️ **2025年11月1日起执行**
>
> 依据 GB/T 50500-2024《建设工程工程量清单计价标准》：
> - **取消"规费"科目**
> - 社会保险费、住房公积金并入人工费和企业管理费
> - 费用结构简化：人工费（含社保）+ 材料费 + 施工机具使用费 + 管理费（含社保统筹）+ 利润 + 税金
> - 不再单独计算规费费率

## 2. 综合单价计算公式（通用版）

### 2.1 通用计算步骤

```
已知：基价 = 人工费 + 材料费 + 机械费

--- 建筑/装饰/安装/园林/房屋修缮/古建筑修缮/仿古建筑 → 计费基础 = 人工费 ---
--- 市政/市政养护维修 → 计费基础 = 人工费 + 施工机具使用费 ---

Step 1: 管理费  = 计费基础 × 管理费费率
Step 2: 利润    = (计费基础 + 管理费) × 利润率
Step 3: 税前综合单价 = 基价 + 管理费 + 利润
Step 4: 税金    = 税前综合单价 × 9%
Step 5: 含税综合单价 = 税前综合单价 + 税金
```

### 2.2 安装工程专用公式

```
管理费  = 人工费 × 48.08%
利润    = (人工费 + 管理费) × 29.15%
         = 人工费 × 1.4808 × 0.2915
         = 人工费 × 43.16%
管理费+利润 = 人工费 × 91.25%

税前综合单价 = 基价 + 人工费 × 91.25%
含税综合单价 = (基价 + 人工费 × 91.25%) × 1.09
```

> **重要区分**：`基价` = 人工费 + 材料费 + 机械费（全口径）；`计费基础` = 人工费（仅人工费部分参与管理费和利润的计算）

### 2.3 综合费率速算公式

**通用公式**：
```
综合费率 (管理费+利润) = 管理费费率 × (1 + 利润率) + 利润率

验证（安装工程）：48.08% × 1.2915 + 29.15% = 62.09% + 29.15% = 91.24% ✓
```

| 计费基础类型 | 计费基础 | 管理费基数 | 利润基数 |
|-------------|---------|-----------|---------|
| 人工费型 | 人工费 | 人工费 | 人工费 + 管理费 |
| 人+机型 | 人工费+施工机具使用费 | 人工费+机具费 | 人工费+机具费+管理费 |

### 2.4 Excel 公式参考（通用模板）

| 列名 | Excel 公式 | 说明 |
|------|-----------|------|
| 计费基础 | `=[@人工费]+IF(工程类型="市政",[@机械费],0)` | 市政工程含机具费 |
| 管理费 | `=[@计费基础]*管理费率` | 按工程类型查表 |
| 利润 | `=([@计费基础]+[@管理费])*利润率` | 按工程类型查表 |
| 税前综合单价 | `=[@基价]+[@管理费]+[@利润]` | |
| 含税综合单价 | `=[@税前综合单价]*(1+9%)` | 增值税一般纳税人 |
| 税金 | `=[@税前综合单价]*9%` | |
| 合价 | `=[@工程量]*[@含税综合单价]` | |

## 12. 数据库查询参考

`quota_reference.db` → `fee_rates` 表查询示例：

```sql
-- 查询安装工程费率
SELECT * FROM fee_rates WHERE engineering_type = '安装工程';

-- 查询建筑工程I类费率
SELECT * FROM fee_rates WHERE engineering_type = '建筑工程' AND engineering_class = 'I';

-- 查询所有市政工程子类费率
SELECT * FROM fee_rates WHERE engineering_type = '市政工程' ORDER BY engineering_subtype;

-- 查询所有以"人工费"为计费基础的专业
SELECT DISTINCT engineering_type FROM fee_rates WHERE calculation_base = '人工费';
```
