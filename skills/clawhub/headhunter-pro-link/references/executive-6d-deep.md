# 高管 6 维度评估深化模块（2026-09-07 新增）

> 高管选错成本 = 年薪 200-400%，~40% C 级失败因文化不适配

## 6 维度评估深化

| 维度 | 评估要点 | 红旗信号 | 评估工具 |
|------|---------|---------|---------|
| **人才触达** | 产业链分析+Mapping+人脉深度 | 只能搜公开简历，无被动候选人触达 | Mapping 覆盖率报告 |
| **保密机制** | 匿名寻访+信息隔离+话术设计 | 在公开渠道暴露客户身份 | 保密协议+信息隔离检查 |
| **薪酬谈判** | 总薪酬包+股权+竞业+对标架构 | 只会传话，不会设计薪酬结构 | 薪酬架构文档 |
| **文化适配** | 领导力模型+价值观+团队融合 | 只看技能不看文化 | BEI+文化适配问卷 |
| **入职护航** | 30/60/90 天跟进+风险预警 | 签 Offer 就结束服务 | 90 天追踪档案 |
| **行业洞察** | 产业链趋势+竞争情报 | 对客户行业一无所知 | 行业趋势报告 |

## 高管评估特殊项

| 评估项 | 要点 |
|--------|------|
| **领导力风格** | 指令型/教练型/民主型/愿景型——与客户团队匹配度 |
| **决策模式** | 数据驱动/直觉驱动/共识驱动——与企业文化匹配度 |
| **利益相关者管理** | 向上/平行/向下管理能力 |
| **变革经验** | 是否有带领组织转型的实战经验 |

## 关键数据

- SHRM 2025：高管招聘成本 $35,879，非高管 $5,475（7 倍差）
- 罗盛咨询：CEO 平均任期 7.1 年，30-36 个月离职数同比增 79%
- C 级高管失败成本 = 年薪 200-400%
- VP/总监级失败成本 = 年薪 150-250%
- ~40% C 级高管失败核心原因：文化不适配
