# Furniture Assembly Reference

## Common Hardware Types

### Cam Lock System (most common in flat-pack)
| Component | Description | Appearance |
|-----------|-------------|------------|
| Cam lock | Round metal disc, ~15mm diameter | Has a directional arrow and a + screw slot |
| Cam dowel/peg | Metal pin with plastic collar, ~10mm | Inserts into panel edge, cam lock grabs it |
| Wood dowel | Wooden cylinder, 8mm × 30mm | Provides alignment, no fastening |

**How it works:** The cam dowel inserts into a pre-drilled hole on one panel edge. The adjacent panel has a larger round hole where the cam lock sits. When you turn the cam lock clockwise, it grabs the dowel and pulls the two panels together.

**Critical rule:** The arrow on the cam lock must point TOWARD the dowel hole. If pointed away, it won't grab.

### Screw Types
| Type | Use Case | Identifying Feature |
|------|----------|-------------------|
| Wood screw | Panel-to-panel | Coarse threads, flat head |
| Machine screw | Metal bracket to panel | Fine threads, usually Phillips |
| Confirmat screw | European flat-pack | Large threads, specific to 15-19mm board |

### Bracket Types
| Type | Use Case |
|------|----------|
| L-bracket | Corner reinforcement |
| Flat bracket | Splicing two panels |
| Drawer slide | Drawer movement |
| Corner brace | Anti-tip wall anchor |

## Common Assembly Step Types

### Frame Assembly (Steps 1-3 typically)
- Panels connected with dowels and cam locks
- Usually starts with the largest panels (sides + top/bottom)
- **Warning:** Verify panel orientation (finished side out) BEFORE inserting dowels

### Shelf/Divider Insertion (Steps 3-5)
- Internal panels slot into pre-drilled holes
- May require rubber mallet
- **Warning:** Check hole alignment before forcing

### Back Panel (usually mid-assembly)
- Thin hardboard nailed to back of frame
- Provides structural rigidity
- **Warning:** Frame must be square before nailing — measure diagonals

### Drawer Assembly (later steps)
- Drawer box assembled separately from slides
- Slides have frame-side and drawer-side tracks
- **Warning:** Don't mix up left/right slides

### Hardware/Final (last steps)
- Legs, handles, hinges
- **Warning:** Wall anchor for tall furniture is NOT optional

## Tools Commonly Needed

| Tool | Frequency | Notes |
|------|-----------|-------|
| Allen key (hex) | 90% of projects | Usually included |
| Phillips screwdriver | 70% | #2 size most common |
| Flathead screwdriver | 30% | For prying and cam locks |
| Hammer | 40% | For back panel nails |
| Rubber mallet | 15% | For tight-fitting joints |
| Level | 10% | For wall-anchoring |
| Drill | 5% | Only for wall anchors |
