## SWC2 需求解析域范本

> **素材声明**：本范本示范中的技能均取自 SWC1 范本快照（公开市场关键词采样 111 条）中真实存在的技能，仅作任务示范，实际执行以实时扫描结果为准。

### SWC2-01 需求解析与场景建模范本

**场景**：某品牌市场人员提出："每个工作日早上 8:30 汇总竞品在知乎热榜与全网的新动态，整理成一页日报存档。"

**输入**：用户原始需求语句。

**执行过程**：
1. 需求要素提取（逐项对照六要素）；
2. 缺失要素核对：目标与输出齐备；频率与触发方式齐备，无需追问（若缺失，一次集中追问，不逐条骚扰；频率与触发方式缺失时默认按 L1 处理并向用户提示该默认）；
3. 边界判定：核心动作是"搜集资讯→加工成文→产出文档"，属知识级上下文加载，落在技能域；若需把日报推送到企业微信群，该交付动作属连接器域，在方案中拆分标注；
4. 场景卡建模。

**产出**（场景卡示范）：

| 要素 | 内容 |
|------|------|
| 目标 | 每个工作日定时汇总竞品动态并成文存档 |
| 输入 | 知乎热榜与全网竞品资讯（公开信息） |
| 输出 | 一页竞品观察日报（Markdown 文档存档） |
| 频率 | 每工作日 |
| 触发方式 | 定时（工作日 08:30） |
| 涉及对象 | 知乎热榜与全网资讯（取数）、日报文档（交付） |
| 边界备注 | 企微推送等外部投递属工具级数据流，超出本技能能力边界，不在本链中编排 |
| 备注 | 频率与触发方式齐备，不适用"L1 默认" |

**校验点**：
- 目标与输出不可缺省，缺失必须追问（一次集中追问，不逐条骚扰）
- 频率与触发方式缺失时默认按 L1 处理并向用户提示该默认
- 场景卡六要素齐备后方可进入 SWC2-02

### SWC2-02 需求到技能的匹配映射范本

**场景**：承接上节场景卡"每日竞品观察日报"。

**输入**：场景卡；SWC1-02 分类展示表（扫描结果）。

**执行过程**：
1. 场景卡拆解为四段能力需求：取数（查知乎热榜与竞品资讯）→处理（汇总成日报文案）→交付（生成 Markdown 日报文档存档）→产出（执行摘要）；
2. 对照扫描清单逐段匹配（仅映射 SWC1 扫描确认存在的技能）；
3. 上下文形态标注；
4. 映射表输出。

**产出**（匹配映射表示范）：

| 段位 | 能力需求 | 候选技能 | 知识作用 | 上下文形态 |
|------|---------|---------|---------|-----------|
| 取数 | 查知乎热榜与创作数据 | zhihu | 装入知乎检索与数据管理方法 | 只读知识加载 |
| 取数 | 全网竞品资讯搜索 | tavily-search | 装入 AI 优化的搜索方法 | 只读知识加载 |
| 处理 | 汇总成日报文案 | content-research-writer | 装入研究型内容写作方法 | 只读知识加载 |
| 交付 | 生成 Markdown 日报存档 | markitdown-skill | 装入文档转换与生成方法 | 只读知识加载 |
| 产出 | 执行摘要 | （对话内产出） | 会话内直接输出 | 只读 |

**多候选并列方案**（可选）：取数段资讯搜索亦可评估 web-access（CDP 直连本地 Chrome 的智能联网工具调度）或 smooth-browser（云端 AI 浏览器代理），视浏览器环境与授权情况二选一；处理段亦可评估 wechat-article-workflow 中的选题整理能力，但该技能面向公众号推送全流程，本场景仅取其整理方法。

**校验点**：
- 仅映射 SWC1 扫描确认存在的技能；匹配不到时如实说明并建议替代路径，严禁虚构技能或能力
- 每段上下文形态必须标注，会产生写入的段进入 SWC5-02 确认流程
- 处理段无对应技能时使用会话内处理能力，不虚构技能

### SWC2-03 安装与触发条件核对范本

**场景**：承接上节映射表，逐技能核对安装状态与触发词。

**输入**：匹配映射表中的技能清单（zhihu、tavily-search、content-research-writer、markitdown-skill）；本地已装清单与平台技能市场状态。

**执行过程**：
1. 逐技能核对安装状态（对照 SWC1-01 本地枚举清单与市场可安装状态）；
2. 逐技能核对触发词并做重叠比对（触发词不确定的以技能详情页为准）；
3. 缺失项与冲突项标记；
4. 引导动作生成（安装指引/触发词取舍）；
5. 汇总为安装与触发核对表，写入组合方案模板"安装与触发前置"栏。

**产出**（安装与触发核对表示范）：

| 技能 | 安装状态 | 触发词 | 冲突标记 | 引导动作 |
|------|---------|--------|---------|---------|
| zhihu | 待安装 | 待确认（以技能详情页为准） | 无 | 请经平台技能管理能力搜索"zhihu"并安装，安装后核对触发词 |
| tavily-search | 待安装 | 待确认 | 无 | 请经平台技能管理能力安装，安装后核对触发词 |
| content-research-writer | 待安装 | 待确认 | 与 content-creation 表述相近 | 安装后核对两者触发词，重叠时明确优先级或请用户裁定 |
| markitdown-skill | 已安装 | 待确认 | 无 | 无需安装；触发词待确认 |

**前置提示汇总**（供方案模板"安装与触发前置"栏引用）：zhihu、tavily-search、content-research-writer 须先安装并核对触发词；content-research-writer 与 content-creation 触发词表述相近，加载时在会话内显式标注各自适用边界。

**校验点**：
- 未安装技能引导用户经平台技能管理能力安装，严禁虚构安装状态或绕过安装
- 触发词重叠时明确优先级或请用户裁定，不得含混带过
- 核对结果写入组合方案模板"安装与触发前置"栏，并传入 SWC5-02
