## 任务清单与依赖拓扑

按执行链路组织的技能工作流编排任务清单，附任务间关系和元操作映射提示。

**域间逻辑流**：SWC0（任务协调）→ SWC1 / SWC2 / SWC4（技能市场发现、需求解析、灵感生成三入口并列）→ SWC3（技能组合）→ SWC5（守护校验）→ SWC6（深化）。三条典型全链路：①需求驱动——SWC0-01 → SWC1 → SWC2 → SWC3 → SWC5 → 落地；②灵感驱动——SWC0-01 → SWC4 → SWC3 → SWC5 → 落地（用户采纳灵感后）；③市场更新——SWC1（重扫）→ SWC6-02 → SWC6-03。守护三道门（SWC5-01/02/03）固定串联在组合与落地之间。

### 依赖拓扑摘要

以下为技能工作流编排任务的主要依赖链路，执行框架可据此自动编排管线：

#### 一、域内链路

**任务协调链路**: SWC0-01 → SWC0-02 → SWC0-03
**市场发现链路**: SWC1-01 → SWC1-02 → SWC1-03
**需求解析链路**: SWC2-01 → SWC2-02 → SWC2-03
**技能组合链路**: SWC3-01 → SWC3-02 → SWC3-03 / SWC3-04 / SWC3-05（三层落地互斥，由 SWC3-01 路由决定）
**灵感生成链路**: SWC4-01 → SWC4-02 → SWC4-03
**守护校验链路**: SWC5-01 → SWC5-02 → SWC5-03（三道门固定串联）
**深化链路**: SWC6-01；SWC6-02（市场触发，独立成线）；SWC6-03 ← SWC6-01 / SWC6-02

#### 二、跨域协同链路

**需求驱动主链路**: SWC0-01 → SWC2-01 → SWC2-02 → SWC3-01 → SWC3-02 → SWC5-01 → SWC5-02 → SWC5-03 → SWC3-03 / SWC3-04 → SWC0-03
**灵感驱动链路**: SWC0-01 → SWC4-01 → SWC4-02 → SWC4-03 → SWC3-01（用户采纳灵感后进入组合）→ SWC3-02 → SWC5 → 落地
**市场查询链路**: SWC0-01 → SWC1-01 → SWC1-02 → SWC1-03
**守护贯穿**: SWC5-01/02/03 固定位于 SWC3-02 与 SWC3-03/SWC3-04/SWC3-05 之间，任何组合方案不得绕过
**市场更新链路**: SWC1-01（重扫）→ SWC6-02 → SWC6-03

#### 三、路由链路

- SWC0-01 → SWC1-01（市场查询）
- SWC0-01 → SWC2-01（需求驱动组合）
- SWC0-01 → SWC4-01（灵感浏览）
- SWC0-01 → SWC6-01（方案迭代）
- SWC0-01 → SWC6-02（市场更新适配）
