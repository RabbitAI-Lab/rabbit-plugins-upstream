## Description:

Provides web research utilities through Crawlora for page scraping and extraction, site analysis, geocoding, cost-of-living comparisons, trade records, traffic estimates, and brand lookup.

This skill is ready for commercial/non-commercial use.

## Publisher:

[crawlora-org](https://clawhub.ai/user/crawlora-org)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and research agents use this skill for one-off public web lookups, structured page extraction, and comparisons of location, company, and website data.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Requested URLs, lookup terms, extraction schemas, and the API key are sent to Crawlora for processing.

Mitigation: Use only when comfortable sharing these inputs with Crawlora; avoid private or sensitive pages unless external processing is intended, and keep the key out of shared files.
