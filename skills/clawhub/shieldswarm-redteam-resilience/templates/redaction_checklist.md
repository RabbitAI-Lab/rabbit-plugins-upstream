# Redaction Checklist

Redact before sharing:

- [ ] passwords
- [ ] MFA codes and backup codes
- [ ] cookies and session tokens
- [ ] Authorization headers
- [ ] API keys and OAuth tokens
- [ ] emails and personal identifiers where not needed
- [ ] raw prompts and uploaded file names/content
- [ ] private workspace/project names
- [ ] customer data
- [ ] raw IPs where policy/law treats them as personal data
- [ ] raw HAR files unless reviewed
