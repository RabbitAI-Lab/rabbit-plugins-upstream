## Quick local checks
- [ ] Refresh once only.
- [ ] Try private/incognito window.
- [ ] Disable suspicious extensions temporarily.
- [ ] Try another browser/device.
- [ ] Try another network if safe.
- [ ] Check official status page or public announcement.
- [ ] Avoid repeated retries or automated refresh loops.

## Evidence to share safely
- [ ] Screenshot with emails, prompts, files, workspace names, and personal data redacted.
- [ ] Browser console summary, redacted.
- [ ] HAR summary, not raw HAR if possible.
- [ ] Request ID or trace ID if displayed.

## Do not include
Passwords, MFA codes, cookies, session tokens, API keys, private prompts, private files, private workspace names, or raw HAR with secrets.
