# Pre-Publish Validation Checklist

- [ ] YAML frontmatter parses.
- [ ] Frontmatter uses only supported keys.
- [ ] Code fences are balanced.
- [ ] No nested-fence rendering bug.
- [ ] Required sections exist.
- [ ] Template files exist.
- [ ] No secrets, tokens, cookies, or credentials.
- [ ] No attack traffic generation instructions.
- [ ] No login bypass instructions.
- [ ] No official endorsement claim.
- [ ] Quickstart and safety rules near top.
- [ ] Local self-test passes.
