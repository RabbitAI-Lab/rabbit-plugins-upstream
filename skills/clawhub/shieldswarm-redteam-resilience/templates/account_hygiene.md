# Account and Token Hygiene

- [ ] Human logs in only through official website/OAuth/SSO/device flow.
- [ ] Agent never sees password, MFA code, cookies, or session token.
- [ ] Use least-privilege roles.
- [ ] Prefer short-lived tokens.
- [ ] Store tokens only in approved secret stores or restricted files.
- [ ] Avoid tokens in shell history, process lists, screenshots, and logs.
- [ ] Rotate tokens after demos, incidents, or public recordings.
- [ ] Revoke unused tokens.
- [ ] Review activity logs periodically.
