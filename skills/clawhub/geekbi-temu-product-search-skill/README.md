# 极鲸云 Temu 商品搜索 Skill

通过极鲸云提供的真实 Temu 商品数据，为国内跨境卖家完成商品搜索、候选筛选和选品判断。该 Skill 可以按关键词、可信类目、站点、销量、销售额、价格、供货价、同款数、评分和上架时间等条件查找商品，帮助卖家发现热销款、新品和低竞争机会，并评估市场表现、价格空间与跟卖压力。

## 主要能力

| 能力 | 可以解决的问题 |
| --- | --- |
| Temu 商品搜索 | 按关键词、可信类目 ID、站点和经营条件查找目标商品，快速形成可验证的候选商品池 |
| 热销与新品发现 | 查询热销商品、日销排行和近期上架新品，识别正在起量或值得持续观察的商品 |
| 商品表现分析 | 比较销量、销售额、增长率、评分、评论数量和上架时间，判断商品热度与生命周期 |
| 价格与供应空间评估 | 对比站点售价与人民币供货价，了解主流价格带并筛选具备进一步利润验证价值的候选 |
| 同款竞争判断 | 结合同款数、销量、增长和价格评估同质化竞争与核价压力，发现相对低竞争机会 |

## 适用场景

本项目适合以下任务：

- Temu 跨境电商选品和候选商品筛选。
- 按关键词查找美国站或其他 Temu 站点的目标商品。
- 热销商品、日销排行和近期新品研究。
- 低同款、低竞争商品和潜力商品发现。
- 商品销量、销售额、价格、供货价和增长表现比较。
- 商品价格带、上架时间与同款竞争分析。
- 为采购、测款和是否进入提供数据依据与验证建议。
