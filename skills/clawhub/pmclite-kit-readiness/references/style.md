# 轻排技能簇视觉规范 v2

目标：从"工具感"走到"仪表感"。不靠装饰取胜，靠**层次、数字和留白**。

判断标准（按顺序）：第一眼看到结论 → 第二眼看到关键数字 → 第三眼才发现边框和阴影。

## 1. 三层色彩结构

| 层 | 取值 | 用途 |
|---|---|---|
| 页面底 | `linear-gradient(180deg,#F7F9FC,#EEF2F7)` | 让白卡浮起来，不用纯灰 |
| 卡片 | `#FFFFFF` + 描边 `rgba(17,24,39,.06)` | 主体 |
| 强调 | 每个技能一条主色 | 只出现在 4 处：图标、accent bar、结论竖线、关键数字 |

阴影两级，禁止用单层大模糊：

```
--shadow-1: 0 1px 2px rgba(16,24,40,.06);
--shadow-2: 0 12px 28px -14px rgba(16,24,40,.28);
```

## 2. 技能主色（三档）

| 技能 | 主色 | 深色 | 浅底 | 语义 |
|---|---|---|---|---|
| 排产解释 | `#2F6BFF` | `#1B3FB8` | `#EEF3FF` | 依据与分析 |
| 齐套检查 | `#0F9D74` | `#067457` | `#EAF7F2` | 就绪与齐套 |
| 插单评估 | `#7A4BFF` | `#4B2BB8` | `#F2EEFF` | 决策与权衡 |

排产解释、齐套检查、插单评估三个技能共用这一套，另外两个暂不上架的沿用旧色板。

## 3. 字号阶梯

| 层级 | 字号/字重 | 用法 |
|---|---|---|
| 结论 | 17 / 700 / 1.55 | 一句话结论，卡片最高优先级 |
| 关键数字 | 26 / 700 / tabular-nums | 只用主色 |
| 表头 | 11 / 500 / 字距 .04em / 大写感 | 弱化成"标签"而非"标题" |
| 正文 | 13 / 400 | 表格与说明 |
| 次级 | 12 / 400 / `#6B7280` | 副标题、下一步 |
| 微标 | 11 / 500 | 状态胶囊、小节标题 |

数字必须等宽：`font-variant-numeric: tabular-nums`，英文与数字优先 `"DIN Alternate","Consolas",monospace` 作第二回退。

## 4. 组件规范

**Accent bar**：卡片顶部 3px 高，`主色 → 深色` 横向渐变，宽度 100%，不圆角。

**头部**：图标 44×44、圆角 12、渐变 135°、内描边 `inset 0 0 0 1px rgba(255,255,255,.18)`、白色汉字 21px/700；技能名 16/700；英文名 11/500/`#8A94A6`；右侧状态胶囊（11/500，浅色底 + 主色字），例如"只读 · 不落库"。

**结论块**：左侧 3px 主色竖线，背景 `主色 6% 透明度` 或浅底色，内边距 12×14，圆角 0 10 10 0。结论文字 17/700。

**小节标题**：11/600/`#8A94A6`/字距 .06em，前置 12px 主色短横线。

**表格**：无竖线；表头浅底 `#F7F9FC`，无加粗；行高 40；首列 500 字重；末列标签右对齐；数字列右对齐等宽。

**风险标签**：圆点 + 文字，而不是纯色块。圆点 6px、内间距 6×10、圆角 999、底为对应浅色。

- 🔴 阻断：字 `#B42318`，点 `#E0483C`，底 `#FDECEA`
- 🟡 需关注：字 `#92400E`，点 `#E08A2C`，底 `#FEF4E6`
- 🟢 可执行：字 `#065F46`，点 `#12A879`，底 `#E9F8F1`

**下一步**：编号圆点用主色 18×18 圆形白字；责任方用小胶囊（12/500，浅灰底）。

**KPI 行**：三格等宽，格间 12；数字 26/700 主色；标签 11/`#8A94A6`；格子底色 `#F7F9FC`，不上边框。

## 5. 栅格与节奏

间距只用 4 的倍数：4 / 8 / 12 / 16 / 20 / 24。卡片内边距 20；区块间距 16；表格行间距靠 padding 而非 margin。圆角：卡片 14，内部元素 10，胶囊 999。

## 6. 窄屏（≤560px）

- 表格转堆叠：隐藏表头，每行变块，单元格 `flex` 两端对齐，前置 11px 标签（`data-label`）。
- 结论字号 15，KPI 数字 22，图标 40。
- 卡片内边距 16，页面左右 14。
- 任何情况下不得出现横向滚动。

## 7. 反模式

- 整段染色、整行高亮；
- 一屏超过 3 处强调色；
- 纯黑 `#000` 文字；
- 每个元素都加边框（用间距和底色代替）；
- 用 emoji 充当图标（仅风险档位允许使用 🔴🟡🟢）。

## 8. 字体

中文 `"Microsoft YaHei","PingFang SC","Noto Sans CJK SC"`；数字/英文第二回退 `"DIN Alternate","Consolas",monospace`。不使用衬线体，不使用斜体。

## 9. 关键数字锚点（v3）

结论块右侧固定一块锚点，放这张卡的"一个数"，让读者不必读完整句就抓到重点。

- 结构：结论文字（flex:1）｜1px 竖分隔｜数字 + 11px 标签（右对齐，最小宽 92px）。
- 数字：30px / 700 / 等宽字体 / 主色；单位用 12px 跟随（如 `50` + `套`）。
- 标签：11px / `#4B5563`，写清数字含义（batch 串行、缺口、最大顺延）。
- 锚点数字属于大字号，对比度门槛 3:1；小字标签仍按 4.5:1。
- 一卡只放一个数。两个数就等于没数。

## 10. 三种呈现（v3）

三张卡不再共用一套骨架，按各自要回答的问题选版式：

**时间轴**（排产解释）：竖向节点，日期用等宽 12px 主色深色，节点圆点已完成填充、未完成描边；用于解释"为什么落在这天"。

**KPI + 明细**（齐套检查）：先一行 3 格 KPI（阻断工单 / 缺料项 / 齐套率），数字 24px 主色；再给缺口明细表；用于"现在什么状况、缺在哪"。

**前后对比**（插单评估）：每行一条工单，左侧原计划、右侧插单后（浅主色底、主色深字），中间箭头，右端顺延标签；用于"代价是多少"。

窄屏下：时间轴保留竖排；KPI 三格保持一行；前后对比改为上下两组，箭头隐藏，顺延标签换行右对齐。
