# 内容工坊

自媒体内容生产全链路技能。将「热点抓取 → 选题决策 → 多平台内容生成 → 风格适配输出」整合为一条流水线，一条指令完成从选题到成品的全流程。

## 触发条件

当用户表达以下意图时触发本技能：
- "帮我做一期内容""今天写什么""生成一批选题"
- "把这篇改成小红书/公众号/抖音版本"
- "从热点到发布一条龙""帮我生产本周内容"
- 涉及多平台内容批量生成、适配、分发

## 工作流程

### 阶段一：热点抓取与选题决策

1. 根据用户指定的领域（如科技、美妆、职场、教育等），调用 `search_web` 搜索当前热点
2. 对抓取到的热点进行筛选，按以下维度打分：
   - 热度（搜索量/讨论量）
   - 相关性（与用户领域匹配度）
   - 可创作性（能否产出有价值内容）
3. 输出 Top 3-5 选题建议，每个包含：
   - 选题标题
   - 热度评分
   - 推荐角度
   - 适合平台（公众号/今日头条/小红书/抖音/知乎）

### 阶段二：多平台内容生成

对每个选定的选题，按平台特性生成适配内容：

**公众号版本：**
- 标题：信息密度高，带悬念或冲突感，12-20字
- 正文：1000-2000字深度长文，三段式结构（引入→展开→总结）
- 风格：说理清晰、有观点、可带个人色彩
- 排版提示：建议小标题分段、适当配图

**今日头条版本：**
- 标题：信息量大、制造悬念、带数字或冲突，15-25字，口语化强
- 正文：短段落、高信息密度，300-800字，开门见山
- 结构：核心事实→关键数据→观点提炼→互动收尾
- 风格：观点鲜明、接地气、适合碎片化阅读
- 结尾：抛开放式问题引导评论互动

**小红书版本：**
- 标题：口语化，带情绪词，8-15字，含 emoji
- 正文：短句分行，300-800字，语气亲切
- 必含：话题标签 3-5 个，文末互动引导
- 风格：种草感、真实分享、利他性

**抖音/短视频脚本版：**
- 开头钩子：3秒抓注意力，1-2句
- 正文：15-30秒节奏块，口语化
- 结尾：引导互动/关注
- 附带：拍摄建议、画面提示

**知乎版本：**
- 标题：问题式或观点式
- 正文：结构化论述，800-1500字
- 风格：理性分析、数据支撑、逻辑清晰

### 阶段三：输出交付

1. 汇总所有内容，以清晰结构呈现
2. 标注每篇内容的目标平台和发布建议
3. 可选：生成内容发布排期表

## 使用方式

**全链路模式：**
```
@内容工坊 帮我做一期科技领域的本周内容，覆盖公众号和小红书
```

**单平台模式：**
```
@内容工坊 把这篇关于AI趋势的分析，改成小红书风格
```

**选题模式：**
```
@内容工坊 美妆领域最近有什么热点？帮我出5个选题
```

## 注意事项

- 热点抓取依赖搜索能力，时效性强的话题优先使用 freshness 参数
- 生成内容仅供参考，发布前建议人工审核事实准确性
- 多平台适配时，保持核心观点一致，只调整表达风格和格式
- 如果用户未指定领域，主动询问以缩小选题范围
