## Description: <br>
Helps agent users and skill authors create ontology-style, typed knowledge-graph workflows for bug fixing, setup hardening, reliability improvement, and adjacent skill creation. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, maintainers, skill authors, and AI-agent users use this skill to turn ontology-style productivity requirements into practical workflows, checklists, code changes, or decision support that can be validated locally. <br>

### Deployment Geography for Use: <br>
Global <br>

Risk: Overly broad activation wording may cause the helper to be invoked outside ontology-style workflow tasks. <br>
Mitigation: Narrow the activation wording or disable implicit invocation so the helper is used only for ontology-style workflow work. <br>
