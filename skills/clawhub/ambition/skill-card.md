## Description:

Helps an agent use the current task context to choose a more ambitious objective and carry it through with an independent check.

This skill is ready for commercial/non-commercial use.

## Publisher:

[abhione](https://clawhub.ai/user/abhione)

### License/Terms of Use:

MIT

## Use Case:

People working with an agent use this skill to elevate an ongoing task into a more ambitious, concrete goal and have the agent execute and check the result.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The agent may reinterpret a request and pursue a harder objective rather than follow the literal task.

Mitigation: Review the proposed objective before proceeding when it changes scope or affects a sensitive, costly, or consequential workflow.

Risk: An elevated task could lead to external actions or changes to accounts or production systems.

Mitigation: Require explicit approval before sending, publishing, provisioning, deleting, or otherwise taking external action.
