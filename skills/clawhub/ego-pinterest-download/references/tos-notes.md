# ToS / ethics notes

- Personal use only. Respect [Pinterest Terms of Service](https://policy.pinterest.com/terms-of-service) and the site's robots rules.
- Do not redistribute scraped media, sell datasets, create accounts automatically, or bypass captchas.
- The default path only saves media the logged-in Ego Lite session can already see. `--allow-anonymous` is an explicit opt-in for public results. Tell the user that a logged-in Ego session improves results.
- Video files are capped (200MB). Previews are small thumbnails (at most 8, 120KB each).
- `count` is capped at 100. Search walks at most 4 resource pages.
- The script does not type passwords and does not print cookie values.
- Do not commit images, `manifest.json`, session files, or Ego profile data.
