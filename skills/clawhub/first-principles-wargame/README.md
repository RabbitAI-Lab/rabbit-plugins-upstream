## 📖 是什么 / What

以第一性原理为锚点，融合**三层九问框架**（门槛关 / 优势关 / 智慧关），对任何候选业务方向、战略动作、新产品线或战略转型进行深度推演。内置事前验尸协议、时机判断框架、心智模型库、退出条件与里程碑设计。

**这不是一个简单的「做/不做」二选一工具，而是一个逼出盲区、校准决策质量、留下可复盘痕迹的系统。**

---

A first-principles anchored strategic decision wargame tool. Combines a **three-layer, nine-question framework** (Threshold / Advantage / Wisdom) with premortem protocols, timing analysis, mental model library, and exit-condition design.

**This is not a simple "go/no-go" tool — it's a system to surface blind spots, calibrate decision quality, and leave an auditable trail.**

## 🧩 框架总览 / Framework Overview

### 第一层：门槛关（闸门，不过直接停下）
- **Q1 · 主线对齐问** — 这事服务于我们唯一的主线吗？
- **Q2 · 团队代价问** — 核心团队的注意力和稳定性会受到什么影响？

### 第二层：优势关（打分评估）
- **Q3 · 竞争根基问** — 我们凭什么取胜？成本/体验 vs 垄断/信息差？
- **Q4 · 时机判断问** — 为什么是现在？太早是先烈，太晚是炮灰。
- **Q5 · 护城河持久问** — 成功了能守多久？会被什么力量消解？

### 第三层：智慧关（深度拷问）
- **Q6 · 不公平优势问** — 凭什么是你？别人拼了命也得不到的东西是什么？
- **Q7 · 事前验尸问** — 假设三年后彻底失败，最可能的死因是什么？
- **Q8 · 非对称回报问** — 赢了赚多少？输了亏多少？赔率合理吗？
- **Q9 · 退出条件与里程碑问** — 什么信号出现时，你会停止投入？

## 🇨🇳 安装

### 方式一：CodeBuddy 用户

1. 下载本仓库解压，放入 CodeBuddy 技能目录：
   ```
   ~/.codebuddy/skills/first-principles-wargame/
   ```

2. 重启 CodeBuddy（或刷新技能列表）。

3. 在对话中说出任意触发词即可激活。

### 方式二：直接导入 .skill 包

将仓库内容打包为 `.skill` 文件，在 CodeBuddy 中导入。
