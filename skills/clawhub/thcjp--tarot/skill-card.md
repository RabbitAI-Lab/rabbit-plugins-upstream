## Use Case:

External users and agent operators use this skill for gentle self-reflection, emotional support, and meaning-making with symbolic tarot language. It is not intended for clinical, legal, financial, or predictive guidance.

### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: Server security evidence marks the release as suspicious because the tarot prompt requests file, command, and write capabilities that do not fit a reflective tarot purpose.

Mitigation: Review before installation and only deploy if shell execution, file writing, broad automation triggers, API keys, and callback handling are removed or tightly scoped and disclosed.

Risk: Users may over-rely on tarot output as prediction or professional advice.

Mitigation: Keep responses symbolic and non-deterministic, refuse medical, legal, and financial instructions, and switch to safety-first support when self-harm intent appears.
