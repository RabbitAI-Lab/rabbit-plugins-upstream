# SEO 分析维度指标细则

本文件定义 `seo_audit.py` 各分析维度的判定标准，供 SKILL.md 工作流第 3–11 步逐项核对使用。每个维度评分区间 0–100，最终加权成整站 SEO Score。

---

## 1. 关键词分析（keyword，权重 10）

关注词来源：`meta keywords` → 无则取 `<title>` 中有效英文词（去停用词），最多 5 个。

检查项：
- **覆盖度**：关注词是否出现在 title / description / H1 / URL slug / 任意 heading。
- **正文密度**：关注词在正文中的出现频率，理想 0.5%–2%；0 偏低，>3% 疑似堆砌。
- **词频发现**：输出英文词频 Top20、中文 bigram 词频 Top20，辅助发现真实主题词。

---

## 2. Title 分析（title，权重 15）

- 必须存在 `<title>`。
- 长度理想 **30–60 字符**（Google 显示约 600px）。
- 应前置核心关键词，且与站内其它页面**不重复**（重复在聚合阶段扣 15 分/页）。
- 禁止关键词堆砌、禁止纯品牌无描述。

---

## 3. Description 分析（description，权重 10）

- 必须存在 `meta description`。
- 长度理想 **70–160 字符**。
- 含核心关键词、有行动号召、不与原内容无关、不与其它页重复。

---

## 4. Heading 分析（heading，权重 10）

- **恰好 1 个 H1**，概括页面主题并含关键词。
- 层级连续（禁止 H1 后直接 H3 跳级）。
- 结构清晰，H2/H3 承载小节主题。

---

## 5. URL 分析（url，权重 10）

- 静态化、连字符 `-` 分隔，含关键词。
- 禁止下划线 `_`、大写字母、动态参数（`?` `=` `&`）。
- 路径长度建议 ≤ 80 字符（首页豁免关键词检查）。

---

## 6. Internal Link 分析（internal_link，权重 10，站点级）

- 每页应有合理数量内部链接（理想 ≥ 3，避免孤岛页）。
- 锚文本应具有描述性，通用词（"点击这里""更多""click here"）占比应 < 30%。
- 检测**孤岛页面**（未被任何其它页面内部链接，首页除外）。

---

## 7. Schema 分析（schema，权重 10）

- 优先 `application/ld+json` 结构化数据，且 JSON 合法。
- 无 JSON-LD 但有 microdata（`itemscope`/`itemtype`）给部分分。
- 完全无结构化数据记 0。

---

## 8. Indexability 分析（indexability，权重 20，最高权重）

- 无 `noindex`（meta robots 或 `X-Robots-Tag`）。
- `robots.txt` 允许抓取当前路径。
- HTTP 状态 200、无错误重定向链。
- 使用 HTTPS。
- 存在自指向 `canonical`。
- 站点具备 `sitemap.xml` 且重要页面被收录其中。

---

## 9. 页面分析（page，权重 5）

- 正文内容充实（≥ 300 词，薄内容 < 150 词重扣）。
- 图片缺失 `alt` 比例应 < 30%。
- 存在 `viewport` 元标签（移动友好）。
- `<html>` 设置 `lang`；字符集为 UTF-8。

---

## 站点级补充检查

- `robots.txt` 是否可抓取、是否错误屏蔽重要目录。
- `sitemap.xml` 是否存在、是否覆盖核心页面。
- 全站 HTTPS 一致性、是否存在混合内容。
- 标题/描述跨页重复率。
