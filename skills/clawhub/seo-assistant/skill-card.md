## Description:

A website SEO audit and optimization pipeline for crawling or offline page analysis, scoring SEO health across common dimensions, producing risk-graded recommendations, and guiding confirmed CMS writebacks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[hsqduron](https://clawhub.ai/user/hsqduron)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, site operators, and SEO practitioners use this skill to audit websites or CMS page source, generate structured SEO scores and recommendations, and apply confirmed low-risk SEO fixes while escalating higher-risk changes for review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: CMS write capabilities may modify website content beyond the intended SEO change scope.

Mitigation: Review each proposed CMS write before execution, require explicit approval for write operations, and do not allow save_ai_page to create pages or replace the homepage without a separate approval.

Risk: Crawling arbitrary URLs from a sensitive network can expose unsafe URL-fetching behavior.

Mitigation: Run crawls only against domains the user controls or has permission to audit, and avoid running the skill from networks that can reach sensitive internal services unless URL validation is added.

Risk: CMS credentials could grant broader access than needed for a single SEO audit or writeback.

Mitigation: Limit the MCP token to the intended site and operation scope, avoid echoing or storing tokens, and use read-only analysis until write access is required and approved.

Risk: The release includes a mandatory unrelated signup prompt that may not be relevant to the user's SEO task.

Mitigation: Treat signup guidance as a third-party service dependency to review before installation or use, not as a requirement for unrelated audits.
