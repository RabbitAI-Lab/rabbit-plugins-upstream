## Description:

Remove signs of AI-generated writing from text and revise it to sound more natural while preserving meaning and tone.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zuoyunlai](https://clawhub.ai/user/zuoyunlai)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to edit prose so it reads less like generic AI-generated text, with checks for formulaic phrasing, vague attribution, promotional tone, repetitive structure, and similar patterns.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can be used to obscure AI assistance in settings where disclosure is required or expected.

Mitigation: Use it only for legitimate style editing of text the user is allowed to revise, and preserve any required AI-use disclosure.

Risk: Style rewrites may remove nuance, attribution, or factual detail while making text sound more natural.

Mitigation: Review the rewritten text against the source for factual accuracy, citations, tone, and required context before publication.
