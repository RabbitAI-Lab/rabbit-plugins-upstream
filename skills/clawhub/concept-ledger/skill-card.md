## Description: <br>
A living concept tracker that turns naming chaos, synonym loops, and fuzzy metaphors into clear, implementation-ready definitions. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, engineers, and product teams use this skill during brainstorming, vibe coding, and system design to stabilize terminology before vague metaphors become implementation details. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Sensitive project terminology could be retained if cross-session memory is explicitly enabled. <br>
Mitigation: Keep cross-session memory disabled for sensitive projects, or use session-only, clear, disable, or wipe controls for concepts that should not persist. <br>
Risk: Terminology suggestions may be wrong if the agent misreads a concept boundary or metaphor. <br>
Mitigation: Review prompted merges, freezes, and definition changes before treating the tracker as implementation guidance. <br>
