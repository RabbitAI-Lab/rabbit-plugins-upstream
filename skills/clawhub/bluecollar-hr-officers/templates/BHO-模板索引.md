# BHO-模板索引

> 命名规范：templates/ 下所有文件统一为「BHO-语义名模板.md」（技能前缀 + 语义名 + 模板后缀），不使用序号前缀、不使用英文 kebab-case；references/ 下统一为 BHO-catalog.md、BHO-requirements.md、BHO-exemplars.md 与 BHO-域代码-域名范本.md。

| 文件 | 配套单元 | 用途 | 使用方式 |
|---|---|---|---|
| BHO-渠道报价单模板.md | N1-03 / B5-02 | 对外报价（🌐） | 复制后替换 `${变量}`，只填对外口径 |
| BHO-月度服务费对账表模板.md | N2-08 / N2-05 | 对账与开票（🔒） | 按批次逐行填，保留三表结构 |
| BHO-批次输送执行计划模板.md | B6-04 / N1-05 | 送人波次与到岗（🔒） | 一波次一行，含驻厂与缓冲 |
| BHO-学生知情确认书结构模板.md | N1-05 / B9-01 | 入场签署（⚖️） | 只列结构与要素，正式文本由法务定稿 |
| BHO-驻厂日报模板.md | N1-02 / B10-02 | 每日报送（🔒） | 7 字段固定，20:00 前发群 |
| BHO-合规自查清单模板.md | B9-01 / B9-07 | 入场/在岗/退场（⚖️） | 三阶段逐项打勾，结果留档 |

约定：
1. 模板内 `${变量}` 为占位符，生成时替换；不得留空占位符交付
2. 每个模板首行标口径级别，跨口径引用须显式换算
3. 模板不写死具体客户、费率与人数
4. 正式对外文本与法律文书须经法务/律师审核后使用
