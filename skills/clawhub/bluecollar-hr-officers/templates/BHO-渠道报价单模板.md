# BHO-渠道报价单模板（🌐 对外口径）

> 仅用于对渠道/院校报价。不得出现成本价、关系费、真实毛利等内部字段。

| 项 | 内容 |
|---|---|
| 报价单编号 | `${QUOTE_NO}` |
| 客户/渠道 | `${PARTNER}` |
| 报价日期 | `${DATE}` |
| 有效期 | `${VALID_UNTIL}`（高峰期价格可能短期调整，以书面确认为准） |

## 一、报价表

| 客户 | 岗位 | 计价方式 | 单价 | 计费期限 | 结算方式 |
|---|---|---|---|---|---|
| `${CLIENT}` | `${POSITION}` | 元/人/月 | `${PRICE}` | `${MONTHS}` 个月 | 背靠背 / 垫资快结 |
| | | 元/小时 | `${HOURLY}` | — | |

## 二、计费规则

1. 计费起点：入职不满 `${MIN_DAYS}` 天不计费；满 `${MIN_DAYS}` 天不满整月按 `单价 ÷ 当月天数 × 出勤天数`
2. 计费依据：以客户回签的在岗清单为准
3. 离职扣减：月离职率超过 `${CHURN_LIMIT}` 时，超出部分按 `${DEDUCT}` 元/人/月扣减
4. 工资发放：由用工企业直接发放至员工本人账户，不经第三方

## 三、结算与账期

- 提报日：每月 `${REPORT_DAY}` 日；核对回签：次工作日；开票：`${INVOICE_DAYS}` 日内送达
- 付款：收票后 `${PAY_DAYS}` 天
- 逾期滞纳金：`${LATE_RATE}`/日

## 四、渠道政策

- 报备保护期：`${PROTECT_DAYS}` 天（自 `${PROTECT_START}` 起算）
- 阶梯激励：单批或年度累计超 `${TIER_QTY}` 人，每人每月增加 `${TIER_ADD}` 元
- 反绕过：跳过我方与资源方合作，按主合同总额 `${ANTI_BYPASS}` 倍计违约金

## 五、说明

1. 本报价不含 `${EXCLUDED}`（如住宿、被褥、体检等，按 `${WHO}` 承担）
2. 本报价单为要约邀请，最终以双方签署协议为准
3. 政策变动（社保基数、派遣比例等）导致成本变化时，双方另行协商调价
