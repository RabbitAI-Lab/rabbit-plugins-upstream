# BHO-批次输送执行计划模板（🔒 内部口径）

> 配套 B6-04 / N1-05。一波次一行，含驻厂配置与缓冲。

批次号：`${BATCH}`｜客户：`${CLIENT}`｜院校/渠道：`${SOURCE}`｜起止：`${START}` ~ `${END}`

## 一、波次计划

| 波次 | 到岗日 | 人数 | 来源渠道 | 车辆/集合点 | 驻厂配置 | 缓冲 | 责任人 |
|---|---|---|---|---|---|---|---|
| 一 | `${D1}` | `${N1}` | `${SRC1}` | `${VEHICLE1}` | `${STAFF1}` 人 | `${BUF1}` | `${OWNER1}` |

| 合计 | | `${N}` | | | | | |

驻厂配置 = 人数 ÷ 100~150（不足 100 人按 1 人配）；缓冲 = 人数 × 10%

## 二、时间窗校验

- [ ] 到岗日不晚于客户产线开线日
- [ ] 实习生批次：入职日 + 6 个月不落在春节前后（避免"7-30 后入职难满期"）
- [ ] 进校宣讲至到岗间隔 ≥ 7 天（留体检与协议时间）

| 时间 | 动作 | 标准 | 责任人 |

## 四、中止条件

出现以下任一情况暂停输送并上报：客户临时减产 / 协议未签 / 保险未生效 / 生源实际到岗低于计划 70%。
