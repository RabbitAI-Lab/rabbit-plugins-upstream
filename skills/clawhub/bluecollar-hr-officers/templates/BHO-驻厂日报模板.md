# BHO-驻厂日报模板（🔒 内部口径）

> 配套 N1-02 / B10-02。每日 20:00 前发群，7 字段固定，数据准确率 ≥98%。

日期：`${DATE}`｜客户：`${CLIENT}`｜批次：`${BATCH}`｜填报人：`${OWNER}`

## 一、当日数据

| # | 字段 | 数值 |
|---|---|---|
| 1 | 接到人数 | `${RECEIVED}` |
| 2 | 面试人数 | `${INTERVIEWED}` |
| 3 | 录取人数 | `${PASSED}` |
| 4 | 男女比例 | `${RATIO}` |
| 5 | 录取率 | `${PASS_RATE}` |
| 6 | 今日入职 / 今日离职 / 目前在岗 | `${IN}` / `${OUT}` / `${ON_JOB}` |
| 7 | 辞职或未录取原因 | `${REASON}` |

## 二、异动与风险

| 类型 | 人数 | 处理 |
|---|---|---|
| 情绪预警（红/黄/蓝） | `${WARN}` | `${WARN_ACTION}` |
| 岗位不适配 | `${MISMATCH}` | `${MISMATCH_ACTION}` |
| 缺勤/旷工 | `${ABSENT}` | `${ABSENT_ACTION}` |

## 三、需支持事项

- `${SUPPORT}`（写明需要谁、什么时候、做什么）

## 四、校验

- [ ] 接到 = 面试 + 未面试；面试 = 录取 + 未录取
- [ ] 目前在岗 = 昨日在岗 + 今日入职 − 今日离职
- [ ] 前 10 天离职率 ≤10%（超出需附专项说明）
- [ ] 群内不含身份证号、银行卡号等敏感信息
