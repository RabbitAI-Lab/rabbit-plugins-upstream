批次：`${BATCH}`｜客户：`${CLIENT}`｜院校：`${SOURCE}`｜自查人：`${OWNER}`｜日期：`${DATE}`

## 一、入场前

- [ ] 逐人核验身份证原件并拍照留档（不收复印件）
- [ ] 建立「年龄—工种匹配表」，16–18 岁标未成年工并比对禁忌岗
- [ ] 三方/四方协议已签（未满 18 岁含监护人签字），先签后上岗
- [ ] 实习责任险 + 商业意外险已生效（保单/名单/保额留档）
- [ ] 报酬 ≥ 本单位同岗试用期工资 80%，并约定直发本人
- [ ] 学生知情确认书已签（两个勾选 + 三人签字，无七类禁止内容）
- [ ] 企业资质、营业执照、许可已核验
- [ ] 未收取任何费用、未押证件

## 二、在岗期间

- [ ] 未安排未成年工夜班（22:00–06:00）与禁忌工种
- [ ] 工时未超上限（8h/日、40h/周），加班有自愿与知情记录
- [ ] 工资由企业直发本人，有银行流水
- [ ] 日报/台账完整，数据准确率 ≥98%
- [ ] 个人信息加密存储，外发已脱敏与审批
- [ ] 派遣岗位与比例符合规定（临时性/辅助性/替代性，≤10%）

## 三、退场

- [ ] 离职单有驻厂签字（未签字视为无效离职）
- [ ] 工资结算清晰、有签字确认
- [ ] 报销兑现（车费/被褥等按约定）
- [ ] 数据归档 24 小时内完成
- [ ] 离职原因统计与批次复盘
