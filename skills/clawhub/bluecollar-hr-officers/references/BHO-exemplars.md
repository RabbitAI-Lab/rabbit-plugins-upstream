## 范本模板格式（每节固定 7 要素）

```markdown
#### {单元ID} {catalog 中的任务名} —— 交付物：《{交付物名}》
{口径级别：🔒 内部口径 / 🌐 对外报价 / ⚖️ 法规口径 / 📊 企业事实}

- **场景**：谁在什么批次情境下要这份东西
- **输入**：域级材料基线 + 上游交付物（执行时按批次细化具体单据）
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | {表/节编号或具体列} |
| 可选组件 | {附注或扩展表} |
| 组装顺序 | {步骤链} |
| 约束 | {计算列/校验规则/附注} |
| 格式 | {表头与单位} |

- **交付物本体**（示例数据·非实际经营值）：

{表格或清单，含表头、行、合计}

- **勾稽**：{公式与验算}
- **口径引用**：见总纲 {条目号}
```

**判定标准**：覆盖矩阵五行不得出现"见交付物本体"之类空落点；指不到具体表、列或附注，即视为该任务要求未体现，须补做。

## 使用规则

1. **样本法仅借结构与颗粒度**：实际交付不得残留「客户 A / 院校 C / 渠道 B / 批次 P-01」等示例实体，须替换为用户真实上下文
2. **覆盖矩阵是自检器**：交付时若某条要求找不到落点，回到 requirements 对应单元补做，不得以"格式限制"为由省略
3. **口径级别优先**：对外物料（🌐）不得引用 🔒 内部字段；跨口径引用须显式换算
4. **数字必须可推导**：示例数字全部由公式算出，禁止填无来源的定点商务值
5. **单域只读**：执行某域任务时只读该域范本，不整读 15 本
