### 三、任务样例

#### N4-01 驻厂与办公 IT 设备管理 —— 交付物：《设备台账与巡检表》
🔒 内部口径

- **场景**：驻厂点新增 3 台电脑与 1 台打印机
- **输入**：设备与系统清单、账号权限表、证件影像、填报数据；上游：无（入口任务）
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 台账 + 巡检表 |
| 可选组件 | 设备生命周期与更换计划 |
| 组装顺序 | 盘点→建账→定巡检→定流程 |
| 约束 | 登记责任人、离职回收、禁私接网络 |
| 格式 | 设备台账（编号/型号/使用人/位置/状态）+ 巡检表 |

- **交付物本体**（示例数据·非实际经营值）：

| 编号 | 设备 | 使用人 | 位置 | 状态 |
|---|---|---|---|---|
| PC-07 | 笔记本 | 驻厂甲 | 客户 A 驻厂点 | 在用 |
| PR-02 | 打印机 | 共用 | 宿舍区 | 待修 |

- **勾稽**：台账数 = 实盘数；待修数 ≤ 2
- **口径引用**：总纲 1.3

#### N4-02 学生与员工信息安全管理 —— 交付物：《数据分级与权限矩阵》

- **输入**：设备与系统清单、账号权限表、证件影像、填报数据；上游：N4-01 驻厂与办公 IT 设备管理
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 分级表 + 权限矩阵 + 同意文本 |
| 可选组件 | 脱敏规则 |
| 组装顺序 | 分级→定权限→定账号流程→定同意→定审计 |
| 约束 | 最小必要、单独同意、外发脱敏与审批 |
| 格式 | 权限矩阵（角色/数据类/读/写/导出）+ 数据分级表 |

| 银行卡号 | 敏感 | 财务 | 审批后 |

- **勾稽**：敏感类可读角色 ≤ 3；导出禁止项 = 0 例外
