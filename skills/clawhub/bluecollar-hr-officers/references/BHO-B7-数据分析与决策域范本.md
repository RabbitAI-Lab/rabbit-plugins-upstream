### 三、任务样例

#### B7-01 批次数据清洗与可视化 —— 交付物：《批次数据底表与清洗说明》
🔒 内部口径

- **场景**：汇总 3 个批次台账
- **输入**：批次台账、结算与考勤数据、指标定义；上游：无（入口任务）
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 清洗说明+底表 |
| 可选组件 | 数据质量评分 |
| 组装顺序 | 取数→清洗→校验→建表 |
| 约束 | 规则留痕、异常不删、金额人数双向核 |
| 格式 | 清洗说明 + 底表（批次/日期/在岗/离职/计费） |

- **交付物本体**（示例数据·非实际经营值）：

| 批次 | 在岗 | 离职 | 有效人月 |
|---|---|---|---|
| P-01 | 300 | 12 | 288 |
| P-02 | 120 | 5 | 116 |

- **勾稽**：在岗 − 离职 = 有效人月（同月口径）
- **口径引用**：总纲 1.3

#### B7-02 蓝领经营指标与看板 —— 交付物：《指标字典与看板草图》
🔒 内部口径

- **场景**：搭建月度经营看板
- **输入**：批次台账、结算与考勤数据、指标定义；上游：B7-01 批次数据清洗与可视化
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 指标树+字典+看板 |
| 可选组件 | 预警阈值与推送规则 |
| 组装顺序 | 定北极星→拆树→写字典→设看板→定预警 |
| 约束 | 一指标一公式、按批次可下钻 |
| 格式 | 指标字典表 + 看板草图（模块/指标/口径/阈值） |

- **交付物本体**（示例数据·非实际经营值）：
北极星：有效人月 → 到岗人数 / 30 日留存 / 在职系数 / 单人毛利 / 账期天数。看板四区：获客、到岗、留存、结算。
- **勾稽**：指标树叶子节点均有取数口径
- **口径引用**：总纲 1.3

#### B7-03 机构 SWOT 与机会评估 —— 交付物：《SWOT 矩阵与结论》
🔒 内部口径

- **场景**：年中战略复盘
- **输入**：批次台账、结算与考勤数据、指标定义；上游：B7-01 批次数据清洗与可视化、B1-03 同行机构与报价情报
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 四象限+交叉+结论 |
| 可选组件 | 机会优先级矩阵 |
| 组装顺序 | 列四象限→交叉→筛机会→结论 |
| 约束 | 每条有依据、愿望不作优势 |
| 格式 | SWOT 矩阵 + 三条结论 |

- **交付物本体**（示例数据·非实际经营值）：
S：央企客户资源；W：单渠道依赖 62%；O：桂籍生源增量；T：同行低价进入。SO：以央企客户换桂籍批量。
- **勾稽**：结论 ≤ 3 条且各带一个动作
- **口径引用**：总纲 1.5

#### B7-04 项目 ROI 与商业论证 —— 交付物：《项目 ROI 表》
🔒 内部口径

- **场景**：评估新建驻厂点
- **输入**：批次台账、结算与考勤数据、指标定义；上游：B7-02 蓝领经营指标与看板
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 投入/产出/ROI/回收期 |
| 可选组件 | 不做的代价 |
| 组装顺序 | 归集→测算→算 ROI→敏感性 |
| 约束 | 按有效人月、含资金成本 |
| 格式 | ROI 表（投入/产出/ROI/回收期/敏感项） |

- **交付物本体**（示例数据·非实际经营值）：
投入 12 万/年；产出 500 人月 × 300 元 = 15 万 → ROI 25%，回收期 9 个月。
- **勾稽**：ROI = （产出 − 投入）÷ 投入
- **口径引用**：总纲 1.2

### 四、域内交叉校验

- 底表（B7-01）→ 指标（B7-02）→ 复盘（B7-08）同源
- 目标分解（B7-05）人月 = 对账（N2-08）计费人月
- ROI（B7-04）与预算调整（B7-07）共用毛利口径
