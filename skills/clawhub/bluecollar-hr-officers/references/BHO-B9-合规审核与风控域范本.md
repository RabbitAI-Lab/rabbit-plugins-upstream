### 二、域内统一约定

- 判定顺序固定：年龄工种 → 协议保险 → 报酬信息 → 转包与派遣比例
- 四类硬阻断：未成年工禁忌岗、协议未签、层层转包、向学生收费——命中即终止管线

### 三、任务样例

#### B9-01 派遣与实习合规风险地图 —— 交付物：《合规风险地图》
⚖️ 法规口径

- **场景**：新批次启动前绘制合规地图
- **输入**：证照与协议、花名册与工资流水、制度与检查记录；上游：无（入口任务）
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 风险点/依据/等级/责任单元/措施 |
| 可选组件 | 历史处罚案例 |
| 组装顺序 | 扫法规→列义务→配场景→分级→落责任 |
| 约束 | 七条红线全部落图、标版本与复核日 |
| 格式 | 风险地图（风险点/依据/等级/责任单元/控制措施） |

- **交付物本体**（示例数据·非实际经营值）：

| 风险点 | 依据 | 等级 | 责任 |
|---|---|---|---|
| 16–18 岁排夜班 | 未成年工特殊保护规定 | 红 | N1-05 / B9-05 |
| 协议缺监护人签字 | 实习管理规定 | 红 | N3-04 / B9-01 |
| 派遣占比>10% | 劳务派遣暂行规定 | 橙 | B2-07 / N3-04 |
| 花名册微信外发 | 个人信息保护法 | 橙 | N4-02 |

- **勾稽**：红线类风险 7 项全部在表；红色项控制措施必为"阻断"
- **口径引用**：总纲 1.7

### 四、域内交叉校验

- 风险地图（B9-01）红线项 = 培训内容（B9-06）= 迎检清单（B9-07）
- 内审发现（B9-04）→ 违规处置（B9-08）→ 制度修补闭环
- 物料审核（B9-02）与内容质检（B3-06）共用禁词表
