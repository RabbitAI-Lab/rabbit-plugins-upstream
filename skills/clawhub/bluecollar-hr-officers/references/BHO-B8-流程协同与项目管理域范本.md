### 三、任务样例

#### B8-01 竞标与专项项目立项 —— 交付物：《项目章程》
🔒 内部口径

- **场景**：参与客户 A 区域总代竞标
- **输入**：项目章程、进度记录、会议纪要与预算；上游：无（入口任务）
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 章程（目标/范围/干系人/成功标准/退出） |
| 可选组件 | 风险清单 |
| 组装顺序 | 定目标→划范围→列干系人→评可行→章程 |
| 约束 | 核资质与保证金、写明不做什么、无退出不立项 |
| 格式 | 项目章程（背景/目标/范围/干系人/里程碑/风险） |

- **交付物本体**（示例数据·非实际经营值）：
目标：取得 2 年总代；范围：客户 A 三个厂区；不做什么：不承接非电子类客户；退出条件：保证金超上限。
- **勾稽**：成功标准可量化（≥2 厂区 / ≥1,200 人月）
- **口径引用**：总纲 1.5

#### B8-02 总代竞标/冲刺项目计划 —— 交付物：《项目计划与甘特》
🔒 内部口径

- **场景**：竞标准备 45 天
- **输入**：项目章程、进度记录、会议纪要与预算；上游：B8-01 竞标与专项项目立项、B7-05 年度送人目标分解、B4-03 进校行程与总控排期
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | WBS+基线+关键路径 |
| 可选组件 | 资源负荷图 |
| 组装顺序 | 拆WBS→估工期→排基线→标关键路径→设变更门 |
| 约束 | 关键路径不得压到无人负责、变更书面 |
| 格式 | 项目计划（WBS/工期/责任人/依赖）+ 甘特图 |

- **交付物本体**（示例数据·非实际经营值）：

| 阶段 | 工期 | 关键 |
|---|---|---|
| 资格与保证金 | 10 天 | 是 |
| 方案与报价 | 20 天 | 是 |
| 现场答辩 | 5 天 | 否 |

- **勾稽**：关键路径合计 ≤ 45 天
- **口径引用**：总纲 1.3

#### B8-03 商务/交付/财务协同 —— 交付物：《跨部门协同表》
🔒 内部口径

- **场景**：报价与交付能力冲突
- **输入**：项目章程、进度记录、会议纪要与预算；上游：B8-02 总代竞标/冲刺项目计划
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 诉求/冲突/方案/裁决 |
| 可选组件 | 升级路径 |
| 组装顺序 | 收诉求→找冲突→设方案→定裁决 |
| 约束 | 不以牺牲合规换进度、结论书面 |
| 格式 | 协同表（事项/诉求方/冲突/方案/裁决） |

- **交付物本体**（示例数据·非实际经营值）：

| 事项 | 冲突 | 方案 |
|---|---|---|
| 接 300 人急单 | 商务要接、交付无驻厂 | 分两批，先 150 人 |

- **勾稽**：方案须各方签字确认
- **口径引用**：总纲 1.4

#### B8-04 项目纪要与行动项 —— 交付物：《纪要与行动项看板》

#### B8-05 一页纸决策汇报 —— 交付物：《一页纸决策汇报》
🔒 内部口径

- **场景**：请老板定是否参标
- **输入**：项目章程、进度记录、会议纪要与预算；上游：B8-02 总代竞标/冲刺项目计划、N3-02 商务文书与对外函件
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 结论+三条依据+选项+建议 |
| 可选组件 | 附件索引 |
| 组装顺序 | 写结论→列依据→给选项→提请求 |
| 约束 | 一页为限、数字与台账一致 |
| 格式 | 一页纸（结论/依据/选项/建议/风险） |

- **交付物本体**（示例数据·非实际经营值）：
结论：建议参标；依据：客户年需求 2,400 人月、我方产能可行、保证金在承受范围；选项：参标 / 不参 / 联合参标；请求：批准 50 万保证金。
- **勾稽**：依据数字 = 台账数
- **口径引用**：总纲 1.2

#### B8-06 批次危机与群体事件 —— 交付物：《危机处置单》
⚖️ 法规口径

- **场景**：20 名学生因宿舍调整集体要求离厂
- **输入**：项目章程、进度记录、会议纪要与预算；上游：B8-02 总代竞标/冲刺项目计划、B1-04 用工舆情与院校口碑监测、N3-09 批次突发事件应急预案
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 等级+动作+口径+上报+善后 |
| 可选组件 | 媒体与家长沟通要点 |
| 组装顺序 | 判级→启动→定口径→处置→上报→善后 |
| 约束 | P1 30 分钟响应、单一口径、不推责 |
| 格式 | 危机处置单（事件/等级/动作/口径/上报/善后） |

- **交付物本体**（示例数据·非实际经营值）：
处置：驻厂 15 分钟到场→厂方 HR 与校方带队老师联合沟通→当晚调整 2 间宿舍→次日逐人回访。
- **勾稽**：处置后 24h 离职 ≤ 3 人
- **口径引用**：总纲 1.7

#### B8-07 批次流程优化 —— 交付物：《流程优化对比》
🔒 内部口径

- **场景**：入场手续 3 天压到 1 天
- **输入**：项目章程、进度记录、会议纪要与预算；上游：B8-02 总代竞标/冲刺项目计划、N4-07 批次台账流程线上化
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 现状/优化/收益 |
| 可选组件 | 数字化配套 |
| 组装顺序 | 画现状→量瓶颈→设方案→试点 |
| 约束 | 不削合规环节、量化收益 |
| 格式 | 流程对比（现状/优化后/收益）+ 试点方案 |

- **交付物本体**（示例数据·非实际经营值）：

| 环节 | 现 3 天 | 优化后 1 天 |
|---|---|---|
| 体检 | 集中 1 天 | 提前线上预约 |
| 签约 | 排队 2 小时 | 分组签约 |

- **勾稽**：总时长下降 ≥ 50%；合规环节数不变
- **口径引用**：总纲 1.7

#### B8-08 批次项目复盘与价值归因 —— 交付物：《项目复盘报告》
🔒 内部口径

- **场景**：竞标结束复盘
- **输入**：项目章程、进度记录、会议纪要与预算；上游：B8-05 一页纸决策汇报、B8-07 批次流程优化
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 目标/结果/差距/归因/沉淀 |
| 可选组件 | 可复制清单 |
| 组装顺序 | 比对→归因→量化→提炼→入库 |
| 约束 | 区分内外因、价值可核算 |
| 格式 | 复盘报告（目标/结果/差距/归因/沉淀） |

- **交付物本体**（示例数据·非实际经营值）：
结果：中标 2 厂区（目标 2）；差距：报价高于对手 3%；沉淀：报价测算模板入库（B10-06）。
- **勾稽**：中标厂区数 = 合同厂区数
- **口径引用**：总纲 1.2

### 四、域内交叉校验

- 章程目标（B8-01）= 复盘结果（B8-08）比对基准
- 危机处置（B8-06）触发 N3-09 预案与 B9-08 违规处置
- 一页纸（B8-05）数字 = 项目计划（B8-02）预算
