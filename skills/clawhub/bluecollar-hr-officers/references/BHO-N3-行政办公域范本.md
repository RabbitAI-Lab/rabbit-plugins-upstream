### 三、任务样例

#### N3-01 例会与批次协调会体系 —— 交付物：《会议体系与决议追踪表》
🔒 内部口径

- **场景**：理顺周会/批次会/客户会
- **输入**：协议原件、证照、票据与申请单、行程安排；上游：无（入口任务）
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 表1、表2 |
| 可选组件 | 会议成本估算 |
| 组装顺序 | 定类型→定议程→定参会→出纪要模板→建台账 |
| 约束 | 每会必有决议与责任人、24h 出纪要 |
| 格式 | 会议体系表（类型/频次/议程/参会/输出）+ 决议追踪台账 |

- **交付物本体**（示例数据·非实际经营值）：

| 类型 | 频次 | 输出 |
|---|---|---|
| 周例会 | 每周一 | 待办清单 |
| 批次协调会 | 按批次 | 波次调整单 |
| 客户对接会 | 月度 | 联合计划更新 |

- **勾稽**：本月决议数 = 台账条目数；未闭环数 ≤ 3
- **口径引用**：总纲 1.3

|---|---|

| 可选组件 | 附件清单 |

- **交付物本体**（示例数据·非实际经营值）：

### 四、域内交叉校验

- 协议台账（N3-03）到期日 → 触发 N3-04 续签评审
