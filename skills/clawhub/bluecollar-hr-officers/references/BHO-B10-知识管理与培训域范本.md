### 三、任务样例

#### B10-01 蓝领业务知识库 —— 交付物：《知识库目录与条目模板》
🔒 内部口径

- **场景**：整理散落文档成库
- **输入**：现有文档与SOP、培训记录、问答与案例素材；上游：无（入口任务）
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 目录树+条目模板+权限 |
| 可选组件 | 标签体系 |
| 组装顺序 | 定分类→定模板→迁内容→设权限→定维护 |
| 约束 | 一主题一条目、过期标失效、商务数据分级 |
| 格式 | 知识库目录树 + 条目模板 |

- **交付物本体**（示例数据·非实际经营值）：
目录：业务线（派遣/实习/小时工）× 职能（渠道/驻厂/结算/合规）× 场景；条目字段：标题/适用/正文/依据/更新日/责任人。
- **勾稽**：条目数 = 迁入文档 × 去重率
- **口径引用**：总纲 1.8

#### B10-02 驻厂与对账 SOP —— 交付物：《驻厂与对账 SOP》
🔒 内部口径

- **场景**：新驻厂照做日报与对账
- **输入**：现有文档与SOP、培训记录、问答与案例素材；上游：B10-01 蓝领业务知识库
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 目的/范围/角色/步骤/异常/记录 |
| 可选组件 | 检查表 |
| 组装顺序 | 定范围→列角色→写步骤→写异常→定留痕 |
| 约束 | 一步一动作、关键步留痕、版本可追 |
| 格式 | SOP（目的/范围/角色/步骤/异常/记录） |

- **交付物本体**（示例数据·非实际经营值）：
步骤示例：20:00 导出考勤→核对在岗与异动→填日报 7 字段→发群 + 上传台账→异常（缺勤>3 人）电话上报。
- **勾稽**：SOP 步骤覆盖率 = 100%（无"视情况"）
- **口径引用**：总纲 1.3

#### B10-03 招生 30/40/20 问问答库 —— 交付物：《招生问答卡》
🌐 对外报价

- **场景**：代理与驻厂统一回答口径
- **输入**：现有文档与SOP、培训记录、问答与案例素材；上游：B10-01 蓝领业务知识库
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 问题/标准答案/依据/禁答 |
| 可选组件 | 场景卡（开场/异议/收尾） |
| 组装顺序 | 收问题→分类→写答案→标禁答→出卡 |
| 约束 | 与现行政策一致、不承诺薪资转正、季度校订 |
| 格式 | 问答卡（问题/标准答案/依据/禁答提示） |

- **交付物本体**（示例数据·非实际经营值）：

- **勾稽**：问答卡数 = 三类受众 × 各 10 问 = 30 张
- **口径引用**：总纲 1.7

#### B10-06 脱敏批次案例库 —— 交付物：《脱敏案例卡》
🔒 内部口径

- **场景**：沉淀一次高流失批次复盘
- **输入**：现有文档与SOP、培训记录、问答与案例素材；上游：B10-01 蓝领业务知识库、B1-06 同行标杆案例拆解、B4-07 单场宣讲 ROI 复盘
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 背景/动作/结果/可复制/教训 |
| 可选组件 | 同类案例对照 |
| 组装顺序 | 选案例→脱敏→写过程→写结果→提炼 |
| 约束 | 全部代号、数字标示例、无商业机密 |
| 格式 | 案例卡（背景/动作/结果/可复制/教训） |

- **交付物本体**（示例数据·非实际经营值）：
背景：客户 A 历史批次 P-00（200 人）前 10 天流失 18%；动作：加班不足当日协调 + 宿舍同乡重组；结果：后续 P-01（300 人）降至 2%（6 人）。
- **勾稽**：前后对比须给同一指标
- **口径引用**：总纲 1.8

#### B10-08 老驻厂经验萃取 —— 交付物：《经验卡》
🔒 内部口径

- **场景**：萃取 5 年老驻厂做法
- **输入**：现有文档与SOP、培训记录、问答与案例素材；上游：B10-06 脱敏批次案例库
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 场景/做法/原理/适用/禁忌 |
| 可选组件 | 对比新人常见错误 |
| 组装顺序 | 选人→访谈→提炼→验证→入库 |
| 约束 | 本人确认、写清不适用、不神化 |
| 格式 | 经验卡（场景/做法/原理/适用条件/禁忌） |

- **交付物本体**（示例数据·非实际经营值）：
做法：入职首周每天与 3 名"关键学生"单独聊 10 分钟；原理：抓住意见领袖可降低群体情绪扩散；不适用：单人零散入职批次。
- **勾稽**：经验卡须含 1 条禁忌
- **口径引用**：总纲 1.8

### 四、域内交叉校验

- SOP（B10-02）步骤 = 日报字段（N4-04）= 对账取数（N2-08）
- 案例（B10-06）指标 = 指标字典（B7-02）
- 胜任力（B10-07）能力项 = 培训课程（B10-04）目标
