- 四类受众四套口径；对外不用"中介/代理/派遣"，统一"岗位实践"；不承诺薪资与转正

### 三、任务样例

#### B3-01 机构定位与双口径信息屋 —— 交付物：《定位信息屋》
🌐 对外报价

- **场景**：统一院校版与企业版主张
- **输入**：品牌与客户资料、受众信息、素材与话术底稿；上游：无（入口任务）
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 主张+三支柱+证据+受众版本 |
| 可选组件 | 品牌视觉要点 |
| 组装顺序 | 定受众→定主张→搭支柱→配证据→分版本 |
| 约束 | 主张须有证据、不承诺无法兑现 |
| 格式 | 信息屋（主张/支柱/证据/受众版本） |

- **交付物本体**（示例数据·非实际经营值）：
院校版主张：就业导向、央企客户、有人驻场管；企业版主张：批量到岗、留存可测、合规兜底。三支柱：客户资源 / 驻厂交付 / 合规体系。
- **勾稽**：支柱数 = 3；每支柱 ≥ 2 条证据
- **口径引用**：总纲 1.1

- **输入**：品牌与客户资料、受众信息、素材与话术底稿；上游：B3-01 机构定位与双口径信息屋
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 日历表 |
| 可选组件 | 素材需求清单 |
| 组装顺序 | 定节点→定主题→排渠道→排产→设复盘位 |
| 约束 | 对齐出人旺季、避开考试周 |
| 格式 | 内容日历（周次/主题/渠道/形式/责任人） |

- **交付物本体**（示例数据·非实际经营值）：

#### B3-03 宣讲稿与招生话术撰写 —— 交付物：《宣讲稿与话术卡》
🌐 对外报价

- **场景**：院校 C 宣讲 40 分钟
- **输入**：品牌与客户资料、受众信息、素材与话术底稿；上游：B3-02 招生与招商内容日历
- **要求覆盖矩阵**：

| 槽位 | 本任务要求在样例中的落点 |
|---|---|
| 必选组件 | 开场+六问+异议 |
| 可选组件 | 30/40/20 问索引 |
| 组装顺序 | 定受众→搭结构→写开场→写六问→写异议 |
| 约束 | 只讲可兑现事实、工资给区间与前提、不贬低同行 |
| 格式 | 宣讲稿（开场/主体/六问/异议/收尾）+ 一页纸话术卡 |

- **交付物本体**（示例数据·非实际经营值）：
六问：做什么（岗位与班次）/ 多少钱（4,000–6,000 含加班，底薪 2,000）/ 住哪（6–8 人间免费）/ 怎么发（企业直发本人卡，每月固定日）/ 能否转正（约 30%）/ 想走怎么办（书面申请 + 驻厂面谈）。
- **勾稽**：承诺项 = 0；区间数 ≥ 3
- **口径引用**：总纲 1.7 红线 5

### 四、域内交叉校验

- 信息屋（B3-01）主张 → 宣讲稿（B3-03）六问 → 审核（B3-06）禁词
- 日历（B3-02）场次 = 活动立项（B4-01）场次
- 复盘（B3-08）到岗 = 批次台账到岗（B4-06）
