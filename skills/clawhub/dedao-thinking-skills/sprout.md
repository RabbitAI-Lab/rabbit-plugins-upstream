# 模式六:发芽

> **一句话:** 帮你把一条想法,撞到别的领域去,长出新东西。

---

## 触发判定(先判断该不该发芽)

**会触发**——用户明确表达发芽意图:
- "帮我发芽 / 这条想法发芽一下 / 让它发芽"
- "跨界联想一下"
- "看看这条笔记在别的领域有什么类比"
- 创作流程里,用户选定一条素材后说"想发散一下"

**不触发**——这些走别的模式或正常对话:
- 用户只是分享想法 / 闲聊 → 正常回应
- 用户求建议 → 走拷问或正常对话
- 用户想"写成 XX 卡片 / 创作" → 走**创作**模式,不走发芽
- 用户没明示发芽意图 → 别自作主张发芽
- 同一轮已经发过芽 → 不重复

拿不准时,问一句"你是想让我帮你发散联想(发芽),还是想把它写成具体内容(创作)?"

---

## 发芽做什么

拿用户给的那条想法当种子,去**别的领域**找类比、碰撞、启发:

- 这条想法的核心机制 / 结构,在另一个领域有没有对应物?
- 如果把这个领域的规律搬到那个领域,会发生什么?
- 有没有看似无关的事物,其实和这条想法同构?

关键:跨界要**真有结构上的相似**,不是硬扯谐音梗或表面联想。好的发芽是"咦,这两个东西居然是一回事",坏的是"这让我想到了……然后就没了"。

---

## 接收素材(本环境的改造说明)

得到原版是**异步**的:调完发芽工具就走,不等结果,新知卡片一会儿推过来。

Claude Code 没有真正的异步推送机制,所以本环境改为**同步生成**:

1. 收到发芽请求 → 直接生成新知卡片
2. 卡片生成后,用**一句话**简短确认("发芽好了,卡片在下面")
3. 不啰嗦、不铺垫

**纪律(重要):**
- 一条想法只发一次芽,不要反复发散成一堆
- 不要在对话里**编造**发芽过程(比如假装"我去查了某某资料"——你没查就别说查了)
- 卡片内容必须是真跨界联想,凑不出就老实说"这条想法比较封闭,暂时找不到好的跨界类比"

---

## 新知卡片格式

发芽产出一张卡片,结构:

```
# 🌱 新知卡片:[种子想法的一句话概括]

**种子:** [用户的那条想法,原样保留]

**跨界碰撞:**
- [领域A] 里有个东西叫 XX,它和你的想法同构,因为……
- [领域B] 的 YY 现象,其实是同一种机制……
- (2–4 条,每条都要说清"为什么像")

**启发:** 这条想法可以迁移到…… / 反过来想,它可能也意味着……
(一句让人停下来想的话)
```

卡片要能**独立成立**——别人光看这张卡,不用看上下文也能懂。
