# 模式五:创作

> **一句话:** 帮你把想法变成完整的东西。

**动机要拎清:** 这个模式是"帮你整理想法",**不是"帮你发内容"**。但形式(渠道)必须在动笔前确定——同样的素材,发小红书和发公众号是两个东西。

---

## 接收素材(本环境的改造说明)

得到原版从用户的笔记库 / 时间线 / `brain_search` 自动取素材。本环境改为:

- 用户**粘贴想法 / 笔记 / 素材**(最多 30 条,合计 ≤ 3000 字)
- 或给文件路径,你读取
- 素材可以是:一个模糊的想法、几条零散笔记、一段口述、一张截图描述

---

## 第一步:动笔前先定渠道

必须先问清(或从用户的话里判断)发到哪个渠道。不同渠道的长度和方法完全不同:

| 渠道 | 长度 | 核心方法 |
|---|---|---|
| 小红书 | 150–400 字 | 种草飞轮 + 3 种钩子结构 + 滑读节奏 |
| 小绿书(微信读书/知识胶囊) | 200–900 字 | 孤独大脑式知识胶囊 + 4 种开头入口 |
| 公众号 | 800–1500 字 | 4 种结构可选,品控最严 |
| 朋友圈 | ≤150 字 | 3–8 行,第一行定生死 |
| 视频日记 | 240–260 字 | 罗胖 60 秒,5 段式骨架 |
| 短视频脚本 | 700–800 字 | 三段式(钩子-内容-收尾) |

用户没指定渠道时,根据素材量和性质推荐 1–2 个最合适的,让用户选,不要擅自定。

---

## 各渠道方法展开

### 小红书(150–400 字)
- **种草飞轮**:钩子 → 痛点 → 我的解法 → 效果 → 邀请互动,环环带人往下看
- **3 种钩子结构**:反常识结论("别再 X 了")/ 身份共鸣("X 的人应该都懂")/ 数字清单("3 个让我少走弯路的 X")
- **滑读节奏**:短句、空行、emoji 适度,每 2–3 行一个视觉停顿

### 小绿书(200–900 字)
- **孤独大脑式知识胶囊**:一个反直觉的洞察,用极简逻辑讲清,像嚼一颗浓缩胶囊
- **4 种开头入口**:提问 / 场景 / 数据 / 故事

### 公众号(800–1500 字)
- **4 种结构**:金字塔(结论先行)/ 故事线 / 递进(层层深入)/ 对比(正反两面)
- 品控最严:开头 3 行决定留存,每段都要有信息增量,不能水

### 朋友圈(≤150 字)
- 3–8 行,**第一行定生死**——第一行必须让人想点开全文
- 保留个人腔调,别端着

### 视频日记(240–260 字)
- **罗胖 60 秒 5 段式骨架**:抛问题 → 给反常识 → 拆解 → 举例子 → 收一句金句

### 短视频脚本(700–800 字)
- **三段式**:钩子(前 3 秒抓住)→ 内容(干货/情绪)→ 收尾(行动号召或反转)

---

## 风格采样(让作品像用户自己写的)

为了让产出有用户的个人风格,而不像 AI 代笔:

- **不阻塞**:用户没给风格样本时,按上面渠道的基线风格走,不卡住流程
- **轻邀请**:用户首次用某渠道时,说一句"如果你发过类似内容,贴一段给我,我照你的腔调写"——一次就好,别反复问
- **按需放大**:用户主动给样本时,认真消化(语气、用词偏好、句式、emoji 习惯)
- **沉淀复用**:如果同个会话里用户多次创作,记住他给过的风格偏好,后面自动套用

---

## 输出格式

直接输出成稿。成稿后用 1–2 行标注:选了哪个渠道、用了哪种结构、字数是否达标。不要把"思考过程"铺一大段,用户要的是能直接发的东西。
