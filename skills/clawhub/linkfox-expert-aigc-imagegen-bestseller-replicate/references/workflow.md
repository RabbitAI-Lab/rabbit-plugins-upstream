# 业务流程详述：爆款复刻

## 业务目标

用户看到销量好的亚马逊 listing（或手上有看中的爆款参考图），希望把这些图片的排版与风格套用到自己的商品上，批量生成对应的新图。最终交付 = 一组"参考图 → 复刻图"的对照图片。

## 输入参数清单

| 参数 | 性质 | 默认 | 说明 |
|------|------|------|------|
| product_image | 运行时入参，必填 | — | 商品原图（图一），1 张，所有复刻图的商品主体 |
| amazon_input | 运行时入参（方式 A） | — | 亚马逊链接/ASIN，解析出 ASIN + 站点 |
| reference_images | 运行时入参（方式 B） | — | 上传的参考爆款图（图二），可多张 |
| provider | 运行时入参 | GPT_2_IMAGE | 生图模型；透传给 imagegen，本 skill 不校验枚举 |
| quality | 运行时入参 | high | 仅 GPT_2_IMAGE 生效 |
| aspectRatio | 运行时入参（可空） | 默认=逐张跟图二 | 「默认比例」/空 → S3 逐张探测当前图二，按真实显示宽高组装 `W:H` 传入；具体比例 → 所有复刻图统一透传。S1 归一化 |
| include_aplus | 运行时入参（仅方式 A） | true | 是否把 listing A+ 纳入参考图；用户/前端「只要主图」→ false |
| amazonDomain | 默认 | amazon.com | 链接带站点则覆盖 |
| outputNum | 硬编码 | 1 | 每张参考图出 1 张 |
| resolution | 运行时入参 | 2K（缺省） | 前端传了原样透传给 imagegen；前端未传缺省 2K |

## 两种输入方式

- **方式 A（亚马逊对标）**：商品原图 + 亚马逊链接/ASIN。仅亚马逊。前置 S2 用 `linkfox-amazon-product-detail` 拉 listing 图片，经 `scripts/extract_reference_images.py` 合并主副图与（默认）A+ 图作为参考图集。
- **方式 B（自备参考图）**：商品原图 + 上传参考图（多张）。不限平台。跳过 S2，参考图集即用户上传图。

## 步骤拆解

| 编号 | 动作 | 上游 | 下游 | 调用能力 |
|------|------|------|------|----------|
| S1 | 识别方式 + 校验 + 模型确认 | 用户输入 | S2(方式A)/S3 | 内部逻辑 + AskUserQuestion |
| S2 | 抓 listing 参考图（主副图 + 可选 A+） | S1 | S2.5 | linkfox-amazon-product-detail + extract_reference_images.py |
| S3 | 逐张配对生图 | S1+S2/上传图 | S4 | linkfox-aigc-imagegen |
| S4 | 落盘 + 对照展示 | S3 | 用户 | linkfox_paths.resolve_media_path |

## 配对与提示词（核心约定）

- **1:1 复刻**：1 张商品原图（图一）套用到每张参考图（图二）。参考图 N 张 → 调 imagegen N 次 → 产出 N 张复刻图。
- **imageUrls 顺序固定** `[图一原图, 图二参考图]`，与提示词的"图一/图二"对应。
- **固定提示词唯一正源**：下方提示词即固定提示词的**唯一维护处**，`SKILL.md` 与运行时不再内联复制——运行时读取本段全文原样使用。修改提示词只改这里。
- **固定提示词**（不接受用户覆盖）：
  > 用图一的产品生成一张亚马逊上架图。仅凭对图一静态画面的肉眼直接观察作为产品认知依据，不推断、不联想同类产品特性，产品的轮廓、厚度、折叠结构与图一严格一致，图一上没有的部件就不存在。视角和镜头数量必须优先跟随图二：图二是单一视角就输出单一视角，图二是多角度/多分区/多镜头组合才输出多角度。允许根据图二的视角和镜头语言调整图一产品的展示角度，但不得主动增加图二没有的额外视角、额外分区或额外商品副本。无论角度如何变化，图一产品的核心识别特征必须完整保留，不得丢失图一中可见的关键部件、标识、图案、颜色分布、边缘形态、厚度关系和结构比例，也不得新增图一没有的部件、配件、图案、接口、装饰或结构。新角度中原图未展示的区域，应基于图一已可见的颜色、材质、厚度、边缘和连接关系进行一致性延展，不能创造新的设计。产品的使用场景中，配合使用的物品按真实使用逻辑自然出现。
  > 图二是竞品参考，你要做的是理解图二的表达策略——它怎么构图、怎么引导视觉层级、文字承载了什么信息量、整体传递什么氛围——然后用同等的商业完成度和表达丰富度，为图一的产品重新设计一张图。重新设计意味着你要基于图一产品的实际形态和使用场景来组织画面，而不是把图二的构图硬套过来。如果图二是局部特写、细节放大或微距画面，则最终也必须生成图一产品对应真实可见部位的局部特写、细节放大或微距画面，不输出完整产品全貌。
  > 画面的背景处理跟随图二，识别图二的意图，若为白底则生成白底图；若为场景则生成场景图。画面是一个连贯的三维空间，所有物体共享统一透视与光源，具备正确的遮挡关系与接触关系，所有材质都保持其真实物理属性，物体之间不互相穿透。产品及场景物品的尺寸必须符合现实世界的真实比例，不得为填充画面而放大或缩小任何物体，有尺码的严格遵照尺码比例。
  > 图二中的产品对你来说不可见——不读取它的形态、结构、部件、功能特征，只读取图二中产品以外的画面表达方式。其余表达手段——景深、道具、色调、模特、视角——从图二学习意图后自由重构，但服从空间逻辑。图二有人物就加入人物，图二没有人物就不加；加入时匹配目标市场人群，全新形象，同一组图中保持同一人的发型、脸型、肤色一致。文字部分：从图二只取排版形式和信息层级结构，具体内容完全基于图一产品独立撰写——观察图一产品本身的材质、功能、设计特征来提炼卖点，不得复制或改写图二的文案措辞。文字语言由图二决定——图二是哪个国家的语言就用哪国语言输出，与本提示词的语言无关。输出比例与图二一致。

- **aspectRatio**：S1 将「默认比例」/「默认」/`auto`/空归一化为默认模式。有具体比例 → 所有复刻图统一透传用户选项；默认模式 → S3 对每张图二调用 `scripts/probe_image_size.py`，读取经 EXIF 方向校正后的真实显示宽高，按原始像素组装 `W:H`（不约分）并传给 imagegen，例如 `1400×600 → 1400:600`。每张参考图独立探测，禁止复用其他图的比例；探测失败只跳过当前图，不影响其他并发任务。固定提示词保持不变，不在 prompt 追加宽高行。

## 已知局限 / TBD

- 方式 A 按 ASIN 计费、单价高；逐张生图耗时成本线性增长。
- imagegen 必须接受原始像素形式的任意 `W:H`；若下游收紧为固定枚举，会按参数非法护栏要求用户改选具体比例。
- 固定提示词为中文，imagegen 偏好英文；效果不稳可在迭代调整。
- 图片型交付，无 skill-output envelope（映射表暂无对应 subject）。
