# 合同管理 - contract-management

面向法务和业务人员的智能合同管理工具。覆盖NDA快筛、合同起草、审查、对比、台账提醒和法条速查，实现合同全生命周期管理的效率提升。

## 子技能列表

| 子技能 | 功能 | 触发关键词 |
|--------|------|-----------|
| NDA快筛 | 上传NDA文件，筛查八项关键条款并给出分级判断 | 审NDA, NDA审查, 保密协议, 保密条款 |
| 合同台账提醒 | 录入合同关键日期，生成分级提醒计划 | 合同台账提醒, 合同台账, 到期提醒 |
| 合同对比 | 上传两份合同，逐条语义级对比差异 | 合同对比, 版本差异, 条款变更 |
| 审查合同 | 逐条审查风险并按红黄绿分级标记 | 审查合同, 合同审查, 合同风险 |
| 法条速查 | 输入业务问题，检索匹配的法律条文和案例 | 查法条, 法条检索, 法律依据 |
| 起草合同 | 描述交易背景，生成专业级合同初稿 | 起草合同, 合同起草, 合同模板 |

## 使用方法

通过 Marvis 对话自然触发，说出需求即可自动匹配对应子技能。
