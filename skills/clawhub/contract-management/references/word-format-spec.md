# 合同Word文档排版参数规范

> 供 contract-drafting.md 第六步「格式化输出Word文档」调用。

## 一、页面设置

| 参数 | 规格 |
|------|------|
| 纸张 | A4（210mm × 297mm） |
| 左边距 | 30mm（含装订线10mm） |
| 右边距 | 25mm |
| 上边距 | 25mm |
| 下边距 | 25mm |
| 页眉 | 15mm |
| 页脚 | 15mm |

## 二、字体规范

| 元素 | 字体 | 字号 | 样式 |
|------|------|------|------|
| 合同大标题 | 黑体 | 二号（22pt） | 加粗、居中 |
| 条标题（第X条） | 黑体 | 四号（14pt） | 加粗 |
| 款标题 | 仿宋 | 四号（14pt） | 加粗 |
| 正文 | 仿宋 | 四号（14pt） | 首行缩进2字符 |
| 表格内文字 | 仿宋 | 小四（12pt） | — |
| 页脚编号 | 仿宋 | 五号（10.5pt） | 居中 |

## 三、段落格式

| 参数 | 规格 |
|------|------|
| 行距 | 固定行距 28pt |
| 段前 | 0pt |
| 段后 | 0pt |
| 首行缩进 | 2字符（正文段落） |
| 对齐方式 | 两端对齐（正文）、居中（标题） |

## 四、签章页

| 参数 | 规格 |
|------|------|
| 位置 | 另起一页，单独成页 |
| 布局 | 双栏布局（甲方左，乙方右） |
| 盖章位置 | 预留 40mm × 40mm 空白区域 |
| 签章位置标注 | 用浅灰色方框标注，注明「盖章处」 |
| 签署日期 | 置于签章下方，格式 XXXX年XX月XX日 |
| 法定代表人/授权代表 | 签字栏置于签章上方 |

## 五、水印

| 参数 | 规格 |
|------|------|
| 默认水印 | "DRAFT 草稿" |
| 字体 | 黑体 |
| 字号 | 一号（26pt） |
| 颜色 | 灰色（RGB: 180, 180, 180） |
| 角度 | 45度倾斜 |
| 布局 | 平铺（5行×5列） |
| 透明度 | 30% |

## 六、特殊标注

| 标注类型 | 格式 |
|------|------|
| 【待确认】标注 | 红色字体（RGB: 255, 0, 0）、加粗、黄色高亮（RGB: 255, 255, 0） |
| 格式条款 | 加粗 + 下划线（履行《民法典》第496条提示义务） |
| 关键数字 | 同时使用阿拉伯数字和中文大写（如：100,000元（壹拾万圆整）） |

## 七、合同编号规则

格式：`【公司简称-类型缩写-YYYY-NNN】`

| 组成部分 | 说明 | 示例 |
|---------|------|------|
| 公司简称 | 2-4个大写字母 | ABC、TECH |
| 类型缩写 | 合同类型代码 | CG（采购）、XS（销售）、FW（服务）、ZL（租赁）、NDA（保密）、LD（劳动） |
| YYYY | 四位年份 | 2026 |
| NNN | 三位流水号 | 001 |

## 八、目录/页码

| 参数 | 规格 |
|------|------|
| 页码位置 | 页面底端居中 |
| 页码格式 | 阿拉伯数字，从正文第1页开始 |
| 目录 | 如条款超过10条，自动生成目录（插入在标题页之后） |
| 目录字体 | 黑体小二号"目录"标题，仿宋四号目录条目 |

## 九、起草说明页（独立页，置于合同末尾）

| 章节 | 内容要求 |
|------|---------|
| 关键设计考量 | 核心条款的设计逻辑和保护意图 |
| 保护性条款说明 | 为我方设计的保护性条款及其意义 |
| 行业惯例参数说明 | 各项商业参数的行业基准来源 |
| 风险提示 | 高频争议场景，签约前需关注的风险点 |
| 建议协商事项 | 可能需要与对方谈判的核心条款 |
| 法律依据索引 | 合同中引用的所有法条和司法解释汇总 |

## 关联Skill

- **contract-drafting** — 供其第六步「格式化输出Word文档」调用，提供页面/字体/段落/签章页等完整排版参数
- **contract-review** — 审查报告如需输出为 Word 文档，可参照本规范生成专业排版
- **contract-comparison** — 对比报告如需输出为 Word 文档，可参照本规范的页面设置和字体规范

## 失败回退机制

| 步骤 | 失败条件 | 回退目标 | 最大重试 | 不可恢复时升级路径 |
|------|---------|---------|---------|------------------|
| 一、页面设置 | Node.js docx 库不支持指定边距（如装订线10mm）或纸张规格异常 | 降级为标准A4+统一25mm边距，标注"[装订线未应用，建议手动调整]" | 2次 | 输出标准A4文档，提示用户在Word中手动调整边距 |
| 二、字体规范 | 目标环境缺少黑体/仿宋字体，导致字体回退 | 降级为通用字体（宋体+黑体），标注"[部分字体缺失，已用通用字体替代]" | 1次 | 输出文档并附字体安装说明，建议用户在目标机器安装黑体/仿宋 |
| 三、段落格式 | 固定行距28pt与表格/图片内容冲突，导致内容被截断 | 表格/图片段落改用单倍行距，标注"[该段落行距已调整]" | 2次 | 输出文档并提示用户检查表格和图片显示是否正常 |
| 四、签章页 | 双栏布局生成失败或盖章位置40mm×40mm预留区域错位 | 降级为单栏布局，盖章位置用文字标注"[盖章处]"，提示用户手动调整 | 2次 | 输出单栏签章页，建议用户在Word中手动调整为双栏 |
| 五、水印 | 水印平铺或45度倾斜或30%透明度设置失败 | 降级为单一居中水印（无平铺），标注"[水印为简化版]" | 2次 | 输出无水印文档，提示用户在Word中手动添加水印 |
| 六、特殊标注 | 【待确认】黄色高亮或格式条款加粗+下划线应用失败 | 降级为仅红色字体标注【待确认】，格式条款仅加粗，标注"[部分标注样式未完整应用]" | 2次 | 输出文档并提示用户手动检查特殊标注样式 |
| 七、合同编号规则 | 公司简称或类型缩写缺失，无法生成完整编号 | 使用占位符[公司简称]-[类型]-YYYY-001，标注"[编号待用户补充]" | 1次 | 输出占位编号，建议用户确认公司简称和类型缩写后替换 |
| 八、目录/页码 | 条款超过10条但目录自动生成失败，或页码从正文第1页开始设置异常 | 跳过目录，仅生成页码（从第1页开始），标注"[目录未生成，建议手动插入]" | 2次 | 输出无目录文档，提示用户在Word中手动插入目录 |
| 九、起草说明页 | 缺少设计考量/风险提示等信息，无法完整填充起草说明 | 输出起草说明页框架，缺失章节标注"[待补充]" | 1次 | 建议用户参考 contract-drafting.md 的起草说明要求手动补充 |
