## Description: <br>
Helps backend and platform teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to turn OpenAPI, Swagger, and REST API documentation requests into practical workflows, checklists, review guidance, code support, and validation steps. It is aimed at API developers, backend teams, developer-experience teams, and maintainers who need services to be understandable to other engineers. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may be selected too broadly for generic API or developer-experience requests. <br>
Mitigation: Use it for explicit OpenAPI, Swagger, REST endpoint documentation, schema validation, or API documentation review tasks. <br>
Risk: Generated documentation guidance can become inaccurate if it is not checked against the actual routes, schemas, authentication rules, and validation behavior. <br>
Mitigation: Review outputs against the service implementation and run available OpenAPI linting, contract, or schema validation checks before relying on them. <br>
