# 知识可视化教学法要点

## 一、为什么可视化能帮到教学

知识可视化的理论基础是**双重编码理论**（文字 + 图像双通道记忆）和**认知负荷理论**（结构化呈现降低外在认知负荷）。对教师而言，一张好图的价值在于：

1. **显化知识结构**：学生听课时获得的是线性信息，图把"包含、因果、对比"等非线性关系画出来。
2. **提供先行组织者**（奥苏贝尔）：新课前给框架图，学生带着"架子"听课，新知识有地方挂。
3. **支持复习提取**：复习课用概念图做"骨架回顾"，比逐页翻 PPT 更能激活长期记忆。
4. **暴露错误概念**：让学生补全概念图的连线词，是诊断迷思概念（misconception）的有效方式。

## 二、选图型的教学逻辑

- **知识点之间是"辐射/展开"关系** → 思维导图（适合发散、联想、概览）
- **知识点之间是"命题/交叉"关系** → 概念图（适合深度理解，连线必须有连接词）
- **知识是"怎么做"的程序性知识** → 流程图（解题步骤、实验操作、算法）
- **知识沿时间演进** → 时间轴（历史、地质年代、技术史）
- **知识需要辨析异同** → 对比矩阵（易混概念是考试富矿）
- **知识是分类体系** → 层级分类图（分类学、语法体系、制度类型）
- **过程周而复始** → 循环图（物质循环、生命周期、经济周期）
- **分析成因/问题归因** → 鱼骨图（历史背景、实验误差、错题归因）
- **单元整体导航** → 知识地图（开篇导览、期末总复习）

判断口诀：**"关系决定图型"**——先问"这些知识之间什么关系"，再选图，而不是先选图再填内容。

## 三、各学科适配建议

| 学科 | 高频图型 | 注意点 |
| --- | --- | --- |
| 语文 | 思维导图（课文结构）、概念图（主旨与手法）、时间轴（作家作品/文言文叙事） | 重感悟的文本不要过度拆碎，图用于结构梳理，替代不了朗读品味 |
| 数学 | 流程图（解题程序）、层级图（知识体系）、对比表（易混公式/概念） | 公式必须完整准确且按 ISO 80000 排版（变量斜体、常量/单位正体、无 ^ 写法）；解题流程图要含"检验/反思"环节 |
| 英语 | 思维导图（词汇场/语法体系）、对比表（时态/语态）、层级图（词类） | 术语可用中英双语；词汇图按语义场组织优于按字母 |
| 物理 | 概念图（规律体系）、流程图（实验）、鱼骨图（误差分析）、对比表 | 因果关系要严谨（条件→现象→结论），公式单位齐全；动态矢量图按最大模长比例尺、箭头防截断并标真实数值，数值与理论误差<0.5% |
| 化学 | 流程图（实验操作/工业流程）、循环图（物质转化）、对比表（物质性质） | 化学方程式配平、条件、气体沉淀箭头标注完整 |
| 生物 | 概念图（生理过程）、循环图（物质/能量循环）、层级图（分类） | 过程图体现"结构与功能相适应"的学科思想 |
| 历史 | 时间轴（主线）、鱼骨图（事件成因）、对比表（变法/革命/制度） | 时间轴必须有阶段划分；因果分析区分根本原因与直接原因 |
| 地理 | 循环图（水循环/大气环流）、流程图（地理过程）、因果链 | 突出空间-因果联系；区域地理可用对比矩阵 |
| 政治/道法 | 概念图（制度体系）、层级图（国家机构）、流程图（程序） | 表述严格依据课标和教材原文，避免口语化偏差 |

## 四、学段语言风格

- **小学（1-6 年级）**：具象化、生活化比喻；节点文字短，可配 emoji；多用"像什么"的类比。
- **初中（7-9 年级）**：引入学科术语但配解释；开始训练"连接词"表达关系；易错点显性标注。
- **高中**：术语直接使用；强调知识网络的交叉联系（跨章节连线）；可加入"考法提示"。
- **高校/职教**：专业表述；可呈现学术争议、多模型对比；侧重体系完整性与应用场景。

## 五、课堂使用建议（可写进互动问题区）

- **新授课**：先展示"留白概念图"（只有节点没有连线词），讲完让学生补连线。
- **复习课**：先给中心主题，让学生 4 人小组默画思维导图，再对照教师版查漏。
- **实验课**：流程图配鱼骨图——流程做对了，误差从哪来？
- **对比教学**：对比矩阵的"相同点"行让学生先填，学生会发现"同"比"异"更难概括。
- **图像探究（函数/示意图）**：先展示静态图让学生预测"参数变了图像怎么变"（如底数变大、温差变大、角度增大），再用交互图像页的滑块验证——猜想-验证循环能有效暴露迷思概念。
- **总览图"先整体后局部"**：课堂开讲先让学生看"适应全图"的知识总览（全部节点同屏、无重叠），再用滚轮放大、拖拽平移聚焦某一局部关系（如某条连线的连接词），建立整体→局部的读图路径，避免学生一上来就盯细节而看不到体系。
- **逐格揭示表格当"提问触发器"**：对比表/公式表内容格初始空白即是提问机会——先让学生口头或板演作答，再单击单元格揭示标准内容；"相同点/不同点"逐条揭示尤其能暴露"比同更难"的思维盲区，适合先想后答的讲授与自学自测。
- **控制面板调节奏**：讲动态演示（受力/运动/简谐）时，用"暂停"定格关键瞬间、用"速度倍率"放慢过程——比连续播放更能让学生看清每个状态变化与物理量关系。
- **当堂自测即答即评**：用互动自测的即时反馈（绿✔/红✘ + 必显完整标准答案）做当堂小测——学生答完立即对照答案的数值、单位与步骤自查，比课后批改反馈更及时；答错时同步标绿的正确选项本身就是一次纠错教学。

## 六、知识正确性保障方法论

### 核查触发条件

以下五类事实性知识在写入 JSON 大纲前**必须核查**：

| 类别 | 典型示例 | 核查要点 |
| --- | --- | --- |
| 年代与日期 | "辛亥革命 1911.10.10""二战结束 1945" | 精确到日的事件需核实具体日期；年份需核实公元/农历 |
| 公式与定律 | F=ma、E=mc²、光合作用方程式 | 检查符号、系数、条件（如"催化剂""加热"标注） |
| 分类标准 | 生物分类（界门纲目科属种）、词类划分 | 核实分类体系版本（如五界/六界/三域系统） |
| 定义与术语 | "匀速直线运动""光合作用"的严格定义 | 需匹配对应学段课标表述，避免口语化偏差 |
| 数据与统计 | "中国人口14亿""地球到太阳距离1.5亿km" | 核实数据来源与时效性；近似值需标注"约" |

### 核查优先级

1. **教材原文优先**：以人教版/北师大版（教师指定版本）教材表述为准。
2. **课标术语优先**：以《义务教育课程标准》或《普通高中课程标准》的术语表述为准。
3. **权威来源优先**：百科全书 > 教材教辅 > 网络资料。

### 置信度判断与标注

- **置信度 ≥ 90%**：直接写入，`unconfirmed: false`。
- **置信度 < 90%**：设置 `unconfirmed: true`，在 `definition` 末尾追加 `[unconfirmed]`。
- **完全不确定**：不写入该节点，在交付说明中告知教师该知识点需要补充。

### 各学科高频核查清单

| 学科 | 高频易错事实 |
| --- | --- |
| 物理 | 公式适用条件（如 v=s/t 仅适用于匀速）；单位换算（kW·h 与 J 的关系）；g 值取值（9.8 vs 10） |
| 化学 | 方程式配平与条件标注；气体↑/沉淀↓箭头；物质分类（混合物/纯净物/化合物） |
| 生物 | 分类体系版本；生理过程场所（叶绿体 vs 线粒体）；遗传术语（基因/DNA/染色体层级） |
| 历史 | 事件精确日期；人物生卒年；条约名称与签订时间对应 |
| 地理 | 数据时效性（人口、GDP）；地理坐标精确值；气候分类标准 |
| 数学 | 公式适用域（如判别式 Δ≥0 才有实根）；定理前提条件 |
| 语文 | 作家生卒年与朝代；作品出处；文言文字词释义的权威版本 |
| 英语 | 语法规则的例外情况；词汇释义的语境差异 |
| 政治/道法 | 表述严格依据课标和教材原文；制度名称的完整准确表述 |

### unconfirmed 标注的教学意义

标注 `[unconfirmed]` 不是 Agent 的能力缺陷，而是**对教师专业判断的尊重**：
- 教师是该学科该学段的最终权威，Agent 提供结构化初稿，教师把关事实准确性。
- 黄色水印让教师在课堂使用前能快速定位需要复核的内容，避免传播错误知识。
- 这一机制比"Agent 自信但错误地输出"更安全，符合"宁可标注不可编造"的原则。

## 七、常见反模式（避免）

1. ❌ 文字搬家：把教材段落原样塞进节点，图变成"彩色的笔记"。
2. ❌ 关系缺失：概念图只有连线没有连接词，学生看不出"为什么连"。
3. ❌ 平均用力：所有节点一样大一样颜色，重点淹没。
4. ❌ 为版面牺牲完整：为追求"少而精"故意删减知识节点，或节点堆叠不排布——总览节点数以完整覆盖为准（不设上限），节点多时应扩大画布、初始适应全图、缩放平移查看，而不是删点或叠放（SKILL.md 原则 26、data-format.md 10.5）。
5. ❌ 事实错误：年代、公式、定义凭印象写——必须核实。
6. ❌ 只给静态死图：知识点含参数影响（函数系数/底数、温差、角度、力的大小等）却只输出一张静态图，不给可平移缩放、滑块调参的交互图像页——违背本技能"图像即交互"原则（见 SKILL.md）。
7. ❌ 千篇一律：十个主题九张思维导图，忽略了知识本身的结构差异。
8. ❌ 表格一次全给：对比表/公式表默认把全部内容平铺呈现，剥夺学生"先想后答"的机会——应默认空白、单击逐格揭示（SKILL.md 原则 14、data-format.md 10.4）。
9. ❌ 总览图拥挤或不可缩放：节点互相重叠、越出画布，或不能滚轮缩放/拖拽平移——违背"总览同屏、一图全收"（SKILL.md 原则 13），学生既看不清整体也看不清细节。
10. ❌ 数值公式不校验：运动学/简谐等只看画得好看、不比对理论值——应内嵌数值自检，典型场景误差<0.5%（SKILL.md 原则 16、data-format.md 10.8）。
11. ❌ 矢量箭头无比例尺或超界：箭头长度随心所欲、越出画布或比例失真——应按最大模长比例尺、超 min(宽,高)/4 截断并标真实模长（SKILL.md 原则 17、data-format.md 10.7）。
12. ❌ 标准答案只给最终数字：自测反馈无判定标识或答案缺单位、缺步骤——应即时双标识（绿✔/红✘+明确文字）并展示含完整数值、单位与关键步骤的标准答案，学生从答案里也能学到过程（SKILL.md 原则 21、data-format.md 10.10）。
13. ❌ 公式排版不合规：用 x^2、x^α 脱字符写幂、变量不做斜体、上下标模糊——应按 ISO 80000 用 <sup>/<sub> 排版、变量斜体、常量/单位/函数名正体，与大屏投影片的学术规范一致（SKILL.md 原则 23、data-format.md 第十一部分）。
14. ❌ 交付页残留自检提示或手拼公式：页面显示"自检通过/未通过"等字样、完整公式用纯文本拼接——自检应静默（仅后台记录）并按质量闭环修改复检直至全过；公式应经 MathML/LaTeX 引擎生成（SKILL.md 原则 10/24/25、data-format.md 10.3 与第十一部分）。
