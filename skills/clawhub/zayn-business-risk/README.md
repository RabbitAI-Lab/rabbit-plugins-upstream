# BUSINESS_RISK() 企业合作风险调查

- Skill：`zayn-business-risk`
- 用途：调查法律、监管、制裁、信用、身份、舆情和运营风险信号。
- 适用：客户、供应商和合作伙伴尽调；不适用法律意见或银行级信用评估。
- 输入：正式名称、辖区、主体线索、风险类型、时间范围、合作场景。
- 最低条件：主体与辖区明确、同名风险可控、调查用途清楚。
- 流程：主体确认→风险问题→权威来源→交叉验证→安全表达。
- 输出：事件、信号、未找到项目、时间线、控制措施和来源。
- 证据与风险：遵守共享规则；无记录不等于无风险。
- 协作：company-research 提供主体，company-fit 使用风险结果。
- 示例：核验某德国供应商近五年的破产、处罚和制裁公开记录。
- 版本：v1.0.0
