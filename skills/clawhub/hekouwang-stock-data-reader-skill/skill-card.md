## Description: <br>
Hekouwang Stock Data Reader Skill turns an A-share stock code into a neutral public-data recap by fetching AkShare market and financial data, calculating fixed indicators, and drafting finance visuals or articles with compliance guardrails. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External finance content creators and developers use this skill to fetch public A-share stock data, analyze price, fund-flow, valuation, financial-statement, and risk signals, and prepare neutral recap assets for WeChat, Toutiao, or limited Xiaohongshu formats. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill runs local scripts, downloads public market data, and writes report artifacts. <br>
Mitigation: Review commands before execution, use a virtual environment, and pin dependencies when reproducible installs are required. <br>
Risk: Finance recaps can be mistaken for investment advice or stock recommendations. <br>
Mitigation: Keep the required neutral posture, avoid buy/sell signals, price targets, and predictions, and include the documented risk disclaimer and data cutoff. <br>
Risk: The screenshot workflow can delete generated HTML files after PNG export. <br>
Mitigation: Preserve source data, analysis JSON, and any needed intermediate HTML before running screenshot cleanup when an audit trail is required. <br>
Risk: Public financial data can be stale, unavailable, or inconsistent across sources. <br>
Mitigation: Verify key figures against AkShare-backed source data and label the data source and cutoff time in each report. <br>
