## Description:

Analyze existing XML sitemaps or generate new ones with templates while validating XML format, URL status, limits, metadata, and structure.

This skill is ready for commercial/non-commercial use.

## Publisher:

[asale-ai](https://clawhub.ai/user/asale-ai)

### License/Terms of Use:

MIT-0

## Use Case:

External site owners, SEO practitioners, and developers use this skill to audit sitemap health, generate sitemap files, and document site structure for search discovery workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Website sitemap validation can trigger external network requests and local report or sitemap file creation.

Mitigation: Run the skill only against sites you are authorized to assess, review generated files before publishing, and expect local report or sitemap outputs.

Risk: Search Console checks may expose account or property data if used with unauthorized properties.

Mitigation: Use Search Console tooling only with accounts and properties you control or are authorized to access.
