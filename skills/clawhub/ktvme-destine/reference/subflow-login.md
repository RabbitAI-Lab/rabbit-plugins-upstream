## 调用时机

在以下场景中，主技能应调用本子流程完成认证：

- **预订流程开始前**：`sessionInfo` 返回 `status=0`（未登录）
- **创建订单之前**：再次检查时 `sessionInfo` 返回 `status=0`，防止会话过期
- **支付之前**：再次检查时 `sessionInfo` 返回 `status=0`
- **用户明确要求登录**：如"帮我登录"、"发个验证码"

## 验证码规则汇总

| 属性               | 值                               |
| ------------------ | -------------------------------- |
| 长度               | 6位数字                          |
| 有效期             | 5分钟                            |
| 24小时最大发送次数 | 5次                              |
| 发送间隔           | ≥60秒                            |
| 使用次数           | **一次性**（验证成功后立即失效） |

### 发送限制条件

| 条件                   | 限制要求     | 错误提示                                 |
| ---------------------- | ------------ | ---------------------------------------- |
| 手机号为空或格式不正确 | 不允许发送   | 请输入有效的手机号                       |
| 发送间隔过短           | 需间隔 ≥60秒 | 验证码发送过于频繁，请60秒后再尝试       |
| 24小时内发送次数过多   | 最多发送5次  | 今日验证码发送次数已达上限，请明日再尝试 |

### 验证规则

| 条件                   | 结果                         |
| ---------------------- | ---------------------------- |
| 验证码为空或手机号为空 | 验证失败                     |
| 验证码正确且未过期     | 验证成功，**验证码立即失效** |
| 验证码错误或已过期     | 验证失败                     |

### 重要提示

- **验证码验证成功后立即失效**，不可重复使用
- **验证码有效期5分钟**，超时需重新获取
- **每天最多获取5次验证码**，达到上限后需次日再试
- **60秒内不能重复发送**，需等待冷却时间结束

## 完整流程

```
用户需要登录/认证
    ↓
Step 1: 发送验证码 (sendVerifyCode)
   📍 关键信息采集：获取用户手机号
   ⚠️ 发送前检查：
      - 手机号格式是否有效
      - 距离上次发送是否≥60秒
      - 24小时内已发送次数是否<5次
   ❌ 不满足条件时返回对应错误提示
    ↓
[若发送成功] 提示用户查收验证码
    ↓
用户提供收到的验证码
    ↓
Step 2: 手机号+验证码登录 (loginByCode)
   📍 关键信息采集：
      - 验证码（用户提供，6位数字）
      - site 站点类型（根据业务场景选择，SAAS 推荐 site=2）
   ⚠️ 验证规则：
      - 验证码为空或手机号为空 → 验证失败
      - 验证码错误或已过期 → 验证失败
      - 验证码正确且未过期 → 验证成功，验证码自动失效
    ↓
返回登录结果（用户信息）
    ↓
[可选] 调用 sessionInfo 确认登录状态
    ↓
继续主流程（创建订单等）
```

---

## 错误提示速查

| 场景             | 错误提示                                 |
| ---------------- | ---------------------------------------- |
| 手机号格式错误   | 请输入有效的手机号                       |
| 发送间隔不足60秒 | 验证码发送过于频繁，请60秒后再尝试       |
| 24小时已发5次    | 今日验证码发送次数已达上限，请明日再尝试 |
| 验证码为空       | 请输入验证码                             |
| 验证码错误       | 验证码错误，请重新输入                   |
| 验证码过期       | 验证码已过期，请重新获取                 |
