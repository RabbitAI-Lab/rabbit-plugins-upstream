## sessionInfo - 查询登录状态

**用途**：检查用户当前是否已登录

**调用方式**：

```bash
km-bot call saasktv sessionInfo "{}"
```

**请求参数**：无

**成功返回示例**：

```json
{
  "jsonrpc": "2.0",
  "id": "km_rpc_xxx",
  "result": {
    "status": 1,
    "customer_id": "12345",
    "phone": "13800138000",
    "companycode": "01171",
    "company_id": 1265
  }
}
```

**返回字段说明**：

| 字段        | 类型   | 说明                                                                          |
| ----------- | ------ | ----------------------------------------------------------------------------- |
| status      | Number | 登录状态：**0 未登录**，**1 已登录**                                          |
| customer_id | String | K米 平台用户 ID（**仅用于前端识别当前登录用户，不可作为后续接口的调用参数**） |
| phone       | String | 用户手机号（**仅供前端展示，下单接口由后端自动识别，前端不传入**）            |
| companycode | String | 当前的商家编码（单值）                                                        |
| company_id  | Number | 当前的商家 ID（单值）                                                         |

**业务分支处理**：

| status 值 | 含义   | 后续操作                                                                |
| --------- | ------ | ----------------------------------------------------------------------- |
| 1         | 已登录 | 可以直接创建订单                                                        |
| 0         | 未登录 | **必须先完成登录流程**（调用 sendVerifyCode + loginByCode）后再创建订单 |

**使用时机**：

- 预订流程开始前，检查用户是否已登录
- 创建订单之前，再次检查登录状态
- 支付之前，检查登录状态是否有效

**未登录时返回示例**：

```json
{
  "jsonrpc": "2.0",
  "id": "km_rpc_xxx",
  "result": {
    "status": 0,
    "customer_id": "",
    "phone": "",
    "companycode": "",
    "company_id": 0
  }
}
```

> **⚠️ 说明**：当用户未登录时（`status=0`），`customer_id`、`phone`、`companycode`、`company_id` 均为空值。此时应引导用户先完成登录流程。

## sendVerifyCode - 发送验证码

**用途**：向用户手机号发送验证码

**调用方式**：

```bash
km-bot call saasktv sendVerifyCode "{\"phone\":\"13800138000\"}"
```

**请求参数**：

| 字段  | 类型   | 必填 | 说明                               |
| ----- | ------ | ---- | ---------------------------------- |
| phone | String | 是   | 手机号（11位，格式 `1[3-9]\d{9}`） |

**⚠️ 发送前校验（必须按顺序检查）**：

| 检查顺序 | 条件           | 限制要求           | 错误提示                                      |
| -------- | -------------- | ------------------ | --------------------------------------------- |
| 1        | 手机号有效性   | 检查格式是否正确   | ❌ "请输入有效的手机号"                       |
| 2        | 发送间隔       | 距离上次发送≥60秒  | ❌ "验证码发送过于频繁，请60秒后再尝试"       |
| 3        | 24小时发送次数 | 当日已发送次数<5次 | ❌ "今日验证码发送次数已达上限，请明日再尝试" |

**发送成功后**：

- 提示用户："验证码已发送，请查收。有效期5分钟。"
- 记录本次发送时间戳和当日发送次数

**验证码属性**：

| 属性               | 值                               |
| ------------------ | -------------------------------- |
| 长度               | 6位数字                          |
| 有效期             | 5分钟                            |
| 24小时最大发送次数 | 5次                              |
| 发送间隔           | ≥60秒                            |
| 使用次数           | **一次性**（验证成功后立即失效） |

## loginByCode - 手机号验证码登录

**用途**：使用手机号和验证码完成登录

**调用方式**：

```bash
km-bot call saasktv loginByCode "{\"phone\":\"13800138000\",\"verify_code\":\"123456\"}"
```

**请求参数**：

| 字段        | 类型   | 必填 | 说明                                                 |
| ----------- | ------ | ---- | ---------------------------------------------------- |
| phone       | String | 是   | 手机号（与 sendVerifyCode 一致）                     |
| verify_code | String | 是   | 验证码（6位数字）                                    |
| site        | Number | 否   | 站点类型：1:系统后台 2:SAAS后台（推荐） 3:自助小程序 |

**⚠️ 验证规则**：

| 条件                   | 结果                         | 错误提示                   |
| ---------------------- | ---------------------------- | -------------------------- |
| 验证码为空或手机号为空 | 验证失败                     | 请输入完整的手机号和验证码 |
| 验证码错误             | 验证失败                     | 验证码错误，请重新输入     |
| 验证码已过期           | 验证失败                     | 验证码已过期，请重新获取   |
| 验证码正确且未过期     | **验证成功，验证码立即失效** | -                          |

> **⚠️ 重要**：验证码验证成功后立即失效，不可重复使用。即使验证码泄露，也无法再次使用。

**site 参数说明**：

| site 值 | 说明       | 适用场景                     |
| ------- | ---------- | ---------------------------- |
| 1       | 系统后台   | 内部管理系统                 |
| 2       | SAAS后台   | 商家SAAS管理后台（**推荐**） |
| 3       | 自助小程序 | 用户自助服务小程序           |

**登录成功返回**：

```json
{
  "jsonrpc": "2.0",
  "id": "km_rpc_xxx",
  "result": {
    "ret": 0,
    "msg": "登录成功",
    "data": {
      "customer_id": "12345",
      "phone": "13800138000"
    }
  }
}
```

**登录失败返回**：

```json
{
  "jsonrpc": "2.0",
  "id": "km_rpc_xxx",
  "result": {
    "ret": -1,
    "msg": "验证码错误"
  }
}
```
