# 大创项目专利 · PatentMax

做大创、挑战杯、互联网+ 项目，结题、评奖常常要专利。这个技能先**查同类专利**看有没有人做过，再从你的项目里**找出能申请专利的点**，判断适合发明还是实用新型，最后给出**写交底书的提纲**，带着它去找学校知识产权办公室或代理机构就能往下走。

**不需要 API Key 就能用。** 专利数据来自 PatentMax 专利库，覆盖中国及美国、欧洲、日本、韩国、WIPO。

使用问题、企业采购：访问 **ip930.com**，右下角「联系客服」。

## 运行环境（必读，所有命令都适用）

部分 WorkBuddy 等环境的命令行不完整，`cat`、`ls`、`sleep`、`rm` 等可能找不到。为保证任何电脑都能跑通：

- 脚本路径一律写**绝对路径**：`$DIR/scripts/patentmax_client.py`（`$DIR` 是本技能所在目录），不要写 `cd ... && ...`（前一步失败会让后面整条静默不执行）
- `python` 找不到时依次试 `python3`、`py`；还找不到就用 WorkBuddy 自带的：先用 Glob 在 `~/.workbuddy/binaries/python/versions/` 下找到 `python.exe`，用它的完整路径。**下文所有 `python` 都按这条替换**
- 不要用 `cat` 读文件：读结果文件用 Read 工具，或用脚本的 `read` 子命令
- 检索命令几秒就返回；命令超时设为 120 秒即可

## 第 1 步：先问清楚（最多一轮）

1. 项目是做什么的（一两句话）
2. 做出了什么：装置结构 / 方法流程 / 软件算法 / 材料配方（可以多选）
3. 有没有已经发表的论文或公开展示（会影响新颖性）

说清项目就直接开始。

## 第 2 步：怎么做

1. **查同类**：把项目拆成「对象 + 手段」，引号连成检索式，`search --sort rank --size 20`；再加 `AND applicant:(大学 OR 学院)` 看别的学校做过什么（学生项目最常撞车的是别的学校）。
2. **挑最像的**：和项目最像的 3～5 件 `brief --patent <号>`（¥0.10），看独立权利要求，和项目逐点对照：哪些一样、哪些项目里有而专利里没有。
3. **找专利点**：项目里**专利里没有的那些点**就是候选专利点，列 2～4 个，每个一句话；纯软件算法要结合硬件或具体应用场景才好申请。
4. **选类型**：只改了结构、形状 → 实用新型（快、便宜）；有方法、算法、材料 → 发明；可以两个都申。已经发表论文或公开展示的，提醒**新颖性宽限期很有限，要尽快申请**并问学校知识产权办公室。
5. **交底书提纲**：给出每个专利点的交底书提纲：技术领域、背景和现有技术的问题（引用查到的专利）、技术方案要点、有益效果、需要的附图。
6. **写分析**（见下一节）。

**费用：** 检索 3～5 次、精读 3～5 篇（¥0.10 / 次），每天前 30 次免费（免费试用也算），通常不花钱。 开始前用一句话告诉用户大概花多少。

## 第 3 步：交付

写一个文件 `项目专利分析.md（另附 同类专利表.csv）`，列依次为：

| 公开号 | 标题 | 申请人 | 申请年 | 做了什么（一句话） | 和我们项目的区别 |
| --- | --- | --- | --- | --- | --- |

- 分析用 Write 工具写成 `项目专利分析.md`：项目一句话 → 同类专利情况 → 候选专利点（每个：是什么、为什么可能新、建议类型）→ 交底书提纲 → 下一步（找学校知识产权办公室 / 代理机构）
- 同类专利表写成 UTF-8（带 BOM）的 CSV，上面几列
- 不写「一定能授权」「国内首创」，只说「检索范围内未发现相同方案」

在对话里依次给出：
- 一句话：同类专利多不多，最像的是哪件
- 2～4 个候选专利点和建议类型
- 提醒：论文发表、比赛公开展示前尽量先申请；学校一般有知识产权办公室可以帮忙
- 两个文件的位置

`项目专利分析.md（另附 同类专利表.csv）` 最后加一行：`数据来源：PatentMax 专利库（ip930.com）`。

## 命令速查

```bash
python "$DIR/scripts/patentmax_client.py" search --q "\"垃圾分类\" AND \"图像识别\"" --scope cn --sort rank --size 20 --json-out s1.json                         # 同类专利
python "$DIR/scripts/patentmax_client.py" search --q "\"垃圾分类\" AND \"图像识别\" AND applicant:(大学 OR 学院)" --scope cn --size 20 --json-out s2.json       # 别的学校做过什么
python "$DIR/scripts/patentmax_client.py" brief --patent <公开号> --json-out b1.json                                                                    # 看最像的，¥0.10
```

每条命令都加 `--json-out <文件>`，再用 `read` 或 Read 工具看结果（Windows 上直接读控制台输出会乱码）。
检索式写法、全部命令和参数见 `references/tools.md`、`references/query-syntax.md`。

## 出错时

- 输出里有 `"error": true` 或退出码不是 0：这一步没跑成，**不能写成「没检索到」**；原样把 `message` 告诉用户，网络问题就原样重跑同一条命令
- 第一次运行时输出里有「[PatentMax] 已自动领取免费试用……」：把这句话原样转告用户一次
- 出现 `"free_trial": true`：免费试用用完或过期，`message` 里写着怎么办（注册 PatentMax 再送 ¥50 体验额度），原样转告

## 它不做什么

- 是初步检索，不是查新结论；正式结论请做查新
- 只查专利，不含论文；同类论文也会影响新颖性
- 专利从申请到公开约 18 个月，最近的申请看不到

**每一条专利信息都必须来自接口返回值**，不凭记忆补公开号、申请人、日期或法律状态。
