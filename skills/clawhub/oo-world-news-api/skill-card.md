## Description:

World News API (worldnewsapi.com). Use this skill for ANY World News API request — searching and reading data. Whenever a task involves World News API, use this skill instead of calling the API directly.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agents use this skill to search, retrieve, and inspect news articles, top news, locations, and news sources through the connected World News API service.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup uses remote installers and automatic agent-skill synchronization that were not available for verification, so installation could introduce unreviewed skill changes.

Mitigation: Use an independently verified CLI release, approve installation separately, and review or disable automatic agent-skill synchronization.

Risk: News requests pass through OOMOL and may consume service credit.

Mitigation: Review expected usage and available service credit before making requests.
