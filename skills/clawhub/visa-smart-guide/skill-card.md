## Description:

Visa Smart Guide helps Chinese citizens check outbound visa requirements, generate application material checklists, and review recent policy updates for 80+ destinations.

This skill is ready for commercial/non-commercial use.

## Publisher:

MIT-0

## Use Case:

External travelers and travel-support agents use this skill to answer visa requirement questions, assemble destination-specific application checklists, and summarize recent visa policy changes before a trip.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Visa policies can change quickly and the skill is not an official immigration source.

Mitigation: Verify requirements with the relevant embassy or consulate before relying on the guidance.

Risk: Policy-update lookups may send the destination query to Google.

Mitigation: Use only the destination needed for the lookup and avoid adding sensitive personal details to policy-update queries.
