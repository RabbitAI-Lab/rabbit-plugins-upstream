This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to select CI Tools components, create or repair GitLab CI configurations, and validate delivery pipelines.

### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: CI changes or GitLab CLI actions could trigger pipelines or deployment and registry writes.

Mitigation: Review configuration changes, pushes, merge-request pipeline runs, and deployment or registry write paths before approval.
