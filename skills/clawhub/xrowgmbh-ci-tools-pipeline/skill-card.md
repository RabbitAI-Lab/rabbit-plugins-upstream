## Use Case:

Developers and engineers use this skill to design, create, or fix GitLab CI/CD pipelines. It helps them select CI Tools catalog components and validate pipeline inputs and delivery workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Pipeline configuration may be sent to the GitLab instance configured for linting, and the security review is incomplete.

Mitigation: Confirm that the configured GitLab destination is trusted before using the skill with private configuration.
