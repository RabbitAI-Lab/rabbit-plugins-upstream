# 感知体系（Perception System）

> **作者：张培霖（Zeppelin）** · CC-BY-NC-4.0 授权
> 一套源自金融科技实战、普适于所有软件产品的体验设计方法论

## 一句话

**感知体系回答的问题是：「用户在什么心理状态下，我该怎么设计？」**

它通过 **四层感知强度 × 四维度矩阵 + MustBe/NotToBe 双列约束 + 文案/动作/组件三级落地**，把"感知"从不可言说的直觉，变成可查询、可执行、可校验的数据结构。

## 核心结构

```
商业目标（安全/信任/风控/服务）
    ↕
感知体系：感知类型 × 感知强度 × 三大支柱（视觉感知/格式塔/认知心理）
    ↕
用户目标（感知→影响→激励→抉择）
```

## 感知强度矩阵

**横轴：** 轻度感知（感知）→ 中度感知（影响）→ 深度感知（激发）→ 强烈感知（抉择）

**纵轴：** 运营 / 视觉 / 产品 / 体验 四维度 × MustBe（必须做）/ NotToBe（禁止做）

**落地：** 每格落到 文案 / 动作 / 组件 三级可执行项

## 为什么它对 AI 友好

感知强度矩阵本质上是一个 **4×4×3 的状态空间**——AI 不需要"理解"温度与信任，只需要定位当前场景的强度档位、查表取用对应策略。它是少数天生为"AI 可执行"而生的设计方法论。
