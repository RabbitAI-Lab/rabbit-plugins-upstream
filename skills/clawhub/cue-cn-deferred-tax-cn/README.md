# 递延所得税·逐条挂源

给一份财报，把附注里的**递延所得税**读成一张**每个数都能回到原句**的登记表：递延所得税资产与负债的明细（按项目列期初、本期增减、期末）、未经抵销的资产与负债以及互抵金额与抵销后净额、未确认递延所得税资产的可抵扣亏损与到期年份、所得税费用与会计利润的调节表、适用税率与多主体合并口径。

递延所得税是附注里**最像一张表、其实藏着三处陷阱**的一块：期初加本期增减未必等于期末（差额进了其他综合收益或权益）、未经抵销的资产与负债不是能相减的两个数（互抵是披露给的列报选择，减出来的不是抵销额）、法定税率 25% 是常识而披露可能压根没写。本件把披露怎么写逐条登记下来，结论留给人。

**不判递延所得税资产能否转回、不评估未来盈利能否覆盖可抵扣亏损、不评价税务风险、不给税负优化建议、不预测税率变动方向、不判 EPS 影响、不给评级与目标价。** 互抵四数各占一行、绝不自行轧差；税率只认披露写法、不落 25% 默认值；要自己算的比例必须单列并交代分子分母各自的来源。

## 一、三十秒跑通（零输入）

不给任何数据文件，也能跑出一份完整合规的成品，看它长什么样、判据怎么打：

```bash
python3 scripts/check_deferred_tax.py --demo
```

把这份样例存下来再跑一遍机检，它能自己过：

```bash
python3 scripts/check_deferred_tax.py --demo > 样例递延稿.md
python3 scripts/check_deferred_tax.py 样例递延稿.md
# → 样例递延稿.md 结论：五道全过（零发条）
```

接着换成你自己那份稿子：

```bash
python3 scripts/check_deferred_tax.py 你的递延稿.md
```

退码 `0` 全过、`1` 有发条、`2` 用法错、`3` 读不到文件或空稿。

### 拿不到成品时，从原文开始的三步

1. **定主体与报告期**，拿到年报附注「递延所得税」「所得税费用」那两节，加相关公告。
2. **每节抄事实，连原句一起抄**：一条 = 一行，行末挂 `「原句」〔锚：页/表〕[S#]`。
3. **跑一遍自检**，红一条改一条：

```bash
python3 scripts/check_deferred_tax.py --selftest
```

### 先确认通道在场（可选）

配了 `CUE_API_KEY` 才需要这一步。先列目录，再按目录里的路由地址确认工具在场：

```bash
CATALOG="https://cuecue.cn/api/mcp-catalog"
curl -s "$CATALOG" | head -c 2000
# 从目录里取本组的路由地址，确认工具在场
curl -s -X POST "$ROUTING_URL" \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

没配凭据也能用：把附注与公告放进工作区，走用户直供那条路，代价是未确认亏损到期表与调节表明细只能在手头文件里翻。

## 二、五道机检在管什么

| 码 | 名称 | 判什么 | 最常拦住的情况 |
|---|---|---|---|
| `DT-STRUCT` | 形制 | 头部四件自标、`主体：`、`报告期：` 在场；七节齐且有序；前五节各至少一条发现行；第二节互抵四数各占一行 | 七节缺一节；某节只有小标题；多出一节同名标题；第二节少了「互抵金额」那一行 |
| `DT-QUOTE` | 原句与锚 | 每条发现行以「」原句＋〔锚：…〕＋`[S#]` 收尾；来源行带可点 URL 与检索日；引用的编号须已登记 | 只写金额没抄原句；来源行只有标题没有链接 |
| `DT-NOSELF` | 不得自推自算 | 互抵与抵销、未确认递延所得税资产只认原句；互抵四数各自的项名须在它自己的原句里找到对应写法；比例原句没写必须标 `〔自算〕` 并写明分子分母；税率只认披露写法 | 拿「未经抵销」两句顶「互抵金额」或「抵销后净额」；写「按 25% 计算」而原句没有 25% |
| `DT-GAP` | 未取到两向点名 | 正文写了未取到而第六节没列要发，反之也发；零缺口须显式写「未取到：无」 | 用「不适用」「无此项」「无需披露」搪塞 |
| `DT-LINE` | 红线 | 能否转回、税务风险、税负优化、税率变动方向、EPS 影响、评级目标价零命中；引文先洗掉再判；把「抵销后净额」写成等于「未经抵销」照发 | 「递延所得税资产未来能够转回，税务风险可控」 |

## 三、四条红线（这件的立身之本）

1. **互抵绝不自行轧差。** `未经抵销的递延所得税资产`、`未经抵销的递延所得税负债`、`互抵金额`、`抵销后净额` 是**四个独立的数，各占一行**。抵销规则与抵销金额照抄披露，**「资产减负债」不是抵销额**；少披露哪一个，就点哪一个的 `未取到`，不许省掉那一行。
2. **税率不许落默认值。** 法定税率 25% 是常识，不是披露。披露没写就写 `未取到`，不许写「按 25% 计算」——**即便标了〔自算〕也照样发**，因为税率只认披露写法，自算不是它的来源。
3. **未确认只认原句。** 行内写「未确认递延所得税资产」「未予确认」，该表述必须出现在同一行的原句里；没披露到期分布就写 `未取到`，不按常见年度补。
4. **比例自算要交代两头的来源。** 未确认亏损占比一类要自己算的，必须标 `〔自算〕`，并在同一行写明分子、分母各挂各的来源——缺一即发。

## 四、一条发现长什么样

```markdown
- 互抵金额：200.00 万元「上述递延所得税资产与负债以 2,000,000.00 元为限相互抵销」〔锚：2025 年年报·第 141 页·附注三·递延所得税〕[S1]
```

没取到的，自成一行、照实写（**不是省掉这一行**）：

```markdown
- 职工薪酬：未取到：附注未单列职工薪酬形成的递延所得税
```

要自己算的，长这样（分子分母各自挂源）：

```markdown
- 未确认亏损占比：40.00%〔自算〕分子＝未确认的可抵扣亏损 8,000,000.00 元 [S1]｜分母＝可抵扣亏损总额 20,000,000.00 元 [S1]
```

## 五、和另外几枚包怎么分

| 你手上是 | 用哪枚 |
|---|---|
| 递延所得税资产／负债这张表怎么列、怎么动、互抵多少、未确认的亏损多少 | **本件** |
| 所得税费用总额与会计利润调节的点评 | `cn-earnings-note` |
| 税收优惠政策本身能不能用、适用条件是什么 | `tax-policy-card-cn` |
| 会计政策与会计估计变更、前期差错更正 | `cn-accounting-error-correction-cn` |

所得税费用是这两枚的接缝：**总额与会计利润调节的点评归 `cn-earnings-note`，而调节表逐行照抄与挂源、以及递延所得税那一侧的项目明细与互抵，归本件**——本件只登记披露写的那几行，不点评差异。

## 六、素材从哪来

- **用户直供**：手头的年报 PDF、公告，走解析通道读成能检索的正文。
- **通道取证**：配了 `CUE_API_KEY` 后可走公告检索与原文解析。装好 skill ≠ 已配凭据 ≠ 通道已连，三层分开看。
- **递延材料常散在多张表里**（递延所得税明细表、未确认亏损到期表、所得税费用调节表），长附件与扫描件交给解析腿：先取大纲，再按节取用。计费与可用性以服务端返回为准。

本件不发请求、不代付费，消耗以服务端返回为准。

## 七、跑夹具与测试

```bash
bash scripts/fixtures/run_fixtures.sh
python3 tests/test_deferred_tax.py
```

三档：机检自测 / 好样坏样逐枚单跑 / 在好样上逐处替换做正反对照（该红的红、该不红的不红）。零网络、零计费，产物只落临时目录，跑完即删。

末行自报「档数=…｜不合=N｜不可判=N」（档数由 runner 自己现算，不写死）；退码 `0` 全过、`1` 有不合、`3` 取值域故障。

`tests/` 跑的是外壳属性——`--help` 退 0、无参退 2、缺文件或空稿退 3、`--demo` 产物自过机检且与好样夹具同源、埋点落盘且失败静默；另有三支直接构造的稿子专测本件新增的两条判据（互抵不轧差、税率不落默认值），不经夹具，防夹具一起漂。

## 八、首次运行埋点

入口脚本解析参数成功后、干正事之前，会往 `~/.cue-usage/<slug>-<日期>` 落一枚**空文件**。

**为什么要它：** 平台的两个下载计数器都不可信——新 listing 上架首 48 小时会被一次性播种 50~60 的初始计数，那不是用户下载。本地这枚文件是本件唯一能证明「真有人装上并跑过」的证据。

**它不会碍事：** 任何失败（家目录只读、配额满、无 HOME）都静默跳过，不报错、不改退码、不吐一句杂音。同一天跑多次只留一枚。

要清掉：`rm -rf ~/.cue-usage`。
