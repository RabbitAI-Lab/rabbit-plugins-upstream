## Known Risks and Mitigations:

Risk: The release is flagged for repeatedly running an unpinned, automatically accepted latest CLI version, creating supply-chain risk when credentials are available.

Mitigation: Use a reviewed, pinned CLI version and check for changes before running it with credentials.

Risk: Search terms may be sent to SocialDataX without a privacy warning.

Mitigation: Avoid sensitive search terms and tell users that their query is sent to SocialDataX.
