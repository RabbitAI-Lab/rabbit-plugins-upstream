## Description:

自动生成适用于电商推广及广告投放的图文营销素材：广告图片、促销图，以及从视频反推的图文种草内容。当用户要求做图文素材、广告图、种草图文、推广图文、笔记素材时必须触发。关键词：青虎AI、qhkit、图文素材、广告图、种草图文、图文笔记、推广图、信息流图片、小红书素材、图文创作。

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: The installation and update instructions can make software changes without enough user control.

Mitigation: Install a reviewed package version in an isolated, non-administrator environment, and require confirmation before updates.

Risk: Selected media is sent to an external service, and generation can spend account credits.

Mitigation: Submit only media approved for external processing and check the estimated credit cost before generating.

Risk: The downloaded CLI's behavior is outside the artifact review.

Mitigation: Review the package version and never blindly run commands suggested by error messages.
