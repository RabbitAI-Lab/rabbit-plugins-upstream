## Description:

Comprehensively scope, enumerate, test, validate, and report security findings with specialized roles for bug bounty assessments.

This skill is ready for commercial/non-commercial use.

## Publisher:

[t3ratech](https://clawhub.ai/user/t3ratech)

### License/Terms of Use:

MIT-0

## Use Case:

Security researchers and developers use this skill to coordinate authorized bug bounty work: confirming scope, enumerating attack surface, testing hypotheses, validating findings, and writing triage-ready reports.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill supports bug bounty activity that could affect third-party systems if used outside an approved scope.

Mitigation: Use it only for authorized security testing and confirm scope before enumeration, testing, validation, or reporting.

Risk: The workflow may involve shell commands, file writes, memory use, private repositories, credentials, or third-party systems.

Mitigation: Review commands, file writes, and memory use during operation, and avoid exposing credentials or private data unnecessarily.
