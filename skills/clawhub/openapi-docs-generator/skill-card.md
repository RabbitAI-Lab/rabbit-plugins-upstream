## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn API documentation requests into practical OpenAPI or Swagger workflows, checklists, analysis, code changes, and verification notes. It is intended for REST API documentation generation, improvement, and validation tasks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad API-documentation language because implicit invocation is enabled and examples are imprecise.

Mitigation: Review activation settings and trigger wording if tighter routing is required.

Risk: Generated OpenAPI or Swagger guidance can be incomplete or misleading if source routes, schemas, authentication rules, or examples are missing.

Mitigation: Validate generated documentation against implementation details, existing API tests, and OpenAPI tooling before publishing.
