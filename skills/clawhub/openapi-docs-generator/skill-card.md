## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to turn REST API documentation needs into practical OpenAPI or Swagger workflows, checklists, artifacts, code changes, and validation steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may cause the skill to respond to requests that are only loosely related to API documentation.

Mitigation: Review generated responses against the user's actual API documentation task before applying recommendations or code changes.

Risk: Generated OpenAPI or Swagger guidance can be incomplete or misleading if the source API behavior is underspecified.

Mitigation: Validate generated specifications against implementation behavior, existing route definitions, and OpenAPI tooling before publishing.
