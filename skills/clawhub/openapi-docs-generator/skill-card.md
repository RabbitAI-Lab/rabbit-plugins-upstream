## Description: <br>
Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

## Use Case: <br>
Developers and engineers use this skill to turn OpenAPI or Swagger documentation requests into practical workflows, checklists, implementation guidance, and validation notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger terms may activate the skill for ordinary API-related requests. <br>
Mitigation: Invoke it explicitly for OpenAPI or Swagger documentation tasks and review generated guidance before applying it. <br>
