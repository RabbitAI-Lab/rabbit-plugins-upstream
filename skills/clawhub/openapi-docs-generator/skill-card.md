## Description: <br>
Helps developers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs through a repeatable workflow, checklist, and verification step. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>

## Use Case: <br>
Developers and engineering teams use this skill to turn REST API documentation requests into concrete OpenAPI or Swagger documentation artifacts, review checklists, validation commands, implementation guidance, and decision support. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may be invoked too broadly for general API or developer-experience requests. <br>
Mitigation: Use it explicitly for OpenAPI or Swagger documentation tasks and confirm the requested output before applying its workflow. <br>
Risk: Generated API documentation guidance may be incomplete or inconsistent with the actual service behavior. <br>
Mitigation: Validate generated OpenAPI or Swagger artifacts against the service implementation, schema tooling, and any available tests before publishing. <br>
