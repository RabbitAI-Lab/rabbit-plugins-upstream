## Description:

Helps backend and platform teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to turn REST API context into OpenAPI or Swagger documentation, validation workflows, checklists, implementation guidance, and review notes. It is aimed at API developers, backend teams, developer-experience teams, and maintainers who need services to be understandable to other engineers.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad implicit invocation may select the skill during general API or documentation conversations where OpenAPI or Swagger help was not intended.

Mitigation: Use explicit invocation for OpenAPI or Swagger tasks, or narrow or disable implicit triggers in environments where accidental selection matters.
