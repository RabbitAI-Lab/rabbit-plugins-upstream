## Description:

Helps API developers and backend teams plan, generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

API developers, backend teams, developer-experience teams, and maintainers use this skill to make REST APIs easier for other engineers to understand. It helps turn a request and available project context into practical OpenAPI documentation, workflows, checklists, or implementation guidance, with validation steps where relevant.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad keywords may activate the skill for unrelated requests.

Mitigation: Use explicit OpenAPI documentation requests or disable implicit invocation if broad activation is unwanted.

Risk: Generated API documentation may contain inaccuracies.

Mitigation: Review generated documentation before sharing it.
