## Description:

Helps API developers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, backend teams, developer-experience teams, and API maintainers use this skill to turn REST API context into practical OpenAPI or Swagger documentation workflows, checklists, implementation support, and validation guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill uses broad API-related auto-activation language and may trigger on general API prompts.

Mitigation: Use explicit invocation for OpenAPI or Swagger documentation tasks and review routing settings if accidental activation would disrupt the agent workflow.

Risk: Generated API documentation guidance can be incomplete or misaligned with the actual service behavior.

Mitigation: Validate generated OpenAPI or Swagger changes against the source implementation, representative requests and responses, and an OpenAPI linter before publication.
