## Description:

Helps API developers and backend teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to create practical workflows, checklists, analyses, code changes, and verification notes for REST API documentation work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate for broad API or developer-experience requests when a narrower OpenAPI or Swagger documentation skill was intended.

Mitigation: Confirm the user's request involves OpenAPI, Swagger, REST API documentation, or a closely related documentation workflow before relying on the skill.

Risk: Documentation outputs can be incomplete or misleading when route definitions, schemas, authentication behavior, or examples are missing.

Mitigation: Validate generated documentation against the service implementation and the user's stated success criteria before use.
