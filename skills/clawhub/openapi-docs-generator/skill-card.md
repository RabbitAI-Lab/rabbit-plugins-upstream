## Description:

Helps backend, platform, and developer-experience teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

Developers and engineers use this skill to turn API documentation needs into practical workflows, checklists, analysis, code changes, or documentation artifacts for OpenAPI and Swagger REST API projects.
