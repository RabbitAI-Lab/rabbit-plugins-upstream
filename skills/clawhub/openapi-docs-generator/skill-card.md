## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn API documentation requests into practical OpenAPI or Swagger workflows, artifacts, checklists, analyses, code changes, and verification notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Implicit invocation is enabled with broad OpenAPI, Swagger, REST API, and documentation triggers, so the skill may run on adjacent API-related prompts.

Mitigation: Use explicit invocation or narrow activation terms when a deployment needs tighter routing.

Risk: The skill can propose documentation, code, shell commands, or configuration changes that may not match a service's actual behavior.

Mitigation: Review generated artifacts against the API implementation and run the verification commands or checks before publishing.
