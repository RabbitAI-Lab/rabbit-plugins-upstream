## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to turn API documentation needs into concrete OpenAPI or Swagger artifacts, checklists, implementation guidance, and validation steps. It is aimed at REST API documentation workflows where clarity, drift reduction, and repeatable review criteria matter.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad auto-activation wording may route some general API or developer-experience requests to this skill.

Mitigation: Prefer explicit invocation when routing precision matters.

Risk: Generated OpenAPI or Swagger guidance can be incorrect when API behavior, schemas, or examples are incomplete.

Mitigation: Review outputs against source code, existing API contracts, and validation tools before publishing.
