## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn REST API documentation needs into practical OpenAPI or Swagger workflows, checklists, code-oriented guidance, and validation steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad OpenAPI, Swagger, REST API, or developer-experience wording.

Mitigation: Prefer explicit invocation when API documentation support is intended.

Risk: Generated OpenAPI or Swagger specifications may not match the service implementation.

Mitigation: Review generated specs against source code, tests, and live API behavior before relying on them.
