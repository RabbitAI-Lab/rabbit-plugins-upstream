## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to turn API documentation requests into practical OpenAPI or Swagger deliverables, workflows, checklists, analysis, code changes, and validation notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad OpenAPI, Swagger, REST API, or developer-experience prompts.

Mitigation: Review trigger wording before deployment and narrow invocation rules when a workspace contains many overlapping skills.
