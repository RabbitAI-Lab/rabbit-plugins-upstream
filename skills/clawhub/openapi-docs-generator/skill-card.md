## Description: <br>
Helps backend and platform teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to turn API context, source details, or documentation gaps into practical OpenAPI or Swagger documentation artifacts, validation checklists, implementation steps, and review notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger phrases could activate the skill for loosely related software-and-data requests. <br>
Mitigation: Tighten invocation guidance so the skill activates only for explicit OpenAPI, Swagger, REST API documentation generation, validation, or documentation-improvement requests. <br>
Risk: Generated API documentation can be incomplete or misleading if the user provides stale routes, schemas, examples, or constraints. <br>
Mitigation: Validate outputs against the user's source code, live API behavior, or existing OpenAPI validation tooling before publishing documentation. <br>
