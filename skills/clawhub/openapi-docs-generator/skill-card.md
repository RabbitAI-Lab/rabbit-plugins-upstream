## Description:

Helps API developers create, improve, and review OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

API developers, backend and platform teams, developer-experience teams, and service maintainers use this skill for practical guidance on creating, improving, and reviewing REST API documentation. It provides a general workflow rather than a bundled OpenAPI generator or validator.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad keywords may activate the skill for unrelated requests.

Mitigation: Use it for explicit OpenAPI or Swagger documentation tasks.

Risk: Generated documentation or code may be incorrect or misleading.

Mitigation: Review generated documentation and code against the API behavior and project requirements.
