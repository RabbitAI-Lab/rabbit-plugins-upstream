## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn REST API documentation needs into practical workflows, checklists, implementation guidance, and validation steps for OpenAPI or Swagger deliverables.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad API or developer-experience wording.

Mitigation: Invoke it explicitly for OpenAPI, Swagger, REST API documentation generation, validation, or review tasks.

Risk: Generated API documentation guidance may be incomplete or inaccurate for a specific service implementation.

Mitigation: Review generated artifacts against the live API behavior, source routes, schemas, authentication requirements, and validation results before deployment.
