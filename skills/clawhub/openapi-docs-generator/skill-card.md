## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineering teams use this skill to create practical workflows, checklists, documentation artifacts, analysis, code changes, and verification notes for OpenAPI or Swagger REST API documentation work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Implicit invocation is enabled with broad trigger wording, which could activate the skill for requests outside OpenAPI, Swagger, REST API documentation, or related validation work.

Mitigation: Tighten the trigger wording before relying on automatic skill selection, or invoke the skill explicitly for OpenAPI documentation tasks.

Risk: Generated documentation, code, commands, or configuration may be incomplete or inaccurate for a specific API implementation.

Mitigation: Review outputs against the service source, run suggested validation commands when code or data is involved, and keep assumptions and remaining risks visible.
