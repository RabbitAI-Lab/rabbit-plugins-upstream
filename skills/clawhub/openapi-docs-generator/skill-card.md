## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to turn REST API documentation requests into practical workflows, checklists, analysis, code changes, or validation steps for OpenAPI and Swagger specs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate for broad OpenAPI, Swagger, REST API, or developer-experience phrasing.

Mitigation: Invoke it explicitly when API documentation help is intended, and confirm that generated guidance matches the user's API stack and documentation goals.

Risk: Generated API documentation or validation advice could be incomplete or mismatched to the service contract.

Mitigation: Review generated artifacts against the source API implementation and run OpenAPI or Swagger validation before publishing.
