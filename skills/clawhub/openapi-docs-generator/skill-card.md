## Description: <br>
Helps API developers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineering teams use this skill to turn API documentation requests into actionable OpenAPI or Swagger workflows, checklists, code or configuration guidance, and validation steps. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate from broad API or software-documentation requests. <br>
Mitigation: Confirm that the user's task is about OpenAPI, Swagger, REST API documentation, or closely related developer-experience documentation before applying its guidance. <br>
Risk: Generated code, configuration, or documentation changes could be incorrect for the user's API framework or service constraints. <br>
Mitigation: Review outputs before applying changes and run the suggested validation commands against the target API specification or codebase. <br>
