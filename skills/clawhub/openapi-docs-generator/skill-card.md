## Description: <br>
Helps API developers, backend teams, and platform teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to turn API documentation needs into practical workflows, checklists, code or configuration changes, and validation steps for OpenAPI or Swagger documentation. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger wording may route general API or developer-experience requests to this skill. <br>
Mitigation: Narrow the trigger keywords or confirm the user needs OpenAPI, Swagger, or REST API documentation support before applying the workflow. <br>
Risk: Generated API documentation guidance can become inaccurate if it is not checked against the current service implementation. <br>
Mitigation: Validate produced OpenAPI or Swagger artifacts against routes, schemas, examples, and CI contract checks before publishing. <br>
