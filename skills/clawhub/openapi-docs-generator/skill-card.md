## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to turn API documentation requests into practical workflows, checklists, analysis, code changes, or decision support for OpenAPI and Swagger REST API documentation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The activation wording is broad and may trigger for loosely related API or developer-experience requests.

Mitigation: Constrain invocation to explicit OpenAPI, Swagger, REST API documentation, or closely related API documentation tasks.
