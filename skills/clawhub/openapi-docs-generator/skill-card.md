## Description:

Helps API and developer-experience teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to create practical OpenAPI/Swagger documentation workflows, checklists, code or configuration guidance, and validation steps for REST APIs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may cause the skill to run for general API or workflow prompts.

Mitigation: Prefer explicit invocation when this skill is intended.

Risk: Generated documentation, code, shell commands, or configuration guidance may be inaccurate for the user's API implementation.

Mitigation: Review outputs against the API source, run validation tools, and test suggested changes before applying them.
