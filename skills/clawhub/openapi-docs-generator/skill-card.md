## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn API context into practical OpenAPI or Swagger documentation artifacts, checklists, implementation guidance, and validation steps. It is intended for REST API documentation work by backend, platform, and developer-experience teams.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may be invoked on broader API or developer-experience prompts because its trigger terms and implicit invocation are somewhat loose.

Mitigation: Confirm the user's request is specifically about OpenAPI, Swagger, REST API documentation, or an adjacent documentation workflow before applying the skill.
