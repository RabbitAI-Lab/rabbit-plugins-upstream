## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn REST API documentation tasks into practical workflows, checklists, implementation steps, and validation notes for OpenAPI or Swagger artifacts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate too broadly because its triggers include generic keywords and truncated examples.

Mitigation: Prefer explicit invocation or narrow the trigger language before deployment so users retain clear control over when the skill runs.

Risk: Incorrect or incomplete OpenAPI guidance could produce misleading API documentation.

Mitigation: Validate generated specifications with OpenAPI tooling and review the result against the service's actual routes, schemas, authentication, and error behavior.
