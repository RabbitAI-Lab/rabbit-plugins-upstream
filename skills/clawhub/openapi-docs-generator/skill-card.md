## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn REST API documentation needs into practical OpenAPI or Swagger artifacts, workflows, checklists, analysis, code changes, or validation guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate for broader REST API or developer-experience prompts than intended.

Mitigation: Use it for explicit OpenAPI, Swagger, REST API documentation generation, validation, or improvement requests.

Risk: Generated API documentation, checklists, code, or configuration can be incorrect or misleading if inputs are incomplete.

Mitigation: Review generated artifacts against the actual service behavior, schemas, authentication model, and validation results before publishing or using them.
