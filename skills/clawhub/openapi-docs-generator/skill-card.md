## Known Risks and Mitigations:

Risk: Broad activation keywords may invoke the skill for unrelated tasks.

Mitigation: Use it when the request concerns OpenAPI or Swagger documentation for REST APIs, and review its proposed steps before applying them.

Risk: Generated API documentation or implementation guidance may not match the service's actual behavior.

Mitigation: Check proposed schemas and examples against the service implementation and validate the resulting specification before publishing it.
