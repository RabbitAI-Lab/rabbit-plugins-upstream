## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn REST API implementation details, schemas, and documentation goals into actionable OpenAPI or Swagger artifacts, workflows, checklists, code changes, and validation steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad API or developer-experience wording may activate the skill for adjacent tasks that are not specifically OpenAPI or Swagger documentation work.

Mitigation: Invoke or install it for explicit OpenAPI, Swagger, REST API documentation, specification validation, or schema-generation requests.

Risk: Generated API documentation guidance or snippets can be incomplete or mismatched to the target service.

Mitigation: Validate generated artifacts against the service implementation, OpenAPI tooling, and the stated success criteria before use.
