## Description:

Helps API developers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, backend teams, developer-experience teams, and API maintainers use this skill to turn REST API context into OpenAPI or Swagger documentation workflows, checklists, code-oriented guidance, and validation notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger wording may select this skill for API or REST documentation requests that are outside OpenAPI or Swagger documentation work.

Mitigation: Confirm the user is asking for OpenAPI, Swagger, REST API documentation, or closely related validation before applying the skill's workflow.

Risk: Documentation, checklist, code, or command suggestions may be incomplete or mismatched to the user's API framework or tooling.

Mitigation: Validate generated guidance against the user's framework, OpenAPI version, existing API behavior, and any test or lint commands available in the project.
