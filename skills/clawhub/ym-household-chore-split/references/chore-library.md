# 家务全清单库 + 冲突处理规则模板

本文件供技能按需加载：列家务时先过一遍本清单（尤其隐形家务），出规则时套用冲突处理模板。耗时均为常识估算，标注「估算」，实际以家庭为准。

## 二、冲突处理规则模板

直接套用，按需改具体值。

### 1. 临时有事怎么换班
- 需提前 [至少半天/一天] 在群里说，自己先找替班人，找不到再请其他成员协调。
- 替班视为「借」，下次原班人还回等额工时，或记在表上月底清算。

### 2. 没做怎么办（不指责，给补救）
- 漏做项在 [24 小时内] 补做，或下一次轮值时多承担一项。
- 连续两次漏做 → 触发复盘，不上升到人格评价，只谈「任务是否过重/标准是否清楚/时间是否够」。

### 3. 标准不一致怎么办（写进表）
- 把模糊项改成可执行标准，例如：
  - 「打扫浴室」→「洗完澡顺手清地漏头发 + 台盆擦干」
  - 「洗碗」→「锅碗无油渍、灶台擦净、垃圾不过夜」
  - 「拖地」→「可见毛发与污渍清除，不要求打蜡」
- 标准写定后所有人按同一把尺，争议回到标准而非「你没认真」。

### 4. 定期复盘
- 每 [1 个月] 复盘一次：谁超时、谁总补位、是否有新家务冒出。
- 复盘只看数据与新增项，调整轮值表，不翻旧账、不评勤懒。

### 5. 儿童参与（如有）
- 只给安全小任务：摆碗、浇花、收自己玩具、给宠物添粮（视年龄）。
- 不安排：高空擦拭、强清洁剂、燃气相关、重物搬运。
