# 家务分工安排 (ym-household-chore-split)

按每个成员的时间和能力排出轮值表，把隐形家务也算进去，算出每人每周总耗时看差距，并给一套冲突处理规则。最后给一版能直接贴冰箱的纯表格。

## 何时使用

- 用户说「家务怎么分」「排个值日表」「谁做什么」「轮值安排」时
- 用户抱怨「总是一个人干」「分工不公平」时
- 用户说「合租怎么排班」「和室友怎么分活」时

## 运行前提

- 依赖：无第三方依赖，纯文本处理
- 不联网、不上传，不主动发送提醒
- 不读取任何本地文件，除非用户明确给出路径

## 输入契约

| 项 | 必需 | 说明 |
|---|---|---|
| 成员数与可投入时间 | 必需 | 如「我每天 1 小时，他只有周末」；缺则按平均分配并注明 |
| 各自擅长/讨厌的家务 | 可选 | 用于平衡分工 |
| 住房情况 | 可选 | 面积、是否有宠物/小孩；缺按两居室一卫一厨 |
| 现有矛盾点 | 可选 | 用于针对性给规则 |

**缺失处理：**

- 缺时间信息 → 按平均分配，注明「第一轮默认均分，执行后据实调整」
- 缺住房情况 → 按两居室一卫一厨排，注明假设
- 成员含儿童/老人 → 不安排危险或过重任务，明确说明
- 用户说「谁付出更多」要评判 → 只给工时数据，不做懒/勤价值判断

## 执行步骤

1. **列家务全清单** — 按 `references/chore-library.md` 的清单库，分 每日/每周/每月/季节性 四组，必须含「隐形家务」（记着买什么、安排维修、倒垃圾、换床品、清理滤网、缴账单、回群里消息等）。缺的项让用户确认是否适用。

2. **标属性** — 每项标：频率 / 单次大致耗时 / 体力要求 / 是否可弹性（能否晚一天）。耗时取常识估算并标注「估算」。

3. **分配** — 按 可投入时间 × 擅长与厌恶 × 公平轮换 三者平衡。写清分配依据（为什么这项给谁），不只给结果。厌恶项尽量避让，擅长项优先；可轮换项用轮值避免长期偏担。

4. **出轮值表** — 每日表（谁做什么）+ 每周表（周几轮到谁）+ 每月与季节性任务认领。固定类（如某人负责的专属区域）单列。

5. **算工时** — 把每人每周总耗时算出来对比（如 A 4.5h / B 4h）。差距超 30% 必须调整或说明原因（如某人承担不可轮换的固定任务、或时间确实更少）。

6. **给冲突处理规则** — 套 `references/chore-library.md` 的冲突规则模板：临时换班 / 没做怎么补 / 标准不一致写进表 / 定期复盘。

7. **出可直接贴版** — 去掉说明文字，只留表格与规则，方便贴冰箱或发群。

8. **硬约束自检** — 不评判谁懒谁勤快（只列工时）；儿童不安排危险任务（高空、强清洁剂、燃气）；不做家庭关系调解，只给规则。

## 输出格式

Markdown：

```
一、家务全清单（含隐形家务，标频率/耗时/体力/弹性）
二、分配依据（每项为什么给谁）
三、轮值表（每日 / 每周 / 每月与季节性）
四、工时分担估算（每人每周 h，差距与调整）
五、冲突处理规则
六、可直接贴出版本（纯表格与规则）
```

## 能力边界

- 不解决家庭矛盾（只给规则建议，不做关系调解）
- 不自动提醒（本环境外不发消息，除非用户主动询问）
- 不保证各方一定满意，只做公平度估算与说明
- 不安排涉及危险的儿童任务；工时为准，不评勤懒

## 常见坑

1. **漏掉隐形家务** — 现象：只列扫地洗碗，没算「记着买菜」「约维修」「回物业群」。原因：隐形家务不显眼。规避：出清单时强制过一遍 `references/chore-library.md` 的隐形项。
2. **只给结果不写依据** — 现象：直接说「碗你洗、地他拖」。原因：省事。规避：每项必须附一句分配依据，否则容易被质疑不公。
3. **工时差距看不见** — 现象：分完没算总时长，实际一人干两倍。原因：没做汇总。规避：必出每人每周 h 对比，超 30% 调整或说明。
4. **标准模糊引争议** — 现象：写「打扫浴室」，执行时一人觉得擦台面就行、一人觉得要刷地砖。原因：标准没写清。规避：把标准写进表（如「洗完澡顺手清地漏头发」而非「打扫浴室」）。
5. **评判勤懒** — 现象：说「你就是懒才不肯干」。原因：把安排当批评。规避：只输出工时数据与规则，不做人格判断。
6. **给小孩危险活** — 现象：让小孩倒强清洁剂、擦高处窗户。原因：没单独处理儿童。规避：成员含儿童时，危险/过重任务一律不分配，给适合的小任务（如摆碗、浇花）。

## 验收用例

- 正常：3 人合租、时间不同 → 轮值表 + 工时估算 + 冲突规则齐全
- 边界 1：一人只有周末有空 → 其任务集中在周末，并写明依据
- 边界 2：有小孩 → 不安排危险任务，给适合孩子的小任务
- 失败：要求评判「谁付出更多」 → 只给工时数据，不做价值判断

## 目录说明

- `references/` — 家务全清单库（含隐形家务）、冲突处理规则模板（按需加载）
- `templates/` — 轮值表与可直接贴版模板
