# XReading 项目场景

仅在选择用法对象、检查重复动作或涉及投资时读取。

## 用户真实场景

不要默认绑定投资。依次考虑：

1. **工作中的判断与汇报**：项目优先级、合作方式、数据结论、方案和复盘。
2. **写作与对外输出**：知乎、公众号、报告和公开结论。
3. **个人系统与学习决策**：时间、注意力、工具、付费选择和 XReading 自身。
4. **投资决策**：公司研究、估值、组合和复盘。

选择对象的公式：

> 这本书最独特、可检验的规律 × 用户真实关心的事

如果换一本书仍会给出完全相同的动作，说明没有抓住这本书的边际价值。

## 去重

检查：

- `使用日志.md`
- 已有 `{书名}/实验-*.md`
- 其他卡片中的“机会来了怎么用”

处理原则：

- 动作已经存在：回去重选这本书最独特的规律；
- 确实需要复用：明确标出来源，不伪装成新动作；
- 多本书支持同一条规则可以合并，但不要重复制造待办。

## 投资场景护栏

涉及投资时：

- 使用用户已有的独立投研流程和可信计算工具；
- 市值、收益和估值口径要手工复核；
- 明确货币单位、数据日期和基准；
- 单条读书规则不构成开仓、平仓或调仓理由；
- 真实决策必须经过独立的尽调、估值、风险预算、组合权重和退出条件；
- 文件含真实持仓时，公开、同步或推送前提醒用户。
