# 质量规则

## 内容配比

目标：

| 部分 | 目标 | 自动检查容差 |
|---|---:|---:|
| 书的内容与论证 | 60% | 不低于 50% |
| 怎么用 | 30% | 不低于 20% |
| 质疑与红旗 | 10% | 不高于 20% |

容差用于避免为了精确数字扭曲章节归类，不代表 50/20/20 是写作目标。

## 可信度

| 标记 | 含义 |
|---|---|
| ★★★★★ | 大样本、多方独立验证，没有关键反证 |
| ★★★★☆ | 有扎实实地数据支持，机制仍有争论 |
| ★★★☆☆ | 效应存在，但情境依赖较强 |
| ★★☆☆☆ | 证据混合、机制不明或只在特定场景成立 |
| ★☆☆☆☆ | 已被推翻、方向相反或作者本人否认 |

星级是筛选工具，不是卡片的主角。不要为了证明一个星级写长篇研究综述。

## 数字与证据表达

- 用量级和自然语言表达，不在卡片写 p 值、置信区间、效应量或 R-Index。
- 数字本身是决策锚点时可以保留，例如长期收益差、失败率或数量级。
- 研究名称、样本和方法细节放入 `查证-{主题}.md`。
- 区分“书里说的”和“当前判断”；不确定就明确说不确定。

## 反模式

| 症状 | 修正 |
|---|---|
| 先做大量查证，最后才发现书不值得读 | 先完成 Gate 0 |
| 质疑比内容长 | 把举证移到查证文件 |
| “怎么用”只是“注意 X” | 改成触发信号、动作和退出条件 |
| 规则没有“不适用” | 补出口，防止变成教条 |
| 给多个实验或设置期限 | 只保留一个可选入口，不设期限 |
| 总绑定同一只持仓 | 改看工作、写作、学习和其他真实场景 |
| 心法被写进工具栏 | 移到“心法” |
| 没有红旗却硬找问题 | 一句话说明未发现，把篇幅还给内容 |
| 卡片偏长 | 先删摘抄、举证、重复解释，保留论证链 |
| 自动把规则提升为“在用” | 只写入候选区，等待用户筛选 |
