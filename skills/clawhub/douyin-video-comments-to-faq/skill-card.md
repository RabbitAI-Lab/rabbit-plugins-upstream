## Description:

Turn Douyin video comments into one comment FAQ still per picked question. This Douyin comment reply studio writes a listing FAQ card from each seller-answered comment, then lays out a 4 to 8 still comment FAQ set. Use it for listing FAQ graphics and a Douyin comment FAQ card that stay one question, one still.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Sellers use this skill to turn selected public Douyin comment questions and confirmed listing facts into a set of FAQ stills. If comment lookup is unavailable, they can provide copied questions instead.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill requires permissions beyond FAQ image creation, and removal may accidentally disconnect other Beatra skills.

Mitigation: Prefer a version with workflow-limited permissions and corrected uninstall inventory validation. If proceeding, review the broader authorization, paid-operation, upload, and installation-reporting behavior, and revoke the shared connection through Beatra Console when needed.
