## Description:

Creates short, unnarrated motion graphics, including kinetic typography, data visuals, maps, overlays, and animated web or social content.

This skill is ready for commercial/non-commercial use.

Mitigation: Review and pin the HyperFrames CLI and package source before allowing updates or initialization; use an isolated workspace.

Mitigation: Review assets before enabling remote providers, and expose only the API keys needed for the chosen workflow.
