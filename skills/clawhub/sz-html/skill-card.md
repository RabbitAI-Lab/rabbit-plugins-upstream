## Description:

Creates browser-ready HTML presentations through a confirmed outline, style selection, page-by-page generation, and a final quality review.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External users and developers can use the skill to create browser-ready presentations for reports, proposals, product launches, and training. It gathers requirements, confirms the outline and visual style, then produces and reviews a single-file HTML presentation.
