# 行业研究：数据要素（七道工序：外部洞察）

## 何时使用
- "做一份数据要素行业研究""行业格局怎么样""有哪些政策东风""传统集团在数据要素里的机会"。
- 立项后进入外部洞察阶段（orchestrator 第 1 步的 ①）。
- 汇报需要"行业趋势"章节时。

## 目标
形成**结构化行业认知**，产出可进汇报材料的研究报，并**落回集团定位机会**。

> 一句话原则：**研究的终点不是"这个行业怎么样"，而是"所以我们能做什么"。**
> 宏观综述没有交付价值；能进汇报、能支撑决策的才叫研究。

---

## 核心方法论：政策 → 市场 → 玩家 三层

数据要素是**政策先行**行业，研究顺序固定，不可颠倒：

```
① 政策层  → 决定"能不能做"（合规边界）       必须先看
② 市场层  → 决定"值不值得做"（空间与成熟度）
③ 玩家层  → 决定"凭什么是我们"（竞争位）
```

**为什么政策必须放第一位**：数据要素的商业模式几乎全部由政策定义边界。脱离政策谈市场，结论会失真——**这是这个行业与一般行业研究的最大区别**。

### ① 政策层（必查四件套）
| 政策 | 关键内容 | 对集团的意义 |
|---|---|---|
| **数据二十条** | 三权分置（资源持有权/加工使用权/产品经营权） | 决定集团能否经营数据 |
| **数据资产入表暂行规定** | 财政部口径，确认条件与计量路径 | 决定能否"变成资产" |
| **公共数据授权运营** | 各地授权机制 | 决定能否拿到公共数据 |
| **地方数据条例** | 属地规则 | 决定本地合规要求 |

**产出**：政策东风速查表（政策 × 条款 × 机遇 × 约束）

### ② 市场层（三个必查问题）
1. **数据交易所现状**：本地/全国所有哪些所？挂牌什么类型产品？**有哪些同类主体已挂牌**？
2. **数商生态**：谁在卖数据、谁在买数据、中间谁在服务？
3. **赛道数据流通成熟度**：本集团所在赛道（农业/农批/线下平台/专业市场）的数据流通到什么程度了？
   - 成熟度高 → 竞争激烈，要找差异化
   - 成熟度低 → **先发机会，但要自建市场教育成本**

**规模数字必须标口径与来源年份，跨来源不可直接相加**（不同机构的"数据要素市场规模"统计口径差异巨大）。

### ③ 玩家层（谁在成为核心数据源）
- 同类集团的数据要素打法是什么？进度到哪？
- 有没有"行业核心数据源"已经出现？它是怎么做到的？
- 上游（货源/生产端）和下游（采购/消费端）谁掌握了数据入口？

**产出**：玩家格局图 + 可借鉴打法清单

## 执行步骤（五步）

### Step 1｜立项信息对齐（半天）
读 orchestrator 的立项信息（主体画像/规模档/驱动因素/决策人关注点）。
**研究要服务于驱动因素**：为入表而做研究 → 重点查政策与会计口径；为业务痛点而做 → 重点查同类解法。

### Step 2｜政策层研究（1 天）
1. 调 `policy-collector` 拉取最新政策，产出"政策东风速查表"。
2. 关注**时效性**：数据要素政策迭代快，必须用当年最新版本。
3. 标注**已废止/被替代**的政策，避免引用过期条款。

**产出**：`政策机会清单.md`

### Step 3｜市场层研究（1–2 天）
1. 调 `industry-scout` 做赛道格局（四维：同业竞争/跨业竞争/数据互补/工具互补）。
2. 查数据交易所挂牌情况（**重点看同类主体**）。
3. 每个规模数字标注：来源机构 / 年份 / 口径 / 是否含预测。

### Step 4｜玩家层研究（1–2 天）
1. 找 3–5 个可对标玩家（同类集团 + 跨业平台 + 数据服务商）。
2. 分析其数据源→数据产品→变现路径。
3. 详细对标移交 `dx-competitor-scout`（本技能只做格局判断，不展开个体拆解）。

### Step 5｜落回集团定位机会（1 天，★最关键的一步）

**专设一节回答：本集团能否/如何成为行业核心数据源？**

结构：
```
① 我们有什么别人没有的？（数据源独特性）
② 政策给了什么窗口？（时机）
③ 谁在争同一个位置？（竞争位）
④ 建议的切入路径（1–2 条，不超过 3 条）
```

**产出**：`行业研究报_<集团>_<日期>.md`

- [ ] `行业研究报_<集团>_<日期>.md`（含定义/产业链/政策/市场/玩家/趋势/**集团定位机会**）
- [ ] `政策机会清单.md`（政策 × 条款 × 机遇 × 约束 × 时效）
- [ ] `图表要点.md`（可直接贴汇报的 5–8 张图/表，供 dx-application-plan 引用）

**门禁**：行业研究报 + 政策机会清单为必需。
**实质性检查**：研究报必须含"集团定位机会"章节，且给出明确建议（不停留在宏观综述）。

## Gotchas

- **离开"数据二十条 / 入表 / 公共数据授权运营"谈数据要素市场会失真**——这是政策驱动型行业，政策顺序必须放第一。
- 研究必须落回**集团定位机会**，不要停在宏观综述；用户主线是"如何成为行业核心数据源"。
- 市场规模数字必须标注口径与来源年份，**跨来源不可直接相加**。
- **不要引用过期政策**：数据要素政策迭代快，引用作废条款是硬伤。
- **不要只查全国政策**：属地数据条例直接影响合规底线，必须查地方版。
- **不要罗列"玩家做了什么"**：要回答"这对我们意味着什么"。
- **"市场空间很大"是无用结论**：必须具体到"我们能在哪个细分拿到多少"。
- **研究周期不要超过 5 天**：数据要素研究容易陷入无穷尽的资料搜集，5 天内出结论。
- **来源必须可追溯**：每条关键数据带链接/出处，领导可能追问。
- **不要替用户下"必须做"的结论**：给机会与约束，决策权交回。
