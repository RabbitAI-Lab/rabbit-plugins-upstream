# 数据要素政策索引（速查）

> 数据要素是政策先行行业，行业研究/竞品调研/应用规划必须引用。采集用 policy-collector，本索引为人工维护锚点。

## 顶层框架
- **数据二十条（2022-12）**：数据产权"三权分置"（持有权/使用权/经营权），公共数据授权运营基础。
- **财政部《企业数据资源相关会计处理暂行规定》（2024-01 施行）**：数据资源可按规定确认为无形资产/存货，入表口径依据。

## 流通与交易
- 数据交易所（上海/深圳/北京/贵州等）准入与产品登记规则。
- 数据商、第三方专业服务机构定位。

## 公共数据
- 公共数据授权运营试点政策（各省市条例）。
- 政务数据与社会数据融合应用指引。

## 安全合规
- 《数据安全法》《个人信息保护法》《网络安全法》三法。
- 数据分类分级、重要数据目录、跨境流动规则。

## 行业（农业/农批/线下平台）
- 农业全产业链数字化政策、农产品大数据试点。
- 线下平台型集团的数据要素化路径（见 offline-platform-data-element 技能）。

> 使用：行业研究技能输出"政策机会清单"时，按"政策名 + 发布时间 + 对集团的含义 + 行动建议"四列。口径与年份必须标注。
