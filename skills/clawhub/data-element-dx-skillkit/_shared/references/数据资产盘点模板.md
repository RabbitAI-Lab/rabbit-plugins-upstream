# 数据资产盘点模板

> 用于 dx-data-baseline 的"数据资产清单"产出。四级：业务域 → 系统 → 库表 → 字段。

## 字段说明
| 列 | 必填 | 说明 |
|---|---|---|
| 业务域 | 是 | 集团业务板块（如：交易/物流/会员/财务/...） |
| 子业务 | 否 | 二级业务线 |
| 系统 | 是 | 业务系统名（采购/自研/老 ERP） |
| 数据库/库 | 是 | DB 类型 + 库名 |
| 表 | 是 | 表名（含 schema） |
| 字段 | 是 | 字段名 |
| 字段业务含义 | 是 | 业务语义（**最重要**，决定后续口径） |
| 口径公式 | 否 | 价/量/均价的计算口径 |
| 主数据标识 | 否 | 是否主数据字段（客户/供应商/商品/...） |
| 数据源（权威源） | 是 | 哪个系统/接口是权威源 |
| 敏感级别 | 是 | 公开/内部/敏感/重要数据 |
| 更新频率 | 是 | 实时/分钟/小时/日/... |
| 负责人 | 是 | 业务+技术 |
| 质量问题 | 否 | 已知问题（缺失/不一致/口径错） |
| 当前是否有使用 | 是 | 在用/沉睡/未用 |

## 使用步骤
1. 调 `_shared/assets/调研问卷模板.md` 设计访谈（系统管理员 + 业务负责人）。
2. 按"业务域 → 系统"分组填表；**先盘系统后填字段**。
3. 主数据字段标黄/加粗，单独导出主数据清单。
4. 完成后用 `maturity_score.py` 跑成熟度分。

## 关键规则
- 业务含义不明的字段不收——治理价值低。
- 同一字段在不同系统口径不同时，**强制选定一个权威源**，其余写"参考源"。
- 离线 Excel/文件也作为"系统"纳入盘点。
