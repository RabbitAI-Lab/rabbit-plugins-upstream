# 数据质量规则库

> 用于 dx-data-quality 的"质量规则集"产出。规则必须可机检（SQL/DQC），并绑定业务语义。

## 五性规则模板
每条规则字段：编号 / 字段 / 维度 / 检查逻辑 / 阈值 / 责任人 / 业务语义。

### 完整性
- 主键非空率 = NOT NULL 数 / 总数 ≥ 99.9%
- 关键业务字段（金额/日期/客户ID）非空率 ≥ 99%

### 准确性
- 抽样比对源单据，错误率 ≤ 0.1%
- 关键字段（如手机号/身份证）正则校验通过率 ≥ 99%

### 一致性
- 跨系统同一字段一致性（如会员ID、单价）≥ 99%
- 关联完整性：外键引用存在率 = 100%
- **业务规则一致性**：均价取自价格明细表（**不是**含数量列的宽表）、订单金额 = 单价 × 数量

### 及时性
- 关键表更新延迟 ≤ 业务约定（如 T+1 ≤ 24h）
- 实时场景延迟 ≤ SLA

### 唯一性
- 主键唯一率 = 100%
- 业务唯一键（如订单号、身份证）重复率 = 0

## 通用 SQL 模板（可机检）
```sql
-- 完整性
SELECT COUNT(*) AS null_cnt FROM tbl WHERE key_field IS NULL;
-- 一致性（均价口径：宽表 JOIN 会导致重复行放大，必须先取明细）
SELECT AVG(wide_table.avg_price) AS possibly_inflated
FROM wide_table WHERE dt BETWEEN ...;
-- 唯一性
SELECT key_field, COUNT(*) FROM tbl GROUP BY key_field HAVING COUNT(*) > 1;
-- 及时性
SELECT MAX(update_time) AS last_update, NOW() - MAX(update_time) AS lag FROM tbl;
```

## 业务语义规则（必须绑定）
- 均价 = 价格明细表口径（**禁**在含数量列的宽表上直接 AVG，这是日粒度表 JOIN 导致的 fanout 放大陷阱）
- 销量 = 业务约定口径（出货 vs 订单）
- 主数据标识唯一：客户=customer_id / uid / accountId 三套映射到统一 ID

## 优先级
1. 高频被用的核心表（如交易/价格）。
2. 对外报送/合规字段。
3. 沉睡表/离线文件可后置。
