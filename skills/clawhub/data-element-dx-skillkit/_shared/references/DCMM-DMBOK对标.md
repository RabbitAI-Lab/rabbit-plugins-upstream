# DCMM / DMBOK 对标速查

> 用于数据现状摸底成熟度初评与架构/质量规划的对标锚点。

## DCMM 八域（GB/T 36073 数据管理能力成熟度）
| 域 | 关注点 | 摸底时怎么评 |
|---|---|---|
| 数据战略 | 规划/定位 | 有无数据战略文件、是否对齐业务战略 |
| 数据治理 | 组织/制度/权责 | 有无数据委员会、数据责任人（DC） |
| 数据架构 | 模型/分布/集成 | 是否有数据蓝图、主数据规划 |
| 数据应用 | 共享/服务/分析 | 自助分析、数据产品成熟度 |
| 数据安全 | 分类分级/权限 | 分类分级、脱敏、审计覆盖 |
| 数据质量 | 规则/监控 | 是否有 DQC、质量看板 |
| 数据标准 | 命名/口径/格式 | 是否有企业级标准 |
| 数据生命周期 | 产生→消亡 | 采集/存储/归档/销毁流程 |

## 成熟度等级
1. 初始级 → 2. 受管理级 → 3. 稳健级 → 4. 量化级 → 5. 优化级

## DMBOK 两大支柱
- **数据治理**（DG）：组织、角色、政策、合规。
- **数据管理**（DM）：架构、建模、存储、集成、安全、质量、元数据、主数据、数据仓库/BI。

## 与七道工序的桥接
DCMM 八域可映射到七道工序：战略/治理→管；架构/生命周期→存；标准/质量→治；应用→服+用；安全→贯穿。摸底评分脚本 `../scripts/maturity_score.py` 按此映射出 8 域分。
