# 七道工序方法论（汇存治管服用模）

> 本套件统一语言。所有交付物必须挂回这七道工序，对外口径四处一致。

## 释义
| 工序 | 含义 | 典型动作 | 对应 DCMM 域 |
|---|---|---|---|
| **汇** | 采集汇聚 | 多源采集、接口/文件/物联网接入 | 数据架构、数据生命周期 |
| **存** | 存储计算 | 湖仓、ODS→DW、计算引擎 | 数据架构 |
| **治** | 治理清洗 | 标准、质量、主数据、清洗 | 数据标准、数据质量 |
| **管** | 资产管理运营 | 数据目录、血缘、权限、资产运营 | 数据治理、数据安全 |
| **服** | 服务共享 | 数据服务、API、自助分析 | 数据服务（应用） |
| **用** | 应用变现 | 报表、数据产品、对外变现 | 数据应用 |
| **模** | 模型算法智能 | 预测、推荐、指数、AI 应用 | 数据应用 |

## 使用原则
1. **顺序不可逆**：地基（汇存治管）未补，不上价值层（服用模）。
2. **对外口径一致**：同一数字在 10 页合并稿 ↔ 全景图 ↔ 分册 ↔ 技术详解 必须一致。
3. **每道工序有产出**：汇→资产清单，存→底座蓝图，治→标准+规则，管→目录+权限，服→服务目录，用→场景地图，模→模型清单。

## 与集团交付的对应
- 数据现状摸底 = 汇 + 存
- 数据架构优化 = 存 + 治 + 管
- 数据质量提升 = 治
- 数据应用规划及呈现 = 服 + 用 + 模
- 行业研究 / 竞品调研 = 外部洞察（"用"之前的决策输入）
