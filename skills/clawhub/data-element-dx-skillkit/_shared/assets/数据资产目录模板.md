# 数据资产目录模板（Markdown 表头）

> 用于 dx-data-baseline 输出"数据资产清单_集团_日期.xlsx"前的字段约定。导出 xlsx 时按本表头。

| # | 字段 | 说明 |
|---|---|---|
| 1 | 业务域 | 集团业务板块 |
| 2 | 子业务 | 二级业务线 |
| 3 | 系统 | 业务系统名 |
| 4 | DB类型 | MySQL/Oracle/PG/Doris/DuckDB/... |
| 5 | 数据库 | 实例+库名 |
| 6 | 表 | schema.table |
| 7 | 字段 | 字段名 |
| 8 | 字段业务含义 | 必填，决定后续口径 |
| 9 | 口径公式 | 价/量/均价的计算口径 |
| 10 | 主数据标识 | 客户/供应商/商品/... |
| 11 | 数据源（权威源） | 哪个系统/接口是权威 |
| 12 | 敏感级别 | 公开/内部/敏感/重要 |
| 13 | 更新频率 | 实时/分钟/小时/日/... |
| 14 | 业务负责人 | |
| 15 | 技术负责人 | |
| 16 | 质量问题 | 已知问题 |
| 17 | 在用状态 | 在用/沉睡/未用 |

## 使用建议
- 主数据字段标黄。
- 离线 Excel/文件作为"系统=Excel文件"纳入。
- 导出 xlsx 时冻结表头，开启筛选，按业务域分组。
