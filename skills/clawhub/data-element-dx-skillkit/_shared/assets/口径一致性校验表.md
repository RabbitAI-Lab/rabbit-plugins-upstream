# 口径一致性校验表模板

> 收口阶段必做。咨询交付最经典的翻车：同一数字在不同材料中不一致，领导当场发现，全案可信度崩塌。

## 一、数字台账
从全部交付物中抽取**所有对外量化表述**，逐条核对。

| # | 数字/表述 | 含义 | 出现在哪些文件 | 各文件取值 | 是否一致 | 处理动作 |
|---|---|---|---|---|---|---|
| 1 | 如"接入 12 个系统" | 系统总数 | 汇报稿/全景图/技术详解 | 12 / 12 / 10 | ❌ | 统一为 12，修正技术详解 |
| 2 | | | | | | |

## 二、量级 vs 精确值处理
同一事实若一处写量级、一处写精确值，视为**冲突**，必须统一：

| 冲突示例 | 处理方式 |
|---|---|
| "百级表" vs "180 张表" | 统一为精确值（若已确定），或统一为量级（若尚在变动） |
| "十亿级营收" vs "12.3 亿" | 对外材料统一用**量级**（避免敏感/避免被追问） |

## 三、易冲突高发区（重点核）
- [ ] **系统数量**：摸底清单数 vs 架构图画出数 vs 汇报提到数
- [ ] **库表/字段数量**：正文 vs 附录
- [ ] **成熟度等级**：初评 vs 目标 vs 汇报口播
- [ ] **时间节点**：路线图 vs 汇报承诺
- [ ] **收益数字**：省多少/赚多少（口径必须说明是年化/累计）
- [ ] **入表金额**：若涉及，注意是"潜在规模"还是"已确认价值"
