# 集团数据现状调研问卷模板

> 用于 dx-data-baseline 的访谈。**先盘系统、再盘数据**——本问卷先采集系统清单与负责人，再深入字段。

## A. 业务域与系统清单（先填）
| 业务域 | 子业务 | 系统名 | 系统类型（采购/自研/老 ERP/Excel） | 上线时间 | 负责人（业务/技术） | 主要数据 | 更新频率 |
|---|---|---|---|---|---|---|---|

## B. 数据流
- 跨系统数据流向：系统A → 系统B 的字段、更新机制（接口/ETL/手工）。
- 数据出口（对外报送/对监管/对子公司）。

## C. 主数据
- 客户/供应商/商品/组织/账户 各自的权威源系统与唯一标识。
- 是否存在多套标识（如 user_id / uid / accountId）。

## D. 数据质量
- 已知质量问题（哪个表/字段、口径冲突、缺失严重）。
- 业务侧最痛点的"数据不准"场景（举例说明）。

## E. 数据安全与合规
- 数据分类分级（公开/内部/敏感/重要）。
- 跨境/跨子公司数据流动。

## F. 数据应用现状
- 当前哪些报表/看板/数据产品，谁用、效果。
- 业务侧最想要的"数据能干什么"（场景与期望收益）。

## G. 痛点与机会
- 一句话业务痛点 + 数据能怎么帮。
- 集团在数据要素行业的机会（结合数据二十条/入表/公共数据授权运营）。

## 访谈记录字段（每条建议存原始回答）
- 受访人 / 时间 / 主题 / 关键论点 / 数据证据 / 待确认事项

## Gotchas
- 一次问不完可分轮；先系统清单、下一轮再字段。
- 业务侧的回答需技术侧复核，避免"看起来有"实则空跑。
