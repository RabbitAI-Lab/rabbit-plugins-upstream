# alist Skill for Marvis

alist REST API 全功能客户端，为 Marvis AI 助手提供 alist 文件管理能力。

## 功能

- 文件系统操作（列表/搜索/创建/重命名/移动/复制/删除/上传/下载/目录扫描/离线下载）
- 存储驱动管理
- 用户与元信息管理
- 设置与任务管理
- 索引管理、备份恢复
- SSH/SFTP、审计日志、2FA、SSO

## 安装

将本仓库克隆到 Marvis 技能目录：

```
skills/market/alist/
```

## 配置

编辑 `meta.json` 配置 alist 服务端地址和认证信息。
