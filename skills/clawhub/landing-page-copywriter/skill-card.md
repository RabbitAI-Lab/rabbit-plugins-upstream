## Description:

Writes a landing page outline from a target keyword with the hero, proof, offer, objection and FAQ sections, and the disclosures the page must carry. Use when the user asks for landing page copywriter, landing page outline template, landing page section order. For US DTC brand owners, freelancers and agencies who write conversion pages for clients.

This skill is ready for commercial/non-commercial use.

## Use Case:

External US DTC brand owners, freelancers, and agencies use the skill to draft a landing-page outline from a target keyword, including offer, objections, FAQs, and disclosure placement. The output is a draft and should be reviewed before publication.

## Known Risks and Mitigations:

Risk: The provided brief may not match the script's keyword input, and generated outlines may be incomplete.

Mitigation: Check the input fields against the script's expected input, use a dedicated output folder, and manually review the generated outline.

Risk: Generated output does not establish that claims or disclosures comply with applicable requirements.

Mitigation: Have a qualified reviewer verify claims and disclosure placement before publication.

Risk: The optional Windows app requires a separate security assessment; a matching hash alone does not establish safety.

Mitigation: The Python workflow does not require the optional app; assess it separately before use.
