## Description:

Provides bilingual academic writing tools for style review, mechanical cleanup, revision planning, and checks that key numbers, identifiers, and terminology survive edits.

This skill is ready for commercial/non-commercial use.

## Publisher:

[docsor1212](https://clawhub.ai/user/docsor1212)

### License/Terms of Use:

MIT-0

## Use Case:

Scholars and academic authors use the toolkit to review and revise Chinese or English drafts for clarity and natural style while checking that important manuscript details survive edits. The author remains responsible for factual review and any required AI-use disclosure.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security summary flags possible changes to protected manuscript text and reliability or audit gaps.

Mitigation: Keep the source draft, inspect changes before adopting them, and use the integrity checks to review protected numbers, identifiers, and terminology.

Risk: The security verdict is suspicious and analysis was partial, so the review evidence is incomplete.

Mitigation: Review the skill before installation and weigh the reported risks before using it in automated workflows.
