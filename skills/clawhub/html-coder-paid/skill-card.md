## Known Risks and Mitigations: <br>
Risk: Broad read, write, search, and command authority could affect unintended project files or run commands outside the intended HTML task. <br>
Mitigation: Use the skill only in scoped workspaces for explicit HTML or web-audit work, and review proposed commands and file changes before execution. <br>
Risk: External API or integration workflows could expose credentials or send project data outside the local environment if configured carelessly. <br>
Mitigation: Avoid providing credentials unless required, keep secrets out of prompts and repositories, and use least-privilege tokens for any necessary integrations. <br>
Risk: Generated accessibility, performance, or security recommendations may be incomplete for the target site. <br>
Mitigation: Review generated code manually and validate important changes with established browser, accessibility, and performance tools before release. <br>
