# 网站链接与内容巡检

[English](README.md)

在指定站点内巡检链接，找出坏链、无效页内定位、重复标题和缺失图片说明，输出问题清单。

## 功能

在指定站点内巡检链接，找出坏链、无效页内定位、重复标题和缺失图片说明，输出问题清单。

在当前助手的工作区运行，输出处理结果和报告，原文件保留。

## 用法示例

安装后，把任意一条发给 AI，并附上相关文件或网址。

```text
检查我的网站前30个页面，列出打不开的站内链接和来源页。
```

```text
找出标题重复、没有标题和图片缺少alt的页面，输出整改清单。
```

```text
检查导航中的页内定位是否存在，再抽查10个外部链接。
```
