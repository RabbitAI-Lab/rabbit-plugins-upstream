# 专业课程目标双源整合生成规则（规则D）

> **设计理念**：专业课程的"课程目标"和"主要内容"**不得由 LLM 自行推理撰写**，必须从两份输入材料中按映射关系提取整合，确保每条表述均可追溯到原始依据。
>
> **生效范围**：表5（专业基础课）、表6（专业核心课）、表7（专业拓展/选修课）
> **不适用**：表4公共基础课（遵循规则B，直接复用模板原文）

## D.1 数据源定义

| 数据源 | 文件 | 关键字段 | 提取时机 |
|:-------|:-----|:---------|:---------|
| **源A：教学标准** | 用户上传的专业教学标准（PDF/TXT） | 专业核心课程表的"**典型工作任务描述**"+"**主要教学内容与要求**" | Phase 2 |
| **源B：职业分析报告** | 用户上传的职业分析报告（MD/PDF） | 第六/七章各**学习领域（LD）**的"**学习目标**"+"**学习内容**"+教学方法+评价方式；**学习情境设计**的具体案例 | Phase 3 |

## D.2 课程 ↔ 学习领域映射

对每门专业课程：在源A中查找该课程"主要教学内容与要求"（有则A_matched=True）；在源B中查找覆盖该课程知识范围的LD（有则B_matched=True，记录LD编号、学习目标、学习内容、学习情境）。映射结果记入 map[C]。

## D.3 课程目标三维分类生成规则

根据映射结果，按以下策略生成 **【知识】【能力】【素质】** 三维课程目标。

### 通用要求（适用于所有情况）

- 每个条目必须是**完整的动词+宾语结构**，禁止模糊表述（如"了解相关知识"不合格，必须写"了解汽车电气系统的组成与工作原理"）
- 知识条目需区分层次：**"掌握"**（核心知识，必考）、**"理解"**（关联知识）、**"了解"**（拓展知识），每个条目必须使用其中一个动词开头
- 能力条目必须采用**"能力+行动"结构**，句式为：`具有/具备……能力，能够从事……工作/完成……任务/制作……作品/提供……服务/开发……产品/实施……设计`。前半句声明能力类型，后半句指向可观察的职业行动（如"具有汽车定期维护能力，能够完成40000km以内各级维护作业"而非"能进行维护"或"具有维护能力"）
- 素质条目必须可观测/可评价（如"养成遵守安全作业规范的职业习惯"而非"有安全意识"）
- 专业核心课最低条目数：知识≥3、能力≥3、素质≥2；专业基础课：知识≥2、能力≥2、素质≥2；专业拓展课：知识≥2、能力≥2、素质≥1

### 情况一：A+B 双源匹配（最严谨）

**适用**：教学标准有详表 **且** 职业分析报告有对应学习领域的课程（通常是专业核心课）

| 维度 | 提取来源 | 提取规则 | 改写规范 |
|:-----|:---------|:---------|:---------|
| **【知识】** | 源A"主要教学内容与要求"中以"掌握/了解/理解"开头的条目 + 源B"学习内容"中的概念性条目 | 合并去重后归纳，按"掌握→理解→了解"层次排列。**当同一知识点在两源均有描述时，取信息量更大、更具体的表述**——若标准只写了"掌握XX结构"而报告详细列出子项，则采用报告表述补充细化 | 使用"掌握...原理/结构/分类/规范/标准""理解...工作过程/逻辑关系""了解...发展趋势/新技术"句式 |
| **【能力】** | 源A中以"能完成/能运用/能进行"开头的条目 + 源B"学习目标"中的技能性条目 + 源A"典型工作任务描述"的操作场景 | 合并去重后归纳，按操作复杂度从低到高排列。**当同一能力在两源均有描述时，取信息量更大、更具体的表述**——若标准写"具有汽车维护作业能力"而报告写"能按照保养手册规范完成汽车定期保养操作"，则采用报告表述 | **"能力+行动"结构**：`具有/具备……能力，能够完成……任务/从事……工作/制作……作品/提供……服务/开发……产品/实施……设计`。前半句声明能力类型，后半句指向可观察的职业行动。如"具有汽车定期维护能力，能够完成40000km以内各级维护作业""具备汽车故障诊断能力，能够运用专用设备进行发动机控制系统故障检测与排除" |
| **【素质】** | 源A"典型工作任务描述"中的安全/5S/质量要求 + 源B"评价方式"中的素养项 + 通用职教素养 | 从原文提炼 + 适当补充通用素养 | 使用"培养...意识/精神/习惯/观念/责任感""树立...理念""养成...习惯"句式 |

> **合并原则补充**：双源匹配时，两源对同一知识/能力点的描述粒度经常不同——教学标准偏概括（如"掌握汽车传动系的结构和工作原理"），职业分析报告偏具体（如"能拆卸、装配和检验离合器、变速器、差速器、传动轴等总成"）。此时应**将报告的具体条目纳入，标准概括性表述作为总领或归纳**，形成"总—分"结构。

### 情况二：仅B单源匹配（职业分析报告有对应LD）

| 维度 | 提取来源 | 说明 |
|:-----|:---------|:-----|
| **【知识】** | 源B对应LD的"学习内容" | 直接改写为知识点表述 |
| **【能力】** | 源B对应LD的"学习目标" | 改写为**"能力+行动"结构**：`具有/具备……能力，能够完成……任务/从事……工作/……` |
| **【素质】** | 源B对应LD的"评价方式"中的素养项 + 通用职教素养补充 | 同上 |

### 情况三：仅A有课程名称，无详细教学内容与要求（专业基础课常见）

**适用**：教学标准列出了课程名称和类别归属（如"专业基础课"），但没有"主要教学内容与要求"详表，且职业分析报告中也没有对应学习领域（通常是专业基础课，如"汽车机械常识""汽车电工电子基础"）

| 维度 | 提取来源 | 说明 |
|:-----|:---------|:-----|
| **【知识】** | 教学标准培养规格中与该课程名称直接对应的条目 + 课程名称推断的核心知识领域 | 如"汽车机械常识"→ 培养规格(5)"掌握汽车机械常识..." + 常识推断（力学基础/机械传动/连接件/润滑密封） |
| **【能力】** | 教学标准培养规格中与该课程相关的能力条目 + 课程名称推断的基本操作能力 | 改写为**"能力+行动"结构**。如"汽车机械常识"→ 培养规格(6)改写为"具备常用工具量具选用能力，能够正确选用和使用汽车常用工具与量具完成测量任务" + 推断（具备机械零部件识别能力，能够识别和分类常用机械零部件） |
| **【素质】** | 通用职教素养（安全意识/规范操作/质量意识等） | 同情况二 |

**关键**：必须先在教学标准培养规格中搜索该课程名称关键词，提取相关条目作为依据，而非完全凭空推理。

> 注：本门课程目标依据教学标准培养规格相关条目和课程名称推断编写，建议后续结合校本课程标准修订。

### 情况四：A/B均无匹配（无原始数据）

**适用**：教学标准仅列名称无培养规格相关条目，且职业分析报告也无对应LD（极少见）

→ **允许基于课程名称和职业教育规律进行合理的 LLM 推理生成**，但必须在表格下方标注：

> 注：本门课程目标因原始材料暂无详细教学内容与要求，系根据课程性质和职业教育普遍规律编写，建议后续结合校本课程标准修订。

## 示例：专业核心课课程目标（双源匹配）

### 示例1：《汽车定期维护》

（来源：教学标准"汽车定期维护"课程详表 + LD"汽车维护"学习领域）

```markdown
**【知识】** 掌握汽车的类型、牌号及型号编制规则；掌握汽车各系统与总成的名称、作用、基本结构和连接关系；掌握汽车零部件检查、润滑、紧固、调整和更换的技术规范；理解汽车维护的分级体系与周期标准；了解汽车40000km维护的标准项目及新能源汽车维护的特殊要求。
**【能力】** 具备汽车定期维护能力，能够完成40000km以内的各级维护作业——清洁、检查、润滑、紧固、调整和更换；具备专用诊断设备操作能力，能够运用专用诊断设备读取并清除车辆保养提示信息；具备汽车专项维护能力，能够完成空调制冷剂回收与加注、车轮换位、尾气排放检测等专项维护作业。
**【素质】** 树立5S现场管理意识，养成工位整洁有序的操作习惯；养成遵守安全作业规范的职业习惯；建立按技术标准作业的质量意识和"一次做对"的精准执行理念。
```

### 示例2：《图形图像处理》

（来源：教学标准详表 + LD"数字图像编辑"）

```markdown
**【知识】** 掌握Photoshop/Illustrator的工具面板、图层、通道、蒙版等核心功能操作原理；掌握色彩模式（RGB/CMYK）、分辨率、位图与矢量图的概念与适用场景；理解图像合成、特效制作、版式设计的基本流程与规范；了解UI设计规范与输出标准。
**【能力】** 具备图像编辑处理能力，能够运用Photoshop完成照片精修、图像合成、特效制作等图像编辑任务；具备矢量图形制作能力，能够使用Illustrator完成标志设计、图标绘制、版式排版等矢量图形制作；具备UI视觉设计能力，能够按照UI设计规范完成移动端界面的视觉设计与切图输出。
**【素质】** 培养版权意识与知识产权保护观念；养成色彩敏感度与审美习惯；树立"以用户体验为中心"的设计思维。
```

## D.4 "主要内容"列的生成规则

| 列 | 来源优先级 | 规则 |
|:---|:----------|:-----|
| **主要内容** | **源B（职业分析-LD学习内容 + 学习情境）优先** > 源A补充 > LLM推理 | 若有对应LD，先采用其"学习内容"条目构建框架，再将**该LD下的学习情境**以项目案例形式融入（见下方格式规范）。若无LD，从源A"主要教学内容与要求"提取框架性条目。 |
| **教学要求** | 源B"教学方法" + 源A原版 + 学习情境中的"教学方式" | 采用LD中的教学法建议，并将学习情境中的"教学方式"融合进去。 |

### 学习情境融入"主要内容"的格式规范

1. 学习情境作为"主要内容"列中的**项目模块**列出，格式：`项目X：[情境名称]（[学时]学时）— [核心内容一句话概括]`
2. **选取策略**：每门课程选取2-4个最具代表性的学习情境，非全部罗列。选取标准：①覆盖课程核心技能；②学时较长的情境优先；③能体现典型工作任务的情境优先
3. 对于一对多/多对多映射中被拆分的LD，仅选取归属到本课程的学习情境
4. 情境中的"教学方式"提取后融入"教学要求"列

### 示例（LD001"汽车构造认知与维护保养"→课程《汽车定期维护》的主要内容片段）

```markdown
**主要内容**：
- 汽车总体构造认知（发动机/底盘/车身/电气四大系统组成与连接关系）
- 汽车维护制度与规范（维护分级、周期标准、作业流程）
- 项目1：桑塔纳轿车5000km定期保养（12学时）— 按保养手册完成润滑、检查、紧固作业
- 项目2：汽车40000km维护作业（16学时）— 执行高级别维护全部项目，含制动液/冷却液更换
```

### 示例（一对多映射：LD003"汽车底盘检修"拆分到3门课，其中"汽车传动及控制系统检修"的主要内容片段）

```markdown
**主要内容**：
- 传动系组成与工作原理（离合器/变速器/传动轴/差速器/驱动桥）
- 传动系常见故障诊断与排除方法
- 项目1：离合器拆卸、检查与装配（12学时）— 按技术规范完成离合器总成拆装与检测
- 项目2：手动变速器检修（16学时）— 变速器分解、齿轮/同步器检测与装配调整
```
