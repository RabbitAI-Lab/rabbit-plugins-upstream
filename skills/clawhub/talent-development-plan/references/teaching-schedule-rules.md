# 教学进程学期编排规则

> 本文件为 Phase 4"教学进程安排表"生成的详细规则，在生成教学进程表前**必须加载**。

## 排课原则

1. **基础先行**：专业基础课排在第1-2学期，为核心课打基础；公共基础课贯穿全程
2. **核心递进**：专业核心课从第2学期起逐学期递进安排，先修课在前、后续课在后（如"汽车定期维护"须先于"汽车发动机机械检修"）
3. **实践穿插**：每学期安排与理论课配套的实训项目；集中实践环节（认知实习、岗位实习）排在学期末或独立周
4. **报告学期参考**：职业分析报告各LD标注了"建议学期"，优先采用；若与教学标准冲突，以教学标准课程逻辑为准
5. **学期学时均衡**：每学期理论教学周学时控制在28-32学时范围内（含公共基础课+专业课），避免单学期过重或过轻

## 学期分配模板（三年制中职）

| 学期 | 课程重点 | 典型安排 |
|:-----|:---------|:---------|
| 第1学期 | 公共基础课 + 专业基础课（入门） | 思政/语文/数学/英语/体育 + 汽车文化与概论/汽车机械常识 + 认知实习 |
| 第2学期 | 公共基础课 + 专业基础课 + 首批核心课 | 公共基础课续 + 汽车电工电子基础/汽车发动机与底盘拆装 + 汽车定期维护 |
| 第3学期 | 公共基础课 + 专业核心课 | 公共基础课续 + 发动机/底盘类核心课 + 对应实训 |
| 第4学期 | 公共基础课（收尾）+ 专业核心课 + 专业拓展课 | 公共基础课尾 + 电气/电控类核心课 + 拓展课 + 对应实训 |
| 第5学期 | 专业核心课（收尾）+ 专业拓展课 + 综合实训 | 剩余核心课 + 拓展课 + 综合实训/顶岗前准备 |
| 第6学期 | 岗位实习 | 全学期岗位实习（按每周30学时计） |

## 学时计算方法

1. 理论教学每学期约20周，每周28-30学时 → 每学期约560-600学时
2. 第6学期岗位实习按每周30学时×20周=600学时（但教学标准规定实习时间累计不超过6个月，校外一般不超过3个月）
3. 3年总学时=前5学期理论教学学时+第6学期实习学时+集中实践学时，须达到教学标准要求（中职一般3160学时）
4. 公共基础课占比、选修课占比、实践学时占比均须通过合规校验

## 教学进程安排表生成步骤

### Step 1：确定每学期总学时框架

- 前5学期每学期约520学时（28学时/周×18-20周），第6学期岗位实习约480学时
- 预留集中实践周（每学期1-2周，每周30学时）

### Step 2：分配公共基础课学期

- 思想政治、语文、数学、英语：第1-4学期连续开设
- 历史：第1-2学期
- 信息技术：第1-2学期
- 体育与健康：第1-5学期
- 艺术：第1-2学期
- 劳动教育：第1-4学期分散安排
- 公共选修课：第3-5学期
- 参照 `references/national-standards.md` 和模板表4中的学期分配建议

### Step 3：分配专业课学期

- 专业基础课：第1-2学期全部完成
- 专业核心课：从第2学期开始，按先修关系递进排列
  - 有对应LD的，优先采用LD的"建议学期"
  - 无LD的，按教学标准课程逻辑：入门→基础→核心→综合
- 专业拓展课：第3-5学期，与核心课搭配
- 集中实践：认知实习第1-2学期，课程实训随课程安排，综合实训第4-5学期，岗位实习第6学期

### Step 4：计算每门课周学时

- 周学时 = 课程总学时 ÷ 开设周数
- 一般课程18-20周/学期，周学时取2/3/4/6（取偶数）
- 实训课可集中安排（如2周集中实训=60学时）

### Step 5：校验与调整

- 每学期周学时合计控制在28-32学时
- 总学时须达标（中职≥3000，3160左右为常见）
- 公共基础课占比、选修课占比、实践占比均须合规
- 若某学期过重，将部分课程调整到相邻学期

## 课程学时分配策略

（教学标准通常只给总学时和比例，不给每门课具体学时）

| 课程类型 | 学时来源 | 分配方法 |
|:---------|:---------|:---------|
| **公共基础课** | `references/national-standards.md`中的标准学时 + 模板表4学时 | 优先采用国标建议学时，参照模板表4数值，可根据本校实际微调 |
| **专业基础课** | 教学标准无明确学时 → 根据课程性质和内容量推算 | 按每门课内容量估算：概论/文化类36-48学时，技术基础类64-96学时 |
| **专业核心课** | 教学标准无明确学时 → LD学时（如有）为主要依据 | 有对应LD的课程采用LD学时（可±10%微调）；无LD的课程按内容量估算，参考同类核心课学时 |
| **专业拓展课** | 教学标准无明确学时 → 根据课程内容量推算 | 每门32-64学时，确保选修课总学时占比≥10% |
| **集中实践** | 教学标准有明确周数 → 按每周30学时折算 | 认知实习1周=30学时，岗位实习按教学标准规定（一般6个月，但折算学时需符合国标） |

**校验**：所有课程学时之和 + 集中实践学时 = 教学标准规定的总学时（如中职3160学时）。若不匹配，按比例调整专业课学时，公共基础课学时不动。
