# 四川省职业院校数字媒体技术专业（高职学段）人才培养方案

**【说明】** 中职学段专业名称：数字媒体技术应用专业（710204）；高职学段专业名称：数字媒体技术专业（510204）。本方案按照《职业教育国家教学标准体系》的规定起草，由四川省教育科学研究院提出。起草单位、主要起草人详见原方案（此处略）。

## 1. 专业名称及代码
高职学段：数字媒体技术专业（510204）

## 2. 入学要求
中职（专）毕业生。

### （二）培养规格（高职学段侧重综合应用与创新）
本专业学生应在系统学习本专业知识并完成有关实习实训基础上，全面提升知识、能力、素质，掌握并实际运用岗位（群）需要的专业核心技术技能，实现德智体美劳全面发展。高职学段在职业知识、职业能力方面提出更高要求，具体如下（在原有基础上深化）：

**职业知识要求补充：**
- 熟练掌握图像处理方法，能够进行复杂图片修复和音效制作。
- 掌握剧本和分镜头脚本理论，熟练掌握摄影理论和运镜技巧，掌握场景调度/灯光/特效/音频知识。
- 理解色彩管理/音频编辑高级技巧，掌握视频调色/特效合成技术，了解素材优化方法和整合策略。
- 掌握图形图像软件操作方法，了解设计理论知识，熟悉图像处理（色彩调整/合成/特效）。
- 掌握三维模型制作思路和方法，熟悉三维动画制作流程，了解游戏引擎基础（场景搭建/地形编辑），掌握蓝图编程系统交互功能方法。
- 了解VR技术理论基础，熟悉VR硬件设备原理参数，了解VR开发平台架构功能，具备面向对象程序设计知识，了解VR项目开发流程。

**职业能力要求补充：**
- 能进行复杂图片修复和音效制作，能完成高质量视频后期制作，能应用工具优化工作流程。
- 能综合应用版式/色彩/空间完成设计，能进行高级图像合成与特效制作，能独立完成平面设计项目。
- 能制作角色/道具/场景模型，能拆分UV并制作纹理贴图，能制作虚拟场景和高质量光影，能使用蓝图完成虚拟交互功能。
- 能制作角色和场景动画，能精细调整动画细节，能完成交互功能和界面设计，能对复杂场景高质量渲染，能完成从策划到上线的项目开发。

**职业素质要求补充：**
- 具备强创意创新能力，具备强色彩创新能力，具备强图形创新能力。
- 具备高水平文本创作与表达能力，发展创新性思维和审美判断力，强化沟通协作和应变能力。
- 具备高效工作流程和创新思维，具备高度审美能力和视觉叙事能力。
- 能与客户有效沟通，能协作完成项目，能持续更新技能适应变化，具备职业道德和知识产权意识。
- 培养创新思维和审美能力，具备团队协作与沟通能力，具备持续学习/抗压能力和空间感。
- 具备创新思维与实践能力，具备抗压与问题解决能力，熟悉团队协作的角色分配与沟通技巧。

## 8. 实施保障（高职部分）

### （一）师资队伍
- 专业核心课程的专任教师与学生比例应保持在1:25左右，每门专业核心课程配备2-3名专任教师，实践指导教师与学生比例约为1:20，一线企业兼职教师与学生比例约为1:30。
- 高级职称占比不低于30%，具有硕士学位的教师占比不低于60%，“双师型”教师比例不低于80%。
- 思想政治上保持高度政治敏锐性与责任感，将思政融入专业教学。职业道德高尚，爱岗敬业。专业知识与能力上深入掌握数字媒体核心理论，精通Maya等高端软件工具。具有丰富行业经验与素养，与企业紧密联系。

### （二）教学设施
- 多媒体教室应具备更高性能的设备，如高清投影仪、智能交互大屏等，网络接入速度快且稳定。
- 专业一体化教室应模拟真实工作环境，配备专业级图形工作站、动作捕捉设备、高清摄像机等，满足影视后期制作、动画设计与制作、虚拟现实开发等课程的实践教学。
- 校内实训基地：打造专业级数字媒体创意中心，包括创意设计区、影视制作区、虚拟现实体验区等。建设校企合作实训基地，引入企业真实项目与管理模式。
- 校外实习实训基地：与知名数字媒体企业、影视制作公司、游戏开发公司等深度合作，建立紧密型校外实习实训基地，能提供动画设计师、影视特效师、游戏开发工程师等专业岗位实习机会。

### （三）教学资源
- 教材：以行业认可度高且含前沿知识的高职高专教材为主，核心课程教材优先选配套丰富教学资源的教材。支持教师参与优质教材编写申报，引入国际化教材。
- 图书文献：重点配深度研究著作与技术手册，及行业标准规范图书。增外文原版图书文献，建共享机制扩资源获取。
- 数字资源：建设虚拟仿真实训平台，模拟真实环境流程。建设数字资源库管理，整理各门课程的学习和教学资源。校企合作融合工作场景、工作经验与新技术，开发在线课程，上线国家智慧教育公共平台或其他课程平台。

### （四）教学方法
- 案例教学法：选取数字媒体行业经典案例与实际企业项目，组织学生深入分析，培养学生综合运用专业知识解决复杂问题的能力与批判性思维。
- 产学研结合教学法：加强学校与企业、科研机构的合作，将企业实际项目引入课堂教学或毕业设计环节，学生在教师与企业导师共同指导下参与项目研发。
- 线上线下混合式教学法：利用网络教学平台，整合优质数字资源，学生在线上进行自主学习、预习复习、交流讨论、提交作业等；线下课堂进行重点知识讲解、项目实践指导、成果展示评价等。

### （五）学习评价
- 过程性与终结性评价相结合。既重视过程性评价（参与度、团队协作、问题解决能力），又关注终结性评价（期末考试、毕业设计）。
- 突出能力与素质评价。着重考查学生专业能力、创新能力、职业素养等。通过项目成果、竞赛获奖、实践作品等评价专业能力；以复杂问题解决中展现的创新思维和方法评价创新能力；从职业态度、职业道德、团队合作精神等方面评价职业素养。

### （六）质量管理
- 完善质量保障机制。构建全面的质量保障体系，包括教学质量监控、教学效果评估、质量反馈与改进等环节。引入行业企业、社会机构等参与评价。
- 推进教学改革与创新。鼓励教师开展教学方法、教学内容和教学手段的改革与创新，采用项目化、任务驱动等教学方式。加强对教学改革项目的支持与管理。
- 强化毕业生质量跟踪。建立毕业生质量跟踪调查机制，定期对毕业生的就业情况、职业发展状况、用人单位满意度等进行调查与分析。根据调查结果，及时调整人才培养方案和教学内容。

| 2.问题分析 | 指标点2-1：能够运用适用于所属学科或专业领域的分析工具，定义与分析问题，并得出实证性结论。<br>指标点2-2：能将数字媒体知识或行业规范知识，应用于图形图像制作、二维动画设计与制作、三维模型制作、微电影制作、VR/AR调试等岗位。<br>指标点2-3：正确理解需求分析报告和项目建设方案，能够运用数字媒体理论知识和技能分析二维、三维等各方面的问题，并能够找到解决问题的路径。 |
| 3.解决方法 | 指标点3-1：能够设计技术问题的解决方案，设计满足特定需求的系统、部件或过程，并能够适当考虑公共健康、安全、文化、社会以及环境等因素。<br>指标点3-2：能够设计二维动画，三维模型制作方案，熟悉游戏开发流程，掌握微电影基本技能，熟悉VR/AR设备调试和搭建流程。<br>指标点3-3：具有媒体项目策划、影视产品推广、综合运用各种多媒体软硬件技术工具和设备的能力。具备提供数字媒体服务应用整体解决方案的能力。 |
| 4.研究应用 | 指标点4-1：能够对问题展开研究，设计并进行实验，以得出有效的结论。<br>指标点4-2：具备市场调研、项目策划、产品推广、职业生涯规划和创业能力；具有独立思考、团队合作、逻辑推理、信息加工能力，数字媒体作品创作设计能力。<br>指标点4-3：具备对新知识、新技能的学习和创新能力；能对已有的商业数据进行分析，具有一定的调研、决策、组织、管理、转岗及自主创业的能力。 |
| 5.职业道德 | 指标点5-1：能够恪守伦理准则，理解和遵守工作实践中的职业道德、责任及规范，履行自身的社会责任。<br>指标点5-2：在数字媒体作品创作和项目实施中，能够遵守学术诚信和职业伦理，确保所有引用和参考材料均正确标注来源，避免抄袭和剽窃。<br>指标点5-3：在数字媒体发布和管理过程中，能够保护客户隐私和数据安全，遵守相关法律法规，确保信息安全和道德标准。 |
| 6.沟通合作 | 指标点6-1：具有一定的表达能力、独立工作能力、人际交往能力和团队合作能力；能够与同行以及社会公众进行有效沟通，能够在具有多样性的团队中作为个体、成员或负责人有效地发挥作用。<br>指标点6-2：在团队项目中，能够明确个人责任，按时完成分配任务，并在遇到问题时主动沟通，共同寻找解决方案。 |
| 7.项目管理 | 指标点7-1：具有基本的项目实施与管理知识；掌握数字媒体技术基本思维方法和研究方法，了解数字媒体技术的应用前景，以及相关行业最新进展与发展动态。<br>指标点7-2：具备数字媒体技术项目的组织与管理能力。 |
| 8.终身学习 | 指标点8-1：能够认识到在专业领域进行自主学习和终身学习的必要性，并具备相应的能力。<br>指标点8-2：能够运用数字媒体技术探索新的创作方法和表现形式，如使用新型软件工具或技术进行内容创作。 |
