## Description:

Guides behavior-preserving frontend refactoring of complex conditionals, guards, special cases, and internal invariants across JavaScript, TypeScript, React, and Vue.

This skill is ready for commercial/non-commercial use.

## Publisher:

[bovinphang](https://clawhub.ai/user/bovinphang)

### License/Terms of Use:

MIT

## Use Case:

Frontend developers use this skill to select and apply one conditional refactoring at a time while checking that observable behavior stays the same.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Suggested refactoring may change behavior if conditional edge cases are missed.

Mitigation: Review each generated diff and test affected behavior before adopting the change.
