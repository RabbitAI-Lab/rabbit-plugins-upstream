## Use Case: <br>
Developers and agent users use this skill to list, search, read, create, and append Apple Notes through documented notectl commands. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Commands that list, show, or search notes may expose Apple Notes content. <br>
Mitigation: Use read commands only when note access is intended and review returned note content before sharing it. <br>
Risk: Commands that add or append notes can change Apple Notes data. <br>
Mitigation: Use write commands only with clear user intent and verify the target title, folder, and text before execution. <br>
