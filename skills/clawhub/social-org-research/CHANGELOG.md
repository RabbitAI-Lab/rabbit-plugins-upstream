# Changelog

All notable changes to this skill are documented here.

## [0.1.0] - 2026-09-25

### Added

- Initial release of `social-org-research` skill
- 10-dimension research framework (4 dimensions for `quick` depth, all 10 for `deep` depth)
- `depth: quick | deep` switch for time-budgeted research
- Built-in user prompt template (copy-paste ready)
- Information source priority table (1-5 star tier rating)
- 8 documented Pitfalls distilled from the BottleDream research case
- Real case study: `references/case-bottledream.md` (simplified)
- Integration guidance for `md-pdf-report`, `market-research`, `deep-research`, `kanban-use`, `anti-sycophancy`
