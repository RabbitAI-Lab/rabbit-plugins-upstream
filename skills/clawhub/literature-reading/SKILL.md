# 文献速读

将中英文学术论文（PDF / 文本 / 截图）解析为**模块化结构化学术笔记**：精简摘要 → 研究问题 → 核心方法 → 关键结论 → 创新点 → 课题参考价值。输出适合文献综述、课题参考、开题报告引用。

## 何时启用

- 用户上传 / 粘贴学术论文 PDF、论文截图、论文正文
- 用户要求：速读论文、精读论文、文献摘要、提取研究问题/方法/结论/创新点、整理学术笔记、说明参考价值
- 匹配下方提示词模板任一意图

## 提示词模板（示例）

**示例 1：** 帮我速读这篇论文，完整提取研究问题、核心方法、关键结论和创新点，生成500字精简摘要，并说明这篇论文对我的课题的参考价值。

**示例 2：** 精读这篇核心期刊，梳理完整研究脉络，重点标注论文创新点、研究局限性，整理成简洁的学术笔记。

## 工作流

### 1. 识别输入与语言

| 输入 | 处理 |
|------|------|
| PDF 文件 | 用 Read 工具读取全文（自动转文本）；含图表处读图补充 |
| 粘贴文本 | 直接分析；缺章节信息时按论文标准结构（IMRaD）分段 |
| 论文截图 / 图片 | 先读图提取文字，再整理；模糊处标注「原文不清」 |
| 英文论文 | 提取时保留关键术语原文（括注中文）；摘要、参考价值用中文输出 |
| 中文论文 | 全程中文输出 |

信息不足时，用简短确认（可一次问清）：论文标题/作者（若可知）、用户课题方向（用于评估参考价值）、是速读还是精读、是否只要某模块。

### 2. 抽取原则

- **忠于原文**：研究问题、方法、结论尽量贴近原文表述；推断处标明「归纳」
- **可溯源**：有页码/章节则标注；无则写「据所给文本」
- **精简规整**：每个模块用短条目，避免大段复述；摘要严格控制在 500 字以内
- **术语一致**：核心术语全文统一；英文论文保留原术语括注中文译名
- **参考价值落地**：结合用户课题方向具体说明可借鉴之处，避免空泛「有参考意义」

### 3. 输出模板

详细空模板见 [references/templates.md](references/templates.md)。默认结构如下。

#### A. 速读版（默认，500字摘要）

```markdown

## 一、精简摘要（≤500字）
<3-5句概括研究背景、问题、方法、结论与贡献；不堆砌细节>

## 二、研究问题
- 核心问题：
- 子问题：
  1. …
  2. …

## 三、核心方法
- 方法名称 / 范式：
- 数据 / 样本：
- 关键步骤 / 模型框架：
- 评估指标 / 实验设计：

## 四、关键结论
- 主要发现 1：
- 主要发现 2：
- 数据 / 实验支撑：

## 五、创新点
- 理论创新：
- 方法创新：
- 应用 / 数据创新：

## 六、课题参考价值（结合用户课题方向）
- 可借鉴方法：
- 可引用结论：
- 可对比 / 可拓展方向：
- 局限与启示：
```

#### B. 精读版（完整研究脉络）

在速读版基础上，增补以下模块：

```markdown
## 七、研究脉络梳理
- 背景 → 问题 → 文献缺口 → 方法 → 实验 → 结论 → 贡献

## 八、文献综述要点（论文中所引关键文献）
- 关键引用 1：观点 / 与本文关系
- 关键引用 2：…

## 九、研究局限性（论文自述 + 读者补充）
- 局限 1：
- 局限 2：

## 十、可摘抄关键表述
| 序号 | 原文表述 | 出处（页/节） | 可用场景 |
|------|---------|---------------|----------|
| 1 | 「…」 | | 综述/开题/… |
```

### 4. 参考价值评估要点

评估「课题参考价值」时，从以下维度具体说明，避免空泛：

- **方法借鉴**：用户课题是否可采用同类方法 / 模型 / 实验设计
- **结论引用**：哪些结论可作为用户论述的支撑论据
- **对比拓展**：与用户课题的异同，可在何处延伸或改进
- **数据 / 工具**：可用数据集、开源代码、评测基准
- **局限启示**：论文局限是否提示用户课题的避坑方向

若用户未提供课题方向，先简短询问；若用户要直接出结果，则按「通用科研场景」给出参考价值，并标注「未结合具体课题方向，建议补充课题信息以精细化评估」。

### 5. 交付检查

- [ ] 摘要 ≤500字，含问题/方法/结论/贡献四要素
- [ ] 研究问题、方法、结论、创新点四个核心模块齐全
- [ ] 参考价值结合用户课题方向，非空泛套话
- [ ] 英文论文术语保留原文括注中文
- [ ] 未把推测写成原文；截图不清处已标注
- [ ] 精读版额外含研究脉络、局限性、可摘抄表述

## 边界

- 不编造未出现的数据、实验结果、作者观点、页码
- 不替代用户完成需原创的整篇文献综述正文（本技能产出**结构化笔记骨架与摘录**；若用户要求扩写成综述，再在笔记基础上扩写并标明哪些是原文表述）
- 版权：仅基于用户提供的文本/PDF整理，不主动拉取整本论文之外的资源
- 无法解析的 PDF（扫描件无文字层、加密）时，提示用户改用图片截图或粘贴文本
