# Case Outline：带 Exhibit 编号的章节大纲模板

> 用法：阶段 3 骨架搭建时复制本模板，填入章节要点、信息来源、关键数据点与 Exhibit 编号。每个 Exhibit 在正文中必须有编号引用。

## 案例信息

- 标题（Title）：`<公司>：<决策困境>`
- 副标题（可选）：`<IPO 还是并购？>`
- 主角（Protagonist）：姓名 / 职位 / 视角
- 决策焦点（Decision Focus）：`X 在 Y 情境下，面对 Z 约束，是否应该做 W？`
- 类型与篇幅：`field / library / armchair`；`mini / full-length`
- 目标课程与受众：`<课程名>` / `本科 / MBA / 高管`
- 目标语言：`中文 / 英文 / 双语`
