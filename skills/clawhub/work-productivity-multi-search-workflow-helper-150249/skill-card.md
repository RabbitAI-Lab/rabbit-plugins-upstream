## Description: <br>
Helps agent users, skill authors, maintainers, and teams turn Multi Search Engine-style productivity needs into practical workflows, checklists, analyses, implementation support, and validation notes. <br>

This skill is ready for commercial/non-commercial use. <br>

External agent users, skill authors, maintainers, and teams use this skill to clarify productivity workflow requests, create concrete plans or artifacts, and check outputs against stated success criteria. <br>

## Known Risks and Mitigations: <br>
Risk: The security scan found overly broad activation wording that could select this skill for ordinary search, engine, or bug-fix requests. <br>
Mitigation: Narrow trigger terms or disable implicit invocation so the skill is selected only for intended multi-search workflow productivity tasks. <br>
