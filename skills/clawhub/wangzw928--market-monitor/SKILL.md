# Market Monitor

不做预测，做风险来源识别 + 长期逻辑判断 + 按规则决策。

## 触发条件

- 用户询问市场、纳指、标普、黄金走势
- 用户对市场波动（涨或跌）表示担忧
- 用户问「加仓/减仓」
- 定时 heartbeats 每周/每季检查

## 核心原则

**不预测方向——识别风险来源——判断长期逻辑——按规则提醒**

**涨也分析，跌也分析**——大涨不等于"没事"，需要判断上涨驱动因素是否可持续。

## 可用数据源（已实测 2026-06-12）

✅ **美国宏观：** FRED (fred.stlouisfed.org) — 美债收益率/利率。Federal Reserve (federalreserve.gov) — FOMC 日历。
✅ **中文财经：** 东方财富 (eastmoney.com) — A股/美股/基金。财联社 (cls.cn) — 快讯/宏观日历。新浪财经 (finance.sina.com.cn) — 美股/汇率/黄金。
⚠️ **QDII：** 天天基金 (fund.eastmoney.com) — QDII 限购/溢价。
🔄 **备用：** web_search — 当直接抓取失败时，用搜索获取最新数据/中文报道（如 CPI 数据、FedWatch 概率、估值指标）。
❌ **不可用（web_fetch）：** Yahoo Finance、CME FedWatch、TradingView、BLS.gov、Reuters。
❌ **不可用（headless browser）：** 知乎、Yahoo Finance 等检测 headless 浏览器。

### 2. 美国通胀 & FOMC（CPI/FOMC/降息预期）

**CPI 数据：** BLS.gov 不可直连，改用：
- web_search "美国CPI 2026年X月" 获取中文财经报道
- 财联社 cls.cn 宏观频道
- 关注：CPI 同比、核心 CPI 同比、下次发布日期

**FOMC 利率决议：**
- Federal Reserve 官网 ✅ — FOMC 声明、点阵图
- 财联社 cls.cn — 中文解读、加息/降息决议报道
- 关注：利率决议结果、点阵图中位数、鲍威尔发布会要点

**市场降息预期：** CME FedWatch 不可直连，改用：
- web_search "CME FedWatch 降息概率 2026年X月" 获取中文转载
- 财联社/华尔街见闻 FOMC 前瞻报道
- 关注：下一次会议降息/加息概率、全年降息次数预期

### 3. 地缘冲突 & 能源影响

**信息来源：**
- 财联社 cls.cn 快讯（最快的中文来源）
- web_search "中东局势 油价" / "俄乌 能源" 等关键词
- 东方财富期货频道 — 油价实时变动

**分析流程（不要只看冲突本身）：**
1. 冲突是否影响原油供应通道？（霍尔木兹海峡、红海、俄罗斯管道）
2. 油价是否因此持续上涨？
3. 油价→通胀→美联储利率→纳指估值，这条传导链是否被激活？
4. 市场是否已经开始定价？（看 VIX、美债、黄金联动）

**能源影响指标：**
- WTI 原油 (CL=F) / Brent (BZ=F) — 东方财富期货
- 美国战略石油储备 (SPR) 动态 — web_search
- OPEC+ 产量决策 — web_search

|------|---------|---------|
| MSFT | Azure 增速、AI 收入、CapEx、营业利润率 | 东方财富 + web_search "MSFT earnings" |
| NVDA | Data Center 收入、毛利率、库存、Guidance | 东方财富 + web_search |
| AAPL | iPhone 收入、服务收入、毛利率、中国区 | 东方财富 + web_search |
| AMZN | AWS 收入/利润、零售利润率、CapEx | 东方财富 + web_search |
| GOOGL | Search 广告、YouTube、Cloud 利润 | 东方财富 + web_search |
| META | 广告收入、AI 推荐效率、Reality Labs 亏损 | 东方财富 + web_search |
| TSLA | 交付量、汽车毛利率、FCF、能源业务 | 东方财富 + web_search |

**利润结构三张表重点：**
- 利润表：收入增速、毛利率、营业利润率、EPS
- 现金流：经营现金流、自由现金流、CapEx
- 资产负债表：现金、债务

**三连恶化信号 = 警告：**
收入增速↓ + 利润率↓ + 管理层下调指引（连续 2 季度以上）

### 5. 纳指估值指标

**定期检查（每周或市场大幅波动时）：**

| 指标 | 含义 | 获取方式 |
|------|------|---------|
| Nasdaq 100 P/E | 静态市盈率 | web_search "Nasdaq 100 PE ratio" |
| Nasdaq 100 Forward P/E | 未来12月预期市盈率 | web_search "Nasdaq 100 forward PE" |
| S&P 500 P/E | 标普估值参考 | web_search "S&P 500 PE ratio" |
| 10Y Treasury | 无风险利率基准 | FRED DGS10 ✅ |
| Equity Risk Premium | 股票相对债券的风险补偿 | 计算：1/PE - 10Y yield |
| 七巨头集中度 | Magnificent 7 占纳指权重 | web_search |

**估值判断框架：**
- 高 PE + 高盈利增速 → 可忍受（成长消化估值）
- 高 PE + 盈利增速放缓 → 危险信号
- 高 PE + 利率上行 + 盈利放缓 → **最高警戒**

### 6. 涨幅逻辑分析（不只是跌了才分析）

**当纳指/QQQ 大涨时，按以下框架判断可持续性：**

1. **驱动因素识别：**
   - 利率驱动？→ 美债收益率↓、降息预期↑ → 估值修复性上涨
   - 盈利驱动？→ 七巨头财报超预期 → 基本面支撑
   - 技术驱动？→ AI 突破/CapEx 回报 → 结构性能上涨
   - 流动性驱动？→ 美联储放水/财政刺激 → 可能短期
   - 情绪驱动？→ 散户/期权狂热 → 警惕回调

2. **可持续性判断：**
   - 盈利增长 + 利率稳定/下行 → 健康牛，可持续
   - 纯利率下行驱动但盈利未增长 → 估值牛，需盈利跟上
   - 纯情绪/流动性驱动 → 警惕回调

3. **风险提示（大涨时更要冷静）：**
   - 估值是否已到极端水平？（检查 Forward PE）
   - 市场情绪是否过度乐观？（VIX 极低？）
   - 是否有未定价的风险？（FOMC、地缘、盈利下修）

## 风险分层

| 层级 | 条件 | 行动 |
|------|------|------|
| 1 普通波动 | QQQ 日波动 -3%~+3% | 不行动，正常 |
| 2 明显回撤 | 纳指高点-10%+ | 进入加仓观察区 |
| 3 大级别修正 | 纳指-20%+，信用恶化 | 分批加仓，保留现金 |
| 4 系统性风险 | 银行/信用/流动性冻结 | 考虑暂停定投 |

## 「黄金+股市同跌」排除法

按顺序：
1. **利率冲击？** → 美债收益率↑、美元↑、FOMC 鹰派？
2. **地缘冲击？** → 油价↑、财联社冲突报道？能源通道受阻？
3. **盈利逻辑坏了？** → 七巨头财报下修、云增速↓？
4. **通道问题？** → QDII 限购、溢价异常？
