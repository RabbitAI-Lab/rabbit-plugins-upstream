# 按需深度分析

用于用户明确要求的深度报告、周报、财报分析、估值判断或投资计划复核。按问题选择章节，不要求每次执行整张清单。

## 跨市场解释

- A股：指数变化是否被涨跌广度、同时间成交额和行业分布支持？大盘权重拉升不必然代表多数股票上涨。结合盈利、国内政策、人民币、资金利率和信用环境。
- 美股：区分科技大盘、等权市场和小盘股；结合盈利预期、美债实际/名义收益率、美元、VIX和信用利差。科技指数不能单独代表全市场。
- 港股：结合中国盈利/政策、离岸人民币与美元利率；互联互通数据仅使用当前真实披露且能核验的指标。
- 股金同跌：利率/美元冲击、融资去杠杆、地缘能源、盈利变化均可作为待检验解释；不按固定顺序排除，也不把地缘冲突机械等同油价上涨。
- 原油上涨先区分供给冲击与需求改善，再讨论通胀和利润率影响；关注运输/供给的实际证据，不仅凭标题。

每个驱动写清依据和替代解释。例如“实际利率上升与估值承压一致”不等于已经证明全部跌幅由利率造成。

## 盈利与估值

### 财报

优先公司IR/监管披露，媒体摘要只作定位。区分报告期、公告日、同比与环比、GAAP与调整后数据、实际业绩与管理层指引；与分析师预期比较时注明预期来源和时点。

| 公司 | 有关时重点检查 |
|---|---|
| MSFT | Azure、AI投入与商业化、营业利润率、CapEx |
| NVDA | 数据中心收入、毛利率、库存、供应与指引 |
| AAPL | iPhone、服务业务、中国收入及利润率 |
| AMZN | AWS、零售利润率、资本开支与自由现金流 |
| GOOGL | 搜索、YouTube、Cloud、资本开支与监管 |
| META | 广告、AI推荐变现、Reality Labs、资本开支 |
| TSLA | 交付、汽车毛利率、能源、自由现金流 |

A股/港股按相关行业选择代表公司，不照搬七巨头：银行看资产质量/息差，消费看收入/毛利与库存，制造看订单/产能/现金流，资源看价格/成本/产量。用同口径历史比较，不给没有来源的行业阈值。

共同检查利润表、经营现金流、资本开支、资产负债表。自由现金流若自行计算须写公式；资本化、一次性项目、回购/股本变化可能影响EPS比较。盈利增速、利润率和指引连续恶化是关注信号，不是自动买卖规则；没有指引不视为下调。

### 估值

- 标明指数/公司、TTM/静态/Forward PE、盈利定义与数据日期；不同供应商的聚合方法、亏损公司处理和预期来源可能不同，不直接拼接。
- 分位数必须交代样本期和可用历史；数据不全不声称“历史极值”。成长能否消化估值需要盈利证据，不能用“高增长”三个字判定安全。
- 统一指数/公司、估值日期、TTM/静态/Forward PE及盈利定义后，按 `100 / PE − 同币种国债收益率(%)` 计算并称为盈利收益率差，仅作简化估值参考。PE≤0、缺失或口径不可比则不算。如展示严格的隐含权益风险溢价，须说明现金流、增长和折现模型，不能直接换名。
- 方法背景：[Damodaran ERP研究](https://pages.stern.nyu.edu/~adamodar/pdfiles/papers/ERP2022Formatted.pdf)。盈利收益率近似依赖强假设，不能代替用户的预期收益或风险承受能力。
- QDII/ETF额外核对基金公司当日申购规则、NAV日期、交易价格时间和汇率影响；过期NAV与盘中价格算出的溢价只能称估算，不直接建议套利。

## 风险与计划复核

风险级别及其判定口径以技能主文件“分析与建议边界”为准，避免在速览和深度报告中出现两套分类。具体判断时把日变化、指定窗口回撤、波动率、盈利/信用证据分开；回撤注明高点窗口、基准日期和价格/总回报口径（“过去52周高点回撤”与“历史高点回撤”不同）。证据缺失时写“暂不能完整分级”；级别不直接推出买卖结论。对已有投资计划，结合期限、现金需求、集中度、可承受回撤和再平衡规则作条件化复核；没有这些信息，不自行给精确仓位或改变用户规则。

## 周报/季度复核的可选模块

- 周报：主要市场表现、广度/成交、利率信用、汇率商品、已发生事件与未来确认日历；区分周涨跌和当天涨跌。
- 季度：相关公司/行业盈利、现金流、资产负债、指引、估值与集中度变化。
- 长期逻辑：AI等资本开支是否产生收益、盈利质量、监管/竞争、融资成本和汇率结构变化；把待验证情景与已经发生的事实分开。

这些模块只用于当前请求或已有安排，不自行创建周期任务。
