## Description:

Find keyword opportunities for a site: discover seeds, score volume, difficulty and intent, check SERPs, and save the winners.

This skill is ready for commercial/non-commercial use.

## Publisher:

[conqueror](https://clawhub.ai/user/conqueror)

### License/Terms of Use:

MIT-0

## Use Case:

External users and SEO teams use this skill to turn seed topics, competitor data, ranking data, or Search Console performance into a prioritized keyword opportunity set for a site.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill relies on a connected Conqueror MCP server and project SEO or Search Console data.

Mitigation: Confirm the MCP server is trusted and that the selected project's data is approved for keyword research before use.

Risk: Saving keywords changes the user's saved keyword set.

Mitigation: Review the proposed keywords and require explicit user confirmation before calling save_keywords.
