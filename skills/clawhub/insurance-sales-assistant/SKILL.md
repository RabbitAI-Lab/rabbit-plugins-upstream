# 🤖 销售行为管理助手

> 保险代理人专属销售行为管理系统 | 飞书原生实现 | 自动初始化

---

## 🎯 核心功能

本技能帮助保险代理人建立系统化的销售行为习惯，包含：

1. **每日任务推送** - 暖客清单 + 朋友圈素材 + 约访进度
2. **暖客池管理** - 客户线索热度分追踪 + 自动跟进提醒
3. **签单追踪** - 产品类型/保费金额/来源线索记录
4. **周期性复盘** - 周复盘 + 月复盘问卷
5. **业绩统计** - 自动汇总销售行为 + 业绩数据

---

## 📋 填写指南

**每个客户填写以下信息：**

```
姓名 | 微信 | 关系状态 | 需求标签 | 当前阶段 | 热度分 (50-100) | 上次联系时间 | 备注
```

**关系状态（4 选 1）：**
- 意向客户 - 正在跟进，有明确购买意向
- 已成交 - 已经买过保单
- 潜在线索 - 聊过但还没明确意向
- 转介绍 - 别人介绍来的，还没接触

**需求标签（可多选）：**
- 重疾、医疗、教育金、养老、寿险、其他

**当前阶段（5 选 1）：**
- 初次接触、需求分析、方案中、跟进中、已成交

**热度分参考：**
- 80-100 分：主动询问、同意见面、快要成交
- 60-80 分：有互动、有需求但不着急
- 40-60 分：偶尔回复、需要培养
- 40 分以下：已读不回、长期失联

## 🎯 暖客池管理规则

### 热度分调整规则

| 反馈 | 热度分变化 |
|------|-----------|
| ✅ 同意见面 | +15 |
| ✅ 主动询问 | +10 |
| ✅ 回复积极 | +5 |
| ✅ 已发无回复 | 0 |
| ❌ 已读不回 | -10 |
| ❌ 明确拒绝 | -20 |
| ❌ 被拉黑 | -50 |

### 下次联系时间规则

| 关系状态 | 间隔天数 |
|---------|---------|
| 意向客户 | 7 天 |
| 潜在线索 | 14 天 |
| 已成交 | 30 天 |
| 转介绍（未接触）| 3 天 |

### 客户分类

**高温池（5-10 人）：**
- 正在跟进的意向客户
- 7 天内必须联系一次
- 转化概率最高

**中温池（20-30 人）：**
- 已成交客户（保单周年日前）
- 潜在线索（聊过但未成交）
- 14-30 天联系一次

**低温池（50-100 人）：**
- 已成交客户（日常维护）
- 转介绍来源（未接触）
- 30-90 天联系一次
