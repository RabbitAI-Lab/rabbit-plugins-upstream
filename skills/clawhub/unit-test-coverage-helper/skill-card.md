## Description:

Helps software teams plan, implement, and verify useful unit tests and coverage improvements for existing codebases.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, QA engineers, maintainers, open-source contributors, and product teams use this skill to create repeatable unit-test and coverage workflows that reduce regression risk in existing codebases.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate for broad software testing or quality requests because implicit invocation is enabled.

Mitigation: Use narrower trigger wording or disable implicit invocation when tighter routing is required.

Risk: Generated test plans or code changes can miss project-specific behavior and create misleading coverage confidence.

Mitigation: Review proposed tests against project requirements and run the relevant test or coverage commands before relying on the result.
