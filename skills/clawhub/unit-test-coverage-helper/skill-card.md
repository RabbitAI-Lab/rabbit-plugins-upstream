## Description: <br>
Helps maintainers, QA engineers, contributors, and product teams add useful unit tests and raise coverage in existing codebases. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, software maintainers, QA engineers, open-source contributors, and product teams use this skill to plan, implement, and verify unit-test coverage improvements for existing codebases. It produces practical workflows, checklists, code changes, and verification notes that help reduce regression risk. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate automatically on broad testing or quality requests. <br>
Mitigation: Use it for explicit unit-test coverage work and review generated code changes before applying them. <br>
Risk: Generated tests or coverage guidance may miss project-specific behavior or encode incorrect assumptions. <br>
Mitigation: Review proposed tests against the codebase, run the relevant test suite, and confirm that assertions reflect intended behavior. <br>
