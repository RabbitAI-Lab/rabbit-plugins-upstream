## Description:

Helps teams add useful unit tests, raise coverage for existing codebases, and verify changes against regression risk.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers, QA engineers, maintainers, open-source contributors, and product teams use this skill to plan and implement practical unit-test and coverage improvements for existing codebases. It helps turn testing requests into actionable workflows, code or checklist outputs, and verification notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may be selected for broad testing or quality-related requests and can propose code edits or tests that do not fit the target codebase.

Mitigation: Review suggested tests, coverage changes, and commands before applying them, and run the repository's normal test suite to confirm behavior.
