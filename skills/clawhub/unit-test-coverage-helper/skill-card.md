## Description:

Helps agents add useful unit tests, raise coverage, and verify changes in existing codebases through a repeatable local workflow.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, maintainers, QA engineers, open-source contributors, and product teams use this skill to plan, implement, and review unit-test and coverage improvements for existing codebases.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Suggested tests or code changes could be incorrect, incomplete, or misaligned with the project under review.

Mitigation: Review proposed changes before applying them and run the relevant project test or coverage commands.

Risk: The skill may be invoked for broad testing or quality requests where the intended scope is ambiguous.

Mitigation: Confirm the target codebase, test framework, coverage goal, and success criteria before making changes.
