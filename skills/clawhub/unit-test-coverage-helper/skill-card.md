## Description:

Helps software maintainers, QA engineers, open-source contributors, and product teams add useful unit tests and raise test coverage for existing codebases.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, maintainers, QA engineers, open-source contributors, and product teams use this skill to plan or implement repeatable unit-test and coverage-improvement work for existing codebases. It helps turn a testing goal into scoped steps, checklists, code changes, and verification notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger language may activate the skill for general testing or quality requests beyond unit-test coverage work.

Mitigation: Use narrower trigger language for deployments that should route only explicit unit-test, coverage, or regression-test requests to this skill.
