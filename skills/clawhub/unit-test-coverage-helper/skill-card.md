## Description:

Helps software maintainers, QA engineers, open-source contributors, and product teams plan, add, and verify useful unit tests and coverage improvements for existing codebases.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, maintainers, QA engineers, open-source contributors, and product teams use this skill to create repeatable unit-test and coverage workflows, plan implementation steps, produce checklists or code changes, and verify behavior after changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can be invoked by broad testing or quality-related requests where a unit-test coverage workflow may not be the best fit.

Mitigation: Confirm the user's goal is specifically about unit tests, coverage, regression testing, or related software-quality work before applying the skill's workflow.

Risk: Generated test plans, code changes, or coverage commands may be incomplete or mismatched to the repository's framework and constraints.

Mitigation: Inspect the local project structure, state assumptions clearly, and run or recommend the repository's test and coverage commands to verify the result.
