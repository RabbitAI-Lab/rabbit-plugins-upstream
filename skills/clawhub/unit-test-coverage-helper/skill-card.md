## Description:

Helps software maintainers, QA engineers, contributors, and product teams plan or add unit tests, improve coverage, and verify regression risks in existing codebases.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers, QA engineers, maintainers, contributors, and product teams use this skill to create practical unit testing plans, add focused tests, raise coverage, and verify that code changes preserve expected behavior.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad testing or quality prompts.

Mitigation: Confirm the request actually needs unit test coverage help before applying the workflow.

Risk: Generated code or test commands may affect an existing project.

Mitigation: Review proposed code changes and commands before running them.
