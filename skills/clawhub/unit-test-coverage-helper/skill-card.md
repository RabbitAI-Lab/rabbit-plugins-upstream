## Description:

Helps agents produce practical unit-test and coverage support for existing codebases, including workflows, checklists, analysis, code changes, and verification notes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, software maintainers, QA engineers, open-source contributors, and product teams use this skill to plan, add, review, and verify unit tests and coverage improvements for existing codebases.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad testing, regression, quality, or coverage requests because implicit invocation is enabled and trigger keywords are loose.

Mitigation: Confirm the user wants unit-test or coverage assistance before making code changes or recommending project-specific commands.
