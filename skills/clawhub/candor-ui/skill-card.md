## Use Case:

Developers use this skill when building or changing React and Next.js interfaces for AI agents. It helps them select Candor UI components, connect supported agent SDKs, and present agent activity and decisions clearly.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup guidance recommends unpinned command line packages.

Mitigation: Review package identity and use reviewed, locked versions of command line tools before running them.

Risk: Remote validation may send a project CSS file to an external service.

Mitigation: Check what CSS would be sent and who receives it before using remote validation.

Risk: The scan is partial because some referenced paths were missing.

Mitigation: Review the missing referenced material and scan the complete release before deployment.
