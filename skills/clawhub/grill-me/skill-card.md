## Description:

Interview the user relentlessly about a plan or design until reaching shared understanding, resolving each branch of the decision tree.

This skill is ready for commercial/non-commercial use.

## Publisher:

[tenequm](https://clawhub.ai/user/tenequm)

### License/Terms of Use:

MIT-0

## Use Case:

External users, developers, and teams use this skill to stress-test plans or designs through direct questioning and recommended answers. It can inspect a codebase when project files are needed to answer design questions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may read project files in a code workspace to answer design questions.

Mitigation: Use it only in workspaces where the agent is allowed to inspect the relevant project files.

Risk: Assertive planning review can produce incorrect or overly forceful recommendations.

Mitigation: Treat recommendations as review input and confirm important design decisions with the responsible team.
