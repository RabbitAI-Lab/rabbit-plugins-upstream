## Description:

Provides Chinese-language guidance for observing QA test execution across functional behavior, responses, logs, UI, data, and performance, then recording anomalies and follow-up questions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kokxi](https://clawhub.ai/user/kokxi)

### License/Terms of Use:

MIT-0

## Use Case:

QA testers and developers use this skill to observe test runs, compare expected and actual results, and document anomalies, environment issues, and follow-up actions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Logs, database queries, screenshots, and monitoring output may reveal sensitive operational or user data.

Mitigation: Use only authorized test environments and limit exposure of sensitive information in observations and reports.
