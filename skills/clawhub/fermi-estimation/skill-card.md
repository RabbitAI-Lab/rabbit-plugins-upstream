## Description:

Helps agents produce defensible order-of-magnitude estimates by decomposing a question, using grounded ranges, and cross-checking results.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ysskrishna](https://clawhub.ai/user/ysskrishna)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and other decision-makers use this skill to ballpark capacity, storage, cost, time, or market size when exact data is unavailable and to identify which assumptions need measurement.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Guessed inputs can make a rough estimate misleading for capacity or cost decisions.

Mitigation: Check available measurements before estimating; label guesses, report ranges, and cross-check the result.
