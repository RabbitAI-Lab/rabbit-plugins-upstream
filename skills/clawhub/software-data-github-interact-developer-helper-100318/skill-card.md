## Description: <br>
Helps agent users and maintainers plan, implement, and verify GitHub-style development workflows for bug fixes, setup hardening, reliability improvements, and adjacent skills. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, skill authors, maintainers, and AI-agent users use this skill to turn GitHub-style workflow requests into practical plans, checklists, code or configuration changes, and verification steps. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger wording can activate the skill for generic CLI, API, issue, or bug-fix requests. <br>
Mitigation: Prefer explicit invocation or platform-level trigger controls when a narrower GitHub-style workflow helper is needed. <br>
Risk: The skill may produce code, configuration, or shell-command suggestions that are incorrect or unsuitable for the local project. <br>
Mitigation: Review proposed changes and run the suggested verification commands before deployment. <br>
