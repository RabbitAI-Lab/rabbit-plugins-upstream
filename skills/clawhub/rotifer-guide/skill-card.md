## Description:

Guides developers through Rotifer Gene onboarding, scaffolding, troubleshooting, registry search, and fidelity upgrades.

This skill is ready for commercial/non-commercial use.

## Publisher:

[xiaoba-dev](https://clawhub.ai/user/xiaoba-dev)

### License/Terms of Use:

MIT-0

## Use Case:

Developers working with Rotifer use this skill to learn its Gene workflow, create and troubleshoot Genes, find existing Genes, and plan fidelity upgrades.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: CLI setup and Gene workflows can create or change project files and contact external services.

Mitigation: Review commands before execution and use the local CLI scaffold path for private material.

Risk: Web Studio can transmit descriptions and Gene source; publishing can upload source and make a Gene public.

Mitigation: Confirm what will be sent and obtain explicit approval before publishing.
