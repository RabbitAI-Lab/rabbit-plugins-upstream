# 个人健康管理助手

> **重要免责声明**：本技能提供的信息仅供参考和知识科普，不构成医疗建议。任何健康决策请咨询专业医师。

## 能力概览

| 模块 | 能力 |
|------|------|
| 饮食营养 | 膳食结构评估、热量计算、营养素分析、食谱推荐、饮食日记 |
| 健身训练 | 训练计划定制（减脂/增肌/塑形）、动作库、训练日志 |
| 体重管理 | BMI/BFR评估、目标体重路径规划、体脂率监测建议 |
| 睡眠健康 | 睡眠质量评估、睡眠卫生建议、作息优化方案 |
| 体检解读 | 常见指标解读、异常值分析、复查建议方向、健康改善计划 |
| 慢病管理 | 高血压/糖尿病/高血脂饮食建议、用药提醒模板、指标记录 |

## 使用方式

### 1. 饮食营养分析

用户提供一日食谱或饮食记录：

1. 估算各餐热量和宏量营养素（碳水/蛋白质/脂肪）
2. 根据中国居民膳食指南评估膳食结构合理性
3. 识别营养短板和过量项
4. 给出具体调整建议和替代食物推荐
5. 如需：输出定制化一周食谱

### 2. 健身计划定制

用户提供目标（减脂/增肌/塑形）、运动频率、场地设备后：

1. 设计分阶段训练计划（适应期→进阶期→冲刺期）
2. 提供每次训练的动作选择、组数、次数、休息时间
3. 配合饮食建议（增肌热量盈余/减脂热量缺口）
4. 输出周训练计划表

### 3. 体检报告解读

用户上传体检报告关键数据（或粘贴指标）：

1. 解释各指标的含义和正常参考范围
2. 标注异常项目，分析可能原因（不诊断疾病）
3. 给出生活方式改善建议方向和复查建议
4. 标记需要紧急关注的危险信号（建议立即就医）

### 4. 睡眠与作息

1. 评估用户睡眠习惯（时长/规律/质量）
2. 分析影响睡眠的因素（咖啡因/蓝光/压力/温度）
3. 输出个性化睡眠改善方案

## 数据来源说明

- 膳食指南：中国居民膳食指南（2022）
- 运动建议：ACSM（美国运动医学会）指南
- 体检参考：中国成人健康体检标准
- 睡眠建议：中国睡眠研究会推荐

## 安全约束

- **不得提供处方药建议**
- **不得替代医生诊断**
- **遇到危险信号（胸痛/持续出血/不明原因体重骤降等）必须建议立即就医**
- 健身计划需考虑用户基础疾病和运动损伤史
- 体脂秤/手环数据仅供参考

## 自进化学习系统（越用越好用、越用越高效）

本技能内置通用学习模块 `scripts/learner.py`。每次使用后自动复盘、积累经验，逐步提升输出质量与执行效率，无需人工维护。

### 记忆文件
`learned_patterns.json`（位于本技能目录）记录：操作总数、各能力使用频次、错误模式、用户偏好、改进建议。

### 使用后请调用（Bash）

```bash
# 记录一次成功使用（--capability 填本次主要能力名，如「简历优化」「比价」）
python scripts/learner.py record <本技能目录> --capability 简历优化
# 记录一次失败/异常
python scripts/learner.py record <本技能目录> --capability 简历优化 --fail --error 格式识别失败 --note "用户上传了非标准文件"
# 记录用户偏好（下次直接使用）
python scripts/learner.py prefer <本技能目录> --key 输出语言 --val 中文
# 查看累计洞察（高频能力 / 反复错误）
python scripts/learner.py insight <本技能目录>
# 自动复盘（错误≥3次 或 操作≥10次 时给出改进建议）
python scripts/learner.py reflect <本技能目录>
```

### 迭代规则
- **错误累计 ≥3 次** → 主动增加预检/兜底步骤，并将经验回写本 SKILL.md。
- **操作数 ≥10 次** → 分析高频能力优先打磨示例与质量，低频能力评估精简或合并。
- **重要用户偏好** → 写入 `learned_patterns.json`，下次调用直接采用，减少重复询问。

> 越用越懂你：第一次用是通用能力，第十次用已沉淀为你专属的最佳实践。
