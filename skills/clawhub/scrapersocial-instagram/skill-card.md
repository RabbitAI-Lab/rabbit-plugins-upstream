## Description:

Retrieves public Instagram profiles, posts, comments, hashtag and location analytics, searches, and reel transcripts or summaries through ScraperSocial.

This skill is ready for commercial/non-commercial use.

## Publisher:

[nikhonit](https://clawhub.ai/user/nikhonit)

### License/Terms of Use:

MIT-0

## Use Case:

Researchers, marketers, and developers use this skill to look up public Instagram account and content data, analyze engagement and comments, and transcribe or summarize reels.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: API requests require a ScraperSocial key and spend account credits.

Mitigation: Provide the key only if comfortable using the service, and confirm the requested lookup before spending credits.

Risk: Transcript, summary, comments, and download requests can incur relatively high costs.

Mitigation: Confirm the user wants the media content or comments before invoking those endpoints.
