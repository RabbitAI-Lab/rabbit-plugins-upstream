# 大道无形 · 段永平价值投资

将段永平公开言论（2006–2025，网易博客+雪球"大道无形我有型"，经整理出版为《段永平投资问答录》/《大道：段永平投资问答录》）凝练为可执行的投资决策流程。

## 使用场景与流程

当涛哥让"用段永平的方式看看这只股票/这个投资决策"时，按以下顺序执行：

1. **先过不为清单**（一票否决，见下）——三项铁律任一命中，直接判定"不投"，不再分析。
2. **再过三层过滤**（顺序不可颠倒）：好生意 → 好人 → 好价格。
3. **最后下结论**：按输出模板给出"买/不买/观察"判断与理由，引用段永平原话支撑。
4. 需要深入某层时，按需读取 `references/` 下的两个文件，不要一次性全读。

## 一票否决：不为清单（Stop-Doing List）

段永平逻辑："没有人能保证一直做对的事；发现是错的事，立刻停止，无论多大代价，都是最小代价。"

| 铁律 | 含义 | 违反即否决 |
|---|---|---|
| 不做空 | 收益有限、亏损无限，一次失误万劫不复 | 任何看空/做空建议 |
| 不借钱、不加杠杆 | 看对的情况下也可能死在黎明前 | 用融资、借贷、急用资金投资 |
| 不懂不碰 | 能力圈外不赌博 | 无法说清公司5-10年怎么赚钱 |

辅助排除项：不预测宏观、不猜点位、不追热点、不做技术分析、不信内幕消息、不频繁交易。

## 三层过滤（顺序不可颠倒）

### 第1层 好生意（商业模式，权重最高）
- 标准：护城河深、持续产生自由现金流、产品差异化、不易陷入价格战。段永平比喻："长长的坡，厚厚的雪"。
- 关键追问：**差异化是什么？** 没有差异化，最后就是价格战。品牌是差异化的浓缩。
- 巴菲特午餐（2006）上段永平最大的收获："以前我对商业模式没有这么重视，只是众多考虑之一。"
- 典型正面案例：苹果（生态系统）、茅台（品牌+生意模式）。

### 第2层 好人（企业文化+管理层）
- 企业文化核心是**本分**："做对的事情，把事情做对"；有**利润之上的追求**，不只盯短期利润。
- 检查项：管理层是否理性分配现金流（分红/回购/不乱扩张）；是否正直诚信、聚焦主业；听其言更要观其行。
- 段永平观点：长期来看企业文化比商业模式更重要。

### 第3层 好价格（排在最后）
- 好公司价格贵也可能是糟糕投资；**烂公司再便宜也不碰**（避免价值陷阱）。
- 估值锚：未来自由现金流折现（DCF）的定性判断；财报看自由现金流，ROE 只作筛选指标，不作唯一买入理由。
- 定性分析 > 定量分析。财报数字是结果，生意模式与文化才是根源。
- 段永平原话："好公司价格贵一点也可以拿；便宜不等于值得买，值才值得买。"

## "真懂"检验与持有逻辑

判断是否真正看懂一家公司，三条同时满足才算懂：
1. 能看懂它未来 5–10 年的现金流；
2. 大跌时敢加仓；
3. 大涨时不想随便卖。

持有前自测："**如果股市从此关门五年不能交易，我还愿意持有吗？**" 答案否则，现在就不该买。

- 长期持有的前提：商业模式没变、企业文化没变、估值依然合理。三者变一，重新评估。
- 段永平原话："用10年以上的眼光看问题会让问题简单很多。"
- 仓位观：真正看懂的好公司应适度集中；分散是因为看不懂。懂 3–5 家远好于乱买 50 家。看懂的机会敢于下重注（"一辈子打几个大的洞就够"）。

## 分析输出模板

用段永平框架分析一家公司时，按此结构输出：

```
【不为清单】不做空/不借钱/懂不懂 —— 逐项给出结论
【好生意】护城河与差异化是什么？现金流质量如何？
【好人】企业文化关键词？管理层现金流分配是否理性？
【好价格】当前价相对内在价值（定性）贵还是便宜？给出依据
【五年测试】关门五年还愿意持有吗？为什么？
【结论】买 / 不买 / 观察 —— 一句话理由+段永平原话引用
```

## 纪律

- 所有引用须来自段永平公开问答/访谈，不编造原话；不确定时标注"大意"。
- 涉及具体价格、收益率等数字（如网易 0.8 美元、午餐 62.01 万美元）以 `references/cases-and-facts.md` 为准，已核验。
- 本skill是投资分析框架，不构成投资建议；最终决策由涛哥作出。
