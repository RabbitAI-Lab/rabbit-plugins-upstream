## Description:

Researches popular Xiaohongshu notes for a keyword or topic and identifies title hooks, content angles, engagement signals, and reusable topic ideas from public samples.

This skill is ready for commercial/non-commercial use.

## Publisher:

[devinchen2014](https://clawhub.ai/user/devinchen2014)

### License/Terms of Use:

MIT-0

## Use Case:

Content creators and marketing teams use this skill to review public Xiaohongshu note samples for a chosen keyword, audience, or product direction and plan future content from observed patterns.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Using this skill requires a SocialDataX API key and running a referenced npm package.

Mitigation: Install and provide a key only if comfortable with the package and service; keep the key in the designated environment variable.

Risk: Returned Xiaohongshu links can contain an xsec_token that may be sensitive when shared or stored.

Mitigation: Share or store reports containing full result URLs only where those tokenized links are appropriate.
