## は and が

SKILL.md Rule 4 has the formula. The cases it does not cover:

| Structure | Particle | Why |
|---|---|---|
| Answer to a wh-question | が | 誰が来ましたか → 田中さんが来ました |
| The wh-word itself | が | 何がありましたか, never 何は |
| Subject inside a relative clause | が or の | 私が撮った写真 / 私の撮った写真 — never 私は |
| Subject of a subordinate clause (とき, ので, から, ば) | が | 雨が降ったら |
| Contrast, either half | は | コーヒーは飲みますが、紅茶は飲みません |
| Negation scope | は | 全部はできません (not all of it) vs 全部できません (none of it) |
| Existence, first mention | が | 公園に犬がいます |
| Same thing, second mention | は | その犬は白かったです |
| Descriptive whole-scene sentence (現象文) | が | あ、雨が降っている |
| Generic statement | は | 犬は忠実な動物です |
| 好き, 嫌い, 上手, ほしい, できる, わかる | が on the object | 私は寿司が好きです — the object takes が, which is why English speakers put を there |
| 〜のは〜だ cleft | が inside, は outside | 私が言いたいのはそこです |

**The scope difference is the deepest one.** は scopes to the end of the sentence and often past it; が scopes to its own clause. 象は鼻が長い is two subjects and one sentence: the topic 象 governs the whole thing, 鼻 is the subject of 長い. A model translating "the elephant's nose is long" produces 象の鼻は長い, which is grammatical and changes what the sentence is about.

**The exhaustive reading of が** is the one that causes offence: 私がやります means "I (and not the others) will do it". As a volunteer it is right; as an answer to 誰かやってくれる？ from someone who did not ask you, it reads as a rebuke of the others.

## The Particle Set

| Particle | Core job | The confusion it causes |
|---|---|---|
| に | Destination, existence point, time point, indirect object, agent of a passive | Versus で below |
| で | Location of an action, means, cause, scope | 東京に住む (state) vs 東京で働く (action) |
| へ | Direction, softer than に | Interchangeable with に for destinations; へ is more written and more directional |
| を | Direct object; also the path traversed | 公園を歩く — the park is not the object, it is the route |
| と | And (exhaustive), with, quotative | パンと牛乳 lists exactly two things |
| や | And (non-exhaustive) | パンや牛乳 implies more items exist |
| も | Also, even | Replaces は/が/を; 私も, not 私はも |
| から / まで | From / until | から also means "because" after a clause |
| より | Comparison, and "from" in formal writing | AよりBのほうが |
| でも | Even, or "or something" | コーヒーでも飲みませんか — softens an invitation |
| しか | Only, with obligatory negative | 一つしかない |
| だけ | Only, neutral polarity | 一つだけある |
| ばかり | Only, with a complaint attached | 文句ばかり言う |

**に vs で in one test**: does the verb *happen at* the place (で) or does the subject *end up at / exist at* the place (に)? 会議室で話す · 会議室にいる · 会議室に入る (entering ends at the room) · 会議室で待つ (waiting happens there).

**The particle a model drops** is も. English "also" becomes a separate word; Japanese replaces the particle, and forgetting it produces a sentence that is grammatical and misses the point: 私はそう思います vs 私もそう思います.

## 自動詞 and 他動詞

Japanese pairs intransitive and transitive verbs where English uses one word, and the choice carries blame.

| 自動詞 (it happens) | 他動詞 (someone does it) |
|---|---|
| 開く (あく) | 開ける (あける) |
| 閉まる | 閉める |
| 始まる | 始める |
| 終わる | 終える |
| 入る | 入れる |
| 出る | 出す |
| 落ちる | 落とす |
| 消える | 消す |
| 直る | 直す |
| 決まる | 決める |
| 変わる | 変える |
| 届く | 届ける |
| 見つかる | 見つける |
| 上がる | 上げる |

**This is a politeness device, not just grammar.** データが消えてしまいました (it disappeared) and データを消してしまいました (I deleted it) describe the same event and assign responsibility differently. Japanese defaults to the intransitive where English defaults to an agent — 会議が延期になりました rather than 私たちは会議を延期しました — and using the transitive where the intransitive is expected reads as either an unusual admission of fault or an accusation.

In an apology, this reverses: a 始末書 (`documents.md`) uses the transitive deliberately, because the intransitive there reads as dodging.

## ている and Aspect

ている is not the progressive. It marks a **resultant state** with one class of verbs and **ongoing action** with another.

| Verb type | ている means | Example |
|---|---|---|
| Durative action (食べる, 読む, 書く) | In progress | 食べている = eating now |
| Instantaneous change (結婚する, 死ぬ, 来る, 落ちる) | The resulting state | 結婚している = married, not "getting married" |
| Wearing/holding (持つ, 着る) | State | 持っている = have |
| Habitual, any verb | Repeated action | 毎日走っている |
| 知る | State only | 知っている = know; 知る alone means "come to know" |

The consequence a model gets wrong: **知りません, not 知っていません** for "I don't know". And 田中さんは来ています means he is here now (arrived), not that he is on his way.

Other aspect forms worth having: 〜てある (someone did it and the result is deliberately in place: 窓が開けてある) · 〜ておく (do in advance: 予約しておく) · 〜てしまう (completion, often with regret: 忘れてしまった) · 〜ところだ (about to / just did: 出るところ / 出たところ).

## Conditionals

Four forms; the differences are real and a wrong one produces a sentence that is odd rather than wrong.

| Form | Use | Constraint |
|---|---|---|
| と | Automatic, inevitable consequence | The main clause cannot be a request, order or intention: 押すと開きます, never 押すと開けてください |
| ば | General or hypothetical condition | Prefers stative main clauses; strongly avoided when the subject of both clauses is the same and the main clause is an intention |
| たら | The general-purpose one; also "when" | Works nearly everywhere; the safe default when unsure |
| なら | Given that (accepting the other party's premise) | 東京に行くなら、東京駅で会いましょう — takes up something the listener just raised |

The workhorse distinction: **たら for a specific one-off, と for a rule, なら for responding to what they just said.** 東京に行ったら連絡します (when I go) vs 東京に行くなら連絡してください (if you're going, as you say).

## Giving and Receiving

The direction of a favour is grammaticalised, and getting it backwards is not a style issue.

| Verb | Direction | Subject |
|---|---|---|
| あげる / さしあげる | I give to you/them | Giver |
| くれる / くださる | You/they give to me | Giver |
| もらう / いただく | I receive from you/them | Receiver |

- **くれる has no English equivalent** and its absence is a tell. 田中さんが手伝ってくれました (he helped me, and I am grateful) vs 田中さんが手伝いました (he helped, flat report). A Japanese text describing help received without くれる or もらう reads as cold or as a machine.
- **あげる upward is presumptuous.** 手伝ってあげます to a superior offers charity. Use お手伝いいたします (`keigo.md`).
- **〜てもらえますか is a request**, literally "can I receive": 送ってもらえますか / 送っていただけますか. This is the standard polite request frame and it is built out of this system.

## Passive and Causative

- **The adversative passive** has no English equivalent: 雨に降られた (I was rained on, to my detriment), 子供に泣かれた. It marks that the event affected the speaker negatively, with no agent blamed.
- **Passive as honorific** overlaps with 尊敬語 (`keigo.md`), which is why 社長が話された is ambiguous.
- **Causative させる** = make or let, disambiguated by context and by particle: 子供に行かせる (let/make the child go). **Causative-passive させられる** = made to do, always unwilling: 残業させられた.
- **させていただく** is the causative + receiving, and its conditions are in `keigo.md`.
- **さ入れ言葉**: godan verbs take せる, not させる. 読まさせる is wrong, 読ませる is right. This is not contested.

## Word Order and Modifiers

- **The verb is final, and everything before it is reorderable.** Word order carries emphasis: what comes immediately before the verb gets the focus.
- **All modifiers precede the noun**, including full clauses, which is why the pre-nominal stack is the structural failure of translated Japanese. Past ~25 characters of modifier, split it (SKILL.md Rule 6): 昨日会議で田中さんが提案した新しい仕組み → 昨日の会議で田中さんが新しい仕組みを提案した。その仕組みは…
- **The topic goes first, always**, even when English would bury it.
- **時 → 場所 → 主体 → 対象 → 動詞** is the unmarked order for adverbial elements. Deviating from it is legal and marks emphasis.
- **Nothing follows the verb** except 終助詞 and the copula. A trailing adverbial (行きました、明日) is spoken 倒置 and reads as broken in writing.

## Dropping What English Keeps

Japanese omits everything recoverable from context. What a model fails to drop:

| Keeps | Should usually drop |
|---|---|
| 私は on every sentence | After the first mention; keep only for contrast |
| あなたは | Almost always (`register.md`) |
| それ / これ as a subject | Where the topic already established it |
| Possessives (私の, 自分の) | 母 already means "my mother" |
| Plural markers | 本 covers books; たち only for people and animate groups |
| The copula in casual speech | これ、いいね (not これはいいですね) |
| Explicit "and" between sentences | そして three times in a paragraph is a tell |

The test: read the sentence without the element. If it is still unambiguous, the element was English.

## 読点 Placement

There is no rule with the force of the English comma rules; there are conventions, and consistency matters more than any single choice.

Place a 読点:
- After the topic when the sentence is long: 今回の施策は、来月から開始します。
- At the end of a subordinate clause: 会議が終わったら、連絡します。
- Before a contrastive or a causal conjunction: 確認しましたが、問題ありません。
- To prevent a misparse: **ここではきものを脱いでください** — the classic ambiguity (はきもの / きもの), resolved only by the 読点.
- Between coordinate items where 、is not being used as the list separator.

Do not place one:
- Before or after a particle for rhythm alone.
- After every clause in a short sentence — one 読点 per 15-25 characters is the working density (SKILL.md Rule 6).
- Immediately before 「 or a closing bracket.

## Connectives

| Casual | Neutral | Formal / written |
|---|---|---|
| だから | ですから | したがって / そのため |
| でも | しかし | ただし / 一方で |
| それで | そこで | よって |
| あと | また | なお / さらに |
| つまり | すなわち | 要するに |
| だけど | ですが | とはいえ |

Two failures: **mixing the columns inside one text** (だから in a paragraph that uses したがって), and **opening every paragraph with one**. Japanese prose connects through the topic chain more than through connectives; a paragraph that opens with そして, そのため, また in three consecutive positions is machine-shaped.
