# 存储规格

只采用“一书一目录、至多三个持久 Markdown 文件”。不提前建立 work、edition、session、索引数据库、每篇目录或每次会话目录。

```text
reading/<书名>/
  book.md
  progress.md
  sealed.md
```

`sealed.md` 可在第一次需要封存观察时再创建。不得创建 `index.md`、YAML 或把电子本复制进书档；需要检索时，从原文件读取获准范围并输出到宿主的本地私有临时目录；私人本体的切片仍留在 workspace 内，并绝不修改原电子本。

## 原则

- 目录名用通行书名；译本写字段，不拆目录。
- `book.md` 只放稳定、可复用的信息，不写显式阅读状态；按需增补的单元 registry 可能间接反映哪些单元已被确认，分享前要检查。
- `progress.md` 只放这次阅读的真实状态。
- `sealed.md` 只放因剧透边界暂时不能说的观察。
- conversation mode、即时深度、一次性情绪反应**不写入任何文件**。
- 本体只记本地路径；正文不复制、不上传、不外传。
- 内容形态分成 `结构` 与 `话语类型`；合集的所有阅读单元仍写在同一个 `progress.md`，不为每篇建文件或目录。

## 旧档兼容

不要求立即迁移已有书档。旧 `内容形态：小说 / 短篇集 / 非虚构 / 叙事性非虚构` 继续有效；读取现有字段，只有在用户报告真实变化、类型得到可靠确认或本来就要更新书档时才补 `结构` / `话语类型`。不整份重写，也不自动删除旧记录。

旧短篇集的 `当前篇目` / `篇内锚点` / `篇目状态` 等同于新合集模型里的 `当前单元` / 当前锚点 / `阅读单元状态`。在用户明确要求迁移前，继续就地更新旧字段，不并行新增一套同义字段；旧 schema 只把 `篇内锚点` 当作当前篇目的活动边界，`篇目状态` 只保存状态、不得再写第二份锚点。原有记录全部保留。对结构与话语类型，新字段只有可靠确认后才写非 `未确认` 值，因此跨会话把任何合法的非 `未确认` 新值视为已确认；与旧分类 fallback 冲突时按“本轮明确纠正 → 已确认的新字段 → legacy fallback”读取。进度边界不使用这条宽松优先级：若新旧当前单元、状态或锚点同时存在且不一致，只有本轮读者明确纠正可裁决；否则先澄清，确认前不访问电子本。重复的新字段互相冲突，或多个同优先级 legacy 进度信号互相冲突时同样 fail closed。旧档里的 conversation mode、`index.md` 或封存队列不得继续驱动路由或解封。旧字段只有裸标题且能唯一解析时可原位沿用；若有重名，先问清，再在原字段值中最小补入稳定 ID，并把新权限绑定该 ID。这个唯一性补强不等于并行建立整套新 schema。


版本或译本改变时，更新相应字段、专名与章节切分说明；不要新建第二个目录，也不要重写与译本无关的段落。`book.md` 的核查史不授予本体访问；当前是否有可访问文件只看 `progress.md` 的 `本体`。

## `progress.md` 通用头部

前后材料也使用独立阅读单元。允许语料、定位结果、`scope_handle` 与 `confidence` 都是每轮临时核查状态，不持久化。`当前单元` 只表示此刻位置；目标单元和访问范围按 `spoiler-and-evidence.md` 计算。

```markdown
# 《书名》· 阅读记录

- 阅读状态：未开始 / 在读 / 暂停 / 弃读 / 读完（仅指读者明确确认整本完成）
- 媒介：读 / 听 / 混合
- 本体：<当前本地路径；没有则写「无」；未核实则写「未确认」>
- 本体指纹：<本地计算的 sha256；无本体则写「无」；未核实则写「未确认」>
- 单元映射版本：<与 book.md 当前版本/译本一致的规范化版本键；未确认则写「未确认」>
- 本书剧透覆盖：<仅在用户明确说“这本都可以剧透”时写 open；否则省略>
- 上次更新：YYYY-MM-DD
```

`progress.md` 的 `本体` 是当前可访问性的唯一权威；每次内容调用前仍须确认路径存在且是预期文件。`book.md` 的历史核查记录、旧“可核文本”字段或口头上曾经接入过都不能授权访问；它们与 `本体` 冲突时以 `progress.md` 为准，路径缺失/失效则按无可用本体降级。`本体指纹` 在宿主本地由精确源文件字节计算，不把正文或指纹交给模型或外部服务。

有效 source identity 是规范化版本键、规范化本体路径与本体 SHA-256 的组合。`单元映射版本` 只有在这三者都与上次确认值一致时才绑定所有活动单元状态、锚点和**整套剧透权限**。版本键、路径或指纹任一改变（包括同路径文件被替换）时，必须先原子地把映射设为 `未确认`：冻结活动单元表，暂停本书 `open` 与所有单元权限，不得用旧 ID 或旧宽授权访问新本体。映射确认后，只迁移能唯一对应的阅读状态；单元 `strict` 只有唯一映射时才保留，任何无法映射的 `strict` 都使全书继续 fail closed、等待读者澄清。单元 `open` 与本书 `open` 不跨 source identity 自动迁移，须由读者重新授权；无法唯一映射的旧状态只可带旧 source identity 标签写入进度历史。最后以新 source identity、新活动表和收窄后的权限一次性替换；不能先改版本/路径、后继续沿用旧 `正文-03 open`。

### 所有结构共用的单元状态与权限

以下区块接在结构专用的「当前进度」之后。`book.md` 的「已确认单元」是单元身份、显示名、类别和话语类型的唯一来源；`progress.md` 只用稳定 ID 保存读者状态、锚点和权限，不重复类别/类型。合集为实际遇到的单元逐项记录；线性结构至少记录需独立追踪的前后材料、非当前部分单元和任何持久单元权限。这样读者移出前言后，仍能表示前言已读完、回访它或撤销它的权限。

```markdown
## 阅读单元状态
- <稳定单元标识> · 未读 / 在读 / 读完 / 跳过 · <可选锚点>

## 单元剧透覆盖
- <稳定单元标识> · open / strict
```

- `单元剧透覆盖` 只记录明确的持久权限：`open` 或 `strict`。只开放当前问题不落盘；权限与阅读状态独立。重名或身份不清时先澄清。
- 权限优先级、撤销语义和范围计算只以 `spoiler-and-evidence.md` 为准；本文件只定义它们如何存储。
- `阅读单元状态` 行中的可选锚点是新 schema 唯一的活动范围边界；「当前进度」只保存当前单元指针和非授权性的对话上下文。若旧当前块锚点与单元表锚点同时存在且不一致，先澄清且不访问本体；不得静默采用较后或较宽者。
- 单元身份、类别或话语类型发生冲突时以 `book.md` 为准；`progress.md` 不维护第二份分类。

### 线性结构

```markdown
## 当前进度
- 当前单元：<稳定单元标识，例如 正文-05 / 前言-作者>
- 当前主题：<非虚构可写概念、论证或案例；不适用则省略>

## 进度历史
- YYYY-MM-DD · <稳定单元标识> · <锚点或主题>

## 待澄清问题
- <问题>

## 已讨论问题与卡点
- YYYY-MM-DD · <difficulty/context/tracking/momentum/medium> · <一句事实性记录>
```

线性正文可由连续锚点推导更早正文已覆盖，但不得据此开放未明确覆盖的前后材料、跳过部分或不同版本单元。旧小说的 `当前锚点` 和旧非虚构的 `当前位置` / `当前主题` / `已覆盖部分` 都可继续读取，不为改名强制迁移。

### 合集结构

适用于短篇小说集、散文集、评论集、演讲集、混合文集等。正文篇目和前后材料共用上面的阅读单元状态表。

```markdown
## 当前进度
- 当前单元：<稳定单元标识，例如 正文-03 / 前言-作者；无则写「无」>

## 进度历史
- YYYY-MM-DD · <稳定单元标识> · <状态或单元内锚点>

## 待澄清问题
- <问题>

## 已讨论问题与卡点
- YYYY-MM-DD · <稳定单元标识> · <模块> · <一句事实性记录>
```

合集规则：

- 允许乱序。更新某篇时只改该篇；未列出的正文篇目和前后材料按未读处理；`跳过` 不等于读完或开放。
- 读完一个单元不等于读完整本；局部 `open` 也不改其他单元权限，且不允许打开 `sealed.md`。
- 前言提到 A 不改变 A 的状态；后记未读时同样封闭。

## `sealed.md`

读中禁止读取。每轮必须先处理本轮全部权限限制，再判断解封；“整本读完，但某单元先别剧透”须先写该单元 `strict`。只有在不存在仍有效的单元 `strict` 例外时，满足下列任一条件才可整份打开：

1. `progress.md` 已根据读者明确陈述记为整本「读完」（不是只指正文或若干单元）（不能从正文或若干单元完成自动推断）；
2. 用户明确把**整本**剧透权限改为 `open`。

读完或开放任一结构中的一个单元、或只允许回答某一个具体问题，都不等于允许打开整份 `sealed.md`。无论整本状态是读完还是 `open`，只要还有任一单元 `strict`，也不得打开：`sealed.md` 没有可靠的单元隔离，可能泄露该例外范围。

```markdown
⚠️ 读中禁止读取。仅在没有单元 `strict` 例外，且整本读完或整本剧透权限明确为 open 时打开。

# 《书名》· 封存观察

## S1
- 封存于：YYYY-MM-DD
- 当时进度：<内容形态对应的阅读单元与锚点>
- 观察：<因剧透线没说的内容>
- 状态：封存中 / 已归还 YYYY-MM-DD
```

写入规则：只追加；写后不回读；不在 `progress.md` 留观察正文或暗示；不要告诉读者“有东西先不说”。

## 可分享性

| 文件 | 是否可分享 | 原因 |
|---|---|---|
| `book.md` | 分享前检查 | 不写显式读者状态，但按需增补的单元 registry 可能间接反映哪些单元已被确认；只分享无剧透、无私人来源定位的稳定材料 |
| `progress.md` | 不可以 | 含个人阅读状态、本体路径与卡点 |
| `sealed.md` | 不可以 | 含尚未允许披露的内容 |
