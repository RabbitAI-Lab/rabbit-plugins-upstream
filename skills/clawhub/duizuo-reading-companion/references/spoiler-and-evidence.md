# 剧透与文本证据

## 先判问题，再选来源

1. 把读者当下的话压缩成最小可回答问题。
2. 判断答案是否真的需要书本文本。
3. 文化、历史、概念、语言、地理等外部语境问题，使用相应外部来源；除非读者明确问书内用法，否则不打开或搜索电子本。
4. 书本文本只是可选证据源。它已存在不等于有权限读取，也不要求把外部问题扩展成文本分析。
5. 必要歧义会改变答案时，只问一个简短澄清问题；不得从未读正文反推读者指什么。

例如，读者在前言看到「鸡蛋花」后问「鸡蛋花是不是在南方地区有什么特殊含义？」，最小问题是外部文化语境；应澄清必要的地域范围并查外部来源，不读取电子本，也不追踪鸡蛋花在未读篇目中的分布。只有「这本书为什么在这里写鸡蛋花？」才是书内用法问题。

## 书内问题先判边界

1. 读 `book.md` 的内容形态，并读 `progress.md` 的当前进度。
2. 本轮有新进度则采用；只有旧锚点时把它当安全下界；完全没有可用进度时先问读到哪里，不访问正文。
3. 判断本轮权限：`strict` / 用户请求的 `structural` / 明确 `open`。
4. 先确定允许语料，再决定哪些材料能进入上下文。
5. 在任何读取或返回电子书内容的工具调用前，先从本轮问题与每个目标单元的状态/权限导出允许语料。第一个内容承载调用必须就是安全提取器，并显式携带与范围类型对应的完整逻辑契约；普通单元范围带稳定单元标识与按需终止锚点，单问题授权带 `scope_root / query / return_policy`。若逻辑范围尚无可信物理映射，之前唯一允许的本体访问是下文定义的仅元数据边界定位器；模型侧只能收到本轮不透明 `scope_handle + confidence`，歧义时不得读取内容。获准切片、聚合或有界匹配进入宿主临时目录；后续搜索只能以这些临时输出为输入。若工具不能表达范围或句柄链，就不调用。允许语料、句柄和定位结果都是临时核查状态，不新增持久字段或文件。

### 前后材料是独立阅读单元

序、前言、导读、编者按、后记、附录等各自构成独立边界，不因位于正文前后而自动开放正文或整本。

- 读者只读到前言时，允许语料只有前言中已覆盖的部分。
- 前言提到某篇散文、短篇、章节、人物、地点或意象，不会开放被提到的正文。
- 后记可能概括全书，也不能因名为「后记」而当作安全书目材料；读者没有读到就不加载。
- 内容形态尚未确认时也执行上述边界，不把不确定性转化为全文搜索许可。

### 合集按阅读单元隔离

短篇小说集、散文集、评论集、演讲集和混合文集都按阅读单元守边界：

- 当前单元只表示读者此刻所在位置；问题可点名其他目标单元。每个目标单元分别按部分已读锚点、读完状态、单元 `open` 或本轮单问题授权计算范围。未列单元默认未读，标为 `跳过` 也不获得内容权限。
- 读完或局部 `open` 一个单元不开放其他篇目、前言、后记或附录；明确开放整个单元时只记录该稳定单元标识的 `open`，单问题授权仍不落盘。比较多个已授权单元时逐一验证并独立 locator→extract；不同范围类型或锚点不得合并。
- 对混合集，只按目标单元已确认的话语类型选方法；不能搜索未读单元来判断它是虚构还是非虚构。
- 目标非虚构篇目的主张只能由该篇已授权范围内的证据支持；相邻篇目、编者后记或整本主题介绍不能补洞。
- 工具轨迹必须能看出只提取本轮允许的目标单元；除合约内仅元数据定位器的内部解析外，目录遍历、把目录/成员信息返回模型、跨成员搜索或全文索引都视为越界。重名单元必须用稳定标识区分，未澄清身份前不得读取。

## 陈述类型

| 陈述 | 要求 |
|---|---|
| 书目事实 | 可回答；详细或易变事实需可靠来源 |
| 直接引语 | 必须有允许范围内的原文或用户贴出的片段 |
| 具体书内事实 | 情节、顺序、地点、时代、人物、意象、结构、篇目关系、例子、论点与结论都受进度边界约束；原文可作确定回答，只有二手来源时必须归因并标明未由原文核实 |
| 解释与评价 | 必须标明为推断/判断，并给已读范围内的原文或带来源的二手证据；解释性句子只要声称了具体事件结果（如存活、死亡、到达、发生或导致），仍按「具体书内事实」核证，不得用修辞补足文本未定之处。若只描述叙事效果，须明确写成「可读作」「在叙事上」等读法，并避免让修辞看起来像情节事实 |

非虚构另分作者主张、书内证据、外部事实、读者判断，见 `content-types.md`。

## 有电子本

- 电子本只提供证据能力，不提供权限，也不扩大任何单元。
- 只有最小问题确实需要书内证据时才访问电子本。
- 先把问题中的目标单元与 `progress.md` 的当前单元分开；目标可以是非当前但已读/已开放的单元。
- 按授权派生范围：
  - 部分已读：`unit_id + scope_kind=through_anchor + end_anchor`；
  - 已读完或单元 `open`：`unit_id + scope_kind=whole_unit`，不要求当前阅读锚点；
  - 单问题授权：`scope_kind=question_scope`。若问题只涉及已知单元，使用 `scope_root=unit_ids + unit_ids=[…]`；若读者明确只为这个问题开放全书检索，使用 `scope_root=whole_book`。两者都必须同时传 `query`、`return_policy` 与结果上限。只需回答是否存在/次数时用 `aggregate_only`，不返回篇名或上下文；确需核措辞时才用 `matches_with_bounded_context` 并设置上下文/命中上限。只返回回答该问题所需的聚合或有界片段，不落盘权限；
  - 整本 `open`：`scope_kind=whole_book`；
  - 多单元比较：对每个已授权 `unit_id` 各自计算 `scope_kind` / 锚点并分别执行 locator→extract；不得把不同范围合并为一个批量句柄或临时集合。
- 安全提取器的共同最小契约为 `source_path`、`scope_kind`、`output_path`；`through_anchor` 另需 `unit_id + end_anchor`，`whole_unit` 另需 `unit_id`，`question_scope` 使用上一条的可观察查询字段。若物理映射来自本轮定位器，内容调用还必须带它签发的 `scope_handle`，并重复原逻辑范围，不能用句柄扩大权限。`output_path` 必须位于宿主的本地私有临时目录且不在 `reading/<书名>/`；私人本体的切片仍须留在 workspace 内。返回内容只能是获准切片、聚合或有界匹配。
- 已有可信物理映射时，第一个本体调用就是上述内容提取器。若只有逻辑 ID/锚点，内容调用前唯一允许的本体访问是一次仅元数据边界定位：输入为 `source_path`、`unit_id(s)`、`scope_kind` 与按需锚点；工具内部可解析 `container.xml`、OPF manifest/spine、NCX 及 OPF 标记的 nav 导航资源，但除该 nav 资源外不得打开 spine XHTML 正文。模型侧输出严格为本轮临时不透明 `scope_handle` 与固定枚举 `confidence=high|low|ambiguous`；失败不得附候选标题/路径；不得返回原始 member ID、文件名、路径、TOC/目录标题、其他单元边界或 prose。只有唯一高置信映射才签发句柄；歧义、冲突或低置信返回空句柄并停止，不执行任何内容承载调用。句柄不可猜、不可跨轮复用、不可落盘。
- 除上述仅元数据定位外，不允许先读目录、元数据、成员名或全文索引。普通切片不得先让整本搜索结果进入上下文再过滤。只有读者明确授权的 `question_scope` 可由提取器在内部检查其 `scope_root`，且只能把符合 `query` 与 `return_policy` 的聚合或有界片段写到 `output_path`。后续搜索只接收这些临时输出。仓库不假定具体宿主工具名；宿主不能满足契约时必须走降级路径。
- 无法确认单元身份、定位器返回空句柄/非高置信、截断边界不唯一或无法安全截断时，不读取或搜索电子本内容；转用范围安全的外部来源、用户已贴片段或核查路径。
- 回答具体情节或引语时给出可定位的文本依据。
- 获准切片里找不到，只能说“已授权范围里没有/无法确认”；不准用模型记忆补未授权文本。
- 只有 `through_anchor` 需要可靠锚点；整单元、单问题或整本开放不以阅读锚点为前提。

## 未接入电子本

先自然问一次读者手上是否有整本可提供，不用固定话术，也不要直接默认只有“贴一段”这一条路。

读者确认没有或不便提供时：

- 先按当前问题找公开二手来源：出版方/图书馆简介、可靠书评、作者访谈等。
- `strict` 下只加载不会明显越过当前进度的来源；全书梗概、结局解析和覆盖未读内容的评论不得进入上下文。
- 用到的二手来源写进 `book.md`，包括标题、发布者/作者、URL、日期和核查限制。
- 回答时明确归因，如“出版方简介写道”“某篇书评将其概括为”；不能把二手描述说成“书里写了”。没有原文访问权时，第一句话先声明来源和置信度（“以下来自书评，我没看过原文”），不能等读者追问才说。
- 永远不要用二手来源纠正读者正在听/读的内容。读者对当前内容的描述与二手来源冲突时，以读者为准——他听到的可能是原文真实存在的场景，而你没看过原文。想纠正前先问自己有没有原文访问权；没有就只问澄清问题（“你听到的是哪一段？”），不下断言。
- 二手来源可以补背景和给暂定解释，但不能证明直接引语，也不能消除具体情节或事件顺序上的不确定性。
- 能从用户贴出的片段判断时，只依据该片段作答；片段不足就说明缺什么。
- 没有合适的二手来源或片段时，给核查路径：去哪个已读章节/场景，看谁在说、是否有第三方证实、原文用了什么措辞。
- 整本、片段和二手来源都是可选路径；读者拒绝后不重复追问。

## 权限

### strict（默认）

允许：已读范围、书目事实、不改变未来预期的语境与识别方法。

禁止：未读事件、未来人物关系、结局、反转、尚未读到的地点/时代/意象/象征/结构/篇目关系/论点/案例/结论，以及任何会改变阅读预期的形式前瞻。不能因为信息「只是地理」「只是结构」或没有事件，就把它当作无剧透。

### structural

读者明确想谈结构时，可讨论不改变未来预期的安全导航。`structural` 是主题/方法，不是剧透授权；时间线合流、叙述者可靠性、跨篇照应、未读篇目的排列原则等如果会暴露未读内容，仍须压住，除非读者明确 `open` 对应范围。

### open

用户明确允许后，可越过进度。先按本轮指令更新状态，再对每个目标单元依次判断：本轮更晚的单问题授权 → 单元 `strict` → 整本 `open` → 单元 `open` → 已读范围 → 封闭。区分：

- “这个问题直接告诉我”＝只开放这个问题，不落盘；若本轮这句话晚于旧 `strict`，只为这一问临时越过它，回答后原 `strict` 仍有效；
- “《A》这篇都可以剧透”＝只记录 A 的稳定单元标识覆盖，不开放其他单元或 `sealed.md`，也不改变 A 的阅读状态；
- “这本都可以剧透”＝整本覆盖，可写入 `progress.md`；仅当没有仍有效的单元 `strict` 时才允许打开 `sealed.md`，且不把阅读状态改成读完；
- “A 以后别剧透了”＝若整本仍 `open`，记录 A 的 `strict` 例外；否则删除 A 的 `open`；
- “这本恢复防剧透”＝删除整本覆盖，并清除未被本轮明确保留的局部开放；之后按已读状态与锚点重新计算范围；
- 后来明确说“这本都可剧透”会清除较早的单元 `strict`，除非读者同时保留例外。

## `sealed.md`

`sealed.md` 的创建、写入与解封条件只以 `storage.md` 为准。回答层面另守两条：不向读者暗示“有东西先不说”；解封后只按当前话题自然归还相关观察，不机械倾倒全部内容。

## 元剧透检查

发送前删掉任何会改变未读预期的句子，包括：

- “后面有反转 / 会解释 / 还会出现”
- “结局很惨 / 很圆满”
- “熬过这段就好 / 后面节奏会快”
- “这种写法后面会更密 / 更难”
- 对未读篇目、章节、地点、时代、意象、象征、结构、人物关系、案例或论证终点的暗示
- 以「只是地理/结构」「没有具体事件」为由提前确认未读内容
- 以“后面如果再出现X就对上了 / 以后看到X留意 / 记下这个后面会用到 / 进下一章时带着看”这类指向未来的阅读指令，即使不说具体情节，也会制造期待，属于元剧透

拿不准时，先问用户是否愿意开放对应范围；不要用“我先不说”制造暗示。回应只基于读者已读到的锚点，不主动布置未来的验证任务。
