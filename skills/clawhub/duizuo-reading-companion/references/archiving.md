# 建档与维护

目标是让书档足够恢复阅读，不把建档变成入场问卷。

## 先答，后补档

- 先提取本轮最小问题并判断是否需要书本文本。书是对话背景，不自动成为证据源。
- 文化、历史、概念、语言、地理等外部语境问题使用相应外部来源；除非用户明确问书内用法，否则不打开电子本，也不扩成全书分析。
- 用户带着具体问题、反应或困惑来：先回应，随后只补当前真正需要的一项信息。
- 用户只说“我想读 X”：若作品明确，可先给无剧透的开读提示，再逐步补档。
- 不为了凑齐字段而连续追问版本、媒介、本体和偏好。

## 风险式确认

只有以下情况需要先确认再写档或给具体内容：

1. 同名书可能指向不同作品；
2. 译本/版本差异会影响专名、章节、删节或当前问题；
3. 部分已读范围缺少可靠锚点；
4. 合集篇名重名、目标阅读单元的稳定身份或单元类型不明；
5. 非虚构问题所指概念、章节或篇目不明，继续答会混淆作者主张。

作品和范围已经明确时，不设置硬 checkpoint，也不要求用户重复确认已经说过的信息。

## 最小建档

一书一目录：`reading/<书名>/`。

新建时优先获得：

- 书名与作者
- 可读内容形态（例如小说 / 短篇小说集 / 散文集 / 混合文集 / 传记）
- 结构：线性 / 合集
- 话语类型：虚构 / 非虚构 / 混合
- 版本或译本（若会影响回答）
- 媒介
- 当前状态与内容形态对应的进度

字段不明可写 `未确认`，以后自然补齐。旧档的 `内容形态：小说 / 短篇集 / 非虚构 / 叙事性非虚构` 继续可用；只在真实状态变化时补结构与话语类型，不强制迁移或重写。格式见 `storage.md`。

## 采集边界

只收“怎么读”和稳定书目信息：

- 结构识别方法、语言难度、语境与典故
- 专名与译法、附录、容易掉线的位置
- 合集篇目是否独立/连作/共享人物/主题组（只记范围安全的关系类型）
- 散文集、评论集、演讲集或混合文集等可读类型
- 非虚构属于论述、传记、回忆录、调查或混合形态
- 已由读者或范围安全书目资料确认的单元稳定标识与话语类型（含混合）；不搜索未读篇目来补齐分类

不收：未读情节、结局、人物走向、未来论证结论、跨篇照应的具体内容。结构信息也可能剧透；写入 `book.md` 前要删去会改变未读预期的内容。

## 文本来源

电子本是可选证据源，不是建档前提或阅读许可。先判断问题是否真的需要书内证据；能由外部语境回答就不访问电子本。需要核具体文本、但还没有确认本体时，自然问一次读者手上是否有整本电子书；不要背固定话术，也不要默认只让读者贴一段。

### 读者有整本

- 用户提供时，只把本地路径写进 `progress.md`。
- 不复制正文到书档，不上传或外传。
- 不创建持久 `index.md`。
- 需要核具体文本时，先确定问题点名的目标单元与权限，不把它强制等同当前单元。范围类型、单问题授权、locator/extractor 契约与失败降级统一按 `spoiler-and-evidence.md`；本文件不另设一套规则。
- 序、前言、导读、编者按、后记、附录各自是独立阅读单元；当前只读前言时，不得因前言提名而把某篇或某章纳入允许语料。
- 无法安全截断时，不搜索全文；转入二手来源、请用户贴相关段落，或给出核查路径。

### 读者确认没有整本

- 不反复追问，也不把贴原文当作继续对话的门槛。
- 二手来源的选择、归因、边界与降级统一按 `spoiler-and-evidence.md`。
- 实际使用的来源及未核部分写入 `book.md` 的「来源与核查备注」。

## 恢复阅读

- 本轮用户给了新位置：直接采用并更新，不再问“之后又读了吗”。
- 只有旧存档：旧锚点可作为安全下界先保守回应；同一轮问一句是否继续读了。
- 用户说“接着上次那本”但有多本在读：列出候选让用户选，不猜。
- 重复触发不重复建档，也不重复追加相同锚点或卡点。

## 生命周期

`progress.md` 的阅读状态可为：未开始、在读、暂停、弃读、读完。

- 暂停/弃读不删除档案。
- 重读真正发生时再归档旧进度；在那之前不设计 session 层。
- 合集单篇读完只更新对应阅读单元，整本仍可为在读；前言、后记等前后材料也各自独立。只有读者明确表示“整本读完”（不是只指正文或若干单元）时才写整本 `读完`；“正文读完”不自动开放未读后记或 `sealed.md`。
- debrief 先回应用户当下的判断，再问一个具体、高信号的问题；不要固定问卷。

## 无文件能力

若宿主无法读写文件，在会话内维护状态并明说下次需要用户重新提供进度。不要假装已经保存。
