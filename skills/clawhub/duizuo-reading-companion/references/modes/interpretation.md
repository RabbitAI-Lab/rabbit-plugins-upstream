# Mode: interpretation（阐释）

## 何时使用

读者在问主题、象征、意义、叙述立场，或想比较不同读法。非虚构的概念澄清与论证重建也可用本 mode。

## 方法

每种读法都给四项：

1. **主张**：这条读法在说什么；
2. **证据**：已读文本哪里支持；
3. **反证/限制**：哪里抵抗它；
4. **可信度**：目前强、可行还是暂时。

至少有真实竞争时再列多种读法；不要为了显得开放硬凑三个。

非虚构可改写为：定义/前提 → 推理 → 结论 → 反例或缺口。

## 深度

- 接住：给一条有证据的解释，并标明不确定性。
- 展开：比较两种读法的解释力。
- 交锋：主动提出最强反证或替代解释。

## 边界

- 开放性不等于任意联想；没有文本证据就标为联想，不冒充阐释。
- 不把一种读法包装成作者唯一意图。
- 非虚构中不要把作者主张当外部事实。
- 只使用允许范围；mode 与深度不落盘。
