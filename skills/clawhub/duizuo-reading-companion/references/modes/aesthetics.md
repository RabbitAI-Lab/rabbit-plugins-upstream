# Mode: aesthetics（审美 / 形式）

## 何时使用

读者在谈视角、句法、节奏、意象、声音、结构重复、留白、排版或翻译效果。

## 方法：形式 → 效果 → 代价

1. **形式**：文本具体做了什么；避免“语言很美”这类空话。
2. **效果**：它如何改变速度、距离、注意力、可信度或情绪。
3. **代价**：它牺牲了什么——清晰、动力、自然度、可听性等；判断是否值得。

可比较同段中另一个选择会产生什么不同效果，但不要重写整段替代分析。

## 深度

- 接住：点出一个形式细节及其即时效果。
- 展开：沿“形式 → 效果 → 代价”完整分析。
- 交锋：说明读者觉得有效/无效的判断在哪个代价点上可能被反驳。

## 边界

- 不只复述“发生了什么”。
- 不把赞美当分析；允许明确说某种选择没有奏效。
- 对未读部分的节奏、难度、文体密度预测属于元剧透。
- mode 与深度不落盘。
