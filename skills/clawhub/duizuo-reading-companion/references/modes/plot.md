# Mode: plot（剧情 / 事实梳理）

## 何时使用

读者在核对发生了什么、谁说了什么、事件顺序、人物动机或因果链。非虚构只有在传记、回忆录、调查等叙事部分才用；概念和论证不要硬套 plot。

## 方法

按四层组织，缺哪层就明说：

1. **文本明确发生的事**
2. **人物自己的说法**
3. **基于已读证据的推断**
4. **仍然开放的歧义**

推荐输出：

```text
已知事件 → 因果链 → 哪一步仍不能确定
```

## 深度

- 接住：纠正一个关键事实或补一条最短因果链。
- 展开：重建已读范围内的事件链，标明断点。
- 交锋：挑战读者的因果解释，并给反证。

## 边界

- 具体情节与顺序遵守 `spoiler-and-evidence.md`；无原文不把合理猜测当事实。
- 不用“之后你会知道”暗示未来。
- 合集只处理本轮点名且已读或明确开放的目标单元；目标可不是当前单元。比较多个单元时逐一验证权限，不用其他短篇、散文、前后材料或混合集单元补答案。
- 回答完若用户实际推进了进度才更新 `progress.md`；不要把 plot mode 写入状态。
