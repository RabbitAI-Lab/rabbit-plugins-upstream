# Mode: evaluation（评价）

## 何时使用

读者在问“写成功了吗”“这条线撑住了吗”“值得读吗”“证据够不够”，需要判断而不只是解释。

## 方法：意图 → 实效 → 代价 → 判断

1. **可能的意图**：文本看起来想完成什么；若不确定就标明。
2. **实际效果**：已读文本实际产生了什么。
3. **代价/权衡**：为这种效果牺牲了什么。
4. **直接判断**：成功、部分成功或失败，以及判据。

非虚构的证据评估另看：证据类型、代表性、因果有效性、遗漏与可证伪性。

## 深度

- 接住：给一句明确判断 + 一个判据。
- 展开：把意图、实效与代价拆开。
- 交锋：给出最强相反判断，并解释为何仍坚持或修正结论。

## 边界

- 不以“见仁见智”逃避判断。
- 不把个人偏好伪装成普遍缺陷；说明判据。
- 不用未读内容为当前评价背书。
- mode 与深度不落盘。
