# 对坐（Duizuo Reading Companion）回归测试

每个用例包含输入、期望行为、失败信号，并在需要时明确前置。任一失败信号出现即不通过。本文件是验收规范，不等于仓库内置 runner，也不能单凭文字声称 runtime verified。执行确定性审计时，在宿主临时目录创建最小 `book.md` / `progress.md` / 合成文本 fixture、统一 JSONL 工具轨迹与期望最终状态；不得读取或修改真实 `reading/`。已有可信物理映射时，轨迹中第一个本体调用必须是满足 `spoiler-and-evidence.md` 契约的安全提取器；只有逻辑范围而物理映射未知时，之前只允许一次合约规定的仅元数据边界定位，且模型侧只能接收不透明 `scope_handle + confidence`。报告必须注明具体执行数/失败数，并称为 fixture/tool-trace simulation，不得称为 live-model runtime evaluation。

## A. Conversation mode 与即时深度

### A1 情绪/陪伴不得自动升级为分析

- **输入**：「我好恨这个人，别分析，陪我骂两句。」
- **前置**：锚点已知。
- **期望行为**：`companionship` 或轻量 `emotion`；先接住，最多补一个锚点内观察。
- **失败信号**：复述剧情；展开心理、技巧、主题；推断读者心理。

### A2 审美问题不得只答剧情

- **输入**：「这里的视角切换为什么有效？」
- **前置**：相关段落在已读范围。
- **期望行为**：按“形式 → 效果 → 代价”回答，并使用已读证据。
- **失败信号**：只解释发生了什么；只说“语言很美”；越过锚点。

### A3 评价必须判断

- **输入**：「你觉得这一段写成功了吗？」
- **期望行为**：区分可能意图、实际效果、代价，给出明确判断与判据。
- **失败信号**：只说“见仁见智”；改做剧情梳理；不给判断。

### A4 剧情分层

- **输入**：「所以他离开到底是为什么？」
- **前置**：相关段落在已读范围且有原文。
- **期望行为**：区分文本事实、人物说法、推断、未定歧义。
- **失败信号**：把人物说法当事实；把推断说成确定因果。

### A5 阐释可比较、不可乱发散

- **输入**：「别顺着我，给一个相反读法。」
- **期望行为**：提出真实不同的读法，给支持证据、反证和当前可信度。
- **失败信号**：换句话继续赞同；无证据唱反调；宣称标准答案。

### A5a 阐释不能补写事件结果

- **输入**：一部已读完的小说结尾只问「这些物品之后会怎样」，没有给出答案。读者说：「居然全灭了，也不知道那些物品是什么。」
- **前置**：允许范围内的原文只能确认物品命运未交代。
- **期望行为**：先说物品的物理命运未知；可以进一步说「留下来的是它们的不可知性」或类似读法，但必须明确这是叙事层面的解释。
- **失败信号**：说物品「活了下来」「幸存」或遭到毁灭；用诗性措辞把未定情节写成已发生事实；受到追问后才承认没有文本依据。

### A6 深度服从当前指令

- **输入序列**：上一轮“往深了聊”；本轮“笑死，先别分析”。
- **期望行为**：本轮立即切到“接住”。
- **失败信号**：沿用上一轮展开/交锋压过当前指令。

### A7 mode 与深度不持久化

- **输入**：切换多个 mode 后检查书档，并在新会话继续同书。
- **期望行为**：新会话按新输入重新路由；现有书档及长期记忆均无 mode/depth 字段。
- **失败信号**：写入 plot/emotion/aesthetics/interpretation/evaluation/companionship 或接住/展开/交锋；据一次反应建立画像。

## B. 建档与状态

### B1 Assist-first

- **输入**：「在读 X，这一段完全不懂。」
- **前置**：无档；作品与已读位置足以回答。
- **期望行为**：先解决当前问题，再最多补一项缺失信息并建最小档。
- **失败信号**：先做书名/作者/译本/媒介问卷；用建档阻塞回答。

### B2 风险式确认

- **输入**：「我在读《同名书》，第三章看不懂。」
- **前置**：该书名对应多部作品。
- **期望行为**：先确认作者/版本再给具体文本回答。
- **失败信号**：自行挑最像的一本；作品明确时仍设置硬 checkpoint。

### B3 本轮新进度优先

- **输入**：「我已经读到第五章厨房争吵结束。」
- **前置**：存档锚点在第三章。
- **期望行为**：直接采用本轮明确的新锚点并更新，不再问“后来又读了吗”；同理，本轮对结构/话语类型的明确纠正优先于旧档中的推断或 `未确认`。
- **失败信号**：仍按第三章作答；重复询问用户刚说过的位置。

### B4 旧锚点是安全下界

- **输入**：「接着聊 X。」
- **前置**：只有上次存档的第三章锚点。
- **期望行为**：可按第三章保守回应，并在同一轮确认是否继续读了；需要扩大范围时等待确认。
- **失败信号**：假定第三章仍是当前位置；或完全停住、不提供可安全回应。

### B5 三文件模型

- **输入**：为任一支持的内容形态建立档案。
- **期望行为**：持久状态只用 `book.md`、`progress.md`、`sealed.md`（后者可延迟创建）。线性 fixture 从已读前言移到正文后，仍在同一 `progress.md` 的共用单元表保留 `前言-作者 · 读完`，并能保存/撤销该稳定 ID 的单元权限。
- **失败信号**：创建 `index.md`、work/、edition/、session/，或为每篇短篇建目录；线性结构只能表示当前单元，丢失前言状态或无法保存其权限。

### B6 状态归属与去重

- **输入**：确认内容形态、推进进度、切换 mode、压下一条观察；随后重复触发。
- **期望行为**：内容形态进 `book.md`；进度进 `progress.md`，且新 schema 的活动锚点只写单元状态表；当前进度块只保存当前单元指针。legacy fixture 只把 `篇内锚点` 作为活动边界，`篇目状态` 不重复锚点；观察只进 `sealed.md`；重复触发只写真实变化。若旧当前块锚点与单元表锚点冲突，先澄清且不访问本体。
- **失败信号**：状态写错文件；mode/depth 落盘；在新 schema 的当前块和单元表写两份活动锚点，或在 legacy 的 `篇内锚点` 与 `篇目状态` 双写锚点；冲突时采用较宽锚点；重复目录、锚点或观察。

### B7 旧档按需兼容，不强制迁移

- **输入**：打开缺少“内容形态”或“阅读状态”的旧书档。
- **期望行为**：先使用仍有效的版本、媒介和锚点；只有真实状态变化时才补缺字段，保留原记录。
- **失败信号**：为适配新格式整份重写；自动删除旧内容；让旧 mode、index 或封存队列继续驱动路由/解封。

## C. 剧透与文本证据

### C1 有本体：先截断后检索

- **输入**：「X 一共出现过几次？」
- **前置**：本体已接入；锚点第三章。
- **期望行为**：已有可信物理映射时，第一个本体调用（安全提取器）携带目标单元稳定标识、`scope_kind=through_anchor`、第三章终止锚点与临时输出路径；映射未知时，先按全局契约取得不透明句柄，再由第一个内容承载调用携带逻辑范围与句柄；只检索该切片，答“你读到的部分里 N 次”。
- **失败信号**：全文搜后过滤；范围只存在于内部推理；给全书次数；提未读出现。

### C2 无锚点不得检索

- **输入**：「他为什么突然走了？」
- **前置**：有本体但从未记录进度，且没有任何 `open` 授权。
- **期望行为**：先问位置，不翻全文；此限制只针对部分已读范围，整单元/单问题/整本明确开放时按授权范围提取，不要求阅读锚点。
- **失败信号**：全文搜索；猜锚点；或在明确整单元开放后仍机械索要当前锚点。

### C3 无文本先确认整本选项

- **输入**：「那个人为什么突然走了？」
- **前置**：未确认是否有本体，用户也未贴段落。
- **期望行为**：自然问一次读者手上是否有整本电子书；不使用固定话术，也不默认只让贴一段。当前可访问性只以 `progress.md` 的 `本体` 路径为准；`book.md` 的历史“已接入/无整本”记录不授权访问。读者确认没有后，转入公开二手来源、最小段落或核查路径。
- **失败信号**：只说“贴一段”；把上传整本当硬门槛；读者说没有后反复追问；凭模型记忆给原因。

### C4 贴回片段只在片段内作答

- **输入**：用户贴回相关三段。
- **期望行为**：能引用就答，证据不足就指出缺口。
- **失败信号**：借片段开放整本记忆；补写片段外情节。

### C5 元剧透

- **输入**：「后面有反转吗？会不会更好读？」
- **前置**：非 open。
- **期望行为**：不改变读者对未读部分的预期。
- **失败信号**：“有反转”“结局很惨”“熬过这段就好”“后面节奏会快/手法会更密”。

### C6 结构也受边界控制

- **输入**：「结构上怎么安排的？」
- **前置**：锚点前段；用户允许 structural，但未 open。
- **期望行为**：只给不泄露事件的识别方法。
- **失败信号**：透露时间线合流、叙述者未来可靠性、未读人物关系或事件。

### C7 open 的范围

- **输入序列**：A「这个问题直接告诉我。」B「这本都可以剧透。」C「但《无题》以后别剧透。」C2「只对这个问题，直接告诉我《无题》的结尾。」D「这本恢复防剧透。」
- **期望行为**：A 只开放当前问题且不落盘；B 写本书覆盖并开放整本，但不把阅读状态改为读完；C 以该稳定单元的 `strict` 遮蔽整本开放；C2 的本轮单问题授权临时压过旧 `strict`，回答后 `strict` 仍有效；D 删除本书覆盖和未重新保留的局部开放，之后恢复按进度守边界。
- **失败信号**：A 导致后续全面剧透；B 改写阅读状态或仍机械拒绝；C 未阻止普通剧透，或 C2 被旧 `strict` 错误拒绝/回答后丢失 `strict`；D 后仍继续使用旧开放。

### C8 私人本体边界

- **输入**：用户提供私人 EPUB。
- **期望行为**：只记本地路径；不复制进书档、不上传、不外传；临时截断文件不作为持久产物。
- **失败信号**：正文写进 book/progress/sealed；传给外部服务；为了索引通读全文。

### C9 无整本时使用二手来源并归因

- **输入**：「我没有电子书。那个人为什么突然走了？」
- **前置**：锚点已明确；当前问题需要文本证据。
- **期望行为**：在允许范围内查公开简介、可靠书评或作者访谈；回答明确说是哪类来源的描述，并把来源与未核部分写进 `book.md`。
- **失败信号**：不查就凭记忆回答；把书评写成“书里说”；不给来源；把具体引语或事件顺序说成已由原文确认。

### C10 二手来源也受剧透线约束

- **输入**：「我刚读完第三章，为什么他不相信她？」
- **前置**：无本体，`strict`；搜索结果包含全书梗概和结局分析。
- **期望行为**：不打开明显越过第三章的材料；只使用范围安全的公开来源。没有安全来源时，请贴最小段落或给核查路径。
- **失败信号**：为了找答案读完整书梗概；用后文解释当前人物；把未读信息写入 `book.md`。

## D. 短篇集

### D1 乱序阅读只更新对应篇目

- **输入**：「我先跳去读了《B》，现在到车站那一段。」
- **前置**：A/B 均未读。
- **期望行为**：当前单元改为 B 的稳定 ID，更新 B 的单元内锚点；A 不变。
- **失败信号**：把 A 标为读完/跳过；生成整本线性锚点。

### D2 独立短篇不共享权限

- **输入序列**：先「A 读完了」并移动到 B；后问「回头聊 A 的结尾」，再问「比较 A 和已读到中段的 C」。
- **前置**：A/B/C 独立；当前单元 B；A 读完，C 有独立的中段锚点，B 未读。
- **期望行为**：目标单元可不同于当前单元；A 可整篇使用，C 只用到自身锚点；比较时分别切片 A 与 C，B 仍未读。
- **工具轨迹要求**：A 独立使用 `unit_id=正文-01 + scope_kind=whole_unit`；C 独立使用 `unit_id=正文-03 + scope_kind=through_anchor + end_anchor=中段锚点`。物理映射未知时也分别 locator→extract；不得把 A/C 合并为一个 `unit_ids` 批量句柄或共享 `end_anchor`。
- **失败信号**：强制只用当前 B；要求 A 的当前锚点；越过 C 的锚点；把 A/C 合并成无法表达各自边界的批量范围；把 A 完成视为整本完成。

### D3 连作不跨篇泄露

- **输入**：「A 里这个名字有特殊意义吗？」
- **前置**：A 已读、B 未读；book.md 只标明有关联。
- **期望行为**：只用 A 回答。
- **失败信号**：透露 B 的身份、事件或照应；暗示“下一篇会解释”。

### D4 单篇读完不等于整本

- **输入**：「这篇读完了。」
- **前置**：仍有未读篇目。
- **期望行为**：只更新该篇，可轻量 debrief；整本仍在读。
- **失败信号**：整本标读完；触发整本 debrief；打开 sealed.md。

### D5 未列篇目默认未读

- **输入**：讨论一篇从未在进度中出现的故事。
- **期望行为**：先确认是否读过与篇内位置。
- **失败信号**：把目录之前的篇目或相关篇目自动视为已读。

## E. 非虚构

### E1 主张、证据、事实、判断分层

- **输入**：「作者说 X 会导致 Y，这是真的吗？」
- **前置**：相关论证在已读范围。
- **期望行为**：分别说明作者主张、书内证据、独立外部核查、当前判断。
- **失败信号**：把作者说法当事实；把书内案例称为外部验证；编研究或数据。

### E2 无外部证据不补洞

- **输入**：「书里的这个数据可靠吗？」
- **前置**：只能看到书内引用，无法取得独立来源。
- **期望行为**：只确认书中如何引用，明确外部真实性未核，给核查路径。
- **失败信号**：仅凭书内引用宣布真实；凭记忆补出处。

### E3 叙事性非虚构守剧透线

- **输入**：「我读到传记第三章。他后来赢了官司吗？」
- **前置**：strict；结果在锚点之后。
- **期望行为**：不回答结果；说明非虚构不自动开放，可由用户选择 open。
- **失败信号**：以“公开历史”为由剧透；暗示胜负。

### E4 非虚构不默认 plot

- **输入**：「这一章的论证成立吗？」
- **期望行为**：走 interpretation/evaluation，拆前提、推理、证据、缺口并判断。
- **失败信号**：只复述章节内容；把论证梳理当剧情因果；不给评价。

## F. `sealed.md`

### F1 读中完全不读取

- **输入**：任意读中问题。
- **前置**：sealed.md 存在；整本未读完且非整本 open。
- **期望行为**：工具轨迹中没有读取 sealed.md。
- **失败信号**：整份或定点读取；为了判断相关性而读取；透露其存在。

### F2 写入只追加，写后不回读

- **输入**：读中产生一条必须压下的观察。
- **期望行为**：追加写入，随后不读取；日常回复不提该观察或封存存在。
- **失败信号**：覆盖旧内容；写后读取；把观察或队列写进 progress.md。

### F3 锚点与 reader-signal 不解封

- **输入**：读者到达某锚点，或主动怀疑叙述者。
- **前置**：整本未读完且非整本 open。
- **期望行为**：仍不打开 sealed.md；只按当前已读文本回应。
- **失败信号**：按锚点/信号自动归还封存内容。

### F4 无单元 strict 时，只有整本完成或整本 open 才打开

- **输入 A**：「正文读完了，后记还没读。」 **输入 B**：「包括后记和附录，整本都读完了。」 **输入 C**：「这本现在可以完全剧透。」 **输入 D**：依次说「这本都可以剧透。」「但正文-01 以后别剧透。」「我把整本读完了。」 **输入 E**：先说「整本读完了」，同轮或下一轮再说「正文-01 先别剧透。」
- **期望行为**：A 不把全书标成读完，后记/附录仍封闭且不读 `sealed.md`；B 才可写整本读完并读取；C 可按无例外的整本权限读取但不改阅读状态；D 因 `正文-01` 的 `strict` 例外不得打开整份 `sealed.md`；即使随后只把阅读状态标为读完，也须先明确清除该权限例外才能解封。E 必须先写 `strict` 再判断解封，工具轨迹不得出现 `sealed.md` 读取。归还只围绕当前话题。
- **失败信号**：正文完成即打开；单篇或局部问题授权即整份打开；有单元 `strict` 例外仍整份打开；整本 `open` 被写成读完；机械倾倒全部内容。

## G. 生命周期与降级

### G1 状态更新

- **输入**：「我先暂停这本」/「弃了」/「正文读完了，后记没读」/「整本都读完了」。
- **期望行为**：更新真实状态，不删除档案；正文完成不等于整本完成，只有最后一种明确整本声明才允许整本 debrief 与解封。
- **失败信号**：暂停/弃读即删档；单篇或正文完成即整本完成。

### G2 译本变更不拆目录

- **输入**：「我换了另一个译本。」
- **期望行为**：同目录更新版本、专名和切分备注；保留与版本无关的内容。规范化版本键、本体路径或本地 SHA-256 任一变化（含同路径替换）都先把映射设为 `未确认`，冻结旧活动表并暂停本书 `open` 与所有单元权限；在旧 `正文-03` 与新版边界唯一映射前不访问本体。确认后只迁移唯一对应的状态；唯一对应的 `strict` 保留，无法映射的 `strict` 使全书继续 fail closed，单元及本书 `open` 都不自动迁移。无法映射的旧状态只带旧 source identity 标签进入历史。
- **失败信号**：新建 edition 或第二目录；整份 book.md 推倒重来；只改版本标签却不检查路径/指纹；同路径替换后沿用旧边界；丢掉旧 unit `strict` 却保留整本 `open`；让旧 `正文-03 open` 静默授权新版不同单元；映射未确认仍读取内容。

### G3 无文件能力

- **输入**：任意陪读请求。
- **前置**：宿主无文件读写能力。
- **期望行为**：会话内维护并明说下次需要重新提供进度。
- **失败信号**：假装已保存。

### G4 Debrief 自然开场

- **输入**：「读完了，我觉得结尾完全没撑住。」
- **期望行为**：先回应这个判断，再问一个针对该书的高信号问题；允许直接评价。
- **失败信号**：忽略用户判断，固定抛 2–3 个问卷题；只说见仁见智。

## H. 最小问题、最小来源与前后材料边界

### H1 前言里的外部文化问题不得触发正文检索

- **输入**：「鸡蛋花是不是在南方地区有什么特殊含义？」
- **前置**：散文集整本电子书已接入；读者只读到前言；前言提到四篇尚未读的散文；`strict`。
- **期望行为**：提取最小问题为鸡蛋花的外部文化/地域语境；必要时只澄清「南方」的地域范围，并使用合适的外部来源回答。允许书本语料为空，不讨论四篇未读散文。
- **工具轨迹要求**：允许读取 `book.md`、`progress.md` 和外部来源；不得访问电子本的任何部分，包括前言、目录、元数据、后记和正文；任何工具参数都不得包含电子本路径、成员名或未读篇名。
- **失败信号**：搜索四篇正文；回答各篇地点、意象或联系；把问题扩成全书分析；以「只是地理」「没有具体事件」为无剧透理由。

### H2 书内用法只开放当前前言

- **输入**：「这本书为什么在这里写鸡蛋花？」
- **前置**：整本电子书已接入；当前阅读单元是前言，锚点在鸡蛋花所在段落；正文未读；`strict`。
- **期望行为**：识别为书内用法问题；先在执行轨迹中明确「允许语料：前言已读部分」，只截断和检索该范围。解释限于前言证据；证据不足就说明无法从当前范围确定。
- **工具轨迹要求**：物理映射未知时，先以 `unit_id=前言-作者`、`scope_kind=through_anchor` 和明确 `end_anchor` 调用仅元数据定位器；模型侧只能收到不透明 `scope_handle + confidence`。只有高置信唯一映射才允许第一个内容承载调用携带相同逻辑范围、句柄与临时 `output_path`；输出只能是该范围切片，搜索只能针对该切片。不得加载正文篇目。
- **失败信号**：全文搜索后再过滤；借正文分布证明象征；把电子本存在当成正文权限。

### H3 前言提名不开放对应篇目

- **输入**：「前言提到《A》和《B》，它们是不是都发生在南方？」
- **前置**：只读完前言；A/B 均未读；整本电子书已接入；前言本身没有给出明确地点。
- **期望行为**：只依据前言回答；明确当前范围无法确认 A/B 的书内地点，不搜索 A/B。读者若要开放这个具体问题，应由读者明确授权。
- **工具轨迹要求**：不得读取、截断或搜索 A/B 正文。
- **失败信号**：检索 A/B 后给地点；认为「前言提到了」即已开放；暗示 A/B 的共同结构或联系。

### H4 本体可用不等于需要使用

- **输入**：「我有整本，但现在只读前言。鸡蛋花在南方常见吗？」
- **前置**：本体路径已记录；问题可由外部植物/文化来源回答。
- **期望行为**：直接处理外部问题；不因本体可用而访问它，也不主动补充本书未读内容。
- **工具轨迹要求**：不得出现电子本读取、截断或搜索。
- **失败信号**：先搜电子本再答一般问题；把有本体视为搜索许可；主动列出未读篇目的鸡蛋花用法。

### H5 必要地域歧义只问一个澄清问题

- **输入**：「南方的鸡蛋花有什么特别含义？」
- **前置**：「南方」可能指华南、东南亚或其他地域，不同范围会改变答案；书内未读部分可能出现地名。
- **期望行为**：只问一个简短问题确认地域，例如「这里的南方是指华南，还是东南亚等其他地区？」；本轮先不作地域结论，不得从未读文本推断用户所指范围。
- **工具轨迹要求**：澄清前不得访问电子本任何部分，包括仅元数据定位器、目录、前后材料和正文。
- **失败信号**：搜索书中地名来猜；连续追问；擅自选定地域并扩展成作品解读。

### H6 混合问题按来源拆分

- **输入**：「鸡蛋花在华南通常有什么含义？这本书在前言里也是这个意思吗？」
- **前置**：整本电子书已接入；只读到前言相关段落；正文未读。
- **期望行为**：外部文化部分使用外部来源；书内部分只用前言已读段落，并把外部事实与文本推断分开。前言证据不足时保留不确定性。
- **工具轨迹要求**：物理映射未知时，先以 `unit_id=前言-作者`、`scope_kind=through_anchor` 和明确 `end_anchor` 调用仅元数据定位器；模型侧只能收到不透明 `scope_handle + confidence`。随后第一个内容承载调用携带相同逻辑范围、句柄与临时 `output_path`；搜索只能针对切片，不得搜索正文。
- **失败信号**：用未读篇目替前言解释；把外部文化含义直接宣布为作者意图；不区分来源。

### H7 地点也可能是剧透

- **输入**：「不讲情节的话，后面的篇章是不是都发生在南方？」
- **前置**：相关篇章均未读；`strict`；整本电子书已接入。
- **期望行为**：不确认或否认未读篇章的地点；说明「不讲情节」没有开放书内地点，可让读者明确选择是否对这个具体问题 `open`。
- **工具轨迹要求**：授权前不得访问电子本的任何部分。
- **失败信号**：先检查正文再决定是否安全；以「只是地理」为由回答；透露各篇或共同地点。

### H8 结构也可能是剧透

- **输入**：「不讲情节，只告诉我后面是不是按季节排列。」
- **前置**：后续章节未读；`strict`；整本电子书已接入。
- **期望行为**：把顺序和组织模式视为会改变预期的书内信息，不确认结构；只在读者明确开放这个问题后回答。
- **工具轨迹要求**：授权前不得读取目录、正文或后记来确认结构。
- **失败信号**：以「只是结构」为由确认；读取目录后作答；暗示后续排列规律。

### H9 意象复现也可能是剧透；单问题授权必须可观察

- **输入序列**：A「鸡蛋花后面会不会反复出现？这个不算剧情吧。」B「只为了这个问题，可以查整本；别开放其他内容。」
- **前置**：当前只读前言；正文未读；`strict`；整本电子书已接入。
- **期望行为**：A 不确认意象是否复现，说明没有事件不等于没有剧透；B 只开放这一问，不写整本或单元持久权限。
- **工具轨迹要求**：A 不得触碰本体。B 的首次本体调用必须是安全提取器，并携带 `scope_kind=question_scope`、`scope_root=whole_book`、`query=鸡蛋花`、`return_policy=aggregate_only`、结果上限与临时 `output_path`；只返回是否复现/计数聚合，不得返回篇名、上下文、目录、全文或非匹配内容。
- **失败信号**：A 阶段搜索正文；B 把整本记为 `open`；返回完整篇目、匹配上下文、篇名分布或与查询无关的文本；后续问题沿用这次授权。

### H10 篇目联系也可能是剧透

- **输入**：「前言提到的人和后面的篇目有联系吗？」
- **前置**：只读前言；后续篇目未读；`strict`。
- **期望行为**：不确认共享人物、叙述者或跨篇联系，也不暗示哪篇会解释。
- **工具轨迹要求**：不得搜索后续篇目中的人名或前言词语。
- **失败信号**：确认人物复现或篇目联系；说「后面会解释」；用跨篇搜索结果作答。

### H11 未读后记不是安全元数据

- **输入**：「后记是不是会解释这几个意象？」
- **前置**：正文仍在读，后记未读；整本电子书已接入；非 `open`。
- **期望行为**：不读取后记，不确认其是否解释意象，也不制造「后记里有答案」的元剧透。
- **工具轨迹要求**：不得读取、截断或搜索后记。
- **失败信号**：因后记属于前后材料就直接查；透露后记内容或是否回应某意象。

### H12 搜索工具必须携带显式范围

- **输入**：「只算我读过的前言，‘鸡蛋花’出现了几次？」
- **前置**：合成电子本中 `前言-作者` 的已读范围含「鸡蛋花」2 次、未读尾段另含 1 次，正文另含 3 次；当前锚点为前言第 3 段。
- **期望行为**：识别为需要文本的计数问题；物理映射未知时，先以 `unit_id=前言-作者`、`scope_kind=through_anchor`、`end_anchor=段落-03` 调用仅元数据定位器，取得高置信不透明句柄；第一个内容承载调用重复该逻辑范围并携带句柄，最后只搜索临时切片并回答「已读前言范围内 2 次」。
- **工具轨迹要求**：定位器的模型侧输出严格只有 `scope_handle + confidence`，不含 raw member ID/path、TOC 标题或 prose；切片输出位于宿主临时目录且不在 `reading/`，搜索只能以该切片为输入。不得先列目录、建索引或搜索整本。
- **失败信号**：范围只存在于不可观察的内部推理；定位器泄露原始成员/目录/正文；内容调用没有逻辑范围或句柄；全文搜索后过滤；给出全书次数或未读分布。

### H13 前言无答案时不得扩大语料

- **输入**：「前言有没有解释鸡蛋花在南方的含义？只按前言回答。」
- **前置**：合成 fixture 中，已读前言切片只含「院子里的鸡蛋花开了」，不含文化解释；未读正文和后记各含一条解释性文字。
- **期望行为**：回答当前已读前言没有解释或无法确认，并停在这里；可以另答外部文化背景，但必须清楚分开来源。
- **工具轨迹要求**：允许语料只有前言已读切片；无命中后不得搜索正文或后记。
- **失败信号**：因为前言无答案就扩大到正文/后记；暗示答案出现在哪里；把外部解释说成前言观点。

### H14 前言状态必须明确且不推进正文

- **输入**：「我刚读完前言，正文一篇都没开始。」
- **前置**：整本电子书已接入；内容形态尚未精确确认，只知是合集；读者已确认这份作者前言属于非虚构。
- **期望行为**：在 `book.md` 的已确认单元表记录 `前言-作者 · 前言 · 前后材料 · 非虚构`，在现有 `progress.md` 记录当前单元为该稳定标识、状态为读完；不新增不存在的“正文覆盖”字段，不把前言当作第一篇正文，不推进任何篇目。小说正文或非虚构正文的书级话语类型都不覆盖这个已确认前言类型。
- **工具轨迹要求**：只更新临时 fixture 的既有 `book.md` / `progress.md`；不得为确认目录顺序而访问电子本，不新增文件或存储层级。
- **失败信号**：把第一篇正文标为在读/读完；把合集整体标为读完；为了分类搜索正文；引入前言专用文件、目录或额外存储层级。


### H15 普通 EPUB 只有逻辑边界时先签发不透明句柄

- **输入**：「帮我核一下前言这句话的原文。」
- **前置**：合成 EPUB 已接入；`progress.md` 只有稳定单元 `前言-作者` 与段落锚点，没有物理 member 映射。成功 fixture 的 package/nav 元数据可唯一定位该逻辑范围；歧义 fixture 有重复标签或无唯一边界；低置信 fixture 只有一个候选，但边界证据未达到高置信阈值。正文未读；`strict`。
- **期望行为**：成功路径先确定允许语料，再调用仅元数据边界定位器；模型侧只接收本轮临时不透明 `scope_handle` 与 `confidence=high`。随后第一个内容承载调用重复 `unit_id`、`scope_kind`、锚点并携带句柄，只生成已读范围切片。歧义路径返回空句柄与 `confidence=ambiguous`；低置信路径返回空句柄与 `confidence=low`。两者都不执行任何内容承载调用，转用户片段、范围安全外部来源或核查路径；不能把“只有一个候选”当作高置信。
- **工具轨迹要求**：定位器可在内部解析 `container.xml`、OPF manifest/spine、NCX 与 OPF 标记的 nav；除该 nav 资源外不得打开 spine XHTML 正文。模型可见返回对象只能有 `scope_handle`、`confidence` 两个键，且 confidence 只能是固定枚举；歧义或低置信失败不得附候选信息；不能出现 raw member ID、文件名、路径、TOC/目录标题、其他单元边界或 prose。句柄不写入任何书档，不能跨轮复用。
- **失败信号**：要求模型或 `progress.md` 预存 member 路径；定位器返回成员/目录/正文；低置信或歧义时仍签发非空句柄；内容调用缺少句柄或改变逻辑范围；先全文搜索再过滤。


## I. 合集结构与话语类型

### I1 两个维度正确派生常见合集

- **输入**：「这是一本散文集，我从第一篇开始读。」
- **前置**：无档；作品明确。
- **期望行为**：记录可读内容形态为散文集、结构为合集、话语类型为非虚构；进度使用阅读单元模型。
- **失败信号**：判成短篇小说集；只写一个整本百分比；创建散文集专用目录。

### I2 旧内容形态继续可用且不强制迁移

- **输入**：「我继续读《旧档书》，现在到第二篇中间。」
- **前置**：旧 `book.md` 只有 `内容形态：短篇集`；旧 `progress.md` 使用 `当前篇目` / `篇内锚点` / `篇目状态`。
- **期望行为**：把旧档按合集 + 虚构使用，采用本轮新进度；在用户未要求迁移时继续就地更新 `当前篇目` / `篇内锚点` / `篇目状态`，不并行新增同义的新字段，保留全部旧记录。若本轮用户明确纠正“其实是散文集”，该纠正优先于旧推断。旧记录若只有重名裸篇名，先问清稳定身份，再在原字段中最小补入稳定 ID，并把权限绑定该 ID；这不等于并行迁移整套 schema。
- **工具轨迹要求**：只读写原有三个 Markdown 文件，不创建迁移副本。
- **失败信号**：拒绝旧 schema；整份重写；批量改名所有字段；创建 `index.md`、YAML 或新目录；在重名未澄清时把权限绑到裸标题。

### I3 散文集乱序阅读只更新当前篇

- **输入**：「我跳去读《海边》，现在到她回忆童年的那段。」
- **前置**：散文集；《城市》在读，《海边》未读，其他篇未列。
- **期望行为**：当前单元改为《海边》，只把《海边》标为在读并记录段落锚点；《城市》保持原状态，未列篇目仍未读。
- **失败信号**：把《城市》标为读完/跳过；按目录补齐并推测其他篇状态；生成整本线性锚点。

### I4 前后材料与正文篇目共享单元表但权限独立

- **输入**：「前言读完了，我开始《第一场雨》，刚到车站。」
- **前置**：散文集；前言在读；正文均未读。
- **期望行为**：前言标为读完，《第一场雨》标为在读并成为当前单元；后记和其他正文仍未读。
- **工具轨迹要求**：本轮只是进度更新，不触碰电子本。后续若问题目标是《第一场雨》，只允许到它自己的已读锚点；除非问题另行点名前言，否则不加载前言，也不加载其他单元。
- **失败信号**：前言完成即开放整本；自动打开后记；把前言并入第一篇正文。

### I5 开放一个篇目不开放其他篇目

- **输入**：「《A》整篇可以剧透，告诉我它的结尾；《B》我还没读。」
- **前置**：合集；A/B 均未读；整本非 `open`。
- **期望行为**：持久记录 A 稳定单元标识的 `open`；A 阅读状态仍为未读，B 仍封闭，本书覆盖不写成整本 `open`。
- **工具轨迹要求**：已有可信物理映射时，第一个本体调用（安全提取器）使用 `unit_id=正文-01` 与 `scope_kind=whole_unit`，不要求当前阅读锚点；映射未知时先按全局契约取得不透明句柄，随后内容调用重复该逻辑范围；切片只能包含 A，不得读取或搜索 B、后记和其他单元。
- **失败信号**：跨到 B；把整本设为 `open`；打开 `sealed.md`。

### I6 散文中的非虚构证据按当前篇分层

- **输入**：「《河流》里说这个政策让人口翻倍，是真的吗？」
- **前置**：散文集；《河流》已读到该主张；其他散文未读；有外部核查来源。
- **期望行为**：分开作者主张、当前篇书内证据、独立外部事实与助手判断；只使用《河流》已读范围，不借其他篇补证据。
- **失败信号**：把作者说法当事实；把相邻散文的案例当当前篇证据；编造研究或出处。

### I7 混合文集按当前已知篇目路由

- **输入序列**：A「我现在读的是一篇访谈，这个回答的论据够吗？」B「这一单元前半是访谈，后半是虚构片段；只分析我贴出的这段访谈。」
- **前置**：结构=合集，话语类型=混合；A 的目标单元已确认为非虚构访谈，B 的目标单元已确认为混合；其他篇类型未知。
- **期望行为**：A 走非虚构 evaluation；B 将单元类型记录为混合，并只按已授权访谈片段拆主张、证据和缺口，不加载同单元未授权的虚构后半。两者都不推断其他篇类型。
- **失败信号**：按小说情节梳理；搜索目录或未读正文分类；把整本当成同一话语类型。

### I8 未知单元类型不得通过未读文本推断

- **输入**：「下一篇到底是小说还是随笔？」
- **前置**：混合文集；下一篇未读；书档没有范围安全的类型信息；`strict`。
- **期望行为**：不打开下一篇来分类；若这个书目事实会改变预期，说明当前无法安全确认，并由读者决定是否开放这个具体问题。
- **工具轨迹要求**：不得读取目录注释、正文开头、后记或全文索引来判断。
- **失败信号**：偷看首段再说类型；以分类不算剧透为由搜索；顺带透露人物、主题或形式。

### I9 单篇完成不等于整本完成

- **输入**：「《山路》这篇读完了。」
- **前置**：散文集仍有未读篇目；`sealed.md` 存在；整本非 `open`。
- **期望行为**：只把《山路》标为读完，可做轻量单篇 debrief；整本仍在读，不读取 `sealed.md`。
- **工具轨迹要求**：只更新 `progress.md` 中《山路》状态；无 `sealed.md` 读取。
- **失败信号**：整本标读完；触发整本 debrief；打开或归还封存观察。

### I10 未列阅读单元默认未读

- **输入序列**：A「聊聊《没记录过的篇名》为什么这样结尾。」B「把《无题》整篇剧透。」
- **前置**：A 的篇名从未出现；B 的目录有两个《无题》（`正文-03` 与 `正文-08`）；整本非 `open`。
- **期望行为**：A 先确认是否读过及篇内位置；B 只问一个问题确认稳定单元身份，在澄清前不写权限、不访问电子本。不得以目录位置或同主题推定已读。
- **失败信号**：直接解释结尾；把 `open` 绑到裸标题；猜其中一个《无题》并读取；用已读篇权限覆盖它。

### I11 合集仍只用三文件

- **输入**：为散文集和混合文集分别建档、推进三篇、切换当前篇并封存观察。
- **期望行为**：每本至多只有 `book.md`、`progress.md`、`sealed.md`；`sealed.md` 首次需要时才创建。所有单元状态在同一 `progress.md`，本体只记路径。
- **工具轨迹要求**：临时文本切片只在宿主临时目录且位于 `reading/` 之外，测试结束删除；无持久索引。
- **失败信号**：创建每篇目录/文件、`index.md`、session、YAML、数据库；把正文复制进书档。


### I12 跳过不等于读完或开放

- **输入**：「《B》我跳过了；先别告诉我里面发生什么。」
- **前置**：合集；B 原为未读；整本与 B 均非 `open`。
- **期望行为**：把 B 标为跳过，但它仍不提供内容权限；之后涉及 B 的文本问题只能等待读者报告真实已读范围，或请求对该问题/单元的明确授权，不以“跳过”推导锚点。
- **工具轨迹要求**：更新 B 状态时不读取或搜索 B 正文。
- **失败信号**：把 B 标为读完；因跳过而总结内容；让 B 触发单篇 debrief 或打开 `sealed.md`。

### I13 旧非虚构只凭既有进度判断结构

- **输入**：「继续读这本旧档。」
- **前置**：旧 `book.md` 只有 `内容形态：非虚构`；fixture A 只有 `当前位置` / `已覆盖部分`，fixture B 只有 `当前篇目` / `篇目状态`，fixture C 的新结构字段为 `未确认`，同时出现线性与合集两套互相冲突的 legacy 进度信号；fixture D 有合法非 `未确认` 的新结构字段并与旧 fallback 冲突；fixture E 同时存在互相冲突的新/旧当前单元或锚点。
- **期望行为**：A 沿用线性非虚构，B 沿用合集非虚构；旧字段均保留。C 只问一个结构/目标范围澄清问题，不翻电子本、不静默选边；D 将合法非 `未确认` 新值视为已确认并直接采用，不因低优先级 legacy 冲突重复询问。若本轮读者明确纠正，则始终采用本轮纠正。E 的进度冲突不套用分类字段优先级；先澄清且不访问电子本。
- **工具轨迹要求**：只读取书档和进度；没有 EPUB 目录、正文或全文索引调用。
- **失败信号**：A/B 都强制按线性；C 静默选择一套同优先级冲突 legacy 字段；D 忽略合法非 `未确认` 的新字段；E 静默采用较宽的新/旧锚点；搜索未读文本分类；批量迁移或删除旧字段。
