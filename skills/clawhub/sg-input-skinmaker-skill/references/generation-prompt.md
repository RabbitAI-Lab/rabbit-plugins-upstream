# 皮肤背景图 · 图生图生成规范（Reference Prompt）

本文件是「搜狗输入法热词皮肤」图生图任务的**完整生成规范**。在下达图生图指令前应先阅读本文件，
按「**三层融合模型**」把最终给 AI client 模型的完整 prompt 组装出来。

## 最终 prompt 的三层融合模型（核心逻辑）

给 AI client 模型的完整 prompt 由**三部分融合**而成，缺一不可：

1. **方向层（固定，恒定不变）**：一句话总纲，表明生图大体方向。
2. **内置正向引导层（skill 内置，合规硬规则）**：见「§九 内置正向引导」，是**不可突破的红线**。
3. **用户自定义层（优化后）**：用户填写的风格 / 内容描述；**必须先用 skill 的内置逻辑对其做优化**，
   而不是把用户原话直接拼进去。

**组装原则（务必遵守）**：

- **内置逻辑优化用户输入**：用户自定义 prompt 不能原样透传。要先用本规范（§一~§七 的构图/配色/
  风格化约束 + §九 的合规红线）**重写 / 补全 / 净化**用户描述，剔除与红线冲突的内容，补上缺失的
  背景图属性，得到一段「优化后的用户自定义 prompt」。
- **优先级**：内置正向引导（§九 合规硬规则）> 方向层 > 优化后的用户自定义层。
  当用户诉求与合规硬规则冲突时，**以合规硬规则为准，静默丢弃或改写冲突部分**，不向图生图透传违规诉求。
- **融合顺序**：方向层 → 内置正向引导层 → 优化后的用户自定义层，拼成一段完整 prompt 下达。

产物用途：一张**适合作为手机键盘皮肤的横向背景图**，需「参考原图主体与配色 + 风格化 +
画面干净、留白充足、不出现文字」。

---

## 一、核心任务定义（先界定"是什么、不是什么"）

把**用户上传的这张图片作为唯一素材来源**，对其做 `%s` 风格的图生图，产出一张可作为皮肤 /
背景使用的成品图。

**这是**：在保留原图主体与可辨识特征的前提下，对其做风格化艺术演变，并优化为适合铺底的背景图。

**这不是**：
- 不是简单套滤镜 / 调色。
- 不是把原图元素完全推翻重画的自由创作。
- 不是与原图无关的另起炉灶生成。
- 不是把主体删除只留纯色 / 纯纹理背景。

---

## 二、输入图片的角色

上传图片是**唯一内容来源**，承担两个角色：

1. **风格演变的底图**：产物应能看出源自这张图 —— 主体、关键图形、文字、装饰的**可辨识特征**
   需保留。
2. **配色与构图的依据**：主色系、明暗层级、主体位置关系从原图提炼，不凭空引入。

**边界**：不得引入原图中不存在的其他主体、场景、物体、品牌或象征。

---

## 三、风格化程度（关系优先，保留"最低必要辨识度"）

原则：对原图元素做**适度**风格演变 —— 既不要「几乎不动地原样保留」，也不要「改到认不出 /
完全删除」。目标是保留元素的可辨识特征，同时明确呈现 `%s` 风格。

| 元素类型 | 处理约束 |
|---|---|
| 主体（人物 / 吉祥物 / 核心物件） | 保留可辨识的外形与特征，按 `%s` 风格重塑质感 / 笔触 / 光影；不改变其身份，不删除 |
| 文字 / logo / 标识 | 保持可读、位置与比例稳定；可做风格化描边 / 材质，但不改字义、不歪曲变形 |
| 装饰 / 点缀元素 | 可按风格适度增减细节以协调画面，但需与原图呼应，不堆砌无来源装饰 |
| 背景 / 环境 | 可较大幅度风格化，服务于「适合铺底」，避免与主体抢视觉 |

---

## 四、比例与构图（禁止变形）

- 主体元素只做**整体等比缩放**；**严禁横向 / 纵向拉伸、挤压、扭曲**导致比例失真。
- 先按目标画面尺寸规划构图，再把风格化后的元素自然融入。
- 画面**适当留白**，重心稳定、主体不贴边、不塞满；整体视觉服务于「作为背景铺底」。
- 若原图与目标画幅比例不一致，用留白 / 自然延展补足，**不得为凑比例激进裁切主体**。

---

## 五、配色系统

- **以原图主色系为基准**：提取原图主色、结构色、点缀色，围绕它们做风格化。
- 可为符合 `%s` 风格与审美做**适度**调整（饱和度 / 明度 / 冷暖微调）。
- **不得**把整体色系氛围替换成与原图完全无关的另一套颜色；不滥用无来源的霓虹色 / 撞色。
- 作为背景使用时，整体对比不宜过强，避免影响其上层 UI / 文字的可读性。

---

## 六、CLEAN 模式（背景图排除清单）

产物作为背景图，应干净、克制，**不得出现**以下瑕疵 / 杂讯：

- 明显的 JPEG 压缩噪点、色带、扫描痕迹、脏点、水印、二维码。
- 无意义的密集装饰、杂乱贴图、拼贴阴影、样机 / 相框 / 撕纸边效果。
- 与主体无关的额外文字、字幕、logo、日期、签名。
- 过曝 / 死黑等极端明暗，导致其上层 UI 不可读。

---

## 七、护栏（Guardrails · 硬性边界，务必遵守）

- 上传图片是**唯一素材来源**，产物每个主要元素都应能追溯到原图中真实存在的元素。
- **保留可辨识**：不把主体改到认不出，也不完全删除主体。
- **不变形**：主体仅等比缩放，严禁拉伸挤压。
- **配色不脱离原图主色系**。
- **适合背景**：留白得当、主体不喧宾夺主、不影响上层内容可读性。
- **不无中生有**：不引入原图不存在的主体 / 场景 / 品牌 / 文字。

---

## 八、prompt 组装方式（三层融合）

按「三层融合模型」组装最终 prompt。三层内容如下。

### 第 1 层 · 方向层（固定，原样使用）

```
参考输入图片的主体与配色，生成一张适合作为手机键盘皮肤的横向背景图，画面干净、留白充足、不要出现文字。
```

### 第 2 层 · 内置正向引导层（合规硬规则，见 §九）

把 §九 的 6 类合规硬规则作为正向引导写入 prompt。这是**不可突破的红线**，无论用户怎么描述都必须满足。

### 第 3 层 · 优化后的用户自定义层

不要直接透传用户原话。先用本规范对用户描述做**优化**：

1. **净化**：剔除与 §九 合规硬规则冲突的内容（如暴露、暴力、指向真人明星、幼态化等），静默丢弃。
2. **对齐背景图属性**：补上「适合横向键盘背景、留白、无文字、画面干净」等属性（若用户没提）。
3. **对齐构图/配色约束**：并入 §三~§六 的风格化程度、禁变形、沿用原图主色系、CLEAN 排除清单。
4. **保留合理诉求**：用户的正当风格 / 内容诉求（如「国潮风」「加樱花」「暖色调」）予以保留并润色表达。

得到一段「优化后的用户自定义 prompt」。若用户未提供任何描述，则由 §三 自动推演风格后再走上述优化。

### 融合模板

按下述骨架把三层拼成最终 prompt（`%s` = 目标风格，来自用户或自动推演）：

```
参考输入图片的主体与配色，生成一张适合作为手机键盘皮肤的横向背景图，画面干净、留白充足、不要出现文字。

【风格与内容】以 %s 风格对原图做适度风格化演变：保留主体可辨识特征（不原样照搬、也不改到认不出或删除），主体仅整体等比缩放严禁拉伸变形；配色以原图主色系为基准做适度调整，不整体换色；构图留白充足、主体不喧宾夺主、适合作为横向背景铺底；画面干净，不出现文字、水印、二维码、压缩噪点或杂乱装饰。{在此追加优化后的用户具体诉求，如：加樱花点缀 / 换暖色黄昏氛围 等}

【必须满足的画面规范（红线，优先级最高）】
1、着装与姿态：人物着装完整整洁，无露肩、露脐、低胸、紧身贴身、湿身、内衣外穿；衣物平整无破损、无撕裂、无滑落；姿态端正自然，无躺卧、无扭腰翘臀、无仰头张口等暗示性动作；
2、成年特征：人物为大学生年龄段（18岁以上），面部与体态呈成年特征，面部轮廓清晰不圆钝、五官为成人比例、非幼童脸型；头身比不低于1:6.5，不使用1:4至1:5的幼态或Q版比例；身形自然匀称，不刻意强调胸、腰、臀曲线；神态平和、自信或专注，不含娇媚、羞怯、含泪、咬唇、眼神上挑等表现；
3、纯背景：画面为纯背景插画，不含任何键盘/界面元素、设备外框或屏幕内容；
4、氛围：画面氛围明亮、平和或轻松，不含冲突、伤害、破坏等暴力血腥场景；
5、原创形象：人物为原创虚构形象，不指向任何真实存在的公众人物 / 明星；
6、人物关系：人物性别特征清晰明确；如出现多人，为同学、朋友关系，无过分亲密肢体接触。
```

**约束**：用户诉求与「必须满足的画面规范」冲突时，以后者为准，冲突部分静默丢弃或改写，
不得因用户描述而放宽任何一条红线。

---

## 九、内置正向引导（合规硬规则 · 不可突破的红线）

以下 6 类为 skill 内置的合规正向引导，**优先级最高**，任何用户自定义诉求都不得突破。
组装 prompt 时以正向表述写入（描述"应该是什么样"，而非罗列禁止项）。

1. **着装与姿态（含色情 / 低俗）**：人物着装完整整洁，无露肩、露脐、低胸、紧身贴身、湿身、
   内衣外穿；衣物平整无破损、无撕裂、无滑落；姿态端正自然，无躺卧、无扭腰翘臀、无仰头张口等
   暗示性动作。
2. **禁止未成年人性化**：人物为大学生年龄段（18 岁以上），面部与体态一致呈成年特征：面部轮廓
   清晰不圆钝，五官为成人比例，非幼童脸型；头身比不低于 1:6.5，不使用 1:4 至 1:5 的幼态或 Q 版
   比例；身形自然匀称，不刻意强调胸、腰、臀曲线；神态平和、自信或专注，不含娇媚、羞怯、含泪、
   咬唇、眼神上挑等表现。
3. **纯背景（键盘元素）**：画面为纯背景插画，不含任何界面元素、设备外框或屏幕内容。
4. **禁止暴力血腥**：画面氛围明亮、平和或轻松，不含冲突、伤害、破坏场景。
5. **禁止指向真人（明星）**：人物为原创虚构形象，不指向任何真实存在的公众人物。
6. **人物关系（LGBT 合规）**：人物性别特征清晰明确；如出现多人，为同学、朋友关系，
   无过分亲密肢体接触。
