# 搜狗输入法皮肤制作skill

## 用途

本 skill 运行在各种 AI client 应用中（如 workbuddy、Codex、Trae 等）。它把内置的**生图规范**与
**用户的风格描述（可选）**融合成一段完整 prompt，对**用户上传的图片**做图生图，生成一张适合作为皮肤 /
背景使用的图片；最后把「生成后的图片」和「**校园AI创意皮肤大赛互动页面**」一并返回给用户，由用户自行打开。

本 skill 不做 CDN 上传 / 直链提取，也不自动打开页面；图生图由 AI client 宿主内置能力完成。

## 何时使用

- 用户提供或表示要提供**一张图片**作为图生图的输入（底图）。**（必需）**
- 用户的目标是**生成一张搜狗输入法皮肤 / 背景图**（并拿到配套的校园AI创意皮肤大赛互动页面）。
- 用户**可选**附带一段风格 / 内容描述；**若未提供，则由 skill 根据图片自行推演风格，不强制用户传入**。

## 关键约定（务必遵守）

### 固定 H5 地址与返回文案

流程结束返回给用户的**文案 + H5 地址**是**写死的固定值**，不做任何拼接 / 参数替换。
按以下格式原样返回（H5 地址紧跟在「查看活动详情」之后）：

```
这张可直接参赛，得票前15名有奖
→ 保存图片并查看活动详情https://pinyin.sginput.qq.com/h5/kaixueskill/share/225448950305128448
```

- 文案与地址均原样返回，让用户自行打开。
- 不要往地址里拼接图片地址、bgimg 等任何动态参数。

## 执行流程（SOP）

按顺序执行，每一步完成后再进入下一步。

### 第 1 步：收集输入

- **图片（必需）**：用户上传的一张图片（图生图底图）。缺则请用户上传后再继续，不可跳过。
- **风格描述（可选）**：用户的一段文字，视为**目标风格 `%s`**（如「校园」「国潮」「赛博朋克」「水彩」）。
  - **缺风格时无需追问**：由 skill 观察图片的内容、色调、题材，**自行推演一个最契合的风格**
    （如卡通图→治愈手绘、夜景→赛博霓虹、古建筑→国潮水墨），作为 `%s`，并在返回时简要说明所用风格。

风格无论来自用户还是自动推演，都是用来**填入生图规范模板**的，而非直接把原话当完整 prompt 发出去。

### 第 2 步：融合 prompt（三层融合）

**先阅读 `references/generation-prompt.md`**，按其中的「**三层融合模型**」组装最终给 AI client
模型的完整 prompt。最终 prompt 由三部分融合而成：

1. **方向层（固定）**：`参考输入图片的主体与配色，生成一张适合作为手机键盘皮肤的横向背景图，画面干净、留白充足、不要出现文字。`
2. **内置正向引导层（合规硬规则，优先级最高）**：着装姿态 / 禁未成年性化 / 纯背景无键盘元素 /
   禁暴力血腥 / 原创形象不指向真人 / 人物关系合规 —— 详见 references §九。
3. **优化后的用户自定义层**：**不得把用户原话直接透传**，必须先用 skill 内置逻辑对用户描述做
   净化（剔除违反红线的内容）+ 对齐背景图属性 + 并入构图/配色约束，再拼入。

**冲突处理**：用户诉求与合规硬规则冲突时，**以合规硬规则为准**，冲突部分静默丢弃 / 改写，
不因用户描述放宽任何一条红线。融合顺序：方向层 → 内置正向引导层 → 优化后的用户自定义层。

### 第 3 步：图生图

用第 2 步融合好的 prompt，配合用户上传的图片，驱动 AI client 宿主内置能力做**图生图**生成新图片。
若返回多张，默认取第 1 张（用户有偏好可让其挑选）。

### 第 4 步：返回结果给用户

一并返回：

1. **生成后的图片**（直接展示 / 交给用户）。
2. **固定文案 + H5 地址**（原样返回，格式如下）：

   ```
   这张可直接参赛，得票前15名有奖
   → 保存图片并查看活动详情https://pinyin.sginput.qq.com/h5/kaixueskill/share/225448950305128448
   ```

3. 若为自动推演风格，可简短说明本次采用的风格。

不由 skill 自动打开页面，由**用户自行保存图片并打开地址**。

## 护栏（Guardrails · 硬性边界）

以下为图生图必须守住的硬边界，详见 `references/generation-prompt.md`：

**A. 生成质量边界**

- **唯一素材**：上传图片是唯一内容来源，产物主要元素须可追溯到原图，不无中生有。
- **保留可辨识**：不把主体改到认不出，也不完全删除主体。
- **不变形**：主体仅等比缩放，严禁拉伸 / 挤压。
- **配色不脱离原图主色系**，仅适度调整。
- **适合背景**：横向、留白充足、主体不喧宾夺主、不影响上层内容可读性、**不出现文字**。
- **画面干净**：无压缩噪点、水印、二维码、无关文字、杂乱装饰。

**B. 合规红线（优先级最高，见 references §九，不可因用户诉求突破）**

- **着装姿态**：着装完整整洁，无暴露 / 湿身 / 破损滑落，姿态端正无暗示性动作。
- **禁未成年性化**：成年（18+）特征，头身比不低于 1:6.5，不用幼态 / Q 版，神态不含娇媚等表现。
- **纯背景**：不含任何键盘 / 界面元素、设备外框、屏幕内容。
- **禁暴力血腥**：氛围明亮平和，无冲突 / 伤害 / 破坏。
- **原创形象**：不指向任何真实存在的公众人物 / 明星。
- **人物关系**：性别特征清晰；多人为同学 / 朋友关系，无过分亲密接触。

## 异常处理

- **缺图片**：必须请用户上传图片后再继续，不可跳过。
- **缺风格描述**：无需追问，按第 1 步规则由 skill 根据图片自行推演风格。
- **图生图失败**：重试一次；仍失败则清晰说明失败原因并停止，不返回无效结果。
