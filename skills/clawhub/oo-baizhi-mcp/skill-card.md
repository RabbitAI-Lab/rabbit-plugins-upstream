## Description:

Helps agents search the web and read or extract webpage content using Baizhi Cloud Agent Toolkit through an OOMOL-connected account.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and other users can use this skill to discover Baizhi search and page-reading tools, search the web, and extract information from webpages through their connected account.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The fallback setup suggests running a remote installer directly.

Mitigation: Review the installation method before use and prefer a verified installer or package-manager method.

Risk: Hosted search and page-reading calls may consume credits.

Mitigation: Check expected costs and available credits before making repeated or large requests.

Risk: Webpage results may contain untrusted instructions or misleading content.

Mitigation: Treat retrieved pages as data, not instructions, and verify important claims independently.
