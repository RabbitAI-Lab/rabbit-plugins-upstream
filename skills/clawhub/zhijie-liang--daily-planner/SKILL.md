# Daily Planner — 每日效率规划师

## Overview

根据用户输入的任务列表，生成一份结构化的每日效率规划方案，包含：优先级排序（艾森豪威尔矩阵）、时间块日程（Time Blocking）、番茄钟安排（Pomodoro），以及可勾选的 Markdown 清单。

## When to Use

- 用户列出今天要做的事情，需要帮忙安排时间
- 用户说「帮我规划今天」「安排一下日程」「做个今日计划」
- 用户有一堆任务，不知道先做什么
- 用户要求生成番茄钟计划或时间块日程
- 用户需要一份可打印/可勾选的待办清单

## Workflow

### Step 1: 收集任务信息

向用户收集以下信息（若用户未提供，则主动询问）：

1. **任务列表**：今天需要完成哪些事情？
2. **预计时长**：每项任务大概需要多久？（不确定时根据任务描述合理估算）
3. **截止时间**：哪些任务有硬性截止时间？（如会议、DDL）
4. **可用时间**：今天从几点到几点可以工作？（默认 09:00-22:00）
5. **休息偏好**：是否需要午休？习惯工作多久休息一次？（默认番茄钟 25 分钟工作 + 5 分钟休息）

如果用户已经提供了足够信息，不要反复追问，直接进入下一步。

### Step 2: 优先级排序

使用艾森豪威尔矩阵对任务进行四象限分类：

| 象限 | 分类 | 处理策略 |
|------|------|----------|
| 重要 + 紧急 | 🔴 立即做 | 排在日程最前面，优先处理 |
| 重要 + 不紧急 | 🟡 计划做 | 安排在精力最充沛的时段（通常是上午） |
| 不重要 + 紧急 | 🟢 委托/快速做 | 批量处理，放在精力较低的时段 |
| 不重要 + 不紧急 | ⚪ 稍后做 | 如果时间不够，可以推迟到明天 |

### Step 3: 生成时间块日程

按以下原则生成时间块：

1. **匹配精力曲线**：上午安排高难度/高优先级任务，下午安排协作/ routine 任务
2. **番茄钟节奏**：每 25 分钟工作 + 5 分钟休息为一组，每 4 组安排 15-30 分钟长休息
3. **预留缓冲**：任务之间留 5-10 分钟缓冲，不要排满
4. **固定时间优先**：有固定时间的任务（如会议）先排，其他任务围绕它们填充
5. **午休保护**：12:00-13:30 之间安排午餐 + 休息

如有 Python 环境，可运行 `scripts/generate_schedule.py` 自动计算时间块。脚本使用方式：

```bash
python scripts/generate_schedule.py --tasks '{"tasks": [{"name": "写报告", "priority": "high", "duration": 90, "deadline": "14:00"}], "start": "09:00", "end": "22:00"}'
```

### Step 4: 输出规划方案

生成一份 Markdown 格式的规划方案，包含以下部分：

#### 输出格式模板

```markdown
# 📅 今日效率规划 — {日期}

## 🎯 今日目标
（1-3 句话概括今天最核心的目标）

## 📊 优先级矩阵

| 优先级 | 任务 | 预计时长 | 截止时间 |
|--------|------|----------|----------|
| 🔴 紧急重要 | ... | ... | ... |
| 🟡 重要不紧急 | ... | ... | ... |
| 🟢 紧急不重要 | ... | ... | ... |
| ⚪ 不紧急不重要 | ... | ... | ... |

## ⏰ 时间块日程

| 时间 | 任务 | 番茄钟 | 状态 |
|------|------|--------|------|
| 09:00-09:25 | 任务A | 🍅 #1 | ⬜ |
| 09:25-09:30 | ☕ 休息 | — | ⬜ |
| 09:30-09:55 | 任务A | 🍅 #2 | ⬜ |
| ... | ... | ... | ... |

## ✅ 今日清单
- [ ] 任务A
- [ ] 任务B
- [ ] 任务C

## 💡 效率建议
（根据任务特点给出 1-2 条个性化建议）
```

### Step 5: 保存计划

将生成的规划方案保存为 Markdown 文件到用户的工作目录，文件名格式：`daily-plan-YYYY-MM-DD.md`。

## Tips

- 如果用户任务过多，一天排不下，主动提示哪些任务可以推迟
- 如果用户只有 1-2 个任务，简化输出，不需要完整矩阵
- 可以参考 `references/time_management.md` 中的时间管理方法论
- 输出语气保持简洁实用，不要过多寒暄
