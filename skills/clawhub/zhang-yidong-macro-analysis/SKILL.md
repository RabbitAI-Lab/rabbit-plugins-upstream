## Core Thinking Models

### 模型一：N型走势分析框架
- 夏季行情大概率呈"N型走势"：先涨后跌再反弹
- 核心逻辑：政策预期→基本面验证→情绪波动三重节奏
- 风险：不是下跌本身，而是结构分化

**举例一（N型的三段如何识别）**：政策预期驱动的第一波上涨通常伴随成交额快速放大；
随后进入基本面验证期，若中报/经济数据未跟上，指数回落构成N型的中间一竖；
若数据兑现，第二波反弹由业绩驱动而非情绪驱动——**看反弹时的成交额与前期是否同量级**，
是区分"真第二段"与"反抽"的关键。

**举例二（结构分化而非指数下跌才是风险）**：同一区间内，指数仅小幅回调，
但前期拥挤的硬件环节回撤显著、红利与资源板块相对抗跌。若只看指数会误判为"没事"，
看结构才会发现持仓可能已经受伤——这正是"风险不是下跌本身"的含义。

**N型走势的三段对照（本轮新增维度）**：

| 阶段 | 驱动因素 | 可观察信号 | 常见误判 | 验证方法（新增） | 不应据此做什么（新增） |
|-----|-----|-----|-----|-----|-----|
| 第一笔上行 | 政策预期/流动性 | 成交额放大、风险偏好回升 | 把预期兑现当成趋势确立 | 看成交额是否连续多日放大 | 不据此认定趋势已确立 |
| 中间回撤 | 基本面验证不及预期 | 成交缩量、板块轮动加快 | 把正常回撤当成趋势终结 | 看回撤是否伴随缩量与轮动加快 | 不据此判断趋势终结 |
| 第二笔上行 | 业绩兑现 | 盈利上修、龙头领涨 | 把反抽当成新一轮主升 | 看成交额与前期是否同量级 | 不把缩量反抽当主升 |

**举例三（用成交额量级区分真第二段与反抽）**：指数回撤后重新上行，成交额只有第一波上行时的六成，
且上涨由少数权重股拉动、多数个股未跟随。按上表验证方法判断：成交额不同量级 → 属反抽而非第二笔上行。
对应的动作是**观察而非加仓**；真正的第二段通常伴随成交额回到前一波同量级且上涨面扩散。

### 模型二：结构性机会优先框架
```
核心命题：
- 整体估值仍处相对高位
- 风险溢价从极低位回落，但未到极值
- 阿尔法机会 > 贝塔机会
- 结构性行情才是长期超额收益的真正来源
```

**举例一（阿尔法 vs 贝塔的判别）**：若某阶段指数横盘但半导体销售额同比大幅增长，
说明产业景气与指数走势背离，此时收益来源是阿尔法（选对行业/个股）而非贝塔（买指数）。

**举例二（风险溢价的位置感）**：风险溢价从极高位回落到中位，意味着"闭眼买"的赔率下降，
但并未到必须清仓的极值。对应的动作不是加减仓，而是**把组合从指数化转向结构化**。

**举例三（风险溢价位置与动作强度）**：把风险溢价粗略分为三段——极高位（赔率极佳）、
中位（赔率下降但仍有结构机会）、极低位（需防守）。同一个"看多产业"的判断，在三段中对应的动作强度完全不同：
极高位可集中，中位应分散到多个子方向并控制单一持仓上限，极低位则应优先保全本金。**结论不变，动作随位置变化**，
这是把框架用对的关键。

**阿尔法/贝塔判别清单（本轮新增维度）**：

| 观察项 | 偏贝塔的特征 | 偏阿尔法的特征 |
|-------|-----|-----|
| 指数与产业景气 | 同向 | 背离（产业强、指数弱） |
| 板块间相关性 | 高，齐涨齐跌 | 低，轮动明显 |
| 成交额 | 持续放量 | 缩量或结构分化 |
| 对应动作 | 关注指数工具 | 关注个股与行业选择 |
| 上涨面（新增） | 普涨 | 少数方向领涨 |
| 回撤特征（新增） | 指数回撤即普跌 | 指数平稳但拥挤板块大跌 |

### 模型三：三大关注热点（2026）
```
1. 高水平科技自立自强
   → 半导体、AI、量子计算等硬科技
   → 国产替代的长期逻辑

2. 消费提振与内需复苏
   → 政策效果传导
   → 消费结构升级

3. 港股/A股联动与海外配置
   → 全球化配置视角
   → 汇率风险管理
```

**三条主线各自的观察指标与举例（本轮新增维度）**：

| 主线 | 关键观察指标 | 举例：如何落到判断上 | 易错点（新增） | 复核来源（新增） |
|-----|-----|-----|-----|-----|
| 1. 科技自立自强 | 半导体销售额同比、国产设备验证进度、研发支出 | 若全球半导体销售额同比高增长而国内增速更快，说明国产替代在兑现而非停留在叙事 | 把"叙事热度"当成"订单兑现" | 行业统计、公司公告、设备验证进展 |
| 2. 消费提振与内需 | 社零同比、CPI/PPI、PMI | PMI在荣枯线下小幅回升属"边际修复"而非"复苏确立"，据此只能做战术配置 | 单月数据波动被当作趋势拐点 | 统计局月度数据、至少连续三月 |
| 3. 港A联动与海外 | 南向资金净流入、美债利率、人民币汇率 | 港股同时受"南向资金托下限"与"海外流动性定上限"两端拉扯，需分开定价 | 只看国内基本面忽略海外变量 | 南向资金数据、海外利率与汇率 |

**举例（港A联动的双向判断）**：当海外AI硬件行情强势时，全球资金向高景气科技资产集中，
对港股形成抽血效应，港股可能弱于A股；当海外降温时，南向资金有望托住港股底部。
判断港股不能只看国内基本面，**必须同时给"海外抽血"和"南向托底"两个变量赋值**。

**举例二（三大热点的权重如何随阶段变化）**：同一条主线在不同宏观阶段的权重并不相同。
- 磨底期：流动性主导，"港A联动"权重最高，因为外部变量决定风险偏好。
- 修复期：盈利主导，"科技自立自强"权重上升，因为景气开始兑现到报表。
- 过热期：估值主导，"消费提振"这类低拥挤方向反而具备相对性价比。
- 用法：先定阶段，再配权重，而不是三条主线平均用力。**权重随阶段迁移，是框架活用的标志**。

### 模型四：耐心稳行框架
```
2026年策略核心："耐心稳行，戒骄戒躁"
- 震荡向上格局中保持定力
- 避免追涨杀跌的短期行为
- 下半年可能迎来重要高点
- 指数高位运行时更需关注个股质量
```

**举例一（戒骄戒躁的具体化）**：指数从区间高点回落时，若持仓跌幅明显大于指数，
说明持仓集中在高波动品种，此时"耐心"不等于"不动"，而是应把结构调向质量与现金流。

**举例二（耐心 vs 麻木的界线）**：耐心是对**方向**的坚持，麻木是对**证据变化**的无视。
判别标准：若当初买入的三条理由中有两条被证伪，就是麻木；若理由仍在只是价格波动，才叫耐心。

**举例三（戒骄戒躁的量化边界）**：给"耐心"设两条可执行的边界——
① 若持仓跌幅超过指数的 1.5 倍且持续两周以上，说明结构有问题，应调而非等；
② 若买入理由三条中被证伪两条，立即重估而非等待。
有了边界，"耐心"才是纪律；没有边界，"耐心"只是对亏损的另一种说法。

**耐心稳行的执行对照（本轮新增维度）**：

| 情形 | 属于耐心 | 属于麻木 |
|-----|-----|-----|
| 价格回撤但逻辑未变 | 是 | |
| 逻辑被数据证伪仍持有 | | 是 |
| 成交缩量、轮动加快时的横盘 | 是（等待催化） | |
| 追高后被动长期持有 | | 是 |
| 估值回到极端高位仍满仓（新增） | | 是 |
| 缩量横盘中降低换手等待催化（新增） | 是 | |

### 模型五：风险识别清单
| 风险类型 | 判断标准 | 应对策略 |
|----------|----------|----------|
| 系统性风险 | 估值极端+情绪过热 | 减仓/对冲 |
| 流动性风险 | 海外央行收紧 | 现金为王 |
| 结构风险 | 旧动能拖累 | 切换新动能 |
| 地缘风险 | 黑天鹅事件 | 分散配置 |
| 成交萎缩风险（新增） | 日均成交额连续回落、两融增速放缓 | 降低换手频率，避免依赖流动性溢价 |
| 估值分化风险（新增） | 指数平稳但前期拥挤板块大幅回撤 | 检查持仓集中度，而非只看指数 |
| 外部抽血风险（新增） | 海外高景气资产强势吸引全球资金 | 港A分开定价，关注南向资金对冲力度 |
| 政策预期落空风险（新增） | 强刺激预期未兑现、政策转向精细化调控 | 不按"预期中的政策"定价，回到已落地的事实 |
| 拥挤度风险（新增） | 单一方向成交占比快速抬升 | 降低该方向权重，避免流动性反转时无法退出 |

**举例（用清单做一次完整风险扫描）**：假设当前A股缩量、港股回调、海外AI主线迁移。
逐项对照——流动性风险：成交萎缩，需降低换手；结构风险：拥挤板块回撤，需查集中度；
外部风险：资金被海外抽离，港股需下调短期预期；系统性风险：估值未到极端，不构成清仓信号。
**结论落在"调结构"而非"砍仓位"上**，这就是清单相对直觉判断的价值。

**举例二（清单的优先级排序）**：同时触发多条风险时，按"不可逆性"排序处理——
① 外部抽血与流动性风险（影响全组合，优先处理）；② 拥挤度风险（影响单一方向，次之）；
③ 估值分化风险（影响持仓集中度，再次）。
若从最容易处理的那条开始，往往会把精力花在影响最小的问题上。**先处理不可逆、影响面最大的风险**，
是清单使用的核心纪律。

### 模型六：周期定位法
- 中国经济受旧动能拖累最严峻时期已过
- 但仍有结构性问题需要消化
- 关注"新旧动能转换"的关键节点
- 政策传导有时滞，需耐心等待

**举例一（如何判断"最严峻时期已过"）**：看三个同步指标——PMI是否连续多月边际回升、
PPI同比跌幅是否收窄、企业盈利预期是否止跌。三者中两项改善即可认为最坏阶段过去，
但**不等于复苏确立**，中间还有一段"磨底"。

**举例二（政策时滞的实务含义）**：政策出台到体现在企业报表通常跨越数个季度。
若在数据兑现前就按"复苏"定价，容易买在预期高点；正确做法是**在政策落地期布局、
在数据兑现期验证、在情绪高点减配**。

**举例三（新旧动能转换的节点识别）**：不看总量增速，看**结构占比的交叉点**——
当新动能（高技术制造、现代服务业）在增加值中的占比提升速度超过旧动能下滑速度时，总量增速可能仍平淡，
但增长质量已发生变化。这类"总量平淡、结构改善"的窗口，往往先于指数反应出现在中观数据里。
用法：**用中观结构数据领先一步，用总量数据确认一步**，两者之间就是布局窗口。

## Workflow
```
【张忆东宏观分析】
Step 1 - 周期定位：现在处于哪个宏观阶段？
Step 2 - 走势预判：N型/趋势向上/震荡？
Step 3 - 结构判断：机会在贝塔还是阿尔法？
Step 4 - 风险扫描：最大风险是什么？概率多大？
Step 5 - 配置建议：仓位/行业/个股优先级
```

**五步流程的落地举例（本轮新增）**：

| 步骤 | 提问 | 举例：判断"现在该不该加仓科技股" | 产出 |
|-----|-----|-----|-----|
| Step 1 周期定位 | 在哪个宏观阶段 | PMI荣枯线下边际修复，属磨底而非复苏 | 定性：磨底期 |
| Step 2 走势预判 | N型/趋势/震荡 | 缩量降波、轮动加快 → 震荡 | 定性：震荡格局 |
| Step 3 结构判断 | 贝塔还是阿尔法 | 指数弱、半导体景气强 → 阿尔法 | 动作：选结构不选指数 |
| Step 4 风险扫描 | 最大风险与概率 | 成交萎缩 + 外部抽血，中等偏高 | 控制：降低换手与集中度 |
| Step 5 配置建议 | 仓位/行业/个股 | 中性仓位、红利底仓 + 科技弹性哑铃 | 结论：不加总仓，只调结构 |
| Step 4 补充：不可逆性排序（新增） | 先处理哪条风险 | 外部流动性 > 拥挤度 > 估值分化 | 结论：优先处理影响全组合的风险 |
| Step 5 补充：动作强度（新增） | 位置决定强度 | 风险溢价中位，动作应分散而非集中 | 结论：控制单一方向权重上限 |

**举例（一句话走完全流程）**：问"港股现在能配吗"——
Step 1 港股处估值低位（周期偏底部）；Step 2 区间震荡而非趋势；
Step 3 阿尔法为主，聚焦算力龙头与高股息；Step 4 风险来自海外利率与资金抽离；
Step 5 结论是**可配但需分批，且必须把海外流动性作为第一观察变量**。
