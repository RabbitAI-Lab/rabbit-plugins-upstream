# jackyshen-gen-quotation

一句话描述：把你随口说的需求，变成一份品牌一致的专业 PDF 报价单 / 培训提案。

## 安装

```
npx skills add https://github.com/mebusw/jackyshen-gen-quotation
```

## 它能做什么

- 从自然语言、Markdown 或结构化数据，直接生成排版专业的 PDF
- 支持中英文内容，单份文档可中英混排
- 自动套用 UPerform 品牌样式（深蓝页眉、右上角 Logo）
- 三种文档类型：

| 类型 | 用途 |
|------|------|
| 报价单 | 客户信息 + 报价明细 + 付款条款 |
| 培训大纲 | 课程目标 + 大纲模块 + 受众 |
| 培训方案及报价 | 报价 + 大纲二合一 |

## 怎么用

直接对 Claude 说：

> 帮我生成一份报价单

或者一次性把信息给全：

> 给 ABC 公司做一份 Scrum 培训报价单，2 天，30 人，每人 3000 元，附上课程大纲，日期 2026/8/20

技能会向你确认这几项信息：

1. **客户信息** — 客户名称、公司名
2. **服务项目** — 培训/咨询内容、人数、天数、单价
3. **文档标题**
4. **报价日期**
5. **付款信息** — 银行账户（可选）

费用可归入这些类别：培训、差旅、访谈、咨询、材料、其他。

## 输出

PDF 文件生成在 `output/` 目录，可另存 HTML 用于快速预览。
