# Vocabulary Checklist — Discussion 学术词汇逐条检查清单

## 使用方法
按顺序检查每一项，✓ 通过，✗ 缺失，⚠ 弱。

---

## Section 1: Hedging Variety（Hedge 多样性）

- [ ] 至少 3 种 hedge 形式（modal / adverb / adjective / cognitive verb / comparative）
- [ ] 不是全用 modal verbs
- [ ] 不是全用 cognitive verbs
- [ ] 有 adverb 类（"Taken together" / "Indeed"）

## Section 2: Hedge-Claim Matching（Hedge 与 Claim 强度匹配）

- [ ] 强 claim 有对应 strong verb（"demonstrate" 等）
- [ ] 弱 claim 有对应 weak verb（"suggest" 等）
- [ ] Modal verb 反映 confidence（will vs may）
- [ ] 没有 over-claim（"prove" 极少）

## Section 3: Cognitive Verb Variety（认知动词多样性）

- [ ] 至少 3 种 cognitive verbs
- [ ] 不是全用 "show" 或全用 "suggest"
- [ ] 没有用 "prove"（除非数学定理）
- [ ] Strong / medium / weak verb 各有使用

## Section 4: Happy Words（Happy Words 恰当性）

- [ ] 每 Discussion 最多 2-3 个 happy words
- [ ] Happy words 不堆叠在同一段
- [ ] 没有 "groundbreaking" / "revolutionary" 等极端词
- [ ] "novel" / "first" / "unprecedented" 适度

## Section 5: Field-Specific Terminology（领域术语）

- [ ] 使用 field 内专业术语（不是 generic "study" "people"）
- [ ] 关键概念用专业词汇表达
- [ ] 术语首次使用时有 context

## Section 6: In-line Definitions（即位定义）

- [ ] 重要术语有 in-line definition
- [ ] 使用 "(i.e., ...)" / "(that is, ...)" / "(for example, ...)"
- [ ] 跨学科术语有解释

## Section 7: Statistical/Methodological Terminology（统计/方法学术语）

- [ ] 区分 Pearson / Spearman / polychoric 等
- [ ] 方法学术语精准
- [ ] 方法学 claim 有 hedge
- [ ] 没有 "我们的方法总是对的"

## Section 8: Hedge Precision（Hedge 精确度）

- [ ] "may" vs "might" 区分使用
- [ ] "could" vs "would" 区分使用
- [ ] Modal 否定形式正确
- [ ] Adverb hedge 位置恰当

## Section 9: Future Work Specificity（未来研究方向具体性）

- [ ] Future work 包含具体方向
- [ ] 至少部分包含 sample / method / variable
- [ ] 不止 "more research is needed"
- [ ] Future work 与 limitations 对应

## Section 10: Anti-Pattern Check（反模式）

- [ ] ❌ "Our results prove..." （over-claim）
- [ ] ❌ "We found groundbreaking..." （happy words 堆叠）
- [ ] ❌ "More research is needed" 单独成句
- [ ] ❌ "interesting" / "important" 单独使用（无具体内容）
- [ ] ❌ 全用 "show" / "suggest"（缺乏 variety）

---

## 严重度判定

| 缺失项数 | 严重度 |
|---|---|
| 0-2 | Minor |
| 3-5 | Major |
| 6+ | Critical |
