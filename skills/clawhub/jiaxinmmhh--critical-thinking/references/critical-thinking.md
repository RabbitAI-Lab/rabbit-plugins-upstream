# 批判性思维 · 论证拆解与评估知识包

> 把《学会提问》（尼尔·布朗，第12版）蒸馏为**可照做的程序化知识**。本文件是 `SKILL.md` 的扩展库：当你需要判断一段论述、识别谬误、评估证据、找替代原因时，按这里模板逐项套用。

---

## 0. 一张图：拿到任何论述先做什么

1. 找论题 → 2. 找结论 → 3. 找理由 → 4. 查关键词歧义 → 5. 找假设 → 6. 查谬误 → 7. 评证据 → 8. 找替代原因 → 9. 验数据 → 10. 查省略 → 11. 给灰度结论。

顺序不是铁律，但前 3 步（论题/结论/理由）没找准，后面的盘问都会跑偏。

## 1. 论证结构拆解规则

任何论证都由 4 件套构成：

| 要素 | 定义 | 怎么找 |
|---|---|---|
| **论题** | 作者在回应什么问题 | 分两类：**描述性论题**（"是什么/为什么"，答案是事实）与**规定性论题**（"该不该/好不好"，答案是价值判断）。看是问事实还是问"应然"。 |
| **结论** | 作者想让你接受的信念 | 找指示词：因此、所以、由此得、证明、表明、建议、由此可见。没指示词时问"这段话最终要我信什么"。**结论是被支撑的，不是证据本身。** |
| **理由** | 支撑结论的信念/证据 | 找指示词：因为、由于、首先、研究显示、证据是。追问"为什么作者这么认为"。 |
| **假设** | 没明说却必须成立、论证才成立的前提 | 分**价值观假设**（应然层面的信念，如"效率比公平重要"）和**描述性假设**（世界如何运转的信念，如"人都是理性的"）。假设是理由→结论之间的"隐形胶水"。 |

**歧义测验（关键动作）**：对抽象词（自由、公平、安全、增长、成功）做替换——把"自由"换成两种相反的定义，看论证是否还成立。若成立与否取决于定义，说明该词需要先界定，否则结论不可信。

**找价值观假设的方法**：
- 反串：如果结论相反，需要什么价值观？那个价值观就是本文默认的。
- 看"由来"：作者用什么标准衡量"好"？
- 第三方后果测验：推论出了对谁有利？作者默认站在哪方利益上？

## 2. 十个批判性问题（详解）

### Q1 论题和结论是什么
- 先定位论题类型（描述性/规定性），再找结论。
- 常见坑：把"例子/数据"误当结论；把"作者赞同的他人观点"当自己结论。

### Q2 理由是什么
- 追问"为什么"，把支撑结论的每一条理由列出来。
- 没有理由的结论 = 纯断言，价值低。理由质量决定结论可信度。

### Q3 哪些词意思不明确
- 对"成功/安全/公平/自由/幸福"等抽象词做歧义测验。
- 量化词也要查："增长"是绝对量还是百分比？"多数"是 >50% 还是主观感受？

### Q4 价值观假设和描述性假设
- 见上文"找价值观假设的方法"。
- 描述性假设常藏在"因为 A 所以 B"之间：例如"因为补贴，所以企业会扩产"隐含"企业追求利润且能自由决策"。

### Q5 论证中有没有谬误（见第 3 节模板）
- 逐一对照谬误清单，看有没有"理由根本撑不起结论"的结构性错误。

### Q6 证据效力（见第 4 节层级）
- 不同证据类型可靠性天差地别，按调查研究的 > 个人观察 > 权威/证言 > 案例/经历 的粗略层级判定，并查样本、测量、偏差。

### Q7 有没有替代原因（见第 5 节）
- 因果关系尤其要找替代解释，至少列 4 种。

### Q8 数据有没有欺骗性（见第 6 节）
- 平均值陷阱、百分比 vs 绝对数、缺少比较基准、刻意选时间段。

### Q9 有什么重要信息被省略了（见第 7 节清单）
- 用省略信息清单逐项排查，特别是反驳论证、负面后果、长期影响。

### Q10 能得出哪些合理结论
- 警惕二分式思维（"要么支持要么反对"）。
- 用条件句给灰度结论："**如果**证据 A 可靠且假设 B 成立，**那么**可接受结论 C；**但如果**D 成立，则需谨慎/反对。"
- 把"我们该怎么做"和"我们相信什么"分开：证据不充分时，结论可以是"还需更多信息"。

## 3. 逻辑谬误识别模板

当理由与结论之间的桥接存在结构性缺陷时，就是谬误。逐条对照：

| 谬误 | 识别特征 | 典型句式 |
|---|---|---|
| **人身攻击（ad hominem）** | 攻击提出者而非论点本身 | "他品行差，所以他说的不对" |
| **滑坡谬误** | 声称一步将导致一连串灾难，却无证据链 | "允许 X 就会一路滑到 Z" |
| **诉诸公众** | 用"多数人都这么想"证明正确 | "大家都在用，所以没错" |
| **诉诸可疑权威** | 引用的权威不在该领域，或利益关联 | "某明星推荐，所以有效" |
| **诉诸情感** | 用煽动情绪替代论证 | "想想孩子多可怜，所以必须…" |
| **稻草人** | 歪曲对方观点再攻击 | "你说要控费，就是想饿死病人" |
| **虚假两难** | 把连续谱压缩成"非此即彼" | "要么全禁，要么全放" |
| **乱扣帽子/贴标签** | 用标签代替解释 | "这是典型的XX主义" |
| **粉饰（光环词）** | 用美好词包装无实质内容 | "这是赋能型、有温度的方案" |
| **转移话题（红鲱鱼）** | 用无关话题带偏 | 被追问预算，转而谈愿景 |
| **循环论证** | 结论本身就是前提 | "圣经可信，因为圣经这么说" |
| **计划谬误** | 低估成本/时间，高估收益 | "这个项目肯定半年回本" |
| **以偏概全** | 把小样本当普遍规律 | "我朋友试了有效，所以对所有人都有效" |

**判定口诀**：理由有没有在"就事论事地"支撑结论？一旦靠攻击人、煽情、吓人、偷换、压缩选项来让人接受结论，就是谬误。

## 4. 证据效力判定（层级 + 检查项）

可靠性从低到高（粗略）：

1. **个人经历 / 典型案例 / 当事人证言**：生动但极易以偏概全，受记忆偏差、选择性呈现影响。**不能当普遍规律。**
2. **权威/专家证词**：看专家是否在该细分领域、是否利益相关、是否 Consensus。单一专家 < 多专家共识。
3. **个人观察**：比证言直接，但仍受观察偏差、情境限制、选择性注意影响。
4. **调查研究（最可靠，但需查）**：
   - 样本：是否随机、代表性、样本量、回应率。
   - 测量：变量怎么定义和量化？有没有操纵定义。
   - 偏差：谁赞助？有没有利益冲突？有无对照组？
   - 来源：同行评审期刊 > 预印本 > 行业报告。
   - 一致性：是否与其他研究重复？效应量多大？

**通用三问**：测量准吗？样本代表性如何？谁出钱、有没有动机扭曲？

## 5. 替代原因与相关性 ≠ 因果

因果关系下，至少列 **4 种解释**再下结论：

1. **甲导致乙**（原假设）
2. **乙导致甲**（因果倒置）
3. **丙同时导致甲和乙**（共同原因/第三变量）
4. **甲和乙相互影响**（双向因果）
5. （补充）纯属巧合 / 数据噪声

**相关性 ≠ 因果**的判断：
- 有没有时间先后？
- 有没有合理的因果机制？
- 有没有被忽略的第三变量？
- 相关系数多高、样本多大、是否可重复？

**证据强度语**：用"与…相关""可能受…影响""尚不能证明因果"，别把相关说成因果。

## 6. 数据欺骗检查表

- **平均值陷阱**：均值/中位数/众数可能天差地别。收入用均值会高估（被富豪拉高）→ 看中位数。
- **百分比 vs 绝对数**："增长 50%"可能是从 2 到 3；"下降 1 个百分点"和"下降 1%"不同。问清基数。
- **缺比较基准**："效率提升"比什么？没有基线的数字无意义。
- **选时间段**：挑涨的时期报、藏跌的时期。
- **省略量纲与误差**：没有置信区间/误差棒的数字要打折。
- **图表操纵**：纵轴不从 0 开始会夸大差异；双轴图易误导。

## 7. 省略信息清单（逐项排查）

拿到结论，主动问"作者没告诉我什么"：

- [ ] 有没有**反驳这个结论**的论证/证据被省略？
- [ ] 关键词/变量的**定义**是否模糊或被操纵？
- [ ] 有没有**负面后果 / 长期影响**被略去？
- [ ] 对谁有利、对谁有害（利益结构）？
- [ ] 证据的**来源、样本、测量方法**是否缺失？
- [ ] 有没有**替代方案**没被讨论？
- [ ] 事实陈述 vs 价值判断有没有混为一谈？
- [ ] 时间/情境限定是否被泛化？

## 8. 认知偏见防御（干扰性原因）

《学会提问》第13章专讲"为什么我们难以客观"——先识别，再设防：

| 偏见 | 表现 | 防御 |
|---|---|---|
| **系统1快思考** | 直觉秒答、不查证 | 强制"慢思考"，对重要结论启用 Q1–Q10 |
| **刻板印象** | 用群体标签预判个体 | 先看具体证据，再谈群体 |
| **晕轮效应** | 一个人某方面好→全好 | 分维度独立评估 |
| **信念固着** | 只找支持自己既有观点的证据 | 主动找反例，做"反串"练习 |
| **确认偏误** | 选择性注意/记忆符合自己立场的信息 | 问"什么证据能让我改主意" |
| **可得性启发** | 容易想到的 ≠ 高概率（新闻惨剧放大风险感） | 查基率/统计数据 |
| **近因效应** | 最近发生的事权重过高 | 拉长时间窗看全貌 |
| **答非所问** | 回应偷换了问题 | 回扣原论题 |
| **自我中心 / 一厢情愿** | "我希望的"当成"会发生的" | 区分愿望与证据 |
| **知识的诅咒** | 懂的人以为别人都懂，省略前提 | 把隐含假设显式写出 |

**设防总纲**：把"我想多了解"而非"我要赢"作为对话姿态；对**自己的**信念用同样严厉的 Q1–Q10 盘问（强势批判性思维）。

## 9. 输出模板（给你的回应用）

当用户要求分析一段论述时，按此结构输出：

```
【论题】描述性 / 规定性：……
【结论】作者想让你信：……
【理由】1) … 2) …
【歧义】"XX"一词在论证中含义不清，需先界定
【假设】价值观假设：……；描述性假设：……
【谬误】发现 N 处：①… ②…
【证据】类型与可靠性：……（查样本/测量/偏差）
【替代原因】至少 4 种解释：……
【数据】平均值/百分比/基准是否有误导：……
【省略】作者没说的：……
【结论】灰度判断：如果…则接受；如果…则谨慎。
```
