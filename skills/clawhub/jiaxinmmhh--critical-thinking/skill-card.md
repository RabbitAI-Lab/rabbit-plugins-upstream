## Description:

A Chinese-language critical-thinking skill that helps agents decompose arguments, evaluate evidence, identify fallacies, check assumptions, and produce qualified conclusions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jiaxinmmhh](https://clawhub.ai/user/jiaxinmmhh)

### License/Terms of Use:

MIT-0

## Use Case:

External users and agents use this skill to analyze articles, claims, advertisements, debates, reports, and their own drafts by applying a structured critical-thinking checklist.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill's default templates and source guidance are Chinese-language, which may not match every user's preferred language.

Mitigation: Ask the agent to answer in the desired language when using the skill outside Chinese-language workflows.

Risk: Argument critiques can be overly confident if the analyzed text lacks context, source details, or complete evidence.

Mitigation: Treat the output as reasoning guidance and provide missing context, source information, or additional evidence before relying on conclusions.
