## Description:

A Chinese-language critical-thinking skill that helps agents analyze arguments by identifying issues, conclusions, reasons, assumptions, fallacies, evidence quality, alternative causes, misleading data, omitted information, and conditional conclusions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jiaxinmmhh](https://clawhub.ai/user/jiaxinmmhh)

### License/Terms of Use:

MIT-0

## Use Case:

External users and agent operators use this skill to critique articles, advertisements, social media claims, expert opinions, reports, policies, and their own arguments. It supports structured reasoning checks, including fallacy detection, evidence review, causal alternatives, data scrutiny, omitted-information review, and gray-area conclusions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill is written in Chinese and may not match user expectations in another language.

Mitigation: Ask the agent to translate or adapt the response format when non-Chinese output is required.

Risk: Argument-analysis guidance can still produce incomplete or misleading critiques if applied to missing or unreliable source material.

Mitigation: Review the agent's critique against the original claim, evidence, and context before using it for decisions.
