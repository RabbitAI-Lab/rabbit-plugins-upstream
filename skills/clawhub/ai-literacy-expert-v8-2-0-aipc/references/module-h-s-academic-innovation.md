## S3.2 跨学科项目创意生成器

### AI 输出（示例 3 条 FYP 选题）

>   - 工具栈：MeshLab + DeepSeek + Python 统计
>   - 预期成果：游戏开发者可参考的网格压缩决策树

## S3.3 AI 文献综述助手

### 工作流

```
输入（用户）
  ↓
  1. 选题关键词 → DeepSeek-R1 本地推理
  ↓
  2. 检索 arXiv / Google Scholar / CNKI → 抓取 50-100 篇
  ↓
  3. 本地 LLM 摘要（5 段式：问题/方法/结果/局限/启发）
  ↓
  4. 自动生成 3 类综述：
     - 时间线综述（按年份组织）
     - 方法论综述（按方法分类）
     - 主题聚类综述（按问题聚类）
  ↓
  输出
```

### 隐私保护（关键）
- **学生选题 / 草稿 / 笔记**: 全部本地推理（`pii_redactor.py` 自动脱敏）
- **导师反馈**: 本地缓存（`llm_cache.py` 7 天 TTL）
- **PII 漏检 5 层安全网**: 学生姓名/学号/家庭住址 自动屏蔽

### 集成
- 复用 V8.1-AIPC `analyze_courseware.py`（两阶段提示词 + 设备降级）
- 复用 `edge_cloud_dispatch.py`（当本地算力不足时降级到云端，元数据 < 10KB）

## S3.5 FYP 阶段化 AI 脚手架

### FYP I（建议 3 学分）— 选题 + 文献综述 + 开题

| 周次 | 任务 | AI 工具 |
|---|---|---|
| W1 | 选题头脑风暴 | S3.2 创意生成器 |
| W2 | 文献检索 | S3.3 综述助手（抓取 50+ 篇） |
| W3-4 | 文献阅读 | S3.3 自动摘要 + 主题聚类 |
| W5 | 研究问题定义 | DeepSeek-R1 苏格拉底式提问 |
| W6 | 方法论选择 | S3.4 方法 AI 顾问 |
| W7 | 实验设计 | DeepSeek + 导师反馈 |
| W8 | 开题答辩 PPT | compose_lesson.py 模板生成 |

### FYP II（建议 3 学分）— 实验 + 写作 + 答辩

| 周次 | 任务 | AI 工具 |
|---|---|---|
| W1-4 | 实验/数据采集 | DeepSeek-R1 + 4 阶段流水线 |
| W5-8 | 数据分析 | Pandas + Scikit-learn + AI 解释 |
| W9-12 | 论文写作 | DeepSeek-R1 草稿 + 导师批注 |
| W13 | 论文润色 | LLM 语法 + 学术风格 |
| W14 | 答辩 PPT | compose_lesson.py 模板 + p5.js 互动 |
| W15-16 | 模拟答辩 | AI 模拟提问 + 学生自评 |

### AI 角色边界（重要）
- ✅ **建议/草稿/初稿**: AI 提供
- ✅ **格式/语法/查重**: AI 辅助
- ⚠️ **核心研究判断**: 导师 + 学生决定
- ❌ **学术诚信红线**: AI 不可代写最终成果
