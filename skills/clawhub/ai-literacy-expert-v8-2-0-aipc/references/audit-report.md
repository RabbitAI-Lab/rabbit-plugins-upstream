### 1.2 发现的问题

#### 问题 1：课程内容时效性不足
- **问题**：A-D 模块内容基于 2026 年初 AI 能力，后续 AI 新发展未覆盖
- **影响**：学员学到的知识与当前 AI 能力存在代差
- **建议**：新增 F 模块（AI 安全与伦理）与 G 模块（AI 最新发展）

#### 问题 2：交互式备课缺乏智能推荐
- **问题**：5 阶段流程需要用户手动选择全部参数，高门槛
- **影响**：新手教师难以快速上手
- **建议**：增加智能推荐引擎（根据受众 + 目标自动推荐模块组合）

#### 问题 3：缺少学习效果评估闭环
- **问题**：课件/游戏/备课包生成后，缺乏学习效果追踪
- **影响**：无法验证教学质量持续改进
- **建议**：新增「AI 学习评估师」能力，生成自适应测评

#### 问题 4：离线支持不足
- **问题**：CDN 依赖强，断网环境无法使用
- **影响**：网络不佳地区用户体验差
- **建议**：引入 Service Worker + IndexedDB 离线缓存

#### 问题 5：多人协作缺失
- **问题**：当前备课系统为单人设计
- **影响**：团队协作备课场景无法支持
- **建议**：新增协作备课模式（角色分配 + 版本管理）

#### 问题 6：references 文档维护性差
- **问题**：module-*.md 分散，最大文件 69KB，难以维护
- **影响**：更新单个模块需要修改整个文件
- **影响**：文档耦合度高
- **建议**：模块内容结构化拆分，引入内容版本标签

## 二、V5 升级规划

### 2.1 升级目标

| 目标 | 描述 |
|------|------|
| 智能化 | AI 驱动推荐 + 自适应难度 |
| 闭环化 | 教学-练习-评估-反馈全链路 |
| 协作化 | 团队备课 + 版本管理 |
| 离线化 | Service Worker + IndexedDB |
| 体系化 | 新增 F/G 模块，内容与时俱进 |

### 2.2 V5 新增能力

#### 能力四 · AI 学习评估师（V5 新增 ⭐⭐⭐）
- **触发词**：「测评」「练习题」「学习效果」「测验」「考试」「评估」
- **核心功能**：
  1. 根据已学模块生成自适应测评题
  2. 支持多种题型（单选/多选/填空/编程/实操）
  3. 智能评分 + 知识点薄弱点诊断
  4. 生成个性化学习建议报告

#### 能力五 · 智能备课推荐（V5 增强）
- **触发词**：「帮我设计课程」「推荐学习路径」「课程规划」
- **核心功能**：
  1. 输入受众 + 学习目标 → AI 自动推荐模块组合
  2. 智能粒度建议（课时分配优化）
  3. 生成完整课程大纲

#### 能力六 · 协作备课室（V5 新增 ⭐⭐）
- **触发词**：「团队备课」「协作」「多人编辑」
- **核心功能**：
  1. 备课角色分配（主讲/助教/出题）
  2. 版本历史 + 回滚
  3. 批注与讨论

### 2.3 V5 技术栈升级

| 组件 | V4.3 | V5 |
|------|------|-----|
| p5.js | 2.0.3 | 2.0.3（+ 3D 增强库） |
| 文档库 | SheetJS/docx/pptxgenjs/jsPDF/JSZip | 同 V4.3 + PDF-lib（高级 PDF 操作） |
| 离线支持 | 无 | Service Worker + IndexedDB |
| AI 接口 | 单次调用 | 流式响应 + token 预算控制 |
| 评估系统 | 无 | 自适应测评引擎 |
