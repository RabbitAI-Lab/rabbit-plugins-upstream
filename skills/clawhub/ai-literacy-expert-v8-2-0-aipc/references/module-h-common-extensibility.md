# Module H · 共同性 + 扩展性中枢

> **核心目的**: 实现学生**共同性**（跨专业 AI 共同语言）+ **扩展性**（从单学科 AI 扩展到跨学科应用）

---

## 1. 共同性 — 跨专业 AI 共同语言

### 1.1 共同性定义
> 不同专业的学生通过**共同的 AI 基础**形成**跨专业对话能力**

### 1.2 5+N 公共核心课（共同性的制度保障）

| 项目 | 共同核心课 | 学分 |
|---|---|---|
| CM+N | GD3103 AI for Art Students / AIM3193 / AIM3123 / GD3113 / MAD1013 / GD2073 | 9-15 |
| DGC+N | DSS2043 / DGCX3003 / COMM3123 / FYP II | 12 |
| IBL+N | BA2003 / DMM3003 / ECON3123 / ECON3113 / EBIS3033 / BUS4073 | 9-15 |
| Math+N | 8 门公共核心必修 + 7 门 0 学分选修（含 AI3003 / COMP4163 / AI3133） | 24 |
| IST+N | AI1003 / AI2013 / AI2033 / AI4005 | 15 |

**5 项目共有 14 门 AI 必修 + 7 门 0 学分 AI 选修 = 21 门共同核心课**

### 1.3 共同语言 4 大基石

#### 基石 1: 数据思维（Data Thinking）
- 所有专业的学生都应理解"数据是 AI 的燃料"
- 来源: IBL+N / Math+N / IST+N 必修
- 工具: Pandas / 数据可视化

#### 基石 2: 提示词工程（Prompt Engineering）
- 所有专业的学生都应会"与 AI 对话"
- 来源: 博智坊第 1+4 期
- 工具: DeepSeek / Kimi / Qwen3

#### 基石 3: AI 伦理意识（AI Ethics Awareness）
- 所有专业的学生都应理解"AI 的边界与责任"
- 来源: V8.1-AIPC F 模块
- 案例: PII 漏检 / 算法偏见 / 隐私

#### 基石 4: 工具素养（Tool Literacy）
- 所有专业的学生都应会"用 AI 工具解决专业问题"
- 来源: S1 学科地图 + S2 工具栈
- 工具: DeepSeek + Cline + p5.js + 本地推理

### 1.4 共同性培养路径

```
大一时（共同基础）
  ↓
公共核心课 14 门 → 4 大基石建立
  ↓
大二时（专业深化）
  ↓
S1 学科地图 + S2 工具栈 → 学科针对性
  ↓
大三时（跨专业对话）
  ↓
博智坊（X1） + 跨学科 FYP（S3）→ 跨专业共同语言
  ↓
大四时（创新输出）
  ↓
跨学科项目 + 育人答卷（X3）
```

## 2. 扩展性 — 从单学科 AI 到跨学科应用

### 2.1 扩展性定义
> 学生**从一个学科的 AI 能力扩展到相邻学科的 AI 应用**

### 2.2 5 级递进路径

```
Level 1: 单学科 AI 认知
  - 完成本专业公共核心课
  - 拿到博智坊 1 证书
  - 输出: 1 个 AI 工具基础使用

  ↓

Level 2: 单学科 AI 工具栈
  - 掌握 S2 工具栈（5-8 件工具）
  - 拿到博智坊 4 证书
  - 输出: 1 个独立 AI 项目

  ↓

Level 3: 单学科 FYP
  - 启动 FYP I/II 6 学分
  - 完成 1 个本专业 AI 选题
  - 输出: 1 个本专业 FYP 成果

  ↓

Level 4: 跨学科 FYP
  - 启动跨学科 FYP（双导师制）
  - 与 1 个跨学科专业联合
  - 输出: 1 个跨学科 FYP 成果 + 1 枚跨学科章

  ↓

Level 5: 跨学科创新项目
  - 主导 / 参与跨学科创新项目
  - 接触 SUTD / AI 创业者嘉宾
  - 输出: 1 个行业级创新成果 + 推荐信 / 实习
```

### 2.3 5 级递进的 AI 工具

| 级别 | 关键 AI 工具 | 来源 |
|---|---|---|
| L1 | Kimi / Qwen3 / 智谱清言 | 博智坊第 1 期 |
| L2 | + DeepSeek-R1 本地 + Cline + p5.js | 博智坊第 2 期 + V8.1-AIPC |
| L3 | + FYP 选题工具栈 | S2 学科工具栈 |
| L4 | + 跨学科工具（如 CM+GD × Math+AI 的 NeRF + 神经网络） | S2 + S3 |
| L5 | + 行业级工具（SUTD / 企业参访 / 嘉宾） | 博智坊嘉宾 + 企业 |

### 2.4 扩展性的 3 个迁移模式

#### 模式 1: 工具迁移
- 例: 从 CM+GD 的 p5.js → Math+FM 的数据可视化
- 例: 从 DGC+N 的 AIGC → IBL+MKT 的智能营销
- 实现: 4 大基石 + 工具素养

#### 模式 2: 方法迁移
- 例: 从 CM+GD 的"用户测试" → DGC+PRA 的"用户调研"
- 例: 从 Math+FM 的"量化建模" → IBL+FIN 的"风险建模"
- 实现: 学科地图 + 跨专业共同语言

#### 模式 3: 范式迁移
- 例: 从 CM+GD 的"AI 辅助创作" → IBL+BUSA 的"AI 辅助决策"
- 例: 从 Math+AI 的"模型开发" → CM+GD 的"AI 角色设计"
- 实现: 跨学科 FYP + 嘉宾资源

## 3. 共同性 + 扩展性的双轨价值

### 3.1 学生侧
- 共同性 → 跨专业对话能力（求职 / 团队协作 / 跨学科项目）
- 扩展性 → 个人 AI 能力成长曲线（5 级递进）

### 3.2 教师侧
- 共同性 → 跨专业教学协同基础（T3 联席机制）
- 扩展性 → 教师跨学科视野（教学创新 T4）

### 3.3 学院侧
- 共同性 → 4 学院 × 5 项目统一培养标准
- 扩展性 → 培养路径可复制到其他博雅院校

## 5. 数据指标

### 5.1 共同性指标
- 完成 14 门公共核心课学生占比（目标 100%）
- 跨专业对话能力自评（目标 80%+）
- 4 大基石掌握度（目标 90%+）

### 5.2 扩展性指标
- L1-L5 各等级学生分布
- 跨学科 FYP 占比（目标 30%+）
- 工具迁移 / 方法迁移 / 范式迁移案例数（目标 50+/年）
