## Description:

Helps developers organize project documentation by project size, audience, and freshness while keeping agent instructions concise.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zning1994](https://clawhub.ai/user/zning1994)

### License/Terms of Use:

MIT

## Use Case:

Developers and project maintainers use this skill to organize documentation, reduce duplicated guidance, and move detailed material out of oversized CLAUDE.md or AGENTS.md files.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad file moves or deletions could remove useful material or break references in project configuration.

Mitigation: Request a dry run listing every proposed move or deletion, archive by default, and approve specific deletion paths before execution; check and update affected references.
