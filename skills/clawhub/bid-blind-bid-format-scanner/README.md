# 暗标格式"防盲"合规扫描仪（bid-blind-bid-format-scanner）

> 投标人封标前的"防盲"体检工具。暗标评审实行"一票否决"或"扣分/零分制"，而判定纯机械——
> 页边距偏 1 毫米、标题用了微软雅黑而非宋体、页码位置不对、文档属性残留作者名，都可能直接废标或零分。
> 本技能用确定性脚本做机械格式检查，把"会被机器揪出的格式问题"在封标前挡在门外。

## 它解决什么痛点

- 页边距、字体、字号、行距、标题层级、页码/页眉/页脚——纯机械项，最适合 AI 逐项核对。
- 标书里残留的公司名、Logo、项目负责人、既往项目名——"显形"即废标，必须清零。
- 文档元数据（作者/公司）这类"看不见的泄漏"——多数投标人会忽略。

## 核心能力

1. **格式硬检**：页边距（上/下/左/右）、行距、字体（中/英/数字）、字号、标题层级编号、页码格式与位置（按容差表判定）。
2. **身份"显形"扫描**：全文 + 文档元数据检索残留的投标人名称、Logo、既往项目名称、可识别的项目负责人姓名；精确命中(🔴)/启发式(🟡)分级 + `--allow` 白名单防误报 + 图片/表格人工复核提醒。
3. **篇幅逻辑裁剪**：超出页数限制时，给出"精简优先级建议"（结合评分权重标注"建议删/保留"）。
4. **一键差异报告**：输出"招标文件要求 vs 当前文件现状"对照表，附 🤖批处理(VBA/Python)/👤人工 分级修订指令。
5. **复检闭环**：修订后上传并输入"复检"，仅复查上次不合格项。
6. **智能提取 / 自检清单**：接收完整招标文件自动定位暗标要求；输出可打印自检清单。

## 输入

1. 招标文件"暗标编制要求"章节（粘贴/上传，或上传完整招标文件自动提取）；
2. 投标人暗标正文（上传 Word/PDF，`.docx` 检测最可靠）；
3. 暗标篇幅限制（如不超过 300 页，可选）；
4. 评分标准（可选，用于篇幅裁剪权重）；
5. 白名单/允许自称（可选，如允许"我公司"，避免误报）。

## 使用方式

在对话中上传暗标 Word/PDF 并说"暗标格式检查 / 封标前体检"，技能会调用 `scripts/scan_docx.py`
（或 `scan_pdf.py`）提取格式画像，结合你提供的招标要求逐条比对并输出差异报告与修订指令。

## 护栏铁律

- 只做机械格式检查，不评价技术方案内容优劣（不预测评分）。
- 不保留用户上传文件副本，扫描后立即清理中间产物。
- 以招标文件条款为最高准绳；仅当招标完全缺失某维度才用通用标尺假设并显式标注，模糊条款标"待确认"反问用户。
- 每条差异标注 🔴 废标级 / 🟡 扣分零分级。
- **不教唆规避暗标规则**（不做暗记、不藏标识、不用谐音替代）；**不替代人工终审**（图片EXIF/隐藏图层等需人工复核）。
