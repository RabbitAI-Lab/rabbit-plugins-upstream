## 运行方式与边界

Python 3.10+，仅标准库。处理当前助手工作区内选定的资料，报告保存到新目录。

只接续当前工作区任务，不跨 BOT 读文件或自动发送交接消息。

## 运行要求

Python 3.10+；标准库
