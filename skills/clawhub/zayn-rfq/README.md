# RFQ() 询价判断

**Skill ID:** `zayn-rfq`
- 所属分类：询价与报价
- 一句话用途：分析一条已经进入手中的询价，判断真实程度、信息完整度、投入价值和下一步处理方式
- 当前版本：`v0.1`
- 当前状态：Draft for testing
- 规则是否完成：是，初版规则已建立
- 是否已有测试案例：否，等待真实脱敏案例
- 下一步待办：测试参数解析、最低运行条件、判断规则、风险边界和输出结构

RFQ() 用于分析一条已经进入手中的询价，判断其真实程度、信息完整度、投入价值和下一步处理方式。它不负责阿里 RFQ 市场筛选，也不负责平台报价表填写。

完整规则见 [SKILL.md](SKILL.md)，调用模板见 [examples.md](examples.md)，测试要求见 [tests.md](tests.md)。
