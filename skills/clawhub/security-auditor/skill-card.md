## Description: <br>
Use when reviewing code for security vulnerabilities, implementing authentication flows, auditing OWASP Top 10, configuring CORS/CSP headers, handling secrets, input validation, SQL injection prevention, XSS protection, or any security-related code review. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineers use this skill to audit application code, identify OWASP Top 10 risks, and receive actionable remediation guidance for authentication, authorization, input validation, secrets handling, and related secure coding practices. <br>

Risk: Security audit guidance can be incomplete or incorrect for a specific application context. <br>
