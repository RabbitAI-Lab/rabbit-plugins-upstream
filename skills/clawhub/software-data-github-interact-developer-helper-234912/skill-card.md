## Description: <br>
Helps agent users, skill authors, maintainers, and teams plan, implement, and verify GitHub-style workflows for bug fixes, setup hardening, reliability improvements, and adjacent skill development. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

## Use Case: <br>
Developers, maintainers, skill authors, and agent users use this skill to turn GitHub-style workflow requests into practical local-friendly plans, artifacts, checklists, code changes, commands, or verification notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate for broad GitHub, CLI, API, or issue-related prompts where a more specific skill might fit better. <br>
Mitigation: Confirm the intended workflow and selected skill before allowing repository-changing actions. <br>
Risk: Developer workflow guidance can lead to code, configuration, or command changes in a repository. <br>
Mitigation: Review proposed changes and run the suggested verification steps before applying them to important branches or environments. <br>
