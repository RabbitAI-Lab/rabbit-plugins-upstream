# WebToWork AI 生态能力参考

面向 webto.work 的 AI 生态。本技能把平台对外公开的能力、接入方式与边界整理为可检索的参考，供 AI 在用户提出相关需求时直接调用或指导操作。完整原文见 `references/webto-ai-ecosystem.md`。

## 何时使用

- 用户提出以下任一需求或咨询：
  - 给已发布「页面 / 站点 / 代码项目」挂 AI 对话浮窗（访客问答、线索收集、引导加微信 / 下单）。
  - 建立 / 使用 AI 知识库做检索增强（RAG 式问答依据）。
  - 模板市场浏览、AI 生成 HTML 草稿并一键发布、把自己的作品上架定价出售（70% 分成）。
  - 分享页 PWA 化（添加到主屏幕、全屏独立打开）。
  - APK 在线打包（自定义包名 / 版本 / 图标 / 声明页，生成公开下载页）。
  - 网址一键克隆（clone_url 抓取 HTML/CSS/JS/图片成单文件或整站）。
  - AI SEO（标题 / 描述 / 关键词直写分享设置）与多语言出海（ai_translate 英日韩西法德葡俄阿繁中副本 + hreflang 互链）。
  - 模板交易做同款定价（set_market_price，他人克隆付积分，70% 归原作者）。
  - 流量与线索复盘（visitor_sources 来路域名 / utm 渠道、list_leads 留资明细）。
  - 事件 Webhook（新线索 / 新订单 / 表单提交，结构化 JSON + HMAC-SHA256 推送自有服务器）。
  - 会员专区付费墙（圈专属区域、有效期套餐、跨域来源校验）。
  - 微信小程序内置 AI（查模板 / 作品、读指南 FAQ、代发布作品）。
- 触发句式示例：
  - "给发布页面挂个 AI 助手，访客能问答、能引导加微信"
  - "把这份产品手册存进知识库，让 AI 助手照着它回答"
  - "把这个网站打包成安卓 App / 帮我出个 APK"
  - "把 example.com 克隆成我的页面，标题改成我的品牌"
  - "给这个页面生成 SEO 文案，再翻译英语和日语副本"
  - "有人留资就推送到我的服务器 / Webhook 怎么配"
  - "给页面加个会员专区，按月收 99 积分"

## 接入方式（让 AI 直接操作系统，而非只给做法）

1. 在工作台「工具 → MCP 接入」创建密钥：**只读**（仅查看，如 list_leads / visitor_sources）或**读写**（可代为创建 / 修改 / 删除）。
2. 把接入地址与密钥填入 AI 客户端（共 40 个工具，清单见 `/mcp` 页）。
3. 同一把 `wk_` 密钥也可直接当 REST 接口用（见下）。

## 开放 REST API（脚本 / 自建系统 / 低代码对接）

- 接口文档：`https://webto.work/api/v1/openapi.json`（自描述 OpenAPI，可匿名访问，可导入 Postman / Apifox）。
- 鉴权：请求头 `Authorization: Bearer wk_xxx`（密钥在工作台「工具 → MCP 接入」创建）。
- 权限：密钥分只读 / 读写；写操作（POST / PATCH / DELETE）需读写密钥，只读密钥返回 403。
- 限流：每把密钥 120 次/分钟，超限临时冻结约 5 分钟。
- 主要资源：`/api/v1/me`（账号）、`/api/v1/pages`、`/api/v1/sites`、`/api/v1/code-projects`、`/api/v1/leads`（线索）、`/api/v1/stats/summary`（概览）、`/api/v1/market/templates`（模板市场）、`/api/v1/webhooks/test`（发测试投递）。

## 能力边界（执行前务必核对，避免承诺做不到的事）

- 分享页 PWA：不提供离线缓存，不支持自定义应用图标。
- 知识库：文本检索（关键词相关度），不做向量语义召回；图片 / PDF 需先转文字录入。
- 访客对话：问答规则 + 自配 AI 接口；知识库增强只影响回答依据，不提供在线人工坐席（引导加微信即转人工）。
- 模板市场上架：作品需平台复核后才公开；平台内置模板与用户上架并存。
- 网址克隆：对登录墙 / 动态渲染 / 防盗链站点无法完整还原；按次扣少量积分，仅抓入口页不递归；尊重源站版权。
- AI 翻译：支持 60KB 以内页面；SEO / 翻译生成的是草稿或副本，原页面不受影响。
- 事件 Webhook / 会员专区：依赖前台支付流程，退款与对账以工作台记录为准；Webhook 需可公网访问的 HTTPS 接收地址，对方几秒内响应。
- APK：实际表现取决于被包装网页本身；构建需排队与编译时间，安装包在平台有留存期限，长期提供下载需及时转存。

## 执行步骤建议

1. 明确用户要的是「只给做法」还是「直接调用平台能力」——后者必须先拿到 MCP 或 REST 密钥。
2. 调用前先核对「能力边界」，对不支持的场景（如 PWA 离线缓存、语义召回）明确告知。
3. 涉及写操作（发布 / 改价 / 删资源）用读写密钥，并在执行前与用户确认关键参数（标题、天数、价格等）。
4. 需要完整清单（40 个 MCP 工具名、REST 资源字段、边界细则）时读取 `references/webto-ai-ecosystem.md`。
