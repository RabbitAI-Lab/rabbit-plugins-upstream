# WebToWork 技能包

把这份文档交给你的 AI 客户端（Codex / Claude / WorkBuddy 等），它就能帮你使用 WebToWork 的各项能力。

## 这个技能包能做什么

- **功能一 · AI 助手挂载**：给已发布的页面 / 站点 / 代码项目挂一个 AI 对话浮窗。访客可以提问、留资、加微信或跳转下单；你能在工作台查看访客线索（未读提醒、标记已读、删除），也能让 AI 客户端用 `list_leads` 工具代查线索。支持两种模式：平台模式（按你配置的问答规则作答，无需模型费用），或接入你自己的 AI 接口。可绑定**知识库**做检索增强，让回答基于你自己的资料，而不是凭空发挥。
- **功能二 · AI 知识库（检索增强）**：把产品说明、FAQ、内部手册等文本存进知识库，系统自动切片建立索引。绑定到 AI 助手后，访客提问会先检索你的资料，再据此作答；命中的片段与相关度可在工作台「检索测试」里直接验证。
- **功能三 · 模板市场 + AI 草稿**：在 `/new` 里浏览模板或直接描述需求，由平台生成 HTML 草稿（保存 7 天），预览满意后一键发布。市场支持**用户自行上架**：把自己的作品（含做同款授权）挂上去定价出售，售出后 **70% 分成归你**，收入与销量在工作台可见。AI 客户端也可直接调用市场与出稿能力。
- **功能四 · 分享页 PWA 化**：分享出去的页面 / 站点 / 代码项目在手机上可以「添加到主屏幕」，全屏独立打开，像原生应用。
- **功能五 · APK 在线打包**：把任意网站或平台内的页面 / 站点 / 代码项目打成安卓安装包。提交时可自定义包名、版本号、桌面图标、更新记录、应用介绍与效果图，并可选择启动声明页的呈现方式与是否显示系统状态栏。构建完成后提供各架构安装包的公开下载页，访客无需登录即可下载。
- **功能六 · 网址一键克隆**：给一个网址，AI 用 `clone_url` 工具抓取该页 HTML / CSS / JS / 图片（页面内联成单文件，或整站打包），直接克隆成你的页面或站点，再按需修改发布。
- **功能七 · AI SEO 与多语言出海**：用 `ai_seo` 为页面生成 SEO 标题 / 描述 / 关键词并可直写分享设置；用 `ai_translate` 把页面翻译成英 / 日 / 韩 / 西 / 法 / 德 / 葡 / 俄 / 阿 / 繁中私有副本，自动登记 hreflang 互链。
- **功能八 · 模板交易（做同款定价）**：用 `set_market_price` 开启页面「允许克隆」并设置授权价——他人做同款需支付积分，其中 70% 分成给你。
- **功能九 · 流量与线索复盘**：用 `visitor_sources` 查看单个作品的来路域名与 utm 渠道排行；用 `list_leads` 查看智能表单提交与 AI 留资明细，量化各渠道引流效果。
- **功能十 · 事件 Webhook（面向程序）**：把「有新线索 / 有新订单 / 表单提交」等事件以结构化 JSON + HMAC-SHA256 签名实时推送到你自己的服务器，可在工作台配置地址、订阅事件、发测试请求、查看投递日志与失败重试结果。与「消息通知渠道」不同：通知给人看，Webhook 给程序用。
- **功能十一 · 会员专区（付费墙）**：给页面圈出会员专属区域，设置有效期套餐与价格；访客在前台订阅支付后可解锁查看。跨域嵌入时会自动处理来源校验，未订阅访客看不到专属内容。
- **功能十二 · 微信小程序 AI**：WebToWork 微信小程序内置 AI 助手（微信官方「AI 开发模式」）。在小程序里可以直接问 AI：查模板市场与作品展示、读新手指南与 FAQ、查我的作品（页面 / 站点 / 代码项目，含复核状态），还能代你发布作品——登录用户按天扣积分，**游客可发布不扣积分的临时页**。AI 回复中内嵌小程序卡片，点击直达对应页面。站长可在管理后台「小程序设置 → 微信 AI 开发模式」一键开关。

## 怎么用

1. 复制本文档全文，粘贴到 AI 客户端的对话中（或把本页地址直接发给它）。
2. 用日常说法提出需求即可，例如：

   - "给发布页面挂个 AI 助手，访客能问答、能引导加微信"
   - "把这份产品手册存进知识库，让 AI 助手照着它回答问题"
   - "模板市场怎么做？AI 生成草稿怎么闭环？我的作品怎么上架卖"
   - "分享页能不能添加到主屏幕 / PWA 化"
   - "把这个网站打包成安卓 App / 帮我出个 APK / 包名怎么填 / 声明页能不能隐藏"
   - "把 example.com 这个网页克隆成我的页面，标题改成我的品牌"
   - "给这个页面生成 SEO 文案，再翻译出英语和日语副本"
   - "有人留资就推送到我的服务器 / Webhook 怎么配 / 怎么看投递有没有失败"
   - "给页面加个会员专区，按月收 99 积分，只有订阅的人能看"
   - "帮我的页面开启做同款并定价 50 积分 / 看看这个页面最近访客都从哪来、有哪些留资"
   - "在微信小程序里帮找个落地页模板 / 发个临时页面给朋友试试"

3. 若希望 AI 直接调用平台能力（而不只是给出做法），请在工作台「工具 → MCP 接入」创建一个密钥：只需查看时选**只读**，需要代为创建 / 修改 / 删除时选**读写**。把接入地址与密钥填入 AI 客户端即可（共 40 个工具，见 `/mcp` 页清单）。

## 微信小程序里的 AI（免装客户端）

除了桌面 AI 客户端，WebToWork 微信小程序内置了 AI 助手（基于微信官方「小程序 AI 开发模式」），无需任何配置即可在微信里直接用：

- **找模板 / 看作品**：问「帮我找个活动报名页模板」「展示墙里有哪些工具类作品」，AI 按分类与关键词检索后给出小程序卡片，点击直达。
- **查指南 / FAQ**：问「怎么给页面绑域名」「积分怎么收费」，AI 检索使用指南与常见问题作答。
- **查我的作品**：问「我有哪些页面快到期」，AI 微信静默登录后列出你的页面 / 站点 / 代码项目与状态。
- **代发布作品**：把 HTML 源码发给 AI 即可发布。登录用户按天扣积分（发布前 AI 会与你确认标题与天数）；未登录可发布**临时页**（不扣积分，可留邮箱延长有效期）。
- **开关**：站长在管理后台「小程序设置 → 微信 AI 开发模式」控制该能力是否开放；关闭后小程序内 AI 会提示功能未开启。

## 开放 REST API（给自己的程序调用）

同一把 `wk_` 密钥也能直接当 REST 接口用，适合写脚本、接自建系统或对接低代码平台：

- **接口文档**：`https://webto.work/api/v1/openapi.json`（自描述 OpenAPI 契约，可匿名访问，可直接喂给 Postman / Apifox 导入）
- **鉴权**：请求头带 `Authorization: Bearer wk_xxx`（密钥在工作台「工具 → MCP 接入」创建）
- **权限**：密钥分只读 / 读写；写操作（POST / PATCH / DELETE）需要读写密钥，用只读密钥会返回 403
- **限流**：每把密钥 120 次/分钟，超限临时冻结约 5 分钟
- **主要资源**：`/api/v1/me`（账号信息）、`/api/v1/pages`（页面列表 / 创建 / 修改 / 删除）、`/api/v1/sites`、`/api/v1/code-projects`、`/api/v1/leads`（线索）、`/api/v1/stats/summary`（数据概览）、`/api/v1/market/templates`（模板市场）、`/api/v1/webhooks/test`（发测试投递）

## 会用到什么

- 一个 WebToWork 账号。
- 如果要让 AI 直接操作平台，需要一个 MCP 接入密钥（见上）。
- 打包安卓安装包时，构建需要排队与编译时间；安装包在平台有留存期限，需要长期提供下载时请及时下载或转存。
- 网址克隆按次扣少量积分，只抓入口页不递归；请尊重源站版权。
- 知识库有容量上限（单文档与知识库总量分别计），超出时先删除不用的旧文档。
- 事件 Webhook 需要你有一个可公网访问的 HTTPS 接收地址；对方接口要能在几秒内响应。

## 能力边界

- 分享页 PWA 目前不提供离线缓存，也不支持自定义应用图标。
- 知识库目前是文本检索（关键词相关度），不做向量语义召回；图片、PDF 需先自行转成文字再录入。
- 访客对话为问答规则 + 你自配的 AI 接口；知识库增强只影响回答依据，不提供在线人工坐席（引导加微信即可转人工）。
- 模板市场里的作品需经平台复核后才会公开上架；平台内置模板与用户上架作品并存。
- 网址克隆对登录墙 / 动态渲染 / 防盗链站点无法完整还原。
- AI 翻译支持 60KB 以内页面；SEO 与翻译生成的都是草稿或副本，原页面不受影响。
- 事件 Webhook 与会员专区订阅依赖前台支付流程，退款与对账以工作台记录为准。
- 安卓安装包的实际表现取决于被包装网页本身。
