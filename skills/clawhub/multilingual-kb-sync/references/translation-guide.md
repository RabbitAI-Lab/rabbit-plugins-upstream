# Translation Quality Guide

## Principles

1. **Tone**: Keep customer service tone consistent — polite, professional, empathetic.
2. **Formality**: Use the formal register (vous/Sie/님) for all languages unless the brand voice specifies casual.
3. **Placeholders**: Preserve `[placeholder]` tokens exactly — do not translate variable names.
4. **Consistency**: Use the same term for the same concept across all templates (e.g., "refund" → "remboursement" in French, consistently).

## Language-Specific Notes

### Français (fr)
- Use **vous** (formal), not tu.
- Use French guillemets: « ... » with non-breaking spaces.
- Punctuation: add non-breaking space before ! ? : ;
- "Customer service" → service client
- "Refund" → remboursement

### 한국어 (ko)
- Use 합쇼체/해요체 (polite formal) — 안녕하세요, 감사합니다.
- Honorifics: use -님 for customers.
- "Customer service" → 고객센터
- "Refund" → 환불

### 日本語 (ja) — if added later
- Use です/ます form.
- Customer → お客様
- Refund → 返金

### Español (es) — if added later
- Use **usted** form.
- Customer service → servicio al cliente
- Refund → reembolso
