# DAILY_REPORT() 日报推进与结果检查

**Skill ID：** `zayn-daily-report`

**版本：** `v0.1.0`

**状态：** Draft for testing

## 核心用途

把当天记录转为可核实的结果、状态、下一步、负责人和期限，识别等待、阻塞、暂停与退出。

## 适用场景

日报、下班汇报、当天复盘、检查哪些事项没有推进，以及面向领导、个人或团队的单日版本。

## 不适用场景

整周分析使用 `zayn-weekly-report`；类型不明先使用 `zayn-report`；需要升级或决策时分别使用 `zayn-escalate`、`zayn-decision`。

## 输入要求与流程

提供日期、岗位、事项、目标、结果/状态、下一步、负责人、期限和支持需求。Skill 先输出参数状态表，再区分动作与结果、检查等待和关闭，最后生成日报。

## 输出

今日结论、有效结果、推进中事项、等待与阻塞、无结果动作、明日最多 3 个结果型目标及管理支持。

## 快速示例

“今天给 A 客户发了报价，但未回复”只属于动作与等待；需补充等待开始时间、最晚确认时间、下一次动作和超时处理。

支持保留现有模板：模板记录事实，Skill 负责检查、追问、分析和纠偏。
