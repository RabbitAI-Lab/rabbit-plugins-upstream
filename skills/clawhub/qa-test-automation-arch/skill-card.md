## Use Case:

QA engineers, developers, and test architects use this skill to plan automation architecture before writing tests, including framework selection, test layering, test data separation, maintainability, and CI integration.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may include real production customer, payment, identity, or financial data in QA examples.

Mitigation: Use synthetic or redacted test data and mask sensitive identifiers, payment values, screenshots, and financial details before sharing examples.

Risk: When Bash is available, project inspection commands may expose more workspace context than needed for architecture planning.

Mitigation: Keep command use user-directed and limited to inspecting project structure needed for the automation architecture.
