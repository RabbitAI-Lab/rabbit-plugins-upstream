# Morandi 商务配色规范（钢蓝 + 赭石）

> 用途：把下面「可复用提示词」整段复制给任意 AI 任务 / 会话，即可让它产出与本看板完全一致的配色。
> 适用：报表、看板、PPT、Word、PDF、HTML 页面。

---

## 一、可直接复制的提示词（整段发送）

```
请按以下配色方案输出/改造，严格遵守，不要自行替换或新增颜色：

【配色名称】Morandi 商务低饱和双主色：钢蓝打底 + 赭石强调。整体调性沉稳、高级、商务，适配科技消费品汇报场景。

【主色】
- 钢蓝  #2E4A62（主色：页头/渐变起点、表头、KPI 左边框、选中态按钮、主序列）
- 钢蓝浅 #42596E（仅用于页头渐变中段）
- 赭石  #B5791F（强调色：章节标题竖条、关键数值、hover 高亮、次级强调）

【辅助色】
- 雾青 #8FA3AD
- 紫灰 #7A6E80
- 卡其 #C2B49A

【语义色】
- 正向 / 通过 / 稳定  → 鼠尾草绿 #6E8471
- 负向 / 风险 / 终止  → 砖红（低饱和）#A8524A

【版式与背景】
- 页面背景 #F7F6F3（暖灰米，不要用纯白）
- 卡片 / 面板背景 #FFFFFF
- 边框 #E4E1DB；轨道与分隔线 #EFEDE8 / #F2F0EB
- 正文 #2B2B2B；次要文字 #4A5A6A
- 页头渐变固定为 linear-gradient(116deg, #2E4A62 0%, #42596E 52%, #7A6E80 100%)
- 警示框：底 #FBF4E6 / 边 #E8D9B8

【图表序列色（按此顺序循环，不要打乱）】
#2E4A62 → #B5791F → #8FA3AD → #7A6E80 → #C2B49A → #6E8471 → #A8725C → #5C7480 → #9E8B6E → #4E6070

【问题 / 风险等级配色（全局统一，同一等级在任何图表里必须是同一个颜色）】
- 1级（最严重）#A8524A 砖红
- 2级           #B5791F 赭石
- 3级           #8FA3AD 雾青
- 4级（最轻）   #C2B49A 卡其

【硬性规则】
1. 禁止使用粉红、玫红、高饱和红、荧光色、彩虹渐变。
2. 除页头外不要再用大面积渐变；图表一律用纯色填充，可叠加 8%~12% 透明度的同色系浅底做层次。
3. 单张图/单屏内主视觉色不超过 3 个，其余走同色系明度变化。
4. 语义色只用于状态、等级、风险表达，不用于常规数据系列。
5. 深浅色搭配保证对比度：深底用白字，浅底用 #2B2B2B / #4A5A6A。
6. 禁止表格跨页断行、文字重叠、分隔线散落、杂乱加粗；字号层级：标题 > 章节 > 正文 > 注释，全篇不超过 4 级。
```

## 二、可直接粘贴的 CSS Token

```css
:root{
  /* 文字 */
  --ink:#2B2B2B;          /* 正文 */
  --ink2:#4A5A6A;         /* 次要文字 / 注释 */
  /* 版式 */
  --bg:#F7F6F3;           /* 页面背景 */
  --card:#FFFFFF;         /* 卡片 */
  --line:#E4E1DB;         /* 边框 */
  --track:#EFEDE8;        /* 进度条轨道 */
  --track2:#F2F0EB;       /* 次级轨道 / 标签底 */
  /* 主色 */
  --steel:#2E4A62;
  --steel-lt:#42596E;
  --ochre:#B5791F;
  /* 辅助色 */
  --mist:#8FA3AD;
  --plum:#7A6E80;
  --khaki:#C2B49A;
  /* 语义色 */
  --sage:#6E8471;         /* 正向 */
  --brick:#A8524A;        /* 负向 */
  /* 组件 */
  --warn-bg:#FBF4E6;
  --warn-line:#E8D9B8;
  --header:linear-gradient(116deg,#2E4A62 0%,#42596E 52%,#7A6E80 100%);
}
```

### 图表序列色（JS 数组）

```js
const PAL = ["#2E4A62","#B5791F","#8FA3AD","#7A6E80","#C2B49A",
             "#6E8471","#A8725C","#5C7480","#9E8B6E","#4E6070"];
```

```js
const LVC = {"1级":"#A8524A","2级":"#B5791F","3级":"#8FA3AD","4级":"#C2B49A"};
```
