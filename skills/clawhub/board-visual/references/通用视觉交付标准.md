# 通用视觉交付标准 v1

> 定位：所有对外交付物（报告 / 看板 / PPT / Word / Excel / PDF / HTML）的统一视觉与版式底稿。
> 用法：把「第一章」的提示词整段复制给任意 AI 任务，第二~四章是验收依据。
> 配色部分单独见《配色规范_Morandi商务.md》，本文件可直接引用。

---

## 一、可直接复制的通用提示词（整段发送）

```
请按以下「通用视觉交付标准」进行版式设计与内容组织，配色另见我提供的配色规范（Morandi 商务：钢蓝 + 赭石）。

【总体调性】
沉稳、高级、商务克制。适配科技消费品 / 采购供应链汇报场景。宁可朴素，不要花哨；宁可留白，不要堆砌。

【内容结构】
1. 结论先行：首页 / 首屏必须是「结论 + 关键数字」，不让读者翻页找答案。
2. 结论 → 细节：先给判断，再给支撑数据，最后给附录。
3. 每个模块必须有可执行结论（谁、做什么、什么时候、依据哪条数据）。
4. 必须标注优先级 P0 / P1 / P2（P0 重大-阻塞 / P1 重要-需决策 / P2 优化-可延后）。

【字号与层级】
全篇不超过 4 级：标题 > 章节 > 正文 > 注释。
正文字号：正文 13~14px（Word/PDF 为 10.5~11pt），注释 11~12px。
同一层级字号、颜色、行高必须完全一致，不允许出现随手加大的字号。

【版式与密度】
1. 卡片（meeting-card）风格：圆角 8~10px，1px 浅边框，白底，内边距 13~17px。
2. 禁止：散落加粗、密横线分隔、条目长度参差、文字重叠、图表类型混杂堆砌。
3. 禁止表格跨页断行；长表要么压到一页、要么显式拆表并重复表头。
4. 卡片等高对齐，同组内的 KPI / 图例 / 指标单位必须对齐基准线。
5. 留白优先，页面 8%~12% 的外边距，卡片间距 12~14px。

【图表规范】
1. 同一份材料里至少混合 2~3 种图表类型（环形/柱状/堆叠条/雷达/横道图/评分表），不要通篇柱状图。
2. 饼图/环形图扇区不超过 6 个，超出归类为「其他」。
3. 数值直接在图旁或条尾标注，不要让读者肉眼刻度读数。
4. 单位统一写在标题或轴名里，不在每个数据点重复写。
5. 每张图必须有标题，标题写「结论」，不写「XX图」。
6. 甘特/进度图：含里程碑、周末阴影、当前日期线，条尾标注工期 + DDL。
7. 禁止 3D、立体效果、拟物阴影、大面积撞色渐变。

【表格规范】
1. 表头深底白字，无纵向分割线，横向分割线用浅色 1px。
2. 数字右对齐、统一千分位与小数位；文本左对齐。
3. 需要对比的数据一律用表格双列并排，不用大段文字描述差异。
4. 状态列用 pill 标签（圆角 12~14px、10~12px 字号），不用裸文字。

【数据纪律】
1. 所有数据来自给定原始资料，禁止估算、推测、补全。
2. 需要估算时必须先标注并经我确认，且用独立样式（虚线框 / 斜体）区分。
3. 派生数值必须展示计算过程或公式，Excel 用公式驱动，禁止硬编码结果。
4. 口径不清时在页面上直接写警示框说明口径与影响范围，不要沉默处理。
5. 数据冲突不要自动择优，原样并列并在「待核实」区域记录。

【导出与交付】
1. PDF：A4，≤7 页（超出必须先压缩到附录或拆分），版式不走形优于截图贴付。
2. Excel：公式驱动 + 独立勾稽验证页（自动 PASS/FAIL）。
3. HTML：单文件，内联样式，无外部 CDN 依赖，响应式 + 打印样式。
4. 图片：需要插图时导出 PNG/JPEG，透明底优先，分辨率 ≥ 150dpi。

【交付前自检】
逐项自查后给我一份检查清单结果，包含：页数/尺寸、色值是否与规范一致、是否有散落加粗、是否有表格跨页、图表类型是否 ≥2 种、数据是否均可溯源。
```

## 二、细则展开

### 2.1 字体与层级

| 层级 | 字号（屏幕） | 字号（打印） | 颜色 | 用途 |
|---|---|---|---|---|
| H1 | 20~22px | 16~18pt | `#2E4A62` | 文档标题 |
| H2 | 15~16px | 13~14pt | `#2B2B2B` + 赭石竖条 | 一级章节 |
| H3 | 13.5~14px | 11~12pt | `#2E4A62` | 二级章节 |
| 正文 | 13.5px | 10.5~11pt | `#2B2B2B` | 正文段落 |
| 注释 | 11.5~12px | 9pt | `#4A5A6A` | 口径、来源、脚注 |

字体栈：中文 `PingFang SC / Microsoft YaHei`，西文 `-apple-system / Segoe UI / Helvetica Neue`。
中英混排时英文用西文字体族，数字统一用等宽变体或 `font-variant-numeric: tabular-nums` 保证对齐。

### 2.2 卡片（meeting-card）参数

```
圆角     9px
边框     1px #E4E1DB
背景     #FFFFFF
内边距   15px 17px
标题下边距 10px
行高     1.62
卡片间距 12~14px
hover   #FAF9F7
```

KPI 卡统一：左侧 3px 主色竖条（`#2E4A62`），数值 22~24px 半透明主色，标签 12px 次要色，副说明 11px。

### 2.3 图表选型速查

| 场景 | 推荐图形 |
|---|---|
| 占比构成（≤6 项） | 环形图 + 中心大数字 |
| 跨对象横向对比 | 横向条形图（降序） |
| 时间趋势 | 柱 + 累计折线（双轴） |
| 双维度构成（如国家 × 等级） | 堆叠条形图 |
| 多指标能力评估 | 雷达图 |
| 综合评价/评级 | 评分表 + 色阶单元格 |
| 工期/里程碑 | 横道图（周末阴影 + 当日线 + 条尾标签） |
| 排名 | 有序条形 + 序号徽标 |

### 2.4 内容与优先级表达

```
P0  重大 / 阻塞：影响定标、合同成立、资金安全
P1  重要 / 需决策：影响成本、工期、质量但存在替代方案
P2  优化建议：可延后或采纳与否影响有限
```

- 优先级用色：P0 `#A8524A`，P1 `#B5791F`，P2 `#8FA3AD`
- 每个结论必须落到「可执行清单」：动作 / 责任人 / 时间点 / 依据数据

### 2.5 数据纪律红线

1. 原始报价、合同金额、台账数字必须原样引用，二次计算的要留公式
2. 估算值：需事先确认 + 视觉隔离 + 明确标注"估算"
3. 口径缺失：用警示框 `#FBF4E6 / #E8D9B8` 明示，并给出可用的代理口径
4. 数据冲突：并列呈现，进入「待核实内容」，不擅自择优

### 2.6 HTML 单文件要求

- 无 CDN、无外部字体、无网络请求，断网可打开
- 图表用手写 SVG（环形用 `stroke-dasharray`，避免引入 ECharts 等）
- 筛选交互用原生 JS + `data-*` 属性 + `.hide` 类切换
- 左侧二级目录导航（sticky），锚点必须命中存在
- 必须含 `@media print`（隐藏侧栏、白底、`page-break-inside:avoid`）
- 折叠区用 `<details>`，日志、口径说明、附表一律默认收起

## 三、禁止清单

| 禁止项 | 替代做法 |
|---|---|
| 粉红 / 玫红 / 高饱和红 / 荧光色 | 负向用砖红 `#A8524A` |
| 通篇柱状图 | 至少 2~3 种图形混合 |
| 3D 图表、拟物阴影、彩虹渐变 | 扁平纯色 + 8%~12% 同色浅底 |
| 表格跨页断行 | 压一页 / 显式拆表并重复表头 |
| 散落加粗、随手放大字号 | 统一层级，强调改用颜色或卡片 |
| 密横线分隔 | 卡片 + 留白分组 |
| 硬编码计算值 | Excel 公式 + 勾稽验证页 |
| 数据估算不标注 | 先确认 + 虚线框/斜体隔离 |
| 截图贴付代替排版 | 原生矢量排版优先 |
| 结论藏在附录里 | 首屏结论 + 关键数字 |

## 四、交付前自检清单

- [ ] 页数 / 尺寸符合要求（A4 PDF ≤7 页）
- [ ] 色值全部落在规范色表内，无新增色
- [ ] 字号层级 ≤4 级，无散落加粗
- [ ] 无表格跨页断行，无文字重叠
- [ ] 图表类型 ≥2 种，每张图标题是结论句
- [ ] 优先级 P0/P1/P2 已标注且配色正确
- [ ] 派生数据可溯源，Excel 为公式而非硬编码
- [ ] 估算值已标注并经确认
- [ ] 口径冲突已进入「待核实」而非静默处理
- [ ] HTML：锚点全命中、JS 通过语法检查、断网可打开
- [ ] 每张图表数据单位统一，数值直接可读，无需目测刻度
- [ ] 附录 / 附表 / 日志默认折叠，正文不被撑长
