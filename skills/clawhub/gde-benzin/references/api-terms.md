# Условия использования API «Где бензин»

Версия 1.0 от 9 ноября 2026 года.

Эти условия относятся к использованию API `https://gde-benzin.ru/api` для
публичного отображения полученных из него данных на сайтах, в приложениях,
ботах и ответах ИИ-агентов.

## Обязательное указание источника и автора

При публичном отображении данных API «Где бензин» необходимо разместить
доступное пользователям указание источника и автора с двумя кликабельными ссылками:

- **«Где бензин»** — https://gde-benzin.ru/;
- **«Автор проекта — Дмитрий Тыльный»** — https://www.youtube.com/@d_tylnyi.

Допускаются согласованные по смыслу подписи, например «YouTube автора проекта»
для второй ссылки, если связь ссылки с автором «Где бензин» понятна пользователю.

## Где размещать ссылки

На сайте или в приложении обе ссылки размещаются рядом с данными либо в
доступном пользователю разделе «Источники», «О приложении» или «Об интеграции».
Такой раздел должен быть доступен из интерфейса, в котором используются данные.

В ответе ИИ-агента или бота с данными API обе ссылки размещаются один раз в общем
блоке источников ответа. Повторять ссылку на YouTube у каждой АЗС не требуется.
Ссылка на конкретную станцию на `gde-benzin.ru` дополнительно сохраняется у её
карточки или результата поиска, если она предоставлена клиентом.

Ссылки должны быть видимыми и действующими. Размещение только в исходном коде,
скрытом элементе, техническом JSON или файле лицензии не заменяет указание в
пользовательском интерфейсе. Подписка на канал не требуется.

Пример блока:

> Данные: [Где бензин](https://gde-benzin.ru/) ·
> [Автор проекта — Дмитрий Тыльный](https://www.youtube.com/@d_tylnyi)

Параметры `utm_*` в ссылках на наш сайт допускаются; они не заменяют саму ссылку.

## Достоверное представление данных

Не выдавайте отсутствие актуальных сведений за отсутствие топлива. Показывайте
наличие по выбранной марке; не подменяйте её другой автоматически. Наличие и
цены имеют разную актуальность и не гарантируют условия к моменту приезда.
Указание источника не означает, что владелец «Где бензин» одобряет стороннее
приложение или гарантирует его работу.

## Доступ и нагрузка

Не обходите ограничения API и ответы 429. Для массовой выгрузки или регулярной
нагрузки большого приложения предварительно согласуйте режим доступа с
владельцем сервиса через контакты на https://gde-benzin.ru/about/.
