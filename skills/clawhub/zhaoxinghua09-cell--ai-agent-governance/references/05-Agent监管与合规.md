# 05 Agent 监管与合规

> 用途：回答「中国/新加坡/欧盟/美国对 Agent 有什么监管要求」。
> 核对基准日：2026-08-27（Agent 监管快速演进，引用前复核官方原文）

## 1. 中国——全球首个 Agent 顶层政策（2026-05）

**《智能体规范应用与创新发展实施意见》**（国家网信办、发改委、工信部三部门，2026-05 印发）——国内首个专门针对 AI 智能体的顶层政策文件。

**核心要求（企业落地要点）**：
- **防越权**：智能体权限边界管理，不得超出授权范围行动；
- **防逃逸**：防止智能体绕过安全控制/沙箱/指令约束；
- **防滥用**：防止智能体被用于违规、欺诈、数据滥用；
- **安全评估**：智能体服务上线前安全评估（有舆论属性/社会动员能力的服务）；
- **备案衔接**：与算法备案、大模型备案体系衔接；
- **内容安全**：智能体生成内容纳入内容安全与标识要求；
- **未成年人保护**：面向未成年人的智能体服务特殊要求。

**判断**：凡对外提供智能体服务（客服、助手、自动化营销等），或企业内部部署自主行动 Agent，均需对照落实。

## 2. 新加坡——Agentic AI 治理框架（2026-05）

IMDA/PDPC 发布**模型 AI 治理框架 Agentic AI 版**（2026-05），全球首个专门针对自主智能体的国家级治理框架：

- **问责与监督**：明确 Agent 部署方的问责义务与人工监督点；
- **安全与可靠**：Agent 失败模式（越权/幻觉）的安全要求；
- **透明度**：Agent 自主行动的可见性与可解释性；
- **数据保护**：Agent 处理个人数据的 PDPA 合规（同意/目的限制/泄露通报）；
- **测试工具**：AI Verify 延伸至 Agent 场景。

## 3. 欧盟——AI Act 延伸（进行中）

- AI Act 本身按"系统"监管，Agent 作为组合系统适用：高风险场景（Annex III 中的招聘/信贷等由 Agent 执行）触发高风险义务；
- 2026 年欧盟委员会与 AI Office 持续关注 Agent 化 AI 的透明度与责任；
- GPAI 规则（2026-08-02 全面执法）覆盖支撑 Agent 的底层模型；
- 未来方向：Agent 可能触发新增透明度/记录义务（观察 AI Act 年度评估）。

## 4. 美国——NIST AI Agent 标准倡议（2026-01）

- NIST 启动 **AI Agent Standards Initiative**（2026-01），将 AI RMF 延伸至自主智能体；
- COSAiS（Securing AI Systems 控制覆盖层）：单 Agent/多 Agent 系统控制项草案（2026 中旬）；
- 加州等州法对 Agent 化决策的关注上升（自动化决策披露义务延伸）。
