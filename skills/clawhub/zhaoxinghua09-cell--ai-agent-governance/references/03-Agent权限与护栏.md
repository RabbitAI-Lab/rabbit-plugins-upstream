# 03 Agent 权限与护栏

> 用途：回答「Agent 权限怎么设计」「工具调用怎么控制」「怎么防越权逃逸」。
> 核对基准日：2026-08-27

## 1. 最小权限原则（Agent 版）

**Agent 只能获得完成任务所需的最少权限**，且权限要动态收敛：

| 维度 | 要求 |
|---|---|
| 工具权限 | 只接入任务必需的工具，其余一律不接 |
| 数据权限 | 只给任务所需数据级别的访问（见 AI 治理 02 模块数据分级） |
| 操作权限 | 只读优先；写操作需场景化授权 |
| 时效权限 | 一次性任务用临时凭证，用完即销 |
| 环境隔离 | 生产/测试环境分离，Agent 默认在受限环境 |

## 2. 工具调用控制（护栏五件套）

| 护栏 | 说明 |
|---|---|
| 1. 工具白名单 | 只允许调用批准清单内的工具 |
| 2. 参数校验 | 关键参数（收件人、金额、目标地址）强校验，敏感操作二次确认 |
| 3. 操作分级 | 只读自动执行；高风险写操作须人工审批（如发邮件/转账/删数据） |
| 4. 速率限制 | 频率/批量限制，防异常放大 |
| 5. 熔断开关 | 异常检测触发自动暂停（停止所有 Agent 行动，转人工） |

## 3. 防越权与逃逸

**越权防护**：
- 权限边界硬编码（Agent 无法自行扩大权限）
- 敏感操作强制人工确认（即使 Agent 自主度高）
- 权限审计：定期比对"实际使用权限 vs 最小所需"

**防逃逸（提示注入防护）**：
- 系统指令与外部输入隔离
- 外部输入（网页/邮件/文档内容）标记为"不可信数据"，不得改变 Agent 指令
- 对 Agent 能读取的外部内容做内容过滤
- 红队定期测试注入攻击

## 4. 审计与日志

| 日志项 | 内容 |
|---|---|
| 调用日志 | 谁（哪个 Agent）调用了什么工具、何时、参数、结果 |
| 决策日志 | Agent 的关键决策路径（为什么执行该操作） |
| 权限日志 | 权限授予/变更/撤销记录 |
| 事件日志 | 异常行为、拦截记录、熔断记录 |

**审计要求**：日志不可篡改（防抵赖）、可检索（事故归因）、保留周期符合监管要求。

## 5. 沙箱与隔离

- 高风险/全自主 Agent：运行在沙箱环境，与生产系统网络隔离；
- 外部内容获取：在隔离环境解析，防止恶意内容直接影响核心系统；
- 凭证管理：Agent 使用的 API 密钥走统一凭据体系，不落盘明文（见 unified-credential-vault 方法论）。

## 6. 权限评估实操（工具 `perm` 命令）

输入 Agent 已配置的工具清单 + 任务所需能力，工具自动判断是否"最小权限"并给出建议：

```
已配置工具 vs 任务必需工具 → 多余权限高亮 → 建议移除
必需但未配置工具 → 缺口提示
高风险操作未设人工确认 → 护栏缺失提示
```
