# 07 Agent 治理 FAQ

> 用途：高频疑问速查 + 常见误区纠偏。

**Q：我们没有专门的"Agent"，只是用了 AI 助手，需要 Agent 治理吗？**
看两点：AI 能否调用工具/API 执行操作（不只是输出内容）？是否有自主决策链路？满足其一即适用 Agent 治理框架（01 模块 §1 对比表）。

**Q：Agent 治理和普通 AI 治理什么关系？**
互补关系：普通 AI 治理（ai-governance-playbook）管"人用 AI"的框架/制度/法规；Agent 治理管"AI 自己行动"的权限/自主性/责任/护栏。Agent 是 AI 治理的"升级场景"，制度可挂接而非另起炉灶。

**Q：给 Agent 配权限，给大点省事行不行？**
不行——权限膨胀是越权风险第一大来源。最小权限 + 动态收敛是硬要求（03 模块），权限越界出事故时部署方担责权重上升（04 模块）。

**Q：Agent 是"黑盒"，出了事怎么找原因？**
靠审计日志（调用/决策/权限/事件四类日志）+ 决策日志记录关键路径。没有日志 = 无法归因 = 责任划分困难。日志不可篡改、可检索是底线（03 模块 §4）。

**Q：中国智能体政策是强制的吗？**
《智能体规范应用与创新发展实施意见》是部门规章层级的政策文件，对外提供智能体服务的企业应对照落实安全评估、备案衔接、防越权逃逸等要求；企业内部 Agent 也要按政策导向建立治理（05 模块 §1）。

**Q：Agent 出事故，公司能说"是 AI 干的"免责吗？**
不能——Agent 行为视同部署方/使用方行为（替代责任），除非能证明是模型/开发方的系统性缺陷且已按规范使用（04 模块）。

**Q：多 Agent 协作的系统风险更高吗？**
是的——级联失败是新增风险（一个 Agent 误判触发下游连锁）。治理要点：互信边界、全局熔断、每层审计（01 模块 §2 风险 #5）。

**Q：工具命令报错怎么办？**
确认 Python 3.8+ 且路径正确（skill 根目录运行 `python tools/agent_gov_toolkit.py --help`）。

**Q：法规更新怎么跟踪？**
中国（网信办智能体实施细则）、新加坡（IMDA/PDPC Agentic 框架更新）、欧盟（AI Act 年度评估）、美国（NIST AI Agent 标准）——季度复核；本技能速查表随版本更新。
