# 01 Agent 与风险全景

> 用途：回答「Agent 是什么」「和传统自动化有什么区别」「有什么独特风险」。
> 核对基准日：2026-08-27

## 1. 什么是 AI 智能体（Agent）

**AI 智能体（Agentic AI）**：能够自主规划、决策并执行行动的 AI 系统——不仅"回答问题"，还能调用工具、访问系统、执行操作、完成任务闭环。

| 对比 | 传统 AI 工具 | AI 智能体（Agent） |
|---|---|---|
| 输出 | 内容/建议 | **行动**（调用工具、操作业务系统） |
| 流程 | 用户驱动 | 自主规划执行（可能多步） |
| 权限 | 无系统权限 | **有工具/API 权限** |
| 失败影响 | 输出错误 | **实际业务后果**（误发邮件/错下订单） |
| 监督 | 人审核输出 | 需要持续监督与护栏 |

**关键差异一句话**：**从"人用 AI"变成"AI 替人办事"**——治理逻辑随之改变。

## 2. 六类核心风险（Agent 特有）

| # | 风险 | 说明 | 示例 |
|---|---|---|---|
| 1 | **越权（Overreach）** | Agent 执行超出预期用途/权限的操作 | 客服 Agent 擅自修改订单价格 |
| 2 | **逃逸（Escape）** | Agent 绕过约束/沙箱/护栏 | 提示注入诱导 Agent 执行任意命令 |
| 3 | **滥用（Misuse）** | Agent 被恶意利用 | 攻击者操纵 Agent 泄露数据 |
| 4 | **幻觉链（Hallucination Chain）** | 多步自主执行中错误被放大 | 基于错误信息自动发出错误指令 |
| 5 | **级联失败（Cascade）** | 多 Agent 协作时错误传导 | 一个 Agent 的误判触发下游连锁操作 |
| 6 | **不可追溯（Untraceability）** | 自主行动难以审计归因 | 无法定位是哪个环节出的问题 |

## 3. 风险等级框架（工具 `risk` 命令的评分模型）

按 4 个维度评估 Agent 风险（1-5 分）：

| 维度 | 权重 | 1 分 | 5 分 |
|---|---|---|---|
| 权限范围 | 35% | 只读、无敏感数据 | 可写可执行、可访问敏感系统 |
| 自主程度 | 30% | 每步人工确认 | 全自主多步执行无干预 |
| 影响后果 | 25% | 可回滚、低影响 | 不可逆、资金/数据/合规损失 |
| 暴露面 | 10% | 内部受控 | 面向外部/公开 |

**判定**：加权 ≥4.0 → 高风险（委员会审批）；2.5-3.9 → 中风险；<2.5 → 低风险。

## 4. Agent 部署形态（决定治理重点）

| 形态 | 例子 | 治理重点 |
|---|---|---|
| 单 Agent | 客服/文档处理 Agent | 权限、输出控制 |
| 多 Agent 协作 | 编排式工作流 | 级联失败、互信边界 |
| Agent + 人审 | 建议型 Agent | 人工复核点 |
| 全自主 Agent | 无人值守执行 | 沙箱、熔断、审计 |
| Agent 即服务 | 外部 Agent 平台 | 供应商评估、数据边界 |

## 5. 快速自查：我们的 Agent 处在什么风险档

1. 能访问什么（只读/可写/敏感）？
2. 自主到什么程度（每步确认/全自主）？
3. 出错的后果（可回滚/不可逆）？
4. 谁在监督（有人工/无人值守）？
5. 谁负责（明确/模糊）？
→ 用工具 `risk` 命令输入 Agent 描述自动评分。
