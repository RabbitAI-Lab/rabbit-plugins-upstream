# 06 Agent 治理制度模板

> 用途：回答「Agent 登记表怎么填」「审批流怎么走」「事件响应怎么做」。
> 配套工具 `risk`/`perm` 命令辅助评估。

## 1. Agent 登记表（模板）

| 字段 | 说明 |
|---|---|
| Agent 编号 | 如 AG-2026-001 |
| Agent 名称/用途 | 一句话描述 |
| 所属部门/负责人 | 责任主体 |
| 部署形态 | 单 Agent / 多 Agent 协作 / Agent+人审 / 全自主 |
| 工具接入清单 | 已接入工具/API |
| 数据级别 | 公开/内部/机密/个人信息 |
| 风险等级 | 低/中/高（用 `risk` 命令评定） |
| 自主程度 | 每步确认 / 条件自主 / 全自主 |
| 人工监督点 | 哪些操作必须人确认 |
| 沙箱/隔离 | 是否隔离环境 |
| 监控与熔断 | 告警配置、熔断开关 |
| 供应商 | 自研 / 第三方平台 |
| 审批状态 | 草稿/审批中/已批准/已驳回 |
| 复审日期 | 权限复审排期 |

## 2. Agent 审批流程（按风险分级）

```
申请（业务填写登记表）
   │
   ▼
风险评估（risk 命令 + 03 模块权限检查）
   │
   ├── 低风险 → 部门审批，登记即用
   ├── 中风险 → 部门+信息安全审批，半年度复审
   ├── 高风险 → AI 治理委员会审批 + 红队测试 + 专项评估，季度复审
   └── 禁止级 → 驳回（如：全自主访问机密系统且无熔断）
```

## 3. Agent 事件响应流程（模板）

```
事件发现（告警/用户上报/审计异常）
   │
   ▼
第1步 冻结：停止 Agent、撤销权限、隔离环境（30 分钟内）
   │
   ▼
第2步 取证：日志快照、参数留存、现场保护
   │
   ▼
第3步 分级：影响范围（数据/资金/合规/声誉）→ 上报层级
   │
   ▼
第4步 处置：数据补救（召回邮件/撤销操作）、止损
   │
   ▼
第5步 归因：三线归因（开发/部署/使用，见 04 模块）
   │
   ▼
第6步 复盘：根因分析 → 修复（权限/护栏/测试）→ 更新制度 → 报告管理层
```
