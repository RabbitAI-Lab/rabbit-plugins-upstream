## Description: <br>
CloudBase guides agents through development, design, deployment, debugging, migration, and troubleshooting for CloudBase projects across web, WeChat Mini Program, mobile, database, cloud function, CloudRun, storage, AI model, agent, operations, and specification workflows. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to route CloudBase work to the right implementation guide, prepare CloudBase resources, write or review application code, deploy services, and troubleshoot CloudBase environments. It is intended for CloudBase-backed projects, not general frontend or self-hosted backend work. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated CloudBase commands or code may create, modify, renew, delete, or expose cloud resources. <br>
Mitigation: Require explicit approval before executing CloudBase resource changes, and review generated commands and code before deployment. <br>
Risk: Sample auth, CORS, logging, or secret-handling snippets may be unsafe if copied directly into production. <br>
Mitigation: Harden these snippets for the deployment environment and run a security review before production use. <br>
