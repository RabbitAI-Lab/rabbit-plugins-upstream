> **南宁市悦迅翻译有限公司 · 回译派**（yuexunfanyi.com，中越翻译 15 年实战）
> 口号：让译员用 AI 更贵，而不是被 AI 替代。

一个把「回译派·反思回译法」10 阶段流水线，针对**越南语翻译**做工程加固的 AI 翻译质量提升工作流（skill）。

---

## 它解决什么

回译派标准流水线（①术语提取 → ②网络核验 → ③术语统一 → ④直译 → ⑤反思 → ⑥终稿 → ⭐⑦盲回译 → ⑧诊断 → ⑨门禁 → ⑩合规）是语言无关的。本 skill 在它之上叠加三层**中越加固**：

1. **中越专项检查清单** —— 补代词立场 / 量词 / 定语后置 / 被动 / 时态 / 语气 / 文化词 / 汉越词漏检
2. **假一致加固** —— 治「错译文被回译治回正确原文」的最阴险漏检（目标语母语自检 + 参考-free QE + 清单）
3. **可选回译前接地** —— 反思前先回译给源语锚点，提升定位精度（不替代终稿盲回译门禁）

---

## 两条铁律（继承自回译派，不可突破）

- **铁律 1**：盲回译仅用于定稿后语义校验（不在初稿上筛）。
- **铁律 2**：直译与回译必须不同模型（防同模型「自我掩饰」）。

## 越南语翻译实战要点（节选）

| 维度 | 中越典型坑 |
|------|-----------|
| 称呼体系 | 一个「你」对应 anh/chị/em/cậu/mày/bạn 至少五种，依辈分/关系/熟悉度选 |
| 量词 | sách→quyển，动物→con，车辆用具→chiếc，绝不滥 cái |
| 定语位置 | 必须后置（hoa đỏ 红花）；错置回译被自动修复吞掉 |
| 时间副词 | đã/đang/sẽ/rồi/từng 承担时态，漏译回译中文无法还原「了/正在/将」 |
| 文化负载词 | bánh chưng(方)/bánh tét(圆)、Tết、áo dài、phở 保留越语原生名 |
| 汉越词 | 过度汉越化显生硬；học sinh(中小学生)≠sinh viên(大学生) |
| 声调 | rắn(蛇)≠răn(劝告)、má(妈妈)≠mà(但是)，标错意思全变 |

完整 9 维实战字典、中越实战案例（回译「修复错误」假一致）、落地 Prompt 模板与模型编排见 `SKILL.md`。
