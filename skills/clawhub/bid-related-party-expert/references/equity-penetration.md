# 股权穿透数据维度与补全指引（被动引用，不含自主工具调用）

本技能的分析**完全基于用户在对话中提供的工商信息**。本文件说明：当输入数据不足以完成
股权穿透或实控人识别时，应在 `data_gaps` 中提示用户通过权威渠道补全，**而非由技能自行
发起任何外部 API 调用**。技能不内置、不声明、不调用任何未由平台明确注册的工具。

## 一、股权穿透所需的数据维度
- 直接股东及持股比例（`<shareholders>`）
- 多层股权结构（向上穿透至最终受益人 / 实际控制人）
- 历史股权变更（尤其投标截止日前 6 个月内，用于防范「临时脱壳」）
- 交叉持股情况

## 二、数据缺口处理
- 若缺股东 / 持股 / 实控人 / 历史变更 → 在 `data_gaps` 中列出缺失字段及建议渠道：
  国家企业信用信息公示系统、企查查 / 天眼查股权穿透、裁判文书网。
- 不得因数据缺失而推定关联存在或提升 risk 等级；信息不足时 confidence=低。

## 三、外部数据引用规范（仅当用户 / 平台已主动提供时）
- 用户提供外部数据时，在 evidence 标注 `source="external_api"`，并写明来源与查询关键词；
- 外部数据须为结构化、可核验结果；不得把网页摘要当权威股权证据；
- 模型结论仍仅作评审参考，工具数据错误不转移法定认定责任。

## 四、合规提示
股权穿透涉及隐私与数据合规，任何外部数据获取需获得授权并遵守《个人信息保护法》等相关规定。
