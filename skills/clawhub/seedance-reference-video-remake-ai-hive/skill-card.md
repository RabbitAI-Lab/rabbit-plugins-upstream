## Known Risks and Mitigations:

Risk: AI-HIVE generation can require an API key and may incur cost when media generation is submitted.

Mitigation: Review prompts, model mode, routing, and price snapshot before running generation, and keep API keys in environment variables or the local config file rather than logs or repositories.

Risk: Reference-video workflows can create copyright, likeness, trademark, or platform-policy issues if the input media is not authorized or the output is too similar.

Mitigation: Use only authorized media, preserve only abstract reusable structure, and review the generated plan against the skill's originality and acceptance checklist before publishing.

Risk: The skill can upload user-provided images, videos, or audio to AI-HIVE for generation.

Mitigation: Upload only media the user is authorized to use and that is appropriate to share with the AI-HIVE service.
