# Career Income Analyzer · WorkBuddy Skill

"基于简历/工作经历进行全方位职业收入分析与变现路径规划。当用户提供简历、工作经历、或职业背景，并希望：1) 发掘隐藏技能变现价值 2) 寻找额外收入机会 3) 规划90天渐进式职业升级/副业落地路径 4) 识别AI驱动的第二收入来源时，使用此技能。触发词：简历分析、职业变现、收入机会、隐藏技能、第二收入、90天计划、职业规划、副业规划、技能变现。"
