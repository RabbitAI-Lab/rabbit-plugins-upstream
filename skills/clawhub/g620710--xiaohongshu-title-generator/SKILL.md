# 小红书爆款标题生成器

> AI驱动的小红书标题生成神器，10秒产出10条爆款标题，点击率翻倍不是梦
> **v1.0**：12大爆款公式 + 8种内容风格 + 智能评分 + 优化建议

## 核心价值

辛辛苦苦写的笔记没人看？90%的问题出在标题上。这个工具帮你：
- **秒出爆款**：输入关键词，10秒生成10条高点击率标题
- **公式化爆款**：内置12大验证过的爆款标题公式，条条都是流量密码
- **风格全覆盖**：种草/测评/干货/情绪/教程/避雷/合集/对比，8种风格任选
- **智能评分**：AI预估点击率，帮你选最优标题
- **优化建议**：告诉你标题哪里可以改得更好
- **场景适配**：美妆/穿搭/美食/旅行/职场/学习/家居/健身全品类

## When to Use

以下场景直接触发本技能：
- 写小红书笔记不知道起什么标题
- 标题写了总觉得不够吸引眼球
- 想提高笔记点击率和互动率
- 批量做号需要快速产出标题
- 做小红书代运营需要给客户写标题
- 想学习爆款标题的底层逻辑
- 同类笔记流量上不去，想换标题试试
- 新人做小红书，不知道标题怎么写

## Core Rules

1. 每次至少生成10条标题，覆盖不同风格和公式
2. 标题必须符合小红书平台调性，口语化、有情绪、带钩子
3. 每条标题附点击率评分（0-100）和适用场景说明
4. 支持指定风格/品类/目标人群，精准生成
5. 给出优化建议，告诉用户为什么这个标题好/不好
6. 输出格式清晰，方便复制粘贴使用

## Quick Start

### 第一步：配置环境变量

```bash
export XHS_API_USER_KEY="你的DeepSeek API Key"
# 可选：自定义API地址
export DEEPSEEK_BASE_URL="https://api.deepseek.com/v1"
```

### 第二步：生成标题

```bash
python3 scripts/generate_title.py "夏季连衣裙穿搭"
```

### 第三步：指定风格和数量

```bash
python3 scripts/generate_title.py "粉底液测评" --style 种草 --count 15 --niche 美妆
```

## 输出格式

每条标题包含：
- 标题内容（带emoji，符合小红书风格）
- 点击率预估评分（0-100）
- 使用的爆款公式
- 适用场景说明
- TOP3推荐

## 12大爆款公式

1. 数字冲击法：「3个方法」「5分钟搞定」
2. 悬念钩子法：「99%的人不知道」「最后一个绝了」
3. 痛点共鸣法：「谁懂啊」「再也不用」
4. 利益承诺法：「白嫖」「必看」「建议收藏」
5. 对比反差法：「从XX到XX」「千万别XX」
6. 情绪煽动法：「绝绝子」「yyds」「破防了」
7. 避雷踩坑法：「避坑」「别踩雷」「血泪教训」
8. 干货教程法：「保姆级」「零基础」「手把手」
9. 合集清单法：「合集」「盘点」「清单」
10. 身份标签法：「打工人」「学生党」「宝妈」
11. 时效性法：「2026最新」「今年必入」
12. 疑问反问法：「还有谁」「你确定」
