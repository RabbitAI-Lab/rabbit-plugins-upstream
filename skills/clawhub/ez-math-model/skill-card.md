## Description: <br>
Use when solving CUMCM, MCM, ICM, or other mathematical modeling tasks that need contest problem intake, model selection, Python solving, figures, paper writing, quality audit, and packaged deliverables. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Students, instructors, and modeling-team developers use this skill to run a structured mathematical modeling workflow from contest problem intake through model selection, Python solving, paper drafting, quality audit, and packaged delivery. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Bundled PaperOrchestra components add broad agent-history scanning, global skill installation, and plaintext credential persistence beyond the main math-modeling workflow. <br>
Mitigation: Review before installing; avoid running external/paper-orchestra/setup.sh unless intentionally installing nested skills and accepting plaintext key storage. <br>
Risk: Corpus and aggregation features can inspect wider local folders than the immediate modeling task requires. <br>
Mitigation: Keep corpus and PaperOrchestra aggregation pointed at narrow project folders, and leave corpus, webcrawl, dataset, and inherited skills disabled unless needed. <br>
