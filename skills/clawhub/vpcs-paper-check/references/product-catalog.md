# 维普 VPCS 15 个产品的标准目录

本目录是产品选型和下单时的单一业务说明。每个产品都有独立编码，不能把“维普查重、AIGC、格式、智评、专项”当成一个产品。

## 价格权威和命名规则

- 价格、启用状态、支付渠道、字数上限和报告保留期已经写入本目录的 2026-09-27 快照；只有用户明确要求最新值时，才查看 `/pwp` 页面或配置接口。
- 本次目录价格快照抓取于 `2026-09-27`。快照用于解释和测试，不是永久价目表。
- `live_label` 是接口返回的页面短名称；`canonical_name` 是本 Skill 对 agent 使用的完整商品名称；`aliases` 用来识别用户口语和旧页面叫法。
- 用户说“维普查重大学生版”时必须落到 `dxs`；说“维普AIGC检测”时必须落到 `aigc`；说“维普格式检测”时必须落到 `format_dxs`。不要用一个产品替换另一个产品。
- 价格不同于平台能否接受学校报告。官方验真能证明报告可被维普验真页识别，不能证明学校会接受该版本。

默认读取本目录中的产品表。需要当前价格或启用状态时查看 `/pwp` 页面；一次页面查看即可，提交前仍以订单页面金额为准。

机器可读目录见 [product-catalog.json](product-catalog.json)。

## 选型决策

先问材料身份，再问检测目标：

1. 材料是本科、硕博、期刊、职称/成果、课程作业还是科研材料？
2. 学校、期刊或单位是否指定了完整产品名、版本和检测系统？
3. 目标是文字相似性、疑似 AI、格式、综合评阅、参考文献、校对，还是数据图像可信度？

选择优先级：

1. 学校/期刊/单位的正式通知；
2. 当前页面可用产品和实时价格；
3. 本目录的场景建议。

常见组合只是阶段组合，不是互相替代：

| 目标 | 组合示例 | 解释 |
|---|---|---|
| 本科定稿 | `dxs` + `aigc` + `format_dxs` | 查重、AIGC 和格式分别处理 |
| 硕博定稿 | `yjs` + `aigc`，按通知决定是否加智评 | 不把智评当查重 |
| 期刊投稿 | `bjb` + `zzzp_qkb` + `special_ref_quality` | 相似性、稿件评阅和参考文献分开 |
| 科研材料 | `ky` + `special_data_image_standard` 或 `special_data_image_pro` | 文字风险和数据图像风险分开 |
| 课程作业 | `zy`；若老师另要求 AIGC，再加 `aigc` | 以课程通知为准 |

不要从价格或名称猜学校是否接受。维普自查结果、官方验真结果和学校终检接受范围是三件事。

## 数据库范围说明

查重类产品都以页面和报告实际展示的数据库范围为准。常见范围包括中文科技期刊、博士/硕士学位论文、外文特色文献、报纸、专利、会议、古籍/图书、IPUB、互联网数据/文档、港澳台、维普优先出版和年鉴等；不同版本的组合不同。

页面展示“高校/机构/个人自建资源”不等于校外订单可以读取任意学校的私有论文库。学校自建库、库更新时间、文档解析和统计公式都可能造成差异。不要把“包含某校私有库”的宣传当成接口事实。

## 给 agent 的强制输出格式

任何产品咨询都至少输出：

```text
产品全名：{canonical_name}
下单编码：{code}
当前价格：{live price snapshot}；正式下单前读取页面或实时配置
计价方式：{按1000字符/10000字符/按篇}
适用场景：{audience}
主要结果：{report_focus}
不能替代：{not_for}
入口：{route}
```

用户只说“维普查重”时，不能直接替用户选 `dxs`。必须追问论文层次/材料类型和学校或单位是否指定版本；用户只说“AI率”时，先区分 `aigc` 与 `zzzp_*`。
