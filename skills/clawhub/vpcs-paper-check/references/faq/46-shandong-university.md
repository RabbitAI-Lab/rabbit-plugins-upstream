## 文章声称的分档

### 本科

- `R ≤ 15%`：文章称查重合格、准予答辩；
- `15%-30%`：文章称限期修改一次，复查合格后答辩；
- `R > 30%`：文章称可能延期并失去优秀资格。

### 硕博

文章称外审/盲审前通常 `R ≤ 10%`，医学部、文学院等部分学科文章建议 `R ≤ 5%-8%`。

## AIGC 文章口径

文章把 AIGC 作为初稿和终稿的两阶段问题：初稿先排查工整、模板化和高疑似段落，向学校提交前再使用学校指定的维普或知网版本做终审。

## 证据边界

山东大学有不同校区、学院和学科规则，不能把文章分档当成“一校三区统一政策”。AIGC 的所谓红线、其他平台价格和降重入口都不是 VPCS API 事实。先查本年度学校通知，再决定产品和系统。
