## 文章给出的参考分档

文章导读把本科常见范围概括为 `15%-20%` 以内、硕博常见为 `5%-10%` 以内，并将毕业季描述为 3-6 月及 10-12 月。正文的示例分档：

| 人群 | 文章描述 |
|---|---|
| 本科 `R < 10%-15%` | 描述为合格、直接答辩或优秀参考 |
| 本科 `15% ≤ R ≤ 30%` | 描述为修改、复查或整改 |
| 本科 `R > 30%` | 描述为可能取消本次答辩资格或延期 |
| 硕博 `R ≤ 5%` | 文章称部分重点高校用于优秀/免送盲审参考 |
| 硕博 `R ≤ 10%` | 文章称常见送外审参考 |
| 硕博 `10% < R ≤ 20%` | 文章称可能进入说明、整改或复议 |
| AIGC `15%-20%` | 文章描述为相对安全区 |
| AIGC `>30%` 或重点章节整段标红 | 文章描述为预警，可能要求过程材料或原始数据 |

## 文章中的站内导流

文章还列出知网、万方、PapersVIP AIGC 和智能降重等入口，并写出相应的检测或服务建议。这些是页面文章的导流内容，不属于 VPCS 的公共 API 合约，也不能作为当前价格、结果差异或服务质量承诺。

## 必须加的边界

这不是全国统一标准，也不是教育主管部门文件。学校阈值会按年份、学院、学科、学位层次、查重系统、章节规则和 AIGC 管理办法变化。回答“我学校多少算合格”时：

1. 先要求用户提供本年度教务处、研究生院、学院或导师的正式通知；
2. 确认学校指定的是维普、知网、Turnitin 或其他系统；
3. 再把同一报告中的同一指标与校方阈值对照；
4. 不把“安全线”“红线”“稳过”写成保证。
