## 文章声称的分档

### 本科

- `R ≤ 10%`：文章称为优秀参考；
- `10% < R ≤ 20%`：文章称通过、准予答辩；
- `20% < R ≤ 30%`：文章称需要整改、复查，可能延后答辩。

### 硕士

- 送盲审前文章称通常要求 `R ≤ 10%`；
- 法学、经管等部分学科文章称可能要求 `R ≤ 8%`。

## 系统和自查说明

文章称郑州大学不同院系可能采用知网或维普。用户不能根据文章或产品价格自行选择系统，必须确认院系、学位层次、年份、送审还是答辩环节。

文章还列出其他平台、智能降重和按篇价格。这些价格和导流信息不属于 VPCS 当前价格，回答时必须回到 `/pwp` 页面或实时配置接口。

## 证据边界

该文章是站点高校指南，不是郑州大学正式通知。只有拿到校方文件后，才能把报告的文字复制比与学校标准逐项对照。
