## Description:

Draw UML and architecture diagrams with PlantUML text syntax: sequence, class, activity, use case, state, component, deployment, timing, ER, C4 architecture, network diagrams, mind maps, Gantt charts, WBS, JSON/YAML visualization, and Salt UI wireframes. 支持主题、样式定制与预处理。Renders as PNG/SVG/ASCII.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to ask an agent for renderable PlantUML source for UML, architecture, data, planning, and UI wireframe diagrams. It helps convert diagram requests into .puml-style text and related rendering guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Remote PlantUML rendering can send diagram text, including architecture details or other sensitive content, to the public PlantUML server.

Mitigation: Use a local or self-hosted PlantUML renderer for confidential architecture, network topology, credentials, customer data, or proprietary diagrams.
