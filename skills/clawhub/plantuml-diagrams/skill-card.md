## Description:

Draw UML and architecture diagrams with PlantUML text syntax, including sequence, class, activity, use case, state, component, deployment, timing, ER, C4 architecture, network diagrams, mind maps, Gantt charts, WBS, JSON/YAML visualization, and Salt UI wireframes.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, architects, and technical writers use this skill to ask an agent for PlantUML diagram source and rendering guidance for software architecture, workflows, data models, schedules, UI wireframes, and structured data visualization.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Rendering diagrams through external includes or an online PlantUML server can expose confidential architecture, schema, or business data.

Mitigation: Use an approved local or trusted rendering path for sensitive diagrams, and avoid sending confidential content to external renderers unless that path is acceptable for the environment.
