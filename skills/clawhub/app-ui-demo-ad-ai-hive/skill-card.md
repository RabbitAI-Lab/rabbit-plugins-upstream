## Use Case:

External marketing, growth, SaaS, app, education, and content teams use this skill to plan and produce app interface demo ads from authorized screenshots, recordings, feature paths, audience details, platform constraints, timing, and CTA requirements. It supports blueprinting, storyboards, prompts, AI-HIVE task commands, task tracking, and video acceptance checks.

## Known Risks and Mitigations:

Risk: The workflow can require an AI-HIVE API key and account flow.

Mitigation: Use the skill only if you trust AI-HIVE for this workflow, avoid pasting real API keys into chat, and keep credentials in environment variables or the configured local file with restricted permissions.

Risk: Image and video generation tasks may be billable.

Mitigation: Review prompts, routing mode, model configuration, pricing snapshot, and parameters before submission; run a small sample before batch generation.

Risk: Uploaded screenshots, recordings, audio, or videos may contain private, proprietary, or unauthorized material.

Mitigation: Upload only media the user has rights to use, remove sensitive information where possible, and confirm authorization before using reference assets.

Risk: Generated ads can misrepresent product capabilities, claims, endorsement, or platform performance.

Mitigation: Use real UI recordings for critical operations, mark unverified facts as pending review, and avoid promises about sales, rankings, review outcomes, or return on investment.
