## Description: <br>
Helps an agent coach users through deliberate practice design for skill plateaus, feedback loops, expert mental representations, and AI-related skill atrophy. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[deciqai](https://clawhub.ai/user/deciqai) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Employees, external users, coaches, and learning designers use this skill to diagnose why effort is not producing improvement and to build practice routines with fast feedback, targeted repetitions, and clear stop rules. It is especially useful when an agent needs to help preserve or rebuild expertise as AI tools absorb routine work. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: External source and marketing links may be mistaken for required permissions or operational dependencies. <br>
Mitigation: Review those links as informational references only; the security evidence found no executable code or hidden access behavior. <br>
Risk: Reflective coaching questions can produce practice plans that depend on incomplete user self-assessment. <br>
Mitigation: Use expert feedback, annotated examples, or fast ground-truth checks where the skill asks for feedback source, latency, and reliability. <br>
