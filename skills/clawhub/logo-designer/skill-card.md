## Use Case:

External users and developers use this skill to call the Craftsman image_generator API through OneKey Agent Gateway and generate editable logo-design image carousels from prompts, reference images, templates, styles, and layout configuration.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts, uploaded reference images, and brand materials are sent to a hosted DeepNLP/Craftsman image-generation service.

Mitigation: Do not submit confidential brand assets, unreleased business material, sensitive images, or regulated data unless the user has reviewed and accepted the external service terms.

Risk: The skill includes an npx onekey CLI execution path that depends on external package behavior outside the inspected artifact.

Mitigation: Review the onekey CLI package and command arguments separately before running the CLI path in production environments.
