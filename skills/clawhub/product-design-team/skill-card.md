## Description:

Transforms product briefs into interface designs and a built, reviewed front end through coordinated design, build, review, and iteration roles.

This skill is ready for commercial/non-commercial use.

## Publisher:

[t3ratech](https://clawhub.ai/user/t3ratech)

### License/Terms of Use:

MIT-0

## Use Case:

Product, design, and frontend teams use this skill to turn a product brief into interface designs, implemented UI, review feedback, and iteration plans for web or cross-surface front ends.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can coordinate multiple roles, write project files, run shell commands, use web search, and store or retrieve memory.

Mitigation: Invoke it with a clear product brief, target platform, repository boundary, and command-execution expectations.

Risk: Generated interface designs or front-end code may be incomplete, incorrect, or fail the bundle's own evaluations.

Mitigation: Run the bundled evaluation set and review generated changes before use.
