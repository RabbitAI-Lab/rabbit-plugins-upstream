## Description:

Transforms product briefs into interface designs and a built, reviewed front end through coordinated design, build, review, and iteration roles.

This skill is ready for commercial/non-commercial use.

## Publisher:

[t3ratech](https://clawhub.ai/user/t3ratech)

### License/Terms of Use:

MIT-0

## Use Case:

Product teams, developers, and design engineers use this skill to turn a brief into UI direction, front-end implementation, review feedback, and iteration steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can coordinate agents that write files and run shell commands in a workspace.

Mitigation: Install it only in trusted workspaces and review generated code and commands before applying them to sensitive repositories.

Risk: Generated frontend changes may be incomplete, incorrect, or misaligned with project standards.

Mitigation: Run the bundled evaluation set and use the reviewer role to check correctness, maintainability, tests, and release readiness before use.
