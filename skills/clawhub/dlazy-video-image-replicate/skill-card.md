## Description:

Analyzes a reference image or video and helps recreate its visual style and structure with the user's own subject, product, or characters.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to study a supplied reference image or video and make a new version featuring their own subject, product, or characters.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security scan is incomplete, and it notes some reported CLI actions that appear unrelated to image and video recreation.

Mitigation: Before installing, review the CLI operations and decide whether the reported login and project-listing actions are acceptable.

Risk: Reference files attached to a task are uploaded to dLazy media storage.

Mitigation: Only attach reference files you are comfortable sharing with the hosted service.
