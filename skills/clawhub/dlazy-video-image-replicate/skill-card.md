## Description:

Recreates the look and structure of a reference image or video using the user's own subject, product, or characters.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators, marketers, and designers use this skill to make images or videos modeled on a reference while substituting their own content.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and attached reference media can be sent to dLazy's external service.

Mitigation: Attach only files you intend to upload and avoid sensitive content.

Risk: An API key may be stored locally, and project sessions may retain context.

Mitigation: Protect or rotate the API key as needed and clear sessions when their context is no longer needed.
