## Description:

Helps recreate the look and structure of a reference image or video using the user's own subject, product, or characters.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to study a supplied image or video and request a similar composition or visual style with their own content.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and attached reference media are sent to dLazy.

Mitigation: Attach only files you intend to upload and confirm you are comfortable sharing prompts and media with dLazy.

Risk: Using the service requires a dLazy API key.

Mitigation: Protect the API key and confirm you are comfortable storing or supplying it to the CLI.

Risk: Project sessions can retain conversation context.

Mitigation: Use explicit invocation wording and clear saved sessions when context should not be retained.
