## Description:

Helps recreate the look and structure of a reference image or video using the user's own subject, product, or characters.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and marketers use this skill to remake reference images or videos with their own subjects while preserving the reference's overall look and structure.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and attached reference media are sent to dLazy's hosted service.

Mitigation: Avoid attaching sensitive files and install only if sharing this material with dLazy is acceptable.

Risk: An API key is stored locally and project sessions retain conversational context.

Mitigation: Use a fresh project for unrelated work and rotate or revoke the API key if needed.
