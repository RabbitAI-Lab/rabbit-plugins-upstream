## Description:

Studies a reference image or video and helps recreate its look and structure using the user's own subject, product, or characters.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to recreate the visual style and structure of a supplied image or video with their own content.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and attached reference files may be sent to dLazy's third-party service.

Mitigation: Review the content before sharing it, and attach only files you are comfortable uploading.

Risk: The CLI may store an API key locally.

Mitigation: Protect local access and rotate or revoke the key through the dLazy dashboard if needed.

Risk: Project history can carry context between tasks.

Mitigation: Start a new project for unrelated work or clear the previous project's context.
