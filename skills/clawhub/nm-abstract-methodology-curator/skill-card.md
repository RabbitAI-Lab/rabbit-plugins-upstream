## Description:

Surfaces expert frameworks for methodology selection, skill design, evaluation, code review, debugging, testing, knowledge management, and decision making.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, agent builders, and reviewers use this skill as an initial methodology check before creating, evaluating, or refining skills, hooks, agents, and related technical guidance. It helps select established frameworks and identify methodology gaps before work proceeds.

### Deployment Geography for Use:

Global

Mitigation: Evaluate and install the external plugin separately; this release should be treated as non-executable reference material.
