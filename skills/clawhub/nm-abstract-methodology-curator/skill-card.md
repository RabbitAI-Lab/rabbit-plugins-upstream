## Description: <br>
Surfaces expert methodology frameworks for design, evaluation, skill authoring, code review, debugging, testing, knowledge management, and decision making. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[athola](https://clawhub.ai/user/athola) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, skill authors, and reviewers use this skill to choose established expert frameworks before creating, evaluating, or revising methodology-heavy agent skills, hooks, and guidance. It helps identify useful principles, missing methodology, and domain-specific anti-patterns without replacing human judgment. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad activation triggers can surface methodology guidance in conversations where it is not needed. <br>
Mitigation: Use the skill when design, evaluation, framework, skill, hook, or agent methodology guidance is desired; skip it for mechanical implementation, quick bug fixes, or already well-defined work. <br>
Risk: Methodology guidance can add unnecessary process or overfit expert frameworks to simple tasks. <br>
Mitigation: Treat outputs as advisory, select only principles that fit the current context, and preserve existing work when a targeted methodology note is enough. <br>
