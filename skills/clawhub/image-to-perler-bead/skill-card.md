## Description: <br>
This skill converts photos into Perler or Hama bead craft patterns with a printable HTML grid, PNG preview, color-coded material list, and optional JSON pattern data. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[zhouhuijia](https://clawhub.ai/user/zhouhuijia) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
External users and craft-focused makers use this skill to turn portraits, cartoons, logos, pet photos, and other images into printable bead patterns with material counts and practical sizing guidance. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill writes craft pattern files to a selected output directory and may require installing Pillow into a local Python virtual environment. <br>
Mitigation: Use a workspace output directory, review generated files before relying on them, and approve dependency installation before running commands. <br>
