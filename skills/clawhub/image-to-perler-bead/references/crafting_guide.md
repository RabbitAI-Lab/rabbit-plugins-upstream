# 拼豆手工制作指南

拿到图纸后，从准备材料到成品出炉的完整流程。

## 一、选图阶段的建议（影响最终效果）

**适合做拼豆的照片：**
- 高对比度、主体清晰（人像、卡通、Logo、宠物头像）
- 色彩鲜明的插画/二次元/扁平风图像
- 纯色背景下的物品
- 像素画本来就有马赛克感的图像

**不太适合：**
- 风景照（细节过多，远看糊成一片）
- 暗调照片（深色过多，黑白灰比例失衡）
- 高噪点照片（量化后噪点被放大）
- 渐变背景的人像（背景会和主体融在一起）

## 二、尺寸选择

图纸尺寸 = 钉板上的珠子数。常见标准：

| 钉板尺寸 | 适用场景 | 作品大小 (5mm 豆) |
|---------|---------|-----------------|
| 20×20 | 钥匙扣、小摆件、测试用 | 10×10 cm |
| 29×29 | 经典方形杯垫、小挂件 | 14.5×14.5 cm |
| 50×50 | 中等挂画 | 25×25 cm |
| 80×80+ | 大幅装饰画、抱枕 | 40×40 cm+ |

**经验法则：**
- 主体越复杂 → 选越大尺寸（细节得以保留）
- 颜色越多 → 选越大尺寸（小尺寸颜色会被合并）
- 想要「Q版可爱」效果 → 选小尺寸（会自然抽象化）

## 三、参数调优速查

| 想要的效果 | 调整参数 |
|-----------|---------|
| 颜色更细腻、保留更多原图颜色 | 增大 `--width` |
| 颜色更简洁、降低成本 | 减小 `--width` |
| 颜色过渡更自然 | 加 `--dither` |
| 想看清每格颜色编号 | 加 `--codes` |
| 想要纯色块（无网格线） | 加 `--no-grid` |
| 高度不想要自动计算 | 指定 `--height` |
| 填满方形不留白 | 用 `--mode cover`（会裁剪原图） |

## 四、材料采购

按生成材料清单采购。每种颜色建议多备 10-15%（拼豆易掉，且不够 1 颗都得重做一列）。

- **5mm 通用拼豆**：单价 0.1–0.3 元/袋（约 1000–2000 颗/袋）
- **5mm 拼豆钉板**：ABS 方形或圆形板，20/29/50 格常见
- **熨斗或热风枪**：家用熨斗即可
- **烘焙纸/锡纸/熨烫布**：垫在珠子和熨斗之间防粘
- **助烫剂（可选）**：喷一点能让融合更均匀
- **镊子**：摆细节时必备
- **收纳盒**：按色号预分装

## 五、制作流程

### 1. 摆豆
1. 把钉板平放，从图纸左下角第一格开始（注意：**大多数拼豆图都是左下原点**，看准列号行号方向）
2. 用镊子逐颗将对应颜色放在钉子上
3. 每摆完 5 格可以用粗网格线对一下图纸
4. 整张摆完后，从背面顶一下，确认所有豆豆都卡住

### 2. 熨烫
1. 在豆豆表面铺一张烘焙纸（防止熨斗直接接触粘连）
2. 熨斗调「中温」或「棉麻档」，**不要用蒸汽**（水汽会让豆变白雾）
3. 缓慢、均匀地在纸上方**画小圈**，每个位置停留约 10-15 秒
4. 看到豆豆开始往下塌、表面发亮、边缘开始融合时停止
5. 重要：**别熨过头**——熨过会变薄变脆，且可能熔穿

### 3. 冷却
1. 让作品在钉板上**自然冷却 3-5 分钟**（不要急着拿）
2. 冷却后从边缘轻撬，作品会自动脱落
3. 翻过来在另一面也轻轻熨 5-10 秒（让背面也融合，背面一般不用完全熔平）

### 4. 成品
- 装饰用：直接装框 / 挂起来
- 实用（如杯垫）：建议背面贴一层毛毡或软木垫防滑
- 做挂件：在边角打孔、穿绳（建议在角落夹一片圆形小铁片再打孔防裂）

## 六、常见问题

**Q: 颜色对不上怎么办？**
A: 以 RGB 值为准，参考 `palette.md` 找视觉最接近的实体色。

**Q: 材料清单某种色太多/太少？**
A: 太多 → 考虑改用更小尺寸（会牺牲细节但减少用量）；太少 → 正常，直接买一袋就够。

**Q: 熨出来发现某个位置错了？**
A: 趁热用镊子把错的那颗挑出来，重新放一颗。冷却后也可以用小刀挖出重做。

**Q: 拼豆作品的边缘有毛刺？**
A: 熨完用剪刀或指甲刀沿外圈剪掉外露的钉子残根即可。

**Q: 5mm 豆和 2.6mm 小豆可以混用吗？**
A: 钉板孔径不同，不通用。2.6mm 豆用 2.6mm 钉板，图纸按比例缩放即可（珠子数 = mm / 0.5）。

## 七、保存与展示

- 避光避潮：颜色会随紫外线缓慢褪色
- 不要重压：会留下压痕
- 想长期保存可真空封袋或装亚克力框
