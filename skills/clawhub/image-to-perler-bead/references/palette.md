## 调色板裁剪建议

如果想减少用色（手头没有这么多颜色），可以：
- 合并相邻灰度：P03+P04 可只用 P03；P05+P06+P07 可只用 P06
- 合并相邻饱和色：P19+P20 可只用 P20；P30+P31 可只用 P31
- 同色相明度相邻的 2-3 色合并后通常视觉损失可接受

如果需要扩展（颜色不够用）：
- 把相邻 RGB 拆分成 2 个新色（修改 `PERLER_PALETTE` 列表即可）
- 或换用更完整的 Artkal S/C/S 系列（约 90 色）

## 修改调色板

直接编辑 `scripts/perler_converter.py` 中的 `PERLER_PALETTE` 列表：

```python
PERLER_PALETTE = [
    ("P01", "白色", "White", (255, 255, 255)),
    # 在这里增删改颜色条目, 格式: (编号, 中文名, 英文名, (R, G, B))
    ...
]
```

注意编号必须唯一。改完保存，下一次运行即生效。
