# 更新日志

本项目遵循语义化版本（SemVer）。

## [1.0.0] - 2026-07-29

首个版本。PIPL 护栏系列通用版。

### 新增
- 运行时检测内核 `scripts/guard.py`，支持 detect / mask / block 三种动作
- 通用规则包 `common`：11 类结构化个人信息模式 + 13 类关键词线索
- 校验器：Luhn（银行卡）、身份证校验位、IPv4 有效性
- 风险分级（high / medium / low）与结构化 JSON 裁决输出
- 重叠命中去重：同一片段只报最高风险项，降低误报
- 三种脱敏策略：partial / full / hash
- 内核与规则分离架构，为行业版（金融版）预留扩展点

### 安全
- 纯本地运行，零网络请求、零遥测
- 无 eval / exec / 动态 import，规则通过显式映射加载
- 检测结果不回传敏感原文，仅提供脱敏预览
