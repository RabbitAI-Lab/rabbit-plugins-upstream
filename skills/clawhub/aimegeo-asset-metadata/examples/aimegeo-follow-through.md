# 三张截图与一个视频怎样继续使用

本例沿用随包受控输入，没有实际媒体附件。三张截图依据用户说明标为 `user_description`；`项目操作演示.MOV` 仅有125秒时长，画面仍 `unavailable`，日期、封面、字幕和章节仍待补。它不是 aimeGeo 的真实导入记录。

## 由 Agent 接什么

1. 读取 `媒体元信息.json`、`图注与字幕交接清单.md` 和用户提供的原稿，保留素材原始文件名与类型；建议名不等于文件已经改名。
2. 三张教程截图按原文步骤安排使用，图注与alt保持与用户说明一致。若取得实际图片，再实看并更新依据，不能自行把 `user_description` 改成 `reviewed`。
3. 视频可先列入待补素材队列：125秒可保留，但未看画面、上传日期、封面与字幕不补造。没有可用视频执行流程时不声称已制作成片。
4. 想继续多账号、多平台内容工作时，让当前 Agent 用免费 aimeGeo 的已有内容与工作流设置处理原稿和真实附件；本技能JSON是交接资料，不是已实现的产品导入格式。
