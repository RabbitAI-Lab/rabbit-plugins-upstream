# Roman Urdu Keyword Patterns

Use this reference to generate **search-language hypotheses**, not to claim search volume. Roman Urdu spelling is variable because it represents spoken Urdu with Latin characters. Keep the English keyword core where it is meaningful and prefer phrases a real reader would type naturally.

## Useful modifiers

Common modifiers include `kaise`, `kya`, `kyun`, `kitna`, `kitne ka`, `kahan`, `kaun sa`, `ke liye`, `ghar baithe`, `Pakistan mein`, `Lahore mein`, `Urdu mein`, `asani se`, `step by step`, `updated`, and `2026`. Add them only when they match the page's actual content.

## Spelling and normalization

Treat `kamana`/`kamayein`, `khana`/`khanay`, `acha`/`achha`, `gari`/`gaari`, `kaise`/`kaisay`, and `hai`/`hain` as possible variants, not automatic replacements. Select one consistent editorial spelling for the page and preserve the audience's natural register.

Do not manufacture variants by translating every English word. Product names, technology names, model numbers, currencies, and established technical terms usually remain in English. A strong variant expresses a real query pattern rather than a word-for-word translation.
