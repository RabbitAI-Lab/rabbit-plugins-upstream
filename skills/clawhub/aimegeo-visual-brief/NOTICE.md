# Rights and release notes

Candidate 1.0.2 retains the independently authored local image inventory validator and adds newly written instructions for creating a user-specific image brief, using an available host image tool, inspecting generated files, and handing approved files back to an aimeGeo article. It does not include the upstream-authored visual workflow, instructions, tutorials, example images, screenshots, or marks. The brief is newly written for the candidate; it does not reuse upstream process text or examples.

The untouched original MIT adaptation package remains outside this candidate and is not included or relicensed. See `SOURCE-ORIGIN.md` for the provenance record.
