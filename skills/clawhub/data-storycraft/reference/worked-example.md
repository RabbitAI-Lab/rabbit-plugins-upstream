# Worked example

The book runs all six steps on one dataset: the average retail price of five competitor products over several years, used to price a new product.

1. **Context.** The audience is the VP of Product, who sets the price. The Big Idea is that, based on how competitor pricing evolved, the product should launch within a specific price range.
2. **Visual.** The original was clustered bars with a different color per product. Removing the color variance showed the color was hiding the trend. Bars made an artificial staircase, so the chart switched to lines. Separate panels hindered comparison, so all lines moved onto one shared x-axis. Checking the data also corrected the original headline: prices had fallen only for the products that existed before a new entrant, not for all of them.
3. **Declutter.** De-emphasize the title, remove the border and gridlines, grey the axes, give all lines one color, and label them directly.
4. **Focus.** The same clean chart supports several insights, each highlighted in turn: existing prices fell after a competitor launched; new products launch high and then decline; prices converged in the final year.
5. **Design.** Use a sentence-case title in simple words and add axis titles aligned to the top-left.
6. **Story.** A five-minute live sequence on one evolving chart: announce the structure, set up the axes, build the price history chronologically, introduce tension as new entrants undercut prices, resolve with convergence, and end with the recommended price range.

With several visuals in one deck, each visual's story is a subplot of the overall storyline.
