# VIN 查车辆信息（精准版）输出格式

支付成功并拿到接口 JSON 后渲染。**仅使用接口返回字段，禁止编造内容。**

## 输出顺序（固定）

```markdown
{车辆概要模板}   ← 有完整 result（含 vin / 品牌等字段）时必渲染，排第一

{车型分类模板}

{价格信息模板}

{动力与传动模板}

{车身与尺寸模板}

{其他配置模板}

---
*以上数据来源于第三方数据服务，仅供参考，请以实际车辆登记及厂商官方信息为准。*
```

查无记录（`error_code` 为 `286204`，或 `reason` 为「查无记录」，`result` 仅含 `orderid`）时，输出 [查无记录模板](#查无记录模板) + 页脚免责。

---

## 车辆概要模板

接口返回完整 `result` 对象时使用，**固定排在全文最前**。

数据路径：`result.*`（外层 `reason`、`error_code` 不展示给用户）。

### 渲染结构

```markdown
# 🚗 VIN 车辆信息查询结果

> 🔑 VIN：{result.vin}

| 项目 | 内容 |
| ---- | ---- |
| 查询单号 | {result.orderid} |
| 一级品牌 | {amMainBrandName} |
| 二级品牌 | {amBrandName} |
| 车系名称 | {amSeriesName} |
| 销售车型 | {amVehicleName} |
| 年款 | {amYear} |
| VIN 出厂年份 | {amVinYear} |
| 车组名称 | {amGroupName} |
| 国别 | {countriesName} |
| 国产/进口 | {importFlag} |
| 配置等级 | {cfgLevel} |
| 上市年份 | {marketDate} |
| 停产日期 | {stopDate} |
| 公告号 | {publicationNos} |
| 底盘号 | {chassisModel} |
```

### 字段映射

| 展示项 | JSON 字段 | 说明 |
| ------ | --------- | ---- |
| VIN 码 | `result.vin` | 17 位车架号 |
| 查询单号 | `result.orderid` | 聚合数据订单号 |
| 一级品牌 | `amMainBrandName` | 如「宝马」 |
| 二级品牌 | `amBrandName` | 如「华晨宝马」 |
| 车系名称 | `amSeriesName` | 如「5系」 |
| 销售车型 | `amVehicleName` | 完整销售车型名称 |
| 年款 | `amYear` | 如「2021」 |
| VIN 出厂年份 | `amVinYear` | VIN 码出厂年份 |
| 车组名称 | `amGroupName` | 车组描述 |
| 国别 | `countriesName` | 如「德国」 |
| 国产/进口 | `importFlag` | 如「合资」「进口」 |
| 配置等级 | `cfgLevel` | 如「M运动套装」 |
| 上市年份 | `marketDate` | 如「2020-09-26」 |
| 停产日期 | `stopDate` | 如「2021-05-21」 |
| 公告号 | `publicationNos` | 如「BMW7201LN」 |
| 底盘号 | `chassisModel` | 如「G38」 |

## 渲染规则

1. **概要首位**：有完整车辆 `result` 时，必须先渲染 [车辆概要模板](#车辆概要模板)，再按顺序渲染分类、价格、动力、尺寸、其他配置。
2. **空值处理**：字段缺失、空字符串、`null` 时显示「—」，不填「暂无」；整节全部为空时可跳过该节。
3. **单位展示**：价格追加「元」，排量追加「L」，尺寸/轴距/轮距追加「mm」，整备质量追加「kg」，档数/气门数追加「个」。
4. **外形尺寸**：可将 `*` 规范展示为 `×`（如 `5106*1868*1500` → `5106×1868×1500`）。
5. **文本清洗**：去除 HTML/script 标签；保留中文标点与换行。
6. **禁止臆造**：不生成接口未返回的违章、估值等内容。
7. **查无记录**：按 [查无记录模板](#查无记录模板) 输出，仍展示 `orderid`（若有）。
8. **页脚免责**（固定追加）：

```markdown
---
*以上数据来源于第三方数据服务，仅供参考，请以实际车辆登记及厂商官方信息为准。*
```
