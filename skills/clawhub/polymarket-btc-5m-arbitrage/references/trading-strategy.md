# BTC 5分钟候选价差说明

## 定位

这是一个只读候选筛选器，不是交易策略执行器。它不下单，也不代表任何结果一定可实现。

## 互补 token 的筛选

对于同一市场的 Up 和 Down token，脚本读取两个 token 各自的最佳卖价：

    candidate_edge = 1 - (up_ask + down_ask + fee_buffer)

只有 candidate_edge > 0 时才报告候选。这里使用两个 ask，而不是同一 token 的 bid 与 ask；同一 token 的 bid/ask 不能证明 Up/Down 互补套利。

## 需要人工复核的因素

- 手续费、价差和价格精度
- 可成交深度、订单大小和部分成交
- 网络延迟、市场临近结算和订单簿变化
- 市场规则、Chainlink 分辨率和最终结算
- 账户、地区和平台服务条款

因此报告中的 edge 是观察时刻的理论毛利候选，不是收益承诺。

## 运行参数

- 默认最小流动性：1000
- 默认最多扫描市场：5
- 默认手续费缓冲：0.01
- 默认请求超时：10 秒
- 持续轮询必须由调用者显式提供 interval

## 安全边界

不要向此 skill 添加私钥、API key 或第三方计费凭据。若需要真实交易执行，应建立独立代码包和独立安全评审，默认 dry-run，并在每一笔订单前获得明确确认。
