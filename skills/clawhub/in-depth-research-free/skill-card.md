## Description: <br>
Provides a Chinese-language structured research workflow for scoping questions, searching across multiple sources, evaluating source credibility, iterating on gaps, and delivering synthesized findings. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External users, developers, and analysts use this skill to run structured research tasks such as technology comparisons, competitive analysis, market trend research, and fact checking with source evaluation and confidence notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill declares broad agent tools and includes API key configuration guidance. <br>
Mitigation: Use normal credential hygiene, avoid committing API keys, and review proposed file or command actions before execution. <br>
Risk: Research outputs may be incomplete, outdated, or biased when sources are inaccessible, paywalled, or conflicting. <br>
Mitigation: Require source tracking, confidence labels, gap notes, and independent corroboration for important decisions. <br>
