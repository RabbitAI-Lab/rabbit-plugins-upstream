## Description: <br>
Searches Tenor and Giphy for WhatsApp GIF reactions, converts selected GIFs to WhatsApp-compatible MP4 files, and helps send them to a specified WhatsApp contact. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[thcjp](https://clawhub.ai/user/thcjp) <br>

MIT-0 <br>


## Use Case: <br>
External personal users use this skill to search for expressive GIFs, convert selected media, and send a single WhatsApp reaction or greeting to one contact. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The security summary flags unrelated SEO trigger text that may cause users or agents to invoke the skill outside its WhatsApp GIF workflow. <br>
Mitigation: Use only for explicit WhatsApp GIF search and send requests, and have the publisher correct the trigger text before broad distribution. <br>
Risk: The skill can download remote media, create local MP4 files, and send a WhatsApp message. <br>
Mitigation: Review the selected media, destination contact, generated file path, and message content before sending. <br>
