## Description:

Turns a fresh idea into a Phantra project with a first scene, gathers reference images, quotes the render, and starts it only after approval.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zeropage-onryo](https://clawhub.ai/user/zeropage-onryo)

### License/Terms of Use:

MIT-0

## Use Case:

External creators use this skill to turn a new video idea into a Phantra project with a drafted first scene, reference images, and a render quote. It waits for approval before starting a render that spends credits.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Reference photos are shared with the studio and rendering provider.

Mitigation: Use only photos you are comfortable sharing, and confirm the selected photos and provider before approval.

Risk: Approving a render spends credits.

Mitigation: Review the quoted credit cost and approve only the render you want to start.
