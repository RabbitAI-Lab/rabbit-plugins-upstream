## Description: <br>
Helps API developers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
API developers, backend teams, developer-experience teams, and maintainers use this skill to create practical OpenAPI or Swagger documentation workflows, checklists, implementation support, and validation notes for REST APIs. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger wording may activate the skill during general backend or API discussions where OpenAPI documentation help was not intended. <br>
Mitigation: Tighten trigger phrases or disable implicit invocation when accidental activation would be disruptive. <br>
