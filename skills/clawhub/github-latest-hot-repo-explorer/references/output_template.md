# 三个问题的回答模板

拿到 `fetch_repo.py` 输出的元数据 + README 后，按下面的格式生成回答。

## 输出格式（Markdown）

### 最近 X 月热门仓库：owner/repo

> **筛选条件：最近 X 月创建，stars > N**

- **名称**：owner/repo
- **Stars**：N
- **主语言**：X
- **创建时间**：YYYY-MM-DD
- **链接**：url
- **简介**：description

### 这个仓库的项目是什么？

用 1–3 句话讲清楚项目定位、产品/工具类别和目标用户；优先直接回答，避免堆砌 README 原文。

### 解决了什么问题？

说明具体痛点场景：用户原来怎么做，以及为什么麻烦、慢、贵或复杂。不要泛泛说“提升效率”。

### 如何解决？

列出最多 5 条核心实现思路：技术方案、关键设计或差异化。可从 README 的 Features/Architecture 段抽取；README 未披露时明确写“README 未披露”。

## 回答质量红线

- 禁止编造 README 未披露的细节。
- 禁止空泛评价。
- 引用具体技术名词、文件结构和命令行示例。
- README 信息不足时，明确标注“信息有限，基于元数据推断”。
