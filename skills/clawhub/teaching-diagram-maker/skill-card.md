## Description:

Create, edit, and visually verify durable teaching diagrams for study notes and technical explanations.

This skill is ready for commercial/non-commercial use.

## Publisher:

[illustrated-paper-guide](https://clawhub.ai/user/illustrated-paper-guide)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, educators, and technical writers use this skill to create editable teaching diagrams beside notes and explanations, then validate rendered outputs for readability and correctness.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may edit nearby note text, add image files, embed links, and render previews.

Mitigation: Use it only on workspaces where note and image changes are acceptable, then review the modified note, generated asset, embedded link, and rendered preview before relying on the result.
