# 制造商与供应链审计

本文件是「避雷」技能第 11 条扫雷的配套清单。核心问题只有一个：**这件东西到底是谁做的，出了事谁兜底。**

## 一、四种生产模式

| 模式 | 判定信号 | 对推荐的影响 |
|---|---|---|
| **自产** | 铭牌「制造商」= 品牌方主体；3C 证书申请人 = 制造商；披露自有工厂/产线/实验室 | 不降级 |
| **自研 + 代工** | 品牌掌握研发、标准、品控；3C「申请人」是品牌、「制造商」是代工厂 | 不降级，但需说明代工厂是谁 |
| **纯代工 / 公模** | 无研发无专利，直接采买代工厂现成方案；同款外观在多个品牌下出现 | 降一级，写明「公模机」 |
| **贴牌授权** | 品牌只出商标与渠道，生产/品控/售后均不掌握；客服答不出生产厂家 | 降一级，写明「品牌不掌握生产与品控」 |

**查不到生产主体 → 写「制造商查不到」，不得默认自产。**

## 二、查询渠道

| 要查什么 | 去哪查 | 怎么用 |
|---|---|---|
| 3C 强制认证 | `cx.cnca.cn` | 按型号或企业名查；重点看**申请人**与**制造商**是不是同一家，不同即代工 |
| 行政处罚 / 经营异常 | 国家企业信用信息公示系统 `gsxt.gov.cn` | 按**厂名**查，不按品牌名查 |
| 缺陷产品召回 | `samrdprc.org.cn`、`dpac.samr.gov.cn` | 型号级命中即出局 |
| 抽检不合格通报 | 市场监管总局及各省局官网、`samr.gov.cn` | 记年份 + 批次 + 不合格项 |
| 商标与持有人 | 中国商标网 `sbj.cnipa.gov.cn` | 判断品牌是不是纯商标运营（无生产资质） |
| 专利与研发 | 国家知识产权局 `pss-system.cponline.cnipa.gov.cn` | 零专利 + 讲参数不讲产线 → 贴牌倾向 |
| 执行标准 | 企业标准信息公共服务平台 `qybz.sac.gov.cn` | 看标准备案主体是品牌还是代工厂 |
| 售后归属 | 说明书保修条款、官网服务网络、400 归属 | 直营 / 外包服务商 / 平台兜底 |

## 三、贴牌信号清单（命中 ≥2 条即高度可疑）

1. 产品页只堆参数与场景图，**不出现工厂、产线、实验室、品控流程**；
2. 同一外观/同一模具在多个品牌下售卖（公模机，换 logo 换包装）；
3. 品牌无任何专利与研发披露，只有商标；
4. 客服或详情页答不出「生产厂家是谁」；
5. 型号命名混乱、跨品类乱扩张（今天卖充电器明天卖锅）；
6. 售后只能走平台、没有品牌自有服务网点；
7. 价格显著低于同类同规格，且无成本解释。

## 四、代工厂水平判定

按**厂名**（不是品牌名）查，四项打分：

- **代工对象**：是否同时给头部品牌代工（能进大厂供应链，通常有基本品控体系）；
- **自有能力**：有无自有实验室、检测设备、研发团队；
- **合规记录**：按厂名查行政处罚、抽检不合格、召回记录，逐条记年份；
- **业务结构**：专做低价白牌走量 / 高低端通吃 / 只做高端定制。

结论写法：`代工厂为 XX（判定：头部代工 / 中端 / 低价白牌）；按厂名检索到 N 条行政处罚（年份，来源）；未检索到公开争议不等于合规良好。`

## 五、售后归属

| 形态 | 识别方式 | 风险 |
|---|---|---|
| 品牌直营 | 官网有服务网点、保修条款主体是品牌 | 低 |
| 外包第三方 | 保修由「XX 服务有限公司」承接 | 中，看外包商口碑 |
| 平台兜底 | 只有「七天无理由」「平台保修」 | 高，出保后基本无解 |

## 六、写进报告的模板

> **制造商**：XX 公司（自产 / 代工 XX 厂 / 贴牌授权）
> **质量把控**：品牌自有品控 / 代工厂自控 / 不掌握
> **售后**：品牌直营 / 外包 XX / 平台兜底
> **代工厂水平**：头部代工 / 中端 / 低价白牌；按厂名检索 N 条处罚记录
> **对结论的影响**：不降级 / 降一级（原因）

## 七、红线

- 不因「品牌知名度高」就默认自产，大牌也有贴牌线；
- 不因「代工」就直接判差，苹果也代工——关键看**谁定标准、谁做品控、谁兜售后**；
- 工厂信息查不到时，写「查不到」，不用猜测的产业带（如「应该是深圳某厂」）填坑。
