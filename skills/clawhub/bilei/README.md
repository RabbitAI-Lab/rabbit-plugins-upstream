**避雷是一个反投毒购物顾问 Skill：**

给它一个品类和预算，
它去查那些公关不了的东西——行政处罚、抽检通报、召回公告，

## 创作背景

本人从事新媒体工作17年（微博第一批段子手），合作创办MCN 10余年，大大小小的软广硬广植入都帮客户做过，本人已经算是人工软广识别机器了。

但是在今年装修自己新家的时候才发现，自己想买一些家电的时候，搜遍了抖音、小红书、B站、知乎、什么值得买，都已经找不到任何客观的评价了。那种横评、测评博主也是懂的都懂，广场也被大量的素人做GEO投毒铺满了，少数的负面也被公关掉了，再加上算法的推流跟屏蔽，你几乎找不到产品的负面，纯夸。

这样的信息茧房也太可怕了，连做了十几年广告的“行内人”都买不到客观公正的产品。于是我在想什么是不能被篡改的，比如行政处罚，这个总公关不了吧，比如产品差评，这个虽然靠人工会被算法屏蔽，但是AI搜集起来还是会方便很多。

这个技能就是按这个思路做的：以行政处罚、抽检通报、召回公告这些公关不了的数据为地基，让 AI 去把散落在投诉平台和社区角落的差评捞回来，按证据强度定级，再谈推荐。

**广告的钱怎么花我最清楚，所以这个技能只认公关不了的东西。**

## 安装

只需两步：

1. 打开你正在用的 Agent（Claude Code / Cursor / Codex / WorkBuddy 等）
2. 对它说：**「帮我安装这个 skill：https://github.com/zhashushu/bilei-skill」**

或者用通用 CLI 安装器（自动识别你的 runtime）：

```bash
npx skills add zhashushu/bilei-skill
```

也可以手动：把整个文件夹放进你所用 Agent 的技能目录（如 `~/.claude/skills/`、`~/.workbuddy/skills/`）。**文件夹名可以随便改**——装进 WorkBuddy 建议命名为「避雷」，WorkBuddy 界面显示的技能名以 SKILL.md 里的 `display_name` 为准，和文件夹名无关。

> <sub>Or manually: copy the whole folder into your agent's skills directory. The folder name doesn't matter — rename it freely (e.g. keep it as-is for Claude Code, or name it 避雷 for WorkBuddy).</sub>

## 它会查什么

1. **强制认证与标准**：这个品类有没有国家强制认证？在哪查、怎么到手验证（3C 查 `cx.cnca.cn`，召回查 `samrdprc.org.cn`）
2. **黑榜**：哪些品牌型号被行政处罚、抽检不合格、召回——型号、处罚单位、日期、来源，逐条列
3. **证据分级**：官方处罚/抽检 > 第三方检测 > 权威媒体实测 > 用户投诉 > 商家宣传/软文，每条标等级
4. **信源建档**：每个被引用的评测博主查清靠什么活（付费测试 / 送测 / 返利 / 网友借机 / 自购），利益冲突只削评价层，不削事实层
5. **通稿识别**：10 个链接可能是 1 篇通稿；大量雷同帖子、相似好评一律按 GEO 投毒处理
6. **定量对价**：溢价必须跑脚本（`scripts/premium_decision.py`）——TCO/EAC、临界故障率 p\*、溢价 ROI、公允价格上限，不许口算
7. **结论先行**：唯一推荐 + 性价比款 + 质价比款 + 检索词/直达链接/SKU 路径 + 到手验证步骤

## 三条纪律

1. **推荐强度 ≤ 证据强度**——推荐的强度不能超过证据的强度，证据的强度不能超过信源的强度
2. **不编数据**——查不到就写查不到，没有可靠选项就说「目前没有」
3. **先取证再动笔**——价格、认证、抽检、召回一律现查现证，禁止凭记忆写

## 定量内核

`scripts/premium_decision.py`（零依赖，仅标准库，Python 3.8+）把「性价比款 vs 质价比款」从口味之争变成数字对价：

```bash
python3 scripts/premium_decision.py selftest   # 自检
python3 scripts/premium_decision.py all --input case.json --format both
```

## 关于准确度的实话

避雷的结果准不准，必须先跟你说清楚：

**结果的准确度，模型本身的能力只占 30%，另外 70% 取决于各家公司做的搜索优化。** 如果搜到的源头大量被投毒，那结果肯定也不太理想——信息源被污染了，谁的模型都救不回来，这不是换一个更强的模型能解决的问题。

实测下来，**DeepSeek 客户端、Gemini 客户端自带的搜索，得到的结果质量会更高一点。**

这也是为什么这个技能死磕「公关不了的数据」——行政处罚、抽检通报、召回公告，以及把散落在角落里的差评捞回来：正面的声音可以被买量，负面的痕迹很难被抹干净。
