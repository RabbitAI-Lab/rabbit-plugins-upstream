## Description:

Synchronizes the latest content from the Lexiang MedXpert knowledge base to a local workspace and regenerates website HTML.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zhaoxinghua09-cell](https://clawhub.ai/user/zhaoxinghua09-cell)

### License/Terms of Use:

All rights reserved

## Use Case:

Website maintainers use this skill to refresh a local MedXpert website from its Lexiang knowledge-base content and regenerate the site's HTML.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Remote content fetching and local website writing are not sufficiently scoped by the skill.

Mitigation: Use only for an intended MedXpert workspace; confirm the content source, destination paths, changed files, and overwrite behavior before use.

Risk: Regenerated website content could be published without review.

Mitigation: Review generated HTML and content before publishing.
