## Description:

Helps synchronize content from the Lexiang MedXpert knowledge base to local website files and regenerate HTML.

This skill is ready for commercial/non-commercial use.

## Use Case:

Website maintainers can use this skill to bring content from the Lexiang MedXpert knowledge base into a local website and regenerate its HTML, subject to review before changes are applied.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Website synchronization may overwrite or introduce unintended changes to local HTML.

Mitigation: Specify the exact destination, back up existing files, inspect proposed changes, and require confirmation before writing.

Risk: Reading local website files and fetching web content grants broad access without stated limits.

Mitigation: Limit the source location and permitted local files before use, and review fetched content before incorporating it.
