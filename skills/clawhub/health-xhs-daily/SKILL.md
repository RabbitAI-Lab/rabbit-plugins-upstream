# 小红书养生笔记日更

一句话跑完：**选题 → 800 字清单体成文 → 引流红线自检 → 存盘 → 入全文库。**

> 首次使用：告诉 AI 你的笔记存放目录，AI 记住后续直接用。

---

## 核心：小红书这一篇该长什么样

| 维度 | 要求 |
|---|---|
| 篇幅 | **800 字左右**（600–1000） |
| 开头 | **3 段，每段 1-2 句**，快速进场景 |
| 结构 | **emoji 锚点 + 短行**，不用长段落 |
| 案例 | **一句带过**，不展开讲故事 |
| 结尾 | **评论打卡 + 收藏引导 + 话题标签** |

> 小红书平台女性用户占七成，"姐妹们"是原生语气，**保持女性视角**最自然。

## 🚨 引流红线（本 skill 最重要的章节）

小红书把「引导加微信」定为**一级高危**：平台《交易导流违规管理细则》+ 社区规范规定，
笔记 / 直播 / 评论区 / 私信 / 主页 / 图片水印 / 私信自动回复，**禁止任何直接或间接方式引导加微信**。
处罚阶梯：笔记下架 + 限流 → 限制私信 → **多次永久封号**（企业主体拉黑），严重的扣违约金。

**以下内容一律不许出现在小红书笔记里：**
- ❌ 明文微信号、QQ、手机号、二维码（机器扫描必中）
- ❌ 谐音/字母/拆字变体：`VX`、`V我`、`绿泡泡`、`薇❤`、图片里藏码（平台 AI 已能识别，不再安全）
- ❌ 诱导话术：加我、私我、扣1领资料、看主页、举手领取、私信我领
- ❌ 引导到公众号/其他平台账号

**合规替代（站内，安全）：**
- ✅ 引导进**小红书官方群聊**：`点头像进主页群聊，咱们一起打卡✨`
- ✅ 引导**关注 + 收藏**（平台鼓励）：`关注我，每天一个养生小知识✨`
- ✅ 变现走**小红书店铺** / 升级企业专业号后用官方「私信获客」组件

**定位建议**：小红书这一端负责**曝光 + 种草 + 站内群聊沉淀**，笔记里不留任何联系方式；需要沉淀到站外的动作，一律放到你自己的其他阵地去做，两边别混用。

**自检动作（每篇必做，双重保险）：**
1. 逐项扫上方红线清单（联系方式/变体/诱导话术/跨平台引导）
2. 人工通读，**重点盯文末引流行**——这是本平台最容易踩雷的位置，逐字确认无任何联系方式
3. 同步检查：疗效承诺（根治/一定有效）、极限词（最/第一）、编造医院药名——一样都不许有

## 流程

1. **选题**：选当天时令 + 高频痛点（季节、节气、人群痛点都行）
2. **成文**：套上面骨架；若已有长文版本，压缩改写——保留要点，砍掉故事铺垫
3. **合规自检**：引流红线 + 疗效承诺 + 极限词 + 编造，逐项过（付费版可跑自动自检脚本）
4. **存盘**：`{笔记目录}/YYYY-MM/YYYY-MM-DD-主题.md`
5. **入全文库**：
   ```bash
   python "$SKILL_PATH/scripts/add_to_library.py" <笔记.md路径>
   ```

## 硬性规则

| 规则 | 说明 |
|---|---|
| 篇幅 | **800 字左右**（600–1000） |
| 每行 | 短，手机一屏 2-3 行一段 |
| 语气 | 姐妹们、感叹号、口语，不用书面语 |

| 引流 | 🚨 **末行禁止微信号/任何联系方式**，只引导官方群聊或关注收藏 |

| 不写 | 医院名、具体药名、绝对化疗效承诺（"根治""一定有效"） |
