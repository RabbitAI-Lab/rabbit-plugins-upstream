## 组合计算

当技术栈涉及多个组件时，取加权平均：

```
综合系数 = (前端系数 × 前端占比 + 后端系数 × 后端占比 + 数据库系数 × 数据库占比)

示例：
Vue 3 (1.0) + Java Spring Boot (1.2) + MySQL (1.0)
假设前端占40%，后端占40%，数据库占20%
综合系数 = 1.0×0.4 + 1.2×0.4 + 1.0×0.2 = 1.08
```

## 快速估算规则

对于常见组合，可直接使用以下速查：

| 典型项目 | 综合系数 | 适用场景 |
|----------|----------|----------|
| Vue + Node + MySQL | 1.0 | 中小型Web应用 |
| React + Java + MySQL | 1.1 | 企业级应用 |
| Vue + Python + PostgreSQL | 0.95 | 数据类应用 |
| 微前端 + 微服务 | 1.4 | 大型复杂系统 |
