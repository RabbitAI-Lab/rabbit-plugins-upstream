## Description: <br>
Specifies tracing, metrics, alerting, sampling, retention, and privacy guidance for operating AI agents or LLM features in production. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineers use this skill to specify production observability for LLM apps and agents, including trace spans, metric ownership, alert thresholds, sampling, retention, and privacy handling. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Observability plans may recommend logging prompts, outputs, tool results, or user data before the team has settled data handling requirements. <br>
Mitigation: Define allowed logged content, access controls, retention periods, deletion handling, and compliance ownership before applying the specification. <br>
