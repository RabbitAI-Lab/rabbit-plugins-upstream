## Description:

Scrape Google Maps places by search term and location, deliver CSV or JSON with optional website contacts and AI verdicts, and compare available scraping and API options to recommend one based on budget, volume, and review needs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[maxouf](https://clawhub.ai/user/maxouf)

## Use Case:

External users can use this skill to find local businesses by type and area, choose a suitable Maps data source, and receive place records as CSV or JSON. They can optionally request published website contact details and AI based business-fit verdicts.

### Deployment Geography for Use:

Global
