# 小程序发布与上线

## 一、测试号 / 游客模式 vs 正式 AppID

| 方式 | AppID 值 | 注册成本 | 能力 | 体验成员 |
|---|---|---|---|---|
| 游客模式 | `touristappid` | 无需注册，DevTools 直接选 | 基础功能，无支付/无后台成员管理 | 无（仅本人预览） |
| 测试号 | 微信公众平台「测试号」分配 | 扫码即可 | 受限，常用于接口调试 | 无体验成员入口 |
| 正式小程序 | mp.weixin.qq.com 注册获得 | 邮箱+主体认证 | 完整能力 | 可加体验成员、可提审发布 |

**结论**：要做给别人用、要体验权限、要发布，必须走**正式小程序**拿到 AppID。

## 二、获取与设置 AppID

1. 打开 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 注册小程序（个人/企业主体）。
2. 后台「开发 → 开发管理 → 开发设置」里看到 **AppID(小程序ID)**。
3. 填到项目中：
   - 方式 A：`project.config.json` 的 `"appid": "wx........"` 字段。
   - 方式 B：DevTools 顶部「详情 → 本地设置 / 项目配置」里修改，或新建项目时粘贴。
4. 重新编译，DevTools 显示「已连接」即生效。

> 个人主体限制：不能开通微信支付、不能做部分类目（如医疗、金融），但普通工具/展示类小程序完全够用。

## 三、让别人能体验（体验成员）

1. mp 后台 → **成员管理 → 体验成员** → 点击「添加」。
2. 输入对方**微信号**（不是昵称），可批量添加。
3. 对方在微信里收到「体验邀请」，确认后成为体验成员。
4. 之后你「预览」生成的二维码，对方扫码即可真机体验（无需发布）。
5. 如需多人协作开发：同页面「项目成员 / 添加成员」按角色（开发/体验/运营）分配。

## 四、上传 → 提审 → 发布流程

1. **上传代码**：DevTools 点击「上传」→ 填版本号（如 1.0.0）+ 备注 → 代码传到微信后台「开发版本」。
2. **提交审核**：登录 mp 后台 → **管理 → 版本管理 → 开发版本** → 点「提交审核」。
   - 填：功能页面路径、服务类目、用户隐私保护指引、测试账号（如有登录）。
   - 类目需对应资质（如电商需营业执照相关类目）。
3. **等待审核**：一般 1–7 个工作日；被拒会说明原因，按意见改后重新提审。
4. **发布**：审核通过后 → 「全量发布」或「分阶段发布（灰度）」。
5. **线上版本**：发布后在「线上版本」可回退/升级。

## 五、上线前必查清单

- [ ] 隐私协议：`app.json` 配置 `requiredPrivateInfos` 并按需声明；后台填《用户隐私保护指引》。
- [ ] 域名白名单：request / upload / download 的域名已在后台配置且为 HTTPS。
- [ ] 体验成员已加，关键路径本人真机走通。
- [ ] 无 `console.error`、无明显卡顿；`setData` 数据量合规。
- [ ] 类目与资质齐全（否则审核驳回）。
- [ ] 图标、名称、简介已设置（后台「基本信息」）。

## 六、常见问题

- **「提交审核」按钮灰色**：多半是类目未选/资质未传，或隐私指引未填。
- **审核被拒「功能不完整」**：在提审时填测试账号 + 录屏/截图说明操作步骤。
- **换电脑/换人接手**：把 `project.config.json` 里的 appid 改成新账号的即可，代码本身通用。
