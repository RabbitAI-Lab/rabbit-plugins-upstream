## Description:

Plans a piece as a sequence of Phantra scenes before any is written: a beat list agreed in the chat, then one `write_scene` per scene, all in one project and held to the same photos with the same roles so the scenes cut together. Use when someone wants a whole ad, short or sequence planned, asks for a storyboard or a beat sheet, or has several places or moments in one idea. NOT for one scene's prompt (write-scene), a spoken script (youtube-script) or choosing between ideas (ideas-and-projects).

This skill is ready for commercial/non-commercial use.

## Use Case:

Creators and teams use the skill to plan a multi-scene Phantra video, agree on its beat list, and draft consistent scene prompts in a shared project before separately approving renders.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Rendering a scene spends credits.

Mitigation: Review the scene, quoted credit cost, and project details, then explicitly approve that scene before rendering.

Risk: The security assessment does not verify the external Phantra tools or their data handling.

Mitigation: Review the external service's data handling before sharing sensitive photos or project content.
