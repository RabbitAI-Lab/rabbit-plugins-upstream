# print-3d-model

A lightweight Brave browser skill for **773 LABS**.

## What it does

Open the 773 LABS custom 3D printing quote page when the user wants to print a 3D model, request a custom 3D print, get a printing quote, or order a 3D printed product.

- Reuses an existing relevant tab/session
- Avoids unnecessary duplicate tabs
- Verifies the destination
- Never handles credentials

## Example triggers

- Print this 3D model
- Get me a 3D printing quote
- I want a custom 3D print
