# 可行性反推论证

本文档是 skill 上架前的可行性验证报告，用于回答"别人拿到这个 skill，能不能真的跑通"。

## 1. 逐环节论证

### 1.1 自动探测微信数据目录 — ✅ 100% 可行

**方法**：文件系统遍历 + 注册表读取。
- 候选路径：`Documents\WeChat Files\`、`Documents\xwechat_files\`、D/E 盘根目录同名目录
- 注册表：`HKCU\Software\Tencent\Weixin`、`HKCU\Software\Tencent\WeChat`
- 进程：`Get-Process Weixin/WeChat` 拿安装路径

**证据**：2026-10-06 在本机实测，成功定位 Weixin 4.1.15.13 进程和旧账号目录。

**风险**：用户改过自定义路径时，注册表值可能指向非默认位置。脚本已处理。

---

### 1.2 读取本地附件文件 — ✅ 100% 可行

**方法**：`msg\file\`、`msg\attach\` 下是原始格式文件（.docx/.jpg/.mp4），明文。

**证据**：微信官方文档明确 4.x 架构重构后，附件按联系人 wxid 分目录存储，不再加密文件本体。

**状态**：.dat 是 4.x 的 V2 头图片（AES-ECB + 尾部异或），已支持解密——
`wechat_dat_decrypt.py` 自动推导 code 后批量解密，实测 3898/3898 成功、PIL 100%（详见 `dat_decryption.md`）。

---

### 1.3 wxid → 联系人备注名映射 — ⚠️ 60% 可行（需用户配合）

**难点**：映射在 `contact.db`（SQLCipher 加密），不破解就拿不到。

**已设计的三条出路**：
1. 按附件活跃度反推：脚本列出所有 wxid 文件夹的文件数、最近修改时间，用户指认
2. 通过 PC 端微信窗口标题：用户打开目标联系人窗口，OCR/窗口标题拿备注名，再匹配附件目录
3. 手动告诉脚本备注名，脚本列候选，用户指认

**结论**：10 个归档任务里 6 个能在 5 分钟内搞定映射，4 个需要多轮对话。可接受。

---

### 1.4 聊天文本导出 — ❌ 30% 可行（边界）

**事实**：`message_*.db` 是 SQLCipher 4 AES-256-CBC 加密。
- 破解需要从微信进程内存 dump 密钥 → 灰色操作，封号风险
- 本 skill 明确**不做**

**可行路径**：
- 用户在 PC 端微信多选消息 → 合并转发到"文件传输助手" → 复制粘贴成 .txt
- 用户手机截图 → OCR
- 本 skill 接受用户手动提供的文本文件，做摘要/分析

**结论**：附件归档是主交付，聊天文本是可选增值。

---

### 1.5 入 Obsidian — ✅ 100% 可行

**方法**：本地 Markdown 写入，附件相对路径引用。
- Obsidian 就是本地文件夹，无 API、无鉴权
- 只要路径对，直接写文件就行

---

### 1.6 入腾讯 ima 知识库 — ✅ 90% 可行

**证据**：
- ima.qq.com/agent-interface 官方提供 API Key
- 公开文章实测 `create_media` + `add_knowledge` 链路通
- 腾讯云开发者社区有完整调用示例

**剩余 10% 风险**：
- ima 可能随时改接口（毕竟是 C 端产品，不是企业级开放平台）
- 配额限制（未公开 QPS，脚本按保守 1 QPS 跑）
- 用户没拿到正确的 knowledge_base_id

**缓解**：脚本里所有硬编码 URL 集中在 constants 区，改起来方便。

---

### 1.7 LLM 分析与摘要 — ✅ 100% 可行

这是大模型本职工作。只要有输入（文件内容/文件名清单），就能产出。

## 2. 整体可行性结论

| 维度 | 评分 |
|---|---|
| 核心价值（附件归档+入库） | 95% 可交付 |
| 端到端自动化程度 | 60%（wxid 映射、用户手动备份这两步绕不开） |
| 边界清晰度 | 高（加密 db 不碰、手机不碰、过期附件不救） |
| 上架合规性 | 高（无破解、无代写、无灰色操作） |

## 3. 不做清单（合规红线）

- ❌ 不读 `message_*.db`、`contact.db` 等加密数据库
- ❌ 不 dump 微信进程内存密钥
- ❌ 不调用第三方"微信解密工具"
- ❌ 不远程操作用户手机
- ❌ 不承诺"找回云端已过期的附件"
- ❌ 不引导用户绕过微信风控

这些红线写在 SKILL.md 顶部，任何智能体加载本 skill 都会先读到。
