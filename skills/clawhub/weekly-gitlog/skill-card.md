## Description:

Generate a compact weekly changelog from a git repository, grouped by author and day, without any dependencies.

This skill is ready for commercial/non-commercial use.

## Publisher:

[terrycarter1985](https://clawhub.ai/user/terrycarter1985)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to produce a concise weekly summary of recent git commits for standups, reports, and release-note drafting.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated changelogs may include sensitive commit subjects or author email addresses from private repositories.

Mitigation: Review the generated summary before sharing it outside the intended audience.

Risk: The script shells out to git and fails when git is unavailable or the selected path is not a git work tree.

Mitigation: Confirm git is installed and run the skill from a repository root or pass a valid --repo path.
