# 通用客服绩效规则包 v1.0

总分 100 分，四个维度加权求和。用户提供自有规则表时以用户规则为准。

## 维度与权重

| 维度 | 权重 | 说明 |
|---|---|---|
| 工作量饱和度 | 30% | 在线时长与接待量是否达标 |
| 服务质量 | 30% | 好评率、差评率 |
| 解决效率 | 25% | 一次解决率（FCR） |
| 响应速度 | 15% | 首次响应时长 |

## 阶梯计分标准（每维度满分 100，再乘权重）

### 工作量饱和度（在线占比 = 在线时长 / 应在线时长）
- 在线占比 ≥ 90%：100 分
- 80% ≤ 在线占比 < 90%：80 分
- 70% ≤ 在线占比 < 80%：60 分
- 在线占比 < 70%：40 分
（若数据表提供接待量达标率，可与在线占比取平均；规则表未定义则只用在线占比）

### 服务质量（好评率 = 好评数 / (好评数 + 差评数)）
- 好评率 ≥ 98%：100 分
- 95% ≤ 好评率 < 98%：85 分
- 90% ≤ 好评率 < 95%：70 分
- 好评率 < 90%：50 分
- **差评数 + 好评数 = 0（无评价）**：该维度标记待复核，不按 0 计
- **差评数为 0 但有好评**：好评率记为 100%

### 解决效率（一次解决率 FCR）
- FCR ≥ 85%：100 分
- 75% ≤ FCR < 85%：80 分
- 65% ≤ FCR < 75%：60 分
- FCR < 65%：40 分

### 响应速度（首次响应时长，秒）
- ≤ 30 秒：100 分
- 30-60 秒：80 分
- 60-120 秒：60 分
- > 120 秒：40 分

## 计分示例（供理解，非硬编码）

某坐席：在线占比 92% → 工作量 100 分 × 30% = 30
好评率 96% → 服务质量 85 分 × 30% = 25.5
FCR 88% → 解决效率 100 分 × 25% = 25
首响 45 秒 → 响应速度 80 分 × 15% = 12
总分 = 30 + 25.5 + 25 + 12 = 92.5

## 缺失值处理

任一维度所需的原始数据缺失，该维度不计分、标记"待人工复核"，该坐席总分标注"含待复核项"。**不得按 0 计分。**
