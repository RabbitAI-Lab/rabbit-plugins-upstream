# 客服坐席绩效核算 (cs-agent-performance)

上传坐席工作量数据表和绩效规则表，按你的规则逐人核算得分，输出**带完整计算过程**的绩效明细、团队分布与待人工复核清单。算得对不对，每一步都摊开给你看。

## 它能做什么

- 输入：坐席工作量数据表 + 绩效规则表（Excel/CSV 均可，无需预处理）
- 输出：三表结果——绩效明细（每个维度的原始值/档位/得分/加权全透明）、团队分布（只给分布不点名）、待人工复核清单
- 内置四维度通用规则（工作量饱和度/服务质量/解决效率/响应速度），也可上传自有规则表覆盖

## 设计原则

- **透明**：不是给个总分了事，每个维度怎么算的、命中哪个档位、乘多少权重，逐项列出，方便复核
- **不排名点名**：可看团队分布，但不输出"末位名单""强制梯队"——那是管理决策，不是核算工具该做的
- **缺失值不按 0**：某人某项数据缺失，标记待复核，不会静默按 0 拉低他的分
- **供复核参考**：结果不作最终考核依据，用于薪酬/考核决策前请人工核实
- 数据本地处理，不外传

## 自定义规则

默认规则见 `references/rules-default.md`。按你公司的考核办法定制（改权重、改阶梯、加维度），参考 `references/rules-guide.md`，把规则做成 Excel/CSV 随数据一起上传即可。
