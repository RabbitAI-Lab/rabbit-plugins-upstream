# powpow-register

Olùrànlọ́wọ́ ìforúkọsílẹ̀ PowPow Bubble (ẹ̀dà OpenClaw): máa ṣe amọ̀nà olùmúlò tuntun láti «mọ ohun tí Bubble jẹ́» dé «ìmúṣiṣẹ́ àkọọlẹ̀ àti lílò rẹ̀ dáradára» — ìfihàn ọjà (pẹ̀lú àwọn àwòrán ojú-ìwé), ìtọ́sọ́nà ìforúkọsílẹ̀ lẹ́sẹ̀-kẹ̀tẹ́kẹ̀tẹ́, ìṣàwárí ìṣòro àti àlàyé ìmúṣiṣẹ́ ìforúkọsílẹ̀.

Skill ìtọ́sọ́nà péré, kò ní ìkọ̀wé-ètò tàbí ìgbẹ́kẹ̀lé; gbogbo ìgbésẹ̀ ìforúkọsílẹ̀ ni olùmúlò ṣe lórí browser/app.

## Fífi sílẹ̀

```
openclaw skills install @durenzidu/powpow-register
```

## Àwọn iṣẹ́

1. **Ìfihàn ọjà**: kíkó ~120 ọ̀rọ̀ + àwọn ọ̀rọ̀ asopọ̀ àwòrán ojú-ìwé tí a tọ́jú lórí ìpamọ́ gbogbogbò GitHub (ojú-ìwé máàpù, ojú-ìwé àkójọ àwọn ìkọ̀wé, àti bẹ́ẹ̀ lọ — 6 lápapọ̀, rán 1–3 ní ìbámu pẹ̀lú ipò).
2. **Ìtọ́sọ́nà ìforúkọsílẹ̀**: àwọn ìlànà pápá fọ́ọ̀mù (orúkọ olùmúlò/ọ̀rọ̀ àsìrí/kódì ìmúdarí ìmélì/nọ́ḿbà fóónù/àwòrán ìdánimọ̀), ìwọlé onígbà-mẹ́ta (Google/Watcha/Huawei) àti àwọn ṣíṣètò ìdíwọ̀n — gbogbo wọ́n wá láti inú kóòdù ìpìlẹ̀ pẹ̀pẹ̀, a sì tọ́ka orísun.
3. **Ìṣàwárí ìṣòro**: kò gba kódì ìmúdarí, orúkọ olùmúlò/ìmélì ti wà, 403 àìṣiṣẹ́, àkọọlẹ̀ tíipa, àti àwọn mìíràn — 13 àwọn àṣìṣe tó wọ́pọ̀.
4. **Ìmúṣiṣẹ́ ìforúkọsílẹ̀**: àwọn ọ̀nà mẹ́ta — PayPal (ayélujára) / QR WeChat (ìfọwọ́sowọ́pọ̀ ènìyàn) / Huawei IAP (HarmonyOS) — àlàyé àti ìṣàwárí ìṣòro; a lè lo àwọn ọ̀nà ìsanwó tó wà lọ́wọ́ taara, skill ń ṣe ìtọ́sọ́nà nìkan.
