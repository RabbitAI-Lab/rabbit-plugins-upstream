## Description:

Markdown note formatting and cleanup utility. Use when cleaning up raw notes, standardizing markdown structure, fixing heading hierarchies, or converting messy pasted text into clean, well-structured markdown documents.

This skill is ready for commercial/non-commercial use.

## Publisher:

[terrycarter1985](https://clawhub.ai/user/terrycarter1985)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, writers, and note-takers use this skill to clean up raw Markdown notes, standardize document structure, and prepare notes for sharing or publication.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can direct an agent to overwrite Markdown files during formatting.

Mitigation: Review formatted diffs or save a new copy before replacing important notes.
