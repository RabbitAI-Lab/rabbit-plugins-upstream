## Description:

Edit, restyle, upscale or remove the background of an image with a Wiro AI model. Use when the user wants an existing image changed, restyled, upscaled or cut out with Wiro AI or through the Wiro MCP server.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers and creators use this skill to edit existing images with Wiro AI, including restyling, upscaling, and background removal, through a connected Wiro MCP server.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Local images may be sent to Wiro for processing when an API key is available.

Mitigation: Before uploading, confirm that the image may be shared with Wiro and avoid sending images containing information the user does not want to disclose.
