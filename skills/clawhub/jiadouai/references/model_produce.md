# 模特生成

> 调用方式及异步轮询见 SKILL.md「调用方式」「异步任务轮询」

## 参数

```json
{
  "feature": {                              // 必填
    "gender": "女",                         // 必填："男" | "女"
    "age": "青年",                          // 可选，默认 null：儿童 | 大童 | 青年 | 中年 | 老年
    "hair_style": "长直发",                 // 可选，默认 null：长直发 | 短直发 | 长卷发 | 短卷发 | 高马尾 | 侧马尾 | 双麻花辫 | 波比卷 | 侧分短发 | 复古长卷 | 精灵短发 | 手推波浪 | 丸子头
    "hair_color": "金色",                   // 可选，默认 null：黑色 | 金色 | 棕色 | 灰色
    "color": "白色",                        // 可选，默认 null：肤色：黄色 | 白色 | 小麦色 | 黑色
    "figure": "偏瘦",                       // 可选，默认 null：偏瘦 | 偏胖 | 肥胖 | 肌肉
    "expression": "微笑"                    // 可选，默认 null：微笑 | 甜美 | 高冷 | 端庄 | 神秘 | 性感
  },
  "url": "https://cdn.example.com/ref.jpg", // 可选，默认 null：模特参考图，公网URL
  "ratio": "3:4",                           // 可选，默认 3:4：21:9 | 16:9 | 4:3 | 1:1 | 3:4 | 9:16 | 9:21
  "prompt": "模特生成提示词"                 // 可选，默认 null
}
```

## 关键约束

- `gender` 在 `feature` 内部（嵌套对象），不是顶层参数 — 与 `model_try_clothes` 不同
