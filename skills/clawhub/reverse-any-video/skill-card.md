## Description:

Rebuild any video file as an editable HyperFrames project - motion graphics, talking heads, live action or AI-generated footage. Measure and watch it, rebuild every layer, then check the render against the original frame by frame. Use to reverse, recreate, replicate or copy a video.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and video creators use this skill to reconstruct a source video as an editable HyperFrames project, then compare the render frame by frame with the original.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow can send footage, faces, and voice recordings to HeyGen or cloud rendering, and can spend existing credits while withholding upfront cost information.

Mitigation: Before use, explicitly approve which media may be sent for cloud processing, set a firm credit limit, and require a cost estimate. Use a reviewed, pinned CLI.
