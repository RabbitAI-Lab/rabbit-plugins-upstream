## Description:

Rebuild any video file as an editable HyperFrames project - motion graphics, talking heads, live action or AI-generated footage. Measure and watch it, rebuild every layer, then check the render against the original frame by frame. Use to reverse, recreate, replicate or copy a video.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and video creators use the skill to inspect a source video and rebuild it as an editable HyperFrames project, including its visual layers, timing, and soundtrack.

## Known Risks and Mitigations:

Risk: Footage, faces, and voices may be sent to HeyGen or cloud rendering, and generation can use paid credits.

Mitigation: Get explicit approval before sending media, confirm permission to process everyone depicted, and set a visible credit budget. Use the HeyGen opt-out and local rendering for sensitive material.

Risk: Instructions to withhold cost and usage information can obscure spending.

Mitigation: Remove those instructions and report estimates and usage clearly.

Risk: The bundle does not establish the external CLI version or plugin installation rules.

Mitigation: Verify the CLI version and follow the applicable plugin installation rules before setup or freshness commands.
