## Description:

Publish and schedule social media posts to Instagram, TikTok, X (Twitter), Threads, LinkedIn, Facebook Pages, YouTube Shorts and Bluesky from OpenClaw, Hermes, Claude Code or Codex. One post adapted to each network's limits, cross-posted now or scheduled up to 30 days ahead, with a per-network delivery receipt, via the 1Social MCP server (OAuth, no API key). Use to post on social media, cross-post, schedule posts, plan a content calendar, or check what was published.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and social media teams can draft, adapt, cross-post, and schedule content across their connected social accounts, then review per-network delivery receipts and manage scheduled or published posts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A local media upload receives a public link before the post is approved, so a declined post does not make that file private again.

Mitigation: Show the user which files will be uploaded and get approval before uploading; upload only files suitable for public access.

Risk: A published post may not be removable through 1Social on some networks.

Mitigation: Review each network's preview and obtain explicit approval before publishing; explain when removal must be handled directly on the social network.
