# image-with-comfyui — SFW model download sources
#
# This file lists clean / official download sources for the model weights
# required by the image-with-comfyui skill. Everything here is SFW.
#
# Common prefix: https://huggingface.co/
# File path = "{prefix}/{repo}/{path}"
#
# Format legend:
#   ✓  = file/weight verified to exist
#   ★  = repo may require login (HTTP 401 without an authenticated HF account);
#        download on a machine where you are logged in.
#
# -----------------------------------------------------------------
# FILENAME CAVEAT (read before deploying)
# -----------------------------------------------------------------
# The SFW weights below usually have DIFFERENT filenames than what the bundled
# workflow's loader nodes expect. The script does NOT rename model files for
# you. If you deploy the SFW weights you must make the workflow match the
# on-disk filenames, EITHER by:
#   (a) renaming the downloaded files to match the workflow node's
#       unet_name / ckpt_name, OR
#   (b) editing that node's unet_name / ckpt_name to the actual filenames.
# For Qwen-Image 2.1 the loader node is node 17 in
#   workflows/qwen_image_2.1_api.json (unet_name).
# For **Qwen-Image 2.1 Turbo** (`qwen21t`) the loader node is node 17 in
#   workflows/qwen_image_2.1_turbo_api.json (unet_name).
# The turbo and legacy workflows have identical node topology; only the
# unet_name (filename) differs — pick the one that matches the file on disk.
# For SD3.5 the loader node is node 4 in
#   workflows/sd3.5-med_t2i_api.json (ckpt_name).
# For Wan2.2 the loader nodes are 307 (high) and 308 (low) in
#   workflows/wan2.2_i2v_api.json (unet_name).
# Leave the workflow's unet_name/ckpt_name pointing at the filenames that
# actually exist on disk after you place the weights.
# -----------------------------------------------------------------

# --- TEXT ENCODER (32B) ===
# The 32B text encoder ships only as NVFP4 (4090-INCOMPATIBLE). Use the GGUF
# build instead, loaded through ComfyUI-GGUF's CLIPLoaderGGUF node with
# type="qwen_image" (do NOT use a plain CLIPLoader for this node).
#
# Repo: nif0/Qwen3-VL-32B-Instruct-MiniMax-H3-GGUF ✓  (SFW, PUBLIC — anonymous
# download works; verified 2026-10-17 with an unauthenticated range GET on both
# files below, HF models API reports gated: false).
# ⚠ CASING TRAP: the repo id is "MiniMax" (capital M + lowercase i). The
# common misspelling "MinMax" (e.g. some shared links) 401s on every request.
# https://huggingface.co/nif0/Qwen3-VL-32B-Instruct-MiniMax-H3-GGUF/tree/main
#
#     text encoder  -> Qwen3-VL-32B-Instruct-MiniMax-H3-L0-49-Q4_K_M.gguf   (~14.9 GB; Q4_K_M)
#     (other quants in the same repo also exist: IQ4_XS, UD-* variants)
#
#     FILENAME RULE (must match exactly — the CLIP and mmproj MUST agree):
#       The text encoder and the mmproj (needed only for image-to-text) share
#       the SAME name stem — i.e. everything BEFORE the quantization tag is
#       identical — and both files live in the SAME folder (models/clip/).
#       The stem is Qwen3-VL-32B-Instruct-MiniMax-H3-L0-49; the quant/role tag
#       after the stem differs. Example correct pair:
#           Qwen3-VL-32B-Instruct-MiniMax-H3-L0-49-Q4_K_M.gguf       # text encoder
#           Qwen3-VL-32B-Instruct-MiniMax-H3-L0-49-mmproj-BF16.gguf  # mmproj (i2t only)
#       Do NOT mismatch stems (e.g. never pair a `-Q4_K_M` stem with an
#       mmproj whose stem ends in something else), and do NOT scatter them
#       across different folders — ComfyUI-GGUF resolves the clip + mmproj
#       together only when the stem matches.
#
# NOTE: the bundled H3 workflows currently set clip_name to the on-disk
# eraiko build (qwen3_vl_32b_minimax_h3_q5_k_m.gguf). If you switch to the
# nif0 Q4_K_M file above, update clip_name in workflows/h3_fasth3_t2v_api.json
# / h3_fasth3_i2v_api.json to the nif0 filename.

# --- ComfyUI-GGUF NODE (pin this fork) ===
# The bundled H3 workflow uses nodes from the Nif00 ComfyUI-GGUF fork (it adds
# the H3/mmproj support). Install + pin the exact commit:
#     cd ComfyUI/custom_nodes
#     git clone https://github.com/Nif00/ComfyUI-GGUF
#     cd ComfyUI-GGUF && git checkout b6a9358c40e0f36febd6b1b06ec3d1cd0fa82ce7   # main HEAD
#
# Node wiring used by the H3 workflows:
#     text encoder  -> CLIPLoaderGGUF, clip_name = <the Q4_K_M stem>.gguf, type = qwen_image
#
# NOTE ON VRAM: a 4090 (24 GB) cannot hold the ~22 GB diffusion + 32B text
# encoder together. The text encoder is a GGUF that ComfyUI-GGUF loads via a
# device/offload policy; if a run OOMs, offload the text encoder to CPU/RAM or
# bind the video run to a 22 GB 2080 Ti (keep the 4090 for the diffusion model).
