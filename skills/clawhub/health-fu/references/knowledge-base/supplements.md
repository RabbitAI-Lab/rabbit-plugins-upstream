# 补充剂循证评价

循证评级：
- A 级：强证据支持，指南一致推荐特定场景使用
- B 级：中等证据，有特定适用场景
- C 级：弱证据或无明确证据，不推荐全民使用
- D 级：有证据不支持或可能存在风险

---

## 维生素类

### 维生素 D — 循证评级：B 级（缺乏/不足人群 A 级）

适用场景：

1. 血清 25(OH)D <20ng/mL（缺乏）：需补充，剂量遵医嘱
2. 25(OH)D 20-30ng/mL（不足）：可补充 400-800 IU/d
3. 日照不足者（北方冬季、长期室内工作、严格防晒）：可补充 400-800 IU/d
4. 65 岁以上老年人：600 IU/d
5. 骨质疏松患者：通常 800-1200 IU/d，遵医嘱

不适用场景：

- 日照充足、饮食鱼类摄入充足且无缺乏证据者：常规补充获益不明确

注意事项：

- D3（胆钙化醇）生物利用度略优于 D2
- 随餐服用（含脂肪）有助于吸收
- 超大剂量间歇服用效果可能不如每日补充
- 过量：>4000 IU/d 长期服用可能导致高钙血症

### 复合维生素 — 循证评级：C 级

适用场景：

1. 饮食明显不均衡、长期热量摄入不足（如严格节食、术后恢复期）
2. 特殊生理阶段（备孕/孕期需含叶酸 400-800μg/d）
3. 严格素食者（需额外关注 B12）

不适用场景：

- 饮食均衡的普通成年人：多项大规模研究（如 PHS II、TACT）未显示复合维生素能降低心血管疾病、癌症或全因死亡率
- 替代均衡饮食

结论：不能替代均衡饮食。饮食不均衡者可作为兜底方案，但改善饮食结构是根本。

### 维生素 C — 循证评级：C 级（预防感冒）/ B 级（特定场景）

适用场景：

1. 饮食摄入不足、吸烟者（额外的氧化应激）
2. 高强度运动训练期间：可能降低上呼吸道感染风险（弱证据）

不适用场景：

- 预防普通感冒：不能显著降低感冒发生率
- 常规保健：食物来源（新鲜蔬果）完全可满足需求

剂量参考：

- 日常补充不宜超过 500mg/d
- 感冒期间大剂量（>2000mg/d）：可能略微缩短病程 8%-14%，但获益与风险需权衡

### B 族维生素 — 循证评级：分项评级

叶酸（B9）：
- 备孕和孕早期补充 400-800μg/d：A 级（预防神经管畸形）
- 普通成人常规补充：C 级（食物可满足）

B12：
- 严格素食者和吸收不良者：A 级
- 普通成人：C 级

B6/B1/B2：
- 有明确缺乏症状或高危因素（酗酒、特定药物）时：B 级
- 普通成人预防性补充：C 级

## 矿物质类

### 钙剂 — 循证评级：B 级

适用场景：

1. 饮食钙摄入严重不足且无法通过饮食改善
2. 骨质疏松高风险人群：配合维生素 D
3. 已确诊骨质疏松且饮食钙不足

不适用场景：

- 饮食钙摄入充足（>800mg/d）
- 单纯为了"预防"而无缺乏风险

注意事项：

- 单次补钙不超过 500mg 元素钙（吸收率考虑）
- 柠檬酸钙 vs 碳酸钙：柠檬酸钙不依赖胃酸，更适合老年人、服用抑酸药者
- 关于补钙和肾结石：膳食钙摄入充足反而降低肾结石风险（草酸在肠道与钙结合）；但大剂量钙补充剂可能增加风险
- 补钙与心血管风险：目前证据不一致，多数指南认为膳食和适量补充剂钙摄入总体安全

### 铁剂 — 循证评级：A 级（确诊缺乏时）

适用场景：

1. 确诊缺铁性贫血：A 级，遵医嘱
2. 孕期常规补铁：各国指南不同，中国指南建议孕中晚期补充 30-60mg/d 元素铁
3. 月经量大的育龄女性伴铁蛋白低：B 级

不适用场景：

- 无缺乏依据的常规补铁：C 级，有铁过载风险
- 男性、绝经后女性：不建议常规补铁

### 锌 — 循证评级：B 级（缺乏时）

适用场景：

1. 有缺乏症状（味觉减退、脱发、伤口愈合慢）且有膳食缺口
2. 儿童腹泻期补锌（WHO 推荐）

不适用场景：普通成人预防感冒（证据不一致，部分研究支持，部分不支持）

### 硒 — 循证评级：C 级

- 中国低硒带地区居民可关注膳食硒摄入
- 无缺乏依据不推荐常规补充
- 过量风险明确（硒中毒）
- 不建议通过"抗癌""增强免疫"等宣传自行补充

### 镁 — 循证评级：B 级（特定场景）

适用场景：

1. 肌肉痉挛伴膳食摄入不足
2. 偏头痛预防（部分研究支持，证据中等）
3. 便秘（柠檬酸镁有渗透性轻泻作用）

形式差异：

- 氧化镁：吸收率低，但有通便作用
- 柠檬酸镁：吸收率较好
- 甘氨酸镁：生物利用度高，胃肠道副作用少

## 其他常见补充剂

### 鱼油 / n-3 多不饱和脂肪酸 — 循证评级：B 级（高甘油三酯 A 级）

适用场景：

1. 高甘油三酯血症（>500mg/dL）：处方剂量 n-3 FA（2-4g/d），A 级
2. 每周吃不到 2-3 次鱼：补充 EPA+DHA 250-500mg/d，B 级
3. 已确诊冠心病：部分指南推荐（证据不一致）

不适用场景：

- 普通人群心血管一级预防：证据偏弱（REDUCE-IT 和 STRENGTH 研究结果不同，可能与剂量和配方有关）

注意事项：

- 藻油是素食者的 DHA 来源
- 抗凝药物使用者补充高剂量鱼油前需咨询医生

### 益生菌 — 循证评级：分适应症

有明确证据的适应症：

1. 抗生素相关性腹泻预防：A 级（尤其 Lactobacillus rhamnosus GG、Saccharomyces boulardii）
2. 儿童急性感染性腹泻辅助：A 级
3. IBS 部分亚型改善症状：B 级（菌株特异性，不同研究差异大）
4. 便秘（某些菌株如 Bifidobacterium lactis）：B 级

证据不足或阴性：

1. 普通人"调节肠道""增强免疫"：C 级
2. 减肥：C 级
3. 湿疹/过敏预防：证据不一致

菌株特异性原则：益生菌效果是菌株特异性的，不可在不同菌株间简单类推。

### 蛋白粉 — 循证评级：B 级

适用场景：

1. 饮食蛋白质摄入不足（<0.8g/kg/d）
2. 运动人群增肌期：总蛋白 1.2-2.0g/kg/d，蛋白粉是补充方式之一
3. 老年人、术后、烧伤等需高蛋白但食欲有限
4. 素食者（植物蛋白粉）

形式和选择：

- 乳清蛋白：吸收快，支链氨基酸丰富，增肌证据最强
- 酪蛋白：吸收慢，睡前补充可能有利
- 大豆蛋白：素食者首选，降脂效果优于乳清蛋白
- 豌豆蛋白、大米蛋白：低致敏性替代

不适用场景：

- 饮食蛋白质已充足的普通成人
- 蛋白粉不能替代均衡饮食

### 肌酸 — 循证评级：A 级（运动表现）

适用场景：

1. 高强度间歇运动、力量训练表现提升：A 级
2. 老年人肌少症辅助：B 级

剂量：

- 标准方案：每日 3-5g 维持，无需冲击期
- 或冲击期 20g/d x 5-7 天，后维持 3-5g/d

安全性：

- 健康人群长期使用安全性良好
- 肾功能不全者不建议

### 天然提取物与"超级食物"补充剂 — 循证评级多为 C-D 级

常见品类评价：

- 螺旋藻/小球藻：营养较丰富，但"排毒""抗癌"等宣称缺乏临床证据
- 姜黄素：抗炎作用有体外和动物实验支持，人体临床证据不足（生物利用度低是主要问题）
- 辅酶 Q10：服用他汀类药物出现肌肉症状者可尝试（B 级），其他抗衰老/抗癌等用途证据不足
- 葡萄籽提取物：抗氧化有体外证据，但临床获益不明确
- 酵素/酶：口服后在消化道被分解，与宣称的"抗炎排毒"无关
- 灵芝孢子粉：传统药用，缺乏高质量临床研究，所谓的抗癌作用多来自细胞和动物实验
- 玛咖：增强性功能证据极弱
- 胶原蛋白：口服后和其他蛋白质一样被分解为氨基酸，但部分研究表明胶原蛋白肽可能刺激皮肤成纤维细胞（B 级，证据强度有限）

通用结论：大多数天然提取物补充剂证据等级不高，营销话术常远超实际作用。性价比低。优先从天然食物获取。

---

## 关键原则

1. 优先从食物获取，补充剂是兜底的，不能替代均衡饮食
2. 有缺乏才补，不建议"预防性"大量补充
3. 搭配有讲究：铁 + 维生素 C 促进吸收；钙 + 铁互相竞争吸收（分开服用）
4. 肾脏、肝脏疾病患者在补充任何营养素之前需咨询医生
5. 不要被营销话术带偏，"天然""草本""超级食物"不等于有效和安全
