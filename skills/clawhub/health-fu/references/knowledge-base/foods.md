## 油脂类

| 种类 | 特点 | 适合用途 | 备注 |
|---|---|---|---|
| 橄榄油（特级初榨） | 单不饱和脂肪酸为主，含多酚 | 凉拌、低温烹饪 | 烟点较低 |
| 菜籽油（双低） | 单不饱和脂肪酸为主，n-6/n-3比例较好 | 日常炒菜 | - |
| 花生油 | 单不饱和脂肪酸为主 | 日常炒菜 | - |
| 亚麻籽油 | α-亚麻酸（n-3）极高 | 凉拌 | 不能高温加热 |
| 猪油 | 饱和脂肪酸 ~39% | - | 建议少用 |
| 椰子油 | 饱和脂肪酸 ~90% | - | 饱和脂肪含量极高，不推荐作为常规用油 |

每日烹调用油推荐量：25-30g（约 2-3 汤匙）
