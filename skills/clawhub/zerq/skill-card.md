## Description:

Zerq Clawhub guides quality issue root cause analysis using the ZerQ/ZeroQ dual-closure method, including technical and management closure checks for reports, corrective actions, and validation planning.

This skill is ready for commercial/non-commercial use.

## Use Case:

Quality, manufacturing, and engineering teams use this skill to structure technical and management root cause analysis, 8D/corrective action reports, closure reports, and recurrence-prevention checklists. It helps separate evidence-backed technical causes from process and accountability issues without replacing professional engineering judgment.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Root cause analysis guidance can be incomplete or misleading if users provide insufficient test data, process history, or validation evidence.

Mitigation: Require users to identify missing evidence, validate conclusions with qualified engineering reviewers, and avoid fabricating test data or responsibility findings.

Risk: Management closure analysis could be misused as personal blame rather than process improvement.

Mitigation: Frame responsibility findings around documented process steps, assigned controls, and corrective actions, and exclude unsupported personal judgments.

Risk: Future full-version releases may add scripts, integrations, or automated report handling that change the security posture.

Mitigation: Review and scan future releases separately before deployment, especially if they add code execution, external APIs, or file-processing behavior.
