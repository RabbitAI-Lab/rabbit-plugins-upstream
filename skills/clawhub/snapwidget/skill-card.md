## Description:

Add social media feeds (Instagram, Facebook, TikTok, X, YouTube) and reviews (Google, G2, testimonials) to a website with SnapWidget.

This skill is ready for commercial/non-commercial use.

## Publisher:

[snapwidget](https://clawhub.ai/user/snapwidget)

### License/Terms of Use:

MIT-0

## Use Case:

Business owners and their developers use this skill to connect authorized social accounts or review sources, create a SnapWidget, and install it on a website. It provides platform-specific steps and embed code for common site builders and web frameworks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Some installation guides may weaken website protections or load third-party code across an entire webshop.

Mitigation: Review the guide for the specific site, preserve HTML filtering and sandbox protections, and restrict widget tags to approved pages, excluding checkout and account pages. Approve broader settings changes explicitly and keep a rollback plan.

Risk: External software and generated embeds were not verified, and manually added testimonials may not be approved for publication.

Mitigation: Review the generated embed and installation steps before use, and upload only testimonials approved for publication.
