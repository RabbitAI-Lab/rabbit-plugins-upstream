# How do I add an Instagram widget to my Kajabi website?

> Add your SnapWidget Instagram widget to a Kajabi website page with a Custom Code section.

Paste your SnapWidget code into a **Custom Code** section where you want the widget to show. The same steps work for Facebook, X, TikTok and YouTube widgets.

### In SnapWidget

1. [Create your widget](https://snapwidget.com/docs/getting-started/create-an-instagram-widget.md), or open an existing widget from your [dashboard](https://snapwidget.com/dashboard).
2. Click **Install Widget**.
3. In the **Install Widget** window, click **Copy Code**.

### In Kajabi

1. In your Kajabi dashboard, click **Website**, then **Pages**. Open the page editor for the page where you want the widget.

2. In the sidebar, click **Add Section**.

3. In the **Custom** category, choose **Custom Code** and click **Add**.

   ![The Custom Code section with the Add button](https://mintcdn.com/snapwidget/QJTE73Rcy1kqujES/images/install/kajabi/6.png?fit=max\&auto=format\&n=QJTE73Rcy1kqujES\&q=85\&s=a85ef3977c816991d8816a79ceb7d840)

4. Click the new **Custom Code** section in the sidebar. Paste your code in the **Code** box. Use **Width** to set how many columns the widget uses.

   ![The Custom Code settings with the Width and Code fields](https://mintcdn.com/snapwidget/QJTE73Rcy1kqujES/images/install/kajabi/9.png?fit=max\&auto=format\&n=QJTE73Rcy1kqujES\&q=85\&s=876f5c4bb2c9a644adab24382c6a6178)

5. Click **Save**.

### Check your widget

Open the page on your live site. The widget shows your latest Instagram posts.
