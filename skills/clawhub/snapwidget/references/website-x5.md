# How do I add an Instagram widget to my WebSite X5 website?

> Add your SnapWidget Instagram widget to a WebSite X5 page with the HTML Code object, then upload your site.

Paste your SnapWidget code into an **HTML Code** object where you want the widget to show. The same steps work for Facebook, X, TikTok and YouTube widgets.

### In SnapWidget

1. [Create your widget](https://snapwidget.com/docs/getting-started/create-an-instagram-widget.md), or open an existing widget from your [dashboard](https://snapwidget.com/dashboard).
2. Click **Install Widget**.
3. In the **Install Widget** window, click **Copy Code**.

### In WebSite X5

1. Open WebSite X5 and open your project.

2. Click **Pages** and open the page where you want the widget.

3. Drag the **HTML Code** object onto an empty cell of the page.

   ![The HTML Code object](https://mintcdn.com/snapwidget/QJTE73Rcy1kqujES/images/install/website-x5/5.png?fit=max\&auto=format\&n=QJTE73Rcy1kqujES\&q=85\&s=fad28d2c32006d83992f2656285b5701)

4. Double-click the object. On the **HTML Code** tab, paste your code and click **OK**.

   ![The HTML Code tab of the HTML Code object](https://mintcdn.com/snapwidget/QJTE73Rcy1kqujES/images/install/website-x5/8.png?fit=max\&auto=format\&n=QJTE73Rcy1kqujES\&q=85\&s=7f8b737766c25f1bbb116f734c3f4cc3)

5. Click **Preview** to check the page.

6. Export your site and upload it to your web host.

### Check your widget

Open the page on your live site. The widget shows your latest Instagram posts.
