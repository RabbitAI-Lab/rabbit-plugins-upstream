# How do I add an Instagram widget to my Dotclear website page or blog?

> Add your SnapWidget Instagram widget to a Dotclear post or page with the Source button of the editor.

Paste your SnapWidget code into a Dotclear post or page with the **Source** view of the editor. The same steps work for Facebook, X, TikTok and YouTube widgets.

### In SnapWidget

1. [Create your widget](https://snapwidget.com/docs/getting-started/create-an-instagram-widget.md), or open an existing widget from your [dashboard](https://snapwidget.com/dashboard).
2. Click **Install Widget**.
3. In the **Install Widget** window, click **Copy Code**.

### In Dotclear

1. In the Dotclear admin, click **New post**. For a page, click **Pages**, then make a new page or open a page.

   ![The New post item in the Blog menu](https://mintcdn.com/snapwidget/QJTE73Rcy1kqujES/images/install/dotclear/14.png?fit=max\&auto=format\&n=QJTE73Rcy1kqujES\&q=85\&s=7dc5486034d62a91c0ef8490736d9993)

2. Make sure **Text formatting** is set to **xhtml**.

3. In the editor toolbar, click **Source**.

4. Paste your code into **Content:** where you want the widget to show.

   ![The Content box in Source view with the Save button](https://mintcdn.com/snapwidget/QJTE73Rcy1kqujES/images/install/dotclear/15.png?fit=max\&auto=format\&n=QJTE73Rcy1kqujES\&q=85\&s=d10fc59e4d1d04eb09ebf6015aa6267d)

5. Set the status to **Published** and click **Save**.

### Check your widget

Open the post or page on your live blog. The widget shows your latest Instagram posts. If you see the code as text, check that **Text formatting** is set to **xhtml**.
