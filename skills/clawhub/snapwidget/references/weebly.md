# How do I add an Instagram feed widget to my Weebly website?

> Add your SnapWidget Instagram widget to a Weebly page with the Embed Code element.

Paste your SnapWidget code into an **Embed Code** element where you want the widget to show. The same steps work for Facebook, X, TikTok and YouTube widgets.

### In SnapWidget

1. [Create your widget](https://snapwidget.com/docs/getting-started/create-an-instagram-widget.md), or open an existing widget from your [dashboard](https://snapwidget.com/dashboard).
2. Click **Install Widget**.
3. In the **Install Widget** window, click **Copy Code**.

### In Weebly

1. Log in to Weebly and click **Edit site**.

2. Open the page where you want the widget. On the **Build** tab, drag the **Embed Code** element onto the page.

3. Click the element (**Click to set custom HTML**), then click **Edit Custom HTML**.

   ![The Click to set custom HTML box](https://mintcdn.com/snapwidget/QJTE73Rcy1kqujES/images/install/weebly/9.jpg?fit=max\&auto=format\&n=QJTE73Rcy1kqujES\&q=85\&s=18b19c39d159b05e2f5317be8d834585)

   ![The Edit Custom HTML button](https://mintcdn.com/snapwidget/QJTE73Rcy1kqujES/images/install/weebly/10.jpg?fit=max\&auto=format\&n=QJTE73Rcy1kqujES\&q=85\&s=5b57d8ee60d8fac50a2338792edec753)

4. Paste your code. Click outside the element to save it.

5. Click **Publish**.

### Check your widget

Open the page on your live site. The widget shows your latest Instagram posts. Some code does not show in the editor, so always check the published site.
