# How do I add an Instagram widget to SnapPages?

> Add your SnapWidget Instagram widget to a SnapPages page with the Code block.

Paste your SnapWidget code into a **Code** block where you want the widget to show. The same steps work for Facebook, X, TikTok and YouTube widgets.

### In SnapWidget

1. [Create your widget](https://snapwidget.com/docs/getting-started/create-an-instagram-widget.md), or open an existing widget from your [dashboard](https://snapwidget.com/dashboard).
2. Click **Install Widget**.
3. In the **Install Widget** window, click **Copy Code**.

### In SnapPages

1. In SnapPages, click **Pages**. Click the menu (**...**) next to the page where you want the widget, then click **Edit**.

2. Click **Blocks** in the left sidebar. Drag the **Code** block onto the page.

   ![The Code block in the list of blocks](https://mintcdn.com/snapwidget/QJTE73Rcy1kqujES/images/install/snappages/6.png?fit=max\&auto=format\&n=QJTE73Rcy1kqujES\&q=85\&s=0206d8cd2cf42aab159af5c63959f892)

3. In the **Add Custom Code** window, click **Create New**.

   ![The Add Custom Code window with Create New](https://mintcdn.com/snapwidget/QJTE73Rcy1kqujES/images/install/snappages/9.png?fit=max\&auto=format\&n=QJTE73Rcy1kqujES\&q=85\&s=aab16e7d4581c4bfb9c2d1abae68257c)

4. Type a **Title** for the snippet, paste your code in the **Code** box and click **Save**.

5. Click **Publish**.

### Check your widget

Open the page on your live site. The widget shows your latest Instagram posts.
