# How do I add an Instagram widget to my HTMLy website?

> Add your SnapWidget Instagram widget to an HTMLy blog post or static page. HTMLy keeps the HTML code as you paste it.

Paste your SnapWidget code into the content of an HTMLy post or static page. HTMLy keeps HTML code in the content as you paste it. The same steps work for Facebook, X, TikTok and YouTube widgets.

> [!NOTE]
>
> Any user can add a post. To add a static page or to clear the cache, you need the editor or admin role.

### In SnapWidget

1. [Create your widget](https://snapwidget.com/docs/getting-started/create-an-instagram-widget.md), or open an existing widget from your [dashboard](https://snapwidget.com/dashboard).
2. Click **Install Widget**.
3. In the **Install Widget** window, click **Copy Code**.

### In HTMLy

1. Log in to HTMLy and click **Add content**.

2. Click **Regular post** or **Static page**.

   ![The Add content list](https://mintcdn.com/snapwidget/QJTE73Rcy1kqujES/images/install/htmly/2.png?fit=max\&auto=format\&n=QJTE73Rcy1kqujES\&q=85\&s=d0acafe557da3ac041ad9ac614c7d329)

3. Enter a title, then paste your code into **Content** where you want the widget to show.

4. Click **Publish**.

   ![The Content box with the widget code and the Publish button](https://mintcdn.com/snapwidget/QJTE73Rcy1kqujES/images/install/htmly/4.png?fit=max\&auto=format\&n=QJTE73Rcy1kqujES\&q=85\&s=d18ce443258cad225fe930ef8f749ae1)

### Check your widget

Open the post or page on your live site. The widget shows your latest Instagram posts. If you do not see the widget, click **Tools** > **Clear cache** and open the page again.
