# How do I add an Instagram widget to any HTML website?

> Paste your SnapWidget code into the HTML file of your page, at the place where you want the widget to show.

Use these steps if you edit the HTML files of your website yourself. Paste your SnapWidget code into the page at the place where you want the widget to show. The same steps work for Facebook, X, TikTok and YouTube widgets.

### In SnapWidget

1. [Create your widget](https://snapwidget.com/docs/getting-started/create-an-instagram-widget.md), or open an existing widget from your [dashboard](https://snapwidget.com/dashboard).
2. Click **Install Widget**.
3. In the **Install Widget** window, click **Copy Code**.

### In your HTML file

1. Open the HTML file of the page in a code editor. For your home page, this is often `index.html`.
2. Paste the code inside the `<body>` tag, at the place where you want the widget to show.
3. Save the file. If the file is on a web server, upload it again, for example with FTP or the file manager of your web host.

### Check your widget

Open the page in your browser. The widget shows your latest Instagram posts. If you still see the old page, reload it.
