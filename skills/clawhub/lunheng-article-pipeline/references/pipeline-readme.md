# 人文社科论文多 Agent 流水线 — 运行手册

> 使用方式：主控 Agent 按本文档派发任务。角色定义见 `agents/`，模板见 `templates/`。
> v2.0（2026-08-11）：新增 Phase 2.5 大纲确认、status.md 状态机、修订说明、引用分级核验、数据时效评级、防选题漂移 G0 检查、AI 去味禁做清单、证据包交付、期刊模板。
> v2.1（2026-08-11）：新增配图节点（Phase 4.5，可选）——任务简报新增「配图需求」字段，写手标 [图N] 图位，主控程序化生成数据图表（数字与数据卡一致），封面视觉按需文生图/SVG 矢量风，图件随证据包交付。

## 快速开始

```
1. 主控确认主题（Phase 0）→ 写 01-任务简报.md + 初始化 status.md
2. 并行 spawn 文献检索员 + 数据检索员（用派发话术）
3. sessions_yield 等两者完成
4. spawn 分析员 → 分析大纲产出 → Phase 2.5 送主人确认 → 通过后 spawn 写手
5. spawn 审计员 → 审计不过 → 写手交修订说明 + 修订稿（≤2 轮）→ 终检交付（含证据包）
```

## 流水线全景

```
Phase 0 定题       主人确认主题/期刊模板/篇幅 → 01-任务简报.md + status.md
Phase 1 并行检索   T1 文献检索员(文献卡A/B/C分级) ∥ T2 数据检索员(数据卡🟢🟡🔴+冲突并列)
Phase 2 分析       T3 分析员 → 分析大纲.md（论点-论据映射 + 反方论证规划）
Phase 2.5 大纲确认 主人过目大纲 → 确认/修改（人在环，改方向成本最低）
Phase 3 写作       T4 写手 → 初稿-v1.md（禁做清单 + 反方论证 + 字数预算）
Phase 4 审计       T5 审计员 → 审计报告（G0覆盖度/G1分级核验/G2溯源/G3逻辑/G4格式/G5规范）
Phase 4.2 修订     写手交 修订说明 + 修订稿 → 审计员复核 → 最多 2 轮 → 仍不过升级主控
Phase 4.5 配图     仅当简报「配图需求」非无：写手已在正文标 [图N] 图位 → 主控程序化生成数据图表（数字与数据卡一致）
Phase 5 终检      主控终检 → final/定稿.md + 图件/（如有）+ 证据包/ + 交付说明.md → 高频问题反哺角色文件
```

## status.md 状态机（主控维护，角色交接时更新）

每个任务状态：`Inbox → Assigned → In Progress → Review → Done | Failed`
- 每个角色交接时必须更新 `status.md` 对应行
- 失败要留原因；任一行停留 >10 分钟无进展 → 主控介入
- 模板：`templates/status-template.md`

## 修订回环

```
审计结论=打回 → 写手交 修订说明（逐条回应）+ 修订稿 → 审计员对照复核
最多 2 轮。仍不过 → 升级主控：重写/砍段落/咨询人类。
```

## 交付（Phase 5）

主控终检后交付：
- `final/定稿.md`
- `final/图件/`（仅当简报「配图需求」非无）：扫描定稿 [图N] 图位生成的数据图表 + 封面视觉（如有）；图件与正文图位一一对应，数字与数据卡一致
- `final/证据包/`：文献卡 + 数据卡 + 审计报告 + 引用核验记录（供投稿/答辩前人工复核）
- `final/交付说明.md`：成稿路径 + 图件清单 + 遗留风险 + 建议人工核验项
- 每单结束：审计高频问题 → 沉淀进 `agents/04-写作-writer.md` 禁做清单（自我改进闭环）

## 配图生成规范（Phase 4.5）

- **数据图表**：程序化生成（matplotlib/SVG 脚本），禁止文生图（数字不可控）。图位来自写手标注的 [图N]，图上数字必须与数据卡/正文 [Dxx] 一致，生成后抽查核对。
- **封面视觉**：文生图或 SVG 矢量风均可；出图先送主人确认风格再定稿。
- **脚本复用**：参考既有图表脚本，或本项目 `run/<项目名>/scripts/` 下已固化的工具。

## 成本与模型建议

| 角色 | 模型 | 理由 |
|------|------|------|
| 文献/数据检索 | 便宜快模型（如 deepseek-v4-flash） | 机械检索，最便宜可靠 |
| 分析/写作 | 推理强模型（如 deepseek-v4-pro / minimax-m3） | 推理与成文质量 |
| 审计 | 顶配模型（如 minimax-m3 / claude） | 专抓错，必须顶配 |
| 主控 | 强推理模型（如 deepseek-v4-pro） | 判断与终检 |
