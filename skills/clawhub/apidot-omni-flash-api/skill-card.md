## Known Risks and Mitigations: <br>
Risk: APIDot API keys and private media details may be exposed if copied into browser code, logs, screenshots, public repositories, or chat output. <br>
Mitigation: Keep APIDOT_API_KEY and private prompts, media URLs, generated video URLs, callback URLs, and task IDs server-side. <br>
Risk: Omni Flash API fields, availability, limits, and commercial terms can change outside this documentation-only skill. <br>
Mitigation: Use the current APIDot docs and model pages before making live API calls or preparing copyable request payloads. <br>
