## Use Case:

Developers use this skill to reflect on improvements to the helm-openclaw project, propose worthwhile changes in self-assigned GitLab merge requests, and close their own merge requests that have had no activity for 10 days.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill directs GitLab changes and publication without an explicit user approval step.

Mitigation: Check the requested GitLab permissions and review proposed changes before allowing remote actions.
