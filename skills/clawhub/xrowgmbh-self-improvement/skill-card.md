## Use Case:

Developers use the skill to identify worthwhile improvements, draft separate GitLab merge requests for distinct issues, and close their own stale merge requests after the stated inactivity period.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can publish findings to GitLab and close merge requests without clear user authorization.

Mitigation: Before use, check what content will be sent and which project it will affect, and require review and authorization for each remote action.
