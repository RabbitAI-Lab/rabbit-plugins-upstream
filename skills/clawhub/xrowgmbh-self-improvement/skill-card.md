## Use Case:

Developers can use this skill to turn useful agent improvement findings into separate self-assigned merge requests in a configured GitLab project and close their own stale merge requests.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may publish improvement findings and create or close merge requests in the configured GitLab project.

Mitigation: Before use, confirm the target project and review the merge request actions the skill may take; proceed only when those changes are intended.
