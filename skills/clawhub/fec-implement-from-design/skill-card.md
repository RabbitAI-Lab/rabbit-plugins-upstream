## Description:

Helps frontend developers implement accessible, maintainable UI from design-tool data, screenshots, and design tokens while reusing existing project components.

This skill is ready for commercial/non-commercial use.

## Publisher:

[bovinphang](https://clawhub.ai/user/bovinphang)

### License/Terms of Use:

MIT-0

## Use Case:

Frontend developers use this skill to turn design files or visual references into production UI, with an implementation plan, reusable components, design-token mapping, and accessibility checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Design-to-code edits may change existing frontend behavior or miss accessibility requirements.

Mitigation: Review code changes against the design and existing components, then run available lint and tests and check keyboard and focus behavior.

Risk: Screenshots or incomplete visual references may not specify interactions, responsive layouts, or exact design values.

Mitigation: Request clearer design details when needed and record unresolved assumptions in the design plan before implementation.
