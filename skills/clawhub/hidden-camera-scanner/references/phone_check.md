# 手机检查与取证引导步骤

本文件是 SKILL.md「阶段③ 手机检查与取证引导流程」的分支执行手册。
Agent 在阶段③ 先用引导提问确认用户需求，再按对应分支带步骤。

> 核心合规闸门：**先授权，后动手**。任何取证/他人设备操作前必须确认权限。
> 本技能**不提供**绕过锁屏、破解密码、未经授权提取数据、利用漏洞入侵的方法。

---

## 0. 授权闸门（所有取证类操作前的硬性检查）

| 设备归属 / 场景 | 是否可做 | 必要条件 |
|---|---|---|
| 本人设备 | ✅ | 本人操作即可 |
| 他人自愿授权委托 | ✅ | 书面授权 / 同意书 |
| 涉案设备（维权 / 诉讼） | ✅ | 公权力文书、法院调查令，或当事人自愿交出并签字确认 |
| 无权属、无授权的他人设备 | ❌ | 一律拒绝，并说明法律依据（侵犯通信秘密 / 个人信息保护） |

无合法权限时：明确告知用户不能执行，不提供任何越权手段，引导其走合法渠道（公证处、警方、法院）。

---

## A. 手机安全体检（分支：自查是否被监控 / 恶意软件 / 被跟踪）

适用：用户怀疑自己手机被装监控、被跟踪，或想做常规安全自查。**默认仅限本人设备**。

### A1. 系统级追踪器 / 被跟踪检测（零门槛，优先做）
- **iPhone / iOS**：打开「查找」App → 底部「我」→「协助朋友」下方或「未知物品」提示；iOS 14.5+ 会自动弹「检测到随行追踪器」。亦可装 Apple「Tracker Detect」。
- **Android**：装 **AirGuard**（可嗅探 Apple Find My / SmartTag / Tile 等）或用系统级「未知追踪器警报」（部分厂商原生支持）；Google「Tracker Detect」亦可。
- 发现陌生追踪器随行 → 按 App 指引播放声音定位，并核实是否本人/同行者物品。

### A2. 应用权限审查（自查被偷拍 / 窃听风险）
- **iPhone**：设置 → 隐私与安全性 → 逐项看「相机 / 麦克风 / 定位服务 / 照片」，留意不常用却长期获权的 App；设置 → 「屏幕使用时间」→「查看所有活动」可查后台行为。
- **Android**：设置 → 应用 → 权限管理，重点查「相机 / 麦克风 / 定位 / 后台弹出」异常的 App；设置 → 安全 → 「应用安装未知来源」是否开启。
- 发现可疑 App（名称陌生、后台常驻、频繁请求敏感权限）→ 卸载并改密码，必要时恢复出厂。

### A3. 红外 / 网络辅助（可选）
- 关灯后用手机摄像头扫房间（部分机型无红外滤镜，可直接看到摄像头红外补光点），见 `manual_checklist.md` 2.3。
- 同一 Wi-Fi 下可用 Fing 等 App 看联网设备，仅作参考。

### A4. 深度威胁检测（MVT，高门槛，可选）
> 仅当用户要求「查已知间谍软件痕迹」且愿自备备份时做。

1. 安装：`pip install mvt`（需 Python 3.9+，详见 MVT 官方文档）。
2. 采集**本人**手机备份：
   - iOS：`idevicebackup2` 或 iTunes/Finder 加密备份（加密含更多数据）；
   - Android：`adb backup` 或取取证镜像。
3. 运行 `mvt-ios` / `mvt-android` 对备份做 IOC 比对，人工研判命中项（区分真实入侵与误报）。
4. 局限：仅识别**已知间谍软件痕迹**，不能发现普通偷拍摄像头；需专业知识，非「连上自动出报告」。

### A5. 体检结论
- 汇总以上各项结果，给出「正常 / 需关注（列出具体项）/ 高风险（建议动作）」结论；
- 不臆造：只基于用户实测/系统反馈下结论。

## B. 取证证据固定（分支：从手机提取侵权 / 维权证据）

适用：用户要从手机里**固定证据**（如对方发布的侵权内容、聊天记录、交易凭证），用于留存或诉讼。**必须过 0. 授权闸门**。

### B1. 保全与隔离
- 立即**飞行模式 + 关机 / 放入法拉第袋**，阻断远程擦除、自动同步、撤回；
- 记录：设备型号、IMEI / 序列号、系统版本、屏幕状态、电量，拍照封存；
- 全程不操作原机数据（避免改动时间戳 / 触发同步）。

### B2. 选择获取方式
| 方式 | 适用 | 做法 | 门槛 |
|---|---|---|---|
| **轻量取证**（推荐起点） | 侵权内容在 App 内可见（朋友圈 / 电商 / 聊天） | 手机截屏 + 录屏（带时间水印）+ 系统「屏幕录制」；关键信息导出为文件 | 零门槛，普通用户可做 |
| **逻辑备份** | 需完整聊天记录 / 文件 | iOS iTunes/Finder 加密备份；Android `adb backup` 或厂商备份 | 需电脑 + 线缆 |
| **专业镜像** | 诉讼强采信 | Cellebrite / 天盘 / MOBILedit 或司法鉴定机构 | 需资质 / 费用 |

### B3. 哈希校验（证据指纹）
- 对导出文件 / 备份做哈希：`sha256sum 证据文件 > 证据.sha256`（macOS/Linux）或 `certutil -hashfile 证据文件 SHA256`（Windows）；
- 记录哈希值、生成时间、设备号，作为原始证据不可篡改凭证。

### B4. 解析与关联
- 时间线重建：按发布 / 发送时间排序；
- 关键词检索：侵权商标、商品名、账号、金额；
- 与维权事实关联：谁发布、何时、内容、链接，形成证据链。

### B5. 出证与封存
- 形成报告：证据清单 + 哈希值 + 操作日志 + 来源说明；
- **公证**：轻量取证建议走公证处 / 区块链存证（如的权利卫士、公证云）以增强诉讼采信；
- 保管链（chain of custody）：记录每个经手人、时间、操作，确保证据连续可追溯；
- 原始设备封存，副本用于分析。

### B6. 取证局限（如实告知）
- 锁屏 / 加密且无权解锁的内容，本流程**不提供破解手段**；
- 已撤回 / 已删除且未备份的内容，普通手段无法恢复；
- 云端数据需向平台 / 法院调取，不在本机取证范围内。

## 跨平台说明（手机端）

| 手机系统 | 安全体检（A） | 取证（B） |
|---|---|---|
| iPhone / iOS | ✅ 查找 App + 权限审查 + AirGuard/Tracker Detect | ✅ 轻量取证（截屏/录屏）+ 公证；逻辑备份需电脑 |
| Android | ✅ AirGuard + 权限审查 + 系统追踪器警报 | ✅ 同上；`adb backup` 逻辑备份更通用 |
| 无终端环境 | 仅系统级 App 自检 | 仅轻量取证 + 公证，重负载交专业机构 |

> 本阶段不依赖 `wifi_scan.py` / `bt_scan.py` 等局域网脚本；它独立于房间反偷拍主线，作为用户主动选择的分支运行。
