# 人工排查、手机取证与授权自检清单

## 1. 授权与安全自检（每次扫描前必做）

- [ ] 确认当前网络是你本人已连接、有权限扫描的网络（如自住酒店房间 Wi-Fi）。
- [ ] 已告知用户 nmap/arp-scan 会发送主动探测包，并获得确认。
- [ ] 不登录任何其他设备、不利用漏洞、不访问摄像头视频流。
- [ ] 扫描结果仅用于用户本人安防，不外传他人设备信息。

## 2. 手电人工排查清单（阶段④）

适用：客户端隔离导致无法扫其他设备，或作为扫描补充。由用户实地执行。

### 2.1 镜面反射测试（查单向镜 / 隐藏镜头）
- 关灯、拉窗帘，使房间全黑；
- 用手电（手机闪光灯）贴近疑似镜面/玻璃斜照；
- 若镜面后出现一个**红点/蓝点**（镜头镀膜反光），可能为隐藏摄像头；
- 手指抵住镜面：真实镜子手指与镜像无间隙，单向镜有空隙（间隙大则后方可能藏空间）。

### 2.2 重点位置逐一检查
- [ ] 烟雾探测器 / 吊顶圆灯（正对床/淋浴区的高处最可疑）
- [ ] 通风口 / 空调出风口
- [ ] 电源插座、USB 充电头、排插（含「带充的装饰物」）
- [ ] 朝向床铺 / 淋浴区的装饰画、钟、玩偶、路由器
- [ ] 热水器、纸巾盒、花盆、衣物挂钩等非常规位置
- [ ] 电视/机顶盒指示灯旁的小孔

### 2.3 手机辅助
- [ ] 关灯后用手机摄像头（部分机型有红外滤镜，可直接看到摄像头红外补光点）扫一圈；
- [ ] 部分 App 可探测同一 Wi-Fi 下摄像头，但准确度有限，仅作参考。

## 3. 手机取证检查（阶段③，MVT）

> 高门槛、需授权与专业操作；本 skill 不内置 MVT，仅给流程与注意。

**MVT (Mobile Verification Toolkit，国际特赦组织)** 用于分析手机备份，查找已知间谍软件（如 Pegasus）入侵痕迹。

步骤概要：
1. 安装：`pip install mvt`（需 Python 3.9+，详见 MVT 官方文档）。
2. 采集备份：
   - iOS：`idevicebackup2` 或 iTunes/Finder 备份（建议加密备份以含更多数据）；
   - Android：`adb backup` 或取取证镜像。
3. 运行对应模块：`mvt-ios` / `mvt-android`，对备份做指标（IOC）比对。
4. 人工研判命中的 IOC，区分真实入侵与误报。

**注意事项**：
- MVT 需要相应数据采集与专业知识，**并非连上手机就自动出全面报告**；
- 分析他人手机前必须获得明确授权；
- 仅识别「已知间谍软件痕迹」，不能发现普通偷拍摄像头。

## 4. 扫描局限（必须如实告知用户）

1. **仅局域网可见**：使用独立蜂窝网络、连接其他 Wi-Fi、或只录本地存储卡（不联网）的摄像头，局域网/蓝牙扫描**发现不了**。
2. **厂商≠偷拍**：即便扫到海康威视等设备，也可能是房东合法安防，不能据此认定偷拍，也无法定位物理位置。
3. **蓝牙启发式**：追踪器地址会轮换，识别靠广播签名 + 多轮关联，存在误报/漏报。
4. **覆盖不全**：酒店智能门锁过时固件、手机恶意采集程序等，需专门工具（如 MVT），不在基础扫描能力内。

## 5. 发现可疑后的建议动作

- 不要擅自拆解/破坏设备（可能影响取证且违法）；
- 先拍照记录位置、MAC、端口等证据；
- 向场所管理方反映；
- 涉及人身安全或确认被跟踪，保留证据并联系警方。
