# DELAY() 交期异常

**Skill ID:** `zayn-delay`
- 所属分类：订单与交付
- 一句话用途：订单或项目出现延期风险时，判断通知时机、可说明事实、内部边界和替代方案
- 当前版本：`v0.1`
- 当前状态：Draft for testing
- 规则是否完成：是，初版规则已建立
- 是否已有测试案例：否，等待真实脱敏案例
- 下一步待办：测试参数解析、最低运行条件、判断规则、风险和输出结构

DELAY() 用于在订单或项目出现延期风险时，判断何时通知客户、哪些事实可以说明、哪些内部原因不应暴露，以及可以提供哪些替代方案。它不负责重新制定完整交付计划，也不默认向客户承诺新的确定日期。

完整规则见 [SKILL.md](SKILL.md)，调用模板见 [examples.md](examples.md)，测试要求见 [tests.md](tests.md)。
