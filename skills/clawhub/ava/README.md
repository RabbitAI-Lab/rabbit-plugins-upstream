# ava

Install the ClawHub skill:

```bash
openclaw skills install @kamalbuilds/ava
```

ClawHub also documents:

```bash
npx skills add @kamalbuilds/ava
```

After install, run `ava_session` and connect HTTP MCP `https://www.getava.xyz/mcp` with `Authorization: Bearer <token>`.

Env: `AVA_API_BASE=https://api.getava.xyz` and `AVA_PORTAL=base`.
