# 接口测试与回归工作台

[English](README.md)

按测试清单请求接口，核对状态码、JSON 字段和响应耗时，生成可重复执行的回归报告。

## 功能

按测试清单请求接口，核对状态码、JSON 字段和响应耗时，生成可重复执行的回归报告。

在当前助手的工作区运行，输出处理结果和报告，原文件保留。

## 用法示例

安装后，把任意一条发给 AI，并附上相关文件或网址。

```text
测试这三个公开接口，检查是否返回200以及JSON中的success字段。
```

```text
用我配置在环境变量里的令牌测试接口，报告里不要保存密钥或响应正文。
```

```text
把这次接口测试结果和上次报告比较，列出新出现的失败和耗时变化。
```
