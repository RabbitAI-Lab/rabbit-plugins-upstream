# 优度评价实战指南

> 优度评价（Superiority Evaluation）是可拓创新方法区别于传统TRIZ的核心能力，也是本技能最独特的价值所在。本指南提供优度评价的完整操作流程和实战技巧。

## 一、优度评价的四大步骤

### 步骤1：建立评价指标体系

#### 1.1 指标选取原则

| 原则 | 说明 | 违反后果 |
|------|------|---------|
| **可测量性** | 每个指标应能用数据或标准评分 | 无法得出客观评价结果 |
| **全面性** | 覆盖方案评价的主要维度 | 遗漏重要维度，评价偏颇 |
| **非冗余性** | 指标间尽量独立，避免重复评价 | 重复计算导致权重失衡 |
| **适度性** | 指标数量5-8个为佳 | 太多→评价复杂，太少→维度不足 |

#### 1.2 常用评价指标体系模板

**工程技术类**：
| 指标 | 建议权重 | 评价依据 |
|------|:--------:|---------|
| 技术可行性 | 0.20-0.30 | 技术成熟度（TRL等级）、关键工艺可实现性 |
| 经济性 | 0.15-0.25 | 成本变化幅度、投资回报周期 |
| 可靠性 | 0.10-0.20 | 预期寿命、故障率、维护频次 |
| 安全性 | 0.10-0.15 | 风险等级、安全冗余设计 |
| 环保性 | 0.05-0.10 | 排放水平、材料可回收性 |
| 可制造性 | 0.05-0.10 | 工艺复杂度、生产周期 |

**产品创新类**：
| 指标 | 建议权重 | 评价依据 |
|------|:--------:|---------|
| 用户价值 | 0.20-0.30 | 解决用户痛点的程度、用户体验提升 |
| 创新性 | 0.15-0.20 | 与现有方案的差异化程度 |
| 可实施性 | 0.15-0.20 | 开发周期、技术储备、团队能力 |
| 市场潜力 | 0.10-0.15 | 目标市场规模、增长趋势 |
| 成本效益 | 0.10-0.15 | 开发成本、制造成本、预期收益 |
| 品牌一致性 | 0.05-0.10 | 是否符合品牌定位和形象 |

**专利申请类**：
| 指标 | 建议权重 | 评价依据 |
|------|:--------:|---------|
| 创造性 | 0.20-0.30 | 非显而易见性、技术突破程度 |
| 实用性 | 0.15-0.25 | 产业应用前景、商业化价值 |
| 可专利性 | 0.15-0.20 | 与现有专利的差异度、侵权风险 |
| 技术覆盖 | 0.10-0.15 | 保护范围宽度、规避难度 |
| 经济价值 | 0.10-0.15 | 许可收益预期、市场竞争优势 |

### 步骤2：确定权重

#### 2.1 层次分析法（AHP）简化版

**操作步骤**：
1. 将指标两两比较，判断相对重要性
2. 使用1-9标度法打分：

| 标度 | 含义 |
|:----:|------|
| 1 | 同样重要 |
| 3 | 稍微重要 |
| 5 | 明显重要 |
| 7 | 强烈重要 |
| 9 | 极端重要 |
| 2,4,6,8 | 相邻判断的中间值 |

3. 构建判断矩阵，计算权重向量
4. 一致性检验（CR < 0.1为可接受）

#### 2.2 直接赋值法（简化版）

当指标数量≤8且用户对指标重要性有明确判断时，使用直接赋值法：

1. 用户对每个指标按重要性打分（1-10分）
2. 归一化得到权重：wᵢ = scoreᵢ / Σ(score)

**示例**：
```
技术可行性：9分
经济性：8分
创新性：6分
可靠性：7分
可实施性：5分

归一化计算：
总分 = 9+8+6+7+5 = 35
权重 = [9/35, 8/35, 6/35, 7/35, 5/35] = [0.26, 0.23, 0.17, 0.20, 0.14]
```

### 步骤3：计算关联度

#### 3.1 定性指标的关联度计算

对于无法精确量化的指标，使用等级评分法：

| 等级 | 评分 | 含义 |
|:----:|:----:|------|
| 优 | 5 | 完全符合，效果显著 |
| 良 | 4 | 符合较好，效果良好 |
| 中 | 3 | 基本符合，效果一般 |
| 差 | 2 | 部分符合，效果有限 |
| 较差 | 1 | 勉强符合，效果微弱 |
| 不合格 | 0 | 不符合，无效果 |

#### 3.2 定量指标的关联度计算

对于有明确数据的指标，使用区间关联函数：

**正向指标**（越大越好）：
```
K(x) = (x - x_min) / (x_max - x_min) × 5
```

**负向指标**（越小越好）：
```
K(x) = (x_max - x) / (x_max - x_min) × 5
```

**区间指标**（在某个范围内最优）：
```
K(x) = 5 - |x - x_opt| / Δ × 5
```
其中 x_opt 为最优值，Δ 为可接受偏差范围

### 步骤4：计算综合优度

#### 4.1 加权求和法

```
C(j) = Σ wᵢ × Kᵢ(j)   （对所有i求和）
```

其中：
- C(j)：方案j的综合优度
- wᵢ：第i个指标的权重（Σwᵢ = 1）
- Kᵢ(j)：方案j在第i个指标上的关联度

#### 4.2 综合评价标准

| 综合优度范围 | 等级 | 含义 |
|:-----------:|:----:|------|
| 4.0-5.0 | 优秀 | 强烈推荐，方案整体表现优秀 |
| 3.0-3.9 | 良好 | 推荐，方案有一定优势 |
| 2.0-2.9 | 一般 | 可考虑，需要进一步优化 |
| 1.0-1.9 | 较差 | 不推荐，存在明显缺陷 |
| 0-0.9 | 不合格 | 淘汰，不可行 |

## 二、实战技巧

### 2.1 指标选取技巧

**避免指标重叠**：
- ❌ "成本"和"经济性"同时出现（重叠）
- ✅ "制造成本"和"维护成本"分别评价（不重叠）

**避免指标过多**：
- ❌ 列出15个指标，评价复杂且权重分散
- ✅ 精选6个核心指标，每个都有明确意义

**指标可操作化**：
- ❌ "用户体验好"（太模糊）
- ✅ "操作步骤数≤3"（可测量）

### 2.2 权重分配技巧

**核心原则**：
- 技术类问题：技术可行性权重最高（0.25-0.30）
- 商业类问题：经济性权重最高（0.25-0.30）
- 创新类问题：创新性权重最高（0.20-0.25）

**与用户沟通权重的技巧**：
1. 提供参考权重方案
2. 询问用户最关心的1-2个维度
3. 根据用户反馈调整权重
4. 确认用户认可权重分配后再进入评价

### 2.3 评分技巧

**减少主观偏差**：
- 对每个方案在同一个指标上依次评分（避免"光环效应"）
- 先打分再写理由（避免"先入为主"）
- 如果两个方案在某个指标上得分相同，检查是否真的没有差异

**处理不确定性**：
- 如果信息不足，使用评分区间（如"3-4分"）
- 标注不确定性来源，供用户决策参考
- 建议用户补充信息后可重新评价

### 2.4 结果解读技巧

**方案排名解读**：
- 综合优度差异>0.5：方案间有明显优劣之分
- 综合优度差异0.2-0.5：有差异但非决定性的
- 综合优度差异<0.2：方案间差异很小，可结合其他因素决策

**敏感性分析**：
- 对权重进行微调（±0.05），观察排名变化
- 如果排名对权重敏感，说明方案间优劣势互补
- 建议用户根据自己的实际情况选择权重
