# IASE四阶段工作流速查表

> 快速参考指南，帮助用户在应用可拓创新方法时快速定位当前阶段和所需工具。

## 一、IASE全景概览

```
┌─────────────────────────────────────────────────────────────────┐
│                    IASE 创新闭环                                 │
│                                                                 │
│  识别(Identify) ──→ 分析(Analyze) ──→ 求解(Solve) ──→ 评价(Evaluate) │
│     ↓                    ↓                  ↓                  ↓       │
│   问题建模             拓展分析           方案生成           优度评价    │
│   矛盾识别             矛盾分析           可拓变换           方案优选    │
│   物场建模             功能分析           TRIZ工具           敏感分析    │
└─────────────────────────────────────────────────────────────────┘
```

## 二、各阶段速查

### 阶段一：识别（Identify）

| 步骤 | 做什么 | 用什么工具 | 输出 |
|------|-------|-----------|------|
| 1.1 问题收集 | 引导用户明确问题背景 | 5W1H提问法 | 问题描述文本 |
| 1.2 物元建模 | 将系统组件形式化描述 | 物元 R=(N,c,v) | 物元模型 |
| 1.3 矛盾识别 | 判断是技术矛盾还是物理矛盾 | TRIZ 39个工程参数 | 矛盾类型+参数 |
| 1.4 物场建模 | 构建物质-场-作用模型 | 物场分析符号 | 物场模型图 |

**关键提问模板**：
- 你想改善什么？（→ 改善参数）
- 改善后什么变差了？（→ 恶化参数）
- 系统中有什么物质？它们之间有什么场的作用？
- 当前系统的核心功能是什么？什么功能不足或有缺陷？

### 阶段二：分析（Analyze）

| 步骤 | 做什么 | 用什么工具 | 输出 |
|------|-------|-----------|------|
| 2.1 发散树 | 从基元发散出多个相关基元 | 发散树 | 可能性空间 |
| 2.2 相关网 | 分析基元间的相关性 | 相关网 | 影响关系图 |
| 2.3 蕴含系 | 分析基元间的蕴含关系 | 蕴含系 | 因果链/条件链 |
| 2.4 分合链 | 分解或组合基元 | 分合链 | 模块分解图 |
| 2.5 矛盾分析 | 查矛盾矩阵找发明原理 | 矛盾矩阵 | 推荐原理编号 |
| 2.6 物场分析 | 匹配标准解 | 76个标准解 | 推荐标准解 |
| 2.7 功能分析 | 识别功能类型和优先级 | 功能分析框架 | 功能优先级表 |

**拓展分析四问**：
1. 还有哪些替代方案？（发散树）
2. 改变这个会影响什么？（相关网）
3. 要实现这个目标，需要什么条件？（蕴含系-反向）
4. 系统可以拆分为哪些部分？（分合链）

### 阶段三：求解（Solve）

| 步骤 | 做什么 | 用什么工具 | 输出 |
|------|-------|-----------|------|
| 3.1 可拓变换 | 对基元应用五种基本变换 | 置换/扩缩/分解/组合/复制 | 方案变体 |
| 3.2 发明原理应用 | 将发明原理具体化 | 40个发明原理 | TRIZ方案 |
| 3.3 标准解应用 | 匹配物场标准解 | 76个标准解 | 物场优化方案 |
| 3.4 方案整合 | 将方案整合为完整描述 | 方案描述模板 | 完整方案 |

**方案生成策略**：
- 每个变换类型至少生成2个方案
- 优先组合可拓变换+TRIZ工具
- 方案描述包含：核心思想、技术指标、优缺点

### 阶段四：评价（Evaluate）

| 步骤 | 做什么 | 用什么工具 | 输出 |
|------|-------|-----------|------|
| 4.1 建立指标体系 | 选取5-8个评价指标 | 评价维度模板 | 指标体系 |
| 4.2 确定权重 | AHP或直接赋值法 | 权重分配方法 | 权重向量 |
| 4.3 计算关联度 | 给每个方案打分 | 关联度评分标准 | 评分表 |
| 4.4 计算综合优度 | 加权求和 | 优度计算公式 | 综合优度 |
| 4.5 排序推荐 | 排名+推荐+优化建议 | 排序模板 | 评价报告 |

**核心区别**：这是本技能区别于传统TRIZ的最重要能力——**传统TRIZ只到方案生成，而可拓创新方法还能对方案进行量化评价和优选**。

## 三、工具选择决策树

```
问题来了
  │
  ▼
问题属于什么类型？
  │
  ├─ 工程技术问题 ──→ 优先使用：物场分析 + 矛盾矩阵 + 可拓变换
  │
  ├─ 产品开发问题 ──→ 优先使用：功能分析 + 拓展分析 + 优度评价
  │
  ├─ 专利申请问题 ──→ 优先使用：发散树 + 置换变换 + 组合变换
  │
  ├─ 方案评价问题 ──→ 优先使用：优度评价（核心能力）
  │
  └─ 综合创新问题 ──→ 完整IASE四阶段流程
```

## 四、常用工具组合推荐

| 场景 | 推荐工具组合 | 理由 |
|------|------------|------|
| 快速突破瓶颈 | 矛盾矩阵+发明原理+可拓变换 | 快速找到创新方向 |
| 深度系统优化 | 功能分析+物场分析+拓展分析 | 全面理解系统问题 |
| 专利规避设计 | 发散树+置换变换+组合变换 | 绕开现有专利保护 |
| 多方案决策 | 优度评价+敏感性分析 | 量化比较，科学决策 |
| 新产品概念设计 | 可拓建模+拓展分析+优度评价 | 从概念到优选的全流程 |

## 五、常见问题与应对

| 问题 | 原因 | 应对策略 |
|------|------|---------|
| 方案太少 | 拓展分析不够充分 | 回到发散树，扩大发散范围 |
| 方案太相似 | 变换类型单一 | 尝试不同的变换类型组合 |
| 评价结果不理想 | 指标体系不完善 | 重新审视指标选取和权重分配 |
| 用户不满意方案 | 需求理解偏差 | 回到识别阶段，重新确认问题 |
| 技术不可行 | 没有考虑现实约束 | 加入"技术可行性"作为评价指标 |
