## Use Case:

Shopify merchants use this skill to learn about Agiexa's planned Smile.io integration and its loyalty capabilities. Interested users can submit confirmed waitlist details after explicitly agreeing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Waitlist submission shares the user's email, role, and any optional URL or message with Agiexa.

Mitigation: Get explicit permission, confirm each submitted field with the user, and omit optional fields they have not provided.

Risk: The described Smile.io operations are preview capabilities that cannot be called today, and the package alone does not verify the provider's security claims.

Mitigation: Explain the November 2026 launch timing, do not present these operations as currently available, and review permissions separately before connecting future integrations.
