# Smile.io tools via Agiexa (6)

Preview only - these become available to the agent after Agiexa launches (November 2026) and the merchant connects Smile.io and turns the tools on. They cannot be called today.

Interactive explorer: https://agiexa.com/integrations/smile-io

| Tool | What it does |
| --- | --- |
| `SMILE_FIND_CUSTOMER` | Find a Smile loyalty customer by email: points balance, membership state, VIP tier progress and referral link |
| `SMILE_POINTS_HISTORY` | List a customer's points transactions (earned, spent, manual adjustments), optionally since a date |
| `SMILE_ADJUST_POINTS` | Add (positive) or deduct (negative) points for a customer as a manual adjustment, e.g |
| `SMILE_LIST_ISSUED_REWARDS` | List rewards issued to a customer (e.g |
| `SMILE_LIST_REWARDS` | List the rewards customers can buy with points (points price, fixed or variable exchange) |
| `SMILE_GET_PROGRAM` | Get the loyalty program's VIP tiers (with milestones and perks) and ways to earn points |
