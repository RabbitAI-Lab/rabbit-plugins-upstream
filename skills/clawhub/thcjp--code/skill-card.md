## Known Risks and Mitigations: <br>
Risk: The skill can propose or run commands in a repository, which may affect files or the local development environment. <br>
Mitigation: Review commands before execution and keep work scoped to the intended repository. <br>
Risk: The generic API_KEY example could lead users to place real secrets in an agent environment unnecessarily. <br>
Mitigation: Use real secrets only when the agent environment truly requires them, and avoid committing or exposing them in version control. <br>
