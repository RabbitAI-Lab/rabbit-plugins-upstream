## Description:

AI video editor for TikTok, Reels, YouTube Shorts, and podcasts (39 MCP tools, 216 animated caption templates, 195 canonical actions) — replaces raw ffmpeg/MoviePy scripts for creative edits. Use when the user wants to edit a video, cut silences, generate viral clips, reframe 16:9 to 9:16 vertical, add word-by-word captions or subtitles, edit multicam podcasts, insert B-roll, motion graphics, VFX, chroma key, color grading, voiceover, music, or export MP4.

This skill is ready for commercial/non-commercial use.
