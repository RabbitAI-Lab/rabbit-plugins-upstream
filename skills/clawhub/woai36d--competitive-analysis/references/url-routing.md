# 多平台URL路由速查

基于实际分析经验，记录各平台已知URL路由模式。

---

## 美团商家中心

| 模块 | URL模式 | 备注 |
|------|--------|------|
| 运营中心 | `https://pos.meituan.com/web/operation/{模块}#/` | 15个模块 |
| 营销中心 | `https://pos.meituan.com/web/marketing/{模块}#/` | ⚠️路由冲突需菜单点击 |
| 供应链 | `https://pos.meituan.com/web/supply/{模块}#/` | 11个模块 |
| 报表中心 | `https://pos.meituan.com/web/report/{模块}#/` | 14个模块 |

**⚠️ 已知问题**：营销中心部分路由和运营中心冲突，必须通过菜单点击导航

## 企迈

| 系统 | 域名 | 备注 |
|------|------|------|
| 主站 | `https://console.qmai.co/` | 品牌视角入口 |
| 子站 | `https://console.qmai.cn/` | 会员、优惠券、营销等9个模块 |
| 门店视角 | `https://store.qmai.cn/` | 门店级运营 |

**⚠️ 已知问题**：
- 两站账号通用，但需分别访问
- 门店视角页面加载异常时，切换品牌视角访问

## URL验证状态标注

| 状态 | 含义 |
|------|------|
| ✅ 已验证 | 实际访问确认有效 |
| ⚠️ 推断 | 根据URL模式推测，需验证 |
| ❌ 无法访问 | URL返回404或无权限 |
