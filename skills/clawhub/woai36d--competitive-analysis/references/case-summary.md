# 竞品分析 - 实战案例总结

## 项目信息
- 竞品：企迈科技（餐饮SaaS）
- 分析时间：2026年4月28日
- 最终产出：总报告50KB + 7份模块文档144KB + 377张截图 + 57条URL路由

## 关键经验

### 1. 入口探索是最关键的步骤
企迈的"业务运营"下拉菜单藏着CRM、MA、财务等核心模块，但这个入口不在左侧菜单，而是在顶部品牌名切换品牌视角后才出现。

**教训**：登录后不要急于分析，先花10分钟彻底探索所有入口，包括：
- 左侧菜单完整展开
- 顶部导航栏
- 品牌名/门店名点击后的下拉菜单
- 首页仪表盘中的快捷入口

### 2. 双视角必须分别扫描
同一账号在品牌视角和门店视角下可见模块差异极大：
- 品牌视角：品牌管理、业务运营（鸿图/财务/供应链）、管理员权限
- 门店视角：日常运营（订单/收银/门店管理/报表）

**教训**：菜单扫描阶段就要逐视角完成，不要假设"品牌视角覆盖了门店视角"。

### 3. SPA页面URL直接导航比菜单点击稳定10倍
企迈是SPA应用，菜单点击经常出现：
- 点击后URL不变
- 内容不切换
- 页面空白

**教训**：R1扫描阶段就要记录所有URL，R2及以后优先用URL导航。

### 4. 子任务拆分粒度决定成功率
全模块大任务几乎必然超时。最佳粒度：
- ✅ 每个子任务处理1-2个模块
- ✅ 鸿图6子模块拆成3个子任务（2模块/任务）
- ❌ 一次性处理所有模块

### 5. "只看不改"原则下的数据获取边界
可以获取的数据：
- ✅ 列表页所有字段
- ✅ 详情页所有字段
- ✅ 新建/编辑表单的字段和校验规则（不点保存）
- ✅ "下一步"按钮查看多步骤表单

无法获取的数据：
- ❌ 提交后的结果页面
- ❌ 需要真实数据才能展示的统计/图表
- ❌ 审批流程的后续步骤

### 6. 门店视角加载异常的解决方案
门店视角(store.qmai.cn)多次出现页面加载异常，解决方式：
- 切换到品牌视角(console.qmai.cn)
- 从品牌视角的"品牌管理→门店管理"入口访问门店相关功能
- 用品牌视角绕过门店视角的加载问题

### 7. Cookie管理的重要性
- 登录状态保存后复用可大幅提升效率
- 美团需手机验证码，每次重新登录都需要用户协助
- 建议先检查Cookie有效性，再决定是否需要重新登录

## 常见URL路径模式

### 企迈URL命名规律

| 前缀 | 含义 | 示例 |
|------|------|------|
| /orgCenter/ | 组织管理（品牌级） | /orgCenter/storeNew/list |
| /commonCenter/ | 通用功能（门店级） | /commonCenter/stalls/index |
| /cateringCenter/ | 餐饮核心业务 | /cateringCenter/orders/orderList |
| /biCenter/ | 数据报表 | /biCenter/dataInfo/businessReport |
| /costCenter/ | 费用管理 | /costCenter/productList |
| /connectorCenter/ | 连接器/事件 | /connectorCenter/eventCenter/index |
| /paymentCenter/ | 支付管理 | /paymentCenter/accountManage/ |
| /finance/ | 财务 | /finance/fund/fundDetail |
| /crm/ | CRM | /crm/member/memberList |

### 美团商家中心URL模式

| 模块 | URL前缀 |
|------|--------|
| 运营中心 | /web/operation/ |
| 营销中心 | /web/marketing/ |
| 供应链 | /web/supply/ |
| 报表中心 | /web/report/ |

**注意**：营销中心和运营中心部分路由冲突，需通过菜单点击导航。

## 截图质量控制

### 高质量截图标准
- 文件大小 > 10KB
- 尺寸：宽≥800px，高≥600px
- 内容：非纯色/非空白
- 命名：`{模块}_{页面描述}.png`

### 问题截图分类
| 问题类型 | 特征 | 优先级 | 处理方式 |
|---------|------|--------|---------|
| 完全空白 | 纯色或无内容 | P0 | 必须重扫 |
| 加载失败 | 404/500错误 | P0 | 必须重扫 |
| 内容极少 | 仅标题无内容 | P1 | 建议重扫 |
| debug状态 | 包含调试信息 | P2 | 可选重扫 |
