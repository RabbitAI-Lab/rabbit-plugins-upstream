## Description:

Change, fix, re-roll or version visuals that Canvora already produced — targeted edits, variations, localization, edit history and revert — without paying to regenerate. Use when the user wants to tweak, fix, restyle, translate or undo an existing visual.

This skill is ready for commercial/non-commercial use.

## Publisher:

[canvora](https://clawhub.ai/user/canvora)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to refine visuals already generated with Canvora, including targeted edits, localization, variations, and version recovery. It guides the agent toward an appropriate operation while making credit costs and scope clear.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Edits and variations may consume credits; localization and variations affect the whole selected generation, and undo may not refund credits.

Mitigation: Set a spending limit, verify target IDs, state costs before credit-consuming operations, confirm the chosen variation count, and check the operation scope before localizing or creating variations.
