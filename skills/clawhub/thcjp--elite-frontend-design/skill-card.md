## Known Risks and Mitigations:

Risk: The skill requests broad command and file authority for a frontend code generator.

Mitigation: Use it only in a contained workspace, review generated changes before applying them, and require explicit approval for command execution.

Risk: The skill may use external APIs or environment credentials during frontend generation workflows.

Mitigation: Expose only the credentials needed for the current task and avoid running it in workspaces that contain unrelated secrets.
