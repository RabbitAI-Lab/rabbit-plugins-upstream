# 软考高级·系统规划与管理师论文辅助（ruankao-spgm-essay-helper）

> ⚠️ **重要声明**：本技能生成的论文框架与提示**仅供参考**，不构成标准答案，亦不替代考生本人的写作与备考；论文须基于考生自身真实项目经验撰写，所有项目信息必须来自本人真实输入，严禁虚构冒用任何第三方资料。

辅助备考软考高级资格「系统规划与管理师」的考生，根据输入的论文题目与个人项目背景，**生成符合官方评分标准的论文框架与写作提示**。

**核心差异化：挂接 IMA 知识库（主库）**——主库提供历年真题 / 参考范文 / 考试大纲 / 教程术语，让框架切题、专业、贴近考情；论文项目背景仅来自考生本人真实参与的项目，技能不引用任何第三方真实项目资料。

## 核心能力

| 能力 | 说明 |
|------|------|
| 题目拆解 | 从题目提取论述维度（规划 / 实施 / 效果等），锚定分论点 |
| 框架生成 | 四段式结构（摘要 + 项目概述 + 正文核心 + 结尾）配字数分配 |
| 写作提示 | 每章节给出写作方向、专业术语、避坑提示 |
| 评分自检 | 对照 5 维度评分标准逐条核查框架完整性 |
| IMA 知识库挂接 | 主库真题 / 范文 / 大纲 / 教程，底稿更真实 |

## 适用科目

- 系统规划与管理师（高级）——IT 服务规划、运营、持续改进、营销、团队、风险、质量、运维等方向

## 使用方法

1. 触发：提及「系统规划与管理师论文 / 系规论文 / 软考高级论文 / 系规论文框架」等。
2. 提供：论文题目原文 + 个人项目背景（系统规划与管理师以 IT 服务 / 运维类项目为背景）。
3. 获取：结构化论文框架 Markdown，含写作提示与术语建议。
4. （可选）授权后调用 IMA 知识库，匹配历年真题范式、提供优秀范文结构参考。

## IMA 知识库挂接

- **主库（唯一外部知识源·写法库）**：`软考系统规划与管理师备考资料`（237 项，索引正常）——论文模板 / 框架 / 历年真题 / 参考范文 / 考试大纲 / 教程第 2 版 / 三色笔记。"真实 IT 项目长什么样"由主库范文与本仓库 `references/project_bg_template.md` 的匿名化示例承担。
- 详细 KB ID、关键文件 media_id 与检索模式见 `references/ima_kb_guide.md`。

## 安全护栏

- **严禁编造**：所有项目信息必须基于用户真实提供的内容；信息不足时以占位符提示补充，不臆造。
- **不代写论文**：输出框架与提示，引导用户结合自身经验完成正文，避免雷同与诚信风险。
- **不引用第三方项目资料**：论文项目背景须来自考生本人真实参与的项目，技能不检索、不引用任何第三方真实项目资料（含招标文件、真实项目库）。
