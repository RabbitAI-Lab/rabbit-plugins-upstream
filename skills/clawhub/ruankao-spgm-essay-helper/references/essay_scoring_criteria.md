# 系统规划与管理师论文评分标准

> 依据软考高级论文通用评分维度整理，适用于系统规划与管理师。生成框架后请对照本表逐项自检。

## 评分维度与分值分布（百分制内部写作自评量表；软考官方论文满分 75 分、及格 45 分，以下五维用于自检切题/实践/深度/逻辑/表达是否均衡，实际计分以当年官方为准）

| 评分维度 | 分值 | 核心评判要点 |
|---------|------|-------------|
| 切题性 | 25 分 | 是否准确理解题意，回应题目中所有关键词 |
| 实践性 | 25 分 | 是否结合真实 IT 服务 / 运维项目经验，而非泛泛而谈 |
| 深度与广度 | 20 分 | 理论联系实际的深度，内容覆盖的完整性 |
| 逻辑性 | 15 分 | 结构层次清晰，过渡自然，论述有据可循 |
| 书面表达 | 15 分 | 专业术语准确，语句通顺，无明显语病 |

## 各维度优秀标准与常见失分点

### 1. 切题性（25 分）
- **优秀**：标题准确反映主题；每个分论点紧扣题目关键词；结尾回扣主题。
- **失分**：题目要求写「服务规划与设计」却大篇幅写项目管理；分论点与关键词无关；结尾不回扣。

### 2. 实践性（25 分）
- **优秀**：项目背景完整（名称、规模、周期、角色）；有真实案例与具体数据；解决方案有细节。
- **失分**：项目信息模糊（"我参与了一个项目"）；只有理论无实践；方案笼统。

### 3. 深度与广度（20 分）
- **优秀**：不仅描述做了什么，更说明为什么这样做；体现专业方法（ITIL 4 / GB/T 24405 / 运维体系）；含问题分析与应对。
- **失分**：浅尝辄止；未引用专业理论；缺问题分析过程。

### 4. 逻辑性（15 分）
- **优秀**：符合四段式框架；分论点间有逻辑关联；段落过渡自然。
- **失分**：结构混乱；分论点无逻辑关系；段落缺过渡。

### 5. 书面表达（15 分）
- **优秀**：术语准确；语句通顺；格式规范。
- **失分**：术语使用错误；语句不通；标点混乱。

## 论文不通过的红线

1. **项目虚假**：明显编造项目经验（金额夸大、周期不合理、角色与规模不匹配）。
2. **严重偏题**：内容与题目要求完全无关。
3. **字数不足**：正文（项目概述 + 正文核心）少于 1500 字。
4. **抄袭痕迹**：与网上范文高度雷同。
5. **结构残缺**：缺摘要、项目概述或正文核心部分。
6. **立场错误**：论点与主流专业观点相悖。

## 系统规划与管理师常见论文主题（供分论点锚定）

- 论 IT 服务规划与设计
- 论 IT 服务运营管理
- 论 IT 服务持续改进
- 论 IT 服务风险管理
- 论 IT 服务质量管理
- 论 IT 服务营销
- 论服务团队建设与管理
- 论信息系统运维管理

## 快速自检清单（生成框架后逐项核对）

- [ ] 论文标题是否包含题目核心关键词
- [ ] 摘要是否概括全文核心内容（约 300 字）
- [ ] 项目背景是否完整（名称 / 规模 / 周期 / 角色 / 目标）
- [ ] 每个分论点是否紧扣题目要求的一个方面
- [ ] 是否引用了专业理论或方法论（ITIL 4、运维体系等）
- [ ] 是否有具体问题分析与解决方案
- [ ] 章节之间是否有逻辑衔接
- [ ] 正文（项目概述 + 核心论述）是否 ≥ 1500 字
- [ ] 是否使用了系统规划与管理师专业术语
- [ ] 结尾是否回扣主题
