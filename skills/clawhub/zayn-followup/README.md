# FOLLOWUP() 客户跟进

**Skill ID:** `zayn-followup`  
**Display Name:** FOLLOWUP()  
**中文名称：** 客户跟进

- 所属项目：WorkFn
- 当前版本：`0.2.0`
- 当前状态：Draft for testing

## 一句话用途

判断客户是否应该继续跟进、何时跟进、跟进目标是什么，以及应提醒、补充价值、重新确认需求还是暂停投入。

## 适用场景

1. 已发生过客户沟通
2. 当前存在未回复或待推进事项
3. 需要判断跟进理由、时间和目标
4. 需要决定继续投入或暂停

## 不适用场景

1. 客户意图仍需深度理解
2. 需要制定长期客户关系维护策略
3. 上次沟通和当前卡点均无法确认
4. 客户已明确拒绝且没有新信息

## 输入要求

正式运行前必须检查必填参数，并使用“已命中、部分命中、缺失、冲突、待验证”输出参数状态表。关键参数缺失或冲突时，只能进入初步分析模式并停止正式分析。
