## Description:

Plans greenfield Huawei Cloud MRS cluster resources from business requirements and produces an Excel sizing report.

This skill is ready for commercial/non-commercial use.

## Publisher:

[huaweicloudskill](https://clawhub.ai/user/huaweicloudskill)

### License/Terms of Use:

MIT-0

## Use Case:

Cloud architects and data platform engineers use this skill to plan a new Huawei Cloud MRS cluster from workload requirements, estimate node and storage capacity, and prepare a sizing report.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Sizing values are planning estimates, and report success checkmarks do not validate capacity.

Mitigation: Independently check capacity, redundancy, regional availability, and pricing before purchasing or deploying.
