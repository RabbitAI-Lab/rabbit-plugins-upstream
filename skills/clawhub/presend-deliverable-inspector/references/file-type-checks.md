# 文件类型检查

优先使用结构化解析和页面渲染。文件工具不可用时，基于可见内容做限制版判断，并列出待补材料。

## PPT

重点检查：

- 每页标题能否独立表达结论。
- 标题、图表、注释、脚注能否对上。
- 关键数据有没有来源、时间范围和口径。
- 同一指标在目录、正文、总结页、附录里有没有多版本。
- 最后一页有没有明确要决策、要确认或要执行的事项。
- 隐藏页、备注区、页脚、文件名里有没有旧项目、旧日期、内部话术。

发现动作：

- 把所有页面标题单独拉成一列，检查标题是否都能被本页图表或正文支撑。
- 把所有数字按指标、周期、单位分组，检查摘要、正文、附录是否冲突。
- 扫隐藏页、备注区、页脚、文件名，查内部话术和旧版本线索。
- 对最后 2 页做决策检查：是否有请求、选项、责任人和时间点。

输出定位优先写 `第 X 页`。

## Word

重点检查：

- 摘要和正文结论能否互相支撑。
- 数据、引用、图片、表格有没有来源。
- 语气有没有越权承诺。
- 章节标题和段落内容有没有错位。
- 页眉、页脚、脚注、尾注、批注、修订痕迹、占位符有没有残留。

发现动作：

- 对摘要里的每个结论找正文证据，找不到就标 `claim_evidence_gap` 或 `source_missing`。
- 搜索承诺词和绝对词，检查是否需要审批或来源。
- 检查页眉、页脚、脚注、尾注、批注、修订、占位符、目录和图表编号。

输出定位优先写 `第 X 页 / 第 X 节 / 表 X`。

## PDF

重点检查：

- 导出后页面有没有遮挡、断行、缺图、乱码。
- 是否缺可抽取文字层；图片型 PDF 不能假装读完正文。
- 页码、目录、引用、图表编号有没有错。
- 来源脚注和附录有没有保留。
- 扫描件或图片 PDF 的可读文字有没有缺失。

涉及版式时，优先渲染页面做视觉检查。

发现动作：

- 渲染页面或查看缩略图，先扫遮挡、断行、乱码、缺图。
- 若几乎抽不到文字，先标 `format_rendering_error`，要求源文件、可复制文字版或逐页渲染复查。
- 对目录、页码、图表编号和脚注做交叉检查。
- 来源链接断裂或脚注缺失时，标 `source_missing` 或 `format_rendering_error`。

## Excel

重点检查：

- 汇总页和明细页数字能否对上。
- 公式、公式错误值、透视表、筛选状态、隐藏行列、隐藏工作表有没有影响结论。
- 单位、币种、税前税后、含不含退款等口径有没有写清。
- 硬编码数字有没有来源。
- 图表引用区域有没有漏行或多行。
- 文件里有没有临时表、旧版本表、个人信息。
- 隐藏工作表有没有内部草稿、旧价格、客户不可见说明或未公开口径。
- 批注、备注或单元格 notes 里有没有内部审批、旧价格、客户不可见说明。

发现动作：

- 汇总页数字和明细表数字逐项对照。
- 查公式引用区域、公式错误值、筛选状态、隐藏行列、隐藏工作表、外部链接和透视表刷新状态。
- 查硬编码数字、单位、币种、税前税后、退款口径。
- 图表引用区域和数据源区域必须对上。
- 扫隐藏工作表内容，外发材料若保留 internal draft、do not share、old pricing 或 client should not see，标 `version_residue`。
- 扫工作表批注和 notes，外发材料若保留 internal note、internal approval、old pricing 或 client should not see，标 `version_residue`。

输出定位优先写 `工作表 + 单元格区域`。

## 粘贴内容

重点检查：

- 开头有没有对象和目标。
- 主结论有没有证据。
- 关键数字有没有口径。
- 段落顺序能否支持收件人快速决策。
- 结尾有没有下一步。

发现动作：

- 先标出收件人、目标动作和截止时间。
- 把正文里的数字、承诺和结论列成短表。
- 对每个主结论找证据句。
- 对结尾检查是否能让收件人下一步行动。

位置可写 `开头 / 中段 / 结尾 / 某个小标题`。

## 多附件包

重点检查：

- 当前收件人与每个附件声明的受众能否对上。
- 文件名、封面、首个工作表、页眉页脚和占位语有没有老板版、董事会版、客户版或内部审阅标签混用。
- 同一指标、来源、客户名、时间线和承诺能否跨文件闭环。
- 邮件正文指向的附件名、版本号和实际发送文件能否对上。

发现动作：

- 先列出 `附件名 + 声明受众 + 证据位置`，再和当前指令里的收件人逐项比较。
- 客户包混入 `Board Pack`、`Boss Update`、`internal review` 或同义标签时，标 `audience_mismatch`，不能只写成版本提醒。
- 对跨文件关键数字建立统一指标身份，对承诺建立审批与责任人链路。

输出定位优先写 `附件名 / 封面、工作表、页眉页脚或具体段落`。
