# 出街风险分类

用于判断一份交付物能不能发。先看阻断风险，再看中风险，最后看润色项。

## 阻断风险

出现任一项，默认给 `暂缓发送` 或 `重做后再发`。

| 风险 | 典型信号 | 修法 |
| --- | --- | --- |
| 数据无来源 | 图表、结论、关键数字没有来源、时间范围或口径 | 补来源脚注，或改成待确认表述 |
| 数字打架 | 同一指标在不同页、表、图里数值不同 | 统一口径和版本，保留一个主数字 |
| 结论强于证据 | 证据只支持趋势，标题写成绝对判断 | 降低措辞强度，或补证据 |
| 标题和图表不一致 | 标题讲增长，图表显示持平或下降 | 改标题，或换图表 |
| 缺少下一步 | 汇报完没有要老板或客户做的决定 | 增加决策页或行动清单 |
| 关键承诺越权 | 承诺价格、交付、法务、资源、时间线 | 改成待确认或需审批 |
| 隐私和保密暴露 | 客户名、员工姓名、未公开计划、合同金额泄露 | 脱敏、打码或改成范围 |

## 中风险

出现 1-3 项通常给 `快改后发送`；多项叠加升到 `暂缓发送`。

| 风险 | 典型信号 | 修法 |
| --- | --- | --- |
| 受众错位 | 给老板看却像执行备忘，给客户看却像内部讨论 | 调整第一页、标题和行动要求 |
| 页面负担过重 | 一页塞入多条主线或过多图表 | 拆成主线 + 附录 |
| 口径没有定义 | GMV、销售额、活跃、转化等指标无定义 | 补口径、周期、样本 |
| 版本痕迹 | 文件名、页脚、备注里有旧版本 | 删除旧日期、旧项目名、旧结论 |
| 证据位置太远 | 结论在前，证据藏在附录 | 在结论页补一句依据 |
| 图表可读性差 | 坐标轴、单位、图例、颜色含义不清 | 补单位和图例，删装饰 |

## 润色项

只影响观感时，不阻断发送。

- 标点、大小写、字体细节。
- 个别标题可再压短。
- 页面密度略高但主线清楚。
- 视觉风格不统一但信息无误。

## 判定原则

优先保护事实可信度、数字一致性、决策清晰度。美化排在后面。

若用户只剩 10-30 分钟，先修阻断风险；中风险只修会被当场追问的部分；润色项直接放弃。
