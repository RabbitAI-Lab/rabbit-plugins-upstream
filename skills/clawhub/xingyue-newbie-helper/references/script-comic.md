## 🌊 三种创作路径

### 路径 A：动态漫/沙雕漫（最易上手）
```
1. 看「剧本模块重磅更新」视频
2. 用星月「小说转剧本」功能一键生成
3. 加画面描述 → 输出剧本
4. 投稿动态漫平台（具体渠道问公开课）
```

### 路径 B：原创剧本（最难但最值钱）
```
1. 看「专业编辑剧本创作思维」理解剧本本质
2. 看「原创剧本全流程」
3. 用星月辅助（但内核必须自己写）
4. 投稿影视公司 / 短视频剧本工作室
```

### 路径 C：改编剧本（已写小说的捷径）
```
1. 已有长篇/短篇小说
2. 看「改编剧本全流程」
3. 星月辅助做结构化 + 节奏调整
4. 双线变现（小说稿费 + 剧本稿费）
```

## 💡 新人最容易踩的坑

- **不要把小说当剧本** —— 剧本是镜头语言，不是有字有人
- **不要省场景描述** —— 动态漫/沙雕漫的画面感全靠场景
- **不要忽略对白节奏** —— 短对白 + 强冲突是剧本核心
- **动态漫首选沙雕向** —— 笑点密度高，制作容错率高

## 🎬 三种形式对比

| 形式 | 字数 | 制作难度 | 单价 | 适合 |
|------|------|---------|------|------|
| 动态漫 | 剧本 + 画面 | 中（需要分镜） | 中 | 已有 IP 加变现 |
| 沙雕漫 | 短对白 | 低（表情包级） | 低-中 | 新人试水 |
| 短剧剧本 | 1-3 万字 | 高 | 高 | 想转型影视 |
