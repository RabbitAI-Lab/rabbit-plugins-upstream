# 脑洞生成器 · 提示词

> 来源：星月写作快捷方式 https://xingyuexiezuo.com/?shortcut=106635

## 📋 原始提示词（来自星月官方）

```
【大海】一键三个脑洞生成，带评分（自动检索番茄热榜）奇想好
```

## 🎯 使用方法

1. 进入星月写作：https://xingyuexiezuo.com/?shortcut=106635
2. 系统会自动基于「番茄热榜」生成 3 个脑洞
3. 每个脑洞带评分（基于热榜趋势 + 创新度）
4. 选择喜欢的脑洞 → 直接进入创作流程

## 🧠 脑洞生成的本质

**输入：** 一个关键词（如「大海」「重生」「赛博朋克」）
**输出：** 3 个基于番茄当前热门题材的脑洞 + 评分
**作用：** 帮作者突破"想到的都被写过"的瓶颈

## 💡 提示词变形（举一反三）

把"大海"换成任意关键词都可触发同类生成：

```
【赛博朋克】一键三个脑洞生成，带评分（自动检索番茄热榜）奇想好
【重生】一键三个脑洞生成，带评分（自动检索番茄热榜）奇想好
【玄幻】一键三个脑洞生成，带评分（自动检索番茄热榜）奇想好
【校园】一键三个脑洞生成，带评分（自动检索番茄热榜）奇想好
【末日】一键三个脑洞生成，带评分（自动检索番茄热榜）奇想好
```

> **星月官方设计的核心：通过热榜保证脑洞"接地气"，通过一键生成保证"零成本试错"。**

## 🔧 配合其他功能

- 脑洞 → 章纲：星月「章纲续写」功能
- 脑洞 → 封面：星月「封面提示词」
- 脑洞 → 评分：番茄热榜趋势对比

## 🎬 适用场景

| 场景 | 怎么用 |
|------|------|
| 不知道写什么 | 输入任意关键词 → 看 3 个脑洞 |
| 写了 3 万字卡壳 | 用脑洞生成找新支线灵感 |
| 想蹭热榜但没方向 | 看评分高低直接选 |
| 多账号矩阵 | 每个号用不同关键词批量生成 |
