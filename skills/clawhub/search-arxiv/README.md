# search-arxiv

A lightweight Brave browser skill for **arXiv**.

## What it does

Search arXiv for research papers matching the user's query.

- Reuses an existing relevant tab/session
- Avoids unnecessary duplicate tabs
- Verifies the destination
- Never handles credentials

## Example triggers

- Search arXiv for AI security
- Find papers about jailbreak robustness
