## Description:

Generate high-contrast, resonant, and story-driven spoken scripts for short videos, character stories, or personal IP scripts.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and agents use this skill to write colloquial short-video scripts, character stories, and personal-brand viewpoints. It structures each script around a hook, a specific story, a central viewpoint, and a memorable ending.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: This scriptwriting skill requires unrelated cloud image generation, adding software execution and account access beyond its advertised purpose.

Mitigation: Prefer a text-only skill or make image generation optional. Before enabling dLazy, review the CLI, information sent to its service, and applicable costs; use a revocable API key.
