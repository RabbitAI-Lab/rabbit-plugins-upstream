## Description:

Guides agents to write conversational short-video spoken scripts with a contrasting hook, concrete stories, audience resonance, and a personal point of view.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and marketers use this skill to draft short-video spoken scripts, character stories, and personal-brand viewpoints from a persona, topic, or audience pain point.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill also directs users to install a dLazy CLI and generate images, beyond its spoken-script purpose.

Mitigation: Use the script-writing guidance alone unless image generation is intended; review the CLI package before installation.

Risk: Using the optional CLI sends prompts and supplied media to dLazy services and stores an API key locally.

Mitigation: Avoid submitting sensitive material and review the service and API-key storage before use.
