## Description:

Guides an agent to write colloquial, story-driven short-video spoken scripts using a seven-step structure.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Content creators and agents use this skill to draft spoken scripts for short videos, character stories, and personal-brand viewpoints. It structures each script around a contrast hook, a specific story, a central viewpoint, and a memorable ending.

### Deployment Geography for Use:

Global
