## Description:

Generate high-contrast, resonant, and story-driven spoken scripts for short videos, character stories, or personal IP scripts.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

External creators and marketers use this skill to draft short-video spoken scripts, character stories, and personal-brand viewpoint scripts. It structures the writing around a seven-step narrative and favors conversational language, concrete situations, and recitable pacing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Using the optional dLazy CLI involves third-party package execution, API credentials, external service use, and possible charges.

Mitigation: Install and use the CLI only when these features are needed; review the package and project information first, and use dLazy's credential rotation or revocation controls if a key may be exposed.

Risk: Prompts and media provided to the CLI may be sent to dLazy services, and local media may be uploaded for model processing.

Mitigation: Avoid submitting confidential prompts or media unless their transfer to the external service is acceptable.
