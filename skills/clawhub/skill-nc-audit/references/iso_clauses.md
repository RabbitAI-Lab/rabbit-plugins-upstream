## 高频不符合项条款

### 条款7.1.5 - 监视和测量资源

**常见不符合模式:**
- 设备超出校准/检定有效期
- 校准证书未在有效期内
- 校准范围不覆盖使用范围
- 无校准状态标识
- 期间核查未按规定执行

**判定标准:**
| 情况 | 建议类别 |
|------|----------|
| 测量结果直接影响产品合格判定 | **major** |
| 设备超期未校准仍在使用 | **major** |
| 校准证书参数不全但不影响使用 | minor |
| 标识不完整但设备在有效期内 | observation |

### 条款8.7 - 不合格输出控制

**常见不符合模式:**
- 不合格品未隔离
- 不合格处理未经授权
- 返工/返修后未重新检验
- 不合格记录不完整

### 条款9.2 - 内部审核

**常见不符合模式:**
- 内审计划未覆盖所有条款
- 审核员未取得资格
- 不符合项原因分析不充分
- 纠正措施跟踪验证缺失

## 判定指南

### 如何区分 major / minor / observation

#### major (严重不符合)
符合以下任一条件:
1. 体系文件**缺失**或**完全未执行**
2. 影响产品/服务**符合性**或**顾客满意度**
3. 问题**系统性**或**广泛性**存在
4. **重复发生**的同类问题
5. 涉及**法律法规**要求

#### minor (轻微不符合)
符合以下条件:
1. 个别/局部偏差
2. 不影响整体体系有效性
3. 可**立即纠正**或短期整改
4. 未造成实际后果

#### observation (观察项)
符合以下条件:
1. 潜在风险或改进机会
2. 良好实践分享
3. 流程优化建议
4. 监控指标偏离趋势

## 条款编号速查

| 大类 | 条款范围 | 主要关注点 |
|------|----------|------------|
| 体系基础 | 4.x - 5.x | 组织环境/领导作用 |
| 策划 | 6.x | 风险/目标 |
| 支持 | 7.x | 资源/能力/文件 |
| 运营 | 8.x | 过程控制(高频) |
| 绩效评价 | 9.x | 监视/内审/管理评审 |
| 改进 | 10.x | 不合格/纠正/持续改进 |
