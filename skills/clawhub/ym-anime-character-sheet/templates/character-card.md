# 角色设定卡模板 (character-card.md)

> 用法：按章节顺序填写，每一节都不能空。每节下方「范例」行用原创角色「凛·艾尔维斯」演示，请勿照抄，仅作格式参考。

## 1. 基本信息

- 姓名（含读音标注）：
- 年龄：
- 身高：
- 生日（含星座 / 血型等可选）：
- 定位（主角 / 配角 / 反派 / 路人）：
- 世界观类型：

范例：凛·艾尔维斯（Lín Aì'ěrwéisī）｜17 岁｜168cm｜星历 3 月 14 日（双鱼座）｜反派（后转中立）｜异世界

## 2. 外貌（≥3 处可画辨识点）

- 发色 / 发型：
- 瞳色 / 眼神特征：
- 标志性伤疤 / 配饰 / 纹身：
- 体型 / 站姿 / 小动作：

范例：银灰长直发齐腰，左鬓一缕染夜蓝；异色瞳（左金右紫）；右锁骨至肩有灼痕状旧疤；习惯性用左手整理袖口，站姿微前倾像随时要出手。

## 3. 性格（必须含至少一组矛盾特质）

- 主导特质：
- 矛盾特质（两组对立面 + 暴露时机）：
- 恐惧 / 底线：

范例：主导——冷静克制、说话慢半拍。矛盾——对外人极度温和有礼，但对「以弱者为棋」的事零容忍；平时藏得住，一旦对方踩线当场翻脸动手。底线——不许拿孩子当筹码。

## 4. 能力（必须配对等价弱点或代价）

- 能力名 / 机制：
- 等价弱点或代价（与能力强度对等）：
- 限制条件：

范例：能力「霜弦」——拨动空气凝出冰线束缚目标。代价——每用一次体温降一截，连用到第三次会失温昏厥；对火属性目标效果减半。限制——只够束缚，不足以杀。

## 5. 口头禅与语言习惯

- 口头禅（附适用 / 慎用场景）：
- 称呼方式（对长辈 / 同级 / 晚辈）：
- 语癖：

范例：口头禅「不急，等它自己凉」。适用——对峙施压时；慎用——朋友难过时（会显得冷漠）。称呼——对长辈称「您」，同级直呼其名，晚辈加「小」。语癖——句尾常带「罢了」。

## 6. 服装（日常 / 正式 / 战斗三套）

- 日常：
- 正式：
- 战斗（注明可画元素）：

范例：日常——深蓝立领校服外罩灰围巾；正式——黑金长礼服，领针是断弦徽；战斗——贴身皮甲外罩冰纹半披，腰挂三枚冰铃（可画发光特效）。

## 7. 成长弧线

- 起点状态：
- 触发事件：
- 终点状态：

范例：起点——为复仇加入恶势力当工具人；触发——发现被利用的孩子正是当年救自己的恩人之子；终点——倒戈护下孩子，自己背负叛徒骂名流亡。

## 8. 关系网（≥2 组，含 1 组张力关系）

- 关系 A（类型 / 对方 / 状态 / 张力来源）：
- 关系 B（张力关系：竞争 / 亏欠 / 立场对立）：

范例：A——盟友·副手瑟琳·互相欣赏；B（张力）——立场对立·前同伴凯德·当年凛为保命抛下他，凯德视为背叛，追杀凛，但双方都不想真下死手。
