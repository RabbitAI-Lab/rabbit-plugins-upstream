# 角色设定卡内部一致性自检清单 (design-checklist.md)

生成角色卡后逐条判定，每条给「通过 / 不通过 / 已修正」。不通过或已修正须说明动作。这是把「能写故事的设定」和「纸片人」区分开来的最后一道关。

## 01. 名字是否易读易搜

- 判定：读音能顺畅拼出、字数 ≤ 4 个汉字或常见译名结构、无打不出的生僻字
- 不通过示例：名字用极生僻字导致输入法打不出、超过 6 字难记
- 规避：起名附读音标注，控制在易记范围，避免纯符号拼接

## 02. 年龄与外貌是否一致

- 判定：身高 / 体型 / 神态描写与年龄自洽，无「13 岁却描写成壮年气场」之类冲突
- 不通过示例：写「稚嫩少年」却配「身高 195cm、满脸风霜」
- 规避：写外貌前先锁定年龄，写完回看两项是否自洽

## 03. 能力是否有代价

- 判定：每条能力都有对等弱点或代价，不存在零成本无敌技
- 不通过示例：能力毁天灭地但代价只是「偶尔乏力」
- 规避：能力节强制配对弱点，强度对齐世界观上限

## 04. 口头禅是否可用在不同情绪场景

- 判定：口头禅至少能在 2 种情绪下成立，且标注了慎用场景
- 不通过示例：口头禅只在对线时用，悲伤 / 战斗场景全穿帮
- 规避：给 2 个以上例句，严肃场景单独标注慎用

## 05. 关系是否有张力

- 判定：关系网 ≥ 2 组且含 1 组张力（竞争 / 亏欠 / 立场对立），张力有具体来源
- 不通过示例：关系网里全是「好友」「挚爱」，没有任何冲突
- 规避：至少一组是对立或被亏欠方，写明冲突来源

## 06. 成长弧线是否有触发事件

- 判定：起点 → 终点之间有明确触发事件，不是「突然就变了」
- 不通过示例：终点写「成为勇者」，但中间没有任何撬动点
- 规避：补写触发事件，说明它如何改变角色

## 07. 外观辨识点是否够画师参考

- 判定：外貌 ≥ 3 处可画点（发色 / 瞳色 / 伤疤 / 配饰 / 站姿）
- 不通过示例：外貌只写「很漂亮」「气质出众」
- 规避：每条都写成画师能直接下笔的样子

## 08. 背景是否与世界观冲突

- 判定：出身 / 能力来源 / 服装材质不违背该世界观设定（如校园世界观不该有魔法战斗装甲）
- 不通过示例：现代校园角色突然有「召唤巨龙」的设定
- 规避：生成前锁定世界观类型，逐项回查

## 09. 是否存在「完美无缺」问题

- 判定：角色有可被利用的缺点或软肋，不是全正面
- 不通过示例：又强又温柔又无私又聪明，毫无短板
- 规避：性格节必须有矛盾特质或明显短板

## 10. 是否撞常见知名角色名

- 判定：名字不与知名作品主角 / 反派高度相似（读音、字型、意象）
- 不通过示例：起名风格直接照搬热门番主角
- 规避：起原创名，比对后若近似当场改名
