# 模型卡生成器 / Model Card Generator

[![LGD](https://img.shields.io/badge/LGD-Governance-blue)](https://github.com/zhaoxinghua09-cell/lgd-theory)

## English

Generate a one-page model card for any AI system: identity / purpose / data / limits / risks / contact, in Markdown + JSON.

**Pain point**: AI systems pile up in teams with no record of what each is for, its limits, or who owns it — nothing to check after incidents.

LGD-I registered (every AI system has one identity card) · TH-LGD-006.
Part of the **LGD governance family** (凡自治之物: registered / evidenced / gated).

Zero-dependency (stdlib only). See `scripts/` for CLI usage (`--help`).

© SynomosAI (LGD initiative) · LGD-Powered

## 中文

给团队内任何 AI 系统生成一页模型卡：身份 / 用途 / 数据 / 限制 / 风险 / 联系人，输出 Markdown + JSON。

**痛点**：团队里 AI 系统越堆越多，每个是干什么的、限制是什么、谁负责，全无记录——事故发生后无据可查。

LGD-I 有籍（每个 AI 系统有一页身份卡）· TH-LGD-006。
隶属 **LGD 治理家族**（凡自治之物：有籍 / 有证 / 有门禁）。

零依赖（仅标准库）。CLI 用法见 `scripts/`（`--help`）。

© SynomosAI（LGD  initiative）· LGD-Powered
