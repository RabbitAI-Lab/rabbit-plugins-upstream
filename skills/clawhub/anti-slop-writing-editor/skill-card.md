## Description:

Edit prose to remove AI-coded rhetoric, filler, and cadence tics while preserving voice.

This skill is ready for commercial/non-commercial use.

## Publisher:

[stanestane](https://clawhub.ai/user/stanestane)

### License/Terms of Use:

MIT-0

## Use Case:

Writers, editors, marketers, and other external users use this skill to audit or rewrite human-facing prose so it keeps the user's facts and voice while removing formulaic model-generated phrasing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Opinionated editing rules may remove phrasing, cadence, or rough edges that the user intentionally wanted to preserve.

Mitigation: Review rewritten prose before publishing and restore intentional language where the edit changes meaning, voice, or emphasis.
