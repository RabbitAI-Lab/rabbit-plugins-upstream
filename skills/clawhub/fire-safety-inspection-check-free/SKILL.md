# 消防设施检查与维保记录核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**、**没有任何广告与购买提示**。

## 什么时候用

**谁会在什么时候用**：物业、工厂、商场、学校的**消防管理员 / 消防安全责任人**，在**每月**
做防火巡查与维保记录归档时；以及迎接消防监督检查、做月度消防安全小结之前。

**为什么每月都躲不过**：消防设施（灭火器、消火栓、喷淋、火灾自动报警、应急照明、疏散指示、防火门、
防排烟）要**每月巡查**，灭火器要**年检 / 维修**，消防设施要**年度检测**，而且巡查记录、维保记录、
故障与整改要形成**闭环台账**。消防设施年检与月检是法定要求；检查时「记录有、隐患没整改」
「灭火器超期未检」都是**直接处罚项**。

**这张表要逐项核什么**（列里给口径，工具只做字面复算）：

| 每月必核的事 | 表里靠哪几列 |
| --- | --- |
| 巡查频次与覆盖 | 规定巡查频次、本月巡查次数、区域、设施类型、台账数量 |
| 灭火器压力与有效期 | 检查日期、下次检定到期日、状态 |
| 台账与记录对不对得上 | 台账数量、明细行数、合计行的数量类列 |
| 记录有没有重复登记 | 设施编号、检查日期 |
| 字段与状态是否合规 | 状态（正常/故障/停用/已整改）、各日期列的格式 |

每条结论都带**原文行号与原文行**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 这个免费版查什么（6 项）

1. **巡查频次覆盖**：逐项核对 `本月巡查次数 ≥ 规定巡查频次`，不足即报出缺口次数。
2. **检定有效期**：`检查日期 ≤ 下次检定到期日`（灭火器年检/维修、设施年度检测），超期即报出超期天数。
3. **数量勾稽**：逐区域 × 逐设施类型核对 `设施台账数量合计 = 明细登记条数`，差额即报。
4. **同一设施同一日期重复登记**：设施编号 + 检查日期重复即点名在先的行号。
5. **合计行逐列复核**：合计/小计行的数量类列与明细行之和逐列复算。
6. **空白/占位符/非法值**：关键字段空白或占位符、日期格式非法、状态值不在 `正常/故障/停用/已整改` 之内、数量为负或无法解析。

**这个免费版不含**（完整档才有）：故障整改闭环时长、故障未闭环清单、维保周期勾稽、
维保单位资质有效期覆盖、分区域×分设施类型的汇总清单与整改动作清单。

## 怎么用

```bash
node scripts/run.mjs --sample                 # 先看样例（内置一张干净的月度巡查表）
node scripts/run.mjs --input 你的材料.json     # 跑自己的材料
node scripts/run.mjs --input 你的材料.json --json
```

入参就是一个 `text`：把 Excel 里的**表头 + 数据行**一起复制成文本（Tab 分隔最稳）。

## 常见错法（消防管理里最容易踩的 5 个坑）

1. **「本月巡查次数」按记录条数填**：一个点位一天巡两次就填 2，却拿「每周一次 = 4 次/月」去比，
   频次永远对不上。这一列要按**本月应巡次数是否完成**的同一口径填，别把「巡了几次」与「记录几条」混着用。
2. **灭火器到期日抄错起点**：把「下次检定到期日」写成出厂日期或上次维修发票日期，而不是**本次年检/维修后
   重新起算**的到期日 —— 于是明明已经超期未检，表上看着还没到。
3. **台账数量填 1，实际点位有多具**：一个点位挂 3 具灭火器，登记只写 1 行、台账数量也写 1 ⇒ 数量勾稽永远平，
   漏检的那 2 具永远看不出来。台账数量要按**实际台/具数**填。
4. **状态与闭环日期不匹配**：整改完了状态还留着「故障」不更新，或者填了「已整改」却不写整改完成日期
   （只写报修日期）⇒ 闭环时长与未闭环清单都会失真。
5. **维保周期从合同日期起算**：用「签合同日期 + 12 个月」当下次维保日期，且维保单位的资质到期日没跟着
   资质延续一起更新 ⇒ 维保记录落在资质有效期之外，检查时等同于**没维保**。

## 需要完整档时（可选）

本免费版是**完整可用的核心产出**，本版本**不包含**下面这些项：

- 故障整改闭环时长（状态=已整改：报修日期 → 整改完成日期 ≤ 整改时限(天)，超时点名并给出超时天数）
- 故障未闭环清单（状态=故障 但整改完成日期为空或超期未整改，按超期天数从大到小排队）
- 维保周期勾稽（上次维保日期 + 维保周期(月) = 下次维保日期，逐行复算）
- 维保单位资质有效期覆盖（上次/下次维保日期 ≤ 资质到期日）
- 分区域×分设施类型的汇总清单（按故障数与超期数排序，给出逐组可整改动作）与合并后的整改动作清单

同名工具的**完整档**是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别**就是上面这些，没有别的**。

## 边界（请务必知道）

本工具**不做**引擎 `CHECKS_OUT_OF_SCOPE` 里列的那些判断：不判定消防设施是否**合格**、
不判定隐患是否**真正消除**、不判会不会被处罚、不现场读压力表读数、核对过程不联网核验资质证书真伪；
材料不足时**不给结论**，也不会输出「未发现问题」。
