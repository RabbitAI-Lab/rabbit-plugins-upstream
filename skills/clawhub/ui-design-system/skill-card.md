## Description: <br>
Provides UI color themes, a custom palette workflow, and soft, minimalist, and brutalist aesthetic variants for frontend visual design. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[paudyyin](https://clawhub.ai/user/paudyyin) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and design-focused agents use this skill to choose or generate coherent UI palettes, select one visual aesthetic, and apply concrete typography, color, motion, and component rules to frontend work. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger terms such as theme or aesthetic may activate the skill during general UI styling work. <br>
Mitigation: Narrow activation triggers or confirm the intended theme and aesthetic variant before code is generated. <br>
Risk: The skill can strongly influence typography, palette, motion, and component choices for frontend output. <br>
Mitigation: Have the user choose one theme and one aesthetic variant, then review the resulting design constraints against project accessibility and brand requirements. <br>
