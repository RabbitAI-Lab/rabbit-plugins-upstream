# 分类索引笔记格式规范（源自 PR Daily 实战验证体系）

写入任何笔记前先读本文件。所有更新一律**追加在笔记最底部**，序号全局续编，绝不改写已有内容。

## 一、独立分类索引笔记（每类 1 篇，目录指引）

**创建**：import_doc 新建（长内容走 COS 路径），标题即首行。

```markdown
# 【{站点名}·分类索引】{分类名}

类型：分类索引笔记（目录指引，全量收录）
来源：{域名} 分类 {slug或栏目名}（{抓取通道} 抓取）
排序：从旧到新；新增文章追加在末尾，序号全局递增
初次抓取日期：{YYYY-MM-DD}

| 序号 | 发布日期 | 标题 | 摘要 | URL |
|---|---|---|---|---|
| 1 | {最旧文章日期} | {标题} | {摘要，无则空} | {URL} |
| 2 | ... | | | |

## 更新记录
{YYYY-MM-DD} 初次建立：收录 {N} 篇，时间范围 {起始} ～ {结束}
```

**追加更新**（在笔记最底部追加，不新建笔记）：

```markdown
## 更新：{起} ~ {止} 新增 {分类名} 文章（{追加日期} 追加）

| 序号 | 发布日期 | 标题 | 摘要 | URL |
|---|---|---|---|---|
| {续编序号} | ... | | | |

## 更新记录
{YYYY-MM-DD} 补充：{起} 至 {止} 期间 {分类名} 新增 {M} 篇，序号 {a}-{b}。
```

## 二、统一更新笔记（全站 1 篇，正式导入记录）

与独立笔记的唯一结构差异：**表格多一列「类别」**（放在序号之后）。

```markdown
# 【{站点名}·分类索引·更新】

类型：更新索引笔记（正式导入知识库的 URL 记录，覆盖 {n} 类）
来源：{域名}（{抓取通道} 抓取）
排序：从旧到新（全局按日期升序）；新增文章追加在末尾，序号全局递增
初次抓取日期：{YYYY-MM-DD}

| 序号 | 类别 | 发布日期 | 标题 | 摘要 | URL |
|---|---|---|---|---|---|
| 1 | {分类名} | ... | | | |

## 更新记录
{YYYY-MM-DD} 初次建立：{n} 类共 {N} 篇（各类明细），序号 1-{N}。
```

追加小节标题格式：`## 第{k}次更新：{起} ~ {止} 新增（{追加日期} 追加）`；每次追加的末尾都带一个新的 `## 更新记录` 小节（历史更新记录保留不动，全文会出现多个，日期依次沉底）。

## 三、写入技术路径（强制）

1. Markdown 内容写入 `.md` 文件（单元格内 `|` 替换为 `/`、去换行，防错列）。
2. `ima_cos_util -f {文件}` 上传取 cosKey。
3. `push_note`：新建不传 note_id；追加传 `{note_id, content_cos_key}`。
4. 超过 1000 行分批追加，每批 ≤1000 行（每次都是一次 COS 上传+push_note）。
5. 写完用 `export_note`（target_content_format=1）下载原文核验最大序号与行数。

**禁止**：append_doc/update_note 直接在 JSON body 里传含表格的内容（触发 WAF）；用 fetch 判断长笔记写入结果（会降级返回加工摘要）。

## 四、大站处理

某分类全量超过约 3000 行时，独立分类笔记标题加前缀：`(建议绕过)【{站点}·分类索引】{分类名}`——提示用户客户端可能打不开，但保留为目录指引与助手可读归档。统一更新笔记不受影响（始终只收录实际导入 KB 的量级）。
