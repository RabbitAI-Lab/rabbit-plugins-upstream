# sites_to_ima

> 🔌 本工具是 [ima.copilot](https://ima.qq.com)（腾讯智能工作台）的 Skill 插件，需在 ima.copilot 环境中使用，非独立运行工具。

网站内容批量标记入库——全量抓取指定网站的内容列表，导出表格，建立分类索引笔记，批量导入知识库，并生成可复用的增量更新手册。

---

## 一、使用场景

你是否遇到过这些痛点？

- **追踪海外专业站点太麻烦**：PR 行业的人想知道 PR Daily 最近发了什么、营销人想看 AdAge 的新趋势——每次打开浏览器翻几十页，重复劳动
- **收藏即遗忘**：看到好文章存了书签，找的时候翻半天找不到
- **知识不成体系**：零散看几篇文章，没有分类索引，回顾时只能靠记忆搜索

`sites_to_ima` 解决的就是这个问题：**一键将某个专业站点的全部内容列表（按分类）建立索引笔记，并批量导入到你的 ima 知识库**，后续只需说"更新知识库"，增量变化自动追加。

典型场景：你想追踪某个海外专业媒体/博客的所有文章，按栏目分类，存进知识库检索。

## 二、本 Skill 优势

| 对比维度 | 手动收藏 | RSS 订阅 | sites_to_ima |
|---------|---------|---------|-------------|
| 覆盖范围 | 逐篇手动 | 仅最近更新 | **全量历史 + 增量** |
| 分类组织 | 自己建文件夹 | 无分类 | 自动按栏目建索引 |
| 检索能力 | 书签搜索 | 无 | **AI 语义检索**（知识库内） |
| 增量更新 | 无 | 自动 | 增量更新手册 + 一键续抓 |

### 成品展示：知识库「【权威】企业品牌公关指南」

在 ima.copilot 知识库广场搜索 **「【权威】企业品牌公关指南」**，可查看本 Skill 的真实产出效果。该知识库已建立以下站点的全量索引：

| 站点 | 分类数 | 说明 |
|------|--------|------|
| **PR Daily**（prdaily.com） | 6 类 | Marketing、Crisis Communications、Media Relations、Social Media、Writing & Editing、AI |
| **AdAge**（adage.com） | 2 类 | Creativity、Brand Marketing |
| **Marketing Brew**（marketingbrew.com） | 1 类 | Stories（全站内容） |

每个分类对应一篇目录索引笔记（含标题、发布日期、摘要、URL），以及一篇统一更新笔记（正式导入知识库的文章记录）。知识库内可通过 AI 直接检索任意文章内容。

## 三、使用方法

### 在 ima.copilot 中激活 Skill

在 ima.copilot 对话窗口直接发送本仓库的 **GitHub / ClawHub 地址**，copilot 会自动下载并注册到本地「技能」。

> 💡 由于涉及爬取与多步流程执行，建议搭配**能力较强的大模型**使用。

激活后通过自然语言指令即可触发：

```
标记网站 https://www.prdaily.com/types/crisis-communications/
把 https://www.adage.com/creativity/ 建成分类索引
更新 PR Daily 知识库
```

### 完整流程（Skill 自动执行）

1. **录入前置确认**：确认目标知识库及文件夹（文章归宿，必问）+ 笔记目标笔记本（还没建？Skill 会提醒并可代建）
2. **自动探测抓取通道**：优先 WordPress API → RSS/Sitemap → 浏览器兜底
3. **首次执行确认**：展示分类数量、全量提取范围、具体导入篇数，用户确认后才执行
4. **全量抓取 + 导出表格**：每分类一个 xlsx 文件
5. **建立双轨笔记体系**：独立分类索引笔记（全量目录）+ 统一更新笔记（导入记录）+ 更新手册
6. **批量导入知识库**：文章按分类子文件夹导入，可 AI 检索
7. **增量更新手册**：下次说"更新 XX 站点"即可一键增量

### 增量更新（关键词触发 + 进度兜底）

```
pr daily 更新
AdAge 更新
更新知识库
```

无需翻笔记、无需重新描述上下文--Skill 为每个站点维护**本地进度底座**（`progress.json`）：

- **关键词识别**：说 "pr daily 更新" 即自动匹配站点（支持站名常用叫法），直接读取该站各类的抓取进度开抓
- **双轨进度**：索引笔记收录到几号几号、共几篇；知识库实际导入到几号几号、共几篇，分开记录、分别续更
- **笔记直达**：索引/统一更新/手册三类笔记的 note_id 全部记录在案，按 ID 直达不靠搜索（ID 失效才用标题兜底）
- **记忆兜底**：即使会话记忆重置，本地进度文件仍在；文件意外丢失时还可从 ima 内的更新手册笔记恢复（双源互备）
- **强制自检**：每次更新后自动校验三项（本地进度已落盘 / 笔记末行序号正确 / 知识库计数到位），未通过不报"完成"
- **完成汇报**：每次更新后输出进度表（各类收录至哪天、累计多少篇、本次新增多少）

## 四、安装与注意事项

### 环境要求

- **必须**在 ima.copilot（腾讯智能工作台）沙箱环境中运行
- 依赖以下平台能力：`push_note`、`import_urls`、`ima_cos_util`、知识库 OpenAPI、笔记 OpenAPI

### 依赖安装

```bash
pip install requests openpyxl            # 必装
pip install playwright                    # 浏览器兜底通道需要
# 浏览器下载必须走国内镜像，直连必超时：
PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors/playwright/ playwright install chromium
apt-get install -y --no-install-recommends xvfb   # 有头模式（过 CF 必需）
pip install patchright                    # 反检测浏览器 fork，强防护站点备选
```

### 重要注意事项

1. **站点抓取限制**：部分站点开启高强度 Cloudflare 防护（JS Challenge + 托管质询），全通道无法抓取。Skill 会自动检测并判定不可行，不会无限重试。已知不可抓取：**MarketingWeek.com**（403 + "Just a moment" 全通道实测失败）
2. **导入前必须确认**：Skill 不会在用户不知情的情况下导入文章——每次导入前会展示完整执行计划（全量范围 + 具体导入数量 + 各类分配），获确认后才执行
3. **知识库条目不可删除**：IMA API 无删除能力，导入产生的内容需在客户端手动删除。Skill 对强防护站点会先试导入 1-2 篇验证可行性，避免批量导入后全部失败
4. **笔记只增不删**：分类索引笔记内容只追加不修改，确保历史更新记录可追溯
5. **大站处理**：某分类超 3000 行时，独立索引笔记标题加 `(建议绕过)` 前缀——客户端可能打不开，但仍可作为助手可读的目录指引
