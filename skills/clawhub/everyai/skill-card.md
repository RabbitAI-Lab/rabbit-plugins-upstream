## Known Risks and Mitigations:

Risk: Text submitted for processing is sent to EveryInfra for AI processing.

Mitigation: Share only data authorized for external processing.

Risk: The skill requires an EveryInfra API key.

Mitigation: Keep the key in secret settings and restrict it to the capabilities needed using the provider's available controls.
