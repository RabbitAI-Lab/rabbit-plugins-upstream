# 小红书发布文案写作指南

小红书文案的核心是**共鸣 + 干货 + 收藏驱动**。语气要像私人博主分享，不像机构/营销号。

## 结构拆解

### 标题（2-3 个备选，抓眼球）
常用套路：
- **扎心反问**：「你缺的不是时间，是精力」
- **痛点直击**：「每天累到不想动？先给精力充电」
- **结果导向**：「5张图，把状态管明白」
- **数字诱惑**：「4个维度，一套精力管理体系」
- **悬念**：「状态差不是懒，是它出了问题」

好的标题 = 命中目标人群的一个具体痛点，让人想点进来看。

### 正文（短段落 + emoji + 分点）
结构建议：
1. **开场共鸣**（2-3 句）：直接说出目标人群的痛点，让人「这说的不就是我」
   - 例：「你是不是也这样👇 明明没干什么，下班却累得不行 / 想专注却一直走神 / 焦虑内耗心很累」
2. **转折亮观点**（1-2 句）：给出反常识/新认知
   - 例：「其实你不是懒，是精力在亏空。时间和精力不一样——时间对每人都是公平的24h，拉开差距的是精力质量」
3. **干货分点**（用标题/emoji 分点，对应图片内容）
   - 例：「🌱 体能：身体的油箱先加满 / 💛 情绪：能量开关，别让它后台偷电 / 🧠 思维：专注是保护出来的」
4. **划重点**（✅/❌ 对比，方便收藏）
5. **行动号召 + 收藏引导**
   - 例：「建议收藏🌟，慢慢把状态养回来 / 从今晚睡个好觉开始💪」

### 话题标签（8-12 个）
- 热门大标签（流量）+ 垂类标签（精准）+ 场景标签
- 例：`#精力管理 #自我提升 #职场干货 #时间管理 #高效工作 #成长干货 #情绪管理 #专注力 #精力充沛`

## 语气要点
- **口语化**：像朋友聊天，不书面、不端着
- **有情绪**：用 emoji（👇🌟💪🔥✅❌😮‍💨）制造语气
- **短句为主**：一句一行，读起来不累
- **弱营销**：不硬卖课、不加联系方式（除非用户明确要引流）

## 反例（避免）
- ❌ 「本课程教您…」「我们的品牌…」——太机构
- ❌ 大段专业术语堆砌——不接地气
- ❌ 没有钩子/收藏引导——流失
- ❌ 标题太平淡（1. 精力管理）——没人点
