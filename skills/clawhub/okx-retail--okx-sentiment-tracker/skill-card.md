## Description:

Provides read-only access to OKX crypto news, coin sentiment, and macroeconomic calendar data through the OKX CLI.

This skill is ready for commercial/non-commercial use.

## Use Case:

Traders and analysts can review crypto news, coin sentiment trends, and macroeconomic events using OKX data. The skill requires the OKX CLI and API credentials.

### Deployment Geography for Use:

Mitigation: Keep credentials, personal details, and confidential information out of queries.
