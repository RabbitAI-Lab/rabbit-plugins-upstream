This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and website owners use this skill to audit deployed pages, improve SEO and AI-search visibility in their site's code, and plan relevant directory submissions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Connecting signed-in reports shares account-linked SEO and visibility data with LaunchRanked.

Mitigation: Connect optional reports only if you are comfortable sharing that data with the service.

Risk: Incorrect noindex, robots.txt, canonical, redirect, or URL-structure changes can reduce search traffic.

Mitigation: Review proposed indexing and URL changes before applying them.
