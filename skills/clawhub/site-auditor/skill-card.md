## Description:

Audits public web pages for on-page SEO issues and page speed, reads page content, and summarizes domain search performance.

This skill is ready for commercial/non-commercial use.

## Publisher:

[hith3sh](https://clawhub.ai/user/hith3sh)

### License/Terms of Use:

MIT-0

## Use Case:

Site owners, marketers, and developers use this skill to check public pages for SEO and speed issues, read page content, and prioritize fixes before launch or against competitors.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Using the skill requires installing and pairing the ClawLink plugin.

Mitigation: Install and pair it only with the user's approval.

Risk: Lookups consume ClawLink credit, especially bulk or higher-cost audits.

Mitigation: Check the current per-call price and ask before bulk audits or higher-cost calls.

Risk: Private or login-only URLs are outside the skill's public-page scope.

Mitigation: Use public URLs only; do not submit private or login-only pages.
