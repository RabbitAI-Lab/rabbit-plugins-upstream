## Use Case: <br>
Developers and engineers use this skill to get ready-to-run jq examples for filtering, transforming, formatting, and debugging JSON from files or API responses. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: A copied file-modification example may overwrite a JSON file. <br>
Mitigation: Review commands that redirect output and move temporary files before running them on important data. <br>
Risk: The skill depends on the local jq binary and package-manager installation. <br>
Mitigation: Install jq from a trusted package manager and confirm the binary is available before using the examples. <br>
