## Description:

Get larger YouTube search result sets with FlashData, requesting up to 700 results per query. Use for video datasets, creator discovery and broader YouTube research, with duration, date and sorting filters. Requires a FlashData API key and paid Credits.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and researchers use this skill to collect larger YouTube search samples, discover channels, and filter video results for datasets or topic research. Searches require a FlashData API key and consume paid Credits.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Using the hosted FlashData service sends the API key and search arguments to that provider and paid queries consume Credits.

Mitigation: Assess trust in FlashData before use, provide the key through protected secret configuration, limit queries to the approved task, and check Credit costs.
