# 概念股/主题驱动产业链分析工作流

> 当用户提出分析某个概念/主题（如"超节点算力"、"CPO"、"液冷散热"等）时使用此工作流。
> 与策略选股不同：策略选股从数据库出发，概念分析从市场热点出发。

## 工作流（6步）

### Step 1: 概念搜索与标的识别

通过 cn-web-search 搜索概念关键词，从搜索结果中提取关联个股。

**搜索策略**：
1. 第一轮：`"<概念名> 产业链 概念股 受益标的"` — 获取产业梳理文章
2. 第二轮：`"<概念名> <核心公司名> 产业链角色` — 深挖具体公司定位

**搜索结果提取要点**：
- 关注 "XX是YY的ZZ供应商" 这类产业链定位描述
- 关注 "独家配套"、"主力供应商"、"核心成员" 等强关联词
- 搜索结果通常会在一段文本中列出多家公司及其角色（如搜狗第一页结果）

**Pitfall**：搜狗网页搜索对连续批量请求触发反爬（1-2次成功后返回空JS）。策略：
- 第一次搜索最有效，尽量在第一次搜索中获取最多信息
- 间隔 3-5 秒后再发第二次
- 对个股新闻，优先用 `ak.stock_news_em(symbol=code)`，不受反爬影响

### Step 2: 产业链分层

将识别出的标的按产业链环节分类。常见分层模式：

**算力/AI基础设施产业链**：
| 层级 | 技术核心 | 代表标的 |
|------|---------|---------|
| 光互联 | 光模块/光引擎/光器件 | 中际旭创、华工科技、天孚通信 |
| 网络交换 | 交换机/网络设备 | 锐捷网络、中兴通讯 |
| 整机系统 | AI服务器 | 工业富联、浪潮信息 |
| 液冷散热 | 浸没式/冷板式液冷 | 高澜股份 |
| 连接器 | 高速铜缆/光连接器 | 立讯精密 |
| 功率半导体 | 电源MOSFET | 新洁能、东微半导 |

**其他常见概念分层**：
- 新能源车：上游资源 -> 中游材料 -> 电池 -> 整车 -> 充电桩
- 半导体：设计 -> 制造 -> 封测 -> 材料 -> 设备
- 光伏：硅料 -> 硅片 -> 电池片 -> 组件 -> 逆变器 -> 电站

### Step 3: 批量行情数据采集

**关键执行方式**：将 Python 脚本 `write_file` 到 `/tmp/` 再执行，**不要用 `python3 -c` 传递含中文的复杂代码**。

```python
# 标准批量行情采集脚本模板
import akshare as ak
import pandas as pd

STOCKS = [
    ("300308", "中际旭创", "光模块", "产业链角色描述"),
    # ... 更多标的
]

codes = [s[0] for s in STOCKS]
df = ak.stock_zh_a_spot_em()  # 全市场数据，约60秒
result_df = df[df['代码'].isin(codes)].copy()

for code in codes:
    row = result_df[result_df['代码'] == code]
    if row.empty:
        continue
    r = row.iloc[0]
    # 提取：最新价、涨跌幅、成交额、换手率、PE、PB、总市值、量比等
```

**Pitfall**：`stock_zh_a_spot_em()` 拉取全市场数据约需 60 秒（58页，每页约1秒）。不要设 timeout=30，至少 120 秒。

**技术指标计算**（MA/MACD/RSI）需单独获取 K 线数据：
```python
df = ak.stock_zh_a_hist(symbol="300769", period="daily",

                        adjust="qfq")
# 然后用 pandas 计算 MA5/MA10/MA20/RSI14/MACD
```

### Step 4: 个股新闻采集

```python
news = ak.stock_news_em(symbol="300769")  # 稳定可用，不受反爬影响
# 返回：新闻标题、新闻内容、文章来源、发布时间
```

### Step 5: 综合研判

按以下框架组织分析：

1. **行情速览表**：所有标的的实时价格、涨跌幅、PE、PB、市值、成交额、换手率
2. **产业链分层分析**：每一层的核心标的、产业链角色、估值水平、资金动向
3. **价值量分布**：各环节在产业链中的成本占比（用 ASCII 柱状图可视化）
4. **弹性排序**：按"纯正度×弹性×估值合理性"排序
5. **与现有持仓的交叉分析**：用户已有持仓中哪些直接受益

### Step 6: 持仓交叉分析

将概念股与用户现有持仓对比，判断：
- 已有持仓是否覆盖了产业链核心环节
- 是否需要增配某些环节的标的
- 现有持仓的"概念纯度"如何

## 实战案例：超节点算力产业链（2026-07-23）

### 概念背景
华为 CloudMatrix 超节点架构：将多颗昇腾AI芯片通过超高速光互联统一内存编址，逻辑等效一台巨型超算。对标英伟达 NVLink+NVSwitch 的国产替代方案。

### 搜索发现的核心标的及产业链角色
| 标的 | 代码 | 产业链角色 | 来源 |
|------|------|-----------|------|
| 中际旭创 | 300308 | 1.6T光模块主力供应商，硅光设计集成 | 搜索结果 |
| 华工科技 | 000988 | 1.6T液冷光引擎独家配套昇腾950 | 搜索结果 |
| 光迅科技 | 002281 | 自研光芯片，3.2T NPO全场景测试 | 搜索结果 |
| 天孚通信 | 300394 | 柜内柜间高速光互联无源器件 | 搜索结果 |
| 高澜股份 | 300499 | 浸没式液冷适配超节点散热 | 搜索结果 |

### 关键洞察
- 光互联是超节点架构中价值量最大（~35%）、技术壁垒最高的环节
- 华工科技"独家配套昇腾950"使其成为华为超节点生态中最纯正标的
- 工业富联 PE 仅 29 倍 + 万亿市值，是性价比最优的服务器标的
- 用户现有持仓（中际旭创+新易盛+工业富联）已覆盖产业链最肥的三个位置
