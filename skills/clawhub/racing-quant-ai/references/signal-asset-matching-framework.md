# 信号-标的匹配框架

## 用途

对外路演或系统说明时，**不要**从系统架构/数据库结构讲起。用户（昭明）明确要求：**要注重解释有哪些信号，以及信号与资产是怎么匹配的**。

## 核心叙事框架

### 一句话定位

> 从量化策略信号到交易标的的智能匹配引擎。

### 三层信号体系

这是整个系统的核心——系统在三个层面产生信号，层层递进：

| 信号层 | 内容 | 本质 |
|--------|------|------|
| **策略信号** | 36+量化模型持续产生的信号，按来源分4类：量价/基本面/事件驱动/机器学习 | 哪些策略在发出有效信号？ |
| **持仓信号** | 选定策略后读取其最新持仓表，核心是「股票代码→权重」的JSON映射 | 策略信号指向哪些资产？ |
| **交易信号** | 将持仓信号转化为买入/卖出/持有指令，含资金分配和风险过滤 | 最终该买什么、卖什么、买多少？ |

**关键概念**：持仓JSON中的`权重 = 信号强度`。策略模型对某只股票的打分越高，分配权重越大。权重向量就是策略信号在资产层面的量化表达。

### 四层匹配机制

信号与资产的匹配不是简单的「策略A→股票B」的一对一映射，而是一个多层级、可插拔、带风险过滤的匹配体系：

```
用户一句话                             输出结果
    │                                      │
    ▼                                      ▼
┌─────────────┐   ┌─────────────┐   ┌─────────────┐
│ 策略信号层   │ → │ 持仓信号层   │ → │ 交易信号层   │
│             │   │             │   │             │
│ 36+策略模型  │   │ 代码→权重   │   │ 买入/卖出   │
│ NLP匹配策略  │   │ 前10-20只   │   │ 资金分配    │
│ 偏好问答筛选 │   │ 多策略交叉  │   │ 风险过滤    │
└──────┬──────┘   └──────┬──────┘   └──────┬──────┘
       │                 │                 │
       ▼                 ▼                 ▼
  匹配什么策略？     匹配哪些股票？     匹配多少资金？
  ─────────────      ─────────────      ─────────────
  量价/基本面/       权重向量决定       资金×权重
  事件/ML策略        标的优先级         100股取整
```

#### 第一层：用户需求 → 策略信号

三种匹配模式：
- **语义匹配**：用户输入「帮我找中长线稳健策略」，NLP匹配strategy_desc字段
- **互动偏好匹配**：多轮提问（周期/风险/风格/行业）→ 关键词精确匹配
- **分类筛选**：按策略分类或推荐标记直接筛选

#### 第二层：策略信号 → 持仓标的

- 权重 = 信号强度：策略打分越高，权重越大
- 持仓即信号输出：每次调仓就是一次信号更新
- 多策略交叉验证：同一股票被多策略持有 → 信号叠加，置信度更高

#### 第三层：持仓标的 → 深度分析验证

5维度验证信号有效性：
1. 交易数据验证：当前价格、流动性是否支持执行
2. 走势验证：信号发出后股价走势是否符合预期
3. 资金面验证：主力资金是否与策略信号方向一致
4. 基本面验证：财务数据是否支撑策略逻辑
5. 综合验证：多维度交叉验证

**验证的意义**：捕捉信号衰减、发现隐藏风险、提供决策依据。

#### 第四层：验证后标的 → 交易指令

- 资金分配：权重 × 总资金 = 目标金额，100股取整
- 全量换仓：卖出现有持仓中不在目标列表的，买入目标列表中新的
- 限价单执行：买入价=现价×1.005，卖出价=现价×0.995
- 风险过滤：偏离昨收10%以上跳过、低于2000元跳过、单日最大20笔

## 应用场景速查

| 场景 | 用户输入 | 信号匹配链路 |
|------|---------|-------------|
| 日常跟踪 | "今天有什么推荐的策略？" | if_recommended=1 → 策略持仓 → 展示 |
| 深度选股 | "看看短周期ML策略的前5只重仓股" | NLP匹配 → 权重排序取前5 → 实时行情+基本面验证 |
| 交易执行 | "把红利低波策略推送到QMT，资金10万" | 策略权重 → 资金×权重分配 → 100股取整 → 限价单 |
| 定时监控 | 设置每日8:30自动推送 | 定时触发 → 全量策略扫描 → 持仓变化检测 → 推送 |
