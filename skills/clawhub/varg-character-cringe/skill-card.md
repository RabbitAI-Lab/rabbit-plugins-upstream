## Description:

Creates character sheets and a repeatable posting format for photoreal, deadpan AI characters with distinctive looks and recurring actions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and social media teams use this skill to develop an original deadpan AI character sheet and a repeatable format for posts and video.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The documented installer is unpinned, which can make the installed code change over time.

Mitigation: Review the installer and package source before running it, and pin a version where possible.

Risk: Media used in the video workflow may be sent to external services.

Mitigation: Use only media you are comfortable sharing with those services; avoid sensitive or identifiable media unless you have consent and accept that processing.
