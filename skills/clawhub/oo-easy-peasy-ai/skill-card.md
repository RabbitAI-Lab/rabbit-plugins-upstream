## Description:

Easy-Peasy.AI (easy-peasy.ai). Use this skill for ANY Easy-Peasy.AI request — reading, creating, and updating data. Whenever a task involves Easy-Peasy.AI, use this skill instead of calling the API directly.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and other Easy-Peasy.AI users can list available text-generation presets, inspect a preset's inputs, and generate text through their OOMOL-connected account.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: First-time setup may run remote CLI installers whose contents are unverified, and automatic skill synchronization can introduce broader agent changes.

Mitigation: Review and approve CLI installation separately; consider disabling automatic skill synchronization before first use.

Risk: Requests use the connected OOMOL account, and text generation consumes credits.

Mitigation: Check the connected account and credit implications before generating text.
