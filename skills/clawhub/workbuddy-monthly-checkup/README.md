# WorkBuddy 月度体检

> 每月自动读取你的 WorkBuddy 对话记录，从 6 个维度生成诊断报告，帮你发现行为盲区、时间黑洞和目标失焦。

[WorkBuddy](https://www.workbuddy.cn) 生态技能 · [安装](#安装) · [使用](#使用) · [示例报告](#示例报告)

---

## 为什么需要「月度体检」？

你可能有这些困惑：

- 为什么复盘总是在重复同样的问题？
- 为什么系统搭建了很多，业务突破却很少？
- 为什么时间总是不够用，但说不清花在哪了？
- 为什么月初计划信心满满，月末发现完成率很低？

**因为这些问题的答案，藏在你每天的对话记录里。**

「月度体检」自动分析你的 WorkBuddy 对话，从标题、话题、情绪、决策、成长、未完成 6 个维度，给你一份**数据驱动的诊断报告**。

---

## 功能亮点

### 6 维诊断框架

| 维度 | 诊断什么 | 输出 |
|------|---------|------|
| **时间分配** | 系统维护 vs 业务突破 | 时间黑洞识别 |
| **话题焦点** | 北极星目标提及频次 | 目标失焦预警 |
| **决策质量** | 重复问题、悬置决策 | 决策效率评分 |
| **情绪模式** | 焦虑/兴奋/沮丧触发点 | 情绪内耗分析 |
| **成长轨迹** | 认知升级 vs 行动跟进 | 知行合一率 |
| **未完成盘点** | 悬置任务、延迟决策 | 隐性债务清理 |

### 自动执行

- **定时运行**：每月 1 日 08:00 自动生成报告
- **无需手动记录**：对话就是数据源
- **只读不写**：不修改任何原始数据

### 可操作建议

每个维度都给出：
- 立即执行（本月内）
- 纳入下月计划
- 长期优化建议

## 安装

### 前置条件

- WorkBuddy 桌面版（本地对话数据）
- Python 3.9+

### 安装步骤

1. **克隆技能仓库**
   ```bash
   git clone https://github.com/你的用户名/workbuddy-monthly-checkup.git ~/.workbuddy/skills/WorkBuddy\ 月度体检/
   ```

2. **重启 WorkBuddy**
   - 完全退出后重新启动
   - 技能会自动加载

3. **验证安装**
   - 在对话中输入："月度体检"
   - 或："诊断上月对话"

## 使用

### 自动执行

每月 1 日 08:00 自动运行，报告输出到：
```
目标管理/YYYY年/MM月/月度诊断/月度对话诊断报告_YYYY-MM.md
```

### 手动触发

在 WorkBuddy 对话中输入以下任意一句：

- "月度体检"
- "诊断上月对话"
- "生成月度诊断报告"
- "分析我上月的对话"

### 自定义配置

编辑 `scripts/config.json`：

```json
{
  "output_dir": "目标管理/YYYY年/MM月/月度诊断",
  "schedule": "每月1日 08:00",
  "dimensions": {
    "time_allocation": true,
    "topic_focus": true,
    "decision_quality": true,
    "emotion_pattern": true,
    "growth_trajectory": true,
    "backlog_review": true
  }
}
```

## 数据来源

- **对话总数**：603 个
- **时间范围**：2026-09-15 ~ 2026-10-15
- **分析方式**：标题关键词统计 + 分类推断

### 局限性说明

- 基于对话标题推断，未读取正文（保护隐私）
- 情绪识别基于关键词匹配，非语义理解
- 时间估算基于会话数，非精确计时

## 技能体系结合

### 上游依赖

- **conversation-exporter**：对话导出工具（已内置）

### 下游对接

- **目标管理**：诊断报告存入月度诊断目录
- **周度计划**：下月 W1 周规划时参考诊断结论
- **复盘流程**：作为月度复盘的数据源

### 与周度复盘互补

| 维度 | 周度复盘 | 月度体检 |
|------|---------|---------|
| 时间粒度 | 7 天 | 30 天 |
| 数据源 | 滴答清单 + git + 产物 | 全量对话记录 |
| 分析深度 | 执行层面 | 模式识别 |
| 输出形式 | 周复盘 md | 诊断报告 + 行动建议 |
