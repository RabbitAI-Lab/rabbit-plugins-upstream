## Description: <br>
Daily Note Helper organizes rough daily notes, meeting bullets, work logs, and personal reflections into concise daily summaries, todo lists, risk reminders, and next-day plans. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Employees, external users, and other note takers use this skill to turn messy daily records, meeting notes, chat fragments, and end-of-day reflections into a clean daily note. It preserves concrete details, groups related items, marks uncertain points for confirmation, and keeps the default output concise and Chinese-first unless the user requests otherwise. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may process private or sensitive notes when selected for note-like content. <br>
Mitigation: Avoid providing sensitive notes unless the user is comfortable having the agent process that text. <br>
