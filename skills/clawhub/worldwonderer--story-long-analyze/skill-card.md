## Description:

Analyzes long-form web novels chapter by chapter to explain plot, pacing, emotion, characters, relationships, and writing style for authors.

This skill is ready for commercial/non-commercial use.

## Publisher:

[worldwonderer](https://clawhub.ai/user/worldwonderer)

### License/Terms of Use:

MIT-0

## Use Case:

Authors and editors use this skill to examine long-form web novels, assess the opening chapters, and turn chapter-level observations into actionable story and style analyses. It can reuse existing analysis or resume incomplete work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill reads selected manuscripts and existing project analyses and writes persistent summaries, indexes, charts, and style excerpts.

Mitigation: Use only project files you intend to share with the agent and review generated files before distributing them.

Risk: Rebuilding or cleaning an analysis may delete or move existing project files.

Mitigation: Use explicit commands for sensitive work and confirm any rebuild, delete, or move choice before proceeding.
