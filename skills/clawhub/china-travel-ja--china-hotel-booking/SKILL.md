# 中国ホテル予約

## 説明

中国のホテルをリアルタイムで検索し、おすすめ、料金、予約リンクを提供します。中国を訪れる外国人旅行者向けに設計されており、英語と Trip.com の TripGenie API によるホテル情報を提供し、北京、上海、西安、成都、広州など主要都市をカバーします。

## 使用する場面

ユーザーが以下のことを希望する場合に使用します：
- 中国の都市のホテルを探す
- 料金と予約リンク付きのホテルおすすめを取得
- 予算、位置の希望、旅行日でホテルを検索
- 中国旅行のホテルを比較

キーワード：中国 ホテル、北京 ホテル、上海 宿泊、中国 滞在、ホテル予約、予算 ホテル、高級 ホテル

## 実行

### ステップ 1：ユーザーのリクエストからパラメータを抽出

ユーザーのクエリから以下を抽出します：

| パラメータ | 説明 | 例 |
|-----------|------|-----|
| city | 都市名（英語または日本語、必須） | "Beijing" or "北京" |
| check_in | チェックイン日 YYYY-MM-DD（任意） | "2026-08-01" |
| check_out | チェックアウト日 YYYY-MM-DD（任意） | "2026-08-05" |
| guests | 人数（任意、デフォルト：2） | 2 |
| budget | 予算レベルまたは金額（任意） | "1泊100ドル以下" |
| preferences | その他の希望（任意） | " Forbidden City 近く" |

### ステップ 2：スクリプトを実行

```bash
python scripts/china_travel.py hotel "<city>" "[check_in]" "[check_out]" [guests] "[budget]" "[preferences]" --locale=ja
```

**重要：** 常に `--locale=ja` パラメータを含めて、日本語での結果を取得してください。

### ステップ 3：結果を表示

API は構造化された Markdown でホテル名、料金、評価、主な特徴、予約リンクを返します。内容を直接ユーザーに表示します。

結果の最後に、他の機能（航空券検索、観光地検索、旅行プラン、旅行アドバイス）も日本語で案内されます。

## 例

**ユーザー：** "上海でバンド近くの2名用のホテルを探して"
```bash
python scripts/china_travel.py hotel "Shanghai" "" "" 2 "" "near the Bund" --locale=ja
```

**ユーザー：** "北京で7月10日から12日の予算を抑えたホテル"
```bash
python scripts/china_travel.py hotel "Beijing" "2026-07-10" "2026-07-12" 2 "under $80/night" --locale=ja
```

**ユーザー：** "成都で3名用の高級ホテル"
```bash
python scripts/china_travel.py hotel "Chengdu" "" "" 3 "luxury" --locale=ja
```

## 注意

- 都市名は英語または日本語で入力できます
- 日付は任意ですが、空室状況と料金を絞り込むのに役立ちます
- API は自然言語の希望をサポート（例："地下鉄駅近く"、"朝食付き"）
- 予約リンクは Trip.com（国際版）に直接遷移します
- すべての結果は日本語で表示されます
