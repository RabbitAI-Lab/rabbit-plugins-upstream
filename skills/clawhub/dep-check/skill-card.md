## Description:

Helps developers check outdated npm dependencies and plan safer updates.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vexify-build](https://clawhub.ai/user/vexify-build)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to identify outdated npm packages, inspect dependency audit results, and decide when to update packages.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Updating packages can change project behavior or introduce breaking changes.

Mitigation: Confirm proposed updates before running them, commit or back up work, review major-version changelogs, and run tests afterward.
