## Description:

Long-term memory for OpenClaw that stays on your computer. Recall past decisions and save new ones with SuperLocalMemory.

This skill is ready for commercial/non-commercial use.

## Use Case:

OpenClaw users and developers use this skill to recall project decisions and preferences across sessions and save useful facts for later.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Stored memories can include sensitive personal or project details.

Mitigation: Do not save secrets, passwords, or API keys; review and remove stored memories with the provided management commands.

Risk: Setup requires installing a separate package.

Mitigation: Review the external SuperLocalMemory package before installing it.
