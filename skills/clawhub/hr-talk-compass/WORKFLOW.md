# HR 员工谈心完整工作流

> 基于设计思维的"员工对话操作系统"：谈前有准备、谈中有框架、谈后有沉淀、季度有洞察。

---

## 全景图

```
┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
│ 触发信号 │ → │ 谈前准备 │ → │ 现场谈心 │ → │ 谈后复盘 │ → │ OD 沉淀 │
└─────────┘   └─────────┘   └─────────┘   └─────────┘   └─────────┘
   什么时候谈    用什么问题     怎么问怎么听     员工真实状态     组织学到什么
   (半小时)      (quick-brief/deep-dialogue)       (本文件话术)     (review-insights)            (季度汇总)
```

## 第 0 步：触发信号 —— 什么时候该谈

**主动约谈的信号（占谈心总量的 70% 应该是主动触发）：**

| 信号类型 | 具体表现 | 紧急度 |
|---------|---------|--------|
| 绩效异动 | 连续两季度下滑 / 突然冒尖 | ⭐⭐⭐ |
| 行为异动 | 突然安静、请假变多、朋友圈分组、准时下班变加班狂（或反之） | ⭐⭐⭐ |
| 关键节点 | 入职 3/6/12 个月、晋升结果公布后、调岗前后、组织架构调整后 | ⭐⭐ |
| 团队事件 | 核心成员离职、leader 更换、项目失败、年终奖发放后 | ⭐⭐⭐ |
| 周期动作 | 季度/半年度例行一对一、人才盘点后 | ⭐ |

**原则：等到员工提离职再谈 = 已经晚了。谈心的最高价值发生在"信号出现、决定未做"的窗口期。**

## 第 1 步：谈前准备（谈前 1-3 天）

### 1.1 明确谈话目标（自己先想清楚）

一次谈心只设 **一个主目标**，别贪多：

- 🔍 **诊断型**：最近状态不对，我想搞清楚发生了什么
- 🧭 **发展型**：帮他看清职业路径，做成长规划
- 🤝 **保留型**：有流失风险，传递重视、摸清诉求
- 🩹 **修复型**：刚经历负面事件（晋升落选、绩效差评、组织变动），做情绪承接
- 👋 **告别型**：已确定离开，体面收尾 + 获取真实反馈

### 1.2 用 AI 生成提纲

- 常规对话 → 用 `prompts/quick-brief.md`（10 分钟）
- 关键人才 / 高风险 / 你心里没底 → 用 `prompts/deep-dialogue.md`（含模拟陪练）

### 1.3 准备清单

- [ ] 想好开场第一句话（决定整场氛围）
- [ ] 准备 1-2 个你观察到的**具体事实**（不是评价），作为切入
- [ ] 想清楚：这场谈话中，我**不能承诺什么**（预先和公司确认授权边界）
- [ ] 选一个安全的空间（不是工位，不是有玻璃墙的会议室正中央）
- [ ] 预留 45-60 分钟，前后不排紧会

## 第 2 步：现场谈心 —— 四段式对话框架

> 对应人生设计四阶段，但翻译成了 HR 的现场话术。

### 第一段：破冰与仪表盘（5-10 分钟）

**目标：让对方放松，拿到现状基线。**

开场话术（选一句）：
- "今天没有议程，就是想听听你最近怎么样。"
- "我注意到你最近 [具体事实]，想找你聊聊，看看有什么我能帮上的。"

仪表盘提问：
> "如果用 0-10 分，你给最近的工作状态打几分？生活状态呢？身体状态呢？……哪个分最低？为什么是这项？"

**听什么**：最低分维度就是本次谈话的真实入口。员工说"工作 7 分"但语气平淡，比分数本身更值得关注。

### 第二段：挖真问题（15-20 分钟）

**目标：分清重力问题 vs 可设计的真问题。**

核心提问：
> "现在最让你焦虑/消耗的一件事是什么？"

然后做关键区分（心里判断，不要说术语）：

| 员工说的 | 性质 | HR 的姿态 |
|---------|------|----------|
| "整个行业薪资就这样" | 重力问题 | 接纳 + 重新定向："这个确实变不了，那在这个前提下，有什么是能动的？" |
| "我学不到东西了" | 真问题 | 深挖 + 可行动 |
| "我leader不信任我" | 真问题（但需核实） | 深挖具体事件，不轻易站队 |
| "我 30 岁了还没成专家" | 半重力（年龄是现实，路径可设计） | 先接住情绪，再重新定向 |

追问三件套（全程通用）：
- "**具体是哪件事？**"（把模糊的不满落成事实）
- "**那一刻你什么感觉？**"（拿到情绪坐标）
- "**你当时是怎么应对的？**"（看到他的行为模式）

### 第三段：校准方向（10-15 分钟）

**目标：摸清他的指南针和能量地图，判断与公司机会是否同向。**

指南针提问：
> "你工作到底图什么？钱、成长、成就感、影响力、稳定——排个序。"
> "三年后你希望自己变成什么样？（不要说岗位，说状态）"

能量地图提问：
> "最近有没有哪个时刻，你干完活虽然累但很兴奋？当时在做什么？"
> "反过来，什么事你明明做得不错，但做完像被抽干了？"

**听什么**：
- 他兴奋的事 ≈ 他热爱且可能擅长的方向 → 公司能不能给更多？
- 抽干他的事 ≈ 消耗源 → 是岗位结构问题还是个人状态问题？
- 擅长 ≠ 热爱。一个人可以 PPT 做得极好但恨死做 PPT。

### 第四段：收口与原型（5-10 分钟）

**目标：不在谈话里做大决定，只做一个小约定。**

禁忌：❌ 当场承诺晋升/调薪/调岗 ❌ 替员工做人生决定

正确收口话术：
> "今天聊的这些，我不会替你下结论，你也先别急着下结论。我们定一件小事：接下来两周，[一个低成本的原型行动]，两周后我们再碰一次，看看感觉怎么样？"

原型行动示例（低成本、两周内、可逆）：
- 和某岗位的人聊一次（职业访谈，不是要职位）
- 接一个小型跨部门任务试试水
- 把最消耗他的一件事暂停或换种做法试两周
- 写一页"三年后理想中的普通周二"描述

## 第 3 步：谈后复盘（谈后 24 小时内）

1. 趁记忆新鲜，把对话要点写下来（**记录员工原话，不是你的概括**）
2. 用 `prompts/review-insights.md` 让 AI 出《谈心分析报告》
3. 归档：建议路径 `谈心档案/{员工代号}_{日期}_复盘.md`
4. 行动分三栏落实：
   - **HR 可做**（你自己能动手的）
   - **需上级/公司配合**（去推动的，明确找谁、什么时候前）
   - **员工本人的原型**（两周后跟进检查）

**两周跟进是灵魂。** 谈完不跟进 = 白谈，还透支信任。

---

## 第 4 步：OD 沉淀（每月/每季度）

### 月度：单点回顾
- 这个月谈了几场？触发信号分布？
- 多少个"两周跟进"闭环了？多少烂尾了？

### 季度：横向分析（用 review-insights 的汇总模式）
把本季度所有复盘报告喂给 AI，让它回答：
1. **共性真问题**：多少个员工提到了同一件事？（如"成长停滞"出现 5 次 → 这不是个人问题，是组织问题）
2. **重力问题清单**：哪些是员工反复抱怨但公司确实改不了的？→ 管理层沟通口径要统一，别画饼
3. **能量错配地图**：哪些岗位/团队普遍出现"擅长但被抽干"？→ 组织设计问题
4. **流失风险热力图**：按团队/层级/司龄分布
5. **给管理层的 3 条建议**：每条都要有依据（来自具体谈心信号，脱敏后）

## 常见问题 FAQ

**Q: 员工什么都不说怎么办？**
A: 不逼。换具体事实切入："我注意到你上周三的会上一直没说话，这不像你。" 还不开口就接纳沉默："没关系，你想说的时候随时找我。" 沉默本身也是信息——信任还没到。

**Q: 员工当场哭/情绪崩溃怎么办？**
A: 暂停框架。递纸、倒水、陪着，不急着"解决问题"。情绪过去后只问一句："现在你想聊，还是想先回去休息？" 事后评估是否需要转介 EAP。

**Q: 员工直接提离职怎么办？**
A: 先听完，不挽留、不施压。问："这个决定里，有没有什么是如果改变了你会重新考虑的？" 有 → 进入保留谈判（确认授权后）；没有 → 转向体面告别 + 挖真实反馈。

**Q: 员工要求的超出了我的权限怎么办？**
A: 诚实说边界："这个我定不了，但我可以帮你去争取/问清楚，周三前给你答复。" 然后**一定要在承诺时间内回复**，哪怕答复是否定的。

**Q: 和员工关系太好，谈不出真东西？/ 关系太僵，他防着我？**
A: 关系好 → 用 deep-dialogue 模拟陪练，练"如何温柔地戳破"；关系僵 → 降低目标，第一次谈心只求"他愿意再和我谈第二次"。
