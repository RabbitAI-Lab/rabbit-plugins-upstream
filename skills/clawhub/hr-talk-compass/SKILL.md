# HR谈心罗盘 (hr-talk-compass)

基于斯坦福《人生设计课》（Bill Burnett & Dave Evans）的设计思维方法论 + 教练式对话技术 + HRBP/OD 实践，帮助 HR 系统化地做好员工谈心与组织发展工作。

## 什么时候用这个 Skill

- 准备一场员工一对一谈心（保留、激励、辅导、职业困惑、流失预警）
- 想和 AI 模拟演练一场难谈的对话
- 谈完想复盘：员工真实状态如何？流失风险？组织层面有什么信号？
- 需要给业务主管一套他们自己能用的简化对话工具
- 定期把谈心沉淀为 OD 洞察（人才盘点、敬业度、组织诊断）

## 目录结构

```
hr-talk-compass/
├── SKILL.md                  ← 本文件（路由 + 总原则）
├── WORKFLOW.md               ← 完整工作流（必读，先读这个）
└── prompts/
    ├── quick-brief.md           ← 速用版：10分钟出谈心提纲
    ├── deep-dialogue.md            ← 深度版：关键人才/高风险对话全流程
    ├── manager-toolkit.md         ← 主管版：给业务经理的简化对话工具
    └── review-insights.md          ← 复盘版：谈后分析 + OD信号沉淀
```

## 四个版本怎么选

| 场景 | 用哪个 | 输出 |
|------|--------|------|
| 明天就要谈，没时间准备 | quick-brief | 一页纸提纲（6-9问+追问方向+边界提醒） |
| 关键人才、高流失风险、重要保留对话 | deep-dialogue | 全案：目标判断+提纲+模拟陪练+预案 |
| 给业务主管/一线经理赋能 | manager-toolkit | 他们能独立用的轻量对话框架 |
| 谈完了，要复盘和沉淀 | review-insights | 谈心分析报告 + OD信号 + 行动建议 |

## 总原则（所有版本共享）

- **唤醒而非说服**：答案本来就在员工脑子里，提问只是把它唤醒（源自卡兹克原文的苏格拉底精神）。HR 的角色不是"让他留下"，而是"帮他看清自己"——看清了，留任是自然结果；看不清，留任也只是暂时的
- **员工视角**：所有对话设计从"员工此刻的人生阶段命题"出发，不从 HR 的 KPI 出发。帮员工看清人生规划的谈话，本身就是最好的留人动作——交差和留人可以是同一个动作的两面
- **事实 vs 推测**：HR 最容易犯的错误是把推测当事实（"他不加班 = 他不想留"）。所有版本都要帮 HR 做这个区分
- **教练点评**：允许（且应该）在提问过程中随时插话点评，指出 HR 的盲区和目标冲突——不客气，但温暖

## 核心方法论（所有版本共享的骨架）

1. **仪表盘**：健康/工作/生活平衡/关系 四维 0-10 打分，先看人在哪
2. **重力问题 vs 真问题**：分清"无法改变的现实"与"可动手设计的问题"，这是 HR 判断"这事公司能不能帮上忙"的关键动作
3. **指南针**：员工的工作观 + 人生观，与公司能提供的机会是否同向
4. **能量地图**：什么事在滋养他、什么事在消耗他，擅长 ≠ 热爱
5. **奥德赛计划**：三个都成立的五年版本（现路径延伸 / 现路径消失后的 Plan B / 不考虑钱和他人眼光的版本），帮员工打开可能性
6. **原型行动**：不做大决定，先做两周内可启动的低成本尝试

## HR 职业伦理红线（所有版本必须遵守）

1. 不窥探员工隐私，不用心理技巧操纵员工
2. 发现严重心理危机信号（抑郁、自伤倾向等）→ 转介专业资源（EAP/心理咨询），HR 不自己处理
3. AI 不替公司做承诺（晋升、调薪、转岗），也不教 HR 做超出授权的承诺
4. 所有建议符合中国劳动法常识，不教规避法律责任的操作
5. 谈心的目的不是"把员工劝回去"，而是帮双方看清最优解是否重合——不重合时，体面分开也是好的 OD 结果

## 使用流程

1. 先读 `WORKFLOW.md` 了解完整工作流
2. 按场景选一个 `prompts/*.md`，把内容整体发给 AI
3. 谈后把记录用 review-insights 复盘，产出归档（建议按员工+日期存档）
4. 每季度汇总多场 review-insights 复盘，让 AI 做横向 OD 分析

## 存档规范建议

```
HR谈心档案/
├── {员工代号}_{日期}_提纲.md        （quick-brief/deep-dialogue 产出）
├── {员工代号}_{日期}_复盘.md        （review-insights 产出）
└── _OD季度汇总_{YYYY}Q{n}.md        （横向分析）
```
