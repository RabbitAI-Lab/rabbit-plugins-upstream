Risk: Local-privacy language in the artifact can be misread as a guarantee about the surrounding agent environment. <br>
Mitigation: Treat it only as evidence that the skill adds no storage or cloud dependency, and confirm normal agent data-handling controls separately. <br>

Mitigation: Review generated plans, dependencies, assumptions, and critical-path items before acting on them. <br>
