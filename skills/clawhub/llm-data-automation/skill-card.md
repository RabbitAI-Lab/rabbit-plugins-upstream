## Description: <br>
Automate construction data processing using LLM (ChatGPT, Claude, LLaMA). Generate Python/Pandas scripts, extract data from documents, and create automated pipelines without deep programming knowledge. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[datadrivenconstruction](https://clawhub.ai/user/datadrivenconstruction) <br>

### License/Terms of Use: <br>
MIT <br>


## Use Case: <br>
Construction professionals, analysts, and developers use this skill to turn project data, documents, BIM exports, schedules, and cost inputs into Python/Pandas workflows, structured summaries, reports, and exportable datasets. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can work with local files and construction documents that may contain confidential project data. <br>
Mitigation: Point the skill only at approved files or folders, and use approved local or private models for confidential documents. <br>
Risk: Generated Python/Pandas scripts may transform data incorrectly or damage important working files if run without review. <br>
Mitigation: Review generated scripts before execution and test them on copies of important datasets first. <br>
Risk: Indexing broad company document folders may expose or process data outside the user's authorization. <br>
Mitigation: Index only specific document sets that the user has permission to process. <br>
