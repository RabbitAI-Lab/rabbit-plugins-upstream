# Watch Schema · 观看协议（Phase 1）

Agent 为每一集生成一份 `watch.json`，描述**观看策略**与**注意点**。它不产生练习卡（看剧是消费），但必须作为 artifact 出现在所有交付物（HTML/Anki 除外纯回忆卡/Excel/Word）里，保证四格式在"七阶段"集合上一致。

## 字段

```json
{
  "protocol": [
    {
      "pass": 1,
      "name": "无字幕抓大意",
      "instruction": "先关字幕看一遍，只抓谁、在哪、发生什么，允许听不懂。"
    },
    {
      "pass": 2,
      "name": "开字幕抓细节",
      "instruction": "开着字幕看，对照不懂的词句，注意连读/弱读/语调。"
    },
    {
      "pass": 3,
      "name": "无字幕再听",
      "instruction": "再关字幕看一遍，检验刚学的词是否 now 听懂。"
    }
  ],
  "notice": [
    "合成音(TTS)只是发音参照，真实原速听力请观看正片。",
    "本工具不替代看剧，观看正片才是听力提升的主场。"
  ]
}
```

## 规则
- `protocol`：3 遍字幕法固定；`name`/`instruction` 可针对剧集类型微调（情景喜剧强调笑点/谐音，罪案剧强调信息密度）。
- `notice`：1–3 条诚实提醒，**必须包含 TTS≠原声 与 看正片为主场**两条。
- 若用户未提供 `watch.json`，`export_hub.py` 使用内置三步字幕法默认协议（不报错）。
- 该阶段**不产出回忆卡**（消费型，无记忆项）；Anki 模式自然不含 Watch，属设计性差异。
