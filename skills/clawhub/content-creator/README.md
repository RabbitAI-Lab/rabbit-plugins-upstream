# Content Creator — 内容创作者技能库

> 面向独立内容创作者、YouTuber、播客主和短视频创作者的技能集合。从策划到发布，覆盖视频/音频/社交媒体内容全流程。

## 技能清单

| 技能 | 描述 | 安装量 | 来源 |
|------|------|--------|------|
| video-editing | 视频编辑：剪辑流程、转场设计、色彩分级、字幕制作、多格式导出 | 7.3K | [skills.sh](https://skills.sh/affaan-m/everything-claude-code/video-editing) |
| youtube-automation | YouTube 运营：SEO优化、缩略图策略、数据分析、发布排期 | 4K | [skills.sh](https://skills.sh/claude-office-skills/skills/youtube-automation) |
| short-video-script | 短视频脚本：Hook设计、节奏控制、故事弧线、平台适配 | 2.3K | [skills.sh](https://skills.sh/mebusw/awesome-jackyshen-skills/jackyshen-gen-short-video-script) |
| podcast-generation | 播客制作：选题策划、采访设计、后期编辑、分发 | 1.9K | [skills.sh](https://skills.sh/bytedance/deer-flow/podcast-generation) |
| newsletter | 新闻简报：选题策划、多源检索策展、结构编排（日报/周报/深度/行业简报）、语气校准、可发布 Markdown | 1.4K | [skills.sh](https://skills.sh/bytedance/deer-flow/newsletter-generation) |

## 工作流

```
短视频脚本 ──→ 视频编辑 ──→ YouTube 运营
 (策划)        (制作)       (发布分析)
               └─→ 播客制作
                   (音频)
```

## 安装

```bash
# 安装全部内容创作技能
npx skills add skills-repo/content-creator -g -y

# 或按需安装单个技能
npx skills add skills-repo/content-creator@video-editing -g -y
npx skills add skills-repo/content-creator@youtube-automation -g -y
npx skills add skills-repo/content-creator@short-video-script -g -y
npx skills add skills-repo/content-creator@podcast-generation -g -y
npx skills add skills-repo/content-creator@newsletter -g -y
```

## 与本组织其他仓库的关系

- **writer-studio** — 文字内容创作（文章、文案、SEO），本仓库聚焦视频/音频
- **marketing-master** — 入站营销，本仓库聚焦内容制作而非营销策略
- **office-master** — 办公效率，本仓库聚焦媒体内容而非办公文档
