# Short Video Script — 短视频脚本

> 短视频不是把长视频剪短。前 0.5 秒抓不住注意力，用户就滑走了。本技能帮你写出让人停下来、看下去、点了赞的短视频脚本。

## 能力

- **Hook 设计**：前 3 秒的 7 种钩子模式（问题、反常识、悬念、结果前置、挑战、对比、情感）
- **节奏控制**：信息密度分布、画面切换频率、留白技巧
- **故事弧线**：3 段式（Hook → Build → Payoff）和 5 段式（Hook → Problem → Solution → Proof → CTA）
- **平台适配**：TikTok (9-60s) / Reels (15-90s) / Shorts (15-60s) 的时长和风格差异
- **口播优化**：语速控制、关键词强调、自然停顿、避免书面语
- **CTA 设计**：关注/点赞/评论/分享的引导，平台推荐机制配合

## 使用方式

在 Claude Code 中使用 `/short-video-script` 调用。

```
/short-video-script 帮我写一个 30 秒的产品功能介绍短视频脚本
/short-video-script 我这个 Hook 太弱了，帮我重写 3 个版本
/short-video-script 把这个 2 分钟的内容压缩到 60 秒
```

## 工作流

1. **目标定义** — 想传递什么信息？想让观众看完做什么？
2. **Hook 打磨** — 写 3-5 个 Hook 变体，选最强的
3. **脚本撰写** — Hook → 核心内容 → CTA，标注画面/字幕/时长
4. **口播练习** — 大声读出来，检查语速和自然度
5. **发布测试** — 发布后分析完播率和互动数据

## Hook 公式

```
问题式：  "你知道为什么你的视频没人看吗？"
反常识：  "每天发 3 条视频比发 1 条效果差"
悬念式：  "这个功能上线后，我们的转化率翻了一倍——但我差点把它砍掉"
结果前置： "3 个月从 0 到 10 万粉丝，只用了这个方法"
```

## 适用场景

- 独立创作者制作 TikTok/Reels/Shorts 内容
- 创业者用短视频做产品获客
- 技术内容创作者做知识科普短视频
- 品牌方搭建短视频内容矩阵

## 限制

- 聚焦脚本撰写，不涉及拍摄、剪辑、特效制作
- 覆盖 TikTok/Reels/Shorts 三大平台，不涉及小红书/快手
- 不涉及付费投流和广告创意脚本
- 不涉及直播脚本（直播节奏和互动模式不同）
