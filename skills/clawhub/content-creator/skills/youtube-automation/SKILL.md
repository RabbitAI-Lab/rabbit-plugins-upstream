# YouTube Automation — YouTube 运营自动化

> YouTube 不只是上传视频——标题、描述、标签、缩略图、发布时间，每一个环节都影响点击率和观看时长。本技能帮你系统化运营 YouTube 频道，让内容被更多人看到。

## 能力

- **频道管理**：频道设置、播放列表组织、社区互动、品牌一致性
- **SEO 优化**：标题关键词研究、描述模板、标签策略、字幕 SEO
- **缩略图策略**：A/B 测试框架、高 CTR 缩略图设计原则、文字叠加规则
- **数据分析**：CTR/AVD/留存曲线解读、流量来源分析、受众画像
- **发布排期**：最佳发布时间窗口、发布频率策略、节日/热点日历
- **内容策略**：内容类型组合（教程/评测/娱乐）、系列化 vs 独立视频

## 使用方式

在 Claude Code 中使用 `/youtube-automation` 调用。

```
/youtube-automation 分析我的频道数据，找出增长瓶颈
/youtube-automation 帮我优化这条视频的标题和描述
/youtube-automation 设计一个月的发布排期
```

## 工作流

1. **频道审计** — 当前数据基线、竞品频道对标、增长机会点
2. **内容规划** — 选题研究 → 关键词 → 标题/缩略图方案
3. **SEO 配置** — 标题/描述/标签/字幕/章节标记
4. **发布执行** — 排期 → 首小时观察 → 社区互动
5. **复盘迭代** — 视频表现分析 → 优化方向 → 下一条改进

## YouTube 关键指标

```
CTR (Click-Through Rate)：    标题+缩略图是否吸引人（>5% 为佳）
AVD (Average View Duration)： 内容质量（>50% 为佳）
Retention Curve：             哪里观众走了（前 30 秒最关键）
Impressions：                 算法推荐力度
Subscriber Conversion：       订阅转化率
```

## 适用场景

- 独立创作者从 0 开始运营 YouTube 频道
- 已有频道的增长瓶颈分析和突破
- 企业/产品通过 YouTube 做内容营销
- 视频发布流程的标准化和自动化

## 限制

- 聚焦 YouTube 平台，不涉及 B站/抖音等其他视频平台
- 不涉及视频拍摄和剪辑（那是 video-editing 的范围）
- 数据分析基于 YouTube Studio，不涉及第三方高级分析工具
- 不涉及 YouTube 广告投放（Google Ads）
