# Newsletter — 新闻简报 / 邮件通讯

> 简报不是把新闻堆在一起。它要"替读者省时间"：从多个信源挑出值得看的，加上你自己的判断，排成扫一眼就懂的结构。本技能帮你产出一份可直接发布的 Markdown 简报。

## 能力

- **选题与定位**：明确主题、受众（技术/高管/大众）、语气、长度、栏目数、是否系列化
- **多源检索策展**：按时间窗检索，按时效性/权威性/独特性/可行动性筛选信源，提取事实与数据
- **结构编排**：日报 / 周报 / 深度 / 行业简报 四种骨架任选，落点清晰、可扫读
- **语气校准**：技术（精确、不解释术语）/ 高管（影响、战略、底线）/ 大众（类比、通俗）三档切换
- **来源归因**：每条事实给内联链接，透明溯源，建立信任
- **可发布产出**：完整 Markdown，适配邮件平台 / 网页发布 / 转 HTML

## 使用方式

在 Claude Code 中使用 `/newsletter` 调用。

```
/newsletter 帮我做一期 AI Agent 周报，面向技术读者，8 个栏目
/newsletter 把这个话题做成行业简报，给投资人看，偏战略视角
/newsletter 我有一组链接，帮我策展成一期深度简报
```

## 工作流

1. **规划**：定主题 / 格式 / 受众 / 语气 / 长度 / 栏目数（见 [references/newsletter-playbook.md](../../references/newsletter-playbook.md) 决策树）
2. **检索策展**：用当前日期做时间锚点，多源检索 → 按六维标准筛 5–8 条优质内容
3. **写作**：头条写 Hook + 事实 + 为什么重要 + 来源；快讯写"粗体标题 + 2–3 句 + 链接"
4. **组装**：套用所选格式骨架，加页眉页脚，过发布前检查清单

## 格式骨架（速查）

- **日报**：头条 1 条 + 快讯 3–5 条 + 今日一句（数据/金句）+ 关注
- **周报**：编者按 + 头条 2–3 条 + 趋势分析 1–2 条 + 快讯 4–6 条 + 工具资源 + 收尾
- **深度**：背景 + 关键进展（详析）+ 多方视角 + 下一步 + 延伸阅读
- **行业简报**：执行摘要 + 市场动态 + 公司动向 + 产品技术 + 政策监管 + 数据指标 + 展望

## 适用场景

- 独立创作者 / 团队做周更或日更简报（技术、行业、创投、AI 等垂直领域）
- 把一组文章 / 链接策展成一期有观点的通讯
- 面向订阅者产出可邮件分发或可网页发布的 Markdown

## 限制

- 聚焦"策展 + 写作 + 编排"，不替代邮件发送平台（Substack / Kit / Mailchimp 等）的投递
- 不总结付费墙内读者无法访问的内容
- 事实必须可溯源；不确定的数据标注"据 X 报道"，不编造数字
- 时效性依赖检索质量：务必用 `<current_date>` 做时间锚点，不写死年份
