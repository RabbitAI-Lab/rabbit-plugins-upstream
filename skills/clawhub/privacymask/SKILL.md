# Privacymask - 数据脱敏与隐私保护助手 v1.1.0

## 能为你做什么

| 场景 | 操作 |
|------|------|
| 上传文件前脱敏 | 检测并脱敏单个文件或文件夹中所有敏感信息 |
| 仅预览不修改 | 只检测敏感项，不输出脱敏副本 |
| 自定义规则 | 添加业务特有的敏感字段规则（如合同编号、内部编号） |
| 导出检测报告 | 将检测结果导出为 JSON/CSV 报告 |
| **敏感数据分级** | 按 L3(高敏感)/L2(中敏感)/L1(低敏感) 自动分类分级，一键评估风险 |
| **脱敏差异报告** | 生成「原始值 → 脱敏后」逐一对比报告（Markdown/JSON/CSV），合规审计必备 |

## 支持的文件格式

| 格式 | 说明 |
|------|------|
| TXT/MD/LOG/HTML/XML | 纯文本直接脱敏 |
| CSV/TSV | 逐单元格脱敏，保留格式 |
| JSON/YAML | 递归脱敏所有字符串值 |
| DOCX | 段落+表格文本脱敏，保留格式 |
| XLSX/XLS | 逐单元格脱敏，保留公式和格式 |
| PPTX | 幻灯片文本脱敏，保留布局和图片 |
| PDF | 文本红笔遮罩脱敏 |

## 敏感数据分级体系

| 等级 | 说明 | 典型数据 | 保护要求 |
|------|------|---------|---------|
| **L3 高敏感** | 健康数据/支付凭证/证件号码 | 病历、SSN、CVV、护照、驾驶证 | 必须最高级别脱敏，禁止测试环境使用 |
| **L2 中敏感** | 个人身份信息 | 姓名、手机号、身份证、邮箱 | 常规脱敏，可在受控环境使用 |
| **L1 低敏感** | 企业信息/业务标识 | 企业名称、统一社会信用代码 | 基础脱敏即可 |

## 脱敏差异报告

支持三种格式，可用于合规审计、变更评审、效果确认：

| 格式 | 特点 | 适用场景 |
|------|------|---------|
| **Markdown** | 按敏感度分级分组，含原始值/脱敏后/位置 | 人工评审、邮件报告 |
| **JSON** | 结构化数据，含 sensitivity 字段 | 系统集成、自动化处理 |
| **CSV** | 标准表格，含 type/rule/original/masked/location/sensitivity | 数据分析师导入 |

## 安全承诺

- **零网络上传**：所有处理在本地执行，不调用任何外部 API
- **原文件不变**：只生成脱敏副本，原始文件完全不受影响
- **完整报告**：每次脱敏后输出发现项统计（类型、数量、位置）
- **合规覆盖**：符合 GB/T 37964-2019、GB/T 45574-2025、PIPL、GDPR、PCI DSS 等法规要求
