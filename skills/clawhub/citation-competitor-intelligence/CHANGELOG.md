# Changelog

## [0.1.0] - 2026-07-31

### Added
- Initial release of citation-competitor-intelligence skill
- 7-step workflow: anchor → backward mining → forward mining → similarity filter → benchmark → author-to-company → competitor matrix
- Bidirectional support: forward (paper→competitors) and reverse (company→academic competitors)
- Similarity filtering with 4-criterion scoring to separate genuine competitors from tangential citations
- Commercialization indicator checklist (Level 0-4) with patent, company, funding, product evidence
- Competitor threat assessment with weighted scoring (tech × IP × commercialization × momentum)
- Bridge integration reference to patent-gap-supply-chain skill
- Real case study: 陈开鑫 (stepped SSC) vs 薄方 (wedge SSC) — spot-size converters in silicon photonics
