## 📖 测算原理

小六爻（小六壬）源自诸葛亮"马前课"，是道家简便速断之法。通过农历月、日、时辰三步推算，在六个掌诀位上顺时针循环：

```
大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡
```

**三步推算法：**
1. **月上起日** — 从大安起正月，顺数至当月
2. **日上起时** — 从月落宫起初一，顺数至当日
3. **时上查掌诀** — 从日落宫起子时，顺数至当时
