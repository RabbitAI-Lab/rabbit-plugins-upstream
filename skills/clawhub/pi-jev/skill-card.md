## Description:

为新任务推荐配套技能及命令、建议模型档位，并记录使用情况供每周复盘。

This skill is ready for commercial/non-commercial use.

## Publisher:

[lichengyu1207](https://clawhub.ai/user/lichengyu1207)

### License/Terms of Use:

MIT-0

## Use Case:

Users choosing among four companion skills can get a task-based recommendation, a suggested model tier, and a weekly summary of locally recorded use.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Initial setup asks users to share a unique installation ID with the publisher for registration.

Mitigation: Review the registration request before sharing the ID; the script does not send it automatically.

Risk: Normal use stores task descriptions and notes in a local usage log.

Mitigation: Avoid entering confidential client, business or personal details unless local logging is acceptable.
