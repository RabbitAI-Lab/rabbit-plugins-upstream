# 想法压力测试 · 思维框架速查

本文件是「来怼一下」技能调用的渐进披露资源。在开怼时按需参考，不必全量加载。

---

## 1. 六顶思考帽（多视角快速过一遍）

- **白帽（事实）**：数据/证据可靠吗？缺什么证据？哪些说法是未经证实的？
- **红帽（直觉）**：第一反应的风险感 / 违和感是什么？情绪信号往往先于逻辑。
- **黑帽（风险）**：最坏情况是什么？致命缺陷在哪？哪里会彻底翻车？
- **黄帽（价值）**：真实成立、站得住的卖点到底是什么？
- **绿帽（替代）**：有没有更优 / 更省 / 更简单的做法？别人怎么解？
- **蓝帽（流程）**：整体框架对吗？前提假设本身是否成立？

## 2. 预演失败 Pre-mortem

假设未来这个想法**已经彻底失败**，倒推最可能的原因。

> 逼问句式："假设半年后它黄了，最可能是哪三个原因？"

价值：绕过"证明它能成"的乐观惯性，直接找死因。

## 3. 第一性原理 First Principles

剥离一切类比、"行业都这么做"、惯例、权威，追问最底层的假设是否成立。

> 逼问句式："抛开'别人都这么做'，你这个想法最底层的假设是什么？它还成立吗？"

## 4. 红队 / 对手视角

站在攻击者、竞争对手、恶意用户、监管方的立场找漏洞。

> 逼问句式："如果你的对手想搞垮它，会从哪下手？""一个想钻空子的人会怎么利用它？"

## 5. 确认偏差 Confirmation Bias

用户常带着"我想证明它行"的预设进场，只收集支持证据。

> 逼问句式："有什么证据会推翻你的结论？你愿不愿意主动去找反例？"

## 6. 反面论证 / 证伪 Falsification

先假设想法是错的，去收集证伪证据；能证伪才说明想清楚了。

关键陷阱：**A 坏 ≠ 非A 好**——指出某条规则/做法不好很容易，但给出"那该怎么做"的正确替代很难，回测/论证常止步于证伪、给不出正解。

## 7. 类比迁移 Analogy

这个想法在别的领域是不是已经被证伪 / 验证过？有没有相似先例值得借鉴或警惕？

> 逼问句式："这件事在别的地方是不是早有人试过、结果如何？"

## 常犯逻辑陷阱（开怼时主动排查）

| 陷阱 | 说明 |
|---|---|
| 宣称价值 ≠ 真实价值 | "帮人赚钱"可能是伪命题；看着有价值可能是安慰剂甚至负价值 |
| 证伪易、替代难 | 指出坏规则容易，给出正确替代难（A 坏 ≠ 非A 好） |
| 历史成立 ≠ 未来成立 | 过拟合、市场状态（regime）依赖、环境变化 |
| 自报 ≠ 真实 | 用户填的画像 / 偏好常自欺（风险承受高估、预期虚高） |
| 相符 ≠ 更好 | 符合预期 ≠ 跑赢基准；"自洽"不代表"更优" |
| 镜子 vs 裁判 | 给偏差（镜子）vs 给结论（裁判）——后者易越界替用户下判断、踩合规红线 |
| 小样本 / 区间选择 | 用一小段漂亮历史论证，统计上不显著 |
| 幸存者偏差 | 只看"活下来"的样本，系统性低估危害 |
| 前视偏差 | 偷偷用了当时还看不到的未来信息 |

## 杀伤力分级（用于排序输出）

- 🔴 致命：让结论直接骗人 / 归零 / 产生负价值
- 🟠 严重：核心逻辑链断裂
- 🟡 中等：削弱价值或适用范围
- 🟢 较轻：体验 / 细节问题
- 🔵 补刀：角度 / 措辞层面的尖锐提醒
