## Description:

Inspect and manage UniFi Network infrastructure with the unifly CLI: devices, clients, VLANs, WiFi, firewall, VPN, switch ports, site settings, and cloud fleets.

This skill is ready for commercial/non-commercial use.

## Use Case:

Network administrators and infrastructure developers use unifly to inspect, monitor, configure, and troubleshoot UniFi Network infrastructure, including devices, clients, VLANs, WiFi, firewall, VPN, switch ports, site settings, and cloud fleets. It does not manage UniFi Protect cameras or recordings.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Network configuration changes may disrupt connectivity or affect the wrong site or devices.

Mitigation: Consult the installed `unifly skill` guide's inspection and change workflows, and confirm the target and intended settings before applying changes.
