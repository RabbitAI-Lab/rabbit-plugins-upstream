## Description:

Helps agents inspect, configure, and troubleshoot UniFi Network infrastructure through the unifly CLI, excluding UniFi Protect cameras and recordings.

This skill is ready for commercial/non-commercial use.

## Publisher:

[hyperb1iss](https://clawhub.ai/user/hyperb1iss)

### License/Terms of Use:

MIT-0

## Use Case:

Network administrators and developers use this skill to inspect devices and clients, monitor sites, troubleshoot UniFi networks, and make network configuration changes through the installed CLI.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Network configuration changes could disrupt connectivity or security controls.

Mitigation: Review planned changes and use a least-privileged UniFi account.

Risk: CLI behavior and authentication steps may differ between installed versions.

Mitigation: Verify the CLI source and version, then run `unifly skill` to review current workflows before use.
