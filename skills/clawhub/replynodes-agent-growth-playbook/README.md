# Agent Growth Playbook

A read-only, evidence-led workflow for planning growth and distribution experiments for AI-agent products, skills, MCP servers, and developer workflows.

## Scope

The skill researches public sources, maps the discovery-to-retention funnel, compares alternatives, and produces an approval-ready experiment backlog. It never posts, schedules, sends messages, buys ads, handles credentials, or edits external records.

## Install

Install the published ClawHub skill with:

```text
clawhub install replynodes-agent-growth-playbook
```

Review the skill's safety boundaries before use. Public-source availability and registry metadata can change; treat cited observations as time-bound.
