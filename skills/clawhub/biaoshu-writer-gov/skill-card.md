## Description:

智能投标文件写作 helps agents interpret Chinese tender documents, generate editable bid document drafts, and run compliance or similarity checks through the 百炼®标书 cloud service after user consent.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and proposal teams use this skill for mainland-China bidding workflows: extracting scoring and hard requirements from tender files, drafting bid documents, and reviewing bid files for rejection risks before submission.

### Deployment Geography for Use:

Mainland China

## Known Risks and Mitigations:

Risk: Tender and bid documents may contain commercial, pricing, or personal information and are uploaded to biaoshu.zhiliaobiaoxun.com for processing.

Mitigation: Use the skill only after the user understands and agrees to that upload and retention behavior, and only with files the user explicitly provides.

Risk: The App Key is a full account credential stored in local config.json.

Mitigation: Do not request, paste, repeat, or expose the App Key in chat; keep the local credential file protected and reset the key if it is exposed.

Risk: Generating bid documents may consume account credits.

Mitigation: Confirm the user is comfortable using the App Key account and check balance or credit impact before generation.

Risk: Custom service or output-path settings can redirect network calls or file writes.

Mitigation: Keep ZCM_BASE and output-path settings pointed only to intended destinations.
