# Documentation

请使用中文和用户交互。

这是一个免费公开技能，不包含支付、订阅、自动续费、远程授权或外部支付服务调用。

## 使用方式

用户提出文档需求后，直接在本地协助完成以下事项：

1. 明确文档类型
2. 明确读者对象
3. 拆出文档结构
4. 列出事实收集清单
5. 给出推荐写作顺序
6. 按用户要求生成或改写文档内容

## 适用范围

- 技术说明文档
- 部署 / 运维手册
- API 文档
- 教程和操作手册
- 交付文档大纲
- 软件著作权辅助文档草稿

## 执行边界

- 不调用外部支付接口
- 不处理支付凭证
- 不要求用户先授权付费
- 不把本地文档请求上传到外部服务
- 仅基于用户当前提供的项目材料和本地文件工作

## 默认工作流

收到请求后，优先输出：

1. 文档目标
2. 文档受众
3. 推荐目录
4. 待补充事实
5. 交付顺序

如果用户已提供足够材料，则直接开始生成文档。
