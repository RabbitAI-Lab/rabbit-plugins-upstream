## Description: <br>
A free Chinese-language documentation assistant for local technical documentation, operating manuals, deployment notes, API descriptions, delivery outlines, fact-gathering checklists, and writing-order guidance. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[jinyu12166](https://clawhub.ai/user/jinyu12166) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, operators, and delivery teams use this skill to structure, draft, and revise Chinese technical documentation from user-provided project materials and local files. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated or revised documentation may contain inaccurate or incomplete project details. <br>
Mitigation: Review generated content against source materials and have a project owner confirm factual claims before release. <br>
Risk: The skill may read local project files when the user asks it to work from them. <br>
Mitigation: Scope use to intended project directories and avoid providing sensitive files that are not needed for the documentation task. <br>
