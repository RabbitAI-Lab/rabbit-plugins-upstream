# 输出总结模板

清理完成后，生成包含以下章节的总结文档。

---

## 清理效果表

| 指标 | 说明 |
|------|------|
| 删除文件数 | 按类型分组（组件层 / 服务层 / 工具层 / 资源层） |
| 删除函数数 | 若有函数级部分删除 |
| 删除代码行数 | 来自 `git diff --stat` |
| 原始代码总行数 | 删除前源码目录总行数 |
| 清理后代码总行数 | 删除后源码目录总行数 |
| 清理率 | 删除行数 / 原始行数 × 100% |
| 图谱节点变化 | before → after（差值） |
| 图谱边变化 | before → after（差值） |
| 受影响外部符号 | 来自 `detect_changes` 结果 |

## 删除清单

列出所有被删除的文件，按层次分组：
- 组件
- 服务
- 工具
- 资源

## 修改清单

列出被修改但未删除的文件（如 config.js 中移除了 import）。无内容则不展示此章节。

## 建议人工复核

若清理涉及表外语言（即不在语言参考模式表中的语言），列出被标记为「需人工复核」的文件。这些文件的 L-dynamic 和 L-reflection 层无法自动化验证，需要人工检查是否存在动态加载或反射引用。无涉及表外语言时不展示此章节。

## 验证方法

列出阶段 2 中实际使用的验证层（表内精确层 + 表外通用层），并确认阶段 4 级联检查已执行。

## 安全原则

列出本次清理遵循的所有安全原则（所有验证层、级联检查等）。

## 风险评估

风险等级 + 影响面分析。
