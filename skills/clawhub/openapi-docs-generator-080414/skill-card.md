## Description: <br>
Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to turn an OpenAPI, Swagger, or REST API documentation request into a practical plan, checklist, artifact, code change, or validation workflow. It is intended for API documentation generation, improvement, review, and verification tasks. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger wording may invoke the skill on general API or developer-experience requests where OpenAPI documentation help is not intended. <br>
Mitigation: Confirm the request is specifically about OpenAPI, Swagger, REST API documentation, or related validation before applying the workflow. <br>
Risk: Generated documentation guidance, checklists, code snippets, or commands may be incomplete or misaligned with the target service. <br>
Mitigation: Review proposed outputs against the API implementation and run any included validation or tests before publishing documentation. <br>
