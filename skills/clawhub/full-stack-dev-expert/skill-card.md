## Description:

Coordinates a development team of specialized roles to plan, build, review, test, document, and deploy full-stack software across multiple technology stacks.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers and engineering teams use the skill to coordinate full-stack projects, admin systems, feature work, refactors, debugging, reviews, testing, and delivery documentation. It routes work across requirements, architecture, UI/UX, frontend, backend, database, security, DevOps, and technical writing roles.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Quick-start commands can affect the local environment.

Mitigation: Review each command and confirm its destination before running it.

Risk: API examples may be unsafe to use unchanged with real credentials or data.

Mitigation: Check the destination and contents of each example and use non-sensitive test credentials and data.

Risk: The referenced shadcn CLI version may change when it is downloaded.

Mitigation: Pin the CLI version before using it.
