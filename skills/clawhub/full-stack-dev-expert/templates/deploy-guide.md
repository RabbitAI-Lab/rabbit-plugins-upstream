# 部署指南（deploy-guide）

> 产出者：DevOps 工程师。归档：`docs/deploy-guide.md`。
> 质量门禁：新人按文档可从零部署；回滚步骤明确；部署演练通过。

## 1. 环境要求

| 项 | 要求 |
|---|---|
| OS / 运行时 | 如：Ubuntu 22.04 / Node 20 / JDK 17 / Python 3.11 |
| 数据库 | 如：MySQL 8，初始化 UTF8MB4 |
| 资源建议 | CPU / 内存 / 磁盘 |

## 2. 从零部署步骤（部署演练已验证）

```bash
# 1. 获取代码
git clone <repo> && cd <dir>
# 2. 安装依赖
<命令>
# 3. 初始化数据库（迁移）
<命令>
# 4. 配置环境变量（对照第 4 节清单）
# 5. 构建
<命令>
# 6. 启动
<命令>
# 7. 验证
curl http://localhost:<port>/health   # 预期输出：...
```

## 3. Docker 方式（如提供）

```bash
docker compose up -d
docker compose ps    # 预期状态
```

## 4. 配置项清单（全部环境变量）

| 变量 | 默认值 | 必填 | 说明 |
|---|---|---|---|
| `DB_URL` | — | 是 | 数据库连接串（示例格式） |

密钥类变量禁止写默认值与示例真实值，仅注明"从密管平台获取"。
