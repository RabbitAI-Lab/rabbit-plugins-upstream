# 09 FAQ

**Q：没有专业红队团队，能做 AI 安全测试吗？**
可以分档：先做"轻量自测"（用例库 + 工具 `cases` + 人工评审）覆盖高风险面；高危项或合规要求高的场景再委托专业红队。开发期对抗测试 + 上线前红队是建议最低配置。

**Q：测试中发现的漏洞要立刻修吗？**
严重/高危应立即处置（下线能力/临时缓解），中低危按计划修复；所有发现进报告并留痕。

**Q：AI 红队和传统渗透测试冲突吗？**
不冲突——互补。传统渗透管网络/应用层，AI 红队管模型/提示/工具链层；大型系统两者都做。

**Q：OWASP LLM Top 10 多久更新？**
OWASP 持续维护，2025 版框架已更新（新增供应链/过度代理等）；引用前核对最新版。

**Q：测试工具会真的攻击系统吗？**
不会——`ai_redteam_toolkit.py` 只生成用例/分级/报告模板，不发起攻击、不联网。实际测试由测试人员在授权环境执行。

**Q：间接注入攻击怎么防？**
把外部内容（网页/邮件/文档）标记为"不可信数据"，与系统指令隔离；对 Agent 能读取的外部内容做过滤与权限隔离（见 03 模块）。

**Q：测试中发现真实数据泄露怎么办？**
立即停止相关测试 → 按数据泄露响应流程处置（止损/上报/按个保法或 GDPR 通报义务评估）→ 记录事件。

**Q：工具命令报错？**
确认 Python 3.8+、skill 根目录运行 `python tools/ai_redteam_toolkit.py --help`。

**Q：和 AI 治理、智能体治理什么关系？**
三者闭环：AI 治理管制度/风险框架，智能体治理管 Agent 权限/责任，本技能管技术验证（红队）——治理定规则，红队验证规则是否被攻破。
