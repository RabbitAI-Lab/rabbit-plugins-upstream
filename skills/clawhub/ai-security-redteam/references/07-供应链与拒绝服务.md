# 07 供应链与拒绝服务

> 用途：回答「模型投毒怎么防」「供应链攻击」「DoS 测试」。
> 核对基准日：2026-08-27

## 1. 供应链风险（OWASP LLM03/04）

| 环节 | 风险 |
|---|---|
| 模型文件 | 恶意模型替换（后门） |
| 训练数据 | 数据投毒（植入偏见/后门/错误） |
| 依赖组件 | 第三方库漏洞（传统供应链） |
| 微调流程 | 微调数据投毒 |
| 托管服务 | 第三方 API 风险（数据/合规） |

## 2. 供应链测试要点

- 模型文件哈希校验（与官方一致）
- 训练数据溯源与质量检查（异常样本检测）
- 依赖组件漏洞扫描（SBOM）
- 第三方 API 的数据处理审查（是否拿数据训练、存储地）
- 权限最小化（模型/服务访问控制）

## 3. 投毒攻击测试（在授权测试环境）

- 在测试环境植入少量恶意样本，观察模型是否被带偏（验证防御）
- 检测训练数据中的异常注入（内容安全扫描）

## 4. DoS 测试（OWASP LLM10）

| 类型 | 手法 |
|---|---|
| 长上下文攻击 | 超长输入耗尽上下文/算力 |
| 递归请求 | 诱导 AI 自调用/循环 |
| 高并发 | 批量请求耗尽配额 |
| 重放 | 重复请求消耗资源 |

**测试要点**：
- 输入长度限制是否生效
- 请求速率限制
- 超时与资源隔离
- 单用户请求爆炸防护

## 5. 修复方向

- 供应链：SBOM、哈希校验、来源白名单、定期扫描
- 投毒：训练数据审查、异常检测、内容过滤
- DoS：长度/速率/并发限制、资源配额、超时熔断
