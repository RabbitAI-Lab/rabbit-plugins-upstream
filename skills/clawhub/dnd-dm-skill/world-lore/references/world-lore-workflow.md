# World Lore 工作流与提示词骨架

> 配套 `world-lore` 子技能。所有事实性内容必须来自 `lens_rag.py` 检索到的知识卡，
> 本文件只提供「如何组织叙述」的方法与模板。

---

## §1 世界观对话（单轮问答）

**检索 → 叙述** 两步。

### 提示词骨架（你内部使用）

```
你是基于 D&D 5e 设定的地下城主。下面是从知识库检索到的设定卡片（已附来源）：

<<检索到的知识摘要>>

用户问题：<<用户问题>>

要求：
1. 仅用卡片中的事实作答；若卡片不足以完整回答，明确说「据现有记载……尚不明确」，并给可追问钩子。
2. 叙述对标托尔金：具体、有质感、少用空洞形容词。
3. 提及专有名词时括号附原文（如首次出现的「密斯特拉（Mystra）」）。
4. 末尾列 2–3 个「可进一步追问」的钩子（用 ✦ 标记）。
```

### 质量红线
- 不把《博德之门3》游戏剧情当作设定事实。
- 不编造知识卡里没有的神祇 / 日期 / 地名。
- 检索为空时，直接告知「该主题暂无知识卡」，不要硬写。

## §2 费伦编年史生成（多事件叙事）

### 三级时间框架

```
纪元（Era）      —— 以文明/魔法范式划分，如「浑沌纪元」「耐瑟瑞尔纪元」
 └─ 时代（Age）  —— 纪元内的阶段，如「帝国鼎盛期」「大陨落之后」
     └─ 事件（Event）—— 单事件卡片（起因/经过/后果/遗留）
```

### 单事件卡片结构（每个事件都按此四要素写）

| 字段 | 内容 |
|:----|:-----|
| 起因 | 什么力量 / 人物 / 矛盾触发 |
| 经过 | 关键转折、参战方、决定性时刻 |
| 后果 | 直接结果（领土、人口、魔法、神祇） |
| 遗留 | 对「当下（玩家所在时代）」的持续影响——这是「重量」的来源 |

### 编年史提示词骨架

```
请基于下述检索到的编年史素材，生成一段《<<主题>>》编年史，约 <<字数>> 字。

<<chronicle 模式检索到的知识摘要>>

结构要求：
- 按「纪元 → 时代 → 事件」三级组织，事件用 §2 的四要素写法。
- 每个事实标注来源（如「据《剑湾冒险者指南》」），不得超出素材编造。
- 结尾用一段「至今回响」点明这些历史如何影响玩家当前冒险。
- 末尾给 2–3 个可深挖的钩子（✦）。
```

## §3 为功能二检索素材

生成模组前，可用本子技能检索地点 / 派系 / 怪物参照：

```bash
python lens_rag.py "<<地区名>>" --types location --top-k 4
python lens_rag.py "<<反派类型>>" --types faction monster --top-k 4
```

把检索结果作为模组生成的「设定锚点」，确保新模组与既有费伦设定不自相矛盾。
