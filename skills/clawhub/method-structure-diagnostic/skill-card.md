## Description:

诊断心理学论文 Method 部分的结构完整性与篇章逻辑，检查核心子模块是否齐全、内容要素是否完整，输出评分与顶刊正例参考

This skill is ready for commercial/non-commercial use.

## Use Case:

External researchers, students, and academic writing reviewers use this skill to assess whether psychology Method sections are structurally complete, reproducible, and logically organized. It produces a scored diagnostic report with prioritized revision guidance and selected exemplar references.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill is oriented toward Chinese Method-section diagnostic reports, which may not fit all review settings.

Mitigation: Confirm the intended reviewer language and request language-adaptive output when the release must serve non-Chinese users.

Risk: Some referenced exemplar paths in the artifact are stale or inconsistent with the bundled file layout.

Mitigation: Verify and update reference paths before relying on exemplar lookup in production reviews.

Risk: A structured score can be mistaken for a complete scientific review.

Mitigation: Use the report as Method-section structure guidance and route study design, statistics, language, and journal-convention checks to appropriate reviewers or companion skills.
