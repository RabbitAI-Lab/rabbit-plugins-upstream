# 片段类型：结构（形容词条目库的分步筛选漏斗）

## 原文片段

> Item Pool. The item pool of personality-descriptive adjectives has been selected from a collection of 5,160 German adjectives (Angleitner et al., 1990; see also Figure 2). Angleitner et al. (1990) collected familiarity ratings for each adjective in the initial list and provided an index variable (SYNDEF a combined score indicating the number of synonyms and definitions given by the raters; for further details, please see the Supplemental Table SM2) that is supposed to indicate familiarity and difficulty for each adjective jointly. We sampled personality-descriptive items from this list and included a sufficient number of adjectives with low familiarity and high difficulty. The extracted set consisted of 268 adjectives, including 93 marker adjectives (extracted as Big Five markers by Ostendorf in earlier work; see Ostendorf, 1990, p. 179) and 175 adjectives whose factor association was not empirically determined yet. The set of 175 adjectives with unclear Big Five assignment was reduced to 135 items based upon semantic redundancy of adjectives within the set or the adjectives being uncommon and outdated. ## 适配诊断点

- 条目筛选漏斗清晰：母库（5,160，出处 Angleitner et al., 1990）→ 提取（268 = 93 marker + 175 未定因子归属）→ 缩减（175 → 135，依据：语义冗余/生僻过时）→ 最终池。
- 每个筛选步骤有量化依据（93/175/135）与明确标准（semantic redundancy, uncommon and outdated），筛选可复现。
- 来源库的先验信息被利用：SYNDEF 指数（熟悉度与难度联合指标）说明其构造与用途，条目选取策略（有意纳入低熟悉高难度形容词）与研究目的绑定。
- marker 形容词的出处精确到页码（Ostendorf, 1990, p. 179），溯源严谨。
