# 片段类型：结构

## 原文片段

Based on recent research about the correlation between Honesty–Humility and deception (Heck et al., 2018), we assumed a medium-to-large effect size (OR = 0.53) but calculated our power analysis with a more conservative effect of r = .20. With an assumed power of 99% and setting Type I error rate at p < .05, the analysis for correlation (two-tailed) revealed a minimal sample size of N = 443. Data of all studies were collected via Amazon Mechanical Turk, except data of Study 4 that was collected via Prolific.

## 来源文献

Reinhardt et al., 2023, Journal of Personality and Social Psychology
