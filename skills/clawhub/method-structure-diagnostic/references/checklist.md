# 心理学实证论文 Method 部分「结构与篇章维度」检查清单

> 标准依据：《Science Research Writing》(2nd ed.) 的 Method 通用 6 模块模型、总-分叙事逻辑、子模块组织原则；正例惯例来自 JPSP / JEP:G / Developmental Psychology / PSPB 等顶刊实证论文。

## 一、核心子模块齐全度

- [ ] Method 部分包含 Participants / Sample 模块（样本描述）
- [ ] Method 部分包含 Design 模块（设计类型、条件数、因素结构）
- [ ] Method 部分包含 Measures / Materials 模块（测量工具与刺激材料）
- [ ] Method 部分包含 Procedure 模块（流程步骤）
- [ ] Method 部分包含数据分析策略模块（Analysis Plan / Analytic Strategy）
- [ ] 按期刊要求包含 Transparency and Openness / 数据可得性声明
- [ ] 多研究论文中每个研究（Study 1/2/3）各自拥有完整且独立的 Method 模块
- [ ] 子模块标题命名符合目标期刊惯例（Participants、Design、Measures、Procedure 等）
- [ ] 需要时引用 Supplemental Materials（补充材料中的量表全文、材料、附录链接）
- [ ] 正文 Method 与补充材料分工明确：可复现的关键信息留在正文，冗长细节放补充材料
- [ ] 模块覆盖研究三要素：被试（who）、材料/工具（what）、程序（how）

## 二、子模块要素完整性

### Participants / Sample

- [ ] 报告招募渠道与招募方式（平台 / 学校被试库 / 社区，如 MTurk、Prolific）
- [ ] 报告报酬或补偿方式（学分、金额）
- [ ] 报告目标样本量及其确定依据（先验功效分析或既有研究估计）
- [ ] 功效分析要素齐全：目标效应量及其假设理由、统计功效、α 水平、分析工具（如 G*Power）
- [ ] 报告实际完成人数与最终样本量，两者不一致时有说明
- [ ] 排除规则逐条列出，每条附排除人数与具体原因（未完成、未通过操纵检验、技术故障、数据质量等）
- [ ] 排除标准引用原文或给出可复现的操作定义
- [ ] 报告最终样本人口学构成（性别比例、年龄 M/SD/范围、种族/民族）
- [ ] 必要时报告额外样本特征（教育程度、政治倾向等，含量表锚点）
- [ ] 报告伦理审批信息（IRB 批准、知情同意）
- [ ] 多研究论文中显式维护跨研究样本口径一致性（"As in Studies 1a–c"）
- [ ] 纵向 / 面板数据报告双重计数（个体数与观测点数量）

### Design

- [ ] 用一句话完整定义设计：条件数 + 被试间/被试内/混合因素 + 各因素水平
- [ ] 报告自变量及其操作定义、水平
- [ ] 报告因变量及其测量时点
- [ ] 报告随机分配方式（个体随机、配对随机等）
- [ ] 报告控制变量 / 协变量及其入选理由
- [ ] 设置操纵检验（manipulation check）并说明检验内容与时点
- [ ] 报告盲法设计（被试盲 / 实验者盲）及其保障方式
- [ ] 平行实验采用一致的句式与结构，仅更换因素水平名称

### Measures / Materials

- [ ] 以总纲句先行概述测量内容与顺序（"The following constructs were assessed in fixed order"）
- [ ] 每个构念独立成段：工具全称与缩写、来源文献
- [ ] 报告条目数、计分方式、量表锚点（0–100、1–7 等）
- [ ] 报告本研究样本中的信度（α 或 ω）
- [ ] 必要时提供心理测量学依据（前人效度证据、与金标准的关系）
- [ ] 必要时给出条目示例
- [ ] 报告测量顺序、固定或随机化安排、减轻作答负担策略（如 planned missingness）
- [ ] 刺激/材料：报告来源、构造过程、数量与版本（含多版本防内容特异性）
- [ ] 材料构造采用漏斗式可复现流程：母库 → 提取 → 缩减 → 最终集，每步有量化依据
- [ ] 既有量表改编时说明改编方式并引用出处（adapted from / revised version of）

### Procedure

- [ ] 步骤按时间顺序形成完整环节链，无跳步
- [ ] 报告精确时序（刺激呈现毫秒数、间隔、练习/正式试验数量）
- [ ] 报告按键 / 响应映射等操作细节
- [ ] 使用精确序列语言（prior to、subsequently、until、at which point），而非仅用 then/next
- [ ] 报告每个步骤的时长与条件
- [ ] 报告任务指令的呈现方式与内容
- [ ] 报告盲态操作与信息隐瞒方式（"was not told whether..."）
- [ ] 报告事后说明（debriefing）
- [ ] 每个操作环节附带理由（in order to、to ensure），非机械罗列

### 数据分析

- [ ] 报告数据清理 / 筛选规则（或与 Participants 排除规则互引）
- [ ] 报告统计分析软件与版本
- [ ] 报告统计方法与模型（与预注册方案一致）
- [ ] 报告缺失数据处理方式
- [ ] 必要时报告多重比较校正方法
- [ ] 明确验证性 vs 探索性分析（预注册声明或如实说明未预注册）

## 三、结构逻辑顺序

- [ ] 采用总-分（top-down）叙事：先给读者整体框架，再展开细节（"先展示墙，再谈砖"）
- [ ] 开头方式恰当：概述研究参数 / 材料来源 / 回指前言中的研究目标
- [ ] 每段以段落入口句（paragraph-entry sentence）开场，先立焦点再填充细节
- [ ] 子模块排列顺序符合目标期刊惯例（Design → Participants → Measures → Procedure → Analysis 或期刊变体）
- [ ] 程序步骤严格按实际执行的时间顺序叙述
- [ ] 叙述由一般到具体（general statement → specific details）
- [ ] 同一因素/条件的不同水平组织在相邻位置，便于对照
- [ ] 多研究间模块顺序与结构保持一致（Study 1 → 2 → 3 同构）
- [ ] 相关材料聚合叙述（同一构念的多个指标相邻出现）
- [ ] 逻辑链无断点：每一步都能从前一步自然推出
- [ ] 排除/筛选流程按漏斗顺序：起始样本 → 逐条限制 → 每步人数与理由 → 最终样本
- [ ] 结尾自然收束（如最终样本量、最终分析集），不突兀

## 四、段落组织规范

- [ ] 一段一主题，每段承担单一功能（概述、细节、理由、比较、问题）
- [ ] 段内信息流遵循：概述 → 细节 → 理由/合理化
- [ ] 段落长度适中、可扫描，避免超长堆砌
- [ ] 使用小标题或加粗构念名辅助快速定位（如 Social dominance orientation.）
- [ ] 句间衔接明确（Thus、Specifically、In all cases、Most of the tests、Moreover）
- [ ] 时态规范：报告本研究行为用过去时（was collected），描述标准程序/设备用现在时（is used）
- [ ] 归属清晰：用 In this study / here / in our model 等标记区分自己的工作与既有方法，避免无施事被动导致的歧义
- [ ] 引用位置准确：citation 放在所归属的方法/语句处，不误挂他人工作
- [ ] 关键选择均提供理由与合理性论证，预判读者质疑
- [ ] 使用体现严谨细致的语言（tightly、precisely、directly、separately、repeatedly）
- [ ] 问题/局限在首次出现处提及，并使用最小化措辞（slightly、negligible、minimal）
- [ ] 与已有方法的关系明确三分：完全相同（as described by）、相似（adapted from）、显著不同（unlike/instead of），并说明差异意义
- [ ] 避免介词短语堆砌造成的歧义句（一串 of/with/in 的嵌套）
- [ ] 图表引用位置恰当：Figure/Table 在其描述的正文处就近引用
- [ ] 句间衔接不依赖读者脑补，每句都能从上一句或总纲推出
