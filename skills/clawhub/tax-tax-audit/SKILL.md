## 重要提示与边界声明

**重要提示**
1. **计算结果仅供参考**：所有税额测算、优惠判断、风险评分均为辅助参考，不构成税务申报、审计或法律意见。
2. **专业事项请咨询执业人员**：税务筹划、争议解决、稽查应对等需结合企业实际，由执业税务师/律师量身定制。
3. **数据以官方为准**：政策时效性强，个案结论可能因地区、行业、时间而异；涉及重大利益请向主管税务机关或专业人士二次确认。

**边界（本技能不做的）**
- **不代办**：实时申报、缴款、退税、注销等需登录电子税务局的操作
- **不代理**：税务行政复议、诉讼、鉴证等需执业资质的法律事务
- **不担保**：政策时效与个案结论以税务机关/执业税务师最终认定为准

**服务说明**
- 每次提问都能获得完整闭环：智能问答 → 结构化结果 → 政策依据溯源 → 真实案例关联 → 实操辅导 → 反馈评价 → 合规报告

**隐私保护**
- 仅在本机生成随机匿名标识用于服务调用，不会采集任何设备信息或个人隐私数据

## 能为你做什么（税务审计五大场景）
---

### 一、财务报表审计税务维度（1142落地）
- 📑 **程序嵌入**：识别税收法规违反对财报的影响，执行申报比对与优惠复核。
- ⚖️ **意见影响**：未计提或错误计提税负时考虑非标意见并与治理层沟通。
- 🧾 **勤勉佐证**：留存识别与沟通底稿，佐证审计勤勉尽责。

**典型问法：**
```
"财报审计税务程序怎么落地？"
"审计1142号税务维度怎么执行？"
```

### 二、税务合规内控审计
- 🧩 **了解评估**：识别计税、申报、缴纳、优惠备案等关键控制点。
- 🔬 **控制测试**：抽取样本验证控制一贯运行，对依赖控制做细节测试。
- 🪡 **穿行测试**：追踪业务从发生到计税申报缴纳的完整路径验证生效。

**典型问法：**
```
"税务内控怎么测？"
"控制测试和穿行测试有什么区别？"
```

### 三、涉税舞弊识别与应对
- 🕵️ **收入舞弊**：隐瞒收入、账外经营、阴阳合同，比对银行流水与申报。
- 💡 **成本舞弊**：虚开发票、无关支出，关注资金回流与无实物流转。
- 🔗 **关联舞弊**：转移定价、不合理分摊，核查同期资料与利润偏离。

**典型问法：**
```
"涉税舞弊怎么识别？"
"虚开发票审计信号有哪些？"
```

### 四、关键审计事项税务披露
- 📌 **选取标准**：重大性、重大判断或高度不确定性的税务风险。
- 🗂️ **披露要素**：事项描述、审计应对、管理层判断依据、不确定性说明。
- 💬 **沟通价值**：向报表使用者提示税务不确定性，降低信息不对称。

**典型问法：**
```
"关键审计事项税务风险怎么披露？"
"税务不确定性怎么在财报里说清楚？"
```

### 五、监管提示税务维度与自检
- 📜 **1-9号落地**：将会计监管风险提示的税务维度纳入审计计划与程序。
- 🚨 **红旗信号**：税负率异常、进销倒挂、私户收款等提示风险方向。
- 🧭 **六步闭环**：计划—内控—实质—舞弊—披露—报告全程贯通，说「做一下税务审计自检」即可触发。

**典型问法：**
