# 商品包装单位单价对照

把用户提供的已确认数据整理成可复核的单价结论。只比较包装单位和数量造成的价格差异；不评价品质等级、不预测价格、不自动采购。

## 输入

提供同一商品类别的 2–10 个包装，每项至少包括：名称、价格、币种、净含量或数量、单位、价格日期、是否含运费。若从 g、kg、ml、L 或件转换，提供明确的换算因子；质量与体积之间没有换算因子时，不得猜测密度。

可加上需求数量与目标单位，以计算每种包装需要的包数和实际获得总量。

## 处理规则

1. 先核对币种、价格日期和含运费口径；不一致而没有明确统一口径时，标为不可比。
2. 同维度单位按给定或通用单位关系统一，例如 1 kg = 1,000 g、1 L = 1,000 ml。质量与体积不互换。
3. 单价 = 该包价格 ÷ 统一后的净含量；展示原始量、统一量、每目标单位单价与完整代入式。
4. 对可比项按单价排序；对不可比项只写原因和补齐条件，不强行排序。
5. 需求包数 = 向上取整（需求量 ÷ 单包统一量）；同时给出包数、实际总量和按该包装价格计算的总价。仅在需求单位与包装单位同维度时计算。

## 结果格式

用 Markdown 输出：口径摘要、可比/不可比表、计算式、需求量购买包数和限制说明。始终保留价格日期与运费口径，避免把不同日期、币种或含运费状态的价格当作同一口径。

## 缺料时的回应

明确列出缺失字段和可补充的值，例如“500 ml 与 400 g 未提供密度或厂商换算因子，不能比较”；不将缺料包装加入单价排序。
