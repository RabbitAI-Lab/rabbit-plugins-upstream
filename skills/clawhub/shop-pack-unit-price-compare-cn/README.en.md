# Pack Unit-Price Comparison (Chinese)

![Promotional image](assets/promo-1600x900.png)

Compare 2–10 confirmed package offers on one unit basis. Provide price, net quantity, unit, currency, price date, and shipping treatment; receive a transparent unit-price table, comparability reasons, formulas, and packs needed for a requested quantity.

Missing quantity, conversion factor, price basis, or currency makes an offer non-comparable. The Skill never guesses density to convert mass and volume, selects across product-quality tiers, forecasts prices, or purchases automatically.

## Install

```bash
npx skills add xxjrq/shop-pack-unit-price-compare-cn
```

See the [successful fixture](fixtures/success-output.md) and [failure fixture](fixtures/failure-output.md). Run `python3 scripts/self_test.py` from this directory to execute both bundled cases.
