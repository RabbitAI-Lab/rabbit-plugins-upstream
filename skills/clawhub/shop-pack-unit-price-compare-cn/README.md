# 商品包装单位单价对照

![商品包装单位单价对照推广图](assets/promo-1600x900.png)

将 2–10 种已确认的包装价格和规格换算成同单位单价，避免“看起来更便宜”的大包装或小包装造成误判。它给出透明计算式、可比/不可比原因，并按你的需求量计算每种包装需要购买的包数与实际总量。

**输入**：同类商品的价格、净含量或数量、单位、币种、价格日期、是否含运费；可选需求数量和目标单位。

**结果**：统一商品量与单位价格表、完整算式、可比性原因、需求量对应的购买包数。缺少净含量、换算因子、价格口径或币种时会标记不可比；不会用密度猜测质量与体积换算。

## 安装

```bash
npx skills add xxjrq/shop-pack-unit-price-compare-cn
```

## 适用边界

仅比较用户提供数据的包装单价，且最多 10 种、单一商品类别。它不选择跨质量等级的“最佳”商品，不预测价格，也不自动采购。

## 使用提示

直接提供各包装的确认数据。例如：

```text
小包装：20 CNY，250 g，2026-10-04，含运费
大包装：35 CNY，500 g，2026-10-04，含运费
需求：750 g；请按每 100 g 对照。
```

输出应保留价格日期与运费口径。若出现 500 ml 对 400 g 而没有明确换算因子，或币种不同且没有汇率规则，Skill 会拒绝直接排序并说明需补什么。

## 自检

在本目录独立运行：

```bash
python3 scripts/self_test.py
```

自检会真实执行内置的成功与失败输入：验证每 100 g 单价及需求包数，并验证质量/体积与跨币种条件不足时不会排序。
