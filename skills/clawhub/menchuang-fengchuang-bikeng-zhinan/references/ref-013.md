# 精装修，阳台微改有几种做法？9.21

作者: 西安装修课堂

发布时间: 2023年9月21日 07:31

发布地点: 陕西

北方精装修房子，大部分阳台没有做封闭，而且客厅与阳台还有推拉门分割，阳台地面瓷砖和大面积都不一样，还有保温层需要处理，甚至后期还得放洗烘机洗衣池，涉及到各种水电改造，所以规划才是精装修阳台装修的第一步，合理规划然后让结果更完美。

## .01

只封阳台，其他不处理

▲阳台封窗是必须做的，纳入室内，地面网购防腐木地板直接铺上即可，原有墙面保温一概不处理，管道网购麻绳自己装饰一下，摆上花架直接使用，非常经济实惠

▲如图，只是封了阳台，然后铺上窗台石，直接定制洗衣柜，抬高地面满足洗衣机下水，安装衣架，直接就可以使用，最省钱的做法

▲原有精装修本身就有窗户，后期定制了书桌吊柜，放了成品的花架，其他什么都没有改造，直接使用

▲什么都不做改变，原有阳台保留露台，只做定制和基本的软装即可
