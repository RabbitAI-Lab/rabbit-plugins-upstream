# SRT 脚本与字幕规范

## 一、口播脚本（制作前写的 `Vxx-主题.srt`）

这是配音、字幕、甚至分镜的共同来源，**段号 = 配音段号 = 字幕重建索引**，务必从 1 连续递增。

### 写法要点

- **每段是一个完整意群**：在 `。！？；：` 等标点处断段，不要在词中间断。
- **单行 ≤ 28 字**。原因：libass 实际渲染字幕遮住画布 y≈717–780（video_y = canvas_y × 0.6944），行太长会压到正文区。
- **时间轴先写「均分占位」即可**（每段 4–6 秒）。真实时间轴在配音合成后由 `build_subtitles.py` 从音轨重建，**不要用手写时间轴做最终字幕**。
- **避免《》内部被硬切**：长意群超 28 字时，`build_subtitles.py` 优先在逗号/冒号处切；仍超才退而在逗号枚举处切，最后兜底硬切且避开书名号内部。

### 模板

```
1
00:00:00,000 --> 00:00:04,500
公司要取证提升竞争力，先得弄清两张证书的分工。

2
00:00:04,500 --> 00:00:09,800
ISO 9001 管的是质量管理体系，适用所有行业。
```

## 二、同步字幕（制作后由 `build_subtitles.py` 重建）

`build_subtitles.py` 的三大原则：
1. **意群优先**：只在意群边界断屏；超长才退而在逗号处切。
2. **声画同步**：切换点对齐配音音轨里的真实静音停顿（能量检测）+ 前向/后向语速约束窗口，保证每条有足够展示时间。
3. **单行不超框**：每屏 ≤ max-chars（默认 28）。

产物 `Vxx-主题-同步字幕.srt` 由真实音轨生成，是最终烧录用字幕。脚本末行会打印 `自检 通过 / 有问题`，重点看「最长字数」是否 ≤ 28、「最短展示」是否 ≥ 0.5s。

## 三、烧录样式（推荐）

```
FontName=Microsoft YaHei,FontSize=21,PrimaryColour=&H00FFFFFF,
OutlineColour=&H00000000,Outline=2,Shadow=1,MarginV=28,Bold=1
```

白字 + 黑描边，放在画面下方，不压正文。详见 `pipeline.md` 命令模板。
