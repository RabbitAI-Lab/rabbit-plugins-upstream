# 主题凝练方法（教材 / 课件类，默认）

本 skill 处理的第一环：**从一篇文档（教材章节 / 课件 / 讲义）里，凝练出若干「可独立成片」的教学视频点**。本项目（化妆品生产质量管理教材 · 模块一 · 项目1）就是按这个打法做的——10 个视频点全部映射到教材的「任务 1.1–1.6」。

## 1. 拆解原则

- **一个视频点 = 一个独立知识点闭环**：有「概念 → 判断 / 操作 → 结论」三段式，时长 90–140 秒。
- **优先按文档原有结构挂接**：章节、任务、子目标。例如教材的任务 1.4「上市两道门」天然就是一个视频点，不必再切。
- **一个任务若信息过载（>140 秒口播），按子主题再拆**：本项目把「中欧美对照」拆成 3 幕、「ISO 选型」拆成 3 幕。
- **每个视频点配一个动词标题**，明确「观众看完能做什么」：
  - ✅「三维度判定化妆品属性」「注册备案分水岭」「质量安全责任制」
  - ❌「关于化妆品的法规知识」（太泛，无法独立成片）

## 2. 产出物：规划表

用一个 `P1-教学视频规划-10个视频点.md` 之类的文档登记每个点：

| 编号 | 主题 | 对应文档位置 | 核心内容 | 目标时长 | 状态 |
|---|---|---|---|---|---|
| V01 | 什么是化妆品·三维度判定法 | 任务1.1 | 施用于人体/调节作用/使用方法 三维度 | 95s | 已出片 |
| V02 | 特殊与普通·注册备案分水岭 | 任务1.2 | 特殊化妆品注册 vs 普通化妆品备案 | 108s | 已出片 |

状态机：`待制作 → 脚本已写 → 线稿已生成 → 已渲染 → 配音字幕完成 → 已出片`。

## 3. 每个视频点的「脚本骨架」（SRT）

凝练完成后，给每个点写一份口播脚本（标准 SRT），结构是**一段一个意群**，例如：

```
1
00:00:00,000 --> 00:00:04,500
公司要取证提升竞争力，先得弄清两张证书的分工。

2
00:00:04,500 --> 00:00:09,800
ISO 9001 管的是质量管理体系，适用所有行业。
```

要点（详见 `srt-guidelines.md`）：
- 每段是完整意群，**单行 ≤ 28 字**；
- 时间轴先写「均分占位」即可，**真实时间轴由配音实测后重建**（见 pipeline）；
- 段号从 1 连续递增，后续配音 / 字幕都按段号对齐。

## 4. 通用文档类（非教材）的变体

若源文档不是教材而是科普文章 / 报告，把「任务 1.x」换成「论点 / 小节 / 数据卡」，拆法一致：每个视频点 = 一个自洽的论点或故事。可在规划表里加一列「论证结构」。

## 5. 一句话触发自己的工作流

> 拿到文档 → 列规划表（编号/主题/挂接位置/时长/状态）→ 逐点写 SRT → 进入视频制作流水线（见 `pipeline.md`）。
