## Description:

AI-powered job search assistant that searches multiple job boards, matches opportunities against your CV, and helps you apply faster.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zy42905163-web](https://clawhub.ai/user/zy42905163-web)

### License/Terms of Use:

MIT-0

## Use Case:

External job seekers use this skill to search job boards, rank roles against a CV, generate cover letters, track applications, and prepare or submit applications.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Bulk auto-apply workflows may submit sensitive application data before the user has reviewed each employer, role, cover letter, CV, and personal detail.

Mitigation: Require explicit user review and approval for each application before submission, and limit account or profile-data access to what the user is comfortable sharing.
