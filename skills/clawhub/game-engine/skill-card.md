## Description:

Game Engine helps agents guide developers through building web-based games and game engines with HTML5, Canvas, WebGL, JavaScript, and common 2D and 3D game frameworks.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to create browser-based games, game engines, gameplay systems, rendering loops, collision detection, controls, audio, multiplayer features, and publishing workflows. It is suited for agents that need to produce implementation guidance, starter code, and troubleshooting advice for 2D and 3D web games.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Unpinned package, clone, or build examples may pull changing dependencies or unreviewed code.

Mitigation: Pin package versions or commits, review cloned repositories and build files, and run builds in a low-privilege project environment before reuse.

Risk: Game examples may use browser sensors, WebRTC, WebSockets, vibration, microphone, or persistent storage in ways that affect privacy or user expectations.

Mitigation: Add explicit user consent, disclosure, fallback controls, and data-retention limits before shipping games that use those APIs.
