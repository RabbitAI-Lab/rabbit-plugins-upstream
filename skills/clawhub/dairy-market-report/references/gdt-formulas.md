# GDT 入仓成本计算公式

用户给出的标准公式 (在报告第 8 节使用). 合约 2 (Contract 2) 为 GDT 主力合约, 拍卖后 1–2 个月交割.

## 公式

| 品种 | 入仓成本 (元/吨) |
|---|---|
| AMF (无水黄油) | `(合约2价格(USD/吨) + 165(USD/吨 海运费)) × CNY/USD汇率 × 1.13(关税+增值税) + 300(CNY/吨 进口杂费)` |
| WMP (全脂奶粉) | `(合约2价格(USD/吨) + 115(USD/吨 海运费)) × CNY/USD汇率 × 1.13 + 300` |
| SMP (脱脂奶粉) | `(合约2价格(USD/吨) + 115(USD/吨 海运费)) × CNY/USD汇率 × 1.13 + 300` |

## 各项说明

- **海运费**: AMF 因体积密度较高 → 165 USD/吨; 粉类 → 115 USD/吨. 这是 2023 年左右的常规报价, 实际会随油价/集装箱指数波动.
- **1.13 倍数**: 关税 10% (HS 0402/0405) + 增值税 13% 复合后约 1.13; 部分自贸协定国 (新西兰) 关税为 0, 此时倍数降为 1.13 → 1.026 左右. 报告默认按 1.13 计算, 若使用 FTA 优惠, 须显式说明.
- **300 元/吨 进口杂费**: 包含报关 / 港杂 / 仓储 / 短驳 等一次性费用, 平摊到吨. 实际可能为 200–400 区间.
- **汇率**: 用 央行中间价 (月均). 报告里标注日期.

## 数字示例 (用于校对)

假设:
- AMF 合约 2 = 5500 USD/吨
- WMP 合约 2 = 3200 USD/吨
- SMP 合约 2 = 2700 USD/吨
- 汇率 = 7.20 CNY/USD

则:
- AMF 入仓 = (5500 + 165) × 7.20 × 1.13 + 300 ≈ **48,786 元/吨**
- WMP 入仓 = (3200 + 115) × 7.20 × 1.13 + 300 ≈ **27,277 元/吨**
- SMP 入仓 = (2700 + 115) × 7.20 × 1.13 + 300 ≈ **24,541 元/吨**

报告引用时须给出 3 个数字 (AMF/WMP/SMP), 注明汇率日期 + GDT 事件日期.

## 工具调用

```bash
python scripts/gdt_calculator.py \
  --contract2-amf 5500 \
  --contract2-wmp 3200 \
  --contract2-smp 2700 \
  --fx 7.20 \
  --out gdt_landed.csv
```

输出 CSV 列: `product, contract2_usd_per_t, freight_usd_per_t, fx_cny_per_usd, landed_cny_per_t`
