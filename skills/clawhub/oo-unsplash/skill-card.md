## Description:

Use this skill to search and read Unsplash photo, topic, and random photo data through an OOMOL-connected account.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to ask an agent for Unsplash searches, listings, topic photos, random photo selections, and detailed photo records without manually calling the Unsplash API.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Fallback setup includes remote installer commands that execute downloaded scripts directly in a shell.

Mitigation: Use an official, verifiable installer when available, or inspect and verify downloaded installer scripts before execution.
