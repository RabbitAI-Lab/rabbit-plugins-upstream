Developers, marketers, and automation builders use this skill to create Orshot template renders, automate recurring image/PDF/video production, publish social media outputs, and migrate render workflows from similar template-generation services. <br>

## Known Risks and Mitigations: <br>
Risk: The skill can lead agents toward broad Orshot publishing, sharing, workflow, workspace-log, and destructive API actions. <br>
Mitigation: Require explicit user confirmation before deleting resources, changing sharing, running workflows, scheduling or publishing posts, connecting accounts, or reading workspace logs/profile data. <br>
Risk: API keys or OAuth tokens may grant access beyond a single render task. <br>
Mitigation: Use narrowly scoped Orshot tokens where possible and avoid exposing credentials in generated code, logs, or shared configuration. <br>
Risk: Generated social posts or scheduled workflows can publish externally without further review. <br>
Mitigation: Keep new workflows in draft or review mode until the user approves the content, destination accounts, schedule, and sharing settings. <br>
