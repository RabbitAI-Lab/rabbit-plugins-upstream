## Description: <br>
Agent Layer helps developers install and set up the AgentLayer local crypto wallet runtime for AI agent hosts. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[lopushok9](https://clawhub.ai/user/lopushok9) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to get host-specific install commands and onboarding guidance for adding an AgentLayer wallet runtime to OpenClaw, Claude Code, Codex, or Hermes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill installs high-impact wallet and finance tooling through unattended remote installer commands. <br>
Mitigation: Install only after verifying the AgentLayer package source and version, understanding key storage and permissions, avoiding meaningful funds during initial setup, and reviewing uninstall or recovery documentation. <br>
