## Description:

Helps create light instrumental background music for dialogue, reels, and explainers using Stable Audio 2.5.

This skill is ready for commercial/non-commercial use.

## Use Case:

Creators and editors use this skill to prepare instrumental music prompts and generation steps for unobtrusive beds beneath narration or short videos.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Unpinned skill installation commands may fetch changed dependencies.

Mitigation: Review the installation commands and use a trusted or pinned installation path when available.

Risk: Prompts or credentials may be exposed when calling an external audio service.

Mitigation: Provide REPLICATE_API_TOKEN only when using Replicate, and omit secrets and private information from prompts.
