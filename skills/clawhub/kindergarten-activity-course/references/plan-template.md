# 周计划组合模板

用户要"一周活动安排"时按此模板组合，每天 1 个主活动 + 1 个机动项：

| 星期 | 主题日 | 主活动领域 | 机动项 |
|---|---|---|---|
| 周一 | 运动日 | 健康 | 户外自由跑跳 20 分钟 |
| 周二 | 语言日 | 语言 | 睡前绘本共读 |
| 周三 | 探究日 | 科学 | 生活观察（天气/植物） |
| 周四 | 创意日 | 艺术 | 自由涂鸦 |
| 周五 | 社交日 | 社会 | 亲子桌游 |
| 周六 | 复习+大活动日 | 任选 | 本周最喜欢的活动再来一次 |
| 周日 | 休息日 | — | 户外、亲情时间，不安排任务 |

生成命令示例（每天单独一页或合成一页均可）：

```bash
python scripts/generate_activity.py --age 大班 --domain health --count 1 --seed 1 --out mon.html
python scripts/generate_activity.py --age 大班 --domain language --count 1 --seed 2 --out tue.html
# ...以此类推
```

与练习型 Skill 的配合：周一/周四加数学练习、周二/周五加思维或英语练习（见课程体系文档第四节周计划）。
