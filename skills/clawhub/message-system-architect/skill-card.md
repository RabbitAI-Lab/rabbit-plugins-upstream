## Description: <br>
Guides an agent through authoring a durable brand message system with a main narrative, three value pillars, per-persona proof points, a tagline, and canon-grade handoff artifacts. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[aaron-he-zhu](https://clawhub.ai/user/aaron-he-zhu) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Marketing, narrative, and brand teams use this skill to create or review a durable brand-level message hierarchy before it seeds a narrative registry. It helps keep the main narrative, pillars, proof labels, claims, and handoff summary consistent across later launch-specific messaging work. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Narrative or claim proposals could become misleading if accepted without review. <br>
Mitigation: Review the message house, proof labels, and every [needs source] claim before approving saves or registry proposals. <br>
Risk: The workflow can read and write project narrative files. <br>
Mitigation: Run it only in the intended project workspace and inspect proposed file or registry-event changes before persistence. <br>
