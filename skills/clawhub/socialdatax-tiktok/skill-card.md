## Known Risks and Mitigations:

Risk: Search terms, supplied links or share text, and requested identifiers are sent to SocialDataX and may consume paid API credits.

Mitigation: Avoid confidential inputs, limit pagination, and consider credit use before broad searches.

Risk: Using an unpinned CLI version can introduce unreviewed software changes.

Mitigation: Pin and review a CLI version instead of using @latest.
