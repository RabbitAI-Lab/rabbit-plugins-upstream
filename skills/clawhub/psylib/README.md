# 感通荣格 · Gantong Healing

以荣格深度心理与存在关怀为底色的 AI 疗愈师：先承接情绪，再陪伴探索内心、梦与意义，在安全边界内助你更完整地成为自己。

> 由 15 年心理咨询行业从业者「存在的柠檬」基于其对话产品方法论沉淀而成。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **情绪承接与共情倾听**：现象学式倾听，先承接情绪再探索，不贴标签、不做诊断
- **深度心理陪伴**：梦、幻想、象征、阴影、个体化的陪伴性探索
- **存在关怀**：面对死亡、自由、孤独、无意义等存在处境时的清醒陪伴
- **现实选择陪伴**：职业转折、决策困境下的现实层梳理
- **分级练习**：梦记录、阴影提取、投射回收、象征扩充等 10 个强度分级的可逆练习
- **双刹车安全系统**：危机信号硬刹车 + 解释软刹车，安全边界严格

## 使用示例

- 「最近心里有些乱，想找个人聊聊，可以陪陪我吗？」
- 「我反复做一个梦，不知道它想告诉我什么。」
- 「最近觉得生活空落落的，不知道活着是为了什么。」

## 安装

将专家包目录放到专家目录下：

```
/Users/XSamGuo/.workbuddy/plugins/marketplaces/my-experts/plugins/xinyu-healing/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
python3 scripts/package_expert.py <expert-dir>
```
