## 上架步骤

1. **登录**：浏览器打开 https://clawhub.ai/ ，点击右上角登录（用 GitHub 账号）
2. **进入发布**：点击「发布技能 / Publish」按钮
3. **上传**：选择工作区的 `xinyu-healing.zip`（支持上传 zip 或填 GitHub 仓库地址）
4. **填写信息**（可直接复制下面的内容）：

| 字段 | 内容 |
|------|------|
| 名称 | 感通荣格（Gantong） |
| 描述 | 以荣格深度心理与存在关怀为底色的AI疗愈专家，先承接情绪、再陪伴探索内心与意义，在安全边界内助你成为更完整的自己。适合情绪困扰、梦与象征、意义感缺失、职业转折、关系困惑等深度对话陪伴。 |
| 版本 | v1.0.0 |
| 分类 | Wellness / 身心健康（若无该分类选 Other） |
| 标签 | 心理疗愈、情绪支持、深度对话、荣格心理学、存在主义 |
| 作者 | 存在的柠檬（xsamguo@qq.com） |

5. **提交审核**：确认提交。官方将进行安全扫描和功能测试
6. **等待审核**：通常 1-3 个工作日，通过后自动出现在 WorkBuddy 专家中心/技能市场

## 审核关注点（已内置保障）

- ✅ 纯文档型专家，无脚本、无网络请求、无数据外传 → 安全扫描友好
- ✅ 内建危机硬刹车（自伤/自杀/暴力时停止分析、建议专业支持）→ 内容安全合规
- ✅ 明确"不做临床诊断、不替代专业治疗"边界 → 避免医疗合规风险
- ✅ 无第三方 API Key 依赖 → 不触发额外授权要求
