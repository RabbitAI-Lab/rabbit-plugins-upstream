video-skill-router

The AI Video & Animation Skill Router

视频创作技能路由器 — 找技能 → 装技能 → 做视频 → 善后，一条龙。
You describe the video. It detects the category, matches local skills, discovers & installs from GitHub when needed, orchestrates production, then asks keep-or-uninstall.

The problem 解决什么问题

想做视频却不知道用什么工具？想让 AI 帮你全自动完成？这个元技能把「发现 → 安装 → 编排 → 善后」整条链路自动化。

●Don't know which skill to use

内置 11 个 GitHub 实证技能包精选目录（manim_skill 1201★、motion-design-skill 2441★、OpenMontage 70908★、herk-edit-kit 2017★ 等），按视频类别自动匹配，零网络成本。

●No local capability

按类别走不同渠道——商业宣传类淘动效/模板/广告技能，知识科普类淘数学动画/数据可视化，其他类淘剪辑/字幕/配音，GitHub + 网络双通道兜底。

●Can't orchestrate after install

下载完成后自动通读并调用所装技能，按其工作流执行，缺环用 FFmpeg 补齐，直接产出成片。

●Skills piling up

每次生成后输出安装清单（技能/作用/来源），一键卸载走 git rm 或回收站机制，可回滚、零残留。

How it works 五步流水线

安装后直接对 Agent 说需求即可，例如「把勾股定理的证明做成讲解动画」。路由器自动完成：

DETECT 类别判定→ MATCH 本地匹配→ DISCOVER 渠道发现→ INSTALL 安全安装→ ORCHESTRATE 编排出片

最后输出善后报告：本次安装清单表 + 保留（回复 1）或卸载（回复 2）的交互询问。安装/卸载全程走安全协议：git 快照可回滚、frontmatter 强校验、多技能包需明确选择、禁 rm -rf。

Install & scripts 安装与脚本

WorkBuddy 技能市场搜索「视频创作技能路由器」一键安装；或手动 clone（Python 3.8+ 纯标准库，零第三方依赖）：

# manual install
git clone https://github.com/guipi888/video-skill-router.git \
  ~/.workbuddy/skills/video-skill-router

# 1. match (local skills + curated catalog)
python3 scripts/match_skill.py --query "做数学公式讲解动画"

# 2. discover (category-based GitHub channel)
python3 scripts/search_anim.py --category education --query "math animation"

# 3. install / list / uninstall
python3 scripts/manage_skill.py install --repo shuyicc/MathLens --reason "数学讲解"
python3 scripts/manage_skill.py list
python3 scripts/manage_skill.py uninstall --name MathLens
