# Differentiation — One Objective, Different Routes

Differentiation is not three versions of the lesson. It is one objective with different amounts of support, removed as accuracy rises. Three separate tasks is unsustainable at four lessons a day and quietly caps the lowest group's ceiling.

**Before planning for a mixed group**, read the `## Needs` table in that group's class file: every adjustment there runs by default in the plan, not on request (SKILL.md Rule 9). Read `## Roster` for the strengths and the watch-items that decide grouping.

## The Default Model

Same objective, same success criteria, different route in:

| Layer | For | Mechanism |
|---|---|---|
| Entry support | Students who cannot start | Worked example on the desk, first item done together, sentence stems, vocabulary pre-taught |
| Core | Most of the class | The planned practice set |
| Extension | Students at criterion early | Deeper, not further: harder cases of the same objective, unfamiliar contexts, explain-why tasks |

- **Support is removed by evidence, not by label.** A student at ≥80% accuracy on completion problems moves to independent work today, whatever the group they were placed in in September.
- **Never differentiate the objective downward without saying so.** A student who is only ever given the easier version never encounters the thing the course is about, and the gap compounds every unit.
- The extension task is permanent, known and posted, or the fast finishers become the behaviour problem (`classroom.md`).

## Scaffolds and How They Are Removed

A scaffold is temporary by definition. A scaffold nobody plans to remove is a ceiling.

| Scaffold | Remove when |
|---|---|
| Worked example visible | Accuracy on completion problems ≥80% |
| Sentence stems / writing frame | Two pieces produced with the frame at criterion |
| Vocabulary list on the desk | The word is used correctly, unprompted, twice |
| Partially completed table or diagram | The student produces the structure themselves once |
| Reduced item count | The student finishes the reduced set with time to spare |
| Adult or peer support at the elbow | The student initiates the first step unaided |

Write the removal condition next to the scaffold when you introduce it. Scaffolds are otherwise removed by the end of term, by accident, or never.

## The Range in Front of You

- The range in a typical class spans several years of attainment, and prior attainment predicts today's performance better than any label attached to the student.
- **Diagnose the specific gap, not the general level.** "Weak at maths" is not actionable; "cannot manipulate negative numbers, which blocks every rearrangement" is a two-lesson fix.
- The prerequisite check (`planning.md`) is the cheapest diagnostic you have. Run it at the start of each unit, not once a year.
- Attainment moves. Fixed groups set in September and never revisited become a prophecy; revisit grouping at every `report_cycle` as a `## Due` row.

## Accommodations and Access Arrangements

- **Record the adjustment and its trigger, never the diagnosis** (SKILL.md Rule 9): "25% extra time, all timed assessments"; "printed slides, off-white paper, every lesson"; "instructions repeated individually after the whole-class instruction". Not the condition, not the report text, not counselling content.
- **Run them by default.** An adjustment a student must request in public is one most students will not use.
- Anything on a formal plan — IEP, 504, EHCP, learning support plan, exam access arrangement — is a legal or contractual obligation in most systems, not a preference. Where you cannot deliver it, that is escalated the same day, not quietly dropped.
- Deliver adjustments discreetly: hand the printed copy to several students, start the timer without announcement, use a seating plan rather than a designated seat.
- The student is the expert on what helps. Ask privately, once, and write what they say into the `## Needs` table of the class file — as an adjustment, in their words.

## Common Adjustments by Need

Described by the barrier, because the barrier is what you can act on and the diagnosis is not yours to make.

| Barrier | Adjustments that usually help |
|---|---|
| Reading speed or decoding | Text read aloud or available as audio, key text extracted, dyslexia-friendly layout, off-white paper, sans-serif at larger size, no dense blocks |
| Writing output | Scribe, laptop, voice input, bullet-point acceptance, reduced volume with the same cognitive demand |
| Working memory | Instructions written as well as spoken, one step at a time, checklist on the desk, worked example left visible, no copying from the board |
| Attention regulation | Shorter work blocks with a defined finish, movement breaks built in, front seating away from doors and windows, task listed in visible steps |
| Sensory sensitivity | Predictable seating, warning before loud demonstrations, permission to leave for a named quiet space, reduced visual clutter |
| Processing speed | Extra time, reduced item count with the same range, no cold call without prior notice and think time |
| Hearing | Face the class when speaking, captions on any video, radio aid used correctly, written instructions, seat with sight lines |
| Vision | Enlarged or high-contrast print, verbal description of anything shown, tactile alternatives, no colour-only coding |
| Anxiety around performance | Answer known in advance where possible, private rather than public response formats, exam room and timing arranged early |
| Motor skills | Alternative recording methods, pre-drawn axes and tables, adapted equipment |

Universal design first: an unclear worksheet layout, colour-only coding and a wall of text harm everyone and harm some students disproportionately. Fixing the material is cheaper than fixing it per student.

## Language Learners

- **Language demand and cognitive demand are separate dials.** Reduce the language, hold the thinking. A student who cannot yet write the explanation can often draw, order, match or select it.
- Pre-teach the five words the lesson depends on, including the academic connectives ("therefore", "whereas", "as a result") that carry the reasoning.
- Give the sentence structures, not just the vocabulary: subject-specific writing is a genre, and native speakers learned it implicitly over years.
- Allow first-language thinking and note-taking; concept formation in a stronger language transfers, and forcing everything into the new language slows the concept, not just the words.
- A silent period at the start is normal and is not a measure of comprehension. Use non-verbal response formats to check understanding meanwhile (`checking.md`).
- Distinguish conversational fluency from academic language: a student can be fluent in the corridor and still be years from the register an exam answer requires. This gap is routinely mistaken for lack of ability.

## Extension for the Fastest

Deeper, never merely more:

- Harder instances of the same objective — unfamiliar contexts, missing information, more constraints.
- Explain-why and prove-it tasks: producing the justification is a level above executing the procedure.
- Find-the-error tasks built from real student work (anonymised).
- Design the next question, with the answer and the mark scheme — the hardest and most valuable version.
- Peer teaching, once, deliberately, with a structure. It is genuinely effective for the explainer and becomes exploitation if it is their permanent role.

Never: extra questions of the same type, unmarked "research", or helping the teacher. All three teach that finishing is punished.

## Reading Load

- Check the reading level of every text you set against the group's actual level, not the year label.
- Extract rather than summarise where the source language matters; summarising removes exactly the difficulty the subject is about.
- Pre-teach the vocabulary, then read the first paragraph together, then release. Cold-releasing a dense text produces a room of students staring at page one.
- Chunk with questions between sections rather than a single question at the end.

## Grouping

- **Flexible, task-specific, and revisited.** Groups fixed by attainment for a year become tracks, and the lower track systematically receives less content.
- Mixed groups work when roles create interdependence (`engagement.md`); they fail when the strongest student is simply doing the task.
- Temporary same-need groups are efficient for a specific gap: pull four students who missed the prerequisite while the rest extend. That is the 50-79% branch of the decision rule (`checking.md`), and it is the highest-value grouping there is.
- Never label a group publicly by attainment. Students always know, and the label becomes the identity.

## What Not To Do

| Practice | Why it fails |
|---|---|
| Three separate worksheets every lesson | Unsustainable, and the "lower" sheet usually has less thinking, not less support |
| Differentiating by learning style | The meshing hypothesis has failed repeatedly (Pashler et al. 2008); planning time spent on it buys nothing |
| Permanent ability tables | Becomes a track within a term; the bottom table's ceiling is set in September |
| Support assistant permanently attached to one student | Creates dependency and separates the student from the teacher's instruction; deploy by task instead |
| Lowering the objective quietly | Nobody notices until the terminal assessment, when it is too late to fix |
| Extension as more of the same | Punishes speed and teaches students to work slowly |
| Reading a diagnosis aloud, or naming an accommodation publicly | A disclosure the student did not consent to, and often unlawful |

**When an accommodation, adjustment or its trigger becomes known**, write it to the `## Needs` table in that class file — the adjustment and when it applies, never the diagnosis. **When a scaffold is introduced**, record its removal condition alongside it; **when it is removed**, note the date, because that is the evidence of progress a review meeting asks for. **When a tiered practice set or scaffolded resource works**, it goes to `~/Clawic/data/teacher/artifacts/<kebab-name>.md` with its `## Boxes` line, in the same turn (`memory-template.md`).
