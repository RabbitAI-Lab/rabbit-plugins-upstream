## Use Case:

Developers use this skill to launch, monitor, organize, and review AI coding agent sessions managed through Agent of Empires and tmux.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: YOLO mode skips permission prompts.

Mitigation: Enable it only when you intend to bypass those prompts.

Risk: Sandboxed sessions still receive documented credentials and mounts.

Mitigation: Use trusted aoe and tmux installations, and review which credentials and mounts are available to the session.

Risk: Forced cleanup or permanent deletion can remove valuable work.

Mitigation: Check for valuable work before using forced cleanup or permanent deletion.
