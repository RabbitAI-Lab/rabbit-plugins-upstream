# 评分规则 (quality_scoring.md)

网页磁力候选的评分由 `aggregator.py` 的 `score()` 实现，**全部加分项来自 `title_parser`
解析后的结构化字段**（年份/分辨率/编码/音轨/字幕/大小/低质判定），不对原始标题做正则。

> 设计原则：标题解析是稳定核心，网页抓取是脆弱外围。评分只依赖标题串内嵌信息。

## 评分公式

```
quality_score = (清晰度权重 + 来源加分 + 音频加分 + HDR加分 + 编码加分 + 语言加分 + 做种加分)
                × 来源可信度 × 可用性系数 × 标题相关度 × 大小合理性
```

## 加分明细

### 清晰度权重（`resolution` 字段）
| 分辨率 | 权重 |
| --- | --- |
| 4320p / 8k | 120 |
| 2160p / 4k | 100 |
| 1440p | 85 |
| 1080p | 80 |
| 720p | 60 |
| 576p | 40 |
| 480p | 30 |
| 未识别 | 50（默认） |

### 来源加分（`source` 字段）
| 来源 | 加分 |
| --- | --- |
| UHD BluRay | +15 |
| REMUX | +12 |
| BluRay | +10 |
| WEB-DL | +5 |
| WEBRip | +3 |
| HDTV | 0 |
| DVDRip | -5 |

### 音频加分（`audio` 字段，按优先级取首个命中）
| 音频 | 加分 |
| --- | --- |
| Atmos | +6 |
| TrueHD | +5 |
| DTS-HD MA | +5 |
| DTS-X | +5 |
| DTS-HD | +4 |
| FLAC | +4 |
| LPCM | +3 |
| DTS | +3 |
| E-AC3 / DDP | +2 |
| AC3 | +2 |
| AAC | +1 |

### HDR 加分（`hdr` 字段）
| HDR | 加分 |
| --- | --- |
| Dolby Vision | +8 |
| HDR | +6 |

### 编码加分（`codec` 字段）
| 编码 | 加分 |
| --- | --- |
| AV1 | +5 |
| H.265 / HEVC | +4 |
| H.264 / AVC | +1 |

### 语言/字幕加分（`language`/`subtitle` 字段）
| 条件 | 加分 |
| --- | --- |
| 三语及以上 | +12 |
| 双语 | +8 |
| 简体+繁体 | +5 |
| 特效字幕 | +6 |
| 含字幕 | +2 |

### 做种加分（`seeders` 字段，对数缩放避免碾压清晰度）
`min(8, seeders // 20)`

## 系数

### 来源可信度（`credibility`，config.json 配置）
正规站 0.9，论坛 0.7，不明 0.5（默认 0.8）。

### 可用性系数（`link_type` 字段）
- `direct` / `magnet`：可直接下载 = 1.0
- `torrent`：种子文件（需二次下载解析）= 0.92
- `playpage`：仅播放页，需二次解析 = 0.5
- 未知 = 0.85

### 标题相关度（对 `title_cn`/`title_en`/原始 `title` 三者匹配取最大）
| 匹配 | 相关度 |
| --- | --- |
| 精确匹配（归一化后相同） | 1.0 |
| 子串匹配，后续非 CJK | 1.0 |
| 子串匹配，后续 CJK + 年份相同 | 0.9 |
| 子串匹配，后续 CJK + 年份不同 | 0.5 |
| 子串匹配，后续 CJK 无年份 | 0.6 |
| 前缀匹配（续集） | 0.8 |
| 弱相关 | 0.3 |

> 相关度 < `min_relevance`（默认 0.6）的候选进入 `excluded`，不参与排序。

## 大小合理性（`size_factor`，NAS 空间有限，过大资源降权）

> 设计意图：适合才是最重要的——不是信息最全的最高分，而是大小合理的优先。
> NAS 可用 3TB，单剧占 7%+（如 40 集×5GB=200GB）不可接受。

大小合理性因子 `0.5~1.0`，分两段：

1. **大小未知**：高码版（`is_high_bitrate`）轻度降权 `0.9`，其余 `1.0`
2. **已知大小**：按集均（剧集）/总大小（电影）与分辨率合理区间评估：

| 类型 | 分辨率 | 理想(≤) | 软上限 | 说明 |
| --- | --- | --- | --- | --- |
| 剧集 | 4K | 2.5 GB/集 | 5 GB/集 | 5GB/集×40集=200GB 过大 |
| 剧集 | 1080p | 1.2 GB/集 | 2.5 GB/集 | |
| 电影 | 4K | 50 GB | 100 GB | |
| 电影 | 1080p | 20 GB | 40 GB | |
| 其他 | — | 1 GB/集(剧) / 10GB(影) | 3 / 20 | 兜底 |

- 理想区间内：`1.0`（不罚）
- 理想→软上限之间：线性 `1.0 → 0.7`
- 超过软上限：重罚，越大越低，下限 `0.5`

集数来源：`title_parser` 解析「全N集/共N集」→ `episode_count`；未知时剧集按 40 集粗估。

> 无码率资源（缺 codec/audio/source 标记）不被额外惩罚——缺失=0 加分而非负分，
> 分辨率仍是主要质量指标，保证公平评分。

### 高码标记（`is_high_bitrate`）
`title_parser` 检测标题中的「高码」字样（如 `[高码版]`/`高码版`）。
- 大小已知时：由 `size_factor` 按实际大小评估，不重复降权
- 大小未知时：`size_factor` 取 `0.9` 轻度降权（高码版体积通常偏大）

### 单集降权（`is_single_episode`）
整季搜索命中单集文件（`-NN.mp4`/`EP01`/`第NN集`）时 ×0.5，排在整季资源之后（不剔除）。

## 硬过滤（不参与评分，直接剔除）

`title_parser.is_low_quality` 判定为真的候选直接进入 `excluded`：
CAM / TS / TC / 枪版 / 枪影 / 抢先版 / 预告版 / 样片 / 预告片 / sample / trailer / DVDScr / workprint。
