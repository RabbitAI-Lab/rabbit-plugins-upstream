## 标准FMEA表格结构

FMEA分析需要记录以下核心信息：

| 字段 | 说明 | 填写要求 |
|------|------|---------|
| 项目编号 | 唯一标识符 | 按系统命名规则，如 A-01, B-02 |
| 系统/子系统 | 分析范围 | 明确界定分析边界 |
| 功能描述 | 组件应完成的功能 | 使用动词+名词格式 |
| 潜在失效模式 | 什么情况下会失效 | 回答"什么会失效" |
| 潜在影响 | 失效的后果 | 对上级系统/用户的影响 |
| 严重度(S) | 后果严重程度 | 1-10分评分 |
| 潜在原因 | 失效的机理/原因 | 回答"为什么会失效" |
| 发生度(O) | 原因发生的频率 | 1-10分评分 |
| 当前预防措施 | 预防失效发生的方法 | 现有控制手段 |
| 当前探测措施 | 发现失效的方法 | 现有检测手段 |
| 探测度(D) | 发现失效的能力 | 1-10分评分 |
| 风险优先数(RPN) | S×O×D | 1-1000 |
| 建议措施 | 改进方案 | 责任人+目标日期 |
| 措施结果 | 实施后的效果 | 更新后的S/O/D |

## 评分标准

### 严重度(S)评分标准

| 评分 | 影响 | 失效后果示例 |
|------|------|-------------|
| 10 | 极高 | 危害安全/违反法规，无预警 |
| 9 | 极高 | 危害安全/违反法规，有预警 |
| 8 | 高 | 系统功能丧失，产品无法使用 |
| 7 | 高 | 系统功能下降，用户不满 |
| 6 | 中 | 性能下降，部分功能受损 |
| 5 | 中 | 性能下降，用户体验差 |
| 4 | 低 | 轻微不便，用户可察觉 |
| 3 | 低 | 轻微不便，用户略察觉 |
| 2 | 极低 | 几乎无影响 |
| 1 | 极低 | 无影响 |

### 发生度(O)评分标准

| 评分 | 可能性 | 近似PPM |
|------|--------|--------|
| 10 | 极高 | >100,000 |
| 9 | 高 | 20,000-100,000 |
| 8 | 高 | 10,000-20,000 |
| 7 | 中高 | 2,000-10,000 |
| 6 | 中 | 1,000-2,000 |
| 5 | 中低 | 200-1,000 |
| 4 | 低 | 100-200 |
| 3 | 低 | 10-100 |
| 2 | 极低 | 1-10 |
| 1 | 极低 | <1 |

### 探测度(D)评分标准

| 评分 | 探测能力 | 说明 |
|------|---------|------|
| 10 | 极低 | 无法探测或无探测方法 |
| 9 | 极低 | 探测方法很不可靠 |
| 8 | 低 | 探测方法依赖目视/人工 |
| 7 | 低 | 探测方法基于简单测量 |
| 6 | 中 | 探测方法基于通用测试 |
| 5 | 中 | 探测方法基于标准测试 |
| 4 | 中高 | 探测方法基于先进测试 |
| 3 | 高 | 探测方法可靠，有预防措施 |
| 2 | 高 | 探测方法很可靠 |
| 1 | 极高 | 探测方法几乎肯定发现 |

## 填写指南

### 功能描述格式
```
[动词] + [对象] + [结果/目的]
```
示例：
- 提供持续的驱动转矩
- 维持工作温度在范围内
- 保护电路免受过载损坏

### 失效模式描述格式
```
[失效类型] + [对象] + [失效特征]
```
常见失效类型：
- 功能丧失：完全不工作
- 功能退化：性能下降
- 功能间歇：时而工作时而不工作
- 意外功能：产生非预期输出

示例：
- 转矩输出不足
- 响应时间超出规格
- 输出信号漂移

### 失效影响描述
从以下层级考虑：
1. 对子系统的影响
2. 对系统的影响
3. 对最终产品的影响
4. 对安全/法规的影响

## 示例分析项

### 示例：电动机的轴承失效分析

| 项目 | 内容 |
|------|------|
| 项目编号 | M-01 |
| 系统/子系统 | 驱动系统/主轴电机 |
| 功能 | 传递持续转矩至负载 |
| 失效模式 | 轴承磨损导致异常振动 |
| 潜在影响 | 转矩波动，噪声增大，最终卡滞 |
| 严重度 | 7 (功能严重下降) |
| 潜在原因 | 润滑不足/安装不当/过载运行 |
| 发生度 | 4 (极少发生) |
| 当前预防 | 定期润滑，振动监测 |
|探测度 | 5 (定期检查可发现) |
| RPN | 140 (很高) |
| 建议措施 | 增加在线振动传感器，设置预警阈值 |
| 责任人 | 张工 |
| 目标日期 | 2024-06-30 |
| 修订后S/O/D | 7/3/3 |
| 修订后RPN | 63 (高) |
| 状态 | 进行中 |

## 2019版FMEA特点

### 5步法工作流程

1. **规划和准备**
   - 定义分析范围和边界
   - 确定团队成员
   - 收集历史数据

2. **结构分析**
   - 建立系统结构
   - 定义项目结构树
   - 确定分析接口

3. **功能分析**
   - 识别功能和要求
   - 建立功能网络
   - 分析功能关系

4. **失效分析**
   - 识别失效模式
   - 分析失效影响
   - 评估风险等级

5. **优化**
   - 制定改进措施
   - 评估措施效果
   - 记录闭环结果

### 关键概念

- **基础FMEA**：完整、标准化的分析
- **补充FMEA**：针对特定问题的深入分析
- **FMEA-MSR**：监视与系统响应（用于安全相关系统）
- **元FMEA**：对FMEA过程本身的FMEA
