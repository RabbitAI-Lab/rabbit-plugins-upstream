# 问询函答复核对 · 监管问询逐条拆解

把一份监管问询函拆成一张表：**每一问都能对到它的答复**。

监管机关问了什么、要求提供什么材料、公司答了什么、还差哪几份回复文件——四栏摆开，缺的显式点名。

**不代写回复、不出结论、不代公司表态。** 引文是公函原话，本件只负责把原话摆到它该在的位置上。

---

## 一、先说清一件事：问询函原件抓不到

**交易所问询函的函件原文，公开公告库里没有正式通道。** 这不是没查：

- 巨潮全文检索「问询函」，命中的绝大多数是**公司侧的回复公告**；另一小部分是公司自己发的「关于**收到**……问询函的公告」——那只是告知，不含问题正文。
- 上交所、深交所自建的「监管问询」频道页面在，但查询接口返回为空；北交所跳转。

所以本件**没有、也不做「自动抓取问询函原文」**。函件原件由你自己贴进来或给本地路径。

能自动拿到的是**回复侧**：回复公告、年报／半年报、募集说明书（发行场景）。本件把这一侧排成骨架并核对齐备性。

## 二、三十秒跑通（零输入）

不给任何数据文件，也能跑出一份完整合规的成品，看它长什么样、判据怎么打：

```bash
python3 scripts/check_inquiry_letter.py --demo
```

把这份样例存下来再跑一遍机检，它能自己过：

```bash
python3 scripts/check_inquiry_letter.py --demo > 样例核对表.md
python3 scripts/check_inquiry_letter.py 样例核对表.md
# → 样例核对表.md 结论：六道全过（零发条）
```

接着换成你自己那份稿子：

```bash
python3 scripts/check_inquiry_letter.py 你的核对表.md
```

退码 `0` 全过、`1` 有发条、`2` 用法错、`3` 读不到文件或空稿。

### 拿不到成品时，从原件开始的三步

1. **把问询函原件放进来**（粘贴或本地路径），抄下每一问，连原句一起抄。
2. **逐问对答复**：答了的写回复要点，没答的写 `- 问题N 未取到：<缺什么>`——**不许留空**。
3. **跑一遍自检**，红一条改一条：

```bash
python3 scripts/check_inquiry_letter.py --selftest      # 10 条内置夹具自检
```

### 先确认通道在场（可选）

配了 `CUE_API_KEY` 才需要这一步。先列目录，再按目录里的路由地址确认工具在场：

```bash
CATALOG="https://cuecue.cn/api/mcp-catalog"
curl -s "$CATALOG" | head -c 2000
# 从目录里取本组的路由地址，确认工具在场
curl -s -X POST "$ROUTING_URL" \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

没配凭据也能用：把材料放进工作区，走用户直供那条路。

## 三、六道机检在管什么

| 码 | 名称 | 判什么 | 最常拦住的情况 |
|---|---|---|---|
| `IL-STRUCT` | 形制 | 头部四件自标、`主体：`、`文件：` 在场；六节齐且有序；前三节各至少一条发现行 | 六节缺一节；某节只有小标题；自造了第七栏 |
| `IL-QUOTE` | 原句与锚 | 每条发现行以「」原句＋〔锚：…〕＋`[S#]` 收尾；来源行带可点 URL 与检索日；引用的编号须已登记 | 只写要点没抄原句；来源行只有标题没有链接 |
| `IL-PAIR` | 问题与回复两向 | 索引里每一问，回复要点节必须有同号条目，反之也判 | 第 3 问在索引里，回复要点节却直接跳到第 4 问 |
| `IL-GAP` | 缺项点名 | 正文写了未取到而清单没列要发，反之也发；零缺口须写 `未取到：无` | 用「不适用」「无此项」搪塞 |
| `IL-MEDIA` | 回复主体齐备 | 一条问询通常出 3–5 份，公司／会计师／保荐机构各出；只登记公司本体且缺项清单也没点名中介机构 ⇒ 发 | 只搜了公司名，漏掉会计师和保荐机构那几份 |
| `IL-LINE` | 红线 | 剥掉「」引文后，代公司表态与出结论的词零命中 | 「本公司将按要求整改」「不构成重大影响」 |

---

## 四、四条红线（这件的立身之本）

1. **不代拟答复。** 「本公司将」「现回复如下」「特此答复」——剥掉引文后仍出现即发。引文里的是原文，照抄不算。
2. **不出结论。** 「不构成重大影响」「不存在问题」「风险可控」「回复充分」「预计通过」一律零命中。核对的产物是登记表，不是判断书。
3. **没答的不许留空。** 索引里每一问，回复要点节必须有一条同号记录：要么给要点，要么写 `未取到`。留空等于把没答的藏起来。
4. **缺项不许搪塞。** `不适用`／`无此项`／`无需披露` 是把没查当成没有，和 `未取到` 不是一回事。

## 五、一条发现长什么样

```markdown
- 问题1 募投项目产能消化「请说明本次募投项目新增产能的消化措施及合理性」〔锚：问询函·第 1 页·问题 1〕[S1]
```

没答的那一问，长这样（没有原句可挂，是设计不是漏网）：

```markdown
- 问题2 未取到：前次募集资金使用明细
```

回复文件那一栏，长这样：

```markdown
## 4. 回复文件

- 主体：公司本体｜[S2]
- 主体：会计师事务所｜[S3]
```

**为什么要有这一栏：** 一条问询的公开产出通常是 3–5 份文件，分别由公司、会计师事务所、保荐机构／律师出。只搜公司名会漏掉中介机构那几份——所以只登记了公司本体、而缺项清单里也没点名中介机构时，`IL-MEDIA` 会发。

## 六、和另外几枚包怎么分

| 你手上是 | 用哪枚 |
|---|---|
| 一份问询函，要逐条拆开、看哪一问还没答 | **本件** |
| 帮我起草回复文本 | 不做——代拟不在本件范围 |
| 这份回复能不能过审、会不会被处罚 | 不做——判断位一律 `[待人工]` |
| 公告事件的五段速读卡 | `event-brief-cn` |
| 尽调清单里监管函／问询函／警示／处罚的登记 | `dd-checklist` |
| 定增发行的十条款卡 | `placement-terms-cn` |
| 可转债的八条款卡 | `convertible-bond-terms-cn` |

**和 `dd-checklist` 的分界**：那一件把问询函归到「合规与处罚」一类，登记的是**一条带锚的事件行**——何时、何种函、涉及谁。本件不登记「有这封函」，本件登记函里**问了哪几条、答了哪几条、哪条没答**。前者是事件，后者是条款对照。

## 七、零通道：先排骨架

没有通道产物也能跑，本脚本只读你给的那份清单：

```bash
python3 scripts/make_outline.py 清单.jsonl 骨架.md
```

清单是 JSONL，每行三键必需：`title`／`url`／`asof`（检索日 `YYYY-MM-DD`），`id` 可省按行序给 `S1`/`S2`…

- 坏行（非法 JSON／缺键／日期不合形／url 不是 http）**逐行点名、不采信**，好行照收。
- **空清单退 1，不出空壳。**
- 排出的骨架**故意过不了机检**，这是设计，不是待修。

```bash
python3 scripts/make_outline.py --selftest       # 15 条内置夹具
```

## 八、跑夹具与测试

```bash
bash scripts/fixtures/run_fixtures.sh
python3 tests/test_inquiry.py
```

三档：机检自测 / 好样坏样逐枚单跑 / 在好样上逐行替换做正反对照（该红的红、该不红的不红）。零网络、零计费，产物只落临时目录，跑完即删。

末行自报「档数=3｜不合=N｜不可判=N」；退码 `0` 全过、`1` 有不合、`3` 取值域故障。

`tests/` 跑的是外壳属性——`--help` 退 0、无参退 2、缺文件或空稿退 3、`--demo` 产物自过机检且逐字节可复现且与好样夹具同源、空清单不出空壳、埋点落盘且失败静默。

## 九、首次运行埋点

入口脚本解析参数成功后、干正事之前，会往 `~/.cue-usage/<slug>-<日期>` 落一枚**空文件**。

**为什么要它：** 平台的两个下载计数器都不可信——新 listing 上架首 48 小时会被一次性播种 50~60 的初始计数，那不是用户下载。本地这枚文件是本件唯一能证明「真有人装上并跑过」的证据。

**它不会碍事：** 任何失败（家目录只读、配额满、无 HOME）都静默跳过，不报错、不改退码、不吐一句杂音。同一天跑多次只留一枚。

要清掉：`rm -rf ~/.cue-usage`。

## 十、素材从哪来

- **问询函原件**：公开库没有正式通道，请自行粘贴或给本地路径。
- **回复侧**：回复公告、年报／半年报、募集说明书（发行场景），走 `+parse` 解析后按清单排骨架。
- **通道取证**：配了 `CUE_API_KEY` 后可走公告检索与原文解析。装好 skill ≠ 已配凭据 ≠ 通道已连，三层分开看。
- **零通道**：`make_outline.py` 排骨架，见第七节。

本件不发请求、不代付费，消耗以服务端返回为准。
