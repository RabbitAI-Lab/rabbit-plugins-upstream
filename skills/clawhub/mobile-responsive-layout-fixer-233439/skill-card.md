## Description: <br>
Helps frontend developers, designers, startup teams, and maintainers create practical workflows, artifacts, checklists, analysis, code changes, and verification notes for mobile responsiveness, navigation layout, and cross-device UI issues. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External developers, designers, startup teams, and maintainers use this skill to plan, implement, and validate fixes for mobile-responsive layouts, navigation behavior, and cross-device UI usability. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad frontend and layout trigger wording may invoke the skill for requests that are not specifically about mobile-responsive layout work. <br>
Mitigation: Confirm the user's target layout, device constraints, and success criteria before producing implementation guidance. <br>
