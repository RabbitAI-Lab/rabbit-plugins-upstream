## Description:

Builds a section-by-section blog outline from a keyword list, with the search intent, a word budget and the questions to answer. Use when the user asks for blog outline generator, article outline template, blog post outline writer. For US content marketers and freelance writers who publish two to four blog posts a month.

This skill is ready for commercial/non-commercial use.

External content marketers and freelance writers use the skill to turn keyword lists into section-by-section blog outlines with search intent, section budgets, and questions to answer.

## Known Risks and Mitigations:

Risk: The optional Windows application is separate from the bundled workflow and has not been independently reviewed.

Mitigation: Avoid using it unless it has been separately evaluated; it is not needed for the bundled workflow.

Risk: The outline may not match the supplied template or input assumptions.

Mitigation: Check the template/input mismatch and review the generated outline before relying on it.

Risk: Reusing an output directory can overwrite `outline.md`.

Mitigation: Use a dedicated output directory and preserve existing output before rerunning.
