# 竞品情报自动化

## 这个技能做什么

输入你的产品和1-3个竞品名称，AI 自动完成：

1. **竞品情报收集**：功能、定价、用户量、融资、团队规模
2. **功能矩阵对比**：逐项对比核心功能的有无和强弱
3. **定价策略分析**：定价模式、价格区间、折扣策略
4. **用户口碑分析**：真实用户评价中的高频好评和高频吐槽
5. **差异化机会识别**：竞品没做好、你可以发力的方向
6. **战略建议**：怎么定位、怎么打、先做什么

## 触发条件

- 提到"竞品""竞争分析""对比""竞品研究"
- 使用 `/competitor-intel` 或 `/competitor` 命令
- 给出多个产品名要求对比

**示例**：
- "帮我分析 Linear 和 Jira 的竞争格局"
- "我们做AI写作工具，竞品是 Jasper 和 Copy.ai"
- "/competitor-intel Notion vs Obsidian vs Roam"

## 工作流

### 步骤 1：确认输入

必需信息：
- 你的产品名称（或你要分析的主产品）
- 1-3个竞品名称

可选信息：
- 你的产品定位（一句话）
- 你最关心的维度（功能？定价？用户？）

### 步骤 2：情报收集（每个竞品独立搜索）

对每个竞品执行3次搜索：

**搜索 1 — 产品和功能**
```
查询: "{竞品名} features pricing review 2026"
目标: 核心功能列表、定价方案、最新版本特性
```

**搜索 2 — 市场表现**
```
查询: "{竞品名} users revenue funding valuation"
目标: 用户量、收入估计、融资情况
```

**搜索 3 — 用户口碑**
```
查询: "{竞品名} review pros cons alternative reddit"
目标: 真实用户的评价、吐槽点、替代需求
```

### 步骤 3：功能矩阵对比

构建功能对比矩阵：

| 功能维度 | 你的产品 | 竞品A | 竞品B |
|---------|---------|-------|-------|
| 核心功能1 | ✅/❌/⚠️ | ✅/❌/⚠️ | ✅/❌/⚠️ |
| 核心功能2 | ... | ... | ... |

标注说明：
- ✅ 完整支持
- ⚠️ 部分支持
- ❌ 不支持

如果不确定你的产品功能情况，向用户确认或标注"待确认"。

### 步骤 4：定价分析

| 产品 | 免费方案 | 入门价 | 专业价 | 企业价 | 定价模式 |
|------|---------|--------|--------|--------|---------|
| 你的产品 | {信息} | {价格} | {价格} | {价格} | {订阅/买断/用量} |
| 竞品A | ... | ... | ... | ... | ... |

**定价洞察**：
- 市场价格区间
- 你的定价是否偏高/偏低
- 有没有定价模式创新的机会

### 步骤 5：用户口碑分析

对每个竞品，总结：

**高频好评**（用户最喜欢的3点）：
1. {优点}
2. {优点}
3. {优点}

**高频吐槽**（用户最不满意的3点）：
1. {缺点}
2. {缺点}
3. {缺点}

**替代需求**（用户提到的"如果有xxx就好了"）：
1. {需求}
2. {需求}

### 步骤 6：差异化机会识别

基于以上分析，识别3-5个差异化机会：

| 机会 | 竞品薄弱程度 | 市场需求强度 | 实现难度 | 优先级 |
|------|:----------:|:----------:|:-------:|:-----:|
| {机会1} | 高/中/低 | 高/中/低 | 高/中/低 | ⭐⭐⭐ |
| {机会2} | ... | ... | ... | ... |

**优先级判断规则**：
- 竞品薄弱 + 需求强 + 难度低 = ⭐⭐⭐ 立即做
- 竞品薄弱 + 需求强 + 难度高 = ⭐⭐ 规划做
- 其他组合 = ⭐ 观望

## 使用示例

**用户输入**：
> 我们做AI代码审查工具 CodeGuard，竞品是 CodeRabbit 和 Cursor

**AI 行为**：
1. 搜索 CodeRabbit 和 Cursor 的信息（各3次）
2. 构建功能矩阵
3. 分析定价
4. 收集用户口碑
5. 识别差异化机会
6. 输出完整报告

## 注意事项

1. **客观性**：不要为了让用户的产品看起来好而贬低竞品
2. **数据来源**：所有信息来自WebSearch，标注获取日期
3. **时效性**：优先2026年数据，旧数据标注日期
4. **可执行性**：战略建议必须具体到"做什么、怎么做"，不能是"加强产品力"
5. **诚实标注**：搜索不到的信息标注"未公开"

## 技能边界

这个技能**不做**：
- 不做恶意竞争分析（如寻找竞品漏洞进行攻击）
- 不做财务深度审计
- 不替代用户的产品决策（报告是辅助，决策是人做的）
