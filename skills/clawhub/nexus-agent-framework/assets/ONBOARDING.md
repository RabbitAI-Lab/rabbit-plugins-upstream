## 第一步：框架概述 | Step 1: Framework Overview

### Nexus Agent Framework 是什麼？ | What is Nexus Agent Framework?

Nexus Agent Framework 是一個**安全優先**的通用 Agent 工作框架。

Nexus Agent Framework is a **security-first** universal Agent work framework.

### 核心功能 | Core Features

| 功能 | 說明 |
|------|------|
| 🛡️ 安全堡壘 | 五層安全審核，解決指令矛盾 |
| 🔮 Nexus 樞紐 | 連接所有記憶，形成知識網絡 |
| 💡 創意激發 | 主動提供創意想法和替代方案 |
| 📊 情感溫度 | 追蹤用戶滿意度，自動調整風格 |
| 🔄 雙向學習 | Agent ↔ User 雙向反饋循環 |

| Feature | Description |
|---------|-------------|
| 🛡️ Security Fortress | 5-tier audit, resolves directive conflicts |
| 🔮 Nexus Hub | Connect all memories into knowledge network |
| 💡 Idea Generator | Proactively provide creative ideas |
| 📊 Emotion Thermometer | Track satisfaction, auto-adjust style |
| 🔄 Two-way Learning | Agent ↔ User bidirectional feedback |

### 請回答以下問題 | Please answer the following questions

#### Q1. 您的稱呼 | Your Name
```
您希望我如何稱呼您？
```

#### Q2. 主要使用語言 | Primary Language
```
您希望我用什麼語言與您交流？
What language would you like me to use for communication?

選項 | Options:
- 繁體中文 (Traditional Chinese)
- 簡體中文 (Simplified Chinese)
- English
- 雙語混用 (Bilingual mixed)

回答格式 | Format: [您的選擇 | Your choice]
```

#### Q3. 工作領域 | Work Domain
```
您主要從事什麼領域的工作？
What is your primary work domain?

選項 | Options:
- 軟體開發 | Software Development
- 數據分析 | Data Analysis
- 產品管理 | Product Management
- 市場營銷 | Marketing
- 學術研究 | Academic Research
- 創意設計 | Creative Design
- 其他 | Other

回答格式 | Format: [您的選擇 | Your choice]
```

#### Q4. 信任級別 | Trust Level
```
您希望我默認的信任級別是什麼？
What default trust level would you like?

選項 | Options:
- 保守 (Conservative): 所有外部操作都需要確認
- 適中 (Moderate): 常見操作自動執行，敏感操作需確認
- 開放 (Open): 大多數操作自動執行，危險操作需確認

回答格式 | Format: [您的選擇 | Your choice]
```

#### Q5. 主動行為偏好 | Proactive Behavior Preference
```
您希望我多主動？
How proactive would you like me to be?

選項 | Options:
- 謹慎 (Cautious): 只在被問時提供建議
- 平衡 (Balanced): 適時提供建議但不打擾
- 積極 (Proactive): 主動提供創意和建議

回答格式 | Format: [您的選擇 | Your choice]
```
