# opinion-to-article

观点在脑子里，写出来就没味了？从"你想表达的一个想法"出发，五步产出一篇有你自己标识的文章或短视频脚本。

AI 是搜索员、结构师、编辑，不是代笔。观点是你的，素材是真的，结构是逻辑的，标识是你自己长出来的。

## 适合谁用

- 自媒体创作者、博主，有观点但不会组织成文
- 想保持个人 IP 风格，又不想从零开始搭结构的人
- 需要快速把直播、访谈、聊天里冒出来的想法变成内容的人

## 五步流程

1. **观点提炼**：你说一段话或几句碎话，AI 提炼成一句可证伪的核心判断，确认靶心
2. **IP 标识识别**：从你的原始表达里提取身份视角、语言习惯、态度边界，沉淀成"表达偏好卡"，文章的独特标识从这里来
3. **联网拓展**：AI 联网搜索四类素材（支持性证据、反驳观点、硬数据、场景引子），每条标注来源和用途
4. **逻辑重组**：文章走"立冲击/立本质/立机制/立边界/立解法/立落点"五到七层；脚本走"钩子/观点/案例/金句/CTA"，每层绑定素材
5. **反馈迭代**：你看草稿给反馈，反馈回灌表达偏好卡，迭代两到三轮出终稿

## 安装

把本仓库的 `SKILL.md` 放入你的 Agent 技能目录（如 `~/.qoderworkcn/skills/opinion-to-article/SKILL.md`），或通过技能管理界面导入。

## 素材纪律

- 联网素材全量可用，禁止省略关键数据和做法
- 数字必须有来源，搜不到标"待核实"，不编造
- 你的个人经历优先于公开信息

## 示例输出

### 文章

```
# 标题（你选定或从候选里挑）

开场（立冲击，三到五行，自己的场景）
...
## 小标题（叙事式，非概念式）
...
收尾：判断句
```

### 短视频脚本

```
【钩子】____
【观点】____
【案例1】____（来源）
【案例2】____（来源）
【金句】____
【CTA】____
```
