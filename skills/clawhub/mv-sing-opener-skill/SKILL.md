# 人物说唱视频制作官（四角色前置 · 图片人物 · 按音频拆镜）

**一句话定位**：把**一个想拍的人物/主题 ＋ 一条说唱音频**，变成**一条开口就对得上口型的说唱视频**——
人物不换、场景不乱；**音频多长成片就多长、速度就是音频的速度**；超过 30 秒按句间切点自动拆镜。

> **本 skill 只做一件事**：图片里的人，跟着你给的音频开口（按 30 秒上限自动拆镜）。
> **不做**：整首歌 MV、多镜叙事、镜头切换、自己生成音频、歌曲下载/翻唱、视频素材处理。
> **要整首多镜 MV** → `mv-production`（另行提供）；**要多镜整首对口型** → `mv-concert`（另行提供）；
> **只要说唱词、不要视频** → 直接用 ④ 的产出；封神人物也可走 `fengshen-rap-30s`（另行提供）。

**四角色边界（不许串岗）**：

| 角色 | 只回答 | 只写 | 不碰 |
|---|---|---|---|
| **任务解读官** | 到底要做什么、做到什么算完成、还缺什么 | `01-解读/01-任务书.md` | 不写方案、不写词 |
| **创意总监** | 唱什么、怎么唱、长什么样 | `02-方案/01-方案.md` | 不写钩子、不写全词 |
| **钩子官** | 第一句凭什么让人不划走 | `02-方案/02-钩子句.md` | 不写第二句 |
| **词作者** | 每一句为什么必须存在 | `02-方案/03-歌词.md` | 不改钩子、不改曲 |

> **用户明确说「跳过前面，直接出片」时**：只能跳 ②③④ 的*展示*，不能跳*落盘*——
> 先把四份记录补齐（可以标「用户授权按默认执行」），再进 ⑤。没有记录的创作＝没有发生。

## 二、输入与四个硬门

| 输入 | 必需 | 处理 |
|---|---|---|
| **人物/主题描述** | **是（硬门）** | 用户原话逐字记进任务书；没描述就不开工 |
| **说唱音频** | **是（音频门）** | 有 → ④ 听写核对；无 → ④ 写词＋出曲参数＋**海绵音乐提示词**，停在 ④ 等回传；未回传不得进 ⑥⑦⑧ |
| **人物图片** | 否 | jpg/png/webp；有 → 校验后用；无 → 按方案风格卡生成一张 |
| 时长 | 否 | 默认 30s / 12 句；可选 40s / 16 句；成片按音频实际长度 |
| 画幅 | 否 | 默认 **9:16**；可选 16:9 / 1:1 / 3:4 / 4:3 |
| 是否要字幕 | 否 | 默认不烧字幕；要就说，⑧ 生成 `.srt`（可选烧进画面） |

### 2.1 四个硬门（顺序不能反）

1. **任务门**：① 结束必须有 `01-解读/01-任务书.md`，写明「做什么/给谁看/多长/素材状态/缺口默认值」。
2. **图门**：⑤ 结束必须有可用人物图（用户图或生成图）。
3. **音频门**：进入 ⑥ 前必须有一条可用说唱音频，已按 ASR 原速切分（末字完整、末段淡出），且不是纯伴奏。
   **音频只能来自用户本次提供或按 ④ 的海绵音乐提示词出曲后回传；禁止从历史项目/其他目录复制旧音频。**
4. **上传门**：⑥ 图与音频都必须拿到**公网直链且 HEAD 200**，才允许进入 ⑦ 与后续出片。
   > 任一门没过就停住，如实报错；**不要假装已上传**，也不要先出片再补链。

### 2.2 音频状态决定路线

| 状态 | ① 任务书要写 | 后续 |
|---|---|---|
| **有音频** | 文件路径、时长、是否 30s 内 | ④ 听写核对（不改词）→ ⑤ 切音频 |
| **无音频** | 「本阶段交付到歌词＋出曲参数＋海绵音乐提示词」 | ④ 写词＋参数＋**海绵音乐提示词** → **停在 ④**；用户出曲回传后才进 ⑤ 切音频；未回传不得进 ⑥⑦⑧ |

**不许因为没音频就停摆，也不许假装音频已在手，更不许从旧项目复制音频。**

## 三、铁律（违反即返工）

① **四角色前置链固定**：① 任务解读 → ② 方案 → ③ 钩子 → ④ 歌词，**一站一角色、一站一文件**。
   不许一个人一口气写完全部内容再补记录；每站完成**停下等确认**。

② **不内置任何信息**：不调用预设人物库、母题库、场景库、金句库、示例文案。
   所有内容必须从**本项目用户原话**推导；每个名词都要能回答「它从哪来」。
   推导链写进对应记录文件，**不能只在对话里说**。

③ **速度＝音频本身的速度，长度＝人声长度，按 30 秒上限自动拆镜**：
   - **一个字都不改速**：`atempo` 永远不用、不改采样率改速；
   - **音频只用 `scripts/cut_audio.py` 切**（没有变速参数），只做裁区间 + 补齐 + 末段淡出；
   - **`--end` 必须 ＝ 最后一个字的结束时间 + 0.5~0.8s**；
     ⚠️ 拿句子的「开始时间」当结尾，会把最后一个字整段切掉；
   - **末段强制 0.25–0.3s 淡出**；
   - **先按信息段拆镜**：40s 拆 3–4 镜、30s 可 1–2 镜；更长的音频再用 `ceil(人声长度 / 30)` 兜底；每镜 `seconds ≤ 30`、`duration = ceil(seconds)`；
     切点必须落在**句与句之间**（不切词），各镜音频首尾相接；
   - 不做帧接续、不做视频延长。
   - **音频来源硬门**：音频只能来自用户本次提供或按 ④ 提示词出曲后回传；**禁止从 `assets/output` 旧项目、其他目录、样例里复制音频**；没有音频不得进入 ⑥⑦⑧，发现旧音频一律删除并回到 ④。

④ **口型由音频驱动**：顶层 `generate_audio: false`，单镜 `ref_audio_urls` **恰 1 条**。

⑤ **必须用用户传的图**：图片是唯一人物锚点，**不重绘脸、不美化、不换装、不换发型**。
   只有**用户没传图**时，才按方案里锁定的风格卡生成一张。

⑥ **正面、嘴部全程可见；镜头要动，但动在节奏上**：正面平视或 3-4 侧脸；不遮嘴、不甩头、不转身、不走位。
   - 镜头跟着拍子动（每 2 拍一次极轻推开/回拉，幅度 <2%；重拍处顿一下）；
   - 允许开场快速推近：前 3 秒从全景/全身推到半身，之后**锁在半身**；
   - 禁止：快速甩镜、横向摇移、变焦跳动、推到位后继续乱推。

⑦ **歌词与音频逐字一致**：音频定稿后**一个字都不许改**；每句用**双引号**包裹，带 `[起-止s]` 相对时间轴；
   不引号＝场景描述，模型不会按字对口型。

⑧ **时间轴写整数秒**：`[0-2s]`、`[2-5s]`…末块 `end` **必须等于该镜 `seconds`**。
   小数时间戳会被静默四舍五入。

⑨ **人物锁定**：提示词必须逐项锁住脸型、发型、服装、配饰、背景关系；`refs_urls` 是人物参考图**绝对直链**，
   提示词里用 `@图片1` 指代。

⑩ **说不是念**：提示词必须显式写「说唱 / Rap / 有 beat 有 flow」，并给 BPM、鼓组、flow 类型；
   不要写成「朗读 / 念白 / 朗诵」。

⑪ **必须有律动，且不能只有人物在动**：提示词 ④ 段必须写**五层**——镜头（卡拍）/ 人物律动 / 手部 /
   饰品（本人物符号持续动、发丝动）/ 环境（本场景元素流动、光屑飘）；再挑 3–5 个与歌词对应的秒点做「画面事件」，
   其余保持轻动态。底线：**不甩头、不转身、不走位**；饰品与环境动效**不进入面部区域**。

⑫ **零可读文字**：画面不出现文字、数字、字母、logo、水印、二维码；歌词只作可选后期字幕。

⑬ **合规**：不影射在世真人/明星/IP/品牌；真人图片需本人/授权/AI 生成；未成年人默认健康表达；
   交付提示加 AI 生成标识。

⑭ **成本纪律**：先 `--dry-run` 看请求体，再出 **1 条**；不连出、不批量抽卡。

⑮ **确认门**：① 任务书、② 方案、③ 钩子＋主题，每站都要**把摘要展示给用户**；
   ③ 结束给一张**四合一确认卡**（任务解读＋方案＋钩子＋主题；开头一句「以下方案是否适合现代社会年轻人？给出优化修改建议。」），用户一次确认后才进 ④；
   **未确认前，④ 不得定稿；已写歌词只算草稿，不得进 ⑤**；
   用户没说「确认/可以/生成」之前，不调付费出片。
   也允许**逐站确认**：① 停一次、② 停一次、③ 停一次。

## 三·五、公共经验（10 条硬口径）

> 详细展开见 `references/08-公共经验.md`。与其它文件冲突时，以这 10 条为准。

| # | 口径 | 落地动作 |
|---|---|---|
| 1 | **概念成立 ≠ 表达成立** | 先判目标人群/文案/时长/画面/平台，再把文学母题翻成目标人群口语；不做父辈独白 |
| 2 | **代际题材先定边界** | 不替沉默父亲解释，让他承认「不会说」；不逼年轻人原谅，给「可以不原谅」的出口 |
| 3 | **平台硬约束前置** | 零文字下，聊天记录/朋友圈/字幕/弹幕一律改成声音、震动、反光、手势、剪影、口播 |
| 4 | **字秒比按口型打折** | 40s 优先 **140–150 字**、每句 **6–9 字为主**；主歌一辙，Bridge 换辙；不用纯文案字数判断 |
| 5 | **结构先让目标人群听进去** | **现代失败 → 神话关系 → 边界出口**；不要一上来全是父辈苦衷 |
| 6 | **钩子狠但不踩线** | 用「物 + 关系 + 落空」；血腥/剔骨/还骨头慎用，口播抽象成「还清/还命」，画面不血腥 |
| 7 | **单镜按信息段拆** | 40s 拆 **3–4 镜**，每镜 **8–12s**；主镜微侧、中景、塔低于嘴 |
| 8 | **视觉母题一个锚点反复出现** | 风格词落到可反复拍的具体物件；塔在腰前掌心或胸腹侧，低于嘴 |
| 9 | **风险控制换表达不删情绪** | 保留复杂情绪，把审判性画面换成承认性口播；不拍剔骨、不说教、不烧字幕 |
| 10 | **可复用检查清单** | 十项见 `references/08` §10；一项不过就停在当前站改 |

**概念可行性五问（② 方案前必答）**：

1. 目标人群是谁？他们平时怎么说这句话？
2. 这个母题能不能用一句**他们的口语**说清？
3. 时长/画幅/零文字/平台，允许这个表达吗？
4. 有没有第二个人、具体场景、可拍动作？
5. 会不会变成人物独白/判词？

五问有一问答不上，回 ① 重写任务书，不许直接出方案。

## 五、项目制总则

## 八、② 出方案

**详细规则见 `references/01-任务解读与方案.md` 第二部分**。最小动作：

1. 先答**概念可行性五问**（见三·五）：目标人群、他们的口语、平台约束、有没有第二个人/具体场景、会不会变成独白；
2. 列**事实清单**（身份/关键事件/物证/关系/争议选择/原数字），只写可核对的事实，不写形容词；
3. 压成**一句母题**：`这个人在 <处境> 里，用 <动作>，换了 <代价>`；再用目标人群的口语说一遍；
4. **只选一件事**（普遍处境／今天有人在经历／有 3–5 个物证），并写明「为什么是这件事」的推理链；
5. 配**三个当代场景**（失败现场／关系冲突／社会比较），每个都过「删句测试 + 推得出来吗」；
   **顺序必须是：现代失败先出现 → 神话关系后置 → 最后边界出口**；
6. 定结构（30s/12 句 或 40s/16 句）、人物卡、唯一符号、镜头、风格、音频方案；
   **40s 目标 140–150 字、每句 6–9 字为主**；**视觉锚点只选一个**，位置固定、低于嘴；
7. 方案必须写一句**「不逼原谅」的出口**（不逼叫爸/不逼回家/不逼和解）；
8. **方案里不许出现完整歌词**，只留槽位；
9. **在对话里展示方案摘要**（母题/一件事/三场景/结构/视觉/音频），`log_step.py` 记一条，停下等确认。

**方案自检**：概念五问答得上吗？删掉人物名还成立吗？现代场景在前吗？有「不逼原谅」出口吗？唯一符号挡不挡嘴？

## 九、③ 写钩子句

**详细规则见 `references/02-钩子句.md`**。最小动作：

1. 先从事实清单里找**可核对的原数字**（年龄/年数/数量/次数/期限/命数/背负时长），查不到就换类型，**不许编**；
2. 把数字落到**今天的生活成本**（工作/工资/房租/首付/道歉/催婚/名单…）；
3. 用「换不来／变不出／才第一次／一句都没／输给」造**自嘲式损失**；
4. 结构优先用「**物 + 关系 + 落空**」：一个具体物件、一个关系称呼、一个换不回的落点；
5. 出 **3–5 个候选**，每个按 **4 分制**打分（有数字／有生活落点／有自嘲式损失／≤12 字不解释）；
   **风险线**：血腥/剔骨/还骨头/剖腹慎用；口播抽象成「还清/还命」，画面不血腥；
6. **4 分才用，3 分改，≤2 分重写**；只留 **1 条主钩 + 1 条备选**；
7. **目标人群语感检查**：把这句念给一个不知道人物背景的人听，他能不能立刻懂？不懂就改成他们的口语；
8. 同时压出**主题一句话**（≤30 字、从方案母题压缩、删掉人物名仍听得懂）；
9. 写 `02-方案/02-钩子句.md`（含打分表、主题、定稿理由、确认状态），`log_step.py` 记一条；
10. **输出四合一确认卡**（任务解读＋方案＋钩子＋主题），停下等用户确认；
   未确认不得进 ④，已写歌词只算草稿。用户说「一起确认」时，①②③连做但每站仍落盘，最后只给这一张卡。

**钩子与主题锁定后，词作者不得改写第一句，也不许跑题。**

## 十、④ 写歌词

**详细规则见 `references/03-歌词写作.md`**。最小动作：

1. 锁三样：钩子（逐字照用）、结构（30s/12 或 40s/16）、主辙（只选开口音：江阳/遥条/言前/发花）；
2. 按结构写全词；每句必须挂功能（钩子/反差/失败现场/关系冲突/社会比较/自嘲/发慌/强硬/签名）；
   **结构顺序：现代失败 → 神话关系 → 边界出口**；前 2–4 句必须先让目标人群听见自己；
3. **字秒比按口型驱动打折**：40s 目标 **140–150 字**、每句 **6–9 字为主**；30s 目标 **100–115 字**；
   主歌统一辙口，**Bridge 可换一个开口辙**制造转折，签名句收回主辙；
4. 规则：写物写动作不写情绪；意象 ≤3；现代场景连续 ≤2 句；
   现代句＝原话＋可拍场景＋具体数字；自嘲 1–2 处；反差 1–2 处；
5. **零文字约束在写词阶段排除**：凡是依赖聊天记录/朋友圈/字幕/弹幕的信息，改成声音、震动、反光、手势、剪影、口播；
6. 必须写**「不逼原谅」的出口**：不逼叫爸、不逼回家、不逼和解；可用「我不逼你……你也别逼自己……」；
7. 签名句**本项目生成**（回扣主钩的物件/动作），不用固定句式；结尾给动作或回答，不给道理；
8. 过「七问 + 六刀」（时间线、三本账、时空跳档、结尾唱完、古物落现代动作、代词给身份）；
   再加「公共经验十问」（见 `references/08` §10）；
9. 输出全词 ＋ 逐句功能表 ＋ 自检 ＋ **出曲参数**（BPM、曲风、人声、字数、咬字要求、逐字歌词）；
   **无音频时必出** `02-方案/05-海绵音乐提示词.md`（主版＋备选＋逐字歌词，写法见 `references/09-海绵音乐提示词.md`）；
10. `log_step.py` 记一条。

**有音频时**：④ 不写词，改为「听写核对」——以音频为准，逐字记录，标出与词稿差异；
然后直接进 ⑤ 切音频。

**无音频时**：④ 交付到「歌词＋出曲参数＋海绵音乐提示词」就停；用户出曲回传后才进 ⑤，
未回传不得进 ⑥⑦⑧。**不许拿旧项目的音频顶上。**

## 十三、⑦ 时间轴 ＋ 提示词 ＋ 分镜 JSON

### 13.1 时间轴（`02-方案/04-时间轴.md`）

- 全部**片段内相对秒**，从 `0` 起；**整数秒**；首尾相接、不重叠、不跳段；
- 末块 `end` = 该镜 `seconds`；
- 时间点跟音频真实断句：ASR 的句首 `w.start` 吸附到整数秒；
- 起势块可无词（`text: ""`），但保留；
- 密字段拆 1–4 秒小块，**一块最多 4 字**；
- **拆镜按信息段，不按秒数硬切**：40s 拆 **3–4 镜**，每镜 **8–12s**；30s 可单镜或 2 镜；
- 切点落在信息段之间（Hook / 现代失败 / 神话关系 / 边界出口）；
- 主镜**微侧、中景**，视觉锚点低于嘴；每镜用同一张参考图、同一套风格句。

详细规则见 `references/04-时间轴与字幕.md`。

### 13.2 六段式提示词（固定标题，QA 会查）

```
① 一句话摘要

一镜到底 <该镜 seconds> 秒；<情绪>；<曲风/BPM>。

② 人物与参考图锁定
以 @图片1（<完整直链>）为唯一人物与造型锚点：同一张脸、同一发型、同一服装、同一配饰、
同一背景关系；<逐项可观察特征>；人物始终位于画面中央偏上，面部受光均匀，
嘴部完整可见、自然开合，全程不遮挡嘴部；不重绘脸、不美化、不换装。

③ 时间轴说唱（相对秒，整数，末块收到该镜 seconds）
[0-2s] 人物看向镜头，吸气、点头找拍，准备开口（不唱）；
[2-5s] 开口说唱："<第一句>"，精准唇形同步音频，每个字都有开合、不吞字；
[5-8s] 继续说唱："<第二句>"，精准唇形同步；
…
[28-30s] 最后一句收尾："<末句>"，尾音落下，看镜头收住。

之后每 2 拍一次极轻推开与回拉（幅度 <2%），重拍处顿一下；不甩镜、不横摇、不变焦跳动。
人物律动：每拍肩线轻微下沉；每 4 拍一个动作单元（点头→耸肩→抬手比划→收手回胸前）。
手部：胸前到小腹之间做说唱手势，不高于下巴、不经过面部、不遮嘴。
面部：重音句挑眉、眼神钉住镜头，句尾吐气收住；不面瘫。
饰品：<本人物符号>持续动、有褶皱/摆荡/反光；发丝摆动。
环境：<本场景环境>缓慢流动、轻摇、飘落、侧光缓慢明暗推移。
画面事件（只挑 3–5 个与歌词对应的秒点，其余轻动态）：
  · <秒点>：<与歌词对应的动作>
边界：不甩头、不转身、不走位、不换景、不换装、不切镜；饰品与环境动效不进入面部区域。

⑤ 声音设计
本镜不生成人声与配乐；口型、咬字、flow 只严格匹配参考音频 @音频1 的人声；
画面节奏跟随该音频的 BPM 与鼓点；成片音轨使用该参考音频本身。

⑥ 画风与强制约束
<风格锁定句>；画面零可读文字、无字幕、无 logo、无水印、无二维码；不出现第二个人；
不出现乐器遮挡面部；不出现畸形手指/五官扭曲/换脸感；不出现画面闪烁/跳帧。
负面：糊嘴、双嘴、吞字、连读含糊、口型滞后、闭嘴不动、唱成旋律腔、念白朗读、
      手挡嘴、侧脸背对、大幅转头、换脸、五官变形、镜头晃动
音频：不额外生成人声与背景音乐；口型与咬字只匹配参考音频 @音频1
```

> ④ 段里的「饰品」「环境」必须换成本项目方案的**具体符号与场景**，不许留占位符。

### 13.3 分镜 JSON（`04-提示词/分镜JSON.json`）

```json
{
  "project": "MV01-<短名>",
  "ratio": "9:16",
  "generate_audio": false,
  "shots": [
    {
      "id": "S01",
      "prompt": "<六段式全文 · 第 1–6 句>",
      "refs_urls": ["04-图片/ref_人物.png"],
      "ref_audio_urls": ["00-输入/音频/S01.wav"],
      "seconds": 16.70,
      "duration": 17,
      "mode": "reference",
      "resolution": "720p",
      "lyrics": [
        {"start": 0, "end": 3, "text": "<第一句>"},
        {"start": 3, "end": 6, "text": "<第二句>"}
      ]
    }
  ]
}
```

| 字段 | 规则 |
|---|---|
| `shots` | **1–4 条**；30s 可 1–2 镜；40s 按信息段拆 3–4 镜，每镜 8–12s |
| `seconds` | 该镜成片长度（≤30，可小数） |
| `duration` | **整数** = `ceil(seconds)` |
| `ref_audio_urls` | 每镜**恰 1 条**，上传后回填直链 |
| `refs_urls` | 每镜都写；多镜时**用同一张图** |
| `lyrics` | 挂在 shot 上，**相对该镜起点**；`assemble.py` 自动累加偏移 |
| `generate_audio` | 顶层 **false** |

## 十四、⑧ 出片 ＋ 合成

```bash
P=assets/output/MV01-xxx

# 1) 干跑：只看请求体（每镜都应有 audio_url）
python3 scripts/generate_video.py "$P/04-提示词/分镜JSON.json" --dry-run

# 2) 逐镜出片（自动裁到每镜 seconds）→ 成片片段/S01.mp4、S02.mp4
python3 scripts/generate_video.py "$P/04-提示词/分镜JSON.json"

# 3) 多镜时合并成无音轨成片（单镜可跳过）
python3 scripts/generate_video.py "$P/04-提示词/分镜JSON.json" --merge

# 4) 贴回音轨 + 精确裁秒 + 字幕 → 06-MV成片.mp4
python3 scripts/assemble.py "$P"
python3 scripts/assemble.py "$P" --subtitle
python3 scripts/assemble.py "$P" --subtitle --burn
```

- 出片落点：`成片片段/SXX.mp4`；合并：`06-MV成片_无音轨.mp4`；合成落点：`06-MV成片.mp4`；
- 出片后**先看一遍**：开口时机、口型、有没有多余人/文字；
- 不满意只重出 **S01**，不批量抽卡。

> **1 镜实测门**：30 秒密字说唱是这套模型最难的一档，若糊嘴/对不上，
> **按顺序最多调 2 次**：① 时间轴切更碎（1–3 秒一块）；② 提示词加强「逐字开合、不吞字、不连读」。
> 仍不行 → 停止批量，如实告诉用户，给三条路：① 换更清晰正面图；② 换慢一点的成曲（BPM 85–90）；
> ③ 改走 `mv-concert`（另行提供）。**不要假装已对上口型。**

### 常见故障 → 处理

| 现象 | 处理 |
|---|---|
| 完全不动嘴 | 查 `ref_audio_urls` 是否 1 条、`generate_audio` 是否 false、`audio_url` 块是否存在 |
| 嘴动但整体早/晚 | 时间轴起点没对齐音频首句；把第一块起点挪到真实首声 |
| 节奏对、字不对 | 歌词没引号 / 一块塞太多字；补引号、拆 1–3 秒小段 |
| 后半段越来越飘 | 末块没收到该镜 `seconds`；原速重切、末块对齐 |
| 糊嘴/双嘴 | 重出同一条；负面加「糊嘴、双嘴、连读」 |
| 人物不像 / 换脸感 | ② 逐项锁死；**确认用的是用户传的图**；降低推近幅度 |
| 唱成旋律腔 | ⑥ 写「说唱，不是唱旋律、不是念白」；负面加「旋律唱腔」 |
| 画面出现文字/logo | ⑥ 加「零可读文字、无 logo」；重出 |
| 上传 404 | 命名空间＝项目文件夹名；图与音频都重跑 `--verify --fill-json` |
