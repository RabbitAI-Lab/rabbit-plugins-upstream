# 对口型经验总结 · 唱歌与说台词（Seedance 2.5 实战）

> 来源：该 MV 品牌 MV（29 镜 / 成片 213.00s）一次完整踩坑与修复复盘。
> 适用范围：**用参考音频驱动嘴型**的生成方式（唱歌、说台词、旁白出镜）。
> 标注约定：`[实测]` = 本项目真机验证；`[推断]` = 由已知行为外推，未单独出片验证。

---

## 0. 一句话结论

**口型不是「提示词写得好不好」的问题，而是三个输入必须同时成立：**

| 输入 | 决定什么 | 缺了会怎样 |
|---|---|---|
| **参考音频** | 什么时候开口、开合多大 | 全程闭嘴不动，或随机开合 |
| **带时间戳的引号台词** | 这个秒数唱/说哪个字 | 节奏对、字不对（跟着节奏瞎动） |
| **嘴部可见的构图** | 嘴长什么样、能不能判读 | 模型干脆不画嘴，或画了也看不出来 |

三样缺一样，改多少措辞都救不回来。**先查输入，再改提示词。**

## 1. 七个必查项（按排查顺序）

按这个顺序查，80% 的问题在前三项就能定位。每项都附本项目实测数据。

### 1.1 音频到底传没传？

坑：提示词里写了 `严格对齐 @音频1`，但请求体 `content[]` 里只有 `text` + `image_url`，**根本没有 `audio_url`**。
引用悬空，模型收不到声音。

```json
// ❌ 看着对，其实没传
"content": [
  {"type": "text", "text": "...严格对齐 @音频1..."},
  {"type": "image_url", "role": "reference_image", ...}
]

// ✅ 必须有这一块
"content": [
  {"type": "text", "text": "..."},
  {"type": "image_url", "role": "reference_image", ...},
  {"type": "audio_url", "role": "reference_audio", "audio_url": {"url": "..."}}
]
```

`[实测]` 该 MV 第一轮：29 个裸请求体**全部没有 audio_url**，只有分镜 JSON 里绑了 25 条。出片自然没口型。

### 1.2 音频长度 == 视频时长？

`[实测]` 旧的「整句切片」比镜长多 **0.40–0.80s**（S01 +0.40，其余 24 条 +0.80）。
模型拿到 10.64s 人声、只出 10.24s 画面 → 后段被压缩 → **口型必然错位**。

判定：

```bash
ffprobe -v error -show_entries format=duration -of csv=p=0 音频.wav
# 必须 ≈ 该镜 seconds（±0.02s）
```

### 1.3 首声从第几秒开始？

最大的隐形杀手。`[实测]` S01 的音频前 **1.19s 是前奏静音**，人声才起；
但提示词写的是 `[0.0-3.3s] 开口唱第一句` → **先天早 1.2 秒**。观众一眼就觉得不对。

```bash
ffmpeg -hide_banner -nostats -i 片段.wav \
  -af "silencedetect=noise=-35dB:d=0.12" -f null - 2>&1 | grep silence
```

把开头的 `silence_end` 当作**第一块台词的起点**，别从 0.0 起。

### 1.4 时间单位是不是整数？（`duration` 是硬约束，时间戳是软约束）

**① `duration` 参数：硬约束，必须整数（4–30）。**
`[实测]` 我们在 该 MV 全片按此执行：`duration = ceil(seconds)`，10.24 → **11**。
仓库口径见 多镜整首流程的《出片与 API 参数》（另行提供）：
> `duration` | **整数秒，4–30** | ＝切片文件长度＝视频秒数

但歌曲时间轴是小数（10.24s），怎么办 → 见第 3 节「时长体系」。

**② 提示词里的时间戳：建议整数，但不是硬报错。**
仓库记录（`Seedance问题清单与交流议题.md`）：
> 官方**不支持用时间戳控制频率**（如「一秒摇头 3 次」），时间轴必须连续（`0-3…5-6` 这种跳空不允许）。**整数秒时间戳才响应**（2.0 只响应镜头序号）。

`[实测]` 反向证据：该 MV 的 S01B 用的是小数时间戳（`[0.0-1.20s]` / `[1.20-11.00s]`），**口型一次就对上了**。
所以小数**不会报错**，最坏情况是「被忽略或四舍五入」——风险不是失败，而是**时间点悄悄偏一点**。

**结论：**
- `duration`：整数，无商量空间
- 时间戳：**优先写整数**（贴官方口径）；只有「首声落在 x.2~x.8 这种小数位、且时间点精度更重要」时，才用小数，并且必须 1 镜实测确认没被吃掉

```text
# 推荐（整数）
[0-1s]   嘴唇轻启、尚未出声，随前奏把脸缓缓转向镜头
[1-11s]  对镜头演唱："……"，精准唇形同步音频

# 已验证可用（小数，S01B 实测通过）
[0.0-1.20s]  嘴唇轻启、尚未出声，随前奏把脸缓缓转向镜头
[1.20-11.00s] 对镜头演唱："……"，精准唇形同步音频
```

### 1.5 时间轴里有没有**引号**？

引号是唯一告诉模型「这一段唱/说哪些字」的输入。没有引号，模型只当画面描述。

`[实测]` 该 MV 第一轮：**29 镜，0 条引号台词**。所以即使传了音频，也只能跟着节奏瞎动。

### 1.6 每块台词是不是 2–4 字？

- 慢歌（≤3 字/秒）：可整句一块
- 中速（3–4.5 字/秒）：2–4 字一块
- 快歌/说唱（>4.5 字/秒）：1–2 字一块，且必须 1 镜实测

### 1.7 构图能不能判读嘴型？

见第 5 节决策表。**这一项决定「做不做得了」，不是「做得好不好」。**

## 2. 音频怎么切（最关键的一步）

### 2.1 三种切法，只有一种对

| 切法 | 长度 | 结果 |
|---|---|---|
| ❌ 整句切片（VAD 起止 + 前后 pad） | 比句长 0.4–0.8s | 音频比视频长 → 后段错位 |
| ❌ 硬裁到镜长 | 强行等于 seconds | 会截掉尾音/开头吸气 |
| ✅ **按母带时间窗切片** | 天然 == seconds | 与成片音轨**同源同轴**，只剩模型固有偏移 |

### 2.2 做法（母带 + 逐镜时间窗）

母带是 `0 → 总时长` 的整轨音频，逐镜时间窗首尾相接（Σ seconds == 母带长度）。

```python
t = 0.0
for shot in shots:                      # shot["seconds"] 是精确小数
    ffmpeg -ss {t:.3f} -t {seg:.3f} -i 母带.wav -acodec pcm_s16le 逐镜音频/{id}.wav
    t += seg
```

校验：每个 wav 的 `ffprobe` 时长必须 == `seconds`（±0.02s）。

`[实测]` 重切后 29/29 全部误差 0，Σ 音频 == 母带 213.00s。

### 2.3 为什么必须「母带窗口」而不是「句子窗口」

成片音轨是母带。只要逐镜音频与母带**同一时间窗**，剪辑点天然对齐；
换句切片就多了一层「句子边界 ≠ 剪辑点」的误差，越短越明显。

### 2.4 传音频的两种姿势（选一个）

| 姿势 | 写法 | 适用 |
|---|---|---|
| 公网直链 | `"url": "https://…/S01.wav"` | 平台网页端手动粘贴；**推荐** |
| 本地路径 | `"url": "01-对轴/逐镜音频/S01.wav"` | 只有脚本出片时可用（会内联 base64，请求体 ~1.4MB） |

> ⚠️ 本地路径在平台端无效。要么先上传换直链，要么只用脚本。

## 3. 时长体系（整数秒 × 精确成片）

### 3.1 双字段

| 字段 | 值 | 用途 |
|---|---|---|
| `seconds` | 10.24（精确小数，保留 2 位） | **成片长度**，出片后裁到它 |
| `duration` | **11**（`ceil(seconds)`，整数） | 传给模型的生成时长 |

**只能向上取整**：

```python
duration = math.ceil(seconds)      # 10.24 → 11  ✅ 尾巴多出来可以裁
duration = round(seconds)          # 10.24 → 10  ❌ 比音频短，尾巴直接被吃掉
```

### 3.2 出片后必须裁

```bash
ffmpeg -i S01.mp4 -t 10.24 -c:v libx264 -crf 18 -c:a aac S01.trim.mp4
```

- 长于目标 → `-t target`
- 短于目标（模型生成不足）→ `tpad=stop_mode=clone` 冻结末帧补齐，正好当落幅定格

### 3.3 时间戳也尽量写整数

`duration` 是整数，**时间轴里的 `[起-止s]` 也建议写成整数**，别一边整数一边小数（`11s` 配 `[0.0-6.14s]` 这种混写最容易被模型按自己的理解抹平）。

```text
# ✅ 推荐：全整数
② 时间轴（本镜 11s，成片裁到 10.24s）
[0-1s]  嘴唇轻启、尚未出声，随前奏把脸缓缓转向镜头
[1-11s] 对镜头演唱："……"，精准唇形同步音频；10s 后人声结束，嘴唇闭合，画面静止
```

小数时间戳 `[0.0-1.20s]` 在本项目实测可用（S01B 通过），但属于「能用，不推荐」：

- 官方口径是整数秒才响应（见 1.4），小数最坏会被**静默四舍五入**，不报错但偏移
- 混写会让「模型看到的时长」和「你写的时长」不一致，排查时很难归因

### 3.4 提示词里的时长标注要跟 `duration` 一致

否则模型会在多出来的零点几秒里自由发挥。定稿写法：

```text
① 一镜 11s 的二维动画画面：…（成片裁到 10.24s）
② 时间轴（本镜 11s，成片裁到 10.24s）
[0-1s]  侧影，嘴唇轻启、尚未出声，随前奏把脸缓缓转向镜头
[1-11s] 3/4 侧脸对镜头演唱："……"，精准唇形同步音频
        ；10.24s 后人声结束，嘴唇放松闭合，画面保持静止
```

**最后那句尾注是刚需**：把「多余时长」明确写成静止，模型才不会自作主张加戏。

## 4. 提示词模板（实测通过版）

```text
# S01 · 11s（成片 10.24s） · 人物 1 人 · 真口型

① 一句话摘要
一镜 11s 的二维动画画面：落地窗前，一位女性由侧影缓缓转至 3/4 侧脸正对镜头演唱，
嘴部全程清晰、不被遮挡；机位完全固定。（成片裁到 10.24s）

② 时间轴（本镜 11s，成片裁到 10.24s）
[0.0-1.20s] 她保持参考图中的侧影，嘴唇轻启、尚未出声，随前奏把脸缓缓转向镜头
[1.20-11.00s] 已转到 3/4 侧脸正对镜头，对镜头演唱："为信任奉献回报 示例同心奔跑"，
精准唇形同步音频，每个字都有开合、不吞字；机位完全固定，不推、不摇、不变焦；
10.24s 后人声结束，嘴唇放松闭合，画面保持静止

③ [主体与素材绑定]
@图片1 = 角色参考图
主体锁定句：人物形象严格以 @图片1 为准：脸型、五官、发型、服装与参考图完全一致，
全程不换脸、不变形；画面内人物共 1 人，不增减。
[口型] 前 1.2s 为侧影，之后转至 3/4 侧脸，嘴部全程清晰可见；严格跟随 @音频1 的人声，
唇形开合与咬字逐字对齐，不提前不滞后，每个字都有开合、不吞字。

④ [全局约束]
风格：…（风格锁定句）
禁止：画面出现任何文字/数字/字母/logo/水印/二维码；不切镜；镜头全程固定；
不出现真实人物面孔、真实品牌标识；不做收益承诺。
负面：90 度正侧脸、背对镜头、嘴部被遮挡或出框、手挡嘴、大幅转头、甩头、
嘴部扭曲、双嘴、糊嘴、吞字、口型滞后、假唱、闭嘴不动、换脸、五官变形、
画面闪烁、镜头晃动、生成额外人声、生成背景音乐
音频：本镜不额外生成人声与背景音乐；口型与咬字只匹配参考音频 @音频1 的人声；
成片音轨后期贴原曲母带与环境音
```

> ⚠️ 上面这版的时间戳是**小数**（`[0.0-1.20s]`），是 S01B 实测通过的原始版本，原样保真。
> 按官方口径应写整数（`[0-1s]` / `[1-11s]`），追精确首声时可用 `[1.2-11s]` 这种一位小数折中。
> 取舍见 1.4 与 3.3。

### 四段式各自的作用（别乱删）

| 段 | 作用 | 删了会怎样 |
|---|---|---|
| ① 摘要 | 定镜头性质、人数、成片长度 | 模型不知道这是「演唱镜」，容易拍成静态站桩 |
| ② 时间轴 | **口型的唯一文字驱动** | 节奏对、字不对 |
| ③ 主体绑定 | 形象一致 + `[口型]` 硬约束 | 换脸、人物漂移、口型无优先级 |
| ④ 全局约束 | 风格锁 + 禁止 + 负面 + 音频说明 | 画面乱入文字/logo，嘴部崩坏无人兜底 |

## 5. 构图可做性决策表

**先判「能不能做」，再谈「怎么写」。** 这一格决定 90% 的工作量。

| 构图 | 可做口型 | 说明 |
|---|---|---|
| **3/4 侧脸、中近景、嘴部无遮挡** | ✅ 最佳 | `[实测]` 该 MV S01B 一次通过 |
| 正面平视、胸像 | ✅ 可行 | 最经典，但要注意别做成大特写（易崩五官） |
| 90° 正侧脸 | ⚠️ 勉强（推断） | 嘴只是一道剪影线，观众也判不出来；本项目首镜即侧脸，但当时还叠加了「没传音频 + 没台词」，无法单独归因 |
| 背影 | ❌ | 没有嘴 |
| 手部 / 道具特写 | ❌ | 没有嘴 |
| 群像（≥2 人） | ❌（推断） | 模型为满足口型会重画脸，多人同时对口型几乎不可能；本项目群像镜未做真口型实测 |

`[实测]` 一个 29 镜的 MV 里，真正能做真口型的只有 **2 镜**（两个单人侧影镜）：
空镜 10、手部 4、群像/背影 11、单人侧影 2。**别默认「每镜都能对口型」。**

### 侧影 → 3/4 的转正技巧

参考图是 90° 侧脸时，不必重出图，可以直接在时间轴里让它转头：

```text
[0.0-1.2s]  保持参考图中的侧影，嘴唇轻启、尚未出声，随前奏把脸缓缓转向镜头
[1.2-11.0s] 已转到 3/4 侧脸正对镜头，对镜头演唱："…"
```

`[实测]` 这样能保住脸的一致性（同一张参考图），同时把嘴转到可判读角度。
前提：**头转动要有明确时间段**，不要写「微微转头」这种无时间约束的软话。

## 6. 唱歌 vs 说台词：差异只有三处

| 维度 | 唱歌 | 说台词 / 旁白出镜 |
|---|---|---|
| 音频来源 | 母带切时间窗，需与剪辑点同轴 | 配音单片，一镜一句 |
| 台词密度 | 1–4 字/秒，可直接整句 | 3–6 字/秒，必须拆 2–4 字块 |
| 情绪 | 跟随旋律线，开口幅度大 | 跟随语气，开口幅度小、表情更重要 |
| 时长对齐 | 必须与母带时间窗一致 | 只要求音频 == duration，无母带约束 |
| 失败特征 | 后半段整体漂移（长度不匹配） | 吞字、糊嘴（块太大） |

歌词/台词**一律用原文中文直接写**，不要机翻英文；不要写「约几秒」，时间戳只写数字。

## 7. 九个典型失败现象 → 根因 → 解法

| 现象 | 根因 | 解法 |
|---|---|---|
| 全程闭嘴不动 | 没传音频 / 音频人声太弱 / 参考图闭嘴 | 补 `audio_url`；提人声响度；换嘴微张的参考图 |
| 节奏对、字不对 | 缺引号台词或时间戳 | 补 `[起-止s] "台词"`；块拆细 |
| 后半段整体错位 | 音频比视频长（整句切片）/ 切片过长 | 按母带窗口重切；单镜 ≤14s |
| **开口早/晚一个固定量** | 时间轴起点没用真实首声位置 | `silencedetect` 量首声，把第一块起点挪过去 |
| 该唱时张嘴、休止也张 | 时间轴有空洞，模型自由发挥 | 插不带引号的 rest 块：「嘴唇闭合等待下一句」 |
| 嘴型像说话不像唱歌 | 缺台词文本 / 参考音频是说话 | 补引号台词；确认音频是唱段 |
| 嘴在动但画面很美却不对 | 画面描述/运镜挤占了同步权重 | 删特效、舞蹈、运镜；口型镜只留主体+时间轴+约束 |
| 偶发糊嘴/双嘴 | 抽卡 | 同段重出；负面加「嘴部扭曲、双嘴」 |
| 人脸疯狂变形 | 参考图质量差 / 动作描述太多 / 运镜复杂 | 换正面清晰图；删肢体与运镜描述 |

## 8. 验收标准（抽 3 帧看）

- [ ] 张嘴幅度与音轨强弱对得上（高音/长音开口更大）
- [ ] 每个字有开合，不吞字
- [ ] 休止处闭嘴或自然闭合
- [ ] 无换脸、无双嘴、无糊嘴
- [ ] 时长不变、画幅不变
- [ ] 抽开头 / 中间 / 结尾 3 帧，嘴部都正常

**不合格就重出或降级，不要硬说「已同步」。**

## 9. 做不到时的诚实降级

口型这行没有「差不多」。做不到就明说：

1. 把该段改成**中景 / 侧身 / 稍背向**，让观众看不清嘴部细节；
2. 缩短正脸时长，插入非正脸镜；
3. 交付说明标 `lip_sync: false`，靠字幕 + 母带撑。

`[实测]` 反面教材：某项目全片 `generate_audio=false` 且音频没传对，用户实测直接判「主唱根本没唱、嘴型完全对不上」。
**口型这件事，不假装。**

## 10. 一页速查清单

出片前逐条打勾：

- [ ] `content[]` 里有 `{"type":"audio_url","role":"reference_audio"}`
- [ ] 音频 URL 是公网直链（平台端）或本地可解析路径（脚本端）
- [ ] `ffprobe` 音频时长 == `seconds`（±0.02s）
- [ ] `silencedetect` 量过首声，时间轴第一块起点 == 首声位置
- [ ] `duration` 是**整数**（4–30），且 == `ceil(seconds)`
- [ ] 时间戳尽量写成**整数**（`[0-6s]`）；用小数（`[0.0-6.14s]`）必须实测确认没被四舍五入
- [ ] 提示词里 `[起-止s] "引号台词"` 首尾相接、末块 == `duration`
- [ ] 末块写了「X.XXs 后不再有新动作 / 人声结束、嘴唇闭合」
- [ ] 构图是 3/4 侧脸或正面，嘴部无遮挡；**不是**背影/手部/群像
- [ ] 镜头固定，不推不摇不变焦
- [ ] 负面清单含：糊嘴、双嘴、吞字、口型滞后、闭嘴不动、手挡嘴、侧脸背对
- [ ] 先出 **1 镜**实测，通过后才批量
- [ ] 出片后裁到精确 `seconds`

## 附：本项目踩坑时间线（供复盘参考）

| 阶段 | 判断 | 实际 |
|---|---|---|
| 第一版 | 「提示词写得好就行」 | 29 镜 0 条引号台词、裸请求体 0 条音频 → 全片无口型 |
| 第二版 | 「补上音频和时长」 | 旧切片比镜长 0.8s，S01 首声 1.19s 却是从 0.0 唱 → 固定早 1.2s |
| 第三版 | 「按母带窗口重切 + 量首声」 | 结构对了，但全片 16 个人物镜都是侧影/背影 → 结构上不可口型 |
