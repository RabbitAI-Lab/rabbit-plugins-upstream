# 03 · 歌词写作（只写词，不改曲）

> **输入**：`01-解读/01-任务书.md` ＋ `02-方案/01-方案.md` ＋ `02-方案/02-钩子句.md`
> **输出**：`02-方案/03-歌词.md`（全词 ＋ 逐句功能表 ＋ 自检 ＋ 出曲参数）；无音频时**再加** `02-方案/05-海绵音乐提示词.md`
> **不内置任何人物、母题、场景、金句。** 每一句都必须从本项目的方案与钩子推出来；
> 写不出来就回 ② 改方案，**不要在歌词里硬凑**。

---

## 一、角色边界

| 做 | 不做 |
|---|---|
| 按定稿钩子写全词 | 不改第一句（钩子已锁定） |
| 按方案的结构与句数写 | 不临时换母题、换人物 |
| 每句挂功能（钩子/失败/关系/比较/发慌/签名） | 不写"过渡句""凑韵句" |
| 自检押韵、字数、语速、意象数 | 不靠加注释解释歌词 |
| 给出曲参数、海绵音乐提示词 | 不生成音频、不改曲 |

**一句话**：词作者只回答「**这 12/16 句里，每一句为什么必须存在**」。

---

## 二、写词前先锁三样

1. **钩子**：`02-方案/02-钩子句.md` 的主钩，逐字照用；
2. **结构**：任务书定的 30s/12 句或 40s/16 句；
3. **主辙**：只从**开口音**里选一个（见 §三），签名句必须收回主辙。

三样不定，不动笔。

---

## 三、押韵：只选开口音

| 辙 | 主元音 | 响度 | 适用 |
|---|---|---|---|
| **江阳 -ang** | /a/ + ng | ★★★★★ | 最响，收尾有力 |
| **遥条 -ao** | /a/ + o | ★★★★☆ | 干脆、带狠劲 |
| **言前 -an** | /a/ + n | ★★★★ | 叙事稳，适合中年 |
| **发花 -a** | /a/ | ★★★★ | 口语、直白、适合父子/家庭 |
| 由求 -ou | /o/ + u | ★★★ | 适合"嘴皮子"型人物 |
| 灰堆 -ei | /e/ + i | ★★★ | 适合阴柔、冷艳 |
| **一七 -i** | /i/ | ★☆ | **闭口细音，不要用** |
| 姑苏 -u | /u/ | ★★ | 闷，慎用 |

硬规则：

1. **主押一辙，但不句句同韵**：每 4–8 句一个押韵组，Hook 单独押稳；
2. 中段可换**一个**开口辙，**签名句必须收回主辙**；
3. **除签名回扣外，韵脚词互不相同**（也不许同音）；
4. 韵脚尽量落**实词**（人、家、话、名、账），别落"了/的/看/很"这种虚词；
5. 句长 **6–9 字为主**（重音句可到 10 字；口型驱动优先）；短句做 punchline，长句做叙事；10 字以上拆句或减字。

## 四、结构（按档位）

### 4.1 30 秒 / 12 句（默认）

| 段 | 句数 | 功能 |
|---|---|---|
| 钩子 | 1 | 原数字 + 生活落点 + 自嘲式损失 |
| 反差 | 1 | 身份/预期/代价/指控，前后两截语义相反 |
| **现代失败** | 2 | 先让目标人群听见自己：地点 + 物件 + 动作 |
| **神话关系** | 3 | 还清/还命/结账，物证落地，不血腥 |
| 社会比较 | 1 | 一个可比对象 + 一个具体数字 |
| Bridge / 发慌 | 1 | 承认慌，下一句必须接动作 |
| **边界出口** | 3 | 不逼叫爸/不逼回家/不逼和解；给动作，不给道理 |

### 4.2 40 秒 / 16 句

| 段 | 句数 | 功能 |
|---|---|---|
| 钩子 | 2 | 主钩 + 反差钩 |
| **现代失败** | 3 | 开场先出现：饭桌/电话/转账/分组/加班 |
| **神话关系** | 3 | 还清/还命/烧庙/托塔，抽象表达，不拍血腥 |
| 关系冲突 | 2 | 第一次出现的人必须带身份名词 |
| 社会比较 | 2 | 一个可比对象 + 一个具体数字 |
| Bridge / 发慌 | 2 | 一句"慌"，下一句动作；可换辙 |
| **边界出口** | 2 | 不逼原谅；回扣主钩，末字拖住 |

> 30 秒是默认档；40 秒更从容，但必须在任务书里确认。
> 96 BPM × 16 bar = 40.0 秒，一句一 bar；**每句 6–9 字为主**。
> 总字数：**30s 100–115 字 / 40s 140–150 字**（口型驱动打折后的目标）。
> **顺序硬规则**：现代失败先出现 → 神话关系后置 → 最后边界出口。
> 前 2–4 句必须是现代场景；一上来全是父辈苦衷 = 不合格。

## 五、每句必须挂功能（硬规则）

写完后做一张表，**没有功能的句子直接删**：

| # | 歌词 | 字数 | 韵脚 | 段 | 功能 | 服务的钩子/母题 |
|---|---|---|---|---|---|---|
| 1 | <主钩> | <…> | <…> | 钩子 | 记忆点 | <…> |
| 2 | <…> | <…> | <…> | 反差 | 反转 | <…> |
| … | | | | | | |

**功能只有这 9 种**：
钩子 / 反差 / 失败现场 / 关系冲突 / 社会比较 / 自嘲 / 发慌 / 强硬 / 签名。

> 一句挂不上任何功能 → 它是废话，删。
> 两句挂同一个功能且没有递进 → 留一句。

## 六、六条内容规则

### 6.1 写物、写动作、写别人的话，不写自己的情绪

| 不写 | 写 |
|---|---|
| 我很惨 | <物件> 摆到发黄 |
| 我被抛弃 | <身份> 把行李拍在桌上 |
| 我很能打 | <具体战果> 放倒一片 |
| 我不服 | 我没回话 <本人物动作，如把某物放得更长> |

### 6.2 意象 ≤3

一个人物最多保留 **3 个意象/物证**，其余古代履历不展开。
连续两句以上纯古物 = 时空跳档，压成一句或换现代动作。

### 6.3 现代场景必须是「原话 + 能拍照的场景 + 具体数字」

| 三件套 | 说明 |
|---|---|
| **一句原话** | 别人真的说过、能一字不差复述的那句 |
| **一个能拍照的场景** | 有地点、有物件、有动作 |
| **一个具体数字** | 年龄、钱、趟数、次数、时间 |

**自检（可数）**：这句里必须同时有
① 一个具体名词（钱/房/岁数/名单/账单/体检单）；
② 一个数字或量词（三十/两百/一趟/三年/第三次）。
两样都没有 = 空话，重写。

**禁令**：

| 禁 | 反例 | 原因 |
|---|---|---|
| 谐音梗 | 三头六臂 = 扛六个岗 | 笑一下就没了，不是生活 |
| 观点句 | 我反的是你们的框 | 是态度不是处境，没有可拍的东西 |
| 热词堆砌 | 内卷、躺平、PUA、emo、破防 | 词是别人的，不是你的 |
| 吐槽腔 | 过年那句有对象没 又问一趟 | 火气有了，但字多、像段子 |
| 解释性字 | 那句、说白了、其实是 | 解释 = 替听众理解，删掉 |
| 硬挂现代身份 | 给不需要买房的人物硬写首付 | 推不出来，人物会消失 |

> 只用**压力词**：首付、房贷、按揭、催婚、饭桌、户口、彩礼、账单、加班费、裁员名单。
> 不用**热词**：打工人、内卷、躺平、emo、YYDS。

**平台约束（零可读文字）**：不要写「群里刷屏 / 聊天记录 / 朋友圈截图 / 弹幕」来交代信息；
改成**手机震动、屏幕反光、手指悬停、人物表情、画外音、剪影**。
约束在写词阶段就要排除，不要留到分镜再想办法。

**代际边界**：涉及父子/原生家庭，必须留「不逼原谅」出口；
不替沉默父亲解释，让他承认「不会说」；不逼年轻人原谅。

**风险表达**：剔骨/还骨头/剖腹**不直写**；用「还清 / 还命 / 结账」抽象；
画面不血腥化，钩子可以狠，但不能踩平台红线。

### 6.4 每首 1–2 处自嘲

| 类型 | 做法 | 要点 |
|---|---|---|
| 把损失说成恩惠 | 用算账的口气讲伤心事，口气要硬 | <某人走了> → <走就走吧 省下半份口粮> |
| 把自己降一格 | 不用「我」，用「我这号人／我这种人／我顶多」 | 我这号人 <数字> 才 <落点> |

三条约束：

1. 1–2 处就够，多了会油；
2. 必须挂在**具体物**上（半份口粮、一张名单、一座塔），不能是"我太没用了"；
3. 不解释——直接算账。

### 6.5 每首 1–2 处反差

四种可用反差：

| 类型 | 结构 |
|---|---|
| 身份反差 | 前半生 / 后半生的身份对撞 |
| 预期反转 | 大家以为的 / 实际上的 |
| 代价反差 | 得到什么 / 付出什么 |
| 指控反转 | 别人给你定的 / 你接下的 |

**自检（只看结构）**：把这句拆成前后两截，两截必须**语义相反**
（生前/死后、榜上/榜外、求人/被求、我做的/他们做的）。
构不成对立 → 它只是陈述，删掉。

反差点放在**第 7–10 句**（中后段），签名句之前，形成「立—转—收」。

### 6.6 第一句不报名，名字可以晚落地

- 第一句必须是钩子，不许「我是 X ……」；
- 人物名可延迟到第 9–12 句，前面靠**只有他成立的物证**认人；
- 名字落地越晚，物证就要越硬；
- 删除一切"这句其实是说……"的注解。

## 七、签名句（每首必须有，且必须本项目生成）

**不用固定句式。** 签名句由本项目自己长出来，三条硬要求：

1. **回扣主辙**，末字能拖住、能收；
2. **前面必须有画面托住**，不许只剩口号；
3. **给动作或回答，不给道理**；不喊成功，不喊"努力就有回报"。

写法：从主钩里抽一个**物件/动作**，结尾把它**再放一次**：

> 主钩里有「塔」→ 签名句回到「塔」；
> 主钩里有「线」→ 签名句回到「线」；
> 主钩里有「名单」→ 签名句回到「名单」。

**自检**：把签名句单独拿出来，听众能不能想起第一句？想不起 = 没回扣。

## 八、成稿前的「六刀」

> 初稿能立住之后，**不要再加新意象**，只修硬伤。一次最多动 4–6 处。

### 第一刀：时间线锁死

人物的年龄/年份一旦是**隐喻**，第一句就要把「今天的我」和「人物的数字」放在同一句里；
**隐喻版**与**真实年龄版**二选一，不许混。

| 版本 | 同龄人写什么 | 不能写什么 |
|---|---|---|
| 隐喻版 | 上岸、晒房、加班 | 办退休、抱孙子 |
| 真实年龄版 | 办退休、晒孙 | 上岸、同学群晒娃 |

锁句压进一个 bar（≤13 字）；压不进就做 2 小节念白，并同步改总长。

### 第二刀：现实逻辑三本账

| 账 | 问法 | 反例 → 改法 |
|---|---|---|
| 数字账 | 数字和单位对得上吗？ | <N 年履历> → <N 份简历> |
| 语法账 | 这个词是这个意思吗？ | 赔的是赊账 → 赔的是欠账 |
| 身份账 | 这个年龄/身份的人会做这件事吗？ | 30 岁同龄人办退休 → 上岸 |

### 第三刀：不许时空跳档

古代物证**连续不超过 2 句**；连排就压成一句或换同义现代场景；
现代段与古代段之间，用一句人物动作或金句隔开。

### 第四刀：结尾唱完

签名句必须完整，末字押主辙、能拖住；只唱半句 = 断气。

### 第五刀：古物落在现代动作上

古物句必须带一个今天可拍的动词（摆摊/投简历/还账/加班/背锅）；
一段纯古物最多 2 句。

### 第六刀：代词第一次出现给身份

`她/他` 不能凭空出现。第一次出现必须带身份名词（对象/合伙人/我妈/我爸/亲戚），
身份名词 2–4 字，给完身份再用代词。

### 改动纪律

1. 只动硬伤，不动骨架；
2. 不加新意象；
3. 一次改 1–2 处（最多 4–6 处）；
4. 能录 demo 就停手，先进棚唱一遍，按 flow 卡点再动字。

## 十一、音频定稿后的红线

音频一旦生成，**一个字都不许改**。原因：

- 口型由**音频**驱动，提示词里的引号台词只告诉模型「这一秒该对哪几个字」；
- 你写的词和音频不一致 → 模型按你的词对口型，声音在唱别的 → **字全错**；
- 补词/删词 → 音频里没有那段 → 模型只能瞎动。

所以音频回来后，④ 的工作只剩三件：**听写核对 → 标整数秒 → 写进提示词与 `lyrics[]`**（见 `04-时间轴与字幕.md`）。
