# 画面动态与感染力（MV / 口播 / 图生视频通用）

> 适用于：本 skill，以及任何「参考图 → 人物开口/表演」的视频生成。
> 来源：该 MV 品牌 MV + 哪吒说唱两个项目的真机实测与返工。
> 关联：`references/对口型经验总结.md`（口型三要素与排障），本文件管**画面为什么不动、为什么不动人**。

---

## 0. 一句话

**「画面丰富」和「有感染力」不是一回事。**
丰富是加法（元素数量），感染力是节奏（静→动→静的对比）。
**全程都在动，等于全程没有动。**

---

## 1. 三层动态：缺一层就死一块

绝大多数「人物像木头人」的返工，根因是提示词**只写了人物**。

| 层 | 写什么 | 不写会怎样 |
|---|---|---|
| **人物** | 律动（每拍肩线下沉）、动作单元（点头→耸肩→抬手→收手）、手势、面部反应 | 站着只动嘴，像会说话的蜡像 |
| **饰品 / 服饰** | 飘带、披风、发丝、腰饰、金属件随律动摆荡、面料褶皱起伏、反光流动 | **全程静止**——这是最容易被忘、也最刺眼的一层 |
| **环境** | 云气流动、树叶/莲叶轻摇、尘埃或花瓣飘落、光缓慢明暗推移、远处空气扰动 | 背景变成一张壁纸，人物像贴在画上 |

**提示词必须给这三层各写一句**，并各配一个「不许静止」的锚点词。

---

## 2. 画面事件：3–5 个就够，其余克制

「每句歌词都配一个动作」是最常见的错——结果是没有高潮，还稀释口型权重。

**正确做法：**

1. 从歌词里挑 **3–5 句带具体名词**的（法宝、动作、场景）；
2. 每句给一个**可执行的画面事件**（谁动、怎么动、动多久）；
3. 其余时间明确写「只保留轻动态」；
4. **收尾留一段几乎静止**——前面才有对比。

30 秒的典型配比：

| 位置 | 强度 |
|---|---|
| 0–3s | 开场第一下（起势） |
| 中段 2 个点 | 最强爆点（与歌词名词对应） |
| 最后 2–3s | 收住、几乎静止 |

---

## 2.5 镜头也是节奏的一部分（最容易被漏的第五层）

只让「人和背景」动、镜头却钉死，画面照样没气——**观众 10 秒就腻**。

| 写法 | 效果 |
|---|---|
| 机位完全固定 | 像 PPT；长拍必死 |
| **每 2 拍极轻推开 / 回拉（幅度 <2%），重拍处顿一下** | ✅ 呼吸感，和音乐咬合 |
| 开场 0–3s 快速推近到**半身**，之后锁景别 | ✅ 通用解法：既保住起势气势，又落回能看清口型的构图 |
| 快速甩镜 / 横摇 / 变焦跳动 | ❌ 口型直接崩 |

**两档运镜**（按气质选）：

| 档 | 写法 | 适合 |
|---|---|---|
| 稳档 | 开场推近到半身，之后每 2 拍 <2% 微推 | 慢歌、口型优先 |
| **动感档** | 景别内每 2 拍交替推 / 拉 / 横移，重拍顿一下；横移 ≤3% 画宽，推拉 ≤1 个景别档 | 说唱、快歌 |

动感档铁律：**动在拍点上，不匀速漂移**；**人动镜头稳、人停镜头动**；不做 180° 甩镜（单镜里甩镜＝切镜）。

**卡拍一定要写秒点，不要写「每 N 拍」**：

```
❌ 每 2 拍做一个动作，三种交替：推 / 拉 / 横移     ← 模型不知道第 2 拍在哪一秒
✅ 3s 向前推一小步（0.4 秒内完成，然后停住）
   8s 向右横移一小步（0.4 秒内完成，然后停住）
   其余时间镜头完全静止
```

要点：秒点要和台词时间轴**同一套秒数**；每个动作标「**0.x 秒内完成，然后停住**」——
**动作短、停顿长**才叫卡点，动作一拉长就变成匀速漂移。

**关键分寸**：
- 幅度 **<2%**——卡拍要的是呼吸，不是炫技；
- **推到位立刻锁景别**——推完还继续推，模型一直在重绘，脸最容易崩；
- 长句开口时**不要边推边唱**，把运动放在句间或重拍空档。

## 2.6 为什么画面「没劲儿」（张力三件套）

「没劲儿」几乎不是细节问题，是**张力被磨平了**。四个常见病：

| 病 | 症状 | 药 |
|---|---|---|
| **光太平** | 柔光 + 低对比 + 高明度 | 光比压硬、暗部压深、背景压暗一档；加一道冷色轮廓光；暖光只留眼与边缘；四角轻暗角 |
| **构图太正** | 正面平视、居中、半身 | **机位略低、微仰 5–10°**，人物占画面更大（近景到中景之间）——压迫感立刻出来 |
| **节奏太匀** | 每 2 拍均匀微动 | **憋 4 拍、动 1 拍**：前 4 拍几乎不动，第 4 拍猛地推近/横移；爆发后回稳再憋 |
| **爆点太多太轻** | 每个点都是「微微」「极轻」 | 只留 **2 个 100 分的爆点**，其余压到 30 分；宁可三个点里只炸一个 |

**劲儿 = 对比**：明暗对比、大小对比、动与静的对比。
全程用力＝没有用力；**憋住的那几拍，才是让爆点变响的原因**。

> 提醒：光比与构图改动会与「柔和参考图」冲突——参考图如果是柔光暖调，
> 单靠提示词改光只能改一半；要彻底硬起来，得连参考图一起重出。

---

## 2.7 参考图决定气质，提示词只能"锁"，不能"改"

同一个角色、同一句提示词，换一张参考图（柔光 vs 硬光），出来是两个片子。

| 做法 | 结果 |
|---|---|
| 提示词里写「光比更硬、暗部压深」 | **只能改一半**——图生视频的重心在参考图，模型会向图的光靠 |
| **直接换一张硬光参考图** | 气质立刻变，提示词只写「**锁定参考图的光、不要重新打光、不要提亮、不要柔光**」 |

**结论**：气质（光、色、质感）在**出图**阶段定，视频阶段只负责**不破坏**。
提示词里再要求"打硬光"会二次加工 → 过曝、人脸烤糊。
负面要加：`柔光、平光、高调发白、整体提亮`。

## 2.8 运镜卡点的能力上限：要"呼吸感"，不要"帧级卡点"

**诚实的边界**：这类模型逐帧生成，没有真正的"镜头轨道"。它能理解**整体趋势**（缓慢推、手持感），
但很难执行「第 3 秒推、第 8 秒横移」这种**时间码级**运镜。

为什么口型能卡准、镜头不能？——**口型有音频在物理驱动，镜头只有文字**。

**所以写法要换**：不要只写「第 X 秒动一下」（模型做不到，画面会显得一动不动），
改成两层——

| 层 | 写法 | 作用 |
|---|---|---|
| **基线律动** | **每一拍做一次极轻的推近/回拉（1–2%），重拍幅度略大** | 画面一直在"呼吸"，看得出跟着拍子 |
| **明显动作** | 句首 0.4 秒推/拉/横移 3–4%，然后停住 | 制造段落感 |

**关键**：光写"第几秒动一下"而没有基线律动，模型会理解成"整体静止 + 几个突变"，
结果就是你看到的"完全没有变化"。**先让它一直在轻微起伏，再给几个明显点。**

底线：匀速滑轨式漂移、甩镜、环绕，一律不写。

## 3. 道具互动三档：风险差十倍

想让画面「和歌词互动」时，先分清自己在做哪一档。

| 档 | 做法 | 可行性 | 说明 |
|---|---|---|---|
| **① 已有道具互动** | 用人物身上本来就有的东西：抓住飘带外甩、腰饰被带动划圈、手抚过配饰 | ✅ **安全，优先** | 模型只需让已存在的东西动，不用造物 |
| **② 前景元素掠过** | 花瓣、云气、尘埃从**画面前方**掠过一瞬 | ⚠️ **可控，最多一处** | 会短暂遮挡画面，注意别挡嘴 |
| **③ 新道具生成 / 场景插入** | 让武器、坐骑、法宝凭空出现；或切到另一个场景 | ❌ **必崩** | 要凭空造物 + 重绘身体，结果是换脸、变形、穿模 |

**台词里的东西不必都画出来。** 词里骂到「哮天犬」「三尖两刃刀」，画面完全可以不出现狗、不出现刀——
观众脑补比模型硬画安全得多。真要让画面呼应，用**角色的反应**代替：眼神一变、下颌一抬、嘴角一挑。

**铁律：能不动结构就不动结构。**
真想「每句歌词都有对应画面」，那是**多镜剪辑**的活（一句一镜、道具特写），不是单镜能做的。

## 4. 加动态的三条边界（破了就毁片）

1. **不进入面部区域**：饰品、手、道具一律「不高于下巴、不经过面部、不遮挡嘴部」；
2. **不甩头、不转身、不走位**：这三样一动，口型和脸同时崩；
3. **不新增物件**：所有互动只发生在已有道具上，写死「不出现武器、不改变身体结构」。

加动态后必须复查：**换脸没有、糊嘴没有**。动效和口型在抢同一份模型注意力。

---

## 5. 负面清单：按病因分组，缺一组就会犯一次

| 病因 | 必写负面词 |
|---|---|
| **僵** | 背景静止不动、饰物静止、云不动、布料僵硬、画面死板、身体僵直、木头人、面瘫、动作卡顿 |
| **崩** | 换脸、五官变形、多手臂、三头六臂、道具穿模、凭空出现新道具、火尖枪、风火轮（按项目替换） |
| **挡** | 手挡嘴、侧脸背对、大幅转头、镜头大幅晃动 |
| **字** | 文字、数字、字母、logo、水印、二维码、字幕 |

> 「僵」这组最容易被漏。不写，模型默认偷懒——主体动，背景和饰品全定死。

---

## 6. 排查表

| 现象 | 根因 | 修法 |
|---|---|---|
| 人物僵直、只动嘴 | 只写了「自然呼吸 + 轻微点头」 | 补「每拍下沉 + 4 拍动作单元 + 手势」 |
| 背景完全不动 | 提示词里没有环境层 | 补云/叶/尘/光；负面加「背景静止不动」 |
| 混天绫、配饰全程静止 | 提示词里没有饰品层 | 补「持续飘动、随律动摆荡、反光流动」；负面加「饰物静止」 |
| 画面热闹但没感染力 | 每句都配了动作，平均化 | 砍到 3–5 个画面事件，收尾留静止 |
| 道具互动后换脸 / 变形 | 做了第 ③ 档（新道具/结构变化） | 退回第 ①② 档；新道具写进负面 |
| 互动时手挡嘴、口型崩 | 动作越过了下巴 | 写死「只在胸前到腰侧/肩高，不经过面部」 |
| 加动态后口型变差 | 动效抢了模型注意力 | 动效减半，先保口型；或拆镜 |

---

## 7. 成本与取舍

- **动效 vs 口型**：同一份注意力预算，动效多了口型就掉。口型是基本盘，先保口型再加动效。
- **一次只改一个变量**：先加环境，再加饰品，最后加画面事件。三样一起加，出问题无法归因。
- **先改一镜**：多镜项目先改 1 镜出片验证，成了再同步；同时改全部，失败就是全废。
- **别用「全程加料」换「有感染力」**：那是两回事，见第 0 节。

## 8. 速查清单（出片前逐条看）

- [ ] ④ 段有**五层**：**镜头（卡拍）** / 人物律动 / 手部 / 饰品 / 环境
- [ ] 镜头不是死机位：有卡拍微推，或开场推近到半身
- [ ] 饰品与环境各有一句「不许静止」的锚点
- [ ] 画面事件 **3–5 个**，其余明确写「轻动态」
- [ ] 收尾有一段**几乎静止**
- [ ] 互动只做第 ①② 档，没有新道具
- [ ] 边界三句：不进面部 / 不甩头转身 / 不新增物件
- [ ] 负面含「僵 / 崩 / 挡 / 字」四组
- [ ] 加完动效后，口型是否仍然可用
- [ ] 气质是否在**参考图**阶段就定好（光/色/质感），提示词只做"锁定"
- [ ] 运镜只要求"运动趋势"，卡点留给后期
- [ ] 台词里的道具没有被硬画进画面
