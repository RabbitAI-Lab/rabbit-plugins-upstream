# 06 · 提示词与出片

## 一、六段式提示词（逐字保留标题）

> 标题必须原样保留，`qa.py` 会按标题检查。正文可以用中文长句，但不要删段。

```
① 一句话摘要
让参考图中的同一位人物，在<场景>中以半身近景正面面对镜头，跟着参考音频开口说唱（Rap），
一镜到底 <该镜 seconds> 秒；<情绪>；<曲风/BPM>。

② 人物与参考图锁定
以 @图片1（<完整直链>）为唯一人物与造型锚点：同一张脸、同一发型、同一服装、同一配饰、
同一背景关系；<逐项可观察特征>；人物始终位于画面中央偏上，面部受光均匀，
嘴部完整可见、自然开合，全程不遮挡嘴部；不重绘脸、不美化、不换装。

③ 时间轴说唱（相对秒，整数，末块收到该镜 seconds）
[0-2s] 人物看向镜头，吸气、点头找拍，准备开口（不唱）；
[2-6s] 开口说唱："<第一句>"，精准唇形同步音频，每个字都有开合、不吞字；
[6-10s] 继续说唱："<第二句>"，精准唇形同步；
…
[26-30s] 最后一句收尾："<末句>"，尾音落下，看镜头收住。

④ 镜头与表演（镜头卡拍 + 人物律动 + 饰品飘动 + 环境流动，画面不能死）
镜头（跟着节奏走，不许死机位）：
  开场 0–3s：从全景/全身快速推到半身，一镜到位，推的过程中不停顿；
  3s 之后：**锁在半身**（腰以上），只做「每 2 拍一次极轻推开 / 回拉」，幅度 <2%，重拍处顿一下；
  不甩镜、不横向摇移、不变焦跳动、推到位后不再继续推。
人物律动：每一拍肩线轻微下沉，胸腔随重音起伏，重心左右小幅转移；
每 4 拍一个动作单元：第 1 拍点头、第 2 拍耸肩、第 3 拍抬手比划、第 4 拍收手回胸前。
手部：左手在胸前到小腹之间做说唱手势，手掌不高于下巴、不经过面部、不遮挡嘴部。
面部：重音句挑眉、眼神钉住镜头，句尾吐气收住；表情<情绪>，不面瘫。
饰品（全程有生命感）：<本人物饰品A>在肩臂/身侧持续飘动、有褶皱起伏与尾端翻卷；
<本人物饰品B>随律动轻轻摆荡、表面反光流动；鬓角发丝随动作摆动。
环境（在人物背后一层，必须有动态）：<本场景环境元素>缓慢流动、轻摇、
空气中细微尘埃/水汽/光屑缓慢飘落、侧光缓慢明暗推移。
画面事件（只在指定秒点发生，其余保持轻动态；只用人物身上已有的道具）：
  · 0–3s：<开场第一下，用本人物已有饰品/衣摆>
  · <爆点 1：手抬到腰侧虚托，带动本人物饰品>
  · <爆点 2：饰品尾端从侧前方扫过一瞬，不经过面部>
  · <收尾：环境元素从画面前方飘过、符号亮一下>
边界：不甩头、不转身、不走位、不换景、不换装、不切镜；
饰品与环境动效一律不进入面部区域、不遮挡嘴部。

⑤ 声音设计
本镜不生成人声与配乐；口型、咬字、flow 只严格匹配参考音频 @音频1 的人声；
画面节奏跟随该音频的 BPM 与鼓点；成片音轨使用该参考音频本身。

⑥ 画风与强制约束
<风格锁定句>；画面零可读文字、无字幕、无 logo、无水印、无二维码；不出现第二个人；
不出现乐器遮挡面部；不出现畸形手指/五官扭曲/换脸感；不出现画面闪烁/跳帧。
负面：糊嘴、双嘴、吞字、连读含糊、口型滞后、闭嘴不动、唱成旋律腔、念白朗读、
      手挡嘴、侧脸背对、大幅转头、换脸、五官变形、镜头晃动
音频：不额外生成人声与背景音乐；口型与咬字只匹配参考音频 @音频1
```

## 二、每段怎么写

### ① 一句话摘要

- 必须出现：同一人物、**半身中景、正面/微侧（偏角 ≤10°）**、**跟参考音频说唱**、一镜到底、**该镜精确秒数**、情绪、曲风。
- 不要写「大约」「左右」；写该镜 `seconds` 的精确值（如 `15.18 秒`），不要一律写 30 秒。
- 不要写「让她开始唱歌」——**说唱 ≠ 唱旋律**，写「说唱（Rap）」。

### ② 人物与参考图锁定

- 先绑 `@图片1` 与完整直链（`@图片1` 是官方按 `content[]` 顺序的编号，别写文件名当引用）；
- 再逐项写：脸型、发型/发色、服装颜色/材质/款式、配饰、背景关系；
- 最后写：居中偏上、受光均匀、嘴部完整可见、自然开合、全程不遮挡；
- **视觉锚点（塔/法宝/饰品）低于嘴**，每镜都在；主镜微侧、中景，给锚点和口型都留空间；
- **明写「不重绘脸、不美化、不换装」**——这是「必须用用户传的图」的执行约束；
- **不要**写「像某明星」「某剧同款」。

### ③ 时间轴说唱

- 全部是**片段内相对秒**，从 `0` 开始，**整数秒**；
- 歌词必须**双引号**包裹，且与音频**逐字一致**；
- 每块都写「精准唇形同步」；
- 明确「说唱，不是唱旋律、不是念白」；
- 第一块是起势（不唱），第一句在 **2 秒内**出现；
- **末块 `end` 必须 = 30**；
- 一块最多 4 个字，超了就拆。

### ④ 镜头与表演

**这一段是「僵不僵」的生死线。** 只写「自然呼吸 + 轻微点头」= 模型会让角色站着只动嘴。

必须写**五层**（少一层就死一块）：

0. **镜头**：跟着拍子动（每 2 拍轻推/回拉，幅度 <2%），开场可快速推近到半身——**死机位等于没气**；
1. **人物律动**：跟着 BPM，每拍肩线下沉；给「4 拍动作单元」（点头→耸肩→抬手→收手）；
2. **手部**：说唱手势，胸前到小腹之间，**不高于下巴、不经过面部、不遮嘴**；
3. **饰品（最容易被忘）**：本人物饰品A要飘、饰品B要晃、发丝要动——**不写就永远静止**；
4. **环境**：本场景环境元素流动/轻摇、尘埃光屑飘、光缓慢明暗推移——**不写背景就是一张壁纸**。

再加一段 **「画面事件」**：只挑 3–5 个与歌词有具体名词对应的秒点（如歌词点到本人物符号 → 该符号明显一晃），
**其余时间保持轻动态**。不要每句都配动作——配满等于没高潮，还稀释口型权重。

机位：**跟着节奏微动**，不是完全不动；把「镜头晃动」从负面里拿掉，否则画面死板。

**先认清能力上限**：模型能理解「运动趋势」（缓慢推近 / 手持），但**做不到时间码级卡点**。
口型能卡准是因为有音频物理驱动，镜头没有。

**所以镜头要分两层写**（只写"第 X 秒动一下"会变成"不动"）：

1. **基线律动**：**每一拍做一次极轻的推近/回拉（1–2%）**，重拍幅度略大——让画面一直在呼吸；
2. **明显动作**：句首 0.4 秒推/拉/横移 3–4%，然后停住——制造段落感。

只写第 2 层不写第 1 层，实测结果就是"画面完全没有变化"。

**运镜两档，按项目气质选：**

| 档 | 写法 | 适合 |
|---|---|---|
| **稳档** | 开场推近到半身，之后只做「每 2 拍 <2% 微推/回拉」 | 慢歌、口型优先、单镜长拍 |
| **动感档** | 3s 后半身固定景别内，**每 2 拍交替推 / 拉 / 横移**，重拍顿一下；横移 ≤3% 画宽，推拉 ≤1 个景别档 | 说唱、快歌、要有冲劲 |

动感档的关键分寸：**动在节奏点上，不是匀速漂移**——重拍顿一下才有卡点感；
**人物动时镜头稳、人物停时镜头动**，两者错开，画面才不打架。
仍然是：不做 180° 甩镜、不做环绕、不整屏横摇（单镜里甩镜等于切镜，会断）。

**卡拍必须写成秒点，不能写「每 N 拍」**（这是最常踩的坑）：

> ❌ 「每 2 拍做一个动作，三种交替：推 / 拉 / 横移」——模型不知道第 2 拍在哪一秒，结果只会动一下或干脆不动。
> ✅ 直接写秒：「3s 向前推一小步、0.4 秒内完成、然后停住；8s 向右横移；13s 向后拉……」

写法要点：
- **一行一个秒点**，和 ③ 的时间轴**同一套秒数**（这样镜头和人声天然咬合）；
- 每个动作都标「**0.x 秒内完成，然后停住**」——**动作要短、停顿要长**，这才是卡点；
- 明确列出「其余时间镜头完全静止」，否则模型会一路匀速漂；
- 镜头时间轴**不要在 `<秒>-<秒>s` 外面加方括号**，会和 ③ 的台词时间块混淆（`qa.py` 只解析 ③ 段）；
- 一条铁律：**句子开头动，句子唱的过程中不动**——人动镜头稳、人停镜头动。

**镜头卡拍怎么写**（这一段最容易写成空话）：

```text
镜头：开场 0–3s 从全身快速推到半身，一镜到位；之后锁在半身，
每 2 拍一次极轻推开与回拉（幅度 <2%），重拍处顿一下；
不甩镜、不横摇、不变焦跳动。
```

- **开场推近**是通用解法：参考图往往是全身/全景，但长拍半身才看得清口型——用前 3 秒把景别「走」过去，既保住起势的气势，又落回能对口型的构图；
- **之后锁景别**：推到位还继续推，模型会一直重绘，脸最容易崩；
- **幅度 <2%**：卡拍要的是「呼吸感」，不是运镜炫技；幅度大了口型直接被稀释。

**「和歌词互动」三档，只做前两档：**

| 档 | 做法 | 判断 |
|---|---|---|
| ① 已有道具互动 | 人物自带的饰品/法宝被手带动、外甩——**道具本来就在身上** | ✅ 安全，优先用 |
| ② 前景元素掠过 | 花瓣/云气从画面前方飘过一瞬，不挡嘴 | ⚠️ 可控，最多一处 |
| ③ 新道具生成 / 场景插入 | 新武器、坐骑、多手臂、切到新场景 | ❌ 必崩：要凭空造物 + 重绘身体 |

写 ③ 的结果一定是换脸或人物变形——**比"背景不动"难看得多**。
如果确实想「每句歌词都有对应画面」，那是**多镜剪辑**的活，不是单镜能做的。
做 ①② 时负面要加「新武器、新坐骑、多手臂、凭空出现新道具、道具穿模」，防止模型自由发挥。

**负面必须补**：`背景静止不动、饰物静止、云不动、布料僵硬、画面死板`——不写这几条，模型默认偷懒。

底线仍然保留：**不甩头、不转身、不走位**；饰品与环境动效**不得进入面部区域**——这几样一动，口型和脸就崩。

### ⑤ 声音设计

这一段和「唱歌版」完全相反——**不要**描述音色/曲风/配器，因为声音**不是模型生成的**：

- 写「本镜不生成人声与配乐」；
- 写「口型、咬字、flow 只匹配参考音频」；
- 写「画面节奏跟随该音频的 BPM 与鼓点」；
- 写「成片音轨使用该参考音频本身」。

> 如果你在这里描述音色和配器，模型会试着**自己再造一版声音**，反而和你的音频打架。

### ⑥ 画风与强制约束

- 有用户原图：写「保持参考图人物与场景，不重绘人物，只做视频层光影与运镜」；
- 无图：逐字照抄「重彩水墨轻鎏金」固定风格句；
- 强制：零可读文字、无 logo/水印/二维码、无第二人、无遮嘴、无畸形、无换脸感、无闪烁；
- **负面清单必须含口型类**：糊嘴、双嘴、吞字、连读含糊、口型滞后、闭嘴不动、旋律腔、念白。

> **附带原则（不写进提示词，是写作决策）**：台词里提到的道具/坐骑/法宝——
> 画面可以完全不出现。观众脑补比模型硬画安全得多（硬画＝凭空造物＝换脸变形）。
> 画面呼应用**角色反应**代替：眼神一变、下颌一抬、嘴角一挑；负面里把该类物件写死（`新道具、坐骑、武器`）。

## 二·五、音频处理：只切，不改速

**速度由音频文件决定，不由我们定。** 永远 1.0 倍，`atempo` 一次都不用。

只用脚本切（它没有变速参数，代码里也没有 atempo）：

```bash
# 单镜
python3 scripts/cut_audio.py 00-输入/音频/原声.wav --start 0.72 --end 31.12 -o 00-输入/音频

# 超 30 秒 → 在句间切开，自动出 S01/S02
python3 scripts/cut_audio.py 00-输入/音频/原声.wav --start 0.72 --end 31.12 \
    --split-at 15.54 -o 00-输入/音频

# 先看方案不落盘
python3 scripts/cut_audio.py 00-输入/音频/原声.wav --start 0.72 --end 31.12 --split-at 15.54 --dry-run
```

### 两条硬指标

| 指标 | 取值 | 为什么 |
|---|---|---|
| `--start` | **第一个字的开始时间**（ASR 定） | 前面是伴奏/静音，切掉不丢字 |
| `--end` | **最后一个字的结束时间 + 0.5~0.8s** | 见下 |

> ⚠️ **最致命的错**：把句子的「开始时间」当结尾。
> 最后一个字的 ASR `start` 只是它**开口**的时刻，它还要唱 0.3–0.5 秒。
> 用它当 `--end`，这个字就被整段切掉——听感就是「突然结束、少几个字」。
> 必须用 `word.end`，再加 0.5–0.8 秒。

### 末段必须淡出

裁在鼓点上会有硬切感（"啪"一下没了）。`cut_audio.py` 默认对**最后一段**做 0.30s 淡出，
输出尾部能量应从 -19 dB 衰减到 -35 dB 以下。校验：

```bash
ffmpeg -hide_banner -nostats -sseof -0.6 -i 00-输入/音频/S02.wav \
  -af "asetnsamples=4410,astats=metadata=1:reset=1,ametadata=print:key=lavfi.astats.Overall.RMS_level" \
  -f null - 2>&1 | grep -o "RMS_level=[-0-9.]*"
```

### 不变速的三条底线

1. **不许为凑时长提速**——嫌长就拆镜，不嫌短就不动；
2. **不许为对齐时间轴提速**——时间轴跟音频走，不是音频跟时间轴走；
3. **语速（字/秒）只记录不优化**——密度过高导致糊嘴，改的是**词**（减字），不是速度。

## 三、分镜 JSON 契约（按音频长度自动拆镜）

**成片长度 = 音频长度，不为 30 秒提速或切字**：先按**信息段**拆镜，再确保每镜 ≤30 秒；
30s 可 1–2 镜；40s 拆 3–4 镜、每镜 8–12s；更长的音频再用 `ceil(音频长度 / 30)` 兜底。
都写在同一个 `分镜JSON.json` 的 `shots[]` 里；`lyrics` 挂在**每个 shot 上**，时间是**相对该镜起点**。

```json
{
  "project": "MV02-nezha",
  "ratio": "9:16",
  "generate_audio": false,
  "shots": [
    {
      "id": "S01",
      "prompt": "<六段式 · 第 1–6 句>",
      "refs_urls": ["04-图片/ref_人物.png"],
      "ref_audio_urls": ["00-输入/音频/S01.wav"],
      "seconds": 16.70,
      "duration": 17,
      "mode": "reference",
      "resolution": "720p",
      "lyrics": [{"start": 0, "end": 3, "text": "<第一句>"}]
    },
    {
      "id": "S02",
      "prompt": "<六段式 · 第 7–12 句>",
      "refs_urls": ["04-图片/ref_人物.png"],
      "ref_audio_urls": ["00-输入/音频/S02.wav"],
      "seconds": 16.34,
      "duration": 17,
      "mode": "reference",
      "resolution": "720p",
      "lyrics": [{"start": 0, "end": 3, "text": "<第七句>"}]
    }
  ]
}
```

| 字段 | 规则 |
|---|---|
| `shots` | **1–4 条**；30s 可 1–2 镜；40s 按信息段拆 3–4 镜 |
| `seconds` | 该镜成片长度（≤30 秒，可小数） |
| `duration` | **整数** = `ceil(seconds)`；出片后自动裁回 `seconds` |
| `ref_audio_urls` | 每镜**恰 1 条** |
| `refs_urls` | 多镜时**用同一张图**，保证是同一个人 |
| `lyrics` | 每镜相对秒；`assemble.py` 自动累加偏移生成绝对秒字幕 |
| `generate_audio` | 顶层 **false** |

### 拆镜规则

1. **先按信息段拆**：Hook / 现代失败 / 神话关系 / 边界出口；不要把同一个信息段硬切两半；
2. 40s 拆 **3–4 镜**，每镜 **8–12s**；30s 可 1–2 镜；**每镜 ≤30s**；
3. 切点必须落在**句与句之间**（先 `silencedetect` 或 ASR 定句边界）；**禁止为了少出一镜而提速**；
4. 后一镜起点 = 前一镜终点，拼回去等于完整人声——**不变速、不丢句**；
5. 多镜的 ② 人物锁定、⑥ 风格句**逐字一致**，只有 ③ 时间轴和歌词不同；
6. 主镜**微侧、中景**，视觉锚点（塔/法宝/饰品）**低于嘴**，保证口型清楚。

## 五、提示词常见坑

| 坑 | 后果 | 修法 |
|---|---|---|
| 歌词没加引号 | 模型当场景描述，不对口型 | 每句歌词用双引号包裹 |
| 时间轴用整曲绝对秒 | 模型不认，口型错位 | 一律片段内相对秒，从 0 开始 |
| 时间轴写小数（`[0.0-2.4s]`） | 被静默四舍五入，时间点悄悄偏 | 全部改整数秒 |
| 末块 `end` ≠ 该镜 `seconds` | 最后一句收不住 / 后半段漂移 | 末块强制收到该镜 `seconds` |
| 一块塞 6 个字以上 | 连读含糊、吞字 | 拆成 1–4 秒小块，每块 ≤4 字 |
| ⑤ 写了音色/曲风/配器 | 模型自己另生成一版声音，和音频打架 | ⑤ 改成「不生成声音，只匹配参考音频」 |
| 写「唱歌」不写「说唱」 | 生成旋律腔 | ①③ 写明「说唱/Rap」，负面加「旋律唱腔」 |
| 写「镜头环绕/甩头/切换」 | 口型崩、人物漂 | 机位不推拉，明确「不甩头」 |
| ④ 只写「自然呼吸 + 轻微点头」 | **人物僵直、只动嘴、像木头人** | 补律动单元 + 手势 + 面部反应；负面加「身体僵直、木头人、面瘫」 |
| 负面写了「镜头晃动」 | 画面死板、没有呼吸感 | 删掉；改「镜头大幅晃动」 |
| ④ 只写人物，没写饰品/环境 | **背景静止、人物自带符号不动**，像一张会说话的画 | 补「饰品：本人物符号持续动 + 发丝动」+「环境：本场景元素流动」+ 负面加「背景静止、饰物静止」 |
| 每句歌词都配一个画面动作 | 没有高潮、口型被稀释 | 只挑 3–5 个有具体名词的句子做「画面事件」，其余保持轻动态 |
| 让模型生成新道具（武器/坐骑/多手臂）跟歌词互动 | **换脸、人物变形、道具穿模** | 只用身上已有的饰品/法宝做互动；新道具写进负面 |
| 道具互动动作跑到脸上 | 遮嘴、口型无法生成 | 写死「互动只在胸前到腰侧，饰品尾端不经过面部」 |
| 手/麦克风挡嘴 | 口型无法生成 | 明确「双手不入镜/不遮嘴」 |
| 负向词写进正向 | 稀释正向描述 | 负向只放⑥，正向写要什么 |
| 人物描述太泛 | 换脸感 | 逐项写脸型/发型/服装/配饰/背景 |
| 多条 refs 图 | 主体混淆 | 只绑 1 张人物参考图 |
| **用字的 `start` 当音频终点** | **最后一个字被整段切掉 →"突然结束、少几个字"** | 用 `word.end` + 0.5~0.8s 当 `--end` |
| 音频尾部没淡出 | 裁在鼓点上，硬切"啪"一下 | `cut_audio.py` 默认对末段 0.30s 淡出 |
| 用 atempo 把音频压到 30 秒 | 语速变快；算太紧就切字 | **禁止**；长就按 30 秒拆镜 |
