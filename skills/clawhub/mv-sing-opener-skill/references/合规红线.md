# 合规红线

## 一、人物图片授权（一票否决）

用户提供的真人图片，必须属于以下三类之一：

1. **本人**：用户就是画面中的人；
2. **已授权**：有肖像权人书面/聊天记录授权；
3. **AI 生成**：图片本身是生成式工具产出，且用户有权使用。

无法确认 → 项目降级为**「仅内部样片」**：

- 禁止公开发布、禁止对外交付；
- 交付物顶部与 `交付清单.md` 标注「仅内部样片 · 未确认肖像授权」；
- 不因为“看起来像网图”就默认可用。

**不做**：人脸识别、身份推断、把普通人说成明星、把明星脸换到普通人身上。

## 二、不影射真人/IP/品牌

- 不写真实姓名、艺名、明星名、网红名；
- 不写“某明星同款”“某剧同款”“某品牌联名”；
- 不复制已有 IP 角色（动漫/游戏/影视）的服装、标志、配色组合；
- 不出现真实品牌 logo、商标、产品包装；
- 歌词不点名真实人物、公司、机构。

## 三、未成年人

- 画面中人物看起来是未成年人时，默认**健康、日常、无成人化**表达；
- 不写恋爱暗示、暴露服装、夜店/酒精/烟草/纹身等元素；
- 歌词不涉及成人情感、暴力、自伤；
- 不确定年龄感时，按“偏年轻”处理，降低风险。

## 四、歌词版权

- 必须**原创**；不抄现有歌词、不洗稿、不改几个字就用；
- 不把古诗/名句整段当歌词（公有领域也要控制比例，避免“拼贴感”）；
- 不引用真实歌名作为标题；
- 用户提供歌词时，默认用户拥有权利；若明显是现成歌曲，提示风险并请用户确认授权。

## 五、内容安全

禁止：

- 政治敏感、宗教冲突、民族歧视、地域歧视；
- 医疗功效承诺、金融收益承诺、投资建议；
- 低俗、色情暗示、暴力、血腥、自伤、自杀；
- 赌博、毒品、诈骗、违法交易；
- 仇恨言论、人身攻击、网络暴力。

金融/广告类内容额外注意：

- 不写“稳赚”“保本”“收益保证”“内幕消息”；
- 不使用未经授权的业绩数据；
- 不冒充机构/官方发布。

## 六、画面合规

- 零可读文字：无字幕、无数字、无字母、无 logo、无水印、无二维码；
- 不出现真实证件、车牌、门牌、聊天记录、合同；
- 不出现可识别的真实地点敏感标识；
- 不出现第二个人（除非用户明确要求且已授权）；
- 不生成畸形、血腥、恐怖画面。

## 七、AI 生成标识

- 交付时提示用户：本片为 **AI 生成内容**；
- 按发布平台要求添加“AI 生成”标识；
- 不冒充真实拍摄、不冒充真人演唱；
- 交付清单里写清“声音与画面均由 AI 生成”。

## 八、上传与外链

- 只上传项目所需的参考图，不上传无关隐私文件；
- 公网直链可能被公开访问，提醒用户不要上传身份证、私密照、聊天截图；
- 项目结束后可按用户要求清理公网目录（本 skill 不自动删除服务器文件）。

## 九、红线自检

- [ ] 图片来源可确认（本人/授权/AI 生成）
- [ ] 无真人明星脸、无 IP 角色、无品牌 logo
- [ ] 未成年人健康表达
- [ ] 歌词原创、无抄袭、无敏感内容
- [ ] 画面零可读文字
- [ ] 无医疗/金融/收益承诺
- [ ] 交付标注 AI 生成
