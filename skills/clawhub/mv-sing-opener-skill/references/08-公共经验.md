# 08 · 公共经验（10 条硬口径）

> 本文件是跨项目复用的**判断标准**，不是模板。
> 它不提供人物、母题、场景、金句；只回答「一个方案为什么会被判不合格」。
> 与其它参考文件冲突时，**以本文件为准**。

---

## 1. 概念成立 ≠ 表达成立

**规则**：好隐喻只能证明「值得做」，不能证明「能做出来」。

**落地动作**：

1. 先判断**概念是否适合目标人群**：他们是谁、平时怎么说话、会不会觉得"这是父辈独白"；
2. 再判断**表达是否成立**：文案、时长、画面、平台约束四条，缺一条就改；
3. 文学化母题必须**转译成目标人群的口语**，不能直接当歌词；
4. 转译后自检：把这句话念给一个不知道人物背景的人听，他能不能立刻对上自己的处境。

**不合格信号**：

- 母题很美，但歌词像散文/判词；
- 全篇是人物在解释自己，没有第二个人、没有具体场景；
- 需要作者在旁边解释「这其实是在说……」才成立。

---

## 2. 代际题材先定边界，再谈和解

**规则**：涉及父子、原生家庭、沉默父母时，**先给边界，再谈关系**。

**三条边界**：

| 不要 | 要 |
|---|---|
| 替沉默父亲解释「他也不容易」 | 让他自己承认「我不会说」 |
| 逼年轻人原谅 | 给出「可以不原谅」的出口 |
| 用大团圆收尾 | 用「不逼」收尾：不逼叫爸、不逼回家、不逼和解 |

**可复用句式**：

> 我不逼你 <做某事>，你也别逼自己 <做某事>。

**自检**：

- 歌词里有没有一句是「承认不会说」，而不是「解释为什么不说」？
- 有没有给听众一个「不原谅也可以」的落点？
- 结尾是不是在逼和解？

---

## 3. 平台硬约束必须前置校验

**规则**：约束不是后期问题，是**写词阶段就要排除的选项**。

**零可读文字下的信息替代表**：

| 想表达的信息 | 不能拍 | 改成 |
|---|---|---|
| 群聊/朋友圈/聊天记录 | 屏幕、文字、弹幕 | 手机震动、屏幕反光、手指悬停、人物表情 |
| 名单/通知/账单 | 纸张上的字 | 纸张的褶皱、盖章动作、手指点一下、人物反应 |
| 时间/年龄/金额 | 字幕、数字 | 口播、手势比数、环境光线变化 |
| 别人的评价 | 评论截图 | 画外音、人物停顿、眼神变化、剪影 |
| 关系变化 | 字幕说明 | 一个动作（推碗、放钥匙、转身）、一个物件（空椅、冷茶） |

**硬规则**：

1. 任何依赖**聊天记录、朋友圈、字幕、弹幕**的信息，一律改成**声音、震动、反光、手势、剪影、口播**；
2. 写词时就把「拍不出来的信息」删掉，不要留到分镜再想办法；
3. 画面里不出现文字，不等于信息不能传达——用**动作和声音**传达。

---

## 4. 字秒比要按「口型驱动」打折

**规则**：纸面能唱 ≠ 口型能对上。

| 档位 | 纸面上限 | 口型驱动建议 | 单句字数 |
|---|---|---|---|
| 30s | 100–130 字 | **100–115 字** | 6–9 字为主 |
| 40s | 150–172 字 | **140–150 字** | 6–9 字为主 |

**原因**：音频驱动口型 + 说唱咬字 + 叙事密度叠加后，字越密越容易糊嘴、吞字、口型滞后。

**硬规则**：

1. **40s 优先 140–150 字**，不要贴 172 字上限；
2. **每句 6–9 字为主（重音句可到 10 字）**，超过 10 字就拆句或减字，**不许提速**；
3. **主歌统一辙口**，Bridge 可换一个开口辙制造转折，签名句收回主辙；
4. 不要用纯文案字数判断说唱容量——**用口型驱动的容量判断**。

---

## 5. 结构先让目标人群「听进去」

**规则**：不要一上来全是父辈苦衷；先让年轻人听见自己。

**推荐顺序**：

```
现代失败（饭桌/电话/转账/分组/加班）
   ↓
神话关系（还清/还命/烧庙/托塔）
   ↓
边界出口（不逼原谅 / 不逼叫爸 / 不逼回家）
```

**硬规则**：

1. **前 2–4 句必须是现代场景**，先建立目标人群的语感；
2. 中段再进「还清/还命」的关系重量；
3. 结尾落「不逼」，不落「和解成功」；
4. 如果全篇前 6 句都是古代事件，判不合格，重排。

---

## 6. 钩子要狠，但不能踩风险线

**规则**：钩子用「**物 + 关系 + 落空**」最稳。

| 结构 | 说明 | 例（占位） |
|---|---|---|
| 物 | 只有这个人物有的具体物件 | 一座塔 / 一张名单 / 一条线 |
| 关系 | 这个物件绑定的关系 | 一声爸 / 一个名字 / 一顿饭 |
| 落空 | 物件换不回关系 | 换不回 / 等不到 / 留不住 |

**风险线**：

- **血腥、剔骨、还骨头、剖腹**类表达**慎用**；
- 口播可以抽象为「**还清 / 还命 / 结账**」，画面**不血腥化**；
- 不拍伤口、不拍骨头、不拍血；
- 钩子可以狠，但不能让平台判违规、让观众生理不适。

**自检**：

- 这句钩子有没有「物 + 关系 + 落空」？
- 有没有血腥/自残/虐待细节？
- 能不能用一句人话复述，不需要解释？

---

## 7. 单镜拆分要按「信息段」而不是按秒数硬切

**规则**：先分信息段，再分秒。

**40s 推荐拆法**：

| 镜 | 信息段 | 时长 |
|---|---|---|
| S01 | Hook + 现代失败 | 8–12s |
| S02 | 神话关系（还清/还命） | 8–12s |
| S03 | 关系冲突/社会比较 | 8–12s |
| S04 | 边界出口/签名 | 8–12s |

**硬规则**：

1. 40s 拆 **3–4 镜**，每镜 **8–12s**；30s 可单镜或 2 镜；
2. 切点落在**信息段之间**，不按秒数硬切；
3. 主镜**微侧、中景**，塔低于嘴，保证口型清楚；
4. 塔、甲、鎏金只做**视觉锚点**，不挡嘴、不抢口型。

---

## 8. 视觉母题要「一个锚点反复出现」

**规则**：风格词要落到一个**可反复拍的具体物件**上。

**落地动作**：

1. 从人物事实里选**一个**符号（武器/法宝/衣饰/伤口/固定动作）；
2. 这个符号在每一镜都出现，位置固定；
3. 风格词（重彩水墨、轻鎏金、暮色海雾）只做**质感**，不新增主体；
4. 符号位置：**腰前掌心或胸腹侧，低于嘴**，不挡口型。

**自检**：

- 去掉风格词，还认得出这个人物吗？
- 这个符号在每一镜都在吗？
- 它挡不挡嘴？

---

## 9. 风险控制不是删情绪，而是换表达

**规则**：保留复杂情绪，把「审判性画面」换成「承认性口播」。

| 不拍 | 改说 |
|---|---|
| 剔骨/剖腹/血腥 | 「我还清了」「我把命还了」 |
| 打骂/羞辱 | 「我没回话」「我把手放下了」 |
| 说教/判词 | 「我不会说」「我不逼你」 |
| 大团圆 | 「塔没塌，我也没塌」 |

**硬规则**：

1. 不洗白、不审判、不强行和解；
2. 不拍剔骨、不说教、不烧字幕；
3. 用「**我不逼你叫爸，塔也不逼你回家**」完成边界表达；
4. 情绪可以复杂，但**画面不能血腥、不能羞辱、不能替观众下判决**。

---

## 10. 可复用检查清单（每项目必过）

- [ ] 概念是否一句话说清？
- [ ] 目标人群语感是否成立？
- [ ] 硬约束是否在写词阶段排除冲突？
- [ ] 字秒比是否按口型驱动打折（40s 140–150 字、每句 6–9 字为主）？
- [ ] 结构是否先现代后关系、最后边界出口？
- [ ] 钩子是否狠而不踩线（物+关系+落空，无血腥）？
- [ ] 单镜是否按信息段拆分（40s 3–4 镜，每镜 8–12s）？
- [ ] 视觉锚点是否不挡口型（腰前掌心/胸腹侧，低于嘴）？
- [ ] 是否有「不逼原谅」的出口？
- [ ] 零文字信息是否都有声/光/动作替代？

> 十项有一项不过，就停在当前站改，不要进下一站。
