# 02 · 钩子句（只写第一句）

> **本文件只干一件事：写第一句。**
> 不写第二句、不写段落、不写歌词。第一句没定稿，词作者不许开工。
> **不内置任何现成钩子、人物、数字、金句。** 所有候选必须从本项目的
> `01-解读/01-任务书.md` 与 `02-方案/01-方案.md` 现场推导。

## 一、角色边界

| 做 | 不做 |
|---|---|
| 从事实里找「原数字」 | 不编数字、不换算、不模糊成"很多年" |
| 出 3–5 个候选第一句 | 不写整段 |
| 按 4 分制打分 | 不靠"我觉得好听"定稿 |
| 选定 1 条主钩 + 1 条备选 | 不把候选全塞给用户让他选 |

## 二、四步写法

### 第 1 步：先把「原数字」找出来

翻任务书与方案的事实清单，找**这个人物最有辨识度、且可核对**的数字。

| 数字类型 | 来源 | 适合落点 |
|---|---|---|
| 年龄 | 原始材料明确写的岁数 | 求职、入职、退休、人生阶段 |
| 年数/时长 | 明确写了多少年 | 投入产出、努力输给表达、背负等待 |
| 数量 | 明确的件数/人数/层数/颗数 | 交换、首付、资产落差 |
| 次数 | 明确写了几次 | 反复失败、反复被拒、反复重来 |
| 技能/变化数 | 明确写的本领数量 | 本事多但变现难 |
| 命数/关系数 | 明确的亲缘/命债结构 | 原生家庭、亲情切割 |
| 背负时长 | 明确写的被误解/被压时长 | 网暴、背锅、等平反 |

**硬规则**：

1. **能查到才写**；查不到就换一个数字类型，**不许估**；
2. 不把"半辈子""这些年""很久"当数字；
3. 不为了押韵改数字；
4. 数字必须是**这个人物独有**的，换给别人还成立就不是好数字。

### 第 2 步：把数字落到「今天的生活成本」上

把古代/神话的单位，换成今天的人**正在付**的成本：

> 工作、工资、房租、首付、房贷、按揭、简历、面试、汇报、背锅、道歉、
> 催婚、饭桌、户口、彩礼、体检、裁员名单、同学群、家长群、35 岁门槛。

**两条测试**：

1. 这个落点，今天一个普通人**正在经历**吗？
2. 这个落点，能从人物的核心事件**直接推出来**吗？

推不出来 → 换落点，不许硬挂。

### 第 3 步：造「自嘲式损失」

不是写"我很惨"，是写**数字和落点撞出来的亏**，而且口气要硬。

三种可用结构：

| 结构 | 句式 | 要点 |
|---|---|---|
| **换不来** | <数字/物件> 换不回 <落点> | 交换失败，不解释 |
| **变不出** | <本事/数字> 变不出一 <落点> | 能力与结果错位 |
| **才第一次** | <数字> 才第一次 <落点> | 时间差，自嘲 |
| **一句都没** | <数字/身份> 一句 <落点> 都没有 | 关系失败 |
| **输给** | <数字/本事> 输给 <落点> | 比较失败 |

> 自嘲 = **他自己先笑一下，然后更疼**；不是卖惨，也不是骂别人。

**优先结构：物 + 关系 + 落空**（最稳）

| 物 | 关系 | 落空 |
|---|---|---|
| 一个只有他有的具体物件 | 一个关系称呼/身份 | 换不回 / 等不到 / 留不住 |
| 一座塔 | 一声爸 | 换不回 |
| 一张名单 | 一个名字 | 等不到 |
| 一条线 | 一顿饭 | 留不住 |

**风险线（硬规则）**：

1. **血腥、剔骨、还骨头、剖腹**类表达**慎用**；
2. 口播可以抽象成「**还清 / 还命 / 结账**」，画面**不血腥化**；
3. 不拍伤口、不拍骨头、不拍血；钩子可以狠，但不能让平台判违规、让观众生理不适。

**目标人群语感检查**：

> 把这句念给一个不知道人物背景的人听，他能不能立刻懂？不懂就改成他们的口语。

### 第 4 步：压到「一句人话、不解释」

硬指标：

- **≤12 字**（不含标点/空格）；
- 一句说完，信息完整；
- **不出现**：因为 / 所以 / 其实 / 虽然 / 说到底 / 毕竟；
- 不用程度副词撑（非常、特别、极其）；
- 不解释背景，听众自己补。

## 三、4 分制（每项 1 分，可数）

| # | 项 | 角色 | 判据 | 过关 | 不过关 |
|---|---|---|---|---|---|
| 1 | **有数字** | 记忆点 | 年龄/年数/数量/次数/期限 | 具体数字 | 「很久」「这些年」 |
| 2 | **有生活落点** | 共鸣点 | 今天的人正在付的成本 | 上岗/钞票/点头/一套（房）/道歉 | 「道行」「神通」「身价」 |
| 3 | **有自嘲式损失** | 反差点 | 明确失掉什么 | 才第一次/变不出/换不来/一句都没 | 「我很惨」「太难了」 |
| 4 | **短且不解释** | —— | ≤12 字；无因果词、无程度副词 | 9–12 字 | 「虽然我……才……」 |

**4 分才用，3 分改，≤2 分重写。**

> 打分要写进记录文件，不能只写"选了 A"。评审看的是**为什么 A 比 B 高**。

## 五、三条避坑

| 坑 | 表现 | 改法 |
|---|---|---|
| **全员年龄梗** | 不论什么人物都在说自己几岁 | 按数字类型走：年数/数量/次数/期限/命数 |
| **写成人物判词** | 「不如一张口」「一辈子没赢过」 | 落点换成具体生活成本（工资/首付/汇报/道歉） |
| **靠解释制造反差** | 要先知道原著才觉得妙 | 事实自带反差，不解释 |
