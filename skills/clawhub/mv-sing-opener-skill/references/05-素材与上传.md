# 05 · 素材与上传

本 skill 只收**两张东西**：**一张正面人物图**（可选，没有才生成）＋ **一条说唱音频**（必需）。
音频由 ④ 定稿的词出曲后回传；长度不限 30 秒，**人声超过 30 秒自动拆镜**（见 2.4）。
视频不支持——收到视频时，先请用户截一张「正面、嘴部完整可见」的图。

---

## 一、图片校验

| 项 | 合格 | 不合格怎么办 |
|---|---|---|
| 格式 | `.jpg / .jpeg / .png / .webp` | 请用户转格式；不要直接改扩展名 |
| 尺寸 | 短边 ≥ 768px | 请用户换原图；低于 768 会糊、口型会崩 |
| 人脸 | **单人、正面平视，偏角 ≤10°** | 侧脸 / 背影 / 大仰俯角 / 多人 → 退回 |
| 嘴部 | **完整可见、不遮挡、自然微张** | 手挡嘴、口罩、墨镜、低头 → 退回 |
| 画质 | 无重度美颜/滤镜/拼接/模糊 | 退回，请用户给原图 |
| 光线 | 面部受光均匀 | 大面积阴影/逆光剪影 → 退回或建议换图 |
| 背景 | 人物主体清楚 | 背景太乱不致命，但要在方案里说明「保留原背景关系」 |

### 1.1 构图可做性判定（先判能不能做，再谈怎么写）

| 构图 | 可做 | 说明 |
|---|---|---|
| 正面平视 | ✅ 最佳 | 说唱密字，只有正面才读得清 |
| 3-4 侧脸（≤10°） | ✅ 可用 | 仍能看清嘴部开合 |
| 90° 正侧脸 | ❌ | 嘴只是一道剪影线，观众判不出对没对上 |
| 背影 / 手部 / 单眼遮挡 | ❌ | 没有嘴可看 |
| 群像（≥2 人） | ❌ | 多人同时对口型不可能，模型还会重画脸 |

> 这条是**能不能做**的判定，不是**做得好不好**。构图不对，提示词写得再细也救不回来。

### 1.2 处理原则

**不合格就明确说哪一条不满足，不要静默凑合。**
用户坚持要用时，明确告知「口型/相似度风险高」，并在交付清单里记录。

### 1.3 这张图是唯一人物锚点

- 出片时**不允许**模型重绘脸、美化皮肤、换装、换发型；
- 提示词里用 `@图片1` 指代，并在 ② 段逐项锁死；
- **只有用户没传图**时，才走第四节生成一张。

## 二、音频校验与切分（只切，不改速）

### 2.1 合格标准

| 项 | 要求 |
|---|---|
| 速度 | **不改**——音频多少速度就多少速度（永不 atempo） |
| 内容 | 有清晰说唱人声，**不是纯伴奏** |
| 起止 | 首字 `start` → 末字 `end`（+0.5~0.8s 尾音） |
| 水印 | 尾部不能有「AI 生成」类语音水印（落在末字**之后**可忽略） |
| 格式 | mp3 / wav / m4a；切完转 wav / 44.1k / 单声道 |

### 2.2 用 ASR 定三个人声坐标

```python
# faster-whisper ｜ word_timestamps=True ｜ initial_prompt=完整歌词
# 每个词都有 w.start 和 w.end
```

- **首字 `start`** → `--start`
- **每句 `start`** → 时间轴（相对该镜起点，取整）
- **末字 `end`** → `--end` 的基准（再 +0.5~0.8s）

> `silencedetect` 只能告诉你"哪里安静"，分不出"第几句"——要句首时间必须走 ASR。
> **拿句首的 `start` 当结尾，是这个 skill 栽过最惨的坑**：最后一个字被整段切掉，
> 听感就是"突然结束、少几个字"。

### 2.3 切分（脚本没有变速参数）

```bash
# 单镜
python3 scripts/cut_audio.py "00-输入/音频/原声.wav" \
  --start 0.72 --end 31.12 -o "00-输入/音频"

# 超 30 秒：加句间切点，一次出 S01/S02
python3 scripts/cut_audio.py "00-输入/音频/原声.wav" \
  --start 0.72 --end 31.12 --split-at 15.54 -o "00-输入/音频"
```

脚本会自校验「切片与原声对应位置逐字节一致」，不一致直接报错（防止被偷偷改速）。

**原则：**

1. `--start` 取首字 `start`——前面是伴奏，切掉不丢字；
2. `--end` 取末字 **`end`** + 0.5~0.8s——**不要用 `start`**；
3. 末段自动 0.30s 淡出，避免裁在鼓点上的硬切感；
4. 尾部水印若在末字之后，本来就被 `--end` 切掉，不用管。

### 2.4 时长怎么办

| 情况 | 处理 |
|---|---|
| ≤30s | 1–2 镜，按信息段拆；`seconds` = 人声长度（可小数） |
| 30–60s | 40s 拆 **3–4 镜**，每镜 8–12s；按信息段，不按秒数硬切 |
| 60–90s | 建议压到 40s 或拆项目；不硬塞 4 镜 |
| 远超 90s | 拆项目或精简歌词 |

**永远不为凑 30 秒提速或切字。** 语速（字/秒）只记录不优化；密度高导致糊嘴就改词。

### 4.1 写 `文生图提示词.json`

放在**项目根目录**（与 `04-图片/` 同级）：

```json
{
  "style": "重彩水墨轻鎏金",
  "ratio": "9:16",
  "rows": [
    {
      "id": "ref_人物",
      "kind": "",
      "size": "1024x1536",
      "prompt": "<固定节 + 主体节>"
    }
  ]
}
```

`prompt` 按 `风格-重彩水墨轻鎏金.md` 组装，至少包含：

- 主体：人物性别呈现、年龄感、发型、服装、配饰、姿态；
- 场景：与用户描述匹配的东方写意空间；
- 构图：半身近景、**正面平视**、居中偏上；
- 嘴部：完整可见、自然微张（为后续开口说唱做准备）；
- 固定风格句＋负向。

### 4.2 出图


- 默认**一次一张**；不满意让用户说「改发型/改服装/改背景/换气质」，改 prompt 再出。
- 产物：`04-图片/ref_人物.png`。
- 如果接口不可用，脚本会写 `04-图片/generate_image参数.json` 并退出 6；此时按清单走工具出图，出完用 `--adopt` 收位：

## 五、上传外网（硬门：图 + 音频）

### 5.1 命令（⑥ 站：JSON 还没写）

```bash
python3 scripts/upload_project.py assets/output/MV01-xiaoyu --verify --with-line-audio
```

- 命名空间＝**项目文件夹名**（`MV01-xiaoyu`）；
- 必须带 `--with-line-audio`，否则脚本只传图；音频靠 JSON 里的 `ref_audio_urls` 收集，所以**上传前要有一个占位 JSON**；
- 成功后会保存清单到 `03-上传/素材外网路径.json`；
- `--verify` 上传后 HEAD 核验，**图和音频都要 200**。

### 5.2 写完 JSON 后回填（⑦ 站）

```bash
python3 scripts/upload_project.py assets/output/MV01-xiaoyu --fill-only
python3 scripts/upload_project.py assets/output/MV01-xiaoyu --verify-json
```

- `--fill-only` 只读 `03-上传/素材外网路径.json`，把直链回填进 JSON，**不重传**；
- `--verify-json` 要求：`HEAD N 条 · ❌ 0 条`。

### 5.3 直链形状

```
https://your-static-host.example.com/public/mv/MV01-xiaoyu/04-图片/ref_人物.png
https://your-static-host.example.com/public/mv/MV01-xiaoyu/00-输入/音频/S01.wav
```

中文路径会百分号编码；JSON 里保留编码后的完整 URL。

### 5.4 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `[FAIL] 目标根不存在：/var/www/public/mv` | 本机没有站点目录 | 到服务器/容器跑；或 `--dest` 指向可写目录、`--url-base` 指向对应外链根；**不要假装成功** |
| HEAD 404 | 命名空间/路径不一致 | 确认命名空间＝项目文件夹名；路径大小写、中文编码 |
| 回填后 JSON 还是本地路径 | 清单文件名对不上 | 检查 `--fill-json` 是否执行、文件名是否与 JSON 一致 |
| **只传了音频，图片全 404** | 上传器 `overwrite_dir:true` **先删整目录再写** | 要么整项目一起传，要么加 `--no-overwrite-dir`，要么直接 `cp/scp` 到服务器目标子目录 |
| 同名文件多个外链 | 多次上传遗留 | 脚本会告警并保留先出现的；必要时清目标目录重传 |

### 5.5 上传门纪律

- 图或音频任一没拿到 HEAD 200 → **停在 ⑥**，不进入 ⑦，更不进入出片；
- 不允许「先出片、后补链」；
- 不允许把本地绝对路径直接塞进 `refs_urls` / `ref_audio_urls` 当直链。

## 六、素材门 / 音频门 / 上传门检查清单
