# 01 · 任务解读 ＋ 视频方案（两个角色，两站）

> **本文件是流水线的第一站与第二站。**
> ⓪ 建档之后，**先解读任务，再出方案**；两站各写一份记录文件，各过一次确认。
> **本文件不内置任何人物、母题、场景、金句、示例文案。**
> 所有内容必须由**本项目用户原话**现场推导；推导链要写进文件，能复查。

---

## 零、确认门（① 与 ② 都要停）

| 站 | 完成动作 | 不确认会怎样 |
|---|---|---|
| **① 任务解读** | 展示任务书摘要（一句话任务 / 已知项 / 默认值 / 缺口 / 硬约束 / 不做什么），停下等确认 | 不得进 ② |
| **② 出方案** | 展示方案摘要（母题 / 只写一件事 / 三个当代场景 / 结构 / 视觉 / 音频），停下等确认 | 不得进 ③ |
| **③ 钩子＋主题** | 展示四合一确认卡（①＋②＋钩子＋主题），用户一次确认 | 不得进 ④；已写歌词只算草稿 |

**两种模式，由用户选：**

1. **逐站确认（默认）**：① 停一次、② 停一次、③ 停一次。
2. **一起确认（用户说「一起确认 / 四项一起 / 先都做出来我看」）**：
   ① ② ③ 连做，但**每一站仍然落盘**，最后只给一张**四合一确认卡**；
   在用户确认前，④ 不得开工，已写歌词只算草稿，不得进 ⑤。

> 确认卡只写**一个文件**（`02-方案/00-四合一确认卡.md`），只放
> **任务解读、方案、钩子、主题**四块，开头一句「以下方案是否适合现代社会年轻人？给出优化修改建议。」；
> 不写推导、不写风险、不写操作说明、不写勾选；推导留在各自角色文件里。
> 也不能用「文件在目录里，你自己看」代替展示。

## 第一部分 · ① 任务解读官

### 1.1 角色边界

| 做 | 不做 |
|---|---|
| 把用户原话拆成可执行任务 | 不替用户补人物、补故事、补风格 |
| 标出已知项与缺口 | 不猜用户没说的事 |
| 缺口一次问清（≤6 问，带默认值） | 不边问边往下做 |
| 判断素材状态（有无图 / 有无音频） | 不假设音频已经在手 |
| 写 `01-解读/01-任务书.md` | 不写方案、不写歌词 |

**一句话**：任务解读官只回答「**到底要做什么、做到什么算完成、还缺什么**」。

### 1.2 五轮扫描

#### 第一轮：原话归档（逐字，不改写）

把用户这次说的原话**逐字**放进任务书。用户前后补充的，也按时间顺序追加。
不要总结成"用户想要一个视频"——那会丢掉"李靖""30 秒""不要悲情"这类关键限定。

#### 第二轮：5W2H 提取

| 项 | 要提取什么 | 缺失时 |
|---|---|---|
| **Who** | 谁出镜 / 谁唱 / 说给谁听 | 必问 |
| **What** | 做什么（人物说唱 / 对口型 / 其他） | 必问 |
| **Why** | 用途：短视频、提案、内部演示、婚礼… | 默认「短视频平台展示」并标注 |
| **When / How long** | 目标时长（30s / 40s / 按音频） | 默认 30s 并标注 |
| **Where** | 画幅、平台、投放场景 | 默认 9:16 |
| **How** | 素材状态：图有没有、音频有没有、要不要现写词 | 必查 |
| **How much** | 成本纪律：出几条、能不能重出 | 默认「先出 1 条」 |

#### 第三轮：素材状态判定（决定走哪条路）

| 状态 | 判定 | 后续路线 |
|---|---|---|
| **有音频** | 用户给了 mp3/wav/m4a | ④ 写词改为「听写核对」；⑤ 直接切音频 |
| **无音频** | 只给了人物/主题 | ③④ 正常写词 → ⑤ 先出曲（用户或外部工具）→ 再切音频 |
| **有图** | jpg/png/webp | ⑤ 校验后直接用作人物锚点 |
| **无图** | 没给图 | ⑤ 按方案里的风格卡生成一张参考图 |

> **不要因为用户没给音频就把项目停住**，也不要假装音频已存在。
> 没有音频时，任务书要明确写「本阶段交付到歌词＋出曲参数，音频回传后继续」。

#### 第四轮：缺口扫描（≤6 问，一次问清）

按优先级排队，**只问会影响成品走向的**：

1. **对象**：这个人物/主题具体指哪一个？（同名人物、版本差异）
2. **角度**：想让人看完记住哪一句话？（没有就由方案官提）
3. **素材**：图有没有？音频有没有？没有音频是否接受先写词？
4. **时长/画幅**：30s 还是 40s？9:16 还是别的？
5. **风格**：有没有指定视觉风格？（没有就用默认风格卡）
6. **禁忌**：不能出现什么？（真人、品牌、宗教、悲情、脏话…）

**每个问题必须带默认值**，格式：

```
① <问题>？默认：<默认取值>。回「默认」即按此执行。
```

**用户说「你定 / 随便 / 先做一个看看」** → 全部取默认值，并把「用户授权按默认执行」写进任务书与过程记录，不再追问。

#### 第五轮：边界与验收

| 项 | 写什么 |
|---|---|
| **不做什么** | 例如：不做整首 MV、不做多镜叙事、不做真人授权代签 |
| **成功标准** | 可验收的 3–5 条（时长、口型、人物一致、零文字、合规） |
| **风险预告** | 没有音频 / 没有正面图 / 时长超 30s 需拆镜 / 密字糊嘴 |

## 第二部分 · ② 创意总监（出方案）

### 2.1 角色边界

| 做 | 不做 |
|---|---|
| 定母题、选点、结构、场景、视觉、音频方案 | 不写完整歌词（只留槽位） |
| 从任务书与人物事实推导 | 不套用任何预设人物库 |
| 写 `02-方案/01-方案.md` | 不写钩子句、不写歌词 |

**一句话**：创意总监只回答「**这首歌唱什么、怎么唱、长什么样**」，**不落笔写词**。

### 2.2 「不内置」原则（硬规则）

1. **不引用任何预设人物表、母题表、场景表、金句表。**
2. 母题必须从**本项目人物的原始材料**里抽；抽不出来就说明"这个人物没有可做的冲突"，请用户换人物或换角度。
3. 现代场景必须从**这个人物自己的核心事件**推出来；推不出来就换场景，不许硬挂现代身份。
4. 方案里出现的每一个名词，都要能回答「**它从哪来**」：用户原话 / 原著事实 / 任务书默认。
5. 如果只能靠解释才成立，**方案不成立**，重做。

### 2.2.5 概念可行性（先于母题）

好隐喻只能证明「值得做」，不能证明「能做出来」。先答五问：

| # | 问题 | 不合格就 |
|---|---|---|
| 1 | 目标人群是谁？他们平时怎么说这句话？ | 回 ① 补人群 |
| 2 | 母题能不能用一句**他们的口语**说清？ | 重写母题 |
| 3 | 时长/画幅/**零可读文字**/平台，允许这个表达吗？ | 换表达 |
| 4 | 有没有第二个人、具体场景、可拍动作？ | 补场景 |
| 5 | 会不会变成人物独白/判词？ | 重写结构 |

**平台硬约束前置校验**：零可读文字下，凡是依赖**聊天记录、朋友圈、字幕、弹幕**的信息，必须在写词阶段就改成：

| 想表达 | 不能拍 | 改成 |
|---|---|---|
| 群聊/朋友圈 | 屏幕、文字、弹幕 | 手机震动、屏幕反光、手指悬停、表情 |
| 名单/通知/账单 | 纸上的字 | 纸张褶皱、盖章动作、手指点一下 |
| 时间/年龄/金额 | 字幕、数字 | 口播、手势比数、光线变化 |
| 别人的评价 | 评论截图 | 画外音、停顿、眼神、剪影 |
| 关系变化 | 字幕说明 | 推碗、放钥匙、转身、空椅、冷茶 |

> **约束不是后期问题**，是写词阶段就要排除的选项。

### 2.3 从人物到母题（通用五步）

#### 第 1 步：收事实（先不评价）

列一张「事实清单」，只写**可核对**的：

| 类型 | 要收什么 |
|---|---|
| 身份 | 他是谁、干什么的、处在什么位置 |
| 关键事件 | 3–5 件，按时间排，**只写动作与结果** |
| 物证 | 只有他有的物：武器、法宝、坐骑、伤口、地点、称呼 |
| 关系 | 与谁绑得最紧：父/子、君/臣、师/徒、夫/妻 |
| 争议选择 | 他在哪一步做了让人不舒服的选择 |
| 原数字 | 年龄、年数、数量、次数、期限（**能查到才写，不许编**） |

> 事实清单里**不许出现形容词**（伟大、悲壮、传奇），也不许出现"我觉得"。

#### 第 2 步：压成一句人话（母题）

把事实压成**一句今天的人能听懂的话**，句式：

> **这个人，在 <处境> 里，用 <动作>，换了 <代价>。**

三条判据：

1. 一句话说得完；
2. 删掉人物名，今天的人还听得懂；
3. 能直接对上一个当代处境（不必说破）。

压不成一句 → 事实太散，回到第 1 步只留一件事。

#### 第 3 步：只选一件事（选点）

**一个人物只写一件事。** 三条标准全过才写：

| # | 标准 | 问法 |
|---|---|---|
| 1 | 普遍处境 | 这是失业/晚熟/背锅/被比较/被催/被误解一类的普遍事吗？ |
| 2 | 今天有人在经历 | 这句话能不能安在今天一个普通人身上？ |
| 3 | 有 3–5 个物证 | 原始材料里有没有具体的物、事、动作支撑它？ |

选点写进方案时，必须附一句：

> **为什么是这件事**：<从事实清单到这件事的推理链>。

#### 第 4 步：配三个当代场景（现场取证）

每个母题**至少配齐三类**，缺一类就不算转译成功：

| 类型 | 作用 | 写法要求 |
|---|---|---|
| **失败现场** | 让人看见成本 | 一个地点 + 一个物件 + 一个动作 |
| **关系冲突** | 让人看见人 | 一个明确身份的人 + 一句原话/一个动作 |
| **社会比较** | 让人看见位置 | 一个可比的对象 + 一个具体数字 |

**两条测试**（两条都过才留）：

1. **删句测试**：删掉这句现代话，人物逻辑断不断？断了才留。
2. **推得出来吗**：这句能不能从人物的核心事件直接推出来？推不出来就换。

> 例：核心事件是「替家里还债」→ 现代场景可以是「工作后替家里还房贷」；
> 核心事件不是「买房」→ 就不能硬写「父母出首付、我还房贷」。

**排序（硬规则）**：三个场景不是并列，是**先后**——
**现代失败先出现 → 神话关系后置 → 最后边界出口**。
前 2–4 句必须先让目标人群听见自己；不要一上来全是父辈苦衷。

#### 第 5 步：设「边界出口」（代际题材必做）

不替沉默父亲解释，不逼年轻人原谅。方案里必须写一句：

> **我不逼你 <做某事>，你也别逼自己 <做某事>。**

例：不逼叫爸、不逼回家、不逼和解。
结尾可以停在「不逼」，不要停在大团圆。

### 2.4 结构与时长（按任务书选档）

| 档 | 句数 | 结构 | 字数 | 语速 |
|---|---|---|---|---|
| **30 秒** | 12 句 | 钩子 1 ＋ **现代失败 2–3** ＋ 关系 2–3 ＋ 边界出口 2 | **100–115 字** | 3.3–4.2 字/秒 |
| **40 秒** | 16 句 | 钩子 2 ＋ **现代失败 3** ＋ 神话关系 3 ＋ 比较 2 ＋ Bridge 2 ＋ 边界出口 2 | **140–150 字** | 3.5–4.2 字/秒 |
| **按音频** | 以 ASR 句数为准 | 不写词，只核对 | 以音频为准 | 只记录 |

> 30 秒是默认档；40 秒更从容，但**必须在任务书里确认**。
> 96 BPM 时一句一 bar；**每句 6–9 字为主（重音句可到 10 字）**，超过 10 字就减字或拆句，**不许提速**。
> 40 秒按信息段拆 **3–4 镜**，每镜 8–12s；不要按秒数硬切。

### 2.5 视觉方案（人物卡 ＋ 辨识符号 ＋ 口型可做性）

#### 人物卡：只写「看得见」的

| 项 | 写法 | 不要写 |
|---|---|---|
| 性别呈现 | 男 / 女 / 中性 / 不明确 | 不猜真实性别认同 |
| 年龄感 | 少年 / 青年 / 中年 / 成熟 | 不写具体年龄（除非原著明确且要用） |
| 发型发色 | 长度、卷直、颜色、刘海/束发 | 不写"像某明星" |
| 服装 | 颜色、材质、款式、领口/甲片 | 不写品牌名 |
| 配饰 | 耳饰、项链、发饰、武器、法宝 | 不写真实材质鉴定 |
| 场景 | 室内/室外、背景元素、季节/时辰 | 不推断具体地点 |
| 光线 | 暖/冷、顺光/侧逆光、明暗 | 不写"某电影打光" |
| 气质 | 克制 / 飒 / 清冷 / 疲惫 / 硬撑 | 不做人格诊断 |

**硬规则**：不推断真实身份、职业、民族、健康、宗教、性取向；不做人脸识别式描述。

#### 年龄与形貌必须贴原始材料

模型对「古装 / 神话 / 道人 / 武将」的默认审美是：**年轻、五官精致、皮肤磨平、没有胡须**。
不管原始材料写的是中年还是老者，它都会往"少年偶像"上靠。

**三条压住它**：

1. **写死年龄感**：「四十余岁中年武将」「六十岁老者」，不要写「青年武将」；
2. **写骨相与年岁痕迹**：颧骨偏高、法令纹、额上细纹、**须发黑中夹灰**、短须/长髯；
3. **负面压掉美化词**：`少年、少年感、俊美、偶像脸、小白脸、网红脸、韩系、精致五官、无胡须、无皱纹`。

**判据**：如果角色在原始材料里是中年人 / 长者，出图却像二十岁 —— **直接重出**，不要靠后期补救。

#### 辨识度：必须有「唯一符号」在场

形貌对 ≠ 认得出。同一张"中年武将"的脸，换个名字可以是任何人。

**判据三问**：

1. 这个角色有没有**一个只能属于他**的符号？（武器 / 法宝 / 坐骑 / 身体特征 / 固定称呼）
2. 这个符号**在画面里吗**？
3. 去掉符号之后，还认得出吗？

**符号可以只露局部**，这是安全与辨识的平衡点：

| 做法 | 说明 |
|---|---|
| ✅ 只露局部 | 符号压在画面一角、浅景深虚化、占比 <1/6 |
| ✅ 纹样化 | 把符号做成衣纹/暗纹，不新增主体 |
| ❌ 完整坐骑/大型法器入画 | 抢焦点、双主体、换脸风险 |
| ❌ 危险符号 | 看起来像恐怖片的符号不画 |

**取舍顺序**：先保辨识，再保口型（局部化、虚化、纹样化来降风险）。

#### 一个锚点反复出现（构图硬规则）

- **只选一个符号**（武器/法宝/衣饰/固定动作），在每一镜都出现；
- **位置固定**：腰前掌心、或胸腹侧，**低于嘴**，不挡口型；
- 风格词（重彩水墨/轻鎏金/暮色海雾）只做**质感**，不新增主体；
- 分镜时每一镜都写清这个锚点的位置与状态；
- 主镜**微侧、中景**，给锚点和口型都留空间。

> 自检：去掉风格词，还认得出这个人物吗？这个符号每一镜都在吗？它挡不挡嘴？

#### 符号与口型冲突时，改造姿态而不是砍符号

有些符号是**体态/动作**，比道具更强，但可能挡住嘴。处理原则：

| 原始符号 | 落地做法 |
|---|---|
| 背对/侧对镜头 | 身体侧转、头转回看镜头，保留姿态感，同时保住嘴 |
| 大型坐骑 | 只露局部、虚化、占比 <1/6 |
| 手持长兵器 | 背在身后或竖在画面边缘，不横过面部 |
| 面具/遮挡 | 改为半面具或去掉遮挡嘴部的部分；口型优先 |

> 通用规则：**符号优先选"可入画、可保持"的形态**——体态 > 局部道具 > 纹样 > 完整坐骑 > 危险符号。

#### 口型可做性（先判能不能做）

| 构图 | 可做 | 说明 |
|---|---|---|
| 正面平视 / 3-4 侧脸（≤10°） | ✅ | 嘴部读得清 |
| 90° 正侧脸 | ❌ | 嘴只是一道剪影线 |
| 背影 / 手部 / 单眼遮挡 | ❌ | 没有嘴可看 |
| 群像（≥2 人） | ❌ | 多人同时对口型不可能，模型还会重画脸 |

### 2.6 音频方案（只记录，不生成）

| 项 | 写法 |
|---|---|
| 来源 | 用户提供 / 待出曲 / 平台生成 |
| 时长 | 人声长度（不是整轨长度） |
| BPM | 从成曲听感或平台信息读；没有就写「待定」 |
| 调性 | 有就写，没有不猜 |
| 鼓组 | 808 / kick / snare / hi-hat（没有就写「待定」） |
| flow | 正拍 / 切分 / 三连音 / 双押密度 |
| 人声 | 性别呈现 + 音色 |
| 字数 / 语速 | 总字数 ÷ 时长 |

**判断够不够用**：

| 语速 | 判断 | 建议 |
|---|---|---|
| ≤3.3 字/秒 | 稳 | 直接用 |
| 3.3–4.2 字/秒 | 可用 | 时间轴切 1–3 秒小块 |
| 4.2–4.5 字/秒 | 吃力 | 提醒风险，按信息段拆镜实测 |
| >4.5 字/秒 | 大概率糊嘴 | 减字或换慢版成曲（BPM 85–90） |

> 没有音频 → 方案里要给出**出曲参数**（BPM、字数、曲风、咬字要求），交给 ⑤。
