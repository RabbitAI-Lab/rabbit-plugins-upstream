# 07 · 排障与质检

> **先记住本 skill 的机制**：口型由**参考音频**驱动，声音不生成、也不进片（成片音轨就是那条 30s 音频）。
> 所以排障顺序是：**音频有没有传 → 时长对不对 → 首声位置 → 时间轴块大小 → 构图**。
> 不要拿「唱歌版/自己生成声音」那套（调音色、调曲风、加 BPM）来修口型问题——那是另一个 skill 的路子。
> **先查音频来源**：必须是用户本次提供或按 ④ 海绵音乐提示词出曲后回传；
> 无音频项目只停在 ④，不得存在时间轴、提示词、成片；发现旧项目音频一律删除并返工。

## 一、故障表（按性价比排序）

| 现象 | 最可能原因 | 处理顺序 |
|---|---|---|
| **完全不动嘴** | ① JSON 里 `ref_audio_urls` 空 / 多于 1 条；② 请求体没有 `audio_url` 块；③ `generate_audio` 被写成 true | ① 查 JSON；② `--dry-run` 看 content 里有没有 `audio_url`；③ 改回 false 重出 |
| **嘴动但整体早/晚** | 时间轴第一块起点没对齐音频真实首声 | 用 `silencedetect` 量首声，把第一块起点挪到那个整数秒；重出 |
| **节奏对、字不对** | 歌词没引号 / 一块塞太多字 | 补双引号；拆成 1–4 秒小块（每块 ≤4 字）；重出 |
| **后半段越来越飘** | 时间轴末块没收到该镜 `seconds` / 用了提速音频 | 末块 `end` 改成该镜 `seconds`；音频用 `cut_audio.py` 原速重切 |
| **糊嘴 / 双嘴 / 吞字** | 30 秒密字是这套模型最难档，抽卡 | 先重出同一条（1 次）；仍糊 → 拆更细；再不行 → 降 BPM 换慢版成曲 |
| **唱成旋律腔** | 提示词写的是「唱」不是「说」；⑤ 写了曲风音色 | ①③ 改「说唱/Rap」；⑤ 删掉音色配器；负面加「旋律唱腔」 |
| **像念白/朗读** | 同理，缺 beat 感 | ①③ 加「有 beat、有 flow、踩拍」；负面加「念白、朗读」 |
| **让道具互动后人物变形/换脸** | 要求的动作让模型重绘了身体或凭空造物 | 只做「已有道具」的互动（绫/圈）；新道具（枪/轮/六臂）一律写进负面 |
| **道具互动时手挡嘴、口型崩** | 手部动作越过了下巴 | 写死「互动只在胸前到腰侧、不高于下巴、不经过面部」 |
| **镜头死板，全程一动不动，看着累** | ④ 只写了「机位固定/不推拉」 | 改成「每 2 拍极轻推开/回拉（<2%）、重拍顿一下」；口型镜可只在开场 0–3s 快速推近到半身，之后锁景别 |
| **运镜之后口型变差、脸变形** | 推近幅度过大，或推到位还继续推 | 幅度压到 <2%；推到位立刻锁死景别；不要边推边唱长句 |
| **背景完全不动，像一张会说话的画** | ④ 只写了人物，没写环境层 | 补「本场景环境元素流动 / 轻摇 / 光屑飘 / 侧光缓慢推移」；负面加「背景静止不动、画面死板」 |
| **人物自带饰品、发丝全程静止** | ④ 没写饰品层；负面也没禁止静止 | 补「本人物饰品持续飘动/摆荡、发丝摆动」；负面加「饰物静止、布料僵硬」 |
| **画面热闹但没感染力、没有高潮** | 每句都配了动作，平均化 | 只保留 3–5 个「画面事件」（挑有具体名词的句子），其余保持轻动态；收尾留一段几乎静止 |
| **人物太僵硬、只动嘴、像木头人** | ④ 只写了「呼吸 + 小幅点头」，模型最省事的做法就是站桩 | ① 补「每拍肩线下沉 + 4 拍动作单元 + 手势」；② 允许极轻微手持；③ 负面加「身体僵直、木头人、面瘫」；④ 仍僵 → 把机位从「半身近景」放到「半身中景」，给肩臂动作空间 |
| **人物不像 / 换脸感** | ② 人物锁定太泛；**没用用户的图**；推近幅度大 | ① 确认 `refs_urls` 是用户那张；② 逐项写脸型/发型/服装/配饰/背景；③ 降低推近 |
| **画面出现文字/logo/水印** | ⑥ 约束不够 | ⑥ 明确「零可读文字、无 logo、无水印、无二维码」；重出 |
| **出现第二个人/乐器挡脸** | 场景描述太开放 | ⑥ 写「不出现第二个人、不出现乐器遮挡面部」；重出 |
| **人物中途换装/换景** | 镜头/场景描述不稳 | ④ 写「不切镜、不换景、不换装」；② 锁背景关系；重出 |
| **字幕与声音不同步** | `lyrics[]` 与提示词不是同一份时间轴 | 用同一份时间轴生成提示词和 `lyrics[]`；`assemble.py --subtitle` 重生成 |
| **2 镜拼接处人物变了** | 两镜参考图/风格句不一致，或模型抽卡 | ① 确认两镜 `refs_urls` 是同一张图、②⑥ 段逐字一致；② 只重出跳变的那一镜 |
| **成片比 Σ seconds 长/短** | 逐镜裁秒失败，或 `--merge` 用了未裁的片段 | 重新出片（`--enforce-seconds` 默认开），再 `--merge` → `assemble` |
| **字幕第二段整体偏移** | 字幕用了相对秒而没加偏移 | 用 `assemble.py --subtitle` 生成（会自动累加）；不要手工拼 srt |
| **上传 404** | 命名空间/路径不一致；中文未编码 | 命名空间＝项目文件夹名；重跑 `--verify --fill-json`；图**和**音频都要 200 |
| **只传了音频，图片全挂** | 上传器 `overwrite_dir:true` 先删整目录 | 整项目一起传 / `--no-overwrite-dir` / 直接 `cp` 到目标子目录 |
| **成片时长差 >0.3s** | 裁补失败 | `assemble.py` 重跑；检查 ffmpeg；仍不行重出 |
| **成片没音轨** | 参考音频没进成片 | `assemble.py` 会把音频贴回成片；检查音频是否上传成功 |

> 排障原则：**一次只改一个变量**，改完重出 1 条；不要一次改五处，否则不知道哪处生效。

## 二、三步降级（30 秒密字确实难）

按顺序，**每步只改一件事**：

1. **拆时间轴**：把所有块压到 1–3 秒、每块 ≤3 字；
2. **换慢版成曲**：BPM 降到 85–90，字数降到 100 以内（3.3 字/秒）；
3. **换路**：仍糊嘴 → 如实告知用户，改走 `mv-concert`（另行提供）（多镜分片，每片更短，口型压力小）。

**不要靠反复抽卡硬碰**——30 秒密字是模型上限附近，抽卡救不回来。

## 三、QA 清单

### 多镜专项检查

- [ ] `shots` **1–4 条**；30s 1–2 镜；40s **3–4 镜**
- [ ] 每镜 `seconds ≤ 30`、`duration = ceil(seconds)`
- [ ] 40s 每镜 **8–12s**；切点落在**信息段之间**（不切词）
- [ ] 后一镜起点 = 前一镜终点，拼回去＝完整人声
- [ ] 多镜用**同一张参考图**、② 与 ⑥ 段逐字一致
- [ ] `成片片段/SXX.mp4` 逐镜存在且 ≈ 该镜 seconds
- [ ] `06-MV成片_无音轨.mp4` 存在（多镜 `--merge` 产物）
- [ ] `06-MV成片.mp4` 时长 ≈ Σ seconds、**有音轨**
- [ ] `06-歌词字幕.srt` 条数 = 各镜歌词之和、偏移正确
- [ ] 人工：拼接处**人物/光线/背景不跳**

### 机械检查（`qa.py`）

```bash
python3 scripts/qa.py assets/output/MV01-xxx --require-clip --verify-links
```

- [ ] `shots` **1–4 条**
- [ ] 每镜 `seconds ≤ 30`、`duration = ceil(seconds)`
- [ ] `ratio` 合法
- [ ] `generate_audio: false`
- [ ] 每镜 `ref_audio_urls` **恰 1 条**，是绝对直链
- [ ] 六段式标题齐全
- [ ] 含「说唱/Rap」，不含「念白/朗读」当正向要求
- [ ] 每句歌词都在 prompt 里、带双引号
- [ ] 时间轴**整数秒**、首尾相接、**末块 = 该镜 seconds**（不是固定 30）
- [ ] `lyrics[]` 与 prompt 时间轴一致
- [ ] `refs_urls` 全部绝对直链，HEAD 200
- [ ] 成片存在、时长 ≈ Σ seconds（±0.35s）、有音轨

### 公共经验检查（10 条）

- [ ] 概念能用**目标人群的口语**一句话说清，不是父辈独白
- [ ] 前 2–4 句是**现代失败**，不是一上来全是古代苦衷
- [ ] 字秒比按口型打折：30s 100–115 字 / 40s 140–150 字；每句 6–9 字为主
- [ ] 钩子是「物 + 关系 + 落空」，无血腥/剔骨/还骨头直写
- [ ] 有「不逼原谅」的出口（不逼叫爸/不逼回家/不逼和解）
- [ ] 零文字信息都有声/光/动作替代（无聊天记录/字幕/弹幕）
- [ ] 40s 按信息段拆 3–4 镜，每镜 8–12s
- [ ] 视觉锚点每镜都在、低于嘴、不挡口型
- [ ] 主镜微侧、中景
- [ ] 情绪保留，但审判性画面换成了承认性口播

### 人工检查（三帧法）

**抽三帧看嘴**：开头（起势后第一句）、中间（第 4–5 句）、结尾（收尾句）。

- [ ] 第一句开口时机与声音对得上（不早不晚）
- [ ] 逐字有开合，不吞字、不连读成一片
- [ ] 抽的 3 帧里，嘴部都清晰、无遮挡、无糊嘴/双嘴
- [ ] 人物与参考图一致（脸、发型、服装、配饰）
- [ ] 背景/服装全程没换
- [ ] 没有第二个人、没有乐器挡嘴
- [ ] 没有文字/logo/水印/二维码
- [ ] 没有畸形手指、五官扭曲、闪烁跳帧
- [ ] 视觉锚点（塔/法宝/饰品）低于嘴、不挡口型
- [ ] 没有血腥/剔骨/伤口/骨头特写
- [ ] 零文字信息用声音/震动/反光/手势/剪影/口播替代
- [ ] 结尾有「不逼原谅」的出口，不是强行大团圆
- [ ] 情绪与用户描述一致，不审判、不说教

### 合规检查

- [ ] 真人图片：本人/已授权/AI 生成，有留证或用户确认
- [ ] 不影射在世真人、明星、IP、品牌
- [ ] 未成年人：健康、无成人化表达
- [ ] 音频来源合法，且是**本次用户提供/回传**（不是从旧项目复制的）
- [ ] 无音频项目：只交歌词＋出曲参数＋海绵音乐提示词，没有时间轴/提示词/成片
- [ ] 无政治/宗教/医疗/金融承诺/低俗/暴力/自伤
- [ ] 交付提示「AI 生成内容」

## 五、返工口径

- **只改时间轴** → 回 ⑦，改 `02-方案/04-时间轴.md`，同步改 prompt ③ 与 `lyrics[]`，重出。
- **只改风格/画面** → 改 ⑥，重出。
- **换图** → 回 ⑤（新图必须正面、嘴部可见），重新上传，② 全部重做。
- **换音频** → 回 ⑤（重新收音频并按 ASR 原速切），重新上传，⑦ 时间轴全部重做。
- **人物不像** → 先确认是不是用了用户的图，再加强 ②，**不要先改风格**。
- 每次返工都更新 `00-项目状态.md` 的「用户最近意见」。
