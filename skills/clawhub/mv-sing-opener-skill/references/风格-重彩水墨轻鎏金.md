# 风格卡 · 重彩水墨·轻鎏金

> 本卡标 ★固定节 的字段**必须逐字照抄**进提示词，不许改写、不许同义替换。
> **只在两种情况下使用**：① 用户没给图片，需要生成人物参考图；② 用户明确要求换成本风格。
> 用户给了图就用原图，不要擅自把真人重绘成水墨。

## 一、风格定位

| 项 | 内容 |
|---|---|
| **风格 ID** | `重彩水墨轻鎏金` |
| **一句话定位** | 工笔重彩的东方人物，矿物颜料为骨，局部金箔金线点睛，像一幅会呼吸的绢本肖像 |
| **媒介本质** | 重彩水墨/岩彩（矿物颜料、金箔、工笔重彩写意墨骨、绢本宣纸肌理）；**非**纯水墨、**非**扁平插画、**非**3D |
| **与最近似风格的区别** | 与「彩色水墨」不同：本档**矿物颜料更重、金只做局部点睛**；与「国潮厚涂」不同：保留**水墨墨骨与宣纸肌理**，不塑料 |
| **电影级从哪来** | ① 半身正面平视机位 ② 柔和侧逆光＋暖金轮廓 ③ 面部受光均匀 ④ 背景留白/淡墨层次 |

## 二、★固定节（逐字照抄）

```
【风格】重彩水墨·轻鎏金：工笔重彩写意墨骨；矿物颜料石青、石绿、朱砂、蛤白为骨；
局部金箔与金线勾边，金只做点睛、不铺满画面；宣纸/绢本肌理、岩彩颗粒；东方写意；不引其它风格
【光影】柔和侧逆光＋暖金轮廓光；面部受光均匀，嘴部无阴影；低对比、通透；金箔微闪
【色彩】重彩但不艳俗：石青石绿为主，朱砂提气，暖金点缀；背景留白或淡墨晕染
【影像质感】岩彩颗粒、宣纸纤维、金箔微闪、工笔重彩；超细节；非纯水墨、非扁平插画、非3D
【背景】东方写意空间：淡墨山水/庭院/云气/花枝/窗棂；简洁不抢人；无可读文字
【构图】半身近景、正面平视、人物居中偏上；嘴部完整可见、自然微张
```

**命门词**：「**矿物颜料石青石绿朱砂蛤白**」「**金只做点睛、不铺满**」「**宣纸/绢本肌理、岩彩颗粒**」逐字不动。

## 四、逐图可变节（每次重写）

### 4.1 【主体】

按用户描述写，但必须包含：

- 性别呈现、年龄感；
- 发型/发色；
- 服装颜色/材质/款式；
- 配饰；
- 姿态：正面站立或端坐，肩颈放松，双手自然下垂或不入镜；
- **嘴部：完整可见、自然微张**（为后续开口说唱做准备）；
- 神情：与用户描述的情绪一致（温柔/清冷/坚定/明亮）。

示例句式：

```
【主体】一位<年龄感><性别呈现>，<发型发色>，身穿<颜色/材质/款式>，佩戴<配饰>；
正面站立，肩颈放松，双手自然下垂不入镜；面部朝向镜头，嘴部完整可见、自然微张；
神情<情绪>；东方人物五官，工笔重彩刻画。
```

### 4.2 【次要元素·近/中/远】

- 近：衣料纹理、发丝、金线勾边、淡淡墨韵；
- 中：人物主体；
- 远：淡墨山水/庭院/云气/花枝/窗棂；
- 空层写“无”。

### 4.3 【全局】

- 金箔微闪、墨色晕染、少量浮尘/花瓣；
- 不要满屏粒子、不要强光斑。

### 4.4 【构图】

- 半身近景、正面平视、人物居中偏上；
- 头顶留少量空间；
- 嘴部不被衣领、头发、手遮挡；
- **不写焦距/景深**（容易把画面写成摄影）。

## 七、易翻车点

| 翻车 | 原因 | 修法 |
|---|---|---|
| 画成纯水墨/黑白 | 负向没写或正向没强调矿物颜料 | 固定节保留“矿物颜料石青石绿朱砂蛤白”；负向加“纯水墨/黑白/淡彩” |
| 满屏金光、土豪金 | “鎏金”被放大 | 固定节写“金只做点睛、不铺满”；负向加“土豪金/满屏金光” |
| 变成 3D/CG 塑料感 | 模型默认审美 | 正向写“岩彩颗粒、宣纸纤维、工笔重彩”；负向加“3D/CG/塑料感” |
| 嘴被遮/侧脸 | 构图没锁 | 【主体】【构图】都写“嘴部完整可见、正面平视” |
| 出现文字/边框 | 模型自由发挥 | 负向加“文字/logo/水印/二维码/字幕/边框” |
| 人物太像某明星 | 描述里带真人参照 | 不写明星名；用“东方人物五官、虚构人物” |
| 服装/背景太现代 | 场景没锁 | 【背景】锁“东方写意空间”；负向加“现代街头/霓虹/赛博” |
