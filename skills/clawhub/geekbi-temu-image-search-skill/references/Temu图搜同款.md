# Temu 图搜同款

## 适用范围

用于用户提供商品图、实拍图、供应商图片、网页图片或图片编码后，在 Temu 中查找视觉相似的同款商品，并结合商品经营数据判断这个产品的市场表现、价格带、竞争程度和进入机会。

典型任务包括：

- 上传一张图片查找 Temu 同款。
- 按销量、销售额、价格、上架时间或同款数筛选图片命中的商品。
- 比较同一产品在不同商品、店铺或价格带中的表现。
- 从图片对应的同款市场中筛选热销、低竞争、新品或高评分候选。
- 审核视觉候选并分析返回商品的销量、价格、评分、上架时间和同款竞争。

## 查询原则

1. 用户提供图片或明确要求以图找同款时，将图片作为主检索依据，不先凭肉眼描述图片并改用关键词搜索。
2. 图搜先形成视觉相似商品候选池，再在候选池中应用站点、关键词、可信类目 ID、销量、销售额、价格、供货价、评分、评论数、库存、同款数、托管模式和时间条件。
3. 用户没有提出业务排序时，保留图片相似度顺序；用户要求热销、低价、新品、低竞争等目标时，使用对应商品字段对候选池重新排序。
4. 图片与筛选条件是交集关系。条件越多，结果越少；只生成回答决策问题所需的最小条件。
5. 每张图片先形成服务端返回的视觉候选池，再叠加站点和商品条件。分析中的命中数与占比都以实际返回的候选范围为边界，不表述为 Temu 全平台全部同款。
6. 图搜没有结果时如实说明当前图片未命中可分析商品，可以建议用户换用主体更清晰、遮挡更少、背景更简单的图片，不用普通关键词结果冒充图搜结果。
7. 图搜同款返回完整的 Temu 商品对象，原样读取接口文档列出的字段。
8. 对返回商品遵守 [Temu 图搜同款接口](Temu图搜同款接口.md) 的金额、币种、库存和同款数口径，并将每个商品标题链接到服务端返回的 `linkUrl`。

## 图片选择建议

- 优先使用商品主体完整、占画面比例较高、清晰且没有大面积文字或拼贴的图片。
- 同一张图中尽量只有一个主要商品；多人、多商品或复杂场景图可能降低匹配准确度。
- 主图、实拍图、供应商图和网页图片都可以使用。无法直接访问远程图片时，先将图片保存到本地再查询。
- 需要比较多张图片时逐张查询并分别保留结果口径，不把多张图片合并为一次搜索。

## 市场分析框架

取得同款商品后，根据用户问题选择以下指标，不机械展示所有字段：

- 市场热度：命中商品数量、总销量、日/周/月销量及增长、销售额。
- 价格结构：站点售价区间、中位价格、供货价区间和价格分层。
- 竞争程度：同款数、商品数、店铺分布、头部商品或头部店铺集中度。
- 生命周期：上架时间、新品占比、近期增长和老品稳定性。
- 口碑信号：评分和评论数。图搜结果不包含评论文本，不据此推断具体好评、差评或产品改良方向。

图搜命中只证明视觉相似，不自动证明规格、材质、尺寸、功能或供应链完全相同。形成选品结论时将视觉相似与经营数据分开表述；规格差异会影响决策时，将其列为后续需核验事项。

## 输出要求

- 先说明图片搜索的站点、筛选条件、排序、分页范围和实际样本量。
- 用户要求查看全部同款或分析完整市场时，先读取命中总数，再以单页 200 条逐页查询直至覆盖全部命中；只查询部分页面时必须明确为样本，不能把当前页条数当成全部同款数量。
- 商品名称必须写成 `[商品名称](<linkUrl>)`；同一商品在表格、清单或正文再次出现时仍保持可点击。
- 结论至少区分“图像匹配事实”“商品数据事实”和“经营判断”。
- 用户只要求同款列表时直接返回精简结果；用户要求市场分析时再汇总价格、销量、同款竞争、店铺分布和机会风险。
