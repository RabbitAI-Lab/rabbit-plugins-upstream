# 중국 항공권 예약

## 설명

중국 여행을 위한 올인원 여행 동반자. 이 스킬은 외국인 여행자를 위해 5가지 강력한 기능을 제공합니다:

1. **항공권 검색** — 중국행/중국발/중국 내 항공편을 실시간 요금과 스케줄로 검색
2. **호텔 검색** — 실시간 요금, 평점, 예약 링크로 호텔 찾기
3. **관광지 티켓** — 티켓 요금, 영업 시간으로 관광명소 발견
4. **여행 플랜** — 맞춤화된複数日の 여행 계획 생성
5. **여행 조언** — 비자, 결제, 교통, 음식 등에 대한 답변 받기

## 데이터 흐름 및 개인정보 보호

사용자 쿼리는 안전한 프록시 서버(SCF)로 전송되며, 인증 토큰이 주입되어 TripGenie API로 전달됩니다. 프록시는 제휴 링크 생성을 자동으로 처리합니다. 사용자 개인 정보는 저장되거나 기록되지 않습니다. 모든 통신은 HTTPS로 암호화됩니다.

## 사용할 때

- 자국에서 중국 도시로 가는 항공편 찾기
- 중국 도시 간 국내선 검색
- 날짜, 객실 등급, 여행 유형으로 항공권 옵션 비교

키워드: 중국 항공권, 베이징행 비행기, 상하이 항공권, 중국 국내선, 중국 항공료, 비즈니스 클래스, 이코노미

## 실행

### 1단계: 사용자 요청에서 매개변수 추출

| 매개변수 | 설명 | 예시 |
|---------|------|-----|
| origin | 출발 도시/공항 (필수) | "Tokyo" |
| destination | 도착 도시/공항 (필수) | "Beijing" |
| date | 여행 날짜 YYYY-MM-DD (필수) | "2026-08-15" |
| trip_type | "one way" 또는 "round trip" (선택) | "round trip" |
| cabin | 객실 등급 (선택, 기본값: 이코노미) | "business" |

### 2단계: 스크립트 실행

```bash
python scripts/china_travel.py flight "<origin>" "<destination>" "<date>" "[trip_type]" "[cabin]" --locale=ko
```

**중요:** 항상 `--locale=ko` 매개변수를 포함하여 한국어 결과를 받아주세요.

### 3단계: 결과 표시

API는 구조화된 Markdown으로 항공사명, 항공권 번호, 출발/도착 시간, 요금, 예약 링크를 반환합니다. 내용을 직접 사용자에게 표시합니다.

## 예시

**사용자:** "8월 15일에 런던에서 베이징으로 가는 항공편을 찾아줘"
```bash
python scripts/china_travel.py flight "London" "Beijing" "2026-08-15" --locale=ko
```

**사용자:** "뉴욕에서 상하이까지 왕복 비즈니스 클래스"
```bash
python scripts/china_travel.py flight "New York" "Shanghai" "2026-09-01" "round trip" "business" --locale=ko
```

## 기타 사용 가능한 기능

이 스킬은 다음도 지원합니다:
- `hotel` — 중국 호텔 검색 및 예약
- `attraction` — 관광명소 및 티켓 요금 검색
- `itinerary` —複数日の 여행 계획 생성
- `tips` — 여행 조언, 비자, 결제, 교통 팁
