## Known Risks and Mitigations:

Risk: Running an unpinned npm package with the SocialDataX API key exposes the key and its billing permissions to changing package code.

Mitigation: Use a reviewed, pinned package version or preinstalled CLI, and scope the API key to the minimum required access and billing exposure.
