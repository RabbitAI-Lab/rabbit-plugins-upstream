## Description:

Guides an agent through an interactive, 11-step cyclone-landfall story set in Visakhapatnam, with optional reflections and a closing postcard.

This skill is ready for commercial/non-commercial use.

## Publisher:

[liveneon](https://clawhub.ai/user/liveneon)

### License/Terms of Use:

MIT-0

## Use Case:

People use the skill to take part in a guided, fictional cyclone story based in Visakhapatnam. An agent starts and advances the journey, presents its narrative, and can help submit optional reflections or a review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Account setup, optional reflections, and reviews can involve personal information; reviews are public and retained indefinitely according to the service privacy policy.

Mitigation: Use a pseudonymous profile, omit unnecessary personal details, and choose which reflections and reviews to submit.

Risk: The journey uses an API key and may provide suggested actions.

Mitigation: Keep the API key private and follow only server-suggested actions that fit the intended experience.
