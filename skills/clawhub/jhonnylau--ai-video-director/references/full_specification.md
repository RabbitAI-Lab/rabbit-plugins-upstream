# 完整规范文档

> 本文件为《AI视频分镜提示词 Skill V1.0｜DeepSeek/豆包验证版》Word文档的完整规范原文，供需要查阅完整规范时参考。

## 用途

将本文件直接上传给DeepSeek、豆包或其他大模型，要求其遵循文中的Skill规范。然后用测试指令验证：它能否把剧本或一句话创意，转换为带时间轴与镜长的即梦分镜式提示词V2。

## 版本原则

简单与中等复杂度自动处理；复杂与极其复杂内容由创作者人工重写，并依靠剪辑、补镜头与局部修改达到预估质量。

## 使用说明

本文件包含一段可直接交给AI大模型执行的完整Skill提示词。验证时建议保持原文不改，先测试模型是否能稳定遵循结构、时长判断、难度分级与分镜格式。

1. 把本Word文件上传给DeepSeek或豆包。
2. 告诉模型："请完整读取并遵循文件中的Skill规范。"
3. 发送测试指令，例如："我想生成一个女侠大战剑客的视频。"
4. 检查它是否输出：工作模式、难度、建议时长、资产建议、分镜式提示词V2。
5. 再发送一段剧本，检查它是否能判断时长、拆段，并识别复杂内容。

## 合格标准

输出整体达到6分以上，结构可用、时长合理、分镜清楚，能够显著减少人工拆解与提示词编写时间，即可判定该Skill具备实用价值。

## 核心能力边界

| 复杂度 | Skill处理方式 | 预期 |
|---|---|---|
| 简单 | 直接转换或直接创作 | 一次输出可作为生成基础 |
| 中等 | 适当简化后转换 | 生成后需少量修改或剪辑 |
| 复杂 | 标记风险，建议创作者人工重写 | 不承诺一次生成达到剧本要求 |
| 极其复杂 | 不强行转换，由创作者亲自设计 | 依靠拆段、补镜头、局部修改与剪辑完成 |
