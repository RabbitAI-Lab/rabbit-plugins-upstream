# AI视频分镜提示词导演 🎬

将剧本、小说片段、故事梗概或一句话创意，自动转换为适合即梦 / Seedance 等 AI 视频模型使用的分镜式提示词 V2。

## 为什么需要它

AI 视频模型（即梦、Seedance 等）需要结构清晰、动作可执行的提示词，但大多数创作者直接把剧本或一句话丢给模型，结果要么缺乏时间轴、要么动作抽象无法生成。本 Skill 把"编剧 + 分镜师"的工作流固化成可复用的提示词生成规范，产出**可生成、可剪辑、可继续修改**的分镜提示词。

## 它能做什么

- **双模式自动识别**：剧本转换模式 / 一句话创意生成模式
- **关键歧义询问**：遇到会改变分镜、结局、风格的核心歧义时，先问清楚再生成
- **复杂度四级预警**：简单 / 中等 / 复杂 / 极其复杂，不强行生成无法稳定实现的内容
- **自然时长判断**：4—25 秒内根据对白、动作、情绪判断合理时长，禁止默认 25 秒
- **商业广告 / TVC 支持**：自动识别产品、卖点、特写、收尾和 Logo 预留区域
- **分镜式提示词 V2**：固定输出风格限定、简单描述、逐镜头时间轴（景别 / 机位 / 运镜 / 画面内容 / 人物动作 / 台词对白 / 特别强调）
- **动作描述规范**：强制"主体 + 明确动作 + 作用对象 + 产生结果"，拒绝抽象表达
- **负面限定词统一**：所有提示词结尾自动加入"无字幕，不要出现任何文字，无音乐"

## 适用场景

| 场景 | 示例 |
|---|---|
| 动作 / 武打短片 | 女侠大战剑客、屋顶群战（拆段处理） |
| 剧情 / 暧昧对白 | 便利店镜像悬念、客厅对峙 |
| 东方奇幻 | 变身、空间穿越 |
| 商业广告 / TVC | 高端香水、城市跑鞋、护肤品 |

## 安全边界（本 Skill 绝不做什么）

- 不生成视频文件，只产出结构化提示词
- 不擅自补写主角、阵营、胜负、文化体系、结局等核心设定
- 不把极其复杂内容假装一次生成可实现，会诚实提示能力边界
- 不越权要求用户提供品牌战略、人群画像、广告预算等营销方案
- 不生成错误品牌文字，无参考资产时可用无文字包装或虚构外形
