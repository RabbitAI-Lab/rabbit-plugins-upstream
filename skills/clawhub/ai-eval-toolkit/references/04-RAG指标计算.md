# 04 RAG 指标计算

> 适用：RAGAS 四指标的本地简化实现——零依赖版 RAG 评测
> 核对基准日：2026-08

## 1. 四指标实现口径

| 指标 | 简化实现原理 | 输出 |
|---|---|---|
| 忠实度 Faithfulness | 回答关键词在上下文的覆盖率（词重叠） | 0-1 |
| 答案相关性 Answer Relevance | 回答与问题的关键词重叠度 | 0-1 |
| 上下文精度 Context Precision | 上下文中与回答相关句子的占比 | 0-1 |
| 上下文召回 Context Recall | 上下文中覆盖回答关键论断的比例 | 0-1 |

> ⚠️ 简化实现用词重叠近似语义相似，适合快速基线；RAGAS 官方用 LLM 打分，更准（07 模块）。

## 2. 使用方式

```bash
python tools/eval_toolkit.py ragscore --answer "保修期1年" --context "产品文档：保修期1年，含电池" --question "保修期多久"
# → faith=1.0, relevance=0.8, precision=1.0, recall=0.9 等
```

## 3. 指标解读

| 得分 | 含义 | 动作 |
|---|---|---|
| 忠实度 <0.5 | 回答与上下文脱节 | 查生成端（是否没读上下文） |
| 召回 <0.5 | 关键信息没被检索到 | 查检索端（切块/embedding/重排） |
| 精度 <0.5 | 检索结果杂而不准 | 查检索端（相似内容/噪音） |
| 相关性 <0.5 | 答非所问 | 查 Prompt/意图理解 |

## 4. 批量评测
- 评测集每行含 question/answer/context → 逐行算指标
- 聚合：分场景均值 + 总均值（衔接 report）

## 5. 常见误区
1. "简化指标=RAGAS"——词重叠 ≠ 语义，基线可用，门禁从严需专业框架
2. "只看忠实度"——四个指标对应不同环节，诊断要四维一起看
