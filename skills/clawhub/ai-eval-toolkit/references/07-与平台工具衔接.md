# 07 与平台工具衔接

> 适用：从本工具链升级到专业评测框架的路径
> 核对基准日：2026-08

## 1. 对照表

| 能力 | 本工具链 | RAGAS | OpenAI Evals | LangSmith/Langfuse |
|---|---|---|---|---|
| 评测集管理 | ✓ 本地 JSONL | ✓ | ✓ | ✓ |
| 幻觉检测 | 规则（快速基线） | LLM 判定 | LLM 判定 | 插件 |
| RAG 指标 | 词重叠近似 | LLM 精确 | 部分 | 集成 |
| 回归对比 | ✓ | 部分 | ✓ | ✓ |
| 报告门禁 | ✓ 本地 | 部分 | ✓ | ✓ |
| 依赖 | 零依赖 | 需安装 | 需 API | 需平台 |
| 数据 | 本地闭环 | 可本地 | 走 API | 走平台 |

## 2. 升级决策

| 场景 | 推荐 |
|---|---|
| 快速基线/教学/CI 冒烟 | 本工具链（零依赖） |
| 生产级 RAG 评测 | RAGAS（LLM 打分） |
| 大规模回归平台 | OpenAI Evals / LangSmith |
| 全链路可观测 | Langfuse + 监控（衔接可观测性 skill） |

## 3. 升级路径（保留评测集）
- 评测集 JSONL 格式基本兼容（RAGAS 的 `EvaluationDataset` 可导入）
- 检测结果可对比：先跑本工具链基线，再跑 RAGAS 校准差异
- 双轨运行：本工具链做快速门禁，专业框架做月度深度评测

## 4. 常见误区
1. "必须用最贵的工具"——先本工具链建基线，需求明确再升级
2. "换了框架评测集作废"——JSONL 可迁移，评测集是资产
