# 06 报告与门禁

> 适用：评测结果落成报告 + 上线门禁判定
> 核对基准日：2026-08

## 1. 报告结构

```
一、评测概况（评测集版本/规模/被测版本/检测器版本）
二、总览（综合得分 vs 基线 + 门禁结论）
三、分场景得分表（对比基线，退化标红）
四、幻觉检出清单（Top 可疑样本：输入/输出/命中规则/严重度）
五、结论与建议（通过/拦截/修复项）
```

## 2. 门禁判定

```bash
python tools/eval_toolkit.py report --result result.json --gate 0.05
# gate=核心指标允许下降幅度（如 5%）
```

### 门禁规则（示例）
| 条件 | 结论 |
|---|---|
| 核心指标下降 ≤ gate | 通过 |
| 核心指标下降 > gate | 拦截 |
| 幻觉检出新增高危 | 拦截 |
| 单场景退化 > 2×gate | 拦截 |

## 3. 与 CI 集成
- 推送触发：`dataset check` + 冒烟检测
- 发布前：全量评测 + `compare` + `report` 门禁
- 门禁失败 → 拦截发布（衔接 LLMOps 版本管理）

## 4. 常见误区
1. "报告写了没人看"——门禁自动判定，报告是证据
2. "gate 拍脑袋"——gate 基于历史基线波动校准
