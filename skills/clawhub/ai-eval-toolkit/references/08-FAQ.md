# 08 常见问题 FAQ

> 核对基准日：2026-08

## Q1：这个工具链和 RAGAS 什么区别？
本工具链是零依赖的规则/词重叠近似实现（快速基线、本地闭环、可解释）；RAGAS 用 LLM 打分更准但需安装与 API。**建议：本工具链做 CI 冒烟门禁，RAGAS 做月度深度评测**（07 模块有对照）。

## Q2：规则检测准确吗？
设计为"召回优先"：宁可误报也不漏报，命中即标 suspicious 待人工复核。抽样 20-50 条校准检出率/误报率后使用。**它不是完美检测，是快速基线**。

## Q3：评测集 JSONL 怎么建？
`dataset init` 生成模板，字段：id/scenario/question/answer/context/reference。起步 50-100 条，覆盖 normal ≥70% + boundary + adversarial（02 模块）。

## Q4：RAG 四指标用词重叠靠谱吗？
近似语义，方向对但精度有限：完全同义改写会漏、部分重叠会误。**看趋势和对比（同口径跑基线）有效，绝对值慎用**。生产用 RAGAS。

## Q5：怎么集成到 CI？
推送触发冒烟（dataset check + 抽样检测），发布前全量（compare + report 门禁）。门禁失败拦截发布（衔接 LLMOps）。

## Q6：工具链能测安全吗（注入/越狱）？
本工具链测"事实性幻觉/质量"；安全（注入/越狱/有害内容）用 AI 安全与红队 skill。**安全是底线、质量是体验，各司其职**。

## Q7：需要联网或装依赖吗？
不需要。纯 Python 标准库，数据不出本机，零网络零采集。这是刻意设计（安全门禁要求本地闭环）。

## Q8：评测结果能直接当上线证据吗？
工具链出报告 + 门禁判定（通过/拦截）可作为 CI 门禁证据；但对外/高合规场景建议附 RAGAS 等专业框架结果交叉验证。

## Q9：和 LLM 质量评测 skill 怎么配合？
**质量评测（方法论）教你选指标、建评测集、定流程；工具链（实现）帮你跑起来**。先看方法论定体系，再用工具链执行，方法论里的评测集设计指南对应该工具链的 dataset 命令。

## Q10：工具链会持续维护吗？
规则库与指标实现会随方法论演进更新（README 标注版本）；核心价值是"零依赖可解释的快速基线"，长期配套专业框架使用。
