## Description:

Helps agents provide DNS configuration guidance for records, TTL planning, email authentication, migration checks, and troubleshooting commands.

This skill is ready for commercial/non-commercial use.

## Publisher:

[thcjp](https://clawhub.ai/user/thcjp)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and operators use this skill to plan DNS migrations, configure common DNS records, check email authentication records, and diagnose DNS propagation or provider-specific behavior.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad DNS-related words or produce DNS changes that affect live routing, email delivery, or certificate issuance.

Mitigation: Scope invocation to DNS-related requests and review suggested DNS changes before applying them in a provider console.
