# 问卷数据卡 · 数据形态卡

> 本卡是**防错经验库，不是章节骨架**。问卷/调研形态数据时按需查阅；章节自由组织，不存在图数配额与必备章节。

## 何时参考本卡（触发键）

数据含大量低基数分类列、题号前缀列名（Q1/第x题）、量表值域（1~5 / 1~7），或用户明示问卷/调研/满意度分析。

## 防错清单（核对后再动笔）

* 样本说明必须有：回收量、有效样本、构成分布；样本不代表总体时必须入 caveats
* 量表题给均值必须同时给分布（均值会掩盖双峰）
* 交叉分析的差异必须做规模校正：用行百分比而非绝对数（防大群体主导）
* 单选题/多选题口径不同：多选题占比分母是答题人数非总人数，叙事中写明
* 无群体维度列（纯总体数据）时交叉分析不可算，如实声明
* 全文本题：用 transform 提取关键词频次，声明「文本题为关键词视角」
