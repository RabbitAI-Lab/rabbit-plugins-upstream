# 目标对照卡 · 数据形态卡

> 本卡是**防错经验库，不是章节骨架**。目标/对照形态数据或复盘场景时按需查阅；章节自由组织，不存在图数配额与必备章节。

## 何时参考本卡（触发键）

数据含目标/预算/成本列，用户给定目标值或对照期，或用户明示达成率/复盘/ROI/效果评估。

## 防错清单（核对后再动笔）

* 达成率必须给目标基线并交代口径：目标来自哪、含税与否、按订单还是回款
* 复盘必须有对照基线，三选一并写明口径：目标值 / 上期同类活动 / 不做事的对照组；无对照基线时降为自身前后对比，局限入 caveats
* 过程分析的时间范围尽量覆盖活动前后（前基线期 + 活动期 + 衰减期，数据支持时）
* 投入产出必须给 ROI 计算式（分子分母口径），不能只给结论；无成本数据时如实声明「ROI 不可算」
* 经验与改进分开写：经验是可复用做法，改进是下次的待办；每条「经验」指回具体证据
* 增长数字尽量区分「价格驱动 vs 量驱动」（数据支持时）
