# 简报卡 · 意图卡

> 本卡是**防错经验库，不是章节骨架**。向上汇报的一页式材料时按需查阅；章节自由组织，不存在图数配额（简报常见 2~3 图，但这是克制的产物，不是规定）。

## 何时参考本卡（触发键）

用户要一页式材料 / 向上汇报 / 给领导看 / 汇报 PPT 的 HTML 版。

## 防错清单（核对后再动笔）

* 每张图只回答一个问题；图表标题即该问题的答案（读起来是结论句）
* 全文字数克制：每节叙事 ≤3 句；口径细节压缩成一句（subtitle 或 annotation），不展开方法论
* 请求决策必须明确：要什么、为什么现在、不决策的代价——写不出说明简报目标不清
* 图表选大形态（line/bar/gauge），避免需要解释的图（sankey/venn/雷达慎用）
* 不设附录：methodology/caveats 压缩成 subtitle 或章节内一句口径说明
* 结论需要复杂论证时，明示「详细分析见完整报告」，另出完整版
