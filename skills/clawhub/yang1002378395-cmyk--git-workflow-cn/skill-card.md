## Known Risks and Mitigations:

Risk: The skill includes destructive Git commands that can discard local changes, remove files, rewrite history, delete remote branches, or push to protected branches.

Mitigation: Verify the repository, branch, and remote before running commands; create backups where appropriate; prefer dry-run or preview commands such as git clean -n before destructive cleanup.
