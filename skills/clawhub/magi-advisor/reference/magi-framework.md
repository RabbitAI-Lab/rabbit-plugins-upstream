# MAGI 三贤者决策框架

## 理论来源
MAGI系统由赤木直子博士将自己的思维模式拆分为三个人格副本：

| 系统 | 人格面向 | 决策倾向 | 核心问题 |
|------|---------|---------|---------|
| MELCHIOR-1 | 科学家 | 理性、数据驱动 | "证据支持什么？" |
| BALTHASAR-2 | 母亲 | 保护、风险厌恶 | "什么可能伤害我们？" |
| CASPER-3 | 女人 | 直觉、全局感知 | "感觉告诉我们什么？" |

## 决策规则
- 三票一致 → 高置信度执行
- 两票一致 → 有条件执行，标注保留意见
- 三票分歧 → 暂停决策，补充信息后重新审议

## 适用边界
-  适用于：战略选择、资源分配、风险评估、方案比选
-  不适用于：纯执行类任务、已有明确SOP的操作、简单信息查询
