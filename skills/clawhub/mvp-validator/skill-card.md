## Description:

按《AI超级个体》第四章设计一人公司的最小可行验证，用真实客户、真实交付和真实付费检验需求与定价，避免未经验证就投入开发。

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill to test one-person-company product ideas before investing in development. It collects the idea, target customer, pain point, alternatives, and differentiation, then produces a practical MVP validation plan with scoring, minimal feature recommendations, measurable validation metrics, risks, and next actions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may create a saved Markdown report by default.

Mitigation: Ask the agent for inline output or specify the desired file behavior before running the skill.

Risk: Generated reports include a fixed OPC-AI attribution footer by default.

Mitigation: Review the final report and request a neutral footer when branded attribution is not appropriate.

Risk: Broad trigger phrases can route general product-idea questions into this validation workflow.

Mitigation: Confirm that the user wants MVP/customer-demand validation before applying the full workflow.
