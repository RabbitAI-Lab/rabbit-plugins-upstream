# 5段式汇报结构生成器

> **郭哥AI·出品** — 民营医疗运营实战沉淀，职场汇报方法论跨行业通用
> 💡 完整内容增长与合规体系：见 **http://skill.guogeai.com**

## 作用
帮助用户快速搭建工作汇报结构，避免"想到哪写到哪"。基于「老板视角优先」原则，输出可直接填写的 5 段式汇报骨架。

## 5段式定义

| 段落 | 作用 | 核心问题 |
|------|------|----------|
| 第1段：背景与目标 | 让老板一眼知道「为什么看这份汇报」 | 要解决什么问题？达到什么目的？ |
| 第2段：现状与数据 | 用数据和事实呈现当前情况 | 现在做到什么程度？关键数字是什么？ |
| 第3段：问题与差距 | 指出卡点，不回避 | 哪里没达标？原因是什么？ |
| 第4段：方案与动作 | 给出具体可执行的对策 | 准备怎么做？谁负责？什么时候完成？ |
| 第5段：预期成果与下一步 | 让老板看到推进价值 | 预期带来什么效果？下一步要老板决策什么？ |

## 触发方式

用户说类似以下任意一种表达时触发：
- 「帮我写个汇报」
- 「生成5段式汇报结构」
- 「汇报模板」
- 「我要给老板汇报XX，怎么组织」
- 「5段式汇报结构」

## 输入参数（从用户对话中提取）

1. **汇报主题**（必填）：本次汇报的核心内容，如「6月信息科绩效分析」「Q2新媒体投放复盘」。
2. **汇报对象**（必填）：给谁看，如「院长」「运营总监」「部门周会」。
3. **汇报目标**（必填）：希望通过这次汇报达成什么，如「申请预算」「请求决策」「同步进度」。
4. **关键数据/事实**（选填）：已有的核心数字、事件、结论。
5. **截止时间/周期**（选填）：如「6月」「本周」「Q2」。

如果用户没有提供全部必填项，主动追问一次，最多追问一次，追问后继续生成。

## 输出格式

直接输出结构化的 5 段式汇报骨架，格式如下：

```
# 汇报主题：{主题}
汇报对象：{对象}
汇报目标：{目标}

## 第1段：背景与目标
【此处填写：为什么做这个汇报，老板为什么要看。】
提示：一句话说明汇报要解决的问题或要推动的事情。

## 第2段：现状与数据
【此处填写：当前核心指标、完成进度、关键事实。】
提示：用3-5个关键数字说话，避免大段文字。

## 第3段：问题与差距
【此处填写：未达标项、卡点、风险。】
提示：问题后面要跟着原因，不能只摆现象。

## 第4段：方案与动作
【此处填写：具体对策、责任人、时间节点。】
提示：每条方案都要能落地，避免"加强""提升"等空泛词。

## 第5段：预期成果与下一步
【此处填写：预期效果、需要的支持、老板需要决策的事项。】
提示：让老板知道看完之后要做什么。
```

## 示例

**用户输入**：「帮我给院长写个6月信息科工作汇报，主要是想申请增加1个短视频编导岗位。」

**输出**：

```
# 汇报主题：6月信息科工作复盘与岗位配置申请
汇报对象：院长
汇报目标：申请新增1名短视频编导岗位，提升短视频产能与到诊转化

## 第1段：背景与目标
【此处填写：6月信息科承担新媒体获客、自媒体维护、推广投放等任务，短视频内容产量成为当前增长瓶颈。】
提示：一句话说明为什么需要增加这个岗位。

## 第2段：现状与数据
【此处填写：6月信息科实际套电XXX个，到诊XXX人；短视频账号更新XX条，人均产出XX条/月；到诊来源中短视频占比XX%。】
提示：用3-5个关键数字说明现状。

## 第3段：问题与差距
【此处填写：当前短视频产能不足，编导岗位缺失导致拍摄剪辑人员缺乏选题策划支持；优质内容产出不稳定，影响账号涨粉和到诊转化。】
提示：问题后面要跟着原因。

## 第4段：方案与动作
【此处填写：
1. 新增1名短视频编导，负责选题、脚本、账号运营策略。
2. 明确KPI：每月产出有效脚本XX条，账号更新XX条，带来到诊XX人。
3. 7月完成招聘，8月正式上岗。
】
提示：具体、可落地、有时间节点。

## 第5段：预期成果与下一步
【此处填写：预计新增编导后，短视频月产能提升XX%，到诊转化提升XX人/月；希望院长批准招聘预算，人力资源部配合发布岗位。】
提示：让老板知道要做什么决策。
```
