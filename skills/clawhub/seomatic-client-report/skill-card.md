## Description:

Creates a monthly client SEO report from connected site data, comparing search performance with the prior period and summarizing completed work, AI search visibility, and next steps.

This skill is ready for commercial/non-commercial use.

## Publisher:

[minh42](https://clawhub.ai/user/minh42)

### License/Terms of Use:

MIT-0

## Use Case:

Agencies, site owners, and marketing teams use this skill to prepare concise monthly SEO updates for clients or stakeholders, with sourced performance numbers, measured results, and priorities for the next month.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The SEOmatic connection can access the selected site's Search Console and analytics data.

Mitigation: Trust the connection before installing and confirm the intended workspace and site before generating a report.

Risk: Proposed SEO changes could affect a live site if approved.

Mitigation: Review each proposed change separately before approving it; report generation does not publish changes automatically.
