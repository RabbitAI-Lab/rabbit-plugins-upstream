# 不进房子就能设计，和骗子没有什么区别6.23

> 安全提示：本专题涉及燃气设施隐蔽、墙体拆改、阳台打通等高风险操作，均须由持证专业人员确认并实施——① 燃气管道/表/热水器严禁私自隐蔽包裹，须取得当地燃气公司书面批准并确保通风与检修通道；② 拆墙、开洞、门洞加高拓宽、打通阳台须先确认非承重墙及墙内管线，取得物业与结构书面许可；③ 本指南仅帮助业主理解设计思路、与师傅沟通，不构成施工指导，严禁擅自施工。


常常告诉大家用生活经验去看装修，另一层意思其实是想说，装修设计没有那么高端，只不过人家的工作就是设计装修，经验比你多而已，仅此而已。

但是大部分装修业主在初次面对装修，接受铺天盖地无法分辨的信息冲击，给自己的感受就是，装修好难，设计好高端。这样的后果就是刚好中了商家和媒体的下怀，刚好可以利用信息不对称共同宰割业主的血汗钱而已。

特别是准备自己动手装修的业主，更是一筹莫展；病急乱投医，于是在网上各种搜索，看到有各种不需要上门就可以给你设计的，只需要提供具体尺寸以及房间照片，给你完美的家。于是花了钱弄回一大堆复制臆想出来的图纸，自己找工人施工，结果是设计师压根不在场，施工是每一步几乎都和设计有冲突，往往是设计等于白做，钱并没有少花，而且并没有任何效果。

为什么不建议你找不上门的设计，因为你不知道对方是刚毕业的学生，还是拿你家当玩的设计师，一切只不过是纸上谈兵，没有进房子靠照片和尺寸想象（糊弄）一下上帝而已。说不定连个基本的施工经验都不具备，做出来的东西仅仅局限于看的标准，想要落地一塌糊涂。

所以奉劝各位准备自己装修的业主，如果不想找装修机构，自己又不懂，你可以多去咨询咨询，各大装修公司不会把你拒之门外的，拿着户型图去取经，多听听多看看，然后找一个经验丰富人品正的施工队也是可以装修落地的。

千万不要想着设计多么高端，自己也想弄堆图纸，施工队照着就能施工，这个是白费功夫，把装修施工完全抛之脑后了。装修重要的不是你花里胡哨的设计，是要有经年的经验以及随时可以发现问题的眼睛，要有全身心替工地着想的责任心。

坚决不要找不上门就可以设计的付费设计，如果你真的有钱，找当地能随时上门的设计师即可，前提是你真的有钱《独立设计不是不好，而是有的存心不善》
