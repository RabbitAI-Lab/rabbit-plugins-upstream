# 35㎡挑空公寓，自制LOFT极致空间

单身公寓有两种，一种是平层公寓，一种就是挑空公寓，可以自己分割成两层空间，满足更多功能；今天这套挑空公寓层高本身4.7米，所以有隔层的需求。

▲房子的原始样子，挑空小公寓，像这种空间就是为了自己搭建，可以拓展更多空间，所以对于单身公寓来说非常划算。

▲为了保证功能最大化以及采光的最大化，把进门口钢结构搭建，可以满足楼上的睡眠空间以及衣帽间卫生间安排。
▲草图模型，能看到二楼利用了过道空间，所以刚好成就楼上的衣帽间。▲原始结构图，一楼进门就是一个挑空的开间，二楼的面积稍大，因为有了过道的赠送空间。如此小空间采用搭建布局满足一个人的入住，相对来说不算复杂▲一楼布局图。进门就是个大开间，一楼主要作为公共布局，进门左手顶天立地的收纳柜，兼顾进门的鞋柜；右手开放布局橱柜，同时借用下水镶嵌洗烘机；进门左手楼梯下方定制收纳柜，下方还能放置冰箱，旁边一个小的餐桌，满足一个人的就餐；靠近窗户客厅区域因为需要满足整体采光，所以挑空布局，让整体空间光线一览无余▲搭建以后二楼的布局图纸，客厅区域挑空布局，进门上头搭建钢结构以后，刚好借用了过道赠送空间，让搭建多了一部分面积，刚好作为楼上卧室的衣帽间使用。一个人住所以直接在楼上安排一个卫生间即可；卧室区域采用钢化玻璃护栏，光线通透
▲进门左手定制顶天立地收纳柜，兼顾收纳同时兼顾进门的鞋柜；楼梯下方打造一部分收纳柜，利用高度差刚好布局冰箱，剩余空间安置了一张小的餐桌，用来满足一个人的就餐
▲一个人住小的餐桌兼顾书桌，完全满足，铺上好看的桌布，摆上挂画以及饰品，这里也是进门的温馨一角
▲进门右手过道就是开放式厨房空间，因为没有天然气，所以电磁炉完全满足偶尔的烹饪需求；墙面采用水泥瓷砖铺贴，搭配白色的橱柜定制，视觉上有层次而且显得更干净；利用水槽下水位置刚好满足洗烘机的镶嵌，台面上方置物架，放置小的家电
▲非常娇小精致的小厨房，一个人闲下来可以满足简单的烹饪，也是不错的
▲水槽旁边的两根下水管道包裹以后，导致台面变窄，刚好利用垂直置物架，满足餐具和刀具的收纳，合理利用起来
▲挑空地方刚好布局客厅，一个人住，也不需要电视，所以角落摆了一个艺术雕塑的摆件，只是为了装饰而已；暖色调布局，挑高的窗户光线一览无余
▲客厅暖色调的搭配弥补挑空的单调感，落地窗的飘窗柜不仅满足收纳，同时也能满足人多的时候，更多空间就坐
▲一个人住，为了视觉更简洁，楼梯选择不要扶手，同时楼梯尽量给客厅留出空间，用来满足便携式投影的偶尔娱乐
▲客厅看全景，空间小，不得不用广角拍摄，整体浅色调，同时极简布局，玻璃材质的加入，让小空间更明亮
▲浅色的搭配以及毫无拥堵感的开放布局，让小空间增加开阔感，同时视觉上也不会有厚重之感
▲二楼的卧室栏杆采用全部钢化玻璃，让空间更通透，视觉明亮
▲因为楼上空间比较矮，所以采用直接摆放床垫的形式，保证睡眠的安全，同时低矮的床铺可以视觉上拉伸层高
▲床垫旁边采用矮柜满足床头柜功能，旁边打造吊柜壁龛作为化妆台功能，搭配一把幽灵椅，非常简洁时尚
▲床头单独造型暗藏灯带，同时台面可以作为置物展示空间
▲放上香薰和喜欢的手办，床头也温馨
▲楼上卫生间很小，与楼下厨房采用同样款式的瓷砖，壁挂马桶不留卫生间死角，同时上方台面还能置物，淋浴地方采光挡水加浴帘的形式分割，壁龛满足收纳
▲卫生间门外成品洗漱盆满足了干湿分离的需求，同时因为过道上方的大梁，导致衣帽间无法装门，采用半帘的形式，视觉上更活泼
▲衣帽间内部，其实这个就是过道上方的赠送空间，刚好做成衣帽间，全部采用帘子遮挡，放上全身镜，非常完美END
