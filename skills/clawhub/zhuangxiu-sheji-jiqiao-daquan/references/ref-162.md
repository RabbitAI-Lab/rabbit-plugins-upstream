# 装修中那些不为人知的，不对称设计12.2

上一篇讲了对称设计，这一篇讲一下装修中那些不对称。同样对称是一种美，不对称也是一种美。

◆卧室背景墙以及床的不对称设计反而有种灵动感

◆背景墙装饰的错乱不对称更显前卫

◆不对称的设计反而区分了空间格局

◆台灯摆放不对称，各司其职

◆柜子的不对称设计，会让空间减少压抑感

◆餐厅吊顶的不对称随意增加情趣

◆照片的不对称摆放也是一种美

◆单椅的不对称摆放出现另一种效果

◆装饰画的不规则，不对称，创意书架的不对称

◆电视墙不对称设计现代前卫

◆电视墙不对称造型增加空间灵动性

◆上图电视墙不对称设计便于分割区域而不使空间缩小，否则电视墙对称反而缩小了整个空间

◆小户型电视墙不对称设计增加储物，空间不压抑

◆电视墙不对称的设计，打破空间整体呆板

◆沙发背景墙挂画的不对称摆放更显大气
