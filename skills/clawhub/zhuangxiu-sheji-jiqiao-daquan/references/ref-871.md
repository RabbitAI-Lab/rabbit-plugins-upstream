# 除过厨房，哪地方还能做吊柜？10.27

▲一般家庭门厅鞋柜这样做足够，一个长条凳下面放常穿的鞋，又能当做换鞋凳，吊柜又能放置换季的鞋和杂物。镂空背景简单挂衣钩设置即可

▲书桌上头更不能浪费了，做成吊柜可以储物，下方隔板收纳，镂空区域刚好放置电脑和书籍

▲吧台上方也可以做吊柜储物，平时的酒水具刚好收纳

▲书房空间吊柜更能节省地方，还可以满足储物收纳，对于小空间更实用

▲楼梯下方收纳储物空间，吊柜地柜设置，虚实结合视觉上不会显得压抑

▲单独狭小的学习空间，书桌上方储物吊柜，增加收纳区

▲靠窗户的简易书桌侧墙，制作局部吊柜，收纳储物

▲床头区域也可以吊柜收纳，而且做出来美观大方，储物不足的可以试试

▲床头吊柜与旁边书桌一体设置，书桌上方镂空设置，背景镜面处理，虚实结合，可以减轻视觉上的压抑感

▲卧室角落书桌上方局部吊柜收纳储物，增加收纳功能

▲拐角书桌上方的拐角吊柜，虚实结合设置

▲客厅过道局部吊柜收纳兼装饰功能

▲阳台洗衣池上方更不用说，能做吊柜尽量做了，各种杂物都要收纳

▲餐边柜兼西厨空间，可以做成玻璃门吊柜，收纳兼装饰都可以

▲电视墙也是一样，局部吊柜不仅仅是收纳，同时也是装饰

▲客厅角落吧台休闲区，同样吊柜加隔板做法，增加收纳，同时也是装饰

▲榻榻米书房更不用说了，能做吊柜尽量做，或书柜或者储物柜都可以

▲卧室靠窗一面墙这样做，吊柜增加收纳，储物再也不愁了

▲客厅拐角休闲空间，吊柜玻璃门设置，收纳更多
