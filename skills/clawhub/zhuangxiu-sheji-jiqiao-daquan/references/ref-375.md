# 吊柜变掉柜，悬空柜并不无限承重2.7

吊柜几乎每一家都有，但是大部分人在定制的时候，恐怕都不会想到，吊柜有时候会变成掉柜，直接脱落，没有砸到自己是万幸，一旦家里有小孩、老人或者孕妇行动不便，运气不好，吊柜随时就成了家里的定时炸弹了。

▲最常见的就是厨房吊柜，几乎家家户户都有，如上图是年限太久，长期承重以后，吊柜突然脱落导致，而且间接砸坏了烟机；如果是出租房发生危险砸到人的话，后果不堪设想。
所以不论你家吊柜多么结实，一定注意，是为了放置轻便杂物的，千万不要把过于沉重的东西放进去，例如家里的米面油严禁放入吊柜，一时不掉是侥幸，时间久了那是必然的事情
▲家里厨房长的话，最好分段定制吊柜，不要无限延伸，否则后期一旦承重超过负荷，随时都有可能全部脱落。所以长吊柜尽量分开一组一组定制安装，后期分别固定，比较妥当。▲不要尝试采用吊柜做书柜使用，变形脱落是必然的事情，膨胀螺丝再好也没有办法常年累月承重书籍的重压；所以做书柜一定要用落地柜或者矮柜，吊柜只是用来放轻便杂物，或者零散几本展示书籍，千万不要把吊柜真的当做书柜使用▲餐边柜悬空柜直接脱落，你能说是安装问题，但是餐边柜为了弥补厨房收纳不足，大部分内部都是重物，所以这种下方悬空的安装脱落是必然的结果。所以在定制餐边柜的时候一定要落地定制▲如图所示，落地餐边柜用来弥补厨房收纳不足，可以随便放置重物，一定要落地定制；上方吊柜是为了放置轻便物品以及杂物，坚决不能放置重物▲悬空的浴柜直接脱落，这就是为什么不建议做悬空浴柜的原因，而且大部分家里悬空浴柜背后都不是混凝土，直接安装在红砖墙体，后期肆无忌惮的放置物品，一天比一天负荷大，不脱落才叫奇迹▲即使是湿区空间，也不建议采用悬空浴柜，建议采用金属支撑腿支撑，高低都有，都可以满足功能▲至于没有水的干区空间，更建议仿照橱柜地柜的做法，下方做支撑腿，采用踢脚板装饰一下，最稳固，也没有卫生死角的后顾之忧▲即使没有干湿分离，浴柜也可以落地采用支撑腿，搭配防潮的PVC踢脚板即可，稳固而且没有卫生死角▲彻底的干区，也可以直接采用落地定制，下方踢脚板可以采用与柜门同色同材质的做法，收纳更多，也同样没有卫生死角▲如果你非得采用墙排下水，悬空安装浴柜，一定是后面必须混凝土墙面，尽可能多打膨胀螺丝，做到稳固不出意外，同时悬空浴柜内部，严禁放置承重物品，否则时间久了还得脱落。肯定有人会说，如果浴柜必须承重墙，那厨房吊柜好多都不是承重，吊柜都无法安装了？其实这两者相差很远，浴柜本身高度以及厚度远远大于吊柜，而且上方还得承受石材以及陶瓷盆的重量，所以重力下，悬空浴柜自身的重量要远远大于非常薄非常低的厨房吊柜的，所以厨房吊柜放置轻便物品，吊码安装到位，一般即使是非承重也没有问题。
