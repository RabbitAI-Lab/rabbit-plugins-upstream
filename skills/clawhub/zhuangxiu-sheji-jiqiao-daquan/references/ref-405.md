# 悬空电视柜真有颜值，但是翻车了11.6

翻车的专辑里头有很多案例，大家可以从这些翻车案例中汲取经验教训，避免自己装修重蹈覆辙。今天看一下悬空电视柜翻车案例。▲L型悬空电视柜是不是看起来很漂亮，然而墙体不是承重，在没有入住的时候，电视柜已经与墙体分离，为了不至于报废，只能网购这种亚克力腿后期支撑起来，真的是多此一举，所以奉劝想做悬空电视柜的业主，墙体一定是混凝土，不要有任何侥幸不会掉，只是时间问题▲投影幕没有问题，然而自己不懂比例，悬空电视柜太厚重，空间立马失调，后悔已经晚了。悬空电视柜重点在颜值，收纳只是少量的，如果要多收纳直接做满墙柜算了，否则贪心的后果就得付出颜值受损的代价▲整体没错，但是细节翻车了，注意右上方高柜已经突出吊顶位置，这种做法，把无主灯以及悬浮吊顶的高级感全部毁掉了▲比例做短了，感觉非常小气，没有办法，只能靠窗帘放了绿植，右边放一副挂画，但是还是感觉悬空与电视不搭，非常小气▲大的方向没有太大问题，然而前期忽视了线路以及插座高低，导致插座以及线路全部外露，后期入住只能靠一些物品进行遮挡处理▲悬空太过于厚重了，柜机本身就压抑，旁边还做了一组高柜，导致视觉更乱，接着左边还做了局部的木质饰面，显得多余，整体显得臃肿了，▲没有柜机，没有窗帘，想着留白更好，谁知道入住以后越看越小气，应该一直延伸到头更大气▲一白也未能遮千丑，装修还是整体规划的好，自己装修走一步看一步，每一步都会出错，虽然不影响使用，但是价值还是降低了▲太厚重了，多亏是白色，是深色直接翻车到底了▲墙体不垂直，而且超过2.4米需要拼接，导致不是墙面有缝隙，就是拼接缝隙宽窄不一，此时墙面平整度是无法满足电视柜安装的，需要把墙面做到标准才可以，装修是一环套一环，并不是毫不相干的，否则每一步都会导致后面的翻车
