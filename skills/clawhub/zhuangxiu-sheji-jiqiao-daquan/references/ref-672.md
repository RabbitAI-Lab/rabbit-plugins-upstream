# 55㎡老旧顶楼复式，改造潮流民宿

今天又是一套商业操作，以前有过一篇旧房改民宿的案例，大家可以查阅一下《低成本造就高颜值，35m²老房变网红民宿》因为本身要出租，像这种很小的复式比普通平层要难很多，所以为了利益的最大化，业主决定做成民宿，目前民宿的收益显然要比普通房租大很多。

户型：复式
风格：北欧民宿
造价：拆除1万，全包7万，总造价10万。
▲原始户型一楼空间，进门只有餐厅以及厨卫，楼梯占了很大一部分，因为原本就是现浇的楼梯，占地不太实用，而且光线阴暗潮湿；厨房的操作空间无法布局，卫生间也非常小，连基本的淋浴区都无法安排。

▲没有装修前的现状，进门就是餐厅，谈不上是客厅区域，尽头分别是现浇楼梯，一边各是厨卫，整体很小而且极其老旧。
▲原始户型二楼空间，主卧很大，竟然上头有个公共区域，可以安排客厅，为了多住人，只能尽可能改成最起码能让一家三口入住的场所，或者同时容纳四个人入住，这也是小户型民宿的最低配置了。▲原始户型一楼改动图纸，原来的现浇楼梯砸掉，取而代之是轻巧的钢结构楼梯，这样楼梯一部分可以做收纳储物；把卫生间墙体朝厨房移动，满足墙排马桶的移位，腾出单独淋浴区域。▲原始户型二楼改动图纸，原来的主卧一分为二，做成了卧室和书房的套间，同时书房区域安排上下铺的布局，可以同时容纳两个人入住，最里头区域同样做了很小的卧室，这样就可以完美容纳三个人同时入住。▲一楼的最终设计布局，进门左手安排鞋柜和冰箱，楼梯改作了钢结构楼梯，下方刚好可以放置洗衣机；靠近楼梯安排很小的餐桌，在厨房门口，满足基本的就餐需求；卫生间移动墙体以后，做了墙排马桶移位，成就了门后面很小的淋浴布局。▲二楼的最终设计布局，大卧室分割成了套间加书房的样式，书房书桌对面的凹陷区安排上下铺的布局，同时满足两个人的入住，楼梯的另一边很小的区域同样可以单独住人，这样二楼同时可以容纳三个人同时入住了。
▲重新装修后的进门，为了让采光足够，统一采用白色系，明装筒灯让视觉更简洁；进门左手区域分别布局冰箱、鞋柜以及挂机空调；右手墙面简单木质挂钩，满足进门挂衣服包包的需求；窗户下暖气片涂刷成黑灰色，与大面积白色形成对比，视觉上要高端时尚很多，同时地面通铺的北欧花砖，也让空间光线提升不少
▲空间太小，只能采用门厅和餐厅一体的方式。斗柜不仅仅是鞋柜，同时用来放置进门的杂物包包，还可以兼顾放置各种水杯等物。上面的挂画是手工DIY的，简单温馨，不仅功能齐全，颜值也清爽很多
▲网购的玻璃相框，小区捡的竹子树叶装饰，就是独一无二的自然气息，也让民宿有家的温馨感
▲进门的全景，为了视觉更明亮，多以白色为主，窗帘也没有采用会造成视觉障碍的布帘，而是白色的透光卷帘，不论放下还是收起，都不会影响光线的通透；楼梯做了钢结构处理以后，下方刚好容纳洗衣机位置，旁边很小的餐桌布局，平时做饭简餐是完全可以满足的
▲大面积白墙搭配钢结构原始的黑漆，强烈对比也能让视觉有质感，餐桌上方竹制的艺术吊灯，让进门也能有艺术感。为了节省更多空间，厨房没有装门，采用藏蓝色的半截帘遮挡，让空间更柔和自然，最重要的是节省出更多空间，做饭时放下布帘就可以解决油烟问题
▲一楼尽头的厨房空间，前后对比；移动墙体以后厨房刚好形成L形布局，空间更合理，深蓝色橱柜与白色瓷砖对比，视觉明亮而且非常有质感。同样还耐脏，做民宿颜值和功能都有了
▲原始的卫生间，进门就是马桶，对面安排洗手池，淋浴几乎不可能有空间
▲移动卫生间局部墙体到厨房，让厨房布局合理，同时成就了墙排马桶的移位功能，马桶上方安排热水器位置，这样门口就可以作为很小的淋浴地方，同样白色为主，很小的定制浴柜满足基本的洗漱功能
▲卫生间虽小，但是功能齐全；木质的玻璃门与楼梯踏步呼应一体，视觉更完整统一
▲原始的现浇楼梯，非常窄，而且抬头容易磕碰
▲重新装修以后，大面积白色，砸掉二楼的墙体，取而代之是轻巧的扶手，不仅让上下互通，同时采光更好
▲原来的客厅空间，因为与楼梯一墙之隔，空间显得逼仄狭小
▲砸掉楼梯墙体以后，客厅豁然开朗，搭配原木的温馨家具以及米色的软配布艺，视觉上温馨有家的感觉
▲大面积白色让视觉明亮，原木的家具增加温馨感，客厅沙发床可以拉出来完全满足一个人居住
▲因为是顶楼复式，二楼的层高很高，光线一览无余无遮挡，原木以及北欧绿植的简单装点，非常自然清爽
▲绿植的点缀让大面积白色充满自然生机
▲站原来的卧室看客厅空间，老旧狭小，楼梯口的墙体影响空间通透和光线
▲把原来的大卧室分割成了两个区域，书房凹陷区定制上下铺，上铺睡人，下铺满足衣物和书籍杂物的收纳，这里也可以当做一间卧室使用
▲上铺虽小有孩子入住是足够了，旁边网购的云朵壁灯可以满足晚上起夜需求
▲上下铺对面刚好有窗户，采光够用，采用原木隔板做了书桌，利用空间作为工作区，入住的人可以随时处理工作事务
▲分割出来的书房和客厅开放互通，两个窗户光线互相通透，加上顶楼的斜顶层高，空间非常明亮
▲复古的台灯以及算盘，简单木质隔板收纳，摆放复古的门环，非常有韵味
▲楼梯的尽头有个很小的空间，原来采用柜子遮挡
▲改造以后，原来柜子更换成新作墙体，空间变大，可以放床，大白墙搭配温馨木质，干净清爽
▲床尾木质的衣帽架，可以满足晚上挂衣物，门后空间安排暖气片，同时黑色质感涂刷。床头角落复古的木质梯子吊灯搭配，非常自然有韵味
▲没有改动之前的楼上主卧，空间挺大，而且两个窗户
▲改动之后，分割成了两个空间，缩小原来卧室，原木床铺搭配大面积白色，同样延续温馨简洁的做法
▲床头木质圆几和绿植搭配，虽然简单，但是自然温馨
▲侧墙简单的衣帽挂钩，可以满足晚上挂衣服，进门右手刚好满足衣柜的收纳END
