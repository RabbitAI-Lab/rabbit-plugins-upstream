## Description:

Helps ChatGPT Work and Codex users inspect, adapt, publish, and retrieve ClawHub skills through the documented CLI or website.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ciklopentan](https://clawhub.ai/user/ciklopentan)

### License/Terms of Use:

MIT-0

## Use Case:

Developers using ChatGPT Work or Codex can inspect and adapt public ClawHub skills, prepare user-approved releases, and retrieve skills on request. It is not an OpenClaw-native integration.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Publishing can make skill files publicly available under MIT-0.

Mitigation: Review staged files and licensing rights, and obtain explicit approval for the specific release before publishing.

Risk: Publisher actions may use an authenticated ClawHub CLI or website session.

Mitigation: Review each publishing or installation action, verify the target listing, and keep credentials out of released files.
