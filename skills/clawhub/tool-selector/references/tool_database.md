## Material Matching Guide

### Drilling Bits by Material
| Material | Bit Type | Notes |
|----------|----------|-------|
| Wood | Brad point or twist | Brad point prevents wandering |
| Drywall | Drywall bit | Has depth stop collar |
| Metal | Cobalt or titanium | High-speed steel for aluminum |
| Masonry | Carbide-tipped | Requires hammer drill mode |
| Tile/Glass | Diamond or carbide | Use low speed with water |
| Concrete | SDS carbide | Requires SDS rotary hammer |

### Screws by Application
| Application | Screw Type | Notes |
|-------------|-----------|-------|
| Indoor wood | Drywall or wood screws | Phillips or square drive |
| Outdoor wood | Deck screws (galvanized) | Corrosion-resistant |
| Pressure-treated wood | Structural screws | Coated for ACQ lumber |
| Metal-to-wood | Self-tapping sheet metal | Pre-drill not needed |
| Masonry | Tapcon screws | Requires pilot hole |
| Drywall | Drywall screws | Fine thread |

## Common Project Categories

1. **Hanging & Mounting:** Shelves, TV mounts, pictures, mirrors
2. **Furniture Assembly/Repair:** Tightening, replacing hardware, re-gluing joints
3. **Wall Work:** Patching holes, painting, installing trim
4. **Outdoor:** Garden beds, fences, decks, planters
5. **Plumbing Basics:** Faucet replacement, drain cleaning
6. **Electrical Basics:** Outlet/switch replacement, light fixtures
7. **Storage:** Closet organizers, garage shelving, under-bed storage
