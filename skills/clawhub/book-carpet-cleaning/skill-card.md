## Use Case: <br>
External users can use this skill to search for carpet-cleaning providers, check availability, and create a booking through Lokuli. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The booking flow shares customer contact details and location or ZIP code with Lokuli. <br>
Mitigation: Confirm the user is comfortable sharing name, email, phone number, location or ZIP code, selected provider, service, and time slot before creating a booking. <br>
Risk: A booking may be created with the wrong provider, service, or appointment time. <br>
Mitigation: Review the provider, service, and appointment details with the user before allowing a booking to be created. <br>
