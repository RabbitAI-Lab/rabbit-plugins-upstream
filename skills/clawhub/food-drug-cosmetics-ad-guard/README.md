# 食药化妆品广告合规护栏 (food-drug-cosmetics-ad-guard)

在药品 / 医疗器械 / 保健食品 / 特殊医学用途配方食品 / 化妆品 的广告文案、产品详情、直播话术、对外宣传发布前，实时拦截 6 类高频违法违规表述，按风险分级给出整改建议。

## 覆盖的 6 类红线

1. **药品 / 医疗器械广告禁止内容**：保证治愈、根治、治愈率、有效率、与其他药品比较 —— 广告法第16条
2. **保健食品广告禁止内容**：功效保证、涉及疾病预防治疗、与药品比较、代言人推荐、声称保障健康必需 —— 广告法第18条
3. **化妆品广告禁止内容（医疗作用暗示）**：治疗功效、消炎、抗炎、杀菌、药用 —— 化妆品监督管理条例第43条
4. **疾病治疗宣称违规（非药品滥用医疗用语）**：治疗糖尿病/高血压/癌症、消炎杀菌、抗感染 —— 广告法第17条
5. **处方药违规发布**：大众媒介发布、面向公众、无处方可购 —— 广告法第15条
6. **功效断言与绝对化用语**：最佳疗效、100%有效、最高安全、国家级 —— 广告法第9条 + 第16/18条

## 快速使用

```bash
# 检测一段广告文案
python3 scripts/guard.py --text "本品保证治愈，根治高血压，100%有效" --format json

# 从标准输入读取
echo "化妆品具有消炎杀菌的治疗功效" | python3 scripts/guard.py --stdin

# 列出违规类别
python3 scripts/guard.py --list-categories
```

## 能力边界

- ✅ 表述级红线拦截（功效断言、治愈率、疾病治疗宣称、医疗作用暗示、绝对化用语）
- ⚠️ 不替代广告审查批准文件、广告主资质、特殊化妆品注册证、功效宣称评价报告等技术/资质核查（应归深度审查）
