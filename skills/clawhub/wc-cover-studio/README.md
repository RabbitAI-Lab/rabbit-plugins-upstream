# wc-cover-studio · 公众号封面生成

> 读文章 → 定风格 → 选行业意象 → 生成 1:1 主图 → PIL 后处理，一次交付三种版式：**900×383 头条 / 1080×1080 方版 / 单图双用**。
> 单图双用通吃微信两种裁切比例，中文标题 100% 无错字，内置程序化 QA。

适用所有公众号 / 自媒体创作者。

## 功能亮点

- 📖 **读文章出封面**：解析文章发布信息块（标题候选 / 摘要 / 封面建议），自动定风格
- 🎨 **行业意象选择**：内置中医 / 金融 / 教育 / 科技 / 西医 / 电商 / 农业 / 法律 / 建筑 / 历史 十大行业意象速查表，拒绝通用符号
- 🖼️ **三种版式一次交付**：900×383 头条横版 + 1080×1080 方版 + 单图双用版
- 🔀 **单图双用**：一张图同时适配微信「头条大图」与「分享缩略图」两种裁切，正文区、分享区互不遮挡
- ✍️ **中文标题零错字**：标题由 PIL + 系统字体叠加，不走 AI 绘图模型（不产生错别字）
- ✅ **内置程序化 QA**：输出后自动像素采样验证（标题区 / 主体区 / 延伸区），无读图能力也能确认渲染成功

## 安装方法

### 方式一：WorkBuddy 技能市场（推荐）

1. 打开 WorkBuddy → 左侧「技能」→「技能市场」
2. 搜索「公众号封面生成」
3. 点击「安装」

### 方式二：URL 导入（本仓库）

1. 打开 WorkBuddy → 设置 → 技能管理 → 「通过 URL 导入」
2. 粘贴本仓库地址：`https://github.com/jondeng11-creator/wc-cover-studio`
3. 自动拉取并安装

### 方式三：手动放置

下载本仓库 ZIP，解压后将 `wc-cover-studio` 文件夹放入：

- 用户级：`~/.workbuddy/skills/`（所有项目可用）
- 项目级：`{项目目录}/.workbuddy/skills/`（仅该项目可用）

## 使用方法

安装后直接在对话中说：

> 「给这篇文章做一个公众号封面」（附文章文件）
> 「帮我设计一个封面图，主题是XXX」
> 「用 wc-cover-studio 生成封面」

技能会自动执行：**读文章 → 定风格 → 选行业意象 → 生成主图 → PIL 后处理 → 交付三种版式 + 封面说明**。

> ⚠️ 生成主图会调用 AI 图像生成（消耗少量积分）。

## 文件结构

```

```
