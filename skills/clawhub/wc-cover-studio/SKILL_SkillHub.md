# 公众号封面生成

## 功能

读文章 → 定风格 → 选行业意象 → 生成 1:1 主图 → PIL 后处理 → 交付，一次生成三种版式：

1. **900×383 头条大图**（公众号消息卡片）
2. **1080×1080 方版**（分享图）
3. **单图双用版**（核心卖点）：中央 383×383 安全区放主体+标题，两侧延伸氛围背景——微信后台只能传一张图，本技能让一张图通吃头条大图和分享方图两种裁切，都不丢信息

## 使用方法

对 Agent 说：

- 「给这篇文章做一个封面」（附文章 .md）
- 「帮我重新设计公众号封面，深夜氛围，暖黄灯光」
- 「做一张金融科普类封面，歸藏材质风」

Agent 自动执行完整工作流，输出到文章所在目录。

## 目录结构

```
wechat-cover-generator/
├── SKILL.md                          # 主文件：6 步工作流
├── config.yaml                       # 元数据
├── references/
│   └── wechat-cover-rules.md         # 微信裁切机制/风格库/行业意象库/QA 表
└── scripts/
    └── make_cover.py                 # PIL 后处理脚本
```

## 依赖与安装

```bash
pip install pillow
```

脚本可脱离 Agent 手动运行：

```bash
python scripts/make_cover.py <输入1x1主图.png> --title "主标题" --subtitle "副标题" -o <输出目录>
```

可选参数：`--modes square,wide,dual` 指定版式；`--crop-center 0.52` 调整横版裁带位置。

## 核心能力

- 中文标题 100% 无错字：长标题用 PIL + 系统字体叠加（微软雅黑/苹方/Noto 自动检测）
- 内置程序化 QA：无读图能力也能验证渲染成功
- 行业专属意象库：10 大领域专属符号速查表（避开阴阳图、星星、齿轮等泛化符号）
- 三种风格库：歸藏材质插画（白底3D+IKB蓝）/ 扁平插画 / 深夜氛围摄影

## 异常处理

- 缺输入文件：提示确认路径
- 缺中文字体：自动检测多平台字体，找不到则明确报错
- 标题渲染失败：QA 提示偏低，可调整参数重跑
