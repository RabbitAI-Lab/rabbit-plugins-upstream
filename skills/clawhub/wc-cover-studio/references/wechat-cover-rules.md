# 公众号封面生成 · 核心规则库

## 1. 微信封面机制（为什么必须这样设计）

公众号后台**只能上传一张封面图**，但系统会自动裁出两种展示：

| 展示位置 | 比例 | 裁切方式 |
|---|---|---|
| 头条大图（消息卡片） | 2.35:1 (900×383) | **整张显示**，不裁切 |
| 分享给好友/朋友圈缩略图 | 1:1 方图 | **默认取图片正中央的 1:1 区域** |

**推论（最重要的设计原则）**：
> 主体 + 标题等关键信息，必须放在**正中央 383×383 方区**内。
> 两侧 258px 区域只放氛围背景（暗色/模糊延伸），确保分享方图裁切后信息不丢。

这就是「单图双用」版式：900×383 画布 = 中央 383×383 安全区 + 左右各 258px 延伸区。

## 2. 完整工作流

```
① 读文章 → 提取发布信息（标题候选/摘要/封面建议）
② 定风格 → 从风格库选（见第 3 节）
③ 生成 1:1 主图（ImageGen）→ 提示词要求主体居中、上下留安全区
④ 后处理 → 运行 scripts/make_cover.py（PIL 叠字 + 三种版式 + QA）
⑤ 交付 → 横版(900×383) + 方版(1080×1080) + 单图双用(900×383)
```

**关键约束**：
- 主图必须是 **1:1**（ImageGen size=1024×1024），且主体集中在**中部 40% 高度带**
- 生成时在提示词里明确"upper third clean empty space reserved for title"
- **长中文标题（≥6 字）禁止让图像模型渲染**——用 PIL + 系统字体叠加，100% 无错字
- 短标签（2-5 字）可以让图像模型渲染（归藏材质 Skill 已验证稳定）

## 3.5 行业专属意象库（通用方法论 · 最重要的一节）

**原则：每个领域都有自己的"专属符号"——使用它们，避开"泛化符号"。**

泛化符号（道家风水的阴阳图、纯装饰的祥云、通用齿轮等）不属于任何行业，会稀释专业感甚至误导读者。专属符号（该领域的工具、文物、标志性物件）一眼可识别，读者扫到封面就知道在讲什么领域。

**意象选择三步法**：
1. **列候选**：该领域最经典的工具/文物/标志性物件 3-5 个
2. **验证专属**：这个符号是否"只有"该领域在用？如果不是（如阴阳图、爱心、星星），淘汰
3. **材质对比**：与对比方形成材质反差（青铜 vs 白卡、金属 vs 木头）更抓眼

**常用行业意象速查表**：

| 领域 | ✅ 专属符号（优先） | ❌ 泛化符号（避开） | 备注 |
|---|---|---|---|
| 中医 | 针灸铜人、药葫芦、戥子、草药、脉诊手势、经络图 | 阴阳图/太极图（道家符号）、祥云、香炉 | 针灸铜人=北宋王惟一铸，中医最经典标志 |
| 金融/投资 | K线图、天平、账本、算盘、金库 | 金币堆、美元符号 | 算盘=东方金融专属 |
| 教育/考试 | 黑板、粉笔、课本、课桌、毕业帽 | 星星、灯泡（太泛） | — |
| 科技/AI | 芯片、电路板、服务器机架、终端屏、神经网络节点 | 齿轮（通用机械感）、闪电 | 引擎块+发光核心传达"智能" |
| 医疗(西医) | 听诊器、化验单、注射器、显微镜、心电图 | 红丝带（公益而非医疗）、红十字（机构标志慎用） | 化验单+箭头+对勾="一指标一结论" |
| 电商/物流 | 购物车、包裹、纸箱、条形码、货车 | 钱袋 | — |
| 农业/食品 | 稻穗、麦穗、陶罐、菜篮、灶台 | 绿叶（太泛） | — |
| 法律/合规 | 法典、天平、印章、卷宗 | 法槌（仅法庭场景） | 天平在金融和法律都可用，注意上下文 |
| 建筑/工程 | 蓝图、安全帽、水平仪、脚手架 | 砖墙纹理 | — |
| 历史/人文 | 古籍、毛笔、印章、罗盘、青铜器 | 兵马俑（过于具体） | 按时代选文物，先查参考 |

**冷门概念查参考**：遇到不确定的行业符号/品牌/科学装置，先搜索参考信息（视觉线索：轮廓、配色惯例、标志性形状），再转成所选风格。参考只用于画对，不用于抄画风。

**测试过的对比组合**（中西医封面实测）：
- 西医侧：白卡化验单 + 血糖仪 + 直线箭头 + 蓝色对勾（一个指标=一个结论）
- 中医侧：青铜针灸铜人 + 药葫芦 + 草药 + 戥子（多症状=一个证型）
- 效果：白 vs 铜材质对比，天然传达"两种体系"张力

## 4. 提示词模板（ImageGen 1:1 主图）

```text
Use case: stylized-concept
Asset type: 1:1 square labeled material illustration for a WeChat article cover about [主题]
Primary request: [场景描述：物件、空间关系、隐喻]
Chinese labels: [如需要短标签，列 2-5 字标签+指定方位，强调 ALL N MUST appear]
Style/medium: [从风格库选]
Composition/framing: square 1:1 composition, subject fills the lower two thirds, centered horizontally,
  upper third reserved as clean empty background for title overlay, generous safe margins, no crop
Lighting/mood: [氛围]
Constraints: no words beyond the specified labels, no English, no logo, no watermark,
  upper third must stay clean and empty of any objects or text
```

**多标签防漏技巧**（实测经验）：
- 5 个标签时容易漏渲染 1 个 → 必须写 "ALL FIVE ... MUST appear, no exceptions, no omissions"
- 给每个标签指定**具体方位**（above-left / directly above / below / above-right）
- 用 "clean white callout plate" 让标签独立成块，可读性+渲染稳定性都提升

## 5. 标题叠加规范（PIL）

| 参数 | 深夜深色背景 | 浅色背景 |
|---|---|---|
| 主标题字体 | msyhbd.ttc 粗体 76-82px | 同左 |
| 主标题颜色 | 暖白 (255,240,215) | 深灰 (30,32,35) |
| 副标题 | msyh.ttc 34-36px，琥珀 (255,210,150) | 灰 (110,115,120) |
| 描边 | 深色描边增强可读性（横版必备） | 白色描边 |

- 方版标题放上部留白区（y ≈ 0.11×H）
- 横版标题放**左上角**（避免遮挡中央主体）
- 单图双用版标题放**中央方区顶部**（y 18-110）

## 6. 程序化 QA（无读图能力时验证渲染）

| 检查项 | 方法 | 阈值 |
|---|---|---|
| 标题是否渲染 | 标题区域浅色像素计数（r>230 且 g>210） | >400 通过 |
| 主体是否在中央 | 中央方区暖色像素网格统计（r>120 且 r>g+30） | 显著 >0 |
| 深夜氛围 | 四角/上下采样应为深蓝黑 (r+g+b<200) | 通过 |
| 顶部留白 | 上方采样应为纯白/纯暗（无杂物） | 通过 |
| 背景色提取 | img.getpixel() 采样四角 → 用于扩展填充色 | — |
