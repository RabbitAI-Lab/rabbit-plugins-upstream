# 本工作区的长期偏好

这是接收者的空白偏好起点，不含作者的私人制作历史。

- 采用“素材＋描述 → 实际审阅/时间线 → 分镜 → 粗剪确认 → 精剪及逐镜检查 → 成片、封面、短文案 → 确认锁定”。
- 视觉起点为照片01斜落轻放、艺术字B立体贴纸、文字页C静态笔刷；按题材适配，普通字幕稳定，不遮主体。
- 音乐服务故事，对白和原声清楚；首次制作建立本用户基准。只有明确要求减30%才对所指BGM分轨乘0.70，已接受音轨不再累计降低。
- 关键词与画面对齐，照片叠加时背景保持播放，有意义留白，按情绪选择防抖，局部修改保护后续位置。
- 重复题材递进蒙太奇只在当前作品明确要求后使用，不默认沿用到下一作品。
- 完整连续观看、完整实际试听与程序检查独立记录；确认后不自动返工、发布或删除。

以后只有本用户明确要求保存的长期偏好才补充到这里。单片事实与特定裁切/时间/音色放对应作品中。
