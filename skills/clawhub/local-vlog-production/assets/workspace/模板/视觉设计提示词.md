# 可选设计提示词

使用接收者实际可用的图像生成工具。每次仅提交已授权的必要参考图，保存提示词与真实输出；不承诺离线或免费。没有图像生成工具时可使用用户提供的设计图，或交付简单静态排版并说明差异。

## C文字页
为当前作品制作一张9:16静态叙事文字页。炭黑纸感/森林纹理底，米白与少量亮黄笔刷字，大小层级清晰，每页一个重点。装饰为抽象山形树影，不冒充真实地理。下方四分之一留给字幕和署名。准确写入【本片文字】，无多余文字，不包含人物。生成后逐字核对、检查实际尺寸；不要从多页风格板直接裁一页投入成片。

## 发布封面
以本片经用户确认的真实核心照片为底，保留人物身份与真实环境。按发布平台构图，以裁切和设计文字减少朋友完整面孔，避开主角面部。艺术字有笔刷层级、描边与阴影，文字为【标题】。不要改写山形、动物形态或成绩，不将示例主题带入本片。生成后与原图对比，不把美化后的图用于证明实拍细节。
