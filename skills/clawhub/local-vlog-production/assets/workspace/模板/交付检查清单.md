# 新作品执行与交付检查单

从公共模板复制到新作品，按实际完成情况勾选；未做的检查写明，不预勾选。

- [ ] 读取长期记忆、WORKFLOW和作品状态，保存本次描述，确定主题/平台。
- [ ] 盘点素材、元数据与关联文件，恢复时间线并记录不确定性。
- [ ] 实际看照片、审阅候选视频，记录原声/对白、身份及构图风险。
- [ ] 输出故事结构、逐镜分镜和需要的旁白稿。
- [ ] 关键主体/动作与对白关键词对齐，前景照片和背景视频均匹配；内容或时长修订同步核对声音与字幕。
- [ ] 普通对白后的约2–3秒余量按叙事评估，无无意义拖尾；有价值的自然声、动作、风景或情绪留白可延长。
- [ ] 照片与当前叙事相关，照片入场/停留/退场时背景视频持续播放；有意定格与全屏照片例外已注明。
- [ ] 若使用重复题材的递进蒙太奇，记录当前作品用户明确要求及使用范围；未明确要求则不启用并记“不适用”，普通照片入场不受此限制。
- [ ] 完成粗剪，确认结构、节奏、配乐/原声、旁白、主要字体；记录用户确认版本。
- [ ] BGM从合适乐句进入；与已接受参考可比后定音量，只控制BGM，避免重复减30%。
- [ ] 有对白时音乐平滑避让，关键原声保留，已确认音轨不因纯视觉修改重调。
- [ ] 逐镜检查曝光/白平衡/色彩衔接，按叙事情绪决定是否防抖；检查裁切/边缘/运动，保留有叙事价值的自然手持，变差则撤回。
- [ ] 普通字幕稳定清楚；重要节点按需设计艺术字及轻晃/弹入/回弹，不挡主体。
- [ ] 局部修订前后核对已确认的后续照片、章节、声音和字幕时点；确需改总时长时同步调整并记录影响，不用无意义拖尾凑时长。
- [ ] 程序检查与实际看图分别记录，缓存/ASR/指标不替代观看或试听。
- [ ] 最终导出版本完整连续观看，记录版本、实际覆盖区间、问题与复查结果；未完成或仅抽查如实注明。
- [ ] 最终导出版本完整实际试听，记录版本、实际覆盖区间、问题与复查结果；未完成或仅抽查如实注明，能力受限时在交付中列出限制。
- [ ] 输出版本化成片、净版、字幕、封面、短文案、检查报告与工程记录。
- [ ] 封面确认主体，裁剪/字块处理朋友出镜；标题文案简短、事实可靠。
- [ ] 用户确认后锁定，不自动追加加工、发布或删除；更新状态和修改记录。
