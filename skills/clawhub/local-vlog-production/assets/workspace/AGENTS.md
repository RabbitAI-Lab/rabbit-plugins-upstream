# 本地 Vlog 工具包工作区

本目录是可移动的影像工作区，所有路径以这里为根。只在本工作区的影像制作任务中使用这些规则。

- 先读 `使用指南.md`、`WORKFLOW.md`、`长期记忆.md`、`workspace_config.json`、`workspace_state.json`、`capability_report.md`；续作读对应作品的 brief.md、notes.md、state.json、decisions.md。
- 制作任务使用已安装的 `local-vlog-production` 技能；安装位置以当前Agent提供的技能路径为准，未自动发现时由用户指定其 `SKILL.md` 路径，不反复索要已经给出的授权。
- 原始素材入口 `素材/`，直接子目录定义主题；只读，不移动归类，不追随链接，不把私人数据提交 Git、打包或批量上传。
- 先审阅和整理拍摄时间线，再分镜、粗剪确认、精剪及检查、封面短文案、用户确认锁定。没有强制样片确认门。
- 递进蒙太奇默认不启用，仅当前作品明确要求后生效；普通照片入场不受此限制。
- 声音以当前用户确认结果为基准；纯视觉修订不累计减 BGM。不要假定作者的私人混音、角色音色或 AI 服务可用。
- 生成缓存、ASR、程序检查、实际看图、完整连续观看与完整试听分别记录；未执行不写通过。
- 工具只执行明确时间线；Codex负责审阅、分镜、构图、音画对应及质量判断。锁定、发布和删除是不同动作，不自动发布或清理。
- 初次使用先检查环境。分享前只复制工具/模板/技能，不复制使用过程中新增的私人数据。
