# 工具命令

所有命令从工具包根目录运行。`--root` 是工作区根目录，省略时使用脚本所在工具包的根目录，不依赖终端当前目录。Python 需为 3.10 或更新版本。照片解码依赖 Pillow；FFmpeg/ffprobe 需已安装并在 PATH 中，或在工作区配置中指定。原片不改写，输出不能在素材目录中；已有文件、已有作品及已有输出目录都拒绝覆盖，请递增版本号。

先安装核心依赖；建议在自己的 Python 虚拟环境中执行，FFmpeg 仍需单独准备：

```powershell
python -m pip install -r requirements-core.txt
```

```powershell
python tools/workspace.py doctor
python tools/workspace.py topics
```

若使用另一处工作区，`--root` 写在子命令前：

```powershell
python tools/workspace.py --root "D:/我的Vlog工作区" doctor
```

## 配置工具路径

`workspace_config.json` 的 `executables` 支持程序名、相对于工作区的路径、绝对路径。可新建 `environment.local.json` 仅覆盖本机程序位置；不要把本机路径加入分享包。例如使用自己的便携 FFmpeg：

```json
{
  "executables": {
    "ffmpeg": "tools/vendor/ffmpeg/bin/ffmpeg.exe",
    "ffprobe": "tools/vendor/ffmpeg/bin/ffprobe.exe",
    "exiftool": null
  }
}
```

`null` 会回退到 PATH 查找同名程序。ExifTool 是可选环境检查项；当前盘点脚本使用 Pillow 提取照片 EXIF，使用 ffprobe 探测媒体，不调用 ExifTool 批量提取。

`doctor` 检查 FFmpeg、ffprobe、可选 ExifTool、Pillow、NumPy、可选 faster-whisper，并用合成黑帧实际测试一次 libx264 编码。报告写到配置的日志目录（默认 `工作数据/日志/doctor_时间.json`）。`ready_for_inventory_and_contacts` 表示基础盘点/抽帧依赖齐全；`ready_for_rendering` 额外要求 NumPy，仅表示基础环境条件，不是渲染器端到端验证。它不下载依赖，也不证明真实素材解码、GPU 编码、字幕烧录、ASR 推理、阅片或试听已完成。所需基础工具缺失时退出码为 1，可选 ExifTool 或 faster-whisper 缺失不会阻止基础能力通过。

## 创建作品

先自行建立 `素材/主题一/` 等主题并放入素材，再准备 UTF-8 文字说明文件：

```powershell
python tools/workspace.py new "新作品" --themes "主题一" "主题二" --brief "作品描述.txt"
```

`--brief` 是用户明确指定的文件，按终端当前目录解释相对路径，也可以给绝对路径。素材主题必须是素材目录中真实存在的直接子目录。拒绝路径穿越、符号链接和 Windows 目录联接；不创建主题、不复制原片、不遍历其他私人目录。

输出为 `作品/新作品/`，含 `brief.md`、`notes.md`、`decisions.md`、`state.json`、`project_config.json`、`asset_usage.json`、复制的 `交付检查清单.md` 和公共样式快照 `style.json`，以及 `00_input`、`01_analysis`、`02_story`、`03_edit`、`04_review`、`05_exports`、`logs`。只建立结构，阶段仍是输入，审阅、粗剪批准和最终锁定均未完成。

## 盘点指定主题

```powershell
python tools/media.py inventory --themes "主题一" "主题二" --out "工作数据/索引/素材清单_v001.json"
```

脚本只递归这些主题。每条清单包含工作区相对路径、主题、`asset_id`、文件大小、完整 SHA256、分类（`images` / `videos` / `companions`）、ffprobe 信息、可读取的照片 EXIF、同名伴随候选、时间候选和错误。未知扩展名归入伴随文件，并不保证其用途已识别；同名关联只代表候选，不自动断定 Live Photo、代理或分段关系。RAW、HEIC 或厂商格式是否支持取决于本机解码器，不支持时明确记录错误。

`asset_id` 取工作区相对路径的 SHA256 前 20 个十六进制字符并加前缀 A：整包移动后保持稳定，重命名或移动素材会得到新 ID。文件内容完整 SHA256 用于检查内容变化和辅助查重；脚本不删除重复文件。

EXIF、媒体 `creation_time` 和文件名 `YYYYMMDD_HHMMSS` / `YYYYMMDD-HHMMSS` 仅作为未核实候选。不会把文件修改时间当作拍摄时间，不自动加时区偏移、不猜日期；`selected_capture_time` 保持空值，供后续结合画面与描述确认。所有审阅标记为 `false`。

盘点个别文件失败仍保存其他结果，退出码为 2，并显示 `assets_with_errors` / `scan_errors`；应打开清单查看具体错误。链接和特殊文件被跳过并登记，不追随读取。完整指纹计算会顺序读取文件，大素材盘点耗时可能较长。

## 生成缩略图和视频联系表

```powershell
python tools/media.py contacts --manifest "工作数据/索引/素材清单_v001.json" --out "工作数据/缓存/联系表_v001" --samples 5
```

输出包括每张照片的缩略图、每个视频默认 5 个均匀位置的实际解码帧、分页 `contact_001.jpg` 等联系表，以及 `contacts.json` 和逐帧 FFmpeg 日志。`--samples` 范围为 1–30；时长未知时只尝试片头，并明确报告覆盖不足。照片按 EXIF 方向生成缩略图，原文件不变。联系表以稳定素材 ID 标注，中文文件名可在清单中查找，避免依赖系统中文字体。

`requested_seek_seconds` 是输入寻址请求；`decoded_pts_seconds` 仅在 FFmpeg `showinfo` 返回实际解码 PTS 时填写，并保存原始命令与日志。PTS 是原流时间戳，可能不从零开始；无 PTS 时保留空值，不将请求时间冒充精确取帧时间。概览抽帧数量不代表细致审阅覆盖，需要针对动作和对白另行补看。

此命令还会核对盘点时的素材指纹，发生内容变化时停止处理该素材并记录错误。概览图不做 HDR tone mapping 或逐镜调色，HDR 素材可能显示不正确的亮度/颜色，不能据此确认调色。产生图片不等于实际看图，更不等于连续看完视频；`images_viewed`、`video_frames_viewed`、`motion_watched`、`audio_listened` 全部保持 `false`。个别失败保存到报告，退出码为 2。

## 可选：使用已有本地模型转写

基础安装不包含 ASR 模型或 faster-whisper。需自行安装可选依赖，并准备完整的 faster-whisper / CTranslate2 模型目录；至少必须有 `model.bin`、`config.json`、`tokenizer.json`。本工具不接收远程模型名，不自动下载模型或 tokenizer，执行时设置离线模式。

```powershell
python -m pip install -r requirements-asr.txt
python tools/transcribe.py --input "素材/主题一/片段.mp4" --model "models/本地模型" --out "作品/新作品/01_analysis/ASR_v001" --language zh
```

`--input` 必须是工作区内的一个音频或视频文件；`--model` 相对路径以工作区为基准，也可显式给本地绝对路径。默认 `--device cpu --compute-type int8`；可根据已安装环境选择 `--device cuda` 等参数，GPU 是否可用需实际验证。`--language auto` 自动判断语言；`--vad-filter` 可选开启 VAD，默认关闭。

输出 `transcript.json` 和机器初稿 `transcript.srt`；记录每段时间、文本、模型置信相关数值和 `not_listened`。ASR 不是试听，不保证对白正确，风声、音乐和静音都可能产生错误；必须实际听音核对后才能当作最终字幕。转写失败时可能保留 `failed_partial_transcription` JSON，重跑需换新输出目录。工具包交付时不包含私人音频或模型；制作时仅用合成音频验证过此入口，接收者的模型环境和真实语音准确率仍需另行验证。

## 边界与状态

- 这三个脚本提供结构、盘点、概览和可选转写，不是通用自动剪片渲染器。分镜、剪辑、裁切、音量、字幕与封面需按实际素材继续制作。
- `--out` 相对路径均以工作区为基准，所有输出必须位于该工作区且不在素材目录。原片与旧版本只读，不支持 `--force` 覆盖。
- 正常退出码为 0；参数、路径、缺少必要依赖等阻断错误为 1；盘点/抽帧保留了结果但存在局部错误时为 2。成功生成不代表用户批准、锁定或发布。
- 工具不自动更改作品状态中的审阅或批准，不上传、发布、删除原片。实际看图、连续观看、试听、确认版本，应按交付检查清单由执行者如实记录。

## 可重跑合成自检

```powershell
python tests/test_workspace.py
```

也可以显式指定程序路径：

```powershell
python tests/test_workspace.py --ffmpeg "tools/vendor/ffmpeg/bin/ffmpeg.exe" --ffprobe "tools/vendor/ffmpeg/bin/ffprobe.exe"
```

自检在当前包配置的缓存目录内新建隔离工作区，只生成合成照片与视频，检查建作品、盘点、真实 PTS 抽帧、覆盖/越界/素材写入拒绝、原件不变及缺模型报错。它不运行 ASR 模型推理，也不做连续观看或试听。结果写入该隔离目录的 `test_report.json`，测试目录保留，不自动删除任何用户目录；其中的临时环境配置可能含执行机器路径，不应加入分享包。
