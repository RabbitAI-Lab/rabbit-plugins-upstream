# 提示词示例

下面的主题、作品名和版本号都是示例。替换成自己的实际信息即可；你也可以直接用自然语言描述，不必严格按模板说话。

## 第一次打开工具包

```text
请读取根目录 AGENTS.md、使用指南.md 和项目级 local-vlog-production 技能。
检查当前电脑能否运行本工具包，记录依赖和字体的实际结果。
配置中文字体后用 tools/make_demo.py 在本机生成合成演示，验证盘点、渲染和程序检查，说明哪些项目仍需人工观看或听音。
不要扫描工作区之外的私人目录，不启用付费服务。
```

## 开始新作品，先看分镜

```text
用“周末散步”和“路边小店”两个主题，新建作品“一个慢下来的下午”。
做一条竖屏 Vlog，讲清楚从出门、途中停留到回家的过程，风格自然、有生活感。
保留有意思的原声，重要互动别剪得太快，画面不足时不要编造经历。
先盘点并实际查看素材，恢复有依据的时间线，写出分镜和旁白建议。
这次先停在分镜，等我看完再做粗剪。
```

只有素材真实支持的内容才应进入分镜。示例故事不是已发生事实，旁白也不应被写成未经确认的回忆。

## 直接推进到粗剪

```text
用“周末散步”主题做一条自然轻松的短 Vlog，作品名叫“周末散步”。
先实际审阅，给我可查看的素材说明和分镜；没有影响故事的事实疑点时继续做粗剪。
照片按内容决定停留时间，重点字可以少量用立体贴纸风格，普通字幕保持稳定。
这次不需要额外制作风格对比样片。粗剪完成后停下来让我确认。
```

## 指明主角与隐私

```text
主角是我：我在这些素材里穿蓝色外套、背灰色背包。
这是本次我提供的身份线索；遇到看不清或有相同穿着的人请标为不确定。
视频可以保留朋友参与互动的画面，封面尽量通过裁剪或文字设计避开朋友完整面部。
车牌、聊天内容和家庭地址不要进入公开交付。
```

## 确认粗剪后精剪

```text
我确认“周末散步”粗剪 v001 的故事、选材、顺序和时长。
继续精剪，逐镜检查构图、颜色和字幕，只对确实需要的片段防抖。
保留重要现场声；音乐与旁白的关系按我已接受的版本保持。
给我带字幕成片、净版、字幕文件、封面、简短发布文案和实际检查记录。
没有完成的连续观看或实际听音要明确列出，不写成已通过。
```

## 第一次建立音乐基准

```text
我已把这次允许使用的音乐和来源说明放入公共资源。
请按故事选合适片段，按乐句处理前奏和淡入淡出，旁白与重要现场声优先清楚。
先给我一个可试听的混音版本，记录音乐分轨和处理参数。
这次建立我自己的音乐音量基准，不引用包外任何人的历史混音。
```

## 精确降低 BGM

```text
以“周末散步”v002 当前音乐分轨为基准，把 BGM 降低 30%，即该分轨乘 0.70。
旁白和原声保持不变，输出新版本并记录所用基准。
以后纯视觉修订沿用这次调整，不要再次累计降低。
```

如果当前只有混在一起的声音，没有可分离的音乐轨道，Codex 应先说明限制，不能声称只降低了其中的 BGM。

## 使用照片入场和重点字

```text
00:20 附近讲到合影时，让对应照片按“照片 01 斜落轻放”进入。
背景视频继续自然播放并保持清晰，照片落位后留足阅读时间，避开人物脸部和字幕。
“终于见面”作为重点艺术字，使用 B 立体贴纸的短暂入场和轻回弹，之后稳定。
不要让普通字幕或整个画面持续晃动。保留后续已确认的时点和音轨。
```

## 独立文字页

```text
在这一章结尾加一页 C 运动笔刷风格文字页，只写我已经确认的这句话。
使用清楚的字号层级，默认静态阅读，预留底部字幕空间。
它是叙事文字页，不要把装饰山形或纹理当作真实路线与拍摄证据。
```

## 当前作品明确启用递进蒙太奇

```text
这条作品明确采用递进蒙太奇：把同一主题的几次拍摄按远景、细节、人物反应逐步展开。
每次出现都要增加信息，保留实际来源；如果跨了拍摄时段，不要假装是连续发生的过程。
仅在这条作品中启用，不自动应用到以后其他作品。
```

普通的“帮我优化故事”或“多用几张照片”不会自动启用这项手法。

## 局部修改并保护后续位置

```text
继续“周末散步”v003，只修改 00:35–00:42 这一段的照片和标题。
先列出受影响的镜头与声音，尽量在原时段内完成，保留后续章节和字幕位置。
如果确实需要改总时长，统一调整相关画面、字幕、旁白、原声和音乐并复查同步。
保留旧版，输出 v004，不覆盖原片。
```

## 重新进入未完成作品

```text
继续作品“周末散步”。先读取 brief.md、notes.md、state.json、decisions.md 和最新检查记录。
告诉我当前实际完成到哪一步，区分已生成、已审阅和已确认。
按已有授权继续剩余工作，不把历史待办当成新确认要求。
```

## 确认完成并锁定

```text
我确认“周末散步”成片 v004 与封面 v002 完成，请记录并锁定这些版本。
没有我的新要求，不再加工，不自动发布，不删除原片或旧工程。
实际没有执行过的检查保留原记录，不因为我接受作品而改写成通过。
```

## 整理缓存

```text
请检查“周末散步”的抽帧和代理缓存，列出可以重建的文件、空间大小与其他作品引用情况。
保留原片、唯一工程、已确认成片和无法重建的设计资源。
这次先给我明确的清理清单与影响说明，再按我后续指定的范围处理。
```

上述最后一段特意要求先列清单，不构成删除授权。需要执行删除时，另行明确目标范围和已了解的后果。
