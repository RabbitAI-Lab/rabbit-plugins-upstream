# 迁移边界与隐私

本包迁移的是制作方法、通用工具、样式起点和空白记录结构。使用者要提供自己的素材、故事、音乐许可和声音偏好。

## 1. 可以随包带走什么

- 项目级 `local-vlog-production` 技能及视觉参数说明。
- 通用工作流、配置起点、作品模板与检查清单。
- 经过适配的工作区管理、媒体处理和 JSON 时间线渲染脚本。
- 生成本机合成演示的代码及示例时间线。
- 字体不随ClawHub包分发，需从原作者处另行取得并保留许可；详情见 [第三方声明](../THIRD_PARTY_NOTICES.md)。

原工作区中用于某一条作品的脚本可能包含素材、裁切、时间点和输出目录的硬编码。它们不会因为放入技能文件夹就自动成为通用工具。新作品只应使用本包的可移植入口，或由 Codex 先读代码、移除具体作品依赖并完成验证。

## 2. 本包不包含什么

- 原制作者的照片、视频、原声、转写、私人描述、人物身份和历史作品。
- 历史音乐分轨、私人混音基准、个人声音或声音克隆模型。
- 配乐文件、商业歌曲、购买的模板和第三方账号凭据。
- Python、FFmpeg 二进制、ASR 模型与机器专用虚拟环境。
- 剪映、Premiere、Resolve 原生工程或第三方平台发布权限。

“相同视觉起点”不等于“复刻某条私人作品”。字体和绘制方式可以复用，人物、地点、经历、音乐以及历史确认不能代替新使用者的选择。

## 3. 推荐迁移方式

ClawHub安装得到完整技能目录，再通过其中 `scripts/init_workspace.py` 创建独立工作区。工具、模板和配置复制进入工作区；字体由用户明确提供。技能更新与作品继续制作分开，不能用重新初始化覆盖已有工作区。

Codex可通过项目级 `.agents/skills/` 发现技能，也可在请求中明确指定已安装技能路径。技能安装目录不存放用户素材。首次安装或移动到另一台电脑后，更新工具路径并重新运行环境检查与本地合成示例。

迁移已有作品时，还需要保留该作品实际引用的素材、字体、设计资源、音频及其许可记录。将本机工具路径改成目标电脑的有效路径；外部素材路径也要检查。只留下 MP4 和时间线 JSON，不能恢复缺失的原片或完整编辑能力。

版本 1.0.0 主要在 Windows 环境验证。其他系统的目录分隔符、可执行文件名、字体渲染与依赖安装方式可能不同；可迁移不等于已经在所有系统测试通过。GPU 不是基本运行要求。

## 4. 哪些处理留在本地

包内 Python/FFmpeg 素材盘点、抽帧和渲染在当前电脑处理文件；配置本地模型的语音转写可以在本机完成。下载依赖或模型本身需要网络，但不应因此上传素材。

**使用 Codex 看图或分析内容时，不应宣称整个流程完全离线。** 模型会按当前产品、账户和工具的能力接收会话内容。不要把“文件在电脑上”理解成“任何环节都不会与在线服务交互”。

需要在线 TTS 时，发送的是该次选择的文本；需要内置图像生成或编辑时，只提供完成当前任务所必需的提示词和参考图。是否启用这些能力应遵循本次任务的授权与当前服务设置。本包不会自动开通付费接口，也不把原始素材集上传第三方分析服务。

## 5. 扫描与原片保护

只读取用户本次指定的主题及明确提供的外部文件。不追随素材目录中的符号链接或目录联接，不顺着路径探查无关私人目录。

原片制作期间只读。裁剪、调色、防抖、转写和抽帧结果保存在派生文件或作品目录，不写回原片。目录中可能含有人脸、声音、定位、拍摄时间、车牌和聊天信息；公开封面、字幕及短文案也要检查这些内容。

照片、视频、转写、素材索引、作品描述和生成缓存都可能包含私人信息。不要提交到 Git、上传公共仓库或随工具包再次分享。再次分发工具包前应从干净模板或明确筛选的文件建立发布包，而不是直接压缩已经做过作品的整个工作目录。

## 6. 音乐、字体与配音

字体按各自许可使用并保留许可文本。本包不提供音乐授权；用户自行添加音乐后，应记录来源、可用范围和需要的署名。文件能下载、能播放不等于允许在目标平台公开发布。

首次使用音乐，需要试听并确认自己的基准。历史作品的听感、分轨、音色和确认记录未迁移，因此不能宣称复刻原始混音。之后调低 BGM 应绑定明确版本，只改对应分轨，不累计重复处理已接受音轨。

配音服务和音色按作品选择。不要把普通 TTS 的调音结果称为某个演员原声、他人的克隆声或未实际使用的专用模型。

## 7. 确认、发布与删除

粗剪确认、最终接受和锁定都应绑定具体作品与版本。选择一个样式不是接受整片；生成成功不是实际看完或听完；用户接受也不能把未执行的检查改成已通过。

导出后不自动发布，不自动删除原片或旧版。已锁定作品只有在用户提出新修改要求时才重新制作。

清理必须有明确范围，先检查跨作品引用、唯一文件和重渲染影响。Windows 下执行递归删除或移动前核对最终绝对路径在授权目录内，拒绝根目录和重解析点。只有确认可重建的文件才按缓存处理；原片、独有设计资源和唯一工程不是缓存。
