# 逐镜精修与声音处理

本工具包提取了可移动的工作区、审阅工具、时间线渲染与视觉效果。精剪仍由 Codex 根据实际素材作逐镜决策，以下环节不能被“渲染成功”代替。

## 保存原片与派生关系

每项处理先记录源素材 ID、源区间、方向、色彩信息和参数，把派生文件写到作品的 `03_edit` 或工作数据的预处理目录。不要覆盖原片。时间线引用派生文件时保留原片映射、处理目的及前后对照。

## 调色、HDR 和防抖

- 先用 ffprobe 确认颜色原色、传递函数、矩阵和范围。遇到 HLG/PQ/BT.2020 等超出本渲染器支持的输入时，先制定并验证向 SDR 的转换；不要靠写 BT.709 标签冒充实际转换。
- FFmpeg 的 `zscale`/`tonemap` 是否可用取决于接收者安装的构建。先检查本机滤镜帮助，结合源媒体的真实标签配置输入，不照抄其他设备的 HLG/PQ 假设。线性化、色域变换、亮度映射与输出传递函数各有作用；检查雪景高光、肤色、森林暗部和相邻镜头。
- 逐镜选择轻微曝光、白平衡、饱和度或对比度调整，避免整片统一强滤镜。调色只作用于实拍照片/视频层，不能把文字、相纸白边、证书或品牌图形一起改色。
- 先剪去严重模糊或无信息抖动。剩余镜头才试防抖，比较主体保留、裁切、边缘、运动和形变。平静赏景与紧张现场按叙事分别判断；不能固定“只防抖前半段”，也不能将自然手持一律消除。
- 若使用 `vidstabdetect`/`vidstabtransform` 两遍处理，确认本机支持并逐镜保存分析结果。小幅平移/旋转与裁切也需要实测。不要把某个镜头使用的缩放量、平滑窗口或角度上限写成所有素材默认值。

这些派生处理由 Codex 选用本机实际可用工具完成。工具包没有未经测试的“自动逐镜调色/防抖通过”按钮，也没有附带商业剪辑软件插件。

## 音轨与版本

先分清原声、旁白、音乐与已接受总混音。保留分轨、入点、音量、淡入淡出及音乐授权说明。没有用户自己的参考混音时，先建立本片听感基准；作者私人参考音轨不在包内。

去掉冗长前奏应从合适乐句切入，不固定裁去若干秒。对白期间用明确音量包络或经过试听的避让处理，使人声清楚，保留有价值的呼吸、脚步、互动等原声。音乐低不等于全片低；“减30%”仅在用户要求时对所指旧 BGM 分轨乘0.70，已接受音乐不反复降低。

纯视觉修改且时间线时长相同，优先使用渲染器的已接受 AAC 主音轨复制模式。除容器元数据以外，音频压缩数据与时间位置应保持；用包内集成测试示范的分包校验确认，而不只是看总时长相近。若删句、改变时长或新做混音，重新核对语音、画面、字幕及音乐节奏，不把修改过的混音标成原音轨逐字节沿用。

具体音轨字段和渲染器当前支持的混音范围见 `时间线格式.md`。复杂自动避让、角色配音、音效和第三方 TTS 都不是隐含能力；需要时建立本片工具与实际检查记录。技术电平、解码和 ASR 不能代替完整实际试听。

## 交付审阅

对齐关键词检查主体和背景，照片入场期间核对视频确实持续播放；检查图卡落位、全屏扩展、文字回弹后稳定、字幕区域和脸部避让。改动过的段落还要连同前后切点一起播放。

最终导出后做整片连续观看和完整实际试听，分别记录版本、范围、问题和复查。能力不足时，明确未执行项，交付其它已完成部分供用户查看。最终用户接受不改变未执行检查的历史事实，也不触发自动发布或删除。
