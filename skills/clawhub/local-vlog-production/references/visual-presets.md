# 已确认的 Vlog 视觉预设

本文件保存照片 01、画面艺术字 B、独立文字页 C 的可复用设计。工作区 `公共资源/style.default.json` 是可调起点；当前用户的具体要求优先。

## 照片 01：斜落轻放

照片像被轻放进正在播放的画面：由右上向落点斜入，轻透视与小角度旋转随运动减弱，自然减速。暖白纸边、细边线和柔软接触阴影提供层次。只柔化投影，不主动虚化或压暗背景视频；素材原有模糊不等于新增背景模糊。

先区分照片卡与全屏照片：

- 照片卡保留经审阅的长宽比，落位后保持清晰视频背景与稳定阅读时间。照片图层与背景视频分别计时，入场、停留、退场期间背景持续推进；不能把进入照片段落时的一帧误当整段背景。只有明确的定格设计或全屏照片接管画面才停止背景。
- 全屏照片先有同类摆入过程，落位后转正、放大到画布，边框离开屏幕。使用已审阅的全屏裁切，不能靠拉伸铺满，不留意外白条/黑边。卡片外框和照片实际边界不同，最后落位必须核对。
- 看过实际原图后才裁切放大主体；入场可略提前，提到主体的关键词出现时主体须清晰可见，不能让转场吞掉主要阅读时间。照片与当前叙事相关，叙述切换时同时核对背景视频，不在无关背景上只用照片遮盖。
- 同段多张照片可依次摆入，错开入场与阅读时间，避开主体和字幕；这类照片入场不自动启用跨时段的递进蒙太奇，后者遵循 SKILL.md 中的明确请求条件。

1080×1920、30fps 已用实现的可调起点：

| 项目 | 实现参考 |
|---|---|
| 入场 | 通常 0.65 秒，与前镜重叠；短照片连续段可 0.30–0.50 秒，文字页后可约 0.25 秒 |
| 缓动 | `e = 1 - (1-u)^3`，位置从 `(1080,530)` 到 `(540,930)`；新构图应重选落点 |
| 姿态 | scale `1.04→1`；pitch `−15°→0°`、yaw `7°→0°`、roll `7.5°→−1.2°` |
| 纸边 | 暖白 `#F6F4EE`；示例侧/上边 18px、下边 42px；横照片内宽 924px |
| 全屏扩展 | 初始基准缩放约 0.78；落位后用 0.22–0.32 秒转正并铺满 |
| 运动采样 | 可用 3 个子帧；自适应快门限制角点总位移约 5px，避免多重白边 |

这些是运动参数而非照片停留时长。约 1 秒用于快照片段；重要照片按叙事延长。将重叠按帧率量化并计入时间线。文字页到照片时，照片入场须叠在更新后的文字页上，避免页替换把动作盖掉。

可移植实现见工作区 `tools/vlog_effects.py` 与 `tools/render_timeline.py`，实际支持的字段见 `docs/时间线格式.md`。效果按当前画布缩放；重新指定素材、裁切、位置与时点，不沿用任何示例构图。

## 画面重点艺术字 B：立体贴纸

关键词独立分层，利用字号与错落角度形成层级，厚米白描边、深色细描边和暖色偏移厚度。参考字形为得意黑，实际字体取工作区 `公共资源/style.default.json` 中已配置的 `font_roles` / `font_candidates`；ClawHub包不带字体，确认可用文件与许可，不擅自安装系统字体。

参考配色：森林绿 `#214C41`、杏桃 `#EAAA7E`、米白 `#FFF7E5`、墨绿 `#14251F`、厚度阴影 `#AF765C`。配色服务题材，可调整；不要把绿色写成所有作品硬性要求。

参考动效：词组相隔约 0.12 秒递入；约 0.36 秒平滑减速，左右交替约 72px、上方约 26px 偏移，缩放回弹公式的振幅上限 7.5%；短衰减转角扰动，约 0.9 秒后完全稳定。进入时约 8° 动态角度叠加最终静态倾斜，正文常用最终 ±2–3°；符号可更活泼。数值按画布与内容缩放，长词组合理分行/缩字，不逐字扭曲。

艺术字动效只作用于艺术字图层，不带动普通字幕或实拍背景；原素材是否防抖按叙事情绪判断。稳定阅读占主要时间，不持续抖动。依据动作、语气或节拍安排，情绪沉静或伤痛段落降低强度。逐镜放置，避开人脸、动物、路线、关键动作和底部字幕区；检查阴影、描边与回弹的完整边界。

可移植实现见工作区 `tools/vlog_effects.py` 与 `tools/render_timeline.py`，实际支持的字段见 `docs/时间线格式.md`。效果按当前画布缩放；重新指定素材、裁切、位置与时点，不沿用任何示例构图。

## 独立文字页 C：运动笔刷

与画面艺术字 B 区别：C 是独立的深色叙事文字页，适用于章节、素材空缺的真实交代或收束。炭黑森林/纸感纹理，米白与荧光黄笔刷大字，明显字号对比，少量装饰山形/树影。装饰不冒充实际地形、轨迹或实拍证据。

当前已确认版是**静态阅读页**：自然切入，按段落停留；部分页面结束时由照片 01 入场接走。没有内部晃动或逐字笔刷动画，不能把视觉风格板或静态 PNG 记成已实现的页内动效。默认保留静态可读；只有新任务需要时再设计克制的入/出场，并实际检查后记录。

以 9:16 构图，保留底部字幕/署名空间，当前参考下方四分之一不放主文案。每页一句主信息，笔刷强弱与大小变化有层级，不只是在纯黑底堆字体。中文、标点、人名与事实逐项看图校对；检查实际输出尺寸、适配后的字形、边缘与字幕避让，不把请求的尺寸当生成尺寸。需要位图笔刷设计时调用内置 imagegen，保留提示词及输出；独立生成单页，不把三页对比板直接塞进成片。

每个作品自行保存文字页设计、提示词、输出及审阅证据。工具包提供 `模板/视觉设计提示词.md`；需要笔刷纹理页时用接收者可用的图像生成工具制作并逐字核对，再作为静态设计图输入。渲染器可以展示设计图，不等于自动生成同等完成度的笔刷纹理。

## 复用验证

新作品按实际素材调整后，核对入场开始/中段/落位/全屏完成、文字初入/回弹/稳定及照片和文字页衔接。检查字错、遮挡、边框重影、相邻帧跳变、裁切和关键词处的音画对齐；照片叠加段还需核对背景时间持续推进。局部修改后对照已确认的后续时点，避免照片或文字页缩短使后面的画面与声音意外错位。记录实际看过的帧与播放/试听覆盖；仅关键帧检查不能写成连续运动通过。纯视觉版保留已接受音频，音量和台词未获新指令不变更。用户已选预设时直接复用，无需每次再做 A/B/C 样片。
