# 本地 Vlog 制作 / Local Vlog Production

将照片、视频与文字描述整理成有故事的Vlog：实际审阅和时间线、分镜、粗剪确认、精剪、封面与短文案。包含照片斜落轻放、重点文字立体贴纸和静态运动笔刷文字页的制作规则，以及本地Python/FFmpeg工具。

安装后先读 [首次使用](references/first-run.md)。技能安装目录与素材工作区分开；初始化不会覆盖既有工作区。日常直接向Agent提供主题目录与故事描述，按分镜、粗剪、精剪阶段推进。

本发布版不附带字体、配乐、语音模型、真实素材或成片。字体可从原作者来源另行取得，按其OFL许可使用；不将第三方字体重许可为技能代码的许可。示例在本机生成，Windows以外平台尚需实际验证。
