# Medical Device QMS/GMP Documents / 医械质量体系 GMP 文档

## English

Generate and review medical-device GMP / ISO 13485 QMS documents: quality manual, procedure framework, process validation (IQ/OQ/PQ), reusable-device reprocessing validation, and sterilization qualification. Writing-assistance skill, no `scripts/`; entry point is `SKILL.md`. After generation, self-check with `medical-device-compliance-grader` C5 dimension.

## 中文

生成与核查医疗器械 GMP / ISO 13485 质量体系文档：质量手册、程序文件框架、工艺验证（IQ/OQ/PQ）、复用器械再处理验证、灭菌确认。编写辅助型技能，无 `scripts/`；入口为 `SKILL.md`。生成后建议用 `medical-device-compliance-grader` C5 维度自测。
