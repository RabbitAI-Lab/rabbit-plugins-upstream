## Description:

Guides agents working on Laravel applications with PHP 8.4 patterns for architecture, Eloquent, migrations, queues, and testing.

This skill is ready for commercial/non-commercial use.

## Publisher:

[iliaal](https://clawhub.ai/user/iliaal)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to implement and review framework-based PHP applications, including Laravel persistence, HTTP behavior, and tests. It is not intended for PHP internals or standalone libraries.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Following development guidance may lead an agent to inspect project code or run local validation commands in sensitive repositories.

Mitigation: Review proposed commands and their scope before execution, especially in sensitive repositories.
