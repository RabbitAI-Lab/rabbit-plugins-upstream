Developers and engineers use this skill when building, reviewing, or testing Laravel and framework-based PHP applications. It guides Laravel architecture, Eloquent persistence, queues, validation, feature tests, factories, mocking, performance, and common production pitfalls.

## Known Risks and Mitigations:

Risk: The skill may encourage running project-local Laravel, test, analysis, queue, or deployment-cache commands in repositories where those workflows are not expected.

Mitigation: Use it in Laravel or framework-based PHP repositories and review suggested commands before execution.

Risk: Generated coding guidance can affect application behavior, data migrations, queues, validation, or production deployment steps.

Mitigation: Validate changes through the project test suite, static analysis, migration checks, and Laravel entrypoints before release.
