## Description:

When explicitly invoked, helps design, specify, implement, review, refactor, or explain software using Daniel Jackson's concepts and synchronizations, checks CONCEPT.md/SYNCS.md structure, and generates Mermaid relationship diagrams.

This skill is ready for commercial/non-commercial use.

## Publisher:

[agenticweb4](https://clawhub.ai/user/agenticweb4)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use the skill to design and document software as independent concepts coordinated by synchronization rules. It can help produce specifications, diagrams, implementation guidance, and reviews grounded in the project's stated requirements.

### Deployment Geography for Use:

Global
