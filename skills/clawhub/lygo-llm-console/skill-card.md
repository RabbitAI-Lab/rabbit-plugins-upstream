## Description:

This skill is ready for commercial/non-commercial use.

## Use Case:

Operators and developers use this pointer to find LYGO LLM Console installers, guidance for a local GGUF setup, or the online API portal. The skill itself installs no runtime.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The linked console is a separate download and is not sandboxed.

Mitigation: Verify the publisher's SHA-256 and use official sources before running it; run as an unprivileged user and keep secrets and unrelated files outside its working folder.
