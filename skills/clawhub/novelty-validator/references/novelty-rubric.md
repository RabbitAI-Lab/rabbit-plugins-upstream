# 新颖性判定与报告 v1.3 / Novelty rubric & multi-agent workflow

> v1.3 核心升级：**从「关键词重叠」升到「结构化碰撞分级 + 多智能体对抗」**，对标 NTU×微软 IdeaSpark 的「Scoop-Check 4 维撞车等级 1–5」与 Novoscan 的「多智能体对抗（6 专家+辩论引擎）」。

## 一、Claim 四维拆解（Decomposition）

把会议讨论里抽出的 claim 拆成 4 个可独立比对的维度（每个维度单独检索、单独打分）：

| 维度 | 含义 | 检索侧重 |
|------|------|----------|
| **D1 Problem** | 研究问题 / 痛点 / 待解任务 | 问题关键词（K=问题） |
| **D2 Method** | 技术方法 / 架构 / 算法 / 模型 | 方法关键词（K=方法） |
| **D3 Data/Scene** | 数据 / 场景 / 领域 / 群体 | 领域词（K=领域） |
| **D4 Contribution** | 贡献类型：新模型 / 新理论 / 新应用 / 新数据集 / 新系统 | 贡献词（K=贡献） |

> 每个维度用 `api_path`（CN 主引擎，稳定）检索 1 次（≥1s 间隔防 433），取 top 候选合并去重。**Global 语义端点（`/search/global`）本轮实测返回空，已降级为可选次级，空返回绝不判新颖。**

## 一之二、向量召回精校（v1.5，位于检索与判定之间）

对合并去重后的候选池做语义相似度精校（完整方法见 `references/vector_recall.md`）：

- **三档实现**：A=`SILICONFLOW_API_KEY` 已设 → 真向量余弦（捕获改写近邻）；B=网关 Global 语义端点（当前空，自动回退）；**C=本地词重叠（离线兜底，无需密钥）**：`sim = 命中token数 / claim总token数`。
- **动作**：按 sim 降序重排；sim≥0.6 但关键词未命中的候选标「改写近邻，疑撞车」；sim 表喂给下方五级分级做阈值校准。
- **校准阈值**：sim≥0.6 推高（near-miss→L2）；0.3–0.6 维持部分重叠；<0.3 弱/无关。
- **防假阴性（最高优先级）**：**0 召回 或 全部候选 sim<0.3 → 一律「证据不足·结论降级」，禁止判 L5 新颖**。依据案例库 C1（扩散蛋白设计）、C2（LLM逆合成）实测 0 召回但属真实活跃方向，自动判 L5 即假阴性。

## 二、五级碰撞分级（Collision Level，对标 IdeaSpark 1–5）

| 级别 | 名称 | 四维命中规则 | 含义 |
|------|------|------------|------|
| **L1** | 被覆盖 / 重复 (Scooped) | D1+D2+D3+D4 全部高度重叠 | 已有工作完整覆盖，无新意 |
| **L2** | 高度相似 (Strong overlap) | 任意 3 维命中（如 问题+方法+数据） | 仅场景/细节差异，易被判撞车 |
| **L3** | 部分重叠 (Partial) | 任意 2 维命中 | 有实质重叠，需差异化论证 |
| **L4** | 相邻 (Adjacent) | 仅 1 维相关 | 方法论相关但问题/场景不同，可视为增量 |
| **L5** | 新颖 (Novel) | 0 维实质重叠 | 各维度均无重合，可切入 |

**重叠度辅助打分（每篇候选 0–5）**：5=四维全中；3=两维中；1=仅主题相邻；0=无关。用于 L1–L5 之间的置信度微调。

## 三、多智能体对抗工作流（Multi-agent，对标 Novoscan）

不是单程「检索→判定」，而是**角色互搏**后由仲裁者终裁：

```
[A 检索员 Retriever]  →  跑 CN+Global 双引擎，召回先验工作池（带可验证证据 v1.2）
        ↓
[B 怀疑者 Skeptic]    →  扮演模拟审稿人：逐篇论证「已被做」，列出重叠维度+证据链
        ↓  (辩论循环 ≤2 轮)
[C 辩护者 Defender]   →  扮演作者视角：逐条反驳，指出差异点（D? 未中）、可新颖空间
        ↓
[D 仲裁者 Adjudicator]→  综合 B/C 证据，按「四维×五级」给最终 Collision Level + 置信度
```

- **辩论循环**：B 与 C 至多互搏 2 轮；若 B 证据均被 C 反驳且 C 能指出 ≥2 个未命中维度 → 倾向 L4/L5；若 C 无法反驳 B 的 ≥3 维命中 → 倾向 L1/L2。
- **仲裁依据**：以「可验证证据」（摘要原文 + DOI + 链接）为硬证据，不以模型臆测为准。
- **降级规则**：若检索面覆盖不足（如某维度 0 召回且非因真无），标注「证据不足，结论降级」，绝不凭空判新颖。**最高优先级防假阴性**：整个 claim **0 召回 或 全部候选 sim<0.3**（见一之二 向量召回精校）→ 一律「证据不足·结论降级」，禁止判 L5 新颖；先换检索式放宽（单 K 词）→ 提示用户人工确认 / 待 Global 端点恢复后复检。

## 五、诚实边界（每条报告必带）
- 实时 = 转写切片/手动触发，非流式逐字。
- 新颖性 = 防重复，非保证绝对首创；L5 仅代表「本检索面内未见实质重叠」。
- 证据可溯（v1.2 摘要原文+DOI+链接），空白分支交用户取全文核验。
- 多智能体对抗是**结构化推理框架**，非独立运行进程；由主 agent 按本工作流分角色执行。
