# 向量召回精校 / Vector Recall Refinement — v1.5

> 解决 v1.4 已知缺口「语义深比对」：在关键词检索（CN `api_path`）召回候选池之后，增加一层**语义相似度精校**，用于重排序、捕获关键词漏检的**改写近邻（paraphrase near-miss）**、并把相似度分数喂给五级碰撞分级做阈值校准。

## 一、为什么需要这一层
- 关键词检索（K=方法 AND K=问题）只能命中**字面重叠**的先验；对「换了个说法但做的是同一件事」的改写先验（near-miss）会漏检 → 导致假阴性（误判新颖）。
- 纯判定准确度落后 OpenNovelty / IdeaSpark 的根因之一是缺大规模标注训练的语义匹配；向量召回精校是**无训练数据下的轻量替代**。

## 二、三档实现（按可用环境自动降级）
| 档位 | 条件 | 实现 | 精度 |
|------|------|------|------|
| **A · SiliconFlow 真向量** | **已实装**（用户已配 `SILICONFLOW_API_KEY`，2026-07-18 真机跑通 BAAI/bge-m3 1024 维） | 用 SiliconFlow 嵌入（BAAI/bge-m3）对 claim 与每篇候选摘要做向量化，余弦相似度 | 最高，可捕获改写近邻 |
| **B · 网关语义端点** | **v1.7 复测稳定，已恢复为主引擎之一** | 复用 global-biblio-base `/search/global` 的语义排序信号（`endpoint:/search/global`+`rule` 正确格式） | 中（跨语言语义信号可用） |
| **C · 本地词重叠（离线兜底）** | 始终可用，无需密钥 | 对 claim 的「方法/问题」关键 token 与候选标题+摘要做归一化命中率：`sim = 命中token数 / claim总token数` | 基础，可捕获术语级邻近 |

> **Tier A 真机实现**：见 `references/vector_recall_impl.py`——读 `SILICONFLOW_API_KEY`（env 优先 → 本技能 `config.json` 兜底），调 `https://api.siliconflow.cn/v1/embeddings`（模型 BAAI/bge-m3），对 claim 与候选 `title+desc` 做余弦，输出降序重排 + `near_miss` 标记。仅标准库（urllib/json/math），无第三方依赖，便于嵌入自动化。
>
> **发布安全**：打包发布时 `config.json`（含密钥）**不进发布包**，避免 key 泄露；使用者安装后自行 `export SILICONFLOW_API_KEY=...` 或在本机 `config.json` 填入自有 key 即可启用 A 档。
>
> 诚实边界：档位 C 是**无密钥环境也能跑**的离线近似，不是真向量；档位 A 才是语义深比对。技能必须**声明当前所用档位**于报告，不得假装 C 档等于 A 档。v1.6 起默认走 A 档（key 已配），仅当 key 缺失/失效时回退 C。

## 三、精校流程（位于主链路 ③ 与 ④ 之间）
```
③ 文献比对（CN api_path 召回候选池）
        │
  ③.5 向量召回精校（本文件）
        ├─ 对 top-K 候选计算 sim（按上表档位）
        ├─ 重排序：sim 降序
        ├─ near-miss 标记：sim≥0.6 但关键词未命中的候选 → 标「改写近邻，疑撞车」
        └─ 输出 sim 表喂给 ④ 碰撞分级
        │
  ④ 新颖性判定（多智能体对抗 + 五级分级，sim 参与阈值）
```

## 四、相似度 → 碰撞分级 校准阈值（v1.5，待案例库迭代调参）
| 候选 sim | 含义 | 对 Collision Level 的影响 |
|----------|------|---------------------------|
| **≥ 0.6** | 强重叠（含改写近邻） | 推高：命中维 → 至少 L2；near-miss 直接标 L2 |
| **0.3 – 0.6** | 部分重叠 | 维持：对应维记命中，走 L3/L4 |
| **< 0.3** | 弱/无关 | 该候选不计入重叠维；但**单一候选 <0.3 不=>新颖**（见下） |

## 五、与降级规则的配合（防假阴性，最高优先级）
- **0 召回 或 全部候选 sim<0.3** 的 claim：**一律「证据不足·结论降级」，禁止判 L5 新颖**。
  - 依据：案例库 C1（扩散蛋白设计）、C2（LLM逆合成）实测均为 0 召回/全 0 词重叠，但二者均为真实活跃方向 → 自动判 L5 即假阴性。
  - 正确动作：换检索式放宽（单 K 词）→ 提示用户人工确认 / 待 Global 端点恢复后复检。
- 此规则写入 `novelty-rubric.md` 降级规则第 2 条 + `SKILL.md` ③ 容错第 4 条。

## 六、真机取证
- **v1.5（档位 C 本地词重叠）**：6 案例跑通，见 `case_library.md`：C3/C6 出现 sim=1.0 直接命中（正确 L2），C1/C2 全 0（触发降级）。
- **v1.6（档位 A 真向量，2026-07-18）**：用户已配 `SILICONFLOW_API_KEY`，`references/vector_recall_impl.py` 真机跑通 BAAI/bge-m3（1024 维）。对 6 案例真实 CN 候选做余弦精校：
  - 标杆 L2（C3/C6）真向量 top ≥0.6（0.856 / 0.731）→ 稳健印证 L2；
  - C1 关键词全 0 但向量 0.44–0.539 → **揭示相邻文献存在**，把"0 召回假阴性"修正为"有相邻、无直接先验"，是向量相对纯关键词的核心增益（防假空缺）；
  - C2/C5 为 CN 0 候选 → 向量无候选可比，**诚实确认向量只精校召回池内、不补基础召回**；
  - 6 案例均未触发 near_miss（CN 候选本身关键词相关），该机制待跨语言/改写案例验证。
  - 详见 `case_library.md` 末尾「v1.6 真向量召回校准」表。
- Global 端点（档位 B）持续返回 0 条，已确认降级；档位 A 现为默认主档，仅 key 缺失/失效时回退 C。
