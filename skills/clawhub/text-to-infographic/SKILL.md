# Text to Infographic v1.1.3

将当前对话中的现有内容整理为精确、可复核的单页信息图结构。不会外部补充事实，也不会产生状态变更。

## 何时使用

仅在用户明确提出以下意图时调用：

- 生成一页信息图规格；
- 生成可复制的独立信息图 HTML；
- 把当前对话中已提供的内容组织为信息图布局。

不要用于普通摘要、数据收集、幻灯片、多页报告、图片编辑，或没有明确信息图规格/独立 HTML 意图的请求。

## 输入边界

- 只使用当前对话中用户已提供的源内容与约束。
- 可接收标题、阅读场景、尺寸、方向、密度、配色、字体、层级和无障碍要求。
- 可安排用户已提供的来源注记、署名和事实标签。
- 缺失的事实、数值、引用、素材和偏好保持未指定。
- 不读取文件，不联网研究、抓取或核验，不运行浏览器、渲染器、脚本或命令，不上传、发布、导入或写入外部状态。

## 输出契约

### 单页信息图规格

- 标题与可选副标题；
- 传播目标与预期阅读顺序；
- 章节层级及内容块；
- 每个内容块的合适视觉形式，如文本、指标、对比、序列、时间线、矩阵或图解；
- 布局、间距、颜色、字体和无障碍说明；
- 已提供来源注记或署名的放置建议；
- 每条展示性主张到用户已提供内容的简明对应清单。

### 独立 HTML 源码

仅在用户明确要求时输出：

- 以 `<!doctype html>` 开始的完整文档；
- 单个连续、可复制的源码块；
- 仅使用 HTML 与内联 CSS；
- 静态、自包含、无主动行为、无外部依赖；
- 语义结构和阅读顺序清晰，去除视觉样式后文本仍可读；
- 不仅依赖颜色传达信息；
- 用户提出打印约束时包含 print-safe 样式。

当前版本只返回规格或 HTML **源码**，不承诺写出 HTML 文件、PNG、PDF、Share Pack、evidence sidecar 或 adapter。

## 工作流程

1. 确认用户明确要求的交付物：规格、HTML 源码或两者。
2. 提取已提供事实、约束、来源注记和署名。
3. 标记缺失项，但不补造。
4. 设计单页信息层级、阅读顺序和视觉映射。
5. 建立展示性主张与已提供内容的对应关系。
6. 按输出契约生成并自检。

## 验证清单

- 名称为 `text-to-infographic`，版本为 `1.1.3`。
- 所有事实、数值、引用和素材均可追溯到当前对话。
- 结果严格为一页。
- 规格包含目标、层级、阅读顺序、内容映射和视觉指导。
- HTML 是完整、可复制的静态文档，CSS 全部内联，无脚本和外链。
- 语义文本、标题顺序、阅读顺序和非颜色编码符合无障碍要求。
