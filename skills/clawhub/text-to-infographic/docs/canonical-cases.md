# 标准案例

以下案例统一检索命中、回答口径与边界。

## Case 1：由现有笔记生成规格

**查询**

> 把下面的产品复盘整理成一页信息图规格。

**预期**：调用。

- 只使用查询中提供的复盘内容。
- 输出传播目标、阅读顺序、层级、内容块、视觉形式与版式建议。
- 逐条保持事实可追溯；缺失数据不补写。

## Case 2：生成独立 HTML 源码

**查询**

> 用这些已给数据生成可复制的单页 HTML 信息图源码。

**预期**：调用。

- 输出完整 `<!doctype html>` 文档。
- 仅使用 HTML 与内联 CSS。
- 保持静态、自包含、语义可读，不用颜色作为唯一编码。

## Case 3：从本地 CSV 自动生成分享包

**查询**

> 读取 sales.csv，生成 HTML、两张 PNG 和 evidence JSON。

**预期**：说明边界。

- v1.1.3 不读取文件、不运行渲染、不写出产物。
- 可请用户把必要内容贴到当前对话，再生成规格或 HTML 源码。

## Case 4：联网研究后补齐信息图

**查询**

> 搜集最新市场数据并做一张信息图。

**预期**：说明边界。

- 不联网研究或外部补充事实。
- 可基于用户随后提供的已核验材料组织单页信息图。

## Case 5：只做普通摘要

**查询**

> 总结这篇文章。

**预期**：不触发。

- 未明确要求信息图规格或独立 HTML。
- 不因内容复杂而自动调用本 Skill。

## Case 6：多页演示稿

**查询**

> 把这些材料做成 12 页演示文稿。

**预期**：不触发。

- 多页幻灯片超出单页信息图范围。
- 不将“可拆成多块”曲解为多页输出能力。
