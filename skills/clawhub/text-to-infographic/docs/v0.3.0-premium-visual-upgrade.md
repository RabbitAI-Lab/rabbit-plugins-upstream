## 1. 背景与定位（不改写的长期决策）

skill 的差异化叙事是 **「可编辑 plan + 信息正确校验 + 飞书办公嵌入 + 伴生文档」**，不与海报型工具正面卷视觉排版。

- 独有领地：`chart_family` 图表专用布局（flywheel / fishbone / sankey / pyramid / timeline / dashboard）

**本次目标**：在不破坏「信息正确 / 可编辑 plan / schema 向后兼容」三条底线的前提下，为成品图新增 premium 视觉层。

## 2. 开工前现状诊断（读代码确认）

| 现有机制 | 实际控制力 | 诊断 |
|---|---|---|
| `palette_mode`（brand/mono/duo/triad/custom） | 只取 3 色 → `--primary/--accent/--warn` | 配色 token 化，但装饰性弱 |
| `emphasis_style`（clean/editorial/playful/technical/luxury） | 只控制 `--radius / --heading-font / --shadow` 3 个 token | **"视觉不够 premium"根因** |
| 6 布局渲染逻辑（文本截断、sankey weight、relation 校验） | 与视觉壳**完全独立** | → 纯加 CSS 装饰层不碰内容，天然安全 |
| SVG 布局内颜色 | 大量用 `var(--primary/--text/...)`，但仍有**多处硬编码** `#FFFFFF / #0F172A` | → 深色 premium 会翻车，需先变量化 |

结论：premium 视觉层 = 「CSS 变量覆盖 + 装饰补丁」，不改任何 block/布局/校验代码。

## 4. 实施明细

### 4.1 `scripts/render_infographic_html.py`（核心，纯增量）

1. **语义变量补齐**（`:root` 新增，默认值与旧硬编码完全一致 → 零回归）：
   `--on-primary`、`--positive`、`--note-bg`、`--note-border`
2. **BASE_CSS 硬编码色 → 变量引用**：
   - badge / trend.up / note-card / takeaway / pyramid 高亮 / dash-highlights
   - `color-mix(in srgb, var(--X) n%, white)` → `color-mix(..., var(--panel))`（深色下 white 会错误变浅）
3. **SVG 内 4 处硬编码颜色 → 变量**（radial / fishbone / sankey 的卡片底与文字色）：
   `#FFFFFF → var(--panel) / var(--on-primary)`、`#0F172A → var(--text)`
4. **新增 premium 系统**（约 +150 行，纯 CSS）：
   - `PREMIUM_STYLES = ("data-journal", "night-ops")`
   - `_PREMIUM_CSS`：data-journal（纸感网格、衬线数字、双线刊头、直角细边）、night-ops（深蓝黑底、高对比）
   - `lighten_hex()` / `readable_on()`：night-ops 时把 brand 色自动提亮、确保主色文字可读
   - `build_premium_css(premium_style, palette)`：注入 premium CSS + 覆盖语义变量
5. `build_html()` 末尾接入：`css += build_premium_css(premium_style, palette)`

### 4.2 `schemas/infographic-plan.schema.json`

- `visual_system` 新增**可选**字段 `premium_style`：
  ```json
  "premium_style": { "type": "string", "enum": ["data-journal", "night-ops"] }
  ```
- 向后兼容：老 plan 不带该字段 → 渲染像素等价（CSS 变量默认值 = 原硬编码值）
