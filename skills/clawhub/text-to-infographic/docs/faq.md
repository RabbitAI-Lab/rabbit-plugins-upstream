# 常见问题

## 这个 Skill 能直接生成什么？

`current-safe`：单页信息图规格；在用户明确要求时，还可输出完整、可复制、自包含的静态 HTML 源码。

## 它会读取 CSV、JSON 或 Markdown 文件吗？

不会。v1.1.3 的边界是“当前对话中已提供的内容”。直接读取或解析文件不属于当前能力。

## 它会联网补充资料或核实事实吗？

不会。它不做外部补充。缺失事实、数值、引用、素材和偏好会保持未指定。

## 它会把 HTML 保存成文件或导出 PNG/PDF 吗？

不会。当前版本提供可复制的 HTML **源码**，不承诺写文件、渲染图片或导出 PDF。

## HTML 是否可以包含 JavaScript、CDN 或远程素材？

不可以。当前 HTML 是静态、自包含文档，仅含 HTML 与内联 CSS，无主动行为和外部依赖。

## 是否支持多页报告或幻灯片？

不支持。目标是**单页**信息图。多页报告、幻灯片和普通长文不在适用范围内。

## 用户没有给出引用或数据怎么办？

保持未指定，不补写来源，不制造数值，不把推测写成事实。

## 是否能改善可访问性？

可以在规格中给出可访问性说明，并确保 HTML 使用语义结构、连贯标题和阅读顺序，且颜色不是唯一的信息载体。

## 什么情况下不应调用？

当请求主要是普通摘要、数据收集、外部研究、图片编辑、发布上传，或未明确要求信息图规格/独立 HTML 时，不应调用本 Skill。可建议用户提供材料或选择更合适的工具。
