# Product Screenshots — powpow-openclaw-test

Used at runtime, on demand. When the user has no concept of PowPow, or needs to "see"
what the finished result looks like, send the corresponding link directly.

## Link rules

- Primary (raw):
  `https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-0N.jpg`
- Mirror (use when raw is unreachable, `N` = 1–6):
  `https://cdn.jsdelivr.net/gh/durenzidu/durenzidu@main/screenshots/powpow-0N.jpg`
- The images live in a public repo and can be sent as-is; **do not** download them
  into the skill directory, and never send local paths as images.
- Send only the 1–3 screenshots relevant to the current topic.

## Inventory

Note: the screenshots show the product's Chinese UI. When sending them to a
non-Chinese user, briefly say in the user's language what each screen shows.

### powpow-01.jpg — Digital-human detail page

![Digital-human detail page](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-01.jpg)

The card for a real/historical person turned into a digital human: online status,
location (e.g. a residence address), bio, "Start conversation" / "I was here" /
"Favorite" / "Share" actions, and the publisher.
**Use when**: the user asks "what does a digital human look like" / "what can it do
once created" / "how do I chat with it".

### powpow-02.jpg — Post editor page

![Post editor page](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-02.jpg)

The editor for writing posts/travelogues, with a cluster of floating buttons in the
bottom-right corner (locate, bubble, card, image, etc.).
**Use when**: the user asks "where do I write" / "can I edit it myself" / "how do I
post from my phone".

### powpow-03.jpg — Map page (bubbles + digital humans)

![Map page](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-03.jpg)

The public map at a glance: posts with locations cluster on the map as "bubbles"
(numbers are cluster counts), digital humans are pinned by avatar at their real-world
spots; search and an "All / Bubbles / Digital humans" filter sit at the top.
**Use when**: explaining "where will people see my post" / "what are the bubbles on
the map" — also the first-choice image for the opening "what does the result look
like".

### powpow-04.jpg — Profile page (digital assets)

![Profile page](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-04.jpg)

The user's own page: friends/followers/fans, plus "Digital assets" — **badge balance**
(3 in the shot), **my bubbles**, **my digital humans** (manage published ones), with
the note "2 badges publish 1 digital human, valid for 30 days".
**Use when**: the user asks "what are badges, what do they do" / "how many badges do
I have left" / "what have I posted".

### powpow-05.jpg — Story-progress page

![Story-progress page](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-05.jpg)

The in-platform story mode (example: "Yongle · 1421"): chapter progress, badges
earned, a character portrait generated from the user's avatar, "Start roleplay".
**Use when**: the user asks "what else can I do on PowPow besides posting" / "how
else can I earn badges". Note: this is platform gameplay, not part of this skill's
flow.

### powpow-06.jpg — Post detail page (finished example)

![Post detail page](https://raw.githubusercontent.com/durenzidu/durenzidu/main/screenshots/powpow-06.jpg)

What a published travelogue looks like: author, location tag ("Ditan Park 26.9km"),
time, body text, photos, and like/comment/share/favorite actions at the bottom.
**Use when**: the user asks "what does the published result look like" / "long or
short" / "can it carry images".
