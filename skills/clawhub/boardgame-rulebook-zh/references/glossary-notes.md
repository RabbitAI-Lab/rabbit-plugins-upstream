# 桌游术语易混点

`glossary.csv` 是查表用的；这里解释“为什么”和“怎么选”。

## deck / deck-building / deck construction

- **deck**：board game 里通常是“牌库”（你从中抽牌的那叠）。`discard pile` 是“弃牌堆”，不是“废牌堆”。
- **deck-building**：牌库构筑（Dominion 类，游戏过程中逐步买牌加入牌库）。
- **deck construction**：构筑套牌（TCG 赛前组牌）。不要把两者都译成“卡组构筑”。
- **甲板**是 ship deck；board game 里几乎不会用这个义项。
- TCG 语境里 deck 可译“套牌/卡组”，但同一本规则书要统一。

## token / marker / counter / coin

- **token**：指示物（实体小配件）。货币 token 可译“金币/硬币”。
- **marker**：标记（状态、位置、进度）。`first player marker` 起始玩家标记。
- **counter**：标记物/指示物；卡牌游戏的 `+1/+1 counter` 官方常译“+1/+1指示物”。不要译“柜台”。
- **coin**：金币/硬币；作为货币单位时用“枚”。
- 同一页不要把 token 一会儿叫“指示物”一会儿叫“代币”；termbase 定死。

## meeple / pawn / miniature / standee

- **meeple**：米宝（《卡卡颂》官方中文译名）。不要音译“米普”，也不要用“小人”当正式术语。
- **pawn**：棋子（普通人形棋子）。
- **miniature**：微缩模型（涂装模型/战棋单位）。
- **standee**：立牌（纸板/塑料立牌）。
- 量词：米宝/棋子/模型用“个”，立牌可用“个/块”。

## exhaust / tap / ready / untap

- **tap**：横置（万智牌等）。
- **exhaust**：卡牌横置也用“横置”（Netrunner/Arkham 类）；资源/能力“耗尽”才用“耗尽”。
- **ready**：卡牌从横置状态恢复时译“重置”；作为状态“准备”则看语境。
- **untap**：重置。
- 不要把 exhaust 译“疲劳”——那是疲劳机制，不是横置。

## reveal / flip / look at

- **reveal**：展示（给所有玩家看）。
- **flip**：翻面（物理翻到另一面）；`flip it face up` 翻至正面。
- **look at**：查看（私下看）。
- **search**：搜寻（从牌库找牌）。
- `turn face down` 面朝下；`face-up` 正面朝上。

## round / turn / phase / step

- **round**：轮（所有人各行动一次的大循环）。
- **turn**：回合（单个玩家的行动机会）。
- **phase**：阶段（一个回合内的功能段）。
- **step**：步骤（阶段内的小步）。
- 常见：`upkeep` 维护阶段、`cleanup` 清理阶段、`end phase` 结束阶段。

## score / points / victory point

- **score**：计分（动词）；`scoring` 计分。
- **points**：分（计分单位）；卡牌 `rank` 才是“点数”。
- **victory point / VP**：胜利点（首次可写“胜利点（VP）”）。
- 中文自然写法：“得3分”“获得2胜利点”“每块板块1分”。
- 不要写“胜利分数”。

## worker placement / action selection

- **worker placement**：工人放置。
- **action point allowance**：行动点分配。
- **action selection**：行动选择；`simultaneous action selection` 同时行动选择。
- **rondel**：轮盘；**time track**：时间轨；**mancala**：播棋。

## deck-building / bag-building / tableau building

- **bag-building**：袋抽构筑（从盲抽袋抽指示物构建引擎）。
- **tableau building**：牌阵构筑（玩家面前逐渐铺开的牌阵）。
- **engine building**：引擎构筑。
- **tableau** 不要译“桌面”（table 才是桌面）。

## area control / area majority / set collection

- **area control**：区域控制。
- **area majority**：区域多数。
- **set collection**：成套收集。
- **pick-up and deliver**：拾取与运送。
- **route building**：路线建设；**network building**：网络建设。

## trick-taking / trump / suit / rank

- **trick-taking**：吃墩；**trick**：墩。
- **trump**：将牌/王牌；`trump suit` 将牌花色。
- **suit**：花色；**rank**：点数。
- 不要用“特朗普”以外当然也别用（笑）。

## legacy / campaign / scenario

- **legacy**：传承（会永久改变组件的连续游戏）。
- **campaign**：战役（连续多局、有成长/剧情）。
- **scenario**：剧本/情景（单局关卡）。
- `scenario book` 剧本集；`campaign book` 战役书。
- **legacy** 不要译“遗产”——“遗产游戏”会让玩家以为是继承主题。

## wargame / 4X / COIN

- **wargame**：战棋/兵棋；历史兵棋常用“兵棋”，模型战棋常用“战棋”。
- **hex-and-counter**：六角格算子。
- **4X**：保留 4X（探索、扩张、开发、消灭）。
- **COIN series**：COIN 系列（反叛乱）；系列名保留。

## LCG / TCG / CCG

- **LCG**：成长式卡牌游戏（Living Card Game），首次可保留缩写。
- **TCG**：集换式卡牌游戏。
- **CCG**：集换式卡牌游戏（Collectible Card Game）。
- **booster pack**：补充包；**starter deck**：起始套牌。

## 万智牌官方简中（仅卡牌游戏语境）

法术力、地、咒语、瞬间、法术、结界、神器、鹏洛客、衍生物、徽记、备牌、先攻、连击、敏捷、警戒、死触、系命、践踏、飞行、守护、辟邪、不灭、召唤失调、反击咒语。

`sorcery` 在万智牌是“法术”；泛奇幻规则书的 sorcery 也可译“法术”。`spell` 在万智牌是“咒语”，通用语境可译“法术”。按游戏官方中文版定。

## neighbor / adjacent

- 玩家座位/行动关系：`neighbor` 相邻玩家；`adjacent` 相邻。
- 地图/王国关系：`neighboring kingdom` 邻国；`adjacent province` 相邻行省。
- 不要机械把 neighbor 都译“相邻玩家”；这是术语库 info 常报假阳性的地方。

## play / draw 的两个义项

- `play a card` 打出1张牌；`play a tile` 放置1块板块；`play the game` 进行游戏。
- `draw a card` 抽1张牌；`draw a picture` 绘制插图（美术/制作人员页）。
- `draw` 在规则正文几乎总是“抽”；在 credits/art 页才可能是“绘制”。

## counter / track / dial

- **counter** 标记物；**track** 轨道；**score track** 分数轨；**dial** 转盘。
- 不要译“柜台/跟踪/拨号”。

## “官方译名”优先级

1. 游戏官方中文版（出版社/中文代理）的术语。
2. 本 skill 的 `glossary.csv`。
3. 中文桌游社区通行译法（保持全篇一致）。

如果官方版和本表冲突：改 `termbase.tsv` 第二列；QA 以项目术语库为准。  
如果某个词在本作是特殊用法（例如 ship deck 真的是甲板），也在 termbase 里显式写正确译法，QA 会把它当作覆盖。
