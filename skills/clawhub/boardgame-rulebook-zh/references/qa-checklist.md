# 交付前 QA 清单

## 0. 先看结论

打开 `out/qa/report.md`：

- [ ] **error = 0**；否则不交付。
- [ ] warning 逐条看过；`line-start-punctuation` 与 `small-font` 通常要处理。
- [ ] info 只作参考（术语库建议/自动换字体）。

## 1. 资产检查（自动）

- [ ] 位图完整性：通过
- [ ] 矢量图完整性：通过
- [ ] 页面尺寸/旋转：通过
- [ ] 页数：与原文一致

任何一项失败，先停止排版修复，检查是否扫描页/特殊 PDF/输入文件变化。

## 2. 逐页目检（必须）

打开 `out/qa/pages/page_*.png`，左右对照，**每一页都看**，重点页放大看。

### 插图与图标

- [ ] 棋盘、卡牌图、人物插画、装饰边框的位置与原文一致。
- [ ] 译文没有盖住任何图标/小图。
- [ ] 内嵌图标的先后顺序合理（例如“获得 [资源图标] 2”）。
- [ ] 满页底图（羊皮纸/纹理）没有被白框/灰块破坏。

### 表格

- [ ] 表格线完整，没有断线/白块。
- [ ] 单元格文字在格内，没压线。
- [ ] 表头仍加粗/居中，与原文风格接近。
- [ ] 合并单元格没有错位。

### 双栏/标题/图注

- [ ] 左栏/右栏没有串栏。
- [ ] 标题在原位，字号层级正确。
- [ ] 图注仍居中/贴图，没有跑到另一栏。
- [ ] 页眉、页脚、页码在原位（页码通常保留数字）。
- [ ] 没有文字掉到页边距外。

### 中文排版

- [ ] 行首没有 `。，、；：！？）》」』】”’`。
- [ ] 没有一行只有一个字（孤字）或一个标点（孤标点）。
- [ ] 数字与量词之间没有多余空格。
- [ ] 引号、书名号、括号成对。
- [ ] 字号没有小到难读（正文 ≥ 7pt 为宜）。

### 术语与内容

- [ ] 术语表/项目术语库中的词前后一致。
- [ ] 卡牌名、角色名、资源名没有同页不同译。
- [ ] 数字、骰子记号、编号、图标保留。
- [ ] 没有整段英文残留（保留原文的 URL/版权/页眉除外）。
- [ ] 没有漏译整段（missing=0）。

## 3. 错误码与修法

| code | 原因 | 修法 |
| --- | --- | --- |
| `missing-translation` | 漏译 | 补 `translations.tsv`；或对 URL/版权/页码写 `=` |
| `glossary-wrong` | 命中明确错译（米普/甲板构筑等） | 按 `glossary.csv` 改；特殊用法在 termbase 显式覆盖 |
| `termbase-mismatch` | 项目术语库建议译法未出现 | info；确认是否官方译名/语境不同，必要时改 termbase 或译文 |
| `overflow` | 最小字号仍放不下 | 精简译文；用 override 扩框；不要缩到 5pt 以下 |
| `table-cell-overflow` | 表格单元放不下 | 精简译文；不能扩出 cell |
| `art-covered` | 译文压住位图/图标 | 精简/override；绝不忽略 |
| `vector-covered` | 译文压住矢量图标 | 同上 |
| `text-overlap` | 两段译文互相重叠 | 精简/override；检查列表行距 |
| `text-overlap-source` | 译文压到保留/未翻译原文 | 精简/override；确认 keep 段位置 |
| `source-residue` | 原英文没擦干净 | 检查是否扫描/OCR 层；重跑渲染；仍失败则停止 |
| `text-not-found` | 输出找不到完整译文 | 多为缺字/字体；换字体或改译文 |
| `missing-glyphs` | 字体缺字（emoji/生僻字） | `--font` 换字体；删掉非必要符号 |
| `line-start-punctuation` | 中文标点跑到行首 | 改写该句；或用 override 改框宽/字号 |
| `small-font` / `font-shrunk` | 字号过小 | 精简译文，优先恢复字号 |
| `number-missing` | 数字没出现在译文 | 核对是否漏译/改写数字 |
| `length-ratio` | 译文过长/过短 | 精简/检查漏译 |
| `mostly-latin` | 译文大量英文 | 检查是否漏译；专有名词过多可接受 |
| `images-changed` | 位图位置/内容变了 | **停止交付**；检查是否扫描页/特殊 PDF/输入变化 |
| `vector-art-changed` | 矢量图摘要变了 | **停止**；同上 |
| `geometry-changed` | 页面尺寸/旋转变了 | **停止**；检查输入/输出 |
| `scanned-page` | 疑似扫描页 | 不覆盖；见 `scanned-pdfs.md` |
| `pdf-changed` | 输入 PDF 哈希与提取时不同 | 重新 extract，确认版式 |
| `unknown-id` | 译文 id 不在 segments.json | 重新 extract 或恢复匹配的译文；用 `--reset-translations` 可重生成模板 |
| `stale-workdir` | 重新提取后 id 变了 | 同上 |
| `no-previews` | 没生成预览 | 必须带预览重跑，完成目检 |

## 4. 行首标点的处理

这是最常见的 warning。三种修法，按优先级：

1. **改写译文**：增删一两个字，改变换行点。例如把“，也没有任何……”改成“，任何……都无法……”或去掉逗号。
2. **改框宽**：`layout_overrides.json` 把该段 `box` 的 x1 加/减 4–12pt，改变折行；不要越栏/越表格。
3. **换字号**：只作为最后手段；同一段不要比原文小 30%。

改完必须重跑 render，确认 warning 消失、没有新增 `text-overlap`。

## 5. 内嵌图标段的额外检查

`source.md` 标 `inline_art` 的段：

- [ ] 图标没有被译文覆盖。
- [ ] 图标与文字的语义顺序合理；如果图标夹在句子中间，中文读起来是否仍然通顺？
- [ ] 译文没有为了绕图标而碎成奇怪的多行。
- [ ] 必要时用 override 把框向右扩，而不是缩小字号。

## 6. 最终签收

- [ ] QA error = 0。
- [ ] 所有页预览已目检（至少所有含图片/表格的页）。
- [ ] 交付 PDF 的页数、纸张尺寸与原文一致。
- [ ] 术语库随交付一起给用户。
- [ ] 说明哪些页未覆盖/扫描页/保留原文段。
- [ ] 说明这是“原位汉化”，不是重新排版；原版插图/版式保持不变。

## 7. 不要做的

- 不要用 Adobe Acrobat/Preview 手动编辑输出 PDF 后当最终版；会绕过 QA。
- 不要为了让 QA 通过而删除插图、压平页面、栅格化整页。
- 不要在公开仓库提交受版权保护的原始规则书或整页译文。
- 不要把“结构校验通过”说成“翻译完全正确”；仍要人工/术语复核。
