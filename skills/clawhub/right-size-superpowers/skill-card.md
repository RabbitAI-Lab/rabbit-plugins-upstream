## Use Case:

Developers and agent operators use this skill when they want Superpowers-style workflow depth scaled to task scope and risk. It guides agents to handle routine or reversible work directly while reserving deeper workflow steps for higher-risk changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can reduce heavyweight planning or review steps for routine work.

Mitigation: Reserve deeper workflows when extra rigor is needed, especially for architecture, public interfaces, persistent data, security, destructive actions, or materially ambiguous product behavior.
