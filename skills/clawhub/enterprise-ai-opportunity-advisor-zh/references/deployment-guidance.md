# 中国企业部署建议

## 普通 SaaS / 模型 API

适合公开资料、普通宣传内容、低敏内部资料和早期试点。

## 企业私有应用 + 模型 API

应用、数据库、权限和知识库在企业自己的服务器或企业云中运行，只把必要内容发送给模型 API。适合多数中小企业。

## 混合部署

敏感资料在本地检索、脱敏和筛选，只发送必要片段。适合客户资料、合同、内部技术资料和一般商业秘密。

## 完全本地部署

只有在明确不能联网、核心研发秘密、强监管数据、数据不得离开企业环境，且企业具备服务器和长期模型运维能力时优先考虑。

## 判断维度

- 数据类型和敏感度
- 数据能否脱敏
- 是否需要跨境
- 业务量和并发
- 企业运维能力
- 模型效果、延迟和成本
- 权限、日志和审计
- 供应商数据条款
- 模型切换能力

私有化不等于天然安全，也可能增加维护和升级风险。
