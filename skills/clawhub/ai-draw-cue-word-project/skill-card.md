## Description:

Helps create consistent adult-character prompts for image, storyboard, comic, video, and 3D workflows across several model syntax families.

This skill is ready for commercial/non-commercial use.

[nohn3043-arch](https://clawhub.ai/user/nohn3043-arch)

## Use Case:

Artists, designers, and developers use this skill to draft consistent fictional adult-character prompts and plan multi-scene image, comic, storyboard, video, and 3D work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Some example prompts use 'young woman,' which could leave adulthood unclear to an image model.

Mitigation: Explicitly state 'adult woman (18+)' in generated prompts before production use.

Risk: Uploading reference images to an external image provider may expose their content.

Mitigation: Share reference images only with providers trusted to handle that content.
