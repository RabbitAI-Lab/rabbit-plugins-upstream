# 专利五书撰写规范详解

## 一、说明书（Specification）

### 结构顺序（必须按此顺序）
1. **技术领域** — 1-2句话，格式："本发明涉及[领域]，具体涉及[方向]。"
2. **背景技术** — 指出已有技术的具体缺陷，引用公开文献
3. **发明内容** — 三个子部分：
   - 技术问题：与背景技术缺陷对应
   - 技术方案：与独立权利要求对应
   - 有益效果：具体量化，有数据支撑
4. **附图说明** — 逐图说明
5. **具体实施方式** — 至少一个完整实施例

### 常见错误
- 技术领域过宽或过窄
- 背景技术只用"现有技术不完善"泛泛描述
- 有益效果无数据支撑（"提高了效率" → "速度提升30%"）
- 功能性限定仅有一种实现方式

## 二、权利要求书（Claims）

### 独立权利要求结构
```
一种[发明名称]，包括：
[A特征]；
[B特征]；
其特征在于，还包括：
[C特征]，用于[实现某功能]。
```

或二段式：
```
一种[发明名称]，包括[已知特征A、B]，其特征在于，[区别特征C、D]。
```

### 从属权利要求结构
```
根据权利要求1所述的[发明名称]，其特征在于，[附加特征]。
```

### 布局策略：宽窄并进
- 独立权利要求 → 写宽（覆盖核心发明构思）
- 从属权利要求 → 写窄（具体优选实施方式）

### 常见驳回原因
| 问题 | 说明 |
|------|------|
| 不清楚 | 使用相对语言（"大功率""高温"），时序不明确 |
| 不支持 | 功能性限定超出说明书公开范围 |
| 缺必特 | 独立权利要求遗漏必要技术特征 |
| 无新创性 | 与现有技术无实质区别 |

## 三、说明书摘要（Abstract）
- ≤300字
- 不含权利要求式语言
- 反映技术方案和主要技术效果

## 四、说明书附图（Drawings）
- 线条图（非照片）
- 附图标号为阿拉伯数字
- 同一部件各图标号一致
- 图中不得出现文字说明（标注除外）

## 五、摘要附图（Abstract Figure）
- 最能说明发明技术特征的一幅图

## 格式细节
- A4纸，字体≥小4号
- 权利要求用阿拉伯数字（非中文大写）
- 每项权利要求以句号结束
- 各章节标题使用规定标准格式
