# 专利申请提交前自查清单

## 权利要求书检查
- [ ] 独立权利要求是否包含所有必要技术特征（去掉任何一个，技术效果是否无法实现）
- [ ] 权利要求中每个技术特征，在说明书实施例中是否均有对应描述
- [ ] 权利要求的保护范围是否超出说明书实施例覆盖范围
- [ ] 从属权利要求引用关系是否正确
- [ ] 是否使用了模糊/相对语言（如"大""高""约""左右"）
- [ ] 方法权利要求的步骤顺序是否清晰
- [ ] 功能性限定是否有多种实施例支撑

## 说明书检查
- [ ] 技术领域是否准确（不过宽、不过窄）
- [ ] 背景技术与发明内容中的技术问题是否对应
- [ ] 技术方案描述是否与独立权利要求一致
- [ ] 有益效果是否具体（最好有量化数据）
- [ ] 每个权利要求特征是否在实施例中可找到
- [ ] 附图标号与说明书文本是否一致
- [ ] 参数范围是否有端点实施例覆盖
- [ ] 各章节顺序是否符合规范

## 摘要检查
- [ ] 是否在300字以内
- [ ] 是否无权利要求式语言
- [ ] 是否反映了技术方案和主要效果

## 附图检查
- [ ] 是否为线条图
- [ ] 标号是否使用阿拉伯数字
- [ ] 同一部件各图标号是否一致
- [ ] 图中是否无文字说明

## AI相关发明额外检查（2026新规）
- [ ] 训练数据类型和来源是否在说明书中有披露
- [ ] 模型架构关键参数是否在实施例中记载
- [ ] 技术效果是否有可量化的验证数据
- [ ] 技术问题是否非纯数学/算法问题（确保是可专利客体）

## 格式检查
- [ ] 字体大小是否≥小4号
- [ ] 权利要求数字是否用阿拉伯数字
- [ ] 每项权利要求是否以句号结束
- [ ] 引用的背景技术文献公开日是否早于本申请公开日
