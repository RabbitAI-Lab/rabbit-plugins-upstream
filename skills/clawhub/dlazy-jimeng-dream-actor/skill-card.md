## Description:

Convert static character images into action videos with Jimeng Dream Actor through the dLazy hosted API.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to turn a static character image, prompt, and optional reference media into an action video generated by dLazy's Jimeng Dream Actor workflow.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected media files are processed by dLazy's hosted cloud service.

Mitigation: Use the skill only when cloud processing of those prompts and media files is acceptable for the user and organization.

Risk: Using a global npm install can increase local supply-chain exposure.

Mitigation: Prefer the pinned npx invocation or an isolated local install, review the @dlazy/cli package before use, and avoid administrator privileges.

Risk: The dLazy API key is a reusable credential that may be stored locally or supplied through the environment.

Mitigation: Keep the key revocable, rotate it when needed, and avoid exposing it in shared logs, prompts, or shell history.
