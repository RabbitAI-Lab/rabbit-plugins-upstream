## Description:

Creates and edits images for e-commerce and marketing, including product image sets, posters, background removal, object removal, and upscaling.

This skill is ready for commercial/non-commercial use.

## Publisher:

[adsturbo](https://clawhub.ai/user/adsturbo)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and marketing teams use this skill to generate and edit promotional images, product shots, and campaign artwork with AdsTurbo.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Uploading local media makes it available through a public URL and sends it to AdsTurbo.

Mitigation: Upload only media approved for public URL exposure; avoid confidential, personal, biometric, or regulated material unless exposure is acceptable.

Risk: Watermark or object removal can be used to modify material without authorization.

Mitigation: Use removal only on content you own or are authorized to modify.

Risk: Image requests consume AdsTurbo credits under the user's API key.

Mitigation: Confirm the intended use of the API key and credits before submitting requests.
