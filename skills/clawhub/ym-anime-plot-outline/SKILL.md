# 番剧剧情大纲生成器 (ym-anime-plot-outline)

生成带分集梗概与伏笔台账的番剧式剧情大纲，靠台账强制伏笔闭环，保证追更不烂尾。生成完逐条核对每个伏笔都有回收集，没有的当场补。大纲交付后用户可直接拿去写剧本、做分镜或向合作者汇报结构，不需要再自己梳理伏笔去向。本技能同时约束节奏（中点反转、每集钩子）与闭环（伏笔必回收），避免常见烂尾与注水。

## 何时使用

- 用户说「剧情大纲」「番剧企划」「分集梗概」「故事线设计」时
- 用户有一个主角设定或一句话点子，要扩成可落地的分集结构时
- 用户已有设定卡，需要据此长出剧情骨架时
- 用户写到大中途发现伏笔没收、节奏拖沓，要重梳结构时

## 运行前提

- 依赖：纯文本生成，无第三方依赖、不联网、不读取本地文件
- 不写台词级剧本，只做大纲与台账
- 若用户提供了设定卡内容，基于该内容生成，不另起炉灶
- 不调用任何脚本，所有节拍与闭环检查由模型按 `references/season-structure.md` 与 `templates/plot-ledger.md` 完成
- 生成时若用了默认假设（题材 / 主角 / 篇幅），在输出开头集中列出，方便用户定位需要替换的地方，不把假设混入「已确认」内容

## 输入契约

| 项 | 必需 | 说明 |
|---|---|---|
| 题材与基调 | 可选 | 热血 / 日常 / 悬疑 / 恋爱 等；默认热血，决定钩子与反转的力度 |
| 主角一句话设定 | 可选 | 用户给则沿用，作为分集推进的锚 |
| 篇幅 | 可选 | 12 集季番（默认）/ 24 集 / 自定义集数 |
| 已有设定卡 | 可选 | 若提供，剧情须贴合该设定，不冲突 |

**缺失处理：** 题材或主角设定缺失时按默认值生成，并在开头标注「以下为默认假设：【缺失项】」；篇幅缺失默认 12 集。不中止生成。自定义集数按 `references/season-structure.md` 末尾的「自定义篇幅」比例切分，并同样遵守硬性约束（小高潮、中点反转改目标、总爆发收 ≥ 2 伏笔、每集有钩子）。

## 执行步骤

1. **定三幕结构** — 先按 `references/season-structure.md` 的节拍表切分：第 1-2 集建立世界观、第 3 集小高潮、第 6-7 集中点反转、第 11-12 集总爆发。24 集或自定义按该文件的拉伸规则处理。中点反转必须改变主角目标或认知，不是换地图。

2. **写每集梗概** — 固定 3 行格式：本集事件 / 转折或推进 / 结尾钩子。每集结尾必须有钩子，钩子要有变化（不能每集都是「强敌出现」）。

3. **建伏笔台账** — 按 `templates/plot-ledger.md` 建表，每个伏笔编号 F01 起。记录埋设集、内容、计划回收集、回收方式。**总爆发集必须集中回收至少 2 个伏笔**。反派动机要用「反派视角也合理」检验，站不住的补强。

4. **强制闭环检查** — 生成完逐条检查台账：每个伏笔都有回收集，没有的当场补回收集与回收方式；确实无法回收的标「作废」并写原因。不允许悬空伏笔。

5. **输出主线节点表** — 列 3 个高潮点（第 3 集小高潮 / 第 6-7 中点 / 第 11-12 总爆发），各自写清触发、代价、改变。

6. **交付** — 三幕结构说明 + 分集梗概 + 伏笔台账 + 主线节点表一并返回。用户要改某集时，局部重生成后重跑台账闭环检查，重点看被改集牵连的伏笔。

## 各集写法要点

- 建立集：世界观与主角一起抛，别用大段说明文，用事件带出规则
- 小高潮：让主角第一次主动选择，显出性格与代价
- 中点反转：必须改写目标或认知，否则不算反转
- 缓冲集：给情绪落地，但埋一个小伏笔保持张力，别让观众在这个集脱坑
- 总爆发：靠已埋伏笔回收解决，不靠新力量开挂，回收时呼应埋设细节

## 伏笔与钩子设计要点

- 伏笔要「早埋晚收」：多在建立集与发展集埋，集中到中点与总爆发收，形成回响
- 伏笔要有「双重功能」：既能推动当期剧情，又是后期回收的钩子，避免纯装饰性伏笔
- 钩子类型要轮换：秘密揭露、关系裂痕、代价显现、选择困境轮流用，避免每集都是「强敌出现」
- 回收要「呼应埋设点」：回收时的细节要与埋设时一致（同一件物品、同一句台词），让观众有「原来如此」的满足感
- 反派动机要经得起「反派视角也合理」检验：反派不是为坏而坏，他的目标在自家立场里说得通

## 三幕结构为什么这样切

- 建立段（约 15%）负责让观众「入坑」：世界观、主角、核心悬念三件套一次给足，不能靠大段说明文
- 发展段（约 35%）负责「养关系与铺规则」：伙伴、能力体系、世界观规则在此展开，并埋下后期伏笔
- 中点反转（约 10%）是分水岭：主角目标或认知被改写，后半程的方向由此定调
- 缓冲段（约 10%）给情绪落地，但必须保留一个小钩子，否则观众脱坑
- 总爆发（约 30%）靠已埋伏笔闭环解决，是观众追更的理由所在

## 输出格式

Markdown，含四块：

```
## 三幕结构
（简述各阶段职能与集数区间）

## 分集梗概
第 1 集｜【本集事件】……
第 1 集｜【转折或推进】……
第 1 集｜【结尾钩子】……

## 伏笔台账
（套用 templates/plot-ledger.md 的表格）

## 主线节点表
高潮点 1（第 3 集）：触发——…｜代价——…｜改变——…
高潮点 2（第 6-7 集）：触发——…｜代价——…｜改变——…
高潮点 3（第 11-12 集）：触发——…｜代价——…｜改变——…
```

## 验收用例

- 正常：12 集悬疑题材 → 12 条分集梗概每条有钩子、伏笔台账 ≥ 4 条且全部有回收集、第 6-7 集有中点反转
- 边界：只给主角一句话设定 → 按默认题材生成 12 集，开头标注默认假设项
- 失败：某伏笔无回收集 → 闭环检查不通过，当场补回收集
- 节奏检查：第 4-6 集若全是日常空转无钩子推进 → 退回在发展段插入支线小案，保证中段不注水

## 能力边界

- 不写台词级剧本，只做大纲与台账
- 不保证商业成功，不做市场预测
- 不做续作规划，除非用户明确要求
- 不替用户决定题材基调，缺失时给默认但标注
- 不跨次保存大纲与台账（除非用户明确要求导出到文件）

## 常见坑

1. **伏笔埋了忘回收** — 现象：前期埋的怀表、台词到结尾没下文，观众觉得挖坑不填。原因：脑暴时顺手埋，写完没对账。规避：伏笔台账强制闭环，生成完逐条检查回收集。
2. **第 4-6 集注水拖节奏** — 现象：中段日常空转，追更掉粉。原因：中点前没安排支线推进。规避：用支线小案推进角色与世界观，每集仍有钩子。
3. **反派动机站不住** — 现象：反派「为坏而坏」，反转无力。原因：没做反派视角合理性检验。规避：用「反派视角也合理」检验，站不住的补强其动机与代价。
4. **高潮靠新力量而非已有伏笔** — 现象：决战突然冒出主角从没练过的能力翻盘。原因：前期没铺回收点。规避：总爆发必须集中回收 ≥ 2 个已埋伏笔，新力量需提前铺垫。
5. **每集钩子都是「强敌出现」** — 现象：钩子公式化，观众预知。原因：钩子类型单一。规避：钩子轮换（秘密揭露 / 关系裂痕 / 代价显现 / 选择困境），保持变化。
6. **中点反转不改目标** — 现象：第 6-7 集只是换个地点打，主角没变。原因：把「新地图」当反转。规避：中点必须改写主角目标或认知，否则退回重写。

## 目录说明

- `references/season-structure.md` — 12 集节拍表与 24 集拉伸规则，自定义篇幅比例也在此
- `templates/plot-ledger.md` — 伏笔台账模板，含填好的示例行，生成时直接套用
