# 伏笔台账模板 (plot-ledger.md)

> 用法：每个伏笔一行，从 F01 顺序编号。生成分集梗概后立即填，杜绝「埋了忘回收」。总爆发集必须集中回收至少 2 个伏笔。

| 编号 | 埋设集 | 伏笔内容 | 计划回收集 | 回收方式 | 状态 |
|---|---|---|---|---|---|
| F01 | 第1集 | 主角母亲留的旧怀表，指针停在某个时刻不走 | 第11集 | 总爆发时怀表亮起，揭示母亲当年用命封印了异能，指针重新开始走 | 已埋待收 |
| F02 | 第3集 | 反派随口说「我也有过想保护的人」，说完立刻岔开 | 第7集 | 中点揭示反派曾是主角恩师门下，立场反转后这句话成为他动摇的伏笔 | 已埋待收 |

## 字段说明

- 编号：F + 两位数字，全局唯一，生成时按顺序排，不要跳号
- 埋设集：伏笔首次出现的集数，精确到「第 X 集」
- 伏笔内容：一句话写清「埋了什么」，避免含糊
- 计划回收集：承诺在哪集收，必须非空；这是台账的核心约束
- 回收方式：怎么收，必须与已埋设定呼应，不靠新力量硬解
- 状态：已埋待收 / 已回收 / 作废（作废需注明原因，例如设定改动后该伏笔不再成立）

## 闭环规则

生成完逐条检查：状态为「已埋待收」的必须有非空「计划回收集」。没有回收集条目的，当场补上回收集与回收方式；若确实无法回收，改为「作废」并写原因，不允许留下无下落的悬空伏笔。

## 每集梗概格式（固定 3 行）

```
第 X 集｜【本集事件】……
第 X 集｜【转折或推进】……
第 X 集｜【结尾钩子】……（每集必须有钩子）
```

## 主线节点表格式

```
高潮点 1（第 3 集小高潮）：触发——……｜代价——……｜改变——……
高潮点 2（第 6-7 集中点反转）：触发——……｜代价——……｜改变——……
高潮点 3（第 11-12 集总爆发）：触发——……｜代价——……｜改变——……
```
