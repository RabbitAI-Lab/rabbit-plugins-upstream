# 七维分析框架 / Seven-Dimension Analytical Framework

> 此框架将三十六计与现代顶级思维体系深度融合。每一维度独立加载，按需使用。

---

## Dimension 1: 博弈论视角 / Game Theory

### 核心概念
- **信息不对称**：一方拥有另一方不知道的信息 → 瞒天过海、暗度陈仓、假痴不癫
- **承诺与可信度**：改变自身支付函数使威胁/承诺变得可信 → 破釜沉舟（借尸还魂）、上屋抽梯
- **信号传递**：发送信号诱导对手行动 → 抛砖引玉、打草惊蛇、空城计
- **混同均衡 vs 分离均衡**：欺骗者模仿诚实者的信号 vs 诚实者发送骗子无法模仿的信号 → 瞒天过海(混同) vs 苦肉计(分离)
- **序贯博弈**：先动者 vs 后动者优势 → 以逸待劳(后动)、先发制人(先动)
- **混合策略**：随机化行动使对手无法预测 → 声东击西

### 关键计策映射
| 计策 | 博弈论机制 |
|------|-----------|
| 瞒天过海 | 信号博弈中的混同均衡 |
| 空城计 | 高阶信念操纵——"我知你知我知"无限递归 |
| 苦肉计 | 昂贵的诚实信号——分离均衡 |
| 欲擒故纵 | 序贯博弈中的战略性让步 |
| 上屋抽梯 | 诱导对手先做不可逆投资，改变后续博弈的议价能力 |

### 分析引导问题
1. 各方分别掌握什么信息？各方分别在隐藏什么？
2. 这是一次性博弈还是重复博弈？（重复博弈中声誉和合作可能）
3. 各方能做哪些可置信的承诺？承诺的"可信度"来源是什么？
4. 行动顺序是什么？先发优势还是后发优势？
5. 当前博弈是零和还是正和？能否通过改变博弈结构创造正和？

## Dimension 2: 系统思维 / Systems Thinking

### 核心概念
系统思维的干预深度从浅到深分为四层：

**浅层干预（改变流量/参数）**：
- 调整信息和资源的流向 → 声东击西、顺手牵羊

**中层干预（改变反馈回路）**：
- 激活负反馈使对手过度谨慎 → 打草惊蛇
- 削弱正反馈使对手放松 → 欲擒故纵
- 建立新的正反馈以小撬大 → 抛砖引玉

**深层干预（改变系统结构）**：
- 拔除系统核心节点 → 釜底抽薪
- 攻击枢纽节点使网络瓦解 → 擒贼擒王
- 改变边界条件限制自由度 → 关门捉贼

**元层干预（改变系统目标/认知范式）**：
- 重新定义系统主人 → 反客为主
- 替换核心要素不改变外观 → 偷梁换柱
- 在"正常运作"的幻觉中改变方向 → 瞒天过海

### 关键计策映射
| 计策 | 系统杠杆点 | 干预深度 |
|------|-----------|---------|
| 瞒天过海 | 信息流（感知层） | 元层 |
| 釜底抽薪 | 资源输入流 | 深层 |
| 擒贼擒王 | 网络枢纽节点 | 深层 |
| 反客为主 | 系统归属/控制权 | 元层 |
| 打草惊蛇 | 反馈回路（触发反应） | 中层 |

### 分析引导问题
1. 这个竞争系统的核心要素是什么？（参与者、资源流、信息流、规则）
2. 系统的关键杠杆点在哪里？（改变哪里能产生最大的连锁效应？）
3. 当前系统的反馈回路是什么？正反馈（放大）还是负反馈（稳定）占主导？
4. 对手最依赖的输入是什么？（资金流？人才流？数据流？）哪里可以被釜底抽薪？
5. 系统的边界在哪里？能否通过改变边界改变博弈？

## Dimension 3: 认知心理学 / Cognitive Psychology

### 核心概念——36计利用的认知偏误

| 认知偏误 | 被利用的计策 | 利用机制 |
|----------|-------------|---------|
| **确认偏误** | 瞒天过海、假痴不癫 | 人只看见自己相信的 → 制造符合预期的假象 |
| **损失厌恶** | 趁火打劫、釜底抽薪 | 人对损失的恐惧远超对收益的渴望（~2.25倍） |
| **锚定效应** | 抛砖引玉 | 先给一个低锚点，后续出价都围绕锚点波动 |
| **从众效应** | 树上开花、无中生有 | 制造"声势浩大"的假象，引发从众 |
| **沉没成本谬误** | 上屋抽梯 | 投入越多越不舍得退出 |
| **可得性启发** | 打草惊蛇、指桑骂槐 | 强烈信号使人高估事件概率 |
| **框架效应** | 笑里藏刀 | 同一个事实换一个包装，反应截然不同 |
| **习惯化** | 瞒天过海 | 重复刺激导致反应递减 → "异常常态化" |
| **变化盲视** | 偷梁换柱、暗度陈仓 | 人的注意容量有限，只能追踪有限变化 |
| **权威依赖** | 擒贼擒王 | 群体在失去领导者后决策瘫痪 |
| **登门槛效应** | 反客为主 | 先接受小请求，更容易接受大请求 |
| **阴谋论偏误** | 空城计 | 在充满欺骗的环境中，简单真相反而不被相信 |

### 分析引导问题
1. 对手的决策者存在哪些认知偏误可以利用？
2. 当前局势激活了对手的哪种情绪？（恐惧？贪婪？愤怒？安逸？）
3. 对手的"注意力焦点"在哪里？（你能在注意力盲区做什么？）
4. 对手已经投入了多少沉没成本？（可以利用这些成本锁定的心理效应吗？）
5. 对手的"可信度启发式"是什么？（什么信号会让对手相信你？）

## Dimension 4: 孙子兵法元原则 / Sun Tzu Meta-Principles

### 四大核心原则与计策映射

**1. 兵者，诡道也（Deception）**
- 能而示之不能 → 假痴不癫、笑里藏刀
- 用而示之不用 → 声东击西、暗度陈仓
- 近而示之远 → 瞒天过海、调虎离山
- 利而诱之 → 抛砖引玉、上屋抽梯
- 乱而取之 → 趁火打劫、浑水摸鱼

**2. 不战而屈人之兵（Win Without Fighting）**
- 伐谋 → 离间计、反间计（从内部瓦解）
- 伐交 → 远交近攻（阻断外部支援）
- 伐兵 → 围魏救赵、关门捉贼（精准打击）
- 攻城 → 最后手段（三十六计基本避免）

**3. 知己知彼（Know Yourself and Your Enemy）**
- 知彼手段 → 打草惊蛇（测试反应）、抛砖引玉（诱导暴露）、反间计（利用间谍）
- 知己要求 → 走为上（知不可战则退）、空城计（知自身虚实）

**4. 致人而不致于人（Seize Initiative）**
- 以逸待劳 → 控制战场节奏
- 反客为主 → 从被动变主动
- 欲擒故纵 → 控制对方行动方向
- 围魏救赵 → 迫使对手按你的意愿行动

### 分析引导问题
1. 当前你是"致人"还是"致于人"？如何将主动权抢回？
2. 有哪些不需要正面交战就能达成目标的方式？
3. 你是否真正了解对手的强弱虚实？对手有哪些盲区？
4. 当前局势具备哪些"诡道"的条件？

## Dimension 5: 现代竞争战略 / Modern Competitive Strategy

### 战略框架与三十六计映射

**波特五力（Porter's Five Forces）**
- 提高进入壁垒 → 关门捉贼、上屋抽梯（锁定市场，封死竞争者入口）
- 削弱供应商议价力 → 釜底抽薪（切断资源命脉）
- 削弱买方议价力 → 反客为主（从供应商变为不可替代的伙伴）
- 阻止替代品 → 偷梁换柱（用自己的方案替换对手的方案）
- 管理竞争强度 → 远交近攻（与部分对手共存，专注消灭特定对手）

**蓝海战略（Blue Ocean Strategy）**
- 创造新市场，避开红海竞争 → 无中生有（在无人区建立新赛道）
- 价值创新 → 借尸还魂（用旧载体承载新价值）

**OODA 循环（Observe → Orient → Decide → Act）**
- Observe: 打草惊蛇（探测信息）
- Orient: 暗中分析，不被对手的信号误导
- Decide: 擒贼擒王（选择关键目标）
- Act: 趁火打劫（抓住时机快速行动）
- 核心：你的OODA循环比对手快 → 让对手还在上一步时你已经完成本轮

**颠覆式创新（Christensen's Disruptive Innovation）**
- 边缘市场切入 → 反客为主
- 先服务被忽视的客户群 → 趁虚而入
- 逐步提升性能进入主流市场 → 渐进颠覆

**柔道战略（Judo Strategy）**
- 快速移动避免正面交锋 → 走为上（战略性撤退）
- 利用对手的动量 → 借力打力
- 在狭窄空间建立根据地 → 关门捉贼的防守版

### 分析引导问题
1. 行业五力中哪个是最大的压力点？三十六计中哪一计可以缓解这个压力？
2. 是否存在"无中生有"的蓝海空间？是否可以用"借尸还魂"重新激活旧资产？
3. 你的OODA循环比对手快还是慢？如何加速？
4. 你是在主流市场正面竞争（红海）还是在边缘市场积累力量（颠覆式路径）？

## Dimension 6: 四层深度模型 / Four-Layer Depth Model

### 模型概述

```
第一层：表象操纵（Manipulating Perception） → 认知战
  瞒天过海、无中生有、声东击西、暗度陈仓、树上开花、假痴不癫
  → 关键词：制造假象、控制信息、管理感知

第二层：关系操纵（Manipulating Relationships） → 网络结构战
  借刀杀人、离间计、反间计、远交近攻、隔岸观火、指桑骂槐
  → 关键词：联盟与分化、第三方利用、间接影响力

第三层：情境操纵（Manipulating Context） → 环境设计战
  趁火打劫、调虎离山、抛砖引玉、欲擒故纵、打草惊蛇、关门捉贼
  → 关键词：创造/利用有利条件、环境控制

第四层：结构操纵（Manipulating Structure） → 架构战
  釜底抽薪、擒贼擒王、偷梁换柱、反客为主、李代桃僵、借尸还魂、上屋抽梯
  → 关键词：改变游戏规则、替换核心要素、重构系统

元层：时间与节奏（Meta-Layer） → 动态平衡战
  以逸待劳、走为上、连环计、苦肉计、围魏救赵、顺手牵羊、金蝉脱壳、空城计、美人计
  → 关键词：时机选择、节奏控制、韧性生存
```

### 使用指南

- **层次越高，影响越深远但越难执行**
- **同一层的计策可以组合使用**
- **跨层组合效果最强**：如第一层（声东击西）为第四层（釜底抽薪）创建掩护
- **元层始终贯穿**：任何计策的使用都需要考虑时机和节奏

### 分析引导问题
1. 你的策略主要停留在哪一层？是否应该上升到更深层？
2. 对手的优势在哪一层？你能在另一层攻击它吗？
3. 元层（时机）是否对你有利？是应该加速还是减速？

## Dimension 7: 七种元思维范式 / Seven Meta-Thinking Paradigms

### 1. 非线性思维（Non-Linear Thinking）
- **要义**：不直接解决问题，而是攻击系统的耦合弱点
- **代表计策**：围魏救赵
- **问题**：问题的真正原因是直接原因还是系统中的耦合关系？
- **应用**：面对一个难题，列出所有"不直接但有因果关联"的干预点。

### 2. 反直觉思维（Counter-Intuitive Thinking）
- **要义**：最优策略常常与直觉相反
- **代表计策**：欲擒故纵、空城计、苦肉计
- **问题**：直觉告诉你要做X，那么不做的结果是什么？
- **应用**：当所有常规方案都试过后，考虑"颠倒"的方案。

### 3. 涌现思维（Emergence Thinking）
- **要义**：多个弱信号的叠加可以涌现出强大的实体或感知
- **代表计策**：无中生有、树上开花
- **问题**：哪些小的独立行动叠加起来会产生质变？
- **应用**：设计多个并行的"弱信号"（PR、社交证明、合作伙伴），让它们叠加涌现出远超实际实力的"声势"。

### 4. 借力思维（Leverage Thinking）
- **要义**：不消耗自身资源，利用系统中的现有能量
- **代表计策**：借刀杀人、借尸还魂、反客为主、顺手牵羊
- **问题**：系统中的"势"在哪里？如何顺势而为而非逆势挣扎？
- **应用**：列出所有可用于自身目标的"现有力量"（别人的资源、已有的趋势、现有的基础设施）。

### 5. 不对称思维（Asymmetric Thinking）
- **要义**：攻击关键少数（20%）获得80%效果；不在对称点对抗
- **代表计策**：釜底抽薪、擒贼擒王
- **问题**：对手的"20%"是什么？你的"20%"是什么？
- **应用**：绘制对手的价值链/力量图，圈出最脆弱的关键节点。

### 6. 时序思维（Temporal Thinking）
- **要义**：时机选择比力量对比更重要
- **代表计策**：以逸待劳、顺手牵羊、走为上
- **问题**：当前是行动的最佳时机还是等待的最佳时机？时间站在哪一边？
- **应用**：评估"行动的紧迫性"vs"等待的价值"——如果时间站在你这边，以逸待劳就是最优策略。

### 7. 灰度思维（Gray-Zone Thinking）
- **要义**：不追求非黑即白，在模糊地带操作——保持否认空间
- **代表计策**：假痴不癫、笑里藏刀、指桑骂槐
- **问题**：你能在"不可接受"和"完全无害"之间找到操作空间吗？
- **应用**：设计"模棱两可"的行动方案——对自己的支持者它意味X，对对手它意味Y，任何一方都无法明确指控。

### 元范式使用指南

分析任何竞争场景时，依次问七个问题：
1. 我能不能不正面解决这个问题？（非线性）
2. 我的直觉是什么？反着来会怎样？（反直觉）
3. 哪些小行动可以叠加产生大效应？（涌现）
4. 有什么现成的力量可以利用？（借力）
5. 对手的"要害"在哪里？（不对称）
6. 现在该行动还是等待？（时序）
7. 有没有"灰色地带"的行动方案？（灰度）
