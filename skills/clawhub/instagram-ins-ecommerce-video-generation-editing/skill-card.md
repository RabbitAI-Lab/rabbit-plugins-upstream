## Use Case:

External creators, ecommerce marketers, and developers use this skill to generate or adapt Instagram-ready product videos for Reels, Stories, Shop demos, creator UGC, and paid-social variants while preserving product truth, rights, and placement constraints.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and provided media are sent to AI Hive for generation or editing.

Mitigation: Use only media you have rights to upload and avoid submitting confidential or unapproved assets.

Risk: Running init stores an AI Hive API key locally.

Mitigation: Use an intended AI Hive account/API key and protect the local configuration file.

Risk: Generated files are downloaded to ~/Downloads/AiHive by default.

Mitigation: Review downloaded outputs before publication and change the output directory when project storage controls require it.
