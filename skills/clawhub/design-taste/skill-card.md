## Description:

Helps agents create, refine, and review intentional visual designs for interfaces, documents, images, and game art.

This skill is ready for commercial/non-commercial use.

## Publisher:

[linkxzhou](https://clawhub.ai/user/linkxzhou)

### License/Terms of Use:

MIT-0

## Use Case:

Designers and developers use this skill to establish visual direction, build or polish interfaces, create design tokens, and critique websites, images, and game art.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Website review opens the requested URL, fetches page assets, may interact with cookie consent, and saves screenshots and metrics locally.

Mitigation: Review only URLs and project files you intend the agent to analyze; check local output before sharing it.
