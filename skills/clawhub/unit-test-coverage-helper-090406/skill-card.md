## Description: <br>
Helps software teams add useful unit tests and raise test coverage in existing codebases through repeatable workflows, implementation support, and verification notes. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, QA engineers, maintainers, and product teams use this skill to plan and produce practical unit-test coverage improvements for existing software projects. It helps clarify requirements, propose implementation steps, generate checklists or code-oriented guidance, and identify verification commands. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may be selected for broad testing or quality-related prompts where a more specific QA, debugging, or implementation skill would be better. <br>
Mitigation: Invoke a more specific skill by name when the request needs narrower QA, debugging, or implementation behavior. <br>
