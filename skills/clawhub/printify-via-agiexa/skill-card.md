## Description:

Explains the planned Printify for Shopify integration through Agiexa and can submit a waitlist request with the user's explicit permission.

This skill is ready for commercial/non-commercial use.

## Use Case:

Merchants use this skill to understand Agiexa's planned Printify integration and its future commerce capabilities. If they choose, it can submit their own details to Agiexa's launch waitlist with explicit permission.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Joining the waitlist shares the user's email, role, and any optional link or message with Agiexa.

Mitigation: Submit only details the user provides and confirms in the conversation, and only after explicit permission.

Risk: Sharing an API key in chat could expose account access.

Mitigation: Enter API keys only through Agiexa's service connection flow.

Risk: Future commerce tools may have access to consequential store actions.

Mitigation: Review the requested permissions before enabling tools for an agent.
