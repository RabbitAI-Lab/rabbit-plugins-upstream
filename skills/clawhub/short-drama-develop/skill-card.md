## Description:

将短剧或漫剧创意及改编材料发展为创作简报、故事引擎和分集地图，并保留创作者对故事方向与改动的决定权。

This skill is ready for commercial/non-commercial use.

## Use Case:

面向短剧与漫剧编剧及开发者，用于梳理原创点子或长篇改编材料，形成可审阅的故事方向、系列设定与逐集规划。

### Deployment Geography for Use:

Global

Mitigation: Review the proposed changes and their effects before accepting them for downstream work.

Mitigation: Assess the companion independently before using project integration.
