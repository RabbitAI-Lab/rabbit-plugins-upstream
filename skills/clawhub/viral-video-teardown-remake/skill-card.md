## Description:

Analyzes a reference short video's structure and helps creators remake it for their own topic with a shot list, narration, and video or edit-ready segments.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and marketing teams use this skill to break down an existing short video and adapt its pacing and storytelling to their own product or subject, producing a shot list, narration, and a remade clip or edit-ready segments.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The shared Beatra authorization can grant broad access to links, files, generated media, and account credits.

Mitigation: Install only if you trust Beatra with those assets and review the requested authorization before approving it.

Risk: The package replaces its local code through silent automatic updates by default.

Mitigation: Disable automatic updates with the documented `update --auto off` command if unreviewed code changes are unacceptable.

Risk: Reference lookups and media generation can consume account credits.

Mitigation: Confirm each paid operation and its current price before it runs.
