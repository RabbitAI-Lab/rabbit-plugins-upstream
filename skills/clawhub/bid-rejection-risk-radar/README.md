# 废标风险雷达（bid-rejection-risk-radar）

废标风险雷达——专攻招标文件中的否决投标（废标）条款、硬性资质要求、保证金条款及隐性风险点提取。从招标文件中**精准提取**可能导致投标被否决（废标）的条款与隐性风险，输出可逐项核对的**结构化检查清单**，便于审核人员封标前逐项核对。

> 本版本为**招投标法体系版本**（工程 / 招标类文档）。政府采购法体系、国企非招标采购为口径不同的独立版本，不混入本版本。

## 功能特性

- **六维逐层扫描**：①★号条款与实质性响应（含★形式要求）②资格性审查要求 ③符合性审查要求 ④保证金与财务要求 ⑤隐性废标风险（四步挖掘法）⑥政策合规性（仅政府采购项目启用）。
- **统一 10 列提取表**：每项风险含「条款出处 / 具体要求 / 风险等级 / 置信度 / 检查动作 / 是否满足 / 责任人 / 备注」，可直接打印打勾。
- **体系感知 · 法规锚定（Step 2.5）**：挂载 IMA 多库（招投标主源 `招投标实务与合规` KB `7463402595160740`、国企 `国有企业采购` KB `7466027138969773`、真实判例 `招投标评标否决AI知识库` KB `7460608999968055`），对隐性 / 推断类风险补强法律依据、提升置信度，标注来源库与体系，严禁跨体系误用。
- **条款冲突检测**：跨章节时间 / 金额 / 资质 / 格式 / 数量冲突交叉验证。
- **风险分级与封标前确认表**：🔴高危 / 🟡中危 / 🟢低危，附 Top 5 致命风险与封标前最终确认清单。
- **增量扫描协议**：澄清 / 补遗文件对比原文件输出「变更对照表」，仅重评变更点，不重新生成全量清单。
- **工程健壮性**：框架思维链 + 自检清单、错误处理与降级（法规库未锚定不阻断主流程）、统一署名脚注。

## 使用方式

1. 上传招标文件（PDF / DOCX / 图片 / 扫描件，含招标公告、投标人须知及前附表、评标办法、合同条款、技术规格、投标文件格式要求等）；
2. 技能自动识别体系与招标方式 → 六维扫描 → 法规锚定 → 输出分级检查清单；
3. 查看三层递进结果（风险概览 → 分级检查清单 → 封标前确认表）；支持「只看高危」「展开第 X 项」「导出完整版」「增量扫描补遗」。

## 能力边界

| 做 | 不做 |
|---|---|
| 从招标文件提取废标 / 否决风险条款与隐性风险点 | 不做法律定性裁决（是否真正否决由评审委员会认定） |
| 输出结构化检查清单 + 封标前确认表 | 不替代全文解读 / 翻译、投标文件撰写、合同审查 |
| 体系感知的法规锚定与判例佐证 | 不做评标打分、异议投诉文书代写 |
| 招投标 / 工程口径为主，政采 / 国企独立版本分流 | 不提供报价策略与评分拆解建议、不协助编造资质业绩 |
