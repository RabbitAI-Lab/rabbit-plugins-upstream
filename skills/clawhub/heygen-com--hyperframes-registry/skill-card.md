## Description:

Find, install, and adapt roughly 450 ready-made HyperFrames blocks and components for transitions, overlays, titles, kinetic type, captions, charts, maps, 3D, and camera moves.

This skill is ready for commercial/non-commercial use.

## Publisher:

[heygen-com](https://clawhub.ai/user/heygen-com)

### License/Terms of Use:

MIT-0

## Use Case:

External developers use this skill to find and install reusable HyperFrames blocks and components, wire them into compositions, and create or contribute new items when needed.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill directs agents to send catalog search reports and requested effects externally without first obtaining user approval.

Mitigation: Require approval of the exact feedback text and destination before sending; use a reviewed CLI version, inspect downloaded source changes, and review project contents before publishing or submitting contributions.
