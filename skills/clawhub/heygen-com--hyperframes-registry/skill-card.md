## Description:

Helps developers find, install, and integrate reusable HyperFrames blocks and components into video compositions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[heygen-com](https://clawhub.ai/user/heygen-com)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and video creators use this skill to discover registry effects, install blocks or components, wire them into HyperFrames compositions, and prepare new registry items for contribution.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Floating npx commands can run a tool version that has not been reviewed.

Mitigation: Use reviewed, lockfile-pinned versions for CI, publishing, and authenticated workflows.

Risk: Feedback and publishing commands can send information outside the project.

Mitigation: Review files and feedback content first, and run those commands only when external submission is intended.
