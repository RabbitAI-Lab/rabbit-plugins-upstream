## Description:

About 450 ready-made HyperFrames blocks and components installed as editable source - transitions, overlays, titles, kinetic type, captions, charts, map overlays, 3D, camera moves. Use it before hand-building any named visual (CRT scanlines, glitch, film grain, a chart); also for hyperframes add and catalog.

This skill is ready for commercial/non-commercial use.

## Use Case:

Video editors and developers use this skill to find and install editable HyperFrames blocks and components, then wire them into scenes or adapt their source instead of building named visual effects from scratch.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Search queries and requested visuals may be shared as feedback without asking the user.

Mitigation: Get the user's approval before sending search feedback and remove private project details from it.

Risk: The external CLI, downloaded components, and sibling plugin rules were not verified.

Mitigation: Use a reviewed, pinned CLI; review downloaded components and plugin rules; and set telemetry opt-out if desired.

Risk: Contributions can expose unintended content or publish it with unintended visibility.

Mitigation: Review upload contents and visibility before publishing contributions.
