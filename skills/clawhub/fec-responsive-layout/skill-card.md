## Description:

Guides the design, implementation, and review of responsive frontend layouts across screen sizes and input methods.

This skill is ready for commercial/non-commercial use.

Frontend developers and designers use this skill to prioritize content, choose mobile-first breakpoints or container queries, and review data-heavy layouts for overflow, touch, keyboard, and viewport issues.
