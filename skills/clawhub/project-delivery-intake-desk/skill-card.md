## Description:

Turn project intake notes into recorded delivery ledger entries.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wxt-ai](https://clawhub.ai/user/wxt-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Project delivery teams use this skill to turn supplied client briefs, delivery notes, or project updates into concise project context and delivery ledger entry fields.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may treat generated delivery entries as authoritative project records.

Mitigation: Use the skill to structure supplied notes, then have authorized project systems or reviewers approve and record official ledger entries.

Risk: The workflow is narrow and may not provide broader project management controls.

Mitigation: Use it only for intake-note formatting unless the surrounding system provides validation, permissions, audit trails, and record-writing controls.
