## Description: <br>
Add frontend pages to WCS (Warehouse Control System) applications. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineers use this skill to add WCS Vue2 business list pages while reusing existing project patterns for API modules, Vue components, routes, and i18n keys. It is intended for frontend code changes in WCS applications that need query forms, tables, action columns, optional import/export, and route registration. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated route, API, i18n, and Vue component changes can affect WCS application behavior. <br>
Mitigation: Review the generated diff, route registration, API endpoints, and update/delete behavior before merging. <br>
Risk: Incorrect assumptions about endpoint ID placement or data dictionary keys can cause frontend/backend mismatches. <br>
Mitigation: Confirm unclear update/delete API shapes and dictionary keys before implementation, as the skill directs. <br>
