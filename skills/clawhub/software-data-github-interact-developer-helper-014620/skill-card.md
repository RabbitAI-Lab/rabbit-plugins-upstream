## Description: <br>
Helps agent users, skill authors, maintainers, and teams create practical GitHub-style workflows for bug fixes, setup hardening, reliability work, and adjacent skill development. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, maintainers, and skill authors use this skill to turn GitHub-style issue, PR, CLI, reliability, setup, or skill-authoring requests into clear workflows, checklists, implementation plans, artifacts, and validation notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The activation language is broad and could make the skill appear for unrelated developer requests. <br>
Mitigation: Invoke it explicitly for GitHub-style issue, PR, CLI, repository workflow, reliability, setup, or skill-authoring support. <br>
Risk: The skill can produce implementation plans, commands, code changes, or configuration guidance that may be incorrect for a specific repository. <br>
Mitigation: Review proposed changes and run the included verification steps before applying them to production work. <br>
