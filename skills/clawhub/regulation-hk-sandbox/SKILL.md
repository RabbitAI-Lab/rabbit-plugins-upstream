## I — 方法论骨架 (Interpretation)

这套方法论是一张"全球监管地图 + 跨境桥接逻辑"，帮你在动手前先回答一个根本问题：**我的资产在哪个法域能做什么、不能做什么**。

三个范式是理解全世界的钥匙：

1. **传统金融延伸（美/欧）**：不另起炉灶，把代币塞进现有证券法框架，按证券定性、持牌经营、投资者适当性严格。
2. **积极探索与生态构建（香港/新加坡）**：以监管沙盒 + 快速发牌抢规则制定权，按"同风险同监管"原则务实推进，是境内资产最现实的合规出海窗口。
3. **禁止与隔离（中国内地）**：禁虚拟货币、禁代币化融资，只鼓励"非金融"的数字化赋能（溯源、计量、RDA）。

桥接逻辑只有一条主线：**"境内止步 + 香港/境外衔接"**。境内用联盟链把资产数字化、上链、做一级发行（价值生成）；价值流通（代币化、二级、市值管理）整体搬到香港沙盒或境外持牌区，且境内资产出境须证监会备案前置。两者不可在境内并轨，也绝不能用"境外合规"反过来规避境内红线。

## A1 — 书中的应用 (Past Application)

### 案例 1：朗新集团 / 协鑫能科 充电桩·光伏收益权 RWA（香港沙盒）
- **问题**：境内绿色基建存量大、流动性不足，想融资却被境内代币化红线锁死，不能境内发币。
- **方法论的使用**：先用 f20 判定内地属"禁止隔离"范式，境内只能做非金融数字化；再把收益权代币化整体放到香港监管沙盒，搭建"两链一桥"平台，锚定收益权而非所有权、不面向境内居民募资。
- **结论**：形成"境内资产、境外价值释放"的双层结构，是先判范式、再定出海通道的标准范本。
- **结果**：2024 年于香港沙盒发行；与协鑫共同验证了新能源资产境外合规代币化路径（c23 / c24）。

### 案例 2：华润隆地「充美好」充电桩 RWA（香港 Ensemble 沙盒）
- **问题**：香港车桩比仅 7%、融资缺口大，但必须合规且穿透监管，不能做成离岸集资盘。
- **方法论的使用**：以特定充电站未来 1–3 年经营收益权（非所有权）为底层，ERC-20 分割；接入金管局 Ensemble 沙盒、穿透式监管、物联网数据实时上链；依 p25"同风险同监管"原则不碰稳定币、不向零售无差别发售。
- **结论**：国企 RWA 合规试点范式——收益权通证化而非资产货币化，是"积极探索"范式下的样板。
- **结果**：入选金管局 Ensemble 沙盒，为绿色基建收益权通证化提供可复制路径（c03）。

### 案例 3：德林控股 香港地产类 RWA 合规代币化（持牌架构）
- **问题**：商业地产 / 私募股权流动性枯竭、跨境流通受限，需打通持牌监管框架下的代币化。
- **方法论的使用**：依托香港证监会持牌机构（第 1/4/6/9 类牌照）装入有限合伙基金（LPF）获"无异议函"；按 f20 香港"积极探索"范式 + 投资者适当性要求，以 HashKey Chain + XRPL 双链做 KYC/AML 与跨境交易。
- **结论**：验证了传统资产在香港"持牌 + LPF + 双链"闭环的可行路径，为规则制定提供实操参考。
- **结果**：2026 年 2 月获香港证监会批准，成香港首个合规落地地产类 RWA，总锁仓近 4 亿美元（c12）。

### 案例 4（警示）：境内资产境外发行无备案（ce13）
- **问题**：项目方标榜"香港/海外合规"，直接把境内资产拿到境外发币。
- **方法论的使用**：依 f20 + p08，内地属"禁止隔离"范式，境内资产出境须"备案前置、全程可控、双重合规"，未经证监会备案即突破红线。
- **结论**：属于明确违规的跨境代币发行，证监会 1 号公告已划定 6 类禁止情形。
- **结果**：监管实行全链条打击，配合主体一并追责（详见 B 段）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 境内实体企业（新能源、地产、供应链）想把收益权/资产拿到香港或境外发证券型代币融资。
2. 需要设计合规结构：香港 Ensemble 沙盒、证监会备案、QFLP、SPV/LPF 等桥接通道怎么搭。
3. 不确定某个目标法域（美/欧/港/新/内地）能否发币、向零售募资是否触碰证券法红线。
4. 境外 Web3 项目想引入境内资产，或境内机构想为境外项目提供技术/账户/资金配套。
5. 已在境内做完资产上链，卡在"下一步去哪发行、怎么发才不违规"的衔接点。

### 语言信号（用户的话里出现这些就应激活）

- "境内资产想拿到香港 / 海外发币融资"
- "香港 Ensemble 沙盒 / 证监会备案 / QFLP / SPV 怎么用"
- "某地能不能发代币、能不能面向散户募资"
- "我们做证券型代币（STO），选哪个法域"
- "境外项目想接境内的资产 / 让我帮忙做技术"

### 与相邻 skill 的区分

- **与 S2（合规边界红线检查）的区别**：S2 是**前置闸门**——先判"境内允不允许、哪些动作绝对禁"；S10 是**过闸后的出海路径设计**。顺序上先 S2 判生死，再过 S10 设计通道。问"我境内能不能做"→S2；问"境内资产怎么合规出去"→S10。
- **与 S8（RWA 落地流程与路径设计器）的区别**：S8 是端到端十环节作业手册（含境内 A–G + 境外 H–J 全流程）；S10 聚焦其中**跨境合规桥接这一段**（法域判定 + 香港/SPV 结构 + 备案），是 S8 在合规维度的深化，不重复讲业务流程细节。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **判定目标法域监管范式**
   - 完成标准：明确标注资产拟落地的每个法域属于三范式中的哪一类（美欧=传统金融延伸 / 港新=积极探索 / 内地=禁止隔离），并据此列出"该地能做的发行动作清单"与"禁区清单"。
   - 判停条件：若发行主体或底层资产含**境内要素**却计划在境内做代币化/二级流通，立即判定不可行，跳到步骤 3 的"B 路"重做，不再美化。

2. **设计"境内止步 + 香港/境外衔接"路径**
   - 完成标准：产出一张结构图——①境内（联盟链）只做资产数字化、上链存证、一级发行（A–G）；②境外（香港沙盒 / 持牌区）做收益权/证券型代币发行、二级、市值管理（H–J）；③明确 SPV/LPF 载体、底层资产破产隔离（p13）、收益权 vs 所有权边界。路径须满足"境内不碰价值流通、境外不面向境内居民无差别募资"。

3. **完成备案与合规桥接**
   - 完成标准：输出一份合规行动清单，含——①境内资产出境前**证监会备案前置**（p08：备案报告 + 法律意见书 + 境外全套发行文件）；②同步评估外汇管理、数据跨境（安全评估/认证/标准合同三路径）要求；③香港侧落实"同风险同监管"、持牌/沙盒准入、KYC/AML 与投资者适当性。三项齐备方可推进，否则标注为"待补正"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯境内"非金融"数字化赋能**（只做溯源、贡献计量、RDA，无境外发行意图）：属 S2 范畴，S10 仅作轻扫描。
- **纯术语 / 概念澄清**（只问"什么是证券型代币 / QFLP"）：转 S1 概念辨析器。
- **纯境外无境内要素的项目**（香港持牌、美欧注册，无境内资产、无境内居民参与、无境内配套）：本 skill 的"境内止步 + 备案"逻辑不适用，误激活会过度约束。

### 作者在书中警告的失败模式（来自 counter-examples）

- **ce13 无备案跨境发行**：标榜"香港/海外合规"却绕开证监会备案直接把境内资产境外发币，属明确违规，构成违规跨境代币发行。
- **ce14 跨法域监管套利**：借全球发行的"无界性"规避单一法域监管，向不特定零售用户无差别发售，极易触碰各国证券法（投资者适当性）红线；管辖与争端解决约定模糊时事后被多法域追责。
- **ce11 配套服务连带担责**：不仅直接参与违规违法，为境外违规 RWA / 虚拟货币提供账户、资金划转、技术支持也追责——"只是帮忙做技术"不能免责，科技公司、支付通道、技术外包是高发连带主体。
- **ce03 / ce12 虚假资产与投机炒作**：未经批准的 RWA、底层资产清单模糊、强调币价升值而非产业收益，我国金融管理部门未批准任何 RWA 代币化活动。

### 作者的盲点 / 时代局限

- 编写组含道衍数科（项目方）及多家 RWA 产业链服务商，**天然带有推广 Web3 产业应用的立场**，对监管态度的**不确定性偏乐观**——常以"合规化路径"收束，但境内红线仍刚性且可能随政策收紧。
- 稳定币 / 代币化的全球合法化进程、香港沙盒规则仍在快速演化，书中部分"前沿实践"可能已被新规覆盖。**使用时必须以最新监管公告（证监会、香港 SFC、金管局）为准，宁保守、不抢跑。**

### 容易混淆的邻近方法论

- "积极探索"≠"自由放行"：香港沙盒/持牌仍是强监管（发牌、KYC/AML、适当性），并非法外之地；误以为"去香港就能随便发"是常见认知偏差。
- 境内外双轨不可并轨：境内联盟链与境外代币市场之间必须有断裂点，任何"境内发、境外接"试图绕过备案的设计都应判为违规。


### 合规红线与使用须知（普通用户必读）

本技能提炼自《价值互联网产业应用蓝皮书（2025）》（蓝皮书编写组，主编：梁超杰）第三篇·第五章「合规边界」，仅供风险识别与科普参考，**不构成任何投资建议、法律意见或投资邀约**。

- 中国境内开展价值互联网与通证经济产业应用，**不得涉及通证代币化等加密金融行为**，应聚焦"非金融"的数字化赋能（溯源、贡献计量、RDA 真实数据资产等）。
- 包括稳定币在内的虚拟货币，**在中国境内发行与交易属于非法金融活动**（央行等十部门 2021 年《关于进一步防范和处置虚拟货币交易炒作风险的通知》）。境外交易所、项目向中国境内居民提供服务同样属非法。
- **连带责任无死角**：不仅直接参与违法，为境外违规项目提供账户、资金划转、技术支持也依法追责——"只是帮忙做技术"不能免责。
- 任何以"Web3/区块链"为名、要求充值、拉人头返利、承诺升值预期的，极可能是资金盘，**请勿参与、勿投资、勿转发**。

> 引用原文："不能涉及通证代币化等加密金融行为，而应聚焦探索'非金融'的数字化赋能产业提效方向。""包括稳定币在内的虚拟货币无法满足 KYC、AML 等要求，在中国境内发行与交易虚拟货币属于非法金融活动。" —— 第三编·第五章（合规边界）／ p02、ce03
