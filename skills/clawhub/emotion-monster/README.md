# 🦋 情緒小怪獸（Emotion Monster）

幫助 2-6 歲孩童認識、理解、表達自己情緒的互動工具。

## 🎯 這是什麼？

情緒小怪獸是一套專為幼兒設計的情緒教育工具。每一種情緒都化身成一隻可愛的小怪獸，讓孩子把情緒當朋友，而不是害怕或壓抑它們。

## 🚀 快速開始

```bash

python3 ~/.qclaw/skills/emotion-monster/scripts/emotion_cards.py

# 記錄情緒日記

```

## 📦 工具一覽

### 1. 情緒卡片（emotion_cards.py）⭐ 核心工具
展示 8 種基本情緒卡，每張包含：
- 彩色 ASCII 藝術
- 小怪獸角色
- 幼兒能理解的描述
- 「為什麼會這樣？」解說
- 「我可以怎麼做？」建議

### 2. 情緒日記（mood_diary.py）
- 📝 記錄每天的情緒（互動引導問答）
- 📊 本週情緒統計與趨勢圖
- 🌟 進步追蹤（鼓勵孩子看見自己的成長）

### 3. 情緒急救箱（emotion_coach.py）🩹
當孩子「崩潰 / 大哭 / 生氣」時的即時引導腳本，分五步驟：
1. 🏷️ 命名情緒：「我看見你很生氣」
2. 🤗 接受情緒：「生氣是正常的」
3. 🌬️ 深呼吸引導：「一起做泡泡呼吸」
4. 🗣️ 表達情緒：「用嘴巴說出來」
5. 🌟 解決方案：「現在可以怎麼做？」

### 4. 情緒日曆（emotion_calendar.py）
- 📆 月度彩色文字日曆（ Emoji 標記每天情緒）
- 📊 月度情緒統計與分佈圖
- 🌟 認識了幾種情緒小怪獸？

## 🎓 使用理念

### 核心概念
- **「小怪獸跑出來了」**：情緒來了不是壞事，是朋友來拜訪了
- **情緒沒有對錯**：開心、傷心、害怕都是正常的
- **爸媽陪伴**：每一個情緒都是爸媽陪伴孩子的好機會

### 語言風格
- ✅ 零責怪、零羞辱、零惩罚暗示
- ✅ 全繁體中文，適合 2-6 歲理解
- ✅ 爸媽版 vs 孩子版引導語分開顯示
- ✅ Emoji 大量使用，增加親和力

## 👶 適合年齡

- 主要：2-6 歲幼兒
- 爸媽可在旁邊陪同操作或朗讀引導語

## 🛠️ 需求

- Python 3（標準庫，無需額外套件）
- 終端機支援 ANSI 顏色代碼
- macOS / Linux / Windows
