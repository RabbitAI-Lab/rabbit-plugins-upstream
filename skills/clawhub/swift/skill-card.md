## Description: <br>
Swift helps agents write, review, debug, and optimize Swift code across concurrency, ARC, optionals, generics, SwiftUI, packages, testing, interoperability, Linux, and Swift 6 migration issues. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineers use this skill when writing or reviewing Swift code, resolving compiler and runtime issues, migrating to Swift 6 concurrency, tuning performance, and producing Swift package, SwiftUI, testing, or interop guidance. It is not intended for Xcode signing, App Store submission, or iOS app lifecycle tasks. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Local preference memory under ~/Clawic/data/swift/ can persist Swift project context, coding preferences, or corrections and reuse them in future assistance. <br>
Mitigation: Review or delete files under ~/Clawic/data/swift/ before use if persistence is unwanted, and allow preference writes only for preferences or corrections the user states. <br>
