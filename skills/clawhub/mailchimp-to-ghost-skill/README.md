# Mailchimp to Ghost SKILL

**Version: 1.0.0**

This repository contains the `mailchimp-to-ghost` skill for Agents, allowing your AI agent to mirror posts made to a Mailchimp mailing list over to a Ghost blog. It's useful when migrating your content from the former to the latter.

It's available from:
- [https://github.com/nickludlam/mailchimp-to-ghost-skill](https://github.com/nickludlam/mailchimp-to-ghost-skill)
- [https://clawhub.ai/nickludlam/mailchimp-to-ghost](https://clawhub.ai/nickludlam/mailchimp-to-ghost)
