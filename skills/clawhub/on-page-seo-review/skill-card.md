## Description:

Review one URL against its target query and hand back exact Before → After edits for the title, headings, opening, content gaps, links, images, schema and CTA. Use for "review this page for SEO", "why isn't this page ranking for X", "on-page audit", "optimize this blog post".

This skill is ready for commercial/non-commercial use.

## Use Case:

SEO practitioners and site owners use this skill to review one page against a target search query and prepare prioritized, specific on-page edits.

## Known Risks and Mitigations:

Risk: The security review found no issues but noted that one unresolved reference leaves the review evidence incomplete.

Mitigation: Consider that uncertainty before installing, and check proposed edits against the page and current search results before applying them.
