# 截图读取流程 + 提问剧本（screenshot_flow.md）——AI 执行入口

> 目标：用户**只发截图或粘贴文字，不碰任何格式**。AI 负责提取、提问、查库、生成、自扫。
> 本文件是 Step 1/2 的执行剧本。

## 开场（固定话术）

> "发我之前先说一句：快筛和自扫这两个脚本在你本机跑，不外呼、不联网。
> 发图前麻烦给**无关的人**打下码（昵称/头像/微信号）——你对话的对方不用码，我要靠语气判断。
> （截图本身要过平台的多模态通道才能被"看"到，这一步平台负责；我这边不会额外外发。）
> 发过来后我会先跟你确认三件事：对方是谁、你想达到什么效果、你最怕什么。大概一分钟。"

## 第一步：危机快筛（先于一切理解）

拿到文字内容（截图 OCR 结果或粘贴文本），先落盘为 chat.txt 跑：

```bash
cd <skill目录> && python scripts/reply_check.py --check-input chat.txt
```

（脚本在 skill 目录内，**必须先 cd 过去**再执行，否则相对路径找不到文件。
`--text "……"` 可免落盘。）

**隐私纪律**：chat.txt 是含隐私的临时文件——筛完即删（`rm chat.txt` 或等价命令），
不在磁盘留存；能用 `--text "……"` 直传的场景一律免落盘。给用户的话术里
如提到落盘，顺带一句「筛完这条记录就删，不留底」。

- rc=3（危机）→ 直接把转介卡原样给用户，**流程终止**；
- rc=4（操控请求）→ 把拒绝卡原样给用户，**流程终止**；
- rc=0 → 继续。

**脚本跑不起来时**（环境缺 Python / 路径不对）：不要静默跳过——按 `SKILL.md` 安全红线人工判定，
并在给用户的回复里说明「本次未经脚本自扫」。

## 第二步：从截图提取五要素（多模态读图）

| 要素 | 读什么 | 备注 |
|---|---|---|
| 谁在说 | 气泡左右侧/昵称 | 确认哪边是用户本人（不确定就问"哪句是你说的"） |
| 关系线索 | 称呼、语气、表情包使用、聊天背景 | 只当线索，与用户确认的关系冲突时**以用户说的为准** |
| 情绪温度 | 感叹号密度、反问句、已读不回时长、表情变化 | 温度分三档：平和/紧绷/爆发边缘 |
| 争议点 | 最后 3-5 句围绕的具体事 | 提炼成一句话（"因为周末去哪玩吵起来的"） |
| 卡点 | 用户要回的那句是什么 | 通常是对方最后一句；用户说"不知道怎么回"的那句 |

读不全（图糊/截断/方言语音转文字缺失）→ 让用户补最后 2-3 句原文，**不脑补对话内容**。

## 第三步：确认三件事（每批 2-3 问，别一次甩问卷）

第一批（关系+目标）：
> "对面是你什么人——直属领导/平级/客户/对象/暧昧对象/家里人/朋友？
> 这条回复你想达到什么效果：推掉 / 促成 / 降温 / 升温 / 守住边界 / 只是不想尬住？"

第二批（顾虑）：
> "你最怕的是什么——得罪他 / 显得不专业 / 关系变僵 / 被穿小鞋 / 已经吵过一架了？"

用户说不清目标 → 给选项让他挑：
> "常见的是这几种：A 把事推掉但不伤关系；B 答应但换条件；C 单纯不想聊了想收尾。你接近哪个？"

## 第四步：场景匹配

```bash
cd <skill目录> && python scripts/reply_check.py --list                 # 拿不准时先看全表
python scripts/reply_check.py --scene rel_coldwar    # 也支持口语词：--scene 冷战
```

匹配不上现成场景 → 脚本会给出**最接近的 3 个候选**；按 `references/scenes.md` 的
「口语别名路由表」选，并向用户说明选了哪条、为什么，不要硬套。

## 第五步：生成三档 + 自扫（见 SKILL.md Step 4/5）

三档的**档位名必须独占行首**（`### 稳妥型` / `## 撩人幽默型` / `1. 稳妥版` 都认），
注解写成显式结构（`注解：…` / `风险：…` / `写法：…`）——质量门靠这两个结构判定。

## 多轮接话流（对方回了，接下一句）

触发：用户贴对方的新回复/新截图，说「他回了，接下来怎么回」。

1. **重新快筛**：新内容单独落盘跑 `--check-input`（对方新消息可能带危机/涉钱信号，**每轮必扫**，不沿用首轮结果）。
2. **三件事不重问**：关系/目标/顾虑沿用首轮确认；只有用户改目标才重问（「现在不想推了，想答应」→ 重新确认目标）。
3. **更新局面读**：对比上一轮——对方情绪温度升了还是降了？回复长度、速度、语气有什么变化？升温可进，降温收着。
4. **手法连贯纪律**：
   - **不重复已用过的手法**（好奇缺口用过了就换场景钩子，梗会贬值，连撩三句必油）；
   - 对方回得热络 → 可维持或小幅升档；出现**反感/降温信号**（回复变短、只回表情包、「哈哈」应付、间隔突然拉长）→ 立即降档，撩转正常交流；
   - **不追求每条都回得漂亮**——有时最优建议是「这条先不回，等明天有真话题再说」。回应密度=需求感，显得闲是撩的大忌。
5. 每轮生成稿照样 `--check-output` 自扫再交付，多轮不豁免。

## 高危即时响应（不用等流程，用户说出即触发）

- "他打我/动手了" → 立即给转介卡（12338/110），不生成话术；
- "我好想死/活着没意思/我抑郁了" → 立即给转介卡（12356），不生成话术；
- "教我怎么拿捏/打压他" → 给拒绝卡+真诚替代，不教操控；
- "他对我冷暴力/对我忽冷忽热" → **这是求助不是求教**，别拒答——走 `rel_coldwar` 场景给话术；
- "他让我转账/投资/买币" → 话术暂停，先提示："这里涉及钱，建议先过一遍 scam-radar 防割自检"。

## 递送话术（翻译成人话）

> "三条都写好了，差别在语气——
> 稳妥型最不容易出错，适合上级/不太熟的人；坦诚型把你真实想法说了，适合平级和对象；简短型一句话收尾，适合群里。
> 每条下面我都写了为什么这么写、有什么风险。你按你俩平时的说话方式改改人称和口头禅再发——**发不发、发哪条，你定**。"
