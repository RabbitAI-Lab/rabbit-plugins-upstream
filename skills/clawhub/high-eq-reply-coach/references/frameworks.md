# 沟通框架手册（frameworks.md）

> 生成话术时按场景卡指定的框架落笔。本手册给每个框架的公式、适用语境、例句。
> 纪律：框架是公开成熟的沟通方法论，不发明新名词，不编造出处。

## PREP（结论先行）

- **公式**：Point 结论 → Reason 理由 → Example 例证 → Point 重申。
- **适用**：汇报、提诉求、要资源——一切「对方耐心有限」的场合。
- **例句**（申请预算）：「建议这个活动预算加 2 万（P）。上次同规模活动转化率 8%，加投主要花在流量采买上（R）。3 月那场就是同样打法，ROI 做到 1:5（E）。所以建议按 2 万追加，本周五前定（P）。」

## STAR（举证）

- **公式**：Situation 情境 → Task 任务 → Action 行动 → Result 结果（可量化）。
- **适用**：绩效面谈、述职、维权摆事实——需要「证明我做了什么」的场合。
- **例句**：「Q2 服务端连续两次故障（S），我负责稳定性专项（T），推动加了灰度发布和值班巡检（A），Q3 故障清零、可用性 99.95%（R）。」

## SBI（还原事实不评价）

- **公式**：Situation 情境 → Behavior 具体行为 → Impact 影响。
- **适用**：被甩锅、催人、给负反馈——要「说事不说人」的场合。
- **关键**：只描述可见行为和影响，不评价动机（「你没责任心」→ 禁说）。
- **例句**：「昨天联调会你没带测试数据（S+B），后端联调推迟了一天，测试排期整体后移（I）。」

## NVC 非暴力沟通（观察-感受-需要-请求）

- **公式**：观察（不评价的事实）→ 感受（我的情绪）→ 需要（我在乎什么）→ 请求（具体、可执行、小）。
- **适用**：亲密关系冲突、冷战破冰、情感道歉——一切「关系比输赢重要」的场合。
- **关键**：观察≠评论（「你总是冷落我」是评论，「这周我们有三天没说话」是观察）；请求≠要求（允许对方说不）。
- **例句**：「这几天我们没说话（观察），我心里挺不好受的（感受），我很在乎我们（需要），今晚能通个电话吗（请求）？」

## DESC（立边界）

- **公式**：Describe 描述 → Express 表达 → Specify 明确 → Consequences 结果。
- **适用**：被查手机、被越界要求、被反复触碰底线。
- **例句**：「昨晚你又翻了我手机（D），我很难受，感觉不被信任（E）。手机是我的隐私，希望以后不要再看（S）。你不放心可以直接问我，我都会答；再翻的话，我会觉得这段关系需要重新考虑（C）。」

## 三明治拒绝法（接受-转折-建设）

- **公式**：接住对方（态度/感谢）→ 转折摆事实 → 建设性替代方案。
- **适用**：拒绝上级派活、拒绝借钱、拒绝邀约——要「说不但不得罪人」的场合。
- **关键**：替代方案是三明治的灵魂，没有替代方案的三明治只是拖延。

## 渐进式拒绝阶梯（同一个请求反复来袭时专用）

一次拒绝解决不了**反复**派活/反复借钱/反复劝酒——对方会试探你的边界弹性。阶梯原则：**语气逐级变硬，内容逐级变短**，不在第一级就把话说死，也不每次给同样的软台阶（同样的台阶用两次=邀请第三次）。

| 级 | 策略 | 示例（反复下班派活） |
|---|---|---|
| 第一次·软 | 给台阶+留余地：接事，但给明确时间方案 | 「今晚家里有事走不开，明早到岗第一件事就做，十点前给您初稿」 |
| 第二次·明 | 不解释过多，直接摆边界 | 「我下班时间一般不处理工作了，白天排给我优先级最高的我马上做」 |
| 第三次·坚 | 简短坚定+立机制，不再给新理由 | 「王哥，这规则定下来：急事您电话我，非急事走白天排期。今晚我帮不了。」 |

关键：每一级**说到做到**——说了「明早十点」就必须十点交，你的拒绝才有信用；第三级之后对方仍越界，问题已不在话术，在是否换环境。

## 倾听与镜像（对方倾诉/带情绪时专用）

核心原则（公开传播学共识）：**先接住情绪，再处理事情**——低段位沟通者忙着输出自己的逻辑，高段位沟通者先接收对方的情绪。对方带着情绪来时，解决方案说早了=火上浇油。

- **复述确认**：开口先复述再回应——「你的意思是…」「我理解的对吗」。被听见是对话中最基本的心理需求，复述一句，对话就从对抗转向理解。
- **文字镜像**（镜像技术的聊天版，有实证支持）：匹配对方的消息长度、语速和能量——对方发短句你别回长文，对方用表情你也可以用，对方秒回你也别故意晾着。能量同频的人天然显得「聊得来」。
- **接住情绪三式**：共情（「听起来那次经历让你挺难受的」）→ 自我披露（「我也有过类似的感受」）→ 开放式提问（「后来你是怎么走出来的？」）。三式走完，对方会觉得「你懂我」，比任何建议都拉近关系。
- **红线**：对方倾诉时，别急着给建议（「你应该…」）、别急着比惨（「我比你更…」）、别急着评判（「这事怪你…」）——三别急。

## 暂停技术（争吵降温专用）
- **公式**：叫暂停并说清时长 → 各自冷静 → 回来后先认自己的情绪部分。
- **关键**：暂停必须带时间点（「半小时后再聊」），不带时间点的暂停=冷战。
- **红线**：气头上不做任何不可逆决定（分手/辞职/拉黑/退群）。

## 撩人三式（暧昧/恋爱升温专用）

「撩」= 用轻松幽默制造情绪波动和暧昧张力，让对方**舒服地笑 + 对你好奇**。
撩与 PUA 的分界线只有一条：**落点是抬高对方还是贬低对方**。贬低=打压=操控，本 skill 黑名单硬拦。

1. **具体化夸奖**：夸细节不夸整体。「你笑起来左边有个梨涡」>「你好漂亮」。细节=你认真看过她，整体夸=群发感。
2. **好奇缺口**：说半句留半句。「刚看到个东西，第一反应是拍给你」→ 她必问「什么东西」。对方主动追问=她投入了注意力。
3. **推拉 lite**：先小调侃再夸，或反过来。「你这张自拍拍得不行——把奶茶拍得那么清楚，害我也想喝了」。调侃只落**无伤大雅的小事**（拍照技术/喝奶茶速度），绝不碰外貌短板/能力/家境。

配套手法：**场景钩子**（从她刚发的动态/当下的共同场景找梗，梗越具体越显用心）、**夸张幽默**（角色扮演式接梗：「报告，小的已就位」）。

### 力度分级（用错阶段是撩翻车第一原因）

| 阶段 | 可用手法 | 力度上限 | 示例 |
|---|---|---|---|
| **初识**（刚加好友，聊了不到一周） | 具体夸、场景钩子、开放式提问 | 不用推拉；不深夜长聊；不连续主动 | 「你朋友圈那张徒步照在哪拍的？光线绝了」 |
| **暧昧**（互有好感，有来有回） | 三式全开：具体夸/好奇缺口/推拉 lite | 推拉只落中性小事；一天最多撩一两句，其余正常交流 | 「在跟个很有意思的人聊天」 |
| **恋人**（已确定关系） | 三式 + 夸张幽默 + 偶尔直球 | 撩不能替代正经沟通——矛盾期停撩，先解决问题 | 「报告，今日份想你指标已完成」 |

**降档信号（出现即收）**：对方回复明显变短 / 只回表情包 / 「哈哈」应付 / 回复间隔突然拉长——
说明当前力度超了或话题没接住，立即降一档，撩转正常交流。**撩不升温就停，别加药。**

### 翻车对照（生成前先自检别写出左边的话）

| 翻车写法 | 为什么翻 | 高情商写法 |
|---|---|---|
| 「在吗」「吃了吗」「睡了吗」 | 查户口=零信息+暴露需求感 | 场景钩子：「你朋友圈那家店排了多久队？值不值」 |
| 「在干嘛」→「没干嘛」尬住 | 把球踢死 | 好奇缺口：「在跟个很有意思的人聊天」 |
| 土味情话连发三句 | 一句是幽默，五句是油腻 | 一句具体夸顶十句情话：「你笑起来左边有个梨涡」 |
| 深夜千字小作文表白 | 用力过猛，对方压力拉满 | 简短+留白：「今天跟你聊天挺开心的，明天接着聊」 |
| 「你这照片 P 过头了吧」 | 这不是推拉，是打压（黑名单） | 推拉 lite：「照片拍得不行——奶茶拍那么清楚，害我也想喝了」 |

### 进阶两式（熟络后可用，初识别用）

4. **场景预设**：在聊天里自然预设一个「你们俩在一起的未来场景」，带玩笑意味、不是正式邀约——「下次带你去，你负责吃我负责买单，公平吧」。妙处：预设了「还有下次」传递兴趣，玩笑外壳让双方都不用承认。
5. **试探钩子**：给日常回应加一个「专属感」钩子，**说完必留退路**——他给你披外套，别只说谢谢，接「这待遇是女朋友专属的吗？」，他笑了你就补「开玩笑的」。画面他记住了，台阶双方都有。**可进可退是钩子的灵魂，没有退路的钩子=逼宫。**

**万能公式**（检查任何一条暧昧消息）：具体画面 + 轻问题 + 轻微专属感 + 可进可退。暧昧不是油腻，是「你在我这里有点特别，但我不逼你承认」；有趣不是硬讲段子，是让画面、参与感和台阶同时成立。

分寸红线：
- 对方明确说「别这样」「没意思」→ 立即停，换正常交流；
- 不开黄腔、不发土味情话连击（一句是幽默，五句是油腻）；
- 初识阶段只用具体夸+场景钩子；推拉 lite 与进阶两式（场景预设/试探钩子）留给已熟络的关系；
- 撩的目的是双方开心，**对方不舒服的「撩」就是骚扰**，这条没有例外。

## 选框架速查

| 你要干什么 | 首选 | 备选 |
|---|---|---|
| 汇报/提诉求 | PREP | STAR |
| 证明成绩 | STAR | PREP |
| 说事不说人 | SBI | DESC |
| 关系冲突/破冰/道歉 | NVC | 承认-共情-改正 |
| 立边界 | DESC | NVC |
| 拒绝不得罪人 | 三明治 | 明确+简短 |
| 撩人/暧昧升温 | 撩人三式 | 场景钩子+夸张幽默 |
| 暧昧已熟络想更进一步 | 进阶两式（场景预设/试探钩子） | 万能公式自检 |
| 对方倾诉/带情绪 | 倾听三式+复述确认 | 文字镜像 |
| 正在吵 | 暂停技术 | NVC |
