## 口语别名路由表（2026-11-02 重构，方向敏感）

别名匹配按**长度降序**做，且**方向明确**才收——单字别名（「催」「表白」）歧义太大，一律不收。

| 用户口语 | 场景 key | 备注 |
|---|---|---|
| 对象催我回消息 / 对象催我见面 / 他不理我了 / 已读不回 | `rel_coldwar` | 情感，**不是**职场催进度 |
| 领导催进度 / 老板催交稿 / 催一下 | `work_urge` | 职场 |
| 我想表白 / 怎么表白 / 撩妹 / 暧昧 | `rel_flirt` | 主动开口，**不是** `rel_reject` |
| 被表白 / 拒绝表白 / 表白被拒 / 备胎 | `rel_reject` | 拒人 |
| 领导让我周末去公司 / 周末加班 | `work_refuse_overtime` | |
| 老板骂我 / 批评我 / 质疑我 | `work_blame` | |
| 客户不给钱 / 房东涨租 / 退款 / 投诉 | `gen_complaint` | |
| 对象说我胖了 / 嫌弃我 | `rel_boundary` / `rel_conflict` | 边界与降温两可时取边界 |
| 催婚 / 相亲 / 逼婚 | `rel_marriage_pressure` | |
| 家长群 / 老师 / 家校 | `gen_school` | |

匹配不上时脚本给出**最接近的 3 个候选**（按场景名 + 识别信号的字面重合度排序），
不要硬套——取候选里最像的并向用户说明选了哪条、为什么。

## 职场（work_*）

### work_refuse_overtime · 拒绝加班/下班派活
- **识别**：下班时间派活、周末加急/周末去公司、「辛苦一下」、临时需求。
- **典型目标**：推掉这次，但不留「不积极」的印象。
- **框架**：三明治拒绝法（接受-转折-建设）；备选「简短确认+边界」。
- **骨架**：接住态度 → 摆事实（手头事项）→ 给替代（明确时间点）。
- **示例**：「好的，需求我记下了。手头 A 项目今晚必须交，明早九点我先处理这个，十点前给您初稿，您看可以吗？」
- **雷区**：只回「做不了」；在群里情绪化吐槽；连续拒绝不给替代方案。

### work_report_up · 向上汇报/邀功
- **识别**：周报/述职/被问进展。
- **框架**：PREP；备选 STAR。
- **骨架**：结论先行 → 数据支撑 → 归因到动作 → 下一步。
- **雷区**：流水账；只讲苦劳；数据不可核实。

### work_performance · 绩效面谈/谈薪
- **识别**：绩效沟通、调薪、年终面谈。
- **框架**：STAR 举证 + PREP 诉求。
- **骨架**：2-3 个可量化成果 → 明确诉求 → 沉默等出价。
- **雷区**：用「我需要钱」当理由；当场接受第一个报价；无市场对照。

### work_blame · 被甩锅/被质疑
- **识别**：群里点名、跨部门推责、被质疑能力、被骂/被批评。
- **框架**：SBI 还原事实；备选 DESC。
- **骨架**：稳住不回怼 → 时间线+证据 → 聚焦补救分工。
- **雷区**：群里互撕；「你什么意思」反问；带人身评价。

### work_urge · 催人/被催进度
- **识别**：「好了吗」「几点能给」、催别人或被催、催进度/催稿。
- **框架**：SBI + 明确承诺。
- **骨架**：催人说影响要时间点；被催给准确时间点+风险前置。
- **雷区**：「尽快」等于没说；催三次不升级。

### work_apologize · 工作失误道歉
- **框架**：承认-补救-预防三段式。
- **骨架**：认具体错 → 补救动作 → 预防机制。
- **雷区**：「对不起但是…」；过度自责表演。

### work_credit · 被抢功劳/成果被冒领
- **识别**：同事把我的方案说成他做的、汇报里没提我、功劳被冒领。
- **框架**：SBI 还原事实 + 不撕破脸的自我主张；备选 PREP。
- **骨架**：私下沟通（不在群里开撕）→ 事实链（谁在什么场合说了什么、我的产出留痕在哪）→ 谈影响 → 提制度性诉求（针对流程不针对人）。
- **雷区**：群里公开对撕（赢口舌输关系）；只抱怨不给机制；事实没留痕就开谈。

### work_resign · 提离职/辞职开口
- **识别**：想离职、辞职、拿到 offer 要走、提离职怎么开口。
- **框架**：PREP + 感恩-明确-交接；备选三明治。
- **骨架**：一对一私下面谈 → 明确表态（不试探不拉扯）→ 一段具体的感谢 → 交接方案 → 原因只说中性（发展方向），不吐槽不控诉。
- **示例**：「王姐，想跟您当面说个事。我决定离职了，最后工作日是 X 月 X 日（明确）。这两年在咱组学到的 XX 是我最大的收获（感谢）。交接我列了文档，这周先把 A 项目交给小李，您看节奏行不行（交接）？」
- **雷区**：拿离职当谈判筹码（除非真想留且想好答案）；原因评价具体人；领导当场挽留就当场松口。

### work_ostracism · 被孤立/被排挤
- **识别**：群里没人理、开会不叫我、同事抱团、被排挤。
- **框架**：SBI 观察事实 + 自我节奏（先事实后归因）；备选找关键人一对一 DESC。
- **骨架**：区分「真孤立」还是「多心」（列三个可观察事实）→ 不急于讨好 → 找一个中立关键人一对一了解 → 保持稳定交付 → 涉霸凌/歧视留证据走 HR。
- **雷区**：群发小作文质问；过度讨好换认同；长期霸凌且 HR 无效还硬扛（认真评估去留）。

## 情感（rel_*）

### rel_icebreak · 破冰/开场
- **识别**：刚加好友、想开场、尬聊。
- **框架**：共同话题+开放式提问。
- **骨架**：从对方可见信息找具体点 → 具体评论 → 开放式问题收尾。
- **雷区**：查户口连问；「在吗」开场；上来夸外表。

### rel_flirt · 撩人/暧昧升温/主动表白
- **识别**：想撩、暧昧期、「在干嘛」「想你了」、土味情话、调情升温、想表白/怎么开口。
- **典型目标**：制造情绪波动和暧昧张力，让对方舒服地笑+对自己好奇。
- **框架**：撩人三式（具体夸/好奇缺口/推拉 lite）；备选场景钩子+夸张幽默。
- **骨架**：细节夸奖 / 说半句留半句 / 小调侃+夸（调侃只落中性小事）。
- **示例**：对方发「在干嘛」→「在跟人聊天（缺口）。这个人刚问我「在干嘛」（推拉），我正想怎么回显得比较帅（幽默自嘲收尾）」。
- **雷区**：调侃落点贬低对方=打压=PUA（硬拦）；土味情话连发油腻；开黄腔；对方反感不停。

### rel_coldwar · 冷战/已读不回/被冷暴力
- **识别**：冷战、已读不回超一天、吵架后互不联系、他对我冷暴力、对象不回我消息、催我回消息。
- **框架**：非暴力沟通 NVC。
- **骨架**：不翻旧账 → 观察 → 感受 → 小请求。
- **示例**：「这几天我们没说话（观察），我挺难受的（感受），我不想这样僵着（需要），今晚通个电话好吗（请求）？」
- **雷区**：第一条就讲道理分对错；「你再不回我就…」；找朋友轮番劝。

### rel_apologize · 情感道歉
- **框架**：承认-共情-改正三段式。
- **骨架**：认具体错 → 说出对方感受 → 具体改进行动。
- **雷区**：「对不起但是…」；道完歉立刻要对方表态原谅；空头保证。

### rel_marriage_pressure · 催婚/被逼相亲
- **识别**：催婚、催生、被安排相亲、亲戚追问「什么时候结婚」。
- **框架**：三明治 + 明确边界（不给虚假希望）；备选 DESC。
- **骨架**：接住关心（「知道你们是为我好」）→ 明确表态（不含糊、不用「再说吧」）→ 给替代（「我自己在接触，有进展会告诉你们」）→ 逼太紧就约定下次再谈的时间。
- **示例**：「妈，我知道你催我是怕我一个人过得辛苦（接关心）。这事我自己放在心上，也在接触。到年底真有情况我第一时间告诉你，别托人给我安排了行吗？（明确+替代+边界）」
- **雷区**：硬顶伤感情；用「再说吧」拖（会被反复追问）；承诺糊弄的假期限（后面更难收）；被逼到人身攻击时先暂停再谈。

### rel_parents · 跟父母沟通大事
- **识别**：跟爸妈说大事：换工作/不考研/去外地/对象他们不满意/要钱创业。
- **框架**：PREP + 接关心-摆计划-要信任；备选 NVC。
- **骨架**：接住担心（「我知道你们怕什么」）→ 摆事实摆计划 → 要一个具体的信任（「给我一年，年底看结果」）→ 分歧大不当场争输赢，约下次再谈。
- **示例**：「爸，我知道你们担心我去外地没人照应（接关心）。我查过了，那边公司宿舍、医保都落实了，头半年每月跟你们视频汇报一次（摆计划）。给我一年，年底要真不行我回来，行吗？（要信任）」
- **雷区**：「你们不懂」开场（一出口就对立）；要钱/要自由不给可验证的里程碑；当场吵翻（用暂停技术改天再谈）。

### rel_reject · 拒绝表白/邀约
- **识别**：被表白想拒绝/不想去的约会/备胎想脱身、表白被拒后怎么回应。
- **框架**：明确-感谢-不吊着。
- **骨架**：感谢真诚 → 明确表态 → 不给虚假希望。
- **雷区**：模糊拒绝=吊着；发好人卡还继续享受付出。

### rel_boundary · 立边界（查手机/越界要求）
- **识别**：查手机、报备行踪、断绝异性朋友、借钱给对象、被嫌弃/被说胖。
- **框架**：DESC。
- **骨架**：描述行为 → 表达感受 → 明确边界 → 后果与替代。
- **雷区**：边界说出口就要执行；内疚补偿式退让；涉钱越界转 scam-radar。

### rel_conflict · 争吵降温
- **识别**：对话升级、翻旧账、音量变高、对方说我胖了/嫌我。
- **框架**：暂停技术 + NVC。
- **骨架**：叫暂停（说清时长）→ 认自己的情绪部分 → NVC 说事不评价人。
- **雷区**：气头上做决定；翻三个月前旧账；人身攻击收不回。

## 通用（gen_*）

### gen_refuse_money · 拒绝借钱
- **框架**：明确+简短+不解释过多。
- **骨架**：直接表态 → 一句理由 → 可选非钱帮助。
- **雷区**：问「借多少」（一问就难拒）；被「这么点钱都不借」绑架；对方提投资抵债转 scam-radar。

### gen_school · 家校沟通（家长对老师）
- **识别**：家长群被@、跟老师沟通孩子问题、老师反馈情况怎么回。
- **框架**：PREP + 配合姿态；备选 SBI。
- **骨架**：回应事实与感谢关注 → 家庭侧动作（「我们在家会…」）→ 请老师同步观察点 → 有异议先私下找老师，不在群里争。
- **示例**：「谢谢李老师跟我说这个情况（感谢）。孩子在家我们今晚就跟他聊，这周先盯他作业完成时间（家庭动作）。您那边麻烦观察他上课状态，周五我跟您通个电话对一下，行吗（同步观察点）？」
- **雷区**：家长群抬杠/晒娃/拉踩；涉及孩子被区别对待先做事实记录再沟通；情绪上头的话隔夜再发。

### gen_complaint · 客诉/维权沟通
- **识别**：买到问题商品/服务缩水/要退款投诉、对方不给钱、房东涨租。
- **框架**：STAR 摆事实 + 明确诉求。
- **骨架**：事实链+凭证 → 依据条款 → 明确诉求 → 升级预告（12315）。
- **雷区**：情绪化辱骂（截图对你不利）；诉求不具体；口头承诺不落文字。
