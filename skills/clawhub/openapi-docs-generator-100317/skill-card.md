## Description: <br>
Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
API developers, backend teams, developer-experience teams, and maintainers use this skill to turn REST API details into clearer OpenAPI or Swagger documentation, reusable checklists, validation notes, and implementation guidance. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate for broad API or documentation requests because its trigger wording is loose. <br>
Mitigation: Users who want tighter routing should narrow the trigger phrases or disable implicit invocation before installation. <br>
Risk: Generated OpenAPI or Swagger guidance can be incomplete or mismatched if the available API details are incomplete. <br>
Mitigation: Review outputs against the service implementation and run any suggested validation commands or schema checks before publishing documentation. <br>
