# 风险应对策略详解

## 概览
ISO31000 标准定义了5种风险应对策略，本文档用通俗语言解释每种策略的含义和适用场景。

## 5种应对策略

### 1. 规避（Avoid）
**通俗解释**：不做这件事了，彻底避免风险发生。

**适用场景**：
- 风险极高且无法控制
- 采取应对措施的成本超过风险造成的损失
- 有替代方案可以完全避开风险

**制造业示例**：
- 不使用不稳定的供应商，改用稳定供应商
- 放弃高风险的新产品项目，专注于成熟产品
- 停止使用易出故障的老旧设备，更换为新设备

**优点**：彻底消除风险
**缺点**：可能放弃机会或增加成本

---

### 2. 降低（Reduce）
**通俗解释**：通过一些措施，减少风险发生的可能性或减轻后果。

**适用场景**：
- 风险可控，可以通过预防措施减少发生概率
- 风险发生后，可以通过应急预案减轻损失
- 这是最常用的策略

**制造业示例**：
- 培训工人，减少操作失误（降低发生可能性）
- 增加设备保养频率，减少故障（降低发生可能性）
- 建立备件库存，缩短故障停机时间（减轻后果）
- 增加质量检验环节，提前发现问题（减轻后果）

**优点**：灵活、实用、成本相对较低
**缺点**：无法完全消除风险

---

### 3. 转移（Transfer）
**通俗解释**：把风险转给别人，比如买保险、外包给有经验的公司。

**适用场景**：
- 自己没有能力或资源控制风险
- 外部专业机构能更好地处理风险
- 风险造成的损失可以通过保险覆盖

**制造业示例**：
- 购买设备保险，转移设备故障风险
- 将物流运输外包给专业物流公司，转移运输风险
- 购买产品责任险，转移产品质量风险
- 将危险化学品处理外包给专业公司，转移安全风险

**优点**：将专业的事交给专业的人
**缺点**：需要支付额外成本，且转移不完全（可能还有残留责任）

---

### 4. 分担（Share）
**通俗解释**：和别人一起承担风险，比如和供应商合作共担损失。

**适用场景**：
- 风险涉及多个相关方
- 通过合作可以共同降低风险
- 建立长期合作关系，共担风险共享收益

**制造业示例**：
- 与供应商签订质量协议，双方共担质量风险
- 与客户协商，共担市场变化风险
- 与合作伙伴共同投资新项目，共担项目风险
- 建立供应链联盟，共担供应风险

**优点**：分散风险、增强合作、共享资源
**缺点**：需要协商和信任，可能存在沟通成本

---

### 5. 承受（Accept）
**通俗解释**：风险不大或成本太高，自己扛着，出了问题再处理。

**适用场景**：
- 风险值很低（低风险）
- 应对措施的成本远高于风险造成的损失
- 风险无法控制，只能接受

**制造业示例**：
- 小幅度的工时浪费风险，可以承受
- 极低概率的微小质量问题，可以承受
- 市场价格小幅波动的风险，可以承受
- 偶尔的设备小故障，可以承受

**优点**：不花费额外成本
**缺点**：风险可能累积或放大，需要监控

## 策略选择建议

### 按风险等级选择
| 风险等级 | 推荐策略 | 说明 |
|----------|----------|------|
| 极高（≥15分） | 规避或降低 | 优先考虑规避，若无法规避则强力降低 |
| 高（10-12分） | 降低或转移 | 主要通过降低措施控制，可考虑转移部分风险 |
| 中（5-8分） | 降低或承受 | 适当降低，成本过高时可承受 |
| 低（1-4分） | 承受 | 一般可承受，定期监控即可 |

### 按风险类型选择
- 内部可控风险 → 降低策略
- 外部不可控风险 → 转移或分担策略
- 高成本高风险 → 规避策略
- 低成本低风险 → 承受策略

## 使用示例

### 示例1：设备故障风险
```
用户：针对"设备故障"这个风险，选什么策略？
系统：推荐使用"降低"策略，具体措施包括：定期保养、建立备件库存、培训维修人员
```

### 示例2：新供应商质量不稳定
```
用户：针对"新供应商质量不稳定"这个风险，选什么策略？
系统：可以考虑"降低"策略（加强质量检验）+ "分担"策略（签订质量协议，共担风险）
```

### 示例3：安全事故风险
```
用户：针对"安全事故"这个风险，选什么策略？
系统：推荐"规避"策略（消除安全隐患）+ "降低"策略（建立应急预案），绝不能承受
```

## 注意事项
- 策略不是绝对的，可以组合使用（如降低+转移）
- 选择策略时要考虑成本效益
- 策略确定后，要具体化到可执行的措施
- 定期评估策略有效性，必要时调整
