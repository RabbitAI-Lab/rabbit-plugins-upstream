# 报告模板

## 概览
本文档提供 ISO31000 风险评估报告和风险应对行动计划表的默认模板，采用 Markdown 格式。

## 风险评估报告模板

| 责任部门 | {责任部门} |
| 时间周期 | {时间周期} |
| 评估日期 | {评估日期} |

## 二、风险评估汇总表

| {编号1} | {描述1} | {分数} | {分数} | {分数} | {等级} | {措施} |
| {编号2} | {描述2} | {分数} | {分数} | {分数} | {等级} | {措施} |

- {风险编号1}：{风险描述}
  - 建议：{具体建议}

## 使用示例

### 示例1：新产品量产风险评估报告

```markdown
# 新产品量产 ISO31000 风险评估报告

## 一、场景信息

| 项目 | 内容 |
|------|------|
| 业务场景 | 新产品量产前试产 |
| 核心目标 | 保证首批产品良率达到95%以上 |
| 责任部门 | 生产部 |
| 时间周期 | 2024年1月-3月 |
| 评估日期 | 2024-01-05 |
| 报告版本 | V1 |

## 二、风险评估汇总表

| 风险编号 | 风险描述 | 发生可能性 | 后果严重性 | 风险值 | 风险等级 | 现有控制措施 |
|----------|----------|------------|------------|--------|----------|--------------|
| XCPCL-001-V1 | 新工人不熟练（触发）→ 产品不良率上升（事件）→ 影响良率目标（影响） | 4 | 3 | 12 | 高 | 已安排导师带教 |
| XCPCL-002-V1 | 设备调试不稳定（触发）→ 生产线停机（事件）→ 影响交付时间（影响） | 3 | 4 | 12 | 高 | 技术人员现场支持 |
| XCPCL-003-V1 | 核心原材料供应延迟（触发）→ 生产中断（事件）→ 影响交付目标（影响） | 2 | 5 | 10 | 高 | 已备安全库存 |

## 三、风险等级统计

| 风险等级 | 数量 | 占比 | 风险编号 |
|----------|------|------|----------|
| 极高（≥15分） | 0 | 0% | - |
| 高（10-12分） | 3 | 100% | XCPCL-001-V1, XCPCL-002-V1, XCPCL-003-V1 |
| 中（5-8分） | 0 | 0% | - |
| 低（1-4分） | 0 | 0% | - |

## 四、重点关注建议

### 极高风险项（需立即处理）
- 无

### 高风险项（需尽快处理）
- XCPCL-001-V1：新工人不熟练导致产品不良率上升
  - 建议：增加岗前培训时长，强化技能考核
- XCPCL-002-V1：设备调试不稳定导致生产线停机
  - 建议：提前进行设备试运行，优化调试流程
- XCPCL-003-V1：核心原材料供应延迟导致生产中断
  - 建议：增加备选供应商，提高安全库存

## 五、总结
本次识别出3个高风险项，主要集中在人员技能、设备稳定性和供应链三个方面。建议立即制定应对方案，确保量产目标达成。
```

### 示例2：风险应对行动计划表

```markdown
# 新产品量产 风险应对行动计划表

## 一、计划信息

| 项目 | 内容 |
|------|------|
| 业务场景 | 新产品量产前试产 |
| 责任部门 | 生产部 |
| 制定日期 | 2024-01-06 |
| 计划版本 | V1 |

## 二、风险应对计划

| 风险编号 | 风险描述 | 风险等级 | 应对策略 | 具体措施 | 责任人 | 完成时间 | 验证方式 |
|----------|----------|----------|----------|----------|--------|----------|----------|
| XCPCL-001-V1 | 新工人不熟练导致产品不良率上升 | 高 | 降低 | 组织新工人进行为期5天的专项技能培训，培训后进行实操考核 | 生产部经理 | 2024-01-15 | 检查培训记录和考核成绩，统计培训后2周内的产品不良率 |
| XCPCL-002-V1 | 设备调试不稳定导致生产线停机 | 高 | 降低 | 提前1周进行设备试运行，优化调试流程，建立设备调试检查清单 | 设备工程师 | 2024-01-10 | 检查试运行记录，统计调试期间停机次数 |
| XCPCL-003-V1 | 核心原材料供应延迟导致生产中断 | 高 | 降低+分担 | 增加备选供应商，提高安全库存至15天，与主供应商签订质量协议 | 采购经理 | 2024-01-20 | 检查备选供应商资质，确认库存水平 |

## 三、策略统计

| 应对策略 | 数量 | 占比 | 风险编号 |
|----------|------|------|----------|
| 规避 | 0 | 0% | - |
| 降低 | 3 | 100% | XCPCL-001-V1, XCPCL-002-V1, XCPCL-003-V1 |
| 转移 | 0 | 0% | - |
| 分担 | 1 | 33% | XCPCL-003-V1（组合策略） |
| 承受 | 0 | 0% | - |

## 四、实施跟踪
建议每周跟踪措施执行进度，每月评估风险值变化情况，必要时调整应对策略。
```

## 注意事项
- 报告采用纯 Markdown 表格格式，不包含复杂的排版
- 风险描述格式为"触发条件+风险事件+影响目标"
- 风险编号遵循 risk-numbering.md 中定义的规则
- 版本号与风险编号中的版本一致
- 统计信息自动计算，保持数据一致性
