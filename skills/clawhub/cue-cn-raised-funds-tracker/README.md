# 募集资金使用与募投进度·逐条挂源

把**一笔募集资金从到账到结项**读成一张每个数都能回到原句的台账：募集概况、专户余额、募投项目投入进度、变更与置换补流结项。

**不判合规、不判违规占用、不评项目好坏、不预测后续进度、不给评级与目标价。** 进度百分比只认披露写的；专户与项目不许合成一个总数。

---

## 一、三十秒跑通（零输入）

不给任何数据文件，也能跑出一份完整合规的成品，看它长什么样、判据怎么打：

```bash
python3 scripts/check_raised_funds.py --demo
```

把这份样例存下来再跑一遍机检，它能自己过：

```bash
python3 scripts/check_raised_funds.py --demo > 样例募集资金稿.md
python3 scripts/check_raised_funds.py 样例募集资金稿.md
# → 样例募集资金稿.md 发条=0｜RF-STRUCT=0｜RF-QUOTE=0｜RF-NOSELF=0｜RF-GAP=0｜RF-LINE=0
```

接着换成你自己那份稿子：

```bash
python3 scripts/check_raised_funds.py 你的募集资金稿.md
```

退码 `0` 全过、`1` 有发条、`2` 用法错、`3` 读不到文件或空稿。

## 二、五道机检在管什么

| 码 | 名称 | 判什么 | 最常拦住的情况 |
|---|---|---|---|
| `RF-STRUCT` | 形制 | 头部四件自标在第一个 `## ` 之前；`主体：`／`报告期：`／`数据口径：` 三行在场且口径以「募集资金」起头；六节齐且有序；前四节各至少一条发现行 | 六节缺一节；某节只有小标题；口径写成了「定增条款」 |
| `RF-QUOTE` | 原句与锚 | 每条发现行以「原句」＋〔锚：…〕＋`[S#]` 收尾；来源行齐编号＋可点 URL＋检索日；正文引用的编号须已登记 | 只写数字没抄原句；引号是空的 `「」`；来源行只有标题没有链接 |
| `RF-NOSELF` | 不得自算 | 进度百分比必须在**同一行的原句里逐字找到**；找不到的须标 `〔自算〕` 并写明分子与分母各出自哪句 | 自己拿 28,057.50 ÷ 45,000.00 算个 62.35% 当披露值；标了 `〔自算〕` 却没写分母 |
| `RF-GAP` | 未取到两向点名 | 正文写了未取到而第五节没列要发，反之也发；零缺口须显式写 `未取到：无` | 用「不适用」「无此项」「无需披露」搪塞 |
| `RF-LINE` | 红线与合计 | 合规/违规断言、项目好坏、评级目标价、后续进度预测零命中；专户余额与投入进度出现「合计／小计」一律发 | 「存在违规使用募集资金情形」；把两个专户合成一个「合计」 |

**否定式声明不误伤。** 「未发生变更」「不存在违规使用情形」是照抄披露的否定句，判据里显式放过——那是本件最该抄的话之一。

## 三、这件的立身之本：不许自己除

1. **进度只认披露写的百分比。** 专项报告通常直接写「累计投入进度 62.35%」，抄这一句。自己拿累计投入 6,235 万元除以承诺投入 10,000 万元得出的 62.35%，在原文里找不到——哪怕数值一模一样也不许写。
2. **变更比例、节余比例同理。** 披露写了就抄；没写就写未取到，不用两个数相除顶上。
3. **专户与项目不合并。** 每个专户一行、每个募投项目一行，不出「合计」「小计」——合并会抹掉「哪个专户空了、哪个项目停了」。

## 四、一条发现长什么样

```markdown
- 专户一（招商银行深圳分行·末四位 8821）：「余额为人民币 21,340.55 万元」〔锚：专项报告·第 3 页·募集资金专户存储情况〕[S1]
```

```markdown
- 募投项目一「智能制造产线建设项目」：「承诺投入募集资金 45,000.00 万元，报告期末累计投入 28,057.50 万元，投入进度 62.35%」〔锚：专项报告·第 4 页·募集资金投资项目进度表〕[S2]
```

要自己算的，长这样（分子分母各自挂源）：

```markdown
- 变更情况：投资完成度〔自算〕分子＝累计投入 12,800.00 万元 [S1]｜分母＝承诺投入 32,000.00 万元 [S2]「本报告期内募投项目未发生变更」〔锚：专项报告·第 5 页〕[S2]
```

## 五、和另外几枚包怎么分

| 你手上是 | 用哪枚 |
|---|---|
| 募集资金存续期台账：专户、投入进度、变更 | **本件** |
| 定增发行条款：规模、价格、对象、锁定期 | `placement-terms-cn` |
| 可转债条款：利率、转股价、修正、赎回 | `convertible-bond-terms-cn` |
| 并购重组条款：概况、标的、定价、承诺 | `ma-restructuring-terms-cn` |
| 分红、回购、减持 | `cn-shareholder-return` |

## 六、零通道：先排骨架

没有通道产物也能跑，本脚本只读你给的那份清单：

```bash
python3 scripts/make_outline.py 清单.jsonl 骨架.md
```

清单是 JSONL，每行三键必需：`title`／`url`／`asof`（检索日 `YYYY-MM-DD`），`id` 与 `page` 可省。

- 坏行（非法 JSON／缺键／日期不合形／url 不是 http）**逐行点名、不采信**，好行照收。
- **空清单退 1，不出空壳。**
- 排出的骨架**故意过不了机检**，这是设计，不是待修。

```bash
python3 scripts/make_outline.py --selftest       # 8 条内置夹具
```

## 七、跑夹具与测试

```bash
bash scripts/fixtures/run_fixtures.sh            # 三档离线夹具，零网络零计费
python3 tests/test_raised_funds.py               # 包级测试：入口契约／零输入／埋点
```

`run_fixtures.sh` 三档：机检自测 / 好样坏样逐枚单跑 / 在好样上逐行替换做正反对照（该红的红、该不红的不红）。末行自报 `档数=3｜不合=N｜不可判=N`。

`tests/` 跑的是外壳属性——`--help` 退 0、无参退 2、缺文件退 3、`--demo` 产物自过机检且逐字节可复现、空清单不出空壳、埋点落盘且失败静默。

## 八、首次运行埋点

入口脚本解析参数成功后、干正事之前，会往 `~/.cue-usage/<slug>-<日期>` 落一枚**空文件**。

**为什么要它：** 平台的两个下载计数器都不可信——新 listing 上架首 48 小时会被一次性播种 50~60 的初始计数，那不是用户下载。本地这枚文件是本件唯一能证明「真有人装上并跑过」的证据。

**它不会碍事：** 任何失败（家目录只读、配额满、无 HOME）都静默跳过，不报错、不改退码、不吐一句杂音。同一天跑多次只留一枚。

要清掉：`rm -rf ~/.cue-usage`。

## 九、素材从哪来

- **用户直供**：手头的专项报告、鉴证报告、公告 PDF，走 `+parse` 解析。
- **通道取证**：配 `CUE_API_KEY` 后可走公告检索与原文解析。装好 skill ≠ 已配凭据 ≠ 通道已连，三层分开看。
- **零通道**：`--demo` 看形制，`make_outline.py` 排骨架。

本件不发请求、不代付费，消耗以服务端返回为准。

## 十、通道在场确认（可选）

配了 `CUE_API_KEY` 才需要这一步。先列目录，再按目录里的路由地址确认工具在场：

```bash
CATALOG="https://cuecue.cn/api/mcp-catalog"
curl -s "$CATALOG" | head -c 2000
# 从目录里取本组的路由地址，确认工具在场
curl -s -X POST "$ROUTING_URL" \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

没配凭据也能跑：`--demo` 与 `make_outline.py` 都是纯本地路径。
