# 渗透者悬疑局 · Infiltrator Suspicion Module

> **文件**：`skill/rules/suspicion.md`
> **定位**：局部事件模块（非主范式）。
> **路由**：SKILL.md §5 按需读取；§1 回合循环第 4 步在有 open 悬疑局时推进其阶段。
> **上游依赖**：`rules.md`（§2 判定四档 / §6 失败后果 / §7 关系 schema）、`events.md`（模板与本模块的接口）。
> **零新顶层字段**：本模块只增/改 `relations` · `flags` · `events` 三类已有字段，**绝不碰 `world.json`**。

---

## 一、定位与设计理由

狼人杀的范式是**二元阵营 + 有限局 + 集体投票 + 零和**：好人赢＝狼全灭，反之亦然，且必须"投死一个"。

《上下文》的范式是**多极博弈 + 开放世界 + 个体行动 + 关系账本**：没有"结束"这一说，势力互算，玩家以自由文本行动。二者**不可调和**——若让"抓内鬼"成为主玩法，会砍掉开放世界的连续性，把多极博弈压成二元对抗（**支柱漂移**）。

因此本模块只做一件事：**在既有世界里嵌一局"渗透者悬疑"**。它有明确的开始与收敛（像"一个事件"），但：
- 阵营不是二元**零和**，而是"内鬼效忠某个**真实存在的 rival 势力**，有**政治目标**"（渗透者模型）；
- 抓出内鬼**不结束游戏**，反而**牵出幕后势力**，把局势接回既有的势力博弈（A 支柱不降级）；
- 玩家不必"投票"，而是"**收集表态 + 自行判断 + 指认**"，附和与放逐由骰子裁决。

一句话：**它是事件，不是模式；它添一道暗流，不改整条河道。**

---

## 二、阵营模型（渗透者模型）

### 2.1 内鬼是谁

- **来源**：从本局所属势力的核心 NPC 中选（精写世界的 `core_npcs`；骨架世界现场补写的 NPC）。**必须**是该势力 `relations` 中已存在的实体（"名字即契约"）。
- **如何选**：优先选**有动机矛盾、有把柄、或与 rival 势力有可解释接触面**的 NPC；其立场须能自洽推出"为何背叛"（可取自该势力的 `tension_seeds` 或既有 secrets）。
- **不可暴露**：内鬼的**真实身份与真实阵营**只写在 `relations[<内鬼>].secrets`，玩家**不可见**（见 §四 泄底铁律）。

### 2.2 内鬼效忠谁 · 政治目标

内鬼效忠 `world.json` 中**真实存在的某个 rival 势力**（通常是敌国/竞争势力/结构性敌意方）。它不是"要杀光对方"，而是完成**一个政治目标**——四选一（或多选组合）：

| 政治目标 | 语义 | 达成时的影响 |
|---|---|---|
| 窃取情报 | 把该势力的关键秘密/档案/名单交给效忠方 | 该势力 `relations` 情报侧受损；效忠方获得把柄 |
| 破坏一次行动 | 让该势力的一次关键行动（军演/押运/谈判/清算）失败 | 行动相关 NPC 处境恶化；可联动 events 模板 |
| 策反关键人物 | 拉拢/胁迫该势力另一核心 NPC 倒戈 | 被策反者 `relations` 反转；关系图谱结构性变动 |
| 拖到某 due_clock | 延迟/破坏一个时限目标，拖过其 `due_clock` | 相关 open 事件到点失败；格局偏移 |

**书写规范**：政治目标与效忠势力合写成 `relations[<内鬼>].secrets` 中的**一条标记条目**，格式固定：

```
"真实效忠：<rival势力名>｜目标：<政治目标一句话>"
```

例：`"真实效忠：麟河｜目标：经灰潮港把审计长数据副本交出去，换麟河停遣卡萨德商船"`。

> 这条标记是**内鬼的唯一真相锚点**，也是 agent 判断"谁是内鬼"的依据。它不是普通秘密——但**玩家未取得决定性验证前，agent 不得承认或暗示它存在**。

### 2.3 玩家可当渗透者（方案 A）

- **默认**：玩家是"清白人"（与在场 NPC 同侧，共同面对一个未知内鬼）。
- **例外**：**仅当玩家已主动深度绑定某势力后**（帮过大忙 / 欠下大人情 / 已加入），agent 可**在某次悬疑局中暗中指定玩家为渗透者**，给玩家**双面身份**——玩家自知、NPC 不知；玩家须**当众演受害者**，同时**偷偷完成渗透目标**。
- **硬约束**：**绝不在玩家无准备时强塞**。指定前必须满足：玩家与该势力 `trust ≥ 70` 且近期有绑定行为；且需在叙事上给玩家可回绝的余地（如"你可以选择不接"）。
- **落盘**：`flags.player_hidden_role = "渗透者:<势力名>"`（普通状态为 `"清白人"` 或空；工程侧保留键，勿改名）。
- **对称性**：玩家当内鬼时，其行动**同样产生痕迹**（见 §四通道 1），在场 NPC 也可能调查玩家、指认玩家；规则对称，不因"主角光环"豁免。

## 三、生命周期四阶段

阶段存于 `flags.suspicion_phase`，取值 `潜伏 / 发酵 / 爆发 / 裁决`。

### 阶段 1 · 潜伏（创建）

| | 内容 |
|---|---|
| **引擎动作** | 闸门全开（§六）→ 选定势力与内鬼 → 定义政治目标 → 写入真相锚点 → 建事件。此阶段**不在叙事中点破任何异常**，最多呈现该势力"最近不太对劲"的**中性氛围**（不得暗示性）。 |
| **落盘字段** | `events` 追加一条（`name` 建议 `<势力>·渗透疑云`，`status=open`，`tension=30~50`，`due_clock=创建 clock + 数日~数周折算`）；`relations[<内鬼>].secrets += "真实效忠：…"`；`flags`：`suspicion_faction` / `suspicion_phase="潜伏"` / `suspicion_start_day` / `suspicion_year` / `suspicion_count_this_year`（+1）。<br>> 注：`tension` 起值取 30-50（比 `events.md` 通用"潜伏档 30-40"略高，因内鬼局初始暗流更重）——两者不冲突，本模块优先。 |
| **叙事要求** | 克制。玩家此时只应感到"世界照常运转"，**没有任何可疑描写**。tension 只体现在事件账本里，不必上叙事。 |

### 阶段 2 · 发酵（内鬼暗中行动）

| | 内容 |
|---|---|
| **引擎动作** | 内鬼按其政治目标**做一件事**（每推进一段或每轮一次，节奏由 agent 定）。**每次行动必须留一条"可被察觉的痕迹"**（见 §四通道 1）。tension 缓升（每痕 +5~10）。 |
| **落盘字段** | `memory.md` 活跃区追加**一条客观痕迹条目**（`- 【day N hh:00】…`）；`flags.suspicion_phase="发酵"`；`flags.suspicion_traces`（本局已产生痕迹数，自查用）。不写未查证痕迹的正文进 flags。 |
| **叙事要求** | 痕迹必须是**物 / 事 / 时间**的客观陈述，**禁写人、神态、动机**。玩家不查 → 只是背景噪音；玩家查 → 可能成为线索。**不点破、不暗示谁可疑。** |

### 阶段 3 · 爆发（矛盾顶到明面）

| | 内容 |
|---|---|
| **引擎动作** | 触发一次**关键事件**把矛盾公开化——三选一：**公开指控** / **重大失窃** / **关键时刻掉链子**。tension 跳升（→80~95，与 `rules.md §5.3` 重大恶化 80+ 对齐）。进入**指认窗口**（限时若干行动窗）。 |
| **落盘字段** | `tension` 跳升；`flags.suspicion_phase="爆发"`；`flags.suspicion_window_left=N`（建议 4~8 个行动窗）；`events` 更新 summary/分支状态；`memory.md` 记录爆发事件。 |
| **叙事要求** | 此刻矛盾**已在明面上**：有人公开质疑、或损失已发生。玩家现在可"收集表态 / 调查痕迹 / 决定性验证"。窗口内每过一窗 `suspicion_window_left` 递减。 |

### 阶段 4 · 裁决（指认与揭晓）

| | 内容 |
|---|---|
| **引擎动作** | 玩家给出指认（或窗口耗尽=不指认）→ 按 §五 掷骰裁决附和是否充足 → 揭晓结局。**只有此刻**才可揭示真相。 |
| **落盘字段** | `flags.suspicion_phase="裁决"`；`save.py roll` 记录；按结局（§五）改 `relations` / `flags` / `events`；事件转 `closed` 或归档；**更新闸门**：`suspicion_last_end_day=当前 day`、`suspicion_count_this_year`（已计）、`suspicion_last_faction=<本局势力>`；清除 `suspicion_window_left` / `suspicion_phase`（或置回空）。 |
| **叙事要求** | 真相在此刻落地：证据链、内鬼身份、效忠势力、外交后果一并揭晓。**收敛要干净**——事件结束，余波沉淀为记忆，无结构残留。 |

### 3.5 极小示例（硬科幻题材《双陆纪元》）

| 字段 | 值 |
|---|---|
| 势力 | 卡萨德（军工官僚共和国，炮坊环带） |
| 内鬼 | 米洛（海关总署副署长） |
| 真实效忠 | 麟河（卡萨德与麟河 `relation=-55`，结构性敌意） |
| 政治目标 | 经灰潮自由港把失踪审计长托付的数据副本交出去，换麟河停遣卡萨德走私商船 |

- **潜伏（day 60）**：世界压力表掷出 61-84，被动子表命中「情报泄露(6)」；agent 过闸门：卡萨德内部张力（审计长失踪种子）≥60 ✅、开局 >30 日 ✅、本年 0 次 ✅、玩家无围猎与重大恶化 ✅、上一局非卡萨德 ✅ → 全开。
  `events += {name:"炮坊环带·渗透疑云", status:"open", tension:35, due_clock: day 74}`；
  `relations["米洛"].secrets += "真实效忠：麟河｜目标：经灰潮港转交数据副本，换麟河停遣商船"`；
  `flags: suspicion_faction="卡萨德", suspicion_phase="潜伏", suspicion_start_day=60, suspicion_year=1, suspicion_count_this_year=1`。
  叙事：只写炮坊环带照常运转。**无色。**

- **发酵（day 63 / day 66）**：内鬼行动两次，memory 追两条**客观痕迹**：
  `- 【day 63 21:00】海关档案室的封条换了新的，旧封条被平整地压在抽屉底。`
  `- 【day 66 14:00】一份审计卷宗的调阅记录上，经手人签名是打印的，不是手写。`
  tension 35→45；`suspicion_phase="发酵"`。**叙事仍不点破。**

- **爆发（day 74）**：due_clock 到点，麟河领事馆公开照会指控卡萨德"违约遣返"，同日炮坊环带公告审计卷宗核心页散佚。tension 45→85；`suspicion_phase="爆发"`, `suspicion_window_left=6`。玩家可在 6 个行动窗内查证。

- **指认（day 75~78）**：玩家查得两条痕迹（`flags.clue_档案封条=true`, `flags.clue_打印签名=true`）+ 询问伊莲（trust 高，通道 2 得分）→ 指认米洛。
  掷骰：证据 = 2 痕迹 + 1 证词 → 定档 **难度 60**；修正逐项按 `rules.md §2` 计：`+15 伊莲(在场附和,trust78) +12 持有米洛把柄(leverage)` → modifier=27。
  `save.py roll --slot xx --difficulty 60 --modifier 27 --label "指认米洛" --reason "难度=困难60(两条痕迹+证词,可信度中高); 修正=+15 伊莲trust78 +12 持有米洛把柄"`。

- **裁决**：roll 成功 → 米洛败露，`relations["米洛"]` 转敌对（`attitude≤-50`, `standing="败露"`），其效忠麟河暴露 → 卡萨德与麟河关系进一步恶化（可联动 events 模板 3/12）；玩家在卡萨德盟友 `trust` 上升。`flags.suspicion_last_end_day=78`, `suspicion_last_faction="卡萨德"`；事件转 `closed`。

## 四、信息机制（三通道 + 泄底铁律）

### 4.1 通道 1 · 行为痕迹（可调查）

- **产生**：内鬼每次行动，agent **必须**在 `memory.md` 活跃区留一条**可被察觉的异常**。
- **书写规范（硬性）**：只写**物 / 事 / 时间**，**禁止**写人、神态、语气、动机。
  - ✅ `仓库封条被动过` / `调令晚到了一天` / `卷宗调阅签名是打印的`
  - ❌ `他眼神闪躲` / `他答得太快了` / `他心虚地移开视线`
- **玩家调查** → 掷骰，难度按痕迹隐蔽度定档：
  | 痕迹性质 | 难度 |
  |---|---|
  | 公开可见（公告、公开记录） | 40 |
  | 需权限/需跑腿调档 | 60 |
  | 被刻意掩盖（销毁痕迹的边缘） | 75 |
  | 深度隐匿（需专业能力） | 90 |
- **成功**：`flags.clue_<slug>=true`（`<slug>` 为线索短名，如 `档案封条`），或记入相关 NPC `notes`。
- **未查证前**：痕迹只是背景噪音，**不点破、不提示**。
- **密度**：每局痕迹建议 ≤5 条，避免证据过密导致悬疑失效。

### 4.2 通道 2 · NPC 证词（会说谎）

- **机制**：在场 NPC 各有**观察片段**，其真伪**取决于玩家与该 NPC 的 `trust` / 立场**：
  | 状态 | 证词倾向 |
  |---|---|
  | `trust ≥ 70` | 大概率说真话 |
  | `trust 40~69` | 真假掺半 |
  | `trust < 20` 或立场对立 | 可能误导（未必撒谎，也可能是误判/偏见） |
- **触达**：玩家"询问 / 对质" → 掷骰。难度：常规询问 **40** / 撬开戒备者 **60** / 对质权势者 **75**。
- **结果**：`margin` 越高 → "撬开越多嘴"（越多 NPC 给出关键证词 / 证词越接近真相）。证词可入 `flags.clue_<slug>` 或相关 NPC `notes`。
- **禁止**：agent 不得在玩家**未开口询问**时，让 NPC 主动剧透。

### 4.3 通道 3 · 决定性验证（"验人"，有代价）

拿到**定论级证据**须付出代价，三选一（或多者叠加）：
1. **一次高难度掷骰**：难度 **75** 或 **90**；
2. **消耗关键资源**：支付 `relations.leverage`（把柄）/ `secrets`（情报单）/ 人情感，写成对应用户条目的扣减或 `flags` 计入消耗；
3. **冒暴露风险潜入查证**：成功得铁证，失败按 §6 失败后果表结算（可能暴露、可能树敌）。

- **定价原则**：验人代价应"**肉疼但不致命**"——一次机会成本 + 可能的关系损失；不得让验人变成零成本的必选动作。
- **拿到后**：`flags.clue_<决定性>=true`，**可支撑一次指认**，并使指认判定**降至难度 40**（铁证面前众人无话可说）。

### 4.4 局内泄底铁律（信息边界铁律的悬疑局特例）

> **你（引擎）掌握真相，玩家没有。**
>
> 叙事层**只允许出现可被观察的表象**。玩家**未取得的线索，一个字都不许提前泄露**：
> **禁止**任何暗示性描写（"他眼神闪躲""他答得太快""他不自然地顿了顿"），
> **禁止**替玩家做推理，**禁止**用形容词给 NPC 标注"可疑度"。
>
> **渲染的信息量必须严格等于玩家已掌握的信息量**：玩家没查到的痕迹＝不发生；
> 玩家没问出的证词＝不存在；玩家没验证的真相＝不在场。
>
> 真相**只活在 `secrets` 与你（agent）的内部推理里**，**绝不进入叙事层**。
> 泄底与"改档/换名"同罪——**一次泄底，整局悬疑作废**。

**与总则的关系**：本条是 SKILL.md §4.1「信息边界铁律」在悬疑局内的**局内特例/加强**，
二者不冲突，悬疑局场景下**同时生效**（§4.1 的三级信息呈现标尺同样是悬疑局叙事的底线）。

## 五、指认与裁决

### 5.1 不是"全体投票"

玩家不投"处决票"。流程是：**收集在场 NPC 表态 + 自行判断 → 玩家选择指认谁 → 掷骰裁决"附和是否足够"**。

### 5.2 附和判定（掷骰）

```
save.py roll --slot <档> --difficulty N --modifier M --label "<指认对象>" --reason "<依据>"
```

- **难度 N**：由**指认可信度**（证据强度）定档，**只取四档 40/60/75/90**：

  | 玩家手中的证据 | 难度 | 理由 |
  |---|---|---|
  | 决定性验证（通道 3） | 40 | 铁证在握，众人无话可说 |
  | ≥2 条痕迹 或 痕迹+可信证词 | 60 | 可信度中高，但仍需说服 |
  | 仅单一痕迹 或 单份证词 | 75 | 证据单薄，需过硬说服力 |
  | 空手指认（仅凭直觉/关系） | 90 | 近乎不可能——本就不该掷骰，除非玩家坚持 |

- **修正值 M**：**玩家关系资本**，逐项按 `rules.md §2` 计（在场 NPC 的 `trust`/`attitude`、玩家持有的 `leverage`/`secrets`），**禁止凭感觉填 0**。
- **`--reason` 格式**：`难度=<档位名><值>(<证据依据>); 修正=±a <来源> ±b <来源> …`

### 5.3 裁决矩阵（roll 结果 × 指认对象）

| | 指认**对**（真内鬼） | 指认**错**（无辜者） | **不指认**（窗口耗尽） |
|---|---|---|---|
| **roll 成功** | **内鬼败露**：身份暴露 → `relations[内鬼]` 转敌对（`attitude≤-50`, `standing="败露"`）；**效忠势力暴露** → 该势力与效忠方外交后果（可联动 events 3/6/12）；玩家在该势力盟友 `trust` 上升 | **诬告成立**：无辜者 `attitude/trust -15 起`（惨败 -30）；真内鬼继续潜伏；在场附和者可能追悔 | — |
| **roll 失败** | **证据不足被驳**：指认流产；内鬼**警觉并加速**，tension 反弹（+15~25），退回发酵 | **双输**：无辜者受损 + 内鬼趁乱坐实 | **内鬼得手**：政治目标达成，以**可量化损失**收场（§6 失败后果表） |

**共性收尾（三结局共用）**：
- 事件从 `events.open` 转 `closed`（或归档）；
- **闸门更新**：`suspicion_last_end_day = 当前 day`、`suspicion_last_faction = 本局势力`、`suspicion_count_this_year` 已计；清除 `suspicion_phase` / `suspicion_window_left`；
- **玩家渗透者局结束 → 复位 `player_hidden_role` 为 `"清白人"`（或置空）**；仅当该渗透身份成为后续剧情的长期伏笔时，由 agent 判断保留并在 notes 注明"身份持续中"，不得默认残留；
- 结论沉淀为 `memory.md` 压缩区/世界观记忆（**无结构性残留**）；
- **绝不动 `world.json`**。

## 六、触发与稀缺闸门

触发由**局势驱动为主**，世界压力表**兜底**，玩家**可主动发起**：

| 优先级 | 触发来源 | 说明 |
|---|---|---|
| 1 | **局势驱动**（主） | 出现"内鬼土壤"：某势力内部清洗 / 战前同盟集结 / 关键物资押运 / 一群人被迫隔离共处 |
| 2 | **世界压力表**（兜底） | `save.py pressure` 结果命中被动子表中「情报泄露(6)」或涉"内鬼/渗透"语义的模板时，**先查 §6.1 五维闸门再定形态**（全开→悬疑局 / 否则→普通事件，裁决见下） |
| 3 | **玩家主动** | 玩家可主动发起调查——**但是否真有内鬼由 agent 依局势定**，可能查了个寂寞（空局收场） |

> **触发源 2 的形态裁决**：命中被动子表「情报泄露(6)」或涉"内鬼/渗透"语义的模板时，先查 §6.1 五维闸门：**全开 → 以悬疑局形式实例化**（复合事件，走本模块四阶段）；**任一不满足 → 作为普通事件生成**（单次事件，走 events.md 被动路径）。同一模板两路触发的区分见 events.md《被动触发子表》。

### 6.1 智能稀缺闸门（五维联合判断，**全开才触发**）

| # | 维度 | 判据（agent 须读得到具体数字） |
|---|---|---|
| ① | **局势成熟度** | 某势力内部张力 ≥60，**或** 存在隔离共处场景（押运/围困/同盟集结等） |
| ② | **时间冷却** | `clock.day - suspicion_last_end_day ≥ 90`（从未有过则视为满足）；**且** 新档开局前 30 日不出（`clock.day ≥ 30`） |
| ③ | **密度上限** | 每游戏年（360 日）最多 **3** 次：`suspicion_year` 若 ≠ 当前年则先清零 `suspicion_count_this_year`；`suspicion_count_this_year < 3` |
| ④ | **错峰避让** | 玩家不在围猎（`flags.heat < 60`）、不在濒死/养伤、无 `tension ≥ 80` 的重大恶化事件进行中 |
| ⑤ | **反重复** | 候选势力 ≠ `suspicion_last_faction`（同一势力不得**连发**两次悬疑局；若两次确为同一势力，则其间须已发生**至少一次其他类型**的主要事件，由 agent 依 `events`/`memory` 判断） |

### 6.2 闸门状态 flags（供 agent 读取，替代记忆）

| 键 | 类型 | 含义 |
|---|---|---|
| `suspicion_last_end_day` | int | 上一局结束的游戏日（冷却判据） |
| `suspicion_count_this_year` | int | 本游戏年已触发次数（密度判据） |
| `suspicion_year` | int | `suspicion_count_this_year` 计数归属的游戏年（`年 = (day-1)//360 + 1`） |
| `suspicion_last_faction` | str | 上一局势力（反重复判据） |
| `suspicion_faction` | str | 本局所属势力 |
| `suspicion_phase` | str | 当前阶段：`潜伏/发酵/爆发/裁决` |
| `suspicion_start_day` | int | 本局创建日 |
| `suspicion_window_left` | int | 爆发期指认窗口剩余行动窗 |
| `suspicion_traces` | int | 本局已产生的可察觉痕迹数（自查用） |
| `clue_<slug>` | bool | 玩家已查证的线索标记 |
| `player_hidden_role` | str | 方案 A：玩家的隐藏身份。空/`"清白人"`＝普通；`"渗透者:<势力名>"`＝玩家为渗透者、效忠该势力（**工程侧保留键**，勿改名） |

> **铁律**：agent 每轮自查时**读这些数字**，不靠"记得上次是什么时候"——冷却是 90 日而非"大概隔了一阵"。

## 七、收束与边界

1. **只改状态层**：悬疑局**只**产生 `state.json` 变更（`relations` / `flags` / `events`），**绝不改 `world.json` 骨架**（势力矩阵、国家、核心设定一律不动）。
2. **收敛干净**：裁决后该事件从 `events.open` 转 `closed` 或归档（`archive`）；`suspicion_phase` / `suspicion_window_left` 归还为空；真相锚点**保留在** `relations[内鬼].secrets`（不删除——败露者身份成为既成事实，也可被后续事件引用）。
3. **沉淀记忆**：结论写入 `memory.md` 压缩区/世界观记忆——玩家此后"知道该势力有过一个内鬼"。**无结构性残留**：不新增顶层字段、不新增常驻机制。

## 八、题材适配表（十四题材）

底层张力结构不变（"一个内部人效忠外部、有政治目标、留下痕迹、被指认"），只换皮：

| tone_family | 渗透者语义 | 内鬼效忠谁 | 政治目标例 |
|---|---|---|---|
| `hard-sci-fi-political-thriller`（硬科幻） | 战前混入敌谍 / 军政内部清洗对象 | 敌国 / 竞争军政府 | 窃取舰队预算密档 / 破坏一次边检行动 |
| `modern-urban` | 竞标内鬼 / 公司内线 | 对手财团 / 资本集团 | 泄露标底 / 策反关键高管 |
| `military` | 战前混入的敌谍 | 敌对联盟 | 破坏补给押运 / 泄露作战序列 |
| `mystery` | **本命题材**（凶手/内鬼） | 真相掩盖方 / 幕后势力 | 抹除证据 / 制造伪证 |
| `corporate-war` | 商业间谍 / 并购内应 | 敌对公司 / 投行 | 泄露并购底价 / 拖垮一次董事会表决 |
| `campus` | 社团告密者 / 学生会内鬼 | 校外势力 / 对立社团 | 泄露评审内幕 / 破坏一次校园评选 |
| `isekai` | 新时空同化者 / 二心者 | 原时空派系 或 新时空派系 | 窃取交界情报 / 拖过裂隙窗口 |
| `cultivation` | 宗门叛徒 / 魔道暗桩 | 魔道 / 敌对宗门 | 盗取功法/丹药配方 / 破坏一次宗门大比 |
| `romance` | **弱适配**（可选，非优先） | 前段/对立方家族 | 隐瞒关键旧情 / 拖到某个婚约时限 |
| `closed-circle` | 狱中内线 / 号子里的眼线 | 对立帮派 / 外部走私势力 / 狱署 | 传递违禁品 / 制造一次"意外" / 铺垫越狱时机 |

| `apocalypse` | 据点内鬼 / 引路奸细 | 敌对军阀 / 掠夺者 / 教团 | 泄露水源坐标 / 破坏补给线 / 策反聚落 |

| `wuxia` | 门派叛徒 / 魔教暗桩 | 魔教 / 敌对门派 / 朝廷鹰犬 | 盗取秘笈 / 破坏武林大会 / 递送门派虚实 |
