## 一、题材定位与设计意图

《礁屿狱城》是一部"囚笼共处"题材的封闭关系生存局。锁礁屿是一座四面环海的孤岛重刑监狱，唯一通向外界的通道是货栈帮经营的驳岸码头。礁屿狱署、号门会、耳房线、墙外盟、货栈帮五方在此共处，谁都无法真正离开，放风场是各方唯一都给面子的公共空间。主角是转押入狱的新囚，也是棋盘上唯一还能选择"信任谁、背叛谁"的人。

本题材的核心张力来自立项书定死的两条独有机制：

- **信任度 / 猜疑度仪表**——每个 NPC 对玩家有独立信任值；封闭环境下信息稀缺，玩家每次透露或隐瞒都改变信任。信任崩塌即被孤立，而在狱中被孤立等于死。运行时例：玩家把线人的话转告号门会 → 线人信任 −30，此后不再供料。
- **情报货币（配额交换）**——物资配额（一包烟、一块肥皂、一顿加餐）与情报互为货币，玩家可用物资换情报、用情报换庇护。运行时例：玩家用两根烟从货栈帮换到"某狱警受贿"的把柄，再拿把柄向狱署要一次减刑。

第三条独有机制是**隔离事件触发**——"共处一室"使每个人都是嫌疑人。运行时例：号门会头目厉彪暴毙于放风场、全员在场，直接开悬疑局，四档判定（调查 40 / 取证 70 / 对质 85 / 审判 90）。

叙事张力机器沿用《上下文》通用骨架：**多方势力互算 + 结构性敌意 + 表面同盟藏裂缝 + 中立交汇点**。中立交汇点 = 放风场，其"谁在此动手谁犯众怒"的密约是物理边界。贯穿全局的母悬念是 `history` 末条"厉彪暴毙"：头目死因未明，五方信任同时崩塌，玩家每一个动作都在"信谁、卖谁"的赌桌上压注。

## 二、参考作品点名（仅点名，不列 URL）

下列作品在"封闭空间""信任博弈""囚徒生态"上对本作有启发：

1. **《肖申克的救赎》**——监狱生态的写实感与"越狱三条件"（时机/内应/物资）的耐心铺陈。
2. **《越狱》（Prison Break）**——狱内多方势力互算、内线与走私的齿轮式咬合。
3. **《东方快车谋杀案》**——封闭空间 + 有限人数 + 人人有动机的"全员嫌疑"结构。
4. **《大逃杀》《鱿鱼游戏》**——资源稀缺下的人际信任崩塌与规则内的算计。
5. **《监狱风云》**——狱霸帮派、号子地盘、狱警睁只眼的本土囚笼生态参照。

- **表面同盟藏裂缝（≥1 对 ≥50 且 note 藏裂缝）**：

  两对都"表面合作、内里裂痕"，玩家可顺裂缝切入。
- **微妙灰色 pair**：`huozhan|yushu = 20`——官商勾结、见不得光却牢不可破，是最易被玩家误判、也最该被利用的关系。

**关键 NPC 与裂缝锚点（共 10 名）**：

- 厉彪（已故头目）把受贿账本副本交托何笺作保命符，反被其害；渠五（暂摄会务）欲越过狱署与货栈帮结盟——号门会内忧外患。
- 何笺（耳房线头目）把线人名单分卖两家收双份；邬哑（装哑线人）替墙外盟递信却把请愿路线卖给货栈帮——内线的双面生意。
- 谈梧（律师）自抽卷页护人反成把柄；邱芷（家属干事）收钱卖路线——墙外盟的裂缝双源。
- 麻四（送货头目）自导查扣栽赃耳房线；索娘（账房）同时要挟狱署与墙外盟——货栈帮的两头通吃。

## 四、玩家起点与胜利通道

身份三选一（沿用 SKILL.md 开局）：**旅人**（新转押囚犯，无帮派）、**本地人**（狱中老人，自带 1 中立 1 紧张关系）、**空白身世**（身世随剧情揭示后补写）。

**3 条"玩家可以赢"的路径**（照立项书 §七）：

1. **翻案出狱通道**：集齐证据（家属团 + 律师 + 内线）证明冤案，合法出狱——赢在"洗清罪名、带着身份走出去"。
2. **越狱通道**：策反内线 + 筹物资 + 等时机，三条件齐备后越狱成功——代价是成为逃犯、失去社会身份。
3. **掌狱通道**：联合号门会与货栈帮架空狱署，成为"狱中实际控制者"——赢在狱内，代价是永久失去自由。

*失败不清档：如翻案证据被毁则越狱线开启；越狱失败则退守掌狱线，棋局层层收窄但不锁死。*

## 五、题材设计说明

本题材（《礁屿狱城》· `closed-circle`）的定位与独特性：

| 维度 | 本题材说明 |
|---|---|
| 势力语义 | 5 方：狱政当局 / 狱霸帮派 / 内线 / 家属律师网 / 走私势力 |
| 中立交汇点 | 放风场（唯一公共院子，禁在此动手） |
| 独有机制 | 信任仪表 + 情报货币（配额交换）+ 隔离事件触发 |
| 禁止项 | 万能钥匙式逃脱、无限物资、超级英雄式以一敌百 |
| 命名风格 | 封闭机构/空间词（狱署/号门/耳房/墙外/货栈/放风）+ 冷硬写实 |
| 张力机器 | 15 对矩阵；新增"翻案者 vs 狱署"的硬敌意底（墙外盟｜狱署 -70 等） |

**与最近邻题材的划界（一句话）**：最近者 `mystery`（同属封闭 / 调查）——悬疑=真相与证据（谁干的，一次性破案），封闭囚笼=生存与信任（如何共处，长期关系博弈）；本题材核心是"信任机器 + 资源稀缺"，非"破案"，且它是悬疑局的触发土壤（互操作而非同构）。

## 七、题材专属护栏确认（协议 §3.2）

- **辨识锚点齐备——封闭空间生态真实**：狱规、放风、探视、配额、帮派地盘、越狱代价均落地——`world_tech` 的 `tech_cc_escape`（越狱三条件）、`tech_cc_quota`（配额有限）、`tech_cc_isolation`（放风场密约）与 `key_locations`（正门哨塔/甲字大号/探视窗/驳岸码头）共同构成可信的囚笼生态。
  - **越狱代价**（`tech_cc_escape`）：越狱须同时满足"时机 + 内应 + 物资"三条件，缺一不可，孤岛无船必死——**杜绝万能钥匙式逃脱**；
  - **物资约束**（`tech_cc_quota`）：配额有限、用尽须重新交换，不能凭空取用——**杜绝无限物资**；
  - **武力约束**（`tech_cc_strength`）：人多 + 规矩 + 封闭，个人武力有天花板——**杜绝超级英雄式以一敌百**；
  - **信任约束**（`tech_cc_trust`）：信任崩塌即被孤立、等于死，玩家不能既讨好所有人又全身而退——**防开挂核心：资源稀缺 + 信任脆弱**。
- **明确禁止项均未出现**：无"万能钥匙式逃脱"（三条件缺一不可）；无"无限物资"（配额有限）；无"超级英雄式以一敌百"（武力天花板 + 帮派规矩）。
- **命名合规**：实体 id 全 ASCII 前缀 + 小写；展示名中文 2-4 字；未撞真实国家/知名跨国公司/在世真实人物/宗教神祇；跨题材零重名（词根 礁屿/号门/耳房/墙外/货栈/放风 与既有 9 题材零复用，未用禁词根 砚/泓/北岭/东岸/沈氏/东/青/铁）；封闭机构 / 空间词 + 冷硬写实的命名风格，与悬疑题材的"分局 / 会 / 馆"语汇刻意错开。
