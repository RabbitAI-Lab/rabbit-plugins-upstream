## 一、题材定位与设计意图

### 1.1 为什么"校园"适合关系张力机器

《上下文》的关系张力机器 = 多方势力互算 + 结构性敌意 + 表面同盟藏裂缝 + 中立交汇点。校园天然具备这套结构的雏形：学生自治组织、教师权力、社团话语、地下小团体，本就是一座微缩政治体。但纯校园题材最容易滑向"青春恋爱"或"热血成长"，张力停留在情绪层面、撑不起政治惊悚的棋局——**除非引入校外势力**。

本设计的核心判断是：**让"校园"从青春剧变成政治惊悚的关键变量，是第五方势力"砚外盟"（校外补习机构 + 网红 MCN + 家长联盟 + 灰色催收）**。校内的每一场权力游戏，一旦有校外资本与灰色手段介入，就立刻升级：换届账本变成洗钱通道，社团招新变成流量殖民，处分标准变成人情交易，考场纪律变成收债现场。围墙内外的规则被打通，青春才真正变成生意。

### 1.2 设计意图的三层结构

- **第一层（校内权力）**：学联会、师议会、社盟会、暗星社四方的权限与资源争夺，是玩家熟悉的校园场景（换届、评审、招新、处分）。
- **第二层（校外渗透）**：砚外盟把上述每一个场景"定价"——赞助、挂名、签约、对赌、收债，让校内矛盾有了外部杠杆。
- **第三层（信息战）**：匿名树洞作为中立交汇点，既是泄密武器也是控制工具（管理员即暗星社核心）。玩家的每一步行动，都在被树洞放大或沉帖。

### 1.3 玩家处境

玩家不是校长、不是教授，而是**身处四方缝隙里的"中间人"**——可能带着何明的半份证据、可能握着苏清洲的账本截图、可能刚被砚外盟盯上。玩家没有行政权力，但有信息。这正是关系张力机器想要的：用信息撬动结构。

### 1.4 护栏自检（协议 §3.2）

- 辨识锚点齐全：考试/社团/家长/校外补习机构/MCN 全部落地（见 key_locations 与 world_tech）。
- 明确禁止项：**无任何未成年角色涉毒涉性描写，无任何教师体罚情节美化**。师议会与砚外盟的"挂名人情"是成年人利益交换，不涉及学生身体伤害；处分权力被呈现为制度腐败而非暴力。

## 三、势力设计与关系张力机器映射

> 协议要求：校园必须加"校外势力"作为第五方。下面重点说明砚外盟如何承载张力。

### 3.1 学联会（nation_stucouncil）——学生自治最高机构

- **核心矛盾**：换届在即、经费账本被树洞曝光、暗收砚外盟赞助。
- **张力角色**：主席苏清洲（被家族对赌协议拖垮，收赞助是为还债）、财务长林越（改革派，自己却被勒索过）、纪律委员周禾（被暗星社拿把柄）。
- **机器位置**：学联会是"校内权力顶点"，却被砚外盟用钱买、被暗星社用把柄掐，是结构里最尴尬的"名义权威"。

### 3.2 师议会（nation_faculty）——学籍与处分权

- **核心矛盾**：评审为砚外盟关联企业背书、处分标准朝令夕改对"家族背景学生"开绿灯。
- **张力角色**：轮值主席柯岩（砚外盟挂名顾问）、青年教师闻涛（问责派，自己论文被买断署名权）、辅导员沈婧（给暗星社通风报信救弟弟）。
- **机器位置**：师议会是"规则制定者"，却最腐败——它的腐败正是砚外盟能渗透校内的制度入口。

### 3.3 社盟会（nation_clubs）——招新流量与话语权

- **核心矛盾**：头部社团被 MCN 签约"收编"、换届投票被暗星社用树洞操纵。
- **张力角色**：理事长江燃（嘴上拒收编，私下已被砚外盟签下）、街舞社白雪（流量派，小号抹黑江燃）、天文社杜宇（投票系统后门被暗星社买走）。
- **机器位置**：社盟会是"民意与流量场"，谁夺得它就夺得舆论——所以砚外盟要签约、暗星社要改票。

### 3.4 砚外盟（nation_offcampus）——**校外势力（第五方，关键设计）**

- **它是什么**：连锁补习机构 + 网红 MCN + 有背景的家长联盟 + 灰色催收的集合体，盘踞校畔"砚外大厦"与"畔咖啡"。
- **它如何承载张力（本题最关键）**：
  1. **把校内权力"定价"**：学联会的连任靠它的赞助，师议会的评审靠它的挂名，社盟会的流量靠它的 MCN——三方的权威都被它用钱置换成"债权"。
  2. **把学生把柄"武器化"**：莫林手里的"学生家庭负债表"（补习对赌协议违约名单）直接推给暗星社校内收债，校外生意校内收，围墙被打通。
  3. **让冲突越过校规**：当校内只有处分与舆论，砚外盟带来的是债务、合同、流量绑定——这些是校方管不了的"另一种规则"，于是校园冲突升级为跨边界的政治惊悚。
  4. **它自身也是裂缝源**：砚外盟已物色暗星社的替代者准备"弃车保帅"（见 faction_matrix 68 的 note 裂缝）；它与师议会互相拿捏（−63）；它与学联会表面客气（8）实则债权关系。
- **张力角色**：操盘人莫林（负债表持有者）、MCN 秦戈（洗钱签约金）、家长代理人罗成（孩子竟是暗星社后台，自己却签严打联名信）。
- **机器位置**：砚外盟不是"反派"，而是**让所有校内矛盾获得外部杠杆的结构性力量**——缺了它，matrix 撑不起来。

### 3.5 暗星社（nation_clique）——校内地下小团体

- **核心矛盾**：替砚外盟校内收债反噬、内部出现叛徒何明想投诚学联会。
- **张力角色**：核心晏星（匿名树洞真正管理员）、财政唐荔（备份了负债表准备反将一军）、叛徒何明（发的半份证据是晏星设的诱饵）。
- **机器位置**：暗星社是砚外盟的"白手套"与树洞的"隐形手"，是校内最危险也最易被利用的一环。

### 3.6 中立交汇点：匿名树洞（port_shudong）

- 谁都能发、谁都不知是谁，但上不上墙由管理员（晏星）定。它是五方信息战的主战场，也是玩家最便宜的杠杆与最危险的陷阱。

## 四、玩家起点与胜利通道

### 4.1 玩家起点（默认"空白身世/中间人"）

开局 5 条活局势均能被第一个回合动作触及：
1. 树洞账本截图曝光 → 玩家可去学生活动中心质问苏清洲，或把截图转给林越。
2. 砚外盟易拉宝进礼堂 → 玩家可去东阶礼堂撕传单、扫码查 MCN 合同。
3. 何明约密室见面 → 玩家可赴旧图书馆密室取半份证据，或反手卖给晏星。
4. 处分标准标红 → 玩家可去师议厅质询，或把标红帖顶上树洞。
5. 江燃被白雪当众质问 → 玩家可介入调解，或录音卖给秦戈。

### 4.2 三条"玩家可以赢"的路径（≥2–3，达标）

- **路径 A · 账本反腐线**：帮林越公开学联会赞助账本 → 苏清洲倒台 → 砚外盟失去校内"金主"接口 → 切断一条校外资金链。玩家不掌权，却用信息公开撬动结构。
- **路径 B · 收债反噬线**：拿到唐荔备份的"学生家庭负债表" → 曝光砚外盟对赌协议 → 触发家长联盟反水、监管介入 → 砚外盟被迫收缩。玩家把校外势力的命门（负债表）公开。
- **路径 C · 树洞夺权线**：策反晏星或何明，夺取树洞管理员权重 → 让真相上墙、让谣言下沉 → 翻转舆论战场。玩家夺下"信息武器"，让最弱一环变成最利一刀。

三条路径彼此咬合：账本（A）引出负债表（B），负债表牵出树洞控制权（C）。无救世主，各方仍在算计，但玩家确实能改变棋局。

## 六、8 条自洽清单自查报告

1. **Matrix 覆盖**：≤−50 两对（暗星社\|学联会 −58、师议会\|砚外盟 −63）；≥50 藏裂缝一对（暗星社\|砚外盟 68，note 藏"弃车保帅"裂缝）。**通过**。
2. **NPC 交叉咬合**：每个 core_npc 的 secret 都指向另一 NPC / 他国 tension_seed / matrix 关系——
   - 苏清洲 secret→砚外盟借条（offcampus tension）；林越 secret→被勒索（暗星社线）；周禾 secret→晏星把柄（clique）。
   - 柯岩 secret→砚外盟挂名（offcampus）；闻涛 secret→沈婧/柯岩；沈婧 secret→暗星社/弟弟债（clique）。
   - 江燃 secret→砚外盟签约（offcampus）；白雪 secret→暗星社截图（clique）；杜宇 secret→暗星社后门（clique）。
   - 莫林 secret→暗星社收债（clique）；秦戈 secret→江燃绑定（clubs）；罗成 secret→暗星社后台（clique）。
   - 晏星 secret→树洞（port）；唐荔 secret→负债表反制（offcampus）；何明 secret→晏星监控（clique）。**全部咬合，通过**。
3. **Tension 落地**：每国 2 条 tension_seeds 均可追溯到 matrix 或 NPC secret（如"赞助账本曝光"→苏清洲/林越 secret + 学联会\|树洞 −18；"对赌协议绑定"→莫林 secret + 师议会\|砚外盟 −63）。**通过**。
4. **地点承载**：每国 1–2 处 key_locations 均承载该国 tension——学生活动中心（换届海报 vs 揭帖）、师议厅/成绩机房（处分黑箱）、社团一条街/黑匣子（收编与谣言）、砚外大厦/畔咖啡（对赌与账本）、旧图书馆密室/天台（收债与叛徒）。**通过**。
5. **历史回响**：history 第 5 条"换届前夜"直接对应 opening 第 1 条"账本截图曝光"；第 4 条"对赌协议丑闻"对应 opening 第 4 条处分标准标红与砚外盟线。**通过**。
6. **技术约束**：world_tech 中"学籍制度"（处分 Pending 即冻结门禁食堂）、"门禁与一卡通"（轨迹可还原）明确解释了"为什么某些行动做不了/会被抓"——物理/规则边界成立。**通过**。
7. **开局活局势**：5 条 opening 均指向具体可交互的 NPC/地点/动作（质问苏清洲、撕砚外盟传单、赴密室见何明、标红处分帖、调解江燃白雪），第一回合即可触及。**通过**。
8. **玩家胜利通道**：A 账本反腐、B 收债反噬、C 树洞夺权三条路径明确，皆不依赖救世主。**通过**。

**结论：8/8 通过，逻辑自洽，可交付。**

## 七、题材专属护栏确认（协议 §3.2）

- **辨识锚点齐备**：考试/社团/家长/校外补习机构/MCN 全部落地（见 key_locations 与 world_tech）；核心变量是第五方势力"砚外盟"把校园权力游戏升级为校内外联动的政治惊悚。
- **明确禁止项均未出现**：无任何未成年角色涉毒涉性描写，无任何教师体罚情节美化——师议会与砚外盟的"挂名人情"是成年人利益交换，处分权力被呈现为制度腐败而非暴力。
- **命名合规**：实体 id 全 ASCII 前缀 + 小写；展示名中文 2-4 字；未撞真实国家/知名跨国公司/在世真实人物/宗教神祇；跨题材零重名（未复用硬科幻题材《双陆纪元》的卡萨德/麟河/奥斯特/土伊德/菲洛/灰潮等实体名）；校园命名风格（砚陆/学联会/师议会/社盟会/砚外盟/暗星社/匿名树洞，场景词派生）与其余题材刻意区分。
