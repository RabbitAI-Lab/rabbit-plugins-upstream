## 一、题材定位与设计意图

**开篇先说分野。** 《烟波江湖》与既有 `cultivation`（《天衍修真界》）同为古风江湖，是本批最需警惕的换皮项。二者的机制分野必须写死、不可靠氛围区分：

| 维度 | 修仙（cultivation） | 武侠（本题材 wuxia） |
|---|---|---|
| 主导力量 | **力量体系主导**：个人修为九阶，可外放法术、越阶碾压 | **社会规则主导**：门派格局 + 名声辈分，内力仅强化体魄 |
| 力量边界 | 法术威力随阶位上不封顶（仅受化神天花板约束） | **低魔红线**：内力不可外放伤人于百步，无飞剑、无御空 |
| 胜负关键 | 谁的阶位高、谁的法宝强 | 谁的名声正、谁的辈分高、谁占规矩与地利 |
| 语汇 | 宗 / 府 / 洞天 / 坊市 / 皇朝 / 境 | 门 / 帮 / 谷 / 会 / 楼（江湖），刻意避开修仙语汇 |

一句话：**修仙里"修为即真理"，武侠里"规矩即真理"。** 本题材是一部"门派格局 + 江湖规矩"为骨架的低魔武林局，玩家靠名声、辈分与拳脚在恩怨中立足——**内力有上限，规矩没有；江湖的胜负一半在拳脚，一半在辈分与名声。**

**三条独有机制（写进 `world_tech`）**：

1. **江湖规矩约束（名声 / 辈分即权限）**——每角色有"名声值"与"辈分资历"；违反规矩（偷袭、以大欺小、在禁斗之地动武）掉名声，名声低者被武林排斥，无法约战名宿、无法入盟。运行时：在八方栈动手 → 名声 −20，此后江湖帖不再送达、名门闭门不见。
2. **比武四档判定**——切磋（40，点到即止）/较技（70）/挑战（85）/生死决斗（90）。胜负由招数/兵器/地形/内力共同决定，**非纯数值碾压**。运行时：挑战落雁门首徒掷 88 落入"挑战"档——赢，但对方怀恨，结下新怨。
3. **秘笈 / 传承争夺（资源 + 秘密）**——秘笈、师门信物、旧怨账是核心资源与秘密；得秘笈者得一门绝学（**有限加成，非无限开挂**）。运行时：夺回被窃的《落雁刀谱》，可换落雁门庇护或转卖听雨楼换情报。

叙事张力机器沿用《上下文》通用骨架：**多方势力互算 + 结构性敌意 + 表面同盟藏裂缝 + 中立交汇点**。中立交汇点 = 八方栈（通衢客栈），"栈内禁斗"是各派共守的江湖共识，是其物理边界。

贯穿全局的"母悬念"是 `history` 首条"青霜灭门"：二十年前名门青霜门一夜灭门，真凶至今逍遥——落雁门掌门压案、执法长老是凶手、听雨楼楼主是唯一活口。玩家的每个动作都在"这桩旧案该不该翻、翻出来谁死"的赌桌上压注。

## 二、参考作品点名（仅点名，不列 URL）

下列作品在"门派格局""江湖规矩""低魔武学"上对本作有启发：

1. **金庸《笑傲江湖》**——名门与魔教的格局对立，以及"正道内部亦藏血案"的裂缝感。
2. **金庸《天龙八部》**——旧怨、身世与江湖辈分如何共同决定一个人的处境。
3. **古龙《多情剑客无情剑》**——杀手/情报楼生态与"卖消息卖人命"的灰色营生。
4. **《武林外传》**（取其客栈作为江湖交汇点的生态感，非其喜剧基调）——八方栈"谁来都得守栈规"的中立场设定。
5. **《绣春刀》**（取其在体制与江湖夹缝中、以规矩与名声为生的质感）。

| 实体 id | 名称 | 势力语义 | 核心矛盾 |

**张力机器映射（精选）**：

- **结构性敌意（≥2 对 ≤-50）**：`luoyan|tingyu = -62`（正道魁首与杀手楼势不两立）、`biaoqi|tingyu = -55`（听雨楼劫镖卖路，镖旗会视之为命脉大敌）。两对硬敌意构成江湖底色。
- **表面同盟藏裂缝（≥1 对 ≥50 且 note 藏裂缝）**：`biaoqi|canglang = 52`——镖旗会与沧浪帮共掌江湖商路、物流命脉上互相依存；裂缝在于镖旗会暗收名门的钱、也替他们押见不得光的私货。这是本作最该被利用的"蜜月裂缝"。
- **微妙灰色 pair**：`jingzhe|tingyu = 40`——惊蛰谷的毒与听雨楼的杀互补、暗中有交易，裂缝在于听雨楼早想吞下谷中秘方（毒方的窃与买的线）。
- **中立交汇点张力**：`tingyu|port_bafang = -8`——听雨楼明面在栈中卖消息，栈主却防着它暗面卖人命、坏了栈规。

**关键 NPC 与裂缝锚点（共 13 名）**：
- 楚雁回（门主）压案、与真凶共犯；商寒衣（执法长老）是灭门案真凶、毒方来自惊蛰谷；骆冰弦（首徒）查案逼近真相、还查出听雨楼楼主身份——落雁门三人各藏一手。
- 屠啸江（帮主）两头分赃；蒋三娘（军师）是听雨楼暗桩；段江生（水寨头领）私藏失窃毒药——沧浪帮内外皆是戏。
- 傅三针（谷主）认出灭门毒却装聋；商小满（弟子）把毒方卖给听雨楼换盘缠——药毒谷的明暗双账。
- 程万里（总镖头）押过灭门案赃物、握落雁门死穴；韦长庚（镖师）撞破沧浪帮私运军械却被会里抛弃——镖旗会的两头难。
- 萧夜阑（楼主）是青霜门唯一活口、以听雨楼复仇；燕无声（首席杀手）接的杀单背后另有黑手；白无算（消息先生）一桩案子卖三遍——听雨楼把所有人串成一张网。

## 四、玩家起点与胜利通道

身份三选一（沿用 SKILL.md 开局）：**旅人**（初入烟波洲、无门派）、**本地人**（某派中低层，自带 1 中立 1 紧张关系）、**空白身世**（身世随剧情揭示后补写）。

**至少 3 条"玩家可以赢"的路径**（协议 §3.1 通用护栏，照立项书）：

1. **盟主通道**：以名声 + 实力推动武林大会，当选盟主，重定江湖规矩——赢在"以规矩号令群雄"。
2. **破局通道**：揭穿某门派旧怨黑幕（如落雁门当年血案真凶商寒衣），瓦解旧格局——赢在"翻案改局"。
3. **商路通道**：联合镖旗会 + 沧浪帮控制江湖商路（物流即命脉），以势压名门——赢在"以势制名"。

失败不清档：盟主推举失败则各派割据加剧，棋局自然推向破局或商路路径，符合"失败改变棋局"。

## 五、题材设计说明

本题材（《烟波江湖》· `wuxia`）的定位与独特性：

| 维度 | 本题材说明 |
|---|---|
| 势力语义 | 5 方：名门剑派 / 漕运大帮 / 药毒谷 / 镖局联盟 / 杀手情报楼 |
| 中立交汇点 | 八方栈（通衢客栈，栈内禁斗） |
| 力量体系 | **低魔**：内力仅强化体魄、不可外放；名声辈分即权限；比武四档 |
| 禁止项 | 修仙式灵力/飞剑/御空、越级秒杀、一招灭门 |
| 命名风格 | 门派名（门/帮/谷/会/楼）+ 江湖场景词；刻意避开修仙语汇 |
| 张力机器 | 15 对矩阵；新增"旧案复仇网"（听雨楼把所有人串成一张网） |

**与最近邻题材的划界一句话**：武侠 = **门派格局 + 名声辈分规则**（社会规则主导，低魔，内力不可外放）；修仙 = **个人修为九阶天花板**（力量体系主导，可外放法术）——两者古风江湖的皮相相近，但"谁主江湖"的答案是规矩而非修为。

## 七、题材专属护栏确认

- **辨识锚点齐备——门派格局与江湖规矩可信**：门派格局（门/帮/谷/会/楼五方）、江湖规矩（名声/辈分）、比武礼节（拜帖、约战、栈内禁斗）在 `world_tech` 与 `key_locations` 中落地；镖局/客栈/码头生态（镖旗、镖单、官道镖路、漕运码头、通衢客栈）可信。
- **明确禁止项均未出现**：
  - **禁止修仙式灵力 / 飞剑 / 御空**——`tech_neili_limit` 写死低魔红线：内力仅强化体魄，不可外放伤人于百步，无飞剑、无御空、无隔空取物；
  - **禁止越级秒杀**——`tech_duel_four_tiers` 明确胜负由招数/兵器/地形/内力综合决定、同级别互有胜负；`tech_neili_limit` 明确再高的手也敌不过人多与刀阵；
  - **禁止一招灭门**——`tech_manual_scarcity` 明确秘笈仅有限加成、绝不带来力量体系整体跃迁；再高的手也敌不过人多 + 规矩。
- **防开挂核心落地**：内力有上限 + 名声约束（`tech_neili_limit` + `tech_jianghu_rules`）——武力不是通行证，名声与规矩才是。
- **与修仙的划界落地**：GDD 一节以对照表写死"力量体系主导 vs 社会规则主导""可外放法术 vs 内力不可外放""宗/府/洞天 vs 门/帮/谷/会/楼"；`world_tech` 首条即低魔红线硬约束；命名刻意避开修仙语汇。
- **命名合规**：实体 id 全 ASCII 前缀 + 小写；展示名中文 2-4 字（落雁门/沧浪帮/惊蛰谷/镖旗会/听雨楼/八方栈）；未撞真实国家/知名跨国公司/在世真实人物/宗教神祇；跨题材零重名（未复用既有 9 题材的词根：砚/泓/北岭/东岸/沈氏/东/青/铁 均未使用；亦刻意避开修仙的 宗/府/洞天/坊市/皇朝/境 语汇）；武侠命名风格（门/帮/谷/会/楼 + 江湖场景词）与修仙的"宗/府/洞天"、现代的"集团/资本/市政"刻意区分。
