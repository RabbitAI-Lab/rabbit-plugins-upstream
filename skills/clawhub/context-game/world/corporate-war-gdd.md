## 一、题材定位与设计意图

《中洲并购战》把《上下文》的"关系张力机器"搬进一座金融都会。这里没有军队，只有一场围绕家族企业控制权的敌意要约收购：敌对公司、友商联盟、投行、律所、家族企业五方混战，中立交汇点是反垄断委。玩家不是一个能凭空掏出资金的金手指，而是被卷进并购战的角色——可能是某方的顾问、掮客、董办新人，甚至是对赌条款里的隐名受益人。

设计的第一条铁律是**术语与规则必须准确**：要约收购期限、反垄断审查周期、代持股权隐蔽性、对赌、股权质押、白衣骑士、毒丸——这些不是装饰词，而是"为什么某些事做不了"的硬边界。本世界明确禁止"一夜暴富"和"无成本并购"，每一次收购动作都卡在 30 交易日期限、30+90 日审查周期、5%/30% 披露阈值上。

第二条意图是**让"盟友"都可能是债主**。鼎晖资本表面任郑氏防御顾问，暗里与磐石勾兑准备倒戈；联锐盟牵头反收购财团，却因自身资金链紧埋了"超期自动退出"条款；衡宇律所是御用辩护，却向反垄断委递了不利备忘自保。玩家若把任何组织当成"自己人"，就会被对赌与受偿顺序反噬。

第三条意图是**把中立监管做成真正的裁判而非背景板**。反垄断委握有强制要约认定权与审查周期，郑氏的代持一旦被认定触发阈值，郑烨即失过半表决权——这把"监管"从装饰提升为可改变棋局的力量。

第四条意图呼应共同骨架：五方 + 中立交汇点 + 关系张力机器，只是"战争"从星际政治博弈换成了资本与监管的短兵相接。

## 二、参考作品点名（仅点名，不列 URL）

- 《金元霸王花》（Barbarians at the Gate）：真实并购案改编，敌意要约、投行双面、董事会博弈。
- 《商海纵横》（电视剧）：家族企业控制权、代持与对赌的现实主义商战。
- 《大空头》（The Big Short）：金融术语严谨、对赌与受偿顺序的致命细节。
- 《门口的野蛮人》（原著）：毒丸、白衣骑士、一致行动人等防御工具的教科书式呈现。
- 《亿万》（Billions）：监管、投行、律所在利益前的立场漂移。

这些作品的共同点是"规则即战场、术语即武器"，而非"主角突然有钱通关"，这正是本世界拒绝一夜暴富的理由。

## 四、玩家起点与胜利通道

玩家三种开局身份（旅人 / 本地人 / 空白身世）都落在中洲，可被任意一条 opening_situation 牵引。本世界预留 **3 条"玩家可以赢"的路径**（满足护栏 3.1 与自洽清单第 8 条）：

1. **守控路径（挡下要约）**：玩家帮郑氏凑齐反收购弹药、稳住联锐一致行动人、逼鼎晖不敢倒戈，在 30 交易日期限内让要约失效。胜利标志：磐石要约过期作废、郑烨保住过半表决权。
2. **反杀路径（掀翻双面顾问）**：玩家收集苏阙双面下注与林澈压价模型的证据，在反垄断委或联锐面前揭穿鼎晖，使其失去双方委托。胜利标志：鼎晖信用破产、倒戈计划流产。
3. **监管路径（触发代持认定）**：玩家把郑氏代持托管协议（温律保管）递交给反垄断委，触发 5%/30% 阈值强制要约认定——未必帮郑氏，而是借监管改变棋局、从混乱中获利。胜利标志：反垄断委认定触发，控制权重新洗牌，玩家作为信息掮客套现。

每条路径都卡在 world_tech 的硬边界上：要约期限、审查周期、代持隐蔽性天花板、对赌合理区间、重大信息停牌——没有"无成本并购"的空间。

## 六、8 条自洽清单自查报告

**1. Matrix 覆盖（≥2 对 ≤ -50；≥1 对 ≥50 且藏裂缝）**
→ **PASS**。≤ -50 两对：-80（磐石｜郑氏）、-65（磐石｜联锐盟）。≥ 50 四对藏裂缝：70（鼎晖｜郑氏，倒戈伪装）、60（鼎晖｜联锐，债主暗桩）、55（衡宇｜联锐，自保暗手）、68（联锐｜郑氏，超期退出）。全部 relation 值两两互异（save.py 强制通过）。

**2. NPC 交叉咬合（secret 至少指向另一 NPC / 另一国 tension_seed / 一对 matrix）**
→ **PASS**。15 名 NPC 的 secret 全部可对应到具体实体或关系（见第 3 节表格），无悬空 secret。

**3. Tension 落地（每条 tension_seed 能追溯到 matrix 或 NPC）**
→ **PASS**。10 条 tension_seeds 均挂接矩阵对或具体 NPC（如"敌意要约30日期限"→ 矩阵 -80 + 古岩/鲍辰；"一致行动人超期退出"→ 秦骁 / 矩阵 68）。

**4. 地点承载（每国 1-2 个 key_locations 能承载该国至少一个 tension_seed）**
→ **PASS**。10 处地点各有归属场景：磐石作战室（申报口径）、郑氏董事会厅（代持与超期退出）、鼎晖模型底稿室（压价模型）、衡宇托管档案室（代持协议）、联锐资金调度室（对赌落地）等，均直接承托对应 tension。

**5. 历史回响（history 至少 1 条能被当前 opening_situation 引用）**
→ **PASS**。"本月·磐石披露敌意要约当日"直接对应 opening 第 1 条（磐石披露要约）；"三年前代持结构落定"被 opening 第 5 条（钟屿递代持备忘）与郑伯/安琪 secret 引用。

**6. 技术约束（world_tech 至少 1 条是规则边界，解释为什么某些行动做不了）**
→ **PASS**。5 条 world_tech 全是边界：要约收购期限（不能无限拖延）、反垄断审查周期（不能先买后补票）、代持股权隐蔽性（代持终会暴露）、估值与对赌约束（不能无本套现）、重大信息停牌（不能悄悄完成收购）。

**7. 开局活局势（5 条 opening_situation 都能被玩家第一个回合动作触及）**
→ **PASS**。5 条分别对应可行动地点：去磐石大厦 / 混进郑氏总部 / 去联锐中枢 / 去鼎晖交易层 / 去衡宇议庭，均为玩家首回合可执行的移动+调查动作。

**8. 玩家胜利通道（至少 2-3 条明显路径）**
→ **PASS**。第 4 节给出守控 / 反杀 / 监管 三条明确胜利通道，且都被 world_tech 边界与 NPC secret 网络支撑，非空中楼阁。

**自查结论：8/8 PASS，无 FAIL、无 CONCERNS。** 唯一需主理人留意的是"鼎晖｜郑氏 70"这对表面同盟的裂缝——它是全局最大的定时炸弹（双面顾问倒戈），建议在运行时让苏阙的倒戈随股价破位逐步显形，而非开局即揭，以保留并购战"谁在背后捅刀"的核心悬念。

## 七、题材专属护栏确认（协议 §3.2）

- **辨识锚点齐备——财务/法务/股权/监管术语准确**：要约收购、反垄断审查、代持、对赌、白衣骑士、毒丸、一致行动人、受偿顺序均按现实规则使用；`world_tech` 的要约期限、审查周期、代持隐蔽性天花板、对赌合理区间、重大信息停牌构成"为什么某些事做不了"的硬边界。
- **明确禁止项均未出现**：无"一夜暴富"、无"无成本并购"——每一次收购动作都卡在 30 交易日期限、30+90 日审查周期、5%/30% 披露阈值上。
- **命名合规**：实体 id 全 ASCII 前缀 + 小写；展示名中文 2-4 字；未撞真实国家/知名跨国公司/在世真实人物/宗教神祇；跨题材零重名（未复用硬科幻题材《双陆纪元》的卡萨德/麟河/奥斯特/土伊德/菲洛/灰潮等实体名）；商战命名风格（磐石集团/联锐盟/鼎晖资本/衡宇律所/郑氏实业/反垄断委，企业派生）与其余题材刻意区分。
