## 一、题材定位与设计意图

《长夜暗局》是一部"谍战·双面人生"题材的开放世界。被占领的临渊城明面上照常运转，暗地里拂晓社、黑沙组、双宿者、孤星线、蒸米社五方互相渗透——**你在用谁的掩护身份活着？说破一个谎，就要用一百个谎去圆。**

本题材最关键、也最易踩雷的约束是立项书第④问的**划界**：谍战必须与 `mystery`（悬疑）划开，机制上写死"**身份与谎言（我是谁）** vs **真相与证据（谁干的）**"：

- 悬疑是单局内鬼事件（短程，母题"谁干的"）；谍战是全景式身份博弈（长期，母题"我是谁"）。
- 谍战棋盘上的任何单局事件（下线被杀、密码本失窃、接头被截）**可直接触发一次悬疑局**，破案结果写回身份/渠道状态——两面一体，悬疑局是谍战大棋的"微观切片"。
- 再与军事划清：军事是明面战场；谍战是**和平表面下的暗线**——本作全城无一场公开交火，胜负全在暗线。

**三条独有机制（写进 `world_tech`）**：

1. **掩护身份维护度**（身份即生命线）——玩家持有一个假身份，有"可信度"值；言行穿帮、被验、被跟踪都会掉值，归零 = 暴露 = 被捕或灭口。运行时：在茶楼用错暗号 → 可信度 −40，须连夜换住处、烧档案、改联络方式。
2. **接头渠道管理**（渠道即弱点）——每组上下线有固定接头方式与暗号；渠道被渗透即整条线失效。运行时：发现下线已被策反 → 弃用该渠道并布置假情报反钓，否则整组暴露。
3. **双重忠诚博弈**（忠诚即筹码）——角色可有"双重忠诚"属性（对甲乙各有所图）；玩家可策反他人、也可演"叛变"钓鱼。运行时：谎称叛变投靠黑沙组，换来对方信任，再设局引其主力入瓮。

叙事张力机器沿用《上下文》通用骨架：**多方势力互算 + 结构性敌意 + 表面同盟藏裂缝 + 中立交汇点**。中立交汇点 = 半盏茶楼（接头暗点），"谁在此动手谁就烧了所有桥"的茶楼铁规是其物理边界。

贯穿全局的"母悬念"是 `history` 末条"密电失窃"：拂晓社一份真密电副本去向不明，黑沙组与双宿者同时闻风而动。玩家的每个动作都在"谁拿到了那份副本"的赌桌上压注。

## 二、参考作品点名（仅点名，不列 URL）

下列作品在"身份博弈""谍战流程""双面人生"上对本作有启发：

1. **《潜伏》**——掩护身份与单线联系的质感，以及"家庭、职业、社交圈的伪装成本"的社会可信度。
2. **《谍影重重》**（取其系列，非单部）——身份即生命线，暴露即重启的"金蝉脱壳"结构。
3. **《柏林谍影》**（勒卡雷）——双重忠诚、叛变与反叛变的灰色地带，无英雄主义的暗线互算。
4. **《风声》**——单局内鬼与验明正身的张力（作为"微观切片"触发悬疑局时的参照）。
5. **《窃听风暴》**——暗线渗透下"谁在监视谁"的全景式猜忌（信息边界铁律的参照）。

**关键 NPC 与裂缝锚点（共 13 名）**：

- 乌鸦（渗透组长）被反向策反、递假战果；夜枭（审讯官）私放要犯有旧账；礁石（账房）替双宿者走账——黑沙组明暗双线。
- 半面（话事人）各交半份真情报压两边；镜心（伪造师）私留真身份底册；归客（新入伙）是黑沙钉子却动摇了——双宿者内部皆戏。

## 四、玩家起点与胜利通道

身份三选一（沿用 SKILL.md 开局）：**旅人**（初入临渊城、无身份）、**本地人**（某派中低层，自带 1 中立 1 紧张关系）、**空白身世**（身世随剧情揭示后补写）。

**至少 3 条"玩家可以赢"的路径**（协议 §3.1 通用护栏，照立项书）：

1. **深度潜伏通道**：以掩护身份潜入黑沙组高层，反手策反关键人物、掌握敌方代理人名单——赢在"渗透制胜"。
2. **一网打尽通道**：保留我方网络完整，向拂晓社移交足够的证据链，收网黑沙组——赢在"情报战胜利"。
3. **金蝉脱壳通道**：身份暴露后反用暴露设局，假死脱身、另立新身份重启棋局——赢在"重新博弈"。

失败不清档：任一通道失败即身份 / 网络受损，但总有一条剩余路径可走（如潜伏失败则网络受损、转走一网打尽或金蝉脱壳），符合"失败改变棋局"。

## 五、题材设计说明

本题材（《长夜暗局》· `espionage`）的定位与独特性：

| 维度 | 本题材说明 |
|---|---|
| 势力语义 | 5 方：情报机关 / 敌对情报机构 / 双重间谍网络 / 占领区抵抗网 / 中立线人行会 |
| 中立交汇点 | 半盏茶楼（接头暗点，杯盏即暗号） |
| 独有机制 | 掩护身份维护度 + 接头渠道代价 + 双重忠诚账本 |
| 禁止项 | 一眼看破伪装、无成本叛变、单枪匹马灭据点 |
| 命名风格 | 代号化 / 隐喻化（拂晓/黑沙/双宿/孤星/蒸米/半盏）+ 老旧城市场景 |
| 张力机器 | 15 对矩阵；新增"双重间谍网络"这一身份性势力 |

**与最近邻题材的划界一句话**：谍战 = **身份与谎言**（"我是谁"，全景式身份博弈，长期互骗）；悬疑 = **真相与证据**（"谁干的"，单局破案）——本作所有"单局事件"都可下钻成一场悬疑局，但悬疑局的结果必须写回身份/渠道状态，使谍战始终是那盘更大的棋。

## 七、题材专属护栏确认

- **辨识锚点齐备——情报术语与流程真实**：掩护身份、接头暗号、死信箱、单线联系、验明正身、反跟踪、死信箱墙、杯盏即暗号——全套谍战流程在 `world_tech` 与 `key_locations` 中落地；双面身份的社会质感可信（家庭、职业、社交圈的伪装成本体现在"掩护身份维护度"里）。
- **明确禁止项均未出现**：
  - 禁止"一眼看破伪装"——`tech_cover_integrity` 明确"本世界无读心术，识别伪装只能靠调查、测试与证据"；
  - 禁止"无成本叛变"——`tech_double_loyalty` 明确"叛变即断一切旧关系，且新主未必真信任；策反有冷却、有反噬"；
  - 禁止"好莱坞式单枪匹马灭据点"——`tech_no_superman` 明确"谍战的胜利靠情报与布局，不靠火力；凭暴力只会烧光掩护身份"。
- **防开挂核心落地**：掩护身份维护度 + 渠道管理双轨（`tech_cover_integrity` + `tech_channel_cost`）——身份与渠道都是会被消耗、崩溃的资产，玩家不能无限穿墙。
- **与悬疑的划界落地**：GDD 一节、五节明确"身份-谎言 vs 真相-证据"；本作任意单局事件可下钻为悬疑局、结果写回身份/渠道状态，但谍战始终是全景式长期博弈。与军事的划界落地：全城无公开交火，胜负全在暗线。
- **命名合规**：实体 id 全 ASCII 前缀 + 小写；展示名中文 2-4 字（拂晓社/黑沙组/双宿者/孤星线/蒸米社/半盏茶楼）；未撞真实国家/知名跨国公司/在世真实人物/宗教神祇；跨题材零重名（未复用既有 9 题材的词根：砚/泓/北岭/东岸/沈氏/东/青/铁 均未使用）；谍战命名风格（代号化/隐喻化 + 老城场景）与悬疑的"分局/馆"、军事的"司令部/佣兵"刻意区分。
