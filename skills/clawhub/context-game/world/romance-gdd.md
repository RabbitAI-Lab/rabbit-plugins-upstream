## 一、题材定位与设计意图

### 1.1 为什么"情感/婚变"适合关系张力机器

情感题材最容易被写成"两个人爱不爱"的内心戏，但《上下文》的关系张力机器要求的是**多方势力的结构性互算**。婚变题材的天才之处在于：一段婚姻从来不是两个人的事——它是**两个家族的联姻、两段关系网的交叠、一圈闺蜜兄弟的情报网**。主角被"两家人 + 两个朋友圈"五方同时拉扯，每一方都有自己的利益与秘密，这正是关系张力机器最肥沃的土壤。

本设计的关键判断：**把"家族/朋友圈"拆成独立势力，而非背景板**。女方家族（林氏）、男方家族（周氏）是明面上的两方；前段关系网（沈氏旧部，旧情人+前任的现任+当年共同朋友圈）是悬在婚约头顶的旧账；现段关系网（顾氏新盟，新欢+顾家亲友+利益方）是看似救赎实为围猎的新局；闺蜜兄弟圈（挚友圈）本该是避风港，却因各自被收买成了传声筒。主角林绾站在五方的交叉点上。

### 1.2 设计意图的三层结构

- **第一层（婚约本身）**：林周两家的联姻是明线，房产公证、家委会代议、接班人之位是它的支点。
- **第二层（两段关系网）**：沈氏旧部用旧账不许退婚，顾氏新盟用温柔逼退婚——一前一后把主角夹在"退不了、又不愿"的窒息里。
- **第三层（朋友圈泄密）**：挚友圈是谣言倍增器，私房话经两端外流，在两家人间指数级变形；谁掌握朋友圈节点，谁掌握叙事。

### 1.3 玩家处境

玩家不是上帝视角的旁观者，而是**处在五方交叉点的当事人林绾**（或可选择"空白身世"从边缘切入）。玩家没有家族的法定权力，但有秘密与选择：退婚、曝光、周旋、反制。每一步都在重塑五方关系。

### 1.4 护栏自检（协议 §3.2）

- 辨识锚点齐全：家人/朋友/前段关系的现实反应全部可信落地（家委会代议、房产公证、闺蜜被收买、兄弟盯梢）。
- 明确禁止项：**无无脑圣母、无无理由原谅、无单方面"救世主"恋爱**。顾辰的温柔是围猎而非拯救；沈砚的旧情是筹码而非深情；所有"爱"都有利益底色，玩家不能靠"真爱无敌"通关。

## 三、五方势力设计与关系张力机器映射

> 协议要求：情感要把家族/朋友圈拆成独立势力。下面重点说明"两家人 + 两个朋友圈"的具体拆解方案。

### 3.1 林氏家族（nation_linshi）——女方家族

- **核心矛盾**：借联姻稳地产融资、女儿意愿被家委会代议；早年替沈家背的账被沈氏旧部握作把柄。
- **拆解要点**：家族不是铁板——当家林柏（急于用婚约救项目）、继母林茹（已暗联顾家）、女主林绾（想挣脱）三方立场不同，家委会代议正是林柏压制女儿意愿的工具。
- **张力角色**：林绾（藏旧信）、林柏（背沈家账）、林茹（内鬼）。

### 3.2 周氏家族（nation_zhoushi）——男方家族

- **核心矛盾**：要房产公证林家觉受辱；接班人位悬而未决，婚约被当站队筹码。
- **拆解要点**：周家也不是一体——当家人周烨（把婚约当期权，已评估顾家"备胎"）、公子周牧（多疑、买通盯梢）、姑姑周敏（反婚约、早联顾家）各有算盘。周烨的"备胎亲家"评估是整张棋的暗线。
- **张力角色**：周牧（盯梢反被卖）、周烨（期权思维）、周敏（顾家内应）。

### 3.3 沈氏旧部（nation_shenshi）——**前段关系网（旧情人+前任的现任+共同朋友圈）**

- **它是什么**：林绾前任沈砚的家族余部——旧情人沈砚、现任沈菲、旧部财务沈陆，加上当年共同朋友圈。
- **它如何承载张力**：
  1. **旧账要挟**：沈砚握着林柏当年替沈家背账的原始凭证，以此不许林绾退婚（matrix 林氏\|沈氏 −55）。
  2. **谣言搅局**：沈菲在闺蜜圈放"旧情未了"，挑拨周家疑心（沈氏\|周氏 −52）。
  3. **凭证已不唯一**：沈陆偷偷把复印件卖给顾家，沈家还以为独家——这颗雷迟早炸自己（与顾氏 −63 死敌）。
- **张力角色**：沈砚（原始凭证）、沈菲（泄密者反装被害）、沈陆（卖复印件）。
- **机器位置**：前段关系网是"过去的幽灵"，它不图现在，只图不让现在安稳。

### 3.4 顾氏新盟（nation_gushi）——**现段关系网（新欢+顾家亲友+利益方）**

- **它是什么**：林绾当前新暧昧对象顾辰的圈子——新欢顾辰、姑妈顾湘、眼线顾烨，加上收购林家地产的利益关联方。
- **它如何承载张力**：
  1. **温柔围猎**：顾辰以"不捆绑"接近，实为压价收购林家地产（matrix 顾氏\|林氏 52，**藏裂缝**：顾湘已握沈家凭证复印件）。
  2. **多方眼线**：顾烨同时替周家与沈家领薪，倒卖林绾动向（信息差赚三份钱）。
  3. **剧本是别人写的**：顾辰的接近剧本由周敏+沈陆共同喂料，他以为主导，实为棋子。
- **张力角色**：顾辰（被操纵的新欢）、顾湘（收购操盘）、顾烨（双面眼线）。
- **机器位置**：现段关系网是"看似救赎的新局"，它比前任更危险，因为它裹着糖衣。

### 3.5 挚友圈（nation_zhiyou）——**闺蜜兄弟圈（朋友圈拆解）**

- **它是什么**：林绾闺蜜（苏蓉）+ 周牧兄弟（江浩）+ 调停人（戚越）组成的朋友圈。
- **它如何承载张力**：
  1. **闺蜜被买通**：苏蓉收沈菲的钱在闺蜜群带节奏，林绾却最信她。
  2. **兄弟卖情报**：江浩替周牧盯梢，把记录转卖沈氏旧部。
  3. **调停人是内鬼**：戚越在谈心室兼职，把听到的秘密整理成小抄卖给顾氏新盟。
- **张力角色**：苏蓉（被收买的死党）、江浩（双卖的兄弟）、戚越（谈心室内鬼）。
- **机器位置**：朋友圈本是最弱的势力，却因"信任"成了泄密效率最高的节点——它证明关系张力机器里，**最亲密的关系往往是最脆的裂缝**。

### 3.6 中立交汇点：谈心室（port_tanxin）

- 心理咨询室，保密例外条款让它"只进不出"，人人来倾诉却人人被记录。戚越在此兼职，把秘密变成商品。它是五方秘密的漏斗与黑洞。

## 四、玩家起点与胜利通道

### 4.1 玩家起点（默认林绾 / 或空白身世）

开局 5 条活局势均能被第一个回合动作触及：
1. 沈菲在闺蜜群甩旧合照 → 玩家可私聊周牧解释、或反查照片来源（沈菲泄密）。
2. 林柏推房产公证草稿 + 沈家未拆信 → 玩家可拒签、或拆信看旧账。
3. 顾辰艺廊"不捆绑"却摊出地产估值报告 → 玩家可追问报告来源（周敏笔迹）、或借力周旋。
4. 戚越说"只进不出"却手机亮着"顾家眼线" → 玩家可戳破、或录音取证。
5. 江浩说"牧哥让我看着你"、苏蓉耳语"沈家给了我钱" → 玩家可策反任一方、或把两人对质。

### 4.2 三条"玩家可以赢"的路径（≥2–3，达标）

- **路径 A · 旧账反转线**：拿到沈陆卖给顾家的凭证复印件（或逼沈陆交出），证明"沈家凭证已不唯一" → 沈氏旧部失去要挟筹码 → 林绾获得退婚主动权。玩家把前段关系网的命门公开。
- **路径 B · 房产与代议线**：联合林茹（已暗联顾家）与周敏（反婚约），推翻家委会代议、重谈房产公证 → 把婚约从"家族交易"变成"当事人协议"。玩家重构两家人之间的规则。
- **路径 C · 朋友圈夺回线**：策反苏蓉或江浩，让挚友圈从泄密前线变回真实盟友 → 掐断谣言倍增器 → 掌握叙事权，反过来用谈心室与树洞式信息战反制顾氏/沈氏。玩家夺回最亲密也最脆的节点。

三条路径互相咬合：旧账（A）削弱沈氏，代议（B）重定两家人，朋友圈（C）切断传播——无救世主，但玩家确实能改写棋局。

## 六、8 条自洽清单自查报告

1. **Matrix 覆盖**：≤−50 三对（顾氏\|沈氏 −63、林氏\|沈氏 −55、沈氏\|周氏 −52）；≥50 藏裂缝一对（顾氏\|林氏 52，note 藏"顾湘已握沈家凭证复印件欲压价收购"）。**通过**。
2. **NPC 交叉咬合**：每个 core_npc 的 secret 都指向另一 NPC / 他国 tension_seed / matrix 关系——
   - 林绾 secret→沈氏旧部要挟（shenshi）；林柏 secret→沈砚原始凭证（shenshi）；林茹 secret→暗联顾氏（gushi）。
   - 周牧 secret→江浩双卖（zhiyou）；周烨 secret→备胎顾家（gushi）；周敏 secret→顾氏往来（gushi）。
   - 沈砚 secret→林柏账+复印件外流（linshi/gushi）；沈菲 secret→当年自己泄密（shenshi）；沈陆 secret→卖复印件给顾家（gushi）。
   - 顾辰 secret→周敏+沈陆喂料（zhoushi/shenshi）；顾湘 secret→沈家凭证复印件（shenshi）；顾烨 secret→三家眼线（zhoushi/shenshi）。
   - 苏蓉 secret→收沈菲钱（shenshi）；江浩 secret→双卖（shenshi）；戚越 secret→谈心室卖密（port）。**全部咬合，通过**。
3. **Tension 落地**：每国 2 条 tension_seeds 均可追溯（如"旧账被握"→沈砚 secret + 林氏\|沈氏 −55；"顾家温柔围猎"→顾辰 secret + 顾氏\|林氏 52）。**通过**。
4. **地点承载**：每国 1–2 处 key_locations 均承载 tension——林家老宅/地产总部（代议与融资）、周家公馆/会所（接班与备胎）、沈家旧墅/咖啡（凭证与谣言）、顾家艺廊/办公室（围猎与眼线）、挚友酒吧/公园（泄密与偶遇）。**通过**。
5. **历史回响**：history 第 5 条"婚约风暴眼"直接对应 opening 第 1 条（沈菲放旧照）、第 3 条（顾辰逼近）、第 5 条（江浩苏蓉对质）；第 1–2 条旧账对应沈氏要挟线。**通过**。
6. **技术约束**：world_tech 中"婚约法律约束"（退婚需赔付商誉）、"房产登记归属"（分割天差地别）、"心理疗程周期"（保密例外只进不出）明确解释了"为什么某些动作做不了/会被拿捏"——规则边界成立。**通过**。
7. **开局活局势**：5 条 opening 均指向具体可交互的 NPC/地点/动作（私聊周牧、拆沈家信、追问顾辰报告、戳破戚越、策反苏蓉江浩），第一回合即可触及。**通过**。
8. **玩家胜利通道**：A 旧账反转、B 房产代议、C 朋友圈夺回三条路径明确，皆不依赖救世主恋爱。**通过**。

**结论：8/8 通过，逻辑自洽，可交付。**
