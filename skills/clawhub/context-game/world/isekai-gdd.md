## 一、题材定位与设计意图

《双轨异界》是一部"双时空穿越博弈"题材的开放世界。玩家的世界被劈成两半：**原轨大陆**（continent_yuan，现代科技社会）与**新轨大陆**（continent_xin，灵气修炼世界），两者由名为"两界渡"的裂隙中转站相连。穿越者**林深**是唯一同时脚踏两界的人——他是原时空北岭集团的前工程师、和砚家属会牵挂的亲人，也是新时空灵墟宗盟手中的"异界之桥"。

设计这一题材时，最难、也最关键的约束是**协议 §3.2 对 isekai 的护栏**：

- **必须有的辨识锚点——双时空规则明确**。本作把"双时空"落到了可玩的物理/社会规则上：原时空遵循现代国家机器与资本逻辑（东岸总署追查、北岭集团逐利、家属会守情），新时空遵循灵气与宗门/皇朝逻辑（灵脉决定修炼上限、宗盟与皇朝世仇）。两界时间流速不同（原一日≈新三旬），长期分隔会引动"灵息剥离"。这些不是背景装饰，而是**限制玩家行动的真实边界**。
- **明确禁止——穿越者无限开挂**。林深带回的"无主灵机"是稀缺资源、密钥每用一次衰减、裂隙开启需祭祀维持、回归即被位移监测网标记。四道枷锁共同封死"无限穿越、无限取利、无限碾压"的爽文路径。
- **明确禁止——两个时空无摩擦融合**。两界渡是高度不稳的真空地带，幽冥与灵墟在此隔渡对峙、原时空的资本与体制在此暗战；任何"顺滑融合"的想象都被世仇、监控与灵脉枯竭打碎。

叙事张力机器沿用《上下文》的通用骨架：**多方势力互算 + 结构性敌意 + 表面同盟藏裂缝 + 中立交汇点**。本作的中立交汇点有两层——物理上是一处谁都不敢独占的裂隙"两界渡"（neutral_port），叙事上是穿越者林深本人（唯一两边都算外来的人）。所有张力最终都汇聚到"林深该被谁握在手里"。

玩家不是林深（林深是世界的支点 NPC），而是介入双界博弈的自由行动者：可以是总署外勤、北岭特派、家属会信使，或灵墟/幽冥的渡口来客。玩家的每一个动作都在两界杠杆上压砝码。

## 二、参考作品点名（仅点名，不列 URL）

下列作品在"双时空错位""穿越者处境""两界势力博弈"上对本作有启发，供主理人与玩家对位理解基调：

1. **《Re:从零开始的异世界生活》**——穿越者的脆弱性与"被多方势力争夺"的处境。
2. **《犬夜叉》**——现代少女与妖怪世界的双界切换、以及"不能自由往返"的边界感。
3. **《命运石之门》**——世界线/时空规则作为硬约束，而非任性的许愿机。
4. **《诡秘之主》**（克苏鲁风，但取其"多势力在暗处互算、表面同盟藏裂缝"的结构）。
5. **《环界 / 午夜凶铃》世界观**——"里世界"与"表世界"并存、通道稀缺且危险。

> 说明：修仙参考作品在 `cultivation-gdd.md` 中另列；两题材命名风格刻意区分（穿越用"东岸/北岭"等现代派生 + "灵墟/幽冥"等古风新界；修仙全用古风音译如"玄枢宗/青衍剑府"）。

## 三、8 方势力设计与关系张力机器映射

本作 `nations` 字段承载**双 matrix**：前 3 个属原时空派系，后 2 个属新时空派系；faction_matrix 同时含"原×原""新×新""原×新"三类 pair。

| 实体 id | 名称 | 所属时空 | 势力语义 | 核心矛盾 |
|---|---|---|---|---|
| nation_dongan | 东岸总署 | 原 | 追查穿越者机构 | 收容派 vs 研究派；保密令被资本渗透 |
| nation_beiling | 北岭集团 | 原 | 穿越者旧雇主（资本） | 激活密钥 vs 掩盖；影子账户濒临曝光 |
| nation_heyan | 和砚家属会 | 原 | 穿越者家人/旧友 | 劝留 vs 强迎；旧物发热之谜 |
| nation_lingxu | 灵墟宗盟 | 新 | 宗门联盟 | 护桥派 vs 夺桥派；灵脉枯竭 |
| nation_youming | 幽冥皇朝 | 新 | 世仇皇朝 | 夺渡 vs 内乱；皇子秘恋 |
| port_liangjie | 两界渡 | 跨界 | 中立交汇点 | 谁控渡口=谁握两界钥匙 |

**张力机器映射（精选）**：

- **结构性敌意（≥2 对 ≤-50）**：`lingxu|youming = -68`（世代世仇）、`youming|port_liangjie = -55`（幽冥必夺渡口）。两对都落在跨时空/新时空内部，构成不可调和的硬敌意。
- **表面同盟藏裂缝（≥1 对 ≥50 且 note 藏裂缝）**：`heyan|lingxu = 58`——家属会与灵墟"共谋兄归"，裂缝在于灵墟要林深永作桥、温知不知情。这是最危险的甜蜜陷阱，也是玩家可撬动的支点。
- **跨时空 pair（原×新）的特殊处理**：`dongan|lingxu = 3`、`dongan|youming = -5` 等数值贴近空值，note 注明"尚未直接接触"；`beiling|lingxu = 35` 则是少数已建立试探性接触的跨时空 pair。数值高低本身编码了"两界是否已摩擦"。
- **原时空内部张力**：`beiling|dongan = -42`（资本 vs 体制）、`dongan|heyan = -28`（监控 vs 被当人质），体现原界并非铁板一块。

**关键 NPC 与裂缝锚点（共 13 名）**：
- 沈彻（总署收容派）已确认林深身份却瞒北岭；陆桉（研究派）拿了北岭影子账户的钱；戚岚（外勤）收了灵墟定息玉——三人构成总署的"内鬼三角"。
- 严桓（北岭 CEO）伪造林深失踪档案；陶絮（北岭安全）把密钥副本给了家属会——资本内部也有裂隙。
- 温知（家属会）压着灵墟来信；穆老认出灵息残留——情感锚点本身即裂缝。
- 宗沄（灵墟宗主）对温知许下空头承诺；青翎（执法长老）私通幽冥；玉灵侍（守关人）隐瞒细作——灵墟护桥派与夺桥派之争延伸到渡口。
- 幽泓（幽冥之主）将计就计借联姻；子夜（皇子）以假契诱反；冥戎（细作）收买戚岚——幽冥的暗线已插进两界。

## 四、玩家起点与胜利通道

身份三选一（沿用 SKILL.md 开局）：**旅人**（初到两界渡、两边皆陌生）、**本地人**（原时空某派系低层或灵墟/幽冥门下）、**空白身世**（背景随剧情揭示）。

**至少 3 条"玩家可以赢"的路径**（协议 §3.1 通用护栏）：

1. **归乡通道**：玩家串联和砚家属会与东岸收容派，用密钥安全关闭裂隙、把林深接回原时空，并留两界渡为受控纪念馆——赢在"护住一个人、消解一场跨界危机"。
2. **宗盟续命通道**：玩家协助灵墟护桥派稳住裂隙、把无主灵机导回灵脉，击败夺桥派与幽冥夺渡阴谋——赢在"续上一方修炼文明"，但代价是林深永镇渡口（道德灰度）。
3. **皇朝倾覆通道**：玩家借幽冥之手夺取两界渡、倾覆灵墟，或反过来帮灵墟先发制人——赢在"改写新时空权力版图"，但会引爆原时空的外溢风险。

失败不清档：每条通道的失败都会关闭某扇门（如密钥耗尽、渡口塌缩、某派系覆灭），把棋局推向剩下的路径，符合"失败改变棋局"。

## 六、8 条自洽清单自查报告

1. **Matrix 覆盖**：`lingxu|youming=-68`、`youming|port_liangjie=-55` 两对 ≤-50（结构性敌意）；`heyan|lingxu=58` 一对 ≥50 且 note 藏裂缝（灵墟要林深永作桥）。✅ 满足"≥2 对 ≤-50、≥1 对 ≥50 藏裂缝"。
2. **NPC 交叉咬合**：13 名 NPC 的 secret 均指向另一 NPC / 另一国 tension_seed / 一对 matrix 关系。例：沈彻→北岭（beiling）；陆桉→北岭影子账户（beiling tension）；戚岚→灵墟（lingxu）；陶絮→家属会（heyan）；温知→灵墟承诺（heyan|lingxu）；宗沄→温知（heyan）；青翎→幽冥（youming）；冥戎→戚岚（dongan）。✅
3. **Tension 落地**：每国 2 条 tension_seeds 均有对应 NPC 承载（如总署"研究派被渗透"由陆桉 secret 落地；北岭"激活密钥分歧"由严桓/陶絮 secret 落地）。✅
4. **地点承载**：每国 1-2 处 key_locations 承载其 tension。例：密钥金库承载"激活分歧"；裂隙观测站承载"戚岚放行"；和砚旧居承载"旧物发热"。共 9 处。✅
5. **历史回响**：5 条 history 中"林深失踪/裂隙初现/异客临墟/双桥暗通/渡口之争"均被 opening_situation 引用（如开局 1 提戚岚放行呼应"裂隙初现"，开局 2 提密钥呼应"林深失踪"）。✅
6. **技术约束**：`tech_spatiotemporal_rule`（时间流速/灵息剥离）、`tech_rift_stability`（裂隙塌缩）、`tech_yuan_track`（回归即标记）、`tech_key_seal`（密钥衰减）均为"世界的物理/规则边界"，能解释为何某些行动做不了。✅
7. **开局活局势**：5 条 opening_situation 分别触及 dongan/beiling/heyan/lingxu/youming 与 port，玩家首回合动作均可触及（调查、交易、说服、对质皆可用）。✅
8. **玩家胜利通道**：§四 列出 3 条明显可赢路径，且失败改变棋局、不锁死。✅

## 七、冒烟测试与交付物

- 文件：`isekai.json`（骨架）、`isekai-detailed.json`（精写）、本 GDD。
- 校验命令见任务冒烟流程；须 world-init 通过且 `rm -rf saves/_test_isekai` 清理。
- **双时空共存实现说明**：`nations` 数组前 3 项（`nation_dongan`/`nation_beiling`/`nation_heyan`）为原时空派系，均 `continent: continent_yuan`；后 2 项（`nation_lingxu`/`nation_youming`）为新时空派系，均 `continent: continent_xin`；`port_liangjie`（两界渡）落到 `continent_xin`（裂隙在灵墟一侧开启）。faction_matrix 因此天然分三类 pair：
  - **原×原**（beiling-dongan / beiling-heyan / dongan-heyan）：原时空内部博弈；
  - **新×新**（lingxu-youming）：新时空世仇；
  - **原×新**（beiling-lingxu=35、beiling-youming=-15、dongan-lingxu=3、dongan-youming=-5、heyan-lingxu=58、heyan-youming=-22，以及各自与 port 的 pair）：跨时空接触状态由数值编码——贴近空值者"尚未直接接触"，偏高者"已建立试探性联系"，藏裂缝者"表面同盟"。
  如此，双 matrix 共存于同一份 world.json，无需拆分文件。
