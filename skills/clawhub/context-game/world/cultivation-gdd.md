## 一、题材定位与设计意图

《天衍修真界》是一部"修仙江湖"题材的开放世界。天衍大陆上，宗门、皇朝、散修、魔道并立，灵脉决定一切——谁握灵脉，谁握修炼上限。主角是介入这场灵气博弈的自由行动者，可以是一名宗门弟子、皇朝密使、散修客卿，或魔庭暗桩。

本题材最关键、也最易踩雷的约束是**协议 §3.2 对 cultivation 的护栏**：

- **必须有的辨识锚点——灵力量级分层清晰**。本作在 `world_tech` 中明确写入"修为九阶"：练气→筑基→结丹→元婴→化神，每阶再分初/中/后/圆满；跨阶战力以十倍计，同阶之内差距有限。这是玩家判断"我能打谁、打不过谁"的硬标尺。
- **明确禁止——力量体系无上限**。本作设**化神为当世天花板**：上古"化神之上"因灵潮大劫已绝迹（见 history"灵潮大劫"），当世无人可越。从此封死"越练越强、没有尽头"的爽文路径。
- **明确禁止——越级秒杀常态化**。本作设"突破禁忌"：每越一阶须渡劫，失败轻则倒退、重则殒身；强行冲阶必遭反噬。低阶者绝不可能靠秘宝抹平跨大阶差距秒杀高阶，阶位天花板锁死碾压。
- **灵力/法术的护栏改造**：硬科幻"禁魔法"条款在本家族失效——允许灵力与法术存在（这是修仙的本体），但法术威力严格受施法者阶位上限约束，高阶法术需对应阶位方可施展，低阶强行催动会自伤。魔法有，但被阶位天花板锁死。

叙事张力机器沿用《上下文》通用骨架：**多方势力互算 + 结构性敌意 + 表面同盟藏裂缝 + 中立交汇点**。中立交汇点 = 万宝坊市（拍卖场 / 散修聚义 / 云渺秘境入口），入者弃前怨、禁私斗的"坊市铁律"是其物理边界。

贯穿全局的"母悬念"是 `history` 末条"四海同枯"：所有势力争夺灵脉，根因都是灵脉正在枯竭。玄真子瞒报、昭明掩盖、青璇图谋秘境，皆因同一真相。玩家的每个动作都在"谁续上灵脉"的赌桌上压注。

## 二、参考作品点名（仅点名，不列 URL）

下列作品在"力量分层""宗派冲突""江湖博弈"上对本作有启发：

1. **《凡人修仙传》**——凡人流的阶位爬升与"突破有风险"，是本病设"九阶 + 渡劫反噬"的直接参照。
2. **《诛仙》**——正魔对立、青云门与鬼王宗的世仇结构，以及"表面正道内亦有暗线"的裂缝感。
3. **《斗破苍穹》**——阶位体系的可读性（明确的等级标尺），以及"资源决定修炼速度"的设定。
4. **《诡秘之主》**（克苏鲁风，但取其多势力暗处互算、表面同盟藏裂缝的结构）。
5. **《雪中悍刀行》**——江湖与庙堂并立、名门与散人交织的格局感（皇朝与宗门共治的参照）。

## 四、玩家起点与胜利通道

身份三选一（沿用 SKILL.md 开局）：**旅人**（初入坊市、无门派）、**本地人**（某派中低层，自带 1 中立 1 紧张关系）、**空白身世**（身世随剧情揭示后补写）。

**至少 3 条"玩家可以赢"的路径**（协议 §3.1 通用护栏）：

1. **宗门续脉通道**：玩家串联玄枢宗主战派与赤火洞天，抢在灵脉枯竭前重布灵枢大阵、导灵脉归宗，压制魔庭与皇朝暗盟——赢在"续上正道文明"。
2. **皇朝削宗通道**：玩家助裴相/昭明借魔庭之力削玄枢宗权，改"共治"为"皇朝独尊"，再反手弃魔——赢在"改写庙堂与江湖的权力比重"。
3. **散修/秘境通道**：玩家借万宝坊市聚散修、夺云渺秘境入口，绕过宗门垄断自成一方——赢在"打破资源垄断"，代价是与所有大宗为敌。

失败不清档：任一通道失败都会关闭对应门（如灵脉归宗失败则资源向魔庭倾斜），把棋局推向剩余路径，符合"失败改变棋局"。

2. **NPC 交叉咬合**：13 名 NPC 的 secret 均指向另一 NPC / 另一国 tension_seed / 一对 matrix 关系。例：守拙→裴相眼线（yanhuang）；顾长亭→幽媱（shihun）；青璇→裴相（yanhuang）、凌虚→玄真子（xuanshu）；赤炎翁→嫁祸魔庭（shihun）；陶朱→魔庭/坊市（shihun/port）；炎昭帝→裴相暗线；裴相→噬魂尊（shihun）；昭明→灵脉真相（tech）；噬魂尊→裴相（yanhuang）；血河→幽媱；幽媱→宗门灵脉图（xuanshu）。✅
3. **Tension 落地**：每国 2 条 tension_seeds 均有对应 NPC 承载（如玄枢"灵脉瞒报"由玄真子 secret 落地；皇朝"暗通魔庭"由裴相/炎昭帝 secret 落地）。✅
4. **地点承载**：每国 1-2 处 key_locations 承载其 tension。例：思过崖承载"弟子通魔"；器藏阁承载"失窃嫁祸"；帝都监会承载"灵脉掩盖"。共 10 处。✅
5. **历史回响**：5 条 history（灵潮大劫/正魔决/皇朝立/秘境现/灵脉枯）均被 opening_situation 引用（如开局 4 提灵材暴涨呼应"灵脉枯"，开局 1 提血河坛令牌呼应"正魔决"）。✅

## 七、冒烟测试与交付物

- 文件：`cultivation.json`（骨架）、`cultivation-detailed.json`（精写）、本 GDD。
- 校验命令见任务冒烟流程；须 world-init 通过且 `rm -rf saves/_test_cultivation` 清理。
- **力量分层设计说明**：本作以 `world_tech` 的 `tech_realm_ladder` 确立五阶主层级——**练气 → 筑基 → 结丹 → 元婴 → 化神**，每阶再分"初 / 中 / 后 / 圆满"四小阶，共二十个小阶位。规则内核：
  - **量级差**：跨一大阶战力以**十倍**计，同阶之内差距有限，因此可预判胜负、避免无厘头碾压；
  - **天花板**：**化神为当世顶点**，上古"化神之上"因灵潮大劫已绝迹，从根上封死"无上限"；
  - **突破约束**（`tech_breakthrough_risk`）：每越一阶须渡劫，失败轻则修为倒退、重则殒身道消；强行冲阶必遭反噬，**杜绝越级秒杀常态化**；
  - **资源约束**（`tech_lingqi_dist`）：灵气集中于名山洞天，灵脉枯竭区无法突破，修炼速度绑定地位与资源；
  - **法术约束**（`tech_magic_allowed`）：允许灵力/法术（修仙本体），但威力受阶位上限约束，高阶法术需对应阶位方可施展，低阶强行催动会自伤。
  五条技术共同构成"有上限、有代价、有分层"的力量体系，是本协议 §3.2 对修仙家族护栏的落地实现。
