## 一、题材定位与设计意图

《九重阙》是一部"宫廷权谋·朝堂博弈"题材的开放世界。京畿皇城里，后党、宠妃系、权臣党、宦官、储君党五方在龙椅的阴影下互算生死——**圣心是唯一的硬通货，位份是唯一的通行证。** 主角是棋盘上唯一还能选择站队的人。

本题材立项书第④问为**附条件通过**，最近邻有二：`cultivation` 的炎黄皇朝支线（继位之争、权臣暗线）与 `romance` 的家族联姻。划界必须写死：

- 与修仙划界：修仙的力量资源是**灵脉**（皇朝只是灵脉附属）；权谋的硬通货是**圣心与位份**（恩宠与品级本身即资源，与灵力无关）。
- 与情感划界：情感的筹码是**婚约与旧账**（血缘与情感绑定）；权谋的筹码是**恩宠与官阶**（可涨落、可交易、与血缘脱钩）。
- 一句话：**恩宠替代血缘与资本成为资源**——谁得圣眷、谁有位份，谁就能进那道门、调那个人。

**三条独有机制（写进 `world_tech`）**：

1. **圣眷涨落表（"恩宠即资源"）**——每势力维护一个 −100..+100 的"圣眷"值，比兵权更硬：圣眷高者奏对优先、查案优先、调人优先。运行时：向皇帝进谗"掌印司私通外使"，判定成功 → 掌印司圣眷 −15、辅政阁 +5，内廷行事立遭掣肘。
2. **位份阶梯（品级即权限）**——仿修仙"九阶"的分层，语义是官阶：九品 → … → 一品 → 超品（摄政）。位份决定"能进哪道门、能调谁"。运行时：以七品身份求见首辅被挡，须先借储英堂举荐升至五品方得入阁。
3. **把柄账（密折即弹药）**——宫廷秘密可量化：每派握有他人把柄，把柄可"递折子"一次性引爆。运行时：掌握某官科场舞弊证据，在朝会递折，重创其所属派系圣眷并逼其倒戈。

叙事张力机器沿用《上下文》通用骨架：**多方势力互算 + 结构性敌意 + 表面同盟藏裂缝 + 中立交汇点**。中立交汇点 = 司晨楼（黎明朝会鼓楼），"楼内动刀兵即犯众怒"的朝会规矩是其物理边界。

贯穿全局的"母悬念"是 `history` 首条"夺嫡旧案"与今条"贵妃请易储"：旧案留下大批把柄与旧账，而今上圣心难测、易储之议已起——玩家的每个动作都在"太子能不能保住"的赌桌上压注。

## 二、参考作品点名（仅点名，不列 URL）

下列作品在"朝堂博弈""恩宠位份""密折把柄"上对本作有启发：

1. **《大明王朝1566》**——内外朝、君臣相疑与"密折即弹药"的政治质感，是本作"圣眷/把柄"机制的直接参照。
2. **《甄嬛传》**——后宫位份、恩宠涨落与"无子之后如何自处"的嫡统博弈。
3. **《琅琊榜》**——旧案翻覆、储君之争与清流士林在权谋中的位置。
4. **《雍正王朝》**——夺嫡旧案留下的把柄账，以及"圣心难测、位份循阶"的官场逻辑。
5. **《纸牌屋》**（取其多方合纵、表面同盟藏裂缝的结构，非其现代设定）。

## 四、玩家起点与胜利通道

身份三选一（沿用 SKILL.md 开局）：**旅人**（初入京畿、无官身）、**本地人**（某派中低层，自带 1 中立 1 紧张关系）、**空白身世**（身世随剧情揭示后补写）。

**至少 3 条"玩家可以赢"的路径**（协议 §3.1 通用护栏，照立项书）：

1. **扶立储君通道**：助储英堂保住太子位、逼退宠妃系与外戚——赢在"从龙定策"。
2. **清君侧通道**：联合清流 + 辅政阁扳倒掌印司，收编内廷密报网——赢在"夺回内廷"。
3. **摄政通道**：在圣眷最高时推动"托孤/摄政"，凌驾五派——赢在"改写皇权结构"。

失败不清档：任一路线失败则关闭对应门（如储君被废），棋局自然推向剩余路径，符合"失败改变棋局"。

## 七、题材专属护栏确认

- **辨识锚点齐备——宫廷礼制与品级可信**：宫廷礼制/品级/奏对/后宫位份/内廷外朝之分在 `world_tech` 与 `key_locations` 中落地（早朝、密折、司晨楼朝议、批红、票拟、内廷档案库等）；恩宠涨落与位份权限的机制可信。
- **明确禁止项均未出现**：
  - 禁止"金手指式预知圣意"——`tech_shengchong` 明确"圣心只能靠试探与推理"、`tech_chaojun` 明确"无读心"；
  - 禁止"一夜从白身跃居一品"——`tech_pinji` 明确位份须循阶、越阶须强情节 + 重代价，且圣眷一崩位份形同虚设；
  - 禁止超自然——`tech_chaojun` 明确"无妖法、无穿越、无读心、无异能"。
- **防开挂核心落地**：位份 / 圣眷双轨（`tech_pinji` + `tech_shengchong`）——权力同时依赖品级与恩宠，二者皆需积累且会跌落；圣眷一崩，位份形同虚设。
- **与修仙/情感的划界落地**：GDD 一节写死"恩宠替代血缘与资本成为资源"；`world_tech` 明确资源是品级与恩宠、不是灵力；命名用"宫/殿/阁/司/堂"刻意区别于修仙的"宗/府/洞天/坊市"。
- **命名合规**：实体 id 全 ASCII 前缀 + 小写；展示名中文 2-4 字（凤仪宫/承欢殿/辅政阁/掌印司/储英堂/司晨楼）；未撞真实国家/知名跨国公司/在世真实人物/宗教神祇；跨题材零重名（未复用既有题材词根：砚/泓/北岭/东岸/沈氏/东/青/铁 均未使用；亦刻意避开修仙的 宗/府/洞天/坊市/皇朝 语汇）；权谋命名风格（殿阁派系名 + 官职爵号）与修仙、情感、校园等刻意区分。
