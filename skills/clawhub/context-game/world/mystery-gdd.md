## 一、题材定位与设计意图

《雾港连环案》把《上下文》的"关系张力机器"搬进一座临海工业旧城。这里没有国家与军队，只有一条连环命案牵出的五方：官方调查组、民间侦探、嫌疑帮会、掩护医院、真相档案库。玩家不是穿上风衣的万能侦探，而是一个被卷进案子的普通人——可能受雇查案、可能替某方跑腿、也可能自己就是某条线索的当事人。

设计的第一条铁律是**线索链自洽**：任何"真相"都必须能被时间戳、物证、口供三样东西交叉验证。我们要的不是"凶手突然招了"，而是玩家一步步把三处断裂的物证链、被篡改的死亡时间、被抽走的三页旧卷拼回原状。所以本世界明确禁止侦探超能力，也禁止"意外"解开所有疑点——每推进一步，都得有可核实的凭据。

第二条意图是**让官方也不可全信**。第七分局握着调查权，却背着三年前抽走的三页旧卷；北岸医院是物证送检的官方协作者，却在太平间擅自处理无名遗体。玩家如果只信官方口径，会顺着"南巷会模仿作案"的结论走进死胡同——这正是开局埋好的诱导。

第三条意图是**把"中立交汇点"做成信息枢纽而非安全屋**。暗访周刊不是避风港，而是泄密与爆料的放大器：分局内勤向它卖线索，南巷会防它，封案馆限制它。玩家在这里既能买消息也能卖消息，但每笔交易都会留下关系痕迹。

第四条意图呼应共同骨架：五方势力 + 一个中立交汇点，构成与《双陆纪元》同构的"关系张力机器"——只是这里的'战争'是查案与反查案、藏证与挖证。

## 二、参考作品点名（仅点名，不列 URL）

- 《真探》（True Detective）：长篇多线程、旧案与现案手法同源、主角背负旧账。
- 《福尔摩斯》系列：线索—物证—口供三角推理范式，民间侦探与官方并行。
- 《漫长的季节》：旧案档案、时间跨度、被掩埋的真相与平凡人的卷入。
- 《沉默的真相》：层层掩护、证人保护、以命换真相的沉重张力。
- 《信号》（Signal）：跨时空旧案、档案库作为真相容器的设定。

这些作品的共同点是"案中有案、旧账未清"，而非"神探一锤定音"，这正是本世界拒绝侦探超能力的理由。

### 势力关系张力机器（faction_matrix 设计意图）

- **结构性敌意（≥2 对 ≤ -50）**：
  - 南巷会｜第七分局 = **-75**：分局锁定南巷会，南巷会反指"分局办错案"，公开对峙，物证链在三处断裂。
  - 北岸医院｜南巷会 = **-64**：医院空壳科室流水被南巷会用作模仿案资金通道，院方无意间成掩护，彼此防备。
  - 封案馆｜南巷会 = **-60**：旧档显示南巷会十年前悬案与今案手法同源，卷宗被抽三页，隔空对峙。
- **表面同盟藏裂缝（≥1 对 ≥50 且 note 藏缝）**：
  - 北岸医院｜第七分局 = **58**：正式送检协作，表面配合无间；但太平间三具无名遗体未报备、死亡时间被篡改——协作外壳下藏着擅自处理的暗门。
  - 封案馆｜瞰微所 = **64**："民间查案同盟"共享旧档检索权，但馆长私藏指向委托方的半页纸未交——同盟里有不敢摊开的半页。
- 其余 10 对 relation 值两两互不相同，分布于 -42 至 46 之间，构成完整的竞合光谱（详见 JSON）。

## 四、玩家起点与胜利通道

玩家三种开局身份（旅人 / 本地人 / 空白身世）都落在雾港，可被任意一条 opening_situation 牵引。本世界预留 **3 条"玩家可以赢"的路径**（满足护栏 3.1 与自洽清单第 8 条）：

1. **翻案路径（戳破模仿局）**：玩家收集第三案监控盲区时间戳 + 北岸排班重合 + 戚屿比对，证明第四起是杜歧自导模仿案，逼分局撤销"南巷会作案"定性。胜利标志：冷峻被迫重开物证链，南巷会嫌疑降级。
2. **旧账路径（拼回三页卷）**：玩家串联冷峻抽卷（三年前）+ 穆青修复 + 唐砚私藏半页，还原十年前同源手法真凶，让连环案与旧案并案。胜利标志：真凶身形锁定（言素照片 + 沈默目击），封案馆真相重见天日。
3. **证人路径（保下沈默）**：玩家在沈默进入官方保护程序（72 小时身份遮蔽）前护住他，借周刊或瞰微所把口供固化，绕过北岸医院的掩护。胜利标志：沈默安全指认，北岸擅自处理遗体的暗门曝光。

每条路径都不是"一键通关"：监控盲区、物证留存年限、证人保护程序、法医鉴定时效、档案调阅权限（见 world_tech）共同构成了"为什么某些事做不了"的硬边界。

## 六、8 条自洽清单自查报告

**1. Matrix 覆盖（≥2 对 ≤ -50；≥1 对 ≥50 且藏裂缝）**
→ **PASS**。≤ -50 三对：-75（南巷会｜分局）、-64（北岸｜南巷会）、-60（封案馆｜南巷会）。≥ 50 两对藏裂缝：58（北岸｜分局，太平间暗门）、64（封案馆｜瞰微所，私藏半页纸）。全部 relation 值两两互异（save.py 强制通过）。

**2. NPC 交叉咬合（secret 至少指向另一 NPC / 另一国 tension_seed / 一对 matrix）**
→ **PASS**。15 名 NPC 的 secret 全部可对应到具体实体或关系（见第 3 节表格），无悬空 secret。

**3. Tension 落地（每条 tension_seed 能追溯到 matrix 或 NPC）**
→ **PASS**。10 条 tension_seeds 均挂接矩阵对或具体 NPC（如"第四起急定性断裂"→ 矩阵 -75 + 冷峻/杜歧；"排班表被滥用"→ 方彻/戚屿）。

**4. 地点承载（每国 1-2 个 key_locations 能承载该国至少一个 tension_seed）**
→ **PASS**。10 处地点各有归属场景：分局专案室（断裂定性）、第三案天桥（监控盲区）、南巷堂口（模仿局放风）、北岸太平间（遗体暗门）、封案库（缺失三页）等，均直接承托对应 tension。

**5. 历史回响（history 至少 1 条能被当前 opening_situation 引用）**
→ **PASS**。"本月·连环案第四起定性当日"直接对应 opening 第 1 条（冷峻定性第四起）；"十年前同源手法悬案"被 opening 第 4 条（真凶在封案馆旧照）与多条 secret 引用。

**6. 技术约束（world_tech 至少 1 条是规则边界，解释为什么某些行动做不了）**
→ **PASS**。5 条 world_tech 全是边界：监控盲区（不能调监控直接抓人）、物证留存年限（旧案物证不能重鉴）、证人保护程序（证人不能立刻安全指认）、法医鉴定时效（死亡时间难推翻）、档案调阅权限（侦探不能随便翻旧案）。

**7. 开局活局势（5 条 opening_situation 都能被玩家第一个回合动作触及）**
→ **PASS**。5 条分别对应可行动地点：去分局专案室 / 去瞰微所门口 / 去北岸急诊科 / 去封案馆阅档厅 / 去南巷堂口，均为玩家首回合可执行的移动+调查动作。

**8. 玩家胜利通道（至少 2-3 条明显路径）**
→ **PASS**。第 4 节给出翻案 / 旧账 / 证人 三条明确胜利通道，且都被 world_tech 边界与 NPC secret 网络支撑，非空中楼阁。

**自查结论：8/8 PASS，无 FAIL、无 CONCERNS。** 唯一需主理人留意的是"北岸医院｜第七分局 58"这对表面同盟的裂缝——它把医院从单纯'送检节点'抬升为潜在共犯，建议在运行时不要让北岸医院的暗门过早暴露，保留玩家自行挖出的叙事快感。

## 七、题材专属护栏确认（协议 §3.2）

- **辨识锚点齐备——线索链自洽**：任何"真相"都由时间戳、物证、口供三角交叉验证；`world_tech` 的监控盲区、物证留存年限、证人保护程序、法医鉴定时效、档案调阅权限构成"为什么某些事做不了"的硬边界。
- **明确禁止项均未出现**：无侦探超能力；无"'意外'解决所有疑点"——每推进一步都需可核实凭据，开局即埋好"南巷会模仿作案"的诱导结论。
- **命名合规**：实体 id 全 ASCII 前缀 + 小写；展示名中文 2-4 字；未撞真实国家/知名跨国公司/在世真实人物/宗教神祇；跨题材零重名（未复用硬科幻题材《双陆纪元》的卡萨德/麟河/奥斯特/土伊德/菲洛/灰潮等实体名）；悬疑命名风格（第七分局/瞰微所/南巷会/北岸医院/封案馆/暗访周刊，线索档案风）与其余题材刻意区分。
