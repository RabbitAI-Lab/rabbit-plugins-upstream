## 一、题材定位与设计意图

《余烬荒年》是一部"末日废土·废土生存"题材的开放世界。大崩塌十年后的烬原上，烬市议会、旷野军、新芽聚落、荒泉教、商漠驼队五方为净水、弹药、疫苗、净粮四类硬通货互算生死——**文明没了，规则也没了；谁握着水，谁就是新的神。**

本题材立项书第④问为**高危条件通过**，最近邻是 `military`（军事）。划界必须写死：

- 军事 = **指挥战斗**（兵种、编制、战术、力量对抗，"打赢一场仗"）。
- 末日废土 = **生存与分配**（资源经济学 + 幸存者政治，"怎么活下去、资源怎么分"）。
- 一句话：**废土的胜负手是"资源即命脉"，不是"谁的火力猛"。** 本作没有一场以歼敌为目标的战役，所有冲突都围绕水源、补给线与人口展开。

**三条独有机制（写进 `world_tech`）**：

1. **资源经济学（净水 / 弹药 / 疫苗 / 净粮 = 硬通货）**——废土没有货币，只有四类硬通货；供给线即命脉，断供即崩盘。运行时：切断旷野军的弹药补给线 → 旷野军战力 −30，被迫向议会和谈。
2. **补给线即命脉（物流即政治）**——每条补给线是一对"上游-下游"关系，可被拦截、抬价、改道；控制补给线者控制分配权。运行时：联合商漠驼队改走新芽聚落的商路，把议会挤出分配圈。
3. **幸存者政治（人口 = 税基 = 兵源）**——聚落 / 人口是稀缺资源，谁得人心谁得产能；玩家可用政策 / 物资换取归附。运行时：用疫苗救下新芽聚落，聚落归附，玩家获得稳定兵源与产能。

叙事张力机器沿用《上下文》通用骨架：**多方势力互算 + 结构性敌意 + 表面同盟藏裂缝 + 中立交汇点**。中立交汇点 = 旧站集市（旧车站集市），"站内禁抢"是残存秩序，是其物理边界。

贯穿全局的"母悬念"是 `history` 首条"大崩塌"与末条"配给断供"：旧世界档案与净水厂设施残存于地下，而荒泉教的"神迹净泉"不过是旧净水厂的一角——玩家的每个动作都在"废土还能不能重新分好这口水"的赌桌上压注。

## 二、参考作品点名（仅点名，不列 URL）

下列作品在"资源稀缺""废土政治""幸存者生态"上对本作有启发：

1. **《疯狂的麦克斯》系列**——净水/燃料即权力、以补给线争夺为核心的废土生存质感。
2. **《辐射》系列**（取其据点政治与"旧世界残骸"设定，非其变异开挂部分）——旧政府残部、旧设施宝藏与末日教会的生态。
3. **《最后生还者》**——幸存者聚落的自耕自守与"聚落政治"，以及稀缺资源下的道德困境。
4. **《行尸走肉》**——据点间的合纵连横与"谁掌握物资谁定规矩"的分配政治。
5. **《水世界》**（取其"净水即货币"的极端设定，作为资源经济学的参照）。

## 四、玩家起点与胜利通道

身份三选一（沿用 SKILL.md 开局）：**旅人**（初入烬原、无归属）、**本地人**（某派中低层，自带 1 中立 1 紧张关系）、**空白身世**（身世随剧情揭示后补写）。

**至少 3 条"玩家可以赢"的路径**（协议 §3.1 通用护栏，照立项书）：

1. **重建秩序通道**：联合烬市议会 + 商漠驼队 + 新芽聚落建立分配公约，重建文明——赢在"恢复规则"。
2. **垄断命脉通道**：控制净水 / 疫苗两条命脉，以资源为杠杆整合各方——赢在"资源霸权"。
3. **迁徙通道**：勘探出未被污染的安全区，带领追随者迁徙——赢在"另起炉灶"。

失败不清档：公约被军阀打破则转垄断线；垄断崩盘则转迁徙线，棋局不锁死，符合"失败改变棋局"。

## 五、题材设计说明

本题材（《余烬荒年》· `apocalypse`）的定位与独特性：

| 维度 | 本题材说明 |
|---|---|
| 势力语义 | 5 方：市政残部 / 军阀 / 幸存者聚落 / 末日教会 / 商队 |
| 中立交汇点 | 旧站集市（旧车站集市，站内禁抢） |
| 独有机制 | 资源经济学（四类硬通货）+ 补给线即命脉 + 幸存者政治 |
| 禁止项 | 无限资源、单枪匹马救世、变异超人开挂 |
| 命名风格 | 废墟/环境词（烬市/旷野/新芽/荒泉/商漠/旧站）+ 后末日苍凉感 |
| 张力机器 | 15 对矩阵；新增"资源即硬通货"的生存经济学 |

**与最近邻题材的划界一句话**：末日废土 = **生存与分配**（资源经济学 + 幸存者政治，"怎么活"）；军事 = **指挥战斗**（兵种/编制/战术，力量对抗，"打赢一场仗"）——两者都有武装势力，但废土的拳头只为抢水与守补给线，不为歼敌。

## 七、题材专属护栏确认

- **辨识锚点齐备——废土生态真实**：资源稀缺（四类硬通货）、辐射区、变异生态、旧文明废墟、补给线、据点政治在 `world_tech` 与 `key_locations` 中落地（议会大厅、档案地库、旷野营地、旷野隘口、新芽寨、荒泉圣坛、驼队宿营地、旧站集市等）。
- **明确禁止项均未出现**：
  - 禁止"无限资源"——`tech_hard_currency` 明确"四类硬通货存量有限、须持续补给，断供即崩盘"；`tech_supply_line` 明确改线有代价、不能无限安全运补；
  - 禁止"单枪匹马救世"——`tech_no_savior` 明确"个人武力救不了一整片废土，胜利靠资源 + 分配 + 人心的组合"；
  - 禁止"变异超人开挂"——`tech_mutation_threat` 明确"变异生态是威胁与环境，不是玩家的力量来源，不强化个人战力"。
- **防开挂核心落地**：资源稀缺 + 分配权（`tech_hard_currency` + `tech_survivor_politics`）——玩家不能既独占资源又得人心，分配永远有代价。
- **与军事的划界落地**：GDD 一节写死"生存与分配 vs 指挥战斗"；本作无一场以歼敌为目标的战役，所有冲突围绕水源、补给线与人口展开；命名（烬市/旷野/新芽/荒泉/商漠/旧站）刻意区别于军事的"司令部/佣兵/联邦/情报"语汇。
- **命名合规**：实体 id 全 ASCII 前缀 + 小写；展示名中文 2-4 字（烬市议会/旷野军/新芽聚落/荒泉教/商漠驼队/旧站集市）；未撞真实国家/知名跨国公司/在世真实人物/宗教神祇；跨题材零重名（未复用既有题材词根：砚/泓/北岭/东岸/沈氏/东/青/铁 均未使用；亦与军事的"北岭/南线/黑铁/霜刃/赤道/银湾"零碰撞）；废土命名风格（废墟/环境词 + 后末日苍凉感）与军事、修仙等刻意区分。
