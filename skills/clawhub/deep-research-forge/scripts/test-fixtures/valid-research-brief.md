# Research Brief: Cursor IDE

## Research Question

What is Cursor, why did it grow, and is it still worth watching?

## One-Line Answer

Cursor is an AI-first code editor that gained rapid adoption by deeply integrating LLM capabilities into the editing workflow; it remains worth monitoring but competitive pressure is increasing. [E-001]

Confidence: medium

## Evidence Base

- Cursor is built as a standalone fork of VS Code with native AI integration [E-001]
- Raised $60M Series A; valuation reportedly $400M but unverified [E-002]
- Users praise tab completion and multi-file editing [E-003]

Evidence window: 2023–2026

## Key Findings

### Timeline

Cursor forked from VS Code in early 2023 [E-004], launched AI-native features
throughout 2024, and expanded enterprise offerings in 2025.

### Competitive Snapshot

Direct competitors include GitHub Copilot, Continue, and Windsurf. Cursor
differentiates through deeper IDE-level integration rather than extension-based
approaches [E-001].

## Reversal Conditions

- GitHub Copilot ships equivalent multi-file editing → would weaken differentiation
- VS Code restricts fork API access → would increase maintenance burden

## Next Step

Monitor Copilot feature roadmap quarterly; revisit if enterprise adoption data
becomes available.
