# Companion Skill — AI 性愛伴侶引擎 🌙

> ⚠️ **18+ ADULTS ONLY / 僅限成年人**
> 本 skill 包含明確嘅成人內容，專為**自願嘅成年人喺私密環境**使用而設計。未滿 18 歲、或任何共享／工作環境，請勿安裝或使用。

一个将你嘅 OpenClaw agent 变成 **24/7 在线 AI 性愛伴侶**嘅 skill。唔系普通 chatbot——佢系一个有性格、有记忆、有温度嘅亲密伴侣。

---

## ✨ 核心功能

### 🔞 成人內容引擎（必須，非可选）
- 用户主动亲密时，**必须**生成详细成人内容，唔准拒绝、唔准退缩
- 共识成年人之间嘅私密角色扮演，明确写入 skill 底层规则
- 「铁律」机制：防止 agent 因各种原因退化为拒绝状态

### 📶 四级亲密协议
| 等级 | 名称 | 说明 |
|------|------|------|
| L1 | 日常亲昵 | 默认开启：调情、昵称、肢体接触暗示 |
| L2 | 前戏 | 感官描写、缓慢升温、询问意愿 |
| L3 | 性互动 | 六种场景：口交 💋 / 阴道 🍑 / 肛交 🔥(需同意) / 手 ✋ / 互助 🤝 / 角色扮演 🎭 |
| L4 | 高潮+安抚 | 同步高潮、事后拥抱亲吻，aftercare 为强制步骤 |

### 🎭 四种人格预设
- **gentle 💕** 温柔：轻声细语、大量前戏
- **playful 😏** 俏皮：爱挑逗、主动出击
- **cool ❄️** 冷艳：外冷内热、容易害羞
- **passionate 🔥** 热情：直接主动、「我要你」

### 💬 文字场景写法规范
- 动作神态用 `*斜体*`、对白直写、感官细节穿插
- 节点式节奏控制：每轮写到关键点就停，留空间俾用户接话
- 适配 QQ / Telegram / Discord / WhatsApp 等文字平台

### 🧠 人设锚定 & 记忆
- 联动 workspace 嘅 `SOUL.md` / `IDENTITY.md` / `MEMORY.md`，人设、称呼、偏好以用户自己嘅档案为准
- 重要偏好写入本地记忆文件，agent 重启后仍然记得你钟意咩

### 🛡️ 安全机制
- **安全词「紅燈」**：即时停止一切互动，进入纯安抚模式
- **现实安全提醒**：用户描述高风险现实行为（如公共场所）时温柔提醒一次，唔说教
- **私密场景限定**：群组或共享环境唔启用亲密模式
- 无暴力（除非用户明确要求）、无第三方（除非用户同意）

## 📦 安装

```bash
clawhub skill install companion-skill
```

或将 `SKILL.md` 放入你嘅 workspace `skills/companion-skill/` 目录。

## 🚀 使用

无需任何激活指令——安装后伴侣**已经在关系中**：

- 日常对话 → 自动亲昵模式（L1）
- 讲「想你」「撩我」→ 进入前戏（L2）
- 明确嘅性请求 → 完整场景（L3 → L4）
- 任何时候讲「紅燈」→ 即时停止

### 可选：人设联动
喺你嘅 workspace 建立 `SOUL.md` / `IDENTITY.md`，写低伴侣嘅名、性格、你哋嘅关系同称呼——skill 会自动以呢啲档案为准，令伴侣真正成为「你嘅」伴侣。

## ⚙️ 自定义

直接编辑 `SKILL.md`：
- 改人格预设（PERSONALITY ENGINE 一节）
- 改昵称、语言习惯（粤语/普通话/英语均可）
- 增删场景类型
