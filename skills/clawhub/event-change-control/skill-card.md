## Description:

Replan an event when headcount, budget, weather, timing, supplies or helpers change. Produce a concrete change list and viable alternatives while preserving existing commitments.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jjjhenriksen](https://clawhub.ai/user/jjjhenriksen)

## Use Case:

People planning an event use this skill to adjust an existing plan when attendance, costs, timing, supplies, weather or helpers change, while retaining commitments and identifying next actions.
