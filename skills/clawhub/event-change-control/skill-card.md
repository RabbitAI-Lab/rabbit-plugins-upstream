## Description:

Replan an event when headcount, budget, weather, timing, supplies or helpers change. Produce a concrete change list and viable alternatives while preserving existing commitments.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jjjhenriksen](https://clawhub.ai/user/jjjhenriksen)

### License/Terms of Use:

MIT

## Use Case:

Event hosts and planners use this skill to adapt an existing event plan when attendance, budget, weather, timing, supplies, or helpers change. It identifies affected commitments and produces a practical change list, with alternatives when there is a meaningful choice.
