# 品牌语气校对报告模板

> 复制本文件填充内容。五节必须齐全；某节无内容时保留标题并写明原因。方括号内为需替换的占位。

```
## 一、语气规则解读（可判定条目）
- 人称：[我们 / 我 / 你 / 您 / 咱]
- 正式度：[口语 / 半正式 / 正式]
- 句式长度：[短句为主 / 长短交错 / 长句论述]
- 感叹号与 emoji：[禁用 / 少量 / 自由]
- 术语程度：[通俗 / 适度 / 高密度]
- 情感浓度：[克制 / 中等 / 热情]
- 待确认项：[无 / 列出哪些维度用户未明确，标注待裁决]

## 二、不一致清单
| 位置 | 原文 | 类型 | 依据 | 改写建议 |
|---|---|---|---|---|
| 第 N 段第 N 句 | [原句] | [语气跳变 / 用词不一致 / 人称混乱 / 禁词或必用词] | [对照规则哪一条] | [可直接替换的成句文字] |

（无不一致时写：经逐段扫描，未发现四类不一致项。）

## 三、事实待确认（不在语气校对范围内）
- [位置] [疑似事实问题，如数字/时间/价格/范围/承诺与常识或上下文不符] → 请自行核实，本技能不改写

## 四、一致性小结
- 一致性评分：[0~100，附一句依据，不精确]
- 问题分布：语气跳变 [N] / 用词不一致 [N] / 人称混乱 [N] / 禁词或必用词 [N]
- 风险词提示：[命中 references 风险词表的词及类别，仅提示不判定]

## 五、统一后的全文版本
（贴整稿：只改语气用词，不改任何事实与承诺。规则与文案冲突未裁决处保留原文并标注）
```

## 填写约束

1. 第二节每条都必须有"原文 / 类型 / 依据 / 改写建议"四列，缺一不可。
2. 改写建议只能换语气词、句式、用词统一、标点风格，**不得改动数字、时间、价格、范围、退换/时效/保修等承诺**。
3. 疑似事实错误必须进第三节，不得在校对中"顺手修正"。
4. 风险词只提示、不判定合规；合规结论由用户或法务作出。
5. 全文控制在便于团队复盘的长度，逐条清单优先于评分。
