# 品牌语气一致性校对 (ym-brand-voice-check)

按你给的语气规则逐处标出不一致并给改写，但不擅自改动事实与承诺。把"像不像我们"变成一份可逐条核对的清单，而不是一句"调性不太对"。

## 何时使用

- 用户说「检查语气一致」「按我们调性改一下」「品牌文案校对」「这段是不是不太像我们」时
- 用户贴了多篇文案、多条回复，说「帮我看看它们是不是一个调性」时
- 用户准备了一批对外文案，希望上线前统一口径时

## 运行前提

- 依赖：无第三方依赖，纯文本处理
- 不读取任何本地文件，除非用户明确给出路径
- 不联网、不上传任何数据

## 输入契约

| 项 | 必需 | 说明 |
|---|---|---|
| 待校对文案 | 必需 | 一段或多段自由文本，可以是推文、落地页、客服回复、产品介绍等 |
| 语气规则 | 必需（来源可替代） | 两种来源任选：①一份品牌语气说明；②2~3 段用户认可的"写得对的"样稿作为基准 |
| 禁用词表 | 可选 | 明确不能出现的词或表述 |
| 必用词表 | 可选 | 必须出现或必须统一使用的词（如统一叫"会员"不能叫"用户"） |
| 受众 | 可选 | 学生 / 职场人 / 银发群体等，影响正式度判断 |
| 投放渠道 | 可选 | 公众号 / 客服消息 / 电商详情页，影响长度与 emoji 容忍度 |

**缺失处理：**

- 无语气规则 → 请用户至少给 2~3 段认可的自家文案作为基准；若用户只给待校文案，则从中反推语气规则并在报告开头列出，**标注"以下规则为反推，待你确认"**，不自行当作定论。
- 规则与文案冲突（如规则要正式，但基准样稿很口语）→ 按规则改，但把冲突点单独列进"需你裁决"清单，不替用户二选一。
- 无禁用词表 → 只做语气与用词一致性检查，不判定合规；如文中出现常见风险词，提示到"常见风险词提示"节，但不下"违规"结论。
- **待校文案为空 → 直接说明无法校对，列出需要提供的信息，绝不编造不一致项**

## 执行步骤

1. **把语气规则转成可判定条目** — 先把模糊规则落到六个可判定维度（详见 `references/voice-dimensions.md`）：人称（我们/我/你/您）、正式度（口语/半正式/正式）、句式长度（短句为主/长短交错）、是否可用感叹号与 emoji、专业术语使用程度、情感浓度（克制/热情）。规则不明确处标"待确认"，不要猜。

2. **逐段扫描，标四类不一致** — 对每段检查：①语气跳变（同一段内由亲切突然变官方）；②用词不一致（同一事物出现两个叫法）；③人称混乱（我们/我/咱混用）；④命中禁词或违反必用词。每条记录原文位置（如"第 2 段第 3 句"）。

3. **每条给改写建议** — 格式为：原文 / 问题类型 / 为什么不一致（对照规则哪一条）/ 改写建议（给可直接替换的成句文字）。改写只动语气与用词，**不动事实**。

4. **事实与承诺保护（硬约束）** — 校对不改变任何事实性表述（数字、时间、价格、范围）与承诺（退换、时效、保修）。若扫描中发现疑似事实错误（如"7 天无理由"写成"15 天"），**不要擅自改**，单独列入"事实待确认（不在语气校对范围内）"节，提醒用户自行核实。

5. **出一致性评分与问题分布** — 给一个 0~100 的主观一致性评分（附依据，不精确），并统计四类问题各出现几次，供团队复盘。评分只是辅助，不替代逐条清单。

6. **给统一后的全文版本** — 输出一份"只改语气用词、不改事实"的整稿，让用户能直接替换。若规则与文案冲突未裁决，则保留原文并标注。

7. **硬性约束** — 不擅自增删信息；不为了调性牺牲准确性；不做法律合规与广告法合规审查（仅提示常见风险词，见 references）。

## 输出格式

Markdown，套用 `templates/report-template.md`，五节：

```
## 一、语气规则解读（可判定条目）
- 人称：…
- 正式度：…
- …（六维度）
- 待确认项：…

## 二、不一致清单
| 位置 | 原文 | 类型 | 依据 | 改写建议 |
|---|---|---|---|---|
| 第2段第3句 | … | 用词不一致 | 与"会员"叫法冲突 | … |

## 三、事实待确认（不在语气校对范围内）
- [第1段] "15天无理由"与常见"7天"不符，请核实是否笔误

## 四、一致性小结
- 评分：82 / 100
- 问题分布：语气跳变 1 / 用词不一致 3 / 人称混乱 0 / 禁词 1

## 五、统一后的全文版本
（贴整稿）
```

## 能力边界

- 不做广告法合规审查（只提示常见风险词，交由用户或法务自查）
- 不保证改写后更符合品牌（最终以品牌方判断为准）
- 不校对非中文语种的细微语感
- 不自动发布、不修改原文件；不读取本地文件除非用户给路径

## 常见坑

1. **把反推规则当既定规则** — 用户没给规则只给样稿时，模型容易直接以样稿为基准下结论。规避：反推的规则必须标注"待确认"，让用户拍板。
2. **为调性改了事实** — 看到"原价 999"和"现价 199"不一致，可能顺手"修正"。规避：事实性数字、时间、价格、范围一律不碰，疑似错误只进"事实待确认"。
3. **改写把承诺写重了** — 原文"尽快处理"，改写时写成"24 小时内解决"，凭空加了承诺。规避：改写只换语气词与句式，不新增时效、保修、退换等承诺。
4. **人称混乱没标全** — "我们"和"咱"混用容易被当成同一人称放过去。规避：人称维度逐句过，凡出现非规则指定的人称即标"人称混乱"。
5. **禁词只判字面不判变体** — 禁用词写了"最"，却漏了"顶级""第一""史上"。规避：碰到超级lative相关词都进"常见风险词提示"对照，提醒用户自查。
6. **评分当结论** — 给了 82 分就以为没问题。规避：评分只辅助，报告价值在逐条清单；若清单空着，评分再高也不能交付。

## 验收用例

- 正常：给规则 + 500 字文案 → 逐条标出不一致并给改写，事实项未动
- 边界 1：无规则 → 请求提供基准样稿或反推并标"待确认"，不凭空判断
- 边界 2：文案含明显事实错误（"永久免费"疑似夸大）→ 列入事实待确认，不擅自改
- 失败：规则与文案严重冲突且用户不裁决 → 输出两版（按规则 / 保留原文）供选
