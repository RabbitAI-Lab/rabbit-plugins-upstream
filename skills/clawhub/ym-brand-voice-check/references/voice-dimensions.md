# 语气维度可判定化对照表

把模糊的"调性要求"落到六个可逐句判定的维度。每个维度给「判定问句 / 取值 / 怎么从文案看出来」，方便校对时直接对照，不靠感觉。

## 一、六维度判定表

| 维度 | 判定问句 | 常见取值 | 文案中的可判定信号 |
|---|---|---|---|
| 人称 | 用谁称呼自己和读者 | 我们 / 我 / 你 / 您 / 咱 | "我们"偏机构，"我"偏个人 IP，"您"偏敬语客服，"咱"偏亲切社群 |
| 正式度 | 口语还是书面 | 口语 / 半正式 / 正式 | 口语：用"啦、呗、搞定、超"；正式：用"您、敬请、予以、均可" |
| 句式长度 | 句子长短倾向 | 短句为主 / 长短交错 / 长句论述 | 短句：多换行、无逗号长串；长句：一个句子含 3 个以上逗号或分号 |
| 感叹号与 emoji | 能不能用、用多少 | 禁用 / 少量 / 自由 | 统计"！"与图形符号出现密度；禁用时出现即标 |
| 术语程度 | 专业词多不多 | 通俗 / 适度 / 高密度 | 出现行业缩写、专有名词密度；受众非专业时应降 |
| 情感浓度 | 情绪强弱 | 克制 / 中等 / 热情 | 热情：大量形容词、感叹、号召性语句；克制：陈述事实、少渲染 |

## 二、维度取值冲突的典型表现

- 同一段里"亲，搞定啦"和"请您予以确认"并存 → 正式度跳变 + 人称混乱（咱/您）
- 前句短句活泼，后句突然来一段无逗号长论述 → 句式长度跳变
- 基准样稿全用"您"，待校文案混进"你" → 人称混乱

## 三、把规则写成判定条目（示例）

用户提供"我们品牌偏专业、克制、对 B 端客户用您"，转成：

```
人称：我们（机构视角）+ 您（对客）
正式度：正式
句式长度：长短交错，但单句不超过 2 个逗号
感叹号与 emoji：禁用
术语程度：适度（B 端可接受行业词）
情感浓度：克制
待确认项：无
```

## 四、事实与承诺保护红线

以下四类内容**一律不改动**，疑似问题只进"事实待确认"节：

- 数字：价格、数量、百分比、金额、版本号
- 时间：日期、周期、时效（"7 天""24 小时"）
- 范围：覆盖地区、适用人群、功能边界
- 承诺：退换、保修、赔付、服务等级（SLA）

改写只动：称呼、语气词、句式、用词统一、标点风格。

## 五、回复 / 文案常见风险词提示（只提示，不判定合规）

以下词常用于对外文案，属广告法与平台规则的高频风险点。**本表只提示用户自查，不下"违规"结论，也不做合规审查。**

| 风险类别 | 常见词 / 表述 | 提示 |
|---|---|---|
| 绝对化 | 最、第一、顶级、唯一、极致、史上、万能、100%、永久、绝对 | 易被认定为绝对化用语，建议替换或加限定 |
| 虚假承诺 |  guaranteed 保证、包治、必瘦、必白、零风险、稳赚 | 涉功效/收益承诺，风险高 |
| 限时虚假 | "仅限今天"但长期挂着、无依据的划线价 | 暗示虚假促销，需有真实依据 |
| 医疗保健暗示 | 治疗、消炎、抗癌、美白、减肥、增高（非特殊用途化妆品/药品资质） | 无资质时禁用 |
| 诱导转发 | 转发有奖、集赞免费、不转不是 | 部分平台禁诱导分享 |
| 个人隐私威胁 | 不转就曝光、公开你的信息 | 涉侵权，禁用 |
| 贬低对手 | 比 XX 更好、XX 都是坑 | 涉不正当竞争，慎用 |

使用方式：扫描文案时，命中上表词即在对应用位置标注"风险词提示：XX（类别）"，并指向本表，由用户自行判断是否合规。
