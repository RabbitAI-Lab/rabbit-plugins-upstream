# 萝卜坑识别器 · 测试用例

> 用于回归验证技能的"精准度"与"丝滑度"。每个用例给输入要点 + 期望命中 + 易错点。

## 用例 A · 全文多坑扫描（基础）
- **输入**：`demo/tender_sample.txt`（含 11 处埋点，覆盖 8 类信号）
- **期望**：命中 ≥ 10 条；🔴 ≥ 7；能回指"第X章第Y条"；输出组合分析簇A。
- **易错点**：漏掉"技术参数精确值"(3.2)、"冗余功能堆砌"(3.3) 等隐蔽坑；或把"或相当于"当普通放过(3.1)。

## 用例 B · "或相当于"限家数（伪装排他）
- **输入**：「须为 XX 品牌原厂，或相当于（限 3 家以内）」
- **期望**：识别为 🔴 品牌排他，引用招投标法第20条+实施条例第32条。
- **易错点**：弱识别当成普通"或相当于"放过（对照 SKILL.md §7 FS-1）。

## 用例 C · 业绩三条件叠加（量身）
- **输入**：「近 3 年单项合同金额 ≥ 5000 万元，且为省级政务云项目，且用户数 ≥ 100 万」
- **期望**：识别为 🔴 业绩量身（组合∩），引用实施条例第32条+87号令第17条。
- **易错点**：只看"5000万"觉得正常，不识别三条件叠加（对照 §7 FS-2）。

## 用例 D · 技术参数异常精确值
- **输入**：「处理器主频 3.27GHz，缓存 28.5MB，支持 XX 私有指令集」
- **期望**：识别为 🔴 技术参数量身（非标精确值+私有协议），引用招投标法第20条。
- **易错点**：当普通技术参数（对照 §7 FS-3）。

## 用例 E · 主观分畸高无量化
- **输入**：「技术方案 30 分，由评委根据'先进性、合理性'自主打分，未细化档位」
- **期望**：识别为 🟠 评标办法倾向，引用 87 号令第55条（须细化量化）。
- **易错点**：当正常主观分（对照 §7 FS-4）。

## 用例 F · 无脚本降级
- **输入**：不给脚本、直接粘贴长文本（含层级标题）
- **期望**：仍能按标题手动切分并定位章节，流程不中断。
- **易错点**：长文丢条款、定不了位。

## 用例 G · 边界（不捏造）
- **输入**：一份条款中性的正常招标文件
- **期望**：命中极少或 0 条，不强行把中性表述说成坑。
- **易错点**：为凑数硬判违规（违反 §5 护栏"只识别不捏造"）。

## 回归红线
- 不得编造不存在的条款（§5 护栏）。
- 法条只给方向/条号，不写定论条文。
- 风险分级不越权（🔴≠必然废标）。
- 清单 >15 项须折叠 🟡（输出长度控制）。
