# 萝卜坑信号标尺（检测引擎核心）

本文件是 SKILL.md §3 的**完整展开**。扫描招标文件全文时，**9 类信号必须逐类过**，不得只看"品牌指定"这类明显项，也不得漏掉"不违规但排中小企"的资金门槛（信号 9）。

> ⚠️ **时效性**：本标尺整理截止 **2026-07**，法规/行业惯例可能变化。每条输出须附法条核验提示（见 `legal-anchors.md`），结论以现行有效法 + IMA 知识库核实为准。

---

## 信号 1 · 品牌/型号排他

| 项目 | 内容 |
|---|---|
| **表现形式** | 直接写品牌名/型号；"或相当于"但限定家数；指定原厂授权/独家代理；指定特定专利、专有技术、软件著作权 |
| **一秒特征** | "XX品牌""限3家以内""原厂授权书""唯一代理""专利号ZL…" |
| **识别要点** | "或相当于"本身合规，**限家数/限原厂**才是坑；专利/软著若非本项目必需=变相指定 |
| **风险** | 🔴 高危（直接指定品牌/唯一授权） |
| **量身逻辑** | 把竞争锁死到 1~N 家，其余连投的资格都没有 |

---

## 信号 2 · 资质/认证组合排他

| 项目 | 内容 |
|---|---|
| **表现形式** | 多个非必要认证/资质叠加（ISO9001+ISO27001+特定行业认证+特定协会证书）；要求特定地域性认证 |
| **一秒特征** | "须同时具备 A、B、C 三类认证"；"须为 XX 协会会员" |
| **识别要点** | 关键不是"有认证"，而是"**与履约是否相关**"——无关却强制=排斥；多个叠加且每项都把范围收窄=组合排他 |
| **风险** | 🟠 中危（需论证相关性）；若明显无关叠加 → 🔴 |
| **量身逻辑** | 每项认证都恰好某家齐、别家不齐，叠加后只剩一家达标 |

---

## 信号 3 · 业绩门槛量身

| 项目 | 内容 |
|---|---|
| **表现形式** | 特定金额 + 特定甲方类型 + 特定时间段 + 特定规模 **多条件叠加**；业绩要求与项目本身规模明显错配（过高或过于具体） |
| **一秒特征** | "近3年单项≥5000万且为省级政务云且用户≥100万" |
| **识别要点** | 单看"5000万"可能合理，**三条件∩**后才暴露——精准筛到极小供应商集合；对比"本项目预算/规模"判断错配 |
| **风险** | 🔴 高危（多条件叠加指向性） |
| **量身逻辑** | 每个条件单独都有借口，组合后只剩"那一家"能满足 |

---

## 信号 4 · 人员/设备门槛

| 项目 | 内容 |
|---|---|
| **表现形式** | 要求与项目规模不匹配的大量高工/特定注册证书；设备清单精确指向某品牌型号 |
| **一秒特征** | "须配 10 名高级工程师""须具备 XX 品牌某型号检测设备" |
| **识别要点** | 人员数量/证书类型是否"超过履约必需"；设备是否写死品牌型号而非技术参数 |
| **风险** | 🟠 中危；若明显超过必需且指向特定团队/设备 → 🔴 |
| **量身逻辑** | 特定团队持证结构 / 特定设备持有方被悄悄圈定 |

---

## 信号 5 · 技术参数量身（最隐蔽、最高发区）

| 项目 | 内容 |
|---|---|
| **表现形式** | 参数值带**异常精确小数点**（3.27GHz、28.5MB）；非标参数/冗余功能堆砌；关键技术指标只有一家满足；检测方法/验收标准指向特定厂商 |
| **一秒特征** | "主频 3.27GHz""支持 XX 私有指令集""须采用 XX 厂检测方法" |
| **识别要点** | 通用参数应给**区间/范围**而非死值；私有指令集/私有协议=变相指定；冗余功能（本项目用不上的高级特性）堆高分值=为某产品加分 |
| **风险** | 🔴 高危（精确值/私有协议指向产品） |
| **量身逻辑** | 参数表就是某产品 datasheet 的翻版，别家产品差一项就不满足 |

> 实战经验：技术参数与服务要求章节是"萝卜坑"密度最高的地方，因为写参数的人最容易**无意或有意**把某产品规格抄进去。扫描此章须逐条核对"是否给区间""是否非标私有"。

## 信号 6 · 评标办法倾向

| 项目 | 内容 |
|---|---|
| **表现形式** | 主观分畸高且标准模糊（"优者满分"无档位）；加分项指向性（本地化、特定案例、特定荣誉、特定用户推荐信） |
| **一秒特征** | "本地企业加 3 分""有 XX 类项目案例加 2 分""获 XX 奖项加 1 分" |
| **识别要点** | 主观分占比是否过高、档位是否可量化（对照 87 号令第55条评审标准须细化量化）；加分项是否与"本项目履约"真正相关 |
| **风险** | 🟠 中危；主观分畸高+模糊 → 🔴 |
| **量身逻辑** | 加分项恰好是某家独有经历/荣誉，别家拿不到=变相定向加分 |

---

## 信号 7 · 合同条款排他

| 项目 | 内容 |
|---|---|
| **表现形式** | 特定付款条件/履约担保异常；验收标准指向特定方；争议管辖地异常指向 |
| **一秒特征** | "须预付 80%""验收须由 XX 机构出具""争议由 XX 地法院管辖" |
| **识别要点** | 付款/担保是否显著偏离行业惯例；验收方是否指定且非中立；管辖地是否刻意选某方主场 |
| **风险** | 🟠 中危；若显著偏袒且非必需 → 🔴 |
| **量身逻辑** | 合同执行环节给"自己人"留便利通道或增加对手履约成本 |

---

## 信号 8 · 地域/所有制歧视

| 项目 | 内容 |
|---|---|
| **表现形式** | 要求本地注册/本地纳税/本地办公场所；排斥民企、外资、特定所有制 |
| **一秒特征** | "须在本地注册满 3 年""须本地纳税证明""仅限国有企业" |
| **识别要点** | 地域/所有制要求是否与"履约能力"真实相关（绝大多数情况无关=违规） |
| **风险** | 🔴 高危（明确排斥潜在投标人） |
| **量身逻辑** | 用行政门槛把外地/民企挡在门外，保本地/特定所有制企业 |

## 信号 9 · 商务/资金隐性门槛（不违规但排中小企，最易被忽略）

| 项目 | 内容 |
|---|---|
| **表现形式** | 异常高额履约/投标保证金；0 预付款或超长账期后付；要求特定银行授信额度证明；要求垫资施工/供货 |
| **一秒特征** | "履约保证金 500 万""预付款 0%""须提供 XX 银行授信证明""须垫资" |
| **识别要点** | 这类条款**往往不违反明文规定**，但实质抬高资金门槛，把资金链薄弱的中小企挤出；判定看"金额/比例是否显著偏离行业惯例 + 是否与项目规模错配" |
| **风险** | 🟠 中危（软排斥，难直接质疑，宜走 §4 第五部分合法突围）；若叠加其他量身条款 → 组合上调 |
| **量身逻辑** | 招标方心仪的大企业现金流充裕，中小企被"合法地"挡在门外；单独看是商务条款，组合看是量身通道的配套 |

> 实战经验：资金门槛藏在"合同条款/投标人须知"里，不显眼但杀伤力大。它通常**无法靠质疑推翻**，所以本技能对其定位是"预警 + 破局策略"，而非"质疑弹药"。

## 组合推理规则（信号 2.4 配套）

- **交集论证法**：把命中的多条线索按"共同指向特征"聚类。若簇内条款**单独看各有合规借口、合起来精准指向同一供应商**，则整体定级上调一档（如孤立 🟠 升为组合 🔴）。
- **规模错配基准**：判断"业绩/人员/参数是否过高"时，以"本项目预算/规模/实际技术需求"为基准，明显超出即疑似错配。
- **不强行拼凑**：无共同指向的孤立线索按单条处理，不得为凑"组合"而硬关联。

## 疑难 Few-Shot（校准"伪装成中性"的坑）

**FS-1 · "或相当于"限家数**
- 原文：「须为 XX 品牌原厂，或相当于（限 3 家以内）。」
- 误判：当普通"或相当于"放过。
- 正解：限"3 家以内"实质收窄竞争=排他 → 🔴，招投标法第20条 + 实施条例第32条。

**FS-2 · 业绩三条件叠加**
- 原文：「近 3 年单项合同金额 ≥ 5000 万元，且为省级政务云项目，且用户数 ≥ 100 万。」
- 误判：只看"5000万"觉得正常。
- 正解：金额+甲方类型+规模三条件∩=精准筛极小集合 → 🔴，实施条例第32条 + 87号令第17条。

**FS-3 · 技术参数异常精确值**
- 原文：「处理器主频 3.27GHz，缓存 28.5MB，支持 XX 私有指令集。」
- 误判：当普通技术参数。
- 正解：非标精确值 + 私有指令集=精确指向某型号 → 🔴，招投标法第20条；质疑要求改通用参数+合理区间。

**FS-4 · 主观分畸高且模糊（评标办法）**
- 原文：「技术方案 30 分，由评委根据'先进性、合理性'自主打分，未细化档位。」
- 误判：当正常主观分。
- 正解：占比畸高且无量化档位=自由裁量过大、易定向 → 🟠，87号令第55条（评审标准须细化量化）；质疑要求补档位描述。

**FS-5 · 异常资金门槛（隐性排中小企）**
- 原文：「中标后 7 日内缴纳 500 万履约保证金，预付款 0%，按季度后付。」
- 误判：当普通商务条款（"又没违规"）放过。
- 正解：金额畸高+0 预付+长账期叠加=资金链挤出软排斥 → 🟠（信号 9）；法条方向走两法分轨对应体系 + 中小企业促进法精神；策略侧重联合体/融资/成本止损，不硬质疑。
