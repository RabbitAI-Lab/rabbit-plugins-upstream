# 法条方向表（萝卜坑识别器专用）

本文件是 SKILL.md §2.5 的**法条锚点来源**。与「投标模拟评标·模式 C」的 `compliance-review.md` **同源、对齐**，此处按"量身定制/排他性"场景扩展。

> ⚠️ **时效性**：整理截止 **2026-07**，法规可能修订。每条输出须附核验声明，结论以现行有效法 + IMA 知识库核实为准，重大质疑建议咨询专业律师。本技能**不保证法条最新**。

## 1. 高频法条速查表（内置，硬法条优先引用）

引用时优先从此表取**硬法条**（法律/行政法规/部门规章，带精确条号）；**软依据**（规范性文件/指导意见/行业惯例）仅作辅助，不单独作为质疑支点。

| 违规类型（萝卜坑形态） | 硬法条（精确条号） | 软依据（辅助） |
|---|---|---|
| **品牌/型号排他**（指定品牌、原厂授权、限定家数、特定专利/软著） | 招标投标法第20条（招标文件不得要求或标明特定生产供应者）；招标投标法实施条例第32条（以不合理条件限制排斥的具体情形，含限定品牌/专利） | 财政部涉企违规专项整治要求 |
| **地域/所有制歧视**（本地注册、排斥民企/外资） | 招标投标法第18条（不得以不合理条件限制排斥潜在投标人）；招标投标法实施条例第32条；政府采购法第22条第2款 | 中小企业促进法（扶持例外合法，但非排斥依据） |
| **业绩/资质门槛量身**（多条件叠加、与履约无关、规模错配） | 招标投标法实施条例第32条（限定特定业绩/奖项属不合理条件）；政府采购法实施条例第20条（限定特定业绩属以不合理条件限制排斥）；87号令第17条（不得设与履约无关条件） | — |
| **技术参数量身**（精确值、私有协议、非标参数） | 招标投标法第20条；招标投标法实施条例第32条（限定特定专利/商标/品牌/原产地） | — |
| **评标办法倾向**（主观分畸高无量化、指向性加分） | 政府采购货物和服务招标投标管理办法（87号令第55条：评审标准须细化量化） | 财库〔2007〕2号 |
| **合同条款排他**（付款/验收/管辖异常偏袒） | 民法典合同编基本原则（公平、诚信）；招标投标法第46条（按招标文件订立合同，不得背离实质性内容） | 行业合同示范文本 |
| **商务/资金隐性门槛**（高额保证金、0 预付、特定授信） | 视项目属性走对应体系（政府采购法/招投标法）+ 中小企业促进法精神（扶持中小企业、禁止隐性排斥） | 公平竞争审查制度（软依据） |

> **引用纪律**：硬法条须写全「法/条例/令 + 条号」；软依据只写方向，不伪造文号。两法分轨——政府采购法体系 vs 招标投标法体系口径不同，按项目所属法律体系适用。

## 2. 两法分轨速查

| 项目属性 | 主适用体系 | 关键条款锚点 |
|---|---|---|
| **政府采购（货物/服务/工程）** | 政府采购法 + 实施条例 + 87号令（货物服务）/ 相关工程令 | 政府采购法第22条、实施条例第20条、87号令第17/55条 |
| **工程招投标（依法必须招标）** | 招标投标法 + 实施条例 | 招投标法第18/20条、实施条例第32条 |
| **国企/央企采购（非依法必招）** | 企业内部规章 + 参照上述 + 反垄断/公平竞争审查 | 参照实施条例第32条精神 + 内部合规制度 |

> **⛔ 两法硬隔离（红线）**：政府采购体系**绝对禁止**引用《招标投标法》及《实施条例》作为质疑支点；工程招投标体系**绝对禁止**引用《政府采购法》及 87 号令。跨体系引用是"行业笑柄级"错误，会被招标人直接驳回。用户未明示项目属性时（§2.1 预检已问），两法并列标注，不擅断、不混引。

## 3. 质疑/投诉路径方向（弹药配套）

| 阶段 | 路径方向 | 时效方向（须以现行规定核实） |
|---|---|---|
| 投前澄清 | 向招标人/代理提**澄清要求**（对模糊/疑点条款要求明确） | 通常在招标文件发售/提疑期限内 |
| 投前质疑 | 法定质疑（政府采购）/ 异议（招投标） | 法定时限内（以现行法为准，本技能不给具体天数定论） |
| 投后投诉 | 向财政部门/发改部门投诉 | 质疑/异议答复后法定时限内 |

> **不教唆缠诉**：质疑/投诉须基于真实合法权益，不指导「恶意异议」「程序滥用」。

## 4. 护栏（与 SKILL.md §5 一致）

- 只识别、不捏造：萝卜坑必须基于文件真实条款。
- 法条模糊化、不默写：仅给「法/条例/令 + 条号 + 方向性引用」，禁止 LLM 自行默写具体法条原文（防废止法条/串法幻觉）；以现行有效法 + IMA 知识库核实为准。
- 两法分轨硬隔离：政府采购体系绝不引《招标投标法》；工程招投标绝不引《政府采购法》及 87 号令。
- 时效核验声明：每段弹药须附「发送前请通过全国法律法规数据库核实现行有效性」。
- 风险分级不越权：🔴 是"高度疑似/明显违规可质疑"，非"必然废标"。
