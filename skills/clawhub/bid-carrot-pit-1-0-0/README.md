# 萝卜坑识别器 · 招标文件量身定制扫描

> 投标人侧独立技能（`slug: bid-carrot-pit`）。扫描**整份招标文件全文**，识别为特定供应商"量体裁衣"的排他性/歧视性/不合理门槛条款，输出风险等级 + 法条方向 + 质疑/投诉弹药。

## 与「投标模拟评标」的关系
- **本技能**：看**招标文件全文**里的"坑"（技术参数、合同条款、资格条件等最高危区）。
- **投标模拟评标·模式 C**：只看**评标表一块**的合规审查。
- 两者解耦、可串联：先本技能扫全文找坑 → 再投标模拟评标看我方得分与覆盖。

## 能力边界
| 做 | 不做 |
|---|---|
| 扫描全文 5 大区域、多维信号标尺识别 | 不模拟评委打分、不审计"我方响应"覆盖 |
| 组合推理（多条款叠加指向同一家） | 不对"我方是否废标"下法定结论 |
| 风险分级 + 法条方向 + 质疑弹药 | 不提供规避合规/骗分建议、不教唆缠诉 |

## 快速使用
1. 触发技能（见 SKILL.md §6 触发词）。
2. 按 §2.1 预检清单上传**完整招标文件**。
3. 技能自动分章节（脚本或降级）→ 跑 §3 信号标尺 → 出报告。

## 部署建议
- `references/` 作 Agent 平台 **Knowledge Base** 挂载（省 Token、法规更新只改 KB）。
- 触发即抛 §2.1 预检清单作 Welcome Message。
- 发现某类"伪装坑"仍看不准 → 在 `carrot-pit-signals.md` 追加 Few-Shot。
