## Description:

帮助品牌、MCN、内容运营和创作者研究小红书博主的内容列表、近期发布和互动表现。

This skill is ready for commercial/non-commercial use.

## Use Case:

品牌、MCN、内容运营和创作者可用它获取小红书账号的笔记列表，复盘发布时间和互动信号，分析内容风格并对标创作者。

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: 运行时下载并执行未锁定版本的 npm 包，且该包可使用 SocialDataX API Key。

Mitigation: 使用已审查的固定版本或预装的可信程序；仅在接受其执行风险的环境中提供 SOCIALDATAX_API_KEY。
