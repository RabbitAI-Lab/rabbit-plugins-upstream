## Known Risks and Mitigations: <br>
Risk: The skill requests broad read, write, and command execution authority beyond a narrow database-help role. <br>
Mitigation: Review before installation and grant read, write, or command execution access only for explicit database-related tasks. <br>
Risk: Generated database remediation guidance could affect production data, performance, or availability if applied without review. <br>
Mitigation: Validate recommendations in a non-production environment, keep backups, and have an experienced operator review changes before applying them to production systems. <br>
