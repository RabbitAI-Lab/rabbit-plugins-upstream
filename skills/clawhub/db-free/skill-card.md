## Description:

db-free helps developers and operators identify basic database connection, transaction, query, and data integrity pitfalls and apply practical mitigation guidance.

This skill is ready for commercial/non-commercial use.

## Publisher:

[thcjp](https://clawhub.ai/user/thcjp)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, database practitioners, and automation workflows use this skill to recognize common database usage traps around connection management, transactions, query performance, and data integrity. It is not positioned for database architecture design decisions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill requests broad execution, file, and API authority that is not clearly scoped to its database guidance purpose.

Mitigation: Review the skill before installing and use it only as database advice unless command execution or file edits are explicitly intended.

Risk: The artifact references a generic API_KEY without documenting a concrete external API or transmitted data.

Mitigation: Do not configure a generic API_KEY until the publisher documents the API, data flow, and operational need.

Risk: Database guidance may be incomplete or unsuitable for a specific production environment.

Mitigation: Have a qualified reviewer validate recommendations against the target database, workload, and change-management process before applying them.
