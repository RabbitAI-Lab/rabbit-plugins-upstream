# 🎤 Karaoke Companion

歌詞隨唱伴侶 — 跟著歌詞學唱歌、卡拉 OK 模式、填詞創作、翻譯對照。

## 功能

- 📝 LRCLIB 即時歌詞搜尋
- 🎤 卡拉 OK 播放器（減速 + 逐句 + 反覆）
- ✍️ 填詞創作工具（韻腳表 + 段落模板）
- 🌏 中/英/日 翻譯對照

## 快速開始

```bash
python3 scripts/lyrics_searcher.py search "歌名"
python3 scripts/karaoke_player.py play -t "歌詞文字..."
python3 scripts/lyrics_creator.py guide
python3 scripts/lyrics_translator.py compare -t "I love you"
```
