## Description: <br>
Helps agent users, skill authors, maintainers, and teams produce practical GitHub-style workflow support for bug fixes, setup hardening, reliability work, and adjacent skill creation. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, maintainers, skill authors, and agent users use this skill to turn GitHub-style software and data requests into concrete plans, artifacts, code changes, checklists, verification steps, and decision support. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate for broad software or GitHub-related requests because its trigger wording is broad. <br>
Mitigation: Use explicit invocation for precise routing or narrow the trigger wording before deployment in environments with many overlapping developer workflow skills. <br>
