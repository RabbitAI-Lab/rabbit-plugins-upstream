# IP Character Image System

一个用于 Codex 的 IP 角色形象开发 Skill。

它可以把一个 IP 想法、草图、参考图、品牌概念或吉祥物设定，转化为一整套可用于图像生成的 IP 图片资产方案，包括主形象、三视图、线稿三视图、表情包、动作姿态、手办图、包装图、周边展示图和社媒传播图。

## 适合谁使用

这个 Skill 适合：

- IP 角色设计师
- 品牌设计师
- 插画师
- 文创产品设计者
- AI 视觉创作者
- 需要快速搭建角色视觉体系的策划 / 内容创作者

## 它能做什么

这个 Skill 可以帮助生成：

- IP 角色核心设定
- 视觉锚点与不可改变项
- 主形象生成提示词
- 正视图 / 侧视图 / 后视图三视图提示词
- 黑白线稿三视图提示词
- 表情包提示词
- 动作姿态提示词
- 潮玩手办图提示词
- 盲盒包装图提示词
- 周边和社媒视觉提示词
- 角色一致性检查清单

## 核心工作流

```text
想法输入
→ 角色提炼
→ 视觉锚点
→ 风格规范
→ 资产矩阵
→ 分项 Prompt
→ 一致性检查

案例：蒜鸟 IP：以“蒜鸟”为例。

这是一个由“大蒜 + 小鸟”组合而成的拟人化 IP 角色，整体方向是可爱、潮玩感、轻松幽默，适合用于文创产品、表情包、盲盒手办和社交媒体传播。

角色核心设定

* 名称：蒜鸟 / Garlic Bird
* 原型：大蒜 + 小鸟
* 性格：外表清凉，内心热血，有一点懒散和呆萌
* 风格：泡泡玛特风格、3D 卡通、软胶手办、干净明亮
* 应用：文创、表情包、盲盒、手办、社媒内容、品牌吉祥物

必须保留的视觉特征

* 圆润饱满的大蒜身体
* 顶部蒜瓣或蒜芽结构
* 半眯眼表情
* 黄色小鸟嘴
* 两侧短小翅膀
* 细小鸟腿和黄色鸟爪
* 背面保留大蒜纹理与尾部结构
* 整体比例圆润、可爱、适合手办化


示例 Prompt

1. 主形象 Prompt
基于“蒜鸟”IP角色设定，生成一个泡泡玛特风格的3D卡通角色，软胶手办材质，圆润饱满的大蒜身体，顶部有蒜瓣和淡紫色蒜芽结构，半眯眼表情，黄色小鸟嘴，两侧短小翅膀，细小鸟腿和黄色鸟爪，整体可爱、呆萌、潮玩感，高清产品渲染，柔和棚拍光影，明亮干净色调，纯白背景，保持角色比例和所有标志性特征一致。

2. 三视图 Prompt
生成“蒜鸟”IP角色三视图设计图，正视图、侧视图、后视图横向排列，保持同一角色身份、比例和结构。角色为大蒜与小鸟结合的拟人化形象，圆润大蒜身体，顶部蒜瓣和淡紫色蒜芽，半眯眼，黄色小鸟嘴，短小翅膀，细小鸟腿和黄色鸟爪。后视图需要展示完整的大蒜背部纹理和身体轮廓。纯白背景，干净现代角色设定图风格。

3. 线稿三视图 Prompt
基于“蒜鸟”IP角色生成黑白线稿三视图，包含正视图、侧视图、后视图，横向排列。只保留清晰轮廓线和必要结构线，不使用颜色，不使用复杂阴影。保留圆润大蒜身体、顶部蒜瓣结构、半眯眼、小鸟嘴、短翅膀、细腿、鸟爪和背部纹理，适合作为角色设定图和建模参考。

4. 表情包 Prompt
生成“蒜鸟”IP角色表情包九宫格，保持同一角色身份、比例、颜色分区和五官结构。九种表情分别为：开心、疑惑、生气、委屈、震惊、害羞、困倦、得意、加油。角色保持圆润大蒜身体、顶部蒜瓣结构、黄色小鸟嘴、短小翅膀和细小鸟腿。表情夸张但不改变角色基本结构，适合聊天表情包使用，纯白或浅色背景。

5. 包装展示 Prompt
生成“蒜鸟”IP潮玩盲盒包装展示图，画面包含蒜鸟软胶手办和对应包装盒。包装盒采用干净现代、可爱潮玩风格，盒面展示蒜鸟主形象、角色名称“蒜鸟 / Garlic Bird”、浅色背景和简洁图形元素。整体为高清产品摄影风格，柔和棚拍光影，适合展示IP商品化和文创产品开发。
设计原则

这个 Skill 的重点不是生成一张漂亮图片，而是建立一套稳定、可复用、可迭代的 IP 角色形象生产流程。

核心原则：

* 一致性优先于单张图惊艳感
* 先定义角色，再生成图片
* 先锁定视觉锚点，再扩展资产
* 每一类图片都单独生成 Prompt
* 用检查清单控制角色不跑偏
