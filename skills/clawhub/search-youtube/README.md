# search-youtube

A lightweight Brave browser skill for **YouTube**.

## What it does

Search YouTube for videos matching the user's query.

- Reuses an existing relevant tab/session
- Avoids unnecessary duplicate tabs
- Verifies the destination
- Never handles credentials

## Example triggers

- Search YouTube for Blender tutorials
- Find videos about Android pentesting
