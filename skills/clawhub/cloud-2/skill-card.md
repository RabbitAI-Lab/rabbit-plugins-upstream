## Description:

Guides users through choosing, organizing, syncing, sharing, cleaning up, and backing up personal files across consumer cloud storage services such as iCloud, Google Drive, OneDrive, and Dropbox.

This skill is ready for commercial/non-commercial use.

## Publisher:

[thcjp](https://clawhub.ai/user/thcjp)

MIT-0

## Use Case:

External users and support agents use this skill to answer consumer cloud storage questions, compare services, troubleshoot sync or storage issues, and plan file sharing or backups.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad file or cloud-related requests.

Mitigation: Confirm the request is about consumer cloud storage before applying its recommendations.

Risk: Sharing, cleanup, cancellation, or backup advice can affect access to personal or sensitive documents.

Mitigation: Review recommendations before acting, verify service-specific behavior, and avoid storing sensitive documents unencrypted in cloud services.
