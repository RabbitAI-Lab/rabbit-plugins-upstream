## Description: <br>
Build and run grounded business agents on agent4.io over MCP - agents, knowledge bases, load-on-demand skills, stateful Storylines and page playbooks. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and operators use this skill to configure and manage agent4.io business agents, knowledge bases, Storylines, page playbooks, and related MCP-backed workflows from an agent environment. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill sends selected business content, knowledge-base material, configurations, and queries to the agent4.io tenant. <br>
Mitigation: Use it only when agent4.io remote processing fits the user's data handling requirements, and avoid uploading sensitive material unless those requirements allow it. <br>
Risk: The skill requires an agent4.io tenant API key for remote access. <br>
Mitigation: Use a dedicated tenant API key and handle it as a secret. <br>
Risk: Published or shared agents can become reachable by end users. <br>
Mitigation: Review publish and share actions before making agents available. <br>
