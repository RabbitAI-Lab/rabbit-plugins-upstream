## 一、产品概述

**产品名称**：P的事
**定位**：轻量级个人/小团队待办管理桌面工具
**平台**：Windows 桌面
**技术栈**：Java 25 LTS + JavaFX 26 + SQLite（详见 §6.1）
**设计原则**：零学习成本、原生性能、离线优先、无广告、全本地运行

## 二、核心功能

### 2.1 待办管理
- **新建待办**：点击顶栏"+ 新建"或按 Ctrl+N（弹窗填写标题/描述/负责人/优先级/截止日期）
- **编辑待办**：双击任务弹出详情弹窗，可编辑全部字段（标题、描述、状态、优先级、负责人、截止日期）
- **完成待办**：勾选复选框或按 Enter 切换完成状态
- **删除待办**：选中后按 Delete 键或详情弹窗内删除（有确认提示）
- **认领任务**：任务行右侧"认领"按钮，选择或创建身份；已认领显示认领人姓名
- **评论**：详情弹窗内可查看/发表评论
- 注：自然语言日期解析（NaturalDateParser）代码已存在但**当前未启用**，新建弹窗为年/月/日下拉选择

### 2.2 颜色系统（自动分配）
系统根据待办状态和截止时间自动计算颜色标签（`ColorTagService`），用户无需手动设置：

| 颜色 | 含义 | 说明 |
|------|------|------|
| 绿色 #10B981 | 当前需要完成 | 进行中 |
| 蓝色系（7级） | 未开始的待办 | 越蓝越不急，蓝绿=下一个待办 |
| 黄色系（7级） | 主动延后的待办 | 越黄延后越严重 |
| 红色系（7级） | 已超时未完成 | 棕色=刚超时，大红=超时最严重 |
| 灰色 #9CA3AF | 已完成/已取消 | — |

### 2.3 迷你小窗
- 一行横排小窗口，始终置顶、无标题栏、不在任务栏显示（Swing JFrame + JFXPanel）
- 显示当前待办标题、截止时间倒计时、颜色块、完成勾选
- "▼ 列表"展开全部待办（按紧急度排序）、"主界面"打开主窗口（小窗关闭）、"—"隐藏
- 窗口可拖动；显示已认领且未完成的待办

### 2.4 主界面布局
- **顶栏**：应用标题、搜索框（回车过滤）、小窗按钮、新建按钮
- **左侧导航**：工作台、我的任务（含统计子菜单筛选：全部/进行中/待办/逾期/完成）、日历、统计、设置、关于
- **主内容区**：列表/看板切换；各视图在 contentPane 中切换
- **底栏**：状态信息（就绪/当前任务/搜索结果）、统计（总数/完成/超时）

### 2.5 视图系统
- **列表视图**：任务行 = 颜色块 + 完成勾选 + 标题 + 状态标签 + 优先级标签 + 认领 + 截止日期 + 倒计时
- **看板视图**：4 列（进行中/待办/逾期/已完成），卡片式，点击卡片打开详情
- **日历视图**：月视图（周一起始），格子显示公历+农历/节日+待办数，下方显示选中日待办列表
- **统计面板**：总任务、进行中、超时、已完成 4 张统计卡片
- **工作台**：统计卡片 + 今日到期列表 + 最近任务
- **关于页**：内联文本页（使用方法/Agent API/权限/已知问题/开发进度/许可证/制作人）

### 2.6 搜索功能
- Ctrl+K 打开全局搜索弹窗；输入即搜；匹配标题和描述；点击结果定位

### 2.7 通知与提醒
- 系统提示音（完成/警告/错误/通知/提醒），支持自定义音效文件（设置页）
- 提醒调度器每 30 秒检查，到期弹出提醒弹窗（标题+截止时间）

### 2.8 设置页面
- **语言切换**：9 种语言下拉即时切换（见 §7）
- **团队成员管理**：输入框 + 「更新」（把选中成员改名为输入内容）/「新增」（添加新成员）/「删除选中成员」；输入为空时「更新」禁用；输入最长 20 字符
- **通知音效**：选择自定义音频文件、测试
- **数据导出**：JSON / CSV（表头跟随界面语言）
- **API 服务**：监听端口修改（默认 9527，需重启生效）
- 数据库路径显示

### 2.9 系统托盘
- 托盘图标（icon.png）；双击打开主界面；右键菜单：小窗/打开/退出
- 关闭窗口默认隐藏到托盘；托盘菜单语言跟随切换

### 2.10 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+N | 新建待办 |
| Ctrl+K | 全局搜索 |
| Ctrl+M | 切换小窗/主界面 |
| Enter | 完成/取消完成选中待办 |
| Delete | 删除选中待办 |
| ↑ / ↓ | 上下选择待办 |
| Esc | 关闭弹窗 |

### 2.11 REST API（智能体调用）
内置 HTTP 服务监听 `127.0.0.1:9527`（可在设置页修改），支持健康检查、任务/用户/评论的增删改查、统计、搜索，以及设置与导出：
- **任务**：GET/POST `/api/todos`、GET/PUT/DELETE `/api/todos/{id}`、POST `/api/todos/{id}/complete`
- **评论**：GET/POST `/api/todos/{id}/comments`、DELETE `/api/comments/{id}`
- **成员**：GET/POST `/api/users`、PUT/DELETE `/api/users/{id}`（更新改名/删除）
- **统计/搜索**：GET `/api/stats`、GET `/api/search?q=keyword`
- **设置**：GET/POST `/api/settings/sound`（获取/设置音效路径）、GET/POST `/api/settings/language`（获取/切换语言，界面实时生效）
- **导出**：POST `/api/export`（body: `{"format":"json"|"csv","path":"可选"}`）

接口详见 `SKILL.md`。错误消息跟随当前界面语言。

## 七、多语言（i18n）操作手册 ⭐

> 改任何界面文字前必读本节。核心：**所有用户可见文字必须来自 `i18n/texts_*.properties`，且 9 个语言文件同步维护。**

### 7.1 文件位置
```
src/main/resources/i18n/texts_zh.properties      简体中文（基准，缺词回退到这里）
src/main/resources/i18n/texts_zh_tw.properties   繁體中文
src/main/resources/i18n/texts_en.properties      English
src/main/resources/i18n/texts_ja.properties      日本語
src/main/resources/i18n/texts_ko.properties      조선어（朝鲜语，用词偏平壤文化语）
src/main/resources/i18n/texts_fr.properties      Français
src/main/resources/i18n/texts_de.properties      Deutsch
src/main/resources/i18n/texts_es.properties      Español
src/main/resources/i18n/texts_pt.properties      Português
```
格式：`key=文本` 每行一条，`#` 开头为注释分组。**文件必须 UTF-8 编码**。当前共 344 个 key。

### 7.2 核心机制（I18n.java）
`src/main/java/com/teamtodo/util/I18n.java` 提供 5 个 API：

| API | 用法 | 说明 |
|---|---|---|
| `I18n.t("key")` | 即时取值 | 每次调用读当前语言；用于临时文本、弹窗标题、拼接 |
| `I18n.t("key", 参数)` | 带格式化 | `%d`/`%s` 占位，如 `I18n.t("kanban.overdue", 3)` |
| `I18n.text("key")` | 绑定属性 | 返回 StringProperty，语言切换自动更新：`label.textProperty().bind(I18n.text("key"))` |
| `I18n.textf("key", 参数)` | 绑定+格式化 | 同上，带参数 |
| `I18n.onLangChange(监听)` | 注册监听 | 语言切换回调，用于刷新 setText 型文字/重建视图 |

切换语言流程：`I18n.setLang("en")` → 重新加载 properties → 刷新所有绑定 → 通知所有监听器。
语言代码与自名表：`I18n.LANGS` / `I18n.LANG_NAMES`（**ko 显示为 조선어**）。

### 7.3 三种文字更新模式（按控件类型选择）
1. **FXML 控件**：FXML 里写的中文只是初始显示值，必须由 controller 在初始化时绑定覆盖。各 controller 的绑定方法：
   - `MainController.updateAllTexts()`（顶栏/侧栏/按钮 + 清缓存重建所有视图）
   - `SettingsController.updateSettingsTexts()` / `TodoDetailController.updateDetailTexts()` / `MiniFrameController.updateMiniTexts()` / `TodoListController.updateTexts()`
   - 新加 FXML 控件：加 `fx:id` → controller 加字段 → 上述方法里 `bind(I18n.text("key"))`
2. **纯代码控件**（看板/日历/统计/工作台/弹窗）：创建时 `I18n.t("key")` 即可；语言切换后仍存活的视图由 MainController 置 null 重建。
3. **动态文字**（按钮随数据变化，如"标记完成/取消完成"、"共 N 名成员"）：状态变化处用 `I18n.t()` 重设；语言切换时在监听器里按当前数据重设。

### 7.4 如何修改文字
改某处显示文字：找到 key → 修改 **9 个文件**对应行。例：把"工作台"改为"工作台首页"：
```
texts_zh.properties:    nav.workbench=📊 工作台首页
texts_zh_tw.properties: nav.workbench=📊 工作台首頁
texts_en.properties:    nav.workbench=📊 Workbench Home
...（其余 6 个语言同理）
```

### 7.5 如何新增文字
1. `texts_zh.properties` 合适分组下加 `新key=中文文本`。
2. **其余 8 个语言文件必须同步加**（漏加会回退显示中文——历史大坑：曾缺 200+ key 导致切语言后大量界面显示中文）。
3. 代码引用：绑定 `I18n.text("新key")`，即时 `I18n.t("新key")`。
4. 运行 `python -X utf8 tools/check_i18n.py` 校验（key 齐全 + `%d/%s` 格式符一致）。

### 7.6 如何新增一种语言
1. `I18n.java` 的 `LANGS` 加代码、`LANG_NAMES` 加自名（如 `"ru", "Русский"`）。
2. 新建 `texts_ru.properties`，以 zh 为基准逐行翻译全部 key。
3. 设置页下拉框自动出现新语言（SettingsController 遍历 LANGS）。

### 7.7 特殊规则
- **枚举标签**（状态/优先级）：`TodoStatus`/`TodoPriority` 构造函数**必须传 key 字符串常量**（如 `"status.pending"`），不能传 `I18n.t(...)` 求值结果——否则类加载固化成中文，切语言永不生效（历史教训）。
- **农历/节日**：`LunarCalendarUtil` zh 简体、zh_tw 繁体、其他语言返回 null（不显示）；日历控件已做 null 保护。
- **CSV 导出表头 / API 错误消息**：已 i18n（key 前缀 `csv.*` / `api.*`）。
- **日志与注释里的中文**：诊断信息，不面向界面，保持中文，无需 i18n。

## 九、常见坑（历史教训，务必看）

1. **compile.ps1 中文路径乱码**：PowerShell 5.1 按 GBK 读无 BOM 的 UTF-8 脚本，中文路径参数会乱码失败。→ 直接用 §6.2 方式在项目目录执行 mvn。
2. **Properties 文件必须 UTF-8**：I18n 用 `InputStreamReader(UTF_8)` 读取；保存时确认编码。
3. **GBK 控制台显示乱码 ≠ 数据错误**：PowerShell 输出韩文/法语重音字符显示 `?` 是控制台编码问题，用 `python -X utf8` 或 IDE 确认。
4. **绑定与 setText 冲突**：`textProperty().bind(...)` 后不能再 `setText(...)`（抛异常）。动态值控件（如带计数的筛选按钮）用 unbind + setText 或 `I18n.t()`。
5. **模态弹窗**（新建/搜索/快捷键帮助）：打开期间无法切语言，创建时 `I18n.t()` 取一次即可。
6. **I18n.text() 是弱引用绑定**：控件解绑后自动回收；不要持有 property 而不 bind。
7. **不要删 `target/P-Todo-1.0.0.jar`**：当前可运行版本；target 下其他产物（dist/original jar 等）可再生，可随时清理。
8. **旧版遗留**：`todo-list.fxml`/`TodoListController`/`NaturalDateParser` 未引用，改动时别误以为生效。
9. **改完代码必须重新打包重启**：`mvn -q -DskipTests package` → taskkill 旧进程 → java -jar 新 jar。
10. **跨线程 runLater 要二次 null 检查**：小窗的 hide/destroy 等用 `Platform.runLater` 延迟执行，排队期间实例可能已被置空（如 destroy 后 hide 才执行）→ lambda 内必须再检查 `instance == null` 直接 return，否则 NPE。
