# 75㎡旧房改造不要沙发，一人住也得稳稳的幸福

因为是过去的老旧结构，这么大面积只有一室户型，不过女主一个人住，这样还可以让公共空间更宽敞。

▲不算破旧，毕竟二手。这是新主人的评价，所以推倒重新来过。

▲这是原始的图纸，进门左手是很小的厨房，直对就是客餐厅全景一直到阳台空间；一间卧室带一个很小的卫生间。卧室毕竟一个人住倒是无所谓，但是需要满足更多收纳，就有点紧张；卫生间没有干湿分离也是最不满意的地方；最不能忍受的就是厨房，太小，虽然一个人住平时做饭很少，但是小到憋屈。
▲重新设计后的布局；打掉厨房做开放式，这是大部分年轻人的梦想，轮到自己做主直接让它成真；
进门右手定制鞋柜，同时与冰箱刚好完美契合；一个人住不需要传统的客厅，但是需要大量的藏书空间；所以把原有的卧室与客厅墙体彻底砸掉，利用空间做了双面柜，既满足卧室衣物的收纳，同时又满足客厅大量书籍的放置；利用双面柜的位置还实现了干湿分离的布局，完美。
▲利用进门右手定制白色鞋柜，满足进门的基本收纳，同时成就一个换鞋凳，挂衣以及坐着换鞋方便舒适
▲砸掉厨房融进门厅空间，让进门就豁然开朗；因为不喜欢木地板的质感，所以通铺木纹瓷砖，门厅以及厨房地面采用局部六边形瓷砖点缀，时尚而且有高级感
▲好不容易打开的空间怎么能让压抑呢，所以经典的小白砖铺贴，白色的U型定制橱柜，灰色的石英石台面，白色的烟机搭配，清爽干净才是最好的搭配
▲U型延伸，增加一个复古小吊灯，满足一个休闲吧台的地方，满足一下年轻人的小资心里
▲转过来看客厅，比较惊艳了，舍弃了传统的布局，采用两边收纳柜，满足女主无穷无尽的图书，同时新砌隔墙利用休闲阳台以及客厅局部，满足了会客的宽敞地方
▲木质的长条形书桌布局，既满足办公又能兼顾聚会就餐，顶部采用水泥漆涂刷，搭配黑色的滑轨灯，有轻工业风的质感
▲两米长的书桌，一边的长条木凳，一边两把木质的单椅，不论是视觉还是功能，都能舒适；原有沙发墙以及电视墙全部收纳柜定制，满足书籍的收纳；一边局部留白是为了安置猫爬架
▲另一边局部书柜和地柜搭配，视觉留白，同时满足了猫爬架的布局
▲另一边顶天立地的书柜，开放式布局，满足随手拿取的方便，不仅仅满足了功能，同时也是一面书墙的装饰
▲居中书桌的布局，让四周动线更合理，让小空间也有了大宅的既视感
▲半截墙分割区域，两人位舒适沙发面朝阳台，这边作为会客休闲采光独好
▲利用阳台与客厅的大梁位置还打造了酒柜区域，阳台遮光帘的布局，为了满足偶尔娱乐需求，隐藏幕布完美实现会客区的娱乐功能
▲唯一的卧室同样延续木纹瓷砖通铺，素雅的黑白灰色调；床尾以及侧墙同时打造顶天立地的衣柜，满足女主的所有衣物的收纳
▲灰色背景搭配胡桃木的床头，两边白色壁灯营造氛围；沉稳简洁
▲侧墙的另一组镶嵌衣柜，与床尾衣柜共同满足衣帽间的容量
▲利用卧室与客厅双面柜的空间，实现了干湿分离的品质生活
▲湿区延续厨房的风格搭配，小白砖与六边形对比质感；墙排马桶更好打理，玻璃隔断分区布局
