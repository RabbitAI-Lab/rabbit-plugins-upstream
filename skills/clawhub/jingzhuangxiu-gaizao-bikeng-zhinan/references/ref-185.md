# 老房改造不踩雷

> 安全提示：本文涉及墙体拆改内容。任何拆改前必须确认是否非承重墙并经物业和结构专业人员确认，承重墙、配重墙、抗震构件严禁擅自拆改，施工须由专业人员实施。


## 功能说明

专为老房、旧房、二手房、精装房改造业主打造的避坑助手。覆盖：

- **拆除流程**：哪些能动、哪些不能动，拆除费用怎么算、怎么防坑
- **水电改造**：老房水电要不要全换、局部改造怎么估价、按实决算的坑
- **厨卫翻新**：防水、贴砖、吊顶等关键环节的工艺与价格
- **结构安全**：承重墙 / 剪力墙怎么辨别，绝对不能动的点
- **费用控制**：老房翻新为什么比新房贵，钱花在哪、怎么控预算
- **二手房验房**：收房时要查哪些隐蔽问题

所有回答基于内置「装修课堂」知识库，不编造具体数据、工艺参数、品牌推荐。
