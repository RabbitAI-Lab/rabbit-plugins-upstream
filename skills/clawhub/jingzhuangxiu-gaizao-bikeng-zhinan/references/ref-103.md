# 35㎡挑空LOFT，二手旧房极简改造成两人婚房

购买的是二手挑空公寓，原来的基础都基本比较新，所以为了节省更多费用，没有全部拆除重新做，而是局部改动，最经济的做法满足入住
▲原始的样子，本身是挑空空间，进门右手原来就定制了鞋柜，进门左手是卫生间，过道进去就是一个开间，原来房东搭建了少部分，上头满足了卧室功能，旋转楼梯是原来做好的。卧室下方刚好就是开放式厨房。
▲原来的样子几乎没有做改动，更换了洁具，定制了一些收纳柜而已；上头卧室因为层高太低，没有床，直接席地而睡；客厅太小也不要沙发了，摆个大餐桌兼顾就餐和办公即可

▲原来入户的样子，枣红色防盗门太难看，过道地面脏兮兮感觉非常昏暗
▲改变以后的样子，重新修补吊顶，更换了比较明亮简洁的筒灯；入户门采用毛毡做了装饰；地面购买的灰色地毯盖住了昏暗的瓷砖；原来的木地板没有动，基本没有损坏；鞋柜还是保留了原来的样子，只不过给原来的镂空处引了电源安置了感应灯条，回家就会自动亮起，温馨好多
▲原来鞋柜保留，增加了感应灯条，摆上好看的玩偶装饰一下；利用鞋柜旁边的柱子，简易的挂钩，满足了进门包包衣服的悬挂，颜值也好看
▲因为有在家办公的需求，过道进来的墙面摆放了书柜布局，同时兼顾了进门的展示功能
▲过道进来以后开间原来的样子，墙面有点脏，木地板完好无损，灯带颜色难看可以更换；原来房东因为上方层高限制，床具摆在客厅，显得拥挤不堪
▲新刷墙，更换灯具以后，亮堂了好多，摆放了收纳柜，让空间满足基本收纳
▲旋转楼梯还是原来的样子，楼梯对面过道成品的矮柜布局，灰色与蓝红色搭配，可以让大面积大白墙更有活力
▲全景空间，旋转楼梯居中，刚好满足上头的卧室空间，楼梯的内侧刚好布局开放式厨房；客厅空间没有放沙发，而是采用餐桌代替，兼顾就餐和办公；同时靠边单独布局一张书桌，平时两人同时办公也可以满足
▲虽然简陋，但是小日子过得很甜蜜
▲旋转楼梯居中布局，节省空间，同时满足上方休息以及下方的厨房空间
▲原来厨房的样子，一切都是现成的，为了省钱不想拆除，但是这个颜色实在太突兀
▲没有改变原有的摆设，网购贴画把冰箱装饰一下；网购木纹贴纸把橱柜改变了颜色，立马看起来顺眼多了
▲全景空间，大书桌代替沙发的功能，同时满足了在家办公和餐厅功能；两人居住的生活简单而且惬意
▲白色的餐桌，搭配了两把黄色的舒适单椅，视觉活泼许多；靠墙另外布局一张书桌，兼顾书桌和女主的化妆台，角落绿植点缀，温馨干净
▲铁艺的极简挂钟非常完美的装饰，抱枕网购看起来更温馨
▲收纳柜来自宜家，非常实用
▲楼上空间，因为层高限制，无法布局床，直接席地而卧；放置了小的茶几，两个座椅，平时可以办公，也可以喝茶聊天
▲极简落地灯照明，层高比较低，席地而卧，直接铺上就可以当卧室使用
