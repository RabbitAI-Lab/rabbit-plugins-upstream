## Description: <br>
Generates professional PowerPoint presentations from a requested topic, industry, style, language, and optional template. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External users and developers use this skill to turn a presentation topic or brief into a structured, visually designed PPT deck, including outline, slide content, color direction, and generation steps. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may use web searches to fill sparse presentation topics, which can introduce inaccurate, stale, or unsuitable source material. <br>
Mitigation: Provide source content directly for high-stakes or confidential decks, and review generated facts, data, and examples before use. <br>
Risk: The skill may install presentation-related dependencies before generating or previewing files. <br>
Mitigation: Run it in a controlled environment and approve dependency installation only when the packages and commands are acceptable. <br>
Risk: The skill writes PPT and preview files locally. <br>
Mitigation: Choose an appropriate private output directory for sensitive business, medical, financial, or personal material. <br>
