# 变更记录

### 0.1.0 — 2026-11-13（新建：应收应付票据的逐条挂源）

首版。票据这一族在我方 57 枚在架件里原本是零覆盖（现读 `grep -rn '应收票据\|应付票据\|贴现\|终止确认' cue-awesome/*/SKILL.md` → 0 命中），本件补的就是这个洞。

**一、四块内容**

1. **票据分类**：银行承兑／商业承兑，应收与应付各一行起头；
2. **期末余额与坏账准备**：余额、坏账准备、计提比例；
3. **已背书与已贴现**：按承兑类型分列，终止确认那一格单独占行；
4. **到期托收与拒付**：托收金额与拒付记录各占一行，没披露就写未取到。

**二、五道机检（`scripts/check_notes.py`，零网络）**

`NR-STRUCT` 形制／`NR-QUOTE` 原句与锚／`NR-NOSELF` 不得自推自算／`NR-GAP` 未取到两向点名／`NR-LINE` 红线。`--selftest` 13 档（好样零发条、五道各一支坏样、七支反证样），`--demo` 零输入出样例。

**三、本件特有的两条判据（相对同族件新增，不是抄来的）**

- **分类只认原句**：行内写「银行承兑／商业承兑」，该词必须在同一行的原句里也出现。判域刻意剥掉**项名**——「应付票据·商业承兑」这种项名是在标登记对象，不是在替披露分类，把它算进自推会冤枉正确写法；「未取到」行整行豁免，那正是「原句没分类所以照实写没取到」的正确形态。
- **终止确认只认原句**：同理，「已背书」≠「已终止确认」。这条不能靠词表兜，因为它判的不是禁词而是**证据来源**。

**四、边界（写进 SKILL 与 README，两处一致）**

- `cn-working-capital-quality` 管存货／应收账款／合同资产的余额与账龄，**票据是独立科目，不进那一枚**；
- `cn-cash-flow-quality` 管三张现金流，本件只在口径节给一句指向、不重算；
- `related-party-terms-cn` 管关联方资金占用，本件不碰。

**六、三处口径修正（第一版自己踩的，记在明处）**

1. **红线洗引文要在切分句之前**：先按行洗掉「」再切分句。反过来的话，引文里的逗号会在切分处断成两截，逐句洗就洗不干净——「公司称承兑人信用良好，未发生拒付」这类照抄原文会被误判成本件断言，正是反证样 `OK_QUOTED_REDLINE` 盯着的那一格。
2. **未取到两向对账的取键要认两种写法**：正文写 `- 项名 未取到：原因`（项名在**前**），第五节写 `- 未取到：项名`（项名在**后**）。一律取「未取到」后面那段，正文标准形会取到**原因**而不是项名，两向必然对不上——判出来的是假红，不是真缺。
3. **越界判据只判前四节**：第五节「口径与未取到」正是写明与另几枚件分界的地方，在那里点名 `cn-working-capital-quality`／`cn-cash-flow-quality` 是本件要求的动作，不是越界。第一版把它算进判域，好样自己就红了一条。

**七、runner 的两条实话**（都在这枚件上现试出来过，写进脚本头注释防下一趟重新踩）

- 码集必须从机检**自己的输出**里取（`  NR-XXX L12 …` 的行首码），不另跑一份统计——取的是「这枚稿实际发了哪几道」，不是「我以为它发了哪几道」。
- 判「节在不在」那道认的是**多出同名节**与**不认识节名**；改标题会让整节变 stray、节内发现行一并丢，连带别的注入测不到。所以结构注入插的是重复节标题，正文一条不丢。
