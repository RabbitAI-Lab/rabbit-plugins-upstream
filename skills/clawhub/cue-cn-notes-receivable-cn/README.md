# 应收应付票据·逐条挂源

给一份财报，把**票据**这一族科目读成一张**每个数都能回到原句**的登记表：票据分类（银行承兑／商业承兑）、期末余额与坏账准备、已背书与已贴现未到期、终止确认与否、到期托收与拒付。

票据是资产负债表上一块独立的科目：它既不像应收账款那样按账龄提坏账，也不像货币资金那样随时可用。**一张票据能不能算数，取决于它是什么类型、有没有出表、到期有没有收回**——这三件事本件逐条登记，结论留给人。

**不判票据真伪、不判承兑人信用、不预测兑付风险、不给评级与目标价、不代算贴现金额。** 分类与终止确认只认原句；要自己算的贴现利息，必须单列并交代利率、期间、天数口径。

## 一、三十秒跑通（零输入）

不给任何数据文件，也能跑出一份完整合规的成品，看它长什么样、判据怎么打：

```bash
python3 scripts/check_notes.py --demo
```

把这份样例存下来再跑一遍机检，它能自己过：

```bash
python3 scripts/check_notes.py --demo > 样例票据稿.md
python3 scripts/check_notes.py 样例票据稿.md
# → 样例票据稿.md 结论：五道全过（零发条）
```

接着换成你自己那份稿子：

```bash
python3 scripts/check_notes.py 你的票据稿.md
```

退码 `0` 全过、`1` 有发条、`2` 用法错、`3` 读不到文件或空稿。

### 拿不到成品时，从原文开始的三步

1. **定主体与报告期**，拿到年报或半年报原文（附注五「应收票据」「应付票据」两处，加现金流量表补充资料）。
2. **每节抄事实，连原句一起抄**：一条 = 一行，行末挂 `「原句」〔锚：页/表〕[S#]`。
3. **跑一遍自检**，红一条改一条：

```bash
python3 scripts/check_notes.py --selftest      # 13 条内置夹具自检
```

### 先确认通道在场（可选）

配了 `CUE_API_KEY` 才需要这一步。先列目录，再按目录里的路由地址确认工具在场：

```bash
CATALOG="https://cuecue.cn/api/mcp-catalog"
curl -s "$CATALOG" | head -c 2000
# 从目录里取本组的路由地址，确认工具在场
curl -s -X POST "$ROUTING_URL" \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

没配凭据也能用：把财报放进工作区，走用户直供那条路，代价是附注里的背书明细与坏账准备明细只能在手头文件里翻。

## 二、五道机检在管什么

| 码 | 名称 | 判什么 | 最常拦住的情况 |
|---|---|---|---|
| `NR-STRUCT` | 形制 | 头部四件自标、`主体：`、`报告期：` 在场；六节齐且有序；前四节各至少一条发现行 | 六节缺一节；某节只有小标题；多出一节同名标题 |
| `NR-QUOTE` | 原句与锚 | 每条发现行以「」原句＋〔锚：…〕＋`[S#]` 收尾；来源行带可点 URL 与检索日；引用的编号须已登记 | 只写数字没抄原句；来源行只有标题没有链接 |
| `NR-NOSELF` | 不得自推自算 | 分类与终止确认只认原句；比例原句没写必须标 `〔自算〕` 并写明分子分母；贴现利息自算须写利率／期间／天数口径 | 原句只写「应收票据」，本件自己写「商业承兑」；贴现息只乘出个数就报 |
| `NR-GAP` | 未取到两向点名 | 正文写了未取到而第五节没列要发，反之也发；零缺口须显式写「未取到：无」 | 用「不适用」「无此项」「无需披露」搪塞 |
| `NR-LINE` | 红线 | 真伪、承兑人信用、兑付风险、评级目标价零命中；引文先洗掉再判；保证金＝货币资金照发 | 「承兑人信用良好，兑付风险低」 |

## 三、四条红线（这件的立身之本）

1. **分类只认原句。** 附注只写「应收票据」不分类时，正确做法是写未取到，不是按出票人名称或票面习惯自推——同一个出票人既可能开银承也可能开商承。
2. **终止确认只认原句。** 「已背书」不等于「已终止确认」，「未到期」不等于「未出表」；这一步是会计判断，由披露做，不由本件做。
3. **贴现利息不代算。** 原句给了就照抄；要自己算的必须标 `〔自算〕`，并在同一行写明利率取哪一句、期间取哪一句、按 360 还是 365 天折算——三项缺一即发。
4. **票据保证金 ≠ 货币资金。** 保证金是受限资金（保证金账户与基本户都不同），不许写成相等或互相印证。

## 四、一条发现长什么样

```markdown
- 应收票据·银行承兑 8,600.00 万元「应收票据—银行承兑票据 86,000,000.00 元」〔锚：2025 年年报·第 96 页·附注五·应收票据〕[S1]
```

没取到的，自成一行、照实写：

```markdown
- 应付票据·商业承兑 未取到：附注只按银行承兑列示
```

要自己算的，长这样（分子分母各自挂源）：

```markdown
- 坏账准备计提比例为 1.50%〔自算〕分子＝坏账准备 1,500,000.00 元 [S1]｜分母＝应收票据期末余额 100,000,000.00 元 [S1]
```

## 五、和另外几枚包怎么分

| 你手上是 | 用哪枚 |
|---|---|
| 应收票据、应付票据、背书、贴现、终止确认、托收拒付 | **本件** |
| 存货、应收账款、合同资产的余额与账龄 | `cn-working-capital-quality` |
| 三张现金流量表、净现比、收现比、自由现金流 | `cn-cash-flow-quality` |
| 关联方资金占用、担保 | `related-party-terms-cn` |

票据保证金、贴现收到的现金在现金流量表里，**本件只在口径节给一句指向、不重算**——那一块归 `cn-cash-flow-quality`。

## 六、素材从哪来

- **用户直供**：手头的年报 PDF、公告，走解析通道读成能检索的正文。
- **通道取证**：配了 `CUE_API_KEY` 后可走财报检索与原文解析。装好 skill ≠ 已配凭据 ≠ 通道已连，三层分开看。
- **附注常在几百页的 PDF 里**（分类表、背书明细表、坏账准备表），长附件与扫描件交给解析腿：先取大纲，再按节取用。计费与可用性以服务端返回为准。

本件不发请求、不代付费，消耗以服务端返回为准。

## 七、跑夹具与测试

```bash
bash scripts/fixtures/run_fixtures.sh
python3 tests/test_notes.py
```

三档：机检自测 / 好样坏样逐枚单跑 / 在好样上逐处替换做正反对照（该红的红、该不红的不红）。零网络、零计费，产物只落临时目录，跑完即删。

末行自报「档数=3｜不合=N｜不可判=N」；退码 `0` 全过、`1` 有不合、`3` 取值域故障。

`tests/` 跑的是外壳属性——`--help` 退 0、无参退 2、缺文件或空稿退 3、`--demo` 产物自过机检且与好样夹具同源、埋点落盘且失败静默。

## 八、首次运行埋点

入口脚本解析参数成功后、干正事之前，会往 `~/.cue-usage/<slug>-<日期>` 落一枚**空文件**。

**为什么要它：** 平台的两个下载计数器都不可信——新 listing 上架首 48 小时会被一次性播种 50~60 的初始计数，那不是用户下载。本地这枚文件是本件唯一能证明「真有人装上并跑过」的证据。

**它不会碍事：** 任何失败（家目录只读、配额满、无 HOME）都静默跳过，不报错、不改退码、不吐一句杂音。同一天跑多次只留一枚。

要清掉：`rm -rf ~/.cue-usage`。
