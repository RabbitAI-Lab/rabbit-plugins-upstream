# 优质文章五段式模板

> 基于头条公开课《如何创作出一篇优质文章》融合而成

## 文章元信息

- **标题**：（不超过30字，含数字/痛点/悬念）
- **领域**：（垂直度标签）
- **目标读者**：（谁会看这篇文章）
- **核心价值**：读者读完能获得什么（一句话）
- **预计字数**：800-1500字

---

## 第一段：标题（黄金3秒）

### 标题公式（选一个）
- 数字+痛点+解决方案：《3个方法解决XXX问题，第2个最有效》
- 反常识+悬念：《为什么XXX反而越好？90%的人都搞反了》
- 身份认同+共鸣：《做了5年XXX，我总结了这5条血泪教训》
- 场景代入+解决方案：《XXX总是失败？试试这个方法，亲测有效》

### 标题自检
- [ ] 不超过30字
- [ ] 不含极限词（最/第一/唯一/顶级）
- [ ] 不做标题党（内容与标题一致）
- [ ] 有明确的读者指向

---

## 第二段：开头（钩子，前100字）

### 开头公式（选一个）
1. **场景代入**：描述一个读者熟悉的场景，引发共鸣
   > "你是不是也遇到过这样的情况：XXX，试了很多方法都没用？"

2. **提问引发**：用一个问题引发读者思考
   > "为什么同样是做XXX，有人月入过万，有人却连门槛都摸不到？"

3. **数据冲击**：用一个出人意料的数据开头
   > "根据最新统计，XXX的失败率高达80%，但掌握方法的人成功率能提升3倍。"

4. **反常识**：先说一个反常识的观点，引发好奇
   > "大多数人以为XXX是因为A，但真正的原因其实是B。"

### 开头自检
- [ ] 前3秒能抓住注意力
- [ ] 与标题呼应，不跑题
- [ ] 不虚假承诺，不夸大
- [ ] 自然过渡到正文

---

## 第三段：主体（3-5个核心段落）

### 段落结构（每段一个要点）
```
【小标题/要点】（加粗，一句话概括）
  展开说明（2-3句话，讲清楚是什么/为什么/怎么做）
  案例/数据（1个具体例子或数据支撑）
  小结（一句话总结要点）
```

### 主体写作原则
1. **信息增量**：每段至少提供一个新知/新视角/新方法/新数据
2. **逻辑递进**：段落之间有逻辑关系（并列/递进/因果/对比）
3. **节奏控制**：每段不超过200字，多分段，多留白
4. **案例支撑**：至少2个具体案例，避免空泛说教
5. **实用导向**：读者读完能直接用，不只是"知道了"

### 主体自检
- [ ] 3-5个核心要点，不贪多
- [ ] 每个要点有案例/数据支撑
- [ ] 段落之间有逻辑过渡
- [ ] 提供了可操作的方法/步骤
- [ ] 没有重复啰嗦的内容

---

## 第四段：深度（信息增量，核心竞争力）

### 深度四维度（至少覆盖2个）
1. **新知**：读者不知道的事实/数据/案例
   > "很多人不知道，XXX其实是因为..."

2. **新视角**：对已知事物的独特解读
   > "换个角度看，XXX其实不是问题，而是机会..."

3. **新方法**：可操作的步骤/工具/技巧
   > "我总结了一个三步法：第一步...第二步...第三步..."

4. **新联系**：把不相关的事物建立有意义的关联
   > "XXX和YYY看似无关，其实底层逻辑是一样的..."

### 深度自检
- [ ] 至少提供了2个信息增量
- [ ] 不是网上随处可见的内容
- [ ] 有自己的思考和观点
- [ ] 读者读完有"原来如此"的感觉

---

## 第五段：结尾（升华，最后100字）

### 结尾公式（选一个）
1. **总结金句**：用一句话总结全文核心观点
   > "说到底，XXX的本质就是XXX。掌握了这一点，你就超过了90%的人。"

2. **行动号召**：给读者一个具体的行动建议
   > "今天就试试这个方法，坚持一周，你会看到明显变化。有问题评论区告诉我。"

3. **情感共鸣**：用情感化的语言收尾
   > "每个努力的人都值得被看见。愿你在XXX的路上，越走越远。"

4. **留白思考**：用一个问题结尾，引发读者思考
   > "那么，你觉得XXX最重要的是什么？欢迎在评论区分享你的看法。"

### 结尾自检
- [ ] 不突然结束，有自然的收尾
- [ ] 与开头呼应，形成闭环
- [ ] 不含违规引导语（转发给爸妈/关注我每天学等）
- [ ] 给读者留下思考或行动的空间

---

## 发布前最终检查

- [ ] 标题合格（不超过30字，无极限词，不标题党）
- [ ] 开头有钩子（前100字能抓住注意力）
- [ ] 主体3-5个要点，每个有案例支撑
- [ ] 至少2个信息增量（新知/新视角/新方法/新联系）
- [ ] 结尾有升华，不突然结束
- [ ] 字数800-1500字
- [ ] 无违规推广/虚假内容/旧闻新发
- [ ] 无平台违规引导语
- [ ] 排版清晰，段落短，多留白
- [ ] 无错别字，标点正确
- [ ] AI生成内容已标注
