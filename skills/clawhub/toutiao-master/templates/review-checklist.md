# 头条发布前12项自检清单

> 基于头条公开课《头条发文违规行为避坑指南》融合而成
> 每篇文章发布前必须逐项检查，全部通过才能发布

## 一、内容真实性（3项）

### 1. 标题真实性
- [ ] 标题与内容一致，不夸大不误导
- [ ] 标题不含极限词（最/第一/唯一/顶级/极品/绝对）
- [ ] 标题不做标题党（震惊/不看后悔/太可怕了/99%的人不知道）
- [ ] 标题不超过30字，手机端一行能显示完

### 2. 数据/案例真实性
- [ ] 关键数据有可追溯来源（标注出处或时间）
- [ ] 案例真实可信，不编造不虚构
- [ ] 引用他人内容已标注来源，不断章取义
- [ ] 不使用过时数据（超过1年的数据需标注时间）

### 3. 观点真实性
- [ ] 观点有论据支撑，不空喊口号
- [ ] 不传播未经证实的谣言或传言
- [ ] 不伪科学/不迷信/不反智
- [ ] 个人观点明确标注，不冒充官方或权威

## 二、推广合规性（3项）

### 4. 无违规推广
- [ ] 无硬广植入（产品/品牌/价格/购买链接）
- [ ] 无软性引流（微信/QQ/手机号/二维码/扫码）
- [ ] 无"加我/私信我/联系我/咨询我"等引导
- [ ] 如有推广内容，已明确标注"广告"或"推广"

### 5. 无虚假宣传
- [ ] 不夸大产品/服务效果
- [ ] 不承诺"包教包会/月入过万/一夜暴富"
- [ ] 不使用"秒杀/吊打/完爆/碾压"等夸张对比
- [ ] 不伪造用户评价或成功案例

### 6. 无侵权内容
- [ ] 文字内容原创，不抄袭不洗稿
- [ ] 配图有版权或已授权，不盗用他人图片
- [ ] 不侵犯他人肖像权/名誉权/隐私权
- [ ] 引用他人作品已获得授权或符合合理使用

## 三、平台规则（3项）

### 7. 无违规引导语
- [ ] 无"转发给爸妈/关注我每天学"等引导关注语
- [ ] 无"点赞收藏/关注不迷路/双击屏幕"等引导互动语
- [ ] 无"评论区告诉我/记得点赞/帮忙转发"等引导语
- [ ] 互动引导自然融入内容，不生硬不强制

### 8. 无敏感内容
- [ ] 无政治敏感内容（不讨论敏感政治话题）
- [ ] 无色情低俗内容（不露骨不暗示不擦边）
- [ ] 无暴力血腥内容（不描写不展示不宣扬）
- [ ] 无封建迷信内容（不宣扬不推荐不诱导）

### 9. 无旧闻新发
- [ ] 信息时效性已确认，不是过时新闻
- [ ] 不重复发布已发布过的内容
- [ ] 不洗稿/搬运他人已发布内容
- [ ] 如涉及旧闻，已标注时间并提供新视角/新信息

## 四、质量规范（3项）

### 10. 格式规范
- [ ] 字数800-1500字（特殊题材除外）
- [ ] 段落短（每段不超过3行），多留白
- [ ] 重点内容加粗，小标题清晰
- [ ] 无错别字，标点正确，中英文标点不混用

### 11. 结构完整
- [ ] 标题/开头/主体/结尾齐全
- [ ] 开头有钩子（前100字能抓住注意力）
- [ ] 主体3-5个要点，每个有案例支撑
- [ ] 结尾有升华，不突然结束

### 12. AI标注
- [ ] AI生成或辅助生成的内容已标注
- [ ] 标注方式：文末注明"本文由AI辅助生成"或"本文部分内容由AI生成"
- [ ] AI生成内容经过人工审核和修改
- [ ] 不将AI生成内容冒充为纯人工原创
