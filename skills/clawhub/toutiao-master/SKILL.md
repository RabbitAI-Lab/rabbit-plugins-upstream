## 核心能力

### 1. 选题引擎（Topic Engine）

**优秀选题四要素**（来自头条公开课）：
- **价值性**：对读者有用（知识/方法/资讯/情感）
- **独特性**：差异化视角，不人云亦云
- **时效性**：蹭热点但不盲从，有时间窗口意识
- **共鸣性**：戳中目标读者的痛点/爽点/好奇点

**赛道选择双重点**：
1. **兴趣交集**：你擅长的 ∩ 读者需要的 ∩ 市场空白的
2. **可持续性**：能持续产出100篇以上不枯竭的方向

**选题工作流**：
```
输入领域/关键词 → 扫描热点（头条热榜/百度指数/微信指数）
→ 筛选四要素（价值/独特/时效/共鸣）
→ 评估垂直度（是否符合账号定位）
→ 输出选题清单（含预估热度/竞争度/切入角度）
```

### 2. 写作工坊（Writing Workshop）

**优质文章五段式结构**：
1. **标题**（黄金3秒）：数字+痛点+悬念/反差，不做标题党
2. **开头**（钩子）：场景代入/提问引发/数据冲击/反常识
3. **主体**（节奏）：3-5个核心段落，每段一个要点，段间过渡自然
4. **深度**（增量）：提供新知/新视角/新方法/新数据，不重复已知
5. **结尾**（升华）：总结金句/行动号召/情感共鸣/留白思考

**信息增量四维度**（核心竞争力）：
- **新知**：读者不知道的事实/数据/案例
- **新视角**：对已知事物的独特解读
- **新方法**：可操作的步骤/工具/技巧
- **新联系**：把不相关的事物建立有意义的关联

**优质内容四标准**：
- **有用**：解决实际问题或提供实用价值
- **有趣**：可读性强，不枯燥
- **有深度**：不止于表面，有分析有洞察
- **有态度**：有明确观点，不模棱两可

### 3. 运营参谋（Operations Advisor）

**垂直度三原则**：
1. **领域聚焦**：80%内容在核心领域，20%可跨界但需关联
2. **风格统一**：文风/排版/配图风格保持一致
3. **标签清晰**：让算法和读者都能一眼识别你的定位

**推荐机制四步优化**（来自头条公开课）：
1. **完读率**：控制篇幅（800-1500字最佳），段落短，多留白
2. **互动率**：结尾设提问/投票/讨论引导，正文埋共鸣点
3. **转发率**：提供"值得分享给朋友"的价值（实用/情感/身份认同）
4. **关注率**：结尾引导关注，提供"关注后能获得什么"的明确预期

**复盘诊断框架**：
```
数据采集（阅读/完读/互动/转发/关注/收益）
→ 问题定位（哪项数据异常？）
→ 原因分析（标题？开头？内容？发布时间？垂直度？）
→ 优化方案（具体可执行的改进措施）
→ 效果验证（下一篇是否改善？）
```

### 4. 避雷雷达（Violation Radar）

**四大违规雷区**（来自头条公开课）：

| 雷区 | 具体表现 | 后果 |
|---|---|---|
| **违规推广** | 硬广植入/软性引流/二维码/微信号/购买链接 | 限流/下架/扣分 |
| **虚假内容** | 标题党/虚假数据/夸大宣传/编造故事/伪科学 | 限流/下架/封号 |
| **旧闻新发** | 过时信息当新闻/重复发布/洗稿/搬运 | 限流/扣分/信用降级 |
| **其他违规** | 低俗/色情/暴力/敏感/侵权/抄袭/恶意营销 | 下架/封号/法律责任 |

**发布前自检清单**（12项）：
- [ ] 标题是否夸大/误导/与内容不符？
- [ ] 开头是否有虚假承诺/诱导点击？
- [ ] 数据/案例是否真实可查？
- [ ] 是否有硬广/软广/引流信息？
- [ ] 是否有二维码/微信号/联系方式？
- [ ] 信息是否过时？是否标注了时间？
- [ ] 是否与已发布内容重复度过高？
- [ ] 是否有洗稿/搬运/抄袭嫌疑？
- [ ] 是否有低俗/暴力/敏感内容？
- [ ] 是否侵犯他人权益（肖像/著作/名誉）？
- [ ] 配图是否有版权问题？是否有水印？
- [ ] 排版是否清晰？是否有错别字？

## TRACE五维审查制度

> 基于腾讯SkillHub TRACE评测体系，为头条内容生产建立质量门禁。

### T — Trust（可信任度）
- **事实核查**：关键数据/案例必须有可追溯来源
- **原创声明**：AI生成内容必须标注，洗稿零容忍
- **敏感过滤**：政治/色情/暴力/低俗内容一票否决
- **广告合规**：推广内容必须标注，不得虚假宣传

### R — Reliability（可靠性）
- **结构完整**：标题/开头/主体/结尾齐全，不残缺
- **逻辑自洽**：论点-论据-结论链条完整，无矛盾
- **格式规范**：段落清晰/标点正确/无错别字
- **异常处理**：引用他人内容必须标注来源，不得断章取义

### A — Adaptability（适用性）
- **垂直度匹配**：内容符合账号定位和标签
- **场景适配**：适配头条阅读场景（手机端/碎片化/快节奏）
- **受众匹配**：语言风格/深度/案例匹配目标读者
- **边界清晰**：不越界写不擅长的领域，不硬蹭无关热点

### C — Convention（规范性）
- **标题规范**：不超过30字，不含违规词，不做标题党
- **排版规范**：段落不超过3行，重点加粗，配图合理
- **字数规范**：800-1500字为最佳区间（特殊题材除外）
- **发布规范**：固定发布时间，标签/分类正确选择

### E — Effectiveness（有效性）
- **信息增量**：是否提供了新知/新视角/新方法/新数据
- **实用价值**：读者读完是否能获得实际帮助
- **情感共鸣**：是否触动读者的痛点/爽点/好奇点
- **传播潜力**：是否有值得转发/收藏/评论的价值

### 审查流程

```
创作完成 → 自动审查（脚本检测违规词/重复度/字数/格式）
→ 人工复核（TRACE五维打分）
→ 拦截项整改（不通过的必须修改）
→ 发布上线（通过后发布）
→ 数据复盘（发布后48小时数据复盘）
```

## 功能说明

1. **选题引擎**：按价值性/独特性/时效性/共鸣性四要素审选题，给出赛道选择建议
2. **写作引擎**：优质文章五段式结构、信息增量四来源（新知/新视角/新方法/新数据）、黄金三秒开头与收尾升华
3. **推荐机制适配**：按完读率/互动率/转发率/关注率四指标反向优化内容结构
4. **违规避雷**：全品类违规清单（硬广/软广/引流/标题党/虚假/旧闻新发），发文前逐项过闸
5. **自动审查脚本**：`toutiao_audit.py` 对单篇或目录批量审查，输出通过/拦截/警告与 JSON 报告
6. **复盘模板**：数据诊断→问题定位→优化迭代

## 适用场景

- 头条号文章/微头条发布前的质量与合规自查
- 选题会：判断一个选题值不值得写、从哪个角度写
- 写完初稿后按爆款结构改写（标题/开头/节奏/结尾）
- 账号数据下滑后的复盘诊断
- 批量审查一个目录下的多篇稿件，拦截高风险内容
- 不适用于：公众号/小红书等其他平台的内容规范（平台规则不同）、视频脚本创作

## 使用方法

### 快速开始

1. **选题**：调用选题引擎，输入领域/关键词，获取选题清单
2. **写作**：调用写作工坊，按五段式结构创作
3. **审查**：运行审查脚本，检测违规/重复/格式问题
4. **发布**：通过审查后发布，记录发布时间和标签
5. **复盘**：48小时后采集数据，按复盘框架诊断优化

### 脚本使用

```bash
# 内容审查（检测违规词/重复度/字数/格式）
python scripts/toutiao_audit.py <文章文件路径>

# 批量审查目录
python scripts/toutiao_audit.py <目录路径> --batch
```

- `templates/title-templates.md`：20种爆款标题公式

## 参数说明

| 参数 | 必填 | 说明 |
|---|---|---|
| `path` | 脚本必填 | 待审查的文章文件或目录路径 |
| `--batch` | 否 | 目录批量模式，输出 audit_report.json |
| `稿件文本` | 对话模式必填 | 直接粘贴文章全文，按单篇审查流程处理 |

## 输出格式

对话模式输出：**审查结论（通过/拦截/警告）→ 违规项清单（原文位置 + 违规类型 + 改法）→ 质量建议（标题/开头/结构）**。
脚本模式输出：控制台报告 + JSON（`audit_report.json` / `<文件名>.audit.json`）。

示例输出（完整样例）：

```text
【审查结论】⚠️ 警告通过（2 处警告，0 处拦截）

【违规项】
1. 第 3 段「扫码关注公众号领取资料」→ 违规类型：引流（硬性拦截级，必须删除或改为合规表述）
2. 标题「震惊！90%的人都不知道」→ 违规类型：标题党（警告级，建议改为具体利益点）

【质量建议】
- 开头：前 3 行未出现钩子，建议把结论前置
- 结构：缺少小标题，长段落建议拆分（当前平均段长 280 字）

【推荐机制预判】
- 完读率风险：中（结尾升华段偏长）
- 互动设计：无提问引导，建议结尾加互动问题
```

## 权限与安全

- 脚本仅读取用户指定的稿件路径，报告写回同目录，不访问其他路径、不联网
- 不收集、不上传任何稿件内容；所有审查在本地完成
- 审查结论为参考建议，发布决策与合规责任由发布者承担
- 不代发、不登录任何账号
