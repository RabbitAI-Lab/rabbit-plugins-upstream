# 头条违规避雷完整指南

> 基于头条公开课《创作避雷小课堂》系列课程融合而成

## 一、违规推广

### 1.1 什么是违规推广

违规推广是指在文章中植入广告、引流信息，违反头条平台的推广规范。

### 1.2 常见违规推广形式

**硬广植入**
- 直接介绍产品/品牌/服务
- 包含价格、购买链接、促销信息
- 明显的广告文案风格
- 未标注"广告"或"推广"

**软性引流**
- 微信号/QQ号/手机号
- 二维码/扫码/扫一扫
- "加我/私信我/联系我/咨询我"
- "关注公众号/搜索XXX"
- "VX/V信/微/扣扣"等谐音变体

**违规导流**
- 引导到其他平台（微信/微博/抖音/小红书）
- 引导到个人网站/博客/论坛
- 引导到线下店铺/活动
- 引导加入社群/群组

### 1.3 违规推广的后果

- **轻度**：限流，减少推荐
- **中度**：文章下架，扣信用分
- **重度**：账号封禁，永久禁言
- **法律责任**：虚假广告可能面临法律追责

### 1.4 如何合规推广

1. **使用头条官方推广工具**：头条广告/星图/商品卡
2. **明确标注**：推广内容必须标注"广告"或"推广"
3. **内容真实**：不夸大不虚假，有事实依据
4. **频率控制**：推广内容不超过总内容的20%
5. **价值导向**：即使是推广，也要给读者提供价值

## 二、虚假内容

### 2.1 什么是虚假内容

虚假内容是指文章中的信息不真实、不准确、有误导性。

### 2.2 常见虚假内容形式

**标题党**
- 标题夸大、误导，与内容不符
- "震惊/不看后悔/太可怕了/万万没想到"
- "99%的人不知道/速看/紧急通知"
- 标题承诺的内容正文没有

**虚假数据**
- 编造统计数据、调查结果
- 夸大数字、比例、效果
- 使用过时数据冒充最新数据
- 数据来源不可查或不存在

**编造故事**
- 虚构个人经历、案例
- 冒充他人身份、经历
- 编造对话、截图、聊天记录
- "我朋友/我亲戚/我同学"的虚假故事

**伪科学/反智**
- 传播没有科学依据的说法
- 宣扬迷信、伪科学、反智观点
- 歪曲科学事实、断章取义
- 用个例代替普遍规律

### 2.3 虚假内容的后果

- **轻度**：限流，减少推荐
- **中度**：文章下架，扣信用分
- **重度**：账号封禁，永久禁言
- **法律责任**：造谣传谣可能面临法律追责

### 2.4 如何避免虚假内容

1. **事实核查**：关键数据/案例必须有可追溯来源
2. **标注来源**：引用他人内容必须标注出处
3. **区分观点和事实**：个人观点明确标注，不冒充事实
4. **不夸大不误导**：标题与内容一致，不用夸张词汇
5. **及时更正**：发现错误及时更正并说明

## 三、旧闻新发

### 3.1 什么是旧闻新发

旧闻新发是指将过时的、已经发布过的信息重新当作新闻发布，或者重复发布自己/他人的内容。

### 3.2 常见旧闻新发形式

**过时信息当新闻**
- 几年前的新闻/事件当作最新发布
- 不标注时间，让读者误以为是新闻
- 已经过时的政策/数据/趋势
- 已经被辟谣的信息重新发布

**重复发布**
- 自己已经发布过的内容重新发布
- 稍微改改标题/开头就重新发
- 同一内容多次发布（换账号/换平台）
- 批量发布同质化内容

**洗稿/搬运**
- 他人文章改头换面后发布
- 多篇文章拼凑组合
- 翻译外文内容不标注
- 用AI改写他人原创内容

### 3.3 旧闻新发的后果

- **轻度**：限流，减少推荐
- **中度**：文章下架，扣信用分
- **重度**：账号封禁，永久禁言
- **信用降级**：账号信用等级降低，影响后续推荐

### 3.4 如何避免旧闻新发

1. **时效性确认**：发布前确认信息是否过时
2. **标注时间**：涉及时间的信息必须标注具体时间
3. **提供新视角**：如果写旧闻，必须提供新的视角/信息/分析
4. **原创为主**：坚持原创，不洗稿不搬运
5. **不重复发布**：同一内容不重复发布，更新可以写新文章

## 四、其他违规行为

### 4.1 低俗色情

- 不露骨、不暗示、不擦边
- 不使用低俗词汇、暗示性语言
- 不配低俗、性感、暴露的图片
- 不讨论性相关话题（除非是严肃的科普/教育）

### 4.2 暴力血腥

- 不描写、不展示暴力血腥内容
- 不宣扬暴力、仇恨、报复
- 不使用暴力、血腥的图片/视频
- 不讨论犯罪方法、作案技巧

### 4.3 政治敏感

- 不讨论敏感政治话题
- 不发表政治观点、立场
- 不涉及敏感人物、事件
- 不传播政治谣言、阴谋论

### 4.4 侵权内容

- 不抄袭、不洗稿、不搬运
- 不盗用他人图片、视频
- 不侵犯他人肖像权、名誉权、隐私权
- 引用他人作品必须获得授权或符合合理使用

### 4.5 恶意营销

- 不刷量、不刷评、不刷赞
- 不互粉、互评、互赞
- 不诱导关注、诱导互动
- 不使用机器人、脚本批量操作

## 五、违规行为自查表

发布前逐项检查：

- [ ] 标题是否真实，不夸大不误导？
- [ ] 数据/案例是否有可追溯来源？
- [ ] 是否有硬广/软广/引流信息？
- [ ] 是否有微信号/QQ号/二维码？
- [ ] 信息是否过时？是否标注了时间？
- [ ] 是否与已发布内容重复度过高？
- [ ] 是否有洗稿/搬运/抄袭嫌疑？
- [ ] 是否有低俗/暴力/敏感内容？
- [ ] 是否侵犯他人权益？
- [ ] 配图是否有版权问题？
- [ ] 是否有诱导关注/诱导互动？
- [ ] AI生成内容是否已标注？

## 六、违规后的处理

### 6.1 收到违规通知后

1. **仔细阅读**：认真阅读违规通知，了解具体违规原因
2. **及时整改**：按照要求修改或删除违规内容
3. **申诉渠道**：如果认为误判，可以通过官方渠道申诉
4. **总结教训**：分析违规原因，避免再次犯错
5. **恢复信用**：持续发布优质内容，逐步恢复信用分

### 6.2 账号被封禁后

1. **查看封禁原因**：了解具体封禁原因和期限
2. **申诉解封**：如果是误判或轻度违规，可以申诉解封
3. **吸取教训**：分析被封原因，避免新账号重蹈覆辙
4. **重新开始**：如果无法解封，注册新账号，遵守规则

---

**记住：平台规则是底线，不是天花板。遵守规则是基础，优质内容才是核心。**
