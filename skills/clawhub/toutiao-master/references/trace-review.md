# TRACE五维审查详细标准

> 基于腾讯SkillHub TRACE评测体系，为头条内容生产建立质量门禁
> T=Trust(可信任度) R=Reliability(可靠性) A=Adaptability(适用性) C=Convention(规范性) E=Effectiveness(有效性)

## 审查总览

| 维度 | 核心问题 | 权重 | 审查方式 |
|---|---|---|---|
| T-Trust | 能不能放心用？ | 25% | 事实核查+原创检测+敏感过滤 |
| R-Reliability | 能不能稳定用？ | 20% | 结构检查+逻辑检查+格式检查 |
| A-Adaptability | 该不该在这个场景用？ | 15% | 垂直度评估+场景适配+受众匹配 |
| C-Convention | 能不能被理解和复用？ | 15% | 标题规范+排版规范+字数规范 |
| E-Effectiveness | 用了以后问题真的解决了吗？ | 25% | 信息增量评估+实用价值评估+传播潜力评估 |

**评分标准**：
- 90-100分：优秀，直接发布
- 75-89分：良好，小修改后发布
- 60-74分：及格，需要修改后重新审查
- <60分：不合格，拦截，必须大幅修改或重写

## T — Trust（可信任度）

### T1. 事实核查（权重40%）

**检查项**：
- [ ] 关键数据有可追溯来源（标注出处或时间）
- [ ] 案例真实可信，不编造不虚构
- [ ] 引用他人内容已标注来源，不断章取义
- [ ] 不使用过时数据（超过1年的数据需标注时间）
- [ ] 观点有论据支撑，不空喊口号

**评分标准**：
- 5分：所有关键信息有来源，事实准确无误
- 4分：大部分信息有来源，个别小问题
- 3分：部分信息缺乏来源，需要补充
- 2分：多处信息缺乏来源，可信度低
- 1分：信息严重不实，有虚假内容

### T2. 原创声明（权重30%）

**检查项**：
- [ ] 文字内容原创，不抄袭不洗稿
- [ ] AI生成或辅助生成的内容已标注
- [ ] 不搬运他人已发布内容
- [ ] 引用他人作品已获得授权或符合合理使用
- [ ] 与自己已发布内容重复度<30%

**评分标准**：
- 5分：完全原创，AI标注规范，无抄袭嫌疑
- 4分：基本原创，少量引用已标注
- 3分：部分内容疑似洗稿，需要修改
- 2分：大量内容非原创，抄袭嫌疑大
- 1分：完全抄袭或搬运，零容忍

### T3. 敏感过滤（权重30%）

**检查项**：
- [ ] 无政治敏感内容
- [ ] 无色情低俗内容
- [ ] 无暴力血腥内容
- [ ] 无封建迷信内容
- [ ] 无违规推广/引流信息
- [ ] 无平台违规引导语

**评分标准**：
- 5分：完全无敏感内容，安全合规
- 4分：基本安全，个别边缘内容需注意
- 3分：有少量敏感内容，需要修改
- 2分：有较多敏感内容，风险较高
- 1分：有严重敏感内容，一票否决

---

## R — Reliability（可靠性）

### R1. 结构完整（权重40%）

**检查项**：
- [ ] 标题/开头/主体/结尾齐全
- [ ] 开头有钩子（前100字能抓住注意力）
- [ ] 主体3-5个核心要点
- [ ] 每个要点有案例/数据支撑
- [ ] 结尾有升华，不突然结束
- [ ] 段落之间有逻辑过渡

**评分标准**：
- 5分：结构完整，逻辑清晰，过渡自然
- 4分：结构基本完整，个别部分需优化
- 3分：结构有缺失，需要补充
- 2分：结构混乱，逻辑不清
- 1分：结构严重残缺，无法阅读

### R2. 逻辑自洽（权重30%）

**检查项**：
- [ ] 论点-论据-结论链条完整
- [ ] 前后观点一致，无矛盾
- [ ] 因果关系合理，不牵强
- [ ] 案例能支撑观点，不脱节
- [ ] 推理过程清晰，可验证

**评分标准**：
- 5分：逻辑严密，论证充分，无懈可击
- 4分：逻辑基本自洽，个别地方需加强
- 3分：逻辑有漏洞，需要补充论证
- 2分：逻辑混乱，论证不足
- 1分：逻辑严重错误，观点矛盾

### R3. 格式规范（权重30%）

**检查项**：
- [ ] 无错别字
- [ ] 标点正确，中英文标点不混用
- [ ] 段落清晰，每段不超过3行
- [ ] 重点内容加粗，小标题清晰
- [ ] 无连续空行
- [ ] 排版美观，适合手机阅读

**评分标准**：
- 5分：格式完美，零错误，排版美观
- 4分：格式良好，个别小错误
- 3分：格式一般，有多处需要修改
- 2分：格式较差，影响阅读
- 1分：格式混乱，无法阅读

## A — Adaptability（适用性）

### A1. 垂直度匹配（权重40%）

**检查项**：
- [ ] 内容符合账号定位和标签
- [ ] 与账号已发布内容领域一致
- [ ] 目标读者明确
- [ ] 不越界写不擅长的领域
- [ ] 跨界内容与核心领域有关联

**评分标准**：
- 5分：完全垂直，精准匹配账号定位
- 4分：基本垂直，略有跨界但有关联
- 3分：垂直度一般，需要调整方向
- 2分：偏离账号定位，影响标签
- 1分：完全不相关，严重影响垂直度

### A2. 场景适配（权重30%）

**检查项**：
- [ ] 适配头条阅读场景（手机端/碎片化/快节奏）
- [ ] 篇幅适合（800-1500字）
- [ ] 段落短，多留白，适合快速阅读
- [ ] 标题适合信息流展示（不超过30字）
- [ ] 开头3秒能抓住注意力

**评分标准**：
- 5分：完美适配头条场景，阅读体验极佳
- 4分：基本适配，个别地方需优化
- 3分：适配一般，需要调整
- 2分：适配较差，影响阅读体验
- 1分：完全不适配，不适合头条

### A3. 受众匹配（权重30%）

**检查项**：
- [ ] 语言风格匹配目标读者
- [ ] 内容深度匹配目标读者认知水平
- [ ] 案例/例子贴近目标读者生活
- [ ] 不使用目标读者看不懂的专业术语（或有解释）
- [ ] 能引发目标读者共鸣

**评分标准**：
- 5分：精准匹配受众，共鸣强烈
- 4分：基本匹配，个别地方需调整
- 3分：匹配一般，需要优化
- 2分：匹配较差，受众不买账
- 1分：完全不匹配，受众看不懂

---

## C — Convention（规范性）

### C1. 标题规范（权重40%）

**检查项**：
- [ ] 不超过30字
- [ ] 不含极限词（最/第一/唯一/顶级）
- [ ] 不做标题党（震惊/不看后悔等）
- [ ] 标题与内容一致
- [ ] 有明确的读者指向
- [ ] 手机端一行能显示完

**评分标准**：
- 5分：标题完美，吸引人又真实
- 4分：标题良好，个别地方可优化
- 3分：标题一般，需要修改
- 2分：标题较差，有违规风险
- 1分：标题严重违规，必须重写

### C2. 排版规范（权重30%）

**检查项**：
- [ ] 段落不超过3行
- [ ] 重点内容加粗
- [ ] 小标题清晰
- [ ] 多留白，段落之间空行
- [ ] 配图合理（如有）
- [ ] 列表/编号使用规范

**评分标准**：
- 5分：排版精美，阅读体验极佳
- 4分：排版良好，个别地方可优化
- 3分：排版一般，需要调整
- 2分：排版较差，影响阅读
- 1分：排版混乱，无法阅读

### C3. 字数规范（权重30%）

**检查项**：
- [ ] 字数在800-1500字区间（特殊题材除外）
- [ ] 不低于300字（最低要求）
- [ ] 不超过3000字（避免过长）
- [ ] 内容充实，不凑字数
- [ ] 信息密度合理，不啰嗦

**评分标准**：
- 5分：字数完美，信息密度合理
- 4分：字数良好，略有偏差
- 3分：字数一般，需要调整
- 2分：字数偏差较大，影响推荐
- 1分：字数严重不足或过长

---

## E — Effectiveness（有效性）

### E1. 信息增量（权重40%）

**检查项**：
- [ ] 至少提供2个读者不知道的东西
- [ ] 新知：新的事实/数据/案例
- [ ] 新视角：新的解读角度
- [ ] 新方法：新的操作技巧
- [ ] 新联系：建立不相关事物的关联
- [ ] 不是网上随处可见的内容

**评分标准**：
- 5分：信息增量丰富，读完有"原来如此"的感觉
- 4分：有一定信息增量，部分内容有新意
- 3分：信息增量一般，大部分是已知内容
- 2分：信息增量不足，内容比较陈旧
- 1分：完全没有信息增量，都是老生常谈

### E2. 实用价值（权重30%）

**检查项**：
- [ ] 读者读完能获得实际帮助
- [ ] 提供具体的步骤/方法/工具
- [ ] 可操作，读者能直接用
- [ ] 解决实际问题，不只是理论
- [ ] 有清单/模板/案例等实用形式

**评分标准**：
- 5分：非常实用，读完就能用，价值极高
- 4分：比较实用，有可操作的方法
- 3分：实用性一般，部分内容可操作
- 2分：实用性较差，大部分是理论
- 1分：完全不实用，空泛说教

### E3. 传播潜力（权重30%）

**检查项**：
- [ ] 有值得转发的价值（实用/情感/身份认同）
- [ ] 能引发读者评论/讨论
- [ ] 有收藏价值（干货/资料/方法）
- [ ] 有关注价值（想看下一篇）
- [ ] 标题/开头有吸引力，能提高点击率

**评分标准**：
- 5分：传播潜力极高，有爆款潜质
- 4分：传播潜力较高，容易获得互动
- 3分：传播潜力一般，需要优化
- 2分：传播潜力较低，互动可能较少
- 1分：完全没有传播潜力，没人愿意看

## 审查流程

### 第一步：自动审查（脚本检测）

运行 `scripts/toutiao_audit.py`，自动检测：
- 违规词（极限词/标题党/AI黑话/违规引导语）
- 字数统计
- 格式检查
- AI标注检查
- 重复度检测

### 第二步：人工复核（TRACE五维打分）

按照上述五个维度逐项打分，计算总分：
- T-Trust：___/5 × 25% = ___
- R-Reliability：___/5 × 20% = ___
- A-Adaptability：___/5 × 15% = ___
- C-Convention：___/5 × 15% = ___
- E-Effectiveness：___/5 × 25% = ___
- **总分**：___/100

### 第三步：拦截项整改

- 总分≥90分：直接发布
- 75-89分：小修改后发布
- 60-74分：修改后重新审查
- <60分：拦截，必须大幅修改或重写

### 第四步：发布上线

通过审查后发布，记录：
- 发布时间
- 标题
- 标签/分类
- 审查得分

### 第五步：数据复盘

发布后48小时采集数据，按复盘框架诊断优化：
- 阅读量/完读率/互动率/转发率/关注率/收益
- 问题定位→原因分析→优化方案→效果验证
