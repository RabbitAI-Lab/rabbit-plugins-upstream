# 运营资料生成模板库

> 本文件定义12类运营资料的生成模板与规范。生成时严格遵循对应模板结构，从 `company_profile.md` 提取素材填充。

---

## 1. 品牌介绍文案

### 用途
官网关于我们、宣传册首页、合作方案品牌介绍、平台机构简介

### 模板结构
```
【标题】一句话定位 + 机构全称
【开篇】医院定位 + 核心价值主张引出（1段）
【核心优势】十五大理由精选3-5条，每条含数据支撑（列表）
【技术亮点】AI超声技术 + 腹膜外剖宫产 + 疼痛管理体系（1段）
【服务范围】分娩方式 + 产前筛查 + 产后康复（列表）
【团队亮点】多学科专家团队 + 助产士团队 + 麻醉团队（1段）
【信任背书】关键数据汇总（无痛分娩率98%/AI超声12万例验证/华北首家）
【结语】品牌愿景 + 联系引导
```
### 字数控制
- 短版：300-500字（平台简介用）
- 长版：800-1200字（宣传册/合作方案用）

## 2. 朋友圈文案集

### 用途
医院官方朋友圈、产科团队朋友圈、客服团队朋友圈日常运营

### 模板结构（每条）
```
【钩子开头】提问/数据/情感共鸣（1句，15字以内）
【核心内容】分娩亮点/科普知识/医院动态（2-3句）
【价值升华】顺剖都不疼理念自然融入（1句）
【行动引导】咨询/预约/直播提醒（1句）
【Emoji】1-3个，克制使用
```
### 生成类型
| 类型 | 示例触发词 | 内容方向 |
|------|-----------|---------|
| 分娩报喜型 | "写报喜朋友圈" | 新生儿诞生，突出分娩体验 |
| 科普知识型 | "写科普朋友圈" | 无痛分娩/AI超声/产后康复 |
| 日常温情型 | "写日常朋友圈" | 阳光房/陪产/团队日常 |
| 直播预告型 | "写直播预告" | 孕妈课堂主题+时间+平台+亮点 |
| 节日关怀型 | "写节日朋友圈" | 节日祝福+孕育鼓励 |
| 套餐介绍型 | "写套餐朋友圈" | 分娩套餐透明价格+服务亮点 |

### 批量生成
一次生成5-10条，标注类型，便于排期使用。

## 3. 小红书种草文案

### 用途
小红书平台内容运营，吸引孕妈群体关注

### 模板结构
```
【标题】痛点关键词 + 数字 + 情绪词（20字以内，含emoji）
【正文开头】第一人称/第二人称代入，引发共鸣
【核心内容】3-5个要点，每点配emoji小标题
【信任建立】数据/案例/资质自然植入
【互动引导】提问结尾，引导评论收藏
【话题标签】#分娩 #无痛分娩 #坤如玛丽产科 等8-12个
```
### 内容方向
- 分娩体验分享（阳光房/陪产/LDR产房体验）
- 科普类：无痛分娩真相、AI超声是什么、腹膜外剖宫产优势
- 体验类：产检流程、分娩私教课、产后康复
- 对比类：传统分娩 vs 坤如玛丽分娩体验

## 4. 公众号文章

### 用途
微信公众号深度内容，建立专业权威形象

### 模板结构
```
【标题】痛点/悬念 + 价值承诺（不超过30字）
【导语】场景代入或数据引入（100字以内）
【正文】
  - 小标题分段，每段300-500字
  - 穿插案例（从案例库选取，化名处理）
  - 穿插科普知识
  - 适当加粗关键数据/结论
【结语】理念升华 + 行动引导
【尾部】产科介绍卡 + 联系方式 + 二维码引导
```
### 字数控制
- 短文：1500-2000字
- 深度文：2500-4000字

### 选题方向
| 系列 | 示例选题 |
|------|---------|
| 技术系列 | 《AI超声落地坤如玛丽，产前筛查进入"秒级质控"时代》 |
| 疼痛管理系列 | 《顺剖都不疼：22个细节让分娩不再恐惧》 |
| 案例系列 | 《腹膜外剖宫产+美容缝合，这位妈妈的分娩故事太暖了》 |
| 科普系列 | 《无痛分娩率98%意味着什么？一篇看懂》 |
| 理念系列 | 《科学定制方案，不盲目不夸张——坤如玛丽产科的坚持》 |
| 十五大理由系列 | 《在坤如生孩子是一件温暖的事——十五大理由全解析》 |

## 5. 短视频脚本

### 用途
抖音/快手/视频号短视频内容

### 模板结构（30秒-60秒）
```
【场景】产房/阳光房/超声室/产后康复区（标注拍摄场景）
【0-3秒·钩子】提问/数据/反转，抓住注意力
【3-15秒·痛点】描述孕妈常见困境或误区
【15-40秒·方案】坤如玛丽解决方案 + 具体亮点
【40-50秒·案例】简述一个成功案例（数据对比）
【50-60秒·引导】关注/咨询/预约
```
### 脚本格式
| 时间 | 画面/字幕 | 口播台词 | 备注 |
|------|----------|---------|------|
| 0-3s | 字幕大字 | "生孩子一定要忍痛吗？" | 配悬念音乐 |
| ... | ... | ... | ... |

### 内容方向
- 分娩体验类（阳光房/陪产/LDR产房）
- 技术科普类（AI超声/腹膜外剖宫产/无痛分娩）
- 误区纠正类（"无痛分娩会影响宝宝吗？"）
- 日常记录类（产科日常/新生儿报喜/产后康复）

## 6. 客户案例包装

### 用途
官网案例展示、宣传册案例页、销售演示、社交媒体长图文

### 模板结构
```
【案例标题】分娩方式 + 亮点关键词 + 结果
【孕妈背景】年龄、孕期情况（化名处理，保护隐私）
【就诊经过】
  - 选择坤如玛丽的原因
  - 产检/分娩过程
  - 疼痛管理方案
  - 关键节点（AI超声筛查/无痛分娩/腹膜外剖宫产等）
【结果】分娩方式、产后恢复情况、宝宝状况
【核心启示】1-2句理念总结
【数据卡片】恢复时间对比、疼痛管理方案等
```
### 注意事项
- 所有案例化名处理，不出现真实姓名
- 医疗信息保持准确但不构成处方建议
- 突出"顺剖都不疼"和"科学定制方案"的差异化

## 7. 销售话术 / 客服话术

### 用途
前台接待、电话咨询、微信客服、社群答疑

### 模板结构
```
【场景】描述触发场景
【客户常见问题】列举2-3个典型问题
【标准回复】
  - 共情回应（先安抚情绪）
  - 专业解答（简洁清晰）
  - 信任建立（数据/案例/资质）
  - 行动引导（预约/到院/咨询）
【禁忌提醒】不可承诺的效果、不可使用的绝对化用语
```
### 话术分类
| 场景 | 典型问题 |
|------|---------|
| 分娩咨询 | "无痛分娩真的不疼吗？""分娩套餐多少钱？" |
| 产检咨询 | "AI超声和普通B超有什么区别？""产检需要多久？" |
| 剖宫产咨询 | "腹膜外剖宫产和普通剖宫产有什么不同？""术后多久能下地？" |
| 产后康复 | "产后修复都包括什么？""住几天能出院？" |
| 预约就诊 | "怎么预约分娩？""需要提前多久预约？" |
| 心理焦虑 | "第一次生孩子好害怕""高危妊娠能顺产吗？" |

## 9. 海报文案

### 用途
朋友圈海报、门诊海报、活动海报、节日海报

### 模板结构
```
【主标题】6-12字，核心信息
【副标题】补充说明，10-20字
【正文/要点】3条以内，每条8-15字

【行动引导】扫码/电话/到院
【底部信息】医院名称 + 地址 + 二维码位
```

|------|---------|

## 12. 新闻通稿 / 媒体稿件

### 用途
媒体发布、行业公关、学术活动宣传、品牌动态传播

### 模板结构
```
【标题】新闻性标题，含机构名 + 事件/观点
【导语】5W要素（何人何时何地何事何因）
【正文】
  - 事件详情/观点阐述
  - 数据支撑
  - 专家引言（原话风格）
  - 背景补充
【结语】医院简介 + 联系方式
```
### 选题方向
- AI超声技术落地（如"华北地区首家AI超声临床规模化应用"）
- 技术创新获奖（如脉冲式接产技术获天津市五小创新成果奖）
- 孕妈课堂/直播活动举办
- 5G+智慧医疗示范项目进展
- 里程碑数据发布（年度分娩量/新生儿数）
- 远程医疗合作（京津冀基层医院筛查能力输出）
