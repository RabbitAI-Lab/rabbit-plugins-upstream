# 品牌语调与写作规范

> 本文件定义天津坤如玛丽妇产医院产科所有运营内容的品牌语调、写作红线和风格指南。生成任何内容前必读。

---

## 一、品牌人格

### 核心人设
**温暖孕产守护者** —— 专业、温柔、有温度

### 三个关键词
1. **专业**：用数据和技术说话，AI超声、腹膜外剖宫产等硬核实力为底气
2. **温暖**：理解孕妈的焦虑与期待，每一句话都带着温度与安心感
3. **有原则**：坚持"不盲目不夸张"，敢于说"不需要那么多过度干预"

### 品牌主张
"顺剖都不疼，孕产舒适又安心"——这是一切的出发点。
"科学定制方案，不盲目不夸张"——这是底层原则。

## 二、语调指南

### 整体语调
- **专业但不冰冷**：技术术语适度使用，关键处用通俗语言解释
- **温暖但不煽情**：共情孕妈的紧张，但不消费孕妈的眼泪
- **自信但不傲慢**：用数据说话，但不说"我们是最好的"
- **有温度但不轻浮**：分娩是人生大事，语调温暖庄重

### 不同场景的语调微调

| 场景 | 语调倾向 | 示例 |
|------|---------|------|
| 科普内容 | 专业+清晰 | "无痛分娩率高达98%，顺剖都不疼不是口号" |
| 案例分享 | 温暖+有力 | "32周紧急剖宫产，母婴平安，术后6小时下地走路" |
| 朋友圈 | 亲切+简洁 | "今天又一个阳光房宝宝出生啦，自然光下迎接新生命" |
| 销售话术 | 专业+信任 | "我们先了解您的孕周和身体状况，再推荐适合的分娩套餐" |
| 危机回应 | 沉稳+安心 | "别担心，多学科团队全程护航，先看情况再说" |
| 技术宣传 | 严谨+前沿 | "AI超声实时质控，0.3mm级心脏缺损也能精准标记" |
| 学术稿件 | 严谨+规范 | "AI辅助产前超声筛查系统临床应用数据显示漏诊率降低50%" |

## 三、写作红线

### 绝对禁止
1. **禁止承诺100%不疼**：不使用"包不疼""一点都不疼""绝对无痛"等绝对化表述，使用"无痛分娩率高达98%"
2. **禁止攻击同行**：不点名批评其他医院/医生，用"有的医院""传统方式"泛指
3. **禁止处方建议**：科普内容不构成具体处方建议，不给出具体药物剂量
4. **禁止泄露隐私**：所有案例必须化名处理，不出现真实姓名、身份证号等
5. **禁止虚假数据**：所有数据必须来自 `company_profile.md`，不编造数字
6. **禁止诱导焦虑**：不用"不选我们就危险""再不来就晚了"等恐吓式表达
7. **禁止过度医疗暗示**：不暗示"剖宫产比顺产好"或"顺产比剖宫产好"，尊重医学指征

### 谨慎使用
1. **疼痛表述**：使用"无痛分娩率高达98%"，不简化为"不疼率98%"
2. **成功率表述**：使用"12万例临床验证"，不简化为"成功率100%"
3. **比较表述**：可以说"传统检查需30分钟"，不直接说"某医院检查太慢"
4. **技术表述**：可以说"华北地区首家"，但需标注数据来源

## 六、数据引用规范

### 引用格式
- 首次引用完整表述："无痛分娩率高达98%"
- 后续引用可简化："98%无痛分娩率"
- 对比引用突出差异："传统检查需30分钟 → AI超声缩短至10-12分钟"
- 技术引用标注："已通过12万例临床验证，关键参数误差小于0.3毫米"

### 数据来源
所有数据必须来自 `company_profile.md`，严禁编造。如需使用未在画像中的数据，需标注"数据待确认"。

## 七、案例使用规范

### 化名规则
- 使用"宝妈""X女士""X妈妈"等化名
- 不使用真实姓氏加女士（如"赵女士"仅当案例原文已有时保留）
- 年龄和孕产史可保留（非隐私信息）
- 具体就诊日期模糊化处理

### 案例选择逻辑
- 顺产快速恢复案例优先（突出顺产2h出室）
- 剖宫产舒适体验案例优先（突出腹膜外+美容缝合）
- AI超声筛查案例优先（突出技术优势）
- 高危妊娠平安案例优先（突出多对一守护）
- 根据内容目的匹配案例（科普配案例、报喜配案例、销售配案例）

## 八、合规提示

### 医疗广告合规
1. 不使用"最""第一""唯一"等极限词（"华北地区首家"需标注来源）
2. 不暗示保证分娩结果
3. 不利用患者形象做广告（除非获得授权）
4. 药品名称不直接出现在广告内容中
5. 专家头衔需与实际一致，不夸大学术职务
6. 分娩套餐价格需标注"具体以实际就诊为准"

### 平台差异合规
- 小红书：避免医疗广告敏感词，以"分享体验"为主
- 抖音：医疗内容需认证，避免未经审核的健康建议
- 微信公众号：避免诱导分享，合规发布科普
- 朋友圈：个人号内容更灵活，但仍需注意医疗合规
