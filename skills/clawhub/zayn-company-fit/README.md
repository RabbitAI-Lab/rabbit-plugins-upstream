# COMPANY_FIT() 潜在客户匹配度分析

- Skill：`zayn-company-fit`
- 用途：用已有研究和我方能力判断合作匹配度。
- 适用：客户、供应商、伙伴匹配；不适用重新做公开调查或资格排序。
- 输入：目标、我方产品、市场、目标、研究结果、风险、供应交付能力。
- 最低条件：主体、目标、我方能力及基础研究明确。
- 流程：汇总证据→匹配维度→风险与缺口→分级→下一步。
- 输出：匹配等级、正反原因、风险、缺口、重判条件和动作。
- 证据：遵守共享规则；默认不评分。
- 协作：上游 research/risk/profile，下游 qualify/priority/account。
- 示例：结合客户研究、付款记录和我方交付能力判断是否适合长期开发。
- 版本：v1.0.0
