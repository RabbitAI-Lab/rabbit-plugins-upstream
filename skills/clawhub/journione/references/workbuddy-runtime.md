# 运行与交付边界

输入是旅行想法、目的地与天数、约束、已有行程或可读资料。输出为行程总览、逐日建议时间线、固定事项、待核实项与同行者提示；用户确认且生成能力可用时，再交付真实 Travel Journal。

## 所需能力

| 任务 | 所需能力 |
|---|---|
| 整理已有资料、规划与调整路线 | 模型与本 Skill 规则 |
| 核验当前开放时间、交通、活动 | 宿主联网搜索或浏览工具 |
| 读取文件与照片 | 对应文件读取、OCR 或视觉能力 |
| 生成在线日志 | Node.js 22+ 运行请求准备脚本并访问 HTTPS，或执行同等校验的已验证 Connector |
| 酒店查询 | 实际可用的 TourMind 工具、完整官方 Skill 及其参数指南 |
| 航班查询 | 实际暴露的 Kiwi `search-flight` 工具 |

机酒按用户需要查询，不阻塞基础规划。只使用实际可调用的工具，不凭名称推定能力，也不虚构接口或配置。

## 能力缺失时

- 没有联网：仍整理已有事实与偏好；营业、交通、活动和价格等写明待核实，不伪称已搜索，不杜撰店名、班次或库存。
- 不能读取附件：说明不能读取的范围，继续使用已有文字，不编造图片或文档内容。
- 没有机酒工具：保留搜索条件，讨论住宿区域及抵离对路线的影响；不提供虚构实时报价或预订链接。
- 不能运行脚本或访问生成服务：交付完整文字确认稿，明确“行程已整理好，当前环境还不能生成在线日志”。保留已确认内容，不构造 Preview。
- Connector 只有经过验证、能完成同等输入校验、同请求同幂等键重试和响应验证时，才可代替脚本；不能自行省略校验。
- 生成成功：仅交付服务实际返回的同源 Preview。链接返回不等于全部视觉素材完成；生成确认和预订授权规则继续适用。

恢复能力后承接原确认稿，不重新收集已知输入。文字方案与在线 Travel Journal 的完成状态分开说明。

## 数据与隐私

- 确认生成后，仅把已确认行程及获准上传的材料发送到 JourniOne；生成无需 JourniOne Token。
- Preview 可以公开查看，不上传证件、精确住址、健康信息或未经允许的私人照片；不承诺未证实的私密链接、保存期限或自动删除机制。
- 酒店、航班和地图查询只发送必要的地点、日期及同行配置，订单身份信息由对应服务处理，不写入公开行程。
- 个人编辑使用实际账号会话；对外分享使用页面返回的真实链接，请求内容与私人链接不写入公开日志。
