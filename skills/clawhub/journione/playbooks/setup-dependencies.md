# Playbook: 运行能力检查

## 目的
按当前可用能力完成旅行任务，缺少外部工具时仍交付可完成的规划内容。

## 前提条件
- 用户正在规划、调整旅行，整理旅行资料或生成旅行日志。
- 只读取宿主实际暴露的工具与已授权连接，不推测后台能力。

## 步骤
1. 识别用户需要文字规划、事实核验、资料整理、在线日志或机酒查询。
2. 检查所选任务对应能力；已知结果在本轮复用，不反复检查。
3. 按 [能力边界](../references/workbuddy-runtime.md) 执行可完成部分，明确具体缺口。
4. 用户要求接入缺失能力时，仅使用当前平台提供的配置流程；没有准确配置依据就说明待接入，保留旅行输入。

## 判断标准
- 基础路线规划不依赖酒店或航班连接，不自动执行安装或添加 MCP。
- 缺联网工具时基于已知资料形成草案，标注待核实事实。
- 缺网页生成能力时交付完整文字确认稿，说明未生成网页；不伪造预览或图片。
- 服务工具存在时按其实际版本契约调用，价格、库存与预订状态来自真实返回。
- 平台要求授权、用户点击或重载时遵循平台流程，不声称后台已完成。

## 验证
- 已确认内容保留，可完成的结果已交付。
- 工具可调用与实际执行成功分别判断，以真实结果报告完成状态。
- 没有虚构工具、当前事实、价格或交付链接。
