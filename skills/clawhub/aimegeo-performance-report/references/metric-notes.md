# Metric interpretation notes

The program returns values defined directly by its input field mappings: counts, ratios, status totals, and period deltas where a valid comparison input exists. It does not claim statistical significance.

- Distinguish record counts from unique entities; a post sent to two destinations may represent one article and two publication records.
- Report the valid denominator beside every rate. Failed, simulated, and unrun observations are not successful zero-result observations.
- A missing data source is unknown, not zero. An empty citation list is meaningful only when the capture was complete.
- Currency values with different units must remain separate. Return on investment requires supplied, aligned, attributable revenue and cost.
- Period-to-period differences do not establish causation. Changes in time window, filters, or sample composition limit comparability.
