# 数据图表领域

## 适用范围

源内容包含数量、金额、比例、评分、排名、阶段值或分类对比时使用本领域。最小实体是“类别 + 数值”，多系列时再增加系列维度。

```text
观测值 = label + value + 可选 series
```

## 图形选择

- `chart.bar`：普通分类对比，默认选择。
- `chart.line`：月份、季度、阶段等有序趋势。
- `chart.pie`：单系列、非负的构成比例。
- `chart.radar`：质量、能力、服务等多维画像。
- `chart.comparison`：分类名称较长、适合横向比较。
- `chart.funnel`：商机到中标、线索到转化等递减阶段。
- `chart.matrix`：分类 × 系列的完整评分矩阵。

## 数据规则

```json
{
  "kind": "chart",
  "variant": "bar",
  "unit": "人",
  "data": [
    {"label": "研发部", "value": 24},
    {"label": "实施部", "value": 26}
  ]
}
```

多系列的每一行都必须有 `series`，且每个分类和系列的组合都必须有值。不能混用有 `series` 和无 `series` 的行，不能重复同一组合，也不能把缺失值补成 0，除非业务明确就是 0。

## 文字规则

图表标签建议不超过 14 个字符。长标签应压缩为“部门名”“阶段名”“指标名”，单位单独放 `unit`，不要把“24 人”“完成率 92%”整句塞进 `label`。
