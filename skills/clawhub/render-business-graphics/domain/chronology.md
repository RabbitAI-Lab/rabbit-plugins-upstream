# 时间轴领域

## 适用范围

当主关系是时间先后、项目历史、阶段里程碑或发展演进时使用时间轴。`date` 可以是年份、月份或阶段文字，不要求一定是 ISO 日期。

## 事件实体

```json
{
  "ref": "C",
  "date": "2026",
  "title": "成果交付",
  "description": "完成验收并移交运行",
  "position": "top",
  "icon": "trophy"
}
```

事件必须有唯一 `ref`、`date`、`title`，总数 2–8。`position` 省略时服务自动上下交替；图标必须使用契约允许的名称。不同时间轴 variant 共用同一事件数据，只改变视觉表达。

## 文字规则

事件标题建议 14 个字符以内，说明建议 32 个字符以内。日期只写“2026”“一期”“验收阶段”等短标记，不要把长叙述塞到日期字段。
