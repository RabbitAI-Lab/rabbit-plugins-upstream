## Description:

Computes common technical indicators such as MACD, RSI, KDJ, Bollinger Bands, moving-average signals, and volume-price signals for educational demonstrations.

This skill is for demonstration purposes and not for production usage.

## Use Case:

Developers and educators can use this skill to demonstrate technical-indicator calculations and output formatting for selected stock codes. It is not suitable for trading, investment analysis, or production financial decision support without replacing the fixed demo values with real validated market data.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Demo finance signals may be mistaken for real market analysis or investment advice.

Mitigation: Keep the demo-only disclosure visible in every output mode and do not present outputs as real market data or investment guidance.

Risk: Fixed demo values can produce misleading technical-analysis conclusions if used outside teaching contexts.

Mitigation: Require real, validated input K-line data before using the calculations for any non-demonstration workflow.
