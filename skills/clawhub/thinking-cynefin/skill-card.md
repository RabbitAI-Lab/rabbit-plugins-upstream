## Description:

When the right response mode is unclear, classify the cause-effect domain first; decompose disorder.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and agents use this skill to choose a response mode for ambiguous decisions, incidents, or mixed problems before solution work begins.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can shape the agent's response format when ambiguity calls for Cynefin classification.

Mitigation: Use it as a thinking aid; confirm that the selected domain and first actions fit the actual situation before acting.

Risk: A wrong cause-effect classification can lead to an unsuitable response mode.

Mitigation: Apply the skill's falsifier and mismatch checks, then reclassify only when evidence shows the domain has shifted.
