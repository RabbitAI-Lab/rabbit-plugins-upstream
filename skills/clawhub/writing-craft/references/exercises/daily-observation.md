# 每日微观察训练

## 训练目标
训练"把生活变成素材"的能力。刘军强说写作的本质不是修辞，是观察——你看到的东西跟别人一样，但你看出来的东西不一样。

## 训练说明
这是"写作是门手艺"体系的基础训练，建议每天一次，每次15分钟。连续21天后，你对日常生活的感知颗粒度会明显变细。

---

## 今日训练

### 第一步：选取素材（1分钟）

从今天的生活中，抓一个**最容易被忽略的瞬间**。标准：
- 它发生在5秒以内
- 你差点没注意到它
- 它看起来"不值得写"

示例素材：
- 电梯里两个陌生人同时伸手按楼层，同时缩手，又同时伸出去
- 外卖小哥在小区门口看手机地图，转了三个圈
- 同事说"没事"的时候，嘴角往下撇了0.5秒

### 第二步：表层记录（3分钟）

用"王晶式写法"——纯事实，不加工，像监控摄像头一样记录。

格式：时间 + 地点 + 人物 + 动作 + 一句话对话（如果有）

```
示例：
下午2:15，公司茶水间。两个同事同时走到咖啡机前。
A伸手说"你先"，B也伸手说"你先"。
两人同时笑，但眼睛都没看对方。
A先倒了咖啡，B在旁边刷了三下手机。
全程12秒。
```

### 第三步：深度挖掘（8分钟）

用"周星驰式写法"——在这个瞬间里，找到那个"不像表面那么简单"的东西。

**挖掘提示（选1-2个来写）**：

1. **反常**：这个瞬间有什么是"本该如此，但偏偏不是"的？
   - 例：他们说着"你先"，但身体一点都不想让——客气话和身体语言在打架。

2. **折叠**：这个瞬间里折叠了什么更大的东西？
   - 例：咖啡机前的"你先""你先"，折叠了中国人所有的社交本能——用谦让表达地位，用客气掩盖疏离。

3. **隐喻**：这个瞬间像一部什么电影/一个什么场景？
   - 例：两个同时伸手的人，像极了人生的地铁站——每次你以为要一起走，最后都是各上各的车。

4. **逆向**：把"正常"反过来看会怎样？
   - 例：如果他们不客气呢？如果A直接倒了就走呢？B会觉得A没教养，还是松了一口气？

5. **时间的针脚**：把这个瞬间拉长或缩短会怎样？
   - 例：这12秒的咖啡机相遇，如果拉长到一生——你会发现，我们一辈子都在跟人同时伸手、同时缩手。

### 第四步：提炼主题句（3分钟）

用一句话收住这个观察。这句话必须同时做到：
- 有画面（让人能看到那个瞬间）
- 有反转（让人产生"哦，原来如此"）
- 能记住（可以当标题）

```
示例主题句：
"茶水间的咖啡机，是中国式社交的最小排练场。"
"我们每天都在跟人碰杯，但眼睛从来没看过对方。"
"'你先'是这个世界上最假的真话，也是这个世界上最真的假话。"
```

## 进阶变体

### 变体A：连续观察
同一类场景连续观察3天（比如每天的地铁、每天的午餐）。找出3天之间的差异——差异就是文章。

### 变体B：换对象
周一观察别人，周二观察自己。你会发现：你描述别人的时候有多准确，描述自己的时候就有多模糊。

### 变体C：声音版
只写声音，不写画面。把你今天听到的所有声音串成一个"声音场景"——你会发现一个完全不同的世界。
