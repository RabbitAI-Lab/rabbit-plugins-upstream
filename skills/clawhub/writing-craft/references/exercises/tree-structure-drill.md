# 树形结构搭建练习

## 训练目标
训练"从一句话长出一篇文章"的能力。刘军强说大多数写作卡住，不是因为没话说，是因为没想清楚"这句话到底要长成什么样"。树形结构解决的就是这个问题。

## 训练说明
每次当你准备写一篇重要文章时，先做这个练习。花30分钟搭好树，后面写正文会顺畅很多。

---

## 今日训练

### 第一步：找种子（5分钟）

不写"我想写XXX"，而是写下10个"为什么"开头的问题。不要筛选，想到什么写什么。

```
示例（话题：远程办公）：
1. 为什么远程办公让一些人效率更高，另一些人反而废了？
2. 为什么明明在家更舒服，却有人想回办公室？
3. 为什么老板普遍不喜欢远程办公？
4. 为什么远程办公省了通勤时间，但大家并没有更快乐？
5. 为什么有些工作适合远程，有些完全不行？
6. 为什么疫情结束后，远程办公反而"退潮"了？
7. 为什么远程办公的会议比办公室还多？
8. 为什么大公司比小公司更难接受远程？
9. 为什么有人说远程办公是"孤独的狂欢"？
10. 为什么远程办公的自由，最后变成了"随时待命"？
```

从10个里选1个最能让你"想写"的。标准：你一看到它就想说点什么。

### 第二步：长出树根（5分钟）

把选中的问题，用"问题三步法"重新打磨。

```
选中：为什么明明在家更舒服，却有人想回办公室？

第一步（研究对象）：远程办公群体中"自愿回办公室"的现象。
第二步（因果追问）：具体而言，为什么在省掉了通勤、拥有了自由之后，反而有人主动想要回到格子间？是真的想念办公室，还是想念办公室所代表的某种东西——比如"下班"这个动作？比如跟同事一起吐槽老板的默契？
第三步（写作目的）：回答这个，是为了让远程办公的倡导者看到"自由"的另一面账单——人需要的不是自由，是有边界的自由。也是为了让老板理解：员工想回来的不是办公室，是"有人知道我在工作"的确认感。
```

### 第三步：长成树干（5分钟）

用一句话说出你的核心观点。这句话必须：
- 能在5秒内被理解
- 让人产生"对，就是这种感觉"
- 哪怕不读全文，只读到这一句话，也有收获

```
❌ 差的树干："远程办公有利有弊，要辩证看待"（废话）
❌ 差的树干："远程办公不适应所有人"（太浅）
✅ 好的树干："想回办公室的人，不是想念办公桌，是想念'下班'——远程办公偷走了工作和生活的边界，自由变成了24小时待命的牢笼。"
```

### 第四步：分出树枝（10分钟）

从树干出发，长出3-4根树枝。每根树枝必须是树干的一个"为什么"或"怎么样"。

**树枝关系选择**：
- 如果是解释原因 → 用**并列**（三个原因导致同一个结果）
- 如果是递进逻辑 → 用**因果链**（A导致了B，B又导致了C）
- 如果观点有争议 → 用**对比**（常见误区 vs 实际情况）
- 如果是解决方案 → 用**步骤**（三步/四步法）

```
示例（树干：远程办公偷走了边界）

🌿 树枝一（并列-原因1）：物理空间的消失
  "通勤不是在浪费时间，是在完成'角色切换'。地铁上的20分钟，你从一个'员工'变成了'自己'。
   远程办公省掉了这20分钟，也省掉了切换——你永远卡在'半个员工半个自己'的状态里。"

🌿 树枝二（并列-原因2）：社交确认的缺失
  "在办公室里，同事看到你在干活，这件事本身就是一种确认。远程办公连这个确认都省了——
   你以为能用产出替代存在感，但人类的大脑不认产出，认的是'有人在看我'。"

🌿 树枝三（并列-原因3）：下班键被删掉了
  "办公室的好处不是能干活，是能'不干活'。下班刷卡那一秒，你正式切换到了'非工作模式'。
   远程办公没有这一秒。你什么时候下班？回完最后一封邮件？那封邮件永远不会是最后一封。"

🌿 树枝四（解决方案）：重新发明边界
  "'假装通勤'——每天上班前出门走一圈，下班后也走一圈。这不是自欺欺人，是用身体动作给大脑发信号。
   你的身体比你的大脑更擅长画线。"
```

### 第五步：给每根树枝挂叶子（5分钟）

每根树枝至少要挂一片具体的"叶子"——案例、数据、引用、或一个让人记住的画面。

```
🌿 树枝一：物理空间的消失
  🍃 案例：Twitter员工把衣柜改成了"办公间"，关上衣柜门就等于下班
  🍃 数据：Buffer的调研显示，49%的远程工作者最大的困难是"下班后无法停止工作"

🌿 树枝二：社交确认的缺失
  🍃 引用：一个Reddit用户说"我开始在Slack上发猫的照片，只是想被看到"
  🍃 画面：深夜11点的工作群里，三个人同时在线，谁也不说话，但都在

🌿 树枝三：下班键被删掉了
  🍃 对比数据：2020年前，平均下班时间是17:43；2020年后变成了19:12，而且越来越晚
  🍃 个人故事：一个产品经理说她开始用"关掉钉钉通知"作为"下班"的替代仪式

🌿 树枝四：重新发明边界
  🍃 方法：一个设计师每晚6点准时换上运动服，"哪怕不运动，换衣服这个动作就够了"
  🍃 方法：把手机放在另一个房间充电，"让焦虑跟手机一起在客厅过夜"
```

## 自查清单

搭建完后，按以下清单逐条检查：

- [ ] 树根是问题还是话题？（必须是一个问题，不能是"我想讲讲XX"）
- [ ] 树干能不能在5秒内让人听懂？（找人念一遍，看对方是不是直接说"懂了"）
- [ ] 树枝和树干之间是不是"因为……所以……"的关系？（如果不是，树枝是假树枝）
- [ ] 每片叶子长在确定的树枝上吗？（如果一片叶子你挂不到任何一根树枝上，删掉）
- [ ] 树枝之间的关系清楚吗？（并列 / 递进 / 对比 / 因果？问自己到底是哪一种）
- [ ] 有没有哪根树枝在重复另一根树枝？（换了个说法但说的是一回事 → 合并）
- [ ] 看完树形结构，一个没读全文的人能不能复述出你大概要说什么？

## 常见失败模式与修复

| 失败模式 | 症状 | 修复 |
|---------|------|------|
| **无根之树** | 有观点没提问，树干直接飘在天上 | 退回去，先写出你要回答的那个问题 |
| **树干太粗** | 一句话说不清楚，要用三四句话解释 | 砍掉修饰，只保留最核心的那一句判断 |
| **树枝乱长** | 分论点之间没有逻辑关系，想到哪写到哪 | 给树枝标上关系类型（并列/递进/对比） |
| **光杆树枝** | 有分论点，没有证据 | 每根树枝至少挂一片叶子 |
| **叶子太多** | 一个观点配了四个案例 | 留最有冲击力的那个，其余删掉 |
| **歪脖子树** | 树干是一个方向，树枝莫名其妙拐到了另一个方向 | 检查每根树枝：它真的是在支撑树干吗？ |
