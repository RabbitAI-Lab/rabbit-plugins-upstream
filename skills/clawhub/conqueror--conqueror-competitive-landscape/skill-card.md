## Description:

Map who wins an SEO market: recurring domains, winning content themes, keyword coverage, backlink strength, and the openings.

This skill is ready for commercial/non-commercial use.

## Use Case:

SEO practitioners, marketers, and developers use this skill to map market-level search competitors, compare winning content themes, assess keyword and authority signals, and identify openings before selecting specific targets.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can use a connected Conqueror MCP server and may access first-party Search Console performance metrics when that integration is connected.

Mitigation: Install and run it only in projects where Conqueror MCP and Search Console access are appropriate for the SEO research task.
