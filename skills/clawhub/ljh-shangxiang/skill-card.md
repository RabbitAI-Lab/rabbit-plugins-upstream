## Use Case:

Ecommerce strategy, merchandising, and content teams use this skill to convert existing product positioning, selling points, scenarios, audience conclusions, and validation evidence into a product-detail page persuasion map, content document, and optional low-fidelity HTML handoff. It is intended for strategy and structure, not final visual design, image generation, production, platform publishing, or compliance approval.

## Known Risks and Mitigations:

Risk: The skill may create a small onboarding marker in the user's home directory and may read or update local ljh-档案 project files for brand-strategy continuity.

Mitigation: Run it only in the intended project directory and tell the agent not to use archives when local persistence is not desired.

Risk: Generated product-detail guidance can become misleading if claims, prices, qualifications, platform rules, or evidence are missing or unverified.

Mitigation: Keep unsupported facts marked as pending, require source-backed evidence for claims, and complete human review before using the strategy in production content.

Risk: The optional HTML output is a low-fidelity structure, not final visual design or production publishing code.

Mitigation: Use the HTML only to review information order and page structure, then hand off to design, compliance, and platform publishing workflows.
