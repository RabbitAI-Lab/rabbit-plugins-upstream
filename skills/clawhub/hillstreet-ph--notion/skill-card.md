## Known Risks and Mitigations:

Risk: Using the skill requires a Notion API token to authenticate requests.

Mitigation: Use a token authorized for the intended workspace and keep it private.

Risk: Commands can create, update, or trash Notion content, and raw API calls can make direct workspace changes.

Mitigation: Review command targets and request details before execution, especially for trash and raw API operations.
