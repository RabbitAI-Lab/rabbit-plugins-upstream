# GEO-CN 更新日志

所有显著变更记录于此。版本遵循语义化版本（MAJOR.MINOR.PATCH）。

## v2.0.4 (2026-09-20)

### 成果报告双格式

- 每次诊断/监测产出两份文件：`.md`（AI 存档伴侣，下次监测自动读取）+ `.html`（客户浏览器直接打开的成品网页报告：评分卡、AI 引用率明细、待办操作指引卡片，内置样式、手机适配）
- 隐私红线：报告含客户地址、电话、经营数据，默认仅落本地，**未经客户同意禁止部署公网**；托管须去敏感字段并使用带随机 token 的 URL

## v2.0.3 (2026-09-20)

### 问询逻辑精修

- 修正 v2.0.2「AI 自查字段不问用户」的过度表述：平台账号改为**先自查、再确认式提问**
- 三种情况必须问（问时附操作指引）：① 无官网或页脚没列账号 ② 封闭平台深度核实需要主页分享链接 ③ 有账号但搜索不到

## v2.0.2 (2026-09-20)

### 小白友好化

- **三级问询清单**：必问仅 3 项（品牌名/地域/行业），每问必附「为什么问 + 举例 + 答不上怎么办」；客户答不上立即降级为审计补全，不追问
- ICP 备案号、平台账号、地图 POI、竞品等 AI 自查字段不再要求用户提供
- 人工自查表附判定标准话术（「回答里出现您的店名就填 ✅」）与平台指引
- **新增第六步：成果报告落盘**——每次诊断/监测产出人类可读报告，待办每条附操作指引与耗时

## v2.0.1 (2026-09-20)

### 冷启动压测修复（10 项可执行性问题）

- **最小可行档案**：品牌名 + 地域 + 行业三项即可开工，消除「档案不完整不得评分」的门禁死锁
- **自主运行模式**：客户不在场时跳过一切询问，全证据阶梯运行
- 第零步前置条件显式化；竞品对比类问题标记可选（有名单才测）
- **AI 实测平台重分组**：百度AI搜索（chat.baidu.com，免登录）为自动化首选；豆包/DeepSeek/Kimi/元宝登录墙直接归入人工路径
- 答案完成判定：正文出现 + 间隔 ≥8 秒双读长度稳定；超时 120 秒记「生成未完成」，不得记为引用缺失
- 提取规则：侧栏对话历史污染规避；每问独立会话
- 引用稳定性规范：诊断基线单次可接受；监测对比关键问题测 2 次取多数
- 附录 A 高德/腾讯路径修正：自动化不可用（滑块验证码+登录墙），仅人工 App 核实
- 内置 AI 实测自查表模板；预检 web_search 探针具体化；标注 L1 检索仅作存在性信号

## v2.0.0 (2026-09-20)

### AI Native 架构重构（自 v1.0.1 的破坏性升级）

**背景**：v1.x 实战首跑 8 个诊断维度误判 3 个（官网漏检、知乎计数失真、社媒矩阵漏盘）。根因：用搜索引擎可见性这一代理指标，推断品牌资产与 AI 引用两个不同的问题。

- **新增第零步：AI 平台实测（地面真值）**——直接在 AI 平台提问客户的「金钱问题」，以 AI 引用率为北极星指标；诊断从推断变为测量
- **分层证据审计**：L1-L5 证据阶梯（关键词检索 → site: 定向 → 直连/API → 浏览器渲染 → 客户确认）+ 负证据硬规则（搜不到 ≠ 不存在；❌ 判定需两级证据且至少一级非 L1；无法核实记 ❓待核查）
- **客户实体档案（强制门禁）**：最小可行档案三项开工，其余字段审计回填；跨平台一致性校验（名称变体、数据口径、POI 名称冲突——AI 实体识别关键信号）
- **封闭平台分治协议**：抖音/小红书等封闭生态禁止用搜索引擎下结论（实测会产生误关联），改用分享短链解析 + 浏览器渲染等实测路径
- **平台数据获取路径速查**（附录 A，全部实测验证）：B站开放 API、知乎主页直读、小红书/抖音分享短链解析、百度地图 POI 公开接口
- **存档 v2 格式**：实体档案 + 记录数组，支持勘误类型，**向后兼容 v1.x 旧存档**（自动转换，历史保留）
- **工具能力预检**：按 web_search / 网页直读 / 浏览器自动化 / 文件写入四项能力自动选择全自动/半自动/最小路径
- 模块 A-E（百科词条/FAQ/知乎问答/新闻稿/内容平台优化）领域知识完整保留，文件自包含
