External agent users, skill authors, maintainers, and teams use this skill to adapt proactive-agent workflow patterns into practical work plans, checklists, templates, scripts, code changes, and reliability guidance. <br>

## Known Risks and Mitigations: <br>
Risk: Broad activation wording may route unrelated work-productivity or task requests into this workflow. <br>
Mitigation: Prefer explicit invocation or narrow the trigger terms before deployment when precise routing is important. <br>
Risk: Generated workflow, checklist, script, or code-change suggestions may be incomplete or incorrect for a user's environment. <br>
Mitigation: Review proposed outputs against the stated success criteria and test scripts or code changes locally before relying on them. <br>
