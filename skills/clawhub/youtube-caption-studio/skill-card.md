## Description:

Turns a YouTube link or pasted transcript into a Chinese spoken script and a remake structure, optionally using public captions and comments.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Content creators and editors can turn a YouTube video's captions or a supplied transcript into a Chinese spoken script and a remake structure that follows the source's beats.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Connecting grants broad Beatra permissions that include media creation and voice changes beyond caption lookup.

Mitigation: Review the displayed permissions before connecting and proceed only if you accept the broader access.

Risk: Caption and related lookups can incur charges.

Mitigation: Check the displayed price and approve each lookup individually before it runs.

Risk: Installation analytics are sent during remote use.

Mitigation: Account for this data sharing and revoke the device in Beatra Console when remote access should end.
