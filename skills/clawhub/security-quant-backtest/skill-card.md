## Known Risks and Mitigations:

Risk: Sample backtesting code can mislead strategy review because evidence.security reports serious correctness flaws in portfolio accounting and signal-execution timing.

Mitigation: Treat the code as an educational template; review, fix, and test accounting and trade-timing behavior before using results for investment decisions.

Risk: Backtesting, walk-forward, and Monte Carlo outputs may be mistaken for forecasts or return guarantees.

Mitigation: Label outputs as simulated research, disclose assumptions and data limits, and avoid presenting them as investment advice or promised performance.
