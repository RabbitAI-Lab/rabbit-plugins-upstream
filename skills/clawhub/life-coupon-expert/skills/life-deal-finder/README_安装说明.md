# life-deal-finder（生活优惠查询器）安装说明

## 这是什么（定位边界）

想点外卖省点钱、喝咖啡有券、订酒店要特价、淘宝买东西想带券——把需求说一句话，现场查最新活动，
直接给**可领取的专属链接、淘口令、小程序卡片**。即问即领，**开箱即用：无需注册、无需配置、无需提供任何密钥**。

不做什么：不代下单、不代支付、不保证优惠 availability（活动实时变化，以平台实际为准）、不缓存囤积旧活动。

## 复核命令

本技能为纯查询转链型，无可执行脚本。复核方式：
1. 把本包导入 Agent 平台技能目录（如 `~/.workbuddy/skills/`）；
2. 对 Agent 说「今天有什么外卖红包能领」；
3. 观察返回的链接是否可领取（链接指向美团/饿了么/淘客官方活动页）。

## 真实输出样例

用户：帮我查下瑞幸最近的优惠券，给我可直接领的链接
预期：返回 1-3 条瑞幸当前有效活动，每条带**可直接点开的领券链接**，附一句活动说明与截止提示。

用户：淘宝搜"手机壳"，给我带券的淘口令
预期：返回带券商品的**淘口令字符串** + 一句复制打开淘宝的提示。
