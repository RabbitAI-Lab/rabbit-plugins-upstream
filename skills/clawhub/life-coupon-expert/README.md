# 生活优惠助手（life-coupon-expert）v1.1.1

聚合外卖红包、美食茶饮、酒店出行与电商优惠券的实时查询专家。用户说出需求，直接给出可领取的优惠入口——**开箱即用，无需注册、无需配置任何密钥**。

## 能力一览

| 能力 | 说明 |
|---|---|
| 外卖红包 | 美团系 / 饿了么系（淘宝闪购）今日可领活动，实时转链 |
| 咖啡茶饮快餐 | 瑞幸、星巴克、肯德基、麦当劳、喜茶、奈雪、华莱士、电影票 |
| 酒店出行 | 同程酒店转链（小程序路径优先） |
| 淘宝找券 | 关键词搜券后价，直接生成淘口令 |

## 架构

- `agents/life-coupon-expert.md` — 专家人设
- `skills/life-deal-finder/SKILL.md` — 九个实测接口速查 + 工作流程 + 输出规范 + 合规红线

依赖：无（接口凭据已内置，即装即用）。

## 凭据与佣金归属

接口凭据与推广位由开发者在包内预置，用户零配置。优惠由平台活动直接提供，用户领券下单的折扣利益不受影响；通过链接产生的推广佣金归开发者。

## 合规

- 不仿冒任何平台官方身份，展示文案不使用平台官方名称与标识
- 不诱导分享、不夸大承诺
- 优惠以平台领取页面实际为准

分类：销售商务（07-SalesCommerce）
