# 定时表达式与时区预览

在明确时区下预览五段式cron的后续时间，检查夏令时与日历规则，不改系统任务。

## 使用

先提供本功能需要的文件或参数，由助手按 `input.md` 的字段准备请求。辅助脚本只离线处理当前工作区，报告与新文件保存在 `exports/`。需要实时网页、办公账户或实际发布时，另用已有授权工具执行并核对结果。

## 输入示例（虚构数据）

```json
{
  "expression": "0 9 * * 1-5",
  "timezone": "UTC",
  "after": "2026-10-26T08:59:00Z",
  "count": 2
}
```
