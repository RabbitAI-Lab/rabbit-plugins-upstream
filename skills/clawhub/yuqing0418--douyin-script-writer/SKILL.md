# 抖音口播脚本生成器（douyin-script-writer）

将一条想法、一个主题或一段素材，转化为可直接录制的竖屏短视频口播脚本。

## 何时使用

- 用户想写抖音 / 快手 / 小红书视频 / TikTok 的口播稿
- 需要「带货 / 剧情 / 科普 / 观点 / Vlog」任一类脚本
- 已有素材或选题，但不知道如何开场、如何留住观众、如何收尾

## 核心能力

1. **选题定调**：一句话提炼核心卖点 / 钩子。
2. **黄金三秒开场**：用「反常识 + 痛点 + 悬念」抓住前 3 秒。
3. **分镜脚本输出**：按时间轴输出「画面 / 口播 / 字幕 / BGM 提示」。
4. **完播率优化**：控制时长、节奏卡点、循环结尾与互动引导。

## 工作流程

1. 确认主题、目标人群、时长（默认 30–60 秒）与风格。
2. 生成 3 个备选「开场钩子」，请用户挑选或合并。
3. 按以下结构生成完整脚本：

   - 0–3s 钩子：一句话制造冲突或悬念
   - 3–15s 铺垫：讲出用户痛点或背景
   - 15–45s 主体：给出信息/方法/证据（用「你」「因为」「所以」句式）
   - 45–55s 情绪高点：金句 / 反转 / 呼吁
   - 55–60s 互动收尾：引导点赞、关注或评论

4. 输出 Markdown 分镜表，可直接照读录制。

## 输出格式（模板）

| 时间 | 画面 | 口播内容 | 字幕/花字 | BGM/音效 |
|------|------|----------|-----------|----------|
| 0-3s | 特写+大标题 | …… | …… | 密集鼓点 |

## 示例

见同目录 `examples.md`（含一条完整 60 秒口播脚本样例）。

## 注意事项

- 口语化：用「你」不用「大家」，用短句不用长句。
- 一句话一个信息点，避免信息过载。
- 结尾务必给一个明确的互动指令（提问 / 投票 / 收藏理由）。
