# 🔮 易经卦象解读助手 — 使用说明

## 这个 Skill 是做什么的？

当你求得一个易经卦象后，输入卦名和变爻，自动生成一份结构化的解卦报告。

**不是给你讲一堆古籍原文，而是告诉你：这个卦在说啥，你应该怎么做。**

---

## 快速开始

### 最低输入

```
卦名：乾为天
```

### 推荐输入

```
卦名：火水未济
变爻：六五爻变
背景：正在考虑要不要离职创业
问题：这个时候创业合适吗？
```

---

## 如何判断结果好不好？

### ✅ 好的解读

- 逐爻都有覆盖（初爻到上爻都解读）
- 有具体行动建议（不是"多行善事"这种废话）
- 变爻单独重点分析
- 字数在 600-1200 字之间

### ❌ 需要重新生成的信号

- 只讲古文不解释
- 建议模糊空洞（如"顺其自然"）
- 缺爻（少了一爻没解读）
- 字数过短（低于 400 字）

---

## 限制说明

- 只能解读六十四正经卦
- 梅花易数、火焰济等特殊卦法不在范围内
- 本解读仅供参考，不构成命运判定
- 重大决策请结合多方信息审慎判断
