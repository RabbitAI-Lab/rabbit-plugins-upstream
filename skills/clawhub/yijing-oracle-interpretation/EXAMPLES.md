# 🔮 易经卦象解读助手 — 使用示例

以下展示三个不同场景的真实输入与输出：

---

## 示例一：投资决策场景

### 用户输入

```
卦名：风雷益
变爻：六二爻变
背景：手上有笔闲置资金，考虑要不要投入股市
问题：现在进场时机合适吗？
```

### 技能输出（精简版）

---

### 🌿 风雷益卦 · 第六爻变

**核心主题**：损上益下，借势而为

益卦的核心是"受益"——当你做的事能让他人受益，天地都会来帮助你。风雷相益，象征顺势而为、借力打力。

---

#### 逐爻解读

**初九**：利用为大作 → 起步要大胆，但要有根基
**六二**：永贞之吉 / 或益之十朋之龟 → 中正之道，坚守正道自然有收获（变爻重点）
**六三**：有孚中行 / 告公用圭 → 诚信行走，不要走偏门
**六四**：中行告公从 / 利用依幕 → 依附强者，借势前行
**九五**：有孚惠心 / 勿问元吉 → 施惠于人，最终自己也受益
**上九**：莫益之 / 或击之 → 贪得无厌会招来攻击

---

#### 主卦判断

**当前能量状态**：发展期，益卦意味着你处于一个"可以借势"的阶段  
**关键警示**：不要急功近利，靠谱比暴利重要  
**有利方向**：做能帮助他人的事，顺势而为

#### 变爻影响

六二阴爻居中得正，是卦中至善之爻。此爻变化带来的影响：**你的谨慎和正道选择是正确的，保持这个节奏，不要被短期的诱惑带偏。**

---

#### 行动建议

1. **当下最该做**：先把资金分批规划，不要一把梭哈进场
2. **要避免的事**：不要只想着"我要赚多少"，要思考"我的投资对市场有什么价值"
3. **建议时间窗口**：可以分3批进场，第一批试水（不超过总资金的30%）
4. **补充思考**：考虑自己的风险承受能力，而不是只看市场机会
5. **再次确认时机**：如果市场出现剧烈波动，不要急着追加

---

#### 精简结语

> 风雷益告诉你：**机会是存在的，但要用正道的方式去抓住它。** 股市有风险，此卦提醒你：慢一点、稳一点，反而快一点。

*本解读仅供参考，不构成投资建议。决策自主，后果自负。*

## 示例二：感情场景

### 用户输入

```
卦名：泽山咸
背景：和暧昧对象关系进展顺利，想知道下一步该怎么推进
问题：要不要主动表白？
```

### 技能输出（精简版）

---

### 💑 泽山咸卦 · 综合解读

**核心主题**：心心相印，以诚动人

咸卦是易经中专门讲感情的卦——"咸"者，感也。少男少女以诚相感，心意相通。泽山相临，象征柔软的心与坚实的行动结合。

---

#### 逐爻解读

**初六**：咸其拇 → 刚开始有感觉，还不到行动的时候  
**六二**：咸其腓 / 凶 / 居吉 → 急于求成会坏事，耐心反而吉  
**九三**：咸其股 / 执其随 → 被对方牵着走，没有自己的主见  
**九四**：贞吉 / 悔亡 / 幢幢往来 / 乃无悔 → 保持真诚地互动，不会有问题  
**九五**：咸其脢 / 无悔 → 情感表达适度，不过火  
**上六**：咸其辅 / 颊 / 舌 → 光说不做，最终没有实质进展

---

#### 主卦判断

**当前能量状态**：感知期，感情在萌芽，节奏很重要  
**关键警示**：不要操之过急，也不要只停留在暧昧  
**有利方向**：真诚互动，适度推进

---

#### 行动建议

1. **当下最该做**：继续保持真诚互动，不要刻意表现或者讨好
2. **要避免的事**：不要突然表白——咸卦的节奏是"感而遂通"，水到渠成
3. **建议时间窗口**：观察对方的反馈信号，如有回应则可推进
4. **补充思考**：你想表白是为了对方的回应，还是真的准备好了？

---

#### 精简结语

> 泽山咸告诉你：**感情是相互感应的过程，不是单方面的进攻。** 真诚地互动，观察对方的回应，顺着感觉走，比刻意表白更有效。

*感情决策需自行判断，本解读仅供参考。*

## 示例三：职业转型场景

### 用户输入

```
卦名：天山遁
背景：现在的工作做得很痛苦，想辞职转行
问题：要不要辞职去追梦？
```

### 技能输出（精简版）

---

### 🏔️ 天山遁卦 · 综合解读

**核心主题**：知进退，当退则退

遁卦不是消极的逃跑，而是**主动的战略转移**。天山之上，君子看到趋势已变，选择先退一步，保存实力，以待时机。

---

#### 逐爻解读

**初六**：遁尾 / 厉 / 勿用有攸往 → 退得太慢会有危险，现在就要开始规划  
**六二**：执之用黄牛之革 / 莫之胜说 → 拖延是最危险的，想法定了就执行  
**九三**：系遁 / 有疾 / 厉 / 畜臣妾 → 被琐事和人牵绊，要有决断  
**九四**：好遁 / 君子吉 / 小人否 → 有实力的人能优雅转身  
**九五**：嘉遁 / 贞吉 → 完美时机，果断行动  
**上九**：肥遁 / 无不利 → 完全超脱，没有任何坏处

---

#### 主卦判断

**当前能量状态**：转折期，遁卦告诉你：可以走了  
**关键警示**：不要裸辞，先退后一步再跳  
**有利方向**：做好充分准备后转身，而不是被逼逃跑

---

#### 行动建议

1. **当下最该做**：不要急着辞职，先把"追梦"的路径想清楚
2. **要避免的事**：不要被负面情绪推着走——"痛苦"不等于"该走"，要先区分
3. **建议时间窗口**：给自己3-6个月准备期，边工作边准备
4. **补充思考**：你的"梦想"是什么——是一个清晰的职业方向，还是只是对现状的逃避？
5. **再次确认时机**：当你准备好Plan B（哪怕是6个月生活费存款）再行动

---

#### 精简结语

> 天山遁告诉你：**退是一种智慧，不是懦弱。** 但真正的遁，是有准备的离开，而不是被逼走的逃跑。准备好你的"逃生舱"，再跳。

*职业决策重大，请综合多方面因素判断，本解读仅供参考。*
