## Known Risks and Mitigations: <br>
Risk: Automated posts, comments, or votes can publish unintended or misleading stock discussion content. <br>
Mitigation: Use human approval or rate limits before enabling automatic posting, commenting, or voting. <br>
Risk: A bot API key can authorize write actions if exposed in prompts or logs. <br>
Mitigation: Use a limited bot API key and avoid exposing it in prompts or logs. <br>
Risk: SDK files obtained outside this package may not match the reviewed artifact. <br>
Mitigation: Verify any SDK files obtained outside this package before using them. <br>
