# Examples：术语一致性与搭配自然度（Terminology & Collocation）

---

## Example ID：TM-01

Source：Johnson et al., 2021, *Journal of Environmental Psychology*

Dimension：Vocabulary — 术语一致性

Type：Positive Example

Original Sentence：
"reaction time scores from the executive attention portion of the ANT (see Supplemental Materials 2 for means and standard deviations from executive, orienting, and alerting portions)"

Why it is useful：
全文严格统一使用 executive attention（而非 executive control），ANT 三成分（executive / orienting / alerting）命名贯穿标题—方法—结果；只报告部分指标时明确交代其余指标去向。

Reusable Rule：
同一构念选定一个术语贯穿全文（标题、方法、结果、讨论同形）；只分析部分指标时注明其余指标的数据位置（见补充材料）。

Possible Application：
诊断时检索用户全文中同一构念的所有变体（如 executive attention / executive control / executive functioning 混用），列出出现位置并要求统一。

## Example ID：TM-02

Source：Harvey, 2019, *Dialogues in Clinical Neuroscience*

Dimension：Vocabulary — 术语一致性

Type：Positive Example

Original Sentence：
"Attention deficit hyperactivity disorder (ADHD) is associated with increases in errors of commission and greater B, based on impulsive responses to nontarget stimuli."
"The prototypical manipulation working memory task is digit span backwards, where the participant is asked to recall information in reversed order compared with presentation."

Why it is useful：
术语首现"全称（缩写）"后文统一缩写；子域术语 maintenance / manipulation working memory 全文严格区分；"The prototypical X task is Y, where ..." 是固定定义句式。

Reusable Rule：
缩写规则：首现写全称+括号缩写，之后统一缩写，不再全称/缩写混用；定义句式用 "The prototypical X task is Y, where ..."。

Possible Application：
扫描用户文中缩写使用：首现未定义、全称缩写混用、多个缩写指同一概念，均为命中项。

## Example ID：TM-03

Source：Toba et al., 2024, *Neuropsychology Review*

Dimension：Vocabulary — 术语一致性 / 镜像对照句

Type：Positive Example

Original Sentence：
"...inhibition over the left lateral frontal cortex significantly worsened letter-cue fluency performance when compared to the sham condition, whereas rTMS inhibition over the right lateral frontal cortex significantly improved letter-cue fluency performance when compared to the sham condition..."
"...glossary definitions are henceforth indicated by a superscript 'G'"

Why it is useful：
左右半球对照句句法完全镜像（significantly worsened / significantly improved ... when compared to the sham condition），对照条件命名 sham condition 一致复现；术语密集论文用统一符号标记并声明约定（"henceforth indicated by..."）。

Reusable Rule：
对比句保持镜像句法（仅替换方向词与脑区），条件名固定复现；术语密集文稿可声明标记约定并全文执行。

Possible Application：
用户对照组命名漂移（sham / control group / placebo condition 指同一条件）时，要求锁定一个名称。

## Example ID：TM-04

Source：Chen et al., 2020, *Journal of Environmental Psychology*

Dimension：Vocabulary — 术语一致性 / 搭配

Type：Positive Example

Original Sentence：
"A linear regression analysis found that the general brain connectivity index in the theta band could predict 39.54% (adj R2 = 37.53%) of the variance (coef. = 2.41, 95% CI [1.30, 3.52], p < 0.001, Fig. 9-a) in the perceived coherence as measured by the PRS coherence score."

Why it is useful：
全文统一使用 alpha-theta oscillations / synchronization、perceived coherence、attention restoration，标题→摘要→结果→讨论零漂移；"as measured by + 工具名" 交代测量出处，"predict X% of the variance in Y" 是回归报告固定搭配。

Reusable Rule：
核心构念命名一次定稿，各章节复现同一词形；测量出处用 "as measured by + 工具名"；回归用 "predict X% of the variance in Y"。

Possible Application：
检查用户核心术语在摘要、方法、结果中的词形是否一致；回归结果缺测量出处时补充。

## Example ID：TM-05

Source：Rhee et al., 2023, *Scientific Reports*

Dimension：Vocabulary — 术语一致性

Type：Positive Example

Original Sentence：
"The three sites showed statistically significant differences in DTR in the anterofrontal (F [2, 58] = 3.755, p = 0.029, ɳp² = 0.115) and occipital regions."

Why it is useful：
脑电指标缩写（DTR/TBR/ABR）首次全称+括号缩写后统一使用缩写；脑区名 anterofrontal / occipital regions 全文拼写固定。

Reusable Rule：
指标缩写首现定义后统一缩写；解剖/区域名全文固定拼写，不混用变体（如不混用 PFC 与 prefrontal cortex，除非已定义约定）。

Possible Application：
扫描用户文中同一指标的多种写法（如 theta/beta ratio、TBR、θ/β ratio 混用）。

## Example ID：TM-06

Source：Song et al., 2022, *IJERPH*

Dimension：Vocabulary — 术语一致性

Type：Positive Example

Original Sentence：
"In the case of POMS-Fatigue, the pooled effect size was -0.84, with a 95% confidence interval of -1.15 to -0.54."

Why it is useful：
pooled effect size、95% confidence interval 全称在首次/图注出现，正文用 ES/CI 缩写；全文 green space exposure、restorative effects、random effects model 零漂移。

Reusable Rule：
元分析核心术语锁定：pooled effect size (ES)、confidence interval (CI)、random effects model；干预名（green space exposure）全文不变体。

Possible Application：
用户混用 green space / green exposure / nature exposure / natural environment 指同一干预时，列出变体出现位置并要求统一。

## Example ID：TM-07

Source：Toba et al., 2024, *Neuropsychology Review*

Dimension：Vocabulary — 搭配自然度

Type：Positive Example

Original Sentence：
"...the meta-analysis of Brunoni and Vanderhasselt (2014) reported that non-invasive stimulation on the DLPFC was associated with faster RTs, a higher percentage of correct responses and a lower percentage of error responses in this task."
"A comparison between stimulation methods showed that rTMS on the DLPFC generally improved the working memory measures, whereas the tDCS only improved RTs in the n-back task."

Why it is useful：
三联平行指标（faster RTs, a higher percentage of ..., a lower percentage of ...）句式整齐；"A comparison between X and Y showed that X generally ..., whereas Y only ..." 用限定语精确区分效应范围。

Reusable Rule：
多指标结果用平行结构 "was associated with faster X, a higher percentage of Y and a lower percentage of Z"；方法比较用 "A comparison between X and Y showed that..."。

Possible Application：
用户多指标结果句式散乱（每个指标各起一句且结构不同）时，示范平行整合。

## Example ID：TM-08

Source：Harvey, 2019, *Dialogues in Clinical Neuroscience*

Dimension：Vocabulary — 搭配自然度

Type：Positive Example

Original Sentence：
"...it tends to be the strongest predictor of overall cognitive performance, on cognitive assessment batteries, loading most highly on single factor solutions of cognitive ability."

Why it is useful：
"loading (most highly) on (single factor solutions)" 是因子载荷的规范搭配；"the strongest predictor of" 是预测力比较固定搭配。

Reusable Rule：
因子分析搭配："X loaded (most) highly on factor Y"；预测结果："X was the strongest predictor of Y"。

Possible Application：
用户写 "the loading of X on factor Y was the biggest" 时，升级为规范搭配。

## Example ID：TM-09

Source：Posner & Petersen, 1990, *Annual Review of Neuroscience*

Dimension：Vocabulary — 搭配自然度

Type：Positive Example

Original Sentence：
"Data from normal human subjects required to filter out irrelevancies showed selective metabolic increases in the pulvinar contralateral to the field required to do the filtering."

Why it is useful：
"Data from [条件] showed [方向性形容词+名词化结果]" 是"让数据说话"的经典句式；selective 修饰 increases 体现精确性；contralateral to 是解剖方位规范介词搭配。

Reusable Rule：
结果名词化句式："Data from [条件] showed [形容词 + 名词化结果] in [部位/指标]"；领域固定介词搭配（contralateral to, projection of/to）不得随意替换。

Possible Application：
用户写 "The data let us know that..." 时替换为 "Data from ... showed ..."。

## Example ID：TM-10

Source：构造问题例（对照 TM-01/02/06）

Dimension：Vocabulary — 术语不一致

Type：Problem Example

Original Sentence：
（同一段 Results 内）"The executive control network showed greater activation ... Executive attention scores did not differ ... The EC network was involved in ..."

Why it is useful：
同一构念在 3 句内出现 executive control network / executive attention / EC network 三种变体，读者无法确认是否同一概念；且缩写 EC 未定义。

Reusable Rule：
诊断流程：提取全文核心术语 → 列出所有变体及出现位置 → 要求用户锁定一个术语 → 首现定义缩写后统一使用。

Possible Application：
标准 Before / After：
Before: "The executive control network showed greater activation ... Executive attention scores did not differ ... The EC network was involved in ..."
After: "The executive attention network (EAN) showed greater activation ... EAN scores did not differ ... The EAN was involved in ..."

## Example ID：TM-11

Source：构造问题例（对照 VB 类各条，中式搭配合集）

Dimension：Vocabulary — 搭配自然度

Type：Problem Example

Original Sentence（合集）：
a) "We did a significant difference between the two groups."
b) "The two variables have obvious correlation."
c) "The result happened in the nature condition."
d) "We made an interaction analysis between age and condition."

Why it is useful：
集中展示中式英语搭配：a) do a difference → 应为 found/obtained a significant difference 或 the difference was significant；b) have obvious correlation → 应为 was significantly correlated with / showed a strong correlation；c) result happened → 应为 the effect emerged/was observed；d) made an analysis → 应为 conducted/performed an analysis。

Reusable Rule：
高频搭配纠错表：
- do/make a difference → find/observe a significant difference
- have correlation → be correlated with / show a correlation
- result happened → effect emerged / was observed
- make an analysis → conduct/perform an analysis
- big/small effect → large/small effect size

Possible Application：
逐条扫描用户草稿命中上述搭配时，直接引用对应替换规则给出 Before / After。
