# Checklist：Results 词汇与搭配逐项检查表

诊断时按以下顺序逐项检查。每项命中则记录：原句 → 问题类型 → 严重程度（高/中/低）。

## 0. 范围确认

- [ ] 是否只诊断 Results 部分？（混入的 Discussion 解释句只做词汇标记，不做结构判断）
- [ ] 是否已读取上游成员 A/B/C 的输出，避免重复报告结构、统计格式、时态语法问题？

## 1. 口语化表达

- [ ] 是否存在口语动词：look at / get / got / do / make / have（作实义动词表"存在"）/ turn out / show up？
- [ ] 是否存在口语强化词：very / really / super / huge / a lot of / lots of / basically / actually / obviously？
- [ ] 是否存在缩略形式：don't / can't / didn't / it's？
- [ ] 是否存在模糊量词：some / many / a few（应替换为具体数值或比例）？
- [ ] 是否存在第一人称口语视角：we can see / you can see / let's look at？
- [ ] 命中项是否已对照 VB-10 / RQ-10 / FT-08 给出替换？

## 2. 学术动词

- [ ] 每个结果句的报告动词是否与证据类型匹配？（相关/横断面 → associated with/correlated with；实验 → induced/showed；元分析 → pooled estimate indicated；对照 VB-02/04/07）
- [ ] 是否存在 prove / confirm / establish 修饰单研究结论？（高严重度）
- [ ] 阴性结果是否使用规范措辞：did not significantly differ from / had no significant effect on / No association was found？（对照 VB-04/08, RQ-06）
- [ ] 结果→解释是否用 suggesting/indicating 分层，而非直接断言？（对照 VB-09）
- [ ] "自己结果"（过去时 showed）与"领域共识"（has been shown）的动词形式是否区分？（对照 VB-06）

## 3. 图表邀请语

- [ ] 每个图/表首次引用是否有内容性引导（Figure X shows...），而非仅 "(see Figure X)"？（对照 FT-01/02）
- [ ] 是否存在 "the picture / the graph above / the following figure" 等不规范指称？
- [ ] 同一段落内邀请句式是否有变化（shows / as shown in / 句末括号交替）？（对照 FT-04）
- [ ] 次要图表是否使用括号嵌入而非另起整句？（对照 FT-05/07）
- [ ] 指向图内具体元素时是否具体化（"(gray area in Figure 1)"）？（对照 FT-06）
- [ ] 图表编号与实际图表清单一一对应？（用户未提供清单时跳过并注明）
- [ ] 正文引用的图号是否连续递增、与各图注编号一致？（如图注编号与正文引用错位、同一图号对应两张不同的图，属高严重度）
- [ ] 是否存在逐字重复的模板句（如异质性报告句、结果解释句在多个小节中原样复现）？重复即标记为冗余，建议删减或改写。

## 4. 结果描述词

- [ ] significant 是否仅用于统计显著，且附统计量/p 值？（歧义用法对照 RQ-11）
- [ ] 是否存在 very/quite/highly significant 类修饰？（对照 RQ-10）
- [ ] 边缘结果（.05 < p < .10）措辞是否规范：though not significant / despite the potential trend，而非 "almost significant" + 强结论？（对照 RQ-04）
- [ ] 校正后不显著是否如实报告？（对照 RQ-02）
- [ ] 亚组显著是否限定 "significant only among ..."？（对照 RQ-08）
- [ ] robust 是否仅修饰跨研究/跨样本可复现发现？（对照 RQ-07）
- [ ] 与理论/前人结果的关系是否用 consistent with / compatible with / fits well with，而非 prove？（对照 RQ-05/09）

## 5. 术语一致性

- [ ] 提取文中全部核心构念，逐一检查是否存在 2 种以上变体？（对照 TM-01/10）
- [ ] 每个缩写是否首现"全称（缩写）"定义？定义后是否统一使用缩写？（对照 TM-02/05）
- [ ] 对照条件、组别、干预名称是否全文锁定一个名称？（对照 TM-03/06）
- [ ] 脑区/量表/仪器名拼写是否全文固定，无变体混用？（对照 TM-05）
- [ ] 核心术语在摘要—方法—结果—讨论之间词形是否一致？（对照 TM-04）

## 6. 搭配自然度

- [ ] 是否存在 TM-11 纠错表中的中式搭配（do a difference / have correlation / make an analysis / big effect）？
- [ ] 统计术语搭配是否正确：main effect of / interaction between X and Y / post hoc tests showed / loaded on factor / predict X% of the variance in？（对照 TM-07/08）
- [ ] 领域固定介词搭配是否正确：associated with / correlated with / consistent with / relative to / compared to？（介词误用是高频问题）
- [ ] 平行结构列举多指标时句式是否平行？（对照 TM-07）

## 7. 输出质量自检

- [ ] 是否有明确的问题定位（引用原句）？
- [ ] 是否引用了 examples 作为依据（标注 Example ID）？
- [ ] 是否给出 Before / After 示例？
- [ ] 是否说明问题严重程度（高/中/低）？
- [ ] 是否给出可操作的修改建议（可复用规则）？
- [ ] 是否避免做超出本 Skill 范围的判断（结构→A、统计格式→B、时态语法→C、衔接→E、claim强度→F，均在 Handoff Notes 中转介）？
- [ ] 是否按照 rubric 完成 1—5 分评分并写明理由？
- [ ] 是否输出结构化诊断报告（Dimension Score / Key Problems / Evidence / Comparison / Suggestions / Priority / Handoff Notes），可供成员 G 直接整合？
