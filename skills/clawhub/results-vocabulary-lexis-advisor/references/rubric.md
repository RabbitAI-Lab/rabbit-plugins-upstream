# Rubric：Results 词汇与搭配评分标准（1—5 分）

评分对象：英文心理学论文 Results 部分的学术词汇与搭配质量。六个子维度：口语化表达、学术动词、图表邀请语、结果描述词、术语一致性、搭配自然度。

---

## 5 分：高度符合 Results 写作规范，几乎无需修改

表现包括：

- 全文无口语化表达（无 a lot of / big / get / do / make 类口语动词，无 very / super / huge 类口语强化词，无缩略形式 don't / can't）；
- 学术动词强度与证据类型完全匹配：直接结果用 show/reveal/find，相关证据用 be associated with，推测用 suggest/appear to，无 prove/clearly 类越级动词；
- 图表邀请语规范且有变化："Figure X shows..." / "As shown in Fig. X, ..." / 句末 "(Fig. X)" 交替使用，每个图表都有内容性引导（对照 FT-01 至 FT-07）；
- 结果描述词精确：significant 仅指统计显著并附统计量，阴性/边缘结果措辞规范（对照 RQ-01 至 RQ-04）；
- 核心术语全文零漂移，缩写首现定义后统一（对照 TM-01、TM-02）；
- 搭配全部自然，无中式英语；
- examples 对照后基本符合优秀论文写法。

## 4 分：整体规范，仅有少量表达问题

表现包括：

- 基本无口语化表达，偶有 1 处轻微非正式用词；
- 动词强度基本匹配，个别动词可微调（如该用 suggest 处用了 show）；
- 图表邀请语规范但句式略单调（连续 3 句以上同一句式）；
- 结果描述词基本准确，1—2 处可补充限定（如亚组显著未限定 only among）；
- 术语基本一致，存在 1 处次要变体；
- 个别搭配可优化（1—2 处），不影响理解。

## 3 分：基本可用，但有明显词汇问题

表现包括：

- 存在多处口语化表达（3—5 处），如 "got better"、"looked at the data"；
- 动词强度有失配：如相关研究用 demonstrate，或零结果用 "no effect at all" 绝对化表达；
- 图表引用混乱：部分图只有 "(see Figure X)" 无内容引导，或出现 "the picture above"；
- significant 存在歧义用法（统计义与"重要"义混用，对照 RQ-11）；
- 核心术语存在 2 种变体，但结合语境尚可辨认；
- 存在 3 处以上中式搭配（对照 TM-11 纠错表）；
- 需要中等程度修改。

## 2 分：问题较多，影响可读性和学术规范性

表现包括：

- 口语化严重（5 处以上），段落读起来像实验记录而非论文；
- 动词强度频繁失配：prove / obviously / clearly 修饰单研究因果结论；
- 图表邀请语大面积缺失或不规范；
- 阴性结果被隐瞒或表述为 "almost significant" 并据此下强结论；
- 核心术语 3 种以上变体混用，同一概念前后无法确认（对照 TM-10）；
- 中式搭配密集，多处需要重写句子；
- 需要大幅修改。

## 1 分：严重不符合 Results 写作要求，需要大幅重写

表现包括：

- 全篇口语化，不具备学术语域特征；
- 动词与证据完全脱节（如横断面数据写 "X caused Y, proving that..."）；
- 无任何规范图表引用；
- 术语完全混乱，无法追踪变量指称；
- 无法形成有效词汇诊断报告之外的其他选择——只能建议重写。

## 子维度扣分参考

| 命中问题 | 严重程度 | 评分影响 |
|---|---|---|
| prove / obviously 修饰单研究结论 | 高 | 直接降至 ≤3 |
| 术语 3 种以上变体 | 高 | 直接降至 ≤3 |
| 口语化动词 ≥5 处 | 高 | 直接降至 ≤3 |
| "the picture / we can see" 类图表语 | 中 | 每类降 0.5—1 |
| "almost/marginally significant" 强结论 | 中 | 降 1，并转介成员 F |
| significant 歧义用法 | 中 | 降 0.5—1 |
| 句式单调（同句式 ≥3 次） | 低 | 降 0.5 |
| 单个中式搭配 | 低 | 累计 ≥3 处降 1 |

评分最终取整数（1—5）。边界情况按"就低不就高"处理，并在评分理由中说明。
