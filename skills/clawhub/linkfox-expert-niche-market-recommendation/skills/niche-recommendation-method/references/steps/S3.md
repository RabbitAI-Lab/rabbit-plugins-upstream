# S3: 排序输出

## 输入
- S2 评分结果
- S1 被淘汰的市场（附淘汰原因）
- sortBy 参数

## 排序

根据 sortBy 参数选择排序方式：
- `demand`: 按需求量降序
- `growth`: 按季度增长率降序
- `score`: 按综合评分降序

排序后：通过过滤的市场在前，被淘汰的市场在后。

## 分级

| 评分范围 | 推荐等级 | 标记 |
|----------|----------|------|
| ≥ 60 | 强烈推荐 | ★ |
| ≥ 45 | 推荐 | ✓ |
| ≥ 30 | 谨慎考虑 | ? |
| < 30 或被淘汰 | 不推荐 | ✗ |

## 输出

- JSON 文件：完整推荐清单（含通过+淘汰）
- stdout：摘要表格（排名/市场名/推荐等级/评分/需求量/周搜索/Top5占比/增长率/淘汰原因）
- 淘汰的市场 `eliminationReason` 标注原因，通过的市场 `eliminationReason=null`

## 输出字段

排名、nicheTitle、translationZh、recommendation、score、competition、demand、searchVolumeWeekly、unitsSoldWeekly、productCount、brandCount、top5ClickShare、cpc、avgPrice、growth、successfulLaunches、eliminationReason
