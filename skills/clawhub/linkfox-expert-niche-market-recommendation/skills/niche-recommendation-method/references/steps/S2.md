# S2: 评分

## 输入
- S1 通过硬过滤的市场池
- scoreWeights 权重配置

## 评分公式（5维度，0-100分）

各维度先归一化到 0-1（在该批次市场内做 min-max 归一化），然后加权求和 × 100：

```
score = w_demand × norm(demand)
      + w_growth × norm(growth)
      + w_competition × (1 - norm(top5ClickShare))
      + w_diversity × norm(brandCount)
      + w_newproduct × norm(successfulLaunches)
```

### 默认权重

```json
{"demand": 0.30, "growth": 0.25, "competition": 0.20, "diversity": 0.15, "newproduct": 0.10}
```

### 归一化方式

- demand: min-max 归一化
- growth: min-max 归一化（负增长的市场 growth 值为负数，归一化后得分低）
- top5ClickShare: min-max 归一化后取反（1 - norm），垄断越低得分越高
- brandCount: min-max 归一化
- successfulLaunches: min-max 归一化

### 特殊处理

- 若 successfulLaunches 全部为 0，则 newproduct 维度贡献为 0，其余维度权重等比放大
- 若某字段缺失，该维度贡献为 0

## 输出
- 每个市场的综合评分（0-100，保留1位小数）
