# S0: 极目查细分市场

## 输入
- seedKeyword: 种子关键词
- marketplace: 站点（US/JP/DE）

## 操作
1. 调用 `linkfox-jiimore-get-niche-info-by-keyword`，参数：
   ```json
   {"keyword": "<种子词>", "countryCode": "US", "pageSize": 100, "sortField": "unitsSoldT7", "sortType": "desc", "page": 1}
   ```
2. 检查返回的 `total` 字段，若 total > 100 则翻页：
   - page=2: `{"keyword": "...", "countryCode": "US", "pageSize": 100, "page": 2, ...}`
   - 某页返回条数 < pageSize 即停止，不再调下一页
3. 合并所有页的 `data` 数组，去重（按 nicheId）
4. 从每个 niche 提取以下字段：
   - nicheId, nicheTitle, translationZh
   - demand, searchVolumeWeekly, unitsSoldWeekly
   - productCount, brandCount
   - top5ProductsClickShare, top5BrandsClickShare
   - cpc (low/medium/high)
   - avgPrice, minimumPrice, maximumPrice
   - searchVolumeGrowthQuarterly
   - successfulLaunchedSemiannual, launchRateSemiannual
   - returnRateAnnual, acos, breakEvenRatio

## 输出
- 细分市场列表，每个含上述字段

## 落盘注记
- 落盘：极目脚本自动保存JSON到会话目录
- 读取：从保存的JSON文件读取 data 数组
- 判定：响应含 errcode=200, total, data 数组
