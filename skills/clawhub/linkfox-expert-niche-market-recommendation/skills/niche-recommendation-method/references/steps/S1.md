# S1: 硬过滤

## 输入
- S0 的细分市场列表
- 可配置参数

## 操作（按顺序判定，任一命中即淘汰）

| 条件 | 判定 |
|------|------|
| searchVolumeWeekly < minSearchVolume | 淘汰-搜索量过低 |
| top5ProductsClickShare > monopolyThreshold | 淘汰-头部垄断 |
| brandCount < minBrands | 淘汰-品牌极少 |
| searchVolumeGrowthQuarterly < maxDeclineRate | 淘汰-市场萎缩 |
| returnRateAnnual > maxReturnRate | 淘汰-退货率高 |
| avgPrice < minPrice（若设） | 淘汰-价格过低 |
| avgPrice > maxPrice（若设） | 淘汰-价格过高 |
| cpc.medium > maxCPC（若设） | 淘汰-广告成本过高 |
| productCount > productCountMax（若设） | 淘汰-商品数超限 |

## 输出
- 通过过滤的市场池 + 被淘汰的市场（标注淘汰原因）

## 竞争度分级

| 条件 | 竞争度 |
|------|--------|
| top5ClickShare > monopolyThreshold | 高 |
| productCount > 50 且 demand < 100000 | 高 |
| productCount > 50 | 中 |
| productCount >= 20 | 中 |
| productCount < 20 | 低 |
