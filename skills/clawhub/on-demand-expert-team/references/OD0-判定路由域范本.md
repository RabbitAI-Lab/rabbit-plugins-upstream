## OD0-判定路由域范本

### 范本概述

OD0 域全任务范本，覆盖 OD0-01/OD0-02/OD0-03 全部任务的产物样式。示例任务为「撰写一份行业研究报告」（示例内容均为演示格式用，业务数据以实际任务为准）。

### 范本正文

**【OD0-01 任务接收与需求感知】需求信息表**：

```markdown
## 需求信息表

- **用户任务**：撰写一份行业研究报告
- **交付物形态**：研究报告（Markdown→可导出）
- **关键约束**：覆盖市场规模、竞争格局、趋势判断三部分；结论需有数据支撑
- **已有材料**：用户提供的 2 份往期报告（本地文件）
- **质量要求**：多角度交叉验证；数据不确定处标注"待验证"
- **语言**：中文
```

**【OD0-02 专家团必要性判定】判定记录**：

```markdown
## 组团判定记录

**判定结果**：组团（小型专家团）

**判定依据**（对照组建判断标准逐条核对）：

| 条件 | 阈值 | 本任务 | 是否满足 |
|------|------|--------|---------|
| 专业领域数 | ≥2 | 资料调研 + 数据分析 + 撰写 + 审核交叉验证 | ✅ |
| 子任务数 | ≥3 | 采集→分析→撰写→审核，4 个 | ✅ |
| 协作依赖数 | ≥2 | 撰写依赖调研与分析产出；审核依赖撰稿完成 | ✅ |
| 质量要求 | 高 | 用户明确要求交叉验证 | ✅ |

**结论**：4 项标准全部满足，组建小型专家团；判定依据已向用户展示。
```

**【OD0-03 运行方案规划】运行方案**：

```markdown
## 运行方案

- **团队形态**：小型专家团（编排者 + 5 名成员，覆盖调研/数据/撰写/审核 4 个领域）
- **拉起机制三态判定**：
  - 环境工具核对：当前会话可用子代理（Agent）工具，不可用团队工具 → **态2 子代理态**
  - 实例化方式：每成员以子代理拉起，name 参数传成员角色名（中文）；本会话承担编排者职责
- **预计 SOP 阶段数**：4（采集 ‖ → 分析 → 撰写 → 审核）
- **产出文件规划**：用户未要求留档设计文档 → 设计稿与提示词不落盘，仅交付任务结果
```

### 结构要点标注

1. OD0-02 判定必须逐条对照组建判断标准并展示，禁止跳过判定直接拉起
2. OD0-03 机制三态判定必须先核对环境实际可用工具，不确定时按三态降级路径处理
3. 产出文件规划决定后续设计稿是否落盘——用户未要求留档则全程对话内呈现
4. 方案确定后立即进入 OD1，不停留等待确认（用户有异议可随时叫停）

### 替换清单

任务描述、交付物形态、关键约束、判定依据各行的任务特征值、团队形态结论、机制三态结论、SOP 阶段数全部替换为实际任务内容；判定表结构、三态判定结构、要点标注框架为固定样式。
