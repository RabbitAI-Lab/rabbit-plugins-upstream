## OD4-整合交付域范本

### 范本概述

OD4 域全任务范本，覆盖 OD4-01/OD4-02/OD4-03 全部任务的产物样式，承接 OD3 范本（示例任务收尾）。

### 范本正文

**【OD4-01 产出整合汇编】汇编记录**：

```markdown
## 产出汇编记录

- **输入归集**：资料要点集 + 数据核对表 + 报告终稿（定向重跑后）+ 审核意见闭环清单
- **汇编动作**：结构整合（附录并入来源清单与"待验证"标注清单）→ 一致性核对（正文数据引用与核对表逐条对齐）→ 结论聚合（三部分结论汇总至执行摘要）
- **交付物**：行业研究报告（Markdown，按 OD0-01 约定形态）
- **边界说明**：编排者仅做结构整合与一致性核对，未改写任何专业内容；矛盾项已于 Phase 3 门禁闭环
```

**【OD4-02 交付与团队释放】交付记录**：

```markdown
## 交付与释放记录

**交付内容**：
1. 任务成果：行业研究报告终稿
2. 执行摘要：
   - 团队构成：编排者（本会话）+ 资料研究员 + 数据分析师 + 撰稿人 + 审稿人（态2 子代理态）
   - SOP：采集 → 数据核对 → 撰写 → 审核交付（4 阶段，含 1 次定向重跑）
   - 成员贡献：要点集（资料研究员）/ 数据核对表（数据分析师）/ 报告初稿与终稿（撰稿人）/ 审核意见（审稿人）
   - 门禁记录：Phase 3 拦截 2 项 FAIL，循环 1 次闭环

**团队释放**：
- 子代理会话全部结束 ✅
- 无常驻资源遗留 ✅
- 用户未要求留档设计文档 → 设计稿与提示词未落盘 ✅
```

**【OD4-03 执行复盘深化】复盘记录**：

```markdown
## 执行复盘记录

- **做得好**：门禁三查在 Phase 3 拦截缺章节与数据引用不一致，避免带病交付；定向重跑一次闭环
- **卡点**：撰稿人首次产出遗漏"趋势判断"章节——下一轮同类任务在 Phase 3 门禁点预置"三部分结构逐项核对"子项
- **复用价值判定**：本团队（调研+数据+撰写+审核）为通用研究型构成，**可复用**
- **固化建议**（仅建议不执行，须用户确认）：
  - 需要组建方案与系列提示词 → 按固化建议形态一：输出设计要点与复用场景，由用户选择实现方式
  - 需要可上架资产包 → 按固化建议形态二：标注团队构成与铁律条款，由用户选择实现方式
```

### 结构要点标注

1. 汇编三动作（结构整合/一致性核对/结论聚合）缺一不可；严禁代写或改写成员专业内容
2. 执行摘要四要素：团队构成 / SOP / 成员贡献 / 门禁记录摘要
3. 团队释放为强制收口：解散或结束子代理、确认无遗留；用户要求留档的设计文档此时落盘
4. 复盘必须给出复用价值判定；固化建议仅建议不自动执行，须用户确认

### 替换清单

汇编输入与动作、交付物形态、团队构成与成员贡献、复盘内容、复用判定结论全部替换为实际任务；汇编边界说明、执行摘要四要素、释放检查项、固化建议双形态为固定框架。
