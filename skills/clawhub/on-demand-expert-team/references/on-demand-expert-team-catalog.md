## 任务清单与依赖拓扑

按运行流程组织的任务清单，附任务间关系和元操作映射提示。

**域间逻辑流**：OD0 → OD1 → OD2 → OD3（↻ 缺口修正循环）→ OD4；OD0-02 判定"无需专家团"时条件退出（单专家直办）。

### 依赖拓扑摘要

#### 一、域内链路

**判定路由链路**：OD0-01 → OD0-02 → OD0-03
**动态设计链路**：OD1-01 → OD1-02 → OD1-03
**拉起运行链路**：OD2-01 → OD2-02 ‖ OD2-03（执行与通报并行推进）
**守护校准链路**：OD3-01 →（OD3-02 ↻ 回对应生成任务 / OD3-03）
**整合交付链路**：OD4-01 → OD4-02 → OD4-03

#### 二、跨域协同链路

**主运行管线**（P4 条件分支 + P5 交互驱动嵌套 P2 迭代精炼）：OD0-01 → OD0-02 ?(组团)→ OD0-03 → OD1-01 → OD1-02 → OD1-03 → OD2-01 → OD2-02 ‖ OD2-03 → ↻(OD3-01 → OD3-02 → 复检) → OD3-03 → OD4-01 → OD4-02 → OD4-03

**快速通道**（P4 条件退出）：OD0-02 ?(无需专家团)→ 单专家直办 → 交付（退出本技能管线）

**缺口回修边**（迭代协同）：OD3-02 缺角色 → 回 OD1-01（补设计）→ OD1-03（补提示词）→ OD2-01（补拉起）；产出不合格 → 回 OD2-02（定向重跑）

**固化交接边**：OD4-03 判定团队可复用 → 输出固化建议（组建方案+系列提示词 / 可上架资产包等形态），本次运行就此收口；固化实现方式由用户另行决定

#### 三、入口说明

标准入口为 OD0-01。用户明确指定团队构成或直接给出"拉起某类团队跑任务"指令时，OD0-01/OD0-02 可合并快跑（判定依据仍须记录并向用户展示），后续链路不变。

#### 四、知识图谱

**实体节点类型**：任务节点 OD0-01~OD4-03（15 个）；域节点 OD0~OD4（5 个）；元操作节点 S/C/A/O/I/G；拉起机制节点（态1 团队工具/态2 子代理/态3 单会话）；团队形态节点（单专家/小型团/大型团）。

**关系边类型**：依赖边（→）、并行边（‖）、条件边（?）、迭代边（↻）、扇出边（⇉）、回修边（缺口→对应生成任务）、固化交接边（临时团→固化建议）。

**推理能力**：由任务特征反推所需团队形态与机制三态；由门禁 FAIL 项定位所属任务并给出回修路径；由依赖边识别可并行成员调度组合；由复用判定输出固化交接建议。
