# 八字（四柱命理）

## 核心原则

> [!important] 七条铁律（源自五大古籍）

| # | 铁律 | 来源 |
|------|------|------|
| 1 | **调候为第一义**。寒暖燥湿不调，格局再好也难发。 | 《穷通宝鉴》 |
| 2 | **格局定层次上限**。成格者贵，破格者贱。 | 《子平真诠》 |
| 3 | **有病方为贵，无伤不是奇**。关键看有没有"药"。 | 《神峰通考》 |
| 4 | **源流看气势**。五行之气流通则吉，截断则凶。 | 《滴天髓》 |
| 5 | **神煞不主吉凶**。神煞只做 ±10% 修正。 | 《命理约言》 |
| 6 | **合能解冲，冲不能解合**。刑冲合害有严格优先级。 | 《渊海子平》 |
| 7 | **男女命十神本质不同**。男财为妻，女官为夫。 | 《三命通会》 |

> 分析层级（九层，不可颠倒）：
> **排盘验证 → 调候 → 格局 → 强弱 → 刑冲合害 → 用神 → 病药 → 空亡墓库 → 神煞 → 岁运**
