# BaZi-OS — 八字操作系统

> **世界顶级命理师思维框架 · 九层诊断 · 四流派交叉验证 · 古籍溯源**
>
> 不是算命软件，是命理学的 **Operating System**。
> 把《穷通宝鉴》《子平真诠》《神峰通考》《滴天髓》的方法论编译成可执行的推理引擎。

---

## 这是什么

一个基于 **Obsidian 知识库 + Claude Code Skill** 的八字全盘分析系统。

不同于市面上的排盘工具，BaZi-OS 的核心是**顶级命理师的思考框架**——它教 AI 像梁湘润、徐乐吾、韦千里一样分析八字：

- ❌ 不是"见财就断富，见官就断贵"
- ✅ 而是**九层逐层下钻**：调候 → 格局 → 强弱 → 刑冲合害 → 用神 → 病药 → 空亡墓库 → 神煞 → 岁运
- ✅ 每个结论**至少两个流派交叉验证**，标注**置信度**
- ✅ 每条判断**追溯到具体古籍段落**

## 快速开始

### 前置条件

- [Obsidian](https://obsidian.md/) （知识库浏览）
- [Claude Code](https://claude.ai/code) （AI 分析引擎）

### 安装

```bash
git clone https://github.com/yourname/bazi-os.git
cd bazi-os
```

在 Obsidian 中打开此文件夹作为 Vault。

### 使用

在 Claude Code 终端中输入：

```
/bazi
```

按提示输入：出生日期、时间、地点、性别。

AI 自动执行九层诊断，输出报告到 `输出/` 目录。

### 手动分析

打开 `框架/排盘分析模板.md`，按表格逐项填写。

## 分析示例

输入：**男，1993年5月15日 14:30，武汉**

输出片段：

```
## 调候诊断 🟢
《穷通宝鉴》丙火巳月篇："四月丙火，建禄于巳，火势炎炎，专用壬水。"
→ 调候用神：壬水。命局年干癸水(七杀)可替代壬水调候，调候得宜。

## 格局判定
月令巳火 → 劫财格（非正八格）
透干取格：年透癸水正官 + 时透乙木正印 → 官印相生格
《子平真诠》论正官格："官以印护，则官星安然而不伤。"
→ 成格。层次：中上。

## 用神系统（五类）
1st 调候用神：壬水(癸水代) ✅
2nd 格局用神：印(乙木)护官 ✅
3rd 病药用神：病在劫财透干 → 药在官制劫 ✅

## 综合结论 🟢 高置信度(85%)
命局层次：中上。34岁癸丑运起进入50年喜用神运，中晚年后劲极强。
```

完整报告 13 节，含古典引述索引。
