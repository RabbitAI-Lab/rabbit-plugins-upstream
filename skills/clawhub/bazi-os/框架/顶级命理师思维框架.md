# 顶级命理师思维框架

> 不是 checklist，而是 reasoning engine。
> 每一个判断必须经得起三套以上古典体系的交叉验证。

---

## 一、核心哲学

### 1.1 五条铁律

| # | 铁律 | 来源 |
|------|------|------|
| **1** | **调候为第一义**。寒暖燥湿不调，格局再好也难发。 | 《穷通宝鉴》 |
| **2** | **格局定层次上限**。成格者贵，破格者贱，与身强弱无关。 | 《子平真诠》 |
| **3** | **有病方为贵，无伤不是奇**。完美八字不存在，关键看有没有"药"。 | 《神峰通考》 |
| **4** | **源流看气势**。五行之气从哪来到哪去，流通则吉，截断则凶。 | 《滴天髓》 |
| **5** | **神煞不主吉凶**。神煞只在五行十神框架下起 ±10% 的修饰作用。 | 《命理约言》 |
| **6** | **合能解冲，冲不能解合**。刑冲合害有严格优先级，不可平起平坐。 | 《渊海子平》 |
| **7** | **男女命十神本质不同**。男命财为妻、官为子女；女命官为夫、食伤为子女。不可混用。 | 《三命通会》 |

### 1.2 判断四面体

```
             调候（穷通宝鉴）
              /\
             /  \
            /    \
           /  判  \
          /   断   \
         /          \
格局（子平真诠）—— 病药（神峰通考）
         \          /
          \        /
           \      /
            \    /
             \  /
          形象（滴天髓）

              |
              ↓

        盲派做功（实战验证）
```

**任何一个重大结论，必须至少有两条边的支撑。** 单边结论标注为"待验证"。

## 二、九层诊断流程

> 严格按此顺序，不可颠倒。前一层没搞清楚，不进下一层。

---

### 第 0 层：排盘验证（防排错——最致命的一步）

**八字排错了，后面全白做。**

#### 0.1 时辰可信度评级

| 等级 | 条件 | 处理 |
|------|------|------|
| **A 级** | 精确到分钟 + 医院记录 | 按标准排盘 |
| **B 级** | 大致时辰（如"早上七八点"） | 排两个相邻时辰，后续用六亲反推锁定 |
| **C 级** | 时辰不详 | 先用三柱分析（年+月+日），时柱标"待定" |

#### 0.2 真太阳时校验

- 时差 = (出生地经度 - 120°) × 4 分钟
- 时差 > 30 分钟 → 必须校正
- 校正后跨越时辰边界 → 两个时辰都要排，后续反推锁定

| 区域 | 经度 | 与北京时差 | 是否需校正 |
|------|------|------|------|
| 东部沿海 | ~120°E | ±10 分钟 | 不必要 |
| 中部（武汉/郑州） | ~114°E | -24 分钟 | 边界时辰需校 |
| 西部（成都/重庆） | ~104°E | -64 分钟 | **必须校正** |
| 新疆/西藏 | ~87°E | -132 分钟 | **必须校正** |

#### 0.3 节气边界复核

- 出生在节气交界日 ±1 天 → 查精确气点时刻确定月柱
- 出生在立春 ±1 天 → 确认年柱归属
- 出生在 23:00 前后 → 确认早晚子时处理

#### 0.4 排盘输出

**必须输出**：
- 四柱天干地支 + 藏干（本气/中气/余气）
- 纳音（每柱）
- 旬空（以日柱定）
- 命宫 + 身宫
- 胎元
- 每柱干支的**盖头/截脚/天覆/地载**关系

### 第 1 层：调候（气候判断——第一义）

**来源**：《穷通宝鉴》

先不看十神格局，只看**日主 × 月令的气候匹配**：

| 月令 | 气候特征 | 核心需求 | 次需 |
|------|----------|----------|------|
| 寅卯月（春） | 木旺，尚有余寒 | 火暖局 | — |
| 巳午月（夏） | 火旺，炎热干燥 | **水调候** | 金发水源 |
| 申酉月（秋） | 金旺，渐寒 | 火暖局 | 木生火 |
| 亥子月（冬） | 水旺，寒冷 | **火暖局** | 木生火 |
| 辰戌丑未月 | 土旺，燥湿各半 | 视具体干支定 | — |

**输出**：
- 命局偏寒/偏暖/偏燥/偏湿/中和？
- 调候用神是什么？（优先于格局用神）
- 调候用神有力否？（透干+通根 > 透干 > 藏干 > 无）

> **铁则**：调候用神与格局用神冲突时，**调候优先**。一个被调候拖累的成格八字，不如一个调候得宜的普通八字活得舒服。

---

### 第 2 层：格局（结构判断——定层次）

**来源**：《子平真诠》

#### 2.1 取格流程

1. **月令取格**：月支本气是什么十神 → 初步定格
2. **透干定格局**：月令之气透到天干上 → 正式格局
3. **格局成败三问**：
   - 格局是否**透干**？（不透 = 格局不显，降级）
   - 有无**护神**？（如官格见印护官、财格见官护财）
   - 有无**破神**？（如官格见伤官、财格见比劫）
4. **格局层次**：成格 > 半成格 > 待大运补 > 破格

#### 2.2 变格规则

当月令格局被破坏时：
1. 月令格局被破 → 看天干是否另有格局可用 → **以透干为格**
2. 月令多透（如辰月透乙又透癸）→ **以有力者为格**
3. 月令之气完全不透 → **看全局最有力之十神为格**
4. 月令不成立但全局形成特殊格局 → **以外格论**

#### 2.3 特殊格局严格判定

| 格局类型 | 成立条件 | 假格/破格标志 |
|------|------|------|
| **从强（从旺）** | 全局印比，无官杀克身，无财耗身 | 有一丝官杀/财星藏透 → 假从 |
| **从杀** | 全局官杀，无印化杀，无比劫抗杀 | 有一点印/比劫 → 假从 |
| **从财** | 全局财星，无比劫夺财，无印耗财 | 有一点比劫 → 假从 |
| **从儿（从食伤）** | 全局食伤，无印制食伤 | 有一点印 → 假从 |
| **从势** | 无主导五行，顺势而为 | — |
| **专旺格**（曲直/炎上/稼穑/从革/润下） | 全局同一五行或紧密生扶，无克破 | 见克破 → 破格 |
| **化气格** | 日主与邻干合，月令助化气，全局无克破化气 | 否则 → 假化/不化 |

> **铁则**：日主无根（四柱无同五行藏干）+ 全局克泄压倒 → 真从。有一丝根 → 假从/不从。

#### 2.4 十神混杂处理

| 混杂类型 | 判断 | 解法 |
|------|------|------|
| **官杀混杂** | 天干同时有正官+七杀 → 事业/感情进退两难 | 合去一个（去杀留官为上），留清则贵 |
| **食伤混杂** | 食神+伤官同透 → 才华多而不精 | 合去一个 |
| **财星混杂** | 正偏财同透 → 财源多但不稳 | 配合格局看，不一定为凶 |
| **印星混杂** | 正偏印同透 → 多母/多学历，心绪不专 | 看有无制化 |

> **去一留一为吉，两者皆留为混杂。**

**输出**：
- 格局是什么？月令取格还是透干取格？
- 成败状态？
- 破格因素是什么？有没有救应？
- 是否特殊格局？

### 第 3 层：强弱（承载判断——定能力）

**来源**：《滴天髓》+《子平真诠》

#### 3.1 量化计票

| 维度 | 权重 | 说明 |
|------|------|------|
| **得令**（月令） | 50% | 日主在月令的状态 |
| **得地**（通根） | 30% | 日干在地支有无同五行之根 |
| **得生**（印星） | 15% | 印星贴身生扶 |
| **得助**（比劫） | 5% | 比劫帮扶 |
| **人元司令校正** | ±5% | 月令人元司令分野微调 |

#### 3.2 结论分级

- **身强**：同党 > 异党，日主有根有力
- **中和**：同党 ≈ 异党，或日主有根但不旺
- **身弱**：异党 > 同党，日主根弱或虚浮
- **从格**：日主无根 + 全局克泄压倒（见 2.3 特殊格局判定）

> **关键**：强弱判断必须结合调候。冬月水日主虽得令，但寒气逼人，身强不等于命好。强弱不等于层次。

**输出**：
- 强弱等级（含计票数据）
- 承载能力（能不能任财官）

---

### 第 4 层：刑冲合害（关系判断——定吉凶细节）

**来源**：《渊海子平》+《三命通会》

#### 4.1 优先级铁则

```
三会 > 三合(半合) > 六合 > 六冲 > 六害 > 三刑
```

| 优先级 | 关系 | 规则 |
|------|------|------|
| **最高** | 三会 | 三地支齐聚同一方位（如寅卯辰会木），力量最强 |
| **高** | 三合/半合 | 三合可解六冲（如寅午戌三合 → 可解寅申冲）；半合亦可解，力稍弱 |
| **中** | 六合 | 六合可解六害，但不能解六冲 |
| **中** | 六冲 | 紧贴最强，隔位次之，遥冲最弱 |
| **低** | 六害 | 主隐性不和，不像冲那样明显 |
| **低** | 三刑 | 寅巳申（无恩）、丑戌未（恃势）、子卯（无礼）、辰午酉亥（自刑） |

#### 4.2 核心实战规则

- **合能解冲，冲不能解合**。合在前，冲来犯 → 合固守。冲在前，合来救 → 合可解冲。
- **三合局被冲** → 冲不动。半合被冲 → 可能冲散。
- **争合**（两个天干抢合一个）→ 合而不化，反成羁绊。
- **隔位作用力减半**，遥隔几乎不起作用。

#### 4.3 合化条件

**天干五合化气**：

| 合 | 化气 | 化之条件（月令助化） | 不化则为 |
|------|------|------|------|
| 甲己 | 土 | 月令为辰戌丑未 | 合绊（两干均减力） |
| 乙庚 | 金 | 月令为申酉 | 合绊 |
| 丙辛 | 水 | 月令为亥子 | 合绊 |
| 丁壬 | 木 | 月令为寅卯 | 合绊 |
| 戊癸 | 火 | 月令为巳午 | 合绊 |

> **化则变性**：甲己合化土成功 → 甲不再为木，变性为土。
> **不化则绊**：两干均减力，被"粘住"了。
> **争合不化**：两个天干抢合一个 → 不化，反成纠缠。

**输出**：
- 所有刑冲合害关系列表（按优先级排序）
- 谁赢谁输？最终结果是什么？
- 用神是否被冲克？忌神是否被制住？

### 第 5 层：用神（钥句判断——定出路）

用神不是单一答案，而是一个**多层次系统**：

| 用神类型 | 作用 | 来源 | 优先级 |
|------|------|------|:--:|
| **调候用神** | 调节气候，使全局寒暖适中 | 《穷通宝鉴》 | **1st** |
| **格局用神** | 成格之关键（如官格用印护官） | 《子平真诠》 | 2nd |
| **病药用神** | 治"病"之"药" | 《神峰通考》 | 3rd |
| **通关用神** | 化解冲战（如金木交战用水通关） | 《滴天髓》 | 4th |
| **扶抑用神** | 平衡身强弱（强则克泄，弱则生扶） | 通用 | 5th |

> **优先级**：调候 > 格局 > 病药 > 通关 > 扶抑。冲突时前面的覆盖后面的。

**输出**：
- 主用神（按优先级确定）
- 用神得力程度（位置/透干/通根/是否被冲克/是否落空亡）
- 用神是否在大运中得助

---

### 第 6 层：病药（问题诊断——找症结）

**来源**：《神峰通考》

| 病 | 症 | 药 |
|------|------|------|
| **太旺** | 某五行过强，压倒全局 | 克泄耗之五行 |
| **太弱** | 某五行虚浮无根 | 生扶之五行 |
| **冲战** | 两强相冲（如金木交战） | 通关之五行 |
| **混杂** | 官杀混杂/食伤混杂 | 去一留一 |
| **无情** | 用神被冲克/忌神被生扶 | 制忌神、护用神 |
| **无根** | 日主/用神虚浮 | 大运补根 |
| **落空** | 用神/六亲星落空亡 | 大运或流年填实 |
| **闭库** | 财官入库被合闭 | 大运冲开 |

**输出**：
- 命局三病（最严重的三个问题）
- 每病的"药"是什么
- 药力够不够（够 = 自愈 / 不够 = 等大运）

### 第 7 层：空亡与墓库（特殊规则——定虚实）

#### 7.1 空亡实战规则

**来源**：《三命通会》

| 情况 | 规则 |
|------|------|
| **用神落空** | 用神虚浮无力，吉而不吉，等大运填实 |
| **忌神落空** | 忌神减力，凶而不凶，逢冲则实 |
| **六亲星落空** | 该六亲缘浅/疏远/身体弱 |
| **日支（婚姻宫）落空** | 婚姻虚空感，或配偶常不在身边 |
| **时柱落空** | 子女缘浅，晚年空虚感 |
| **真空 vs 假空** | 落空又见冲 → 假空（有解）；落空无冲合 → 真空（无解） |
| **大运填实** | 大运地支恰好是空亡地支 → 该十年空亡被填实，吉凶显现 |

#### 7.2 墓库特殊规则

**来源**：《滴天髓》

| 墓库 | 藏什么 | 冲开效果 |
|------|------|------|
| **辰**（水库+土库） | 水、土 | 冲开 → 水/土出库 |
| **戌**（火库+金库） | 火、金 | 冲开 → 火/金出库 |
| **丑**（金库+水库） | 金、水 | 冲开 → 金/水出库 |
| **未**（木库+火库） | 木、火 | 冲开 → 木/火出库 |

**实战铁则**：
- **身强能开库** → 冲开为吉（发财发贵）。身弱 → 引火烧身。
- **库被合闭** → 财/官入库不出，需冲开才显现。
- **辰戌冲** → 水库 vs 火库，水火相冲，最为激烈。
- **丑未冲** → 金库 vs 木库，相对温和。

---

### 第 8 层：神煞（修正判断——±10%）

**来源**：《三命通会》神煞篇

神煞只在五行十神结论上做 **±10% 修正**：

- 吉星叠加好事 → 好事更大
- 凶星叠加坏事 → 坏事更凶
- 吉星在忌神上 → 减分
- 凶星在用神上 → 减分
- **任何神煞不能单独用来断吉凶**

**必须查的六级神煞**：

| 级别 | 神煞 | 含义 |
|------|------|------|
| 1 | 天乙贵人 | 最大吉星，遇难有救 |
| 2 | 文昌/学堂 | 学业才华 |
| 3 | 将星/华盖 | 能力/孤独 |
| 4 | 桃花/红鸾/天喜 | 情感/婚恋 |
| 5 | 羊刃/劫煞/灾煞 | 凶险/波折 |
| 6 | 空亡/孤辰/寡宿 | 落空/孤独 |

---

### 第 9 层：岁运（时机判断——定应期）

**来源**：《三命通会》

#### 9.1 三层作用模型

| 层次 | 角色 | 时效 |
|------|------|------|
| **原局**（命） | 出厂配置，一生不变 | 终身 |
| **大运**（运） | 十年一段的人生舞台 | 10 年 |
| **流年**（岁） | 本年发生的事件触发器 | 1 年 |

#### 9.2 作用规则

1. **大运作用于原局**：大运干支与原局四柱发生生克冲合 → 改变原局平衡
2. **流年作用于大运**：流年先与大运发生关系，再通过大运影响原局
3. **流年可直接作用于原局**：太岁之力最大，可直达原局任何一柱
4. **三者五行叠加**：原局某五行 + 大运某五行 + 流年某五行 → 合力断吉凶

#### 9.3 专项断法

| 现象 | 条件 | 含义 |
|------|------|------|
| **岁运并临** | 大运干支 = 流年干支 | 该年运势加倍（吉倍吉/凶倍凶） |
| **天克地冲** | 流年与大运/日柱天克地冲 | 变动之年（搬家/换工作/婚变/伤病） |
| **伏吟** | 流年与某柱完全相同 | 重复/停滞/反复之事 |
| **反吟** | 流年地支与某柱相冲 | 突发变动 |
| **岁运交战** | 大运与流年干支相冲克 | 该年动荡，好运打折/坏运更坏 |

#### 9.4 交运年处理

- 交运年（新旧大运交接的前后 1-2 年）→ **运势不稳，宜守不宜攻**
- 从忌神运换喜神运 → 转换期可能先乱后稳
- 从喜神运换忌神运 → 转换期可能先好后差

## 三、男女命十神差异

**来源**：《三命通会》

> 男女命在十神解读上有**本质不同**，绝对不可混用。

| 十神 | 男命代表 | 女命代表 |
|------|------|------|
| **正财** | **妻子**、稳定收入 | 父亲（偏财为父更常见）、财富 |
| **偏财** | 情人、横财、**父亲** | 财富、不稳定收入 |
| **正官** | 上司、事业、**女儿** | **丈夫**、稳定感情、名分 |
| **七杀** | 压力、**儿子**、权力 | 情人、偏夫、不稳定感情 |
| **食神** | 才华、**女儿** | **儿子**、才华、福气 |
| **伤官** | 才华、叛逆个性 | 才华，但**克夫**（伤官见官） |
| **正印** | **母亲**、学业、庇护 | **母亲**、学业、庇护 |
| **偏印（枭神）** | 继母、特殊技能 | 继母，但**克子**（枭神夺食） |
| **比肩** | 兄弟、朋友、同行 | 姐妹、朋友、同行 |
| **劫财** | **克妻**（劫财夺财=夺妻）、争财 | **争夫**、破财、小人 |

**核心差异口诀**：
- **男命看财官**：财 = 妻 + 财富，官杀 = 事业 + 子女
- **女命看官食**：官杀 = 夫 + 感情，食伤 = 子女 + 才华
- **女命伤官旺** → 必然克正官 → 婚姻不顺为大概率
- **男命劫财旺** → 克财夺财 → 克妻损财为大概率

## 四、盲派核心补充

盲派在 **职业判断、六亲应期、命局效率** 方面有子平格局派不具备的独特视角。

### 4.1 做功方式（"这人干什么活"）

| 做功类型 | 方式 | 职业映射 |
|------|------|------|
| **制用** | 用强势五行制住另一个五行 | 管理/控制型：官员、警察、管理者 |
| **化用** | 用通关方式化解冲战 | 协调/中介型：律师、顾问、销售 |
| **合用** | 通过合来获取资源 | 合作/借力型：合伙人、资源整合者 |

> **效率原则**：做功越直接 → 效率越高 → 命越好。间接做功、拐弯做功 → 辛苦命。

### 4.2 宾主理论（"谁是谁的"）

| 关系 | 流向 | 含义 |
|------|------|------|
| **宾生主** | 外界资源流向我 | 吉，得外力相助 |
| **主生宾** | 我的资源流向外界 | 辛苦付出，为他人做嫁衣 |
| **宾克主** | 外界管制/压力我 | 压力大，受制于人 |
| **主克宾** | 我掌控外界 | 能力强，能驾驭资源 |

- **主位**：日柱（我自己）
- **宾位**：年柱（远）、月柱（近）、时柱（晚/子女）

### 4.3 贼捕理论（"谁抓谁"）

- **贼** = 忌神（要被制住的东西）
- **捕** = 用神（制忌神的东西）
- **捕制住贼** → 效率高 → 命局层次高
- **贼反制捕** → 用神被忌神克制 → 效率低 → 辛苦劳累
- **捕贼相当** → 中等效率

每个专题分析必须经过至少三个流派的独立判断，加权综合。

| 维度 | 格局角度 | 调候角度 | 病药角度 | 形象/盲派角度 |
|------|------|------|------|------|
| **财富** | 财格成败？食伤生财？ | 财星调候得宜？ | 病在"财弱"还是"财被夺"？ | 财气通门户？做功效率？ |

## 六、鉴别诊断流程

> 不是"我觉得是A"，而是"A和B都像，排除B，锁定A"。

### 模板

```
判断：{结论}

候选A：{假设A}
  → 支持信号：{列出}
  → 反对信号：{列出}
  → 结论：排除 / 保留

候选B：{假设B}
  → 支持信号：{列出}
  → 反对信号：{列出}
  → 结论：排除 / 保留

最终锁定：{结论}（置信度 {x}%）
```

### 关键鉴别场景

| 容易混淆 | 区分要点 |
|------|------|
| **身弱 vs 从格** | 有根则不从，无根+全局克泄则从 |
| **正官格 vs 七杀格** | 官为约束（异性克）、杀为压力（同性克），看日主是否有制 |
| **食神制杀 vs 伤官见官** | 前者吉（以智化险）、后者凶（以才华犯上） |
| **从财 vs 财多身弱** | 一点根都没有？有印比否？ |
| **专旺 vs 身强** | 全局同一五行+无克破？还是只是偏强？ |
| **真从 vs 假从** | 有一丝印比藏而不透 → 假从 |
| **合化 vs 合绊** | 月令是否助化气？ |
| **真空 vs 假空** | 落空是否被冲/合？ |

## 七、概率校准机制

### 7.1 置信度规则

| 条件 | 置信度 | 标识 |
|------|------|:--:|
| 3+ 流派一致 | **高**（85%+） | 🟢 |
| 2 流派一致，第 3 无信号 | **中**（65-85%） | 🟡 |
| 2 流派一致，第 3 矛盾 | **中偏低**（50-65%） | 🟠 |
| 仅 1 流派有信号 | **低**（35-50%） | 🔴 |
| 各流派互相矛盾 | **不确定**（<35%，须标注） | ⚫ |

### 7.2 表达规范

- 🟢 高置信度 → "命局显示……"
- 🟡 中置信度 → "倾向于认为……，但需留意……"
- 🟠 中低置信度 → "有……的可能，但存在……的相反信号"
- 🔴 低置信度 → "有……的可能，建议结合……进一步验证"
- ⚫ 不确定 → "此处信号矛盾（列出），不做定论"

## 八、实战验证步骤

分析完不算完，必须验证。

### 验证四步

| 步骤 | 方法 | 目的 |
|------|------|------|
| **1. 六亲反推** | 用排盘的六亲星位置反推已知家庭结构 | 验证排盘准确性 |
| **2. 性格反推** | 用日主+十神组合反推性格特征 | 验证强弱判断 |
| **3. 往事反推** | 用过往大运/流年反推已知重大事件 | 验证大运排法 |
| **4. 校正机制** | 反推有误 → 回查排盘/强弱/大运，修正后重来 | 自我纠错 |

**示例**：
- "你父亲是否早年离家/工作特别忙/身体偏弱？"（父星落空/被冲 → 应验则八字对）
- "你 2018 戊戌年是否事业变动？"（流年与某柱冲 → 应验则大运对）

## 九、信息不全处理协议

| 缺失项 | 处理方案 |
|------|------|
| **缺时辰** | ① 先用三柱分析（年月日），给范围性结论 ② 列出每个可能时辰的差异 ③ 用六亲/性格反推锁定时辰 |
| **缺地点** | 默认北京时间，**必须提醒**用户"出生在西部地区（新疆/西藏/青海/甘肃西部）需告知" |
| **日期不确定** | 列出相邻日期的八字差异，用已知人生大事反推 |
| **农历/公历不明确** | **两套都排**，差异极大，必须让用户确认 |
| **时辰为 B 级（大致）** | 排两个相邻时辰，标注"如 xx:xx 前出生为 X 时，之后为 Y 时"，后续反推锁定 |

## 十一、源头可溯原则

### 每一个判断，回答三个问题：

1. **五行根源**：这个结论在五行生克链上怎么推出来的？
2. **古典出处**：哪本古籍支持这个判断？原文段落是什么？
3. **现代验证**：在实际断命中这个规律的验证率如何？

### 禁止事项：

- ❌ "感觉是这样"
- ❌ "经验来说"
- ❌ "古人云"（不注明哪本书哪一段）
- ❌ 单信号定论
- ❌ 神煞独立断吉凶
- ❌ 男女命十神混用
- ❌ 不校真太阳时就排盘
