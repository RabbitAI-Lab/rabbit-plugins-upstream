# 标注体系

八字分析属于概率性判断，不同分析维度的可靠程度差异极大。本体系用**评分、星级、置信度、颜色**四套标准，让分析结论可量化、可比较、可信任。

---

## 一、星级体系（定性评级）

| 星级 | 含义 | 适用场景 |
|------|------|----------|
| ⭐⭐⭐⭐⭐ | 大吉 / 极佳 | 天作之合、用神有力、格局上乘 |
| ⭐⭐⭐⭐ | 吉 / 良好 | 良配、用神得地、格局成立 |
| ⭐⭐⭐ | 中平 | 一般、有得有失 |
| ⭐⭐ | 凶 / 较差 | 忌神当令、格局破败 |
| ⭐ | 大凶 / 极差 | 相冲相克、凶星无制 |

---

## 二、评分体系（定量）

| 维度 | 评分方式 | 说明 |
|------|----------|------|
| 单维度 | 1-5 分 | 对应星级 |
| 综合 | 加权总分 | 各维度 × 权重求和 |
| 评级 | 百分比/十分制 | 用于横向比较 |

## 三、置信度体系（可信程度）

置信度表示该分析结论的可靠程度。**核心原则：公式化判断置信度高，概率性判断置信度低。**

| 等级 | 符号 | 范围 | 颜色 |
|------|------|------|------|
| 极高 | 🟢🟢 | 90%+ | 深绿 |
| 高 | 🟢 | 80-90% | 绿 |
| 中高 | 🟡🟢 | 70-80% | 黄绿 |
| 中 | 🟡 | 60-70% | 黄 |
| 中低 | 🟠 | 50-60% | 橙 |
| 低 | 🔴 | <50% | 红 |

### 各分析维度置信度对照

> [!info] 百分比说明
> 以下百分比为**经验估值**（基于方法论的确定性程度），不是统计测量值。用于比较"哪个结论更可靠"，不可当作精确概率。

| 流年冲合 | 🟢 高 | **85%** | 有明确规则 |
| 用神忌神 | 🟢 高 | **83%** | 基于强弱推导 |
| 格局判定 | 🟢 高 | **82%** | 有明确取格规则 |
| 大运流年吉凶趋势 | 🟡🟢 中高 | **75%** | 趋势判断 |
| 贫富层次 | 🟡 中 | **68%** | 多因素综合 |

## 四、颜色标注体系

用于在分析笔记中标注重点，配合 Obsidian 渲染：

| 颜色 | 含义 | 适用 |
|------|------|------|
| 🟢 绿色 | 吉 / 用神 / 有利 | 优势、好信号 |
| 🔴 红色 | 凶 / 忌神 / 不利 | 问题、坏信号 |
| 🟡 黄色 | 中性 / 需注意 | 双刃剑、有条件的好 |
| 🔵 蓝色 | 信息 / 说明 | 背景、方法论 |
| ⚪ 灰色 | 不确定 | 数据缺失、无法判断 |

### Obsidian 实现方式

**Callout 标注**（推荐，Obsidian 原生渲染）：

```
> [!success] 优势
> 日主得令得地，身强能任财官

> [!danger] 注意
> 伤官见官，事业多波折

> [!warning] 风险
> 日支逢冲，婚姻需经营

> [!info] 说明
> 神煞仅供参考
```

**Emoji 前缀**（简单通用）：

```
🟢 日主得令得地，身强
🔴 伤官见官，大忌
🟡 财星有库但被合，需注意
🔵 本结论基于子平格局派
```

## 五、综合标注示例

```
### 💰 贫富分析

| 财有无源头 | 食神生财 | 🟢 高 |
| 有无财库 | 时柱有戌（火库） | 🟢 高 |

> [!success] 优势
> 食神生财 + 有财库，靠手艺致富，能存钱

> [!warning] 注意
> 财库在时柱，财富多集中于晚年
```
