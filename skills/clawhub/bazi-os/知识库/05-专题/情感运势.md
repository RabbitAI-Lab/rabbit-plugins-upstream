# 情感运势

情感看三件事：**有没有、顺不顺、什么时候来**。比看配偶性格（[[日柱看另一半]]）更偏重运程层面。

---

## 一、看情感的基本要素

### 男命

| 要素 | 代表 |
|------|------|
| 正财 | 正妻、稳定感情 |
| 偏财 | 情人、恋爱对象、异性缘 |
| 日支 | 配偶宫 |
| 桃花/红鸾/天喜 | 婚恋信号 |

### 女命

| 要素 | 代表 |
|------|------|
| 正官 | 正夫、稳定感情 |
| 七杀 | 情人、偏缘、烂桃花 |
| 日支 | 配偶宫 |
| 桃花/红鸾/天喜 | 婚恋信号 |

---

## 二、情感好坏判断

### 好的情感配置

| 配置 | 解读 |
|------|------|
| 配偶星一位清透 | 感情专一，婚姻稳定 |
| 配偶星为用神 | 配偶对你有帮助，越处越好 |
| 日支为用神 | 婚姻是加分项 |
| 配偶星坐天乙贵人 | 配偶是你的贵人 |
| 日支不受冲克 | 婚姻稳定 |

### 差的情感配置

| 配置 | 解读 |
|------|------|
| 配偶星多位混杂 | 感情复杂、多段恋情 |
| 配偶星为忌神 | 感情带来压力、消耗 |
| 日支为忌神 | 婚姻是减分项 |
| 日支被冲 | 婚姻动荡、聚少离多或离婚 |
| 日支被害 | 夫妻面和心不和 |
| 伤官见官（女命） | 克夫，婚姻不顺概率高 |
| 比劫夺财（男命） | 克妻，钱财与婚姻两失 |
| 孤辰寡宿入命 | 孤独命，感情寡淡 |
| 孤鸾煞 | 婚姻不顺的强信号 |

## 三、婚恋时机

### 看大运

| 大运 | 婚恋信号 |

| 流年 | 婚恋信号 |

## 四、情感模式

### 被动型

| 特征 | 解读 |
|------|------|
| 配偶星不显（命局无） | 感情来得晚，被动等待 |
| 配偶星藏支不透 | 暗恋多、行动少 |
| 日主身弱官杀强 | 被追求、被动接受 |

### 主动型

| 特征 | 解读 |
|------|------|
| 配偶星透干有力 | 主动出击，感情主动 |
| 日主身强合财/合官 | 直接追求目标 |
| 食伤旺 | 会撩会追，异性缘主动 |

### 多情型

| 特征 | 解读 |
|------|------|
| 配偶星多位 | 多段感情，一生不止一段 |
| 桃花旺 + 偏财/七杀 | 异性缘旺，容易惹情债 |
| 金水旺 | 欲望强、感情经历丰富 |

### 专一型

| 特征 | 解读 |
|------|------|
| 配偶星一位清透 | 从一而终 |
| 日支安静无冲无合 | 婚姻稳定 |
| 正官正印配合 | 传统专一 |
