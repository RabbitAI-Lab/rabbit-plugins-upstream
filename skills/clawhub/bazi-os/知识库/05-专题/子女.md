# 子女

在八字中看子女，主要看**子女星**（男命官杀、女命食伤）和**时柱**（子女宫）。星为子女的"命"，宫为子女的"家"。

---

## 一、子女星

| 命主 | 子女星 | 说明 |
|------|--------|------|
| **男命** | 正官（女）、七杀（子） | 官杀为子女，阴阳不同性别不同 |
| **女命** | 食神（女）、伤官（子） | 食伤为子女，阴阳不同性别不同 |

> 流派差异：部分流派男命以官杀为子女不分性别，七杀为子、正官为女较常见。

---

## 二、子女数量

### 传统数法（古代参考，现代受计划生育影响）

以子女星在命局中出现的次数和旺衰来估算：

| 子女星状态 | 子女数量倾向 |
|-----------|------------|
| 子女星旺相且多位 | 子女多（3 个以上） |
| 子女星一位清透 | 1~2 个 |
| 子女星藏而不透 | 少，可能 1 个 |
| 子女星不显 | 子女缘薄，少或无 |
| 子女星坐空亡 | 有子女但缘分淡，或数量打折扣 |
| 子女星被冲 | 有损（流产、夭折风险） |
| 枭神夺食（女命） | 不利生育，子女少或求子艰难 |

> 现代社会避孕普及，子女数量更多取决于个人意愿，八字仅看"气数"而非精确人头数。

### 子女星数量快速估算

数命局中子女星出现的次数：
- 天干出现 1 次 = 1 个
- 地支本气出现 1 次 = 1 个
- 中气/余气 = 算半个

合计后，男命和女命分别看对应星的数量，综合考虑。
