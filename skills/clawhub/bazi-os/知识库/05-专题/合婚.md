# 男女八字婚配（合婚）

合婚是八字最经典的应用之一，判断两个人的八字是否匹配、婚姻能否长久。合婚不是"配不配"的简单结论，而是看清两个人的相处模式和问题所在。

---

## 一、合婚的七个维度

### 1. 日主五行关系（性格匹配）

| 关系 | 组合示例 | 解读 | 婚配 |
|------|----------|------|------|
| **相生** | 甲木 + 壬水（水生木） | 一方滋养另一方，和谐 | ⭐⭐⭐⭐⭐ |
| **比和** | 甲木 + 乙木 | 同类，如朋友如战友 | ⭐⭐⭐⭐ |
| **我生** | 甲木 + 丙火 | 我付出多，对方受益 | ⭐⭐⭐ |
| **我克** | 甲木 + 戊土 | 我主导，对方受压 | ⭐⭐⭐ |
| **克我** | 甲木 + 庚金 | 我被压制，需看双方强弱 | ⭐⭐ |
| **相克且相冲** | 甲木 + 申金 | 冲突激烈 | ⭐ |

> 相生最好，比和次之。相克不一定差——如果克方八字刚好需要"被泄"（如对方火太旺需水制），相克反而是互补。

### 2. 生肖合冲（年支关系）

| 关系 | 组合 | 解读 |
|------|------|------|
| **六合** | 鼠牛、虎猪、兔狗、龙鸡、蛇猴、马羊 | 上上配，天生默契 |
| **三合** | 猴鼠龙、蛇鸡牛、虎马狗、猪兔羊 | 上配，互助互旺 |
| **相生** | 生肖五行相生 | 中上配 |
| **比和** | 同生肖或同五行 | 中配 |
| **相害** | 鼠羊、牛马、虎蛇、兔龙、猴猪、鸡狗 | 下配，暗伤 |
| **六冲** | 鼠马、牛羊、虎猴、兔鸡、龙狗、蛇猪 | 下下配，冲突多 |

> 生肖合冲只是七个维度之一，不要因为"生肖相冲"就一票否决。日柱关系远比年柱重要。

### 3. 日支（夫妻宫）关系

日支是配偶宫，两人的日支关系最直接反映婚后相处：

| 关系 | 解读 |
|------|------|
| 双方日支六合 | 婚后如胶似漆，感情稳定 ⭐⭐⭐⭐⭐ |
| 双方日支三合/半合 | 相处融洽，互相吸引 ⭐⭐⭐⭐ |
| 双方日支相生 | 一方照顾一方 ⭐⭐⭐ |
| 双方日支比和 | 平等相处，如朋友 ⭐⭐⭐ |
| 双方日支相冲 | 性格冲突大，吵一辈子 ⭐ |
| 双方日支相害 | 面和心不和，暗中较劲 ⭐ |
| 一方日支被对方三合局合走 | 一方易被外界牵制，婚姻易变 ⚠️ |

### 4. 配偶星匹配

| 检查项 | 解读 |
|--------|------|
| 男命财星 = 女命日主五行 | 天作之合，你就是对方的"正缘" |
| 女命官星 = 男命日主五行 | 天作之合 |
| 男命财星 = 女命旺势五行 | 女方旺夫 |
| 女命官星 = 男命旺势五行 | 男方旺妻 |
| 双方配偶星互补 | 中等 |
| 双方配偶星相冲克 | 需谨慎 |

### 5. 用神互补

| 组合 | 解读 |
|------|------|
| 男喜水，女八字水旺 | 女方是男方的"药"，旺夫/旺妻局 ⭐⭐⭐⭐⭐ |
| 女喜木，男八字木旺 | 男方是女方的"药" |
| 双方用神相同 | 同喜同忌，顺时同顺、逆时同逆 |
| 双方用神相冲 | 我的喜神是你的忌神，难协调 ⭐ |

### 6. 大运同步性

| 检查项 | 解读 |
|--------|------|
| 双方当前大运都顺 | 婚期顺利，婚后起步好 |
| 一方顺一方逆 | 一方付出多，需包容 |
| 双方忌神大运重叠 | 同阶段低谷，考验婚姻 |
| 双方桃花大运重叠 | 需共同经营，防外缘 |

### 7. 日柱纳音

| 关系 | 解读 |
|------|------|
| 纳音相生 | 加分项 |
| 纳音相同 | 性情相投 |
| 纳音相克 | 减分项（但权重低） |
| 特殊格局 | 如天上火+大海水，"日出东海"，反吉 |

> 纳音在合婚中权重最低，仅作参考。

## 四、合婚的正确姿势

1. **先看各自命局**：先分别分析两人的婚姻宫是否各自安稳，再看合婚。自己婚姻宫被冲的人，跟谁都难合。
2. **日柱 > 年柱**：日支关系远比生肖冲合重要
3. **互补 > 相同**：双方用神互补的婚姻，比"性格相同"更有生命力
4. **忌单一指标**：不要因为生肖相冲或纳音相克就否掉一段感情
5. **八字是参考**：最终决定权在你们的相处质量。合婚是"天气预报"，不是"判决书"
