# 事业

八字看事业，官杀是核心（名位权力），财星是动力（利益驱动），印星是背书（学历贵人），食伤是才华（技术创意）。

---

## 一、事业的十神角色

| 十神 | 在事业中的角色 | 适合的工作性质 |
|------|--------------|--------------|
| **正官** | 职位、名声、管理 | 公务员、管理者、体制内 |
| **七杀** | 权力、竞争、魄力 | 军警、创业者、高风险高回报 |
| **正印** | 学历、贵人、靠山 | 教育、科研、文化、文职 |
| **偏印** | 特殊技能、冷门专长 | 技术专家、科研、玄学 |
| **正财** | 稳定收入、资产 | 财务、实业、稳定行业 |
| **偏财** | 投资、生意、外快 | 贸易、投资、销售、创业 |
| **食神** | 技艺、创意、口才 | 手艺、餐饮、设计、咨询 |
| **伤官** | 才华、创新、表达 | 艺术、演艺、研发、自由职业 |
| **比肩** | 合作、团队 | 合伙创业、团队型工作 |
| **劫财** | 竞争、开拓 | 竞争性行业、市场开拓 |

## 二、事业好坏判断

### 事业有成的信号

| 信号 | 解读 |
|------|------|
| 官星为用神且有力 | 有职位有名声，体制内吃香 |
| 财官双美 | 名利双收，老板命 |
| 食神生财 | 靠手艺/专业赚钱，越老越吃香 |
| 杀印相生 | 文武双全，实权人物 |
| 食神制杀 | 技术型领导，以能力服人 |
| 官印相生 | 学历+官位，知识分子型领导 |
| 用神透干通根 | 事业根基扎实，步步高升 |

### 事业受阻的信号

| 信号 | 解读 |
|------|------|
| 官星为忌神 | 工作压力大、升职困难 |
| 伤官见官 | 与领导冲突、频繁跳槽、犯官非 |
| 财破印 | 为钱放弃学业/编制，得不偿失 |
| 比劫夺官 | 职位被同事/同行抢走 |
| 官杀混杂 | 双重工作压力、进退两难 |
| 用神被冲克 | 事业关键时刻被破坏 |

## 三、职业倾向速查

### 看主导十神

| 主导十神 | 职业大方向 |
|----------|-----------|
| 正官旺 | 公务员、国企、行政管理 |
| 七杀旺（有制） | 军警、公检法、高管、外科 |
| 正印旺 | 教师、研究员、作家、公务员 |
| 偏印旺 | 技术专家、科研、医生、命理师 |
| 正财旺 | 财务、会计、银行、实业 |
| 偏财旺 | 生意人、投资、贸易、自由职业 |
| 食神旺 | 厨师、设计师、手艺人、咨询师 |
| 伤官旺 | 艺术家、演员、程序员、创业者 |

### 看做功方式

| 做功 | 职业倾向 |
|------|----------|
| 制用（克制得） | 竞争型：管理、军警、竞技 |
| 化用（转化得） | 技术型：手艺、专业服务、研究 |
| 合用（直接拿） | 直接型：销售、贸易、自主创业 |

## 四、事业高峰期

### 大运看十年

| 大运 | 事业状态 |
|------|----------|
| 走官杀用神运 | 升职、掌权 |
| 走财运（用神） | 收入增长、创业成功 |
| 走印运（用神） | 学历提升、贵人提拔 |
| 走食伤运（用神） | 才华爆发、出代表作 |

### 流年看应期

| 流年 | 事业事件 |
|------|----------|
| 流年逢官星 | 升职、换工作 |
| 流年逢财星 | 加薪、业务扩张 |
| 流年合官星 | 跳槽、职位变动 |
| 流年冲官星 | 辞职、被辞退 |
| 流年官印相生 | 考试通过、拿到编制 |

## 五、事业断语

| 口诀 | 解读 |
|------|------|
| 官星有理会，稳坐钓鱼台 | 官星为用且有护，事业稳定 |
| 伤官见官，为祸百端 | 伤官克正官，事业多波折 |
| 杀印相生，功名可许 | 七杀+正印，实权人物 |
| 财官双美，名利双收 | 财生官护，老板命 |
| 食神制杀，独压万人 | 以能力服众，技术型领导 |
| 身弱官强，有志难伸 | 身太弱担不起官，有抱负没舞台 |
