# 合盘提示

"合盘"有两层含义：①命局 + 大运 + 流年的三层合看；②两个人的八字合婚合看。本笔记覆盖两者，给出实操提示。

---

## 一、命局 + 大运 + 流年合盘

### 三层结构

```
流年（年运）→ 大运（十年）→ 命局（先天）
```

| 层 | 角色 | 权重 |
|----|------|------|
| 命局 | 车（先天配置） | 决定上限 |
| 大运 | 路（十年环境） | 决定阶段 |
| 流年 | 天气（当年变化） | 决定应期 |

### 合盘核心提示

#### 提示 1：先看用神，再看合盘

任何大运流年，第一步判断其是**用神还是忌神**：

| 大运/流年 | 判断 |
|-----------|------|
| 十神为用神 | 吉，加分 |
| 十神为忌神 | 凶，减分 |
| 通关五行 | 化凶为吉 |
| 破坏用神 | 吉中藏凶 |

#### 提示 2：合盘的三种结果

| 组合 | 结果 |
|------|------|
| 命局好 + 大运好 + 流年好 | 人生巅峰期 |
| 命局好 + 大运差 + 流年好 | 凶中有救，小波动 |
| 命局差 + 大运好 + 流年差 | 好中有阻，总体尚可 |
| 命局差 + 大运差 + 流年差 | 低谷期，宜保守 |

#### 提示 3：合盘看冲合

| 合盘信号 | 解读 |
|----------|------|
| 流年合大运 | 当年运势被"绊住"，好事来得慢 |
| 流年冲大运 | 十年运中该年有剧变 |
| 流年合命局用神 | 好事临门 |
| 流年冲命局用神 | 用神受损，当年不利 |
| 大运流年命局三合 | 三合成局，当年必有大事 |
| 岁运并临 | 变化加倍，吉凶皆剧 |

#### 提示 4：天克地冲是最高警报

| 冲在哪 | 影响 |
|--------|------|
| 流年天克地冲大运 | 十年运中转折之年 |
| 流年天克地冲年柱 | 父母/祖上/根基 |
| 流年天克地冲月柱 | 事业/父母/兄弟 |
| 流年天克地冲日柱 | 婚姻/自身健康 |
| 流年天克地冲时柱 | 子女/投资/晚年 |

## 二、两人八字合盘（合婚）提示

### 合盘前的自查

| 检查项 | 提示 |
|--------|------|
| 各自婚姻宫 | 先看各自日支是否安稳，再合看 |
| 各自用神 | 各自强弱用神先定，才能看互补 |
| 各自当前大运 | 双方运势状态，决定婚姻时机 |

### 合盘七大提示

#### 提示 1：日支关系重于生肖

| 日支关系 | 提示 |
|----------|------|
| 六合 | 婚后如胶似漆，首选 |
| 三合/半合 | 相处融洽 |
| 相冲 | 性格冲突大，慎 |
| 相害 | 面和心不和 |

> 生肖（年支）相冲 ≠ 不能结婚，日支相冲才需重视。

#### 提示 2：用神互补是"旺夫/旺妻"

- 男命喜水，女命八字水旺 → 女方旺夫
- 女命喜木，男命八字木旺 → 男方旺妻
- **互补 > 相同**，差异产生生命力

#### 提示 3：配偶星匹配是"正缘"标志

- 男命财星 = 女命日主 → 天生一对
- 女命官星 = 男命日主 → 正缘
- 双方配偶星都"对得上"，是最佳合盘

#### 提示 4：检查"争合"信号

| 信号 | 提示 |
|------|------|
| 男方财星被比劫合走 | 有第三者竞争 |
| 女方官星被比劫合走 | 有情敌 |
| 双方日支同时被第三方合 | 婚姻易被外界破坏 |

#### 提示 5：大运同步性

| 状态 | 提示 |
|------|------|
| 双方大运同步走高 | 婚后共同上升 |
| 一高一低 | 一方需多付出 |
| 双方忌神运重叠 | 共同低谷，需经营 |

#### 提示 6：桃花运重叠要警惕

双方桃花大运/流年重叠 → 各自异性缘都旺，需共同经营，防外缘。

#### 提示 7：合盘评分后再择时

先 [[合婚]] 评分，再 [[婚配择时]]，顺序不可颠倒。

## 三、合盘快查清单

### 单人合盘（命局+运年）

- [ ] 当前大运是用神运还是忌神运？
- [ ] 当前流年天干地支是什么十神？
- [ ] 流年有没有冲、合、刑命局？
- [ ] 有没有天克地冲、岁运并临？
- [ ] 冲的是哪一柱（对应哪方面）？

### 双人合盘（合婚）

- [ ] 双方日主五行关系？
- [ ] 双方日支关系（合/冲/害）？
- [ ] 配偶星是否匹配？
- [ ] 用神是否互补？
- [ ] 有没有争合信号？
- [ ] 大运是否同步？
- [ ] 综合评分多少？
