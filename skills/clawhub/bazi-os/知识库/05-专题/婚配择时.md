# 婚配择时

结婚择时从大到小分四层：**择大运 → 择流年 → 择流月 → 择日择时**。层次越高越重要，先定年再定月日时。

---

## 一、择大运（哪十年适合结婚）

| 大运类型 | 适合度 | 解读 |
|----------|--------|------|
| 走配偶星大运 | ⭐⭐⭐⭐⭐ | 正缘出现期，最宜婚嫁 |
| 走桃花大运 | ⭐⭐⭐⭐ | 异性缘旺，机会多 |
| 走红鸾/天喜大运 | ⭐⭐⭐⭐⭐ | 婚期信号强烈 |
| 走印星大运（身弱） | ⭐⭐⭐ | 得长辈支持，可成家 |
| 走比劫大运（男命） | ⭐ | 有竞争、钱财消耗，谨慎 |
| 走伤官大运（女命） | ⭐ | 婚期难定，易生变 |

> 配偶星大运 = 男命走财运、女命走官杀运。

---

## 二、择流年（哪一年适合结婚）

### 首选年份

| 流年信号 | 适合度 | 机制 |
|----------|--------|------|
| 流年逢**配偶星** | ⭐⭐⭐⭐⭐ | 男逢财年/女逢官年，正缘到位 |
| 流年**合日支** | ⭐⭐⭐⭐⭐ | 流年地支与日支六合，婚恋大事发动 |
| 流年逢**红鸾/天喜** | ⭐⭐⭐⭐⭐ | 最直接的婚期信号 |
| 流年与日柱**天合地合**（鸳鸯合） | ⭐⭐⭐⭐⭐ | 洞房花烛之年 |
| 流年逢**桃花** | ⭐⭐⭐⭐ | 有婚恋机会，需主动把握 |
| 流年**合配偶星** | ⭐⭐⭐⭐ | 缘分被拉近 |

### 避开年份

| 流年信号 | 原因 |
|----------|------|
| 流年**冲日支** | 冲夫妻宫，当年不宜结婚 |
| 流年**冲太岁**（本命年） | 变动大，诸事不稳 |
| 流年**害日支** | 暗伤，婚后易生间隙 |
| 流年**冲配偶星** | 正缘被冲散 |
| 流年天克地冲日柱 | 大凶之年，不宜婚嫁 |
| 双方生肖的相冲年 | 对新人都不利 |

---

## 三、择流月（哪个月适合结婚）

在选定年份内，选流月：

| 流月类型 | 适合度 |
|----------|--------|
| 流月逢配偶星 | ⭐⭐⭐⭐⭐ |
| 流月合日支 | ⭐⭐⭐⭐ |
| 流月为用神 | ⭐⭐⭐⭐ |
| 流月逢红鸾/天喜 | ⭐⭐⭐⭐⭐ |
| 流月冲日支 | ❌ 避开 |
| 流月为忌神 | ❌ 避开 |

> 月份优先级：配偶星月 > 红鸾天喜月 > 用神月 > 合日支月。

---

## 四、择日（哪一天办婚礼）

### 传统择日法

| 吉日类型 | 说明 |
|----------|------|
| **黄道吉日** | 青龙、明堂、金匮、天德、玉堂、司命六黄道 |
| **天赦日** | 每年 4~5 个，天然大吉日，见 [[神煞速查表#一、吉神贵人类|神煞速查表]] |
| **不将日** | 传统婚嫁专用吉日 |
| **周堂嫁娶吉日** | 传统嫁娶月表 |

### 八字个性化择日

| 原则 | 说明 |
|------|------|
| 日干支为新人**用神** | 最重要原则，用神日办事事半功倍 |
| 避开新人**忌神日** | 忌神日诸事不顺 |
| 避开冲日柱 | 日支与任一方日支相冲 |
| 避开冲生肖 | 日支与双方年支相冲 |
| 双方日支**三合/六合**的日支 | 利于感情稳定 |
| 女命**大利月**/小利月 | 传统以女方为主定月 |

### 择日口诀

> 建满平收黑，除危定执黄，成开皆可用，破闭不相当。

- 黄道：除、危、定、执、成、开
- 黑道：建、满、平、收、破、闭

## 五、择时（几点行礼）

### 时柱选择原则

| 原则 | 说明 |
|------|------|
| 时支为新郎用神 | 男为主 |
| 时支与新娘日支**六合** | 女旺夫，家宅安 |
| 避开时支冲双方日支 | 冲夫妻宫不吉 |
| 选阳气上升的时辰 | 传统上午行礼（辰巳时） |
| 避开亥子时（阴气重） | 婚嫁大事忌深夜 |

### 时辰吉凶参考

| 时辰 | 适合度 | 原因 |
|------|--------|------|
| 辰时（7-9 点） | ⭐⭐⭐⭐⭐ | 龙时，阳气升，传统大吉 |
| 巳时（9-11 点） | ⭐⭐⭐⭐⭐ | 蛇时，吉庆 |
| 午时（11-13 点） | ⭐⭐⭐ | 正午，旺但过阳 |
| 未时（13-15 点） | ⭐⭐⭐ | 下午可行 |
| 卯时（5-7 点） | ⭐⭐⭐⭐ | 晨光，但太早 |
| 子时（23-1 点） | ❌ | 忌深夜 |

## 六、完整择时流程

```
第1步：先合婚 → 确认两人是否匹配（[[合婚]]）
第2步：择大运 → 哪十年宜婚
第3步：择流年 → 哪一年宜婚（红鸾/天喜/合日支/配偶星年）
第4步：择流月 → 哪个农历月（避开冲日支的月）
第5步：择日 → 黄道吉日 + 用神日 + 不冲新人日柱
第6步：择时 → 辰时/巳时，避开冲日支的时辰
```

---

## 七、注意事项

1. **先合婚再择时**：如果 [[合婚]] 评分很低，择时再好也难长久
2. **领证与婚礼分开看**：领证以证件登记日为准，婚礼以仪式日为准，两者可分别择日
3. **以新娘为主**：传统"男靠出生时、女靠出嫁日"，女方日柱在择日中权重更大
4. **现实优先**：好日子订不到酒店，就退而求其次选次吉日，不纠结
5. **忌选的日子**：双方父母忌日、清明、中元节等特殊日子
