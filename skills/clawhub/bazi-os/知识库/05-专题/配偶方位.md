# 配偶方位与远近

八字不仅能看配偶性格长相，还能看配偶在**哪个方向**、**距离多远**。这在择偶、相亲、异地恋判断中有实际参考价值。

---

> 以**出生地**为中心，看配偶星或日支所在的地支，对应方位。

---

## 二、看配偶方位的三种方法

### 方法一：配偶星所在地支（最常用）

- **男命**以**正财/偏财**为配偶星
- **女命**以**正官/七杀**为配偶星

找配偶星落在哪个地支 → 看该地支的方位 → 即配偶来的方向。

| 配偶星位置 | 方位解读 |
|------------|----------|
| 年柱的地支 | 远方（跨省跨国）、祖籍方向 |
| 月柱的地支 | 同城邻近、祖籍方向 |
| 日支 | 近在眼前、同学同事邻居 |
| 时柱的地支 | 远方（异国异地）、年龄差大 |

### 方法二：日支看方位

日支（配偶宫）本身也有方位属性：

> 子午卯酉 → 四正方向，配偶来的方向很正
> 寅申巳亥 → 四隅方向，偏角
> 辰戌丑未 → 方位不太固定，配偶来源多元

### 方法三：桃花所在地支

日支桃花所在的地支，也是配偶来源的方向参考。桃花的查法见 [[神煞速查表#六、情感婚姻类|神煞速查表]]。

## 三、看配偶远近

### 以配偶星所在柱位判断

| 配偶星所在 | 距离 | 典型情况 |
|-----------|------|----------|
| **年柱** | 远方 ⭐⭐⭐⭐⭐ | 外省、外国、年龄差 5 岁以上 |
| **月柱** | 中等 ⭐⭐⭐ | 同城不同区、邻近城市、同学同事 |
| **日支** | 最近 ⭐ | 身边人、青梅竹马、同行同业 |
| **时柱** | 远方 ⭐⭐⭐⭐ | 异国异地、网恋、晚婚对象 |

### 以配偶星五行辅助判断

| 配偶星五行 | 距离倾向 |
|-----------|----------|
| 木（寅卯） | 中等偏近 |
| 火（巳午） | 较远 |
| 土（辰戌丑未） | 近（土主本地） |
| 金（申酉） | 中等偏近 |
| 水（亥子） | 较远（水主流动） |

### 以驿马辅助判断

配偶星或日支带**驿马** → 配偶大概率是外地人，或认识时有地域流动（求学、出差、旅行等）。

> 配偶宫（日支）见驿马 → 极大概率远嫁/远娶。

## 四、配偶方位远近综合示例

**男命：甲木日主，正财星在年支丑**

| 分析维度 | 结论 |
|----------|------|
| 财星在年柱 | 远方，对方不是本地人 |
| 年支丑 | 丑为东北偏北 |
| 五行土 | 偏近的倾向 |
| 综合 | 东北方向的邻近省份，或年龄差距较大的本地人 |

**女命：丙火日主，正官星在时支亥，日支为午**

| 分析维度 | 结论 |
|----------|------|
| 官星在时柱 | 远方、晚婚 |
| 时支亥 | 亥为西北偏北 |
| 日支午 | 午为正南（配偶宫方位可能与配偶星方位不一致 → 需跨方向结合） |
| 综合 | 配偶大概率是西北方向的外地人，或通过网上认识 |

## 五、实战要点

### 多配偶星怎么看

如果命局同时有正财和偏财（男命），或正官和七杀（女命），以**离日柱最近的那个**为主要参考：

- 最近的配偶星看第一个对象的方向
- 另一个配偶星看再婚/第二个缘分的方向

### 配偶星不显怎么看

如果命局本身没有配偶星（男命无财、女命无官）：
- **看日支**的藏干与日主的关系
- **看大运**，走到配偶星出现的大运时，以该大运的地支为方位

### 方位只是参考

> 配偶方位远近是概率性参考，不是绝对命定。现实中受制于你的人际圈、工作环境、时代变迁（网络时代地域限制大幅减弱），不能孤立使用。
