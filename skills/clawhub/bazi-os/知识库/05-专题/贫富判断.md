# 贫富判断

贫富是八字中最受关注的问题。核心逻辑：**身强能任财 + 财有源头 + 财有库守 = 富**。

---

## 一、判断贫富的五大要素

### 1. 日主能不能任财

| 状态 | 能否任财 | 结果 |
|------|----------|------|
| 身强 + 财旺 | ✅ 能任 | **大富之命** |
| 身强 + 财弱 | 能任但财少 | 小康，财运平平 |
| 身弱 + 财旺 | ❌ 不能任 | 富屋贫人，财来财去 |
| 身弱 + 财弱 | — | 贫困 |

> **第一铁律**：身强才能担财。身弱财旺，如小儿抱金过闹市，不但不是福，反为祸。

### 2. 财星有没有源头

财星是否有食神/伤官来生 → 财的来源是否稳定。

| 财源 | 富的程度 |
|------|----------|
| 食神生财 | 细水长流，稳定富裕 |
| 伤官生财 | 才华变现，爆发力强 |
| 财星孤悬无源 | 死财，坐吃山空 |

### 3. 财有没有库

| 状态 | 结果 |
|------|------|
| 有财 + 有财库 | 能赚能存，越来越富 |
| 有财 + 无财库 | 能赚不能存 |
| 无财 + 有财库 | 空库，收入有限 |
| 财库被冲开（用神） | 爆发式进财 |

> 财库详见 [[财库]]。

### 4. 财星是否被夺

| 破坏 | 结果 |
|------|------|
| 比劫夺财 | 钱财被分走、破财、合伙失败 |
| 官杀护财 | 官杀制比劫，保护财星 → 富而有权 |
| 财被合走 | 钱财被牵制，投资被套 |

### 5. 财星是否透干

| 状态 | 结果 |
|------|------|
| 财星透干 + 通根 | 明财，大富 |
| 财星不透只藏 | 暗财，默默有钱不显 |
| 财星虚浮无根 | 表面风光，实际没钱 |

---

## 二、贫富层次速判

| 层次 | 条件 |
|------|------|
| **巨富** | 身强 + 财旺有源 + 有财库 + 官杀护财 |
| **大富** | 身强 + 财旺 + 有财库 |
| **中富** | 身强 + 财旺无库，或中和 + 财有源 |
| **小康** | 身强财弱，或中和 |
| **温饱** | 身弱财弱，或无财 |
| **贫困** | 身弱财旺（富屋贫人），或比劫夺财无制 |

---

## 三、贫富与格局

| 格局 | 贫富倾向 |
|------|----------|
| 食神生财格 | 技艺致富，中富以上 |
| 伤官生财格 | 才华致富，大起大落 |
| 财官双美格 | 名利双收，中富以上 |
| 从财格 | 巨富（但大运破格则大败） |
| 财破印格 | 为财损名，得不偿失 |
| 比劫夺财格 | 一生钱财难聚 |

## 四、贫富断语口诀

| 口诀 | 解读 |
|------|------|
| 财为养命之源 | 无财寸步难行 |
| 财不露白 | 财星藏支不透，反而真富 |
| 身弱财多，富屋贫人 | 银行柜员经手亿万家财，自己拿死工资 |
| 财多身弱，妻财难守 | 男命不但不富，还留不住老婆 |
| 财星归库，必定富足 | 财库在时柱最好，晚年爆发 |
| 一财得所，红颜失配 | 八字只有一个清纯财星且得位，反而婚姻不美 |
