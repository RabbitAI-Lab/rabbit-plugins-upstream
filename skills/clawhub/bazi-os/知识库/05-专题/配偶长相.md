# 配偶长相

在八字中看配偶长相，主要从三个维度入手：**日支五行**（肤色体形）、**配偶星**（正财/正官为参考）、**桃花神煞**（气质加成）。

> 以下方法为简化参考，实际需结合全局综合判断。

---

## 一、日支五行 → 肤色与体形

日支（配偶宫）的五行属性，决定了配偶的基础外貌特征：

### 日支为木（寅、卯）

| 特征 | 描述 |
|------|------|
| 肤色 | 偏白或青白色 |
| 脸型 | 长脸、瓜子脸 |
| 体型 | 修长挺拔，不会太胖 |
| 气质 | 斯文清秀、文质彬彬 |
| 身高 | 偏高 |

### 日支为火（巳、午）

| 特征 | 描述 |
|------|------|
| 肤色 | 偏红润、气色好 |
| 脸型 | 圆脸或方形脸 |
| 体型 | 结实饱满、不瘦 |
| 气质 | 热情开朗、活力四射 |
| 身高 | 中等 |

### 日支为土（辰、戌、丑、未）

| 特征 | 描述 |
|------|------|
| 肤色 | 偏黄、肤色偏暗或小麦色 |
| 脸型 | 方脸、国字脸 |
| 体型 | 敦实厚重、骨架大 |
| 气质 | 稳重踏实、可靠感 |
| 身高 | 中等或偏矮 |

### 日支为金（申、酉）

| 特征 | 描述 |
|------|------|
| 肤色 | 白净、皮肤好 |
| 脸型 | 轮廓分明、棱角清晰 |
| 体型 | 骨感、偏瘦 |
| 气质 | 高冷精致、有质感 |
| 身高 | 中等或偏高 |

### 日支为水（亥、子）

| 特征 | 描述 |
|------|------|
| 肤色 | 偏黑或肤色偏暗 |
| 脸型 | 圆润、有肉感 |
| 体型 | 丰满、有曲线 |
| 气质 | 柔美温和、眼神灵动 |
| 身高 | 中等 |

---

## 二、配偶星 → 气质类型

男命以**正财**为正妻，女命以**正官**为正夫。但实际参考配偶星时，还需看偏财（男）/七杀（女）。

| 配偶星 | 气质特征 |
|--------|----------|
| **正官** | 端正正直、有威严感、气质传统 |
| **七杀** | 气场强大、有压迫感、硬汉/御姐型 |
| **正财** | 温婉贤淑、朴素大方、适合过日子 |
| **偏财** | 时尚有魅力、潇洒风流、异性缘好 |
| **正印** | 斯文儒雅、有书卷气、长辈感 |
| **偏印** | 特立独行、文艺范、气质清冷 |
| **食神** | 温柔可爱、亲和力强、娃娃脸 |
| **伤官** | 颜值高、会打扮、明星脸 |
| **比肩** | 朴实无华、不爱打扮、路人感 |
| **劫财** | 个性张扬、有攻击性美感 |

---

## 三、桃花星 → 颜值加成

日支或配偶星带以下神煞，颜值加分：

| 神煞 | 颜值加成 |
|------|----------|
| **桃花（咸池）** | 天生有魅力、异性缘好、会撩 |
| **红鸾** | 喜庆之气、面相讨喜、旺夫/旺妻相 |
| **红艳煞** | 外貌吸引、浪漫气质、有明星相 |
| **金神** | 轮廓分明、五官立体、精致 |
| **伤官**（配偶星为伤官） | 颜值上限高，但下限也可能低 |

---

## 四、配偶星所在位置 → 相遇方式

| 位置 | 相遇方式 |
|------|----------|
| **年柱** | 青梅竹马、长辈介绍、年纪差距大 |
| **月柱** | 同学同事、同龄人、工作环境中认识 |
| **日支** | 婚后才知道对方的长相与性格真相 |
| **时柱** | 晚婚、年纪差距大、异国异地 |

## 五、综合判断示例

**女命：甲木日主，日支坐午**

- 日支午属火 → 配偶肤色红润、圆脸、中等身材
- 甲木女命的配偶星是辛金（正官）或庚金（七杀），看全局有无
  - 如果有辛金正官透出 → 配偶端正有威严
  - 如果有庚金七杀 → 配偶强势有气场
- 午为桃花地 → 配偶颜值较高，异性缘好
- 综合：嫁给一个面红圆脸、气场较强、长得不错的男人
