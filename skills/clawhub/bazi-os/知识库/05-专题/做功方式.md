# 做功方式

"做功"是盲派八字的核心概念，指命局通过什么方式获取财富、地位、成就。十神是"角色"，做功是"动作"——你怎么干活、怎么赚钱。

---

## 一、三种基本做功方式

### 1. 制用结构（克制得财）

通过**克制忌神**来获得。

| 制用类型 | 示例 | 职业倾向 |
|----------|------|----------|
| 食神制杀 | 食神克七杀 | 技术型管理者、外科医生、军警 |
| 伤官制杀 | 伤官合克七杀 | 风险投资、创业者 |
| 官制比劫 | 正官制比劫 | 公务员、执法者、管理者 |
| 印制伤官 | 正印约束伤官 | 学者、策划师、幕僚 |

> 制用 = 消耗自己的能量去克制某个东西，从而获利。适合有明确目标、竞争性强的工作。

### 2. 化用结构（转化得财）

通过**通关转化**来获得。不直接对抗，而是引化。

| 化用类型 | 示例 | 职业倾向 |
|----------|------|----------|
| 杀印相生 | 七杀生印、印生身 | 文职领导、学者、幕僚 |
| 食神生财 | 食神生财星 | 手艺、餐饮、艺术创作 |
| 伤官生财 | 伤官生财星 | 设计、演艺、销售 |
| 财官相生 | 财生官、官护财 | 企业管理、公职 |

> 化用 = 把一种能量转化为另一种能量，不硬碰硬。适合技术型、智力型、创意型工作。

### 3. 合用结构（合作得财）

通过**天干五合、地支六合**来获得。合财、合官都是直接拿过来。

| 合用类型 | 示例 | 职业倾向 |
|----------|------|----------|
| 日主合财 | 日干合财星 | 直接做生意、面对面赚钱 |
| 日主合官 | 日干合官星 | 体制内升迁、直接获权 |
| 比劫合财 | 比劫合财为日主所用 | 合伙经营、团队创业 |

> 合用 = 直接"拿"，效率高但容易有争夺（争合）。

---

## 二、做功效率的判断

### 效率高低的标准

| 效率 | 条件 | 结果 |
|------|------|------|
| **高效率** | 做功路径短 + 直达目标 | 事半功倍，轻松成功 |
| **中等效率** | 做功路径有通关或转弯 | 需要努力但能成 |
| **低效率** | 做功路径被阻断 | 辛苦但回报不成正比 |
| **无做功** | 全局没有做功结构 | 随波逐流，没有明确的谋生方式 |

### 效率口诀

> 做功路径越短越高效。最好的是**日主直接合财/合官**（日干直接拿），其次是**紧贴的食神生财**（一步转化），最慢的是**需要通过多个中间环节的通关**。

## 三、做功方式的职业映射

| 做功结构 | 适合职业 |
|----------|----------|
| 食神生财 | 厨师、设计师、手工艺人、咨询师 |
| 伤官生财 | 艺术家、演艺人员、销售高手、创业者 |
| 食神制杀 | 外科医生、军警、高管、技术总监 |
| 杀印相生 | 公务员、学者、研究员、幕僚 |
| 财官双美 | 企业老板、财务总监、体制内实权 |
| 印制伤官 | 编辑、策划、教师、科研人员 |
| 比劫夺财 + 食神泄劫 | 从竞争激烈的行业杀出来的人 |
| 枭神夺食（被破） | 越是被压越不服，终在特殊领域成功 |

---

## 四、做功结构的破坏

| 破坏方式 | 后果 |
|----------|------|
| 枭神夺食 | 食神生财的路径被阻断 → 才华无法变现 |
| 财破印 | 杀印相生的路径被阻断 → 贵人失势 |
| 比劫夺财 | 财被分走 → 合伙纠纷 |
| 伤官见官 | 官被伤 → 丢工作、犯官司 |
