# 绿帽判断

"绿帽"在八字中指配偶出轨的信号。男女看法不同，但核心机制一致：配偶宫/配偶星被他人染指。

---

## 一、男命（妻有外情）

男命看财星（正财为妻、偏财为情人）和日支。

### 高危信号

| 信号 | 机制 | 风险等级 |
|------|------|----------|
| **比劫夺财** | 比劫（兄弟/朋友）分夺你的财星（妻子） | ⭐⭐⭐⭐⭐ |
| **日支被合（争合）** | 配偶宫被其他地支合走，如两戌合一卯 | ⭐⭐⭐⭐⭐ |
| **财星被合** | 妻星被其他天干合走 | ⭐⭐⭐⭐ |
| **日支坐桃花 + 被冲** | 配偶宫桃花被冲开，引动外情 | ⭐⭐⭐⭐ |
| **正偏财混杂** | 你自身易出轨在先，引致婚姻不稳定 | ⭐⭐⭐ |
| **财星坐比劫** | 妻子身边围绕着兄弟/朋友型人物 | ⭐⭐⭐ |
| **日支为伤官 + 无印制** | 配偶个性叛逆，不受约束 | ⭐⭐⭐ |

### 应期

| 运年 | 触发 |
|------|------|
| 走比劫大运 | 十年内容易被"兄弟"夺妻 |
| 流年合财星 | 当年妻子外情信号 |
| 流年冲日支 | 当年婚姻危机 |
| 流年与日支争合 | 当年有第三者介入 |

---

## 二、女命（夫有外情）

女命看官星（正官为夫、七杀为情人）和日支。

### 高危信号

| 信号 | 机制 | 风险等级 |
|------|------|----------|
| **官杀混杂** | 正官七杀同现 → 丈夫之外有偏缘纠缠 | ⭐⭐⭐⭐⭐ |
| **伤官见官** | 伤官克正官，你管太严/太强势反而把丈夫推出去 | ⭐⭐⭐⭐⭐ |
| **日支被合** | 配偶宫被其他地支合走 | ⭐⭐⭐⭐⭐ |
| **正官被合** | 丈夫星被其他天干合走 | ⭐⭐⭐⭐ |
| **日支坐桃花** | 配偶宫自带桃花，丈夫异性缘旺 | ⭐⭐⭐⭐ |
| **比劫合官** | 其他女人（比劫代表同性竞争者）合走你的官星 | ⭐⭐⭐⭐ |
| **财星旺而生七杀** | 财生杀 → 偏缘主动找上门 | ⭐⭐⭐ |

### 应期

| 运年 | 触发 |
|------|------|
| 走伤官大运 | 十年内容易因性格冲突致丈夫外求 |
| 流年合正官 | 当年丈夫外情信号 |
| 流年冲日支 | 当年婚姻危机 |
| 走七杀大运 | 偏缘旺盛，婚姻受考验 |

## 三、男女通用的高危信号

| 信号 | 解读 |
|------|------|
| 日支伏吟（与别柱地支相同） | 配偶宫重复出现 → "分身"之象 |
| 日支与月支/时支相害 | 暗中伤害，配偶私下有动作 |
| 桃花 + 羊刃同柱 | 色中带凶，易因出轨引发暴力事件 |
| 红艳煞入命 | 自身或配偶异性缘过于旺盛 |
| 金水旺而无制 | 欲望强，难守一夫一妻 |

---

## 四、防绿帽的积极因素

| 信号 | 解读 |
|------|------|
| 官杀护财（男命） | 正官制比劫 → 朋友不敢动你的妻 |
| 印制伤官（女命） | 性格被约束 → 不会把丈夫逼走 |
| 日支安静无冲无合 | 配偶宫稳固 |
| 配偶星一位清透 | 感情专一线，关系简单 |
| 日支为用神 | 婚姻对你有益，正缘稳固 |

---

## 五、重要提醒

> 以上是高概率信号，但**不代表铁定出轨**。八字看的是"气数"——某个阶段有这个风险，但不等于一定会发生。大运流年才是触发器，命局只提供风险结构。婚姻的经营仍在自己手中。
