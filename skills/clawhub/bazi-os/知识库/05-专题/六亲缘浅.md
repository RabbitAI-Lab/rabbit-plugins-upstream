# 六亲缘浅

六亲指父母、兄弟、配偶、子女六种人伦关系。八字中六亲有对应的十神和宫位。"缘浅"指缘分薄弱——或早分离、或感情疏远、或虽有却得不到助力。

---

## 一、六亲的十神与宫位

| 六亲 | 对应十神 | 对应宫位 |
|------|----------|----------|
| **母亲** | 正印（主）、偏印（继母/干妈） | 年柱、月柱 |
| **父亲** | 偏财（主）、正财（兼看） | 年柱、月柱 |
| **兄弟** | 比肩、劫财 | 月柱 |
| **配偶** | 男正财/女正官 | 日支 |
| **子女** | 男官杀/女食伤 | 时柱 |

> 十神为"星"，宫位为"宫"。星宫同看，星不显看宫，宫被冲看星。

---

## 二、六亲缘浅的共性标志

无论哪一亲，以下信号出现越多，缘分越薄：

| 标志 | 解读 |
|------|------|
| 六亲星不显（命局无该十神） | 缘分先天薄弱，该六亲对你影响小 |
| 六亲星坐空亡 | 有等于无，或虽在身边但感情空虚 |
| 六亲星被冲克 | 关系紧张或该六亲自身运势差 |
| 六亲所在宫位被冲 | 该阶段六亲缘变动（如年柱冲→童年父母离开） |
| 六亲星为忌神且旺 | 该六亲不但帮不到你，反而拖累你 |
| 孤辰、寡宿入命 | 整体六亲缘偏薄，孤星照命 |
| 魁罡、华盖过旺 | 性格孤高，主动疏远六亲 |

---

## 三、各六亲缘浅的具体判断

### 父母缘浅

| 八字信号 | 含义 |
|----------|------|
| 年柱逢冲 | 童年家庭变动，父母关系不稳 |
| 年柱坐空亡 | 与祖上/父母缘分虚浮 |
| 正印不显（母）/ 偏财不显（父） | 与该亲缘薄 |
| 正印被财星克（财破印） | 父母关系不和，或为钱伤及母子情 |
| 偏财被比劫夺 | 父缘薄，父亲运势不佳 |
| 年月柱截脚 | 父母能力受限于环境，对你的扶持有限 |

### 兄弟缘浅

| 八字信号 | 含义 |
|----------|------|
| 比劫不显 | 独子/独女，或兄弟姐妹缘薄 |
| 比劫坐空亡 | 兄弟姐妹难依靠 |
| 比劫被官杀强克 | 兄弟有灾，或与你对立 |
| 比劫为忌神旺 | 被兄弟姐妹拖累 |
| 月柱逢冲 | 青年期与家庭/兄弟疏远 |

### 配偶缘浅

| 八字信号 | 含义 |
|----------|------|
| 配偶星不显 | 晚婚，或感情缘分淡 |
| 日支逢冲 | 婚姻不稳，聚少离多 |
| 日支坐空亡 | 配偶有名无实，或形婚 |
| 孤鸾煞、阴差阳错日 | 婚姻缘薄信号 |
| 配偶星为忌神 | 感情带来的痛苦多于幸福 |

> 配偶详细见 [[情感运势]]、[[日柱看另一半]]。

### 子女缘浅

| 八字信号 | 含义 |
|----------|------|
| 子女星不显 | 与子女缘分淡，或无子女 |
| 时柱逢冲 | 子女远离、晚来或不亲 |
| 时柱坐空亡 | 子女缘分薄 |
| 枭神夺食（女命） | 不利生育、与子女感情疏离 |
| 子女星为忌神 | 子女让你操心费力 |

---

## 四、缘浅的深浅程度

| 程度 | 条件 |
|------|------|
| **极浅**（几乎无缘） | 星不显 + 宫空亡 + 星被冲克 |
| **偏浅**（有但疏远） | 星有但坐空亡，或宫被冲 |
| **时浅时深** | 星有用神大运帮扶时缘深，走到忌神运时缘浅 |
| **假浅**（其实不浅） | 星不显但在大运流年中出现，该阶段缘分突然加深 |

---

## 五、缘浅 ≠ 命差

> 六亲缘浅不是诅咒。很多成就大事业的人命中带有孤辰寡宿、华盖等"孤星"——正因为六亲靠不住，才逼着自己独当一面。缘浅意味着你在这条路上需要更独立，但不代表这条路走不通。
