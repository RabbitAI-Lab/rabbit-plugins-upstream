# 家庭关系

八字看家庭，四柱各管一宫：年柱祖上/父母、月柱父母/兄弟、日柱自己+配偶、时柱子女。家庭好不好，看宫位是否安宁、星是否得力。

---

## 一、四柱家庭宫位

| 四柱 | 家庭角色 | 看什么 |
|------|----------|--------|
| **年柱** | 祖上、父母（早期） | 出身家庭、祖荫、童年环境 |
| **月柱** | 父母、兄弟 | 父母能力、家庭氛围、手足关系 |
| **日柱** | 自己 + 配偶 | 夫妻关系、小家庭质量 |
| **时柱** | 子女 | 子女运、晚年的家庭状态 |

---

## 二、父母关系

### 与母亲（正印）

| 信号 | 解读 |
|------|------|
| 正印为用神且旺 | 母亲是你的贵人，关系亲密 |
| 正印为忌神 | 母亲过度保护/控制，或关系紧张 |
| 正印被财星克 | 母亲身体不好，或父母关系不和波及母子 |
| 正印坐空亡 | 与母亲缘分薄 |
| 正印透干 | 母亲对你影响深远且正面 |

### 与父亲（偏财）

| 信号 | 解读 |
|------|------|
| 偏财为用神且旺 | 父亲有能力，是你后盾 |
| 偏财为忌神 | 父亲拖累你，或父子关系紧张 |
| 偏财被比劫夺 | 父亲运势不佳或父子关系疏离 |
| 偏财被冲 | 父亲健康有问题或早年分离 |
| 偏财不显 | 与父亲缘分浅 |

### 父母之间的关系

| 信号 | 解读 |
|------|------|
| 财印不战（财不克印） | 父母关系和谐 |
| 财破印（财星克印星） | 父母不和，常有争执 |
| 年柱逢冲 | 童年家庭不稳，父母可能离异 |
| 年月柱截脚 | 父母之间一方压制另一方 |

## 三、夫妻关系

### 和谐信号

| 信号 | 解读 |
|------|------|
| 日支为用神 | 婚姻对你有益，配偶是加分项 |
| 日干生日支（天覆） | 你爱护配偶，主动付出 |
| 日支生日干（地载） | 配偶支持你，背后支柱 |
| 配偶星一位清透 | 感情专一，关系纯粹 |
| 日支无冲无合 | 婚姻稳定，不折腾 |
| 日支坐天乙贵人 | 配偶是你的贵人 |

### 紧张信号

| 信号 | 解读 |
|------|------|
| 日支为忌神 | 婚姻让你痛苦，或配偶拖累你 |
| 日支逢冲 | 夫妻矛盾激烈，聚少离多或离婚 |
| 日支被害 | 面和心不和，暗中伤害 |
| 日支被合 | 配偶被外界牵制 |
| 日干克日支（盖头） | 你压制配偶，对方不幸福 |
| 日支克日干（截脚） | 配偶压制你 |
| 比劫夺财（男命） | 克妻信号 |
| 伤官见官（女命） | 克夫信号 |

## 六、家庭全局判断

### 好家庭的八字特征

| 特征 | 解读 |
|------|------|
| 四柱宫位安静少冲 | 家庭平稳，少变动 |
| 财印不战 | 父母关系好 |
| 日支为用神 | 婚姻质量高 |
| 时柱为用神 | 子女运好 |
| 年月日时依次相生 | 家庭代代和谐传承 |
| 魁罡/孤寡不犯 | 没有孤星破坏家庭运 |

### 家庭薄弱的八字特征

| 特征 | 解读 |
|------|------|
| 四柱多冲 | 家庭动荡，人际关系频繁变动 |
| 财破印 + 年柱冲 | 父母离异信号强 |
| 日支被冲克 | 婚姻难稳 |
| 时柱空亡 + 子女星不显 | 子女缘极薄 |
| 孤辰寡宿入命 | 整体六亲缘淡 |
