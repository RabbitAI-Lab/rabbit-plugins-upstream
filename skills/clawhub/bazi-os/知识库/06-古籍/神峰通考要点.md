# 神峰通考要点

> 《神峰通考》，明·张楠（字神峰）著。核心方法：**病药理论**——八字有病不可怕，有药能治即为贵。

---

## 一、病药理论核心

### 1.1 基本原理

```
八字 = 人体
  ↓
有病（失衡）= 命局有缺陷
  ↓
有药（制化）= 用神到位可治
  ↓
药力够 → 层次高（大病大药 = 大贵）
药力不够 → 一般
无药 → 贫贱
无病 → 平淡（无大病之人，亦无大成就）
```

### 1.2 核心口诀

> **"有病方为贵，无伤不是奇。病若遇药，终见荣昌。"**

- "完美"的八字（无冲、无克、平衡）→ 往往**平淡一生**
- 有缺陷但有解决之道的八字 → **可有作为**
- 有缺陷且无解的八字 → **困顿**

## 二、六种病与对治

### 2.1 太旺之病

| 症状 | 药方 | 药力判断 |
|------|------|------|
| 日主过旺 | 官杀克之 / 食伤泄之 / 财耗之 | 药透干+通根 = 能治；药虚浮 = 治不了 |
| 某五行过旺 | 克泄耗该五行 | 同上 |
| 全局火炎土燥 | 水调候润之 | 壬癸水透干有力 = 可治 |

**经典案例**：
- 日主丙火生于巳月，四柱火土重重 → 病"火炎土燥" → 药"壬水调候"
- 若壬水透干坐子水 → 药力强，可治 → 富贵可期
- 若只有一点癸水藏于未中 → 药力弱 → 杯水车薪，治不了

### 2.2 太弱之病

| 症状 | 药方 | 药力判断 |
|------|------|------|
| 日主过弱 | 印生之 / 比劫助之 | 需通根才有力 |
| 用神虚弱 | 生扶用神之五行 | 需大运补 |
| 某五行虚浮无根 | 大运补根 | 等相应大运 |

### 2.3 冲战之病

| 症状 | 药方 | 实例 |
|------|------|------|
| 金木交战 | **水通关**（金生水→水生木） | 用水泄金生木，化敌为友 |
| 火金交战 | **土通关**（火生土→土生金） | 用土泄火生金 |
| 木土交战 | **火通关**（木生火→火生土） | 用火泄木生土 |
| 水火相冲 | **木通关**（水生木→木生火） | 用木泄水生火 |
| 土水相战 | **金通关**（土生金→金生水） | 用金泄土生水 |

> **通关是最好的药**：不压制任何一方，而是架桥让双方和解。

### 2.4 混杂之病

| 症状 | 药方 | 优先级 |
|------|------|------|
| **官杀混杂** | 合去一个（去杀留官为上） | 去杀留官 > 去官留杀 |
| **食伤混杂** | 合去一个 | — |
| **正偏印混杂** | 合去偏印（去枭留印） | 去枭留印为上 |
| **正偏财混杂** | 不一定是病，看配合 | 格局清则吉 |

### 2.5 无情之病

| 症状 | 药方 |
|------|------|
| 用神被忌神冲克 | **制忌神**、护用神 |
| 忌神得生扶 | 克制忌神源头 |
| 吉神被合走 | 看合化后是否还有用 |

### 2.6 无根之病

| 症状 | 药方 |
|------|------|
| 日主虚浮无根 | 等大运通根之运 |
| 用神虚浮无根 | 等大运补根，或格局层次降级 |
| 六亲星虚浮无根 | 该六亲缘浅或身体弱 |

## 三、药力等级

| 等级 | 条件 | 效果 |
|------|------|------|
| **大药** | 药透干 + 通根有力 + 不被冲克 + 贴身 | 彻底治好，命局层次跃升 |
| **中药** | 药透干但根弱 / 藏干有力但未透 | 部分治好，中等层次 |
| **小药** | 药只在藏干中微现 | 略有缓解，层次一般 |
| **无药** | 药完全不存在 | 病无法治，须等大运 |
| **假药** | 药被冲克 / 药落空亡 | 有名无实，治不了 |

---

## 四、病药与调候的关系

| 情况 | 处理 |
|------|------|
| 调候用神 = 病药用神 | 最优，两派结论一致 |
| 调候用神 ≠ 病药用神 | 以调候为主，病药为辅助视角 |
| 无调候问题（中和） | 病药成为主要诊断工具 |
