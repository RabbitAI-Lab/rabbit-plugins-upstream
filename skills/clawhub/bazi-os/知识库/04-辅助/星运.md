# 星运

在八字命理学中，"星运"并非指真实的天体，而是对命盘中各种吉凶符号、五行生克关系及能量状态的统称。星运主要可分为三大类：**十二长生星运**、**十神星运**和**神煞星运**。

## 一、十二长生星运（十二运）

十二长生是以日干为基准，描述五行气场从产生、鼎盛到消亡、再生的十二个阶段，代表运势的起伏状态。

| 阶段 | 含义 |
|------|------|
| **长生** | 代表新生和希望，运势顺遂，事业发展，身体强健 |
| **沐浴** | 代表洗涤和变化，状态不稳定，易有变动或情感波动 |
| **冠带** | 代表成熟和壮大，事业顺利，人际关系和谐 |
| **临官（建禄）** | 代表得势和掌权，权力地位上升，财运亨通 |
| **帝旺** | 代表极致和鼎盛，万事如意，发展达到高峰 |
| **衰** | 代表衰退和无力，运势下滑，健康易出问题 |
| **病** | 代表疾病和困厄，健康不佳，事业受阻 |
| **死** | 代表消亡和终结，运势低迷，可能遭遇变故 |
| **墓** | 代表收藏和隐匿，运势平稳，适合静养 |
| **绝** | 代表断绝和绝境，运势消沉，事业难有起色 |
| **胎** | 代表孕育和萌发，有转机，新事物可能出现 |
| **养** | 代表养护和调养，运势平稳，宜休养生息 |

> 十二长生在日柱自坐的应用，详见 [[自坐详解#2. 按十二长生位分类|自坐·十二长生分类]]。

## 二、十神星运（正星）

十神是根据日干与其他干支的生克关系推导出的十种角色，代表个人的性格、六亲及人生各领域的吉凶。

| 十神 | 含义 |
|------|------|
| **正官** | 代表名声、地位、事业、责任感 |
| **偏官（七杀）** | 代表权力、魄力、竞争、压力或凶险 |
| **正印** | 代表学业、贵人、长辈、文化修养 |
| **偏印（枭神）** | 代表智慧、谋略、宗教或直觉 |
| **正财** | 代表稳定收入、财富、妻子或物质享受 |
| **偏财** | 代表意外之财、投资、投机或父亲 |
| **食神** | 代表才华、口福、艺术、子女 |
| **伤官** | 代表聪明、叛逆、表现欲、口舌是非 |
| **比肩** | 代表兄弟姐妹、朋友、同事、助力 |
| **劫财** | 代表竞争对手、冲动、破耗、争夺 |

> 十神的详细定义与分组，详见 [[十神]]。

## 三、神煞星运（辅星/杂星）

神煞是特殊的干支组合符号，分为吉星、凶星和中性星，用于辅助判断命运的吉凶祸福。

### 吉星（主富贵、福气）

- **天乙贵人**：最吉之神，主逢凶化吉，得贵人相助
- **天德贵人/月德贵人**：主福德深厚，化解灾厄，性格仁慈
- **文昌星**：主学业、才华，利考试和文化学术工作
- **禄神（禄存星）**：主福禄财源、衣食丰足
- **将星**：象征领导力，易掌权
- **天魁星/天钺星**：主贵人相助、权力地位、官运亨通
- **紫微星**：帝王之星，主贵气、权势
- **天府星**：主富贵、福气、家庭和睦
- **武曲星**：主武功、竞争力和事业成功
- **三台星/八座星**：主科举升官、名利双收及房地产运
- **天马星**：主驿马运（奔波、旅行），利远方发展
- **福星/天贵星**：主福气和喜庆，一生衣食无忧
- **红鸾星/天喜星**：主姻缘、桃花运，感情机遇
- **学堂星/天厨星**：主学业有利、美食机遇
- **天医星**：主健康养护

### 凶星（主波折、灾厄）

- **七杀星**：主凶险、意外、疾病或争斗
- **破军星**：破坏力强，主破财、官非、事业变动或婚姻不顺
- **羊刃星（擎羊星）**：主刚烈冲动、血光之灾或官非，需有制化方可转吉
- **劫煞**：主破财、意外、是非
- **孤辰寡宿**：主孤独，不利婚姻人际
- **空亡（旬空）**：象征虚浮无力，吉神空则减福，凶神空则减凶
- **亡神**：伴随财物损失或意外伤害
- **丧门星**：主晦气，入命期间不利探病问丧
- **病符星**：影响身体健康
- **阴煞星**：带来负面影响，可通过行善积德减轻
- **灾煞**：主灾祸，需注意方位气场调整
- **五鬼星**：主凶险、灾厄
- **卷舌星**：主口舌纠纷，需培养宽容心态化解

### 中性星（吉凶参半，需结合全局）

- **驿马星**：主变动、远行，有人因奔波升职加薪，有人则劳碌影响健康
- **桃花星（咸池）**：主异性缘，为用则人缘佳，为忌则易陷感情纠纷
- **华盖星**：主艺术、宗教天赋，但易孤高、人际疏离
- **贪狼星**：主桃花、风流、欲望强烈，艺术天分高，易招惹是非
- **廉贞星**：主孤傲清高、官禄，人际关系较差，事业多坎坷
- **巨门星**：主口舌是非，但也代表口才好、表达能力强
- **天同星**：主福气、安逸、享受悠闲
- **天相星**：主仁慈、宽厚，适合做顾问
- **太阴星**：主温柔、贤惠、善解人意
- **太阳星**：主光明、积极、热情开朗
- **天机星**：主智慧、机灵、善于交际

## 总结

在八字命理分析中，星运的判断极为复杂。十神和十二长生构成了命局分析的核心骨架，而神煞则是重要的辅助参考。星运的吉凶并非绝对，必须结合五行旺衰、格局组合以及大运流年等综合因素来推断，不可单论某一星曜定吉凶。
