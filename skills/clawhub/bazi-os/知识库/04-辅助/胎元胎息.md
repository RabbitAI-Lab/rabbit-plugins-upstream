# 胎元与胎息

胎元是母体受孕之月，胎息是受孕之时。二者是八字之外的"暗柱"，代表命主先天的原始禀赋和隐藏信息。

---

## 一、胎元

### 什么是胎元？

胎元 = 出生月份向前推十个月（约 300 天），即受孕之月。以干支表示。

### 胎元推算

```
胎元天干 = 月干顺数一位
胎元地支 = 月支顺数三位
```

| 月柱 | → 胎元 | 口诀 |
|------|---------|------|
| 甲寅 | 丁巳 | 天干进一、地支进三 |
| 乙卯 | 戊午 | |
| 丙辰 | 己未 | |
| 丁巳 | 庚申 | |
| 戊午 | 辛酉 | |

> 天干顺序：甲乙丙丁戊己庚辛壬癸 → 进一
> 地支顺序：子丑寅卯辰巳午未申酉戌亥 → 进三

**月份特殊处理**：地支进三超过"亥"则循环回"子"。如亥月 → 顺三为寅，子月 → 顺三为卯。

### 胎元的意义

| 胎元状态 | 含义 |
|----------|------|
| 胎元为用神 | 先天禀赋好，根基深厚 |
| 胎元为忌神 | 先天不足，体质偏弱 |
| 胎元与年柱同 | 祖荫深，家族信息强 |
| 胎元与日柱同 | 自我与先天高度一致 |
| 胎元与月柱冲 | 先天受孕时母体不安 |
| 胎元与命局某柱合 | 有隐藏的贵人/缘分 |
| 胎元空亡 | 先天根基弱的信号 |
| 胎元纳音克年柱纳音 | 祖上父母不利 |

---

## 二、胎息

### 什么是胎息？

胎息即受孕的时辰。如果胎元是月，胎息就是受孕的日时。

### 胎息推算

```
胎息天干 = 日干与时干合化之天干
胎息地支 = 日支与时支合化之地支
```

> 如甲日己时，甲己合土，胎息天干取戊（土之阳干）。

> ⚠️ 部分流派以日柱纳音五行生克来推算胎息，方法各异。胎息在实战中使用较少，八字轻重缓急上优先级低于胎元。

### 胎息的意义

- 胎息为用 → 先天根基极深厚，身体素质好
- 胎息被冲 → 在母胎中曾受惊扰
- 胎息与命局组成三合三会 → 隐藏的大运引动点

---

## 三、胎元与命局的互动

| 关系 | 含义 |
|------|------|
| 胎元生命局 | 先天滋养后天，命主受孕育良好 |
| 命局克胎元 | 后天力量反制先天，体质偏弱 |
| 胎元命局通气 | 先天后天一致，顺遂 |
| 胎元命局冲克 | 先天后天矛盾，人生波折 |
| 大运填实胎元 | 该大运引发先天之事（祖荫、家族、遗传等） |
