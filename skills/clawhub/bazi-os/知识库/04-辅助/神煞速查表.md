# 神煞速查表

> 神煞是特殊的干支组合符号，分为吉神、凶煞和中性星，用于辅助判断命运的吉凶祸福。

## 一、吉神贵人类

| 神煞 | 查法（摘要） | 含义 |
|---|---|---|
| **天乙贵人** | 以日干/年干查四支。甲戊丑未，乙己子申，丙丁亥酉，壬癸卯巳，辛寅午 | 最尊贵吉神，逢凶化吉，遇事有人帮 |
| **天德贵人** | 以月支查天干地支。正丁二申三壬四辛，五亥六甲七癸八寅，九丙十乙冬巳腊庚 | 一生吉利，逢凶化吉，主先天之福 |
| **月德贵人** | 以月支三合局起天干。寅午戌月丙，申子辰月壬，亥卯未月甲，巳酉丑月庚 | 主宽厚、福分、人缘佳，逢凶化吉 |
| **天德合** | 由天德所合之干支推（如天德在丁，丁壬合，壬为天德合） | 助天德之力，重合化是否有情 |
| **月德合** | 由月德天干六合推。月德丙合辛，壬合丁，甲合己，庚合乙 | 补月德之力，常看人缘与助力 |
| **太极贵人** | 以日干查四支。甲乙子午，丙丁卯酉，戊己辰戌丑未，庚辛寅亥，壬癸巳申 | 喜玄学、学问、悟性，逢吉更显 |
| **三奇贵人** | 天干顺见乙丙丁（地下）、甲戊庚（天上）、壬癸辛（人中） | 主奇遇、才华、博学多能，胸怀坦荡 |
| **福星贵人** | 以日干查四支。甲丙相邀入虎乡，乙癸逢牛卯禄昌…… | 主衣食、福气、安穩，一生福禄无缺 |
| **国印贵人** | 以日干查四支。甲戌乙亥丙戊丑，丁己寅，庚辰辛巳，壬未癸申 | 主印信、名位、制度、资格，诚实可靠 |

| **日德** | 指定日柱：甲寅、丙辰、戊辰、庚辰、壬戌 | 主厚道、福德、解凶 |
| **日贵** | 指定日柱：丁酉、丁亥、癸巳、癸卯 | 主日坐贵人，气质清贵 |
| **天赦（天赦日）** | 以日柱论。春戊寅，夏甲午，秋戊申，冬甲子 | 主赦免、解厄、转圜，逢凶化吉 |

## 重要提醒

以上整理涵盖了近百种神煞。但需要强调的是：

1. **神煞仅为辅助参考**：神煞是在五行旺衰、十神、格局、刑冲合害基础上的辅助论断工具，不宜把单一神煞当成断命结论。
2. **神煞需看坐旺坐绝**：如桃花坐旺则征兆明显，坐绝则接近于无；吉神逢刑冲也一样无用。
3. **神煞需兼论刑冲合会**：神煞遇冲、遇合均会影响其效应，坐空亡则不论吉凶俱作减半论。
4. **神煞要结合年限位置**：神煞在年主幼年，在月主青年，在日主中年，在时主晚年，需依据人生实际形态推论。
