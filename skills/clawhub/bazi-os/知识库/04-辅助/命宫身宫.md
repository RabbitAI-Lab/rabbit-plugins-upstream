# 命宫与身宫

十二宫是八字之外的辅助参照系，其中**命宫**和**身宫**最为重要。命宫看先天之命，身宫看后天之身。

---

## 一、命宫

命宫代表命主的**先天根基、气质禀赋**，是八字之外的"第六柱"。

### 命宫推算

以**月支**和**时支**为基准：

```
命宫地支 = 月支 + 时支对应位
命宫天干 = 按年上起月法（五虎遁）推
```

**地支推算口诀**：

> 正月起寅，逆数至生月。再从生月位顺数至生时，即为命宫。

**具体步骤**：
1. 正月从寅位起，逆数到出生月份 → 得到一个地支位
2. 从该位起子时，顺数到出生时辰 → 得到命宫地支
3. 用五虎遁（年上起月）推命宫天干

> **速查法**：十四减去（月数+时数），再按寅1、卯2……排列。若月数+时数>14，则用26减去。

### 命宫的意义

| 命宫状态 | 含义 |
|----------|------|
| 命宫为用神 | 先天根基好，有贵气 |
| 命宫为忌神 | 先天条件受限 |
| 命宫与年柱同 | 祖荫深厚 |
| 命宫与日柱同 | 自我意识极强 |
| 命宫空亡 | 根基虚浮，中年后才能稳住 |
| 命宫逢冲 | 一生大起大落 |

### 命宫坐十二支简断

| 子 | 聪明圆滑、善社交 |

## 二、身宫

身宫代表命主的**后天形态、身体状态**，是命宫的补充。

### 身宫推算

以**月支**和**时支**为基准：

```
身宫地支 = 从正月寅位顺数至生月，再从该位起子时逆数至生时
```

**口诀**：与命宫方向相反——命宫正月起寅逆数，身宫正月起寅顺数。

### 身宫的意义

| 身宫状态 | 含义 |
|----------|------|
| 身宫为用神 | 后天条件好，能补先天不足 |
| 身宫为忌神 | 身体弱、后天环境差 |
| 身宫与命宫同 | 表里如一，先天后天一致 |
| 身宫与命宫冲 | 内心矛盾，外在表现与内心不符 |
| 身宫坐驿马 | 一生奔波，宜动不宜静 |
| 身宫坐桃花 | 异性缘旺，感情丰富 |

---

## 三、命宫与身宫的配合

| 关系 | 含义 |
|------|------|
| 命宫强 + 身宫强 | 先天后天皆好，根基扎实 |
| 命宫强 + 身宫弱 | 先天好但后天跟不上，身体偏弱 |
| 命宫弱 + 身宫强 | 先天一般但后天努力可补 |
| 命宫弱 + 身宫弱 | 需格外注意健康和根基稳定 |
| 命身相生 | 表里协调一致 |
| 命身相冲 | 内外矛盾，人生波折多 |
