# 刑冲合害

天干地支之间的合、冲、刑、害，是八字中最核心的动力学。十神讲"是什么"，刑冲合害讲"怎么动"。

---

## 一、天干关系

### 天干五合（合化）

| 合 | 化气 | 合化条件 |
|----|------|----------|
| 甲己合 | 土 | 地支有辰戌丑未，或月令为土 |
| 乙庚合 | 金 | 地支有申酉，或月令为金 |
| 丙辛合 | 水 | 地支有亥子，或月令为水 |
| 丁壬合 | 木 | 地支有寅卯，或月令为木 |
| 戊癸合 | 火 | 地支有巳午，或月令为火 |

> **合化成功** = 两者失去原性，化为新五行；**合而不化**（绊住）= 两者互相牵制，谁也使不上力。

**争合**：两个天干同时合一个天干（如两甲合一己）→ 争夺之象，婚姻易有第三者。

### 天干相冲

| 冲 | 关系 |
|----|------|
| 甲庚冲 | 金木交战 |
| 乙辛冲 | 金木交战 |
| 丙壬冲 | 水火相冲 |
| 丁癸冲 | 水火相冲 |

> 天干冲较少被单独强调，但天克地冲（天干相克+地支相冲）是凶格。

## 二、地支六合

| 合 | 化气 | 意象 |
|----|------|------|
| 子丑合 | 土 | 阴水与湿土结合，黏滞 |
| 寅亥合 | 木 | 木得水生，合中带破 |
| 卯戌合 | 火 | 花草入炉，合中带克 |
| 辰酉合 | 金 | 湿土生金，亲密 |
| 巳申合 | 水 | 火金相合，合中带刑 |
| 午未合 | 土 | 火生土，阳光普照 |

**实战要点**：
- 合 = 牵绊，被合住的地支失去部分行动力
- 日支被合 → 配偶被外界牵制（事业、桃花等）
- 月支被合 → 事业根基被动摇
- 合而不化 → 两者都使不上全力
- 合化成功 → 以化气为新五行

## 三、地支三合局

三个地支构成一个完整的五行局，力量极强：

| 三合局 | 五行 | 长生 | 帝旺 | 墓库 |
|--------|------|------|------|------|
| 申子辰 | 水 | 申 | 子 | 辰 |
| 亥卯未 | 木 | 亥 | 卯 | 未 |
| 寅午戌 | 火 | 寅 | 午 | 戌 |
| 巳酉丑 | 金 | 巳 | 酉 | 丑 |

**半合**（两个地支）：
- **生地半合**（长生+帝旺）：申子、亥卯、寅午、巳酉 → 力量较强
- **墓库半合**（帝旺+墓库）：子辰、卯未、午戌、酉丑 → 力量稍弱

> 三合局力量 > 六合，是八字中最强的合。三合局成则长生、帝旺、墓库三支连成一体。

| 三会局 | 方位 | 地支 | 力量 |

> 三会局力量 > 三合局。会局成则一方之气独旺。

## 五、地支六冲

互相对冲，力量最大、反应最直接：

| 冲 | 五行 | 意象 |
|----|------|------|
| 子午冲 | 水火冲 | 情绪极端、心血管问题 |
| 丑未冲 | 土土冲 | 固执冲突、脾胃问题 |
| 寅申冲 | 金木冲 | 车祸外伤、筋骨问题 |
| 卯酉冲 | 金木冲 | 肝胆肺病、门面破败 |
| 辰戌冲 | 土土冲 | 库被打开、大进大出 |
| 巳亥冲 | 水火冲 | 突发变故、出行意外 |

**冲的层次**：
- **近冲**（相邻两柱相冲）> **远冲**（年时相冲）
- **月日相冲**：提纲与自身相冲，一生动荡
- **日时相冲**：婚姻不稳、子女缘薄
- **大运冲命局**：十年大变动
- **流年冲命局**：当年大变动

**冲的结果**：
- 冲旺（忌神被冲）→ 吉
- 冲败（用神被冲）→ 凶
- 冲开墓库 → 爆发（好坏看库中所藏是为用还是为忌）

## 六、地支六害（相穿）

暗中伤害，不正面冲突但背地里使坏：

| 害 | 关系 | 意象 |
|----|------|------|
| 子未害 | 水克土 | 恩将仇报、好心没好报 |
| 丑午害 | 土克火 | 互相伤害、两败俱伤 |
| 寅巳害 | 木火相害 | 表面友好、暗中算计 |
| 卯辰害 | 木克土 | 剥皮之害、渐进破坏 |
| 申亥害 | 金水相害 | 嫉妒之害、暗中破坏 |
| 酉戌害 | 金土相害 | 背后捅刀、失信 |

> 害不如冲直接，但更阴险。配偶宫被害 → 夫妻面和心不和。害在年月 → 家族内部暗斗。

## 七、地支三刑

| 刑 | 类型 | 地支 | 意象 |
|----|------|------|------|
| 无恩刑 | 三刑 | 寅巳申 | 恩将仇报、好心没好报 |
| 恃势刑 | 三刑 | 丑戌未 | 仗势欺人、互相残害 |
| 无礼刑 | 两刑 | 子卯 | 以下犯上、不讲礼数 |
| 自刑 | 自刑 | 辰、午、酉、亥 | 自我伤害、内心折磨 |

**刑的特点**：
- 带有"法律""纠纷"性质
- 自刑（辰见辰、午见午、酉见酉、亥见亥）→ 自我内耗、自己跟自己过不去
- 三刑全 → 法律诉讼、官非、手术
- 两刑 → 小磕碰、口舌是非

## 八、合冲刑害的力量排序

```
三会 > 三合 > 半合 > 六合 > 冲 > 刑 > 害
```

### 优先规则

| 规则 | 说明 |
|------|------|
| **合能解冲** | 有冲又有合，合优先，冲被解 |
| **冲能解合** | 先合后冲 → 合被冲开，关系破裂 |
| **合能解刑害** | 合住则不刑不害 |
| **贪合忘冲/忘克** | 某字被合住 → 顾不上冲克其他字 |
