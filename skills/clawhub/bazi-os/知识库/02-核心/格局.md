# 八字格局

格局是八字命理中判断命主一生层次高低、事业成就、人生走向的核心框架。如果说五行十神是"零件"，格局就是将这些零件组合起来形成的有意义的"结构"。

> 格局的精髓在于 **"成格者贵，破格者贱"** — 格局成立则层次高，格局破坏则一生多舛。

---

## 一、格局概论

### 什么是格局？

格局是指月令（月支藏干）透出天干后，与日主及其他干支形成的特定组合关系。传统子平法以**月令取格**为核心，再配合四柱生克制化来判断格局成败。

### 格局的三大要素

1. **格**：由月令藏干透出而定，如正官格、食神格等
2. **局**：干支配合形成的特定结构，如三合局、三会局等
3. **用神**：维护格局平衡的关键十神

---

## 二、正格（八格）

以月令十神为基准，分为正八格：

### 1. 正官格

月令藏干透正官，或正官得令。

- **性格**：正直端庄，重视名誉，遵纪守法，有领导力
- **事业**：适合公职、管理、体制内发展
- **成败关键**：
  - 喜财星生官、印星护官
  - 忌伤官克官（伤官见官，为祸百端）
  - 忌官杀混杂（正官与七杀同现）
  - 忌身弱官强（官变为压力）

### 2. 七杀格（偏官格）

月令藏干透七杀，或七杀得令。

- **性格**：果敢刚毅，魄力十足，雷厉风行，但急躁易怒
- **事业**：适合军警、外科、竞争性强的行业
- **成败关键**：
  - **食神制杀**：以食神克制七杀，化煞为权，贵格
  - **杀印相生**：印星化杀生身，文武双全
  - 忌身弱无制（杀攻身，灾祸不断）
  - 忌财星党杀（财生杀旺，更凶）

### 3. 正财格

月令藏干透正财，或正财得令。

- **性格**：勤俭务实，重视物质，信守承诺，但可能趋于保守
- **事业**：适合金融、财会、实体经济
- **成败关键**：
  - 喜身旺承载（身旺才能任财）
  - 喜食伤生财（才华变现）
  - 忌身弱财旺（富屋贫人，财来财去）
  - 忌比劫夺财（破财、合伙纠纷）

### 4. 偏财格

月令藏干透偏财，或偏财得令。

- **性格**：慷慨大方，善于交际，投资眼光好，但花钱冲动
- **事业**：适合投资、贸易、销售、创业
- **成败关键**：
  - 喜身旺，财来能受
  - 忌比劫夺财（比正财格更忌，因偏财为众人之财）
  - 喜官星护财

### 5. 正印格

月令藏干透正印，或正印得令。

- **性格**：仁慈善良，好学不倦，有文化底蕴，但易依赖
- **事业**：适合教育、文化、学术、慈善
- **成败关键**：
  - 喜官杀生印（官印相生，贵格）
  - 忌财星破印（财克印，学业受阻，贵人失势）
  - 忌印星过旺（过于依赖，缺乏独立）

### 6. 偏印格（枭神格）

月令藏干透偏印，或偏印得令。

- **性格**：思维独特，悟性极高，善于钻研，但孤僻多疑
- **事业**：适合科研、技术、宗教、玄学
- **成败关键**：
  - 忌食神被夺（**枭神夺食**，才华受压抑，有口难言）
  - 喜偏财制枭（财星克偏印，化解枭性）

### 7. 食神格

月令藏干透食神，或食神得令。

- **性格**：温和宽厚，乐天知命，有口福，艺术天赋高
- **事业**：适合文艺、餐饮、教育、创意行业
- **成败关键**：
  - 喜食神生财（技艺谋生，细水长流）
  - 喜食神制杀（以柔克刚，化敌为友）
  - 忌枭神夺食（才华被压制，抑郁不得志）
  - 忌食神过旺（贪图安逸，缺乏进取）

### 8. 伤官格

月令藏干透伤官，或伤官得令。

- **性格**：聪明绝顶，才华横溢，口才犀利，但叛逆好胜
- **事业**：适合艺术、设计、演说、技术研发
- **成败关键**：
  - 喜伤官生财（才华变现，名利双收）
  - 喜印制伤官（约束锋芒，反成贵气）
  - **忌伤官见官**（最忌，以下详解）
  - 忌身弱伤旺（精力透支，怀才不遇）

## 三、重要格局组合详解

### 伤官见官

> "伤官见官，为祸百端" — 伤官克制正官，是格局中最凶险的组合之一。

**构成条件**：
- 命局中伤官与正官同现且无解救
- 伤官旺而正官弱
- 大运流年引动伤官冲克正官

**各层面影响**：

| 层面 | 表现 |
|------|------|
| 事业 | 与上司冲突、不服管束、频繁跳槽、创业难成 |
| 官非 | 容易招惹官司、口舌是非、合约纠纷 |
| 女命 | 克夫之象，婚姻不顺，感情多波折 |
| 性格 | 过于自我、目中无人、得理不饶人 |

**化解条件**：
- **有财星通关**：伤官生财，财生官，伤官不但不克官反而间接助官 → 最妙化解
- **有印制伤官**：约束锋芒，伤官被制则官星得护
- **身弱官强**：伤官反而起到制衡作用，不为祸

### 食神制杀

> "食神制杀，英雄独压万人" — 以柔克刚，化敌为友，是七杀格的上佳配合。

**构成条件**：
- 命局七杀当令或旺相
- 食神有力，能克制七杀
- 日主有根，身不太弱

**表现**：
- 以智谋化解危机，以柔和的领导力统御部属
- 适合当领导、管理者、决策者
- 处事从容，不怒而威

**忌**：
- 偏印（枭神）夺食：枭神克食神，食神无法制杀，格局破败
- 财星党杀：财生杀旺，食神制不住

### 杀印相生

> "杀印相生，功名显达" — 七杀生印，印生身，化压力为动力。

**构成条件**：
- 七杀旺（压力大）
- 印星透出化杀
- 日主得印生

**表现**：
- 在巨大压力下成长，越挫越勇
- 文武双全，既有魄力又有智慧
- 多成大器，特别是公检法、军队、管理层

### 财官双美

> 财生官，官护财，财官不相伤，名利双收。

**构成条件**：
- 正财与正官同现
- 两者有力且不相克
- 日主有根可任财官

**表现**：
- 事业有成，财富稳定，社会地位高
- 为人稳重务实，既有经济头脑又有管理能力
- 男命妻贤子贵，女命夫荣子贵

### 食神生财

> "食神生财，富贵自天来" — 靠才华技艺创造财富。

**构成条件**：
- 食神有力
- 食神能生到财星
- 日主身旺能任

**表现**：
- 以技艺、才华、创意赚钱
- 财运细水长流，不暴富但稳定
- 适合艺术家、设计师、厨师、咨询师等

**忌**：
- 枭神夺食 → 才华变现渠道被断
- 比劫直接夺财 → 辛苦赚的钱被分走

### 枭神夺食

> "枭神夺食，饥寒交迫" — 偏印克食神，最凶的格局破坏之一。

**构成条件**：
- 食神格或食神为用
- 偏印（枭神）透出克制食神

**表现**：
- 才华无法施展，怀才不遇
- 说话做事总被打压
- 情绪压抑，易抑郁
- 女命：不利子女
- 身体：消化系统易出问题

**化解**：
- 偏财制枭：财星克偏印，保护食神
- 比劫化枭生食：比劫泄枭生食，通关

### 财破印（财星坏印）

> 财星克制印星，学业、贵人、名声受损。

**表现**：
- 为钱财放弃学业或名誉
- 贵人因利益关系疏远
- 贪财坏德，因小失大

**化解**：
- 官杀通关：财生官，官生印，财不直接克印
- 比劫制财护印

## 四、外格（特殊格局）

除了正八格，还有一些特殊格局（外格），多为贵格：

| 格局 | 构成 | 特点 |
|------|------|------|
| **专旺格** | 某一五行极旺成势（曲直格、炎上格、稼穑格、从革格、润下格） | 从强而顺，忌克制 |
| **从格** | 日主极弱，弃命从强（从杀格、从财格、从儿格等） | 顺从旺势，忌帮扶日主 |
| **化气格** | 天干五合成化（甲己化土、乙庚化金等） | 以化神为用 |
| **两神成像格** | 两种五行各占一半，势均力敌 | 清纯专一，忌第三种五行介入 |

## 五、格局成败判断口诀

1. **有杀先论杀**：七杀为凶神，先看能否制化
2. **有官先看官**：正官为贵气，先看是否纯清无损
3. **用神有力格局高**：保护格局的十神旺而有力
4. **忌神无制格局低**：破坏格局的十神无制则一生多舛
5. **通关为贵**：相战的十神之间有通关之神，格局提升

## 六、格局取法（如何定格局）

### 月令取格法（子平正统）

以月支本气藏干透出天干取格。月令是八字的"提纲"，格局由月令定。

**步骤**：
1. 看月支的藏干
2. 看哪个藏干透出了天干
3. 透出的藏干与日主的关系，即为"格"

**示例**：日主甲木，生于酉月（酉藏辛金）：
- 天干透辛金 → 正官格（辛金克甲木，阴阳相异）
- 天干透庚金 → 七杀格（庚金克甲木，阴阳相同）

### 透干取格细则

| 情况 | 取格规则 |
|------|----------|
| 月支仅一个藏干透出 | 直接取该十神为格 |
| 月支多个藏干透出 | 取**本气**为格（优先本气） |
| 月支藏干均不透 | 取**本气藏干**与日主的关系为格（虚格） |
| 月令为比劫（寅卯月木日主） | 取**建禄格**（月令为禄）或**月刃格**（月令为羊刃） |
| 其他天干透出非月支藏干 | 取**变格**，权重次于月令格 |

### 格局的优先级

当命局同时满足多个格局条件时（如月令正官但全局七杀也多）：

| 优先级 | 格局 | 说明 |
|--------|------|------|
| 1 | 七杀格 | 有杀先论杀 |
| 2 | 正官格 | 官为贵气 |
| 3 | 月令正格 | 食伤格、财格、印格 |
| 4 | 建禄/月刃格 | 比劫当令 |
| 5 | 变格/外格 | 从格、专旺格等 |

### 格局成败三要素

| 要素 | 说明 |
|------|------|
| **透干** | 月令藏干透出天干 → 格局成立 |
| **有护** | 格局的保护神存在（如正官格见财印） |
| **无破** | 格局的破坏神不现（如正官格无伤官） |

### 格局随大运变化

格局不是一成不变的——大运可以补格局不足，也可能破坏原有格局：

- 原局不成格 + 大运补上 = 此十年格局成立，运势提升
- 原局成格 + 大运破坏 = 此十年格局破败，运势下滑
- 原局破格 + 大运来救 = 此十年转危为安
