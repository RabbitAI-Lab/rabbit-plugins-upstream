# 用神体系

> 用神不是单一答案，而是一个**五层嵌套系统**。不同流派在不同层级上各有侧重，顶级命理师在五层之间灵活切换。

---

## 一、五类用神总览

| 类型 | 作用 | 来源 | 优先级 | 核心问题 |
|------|------|------|:--:|------|
| **调候用神** | 调节全局寒暖燥湿 | 《穷通宝鉴》 | **1st** | 命局"舒不舒服"？ |
| **格局用神** | 成就格局之关键 | 《子平真诠》 | 2nd | 命局"成不成立"？ |
| **病药用神** | 治疗命局之"病" | 《神峰通考》 | 3rd | 命局"哪里有病"？ |
| **通关用神** | 化解五行冲战 | 《滴天髓》 | 4th | 命局"哪儿打架"？ |
| **扶抑用神** | 平衡日主强弱 | 通用 | 5th | 命局"扛不扛得住"？ |

---

## 二、各类用神详述

### 2.1 调候用神（第一优先级）

**来源**：《穷通宝鉴》

**判断方法**：
- 看日主 × 月令的气候组合
- 寒 → 用火暖，燥 → 用水润
- 详见 [[../06-古籍/穷通宝鉴要点]]

**铁则**：
- 调候用神与格局用神冲突 → **调候优先**
- 调候得宜 → 即使格局一般，人生平顺
- 调候失调 → 格局再高，怀才不遇

**示例**：
- 丙火巳月 → 调候用水（壬水最佳）→ 壬水透干有力 → 调候得宜
- 庚金午月 → 调候用水（壬水护金）→ 无水 → 火旺金熔，辛苦

---

### 2.2 格局用神（第二优先级）

**来源**：《子平真诠》

**判断方法**：
- 看格局是什么 → 格局需要什么来成格
- 正官格 → 用印护官（官印相生）
- 财格 → 用官护财（财生官）
- 印格 → 用官生印（官印相生），或用食伤泄秀
- 食伤格 → 用财泄食伤（食伤生财）
- 七杀格 → 用食神制杀 / 用印化杀

**铁则**：
- 格局用神是格局成功的关键
- 格局用神被冲克 → 破格，大运补可复

---

### 2.3 病药用神（第三优先级）

**来源**：《神峰通考》

**判断方法**：
- 找命局最大的"病"
- 找能治这个病的"药"
- 详见 [[../06-古籍/神峰通考要点]]

**六病**：太旺 / 太弱 / 冲战 / 混杂 / 无情 / 无根

**示例**：
- 病 = 金木交战 → 药 = 水通关
- 病 = 官杀混杂 → 药 = 合去一个（去杀留官）
- 病 = 用神落空 → 药 = 等大运填实

---

### 2.4 通关用神（第四优先级）

**来源**：《滴天髓》

**判断方法**：
- 看两两五行之间是否冲战
- 冲战 → 用中间五行架桥

| 冲战对 | 通关五行 | 原理 |
|------|------|------|
| 金 ↔ 木 | **水** | 金生水 → 水生木 |
| 火 ↔ 金 | **土** | 火生土 → 土生金 |
| 木 ↔ 土 | **火** | 木生火 → 火生土 |
| 水 ↔ 火 | **木** | 水生木 → 木生火 |
| 土 ↔ 水 | **金** | 土生金 → 金生水 |

**铁则**：
- 有通关 → 冲战化解，双方受益
- 无通关 → 两败俱伤，内耗严重

---

### 2.5 扶抑用神（第五优先级）

**来源**：通用

**判断方法**：
- 身强 → 用克泄耗（官杀克 / 食伤泄 / 财耗）
- 身弱 → 用生扶（印生 / 比劫助）

**铁则**：
- 这是最基础的用神观，但层次最低
- 必须在前四层用神没问题的情况下，扶抑用神才有效
- 单纯的"身强用克泄耗"不考虑调候 → 可能完全用错

---

## 三、用神冲突解决规则

当不同类型的用神指向不同五行时，按以下规则解决：

| 冲突 | 裁决 |
|------|------|
| 调候用神 ≠ 格局用神 | **调候优先**。格局降级为"待大运"层次 |
| 格局用神 ≠ 病药用神 | **格局优先**（成格比治病更重要） |
| 病药用神 ≠ 扶抑用神 | **病药优先**（治病比平衡强弱更重要） |
| 通关用神 ≠ 扶抑用神 | **通关优先**（和解比压制更高级） |

---

## 四、用神得力程度评级

| 等级 | 条件 |
|------|------|
| **A 级**（极得力） | 透干 + 通本气根 + 贴身 + 不被冲克 + 不落空亡 |
| **B 级**（得力） | 透干 + 有根（中气以上）+ 不被冲克 |
| **C 级**（一般） | 透干但根弱 / 藏干有力但未透 |
| **D 级**（弱） | 只在藏干中微现 |
| **E 级**（虚） | 用神落空 / 用神被冲克 |

---

## 五、大运对用神的影响

| 大运用神状态 | 含义 |
|------|------|
| **用神大运** | 大运干支正好是用神五行 → 十年好运 |
| **生用神大运** | 大运生扶用神 → 运势上升 |
| **克用神大运** | 大运克用神 → 运势受损 |
| **填实用神** | 虚浮用神在大运通根 → 用神被激活 |
| **冲破用神** | 大运冲克用神 → 用神被破坏 |
