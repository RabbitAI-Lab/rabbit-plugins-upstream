# 十神

八字中的"十神"共有十个，分别是：**比肩、劫财、食神、伤官、正财、偏财、正官、七杀（又称偏官）、正印、偏印（又称枭神）**。

它们是以日干（代表命主自己）为中心，根据其他干支与日干的五行生克关系，再结合阴阳异同而划分出的十种关系符号。

---

## 基础定义

### 分组概览

| 组别 | 十神 | 生克关系 | 通常代表 |
|------|------|----------|----------|
| **印星** | 正印、偏印 | 生我 | 母亲、长辈、学业、庇护与精神世界 |
| **比劫** | 比肩、劫财 | 同我 | 兄弟、朋友、同辈、竞争与合作 |
| **食伤** | 食神、伤官 | 我生 | 才华、创造力、子女、表达与展示 |
| **财星** | 正财、偏财 | 我克 | 财富、收入、妻子（男命）、物质资源 |
| **官杀** | 正官、七杀 | 克我 | 事业、地位、丈夫（女命）、管束、压力与权力 |

### 界定法则

遵循 **"异性为正，同性为偏"**：与日干阴阳相异者为"正"，阴阳相同者为"偏"。

## 十神详解

---

### 正官

> 克我，阴阳相异。代表约束、规则、官位、丈夫（女命）。

**正面性格**：
- 正直端庄，重视名誉，遵纪守法
- 有责任感，做事有分寸，行为得体
- 自我约束力强，有管理天赋
- 为人公正，适合领导岗位

**负面性格**：
- 官多则变压力，过于拘谨保守
- 死守规矩不知变通，胆小怕事
- 受制于人，缺乏主见

**各柱表现**：
- **年柱正官**：出身正统家庭，幼年受严格管教
- **月柱正官**：青年得志，事业稳定上升
- **日支正官**：配偶正直传统，自我要求高
- **时柱正官**：子女有出息，晚年受尊重

**关键互动**：
- 正官 + 正印 = **官印相生**，贵气文雅
- 正官 + 伤官 = **伤官见官**，大忌，官非口舌
- 正官 + 七杀 = **官杀混杂**，进退两难

---

### 七杀（偏官）

> 克我，阴阳相同。代表压力、竞争、魄力、权力。

**正面性格**：
- 果敢刚毅，行动力超强，敢做敢当
- 有魄力有手腕，能成大事
- 在压力下反而越战越勇
- 领导才能出众，有慑人之威

**负面性格**：
- 急躁易怒，行事霸道，不留情面
- 好斗好胜，容易树敌
- 身弱杀旺则胆小怯懦，被压力压垮
- 多疑多忌，缺乏安全感

**各柱表现**：
- **年柱七杀**：出身艰难，幼年多病或家贫
- **月柱七杀**：青年压力大，但磨练成才
- **日支七杀**：配偶强势，婚姻有压力感
- **时柱七杀**：子女有个性，晚年仍需操劳

**关键互动**：
- 七杀 + 食神 = **食神制杀**，化煞为权，贵格
- 七杀 + 正印 = **杀印相生**，文武双全
- 七杀 + 财星 = **财生杀旺**，为财所累

---

### 正印

> 生我，阴阳相异。代表母亲、学业、贵人、庇护。

**正面性格**：
- 仁慈善良，有同情心，乐于助人
- 好学上进，有文化修养，重视精神生活
- 不计较得失，心胸宽广
- 得长辈、贵人之助

**负面性格**：
- 过于依赖他人，缺乏独立能力
- 印多则懒散，好高骛远，眼高手低
- 过于理想化，脱离现实

**各柱表现**：
- **年柱正印**：出身书香门第，得祖上荫庇
- **月柱正印**：学业顺利，多得师长提携
- **日支正印**：配偶如母如师，受照顾多
- **时柱正印**：晚年安逸，子女贤孝

**关键互动**：
- 正印 + 正官 = **官印相生**，贵格
- 正印 + 伤官 = **印制伤官**，才华得约束，有成就
- 正印 + 正财 = **财破印**，为钱财损名誉学业

---

### 偏印（枭神）

> 生我，阴阳相同。代表继母、特殊技能、玄学、孤独。

**正面性格**：
- 思维独特，悟性极高，善钻研冷门学问
- 有创造力，不走寻常路
- 第六感强，有宗教或玄学天赋
- 在专业领域可达极高造诣

**负面性格**：
- 孤僻多疑，不善交际
- 思想偏激，钻牛角尖
- 缺乏安全感，疑心重
- 对人忽冷忽热，难以捉摸

**各柱表现**：
- **年柱偏印**：与生母缘薄，或被过继
- **月柱偏印**：学业偏科，专精冷门
- **日支偏印**：配偶性格孤僻，精神交流多
- **时柱偏印**：晚年喜静，研究型生活

**关键互动**：
- 偏印 + 食神 = **枭神夺食**，大忌，才华受压制
- 偏印 + 伤官 = 奇才异士，思维超常
- 偏印 + 偏财 = 财制枭，偏印得制反成智谋

---

### 正财

> 我克，阴阳相异。代表稳定收入、妻子（男命）、勤劳所得。

**正面性格**：
- 勤俭务实，脚踏实地，重视积累
- 诚实守信，重视承诺
- 有经济头脑，善于理财
- 对家庭有责任感

**负面性格**：
- 过于看重金钱，有时显得小气
- 缺乏冒险精神，保守守成
- 为财所困，成为金钱的奴隶

**各柱表现**：
- **年柱正财**：祖上有产业，幼年不愁吃穿
- **月柱正财**：青年即可自食其力，有稳定收入
- **日支正财**：配偶是贤内助，持家有方
- **时柱正财**：晚年有积蓄，子女经济独立

**关键互动**：
- 正财 + 正官 = **财官双美**，名利双收
- 正财 + 正印 = **财破印**，为财损名
- 正财 + 食神 = **食神生财**，靠技艺赚钱

---

### 偏财

> 我克，阴阳相同。代表意外之财、投资、父亲、情人。

**正面性格**：
- 慷慨大方，善于交际，人脉广
- 投资嗅觉敏锐，敢冒风险
- 头脑灵活，善于把握机会
- 为人豪爽，不拘小节

**负面性格**：
- 花钱大手大脚，不善储蓄
- 投机心理重，容易大起大落
- 喜新厌旧，感情上不够专一
- 对钱财不够珍惜

**各柱表现**：
- **年柱偏财**：父亲有能力，家境不错
- **月柱偏财**：青年时就有投资头脑，好冒险
- **日支偏财**：配偶善于理财或有外财
- **时柱偏财**：晚年有投资回报，子女大方

**关键互动**：
- 偏财 + 七杀 = 胆子大，高风险高回报
- 偏财 + 偏印 = 借智谋生财
- 偏财 + 比劫 = 众人争财，大忌

---

### 食神

> 我生，阴阳相同。代表才华、口福、艺术、子女、温和。

**正面性格**：
- 温和宽厚，心地善良，人缘极好
- 乐天知命，性格乐观，享受生活
- 艺术天赋高，有审美情趣
- 善于表达，口才流畅自然
- 懂吃会玩，生活品质高
- 有包容心，不计较小事
- 智慧型人才，学东西快
- 有创造力但不过分张扬

**负面性格**：
- 过于安逸懒散，缺乏进取心
- 贪图享受，容易发胖
- 过于感性，有时不切实际
- 缺乏竞争意识，容易满足现状
- 食神过旺则话多、好管闲事

**各柱表现**：
- **年柱食神**：祖上有口福之人，幼年受宠
- **月柱食神**：性格温和，人缘好，适合与人打交道的工作
- **日支食神**：配偶温柔体贴，会照顾人，婚姻生活有情调
- **时柱食神**：晚年安逸，子女孝顺且有才艺

**食神的五行属性差异**：
- 木食神（甲日见丙）：热情直接，有领导魅力
- 火食神（丙日见戊）：大方豪爽，朋友多
- 土食神（戊日见庚）：稳重可靠，实干型
- 金食神（庚日见壬）：聪明机智，善于应变
- 水食神（壬日见甲）：思维敏捷，口才出众

**关键互动**：
- 食神 + 七杀 = **食神制杀**，以柔克刚，贵格
- 食神 + 正财 = **食神生财**，靠才华赚钱，财运稳定
- 食神 + 偏印 = **枭神夺食**，才华受压制（大忌）
- 食神 + 伤官 = 食伤混杂，想法太多，行动力不足

**职业倾向**：
- 适合文艺创作、餐饮美食、教育培训、心理咨询
- 也适合需要耐心和温和态度的服务型行业

---

### 伤官

> 我生，阴阳相异。代表叛逆、表现欲、聪明、口舌。

**正面性格**：
- 聪明绝顶，反应极快，悟性超群
- 才华横溢，有艺术天赋和创造力
- 口才犀利，表达能力强
- 不甘平凡，有强烈的上进心
- 审美水平高，颜值通常不错

**负面性格**：
- 叛逆好胜，不服管束
- 心高气傲，容易得罪人
- 得理不饶人，言语刻薄
- 情绪波动大，喜怒无常
- 喜新厌旧，缺乏耐性

**各柱表现**：
- **年柱伤官**：幼年聪明但叛逆，家运有起伏
- **月柱伤官**：才华早显但人际关系紧张
- **日支伤官**：配偶颜值高，但感情不稳定
- **时柱伤官**：子女聪明但有个性，晚年不寂寞

**关键互动**：
- 伤官 + 正官 = **伤官见官**，最忌，官非口舌
- 伤官 + 正印 = **印制伤官**，才华得以约束，有成就
- 伤官 + 正财 = **伤官生财**，靠才华变现
- 伤官 + 伤官 = 才华过于泛滥，难以聚焦

---

### 比肩

> 同我，阴阳相同。代表兄弟、朋友、同事、平辈。

**正面性格**：
- 自尊心强，独立自主
- 意志坚定，不轻易放弃
- 公平正直，不占人便宜
- 有同辈缘，朋友多

**负面性格**：
- 固执己见，不善变通
- 自我中心，不喜合作
- 过强则刚愎自用
- 钱财方面大手大脚（比肩克财）

**各柱表现**：
- **年柱比肩**：兄弟姐妹多，幼年竞争强
- **月柱比肩**：朋友圈广，但合作易有矛盾
- **日支比肩**：夫妻如战友，平等但有争执
- **时柱比肩**：子女独立，各走各路

**关键互动**：
- 比肩 + 七杀 = 有胆识有担当，竞争中找到出路
- 比肩 + 财星 = **比劫夺财**，钱财难聚

---

### 劫财

> 同我，阴阳相异。代表竞争对手、冲动、破耗。

**正面性格**：
- 行动力强，做事果断
- 社交能力强，有号召力
- 敢闯敢拼，不畏惧挑战

**负面性格**：
- 冲动易怒，做事不计后果
- 不善于理财，钱来得快去得快
- 好争斗，容易惹是非
- 合作中容易反目成仇

**各柱表现**：
- **年柱劫财**：祖业难守，幼年有竞争
- **月柱劫财**：青年多竞争，不宜合伙
- **日支劫财**：夫妻易争执，财务需分开
- **时柱劫财**：晚年不宜担保借贷

**关键互动**：
- 劫财 + 正财 = 财运被夺，不宜合伙
- 劫财 + 七杀 = 冲动惹祸
- 劫财 + 食神 = 劫财泄于食神，冲动转化为创造力

## 十神生克关系图

```
        生 →
  官杀 ────→ 印星 ────→ 比劫 ────→ 食伤 ────→ 财星
 （克我）    （生我）    （同我）    （我生）    （我克）
         ← 克
```

- **相生链**：官杀 → 印星 → 比劫 → 食伤 → 财星 → 官杀（循环）
- **相克链**：官杀 → 比劫 → 财星 → 印星 → 食伤 → 官杀（循环）
