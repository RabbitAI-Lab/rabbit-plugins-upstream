# 五行能量

五行能量指命局中各五行的实际力量总和。它是判断强弱、用神、格局的量化基础。

---

## 一、能量的三个来源

### 1. 天干透出

| 位置 | 分值 |
|------|------|
| 天干透出（阳干） | 10 分 |
| 天干透出（阴干） | 8 分 |

> 阳干力量略强于阴干（阳主刚猛，阴主柔韧）。

### 2. 地支藏干

| 层次 | 分值 |
|------|------|
| 本气 | 10 分 |
| 中气 | 6 分 |
| 余气 | 4 分 |

### 3. 季节旺衰加成

| 状态 | 系数 |
|------|------|
| 旺 | ×1.5 |
| 相 | ×1.2 |
| 休 | ×1.0 |
| 囚 | ×0.7 |
| 死 | ×0.5 |

---

## 二、能量计算公式

```
某五行总能量 = Σ（天干分 × 旺衰系数）+ Σ（藏干分 × 旺衰系数）
```

### 计算步骤

1. 列出命局中所有天干、藏干的五行归属
2. 每个字按位置给基础分（天干10/8，本气10，中气6，余气4）
3. 每个字乘以所在季节的旺衰系数
4. 按五行归类求和
5. 比较五种五行的总能量

---

## 三、计算实例

**命例**：甲木日主，生于寅月（春）

```
年：丙寅（丙火 + 寅藏甲丙戊）
月：甲寅（甲木 + 寅藏甲丙戊）
日：甲午（甲木 + 午藏丁己）
时：己巳（己土 + 巳藏丙庚戊）
```

### 木的能量

| 来源 | 基础分 | 旺衰系数 | 得分 |
|------|--------|----------|------|
| 月干甲 | 10 | ×1.5（旺） | 15 |
| 日干甲 | 10 | ×1.5 | 15 |
| 年支寅本气甲 | 10 | ×1.5 | 15 |
| 月支寅本气甲 | 10 | ×1.5 | 15 |
| **木总计** | | | **60** |

### 火的能量

| 来源 | 基础分 | 旺衰系数 | 得分 |
|------|--------|----------|------|
| 年干丙 | 10 | ×1.2（相） | 12 |
| 年支寅中气丙 | 6 | ×1.2 | 7.2 |
| 月支寅中气丙 | 6 | ×1.2 | 7.2 |
| 日支午本气丁 | 10 | ×1.2 | 12 |
| 时支巳本气丙 | 10 | ×1.2 | 12 |
| **火总计** | | | **50.4** |

### 土、金、水（略）

按同样方法计算后比较，得出：**木 60 > 火 50 > 土 > 金 > 水**，木最旺、身强，喜克泄耗。

## 四、五行能量失衡的判断

### 五行俱全（平衡）

| 特征 | 解读 |
|------|------|
| 五种五行都有能量 | 命局平稳，起伏小 |
| 能量分布均匀 | 性格均衡，适应力强 |

### 五行缺失

| 缺失 | 解读 |
|------|------|
| 缺金 | 决断力弱、呼吸系统需注意 |
| 缺木 | 缺乏主见、肝胆需注意 |
| 缺水 | 智慧欠奉、肾泌尿需注意 |
| 缺火 | 缺乏热情、心血管需注意 |
| 缺土 | 诚信待修、脾胃需注意 |

### 五行过旺

| 过旺 | 解读 |
|------|------|
| 木过旺 | 固执好斗、易怒 |
| 火过旺 | 急躁冲动、易上火 |
| 土过旺 | 保守固执、不善变通 |
| 金过旺 | 刚烈刻薄、好争斗 |
| 水过旺 | 情绪化、多疑 |

---

## 五、能量分析的应用

1. **判断日主强弱**：日主五行能量 vs 其他五行能量
2. **确定用神**：能量最弱的五行（若为日主所需）可能是用神
3. **看健康**：能量最弱的五行对应脏腑最需关注
4. **看性格**：能量最旺的五行主导性格
5. **看事业**：能量最旺的五行对应的行业最易成

> 量化能量是辅助手段，最终判断仍要结合格局、刑冲合害综合来看。
