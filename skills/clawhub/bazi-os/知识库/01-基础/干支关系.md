# 干支关系

四柱八字每一柱都由天干 + 地支组成。天干在上为"天"，地支在下为"地"。天地之间的生克关系，决定了这一柱的**质量**和**力量**。

---

## 一、干支关系的四种基本形态

### 1. 盖头（天干克地支）

天干克地支 → 天干压制地支，地支的力量被天干盖住，发挥不出来。

| 盖头组合 | 解读 |
|----------|------|
| 甲辰 | 甲木克辰土，辰中藏干能量被压制 |
| 甲戌 | 甲木克戌土 |
| 乙未 | 乙木克未土 |
| 乙丑 | 乙木克丑土 |
| 丙申 | 丙火克申金 |
| 丁酉 | 丁火克酉金 |
| 戊子 | 戊土克子水 |
| 己亥 | 己土克亥水 |
| 庚寅 | 庚金克寅木 |
| 辛卯 | 辛金克卯木 |
| 壬午 | 壬水克午火 |
| 癸巳 | 癸水克巳火 |

> 盖头之柱，地支代表的方面（根基、配偶、子女等）被压制。如日柱盖头 → 配偶受压，婚姻不和谐。

### 2. 截脚（地支克天干）

地支克天干 → 天干被地支截断，天干的力量发挥不出来。

| 截脚组合 | 解读 |
|----------|------|
| 甲申 | 申金克甲木，天干甲木被截 |
| 乙酉 | 酉金克乙木 |
| 丙子 | 子水克丙火 |
| 丁亥 | 亥水克丁火 |
| 戊寅 | 寅木克戊土 |
| 己卯 | 卯木克己土 |
| 庚午 | 午火克庚金 |
| 辛巳 | 巳火克辛金 |
| 壬辰 | 辰土克壬水 |
| 壬戌 | 戌土克壬水 |
| 癸未 | 未土克癸水 |
| 癸丑 | 丑土克癸水 |

> 截脚之柱，天干代表的方面（事业、名声、外在表现）被暗伤。如日柱截脚 → 自身能力被内在缺陷限制。

### 3. 天覆（天干生地支）

天干生地支 → 气从上往下灌注，地支受益。

| 类型 | 组合示例 | 解读 |
|------|----------|------|
| 天生地 | 甲午（木生火）、乙巳（木生火）、丙辰（火生土）、丁未（火生土）、戊申（土生金）、己酉（土生金）、庚子（金生水）、辛亥（金生水）、壬寅（水生木）、癸卯（水生木） | 天干之气灌注地支，根基稳固 |

> 日柱天覆 → 命主的内在根基得到良好滋养，身体好、心态稳。

### 4. 地载（地支生天干）

地支生天干 → 气从下往上输送，天干受益。

| 类型 | 组合示例 | 解读 |
|------|----------|------|
| 地生天 | 甲子（水生木）、乙亥（水生木）、丙寅（木生火）、丁卯（木生火）、戊午（火生土）、己巳（火生土）、庚辰（土生金）、辛未（土生金）、壬申（金生水）、癸酉（金生水） | 天干得地支源源不断供养 |

> 日柱地载 → 命主的内在素质支撑外在成就，底气足。这是最好的干支关系。

## 二、干支关系对四柱的影响

### 年柱

| 关系 | 含义 |
|------|------|
| 年柱盖头 | 祖上产业被压制、家道中落 |
| 年柱截脚 | 父母能力受内在因素限制 |
| 年柱天覆/地载 | 祖上根基好、家运亨通 |

### 月柱

| 关系 | 含义 |
|------|------|
| 月柱盖头 | 事业表面好但根基不稳 |
| 月柱截脚 | 能力被环境限制，怀才不遇 |
| 月柱天覆/地载 | 事业有扎实基础，稳步上升 |

### 日柱（最关键）

| 关系 | 含义 |
|------|------|
| 日柱盖头（干克支） | 命主压制配偶，婚姻紧张 |
| 日柱截脚（支克干） | 配偶/内在因素限制命主发展 |
| 日柱天覆（干生支） | 命主滋养内在，身体健康 |
| 日柱地载（支生干） | **最佳**，内在支撑外在，底气十足 |
| 干支同气（干支五行同） | 内外一致，表里如一，但过于刚强 |

### 时柱

| 关系 | 含义 |
|------|------|
| 时柱盖头 | 子女受压制、晚年规划受阻 |
| 时柱截脚 | 子女内在限制发展 |
| 时柱天覆/地载 | 子女有出息、晚年安逸 |

## 三、干支一体论

干支在同一柱内是一个整体，不能完全割裂：

| 柱的整体质量 | 干支关系 |
|------------|----------|
| **最优质** | 地生天（地支生天干）— 根基支撑外在 |
| **良好** | 天生地（天干生地干）— 外在滋养内在 |
| **一般** | 干支同气 — 表里一致但缺乏流通 |
| **较差** | 盖头 — 外在压制内在 |
| **最差** | 截脚 — 内在否定外在 |

---

## 四、干支通气

当天干与地支藏干五行一致时，称"通气"，力量最为通透：

| 通气类型 | 示例 | 说明 |
|----------|------|------|
| 天干 = 本气 | 甲寅（甲木坐寅，本气甲） | 完全通气，最强 |
| 天干 = 中气 | 甲亥（甲木坐亥，中气甲） | 半通气 |
| 天干 = 余气 | 甲辰（甲木坐辰，余气乙木不完全通气） | 微弱通气 |

> 通气 = 天干与地支有血缘关系。通气的柱力量 > 不通气的柱。
