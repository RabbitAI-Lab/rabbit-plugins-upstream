# 阴阳

阴阳是八字乃至整个中国传统哲学的**第一原理**。五行是阴阳的展开，八卦是阴阳的符号，干支是阴阳的载体。理解阴阳，才能理解命理的一切。

---

## 一、什么是阴阳？

阴阳是对宇宙中一切对立统一关系的抽象概括。

| 阳 | 阴 |
|----|----|
| 天 | 地 |
| 日 | 月 |
| 男 | 女 |
| 动 | 静 |
| 刚 | 柔 |
| 显 | 隐 |
| 热 | 寒 |
| 昼 | 夜 |
| 明 | 暗 |
| 生发 | 收藏 |
| 外 | 内 |

> **核心**：阴阳不是两种"东西"，而是两种"状态"。任何事物都是阴阳的统一体，纯阳纯阴都不存在。

---

## 二、阴阳的四大关系

### 1. 对立制约（阴阳相反）

阴阳相互对立、相互制约，维持平衡。

- 阳盛则阴衰，阴盛则阳衰
- 八字中：木火（阳）旺则金水（阴）弱，反之亦然

### 2. 互根互用（阴阳相成）

阴阳相互依存，一方的存在以另一方为前提。

- 没有白天就没有黑夜的概念
- 八字中：无印则杀无制，无财则食无所生

### 3. 消长平衡（阴阳相消长）

阴阳此消彼长，动态平衡。

- 春夏阳气渐长，阴气渐消；秋冬反之
- 八字中：大运走阳运则阳增阴减，走阴运则反之

### 4. 相互转化（阴阳相转化）

物极必反，阴阳在一定条件下相互转化。

- 冬至一阳生（阴至极则阳生）
- 夏至一阴生（阳至极则阴生）
- 八字中：旺极而衰，绝处逢生

## 三、天干的阴阳

| 五行 | 阳干 | 阴干 |
|------|------|------|
| 木 | **甲**（参天大树） | **乙**（藤蔓花草） |
| 火 | **丙**（太阳之火） | **丁**（灯烛之火） |
| 土 | **戊**（城墙之土） | **己**（田园之土） |
| 金 | **庚**（刀剑之金） | **辛**（首饰之金） |
| 水 | **壬**（江河之水） | **癸**（雨露之水） |

### 阳干阴干的性格差异

| 维度 | 阳干 | 阴干 |
|------|------|------|
| 性格 | 刚猛、外放、直接 | 柔韧、内敛、迂回 |
| 处事 | 大刀阔斧、冲在前面 | 以柔克刚、谋定后动 |
| 例 | 甲木参天，宁折不弯 | 乙木藤蔓，能屈能伸 |

## 四、地支的阴阳

| 阴阳 | 地支 |
|------|------|
| **阳支** | 子、寅、辰、午、申、戌 |
| **阴支** | 丑、卯、巳、未、酉、亥 |

> 阳支藏干以阳干为主，阴支藏干以阴干为主。十二地支阴阳交错排列，形成循环。

## 五、阴阳在八字中的核心应用

### 1. 十神的正偏之分（最重要）

十神遵循"**异性为正，同性为偏**"：

| 关系 | 定义 | 十神 |
|------|------|------|
| 异性（阴阳相反） | 日干阳 + 他干阴（或反之） | 正印、正财、正官、食神、劫财 |
| 同性（阴阳相同） | 日干阳 + 他干阳（或同为阴） | 偏印、偏财、七杀、伤官、比肩 |

> 详细见 [[十神]]。

### 2. 命局寒暖燥湿

八字整体阴阳平衡，要看寒暖燥湿：

| 维度 | 阳（热/燥） | 阴（寒/湿） |
|------|-----------|-----------|
| 五行 | 火、燥土（戌未） | 水、湿土（辰丑） |
| 季节 | 夏生 | 冬生 |
| 问题 | 火太旺则焦 | 水太旺则寒 |
| 调候 | 喜水润之 | 喜火暖之 |

> 冬生（亥子丑月）无火 → 命局偏寒，喜火调候；夏生（巳午未月）无水 → 命局偏燥，喜水调候。

### 3. 男命女命

| 维度 | 男命 | 女命 |
|------|------|------|
| 日干阴阳 | 阳干男更刚 | 阴干女更柔 |
| 配偶星 | 财星（我克） | 官星（克我） |
| 大运顺逆 | 阳男顺排 | 阴女顺排 |
| 格局偏重 | 喜官杀（阳刚） | 喜印食（阴柔） |

### 4. 身强身弱的阴阳观

- 身强（阳偏盛）→ 喜克泄耗（阴来平衡）
- 身弱（阴偏盛）→ 喜生扶（阳来补充）
- **本质**：强弱平衡就是阴阳平衡

### 5. 大运流年的阴阳应期

| 大运阴阳 | 应期特点 |
|----------|----------|
| 阳干大运 | 外在、明面、来得快 |
| 阴干大运 | 内在、暗面、来得慢 |
| 阳支大运 | 动象明显、变化大 |
| 阴支大运 | 静象为主、潜移默化 |

## 六、阴阳平衡的判断口诀

| 口诀 | 解读 |
|------|------|
| 孤阴不生，独阳不长 | 纯阴纯阳的命局都难有大成 |
| 阴中有阳，阳中有阴 | 好的命局阴阳互含 |
| 物极必反，否极泰来 | 旺极必衰，绝处逢生 |
| 阴阳平衡，命局有情 | 平衡是命局上乘的标准 |
| 寒命喜火，燥命喜水 | 调候即调阴阳 |

## 七、阴阳与五行的关系

```
          阳  ──  阴
           │      │
    木火土金水（五行是阴阳的展开）
           │
     十神（五行生克再分阴阳）
```

- **阴阳是第一层**：一切对立统一的总纲
- **五行是第二层**：阴阳具体化为五种气的状态
- **十神是第三层**：五行生克关系再分阴阳
