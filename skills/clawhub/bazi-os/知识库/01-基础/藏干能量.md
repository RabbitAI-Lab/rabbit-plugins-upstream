# 藏干能量强弱

藏干（地支所藏人元）是判断日主强弱、通根真假、十神力量的关键。不是所有藏干都一样有力。

---

## 一、藏干三层能量

每个地支藏 1~3 个天干，按力量排序：

| 层次 | 力量占比 | 特性 |
|------|----------|------|
| **本气** | 约 60-70% | 地支的"正主"，力量最强，与地支五行一致 |
| **中气** | 约 20-30% | 次要力量，三合局或季节余气 |
| **余气** | 约 5-10% | 最弱，上季残留之气 |

## 二、通根（日干得地）

"通根"指日干天干在地支藏干中找到同五行的根。有根则有底气，无根则虚浮。

### 通根等级

| 等级 | 条件 | 力量 | 举例（甲日主） |
|------|------|------|--------------|
| **强根** | 本气同五行 | ⭐⭐⭐⭐⭐ | 地支见寅（本气甲）、卯（本气乙） |
| **中根** | 中气同五行 | ⭐⭐⭐ | 地支见亥（中气甲） |
| **弱根** | 余气同五行 | ⭐⭐ | 地支见辰（余气乙为劫财，也算根） |
| **无根** | 四柱无同五行藏干 | ⭐ | 日主虚浮，风吹即倒 |

### 各天干通根对照

| 日干 | 强根（本气） | 中根（中气） | 弱根（余气） |
|------|------------|------------|------------|
| 甲 | 寅 | 亥 | — |

## 三、透干（藏干在天干出现）

藏干中某个字在四柱天干中出现，叫**透干**。透干 = 该藏干的能量翻倍，从幕后走向台前。

### 透干的能量变化

| 状态 | 力量 | 表现 |
|------|------|------|
| 藏而不透 | 1x | 潜在特质，不显现 |
| 藏而透出 | 3x | 该特质强烈外显，成为性格标签 |
| 透而不藏（只有天干，地支无根） | 0.5x | 虚浮无根，空有其表 |

> **判断法则**：透干 + 通根 = 最强；只透不通 = 虚有其表；只通不透 = 暗藏实力。

## 四、实战应用

### 判断日主强弱（最关键用途）

参见 [[日主强弱]]，核心逻辑：

```
日主强 = 得令（月令生扶）+ 得地（通强根）+ 得生（印星透）+ 得助（比劫透）
日主弱 = 失令 + 无强根 + 克泄多
```

**藏干层面的细化**：

| 藏干表现 | 强弱判断 |
|----------|----------|
| 日支本气为同五行 | → 得地，根基扎实 |
| 多柱中气/余气为同五行 | → 有根但不稳，需大运帮扶 |
| 四柱藏干无同五行 | → 无根虚浮，极弱 |

### 判断十神真假

一个十神透出天干，但地支没有对应的藏干通根 → 该十神是"假"的，力量大打折扣。

**例**：天干透正官，但四柱地支无正官的五行藏干 → 表面有官职，实际没实权（虚官）。

### 判断藏干是否被破坏

| 情况 | 说明 |
|------|------|
| 地支被冲（六冲） | 藏干受伤，能量大减 |
| 地支被合（六合/三合） | 藏干被牵制或转化 |
| 地支被刑 | 藏干内部打架，气场紊乱 |
| 空亡 | 该地支藏干力量悬空，吉凶减半 |
