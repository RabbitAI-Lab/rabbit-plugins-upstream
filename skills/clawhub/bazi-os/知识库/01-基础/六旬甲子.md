# 六旬甲子

六十甲子每 10 个为一组，称一"旬"，共六旬。每旬有 10 个干支组合 + 2 个轮不到的地支 → 这 2 个地支就是该旬的**旬空（空亡）**。

## 二、快速记忆法

**旬空口诀**：六甲旬首推空亡，地支逆数两位即为空。

```
甲子旬 → 子逆1=亥、逆2=戌 → 戌亥空
甲戌旬 → 戌逆1=酉、逆2=申 → 申酉空
甲申旬 → 申逆1=未、逆2=午 → 午未空
甲午旬 → 午逆1=巳、逆2=辰 → 辰巳空
甲辰旬 → 辰逆1=卯、逆2=寅 → 寅卯空
甲寅旬 → 寅逆1=丑、逆2=子 → 子丑空
```

> 任何一柱的天干地支组合，看其属于哪一旬，就能知道其旬空。

## 三、旬空在八字中的应用

### 日柱旬空（最常用）

以**日柱干支**确定属于哪一旬，该旬的旬空地支即为命局的空亡。

**例如**：日柱甲子 → 甲子旬 → 戌亥空 → 命局地支见戌或亥即为空亡。

### 各柱旬空的意义

| 空在哪柱 | 含义 |
|----------|------|
| **年柱空亡** | 祖上根基虚浮，幼年运不稳 |
| **月柱空亡** | 事业根基不稳，父母缘薄 |
| **日柱空亡** | 婚姻根基不稳，自身方向感弱 |
| **时柱空亡** | 子女缘薄，晚年规划落空 |

### 空亡的双面性

| 情况 | 效果 |
|------|------|
| 用神坐空亡 | 用神减力，好事打折扣 |
| 忌神坐空亡 | 忌神减力，坏事不那么坏 |
| 吉星坐空亡 | 吉星减力 |
| 凶星坐空亡 | 凶性减轻（空亡解厄） |
| 大运填实空亡 | 空亡之宫位该年应事 |
| 流年填实空亡 | 当年该宫位之事落地 |

### 旬空 + 神煞

| 组合 | 解读 |
|------|------|
| 天乙贵人坐空亡 | 贵人力量减弱，帮得不到位 |
| 桃花坐空亡 | 虚幻的感情，有缘无分 |
| 财库坐空亡 | 钱财虚浮，积攒不起 |
| 羊刃坐空亡 | 凶性减弱，伤害减轻 |

## 四、年柱旬空（另一体系）

部分流派也用年柱定旬空，以**年柱**所在的旬找空亡，代表**一生的大环境空亡**。

日柱旬空看个人，年柱旬空看时代背景。
