# 节气历法

八字排盘对时间的要求极为精确——时辰错则全盘错。本节涵盖节气、真太阳时、子时、岁数等时间相关问题。

---

## 一、二十四节气

八字以**节气**定月，不以农历初一为界。二十四节气中的"节"是月份的分界点。

| 月份 | 地支 | 节（月起点） | 气（月中点） |
|------|------|------------|------------|
| 正月 | 寅 | **立春** | 雨水 |
| 二月 | 卯 | **惊蛰** | 春分 |
| 三月 | 辰 | **清明** | 谷雨 |
| 四月 | 巳 | **立夏** | 小满 |
| 五月 | 午 | **芒种** | 夏至 |
| 六月 | 未 | **小暑** | 大暑 |
| 七月 | 申 | **立秋** | 处暑 |
| 八月 | 酉 | **白露** | 秋分 |
| 九月 | 戌 | **寒露** | 霜降 |
| 十月 | 亥 | **立冬** | 小雪 |
| 十一月 | 子 | **大雪** | 冬至 |
| 十二月 | 丑 | **小寒** | 大寒 |

> **核心规则**：过了"节"才换月。如立春之前仍算上一年的十二月（丑月），立春之后才进入正月（寅月）。

### 年柱也看节气

年柱以**立春**为界：立春前出生算上一年，立春后算下一年。

## 二、真太阳时 vs 北京时间

### 问题

中国统一使用北京时间（东八区 120°E），但中国横跨五个时区。**北京时间 12:00 ≠ 当地正午 12:00**。

| 城市 | 经度 | 与北京时差 |
|------|------|-----------|
| 哈尔滨 | 126°E | 快约 24 分钟 |
| 北京 | 116°E | 慢约 16 分钟 |
| 上海 | 121°E | 快约 4 分钟 |
| 成都 | 104°E | 慢约 64 分钟 |
| 乌鲁木齐 | 87°E | 慢约 132 分钟 |
| 拉萨 | 91°E | 慢约 116 分钟 |

> 时差 = (当地经度 - 120°) × 4 分钟

### 怎么处理

- **东部地区**（经度接近 120°）：时差小，可用北京时间
- **中西部地区**（经度远离 120°）：**必须校正为真太阳时**，否则时辰可能跨时区
- 北京时间 23:10 出生的新疆人 → 真太阳时可能才 21:00 左右 → 还是亥时！

## 三、早晚子时（子时拆分）

### 问题

子时是 23:00-01:00，横跨两天。这一天交界处如何归属？

### 两种流派

| 流派 | 规则 | 说明 |
|------|------|------|
| **早晚子时** | 23:00-00:00 → **晚子时**（当日）<br>00:00-01:00 → **早子时**（当日） | 多数排盘软件采用 |
| **不分早晚** | 23:00-01:00 → 全部归次日 | 古法，部分流派使用 |

### 日柱与时柱的早晚子时处理

| 时段 | 日柱归属 | 时柱天干 |
|------|----------|----------|
| 23:00-00:00（晚子时） | **当天日柱** | 按当天日干起时 |
| 00:00-01:00（早子时） | **当天日柱** | 按当天日干起时 |

> 部分古法将 23:00 后的子时全部算入次日，日柱用次日的。这会导致同一个人在不同排盘工具中得到两个不同的八字！

**建议**：使用主流排盘软件（如问真、八字排盘宝等），它们多采用早晚子时分法。

## 四、虚实岁

### 虚岁

中国传统计岁法，出生即算 1 岁，每过一次春节加 1 岁。

### 周岁（实岁）

现代计岁法，出生后满 365 天为 1 岁。

### 在大运中的应用

| 概念 | 说明 |
|------|------|
| 起运年龄 | 按周岁计算（三日出一天 = 约 1 岁） |
| 换运年龄 | 每十年一步，逢整数岁交运 |
| 大运年龄 | 通常表示为 "N 岁起运"，此处的"岁"多为周岁 |

### 虚岁在八字中的残留

部分古籍和流派用虚岁标记大运，阅读古籍时需注意转换。现代排盘以周岁为准。

## 五、时光校准自查清单

排盘前检查以下事项：

1. ☐ 出生日期确认是公历还是农历
2. ☐ 出生时间精确到分钟
3. ☐ 出生地点经度（是否需要真太阳时校正）
4. ☐ 子时出生 → 是否需要早晚子时处理
5. ☐ 出生在节气交界日 → 确认过"节"了没有
6. ☐ 出生在立春前后 → 确认年柱归属
