# 五行基础

五行（金、木、水、火、土）是八字命理的底层语言。一切干支、十神、格局的分析都建立在五行生克之上。

---

## 一、五行特性

| 五行 | 特性 | 方位 | 季节 | 颜色 | 脏腑 | 五官 | 情志 |
|------|------|------|------|------|------|------|------|
| **木** | 生发、条达、向上 | 东 | 春 | 青/绿 | 肝、胆 | 目 | 怒 |
| **火** | 炎热、向上、光明 | 南 | 夏 | 红/赤 | 心、小肠 | 舌 | 喜 |
| **土** | 承载、生化、厚重 | 中 | 四季末 | 黄 | 脾、胃 | 口 | 思 |
| **金** | 收敛、肃杀、变革 | 西 | 秋 | 白 | 肺、大肠 | 鼻 | 悲 |
| **水** | 滋润、下行、闭藏 | 北 | 冬 | 黑/蓝 | 肾、膀胱 | 耳 | 恐 |

## 二、五行生克

### 相生（顺生为吉）

```
木 → 火 → 土 → 金 → 水 → 木  (循环)
```

| 相生 | 口诀 | 含义 |
|------|------|------|
| 木生火 | 钻木取火 | 木使火得以持续燃烧 |
| 火生土 | 火烬成灰 | 火燃尽化为灰土 |
| 土生金 | 土中淘金 | 金属矿藏出自土中 |
| 金生水 | 金熔为液 | 金属高温融化如水流 |
| 水生木 | 水润草木 | 水滋养树木生长 |

### 相克（制衡为用）

```
木 → 土 → 水 → 火 → 金 → 木  (循环)
```

| 相克 | 口诀 | 含义 |
|------|------|------|
| 木克土 | 树根破土 | 树木根系穿透土壤 |
| 土克水 | 水来土掩 | 堤坝阻挡水流 |
| 水克火 | 水灭火 | 水能熄灭火焰 |
| 火克金 | 火炼金 | 烈火熔化金属 |
| 金克木 | 斧斫木 | 金属刀具砍伐树木 |

### 异常生克

| 类型 | 关系 | 含义 | 举例 |
|------|------|------|------|
| **相乘** | 过度克制 | 克方太强或被克方太弱，导致伤害 | 水太旺把火完全扑灭 |
| **相侮** | 反向克制 | 被克方太强反过来克制克方 | 火太旺水太少，水反被蒸发（火侮水） |

## 四、五行在八字中的应用

### 1. 看日主五行属性

甲木人、丙火人、戊土人……日主天干决定了命主的"本命五行"，以此为出发点分析整个命局。

### 2. 看五行平衡

| 状态 | 含义 |
|------|------|
| 五行俱全 | 命局平稳，人生起伏较小 |
| 缺某一行 | 该五行所代表的方面较弱（如缺金则肺气不足、决断力弱） |
| 某行过旺 | 该行特征过度放大，需用克泄来平衡 |
| 某行过弱 | 该行被严重克制，对应方面易出问题 |

### 3. 看流通

理想的命局五行之气应能**顺畅流通**：
- 五行依次相生，无阻塞，为大吉
- 两行相战（如金木交战），需通关之神（如以水通关，金生水、水生木）
- 三行循环相生，格局流通有情

### 4. 看用神

通过五行生克找出维持命局平衡的关键五行，即为[[日主强弱|用神]]。

## 五、五行与性格速查

| 五行 | 过旺时的性格 | 过弱时的性格 |
|------|------------|------------|
| 木 | 固执、好斗、易怒 | 无主见、缺乏进取、胆小 |
| 火 | 急躁、冲动、好表现 | 缺乏热情、冷淡、无活力 |
| 土 | 保守、固执、不善变通 | 缺乏诚信、轻浮、不踏实 |
| 金 | 刚烈、刻薄、好争斗 | 优柔寡断、缺乏决断力 |
| 水 | 情绪化、多疑、好幻想 | 缺乏智慧、目光短浅 |
