# 同党与异党

"同党异党"是判断日主强弱的量化方法。与日主同心者为同党，与日主异心者为异党。数清楚哪边人多，就知道日主强弱。

---

## 一、划分标准

以日干为中心，将十神分为两派：

| 派别 | 包含十神 | 与日主关系 | 作用 |
|------|----------|-----------|------|
| **同党** | 印星（正印/偏印）、比劫（比肩/劫财） | 生我、同我 | 帮扶日主，增强力量 |
| **异党** | 食伤（食神/伤官）、财星（正财/偏财）、官杀（正官/七杀） | 我生、我克、克我 | 消耗日主，削弱力量 |

> 口诀：**印比一家（同党），食财官杀是一家（异党）**。

---

## 二、同党异党力量计算

四柱 8 个字（4 天干 + 4 地支），逐个判断归属：

### 计数规则

| 位置 | 计法 |
|------|------|
| 天干 | 每个天干直接计 1 票 |
| 地支本气 | 力量最大，计 1 票 |
| 地支中气 | 力量中等，计 0.5 票 |
| 地支余气 | 力量最小，计 0.3 票 |
| 日干 | 本身是 1 票，归同党 |

> 不同流派计法略有差异，但核心逻辑相同：数人头的升级版——数能量。

### 分数法

| 层别 | 分值 |
|------|------|
| 天干出现 | 10 分 |
| 地支本气 | 10 分 |
| 地支中气 | 6 分 |
| 地支余气 | 4 分 |
| 透干 + 通根 | 额外加 5 分 |

---

## 三、判断标准

### 粗略判断（计票法）

| 同党票数 | 结论 |
|----------|------|
| > 异党票数 | 身强 |
| = 异党票数 | 中和 |
| < 异党票数 | 身弱 |

### 精确判断（分数法）

| 同党得分占比 | 结论 |
|------------|------|
| > 60% | 身强 |
| 40% ~ 60% | 中和 |
| < 40% | 身弱 |
| > 80% | 极强（论从强） |
| < 20% | 极弱（论从弱） |

## 四、实例分析

```
女命：甲木日主
年：丙寅（丙火食神 + 寅藏甲丙戊）
月：丁卯（丁火伤官 + 卯藏乙）
日：甲午（甲木比肩 + 午藏丁己）
时：己巳（己土正财 + 巳藏丙庚戊）
```

**逐个计票**：

| 柱 | 天干/藏干 | 十神 | 派别 | 票数 |
|----|----------|------|------|------|
| 日干 | 甲 | 日主 | 同党 | 1 |
| 年干 | 丙 | 食神 | 异党 | 1 |
| 年支本气 | 甲 | 比肩 | 同党 | 1 |
| 年支中气 | 丙 | 食神 | 异党 | 0.5 |
| 年支余气 | 戊 | 偏财 | 异党 | 0.3 |
| 月干 | 丁 | 伤官 | 异党 | 1 |
| 月支本气 | 乙 | 劫财 | 同党 | 1 |
| 日支本气 | 丁 | 伤官 | 异党 | 1 |
| 日支中气 | 己 | 正财 | 异党 | 0.5 |
| 时干 | 己 | 正财 | 异党 | 1 |
| 时支本气 | 丙 | 食神 | 异党 | 1 |
| 时支中气 | 庚 | 七杀 | 异党 | 0.5 |
| 时支余气 | 戊 | 偏财 | 异党 | 0.3 |

- 同党：1 + 1 + 1 = 3 票
- 异党：1 + 0.5 + 0.3 + 1 + 1 + 0.5 + 1 + 1 + 0.5 + 0.3 = 7.1 票

→ **身弱**（同党远少于异党），喜水木（印比帮扶）。

## 五、同党异党的特殊处理

### 例外情况

| 情况 | 处理 |
|------|------|
| 日主得令（月令生扶） | 同党虽然人少但质量高，可能仍偏强 |
| 全局同党但虚浮无根 | 势众但质弱，中和偏弱 |
| 合化改变五行 | 某个字的五行变了，重新判断归属 |
| 从格 | 同党极少 → 从弱；异党极少 → 从强 |

### 同党异党 + 得令的综合判断

这是最准确的强弱分析法：

```
最终强弱 = 同党异党比值 × 月令权重系数
```

月令权重系数：得令 = 1.5，半得令 = 1.2，失令 = 0.8
