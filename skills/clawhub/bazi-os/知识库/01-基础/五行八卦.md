# 五行八卦

五行是八字的核心语言，八卦是易经的核心符号。二者在命理、风水、方位、择日中深度融合。本笔记系统梳理五行与八卦的关系及其在八字中的应用。

## 三、先天八卦 vs 后天八卦

### 先天八卦（伏羲八卦）

讲**阴阳对峙**，用于定"体"：

```
方位排列：
        乾（南）
   兑（东南）  巽（西南）
 离（东）        坎（西）
   震（东北）  艮（西北）
        坤（北）
```

**先天八卦数**：乾一、兑二、离三、震四、巽五、坎六、艮七、坤八

### 后天八卦（文王八卦）

讲**五行流转**，用于定"用"，是风水和命理实战采用的体系：

```
方位排列（上南下北）：
        离（南）
   巽（东南）  坤（西南）
 震（东）        兑（西）
   艮（东北）  乾（西北）
        坎（北）
```

**后天八卦数（洛书数）**：

```
  4  9  2
  3  5  7
  8  1  6
```

| 卦 | 洛书数 | 方位 |
|----|--------|------|
| 坎 | 1 | 北 |
| 坤 | 2 | 西南 |
| 震 | 3 | 东 |
| 巽 | 4 | 东南 |
| 中 | 5 | 中央 |
| 乾 | 6 | 西北 |
| 兑 | 7 | 西 |
| 艮 | 8 | 东北 |
| 离 | 9 | 南 |

> 命理和风水实战中一律用**后天八卦**。先天八卦多用于哲学推演。

| 土 | 五 | 十 | 中 |

## 八、八卦在八字中的实战应用

### 1. 命卦（八宅风水）

以出生年推算命卦（见 [[命卦]]），确定东四命/西四命，选择吉方位。

### 2. 方位吉凶

八字用神对应的方位，即八卦方位：

| 用神五行 | 吉方位 | 对应卦 |
|----------|--------|--------|
| 木 | 东、东南 | 震、巽 |
| 火 | 南 | 离 |
| 土 | 西南、东北、中 | 坤、艮 |
| 金 | 西、西北 | 兑、乾 |
| 水 | 北 | 坎 |

> 发展事业选用神方位，置业选用神方向，这是八卦五行在八字中最直接的落地。

### 3. 择日

传统择日（黄历）结合八卦方位与值日星神，判断某日利于做什么方向的事。

### 4. 六亲定位

用八卦家庭成员对应，辅助判断兄弟姐妹排行与关系（见第六节）。

### 5. 命理合参

部分流派将出生日对应八卦（纳甲），与八字十神互参，看命主的气场偏性。

## 九、八卦与五行生克的统一

八卦虽分阴阳五行，但最终回归五行生克：

```
八卦五行关系示例：
- 离（火）克 乾（金）→ 火炼金
- 坎（水）克 离（火）→ 水火既济/未济
- 震巽（木）克 坤艮（土）→ 木克土
- 乾兑（金）克 震巽（木）→ 金克木
- 坤艮（土）克 坎（水）→ 土克水
```

**卦名中的生克智慧**：
- 火天大有、地天泰、水地比——相生相配之卦
- 天地否、火水未济、天水讼——相克相逆之卦
