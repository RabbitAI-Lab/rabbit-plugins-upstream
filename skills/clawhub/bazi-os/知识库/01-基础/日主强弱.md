# 日主身强身弱

日主（日干）的强弱是八字分析第一步，也是最关键的一步。强弱判断错了，后面十神、格局、用神的分析全盘皆错。

**核心原则**：日主强则喜克泄耗（官杀/食伤/财星），日主弱则喜生扶（印星/比劫）。

---

## 一、判断日主强弱的四大标准

### 1. 得令（看月令）— 最重要

月令（月支）掌一月之气，权重最大。

| 日主 | 得令月份 | 状态 |
|------|---------|------|
| 甲乙木 | 寅月、卯月 | 木旺于春，得令 |
| 丙丁火 | 巳月、午月 | 火旺于夏，得令 |
| 庚辛金 | 申月、酉月 | 金旺于秋，得令 |
| 壬癸水 | 亥月、子月 | 水旺于冬，得令 |
| 戊己土 | 辰戌丑未月 | 土旺四季末，得令 |

> **例外**：土寄旺于四季末，但辰月木气尚存、戌月金气尚存、丑月水气尚存、未月火气尚存。辰戌丑未月具体看藏干。

**半得令**：生于相生的季节，如甲木生于亥月子月（水生木），虽不当时但有气。

### 2. 得地（看自坐与通根）

日干在地支有**同五行之根**：

| 标准 | 说明 |
|------|------|
| **本气根** | 日支藏干本气与日干同五行（如甲见寅、卯）→ 最强 |
| **中气根** | 藏干中气同五行 → 中等 |
| **余气根** | 藏干余气同五行 → 较弱 |
| **无根** | 四柱无同五行地支 → 虚浮无根 |

**日干在地支的通根**：

| 天干 | 本气根 | 藏干根 |
|------|--------|--------|
| 甲 | 寅 | 亥（中气甲）、辰（余气乙） |
| 乙 | 卯 | 未（中气乙）、辰（余气乙） |
| 丙 | 午 | 寅（中气丙）、巳（本气丙） |
| 丁 | 巳 | 午（中气丁）、未（余气丁） |
| 戊 | 辰、戌 | 巳（中气戊）、寅（余气戊） |
| 己 | 丑、未 | 午（中气己） |
| 庚 | 申 | 巳（余气庚） |
| 辛 | 酉 | 丑（余气辛） |
| 壬 | 子 | 申（中气壬）、亥（本气壬） |
| 癸 | 亥 | 子（本气癸）、丑（余气癸） |

### 3. 得生（看印星）

日干得到印星（正印/偏印）的生扶。

- 印星透出天干，紧贴日主 → 生扶力量强
- 印星藏于地支，不直接生日主 → 生扶力量弱
- 印星多而旺 → 日主得生，偏强

### 4. 得助（看比劫）

日干得到比肩、劫财的帮扶。

- 比劫透干且旺 → 助力强
- 比劫多且紧密 → 日主得众助
- 比劫在年时柱远离日主 → 助力弱

## 二、强弱等级速判

| 等级 | 判断条件 | 用神方向 |
|------|---------|----------|
| **极强（专旺）** | 得令 + 得地 + 得生 + 得助，全局帮扶，克泄全无 | 从强，喜生扶（特殊格局） |
| **身强** | 得令 + 得地，或有得生/得助 | 喜克泄耗（官杀/食伤/财） |
| **中和偏强** | 得令，但根气一般，克泄与生扶约各半 | 喜克泄为主 |
| **中和偏弱** | 失令，但有根有生助，克泄与帮扶约各半 | 喜生扶为主 |
| **身弱** | 失令 + 根弱，克泄多 | 喜生扶（印/比劫） |
| **极弱（从格）** | 失令 + 无根 + 无生扶，全局克泄 | 从弱，喜克泄（特殊格局） |

## 三、实战判断示例

### 例1：身强

```
甲木日主，生于寅月（得令，木旺于春）
日支坐寅（得地，自坐本气根）
月干透甲木比肩帮扶
→ 身强，喜火（食伤泄秀）、土（财星）、金（官杀克身）
```

### 例2：身弱

```
丙火日主，生于亥月（失令，水旺克火）
日支坐子（失地，自坐官杀）
全局无木印星生扶，无比劫帮扶
→ 身弱，喜木（印星生身）、火（比劫帮身）
```

### 例3：从格

```
癸水日主，生于巳月（失令，火旺水绝）
日支坐巳（失地）
全局火土一片，无金生水，无亥子丑根
→ 从弱（从财），喜火土，忌金水
```

## 四、身强身弱不等于命好命差

> [!important] 关键认知
> **身强弱 ≠ 命好坏**。身强不一定富贵，身弱不一定贫贱。关键在于有没有**用神得力**。

| 组合 | 结果 |
|------|------|
| 身强 + 有克泄（官杀/食伤/财）得力 | 富贵双全 |
| 身强 + 无克泄 | 旺而无用，过于刚强反成灾 |
| 身弱 + 有生扶（印/比劫）得力 | 逆境奋发，终有所成 |
| 身弱 + 无生扶 | 弱不受生，一生飘零 |

## 五、用神与忌神

判断出日主强弱后，就可以找出**用神**与**忌神**：

| 日主状态 | 用神（喜） | 忌神（忌） |
|----------|------------|------------|
| 身强 | 官杀（克）、食伤（泄）、财星（耗） | 印星（生）、比劫（助） |
| 身弱 | 印星（生）、比劫（助） | 官杀（克）、食伤（泄）、财星（耗） |
| 从强 | 印星、比劫（顺其旺势） | 官杀、食伤、财星 |
| 从弱 | 官杀、食伤、财星（顺其弱势） | 印星、比劫 |

> 用神是命局的"药"，忌神是命局的"病"。有病有药方为贵，无病无药是常人。
