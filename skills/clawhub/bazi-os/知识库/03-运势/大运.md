# 大运

大运是八字中最重要的动态系统。命局（原八字）是"车"，大运是"路"。好车走烂路也颠簸，差车走高速也顺畅。

---

## 一、什么是大运？

大运以十年为一步，从月柱出发，顺排或逆排，每一步代表人生一个阶段的运势走向。

| 概念 | 说明 |
|------|------|
| 命局 | 出生时的八字，一生不变（车） |
| 大运 | 十年一步的运势（路） |
| 流年 | 每一年的运势（天气） |

> **大运重地支**：每一步大运的地支决定了这十年的基调，天干决定前五年的偏重。

---

## 二、排大运

### 顺排 vs 逆排

| 年柱 | 性别 | 排法 |
|------|------|------|
| 阳年（甲丙戊庚壬） | 男 | **顺排** |
| 阳年（甲丙戊庚壬） | 女 | **逆排** |
| 阴年（乙丁己辛癸） | 男 | **逆排** |
| 阴年（乙丁己辛癸） | 女 | **顺排** |

> 口诀：**阳男阴女顺，阴男阳女逆**。

### 起运年龄

从出生日到下一个（或上一个）节气的天数，换算为起运年龄：

**大约 3 天 = 1 岁起运**。

- 顺排：从出生日数到**下一个**节气
- 逆排：从出生日数到**上一个**节气

> 起运年龄约在 1~10 岁之间，大多数人 5~8 岁起运。

### 大运排列

以月柱为起点，顺排则月柱 → 下一步大运 → 再下一步……依次顺行六十甲子；逆排则反向。

**示例**：甲木年男命（顺排），月柱丙寅
- 第一步大运：丁卯
- 第二步大运：戊辰
- 第三步大运：己巳
- ……

## 三、大运与命局的关系

### 大运是好是坏？

判断标准：**大运天干地支是否为命局的用神/喜神**。

| 日主状态 | 喜（好大运） | 忌（坏大运） |
|----------|------------|------------|
| 身强 | 官杀运（克）、食伤运（泄）、财运（耗） | 印运（生）、比劫运（助） |
| 身弱 | 印运（生）、比劫运（助） | 官杀运（克）、食伤运（泄）、财运（耗） |
| 从强 | 印运、比劫运 | 官杀、食伤、财运 |
| 从弱 | 官杀、食伤、财运 | 印运、比劫运 |

### 常见大运格局

| 大运类型 | 特征 |
|----------|------|
| **用神运** | 十年顺遂，该阶段人生最好 |
| **忌神运** | 十年波折，事事受阻 |
| **通关运** | 原局两行相战，大运出现通关五行 → 化敌为友 |
| **冲提运** | 大运地支冲月令（提纲逢冲），人生重大转折 |
| **换运** | 每十年换运时（前后一年），运势不稳，易有变动 |

## 四、大运天干与地支的分工

| 维度 | 天干（前五年偏重） | 地支（后五年偏重） |
|------|------------------|-------------------|
| 层面 | 外在事件、名气、人际关系 | 内在变化、根基、实际结果 |
| 速度 | 来得快去得快 | 来得慢但持久 |
| 举例 | 升职消息（天干官星运前五年） | 坐稳位置、出成绩（地支官星运后五年） |

> **天干地支同看**：干支一体，不能割裂。天干为用、地支为忌 → 前五年好、后五年差；反之亦然。

## 五、大运口诀

| 口诀 | 含义 |
|------|------|
| **十年一步运，一步一重天** | 大运一变，人生大不同 |
| **命好不如运好** | 命局好但走忌神运照样不顺 |
| **运好不如流年好** | 大运好但碰到差的流年也有波折 |
| **提纲逢冲，十有九凶** | 大运冲月柱，人生重大变故 |
| **伤官见官，为祸百端** | 大运引动伤官克官 |
