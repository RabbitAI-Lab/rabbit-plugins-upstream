# 流月、流日、流时

大运管十年、流年管一年、流月管一月、流日管一日、流时管一时辰。层次越低，时效越短，但对具体事件的触发越精准。

> **大运 = 方向、流年 = 主题、流月 = 节奏、流日 = 触发、流时 = 应点**。

---

## 一、流月

### 什么是流月？

流月是每年十二个月的干支，以**节气**为界（非农历初一）。每个月由一对干支代表。

### 流月干支

流月的天干根据**年干**用五虎遁推算，地支固定：

| 月份 | 月支 | 节气起点 |
|------|------|----------|
| 正月 | 寅 | 立春 |
| 二月 | 卯 | 惊蛰 |
| 三月 | 辰 | 清明 |
| 四月 | 巳 | 立夏 |
| 五月 | 午 | 芒种 |
| 六月 | 未 | 小暑 |
| 七月 | 申 | 立秋 |
| 八月 | 酉 | 白露 |
| 九月 | 戌 | 寒露 |
| 十月 | 亥 | 立冬 |
| 冬月 | 子 | 大雪 |
| 腊月 | 丑 | 小寒 |

### 流月的实战用法

- 流月干支是用神 → 当月顺遂
- 流月干支是忌神 → 当月波折
- 流月冲日支 → 当月婚姻/感情有变
- 流月伏吟月柱 → 当月事务反复
- 流月 + 流年 + 大运形成**三合/三会** → 该月必有大事
- 流月填实空亡 → 该月空亡之事落地

> 流月是节奏器——一年之中哪个月好哪个月差，全看流月配合。

## 二、流日

### 什么是流日？

流日就是每一天的干支（六十甲子循环），是最小单位的"天时"。

### 流日的实战用法

- **择日**：选流日干为用神的日子办事（签约、开业、出行）
- **冲合引动**：流日冲合命局某字 → 当天有变
- **日柱伏吟**：流日与命局日柱完全相同 → 当天事情加倍
- **日柱反吟**：流日天克地冲日柱 → 当天大凶，诸事不宜
- **三合日**：流日与命局形成三合 → 合作、聚会、圆满之日

### 天赦日（特殊情况）

每年 4~5 个天赦日，是天然的"好日子"，宜嫁娶、开业、出行。查法见 [[神煞速查表#一、吉神贵人类|神煞速查表·天赦日]]。

## 三、流时

### 什么是流时？

流时是每天的十二个时辰，天干按**日干**用五鼠遁推算。

| 时辰 | 地支 | 时间 |
|------|------|------|
| 子时 | 子 | **23:00-01:00**（注意早晚子时） |
| 丑时 | 丑 | 01:00-03:00 |
| 寅时 | 寅 | 03:00-05:00 |
| 卯时 | 卯 | 05:00-07:00 |
| 辰时 | 辰 | 07:00-09:00 |
| 巳时 | 巳 | 09:00-11:00 |
| 午时 | 午 | 11:00-13:00 |
| 未时 | 未 | 13:00-15:00 |
| 申时 | 申 | 15:00-17:00 |
| 酉时 | 酉 | 17:00-19:00 |
| 戌时 | 戌 | 19:00-21:00 |
| 亥时 | 亥 | 21:00-23:00 |

### 流时的实战用法

- 时支逢驿马 → 该时辰有奔波、移动
- 流时冲日支 → 该时辰情绪波动、突发争执
- 流时合日支 → 该时辰有好事临门
- 择时办事 → 选流时为用神的时辰

## 四、四层时间体系对照

| 层级 | 管多久 | 作用 | 实战 |
|------|--------|------|------|
| **大运** | 十年 | 人生阶段方向 | 看这十年走什么运 |
| **流年** | 一年 | 年度主题事件 | 看今年发生什么 |
| **流月** | 一月 | 月度节奏 | 看哪个月应事 |
| **流日** | 一日 | 事件触发 | 选日子、看哪天出事 |
| **流时** | 一时辰 | 精确应点 | 看几点办事、几点出事 |
