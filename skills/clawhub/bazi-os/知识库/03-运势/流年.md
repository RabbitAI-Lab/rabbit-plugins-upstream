# 流年

流年即每一年的干支。流年是应期——大运决定了十年底色，流年决定了这一年具体发生什么。

> 命局 = 车　｜　大运 = 路　｜　流年 = 天气。天气好坏决定你今天出门顺不顺。

---

## 一、流年怎么看？

### 三层作用关系

```
流年 → 大运 → 命局
```

流年先与大运发生生克刑冲合害，再共同作用于命局。

### 流年天干 vs 流年地支

| 维度 | 天干 | 地支 |
|------|------|------|
| 层面 | 外在事件、表面现象 | 内在实质、深层结果 |
| 应期 | 上半年明显 | 下半年明显 |
| 力量 | 较轻 | 较重（地支为主） |

> 流年地支也叫**太岁**，是这一年最大的"话事人"，力量最强。

---

## 二、流年与命局的互动

### 流年引动命局的十种方式

| 方式 | 含义 | 举例 |
|------|------|------|
| **生** | 流年生助命局某字，该字力量增强 | 流年印星生命局日主 → 今年得贵人助 |
| **克** | 流年克制命局某字，该字受伤 | 流年伤官克命局正官 → 今年犯官非、辞职 |
| **合** | 流年合住命局某字（天干五合/地支六合） | 流年合财星 → 今年进财或恋爱 |
| **冲** | 流年冲命局某字（六冲） | 流年冲日支 → 婚姻变动、搬家 |
| **刑** | 流年与命局发生刑的关系 | 流年刑太岁 → 口舌是非、小伤 |
| **害** | 流年与命局发生害的关系 | 流年害配偶宫 → 夫妻误会、冷战 |
| **会** | 流年与命局形成三会局 | 流年寅 + 命局卯辰 → 寅卯辰会木局 |
| **合局** | 流年与命局形成三合局 | 流年子 + 命局申辰 → 申子辰合水局 |
| **填实** | 流年走到空亡的地支 | 空亡填实之年，该宫位有事发生 |
| **伏吟** | 流年与命局某柱干支完全相同 | 该柱所代表的人事今年"加倍" |

## 三、流年专项

### 天克地冲

**流年与命局某柱天干相克 + 地支相冲** = 该柱代表的六亲和人事大凶。

| 被冲之柱 | 影响 |
|----------|------|
| 冲年柱 | 祖上、父母、根基动摇 |
| 冲月柱 | 事业变动、父母、兄弟 |
| 冲日柱 | 婚姻危机、自身健康、重大转折 |
| 冲时柱 | 子女、投资、晚年规划 |

> 天克地冲是流年中最凶的组合之一。若该柱为忌神反为好事（忌神被冲走）。

### 岁运并临

大运干支与流年干支**完全相同** → 该年力量加倍，好事加倍好、坏事加倍坏。

> "岁运并临，不死自己死他人" → 古书夸张说法，实际是变化剧烈之年。

### 三刑逢冲

流年与命局同时出现**三刑 + 六冲** → 极为动荡之年，容易有意外的灾祸或重大变故。

### 日柱伏吟/反吟

| 类型 | 条件 | 含义 |
|------|------|------|
| 伏吟 | 流年干支与日柱完全相同 | 日主之事加倍，好事坏事都放大 |
| 反吟 | 流年天克地冲日柱 | 婚姻、健康大变动之年 |

## 六、三步分析法

拿到一个流年，按以下顺序分析：

1. **看太岁**：流年地支是什么？冲了谁？合了谁？
2. **看十神**：流年天干是什么十神？是用神还是忌神？
3. **看组合**：天克地冲？岁运并临？三刑？三合？
4. **看年限**：冲在年看父母，冲在月看事业，冲在日看婚姻，冲在时看子女
