# S9 · OPC / 超级个体落地清单

## R — 原文 (Reading)

> "企业层面，微小任务可通过灵活用工、OPC 承接，实现瘦身、归核与轻资产运营，借助 Web3 共建社区实现融人、融智、融资源、融市场。"
> — "价值互联网产业应用蓝皮书"编写组，第一篇·导言（p22）
>
> "OPC（One Person Company，一人公司）依托 Web3 共建社区承接微小任务、轻资产运营……个人凭核心能力参与模块协作获取通证回报，是企业'瘦身、归核、轻资产'运营下的个体承接单元。"超级个体在"AI+数据"破坏性就业趋势下把能力长板拉长、承接模块化任务获通证回报；数字游民通过分布式分工远程参与模块协作。

## I — 方法论骨架 (Interpretation)

OPC / 超级个体的核心不是"一个人开公司"的法律概念，而是一种**组织依附关系**：当产业链被 Web3 拆成可独立计价的功能模块后，个体不再需要自建团队或重资产，而是凭一项核心能力，作为"一人单元"嵌入共建社区去接这些微小任务，并按贡献拿通证回报。

轻资产逻辑是双向的：
- **企业侧**：把非核心的微小任务（内容、标注、运维、传播、设计）分包出去，自己聚焦核心能力、瘦身归核，不再养全套人力与固定资产。
- **个体侧**：不需要办公室、不需要融资、不需要雇佣，只用一台设备和一项长板就能参与全球分工，风险与成本压到最低。

通证在这里不是"币"，而是**贡献的计量尺与积累凭证**——你接的每一单都被上链记录、可验证、可累计，长期沉淀为个人数字资产（技能声誉 + 通证权益），这正是它区别于普通自由职业"干完一单是一单"的地方。

## A1 — 书中的应用 (Past Application)

### 案例 1: 道衍数科「学习即创业」商学苑（c13）
- **问题**：Web3 转型存在"人才鸿沟"，学员有意愿但无落地场景，个体难以把学习转化为可度量价值。
- **方法论的使用**：把课程拆成"商业思维课 / 超级个体实操课 / 事业焕新研学课"，用区块链学分记录学习、分享、实训行为，形成"行为即贡献、贡献即激励"闭环；数字学分可兑换权益并链接 B 端企业转型需求。
- **结论**：非标准化的个体参与被转化为可度量贡献，个体既是学员也是"超级个体"承接方。
- **结果**：形成"学习即创业"共识，呈现自组织裂变、动态迭代成长态势。

### 案例 2: OORT 去中心化 AI 数据云（c02）
- **问题**：AI 训练算力/存储成本高，分散在全球的个人闲置设备无法被可信整合结算。
- **方法论的使用**：以区块链为激励层聚合全球分散算力（高校实验室、企业数据中心、个人闲置设备），用"贡献激励 + 算力证明（PoH）"保障个人贡献可追溯、结果可验证，智能合约自动调度与结算。
- **结论**：个人凭闲置算力作为"数字游民/超级个体"单元远程参与，贡献被精准计量。
- **结果**：成员遍布 130+ 国家、超 35 万人；中国实践使计算时间缩短约 35%、成本降约 50%。

### 案例 3: 海数交（海南）RDA 服务平台（c19）
- **案例背景**：项目方承接"制造业高质量数据集"等订单时，模块化任务协同、工作量计量与分账缺乏可信自动化机制。
- **方法论的使用**：协同标注、清洗等共建者以工作量证明（POW）计工作量、用价值凭据 HAI 计价结算，RDA 上架流通后按社区模型智能合约自动分账。
- **结论**：分散的个体标注/清洗任务被包装成可计价模块，个体凭技能远程接单、累计回报。
- **结果**：建成海南数据流通基础设施，支持海外数据"来数加工"并自动分账。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 个体创作者/自由职业者想进入 Web3 领域，但不知道"自己能接什么活、从哪接"。
2. 想做轻资产的"一人公司 / 超级个体"，不愿租办公室、养团队、重资产投入，只想凭一项能力变现。
3. 数字游民/远程工作者想用分布式分工参与某个产业链，但找不到可独立计价的任务入口。
4. 已经在某个社区/平台接单，但不清楚自己的零散贡献能否被可信计量、长期积累成个人资产。
5. 小微企业主想"瘦身归核"，把非核心微小任务分包出去，需要一份个体侧接单与自保清单。

### 语言信号 (用户的话里出现这些就应激活)

- "我就是一个人 / 自由职业，想做 Web3 但不知道能干什么"
- "不想重资产创业，想做轻资产的一人公司、超级个体"
- "我在外地/国外远程，怎么参与你们的共建、接模块任务"
- "我帮人写稿/做图/标注/运维，这些贡献怎么算、怎么累计"
- "我想把零散能力变成可接单、可计价的小任务"

### 与相邻 skill 的区分

- 与 `S6 共建社区运营框架` 的区别：S6 是**平台/企业侧**如何搭建事业共同体、设计四融与黏性工具；本 skill 是**个体侧**"我作为承接单元怎么接单、怎么累计"，不从零搭社区。
- 与 `S5 贡献计量与分配设计器` 的区别：S5 解决"社区/平台如何把多元贡献代码化、公平分润"的规则设计；本 skill 假设规则已存在，聚焦"个体如何盘点能力、匹配任务、累计通证"。
- 与 `S2 合规边界红线检查` 的区别：S2 判境内能不能做（严禁代币化等加密金融）；本 skill 在合规前提下谈个体接单路径，但接单前应先过 S2。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **盘点自身可承接的微小任务**
   - 引导用户列出自己的核心能力长板（写作/设计/标注/运维/翻译/社群/调研等），并拆成**可独立交付、可计价**的模块任务（如"一篇科普长文""100 张数据标注""一次社群答疑"）。
   - 完成标准：产出一张"能力 → 可交付模块任务 → 预估单价/时长"清单，至少 3 条，每条可被外部验收。

2. **接入共建社区 / 接单入口**
   - 帮用户匹配能承接上述模块的 Web3 共建社区或平台（如产业侧 RDA 数据标注平台、创作者共建社区、去中心化算力/内容网络），确认其采用"贡献即确权"的通证计量机制。
   - 完成标准：用户锁定 1–2 个具体接单场景，并明确该场景用什么通证/凭据计量贡献、结算周期。
   - 判停条件：若用户目标场景涉及"发币募资 / 代币升值 / 境内面向居民募资"等元素，跳到步骤 ③ 前先提示转用 S2 合规边界红线检查，否则不得继续。

3. **用通证计量与积累回报**
   - 指导用户把每单贡献上链记录（学分/凭据/工作量证明），定期核算累计的通证权益与声誉，形成个人数字资产账本；并提醒其区分"产业收益驱动"与"拉新噱头"。
   - 完成标准：用户建立可持续的"接单 → 上链计量 → 累计回报"闭环，能说出自己已沉淀的通证/权益数量与来源，而非仅依赖平台口头承诺。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户想做的是**平台/企业侧的社区搭建与分配规则设计**——改用 S6 共建社区运营框架、S5 贡献计量与分配设计器。
- 用户问的是**境内能不能发币/代币化融资**——改用 S2 合规边界红线检查；本 skill 不处理任何涉加密金融的合规判定。
- 用户已有清晰的一人公司注册与财税方案，仅咨询工商流程——超出本书方法范畴。

### 作者在书中警告的失败模式

- **"伪 RWA"以"赋能实体/贡献分配"为名实为变相集资盘**（ce18）：历史大量项目用"贡献即确权"叙事掩盖资金池运作，收益主要来自拉新而非真实产业现金流。个体参与前必须确认分配有真实审计、收益来自产业现金流而非拉人头。
- **概念包装 / 监管联想风险**（ce16、ce10）：把普通"拉新返利""微商"包装成"超级个体通证激励"，或用"通证"一词暗示金融工具——本质仍是空气币/传销。真正的 OPC 承接的是**真实产业链微小任务**，不是买币升值的故事。
- **"慢资产快金融"错配与投机炒作**（ce06、ce12）：警惕任何强调"币价升值、已获批"却无真实锚定资产与第三方审计的项目，普通参与者信息不对称的崩盘风险极高。

### 作者的盲点 / 时代局限

- 编写组含项目方（道衍数科等），对"通证激励是否真能持续激活贡献、而非沦为拉新噱头"实证不足——个体需自行验证社区的真实活跃与分润兑现率。
- 假设"贡献可被通证精准计量"，但创意、关系、声誉类贡献难以客观度量；个体承接时应优先选**可量化、可验收**的模块任务，避开纯主观贡献。
- 成稿于 2025 年，监管（尤其香港沙盒、稳定币合法化）仍在快速演化，个体跨境接单须以最新合规口径为准。

### 容易混淆的邻近方法论

- 把 OPC 当成"一人有限责任公司"法律实体（t15 明确：它是组织形态/就业趋势描述，不对应特定商事登记）——不要套用公司法条去设计。
- 把"超级个体"等同于"自由职业/斜杠"（t16 强调其依赖 Web3 共建社区与通证计量的新型组织依附，而非单纯兼职）。


### 合规红线与使用须知（普通用户必读）

本技能提炼自《价值互联网产业应用蓝皮书（2025）》（蓝皮书编写组，主编：梁超杰）第三篇·第五章「合规边界」，仅供风险识别与科普参考，**不构成任何投资建议、法律意见或投资邀约**。

- 中国境内开展价值互联网与通证经济产业应用，**不得涉及通证代币化等加密金融行为**，应聚焦"非金融"的数字化赋能（溯源、贡献计量、RDA 真实数据资产等）。
- 包括稳定币在内的虚拟货币，**在中国境内发行与交易属于非法金融活动**（央行等十部门 2021 年《关于进一步防范和处置虚拟货币交易炒作风险的通知》）。境外交易所、项目向中国境内居民提供服务同样属非法。
- **连带责任无死角**：不仅直接参与违法，为境外违规项目提供账户、资金划转、技术支持也依法追责——"只是帮忙做技术"不能免责。
- 任何以"Web3/区块链"为名、要求充值、拉人头返利、承诺升值预期的，极可能是资金盘，**请勿参与、勿投资、勿转发**。

> 引用原文："不能涉及通证代币化等加密金融行为，而应聚焦探索'非金融'的数字化赋能产业提效方向。""包括稳定币在内的虚拟货币无法满足 KYC、AML 等要求，在中国境内发行与交易虚拟货币属于非法金融活动。" —— 第三编·第五章（合规边界）／ p02、ce03

## 相关 skills

- **depends-on**：**S5 贡献计量与分配设计器**——个体接单前需有可信的贡献计量与分润规则（由 S5 设计），S9 在其上做个体侧累计。
