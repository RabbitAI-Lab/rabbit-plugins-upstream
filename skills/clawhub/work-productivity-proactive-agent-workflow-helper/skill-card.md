## Description:

Helps AI-agent users, skill authors, maintainers, and teams turn Proactive Agent-style productivity requests into practical workflows, checklists, analyses, code changes, or implementation support.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

## Use Case:

External developers, AI-agent users, skill authors, maintainers, and teams use this skill to structure proactive productivity work into clear outcomes, plans, checklists, analyses, code changes, and verification notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may trigger this workflow on generic productivity or bug-fix requests where it was not intended.

Mitigation: Narrow the trigger terms or invoke the skill manually in environments where broad productivity assistance is not desired.
