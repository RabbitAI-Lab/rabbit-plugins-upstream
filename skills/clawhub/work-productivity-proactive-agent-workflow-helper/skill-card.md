## Description: <br>
Helps AI-agent users, skill authors, maintainers, and teams create practical workflows, checklists, analysis, code changes, and decision support for proactive-agent-style productivity work. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

## Use Case: <br>
External AI-agent users, skill authors, maintainers, and teams use this skill to turn proactive-agent productivity requests into concrete plans, artifacts, checklists, analysis, implementation support, or verification notes. It is intended for practical workflow support around bug fixing, setup hardening, reliability improvements, and adjacent skill creation. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger words and implicit invocation can make the skill activate for ordinary work or bug-fix requests where a more specific skill would fit better. <br>
Mitigation: Confirm the user's immediate outcome and constraints before applying the workflow, and prefer a more specific skill when the request clearly belongs to one. <br>
