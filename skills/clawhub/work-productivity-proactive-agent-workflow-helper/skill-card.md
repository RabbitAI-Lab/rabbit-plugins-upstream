## Description:

Helps agent users, skill authors, and maintainers plan, improve, and validate proactive workflows and related work artifacts.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

External users, developers, and skill maintainers use the helper to turn workflow needs into practical plans, checklists, analyses, implementation artifacts, and validation steps. It is intended for improving proactive-agent workflows or creating reliable adjacent workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation keywords may select this helper for an unrelated request.

Mitigation: Invoke it explicitly when selection is uncertain and check that its workflow matches the task.

Risk: Generated plans or automation may not fit the user's environment or actual task.

Mitigation: Review proposed steps and generated automation against the task and environment before running them.
