## Description:

Helps AI-agent users, skill authors, maintainers, and teams turn proactive-agent workflow needs into practical plans, artifacts, checklists, analysis, code changes, or decision support.

This skill is ready for commercial/non-commercial use.

## Use Case:

AI-agent users, skill authors, maintainers, and teams use this skill to convert proactive-agent productivity requests into concrete workflows, implementation support, checklists, or review notes. It is intended for practical work-productivity assistance that stays feasible on ordinary local hardware.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on generic productivity wording because implicit invocation is enabled and trigger wording is broad.

Mitigation: Use explicit invocation or tighter trigger settings when unwanted activation would disrupt the agent workflow.
