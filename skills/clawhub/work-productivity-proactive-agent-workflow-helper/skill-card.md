## Description:

Helps agent users and skill authors turn proactive-agent workflow needs into practical plans, checklists, code changes, analysis, and validation notes.

This skill is ready for commercial/non-commercial use.

## Use Case:

AI-agent users, skill authors, maintainers, and teams use this skill to clarify proactive workflow requests, create practical plans or reusable checklists, and validate outputs without requiring the original demand evidence.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger language and implicit invocation can route generic productivity, task, or bug-fix requests to this skill unexpectedly.

Mitigation: Confirm that the request fits a proactive workflow, skill-authoring, reliability, or work-productivity planning need before applying the workflow.

Risk: Workflow guidance, generated code, shell commands, or configuration snippets could be incorrect or incomplete for the user's environment.

Mitigation: Review proposed changes before execution, run local tests or scans where applicable, and keep assumptions and follow-up risks visible in the final output.
