## Description:

Helps agent users, skill authors, maintainers, and teams turn proactive-agent productivity needs into practical workflows, checklists, artifacts, analyses, code changes, or decision support.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

AI-agent users, skill authors, maintainers, and teams use this skill to turn proactive-agent productivity requests into practical workflows, templates, checklists, implementation help, or decision support. It is intended for productivity tasks such as bug fixing, setup hardening, reliability improvement, and creating adjacent skills inspired by similar user needs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Implicit invocation is enabled with broad productivity and bug-fix keywords, so the skill may activate on loosely related requests.

Mitigation: Use explicit invocation when available, or confirm the intended productivity workflow before applying the skill to ambiguous requests.

Risk: Generated workflows, code changes, or decision aids may be incorrect for a user's environment or success criteria.

Mitigation: Review assumptions, validate the output against the stated success criteria, and test code or shell commands before relying on them.
