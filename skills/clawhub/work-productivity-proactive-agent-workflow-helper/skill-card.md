## Description:

Helps AI-agent users and skill authors turn proactive-agent workflow needs into practical plans, artifacts, checklists, code support, and verification notes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

AI-agent users, skill authors, maintainers, and teams use this skill to convert proactive-agent workflow needs into practical, local-friendly plans, checklists, implementation support, and decision aids. It is intended for productivity workflows such as fixing bugs, hardening setup and safety, improving reliability, and adapting adjacent skill patterns.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad triggers and implicit invocation may route ordinary productivity or bug-fix requests to this helper when the user did not intend it.

Mitigation: Prefer explicit invocation for predictable routing, and confirm the user's outcome, constraints, and success criteria before producing artifacts.
