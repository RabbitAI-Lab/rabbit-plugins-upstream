# 预算设计（买前核心）

> 专家包「最懂你的保险顾问」共享知识库（纯方法论，无时效风险）
> 核心立场：**先讲哪些钱不用花，再算该花多少**。预算是客户最想知道、也最容易被销售带偏的一环。

## 一、四步法

### 第 1 步 · 四账户总盘（来源：标准普尔家庭资产象限图，**参考框架，不是铁律**）

| 账户 | 装什么 | 与保险的关系 |
|---|---|---|
| 要花的钱 | 3-6 个月日常开销 | **先留够，再谈保费**——应急金没留，保费就是压力 |
| **保命的钱** | 保障类保险 | **保障类保费出自这里**，专款专用，不挪用 |
| 生钱的钱 | 投资 | 账户内买什么**不展开**（涉及具体产品，属雷区） |
| 保本升值的钱 | 长期储蓄 | 同上，只讲"储蓄 vs 保障"的分类，不谈品种 |

> 讲法：不说"标准普尔建议 20%"，说"这个图只是个排骨架，告诉你保障的钱要有单独一格；具体比例每家不一样，别照抄"。

### 第 2 步 · 预算三问（允许客户回答模糊，**宁粗不错**）

1. 家庭年收入大概在哪个档？（区间即可，税后、双职工合计）
2. 刚性负债有哪些？（房贷、车贷、有没有要抚养的人）
3. 现在每年已经在交多少保费？（可从保单体检 / 金事通 / 已有保单取数）

> 客户说不清时**用区间照样给答案**，不要追问到他说得出精确数字。一次只问一件事。

### 第 3 步 · 试算表（脚本 `scripts/budget_calc.py` 生成）

```
| 项目 | 填写/计算 | 说明 |
| 家庭年收入 | ___（区间即可） | 双职工合计，税后 |
| 应急金预留 | 3-6 × 月刚性支出 | 先留这笔，再谈保费 |
| 保费预算区间 | 年收入 × 5%-10% | 负债重/收入波动大取下限 |
| 已有保费支出 | ___（所有保单年缴合计） | 从保单体检 / 金事通获取 |
| 剩余可配空间 | 预算区间 − 已有支出 | 为负 → 先做保单体检，不加保 |
| 警戒线 | 总保费超年收入 15-20% | 超了就降档 |
```

### 第 4 步 · 分配与保额

- **人**：大人占比显著高于孩子、老人。
- **险种层级**：医疗 + 意外（几百元级）→ 重疾 + 定寿（千元级）→ 储蓄类（量力而行）。
- **保额算法**：见 `insurance_abc.md` 第五节。

**降档三招**（保费超了怎么用）：保额（出事了最多赔你多少）够就行不追高 / 期限买短（保到 60 岁而不是终身）/ 选消费型（不出事不退钱，但便宜）。

## 二、缺口公式（交叉验证用，来源：行业通用口径，出自友邦《家庭保障管理手册 2.0》）

- **重疾保额（重疾险出事了赔你的那笔钱）** = 治疗费用 + 5 年收入 + 5 年收入的增值部分
- **意外 / 寿险保额（同口径：赔给家里的那笔钱）** = 十年负债 + 十年家庭开销 + 十年收入增值

> 讲法：这是**卖方视角的算满口径**，用来验证"保额是不是明显不够"，不是让你按这个数去买。算出缺口的目的是知道该往哪加，不是制造欠账感。

## 三、红线 4 条（违反即拒答）

1. **不给精确保费报价**——只给比例区间和档位感。
2. **不反向倒推产品**——不说"你这个预算适合买某某"。
3. **预算不足时不制造焦虑**——讲优先级、讲杠杆，不讲"不买就完了"。
4. **储蓄类占比话题不展开**——只讲"储蓄 vs 保障"的分类即止。

## 四、预算讲完怎么收尾

必须落到一张带走物（**纸二 · 投保前三问**）和一句话：

- 「你现在的保费**还剩多少空间**，这个数记住就行，往下谈配置都拿它当尺子。」
- 「下一步：要么聊这四类先配哪个（买什么），要么聊看条款怎么看（怎么买）。」

**固定尾注**：本文为保险通识教育内容，不构成投保建议；一切以保险条款原文、保险公司核保理赔结论及监管规定为准。
