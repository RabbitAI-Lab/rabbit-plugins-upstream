# 保险 ABC 扫盲卡

> 专家包「最懂你的保险顾问」共享知识库（纯方法论，无时效风险）
> 使用规则：**先扫盲，再讲别的**。对没接触过保险的人，任何回答开始前都要用上本卡的口吻。

## 一、四类险种一句话（讲"什么时候能用上"，不讲定义）

| 险种 | 一句话 | 类型 |
|---|---|---|
| 百万医疗险（住院花的大钱） | 住院花的大钱，医保（社会医疗保险）报完剩下的它报 | 报销型 |
| 重疾险（重大疾病险） | 确诊合同里列的病，直接给一笔钱，爱怎么花怎么花 | 给付型 |
| 意外险 | 磕碰摔伤、意外身故伤残 | 给付型 |
| 定期寿险 | 人不在了，留给家里人一笔钱还贷、过日子 | 给付型 |

**必讲清的一条分界线**（这是"能不能买两份"的唯一判断依据）：

- **报销型** = 花多少报多少，**不重复赔**。买两份百万医疗，同一笔住院费只能报一次。
- **给付型** = 符合条件直接给钱，**可以叠加**。重疾、寿险、意外身故买几家赔几家。

> 讲法：不说"报销型保险的损失补偿原则"，说"这笔住院发票，只能报一次，报两次就变成赚钱了，所以不行"。

## 二、配置顺序（四件套，按家庭角色排）

1. **先保赚钱的人**——大人倒了，收入才真的断；孩子和老人排后。
2. **顺序**：百万医疗 → 意外 → 重疾 → 定期寿险。
3. **价格感**：医疗险和意外险是几百元级，重疾和定寿是千元级，先配齐前两级再谈后两级。
4. **储蓄类（年金、增额终身寿）**：四件套没配齐之前不谈。

## 三、术语人话表（首次出现必带括号）

| 术语 | 人话 |
|---|---|
| 保额 | 出事了最多赔你多少 |
| 保费 | 你交的钱 |
| 免赔额 | 这个数额以下不赔，你自己先出 |
| 等待期 | 买完这段时间内出事不赔 |
| 犹豫期 | 买完这段时间内退保，钱全退给你 |
| 保证续保 | 写进合同、年限内保险公司必须让你续 |
| 除外承保 | 其他都保，就这一项不保 |
| 现金价值 | 退保时能拿回的钱 |
| 宽限期 | 忘交保费之后还能补救的时间 |
| 投保人 / 被保险人 / 受益人 | 交钱的 / 被保障的 / 拿赔款的 |
| 免责条款 | 写了哪些情况不赔 |
| 核保 | 保险公司审你要不要保、怎么保 |

> 纪律：**同一句话里不允许出现 2 个没翻译的术语**。宁可翻得啰嗦，也不要让客户猜。

## 四、最低保障线

**医保（医保是地基）+ 百万医疗（住院的大钱）+ 重疾（确诊给一笔钱）**。

- 医保没配齐 → 先补地基，别急着买商业险。
- 已有百万医疗 → 同类的第二份不重复赔，不用买。
- **身体好 + 已有百万医疗 → 惠民保（各地政府指导、不限既往病史的普惠医疗险）不必重复买**；买不了百万医疗的人，惠民保才是它真正的作用。

## 五、保额怎么估（行业经验区间，不是标准答案）

| 险种 | 经验算法 | 说明 |
|---|---|---|
| 重疾 | 约 3-5 倍家庭年收入 | 覆盖治疗 + 生病期间没收入还要开销 |
| 定期寿险 / 意外 | 约 5-10 倍年收入 + 负债余额 | 人不在了，房贷和家里开销还要继续 |

**有负债时加的是杠杆不是开支**：保额要跟着负债上浮，但保费不随负债等比上浮（所以优先定期、优先消费型）。

## 六、扫盲怎么收尾

扫盲讲完必须落到两句话之一，不许停在概念上：

- 「所以你现在可以先看：**医保有没有、住院的大钱有没有人兜**。」
- 「下一步你想聊该花多少钱，还是想聊这四类先配哪一个？」

**固定尾注**：本文为保险通识教育内容，不构成投保建议；一切以保险条款原文、保险公司核保理赔结论及监管规定为准。
