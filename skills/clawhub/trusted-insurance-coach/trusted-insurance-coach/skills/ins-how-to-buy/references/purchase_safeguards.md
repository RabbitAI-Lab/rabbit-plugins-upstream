# 投保与买后：该留的凭据与四个日期

> 数据截至：2026-10-31 ｜ 纯方法论（具体天数以合同为准，不引用数字）
> 用法：客户问"犹豫期能退吗""忘交保费了怎么办""受益人怎么填""买完要留什么"时按本文讲。

## 一、四个日期（买完先抄下来）

| 日期 | 为什么重要 | 客户动作 |
|---|---|---|
| **犹豫期（买完这段时间内退保全退）截止日** | 这是唯一能**无损反悔**的窗口 | 拿到保单先看它是多少天，记下来 |
| **缴费日** | 忘交会进入宽限期（忘交保费后的补救时间）；宽限期也过了会失效 | 设个提醒；让它从家庭固定支出里出 |
| **等待期（买完这段时间内出事不赔）截止日** | 这段时间内出险通常不赔 | 记下来，别在这期间做非必要的检查 |
| **续保（到期接着买）日** | 医疗险和一年期意外险到期要处理 | 到期前一个月自己主动问 |

## 二、犹豫期怎么用

- **它能做什么**：这段时间内退保，钱全退给你。这是你唯一能无损反悔的机会。
- **怎么用**：拿到合同后，先在犹豫期（买完这段时间内退保全退）内把**责任免除（免责条款，写了哪些情况不赔）**读完——读完再决定留不留。
- **不替客户决定留不留**：只告诉他这个窗口存在、怎么用。

## 三、忘交保费怎么办

- **宽限期（忘交保费后的补救时间）**：忘交之后还有一段补救时间，**这段时间内出事通常照样能赔**。
- **客户动作**：发现忘交 → 尽快补交 → 补交前先打官方客服确认保单状态。
- **别说"忘交保单就作废了"**——这是制造焦虑，也和宽限期（忘交保费后的补救时间）的约定不符。

### 3.1 真失效了还能救回来：复效（失效后申请把保单救活）

宽限期也过了、保单进入**中止状态**（不赔、但还没彻底作废）——**这时候还有救**，动作叫**复效**（失效后申请把保单救活）。

| 关键点 | 说明 |
|---|---|
| **救的时间窗** | 一般是失效后 **2 年内**可以申请复效，**过了这 2 年合同才真的终止**（具体以合同为准，务必翻原文） |
| **为什么要救** | 失效期间出事不赔；但**重新买一份更麻烦**——年龄大了贵，身体有新问题可能买不了 |
| **要付什么** | 补交欠的保费 + 通常要补利息；**可能要重新回答健康问题、可能重新算等待期** |
| **不一定能救成** | 保险公司会**重新审核**，身体情况变化大可能被拒，这是复效和"续交"最大的区别 |
| **怎么开始** | **别在 App 里自己乱点**，先打官方便民客服，问三句：保单现在什么状态 / 还能不能复效 / 复效要不要重新核保 |

> **讲给客户的原话**：「失效不等于废了，一般两年内还能救。但救的时候可能要重新查身体，所以**越早打客服越好**——拖到身体有变化，想救也救不回来。」
>
> **反向提醒（防销售套路）**：如果有人说"你这保单失效了，正好换一份更好的"——**先别信**。先问清楚原来那份还能不能复效。**新买一份，等待期要重新算，这两年等于白保。**

## 四、受益人（拿赔款的人）怎么填

- **写名字，不写「法定」**。只写法定，将来按遗产处理，手续更麻烦。
- 可以指定多人并写明比例。
- 家庭情况变化（结婚、生子、离婚）后要回头改一次。

## 五、买完要留的四样凭据

1. **合同原文**（纸质或电子版都行，能翻到条款正文的那种）；
2. **缴费记录**（扣款凭证，别只靠记忆）；
3. **报案电话**（抄合同封面上的**官方客服号**，不要只存销售的手机号）；
4. **纸一 · 我的保险清单**，并交给一个家人。

## 六、销售的说法怎么留痕

- **落在口头上的不算**：凡是承诺，让对方写进合同或书面说明。
- **写不下来就是没有**——这句话要讲得客气：**「不是他说谎，是只有写在纸上的才作数」**。
- 涉及具体承诺争议 → 走**理赔怎么办**那一条路径（先拿书面结论）。

## 七、买后三条叮嘱（与同伴 skill 共用）

1. 看病时跟医生**讲症状和经过**，不猜病名、不说"我以前就有"——**病历写错最难改**；
2. 病历、诊断证明、发票原件、费用清单留好，出险第一时间报案；
3. **告诉一个家人**你买了什么、报案电话是多少。

## 八、收口

> 「买完不是结束。这四个日期抄下来、四样凭据留好、告诉一个家人——做到这三件事，这份保单才真的算买好了。」

**固定尾注**：本文为保险通识教育内容，不构成投保建议；一切以保险条款原文、保险公司核保理赔结论及监管规定为准。
