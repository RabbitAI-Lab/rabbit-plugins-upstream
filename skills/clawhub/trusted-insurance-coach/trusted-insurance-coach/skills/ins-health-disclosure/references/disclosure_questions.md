# 告知问卷高频题型库（逐题讲懂用）

## 0. 讲题之前必讲的三条规则（第一题之前就讲）

1. **有限告知原则（问什么答什么）**：问卷问到的必须如实答；**没问的不用主动交代**。法律依据见 `law_citations.md`（《保险法》第十六条，通识表述）。
2. **判断依据是你手上的材料，不是记忆**：体检报告、门诊/住院病历、用药记录、医保卡使用记录。医生说"没事"≠ 问卷可以答"没有"——**问卷问的是"有没有过这个情况"，不是"严不严重"**。
3. **严格按题目的时间段**：写"最近 2 年"就只翻 2 年内的材料；写"曾经/是否曾"则是**终身范围**。不要自己扩大，也不要自己缩小。

## 1. 既往疾病史 / 病史

| 项目 | 内容 |
|---|---|
| 常见问法 | "您是否曾患有或被告知患有下列疾病：高血压、糖尿病、心脏病、脑卒中、肿瘤/肿块、肝炎、肾病……" |
| 它在问什么 | 你有没有被医生**诊断过**（写在病历/诊断里的），不是你自己觉得有没有不舒服 |
| 怎么核对 | ①翻门诊病历本/医院公众号电子病历的"诊断"栏；②翻住院病案首页的"出院诊断"；③翻体检报告的"异常汇总/建议复查"页 |
| 常见误答 | ①"医生说不用治"就答没有（错：有没有 ≠ 要不要治）；②"体检报告上写了但我没看过"当作没有（错：以报告为准）；③忘了几年前住过院 |

## 2. 体检异常（结节 / 息肉 / 增生 / 指标异常）

| 项目 | 内容 |
|---|---|
| 常见问法 | "最近 2 年内是否接受过检查并发现异常（如结节、息肉、囊肿、肿块、占位、结节影、磨玻璃影、指标异常）？" |
| 它在问什么 | 影像或化验报告里**有没有被标注为异常的字眼**——"结节（报告上的小疙瘩）""磨玻璃影（肺CT上的模糊影）""占位（医生还不确定是什么的阴影）"都算 |
| 怎么核对 | ①近 2 年体检报告每份都要翻，重点看"异常汇总"与"影像/超声结论"；②有 CT/超声/MRI 的，看"检查结论"和"建议"，不看描述正文的自我判断；③抽血看箭头与"异常提示" |
| 常见误答 | ①"良性的就没关系"（错：问的是有没有发现，良性也要告知，结论通常是除外或标准体）；②"很小不用管"（错：大小是核保判断，不是你判断）；③只翻了去年忘了前年（注意时间范围） |

> **结节类三步走**（最常见的体况）：①先确认报告上写的**位置、大小、分级（如甲状腺 TI-RADS 分级、乳腺 BI-RADS 分级）、医生建议**；②把这些原话抄下来，答题时按原话描述；③拿不准 → 走智能核保/预核保（见 `underwriting_paths.md`），不凭感觉选。

## 3. 住院史 / 手术史

| 项目 | 内容 |
|---|---|
| 常见问法 | "最近 5 年内是否曾住院治疗或接受手术？" |
| 它在问什么 | 有没有**住过院（哪怕一天）**、做过手术（含微创、日间手术、剖腹产、人流、内镜下治疗） |
| 怎么核对 | ①出院小结/出院记录（最权威）；②住院病案首页；③医保结算记录（国家医保服务平台 App 可查消费记录，用来回忆在哪家医院） |
| 常见误答 | ①"就住了两天不算"（错：算）；②"剖腹产是生孩子不算"（错：算手术）；③"二十年前的不问了"——注意题目时间窗是 2 年/5 年还是"曾经" |

## 4. 用药史

| 项目 | 内容 |
|---|---|
| 常见问法 | "最近 1 年/2 年内是否连续服药超过 2 周（或 30 天）？" |
| 它在问什么 | 长期规律服药 = 身体有需要持续管理的状况（降压药/降糖药/甲状腺素/抗抑郁药等） |
| 怎么核对 | ①医保购药记录（国家医保服务平台 App）；②药盒与处方；③门诊病历的"处方/用药"栏 |
| 常见误答 | ①"保健品不算药"——处方药才算，但不确定就按原话告知；②"断续吃的"——看"连续"怎么定义，按题目天数如实描述 |

## 5. 两年内检查 / 就诊史

| 项目 | 内容 |
|---|---|
| 常见问法 | "最近 2 年内是否曾接受门诊诊疗、影像学检查、病理活检、或被建议复查/住院？" |
| 它在问什么 | 只要**看过门诊、做过检查、被医生建议进一步检查**就算（不需要确诊） |
| 怎么核对 | ①门诊电子病历；②检查报告单；③体检报告里"建议复查"那一句 |
| 常见误答 | "只是去查了一下，没问题就没告知"——**"被建议复查"本身就是要告知的内容** |

## 6. 医保卡外借

→ 专项见 `medical_insurance_card.md`。问卷通常问："您是否有将医保卡交付他人使用/外借的情况？"

## 7. 既往投保与核保史

| 项目 | 内容 |
|---|---|
| 常见问法 | "您是否曾被保险公司拒保、延期、加费或除外承保？是否曾申请过理赔？" |
| 它在问什么 | 你在别家的核保与理赔记录（行业内有共享的核保理赔信息） |
| 怎么核对 | 凭记忆 + 过往保单/核保结论通知；不确定就不要猜，如实写明"不确定，曾于某年在某司投保"（**不得隐瞒已知事实**） |
| 常见误答 | 以为"别的公司不知道"——核保理赔信息行业共享，瞒不住，且瞒了反而坐实不如实告知 |

## 8. 职业与高风险运动

| 项目 | 内容 |
|---|---|
| 常见问法 | "您的职业是？是否从事高空/井下/爆破/海上作业？是否有潜水、攀岩、赛车等高风险运动？" |
| 它在问什么 | 意外与身故风险的定价因素 |
| 怎么核对 | 按实际工作内容填（不是按名片上的职位）；兼职的高风险活动也要说 |
| 常见误答 | 办公室职员周末去攀岩 → 只填了"职员"，出险时易起纠纷 |

## 9. 生活习惯（吸烟 / 饮酒）

| 项目 | 内容 |
|---|---|
| 常见问法 | "您是否吸烟？每日多少支、多少年？是否每日饮酒？量多少？" |
| 它在问什么 | 费率与核保口径（有明确的支数与量级档位） |
| 怎么核对 | 按实际平均量如实填，不要"美化" |
| 常见误答 | "偶尔抽"当成"不吸烟"；已戒的通常要说明戒烟时间 |

## 10. 女性专项（怀孕 / 乳腺 / 妇科）

| 项目 | 内容 |
|---|---|
| 常见问法 | "是否怀孕？孕几周？是否有妊娠期并发症（妊娠糖尿病/高血压）？是否有乳腺结节、子宫肌瘤、卵巢囊肿、宫颈病变（TCT/HPV 异常）？" |
| 它在问什么 | 孕周直接决定能否投保与延后；乳腺/妇科异常按分级与随访情况核保 |
| 怎么核对 | ①产检手册（孕周、并发症）；②乳腺超声报告的 BI-RADS 分级；③妇科超声与 TCT/HPV 报告 |
| 常见误答 | ①"怀孕了先不说，买了再说"（错：孕周是必问项，隐瞒影响理赔）；②把"乳腺增生"当乳腺结节混答（两者不同，按报告原话填） |

## 11. 儿童专项

| 项目 | 内容 |
|---|---|
| 常见问法 | "是否早产（孕周<37周）/低出生体重（<2.5kg）？是否有先天性疾病、遗传性疾病、发育迟缓、抽搐史、新生儿住院史？" |
| 它在问什么 | 新生儿期的风险记录 |
| 怎么核对 | ①出生证明（孕周、体重）；②儿童保健手册（发育评估）；③新生儿科住院记录；④预防接种证（间接核对时间线） |
| 常见误答 | "孩子很健康就不用翻本子了"——**孕周和出生体重必须查出生证明**，很多家长记不准 |

## 12. 家族史

| 项目 | 内容 |
|---|---|
| 常见问法 | "您的父母、兄弟姐妹是否患有癌症、糖尿病、高血压、心脏病、精神病等？" |
| 它在问什么 | 仅限题目列明的亲属范围，通常**不含祖父母、不含配偶的家人** |
| 怎么核对 | 按题目列举的亲属逐位回想，不确定就答"不确定/不清楚"（不要编） |
| 常见误答 | 把爷爷奶奶的病史也答上去（超出询问范围，无谓地增加核保难度） |

## 附：翻不到病历的三条补打途径（口述降级分支用）

1. **医院病案室复印**：带本人身份证（代办需双方身份证 + 委托书），到就诊医院的病案室/医务科申请复印住院病案与门诊病历，一般可现场取或邮寄；问清是否有电子申请渠道。
2. **医院公众号 / 小程序 / App**：多数三甲医院支持线上调阅电子病历、检查报告与处方；在"就诊记录/报告查询"里导出或截图。
3. **区域电子健康档案 & 医保记录**：地方卫健委/健康云类平台的电子健康档案可查历史就诊与检验；医保消费记录用**国家医保服务平台** App 或本地医保小程序查询（用来回忆在哪家医院、什么时间看过病）。

> **降级纪律**：拿不到材料时，输出"不完整版清单"并逐项标注 `【未核实】`，明确告知"未核实项按口述记录，正式投保前必须补核；不一致时以材料为准"。**不得让用户凭记忆拍脑袋答题。**
