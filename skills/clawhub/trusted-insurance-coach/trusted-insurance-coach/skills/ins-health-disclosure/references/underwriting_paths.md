# 核保三路径 + 五结论 + 两年不可抗辩真相

## 1. 三条核保路径（用户最缺的操作地图）

| 路径 | 怎么操作 | 会不会留记录 | 什么时候用 |
|---|---|---|---|
| **智能核保** | 投保页面上的问卷逐项答，实时出结论 | **匿名，不留拒保记录** | **体况有任何异常，永远先走这条**（试水成本最低） |
| **预核保** | 正式投保前先把体况材料交给保险公司的核保端（常通过经纪/代理渠道或保司预核保入口）拿意向结论 | **不产生正式投保记录** | 体况复杂时"探路用"：拿结论再决定要不要下单，可多家同时问 |
| **人工核保** | 正式投保并提交病历/体检报告，核保员审核 | **可能留下核保记录**（含加费/除外/拒保） | 前两条走完仍需要更灵活结论时才走；宜多家同时申请，避免"一家拒了处处拒" |

**策略输出（按体况分档）**

- 干净体况 → 智能核保直过；
- 有明确异常（结节/息肉/指标异常） → 智能核保先试水 → 结论不理想再**多家预核保比结论** → 最后才考虑人工核保；
- 复杂体况（多病共存、住院史新近） → 直接走预核保（多家并行）→ 择优下单。

**30 天窗口提示**：预核保结论通常有有效期（常见为 30 天内正式投保按预核保结论承保，**以保司规则为准**），拿到结论后别拖过窗口期，到期要重新申请。

## 2. 核保五种结论（人话卡，每张带"下一步"）

| 结论 | 人话 | 下一步 |
|---|---|---|
| **标准体承保** | 按正常价格和全部责任买到了（最优） | 直接投保，记下核保结论与告知要点留存 |
| **加费承保** | 责任一样，钱多交一点 | 算一算多交的钱占预算多少，值不值；可对比别家结论 |
| **除外承保** | 其他都保，这一项（以及相关并发症）不保 | **这是最常见结论，不是坑，比拒保强得多**——先拿到保障，别因小失大；确认除外范围写在哪一条 |
| **延期承保** | 现在定不了，观察一段时间（如术后恢复期）再来申请 | 记下建议的时间点，到期再申请；期间保持复查与随访记录 |
| **拒保** | 这家不收 | 换路径：其他产品智能核保 / 多家预核保；同时看惠民保等替代出路（第 5 节） |

> 讲结论时的纪律：不做"这个结论好不好"的价值判断（不替客户决定），只讲**它意味着什么 + 下一步能做什么**。

## 3. 核保信息行业共享（提醒用）

保险行业有核保与理赔信息共享机制，**一家公司的拒保/理赔记录在别家也可能被查到**。所以：
- 被问到"是否被拒保/延期/加费过"必须如实答；
- 不要抱着"换家公司就查不到"的侥幸——瞒报的代价是理赔阶段的如实告知争议。

## 4. "两年不可抗辩"的真相（用户最容易被误导的一条）

**销售话术**："只要熬过两年，保险公司就必须赔。"
**真相（三层，逐层讲清）**：

1. **它管的是"合同解除权"**：保险合同成立满两年后，保险公司不得再以投保时未如实告知为由解除合同（《保险法》第十六条，通识表述，原文见 `law_citations.md`）。
2. **它不等于"带病投保两年后就一定赔"**：两年内出险不赔；涉及**故意不如实告知**的，司法实践中争议极大（是否构成欺诈、是否适用不可抗辩），**不能当免死金牌**。
3. **真实代价**：被查到不如实告知 → 拒赔 + 合同解除 + 退保只退现金价值（可能远少于已交保费），而**理赔纠纷中超六成与告知有关**（见方案第 3 节权威信号）。

**一句话讲给用户**：如实告知才是真正省事的买法——告知之后拿到的是"除外/加费"，不告知拿到的是"以后可能拒赔"，前者是确定成本，后者是不确定炸弹。

## 5. 被拒/买不了之后的出路

| 出路 | 说明 | 边界 |
|---|---|---|
| **惠民保（城市定制型商业医疗保险）** | 各地政府指导的普惠型医疗险，**不限既往病史、不限年龄、价格低**，是带病体与老人的兜底选择 | 它是"大病版社保"：免赔额高、报销比例有限；**健康体且已有百万医疗的，通常不必重复配置** |
| **防癌医疗险 / 防癌险** | 只保癌症相关，健康告知相对宽松，适合高龄或买不了医疗险的人 | 保障范围窄，是替代方案不是升级方案 |
| **意外险** | 大多不问病史（主要看职业与既往伤残），是带病体最容易拿到的保障 | 只保意外，不保疾病 |
| **社保 / 医保不断缴** | 地基始终要先保住 | — |

> 纪律：讲出路时只讲"有什么类型的选择"，**不推荐具体产品、不做优劣排名、不给价格**。

## 6. 陪审收尾时的路径建议模板（可直接用）

```
你这情况的建议走法：
1. 先在投保页面走智能核保（匿名、不留记录），把结论截图留存；
2. 结论不理想 → 同时向 2-3 家申请预核保，比一下结论（注意 30 天窗口）；
3. 都不理想 → 再考虑提交病历走人工核保；
4. 最终都买不了 → 惠民保 + 意外险兜底，医保千万别断。
（以上为路径与方法，不构成投保建议；以各家保险公司的规则与结论为准。）
```
