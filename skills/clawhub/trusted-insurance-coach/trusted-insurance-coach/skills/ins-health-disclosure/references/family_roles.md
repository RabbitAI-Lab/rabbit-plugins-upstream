# 家庭角色矩阵（给谁买，差异在哪）

> 用途：陪审时先问"给谁买"，再按角色调整题眼与叮嘱。顺序纪律不变：**先大人（经济支柱）后小孩老人**。

## 1. 角色速查表

| 角色 | 常见险种 | 告知与核保的差异点 | 特别叮嘱 |
|---|---|---|---|
| **本人 / 配偶（经济支柱）** | 百万医疗、重疾、意外、定寿 | 四类里告知最细；体检异常、住院史、用药史、职业都问 | 先把大人配齐，再谈孩子；缴费日与受益人写清楚 |
| **孩子** | 医疗（少儿百万医疗/小额医疗）、重疾（少儿）、意外 | 重点问**出生情况**：是否早产（孕周<37周）、低出生体重（<2.5kg）、新生儿住院、先天性疾病、发育情况、既往住院与手术 | **别把预算全花在孩子身上**（十大坑第 1 条）；出生证明上的孕周和体重必须查，不能凭记忆 |
| **老人（60+）** | 防癌医疗、意外、百万医疗（视年龄与健康） | 慢病（高血压、糖尿病）几乎必问；年龄越大可选项越少；65+ 百万医疗难投 | 讲清替代思路（防癌医疗 + 意外 + 惠民保），**不硬买保费与保额倒挂的重疾** |
| **孕妇** | 医疗（孕期多被限制）、孕产相关 | **孕周是必问项**（多少周、有无妊娠期糖尿病/高血压等并发症），通常需产后一段时间才可投保一般医疗/重疾 | 怀孕了要如实告知孕周，**"先买了再说"是坑**；产后按条款约定的时间再投保 |
| **全职/无固定收入成员** | 医疗、重疾、意外 | 定寿与收入相关的保额逻辑不同；职业问法按实际工作填 | 看护工作同样是有经济价值的，别忽略医疗与重疾 |

## 2. 人生阶段（影响优先级，不影响告知口径）

| 阶段 | 保障优先级（通用顺序，非标准答案） |
|---|---|
| 单身、无房贷 | 百万医疗 + 意外；有余力加一份重疾；定寿优先级低 |
| 二人世界 / 新婚 | 医疗 + 意外 + 重疾；开始考虑定寿（若一方为主要收入来源） |
| 有娃家庭（三口之家） | 先大人（经济支柱）：医疗 + 重疾 + 定寿 + 意外；再孩子（医疗 + 意外 + 少儿重疾） |
| 中产 / 有房贷 | 定寿保额覆盖负债（通用算法：5-10 倍年收入 + 负债，行业经验区间） |
| 中年 / 上有老 | 自己的医疗与重疾优先；老人走防癌医疗 + 意外 + 惠民保路径 |
| 临近退休 / 退休 | 医疗（含惠民保兜底）+ 意外；重疾此时性价比通常已不高 |

## 3. 陪审时可复用的两句提醒

- **顺序提醒**："先保赚钱的人。孩子出事有大人扛着，大人出事家里就断粮了。"（讲逻辑不讲恐吓。）
- **预算提醒**："孩子的保费不该比大人高——这通常是被带着走的错配。"（接专家包「买什么」的预算分配框架。）

## 4. 纪律

- 不给"这个角色该买多少保额"的绝对数字，只讲**通用算法与经验区间**（标注"行业通用经验区间，非标准答案"）；
- 不推荐产品、不比价；
- 孕妇与老人的医学相关问题，**不做医学判断**，一律引导就医 + 如实告知 + 核保。
