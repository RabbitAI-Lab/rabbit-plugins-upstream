# 医保卡外借专题（讲透，别让人稀里糊涂背上病史）

## 1. 一句话结论

**医保卡外借给别人看病买药，那些就诊和购药记录会记在你本人名下；投保时保险公司看到的是"你有这些病史"，轻则加费/除外，重则拒保，理赔时还可能被认定为未如实告知。**

## 2. 为什么这么严重（三层逻辑）

1. **记在你名下**：医保卡实名，别人拿你的卡挂号、看病、拿药，医院的就诊记录和医保消费记录都挂在你的身份证号下。
2. **核保只能按记录判断**：保险公司核保查到这些记录时，无法鉴别到底是不是你本人患病——站在它的角度，只能按"你有过这些病"来处理。
3. **后果分档**：轻 → 加费、除外相关疾病；重 → 拒保；已投保且未如实说明的 → 理赔阶段被质疑未如实告知，**大概率被认定为隐瞒**。

## 3. 法律层面（点到为止，不做法律结论）

- 医保卡外借属于**违规使用医保凭证**；涉及骗取医保基金的，依《社会保险法》相关规定处理（第八十八条涉及以欺诈、伪造证明材料等手段骗取社会保险待遇的退回与罚款），情节严重的可依《刑法》第二百六十六条（诈骗罪）相关立法解释追究刑事责任。
- **本 skill 不做法律定性**：只引用官方提示的定性方向，具体认定以监管部门与司法机关为准。

## 4. 已经外借过，怎么办（补救路径，按效果排序）

1. **投保时主动如实说明**：在告知环节或投保后的补充告知中说明"医保卡曾外借给家人，具体记录为……"，并**准备好自证材料**（被借用人自己的病历、购药凭证、关系证明、时间线说明）。
2. **自证的逻辑是"谁主张谁举证"**：你需要证明这些记录不是你的病。材料越全越好，但**要提前告诉用户：自证难度不小，成功的把握无法承诺**。
3. **走智能核保（线上答题、系统当场给结论）/ 预核保（正式投保前先试算结论，留痕但不留拒保记录）试探**：先匿名走智能核保看结论；需要时多家预核保，把"外借说明 + 自证材料"一并提交。
4. **别抱侥幸**：不说 = 埋雷；说了最坏是加费/除外，不说最坏是拒赔 + 合同解除。

> **红线**：绝不建议用户"先别说，等过了两年再说"——这正是两年不可抗辩误导的入口（见 `underwriting_paths.md` 第 4 节）。

## 5. 预防教育（最重要，放在陪审清单里）

- 医保卡**不外借**，包括父母、配偶、子女——很多人是给父母拿药才踩的坑；
- 家人需要用药，走**本人的医保或家庭共济**（各地医保家庭共济渠道，以当地医保局公布为准），不要把卡交出去；
- 已经借过的，**从现在起停止**，并把借用的时间、医院、药品尽量回忆记录下来（将来告知要用）；
- 陪审时把"医保卡是否外借"作为**投保前自查清单的固定一条**。

## 6. 陪审输出模板（可直接用）

```
关于"医保卡外借"这一项：
- 问卷问的是：你有没有把医保卡交给别人使用（挂号、看病、拿药都算）。
- 你要核对：国家医保服务平台 App 的医保消费记录，看看有没有不是你自己看病的记录。
- 如果有：在告知环节主动说明外借的时间、对象、大致病种，并准备自证材料（对方的病历/购药凭证/关系证明）。
- 千万别做：不说、或听销售说"没事都填否"——理赔查到就是未如实告知。
- 也别做：伪造材料去自证。
（如实说明最坏是加费或除外，不说明最坏是拒赔。以保险公司核保结论为准。）
```
