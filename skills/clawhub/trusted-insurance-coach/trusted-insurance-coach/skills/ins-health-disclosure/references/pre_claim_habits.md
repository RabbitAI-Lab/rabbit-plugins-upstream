# 买后三条叮嘱（陪审收尾固定附）

> 用途：陪审结束（告知通过/除外/加费）后，固定附这三条，把"买对"延伸到"用得上"。
> 纪律：只讲习惯与方法，不预测理赔结果、不承诺赔付。

## 叮嘱一：就医时别说错话（病历是理赔的第一证据）

- **跟医生讲症状和经过**，不猜病名、不自己下诊断；
- **不要说"我以前就有过""老毛病了""好几年前就这样"**——这类表述一旦写进病历，理赔时会被当作"投保前已存在"，是最难改的一类记录；
- 医生写的每一个字都可能进理赔审核，**发现病历写错了，及时请医生按规范更正**（更正有流程，越早越好）；
- 有商业保险不代表可以过度医疗——**按医嘱治疗**，不为了"用上保险"做不必要的项目。

## 叮嘱二：材料留好（理赔就是拼材料）

| 材料 | 说明 |
|---|---|
| 门诊/住院病历、出院小结 | 完整留存，可复印备份 |
| 诊断证明 | 通常需医院盖章 |
| 发票原件 + 费用清单 | 报销型医疗险的**核心凭证**，原件丢失补办很麻烦 |
| 检查/检验报告、病理报告 | 大病理赔的关键依据 |
| 身份证、银行卡、申请人身份证明 | 领款账户用 |
| 事故证明（意外） | 如交通事故认定书、警方证明等（视情形） |

- **报案有时限**：出险后应尽快联系保险公司报案，具体时限以合同约定为准（合同中通常写明"及时通知"），**别拖**；
- **医院等级与范围**：多数医疗险要求**二级及以上公立医院**（具体以条款为准，部分含特定私立/特需的要看条款），急诊等情形通常有放宽，以条款约定为准；
- **提交后记下受理号**，便于追踪进度与后续查询。

## 叮嘱三：告诉一个家人（别让保单躺在抽屉里）

- 把**保单在哪、保险公司报案电话、缴费日**告诉一位家人；
- 自己留一份"我的保险清单"（谁 / 什么险 / 保额 / 一年交多少 / 缴费日 / 报案电话 / 受益人）——**这是专家包「三张纸」里的第一张**；
- 忘交保费有宽限期（通常为 60 天，以条款为准），但**不要依赖宽限期**，建议设置缴费日提醒；
- 家庭结构、收入、负债变化了，每年过一遍保单（专家包的"年度保单检视"触点）。

## 收尾模板（可直接用）

```
买完以后就三件事：
1. 看病时讲症状、别猜病名，更别说"我以前就有"——病历写错最难改；
2. 病历、诊断证明、发票原件、费用清单都留好，出险第一时间报案（时限看你的合同条款）；
3. 把保单放在哪、报案电话多少，告诉一个家人，顺便设个缴费日提醒。
（以你的保险合同条款与保险公司要求为准。）
```

## 自动化提醒（收尾提示话术）

> "需要我在**缴费日 / 续保日 / 预核保 30 天窗口**之前提醒你吗？"（由用户决定是否创建，不代替用户决定。）
