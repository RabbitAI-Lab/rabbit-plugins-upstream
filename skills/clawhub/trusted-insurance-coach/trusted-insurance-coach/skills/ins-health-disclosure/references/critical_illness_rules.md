# 重疾新规速查（28 + 3）

## 1. 一张图讲清

- **重度疾病（重疾，确诊合同里列的病就直接给一笔钱）28 种 + 轻度疾病（轻症，病情轻一档、按比例给钱）3 种** 为行业统一定义，所有重疾险产品必须包含，定义与赔付条件统一（这是监管硬要求）。
- 这 28 种已覆盖国内重疾理赔的绝大多数（行业口径为 95% 以上），**看产品"病种够不够"，核心就是看它有没有这 28 + 3，而不是比谁列了 100 种还是 120 种**。

## 2. 必背的三条硬知识

| 条 | 内容 | 对用户意味着什么 |
|---|---|---|
| **① 分级赔付，不是剔除** | 恶性肿瘤、急性心肌梗死、脑中风后遗症三种，**按重度 / 轻度两级赔付** | 甲状腺癌（属恶性肿瘤）**没有被剔除，只是按分级赔**——轻度按轻症额度赔，重度按重疾额度赔 |
| **② 轻症赔付比例上限 30%** | 轻度疾病的保险金额，**不得高于重度疾病保险金额的 30%** | 看到"轻症赔 45%"之类超过 30% 的宣传，属于不合规，要警惕 |
| **③ 统一定义 28 + 3** | 2021 年 2 月起新单全部执行统一定义 | 老保单按老定义，新单比"病种数量"意义不大，比的是 28+3 之外的责任设计、赔付次数、保额与价格 |

## 3. 28 种重度疾病（行业统一定义，速查用）

> 由原规范 25 种扩展而来，新增的 3 种为：严重慢性呼吸衰竭、严重克罗恩病、严重溃疡性结肠炎。

| 类别 | 病种（通识名称） |
|---|---|
| 恶性肿瘤相关 | 恶性肿瘤——重度 |
| 心脑血管 | 较重急性心肌梗死、严重脑中风后遗症、冠状动脉搭桥术（或称冠状动脉旁路移植术）、心脏瓣膜手术、严重原发性肺动脉高压、主动脉手术、严重原发性心肌病、严重冠心病、严重心肌炎、Ⅲ度房室传导阻滞 |
| 神经与认知 | 严重阿尔茨海默病、严重帕金森病、严重运动神经元病、严重多发性硬化、严重脑损伤、深度昏迷、瘫痪、严重癫痫、严重重症肌无力、严重肌营养不良症 |
| 器官与代谢 | 重大器官移植术或造血干细胞移植术、终末期肾病（或称慢性肾功能衰竭尿毒症期）、急性或亚急性重症肝炎、慢性肝功能衰竭失代偿期、重型再生障碍性贫血、严重慢性肝衰竭、严重 1 型糖尿病 |
| 其他 | 多个肢体缺失、急性重症肝炎或亚急性重症肝炎、严重Ⅲ度烧伤、严重慢性呼吸衰竭（新增）、严重克罗恩病（新增）、严重溃疡性结肠炎（新增）、系统性红斑狼疮并发重度的肾功能损害、严重类风湿性关节炎、严重重症急性胰腺炎、植物人状态、双目失明、双耳失聪、语言能力丧失、侵蚀性葡萄胎（或称恶性葡萄胎） |

> **纪律**：上表为便于理解的通识速查，**病种名称与赔付条件以保险合同条款与中国保险行业协会规范原文为准**；陪审时不必背全表，讲清"看有没有 28+3"这条判断方法即可。

## 4. 3 种轻度疾病

- 恶性肿瘤——轻度
- 较轻急性心肌梗死
- 轻度脑中风后遗症

（赔付比例上限为重疾保额的 30%，超额宣传不合规。）

## 5. 陪审与答疑时的常用口径

- 用户问"我买的（或要买的）这个重疾病种够不够" → 答：**看它是否包含行业统一的 28 + 3**，其余病种是各家自行扩展，意义有限；具体以条款为准。
- 用户问"甲状腺癌到底赔不赔" → 答：**赔，但按分级**——属恶性肿瘤的按重度赔，属轻度的按轻症额度赔（上限为重疾保额的 30%）；不同时期的诊断与病理结果对应不同分级，以病理与条款定义为条件。
- 用户问"轻症赔多少合理" → 答：**监管上限是重疾保额（重疾那一档赔你的钱）的 30%**，超过这个比例的宣传不合规。
- **不做的**：不评价具体产品的好坏、不比价、不建议"买哪个"。

## 6. 与告知的关系（本 skill 的边界）

重疾险的告知问卷同样问病史与体检异常，但**本文件只用于解答"病种/定义/比例"类疑问**；涉及"我这个体况能不能买、要不要告知"，一律回到 `disclosure_questions.md` 与 `underwriting_paths.md`。
