# 医疗险续保陷阱速查（投诉重灾区）

## 1. 一句话版本

**"可续保"是话术，"保证续保"才是承诺——只认合同里白纸黑字的"保证续保"四个字和最长年限。**

## 2. 四个必须讲清的点

| # | 说法 | 真相 |
|---|---|---|
| 1 | "可续保至 99 岁" / "自动续保" / "承诺续保" | **都不等于保证续保**。它们通常附带"经我们审核同意""产品未停售"等条件，或者干脆只是宣传语 |
| 2 | "保证续保" | 真正的保证续保 = 条款白纸黑字写明 + **停售也不影响** + **理赔过照续** + **不因个人健康状况单独涨价**；目前市场上最长的保证续保期间为 **20 年**（以条款约定为准） |
| 3 | 主险保证续保 + 外购药械做成一年期附加险 | 这是**"假兜底"**：核心的外购药责任被放在一年期附加险里，附加险停售或不续，保证续保的主险就缺了最关键的一环（DRG 付费改革后，外购药恰恰是医疗险的核心竞争力） |
| 4 | 保证续保期满之后 | **期满后仍可能要重新核保**——这就是"保障悬崖"：20 年后你身体变差了、产品停售了，可能买不上新的 |

## 3. 陪审时怎么用（自查四问，模板可直接给）

```
买之前问自己/问销售这四句，答案要落在条款里：
1. 写的是"保证续保"还是"可续保"？——看条款原文四个字。
2. 保证续保多少年？到期之后怎么办（要重新核保吗）？
3. 外购药、特药、质子重离子这些责任，是不是也在保证续保范围内？（还是一年期附加险？）
4. 理赔过之后还能续吗？产品停售了还能续吗？会不会因为我一个人涨价？
（只讲方法与判断口径，不评价具体产品；以条款原文为准。）
```

## 4. 与告知的关系（本 skill 的边界）

- 医疗险的健康告知通常是四类险种里**最严格**的，所以"能不能续上"和"买的时候怎么告知"是两件事，但都很重要：告知阶段留下的隐患，理赔与续保阶段都会爆发。
- 用户问"我身体变差了还能续吗" → 属于续保问题，用本文件的四条口径解答；涉及"要不要加保/换产品" → 超出本 skill 范围（属专家包「买什么」能力），只提示路径不推荐产品。

## 5. 纪律

- 不评价具体产品的续保条款好坏、不排名、不比价；
- 不预测某产品会不会停售、会不会涨价（不做结果断言）；
- 涉及"保证续保 20 年"等具体年限，一律加"以条款约定为准"（不同产品、不同时期监管规定不同）。
