# Demo 03 · 医保卡外借（口述降级分支，合成案例）

## 用户画像（合成，非真实）

- 42 岁，身体一直很好，准备买重疾险；
- 两年前把医保卡给妈妈去社区医院开过几次降压药；
- 关键问题：**"我又没病，要不要说？说了会不会买不了？"**
- 附加情况：**病历和体检报告一时拿不到**（演示 `--mode oral` 降级分支）

## 用户输入

> 我前两年把医保卡给我妈去开降压药了，我自己血压正常。现在买重疾险，这事儿要不要说？说了是不是就买不了了？另外我体检报告一时找不到了。

## 陪审输出（示例）

### 先说结论（这条最不能含糊）

**要说。** 医保卡是实名的——别人拿你的卡看病拿药，那些记录全挂在你的名下。保险公司核保时看到的是"你有高血压就诊记录"，它没法鉴别到底是谁看的病，**大概率按你的病史处理**。

不说的最坏结果不是"买不了"，是**以后理赔被认定为未如实告知**。说了最坏是加费或除外。

### 外借这个坑，讲透三层

1. **记在你名下**：医院的就诊记录和医保消费记录都跟你的身份证绑定；
2. **核保只能按记录判断**：它无法鉴别是不是你本人患病；
3. **后果分档**：轻则加费/除外，重则拒保；已投保且未说明的，理赔阶段大概率被质疑。

### 你要做的三件事

1. **如实说明**：在告知环节写明"医保卡曾外借给家人，记录为降压药就诊"，并准备**自证材料**——妈妈的病历/购药凭证、关系证明、你们的时间线说明；
2. **自证逻辑是"谁主张谁举证"**：难度不小，但我不能因为难就让你别说。**也千万别伪造材料去自证**；
3. **走智能核保试水**：先匿名走一遍看结论；需要时把"外借说明 + 自证材料"一并提交预核保。

### 你的核对清单（口述降级版）

你一时拿不到体检报告，所以用不完整版清单——每项标 `【未核实】`，**口述不能替代材料**，正式投保前必须补齐核对。

```bash
python3 scripts/disclosure_checklist.py --insurance-type 重疾 --role 本人 \
  --findings "医保卡外借给妈妈买过降压药" --mode oral --output sample/output_03_card_lent.md
```

→ 见 `output_03_card_lent.md`（含补打病历的三条途径）

**补打材料的三条途径**：① 医院病案室复印（带身份证）；② 医院公众号/小程序的电子病历与报告；③ 区域电子健康档案 + 国家医保服务平台 App 查医保消费记录（用来回忆时间线）。

### 纪律（这题的红线）

- **不建议"先别说，熬两年再说"**——这正是"两年不可抗辩"误导的入口：两年不可抗辩限制的是合同解除权，**不是带病投保的免死金牌**；
- **不代填**：这一项怎么勾，只能你自己决定，我只讲后果和路径；
- **不预测结果**：会不会加费、会不会拒保，只有核保结论算数。

### 收尾：接续点 + 三条叮嘱

- **接续提示**：如果最终被拒或买不了，可以走惠民保 + 意外险兜底；涉及"理赔被拒怎么办"属于同伴能力「理赔怎么办」。
- **买后三条叮嘱**：① 看病讲症状不猜病名；② 病历、诊断证明、发票原件、费用清单留好；③ 告诉一个家人。
- **提醒**：需要我在补打材料的进度上定时提醒你吗？
