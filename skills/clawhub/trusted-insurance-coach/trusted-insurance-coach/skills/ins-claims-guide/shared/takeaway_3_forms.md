# 三张可带走的纸（模板）

> 专家包「最懂你的保险顾问」共享知识库（纯方法论，无时效风险）
> 使用规则：**每走完一段旅程，客户手里必须有带走物**。三张纸是"讲完留东西"这条铁律的落地件。
> 其中「纸四 · 缴费日历」由**保单体检**收尾时发放（保单盘完顺手把日子定好），其余三张按各 skill 的收尾规则发放。

## 纸一 · 我的保险清单（交给家人一份）

```
| 谁 | 什么险 | 保多少（保额） | 一年交多少 | 缴费日 | 报案电话 | 受益人（谁拿钱） |
| -- | ------ | -------------- | ---------- | ------ | -------- | ---------------- |
|    |        |                |            |        |          |                  |
```

**填写提示**：

- 「谁」要写清楚是投保人（交钱的）还是被保险人（被保障的）。
- 报案电话抄合同封面上的官方客服号，不要存销售的手机号。
- 受益人一栏写名字，不写"法定"两个字就完事——写"法定"意味着将来按遗产处理，手续更麻烦。

> 这张纸的最终用途：**交给一个家人，并存一份在手机备忘录里**。

## 纸二 · 投保前三问（下单前自己念一遍）

1. 我翻过近 2-5 年的体检报告和病历了吗？
2. 我准备告知的内容，和病历上写的一致吗？
3. 这笔保费占家庭年收入多少？（超过 15-20% 先降档）

> 讲法：三问念完有一问答不出来，就先别交钱，回去补那一问。

## 纸三 · 出险三步（贴在保单第一页）

1. **报案**：出事第一时间打官方客服报案，问清报案时限和要交什么材料，记下报案号。
2. **收材料**：病历、发票原件、费用清单、诊断证明、身份证与银行卡。
3. **提交并留痕**：提交后记下受理号；超期没动静，打 **12378**（金融监管总局保险消费投诉热线）反映。

**就医说法纪律**（写在纸三背面，最重要）：

> 跟医生讲**症状和经过**，不猜病名、不说"我以前就有"。病历写错最难改，改病历比改保单难十倍。

## 纸四 · 我的缴费日历（保单体检收尾时给）

> 保单盘完，顺手把每年什么时候交钱、交多少、从哪张卡扣，写在一张纸上——**忘交费 = 保单失效，理赔时最亏的就是这个**。

```
| 缴费日（月/日） | 谁的保单 | 什么险 | 一年交多少 | 扣款卡（最后4位） | 宽限期到什么时候 |
| -------------- | -------- | ------ | ---------- | ---------------- | ---------------- |
|                |          |        |            |                  |                  |
```

**填写提示**：

- 「缴费日」以**合同生效日**为准（保单第一页就有），不是销售告诉你的日子。
- 「宽限期」= 忘交费后保险公司还给你留的缓冲期，一般是 **60 天**，宽限期内出事照样赔；过了宽限期没交，保单就**失效**了（失效后 2 年内可以申请复效，但要重新核保）。拿不准哪年到期，打官方客服问。
- 交完一年，就在这行后面打个勾。**建议设手机日历每年提醒**，提醒提前 3 天。
- 扣款卡里**留够余额**——卡里没钱扣款失败，效果等于没交。

> 这张纸的最终用途：**贴在冰箱上或存手机备忘录，每年对照一次**。和「纸一 · 我的保险清单」放在一起。
