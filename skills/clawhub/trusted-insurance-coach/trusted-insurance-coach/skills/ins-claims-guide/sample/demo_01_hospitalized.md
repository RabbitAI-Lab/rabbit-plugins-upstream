# Demo 01 · 刚住院，还没报案（合成案例，A 情形）

## 用户画像（合成，非真实）

- 38 岁，买了百万医疗（第二年），因急性阑尾炎在三甲医院住院手术，明天出院；
- 没报过案，不知道要准备什么；
- 情绪：有点慌，担心"报不了"。

## 用户输入

> 我住院做个手术，明天出院，有百万医疗，这个怎么理赔？要准备什么？

## 陪审输出（示例）

### 先说结论

**别等出院后慢慢弄——今天就能报案，材料出院时一次收齐。** 理赔拼的就是材料，材料齐了流程通常很顺。

### 你现在做两件事（五步里的前两步）

**第一步：今天报案**

- 打保单上的报案电话（或在保司 App 上报案），说清：出险时间、医院、诊断、住院情况；
- 报案时问清四件事：**报案时限**多少、要哪些材料、就诊医院有没有等级要求、**报案号**是多少；
- 记下报案号——后面所有沟通都靠它。

**第二步：出院时把材料一次收齐**

```bash
python3 scripts/claim_checklist.py --insurance-type 百万医疗 --event 住院 \
  --hospital "三甲医院" --output sample/output_01_hospitalized.md
```

→ 见 `output_01_hospitalized.md`

最容易漏的三样：**发票原件、费用总清单、医保结算单**——只有发票没有清单通常不行。

### 后面三步（先知道，别急着做）

- **第三步 提交**：记下受理号与提交日期，邮寄用可查询的快递并留底单；
- **第四步 配合审核**：让补材料就在期限内补，留好回执，**材料必须真实**；
- **第五步 拿结论**：**结论要书面的**，口头答复不作数。

### 三条纪律（收尾固定附）

1. **发票原件**是报销型的命根子，丢了补办极麻烦，出院结账时就收齐；
2. **先拍照留底**：所有材料提交前拍一套完整照片，寄出去就回不来了；
3. **结论要书面**：任何结论都要落到书面，拒赔必须写明理由与引用条款。

### 接续与提醒

- **接续提示**：如果最后拿到的是拒赔结论，下一步走"书面通知书 → 证据保全 → 条款自查 → 复核 → 12378 → 调解"这条阶梯（见 `demo_02_rejected.md`）。
- **提醒**：需要我在补正材料的期限、缴费日/续保日之前提醒你吗？
