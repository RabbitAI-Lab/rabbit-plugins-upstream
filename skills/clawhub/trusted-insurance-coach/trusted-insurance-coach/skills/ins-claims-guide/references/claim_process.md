# 理赔五步流程（出险后先干什么）

## 1. 五步速览

| 步 | 动作 | 关键纪律 |
|---|---|---|
| 1 | **报案** | 出险后尽快联系保险公司（保单/官微/App 上有报案电话），问清**报案时限**与材料要求，记下**报案号** |
| 2 | **收材料** | 按材料清单逐项收（见 `claim_materials.md`），所有材料先拍照留底 |
| 3 | **提交** | 记下**受理号**与提交时间；邮寄用可查询的快递并留底单 |
| 4 | **配合审核** | 补材料要书面留痕；如实配合核实，**不伪造、不凑材料** |
| 5 | **拿结论** | 赔付 / 部分赔付 / 拒赔，**结论要书面的**；有争议进 `rejection_paths.md` |

## 2. 报案（最容易拖的一步）

- **时限以合同约定为准**：多数条款写"及时通知"，部分产品写明具体天数（如出险后 10 日内）。**不要等出院、不要等康复、不要等家人商量好**——先报案，材料后补。
- 报案时问清四件事：① 报案时限与受理渠道；② 需要哪些材料（有没有指定格式）；③ 就诊医院有没有等级要求（多数要求二级及以上公立，以条款为准）；④ 报案号是多少。
- **先报案 ≠ 放弃什么**：报案只是通知，材料齐了再正式申请。

## 3. 提交与审核

| 环节 | 注意事项 |
|---|---|
| 提交渠道 | App 上传 / 网点递交 / 邮寄均可，优先选可留痕、可查询的方式 |
| 受理号 | 记下受理号与提交日期，后续追踪全靠它 |
| 补正材料 | 收到补正通知要**在要求期限内补**，并保留补交通知与回执 |
| 审核与调查 | 大额或存疑案件可能有面访、调查；如实配合，**材料必须真实** |
| 结论 | 要求出具**书面结论**（拒赔必须写明理由与引用条款） |

## 4. 时效口径（讲口径，不做断言）

- 保险金请求权受**诉讼时效**限制：人寿保险与其他保险的期间不同（人寿保险的期间更长），**自知道或应当知道保险事故发生之日起计算**；具体期间以《保险法》规定与官方文本为准（见 `law_citations.md`）。
- **别卡时效**：材料早收早完整，拖久了证人难找、病历难补、发票难重开。

## 5. 三条最常犯的错

1. **先吵后收材料**——没有书面拒赔通知和完整材料，吵了也推不动；
2. **发票原件丢失**——报销型医疗险的核心凭证，补办极麻烦，出院时就要收齐；
3. **病历说法出错**——跟医生讲症状和经过，不猜病名、不说"我以前就有过"（见 S1 `pre_claim_habits.md`）。

## 6. 收尾模板（可直接用）

```
出险后按这个顺序走：
1. 先报案（保单上有电话），记下报案号，顺便问清材料清单和时限；
2. 出院时把病历、诊断证明、发票原件、费用清单、检查报告一次收齐，全部拍照留底；
3. 提交时记受理号，邮寄用可查询的快递；
4. 让补材料就在期限内补，留好回执；
5. 结论要书面的——口头答复不作数。
（报案时限与审核时限以你的保险合同条款约定为准。）
```
