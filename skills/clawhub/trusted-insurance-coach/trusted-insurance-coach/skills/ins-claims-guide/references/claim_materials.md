# 理赔材料矩阵（险种 × 事故类型）

> 用途：客户说"我要理赔"时，按险种与事故类型给逐项勾的清单。
> 纪律：这是**通用清单**，最终以保险公司给的材料清单为准；不代写申请书，可讲格式与要点。

## 1. 通用必备（任何理赔都要）

| 材料 | 要点 |
|---|---|
| 理赔申请书 | 按保司格式填写，**本人签字**；不代写内容，可讲填写要点 |
| 申请人身份证明 | 被保险人（被保障的人）/ 受益人（拿赔款的人）身份证 |
| 银行卡（领款账户） | 开户行、户名与账号，户名须与领款人一致 |
| 保单信息 | 保单号（脱敏说明：只需确认合同，不用在这里贴完整号） |

## 2. 按事故类型

| 事故类型 | 追加材料 | 常见漏项 |
|---|---|---|
| **住院医疗** | 住院病历、出院小结、诊断证明（盖章）、**发票原件 + 费用总清单**、医保结算单、检查/检验报告 | 费用总清单（只有发票不行）、医保结算单（医保报销过的要提供） |
| **门诊医疗** | 门诊病历、发票原件 + 费用明细、检查报告、诊断证明 | 每次就诊的病历都要，不能只交最后一次 |
| **重大疾病** | **病理报告/确诊材料**、影像与检验报告、出院小结、诊断证明（盖章）、手术记录（如有） | 病理报告（肿瘤类必须有）、诊断证明要盖章 |
| **身故** | 死亡医学证明、户籍注销证明、丧葬证明（视要求）、受益人身份证明与**关系证明**、事故证明（若涉意外） | 关系证明（户口本/公证书等，按保司要求） |
| **伤残** | **伤残鉴定报告**（按条款约定的鉴定标准与机构）、事故证明、完整就诊材料 | 鉴定机构要符合条款约定，别随便找一家 |
| **意外医疗** | 事故说明（时间地点经过）、门诊/住院材料、发票原件、事故证明（交通事故需认定书） | 事故经过说明（要写清外来的、突发的、非本意的、非疾病的） |

## 3. 按险种的差异提示

| 险种 | 提示 |
|---|---|
| 百万医疗 | **报销型**：发票原件 + 费用清单 + 医保结算单是核心；注意免赔额（保险公司不赔、你自己先出的部分）与报销比例 |
| 小额医疗/门诊险 | 单次限额与免赔额通常较低，看条款 |
| 重疾险（重大疾病险） | **给付型（符合条件直接给一笔钱）**：确诊即申请，看条款约定的确诊标准（部分病种需达到约定状态或实施约定手术） |
| 意外险 | 意外医疗走报销，身故/伤残走给付；伤残按条款约定的伤残评定标准 |
| 定期寿险 | 身故/全残给付；注意责任免除条款（如两年内自杀等，以条款为准） |

## 4. 材料纪律（四条，每次都讲）

1. **发票原件**：报销型理赔的核心凭证，丢了补办极麻烦——出院结账时就要收齐；
2. **盖章**：诊断证明、部分报告通常要求医院盖章，交之前检查一遍；
3. **先拍照留底**：所有材料提交前拍一套完整照片/扫描件，寄出去就回不来了；
4. **不伪造、不凑材料**：任何"补一张""这样写就能赔"的说法都是坑，涉及保险诈骗风险。

## 5. 脚本用法

```bash
python3 scripts/claim_checklist.py --insurance-type 百万医疗 --event 住院 --output claim_materials.md
python3 scripts/claim_checklist.py --insurance-type 重疾 --event 确诊重大疾病 --mode oral
```

`--mode oral` = 材料暂时不齐时的**降级分支**：输出"不完整版清单"，逐项标 `【待补】`，并给出补材料的三条途径（医院病案室复印 / 医院公众号电子病历与报告 / 医保消费记录核对时间线）。
