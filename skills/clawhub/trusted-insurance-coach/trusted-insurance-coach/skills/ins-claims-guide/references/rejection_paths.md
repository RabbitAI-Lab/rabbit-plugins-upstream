# 被拒赔之后的五步阶梯

> **核心原则**：不吵、不拖、不签不明不白的文件。**先拿到书面结论 + 保住证据**，事情才推得动。
> 纪律：只讲路径与方法，不预测结果、不定性"耍赖"、不承诺追回。

## 第一步：拿到"盖章的书面拒赔通知书"

- **必须包含**：拒赔理由 + 引用的条款依据；口头答复、App 上的一句话状态都**不算**。
- 拿不到怎么办：书面致电/致函保司要求出具，并保留申请记录；客服电话要记时间、工号、答复内容。
- **为什么这一步最关键**：后面每一步（复核、投诉、调解、诉讼）都要以这份通知书为起点。

## 第二步：保全证据，两件事别做

| 要做 | 千万别做 |
|---|---|
| 保单与缴费记录；病历、发票、费用清单、检查报告；提交材料的回执与快递底单；与保司的沟通记录（时间、工号、内容） | **不签和解文件**（没看明白就签，等于放弃后续权利） |
| 报案号、受理号、补正通知 | **不轻易退保**（退保会让你失去争议标的，钱也拿不回来多少） |

## 第三步：对照条款自查 → 书面申请理赔复核

- 自查用什么：拒赔通知书引用的**条款原文** + 你的材料（见 `dispute_reasons.md` 的常见拒赔原因自查表）；
- 自查三问：① 我出的事在不在"保什么"里？② 它引的"不保"条款，投保时有没有被明确提示和说明（免除责任的条款需要提示与说明，见 `law_citations.md`）？③ 我的材料齐不齐、是不是漏了关键件？
- 向保司**书面**提交理赔复核申请（写清异议点 + 依据 + 诉求），保留提交凭证。

## 第四步：12378 与行业调解

- **12378**：国家金融监督管理总局消费者投诉热线。一般时限口径：**收到投诉后 15 日内告知是否受理**，**自受理之日起 60 日内作出处理决定**（可依法延长，以官方口径为准）。
- **行业调解**：保险纠纷调解渠道，通常**免费**，比诉讼成本低、速度快；可在投诉过程中或之后提出。
- 投诉材料怎么写：事实经过（时间线）+ 争议焦点 + 你的诉求 + 证据清单，**讲事实不喊情绪**（情绪化指控会削弱可信度）。

## 第五步：仲裁或诉讼

- **仲裁**：看合同里有没有仲裁条款（有则从约定）；
- **诉讼**：注意管辖法院与诉讼时效（见 `law_citations.md`，以法律规定与官方文本为准）；
- **专业帮助**：复杂争议建议咨询专业律师或申请法律援助——**本 skill 不出具法律意见**。

## 红线（每一步都要带）

- 不预测"能不能告赢"、不给胜率；
- 不定性"保险公司耍赖"、不写情绪化指控；
- 不承诺"能追回多少钱"；
- **不推荐"代理退保/代理维权"中介**（高风险，常涉信息泄露与二次收费，另见 scam-radar 十问）；
- 不代替律师出具法律意见。

## 收尾模板（可直接用）

```
被拒赔了，按这个顺序走：
1. 先要一份盖章的书面拒赔通知书（写明理由和引用条款），口头的不算；
2. 保单、缴费记录、病历票据、受理号、沟通记录全部留底；别签和解文件，别退保；
3. 拿着通知书对照条款自查三条：保不保、免责条款有没有被提示说明、材料齐不齐；
4. 自查后书面向保险公司申请理赔复核；
5. 复核无果 → 打 12378（15 日内告知是否受理，60 日内出处理决定）→ 行业调解（免费）→ 仍不决再考虑仲裁或诉讼。
（以上为路径与方法，不构成法律意见；以保险合同条款与监管规定为准。）
```
