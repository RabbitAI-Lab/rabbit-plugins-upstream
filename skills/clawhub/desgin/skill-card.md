## Description:

Use when designing, redesigning, or improving a frontend interface in Angular, React, or Blazor. Use for landing pages, dashboards, components, forms, and responsive layouts that must work mobile-first and then scale to desktop.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and product teams use this skill to shape, critique, and improve frontend interfaces with mobile-first layouts, accessible interaction states, responsive breakpoints, and framework-aware conventions for Angular, React, or Blazor.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill provides opinionated frontend design guidance that may not match a product's brand, locale, accessibility requirements, or team conventions.

Mitigation: Review proposed copy, typography, motion, colors, and approval workflow against the product context before implementation.

Risk: Frontend design recommendations can still produce unsuitable layouts if they are not checked across responsive sizes and accessibility states.

Mitigation: Validate mobile and desktop behavior, WCAG AA contrast, keyboard focus, reduced-motion behavior, and readable typography before release.
