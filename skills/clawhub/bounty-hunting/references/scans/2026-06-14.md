## Key Learnings

1. `gh search prs` does NOT have a `--keyword` flag — use positional query: `gh search prs "keyword" --repo ...`
2. `gh api repos/X/Y --jq '.language'` works directly (raw API field), while `gh repo view --json language` fails (needs `primaryLanguage`)
3. `execute_code` is blocked in cron mode — must use terminal commands directly
4. `gh` was already authenticated via keyring — no need to extract token from git-credentials
5. Engram is a new bounty farm pattern: no USD labels, open-ended tasks, massive bot competition
