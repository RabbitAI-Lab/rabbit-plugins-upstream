## Authentication Note
- `GH_TOKEN` from ~/.git-credentials conflicts with keyring auth
- Use `unset GH_TOKEN && gh auth status` — keyring auth works fine
- For cron jobs: `unset GH_TOKEN` before any `gh` commands
