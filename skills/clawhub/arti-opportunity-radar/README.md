# ChanceRadar

ARTi 机会雷达：把分散的市场新闻整理成可验证的持仓提醒、关注股动态和新机会线索，并为每只相关股票生成独立的 ARTi 深度分析入口。

## 一句话安装

```bash
npx -y skills add illli/ChanceRadar -g --all
```

安装后可以直接说：

> 帮我配置机会雷达：我持有腾讯，关注英伟达和台积电，关心 AI 基础设施和半导体，信息源使用 Readhub、AI HOT、Poche 和官方公告。

Skill 会先回显规范化后的股票、市场和信息源；取得确认后，才在当前项目中保存本地画像。

## 主要能力

- 根据持仓、关注股票和板块生成个性化早报、晚报与突发新闻提醒。
- 从 Readhub、AI HOT、Poche、Hacker News、GDELT 等来源发现线索。
- 使用交易所公告、监管披露、公司投资者关系页面和官方统计核验事实。
- 区分已确认事实、合理推测和待验证信息。
- 将单条新闻映射到多只相关股票，并为每只股票生成“用 ARTi 分析”入口。
- 对台积电、阿里巴巴等跨市场证券先确认上市地，避免代码映射错误。
- 检测腾讯自选股连接器；只有连接器可用且用户授权后才读取。

## 隐私边界

- 默认不收集持仓数量、成本价、仓位比例、账户资产或券商凭证。
- 用户画像保存在当前项目的 `.arti-opportunity-radar/profile.json`，不会写入 Skill 目录。
- 不会未经允许安装连接器、登录第三方账户或读取腾讯自选股。
- 新闻分析仅供研究，不构成投资建议。

## 更新

重新运行安装命令，即可从本仓库获取最新版本：

```bash
npx -y skills add illli/ChanceRadar -g --all
```
