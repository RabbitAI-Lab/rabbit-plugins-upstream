## Description:

Generate 3D models with EmpirioLabs AI from an image or, on supported models, a text description, then retrieve the completed model file.

This skill is ready for commercial/non-commercial use.

## Publisher:

[empiriolabs](https://clawhub.ai/user/empiriolabs)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and creators use this skill to turn object images or supported text prompts into 3D assets, and to resume and download long-running generation jobs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: ClawScan reports that an API key could be exposed if a request redirects to another host.

Mitigation: Address the redirect risk before installation; if proceeding, protect the API key and avoid sending sensitive images until their handling is clear.
