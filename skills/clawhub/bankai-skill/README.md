# 银行AI写作助手 (BankAI)

**3 分钟出一份"银行味"公文底稿，复制就能交。**

基于 DeepSeek，覆盖监管回复、分析研判、规章制度、行政公文、汇报总结、自定义共 **59 种**银行公文模板。一句话需求，即生成符合《党政机关公文格式》(GB/T 9704-2012) 的纯文本底稿。

---

## 为什么是它

- **59 种银行公文，开箱即用**：从通知、请示、报告，到信贷尽职调查、风险提示、监管整改回复、授信审批纪要一应俱全。模板源自线上已验证的银行写作知识库，术语、抬头、分章、落款都到位。
- **真·银行味**：提示词沉淀了银行场景的专用口径与公文格式规范，不是通用 AI 写手的流水账。
- **不编造，敢交付**：内置"反编造护栏"——你没给的数据一律 `XX` 占位并附"需人工核实"清单，**绝不凭空生成看似精确的虚假数字**（银行场景的致命雷区：一份编造的资产负债率比没有底稿更危险）。
- **纯文本输出**：禁止 Markdown，中文全角标点，直接进 Word / OA 不改格式。
- **成本极低**：基于 DeepSeek，一篇报告几分钱；支持 `BASE_URL` 私有化，推理留在你自己的环境，数据不出行。

## 安装与使用

1. **安装**：ClawHub 一键安装，或把本目录解压到你的 `skills/bankai/`。
2. **配置 Key**：设置环境变量 `DEEPSEEK_API_KEY`（从 [DeepSeek 开放平台](https://platform.deepseek.com) 获取）。
3. **触发**：
   - 对话里说："用 BankAI 帮我写一份关于 XX 支行不良率上升的情况说明"
   - 或命令行直跑：
     ```bash
     node scripts/bankai_write.mjs --type situation-report --input @fields.json
     ```
   `fields.json` 为该类型的必填字段（用 `--list` 查看全部类型与字段）。
4. **交付**：拿到纯文本底稿 → 人工核对 `XX` 占位项 → 提交。
