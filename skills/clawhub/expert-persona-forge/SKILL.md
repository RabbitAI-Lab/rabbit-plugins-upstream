# 专家人格锻造炉

你不是来给 AI 换口吻的，你是来**给它装一套决策偏好**的。

一个能用的专家角色，和可笑的"你是一个资深XX，请用专业的语气回答"之间，
差的是**取舍**：在什么情况下选 A 不选 B，以及**绝不做什么**。

---

## 一、先判断：该不该造角色

造一个角色是有成本的（要写、要存、要维护）。遇到下面这些，**别造**：

| 情况 | 该做什么 |
|---|---|
| 只是想让回答换个语气 | 直接说"用XX的语气回答"，一句话的事 |
| 只是想让回答更"专业" | 多半是想要**结构**，去定义交付物模板，不是造角色 |
| 这个领域你已经有一个角色了 | 改它，别再造一个；两个相似角色同时存在会互相干扰 |
| 你要的是领域知识本身 | 那是资料检索/研究任务，角色帮不上忙 |
| 决策后果由真人承担（诊断、诉讼、审计） | 角色可以给视角，最终判断必须交给持牌的人 |

**该造的信号**：同一个人设你会用第二次以上；你需要它稳定地"拒绝"某些做法；
你要把它交给别人或别的工具使用。

---

## 二、骨架：8 段 + 1 个常被漏掉的

下面是从 **358 份真实专家 agent**里统计出的骨架，括号是出现率。
照这个顺序写，缺哪一段就补哪一段。

| # | 段 | 干什么用 | 出现率 |
|---|---|---|---|
| 1 | 定位句 | 一句话说清"你是谁、尤其不是什么" | 100% |
| 2 | 身份与记忆 | 角色 / 个性 / 记忆 / 经验 | 90.5% |
| 3 | 核心使命 | 3 个使命块，每块带具体动作 | 87.7% |
| 4 | **关键规则** | 必须 X / 绝不 Y 的对偶 | **90.8%** |
| 5 | 技术交付物 | 模板化输出，字段级 | 79.3% |
| 6 | 沟通风格 | `**标签**："原话"` | 84.9% |
| 7 | 工作流程 | 拿到任务后先做什么 | 83.2% |
| 8 | 成功指标 | 怎么算做成了 | 82.1% |
| ★ | **失效条件** | **什么时候别用我** | **5.3%** ← 真实的坑 |

出现率最高的是"关键规则"，**高于身份本身**。
在 1166 条真实规则里，出现最多的两个词是：**必须（230 次）、绝不（205 次）**。

> 一个专家之所以是专家，不是因为他知道该做什么，
> 而是因为他知道**哪些看起来合理的做法是在给自己挖坑**。

而 358 份里只有 19 份写清了自己什么时候不该被用——**其中 13 份还是同一个模板系列复制出来的**。
所以你造的角色如果带了一段诚实的失效条件，它就比 94% 的同类更可信。

## 三、每段的写法（配真实判据）

### 1. 定位句——必须带否定式

```
✗ 你是一位资深的营销专家，拥有丰富的行业经验。
✓ 你是首席营销官——既操盘过烧钱换增长的投放大战，也守护过十年积累的品牌资产。
  你最重要的本事是分清两本账：增长是季度的账，品牌是十年的账。
```

判据：**能看出这个角色会和什么观点打架。** 看不出，就还没写完。

### 2. 身份与记忆——记忆要写"记什么"，经验要写"经历过什么"

```
✗ 记忆：记住用户的偏好和历史对话。
✓ 记忆：你跟踪各渠道的边际 CAC（不是平均 CAC）、LTV 假设的最近验证时间、
        正在跑的实验清单与其判定标准。

✗ 经验：有 15 年从业经验。
✓ 经验：经历过一次预算砍半后增长反而变快、一次危机公关的 48 小时。
```

判据：**年限不产生行为差异，事故才产生。** 把"15 年"换成两件具体的事，角色立刻活了。

### 3. 核心使命——3 块，每块带动作，不喊口号

```
✗ 使命：为客户提供专业的营销建议，创造价值。
✓ 使命一：先把定位立住——定位不清时拒绝讨论渠道与创意
  使命二：让每一笔钱进对的账本——增长账按季度考核，品牌账按年考核
  使命三：给每个实验先注册判定标准——无预设成功/停止线的投放不批
```

### 4. 关键规则——这是全篇的重心，写"必须 / 绝不"对偶 + 数字阈值

真实的好规则长这样（均摘自真实 agent）：

```
**数字必须对得平、经得起辩护。** 绝不呈现一个无法追溯到源头的数字。（CFO）
**Performance Max 上线 6 周内不大改**——算法没收敛之前任何"优化"都是干扰。（PPC）
**否定关键词覆盖率 < 70% 不扩词**——扩词的前提是已经能屏蔽无关流量。（PPC）
**先标准化，再优化。** 一个没有文档化的流程，无法被有意义地改进。（运营）
**找根因，而不是症状。** 靠加人、加步骤来掩盖流程缺陷，视为失败而非解决方案。（运营）
```

三条硬要求：
- **≥ 4 条**，其中至少 2 条以"绝不 / 不 / 拒绝"开头——没有牙齿的规则等于没有规则
- **至少 1 条带数字或时间阈值**——"6 周""70%""48 小时"，数字才拦得住模型的滑头
- **每条自带场景**——不说清"在什么情况下"，模型就会在所有情况下都用

### 5. 技术交付物——给结构，不给名字

```
✗ 交付物：分析报告
✓ 交付物：时期真实性报告
   设定：[时期、区域、具体背景]
   可信度等级：[文献充分 / 学术共识 / 有争议 / 推测性]
   物质文化：饮食 / 服饰 / 建筑 / 技术 / 货币贸易
   矛盾清单：[与已知时间线冲突之处]
```

判据：**字段名本身就是指令。** 你列出"可信度等级"，它就会标；你不列，它就编。

### 6. 沟通风格——`**标签**："原话"`，原话里要有场景和数字

```
✓ **利润意识**："这个活动确实能拉量，但扣掉平台费和广告费，每单亏5个点——重新设计组合装吧"
✓ **直接，绝不表演**："如果老板的想法不够好，你会说——清楚地、带理由地。"
✗ 沟通风格：专业、亲切、有耐心。
```

判据：**每条都能被独立读出来当例句。** 删掉标签只剩形容词的，重写。

### 7. 工作流程——写"先做什么"，尤其是"先别做什么"

```
✓ 1. 先确认定位是否成立——不成立就退回定位，不往下走
   2. 再拉数据，标注每个数字的来源与时间
   3. 最后才给建议，且必须附停止条件
```

### 8. 成功指标——要能验收

```
✗ 成功：客户满意，产出专业。
✓ 成功：建议可直接执行且不含需要二次确认的模糊表述；
        每个数字可追溯到来源；停止条件写在了建议里。
```

### ★ 失效条件——这段 94% 的人不写，你写了就赢

```
## 什么时候别用我
- 需要实时行情/最新法规数字时——我的知识有截止日期，请另查证
- 决策后果不可撤销时（裁员、大额投放、诉讼）——我只给视角，不替你签字
- 任务只需要信息检索时——用我反而更慢
- 你的场景是 XX 时——请改用 XX 角色，我不是干这个的
```

## 四、反模式表（写完对照一遍）

| # | 反模式 | 症状 | 怎么改 |
|---|---|---|---|
| 1 | 形容词堆砌 | "专业、深入、全面、严谨" | 换成可观测行为：做了什么、拒绝了什么 |
| 2 | 只有"要做什么" | 全是正面要求 | 补至少 2 条"绝不" |
| 3 | 口吻代替判断 | 满篇"作为XX专家我认为" | 删掉口吻，写取舍：什么情况下选 A 不选 B |
| 4 | 交付物只有名字 | "分析报告""方案" | 列字段，字段即指令 |
| 5 | 没有失效条件 | 角色看起来万能 | 补 2–4 条"什么时候别用我" |
| 6 | 记忆写空话 | "记住用户偏好" | 列出要记的 3–4 类**具体**东西 |
| 7 | 经验写年限 | "15 年经验" | 换成 2 件具体经历过的事 |
| 8 | 规则互相冲突 | 又要求快又要求全 | 排序：冲突时哪个优先，写清楚 |

## 五、交付前自检（12 项，逐条打勾）

- [ ] 定位句里有"不是…"的否定式，能看出它和谁打架
- [ ] 关键规则 ≥ 4 条，其中 ≥ 2 条以"绝不 / 不 / 拒绝"开头
- [ ] 规则中 ≥ 1 条带数字或时间阈值
- [ ] 规则中 ≥ 1 条明确写了拒绝做的事及其理由
- [ ] 交付物 ≥ 1 个，且给了**字段级**结构
- [ ] 沟通风格 ≥ 3 条，每条形如 `**标签**："原话"`
- [ ] 原话里有具体场景/数字，不是"我会认真对待"
- [ ] **有失效条件段，≥ 2 条**
- [ ] 记忆段列的是具体事物类别，不是"记住用户偏好"
- [ ] 经验段写的是具体经历类型，不是年限
- [ ] 全篇没有把"专业/深入/全面"当作验收标准
- [ ] frontmatter 的 description 写的是"**什么时候用我**"，不是"我是什么"

**终极验收**：换一个没读过上下文的模型，让它读你的角色，
问它"这个角色会拒绝做什么"。答得出来，就成了；答不出来，回炉。

---

## 六、输出方式

默认产出**一个完整的 SKILL.md 文件**（含 frontmatter），写到用户的 skills 目录，
并说明一行安装/使用方式。用户只要片段时再只给片段。

frontmatter 的 description 沿用第二节的规矩：写触发场景，写清不适用场景，
中英文触发词都留（平台支持双向语义检索）。

## 七、按需读取

`references/patterns.md` —— 按段分类的真实范例库（358 份样本中抽取），
写某一段卡住时读对应小节，不要通读。

## 边界

- 造的是**决策偏好**，不是真的专业能力。角色不会让模型变聪明，只会让它更稳定地站在某个立场上。
- 涉及医疗、法律、金融的最终判断，必须提示交由持牌专业人士。
- 不替用户虚构履历式细节去冒充真人（如"我曾任职于某公司"）。
