## Description:

This skill helps merchants, review accounts, and small teams create faceless commerce video plans, scripts, prompts, AI-HIVE generation commands, task records, and acceptance checklists from authorized product materials and verified claims.

This skill is ready for commercial/non-commercial use.

## Use Case:

External commerce creators, small merchants, product-review accounts, and marketing teams use this skill to turn faceless product-video requests into reviewable production briefs, shot scripts, prompts, runnable AI-HIVE commands, task tracking, and final quality checks.

## Known Risks and Mitigations:

Risk: AI-HIVE generation tasks can incur costs.

Mitigation: Review prompts, model choice, routing mode, and pricing snapshot before submitting generation tasks; start with a small sample before batch work.

Risk: The skill uploads user-selected media to AI-HIVE for generation workflows.

Mitigation: Upload only media the user has rights to use, and avoid submitting sensitive, private, trademarked, or copyrighted material without authorization.

Risk: An API key may be stored locally in ~/.ai-hive/config.json.

Mitigation: Prefer the AI_HIVE_API_KEY environment variable when possible; if using the config file, keep permissions restricted and do not commit, log, or screenshot the key.

Risk: Generated commerce content can make misleading claims or imply unauthorized testimonials or endorsements.

Mitigation: Keep product claims grounded in verified facts, mark uncertain claims for review, and reject requests to fabricate user testimony, rankings, platform approval, or guaranteed sales outcomes.
