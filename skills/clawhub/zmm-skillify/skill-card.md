## Description:

Turns a completed, verified workflow from the current session into a reusable local agent skill, with gates that prevent unverified ideas or one-off work from becoming persistent instructions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[iamzifei](https://clawhub.ai/user/iamzifei)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent users use this skill after a workflow has produced a verified result to capture the repeatable method as a local skill. It is intended for reusable skill creation from proven practice, not for inventing skills from ideas alone.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can create or update reusable skill instructions that may influence future agent behavior.

Mitigation: Invoke it deliberately and review any generated or modified skill before relying on it.
