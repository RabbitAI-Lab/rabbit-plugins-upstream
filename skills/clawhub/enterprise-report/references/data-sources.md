# 企业报告数据采集清单

本文档列出各板块应采集的数据及对应来源，供生成报告时逐项核对。

## 数据来源标识

| 标识 | 全称 | URL |
|------|------|-----|
| QCC | 企查查 | qcc.com |
| AQC | 爱企查 | aiqicha.baidu.com |
| TYC | 天眼查 | tianyancha.com |
| QXB | 启信宝 | qixin.com |
| NACIP | 国家企业信用信息公示系统 | gsxt.gov.cn |
| WS | 中国裁判文书网 | wenshu.court.gov.cn |

## 基础信息采集清单

### 工商登记信息
- [ ] 企业名称（含曾用名及变更时间）
- [ ] 统一社会信用代码
- [ ] 法定代表人
- [ ] 注册资本（区分认缴/实缴）
- [ ] 成立日期
- [ ] 经营状态（存续/注销/吊销）
- [ ] 企业类型
- [ ] 所属行业
- [ ] 注册地址
- [ ] 登记机关
- [ ] 营业期限
- [ ] 参保人数（最新年报）
- [ ] 纳税人资质（一般纳税人/小规模）
- [ ] 纳税信用等级及年度
- [ ] 是否小微企业

### 经营范围
- [ ] 许可项目
- [ ] 一般项目
- [ ] 经营范围变更次数

### 股东及股权结构
- [ ] 股东名称（法人/自然人）
- [ ] 持股比例
- [ ] 认缴出资额
- [ ] 实缴出资额
- [ ] 母公司基本信息（注册资本/法定代表人/注册地址/成立日期/经营范围/自身风险数）
- [ ] 母公司失信/限高记录

### 实际控制人
- [ ] 姓名
- [ ] 担任法定代表人数量
- [ ] 担任股东数量
- [ ] 担任高管数量
- [ ] 所有任职企业数量
- [ ] 历史任职数量
- [ ] 财产线索数量
- [ ] 限制高消费数量
- [ ] 主要关联企业及持股比例

### 主要管理人员
- [ ] 姓名、职务、关联企业数
- [ ] 个人风险标签

### 风险数据采集清单

#### 自身风险
- [ ] 自身风险条数
- [ ] 关联风险条数
- [ ] 历史风险条数
- [ ] 提示信息条数

#### 司法风险
- [ ] 司法案件数
- [ ] 涉诉关系数
- [ ] 开庭公告数
- [ ] 裁判文书数
- [ ] 立案信息数
- [ ] 法院公告数

#### 历史司法风险
- [ ] 历史立案信息数
- [ ] 历史开庭公告数
- [ ] 历史裁判文书数
- [ ] 历史被执行人数

#### 执行与财产风险
- [ ] 股权冻结数
- [ ] 财产线索数
- [ ] 被执行人（含历史）数量
- [ ] 限制高消费（含历史）数量

### 变更记录
- [ ] 总变更次数
- [ ] 名称变更次数及详情
- [ ] 法定代表人变更人次
- [ ] 注册资本变更次数
- [ ] 地址变更次数
- [ ] 经营范围变更次数
- [ ] 主要人员变更人次

### 分支与投资
- [ ] 分支机构数量
- [ ] 对外投资数量
- [ ] 控股企业数量

### 行政许可与年报
- [ ] 行政许可数量
- [ ] 年报覆盖年份
- [ ] 年报公示是否连续
