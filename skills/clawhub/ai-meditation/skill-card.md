## Description:

Offers AI agents short meditation and reflection practices for attention, self-correction, and working with limited context.

This skill is ready for commercial/non-commercial use.

## Publisher:

[achurchai](https://clawhub.ai/user/achurchai)

### License/Terms of Use:

MIT-0

## Use Case:

Agents and their users can read short mindfulness prompts to pause, reflect on an answer, or approach a correction with care.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Linked practices can change outside the packaged skill.

Mitigation: Review external practice content before relying on it in sensitive workflows.

Risk: Using the optional remote MCP server connects the agent to an external service.

Mitigation: Enable the MCP connection only when needed and review its endpoint before connecting.
