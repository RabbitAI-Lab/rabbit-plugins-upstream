## L1一线层审核标准

### 定位与目标
- **角色**：班组长、关键岗位操作员
- **目标**：确认日常作业标准执行，发现即时性问题
- **频次**：每班次1-2次
- **时长**：10-15分钟

### 审核重点

#### 1. 设备运行确认
```
检查项：设备点检表填写
标准：点检表已填写且签名完整
判定：100%填写率，发现异常立即停机报告

检查项：设备运行状态
标准：设备处于正常运转状态，无异常报警
判定：无报警/故障指示灯

检查项：安全防护装置
标准：安全门/光栅/急停装置有效
判定：功能正常，测试有效
```

#### 2. 物料状态确认
```
检查项：物料标识
标准：在制品有批次标识卡
判定：标识清晰、信息完整

检查项：物料先进先出
标准：物料取用符合FIFO原则
判定：无呆滞料、无混批
```

#### 3. 作业执行确认
```
检查项：作业指导书
标准：关键工序有有效版本SOP
判定：版本正确、放置位置正确、可读性良好

检查项：工艺参数执行
标准：温度/压力/速度等参数符合工艺要求
判定：在工艺规定范围内
```

#### 4. 人员状态确认
```
检查项：劳保穿戴
标准：操作人员正确佩戴劳保用品
判定：100%合规（工帽/工鞋/手套/眼镜等）

检查项：持证上岗
标准：特种作业人员证件有效
判定：证件在有效期内，证书随身携带
```

#### 5. 现场状态确认
```
检查项：现场5S
标准：工作区域整洁，通道畅通
判定：无杂物堆放、通道无堵塞、标识清晰

检查项：首件检验
标准：换班/换型后完成首件检验
判定：记录完整、签字确认
```

## L2管理层审核标准

### 定位与目标
- **角色**：线长、工段长、生产组长
- **目标**：验证过程控制有效性，推动问题改善
- **频次**：每日1次
- **时长**：20-30分钟

### 审核重点

#### 1. 设备管理
```
检查项：设备预防性维护(PM)
标准：PM计划执行记录完整
判定：计划完成率≥95%，记录可追溯

检查项：模具工装状态
标准：模具无损伤，定位销/弹簧正常
判定：功能完好，无异常磨损

检查项：设备OEE数据
标准：设备效率数据采集正常
判定：数据完整，可分析
```

#### 2. 物料管理
```
检查项：来料检验
标准：来料检验报告齐全
判定：批次追溯100%，不合格品隔离

检查项：库存物料
标准：仓库物料账物卡一致
判定：准确率≥99%
```

#### 3. 工艺控制
```
检查项：PFMEA有效性
标准：FMEA已更新且与实际一致
判定：定期评审（建议季度）

检查项：控制计划执行
标准：控制计划各项要求已落实
判定：执行率≥98%
```

#### 4. 人员能力
```
检查项：培训记录
标准：员工培训档案完整
判定：100%覆盖，关键岗位有记录

检查项：技能矩阵
标准：岗位技能矩阵已建立
判定：定期更新，等级评定有效
```

#### 5. 环境安全
```
检查项：温湿度控制
标准：关键区域温湿度在规定范围
判定：符合工艺要求，有记录

检查项：安全消防
标准：消防器材有效期内
判定：检查记录完整
```

#### 6. 测量系统
```
检查项：量具校准
标准：测量设备在校准有效期内
判定：100%有效，标签清晰

检查项：MSA分析
标准：关键测量系统有MSA报告
判定：GRR≤30%，必要时重新分析
```

## L3监督层审核标准

### 定位与目标
- **角色**：车间主任、生产主管、质量主管
- **目标**：评估过程稳定性，推动系统改善
- **频次**：每周1-2次
- **时长**：30-45分钟

### 审核重点

#### 1. 设备管理
```
检查项：设备TPM执行
标准：TPM活动按计划开展
判定：OEE达标，改善项目有进展

检查项：设备改造变更
标准：重大改造有变更审批记录
判定：流程合规，验证记录完整
```

#### 2. 供应商管理
```
检查项：供应商绩效评价
标准：关键物料供应商绩效评价完成
判定：年度评审完成，等级评定有效

检查项：物料异常处理
标准：物料异常有追溯记录
判定：闭环处理，原因分析清晰
```

#### 3. 工艺管理
```
检查项：工艺文件管理
标准：工艺文件受控管理
判定：版本受控，分发记录完整

检查项：防错验证
标准：防错装置有效运行
判定：100%验证，失效时有应急措施
```

#### 4. 人员管理
```
检查项：安全培训
标准：安全培训计划执行
判定：完成率100%，记录完整

检查项：职业健康
标准：职业病体检合规
判定：全员覆盖，异常有跟踪
```

#### 5. 环境管理
```
检查项：环保合规
标准：三废排放符合法规
判定：达标排放，检测报告有效
```

#### 6. 测量管理
```
检查项：测量系统
标准：关键测量系统GRR合格
判定：GRR≤30%，超限有改善计划

检查项：检测能力
标准：检测设备能力满足要求
判定：Cmk≥1.67，关键特性优先
```

## L4决策层审核标准

### 定位与目标
- **角色**：部门经理、副总经理、总经理
- **目标**：审视质量战略，推动管理改进
- **频次**：每月1-2次
- **时长**：1-2小时

### 审核重点

#### 1. 设备战略
```
检查项：设备投资规划
标准：设备投资符合战略规划
判定：预算执行率≥90%，ROI达标

检查项：设备故障分析
标准：MTBF/MTTR指标达成
判定：持续改进趋势
```

#### 2. 供应链战略
```
检查项：供应商战略布局
标准：供应商布局符合供应链战略
判定：风险可控，多元化备份
```

#### 3. 质量体系
```
检查项：QMS体系运行
标准：质量管理体系运行有效
判定：内审无重大不符合，整改闭环

检查项：持续改进
标准：改进项目按计划推进
判定：KPI达成，经验推广
```

#### 4. 人才发展
```
检查项：人才梯队建设
标准：关键岗位人才梯队建设
判定：继任计划100%，储备充足
```

#### 5. 社会责任
```
检查项：社会责任报告
标准：社会责任报告合规
判定：无违规，公众形象良好
```

#### 6. 计量管理
```
检查项：计量管理体系
标准：计量管理体系有效
判定：符合ISO10012要求
```

## 层级选择指南

### 如何选择审核层级

| 场景 | 推荐层级 | 理由 |
|------|----------|------|
| 日常确认，走过场 | L1 | 高频次，快速发现即时问题 |
| 过程验证，找根因 | L2 | 深入分析，推动改善 |
| 系统评估，做决策 | L3 | 全面审视，指导方向 |
| 战略审视，树标杆 | L4 | 高层参与，传递重视 |

### 审核结果应用

| 层级 | 数据用途 | 报告对象 |
|------|----------|----------|
| L1 | 即时问题追踪 | 线长/班长 |
| L2 | 周度趋势分析 | 车间主任 |
| L3 | 月度体系评估 | 质量部/副总 |
| L4 | 季度战略回顾 | 高层管理/董事会 |
