# 验收标准

## 功能验收

- [ ] skill 能成功调用华为云CCE ListClusters API
- [ ] 返回结果正确展示集群列表（含名称、状态、版本、平台版本等关键字段）
- [ ] 表格化输出，列对齐、可读性好
- [ ] 认证凭证正确配置（AK/SK）
- [ ] 支持区域参数

## 错误处理验收

- [ ] 网络异常时输出友好错误提示
- [ ] 认证失败时输出明确错误信息
- [ ] API返回空列表时输出合理提示
- [ ] 不支持的区域代码有明确提示

## 代码验收

- [ ] 通过结构验证（validate-skill.sh）
- [ ] 通过功能测试（test-skill-commands.sh）
- [ ] 无硬编码 AK/SK
- [ ] 无 mock 代码
- [ ] 错误处理完整

## PR 验收

- [ ] PR 合并到 main 分支
- [ ] Code Review 通过
- [ ] QA Agent 测试通过
