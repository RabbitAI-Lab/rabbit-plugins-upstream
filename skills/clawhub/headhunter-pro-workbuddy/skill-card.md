## Description:

Headhunter Pro is an AI-assisted recruiting workflow toolkit for talent mapping, candidate screening, recommendation reports, outreach scripts, interview assessment, offer negotiation, onboarding support, compliance workflows, and data-driven pipeline management.

This skill is ready for commercial/non-commercial use.

## Publisher:

[walterjiang-sketch](https://clawhub.ai/user/walterjiang-sketch)

### License/Terms of Use:

MIT-0

## Use Case:

Recruiters, headhunters, and talent teams use this skill to structure end-to-end recruiting work: screen resumes against a JD, build candidate profiles, generate recommendation reports, draft outreach, assess interviews, manage client and pipeline workflows, and support onboarding.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill handles sensitive candidate and recruiting data and may encourage collection or reuse without consistent consent, limits, or secure handling.

Mitigation: Use it only inside an approved recruiting process; obtain written consent for background checks, reference outreach, recording or transcription, long-term talent-pool reuse, and automated follow-up; store candidate data only in approved secure HR systems.

Risk: Social-profile sourcing, GitHub review, or external-tool guidance can create privacy and compliance exposure.

Mitigation: Avoid harvesting commit emails or scraping social profiles, and review any GitHub token, cron, or external-tool guidance before use.
