# Q4 / 春节前关单日历与季节战术（v28 新增 · 源自 2026-11-06 学习）

> 反共识：Q4 不是招聘淡季，是**全年机会最密集的关单窗口**（Q1 hiring starts in Q4）
> 三个理由：公司用**明年预算和编制**定 offer；候选人开始盘算去留、触达窗口打开；流程快的公司 Q4 锁人，避开 Q1 海量竞争

## 一、首轮电话三问（奖金/归属日历前置侦察）

**必须在 recruiter 首轮电话就问，不要拖到 offer 阶段。**

| # | 问什么 | 为什么关键 | 话术 |
|---|--------|-----------|------|
| 1 | **年终奖**：金额量级 + 发放日 | 候选人已攒 9-11 个月绩效奖金，现雇主最趁手的 counter 武器就是"发了奖金再走" | "你们年终奖一般几号发？大概几个月？我帮你把时间线算清楚" |
| 2 | **vesting / 成熟日**：最近一个归属点 | 股票归属点落在 Q4/Q1 → 放弃成本必须可视化 | "你手上有没有快到期的股票或期权？归属日是哪天？" |
| 3 | **通知期 + 真实可到岗日** | 年底交接 + 假期，合同通知期 ≠ 实际到岗日 | "合同上通知期多久？考虑到年底交接，你现实里最快哪天能入职？" |

## 二、make-whole 补偿计算器

> 精确算账比抬 base 有效（sign-on = 最易动杠杆：一次性、不占薪资带宽、不设先例）

```
make-whole 金额 =
    未领年终奖（按已服务月数折算）
  + 未归属股票/期权（授予值 × 未归属比例 × 估值调整）
  + 其他一次性损失（十三薪/十六薪差额、未休年假折算）
```

- 谈判话术："如果我们帮你把未领的年终奖做成 make-whole，你还需要犹豫什么？"
- 给客户的话术：签字费是**一次性成本、不冲击职级带宽、不设内部先例**——比抬 base 好批
- 中国语境补充项：十三薪/十六薪、期权成熟日、春节前后发放的年终奖金

## 三、二段式 start date（Q4 关单核心工具）

| 场景 | 写法 | 效果 |
|------|------|------|
| 候选人要等年终奖 | offer 12 月签、start date 排 **1 月下旬/2 月** | 奖金落袋，counter offer 火力自然衰减 |
| 候选人要等 vesting | start date 排在归属日之后 1-2 周 | 避免"白送"未归属股权 |
| 客户要年底到岗 | 拆两段：12 月签 + 1 月到岗；或 12 月到岗但 make-whole 覆盖损失 | 满足客户预算年度切换 |

**预算年度切换话术（帮客户算账）**："12 月入职走 2025 剩余预算，1 月入职占用 2026 编制——你想让这笔钱算在哪一年？"聪明钱做法：Q4 花完剩余预算预支次年成本（入职礼包/设备/工具提前采购）。

## 四、中国化校准：春节观望期（12 月—次年 3 月）

- 国内对应物：**年终奖（春节前后发）+ 十三薪/十六薪 + 期权成熟日**
- "金九银十"后进入签约-等待期 → 11 月的正确姿势：**谈好、排期到春节后入职、用 make-whole 锁人**
- 春节前离职窗口：候选人通常愿意接受"过完节再来" → start date 写 2 月下旬
- 反悔高危窗口 = **奖金到账后 48 小时**（钱到手、现雇主挽留火力最猛）→ 必须主动跟进，不等候选人开口

### 发奖后 48h 跟进话术
```
XX，奖金到账了吧，恭喜！
按我们之前聊的，你的 start date 定在 [日期]，
我这边已经跟 [客户] 同步了入职安排，团队那边也在准备。
有什么变动或者新想法，第一时间跟我说——
咱们把后面的事排顺，别让最后这段出岔子。
```

## 五、客户 Q4 加速器服务包（顾问价值最大化）

**Q4 卡点（Cornerstone）**：假期打断面试、manager 年末过载、审批挂起、"10 月感兴趣的候选人 12 月早没了"、offer 卡预算/薪酬/审批。

| 加速器动作 | 标准 |
|-----------|------|
| 发布前对齐要求 | intake 前置，别拖到 12 月才校准 |
| **锁定面试时段** | manager 日历提前占位（不占位=12 月排不上） |
| **48 小时反馈强制令** | 每轮面试后 48h 内给结论，写进合作约定 |
| 流程压缩目标 | 首面 → 终面 offer **7-10 个工作日** |
| 审批提前备案 | HC / 薪酬包 / 审批链年末前走通（年末流程慢是结构性问题） |
| 预算切换算账 | 见第三节话术 |

## 六、Quiet Onboarding：12 月/1 月入职者的静默融入

> 假期季入职 = 最容易 ghost/闪离的 30 天。这是过保率的隐形战场。

**前三周节奏 = Learn / Connect / Plan，不排硬任务**
- Day 1 装备齐：笔记本/账号/权限/节日欢迎礼
- 指定 Buddy（不是直属领导）
- **拉进所有年末聚会**（年会/部门聚餐/客户答谢）——假期季融入靠非正式场合
- 节前 HR/HM 面谈：**批准他的 30-60-90 计划再放假**（避免假期空转、回来无方向）

### 11-2 月护航节奏改版
| 原节奏 | 春节季改版 |
|--------|-----------|
| 第 1 周回访 | **节前确认**：装备/账号/聚会安排/30-60-90 是否批准 |
| 第 2 周回访 | **节中问候**：轻量、不谈工作，只维系关系 |
| 第 2-4 周快赢期 | 顺延至节后第一周启动（节前不压任务） |

## 七、季节节奏总览（全年适用）

| 季节 | 特征 | 主战术 |
|------|------|--------|
| 金三银四（3-4 月） | 年终奖已发、跳槽高峰 | 速度战：抢人窗口短，流程压缩 |
| 6-8 月 | 相对淡季 | Mapping 蓄水、Silver Medalist 池激活、客户关系维护 |
| 金九银十（9-10 月） | 第二波高峰 | 正常交付节奏 |
| **Q4（11-12 月）** | **关单黄金季** | 三问侦察 + make-whole + 二段 start date + 客户加速器 |
| 春节观望期（12-3 月） | 等奖金、反悔高发 | 发奖后 48h 跟进 + Quiet Onboarding + 护航改版 |
