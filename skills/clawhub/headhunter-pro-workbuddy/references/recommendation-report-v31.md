# 推荐报告 v3.1 微升级 + 行业趋势报告 Deep-Research 框架（v27 新增）

> v3.0（岗位任务反推）基础上补 5 个客户体验细节 + 1 个研究方法论框架

## 一、v3.1 五个升级点

### ① 一句话画像钩子（报告最开头）
用一句话讲清"这人是谁 + 为什么值得看"，客户读这句决定要不要往下看：
- 例："985 本硕 + 字节电商核心业务 5 年，主导推荐系统 0→1，GMV +23%"
- 原则：具体数字 + 具体背景，**不用形容词**

### ② JD 对标改为左右分栏表
| JD 要求（左列） | 候选人证据（右列） | 匹配 |
|---|---|---|
| 必备：5 年+后端 | 6 年美团后端，主导闪购系统重构 | ✅ |
| 加分：从 0 到 1 经验 | 参与新业务但只做组件，未整体 0→1 | ⚠️ 半 |

每行左列写要求、右列写**可验证证据**；❌ 项必须附解释和潜力判断。

### ③ 评价六要素检查表（提交前自检）
- [ ] 技能熟练度（深度/广度/证据）
- [ ] 年限总结（有效年限，非物理年限）
- [ ] 名企背书（公司/团队/汇报线的含金量）
- [ ] 业绩数据（至少一个可验证的量化结果）
- [ ] 性格判断（基于行为观察证据，非贴标签）
- [ ] 解决什么问题（直接回答岗位的真实业务问题——岗位任务反推落点）

### ④ 总包拆解段落（衔接股权模块）
```
| 构成 | 数值 | 说明 |
| base | XX | 月薪 × 几薪 |
| bonus | XX | 近两年实发，target vs actual |
| 股权/期权 | XX | 授予值/归属节奏/未归属部分/估值逻辑 |
| sign-on | XX | 金额与 clawback 条款 |
| 税后估算 | XX | 考虑归属节奏与税率后的真实现金 |
```

### ⑤ 内部公平性/薪资倒挂风险预判
33% 企业存在薪资倒挂（新人高于资深员工）——推荐报告加一句：
"候选人期望总包处于团队内部 XX 水位；若高于同职级 X%，建议客户以总包结构（职级/签字费/股权）而非单纯抬 base 方式处理。"

## 二、AI 辅助推荐报告工作流（完全自主可控）

```
沟通记录/简历 → 关键词提炼（JD 核心要求）→ 逐条对标 → 生成初稿
→ 人工微调（画像钩子/风险点/语气）→ 客户内审 → 提交
```
模板可按客户偏好定制；发送前必过六要素检查表。

## 三、行业趋势报告 Deep-Research 框架

> 把《行业趋势报告》（首次触达价值前置的核心道具）从"搜一下拼一拼"升级为可交叉验证的研究产品。

### 五维分解（每个子问题单独检索）
1. **供需**：岗位量 vs 人才量、紧缺岗、供需比（如智能驾驶 16:1）
2. **薪酬**：涨幅分位、热招岗薪资（引用 references/salary-intel-2026-cn.md）
3. **流动**：去向/城市流动系数（珠海 +88%）、回流/出海方向
4. **技能**：硬性要求变化（AI 能力 34%）、消失/扩招岗位清单
5. **政策**：监管/补贴/集采/行业准入对人才需求的影响

### 四条硬规则
- **多源**：平台报告（猎聘/脉脉）+ 咨询白皮书（RGF/Morgan McKinley/光辉国际）+ 新闻 + 财报招聘信号
- **交叉验证**：同一数据点 ≥2 个独立来源印证；单源数据降级为"待验证"
- **带引用**：每个关键数字标来源+日期，客户和候选人可查证 → 专业信任
- **标注冲突**：呈现相反观点（如"降本增效 vs 关键岗争夺加剧"悖论）+ 标注知识缺口，不假装确定

产出用途：首次触达附件 / 客户 briefing / 推荐报告市场情报段数据层。
