# Offer 反悔预防与补救 + 谈判杠杆排序 + 股权三架构（v27 新增）

> 与 counter-offer-defense.md 的分工：那边管"现雇主挽留"攻防；本文管"候选人拿到 offer 后反悔"预防补救 + 薪酬谈判杠杆工具。每补救一个流失候选人 = 省 28 天 + 降 40% 综合成本（vs 从零重启），此数据可入客户汇报。

## 一、Offer 反悔五大真实原因（薪资只是表层）
1. 面试体验差留下负面印象
2. **发 offer 后企业突然"静默"** → 候选人不安
3. 看不到职业成长路径，缺乏长期吸引力
4. 原公司"感情+薪资"双重挽留（衔接 counter-offer 攻防）
5. 竞业限制和背调顾虑没有提前打消

## 二、预防清单（发 offer 同时就要做）
- [ ] 约定"反静默"机制：入职前固定更新节奏（衔接 ghosting-prevention.md）
- [ ] 竞业/背调顾虑提前打消（书面确认范围，不让候选人自己猜）
- [ ] 展示成长路径（入职后 12 个月的具体安排）
- [ ] offer 由招聘经理电话沟通而非只发文本（个性化提升接受率）

## 三、48 小时黄金窗口：三句话术结构
候选人说"再考虑一下"后 48h 内是挽回黄金期：
1. **先表达理解**："这么重要的决定，考虑清楚是对的"
2. **提供信息而非索要承诺**："有什么信息我可以帮你补充了解的？比如团队架构、业务规划、入职后的具体安排"
3. **设温和跟进节点**："那我周四下午跟你同步一下后续安排，你看方便吗？"

> 核心姿态转换：从"等你的答复" → **"我帮你做决策"**

## 四、催 vs 跟（offer 发出后的跟进节奏）
| 时点 | 动作 | 禁忌 |
|------|------|------|
| 24h 内 | 正式跟进，**用电话不用微信** | 文字催答复 |
| 48-72h | 非正式：安排直属上级午餐/咖啡 | 重复"考虑得怎么样了" |
| 一周未回复 | 不再催，换角度：分享公司好消息/团队动态，保持正向连接 | 死缠硬逼、反复催 |

频率 ≤2 次/周；每次沟通必须带新信息或新价值。催 = "你快点做决定我等着"；跟 = "我陪你走完这个决策过程"。

## 五、谈判杠杆排序（从易到难）
1. **Sign-on bonus = 最易动的杠杆**：一次性成本、不影响薪资带宽、不设先例，审批门槛低
2. RSU 追加：需更高层审批；让候选人 "model the after-tax, after-schedule value" 再开口
3. base：最难（冲击带宽与内部公平）→ 用总包结构（签字费/职级/股权）替代单纯抬 base

- 客户预算有限时按此顺序加杠杆
- 候选人两个合理谈判场景：补偿放弃的未归属股权 / 弥补 base 低于预期
- 信息差就是钱：Levels.fyi 实盘中级岗平均谈高 $20K、领导岗 $90K

## 六、股权激励讲解（猎头讲清总包 = 专业信任 + 关闭率）

> 高管/资深技术岗股权占总薪酬 40-70%。RSU 授予是候选人**质疑最少、后悔最多**的部分——"第一稿就接受"比例最高。

### RSU 五大认知误区对照表（候选人预期管理用）
| 误区 | 真相 |
|------|------|
| "RSU 就是我已有的股票" | 归属前只是有条件的未来薪酬承诺，未归属离职 = $0 |
| "授予时价值确定" | 归属前暴露股价波动，实现价值可能差异很大 |
| "税只在卖出时重要" | 归属/交付时就按雇佣收入计税（第一道税务事件更早） |
| "所有 RSU 都一样" | 归属节奏/交付时点/扣缴方式（净额 vs 卖股代扣）/交易窗口/锁定期/离职处理差异很大 |
| "Sign-on 和 RSU 等价" | Sign-on 一次性不复利；RSU 每年归属，股价上涨重置收益率 |

基础结构：典型 4 年归属 + 1 年 cliff（满 1 年归 25%，之后按季）；每次归属 = 应税事件，sell-to-cover；ESPP 通常 15% 折价用税后工资买股。

### 三种上市架构工具差异速查
| 架构 | 常用工具 | 关键特点 |
|------|---------|---------|
| **A 股** | 期权 + 限制性股票（**无 RSU**） | 限制性股票要**自己先出钱**（约股价 1/2 定价），股价腰斩会赔钱；定价和业绩条件严苛 |
| **H 股** | 股票增值权（现金结算为主） | 避免外籍人员成为股东；红线：计划合计 ≤ 已发行股份 10%（每 3 年可刷新）、**归属期至少 12 个月**、个人上限 1% |
| **红筹/美股** | RSU / 期权（ISO/NSO） | 0 对价 RSU 最受员工欢迎；ISO 有税收优惠但可能触发 AMT，NSO 按普通收入纳税 |

### 总包计算话术（Amazon 式结构为例）
总包 = base + 两年 sign-on（12 个月分摊）+ RSU 后置归属（Y1 5% / Y2 15% / Y3-4 每半年 20%）——前两年补现金、后期靠 RSU 留人。
- 候选人从这类公司跳槽：算清**未归属 RSU 损失** → 用新公司 sign-on / 加速归属弥补
- 对创业公司候选人："期权高风险高回报，股价停滞可能一文不值；RSU 低风险稳健，股价略跌仍有剩余价值"
- 对 A 股公司候选人：提醒限制性股票要自己先出钱，有下行风险
