# 猎头合同与收费条款谈判攻防（v28 新增 · 源自 2026-11-03 学习）

> 核心原则：**Trading, not demanding**——客户用独家/量/决策速度做筹码，我们也用这三样换条款
> 年薪口径模糊 = 纠纷第一源头（"天价猎头费"判例教训）

## 一、四大收费模型（2026 买方视角）

| 模型 | 费率 | 特点 | 适用 |
|------|------|------|------|
| Contingency | 15-30% | 只成功付费，客户最熟悉 | 中基层、批量岗 |
| Retained | ~33%，$80-100K 起，分三期 | 高管寻访、独家、深度咨询 | C-suite / VP / 保密岗 |
| **Engaged / Container（混合）** | **$5-15K 不可退启动费 + 18-25%** | 2026 增长中的中间形态；有前期承诺但门槛低于纯 retained | 客户想砍 retained 但又要质量时的折中产品 |
| Fractional（按小时） | $75-250/hr | 嵌入式招聘支持，无成功费 | 长期陪跑、项目制支持 |

**中国市场费率惯例**：90%+ 按年薪比例——基层 15-20 点、中高层 20-25 点、CXO 25-30 点。
**分期惯例**：签约预付 30-40% → 入职 40-50% → 过保证期尾款 20-30%（预付 50% 的客户通常拿到更低费率——资金占用成本）。
**费率阶梯示例（合同范本）**：年薪 <15 万 → 22%；15-30 万 → 25%；30-100 万 → 28%；CEO 另议（保证期 3 个月）。
**违约金惯例**：逾期每天万分之四；客户直挖猎企顾问 = 双倍佣金。

## 二、买方压价筹码 vs 我方对等交换清单

客户会拿着"费率普遍可谈 3-7 个百分点"来找你砍价。提前备好交换表：

| 客户要求 | 客户付出什么 | 我方可让 | 我方必须守住 |
|---------|-------------|---------|-------------|
| 降费率 3-5 点 | **独家委托**（非独家=多家赛马，独家才配深度资源） | 费率让步 | 保证期不缩短、年薪口径不模糊 |
| 降费率 | **量承诺**（打包多岗位） | 阶梯折扣 | 单岗位交付质量不打折 |
| 降费率 | **付款快**（net-15 vs net-30） | 小幅让步 | 发票与付款解耦（见第六节） |
| 保证期 90 天全额退款 | —— | 可谈"剩余期比例退" | **拒绝"全额退款"**，改为"免费替换 + 比例退" |
| 归属期压到 6 个月 | 更高费率 | 归属期让步 | 费率相应上浮 |
| "被拒的直投候选人不计入归属" | —— | 可接受 | 但须定义"直投"时间点 + 书面确认机制 |
| 试单机制（15 天独家证明交付力） | 独家 15 天 | 可接受 | 明确 15 天内的交付标准（推荐 N 人 / 安排 N 场面试），否则"不行就撤"无客观依据 |

### 影响费率的五因子（报价逻辑透明化，可用于向客户解释定价）
1. **职级**：C 级 → 25%+
2. **稀缺度**：数据科学/金融科技/AI 等溢价岗位 → 上浮
3. **独家**：给独家 → 可降
4. **量承诺**：多岗位打包 → 折扣
5. **预付比例**：预付越高 → 费率越低

## 三、⚠️ 年薪口径标准条款（防"天价案"式争议）

**判例教训**：合同约定"税前年薪含股票、签约奖金、津贴"，候选人总包含**每年保底 1000 万股票** → 28% 费率算出天价 → 法院按"缔约时可确定的金额"裁量。

### 推荐条款文本（量化、无歧义、附例）
> "本合同所称'年薪'指劳动合同载明的**年度基本工资 + 固定津贴**之和，**不含**绩效奖金、加班费、福利、股权激励及任何非固定收入，以候选人**首年劳动合同**约定金额为准。"

### 高端岗精细式写法
```
计薪基数 = base × 12
         + 保证奖金（guaranteed bonus，如有书面承诺）
         + 预期浮动奖金 × 折算系数（系数需双方书面确认，建议 0.5-0.7）
```
签约前**双向书面确认口径**，并在推荐报告中同步标注候选人总包结构，避免入职后口径不一致。

## 四、保证期条款四要素（含糊必扯皮）

| 要素 | 必须写明 |
|------|---------|
| 1. **起算日** | 通常为候选人**实际入职日**（非 offer 日/签约日） |
| 2. **哪些离职可索赔** | 分开写：候选人主动离职 / 企业辞退 / 试用期以"不符录用条件"解除 —— 三类责任不同 |
| 3. **退款标准** | 剩余期比例退 / 退未付尾款 / 退已付某比例（三选一，写死） |
| 4. **替换流程 + 时限 + 次数** | 客户通知后 N 天内启动替换、替换次数上限（建议 1 次）、替换期是否重新起算 |

### 🔑 我方保护条款（谈判时别丢）
> "因**甲方原因**（战略调整、业务停顿、组织架构变更、岗位撤销等）导致候选人在保证期内被动离职的，甲方仍应**全额支付**服务费，乙方不承担替换义务。"

## 五、防跳单三条款（司法背书版本）

客户拒付五大抗辩 → 靠条款预先封堵：

| 客户抗辩 | 封堵条款 | 要点 |
|---------|---------|------|
| "人是第三方推荐/我们自己招的" | **独家委托条款** | 委托期限内，该岗位经任何第三方成交，甲方仍需付费 |
| 同上 | **人选排除条款（off-limits）** | 乙方推荐过的候选人，**12 个月内**经任何渠道（含甲方直招、关联企业）录用，均视为乙方成果 |
| "这简历我们也有" | **及时告知条款** | 甲方其他渠道已有该候选人简历的，须在 **24 小时（范本）/ 3 个工作日（研究报告版）**内书面声明；逾期视为乙方推荐有效 |
| "履历造假，你们背调失职" | 背调义务边界条款 | 明确谁做背调、做到什么程度（基础层/标准层/深度层）+ 保留背调过程记录 |
| "保证期离职你们没补人" | 替换流程时限 + 留痕 | 时限写明 + 保留推荐动作证据 |
| "没开票所以不付" | 发票与付款解耦 | 见第六节 |

**法院态度**：此类防跳单条款**不构成无效格式条款**，属正当保护猎企远期利益；私下录用（含经关联企业）会**减轻猎企举证责任**——但合同里必须预先定义"关联企业"和"录用"（含试用期、劳务、顾问等变相形式）。

**响应时限条款双向化**（写进合同，同时是过程管理抓手）：甲方 48h 内反馈是否面试、面试后 24h 内给结果。

## 六、发票陷阱与现金流保护

**问题**：客户惯例"先见发票后走款" → 猎企垫付 6% 增值税 + 回款周期被拉长。

**应对**：
- 付款节点绑定 **"入职日 / 保证期结束日"**，而非"收到发票后 X 天"
- 或明确 **开票时点 = 付款到期日同步**（同时触发，不给垫资窗口）
- 合同里写清发票类型（专票/普票）、开票信息变更的通知义务

## 七、客户抗辩自查清单（每月归档一次）

- [ ] 每次推荐都有书面留痕（邮件/微信记录 + 推荐报告存档）
- [ ] 候选人确认记录（是否知情被推荐给该客户）
- [ ] 背调边界声明（合同里写了做哪一层，实际做了哪一层）
- [ ] 保证期动作记录（离职通知时间、替换启动时间、沟通记录）
- [ ] 年薪口径确认书（候选人 + 客户双签）
- [ ] 发票与付款时间对应表（防垫资）
- [ ] 独家/人选排除条款是否在本合同中生效（易被漏签）
- [ ] 关联企业定义是否明确
- [ ] 响应时限条款是否双向（我方也要守 48h 推荐节奏）
- [ ] 争议解决条款（仲裁地/法院管辖）是否对我方便利
