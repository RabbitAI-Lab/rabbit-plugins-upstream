## 医疗健康行业人才情报 2026 — 创新药 BD 出海大年 + CXO 复苏 + 器械分化

> 来源：大公国际《2026 年下半年创新药行业前瞻》、浦银国际《医药行业 2026 年展望》、普华永道《2026 年全球并购趋势展望：医疗健康》、医药魔方 NextPharma、Evaluate Pharma

### 一、行业景气度总判断（2026 下半年）

大公国际核心结论：**景气回升与信用分化并行，价值驱动加速行业洗牌**

| 维度 | 状态 |
|------|------|
| **需求端** | 刚性增长 + 支付能力改善正向循环；医保加速准入 + **商保目录落地**推动"以价换量"持续兑现 |
| **供给端** | 上市新药数量、BD 出海总金额、研发管线规模**均创历史新高**；CXO 新签订单持续回暖 |
| **政策端** | **自主定价新机制落地**，全链条支持进入精细化执行阶段 |
| **信用端** | 多数企业杠杆低、流动性充裕；**但部分中游企业营运效率偏低、再融资收紧 → 尾部主体信用风险** |

**⚠️ 对猎头的意义**：行业扩张但分化加剧。**选客户比选候选人更重要**——尾部 Biotech 可能裁员/关停/付不出服务费。做单前先做信用筛查（详见 `payment-terms-collection.md` 客户信用分级）。

### 二、创新药 BD 出海：2025 创纪录，2026 继续爆发

| 指标 | 数据 |
|------|------|
| BD 授权交易笔数（2025） | **157 笔**（另一口径 167 起，差异在是否含 NewCo/平台合作，**引用须注明口径**） |
| 交易总金额 | **1,356.55 亿美元**（突破 1300 亿大关） |
| 首付款总额 | **70 亿美元** |
| 全球占比 | **数量占全球半壁江山，超越美国成为全球出海金额最高地区** |
| 年度前十门槛 | 升至 **30 亿美元以上** |

2026 年初势头：西比曼、荣昌生物等**不到一个月内密集达成至少 5 项海外授权交易**。

**驱动力：MNC 专利悬崖**
- **2027-2028 年**：全球年销售额约 **1,800 亿美元、占比近 12%** 的产品面临专利到期
- **2026 年**失去专利保护的产品销售额预计**超 400 亿美元**
- MNC 内部管线难补缺口 → **高首付款抢购中国优质创新资产**

**出海模式升级（Out-licensing 2.0）**

| 阶段 | 模式 | 特征 |
|------|------|------|
| 早期 | Single Asset License | 单一资产授权，引发"卖青苗"担忧 |
| 2025 起 | **平台型合作 + Co-development** | MNC 认可"平台价值"而非单个分子 |
| 进阶 | **Co-Co（共同开发+共同商业化）** | 中方保留更多全球权益和长期收益 |
| NewCo | 资产注入海外新实体 | 从 2024 年 **6 笔**增至 2025 年 **9 笔** |

**标志性交易（客户 briefing 可直接引用）**
- **和铂医药 × 阿斯利康**（2025-03）：Harbour Mice® 全人源抗体平台全球战略合作
- **石药集团 × 阿斯利康**（2025-06）：**AI 制药平台出海**
- **恒瑞 → Braveheart Bio**：III 期 HRS-1893，恒瑞**保留大中华区权利**，获预付款+里程碑+特许权使用费

**市场情绪转折**：BD 从稀缺事件变常态后，"简单授权故事已不足以支撑估值"——市场追问里程碑兑现、全球开发能力、平台造血可持续性。**给客户/候选人 briefing 时体现这一点，展示专业度。**

### 三、BD 热潮 → 招聘的传导链条

```
BD 回流资金 → 研发投入 ↑ → ADC/多肽需求增长 → CXO 新签订单大增
→ 管线从早期探索推进到关键临床 → 后期 NDA → 获批 → 商业化放量
→ 销售收入反哺研发（正向循环）
```

前提：融资环境持续改善是撬动链条运转的前提，**任何环节阻滞都影响景气传递**。

**CXO 订单实盘（2025）**

| 企业 | 指标 | 增速 |
|------|------|------|
| 药明康德 | 在手订单 | **+28.8%** |
| 康龙化成 | 新签订单 | **+14% 以上** |
| 美迪西 | 全年新签订单 | **+47%** |

CXO 2026 乐观三理由（浦银国际）：①美元降息节奏提振海外投融资；②头部新签订单双位数增长；③**生物安全法案可行性不断下降**（地缘风险缓解）。

### 五、医疗科技并购趋势（普华永道）

- 主线：**资产组合聚焦 + 下一代技术驱动**——剥离低增长资产、重投高增长领域
- 标志交易：2025 碧迪医疗（BD）约 **175 亿美元**向沃特斯出售先进生物工艺业务及部分诊断资产
- 财务投资者聚焦**企业业务分拆**领域
- 下一代技术：机器人、AI 辅助成像、传感器、居家医疗设备
- 收购方筛选标准：差异化技术 + 支撑**经常性收入、客户留存**的数据/软件/服务体系
- **中国定位**："中国正崛起为生命科学交易的核心枢纽"；亚洲是全球生物医药与医疗服务并购的增长引擎

### 八、⭐ BD 岗五维复合能力评估（推荐报告写作要点）

能做大额 License-out 的 BD 需同时具备：
1. **科学判断力**——读懂管线数据、评估靶点价值
2. **交易能力**——term sheet 谈判、里程碑设计、尽调应对
3. **英文商务沟通**——与 MNC 直接对话
4. **人脉网络**——MNC BD 圈层
5. **项目管理**——Co-development 跨方协调

> **薪酬溢价论证**："重磅 BD 潜力"已成券商选股标准——BD 能力从职能变成**估值驱动因素**。跟客户谈这个岗位薪酬时引用这一点。
