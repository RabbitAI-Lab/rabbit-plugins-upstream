## Counter-Offer 攻防 — 可辩护数据、7 阶段 SOP 与离职护航话术

> 适用：8 步服务流程第 7 步「离职护航」+ 推荐报告第七段「薪酬架构建议」
> ⚠️ **数据纪律**：不得使用"80% 接受 counter-offer 的人 6 个月内离职"——PRL International（2026-07-15）溯源确认**找不到任何一手研究支持 80-90% 这个说法**。谁报精确数字，谁就在卖数据不支持的确定性。

**雇主侧行为数据（Hyreus, 2026-05-26）**
- **40% 的英国雇主**已把 counter-offer 纳入留才策略
- **51%** 使用 counter-offer 的雇主，其使用频率**同比增加**
- 专业市场（technology / finance / engineering / professional services）猎头报告：**50-70% 的强候选人**离职后会收到 counter-offer
- 结论：counter-offer 已不是异常行为，**在多个行业是标准动作**

**候选人侧还价数据（Resume Optimizer Pro, 2026）**
- **85%** 主动还价的候选人拿到更高报价，平均涨幅 **18.83%**
- offer 被撤回的概率 **< 1%**
- 跳槽者比留守者多赚 **7.7%**，且差距在后续每次调薪中**复利放大**
- 职业生涯杠杆最高的时刻 = **书面 offer 到答复之间的 24-48 小时**
- 还价技巧：报价略高于目标（目标 $185K → 还 $190-192K），对方很少一次给到；**保留价不低于市场中位数**——接受低于中位数会永久封顶未来调薪

### 二、为什么 counter-offer 大多失败（说服候选人的核心）

**核心一句：薪资通常不是人开始看外面机会的真实原因。**

Counter-offer 只解决了"钱"，没解决触发离职的结构性问题：

1. **信任已破裂**——提过离职后，老板心里已把你归为"不稳定资产"，重要项目/晋升开始绕开你
2. **原问题原封不动**——让你想走的那个领导、流程、天花板，加薪后一个都没消失
3. **加薪来源可疑**——这笔钱本来就该给你（薪资倒挂），只是用"挽留"名义延迟发放；下次调薪周期可能被以"已加过"为由压低
4. **预算是挪来的**——为留你临时挤出的预算，往往要在别处找补
5. **标签效应**——留下 = "被钱留住的人"，未来谈判筹码反而下降

**但有 3 种情况 counter-offer 是合理的（必须给诚实建议）**
1. 离职原因**纯粹是钱**，且新机会在其他维度并无优势
2. 原公司提供**结构性改变**而非单纯加薪：换汇报线、换业务、明确晋升时间表并**写入书面**
3. 新 offer 存在**重大不确定性**：初创现金流风险、岗位可能被砍、异地家庭成本被低估

> **顾问定位**：不是"劝人跳槽的销售"，而是帮候选人算清全账的顾问。诚实地说"这个 counter-offer 你可以考虑"，反而会让你在下一个单子里被信任。

### 三、猎头侧 7 阶段攻防 SOP

#### 阶段 1：流程早期"打预防针"（最关键）
**在候选人还没拿 offer 时就谈 counter-offer**，不要等出事再救火。

话术：
> "X 总，有个情况我得提前跟您说——以您的级别和稀缺度，您提离职后大概率会收到挽留，可能是加薪 20-30%，也可能是换岗承诺。行业数据是**一半左右的人会收到，收到的里面一半以上会接受，但接受后一年内离开的比例高达 70-80%**。我不是要打预防针让您拒绝，是想让您**在情绪上来的那一刻，还记得住今天我们一起算过的这笔账**。"

作用：counter-offer 真来时，候选人心里会响起"他说过这会发生"——**被预演过的诱惑，杀伤力减半**。

#### 阶段 2：书面化"离职理由清单"
让候选人自己写下**为什么走**（不含薪资的那几条），签字或微信留存。
- 提离职前一起过一遍："这几条，加薪能解决哪一条？"
- counter-offer 出现时，把清单发回去："您自己写的，我们对照一下。"

#### 阶段 3：Paperwork 速度就是防守
- **口头 offer 当天发书面 offer letter**——verbal 到 paperwork 之间是最危险窗口（可能被其他 offer、被 counter-offer、被家人劝退）
- 背调、体检、入职材料**并行推进**，不给"再想想"留时间窗

#### 阶段 4：摸清客户公司的挽留惯例
提前问 HR/用人经理："贵司历史上有人提离职时，通常怎么处理？会加薪挽留吗？幅度大概多少？"
- 知道了就能提前做心理建设 + 设计应对话术
- 也能预判风险：惯用"加薪+画饼"的公司，你的候选人跳票概率显著更高

#### 阶段 5：离职会议当天"接应"
- 明确告诉候选人："**开完会立刻打我电话**，不管结果怎样。"
- 那通电话的作用：在不愉快的对话之后，听到一个来自"他看到的未来"的支持性声音，能把心态稳回来
- 若已被动摇 → 立刻用"离职理由清单"+ 全账对比拉回；**不硬劝，帮他重新算**

#### 阶段 6：股权/期权作为最后的谈判工具
客户还有空间时，**用长期激励（股权、签字费、职级）而非继续抬 base** 来 closing：
- base 抬太高触发内部薪资倒挂，客户 HR 会卡
- 股权/签字费是一次性成本，客户更容易批
- 对候选人来说，长期激励的"心理锁定"效果比 base 更强，跳票率更低

#### 阶段 7：提离职话术演练（离职护航）

| 老板反应 | 应对话术 |
|---------|---------|
| **情感牌**（"我这么栽培你"） | "非常感谢您的培养，这个决定我想了很久，不是因为团队或您，是我自己下一阶段的方向。交接我一定负责到底。" |
| **加薪牌**（"给你加 30%"） | "谢谢您认可。不过我这次的决定不是薪资驱动的，加薪不改变我的判断。我们已经签了，我希望体面地完成交接。" |
| **拖延牌**（"再等一个季度"） | "我理解您的难处。我可以在离职日期上有一定弹性（最多 X 周），但决定本身不变。我们一起把交接计划做细。" |

**铁律**：不批评原公司、不透露新公司名字（防挖角/防负面 reference）、交接计划主动写细。

**风险等级判定参考**

| 等级 | 特征 |
|------|------|
| **高** | 总监级以上稀缺岗 / 原公司有加薪挽留惯例 / 候选人为家庭或情感因素易动摇 / 离职理由含"钱"且占比高 |
| **中** | 中层岗 / 原公司挽留惯例不明 / 离职理由以发展空间为主 |
| **低** | 原公司缩编或业务收缩 / 离职理由为不可逆的结构性问题（业务线关停、领导离职、地点变动） |

### 五、Silver Medalist 回流池（反向机会）

**接受 counter-offer 留下的人，6-12 个月后会重新进入市场，是最高质量的 Silver Medalist 来源。**

建档动作：
1. 标记原因为"接受 counter-offer 留下"（区别于"薪资不匹配"/"另有选择"）
2. 记录 counter-offer 内容（加薪幅度/换岗承诺）
3. 标注**预计回流窗口**（留下后 6-12 个月）
4. 到期前 2 周轻量触达："X 总，上次聊完之后半年多了，那边承诺的调整落地了吗？"

> 数据支撑：接受 counter-offer 后留存过 12 个月仅 **29%** → 这个池子的转化率远高于普通冷触达。

### 六、在推荐报告中的落点

`offer_negotiation` 任务须输出「**Counter-Offer 风险预判与应对**」小节：
- 风险等级（高/中/低）+ 判断依据
- 客户公司历史挽留惯例（若已知）
- 应对方案：预防针话术 + 离职理由清单 + 长期激励替代 base 的空间
- 若预判为高风险：建议 offer letter 当天发出 + 背调并行 + 离职会议当天接应
