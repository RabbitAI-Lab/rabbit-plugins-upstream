# 推荐报告 v3 升级模块（2026-09-05 新增）

> 核心升级：从"匹配 JD"到"反推岗位真实任务"，附带薪酬架构建议和风险预判

## 岗位任务反推法

不只看 JD 字面要求，反推这个岗位要解决的真实业务问题。

**示例：**
- JD 字面："8 年+ SRE 经验，Kubernetes 熟练"
- 真实任务："保证临床平台 99.9% SLA，支撑 50+ 医院、30+ 申办方的业务连续性"
- 推荐报告写法：候选人不是"会 K8s"，而是"在 XX 场景下保障过 XX SLA"

**反推公式：**
1. 看公司业务 → 技术/业务支撑了什么收入？
2. 看 JD 痛点 → 为什么现在招？前任出了什么问题？
3. 看团队规模 → 这个人要带几个人？汇报给谁？
4. 看薪酬区间 → 这个薪酬能招到什么级别的人？

## 薪酬架构建议栏（给客户 + 候选人各一份）

### 给候选人的薪酬建议
- **锚定区间**：市场基准的 60-75 分位
- **底线**：候选人当前总包的 +15-20%
- **可谈项**：股权/签字费/远程天数/培训预算/弹性工作
- **1-10 测试**："如果 10 分是完美 Offer，你现在打几分？差的那几分是什么？"

### 给客户的薪酬建议
- **市场基准**：同行业同级别薪酬分位
- **竞对薪酬**：目标公司的薪酬水平
- **挽留成本 vs 招聘成本**：现有候选人市场价值 vs 重新寻访成本（通常为年薪 50-150%）
- **非现金筹码**：股权、职级、汇报线、项目主导权

## 风险预判

每个推荐人选附带 1-2 个潜在风险点：

| 风险类型 | 信号 | 推荐报告写法 |
|---------|------|-------------|
| **稳定性风险** | 跳槽频繁/在职时间短 | "候选人过去 3 年有 2 段经历<2 年，建议面试中重点考察长期意向" |
| **技能断层** | 理论 OK 但缺实战场景 | "候选人有 K8s 认证，但生产环境规模待确认" |
| **文化适配** | 大公司→小公司的落差预期 | "候选人来自 5000 人企业，目标公司仅 50 人，需评估适应度" |
| **薪酬落差** | 期望高于预算 | "候选人期望比预算高 15%，但股权部分可能弥补" |
| **动机存疑** | 离职原因模糊 | "候选人未明确说明离开现公司的触发事件，建议深挖" |
