# headhunter-pro 核心指令模板

> 从 headhunter-pro SKILL.md v15.0 提取的可执行指令。

## 1. 任务路由逻辑

根据 `task_type` 分发到不同处理流程：

| task_type | 处理流程 | 核心输出 |
|---|---|---|
| `resume_screen` | 简历筛选 → JD 对标 → 9+1 评分 → 推荐结论 | 评分表 + 推荐/不推荐 |
| `write_recommendation` | 候选人画像 → 深度叙述 → 五段式报告 → 9+1 评分 | 完整推荐报告 |
| `generate_outreach` | 候选人类型识别 → 话术框架选择 → 个性化生成 | 触达话术 |
| `interview_assess` | BEI/STAR 框架 → 情景模拟设计 → 评分矩阵 | 面试评估表 |
| `client_manage` | 客户阶段识别 → 四阶段流程 → 关键动作建议 | 客户维护计划 |
| `talent_mapping` | 人才地图 → 三合一能力模型 → 季度更新 | 人才地图报告 |

**路由规则：**
1. 缺少 `candidate_info` 且 `task_type` 需要 → 停止执行，请求补充
2. 缺少 `job_description` 且 `task_type` 为 `resume_screen`/`write_recommendation` → 标注"无 JD，仅基于通用标准评估"
3. 输入字段缺失或冲突 → 识别并标注，不阻断但降低评分置信度

## 2. 9+1 维度评分执行步骤

**评分维度（9 维度 + 1 批判性思维）：**

1. **学历匹配度**（/10）— 学历层次、学校排名、专业相关性
2. **经验匹配度**（/10）— 工作年限、行业深度、规模适配
3. **技能重叠度**（/10）— 核心技能与 JD 要求的覆盖度
4. **行业相关性**（/10）— 过往行业与目标行业的迁移成本
5. **团队/管理匹配度**（/10）— 管理经验、团队规模、领导力
6. **文化适配度**（/10）— 价值观契合、工作风格、组织文化
7. **稳定性风险**（低/中/高）— 跳槽频率、空窗期、动机合理性
8. **薪资期望匹配**（/10）— 当前薪资与 JD 预算的差距
9. **垂直行业洞察**（/10）— 对目标行业的理解深度和趋势敏感度（v15.0 新增）
10. **批判性思维/适应性**（/10）— Korn Ferry 2026 #1 需求技能

**评分规则：**
- 每个维度单独评分后，计算加权综合分
- 稳定性风险为"高"时，综合评分自动下调 1 分
- 批判性思维低于 6/10 时，标注"需重点考察"
- 评分必须有明确的对标依据（JD 条款 vs 候选人履历）

## 3. 推荐报告五段式结构

**第一段：基本信息**
- 出生年月、性别、婚姻状况、所在地、学校情况、语言能力
- 仅当 Walter 提供时才写，没有则不写

**第二段：经历总结（职业亮点深度叙述 v3）**
- 围绕与职位最相关的 1-2 个职业阶段做深度叙述
- 不要罗列简历，要讲故事
- 体现核心贡献、业务影响和独特价值
- 总结最近三段工作经历

**第三段：求职动机深度分析**
- 使用 PMCC 模型（Probe→Match→Confirm→Close）
- 区分表面动机和真实动机
- 表面是"薪资"，真实可能是"发展空间受限"或"团队冲突"

**第四段：薪资情况**
- 基本薪资（国内：人民币）、年终奖、绩效、提成、年薪总额
- 期望薪资（XX% 增幅）

**第五段：9+1 维度评分**
- 全部 10 个维度逐一评分
- 综合评分
- 技术岗附加 GitHub Proof of Work 5 信号

## 4. 触达话术生成原则

**核心原则：**
- **不群发、不模板化** — 每条消息必须包含 1-2 个与候选人履历直接相关的个性化点
- **Hormozi 框架**：Hook（吸引注意）→ Story（建立信任）→ Offer（价值主张）→ CTA（明确行动）
- **三分法策略**：
  - 积极求职者 → 直接推职位，强调机会价值
  - 中间阶层⭐ → 重点战场，关注痛点（天花板、冲突、成长）
  - 锁定状态 → 不推销，建立关系，等待时机

**话术禁忌：**
- 不用"你好，我是猎头"开头的冷消息
- 不在第一条消息中要求简历
- 不用"我有一个绝佳机会"等陈词滥调
- 不在候选人刚入职<3 个月时触达

## 5. 面试评估 BEI/STAR 框架

**BEI（Behavioral Event Interview）：**
- 通过过去的真实行为预测未来表现
- 每个核心能力至少追问 1 个完整 STAR 事件

**STAR 框架：**
- **S**ituation — 当时的背景和挑战
- **T**ask — 需要完成的任务或目标
- **A**ction — 候选人采取的具体行动（重点）
- **R**esult — 最终结果和量化影响

**评估维度：**
- 技术能力 → 技术深度追问 + 编码/系统设计样本
- 领导力 → 团队管理场景 → 冲突解决 → 决策逻辑
- 商业意识 → 业务理解 → 战略思维 → 数据驱动
- 文化匹配 → 价值观 → 工作风格 → 团队融入
- 稳定性 → 离职动机 → 职业规划 → 长期意愿

**情景模拟设计：**
- 根据 JD 设计 2-3 个真实工作场景
- 评估候选人的即时反应、思考框架和解决方案质量

## 6. 6 个月入职护航时间表

| 阶段 | 时间 | 关注重点 | 回访频率 |
|---|---|---|---|
| 蜜月期 | 第 1-2 周 | 入职体验、期望对齐 | 第 3 天 + 第 10 天 |
| 适应期 | 第 3-4 周 | 团队融入、角色定位 | 每周 1 次 |
| 产出期 | 第 2-3 月 | 工作表现、目标达成 | 每 2 周 1 次 |
| 巩固期 | 第 4-6 月 | 长期发展、忠诚度评估 | 每月 1 次 |

**量化指标：**
- 入职 30 天：团队融入度 ≥ 7/10
- 入职 60 天：首次交付成果
- 入职 90 天：独立负责模块
- 入职 6 个月：稳定产出 + 明确发展路径

**风险预警信号：**
- 🔴 红色：连续 2 次未回复回访、明确表达不满、考虑离职
- 🟡 黄色：回复延迟、工作满意度下降、团队摩擦
- 🟢 绿色：主动分享进展、积极融入、认可公司文化

## 7. 客户维护四阶段流程

**阶段 1：破冰（0-3 个月）**
- 建立信任，理解客户痛点和决策链
- 交付首批高质量候选人（2-3 人短名单）
- 目标：获得首次合作机会

**阶段 2：验证（3-6 个月）**
- 通过首次交付质量证明能力
- 建立定期沟通机制（月度人才市场简报）
- 目标：客户主动分享更多职位

**阶段 3：扩展（6-12 个月）**
- 从单一职位到多部门合作
- 提供人才地图和行业洞察
- 目标：成为首选供应商

**阶段 4：战略伙伴（12 个月+）**
- 参与客户人才战略规划
- 提供继任规划、组织架构咨询
- 目标：独家合作 / 年度框架协议

**5 个关键动作：**
1. 月度人才市场简报（行业趋势 + 薪资数据）
2. 季度业务回顾（交付数据 + 改进建议）
3. 年度人才战略规划（继任规划 + 组织架构）
4. 非正式关系维护（行业活动 + 社交）
5. 价值延伸（薪酬咨询 + 市场对标）

## 8. Purple Squirrel 管理流程

**Purple Squirrel = 市场上极难找到的理想候选人（<1% 候选人库）**

**识别标准：**
- JD 要求 8+ 项硬性条件，同时满足 ≥7 项
- 行业经验 + 技术栈 + 管理经验的罕见组合
- 地域 + 薪资预算进一步缩小范围

**管理策略：**
1. **调整期望**：与客户沟通"完美候选人"不存在，区分 Must-have vs Nice-to-have
2. **扩大搜索**：跨行业、跨地域、跨职级寻找
3. **培养策略**：寻找满足 60-70% 条件的高潜候选人 + 入职培养计划
4. **人才地图**：建立完整目标人才库，标注每个候选人的差距项
5. **长期追踪**：Purple Squirrel 可能需要 6-12 个月培养窗口

## 9. Talent Gap Analysis 四步法

**Step 1：业务诊断（Business Diagnosis）**
- 理解客户业务目标、增长/收缩趋势、战略方向
- 识别组织当前的人才瓶颈和业务痛点
- 交付物：业务背景分析

**Step 2：岗位必要性评估（Role Necessity Assessment）**
- 评估 JD 中的每个要求是否真正必要
- 区分 Must-have（不做不行）和 Nice-to-have（有更好）
- 识别"假 JD"（客户不知道自己要什么）

**Step 3：人才差距分析（Talent Gap Analysis）**
- 对比市场人才供给 vs JD 需求
- 量化差距：技能缺口、经验缺口、地域缺口、薪资缺口
- 提供市场数据支撑（薪资基准、人才密度、竞争格局）

**Step 4：人才画像共建（Co-create Success Profile）**
- 与 Hiring Manager 共同定义"成功候选人"画像
- 基于前 3 步的分析，调整 JD 使其与市场匹配
- 交付物：Talent Gap Analysis Report
