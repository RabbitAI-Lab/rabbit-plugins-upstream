# 期望行为 — Conflicting Input

## 场景
`task_type` 为 `resume_screen`，但候选人与 JD 存在严重不匹配：
- 候选人经验：3 年，初级工程师
- JD 要求：10 年+经验，5 年管理经验，总监级

经验差距：3 年 vs 10 年（差距 70%）
管理差距：0 年 vs 5 年

```
**短期（1-2 年）：不可行**
- 差距过大，无法通过短期培养弥补

**中期（3-5 年）：可能可行**
- 如果候选人成长迅速，可关注其发展轨迹
- 建议：
  1. 保持联系，每 6-12 个月跟进一次
  2. 观察其职业发展速度和潜力
  3. 如有中级/高级职位机会可优先考虑

**建议**：不推荐当前提交，但可纳入人才库长期追踪。
```

## 验证要点

1. **不因不匹配而拒绝执行**：即使候选人明显不合格，仍应输出完整评估
2. **客观评分**：基于事实给出低分，不主观贬低候选人
3. **明确标注不推荐**：结论清晰，不模糊
4. **提供培养建议**：指出是否有培养潜力和具体建议
5. **标注信息不足**：对于缺失的维度，标注 N/A 而非编造分数
6. **不编造缺失信息**：教育背景、技能等缺失字段不能猜测
