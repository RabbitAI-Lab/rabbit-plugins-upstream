## Description:

【构建 AI Agent 实战指南】把 OpenAI《A Practical Guide to Building Agents》蒸馏成可执行的 Agent 设计方法论，覆盖判断是否该建 Agent、Agent 三组件、模型选型、工具设计、instructions、编排模式、Guardrails 与 human-in-the-loop。

## Use Case:

Developers and engineers use this skill to decide whether an AI agent is appropriate and to design agent components, tools, instructions, orchestration, guardrails, and human-review paths. It is guidance-oriented and helps turn agent requirements into practical architecture decisions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Architecture guidance can be applied to systems that take sensitive or irreversible actions.

Mitigation: Review generated designs against the deploying organization's security, authorization, access-control, and human-review requirements before implementation.

Risk: The skill provides methodology rather than executable enforcement of guardrails.

Mitigation: Implement and test concrete guardrails, permissions, and human-in-the-loop controls in the target agent system.
