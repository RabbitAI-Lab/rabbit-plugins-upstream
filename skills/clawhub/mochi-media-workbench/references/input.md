# Job contract

Every JSON job is <=1 MiB and includes requestId (1..80 ASCII letters, numbers, hyphens or underscores). Identical retries reuse verified results. A changed job/source needs a fresh requestId.

file: one workspace-local mp4/mkv/mov/webm/mp3/wav/m4a/flac/ogg/aac, <=1 GiB and known duration <=4 hours. action inspect|extract-audio|clips|frames|subtitles|transcribe|package. clips:[{start,end}] seconds, 1..20, 0<=start<end<=source duration. frames:[seconds], 1..40, within source duration minus0.05. package may combine clips,frames,segmentsFile,extractAudio:true. segmentsFile: JSON <=5MiB, array or {segments:[{start,end,text}]}; <=30000 entries, finite seconds, sorted start, positive duration, <=5000characters each, no --> in text. transcribe: model tiny|base|small(defaulttiny), language optional en/zh/etc, threads1..8(default2), allowModelDownload boolean(defaultfalse), modelPath optional workspace-local converted Whisper folder containing model.bin/config.json/tokenizer.json/vocabulary.txt; each <=750MiB. CPU/int8; chunk300seconds. Models and chunk caches are workspace-local. Output audio.wav, clips, frames, previews, SRT/VTT, transcript.json/md and manifest as appropriate. package includes results.zip; subtitle clips have their own time-offset sidecars. Source SHA256 and output SHA256 included.
