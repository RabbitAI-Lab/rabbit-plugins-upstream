Mitigation: Prefer explicit invocation by skill name and review activation settings before relying on implicit invocation. <br>
Risk: Workflow, checklist, analysis, or code guidance may be context-dependent. <br>
Mitigation: Review assumptions, validate outputs against the stated success criteria, and scan any generated code or commands before use. <br>
