# 裁判文书 — 程序性知识

> **Unbook Skill**：资深法官的思维过程，不是模板，是"怎么想"。
> 参考 Anthropic：skill 是 procedural knowledge，sources of truth 是 declarative knowledge。

## 资深法官的思维框架

### 第一步：拿到案件后的"三问"

在动笔之前，资深法官会先在脑中回答三个问题：

1. **这个案件的核心法律关系是什么？**
   - 不是案由名称，而是底层的民事权利义务关系
   - 例：名为买卖实为借贷 → 按借贷纠纷处理
   - 例：名为租赁实为担保 → 按担保纠纷处理

2. **双方真正争的是什么？**
   - 表面争议 vs 实质争议
   - 例：表面上争利息金额，实质上争合同是否成立
   - 例：表面上争赔偿数额，实质上争因果关系是否成立

3. **这个案件的"典型性"在哪？**
   - 是常规案件还是新类型案件？
   - 有没有入库案例可参照？
   - 判决结果对同类案件有什么示范效应？

### 第二步：事实认定的"证据链思维"

资深法官不是"看到什么认定什么"，而是**用证据链条还原事实**：

```
证据A（借条）──→ 证明借贷合意
    │
证据B（转账记录）──→ 证明款项交付
    │
证据C（还款记录）──→ 证明还款事实
    │
三者结合 ──→ 完整的借贷法律关系
```

**关键原则**：
- 单一证据不够，需要**多证据交叉验证**
- 间接证据需要形成**完整证据链**
- 当事人陈述与证据矛盾时，**以证据为准**
- 证据不足的部分，**按举证责任分配**（谁主张谁举证）

### 第三步：法律适用的"三段论推演"

这是裁判文书的核心逻辑：

```
大前提（法律规范）
  ↓ 具体条文 + 构成要件
小前提（案件事实）
  ↓ 事实认定 + 证据支持
结论（裁判结果）
  ↓ 判决主文
```

**常见错误**：
- ❌ 大前提不准确：引用已废止的法条
- ❌ 小前提不充分：事实认定缺乏证据支持
- ❌ 跳跃推理：从事实直接到结论，缺少法律适用的论证
- ❌ 以偏概全：只论证了部分要件，遗漏其他要件

### 第四步：说理的"层层递进法"

说理不能"一锅端"，要**逐层展开**：

```
第一层：争议焦点归纳
  "本案的争议焦点为：1.合同是否有效；2.违约责任如何承担"

第二层：逐项分析
  "关于焦点一（合同效力）：
   根据《民法典》第XXX条……
   本案中……（事实认定）
   因此……（结论）"

第三层：综合论证
  "综上所述，……"

第四层：判决结论
  "判决如下：……"
```

### 第五步：文字的"减法原则"

好文书不是写得多，而是**每句话都有存在意义**：

- **删**：删除不提供新信息的重复表述
- **精**：用一个精准词替代三个模糊词
- **直**：结论前置，不绕弯子
- **稳**：语气平和，不煽情不冷漠

## 案由特有的思维模式

### 民间借贷纠纷
**核心思维链**：借贷合意 → 款项交付 → 利息约定 → 还款事实 → 担保责任
**常见陷阱**：
- 虚假诉讼（虚构债务）→ 审查资金来源、交易习惯
- 砍头息（预扣利息）→ 按实际交付认定本金
- 高利贷（超过LPR 4倍）→ 超出部分不予保护

### 买卖合同纠纷
**核心思维链**：合同签订 → 标的物 → 价款 → 交付 → 验收 → 违约
**常见陷阱**：
- 质量争议 → 审查验收标准、检验期间
- 风险转移 → 交付时转移（除非另有约定）
- 违约金过高 → 以实际损失为基础调整

### 劳动合同纠纷
**核心思维链**：劳动关系 → 工资 → 工时 → 社保 → 解除/终止
**常见陷阱**：
- 未签劳动合同 → 双倍工资差额
- 违法解除 → 赔偿金 = 2×经济补偿
- 加班工资 → 审查考勤记录、加班审批

### 交通事故责任纠纷
**核心思维链**：事故经过 → 责任划分 → 损害赔偿 → 保险理赔
**常见陷阱**：
- 多车事故 → 按责任比例分别赔偿
- 交强险限额 → 先由交强险赔偿，不足部分按责任比例
- 精神损害抚慰金 → 伤残等级越高，金额越高

## 对抗性思维（Adversarial Thinking）

资深法官在写判决书时，会**主动设想对方可能的反驳**：

```
我方认定：合同有效
├─ 对方可能反驳：合同无效（欺诈/胁迫/显失公平）
│   └─ 我方回应：逐一分析无效事由不成立的理由
│
我方认定：违约责任成立
├─ 对方可能反驳：不可抗力/情势变更
│   └─ 我方回应：分析为何不构成免责事由
│
我方认定：赔偿金额X元
├─ 对方可能反驳：金额过高
│   └─ 我方回应：以实际损失为基础，说明计算依据
```

**这就是为什么对抗性审查（adversarial review）如此重要**——同一个 agent 做两件事会自我审查，漏掉真阳性。

## 常见错误模式（从形与神146个案例中提炼）

| 错误模式 | 表现 | 修正方法 |
|---------|------|----------|
| **说理空洞** | "依法应当支持"而不展开 | 每个法律适用都要有论证过程 |
| **事实遗漏** | 对裁判结果有影响的事实未认定 | 逐一对照诉讼请求检查 |
| **逻辑跳跃** | 从事实直接到结论，缺少法律适用 | 补充三段论的"大前提"环节 |
| **法条错误** | 引用已废止的法条 | 用 scripts/law_checker.py 核查 |
| **焦点遗漏** | 未回应被告的抗辩意见 | 逐一分析各方诉辩意见 |
| **文字冗余** | 同一意思反复表述 | 执行"减法原则" |
