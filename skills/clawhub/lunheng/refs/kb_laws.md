# 法律法规 — 参考文档

> **LLM-friendly reference doc**：为 agent 法条检索设计。
> 核心原则：法条必须是**现行有效版本**，已废止的绝不援引。

## Quick Reference

### Business Context
法律法规是裁判文书的"大前提"。引用法条必须：全称+书名号+精确到条+款+项。新旧法衔接是最高频错误源。

### Entity Grain
一条法条引用 = 法律名称 + 条号 + 款号 + 项号。

### Standard Hygiene Filter
- 必须确认法条**现行有效**（已修订/已废止的排除）
- 注意新旧法衔接（如民法典施行后原合同法已废止）
- 引用格式：《法律名称》第X条第X款第X项

## 司法解释速查

### 最高人民法院关于审理民间借贷案件适用法律若干问题的规定（2020年修正）
- **利率保护上限**：以一年期LPR的4倍为标准
- **砍头息**：预先在本金中扣除的，按实际交付认定本金
- **虚假诉讼**：严格审查借贷关系的真实性

### 最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）（2021年）
- **实际施工人**：可以发包人为被告主张权利
- **工程价款优先受偿权**：优于抵押权

## Gotchas

- **民法典与旧法衔接**：2021年1月1日后，原《合同法》《物权法》《侵权责任法》等9部法律废止
- **司法解释的效力**：司法解释不是法律，但具有普遍约束力
- **地方性法规**：只在本行政区域内有效
- **新法优于旧法**：同一事项新旧法规定不一致时，适用新法
