## 百篇优秀裁判文书范式库

### 数据来源

最高人民法院第一届至第八届"全国法院百篇优秀裁判文书"评选（2019-2026），共 700+ 篇获奖文书。

### 使用方法

**起草文书时**：
1. 先查「快速索引.md」定位同类获奖文书
2. 参考其说理结构和论证方法
3. 运用「写作风格规范.md」中的写作要点

**审查文书时**：
1. 对照「写作风格规范.md」逐项检查
2. 重点审查说理深度和事实认定
3. 确保无扣分项

**学习提升时**：
1. 研读获奖法官的撰写心得（见《形与神》系列）
2. 分析高频获奖法官（如魏海、王亦非、费汉定）的裁判思路
3. 积累优秀表达方式

### 海南法院获奖记录

海南法院共获奖 **14 篇**（刑事1、民事6、行政6、海事1），覆盖海南高院、海口海事法院、海南第一中级人民法院、海南自贸港知识产权法院。

## 《形与神》优秀文书范式库

### 数据来源

《双百优秀裁判文书的形与神：裁判思路与说理技巧》（最高人民法院审判管理办公室编），共4卷：

| 卷册 | 标识 | 页数 | 案例数 |
|------|------|------|--------|
| 民事卷 | civil | 460 | 42 |
| 刑事卷 | criminal | 284 | 25 |
| 商事/海事/知识产权卷 | commercial | 460 | 49 |
| 行政/国家赔偿/执行卷 | administrative | 356 | 30 |

**总计**: 1578页，146个获奖案例（含撰写心得+专家评析）

### 使用方法

```bash
# 列出所有案例
python3 scripts/shape_spirit_index.py list [volume]

# 按案由搜索
python3 scripts/shape_spirit_index.py cause <案由> [volume]

# 查看案例详情
python3 scripts/shape_spirit_index.py case <volume> <num>

# 查看撰写心得
python3 scripts/shape_spirit_index.py tips [volume]
```

### 撰写心得精华

从146个案例中提炼的核心写作原则：

1. **事实认定**：以证据为基础，用证据拼出案件事实
2. **争议焦点**：准确归纳，切中要害，像花瓣一样绽放
3. **说理论证**：层层递进，逻辑严密，不跳跃
4. **文字表达**：准确、精炼、有温度
5. **格式规范**：外在形式严谨，内容紧凑
