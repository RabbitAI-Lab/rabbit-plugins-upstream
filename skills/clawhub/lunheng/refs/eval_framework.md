## 评分标准

### 准确率计算
```
accuracy = correct_predictions / total_predictions
```

### 分级标准
| 等级 | 准确率 | 说明 |
|------|--------|------|
| A | ≥95% | 可以放心使用 |
| B | 90-95% | 基本可用，需人工复核关键部分 |
| C | 80-90% | 需要人工指导 |
| D | <80% | 需要大幅改进 |

## 维护规则

1. **每次 skill 更新后**：跑一轮 eval，确认准确率不下降
2. **每月**：补充新的 eval case（从用户反馈中提取）
3. **每季度**：清理过时的 eval case（法律变化导致）
4. **锚定真相**：每个 eval 都绑定到快照日期或稳定事实表，避免漂移
