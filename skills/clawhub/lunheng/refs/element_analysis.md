# 要素式起诉状/答辩状分析

> 当用户提供了要素式起诉状或答辩状时，按此文档进行解析。

## 背景

最高人民法院推行民事诉讼文书样式改革，当事人需提交**要素式起诉状和答辩状**。
要素式文书将案件事实分解为结构化要素字段，便于法院快速查明事实。

**模板位置**：`<workspace>/brain/motor-cortex/法律文书工作成果/起诉状答辩状示范文本.pdf`
**覆盖范围**：67种案件类型，按9大领域分类

## 要素式起诉状结构（以民间借贷为例）

```
当事人信息（表格化）
  ├─ 原告（自然人/法人）：姓名、性别、出生日期
  ├─ 被告（自然人/法人）：同上
  └─ 第三人（如有）
─────────────────────────────
诉讼请求（要素式表格）
  ├─ 1. 本金：尚欠本金金额
  ├─ 2. 利息：截至日期 + 金额 + 计算方式
  ├─ 3. 是否提前还款/解除合同
  ├─ 4. 是否主张担保权利
  ├─ 5. 是否主张实现债权费用
  ├─ 6. 是否主张诉讼费用
  ├─ 7. 其他请求
  └─ 8. 标的总额
─────────────────────────────
事实与理由（要素式表格）
  ├─ 1-9. 合同签订→金额→期限→利率→交付→还款→逾期
  ├─ 10-15. 担保相关（抵押/质押/保证）
  ├─ 16. 其他需要说明的内容
  ├─ 17. 请求依据（合同约定 + 法律规定）
  └─ 18. 证据清单
```

## 从要素式文书提取裁判信息

### 步骤 1：结构化解析

```python
case_info = {
    "当事人": {
        "原告": {"姓名": "", "类型": "自然人/法人", "身份信息": ""},
        "被告": {"姓名": "", "类型": "自然人/法人", "身份信息": ""},
        "第三人": "无/有（详情）"
    },
    "案由": "",
    "诉讼请求": [],
    "要素事实": {
        "核心要素": {},
        "担保要素": {},
        "违约要素": {},
    },
    "证据清单": [],
    "法律依据": [],
    "答辩要点": []
}
```

### 步骤 2：争议焦点识别

| 焦点类型 | 识别方法 | 示例 |
|----------|----------|------|
| **事实争议** | 原告主张 vs 被告否认 | "借款金额：原告主张10万，被告否认仅收到8万" |
| **法律争议** | 法律适用分歧 | "利率标准：原告主张年利率24%，被告主张应按LPR" |
| **程序争议** | 管辖、时效等 | "已过诉讼时效" |
| **数额争议** | 计算方式分歧 | "利息计算基数、起止时间、利率标准" |

### 步骤 3：要素→裁判文书映射

| 要素式起诉状部分 | 判决书对应部分 | 注意事项 |
|------------------|----------------|----------|
| 当事人信息 | 首部（当事人列明） | 核实身份信息准确性 |
| 诉讼请求 | 判项（判决主文） | 逐一回应，不遗漏 |
| 事实与理由要素 | 事实认定部分 | 按要素逐一审查认定 |
| 证据清单 | 证据认证部分 | 逐项质证分析 |
| 法律依据 | 本院认为部分 | 引用准确、完整 |
| 答辩要点 | 本院认为部分（被告抗辩） | 逐一回应被告抗辩 |

### 步骤 4：遗漏要素检查

**关键检查**：判决书是否遗漏了起诉状/答辩状中的重要要素？
- 要素式起诉状中的**每个实质要素**，判决书都应当在事实认定或说理部分予以回应
- 如有遗漏，需在审查意见中指出
- 要素之间的**递进/并列关系**需在说理中体现（如：本金→利息→担保是递进关系）

### 特殊案由处理（模板未覆盖的案由）

1. 参照最接近的模板结构
2. 自行构建要素框架（根据法律构成要件）
3. 通用要素提取规则：当事人→诉讼请求→争议标的→法律关系→损害/损失→因果关系→证据→法律依据
