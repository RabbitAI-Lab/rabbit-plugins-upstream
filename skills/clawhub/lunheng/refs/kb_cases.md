# 入库案例 — 参考文档

> **LLM-friendly reference doc**：为 agent 检索设计，非人类阅读。
> 参考 Anthropic reference doc 模板：grain + scope + gotchas + routing triggers。

## Quick Reference

### Business Context
人民法院入库案例是最高法院公布的指导案例、公报案例及参考案例，用于统一法律适用、实现同案同判。**起草文书前必须检索类案，确保裁判结论与入库案例一致。**

### Entity Grain
一行 = 一个入库案例，包含：案例标题、裁判要点、基本案情、裁判结果、法院名称。

### Standard Hygiene Filter
检索时必须过滤：
- 民事/商事案件排除"检例"开头的检察院案例（对民事判决参考价值低）
- 关注裁判要点而非全文细节
- 注意案例编号格式：`YYYY-N-N-NNN-NNN`

## 检索策略

### 关键词构造
- **主关键词**：案由名称（如"民间借贷"）
- **辅助关键词**：核心争议焦点（如"利率""砍头息"）
- **同义词扩展**：法律术语 ↔ 通俗表达（如"借贷合意" ↔ "借钱约定"）

### 检索顺序
1. 精确匹配：案由 + 争议焦点
2. 模糊匹配：案由 + 法律问题
3. 扩展检索：相关案由

### 结果筛选
- 优先参考最高法院、高级法院的入库案例
- 关注裁判要点中的法律适用规则
- 注意案例的时效性（民法典施行后的案例优先）

## Gotchas

- **入库案例≠必然正确**：它是参考而非约束，如有充分理由可以不遵循（但必须说明理由）
- **注意案例的时效性**：旧案例可能引用已废止的法条
- **注意地域差异**：不同地区的裁判尺度可能有差异
- **注意案例类型**：刑事案件的入库案例对民事判决参考价值有限
