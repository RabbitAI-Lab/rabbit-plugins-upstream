# 优秀文书 — 参考文档

> **LLM-friendly reference doc**：为 agent 写作范式检索设计。
> 来源：全国法院百篇优秀裁判文书（700+篇）+ 《形与神》系列（146个案例）。

## Quick Reference

### Business Context
优秀文书是裁判文书写作的"最高标准"。不是模板，是**说理方式和论证结构的范式库**。起草/审查文书时参照，提升说理深度和文字质量。

### Entity Grain
一篇获奖文书 = 法院名称 + 案由 + 法官姓名 + 获奖届次 + 写作经验 + 专家评析。

### Standard Hygiene Filter
- 优先参考同类案由的获奖文书
- 关注说理结构（怎么论证）而非具体内容（什么案件）
- 参考撰写心得中的写作技巧

## 写作范式库

### 说理结构范式

**范式 A：递进式说理**（最常用）
```
争议焦点归纳
  → 法律规范引用
    → 构成要件分析
      → 事实认定
        → 结论
```
适用：绝大多数民事案件

**范式 B：并列式说理**
```
争议焦点一 → 分析 → 结论
争议焦点二 → 分析 → 结论
争议焦点三 → 分析 → 结论
  → 综合结论
```
适用：多争议焦点的复杂案件

**范式 C：对比式说理**
```
原告主张 → 分析 → 采纳/不采纳
被告抗辩 → 分析 → 采纳/不采纳
  → 法院认定
```
适用：双方争议激烈的案件

### 文字表达范式

**精准用词**：
- ❌ "被告应当赔偿原告的损失" → ✅ "被告应赔偿原告医疗费32,450元、误工费8,600元"
- ❌ "合同无效" → ✅ "案涉合同违反法律、行政法规的强制性规定，应属无效"

**中正语气**：
- ❌ "被告的辩解毫无道理" → ✅ "被告的抗辩理由缺乏事实和法律依据，本院不予采纳"
- ❌ "原告的请求完全合理" → ✅ "原告的诉讼请求于法有据，本院予以支持"

**有温度**：
- 在法律框架内体现人文关怀（如未成年人保护、老人赡养等案件）

## 撰写心得精华（从146个案例提炼）

1. **事实认定**：以证据为基础，用证据拼出案件事实
2. **争议焦点**：准确归纳，切中要害，像花瓣一样绽放
3. **说理论证**：层层递进，逻辑严密，不跳跃
4. **文字表达**：准确、精炼、有温度
5. **格式规范**：外在形式严谨，内容紧凑
