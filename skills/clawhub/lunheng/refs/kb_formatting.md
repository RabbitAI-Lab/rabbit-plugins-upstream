# 文书格式规范 — 参考文档

> 来源：《人民法院民事裁判文书制作规范》（法〔2016〕221号）

## Quick Reference

### Entity Grain
一份判决书 = 首部 + 当事人 + 案由 + 诉讼请求 + 事实认定 + 证据 + 本院认为 + 判决主文 + 尾部。

### 标准 Hygiene Filter
- 字体：正文仿宋三号（16pt），标题方正小标宋二号（22pt）
- 行距：固定值28pt
- 页边距：上3.7cm 下3.5cm 左2.8cm 右2.6cm

## 结构规范

### 首部
- 法院名称：全称，居中
- 文书类型：居中（如"民事判决书"）
- 案号：括号内年份+法院简称+案件类型+编号

### 当事人
- 按原告、被告、第三人顺序排列
- 自然人：姓名、性别、出生年月日（汉字）、民族、职业/工作单位、住所
- 法人：名称、住所地、法定代表人

### 事实部分
按以下顺序：
1. 诉称（原告主张）
2. 辩称（被告抗辩）
3. 举证质证
4. 法院认定

### 理由部分
- 争议焦点归纳
- 逐项分析
- 法条原文引用
- 结论

### 判项
- 明确、具体、便于执行
- 利息：写明起止点+计息本金+利率
- 多项判决：按主次排列

### 尾部
- 审判长 + 审判员 + 人民陪审员（合议庭）
- 日期：汉字数字
- 附：诉讼费用承担

## 数字用法

- 案号中的序号：汉字数字
- 案号中的年份：阿拉伯数字
- 金额：阿拉伯数字+单位（元/万元）
- 日期：汉字数字（二〇二六年六月四日）
