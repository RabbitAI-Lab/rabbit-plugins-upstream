# IMA 类案检索

> 每次起草文书前，必须先检索类案。审查文书时，若裁判结论可能与入库案例不一致，也需检索确认。

## 知识库信息

- **知识库名称**：人民法院入库案例全库
- **知识库 ID**：`gX9KQdefz9I8y0r-ki16B2uJ_1Il_841ytJ2OGwaplc=`
- **内容**：最高院公布的指导案例、公报案例及参考案例全部（7700+ 条）
- **更新频率**：定期同步最高院最新入库案例

## 检索步骤

### 1. 构造检索词

以案由名称为主关键词，核心争议焦点为辅助关键词。
- 示例："民间借贷 利率"、"外嫁女 集体经济组织成员"
- 优先使用法律术语，避免口语化表达

### 2. 调用 IMA 搜索 API

```
IMA 接口：openapi/wiki/v1/search_knowledge
参数：
  - knowledge_base_id: "gX9KQdefz9I8y0r-ki16B2uJ_1Il_841ytJ2OGwaplc="
  - query: "<检索词>"
  - cursor: ""（首次请求）
注意：不走代理（unset HTTP_PROXY HTTPS_PROXY），ima.qq.com 直连更快
```

### 3. 分析检索结果

- 关注 `highlight_content` 字段中的匹配片段
- 提取裁判要点、法律适用、裁判结果
- 评估与当前案件的关联度

### 4. 将类案结论融入文书

- 在"本院认为"部分引用入库案例的裁判要点
- 确保裁判结论与入库案例保持一致
- 如存在差异，必须说明理由（如案件事实有本质区别）

## 检索注意事项

- **不要仅搜一次**：如首次检索结果不相关，尝试变换关键词（同义词、法律术语 vs 通俗表达）再搜
- **关注裁判要点而非全文**：入库案例的核心价值在于裁判要点，而非案件细节
- **注意案例编号格式**：入库案例编号以"YYYY-N-N-NNN-NNN"格式标识
- **如检索无结果**：说明当前案由可能尚无入库案例，按正常三段论流程起草，但在文书中注明适当表述
