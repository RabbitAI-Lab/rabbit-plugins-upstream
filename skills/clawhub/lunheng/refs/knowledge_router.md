# 论衡 — 知识路由器

> **Knowledge Skill**：薄路由器，按需加载领域知识。
> 参考 Anthropic "pairwise skills" 模式：knowledge router + procedural unbook。

## 前置检查（每次激活必须）

在路由任何问题之前，先执行前置检查：

```
检查 practice_profile.md 是否存在
  ├─ 不存在 → 提示："运行冷启动访谈以获得个性化配置"
  │          → 进入 Provisional 模式（使用默认值）
  └─ 存在 → 检查是否包含 [PLACEHOLDER] 标记
       ├─ 包含 → 进入 Provisional 模式
       └─ 不包含 → 读取配置，正常执行
```

**Provisional 模式**：未配置时使用以下默认值：
- 文书风格：详尽型
- 事实查明：重点突出
- 说理深度：混合型
- 法条核查：标准
- 审查严格度：标准
- 检索策略：平衡

## 路由逻辑

当用户提出法律问题时，**先判断问题类型**，再按路由表加载对应知识：

### 路由表

| 问题类型 | 关键词触发 | 路由目标 | 优先级 |
|----------|-----------|---------|--------|
| **配置/设置** | 配置、设置、偏好、习惯、风格 | → `practice_profile.md` | P0 |
| **冷启动访谈** | 开始设置、首次使用、初始化 | → `cold_start_interview.md` | P0 |
| **起草文书** | 写判决书、起草、撰写、帮我写 | → `SKILL.md` §起草文书流程 | P0 |
| **审查文书** | 审查、检查、修改、润色、改一下 | → `SKILL.md` §审查文书流程 | P0 |
| **类案检索** | 类似案例、同案、判例、入库案例 | → `SKILL.md` §IMA 类案检索 | P0 |
| **法条查询** | 哪条法律、法条、法律规定、依据 | → `refs/laws/` 领域法条参考 | P1 |
| **案由知识** | XX纠纷怎么判、案由、构成要件 | → `refs/causes/` 案由参考文档 | P1 |
| **写作范式** | 优秀文书、获奖、说理技巧、怎么写 | → `refs/writing/` 写作范式参考 | P1 |
| **文书格式** | 格式、排版、结构、字体、字号 | → `refs/formatting/` 格式规范参考 | P2 |
| **费用计算** | 诉讼费、受理费、交多少钱 | → `scripts/fee_calculator.py` | P2 |
| **要素式文书** | 要素式、起诉状、答辩状、模板 | → `SKILL.md` §要素式文书分析 | P1 |

### 路由决策流程

```
用户问题
  │
  ├─ 包含文书内容（判决书/裁定书文本）？
  │   └─ YES → 审查流程（SKILL.md §审查文书）
  │
  ├─ 要求起草/生成？
  │   └─ YES → 起草流程（SKILL.md §起草文书）
  │
  ├─ 要求检索/查找？
  │   ├─ 类案 → IMA 类案检索
  │   ├─ 法条 → refs/laws/
  │   └─ 范式 → refs/writing/
  │
  ├─ 询问知识/怎么做？
  │   ├─ 案由 → refs/causes/
  │   ├─ 格式 → refs/formatting/
  │   └─ 通用 → 加载 procedural knowledge
  │
  └─ 其他 → 加载 procedural knowledge + 通用回答
```

## 知识库边界（Canonical Datasets）

### 三个知识库的职责

| 知识库 | 职责 | 何时用 | 何时不用 |
|--------|------|--------|----------|
| **入库案例** (IMA KB) | 同案同判的权威参考 | 起草前检索类案、审查时对比 | 不用于法条查询 |
| **法律法规** (IMA KB) | 现行有效的法律规范 | 确认法条引用、新旧法衔接 | 不用于案例分析 |
| **优秀文书** (本地形与神) | 写作范式和说理技巧 | 学习说理方式、优化文字表达 | 不用于法律适用 |

### 边界规则

1. **不混用**：入库案例不替代法条引用，优秀文书不替代入库案例
2. **不重复**：同一信息只在一个知识库中维护
3. **有层级**：语义层（结构化模板）> 参考文档（LLM 可检索）> 原始数据（PDF/JSON）
