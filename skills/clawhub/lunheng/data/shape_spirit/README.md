# 《双百优秀裁判文书的形与神》结构化数据

## 数据来源

本目录下的结构化数据（`*.json`）由项目作者通过对以下出版物进行阅读、分析和整理而成：

**《双百优秀裁判文书的形与神：裁判思路与说理技巧》**
- 最高人民法院审判管理办公室 编
- 人民法院出版社 出版
- 共 4 卷：民事卷、商事·海事海商·知识产权卷、刑事卷、行政·国家赔偿·执行卷
- 收录第一至第三届全国法院"百篇优秀裁判文书"获奖作品

## 数据结构

### 索引 (`index.json`)
- 总案例数统计
- 各卷案例数量

### 卷册数据 (`civil.json`, `criminal.json`, `commercial.json`, `administrative.json`)
每个案例包含：
| 字段 | 说明 |
|------|------|
| `num` | 案例编号 |
| `title` | 案例标题（公开裁判文书案号） |
| `keywords` | 提炼的关键词 |
| `brief_facts` | 案情摘要（原创整理） |
| `writing_experience` | 撰写心得总结（原创提炼） |
| `expert_analysis` | 专家评析摘要（原创提炼） |

## 版权声明
