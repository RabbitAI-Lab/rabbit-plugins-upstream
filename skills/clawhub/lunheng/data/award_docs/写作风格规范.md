# 百篇优秀裁判文书 — 写作风格规范

> **来源**：最高人民法院第一届至第八届"全国法院百篇优秀裁判文书"评选（2019-2026）
> **提炼日期**：2026-05-28
> **用途**：作为裁判文书写作的最高标准参考

## 一、总体特征

历届获奖文书共 700+ 篇，覆盖刑事、民事、行政（赔偿）、执行四大类别。经分析，获奖文书呈现以下共性特征：

### 1. 说理深度
- **不以"依法"二字了事**：每一个法律适用都有详细的论证过程
- **层层递进**：从法律规范→构成要件→事实认定→结论，环环相扣
- **回应各方诉辩意见**：逐一分析，不回避、不遗漏

### 2. 事实认定
- **以证据为基础**：用证据链条还原事实，而非主观推断
- **关键事实不遗漏**：对裁判结果有实质影响的事实均需认定
- **证据认证充分**：对每份关键证据的证明力进行分析

### 3. 文字表达
- **精准**：法律术语准确，无歧义
- **精炼**：每句话都有存在意义，无冗余
- **中正**：不冷漠、不煽情，平和而有力
- **有温度**：在法律框架内体现人文关怀

## 二、分类写作要点

### 民事类（约 400 篇）

**核心要点**：
- 注重当事人意思自治的尊重
- 合同解释需结合文义、目的、交易习惯
- 证据规则运用准确（举证责任分配、证明标准）
- 损害赔偿计算有明确依据

**高频获奖法院**：最高法、江苏高院、广东高院、上海高院、浙江高院

**代表性法官**：王亦非（浙江）、费汉定（广东）、何琼（浙江）、龚雪林（江西）

### 刑事类（约 180 篇）

**核心要点**：
- 死刑复核裁定书说理尤为详尽
- 犯罪构成要件逐一论证
- 量刑情节分析到位（自首、立功、累犯等）
- 证据链完整性审查严格

**高频获奖法院**：最高法、广东高院、江苏高院、河北高院

**代表性法官**：魏海（广东，多届获奖）、仇晓敏（最高法）、蔡智玉（河南）

### 行政（赔偿）类（约 140 篇）

**核心要点**：
- 行为合法性审查标准明确
- 程序合法性与实体合法性并重
- 国家赔偿计算精准
- 行政机关举证责任分析充分

**高频获奖法院**：最高法、江苏高院、湖南高院、重庆高院

**代表性法官**：李纬华（最高法）、马小莉（陕西）、蒋先华（广东执行）

### 执行类（约 20 篇）

**核心要点**：
- 执行异议审查标准明确
- 财产处置程序合法性
- 权益平衡（申请执行人 vs 案外人）

## 三、写作规范速查

### 格式规范

| 要素 | 规范 |
|------|------|
| 标题 | 法院全称 + 文书类型 |
| 案号 | （年份）+ 法院简称 + 案件类型缩写 + 序号 |
| 当事人 | 自然人：姓名+性别+出生日期+住址；法人：名称+住所地+法定代表人 |
| 事实 | 按时间顺序或逻辑顺序排列 |
| 理由 | "本院认为"开头，逐层论证 |
| 判项 | 明确、具体、可执行 |
| 落款 | 审判人员 + 日期 + 印章 |

### 常见扣分项（应避免）

| 问题 | 说明 |
|------|------|
| 说理不充分 | 仅引用法条，未论证为何适用 |
| 事实认定不清 | 关键事实未查清或未认定 |
| 逻辑跳跃 | 大前提→结论之间缺乏充分论证 |
| 遗漏诉辩意见 | 未回应当事人的重要主张 |
| 法条引用错误 | 引用已废止或不适用的法条 |
| 文字冗余 | 存在大量无意义的套话 |

## 五、使用方法

**起草文书时**：
1. 按案由在本文件中搜索同类获奖文书
2. 参考其说理结构和论证方法
3. 运用其文字表达技巧

**审查文书时**：
1. 对照本规范逐项检查
2. 重点审查说理深度和事实认定
3. 确保无扣分项

**学习提升时**：
1. 研读获奖法官的撰写心得（见《形与神》系列）
2. 分析其裁判思路
3. 积累优秀表达方式
