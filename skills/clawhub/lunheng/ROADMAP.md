# Lunheng 路线图 v3

> 最后更新：2026-07-29
> 竞品对标：最高院"法信法律基座大模型" + 深圳智审系统

## 战略定位

**法信 = 法院系统标配（大而全）**
**论衡 = 个人法官/律师的精锐工具（小而精、可解释、可定制）**

不正面竞争数据量和系统集成，聚焦法信做不到的差异化：
1. 三段论显式推演（可解释性）
2. 优秀文书范式对标（说理质量）
3. 个性化适配（Practice Profile）
4. 律师端覆盖（法信只服务法官）
5. 开源可定制

## Phase 3: 说理质量引擎（P0 — 核心差异化）

### 3.1 优秀文书范式检索器 ✅ 2026-07-29
- [x] `scripts/style_retriever.py` — 根据案由从 210 篇《形与神》获奖文书 + 700+ 篇百篇优秀文书中检索最相关的 3-5 篇
- [x] 基于关键词+案由+案情的多维相关性评分（标题0.3 + 关键词0.4 + 案情0.2 + 心得0.1）
- [x] 提取说理结构范式（递进式/并列式/反驳式/混合式）
- [x] 输出为 assembler 的 few-shot 示例，注入 prompt
- [x] 集成到 retriever.py，替代原有 ShapeSpiritIndex 基础检索
- **目标**：让 LLM 生成的说理段落"像获奖法官写的"

### 3.2 说理质量评分器 ✅ 2026-07-29
- [x] `scripts/reasoning_scorer.py` — 自动评估生成文书的说理质量
- [x] 6 维度评分：争议焦点归纳(10) + 法条引用(10) + 构成要件(10) + 事实认定(10) + 逻辑连贯性(10) + 语言规范性(10)
- [x] 与获奖文书基线对比（A/B/C/D/F 等级）
- [x] 自动生成改进建议（针对最薄弱维度）
- [x] CLI 支持：`python3 reasoning_scorer.py judgment.md 案由`
- **目标**：量化“好不好”，而不只是“生成了”

### 3.3 说理深度自动增强 ✅ 2026-07-29
- [x] `scripts/reasoning_enhancer.py` — 当评分 < 60% 时自动触发增强流程
- [x] 3 种增强策略：补充构成要件分析 → 强化事实-法律联结 → 添加类案引用
- [x] 最多 3 轮迭代，每轮重新评分
- [x] 自动选择最匹配的增强策略（基于最薄弱维度）
- [x] 集成 style_retriever 范式参考注入增强 prompt
- [x] CLI 支持：`python3 reasoning_enhancer.py judgment.md 案由`
- **目标**：自动迭代到合格水平

## Phase 4: 类案实时检索（P1 — 数据壁垒）

### 4.1 裁判文书网 API 集成 ✅ 2026-07-29
- [x] `scripts/case_search.py` — 多数据源类案检索器（IMA API + 本地 shape_spirit fallback）
- [x] 输入：案由 + 关键事实
- [x] 输出：Top N 类案（案号/法院/裁判日期/裁判要旨/相关度）
- [x] 自动去重 + 相关性排序
- **目标**：从 700+ 篇静态数据 → 多源实时检索

### 4.2 类案裁判差异分析 ✅ 2026-07-29
- [x] `scripts/case_divergence.py` — 对比多个类案的裁判结果
- [x] 5 种常见分歧模式（利息上限/保证责任/违约金/举证责任/合同效力）
- [x] 输出“同案不同判”风险提示（high/medium/low）
- [x] 一致性评分（0-1）
- **目标**：帮助法官避免被上诉/改判

### 4.3 指导性案例自动匹配 ✅ 2026-07-29
- [x] 集成到 case_search.py 的本地检索（279 篇指导性案例）
- [x] 按案由+关键词匹配，输出裁判要点
- **目标**：提升文书权威性

## Phase 5: 刑事文书专项（P1 — 差异化突破口）

### 5.1 刑事案由模板补全
- [ ] 当前：15 种刑事案由 → 目标：30+ 种

- [ ] 每个案由模板包含：构成要件清单 + 量刑情节清单 + 常见辩护观点

### 5.2 量刑建议计算器 ✅ 2026-07-29
- [x] `scripts/sentencing_calculator.py` — 根据犯罪情节自动计算量刑建议区间
- [x] 支持 11 种常见罪名（故意伤害/盗窃/诈骗/危险驾驶/交通肇事/抢劫/故意杀人/贩卖毒品/帮信罪/贪污/受贿）

- **目标**：刑事法官最耗时的环节之一

### 5.3 刑事辩护观点预判

## Phase 6: 律师端拓展（P2 — 市场扩展）

> **隐私提醒**：以下功能涉及处理含当事人信息的法律文书。使用时请确保已脱敏处理敏感个人信息。
> 论衡不会在本地持久化存储任何案件数据，所有处理均基于当前会话上下文。

### 6.1 起诉状生成器
- [ ] 输入：当事人信息 + 诉讼请求 + 事实与理由
- [ ] 输出：符合最高法示范文本格式的起诉状
- [ ] 复用已有 50 种案件类型模板（`brain/motor-cortex/法律模板/`）
- **目标**：律师端第一个功能

### 6.2 答辩状生成器
- [ ] 输入：起诉状 + 答辩要点
- [ ] 输出：结构化答辩状
- [ ] 自动识别起诉状中的薄弱点

### 6.3 代理词/辩护词生成器
- [ ] 输入：案件材料 + 代理/辩护策略
- [ ] 输出：完整代理词或辩护词
- [ ] 集成类案检索，增强说服力
