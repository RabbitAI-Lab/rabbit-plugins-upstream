## Description:

Creates HTML review boards for storyboards, moodboards, look tests, stills, and device or app mockups, with prompts and per-frame feedback.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

Creative teams and agents use the skill to plan storyboards, set visual direction, review stills, and prototype device or app screens before producing video.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The example installation uses unpinned sources.

Mitigation: Review and pin installation sources to a trusted, specific version or commit before installing.

Risk: Prompts, reference images, or files may be shared with an external image service.

Mitigation: Check the service and its data handling, and remove sensitive material before uploading.

Risk: A template was only partially inspected.

Mitigation: Review the template and any unresolved references before using them.
