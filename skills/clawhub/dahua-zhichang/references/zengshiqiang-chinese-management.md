# 分寸层 · 曾仕强中国式管理

> 曾仕强（1935—2018），台湾交通大学、台湾师范大学教授，英国莱斯特大学管理哲学博士，央视《百家讲坛》主讲人，被称"中国式管理之父"。
> 本册整合四部代表作：《中道管理》《被领导的艺术》《圆通的人际关系》《中国式管理全集》。
> 适用：与上司/同事/下属相处、要不要硬刚、领会领导意图、沟通冲突、晋升路径、职场人情与分寸。

---

## 一句话总纲

**管理就是"修己安人"的历程——起点是修己，终点是安人。**

> 先把自己管好（修己），再推己及人让周围人安宁（安人）。
> 中国式管理 = 用中国的"道"，把西方现代管理科学落实得合理有效。

---

## 一、《中道管理》—— M 理论（思想内核）

**中道**即中庸之道：合乎人性的合理化管理，目标在"求恰到好处，以便安人"。依循"仁、义、礼"三道。

| 三向度 | 一字纲领 | 含义 | 现代对应 |
|---|---|---|---|
| **安人之道** | 仁 | 安人第一、以人为本 | 以人为本的组织氛围 |
| **经权之道** | 义 | **持经达变**——原则（经）不变，方法（权）随时调整 | 与时俱进、灵活应变 |
| **絜矩之道** | 礼 | 将心比心（《大学》"所恶于上，毋以使下"） | 共造和谐关系 |

- **修己安人**：要安人必先修己。修己是**修造自己，不是改变他人**；先改变自己，让周围受到感应而自动改变，比高压要求有效得多。
- **安人的历程**：**开心 → 交心 → 共同关心 → 同心**。安人是"心连心"的结果。
- **求安足，不求富强**：中华文化求"安足"（心安理得），不是盲目做大做强。**"强就是准备要弱了"**——大有大的安，小有小的安。

## 二、《被领导的艺术》—— 如何当好下属（职场人最该先学的一课）

**核心命题：被领导是领导的基础；人人都同时是领导者与被领导者，先学会被领导，才能当好领导。**

> 组织中最可怕的人，是那些**既不能命令又不受命**的害群之马。

### 九章骨架
1. **做有准备的被领导者**：选择值得付出的领导；**要"卖力"而不"卖命"**。
2. **与领导建立和谐关系**：正确认识"**合理的不平等**"——上下级**人格平等、地位不平等**；讨好领导不明智。
3. **领会领导的真实意图**：中国人有意见不会直接表达——**"听话不如看话"**；站在领导立场想问题。
4. **不做只听命令的奴才**：**"合理地阳奉阴违""执行命令慢半拍"**——在听与不听之间拿捏。
5. **达到领导期望的目标**：做好交办之事；把握好"多沟通还是多请示"的分寸；**有错善于补过**。
6. **获得授权时做好本分**：**多担责、少争权**；不越权、不弄权、不失职；**时时汇报让领导放心**。
7. **协助领导管理好下属**：平衡"情理法"；与领导默契配合。
8. **同级之间分工协作**：分工不同、目标一致；老板区别对待时泰然处之。
9. **被领导者的自我提升**：**"与领导共同晋升"是上上策**——上司出头，你才更容易出头。

**晋升的三种情形**（曾仕强判断）：
1. 上司被撤换，你替补上位（偶然，走不远）；
2. 平行调动、与上司平级（偶然）；
3. **上司一路高升，你跟着一路上升（"实在是上上策"）**——能力与上司的本事都被看见，形成共同前进的势头。

## 三、《圆通的人际关系》—— 圆通而不圆滑

**核心：在"圆通"中分是非——把是非分得大家都有面子，不得罪人，也不讨好人。**

> 西方人际重**平等**，中国人际重**人伦与长幼次序**，讲究伦理规范。这是两套不同的交往逻辑。

### 中国人的四大特性（先认清对象再交往）
- **言**：模棱两可、言不由衷 → "听话不如看话"；"随便"并不随便；"不反对"并非"赞成"。
- **行**：谨慎小心、反求诸己 → 先弄清对方是谁；凡事追求"合理"。
- **心**：追求圆通、善于自保 → **圆通≠圆滑**；遇事先求自保。
- **性**：爱占便宜、死要面子 → 就怕吃亏上当；自私又爱面子。

### 圆通十字诀（字字可操作）

| 要领 | 含义 |
|---|---|
| **一表人才** | 提升第一印象，正确认识自己，不以貌取人 |
| **两套西装** | 外在表现与内在同样重要；着装因场合而异 |
| **三杯酒量** | 爱好是媒介，但凡事适可而止 |
| **四圈麻将** | 人际关系要经营——"赢到后来总是输" |
| **五方交游** | 多个朋友多条路；严于律己获益多 |
| **六出祁山** | 明知不可为而为之——职场要有一股韧劲 |
| **七术打马** | 多说恭维话，少去讨好人 |
| **八口吹牛** | 要自己肯定自己，也让别人赞扬你（表达能力） |
| **九分努力** | 努力是基础，但"努力没有用，运气很重要" |
| **十分忍耐** | **会忍才能赢；欲速则不达**——第一条被破了，前九条也会功亏一篑 |

### 沟通的四个层次
**不沟不通 → 沟而不通 → 沟而能通 → 不沟而通**（最高境界，默契）
- 沟通三忌：**"先说先死、不说也死、说到不死"**——关键是拿捏分寸。
- 三方向沟通：向上、向下、平行，各有打法。

### 内部关系三视角
- **老板**：对自己严格，对干部恩威并施，对员工关怀照顾。
- **干部**：建立**"主伴关系"**——让老板放心、让员工舒心、让平级安心。
- **员工**：成为受欢迎的人，学会应对上司，与同事和平相处。

## 四、《中国式管理全集》—— 体系总纲

### 三大主轴
- **以人为主**：人与人的关系是核心；人品往往是管理有效与否的关键。
- **因道结合**：志同道合是合理应变的基础；重视伦理、建立共识。
- **以理应变**：规则只是"品质管制的范围"，部属应在规定范围内自主发挥，做到合理。

### 六字真诀
**两难 → 兼顾 → 合理**
- 两难：凡事都是相对的，都有矛盾。
- 兼顾：把矛盾统一起来，"合起来想"。
- 合理：寻找"此时此地"的合理决策。

### 核心方法论
- **把二看成三**：不在别人给的两个选项里选，而是找到中间地带，用全新做法化解矛盾。
- **推、拖、拉**：不是消极，而是①留出思考时间 ②把事交给最合理的人 ③避免误解、保护自己。**推拖拉本身没有好坏，动机良好、方式合理，效果可能很理想。**
- **情理法兼顾**：以情为先、按理解决、以法为底线；"先有情入理，不得已才翻脸无情、依法办理"。
- **寓人治于法治中**：人治大于法治，但建立在法治基础上，人人自然、自发、自动地重纪守法。
- **以让代争**：礼让为先，合理的"当仁不让"；让来让去，把机会交给最合理的人。

### 一句总纲
> 管理是修己安人的历程。修己要旨在**自觉**：受人敬重必须自觉讲理，敬重他人应给足面子，自主提高自动自发的精神——这是修己的三大要领。

## 决策用法（分寸层）

当用户纠结**职场上下级关系、要不要跟领导硬刚、被领导/带团队、同事协作、晋升路径、沟通冲突、职场人情**时，用本册：

1. **先定位角色与关系**：他此刻是"被领导"还是"领导"？相手是上级、同级还是下属？先承认"人格平等、地位不等"的现实，再谈策略。
2. **用"经权之道"找分寸**：原则（经）不让，方法（权）灵活——"合理的不平等""慢半拍"是分寸艺术，不是教你阳奉阴违，而是**在坚持原则前提下保留弹性**。
3. **用"絜矩之道"换位**：将心比心，站在对方（尤其领导）的立场想问题。
4. **用"修己安人"收口**：能改变的是自己，先把本分做到位、让领导放心，再谈利益与晋升。
5. **提醒"十分忍耐"**：职场很多溃败，败在最后那一口忍不下。

> ⚠️ 诚实边界：
> - 中国式管理是**文化视角与管理哲学**，不是西方管理学的实证定论；其"阳奉阴违""合理的不平等""人情面子"等说法，应理解为**特定文化情境下的分寸智慧**，**不可当作消极怠工、推卸责任或"耍心机"的借口**。
> - 涉及**劳动法、劳动合同、职场霸凌/骚扰、欠薪、违法指令**等具体权益问题时，一律提示以法律规定与专业咨询为准，不鼓励用"人情话术"替代正当维权。
