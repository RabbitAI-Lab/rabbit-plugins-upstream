## Description: <br>
Helps API developers and platform teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to plan, write, review, and validate OpenAPI or Swagger documentation for REST APIs. It produces practical workflows, checklists, implementation guidance, and verification notes tailored to the user's API documentation task. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad API-related trigger wording may activate the skill for tasks that are not OpenAPI or Swagger documentation work. <br>
Mitigation: Invoke it explicitly for API documentation tasks and dismiss it when the request is about unrelated API implementation, debugging, or data access work. <br>
