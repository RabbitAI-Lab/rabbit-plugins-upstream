## Use Case:

Developers and technical writers use this skill to draft REST API documentation templates, endpoint specifications, request and response examples, status-code tables, and RESTful design guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated API documentation examples may contain real credentials or personal data if users paste production values into placeholders.

Mitigation: Use synthetic or redacted values for names, phone numbers, emails, tokens, and passwords before sharing or committing generated documentation.
