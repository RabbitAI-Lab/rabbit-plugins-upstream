## 二、Amazon（重点）

### 费用结构
```
售价
 − Referral Fee（佣金，类目 8%–15%，多数 15%）
 − FBA 配送费（按尺寸段 + 重量，含仓储）
 − 仓储费（月度 + 长期仓储，旺季更高）
 − 广告费（CPC，ACOS 目标通常 15%–30%）
 − 退货处理（多数类目退货可二次销售，部分损耗）
 − 其他：退款管理费、跨境收款费、品牌备案/订阅费
```

### 流量机制（A9）
- **核心排序因子**：关键词相关性（标题/五点/Search Term）→ 转化率 → 销量与销量增速 → Review 评分与数量 → 价格与库存
- **权重顺序实操**：先有精准流量（关键词）→ 再靠转化率稳住 → 销量累积推排名 → Review 护城河
- **广告**：SP（商品推广）/ SB（品牌）/ SD（展示）；新品期靠自动广告跑词，再转手动精准

### 冷启动打法
1. **关键词布局**：标题埋核心大词，五点埋场景词与长尾，后台 Search Term 补漏
2. **vine / 早期评论**：新品期快速攒 Review（合规途径）
3. **自动广告跑词**：先宽泛跑 1–2 周，筛出高转化词转手动
4. **Coupon / 秒杀**：给转化一个理由，配合广告拉排名
5. **稳库存**：断货会直接把排名打回原点

### 合规红线
- 禁止刷单刷评、禁止操纵 Review（账号风险）
- 侵权（商标/专利/版权）直接下架甚至封店
- 类目审核（部分类目需 approval）
- 产品合规：CE（欧）、FCC（美无线）、CPC（儿童）、FDA（食品/美妆）、MSDS/UN38.3（带电/电池）

## 三、TikTok Shop（内容电商）

- **流量来自推荐算法**：完播率 > 互动率 > 转化率的传导链
- **短视频带货**：前 3 秒定生死，场景化展示 > 参数罗列
- **直播带货**：停留时长 + 互动 + 转化决定推流
- **达人分销**：给达人寄样 + 高佣金（20%–30%）撬动带货
- **冷启动**：先跑通一条能出单的内容，再放大（投流 + 达人矩阵）

## 四、东南亚（Shopee / Lazada）

- **价格敏感**：客单价低，免运费/包邮活动权重高
- **大促驱动**：双11、12.12、Payday、斋月等节点贡献大量 GMV
- **物流**：平台官方物流（SLS/LGS）为主，时效与妥投率影响店铺分
- **店铺分**：延迟发货率、取消率、差评率直接影响流量分配

## 五、独立站（Shopify）

- **没有平台内流量**，全部靠自建：付费广告（Meta/TikTok/Google）、SEO、社媒、邮件
- **核心指标**：CAC（获客成本）、LTV（客户终身价值）、ROAS、加购率、结账放弃率
- **冷启动**：先测品（小额广告测素材）→ 跑通 ROAS → 放量 → 复购/EDM 承接
- **支付**：Stripe/PayPal 手续费约 2.4%–2.9% + 固定费；拒付（chargeback）风险需关注

## 六、选型建议（给老板的一句话版）

| 你的情况 | 建议 |
|---|---|
| 有供应链、想做品牌 | Amazon（美/欧）+ 独立站长期沉淀 |
| 价格有优势、能走量 | Temu / SHEIN 全托管（但利润薄、无定价权） |
| 会做内容/有达人资源 | TikTok Shop |
| 想试水东南亚 | Shopee / Lazada（门槛低，但客单低） |
| 有美国公司资质 | Walmart（竞争小、利润好，但门槛高） |
