# 投放测算：保本 ROI / 最高出价 / 目标 ROI 反推

## 一、三个恒等式（禁止临场推导，全部走 `profit_roi.py`）

```
ROAS        = CVR × 客单价 ÷ CPC          # 三变量知二求一
保本 ROAS   = 1 ÷ g_eff                   # g_eff = 毛利率 - 达人分摊率 - 目标净利率
最高 CPC    = 客单价 × g_eff × CVR
最高 CPM    = 1000 × 最高 CPC × CTR
```

**推导校验**：花 1 元广告 → 带来 1/CPC 次点击 → 成交 CVR/CPC 单 → GMV = 客单价 × CVR/CPC = ROAS。利润 = GMV × g_eff − 1 ≥ 0 → ROAS ≥ 1/g_eff。✔

## 二、保本 ROI 的两个版本（报告必须写清用哪个）

| 版本 | 公式 | 用途 |
|---|---|---|
| 保本 ROI（覆盖成本） | `1 / g` | 活下来的底线，低于它卖一单亏一单 |
| 保本 ROI（含目标净利） | `1 / g_eff` | 经营目标线，**日常投放以它为准** |

## 三、最高可承受出价（ bidding 上限）

- **CPC 上限** = 客单价 × g_eff × CVR
- **CPM 上限** = 1000 × CPC 上限 × CTR
- 实际出价建议 = 上限 × 0.7~0.8（留出模型波动空间；冲量期可放到 0.9）
- **放量纪律**：实际 ROAS ≥ 保本 ROI × 1.2 → 加预算 20%~30%/次；ROAS 在保本线 ±10% → 维持；连续 3 天 ROAS < 保本 × 0.8 → 停投并回查转化层

## 四、目标 ROI 反推（三类问法）

| 问法 | 反推公式 |
|---|---|
| 「目标 ROAS = X，最高能出多少 CPC？」 | CPC = 客单价 × CVR ÷ X |
| 「CPC 已经 Y 了，需要多少转化率才不亏？」 | CVR = X × Y ÷ 客单价 |
| 「按当前 CPC 与 CVR，实际 ROAS 是多少？」 | ROAS = 客单价 × CVR ÷ CPC |

## 五、ROI 做不上去的四层归因（从外到内）

1. **口径层**：是否混用了平台后台 GMV 与广告后台消耗？归因窗口是否一致？→ 先修口径再谈优化
2. **出价层**：CPC 是否超过上限？→ 按 §三 设上限，改用「控成本」出价
3. **转化层**：CVR 是否低于同类基准？→ 交给 E3 做漏斗诊断（主图/价格/评价/人群）
4. **结构层**：客单价是否太低导致天花板压死 ROAS？→ 组合装/关联销售抬 AOV，再谈 ROI

## 六、常见算错（命中即判无效报告）

| 错误 | 后果 |
|---|---|
| 用「毛利率（含广告）」算保本 ROI | 保本 ROI 被低估，白白不敢放量 |
| 用点击数当访客数算 CVR | CVR 虚高 → 出价上限虚高 → 投得越多亏越多 |
| 用订单数当支付买家数 | 转化率虚高（同一人下多单） |
| 忽略退货率 | 毛利虚高 2~5 个百分点 |
| 坑位费按预估销量分摊 | 实际销量不及预估时利润直接转负 |
| 平台补贴算进收入 | 收入虚高，补贴是平台给的、不影响毛利 |
