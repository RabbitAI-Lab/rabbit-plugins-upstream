# 电商术语与口径表

> 统一口径，避免"同一个词两种算法"。报告里出现缩写时，以本表为准。
> **口径冲突时：以本报告/脚本定义为准，并在交付物中注明。**

## 一、通用经营指标

| 术语 | 定义 | 口径 |
|---|---|---|
| GMV | 成交总额 | 支付金额（含退款前）；本 Skill 默认用**支付金额** |
| 净销售额 | GMV − 退款 | 对账时以平台结算口径为准 |
| 客单价 AOV | 支付金额 ÷ 支付买家数 | **买家数口径**（R4），不用订单数 |
| 支付转化率 CVR | 支付买家数 ÷ 访客数 | **买家数 ÷ 访客数**（R4） |
| UV 价值 | 支付金额 ÷ 访客数 | = 客单价 × 转化率 |
| ROI / ROAS | 支付金额 ÷ 广告花费 | **同一来源、同一归因窗口**（R5），禁止混算 |
| 毛利 | 销售额 − 商品成本 | 不含广告与固定费用 |
| 贡献毛利 | 毛利 − 佣金 − 履约 − 广告等变动费用 | 未摊固定成本 |
| 净利 | 贡献毛利 − 固定成本分摊 | 最终赚到的钱 |

## 二、流量与广告

| 术语 | 含义 |
|---|---|
| CPC / CPM | 单次点击成本 / 千次曝光成本 |
| CTR | 点击率 = 点击 ÷ 曝光 |
| ACOS（跨境） | 广告花费 ÷ 广告带来的销售额（越低越好） |
| TACOS（跨境） | 广告花费 ÷ 总销售额（看广告依赖度） |
| 保本 ROI / 保本 ACOS | 不亏不赚的临界值 = 1 ÷ 有效毛利率 |
| 归因窗口 | 点击后多少天内下单算广告功劳；平台不同，不可混用 |
| 自然流量 / 付费流量 | 非广告 vs 广告带来的访客 |
| 坑产 | 单个商品位的产出（销售额），直播/活动常用 |

## 三、国内平台术语

| 术语 | 含义 |
|---|---|
| 坑位费 | 达人直播的场次费用（与佣金是两笔，别重复计） |
| 纯佣 / CPS | 按销售额分成，无固定坑位费 |
| 佣金率 | 佣金 ÷ 销售额；合理区间 **0.5%–30%**（R6） |
| 返点 | 广告消耗达标后的平台返利，注意**按实际达成阶梯**计（未达框架量不能按高阶梯算） |
| 动销率 | 有销量的 SKU ÷ 总 SKU |
| 售罄率 | 售出数量 ÷ 备货数量 |
| 连带率 | 客单件数（平均一单买几件） |
| DSR / 店铺体验分 | 平台对服务/物流/描述的综合评分，影响流量 |
| 冷启动 | 新品/新店从 0 曝光到有稳定流量的过程 |

## 四、跨境电商术语

| 术语 | 含义 |
|---|---|
| ASIN | 亚马逊商品编码（相当于国内的商品 ID） |
| Listing | 商品详情页（标题/五点/描述/图片的集合） |
| Buy Box | 亚马逊"加入购物车"的黄金位，多卖家竞价 |
| FBA / FBM | 亚马逊仓发货 / 卖家自发货 |
| Referral Fee | 平台佣金（类目 8%–15%） |
| 头程 / 尾程 | 工厂→海外仓 / 海外仓→买家 |
| HS Code | 海关商品编码，决定关税率 |
| VAT / GST | 目的国增值税 / 商品服务税 |
| IOSS | 欧盟进口一站式申报（≤150 EUR） |
| DDP / DDU | 完税交货 / 未完税交货（谁交税） |
| 申报价值 | 报关用的货值，关税计税基础 |
| 出口退税 | 退国内采购环节增值税，需专票 |
| Chargeback | 信用卡拒付，独立站风险 |
| LTV / CAC | 客户终身价值 / 获客成本（独立站核心） |
| 泛欧/欧洲整合服务 | 亚马逊跨国调仓，涉及多国 VAT 注册义务 |

## 五、本 Skill 的内部标记

| 标记 | 含义 |
|---|---|
| `DATA_MISSING` | 缺数据，禁止用经验值填补 |
| `EXPERT_MISSING` | 专家未回传，禁止主模型代写 |
| `UNAVAILABLE` | 能力/平台不支持，如实说明不伪装 |
| `S1–S4` | 来源档位：平台原始 / 单方 / 公开 / 推算 |
| `P0 / P1` | 异常严重度：P0 必须处理，P1 关注 |

## 六、单位与写法约定

- 金额：除特别说明外，**人民币元**；跨境场景同时给外币与本币
- 比率：用小数（0.15 = 15%），报告展示时转百分比
- 时间：统计区间必须写明（起止日期 + 平台时区）
- 环比 / 同比：环比 = 对比上一周期；同比 = 对比去年同期
- 涨跌配色：红=增长/正向，绿=下降/负向（中国区财务惯例）
