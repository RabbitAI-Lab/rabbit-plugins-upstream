# 文案人味化手册（去 AI 味）

> 来源：借鉴 SkillHub 榜单「文章去 AI 味工具」「李白.Skill」的分层改写思路，
> 并结合本 Skill 的电商场景重写。**适用于所有面向消费者的文案产出。**

## 一、为什么必须过这一关

AI 的默认动作是**提炼 / 缩短 / 工整**——这跟"活人感"正好反向。
电商文案一旦带 AI 味，买家一眼看出是套话，停留和转化直接受损。

**铁律 R15**：本 Skill 产出的任何面向消费者的文案（商品标题 / 主图文案 / 详情页 /
短视频脚本 / 直播话术），写完必须经本文「六步人味化」处理后才能交付。
未经人味化的文案一律视为**草稿**，不得直接用于上架、投放或口播。

---

## 二、AI 味的 8 类症状（附电商实例与改法）

| # | 症状 | AI 写法（废） | 人味写法（活） |
|---|---|---|---|
| 1 | 模板连接词 | 值得注意的是，本产品… / 综上所述… | 直接说事：**这杯子装 500ml，能塞进杯架** |
| 2 | 空洞形容词堆 | 极致体验 / 匠心打造 / 尊享品质 / 焕新上市 | 换成具体事实：**杯壁 3mm 双层，装热水不烫手** |
| 3 | 过度对称排比 | 省时、省心、省力 | 打散：**最省的是时间——30 秒搞定，不用洗第二个碗** |
| 4 | 虚假客观 | 研究表明… / 据统计…（无出处） | 给真实出处，或直接删 |
| 5 | 公式化结尾 | 选择我们，就是选择品质 | 换成具体动作或真问题：**你先量一下杯架宽度，别买回去塞不进** |
| 6 | 无主语缩句 | 投入越多越挑剔 | 补主语：**花的时间越多，人就越舍不得将就** |
| 7 | 抽象大词悬空 | 通透 / 含金量 / 赋能 / 新升级体验 | 换成可验证动作：**多了一层滤网，果渣少一半** |
| 8 | 完美主义 | 只讲优点，缺点全抹 | 承认一个真实局限，反而可信：**不适合榨冰块，刀头会钝**（须先过合规） |

## 三、五类文案各自的病灶与要点

- **商品标题**：AI 味＝堆砌同义关键词。要点＝口语词优先、保留 1～2 个真实属性（尺寸/材质/容量），别满屏形容词。
- **主图文案**：AI 味＝口号式。要点＝**一句具体利益 + 一个数字或场景**；别喊口号。
- **详情页**：AI 味＝说明书腔。要点＝用**买家真实场景**开头，每段只放一个具体事实，加一条"不适用人群"提升可信度。
- **短视频脚本**：AI 味＝照稿念。要点＝判断句、短句（≤25 字）、口语连接词、允许反问自答、结尾真的问观众一个问题。
- **直播话术**：AI 味＝书面复述。要点＝留互动空档、允许重复强调（重复＝人味，不是冗余）、连接词只用口语、结尾不喊关注。

---

## 四、六步人味化流水线

1. **删八股**：按 §二 症状表过一遍，先删连接有害词与虚假客观。
2. **换词**：形容词 → 具体事实（数字 / 材质 / 尺寸 / 场景 / 对比）。
3. **拆句**：长句拆到 ≤25 字一句，**每句必须有主语**。
4. **破对称**：打散排比与整齐结构，制造长短句落差。
5. **补人**：加第一人称判断、反问自答，或坦承一个真实局限。
6. **朗读自检**：念一遍。卡嘴处必改；删掉口头禅（啊/是吧/的话），但**保留自然的重复**。

## 五、交付前自检清单（逐条打勾）

- [ ] 无「值得注意的是 / 综上所述 / 换句话说 / 由此可见」
- [ ] 无无出处的「研究表明 / 据统计」
- [ ] 形容词已尽量换成具体事实（至少改掉一半）
- [ ] 每句有主语
- [ ] 长句已拆到 ≤25 字
- [ ] 结尾是具体动作或真问题，不是口号
- [ ] 念一遍不卡嘴
- [ ] **已跑 `copy_compliance.py` 过违禁词**（见 §七，必须在人味化之后重跑）

## 六、博主 / IP 口播的高阶要求

**适用**：短视频脚本、直播话术——文案以"人"出镜或出声时，观众对 AI 味最敏感，按最高标准执行。

语言特征（照这个写）：

- **判断句，不用陈述句**：「铺货跟精品考的完全不是一个东西」✅ / 「两种模式考察重点不同」❌
- **句子可以短、可以不完整**：「精品就比较深」——补完整就死了
- **连接词只用口语**：然后 / 就是 / 那 / 所以 ✅；因此 / 首先 / 其次 / 总而言之 ❌
- **允许反问自答**：「怎么看？三个地方。」
- **每句 ≤25 字**：长句会喘 → 卡壳
- **结尾真问观众一个问题**，不喊关注
- **每句要有主语**，不写无主语缩句
- **因果链分步断开**：现象 → 推理 → 结论，用「因为…所以…这就是…」三步走

明令禁止：

- 自造的压缩短语假装深刻
- 金句结构：`X≠Y` / `X 不是 A，是 B` / `把 A 当 B`
- 书面语：值得注意的是 / 换句话说 / 总的来说 / 核心在于 / 由此可见
- **没素材时拿"听起来对"的话填空**——每写一句，先确认它真有出处（真实数据 / 实测 / 聊天记录）；拿不准就去查，不许硬编

## 七、与合规检测的执行顺序（不可颠倒）

```
撰写初稿 → 六步人味化（本文）→ copy_compliance.py 违禁词检测 → 修正 → 定稿
```

**原因**：人味化会引入口语化的极限词（如"真的第一好用""绝对不坏"），
所以必须在人味化**之后**再跑一次合规检测，而不是之前。

```bash
python scripts/copy_compliance.py --file 文案.txt --platform tb
# 退出码 1 = 命中 P0，必须改到 0 命中才能交付
```
