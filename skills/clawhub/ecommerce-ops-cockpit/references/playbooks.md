# 场景剧本（Playbooks）

> 从"只会算"到"有打法"。每个剧本给：**触发信号 → 排查/行动顺序 → 用什么脚本 → 交付什么**。
> 剧本是顺序框架，不是死流程；实际按数据调整，但**顺序不能乱**（先定性再动手）。

---

## 剧本 1：新品上市 0→1

**触发**：要上一个新品 / 新店没流量 / 新品不出单

**顺序**
1. **先算能不能赚钱** —— `profit_roi.py`（国内）或 `landed_cost.py`（跨境）
   → 保本售价、目标净利下的定价下限、保本 ROI。**算不赚钱就别上**，先谈成本或换品
2. **判断值不值得做** —— `selection_eval.py` 六维评分 + 竞品对照
3. **定价格带与卖点** —— 对照竞品价格中位数，找空档位
4. **铺内容** —— `copy-playbook.md` 骨架写标题/主图/详情，写完 `copy_compliance.py` 过违禁词
5. **冷启动**
   - 国内：按 `platform-traffic.md` 的平台机制走（如淘宝靠搜索词+转化，抖音靠内容）
   - 跨境：Amazon 靠关键词+自动广告跑词+早期评论；TikTok Shop 靠内容
6. **备货** —— `stocking_plan.py` 算首批备货量与安全库存，**别断货**（断货=排名归零）
7. **周跟踪** —— `weekly_report.py` 看环比，异常用 `funnel_diagnose.py` 定位

**交付**：《新品上市方案》—— 定价 + 保本ROI + 备货量 + 冷启动路径 + 风险项

## 剧本 2：有流量不出单（最常被问）

**触发**：访客稳定或涨了，但订单/转化率掉了

**排查顺序**（自上而下，别跳步）
1. **先确认口径** —— 转化率是不是用支付买家数÷访客数（R4）？拿点击当访客会虚高
2. **跑 `funnel_diagnose.py`** —— 定位主瓶颈：曝光/点击/加购/下单/支付哪一段断了
3. **按瓶颈定性**
   - 加购掉 → 详情/价格/主图没打动人
   - 下单掉 → 价格或竞品比价（去查竞品有没有降价）
   - 支付掉 → 优惠券失效、运费门槛、支付流程问题
4. **看评价/问大家** —— 是不是新增了差评（差评对转化杀伤极大）
5. **看竞品** —— 竞品降价/上新/做活动，会分流
6. **归因** —— `margin_bridge.py` 看是价格、销量还是结构问题

**交付**：《转化诊断》—— 主瓶颈 + 3 条可执行动作 + 预期影响

## 剧本 3：ROI 做不上去

**触发**：广告投产比低于保本值，投了就亏

**顺序**
1. **算保本 ROI** —— `profit_roi.py` 的保本 ROAS = 1 ÷ 有效毛利率。**低于这个数就是在亏**
2. **算最高可承受出价** —— 最高 CPC = 客单价 × 有效毛利率 × CVR。超过就是亏
3. **拆公式**：ROAS = CVR × 客单价 ÷ CPC
   → 提 ROAS 只有三条路：**提转化 / 提客单 / 降 CPC**
4. **定位哪条路**
   - CPC 高 → 关键词竞争/质量分，优化人群与素材
   - CVR 低 → 回剧本 2（落地页/详情/评价）
   - 客单低 → 组合装、凑单满减、关联销售
5. **结构性问题** —— 是不是广告占比过高（TACOS 过高），要靠自然流量承接

**交付**：《投放诊断》—— 保本ROI + 最高出价 + 提 ROI 的三条路排序

## 剧本 4：断货应急

**触发**：库存告急 / 已经断货 / 补货在路上

**顺序**
1. **算还能撑几天** —— 日均销量 × 剩余库存；`stocking_plan.py` 看补货点是否失守
2. **先保排名** —— 断货会清零排名，优先保主力款
   - 降广告预算（避免流量浪费在无货商品）
   - 提价（降速，保利润，也给补货争取时间）
   - 预售/缺货登记（看平台是否支持）
3. **催头程** —— 跨境最怕这个；空运补急货（算清运费侵蚀多少利润）
4. **复盘** —— 补货周期是不是设短了？安全系数是不是该调高？

## 剧本 5：滞销清仓

**触发**：库存周转慢 / 长期仓储费逼近 / 资金被压

**顺序**
1. **算滞销成本** —— 仓储费 + 资金占用成本 + 可能的弃置费
2. **算清仓底线价** —— `profit_roi.py` 反推：至少覆盖变动成本就不如尽快出
3. **选渠道** —— 平台 Outlet / 站外折扣 / 直播清仓 / 捆绑搭售 / 跨境转新兴市场
4. **别拖** —— 拖到长期仓储费 + 资金成本，会比降价损失更多

## 剧本 6：被跟卖 / 被比价

**触发**：Buy Box 被抢 / 有人低价跟卖 / 竞品直接降价

**顺序**
1. **确认对方是不是合规跟卖**（真货 vs 假货）
2. **算自己能降到多少** —— 保本售价是底线，别亏本跟
3. **差异化而不是纯降价** —— 捆绑装、赠品、增值服务（避免价格战）
4. **品牌备案 / 投诉**（跨境：品牌 registry + Report a Violation）
5. **提价也要敢** —— 有品牌力时不跟低价，反而提价做价值感

---

## 剧本 7：差评 / 评分危机

**触发**：评分掉 / 集中出现差评 / 转化突然掉

**顺序**
1. **先定性**：产品问题（质量/描述不符）还是服务问题（物流/客服）
2. **产品问题** → 停投广告（别放大），先修产品或改描述
3. **服务问题** → 修物流/客服话术
4. **合规应对** —— 走平台正规申诉/联系买家，**不刷评、不删评买评**
5. **归零预防** —— 把差评问题反馈到选品/供应链，别再进同样的货

## 剧本 8：大促节奏

| 国内 | 海外 |
|---|---|
| 618（6月）、双11（11月）、双12、年货节、38、99 | Prime Day（7月）、黑五（11月末）、网一（12月初）、圣诞、返校季 |

**节奏（提前量）**
- **T-60 天**：选品定款、备货下单（跨境要更早，海运 30–45 天）
- **T-30 天**：内容/素材/详情页就位，报名活动
- **T-7 天**：预热蓄水（加购/收藏/预售）
- **T-0**：爆发，盯库存与投放
- **T+7**：退货高峰处理 + 复盘

用 `ops-calendar.md` 排期，`stocking_plan.py` 算备货，`weekly_report.py` 盯过程。

## 剧本 9：账号受限 / 申诉

**触发**：店铺被限制、商品下架、账号被封

**顺序**
1. **先看平台通知** —— 定性：侵权 / 违规 / 绩效 / 资质
2. **别急着乱提交** —— 申诉材料要一次到位，反复提交会降低成功率
3. **按平台要求备材料**：发票/授权书/检测报告/整改说明
4. **本 Skill 边界**：提供材料清单与整改思路，**不伪造材料、不协助规避平台规则**

## 剧本 10：选品决策会（综合任务）

**触发**："这款到底值不值得做"

按 §三 六步路由走，**综合任务必须派四位专家**（R2）：
- E1 选品与竞品 → `selection_eval.py`
- E2 利润与定价 → `profit_roi.py` / `landed_cost.py`
- E3 流量与转化 → `platform-traffic.md` / `overseas-platforms.md`
- E4 投放 ROI 与创意合规 → `profit_roi.py` + `copy_compliance.py`
- 跨境场景加派 **E5 跨境与合规** → `cross-border-costs.md`

**交付**：图表化 PDF 报告，含**分项置信度**（`confidence.py`）与来源档位（S1–S4）

---

> 所有剧本遵循两条底线：
> ① **先算再动**——没算过利润和保本，不谈投放与降价
> ② **不可逆动作先确认**——改价、清仓、删品、对外发布都要走 R19/R25
