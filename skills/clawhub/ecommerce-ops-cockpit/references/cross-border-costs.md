# 跨境成本结构全解

> 配合 `scripts/landed_cost.py` 使用。本文件讲**每一项成本是什么、怎么来的、常见坑**；脚本负责算。
> 费率为常见区间（S3），实际以货代/平台/官方政策为准，用前核对日期。

## 一、成本全景（从工厂到买家手上）

```
货品成本（采购/生产成本）
  + 头程物流（工厂 → 目的国仓）      ← 跨境独有
  + 关税（按 HS 编码与申报价值）      ← 跨境独有
  + 目的国 VAT/GST                    ← 跨境独有
  + 履约费（FBA 配送 / 海外仓 / 自发货）
  + 仓储费（月度 + 长期仓储 + 旺季附加）
  − 出口退税（冲减成本）              ← 跨境独有（有专票才行）
  = 到岸成本（Landed Cost）
  
  + 平台佣金（Referral Fee）
  + 跨境收款/结汇费                   ← 跨境独有
  + 广告费
  + 退货净损失（跨境退货多数无法二次销售）
  + 汇率波动缓冲                      ← 跨境独有
  = 总费用
  
  售价（外币 × 汇率） − 总费用 = 净利
```

## 二、头程物流（工厂 → 海外仓）

| 方式 | 时效 | 成本 | 适用 |
|---|---|---|---|
| **海运整柜 FCL** | 30–45 天 | 最低 | 大货、稳定补货 |
| **海运拼箱 LCL** | 35–50 天 | 中低 | 中小批量试单 |
| **空运** | 7–15 天 | 高 | 急货、高价值小件 |
| **国际快递** | 3–7 天 | 最高 | 样品、极小件 |
| **中欧班列** | 18–25 天 | 中 | 欧洲线，海运空运之间 |

**计费重**：取**实重 vs 体积重**的较大者。
体积重（kg）≈ 长×宽×高（cm）÷ 5000（空运常用 6000）。**泡货（轻抛货）按体积重算，很容易低估成本**。

**常见坑**
- 只算海运费，漏了报关费、拖车费、港杂费、查验费、滞港费
- 旺季（黑五前）舱位紧张、涨价，需提前 45–60 天订舱
- 断货代价远大于头程省钱：断货会把排名打回原点

## 三、关税（Duty）

- 按 **HS 编码**（商品编码）确定税率，各国不同，同类目不同材质差异很大
- 计税基础一般是**申报价值**（通常是采购价或售价的一定比例）
- **申报比例**：部分卖家按售价的 3–6 成申报（合规风险自负，本 Skill 不提供规避方案）

**起征点/免税额度（常见）**
- 美国：单票 800 USD 以下通常免税（Section 321）
- 欧盟：150 EUR 以下免关税（但 VAT 照征）
- 英国：135 GBP 以下免关税

⚠️ 本 Skill **不协助低报、虚报、拆单避税**——那是走私风险，会让店铺和公司一起出事。

## 四、目的国 VAT / GST

| 地区 | 税种 | 税率 | 说明 |
|---|---|---|---|
| 美国 | Sales Tax | 州级 0%–10%+ | 多数平台代征代缴（Marketplace Facilitator） |
| 欧盟 | VAT | 17%–27%（德 19%、法 20%） | 可用 **IOSS** 一站式申报（150 EUR 以下） |
| 英国 | VAT | 20% | 平台多代征 |
| 日本 | 消费税 | 10% | 逆算制度 |
| 澳洲 | GST | 10% | 平台多代征 |

**计税基础**：欧盟通常按 **（申报货值 + 关税 + 运费）** 征，所以关税高会连带抬高 VAT。

## 五、履约与仓储

| 方式 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| **FBA**（亚马逊仓） | 流量倾斜、Prime 标识、客服退货平台兜 | 费用高、滞销压仓有长期仓储费 | 主力推品 |
| **海外仓（3PL）** | 成本低、灵活、可 multi-platform | 无平台流量倾斜 | 多平台铺货、大件 |
| **自发货 FBM** | 无仓储压力 | 时效差、转化低 | 试单、超大件、冷门品 |

**仓储坑**：亚马逊**长期仓储费**（超 181 天/365 天）很狠；旺季（10–12 月）仓储费上涨；滞销库存要主动清（Outlet/清仓/移除）。

## 六、跨境收款与汇率

- **收款服务商**：Payoneer / 万里汇 WorldFirst / 连连 / PingPong / 空中云汇，费率常见 **0.3%–1%**
- **结汇**：外币 → 人民币，注意现汇买入价与中间价差
- **汇率风险**：报价到回款有 1–3 个月账期，汇率波动 5% 就能吃掉利润
  - 应对：报价时计提 **2%–3% 汇率缓冲**（脚本 `fx_buffer`）；大额可做锁汇/远期
  - 脚本 `fx_sensitivity` 会给出 ±3%/±5% 时的净利变化

## 七、出口退税（很多人忘了算）

- 退的是**国内采购环节已缴的增值税**，需要**增值税专用发票**
- 退税率分档：13%、9%、6%、0%（看 HS 编码）
- 计算：退税 ≈ 采购不含税金额 × 退税率（脚本按「货品成本 × 退税率」冲减）
- **没有专票就退不了**——小工厂供货常踩这个坑，报价时务必确认

## 八、跨境退货（比国内狠）

- 跨境退货**多数无法二次销售**（运费比货值高、包装破损）
- 常见处理：就地弃置（弃置费）、转海外仓低价处理、捐赠抵税
- 部分类目（服装）退货率可达 15%–30%，**定价时必须把退货损失摊进去**
- 脚本用 `return_rate × return_loss_cny` 摊到每件

## 九、其他容易漏的

- 产品认证费（CE/FCC/CPC/FDA/UKCA）：几百到几万不等，新品必算
- 商标/专利（亚马逊品牌备案需 R 标）
- 保险（产品责任险，欧美客户常要求）
- 平台订阅费（亚马逊专业卖家月费）
- 广告投放测试成本（新品期 ACOS 可能 50%+，属正常投入）
