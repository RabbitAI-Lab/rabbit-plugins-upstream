# 定价与真实利润口径

## 一、单件成本全清单（漏一项就亏一项）

| 类别 | 项目 | 说明 |
|---|---|---|
| 商品成本 | 采购价/生产成本、头程运费、关税 | 含税口径要统一 |
| 履约成本 | 快递费、仓配操作费、包装耗材 | 多件订单要按件分摊 |
| 平台费用 | 佣金（0.5%~30%）、技术服务费、支付通道费（约 0.6%） | 按类目核对结算单 |
| 退货损失 | 退货率 ×（往返运费 + 不可二次销售比例 × 商品成本） | **最容易被漏掉的一项** |
| 达人成本 | 达人佣金 + 坑位费分摊 | 坑位费按预估销量分摊，事后用实际销量重算 |
| 营销成本 | 商家承担优惠券/平台补贴、赠品 | 平台承担的补贴不计入成本 |
| 固定分摊 | 人工、房租、设备折旧按月销量分摊 | 算保本售价时必须带上 |

## 二、核心公式（与 `scripts/profit_roi.py` 完全一致）

```
vc    = 商品成本 + 履约 + 其他变动成本 + 退货率 × 单均退货损失
k     = 佣金率 + 支付通道费率
CM    = P × (1 - k) - vc - 单件固定分摊          # 单件贡献毛利（不含广告）
g     = CM / P                                   # 毛利率（不含广告）
g_eff = g - 达人分摊率 - 目标净利率               # 可投广告比例
保本售价 = (vc + 单件固定分摊) / (1 - k - a - m)   # a=广告占售价比, m=目标净利率
单件净利 = CM - 单件广告费 - 单件达人成本 - 单件补贴
```

**自检**：把广告费代入 `单件广告费 = P × g_eff` 时，净利必须恰好等于「目标净利率 × P」。不相等说明口径混了。

## 三、定价四法（按优先级）

1. **保本倒推法（底线）**：先算保本售价，任何促销价不得低于它（清仓/引流款例外，需单独审批）
2. **竞品锚定法**：取同款 TOP10 的价格中位数，用「差异化卖点」决定溢价或折价幅度（±15% 内用户敏感度最低）
3. **价格带卡位法**：卡 99/129/199 这类心理价位，同时避开平台「比价坑位」（拼多多尤其敏感）
4. **组合定价法**：单件保本 + 多件赚利（第二件半价、三件八折），用件单价拉高 AOV

## 四、各平台费率速查（类目差异大，必须用结算单校对）

| 平台 | 常见佣金/扣点区间 | 备注 |
|---|---|---|
| 淘宝/天猫 | 0.5%~5%（部分类目更高）+ 天猫佣金另计 | 天猫有软件服务费与佣金双项 |
| 京东 | 类目扣点约 1%~10% | POP 与自营规则不同 |
| 拼多多 | 0.6%~3%（百亿补贴另有规则） | 活动价会压低毛利 |
| 抖店 | 1%~5%（类目差异大） | 达人佣金另计，通常 10%~30% |
| 小红书 | 佣金与服务费合计约 5%~20% | 薯条/信息流另计 |
| 快手小店 | 技术服务费约 1%~5% | 达人佣金另计 |
| 微信小店 | 技术服务费约 0.6%~5% | 视类目 |

> 佣金率超过 30% 或低于 0.5% → `settlement_audit.py` C1 会报异常，必须核对类目与是否重复计佣。

## 五、促销价底线规则

- **日常价**：≥ 保本售价 × (1 + 目标净利率)
- **活动价**：≥ 保本售价；低于保本的活动必须明确「引流款」定位，并限定数量与周期
- **直播价**：≥ 保本售价 + 坑位费分摊；坑位费按**实际**销量重摊后重算，不用预估销量
- **清仓价**：可低于保本售价，但必须单列，并计入当期亏损，不得与正常款混算利润

## 六、利润复核三问（交付前必答）

1. 退货率用的是近 30 天真实值还是拍脑袋？（拍脑袋 → `DATA_MISSING`）
2. 达人坑位费是否已经按实际销量重摊？（用预估销量 → 利润虚高）
3. 广告费是「分摊到件」还是「当期总投放」？（必须用分摊到件，否则毛利不可比）
