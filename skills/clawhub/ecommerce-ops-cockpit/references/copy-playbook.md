# 文案创作与合规：标题 / 主图 / 详情页 / 短视频 / 直播

## 一、标题（各平台字数与结构）

| 平台 | 长度 | 结构公式 |
|---|---|---|
| 淘宝/天猫 | ≤30 字 | 核心词 + 属性词 + 场景词 + 长尾词（前 10 字放核心词） |
| 京东 | ≤50 字 | 品牌 + 型号 + 核心词 + 关键参数 |
| 拼多多 | ≤30 字 | 词根 + 利益点 + 规格（价格力优先） |
| 抖店 | ≤30 字 | 场景 + 人群 + 痛点（内容化表达） |
| 小红书 | ≤20 字 | 人群词 + 场景 + 结果（搜索型：用户会搜的那句话） |

**铁律**：不堆砌同义词、不重复核心词、不写无关热词（会被判作弊降权）。写完必须过 `copy_compliance.py`。

## 二、主图五要素（前 3 秒决定点击率）

1. **卖点前置**：一句话说清「解决什么问题」，不写品牌故事
2. **场景化**：真人使用 / 使用前后对比 > 纯白底摆拍
3. **价格锚点**：活动价 + 划线价（划线价必须有成交依据）
4. **信任标**：销量、评价数、检测报告编号（有就写，没有不编）
5. **信息层级**：主图只放 1 个主信息，副信息放第 2–3 张

## 三、详情页结构（按犹豫人群的心理顺序）

```
痛点共鸣 → 解决方案 → 产品证明（参数/对比表/检测） → 使用场景 → 售后保障 → 催单（库存/时效）
```
- 对比表用「我们 vs 普通款」逐项列，禁止贬低同行（可以说「普通款」，不能点名）
- 所有功效宣称必须挂证据（检测报告编号 / 专利号），否则删掉
- 尺码表、材质表、物流时效表必备（直接降低退货率）

## 四、短视频脚本（3 秒定生死）

| 段 | 时长 | 写法 |
|---|---|---|
| 钩子 | 0–3s | 反常识结论或强痛点提问：「为什么你家的 XX 用了三天就 XX？」 |
| 痛点 | 3–10s | 具体场景 + 具体损失（不说「不好用」，说「每次都要 XX」） |
| 方案 | 10–25s | 产品出场 + 一个核心卖点（只讲一个） |
| 证明 | 25–40s | 实测画面 / 对比 / 数据（必须真实） |
| CTA | 40–45s | 明确动作：「点购物车看规格」「评论区说你的情况我帮你选」 |

禁止：开头喊「家人们」、全程叫卖、无证据的功效承诺。

## 五、直播话术四段式

1. **留人**（讲一个与产品相关的具体场景，不喊「欢迎」）
2. **种草**（卖点 + 证据 + 对比，回答一个弹幕真实提问）
3. **逼单**（限时限量必须真实：「这个价格只有这 20 单」，不能虚构库存）
4. **催付**（未付款提醒 + 发货时效承诺）

禁止：「全网最低」「最后一天」「亏本清仓」——全部在 P0/P2 词库内。

## 六、违禁词检查流程（强制）

```
写稿 → python copy_compliance.py --file 文案.txt --platform <平台>
     → P0 命中（退出码 1）：必须改，改完重跑，直到 0 处
     → P1 命中：补资质/证据，或改写
     → P2 命中：建议改，平台可能限流
```

- 词库：`assets/forbidden_words.json`（P0 极限/违禁 ~80 条、P1 需资质 ~55 条、P2 建议优化 ~35 条）
- 豁免：`exempt` 里的短语不误报（如「第一步」不算「第一品牌」）
- 临时加白：`--allow "短语"`，必须人工确认后才可用
- **通过词库 ≠ 绝对合规**：医疗、保健、特妆、食品等类目还有专门法规，涉及功效必须查资质

## 七、常见踩雷（命中即 P0）

极限词（最佳/第一/顶级/万能/永久）、国家机关名义（国家级/特供/国宴）、疗效承诺（根治/治愈/无副作用）、虚假促销（全网最低/最后一天/跳楼价）、站外引流（加微信/私聊/扫码）、格式条款（最终解释权）。

## 八、撰写生成骨架（直接套用，产出后再过合规扫描）

> 写文案时按骨架产出，禁止自由发挥堆词；每段填真实信息，没有的标注「待补」，不许编。写完后必须跑 `copy_compliance.py`。

**标题骨架**（≤平台字数，见 §一）：
`[核心词] + [属性词：材质/规格/型号] + [场景词：谁在用什么场景用] + [长尾词：精准需求]`
例：便携榨汁杯 大容量 无线充电 办公室健身随身榨果汁

**主图文案骨架**（5 张图分工）：
- 图1（卖点前置）：一句话解决什么问题 + 价格锚点
- 图2（场景化）：真人使用前后对比
- 图3（信任标）：销量/评价数/检测编号（有才写）
- 图4（参数表）：核心参数一图看懂
- 图5（催单）：库存/时效/售后保障

**详情页骨架**（按犹豫人群心理顺序）：
痛点共鸣 → 解决方案 → 产品证明（参数/对比表/检测） → 使用场景 → 售后保障 → 催单

**短视频脚本骨架**（套 §四时间轴）：
钩子(0-3s) → 痛点(3-10s) → 方案(10-25s,只讲一个卖点) → 证明(25-40s,真实实测) → CTA(40-45s,明确动作)

**直播话术骨架**（套 §五四段式）：
留人(具体场景,不喊欢迎) → 种草(卖点+证据+答真实弹幕) → 逼单(真实限时限量) → 催付(未付提醒+时效承诺)

## 九、去 AI 味自检（产出后必查，6 项）

> 文案读起来像不像人写的，直接决定转化率。这份 checklist 借鉴社区去 AI 味类技能的做法（「文章去AI味工具」「李白.Skill」），写完逐项自查，命中就改。

| # | 问题 | 典型症状 | 改法 |
|---|---|---|---|
| 1 | AI 高频词 | 值得注意的是 / 换句话说 / 总的来说 / 核心在于 / 由此可见 / 赋能 / 助力 / 打造 | 全删，换成大白话 |
| 2 | 过度结构化 | 每段都「首先/其次/最后」，每条一样长短 | 打断节奏，长短句交替 |
| 3 | 虚假客观 | 通篇陈述句，没有立场 | 改判断句：「A 和 B 根本不是一个东西」而非「两者存在差异」 |
| 4 | 机械化连接词 | 因此 / 综上所述 / 基于此 | 改成「所以 / 那 / 然后」 |
| 5 | 悬浮抽象词 | 新体验 / 更高品质 / 极致之选（无从验证） | 换成可验证描述：「充一次用 7 天」而非「续航强」 |
| 6 | 公式化结尾 | 每段升华、都喊「买它」 | 结尾给一个具体动作，或一个真问题 |

**检查顺序（两步缺一不可）**

```
① copy_compliance.py  —— 合规底线（违禁词/极限词必须清零）
② 去 AI 味 6 项       —— 人味上限（读起来要像人在说话）
```

注意顺序：**先合规，再人味**。为了「自然」去加极限词是不允许的；也不要为了过检测把文案改得没人味——两者都要过。
