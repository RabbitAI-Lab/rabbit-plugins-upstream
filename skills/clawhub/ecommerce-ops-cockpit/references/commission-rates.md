# 平台费率速查（R6 佣金率锚点）

> 用途：填 `profit_roi.py` 的 `--commission-rate` / `settlement_audit.py` 的佣金率区间校验时，先在这里对照平台与类目，确认费率落在 `0.5%~30%`（R6 红线）。
> **费率随类目、活动、年框浮动，下表为常见区间，精确值以商家后台「费率说明」为准；跨类目务必按实际合同填，不要套用均值。**

## 一、平台佣金率（类目佣金，常见区间）

| 平台 | 常见佣金率 | 备注 |
|---|---|---|
| 淘宝/天猫 | 0.5%–10%（多数 2%–5%） | 服饰/美妆偏高，部分类目有软件服务年费（年费可返） |
| 京东 POP | 2%–10% | 自营另算；3C/家电偏低，美妆/服饰偏高 |
| 拼多多 | 0%–1%（类目佣金极低） | 主要成本在「推广 + 活动坑位 + 服务费」；注意百亿补贴/秒杀的资源位费率 |
| 抖店（抖音电商） | 2%–10% | 美妆/个护/食品差异大；达人带货另计佣金（见下） |
| 小红书 | 0%–5% | 店铺佣金低，核心成本在薯条/聚光投放 |
| 快手小店 | 2%–5% | 类似抖店，达人分销另计 |
| 微信小店（视频号） | 1%–5% | 类目费率较低，核心在流量投流 |

## 二、支付通道费率（pay_rate，单独计，不计入平台佣金率）

| 渠道 | 常见支付费率 |
|---|---|
| 支付宝 / 微信支付（国内） | 0.6%–0.7%（多数 0.6%） |
| 微信小店自带支付 | 约 0.6% |
| 货到付款 / 银行转账 | 0%（但占用资金与对账成本） |

> `profit_roi.py` 的 `k = 平台佣金率 + 支付通道费率`，两者是**加和关系**，填参时别漏支付费率。

## 三、达人 / 坑位费（koll_unit，单列，不并入平台佣金率）

- 达人佣金：通常 **10%–30%**（美妆/食品可达 30%+，服饰 10%–20%）
- 坑位费：按场/按链接固定金额，需折算到「单件分摊」
- **R6 校验的是「平台佣金率」**，达人佣金走 `koll_unit` 字段，二者别混；但 `settlement_audit.py` 的 C6 会把「佣金 + 坑位费」合计成等效佣金率，超 30% 即告警重复计风险。

## 四、速填建议

1. 不确定费率 → 先去后台「费率说明 / 结算单」抄真实值，**禁止用本表均值填参**（违反 R1）。
2. 跨平台比价时，把各自真实佣金率 + 支付费率一起代入 `profit_roi.py`，口径才一致。
3. 若结算单算出的佣金率超出本表区间 → 先查是否类目选错、是否把达人佣金/坑位费并进了平台佣金（触发 C6）。
