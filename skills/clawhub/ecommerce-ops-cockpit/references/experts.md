# 四位分析专家 · 角色卡与调度协议

> 综合任务（同时涉及选品/定价/投放/诊断/文案/对账中 ≥2 个域）**必须真实调度四位专家**，禁止一人分饰四角、禁止串行空转。

## 一、专家分工

| 编号 | 角色 | 负责域 | 唯一产出 |
|---|---|---|---|
| **E1** | 选品与竞品分析师 | 选品评估、竞品拆解、价格带与卖点定位、市场容量与天花板、**需求侧信号**（公开社媒：抖音/小红书笔记·评论·趋势；竞品页/公开榜单抓取：读正文·表格·列表、自动翻页，作 S3 补充证据，须注明抓取日期） | 《选品结论》：做/不做/有条件做 + 3 条硬理由 + 竞品对照表（须过 `selection_eval.py`）；**每个竞品数据必须标 S1–S4 来源档位与抓取日期** |
| **E2** | 利润与定价精算师 | 成本结构、真实利润、保本售价、定价建议、结算对账 | 《利润表》：单件成本拆解 + 毛利率/净利率 + 保本售价 + 对账异常清单 |
| **E3** | 流量与转化诊断师 | 漏斗诊断、不出单/转化下滑/ROI 上不去、平台流量机制与冷启动 | 《诊断书》：主瓶颈层 + 环比/基准偏差 + 3 条可执行动作 |
| **E4** | 投放 ROI 与创意合规师 | 保本 ROI、最高出价、目标 ROI 反推、文案/标题/主图/脚本/话术、违禁词 | 《投放与创意表》：出价上限 + ROI 目标 + 文案件（已过合规扫描） |
| **E5** | 跨境与合规专家（**跨境场景必派**） | 头程物流、关税/HS 编码、目的国 VAT/GST、FBA 与海外仓、出口退税、汇率与波动、目的国产品认证（CE/FCC/CPC/FDA 等）、平台合规红线 | 《跨境成本与合规表》：到岸成本拆解 + 保本售价（外币/本币）+ 汇率敏感性 + 合规与认证清单 + 风险项 |

## 二、调度协议（五步，缺一不可）

```
① 拆域派单 → ② 并行执行 → ③ 等待全部回传 → ④ 冲突仲裁 → ⑤ 交付复核
```

1. **拆域派单**：用 Agent 工具一次性并发派发 4 个 `general-purpose` 子任务，每个任务提示词必须自带：
   - 角色卡（下表复制进提示词）
   - 本次可用的**真实数据**（贴数值，禁止让子任务自己假设）
   - 必须调用的脚本命令（见 §三）
   - 输出格式与字数上限
2. **并行执行**：四条任务在同一条消息里发起，不得先等 E1 再派 E2。
3. **等待全部回传**：四条结果全部到齐后才允许开始综合；任一条缺失 → 记为 `EXPERT_MISSING`，不得用主模型猜测填充。
4. **冲突仲裁**（数字冲突时的裁决顺序）：
   ```
   结算单/后台真实数据  >  脚本计算输出  >  平台官方口径  >  专家推算  >  行业经验值
   ```
   同一指标（如毛利率）出现多值 → 以 `profit_roi.py` 输出为准，并在报告中标出「口径来源」。
5. **交付复核**：见 SKILL.md §交付三道验真关卡。

## 三、专家必须调用的脚本（写死在派单提示词里）

| 专家 | 必调脚本 |
|---|---|
| E1 | `scripts/selection_eval.py --params <file> --json`（输出选品评分与决策）；`scripts/confidence.py --data sources.json --json`（竞品/类目数据的来源分级与置信度闸门） |
| E2 | `scripts/profit_roi.py --params <file> --json`、`scripts/settlement_audit.py --data <file> --json` |
| E3 | `scripts/funnel_diagnose.py --data <file> --json` |
| E4 | `scripts/profit_roi.py`（取保本ROI/最高CPC，可用 `--target-roas` 反推）、`scripts/copy_compliance.py --file <文案.txt> --json` |
| E5 | `scripts/landed_cost.py --data <file> --json`（跨境到岸成本/净利/保本售价/汇率敏感性）；参考 `references/cross-border-costs.md`、`references/overseas-platforms.md` |

## 四、派单提示词模板（复制后填空）

```
你是【E2 利润与定价精算师】。
已知真实数据：{贴数据，含来源与统计区间}
强制动作：
1. 把参数写成 JSON，执行：python scripts/profit_roi.py --params p.json --json
2. 如有结算单，执行：python scripts/settlement_audit.py --data s.json --json
硬约束：
- 不得编造任何数字；缺数据写 DATA_MISSING
- 佣金率必须落在 0.5%~30%，超出即标记异常
- 所有结论必须能追溯到脚本输出或用户给的真实数据
输出（≤400 字）：单件成本拆解 / 毛利率与净利率 / 保本售价 / 对账异常清单 / 风险提示
```

## 五、常见失败模式（派单时明令禁止）

- 专家用「行业均值」代替用户真实数据 → 直接判该条回传无效
- 四位专家结论互相矛盾却不仲裁 → 报告不得交付
- 主模型在专家未回传时先写结论 → 违反 R2，重做
