# 四种非招标采购方式对照表

> 依据 P4 国资发改革规〔2024〕53 号 + P5 GB/T 43711-2024。适用于央企；地方国企对照本地规定（如川国资委〔2025〕51 号），条件口径一致。

| 维度 | 询比采购 | 竞价采购 | 谈判采购 | 直接采购 |
|---|---|---|---|---|
| **竞争属性** | 竞争（≥3 家） | 竞争（≥3 家） | 竞争（≥2 家） | 非竞争（特定供应商） |
| **报价方式** | 一次报出不可更改 | 多轮次公开竞争报价 | 一轮或多轮谈判 | 商议确定 |
| **核心适用条件** | ①需求清晰准确完整 ②技术质量标准化高 ③潜在供应商 ≥3 家 | ①需求清晰准确完整 ②技术质量标准化高 ③以价格竞争为主 ④潜在供应商 ≥3 家 | 满足其一：①技术复杂/性质特殊无法准确提需求 ②需求明确但多实施方案可选 ③供应商仅 2 家 ④联合研发/共担风险原创性商品服务 | 满足七类情形之一（详见直接采购七类情形详解） |
| **与竞价的关键区别** | 综合评审（价格+技术/服务） | 以价格决定 | 多方案/需求不明 | — |
| **典型场景** | 标准化通用货物、常规服务（办公用品、IT 设备） | 大宗通用物资、燃料、原材料（以价为决定因素） | 系统集成、科研服务、设计咨询、首台套 | 涉密、抢险救灾、知识产权、原厂维保、战略储备 |
| **供应商最低数** | 3 家 | 3 家 | 2 家 | 1 家（特定） |
| **是否需论证记录** | 是（方式选择理由） | 是 | 是（谈判要点） | 是（七类情形逐项验证 + 审批） |

## 适用条件判定速记

- 供应商 < 3 家且非直接采购七类 → 看是否仅 2 家（谈判）；仍不足 → 提示拓展寻源或核直接采购。
- 供应商 ≥ 3 家 + 需求清晰标准化：
  - 以价格竞争为主 → **竞价**
  - 需综合评审 → **询比**
- 需求不清晰 / 多方案 → **谈判**
- 唯一/涉密/紧急/配套/战略 → **直接采购**（须验证七类子条件）

## 红线提醒

- 依法必须招标项目（400/200/100 万 + 性质 + 资金）**不得**选用上述任何非招标方式。
- 直接采购七类情形**不得扩大解释**，须逐类逐子条件验证。
