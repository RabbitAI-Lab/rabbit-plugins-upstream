## Description: <br>
Query crypto wallet portfolios, transactions, DeFi positions, NFTs, token prices, and gas fees across EVM chains and Solana using Zerion's API. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, analysts, and crypto operations teams use this skill to query Zerion wallet, token, NFT, DeFi, and gas-price data through a configured MCP server. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Queried wallet addresses, token identifiers, and related research questions are sent to Zerion. <br>
Mitigation: Use the skill only for authorized wallet research and avoid submitting sensitive customer, competitor, or internal investigative targets without approval. <br>
Risk: The skill requires an API key for the Zerion MCP server. <br>
Mitigation: Use a dedicated or revocable API key where possible and verify the MCP server URL before adding credentials. <br>
