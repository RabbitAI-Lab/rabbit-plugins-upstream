## 3. P0 论文深度分析

### 3.1 GradCuit: Credit-Assigned Gradient Flow Enables Robust and Interpretable Test-Time Latent Reasoning

**基本信息**
- arXiv: 2608.02585 (2026-08-03)
- 作者: Zhaoxin Yu, Qi Shen, Hengli Li 等
- 机构: 清华/智源相关

**核心动机**
现有的 test-time latent reasoning 方法通过 decoded tokens 连接 latent states 和 reasoning trajectory，导致序列级别的 credit assignment 是间接的。GradCuit 通过在 Transformer 层之间插入可优化的 latent states，利用因果自注意力为每个 continuation token 提供到前面 latent state 的可微路径。

**核心方法**
- 在 prompt hidden representations 和 generated continuation 之间插入可优化 latent states
- 因果自注意力提供从 continuation token log-probability 到前面 latent state 的可微路径
- 整个 continuation 的 reward-weighted gradients 直接分配给 latents

**实验结果**
- 5 个 instruction-tuned backbones, 3 个 reasoning benchmarks
- 平均准确率 64.5%，超过 CoT prompting 6.6 个百分点
- 相比 LatentSeek 标准差从 1.53 降至 0.82，更鲁棒

**与用户研究的关联**
直接相关。GradCuit 解决的是 token-level credit assignment 问题，与当前 multi-scale credit assignment 研究高度契合。其"通过梯度直接分配 credit"的思路可能比传统的 advantage estimation 更精细。

### 3.2 RoMeRL: Balancing Feedback Coverage and the Memory-Reward Trap in Self-Evolving Agent Memory

**基本信息**
- arXiv: 2608.02508 (2026-08-03)
- 作者: Yi Yang, Zhennan Chen 等

**核心动机**
Self-evolving LLM agent 的 memory system 面临两个耦合挑战：(1) trajectory-indexed utilities 随交互历史增长，反馈分散在膨胀的状态空间；(2) trajectory-level rewards 联合分配给 co-retrieved memories，不相关经验可能获得误导性 utility 更新，陷入 memory-reward trap。

**核心方法**
- Reduced-Order Memory Reinforcement Learning
- 用固定维度的 per-task memory state 表示增长的 trajectory-indexed utility space
- 通过 outcome polarity 和 memory dynamics 因子化
- 新经验通过固定语义坐标集整合，反馈集中在有界的 utility support 上

**实验结果**
- ALFWorld 和 LifelongAgentBench
- Cold-Q ratio 降低 80.0%
- Feedback density 提升约 6.0 倍
- Memory size 减少 84.4%
- LLM calls 减少 21.1%

**与用户研究的关联**
高度相关。RoMeRL 将 credit assignment 与 memory 结合，提出了"reduced-order utility states"的新视角。这暗示 credit assignment 和 memory 可能不是独立问题——agent 的记忆结构会影响 credit 的分配效率。

### 3.3 TreeCredit: Shared-Prefix Credit Assignment for Multi-Agent Reasoning

**基本信息**
- arXiv: 2608.02291 (2026-08-03)
- 作者: Yiqing Liu, Zihao Wang 等

**核心动机**
Multi-agent reasoning (MAR) 中，现有的 adaptive routing 方法从 query-level labels 或 trajectory-level returns 学习，这种粗粒度监督无法准确估计多步协作中每个 operator 的状态条件效用。

**核心方法**
- Shared-prefix credit assignment framework
- 通过 state-matched downstream comparisons 估计 operator utility
- 构建 shared-prefix collaboration trees
- 为每个 state-operator pair 分配 correctness-prioritized suffix credit

**实验结果**
- 6 个 reasoning benchmarks
- 准确率适度提升，推理成本显著降低
- 比代表性 MAR 方法更好的 accuracy-cost trade-off

**与用户研究的关联**
相关。TreeCredit 解决的是 multi-agent 场景下的 credit assignment，但当前项目主要是 single-agent。不过其"shared-prefix"思路可能对 multi-turn agent 的 credit propagation 有启发。

## 4. P1 论文概述

### 4.1 APPO: Agentic Procedural Policy Optimization
- arXiv: 2606.12384
- 将 branching 和 credit assignment 从 coarse interaction units 转移到 fine-grained decision points
- 使用 Branching Score 结合 token uncertainty 和 policy-induced likelihood gains
- 13 个 benchmarks 上提升近 4 个点

### 4.2 GAGPO: Generalized Advantage Grouped Policy Optimization
- arXiv: 2605.13217
- 将 TD/GAE-style temporal estimator 引入 critic-free grouped RL
- Step-aligned credit propagation without additional critic

### 4.3 TRIAGE: Role-Typed Credit Assignment for Agentic RL
- arXiv: 2606.32017
- 通过语义 role label 区分有用探索和无进展行为
- 使用 judge 作为结构化分类器而非 scalar scorer

## 5. 方法簇识别与趋势变化

### 5.1 方法簇图谱

```
Credit Assignment (Agentic RL)
│
├── 【Fine-grained Token-level】
│   ├── GradCuit (gradient through circuit)
│   └── APPO (procedural decision points)
│
├── 【Memory-Coupled】
│   └── RoMeRL (reduced-order utility states)
│
├── 【Shared-Prefix / Tree】
│   └── TreeCredit (multi-agent)
│
└── 【Role-Typed / Semantic】
    └── TRIAGE (semantic role labels)
```

### 5.2 趋势变化判断

**趋势 1**: Credit assignment 正在从"在哪里分配"转向"如何表示效用空间"
- RoMeRL 的 reduced-order utility states
- GradCuit 的 gradient-through-circuit
- 共同点：不直接改进分配公式，而是改变效用/梯度的表示方式

**趋势 2**: Memory 和 credit assignment 的耦合越来越紧密
- RoMeRL 明确将 memory structure 和 credit distribution 联合优化
- 这暗示 future direction 可能是"memory-aware credit assignment"

## 6. 对当前研究项目的潜在影响

### 6.1 直接影响
1. **GradCuit 的 gradient-through-circuit 思路** — 可能适用于当前项目的 token-level credit assignment。如果当前的 credit assignment 是基于 advantage estimation 的，可以尝试替换为 gradient-based 方法。
2. **RoMeRL 的 reduced-order utility states** — 对 multi-scale credit assignment 有启发。如果 agent 的 memory 可以压缩为固定维度的 utility states，credit assignment 的计算效率可能大幅提升。

### 6.2 风险信号
- 本周没有直接关于"process reward model"或"turn-level advantage"的新工作
- 方向似乎在向更细粒度（token/procedural）或更结构化（memory/role）发展
