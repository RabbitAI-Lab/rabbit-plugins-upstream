## Description:

Provides local AI-writing self-checks and academic-polishing guidance, including sentence-level suggestions, terminology and consistency checks, and reports.

This skill is ready for commercial/non-commercial use.

## Publisher:

[docsor1212](https://clawhub.ai/user/docsor1212)

### License/Terms of Use:

MIT-0

## Use Case:

Academic authors and editors use the skill to review drafts for AI-writing signals and receive sentence-level, terminology, consistency, translation-style, and journal-convention guidance without automatically rewriting the text.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Crafted report files may inject browser scripts into generated HTML dashboards.

Mitigation: Render dashboards only from report JSON generated by the tool and avoid dashboards created from untrusted reports until the renderer is fixed.

Risk: AI-writing detection scores can be unreliable, especially for short or medical text.

Mitigation: Treat scores as advisory, account for the documented text-length limitations, and review terminology suggestions before using them.
