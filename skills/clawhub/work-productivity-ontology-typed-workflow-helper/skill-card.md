## Description:

Helps AI-agent users, skill authors, maintainers, and teams create practical ontology-style workflows, artifacts, checklists, analyses, implementation support, and adjacent skills for work-productivity needs.

This skill is ready for commercial/non-commercial use.

## Use Case:

External developers, agent users, skill authors, maintainers, and teams use this skill to turn broad ontology-style productivity needs into local-friendly workflows, checklists, decision aids, analysis, or code-oriented implementation support.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger wording may activate the skill for unrelated knowledge, graph, memory, creating, or bug-fix requests.

Mitigation: Narrow the trigger terms or confirm that the request is about ontology-style workflow planning before applying the skill.

Risk: Generated workflows, checklists, or implementation guidance may be incomplete when user constraints or success criteria are missing.

Mitigation: Restate assumptions, ask only for material missing inputs, and validate the result against the stated success criteria before use.
