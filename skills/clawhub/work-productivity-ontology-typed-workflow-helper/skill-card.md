## Known Risks and Mitigations:

Risk: Broad activation wording may cause accidental invocation for ordinary workflow or bug-fix requests.

Mitigation: Invoke the skill explicitly for ontology-style workflow planning, and tighten trigger wording if accidental routing appears after installation.

Risk: The skill produces workflow, analysis, code, shell command, and configuration guidance that may not fit every local project constraint.

Mitigation: Review generated assumptions, commands, code changes, and validation notes against the target project before applying them.
