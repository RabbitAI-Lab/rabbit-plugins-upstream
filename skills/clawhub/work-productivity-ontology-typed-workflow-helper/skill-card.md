## Description:

Helps AI-agent users, skill authors, maintainers, and teams create ontology-style workflows, typed knowledge-graph planning artifacts, checklists, analyses, and implementation support for reliable work-productivity workflows.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

External developers, skill authors, maintainers, and AI-agent users use this skill to turn demand for ontology-style work-productivity workflows into practical local artifacts such as plans, templates, checklists, analysis, code changes, and verification notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generic trigger terms may invoke the skill for unrelated tasks.

Mitigation: Use the skill explicitly for ontology-style workflow, typed schema, or knowledge-graph planning tasks and verify that the response matches that scope.

Risk: Workflow or code guidance could be applied without review.

Mitigation: Review generated plans, code changes, shell commands, and configuration before deployment, then validate outputs against the stated success criteria.
