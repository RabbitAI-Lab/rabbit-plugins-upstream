## Description: <br>
Helps AI-agent users, skill authors, maintainers, and teams create practical GitHub-style workflows for bug fixing, setup hardening, reliability improvement, and adjacent skill development. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, AI-agent users, skill authors, maintainers, and teams use this skill to turn GitHub-style software and data workflow needs into actionable plans, checklists, code changes, artifacts, and verification notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger wording may activate the skill for generic GitHub, CLI, issue, API, or bug-fix requests. <br>
Mitigation: Narrow the trigger wording or disable implicit invocation when precise routing is required. <br>
Risk: Developer workflow guidance may include code or shell commands that are unsuitable for a specific repository or environment. <br>
Mitigation: Review proposed changes and run the included verification steps before applying outputs to important projects. <br>
