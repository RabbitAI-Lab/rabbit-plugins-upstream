## Use Case:

External users use this Chinese-language skill to turn a personal capability goal into a practical 90-day action plan. It gathers the user's current AI tool use, strengths, available time, blockers, and target outcome, then produces weekly tasks and review checkpoints.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The generated plan may include personal goals, constraints, reflections, and the user's name in a local Markdown file.

Mitigation: Ask the agent to show the plan inline or confirm the filename before saving, and review the file before sharing it.
