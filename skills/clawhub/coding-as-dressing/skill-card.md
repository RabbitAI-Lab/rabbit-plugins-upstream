用日常穿搭比喻解释代码，帮助小白理解。当用户要求用穿搭、穿衣、衣柜、outfit 比喻解释代码，或提到 Coding as Dressing 时使用。 <br>

## Use Case: <br>
Developers, learners, and code reviewers use this skill to explain selected code through everyday clothing analogies. It is intended for beginner-friendly structure, issue, and improvement explanations when the user asks for a clothing, outfit, wardrobe, or Coding as Dressing framing. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may activate on ordinary simple code-explanation prompts even when the user did not explicitly request a clothing analogy. <br>
Mitigation: Use it when the user asks for a clothing, outfit, wardrobe, or Coding as Dressing analogy; otherwise prefer a normal code-explanation workflow. <br>
Risk: The skill may answer in Chinese when the user expects another language. <br>
Mitigation: Follow the user's requested language when stated, or ask before continuing if language expectations are unclear. <br>
Risk: Analogy-based explanations can simplify behavior and may miss details needed for code changes. <br>
Mitigation: Treat suggested deletions, merges, or fixes as guidance and verify them against the actual code before applying changes. <br>
