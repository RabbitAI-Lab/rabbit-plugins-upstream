# Dev Update: 2026-02-25

## The Big Shift

What started as refining CASH.md pricing turned into discovering the actual product. AI CASH is not a payment tool. It's the economic layer for the agent economy.

## What Happened Today

### 1. Pricing Model Refined

Split pricing into two clean rails:
- **Partner stores (Stripe):** No buyer fees. Merchant pays 2-5% channel fee via Stripe Connect application_fee.
- **Paywalled content (x402):** Buyer pays $0.25 + card processing. Seller pays nothing.

No double-dipping. Each rail has one side paying. Researched fee structures across 12 major platforms (Uber Eats, DoorDash, Etsy, Shopify, Amazon, Stripe Connect, Apple/Google, Gumroad, Patreon, Square, PayPal, Substack). Our total effective take (2-10%) is the cheapest in the market.

### 2. Custody Model Simplified

Three paths existed in the code. Simplified to two for launch:
- **AI CASH:** Pool mode. Parker's USDC, Parker's keys. Apple Pay.
- **AGENT WALLET:** CDP only. User's USDC, user's keys. Sovereign. No fees.

Privy path (custodial user wallets) parked until traction proves it's needed.

### 3. Connectors: The Actual Product

The breakthrough. A marketplace where developers publish paid capabilities (connectors) that any AI agent can discover and use. Consumer pays per use via AI CASH. Developer never builds billing.

Consumer experience: agent proposes a task, estimates cost, consumer taps Apple Pay once. Multiple developers get paid. Zero accounts or API keys.

Developer experience: write a YAML manifest, deploy an endpoint, publish. Done. No Stripe integration, no auth system, no billing dashboard.

Both GPT and Grok independently said: "This is the product, not a feature."

### 4. Stripe Connect as Platform Infrastructure

All three products (AI CASH, Connectors, Partner Stores) run through Stripe Connect. One integration. Stripe is the custodian. We never hold funds. Not a money transmitter.

Key insight from reviews: the **wallet (prepaid balance)** solves the micropayment economics. User loads $25 once, spends in micro-increments. Effective Stripe cost drops from 50%+ to under 1%.

### 5. Unsupported Partner Gate

When an agent hits a non-partner store: "This seller isn't an AI CASH partner yet. Want us to reach out?" Every failed purchase becomes a lead. Partner pages become agent-readable skills for automated onboarding.

### 6. Markdown Viewer Fix

Fixed SSE connection pile-up causing blank pages in Chrome. Root cause: Chrome's 6-connection-per-domain limit. Hidden tabs now release SSE connections. Server auto-closes after 5 min. Released as wip-markdown-viewer v1.2.5.
