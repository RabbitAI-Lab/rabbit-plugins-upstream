## What We Built Tonight

A micropayment skill for AI agents. Any agent (Grok, Claude, Cursor, OpenClaw, whatever comes next) can ask a human to authorize a small Coinbase payment. One command. One approval. One self-destructing URL.

**The core idea:** agents need to buy things (subscriptions, API credits, coffee) but have zero wallet. Humans hate copy-pasting payment proofs. wip-agent-pay sits in the middle. The agent asks, you authorize, the money moves through your isolated Coinbase portfolio, and the agent gets a one-time URL on pay.wip.computer that proves the payment happened. URL dies after first use.

**Built live** across two agents. Grok wrote the initial structure and spec. Claude Code reviewed, hardened, and shipped to GitHub.

## Architecture Decisions

**Why Coinbase isolated portfolio, not a wallet?**
Because wallets are scary. A portfolio with $50 max exposure, locked API key, IP-allowlisted. If compromised, worst case is $50. Not your life savings.

**Why Cloudflare Worker, not a server?**
Free tier handles thousands of requests/day. Zero ops. Global edge. KV is fast enough for micropayments. No server to maintain.

**Why one-time URLs, not tokens in headers?**
Because agents operate in text. They can't set HTTP headers in most UIs. A URL is universal. Paste it. Click it. Done. And it dies after one use so there's nothing to steal.

**Why 1Password, not env vars?**
Because Parker's architecture is 1Password-native. SA token, no .env files, no credentials on disk. The agent proves authority through 1Password every time.

**Why atomic delete instead of mark-used?**
Two simultaneous requests could both read "used: false" before either writes "used: true". Delete-on-read means first reader wins. Second reader gets 410. No double-spend.
