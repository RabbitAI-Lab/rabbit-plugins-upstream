## What Shipped Today (Session 2)

### Four-Path Architecture
Figured out the entire payment model. Not just one approach ... four paths that cover everyone from normies to crypto-native power users.

| Path | Model | Status |
|------|-------|--------|
| **1. Self-custody** | User owns wallet (CDP or Privy). Agent signs x402 payments. | **BUILT** |
| **2. We-hosted wallet** | We create wallets for users. We custody. | SPEC'd (needs inc + % fee) |
| **3. Stripe + our float** | Stripe holds fiat, we front crypto. | SPEC'd (needs inc + % fee) |
| **4. Pass-through** | Apple Pay per transaction. Money goes directly to seller. Zero custody. | **BUILT** |

Path 4 is the default. No wallet. No crypto. No setup. Face ID and done.

### Key Architecture Decisions

**Stripe is funding, not spending.** User taps Apple Pay, money goes in. CDP/Privy wallets spend it out via x402.

**Pass-through is default.** No wallet needed. Stripe sends money directly to seller. We never custody.

**Crypto is plumbing.** User never sees USDC, Base, Monad, EIP-3009. "My agent bought it."

**Seller registration.** Sellers register Stripe Connect accounts. Worker maps domains to account IDs.

**Budget enforcement in Worker.** Daily + per-tx limits checked before every payment. Ledger tracks all transactions.

### Research Findings

- **Stripe** ... native Cloudflare Worker SDK, Apple Pay auto, USDC payouts (Base + Polygon), x402 support launched Feb 2026
- **Coinbase CDP v2** ... Ed25519 JWT auth, `signTypedData` for EIP-712, Worker-safe via Web Crypto
- **Privy** ... HTTP Basic Auth, `eth_signTypedData_v4` RPC, acquired by Stripe (June 2025)
- **Uber uses Stripe** (primary) + Adyen (secondary)
- **Cloudflare NET Dollar** ... USD stablecoin for AI agent micropayments (announced Sept 2025)
- All four processors (Stripe, Braintree, Adyen, Square) have same $0.30 fixed fee problem for micropayments

### The Insight

Parker's friend Chris pointed out: "You made an elegant thing for normies that have Coinbase accounts." Then Parker realized: skip the Coinbase requirement entirely. Apple Pay. Face ID. The user doesn't know it's crypto. Venmo doesn't say "ACH transfer." Agent Pay doesn't say "USDC."

Then the custody question led to four paths. Path 4 (pass-through) is the breakthrough ... zero custody, zero setup, pure Apple Pay. The incorporation and fee structure for Paths 2-3 can come later.
