## Description:

Design and build distinctive websites, interactive 3D websites, portfolios, and product stories with art direction, scroll choreography, parallax, text animation, optional Three.js/WebGL scenes, responsive behavior, reduced-motion support, and static fallbacks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mustbesimo](https://clawhub.ai/user/mustbesimo)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, designers, and external site builders use this skill to design or implement scroll-led marketing pages, portfolios, product stories, interactive 3D scenes, and motion audits while preserving accessibility, responsive layouts, reduced-motion behavior, and fallbacks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Website and motion-design work can modify project files, routes, assets, or page behavior.

Mitigation: Review diffs and verify the resulting page locally before using it on a production site.

Risk: Package installs, publishing, deployment, or sending project content to external services may exceed normal local design work.

Mitigation: Allow those actions only when the user explicitly requests them.

Risk: Scroll effects, autoplay motion, or real-time 3D can reduce accessibility or performance if fallbacks are incomplete.

Mitigation: Verify responsive layouts, keyboard access, reduced-motion behavior, static fallbacks, and browser runtime errors before handoff.
