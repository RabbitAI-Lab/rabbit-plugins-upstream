## Description:

Design, build, or improve cinematic scroll-driven websites with clear storytelling, purposeful motion, responsive fallbacks, accessibility, and browser-based proof. Use for product stories, portfolios, launches, editorial experiences, interactive heroes, and real-time 3D scenes; not for ordinary dashboards or unrelated animation.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and designers use this skill to plan, build, repair, and verify scroll-driven web experiences such as launch pages, portfolios, product stories, interactive heroes, and real-time 3D scenes while preserving readability, accessibility, responsive fallbacks, and browser proof.

Global

## Known Risks and Mitigations:

Risk: Agent-guided edits can change web project behavior or introduce incorrect motion, accessibility, dependency, or verification guidance.

Mitigation: Review proposed edits, dependency installs, deployments, and external service use before approval; run local build and browser verification when requested.
