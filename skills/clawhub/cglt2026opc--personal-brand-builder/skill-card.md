## Use Case:

External users use this Chinese-language skill to turn real work history, cases, and available time into a personal-brand positioning and content plan. It helps identify credible positioning labels, plan content production, and produce a Markdown personal branding plan.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The generated branding plan could overstate or misrepresent the user's real experience if the user's inputs are incomplete or unverified.

Mitigation: Base positioning labels on real cases, skills, and outcomes, and have the user review the plan before publishing or sharing it.

Risk: The skill can produce or save a Markdown plan file, which could overwrite an existing file if the target path is unclear.

Mitigation: Confirm the filename and save location before writing or overwriting any Markdown file.

Risk: Generated public-facing content may include attribution or planning details that the user does not want to share.

Mitigation: Review the final Markdown, including attribution text, before using it in public profiles, posts, or client-facing materials.
