## 支持的PPT类型

**结构模板**：封面→研究背景→文献综述→研究问题→研究方法→实验/数据分析→结果讨论→创新点→不足与展望→致谢→QA

- 年终总结/述职报告

**结构模板**：封面→工作概述→核心成果→数据展示→问题分析→改进措施→下阶段计划→资源需求→总结→QA

## 工作流程

1. **需求确认**
   - PPT类型（答辩/汇报/路演/教学/其他）
   - 页数要求（10/15/20/25/30页）
   - 目标受众（导师/领导/投资人/学生/客户）
   - 风格偏好（学术严谨/商务专业/创意活泼/极简大气）
   - 是否需要数据图表

2. **大纲生成**
   - 根据类型匹配最佳结构模板
   - 调整页数适配内容密度
   - 确保逻辑递进、故事线清晰

3. **内容填充**
   - 每页：标题 + 3-5个要点 + 建议配图/图表类型
   - 核心页面（痛点/方案/数据/结论）重点展开
   - 过渡页设计建议

4. **优化建议**
   - 配色方案推荐（根据场景）
   - 字体选择建议
   - 图表类型建议
   - 演讲备注要点

## 格式输出规范

每页输出格式：
```
第X页 | [页面类型：封面/目录/过渡/内容/总结]
标题：XXXX
要点：
- 要点1（建议配图类型）
- 要点2
- 要点3
演讲提示：XXX
```

## 配色方案库

根据场景推荐配色：
- **学术答辩**：深蓝+白+灰（专业严谨）
- **商业路演**：深蓝+金色/橙色（高端大气）
- **互联网产品**：紫色渐变+白（科技感）
- **教育培训**：绿色+白+浅灰（清新自然）
- **创意设计**：撞色搭配（活力创新）
- **医疗健康**：蓝绿+白（专业可信）

## 注意事项

- 所有内容原创生成，不套模板
- 自动调整内容密度适配页数
- 每页3-5个要点为最佳阅读密度
- 核心数据页建议配图表（标注图表类型）
- 支持用户输入已有素材，在其基础上完善
