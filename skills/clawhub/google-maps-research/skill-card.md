## Description:

Search Google Maps businesses and places, retrieve place details, and inspect review samples or photos through the Crawlora REST API. Use for current place lookups and comparisons, including addresses, ratings, review themes, and business information.

This skill is ready for commercial/non-commercial use.

## Publisher:

[crawlora-org](https://clawhub.ai/user/crawlora-org)

### License/Terms of Use:

MIT-0

## Use Case:

Agents and researchers can use this skill to look up businesses and places, refresh place details, and compare addresses, ratings, review samples, or photos. It is suited to place research that benefits from current source links and clearly stated data gaps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Using the skill requires trusting Crawlora with an API key; the security analysis has medium confidence because some evidence was incomplete.

Mitigation: Use the skill only if comfortable providing the key to Crawlora, keep it in the environment, and review the complete package if the incomplete scan evidence affects your decision.
