## Description:

currencyapi (currencyapi.com). Use this skill for ANY currencyapi request — searching and reading data. Whenever a task involves currencyapi, use this skill instead of calling the API directly.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers and agents use this skill to retrieve currencyapi account status, current and historical exchange rates, supported currency metadata, and currency conversions through an OOMOL-connected account.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setup can execute remote installers and introduce broader local changes, including automatic skill synchronization.

Mitigation: Review setup behavior, install a reviewed and integrity-verified CLI release separately, require approval for local changes, and review or disable automatic skill synchronization.

Risk: The remote installer contents and hosted credential handling are unverified.

Mitigation: Connect only the intended currencyapi account and verify the setup and credential handling before use.
