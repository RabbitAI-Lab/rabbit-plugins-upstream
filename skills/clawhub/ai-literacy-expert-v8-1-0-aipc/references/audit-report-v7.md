## 1. 升级背景

V6 在第三期 Production AI Skills 大赛已验证 172/172 满分通过，但其「Hybrid AI 端云协同」仍属粗粒度概念。V7 的升级目标：

1. **从粗粒度到细粒度**：V6 按能力划分端云；V7 按任务划分端云
2. **从可上云到零上传**：V6 离线优先但允许数据上云；V7 原始数据永远本地
3. **从概念到协议**：V6 无统一协议；V7 定义 Edge-Cloud Protocol v1.0

## 2. 设计哲学继承

### 2.1 核心设计哲学

> "大模型擅长创意决策（故事编排、字幕撰写、节奏把控），但把解码、抽帧、多模态理解这类视频素材的'重活'——交给 AI PC 本地算力来处理，才是最高效、最经济、最安全的方案。这就是「端云协同」的核心理念。"

## 4. V7 三大核心创新

### 4.1 创新 1 · 零上传隐私计算
- **首创 4 级 PII 自动脱敏**：标识符/关系/行为/内容
- **可审计的零上传证明（ZUP）**：每次端云交互都有审计记录
- **合规支持**：GDPR / 中国《个人信息保护法》/ COPPA

### 4.2 创新 2 · NPU 11 TOPS 智能调度
- **三级算力异构**：NPU（持续推理）+ iGPU（视觉/并行）+ CPU（协调）
- **性能基准**：OCR 4x、ASR 6x、TTS 3x、VLM 5x 加速

### 4.3 创新 3 · Edge-Cloud Protocol v1.0
- **6 段标准化请求结构**：protocol_version / request_id / intent / abstract / request / callback
- **4 大核心约束**：abstract_data < 10KB / pii_detected = false / 7 天保留 / 端侧执行
- **5 级降级策略**：端云协同 → 仅端侧 → 完全本地
