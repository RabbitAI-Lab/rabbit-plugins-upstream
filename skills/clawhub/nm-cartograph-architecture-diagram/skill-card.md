## Description: <br>
Generates a Mermaid architecture diagram showing high-level component relationships. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[athola](https://clawhub.ai/user/athola) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to inspect a codebase or plugin set and create a concise architecture diagram for onboarding, PR review, or system documentation. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Architecture diagrams may expose sensitive internal system structure when rendered or shared outside an approved environment. <br>
Mitigation: Use approved rendering tools and avoid external rendering for diagrams that reveal sensitive internal architecture. <br>
Risk: The generated diagram may omit important components or misstate relationships in complex codebases. <br>
Mitigation: Review the Mermaid diagram against the source project before using it for onboarding, PR review, or documentation. <br>
