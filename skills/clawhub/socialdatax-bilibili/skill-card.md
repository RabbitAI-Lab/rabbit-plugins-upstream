## Description:

Provides Bilibili video and article search, content and comment analysis, creator information, and on-request video downloads.

This skill is ready for commercial/non-commercial use.

## Publisher:

### License/Terms of Use:

## Use Case:

People researching Bilibili content can use the skill to find videos and articles, review content and comments, inspect creator profiles and posts, and save a video locally when requested.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security review flags automatic, unpinned package installation as a supply-chain risk that could expose credentials if a release is compromised.

Mitigation: Review the package and install a fixed CLI version with integrity checks before using it with credentials.
