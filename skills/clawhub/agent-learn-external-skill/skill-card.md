## Description:

Guides agents in comparing external skill packages with their own to identify gaps and improvements without installing or copying those packages.

This skill is ready for commercial/non-commercial use.

## Use Case:

Skill authors and developers use this read-only comparison workflow to benchmark external skills against their own and produce a gap list and proposed improvements.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill describes a read-only comparison workflow but requests file-write access.

Mitigation: Review the requested permissions before installation; prefer a version without Write access or one that clearly separates analysis from file modification.
