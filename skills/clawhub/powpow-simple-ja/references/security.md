# セキュリティ設計とプラットフォームAPI

> メンテナンス／トラブルシューティング専用。SKILL.md の実行時にこのファイルを読む必要はありません。

## このスキルが安全に配布できる理由

このスキルには**プラットフォームの機密情報が一切含まれていません**:

| 項目 | 保証 |
|---|---|
| プラットフォームの機密情報 | パッケージ内になし — すべての操作はプラットフォーム自身のHTTP API経由 |
| 身元 | 実際のログインで発行されたJWT。本人としてしか投稿できない |
| ユーザーのパスワード | 保存されない。短命なトークン（約7日）を取得するためにメモリ上で一度使われるのみ |
| レート制限／モデレーション | サーバー側で強制（1ユーザーあたり1時間10投稿、コンテンツモデレーション） |
| Unsplashキー | ユーザーが指定するもの。省略可（画像はオプション） |

このスキルは資格情報ファイルの読み取り・書き込み・提供を一切行いません。書き込む
唯一の状態はユーザー自身のセッショントークンで、ユーザーのステートディレクトリ
（下記参照）に保存され、スキルパッケージ内には入りません。

`config.json` に含まれるのは `{ "platformUrl", "unsplashAccessKey"（省略可）,
"sessionMaxAgeDays", "skillVersion" }` のみです。Supabaseキー、サービスロール、
管理者トークン等をこのスキルに追加しないこと。

### ユーザーのマシンから出してはならないファイル
- `<POWPOW_STATE_DIR>/session.json`（デフォルト `~/.powpow/session.json`）—
  ログインユーザーのJWT（約7日で自動失効）。ユーザーのステートディレクトリに
  書かれ、（読み取り専用の可能性がある）スキルパッケージ内には決して書かれない。

## 使用するプラットフォームAPIエンドポイント

- `POST /api/auth/login` — `{step:1, username, password}` → JWT（Cookie `powpow_token`）
- `GET  /api/digital-humans?scope=all&search=...` — デジタルヒューマンの一覧／検索（ログイン必須）
- `GET  /api/amap/place/text?keywords=...` — 地名検索（ログイン必須。GCJ-02を返すため
  geocode.js がクライアント側でWGS-84へ変換）。このエンドポイントのパスは
  プラットフォーム内部のものであり、ユーザーに対して言及してはならない。
  内部の議論でも中立的に「場所検索サービス」と呼ぶこと（プロバイダー名を
  ユーザーに伝えない）。
- `POST /api/upload/post-image` — ローカル画像のアップロード（multipart `file`。ログイン必須）
- `POST /api/posts` — 投稿の作成（ログイン必須。サーバーがレート制限とモデレーションを強制）
- `GET  /api/posts/{id}` — 投稿の検証
- `DELETE /api/posts/{id}` — 自身の投稿の削除（テスト後片付け）
- `POST /api/digital-humans` — デジタルヒューマンの作成（ログイン必須。バッジ2個を消費、
  30日で失効）
- `POST /api/digital-humans/generate-avatar` — ペルソナからのAIアバター生成
  （ログイン必須。8〜30秒。プラットフォームの設計上、参照画像URLが必要）
- `GET  /api/badges/balance?userId=...` — バッジ残高の事前確認

注: JWTは端末フィンガープリント（User-Agent + Accept-Language）に紐づいています。
APIクライアントはログイン時にこれらのヘッダーを固定し、以降自動的に再利用します。
`DEVICE_MISMATCH` や 401 が出た場合は、再ログインするだけで解決します。
