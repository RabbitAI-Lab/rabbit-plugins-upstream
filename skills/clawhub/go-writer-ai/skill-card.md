## Description:

Guides developers using an unofficial typed Go client to call the Writer API for chat, files, Knowledge Graphs, and other supported operations.

This skill is ready for commercial/non-commercial use.

## Publisher:

[psyb0t](https://clawhub.ai/user/psyb0t)

## Use Case:

Go developers use this skill to install and work with the go-writer-ai client for Writer API requests, including chat, models, file management, and Knowledge Graph queries.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Exposure of the Writer API key in code, logs, or request headers.

Mitigation: Keep WRITER_API_KEY in a protected environment or secret store; do not hardcode, commit, or log it.

Risk: Prompts or uploaded files may contain sensitive information sent to Writer.

Mitigation: Review prompts and files before sending them to the Writer API.

Risk: File uploads or deletion of files and graphs may change remote resources.

Mitigation: Perform these operations only for explicitly requested resources the task is authorized to manage.
