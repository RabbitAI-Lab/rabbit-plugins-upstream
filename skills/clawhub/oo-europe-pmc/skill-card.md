## Description:

Europe PMC helps agents search and retrieve Europe PMC literature, preprints, grants, annotations, citations, references, full-text XML, evaluations, article status, and related data links through the OOMOL oo CLI.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oomol](https://clawhub.ai/user/oomol)

### License/Terms of Use:

MIT-0

## Use Case:

External researchers, developers, and agent users use this skill to query Europe PMC content and retrieve publication metadata, open-access full text, citation networks, grants, annotations, article status, evaluations, and related data links.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The setup instructions include remote installer commands that execute content returned by a remote server with the user's privileges.

Mitigation: Review the installer source first, prefer a pinned and signed or checksum-verified release, and run the remote-to-shell commands only when that execution path is acceptable.
