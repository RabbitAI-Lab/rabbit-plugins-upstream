# 示例：Evidence-driven Action 全链（v3.1.0）

> ⚠️ 演示数据：仅展示方法。真实的"本地商家内容代做"案例见 examples/v3-decision-run.md；
> 本示例聚焦 V3.1 新增的 **Action 如何继承证据**（SOP §19-21、Case F）。

## 1. Evidence Basis（继承字段）

| 字段 | 值 | 来源 |
|---|---|---|
| target_user | 周边 3 公里、1-3 名老师的小型教培工作室主理人 | VALIDATE 核心用户 |
| problem / pain | 想在小红书获客但不会写、代运营太贵 | FIND + P1/P3 证据 |
| distribution_channel | 本地商家微信群 + 小红书本地话题（Evidence：商家群活跃） | D1 渠道可触达证据 |
| payment_signal | 代运营 2000-5000 元/月公开在售（Evidence）；本方案付费未验证 | Payment 覆盖 55（partial） |
| competition_gap | 垂直品类 + 成品交付 + 低价包月 | EVALUATE 差异化切入点 |
| unknowns | A3 质量稳定性、真实可接受月费区间 | 看板 Unknown 项 |
| hard_gates | 全部 PASS，无 ceiling | v3-hard-gates |

## 2. 报告头部（v3.1 四行）

> **🟢 RECOMMENDED 值得继续做**｜机会评分 **78/100**｜Confidence **High**｜Coverage **73%**｜Hard Gates **PASS**｜Opportunity **MS-104**

## 3. 行动步骤（每步继承证据，禁止泛化）

| Step | 目标 | 做什么（证据实例化） | 成功标准 | 失败转向 |
|---|---|---|---|---|
| 1 | 样品交付 | 在本地商家微信群挑 3 家最匹配的工作室，各免费做 1 条垂直品类样品（附前后对比） | 3 家都回复"能用"，其中 ≥1 家问价格 | 若无人回复：换到小红书本地话题私信 5 家 |
| 2 | 付费验证 | 向 3 家报价 199 元/首月（锚定代运营 1/10），先收钱再交付 | ≥3 家中 2 家真实付款 | 若 <1 家付款：改 99 元体验价再试一轮；仍失败 → 回查 M1/M2 证据 |
| 3 | 履约交付 | 交付 8 条成品 + 1 套活动文案（人工+AI，质检后交付） | 客户愿意续费或转介绍 | 交付后吐槽 → 记录不满点，改模板 |
| 4 | 标准化 | 固定品类模板 + 报价单，要转介绍 | 1 家续费 + 1 家转介绍 | 转介绍不产生 → 改渠道（小红书内容沉淀） |

## 4. Today（动词+对象+数量+成功标准）

1. 用关键词"本地 教培 招生"搜索本地商家群与小红书话题，收集 20 个目标工作室线索 → 成功标准：≥5 家可私信联系。
2. 选出最匹配的 3 家（1-3 名老师、近 30 天发过内容但效果差）→ 成功标准：名单确认。
3. 给 3 家各做 1 条免费样品 → 成功标准：当天发出并约 48h 内反馈。

## 5. 为什么这不是模板套用

- "去哪找"来自证据（商家群活跃），不是假设。
- "报多少价"来自代运营价格锚（payment_signal），不是拍脑袋。
- "验证哪个假设"来自 unknowns（月费区间、质量），与 Evidence Coverage 的缺口一一对应。
- 每步都有 If/Then 转向：无人付款 → 改 Offer，而不是"继续努力"。
