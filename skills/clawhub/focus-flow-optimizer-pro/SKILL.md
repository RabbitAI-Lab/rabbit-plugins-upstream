## 多角色场景指南
### 角色一：独立创业者
**典型痛点**：一个人干五个人的活，优先级混乱，长期过载.
**推荐层级组合**：方向层+执行层+焦点层+复盘层
**专属配置**：
```markdown
- 角色：CEO+产品+技术+运营
- 约束：无团队、无外部监督、决策孤岛
- 能量曲线：早晨高（创作）、下午低（行政）
- 风险：长期过载导致倦怠
1. 每周一上午排"本周北极星"（仅1件）
2. 每天三件事，不超过3件
3. 行政任务集中在周五下午（低能量时段）
4. 每月最后一周做"方向校准"（避免陷入执行细节）
```
**典型场景**：
- 用户："我同时在做产品、技术、运营，每天被紧急事项淹没。"
- Agent诊断：过载+优先级模糊
- 干预：
  1. 强制排出本周北极星（仅1件）
  2. 行政任务批量推迟到周五下午
  3. 每天三件事，超出进someday
  4. 启用估算误差统计，校准你的"我能搞定"错觉
### 角色二：远程工作者
**典型痛点**：工作生活边界模糊、孤独感、会议碎片化.
**推荐层级组合**：焦点层+复盘层（强化）
**专属配置**：
```markdown
- 角色：远程工程师/设计师
- 约束：家庭环境、跨时区协作、无办公室边界
- 能量曲线：因人而异，需个性化建模
- 风险：边界弱、过度工作、会议碎片化
1. 设立"虚拟通勤"仪式（开始/结束工作）
2. 上午保护时段（关闭IM通知）
3. 会议集中下午（避免碎片化）
4. 每周一次"深度工作日"（无会议）
```
### 角色三：团队负责人
**典型痛点**：管理任务挤压执行时间、委托质量低、上下文切换频繁.
**推荐层级组合**：执行层（委托）+团队层+焦点层
**专属配置**：
```markdown
- 角色：Tech Lead / 经理
- 约束：1on1、跨部门会议、汇报
- 能量曲线：上午高（深度）、下午中（会议）
- 风险：管理任务挤压技术工作、委托质量低
1. 委托前15分钟需求对齐
2. 设置明确检查点（非每日催促）
3. 委托质量每月统计（准时率/阻塞率）
4. 保留每日2小时"无管理"深度工作时段
```
### 角色四：ADHD人群
**典型痛点**：执行功能障碍、时间盲、过度专注或无法启动.
**推荐层级组合**：执行层+焦点层（高度强化）
**专属配置**：
```markdown
- 任务颗粒度：拆至15-30分钟可完成
- 启动仪式：5分钟"开始就行"规则
- 外部化记忆：所有任务进capture.md，不依赖工作记忆
- 时间盲应对：每25分钟一个检查点（番茄钟变体）
- 过度专注保护：设闹钟防止"忘了吃饭"
- 不要使用"本周计划"这种长周期（容易引发焦虑）
- 不要列超过5项的待办（会瘫痪）
- 不要在低能量时段安排需要启动力的任务
```
### 角色五：育儿期父母
**典型痛点**：时间碎片化、不可预测中断、睡眠不足导致能量低.
**推荐层级组合**：方向层+执行层（轻量化）
**专属配置**：
```markdown
- 任务颗粒度：拆至15分钟可完成（适应碎片时间）
- 时间块：以孩子的作息为锚点，不以工作时段
- 能量曲线：根据睡眠质量动态调整
- 紧急预案：孩子生病/异常时的"最小维持计划"
1. 接受碎片化，不追求长深度工作
2. 每天三件事改为"每天一件事"
3. 周度复盘改为"每月复盘"
4. 允许"维持现状"作为合法目标
```
### 角色六：倦怠恢复期
**典型痛点**：动不起来、对一切失去兴趣、自我否定.
**推荐层级组合**：方向层（极简）+复盘层（强化）
**专属配置**：
```markdown
- 每日任务上限：1件（不超过）
- 任务类型：仅低认知负荷任务
- 复盘重点：记录"今天做对了什么"（不记录未完成）
- 禁止：长期目标规划、新项目启动、深度工作
1. 第1-2周：仅维持基本职责，不规划
2. 第3-4周：每日1件低负荷任务，开始记录能量
3. 第5-8周：每日2件，恢复周度复盘
4. 第9周+：根据能量曲线逐步恢复深度工作
```
### 角色七：学生
**典型痛点**：截止日期集中、长期目标模糊、社交诱惑多.
**推荐层级组合**：方向层+执行层+复盘层
**专属配置**：
```markdown
- 学期北极星：1-2个核心目标（GPA/项目/实习）
- 周度规划：以课程截止日期为锚点
- 能量曲线：根据课表动态建模
- 社交管理：将社交纳入capture.md，不依赖意志力
- 期末周：启用"过载急救"模式
- 寒暑假：切换为"长期项目"模式
```

| ADHD人群 | 执行功能障碍、时间盲 | 执行+焦点（高度强化） | 任务颗粒度、外部化记忆 |
| 育儿期父母 | 时间碎片、不可预测中断 | 方向+执行（轻量化） | 碎片化适应、最小维持 |
| 倦怠恢复期 | 动不起来、自我否定 | 方向（极简）+复盘（强化） | 渐进恢复、不规划 |
| 学生 | 截止集中、长期模糊 | 方向+执行+复盘 | 学期锚点、期末急救 |
## 性能优化策略
### 估算校准优化
1. **缓冲系数自动调整**：根据历史误差率动态调整缓冲系数
2. **任务分类校准**：不同任务类型使用不同缓冲系数（编码1.5x、会议准备2.0x）
3. **个体差异建模**：建立个人估算偏差模型，而非使用通用系数
4. **周期性校准**：每月重新计算缓冲系数，适应能力变化
### 能量曲线优化
1. **动态建模**：能量曲线随睡眠、情绪、季节动态调整
2. **异常检测**：自动识别能量骤降日，提前调整任务安排
3. **匹配度优化**：监控任务-能量匹配度，目标>80%
4. **趋势预测**：基于历史数据预测下周能量曲线
### 专注会话优化
1. **会话时长优化**：根据个人专注极限设置优选会话时长
2. **干扰源治理**：按频次排序干扰源，逐一治理
3. **保护规则**：高价值时段自动启用保护规则（关闭通知）
4. **模式复用**：识别高产会话模式，主动复制
### 团队委托优化
1. **委托质量监控**：准时率/阻塞率/重做率三维评估
2. **需求对齐机制**：委托前15分钟需求对齐，减少50%阻塞
3. **配对委托**：技能不匹配任务采用老带新模式
4. **检查点优化**：根据任务时长设置合理检查点（非每日催促）
### 成本控制
- 性能分析数据保留90天，超期自动归档
- 团队协作数据按项目分区，避免跨项目混淆
- 多平台集成按需启用，非必要不开启
- 每月清理已完成任务，保持执行层精简
