## Description:

Guides QwenPaw skill lifecycle management, including listing, checking, enabling, disabling, removing, and reviewing skill updates and usage.

This skill is ready for commercial/non-commercial use.

## Publisher:

[trend0522](https://clawhub.ai/user/trend0522)

### License/Terms of Use:

MIT-0

## Use Case:

QwenPaw users and administrators use this skill to inventory skills, check for updates, enable or disable skills, remove unused skills, and report actions and recommendations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Skill-management commands can disable or remove skills, including locally customized skills.

Mitigation: Review planned changes and confirm the exact target skill before running enable, disable, or uninstall commands, especially when local customizations exist.
