## Description:

用于依据作者材料、文献或明确授权来源，协作完成中文本科、硕士和课程论文、开题报告及文献综述的提纲、章节起草、改写和审稿；在组织论证、核对证据与引用、处理长稿一致性或降低模板化表达时使用。

This skill is ready for commercial/non-commercial use.

## Use Case:

External academic writers and reviewers use this skill to draft outlines, sections, revisions, literature review material, proposal content, evidence checks, and review feedback for Chinese academic writing tasks based on provided or explicitly authorized materials.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Academic drafts and source materials may contain confidential, private, or third-party content.

Mitigation: Use only materials the user is authorized to process, and avoid providing confidential or third-party material without the right to use it.

Risk: Web-based source verification or supplementation may go beyond the user's intended scope if authorization is unclear.

Mitigation: Run web checks only after explicit user authorization and only within the agreed topic, source, and task scope.

Risk: Local project-state notes may persist sensitive academic context across writing sessions.

Mitigation: Create local project-state files only with explicit permission, and treat those notes as context records rather than evidence for academic claims.
