# 主线归一化别名表

用于 `mainline_review` 的「主线重检」与 `weekly-summary` 的主线稳定性统计：把用户在不同记录里「说法不同、但指向同一件事」的优先事项，归并到一个**稳定主线名**，从而能程序化判断「这条主线连续出现了几次」。

## 设计原则

- **只归并，不新增语义**：只把明确同义的词归到稳定主线名下，不强行给用户的原话贴新标签。
- **归不进就保留原词**：命中不了任何别名的，一律保留用户原话，不做二次猜测。
- **稳定主线名是展示层**：归一化结果只用于统计和对比，不写回用户记录，不改用户原话。
- **别名表是草版，可随时增删**：这里是维护入口，改这里即可，不动脚本。

## 稳定主线名

### 健康（含恢复）
> 「睡眠 / 休息 / 恢复」与「运动 / 饮食 / 身体」归为同一主线，因为本 skill 视「留白与恢复」为合法优先级。

- 睡眠 / 睡觉 / 补觉 / 早睡
- 恢复 / 恢复精力 / 恢复状态 / 好好休息 / 休息 / 喘口气 / 缓一缓
- 运动 / 锻炼 / 健身 / 走路 / 散步 / 跑步
- 吃饭 / 喝水 / 饮食 / 身体 / 健康 / 体检 / 看医生
- 减负 / 放空 / 发呆 / 留白

### 工作
> 主业与工作推进，是「必须交付」的那类事。

- 工作 / 主业 / 上班 / 职场 / 打工
- 交付 / 项目 / 任务 / 绩效 / KPI / OKR
- 职级 / 晋升 / 跳槽 / 面试 / 裁员
- 开会 / 汇报 / 老板 / 同事 / 团队

### 内容（输出）
> 「把东西做出来、发出去」这条线。学习是输入（见下），这里是输出。

- 副业 / 内容副业 / 内容 / 输出 / 创作 / 写作
- 小红书 / 公众号 / 视频号 / 抖音 / 知乎 / 博客
- IP / 个人品牌 / 账号 / 涨粉 / 选题 / 发布 / 更新
- 作品 / 成品 / 案例 / 复盘文章

### 学习（输入）
> 「学进来」这条线，与「内容（输出）」分开。

- 学习 / 学 AI / AI 相关 / AI 尝试 / 课程 / 听课 / 读书
- Vibe Coding / 编程 / 部署 / 微调 / Agent / RAG / 多模态
- 考证 / 证书 / 考试 / 技能 / 成长 / 提升

### 家庭
> 家人、育儿与家务协作。

- 家庭 / 家人 / 父母 / 伴侣 / 另一半
- 育儿 / 孩子 / 带娃 / 陪伴 / 亲子
- 家务 / 做饭 / 打扫 / 家庭秩序

### 其他
> 明确不做归并、保留原词的常见情形（避免过度归并）。

- 情绪 / 心理 / 焦虑 / 内耗：属于「状态」而非「事项」，不归入健康主线，保留原词。
- 财务 / 收入 / 存款 / 房贷：保留原词，不做归并。

## 使用方式

- `record.py weekly-summary` 和 `mainline_review` 模式 B 读取本表做归一化。
- 归一化匹配规则：对用户原话做「包含匹配」（别名出现在原话中即命中），命中多个稳定主线名时取**第一个命中的**（表内顺序即优先级）。
- 命中不了任何别名 → 保留原话，统计时作为独立主线。
