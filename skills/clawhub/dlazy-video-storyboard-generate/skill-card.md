## Description:

Convert a storyboard into a video-generation pipeline that the user can add to the canvas.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use the skill to turn storyboard details, dialogue, and video prompts into a JSON generation pipeline and add it to a canvas.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security review flags authentication setup and a required image-generation workflow beyond the stated storyboard task; external processing and usage charges may be involved.

Mitigation: Before installation, ask the publisher to clarify the CLI's role, how prompts and media are processed, and any charges; review the linked project and authorize use of the required services.
