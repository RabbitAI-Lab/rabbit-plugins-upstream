## Description:

Turns storyboard scenes, dialogue, and video prompts into a canvas-ready video-generation pipeline.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to lay out storyboard scenes as a video-generation pipeline on a canvas, with shared source audio and scene imagery and per-scene cloned audio and video.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The requested CLI, account, network, and file-upload permissions extend beyond the storyboard-focused description.

Mitigation: Review the exact CLI package and version before installation and grant only the access needed for the task.

Risk: Prompts and referenced media may be uploaded to dLazy services, and the API key may be stored locally.

Mitigation: Use the service only when uploading the selected media is acceptable; avoid sensitive media and protect the local API key.
