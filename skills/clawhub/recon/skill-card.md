## Description:

Inspects repository context, proposes task-specific rules, and pauses for confirmation before non-trivial coding work.

This skill is ready for commercial/non-commercial use.

## Publisher:

[aradmanamnaoon](https://clawhub.ai/user/aradmanamnaoon)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to inspect project context, identify unknowns and likely failure modes, and agree on task-specific rules before undertaking larger or riskier coding tasks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation can delay routine coding work.

Mitigation: Keep inspection focused on relevant files and use the confirmation checkpoint before continuing.
