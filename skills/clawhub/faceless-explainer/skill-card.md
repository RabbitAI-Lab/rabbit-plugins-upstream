## Description:

Turns articles, notes, topics, and briefs into faceless explainer videos with original scene-by-scene visuals.

This skill is ready for commercial/non-commercial use.

## Publisher:

### License/Terms of Use:

MIT-0

## Use Case:

Creators and teams use this skill to turn source text into illustrated topic explainers, concept breakdowns, how-tos, and listicles without filming footage or capturing a website.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Unpinned HyperFrames commands may run changing code and update globally installed skills.

Mitigation: Review commands before execution and prefer a pinned or trusted local HyperFrames CLI.

Risk: Project files retain pasted source text and preferences, which may contain sensitive material.

Mitigation: Avoid confidential briefs unless project storage and access controls are appropriate.

Risk: Audio creation may use local HeyGen or media credentials.

Mitigation: Review credential access and available offline options before using production accounts.
