## Description:

Turns text into a faceless explainer video using scene-specific typography, graphics, diagrams, and data visualizations.

This skill is ready for commercial/non-commercial use.

## Publisher:

[heygen-com](https://clawhub.ai/user/heygen-com)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and developers use this skill to turn articles, notes, and topic briefs into narrated, faceless explainer videos without filming a website or live footage.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: HyperFrames commands may update globally installed skills or execute changing CLI code.

Mitigation: Confirm global updates before running them and pin or pre-vet the HyperFrames CLI where possible.

Risk: Video production can use local media credentials and write project files through frame workers.

Mitigation: Run in a constrained workspace and grant only the media credentials needed for the project.
