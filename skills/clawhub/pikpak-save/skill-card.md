## Description:

Helps an agent save magnet, HTTP, and shared links to PikPak cloud storage, track transfers, and optionally play or download saved files.

This skill is ready for commercial/non-commercial use.

## Publisher:

[pipiguai87-alt](https://clawhub.ai/user/pipiguai87-alt)

### License/Terms of Use:

MIT-0

## Use Case:

PikPak users can ask an agent to save permitted links or shares to their cloud account, monitor transfer progress, and play or download completed files.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The agent can act on links and shares using the user's PikPak account.

Mitigation: Use it only for content the user is allowed to access, and confirm intended cloud saves or share restores.

Risk: Local downloads of large or unfamiliar files may be unwanted.

Mitigation: Confirm before downloading locally; prefer cloud storage or playback when a local copy is unnecessary.
