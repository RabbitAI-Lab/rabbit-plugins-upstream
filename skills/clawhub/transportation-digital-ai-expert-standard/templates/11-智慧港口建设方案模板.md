### 2.3 核心痛点总结

1. **TOS老旧：** 核心码头操作系统功能落后，无法支持自动化设备和智能调度
2. **自动化率低：** 岸桥/场桥以人工操作为主，自动化堆场占比<XX%
3. **数据孤岛：** TOS、计费、闸口、安防各系统独立，数据不互通
4. **集疏运效率低：** 外集卡信息不透明、等待时间长、空驶率高
5. **能源管理粗放：** 缺乏能效监测和碳排放管理，绿色港口建设不足
6. **安全管控薄弱：** 人机混行区域缺乏智能安全管理手段

## 5. 子系统一：智慧TOS（码头操作系统）

### 5.1 功能概述

TOS是码头的"操作系统"，新一代TOS需要实现全自动化码头的智能调度。

### 5.2 核心功能模块

| 模块 | 功能 | 智能化升级 |
|------|------|-----------|
| **船舶计划** | 泊位计划、岸桥分配、靠离泊管理 | AI优化泊位分配和岸桥资源 |
| **堆场计划** | 堆场空间管理、箱区计划、堆存策略 | AI优化堆存位置，减少翻箱 |
| **作业指令** | 岸桥/场桥/拖车/AGV作业指令的生成与分发 | 指令自动生成、实时优化调整 |
| **设备调度** | 岸桥/场桥/AGV/人工拖车的协同调度 | 基于运筹优化的全局调度 |
| **EDI/数据交换** | 船公司/货代/海关/铁路 数据交换 | 支持实时API替代传统EDI报文 |
| **计费结算** | 费收计算、账单生成、线上支付 | 自动化计费+区块链对账 |
| **商务管理** | 合同管理、客户管理、信用管理 | 客户360画像 |
| **智能配载** | 船舶配载计划自动生成 | AI优化稳性与效率平衡 |

## 7. 子系统三：智慧闸口

### 7.1 功能概述

建设"无感通行"的智能闸口，实现外集卡的快速进出和信息全透明。

### 7.2 建设内容

| 模块 | 内容 |
|------|------|
| **智能OCR** | 高清相机+AI识别：箱号、车牌、ISO代码、箱门方向。识别率≥[99%] |
| **预约系统** | 司机/车队App预约→凭预约码/车牌抬杆→指定堆场位置，削峰填谷 |
| **箱体验残** | AI视觉自动检测集装箱残损（破损/变形/污染），拍照存档 |
| **自动抬杆** | OCR识别+预约校验→自动抬杆，通行时间≤[15]秒/车 |
| **信息引导** | 闸口大屏+司机App引导至指定箱区/泊位 |
| **称重集成** | 集成地磅，自动读取毛重/皮重，计算净重 |

## 10. 子系统六：冷链监控

### 10.1 功能概述

对冷藏集装箱（Reefer）和冷库进行全链条温湿度监控与预警。

### 10.2 监控内容

| 监控项 | 方式 | 报警 |
|------|------|------|
| 冷藏箱温度 | 对接PLC/电力载波读取设定温度与实际温度 | 温度超范围自动报警 |
| 冷藏箱状态 | 监测制冷机组运行/停机/故障 | 停机/故障报警 |
| 冷库温湿度 | 无线传感器多点布设 | 超阈值报警 |
| 插拔电监控 | 堆场冷藏箱插拔电事件记录 | 异常掉电报警 |
| 碳足迹追踪 | 记录冷链全程碳排放 | 碳报告生成 |

## 11. 子系统七：港口物流平台

### 11.1 功能概述

构建港口物流生态平台，连接船公司、货代、车队、铁路、海关等各方，打造一站式港口物流服务。

### 11.2 平台功能

| 模块 | 功能 | 服务对象 |
|------|------|----------|
| **船舶服务** | 船期查询、泊位申请、引航/拖轮预约 | 船公司/代理 |
| **提还箱服务** | 在线预约提还箱、电子提货单（e-DO） | 货主/货代/车队 |
| **集疏运调度** | 外集卡进场预约、排队叫号、动态引导 | 车队/司机 |
| **全程跟踪** | 船舶-码头-堆场-运输全程可视化跟踪 | 货主 |
| **在线支付** | 港口费用在线查询与支付 | 货主/货代 |

## 14. 子系统十：港口安全

### 14.2 建设内容

| **安全态势** | 安全指数一屏总览：隐患数量/整改率/人员违章/设备异常 |
| **安全巡检** | 移动端安全巡检，隐患拍照→派单→整改→闭环 |
