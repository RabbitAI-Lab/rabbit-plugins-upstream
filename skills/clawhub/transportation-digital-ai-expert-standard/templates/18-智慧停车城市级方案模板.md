## 三、子系统详设

### 3.1 路内停车（Roadside Parking）

#### 3.1.1 检测方案对比
| 方案 | 高位视频 | 视频桩 | 地磁+巡检车 | 地磁+手持PDA |
|------|:---:|:---:|:---:|:---:|
| 覆盖泊位/设备 | 8-12个/杆 | 1-2个/桩 | 1个/传感器 | 1个/传感器 |
| 检测准确率 | >98% | >99% | >97% | >95% |
| 车牌识别 | 支持 | 支持 | 不支持 | 不支持 |
| 证据链 | 完整(照片/视频) | 完整 | 需巡检车拍照 | 需人工拍照 |
| 施工难度 | 中(需立杆取电) | 低 | 低(地面安装) | 低 |
| 单泊位成本(建设) | ¥[2000-5000] | ¥[3000-6000] | ¥[800-1500] | ¥[500-1000] |
| 运维成本 | 低 | 中 | 高(巡检车) | 高(人工) |
| 适用场景 | 城市主干道/商业区 | 非主干道 | 非主干道/背街小巷 | 偏远/低密度 |

> **推荐方案**: 核心商业区/主干道采用高位视频，非主干道采用地磁+巡检车组合，实现覆盖与成本的平衡。

#### 3.1.2 路内停车业务流程
```
车辆驶入 → 高位视频/地磁自动检测 → 车牌识别+计时开始
    → APP/短信推送停车信息
    → 车辆驶离 → 自动结束计时 → 生成账单
    → APP/小程序/公众号推送支付通告
    → 用户在线支付(微信/支付宝/银联/ETC) 或 无感支付自动扣费
    → 支付完成/超时未付生成欠费记录 → 欠费追缴
```

#### 3.1.3 欠费追缴体系
| 方式 | 说明 |
|------|------|
| 短信/APP推送 | 自动推送欠费提醒+缴费链接 |
| 路侧巡检提醒 | 巡检员对欠费车辆张贴提示单 |
| 年检/过户关联 | 与车管所系统对接，年检/过户前清欠（需法规支撑） |
| 信用积分 | 与城市信用体系对接（部分地区） |
| 法律诉讼 | 对恶意欠费大额用户提起诉讼 |

### 3.2 路外停车（Off-street Parking）

#### 3.2.1 标准停车管理系统
| 硬件 | 功能 | 推荐配置 |
|------|------|----------|
| 入口道闸+车牌识别 | 入场自动识别车牌/车型+抬杆 | 300万像素+补光灯+雷达防砸 |
| 出口道闸+车牌识别+ETC | 出场识别+ETC收费+聚合支付 | 同上+ETC天线 |
| 车位引导摄像机 | 检测车位占用状态 | 2-6车位/摄像头 |
| 车位引导屏 | 显示各层/各区空余车位数 | 每层入口/主要通道 |
| 反向寻车终端 | 输入车牌查询车辆位置 | 电梯厅/主要通道 |
| 室内导航 | APP蓝牙/WiFi/UWB室内导航 | 按面积配置信标 |
| 收费管理终端 | 人工收费/异常处理/无牌车处理 | 出口岗亭 |
| 云坐席 | 远程对讲/抬杆/异常处理 | 中心部署 |
| 充电桩 | 慢充/快充/超充 | 按比例配置 |

#### 3.2.2 停车场接入方式
| 接入方式 | 说明 | 适用对象 | 成本 |
|----------|------|----------|:----:|
| 直连模式 | 停车系统直接接入城市平台（统一标准） | 公共投资新建停车场 | 低 |
| 网关模式 | 通过对接网关转换协议后接入 | 已建停车场/标准不统一 | 中 |
| 数据上报模式 | 停车场运营系统定时/实时上报车位数据 | 商业停车场/不愿改造 | 低(仅数据) |
| 全托管模式 | 停车场完全交由平台方运营管理 | 产权方无运营能力 | 高(全面) |

## 五、运营方案

### 5.1 运营模式
| 模式 | 说明 | 优缺点 | 适用 |
|------|------|--------|:---:|
| 公共部门自建自营 | 公共投资建设+城管/交投运营 | 收益归公/但专业度不够 | 小型城市 |
| PPP模式 | 社会资本建设运营/行业监管 | 专业运营/但分账复杂 | 中型城市 |
| BOT/特许经营 | 授予10-30年特许经营权 | 快速启动/需监管定价 | 大中城市 |
