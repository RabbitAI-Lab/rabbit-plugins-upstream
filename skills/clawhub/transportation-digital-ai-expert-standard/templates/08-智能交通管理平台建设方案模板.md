### 3.2 建设原则

| 原则 | 说明 |
|------|------|
| **统筹规划、急用先行** | 整体规划顶层规划，优先解决最痛的业务问题 |
| **数据驱动、业务闭环** | 以数据为核心资产，实现数据→洞察→决策→行动→反馈闭环 |
| **平台化、服务化** | 建设中台能力，赋能上层应用，避免烟囱式建设 |
| **标准化、开放化** | 统一数据标准、接口标准，架构开放，支持生态扩展 |
| **安全保障、自主可信** | 落实MLPS，推进国产化适配，保障数据安全 |
| **迭代演化、持续演进** | 采用敏捷开发模式，MVP快速验证，持续迭代优化 |
| **集约建设、绿色节能** | 充分利旧现有资源，绿色数据中心理念，避免重复投资 |
