# AI场景优先级评分卡（RICE++）
## AI Scenario Priority Scorecard for Transportation

---

## 一、工具概述

本工具采用RICE++六维评分模型（Reach+Impact+Confidence+Effort+Strategy+Data），对交通领域AI应用场景进行系统化优先级排序。内含25个预评分交通AI场景，可直接使用或根据实际情况调整。

### 适用场景
- AI战略规划与投资决策
- 年度AI项目启动评审
- 交通数字化项目的AI优先级排序
- AI实施路径规划（Phase 1/2/3）
- AI项目投资组合管理

## 二、RICE++ 六维评分模型

### 2.1 维度定义与评分标准

| 维度 | 英文 | 权重 | 说明 | 评分范围 |
|------|------|------|------|----------|
| R | Reach | 20% | 用户/业务覆盖面 | 1-5 |
| I | Impact | 25% | 对核心业务的提升效果 | 1-5 |
| C | Confidence | 15% | 技术可行性和数据就绪度 | 1-5 |
| E | Effort | 15% | 投入成本(人/财/时间)，越低分越高 | 1-5 (5=极低投入) |
| S | Strategy | 15% | 战略对齐度 | 1-5 |
| D | Data | 10% | 数据就绪度和可获得性 | 1-5 |

### 2.2 各维度详细评分标准

#### R - Reach（覆盖面）
| 评分 | 标准 | 示例 |
|------|------|------|
| 1分 | 单部门/单场景使用 | 内部测试环境的模型验证 |
| 2分 | 2-3部门或业务线使用 | 单一路段/试点验证区域的AI应用 |
| 3分 | 全市/全集团多部门使用 | 全城交通信号优化 |
| 4分 | 全行业/跨城市使用 | 省级交通AI平台 |
| 5分 | 公众用户+全行业+可对外输出 | 面向亿级用户的MaaS AI推荐 |

#### I - Impact（业务影响）
| 评分 | 标准 | 示例 |
|------|------|------|
| 1分 | 边际改善（<5%效率提升） | 报表自动化 |
| 2分 | 中等改善（5%-15%效率提升） | 视频事件检测辅助 |
| 3分 | 显著改善（15%-30%效率提升） | 信号配时AI优化 |
| 4分 | 变革性改善（30%-50%效率提升） | 自动驾驶协同调度 |
| 5分 | 颠覆性改变（>50%效率提升或新商业模式） | 无人化运营 |

#### C - Confidence（技术确信度）
| 评分 | 标准 | 示例 |
|------|------|------|
| 1分 | 纯探索性，技术路线未经验证 | 交通大模型从零训练 |
| 2分 | 实验室验证，无生产环境案例 | 新算法理论验证 |
| 3分 | 行业有成功案例，但自身需较高适配 | CV场景（需本地标注数据） |
| 4分 | 成熟技术，自身有类似经验 | 车牌识别、视频结构化 |
| 5分 | 开箱即用，大规模已验证 | 云服务API调用 |

#### E - Effort（投入成本）
| 评分 | 标准 | 示例（参考投入） |
|------|------|------|
| 5分（极低） | 月级别，<50万，<3人，使用现成API | 调用OCR API |
| 4分（低） | 季度级别，50-200万，3-5人 | 基于预训练模型微调 |
| 3分（中） | 半年级别，200-500万，5-10人 | 定制化CV模型开发+部署 |
| 2分（高） | 年级别，500-2000万,10-30人 | 全链路AI平台搭建 |
| 1分（极高） | 2年+，>2000万，30+人团队 | 大模型从头训练 |

#### S - Strategy（战略对齐度）
| 评分 | 标准 |
|------|------|
| 1分 | 与战略方向无直接关联 |
| 2分 | 间接支持某一战略目标 |
| 3分 | 直接支持某一战略目标 |
| 4分 | 支持多个战略目标，属于战略优先级 |
| 5分 | 本身就是战略核心项目，决策者层高度关注 |

#### D - Data（数据就绪度）
| 评分 | 标准 |
|------|------|
| 1分 | 数据不存在，需要从头采集/标注 |
| 2分 | 数据存在但格式混乱/质量差，需要大量清洗 |
| 3分 | 数据存在且有一定标准，需要轻度处理 |
| 4分 | 数据标准化存储，可直接用于训练 |
| 5分 | 高质量标注数据丰富，持续积累中 |

### 3.2 各场景详细说明

---

**场景1：交通视频事件自动检测**
- 描述：利用CV技术对交通监控视频进行实时分析，自动检测交通事故、拥堵、逆行、行人闯入等异常事件
- 关键能力：视频结构化、目标检测、多目标跟踪、事件分类
- 技术需求：GPU服务器、视频接入网关、CV算法框架
- 数据需求：标注交通视频10000+小时（不同天气/光照/场景）
- 行业成熟度：★★★★☆（成熟）
- 典型投入：300-800万（含GPU硬件）
- 实施周期：6-12个月
- ROI预估：减少80%人工巡检、事件发现时间缩短60%

**场景2：AI信号配时优化**
- 描述：基于深度强化学习进行城市路口信号配时动态优化，实现干线/区域协调控制
- 关键能力：强化学习、交通流建模、多智能体协调
- 技术需求：GPU/边缘计算节点、信号机通信接口
- 数据需求：路口流量数据（半年+）、信号配时方案、旅行时间数据
- 行业成熟度：★★★★☆（部分城市已验证）
- 典型投入：500-1500万（50个路口以上）
- 实施周期：12-18个月
- ROI预估：路口通行效率提升15-25%、平均停车次数减少20%

**场景3：智能客服/FAQ问答**
- 描述：基于大模型/知识图谱的交通服务智能问答，覆盖行业规范咨询、业务办理、投诉处理
- 关键能力：NLU、知识库、多轮对话、情感识别
- 技术需求：大模型API/私有化部署、知识库平台
- 数据需求：历史客服对话10万+条、行业法规文档
- 行业成熟度：★★★★★（非常成熟）
- 典型投入：100-300万
- 实施周期：3-6个月
- ROI预估：客服人力减少60%、7x24服务覆盖

**场景4：车牌/车型识别**
- 描述：交通场景下的高精度车牌识别、车型分类、车辆特征提取
- 关键能力：OCR、目标检测、细粒度分类
- 技术需求：GPU/边缘计算盒
- 数据需求：多省份车牌样本、多角度车辆图片
- 行业成熟度：★★★★★（非常成熟，准确率>99%）
- 典型投入：50-200万（软件层面）
- 实施周期：1-3个月
- ROI预估：替代人工录入，效率提升90%+

**场景5：交通流量预测**
- 描述：基于历史数据+实时数据，利用深度学习预测未来15分钟-24小时交通流量
- 关键能力：时序预测、时空图神经网络、多源数据融合

## 五、优先级自动计算公式

### 5.1 加权得分计算

```
场景得分 = R×Wr + I×Wi + C×Wc + E×We + S×Ws + D×Wd
```

其中 Wr+Wi+Wc+We+Ws+Wd = 1.0

### 5.2 优先级分类

| 得分区间 | 优先级 | 实施策略 |
|----------|--------|----------|
| ≥ 3.5 | P0 - 立刻执行 | 立即启动，6个月内上线MVP |
| 3.0 - 3.5 | P1 - 近期执行 | 6-12个月内启动 |
| 2.5 - 3.0 | P2 - 规划储备 | 12-18个月内论证和准备 |
| < 2.5 | P3 - 长期跟踪 | 持续关注，条件成熟再评估 |

### 5.3 Quick-Win 识别算法

```
Quick-Win = (Confidence ≥ 4) AND (Effort ≥ 4) AND (Impact ≥ 3)
即：技术成熟 + 投入成本低 + 业务影响达标注

当前预评分中的Quick-Win场景：
  1. 车牌/车型识别（C=5, E=5, I=3）✓
  2. 智能客服/FAQ问答（C=5, E=5, I=2）- 待确认I
  3. 交通视频事件检测（C=4, E=4, I=3）✓
  4. 停车需求预测（C=4, E=4, I=3）✓
```

## 十二、使用说明

1. **场景筛选**：从25个预评分场景中选择与自身相关的场景（可增加自定义场景）
2. **权重校准**：组织5-7人团队进行权重校准工作坊（参见第四节）
3. **独立打分**：每人独立对每个场景的6个维度评分（1-5分）
4. **汇总计算**：使用加权公式计算各场景综合得分
5. **优先级排序**：按得分从高到低排序，分为P0/P1/P2/P3
6. **识别Quick-Win**：筛选出高确信度+低投入+高影响的快速见效场景
7. **分阶段规划**：结合依赖关系图制定Phase 1/2/3实施计划
8. **投入估算**：使用第六节估算各阶段投资需求
9. **定期复评**：建议每6个月重评，根据技术演进和业务需求调整
