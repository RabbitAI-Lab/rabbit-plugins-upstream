# 交通数据质量评估工具
## Transportation Data Quality Assessment Toolkit

---

## 一、工具概述

本工具提供交通数据质量的系统性评估框架，覆盖6大质量维度、详细评分标准、问题分类与修复指南。适用于交通数据中台、大数据平台、综合交通运行协调中心、AI训练数据等场景的数据质量治理。

### 6大评估维度

| 维度 | 英文 | 定义 | 权重(默认) |
|------|------|------|-----------|
| DQ1 | Completeness（完整性） | 数据是否有缺失/空值，采集覆盖是否全面 | 20% |
| DQ2 | Accuracy（准确性） | 数据是否真实反映实际情况 | 25% |
| DQ3 | Timeliness（时效性） | 数据从产生到可用的延迟是否可接受 | 20% |
| DQ4 | Consistency（一致性） | 不同系统/来源的同类数据是否一致 | 15% |
| DQ5 | Uniqueness（唯一性） | 数据是否有重复记录 | 10% |
| DQ6 | Traceability（可追溯性） | 数据来源、处理过程是否可追溯 | 10% |

---

## 二、详细评分标准（每维度1-5分）

### DQ1：完整性

| 评分 | 标准 |
|------|------|
| 1分 | 关键字段缺失率>20%，核心采集点大量缺失 |
| 2分 | 关键字段缺失率10-20%，部分采集点未覆盖 |
| 3分 | 关键字段缺失率2-10%，主要采集点覆盖 |
| 4分 | 关键字段缺失率<2%，采集点基本全覆盖 |
| 5分 | 关键字段缺失率<0.5%，全要素采集覆盖，有缺失补偿运行框架 |

**交通数据完整性检查项：**

| 数据类别 | 检查字段 | 完整性最低标准 |
|----------|----------|---------------|
| 交通流量 | 时间、路口ID、车道、流量、占有率、速度 | ≥95%（分钟级） |
| 车辆GPS | 车牌/ID、时间、经度、纬度、速度、方向 | ≥98% |
| 公交IC卡 | 卡号、线路、上车时间、下车时间（如有） | ≥90% |
| 视频监控 | 设备ID、时间、视频流URL、设备状态 | ≥99% |
| 信号配时 | 路口ID、相位、周期、绿信比、方案时间 | ≥99% |
| 交通事故 | 时间、地点、类型、伤亡、责任认定 | ≥95% |
| 停车数据 | 停车场ID、时间、进场/离场、车牌 | ≥90% |
| 碳排放 | 时间、区域、排放源、排放量 | ≥85% |

### DQ2：准确性

| 评分 | 标准 |
|------|------|
| 1分 | 主要数据存在大量明显错误（偏差>30%），无校验运行框架 |
| 2分 | 部分数据存在错误（偏差15-30%），基础校验 |
| 3分 | 数据基本准确（偏差5-15%），有校验规则但不够完善 |
| 4分 | 数据准确度高（偏差1-5%），完善的校验和纠错运行框架 |
| 5分 | 数据精度极高（偏差<1%），多源交叉验证+AI自动纠错 |

**交通数据准确度参考标准：**

| 数据类别 | 基准准确度 | 说明 |
|----------|----------|------|
| 车辆检测器流量 | ≥95% | 雷达/线圈检测，需定期标定 |
| 车牌识别 | ≥98%（日间）≥95%（夜间） | 受天气/光照影响 |
| GPS定位 | 民用5-10m，差分<1m | 城市峡谷效应 |
| 手机信令 | ≥85%（位置），≥90%（OD） | 基站切换漂移 |
| 公交IC卡 | ≥98% | 刷卡准确，下车推断有误差 |
| 视频事件检测 | 检出率≥95%，误报率<5% | AI模型精度 |
| 气象数据 | ≥95% | 场站级气象站 |
| 碳排放测算 | ≥80%（估计值） | 本质是模型估算 |

### DQ3：时效性

| 评分 | 标准 |
|------|------|
| 1分 | 数据延迟>1小时，无法满足业务需求 |
| 2分 | 数据延迟15-60分钟，大部分业务可接受但效率受影响 |
| 3分 | 数据延迟5-15分钟，主要业务可正常运作 |
| 4分 | 数据延迟1-5分钟（近实时），核心业务体验良好 |
| 5分 | 数据延迟<1秒（实时），全链路端到端延迟可控 |

**交通数据时效性要求参考：**

| 应用场景 | 时效性要求 | 数据源 |
|----------|-----------|--------|
| V2X安全预警 | <100ms | RSU/OBU |
| 实时信号控制 | <1秒 | 路口检测器 |
| 动态诱导 | 1-5分钟 | 浮动车/检测器 |
| 交通态势监测 | 1-5分钟 | 多源融合 |
| 公交到站预测 | <30秒（更新） | GPS/IC卡 |
| 出行路径规划 | <5分钟 | 路况服务 |
| 交通统计分析 | 日/周/月 | 离线汇总 |
| 碳排放报告 | 月/季度 | 月度汇总 |

### DQ4：一致性

| 评分 | 标准 |
|------|------|
| 1分 | 不同系统同类数据差异>30%，无一致性校验 |
| 2分 | 差异15-30%，偶有校验 |
| 3分 | 差异5-15%，有规则校验但不全面 |
| 4分 | 差异1-5%，系统化的一致性校验 |
| 5分 | 差异<1%，一致性实时监控+自动修复 |

**交通数据一致性常见问题：**

| 场景 | 典型不一致 | 根因 |
|------|-----------|------|
| 不同检测器同路口流量 | 差异>10% | 检测器类型/安装位置不同 |
| 车牌识别与收费系统 | 车牌不一致 | OCR错误/套牌 |
| GPS轨迹与路网匹配 | 车辆偏离道路 | GPS漂移/路网不准确 |
| IC卡与人工统计客流 | 差异>15% | 下车推断算法差异 |
| 事故数据与保险理赔 | 事故严重度不一致 | 统计口径不同 |
| 不同地图路网 | 道路属性不一致 | 更新频率/来源不同 |

### DQ5：唯一性

| 评分 | 标准 |
|------|------|
| 1分 | 重复率>10%，无去重运行框架 |
| 2分 | 重复率5-10%，手动去重 |
| 3分 | 重复率1-5%，基本的去重规则 |
| 4分 | 重复率<1%，自动化去重 |
| 5分 | 重复率<0.1%，实时去重+幂等设计 |

### DQ6：可追溯性

| 评分 | 标准 |
|------|------|
| 1分 | 无任何数据来源记录 |
| 2分 | 有数据来源描述但无结构化记录 |
| 3分 | 关键数据的来源和处理过程有结构化记录 |
| 4分 | 全链路数据血缘跟踪（采集→处理→应用）|
| 5分 | 完整数据血缘+变更历史+版本管理+评估审查日志 |

## 三、评估方法

### 3.1 抽样与检测方法

| 数据类型 | 抽样策略 | 检测方法 | 最小样本量 |
|----------|----------|----------|-----------|
| 交通流量 | 随机2周数据（含工作日和节假日） | 统计校验+可视化 | 10万+条 |
| 车辆GPS | 随机100辆车x7天 | 轨迹分析+异常检测 | 100万+条 |
| 公交IC卡 | 随机1个月 | 统计分析+OD校验 | 50万+条 |
| 视频/图像 | 随机1000+张 | 人工标注校验 | 1000+张 |
| 事故记录 | 全量3个月 | 逻辑校验+人工复核 | 全部 |
| 停车数据 | 随机10个停车场x1周 | 进出场时间校验 | 1万+条 |

### 3.2 评分计算公式

```
维度得分 = (该维度各指标评分之和 / 指标数量)
数据质量总分 = DQ1×20% + DQ2×25% + DQ3×20% + DQ4×15% + DQ5×10% + DQ6×10%

等级判定：
  4.5-5.0 : A级 - 卓越，可直接用于AI训练和关键决策
  3.5-4.4 : B级 - 良好，可用于大部分分析和应用
  2.5-3.4 : C级 - 合格，基础应用可用，高级应用需治理
  1.5-2.4 : D级 - 较差，需重点治理后再使用
  <1.5   : E级 - 极差，建议重建数据体系
```

## 四、数据质量问题分类与修复指南

### 4.1 问题分类体系

| 问题类别 | 编号 | 典型问题 | 严重度 | 修复难度 | 修复方法 |
|----------|------|----------|--------|----------|----------|
| 缺失值 | M01 | 采集设备故障导致数据缺失 | 高 | 中 | 设备修复+数据补采/插值 |
| 缺失值 | M02 | 新系统未采集历史数据 | 中 | 高 | 回溯估算+标注数据起始日期 |
| 缺失值 | M03 | 字段可选导致大量为空 | 低 | 低 | 必填约束+默认值 |
| 异常值 | A01 | 传感器漂移/故障导致离谱值 | 高 | 中 | 异常检测+设备标定 |
| 异常值 | A02 | 传输错误(乱码/截断) | 高 | 低 | 校验+重新采集 |
| 异常值 | A03 | 单位/坐标系统不统一 | 高 | 中 | 格式标准化 |
| 重复值 | D01 | 多系统重复采集同一事件 | 中 | 中 | 去重+主数据管理 |
| 重复值 | D02 | 重传/补传导致数据重复 | 中 | 低 | 去重+幂等设计 |
| 及时性 | T01 | 网络延迟/带宽不足 | 高 | 高 | 网络优化+边缘预处理 |
| 及时性 | T02 | 批处理间隔过长 | 中 | 低 | 调整ETL频率 |
| 一致性 | C01 | 不同系统口径/颗粒度不一致 | 中 | 高 | 统一标准+数据映射 |
| 一致性 | C02 | 异构数据库时间/编码不一致 | 中 | 中 | 统一编码+时区规范 |
| 可追溯性 | R01 | 数据来源不明/中间处理黑箱 | 低 | 中 | 建立血缘+处理日志 |

### 4.2 修复优先级矩阵

```
                    影响大
                      ↑
         立即修复      │      重点修复
      (Critical Bug)  │   (Major Issue)
                      │
    ┌─────────────────┼─────────────────┐
    │                 │                 │
    │  设备故障导致    │  多系统数据口径  │
    │  大面积数据缺失  │  严重不一致     │
    │                 │                 │
    ├─────────────────┼─────────────────┤
    │                 │                 │
    │  少量历史数据    │  老旧设备精度   │
    │  可追溯性欠佳    │  逐步偏低       │
    │                 │                 │
    └─────────────────┴─────────────────┘
         暂缓修复      │      计划修复
      (Minor Issue)   │   (Planned)
                      │
                      低 ←──── 频率/范围 ────→ 高
```

## 八、交通数据质量关键基准

### 8.1 分领域数据质量基准

| 数据领域 | 行业平均 | 领先水平 | 卓越水平 | 快速评估check |
|----------|---------|---------|---------|--------------|
| 城市交通流量数据 | C级(2.8) | B级(3.8) | A级(4.5+) | 检测器在线率 |
| 高速公路收费数据 | B级(3.5) | A级(4.2) | A级(4.8) | 收费准确率 |
| 公交运营数据 | C级(2.8) | B级(3.8) | A级(4.5) | GPS覆盖率 |
