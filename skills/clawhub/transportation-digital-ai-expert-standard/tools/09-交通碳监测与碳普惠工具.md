## 一、工具概述

本工具为交通领域碳排放监测、核算、碳普惠和碳交易提供全链路操作方法。覆盖公路、城市交通、轨道交通、水运、航空五大交通模式的碳核算公式和中国特化排放因子，并包含MRV工作流、碳普惠运行框架设计、碳交易就绪度评估等实用工具。

## 二、交通碳排放计算公式（按模式）

### 2.1 通用计算公式

```
E = Σ(E_i) = Σ(AD_i × EF_i)

其中：
  E = 总排放量（吨CO2）
  E_i = 第i种能源/交通活动的排放量
  AD_i = 活动数据（Activity Data）
  EF_i = 排放因子（Emission Factor）
```

### 2.2 公路交通排放

#### 方法一：基于燃料消耗（自上而下）

```
E_公路 = Σ(Fuel_j × EF_j)

其中：
  Fuel_j = 第j类燃料消耗量（吨），如汽油、柴油、天然气等
  EF_j = 第j类燃料的CO2排放因子（吨CO2/吨燃料）
```

#### 方法二：基于行驶里程（自下而上）

```
E_公路 = Σ(VehType_k × VKT_k × FE_k × EF_fuel)

其中：
  VehType_k = 第k类车辆保有量（辆）
  VKT_k = 第k类车辆年均行驶里程（公里/年）
  FE_k = 第k类车辆平均油耗（升/公里 或 kWh/公里）
  EF_fuel = 燃料排放因子
```

### 2.3 城市交通排放（分模式）

```
E_城市 = E_公交 + E_出租车/网约车 + E_私家车 + E_地铁 + E_货运 + E_其他

E_公交 = Σ(运营里程 × 百公里能耗 × EF) 或
        Σ(客运量 × 人均出行距离 × 人均排放因子)

E_私家车 = 保有量 × 年均行驶里程 × 百公里油耗 × 汽油EF
```

### 2.4 轨道交通排放

```
E_地铁 = 年电力消耗（kWh）× 所在电网电力排放因子（吨CO2/kWh）

注意：电力排放因子随电网清洁化动态变化
```

### 2.5 航空排放

```
E_航空 = 起降循环(LTO)排放 + 巡航排放

LTO排放 = N_起降 × 单次LTO排放因子（按机型）
巡航排放 = 航段距离 × 巡航排放因子（按机型）
```

### 2.6 水运排放

```
E_水运 = Σ(货运周转量 × 单位周转量排放因子) 或
        Σ(船舶燃料消耗 × 燃料EF)
```

## 六、MaaS碳积分计算方法论

### 6.1 计算方法

```
个人出行碳减排量 = 基准线排放 - 实际绿色出行排放

基准线排放 = 出行距离 × 基准线排放因子
  （基准线通常取：同城市私家车平均排放水平）

实际排放 = 出行距离 × 所选出行方式排放因子

出行距离识别方法：
  - GPS轨迹法（精度高，需用户授权）
  - 刷卡/扫码站点法（适用于公交/地铁）
  - 手动填报法（精度低，适用于补充）
```

### 6.2 MaaS碳积分计算速查表

| 绿色出行方式 | 单位减排量(kgCO2/次) | 积分 | 每日上限 | 计算依据 |
|-------------|---------------------|------|----------|----------|
| 步行(≥500m) | 0.15-0.25 | 15-25 | 100 | 替代1km私家车出行 |
| 骑行(≥500m) | 0.12-0.20 | 12-20 | 100 | 替代1km私家车出行 |
| 公交 | 0.10-0.18/km | 10-18/km | 150 | 同距离公交vs私家车 |
| 地铁 | 0.12-0.20/km | 12-20/km | 200 | 同距离地铁vs私家车 |
| P+R(换乘) | 0.20-0.40/次 | 20-40/次 | 120 | 减少进城私家车里程 |
| 电动汽车(非绿色电力) | 0.05-0.10/km | 5-10/km | 100 | EV vs ICE |

**注：** 具体数值需根据城市实际情况、电网清洁度、公交电动化率等因素调整。

### 6.3 MaaS碳减排量聚合与交易

```
聚合流程：
  个人碳账户 → MaaS平台聚合 → 碳资产管理平台 → CCER/碳普惠登记

北京MaaS碳交易案例：
  - 聚合用户数：2400万+
  - 聚合减排量：约2.5万吨CO2/年（一期）
  - 单吨成交价：约50元（自愿减排市场）
  - 碳收益归属：用户激励+平台运营+碳资产开发

碳收益分配建议模型：
  用户激励：50-60%
  平台运营：20-25%
  碳资产开发/核查：15-20%
  数据/技术方：5%
```

## 九、碳中和路径计算器

### 9.1 碳达峰/碳中和路径模拟

```
路径模拟逻辑：

Step 1: 确定基准年排放量 E_base（如2020年）
Step 2: 定义BAU（Business As Usual）情景下的排放增长趋势
Step 3: 定义各项减排措施及减排量
Step 4: 逐年计算净排放量
Step 5: 判断达峰年份和中和可行性

E_year = E_BAU_year - Σ(E_reduction_i)

其中：
  E_BAU_year = E_base × (1 + growth_rate)^(year-base_year)
  E_reduction_i = 第i项减排措施的减排量（吨CO2/年）
```

## 十、使用说明

1. **碳排放核算**：根据项目范围选择第二节的适用公式，使用第三节的中国特化排放因子
2. **MRV体系建设**：按照第四节的MRV工作流建立碳排放监测-报告-核查体系
3. **碳足迹追踪**：参考第五节的碳足迹数据模型设计碳追踪系统
4. **碳普惠运行框架**：使用第六节的方法论和速查表设计碳积分体系
5. **碳交易准备**：使用第七节的检查清单评估碳交易就绪度
6. **认证申报**：按照第八节准备绿色交通认证材料
7. **碳达峰模拟**：使用第九节的路径计算器进行达峰/中和路径模拟
8. **数据更新**：排放因子和碳市场价格需定期更新（建议每次使用前核查最新官方发布值）
