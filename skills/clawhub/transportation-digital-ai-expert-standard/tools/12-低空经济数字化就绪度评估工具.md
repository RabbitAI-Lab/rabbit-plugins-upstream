# 低空经济数字化就绪度评估工具

> 本工具用于评估城市/区域的低空经济数字化基础设施就绪度，涵盖法规行业规范、基础设施、市场需求、技术能力、组织保障五大维度30项评估指标，并提供UTM平台功能检查清单、起降场选址标准、投资估算模型和实施路线图。

## 二、UTM平台功能检查清单（32项）

### 2.1 空域管理（8项）

- [ ] 1. 空域网格化管理（动态划分/合并/释放）
- [ ] 2. 电子围栏管理（永久/临时/动态电子围栏）
- [ ] 3. 航线规划（自动避障+多约束优化）
- [ ] 4. 航线审批（在线申请→自动审核→即时批准）
- [ ] 5. 空域容量管理（实时负载监控+流量控制）
- [ ] 6. 特殊空域协调（与空域管理部门系统对接）
- [ ] 7. 空域冲突检测与消解（4D轨迹预测+冲突预警）
- [ ] 8. 临时禁飞区管理（重大活动/突发事件快速设禁）

### 2.2 飞行监控（8项）

- [ ] 9. 飞行器实时位置监控（北斗/GPS+4G/5G回传）
- [ ] 10. 飞行状态监控（高度/速度/航向/电量/信号）
- [ ] 11. 电子身份识别（Remote ID广播+查询）
- [ ] 12. 飞行轨迹回放（历史轨迹查询+异常分析）
- [ ] 13. 地理围栏告警（接近/突破电子围栏即时告警）
- [ ] 14. 飞行器健康监测（电池/电机/通信/传感器状态）
- [ ] 15. 视频实时回传（可选，用于巡检/安防场景）
- [ ] 16. 多机协同监控（同一空域多飞行器同时监控）

### 2.3 调度与协同（8项）

- [ ] 17. 飞行计划管理（申报→审核→批准→执行→完成）
- [ ] 18. 动态优先级调度（医疗急救/消防救援优先）
- [ ] 19. 多运营商协同（不同运营商的飞行器协同避让）
- [ ] 20. 机场/起降场调度（起降时段分配+冲突消解）
- [ ] 21. 地面保障调度（充电/装卸/维护窗口管理）
- [ ] 22. 恶劣天气应对（雷暴/大风/低能见度自动调整）
- [ ] 23. 应急返航/备降引导（故障/低电量自动规划）
- [ ] 24. 飞行任务效能分析（任务完成率/时效/成本）

### 2.4 安全与合规（8项）

- [ ] 25. 飞行安全风险评估（飞行前风险评分+决策支持）
- [ ] 26. 事故/事件报告（强制报告+自动生成+追踪闭环）
- [ ] 27. 操作员资质管理（证书/体检/培训/飞行记录）
- [ ] 28. 飞行器适航管理（适航证/维修记录/改装记录）
- [ ] 29. 保险管理（第三者责任险+机身险+货运险）
- [ ] 30. 数据安全（飞行数据加密+隐私保护+数据分级）
- [ ] 31. 评估审查与合规报告（操作日志+安全管理报告+监管报表）
- [ ] 32. 网络安全（身份认证+访问控制+入侵检测+等保合规）

## 五、30项法规合规检查清单

### 5.1 民航管理合规（CAAC）

- [ ] 1. 无人机实名登记（所有飞行器完成UOM平台登记）
- [ ] 2. 运营合格审定（运营人持有经营许可证）
- [ ] 3. 飞行人员资质（驾驶员持有有效执照/合格证）
- [ ] 4. 适航管理（飞行器通过适航检查/持证）
- [ ] 5. 飞行计划申报（按规定申报飞行计划）
- [ ] 6. 飞行记录保存（飞行数据/日志按规定保存）
- [ ] 7. 事故/事件报告（24小时内报告不安全事件）
- [ ] 8. UTM平台备案（UTM平台向局方备案）

### 5.2 空域与安全管理

- [ ] 9. 空域使用审批（使用空域经批准）
- [ ] 10. 禁飞区避让（飞行活动避开公布的禁飞区）
- [ ] 11. 临时禁飞遵守（重大活动期间遵守临时禁飞规定）
- [ ] 12. 飞行高度限制（遵守高度层限制）
- [ ] 13. 目视飞行规则（遵守VLOS/BVLOS相关规定）
- [ ] 14. 夜间飞行许可（夜间飞行经特别审批）

### 5.3 地方管理机构合规

- [ ] 15. 项目启动/备案（向地方投资归口部门部门备案）
- [ ] 16. 环境影响评估（涉及建设项目需环评）
- [ ] 17. 土地/规划许可（起降场需用地规划许可）
- [ ] 18. 消防审批（起降场/机库等需消防审批）
- [ ] 19. 特种设备管理（充电桩/储能设备需报备）
- [ ] 20. 噪音排放达标（符合地方噪音排放标准）
- [ ] 21. 公众安全保护（有公众安全告知+防护措施）

### 5.4 公共安全合规

- [ ] 22. 大型活动安全许可（涉及公共活动需安保方案）
- [ ] 23. 危险品运输管理（涉及危险品需专项审批）
- [ ] 24. 个人信息保护（采集人脸/位置等需合规告知）
- [ ] 25. 视频监控管理（公共区域视频需备案）

### 5.5 数据与网络安全

- [ ] 26. 数据安全法合规（数据分类分级+安全保护）
- [ ] 27. 个人信息保护法合规（告知同意+最小必要）
- [ ] 28. MLPS（UTM平台需通过等保测评）
- [ ] 29. CII保护（如被认定为CII需满足关基条例）
- [ ] 30. 数据本地化存储（飞行数据/位置数据境内存储）

## 六、四阶段实施路线图

| 阶段 | 时间 | 核心任务 | 里程碑 |
|:---:|:---:|------|------|
| **Phase 1** 试点验证先行 | 0-12个月 | 发展方案撰写+1-2个起降点+UTM平台V1.0+2-3条试验航线+1家运营商引入 | 首条航线获批运营 |
| **Phase 2** 基础建设 | 12-24个月 | 5-10个起降点+低空通信专网+监视雷达+UTM平台V2.0+3-5家运营商 | 城市低空网络初步形成 |
| **Phase 3** 规模运营 | 24-36个月 | 20+起降点+全域监视+城市级UTM+10+家运营商+8+条常态化航线 | 日均飞行>100架次 |
| **Phase 4** 生态繁荣 | 36-60个月 | 50+起降点+城市群协同+低空大脑+20+家运营商+完整产业链 | 低空经济产业集群形成 |

---

> **使用建议**：本评估工具建议由低空经济归口部门牵头，联合空域管理、民航、工信、交通、交管等部门共同完成评估。每12个月重新评估一次以追踪进展。评估结果可作为低空经济标杆区申报和公共投资决策的依据。
