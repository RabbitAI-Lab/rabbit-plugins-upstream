# 车路协同试点验证部署执行手册

## 手册概览

| 项目 | 说明 |
|------|------|
| **适用场景** | 在城市道路或高速公路部署车路协同（V2X）试点验证项目，包括RSU/OBU/MEC/感知设备安装、系统集成、测试验证 |
| **技术架构** | "车-路-云-网"四层架构，参考中国C-V2X车路云一体化标准体系 |
| **试点验证规模** | 典型试点验证：10-50个路口（城市）/ 10-30公里路段（高速） |
| **总周期** | 5-8个月（不含恶劣天气停工时间） |
| **核心交付团队** | 项目经理1人 + 土木/施工团队(外包) + 网络工程师1人 + 系统集成工程师2-3人 + 测试工程师2人 |
| **安全要求** | 施工安全是第一位——占道施工必须按国标设置安全防护，任何安全事故一票否决 |

## 第一阶段：点位选取与规划（第1-4周）

### 1.1 点位选取标准

**城市道路点位选取评分表：**

| 选取维度 | 权重 | 理想条件 | 评分(1-5) | 说明 |
|----------|------|----------|------|------|
| 道路等级 | 20% | 主干道/次干道（非小支路，非纯居民区小路） | | 主干道5，次干道4，支路2 |
| 交通流量 | 20% | 日均流量>20,000辆，有明显高峰 | | 流量高=矛盾多=V2X价值大 |
| 事故历史 | 25% | 近3年有伤亡事故记录，或事故多发点 | | 事故高发点是V2X价值最强的点位——"解决痛点" |
| 交通场景复杂度 | 15% | 含复杂交叉口（异形路口/无灯控路口/人车混行） | | V2X的安全价值在复杂场景下最突出 |
| 道路拓扑 | 10% | 路口间距合理(200-800m)，有良好视距或无遮挡 | | RSU覆盖约300-500m半径 |
| 供电与通信条件 | 10% | 附近有稳定电源和光纤接入点 | | 无供电需重新拉线，大幅增加成本和周期 |
| **加权总分** | | | | >3.5分优先选，2.5-3.5分可选，<2.5分不建议 |

**高速公路点位选取评分表：**

| 选取维度 | 权重 | 理想条件 | 评分说明 |
|----------|------|----------|------|
| 事故黑点 | 30% | 近3年事故多发路段（弯道/坡道/隧道口/互通区） | V2V/V2I预警最有价值的场景 |
| 恶劣天气常发 | 20% | 团雾/结冰/横风常发路段 | V2X在能见度低时替代视觉感知 |
| 交通流量 | 15% | 日均>30,000辆，货车占比较高 | 货车事故严重度高，V2X预警价值大 |
| 合流/分流区 | 15% | 互通立交、服务区出入口 | 合流冲突是高速事故主因之一 |
| 施工/改扩建区 | 10% | 计划中的施工区（临时部署） | V2X在施工区可提供精准的动态预警 |
| 供电通信条件 | 10% | 附近有供电和光纤条件 | |

### 1.2 覆盖设计

**RSU（路侧单元）部署规划原则：**

| 场景 | 推荐间距 | 覆盖范围 | 安装高度 | 说明 |
|------|----------|----------|----------|------|
| 城市开放道路 | 300-500m | 半径300m左右 | 6-10m（路灯杆/信号灯杆） | 注意高楼遮挡——城市峡谷效应 |
| 城市交叉口 | 每路口1台 | 覆盖整个路口及进口道150m | 6-10m | RSU安装在交叉口中心的信号灯杆或专用杆上 |
| 高速公路直线段 | 500-800m | 半径400m左右 | 8-15m（龙门架/专用杆） | 高速车速快，需提前预警距离 |
| 高速公路弯道/坡道 | 300-500m | 视距受限区域加密 | 8-15m | 弯道内侧或坡顶 |
| 隧道 | 隧道口+隧道内每500m | 隧道内外协同 | 隧道壁安装 | 隧道内无GPS信号，需RSU密集覆盖辅助定位 |

**RSU数量计算：**
```
城市道路试点验证：N_RSU ≈ 路口数 × 1.2（系数考虑路段补充）
高速公路试点验证：N_RSU ≈ 路段长度(km) / 0.5（平均500m一台）
```

### 1.3 基础设施勘察

**杆件/基础设施勘察检查清单：**

**A. 杆件条件：**
- [ ] 杆件类型：路灯杆/信号灯杆/电警杆/交通标志杆/龙门架/专用杆
- [ ] 杆件高度是否满足RSU安装要求（建议6-15m）
- [ ] 杆件承重能力是否满足（RSU+天线+安装附件，通常<20kg，但需确认）
- [ ] 杆件是否有空余的横臂/挂载位置
- [ ] 如需新立杆，是否有地下管线/行道树/建筑红线等障碍？
- [ ] 杆件是否产权清晰？（路灯杆归城管/路灯管理处，信号灯杆归交管，需要对应产权部门许可）

**B. 供电条件：**
- [ ] 附近是否有稳定220V AC电源接入点？
- [ ] 取电距离？如果>50m，需要铺设电缆或采用太阳能+电池方案
- [ ] 是否需要独立电表？（大型项目通常需要独立计量）
- [ ] 备用电源方案？（关键路口建议配UPS或太阳能+电池）

**C. 通信条件：**
- [ ] 附近是否有光纤接入点（如运营商的FTTx/政务网光纤）？
- [ ] 光纤接入点距离？（如果>200m，光纤铺设成本大幅增加）
- [ ] 如无光纤，是否可用5G/LTE-V2X回传？（需确认5G信号覆盖和带宽）
- [ ] 无线回传方案：需确认运营商5G信号强度、带宽、时延（需实测）

**D. 视距条件：**
- [ ] RSU天线安装位置是否被建筑物/树木/广告牌遮挡？
- [ ] 路口4个方向是否都有较开阔的视野？
- [ ] 对于摄像头/雷达/激光雷达，是否在安装高度能看到路口各进口道？

## 第二阶段：土建施工与设备安装（第5-16周）

### 2.1 杆件安装

**新立杆件施工步骤：**

| 步骤 | 内容 | 养护/等待时间 | 注意事项 |
|------|------|------|------|
| 1. 点位放样 | 按设计图纸在实地标注杆件位置 | 1天 | 确认地下无管线（联系城管/地下管线管理部门做管线探测） |
| 2. 基坑开挖 | 按杆件基础图纸开挖 | 1-2天 | 基坑尺寸：通常1.2m×1.2m×1.5m（深），视杆件高度调整 |
| 3. 基础浇筑 | 预埋地脚螺栓+浇筑混凝土基础 | 需养护7-14天 | C25/C30混凝土；预埋PE管（用于穿电缆） |
| 4. 杆件运输 | 将杆件从工厂运至现场 | 1天 | 运输前完成热镀锌+喷漆 |
| 5. 杆件吊装 | 吊车立杆+与地脚螺栓固定 | 半天 | 交通管制+安全员+吊装资质作业人员 |
| 6. 接地施工 | 杆件防雷接地 | 半天 | 接地电阻≤10Ω |
| 7. 验收 | 杆件垂直度+地脚螺栓扭矩+防腐层 | 半天 | |

**利用现有杆件注意事项：**
- 必须取得杆件产权单位的书面同意函
- 施工前对杆件做结构安全评估——腐蚀/倾斜/裂纹，不合格的杆件不使用
- 抱箍安装（非打孔）——不得损伤原杆件结构

### 2.2 供电施工

**供电方案选择：**

| 方案 | 适用场景 | 优势 | 局限 |
|------|----------|------|------|
| 就近取市政电 | 附近<50m有配电箱/路灯电源 | 稳定、成本低 | 需电力部门审批增容/并表 |
| 太阳能+储能电池 | 偏远路段/无市政电 | 独立、可再生 | 连续阴雨天气续航问题、电池周期性更换 |
| 太阳能+市电互补 | 不稳定的市电环境 | 可靠性高 | 成本较高 |
| POE供电（仅限低功耗设备） | 短距离、低功耗 | 布线简单 | 距离<100m、功率<30W(标准)/<90W(POE++) |

**供电施工检查清单：**
- [ ] 已取得电力接入许可
- [ ] 电缆选型符合户外/埋地要求（YJV22铠装电缆或穿管保护）
- [ ] 电缆埋深符合规范（一般>0.7m）
- [ ] 已安装漏电保护装置
- [ ] 已安装防雷浪涌保护器
- [ ] 独立电表已安装（如需独立计量）
- [ ] 电缆路径已做标记（防止后期其他施工挖断）

### 2.3 网络/回传施工

**回传方案选择矩阵：**

| 场景 | 首选方案 | 备选方案 | 建议 |
|------|----------|----------|------|
| 路口附近有光纤接入点（<200m） | 光纤直连 | 5G专网/CPE | 光纤延迟最低，可靠性最高 |
| 路口附近无光纤（200-500m） | 5G CPE | 自建微波/自建光纤 | 5G CPE部署最快，但需做信号和延迟测试 |
| 高速公路沿线 | 沿线光纤（如沿护栏/管道铺设） | 5G + 分段光纤 | 高速通常有沿线管道，优先用光纤 |
| 偏远地区 | 5G/4G | 卫星+边缘缓存 | 延迟和带宽受限，应用场景需降级 |

**光纤铺设要求：**
- 室外光纤：单模、铠装、G.652D
- 光纤接头：LC/UPC或SC/UPC
- 光纤熔接损耗：<0.3dB/点
- 全程衰减：<链路预算（通常<3dB@1310nm，因距离短）
- 预留纤芯：每个点位至少2芯（1主1备+可扩展）
- 光纤保护：埋地穿管（PVC/PE管）、架空钢绞线固定

### 2.4 RSU安装

**RSU安装步骤与检查清单：**

| 步骤 | 内容 | 检查项 |
|------|------|--------|
| 1. 安装前检查 | 设备开箱验收 | 型号、数量、配件完整、外观无损 |
| 2. 支架安装 | 在杆件横臂/顶端安装RSU支架 | 支架是否紧固（扭力扳手校验）、防水密封 |
| 3. RSU主机安装 | 将RSU主机固定在支架上 | 安装方向正确（通常是竖直）、散热面不被遮挡 |
| 4. 天线安装 | 安装V2X天线（PC5/Uu双天线或多天线） | 天线极化方向正确、无遮挡、天线馈线弯曲半径>5倍线径 |
| 5. 线缆连接 | 连接电源线(AC/DC/POE)、光纤/网线、天线馈线 | 接头拧紧、防水处理（户外必须用IP67防水接头+防水胶带） |
| 6. 防雷接地 | 接地线连接到杆件接地系统 | 接地电阻≤10Ω |
| 7. 上电测试 | 通电检查设备状态指示灯 | 电源指示灯绿、系统启动正常、网络连通 |
| 8. 初步配置 | 配置RSU IP地址、PC5参数、对接MEC/云平台地址 | Ping通MEC/云平台、基站授时正常 |
| 9. 标签与记录 | 粘贴设备标签+拍照记录 | 标签含：点位编号、RSU序列号、安装日期、维护电话 |
| 10. 安装报告 | 填写安装记录表 | 每个点位的安装记录表签字+照片归档 |

**关键安装注意点：**
- RSU天线和4G/5G/WiFi天线之间保持至少30cm间距（避免同频/邻频干扰）
- 天线馈线尽量短（每增加1米，信号衰减约0.3-0.5dB@5.9GHz）
- 所有户外接头用防水胶带"三层法"：一层绝缘胶带→一层防水自粘带→一层绝缘胶带
- 安装完成后用V2X路测设备在300m/500m/800m处做信号强度测试

### 2.5 传感器安装与标定

**常见路侧传感器安装：**

| 传感器类型 | 安装方式 | 安装高度 | 视野要求 | 标定方法 |
|----------|----------|----------|----------|----------|
| 摄像头（枪机/球机） | 横臂/杆顶支架 | 6-12m | 覆盖进口道150m+停止线区域 | 棋盘格标定+路面特征点GPS标定 |
| 毫米波雷达 | 横臂支架 | 6-10m | 覆盖2-4车道，远距离>200m | 角反射器标定+静止目标验证 |
| 激光雷达(LiDAR) | 横臂/杆顶 | 6-10m | 360°或定向覆盖 | 点云配准+GPS/IMU标定 |
| 边缘计算单元(MEC) | 杆体机箱/抱杆机箱 | 离地>1.5m | 通风防雨、防晒 | - |

**传感器联合标定流程：**
1. 摄像头内参标定（棋盘格法）
2. 摄像头外参标定——使用GPS RTK测量路面控制点，建立图像像素↔世界坐标映射
3. 雷达标定——使用角反射器在已知位置，校准雷达方位角、俯仰角、距离
4. 多传感器联合标定——激光雷达↔摄像头、雷达↔摄像头坐标系对齐
5. 标定质量验证——已知位置目标物（标定车）的检测位置误差<0.5m

## 第三阶段：系统集成（第13-24周，与第二阶段有重叠）

### 3.1 RSU-MEC-云平台集成

**集成架构：**

```
RSU（路侧单元）
  ├─ PC5接口(V2X直连通信) ←→ OBU(车载单元)
  ├─ 以太网/光纤 ←→ MEC(边缘计算单元)
  └─ 可选: 5G Uu接口 ←→ V2X云平台
MEC（边缘计算单元）
  ├─ 接入多传感器(摄像头/雷达/激光雷达)
  ├─ 运行感知融合算法
  ├─ 生成V2X消息(BSM/RSI/RSM/MAP/SPAT)
  ├─ 以太网/光纤 ←→ V2X云平台
  └─ 可选: 以太网 ←→ 交通信号机
V2X云平台
  ├─ V2X消息管理
  ├─ 跨路口/跨区域协同
  ├─ 数据存储与分析
  └─ 应用服务API
```

**集成测试步骤：**

| 步骤 | 测试内容 | 预期结果 | 工具 |
|------|----------|----------|------|
| 1. 网络连通性 | RSU↔MEC Ping | 延迟<5ms | Ping命令 |
| 2. 授时同步 | RSU和MEC的GPS/NTP时间 | 同步误差<1μs（PC5需要高精度同步） | NTP查询/GPS状态灯 |
| 3. RSU注册 | RSU向MEC/云平台注册成功 | 平台显示RSU在线 | 云平台管理页面 |
| 4. 数据上报 | RSU上报BSM/V2X消息到MEC/云 | 消息接收正常，延迟<50ms（RSU→MEC） | Wireshark + 云平台接收日志 |
| 5. MAP消息下发 | 云→MEC→RSU→OBU MAP消息 | OBU正确解析并显示路口地图 | OBU测试APP |
| 6. SPAT消息下发 | 信控系统→RSU→OBU SPAT信号灯状态 | OBU正确显示绿灯剩余秒数 | OBU测试APP + 与信号灯实际状态对比 |
| 7. RSI消息生成 | MEC融合感知→生成RSI(Road Side Information) | 事件检测正确+消息格式合规 | MEC日志 + OBU测试APP |

### 3.2 V2X消息测试

**核心V2X消息集测试（Day 1场景）：**

| 消息类型 | 缩写 | 发送方 | 内容 | 测试验证点 |
|----------|------|--------|------|------|
| 基本安全消息 | BSM | OBU | 车辆位置/速度/方向/加速度 | OBU周期性发送（10Hz）、RSU正确接收、消息内容正确 |
| 路侧安全消息 | RSM | RSU | 路侧感知到的交通参与者（车辆/行人/非机动车） | MEC融合感知后生成RSM、发送频率、内容准确 |
| 路侧信息 | RSI | RSU | 路侧事件（事故/施工/拥堵/恶劣天气/限速等） | 事件创建→RSI生成→OBU接收→正确触发预警 |
| 地图消息 | MAP | RSU | 路口车道级地图 | OBU是否能正确渲染路口地图、车道信息和连接关系正确 |
| 信号灯消息 | SPAT | RSU | 信号灯实时相位和剩余时间 | OBU显示与实地信号灯一致（延迟<100ms） |

**V2X消息一致性测试工具：**
- 信通院/中国汽研 V2X协议一致性测试工具
- OpenV2X开源测试工具
- 各RSU/OBU厂商自带的测试APP
- Wireshark抓包+V2X消息解析插件

### 3.3 应用场景验证

**Day 1必测场景（17个——CSAE 53-2020标准）：**

| # | 场景名称 | 类型 | 测试方法 | 通过标准 |
|---|----------|------|----------|----------|
| 1 | 前向碰撞预警(FCW) | V2V | 2辆车，1车减速/刹停，另一车接近 | TTC<2秒时预警触发 |
| 2 | 交叉路口碰撞预警(ICW) | V2V | 2辆车从垂直方向接近无灯控路口 | 碰撞前3-5秒预警触发 |
| 3 | 左转辅助(LTA) | V2V | 左转车辆与对向直行车辆冲突 | 检测到冲突时触发预警 |
| 4 | 盲区预警/变道预警(BSW/LCW) | V2V | 相邻车道盲区内有车 | 检测到盲区有车时预警 |
| 5 | 紧急制动预警(EEBL) | V2V | 前车紧急制动（减速度>4m/s²） | 紧急制动触发后100ms内发出预警 |
| 6 | 逆向行驶预警 | V2V | 模拟逆向行驶车辆 | 检测到逆向时立即触发 |
| 7 | 弱势交通参与者预警(VRU) | V2P | 模拟行人/非机动车横穿 | RSU检测到后通过PC5发送预警给车辆 |
| 8 | 绿波车速引导(GLOSA) | V2I | 获取SPAT后计算推荐车速 | 按推荐车速行驶能绿灯通过 |
| 9 | 信号灯车内显示 | V2I | OBU接收并显示SPAT | 与实际信号灯状态一致，延迟<100ms |

### 4.2 性能基准测试

**关键性能指标（KPI）测试：**

| 性能指标 | 定义 | 测试方法 | 行业基准值 | 目标值 |
|----------|------|----------|------------|--------|
| 端到端延迟(E2E Latency) | 事件发生→OBU收到预警的时间 | 高精度时间戳记录（GPS同步）→计算差值 | <100ms(Day1), <20ms(Day2高级) | <100ms |
| PC5通信延迟 | RSU→OBU空口延迟 | 发送时间戳vs接收时间戳 | <20ms | <20ms |
| 消息包到达率(PDR) | PC5广播消息的成功接收比例 | 发送1000条消息，统计OBU收到的数量 | >95% | >95% |
| 通信距离 | PDR>95%的最大距离 | 测试车远离RSU，记录PDR随距离变化 | LOS>800m(城市), >1500m(高速) | >500m(城市) |
| 定位精度 | 车辆自定位精度 | 高精度RTK基准 vs OBU GPS输出 | <1.5m | <1.5m(有RTK时<0.3m) |
| RSU感知精度 | RSU感知的车辆位置vs真实位置 | 高精度RTK基准车 vs RSU感知位置 | 位置误差<1m | <1m |
| RSU感知召回率 | RSU检测到的车辆/实际所有车辆 | 视频回溯人工标注 vs RSU检测结果 | >95% | >95% |
| 系统可用率 | 7×24可用率 | 持续监控1周 | >99.9% | >99.5%（试点验证） |

**延迟测量方法：**
1. 所有设备（RSU/MEC/OBU/测试摄像头/基准传感器）统一使用GPS/北斗授时
2. 在触发性事件（如模拟行人横穿）发生时，用高精度GPS记录T0
3. 在OBU收到预警时记录T1
4. 端到端延迟 = T1 - T0（需扣除T0检测耗时，纯通信延迟=OBU收到时间−RSU发送时间）

### 4.3 性能调优

**常见性能问题与调优方法：**

| 问题 | 原因 | 调优方法 |
|------|------|----------|
| 通信距离不足 | 天线增益低/遮挡/多径干扰 | 更换高增益天线(5→8dBi)、调整天线安装位置和方向角 |
| 包到达率低 | 同频干扰/距离太远/天线问题 | 信道扫描找出干扰源→更换信道、加密RSU部署（缩短间距） |
| 延迟偏高 | MEC计算负载高/网络拥塞/消息队列积压 | MEC硬件升级(GPU加速)、优化融合算法、确保网络QoS |
| 感知误检/漏检 | 传感器标定不准/天气影响/遮挡 | 重新标定传感器、增加冗余传感器（雷达弥补摄像头雨天不足） |
| 定位漂移 | 城市峡谷GPS多径/GNSS信号弱 | 加装惯导IMU融合、RTK差分站补盲、UWB局部定位补充 |
| 系统不稳定 | 散热不良/供电不稳/IP冲突 | 检查机箱通风、UPS/稳压、网络规划 |

## 附C：安全协议（施工期间）

**施工安全十条：**

1. **占道施工必须提前24小时向交管部门报备**，取得书面许可后方可施工
2. **施工区域前方必须按国标（GB 5768）设置安全警示**：警告标志(提前>100m) → 施工标志 → 限速标志 → 锥桶/水马隔离 → 施工区
3. **所有施工人员必须穿着反光背心、安全帽**；高处作业（>2m）必须系安全带，含双钩双挂点
4. **吊车作业必须设专职信号指挥员**——1人操作、1人指挥——不得让他人替代
5. **带电作业必须由持证电工操作**，断电→验电→挂牌→作业→恢复
6. **遇恶劣天气（大风>6级/暴雨/雷电/大雾能见度<200m）时，立即停止高处和带电作业**
7. **每日施工前必须进行安全交底**——今天干什么、危险在哪、怎么办
8. **每天收工时必须清理现场**——不留坑洞未盖、不留尖锐物、不留临时电缆绊脚
9. **施工期间保持1条车道以上通行**——如需全封闭，必须有绕行方案并提前公告
10. **任何人员有权因安全问题停止作业**——安全>进度

**应急预案（施工期间）：**
- 人员受伤：立即拨打120 → 现场急救 → 保护现场 → 报告项目负责人
- 电缆/管线挖断：立即停工 → 通告产权单位 → 隔离危险区 → 启动修复
- 交通拥堵严重：启动临时开放车道方案 → 通告交管部门 → 调整施工计划
- 设备坠落：立即疏散下方人员 → 拉警戒线 → 排查原因
