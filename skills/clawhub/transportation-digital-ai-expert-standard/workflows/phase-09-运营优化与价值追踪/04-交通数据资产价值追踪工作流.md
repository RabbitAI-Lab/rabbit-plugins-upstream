## 二、详细步骤说明

---

### 步骤1：数据资产盘点

**目标**：全面盘点交通数据资产，建立数据资产目录。

**操作指南**：

**1.1 交通数据资产分类**

| 数据大类 | 数据子类 | 核心数据 |
|---------|---------|---------|
| 基础设施数据 | 路网/桥隧/场站/设备 | 路段属性、桥隧BIM、设备台账 |
| 动态运行数据 | 交通流/事件/收费/气象 | 流量序列、事件记录、ETC交易 |
| 业务管理数据 | 养护/应急/执法/客服 | 养护记录、应急方案、热线工单 |
| 出行服务数据 | OD/出行行为/偏好 | 出行路径、模态选择、支付习惯 |
| 企业管理数据 | 人事/财务/资产/工程 | 组织、预算、合同、资产台账 |
| 外部数据 | 气象/POI/舆情/地图 | 天气、导航数据、社交媒体 |

**1.2 数据资产目录模板**

| 数据资产名称 | 所属数据域 | 数据量 | 更新频率 | 重要等级 | 使用部门 | 数据Owner |
|------------|----------|:---:|:---:|:---:|---------|----------|
| 交通流量5分钟数据 | 运行监测 | 50TB | 5分钟 | ★★★ | 运营/养护 | 信息中心 |

### 步骤2：价值评估模型建立

**目标**：建立评估数据资产价值的模型。

**操作指南**：

**2.1 数据价值五维模型**

| 价值维度 | 说明 | 评分(1-5) |
|---------|------|:---:|
| 业务支撑价值 | 数据对核心业务的不可或缺程度 | |
| 决策支撑价值 | 数据对管理决策的支撑程度 | |
| 共享复用价值 | 数据被多个部门/系统共享使用的程度 | |
| 创新开发价值 | 数据对AI/数据产品开发的价值 | |
| 外部交换价值 | 数据对外部（上级/公众/市场）的价值 | |

**2.2 数据资产价值指数计算**

```
价值指数 = Σ(各维度得分 × 权重)

推荐权重:
  业务支撑 30% + 决策支撑 25% + 共享复用 20% + 创新开发 15% + 外部交换 10%

价值分级:
  · A级（指数>4.0）: 核心数据资产，重点保护和经营
  · B级（指数3.0-4.0）: 重要数据资产，持续优化提升
  · C级（指数<3.0）: 一般数据资产，正常管理即可
```

### 步骤3：价值追踪指标监控

**目标**：建立持续的数据价值追踪运行框架。

**操作指南**：

**3.1 数据价值追踪指标**

| 指标类别 | 指标 | 说明 |
|---------|------|------|
| 数据使用量 | API调用次数/月 | 数据被访问和使用的频次 |
| 数据使用者 | 使用数据的不同部门/系统数量 | 数据的覆盖面 |
| 数据驱动决策次数 | 基于数据做出的决策数量 | 数据的实际影响力 |
| 数据质量问题 | 数据质量事件数量 | 数据的可信度 |
| 数据应用场景 | 基于数据开发的应用/模型数量 | 数据的创新应用 |
| 数据共享记录 | 数据对外共享的次数和范围 | 数据的流通价值 |

**3.2 数据价值仪表盘**

```
数据价值仪表盘 (月度):

  ┌──────────────┬──────────────┬──────────────┐
  │ API调用:     │ 活跃用户:    │ 数据产品:     │
  │ 125万次/月   │ 8个部门      │ 15个         │
  │  ↑ 12%      │  ↑ 1个新部门  │  ↑ 3个新品    │
  ├──────────────┼──────────────┼──────────────┤
  │ 数据质量:    │ 数据共享:     │ 决策影响:     │
  │ 99.2%准确率 │ 5次共享/月   │ 12次决策/月  │
  │  → 稳定     │  ↑ 2次       │  ↑ 25%       │
  └──────────────┴──────────────┴──────────────┘
```

### 步骤4：数据服务产品化

**目标**：将数据资产转化为可复用的数据服务产品。

**操作指南**：

**4.1 数据服务产品类型**

| 产品类型 | 说明 | 示例 |
|---------|------|------|
| 数据API | 标准化数据查询接口 | 实时路况API、流量统计API |
| 数据报告 | 定期生成的数据分析报告 | 月度交通运行报告 |
| 数据看板 | 可视化数据展示 | 决策者驾驶舱、运营大屏 |
| 数据模型 | AI/分析模型输出 | 拥堵预测模型、事故风险评估 |
| 数据订阅 | 数据推送服务 | 异常事件实时推送 |

**4.2 数据产品定价参考**

| 定价模式 | 说明 | 适用场景 |
|---------|------|---------|
| 按调用量 | 按API调用次数计费 | 高频访问的API |
| 按订阅期 | 按月/季/年订阅 | 报告/看板类 |
| 按项目 | 一次性项目交付 | 深度分析/定制模型 |
| 按增值分成 | 基于数据产生收益的分成 | 数据联合运营 |

### 步骤5-8：安全合规与战略演进

**5. 数据安全与权限**：
- 数据分类分级管理（按数据安全法规）
- 数据访问权限最小化
- 数据操作评估审查日志

**6. 数据合规与隐私**：
- 个人信息保护（个人信息保护法规合规）
- 交通出行数据的脱敏处理
- 数据出境安全评估（如有外资场景）

**7. 价值报告撰写**：
- 季度数据资产价值报告
- 数据使用效益分析

**8. 数据战略演进**：
- 从"数据资源"到"数据资产"到"数据资本"
- 探索数据交易/数据要素市场参与
- 数据资产入表（详见phase-10-02）
