## 二、详细步骤说明

---

### 步骤1：干系人识别与登记

**目标**：全面识别所有受项目影响的干系人。

**操作指南**：

**1.1 干系人洋葱模型**

```
         ┌───────────────────────────┐
         │     外部干系人             │
         │  ·上级归口部门/投资归口部门/资金方归口部门│
         │  ·公众/出行者/媒体          │
         │  ·合作伙伴/供应商           │
         │  ┌─────────────────────┐  │
         │  │   间接干系人          │  │
         │  │ ·其他部门/同级单位    │  │
         │  │ ·行业监管机构         │  │
         │  │ ┌───────────────┐   │  │
         │  │ │ 核心干系人      │   │  │
         │  │ │·项目Sponsor    │   │  │
         │  │ │·直接用户       │   │  │
```

### 步骤2：影响力-利益矩阵

**目标**：基于影响力和利益度对干系人进行分类，确定管理策略。

**操作指南**：

**2.1 四象限分类与管理策略**

```
         高影响力
            │
   满足需求  │  密切管理
  (Keep      │ (Manage
   Satisfied)│  Closely)
            │
 ───────────┼───────────→ 高利益度
  低利益度   │
            │
   监控      │  保持知情
  (Monitor)  │ (Keep
            │  Informed)
            │
         低影响力
```

| 象限 | 管理策略 | 沟通频次 |
|------|---------|:---:|
| 高影响力+高利益 | 密切管理，核心关注对象 | 每周+ |
| 高影响力+低利益 | 满足需求，不过度打扰 | 每月 |
| 低影响力+高利益 | 保持知情，发挥积极作用 | 每两周 |
| 低影响力+低利益 | 监控，最低限度沟通 | 按需 |

---

### 步骤3：沟通策略制定

**目标**：为每个干系人/干系人群制度框架定量身定制的沟通策略。

**操作指南**：

**3.1 沟通计划模板**

| 干系人 | 沟通目标 | 核心信息 | 沟通方式 | 频次 | 责任人 |
|-------|---------|---------|---------|:---:|-------|
| 局决策者 | 获取支持和资源 | 战略价值、行业地位 | 月报+专题汇报 | 月 | PM |
| 信息中心 | 技术方案认可 | 技术架构、实施计划 | 周会+邮件 | 周 | 架构师 |
| 业务部门 | 积极参与配合 | 业务价值、操作培训 | 演示+培训 | 双周 | BA |
| 资金方归口部门 | 资金审批 | 效益分析、合规说明 | 正式报告 | 按节点 | 商务 |

---

### 步骤4：关键信息撰写

**目标**：为不同干系人撰写定制化的关键信息。

**操作指南**：

**4.1 分层信息设计**

| 层级 | 信息重点 | 信息粒度 | 示例 |
|------|---------|---------|------|
| 决策层 | 战略意义、投资回报、风险可控 | 高度概括 | "项目建成后将使我市智慧交通水平跻身全国前十" |
| 管理层 | 业务价值、实施路径、资源需求 | 中等粒度 | "一期建设将提升事件检测率从30%到80%" |
| 操作层 | 功能变化、操作培训、个人影响 | 具体翔实 | "新系统上线后，您的日常巡检将从2小时减少到15分钟" |
| 外部 | 公共利益、服务改善 | 通俗易懂 | "市民可以通过手机实时查看公交到站时间" |

---

### 步骤5-8：沟通执行-反馈收集-冲突化解-策略复盘

**5. 沟通执行要点**：
- 严格按沟通计划执行
- 重要沟通前有准备、后有纪要
- 灵活选择沟通渠道（正式汇报/非正式交流/工作午餐）

**6. 反馈收集**：
- 每次沟通后记录干系人反馈和态度变化
- 月度更新干系人登记册

**7. 冲突化解**：
- 识别冲突来源（利益冲突/信息不对称/价值观差异）
- 面对面沟通优先、寻找共同目标
- 必要时升级到Sponsor层面协调

**8. 策略复盘**：
- 每月复盘干系人管理效果
- 根据态度变化调整策略
