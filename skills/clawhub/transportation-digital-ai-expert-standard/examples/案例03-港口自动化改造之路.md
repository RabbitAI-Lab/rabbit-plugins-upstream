# 案例03：港口自动化改造之路

## 案例概览

| 维度 | 详情 |
|------|------|
| 港口类型 | 内河集装箱港口（长江下游） |
| 年吞吐量 | 改造前180万TEU，改造后245万TEU |
| 岸线长度 | 2,800米 |
| 泊位数量 | 8个（其中集装箱泊位5个） |
| 自动化投资 | 6.5亿元（数字化+自动化设备） |
| 建设周期 | 2019-2023（四年分三期） |
| 运营主体 | 省港口集团下属合资公司 |

---

## 一、泥泞中的港口：改造前的困境

### 1.1 手工时代的码头

长口港（化名）位于长江下游，是一个有着30年历史的内河集装箱港口。2019年改造前，港口运营状况堪忧：

- **TOS系统老旧**：码头操作系统（TOS）建于2008年，基于C/S架构，数据采用SQL Server 2005存储，已无法扩容。系统经常卡顿，操作员手动Excel表格"补充记录"成为常态。

- **闸口如瓶颈**：进港闸口10条车道，车辆平均等待时间45分钟，高峰期超过2小时。所有信息录入靠人工目视识别和手写录入，一个集装箱进闸需要3-5分钟。

- **堆场管理混乱**：场桥司机凭纸质指令单作业，"找箱"效率低下。堆场利用率不足60%，翻箱率高达35%（行业平均15%），大量时间浪费在无效翻箱上。

- **水平运输低效**：80辆传统集卡在码头内穿梭，调度靠对讲机，空驶率超40%。司机三班倒，人力成本年增8%，招工越来越难。

### 1.2 竞争压力

同时段，同区域的新建自动化码头（太仓港四期、南通通海港）相继投产，自动化率达到70%以上。长口港如果不改造，未来3-5年将面临货源流失的风险。

### 1.3 决策时刻

2019年初，港口合资公司董事会经过多轮论证，最终批准了自动化改造项目。核心论证逻辑：
- 投资6.5亿元，按10年折旧计算，年均增加成本6500万元
- 预期效益：效率提升带来的收入增长约8000万元/年+成本节约约4000万元/年
- 投资回收期：约5.5年
- 不做改造则3-5年内市场份额将下降20-30%

## 二、分阶段实施方案

### 2.1 为什么选择渐进式改造

项目组研究了国际自动化码头建设的两条路径：
- **路径A（绿地建设）**：像洋山四期、青岛前湾那样全新建造，一步到位实现全自动化。效果好但投资大（通常40亿元+），且需要新建港址。
- **路径B（棕色地改造，本项目选择）**：在现有运营基础上分阶段自动化改造，投资适中，不影响现有业务。

选择路径B的核心原因是：停产新建不可行——现有客户合同仍在执行，一旦停工客户立即流失。

### 2.2 三期改造计划

**第一期（2019-2020年）：数字底座+智能闸口 —— 投资1.2亿元**

| 项目 | 内容 | 关键成果 |
|------|------|----------|
| TOS升级 | 更换为本地化TOS（哪吒科技N-TOS），微服务架构，云端部署 | 数据查询速度提升100倍，支持高并发 |
| 智能闸口 | 10条车道全面改造：AI车牌识别+集装箱号OCR+RFID+地磅自动称重，无人值守 | 单车道通行时间从3-5分钟降至15秒 |
| 数据中台 | 建立港口数据中台，统一设备、货物、船舶、车辆数据标准 | 打破12个系统的数据孤岛 |
| 5G专网 | 与运营商合作建设港口5G SA专网，覆盖全港区 | 为后续远程控制和自动驾驶提供通信基础 |

**第二期（2020-2022年）：智能堆场+数字孪生 —— 投资2.6亿元**

| 项目 | 内容 | 关键成果 |
|------|------|----------|
| 自动化场桥 | 3台自动化轨道吊（ARMG），堆场内无人化作业 | 堆场利用率从60%提升至85%，翻箱率降至12% |
| 数字堆场管理 | AI堆场计划：基于机器学习的箱位分配优化 | 场桥作业效率提升35% |
| 远程控制中心 | 场桥司机从现场操作转为中控室远程操控，1人控3台 | 操作人员减少60% |
| 港区数字孪生 | 全港区三维建模+实时IoT数据融合 | 管理可视化，异常事件秒级定位 |

**第三期（2022-2023年）：自动驾驶+智能岸桥 —— 投资2.7亿元**

| 项目 | 内容 | 关键成果 |
|------|------|----------|
| 自动驾驶集卡 | 10辆L4级自动驾驶集卡（西井科技Q-Truck） | 水平运输效率提升40%，24小时不间断运行 |
| 自动化岸桥 | 2台单小车自动化岸桥STS | 岸桥作业效率从28箱/小时提升至38箱/小时 |
| 智能调度 | AI全局调度引擎：船舶-岸桥-场桥-集卡协同优化 | 全港综合效率提升30% |
| 安全管理系统 | AI视频分析全覆盖：人员闯入、设备异常、火灾烟雾 | 安全事故下降80% |

## 三、关键决策与技术选型

### 3.1 为什么选择本地化TOS而不是Navis N4

**决策背景：** Navis N4是全球市场占有率最高的TOS系统，已在全球200+码头部署。但长口港最终选择了本地化N-TOS。核心考量：

| 维度 | Navis N4 | N-TOS（哪吒科技） | 决策权重 |
|------|----------|------------------|----------|
| 一次性软件许可费 | $280万（约2000万人民币） | 800万人民币 | 高 |
| 年维护费 | $56万/年 | 100万人民币/年 | 高 |
| 定制开发 | 需通过认证合作伙伴，周期长，费用高 | 源码级定制，快速响应 | 中 |
| 本地化适配 | 英文界面为主，需定制汉化 | 原生中文，符合国内海关/海事接口标准 | 高 |
| 生态兼容 | 全球主流设备通用 | 适配国内主流设备厂商 | 中 |
| 断供风险 | 全球贸易调整背景下，存在技术服务断供风险 | 自主技术可控，供应安全度高 | 高 |

**最终决策：** 选择N-TOS。除成本优势外，决定性因素是"自主技术可控"——在全球供应链调整背景下，港口作为关键基础设施，需要确保系统供应安全和技术连续性。后续运行验证选择正确：N-TOS系统稳定运行，单次升级最快3天完成（对比Navis N4通常需要1-2个月），定制功能开发费用仅为Navis的1/3。

### 3.2 自动驾驶集卡：纯电动还是混动

在自动驾驶集卡的选型上，团队在纯电动和混动方案之间权衡：

- **纯电动方案（西井科技Q-Truck）**：零排放、低噪音、维护简单。但初期购置成本高（单台约380万元），续航里程约150公里（满载）。
- **混动方案**：购置成本低约30%，无续航焦虑。但碳排放高，与港口绿色发展战略不符。

**最终选择：** 纯电动Q-Truck。原因——国家"双碳"行业规范要求港口逐年降低碳排放，且地方管理机构给予新能源车辆购置资金支持（单车资金支持80万元）。实际运营中，每辆Q-Truck年节省能耗费用约25万元（电费vs油费），维护费用下降60%。

## 四、劳工转型——最难的一道坎

### 4.1 自动化与就业的冲突

改造项目宣布后，港口工会强烈反对。核心担忧：
- 自动化场桥将替代60%的场桥司机岗位（60人→24人）
- 自动驾驶集卡将替代全部80名集卡司机
- 智能闸口将替代全部12名闸口操作员

### 4.2 三方协商与安置方案

港口公司、工会、地方管理机构三方经过长达3个月的协商，达成《长口港自动化改造员工安置协议》：

1. **不让一个人下岗**：承诺自动化改造对现有员工"不裁员、不降薪"
2. **技能转型培训**：
   - 场桥司机→远程操控员（60人转为24人，需培训考证）
   - 集卡司机→自动驾驶安全员/调度员/设备维护员（80人分流）
   - 闸口操作员→客服/异常处理员（12人转岗）
3. **自然减员+提前退休**：利用未来5年的自然退休（约35%）+提前退休激励（50岁以上员工可选择），实现人员平稳过渡
4. **薪资结构调整**：新岗位技能要求提高，薪资上浮10-20%
5. **工会监督权**：工会代表进入项目管理委员会，监督员工安置方案的执行

### 4.3 结果

截至2023年底，通过自然减员+转岗培训+提前退休的组合方式，港口总人数从改造前的620人优化至480人（减少22.6%），其中：
- 自动化相关技术岗位新增35个
- 无一人因自动化而失业
- 员工平均月收入从6800元提升至8500元（+25%）
- 工会满意度调查：82%员工支持改造、15%中立、3%反对

## 六、经验总结

1. **自动化改造不能"为自动化而自动化"**：每个设备的自动化决策都要回答一个问题——"它能提升多少综合效益？"本项目在"全自动岸桥"上审慎投入——仅改造了2台试用，因为自动岸桥对作业效率的提升（增加10箱/h）与投资（1.2亿元/台）之间的回报周期较长。

2. **劳工问题必须前置处理**：项目前期的工会协商耗费了3个月，但正是这3个月换来了后3年的顺利推进。自动化改造本质上是一场组织变革，技术只占30%，人心占70%。

3. **5G专网是自动化的"神经系统"**：5G SA专网的建设投入5000万元，为远程控制（端到端时延<20ms）和自动驾驶提供了关键通信保障。建议所有自动化港口优先部署5G专网。

4. **数字孪生的实际价值在于"协同"**：数字孪生不只是"好看的三维画面"，其核心价值在于打通了"计划-执行-监控-优化"的闭环。实际使用中，数字孪生每天发现3-5个计划调度与实际执行的偏差，这些偏差若按传统方式可能几天后才被发现。

5. **与设备厂商建立战略合作关系**：自动化码头的高度系统集成特性决定了"项目交付"不是终点，而是持续优化的起点。长口港与哪吒科技、西井科技建立了联合创新实验室，每年投入500万元用于持续优化和新场景开发。

6. **自动化之后，数据价值才刚刚开始**：港口的自动化设备每天都在产生海量数据（日均2TB），这些数据是最有价值的"副产品"。长口港已开始探索数据驱动的增值服务——如基于历史数据的船舶到港精准预测、货主物流全程可视化等。
