# 案例07：农村公路数字化管养

## 案例概览

| 维度 | 详情 |
|------|------|
| 区域类型 | 县级行政区域（西部山区） |
| 管养公路总里程 | 832公里（县道185km、乡道312km、村道335km） |
| 桥梁数量 | 186座（含危桥23座） |
| 地形特征 | 山区占75%，海拔落差1800米 |
| 总投资 | 800万元（三年） |
| 建设周期 | 2021-2023 |
| 行业规范背景 | 行业管理部门"四好农村路"高质量发展 |
| 运营主体 | 县交通运输局农村公路管理所 |

## 一、"晴天一身灰，雨天查看路"——传统管养的困境

### 1.1 大山里的公路守护者

云岭县（化名）地处西部山区，832公里农村公路散布于崇山峻岭之间。全县仅有一个农村公路管理所，正式撰写8人，却要管养800多公里的公路。

传统的管养方式令人心酸：
- **人工步行巡查**：每条乡道每月巡查一次，巡查员骑摩托车或步行，带上纸笔记录路面病害。但因为交通不便，实际的巡查覆盖率不足40%。
- **纸质台账手写**：所有巡查记录、维修记录、桥梁检测报告全部是纸质文档，堆满了两个文件柜。想查某条路的历史维修记录，需要翻找半小时以上。
- **"坏了再修"模式**：由于缺乏路况预警手段，绝大部分维修都是"等到路面烂了、老百姓投诉了"才被动响应。预防性养护几乎为零。
- **资金黑洞**：每年养护资金约1200万元，但由于缺乏精确的资产数据和科学的决策支持，资金分配靠"决策者拍脑袋"，真正用在刀刃上的可能不到一半。

### 1.2 一次改变一切的视察

2020年10月，行业管理部门"四好农村路"督导组到云岭县检查，发现：
- 路长制"有名无实"——路长名单上墙了，但没有考核、没有工具、没有数据支撑
- 农村公路技术状况（PQI）评定率为12%（全省平均为65%）
- 危桥改造进度严重滞后——23座四类/五类危桥，仅完成了5座改造

督导组的通报让县委书记坐不住了。第二天就召开常委会，决定用数字化手段"治本"，并把农村公路数字化管养列为2021年全县一号民生工程。

## 二、"螺蛳壳里做道场"——800万怎么花

### 2.1 预算约束下的务实方案

800万对于一个县的三年信息化投入不算小数目，但对于800多公里公路的数字化管养来说，每一分钱都要精打细算。

核心原则：**移动优先、云化部署、低成本传感器、充分利用现有资源。**

不搞大屏、不搞指挥中心装修、不搞高端硬件——一切围绕"让一线管养人员用得上、用得起"。

### 2.2 投入分解

| 农村公路GIS基础数据库 | 80 | 10% | 基于高德/天地图API二次开发，非自建引擎 |
| 路面状况智能采集 | 150 | 18.7% | 手机端AI采集APP+2架无人机+3套车载采集终端 |

## 三、核心系统建设

### 3.1 路长制APP——"让路长真正长起来"

路长制推行多年，在很多地方沦为"墙上制度"。云岭县的路长制APP试图用技术手段解决三个核心问题：

**问题1：路长巡了没有？巡了什么？**

- APP自动记录巡查轨迹（GPS打点），涵盖起止时间、里程、路径
- 路长在APP上打卡关键节点（桥梁、高边坡、事故多发路段）——不是形式主义打卡，而是确保这些关键节点确实被巡查到
- 巡查中发现的问题直接在APP上拍照+定位+描述+分级上报

**问题2：上报的问题谁处理？处理了没有？**

- 建立"路长发现→乡镇受理→交运局/养护公司处置→路长核验→闭环"的工单流程
- 每个工单有明确的时限要求（如路面坑槽48小时内修复）
- 超时自动升级（24小时未处理升级至分管副管理者，48小时升级至管理者）
- 处置结果路长在线核验，不通过则退回重做

**问题3：如何激励路长认真履职？**

- 每月自动生成路长履职报告（巡查里程、问题发现数、问题处置率）
- 排名公示（县路长办每月发布全县路长排名TOP10和末位3名）
- 与绩效考核和年度评优挂钩

**APP上线后的变化：**
- 路长月均巡查里程从不到10公里提升至45公里
- 巡查问题发现率提升300%
- 问题处置时效从平均7天缩短至2.5天
- 路长制从"有名无实"变为"有名有实有数据"

### 3.2 路面状况智能采集——"一部手机搞定路况检测"

传统路况检测需要专业检测车（单价300万+），对于一个年养护资金仅1200万的县级单位来说不现实。

云岭县采用了创新的低成本方案：

| 方案 | 工具 | 精度 | 成本 | 适用场景 |
|------|------|------|------|----------|
| 智能手机AI采集 | 养护人员手机安装专用APP，车辆行驶中手机拍摄路面，AI分析裂缝/坑槽/车辙 | 裂缝宽度精度±2mm | 免费（用现有手机） | 全覆盖日常采集 |
| 无人机桥梁巡检 | 大疆M300 RTK+高清相机，自动航线飞行，AI识别桥面病害、桥下结构异常 | 毫米级（可见裂缝） | 2架共约30万元 | 桥梁和不便到达路段 |
| 车载轻量检测 | 用于路政巡逻车的轻量级车载传感器（加速度计+相机），每月覆盖县道+重点乡道 | 接近专业设备80%精度 | 3套共约25万元 | 县道月度监测 |

**关键数据：**
- 路面PCI采集覆盖率：从12%提升至100%（每季度全覆盖一次）
- 病害发现量：从年均约500处提升至2300处
- 采集成本：从约200元/公里（专业检测车）下降至约8元/公里（手机方案）

### 3.3 公众上报小程序——"全县人民都是养护监督员"

微信小程序"云岭路况通"：
- 市民发现路面坑槽、井盖缺失、路面积水、塌方等道路问题
- 拍照+定位+简单描述（30秒即可完成上报）
- 系统自动分派至对应养护单位
- 处置完成后，上报人收到微信服务通告，可查看处置前后对比照片
- 建立积分激励运行框架——每月上报质量最高的市民获得"最美护路市民"称号

**运营数据：**
- 注册用户：1.2万人（占全县常住人口8%）
- 月均有效上报：320条
- 上报准确率：78%（经人工审核）
- 公众参与大幅降低了巡查盲区——以前养护人员一年不一定去一次偏远村道，现在村民自己就能上报

## 四、养护决策的"AI大脑"

### 4.1 从"凭经验分钱"到"数据驱动决策"

传统模式下，养护资金分配大致是"县道多分、乡道少分、村道不分"。实际上，许多乡道的交通量和破损程度远高于某些县道。

AI养护决策支持系统综合考虑以下因素：
1. 路况指标（PCI、RQI）
2. 交通量（结合卡口数据和移动信令估算）
3. 道路等级和功能（连通乡镇/通往学校/通往产业园区等）
4. 近年养护投入历史（避免某些路段长期"吃偏饭"）
5. 养护成本估算模型
6. 预算约束（1200万元/年）

系统输出：年度养护计划（推荐优先养护路段列表、推荐养护方案、预估费用），供决策者审批。

**效果验证：**
- 在同等养护预算（1200万）下，AI方案的路网PQI改善效果比人工方案高出28%
- 实现了"用相同的钱，养好更多的路"
- 2023年全县农村公路PQI优良路率从58%提升至73%（还超过了全省平均的71%）

## 六、核心经验

1. **"低成本不等于低质量"**：智能手机AI采集方案的总投入不到专业检测车的1/10，但通过每个人都使用、高频次采集，实际获得的数据覆盖面远超专业设备。农村公路数字化要摒弃"设备崇拜"，优先使用现有资源和轻量方案。

2. **路长制需要技术工具支撑**：没有APP和数据平台的路长制，必然沦为"墙上制度"。APP不仅是工具，更是考核和反馈的闭环载体。建议全国农村公路路长制统一配备标准化APP（可以参考本案例模式）。

3. **公众参与是最便宜的"传感器"**：1.2万注册用户相当于免费增加了1.2万个道路问题"感知节点"，覆盖了养护人员永远到不了的角落。投入40万元开发小程序，换来了相当于数十名巡查员的工作量。

4. **AI养护决策需要本土化数据积累**：养护决策模型的准确度取决于本地数据积累。项目第一年的模型准确率仅65%，到第三年（积累了3年的历史数据后）提升至85%。建议新项目在第一年采用"AI推荐+人工调整"模式，逐步提高AI决策权重。

5. **培训比技术更重要**：800万元中花了50万元在培训上，这笔钱花得最值。在18个乡镇进行了5轮培训，覆盖了120名路长和管养人员。确保"系统建好了，有人会用、愿意用、用得好"。

6. **与省级平台对接**：县级系统在设计时就考虑了与省级"四好农村路"管理平台的对接，实现了数据自动上报，避免了重复录入。这为未来区域级（省/市）的农村公路养护大数据分析打下了基础。
