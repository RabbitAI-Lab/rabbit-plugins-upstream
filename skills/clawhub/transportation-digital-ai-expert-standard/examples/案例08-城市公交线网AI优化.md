# 案例08：城市公交线网AI优化

## 案例概览

| 维度 | 详情 |
|------|------|
| 城市类型 | 地级市（中部地区，城区人口150万） |
| 公交运营 | 市公交集团（国有独资） |
| 公交车辆 | 1,180辆（新能源占比65%） |
| 公交线路 | 80条（优化前）→72条（优化后）+ 3个DRT区域 |
| 日客运量 | 28万人次（优化前，年均下降5%） |
| 年营收 | 2.8亿元（票款收入1.1亿+公共部门资金支持1.7亿） |
| 总投资 | 4,500万元（AI线网优化+数字化升级） |
| 建设周期 | 2021-2022 |
| 运营主体 | 市公交集团 |

---

## 一、乘客去哪了——公交的"慢性死亡"

### 1.1 十年曲线向下

新阳市公交集团有着65年历史，曾经是全市人民出行的"生命线"。但进入2010年代后，形势急转直下：

| 年份 | 日客运量（万人次） | 同比变化 | 累计变化（vs 2012） |
|------|-------------------|----------|---------------------|
| 2012 | 52 | — | —（峰值） |
| 2015 | 44 | -5.1% | -15.4% |
| 2018 | 36 | -6.2% | -30.8% |
| 2020 | 28 | -11.1%（疫情冲击） | -46.2% |

**10年间，公交客运量萎缩了近一半。** 与此同时，城市机动车保有量从18万辆增长到55万辆，共享单车投放超3万辆，网约车日均订单15万单。

### 1.2 致命的结构性问题

公交集团内部研究发现，线路结构存在深层问题：

1. **线网老化**：80条线路中60%以上是10年前规划的。当时城市建成区面积仅现在的40%，许多线路的走向早已不适应城市发展。例如，3条线路都经过已搬迁的旧客运站，而新兴的CBD和大型居住区公交覆盖严重不足。

2. **资源错配**：20%的"热线"（高客流线路）承担了55%的客流，但车辆资源配置仅占35%；大量"冷线"上座率不足30%，但"撤线"面临居民反对和社会监督提案压力。

3. **与轨道的竞合失败**：2018年地铁1号线开通后，与之平行的公交8号线客流量一年内暴跌60%，但公交集团未能及时调整该线路线路定位（从"干线"变为"接驳线"）。

4. **资金支持依赖症**：资金方资金支持从2012年的6,000万元增长到2020年的1.7亿元，占营收比例从30%升至61%。资金方归口部门的"耐心"正在耗尽。

### 1.3 转机

2021年初，新到任的公交集团董事长提出了"刀刃向内、用数据说话"的改革方针，决定引入AI技术对公交线网进行全面优化。这在全市公交历史上是第一次——以前的线网调整都是"老专家凭经验画图"。

## 二、AI线网优化方法论

### 2.1 数据基础：多源融合的出行OD

AI优化的前提是精确的乘客出行OD（Origin-Destination，起讫点）。传统方式通过"跟车调查"获取，耗时长、精度低、成本高。本项目采用多源数据融合方法：

| 数据源 | 覆盖人群 | 提供信息 | 局限性 |
|--------|---------|---------|--------|
| 公交IC卡数据 | 公交乘客（约60%刷卡率） | 上车点+上车时间 | 只有上车站点，缺乏下车站点和出行目的 |
| 公交乘车码数据 | 公交乘客（约30%扫码率） | 上下车站点+出行链 | 仅覆盖扫码乘客 |
| 移动信令数据 | 全市居民（约70%覆盖率） | 全方式出行OD+出行目的 | 精度约100-300m，不能区分交通方式 |
| 互联网LBS数据 | 全市居民（约40%覆盖率） | 高精度OD+出行目的+画像 | 样本偏差（偏年轻用户） |
| 共享单车数据 | 骑行人群 | 接驳公交的骑行起讫点 | 仅覆盖共享单车用户 |

**融合算法：** 采用多源数据融合的出行链重构模型（基于隐马尔可夫模型），将IC卡刷卡记录、移动信令轨迹、POI访问序列进行时空匹配，还原出完整的出行链。最终获得了约12万条/天的公交出行OD数据，精度达到站点级。

### 2.2 AI线网优化模型

核心算法框架：

**Step 1：需求分析**
- 基于OD数据识别高OD走廊（400+人次/小时）
- 识别服务盲区（高需求但无覆盖的区域）

**Step 2：线网生成**
- 线网优化采用多目标遗传算法（NSGA-II），优化目标包括：
  - 最大化OD覆盖率（线路覆盖的出行OD对数量）
  - 最小化乘客总出行时间（包括步行+等车+乘车+换乘）
  - 最小化运营成本（车公里）
  - 最大化运营收入（票款收入）
- 约束条件：线路长度（8-25km）、非直线系数（<1.6）、发车间隔（3-15分钟）、车队规模（≤1,180辆）

**Step 3：方案评价**
- 微观交通仿真（基于MATSim进行agent-based仿真）
- 模拟100万+agent的出行行为（包括路线选择、换乘决策等）
- 输出：各方案下的客流、运营成本、乘客体验指标

**Step 4：方案比选**
- 生成3-5个候选方案
- 每个方案包含：线路调整明细、客流预测、成本变化、资金支持需求变化
- 供集团和归口部门决策

### 2.3 优化方案

经过多轮迭代，最终确定的方案如下：

| 调整类型 | 数量 | 典型示例 |
|----------|------|---------|
| 撤销线路 | 8条 | 与地铁高度重叠且客流低于100人次/日 |
| 改线调整 | 15条 | 绕行新居民区、延伸至工业园区、减站提速 |
| 新增线路 | 5条 | 覆盖公交服务盲区的新兴社区、产业园区 |
| 间隔优化 | 28条 | 热线加密（高峰期5分钟→3分钟）、冷线拉大班次 |
| DRT需求响应 | 3个区域 | 低密度郊区的灵活公交服务 |

**3个DRT区域设置：**
- 高新区DRT区（面积18km²，需求密度低但分散）
- 大学城DRT区（面积12km²，潮汐需求明显）
- 城乡结合部DRT区（面积25km²，传统固定线路成本过高）

DRT运营：乘客通过APP预约→AI拼车优化→动态生成路线→中小巴（12-19座）响应式服务。票价高于常规公交（3-5元 vs 1-2元），但低于网约车。

## 三、实施：最难的不是算法，是人心

### 3.1 线路撤销引发的风波

方案公布后，被撤销的8条线路沿线居民反应激烈：

- 朝阳小区线路取消后，居民在市公共部门门口聚集
- 一位退休大爷给市民服务热线写了3000字长信
- 市人大代表提交了"关于保留33路公交的紧急建议"

### 3.2 应对策略

公交集团采取了系统化的沟通策略：

1. **数据公开**：在每条拟撤销/调整线路的公交站台张贴二维码，居民扫码即可查看调整原因、客流数据、替代出行方案

2. **听证会和社区座谈**：为每条撤销线路举办1场社区座谈会，由集团副总经理带队，面对面解答居民疑问

3. **过渡方案**：撤销的8条线路并非"一刀切"停止，而是先降频（30分钟一班→60分钟一班），观察3个月后客流若无回升再正式撤销

4. **替代方案到位**：确保每条撤销线路沿线居民有可替代的出行方案（其他公交线路+共享单车接驳+DRT补充）

5. **弱势群体保障**：对撤销线路沿线的老年公寓、学校等，安排社区巴士（19座）维持基础服务

### 3.3 司机分流

线网优化导致约120名司机岗位受到影响。集团采取了"转岗不下岗"策略：
- 50人转入新增线路和DRT运营
- 30人转入加密线路（增加高峰配车）
- 20人转入定制公交和包车业务
- 20人自愿提前退休或协商离职（给予N+3补偿）

工会全程参与方案制定，最终实现了"零投诉、零仲裁"的平稳过渡。

## 四、数字化配套升级

线网优化不仅是"画线路"，还需要数字化手段支撑落地：

### 4.1 公交实时APP

投资600万元建设"新阳公交"APP：
- 实时公交位置查询（GPS+到站时间预测，精度±30秒）
- 线路规划（多模式：公交+共享单车+步行）
- 上车提醒（到站前3分钟通告）
- 扫码乘车+实时客流查询（车厢拥挤度，红/黄/绿三色显示）
- DRT预约
- 失物招领、意见反馈

**上线效果：** APP注册用户28万（占日客运量的100%），月活跃用户15万，用户评分4.4/5。

### 4.2 公交信号优先

在10条干线公交走廊的82个路口部署公交信号优先（TSP）：
- 公交到达路口前200米，通过C-V2X/4G向信号机发送优先请求
- 策略：绿灯延长（最大+10秒）或红灯早断（最大-8秒）
- 效果：10条干线公交平均行程时间缩短15%，准点率从72%提升至88%

## 六、经验总结

1. **OD数据是线网优化的根基**：没有精确的OD数据，AI模型就是"垃圾进、垃圾出"。本项目在数据融合上投入了8个月时间和约500万元，但这是整个项目最值得的投入。建议所有公交线网优化项目确保至少收集1年以上的完整数据周期（覆盖春夏秋冬、工作日/周末/节假日）。

2. **线网优化不能是纯技术活**：AI可以算出数学上的最优解，但最优解有时意味着"撤销一位80岁老太太每天买菜唯一能坐的那趟公交"。最终的线网方案需要在AI最优方案基础上，加入"人性化调整"——保留少量社会效益大但经济效益低的"民生线路"。

3. **DRT是破解"最后一公里"的利器**：3个DRT区域日均3,200单，单均成本约6.5元（票价3-5元，公共部门资金支持约2-3元/单），虽然资金支持率仍然较高，但远低于同等区域的传统固定线路运营成本（传统线路在同等客流密度下，单均成本超过12元）。

4. **撤线不能"突袭"，需要"软着陆"**：给予居民足够的知情权、参与权和过渡时间是减少阻力的关键。本项目从方案公示到正式实施花了5个月，其中3个月是过渡期——这段时间看起来"浪费"了，实际上换来了长期的平稳。

5. **与地铁的竞合应及早规划**：公交不能"对抗"地铁，而应主动成为地铁的"毛细血管"——用公交把乘客从社区送到地铁站，再用地铁完成跨区出行。本项目在运营一年后，与地铁换乘的公交客流占比从12%提升至28%，这28%的客流实际上是地铁"带"来的新增公交客流。

6. **公交行业的出路在数字化**：本案例证明了——公交客运量是可以"逆转"的，关键在于用数据理解乘客需求的变化，用技术提升服务的精准度。新阳市公交的AI线网优化是全国公交行业的一个积极信号：只要敢于自我革命，公交的"第二春"是完全可能的。
