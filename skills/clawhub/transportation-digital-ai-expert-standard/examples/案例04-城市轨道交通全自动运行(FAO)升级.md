# 案例04：城市轨道交通全自动运行(FAO)升级

## 案例概览

| 维度 | 详情 |
|------|------|
| 线路 | 地铁3号线（南北骨干线） |
| 线路参数 | 全长35.2km，设站28座（地下站22座，高架站6座） |
| 原系统 | CBTC GoA2（司机在驾驶室监控自动驾驶） |
| 目标系统 | FAO GoA4（全自动无人驾驶） |
| 总投资 | 12亿元（vs新建同等线路约80亿元） |
| 改造周期 | 2020-2023（三年，不停运改造） |
| 运营主体 | 市轨道交通集团 |

---

## 一、为什么要升级

### 1.1 老化的骨干线

地铁3号线是省会城市星城的第一条南北骨干线，2005年开通运营，至2020年已运行15年。作为日均客流量最大的线路（日均85万人次），3号线承载了全市约30%的地铁客流。

然而，15年的运行积累了大量问题：

1. **信号系统老化**：原西门子CBTC系统已停产，备件采购越来越困难，部分板卡需要从二手市场淘货。2019年因信号故障导致5分钟以上延误达23次，引起市民不满。

2. **人力成本高企**：155名司机（含替补）三班倒，年均人力成本约2800万元且以每年6%增长。司机岗位对年轻人吸引力下降，招聘难度加大。

3. **运能瓶颈**：最小行车间隔150秒，高峰时段车厢拥挤度达130%。受制于信号系统能力，无法进一步缩短间隔。

4. **乘客期望提升**：同城新建的地铁5号线（2020年开通）已是GoA4全自动运行，整洁、准时、现代化的形象与3号线形成鲜明反差，乘客在社交媒体上频繁表达不满。

### 1.2 升级还是新建

轨道交通集团内部一度存在"拆了重建"的声音。经过8个月的可行性研究，结论明确：

| 对比维度 | 改造升级（GoA2→GoA4） | 新建复线 |
|----------|----------------------|----------|
| 投资 | 12亿元 | 约80亿元（新建35km地铁） |
| 工期 | 3年（不影响运营） | 5-6年 |
| 对运营影响 | 分阶段夜间施工，白天正常运营 | 无影响（新建线路） |
| 技术风险 | 中等（国内有成熟案例） | 低 |
| 行业规范审批 | 市级即可审批 | 需国家投资归口部门审批 |

**结论：改造升级是唯一的理性选择。** 12亿改造 vs 80亿新建，效益差距悬殊。

---

## 二、技术方案

### 2.1 从GoA2到GoA4的路径

项目组制定了"GoA2→GoA3→GoA4"三步过渡策略：

| 阶段 | 时间 | 目标 | 关键内容 |
|------|------|------|----------|
| GoA2→GoA3 | 2020-2021 | 司机从驾驶室移至客室，不操控但需在车上值守 | DTO（有人值守的自动驾驶） |
| GoA3→GoA4 | 2021-2022 | 司机完全下车，远程监控 | 列车自动唤醒/休眠、自动出入库 |
| GoA4全功能 | 2022-2023 | 全场景无人干预 | 障碍物检测、车门/站台门对位故障自愈 |

### 2.2 核心改造内容

**（一）信号系统升级（投资5.5亿元）**

- 新信号系统：交控科技FAO信号系统（本地化自主化CBTC升级版）
- 新增设备：联锁设备更新、新增区域控制器、DSU（数据存储单元）升级
- 新旧系统切换：采用"双系统并行"方案——新旧两套车载设备同时安装，白天使用旧系统运营，夜间切换测试新系统。准备充分后，利用一个周末（56小时）完成全线一次性切换。
- 切换窗口：2022年春节假期（5天，客流量低）+前后各1个周末，共计9天窗口，实际切换仅用56小时。

**（二）车辆改造（投资2.8亿元）**

- 42列车（252节车厢）逐列返回车辆厂进行FAO适配改造
- 改造内容：驾驶台拆除→乘客站立区、新增障碍物检测系统、新增紧急呼叫装置（乘客-控制中心直连）、空调/照明/广播系统升级
- 改造节奏：每2周一列车，同步配备备用列车维持运力。42列车全部改造耗时21个月。

**（三）站台门与间隙防护（投资1.5亿元）**

- 全线28座车站站台门系统升级，新增间隙探测（激光+红外双模）
- 站台门与信号系统联动，间隙异物检测到即阻止发车
- 新增站台CCTV全覆盖，控制中心可实时查看任意站台门状态

**（四）车辆基地自动化（投资6000万元）**

- 全自动停车场改造：自动唤醒/休眠、自动洗车、自动列检
- 新增停车列检库自动化设备：受电弓检测、轮对检测、车底巡检机器人
- SPI（停车库防护区）设置

**（五）控制中心升级（投资8000万元）**

- 新增车辆调度台、乘客调度台、综合维修调度台
- 车载CCTV实时回传（每列车8路视频实时回传至控制中心）
- 乘客紧急对讲系统（每节车厢2个紧急对讲机，直连控制中心乘客调度）

**（六）智能运维系统（投资7000万元）**

- 车辆状态在线监测（走行部、受电弓、牵引系统等关键部件）
- 信号设备状态在线监测
- AI故障预测（基于历史故障数据训练，提前预警）
- 运维知识图谱（故障-原因-处置方案知识库）

### 2.3 安全论证——全自动运行的"通行证"

全自动运行的升级必须通过严格的安全论证。项目组完成了以下工作：

1. **HAZOP分析**：识别了47个危险场景，其中高风险场景12个，逐项制定风险控制措施，确保残余风险降至可接受水平（ALARP原则）。

2. **SIL评估**：对安全相关功能进行SIL等级分配，关键功能达到SIL4（最高安全完整性等级）。

3. **独立安全评估（ISA）**：委托TUV南德作为独立安全评估方，全程跟踪设计、制造、安装、测试各阶段，出具安全证书。

4. **试运营验证**：新系统上线前进行了累计10万公里、2000小时的无人值守试运营（夜间空载），零安全事故。

5. **多场景测试**：模拟了28种故障场景的自动处置能力验证，包括：
   - 列车火灾（自动进站、自动开门、自动广播疏散）
   - 信号故障降级（自动转入限制人工驾驶模式）
   - 障碍物检测（轨道上放置模拟障碍物，列车自动紧急制动）
   - 乘客紧急对讲（模拟乘客突发疾病，控制中心远程处置）

## 三、保障不停运——"在飞行的飞机上换引擎"

### 3.1 运营-施工协同策略

在不停止3号线运营的前提下进行改造，是整个项目最大的技术和管理挑战。项目团队采用的策略是"夜间窗口施工+备用列车+应急预案"三重保障：

1. **每日施工窗口**：凌晨00:00-04:30（4.5小时），但实际有效施工时间仅约3小时（扣除停电/送电、请点/销点时间）
2. **周末延长窗口**：每周六晚00:00-周日早06:00（6小时）
3. **节假日大窗口**：利用春节、国庆等长假，申请3-5天连续施工窗口

### 3.2 三次险情

1. **2021年3月**：信号设备安装中，一根线缆误接导致旧系统出现通信丢包。幸亏新系统尚未接入，影响仅持续15分钟。此后，施工区域与运营区域物理隔离标准升级。

2. **2021年9月**：台风导致一个周末施工窗口损失，项目进度延后3天。此后，在计划中增加15%的天气缓冲时间。

3. **2022年1月切换前夜**：新系统联调发现3处连锁表中数据配置错误——如果带着这些错误切换将导致运营事故。团队连续48小时排查修复，切换推迟至春节后进行。此后，强化了数据配置的自动化校验运行框架。

## 四、公众沟通策略

### 4.1 乘客的恐惧

改造过程中，社交媒体上出现了以下声音：
- "没有司机的列车，你敢坐吗？"（微博阅读量超500万）
- "万一出故障怎么办？电脑能比人更可靠吗？"

### 4.2 沟通策略

轨道交通集团制定了系统的公众沟通策略：

1. **透明展示**：在地铁站设置"未来列车"体验区，用VR让乘客提前体验全自动列车
2. **数据说话**：发布《全自动运行安全白皮书》——全球GoA4线路已累计安全运行超过5亿公里，事故率远低于人工驾驶
3. **意见领袖体验**：邀请20位本地微博/抖音KOL作为"首批体验官"，试乘试运营列车并发布体验报告
4. **应急透明度**：公开披露全部安全测试场景和结果，让公众了解"无人驾驶"背后的"有人守护"（控制中心24小时专业团队监控）
5. **逐步建立信任**：GoA3阶段（司机在客室值守）持续运行6个月，让乘客逐步适应"司机不在驾驶室"到"没有司机"的过程

### 4.3 结果

在2023年1月全功能GoA4运行后：
- 乘客满意度：从改造前的72分提升至89分
- "无人驾驶列车安全性"认知度正面率：从改造前的38%提升至82%
- 3号线客流同比增长8%（超过网络平均增速5%）

## 六、经验启示

1. **改造比新建性价比高得多**：12亿 vs 80亿，不到1/6的投资实现了同等效果。对已有线路的老旧化改造应成为城市轨道交通更新升级的优先选项。

2. **安全论证不能走形式**：HAZOP分析、SIL评估、独立安全评估不是"纸面工程"，每一项都应认真对待。本项目在安全论证中发现的47个危险场景，有3个是设计单位最初完全未考虑到的，如果不做安全论证，上线后可能是重大隐患。

3. **"双系统并行"是改造的屠龙刀**：新旧两套系统同时运行6个多月，不仅保障了运营安全，也为新系统提供了充分的测试验证时间。代价是增加了约15%的设备投入——但这笔钱值得花。

4. **公众沟通与工程技术同等重要**：全自动运行不仅是技术问题，更是社会心理问题。本项目的公众沟通投入约200万元（体验区建设+KOL邀请等），换来了顺利的社会接受过程，价值远超200万元。

5. **智能运维是FAO的"标配"**：全自动运行取消了司机这个最后的"故障兜底人"，因此智能运维必须具备故障自诊断、自愈、快速响应能力。本项目的智能运维系统在上线第一年就成功预警了12次潜在故障，避免了至少3次可能影响运营的设备失效。

6. **人才结构需要重塑**：从"司机操作型"到"远程监控+智能运维型"，对人员技能要求完全不同。集团提前一年启动司机转型培训（电气/自动化/数据分析技能），确保平稳过渡。
