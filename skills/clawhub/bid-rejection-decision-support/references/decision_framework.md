# 决策框架详解（否决/废标决策支持·专家版）

本文件是 SKILL 第五章的详细展开。执行决策时严格按"五步"推进，并用"判定矩阵"对号入座。

---

## 0. 结构化输入（先补全，再决策）

向用户索取或确认以下字段；缺失关键项则追问，不做假设性判断：

| 字段 | 说明 | 缺失处理 |
|---|---|---|
| 项目信息 | 名称、编号、体系（招/政采/国企）、招标方式 | 必须确认体系，否则无法定口径 |
| 投标主体 | 投标人名称 | 必填 |
| 争议响应项 | 投标人具体怎么响应（原文要点/截图） | 必填，无则无法认定事实 |
| 对应条款 | 招标文件章节·条款号·页码·关键词 | 必填，无条款则无法锚定依据 |
| 争议性质 | 资格性/符合性/实质性响应/报价/串标/低于成本 | 归类后进入矩阵 |
| 已知证据 | 已提交的澄清/补正材料、第三方证明 | 可选，影响可澄清性判定 |

## 1. 五步决策流程

### 第一步：体系与法律适用判定
- 招标投标法体系（依法必须招标工程）／政府采购法体系／国企非招标采购。
- 体系不同 → 术语与红线不同（招："否决投标"；政采："无效投标"；招的"废标"仅指否决全部投标）。
- **信息不足立即追问**，不假设。

### 第二步：条款性质归类（用矩阵对号入座）
将该条款归入三类之一：**应当否决** / **可澄清补正** / **裁量空间**。

### 第三步：事实匹配
- 投标人响应是否落入该条款的否决情形？
- 区分 **重大偏差** vs **细微偏差**：
  - 重大偏差：对招标文件实质内容（工期、质量、技术规格、价款等）的偏离/保留，导致实质上影响合同履行、限制评委会裁量权、或不公正影响其他投标人。
  - 细微偏差：不影响实质响应、不影响公平竞争。

### 第四步：可澄清性判定（关键分叉）
依据《招标投标法实施条例》第五十二条：
- **可澄清、不得否**：含义不明确的内容、明显文字错误、明显计算错误。澄清不得超出投标文件范围或改变实质性内容。
- **不得澄清、不满足即否**：实质性内容（投标报价、工期、质量、主要技术参数等）不得通过澄清补正。
- **形式瑕疵**（签字盖章遗漏、装订、份数、电子签章格式）：通常按前附表要求补正或认定；若前附表明定为否决情形则从其规定，谨慎否。

### 第五步：结论 + 依据 + 措辞 + 投诉复核研判
输出决策意见书（SKILL 第七节模板），并调用 KB-E 研判同类被诉情形走向。

## 2. 应当否决 vs 可澄清补正 判定矩阵（核心）

> 用法：按"争议性质"行定位，再用"处理"列定类，最后核"依据/边界"。

| 争议性质 | 典型表现 | 处理 | 依据与边界 |
|---|---|---|---|
| **资格性不符** | 资质类别/等级/有效期不满足；财务/业绩/信誉硬门槛未达；联合体组成不符 | **应当否决（不可澄清）** | 资格后不得借澄清补充；《实施条例》第51条；资格项非"可补正" |
| **法定禁止投标** | 串标、行贿、骗取中标、重大违法记录未满年限、列入失信/黑名单、关联投标（同一负责人/控股） | **应当否决 + 上报** | 《实施条例》第34、42条；指明后果并建议向监督部门反映 |
| **签署盖章缺失** | 未加盖单位公章、无法定效力签署、联合体无共同投标协议 | **应当否决**（若前附表明定为否决情形） | 《实施条例》第51条；非"含义不明确/计算错误"类 |
| **实质性响应偏差** | 技术★指标负偏离、工期超期、质量不达标、主要参数不满足 | **应当否决（不可澄清）** | 实质性内容不得澄清；《实施条例》第51条"未对实质性要求作出响应" |
| **报价超限价** | 投标报价高于招标文件设定的最高限价 | **应当否决** | 超限价即废标/无效，显式检查 |
| **多项负偏离累积** | 非★指标多项负偏离，按评标办法可认定为不响应 | **应当否决**（依办法判定） | 须引用评标办法具体条款，非必然 |
| **串通/弄虚作假痕迹** | 异常一致报价、相同错误、混装证书、虚假业绩 | **应当否决 + 上报** | 《实施条例》第40、42条；建议向监督部门反映 |
| **低于成本警戒线** | 报价低于成本警戒线，先启动成本评审 | **可澄清补正（先澄清）** | 经书面说明+证明仍不成立才否；非直接否 |
| **含义不明确** | 表述歧义、同类问题表述不一致 | **可澄清补正（不得否）** | 《实施条例》第52条；澄清不超范围不改实质 |
| **明显文字/计算错误** | 大写小写不一致、分项汇总误差 | **可澄清补正（修正）** | 《实施条例》第52条；按招标文件修正约定 |
| **形式瑕疵（非明定否）** | 装订、份数、电子签章格式轻微不符，前附表未明定否决 | **可补正 / 谨慎否** | 优先补正；前附表明定否则从之 |
| **细微偏差** | 不影响实质响应与公平竞争的轻微偏离 | **可补正（不否）** | 不影响中标结果，要求补正即可 |

**关键分叉判别口诀**：
- 实质内容（报价/工期/质量/主要技术）出问题 → **否**，不可澄清。
- 含义/文字/计算出问题 → **澄清**，不可否。
- 资格硬门槛出问题 → **否**，资格后不可补。
- 形式小瑕疵 → 看前附表是否明定否；未明定则**补正优先**。

## 3. 法条依据层级映射（招投标法体系）

| 层级 | 依据 | 适用 |
|---|---|---|
| 法律 | 《招标投标法》 | 基本制度、否决原则 |
| 行政法规 | 《招标投标法实施条例》 | 第34/40/42/51/52条为核心否决与澄清条款 |
| 部门规章 | 《评标委员会和评标方法暂行规定》（七部委12号） | 重大偏差/细微偏差定义、低于成本处理 |
| 招标文件 | 投标人须知前附表、评标办法 | 具体★条款、修正约定、否决清单（效力通常最高） |

**效力压制**：招标文件具体条款（尤以前附表）> 部门规章 > 行政法规 > 法律原则；但条款本身不得违反上位法，冲突时提示向代理书面澄清。

## 4. 置信与留痕
- 推断类结论标注置信度；法条引用保留来源角标（库·条目·体系）。
- 跨体系引用须显式声明，严禁把工程判例当政采法条。
- 检索无命中时维持专业判断、不编造，备注"未锚定"。
