# 否决/废标决策支持·专家版

> 评标委员会（专家）侧的否决/废标决策引擎。输入「具体投标人响应 + 招标文件对应条款」，输出：① 是否构成否决及法条/条款依据；② 应当否决与可澄清补正的区分判定；③ 可直接写入评标报告的规范化否决理由措辞。

## 它能做什么

- **评得准**：基于判定矩阵对号入座，区分「应当否决 / 可澄清补正 / 裁量空间」。
- **否得有依据**：每条结论绑定招标文件条款 + 法定依据，引号引用并标注来源库。
- **经得起投诉复核**：调用异议投诉知识库研判同类被诉情形的裁决走向与抗推翻要点。
- **不踩纪律红线**：客观中立、全程留痕溯源、回避人情与领导干预。

## 适用边界

- 体系：以《招标投标法》体系（依法必须招标工程）为主；政府采购、国企采购为可扩展体系（挂载对应库并切换术语）。
- 角色：评标委员会决策支持，**不替代**评委会法定职权。
- 不越界：不做报价策略、不帮投标人规避、不代写异议/投诉文书。
