## Description: <br>
Free developer guide for building paid skills on ClawHub, covering the standard three-phase payment flow, SkillSpector compliance requirements, and common pitfalls while making clear it does not handle payments. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers building paid ClawHub skills use this reference guide to understand payment-flow architecture, SkillSpector compliance expectations, and common implementation pitfalls. It is guidance only and does not process orders, payments, or credentials. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Readers may mistake the guide for an official payment implementation. <br>
Mitigation: Treat it as reference material only and use the official ClawTip or ClawTip sandbox wallet skills for payment handling. <br>
Risk: Payment code built from the guidance could introduce security or compliance issues. <br>
Mitigation: Review and scan any separately built payment code before deployment. <br>
