# bolder — amplify within identity

The surface is timid, not wrong. Bolder makes the same brand **more sure of itself** — never louder than its own system allows. Scope is sovereign: the request names the surface; that's the blast radius.

## 1. Diagnose why it's flat (before touching anything)

Flatness is almost never "needs bigger type". It's usually one of:
- **The section opted out.** A flat section quietly stopped using the system's strongest moves (its type scale tops out two steps early, its color never commits, its layout mirrors the template). Find the opt-out and re-enroll it.
- **Everything is emphasized.** When nothing is distinct, nothing is bold. Identify the ONE thing this surface must say and give it the whole stage.
- **Safety stacking.** Centered + gray + medium-weight + generous padding = a section that apologizes. One strong axis (layout OR type OR color) beats mild boosts on all three.
- **The identity has unused strength** in DESIGN.md / code that this surface simply didn't spend (a display face used only on the homepage, a signature move benched).

## 2. Amplify what the system already owns

Boldness comes from **commitment inside the identity**, not from imports:
- Push the system's own type scale up a step (display sizes, not weight-stacking)
- Spend the brand's strongest color at full conviction (one area, not confetti)
- Use the system's signature move at full size — the one that makes the brand recognizable with content removed
- Break the grid ONCE, deliberately (oversized element, bleed, extreme scale contrast) — randomness is noise; one break is a decision

If the identity genuinely has no strength to amplify (seed mode, empty DESIGN.md): that's `new-work` territory (lands M4), not bolder. Say so.

## 3. The skeleton test

**Strip all copy from the surface. Does the bare structure still say what the section means?** (A pricing section must read as "choose" with zero words; a hero must read as "arrival".) If the skeleton is mute, no amount of styling saves it — fix structure first (that's `layout`, not bolder).

## 4. Boundaries

- Never break mandate 2: boldness may not replace identity. A "bolder" pass that invents a new palette is a redesign in costume.
- Never bold everything. Bolder is a redistribution of emphasis, not a gain multiplier. If the request is "make the whole page bolder," the answer is one focal surface and quieter surroundings.
- Convince/Showcase surfaces earn full boldness; on Work/Read surfaces boldness = clarity at strength (bigger hierarchy, fewer steps to the goal), not theatrics (see `reference/operate.md`).

## 5. Verify

Batched render check at shipping sizes: the bold moment reads in one second from arm's length (squint test), nothing regressed in contrast/overflow, and the surface still looks like the same brand — only more sure of itself.
