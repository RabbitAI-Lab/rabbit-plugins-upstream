# quieter — reduce intensity without going generic

Noise is the target, personality is not. Quiet removes competition for attention; it never removes identity.

## 1. Intensity assessment first

Before reducing anything, name the intensity sources and rank them (loudest first):
- **Color volume** — saturation coverage, accent frequency, how much area the loudest hue owns
- **Type drama** — weight/size/tracking contrast, count of competing voices
- **Shape activity** — radius variety, shadow depth, borders doing decorative work
- **Motion** — count of animated things, distances, durations
- **Density** — elements per viewport, competing focal points

Then pick the **2 loudest** and address those. Quiet-by-everything = bland (see avoid-list).

## 2. The reduction targets (dial, don't zero)

| Source | Quiet target |
|---|---|
| Color | 70–85% saturation on accents; fewer accents; tinted grays derived from the surface hue — **never neutral gray on color** (that's the gray-on-color sin) |
| Type | Fewer weights (2–3 max), smaller size spread, one voice doing more jobs |
| Shape | One radius family, one shadow language, borders structural not decorative |
| Motion | ease-out-quart class, 10–20px distances, shorter durations, fewer animated elements |
| Density | More whitespace between groups (the rhythm law), fewer competing elements per screen |

## 3. Mode split — quiet ≠ uniform

- **Convince/Showcase:** quiet means *composed* — one confident focal moment, everything else recedes. The surface can still be striking; it simply stops shouting everywhere at once.
- **Work/Read:** quiet means **denser and calmer, not blander**. These surfaces were often never loud — "quieter" here means removing decoration while preserving (or increasing) information density. Do not "simplify" a dashboard into emptiness.

## 4. Avoid-list (quiet is not…)

- **Not generic.** If the result could be any product's screen, you removed identity by accident (mandate 2 violation) — restore the signature move, just smaller.
- **Not grayscale.** A monochrome result from a colorful brand is a lobotomy, not a dial-down.
- **Not personality-free.** Keep one idiosyncrasy (a voice, a shape, a motion signature). Quiet brands still have a pulse.
- **Not hedged.** Quiet design is still committed — soft emphasis is emphasis.

## 5. Verify

Squint test: the surface reads calm at arm's length with ONE dominant element. Contrast and states survive the reduction (quieter color must not drift below 4.5:1). And the brand test: a stranger still recognizes the family.
