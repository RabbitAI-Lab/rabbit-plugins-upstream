# designer

> **Ship your identity, not the AI's average.**

Design direction for AI agents: brand preservation as law, a mechanical anti-slop detector, and two reviewers that never see each other's work until the verdict is written.

Plain markdown. One readable Node script. **No binary. No network. Nothing hidden.** — read the entire skill in 20 minutes before you run it. In a world of agent skills that download executables on first edit, that's the feature.

🚧 **Built in public — under construction.** Nothing gets announced before it works.

## What it does

- **Respects your brand if you have one.** `document` records your existing identity as DESIGN.md law; every refinement preserves it; drift gets flagged mechanically.
- **Builds you one if you don't.** Greenfield work rolls a visual direction from a seeded, anti-convergence world deck — never the model's default reflexes.
- **Reviews like a design director.** A scored UX critique and a technical audit run in isolated context — judgment is never anchored by the detector's output.
- **Enforces craft mechanically.** A zero-dependency local detector (`scripts/detect.mjs`) — every rule has a status, a threshold, and a reason, all accounted in `data/rules.json`.
