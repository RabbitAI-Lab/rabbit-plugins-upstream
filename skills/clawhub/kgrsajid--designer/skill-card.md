## Description:

Use when the user wants to design, redesign, review, polish, or improve a frontend interface — build UI, fix visual quality, enforce a brand or design system, or create a visual identity. Not for backend-only work or non-visual refactors.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kgrsajid](https://clawhub.ai/user/kgrsajid)

### License/Terms of Use:

Apache 2.0

## Use Case:

Developers and product teams use this skill to direct agents designing or refining frontend interfaces, documenting brand rules, reviewing UX and implementation quality, and improving visual craft while preserving the stated design brief.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Interactive testing guidance does not establish safeguards for live user data or consequential actions.

Mitigation: Use a sandbox with synthetic data for interactive testing and require approval before consequential actions.

Risk: The partial security analysis does not establish that all referenced content and scripts are safe.

Mitigation: Review referenced files and scripts before installing or executing the skill.
