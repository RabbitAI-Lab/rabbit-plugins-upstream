# PRODUCT.md

## Audience
An ops manager reconciling a queue of invoices before a monthly deadline,
and a reviewer spot-checking flagged entries on a phone.

## Goals
Reconcile the queue fast; trust the totals; never lose an entry.

## Platform
web — evergreen browsers only, no IE; mobile down to 360px; no offline mode.

## Constraints
Lighthouse ≥ 90 on the reconcile table; WCAG AA; zero JS frameworks.

## Terminology
"Queue" not "list". "Entry" not "row". "Reconcile" not "process".

## Confirmed brand commitments
Söhne (display), Inter (body) — names only; laws live in DESIGN.md.
