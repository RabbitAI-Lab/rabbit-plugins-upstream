# 买精装修房，想入住一路坎坷呀10.30

精装修已经大面积开始了，但是面对市面上大品牌各种精装修，真的无力吐槽。大趋势对与不对，屁民也无奈，只能承受。

1.一般普通百姓买了精装修，最大的改造其实就是封个阳台，拆个保温墙，贴个墙砖，然后装上晾衣架，吊顶即可。像恒大的精装修，一般客厅一个阳台，厨房带一个阳台，下来用差不多好一点的材料也得一万以上的费用了。

2.这些做完以后，大部分人最多定制个柜子，包括阳台的洗衣柜等等，然后随便买点家具放上，基本就可以入住了。但是定制也挺麻烦，如果通顶还得拆除原来的石膏线，然后安装柜子，然后在修补原来的石膏线。全房如果都定制，还得好几万。

以上是基本的做法，一般工薪阶层买精装修，谁也不愿意大改变，一是费用，二是搞不好还得增加设计费用，那些从硬装到软装一体设计，让业主拎包入住的精装修服务，在西安地区，少之又少，少则花费十万左右，好的家具拎包进去几十万都有了。这些不是一般工薪阶层能承受的。

▲像这种大动干戈的也是相当少，把原来的石膏线全部拆除，所有墙面改变颜色，因为吊顶就得装筒灯，这些都是费用，然后选择适合家具摆放，包括原来恒大丑陋的水晶灯更换，都是一笔不小的费用。整体除过原有瓷砖不动，原有木门门套不动，其他几乎都大变样了
▲拆掉原来难看的木线条和屎黄色壁纸，去掉壁灯，更换质感壁布，这些都得有不小的费用
▲卧室也是一样的，更换丑陋的灯具，改变墙体颜色，购买家具窗帘等等其实都是费用
▲你如果还想做美式风格，基础不仅大动，后期家具价格更是一般人无法承受的
▲当然，只换个电视墙壁纸，买个普通家具摆上也能过日子
作为普通工薪阶层：真的很少有人能大动干戈，都是钱，基础做个微装就算装修了，家具家电再次费用也不会低。
