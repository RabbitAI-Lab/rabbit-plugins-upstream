# 装修装到一半钱不够了，该按什么顺序砍？

装到一半钱不够了，记住一个顺序：隐蔽工程一分不能砍，面子工程全都可以砍，家具家电往后推。 砍错了顺序，省下的钱还不够返工的。

第一，坚决不能砍的：水电和防水。 水电工程埋雷必炸，爆管淹地板、短路烧厨房、赔邻居加砸墙。关键是专业施工，而不是便宜的工人。防水工程漏水即破产，返碱发霉、楼下水帘洞、天价赔偿。卫生间刷吊顶位置高度，闭水试48小时。这两个是里子工程，出问题维修成本高昂，砍谁都不能砍它们。

第二刀，砍造型。 保持毛坯房原状即可，不要人为添加任何不必要的造型。如吊顶，如石膏线，如窗帘盒，如镶嵌衣柜的假墙。更不要为了心里的面子问题做个难看就没有品位的电视墙。阳台有晾衣架也可以不吊顶，谁说钢丝露出来就难看了？窗套哑口套，能不做就不要做，这个不是必需品，墙面乳胶漆直接就盖住了，何必把钱花到视觉上？不如买个好家具。窗台石就不要了吧，用剩余的瓷砖直接铺上，后期淘宝定个垫子铺上，也美美的，谁知道你垫子下方是瓷砖还是石材？

第三刀，砍墙面和材料档次。 普通腻子加乳胶漆就行，千万不要为了好看或者面子用一卷不到一百的壁纸，这种廉价壁纸不如不用。乳胶漆浅色变色免费就可以，干净又有品味。瓷砖就不要一口一个一线品牌，二线品牌，谁告诉你瓷砖还有一二线之分？都是商家忽悠消费者自吹自擂而已。墙砖除过卫生间以外，都可以用半瓷。厨卫吊顶也不要看什么品牌，就是铝扣板，能供你几次拆卸维修就是好板子。踢脚线最便宜的PVC完全可以用，使用上小心一点，用十来年不会有问题。木门就用普通的，实在困难就用本地门，便宜，能用就行。

第四刀，家电家具往后推。 空调当然挂机了，刚需房看自己的客餐厅面积，如果挂机能用，为什么花钱买柜机？电视也不要要求价钱了，一两千的大电视太多了，高清不高清取决于信号源，而不是电视。冰箱不要贪大，越大的冰箱越让人吃剩饭剩菜。如果是两口之家，先过日子要紧，卧室以及厨卫收拾好，其他客厅家具甚至各种家电都可以不要，能住进去再说，以后慢慢有钱了再添加，否则一次性全部置办，必然质量不高。

但有三样小钱不能省。 马桶釉面不耐脏就罢了，但是软管和角阀不能便宜，否则用不了多久直接爆管。水件五金一定要舍得投入。厨房油烟机要大吸力，功能就是吸烟，其他可以忽略；热水器选老品牌，杂牌寿命非常短。
