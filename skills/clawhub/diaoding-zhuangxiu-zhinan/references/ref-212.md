# 装好厨房，需要做对10件事

作者: 西安装修课堂
发布时间: 2023年7月12日

前面有卫生间总结，今天看厨房注意事项总结。

第一、采光格局。
纯南户型，厨房门在门厅的话，能改就直接让厨房门朝南，满足采光、成就门厅收纳、让餐厨动线合理。移动门会影响格局减少收纳时，可以开窗满足采光，下方地柜保留，格局没受影响，采光最大化。厨房想要装好，采光和格局第一重要，这才是设计。

第二、厨房瓷砖。
学别人铺大规格瓷砖不懂设计，只是多掏钱没效果——缝隙刚好在吊柜地柜之间，意义在哪？正确做法：用大规格瓷砖为少缝隙，费钱满足虚荣心也可，但仅限对设计有极高要求；没审美跟风就算了。其实懂装修根本不是大规格问题，低调内涵做法+相近色美缝，再小瓷砖也不影响美观。没审美不如省点钱用普通400*800墙砖+同色美缝。厨房地面肯定外面大砖通铺，放大空间。大规格瓷砖高兴了装修机构和建材商，满足业主虚荣心，你家高级不高级和瓷砖大小几乎无关。

第八、厨房定制。
橱柜定制是好厨房关键点，不仅满足收纳，还得满足功能和颜值，一旦出错或留遗憾，厨房价值大打折扣。

第三、厨房防水（要点）。
干厨房没地漏就不要做防水，水往哪流？除多赚钱无任何意义。衡量装修机构是否专业，看这些细节。

第四、厨房门。
有条件厨房门越大越好，别人为缩小。门洞大用多联动移门放大进门空间；内部空间有限平开门占地方，做外挂移门省地方。

第五、开放厨房。
只要正常做饭，劝都不要用开放厨房。让人无法接受的不止油烟，是忽略的噪音——两人时一人在卧室睡一人在厨房，烟机噪音水流声锅碗合奏，噪音让人受不了，这是普通家庭做不成开放厨房的原因，入住越多越不能做。想要开放感，用大面积玻璃移门和玻璃隔断解决，杜绝油烟也杜绝噪音。单身或一两人可尝试，人多还是算了。

第六、厨房吊顶。
开放厨房肯定石膏板吊顶协调；封闭厨房用纯色弱化存在感铝扣板，最实惠。学别人做石膏板吊顶别墅可以高层谨慎，检修或变黄漏水时后悔来不及。蜂窝板做成弱化缝隙也美，但考虑以后维修得重做，止逆阀漏烟换烟管得拆除重做。厨房吊顶唯一实惠就是纯色弱化铝扣板。

第七、厨房隐藏设计。
厨房要好看不光有钱，得找对人。热水器、管道隐藏是最好的做法，建立在好设计和对应金钱基础上。定制橱柜只看低价找套餐，能做饭就行。

第九、厨房装修顺序。
连装修顺序没搞清楚就找专业人做。自己装修前提是自己懂装修。顺序：瓷砖铺贴→美缝→量门和橱柜尺寸定制→预埋止逆阀烟管→铝扣板吊顶→安装橱柜→安装石材→安装厨房门→安装烟机灶具热水器及其他电器。

第十、厨房容易翻车点。
学别人做高低台翻车；厨房装修翻车每个都是教训；厨卫吊顶翻车防不胜防；厨卫深色瓷砖铺贴最好慎用；装修最后一难橱柜翻车。
