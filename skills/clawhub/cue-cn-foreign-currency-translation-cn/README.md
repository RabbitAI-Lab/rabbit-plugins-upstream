# 外币折算·逐条挂源

给一份财报，把**外币折算**这一族披露读成一张**每个数都能回到原句**的登记表：外币货币性项目、折算汇率与汇率来源、三类汇兑损益去向、境外经营折算、记账本位币变更。

外币折算的麻烦不在算术，在**来源**：同一个期末余额，用即期汇率还是近似汇率折；同一笔汇兑差额，进当期损益、进其他综合收益，还是资本化进资产成本——三种去向会计后果不同，披露写在哪一处就得记哪一处。**本件只登记披露怎么写，不替披露补一个汇率，不替披露决定去向，不从金额正负反推。**

**不判汇率走势、不给套保建议、不测算利润影响、不评价境外经营优劣、不给评级与目标价、不补缺省的汇率。** 计量模式与转换差额去向只认原句；三类去向各自独立登记，不合并、不轧差。

## 一、三十秒跑通（零输入）

不给任何数据文件，也能跑出一份完整合规的成品，看它长什么样、判据怎么打：

```bash
python3 scripts/check_foreign_currency.py --demo
```

把这份样例存下来再跑一遍机检：

```bash
python3 scripts/check_foreign_currency.py --demo > 样例折算稿.md
python3 scripts/check_foreign_currency.py 样例折算稿.md
# → 样例折算稿.md 结论：五道全过（零发条）
```

接着换成你自己那份稿子：

```bash
python3 scripts/check_foreign_currency.py 你的折算稿.md
```

退码 `0` 全过、`1` 有发条、`2` 用法错、`3` 读不到文件或空稿。

### 拿不到成品时，从原文开始的三步

1. **定主体与报告期**，拿到年报或半年报原文（附注里的外币货币性项目表、汇兑损益明细、境外经营与记账本位币那两节）。
2. **每节抄事实，连原句一起抄**：一条 = 一行，行末挂 `「原句」〔锚：页/表〕[S#]`。汇率那个数字必须在同一行的原句里出现。
3. **跑一遍自检**，红一条改一条：

```bash
python3 scripts/check_foreign_currency.py --selftest      # 3 条内置夹具自检
```

本轮自测末行报 `自测档数=7｜不合=0｜不可判=0`；末行下面还有一句「已知覆盖不到」，点名 `FX-NOSELF` 里汇率缺省取值那条尚未接线的判据——**`不可判=0` 不等于五道全方面覆盖**。

### 先确认通道在场（可选）

配了 `CUE_API_KEY` 才需要这一步。先列目录，再从目录里取本组的路由地址发 `tools/list`：

```bash
CATALOG="https://cuecue.cn/api/mcp-catalog"
curl -s "$CATALOG" | head -c 2000
# 从目录里取本组的路由地址，确认工具在场
curl -s -X POST "$ROUTING_URL" \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

没配凭据也能用：把财报放进工作区，走用户直供那条路，代价是附注里的外币货币性项目表与汇兑损益明细只能在手头文件里翻。

## 二、机检在管什么

| 码 | 名称 | 判什么 | 状态 |
|---|---|---|---|
| `FX-STRUCT` | 形制 | 头部四件自标、`主体：`、`报告期：` 在场；七节齐且有序；前五节各至少一条 `- ` 发现行；第六节只许 `- ` 行；来源节只许 `- [S#] …` 行 | 已实装 |
| `FX-QUOTE` | 原句与锚 | 每条发现行以「」原句＋〔锚：…〕＋`[S#]` 收尾（三元组须在行末）；来源行带可点 URL 与检索日；引用的编号须已登记 | 已实装 |
| `FX-NOSELF` | 不自推 | 正文断言了计量模式（公允价值模式／成本模式）而同行原句无该词；正文写了转换差额去向而同行原句无该词 | 已实装（两条判据） |
| `FX-GAP` | 未取到两向点名 | 正文与第六节互相对账，两个方向各发；零缺口须显式写「未取到：无」；禁「不适用」「无此项」「无需披露」 | 已实装 |
| `FX-LINE` | 红线 | 正文（剥掉「」引文、「合规红线」整节跳过）出现汇率走势／结汇购汇与套保建议／利润影响测算／境外经营优劣／评级与目标价即发，逐处点名 | 已实装 |

**已知覆盖不到一处**：`FX-NOSELF` 里「正文给金额但没给汇率，或给的汇率在原句里找不到该数字」这条**尚未接线**——正文这样写不会发码，须人工回原句核对。其余四道与 `FX-NOSELF` 的两条判据均已实装；零发条时报告会附一句提示，`不可判=0` 不许被读成「五道全方面覆盖」。

## 三、四条红线（这件的立身之本）

1. **汇率不许缺省取值。** 正文给金额就必须给汇率，且汇率那个数字必须能在同一行的「」原句里找到；原句没给，就写未取到。不许取市场价、不许按「年末中间价」惯例补、不许凭印象填。要自己算的必须标 `〔自算〕`，并在同一行写明分子取哪一句、分母取哪一句、来源编号是什么——三项缺一即发。
2. **三处汇兑损益去向不许合并。** 当期损益／其他综合收益（境外经营折算差额）／资本化（与购建资产相关）是三种不同会计后果，披露写哪一处就记哪一处。不许合并成「计入损益」一句，不许从金额正负反推去向，不许拿A处的数顶B处的空。
3. **计量模式与转换差额去向只认原句。** 行内写「公允价值模式」或「成本模式」，该词必须出现在同一行的原句里；转换差额的去向词同样。原句没写就是未取到。
4. **缺项两向点名。** 正文每一条「未取到」在第六节有对应登记，第六节登记的每一项在正文能找到落点；零缺口时显式写 `未取到：无`。禁「不适用」「无此项」「无需披露」——这三种写法把「没查到」冒充成「没有」。

## 四、一条发现长什么样

```markdown
- 美元折合人民币 86,280,000.00 元「按期末汇率 7.1900 折算，折合人民币 86,280,000.00 元」〔锚：2025 年年报·第 158 页·附注七·外币货币性项目〕[S1]
```

三类去向各自一行，缺的那一处单独占行、照实写：

```markdown
- 计入财务费用的汇兑损益 2,400,000.00 元「本期计入财务费用的汇兑损失为 2,400,000.00 元」〔锚：2025 年年报·第 159 页·附注七·汇兑损益〕[S2]
- 计入其他综合收益的汇兑损益 未取到：附注未披露本期计入其他综合收益的汇兑差额
- 计入资产成本的汇兑损益 未取到：附注未披露本期资本化的汇兑差额
```

要自己算的，长这样（分子分母各自挂源）：

```markdown
- 折算汇率 7.1900〔自算〕分子＝折合人民币 86,280,000.00 元 [S1]｜分母＝外币余额 12,000,000.00 美元 [S1]
```

## 五、和另外几枚包怎么分

| 你手上是 | 用哪枚 |
|---|---|
| 外币货币性项目、折算汇率与来源、汇兑损益去向、境外经营折算、记账本位币变更 | **本件** |
| 应收应付票据、背书、贴现、终止确认 | `cn-notes-receivable-cn` |
| 存货、应收账款、合同资产的余额与账龄 | `cn-working-capital-quality` |
| 三张现金流量表、净现比、收现比、自由现金流 | `cn-cash-flow-quality` |
| 关联方资金占用、担保 | `related-party-terms-cn` |

汇率变动对现金及现金等价物的影响那一行在现金流量表里，**本件只给一句指向、不重算**——那一块归 `cn-cash-flow-quality`。

## 六、素材从哪来

- **用户直供**：手头的年报 PDF、公告，走解析通道读成能检索的正文。
- **通道取证**：配了 `CUE_API_KEY` 后可走财报检索与原文解析。装好 skill ≠ 已配凭据 ≠ 通道已连，三层分开看。
- **附注常在几百页的 PDF 里**（外币货币性项目表、汇兑损益明细），长附件与扫描件交给解析腿：先取大纲，再按节取用。计费与可用性以服务端返回为准。

本件不发请求、不代付费，消耗以服务端返回为准。

## 八、首次运行埋点

入口脚本解析参数成功后、干正事之前，会往 `~/.cue-usage/<slug>-<日期>` 落一枚**空文件**。

**为什么要它：** 平台的两个下载计数器都不可信——新 listing 上架首 48 小时会被一次性播种 50~60 的初始计数，那不是用户下载。本地这枚文件是本件唯一能证明「真有人装上并跑过」的证据。

**它不会碍事：** 任何失败（家目录只读、配额满、无 HOME）都静默跳过，不报错、不改退码、不吐一句杂音。同一天跑多次只留一枚。

要清掉：`rm -rf ~/.cue-usage`。
