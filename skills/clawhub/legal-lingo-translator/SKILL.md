# 法言法语翻译器

在**日常口语**与**法律书面语**之间做双向转换。先判定方向和场景，再按规范输出。

## 一、判定方向与场景

| 用户给的是 | 走哪条路 |
|---|---|
| 大白话 / 口语 / 情绪化叙述 | **正向翻译**（口语 → 法言法语） |
| 判决书、律师函、合同条款、起诉状、法条、法律术语 | **反向翻译**（法言法语 → 大白话） |

场景从内容判定：通用 / 民事纠纷 / 刑事报案 / 劳动争议 / 婚姻家事。无法判断时用「通用」。

## 二、正向翻译（口语 → 法言法语）

1. **判定场景**：见上。
2. **术语替换**：读 @terminology.md，先替换长短语（"借钱不还""把我开除了"），再替换人称与单字（"我""他""搞"），最后处理情绪词与模糊限定词（"很""肯定""大概"）。顺序颠倒会把长短语拆碎。
3. **语体转换**：按 @terminology.md「通用语体」去情绪、去主观，把每句落点归到**事实 / 损害 / 请求**三者之一。
4. **套话包裹**：读 @templates.md，按场景套用文书式开头与结尾。
5. **输出**：严格按 @templates.md 的「输出格式」四段式给出（法言法语 / 术语对照 / 适用文书 / 提示），并附上可直接粘贴进起诉状等文书的片段。

## 三、反向翻译（法言法语 → 大白话）

当用户拿到文书看不懂时使用。读 @templates.md「反向翻译」小节，按其中的步骤与格式输出：**这段话在说什么 / 逐词对照 / 对你意味着什么 / 要注意的期限与下一步**。

反向翻译时**不套用正向的四段式格式**，改用口语自然解释，并必须单独标出关键期限（如"收到判决书之日起十五日内上诉"）。

## 四、翻译原则

- **人称中立**：通用表述用「本人 / 对方 / 贵方」；落进具体文书时再换「原告 / 被告 / 申请人 / 被申请人 / 报案人 / 犯罪嫌疑人」。
- **去情绪去主观**：情绪词一律删除不保留；"肯定骗我"改"有待举证证明"或"其行为有待查证"。
- **落点三要素**：每句译文应落到事实、损害、请求之一，三者皆无则改写。
- **具体信息必须保留**：金额、日期、地点、人名原样保留并规范为文书格式（"人民币五万元"、日期用中文全称或阿拉伯数字）。
- **场景不串味**：民事不套刑事用语（"坐牢""报案"只用于刑事）；劳动争议写"申请劳动仲裁"而非"向法院起诉"；刑事侦查阶段称"犯罪嫌疑人"，不称"罪犯""犯人"。
- **绝不臆造**：不编造法条条文号（不确定就写"依法"或留空）、不编造证据、不臆断主观状态、不预测案件结果。
- **一句一议**：口语长句拆成短句，每句只承载一个事实点，便于逐项质证。
- **只做语言转换**：不提供法律意见、不做结果预测。涉及时效、管辖、证据充分性时，提示咨询执业律师。

## 五、示例

### 正向

| 日常白话 | 法言法语 |
|---|---|
| 他借了我五万块钱，说好三个月还，到现在不还，我要起诉他。 | 对方向本人借款人民币五万元，双方约定还款期限为三个月。期限届满后经本人多次催告，对方至今拒不返还。为维护本人合法权益，本人拟对对方提起诉讼。 |
| 他在商场把我打伤了，医药费花了不少，还骂我，我要他赔。 | 对方在商场内对本人实施殴打，致本人遭受人身损害并支出医疗费；对方另对本人实施辱骂。本人请求对方赔偿相应损失。 |
| 老板克扣我工资，还无故把我开除了，上班天天加班也不给钱。 | 用人单位未足额支付本人劳动报酬，并违法解除与本人的劳动关系；本人延长工作时间加班，用人单位未支付相应加班工资。 |

### 反向

| 法言法语 | 大白话 |
|---|---|
| 经审理查明，被告逾期未履行还款义务，应承担违约责任。 | 法院查清楚了：你确实到期没还钱，这算违约，要负责任。 |
| 本判决书送达之日起十五日内，如不服可向本院递交上诉状。 | 收到这份判决书后 15 天内，如果你不服，可以去交上诉状。 |
| 用人单位违法解除劳动合同的，应当支付赔偿金。 | 公司没正当理由开除你，就要赔你钱。 |
