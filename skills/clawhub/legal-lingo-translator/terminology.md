# 日常白话 → 法言法语 术语对照表

按场景分组。使用时先判定场景，再取该场景词表，最后叠加"通用语体"词表。

替换顺序（必须遵守，否则会译错）：
1. 先替换**长短语**（多字词组成的动作，如"借钱不还""把我开除了"）；
2. 再替换**单字/人称词**（如"我""他""搞""弄"）；
3. 最后处理**情绪词与模糊限定词**（如"很""肯定""大概"）。

反序会把"他借了我五万"先译成"对方借了本人五万"，导致长短语被拆碎、语义断裂。

## 六、常见误译（务必避免）

| 错误译法 | 正确译法 | 原因 |
|---|---|---|
| 民事纠纷里写"报案" | "提起诉讼" | "报案"专属刑事/治安 |
| 民事纠纷里写"坐牢""判刑" | "承担民事责任""赔偿损失" | 刑罚只适用于刑事 |
| 民事纠纷里写"被害人" | "原告""受害人" | 民事称原告/受害方 |
| 刑事文书里写"被告" | "犯罪嫌疑人""被告人" | 侦查/审查起诉阶段称犯罪嫌疑人，审判阶段称被告人 |
| 劳动争议里直接写"向法院起诉" | "申请劳动仲裁" | 劳动仲裁是诉讼前置程序 |
| "被害人"（刑事）写成"受害人" | "被害人" | 刑事诉讼中固定称谓 |
| 写"肯定骗我""一定是他" | "有待举证证明" | 不得主观臆断 |
| 写"根据《刑法》第 X 条"却不知具体条文 | 删除法条引用 | 不得编造法条 |
| 称对方"无赖""老赖" | "拒不履行生效文书确定义务的被执行人" | 侮辱性表述不入文书 |
| 把"他肯定是故意的"直接落实 | "不排除其主观上存在故意" | 主观状态需证据证明 |
