## SD4 培训方案域范本

### 一、领域知识要点

- ADDIE 模型：分析、设计、开发、实施、评估
- 成人学习原则：目标导向、经验联结、即学即用、问题中心
- 学习目标三层：知道（知识）、会做（技能）、愿做（态度）
- 柯氏四级评估：反应、学习、行为、结果
- 工作坊设计：破冰 → 输入 → 练习 → 共创 → 输出 → 承诺
- 转化设计：训前任务、训中练习、训后 30 天行动计划和复盘

### 二、判定标准

- 目标须区分知道/会做/愿做
- 每个模块须有练习与产出
- 评估须覆盖至少两级
- 须设计训后转化机制

### 三、范本结构

1. 需求分析与目标
2. 学员画像
3. 课程结构与时长
4. 每模块活动与产出
5. 讲师与物料
6. 评估方案
7. 转化机制

### 四、常见失范

- 只有讲授没有练习
- 目标全是"了解""掌握"
- 无评估或只评满意度
- 训后无转化设计

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 绩效差距、能力缺口、需求优先级、培训边界 |
| 本域产出 | 培训需求报告；培训大纲；工作坊方案；转化方案；评估方案 |
| 下游可用 | 评估方案 |

### 六、交付自检

交付前逐项打勾，任一项不成立即返工：

- [ ] 目标须区分知道/会做/愿做
- [ ] 每个模块须有练习与产出
- [ ] 评估须覆盖至少两级
- [ ] 须设计训后转化机制

同时排除以下失范：

- [ ] 已排除：只有讲授没有练习
- [ ] 已排除：目标全是"了解""掌握"
- [ ] 已排除：无评估或只评满意度
- [ ] 已排除：训后无转化设计

### 七、执行卡（以「培训需求分析」为例）

**开工前备齐**：绩效差距、能力缺口、需求优先级、培训边界

**可选补充**：业务目标、岗位标准、访谈

**按序执行**：

1. 定业务目标
2. 找绩效差距
3. 判是否培训可解
4. 排优先级

**交付前核对**：须区分培训可解与管理/流程问题

**成品须符合**：培训需求报告

### 八、成品骨架

按「培训需求报告」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 培训需求报告

## 1. 需求分析与目标
## 2. 学员画像
## 3. 课程结构与时长
## 4. 每模块活动与产出
## 5. 讲师与物料
## 6. 评估方案
## 7. 转化机制
```

**齐备要求**：必选组件「绩效差距、能力缺口、需求优先级、培训边界」须全部落位；约束「须区分培训可解与管理/流程问题」须逐条成立；可选「业务目标、岗位标准、访谈」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
