## SD5 营销方案域范本

### 一、领域知识要点

- 活动五要素：目标、人群、机制（利益怎么给）、渠道、节奏
- 促销机制类型：满减、折扣、赠品、秒杀、预售、拼团、会员专享、返券
- 价格合规：原价须真实、优惠须可计算、不得虚构折扣
- 节奏设计：预热（蓄水）→ 爆发（转化）→ 返场（追单）→ 沉淀（复购）
- 执行 SOP 要素：时间轴、责任分工、物料清单、话术、风险预案、监控指标
- 复盘四问：目标达成否、哪些动作有效、哪些无效、下次改什么

### 二、判定标准

- 活动机制须可被用户一眼算清
- 目标须量化到 GMV/新客/复购
- SOP 须精确到时间点与责任人
- 预算与 ROI 须预估

### 三、范本结构

1. 活动目标与人群
2. 机制设计
3. 节奏排期
4. 渠道与物料
5. 执行SOP与分工
6. 预算与ROI预估
7. 风险预案
8. 复盘指标

### 四、常见失范

- 机制复杂用户算不清
- 只有创意没有执行排期
- 无风险预案（库存/客服/系统）
- 复盘只报数据不归因

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 目标（量化）、人群、机制、节奏表、资源需求 |
| 本域产出 | 活动方案；促销机制表；节点营销方案；执行SOP；复盘报告 |
| 下游可用 | 复盘报告 |

### 六、交付自检

交付前逐项打勾，任一项不成立即返工：

- [ ] 活动机制须可被用户一眼算清
- [ ] 目标须量化到 GMV/新客/复购
- [ ] SOP 须精确到时间点与责任人
- [ ] 预算与 ROI 须预估

同时排除以下失范：

- [ ] 已排除：机制复杂用户算不清
- [ ] 已排除：只有创意没有执行排期
- [ ] 已排除：无风险预案（库存/客服/系统）
- [ ] 已排除：复盘只报数据不归因

### 七、执行卡（以「活动策划」为例）

**开工前备齐**：目标（量化）、人群、机制、节奏表、资源需求

**可选补充**：历史活动数据、预算

**按序执行**：

1. 定目标
2. 选人群
3. 设机制
4. 排节奏
5. 配资源

**交付前核对**：机制须可算清；目标须量化

**成品须符合**：活动方案

### 八、成品骨架

按「活动方案」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 活动方案

## 1. 活动目标与人群
## 2. 机制设计
## 3. 节奏排期
## 4. 渠道与物料
## 5. 执行SOP与分工
## 6. 预算与ROI预估
## 7. 风险预案
## 8. 复盘指标
```

**齐备要求**：必选组件「目标（量化）、人群、机制、节奏表、资源需求」须全部落位；约束「机制须可算清；目标须量化」须逐条成立；可选「历史活动数据、预算」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
