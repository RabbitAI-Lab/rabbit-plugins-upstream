## SD3 测评方案域范本

### 一、领域知识要点

- 双向细目表：知识点 × 认知层级（识记/理解/应用/分析/评价/创造）配比
- 难度分布：易:中:难 常见 7:2:1 或 6:3:1，按用途调整
- 题型功能：选择（覆盖广）、填空（精确记忆）、简答（表达）、综合（迁移）
- 信度与效度：题目区分度（高分者答对率 − 低分者答对率）、猜测度
- 变式题三法：换数据、换情境、换问法（保持考查点不变）
- 错题反哺：按知识点归因后定向补题

### 二、判定标准

- 须有双向细目表，禁止凭感觉组卷
- 难度分布须明确目标比例
- 每题须标知识点与认知层级
- 变式题须保持考查点一致

### 三、范本结构

1. 命题目标与范围
2. 双向细目表
3. 试卷正文
4. 参考答案与评分标准
5. 难度与区分度预估
6. 讲评建议

### 四、常见失范

- 题目重复考查同一知识点
- 难度失控导致区分度低
- 答案与题干存在歧义
- 变式题实际换了考查点

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 双向细目表、试卷、答案、评分标准、难度预估 |
| 本域产出 | 试卷+答案；结构化题库；变式题组；分层作业单；测评分析报告 |
| 下游可用 | 测评分析报告 |

### 六、交付自检

交付前逐项打勾，任一项不成立即返工：

- [ ] 须有双向细目表，禁止凭感觉组卷
- [ ] 难度分布须明确目标比例
- [ ] 每题须标知识点与认知层级
- [ ] 变式题须保持考查点一致

同时排除以下失范：

- [ ] 已排除：题目重复考查同一知识点
- [ ] 已排除：难度失控导致区分度低
- [ ] 已排除：答案与题干存在歧义
- [ ] 已排除：变式题实际换了考查点

### 七、执行卡（以「试卷生成」为例）

**开工前备齐**：双向细目表、试卷、答案、评分标准、难度预估

**可选补充**：考纲、题库、学情

**按序执行**：

1. 定范围
2. 建细目表
3. 选题
4. 配难度
5. 审题
6. 出答案

**交付前核对**：须覆盖细目表全部条目；答案须唯一

**成品须符合**：试卷+答案

### 八、成品骨架

按「试卷+答案」交付。复制下面骨架，节标题即该节须给出的结论，不要改成中性标题。

```markdown
# 试卷+答案

## 1. 命题目标与范围
## 2. 双向细目表
## 3. 试卷正文
## 4. 参考答案与评分标准
## 5. 难度与区分度预估
## 6. 讲评建议
```

**齐备要求**：必选组件「双向细目表、试卷、答案、评分标准、难度预估」须全部落位；约束「须覆盖细目表全部条目；答案须唯一」须逐条成立；可选「考纲、题库、学情」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
