## SD8 照护方案域范本

### 一、领域知识要点

- 护理程序五步：评估、诊断（护理诊断）、计划、实施、评价
- 常用评估工具：Barthel 指数（ADL）、Braden 压疮风险、Morse 跌倒风险、MMSE 认知
- 护理诊断表述：问题 + 相关因素 + 表现（PES 格式）
- 护理理论：Orem 自理缺陷、Roy 适应模式、Neuman 系统模式、Peplau 人际关系
- 康复方案：早期活动、体位管理、关节活动度、吞咽与营养
- 照护者负担：喘息服务、技能培训、心理支持

### 二、判定标准

- 评估须用标准化工具并记录分值
- 护理诊断须用 PES 格式
- 措施须可执行到频次与责任人
- 须含评价节点与调整条件

### 三、范本结构

1. 评估结果（工具+分值）
2. 护理诊断清单
3. 照护目标（分期）
4. 措施表（频次/责任人/标准）
5. 风险预防
6. 照护者支持
7. 评价与调整节点

### 四、常见失范

- 措施笼统如"加强观察"
- 忽略照护者负担导致方案不可持续
- 无评估直接给措施
- 未考虑居家条件

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 评估工具与分值、风险等级、功能基线 |
| 本域产出 | 护理评估表；护理计划；理论匹配说明；康复方案；照护者支持方案 |
| 下游可用 | 照护者支持方案 |

- [ ] 护理诊断须用 PES 格式
- [ ] 措施须可执行到频次与责任人
- [ ] 须含评价节点与调整条件

同时排除以下失范：

- [ ] 已排除：措施笼统如"加强观察"
- [ ] 已排除：忽略照护者负担导致方案不可持续
- [ ] 已排除：无评估直接给措施

### 七、执行卡（以「护理评估」为例）

**开工前备齐**：评估工具与分值、风险等级、功能基线

**可选补充**：既往病史、居家环境

**按序执行**：

1. 选工具
2. 施测
3. 记分
4. 定级
5. 基线描述

**交付前核对**：须用标准工具；分值须可复测

**成品须符合**：护理评估表

```markdown
## 1. 评估结果（工具+分值）
## 2. 护理诊断清单
## 3. 照护目标（分期）
## 4. 措施表（频次/责任人/标准）
## 5. 风险预防
## 6. 照护者支持
## 7. 评价与调整节点
```

**齐备要求**：必选组件「评估工具与分值、风险等级、功能基线」须全部落位；约束「须用标准工具；分值须可复测」须逐条成立；可选「既往病史、居家环境」按需补充。

**自检**：写完后对照第六节逐项打勾，任一不成立即返工。
