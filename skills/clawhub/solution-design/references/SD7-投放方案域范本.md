## SD7 投放方案域范本

### 一、领域知识要点

- 账户结构：账户 → 计划 → 广告组 → 创意，层级决定优化粒度
- 出价方式：CPC、CPM、oCPC、oCPM、CPA、ROAS 目标出价
- 预算分配：按 ROI 分档（高 ROI 加投、低 ROI 降权）、按生命周期（测试/放量/收割）
- 素材策略：3 秒钩子、卖点前置、多版本 A/B、素材衰减周期
- 关键指标：CTR、CVR、CPA、ROAS、曝光份额、频次
- 平台差异：巨量/腾讯广告/Google Ads/Amazon PPC 的结构与出价逻辑差异

### 二、判定标准

- 预算分配须有 ROI 依据
- 每个计划须有单一优化目标
- 素材须有衰减替换机制
- 须设止损线与日预算上限

### 三、范本结构

1. 投放目标与KPI
2. 账户结构设计
3. 预算分配表
4. 出价与定向策略
5. 素材与创意方向
6. 监控与止损规则
7. 优化节奏

### 四、常见失范

- 一个计划多目标导致算法无法优化
- 预算平均分配不看 ROI
- 素材不换导致衰减
- 无止损导致超支

### 五、交接契约

| 项 | 内容 |
|---|---|
| 上游必给 | 目标与KPI、渠道组合、测试-放量-收割阶段 |
| 本域产出 | 投放策略方案；预算分配表；账户结构方案；投放配置表；投放诊断报告 |
| 下游可用 | 投放诊断报告 |

- [ ] 每个计划须有单一优化目标
- [ ] 素材须有衰减替换机制
- [ ] 须设止损线与日预算上限

- [ ] 已排除：一个计划多目标导致算法无法优化

- [ ] 已排除：素材不换导致衰减
- [ ] 已排除：无止损导致超支

### 七、执行卡（以「投放策略制定」为例）

**开工前备齐**：目标与KPI、渠道组合、测试-放量-收割阶段

**可选补充**：历史投放数据、预算

**按序执行**：

1. 定KPI
2. 选渠道
3. 分期
4. 定策略

**交付前核对**：KPI须单一可优化；阶段须有转换条件

**成品须符合**：投放策略方案
