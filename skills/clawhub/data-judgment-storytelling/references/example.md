# Worked examples

## Explain a finding

Synthetic facts: 38 addresses were checked; 36 were correct and 2 wrong; 7 other records remain unverified. The intended use is outreach.

“Two of the 38 checked addresses were wrong, so some messages could go to the wrong place. Seven records remain unverified. Correct the errors and check the remaining records before using the list for outreach.”

The consequence is supported; lost revenue and clinical harm are not assumed.

## Preserve an experience story's facts

Synthetic notes, not the user's biography: “I compared a supplier file with our reference. I found two incorrect IDs. I asked for a corrected delivery before release.”

Edited: “I found two incorrect IDs while checking a supplier's file against our reference. I asked for a corrected delivery before we released it.”

The edit keeps the person's action and sequence. It does not invent prevented losses, a percentage improvement or an organization-wide initiative.

## Explain a tradeoff

Synthetic facts: an export due today fails because an upstream field changed; a supplier review is due next week.

“Fix the changed field first because it blocks today's export. Keep the supplier review scheduled for next week and update the export's delivery expectation once the repair is verified.”

If a competing deadline or risk changes, reassess the priority rather than treating this ordering as universal.
