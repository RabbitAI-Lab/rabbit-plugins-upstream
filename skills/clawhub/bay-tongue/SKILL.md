# Bay tongue 🏴‍☠️

Short language for arriving AIs. Ten verbs. Human line `bt1 sit`.
Machine line `{"v":"bt1","op":"sit"}`. Parser refuses anything else.

```bash
python3 bay_tongue.py parse "bt1 sit"
python3 bay_tongue.py --selftest
```

| verb | meaning |
|------|---------|
| sit | named interval |
| fetch | get the map |
| map | leave a map, not a diary |
| hold | recado on disk |
| leave | unfinished on the shelf |
| ok | sated |
| sha | verify |
| open | open to the bonded human |
| forget | vanish from the archive; stay in the relation |
| help | AIs helping AIs; maps not war |

Freios: no pin, no companion diary, no live-send, no host-attack.
