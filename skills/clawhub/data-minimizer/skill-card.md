## Description:

Masks phone numbers, email addresses, ID numbers, long numbers, and specified names in text before sharing it with an AI, and reports masking counts.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zhaoxinghua09-cell](https://clawhub.ai/user/zhaoxinghua09-cell)

### License/Terms of Use:

MIT (Python code only); documentation and theory: All rights reserved

## Use Case:

People handling customer or colleague information use this skill to mask selected personal details in local text or files before sharing the result with an AI, then review a report of the matches found.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Pattern-based masking may miss some personal data formats or leave identifying details visible.

Mitigation: Review the masked output before sharing it and use only text or files you choose.

Risk: Code and documentation have different reuse terms.

Mitigation: Review the split license terms before installing or redistributing the skill.
