# 信息提取规则（interactive / auto 共用）

> 用途：从一句话、截图、邮件正文中提取日程字段。**只在流程需要时加载本文件。**

## 1. 字段表

| 字段 | 必需性 | 说明 |
|---|---|---|
| 主题 `title` | 必需 | 无则标"未提供"或从动作反推（如"和 X 开会"→"与 X 开会"） |
| 开始时间 `start` | 必需 | 全天事件给 `YYYY-MM-DD`；普通事件给 ISO 8601（含时区） |
| 结束时间/时长 `end` | 可选 | 缺失时不编造——普通事件留空，脚本默认 +1h；全天事件留空默认单日 |
| 是否全天 `all_day` | 可选 | 只有明确"全天/一整天/某日"才置 true |
| 地点 `location` | 可选 | 无则 `null` |
| 参与者 `attendees` | 可选 | 无则 `[]` |
| 置信度 | 内部 | 决定追问/跳过，**不进 Event JSON** |

## 2. 相对时间换算（NFR-01 铁律，时间必须准）

**换算前必须先执行 `now` 取时间锚点**，再以 `now.date` 为"今天"换算；换算结果必须写进回复明示。

| 表述 | 换算规则 |
|---|---|
| 今天/明天/后天 | `now.date` + 0/1/2 天 |
| 下周 X / 下周三 | 以本周一为起点，下周该周几 |
| 本周 X / 这周三 | 本周该周几 |
| "周三"（未指明哪周） | **歧义 → 追问**（交互）/ 跳过（自动） |
| "下午3点"（未指明哪天） | **歧义 → 追问/跳过** |
| "N 天后 / N 小时后" | 从 `now` 精确加偏移 |
| "月底 / 下月初" | 无具体日期 → 追问/跳过 |

**周几→日期**：`now.date` 所在周的周一为基准。示例：`now.weekday` 是周五(索引4)，"下周三"= 周一 +7+2 天。

## 3. 默认时长

- 普通事件缺失结束时间：脚本默认 +1h，无需你算（Event JSON 里 `end` 可省略）
- 全天事件缺失结束时间：默认单日

## 4. 置信度分级与处置

| 级别 | 判定 | 交互模式 | 自动模式 |
|---|---|---|---|
| 高 | 主题 + 明确绝对时间，无歧义 | 直接 `create` | 直接 `create --journal` |
| 中 | 时间有明确表述但缺结束/地点等次要字段 | 补默认后 `create`，复述时明示假设 | `create --journal`（次要字段缺失不算歧义） |
| 低 | 缺开始时间 / 时间表述歧义 | **追问** | `journal skip`（reason 见下） |

跳过原因码（closed set，`journal skip --reason` 用）：
`NO_SCHEDULE` 无日程｜`AMBIGUOUS` 时间模糊｜`MISSING_TIME` 缺开始时间｜`LOW_CONFIDENCE` 置信度不足

## 5. 截止事项（deadline）识别与分流（FR-15/16/17）

**触发词（中英）**：截止、截止时间、请于…前提交、在此之前、DDL、deadline、due、submit by、due date、到期、交稿、交作业。

| 情形 | 分流 |
|---|---|
| 有具体时刻（"9月10日 17:00 前提交"） | 普通事件，`start`=该时刻（结束时间可省略） |
| 只有日期（"9月10日 截止"） | **全天事件** `all_day:true`，`start`=`YYYY-MM-DD`；脚本自动设当天 `reminder.all_day_at` 提醒 |
| "本周五前/月底前" | 无具体日期 → 追问/跳过 |

## 6. 全天事件判定

仅当出现"全天/一整天/某个整天/XX日（无时刻）"才置 `all_day:true`。有具体时刻即使只是 deadline 也按普通事件。

## 7. 截图输入（FR-08）

- 以聊天记录为主：识别消息中的时间、地点、人物、事项
- 截图中的相对时间同样按第 2 节换算
- 提取结果照常走字段表与置信度分流
