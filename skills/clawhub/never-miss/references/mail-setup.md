# 邮箱兼容性与专用密码指引（需求 §7）

> 用途：配置引导时向用户说明"专用密码"如何获取。**按需加载。**

## 前提

- 只支持标准 IMAPS（993 端口）
- 密码必须用**客户端专用密码 / 授权码**，不用登录密码（多数邮箱已禁止主密码直连）
- 不支持：仅 Web 端、仅 Exchange ActiveSync（POP3/EWS-only）——doctor 自检会明确报错

## 常见邮箱专用密码获取

| 邮箱类型 | 获取路径 | 状态 |
|---|---|---|
| Coremail（高校自建） | webmail → 设置 → 客户端专用密码 | 已实测 |
| QQ 邮箱 / 腾讯企业邮 | 设置 → 账户 → 开启 IMAP → 生成授权码 | 待验证 |
| 163 / 126 | 设置 → 客户端授权密码 | 待验证 |
| Gmail | Google 账户 → 安全性 → 应用专用密码（需先开两步验证） | 待验证 |
| iCloud 邮件 | Apple ID → 应用专用密码 | 待验证 |

## 配置引导话术

1. 询问账户必填项：`host`（IMAP 服务器）、`username`（邮箱地址）、`label`（别名，默认=邮箱地址）
2. 提示用户先到对应邮箱后台生成"专用密码/授权码"，再经 `secret set <邮箱>` 存入 Keychain
3. 若用户只有登录密码（不支持专用密码的邮箱）：明确告知风险，建议开启两步验证 + 专用密码后重试

## 常见服务器地址（示例）

- Coremail 高校：`mail.<学校域名>`（如 `mail.example.edu.cn`）
- QQ 邮箱：`imap.qq.com`
- 163：`imap.163.com`；126：`imap.126.com`
- Gmail：`imap.gmail.com`
- iCloud：`imap.mail.me.com`

> 不确定时请用户在其邮箱帮助页查询"IMAP 服务器地址"。
