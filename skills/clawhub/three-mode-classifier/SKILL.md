## I — 方法论骨架 (Interpretation)

书里把产业 Web3 实践切成三类，关键不是"用了什么链"，而是**改造组织形态的程度**与**融资导向的强弱**两条轴。

- **原生型**：从零长出一个新组织——新建共建社区，用功能型（境内）或权益型（境外）通证驱动，靠"按贡献分配"融人融智融市场融资源。典型如 IP STORY、OORT。
- **产业变革型**：不另起炉灶，而是把既有产业链拆成模块化任务、链上连续簿记，用"产业链改 + 共建社区 + 通证化"重塑底层商业逻辑。典型如红糖链品、某重工装备通证化平台。
- **链改-资产支持型**：最偏金融化，可看作资产支持贷款（ABL）的 V2.0——把优质资产上链、链上锁定现金流归还融资、分配规则写进智能合约，**不改变企业原有组织与共识结构**就完成"资产数字化—数据化—金融化"。典型如华润隆地充电桩、朗新收益权 RWA。

再叠一层 f12 的"二维矩阵 × 五大路径"：纵轴是资产六级转化（资源→要素→产品→资产→资本→金融），横轴是产业链环节（原材料/中间品/终端品/流通/消费/跨境）。两者交汇点对应五条可复用路径——数据资产化（海数交）、实物数字消费（红糖链品/马陆葡萄）、事业共同体任务通证化（道衍）、营销激励通证化（酒域灵境）、资产支持证券代币（朗新/协鑫）。**中式以产业变革型与原生型为主，链改型最敏感**，这是本判别器与美式"上来就代币化融资"最大的不同。

## A1 — 书中的应用 (Past Application)

### 案例 1：IP STORY（原生型）
- **问题**：创作者依赖中心化平台、收益被中介抽走，独立音乐人流媒体收入不足 15%。
- **方法论的使用**：用"是否新建共建社区 + 是否按贡献分配"两轴判别——作品信息上链确权、智能合约实时分润，属新建组织、非融资导向 → **原生型**。
- **结论**：以可编程数字资源 + 自动分润重构 IP 分配，创作者/合作者/传播节点按贡献获激励。
- **结果**：已在多领域落地，形成多方共赢生态（Justin Bieber《Peaches》全球实时版税分配）。

### 案例 2：马陆葡萄 RDA（产业变革型，而非链改型）
- **问题**：农产品流通溯源难、信息不对称、优质难优价。
- **方法论的使用**：在"产品资产化"阶段把全流程数据上链形成不可篡改资产凭证，是**以数据要素改造产业链**（实物数字消费路径），并不锚定现金流融资 → 判为**产业变革型**；若误判为"链改-资产支持型"会错误走融资导向合规结构。
- **结论**：实数融合 RDA 是境内"非金融"数字化赋能标杆，与红糖链品、长白数参同属农产品数字资产矩阵。
- **结果**：成为溯源与品牌溢价模式早期探索样本。

### 案例 3：朗新集团充电桩收益权 RWA（链改-资产支持型）
- **问题**：新能源充电桩存量大但流动性不足，传统融资依赖主体信用、门槛高。
- **方法论的使用**：锚定充电桩**收益权**（非所有权）、链上锁定现金流、智能合约自动分配，企业组织与共识结构不变 → **链改-资产支持型**；且境内不得直接发币，必须走香港监管沙盒 + 两链一桥境外路径。
- **结论**：以蚂蚁链 + IoT + 隐私计算搭建"两链一桥"，为境内资产境外合规发行探路。
- **结果**：2024 年于香港沙盒率先发行，为境内资产跨境 RWA 积累实践经验。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. **传统企业/地方产业**想"上链""数字化转型"，但被各种 Web3 说法绕晕，不知道自己该走哪条路、组织要怎么搭。
2. **内容创作者/咨询方**在写方案或做选题时，需要把一个具体项目（茶园、充电桩、白酒、农产品）准确归类为某类模式，避免误用术语。
3. **投资人/评审**拿到一个 Web3 项目，想先判断它是真做产业赋能还是变相融资盘，选型决定尽调重点。
4. **跨境/融资需求方**想把境内收益权拿去发 RWA，需要确认自己是否属于链改-资产支持型及其合规断点。
5. **创业者**在"做社区积分"和"做资产代币"之间摇摆，需要两轴定位来定方向。

### 语言信号（用户的话里出现这些就应激活）

- "我们/客户想做个**通证**/**上链**项目，但不知道走哪条路"
- "传统产业/茶园/工厂**怎么用 Web3 转型**"
- "想用**收益权/充电桩/电站**去**融资、发 RWA**"
- "这是原生 Web3 还是产业区块链？**组织要怎么改**？"
- "有人说我们这是 RWA，有人说是产业数字化，**到底算哪类**？"

### 与相邻 skill 的区分

- 与 **S4 · W-ABCD 真假 Web3 识别器** 的区别：S4 判定"是不是真·Web3 产业应用"（去伪存真），本 skill 在"已认定是真 Web3"之后，进一步判定"属于哪一类、怎么选型"。S4 看五要素齐不齐，本 skill 看组织改造度 × 融资导向两轴。
- 与 **S8 · RWA 落地流程与路径设计器** 的区别：S8 是链改-资产支持型被选定后的**工程作业手册**（十环节、跨境备案），本 skill 是选型阶段的**前置判别**——先判你是不是链改型，再交 S8 落地。
- 与 **S2 · 合规边界红线检查** 的区别：S2 回答"境内能不能做"，本 skill 回答"该走哪条路、三类合规差异为何不同"，两者在"判为链改型且拟境内发行"时会联动。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **三问定位（资产 / 组织 / 融资）**
   - 向用户确认三个问题：①锚定的是什么（实体资源/数据/现金流收益权）？②是否重建产业链组织与协作形态（有无共建社区、模块化任务协同）？③是否有融资导向（发币募资、锁现金流还贷）？
   - 完成标准：对"资产属性 / 组织改造度 / 融资导向"三者均给出明确答案，无模糊项。

2. **映射到三类模式**
   - 按两轴落点：组织新建、非融资 → **原生型**；组织重构产业链、弱融资 → **产业变革型**；组织不变、强融资、锁现金流 → **链改-资产支持型**。再用 f12 二维矩阵找对应路径（数据资产化/实物数字消费/事业共同体/营销激励/资产支持证券代币）。
   - 完成标准：唯一落定一类，并书面排除其余两类；给出所属五大路径之一。
   - 判停条件：若判为**链改-资产支持型**且拟面向境内发行 → 必须止步并提示"境内严禁代币化融资"，转交 S2/S8 走香港沙盒 + 证监会备案的境外路径，不得继续设计境内发币方案。

3. **给选型与组织建议**
   - 输出：所选模式 + 对应路径 + 组织形态建议（原生/产业型是否成立共建社区或事业共同体；链改型是否设 SPV 实现破产隔离）+ 合规边界提示（境内可做的"非金融"范围 vs 须出境环节）。
   - 完成标准：用户拿到一份"模式判定 + 路径 + 组织/合规要点"的结论清单，可直接用于方案或尽调。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **只想判断"这是不是真 Web3 / 是不是伪概念"**：用 S4（W-ABCD），本 skill 不做真假识别。
- **已确认为链改-资产支持型、只缺工程落地步骤**：用 S8（RWA 流程），本 skill 不做十环节作业。
- **只问"境内能不能发币/做稳定币"**：用 S2（合规红线），本 skill 不做单一合规裁决。
- **纯政策引用/法规条款查询**：作为引用保留，不构成模式选型问题。

### 作者在书中警告的失败模式

- **"伪 RWA"以"赋能实体"为名实为变相融资盘**（ce18 / ce02）：历史大量项目借"贡献即确权"叙事行集资之实，无真实分配审计、收益靠拉新而非产业现金流。判别器若只听叙事、不查现金流自偿性，会把融资盘误判为合规链改型。
- **"慢资产"与"快金融"错配**（ce06）：真实资产回款慢、链上金融 7×24 快，清算速度远超资产处置速度，监管真空期套利、事后追责。链改-资产支持型尤其要验"自偿性"（p17）。
- **跨境零售发售触碰证券法红线**（ce14 / ce15）：链改型若向不特定零售全球募资、无 KYC/合格投资者认证，易触发多法域追责与流动性踩踏。
- **概念窄化污名化**（ce01）：把一切 Web3 等同"RWAT 代币融资/P2P 暴雷"，会反过来误杀原生型与产业变革型的 legitimate 产业应用——判别器应分离"融资导向"轴，避免一刀切。

### 作者的盲点 / 时代局限

- 编写组含道衍数科（项目方）及多家 RWA 服务商，**天然带推广立场**，对链改-资产支持型失败案例与落地难度的披露可能选择性弱化（BOOK_OVERVIEW 批判段）。
- 过度聚焦"赋能实体"叙事，对境内监管**不确定性**着墨偏乐观；成稿于 2025 年，香港沙盒/稳定币全球合法化进程仍在快速演化，部分前沿实践可能已过时。
- 假设"通证激励必然持续激活贡献"，但实证不足——判别为原生型/产业变革型时，应提示"社区是否真能持续贡献"这一未被证明的假设。

### 容易混淆的邻近方法论

- **原生型 vs 产业变革型**：前者新建组织、后者改造存量产业链；都可能是非融资导向，区别在于"是否从零搭共建社区"还是"把公司间契约拆成模块协同"。
- **产业变革型 vs 链改-资产支持型**：前者重心在产业链逻辑重塑、弱融资；后者重心在现金流融资、组织不变。马陆葡萄（RDA 数据赋能）是产业变革型，朗新（收益权融资）是链改型——两者常因都"上链"被混为一谈，正是本判别器要拆开的。


### 合规红线与使用须知（普通用户必读）

本技能提炼自《价值互联网产业应用蓝皮书（2025）》（蓝皮书编写组，主编：梁超杰）第三篇·第五章「合规边界」，仅供风险识别与科普参考，**不构成任何投资建议、法律意见或投资邀约**。

- 中国境内开展价值互联网与通证经济产业应用，**不得涉及通证代币化等加密金融行为**，应聚焦"非金融"的数字化赋能（溯源、贡献计量、RDA 真实数据资产等）。
- 包括稳定币在内的虚拟货币，**在中国境内发行与交易属于非法金融活动**（央行等十部门 2021 年《关于进一步防范和处置虚拟货币交易炒作风险的通知》）。境外交易所、项目向中国境内居民提供服务同样属非法。
- **连带责任无死角**：不仅直接参与违法，为境外违规项目提供账户、资金划转、技术支持也依法追责——"只是帮忙做技术"不能免责。
- 任何以"Web3/区块链"为名、要求充值、拉人头返利、承诺升值预期的，极可能是资金盘，**请勿参与、勿投资、勿转发**。

> 引用原文："不能涉及通证代币化等加密金融行为，而应聚焦探索'非金融'的数字化赋能产业提效方向。""包括稳定币在内的虚拟货币无法满足 KYC、AML 等要求，在中国境内发行与交易虚拟货币属于非法金融活动。" —— 第三编·第五章（合规边界）／ p02、ce03
