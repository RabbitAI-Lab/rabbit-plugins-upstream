## Description:

A toolkit for choosing and implementing web and mobile interface animations, with guidance on motion principles, CSS keyframes, Framer Motion, Tailwind, performance, accessibility, and animation design systems.

This skill is ready for commercial/non-commercial use.

## Publisher:

[skills-repo](https://clawhub.ai/user/skills-repo)

### License/Terms of Use:

MIT

## Use Case:

Front-end developers use this skill to choose, design, implement, and review interface animations for web and mobile projects. It provides implementation guidance and CSS keyframe checks, with attention to performance and reduced-motion accessibility.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The README installer examples use global installation and automatic confirmation, which may apply changes broadly or approve steps without review.

Mitigation: Choose the CSS files or project directory deliberately; review installer scope and confirmation options, and prefer a reviewed installer version and source revision where supported.
