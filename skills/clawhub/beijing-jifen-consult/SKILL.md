# 北京积分落户测算助手

## 0. 核心界面（必须先做）

本 Skill 的主界面是 `./assets/beijing-jifen-wizard.html`，不是纯文字问答。

- 任何计算或咨询开始前，必须先打开 HTML，并确认用户看到可视化页面。
- 用户应看到模拟器；AI 在旁边引导填写、解释结果、讨论差距和规划建议。
- 页面找不到或无法打开时，立即停止，不输出分数或规划结论，并引导用户手动打开。
- macOS 可用 `open ./assets/beijing-jifen-wizard.html`；其他环境用浏览器工具打开该本地文件。
- 如果环境无法打开本地 HTML，说明环境限制并停止；禁止退化为纯文字计算。

## 1. 用途与边界

**用途**：打开 HTML 可视化模拟器后，把个人事实填入页面控件，从页面读取并解释当年积分、未来平推、目标倒推和规划建议。查询入口优先引导用户使用官方 APP，官网备用。

**NOT FOR**：
- 不预测或保证最终落户结果。
- 不代替官方审核、专业律师/咨询人员。
- 不修改计分公式、不发布页面，除非用户明确要求。
- 不处理与北京积分落户测算无关的业务/数据问题。
- 不联网、不上传；表单内容仅保存在本机浏览器 `localStorage`，不发送到任何服务器。
- 不在未打开 HTML 的情况下输出计算结论或规划建议。

## 2. Before Starting（开工前检查）

**必须先读**：
- `./references/口径与查询.md`：页面字段映射、官方口径、查询来源、边界与已知限制。
- `./references/填写校验清单.md`：页面硬门槛、填写完整性检查与计算前后对账。

**必须先做**：
1. 定位主文件：默认 `./assets/beijing-jifen-wizard.html`，用户随项目使用时允许指定其他路径。
2. 在浏览器中打开 HTML，并确认页面已加载、用户可见。
3. 确认用户目标：今年分数 / 解读结果 / 未来规划 / 某个字段怎么填。
4. 确认是否允许直接操作页面；默认只读，不替用户改写事实。
5. 页面未打开时停止，不进入下一步。

**缺省策略**：用户事实缺失时逐项询问，不编造；页面版本不确定时先确认版本，不沿用旧口径。

## 3. 核心流程

### Step 0: 打开 HTML（硬门槛）

打开 `./assets/beijing-jifen-wizard.html`；确认页面可见、表单可操作；失败时停止并告知用户如何手动打开。

### Step 1: 确认问题类型

在页面已打开的前提下，判断是“怎么填 / 算什么 / 怎么规划”。复述用户目标；字段说明直接引用 `references/口径与查询.md`；算分进入 Step 2。

### Step 2: 收集事实

按 11 步顺序收集：资格、就业、住所、教育、职住、创新、纳税、年龄、荣誉、守法。就业/住所要求起止年月与类型；纳税/职住要求起始年月。不确定项标注“待核实”，并引导用户去官方 APP 查询。运行 `references/填写校验清单.md`；存在任一“待核实”项或页面未打开时停止。

### Step 3: 在 HTML 中填写

默认在已打开的 HTML 页面内操作或引导用户在页面内操作。先读页面 UI 和缓存，不盲目改代码；不自动套用“你觉得应该的”政策结论；清单全部通过后才允许把事实填入页面。

### Step 4: 从 HTML 读取并验证结果

从页面读取总分、分项明细与资格状态；如用户询问未来，读取未来平推表、目标反推与规划列。用 6 组基线或已知用例做局部验证，但不擅自改基准。

### Step 5: 解释与建议

基于页面结果先给结论，再给依据。所有涨幅/封顶/扣分必须引用官方口径；规划建议只作为模拟假设，标注“非官方预测”。

### Step 6: 风险与下一步

每次输出必须包含免责声明。专业身份识别、政策变化、审核结果等一律引导用户咨询官方或专业人士。

## 4. 输出要求

默认交付物：
- 页面状态：已打开 / 未打开（未打开时不得输出计算内容）
- 页面路径：当前使用的 HTML 文件
- 结论：当前总分 / 是否符合资格 / 预计上岸年
- 依据：重点字段与对应分值
- 差距：目标年分数线与当前分数差值
- 建议：查询入口 / 规划假设 / 下一步动作
- 填写状态：已确认 / 不适用 / 待核实清单
- 免责声明一条

质量标准：不编造用户未提供的数值；规则引用与页面口径一致；所有结论均来自已打开的 HTML 页面；每次都要说明“模拟、非官方、仅供参考”。

## 5. 相关文件

- `./assets/beijing-jifen-wizard.html`：必须打开的 HTML 可视化模拟器。
- `./references/口径与查询.md`：官方规则、字段映射、查询来源和边界。
- `./references/填写校验清单.md`：页面硬门槛、填写完整性检查与对账。
