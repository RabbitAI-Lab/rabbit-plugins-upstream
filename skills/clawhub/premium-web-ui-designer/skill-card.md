## Use Case:

### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: Automatic activation for broad frontend design requests could apply the skill when a user intended a narrower implementation task.

Mitigation: Invoke the skill explicitly only when frontend or UI redesign help is wanted.

Risk: Generated design or code changes could introduce incorrect frontend behavior, inaccessible UI states, or visual regressions.

Mitigation: Review proposed changes, preserve accessible semantics, and verify at desktop and mobile viewport widths before deployment.
