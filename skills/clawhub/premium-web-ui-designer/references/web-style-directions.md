# Web Style Directions

Pick one direction and adapt it to the product.

## Quiet Enterprise

Best for SaaS, CRM, analytics, admin tools, finance, operations.

- Neutral foundation with one restrained accent.
- Compact controls, tables, filters, tabs, and status chips.
- Thin borders, subtle surfaces, minimal shadow.
- Typography: tight, readable, hierarchy by weight and size.
- Avoid large marketing sections and decorative art.

## Editorial Premium

Best for portfolios, agencies, brands, product showcases, luxury goods.

- Large confident typography.
- Strong image art direction.
- Asymmetric but disciplined layouts.
- Fewer cards, more full-width sections and editorial rhythm.
- Use whitespace as a premium signal.

## Modern Creative Tool

Best for editors, generators, visual tools, dashboards for creators.

- Command bar or inspector style controls.
- Clear canvas/work area.
- Compact icon buttons with tooltips.
- Dark or light theme with high contrast and refined accent states.
- Strong empty/loading states.

## Data Studio

Best for metrics, reports, monitoring, BI, research.

- Dense information architecture.
- Clear filters and comparison tables.
- Charts with restrained palettes and readable labels.
- Status colors used sparingly and consistently.
- Avoid decorative backgrounds behind charts.

## Common Anti-patterns

- One-note color palettes.
- Random gradients behind normal product UI.
- Cards nested in cards.
- All content at the same visual weight.
- Inconsistent radii, borders, shadows, and padding.
- Desktop-only layouts that collapse awkwardly on mobile.
