# middle-aged-social-comment

> 面向 30-50 岁中年读者的微信公众号社会评论文章全流程写作工具。从热点挖掘、选题筛选、素材拆解、金句提炼到风格化成稿，严格遵循非线性叙事、思维毛边、瑕疵美学的灵性写作风格，产出有深度共鸣的社会观察类评论文章。

## Features

- **选题挖掘与定位**：检索近 3-7 天全网热点，按「流量优先级 + 深度价值」筛出中年群体高共鸣、有评论纵深的选题，排除纯娱乐八卦。
- **结构化素材拆解**：将选题落地为现象 / 成因 / 影响 / 解法四大模块，每个模块配 3-5 个具象生活场景，拒绝空泛理论。
- **核心金句提炼**：围绕「痛点戳心、本质揭露、价值升华」生成 5-10 句克制有力的金句，标注推荐使用位置。
- **风格化成稿**：严格遵循「非线性开场 / 思维毛边 / 瑕疵美学 / 隐性共情」四则铁律，标配标题 + 非线性开篇 + 分层论述 + 长短双版本结尾 + 互动话题。
- **优化与收尾**：支持篇幅伸缩、结尾双版本、调性强化 / 弱化，输出前跑 8 条质量自检清单（禁用词、感叹号、场景切入等）。
