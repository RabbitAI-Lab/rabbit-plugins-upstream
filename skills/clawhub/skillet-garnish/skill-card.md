## Description:

Use when auditing or fixing discoverability metadata for a website before publication, including titles, descriptions, canonical URLs, robots policy, Open Graph, structured data, and sitemaps. Not for content strategy or keyword research.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers use Garnish to audit a website's titles, descriptions, canonical URLs, social previews, indexing directives, structured data, and sitemap before publication, then make narrowly scoped metadata fixes when requested.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Incorrect metadata or indexing changes could misrepresent pages or affect live search discovery.

Mitigation: Review proposed changes against the site's declared policy and explicitly approve changes affecting live indexing before applying them.

Risk: The referenced check and plate skills are not included in this release.

Mitigation: Review those companion skills separately when available, and verify fixes against rendered output before making readiness claims.
