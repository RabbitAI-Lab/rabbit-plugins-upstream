## Description: <br>
Uploads PDFs to a compression API with adjustable image quality and DPI settings, supporting single-file or batch compression and returning download links. <br>

This skill is ready for commercial/non-commercial use. <br>

## Known Risks and Mitigations: <br>
Risk: PDF contents and API keys may be sent to a third-party compression API. <br>
Mitigation: Use only an approved compression provider, avoid confidential, regulated, or proprietary PDFs unless the service is approved, and store API keys securely. <br>
Risk: The artifact uses a placeholder API endpoint for the compression request. <br>
Mitigation: Replace the example endpoint with a trusted provider endpoint before running requests with real PDFs or API keys. <br>
