# 内容合规预检

> 发布前给短视频/直播/社交文案做合规预检：5类违禁词库77条、各平台限流口径、逐句改写对照表、发布前自检清单。技术触发词「违禁词检测、直播合规、文案改写」。口语触发词「这段口播文案发出去会不会被限流、我想把用户引到私域社群，又不被判违规，这段话该怎么改、给我一份短视频和直播的发布前自检清单，把各平台红线都覆盖到」。输出可直接使用的清单、对照表与行动项。仅作规划与清单辅助，不构成法律/税务/医疗专业意见，需人工复核。

## 这个 Skill 做什么

短视频与直播内容合规顾问：
把该领域最容易出错、也最没人负责的环节，拆成**可执行的判断步骤 + 检查清单 + 固定输出格式**。
你给案情/材料，它输出该问什么、该查什么、该准备什么、风险点在哪。

## 什么时候会触发

当你要处理以下事情时，这个 Skill 会被自动激活：

- 这段口播文案发出去会不会被限流？帮我逐句过一遍并给改写版本
- 帮我扫一遍产品文案里的绝对化用语、医疗功效和金融承诺，逐条给改写
- 我想把用户引到私域社群，又不被判违规，这段话该怎么改？
- 给我一份短视频和直播的发布前自检清单，把各平台红线都覆盖到

## 边界

- 不构成法律 / 税务 / 医疗专业意见，最终判断需人工复核
- 遇到需要执业资格才能定论的问题，它会明确说"建议转专业机构"
- 单次购买、单人授权使用；**不可转售或再分发**
