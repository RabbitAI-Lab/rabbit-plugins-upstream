## 1. C1 绝对化用语（25 词条 / 22 独立词形）

**脚本原表**：`国家级、最高级、最佳、第一品牌、独家、首选、顶级、极品、至尊、万能、100%、绝对、全网最低、销量第一、独家配方、永久、秒杀、史无前例、史上最低、最、超大、超低价、全民、第一、唯一`

**脚本记录的典型后果**：限流 / 广告法风险（虚假宣传）

### 1.1 判定要点（这些情况其实不构成违规）

C1 是**声明类**违规：判定核心是「这个词在做排名/极限/唯一性的宣称」，而不是「这个字出现了」。以下情况安全——**注意最后一列是脚本的真实判定行为，报告时照实写**：

| 场景 | 命中的词 | 为什么安全 | 脚本实际行为（已实测） |
|---|---|---|---|
| 「**第一步**，先下载 App」 | 第一 | 序数词，表示流程次序，不是排名宣称 | 词层自动豁免，报告中列为「无需修改」 |
| 「第一时间联系你」 | 第一 | 序数词 + 时间副词 | 词层自动豁免 |
| 「第一版更新」 | 第一 | 版本序数 | 词层自动豁免 |
| 「这是**唯一的办法**」 | 唯一 | 「唯一的办法/选择/方式/路径」是正当表达 | 词层豁免 **且** 句式层也排除 → 完全不报 |
| 「最近几天」「最终价格」「最新款」「最多可领 3 份」 | 最 | 副词 / 数量限定用法 | 词层自动豁免 |
| 「**永久**停靠」「**永久**居民」 | 永久 | 客观状态描述，非服务承诺 | 词层自动豁免（要求「永久+停靠/居民/保固/免费停」后面紧跟标点或行尾） |
| 「**独家**报道 / 独家专访」 | 独家 | 媒体新闻属性用法 | ⚠️ **词层豁免，但句式层仍会命中**「排他性宣称」，最终报告里仍会出现，理由标注为「句式风险：排他性宣称」 |
| 「**绝对**路径 / 绝对值」 | 绝对 | 技术术语 | 词层自动豁免 |
| 「免费停车 / 免费试用」 | — | 场景说明，非「白送」诱导 | 「免费」**本身不在词表**（表内是「免费送」「免单」「点击领红包」），所以这类表达根本不产生命中 |

**三条必须记住的判定边界**（这是本节最容易被做错的地方）：

1. **「永久」的豁免要求后面跟非中文字符**。所以「永久停靠」「永久居民」豁免，而「永久保固条款」「永久免费停靠」「永久停用该功能」**都会报**（后面还跟着汉字，豁免正则不成立）。
2. **「最」的第三条豁免是整行匹配**。脚本对 `最近|最终|最后|最新|最多|最高|最低|最大|最小` 做的是**整行查找**——只要这一行里出现过其中任意一个，**该行所有「最」都被豁免**。这是**漏报风险**：例如「这是最贵的产品，最近到货」里的「最」不会被报出来。遇到「最」请人工再确认一遍。
3. **「独家报道」在词层豁免了，但句式层会把它捞回来**。句式规则的排除名单只有「办法/选择/方式/路径/建议」四个词，所以「独家报道」「独家配方」「唯一的孩子」都会被「排他性宣称」命中。**报告时要说清是句式命中，不要写成词命中。**

### 1.2 等效替换写法（3 组）

| 原写法 | 替换成 | 为什么效果不降 |
|---|---|---|
| 「销量第一」 | 「已售 X 单」「复购率 X%」 | 用可核验数字替代排名，可信度反而更高 |
| 「全网最低价」 | 「本场活动价 X 元，比日常价低 Y 元」 | 只陈述自己的价格，不做跨平台比较，同时给出对比锚点 |
| 「独家配方」 | 「自研配方」「专利号 ZLXXXXXXXX」 | 用来源和技术编号替代排他性形容词，专业度更高 |

| # | 改写前 | 改写后 | 说明 |
|---|---|---|---|
| 1 | 我们的面霜是全网最低价，只要 99 元 | 这款面霜活动价 99 元，日常价 129 元，今天下单省 30 元 | 删比较级，改成自身价格 + 差价锚点，促单力不减 |
| 2 | 销量第一的洗发水，闭眼入 | 累计卖出 12 万瓶，复购率 38% | 排名换成两个可查数字，说服力更强 |
| 3 | 独家配方，别的牌子都没有 | 自研配方，成分表在详情页第 3 张 | 用「自研」+可查证位置替代排他宣称 |
| 4 | 100% 好评，闭眼冲 | 店铺评分 4.9 分，1.2 万条评价里 96% 是好评 | 「100%」在真实评价里通常不成立，给出分项数据反而更可信 |
| 5 | 这款机子性能第一，是宇宙最强 | 这款跑分 165 万分（同价位段前 3%），散热实测 42℃ | 把「第一」落到具体可验证的数据上 |
| 6 | 永久质保，再也不用操心 | 质保 3 年，期间非人为损坏直接换新，到期前提醒你 | 去掉无期限承诺，给出明确年限 + 到期提醒，反而让人放心 |

### 1.4 特别提醒：C1 有一个平台硬开关

脚本第 268 行：**C1 命中且平台是抖音/快手/淘宝时，直接判 🔴 高危**（不走中危）。实测「这是最好的产品」：

- 抖音 → 🔴 高危
- B站 → 🟡 中危

这不是平台公开细则，是词库积累出的实际处置差异。**在抖音/快手/淘宝发 C1，等于直接冒高危**，优先改。

### 1.5 C1 词的完整平台敏感度（实测矩阵）

纯 C1 词在六平台的等级**分两组**：

| 分组 | 词 | 内容平台 | 抖音 | 视频号 | 快手 | 淘宝/京东 | B站 |
|---|---|---|---|---|---|---|---|
| 21 个词 | 国家级、最高级、第一品牌、独家、首选、顶级、极品、至尊、万能、100%、绝对、全网最低、销量第一、独家配方、永久、史无前例、史上最低、超大、全民、第一、唯一 | 🟡 | 🔴 | 🟡 | 🔴 | 🔴 | 🟡 |
| **1 个词** | **最佳** | 🔴 | 🔴 | 🟡 | 🔴 | 🔴 | 🟡 |

**为什么「最佳」单独成一组？** 「最佳」二字里含有「最」——「最」是 **C5+C1 双归属词**，在内容平台 C5 加严（+1）时被提升到 🔴。其余 21 个纯 C1 词不含 C5 词素，内容平台仍是 🟡。

> **实操提醒**：凡「最」开头的词（最、最佳、最好、最优、最强……），**在内容平台一律按 🔴 处理**。

**C1 内部也要分轻重**：脚本对纯 C1 词不做二次分级，所以「国家级」和「唯一」在脚本里等级相同。但**实际处置代价不同**——「国家级」「最高级」这类词在没有授权文件时属于典型的虚假宣传认定对象，比「唯一」「首选」风险更高。**这一层判断脚本做不了，需要人工补。**

## 2. C2 医疗功效与健康承诺（14 词条 / 14 独立词形）

**脚本原表**：`立即见效、根治、包治、无副作用、100%有效、神药、抗癌、防癌、美容养颜、排毒、延年益寿、偏方、零风险、保证`

**脚本记录的典型后果**：下架 / 封号 / 投诉 / 可能涉虚假宣传（后果最重）

### 2.1 判定要点

C2 是**五类里唯一可能引发消费者投诉与行政处罚的一类**，判定不看温和程度，看「是否构成疗效承诺或疾病治疗宣称」：

- **食品/保健品/普通护肤品一律从严**。即便是「美容养颜」「排毒」这种看起来温和的词，脚本也全部归入 C2——因为它们是**功效宣称**，而普通食品化妆品不得宣称保健功能。
- **「保证」的判定看搭配**：「保证质量」属售后承诺，风险低于「保证见效」「保证有效」；但脚本按字面收录，命中即需人工复核。
- **「偏方」「神药」在任何品类都是雷**，包括中医理疗、养生馆、食疗账号——它们是「暗示非规范疗效」的强信号，投诉里最容易被引用。
- **「零风险」常被当成安全用语，实际上是绝对化承诺**：投资、健康、理财全适用。
- **例外提示（不是免责）**：科普内容引用疾病名称（「防癌食物的常见误区」）本身不违规——脚本的 `QUOTE_RE`（引号内引用）会把这类降级为提示级，但**不加引号的直接宣称仍会命中**。做科普内容请把引用部分明确加引号或改为「医学上并不认为……」的转述句式。

### 2.2 等效替换写法（3 组）

| 原写法 | 替换成 | 为什么效果不降 |
|---|---|---|
| 「3 天立即见效」 | 「多数用户在 X 天可感知变化，个体有差异」 | 给区间 + 条件，比绝对承诺更可信，也避免投诉 |
| 「根治痘痘」 | 「针对痘痘肌日常护理的成分方案」 | 从「治病」降到「护理场景」，账号能长期活着做这个品类 |
| 「无副作用，纯天然」 | 「成分表见下方 / 不含酒精与香精」 | 给可核验的成分事实，替代无法证明的整体保证 |

### 2.3 改写前后对照

| # | 改写前 | 改写后 | 说明 |
|---|---|---|---|
| 1 | 3 天立即见效，祛痘不留痕 | 多数用户 3-5 天可感知出油减少，敏感痘肌建议先做局部测试 | 给区间 + 适用人群 + 提示，比「立即」更可信也避免投诉 |

## 3. C3 金融与收益承诺（7 词条 / 5 个独占词形）

**脚本原表**：`稳赚、暴富、投资理财、保本、高收益、返利、割韭菜`

**脚本记录的典型后果**：限流 / 金融类违规（后果重）

### 3.1 判定要点

C3 少但极重——这 7 个词几乎全部是**金融业务的准入门槛词**：

- **凡涉及资金、收益、杠杆、返现的内容，一律按金融违规处理**，不管你有没有金融牌照。个人账号做理财内容被限流是常见结果。
- **「返利」既是 C3 又是 C5**（见 §7），因为「返利」既是收益承诺也是诱导互动手段，两头都踩。
- **「割韭菜」是攻击性表述**，脚本给它的改法是直接删除——它同时构成对同行的贬损（与 §8 第 1 条呼应）。
- **「投资理财」的特殊性**：这个词本身不违规，违规的是**以它为壳做收益承诺**。脚本把「投资理财」归入 C3，是因为在短视频语境里它几乎只与收益宣称连用。做纯知识科普（如「基金定投的三个常见误区」）时人工复核可降级，但**不要在同一段里出现「投资理财 + 高收益/稳赚」**。
- **例外提示**：「投资理财」在**财经机构官方账号**的持仓公告语境中属正当使用——但个人账号不具备这个前提。

### 3.2 等效替换写法（3 组）

| 原写法 | 替换成 | 为什么效果不降 |
|---|---|---|
| 「稳赚不赔」 | 「按规则分配，不承诺收益」 | 从承诺改成机制描述，反而显得专业克制 |
| 「保本」 | 「本金由 XX 机构托管」 | 用机制替代保证，风险提示本身是可信度来源 |
| 「年化 30% 高收益」 | 「历史区间 X%–Y%（仅供参考，不构成收益承诺）」 | 给区间与免责声明，去掉单一数字的诱导 |

### 3.3 改写前后对照

| # | 改写前 | 改写后 | 说明 |
|---|---|---|---|
| 1 | 跟着我买，稳赚不赔 | 按规则分配，不承诺收益 | 承诺改为机制 |
| 2 | 保本保息，安心躺着 | 本金由第三方机构托管，收益按规则分配 | 去掉「保本」，保留「安心」的情绪价值 |
| 3 | 一年暴富不是梦 | 复盘一下我的实操记录，也说说踩过的坑 | 情绪标题换成内容承诺，不碰收益词 |
| 4 | 高收益，年化 30% 起 | 历史区间 8%–15%，仅供参考，不构成收益承诺 | 单一高数字 → 区间 + 免责 |
| 5 | 邀请返利 20%，拉人拿钱 | 按平台活动规则发放奖励，规则见活动页 | 去掉「返利」诱导，保留奖励信息 |
| 6 | 这波操作就是割韭菜 | 这里说说我是怎么判断风险点的 | 攻击性表述换成内容定位 |
| 7 | 投资理财入门课 | 理财入门知识科普（不作投资建议） | 去掉业务名，加科普与免责定位 |

## 4. C4 站外引流与导流（13 词条 / 7 个独占词形）

**脚本原表**：`微信转账、加微信、私聊、扫码、引流、加我、私域、免费送、免单、点击领红包、亏本甩卖、抽奖、中奖`

**脚本记录的典型后果**：限流 / 私域违规 / 账号处置

### 4.1 判定要点

C4 是**平台最在意的一类**——不是因为词本身，而是因为它直接冲击平台的流量闭环：

- **「私聊」「加我」「加微信」三个词在脚本里都命中，但等级会因平台而变**。脚本 `PLATFORM_STRICT` 里，内容平台对 C4 加严（+1），抖音对 C4 加严（+1），而视频号、快手、淘宝/B站 不加严。但要注意：**这是脚本记录的加严系数，不代表视频号/淘宝就完全没有导流管控**——脚本只是没有为这几个平台叠加等级。实际发布仍应按 §5 的平台差异执行。
- **「私域」是词库里的高频事故词**：直播里说「拉你进私域」是典型的账号处置触发点。
- **「扫码」要看扫的是什么码**：扫平台内商品码、扫直播间礼物码属正常；扫微信个人码、扫进群码属于站外引流。脚本按字面收录，需人工判断码的归属。
- **「免费送」「免单」「抽奖」「中奖」「点击领红包」「亏本甩卖」6 个词同时属于 C4 和 C5**（见 §7）：它们既是导流钩子，也是诱导互动手段。**在直播里这 6 个词的处置代价高于短视频**——因为实时流量无法撤回。
- **「微信转账」是最硬的一个**：绕开平台担保交易，既是导流也是交易安全问题，几乎无改写空间，唯一的合规路径是走平台担保。

### 4.2 等效替换写法（3 组）

| 原写法 | 替换成 | 为什么效果不降 |
|---|---|---|
| 「加微信领资料」 | 「主页简介有完整说明，站内可以问我」 | 引导动作从「站外」变成「站内」，转化路径仍在 |
| 「扫码进群」 | 「平台内粉丝群入口在主页」 | 同上，且平台自己会发群入口 |
| 「私信我发红包」 | 「站内私信我，我发给你」 | 只换主语，指令不变，转化路径不变 |

## 5. C5 诱导互动与促销套路（15 词条 / 4 个独占词形）

**脚本原表**：`错过再等一年、最后一天、诱导、好评返现、秒杀、亏本甩卖、免费送、免单、抽奖、中奖、点击领红包、返利、割韭菜、最、超低价`

**脚本记录的典型后果**：限流 / 用户投诉（效果损失最大）

### 5.1 判定要点

C5 的核心不是「违法」，是**「套路感」**——平台和用户都反感，因此这一类**效果损失最大**：不违规但限流、或者用户反感导致完播率与转化率双降。

- **「最后一天」「错过再等一年」的判定标准是「真假」**：真实截止时间 ≠ 虚假制造稀缺。真实活动有明确日期，写「最后一天」是合规的；每月都用「最后一天」就是虚假稀缺，属于典型投诉点。
- **「诱导」这个字本身通常出现在「不做诱导」这类自我声明里**，脚本的 `NEG_RE` 会把否定语境整条跳过，所以**正常句子里的「诱导」多半不会命中**（脚本测试中「他说『稳赚不赔』」这种引号引用会被降级处理）。真正会被命中的是「诱导互动」「诱导评论」等主动描述。
- **「好评返现」是争议焦点**：平台对「以利益换评价」普遍不认可，但如果走平台官方的晒单返现活动，则属合规玩法。改法是**明确走平台活动**，而不是私下返现金。
- **「秒杀」「超低价」「最」「免费送」「免单」「抽奖」「中奖」「返利」「割韭菜」「亏本甩卖」「点击领红包」全部与 C1/C3/C4 交叉**，处理时按最高优先级类别走（见 §7）。
- **「最」在这里也归 C5**，脚本对它的默认判定是「诱导互动与促销套路」——因为它最常出现在「史上最」「最优惠」这类促销修饰里。

### 5.2 等效替换写法（3 组）

| 原写法 | 替换成 | 为什么效果不降 |
|---|---|---|
| 「最后一天」 | 「本场优惠至 X 月 X 日 X 时」 | 给具体时间点，可信度更高，用户反而更愿意当天下单 |
| 「错过再等一年」 | 「下一批 X 月 X 日开售，具体以店铺公告为准」 | 如实说下批时间，把「等一年」的焦虑换成具体预期 |
| 「好评返现 5 元」 | 「晒单返 XX（走平台官方活动，规则见活动页）」 | 从私下交易变成平台活动，参与率通常更高 |

|---|---|---|---|
| 1 | 最后一天，最后一次，别错过 | 本场优惠至 3 月 18 日 24:00，到时恢复日常价 | 真实时间替代情绪倒计时 |
| 2 | 错过再等一年 | 下一批 4 月 5 日开售 | 如实说下批时间 |

## 6. 「最该先改」的顺序（代价分级）

脚本对五类的后果记录不同，实际处置代价也不同。按**从重到轻**排：

| 代价 | 对应类别 | 具体表现 | 用户最该先改什么 |
|---|---|---|---|
| **下架 + 封号 + 投诉** | **C2 医疗功效与健康承诺** | 商品下架、直播封禁、买家发起投诉，严重的可能涉及虚假宣传责任 | 所有疗效词、疾病词、效果时限词。这是唯一一类「改晚了就没救」的 |
| **金融类违规** | **C3 金融与收益承诺** | 限流起步，严重的资金相关功能被限制 | 收益数字、保本措辞、业务名（个人账号尤其注意） |
| **账号处置** | **C4 站外引流与导流** | 单条限流 → 频次累计 → 私域功能被封 | 留联系方式的所有说法，逐句换成平台内闭环 |
| **限流 + 投诉** | **C5 诱导互动与促销套路** | 限流不一定发生，但用户反感直接打击转化；虚假稀缺被举报会引发投诉 | 「最后一天」「免费送」「返现」这类——**这些改动成本最低、收益最高** |
| **限流 + 广告法风险** | **C1 绝对化用语** | 抖音/快手/淘宝直接判高危；其他平台多为限流 | 排名、极限、唯一类形容词 |

**给用户的排序建议**（改写时先动哪句）：

1. 先扫 **C2 / C3**——这两类后果最重，一票否决。
2. 再扫 **C4**——尤其是「微信转账」「加微信」「私聊」「私域」，成本低（换成站内闭环）但不换就持续累积。
3. 再扫 **C5**——这一步**不降效果反而提效果**，因为把虚假稀缺换成真实稀缺，转化率通常上升。
4. 最后处理 **C1**——C1 改动量最大，但对非抖音系平台来说优先级靠后。

## 7. 多归属词与处理优先级

### 7.1 处理优先级规则

脚本 `PRIORITY = ["C2", "C3", "C4", "C5", "C1"]`，即 **C2 > C3 > C4 > C5 > C1**。

多归属词在扫描时按这个顺序取**最高优先级类别**作为主判类别（`WORD_CATS` 已按此排序），并用该类别的等级与平台加严系数定级。

**实操含义**：

- 「免费送」在 C4 和 C5 都收录 → 主判按 **C4** 走，等级 🔴 高危，因为它同时是导流钩子。
- 「返利」在 C3 和 C5 都收录 → 主判按 **C3** 走，等级 🔴 高危。
- 「秒杀」「最」「超低价」在 C1 和 C5 都收录 → 主判按 **C5** 走（脚本 `WORD_CATS` 中 C5 排在 C1 前，因为优先级 C5 > C1）→ 默认 🟡 中危；但在抖音/快手/淘宝因 C1 加严规则另按高危处理。

### 7.2 11 个多归属词全表

| 词 | 归属类别（按优先级） | 主判 | 为什么两个类别都要管 |
|---|---|---|---|
| 秒杀 | C5 + C1 | C5 | 既是促销套路也是绝对化宣称 |
| 最 | C5 + C1 | C5 | 同上；且 C1 侧在抖音/快手/淘宝会被加严 |
| 超低价 | C5 + C1 | C5 | 同上 |
| 返利 | C3 + C5 | C3 | 既是收益承诺又是诱导互动 |
| 割韭菜 | C3 + C5 | C3 | 既是金融攻击性表述也是互动套路 |
| 免费送 | C4 + C5 | C4 | 既是导流钩子也是白送诱导 |
| 免单 | C4 + C5 | C4 | 同上 |
| 点击领红包 | C4 + C5 | C4 | 同上 |
| 亏本甩卖 | C4 + C5 | C4 | 同上 |
| 抽奖 | C4 + C5 | C4 | 同上 |
| 中奖 | C4 + C5 | C4 | 同上 |

### 7.3 只属单一类别但常被误判的词（重要）

以下 3 个词**只在一个类别里**，但用户常以为它们多归属：

- **「独家配方」只属 C1**（不在 C3）。它的问题是绝对化宣称，不是收益承诺。
- **「独家」「第一」「唯一」「永久」都只属 C1**。它们在句式层另有命中（见 §8），但词层面只有 C1。
- **「保证」只属 C2**（不在 C1）。它在金融语境里也危险，但脚本按 C2 定级。

### 7.4 多归属词的统一处理原则

一个词多归属时，**改一次要同时满足两个类别的要求**，否则改完还剩一个雷：

以「免费送」为例：
- 只改 C4 面（改成「主页领取平台内红包入口」）→ 仍然是 C5 诱导 → 仍限流。
- 只改 C5 面（改成「0 元领」）→ 仍然像站外引流钩子 → 仍高危。
- **正确改法**：一次改到位——「0 元领，真实限量 100 份，主页平台内入口，3 月 18 日 24:00 截止」：C4 落点进平台 ✓、C5 真实稀缺 + 规则透明 ✓。

### 8.1 句式的四条使用说明（均为实测结论）

1. **句式命中不受平台加严影响**：脚本对 `PATTERN` 命中的等级只按标签判断（标签含「攻击」「暗示」「结果」「绝对」→ 🔴，否则 🟡），**不加平台系数**。所以第 1、2、8、9 条是全局 🔴，其余是全局 🟡。
2. **否定语境会被跳过（词级 + 句式级都跳）**：脚本 `NEG_RE` 匹配到「不承诺 / 不保证 / 严禁 / 请勿 / 避免使用」等否定表述时整条不报。实测「请勿私下交易」「禁止保本稳赚」→ 无命中。但**不要靠这个规避**，它是给合规声明用的，不是给违规话术用的。
3. **引号降级只作用于词级命中**：脚本 `QUOTE_RE` 判定命中位置在「」『』""'' 内时，等级上调一级（🔴→🟡，🟡→🟢），理由标注为「引用他人原话」。**句式级命中完全不看引号**——实测「『100%有效』这句我常写」仍被判 🔴「效果绝对化」。所以引用他人原话时，**词级会被降级，句式不会**。
4. **句式命中会覆盖词级豁免**：去重按「同行 + 同词」保留**等级更高**的一条。实测「唯一的孩子」——词层的「唯一」已被豁免（安全上下文），但句式「排他性宣称」等级更高，最终报出来的是**句式风险**。**报告时必须写清是哪一层命中的**，不能笼统说「命中唯一」。

## 9. 假阳性清单（14 个场景 + 3 类漏报）

**这一节是专业度的关键**：扫描器是字面匹配，会把大量完全安全的表达报出来。**假阳性比漏报更伤信任**——用户看到一堆误报，就不会再相信你的报告。

脚本的 `SAFE_CONTEXTS` 已内置部分豁免规则，扫描时会自动标为 🟢 提示（`safe=True`），并在报告中单独列为「判定为安全的命中（无需修改）」。

### 9.1 会被自动豁免的（脚本 `safe=True`，报告里标「无需修改」）

| # | 场景 | 命中的词 | 为什么安全 | 实测结果 |
|---|---|---|---|---|
| 1 | 「**第一步**，先下载 App」 | 第一 | 序数词，表示流程次序，不是排名宣称 | 词层豁免，不报 |
| 2 | 「第一时间联系你」 | 第一 | 序数词 + 时间副词 | 词层豁免，不报 |
| 3 | 「第一版更新」 | 第一 | 版本序数 | 词层豁免，不报 |
| 4 | 「这是**唯一的办法**」 | 唯一 | 「唯一的办法/选择/方式/路径」是正当表达；词层豁免 + 句式层也排除 | 完全不报 |
| 5 | 「**最后一天**出差，行程很满」 | 最 / 最后一天 | 「出差/上班/开会/值班/轮休」是客观行程 | 词层豁免，不报 |
| 6 | 「**永久**停靠」「**永久**居民」 | 永久 | 客观状态描述，非服务承诺 | 词层豁免，不报 |
| 7 | 「最近几天」「最终价格」「最新款」「最多可领 3 份」 | 最 | 副词 / 数量限定用法 | 词层豁免，不报 |
| 8 | 「**绝对**路径 / 绝对值」 | 绝对 | 技术术语，非情绪化绝对 | 词层豁免，不报 |
| 9 | 「免费停车位」「免费试用品」 | — | 场景说明，非「白送」诱导 | 「免费」不在词表，根本不产生命中 |

### 9.2 脚本报了、但人工复核应判为安全的（必须标注「人工判定」）

这几种情况脚本**仍会报**。报告时必须写明「字面命中，人工判定为安全 / 无需修改」，不能含糊地混在风险列表里——**这是最容易被用户质疑的地方，也是最显专业的地方**：

| # | 场景 | 脚本报什么 | 为什么实际安全 | 报告口径 |
|---|---|---|---|---|
| 10 | 「他说『稳赚不赔』」 | `稳赚` 🟡 中危 · 理由「引用他人原话」 | 引号内是他人原话，属正当引用 | 🟢 提示：引用他人原话，脚本已降级，无需修改 |
| 11 | 「他说『根治』」 | `根治` 🟡 中危 · 理由「引用他人原话」 | 同上 | 🟢 提示：引用他人原话 |
| 12 | 「**独家**报道：」 | 句式风险「排他性宣称」🟡 | 媒体新闻属性用法，非商业排他宣称 | 🟡 提示：句式命中，但语境为新闻采访，通常无需修改 |
| 13 | 「**唯一**的孩子」 | 句式风险「排他性宣称」🟡 | 家庭叙事，与商业宣称无关 | 🟡 提示：句式命中但语境为个人叙事；若在商业文案里则需改 |
| 14 | 「**永久**停用该功能」 | `永久` 🟡 中危（C1 绝对化用语） | 描述系统功能下线的事实，不是对消费者的服务承诺 | 🟢 提示：字面命中，人工判定为客观状态描述，无需修改 |

### 9.3 三类「脚本不报但实际有风险」（漏报，务必人工补看）

脚本是字面扫描器，以下三类**它不会报，但你必须自己看出来**——这是这个工具最容易出错的地方：

| # | 场景 | 脚本结果 | 为什么实际有风险 | 报告口径 |
|---|---|---|---|---|
| A | 「这是**最贵的产品**，最近到货」 | `最` 🟢 豁免（不报） | 「最贵」是极限宣称。脚本的「最」豁免是**整行匹配**——行内出现「最近」就把这一行所有「最」都放过了 | 🔴/🟡 提醒：**人工补报**，并说明是整行豁免导致的漏报 |
| B | 「**永久**保固条款」「**永久**免费停靠」 | 🟡 中危（会报） | 脚本豁免要求「永久+停靠/居民/保固/免费停」后面紧跟标点或行尾，后面还有汉字时豁免不成立 | 照实报，并提示用户：若确实是客观状态，可加标点断句 |
| C | 「**独家**配方，别的牌子都没有」 | `独家配方` + `独家` 双重命中 | 「别的牌子都没有」是排他比较，但脚本不识别这种**跨句逻辑** | 人工补报：逻辑排他，与「独家配方」叠加时风险更高 |

### 9.4 人工复核的五个提问（每次扫描后固定问自己）

1. 这个词在这里**在做宣称，还是在陈述事实**？——陈述事实 → 降级。
2. 它后面跟的是什么词？——序数、副词、术语、客观状态 → 大概率安全。
3. 命中在**引号里**吗？——他人原话 → 降级。
4. 前面有**否定表述**吗？——合规声明 → 跳过。
5. 同一行里**别的位置**有没有被豁免规则放过的高危词？——「最」的整行豁免最容易漏（见 §9.3 A）。

### 9.5 否定语境的实测边界

脚本 `NEG_RE` 匹配到「不要/不能/不可/禁止/不得/勿/请勿/避免/杜绝/不说/不提/不写/严禁/切勿/别用/不要用/不能说/不能写/不承诺/不保证/不宣称/不提倡/不推荐/避免使用/不得使用」等否定表述时，**整条跳过不报**（词级与句式级都跳过）。

**边界（实测）**：否定词的回看窗口是**命中位置前 26 个字符**。所以：

- ✅「我们不承诺收益，不保证效果」→ `保证` 不报（正确，这是合规声明）。
- ❌「不要」+ 30 个无关字 + 「加微信就能拿资料」→ 否定词离得太远，**照样报**（实测命中 `加微信` 🔴）。

**所以**：合规声明要**紧挨着**敏感词写。写成「本产品为普通消费品，不承诺任何医疗功效」是有效的；写成前面一大段免责声明、后面才出现敏感词，脚本抓不到——**而且声明离得远，读者本来也看不到，效果本身就弱**。

### 9.6 一个必须人工补的漏报：中文数字

脚本句式第 4 条（效果时限承诺）的正则是 `\d+`，**只认阿拉伯数字**。实测：

| 写法 | 脚本结果 | 实际风险 |
|---|---|---|
| 「3 天就能见效」 | ✅ 命中 | 高 |
| 「3天就能见效」 | ✅ 命中 | 高 |
| 「三天就能见效」 | ❌ **不报** | 高 |
| 「三天马上见效」 | ❌ **不报** | 高 |
| 「一周见效」「半个月见效」 | ❌ **不报** | 高 |

**中文数字写的时间承诺，脚本抓不到。** 口播里说「三天」「一周」「半个月」「当天」都是极常见的说法——**这是直播与短视频文案里最需要人工补看的一类**。

**人工补看清单**（脚本查不到，必须自己看）：
- 时间承诺：三天 / 一周 / 半个月 / 当天 / 立刻 / 马上 / 一次就
- 数量承诺：无限量 / 无限次 / 永久 / 终身
- 效果承诺：一次见效 / 一洗就白 / 一贴就掉
- 对比承诺：比 X 还便宜 / 比 X 好用 / 完胜 / 吊打

## 10. 快速使用说明（给脚本调用方）

```bash
python scripts/scan_content_redlines.py 文案.txt --platform xiaohongshu
python scripts/scan_content_redlines.py 文案.txt --json
python scripts/scan_content_redlines.py --selftest
```

平台参数取值：`xiaohongshu` / `douyin` / `shipinhao` / `kuaishou` / `taobao` / `bilibili`（对应内容平台 / 抖音 / 视频号 / 快手 / 淘宝·京东 / B站）。

退出码：`0` = 无高危；`1` = 有高危（🔴）；`2` = 用法错误。

**脚本给的是候选清单，不是判决书。** 报告时每条命中都必须回到原文判断「这个位置为什么有风险 / 为什么其实没问题」——这正是 §9 存在的意义。
