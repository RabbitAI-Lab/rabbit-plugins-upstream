# 标题 / 封面 / 前 3 秒专项

> **为什么单列这一份**：标题、封面、开头 3 秒是**同一个文案里风险密度最高的三个位置**。
> - 正文里的违规词，用户往往滑过去了，**标题里的违规词是被专门来看的**。
> - 正文可以长篇解释，**标题只有一个字的空间**——所以标题必须用绝对化词才够劲，而绝对化词正是 C1。
> - 前 3 秒决定了用户是否留下，而**留不住就没机会表达合规内容**——这正是「合规 vs 效果」冲突最尖锐的地方。
>
> 本文件的判定口径全部来自 `scripts/scan_content_redlines.py`；平台侧差异见 `references/platform-rules.md`。

## 1. 标题党 8 种句式

> 每种给：真实例句 → 为什么踩线 → 改法。
> **判断标准**：用户看完标题后点进去，发现内容与标题的预期落差越大，风险越高。**落差本身就是违规点，与是否真的兑现无关。**

### 句式 1：最高级断言

| | |
|---|---|
| **例句** | 「全网最低价的面膜」「最好用的平价粉底」「史上最强XX」 |
| **为什么踩线** | C1 绝对化用语三连（`全网最低`、`最好`、`史上最强`）。**最高级 + 排名 + 极限**是《广告法》认定虚假宣传最典型的形态，且**无法举证**——「全网最低」需要全网比价数据，实际拿不出来 |
| **改法** | 「我对比了 8 家同款，59 元是今天最低的」——把断言变成**可复现的对比过程**。用户信的不是「最低」，是「她真的比了」 |
| **脚本** | C1 命中；抖音/快手/淘宝直接 🔴 |

### 句式 2：结果承诺

| | |
|---|---|
| **例句** | 「3 天见效」「一周瘦 5 斤」「看完这期就能过」 |
| **为什么踩线** | C2 医疗功效 + 句式第 8 条（结果承诺）+ 句式第 4 条（效果时限）。**三类叠加**，而且是投诉时最容易被截图取证的一类 |
| **改法** | 「我用了 3 天，这是我的真实记录」——**把「结果」换成「过程 + 个人记录」**。注意这里的关键不是删掉时间，是**把主体从产品换成自己** |
| **脚本** | C2 🔴 + 句式第 4/8 条 |

### 句式 3：数字落差

| | |
|---|---|
| **例句** | 「99 元的东西卖 9.9」「原价 599 现在 99」 |
| **为什么踩线** | 虚构原价是虚假宣传，脚本抓不到，**必须人工核价**。而且「99 元的东西卖 9.9」本身就暗示了商品档次低 |
| **改法** | 「这一批是清库存，成本价出」——**给出真实原因**。「清库存」比「原价 599」可信得多，因为用户能自己判断合理性 |
| **脚本** | 脚本不报（无匹配词），**属人工补看区** |

### 句式 4：悬念钩子（隐瞒关键信息）

| | |
|---|---|
| **例句** | 「最后一件」「看到最后你会吓一跳」「99% 的人都不知道」 |
| **为什么踩线** | 悬念本身不违规，但**如果悬念靠隐瞒价格、效果、成分来成立**，就构成误导。平台对「标题与内容不符」有独立的「误导」判定，不依赖词表 |
| **改法** | 「最后 1 件，明码 129」——**把悬念建立在真实稀缺上，而不是信息隐瞒上**。诚实版标题的点击率往往并不低 |
| **脚本** | 「最后一件」不含词表词（不含「最后一天」），脚本不报，**属人工补看区** |

### 句式 5：身份代入 / 情绪煽动

| | |
|---|---|
| **例句** | 「后悔没早点知道」「劝你别买」「99% 的人都被骗了」 |
| **为什么踩线** | 「劝你别买」与「99% 的人都被骗了」是**攻击同行式表达**——句式第 1 条覆盖「别家+骗/坑/忽悠/套路」，这类变体常被抓。另有一种隐性风险：**制造焦虑后给出「唯一解」**，实质是排他宣称 |
| **改法** | 「我踩过的 3 个坑，你可能也会遇到」——**讲自己的经历，不指向同行**。同样有吸引力，但风险归零 |
| **脚本** | 句式第 1 条 🔴（部分变体） |

### 句式 6：伪权威 / 伪专业

| | |
|---|---|
| **例句** | 「皮肤科医生都在用」「内部渠道」「专家推荐」 |
| **为什么踩线** | 「内部渠道」命中句式第 2 条 🔴（暗示非公开利益）。**冒用专业身份**还可能单独触发虚假宣传认定，与词表无关 |
| **改法** | 「配方表我拍给你看，你对照着买」——**给证据，不给身份**。用户要的是可核验的东西，不是光环 |
| **脚本** | 句式第 2 条 🔴 |

### 句式 7：免费 / 白送钩子

| | |
|---|---|
| **例句** | 「免费送」「免单」「点击领红包」 |
| **为什么踩线** | C4+C5 双归属词，在**所有六个平台都是 🔴**（脚本实测：全平台高危）。而且是最容易被用户举报的类型 |
| **改法** | 「0 元领，真实限量 100 份」——**如实说明是促销**。注意「免费送」三个字本身要换成「0 元领」，不能只是加个说明 |
| **脚本** | C4+C5 🔴（全平台） |

### 句式 8：极简歧义 / 悬念数字

| | |
|---|---|
| **例句** | 「3 个原因」「重点在第 2 个」「看完这条你就懂了」 |
| **为什么踩线** | 本身不违规。风险在**第 3 条被使用**时的落差：如果「3 个原因」里的内容与标题暗示的完全无关，就构成误导 |
| **改法** | 「3 个原因，重点在第 2 个」+ **内容真的兑现**。这条的重点是**履约**，不是改写 |
| **脚本** | 不报（除非含其他词） |

### 1.1 8 种句式的等级速查

| # | 句式 | 主要命中 | 等级 |
|---|---|---|---|
| 1 | 最高级断言 | C1 多个词 | 🔴（抖音/快手/淘宝） |
| 2 | 结果承诺 | C2 + 句式 4/8 | 🔴 |
| 3 | 数字落差 | 脚本不报 | 🔴 人工核价 |
| 4 | 悬念钩子 | 多数不报 | 🟡 看落差 |
| 5 | 身份代入/煽动 | 句式 1 | 🔴（变体） |
| 6 | 伪权威 | 句式 2 | 🔴 |
| 7 | 免费白送 | C4+C5 | 🔴（全平台） |
| 8 | 极简歧义 | 不报 | 🟡 看履约 |

## 2. 封面文字独立规则

> **封面字是独立审核对象**。正文改干净了，封面写着「最低价」「第一」，一样会被处理。
> 而且封面是**用户主动盯着看**的位置——审核员和用户都会盯着它找问题。

### 2.1 封面文字的三条硬规则

| # | 规则 | 说明 |
|---|---|---|
| 1 | **字数 ≤ 12 字** | 超过 12 字在手机上会小到看不清，看不清的字不该承担承诺。**字数越少，风险越低**——因为绝对化词往往需要长句才能成立，「最低价」3 个字最危险 |
| 2 | **可读性优先于冲击力** | 深底浅字、高对比、无衬线、不叠图。**看不清 = 无法举证你是宣称还是描述**，同时也无法自证合规 |
| 3 | **封面字与正文口径必须一致** | 封面写「免费领」，正文写「0 元领」→ 属于标题正文不一致，见 §5 |

### 2.2 封面字的三种安全结构

| 结构 | 例 | 为什么安全 |
|---|---|---|
| **数字 + 单位** | 「59 元」「3 天装好」「8 片装」 | 纯事实，无宣称 |
| **动作 + 具体对象** | 「教你做 XX」「对比 8 家」 | 讲行为，不讲结论 |
| **疑问 + 自答预告** | 「为什么别人更白？」 | 提问不构成宣称，且天然引出内容 |

### 2.3 封面绝对不能用（4 类）

1. **绝对化词**：「最」「第一」「唯一」「国家级」「顶级」——C1 全平台命中。
2. **疗效词**：「美白」「祛痘」「减肥」「生发」——C2 🔴，医疗/美妆类封面是重灾区。
3. **承诺词**：「保证」「见效」「包过」——C2 + 句式第 8 条。
4. **引流词**：「加V」「扫码」「私聊」——C4 🔴。

### 2.4 ⚠️ 不要用谐音变形规避（反面提醒）

> **这一节专门写「不要做什么」。因为这是最常见、也最危险的做法。**

**违规的做法**：

| ❌ 谐音/变形 | 想表达的意思 | 为什么危险 |
|---|---|---|
| 「薇」→ 微信 | 加微信 | **平台的检测是对「字形」的，不是对「拼音」的**。谐音字在人工审核面前是**更明确的恶意规避证据**——因为没有任何正常表达需要写成这样 |
| 「V信」「薇信」「徽信」 | 微信 | 同上 |
| 「包Y」「包过」 | 包过 | 变形后仍是承诺，且更像规避 |
| 「biu」「必瘦」 | 必瘦 | 同上 |
| 「1OO%」 | 100% | 同上 |
| 「⓪元」「免fei」 | 免费 | 同上 |

**为什么特别危险**（这三条是实测与运营中反复出现的）：

1. **审核是人工 + 机器双轨**。机器可能漏，但人工看到「薇信」会**直接判定为故意规避**——后果通常比直接写「微信」更重。
2. **平台对「故意规避」的处置层级通常高于「直接违规」**。直接写是「违规内容」，变形写是「屡教不改 / 恶意规避」。
3. **用户也看不懂**。变形字实际损失的是转化——你想省下的那点风险，代价是真实流失的订单。

**正确做法只有一个**：**把导流动作换到平台内的合规通道**（站内私信 / 平台群 / 官方客服 / 评论区置顶 / 平台内表单），而不是把字换掉。

> **一句话**：**不要改字，要改动作。**
> 谐音、拆字、符号替代、图片嵌字、拼音缩写——**这六种在《避雷指南》里都出现过，每一种都在把你的账号往更重的处置推。**

### 2.5 封面字改写对照（6 组）

| ❌ 封面 | ✅ 封面 | 说明 |
|---|---|---|
| 「全网最低」 | 「59 元」 | 只给价，不比较 |
| 「3 天祛痘」 | 「3 天护理记录」 | 去疗效，保留具体 |
| 「免费送」 | 「0 元领 · 限 100 份」 | 如实说促销 + 真实名额 |
| 「第一品牌」 | 「2019 年做到现在」 | 用时间代替排名 |
| 「加V领券」 | 「首页领券」 | 落点进平台 |
| 「保证有效」 | 「成分表见下方」 | 给依据 |

## 3. 开头 3 秒钩子的风险

### 3.1 核心矛盾

> **钩子越强 → 风险越高 → 但钩子弱了 → 没人看。**
> 这个矛盾不能靠「少说点违规词」解决，只能靠**把强钩子建立在真实事实上**。

### 3.2 钩子强度与风险的关系

| 钩子类型 | 强度 | 风险 | 说明 |
|---|---|---|---|
| **结果断言型**（「3 天见效」） | ★★★★★ | 🔴 | 强度最高，风险最高。**结果无凭证 = 投诉素材** |
| **绝对化型**（「最便宜」） | ★★★★☆ | 🔴 | 强度高，且无法举证 |
| **否定型**（「别再买 XX 了」） | ★★★★☆ | 🟡→🔴 | 强度高，攻击同行变体风险 |
| **悬念型**（「重点在第 2 个」） | ★★★☆☆ | 🟡 | 强度中，取决于履约 |
| **身份型**（「开了 8 年店」） | ★★★☆☆ | 🟢 | 强度中，**风险低且真诚** |
| **场景型**（「厨房就 2 平米」） | ★★☆☆☆ | 🟢 | 强度低，但**完播率高**（真实感） |
| **过程型**（「先拆开看看里面」） | ★★★☆☆ | 🟢 | 强度中，零风险 |

### 3.3 「强钩子但不踩线」的 5 种写法

**核心方法：把钩子从「结论」换成「过程」，从「断言」换成「悬念」。**

| # | 写法 | 具体做法 | 例句 |
|---|---|---|---|
| 1 | **用过程替代结论** | 不说结果有多好，说怎么做到的 | ❌「这个方法 3 天见效」<br>✅「我把每天的步骤都拍下来了」 |
| 2 | **用数字替代形容词** | 不用「超好用」，用具体数字 | ❌「超好用」<br>✅「洗了 30 次，还是这个」 |
| 3 | **用悬念替代断言** | 留一个真实的信息缺口 | ❌「千万别买错了」<br>✅「买之前先看这一行」 |
| 4 | **用身份/时间替代权威** | 用持续时间代替专家背书 | ❌「皮肤科医生推荐」<br>✅「我做了 8 年」 |
| 5 | **用场景替代夸张** | 用具体场景唤起共鸣 | ❌「巨好用！！」<br>✅「出租屋 5 平米，锅就这么点地方」 |

> ⚠️ **注意「最」字**：它同时在 C5 和 C1 里。**「第 2 个方法最关键」「最重要的 3 个技巧」这类写法会被字面命中（🟡 中危）**——即便这里没有排名宣称的意思。想表达强调，改用「关键的那个」「重点在这」「我更想说的是第 2 个」。

### 3.4 3 秒钩子的自检（4 问）

1. 这句话里有没有词表词？（C1 绝对化 / C2 功效 / C3 收益 / C4 引流 / C5 促销）
2. 有没有对结果下承诺（保证 / 肯定 / 包 / 一定 + 结果）？
3. 这个钩子靠的是**事实**还是**情绪**？
4. 用户看完前 3 秒，接下来 30 秒能兑现吗？（**兑现不了 = 标题党**）

## 4. 各平台标题长度建议

> ⚠️ **以下是行业实测经验，非平台公开细则**。各平台的标题字数限制会调整，且不同版本（标题/描述分开的界面）计数方式不同。**发布前以平台当前界面提示为准。**

| 平台 | 建议长度 | 理由 | 写法偏好 |
|---|---|---|---|
| **内容平台** | **20 字内** | 标题进搜索池，会被长期索引；前 20 字在信息流里基本展示完 | 口语 + 场景 + 数字，如「出租屋收纳，5 平米厨房这样摆」 |
| **抖音** | **短，15–30 字** | 标题在推荐页展示，字多会被截断；视频内容才是主体 | 悬念 + 数字，如「买之前先看这一行」 |
| **视频号** | **20–30 字** | 微信生态内分享卡片会完整显示标题 | 偏叙述、偏信任感 |
| **快手** | **15–25 字** | 信息流完整展示，标题与封面权重接近 | 直给、接地气 |
| **淘宝/京东** | **商品标题约 30 字内** | 搜索结果页按权重截断，关键词前置最重要 | **关键词 + 属性 + 场景**，如「纯棉短袖 T 恤 男女同款 夏季薄款」 |
| **B站** | **可长，约 80 字** | 标题在搜索与推荐中完整显示，是重要的信息入口 | 内容型标题，像一个选题说明 |

### 4.1 长度建议的三条补充

1. **电商标题是例外**：电商标题的第一任务是**被搜到**，不是吸引点击。所以要**关键词前置**（「纯棉短袖」放最前），而不是把最刺激的词放最前。
2. **内容平台标题不是电商标题**：内容平台是**推荐流**，标题的作用是**让人点开**，关键词对搜索的作用次要。
3. **B站标题可以长**，因为 B站用户会读标题判断内容是否值得点——**B站的「信息密度」比「短」更重要**。

### 4.2 长度的真正意义：字数少 = 少一个踩线机会

> **标题的字数与风险负相关。** 绝对化宣称通常需要长句才能成立：
> - 「最便宜」→ 3 字，但本身就是绝对化。
> - 「全网最低价，我对比了 8 家同款，这是 59」→ 长，但**事实陈述**。
>
> **所以压缩标题的正确方向是「砍形容词、留事实」，不是「砍成最短」。**

## 5. 标题与正文不一致（标题党被抓的最常见方式）

### 5.1 为什么这是最容易被抓的

1. **用户举报的入口就是标题。** 用户看完标题点进去，发现内容对不上——**这一刻他已经在举报页面了**。这比平台主动巡查发现的举报率高得多，且举报人往往就是被误导的人。
2. **举证责任在你。** 平台判你标题党时，看的是「标题承诺 vs 内容兑现」的落差，不需要你证明标题合理。
3. **封面 + 标题 + 正文三处要一致。** 只改一处不够——用户会把三处拼在一起看。

### 5.2 六种典型的不一致（附改法）

| # | 不一致类型 | ❌ 标题 | ❌ 正文 | ✅ 怎么改 |
|---|---|---|---|---|
| 1 | **价格不一致** | 「9.9 元」 | 正文写「原价 129，现价 99」 | 价格只出现一次，且两处相同 |
| 2 | **功效不一致** | 「祛痘神器」 | 正文讲「清洁保湿」 | 标题和正文讲同一件事；不能标题靠功效引流、正文讲别的 |
| 3 | **数量不一致** | 「3 个技巧」 | 正文讲了 5 个 | 标题数字 = 正文实际条数 |
| 4 | **身份不一致** | 「十年老师傅」 | 正文是新手的第一天 | 标题身份要么改，要么正文兑现 |
| 5 | **时效不一致** | 「最后一天」 | 活动还剩 8 天 | 标题写真实时点；「最后一天」只在真的是最后一天时用 |
| 6 | **人群不一致** | 「新手也能上手」 | 正文全是高阶技巧 | 标题的人群要真的覆盖正文内容 |

### 5.3 一致性自检（发布前 5 分钟）

```
☐ 标题里的每一个数字/价格/时间，都在正文里出现且一致吗？
☐ 标题里的每一个功效，正文真的讲了吗？
☐ 标题里的身份/资历，正文撑得住吗？
☐ 封面上的字，和标题说的是同一件事吗？
☐ 标题承诺的，正文前 30 秒就兑现了吗？（短视频）
☐ 我愿意为这个标题的内容差异负责吗？（如果用户举报，我会认吗）
```

### 5.4 一个好用的自测法

> **把标题和正文并排放，只看标题的人会失望吗？**
> 如果会失望，就不是标题党，只是**信息量不足**——那属于标题写得不好，不是违规。
> 真正的标题党是：**标题让人以为会得到 A，正文给的是 B。**

## 6. 标题 / 封面 / 前 3 秒的速查表

| 位置 | 必查 | 高危项 | 一句话原则 |
|---|---|---|---|
| **标题** | 词表 + 数字一致性 + 承诺 | C1 绝对化、结果承诺、免费钩子 | 砍形容词，留事实 |
| **封面** | 独立扫一遍 + 与标题一致 | 绝对化、疗效、引流、谐音变形 | ≤12 字，可读，不变形 |
| **前 3 秒** | 承诺 + 兑现 | 结果断言、效果时限 | 用过程替代结论 |
| **标题 vs 正文** | 三处交叉核对 | 价格/功效/数量/时效 | 并排读，问自己会不会失望 |

**最后一句**：

> **标题的作用是让人点进来，不是替用户做决定。**
> 所有「点击率高但风险高」的写法，本质上都是**把用户骗进来**——平台防的正是这个，用户反感的也正是这个。
> 「真实但有力」的路子一直都在：数字、场景、过程、对比、可核验的细节。**这些写法的点击率不比标题党低，只是更耐用。**
