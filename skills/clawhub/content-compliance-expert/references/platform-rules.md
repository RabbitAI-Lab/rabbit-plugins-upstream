# 各平台雷区差异

> **重要声明**：以下平台差异分为两部分——
> - **【脚本口径】**：来自 `scripts/scan_content_redlines.py` 的 `PLATFORM_STRICT` / `PLATFORM_NAME`，是本工具的判定依据。
> - **【行业实测经验】**：来自实际运营中的观察，**非平台公开细则**。平台未公开具体条款编号，本文件**不引用任何条款号、不引用官方文件标题**。
>
> 用户拿本文件做决策时，请区分这两类信息：**脚本口径可以照着改，实测经验需要自己判断。**

## 0. 一页速查：六平台对五类的敏感度

脚本 `PLATFORM_STRICT` 的原始系数（+1 表示该平台对这类加严一档）：

| 平台 | C1 绝对化 | C2 医疗功效 | C3 金融承诺 | C4 站外引流 | C5 诱导促销 |
|---|---:|---:|---:|---:|---:|
| 内容平台 | 0 | **+1** | 0 | **+1** | **+1** |
| 抖音 | **+1** | **+1** | **+1** | **+1** | 0 |
| 视频号 | 0 | **+1** | **+1** | 0 | 0 |
| 快手 | **+1** | **+1** | **+1** | 0 | 0 |
| 淘宝/京东 | **+1** | **+1** | **+1** | 0 | 0 |
| B站 | 0 | 0 | 0 | 0 | 0 |

### 0.1 这张表怎么读

**加严 = 该类的中危命中会被提升到高危。** 换句话说，脚本里本来是 🟡 中危的词，在加严平台上就是 🔴 高危。

**C1 的平台硬规则（脚本第 268 行）**：C1 命中且平台是**抖音/快手/淘宝**时，**直接判 🔴 高危**，不走中危这条路径。

### 0.2 纯 C1 词的完整实测矩阵

22 个纯 C1 词（国家级、最高级、最佳、第一品牌、独家、首选、顶级、极品、至尊、万能、100%、绝对、全网最低、销量第一、独家配方、永久、史无前例、史上最低、超大、全民、第一、唯一）在六平台的等级**分成两组**：

| 分组 | 词 | 内容平台 | 抖音 | 视频号 | 快手 | 淘宝/京东 | B站 |
|---|---|---|---|---|---|---|---|
| 21 个词 | 国家级、最高级、第一品牌、独家、首选、顶级、极品、至尊、万能、100%、绝对、全网最低、销量第一、独家配方、永久、史无前例、史上最低、超大、全民、第一、唯一 | 🟡 | 🔴 | 🟡 | 🔴 | 🔴 | 🟡 |
| **1 个词** | **最佳** | 🔴 | 🔴 | 🟡 | 🔴 | 🔴 | 🟡 |

**为什么只有「最佳」在内容平台是 🔴？** 因为「最佳」两个字里含有「最」——而「最」是 **C5+C1 双归属词**，在内容平台 C5 加严（+1）时被提升到 🔴。其余 21 个纯 C1 词不含 C5 词素，在内容平台仍是 🟡。

> **这个细节值得记住**：词表是按**整词**匹配的，但**多归属词会通过包含关系影响另一类词**。「最佳」看起来是纯 C1 的词，实际触发时 C5 那一档也会跟着生效。**遇到「最」开头的词（最、最佳、最好、最优……），在内容平台一律按 🔴 处理。**

### 0.4 三条平台层面的结论

1. **C2（医疗功效）、C3（金融承诺）、C4（站外引流）在六个平台上全是 🔴**——这三个类别**不存在「换个平台就安全」的说法**。想做跨平台分发，这三类必须在源头改掉。
2. **内容平台是唯一对 C5（诱导促销）加严的平台**。同样一句「最后一天」，内容平台是 🔴，其他平台是 🟡。**内容平台用户对套路感的反感度最高，投诉也最集中。**
3. **B站是唯一一个全系数为 0 的平台**。但这不是"B站没有规则"——B站是**长内容平台**，审核重点在内容质量与版权，不在广告法词表。**"B站系数 0"应该理解为"词表命中不等于 B站会限流"，不是"可以随便写"。** 详见 §7。

## 1. 内容平台

**脚本口径**：C2 +1、C4 +1、C5 +1；C1 系数 0（但仍为 🟡 中危）。
**实测等级**：纯 C1 词 🟡；纯 C5 与 C5×C1 交叉词 🔴；C2/C3/C4 全 🔴。

### 1.1 高频雷区（12 条）

1. **站外引流是头号雷区**——脚本对内容平台 C4 加严。「加微信」「私聊」「扫码」「引流」「私域」「微信转账」在内容平台全是 🔴。笔记正文一旦出现联系方式字样，笔记进不了推荐池。
2. **诱导互动是第二雷区**——「最后一天」「错过再等一年」「好评返现」「免费送」「抽奖」「中奖」「点击领红包」在内容平台全是 🔴。
3. **医疗功效类从严**——C2 加严。保健品、护肤、口腔、健身内容最容易踩。
4. **「功效词 + 导流词」同现是最危险的组合**——见 §1.5。
5. **绝对化用语在内容平台是 🟡 不是 🔴**，但**不要因此放心**——内容平台对虚假宣传的举报会走「虚假宣传」标签，触发的是信用分而非单条限流。
6. **评论区也要查**——笔记正文干净，但评论区置顶写「加V领资料」，用户举报后笔记仍会被处理。
7. **图片内文字同样会被审**——封面图、详情图里的文字不算「非正文」。
8. **品牌词与功效词混写**——「XX 牌祛痘霜」比「祛痘霜」更危险：品牌背书 + 功效宣称叠加，被举报时品牌方连带担责。
9. **「姐妹们」「集美们」等称呼不违规**，但「姐妹们跟着买绝对不踩雷」中的「绝对」属 C1。
10. **种草笔记里的价格绝对化**——「全网最低」「史无前例」在内容平台属于典型举报素材。
11. **直播回放与笔记双发时，直播话术的风险会回流到笔记**——直播里说过的「加微信」，在笔记里再提一次，命中更重。
12. **「私信我」在正文里出现要谨慎**——脚本会命中句式第 12 条（互动诱导）。内容平台本身有「私信我」的功能入口，但正文里反复说「扣 1 私信我」属于典型诱导。

### 1.2 与通用 5 类的差异点

| 差异 | 说明 |
|---|---|
| **C5 单独加严** | 通用口径里 C5 是 🟡 中危（效果损失最大但不必然限流），内容平台是 🔴。**同一个促销话术在内容平台要按高危改。** |
| **C1 不加严** | 但内容平台对「虚假宣传」的举报路径是**信用分扣分 + 限流**，属于长线惩罚，不是单条不推流 |
| **C4 的实际后果更重** | 内容平台的私域导流处置通常是「笔记限流 → 主页限制 → 账号功能限制」的连续动作 |
| **图文与视频要分别查** | 内容平台的图文的图片文字与正文文本会被分别识别，**封面字最容易漏检** |

### 1.3 标题 / 封面 / 正文表述差异

| 位置 | 内容平台的特点 |
|---|---|
| **标题** | 建议 20 字内。标题里出现功效词（祛痘、抗癌、美白）风险最高，因为标题会进搜索池并被长期索引 |
| **封面** | 大字报封面是转化利器，也是审核重点。**封面上的「最」「第一」「免费」与正文同等对待** |
| **正文** | 前 3 行是折叠前可见区域，**导流词不要放前 3 行**；放后面也仍会被扫，但投诉概率低 |
| **话题标签** | 标签也会被审。`#祛痘神器` 属于功效宣称标签，`#平价好物` 属于安全标签 |

### 1.4 内容平台特别容易踩的组合（5 组）

1. **功效词 + 导流词**：「祛痘霜有效，加微信领试用装」→ C2 + C4 双高危，且构成「产品功效 + 站外交易」的完整违规链。
2. **绝对化 + 价格承诺**：「全网最低价 39 元」→ C1 + C1 交叉（销量类），被举报后按虚假宣传处理。
3. **诱导互动 + 稀缺**：「最后一天，评论区扣 1 送小样」→ C5 加严 + 句式第 12 条，双重命中。
4. **医疗词 + 达人背书**：「博主亲测有效，3 天见效」→ 「亲测有效」是效果宣称，「3 天见效」命中句式第 4 条。
5. **私域词 + 官方活动包装**：「进我们的粉丝群，有内部一手货源」→ 命中句式第 2 条 + 第 11 条，且平台活动不能用私域群替代。

### 1.5 通用注意事项

- **正文写「主页简介有完整说明，站内可以问我」是可用的**——这句不含任何词表词，也不命中句式。
- **内容平台的「私信」功能本身合规**，风险在于「扣 1 送资料」这种附带条件的诱导。合规写法：「需要的话站内私信我，我发给你」。

## 2. 抖音

**脚本口径**：C1 +1、C2 +1、C3 +1、C4 +1；C5 系数 0。
**实测等级**：纯 C1 词 🔴（C1 硬规则）；纯 C5 词 🟡；C2/C3/C4 全 🔴。

### 2.1 高频雷区（12 条）

1. **绝对化用语直接高危**——脚本的 C1 硬规则把抖音列为强监管平台。「最好的」「第一」在抖音是 🔴。
2. **导流是账号处置主因**——C4 加严。「加微信」「私域」在口播、字幕、评论、主页简介里都算。
3. **口播比图文更严**——直播与视频的口播内容会被转写后再审，**口语里的「加我一下」照样命中句式第 3 条**。
4. **字幕是独立审核项**——口播没说但字幕写了，同样算违规。
5. **背景音乐/画面里的文字**也可能被识别（部分场景），不要在画面上打「内部价」。
6. **C5 促销话术在抖音是 🟡 但投诉率高**——「最后一天」「免费送」不一定限流，但用户举报会推高账号风险分。
7. **「低价承诺」类表述易触发虚假宣传举报**——「全网最低」即使不限流，也可能引发竞争对手投诉。
8. **「限时」本身合规，「限时」+ 无具体时间则是套路**——写「3 月 18 日 24:00 截止」比写「限时」安全且更有效。
9. **抽奖 / 免单的规则必须写在内容里**——只说「抽奖送免单」不说名额与条件，容易被判虚假活动。
10. **金融、教育类账号在抖音的资质审核更严**——涉及 C3 的内容，除改词外还要看账号资质。
11. **口播里的「秒发」「秒到」注意**——「秒杀」在抖音是 🟡，但如果是自营秒杀活动，需确保库存与价格真实。
12. **评论区维护也算内容**——视频下方的置顶评论若含导流词，同样可被处理。

### 2.2 与通用 5 类的差异点

| 差异 | 说明 |
|---|---|
| **C1 被硬规则提到 🔴** | 这是六平台中对 C1 最狠的之一（与快手、淘宝并列）。**抖音发文案，C1 必须清零。** |
| **C5 不加严** | 促销话术在抖音可存活，但用户反感会体现在完播率与转化率上 |
| **多模态审核** | 口播转写 + 字幕 + 画面 + 评论区，任何一处命中都算 |
| **C3 加严** | 金融内容在抖音本身就属高门槛类目 |

### 2.3 标题 / 封面 / 正文表述差异

| 位置 | 抖音的特点 |
|---|---|
| **标题** | 建议短（约 15–30 字）。标题会被抽帧展示在搜索与推荐页 |
| **封面/首帧** | 第一帧画面上的大字被单独识别，**不要在封面写「最低价」** |
| **口播** | 会被转写后按文本审，口语化表达照样命中 |
| **字幕** | 独立审。大字幕的「最」「第一」比小字幕更容易被识别 |
| **简介/评论区** | 主页简介是导流词的重灾区 |

### 2.4 抖音特别容易踩的组合（5 组）

1. **绝对化 + 排名**：「销量第一」→ C1 硬规则直接 🔴。改「累计卖出 12 万瓶」。
2. **口播导流 + 利益承诺**：「加上我就能领内部资料」→ 句式第 3 条 + 第 2 条，双重命中。
3. **限时 + 稀缺 + 抽奖**：「最后一天抽奖送免单」→ 句式第 12 条 + C5。
4. **功效 + 时限**：「3 天就能见效」→ 句式第 4 条 + C2。
5. **字幕与口播不一致**：口播说「优惠价」，字幕写「全网最低」——**以字幕为准判罚**，很多人栽在这里。

### 2.5 通用注意事项

- 抖音的「主页简介」写「站内私信我」是安全的；写「加V」不是。
- 抖音有官方的「引导咨询」组件（如企业号客服入口），**用它替代口播留联系方式**——这是平台提供的合规路径，不是规避。

## 3. 视频号

**脚本口径**：C1 0、C2 +1、C3 +1、C4 0、C5 0。
**实测等级**：纯 C1 词 🟡；纯 C5 词 🟡；C2/C3/C4 全 🔴。

### 3.1 高频雷区（10 条）

1. **C2 与 C3 加严**——这两类是视频号的重灾区，其余四类相对宽松。
2. **朋友圈/视频号生态的「熟人式信任」是陷阱**——因为面向熟人，用户举报动机强，「骗熟人」的舆论代价高于陌生人平台。
3. **金融内容审核严格**——涉及投资理财、收益、返利的表述，脚本对 C3 加严，实际处置也更重。
4. **医疗健康内容是重点治理领域**——「根治」「抗癌」「排毒」在视频号一律 🔴。
5. **转发与分享类玩法有边界**——「转发给三个好友可领」属于诱导分享，脚本句式第 12 条会命中「转发…领…资料」类结构。
6. **绝对化用语相对宽松，但不要形成习惯**——C1 在视频号是 🟡 中危，改造成本低，没有理由留着。
7. **导流并非零风险**——脚本对视频号 C4 系数为 0（不加严），**但这不代表视频号不管导流**。见 §3.4。
8. **口播与直播**同样会被转写审。
9. **「养生」内容是伪装重灾区**——用养生话术包装的产品最容易触碰 C2。
10. **用户年龄层偏高，健康类内容传播快、影响大**——一次违规扩散成本高。

### 3.2 与通用 5 类的差异点

| 差异 | 说明 |
|---|---|
| **C1/C4/C5 都不加严** | 视频号是六平台里对这三类最宽松的 |
| **但「宽松」不等于「安全」** | C2/C3 加严，且视频号的社交传播会让违规内容扩散更快、影响更大 |
| **熟人社交属性** | 违规内容一旦被熟人看到，投诉与舆情成本高于内容平台 |
| **C3 特别严** | 涉及金融与收益的表述，在视频号的实际处置通常比脚本等级更重 |

### 3.3 标题 / 封面 / 正文表述差异

| 位置 | 视频号的特点 |
|---|---|
| **标题** | 建议 20–30 字，微信生态内信息流会展示完整标题 |
| **封面** | 分享到聊天/朋友圈时缩略图很小，封面字要大，但**大字号更容易被识别** |
| **口播** | 转写审，与抖音同理 |
| **正文/描述** | 描述区也是审核范围 |

### 3.4 关于「视频号 C4 系数为 0」的正确理解

脚本系数为 0 意味着：**在视频号发「加微信」，扫描器不会把它升级为高危**，仍按 C4 的基础等级（🔴 高危）判定——**注意 C4 的基础等级本来就是高危**，加严只是「中危升高危」的机制。

所以：**视频号的「加微信」仍然是 🔴 高危**。系数 0 不代表安全，只代表它不像内容平台那样「本已中危的又被加严」。

> **这是本文件最容易读错的地方**。脚本里 C2/C3/C4 的基础等级恒为 🔴（见脚本第 260 行），`PLATFORM_STRICT` 的 +1 只会把 🟡 提升到 🔴，**不会把 🔴 降级**。

### 3.5 视频号特别容易踩的组合（4 组）

1. **养生话术 + 疗效承诺**：「这个茶排毒养颜，三天见效」→ C2 双重命中。
2. **熟人信任 + 金融收益**：「亲戚朋友跟着买，稳赚不赔」→ C3 + 社交传播，风险放大。
3. **转发福利 + 资料诱导**：「转发给 3 个朋友领课程」→ 句式第 12 条 + 诱导分享。
4. **直播口播 + 私下交易**：「微信转账更便宜」→ C4 全 🔴，且视频号的社交属性会让「私下交易」的信任背书问题放大。

---

## 4. 快手

**脚本口径**：C1 +1、C2 +1、C3 +1、C4 0、C5 0。
**实测等级**：纯 C1 词 🔴；纯 C5 词 🟡；C2/C3/C4 全 🔴。

### 4.1 高频雷区（10 条）

1. **绝对化用语直接高危**——与抖音、淘宝同列强监管平台。
2. **C2/C3 加严**——健康类与金融类是重点。
3. **C4 系数为 0，但基础等级仍是 🔴**——见 §3.4 的说明。
4. **直播是快手的主场景**——直播合规压力大于短视频。实时不可撤回，处置代价更高。
5. **「老铁」「家人们」式称呼不违规**，但「家人们跟着买绝对不亏」中的「绝对」是 C1、「不亏」接近 C3。
6. **价格与赠品描述是快手的敏感点**——「亏本甩卖」「免费送」在快手虽为 🟡，但「虚假划线价」是独立于词表的投诉重灾区。
7. **夸大划线价**——「原价 599 现价 99」如果原价是编的，属于虚假宣传，脚本抓不到，**必须人工核**。
8. **县域/下沉市场的信任链更依赖人设**——主播个人背书一旦翻车，账号与个人品牌同时受损。
9. **口播转写审与字幕审同样适用。**
10. **「内部价」「内部渠道」类表述在快手语境下更敏感**——句式第 2 条。

### 4.2 与通用 5 类的差异点

| 差异 | 说明 |
|---|---|
| **C1 硬规则 → 🔴** | 与抖音、淘宝并列 |
| **C5 不加严** | 促销话术可存活 |
| **C4 系数 0 但基础 🔴** | 同 §3.4 |
| **直播权重高** | 快手直播时长与转化占比高，直播话术的检查权重应高于短视频 |

### 4.3 标题 / 封面 / 正文表述差异

| 位置 | 快手的特点 |
|---|---|
| **标题** | 建议 15–25 字。快手信息流对标题的展示完整 |
| **封面** | 封面字号普遍较大，大字识别风险高 |
| **口播** | 转写审；快手的直播连麦场景也要审 |
| **商品挂载信息** | 商品标题也会被审，且与口播需一致 |

### 4.4 快手特别容易踩的组合（4 组）

1. **划线价 + 限时 + 绝对化**：「原价 599，今天最低价 99，最后一天」→ C1 硬规则 + C5 + 虚假划线价三重风险。
2. **健康品 + 熟人背书**：「我邻居吃了 XX，血压正常了」→ C2 效果宣称 + 个人案例证言。
3. **主播情绪话术**：「不上这个价我倒立洗头」→ 虚假承诺，不在词表内，但属投诉高发。
4. **直播间口头留联系方式**：「私聊我，我给你发内部价」→ C4 + 句式第 2 条 + 第 3 条。

## 5. 淘宝 / 京东详情页

**脚本口径**：C1 +1、C2 +1、C3 +1、C4 0、C5 0。
**实测等级**：纯 C1 词 🔴（C1 硬规则）；纯 C5 词 🟡；C2/C3/C4 全 🔴。

### 5.1 高频雷区（12 条）

1. **《广告法》绝对化用语是详情页的第一红线**——C1 硬规则在淘宝生效，「国家级」「最高级」这类词在电商详情页是典型被处罚对象。**这是所有平台里 C1 法律风险最实在的一个**（电商有真实交易场景与投诉人）。
2. **功效宣称是详情页的高危区**——食品、化妆品、保健品、母婴用品、医疗器械各有专门的宣称红线，脚本把 C2 全部归为 🔴 是保守且正确的。
3. **划线价与「原价」**——虚构原价是虚假宣传，脚本抓不到，**必须人工核**。
4. **赠品与「免费送」**——「买 X 送 Y（价值 299）」若价值不实，属虚假促销。
5. **详情页与商品标题必须一致**——标题说「保湿」，详情页说「美白」，两处都要查，且不一致本身可能被投诉。
6. **「限时抢购」的倒计时须真实**——脚本 C5 系数 0，但虚假限时在电商是明确的违规（价格促销管理）。
7. **「全网最低价」在电商场景基本等于违规宣称**——比较广告需要可验证的比较依据。
8. **「销量第一」「已售 X 万」**——必须有可查证的数据来源，否则涉嫌虚假宣传。
9. **「无副作用」「纯天然」在化妆品/食品详情页是高频处罚项。**
10. **「正品」「官方授权」类表述需有授权凭证。**
11. **图片里的文字同样被审**——详情页长图里的文字是电商审核重点。
12. **客服话术同样有风险**——不是只有详情页，客服自动回复里出现「保证有效」也是风险点。

### 5.2 与通用 5 类的差异点

| 差异 | 说明 |
|---|---|
| **C1 是法律风险最高的平台** | 电商有真实交易与投诉人，绝对化用语的《广告法》责任最实 |
| **C3 加严** | 金融类目商品在电商平台的准入本身就严 |
| **C5 不加严但有独立规则** | 电商有自己的一整套价格促销规范（划线价、限时），脚本抓不到那些 |
| **「留联系方式」不是主要问题** | 电商本来就在做交易，引导站内咨询不算导流——**但 C4 词表里的「微信转账」「扫码」在电商语境是明确违规**（绕过平台担保交易） |

### 5.3 标题 / 封面 / 正文表述差异

| 位置 | 电商详情页的特点 |
|---|---|
| **商品标题** | 约 30 字以内，权重最高，审核最严。**标题里的绝对化用语直接触发处罚** |
| **主图 / 详情长图** | 图片文字同样被审，且是用户投诉时截图取证的重点 |
| **详情页正文** | 段落化，功效词常藏在「使用感受」段落里 |
| **评价区** | 商家回复里的敏感词也会被处理 |
| **客服话术** | 属于运营口径，发布前也要扫 |

### 5.4 淘宝/京东特别容易踩的组合（5 组）

1. **绝对化 + 可验证性**：「全网最低 + 销量第一」→ 两条 C1 同时命中，且都是需要举证的高风险宣称。
2. **成分/功效 + 适用人群**：「适合所有肤质，100% 有效」→ C2 双重命中。
3. **促销 + 价格锚点**：「原价 599 现价 99，最后一天」→ C5 + 虚假划线价。
4. **导流 + 交易**：「加微信领优惠券更便宜」→ C4，且是绕过平台担保交易。
5. **赠品价值 + 促销话术**：「免费送价值 299 的礼包」→ C4+C5 交叉词 🔴，且价值需可举证。

### 5.5 电商类目专属提醒（脚本不覆盖）

以下四类在电商详情页是独立的高风险区，**脚本完全查不到**，必须人工审：

1. **化妆品**：不得宣称医疗作用；「美白」「祛斑」「防脱」需有备案依据。
2. **食品/保健品**：不得宣称疾病预防治疗作用；「增强免疫力」等需有注册批号。
3. **医疗器械**：不得宣传疗效；需有医疗器械注册证。
4. **母婴/儿童用品**：限制更严，绝对化用语的实际处罚力度更高。

## 6. B站

**脚本口径**：全部系数为 0（`PLATFORM_STRICT["bilibili"]` 全 0）。
**实测等级**：纯 C1 词 🟡；纯 C5 词 🟡；C2/C3/C4 全 🔴。

### 6.1 高频雷区（8 条）

1. **B站的核心不是广告法词表**——是内容质量、版权与社区规范。「系数全 0」不等于「不管」。
2. **硬广导流（title/简介/评论）会被处理**——B站对「充电专属内容里放外链」「动态里发联系方式」有明确处置逻辑。
3. **C2/C3 在 B站仍然是 🔴**——「根治」「稳赚」「保本」这类词在知识区同样不可用，B站的知识区用户对这类表述的举报很活跃。
4. **版权是 B站的头号雷区**——搬运、未授权音乐、未授权素材、课程二次录制等。**脚本完全不覆盖版权，这是 B站用户最常踩的坑。**
5. **「三连」诱导（点赞投币收藏）**——「点赞关注收藏抽奖送 XX」是诱导互动的高发结构，命中句式第 12 条。
6. **标题党在 B站有独立的社区规则**——标题与内容不符会被「误导」标签处理，详见 `references/title-and-hook-rules.md`。
7. **口播/视频内的口播内容同样会被审**——转写审。
8. **知识区与财经区的资质与合规要求更严**——涉及金融、法律、医疗的科普有额外的表述要求。

### 6.2 与通用 5 类的差异点

| 差异 | 说明 |
|---|---|
| **所有加严系数为 0** | 唯一全 0 的平台 |
| **但 C2/C3/C4 的基础等级恒为 🔴** | 系数 0 = 「中危不再加严」，**不是「高危变安全」**。C2/C3/C4 在 B站依旧是 🔴 |
| **审核逻辑不同** | B站按社区规范与内容质量审核，广告法词表只是其中一项 |
| **版权风险远大于词表风险** | 用户举报的第一大类是搬运与未授权使用 |

### 6.3 标题 / 封面 / 正文表述差异

| 位置 | B站的特点 |
|---|---|
| **标题** | 可长（约 80 字），是搜索与推荐的重要抓手。标题党有独立判定 |
| **封面** | 封面是点击率核心，也是标题党的重灾区 |
| **简介** | 简介里的链接、外链、群号是导流处置重点 |
| **正文/口播** | 转写审；知识区口播的绝对化表述容易被知识区用户挑刺 |

### 6.4 B站特别容易踩的组合（3 组）

1. **三连诱导 + 抽奖**：「点赞投币收藏参与抽奖送 XX」→ 句式第 12 条 + C5。
2. **知识区严谨形象 + 绝对化**：「这个方法一定能过」→ 句式第 8 条（结果承诺）🔴，在知识区的举报后果尤其重。
3. **充电内容 + 外链导流**：「充电专属里有内部渠道」→ 句式第 2 条 + C4。

## 7. 跨平台发布的通用做法

### 7.1 一套文案多平台发的正确做法

**不要按平台分别改稿，按「最严平台」改一次。**

因为 C2/C3/C4 在六个平台**全是 🔴**，而 C1 在抖音/快手/淘宝是 🔴。所以：

> **统一按「C1 清零 + C2/C3/C4 清零 + C5 给真实信息」的标准改，改完可以六个平台通用。**

平台差异体现在**C5 的松紧**上：
- 内容平台对 C5 加严 → 在内容平台发，C5 写成带具体日期、名额、规则的真实版本。
- 其他平台 C5 是 🟡 → 同一套真实版本也完全可用。

**结论：做一套「最严版」，六平台通用。** 这也是最省力的做法。

### 7.2 各平台必改项速查

| 平台 | 必改（发之前清零） | 建议改 | 可放宽 |
|---|---|---|---|
| 内容平台 | C2 / C3 / C4 / **C5** | C1 | — |
| 抖音 | C1 / C2 / C3 / C4 | C5 | — |
| 视频号 | C2 / C3 / C4 | C1 / C5 | — |
| 快手 | C1 / C2 / C3 / C4 | C5 | — |
| 淘宝/京东 | C1 / C2 / C3 / C4 | C5 | — |
| B站 | C2 / C3 / C4 | C1 / C5 | 词表松，版权另查 |

### 7.3 跨平台分发时最容易忘的三件事

1. **封面文字要单独扫**——每个平台的封面规则不同，且图片文字常被漏检。
2. **同一句口播在不同平台要复检**——尤其加了平台专属信息（如「抖音私信我」）后。
3. **B站要加查版权**——脚本查不出来，但这是 B站最常见的下架原因。

## 8. 平台口径的置信度说明

| 内容 | 置信度 | 依据 |
|---|---|---|
| 各平台对五类的加严系数 | **【脚本口径】可直接依赖** | 来自 `PLATFORM_STRICT` 常量，可复核 |
| C1 在抖音/快手/淘宝直接判高危 | **【脚本口径】可直接依赖** | 脚本第 268 行硬规则 |
| 各词在六平台的实际等级 | **【脚本口径】可直接依赖** | 已实测全词矩阵验证 |
| 「哪些词在某平台是雷」 | **【行业实测经验】** | 来自实际运营观察，非平台公开细则 |
| 「平台对某类内容的处置力度」 | **【行业实测经验】** | 会随平台策略变化，需自行复核 |
| 任何具体条款编号或官方文件标题 | **本文件不提供** | 平台未公开细则，编造条款号是误导 |
| 版权、资质、类目准入 | **本文件不覆盖** | 属于另一类问题，需单独核对 |

**给用户的一句话**：「平台规则每天在变，每个账号的处置口径也不一样。这份差异表能帮你把最重的雷排掉，但重要内容发布前，还是要看一眼你所在平台后台的社区规范——那才是当天的口径。」
