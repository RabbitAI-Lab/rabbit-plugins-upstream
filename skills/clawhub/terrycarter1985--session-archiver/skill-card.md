## Description:

Archive and organize completed OpenClaw session logs into structured markdown notes for long-term memory retention.

This skill is ready for commercial/non-commercial use.

## Publisher:

[terrycarter1985](https://clawhub.ai/user/terrycarter1985)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent users use this skill to turn completed session transcripts into concise, searchable markdown memory files with decisions, actions, blockers, and insights.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Archived session notes can retain secrets, credentials, private URLs, or sensitive project details beyond the original session.

Mitigation: Review and redact generated archives before keeping them long term.

Risk: Summaries may omit context or misstate decisions, actions, blockers, or status.

Mitigation: Review the generated archive against the source session before relying on it as project memory.
