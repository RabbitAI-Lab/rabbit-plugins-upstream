## Known Risks and Mitigations: <br>
Risk: Broad trigger keywords may cause accidental activation for loosely related browser, automation, CLI, or bug-fix prompts. <br>
Mitigation: Use the skill when the user explicitly wants Agent Browser-style workflow planning, reliability hardening, or adjacent skill design help; otherwise confirm fit before applying it. <br>
Risk: Generated workflow or implementation guidance could be incomplete or unsuitable for a user's environment. <br>
Mitigation: State assumptions, keep required inputs visible, and validate the result against the user's success criteria before finalizing. <br>
