# tech-bid-writer 触发词回归测试

> 用途：校验本技能触发词「锚定技术标写作专属场景、不跨技能误激活」，作为 clawhub / SkillHub 上架前的触发合规性回归。

> `技术标写作|写技术标|生成技术标大纲|技术标大纲|生成技术方案|按评分表生成技术标|技术投标文档|施工组织设计|技术偏离表|技术标评分点覆盖`

## 四、回归判定标准

- P1–P7 全部命中 → 触发覆盖合格。
- N1–N7 全部不命中 → 无跨技能误激活（避免 Trigger Abuse / Vague Triggers）。
- B1–B2 命中但语义属写作范畴 → 不越界进入合规审查/废标核查专属域。
- 若任意 N 用例误触发，需收窄 manifest 触发词（删除过宽正则分支）后重测。
