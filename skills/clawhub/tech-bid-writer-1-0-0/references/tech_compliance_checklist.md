# 技术合规预检清单（tech_compliance_checklist）

> 用途：阶段一「技术合规预检」与阶段四「合规红线门禁」的核查依据。
> 范围：**仅技术部分**。商务报价、资格审查、投标函等不在本清单内。
> 说明：本清单为通用技术废标/否决风险速查，地域与行业特殊规则以招标文件原文与外部合规技能复核为准。

## 一、★号 / 实质性技术条款响应

- [ ] 招标文件标注「★」「必须」「实质性」的技术条款，每条均有明确响应段落
- [ ] 实质性技术参数**不允许负偏离**；若无法满足，已在偏离表标注并给出等效替代方案（非★条款）
- [ ] 响应段落标题编号与招标条款编号对应，可回溯

## 二、常见技术否决 / 废标情形（技术侧）

- [ ] **资质/许可类**（技术相关）：所需专业资质、检测报告、认证证书在技术要求中未被虚构；缺失项已标「⚠️ 需人工核实」
- [ ] **关键技术参数**：核心性能指标（如处理能力、精度、工期、规格）与招标要求一致或正偏离；负偏离已说明
- [ ] **工期/进度**：承诺工期不优于（短于）招标强制性下限导致不可行；关键里程碑明确
- [ ] **署名盖章格式**（技术标常踩）：按招标文件要求签署/盖章/份数/装订；暗标项目未泄露投标人信息（公司名/Logo/项目负责人）
- [ ] **方案完整性**：招标要求的必备技术方案章节（如施工组织、质保、培训）无遗漏

## 三、技术规范有效性

- [ ] 引用的标准/规范注明名称与编号（如 GB/T、行业标准的年号），不写"符合相关标准"等空话
- [ ] 规范编号经「⚠️ 需人工核实」标注（AI 生成编号可能过时/错误）
- [ ] 同一参数在全文表述一致（无前后矛盾）

## 四、图纸 / 参数一致性

- [ ] 文字描述与招标文件图纸/清单参数一致
- [ ] 技术偏离表中"投标参数"与正文描述一致
- [ ] 多章节涉及的同一系统/设备参数无冲突

## 五、格式否决项（技术标）

- [ ] 文件组成、装订、密封、份数符合招标文件"提交要求"
- [ ] 字体/字号/行距符合（或已用 doc-format 声明）
- [ ] 暗标项目：页眉页脚/水印未含投标人标识

## 六、预检报告模板

```markdown
# 技术合规预检报告
- 项目：{项目名称}
- 预检结论：通过 / 需补充 / 红线风险

## 红线风险项（必须修复）
| # | 风险点 | 对应招标条款 | 说明 | 严重级 |
|---|--------|------------|------|--------|
| 1 | {风险} | {条款号} | {说明} | P0/P1 |

## 需人工核实项（AI 生成未溯源）
| # | 内容 | 位置 | 核实要点 |
|---|------|------|---------|
| 1 | {参数/规范/业绩} | {章节} | {核实要点} |

## 格式否决项
- [ ] 署名盖章 / 份数装订 / 暗标标识 / 字体版式
```

> **P0（致命，可能废标）**：实质性技术条款未响应、★参数负偏离、暗标泄露身份。
> **P1（严重，明显减分）**：关键技术参数矛盾、必备方案缺失、规范编号错误。
> **P2（一般）**：表述优化、版式微调。
