# IMA 知识库挂载结构模板（tech-bid-writer）

本模板用于规范**挂载到 IMA 知识库**的内容结构，使阶段二·A 能按知识库类型定向检索、精准命中真实素材，降低 AI 编造。

## 一、总体原则

1. **结构化优先**：每条记录用 Markdown 字段/表格，不要整本 PDF 直接丢入。
2. **带标签**：每条记录标注 `行业` / `关键词` / `日期`，便于检索与时效判断。
3. **分库挂载**：企业素材库、法规标准库、脱敏范例库分开，互不混杂。
4. **标时效**：证书/业绩/规范务必带日期——即使来自知识库，阶段二仍输出「⚠️ 需人工核实」。
5. **脱敏**：范例库去除真实公司名/Logo/金额，仅作结构与文风参考。

## 二、库 1：企业素材库（治幻觉核心）

### 2.1 资质与证书库

```markdown
# 资质证书：{证书名}
- 证书编号：{编号}
- 颁发机构：{机构}
- 有效期至：{YYYY-MM-DD}
- 资质范围：{可承接范围}
- 行业标签：{行业}
- 关键词：{证书名, 范围关键词}
```

### 2.2 业绩案例库

```markdown
# 业绩：{项目名}
- 年份：{YYYY}
- 合同金额：{金额} / 保密
- 关键技术指标：{指标}
- 我方角色：{牵头 / 分包 / 技术提供}
- 业主/客户：{名称}
- 行业标签：{行业}
- 关键词：{项目类型, 技术关键词}
```

### 2.3 人员证书库

```markdown
# 人员：{姓名/岗位}
- 证书：{建造师 / 工程师 / PMP ...}
- 证书编号：{编号}
- 专业：{专业}
- 有效期至：{YYYY-MM-DD}
- 行业标签：{行业}
- 关键词：{岗位, 专业}
```

### 2.4 产品与技术白皮书

```markdown
# 产品/技术：{名称}
- 类型：{系统 / 设备 / 平台}
- 核心参数：{参数表}
- 架构要点：{要点}
- 检测报告：{编号 / 结论}
- 行业标签：{行业}
- 关键词：{产品名, 技术关键词}
```

### 2.5 标准技术方案模板

```markdown
# 模板：{施工组织设计 / 质保体系 / 应急预案 / 培训方案}
- 适用行业：{行业}
- 结构大纲：{章节}
- 关键要素：{要素}
- 关键词：{模板类型, 行业}
```

## 三、库 2：法规标准库（合规 / 解析）

> 既有招投标法规库可直接复用；此处规范挂载格式，便于阶段一/四红线核对。

```markdown
# 规范：{标准号} {名称}
- 标准号：{GB/T xxxx—YYYY}
- 发布/实施日期：{日期}
- 适用行业：{行业}
- 关键技术要求摘要：{摘要}
- 关键词：{标准号, 主题}
```

废标 / 否决条款汇编：

```markdown
# 否决项：{行业} · {类型}
- 类型：资质 / 格式 / 参数 / 实质性条款
- 条款来源：{法规 / 招标文件范本章节}
- 风险说明：{说明}
- 行业标签：{行业}
- 关键词：{否决类型, 行业}
```

---

## 四、库 3：脱敏范例库（few-shot）

```markdown
# 范例：{行业} · {技术标类型}（已脱敏）
- 行业：{行业}
- 评分表结构：{结构}
- 章节范式：{章节}
- 术语表：{术语}
- 注意：已去除真实公司名 / Logo / 金额，仅作结构参考
```

> ⚠️ 范例必须脱敏：不得含真实投标人标识、合同金额、涉密信息。AI 仅参考其结构与术语，不直接抄录。

---

## 五、挂载库 ↔ 阶段二·A 检索路由

| 写作需要 | 路由到的库 | 检索主字段 |
|---------|-----------|-----------|
| 企业资质 / 业绩 / 人员 / 产品参数 | 库 1 企业素材库 | 行业标签 + 关键词 |
| ★条款 / 否决项 / 强制规范 | 库 2 法规标准库 | 标准号 / 行业 + 否决类型 |
| 文风 / 结构范式 | 库 3 脱敏范例库 | 行业 + 技术标类型 |

---

## 六、挂载质量自检

- [ ] 每条记录带 `行业标签` + `关键词`，可被精准召回？
- [ ] 证书 / 业绩 / 规范是否标注日期，避免过期命中？
- [ ] 范例是否已完成脱敏（无真实公司名 / 金额）？
- [ ] 三个库是否分开挂载，未混在同一文档？
- [ ] 记录是否为结构化字段，而非整本扫描 PDF？
