# 篇幅规划与字数预算（pages_budget）

> 配套：技术标写作专家 tech-bid-writer。
> 阶段0.5 篇幅规划 → 阶段二 分配各章预算 → 阶段四·门禁5 校验接近度。

## 1. 核心原则：页数由发起人掌握，AI 只推荐

- **发起人指定优先**：用户明确说「写 N 页」→ 以 N 为目标页数。
- **AI 推荐兜底**：用户未指定时，AI 依据「项目性质 + 项目金额」给出推荐页数区间（见第2–3节），由用户确认或调整。
- **不再有固定档位**：废除「1–50万→50页」式硬映射；页数是「建议/约定」，不是强制门槛。
- **页数只定总量**：章节预算按内容承载力分配（见第4节），不机械均分；达标靠合法扩写，禁止空话凑数。

## 2. 项目性质分类（nature）

技术标页数主要由「技术深度」与「可填充的结构化素材量」决定。分为六类：

| 性质 key | 典型项目 | 页数密度(页/万元) | 软下限 | 软上限 | 说明 |
|---------|---------|------------------|-------|-------|------|
| simple_svc | 物业/保洁/餐饮/保安/绿化/会务/租赁/后勤 | 0.13 | 30 | 150 | 技术浅，靠排班/台账/预案/标准填充 |
| goods | 货物/设备采购（含安装调试） | 0.22 | 40 | 250 | 靠参数/配置/供货/技术培训填充 |
| construct | 工程施工/装修/修缮 | 0.28 | 50 | 400 | 靠施组/工艺/进度/质量/安全填充 |
| it_sys | 信息化/系统集成/软件平台 | 0.30 | 45 | 350 | 靠架构/模块/接口/数据/安全/运维填充 |
| design | 设计/咨询/科研/规划/评估 | 0.25 | 35 | 300 | 靠方法论/方案/成果/案例填充 |
| opex | 运维/维保/运营/托管服务 | 0.15 | 30 | 200 | 靠运维体系/SLA/巡检/应急填充 |

> 软下限：低于则技术标显单薄、易被评「方案不详细」；软上限：高于则建议分册或聚焦核心，避免注水。

## 3. 推荐算法

```
recommended = clamp(round(预算万元 × 密度), 软下限, 软上限)
range        = [max(软下限, round(recommended×0.8)), min(软上限, round(recommended×1.2))]
```

示例：
- 医院物业服务，298 万 → 298×0.13=38.7 → 推荐 **39 页**（区间 31–47）
- 信息系统集成，1200 万 → 1200×0.30=360 → 封顶 **350 页**（区间 280–350，建议分册）
- 小型货物采购，60 万 → 60×0.22=13.2 → 触底 **40 页**（软下限）

可用 `scripts/recommend_pages.py --budget 298 --nature simple_svc` 即时计算；或 `--describe "医院物业服务项目"` 由关键词自动识别性质。

## 4. 预算分配（到五章；技术偏离表独立成篇，不计入）

技术偏离表约 1,500–3,000 字，单列。章节预算按「内容承载力权重」分配（可据项目微调），权重随性质略变：

| 章节 | 通用权重 | 说明 |
|------|---------|------|
| 一 重点难点/整体设想 | 1.0 | 所有性质都需 |
| 二 应急预案 | 0.9 | 服务/施工/运维更重 |
| 三 专项方案A* | 1.3 | 保洁(服务)/施工工艺(工程)/系统模块(IT) |
| 四 专项方案B* | 1.0 | 秩序(服务)/安全(工程)/接口(IT) |
| 五 设备运维 | 1.3 | 设备/工程/IT 更重 |
| 合计(章) | 5.5 | |

*专项方案 A/B 的具体指代随项目性质而定（见评分映射）。将「推荐总字数 = 推荐页数 × 1050」按上表权重拆分到各章即为每章字数预算。

## 5. 扩写技术（达预算但不注水）

- 增加 L3/L4 子节（如 保洁 → 各科室 SOP、消毒流程、频次标准）
- 列表化 SOP / 班次 / 巡检路线 / 责任人
- 表格化 人员配置 / 设备清单 / 频次标准 / 考核指标
- Mermaid 流程图（应急响应、巡检闭环、报修流程）
- 风险矩阵（风险—等级—控制措施）
- 量化指标（响应时间、到位率、设备完好率、满意度）
- **严禁**：空话重复、同义反复、与评分项无关的堆砌、复制粘贴凑数。

## 6. 对话约定（优先级）

1. 用户：「写 80 页」→ 以 80 页为目标。
2. 用户：「298 万医院物业，你推荐多少页」→ AI 按第2–3节推荐 39 页（区间 31–47），用户确认或改。
3. 用户仅给预算（如「这标 80 万」）→ AI 识别性质后推荐。
4. 用户未给任何信息 → 阶段0.5 主动询问：「这是什么性质的项目（如物业服务/工程施工/系统集成）？预算约多少万？你希望技术方案写多少页，或让我按性质+金额推荐？」
