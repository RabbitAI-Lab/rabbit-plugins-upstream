# Changelog

## 1.1.0

- 连接器下载改为 **SHA-256 校验**：官方分发源使用内置校验值；自定义源必须显式提供 `--sha256`，校验不符一律拒绝安装（防篡改 / 版本错配）。
- 安全收紧：自动连接链接**仅对官方画布域名**携带连接令牌；输出中的令牌改为脱敏显示（`tokenMasked`）。

## 1.0.0

- 初始版本：下载/启动画布连接器，生成「打开即连」链接（`#agentUrl`/`#agentToken` 自动连接）。
- 零危险调用设计：技能脚本仅做下载/检测/输出，启动命令由 LobsterAI（Agent）执行，兼容技能安全扫描。
