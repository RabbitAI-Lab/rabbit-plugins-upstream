## Description:

Design, generate, beautify, optimize, or review UIFlow2 interfaces, graphics, dashboards, gauges, animations, round-screen layouts, e-paper screens, and LED-matrix experiences for M5Stack devices.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to design, generate, optimize, or review embedded UIFlow2 interfaces for M5Stack devices, including dashboards, gauges, animations, round displays, e-paper screens, and LED-matrix experiences.

## Known Risks and Mitigations:

Risk: Generated or reviewed UIFlow2 code may be incorrect for the target hardware or firmware if device capabilities are not confirmed.

Mitigation: Review generated code before running it on hardware and authorize any device-changing actions separately.
