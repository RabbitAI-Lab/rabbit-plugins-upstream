## Description:

Helps AI-agent users, skill authors, maintainers, and teams create practical multi-search-engine workflow support, including plans, checklists, analysis, implementation help, and verification notes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

External developers, skill authors, maintainers, and agent users use this skill to turn multi-search-engine workflow demand into concrete support artifacts such as plans, checklists, implementation guidance, code changes, and validation notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad implicit invocation terms such as search and engine could route unrelated requests into this helper.

Mitigation: Disable or tighten implicit invocation, or require explicit invocation with the skill slug for teams that use many search-related skills.

Risk: Generated plans, checklists, code, shell commands, or configuration guidance may be incomplete or mismatched to the user's environment.

Mitigation: Review outputs before use, test code and commands in a controlled environment, and verify the final result against the stated success criteria.
