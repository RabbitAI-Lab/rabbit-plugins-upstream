# 差评回复草稿模板

> 复制本文件填充内容。每条差评的三版回复都必须含四要素：承认具体事实 / 说明原因（不甩锅）/ 给可执行补救 / 留下一步。填完对照 `references/attribution-rules.md` 的回复禁区清单逐条检查。

```
## 差评要点
- 评 1：[星级] [时间] [要点，含可核实事实]

## 归因结论
- 评 1：[类别1] + [类别2] → 依据：原文「……」

## 是否需私下跟进
- 评 1：[公开回复 / 建议私聊] → 理由：[触发条件]

## 回复草稿
### 标准版
[承认事实] + [说明原因，不甩锅] + [可执行补救] + [下一步]

### 简短版
[四要素压缩在一两句内，适合公开位]

### 私聊版
[转一对一，可约具体补救时间与方式]

## 需先核实的事项
- 评 1：[订单是否超期 / 是否已发货 / 补偿授权范围]

## 可改进项
- [改详情页哪句话 / 打包加什么 / 话术改哪里]
```

## 填写约束

1. 每条差评三版回复都要能回看出四要素，缺任一要素不合格
2. 归因必须附原文依据，不得凭感觉归类
3. 命中回复禁区（推诿、指责顾客、模板腔、超授权、要求改评删评）须重写
4. 缺订单信息或补偿底线时，补偿处用「已安排专人核实」占位，并列入需先核实事项
5. 涉及人身威胁或违法内容：不填回复草稿，改填「建议走平台申诉或报警」
