# 差评归因判定表与回复禁区

## 一、五类归因判定

判定前先问：差评里能提取出哪类可核实的事实？一类差评可同时命中多类，但每类都必须有原文依据，不能凭感觉归。

| 类别 | 定义 | 典型判定特征 | 典型表述（举例） | 回复侧重 |
|---|---|---|---|---|
| 产品本身 | 质量、描述不符、功能缺陷、实物与图文不一致 | 收到货与预期不一致、用坏了、和详情页写的不符 | 「色差太大」「用了三天就坏」「和图片不一样」「尺寸偏小」 | 承认事实 + 补救（退换/补发） |
| 物流与时效 | 发货慢、运输损坏、配送延误、快递态度 | 提到快递、到货时间、运输破损 | 「半个月才到」「快递把盒子压扁了」「说好今天到没到」 | 说明原因（我方发货/包装环节）+ 补救 |
| 服务态度与响应 | 客服不回、态度差、处理拖沓、售后推诿 | 提到「客服」「没人理」「踢皮球」「态度差」 | 「客服不理人」「问了三天没回」「态度很恶劣」 | 承认响应缺失 + 改进 + 专人跟进 |
| 期望落差 | 宣传与实际落差，非硬伤而是心理预期未满足 | 没有明确硬伤，但「以为会…结果没有」 | 「以为送赠品没有」「宣传很牛实际一般」「和直播间说的不一样」 | 解释宣传口径 + 降低后续预期 |
| 恶意或不合理 | 无事实依据的攻击、要挟、勒索、刷评 | 无具体事实、索要额外利益、情绪化辱骂 | 「必须给我钱否则天天差评」「根本没买过也来评」「纯骂街无诉求」 | 克制得体公开回复，不建议私聊纠缠 |

**并列归因示例：**「衣服色差大，客服还不理人」→ 产品本身（色差）+ 服务态度（不理人），两类都要写依据。

**判定依据写法：** 每条归因后必须附「依据：原文『……』」，不写依据视为未归因。

## 二、是否需私下跟进的触发条件

满足任一即建议私聊（转一对一沟通）：

1. 涉及具体金额或订单（退款、补发、赔偿）
2. 含顾客个人信息（姓名、电话、地址）
3. 需核实订单才能给出准确回复
4. 情绪激烈，公开回复会扩大矛盾

仅纯情绪宣泄、无事实诉求、也无个人信息 → 公开回复即可，不必私聊。

## 三、回复四要素（缺一不可）

1. 承认具体事实 —— 点出对方说的是哪件事，不复述空话
2. 说明原因 —— 解释为什么发生，不甩锅给「平台」「快递」等第三方，从「我方哪里没控好」讲
3. 给可执行的补救 —— 具体动作：补发、退款、优惠券、重新发货
4. 留下一步 —— 联系方式，或「已安排专人联系您核实」

## 四、回复禁区清单

命中任一条，回复必须重写：

| 禁区 | 表现 | 为什么不行 |
|---|---|---|
| 推诿 | 「这是快递的问题」「平台规定的」 | 把责任推出去，顾客觉得被踢皮球 |
| 指责顾客 | 「您自己没看说明」「您拍错了」 | 激化矛盾，即便顾客有错也先承接再引导 |
| 模板腔 | 单独出现「感谢您的反馈，我们会改进」 | 没有承认具体事实，等于没回复 |
| 超授权承诺 | 用户没说能退款却写「全额退款」 | 超出授权范围，商家无法兑现 |
| 要求改评/删评 | 「麻烦您改成好评」「删掉这条」 | 违规诱导，易引发二次投诉 |

## 五、三版回复的适用

- 标准版：四要素完整，适合私聊或长回复位
- 简短版：保留四要素但压缩字数，适合公开回复位受限
- 私聊版：转一对一，语气更具体，可约定具体补救时间或方式
