# 外贸全能助手

> 版本：V1.0.6 | 更新日期：2026-08-17

## 📌 简介

外贸全能助手是一款专为外贸从业者打造的智能工作平台，覆盖31个外贸场景、31个行业、31种语言，提供从开发信到客户背调的全链路服务。

## 🎯 核心能力

| 功能模块 | 说明 |
|---------|------|
| 文案生成 | 开发信/询盘回复/跟进邮件，支持31种语言 |
| 客户回复分析 | 10维度深度解读 + 成交概率评估 |
| 邮件跟进链 | 3阶段递进策略 + GDPR合规 |
| 获客背调 | 全球B2B资源 + 风险评估 + 信用评级 |
| GEO诊断 | AI搜索可见性优化（ChatGPT/Perplexity/Claude） |

## ✨ 特色亮点

- ✅ FABE营销框架融入正文
- ✅ 反AI味规则，输出自然专业
- ✅ 零占位符，复制即用
- ✅ 签名区条件化输出
- ✅ 154份专业知识库支撑

## 🚀 使用示例

### 示例1：写开发信
```
帮我写一封开发信，产品是不锈钢保温杯，目标市场德国，客户类型是连锁超市采购经理，核心卖点是双层真空保温12小时
```

### 示例2：分析客户回复
```
客户回复："Thank you for the quotation. The price is a bit high compared to other suppliers, but the quality seems good. Can you offer a 5% discount?"
```

### 示例3：获客背调
```
帮我背调一下 Samsung C&T Corporation，评估合作风险
```
