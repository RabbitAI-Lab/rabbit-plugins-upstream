# 文化适配详细指南

## 称呼规范

### 日本
- [姓]+様（如：田中様）
- 使用敬体（です/ます形）
- 避免数字4，避免直接说"买"（用"ご検討ください"）

### 韩国
- [姓]+님（正式）或 씨（半正式）
- 必须使用敬语

### 中东（沙特/卡塔尔/阿联酋等）
- Dear Mr./Sheikh [Name]
- 可加伊斯兰问候：As-salamu alaykum
-注意：إن شاء الله仅用于口语，书面商务邮件少用
- 不涉及猪/酒/赌博比喻

### 德国
- Sehr geehrte(r) [Title] [Name]（如：Sehr geehrter Herr Müller）
- 使用Sie（正式称谓）
- 效率优先，直奔主题，数据说话

### 拉美（巴西/墨西哥/阿根廷等）
- Estimado/a [Name]
- 语气可以更warm
- 重视长期关系，灵活性强
- WhatsApp为主，邮件辅助
- 避免过度正式

### 英语通用
- Dear Mr./Ms. [Last Name]（正式）
- Hi [First Name]（半正式）
- 灵活替换：预留Mr./Ms.替换空间

### 印度
- Dear Mr./Ms. [Last Name]
- 不涉及牛皮制品（用合成革替代）
- 避免数字13

### 泰国
- 称呼按商务习惯
- 避开佛教节日打扰
- 避免皇室相关话题

## 发送时段规范

### 中东常规月份
周日-周四 9:00-11:30 / 15:00-17:00（当地时间）

### 中东斋月
仅晚间20:00-22:00发送（日落后开斋后），避开白天工作低效时段

### 泰国
工作日 9:00-11:30 / 14:00-16:00，避开佛教节日

### 南美
周一至周五 9:00-12:00 / 15:00-18:00（当地时间）

### 欧美（B端）
周二/周四 9:00-11:30 / 14:00-16:30

### 欧美（社媒）
北美 19:00-23:00 / 欧洲 18:00-22:00
