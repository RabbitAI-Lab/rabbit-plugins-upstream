# EPLAN 电气图纸 · 常用位号与特征

用于帮助解析器识别元件类型。EPLAN 电气图中元件位号遵循 IEC 81346/GB 惯例。

## 常用位号前缀

| 前缀 | 元件类型 | 示例 |
|------|---------|------|
| QF / Q | 断路器、塑壳断路器 | QF1001, Q1 |
| FU / F | 熔断器 | FU1001, F1 |
| SPD | 浪涌保护器 | SPD1-14 |
| KM | 接触器 | KM20 |
| KA | 继电器 | KA1 |
| K | 中间继电器/限位 | K1 |
| TA | 电流互感器 | TA1 |
| X | 端子排 | X1-X8 |
| H / HL | 指示灯 | H1, HL1 |
| S / SB | 按钮、选择开关 | S1, SB1 |
| TC | 温控器 | TC1 |
| Q / QF | 电源断路器 | |
| U / V | 电源模块/UPS | U1, UPS |
| FAN | 风扇 | FAN1 |
| CPU / HMI / ET200 / IM | 西门子PLC模块 | CPU, HMI, IM155 |

## 位号命名规律

- **连续编号**：如 QF1001-1007（同一柜输出保护），QF1008-1014（下一柜）
- **分组号段**：QF1001-1014 = 14个直流断路器；FU同号段对应熔断器
- **前缀+三级号**：QF(类别)-10(柜号)01(顺序)

## 常见导航

- 主功率导线常为粗线（多 `2xAWG00`、`7AWG` 等大截面），用 `RD`(红)/`BK`(黑) 表示正/负极
- 信号/反馈线多为细线（`17AWG` 等），用 `BU`(蓝)/`BU-WH`(蓝白)
- EPLAN 每页右下角为标题栏（含图号、图名、版本、日期）
- `至AGHxx`/`TO AGHxx` 表示跨页连接点（AGH=绝缘监测模块）
