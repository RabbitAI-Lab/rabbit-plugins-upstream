# Knowledge · 知识库

本目录存放 EPLAN 电气图纸解析的领域知识，辅助解析器正确识别元件类型、位号规律和线路特征。

## 文件

| 文件 | 内容 |
|------|------|
| `eplan_symbols.md` | EPLAN 常用位号前缀、元件类型映射、位号命名规律、导线颜色/截面特征 |

## 用途

- 位号前缀 → 元件类型（QF=断路器, FU=熔断器, SPD=浪涌等）
- 识别主功率线与信号线（截面 + 颜色）
- 识别跨页连接标记（至AGHxx / TO AGHxx）
