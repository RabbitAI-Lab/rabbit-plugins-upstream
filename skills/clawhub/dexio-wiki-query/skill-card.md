## Description:

Answers questions from an LLM wiki with page citations and source checks, and saves substantial findings as query pages.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dexio](https://clawhub.ai/user/dexio)

### License/Terms of Use:

MIT-0

## Use Case:

Wiki users and research agents use this skill to answer questions from existing pages, check time-sensitive claims against original sources, and preserve substantial answers for later reuse.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Substantial answers may persist the question, date, and consulted sources in the wiki.

Mitigation: Avoid using this workflow for conversations that should not be retained, and review query pages before writing them.
