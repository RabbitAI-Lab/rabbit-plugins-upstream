# 面板与系统回顾

> **何时读**：这个人说“打开我的系统”“看看我的面板”或“我现在到哪了”；过了一个月，这个人回来了；或者这个人想要一张可以分享的面板卡或一份回顾。

## 面板

“打开我的系统”展示的是这个人的系统此刻的样子。它是那一刻从系统文件里读出来的。它不是一份存起来的仪表盘，也不是一种汇报状态的仪式。

它展示：

- **开启过的系统**，每个一句话的本质。
- **正在使用的实践**，每项附目前的结果和下一次审视。
- **正在盯住的东西**：信号，以及其中触发了的。
- **个人能力与个人路线。**
- **这个人已经能独立使用的方法。**
- **等级**（如果等级开着），证据只隔一步。
- **此刻**：最值得做的一件事，以一个选择给出。

每一项都链接到它的证据：那个入口，那份实践记录，那次独立使用方法的场合。背后什么都没有的项目，不展示。

### 分寸

- **“此刻”放在最前。** 面板是为了帮这个人行动而存在的。那份清单是在支撑那一个推荐；清单本身不是重点。
- **系统还年轻时，面板就短。** 一次运行之后，面板就是一个系统、它的本质和一个下一步。不要用空的类别去填；没有内容的类别不出现。
- **用这个人的话。** 系统名和本质，是这个人自己的对象，用这个人的语言。
- **形式跟着宿主走。** 在终端里，是一块紧凑的文字面板。在能渲染网页的地方，是一个从这个人的系统里长出来的页面。面板没有固定的版式；固定的只有它的内容。
- **它是入口，不是终点。** 每一行都可以用一句话打开、继续或采取行动。
- **这个人如果带着一件事来，就做那件事。** 面板是给“打开我的系统”用的，不是每次会话的开场白。

### 面板卡

**面板卡**是面板可以分享的形式，1:1 和 9:16 两种，做法和发现卡一样（见 `display/share-pack.md`）。

它**默认可安全分享**：它展示数字和方法的名字（开启的系统数、正在使用的实践数、能力、独立使用的方法、等级），隐藏一切私人内容：系统名与本质、实践细节、盯住的东西、任何关于别人的内容。这个人逐项选择还要展示什么。你从不发布它。

## 系统回顾

每个月，当这个人回来时，提议做一次**系统回顾**。那个月只提议一次，作为一个选择；被拒绝了，到下个月之前不再提。

它涵盖这段时间里的：

- **开启了什么**：各个系统，每个附上最重要的那个揭示；
- **学到了什么**：第二份记录里的变化，用这个人自己的说法；
- **哪些实践有效**，附测得的结果；哪些被调整或放弃了，以及为什么；
- **这个人现在能独立使用哪些方法**；
- **发生了什么变化**：这个人的处境、这个人的系统、现在能做到的事；
- **接下来**：给下个月的一个推荐，以一个选择给出。

### 它只包含真实的内容

系统回顾是为分享而设计的，就像年度回顾。正因为如此，它不能讨好：

- 每个数字都是从系统文件里数出来的，每个说法都链接到它的证据；
- 安静的一个月，就报告成安静的一个月。一份简短而诚实的回顾，好过一份注了水的；
- 没有奏效的实践也在回顾里，连同从中学到了什么；
- 系统拿不出依据的东西，一概不放。

### 形式

回顾是一份成果，遵循 `engines/express.md`：由一个关于这个月的发现领头（这段时间的揭示），形式从这个人的这个月里长出来。它带着签名，也有分享包。它可分享的版本，遵循和面板卡一样的安全分享规则。

### 回顾改变了什么

回顾，也是把“改进”这个阶段用在这个人的整个系统上。借它做系统需要的整理：改写变长了的入口，让不再使用的实践和代码退役，更新审视日期，记下这个人为下个月选的方向。用一句话说明整理了什么。
