## Description: <br>
Deduplicator helps an agent suppress repeated content and links within the current conversation. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[xiiang0529](https://clawhub.ai/user/xiiang0529) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Agents and users can use this skill when processing lists such as search results or profile entries and want repeated content or links skipped within a conversation. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Repeated items may be omitted from results even when the user wants to reconsider them. <br>
Mitigation: Use the reset command when starting a new task or when duplicate tracking should start fresh. <br>
