## Description:

A daily refreshed catalog of agent skills across development, productivity, media, and other categories for use with multiple agent runtimes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[leoyeai](https://clawhub.ai/user/leoyeai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent users can browse the catalog to find skills for common workflows and follow the installation guidance to add selected skills to supported agent runtimes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Catalog entries link to separately downloaded skills whose behavior and future updates are outside this package's scan.

Mitigation: Review each skill's files and permissions before enabling it, especially for account access or automation, and review updates before use.
