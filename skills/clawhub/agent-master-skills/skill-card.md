## Description:

A curated, daily updated collection of agent skills for AI tools, productivity, marketing, development, DevOps, media, finance, communication, and more.

This skill is ready for commercial/non-commercial use.

## Publisher:

[leoyeai](https://clawhub.ai/user/leoyeai)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers can browse or install individual agent skills for tasks across common work and technical areas. The collection's SKILL.md format is described as compatible with multiple agent harnesses.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The broad collection description may lead an agent to activate skills beyond the task's needs.

Mitigation: Choose only the specific skill needed and review its instructions before use.
