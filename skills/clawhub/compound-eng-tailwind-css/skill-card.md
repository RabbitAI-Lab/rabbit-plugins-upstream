## Use Case:

Developers and engineers use this skill when styling applications with Tailwind CSS v4, configuring CSS-first theme tokens, creating variant-based components, migrating Tailwind v3 projects, or resolving dark mode and missing-style issues.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Tailwind CSS edits and migrations can change styling behavior or remove legacy configuration unexpectedly.

Mitigation: Review generated project changes before applying them and run the project build or equivalent Tailwind verification.

Risk: Class scanning, CSS-first theme tokens, overlays, and visibility behavior may fail silently in application code.

Mitigation: Inspect generated CSS, check for conflicting or deprecated classes, and verify affected layout, focus, and overlay behavior in a browser when relevant.
