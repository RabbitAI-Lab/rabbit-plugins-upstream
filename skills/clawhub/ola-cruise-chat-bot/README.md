# Cruise Product Chat Bot

An AI chat bot designed to assist users in finding and booking cruise products right from their chat interface.

由 [CruiseSkillBridge](https://cruiseskillbridge.com) 发布到 [ClawHub](https://clawhub.ai)。

## 安装

```bash
openclaw skills install @OWNER/ola-cruise-chat-bot
```

> 将 `OWNER` 替换为 ClawHub 发布者 handle。
