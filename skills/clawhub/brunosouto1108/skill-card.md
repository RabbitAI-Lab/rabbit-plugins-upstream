## Known Risks and Mitigations: <br>
Risk: Persistent council and self-improvement behavior may continue operating or propose changes without clear safeguards. <br>
Mitigation: Run only in a sandbox until explicit approval, disabled-by-default behavior, audit logging, rollback, and stop controls are verified. <br>
Risk: Broad MCP/A2A or production-server access could expose credentials or sensitive systems if connected too early. <br>
Mitigation: Do not connect production credentials or broad tool access until the behavior is scoped, tested, and limited with least-privilege permissions. <br>
Risk: The install script installs several dependencies and creates user-level configuration, so local environment changes may be hard to inspect after the fact. <br>
Mitigation: Review the install script first and install in an isolated virtual environment or disposable workspace before using persistent credentials. <br>
