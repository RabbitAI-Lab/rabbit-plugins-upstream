# Judge.me tools via Agiexa (8)

Preview only - these become available to the agent after Agiexa launches (November 2026) and the merchant connects Judge.me and turns the tools on. They cannot be called today.

Interactive explorer: https://agiexa.com/integrations/judge-me

| Tool | What it does |
| --- | --- |
| `JUDGEME_LIST_REVIEWS` | List the merchant's Judge.me product and store reviews |
| `JUDGEME_GET_REVIEW` | Get one Judge.me review by its Judge.me review ID |
| `JUDGEME_COUNT_REVIEWS` | Count the merchant's Judge.me reviews, optionally for one product and/or star rating |
| `JUDGEME_SET_REVIEW_VISIBILITY` | Publish or hide a Judge.me review on the storefront |
| `JUDGEME_REPLY_TO_REVIEW` | Post a PUBLIC reply from the store, shown under the review on the storefront |
| `JUDGEME_SEND_PRIVATE_REPLY` | Send a PRIVATE email reply to the author of a Judge.me review (not shown on the storefront) |
| `JUDGEME_GET_PRODUCT` | Look up the Judge.me product (and its Judge.me internal product ID) for a Shopify product ID or product handle |
| `JUDGEME_PRODUCT_RATING_SUMMARY` | Find the lowest (or highest) rated products |
