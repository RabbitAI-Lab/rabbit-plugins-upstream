# Google Search Console tools via Agiexa (9)

Preview only - these become available to the agent after Agiexa launches (November 2026) and the merchant connects Google Search Console and turns the tools on. They cannot be called today.

Interactive explorer: https://agiexa.com/integrations/google-search-console

| Tool | What it does |
| --- | --- |
| `GOOGLE_SEARCH_CONSOLE_ADD_SITE` | Adds a site to the set of the user's sites in Google Search Console |
| `GOOGLE_SEARCH_CONSOLE_DELETE_SITE` | Removes a site from the user's Google Search Console sites |
| `GOOGLE_SEARCH_CONSOLE_GET_SITE` | Retrieves information about a specific Search Console site |
| `GOOGLE_SEARCH_CONSOLE_GET_SITEMAP` | Retrieves sitemap metadata (submitted/indexed counts, errors, warnings, last-submission timestamps) for a specific sitemap in Search Console |
| `GOOGLE_SEARCH_CONSOLE_INSPECT_URL` | Inspects a URL for indexing issues and status in Google Search Console |
| `GOOGLE_SEARCH_CONSOLE_LIST_SITEMAPS` | Lists all sitemaps for a site in Google Search Console |
| `GOOGLE_SEARCH_CONSOLE_LIST_SITES` | Lists all verified sites (properties) owned by the authenticated user in Google Search Console |
| `GOOGLE_SEARCH_CONSOLE_SEARCH_ANALYTICS_QUERY` | Queries Google Search Console for search analytics data including clicks, impressions, CTR, and position metrics |
| `GOOGLE_SEARCH_CONSOLE_SUBMIT_SITEMAP` | Submits a sitemap to Google Search Console for indexing |
