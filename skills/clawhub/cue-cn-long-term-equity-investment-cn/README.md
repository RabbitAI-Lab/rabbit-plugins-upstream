# 长期股权投资·逐条挂源

给一份年报附注的**长期股权投资**一节，把这张表读成一张**每条都能回到原句**的台账：按被投资单位列的明细、核算方法与分类、权益法确认的投资损益、投资收益与现金分红的对应、减值与处置。

长期股权投资是附注里**最容易被顺手推一步**的一节：持股 20% 以上就默认权益法、净利润乘持股比例就是投资收益、投资收益减现金分红就是「留存收益」——三处都不是披露写的，却都能自己算出来。本件把披露怎么写逐条登记下来，**分类只抄原句，三个数不轧差**，判断留给人。

**不判被投资单位值不值钱、不评估投资能否收回、不预测投资收益、不建议追加或退出、不评价对赌条款、不测算对 EPS 与股价的影响、不给评级与目标价。**

---

## 一、三十秒跑通（零输入）

不给任何数据文件，也能跑出一份完整合规的成品，看它长什么样、判据怎么打：

```bash
python3 scripts/check_long_term_equity.py --demo
```

把这份样例存下来再跑一遍机检，它能自己过：

```bash
python3 scripts/check_long_term_equity.py --demo > 样例长投稿.md
python3 scripts/check_long_term_equity.py 样例长投稿.md
# → 样例长投稿.md 结论：五道全过（零发条）
```

接着换成你自己那份稿子：

```bash
python3 scripts/check_long_term_equity.py 你的长投稿.md
```

退码 `0` 全过、`1` 有发条、`2` 用法错、`3` 读不到文件或空稿。

### 拿不到成品时，从原文开始的三步

1. **定主体与报告期**，拿到年报附注里「长期股权投资」那一节，连同重要会计政策里关于合并范围与长期股权投资核算方法的那段。
2. **每节抄事实，连原句一起抄**：一条 = 一行，行末挂 `「原句」〔锚：页/表〕[S#]`。一个被投资单位一组，期初、增减、期末、持股比例、表决权比例各占一行。
3. **跑一遍自检**，红一条改一条：

```bash
python3 scripts/check_long_term_equity.py 你的长投稿.md
```

## 二、五道机检在管什么

| 码 | 管什么 | 典型触发 |
|---|---|---|
| `LE-STRUCT` | 形制 | 缺自标、缺 `主体：`／`报告期：`、节序不对、前五节里某一节空着 |
| `LE-QUOTE` | 原句与锚 | 数字行没挂「原句」〔锚〕[S#]，或来源行缺 URL／检索日，或引了没登记的 [S#] |
| `LE-NOSELF` | 不自推不自算 | 原句没写「权益法」却按持股比例自己标；三个数拼成等式；比例没标〔自算〕或没给分母 |
| `LE-GAP` | 缺口两向点名 | 正文写了未取到、第六节没点名；或第六节点了名、正文没有这条；或用「不适用」搪塞 |
| `LE-LINE` | 红线 | 「具有投资价值」「预计投资收益将增厚利润」「业绩承诺可实现」「目标价」 |

五道全过时结论行是 `结论：五道全过（零发条）`。

## 三、四条红线（这件的立身之本）

1. **分类与核算法只认原句。** 20%／50% 是常识门槛，不是判据：某单位算联营还是合营、能不能控制、用成本法还是权益法，**只有披露知道**。本件不替它判，也不按持股比例补。
2. **三个数不自行轧差。** 被投资单位净利润、按持股比例确认的投资收益、未实现损益抵消额各有披露值；「本期确认的投资收益」与「本期收到的现金分红」也是两个数。把它们拼成等式就是替披露做了减法，缺的那个写 `未取到`。
3. **自算必须交代来路。** 比例一类数值原句里找不到的，必须标〔自算〕并给分子分母，还须写明各取哪一句。
4. **不判投资成色。** 值不值钱、能否收回、本金是否安全、该不该追加或退出、对赌是否合理、对 EPS 与股价的影响、评级与目标价——一律 `[待人工]`。

## 四、一条发现长什么样

```
- 对乙公司权益法确认损益 12,000,000.00 元「本期按权益法确认对乙公司的投资收益 12,000,000.00 元」〔锚：2025 年年报·第 154 页·附注七·长期股权投资〕[S1]
```

结构是 `- 项名 值 「原句」〔锚：位置〕[S#]`。四项缺一不可（`未取到` 行、`[待人工]` 行与〔自算〕行是三个例外）。

自算的一行长这样：

```
- 投资收益与现金分红之比 50.00%〔自算〕分子＝本期确认的投资收益 12,000,000.00 元 [S1]｜分母＝本期收到的现金分红 6,000,000.00 元 [S1]
```

这个比例原句里没有，所以标〔自算〕，并把分母交代清楚。**注意「两者差额」不在这条线上补**——差额要么披露给，要么单独写成 `未取到：两者差额及其披露解释`。

## 五、和另外几枚包怎么分

| 你的问题 | 该用哪一枚 |
|---|---|
| 关联方关系、关联交易的定价与披露 | `cue-related-party-terms-cn` |
| 商誉与长期资产的减值风险判定 | `cn-goodwill-impairment-risk` |
| 控股股东变更与控制权变动 | `cn-controlling-shareholder-change-cn` |
| 四期差异、科目勾稽的点评 | `cn-earnings-note` |
| **投了哪些单位、各占多少、用哪个方法、确认多少损益、减值和处置怎么写** | **本件** |

一句话分界：本件只登记**长期股权投资这一节披露怎么写**，不判投资价值、不判关联关系、不判减值是否充分、不做跨期勾稽点评。

## 六、素材从哪来

- 首选：年报附注里「长期股权投资」一节 + 重要会计政策里核算方法与合并范围那两段；
- 次选：交易所同披件、招股书的长投与对外投资节；
- 末选：第三方摘要——本件会把它降级标注「二手、未对过附注」。

数据通道以目录现值为准：先匿名取 `https://cuecue.cn/api/mcp-catalog`，按返回的域与 `routing` 连；解析腿（`cue-omni-reader`）只在原句落在长附件或扫描件里时才发起。两步形制如下（域与工具名一律照现场返回填，不要照抄示例值）：

```bash
# 一、匿名发现：取现值域清单与 routing（不写死域与工具名）
curl -s https://cuecue.cn/api/mcp-catalog | head -c 400

# 二、已连上后取工具清单：以现场返回为准
curl -s -X POST "$MCP_ENDPOINT" \
     -H "Authorization: Bearer $CUE_API_KEY" \
     -H 'Content-Type: application/json' \
     -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | head -c 800
```

配置页只作指针：文本腿 <https://cuecue.cn/hub/mcp>、解析腿 <https://cuecue.cn/hub/omni-reader>、key <https://cuecue.cn/hub/api-key>。

## 七、跑夹具与测试

```bash
bash scripts/fixtures/run_fixtures.sh                     # 三档，末行现算档数
python3 scripts/check_long_term_equity.py --selftest      # 13 档内置夹具
python3 tests/test_long_term_equity.py                    # 16 条包级测试
```

runner 的末行形制是 `档数=N（由上面逐档现报）｜不合=M｜不可判=K`。**档数不写死在文档里**——加了注入就自己变，写死迟早对不上。

## 八、首次运行埋点

第一次跑（任何子命令）会在 `~/.cue-usage/` 下落一枚空文件 `cue-cn-long-term-equity-investment-cn-YYYY-MM-DD`。同日重复跑只留一枚；家目录不可写或无 `HOME` 时静默跳过，不影响主流程。
