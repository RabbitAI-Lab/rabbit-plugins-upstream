# 变更记录

### 0.1.0 — 2026-11-13（新建：长期股权投资的逐条挂源）

首版。`长期股权投资` 这一节在仓内既有件与平台检索两侧都是空白位（这一判断来自选件前的查位，本件未重新计数）。它是附注里**结构最固定**的一节：四张现成的表——按被投资单位列的明细、核算方法与分类、权益法确认的损益、减值与处置——每一格都能逐条挂回原句，同时每一格旁边都放着一个「顺手推一步」的陷阱。

**一、五块内容**

1. **按被投资单位列的明细**：期初余额、本期增减（追加投资／收回投资／权益法确认损益／其他权益变动）、期末余额、持股比例、表决权比例，一个单位一行，名称与比例只认原句；
2. **核算方法与分类**：子公司／合营企业／联营企业的划分、成本法与权益法的适用——**这个划分与适用是披露做的判断，只照抄，不按持股比例（20%／50%）自己推**；
3. **权益法确认的投资损益**：被投资单位本期净利润、按持股比例确认的投资收益、内部交易未实现损益的抵消——三个数分开登记，**不自行轧差**；
4. **投资收益与现金分红的对应**：本期确认的投资收益、本期收到的现金分红、两者差额及其披露解释——差额算不出就写 `未取到`；
5. **减值与处置**：减值准备期初期末与本期计提、处置投资的损益、对赌或业绩承诺的安排——没披露逐项写 `未取到`。

**二、五道机检（`scripts/check_long_term_equity.py`）**

| 码 | 判什么 |
|---|---|
| `LE-STRUCT` | 头部四件自标 + `主体：`／`报告期：` + 七节按序 + 前五节各至少一条发现行 |
| `LE-QUOTE` | 每条发现行以「」+〔锚：…〕+[S#] 收尾；来源行带 URL 与检索日；引用编号都登记 |
| `LE-NOSELF` | 分类与核算法只认原句；比例自算须标〔自算〕带分子分母；三个数不得拼成等式 |
| `LE-GAP` | 正文与第六节两向点名；零缺口写 `未取到：无`；禁「不适用」类措辞 |
| `LE-LINE` | 投资成色、收益预测、追加退出建议、EPS 与股价影响、评级目标价 |

**三、离线 runner 三档**

档① 机检自测 ／ 档② 好样坏样逐枚单跑 ／ 档③ 20 支边界形逐枚单跑（14 支该红、6 支反证）。每支注入都先断言落地、都只钉一道码，且断言注入点在源件里**恰好出现一次**。档数由 runner 末行现算，文档里不写死。

**四、包级测试（`tests/test_long_term_equity.py`，16 条）**

入口契约（`--help` 退 0／无参退 2／缺件退 3／空稿退 3／自测退 0）、零输入（`--demo` 能跑、能过自己的机检、确定性、与 good 夹具字节相同）、判据行为（坏样五道齐发、好样零发条）、**专项反证（持股 30% 单独出现不足以成为权益法依据：原句没写权益法就必须发 `LE-NOSELF`，且不许连带发结构码与原句码）**、首次运行埋点（落一枚空文件、同日不增殖、失败静默、无 HOME 静默）。

**五、本件的立身之本**

这一节的诱惑不是「算错」，而是**替披露接着写下去**：持股过了 20% 就默认权益法、净利润乘持股比例得到投资收益、投资收益减现金分红得到一个「差额」。三处都能算出来，三处都不是披露写的。所以判据的承重格不是「数字对不对」，是**词族与本件断言分离**：核算方法词必须落在同一行的「」里，三个独立数不许被拼成等式。前者管分类，后者管轧差。

**六、第一版自己踩的五处（记下来给下一枚用）**

1. **反证样换错了行，把词族换到了「」外面。** `OK_QUOTED_REDLINE` 这支本意是证明「引文里的红线词不算本件断言」，第一版把换的引文放在成本法那一行，结果项名被剥掉后，值位里露出的「成本法」在原句里已经没有了，`LE-NOSELF` 照样发——反证样自己红了。**改为换在减值准备那一行，其值位不含任何核算方法词族。** 这是上一枚第 2 条教训的同一形状：反证样必须换在判据**不该看**的那一格，而不是换在判据顺带会看的格子上。
2. **坏样靠差分生成，opcode 一对就叠。** 第一版拿 `difflib.SequenceMatcher` 从「五支单点注入」的原文派生 `bad-long-term-equity.md`，delete/replace 两个 opcode 覆盖了同一段文本，落盘直接断言失败。**改为显式的五对 `(old, new)`，逐对断言 `count(old) == 1`。** 坏样要能被人读懂是哪五处坏的，差分生成做不到这件事。
3. **注入点选得太短，同一句在源件里出现两次。** 档③ 的「锚值为空」一支最初只注入 `〔锚：2025 年年报·第 154 页·附注七·长期股权投资〕 → 〔锚：〕`，runner 报「注入点在源件里出现 2 次」直接判不可判。**改为把注入目标连同前面的「原句」一起写成一段更长的锚文。** 断言恰好一次是对的，但注入点得先足够唯一。
4. **反证注入只改了一处，另一处的对账立刻断掉。** 档③的「〔自算〕差额交代分子分母」这支，本意是把正文里「两者差额」那行改成一个合规的〔自算〕行证明不误伤；只改正文、留着第六节的 `未取到：两者差额及其披露解释`，两向点名就断了，冒出一条假 `LE-GAP`。**改为正文与第六节两处一起改。** 凡是两向对账的项，注入必须双向改。
5. **`--demo` 落盘前没建目录。** `python3 scripts/check_long_term_equity.py --demo > scripts/fixtures/good-…md` 报 `No such file or directory`——`scripts/fixtures/` 还不存在。先 `mkdir -p`。

**七、红线自查**

零网络、零凭据、零外部依赖；`--demo` 零输入可跑且与 good 夹具字节相同；坏样五道齐发无连带码；README 里有同时含 `curl` 与 `tools/list` 的围栏块（首屏判据只读 README）；本件不在场景图表一孤点清单内（`consumes: [parsed-doc]`，`produces: [structured-note]` 有真实接入）。
