## Description:

Run multiple agents in parallel and merge results with intelligent error handling and resource management.

This skill is ready for commercial/non-commercial use.

## Publisher:

[z-hussein](https://clawhub.ai/user/z-hussein)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use the skill to divide independent research, coding, data-processing, or testing work among multiple agents, then review a consolidated report of results and failures.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Delegated-agent reports and shared scratch files may contain task output that is sensitive or misleading.

Mitigation: Limit delegated data to what is appropriate, protect shared scratch storage, and review merged reports before acting on them.
