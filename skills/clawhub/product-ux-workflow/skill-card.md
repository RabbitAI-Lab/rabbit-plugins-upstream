## Description:

Guides agents through a four-stage product UX workflow covering requirements research, user scenarios, information architecture, wireframes, visual design alignment, and developer handoff.

This skill is ready for commercial/non-commercial use.

## Publisher:

[fize](https://clawhub.ai/user/fize)

### License/Terms of Use:

MIT-0

## Use Case:

Product managers, UX designers, and product-focused developers use this skill to plan new web or mobile product experiences, map user journeys, structure information architecture, define wireframes and interaction states, and prepare developer handoff documentation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Structured UX guidance can be applied without enough product or user evidence, leading to misleading requirements, journeys, or wireframes.

Mitigation: Review goals, user scenarios, constraints, and design decisions with product and UX stakeholders before using outputs for implementation.

Risk: Developer handoff documentation may omit states or precise implementation details if the agent output is not checked against the skill's hard rules.

Mitigation: Verify loading, empty, error, hover, focus, disabled, active, and edge states, along with pixel-level annotations, before development.
