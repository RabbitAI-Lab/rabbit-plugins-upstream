## Description:

Guides agents to create, edit, upscale, and analyze images, videos, and music with Sogni AI's creative tools.

This skill is ready for commercial/non-commercial use.

## Publisher:

[sogni-ai](https://clawhub.ai/user/sogni-ai)

### License/Terms of Use:

MIT

## Use Case:

External users can ask their agent to generate, edit, upscale, or analyze media through Sogni AI, including image, video, music, speech, and 3D workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected reference media may be processed remotely, which can raise privacy concerns for sensitive content.

Mitigation: Review remote processing terms and avoid sending sensitive media unless that processing is acceptable.

Risk: Model selection and generation settings can affect cost.

Mitigation: Check the selected model, billing option, and expected cost before starting a job; use paid priority only with the user's opt-in.

Risk: Install instructions may use unpinned packages, and some environments may request elevated privileges.

Mitigation: Review install commands and package versions, and grant elevated privileges only when understood and necessary.
