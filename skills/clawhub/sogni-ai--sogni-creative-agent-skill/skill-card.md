## Description:

Sogni Creative Agent lets AI agents create and edit images, videos, music, and related creative assets through Sogni services.

This skill is ready for commercial/non-commercial use.

## Publisher:

[sogni-ai](https://clawhub.ai/user/sogni-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent users use this skill to create or edit creative media from prompts and reference assets, and to coordinate multi-step creative workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and selected media may be sent to remote processing services.

Mitigation: Review privacy and model-routing details before use, and avoid submitting sensitive media or prompts unless the applicable service terms are acceptable.

Risk: Installation examples may use unpinned packages and setup may add persistent agent configuration.

Mitigation: Review package versions and setup changes before installation, and check the resulting agent configuration.
