# powpow-register

PowPow बुलबुला रजिस्ट्रेशन सहायक (OpenClaw संस्करण): एक नए उपयोगकर्ता को «बुलबुला क्या है पता नहीं»
से लेकर «अकाउंट सक्रिय, वन-क्लिक लॉगिन, खेलने के लिए तैयार» तक ले जाता है — प्रोडक्ट परिचय
(इंटरफ़ेस स्क्रीनशॉट समेत), agent-प्रतिनिधि रजिस्ट्रेशन (अवतार अपलोड समेत), Alipay/PayPal सदस्यता ऑर्डर और
पैसे आने तक ट्रैकिंग, डबल-लिंक वन-क्लिक लॉगिन, एरर-निवारण।

**v2.0.0 से यह एजेंट-सहायक मोड है, और v2.2.0 से प्लेटफ़ॉर्म की मुफ़्त परीक्षण अवधि के अनुकूल भी**: मुख्य स्क्रिप्ट `scripts/powpow-register.mjs` शून्य-निर्भरता वाला है
(Node ≥ 18); उपयोगकर्ता बातचीत सिर्फ़ एक बार छोड़ता है: इनबॉक्स में सत्यापन कोड चेक करने के लिए। वर्तमान मुफ़्त परीक्षण अवधि में पंजीकृत खाता तुरंत हर सुविधा का उपयोग कर सकता है — सदस्यता भुगतान वैकल्पिक है; यदि परीक्षण अवधि खत्म होकर उपयोगकर्ता सदस्यता पेज पर उतरे, प्रवाह स्वतः भुगतान मार्ग पर स्विच हो जाता है। Node के बिना, या जब उपयोगकर्ता खुद करना चाहे, स्वतः शुद्ध मार्गदर्शन मोड में वापस।

## इंस्टॉल

```
openclaw skills install @durenzidu/powpow-register
```

## फीचर्स

1. **प्रोडक्ट परिचय**: ~120 अक्षरों की ओपनिंग + पैकेज में बंडल इंटरफ़ेस स्क्रीनशॉट
   (`assets/screenshots/` में 6 तस्वीरें: नक्शा पेज, पोस्ट डिटेल पेज आदि; सीन के हिसाब से 1–3 चुनें;
   बाहरी इमेज-होस्ट की ज़रूरत नहीं, ऑफलाइन चलती हैं)।
2. **प्रतिनिधि रजिस्ट्रेशन**: agent खुद यूजरनेम/निकनेम सुझाता है, पासवर्ड के दो विकल्प (उपयोगकर्ता
   दे या agent बनाए), सत्यापन कोड भेजना-सबमिट करना, अवतार सीधा अपलोड (≤5MB, SVG नहीं), आम एरर
   अपने-आप संभालना (व्यस्त/समाप्त/रेट-लिमिट)।
3. **वन-क्लिक लॉगिन (दो लिंक)**: सफल पंजीकरण के तुरंत बाद लॉगिन लिंक उपयोगकर्ता को सीधे होम पेज पर ले जाता है (मुफ़्त परीक्षण अवधि में एक क्लिक और उपयोग योग्य);
   यदि सदस्यता पेज पर उतरे (परीक्षण अवधि समाप्त) या उपयोगकर्ता उन्नयन चाहे तो सदस्यता प्रवाह का पालन करें — भुगतान आने के बाद नई लॉगिन स्थिति में बदला जाता है और पूरी सदस्यता वाला लिंक होम पेज पर ले जाता है
   (प्लेटफ़ॉर्म के आधिकारिक `me?token=` पुल के ज़रिए, जो HttpOnly कुकी स्वतः लगा देता है)।
4. **सदस्यता पेमेंट**: Alipay (मासिक ¥6.99 / त्रैमासिक ¥19.99 /
   वार्षिक ¥69.99, एकमुश्त खरीद, ऑटो-रिन्यू नहीं) और PayPal (Premium Monthly, लगभग $1/माह,
   ऑटो-रिन्यू, कभी भी रद्द) — दोनों में agent प्रतिनिधि बनून ऑर्डर + पैसे आने तक पोलिंग;
   WeChat QR/Huawei IAP के लिए रास्ता दिखाना।
5. **एरर-निवारण**: सत्यापन कोड न आना, यूजरनेम/ईमेल व्यस्त होना, 403 न-सक्रिय, अकाउंट लॉक आदि आम
   दिक्कतें — सब प्लेटफॉर्म सोर्स कोड से, सोर्स के साथ।

## सुरक्षा

- **पासवर्ड** सिर्फ एनवायरनमेंट वेरिएबल से स्क्रिप्ट प्रोसेस में जाता है, कमांड लाइन आर्ग्युमेंट में
  कभी नहीं, डिस्क पर नहीं, स्टेट फाइल में नहीं; agent का बनाया पासवर्ड सिर्फ एक बार दिखता है ताकि
  उपयोगकर्ता सेव कर ले।
- **सत्यापन कोड** सिर्फ आधिकारिक रजिस्ट्रेशन इंटरफ़ेस में, इस्तेमाल के बाद फेंक दिया जाता है; स्टेट
  फाइल (ईमेल/यूजरनेम/token/ऑर्डर नंबर) सिस्टम टेंपररी डायरेक्टरी में रहती है, फ्लो के अंत में
  `cleanup` से एक झटके में साफ।
- **पेमेंट**: agent सिर्फ ऑर्डर बनाता है, कैशियर खोलता है, पैसे आने की जांच करता है; उपयोगकर्ता का
  Alipay/PayPal अकाउंट या पेमेंट क्रेडेंशियल कभी नहीं छूता, उसकी ओर से पेमेंट कभी नहीं करता। पेमेंट हमेशा
  उपयोगकर्ता और आधिकारिक कैशियर के बीच होता है।
- सभी रिक्वेस्ट सिर्फ आधिकारिक डोमेन `https://global.powpow.online` पर; पैकेज में कोई की/सीक्रेट नहीं।
