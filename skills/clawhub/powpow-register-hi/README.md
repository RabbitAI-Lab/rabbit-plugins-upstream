# powpow-register

PowPow बबल रजिस्ट्रेशन असिस्टेंट (OpenClaw संस्करण): एक नए उपयोगकर्ता को «बबल क्या है» न जानने से लेकर
«अकाउंट एक्टिवेट और उपयोग के लिए तैयार» तक पहुँचाएँ — उत्पाद परिचय (इंटरफ़ेस स्क्रीनशॉट सहित), चरण-दर-चरण
रजिस्ट्रेशन मार्गदर्शन, एरर समाधान, सब्सक्रिप्शन एक्टिवेशन का विवरण।

विशुद्ध गाइड-प्रकार का skill, कोई स्क्रिप्ट नहीं, कोई डिपेंडेंसी नहीं; सभी रजिस्ट्रेशन क्रियाएँ उपयोगकर्ता
ब्राउज़र/ऐप में स्वयं पूरा करता है।

## इंस्टॉलेशन

```
openclaw skills install @durenzidu/powpow-register
```

## विशेषताएँ

1. **उत्पाद परिचय**: ~120 शब्दों का परिचय + GitHub सार्वजनिक रिपॉज़िटरी में होस्ट किए इंटरफ़ेस स्क्रीनशॉट के लिंक
   (नक्शा पेज, पोस्ट डिटेल पेज आदि 6 तस्वीरें, परिदृश्य के अनुसार 1–3 भेजें)।
2. **रजिस्ट्रेशन मार्गदर्शन**: फ़ील्ड नियम (यूज़रनेम/पासवर्ड/ईमेल वेरिफिकेशन कोड/मोबाइल नंबर/प्रोफ़ाइल फ़ोटो),
   थर्ड-पार्टी लॉगिन (Google/Watcha/हुआवेई), रेट-लिमिट पैरामीटर, सभी प्लेटफ़ॉर्म सोर्स कोड से लिए गए और सोर्स चिह्नित।
3. **एरर समाधान**: वेरिफिकेशन कोड नहीं मिलना, यूज़रनेम/ईमेल पहले से लिया हुआ, 403 एक्टिवेट नहीं, अकाउंट लॉक आदि
   13 सामान्य समस्याएँ।
4. **सब्सक्रिप्शन एक्टिवेशन**: PayPal (वेब) / WeChat स्कैन (मैनुअल कन्फ़र्मेशन) / हुआवेई IAP (HarmonyOS) तीन
   चैनलों का विवरण और समाधान; मौजूदा पेमेंट चेन सीधे दोबारा इस्तेमाल की जा सकती है, skill केवल रास्ता दिखाता है।

## सुरक्षा

- किसी भी चाबी (key) से युक्त नहीं; कोई स्क्रिप्ट नहीं, उपयोगकर्ता की साख (credentials) के संपर्क में नहीं आता।
- **कभी नहीं माँगता** उपयोगकर्ता का पासवर्ड, वेरिफिकेशन कोड या पेमेंट प्रमाण; रजिस्ट्रेशन और पेमेंट सभी प्लेटफ़ॉर्म
  पेज पर होते हैं।
