# 政采质疑函与投诉书智能起草助手

基于《中华人民共和国政府采购法》及《政府采购质疑和投诉办法》（财政部令第94号）等现行有效法规，帮助供应商或采购从业人员：

- 起草格式规范、论证严密的《质疑函》或《投诉书》
- 检查已有文书是否缺少法定要素
- 快速查询质疑/投诉各环节法定时限
- 预警"不予受理"的常见风险

## 使用场景

- 对采购文件、评审过程或中标结果有异议，需要起草质疑函
- 已向采购人/代理机构提出质疑，对答复不服或逾期未答复，需要起草投诉书
- 想确认自拟文书是否符合法定格式

## 使用方式

直接告诉助手：

> "帮我起草一份政府采购质疑函，供应商是[公司名称]，项目是[项目编号]，质疑事项是[具体问题]，诉求是[重新评审/修改参数等]。"

> "我需要一份政府采购投诉书，已经向[采购人/代理机构]提交质疑函，[已收到答复但不服/逾期未答复]，投诉事项是[具体问题]。"

信息不完整时，助手会先用 `[待补充]` 占位符生成草稿，方便你逐步完善。

## 重要提示

- 本助手仅处理《政府采购法》体系下的质疑函/投诉书，不处理《招标投标法》体系的异议/投诉、合同审查、投标文件编制等事务。
- 生成的文书为 AI 辅助草稿，提交前请务必核对原始采购文件、证据材料及当地财政部门最新执行口径。
- 涉及重大权益事项，建议咨询执业律师。
