## Description:

Helps developers use Figma to define design systems, generate component libraries, review UI/UX, and create wireframes and interactive prototypes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[skills-repo](https://clawhub.ai/user/skills-repo)

### License/Terms of Use:

MIT

## Use Case:

Developers and small product teams use this skill to turn Figma design work into design system rules, frontend component scaffolds, wireframes, prototypes, and UI/UX review recommendations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Figma access or source scans could include design material outside the intended review scope.

Mitigation: Limit Figma access and scans to the project being reviewed.

Risk: Optional installation or build steps can introduce external package releases, and global installation may affect the wider environment.

Mitigation: Review package versions and choose whether global installation is appropriate before running those commands.
