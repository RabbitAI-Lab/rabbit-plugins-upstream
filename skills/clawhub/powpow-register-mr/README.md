# powpow-register

PowPow बबल नोंदणी सहाय्यक (OpenClaw आवृत्ती): नवीन वापरकर्त्याला «बबल म्हणजे काय» न माहीत असण्यापासून
«खाते अॅक्टिव्हेट आणि वापरासाठी तयार» या टप्प्यापर्यंत पोहोचवा — उत्पादन परिचय (इंटरफेस स्क्रीनशॉटसह),
टप्प्याटप्प्याने नोंदणी मार्गदर्शन, त्रुटी शोध, सबस्क्रिप्शन अॅक्टिव्हेशनचे वर्णन.

पूर्णपणे मार्गदर्शक-प्रकारचे skill, कोणतीही स्क्रिप्ट नाही, कोणतीही डिपेंडन्सी नाही; सर्व नोंदणी कृती वापरकर्ता
ब्राउझर/ॲपमध्ये स्वतः पूर्ण करतो.

## इन्स्टॉलेशन

```
openclaw skills install @durenzidu/powpow-register
```

## वैशिष्ट्ये

1. **उत्पादन परिचय**: ~120 शब्दांचा परिचय + GitHub सार्वजनिक रेपॉजिटरीत होस्ट केलेल्या इंटरफेस स्क्रीनशॉटच्या लिंक
   (नकाशा पेज, पोस्ट डिटेल पेज इत्यादी 6 फोटो, परिस्थितीनुसार 1–3 पाठवा).
2. **नोंदणी मार्गदर्शन**: फील्ड नियम (यूझरनेम/पासवर्ड/ईमेल व्हेरिफिकेशन कोड/मोबाईल क्रमांक/प्रोफाइल फोटो),
   थर्ड-पार्टी लॉगिन (Google/Watcha/हुआवेई), रेट-लिमिट पॅरामीटर्स, सर्व प्लॅटफॉर्म सोर्स कोडमधून घेतलेले व स्रोत नमूद.
3. **त्रुटी शोध**: व्हेरिफिकेशन कोड मिळत नाही, यूझरनेम/ईमेल आधीच वापरलेला, 403 अॅक्टिव्हेट नाही, खाते लॉक
   इत्यादी 13 सामान्य समस्या.
4. **सबस्क्रिप्शन अॅक्टिव्हेशन**: PayPal (वेब) / WeChat स्कॅन (मॅन्युअल पुष्टी) / हुआवेई IAP (HarmonyOS) तीन
   मार्गांचे वर्णन व समाधान; विद्यमान पेमेंट चेन थेट पुन्हा वापरता येते, skill फक्त मार्ग दाखवतो.

## सुरक्षा

- कोणत्याही किल्ली (key) चा समावेश नाही; स्क्रिप्ट नाही, वापरकर्त्याच्या प्रमाणपत्रांशी (credentials) संपर्क नाही.
- **कधीही मागत नाही** वापरकर्त्याचा पासवर्ड, व्हेरिफिकेशन कोड किंवा पेमेंट पुरावा; नोंदणी आणि पेमेंट सर्व
  प्लॅटफॉर्म पेजवर होते.
