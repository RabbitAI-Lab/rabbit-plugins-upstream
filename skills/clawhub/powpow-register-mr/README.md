# powpow-register

PowPow बुडबुडा नोंदणी सहाय्यक (OpenClaw आवृत्ती): एका नवीन वापरकर्त्याला "बुडबुडा म्हणजे काय हेच माहीत नाही" पासून "खाते सक्रिय, एक-क्लिक लॉगिन, खेळायला सुरुवात" पर्यंत घेऊन जा — उत्पादन ओळख (इंटरफेस स्क्रीनशॉटसह), एजंट-सहाय्यित नोंदणी (प्रोफाइल छायाचित्र अपलोडासह), Alipay/PayPal सदस्यता ऑर्डर व प्राप्ती ट्रॅकिंग, दुहेरी-लिंक एक-क्लिक लॉगिन, त्रुटी निवारण.

**v2.0.0 पासून हे एजंट-सहाय्यित मोड आहे, आणि v2.1.0 पासून PayPal देखील हाताळता येते**: मुख्य स्क्रिप्ट `scripts/powpow-register.mjs` शून्य अवलंबन (Node >= 18), वापरकर्ता संवादातून बाहेर पडत नाही, फक्त दोन वेळा तात्पुरते बाहेर जातो: ईमेलवर संकेतांक पाहण्यासाठी, Alipay/PayPal कॅशियरवर पेमेंट करण्यासाठी. Node नसेल किंवा वापरकर्ता स्वतः करू इच्छित असेल, स्वयंचलितपणे शुद्ध मार्गदर्शन मोडात परतते.

## इन्स्टॉलेशन

```
openclaw skills install @durenzidu/powpow-register
```

## वैशिष्ट्ये

1. **उत्पादन ओळख**: अंदाजे 120 शब्दांची सुरुवात + स्किलसोबत बिल्ट-इन इंटरफेस स्क्रीनशॉट (`assets/screenshots/` अंतर्गत 6 प्रतिमा: नकाशा पृष्ठ, पोस्ट तपशील पृष्ठ इ., परिस्थितीनुसार 1–3 पाठवा; बाह्य प्रतिमा सेवेची आवश्यकता नाही, ऑफलाइन चालते).
2. **सहाय्यित नोंदणी**: एजंट वापरकर्तानाव/टोपणनाव सुचवते, पासवर्ड दोन्हीपैकी एक (वापरकर्ता देतो किंवा एजंट तयार करतो), संकेतांक पाठवणे व सबमिट करणे, प्रोफाइल थेट अपलोड (≤5MB, SVG नाही), सामान्य त्रुटी आपोआप हाताळणे (व्याप्त/कालबाह्य/रेट-लिमिट).
3. **एक-क्लिक लॉगिन (दुहेरी लिंक)**: नोंदणी यशस्वी झाल्यावर "अर्ध-लॉगिन" लिंक थेट सदस्यता पृष्ठावर; पेमेंट आल्यावर नवीन लॉगिन स्थिती बदलून पूर्ण सदस्य लिंक थेट होमपेजवर (प्लॅटफॉर्मच्या अधिकृत `me?token=` ब्रिजद्वारे, स्वयंचलित HttpOnly कुकी).
4. **सदस्यता पेमेंट**: Alipay (महिना ¥6.99 / त्रैमासिक ¥19.99 / वार्षिक ¥69.99, एकदाच खरेदी, स्वयंचलित नूतनीकरण नाही) व PayPal (Premium Monthly, सुमारे $1/महिना, स्वयंचलित नूतनीकरण, कधीही रद्द) या दोन्हीवर एजंट सहाय्यित ऑर्डर + प्राप्ती पोलिंग; WeChat क्यूआर/हुआवेई IAP मार्गदर्शन.
5. **त्रुटी निवारण**: संकेतांक येत नाही, वापरकर्तानाव/ईमेल व्याप्त, 403 सक्रिय नाही, खाते लॉक इ. सामान्य समस्या, सर्व प्लॅटफॉर्म स्रोत कोडमधून व स्रोत नमूद करून.

## सुरक्षा

- **पासवर्ड** फक्त एन्व्हायर्नमेंट व्हेरिएबलद्वारे स्क्रिप्ट प्रोसेसला जातो, कधीही कमांड लाइन आर्ग्युमेंटमध्ये लिहित नाही, डिस्कवर ठेवत नाही, स्थिती फाइलमध्ये जात नाही; एजंटने तयार केलेला पासवर्ड फक्त एकदाच वापरकर्त्याला सुरक्षित ठेवायला दाखवला जातो.
- **संकेतांक** फक्त अधिकृत नोंदणी इंटरफेससाठी, वापरल्यावर टाकला; स्थिती फाइल (ईमेल/वापरकर्तानाव/टोकन/ऑर्डर क्रमांक) सिस्टम तात्पुरत्या डिरेक्टरीत, प्रवाह संपल्यावर `cleanup` एका क्लिकमध्ये साफ.
- **पेमेंट**: एजंट फक्त ऑर्डर तयार करतो, कॅशियर उघडतो, प्राप्ती तपासतो; वापरकर्त्याच्या Alipay/PayPal खात्याला किंवा पेमेंट क्रेडेन्शियलला कधीही स्पर्श करत नाही, कधीही पेमेंट करून देत नाही. पेमेंट नेहमी वापरकर्ता व अधिकृत कॅशियर यांच्यातच होते.
- सर्व विनंत्या फक्त अधिकृत डोमेन `https://global.powpow.online` वर; कोणतीही की नाही.
