## Description:

Research brands, creators, paid Meta ads, Instagram posts, and TikTok videos using Spyglass. Use for competitive creative research, not for managing ad accounts or estimating spend.

This skill is ready for commercial/non-commercial use.

## Use Case:

External marketers, brand strategists, and researchers use this skill to search brands, creators, paid Meta ads, Instagram posts, and TikTok videos for competitive creative research. It helps organize findings with source URLs while distinguishing observed facts from interpretation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Search inputs and API authentication are sent to Spyglass, and requests consume account credits.

Mitigation: Store the API key in the host's secret settings, set a research budget, start with a small result limit, and avoid unnecessary retries or pagination.
