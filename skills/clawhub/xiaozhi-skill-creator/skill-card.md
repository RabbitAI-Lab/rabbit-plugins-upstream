## Description:

A Chinese-language guide for writing and reviewing K–12 learning skills using a four-layer structure, privacy boundaries, templates, and a five-step drafting process.

This skill is ready for commercial/non-commercial use.

## Publisher:

[qizhitang](https://clawhub.ai/user/qizhitang)

### License/Terms of Use:

MIT-0

## Use Case:

Skill developers and high-school students with programming or prompt-writing experience use this guide to draft, test, and troubleshoot Chinese-language K–12 learning skills. It does not provide subject tutoring or generate exercises.

### Deployment Geography for Use:

Mainland China; adapt crisis contacts, curriculum assumptions, and minor-consent rules before use elsewhere.

## Known Risks and Mitigations:

Risk: Crisis contacts, curriculum guidance, and consent rules are tailored to mainland China.

Mitigation: Localize and review these instructions before using generated skills in other regions.

Risk: The referenced SECURITY_BASELINE.md was not included in the inspected artifact.

Mitigation: Obtain and review the security baseline before relying on it when authoring a new skill.
