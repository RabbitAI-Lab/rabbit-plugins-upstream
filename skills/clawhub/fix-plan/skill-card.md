## Description:

Organizes and maintains fix plans and checklists, including task priorities, progress, completion, and external issue status.

This skill is ready for commercial/non-commercial use.

## Publisher:

[drumrobot](https://clawhub.ai/user/drumrobot)

### License/Terms of Use:

MIT

## Use Case:

Developers and project managers use this skill to create, triage, synchronize, and complete tasks in fix_plan.md or checklist.md workspaces.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Replacing a .ralph directory with a redirect file could remove unrelated local files.

Mitigation: Use only in workspaces expecting fix-plan automation; review consolidation manually and require confirmation plus a full recursive backup before replacing the directory.
