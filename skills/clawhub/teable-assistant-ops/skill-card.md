## Use Case:

Teable users can use this agent to manage projects, tables, fields, records, and views; create automations and apps; and handle data workflows, media, and scraping tasks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad project permissions can enable unintended changes.

Mitigation: Use limited account permissions and verify the target project before making changes.

Risk: Uploaded files, notification recipients, or app access settings may expose sensitive information; generated apps are open by default.

Mitigation: Review uploaded files, recipients, and app access settings before sharing or publishing.

Risk: Saved CLI credentials and unreviewed package versions can put account access at risk.

Mitigation: Protect saved CLI credentials and review package versions.

Risk: Scheduled behavior may run before it is ready or as intended.

Mitigation: Review and approve scheduled behavior before activation.
