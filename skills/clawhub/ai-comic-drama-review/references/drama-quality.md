## 诊断原则

1. 先识别作品的类型承诺、目标受众、核心卖点和作者意图，再选择诊断标准。喜剧、悬疑、甜宠、复仇、群像和实验叙事可以有不同结构，不得把单一剧作公式当成唯一正确答案。
2. 区分“作者有意留白”与“文本缺少必要信息”。只有后者造成理解、期待或情感断裂时才记为问题。
3. 分开记录症状与根因。“节奏慢”“人设崩”“台词尬”是症状，必须继续追到目标缺失、因果断裂、选择违机动机、信息任务错误等可修改原因。
4. 先修主干，再修局部。主线因果、人物核心动机未成立时，不以润色对白或增加反转掩盖结构问题。
5. 优先保护原作的独特设定、人物关系和有效名场面。高风险问题同时给出最小改动方案与备选重构方案，并说明各自代价。
6. 只有大纲时，将对白项重点解释为信息表达和台词策略，不评价未写出的具体措辞；所有细粒度判断注明材料限制。

## 故事引擎与类型承诺

用一句话还原故事引擎：

`谁，因为什么触发事件，必须实现什么目标；什么核心阻力不断阻止他；失败会付出什么代价；作品依靠什么独特机制持续推进。`

逐项检查：

- **主角与视角**：观众主要跟随谁？视角切换是否有明确收益，还是造成情感依附中断？
- **触发事件**：什么打破原有平衡？它是否真正迫使主角行动，而非只提供背景？
- **主动目标**：主角是否做出追求、阻止、逃离、查明或守护等可观察行动？目标能否被观众识别？
- **核心阻力**：阻力来自对手、环境、关系、自身弱点还是规则？是否足以持续生成事件？
- **代价与期限**：失败会失去什么？代价是否具体、逐步逼近并影响人物，而非只停留在口头描述？
- **独特机制**：核心设定是否持续产生场景和选择，还是首集使用后便失效？
- **类型承诺**：作品反复提供的核心体验是什么？后续情节是在兑现、升级还是偏离该体验？

诊断结论不得只写“设定不新颖”。应说明设定是否影响行动、冲突和画面，以及具体哪一项故事引擎失效。

## 因果结构、场景与节奏

### 因果链检查

用“因为—但是—因此—导致”重述关键事件，标出只能以“然后”连接且互不改变的段落。

检查：

1. 事件是否由前一事件、人物选择或既定规则引发。
2. 关键成功是否主要来自主角此前选择和能力，而非偶然救援、突然获得信息或反派失智。
3. 每个重大转折是否改变目标、阻力、关系、信息或代价中的至少一项。
4. 巧合是否主要用于制造麻烦；若巧合解决核心危机，检查是否已有充分铺垫与人物行动配合。
5. 支线是否压迫、映照或改变主线；可删除而不影响任何主线的支线应说明其独立价值，否则建议合并或删减。

### 场景功能检查

为重点场景填写：

`入场状态 → 当场目标 → 阻力 → 策略／选择 → 结果 → 离场变化 → 下一场推动力`

- 无离场变化的场景，检查是否承担必要铺垫、氛围、关系或喜剧功能；没有明确功能时合并、压缩或删除。
- 只有信息交代而没有行动和态度变化的场景，将信息嵌入争夺、隐瞒、交易、失败或选择。
- 重复证明同一人物特点或同一冲突的场景，保留最有效的一次，其余用于升级、反转或产生后果。
- 高潮不只靠提高音量或动作规模，应让此前目标、关系、代价和选择在此汇合。

### 节奏检查

节奏是“有效变化与期待管理的速度”，不等于事件越多越好。

- 标出每场的新信息、决定、关系变化和后果，识别连续无变化段落。
- 检查紧张与释放、动作与反应、获得与失去是否交替，避免持续高强度导致麻木。
- 检查关键情绪是否有足够反应时间，重要损失是否被下一场立即覆盖。
- 分集钩子应来自已经升级的行动、选择、揭示或代价，不靠无意义断句、重复误会或故意扣住常识信息。
- 钩子提出后记录兑现位置；长期只叠加不兑现的问题会降低信任。

## 人物、关系与选择

### 人物诊断

- **欲望与需求**：人物外在追求什么，内在真正缺少或拒绝面对什么？两者是否制造选择，而非只是人物小传标签。
- **动机与能力**：行动是否符合其已知信息、经历、性格、利益与当时情绪？能力是否提前展示或有学习过程？
- **能动性**：关键节点是否由人物选择推动？被事件裹挟后是否仍有应对、决定或拒绝？
- **选择代价**：重要选择是否放弃另一种真实价值？无成本决定通常难以形成人物深度。
- **人物弧光**：变化是否由连续事件和压力累积而来？突变前是否有裂缝、试探或反向证据？
- **一致性**：一致不等于不变。改变应符合可辨认的动机链，不变也应在压力下体现坚持或自我欺骗。
- **对手功能**：对手是否有独立目标、合理策略和有效行动？不得仅靠降智、漏算或突然解释来成就主角。
- **配角功能**：是否拥有局部欲望与行动，还是只负责解说、递工具或赞美主角？功能重复者考虑合并。

### 关系诊断

为关键关系标注初始状态、权力差、利益冲突、情感债、边界和每次变化。

重点检查：

- 关系变化是否由具体行为、选择、牺牲、背叛或秘密揭示造成。
- 亲密、信任或仇恨是否升级过快，缺少中间证据。
- 双方是否都能影响剧情，而非一方持续被动接受。
- 冲突是否允许双方各有合理处，避免只靠拒绝沟通维持。
- 关系名场面是否同时推进人物和情节，而非可任意替换的糖点或冲突。

## 对白、潜台词与信息

为重点对白场景判断：谁想从谁那里得到什么，采用什么策略，真正没有说出口的是什么，权力如何变化。

检查与修改：

1. **台词目的**：删除既不推动行动、不揭示人物、不制造情绪也不服务喜剧节奏的台词。
2. **避免互说已知**：人物不向熟悉者复述双方都知道的背景；把信息转为争论证据、交易筹码或隐瞒漏洞。
3. **减少问答说明书**：让提问者带有怀疑、试探、指控或利益，不让配角只负责递问题。
4. **增加策略变化**：同一人物连续说服失败时改变请求、威胁、示弱、回避、交换或沉默，而非重复观点。
5. **潜台词**：表面话题与真实需求可以不同，但必须给足语境和表演线索，不能要求观众凭空理解。
6. **人物声纹**：用词、句长、幽默、回避方式、礼貌程度与权力位置应有差异；抽取台词隐去姓名后仍可辨认主要人物。
7. **信息分配**：观众、主角、对手分别知道什么？信息差是否产生悬念、戏剧反讽或误会，并按时兑现？
8. **动作与停顿**：关键情绪不必全部说破，可用动作、错位回答、转移话题或沉默承担，但避免全员故作深沉。

修改示范不能只把长句改短；必须改变台词的行动目的、信息任务、策略或人物关系。

## 逻辑、伏笔与反转

建立五张清单：

- **时间线**：事件顺序、昼夜、旅程、年龄、期限和回忆位置。
- **人物知识**：每个人在何时通过何种渠道知道什么，秘密何时泄露。
- **空间与道具**：人物位置、移动条件、关键道具来源、持有者和状态变化。
- **规则与能力**：能力边界、代价、限制、例外及其首次展示位置。
- **伏笔与兑现**：伏笔内容、首次出现、加强、误导、兑现和后续影响。

反转审核同时检查：

1. 反转前是否存在可回看的事实线索，而非只有模糊暗示。
2. 旧场景在知道真相后是否仍成立，并获得新意义。
3. 反转是否改变人物选择、关系或主线，而非只增加设定。
4. 是否依赖所有人恰好失智、沉默或错过显而易见的信息。
5. 真相揭示后是否及时处理后果，避免下一场恢复原状。

## 情绪曲线与观众体验

按集或段落记录“作品希望观众感受到什么—实际文本提供什么证据”。

- 标出期待、好奇、担忧、爽感、心疼、愤怒、甜感、释然等关键节点，不机械要求每种类型具备全部情绪。
- 情绪高点前检查积累是否充分，高点后检查反应和后果是否充分。
- “爽点”检查压迫是否具体、反击是否由人物行动赢得、结果是否可见且影响后续。
- “虐点”检查损失是否触及人物真正重视之物，避免只靠误会、降智或重复受难。
- “甜点”检查关系双方是否有独特互动和选择，避免通用对白与无依据宠爱。
- “笑点”检查是否来自人物、信息差、情境和节奏，是否破坏紧张场景或伤害人物可信度。
- 连续相同情绪导致疲劳时，优先调整事件意义和人物反应，不只增加配乐或台词强度。

## 根因诊断与修改处方

| 常见症状 | 可能根因（须用文本验证） | 优先修改动作 |
|---|---|---|
| 开场慢、进入主线晚 | 背景先于行动；触发事件无强迫性；主角目标未形成 | 将背景嵌入第一次失败或争夺；提前触发事件；让主角做出不可撤回的行动 |
| 中段拖沓、重复 | 场景无状态变化；阻力不升级；重复解释同一信息 | 合并同功能场景；让每次行动改变代价或关系；删除重复解释 |
| 冲突弱、不抓人 | 双方目标不直接碰撞；代价抽象；主角可轻易退出 | 让双方争取同一稀缺目标；具体化损失；增加退出成本或期限 |
| 主角被动、工具人 | 关键事件全靠他人推动；没有选择及其后果 | 把信息获得、危机升级或解围改为主角主动选择的结果 |
| 人设崩塌、转变突兀 | 行动与已知动机冲突；变化缺少中间步骤 | 补充压力、裂缝和试探；修改违机动选择；让转变付出实际代价 |
| 反派降智 | 作者需要主角获胜；对手目标与策略不完整 | 先建立对手合理策略，再让主角利用已铺垫的信息、规则或性格破绽取胜 |
| 反转突兀 | 缺少事实伏笔；旧场景与新真相不兼容 | 前置可回看的线索；修正矛盾场景；让反转改变后续选择 |
| 对白尴尬、像说明书 | 人物互说已知；台词没有行动目的；所有人同声同气 | 改为争夺、试探或隐瞒；区分声纹；用动作承担已知情绪 |
| 爽点、虐点或甜点不强 | 积累不足；结果无后果；情绪不是人物行动赢得 | 加强前置投入；展示可见结果；保留反应场景并推动关系或主线 |
| 集尾钩子像硬断 | 没有新选择或信息；只靠突然打断 | 在断点前完成一个变化，再打开更大的问题；后续按承诺兑现 |

每个剧作问题必须给出：

1. **表面症状与观众影响**：可观察的问题是什么，观众理解、期待、情绪或人物可信度受到什么影响。
2. **问题根因**：哪个目标、动机、因果、信息、规则或场景功能失效。
3. **修改原则**：需要恢复或强化什么剧作功能。
4. **最小改动方案**：尽量保留现有集场和设定的具体动作。
5. **备选重构方案**：高风险或核心结构问题必填，说明适用条件、收益和额外返工。
6. **联动修改范围**：受影响的伏笔、人物知识、关系、台词、后续结果和制作资产。
7. **验收标准**：能从修订文本中观察或逐项核对的条件。

## 改写示范规则

1. 选择能证明根因和修法的最短必要片段，不用一段漂亮对白代替结构修复。
2. 明确保留项：核心事实、人设、类型、关系方向、必要伏笔和用户限制。
3. 先写修改前后的场景功能，再给正文。正文应体现新的行动、阻力、选择或信息差。
4. 最小改动版优先调整场景顺序、行动归属、信息出现时机、对白策略和结果，不随意增加新角色或设定。
5. 备选重构版可以改变场景机制，但必须列明需要同步修改的集场和成本。
6. 改写后解释每一处关键调整对应的问题编号，避免只展示文笔。
7. 用户未授权完整改写时，不续写整集，不替作者确定重大结局或价值立场。

## 子维度评分锚点

下表补充通用 0—5 分锚点；2、4 分根据相邻状态程度判断，0 分仅用于文本本身造成完全不可评估或不可用的情况。

| 子维度 | 5 分表现 | 3 分表现 | 1 分表现 |
|---|---|---|---|
| 核心设定与结构 | 故事引擎清楚，设定持续生成冲突；关键事件因果紧密，转折和结局兑现主线 | 主线可辨但有断点、被动解围或支线游离；需要局部调整场景顺序和因果 | 目标与主线无法成立，事件主要任意拼接，核心设定与情节脱节 |
| 冲突升级与叙事节奏 | 阻力、代价和选择持续升级；场景变化明确，张弛与钩子服务整体体验 | 有有效冲突但重复、平铺或节奏失衡；若干场景功能弱、钩子兑现不足 | 冲突长期不升级或依赖误会硬撑，大量场景无变化，观众期待反复被消耗 |
| 人物动机、选择与关系 | 人物以有代价的选择推动剧情；成长有过程，关系变化有行为证据，对手合理有效 | 主要动机基本成立，但能动性、转变步骤或关系过渡存在明显缺口 | 人物主要服务情节，行动频繁违机动机，关系和成长缺乏可信过程 |
| 对白、潜台词与信息表达 | 台词兼具行动、人物和信息功能；声纹鲜明，信息差与潜台词产生戏 | 信息基本清楚但说明书式对白、重复解释或同声同气反复出现 | 对白主要搬运背景，人物无交流目的，信息分配持续阻碍理解或表演 |
| 逻辑、伏笔与连续性 | 时间、知识、空间、规则和道具自洽；伏笔公平，反转可回看且产生后果 | 主干可理解但有明显知识、规则或铺垫漏洞，需要多点修补 | 关键逻辑广泛冲突，核心反转推翻既有事实或依赖持续降智 |

## 复审验收方法

复审不只检查“是否改过”，逐项验证修改是否产生预期功能：

1. **因果复述**：能用因为、但是、因此重述主线，关键胜利可追溯至人物行动与铺垫。
2. **场景抽查**：重点场景均有目标、阻力、策略或结果，离场状态与入场不同，或具有明确不可替代功能。
3. **人物抽查**：重大选择符合当时动机和知识，人物变化有中间步骤，对手策略保持合理。
4. **关系抽查**：每次重要升温、破裂或反转均有前置行为证据和后续影响。
5. **对白抽查**：重点对白场景具有目的和策略，删除台词会损失行动、人物或情绪信息；主要人物声纹可区分。
6. **逻辑抽查**：五张清单无新增矛盾，旧伏笔得到兑现或明确保留，反转后旧场景仍成立。
7. **情绪抽查**：目标高点有前置积累、可见结果和必要反应，连续同功能段落已合并或升级。
8. **联动检查**：修改没有破坏后续人物知识、时间线、伏笔、关系、场景资产和分集钩子。
