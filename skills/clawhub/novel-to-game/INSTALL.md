# Exact companion skills

ClawHub does not auto-install these dependencies. Install all into the same skills root:

```sh
clawhub install @worldwonderer/game-art-direction --version 1.2.0
clawhub install @worldwonderer/game-build --version 1.2.0
clawhub install @worldwonderer/game-concept --version 1.2.0
clawhub install @worldwonderer/game-qa --version 1.0.1
clawhub install @worldwonderer/game-world-design --version 1.1.1
clawhub install @worldwonderer/novel-game-analyze --version 1.0.0
```
