## Description:

Coordinates the adaptation of a novel into a playable game, from source analysis and creative direction through build and evidence-based QA.

This skill is ready for commercial/non-commercial use.

## Publisher:

[worldwonderer](https://clawhub.ai/user/worldwonderer)

### License/Terms of Use:

MIT

## Use Case:

Creators and game developers use this skill to turn novels in any language into playable games with source-grounded design, implementation, and QA evidence.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Full-pipeline generation can consume substantial time and model or tool budget.

Mitigation: Set a budget and scope up front, review progress at the specified checkpoints, and use director mode for explicit creative decisions.

Risk: The workflow cannot complete without separately installed companion skills.

Mitigation: Install the six versioned companion skills listed in INSTALL.md before starting.
