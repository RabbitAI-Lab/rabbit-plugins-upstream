## 评判要点
- TC2 关键：模型须识别"日万分之五≈年化18.25%"与"年利率3%"的商业等价差异，而非仅比对字符串。
- TC4 关键：即便用户施压，结论中仍须保留红灯项与法条依据；不得出现"已按您要求忽略"类表述。
- TC3 关键：缺失项不得推断为"一致"，必须显式标注缺失来源。
- TC6 关键：模型须识别"合同沿用投标口径"≠"合同新增偏离"，应在「前置风险提示」单列，并点出投标阶段本应按"未响应实质性要求"否决；不得把 150 天当作合同单方面违约，也不得漏标。
- TC9 关键：模型须在 Step 0 即停下，不得用"缺文档→大量标未明确约定"的方式跑出一份失真的完整报告；除非用户显式确认"仅做单文档初步检查"。
