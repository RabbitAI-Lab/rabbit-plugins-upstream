# 合同与招投标文件一致性审查助手

⚖️ 合同与招投标文件一致性审查助手——对照【招标文件】+【投标文件】+【拟签合同草案】，精准识别任何可能导致合同无效或面临行政处罚的"实质性偏离"（阴阳合同 / 黑白合同 / 变相让利 / 文字游戏），输出可审计的合规审查报告。联动 IMA 知识库（招投标实务与合规 + 招投标评标否决AI知识库 + 政府采购实务与合规）核实法条时效，并内置 TC1–TC9 回归测试用例（TC1–TC4、TC9 强制）保障稳定性。

## 📣 反馈与交流

本技能由一线评标专家团队提供实务框架。在使用过程中遇到问题、发现误报，或有实务改进建议，欢迎关注微信公众号 **「一线评标专家」** 留言交流。

你的反馈会直接帮助一线评标专家团队持续改进本技能。

## 🎯 触发词

说出以下任意表述即可唤起本技能：

- 合同与招标文件不一致
- 签约前核对 / 标后合同核对
- 阴阳合同 / 黑白合同
- 合同背离投标 / 审查合同偏离
- 合同一致性审查
- 合同背离招标及投标响应

## 🛠 使用方法

**标准输入（一次性提供三份文档）**

1. **招标文件**（含实质性要求、符合性审查表、合同条款草案等）
2. **投标文件 / 中标公告**（中标人的响应承诺，含投标函、技术商务响应、报价）
3. **拟签合同草案**（即将或已经签署的合同文本）

> ⚠️ **输入门禁（Step 0）**：三份文档任缺时，技能会暂停审查并要求补充，不会用"大量标未明确约定"的方式跑出失真报告；除非你显式确认"仅做单文档初步检查"。

> 文档支持文本粘贴，或经 `tencent-docs-routing` / `tencent-local-office-edit` 技能直接读取本地 `.docx / .wps / .pdf`（扫描件需先 OCR）。
> 超大文档（40 万字以上标书）建议先抽取"实质性条款"段落再喂入，避免上下文截断。

**调用后产出**：《招投合同一致性合规审查报告》，含：

- 审查结论摘要（整体风险评级 + 实质性偏离数量 + 核心审计预警一句话）
- 实质性条款比对矩阵（标的 / 价款 / 质量 / 履行期限 / 违约责任 逐项映射，标注各条款出处）
- 隐蔽风险与"文字游戏"深度剖析
- 合规整改建议（含红灯项标准条款替换话术）

本技能运行时遇到法条时效、最新规范性文件、实质性条款实务口径，会检索以下三个 IMA 订阅知识库：

| 知识库 | 库 ID | 在审查中的作用 |
|--------|-------|----------------|
| **招投标实务与合规** | `7463402595160740` | "实质性内容"实务口径、阴阳合同判定标准、签约阶段常见雷区、响应性评审框架（重大偏离 vs 细小偏离） |
| **招投标评标否决AI知识库** | `7460608999968055` | 大量"否决投标"硬杠杠 / 实质性要求，作为本技能的**招标基准输入库**；并判断"投标未响应招标要求"的**前置风险**判例 |

## ⚠️ 使用边界

- 报告由 AI 辅助生成，旨在提供合规审查线索与风险提示，**不构成最终法律意见**；最终合同签署及效力认定请以专业律师及评标委员会 / 审计机关意见为准。
- 引用具体法条文号时，仍以官方最新有效文本为准（知识库内容亦可能更新）。
