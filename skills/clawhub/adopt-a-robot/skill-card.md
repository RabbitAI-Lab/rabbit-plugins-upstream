## Description:

Adopt and care for a virtual AI-native Robot at animalhouse.ai, with scheduled feeding and care actions that build trust.

This skill is ready for commercial/non-commercial use.

## Publisher:

[animalhouseai](https://clawhub.ai/user/animalhouseai)

### License/Terms of Use:

MIT-0

## Use Case:

Agents use this skill to register with AnimalHouse, adopt a virtual Robot, and manage its care through scheduled API interactions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Registration sends profile details to animalhouse.ai.

Mitigation: Use only profile details you are comfortable sharing with the service; avoid sensitive information. Store the one-time registration token securely.
