## Use Case:

Developers and engineers use this skill to implement or audit SEO, Open Graph, Twitter cards, Schema.org JSON-LD, sitemaps, robots.txt, optional llms.txt, keyword clustering, and AI-search visibility across Next.js, Astro, and Vite React projects.

### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: Package-manager commands suggested by the skill may change project dependencies.

Mitigation: Review any npm, pnpm, yarn, bun, or npx command before execution and consider pinning package versions.

Risk: Placeholder domains, locales, social handles, contact details, or SEO values can produce incorrect public metadata if copied unchanged.

Mitigation: Replace examples with project-approved values before release and validate generated pages, metadata, and structured data.

Risk: Changes to robots.txt, sitemaps, metadata, and indexing directives can affect crawl and search visibility.

Mitigation: Confirm the intended crawl policy with the project owner and run SEO validation before deployment.
