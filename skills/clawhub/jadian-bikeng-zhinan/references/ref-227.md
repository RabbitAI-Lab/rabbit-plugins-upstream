# 浴霸开关在里头，照明外头无法控制？6.17

相信今天的问题大家都会遇到，特别是现在大多数新装修的北方家里都会遇到这种情况；

以前大家都用的是物理按键的浴霸开关，一般是留5-6根线的做法，这样可以把照明开关单独放到卫生间外头，其他开关放到卫生间里头，这样方便使用。

▲如图所示就是物理按键开关，过去的浴霸几乎都是这种做法，都是强电接线，这样的好处是随时可以把浴霸照明线路接到卫生间门外头，进卫生间直接开启照明然后进门。

▲但是现在大部分浴霸都是上图的触控面板，这样就会导致，浴霸开关肯定是安装在卫生间内部的，但是浴霸唯一的照明也只能里头控制，无法分线采用单独开关外面控制，此时怎么办？有人说那把控制面板装外头，哈哈，那你正洗澡需要调节温度或者排气的话，就得光着屁股出去了。

▲如上图的卫生间，没有做干湿分离，但是买了触控面板的浴霸，此时浴霸开关在里头，可以把镜前灯的开关单独放到室外门口，这样进卫生间可以直接打开镜前灯，不会抹黑进门然后里头只控制浴霸即可

▲还有一种解决办法，你如果买了触控的面板以后，浴霸面板必须放到室内，此时如果是干湿分离，湿区没有镜前灯咋办？面板+遥控器的做法就可以解决，也就是浴霸控制面板还放到室内，把自带的遥控器贴到卫生间门外，这样就可以进门直接开启浴霸照明了，而不需要抹黑进去去打开照明。

▲当然，如果卫生间除过浴霸照明，吊顶上方还有其他照明的话，此时触控浴霸面板安装里头，外头开关直接控制其他灯具照明，也可以解决触控浴霸面板的问题。

总结：
第一直接购买物理按键的浴霸；
第二买触控式+遥控器的搭配；
第三，没有做干湿分离，外头面板控制镜前灯照明；做了干湿分离里头有其他灯具照明也是可以单独控制的；
第四，还有语音控制或者手机APP控制的，但是这种感觉不实用，比较鸡肋。家有熊孩子的话，你正在洗澡，孩子拿语音当玩具的话，此时你一点办法都没有，娃在外头喊，你在里头喊了。还有专业人士解剖浴霸，把触控的灯具直接重新接线外接到外头的物理开关，很难实现，有的压根实现不了，直接采用以上三种方法轻松解决，没有那么复杂。
