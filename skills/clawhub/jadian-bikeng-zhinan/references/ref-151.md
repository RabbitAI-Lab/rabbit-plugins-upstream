# 烟机有无挡板以及烟管位置，定制注意11.17

> 安全提示：本专题内容涉及燃气设施、墙体拆改、阳台结构、水电隐蔽工程、防水闭水等高风险作业，均须由持证专业人员确认并实施——① 燃气管道/表/热水器严禁私自隐蔽包裹，须取得当地燃气公司书面批准并确保通风与检修通道；② 拆墙、开洞、门洞加高拓宽、打通阳台须先确认非承重墙及墙内管线，取得物业与结构书面许可；③ 水电改造、闭水打压、防水施工属隐蔽工程，须持证水电工按规范施工并留存过程影像，闭水试验须通知楼下共同确认；④ 本指南仅帮助业主理解要点、与师傅沟通，不构成施工指导，严禁擅自施工。


油烟机家家户户几乎都有，除非你用集成灶。但很少有人去关注购买之前的一些常识了解。今天提几点大家容易忽略的地方，在自己装修的时候一定注意。

▲如图所示标红的地方就是烟机挡板，这个在购买烟机的时候一定注意。大部分品牌烟机，顶吸一般自带挡板，有的需要单独购买；侧吸烟机大部分都没有挡板，需要自购，这一点一定注意。
什么时候需要挡板，什么时候不需要挡板，一定根据自己家的设计决定。
▲如图如果自己家烟机是吊柜镶嵌，此时挡烟板可有可无，如果烟机商家需要自购挡烟板，此时可以节省不要了，要了反而占用空间，同时还影响以后的维修。
▲如果你不想隐藏烟机的话，购买烟机一定要购买挡板，否则露出来太丑，太难看
▲不隐藏烟机，又不购买挡板，就是这个样子，露出来太丑太难看了。其实只需要多掏点钱做上吊柜隐藏即可。
▲隐藏烟机并不是多此一举，第一美观好看，第二并不是没有功能性，照样可以储物收纳；
做吊柜橱柜定制注意烟管的位置问题，小细节有可能会造成返工。
▲如图大部分顶吸烟机，烟管的位置几乎都是居中设计的，所以在吊柜制作镶嵌的时候，需要根据挡板居中的尺寸规划内部空间
▲但是大部分侧吸烟机，烟管的位置不是居中位置，这里一定要注意这个细节，在吊柜内部根据设计的时候，这个细节会影响到完美。
