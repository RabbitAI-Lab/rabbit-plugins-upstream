## Description:

Helps AI-agent users, skill authors, maintainers, and teams plan, implement, verify, and harden AdMapix-style software/data workflows.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, maintainers, skill authors, and agent users use this skill to turn AdMapix-style raw-data workflow requests into concrete workflows, checklists, analysis, code changes, configuration guidance, and verification notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad implicit activation may cause the skill to run for software/data requests that are not actually AdMapix-style workflows.

Mitigation: Confirm the request is about an AdMapix-style raw-data workflow before applying the skill, or narrow activation to explicit AdMapix raw-data workflow requests.
