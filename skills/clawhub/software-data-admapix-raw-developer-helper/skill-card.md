## Description:

Helps AI-agent users and skill authors turn AdMapix-style software and data workflow requests into concrete plans, checklists, analyses, code changes, or validation steps.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, skill authors, maintainers, and AI-agent users use this skill to structure AdMapix-style software and data requests into actionable implementation, reliability, safety, and validation work. It is suited for practical workflow support, artifacts, checklists, analysis, code changes, and decision guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may route ordinary data, app, or bug-fix requests through this skill unintentionally.

Mitigation: Narrow the triggers or disable implicit invocation when deploying in environments where accidental routing would add noise or risk.
