## Use Case:

Developers, maintainers, skill authors, and AI-agent users use this skill to turn validated AdMapix-style demand into actionable workflows, checklists, analysis, code changes, shell commands, and configuration guidance. It is intended for practical local-hardware-friendly support around debugging, setup hardening, reliability improvement, and adjacent skill creation.

## Known Risks and Mitigations:

Risk: Broad implicit invocation wording may activate the skill on generic software or data requests.

Mitigation: Before installing, narrow or disable implicit invocation if the skill should only respond to explicit AdMapix-related workflow requests.

Risk: The skill can produce implementation guidance, code, shell commands, and configuration that may be wrong for a user's environment.

Mitigation: Review outputs before execution and run the suggested verification commands or checks in a controlled environment.
