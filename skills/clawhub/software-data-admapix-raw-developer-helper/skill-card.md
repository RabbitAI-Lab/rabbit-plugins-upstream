## Use Case:

Developers, AI-agent users, skill authors, maintainers, and teams use this skill to turn demand for AdMapix-style software-and-data workflows into practical local-hardware-friendly plans, implementation help, checklists, analyses, code changes, and validation notes.

## Known Risks and Mitigations:

Risk: Broad keywords and implicit invocation may cause the skill to activate on generic software or data requests.

Mitigation: Review trigger wording and invocation policy before deployment, and narrow keywords if the skill should only support AdMapix-style workflows.

Risk: Workflow advice may be incorrect or incomplete for a user's specific codebase, data, or operational constraints.

Mitigation: Require users to review proposed changes, run the included verification steps, and validate assumptions before applying recommendations.
