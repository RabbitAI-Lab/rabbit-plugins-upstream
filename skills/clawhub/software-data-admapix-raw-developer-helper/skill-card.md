## Description:

Helps agent users, skill authors, and maintainers adapt software and data workflows by clarifying requirements, planning implementation, and producing practical artifacts.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, agent users, and skill maintainers use this skill to turn a software or data request into a clear plan and a practical deliverable such as guidance, a checklist, analysis, or code. It emphasizes ordinary local hardware and checks the result against the user's stated goals.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may match unrelated requests.

Mitigation: Confirm the request concerns a relevant software or data workflow before applying the skill.
