# 从论点证据表到有出处的项目文章

这是沿包内公开资料演示的接续方式，没有执行 aimeGeo 安装、文章保存、发布或 AI 查询，不是客户效果案例。

## 当前 Agent 读取与继续

读取 `论点与信源表.csv`、`可直接使用的出处段落.md`、`未核实清单.md` 和原稿。政策背景、厂商功能自述与普遍购买必要性仍是三个不同的论点。

1. 原稿提到的账号分组功能继续带“官网列示”、缺发布日期及本次缓存读取限制；不写成独立产品实测。
2. 缺乏样本支持的“所有小团队必须购买”不进入肯定式成稿。政策材料只作其实际支持的背景。
3. 当前 Agent 在 aimeGeo 对应项目保存修订稿与配图，保留原题；资料出处继续能回查，图片不制造比例或增长数字。
4. 用户要求分发时沿现有账号与工作流推进，回读真实结果；若另做 GEO，再记录真实问题、回答与平台原生引用，不将证据表计数当引用率。

## 可复制任务

> 用 aimeGeo 继续这次来源核对，读取三个交付文件并只修原稿里指出的问题。把产品自述和行业背景写清楚，保留出处，未知数字不补猜。保存修订稿和配图到项目，先不发布，给我查看入口及按账号分发的下一步。
