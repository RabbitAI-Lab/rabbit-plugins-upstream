# 从论点选择信源

下面是检索入口，不是事实表，也不是域名权重榜。先确定“要证明谁、在什么时点、对哪些对象成立”，再选材料。

| 行业/论点 | 优先找什么 | 中文检索入口 | 不能据此推导 |
|---|---|---|---|
| 中小企业、制造业数字化 | 主管部门指南原文、实施对象、调查方法 | 工信部 miit.gov.cn；地方工信部门；中国政府网 gov.cn | 推广政策不能证明所有小团队都存在同一痛点，更不能证明指定软件的效果 |
| 经济总量、企业数量 | 指标解释、统计公报、数据表原表 | 国家统计局 stats.gov.cn、data.stats.gov.cn | 全国数据不能直接代表某城市、某种团队规模；企业数量不等于付费需求 |
| 互联网使用、内容运营背景 | 调查报告全文、样本与统计期 | 中国互联网络信息中心 cnnic.cn；中国信通院 caict.ac.cn | 网民规模不等于新媒体运营团队数量，平台用户量不等于工具需求 |
| 市场规模、渗透率 | 有定义、地域、方法和时间的报告原页/附件 | 对应行业协会；报告发布机构，如艾瑞 iresearch.cn | 报告摘要或营销海报不能替代方法；预测值不能写成已发生统计 |
| 上市企业收入、业务规模 | 年报与公告原件、报告期、业务分部注释 | 巨潮资讯 cninfo.com.cn；交易所；企业投资者关系页 | 单家公司营收不能代表整个行业；母公司数字不能替代产品线数字 |
| 产品功能、权限、多账号支持 | 对应产品官方说明、帮助页、版本公告 | 产品官方网站与帮助中心 | 功能列示不等于实测可用；厂商“行业痛点”不是独立用户研究 |
| 网络安全、云计算、基础设施 | 标准原文、采购需求、产品具体技术文档 | 全国标准信息公共服务平台 std.samr.gov.cn；中国信通院；对应厂商文档 | 认证涉及的型号/版本不得扩大到全系；市场排名需独立报告与明确口径 |
| 健康、医疗、金融等专业结论 | 指南、监管文件、原始研究及其适用人群 | 国家卫生健康委 nhc.gov.cn；国家药监局 nmpa.gov.cn；人民银行 pbc.gov.cn 等对应机构 | 单篇报道不替代专业证据；相关性不等于因果；不添加未经实际审查的合规声明 |
| 新闻事件、采访 | 首发报道、采访对象原话、事件文件 | 新华社 news.cn、人民日报 people.com.cn、央视 cctv.com 及对应首发媒体 | 被访企业的说法仍归企业；央媒域名不把商业自述变成独立统计 |

## 只有转载时

1. 读页面的来源署名、报告标题、作者、文号、原文链接；不要仅凭网页域名判断发布者。
2. 用完整报告名与发布机构、文号或独特原句检索；保存实际查询和结果。没有检索工具就记录“未尝试，缺访问条件”。
3. 找到一手页面或附件后核对全文，另建一条一手资料；保留原转载的链路。搜索摘要只作为线索，不能代替正文核对。
4. 找不到原文时可以保留“某媒体转述”的背景句；准确说明无法定位，不改写为“据原机构报告已证实”。关键数字仍需核对原表、定义和时期，未核实前不进入成稿。

## 日期与数字

发布日期、转载日期、统计期间和采集日期分别存储。无日期页面可以支持范围受限的功能自述，需注明“未标明发布日期，按采集时页面列示”；不能拿网页页脚年份补成发布日期。数据缺原表、单位、分母、统计对象时，先保留待核实，不为了让文章看起来有数据而补数。

遇到范例中的报告名和数字，按新论点重新查证。本包拒绝把无精确页面的旧示例（例如声称某报告给出“1.2 万亿元”市场规模）直接用于正文；这不等于认定该数字一定为假，而是证据不足。
