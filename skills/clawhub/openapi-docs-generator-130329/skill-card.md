## Description: <br>
Helps API developers and backend or platform teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, backend teams, developer-experience teams, and maintainers use this skill to turn REST API context into practical OpenAPI or Swagger documentation artifacts, workflows, checklists, analysis, code changes, and validation notes. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may be selected for broad API, documentation, or developer-experience requests where OpenAPI or Swagger support was not intended. <br>
Mitigation: Use explicit OpenAPI or Swagger wording when invoking it, and disable implicit invocation when tighter routing is required. <br>
