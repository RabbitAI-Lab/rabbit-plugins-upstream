# text-message-ad

An agent skill that builds animated iMessage-style conversation ads: a
self-contained HTML animation plus a 1080×1920 MP4 with synthesized
send/receive sounds, ready for YouTube Shorts, Reels, and TikTok.

**Intended use: marketing creative and product demos only.** The conversations
are fictional dramatizations between invented characters — a recognizable ad
format. Don't use it to impersonate real people, fake testimonials, or
fabricate conversations meant to deceive.

Bring your own logo, product, and pain point — the skill collects them
(see `references/brand-checklist.md`) and does the rest.

Requirements: Playwright + Chromium, ffmpeg, Python 3 with numpy.

Originally built for hurricaneinspections.com's Proof System ads and
open-sourced as a generic template.
