# Quick Checklist

Use this right before you return a rewrite. The goal is not perfection; it is
to catch the last obvious layer of AI pose without reopening the whole draft.

## 1. First-pass check

- Did you protect numbers, dates, names, commands, paths, quotes, and owners first?
- Did you identify the main problem family before rewriting?
- Did you use the lightest edit that actually solves the problem?
- Did you keep the scene intact instead of rewriting it into another genre?

## 2. Residue scan

Check only these five things on the second pass:

- **Opener residue**: `值得注意的是`, `直接说结论`, `Great question`, `Let's dive in`
- **Summary residue**: `综上所述`, `总的来说`, `简而言之`, `In conclusion`
- **Narrator residue**: `更重要的是`, `这说明了`, `真正值得注意的是`
- **Empty judgment**: `意义重大`, `方向是对的`, `pivotal`, `transformative`
- **Over-even rhythm**: too many sentences with near-identical length

If one of these is still present, fix it lightly. Do not reopen the whole rewrite unless the sentence is still unusable.

## 3. Rhythm check

- Are three consecutive sentences roughly the same length?
- Do paragraph endings all land in the same short, neat summary shape?
- Did you keep at least one sentence that sounds naturally spoken rather than uniformly “clean”?

Prefer one short interruption over full smoothing.

## 4. Trust-the-reader check

- Did you replace vague praise with a fact, number, or example?
- Did you remove explanation about the explanation?
- Did you cut “quote-ready” lines that sound written to be admired rather than understood?

If a line sounds like a poster, not a person, rewrite it.

## 5. Scene sanity check

- `README`: does the first screen say what it is, who it is for, and what problem it solves?
- `release-note`: does it list changes instead of writing a launch speech?
- `forum-post`: does it sound like a maintainer sharing observations, not a company announcement?
- `issue-reply`: does it answer the case before doing politeness?
- `docs/status`: if sourcing is missing, did you prefer `audit-only` over fake certainty?

## 6. Stop condition

Stop editing when all three are true:

- facts are intact
- the main AI pose is gone
- the remaining stiffness comes from protected spans or scene constraints

Do not polish the text until it loses its human edges.
