# 「机制机器」模板分镜草稿（machine.html）

> 状态：**已确认**（2026-11-05，Bonnie 拍板：白板同源 / 尾屏可选 / 首个样例 RAG），模板已落地 `templates/machine.html`，RAG 样例片为首个用例。
> 灵感：《经济机器是如何运行的》——"一句比喻定全场 + 开场先亮骨架 + 最小原子逐层放大"。

## 定位

讲"一个系统/机制怎么运转"——A 进来，经过几个环节，变成 B。
kepu 现在缺的叙事类型：它只会讲"知识点 / 故事 / 对比"，不会讲"系统怎么转"。

## 适合内容

- Agent 工作流：用户输入 → LLM 理解 → 调用工具 → 返回结果
- RAG 流程：问题 → 检索 → 上下文 → 生成
- 数据流水线、自动化流程、任何"输入 → 处理 → 输出"的机制

## 视觉基调

- 延续白板手绘风（rough.js）：纸面浅色 + 黑线主笔 + 红笔点破
- 新增一种强调色：蓝笔（#2b6cb0 系），专用于"流动粒子 / 反馈回路"，与黑白+红区分
- 机械隐喻元素：齿轮（环节）、管道箭头（流向）、流动小球（数据/状态）、回流虚线（反馈）

## 五幕结构（t 0–10s，约 10 秒）

### 幕 0 · 开场先亮骨架（0–1.2s）
- 画一个虚线机器外框，里面 3 个零件（齿轮或方框），标 ①②③
- 顶部标题点题（如"RAG 是怎么转起来的"）
- 目标：观众 1 秒知道"一台机器、3 个环节"

### 幕 1 · 最小原子点亮（1.2–3.5s）
- 第 1 个零件点亮，箭头流入一个"小球"（输入）
- 文案点出"最小可感单元"（如"你先问了一个问题"）

### 幕 2 · 因果链逐个流动（3.5–6.5s）
- 小球沿管道依次流经零件 2、3，每过一个，零件点亮、标号变实
- 箭头 + 流动粒子，讲"机制"（先 A 再 B 再 C），不罗列名词

### 幕 3 · 循环反馈（6.5–8s，仅闭环系统用）
- 一条蓝色回流虚线箭头（反馈回路）
- 开环（纯流水线）系统跳过此幕，直接进尾屏

### 幕 4 · 尾屏点破（8–10s）
- 舞台淡出，尾屏给「1 句点破 + 3 条法则」（3 法则可选）
- 点破句 ≤14 字

## 示例：RAG（检索增强生成）

- 3 个零件：① 你的问题 → ② 检索（向量库找相关资料）→ ③ 生成（LLM 照着资料写答案）
- 流动：问题小球 → 检索 → 生成 → 答案
- 反馈（可选）：用户反馈 → 优化检索
- 点破句候选：「先抄对书，再开口」（7 字）
