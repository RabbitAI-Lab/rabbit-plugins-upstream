## Description:

Helps assess an invention's novelty against prior art, compare relevant documents, and prepare a downloadable patent-novelty report through PatentMax.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ip930](https://clawhub.ai/user/ip930)

### License/Terms of Use:

MIT-0

## Use Case:

Inventors and R&D teams use this skill to check a described technical solution against earlier disclosures before filing or project review, compare the closest references, and obtain a report for internal review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Invention descriptions and possibly draft documents are sent to PatentMax for processing.

Mitigation: Share only material you are comfortable submitting to PatentMax and obtain user approval before submission.

Risk: A live novelty-search task may incur charges, including if submitted again.

Mitigation: Confirm the quoted cost before running a paid task; check an existing task rather than resubmitting it.

Risk: API credentials and locally saved reports may contain sensitive information.

Mitigation: Use a dedicated API key and keep it and the downloaded DOCX/JSON reports out of shared folders, logs, and public repositories.
