## 过程乌龟图概述

### 什么是过程乌龟图？

过程乌龟图（Turtle Diagram）是一种用于描述和分析过程的图形化工具，因其形状类似乌龟而得名。它通过6个关键要素，全面展示过程的输入、输出、资源、方法、绩效指标和风险。

### 为什么要用乌龟图？

- **系统化**：全面展示过程的各个维度，避免遗漏关键要素
- **可视化**：图形化呈现，便于理解和沟通
- **标准化**：统一的过程描述语言，便于内部审核和管理评审
- **风险导向**：明确识别过程风险和应对措施
- **PDCA循环**：体现过程管理的持续改进思想

### 乌龟图的应用场景

- ISO9001 质量管理体系文件编写
- 过程分析和优化
- 内部审核准备
- 管理评审输入
- 员工培训和沟通

## 乌龟图的6个要素

### 1. 过程（Process）—— 乌龟主体

**定义**：过程的目标、名称和范围

**内容要点**：
- 过程名称：简明扼要，如"生产和服务提供过程"
- 过程目标：该过程要达成的结果
- 过程范围：该过程的起止边界
- 过程所有者：负责该过程的部门或岗位

**示例**：
```
过程名称：生产和服务提供过程
过程目标：按计划、按标准、按时交付合格产品
过程范围：从生产计划下达至产品入库
过程所有者：生产部
```

---

### 2. 输入（Input）—— 乌龟头部

**定义**：过程开始前需要获得的人、财、物、信息等资源

**内容要点**：
- 上一过程的输出（作为本过程的输入）
- 生产/服务所需的物料、设备、信息
- 相关的文件、标准、规范
- 客户要求和订单信息

**示例**：
```
输入清单：
• 生产计划（来自生产计划过程）
• 物料（来自采购过程）
• 工艺文件、作业指导书（来自技术过程）
• 产品图纸、技术规范
• 生产设备、工具
• 质量标准、检验规范
• 人员（具备相应能力）
```

---

### 3. 输出（Output）—— 乌龟尾部

**定义**：过程结束后产生的产品、服务、信息等

**内容要点**：
- 符合要求的产品/服务
- 过程记录和报告
- 向下一过程交付的信息
- 向顾客交付的结果

**示例**：
```
输出清单：
• 合格产品
• 不合格品记录
• 生产记录表
• 检验报告
• 废次品统计
• 过程绩效数据
• 向仓储交付的产品
```

---

### 4. 资源（Resources）—— 乌龟左前腿

**定义**：过程执行所需的资源支持

**内容要点**：
- **人力资源**：人员数量、能力要求、培训情况
- **基础设施**：生产设备、检测设备、办公设施
- **过程环境**：工作环境、安全环境、温湿度等
- **信息系统**：ERP、MES、质量管理系统等
- **财务资源**：预算、资金支持

**示例**：
```
资源清单：
• 人员：生产操作工、检验员、班组长（已培训合格）
• 设备：生产设备50台（正常运行率≥95%）、检测设备10台（已校准）
• 设施：生产车间5000㎡、仓库2000㎡
• 工作环境：温度18-25℃、湿度40-70%、照明≥500lux
• 信息系统：ERP系统、MES系统
```

---

### 5. 方法（Methods）—— 乌龟右前腿

**定义**：过程执行所依据的标准、流程、制度、指导书等

**内容要点**：
- 法律法规和标准要求
- 公司内部制度、程序文件
- 作业指导书、操作规程
- 工艺标准、检验规范
- 工具、模板、检查表

**示例**：
```
方法清单：
• QP-850 生产和服务提供控制程序
• WI-805-01 生产作业指导书
• WI-860-01 检验和试验作业指导书
• 工艺文件、BOM表
• 检验规范、抽样标准
• GB/T 2828.1 计数抽样检验程序
• 设备操作规程
• 安全操作规程
```

---

### 6. 绩效指标（Performance Indicators）—— 乌龟左后腿

**定义**：衡量过程有效性的指标

**内容要点**：
- 效率指标：时间、产量、计划完成率等
- 质量指标：合格率、缺陷率、返工率等
- 成本指标：单位成本、能耗等
- 顾客满意度：交付及时率、投诉率等

**示例**：
```
绩效指标：
• 生产计划完成率 ≥ 98%
• 产品一次交检合格率 ≥ 95%
• 最终产品合格率 ≥ 98%
• 交付及时率 100%
• 生产设备完好率 ≥ 95%
• 单位产品能耗 ≤ [标准值]
• 顾客投诉率 ≤ 1%
```

---

### 7. 风险（Risk）—— 乌龟右后腿（可选要素）

**定义**：过程执行中可能面临的风险和应对措施

**内容要点**：
- 识别过程风险：设备故障、物料不合格、人员失误等
- 评估风险等级：高、中、低
- 制定应对措施：预防措施、应急措施

**示例**：
```
风险与应对：
风险1：生产设备故障
• 风险等级：高
• 影响：停产、延期交付
• 应对措施：定期维护保养、备机备用、设备监控

风险2：物料不合格
• 风险等级：中
• 影响：返工、报废
• 应对措施：进料检验、供应商管理、物料标识

风险3：人员操作失误
• 风险等级：中
• 影响：质量缺陷、安全事故
• 应对措施：技能培训、操作规程、质量意识教育

风险4：交付延迟
• 风险等级：高
• 影响：顾客投诉、违约
• 应对措施：生产计划优化、产能预留、应急预案
```

## 绘制步骤

### 步骤1：识别过程

- 明确过程的名称和范围
- 确定过程的目标和所有者
- 理解过程在整体体系中的位置

### 步骤2：分析输入和输出

- 列出过程需要的所有输入
- 列出过程产生的所有输出
- 识别上一过程和下一过程

### 步骤3：确定所需资源

- 识别人力资源需求
- 识别基础设施需求
- 识别环境和其他资源需求

### 步骤4：确定执行方法

- 列出相关的程序文件、作业指导书
- 列出标准、规范、工艺文件
- 列出其他支持工具和方法

### 步骤5：设定绩效指标

- 根据过程目标设定关键指标
- 确定指标的目标值和测量方法
- 确保指标可测量、可追踪

### 步骤6：识别风险和应对

- 识别过程可能面临的风险
- 评估风险等级
- 制定相应的应对措施

### 步骤7：绘制乌龟图

- 使用图形工具（Word、Visio、PPT等）绘制
- 按照6个要素的位置布局
- 填充具体内容
- 确保清晰、完整、准确

## 绘制注意事项

### 1. 内容完整性
- 确保每个要素都有详细描述
- 不要遗漏关键要素（如风险）
- 输入和输出要相互对应

### 2. 可操作性
- 资源、方法要具体明确
- 绩效指标要可测量、可追踪
- 风险应对措施要可行

### 3. 企业适应性
- 根据企业实际情况调整内容
- 避免照搬模板
- 体现企业特色和行业特点

### 4. 一致性
- 与程序文件、作业指导书保持一致
- 与质量手册中的过程描述保持一致
- 与实际运作保持一致

### 5. 可视化效果
- 图形清晰、美观
- 文字简明扼要
- 便于理解和沟通

### 6. 持续改进
- 定期审查乌龟图的适用性
- 根据实际情况更新内容
- 作为内部审核的依据

## Word中绘制乌龟图的方法

### 方法1：使用表格绘制

1. 创建一个7行2列的表格
2. 合并单元格形成乌龟形状
3. 填充6个要素的内容
4. 添加边框和底色美化

### 方法2：使用SmartArt绘制

1. 插入 → SmartArt → 流程
2. 选择适合的布局
3. 添加文本框填充内容
4. 调整形状和连接线

### 方法3：使用文本框和形状

1. 插入文本框（过程、输入、输出等）
2. 使用形状绘制连接线
3. 调整位置形成乌龟形状
4. 添加颜色和样式
