## 概览
本指南详细说明了如何识别组织的关键过程、制作"乌龟图"以及识别过程风险和控制措施。这是基于ISO9001:2015标准的过程方法和风险思维，将标准要求转化为实际业务流程的核心工具。

## 过程分类方法

### 1. 顾客导向过程（COP）
**定义**：直接与顾客接触，创造价值，满足顾客要求的过程。

**典型过程**：
- 营销管理过程
- 设计开发过程（如适用）
- 采购过程
- 生产/服务提供过程
- 交付过程
- 服务过程（如适用）

### 2. 支持过程（SOP）
**定义**：为COP提供资源和支持，确保COP顺利进行的过程。

**典型过程**：
- 人力资源过程
- 设备管理过程
- 文件控制过程
- 仓库管理过程
- 测量设备管理过程
- 其他支持过程（如培训管理、环境管理等）

### 3. 管理过程（MOP）
**定义**：对质量管理体系进行策划、实施、评价和改进的过程。

**典型过程**：
- 体系策划过程
- 管理评审过程
- 内部审核过程
- 纠正措施过程
- 风险和机遇管理过程

## "乌龟图"制作指南

### "乌龟图"的6个核心要素

#### 1. 过程活动（"乌龟图""1活动"）
**定义**：描述过程的具体活动和步骤。

**格式要求**：
- 按步骤描述，使用箭头连接
- 示例：潜在客户开发 → 询价报价 → 商务谈判 → 合同签订 → 订单管理 → 客户档案维护

#### 2. 过程输入（"乌龟图""2输入"）
**定义**：过程开始时需要的信息和资源。

**分类**：
- **信息类**：如年度经营计划、客户需求、法律法规要求、标准要求
- **资源类**：如原材料、设备、工具

**示例**：
- 年度经营计划
- 客户需求
- 适用的法律、法规要求
- 来源于以前类似设计和开发活动的信息
- 对确定项目的安全性和适用性至关重要的功能和性能要求
- 组织承诺实施的标准或行业规范

#### 3. 过程输出（"乌龟图""3输出"）
**定义**：过程结束时的结果。

**示例**：
- 销售合同
- 客户档案
- 报价单
- 产品
- 服务

#### 4. 过程资源（"乌龟图""4资源"）
**定义**：执行过程所需的各种资源。

**分类**：
- **人力资源**：岗位、人员、技能
- **设施设备**：生产设施、办公设备、工具
- **资金**：预算、成本
- **信息资源**：ERP系统、数据库、网站

**示例**：
- 销售团队
- 资金
- 生产设施
- 供应商
- 原材料及辅料
- 测量设备

#### 5. 责任部门/岗位（"乌龟图""5责任人"）
**定义**：负责执行过程的部门或岗位。

**示例**：
- 责任部门：销售部
- 涉及人员：销售总监、销售经理、销售员

#### 6. 关键绩效指标（"乌龟图""6KPI"）
**定义**：衡量过程有效性的量化指标。

**示例**：
- 销售达成率 ≥ 95%
- 客户满意度 ≥ 90%
- 交付及时率 100%

#### 7. 方法与准则（"乌龟图""7方法"）
**定义**：执行过程的方法、标准、规范。

**示例**：
- 营销管理控制程序
- 客户管理程序
- ISO9001:2015 8.2条款

#### 8. 风险及控制措施（"乌龟图""8风险"）
**定义**：过程中可能存在的风险及其控制措施。

**格式要求**：
- 风险：描述风险
- 措施：描述控制措施

**示例**：
- 风险：客户需求识别不准确 → 措施：多次沟通确认需求
- 风险：价格不合理 → 措施：市场调研定价
- 风险：交货延迟 → 措施：提前储备安全库存

### "乌龟图"制作流程

**步骤1：先完成"1活动"分解**
- 将过程分解为具体的步骤
- 使用箭头连接各步骤

**步骤2：按照活动每一步完成"2,3,4,5,6"**
- 为每个活动步骤确定：输入、输出、资源、责任人、KPI

**步骤3：最后完成"7"，考虑最终形成几个文件**
- 确定方法与准则
- 考虑需要形成几个程序文件、作业指导书、表单

## 风险识别和控制措施

### 风险识别方法

#### 1. 风险识别的维度
- **输入风险**：信息不准确、不及时、不完整
- **过程风险**：流程不合理、资源不足、技能不足
- **输出风险**：结果不符合要求、交付延迟
- **外部风险**：市场变化、法律法规变化、供应商问题

#### 2. 常见风险示例

**营销管理过程**：
- 风险：客户需求识别不准确 → 措施：多次沟通确认需求
- 风险：价格不合理 → 措施：市场调研定价
- 风险：交货延迟 → 措施：提前储备安全库存

**生产过程**：
- 风险：设备故障 → 措施：定期维护保养、备用设备
- 风险：质量不合格 → 措施：首件检验、过程巡检
- 风险：人员技能不足 → 措施：培训考核、持证上岗

**采购过程**：
- 风险：供应商不合格 → 措施：供应商评审、定期考核
- 风险：原材料质量不合格 → 措施：进料检验、供应商改进

### 风险控制措施
- **预防措施**：消除或降低风险发生的可能性
- **纠正措施**：消除风险发生后的影响
- **应急预案**：在风险发生时快速响应

## 过程信息收集流程

### 对话话术

```
智能体：现在开始进行过程识别和分析。

请识别贵公司的关键过程，我建议按照以下分类：

【顾客导向过程（COP）】
  ☐ 营销管理过程
  ☐ 设计开发过程（如适用）
  ☐ 采购过程
  ☐ 生产/服务提供过程
  ☐ 交付过程
  ☐ 服务过程（如适用）

【支持过程（SOP）】
  ☐ 人力资源过程
  ☐ 设备管理过程
  ☐ 文件控制过程
  ☐ 仓库管理过程
  ☐ 测量设备管理过程
  ☐ 其他支持过程（请说明）

【管理过程（MOP）】
  ☐ 体系策划过程
  ☐ 管理评审过程
  ☐ 内部审核过程
  ☐ 纠正措施过程
```

### 信息收集清单

对于每个过程，收集以下信息：

1. **过程名称**

   - 资源类：如原材料、设备

4. **过程输出**（"乌龟图""3输出"）
   - 如销售合同、客户档案、报价单

5. **过程资源**（"乌龟图""4资源"）
   - 如销售团队、市场推广资源、资金

6. **过程责任部门/岗位**（"乌龟图""5责任人"）

### 示例1：营销管理过程"乌龟图"

```
- 年度经营计划

- 销售达成率 ≥ 95%
```

### 示例3：内部审核过程"乌龟图"

```
过程名称：内部审核过程

1. 活动：
制定审核计划 → 编制检查表 → 实施审核 → 开具不符合项 → 跟踪验证 → 出具审核报告

2. 输入：
- 审核计划
- 检查表
- 体系文件

3. 输出：
审核报告、不符合项报告、纠正措施报告

4. 资源：
- 审核员
- 检查表
- 体系文件

5. 责任部门/岗位：
责任部门：质量部
涉及人员：管理者代表、审核组长、审核员

6. 关键绩效指标：
- 审核计划完成率 100%
- 不符合项按时关闭率 ≥ 95%
- 审核员能力符合要求

7. 方法与准则：
内部审核控制程序、ISO9001:2015 9.2条款

8. 风险及控制措施：
- 风险：审核不客观 → 措施：审核员培训、交叉审核
- 风险：不符合项跟踪不到位 → 措施：建立跟踪机制、定期回顾
```
