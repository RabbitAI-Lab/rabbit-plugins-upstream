## 使用说明

1. **文件编号规则**：
   - 一级文件（质量手册）：QM-001
   - 二级文件（程序文件）：QP-XXX-YY
     - XXX：COP（顾客导向过程）、SOP（支持过程）、MOP（管理过程）
     - YY：序号
   - 三级文件（作业指导书）：WI-XXX-YY-ZZ
     - XXX：COP、SOP、MOP
     - YY：程序文件序号
     - ZZ：序号
   - 四级文件（表单）：QR-XXX-YY-ZZ
     - XXX：COP、SOP、MOP
     - YY：程序文件序号
     - ZZ：序号

2. **文件数量参考**：
   - 质量手册：1个
   - 程序文件：10-15个
   - 作业指导书：20-30个
   - 表单模板：30-40个
   - 总计：约61-86个文件

3. **文件选择建议**：
   - 根据企业实际情况选择需要的文件
   - 制造业企业可能需要更多作业指导书
   - 服务业企业可能需要更多服务相关的文件
   - 小型企业可以简化文件结构

4. **文件生成流程**：
   - 先确认企业信息
   - 再识别关键过程（COP/SOP/MOP）
   - 然后确认文件编号规则
   - 最后按需生成文件
