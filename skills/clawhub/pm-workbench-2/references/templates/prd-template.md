# PRD 模板

## 使用说明
- 这是一个 PRD 结构模板
- 实际使用时，AI 会根据用户输入填充各部分
- 标注 [必填] 的部分一定要写清楚
- 标注 [选填] 的部分根据项目复杂度决定是否填写

---

## 1. 需求概述 [必填]

### 1.1 需求标题
一句话描述这个需求是什么。

### 1.2 需求背景
- 谁提出的这个需求？遇到了什么问题？
- 当前怎么解决的？有什么痛点？
- 如果不做，会有什么影响？

### 1.3 需求目标
- 核心目标（要达成什么结果，可量化的指标）
- 成功标准（怎么算做成了？）

### 1.4 涉及范围
- 功能范围：做哪些，不做哪些
- 影响范围：涉及哪些用户？哪些模块？
- 依赖范围：依赖哪些上下游？

---

## 2. 用户分析 [必填]

### 2.1 目标用户
| 用户角色 | 使用场景 | 使用频率 | 核心诉求 |
|---------|---------|---------|---------|
| | | | |

### 2.2 用户故事
作为 **[什么角色]**，我想要 **[做什么]** ，以便 **[达成什么目标]**。

### 2.3 用户路径
描述核心使用路径（从进入功能到完成目标的关键步骤）：
1. ...
2. ...
3. ...

---

## 3. 功能设计 [必填]

### 3.1 功能列表
| 优先级 | 功能 | 说明 | 是否 MVP |
|-------|------|------|----------|
| P0 | | | 是 |
| P1 | | | 否 |
| P2 | | | 否 |

### 3.2 核心功能详解（按优先级逐个展开）
每个功能包含：
- 功能描述
- 交互说明
- 前置条件
- 后置结果
- 异常处理

### 3.3 交互流程
描述主要交互流程，标注关键节点和分支逻辑。

### 3.4 边界情况
- 空态：页面没有任何数据时展示什么？
- 加载态：数据加载中展示什么？
- 错误态：数据加载失败展示什么？用户可以做什么？
- 权限态：无权限用户看到什么？
- 极限情况：数据量为 0 / 极大值时的表现

---

## 4. 数据方案 [视情况必填]

### 4.1 指标定义
| 指标名称 | 口径定义 | 计算方式 | 基线值 | 目标值 |
|---------|---------|---------|-------|-------|
| | | | | |

### 4.2 埋点方案（数据产品重点填写）
| 事件名称 | 触发时机 | 事件属性 | 备注 |
|---------|---------|---------|------|
| | | | |

### 4.3 实验设计（如需 AB 测试）
- 实验假设
- 对照组 vs 实验组
- 核心指标和护栏指标
- 流量分配和样本量
- 实验周期

---

## 5. 非功能需求 [选填]

### 5.1 性能要求
- 页面加载时间
- 接口响应时间
- 并发量预估

### 5.2 安全要求
- 数据权限
- 操作审计
- 敏感数据处理

### 5.3 兼容性
- 浏览器兼容
- 设备兼容
- 版本兼容

### 6.2 验收 checklist
- [ ] 所有 P0 功能通过验收
- [ ] 边界情况处理正确
- [ ] 埋点数据正常上报
- [ ] 无严重性能问题
- [ ] 权限控制正确

## 7. 上线计划 [必填]

### 7.1 灰度策略
- 灰度比例：X%
- 灰度用户：按什么维度选择
- 灰度观察期：X 天

### 7.2 上线 checklist
- [ ] 监控告警已配置
- [ ] 回滚方案已准备
- [ ] 公告/通知已准备
- [ ] 客服 FAQ 已更新

### 7.3 风险与回滚
- 最大风险点是什么？
- 什么情况下需要回滚？
- 回滚操作的步骤和时间
