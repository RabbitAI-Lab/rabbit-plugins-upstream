# 项目复盘模板

## 复盘原则
- 复盘的目的不是追责，是学习
- 从结果反推过程，而不是从过程解释结果
- 好的复盘 = 数据 + 逻辑 + 行动项

### 2. 数据回收

#### 核心指标达成
| 指标 | 目标值 | 实际值 | 达成率 | 备注 |

#### 数据趋势分析
- 上线后指标的变化趋势（从上线到现在的走势）
- 是否有异常波动？原因是什么？
- 与预期的差距有多大？

### 3. 用户反馈

#### 正向反馈
- 用户喜欢什么？为什么？
- 数据上有什么证据支持？

#### 负向反馈
- 用户抱怨什么？为什么？
- 负向反馈的规模和严重程度？

### 4. 根因分析

回答三个问题：
1. **数据好的原因是什么？**
   - 是偶然还是必然？能不能复现？
   - 如果换一批用户，结果还会好吗？

2. **数据差的原因是什么？**
   - 是方案问题还是执行问题？
   - 是需求理解错了还是实现有问题？

3. **超出预期的是什么？**
   - 正面意外 → 能不能继续放大？
   - 负面意外 → 下次怎么避免？

## 复盘 checklist
- [ ] 数据回收完整（核心指标 + 护栏指标）
- [ ] 用户反馈渠道充分（评价、客服、访谈等）
- [ ] 根因分析有数据支撑，不是拍脑袋
- [ ] 行动项有人负责人有 deadline
- [ ] 经验已记录并分享到团队
