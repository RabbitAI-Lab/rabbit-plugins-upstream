# 竞品分析框架

## 分析步骤

### 第一步：确定分析范围
先明确：分析的目的是什么？
- **战略对标**：看行业发展方向，找到自己的定位
- **功能对标**：找功能差距，决定抄不抄、怎么抄
- **用户体验对标**：看交互细节，优化体验
- **定价对标**：看商业模式，调整定价策略

竞品范围：
- 直接竞品（做同一件事的）
- 间接竞品（解决同一问题的不同方案）
- 潜在竞品（可能进入这个领域的）

一般选 3-5 个，别贪多。

### 第二步：功能拆解
按模块列出每个竞品的功能，标注：
- ✅ 有且完善
- ⚠️ 有但不完善
- ❌ 没有
- 🔮 预告/内测中

|---------|---------|-------|-------|-------|
| | | | | |

### 第三步：差异化分析
找到三个关键问题的答案：
1. 竞品做得比我们好的地方 → 我们怎么追上？
2. 我们做得比竞品好的地方 → 怎么放大优势？
3. 大家都做得不好的地方 → 这是不是我们的机会？

### 第四步：策略建议
基于分析给出可落地的建议，按优先级排序：
- 短期要做的事（1-2 周）：小优化、修 bug、补功能
- 中期要做的事（1-2 月）：功能迭代、体验优化
- 长期要做的事（3-6 月）：战略投入、差异化建设

## 分析维度

### 产品维度
- 核心功能完整度
- 用户体验/易用性
- 性能/稳定性
- 更新迭代速度

### 用户维度
- 目标用户画像
- 用户规模和增长趋势
- 用户口碑/评价
- 用户留存和粘性

### 商业维度
- 商业模式
- 定价策略
- 收入规模（估算）
- 融资/资源情况

### 技术维度
- 技术架构
- AI/算法能力
- 数据积累
- 技术壁垒

## 输出格式

分析报告结构：
1. 分析背景和目的
2. 竞品概览（一句话定位 + 关键数据）
3. 功能对比矩阵
4. 差异化分析和洞察
5. 策略建议（含优先级和预期效果）
6. 附录（详细对比数据）

## 注意事项
- 不要为了分析而分析，每次分析都要有明确的「要回答的问题」
- 功能对比要实事求是，不要美化自己、贬低对手
- 竞品分析是手段不是目的，最终要落到「我们该做什么」
- 定期更新竞品信息，竞品是会变的
