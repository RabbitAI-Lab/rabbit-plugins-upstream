# 用户增长方案设计

> 从诊断到执行的全流程增长方法论。覆盖漏斗分析、渠道策略、裂变设计、实验规划、资源分配五大模块。

---

## 一、增长诊断：先找增长杠杆

### 诊断三步法

```
数据扫描 → 杠杆识别 → 方案假设
```

### 第一步：数据扫描

用 AARRR 模型扫描各环节健康度：

| 环节 | 核心指标 | 健康基准参考 | 常见问题 |
|------|---------|-------------|---------|
| Acquisition | 新增用户量、CAC、渠道 ROI | CAC < LTV/3 | 投放效率低、自然量增长乏力 |
| Activation | 激活率、首日关键行为完成率 | 40%+ | 注册流程长、价值感知弱 |
| Retention | 次日/7日/30日留存 | 次日40%+ | 产品粘性不足、核心价值没传达到 |
| Revenue | 付费转化率、ARPU、LTV | 根据行业不同 | 定价策略、付费意愿、支付体验 |
| Referral | 邀请率、K 因子 | K > 0.3 有传播性 | 激励不够、分享门槛高、缺乏社交货币 |

### 第二步：杠杆识别

用以下框架找到「投入产出比最高」的增长杠杆：

```
问题矩阵 = 影响面 × 优化难度

          影响面大
            │
   ┌────────┼────────┐
   │ 低优先级 │ 核心杠杆 │
   │ (难/大)  │ 优先投入 │
   └────────┼────────┘
   ┌────────┼────────┐
优化难度大──┼──优化难度小
   ┌────────┼────────┐
   │  不做   │ 顺手做  │
   │ (难/小)  │ (易/小) │
   └────────┴────────┘
            │
          影响面小
```

**推荐优先级**：核心杠杆（右上）→ 顺手做（右下）→ 低优先级（左上）→ 不做（左下）

### 第三步：方案假设

每个杠杆写出一个清晰的增长假设：

> 「如果我们做 _____（具体行动），预计能带来 _____（量化目标），因为 _____（逻辑依据），我们通过 _____（衡量方式）来验证。」

示例：
> 「如果我们在注册流程第三步加入社交账号一键登录，预计能提升注册转化率 15-20%，因为当前有 30% 的用户在这一步流失，且竞品数据显示社交登录可降低 40% 的注册摩擦。我们通过对比实验组的注册完成率来验证。」

## 二、漏斗诊断与优化

### 漏斗分析标准流程

```
1. 画完整漏斗（每个环节的绝对量 + 转化率）
2. 找最大流失点（绝对量 × 转化率损失）
3. 深挖流失原因（定性 + 定量）
4. 设计优化方案
5. 实验验证
```

### 漏斗拆解模板

以在线教育典型转化漏斗为例：

```
环节                用户量       转化率       行业参考       判断
──────────────────────────────────────────────────────────────
广告曝光          1,000,000       —           —            —
广告点击            30,000      3.0%       2-5%          正常
落地页浏览          28,000     93.3%       90%+          正常
注册                8,400     30.0%       25-35%        偏弱 ⚠️
选择课程            2,520     30.0%       35-45%        偏弱 ⚠️
试听/体验            1,512     60.0%       50-60%        正常
购买                  302     20.0%       15-25%        正常
完课                  196     65.0%       60-70%        正常
续报                   78     40.0%       35-45%        正常
```

**优先优化**：注册转化率（30% → 35%，额外 +420 注册）和选课转化率（30% → 35%，额外 +294 选课）。

### 常见漏斗问题及解法

| 问题 | 常见原因 | 解法方向 |
|------|---------|---------|
| 注册转化率低 | 流程长、信息多、价值不明确 | 缩短流程、社交登录、注册前预览价值 |
| 激活率低 | 没有清晰的首动作、价值感知弱 | 新手引导、首次体验设计、即时反馈 |
| 留存差 | 核心价值没打到、竞品替代性强 | 强化核心功能、个性化推荐、习惯养成机制 |
| 付费转化低 | 价格敏感、信任不足、决策成本高 | 免费增值/试用、价格锚定、信任背书 |

## 三、渠道策略

### 渠道矩阵

```
渠道分类 = 付费渠道 + 免费渠道 + 产品渠道

付费渠道（花钱买量）
├── 信息流投放（抖音/快手/小红书/腾讯广告）
├── 搜索投放（百度/搜狗/应用商店）
├── KOL/KOC 合作
└── 线下渠道

免费渠道
├── SEO/ASO
├── 内容营销（公众号/视频号/知乎/B站）
├── 社群/私域
└── PR/媒体合作

产品渠道（产品自带增长）
├── 社交裂变（分享/邀请/拼团）
├── 自然搜索（产品内搜索流量分发）
├── 应用商店自然量
└── 口碑/NPS
```

### 渠道评估框架

对每个渠道评估 4 个维度（1-5分），选出核心渠道：

```
         量级   精准度  ROI   可持续性  总分
信息流     5      3      3      3      14
搜索投放   3      5      4      4      16  ← 高分
KOL合作    3      4      3      2      12
内容营销   2      4      5      5      16  ← 高分
社交裂变   4      3      5      4      16  ← 高分
```

**策略建议**：搜索投放 + 内容营销 + 社交裂变作为三条主增长线。

## 四、裂变设计

### 裂变四要素

```
触发物 → 分享动机 → 传播路径 → 承接体验
```

### 常见裂变模式

| 模式 | 适用场景 | 核心激励 | 注意事项 |
|------|---------|---------|---------|
| **邀请有礼** | 有天然社交场景的产品 | 双向奖励（现金/权益） | 防刷、风控、成本测算 |
| **拼团** | 客单价较高的付费产品 | 一起买更便宜 | 拼团成功率、团长激励 |
| **分销** | 有用户信任基础的场景 | 佣金分成 | 合规性、分佣透明度 |
| **内容裂变** | 有内容生产能力 | 内容本身是社交货币 | 裂变率由内容质量决定 |
| **工具裂变** | 有实用价值的工具属性 | 工具的使用价值 | 结果页/分享页引导 |

### 裂变方案模板

```markdown
## 裂变活动方案

### 基本信息
- 活动名称：
- 活动目标：
- 目标用户：
- 活动周期：

### 活动机制
- 用户完成什么动作触发裂变？
- 被邀请人的激励是什么？
- 邀请人的激励是什么？
- 上限规则：

### 传播设计
- 分享物（用户分享什么）？
- 分享渠道（微信/朋友圈/其他）？
- 社交话术（默认文案 + 个性化空间）？

### 防刷策略
- 设备/IP 限制
- 行为异常检测
- 收益上限控制

### 成本预估
- 单用户激励成本
- 预期参与人数
- 预估总成本
- 预期 ROI（新增用户价值 / 总成本）

### 衡量指标
- 参与率 = 参与用户 / 曝光用户
- 分享率 = 分享用户 / 参与用户
- 点击率 = 点击用户 / 曝光用户
- 转化率 = 新增用户 / 点击用户
- K因子 = 邀请用户数 / 发起用户数
- 获客成本 = 总激励成本 / 新增用户数
```

## 五、实验规划

### 增长实验节奏

```
轻量级实验（1-2周，快速验证）
├── 文案/UI 微调
├── 流程顺序调整
├── 引导/提醒优化
└── 定价策略测试

中型实验（2-4周，较大改动）
├── 功能模块调整
├── 渠道策略切换
├── 裂变机制迭代
└── 内容策略调整

重型实验（1-2月，结构性改动）
├── 产品定位/价值主张调整
├── 增长模型重构
├── 新渠道/新市场开拓
```

## 六、资源分配与 ROI 测算

### 增长预算分配原则

```
70% → 确定性增长（已验证的渠道/策略优化）
20% → 新增长引擎（新渠道测试、新裂变模式）
10% → 探索性实验（高风险高回报尝试）
```

### ROI 测算框架

```markdown
## ROI 快速测算

### 收入侧
- 单用户 LTV：¥_____
- 月目标新增：_____ 人
- 月预期收入 = LTV × 月目标新增

### 成本侧
- CAC（获客成本）= 总投放成本 / 新增用户数
  - 渠道 A CAC：¥_____
  - 渠道 B CAC：¥_____
  - 自然量 CAC：¥0
- 综合 CAC：¥_____
- 月总成本 = 综合 CAC × 月目标新增 + 固定成本

### 回收周期
- 回收期 = CAC / 月人均贡献收入
- 健康标准：回收期 < 6 个月（内容/教育类偏长）
```

## 七、使用说明

当用户说「帮我做一个增长方案」「我的产品增长遇到瓶颈」「设计一个裂变活动」时：

1. **诊断优先**：先分析现状数据，找到增长杠杆，再设计方案
2. **假设驱动**：每个方案都要有清晰的假设和验证方式
3. **量化表达**：用数据说话，不要「感觉能增长」
4. **资源敏感**：考虑团队实际情况，给出的方案要能落地
5. **风险意识**：每个方案都要有止损条件和回滚方案

### 工作模式

- **诊断模式**：用户描述现状 → 你帮分析数据、找杠杆 → 输出诊断报告
- **方案模式**：用户指定方向 → 你出完整方案（机制、成本、衡量）
- **评审模式**：用户拿出方案 → 你从数据、风险、可行性角度挑战和优化
