# 0 号样本复盘 · 《下一代学校》（李希贵）

> 本文件是 book-traces 的完整链路示范。第一次跑本 skill 时，先读这里掌握完整走法。

## 样本概况

- 书：李希贵《下一代学校》，一本讲「学校如何应对 AI 冲击」的书
- 读者：一位在「敢不敢裸辞」里打转、正从运营转 AI 方向的打工人
- 共鸣点（第①步问清的那句）：**不是要介绍这本书，而是「书里学生的处境 = 我自己的处境」**

## 完整链路（四步怎么落地）

### ① 开读前

共鸣点一句话锁定：读者在纠结要不要裸辞，本质是「没学过自己选」。这决定了后面所有素材都往「自己选 / 判断力」这个方向收。

### ② 读过程（挖素材）

- 收了 12 条划线（P6/P13/P17/P37/P53/P75/P77/P93/P102/P155/P160/P165）+ 16 条口述感受。
- **对话式追问**：读者贴一句划线，就反问「这跟你职场里哪件事对得上」，从她的回答里挖素材。
- **反向映射**的关键产出：
  - 「真正的他人不是背景，而是变量」→ 老板派的活，从没想过是不是真问题
  - 「等待被选择」→ 升学等通知、求职等 offer、跳槽等猎头，从没练过自己拍板
  - 「不得不完美」→ 职场谨言慎行、只交满意答卷，是练了十年的隐藏

### ③ 梳理

- **脉络用递进线**，不是思维导图：P6 处境 → P13 标准 → P17 觉醒 → P37 症结 → P53 结构 → P75/P77 方法 → P93/P102 真实条件/反馈 → P155 敢说 → P160 不得不完美 → P165 回来。
- **题眼 = 同构**：学校被 AI 冲击（从「教答案」转「教组织局面」），读者也被 AI 冲击（从「高效执行」转「自己拍板判断」）。落点一句话：「AI 时代最稀缺的不是执行力，是判断力」。

## 踩过的坑（第二层·方法资产的来源）

1. **书页实拍不落盘会丢**：拍照当时只贴在剪贴板，差点没了。规则：拍照当场存进 `书页实拍/` 并登记素材池。
2. **没读完别急着出结论**：读者读到第一章就问「是不是太早了」，正确节奏是等读完、语料够再成文。
3. **金句卡重点放错**：初版把页码放大强调，读者纠正——重点是**作者署名 + 关键词大字**，页码弱化到右下角。
4. **配图前核对素材池**：正文标了「实拍 P37」，但实拍目录里没有 P37（只拍过 P13/P53/P75/P102/P160）。配图前先对素材池，别凭空写占位。
5. **重复选题要挪落点**：读者之前提过「裸辞」，这次若再以裸辞当钩子会重复。做法是把重心从「敢不敢」挪到「为什么纠结」（不是没勇气，是缺课），同一个伤口挖到根。
6. **违禁词 API 可能积分不足**：REDFOX API 报 code 3210 时，改用 `xiaohongshu-prohibited-words` 本地词库兜底，别卡死。
