## Description:

Helps an agent view and manage Zola wedding planning data, including vendors, budgets, guests, events, seating, registry items, and gifts.

This skill is ready for commercial/non-commercial use.

## Publisher:

[chrischall](https://clawhub.ai/user/chrischall)

### License/Terms of Use:

MIT-0

## Use Case:

People planning a wedding can ask an agent to review Zola account information and manage vendors, budgets, guests, RSVPs, seating, events, and gifts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Account-changing actions could unintentionally alter bookings, budgets, guests, seating, invitations, or event details.

Mitigation: Require explicit user confirmation before any add, update, remove, booking, seating, invitation, or budget change.

Risk: Zola account data may contain sensitive guest, address, budget, RSVP, registry, or vendor information.

Mitigation: Review the skill before installing and use it only when intending to manage that Zola data.
