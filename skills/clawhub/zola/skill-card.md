## Description:

Helps an agent review and manage Zola wedding plans, including vendors, budgets, guests, seating, events, and gifts.

This skill is ready for commercial/non-commercial use.

## Publisher:

[chrischall](https://clawhub.ai/user/chrischall)

### License/Terms of Use:

MIT-0

## Use Case:

People planning a wedding can use this skill to ask an agent about their Zola vendors, budget, guest list, RSVPs, seating, events, registry, and gifts, or to request changes to those records.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can change or remove personal wedding details without clear confirmation boundaries.

Mitigation: Use it only when Zola access is explicitly requested, and require confirmation before adding, updating, removing, assigning, inviting, or changing any vendor, budget, guest, seating, event, RSVP, inquiry, or registry record.
