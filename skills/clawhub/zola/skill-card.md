## Description:

This skill helps agents work with Zola wedding-planning data, including vendors, budgets, guests, RSVPs, seating, registry items, gifts, storefronts, and vendor inquiries.

This skill is ready for commercial/non-commercial use.

## Publisher:

[chrischall](https://clawhub.ai/user/chrischall)

### License/Terms of Use:

MIT-0

## Use Case:

Users planning weddings and their assistants use this skill to retrieve and manage Zola vendors, budgets, guest lists, seating, events, RSVPs, registries, gifts, and vendor inquiries through the connected account.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can expose private guest, address, budget, vendor, registry, RSVP, and gift data from a connected Zola account.

Mitigation: Install and use it only when access to that Zola account data is intended, and review responses before sharing them.

Risk: The skill includes actions that can add, update, remove, invite, seat, or otherwise change wedding-planning records.

Mitigation: Require explicit user confirmation before any account-changing action.
