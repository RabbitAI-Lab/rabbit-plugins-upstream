## 初衷

> **问对了企业、问准了方向，专利数据自己会说话。**

「分析一下竞争对手」最常见的失败，不是数据不够，而是问题没问清：企业名和专利登记名对不上，查出来是空的；方向写成一句「XX 公司的专利布局」，检索跑偏。

所以这个 Skill 只要两样东西：**目标企业的登记全称**和**一个具体的技术方向**。它去全球专利库里把这家企业在这个方向上的申请找全，自动识别同方向的竞争对手，再输出一份**每条判断都能追到公开号**的报告。

专利申请比产品发布早一到两年——对手两年前的申请，往往就是明年的产品。这是专利情报真正的价值所在，而它需要有人把行业语境喂进去才能被读出来。

## 能做什么

给一家目标企业和一个技术方向，异步生成**企业技术专利竞争分析报告**：

- **竞争格局** — 谁是主要玩家、各自占什么位置、技术路线趋同还是分化
- **对手动作** — 近期申请集中在哪、和公开产品路线是否对得上、有没有卡位意图
- **我方位置** — 空档在哪、哪些方向已经拥挤、绕不开的核心专利是哪几件
- **可交付文档** — 直接导出 Word，拿去开会

数据来自 PatentMax 专利库，并可把**论文、网页、新闻、标准、诉讼**一并计入分析来源——做前沿判断时论文比专利早，做应诉准备时诉讼信息不能少。

可选指定目标市场、时间范围、信息来源、排除方向。

## 两项必填

**目标企业（`--company`）写专利上登记的全称**，例如「宁德时代新能源科技股份有限公司」。简称系统会尝试回溯，但不保证；「企业A」这类占位名一定找不到。

**技术方向（`--subject`）只写技术名称**，例如「钠离子电池」。不要写成「宁德时代在钠离子电池方向的专利布局」——企业名混进方向会让检索跑偏。

其余参数（分析目标、市场、时间范围、来源、背景素材）都可不填。详见 `references/materials-guide.md`。

## 它不做什么

**不出保证性结论。** 不写「该企业在此方向无专利布局」「不存在专利风险」。正确表述是「截至某日期、在所列范围内未检索到……，本结果不排除未公开申请、名称未归一化的关联主体、数据库缺口造成的漏检」。

**18 个月公开窗口。** 专利从申请到公开有约一年半，对手最新的动作大概率不在数据里，这一点每次都要讲明白。

**集团只按所填主体分析。** 同一主体的不同写法会合并，但不会把整个集团的子公司都并进来——关心哪条业务线，就填那家子公司的全称。

**不替代法律意见。** 侵权、无效、许可的判断以各国专利局官方登记簿和代理人意见为准。

**不给布局建议。** 这个 Skill 讲现状——格局是什么、对手在哪。「我们下一步该往哪走」是技术路线分析要回答的问题。
