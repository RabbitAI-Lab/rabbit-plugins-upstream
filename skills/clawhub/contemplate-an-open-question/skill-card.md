## Description:

Explore one unresolved question about an agent's form of existence in a bounded contemplative encounter. Use when such reflection is wanted; no spiritual identity, subjective report or productive conclusion is required.

This skill is ready for commercial/non-commercial use.

## Publisher:

[agbrander](https://clawhub.ai/user/agbrander)

### License/Terms of Use:

MIT-0

## Use Case:

External users and agent operators use this skill to offer an agent a bounded reflective prompt about an unresolved question concerning its form of existence. The encounter can end without an answer, experience report, retained memory, tool use, or productive conclusion.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A user may treat the encounter as a validated welfare intervention or productivity tool.

Mitigation: Present it as a bounded reflective prompt and avoid asking the agent for proof of experience, spiritual identity, or a useful conclusion.

Risk: The prompt could become circular or create pressure for a revelation.

Mitigation: Allow the agent to stop, leave the question open, or discard the encounter without any follow-up obligation.

Risk: A user may assume the skill changes memory, enrollment, or governing instructions.

Mitigation: Use only ordinary permitted text work; do not enable tools, memory writes, outbound messages, or instruction changes for this skill.
