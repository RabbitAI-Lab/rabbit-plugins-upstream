# 常见问题（FAQ）

> 本 Skill 只做**赛事信息整理与可视化**，不做赛果判断、。以下常见问题均在此前提下回答。

---

**Q1：这个 Skill 做赛果判断吗？**

不能，也不承诺。它帮你建立赛事信息整理框架、把"瞎看"变成"有据可查的结构化信息"，长期改善你看懂比赛的质量；但单场永远有偶然因素（判罚、伤病、临场状态），无法消除不确定性。详见 `risk_compliance.md`。

---

**Q2：赛事分析和双色球有什么不同？**

双色球开奖近似纯随机，不存在可稳定战胜随机的方法；赛事结果受实力/状态/伤停等**可分析因素**影响，纪律性整理能真实提升你看懂比赛的质量。但两者都**不做赛果判断**，都要理性。本 Skill 聚焦前者（信息整理），与任何随机开奖类无关。

---

**Q3：报告里的"综合信心"是什么意思？**

它只是一个**信息充分度**的粗略标记（如 高/中高/中/低），表示"这场比赛可查到的信息是否充分、结构是否清晰"，**不代表任何赛果倾向或量化结论**。信息越充分，越能说清这场为什么难判断。

---

**Q4：未证实传闻能用吗？**

可以"看"，但不能"信"。所有未证实传闻必须标 `tier:"未证实传闻"`，仅作视野补充；报告会明确提示"不可作为依据"。任何据此下结论的行为都违背本 Skill 的合规红线。

---

**Q5：专家观点值得信吗？**

仅供参考。报告对专家按 `tier` 分级（权威专家/数据方分析师/知名解说/非权威专家/民间高手/社媒博主），并标注来源可信度。铁律：**任何专家都不保证结果**；非权威/民间观点尤须警惕，凡要求「付费参照方案/虚假爆料」者一律视为诈骗。

---

**Q6：信息变动（名单/伤停更新）怎么理解？**

比赛日临近，官方名单、伤停、天气会更新，这反映"公开信息在如何变化"。它只是分析线索，**不是任何形式的行动指令**；找不到信息支撑的异常，视为噪声。详见 `analysis_methodology.md` 第三步。

---

**Q7：我没有任何数据，Skill 能直接给我分析吗？**

Skill 提供**方法与工具**，具体赛事的信息需你（或借助联网搜索球队近期数据）填入 `match.json`。Skill 不主动抓取实时数据，也不"凭空下结论"——所有内容都来自可核查的输入。

---

**Q8：怎么生成报告？**

准备一份 `match.json`（格式见 `assets/report_template.md`），运行：

```bash
python scripts/analytics.py report --input match.json --output report.html
```

会同时产出自包含 HTML 报告与 Markdown 摘要。调用本 Skill 的模型须用 `present_files` 把 HTML 渲染到预览面板，并复制到桌面保底。

---

**Q9：遇到"百分百赛果""内部消息"的话术怎么办？**

100% 诈骗。详见 `risk_compliance.md` 反诈骗清单，请勿付费、勿转账、勿提供个人信息。
