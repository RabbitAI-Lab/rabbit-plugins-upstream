# 合规红线与反诈骗清单

> 本 Skill 的定位是**合法赛事的信息整理与观赛辅助**。本章是硬性红线，发布前、上架后都必须遵守。核心：不做赛果判断、不承诺结论、、不参与任何资金往来。

---

## 一、绝对红线（触碰即违规）

1. 不做赛果判断，不声称"做赛果判断"。
2. 不提供任何赛果判断或结论建议。
3. 不出现任何敏感术语。
4. 不参与任何资金往来：不代投、不代购、不走单、不上下分、不代收代付。
5. 仅适用于**合法体育赛事**；理性观赛、量力而行、未成年人禁止。

---

## 二、反诈骗清单（遇到一律拒绝）

以下话术 100% 是诈骗，本 Skill 一律识别并打假：

- "AI 宣称百分百赛果""历史赛果率 90%+"
- "内部消息 / 不实方案 / 虚假承诺"
- "付费参照方案 / 收费观点 / 会员带单"
- "无依据爆料 / 保证结果"
- 凡要求转账、提供个人信息、下载不明 App 的"客服"

> 任何"保证结果 / 无依据消息 / 收费观点"都属于诈骗话术，本工具主动提示并拒绝。

---

## 三、信息分级纪律

- 🟢 **官方**：俱乐部官网/社媒赛前名单、国家队公告、体育赛事官方数据。
- 🟡 **权威媒体**：主流体育媒体、数据平台。
- 🔴 **未证实传闻**：社媒爆料、论坛、自媒体"无依据消息"。**必须标 `tier:"未证实传闻"`，仅作视野补充，绝不可作为依据。**

---

## 四、为什么强调"信息整理"而非"赛果判断"

- 体育比赛存在大量不可建模的偶然因素（判罚、伤病、临场状态、天气突变），任何分析都无法消除不确定性。
- 本工具的价值在于**提升你"看懂比赛"的信息质量**：把阵型、球员、状态、情报、专家观点结构化、可视化、可核查。
- 把"看结构 / 看变量 / 看不确定性"当成习惯，长期改善你看懂比赛的能力——这比任何"秘籍"都可靠。

---

## 五、合规自检命令

```bash
# 一键自查（综合）：头像 + 信息完整性 + 新鲜度 + 专家去重
python scripts/audit.py <json>
python scripts/audit.py <json> --strict
```

内置 `references/risk_compliance.md` 与 `audit.py` 红线扫描，上架前后均可一键复检合规性。

> 发布口径：只讲真话、只做合法赛事的数据可视化与观赛辅助，绝不承诺赛果、绝不指导任何结论性判断。
