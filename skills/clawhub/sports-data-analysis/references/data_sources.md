# 数据源与分级采集规范

> 本 Skill 的核心关注点是"赛事信息整理 + 比赛看懂"。要做到又专业又准，必须把一切**可量化、可核查**的信息结构化采集进来，再按 `tier` 分级呈现。本章规定"采什么、去哪采、怎么分真伪"。

---

## 一、采集维度与检索词

给定一场比赛，用 `analytics.py gather` 生成结构化检索清单，逐项联网采集：

| 维度 | 检索示例 | 用途 |
| --- | --- | --- |
| 开赛时间 / 时差 | `【赛事】开赛时间 当地时间 北京时间 时差` | 双显（时差比赛必填） |
| 基本面 / 积分排名 | `【联赛 赛事】积分榜 排名 近期战绩` | 竞技实力基线 |
| 主客场表现 | `【主队】主场战绩 / 【客队】客场战绩` | 主场优势量化 |
| 近 5 场状态 | `【主队 客队】近5场 战绩` | 状态输入（W/L/D） |
| 交锋历史 | `【主队 vs 客队】历史交锋 近5次` | 交锋输入 |
| 伤停 / 停赛 | `【主队 客队】伤停 停赛 出战成疑 赛前名单` | 伤停输入 |
| 战意 / 赛程 | `【主队 客队】战意 赛程密集 轮换 杯赛` | 战意输入 |
| 天气（比赛日） | `城市 天气 比赛日 温度 湿度 降水 风速` | 天气输入 |
| 赛前情报 / 传闻 | `【主队 客队】赛前消息 发布会 阵容前瞻 小道消息` | 情报分级（未证实需标注） |

---

## 二、信息分级（tier）

- 🟢 **官方**：俱乐部官网/社媒的赛前名单、国家队公告、体育赛事官方数据。
- 🟡 **权威媒体**：主流体育媒体、数据平台发布的内容。
- 🔴 **未证实传闻**：社媒爆料、论坛、自媒体"无依据消息"。**必须标 `tier:"未证实传闻"`，仅作视野补充，绝不可进入分析结论。**

---

## 三、典型采集脚本

- **伤停 / 状态**：检索"队名 伤停 停赛 出战成疑 赛前名单"。官方赛前发布会给出的主力伤缺/复出/阵容，直接填入 `players[]` 与 `key_players[]`。
- **天气**：检索"城市 比赛日 天气"，记录温度/湿度/风力/降水；对特定打法的偏向写入 `weather.impact`。
- **情报**：检索"队名 赛前消息 发布会 阵容前瞻"，按 `tier` 录入 `intel[]`。

---

## 四、专业度反思：怎么把整理做得"又专业又准"

1. **全采集**：把影响比赛的信息（天气、伤停、状态、交锋、情报）尽量全采集、全结构化。
2. **全分级**：每条信息标注来源与分级；未证实传闻仅作视野补充。
3. **可核查**：结论必须来自可核查的输入；不把"某大 V 说"当依据。
4. **诚实标注不确定性**：信息越充分，越能说清"这场为什么难判断"。

> 一句话：专业 = 把影响比赛的信息**全采集、全结构化、全可核查**；准确 = 用透明结构把这些信息转化为**可讨论的信息要点**，而不是假装能预言结果。

---

## 五、推荐合规数据源

- **官方赛事数据网**：官方赛事、规则说明，以官网当日为准；仅作合法赛事边界参考。
- **公开天气 API**：比赛日天气（温度/湿度/风/降水）。
- **主流体育媒体 / 数据平台**：积分榜、近期战绩、伤停汇总（须标注来源与分级）。
- **俱乐部官方社媒**：赛前名单、发布会要点。

> **核查纪律**：每个进入报告的信息都标注来源与分级；未证实传闻仅作视野补充，绝不驱动结论。数据只是原料，**结论必须建立在可核查的信息与透明结构之上**。

## 六、足球专项公开数据源（联网核实，信息整理用途）

> 下列为 2026 年仍可公开访问的足球数据源，均用于「赛程 / 对阵 / 时间 / 进阶统计」的整理，不含任何敏感衍生字段。各源授权与更新状态会变化，请以官网当日说明为准；凡标 ⚠️ 者为需要留意的口径变化。

| 数据源 | 覆盖 | 获取方式 | 适合采集 | 2026 状态备注 |
| --- | --- | --- | --- | --- |
| TheSportsDB | 全球多球类赛程 / 对阵 / 时间 | 免费测试 key=3（约 3 场/日轮换样本）；Patreon 全量 | 当日真实对阵（本 Skill 已接入） | 稳定可用 |
| StatsBomb Open Data | 公开赛事事件级数据（GitHub 仓库） | 免费开源（非商业 + 署名） | 事件级战术复盘、机会质量模型 | 仍是最佳免费事件数据源；注意非商业授权、不得转售原始数据 |
| Understat | 各联赛机会质量(xG)模型数据 | 网页公开查询 | 机会质量长期趋势 | 自 2014 运行，覆盖约 6 个联赛 + 俄超 |
| FBref | 100+ 联赛球员 / 球队历史统计 | 网页公开查询（需遵循抓取限速） | 历史统计、球员档案背景 | ⚠️ **2026 年 1 月起失去 Opta 授权**，进阶统计不再实时更新；仅作历史/背景参考，勿据其做实时判断 |
| Sofascore / WhoScored / FotMob | 全球多联赛单场评分、热点图、实时统计 | 网页公开查询（需抓取） | 宽覆盖单场统计、球员评分 | 覆盖大量免费源未含赛事，适合补全 |
| FootyStats.org | 联赛统计、趋势、历史数据 | 网页公开查询 | 联赛级趋势与历史 | 适合长期趋势观察 |
| Transfermarkt | 球员身价 / 转会 / 阵容 / 伤停 | 网页公开查询 | 阵容变动、身价基线、伤停线索 | 非表现数据，但伤停/阵容背景必备 |
| Opta Analyst | 行业基准事件数据方发布的文章与进阶指标 | 网页公开 | 战术文章、指标科普 | 权威数据方的公开输出 |
| football-data.co.uk | 历史赛果 CSV 档案（深度数十年） | 公开 CSV（curl 即得） | 赛程 / 赛果历史背景 | ⚠️ 该站含衍生字段列；本 Skill **不使用任何衍生字段**，仅取赛程/赛果背景 |
| mplsoccer | Python 足球可视化库 | 开源（配合 StatsBomb） | 自绘球场 / 射门 / 传球 / 热力图 | 把数据转成专业图最快路径 |
| IMPECT（Packing）/ SkillCorner | 穿透数据 / 转播追踪数据 | 授权订阅（行业下层） | 推进效率、跑动速度 | 行业进阶源，多数经俱乐部/机构获得 |

> 采集纪律：进阶数据（机会质量等）仅作为「机会质量」的描述性参考，应用于信息整理与可视化；它衡量的是长期机会质量，不指向单场赛果。所有外部数据须标注来源与时间。FBref 自 2026-01 失去 Opta 授权后，其"实时进阶统计"已不可靠，做实时判断请改用 StatsBomb / Understat / Opta Analyst 等仍更新的源。
