This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to choose a development method suited to a coding task and carry it through implementation and review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Strict method checkpoints and confirmations may slow development.

Mitigation: Use this skill when the project benefits from a structured method and agree on scope before execution.

Risk: English-only and secret-handling guidance may conflict with project standards.

Mitigation: Review the selected method's guidance against team language and security policies.

Risk: Code editing and shell commands can change workspace files.

Mitigation: Keep normal workspace safeguards and review changes and commands before applying them.
