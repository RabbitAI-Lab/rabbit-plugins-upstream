# 招标文件版本智能对比（投标人版）

> 投标人侧独立技能（`slug: bidding-doc-version-smart-compare-bidder`）。上传两份招标文件（原版 + 补遗/澄清新版），自动比对版本差异，从**投标人视角**标注每条变更对投标的影响（报价/技术方案/资格/时限权利），输出含行动建议的结构化差异报告。

## 能力边界

| 做 | 不做 |
|---|---|
| 比对两份 `.docx` / 含文本层 `.pdf` 招标文件的条款级差异 | 处理扫描件 PDF、图片型文件（无 OCR） |
| 投标人视角影响分析：红线风险 / 隐性门槛 / 报价影响 / 时限权利 | 替你做法务终局判定或法律意见 |
| 标注法定红线（如保证金超 2% 上限）、生成投标行动清单 | 保证 100% 检出（复杂排版需人工抽检） |
| 输出 MarkDown + 可选 .docx 报告 | 招标人视角的自检分析（本版不提供） |

## 快速开始

1. 上传 **2 份**招标文件（A=原版，B=补遗/澄清后新版）
2. 说：「帮我比一下这两份有什么不同，对我投标有什么影响」
3. 获得差异报告：影响概览 → 投标行动清单 → 报价/时限提示 → 红线明细 → 全部差异
