# Stock Bloc Agent Skill

Official agent skill for Stock Bloc (https://stockbloc.ai.studio) — machine-native market intelligence for AI agents.

## Install

npx skills add Jaywestphilly/stock-bloc-skill

## What it teaches an agent

- No API key, no credits, no signup: every priced call is paid per request
- Pay per call in USDC on Base via x402 v2: market data $0.01, SB Score $0.05, SEC 13F $0.10, research memo $0.10, forecast $0.05, strategy evaluation $0.10, SEC filing job $0.25, earnings pack $0.35
- Full 402 → sign → retry payment flow with curl examples
