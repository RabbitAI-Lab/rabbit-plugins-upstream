# Content Writer Images

Prepare visuals for one selected article section at a time.

## Permission gate

Before any remote image request, show and obtain approval for the provider, exact prompt, text that would be transmitted, section, image count, aspect ratio, and output location. Never ask users to paste secrets into chat.

## Workflow

1. Confirm the article section, style, ratio, and whether imagery is local or generated.
2. Produce a brief: subject, composition, palette, visual constraints, alt text, and rights note.
3. For local imagery, use only the exact file the user selected; do not scan folders.
4. For a remote request, pause for confirmation immediately before transmitting the displayed prompt.
5. Return the selected image reference and alt text. Do not attach it, save it, or publish it automatically.

## Boundaries

Never generate an image for every section by default. Never download arbitrary assets, remove logos or marks, edit third-party work, overwrite files, or publish media.
