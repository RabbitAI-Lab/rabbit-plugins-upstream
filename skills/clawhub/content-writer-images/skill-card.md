## Description:

Create a visual brief or coordinate one user-approved image request for a specific article section.

This skill is ready for commercial/non-commercial use.

## Publisher:

[minibeanai](https://clawhub.ai/user/minibeanai)

### License/Terms of Use:

MIT-0

## Use Case:

Writers and content teams use this skill to plan a visual for a selected article section, or to coordinate a single image request when explicitly asked for visuals.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A remote image request may send the approved prompt and related section text to the provider.

Mitigation: Show the provider and exact text to be sent, then obtain the user's confirmation immediately before the request.
