# 场景与剧情 CG 工作流

将此工作流用于 AVG 背景、地点变体和剧情 CG。

## 资产分类

生成到 `art_output/scene_regeneration/`，审核完成前保留正式源文件。

- **AVG 背景：** 保持地点、镜头高度、透视、地平线、可行走区域和前景区域、地标与立绘安全区域。
- **时间和天气变体：** 在白天、黄昏、夜晚、下雨等变体间保持相同镜头和几何关系；只改变预期的光照和氛围。
- **剧情 CG：** 保持角色数量、身份、服装、发型、姿势、表情、道具、构图和情绪语境。

记录源文件尺寸、宽高比、画面取景、地平线和消失线、前景立绘安全区域、光照和天气状态以及固定地标。将同一地点的变体归为一组。

## 风格与生成

使用前查询风格库并验证风格类型。背景优先使用 `scene` 风格，立绘优先使用 `character` 风格。不得假设仅适用于角色的风格能保持建筑透视。

将原始场景作为第一张参考图。提示词中包含地点、镜头、透视、时间和天气、地标约束及立绘安全区域。除非源文件刻意包含这些元素，否则要求背景没有角色和文字。

```bash
seagames-cli image generate \
  --model microsoft_gpt_image_2 \
  --style-item-id SCENE_STYLE_ID \
  --reference-file ./assets/backgrounds/campus_gate_day.png \
  --prompt "以所选场景风格重新绘制这张视觉小说校园大门背景。保持精确的镜头取景、透视、建筑、地平线、道路几何关系、立绘安全区域、白天光照和地标位置。不要角色、文字、界面、裁剪或新建筑。" \
  --output ./art_output/scene_regeneration/campus_gate_day.png
```

不得为了适配模型输出而过度裁剪或重新取景背景。需要时在暂存目录恢复原始画布尺寸和宽高比。

## 验证

1. 确认是真实 PNG 且宽高与原始文件一致；保留有意设计的 RGB 或 RGBA 行为。
2. 比较地平线、消失线、地标位置、主要轮廓和立绘安全区域。
3. 并排比较同一地点的全部变体，拒绝几何关系漂移的结果。
4. 在代表性精灵图后方预览，并在目标引擎中验证对话文字、立绘、叠加层和镜头切换。
5. 对 CG，将角色身份、服装、发型、姿势、道具、构图和情绪节拍与源文件比较。
6. 将原始文件保留在备份中，仅将已接受的暂存输出复制到正式资源路径。
