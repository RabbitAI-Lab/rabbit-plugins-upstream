# 游戏 UI 资产工作流

将此工作流用于图标、按钮、面板、边框、滑块、遮罩和其他功能性游戏 UI 美术资产。

## 提示词前分类

生成到 `art_output/ui_regeneration/`；审核通过前不得将输出路径指向正式资源。

- 每个功能动作生成一个独立图标。保持图标居中、无文字且易于识别。
- 将普通、悬停、选中、锁定和禁用状态保留为不同资产。
- 对九宫格面板，保持角部和边缘几何关系。要求生成单个切片，不要微缩页面。
- 保持九宫格拉伸中心没有特征：不要标题、分隔线、按钮、滑块、图标、光带、图案或文字。
- 对遮罩、边框、线条和滑块保留 Alpha 轮廓和尺寸。
- 以正式 UI 布局作为几何权威。检查画布尺寸、拉伸边距、锚点、偏移和全部使用方。

修改共享资产前搜索场景和脚本参考资料。一个面板可能在多个运行时尺寸中使用；验证每个使用方。

## 对比度与生成

要求页面背景、面板中心、面板边框、次级控件、运行时文字、选中状态和主要动作之间具有清晰层级。不得将 UI 文字生成到图片中；文字标签应由引擎控件承载。

将原始资产作为第一张参考图，并在提示词中说明动作和布局约束。小型资产应在暂存目录中以较大尺寸生成，审核后再缩小。

```bash
seagames-cli image generate \
  --model microsoft_gpt_image_2 \
  --size 1024x1024 \
  --reference-file ./resources/ui/save_icon.png \
  --prompt "仅以已批准的 UI 风格重新绘制这个居中的保存图标；保持其动作语义、轮廓、缩放和 Alpha，不要文字或按钮背景。" \
  --output ./art_output/ui_regeneration/save_icon_generated.png
```

不得假设 `.png` 文件名就代表 PNG 数据。检查实际格式、尺寸和 Alpha。仅当原始 Alpha 蒙版不会裁切已变化轮廓时才保留它。不得对九宫格资源使用这种合成捷径。

## 验证

1. 确认是真实 RGBA PNG，且画布尺寸与原始文件一致。
2. 分别比较可见内容边界和画布边界。
3. 在浅色和深色背景上预览透明资产。
4. 在运行时拉伸尺寸下测试面板和九宫格资源。
5. 在实际布局坐标检查图标、标签、点击区域、对比度、留白和本地化。
6. 拒绝烘焙的棋盘格或画布、低对比度文字安全区域、不兼容的视觉语言，以及拉伸中心有细节的九宫格资源。
7. 暂存候选图被接受并明确批准前，保持正式资源不变。
