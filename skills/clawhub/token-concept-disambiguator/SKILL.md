# S1 · 通证/代币化概念辨析器

## R — 原文 (Reading)

> 通证化（广义/产业向）是把实体资源、产品、资产、服务或权益转化为数字通证，核心是价值数字化；代币化（狭义/金融向）是把资产及其收益映射为具有货币属性代币，核心是资产货币化。RWT 为关联现实世界的总入口，RWAT 锚定具体资产，RDA 仅绑定实体运营数据而非资产本身。
>
> — 《价值互联网产业应用蓝皮书（2025 年）》编写组，第一章（三）主要概念


上引 R 段引述自《价值互联网产业应用蓝皮书（2025）》（蓝皮书编写组），此处为原著要义引述并已署名；本 skill 的改写与编排以 Apache-2.0 授权发布。

## I — 方法论骨架 (Interpretation)

这套辨析器解决的是一个最常见的语言混乱：普通人一听到"上链""发币""RWA"，就把三层完全不同的东西当成一回事。

第一层是**通证化**（广义、产业向）：把资源/权利变成链上凭证，目的是"价值数字化、可计量可分配"，不带货币属性。第二层是**代币化**（狭义、金融向）：把资产收益映射成有货币属性、能 7×24 高流动、可接 DeFi 的代币，本质是"资产货币化"。这两层法律边界和监管口径完全不同，绝不能混用。

RWA 家族再细分：**RWT** 是个大筐（所有连现实世界的通证都算）；**RWAT** 是筐里锚定具体实物/无形资产的那部分（资产的数字分身）；**RDA** 最特殊，它不锚资产，只绑运营数据。把"RWA"笼统叫，会直接错配监管口径。

辨析器靠两个子工具落地：f11 看"一个通证是否同时具备记账+权利+结算三功能、落入五分类（记账/治理/商品/债权/股权）中哪类"——只有债权/股权类才进入金融监管；f10 把"资源要素 × 可锚定权利"映射成"该发哪类链上产品 + 对应哪种监管镜像"。二者合起来，就能把一句模糊的"我们做了通证"拆成"社区治理类"还是"金融监管类"。

一句话：它的活儿是把任何 Web3/RWA 说法**放到正确的层上，并标红是否越过了金融属性这条线**。

## A1 — 书中的应用 (Past Application)

### 案例 1：中网充充电桩运营数据如何变现（不被判为"发币"）
- **问题**：充电桩 BOT 模式资金回收慢，运营数据想变成可定价资产，常被质疑"是不是在发币融资"。
- **方法论的使用**：用 rwa01 分层 + f10 矩阵定位——资源=实时运营数据，权利=消费/数据/生态/收益四重权益 → 映射为 **RDA**（实数融合、绑定运营数据），而非 RWAT（锚定实体资产）也非代币化；按 f11 仅具记账+权益功能，属商品/治理类。
- **结论**：属境内可探索的"非金融数字化赋能"RDA，不触碰金融属性。
- **结果**：2025 年 4 月在上海数据交易所挂牌，发行"中网充·青能权益徽章"，形成合规闭环。

### 案例 2：红糖链品如何让农产品既上链又不踩代币融资
- **问题**：广西隆安非标蔗田想上链确权、提前回笼资金，但怕被判定为代币融资。
- **方法论的使用**：rwa01 + f10 拆解——资源=348 个非标蔗田单元（实物），权利=特定地块甘蔗所有权 → 映射为**实物锚定数字资产**（RWT 非资产融资类）；f11 认定功能仅记账+权益（前两类），规避债权/股权金融属性。
- **结论**：属境内"实物锚定数字资产"通证化，不是 RWAT 代币化。
- **结果**：形成可复制产业标准，种植户提前回笼资金、终端收益占比提升。

### 案例 3：华润隆地/朗新充电桩收益权融资该放哪层
- **问题**：绿色基建收益权想融资，说法常被写成"做了 RWA"。
- **方法论的使用**：rwa01 定位 → 收益权代币化（RWAT Tokenization）属**金融向**，境内严禁；故走 f15 双层——境内联盟链做 A–G（非金融标识/一级发行），境外香港沙盒做 H–J（代币化流通）。
- **结论**：该说法落入"代币化"层，必须置于境外合规区，境内只做前半段。
- **结果**：华润隆地入选香港金管局 Ensemble 沙盒，朗新/协鑫于香港监管沙盒发行，为境内资产境外合规提供范式。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **内容创作/科普**：写稿或做营销时把"我们做了通证化"当"我们发了币"来宣传，需先分层以免误导读者并引发监管联想（见 ce16）。
2. **创业立项**：拿到"上链"需求，分不清该走通证化（产业提效）还是代币化（融资），需先判定路径再动手。
3. **读者/投资人尽调**：看到"RWA 项目"宣传，需判断是 RWT/RWAT/RDA 哪一类、是否触碰金融属性。
4. **社区运营用语**：把"积分"对外叫"通证"，需按 f11 确认是否具备三功能、属五分类哪类。
5. **跨境方案对标**：想把香港/美国案例直接套境内，需识别美式 RWA 普惠叙事对中式"非金融"路径的遮蔽（见 ce17）。

### 语言信号 (用户的话里出现这些就应激活)

- "我们上了链 / 发了币 / 做了 RWA"
- "通证化是不是就是代币化？"
- "这个积分能不能叫通证？"
- "RWA 在国内能做吗？"
- "香港那个案例我们能照搬吗？"

### 与相邻 skill 的区分

- 与 **S2 · 合规边界红线检查** 的区别：S1 只做"概念属于哪一层"的分类判断，不输出合规结论；一旦 S1 判定为代币化/金融属性=Y，是否违规、如何合规由 S2 接管。
- 与 **S4 · W-ABCD 真假 Web3 识别器** 的区别：S4 判断"是不是真·Web3 产业应用"（组织范式维度）；S1 判断"用的概念术语属于哪一层、有无金融属性"。一个项目可过 S4（真 Web3）却用了错的概念层（需 S1 纠正）。
- 与 **S8 · RWA 落地流程与路径设计器** 的区别：S8 是端到端作业手册；S1 在动手前先定性，是 S8 的前置分类步骤。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **抓取并复述核心说法**
   - 完成标准：从用户的话里列出其实际指涉的"动作（上链/发币/通证化…）+ 对象（数据/资产/收益权…）"，并能用自己的话复述对方想表达什么。

2. **用 rwa01 分层表定位层级**
   - 完成标准：每个术语被标注到 {通证化 | 代币化 | RWT | RWAT | RDA} 之一，并注明"金融属性 = Y / N"。
   - 判停条件：若判定为**代币化**或**金融属性 = Y**，则输出一句"该说法已进入金融向，请转 S2 合规边界红线检查"，不再在本 skill 内给任何落地/发行建议，直接结束。

3. **用 f11 + f10 复核金融属性**
   - 完成标准：回答两个问题——(a) 该通证是否同时具记账+权利+结算三功能？属五分类（记账/治理/商品/债权/股权）中哪类？(b) 按 f10 资源×权利矩阵，映射出哪种链上产品与哪种监管镜像？最终给出"社区治理类（前两类）/ 金融监管类（后三类）"判定及一句使用建议。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户已经确定是"某操作是否违规"的纯合规问题 → 直接转 **S2 合规红线**。
- 用户要识别"一个项目是不是真·Web3 产业应用" → 转 **S4 W-ABCD**。
- 用户只是查术语定义、不需要分层判断 → 直接给术语表（glossary），不必走完整辨析流程。
- 用户已进入 RWA 落地排期 → 转 **S8 路径设计器**。

### 作者在书中警告的失败模式

- **ce01 概念窄化与污名化**：社会主流把 Web3/RWT 等同于 RWAT 代币融资、甚至类比 P2P/虚拟货币炒作，导致要么拒斥合法产业应用、要么盲目乐观踩坑。辨析器正是为破除这一混淆而生。
- **ce16 "通证"译名金融联想**：Token 译作"通证/代币"语义过宽，宣传中混用"通证/代币"会直接引发监管联想；须以功能（记账/治理/商品/债权/股权）清晰界定。
- **ce17 美式叙事遮蔽中式路径**：用美国/香港"资产代币化"模板套境内场景，忽视"非金融"合规导向，误判可行性与边界。
- **ce10 / ce12 红线警示**：空气币（无场景、拉人头）、虚假资产投机炒作均属非法金融活动，我国金融管理部门未批准任何 RWA 代币化。

### 作者的盲点 / 时代局限

- 编写组含道衍数科（商学苑/项目方）及多家 RWA 产业链服务商，**天然带"推广 Web3 产业应用"立场**，对概念边界偏乐观、对失败案例披露可能选择性弱化。
- 成稿于 2025 年，稳定币/代币化全球合法化与香港沙盒规则仍在快速演化，部分"前沿实践"可能已被新规覆盖，做境内判断时以最新监管口径为准。

### 容易混淆的邻近方法论

- **通证化 ≠ 代币化**：前者价值数字化（产业向），后者资产货币化（金融向），监管口径天差地别。
- **RWT ≠ RWAT ≠ RDA**：总入口 / 锚定具体资产 / 仅绑运营数据，三者层级与合规路径不同，不可笼统叫"RWA"。


### 合规红线与使用须知（普通用户必读）

本技能提炼自《价值互联网产业应用蓝皮书（2025）》（蓝皮书编写组，主编：梁超杰）第三篇·第五章「合规边界」，仅供风险识别与科普参考，**不构成任何投资建议、法律意见或投资邀约**。

- 中国境内开展价值互联网与通证经济产业应用，**不得涉及通证代币化等加密金融行为**，应聚焦"非金融"的数字化赋能（溯源、贡献计量、RDA 真实数据资产等）。
- 包括稳定币在内的虚拟货币，**在中国境内发行与交易属于非法金融活动**（央行等十部门 2021 年《关于进一步防范和处置虚拟货币交易炒作风险的通知》）。境外交易所、项目向中国境内居民提供服务同样属非法。
- **连带责任无死角**：不仅直接参与违法，为境外违规项目提供账户、资金划转、技术支持也依法追责——"只是帮忙做技术"不能免责。
- 任何以"Web3/区块链"为名、要求充值、拉人头返利、承诺升值预期的，极可能是资金盘，**请勿参与、勿投资、勿转发**。

> 引用原文："不能涉及通证代币化等加密金融行为，而应聚焦探索'非金融'的数字化赋能产业提效方向。""包括稳定币在内的虚拟货币无法满足 KYC、AML 等要求，在中国境内发行与交易虚拟货币属于非法金融活动。" —— 第三编·第五章（合规边界）／ p02、ce03
