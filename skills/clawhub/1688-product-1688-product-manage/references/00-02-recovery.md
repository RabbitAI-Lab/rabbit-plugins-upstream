# 失败、补充与续跑

先读取当前商品的说明、台账及相关回执，找到最后一个有证据的状态。缺资料与工具故障分别处理，不让用户重复提供已经保存的内容。

## 失败时怎样说、怎样继续

| 情况 | 恢复动作 |
|---|---|
| 看不到用户声称已传的图 | 说明目前能收到哪些图、缺哪张，请带短文字重传。没有宿主回执时不诊断为“超时”；未进入会话的消息无法由 Skill 主动处理 |
| 路径受限、URL 失效、格式不支持 | 指出具体编号/路径和实际错误；保留其余素材。能从已可读来源复制到工作区则复制；否则请上传或给有效地址，不扫描无关目录找替代品 |
| 文档只读部分、依赖不可用 | 按文档 reference 做一次合适的替代提取；仍缺则列解析范围与需要的内容，不把缺依赖说成无文字层 |
| 文搜成功但无类目候选 | 记录 `CATEGORY_EMPTY` 并终止当前商品；按 [类目](02-01-category.md) 说明原因，禁止自动换关键词、店铺、类目、scene、参考商品或其他途径绕过，不再入库、生产、保存 |
| 图搜成功但无候选 | 根据清晰商品信息转文搜，信息不足则请用户补名称/用途；文搜空结果仍须中断 |
| `INDUSTRY_CATEGORY_NOT_SUPPORTED` | 外层或解析后的 dataJson 出现均记录该终止码；说明工业品暂不支持 Accio 发品、可前往 PC 端自由发品，能力开发中；与成功空候选执行同一禁止绕过和禁止后续调用规则 |
| 类目查询报错或 schema 不支持 | 区分工具故障和表达限制，按真实回执说明；可继续整理资料但不能用猜测 ID/规格绕过。工具故障不要求用户反复换关键词 |
| SKU 信息不足或冲突 | 价格库存可空，不因缺失追问；必填维度/值缺失按 [SKU](02-02-sku.md) 最多三轮针对性澄清或按用户授权推定。非必填值有歧义可请用户确认或留空；商品归属冲突只问范围 |
| 401 / 明确未授权 | 请用户检查连接器授权；保留本地包。不索要或处理 Token |
| 插件/MCP 初始化失败 | 说明连接暂不可用；不要说商品不存在、用户无权限或功能在开发，除非回执明确支持该原因 |
| 429 / 短暂网络错误 | 遵守工具返回的重试间隔；未明确有副作用的只读请求最多额外重试两次，仍失败保留状态 |
| 某图入库失败 | 只恢复该图，已成功映射保留。明确未提交的失败可有限重试；超时后先检查回执，说明可能已有入库副本 |
| 生成已返回任务 ID 后超时 | 保存原始完整请求、原子工具名、店铺及该类型 `taskId`；下次由同一工具查询，不重新提交，不拿其他类型 ID 补缺 |
| 生成提交回执不明、无任务 ID | 标记结果未知。先查宿主历史/可用状态查询；仍不可核实时说明重提可能重复计算，不能自动无穷重提 |
| 草稿保存返回 null 或明确容量已满 | 按 [草稿回执边界](04-00-draft.md) 记录 `DRAFT_CAPACITY_FULL`，提示去 PC 端检查清理；保留素材、请求，不自动重试/删除，不宣称成功；同店铺剩余发布一并暂停 |
| 草稿超时、断网、未收到业务回执或非 null 但缺 draftId | 标记保存结果待核实。查看已有工具记录或请用户核对草稿箱；不自动打开网页检查，未经核实不重复保存；不等同于接口实际返回 null |
| 其他明确业务拒绝 | 按 [草稿报错处理](04-00-draft.md) 读取实际错误码/文案并解释下一步；不把其他通用错误当容量超限 |

业务终止优先于所有恢复指引：类目终止不能自动解除，只有用户明确提出新的商品/类目需求后才开启新尝试并保留原证据；草稿容量满须用户确认已处理并明确要求继续后才恢复。生成和草稿调用不能套用只读请求的自动重试。其他明确未提交/可修复失败仅按对应 reference 的范围恢复；结果未知时优先查询/核对，不以“业务拒绝”概括为可重试。

## 用户补充或改动

先按 [输入归组](01-00-intake.md) 区分新发品需求和明确续接。新需求默认新建，不因与上款相似就复用旧图/旧值。明确补充或修改时定位商品和 SKU；“黑色 L”同时命中多个货号时才消歧，不对唯一指向重复确认。追加 source 记录，更新采用事实和状态，按依赖决定重做范围：

| 改动 | 通常受影响的内容 |
|---|---|
| 换类目 | schema、SKU 维度、所有依赖类目的生成结果和未保存请求 |
| 用户明确换店 | 重新绑定实际授权店铺，重新取得类目/schema、图片银行映射及生成结果；原始资料保留，不跨店复用任务或草稿请求 |
| 改价格/库存 | sku-input、SKU 生产结果、未保存请求；标题/CPV 若实际依赖这些字段也重做 |
| 补图/换图 | 该图分类、选择与图片银行映射；仅使实际使用该图的生产结果和展示内容失效 |
| 改品牌/材质/认证等事实 | 使用该事实的标题、CPV、详情及请求 |
| 只调整图序 | 选择清单、工具请求中的顺序、主展示图/详情；已入库图片可复用 |

比较每项保存的输入依赖与校验值；表格只是决策提示，不替代实际依赖检查。旧回执留作证据，不当成当前结果。运行中的旧任务可保留查询，但其过期结果不能覆盖新输入。

已取得 draftId 的商品不因“继续”“重新传了图”再次保存。用户要改已保存草稿时，交付现有编辑链接并说明当前只提供新草稿保存；用户明确要求另建一份时新建草稿尝试记录，保留已有 ID。

## 批量恢复

店铺草稿容量满是该店铺级阻塞，暂停本批该店铺所有未完成发布，不继续逐品生产和试保存。类目不支持仅终止当前商品，其他已授权且资料齐全的商品可串行执行；不能通过把同一商品改名/换店/换类目伪装为下一件绕过。

执行计划中保留全部已识别商品。默认只推进用户当前选中的商品，完成后询问下一个；用户已授权全部按顺序执行时才连续串行推进。一件在尚未提交远程任务时因缺资料挂起，或远程任务已明确失败，可继续其他已获授权且资料齐全的商品。某次生成仍在运行或提交结果不明时，先保留状态并结束本轮等待，不因为轮询超时就并发启动下一商品；恢复后先处理该未决任务。未选择的商品只保留资料，不自动生成或保存。计划中分别记已保存、待选择、待补充、工具失败、保存待核实；对用户只提示当前结果和必要下一步。只有真实 draftId 才计入保存成功。
