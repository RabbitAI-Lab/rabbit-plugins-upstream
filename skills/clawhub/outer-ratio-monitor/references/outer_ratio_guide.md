# 外内比原理与实战用法详解

> 来源：实盘经验 + A股行为金融学总结

---

## 一、什么是外盘、内盘

**外盘（主动买盘）**：以**卖价**成交的股票数量，即投资者主动按卖一、卖二……价格买入的量。外盘大，说明买盘积极，看涨情绪强。

**内盘（主动卖盘）**：以**买价**成交的股票数量，即投资者主动按买一、买二……价格卖出的量。内盘大，说明卖盘积极，看跌情绪强。

**关键点**：外盘和内盘都是"主动"成交——区别在于谁在主动进攻。

---

## 二、外内比计算公式

```
外内比 = 外盘量 ÷ 内盘量
```

| 外内比值 | 市场含义 | 操作信号 |
|---------|---------|---------|
| > 1.50 | 极强买盘，主力强势拉升 | 跟进买入 |
| 1.25–1.50 | 主力建仓信号明显 | 重点关注买入 |
| 1.00–1.25 | 多方略强，但不够强烈 | 观察等待确认 |
| 0.80–1.00 | 多空僵持，略偏弱 | 观望 |
| 0.50–0.80 | 空方占优，主力在卖出 | 减仓 |
| < 0.50 | 主力出逃，空方主导 | 止损/规避 |

---

## 三、为什么外内比比K线快半步

**主力建仓时**：庄家在底部悄悄吸筹，K线可能还在横盘震荡，但外内比已经开始逐日攀升——因为主力在持续买入，外盘持续大于内盘。

**主力出逃时**：庄家在高位派发，K线可能还在高位横盘，但外内比已经开始下降——因为主力在出货，内盘持续大于外盘。

**结论**：外内比是主力的"提前量"指标，比K线提前反映主力意图。

## 四、五种实战用法

### 用法1：买入时机确认
**场景**：某只股票技术面出现买点，但不确定是否该买入
**方法**：查看外内比，若 >1.25 确认主力在进场 → 买入； 若 <0.80 主力在卖出 → 等待

### 用法2：止损预警
**场景**：持仓股票突然下跌，不确定是洗盘还是真出逃
**方法**：外内比快速从高位跌至 <0.50 → 主力出逃 → 止损
**反面**：外内比仍维持在 0.80 以上 → 可能是洗盘 → 持有

### 用法3：选股过滤
**场景**：从涨停股中筛选真正有主力拉升的
**方法**：外内比 >1.25 + 涨幅 >5% → 主力真拉升； 外内比 <0.80 + 涨幅大 → 主力拉高出货，不追

### 用法4：盘中异动监控
**场景**：盘中需要第一时间知道自选股的异动
**方法**：配置定时扫描（每30分钟），外内比突破阈值时立即推送飞书告警

### 用法5：趋势跟踪
**场景**：持有趋势股，想判断趋势是否结束
**方法**：外内比持续 >1.00 → 趋势延续； 外内比跌破 0.80 → 趋势减弱，考虑减仓

## 五、注意事项与常见陷阱

### 陷阱1：外内比突然放大不一定是好事
外内比从0.30突然变成0.80，可能是主力对倒（左手卖给右手），制造放量假象。需结合量能变化和K线形态判断。

### 陷阱2：外内比需要看趋势，不看单点
单点外内比波动可能受偶然因素影响。应该看连续2-3个交易日的外内比趋势。

### 陷阱3：大盘股vs小盘股
大盘股外内比波动较小（流动性好），小盘股外内比波动较大。大盘股外内比>1.10已算较强信号。

### 陷阱4：外内比在开盘/收盘时段失真
开盘前30分钟和收盘前30分钟，外内比容易受情绪影响，不宜作为判断依据。
