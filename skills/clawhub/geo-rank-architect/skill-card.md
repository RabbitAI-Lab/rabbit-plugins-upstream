## Description: <br>
Geo Rank Architect helps agents optimize content for generative search by adding JSON-LD structured data, FAQ schema, llms.txt-style summaries, and a five-dimension GEO score gate. <br>

This skill is ready for commercial/non-commercial use. <br>

## Known Risks and Mitigations: <br>
Risk: The security verdict is suspicious because the skill describes broad file, API, and command abilities without tight limits. <br>
Mitigation: Review the skill before installation, run it only in an environment where broad command execution is acceptable, and require explicit approval before file access, command execution, or external API use. <br>
Risk: Generated SEO and GEO optimization guidance may be inaccurate, overstate search outcomes, or introduce misleading content. <br>
Mitigation: Human-review optimized content, JSON-LD, FAQ entries, and GEO scores before publishing; treat the skill as an optimization aid rather than a ranking guarantee. <br>
