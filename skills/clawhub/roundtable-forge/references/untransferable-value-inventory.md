# 不可转让价值清单（Untransferable Value Inventory）

> **版本**：v1.0.0（首版）
> **来源**：本清单由 roundtable-forge 实测圆桌《当一切都可以被定价，人还剩什么？》（2026-06-22）的合成结论派生，是 ns-001 next_step 的首版交付。
> **目的**：把"哪些东西不应被 token 化"这一边界从抽象命题落到可操作的清单，为后续协议设计、产品审计、个人决策提供共同语言。

---

## 核心命题

存在一类价值，其 token 化等同于它的毁灭。一旦这类价值被挂牌流通，它们原本的"价值"被自身的"可流通性"摧毁。

这条边界不是基于道德判断，而是基于结构性观察：**价值的某些维度恰恰依赖于不可流通性**。把它们 token 化，不是"为它们打开新渠道"，而是把它们的本质剥离掉。

---

## 清单：五大维度

### 1. 身份类（Identity）

**为什么不可转让**：身份的完整性依赖于"绑定在你这个人身上"。一旦可转让，"你是谁"就被拆分为可重组的部件，身份的连续性消失。

| 子项 | 当前 token 化危险征兆 | 检测信号（高危 = 应立即停止） |
|------|------------------------|------------------------------|
| 履历（学历、职业历史） | 出现"履历 NFT 交易市场"、"履历合成服务" | 可被任意账户购买并挂在自己名下 |
| 声誉（社区评价、专家认证） | 出现"声誉评分对冲基金"、"声誉借贷" | 可被做空/做多、可被金融化为衍生品 |
| 信用分（金融信用、社交信用） | 出现"信用分切割售卖"、"信用 boost 服务" | 可被他人购买以提升自己的信用 |
| 身份认证（数字身份、KYC 数据） | 出现"身份即服务（IaaS）" | 可被借用、可被合成为新身份 |

**协议层对位**：Vitalik 提出的灵魂绑定代币（SBT, Soulbound Token）正是为这一类价值设计的——它定义"绑在灵魂上、不能转让"的代币，正是为了保护身份的不可拆分性。

---

### 2. 关系类（Relationships）

**为什么不可转让**：关系之所以是关系，正因为它不可被复制、不可被同时属于多人。一旦可流通，"我们"就被还原为"我和他者-商品"（韩炳哲：他者的消失）。

| 子项 | 当前 token 化危险征兆 | 检测信号（高危 = 应立即停止） |
|------|------------------------|------------------------------|
| 友谊 | 出现"友谊 NFT"、"好友关系积分" | 可被出售、好友关系可被打包转让 |
| 爱情/亲密关系 | 出现"关系合约 NFT"、"情感承诺代币" | 关系状态可被挂牌交易、承诺可被转售 |
| 亲子/家庭关系 | 出现"家庭关系图谱 NFT"、"亲属 token" | 关系可被任意账户挂到自己身上 |
| 师徒/同事关系 | 出现"职场关系图谱 token"、"内推 NFT" | 关系可被买入以绕过正常晋升机制 |

**协议层对位**：DeSoc 框架中"关系图谱（graph of trust）"的不可转让性设计正是为此类价值守边界。

---

### 3. 时间类（Time）

**为什么不可转让**：一次性时间（生命时间、记忆）不能被复制或重置。一旦被标价/挂牌，等于把人预先清算（韩炳哲：自我殖民）。

| 子项 | 当前 token 化危险征兆 | 检测信号（高危 = 应立即停止） |
|------|------------------------|------------------------------|
| 生命时间余额 | 出现"生命时长 NFT"、"死亡对冲" | 可被放贷、可被跨代继承 |
| 记忆（一次性体验） | 出现"记忆 NFT 收藏"、"记忆回放市场" | 可被买卖、可被合成为新体验 |
| 个人时间（注意力、专注力） | 出现"注意力 token"、"专注力积分" | 可被出售、可被打包卖给广告主 |
| 死亡/遗愿 | 出现"遗愿 NFT 交易"、"遗嘱代币" | 遗愿可被代位执行、可被金融化 |

**协议层对位**：时间银行（time banking）这种"关系记账、不金融化"模式是对的方向；In Time 那种"可借贷、可破产"是反面教材。

---

### 4. 体验类（Experience）

**为什么不可转让**：体验是关系产物，离开产生体验的关系，体验本身就被还原为可复制的商标（Ted Chiang：情绪的商标 ≠ 情绪）。一旦被 token 化，体验被还原为表征，丢失不可替代性。

| 子项 | 当前 token 化危险征兆 | 检测信号（高危 = 应立即停止） |
|------|------------------------|------------------------------|
| 情绪（喜怒哀乐、悲伤） | 出现"情绪 NFT"、"快乐铸造服务" | 可被标价、可被批量生产、可被对冲 |
| 敬畏/美感/灵感 | 出现"美学 token 化"、"灵感市场" | 体验被切割为可重复消费的单位 |
| 痛苦/创伤 | 出现"痛苦代币"、"创伤 NFT 收藏" | 可被他人购买、可被作为表演素材 |
| 爱情 | 出现"爱情 token 化"、"亲密关系 API" | 爱情被还原为按需服务 |

**协议层对位**：Ted Chiang 的核心质疑"情绪的表征 ≠ 情绪本身"——任何把体验 token 化的产品，本质上卖的是商标，不是体验本身。

---

### 5. 意志类（Will）

**为什么不可转让**：承诺、信念、选择之所以有重量，正因为它们"一旦做出就不可撤回"。一旦可转让，"我承诺"就被还原为"我标价"。

| 子项 | 当前 token 化危险征兆 | 检测信号（高危 = 应立即停止） |
|------|------------------------|------------------------------|
| 承诺（合同、誓言） | 出现"承诺 NFT 转售"、"誓言交易" | 承诺可被任意账户持有、可被转售 |
| 信念（价值观、政治立场） | 出现"立场 token 化"、"信念市场" | 信念可被买入卖出以影响他人 |
| 选择（投票权、决策权） | 出现"投票权 NFT"、"决策权代币" | 选择权可被收购、可被集中 |
| 责任（监护权、信托） | 出现"责任 token"、"监护 NFT" | 责任可被转嫁、可被代位执行 |

**协议层对位**：DAO 治理代币的"可转让投票权"是反面教材——它让治理权变成可被鲸鱼收购的资产。

---

## 通用检测规则

无论哪一维度，下述任一征兆出现，都应触发"暂停评估"：

| 征兆 | 解释 |
|------|------|
| 可被做空 / 做多 | 价值被还原为可定价波动对象 |
| 可被分拆为碎片 | 价值的整体性被打破 |
| 可被衍生化（期货/期权） | 价值被独立于本体之外交易 |
| 可被跨代继承 | 价值脱离自然生命周期 |
| 可被任意账户购买并挂名 | 价值脱离原始产生者 |
| 可被借贷 / 抵押 | 价值被还原为可担保资产 |
| 可被对冲（hedge） | 价值被还原为风险对象 |

**检测口诀**："**可不可以卖给你不认识的人**"——如果可以，基本都是高危。如果需要"本人确认 / 不可转让 / 关系锚定"等约束，至少在安全区。

## 使用方式

### 对个人

- 自查：我身边哪些东西已经被 token 化？我愿不愿意让它离开我？
- 决策：当某个新产品出现"把你的 X token 化"的卖点时，对照本清单识别危险信号
- 行动：在 `assets/detokenization-24h-experiment.md` 实验中验证你的边界

### 对产品团队

- 审计：在设计任何 token 化功能前，对照本清单逐项扫描
- 决策：如果某功能命中本清单的高危征兆，**不应上线**——而不是"上线后再治理"
- 报告：在产品白皮书中明确列出"我们不 token 化的东西"，作为产品边界宣言

### 对协议设计者

- 设计：在协议层划出"不可转让层"（如 SBT），而不是事后修补
- 标准：把本清单的高危征兆编码为 lint 规则，token 化合约部署前自动扫描
- 立法：为不可转让价值提供制度保护（参考 ns-002 不被记账权提案）

### 对圆桌 skill 用户

- 复用：本清单是 roundtable-forge 圆桌讨论的**输入材料**——任何"该不该 token 化 X"的圆桌讨论，都可以以本清单为起点
- 扩展：在新场圆桌中遇到本清单没覆盖的新价值类型，反向回灌到清单

## 与 ns-002 / ns-003 的关系

- **ns-001（本清单）**：从价值维度列出"不该 token 化什么"
- **ns-002（不被记账权）**：把"不该 token 化"上升为新型基本权利（法学/政策层面）
- **ns-003（24h 去 Token 化实验）**：在个人体验层面验证"不被 token 化"的可能与代价

三者构成完整的"价值识别 → 制度保护 → 个人实践"三层链路。
