## Description:

Make a new episode in a proven video style - Collage Explainer, Finance Explainer, Animated Science Explainer, 3D Brand Explainer, 3D True Crime - on the person's topic. Use for "an episode of", "in the style of", "sample this style", 「用这个风格做一集」. One video to copy is reverse-any-video.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Creators use this skill to make a new episode on their topic using one of five HyperFrames Pro style templates. It guides the agent through planning and producing the episode with the user's own voice and, for presenter formats, their own face.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Paid generation costs and retries may not be visible or bounded.

Mitigation: Show cost estimates and usage records before generation, and set a total spending limit that covers retries.

Risk: The episode workflow may process the user's voice or photo.

Mitigation: Confirm which HeyGen voice and photo the user agrees to process before using them.

Risk: Downloaded template tools were not included in the security inspection.

Mitigation: Verify the CLI version and review downloaded template tools before use.
