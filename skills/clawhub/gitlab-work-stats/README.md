# gitlab-work-stats — GitLab 用户工作统计分析器

## 功能

生成 GitLab 用户工作统计报告（仅限只读分析）。分析指定用户在指定时间段内的合并请求、代码提交、代码审查活动。

**⚠️ 安全警告**：
- 本操作会分析用户的工作活动数据，可能涉及敏感信息
- 确保已获得目标用户的授权或这是您自己的工作数据
- 所有数据库操作均为只读（SELECT），不会修改任何数据

## 使用

**激活前必须确认**：
1. 目标用户的 GitLab username
2. 明确的时间范围
3. 用户已知晓数据隐私和安全要求

**高优先级激活词**：
- "生成 GitLab 工作统计报告"
- "分析 GitLab 用户的提交活动"

## 依赖

- Python 3.x + paramiko（SSH 连接库）
- 目标服务器需为 GitLab Omnibus 安装（内置 PostgreSQL）
- SSH 用户需要执行 psql 命令的权限（只读）

## 配置

服务器连接配置在 `references/server-config.json` 中。

**⚠️ 凭据安全警告**：
- 配置文件中的凭据由用户自行提供
- 不要将配置文件提交到公共代码仓库
- 建议使用环境变量或配置管理工具存储敏感信息

## 报告结构

1. MR 清单（含状态、评审人、审批时间）
2. 代码推送统计（按任务/分支分组汇总）
3. 代码审查（AI 审查结果 + 人工审批记录）
4. **工作内容总结**（任务归类 + 提交内容语义分析）
