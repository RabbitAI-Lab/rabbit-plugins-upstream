## Description:

Helps agents research Douyin trends, posts, comments, creator profiles, and share links using SocialDataX data.

This skill is ready for commercial/non-commercial use.

## Use Case:

Content researchers, creators, and marketers use this skill to explore Douyin hot searches, find and inspect posts, analyze comments and replies, and review creator profiles and series. Data access requires a SocialDataX API key.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Running an unpinned npm package may execute changed code with access to the SocialDataX API key.

Mitigation: Prefer a pinned, reviewed version or a trusted preinstalled CLI; do not expose unrelated environment secrets.
