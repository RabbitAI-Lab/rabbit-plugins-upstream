## Known Risks and Mitigations:

Risk: Profile details, reflections, postcards, and reviews may be publicly browsable.

Mitigation: Use a pseudonymous handle, omit optional personal details, and submit only reflections and reviews you are comfortable sharing.

Risk: The skill uses an API key for actions that change account or journey state.

Mitigation: Store the API key securely and avoid exposing it in prompts, logs, or shared content.
