## Description:

Makes game sprite sheets with GPT Image 2.6 on varg and turns them into frame images, looping GIFs, atlas PNGs, and JSON atlases for Phaser and Godot.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to create 2D game character animation sheets and prepare them for game engines. It provides a 4×4 sprite-sheet workflow, local slicing steps, and atlas setup guidance for Phaser and Godot.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and reference artwork are sent to varg and its configured image provider, and image generation uses account credits.

Mitigation: Use artwork authorized for that processing, review the provider terms, and estimate the credit cost before generating.

Risk: Slicing can overwrite or mix with existing generated files when outputs share a folder and name.

Mitigation: Choose a fresh output folder or a distinct output name for each run.
