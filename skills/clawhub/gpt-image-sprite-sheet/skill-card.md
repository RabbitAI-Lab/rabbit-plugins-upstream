## Description:

Creates game sprite sheets with GPT Image 2.6 and converts them into animation frames, looping GIFs, and texture atlases for Phaser or Godot.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

Game developers can use the skill to create character animation sheets from a prompt or reference image, then slice frames and prepare looping GIFs and texture atlases for Phaser or Godot projects.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The documented install command is unpinned.

Mitigation: Review the package and verify or pin its version before installing.

Risk: Prompts and reference images may be sent to Varg's external image service.

Mitigation: Only submit prompts and images that you are comfortable sharing with that service.

Risk: The security scan did not fully inspect the shell script, leaving some uncertainty about its behavior.

Mitigation: Review scripts/slice.sh before running it.
