## Description:

Guides developers through generating 4×4 game sprite sheets with GPT Image on Varg and converting them into animation frames, GIFs, and Phaser or Godot atlases.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to create consistent game character animation sheets and convert them into assets for Phaser or Godot projects.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and artwork are sent to Varg and its processing provider, whose retention practices were not verified in this review.

Mitigation: Use only prompts and artwork you are comfortable sharing with those services.

Risk: Image generation incurs credits or other charges.

Mitigation: Check the current generation cost and estimate it before creating a sheet.

Risk: Matching output files can be overwritten when exports use the same names.

Mitigation: Choose a fresh output folder for each run.
