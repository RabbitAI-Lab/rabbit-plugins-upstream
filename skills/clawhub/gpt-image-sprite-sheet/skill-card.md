## Description:

Creates GPT Image sprite sheets and converts them into game-ready frames, looping GIFs, and texture atlases for Phaser and Godot.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT

## Use Case:

Developers can use this skill to create consistent 2D game animation sheets and turn them into frame images, looping GIFs, and atlases for Phaser or Godot.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and reference images may be sent to an external image service.

Mitigation: Avoid submitting private artwork or prompts unless you are comfortable sharing them with the service.

Risk: The install uses an unpinned package, and analysis of a referenced script was partial.

Mitigation: Review the package version and inspect the skill files before installing or running them.
