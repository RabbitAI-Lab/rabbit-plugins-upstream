# 企业尽调报告 Pro（标准版）

支付宝 AI 付费 Skill。产品形态：**一次付费套餐 = 企业详细工商信息 + 风险汇总**，输出带摘要灯的尽调报告。

> **敏感数据提示（运营方 / 集成方）：** 返回结果可能含法人与主要人员姓名、股东名称、**企业注册地址**、统一社会信用代码/注册号、机构股东证照号，以及被执行/失信中的案号与主体标识字段。查询方无需提供个人隐私，但报告本身含公开敏感标识，须最小化展示与留存。**若返回身份证号须脱敏展示**（前6后4，见 `OUT_FORMAT.md`），禁止明文回显与日志落地。**自然人股东不返回证件类型与证件号**；**不返回自然人住址**；机构股东可能返回营业执照类公开标识（勿文档写成「一律非公示项」）。

## 目录说明

| 路径            | 用途                                     |
| --------------- | ---------------------------------------- |
| `SKILL.md`      | Agent 执行规范（触发、402、约束）        |
| `OUT_FORMAT.md` | 支付成功后的报告渲染模板                 |
| `PRODUCT.md`    | 标准版产品锁定说明（接口清单、分档边界） |
| `docs/`         | 各模块字段释义与单模块实例               |

## 你需要补充的文档

在 `docs/` 下按文件名放入实例文档（Markdown / 截图说明 / JSON 样例均可），建议：

```text
docs/
  工商主体信息.md
  企业经营异常信息.md
  企业被执行人信息.md
  企业失信被执行人信息.md
  企业限制高消费.md
```

（当前仓库内文件名可带内部归档前缀，Agent 以返回字段名为准，勿向用户展示归档编号。）

文档齐全后据此：

1. 写入正式套餐收单 `resourceId` 与请求体
2. 按真实 JSON 路径定稿 `OUT_FORMAT.md`
3. 必要时微调触发词与红黄绿规则
