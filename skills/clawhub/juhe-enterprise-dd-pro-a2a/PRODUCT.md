# 产品锁定：企业尽调 Pro · 标准版

> 状态：标准版已定稿；收单 `resourceId` 见 `SKILL.md` 请求模板；返回结构与字段见 `README.md` / `docs/`；渲染见 `OUT_FORMAT.md`。

## 定位

一次付费，输出「合作前公开风险快检报告」。
输入：企业**工商登记全称** / 统一社会信用代码 / 注册号。
前置：简称、品牌名、明显残缺名称须经「公司名称前置初筛」（见 `SKILL.md` 4.1 第二步），未通过不发起付费。
不做：征信报告、法律意见、「建议合作/不建议合作」类结论；不做静默补全全称后扣费。


## 标准版一次返回字段

| 返回字段 | 模块 | 说明 |
| -------- | ---- | ---- |
| `data.companyinfo` | 主体工商 | 必有；缺失则整单视为查无 |
| `data.jingyingyichang` | 经营异常 | 分页对象：`totalCount` + `data[]`；只返回第 1 页最多 20 条 |
| `data.beizhixingrenxinxi` | 被执行 | 同上 |
| `data.shixinbeizhixingren` | 失信 | 同上 |
| `data.xianzhigaoxiaofei` | 限高 | 同上 |

摘要与专章条数：总数 > 0 写「共 N 条，展示 M 条」；**总数为 0 时摘要只写「共 0 条」，不写展示条数**。展示上限：经营异常全量（本页）；被执行/限高/工商变更 ≤15；失信表 ≤8；义务详情默认全文仅前 3 条，其余提示用户按**案号**追问展开（**追问展开不得再次请求查询接口**，只用本次已返回数据）。N > M 时说明「部分最近记录」。**须明确告知用户：风险类信息每次仅查最近一页、报告最多展示 15 条（失信 8 条），非全量清单，仅供参考；勿对用户强调接口页长 20。**面向用户禁止英文字段名与「同接口××」话术。

**版式冻结**：严格按 `OUT_FORMAT.md`「固定化最优展示」渲染（摘要表、股东/分支/变更汇总表、四大风险一律汇总表）；禁止每次查询换版式或在卡片/表格间随意切换。

红黄绿灯仍以各模块总数等规则判定，不因展示截断改灯。

## 明确不进标准版

| 能力 | 原因 |
| ---- | ---- |
| 行政处罚 | 数据常空、样例难稳；完整版/加项再考虑 |
| 涉诉详情 | 完整版再考虑 |
| 欠税 / 纳税信用 / 非正常户 | 完整版 |
| 舆情 / 招聘 | 完整版 |
| 商标 / 企业专利 | 数据链不足，不做硬凑 |
| 立案清单 | 标准版不承诺 |

## 交付结构

1. 一页摘要（红黄绿灯 + 关键发现）
2. 主体档案（工商字段叙事）
3. 经营异常 / 被执行 / 失信 / 限高
4. 免责声明

空结果必须展示「公开数据未见××记录」（排除风险也是付费价值）。

## 红黄绿规则（字段文档到位后可微调阈值，规则逻辑不变）

| 灯 | 条件 |
| -- | ---- |
| 红 | 存在失信（现）或限高（现）；或主体状态为吊销/注销等且用户按存续企业查询 |
| 黄 | 仅有历史被执行/历史类风险已化解信号；或经营异常在列 |
| 绿 | 红黄条件均未命中；各风险模块无公开记录 |

禁止输出确定性法律/合作建议句。
