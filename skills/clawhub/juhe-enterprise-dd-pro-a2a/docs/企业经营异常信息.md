# 企业经营异常信息

## 返回参数说明：

| 名称       | 类型   | 说明                              |
| ---------- | ------ | --------------------------------- |
| totalCount     | int    | 总条数                                     |
| totalPage      | int    | 总页数                                     |
| pageSize       | int    | 没页条数                                   |
| pageIndex      | int    | 当前页（由于数据展示问题，只查第一页数据） |
| data           | array  | 具体信息                                   |
| name       | string | 企业名称                          |
| reg_no     | string | 注册号                            |
| province   | string | 省份                              |
| in_reason  | string | 列入原因                          |
| in_date    | string | 列入时间                          |
| out_reason | string | 移出原因                          |
| out_date   | string | 移出时间                          |
| department | string | 做出决定机关                      |
| disabled   | string | 0：当前公示信息 ；1：历史公示信息 |
