# 企业失信被执行人信息

## 返回参数说明：

| 名称            | 类型         | 说明                     |
| --------------- | ------------ | ------------------------ |
| totalCount     | int    | 总条数                                     |
| totalPage      | int    | 总页数                                     |
| pageSize       | int    | 没页条数                                   |
| pageIndex      | int    | 当前页（由于数据展示问题，只查第一页数据） |
| data           | array  | 具体信息                                   |
| id              | VARCHAR(32)  | 编号                     |
| reqKeyWord      | VARCHAR(200) | 查询关键字               |
| iName           | VARCHAR(128) | 企业名称                 |
| caseCode        | VARCHAR(100) | 案号                     |
| cardNum         | VARCHAR(50)  | 主体标识字段（说明口径：身份证号码/组织机构代码）。企业尽调场景下多为组织机构代码或统一社会信用代码类公开标识。**若值为身份证号，面向用户必须脱敏**（保留前6后4，规则见 `OUT_FORMAT.md`），禁止明文回显；企业主体标识可原样展示。禁止日志落地明文身份证号、禁止二次扩散或长期留存 |
| courtName       | VARCHAR(100) | 执行法院                 |
| areaName        | VARCHAR(20)  | 省份                     |
| gistId          | VARCHAR(300) | 执行依据文号             |
| regDate         | VARCHAR(15)  | 立案时间                 |
| gistUnit        | VARCHAR(100) | 做出执行依据单位         |
| performance     | VARCHAR(100) | 被执行人的履行情况       |
| disruptTypeName | VARCHAR(500) | 失信被执行人行为具体情形 |
| publishDate     | VARCHAR(15)  | 发布时间                 |
| duty            | TEXT         | 失信信息详情             |
| inputTime       | VARCHAR(30)  | 首次采集日期             |
| updateTime      | VARCHAR(30)  | 最新更新日期             |
| totalAmount     | VARCHAR(30)  | 总执行金额               |
