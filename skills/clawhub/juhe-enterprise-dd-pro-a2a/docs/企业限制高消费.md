# 企业限制高消费

## 返回参数说明：

| 名称       | 类型         | 说明                                       |
| ---------- | ------------ | ------------------------------------------ |
| totalCount | int          | 总条数                                     |
| totalPage  | int          | 总页数                                     |
| pageSize   | int          | 没页条数                                   |
| pageIndex  | int          | 当前页（由于数据展示问题，只查第一页数据） |
| data       | array        | 具体信息                                   |
| serialNo   | VARCHAR(50)  | 记录的序列号                               |
| reqKeyWord | VARCHAR(200) | 返回企业现用名或者曾用名获取的数据         |
| entName    | VARCHAR(300) | 企业名称                                   |
| caseStatus | VARCHAR(120) | 案件状态                                   |
| caseNo     | VARCHAR(100) | 案号                                       |
| court      | VARCHAR(100) | 执行法院                                   |
| sortTime   | VARCHAR(50)  | 立案时间                                   |
| entInfo    | VARCHAR(120) | 企业信息                                   |
| inputTime  | VARCHAR(50)  | 首次采集日期                               |
| updateTime | VARCHAR(50)  | 最新更新日期                               |
| applicant  | ARRAY        | 申请人                                     |
| pubDate    | VARCHAR(50)  | 发布时间                                   |
| pdesc      | TEXT         | 公告正文                                   |
