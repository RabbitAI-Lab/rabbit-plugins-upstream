# 企业被执行人信息

## 返回参数说明：

| 名称           | 类型   | 说明                                       |
| -------------- | ------ | ------------------------------------------ |
| totalCount     | int    | 总条数                                     |
| totalPage      | int    | 总页数                                     |
| pageSize       | int    | 没页条数                                   |
| pageIndex      | int    | 当前页（由于数据展示问题，只查第一页数据） |
| data           | array  | 具体信息                                   |
| serialNo       | string | 序列号，记录的序列号，对应serial_no        |
| reqKeyWord     | string | 查询关键词                                 |
| pName          | string | 被执行人姓名/名称                          |
| caseCode       | string | 案号                                       |
| execCourtName  | string | 执行法院                                   |
| execMoney      | string | 执行标的                                   |
| partyCardNum   | string | 主体标识字段（说明口径：身份证号码/组织机构代码）。企业尽调场景下多为组织机构代码或统一社会信用代码类公开标识。**若值为身份证号，面向用户必须脱敏**（保留前6后4，规则见 `OUT_FORMAT.md`），禁止明文回显；企业主体标识可原样展示。禁止日志落地明文身份证号、禁止二次扩散或长期留存 |
| caseCreateTime | string | 立案时间                                   |
| caseStatus     | string | 案件状态，已不披露/公示中                  |
| inputTime      | string | 首次采集日期                               |
| updateTime     | string | 最新更新日期                               |
| uuid           | string | uuid                                       |
