# 幼儿数学教学法与家长指导话术

## 核心原则

1. **实物 → 表象 → 符号**：任何新概念先用积木/豆子/水果摆一摆，再过渡到图片（emoji / 图画），最后才出现数字符号。跳过实物环节是幼儿"会背不会用"的首要原因。
2. **理解优先于速度**：L1-L4 阶段不计时，不比谁快。速度要求只在 L5 后期引入。
3. **单次 10-15 分钟**：一次练习 12-20 题，做完即停。幼儿注意力窗口有限，超时练习会形成抵触。
4. **正确率先于难度**：正确率不到 90% 不升难度。难度是结果，不是手段。
5. **错题不当场反复讲三遍**：先让孩子自己说"你是怎么想的"，再针对性纠一点，隔两天用同型题复测。

## 分题型讲解话术

### 识数 / 点数（count_objects）
- 标准话术："用小手指着一个一个点，嘴里数一个，手指动一个，最后一个数是几就是一共几个。"
- 纠错：孩子跳数、重复数 → 让他把数过的东西"挪到一边"，形成已数/未数两堆。
- 纠错：数完说不出总数 → 追问"最后数到几？那说明一共就是几"，强化基数原则。

### 数字书写（write_number）
- 标准话术："先看格子里的虚线，从红点开始，沿着箭头走。"
- 只要求笔顺大致正确和占格位置，不追求工整。握笔姿势比字形重要。
- 镜像数字（写反 2、3、5）在 5 岁前属正常现象，示范纠正即可，不要反复批评。

### 比大小（compare）
- 标准话术："大嘴巴朝大数，尖尖角朝小数。"（鳄鱼嘴巴法）
- 先比实物：左边 5 颗糖，右边 3 颗糖，谁多？再引符号。

### 分解组成（compose）
- 标准话术："5 个苹果分给两个人，你有几种分法？" 边分边记，形成有序思维（1 和 4、2 和 3、3 和 2……）。
- 强调"有序分"：从 1 开始一个一个移，避免漏分、重复分。
- 分解组成是加减法的基础，L4 计算卡壳时，退回来补 L3 分解。

### 加法（add）
- 合并模型："原来有 3 只，又来了 2 只，合起来是几只？"
- 关键问句："'一共'是什么意思？"——确认孩子理解加法场景，而不是看到"+"就加。
- 数数策略 → 接着数策略：从 3 往后数 2 个（4、5），比从头数更快，这是必须过渡的一步。

### 减法（sub）
- 三种模型都要练：拿走（吃了 2 个）、剩下（还剩几个）、比较（哥哥比弟弟多几个）。
- 标准话术："'还剩'就是去掉一部分，从总数里去掉。"
- 常见困难：减法都用加法做 → 用实物演示"拿走"动作后再写算式。

### 进位加 / 退位减（L5）
- 凑十法："9 差 1 就满 10，把 3 分成 1 和 2，9+1=10，10+2=12。" 口诀："看大数，分小数，凑成十，加剩数。"
- 破十法："13-5，13 分成 10 和 3，10-5=5，5+3=8。"
- 允许孩子先用手指/实物，逐步脱离。禁止用"竖式硬算"替代理解。

### 应用题（word_problem）
- 三步法：读题 → 说"这道题在讲一件什么事" → 列式。
- 关键问句："题目问的是'一共'还是'还剩'？" 让孩子自己判断运算。
- L4 只做一步运算，L5 才做两步。

## 常见错误与纠正

| 表现 | 可能原因 | 纠正方式 |
|---|---|---|
| 会背 1-100 但数不出 5 个物体 | 只会唱数，未建立数物对应 | 回到 L1 大量点数实物，唱数与点数分开练 |
| 加法算对，减法全错 | 只理解"合起来" | 用拿走/剩下的实物演示补减法三种模型 |
| 看到数字就猜 | 未建立量的概念 | 每题都要求"先画出来/摆出来"再说答案 |
| 20 以内进位加频繁错 | 未掌握凑十 | 单独练"几和几凑成 10"的互补数对，再练进位 |
| 会做横式不会做应用题 | 不理解情境 | 先让孩子用自己的话复述题意，再列式 |
| 书写反字、出格 | 手部精细动作未达标 | 加大描红量，降低书写速度要求，不批评 |

## 给家长的反馈话术模板

练习完成后，向家长输出 3 条以内的指导，格式固定：

1. **本次结果**：「共 X 题，做对 Y 题（Z%）。」
2. **薄弱点**：「错的主要是『分解组成』，说明还不太熟练 5 可以分成几和几。」
3. **下一步**：「建议明天用家里的小玩具玩『分两份』游戏，5 分钟即可，后天再做一份同难度练习。」

注意：
- 不对孩子做横向比较，不出现"别人家孩子""太慢了""这么简单都不会"等表述。
- 先肯定具体行为（"今天第 3 题你自己画了图，这个方法很好"），再提改进点。
- 一次只提一个改进点。
