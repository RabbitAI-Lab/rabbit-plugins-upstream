# 短视频脚本写作 SOP

这是一个面向短视频/口播脚本生产场景的开源技能，把"开头怎么写"变成一套可复用、可自查的固定结构 + 钩子公式轮换。

它给每条脚本一条清晰的执行规范：

- 3 段固定结构怎么搭？
- 5 种钩子公式怎么轮换？
- 9 条质检红线怎么自查？
- 引流句怎么参数化？

## 适合谁用

- 短视频创作者、口播博主、内容团队。
- 脚本要量产、风格要稳定、又不想每条都从零想"开头怎么写"。
- 想要一份可复用、能被同事或未来的自己看懂的脚本规范。
- 需要在多个平台（抖音/视频号/小红书）做适配。

## 快速开始

1. 确认素材已经过 `content-material-scorer` 评级（A/B 级）。
2. 复制 `assets/script-template.md` 到自己的 `outputs/` 目录。
3. 选钩子公式（5 种轮换），按 3 段结构填入。
4. 收束段用参数化引流句，把 `{creator_name}` 替换成实际署名。
5. 跑一遍 `references/hook-formulas.md` 末尾的质检对照表。

## 文件

- `README.md`：本文件。
- `LICENSE`：MIT 许可证。
- `SKILL.md`：可复用的技能说明。
- `assets/script-template.md`：脚本文件模板。
- `references/hook-formulas.md`：5 种钩子公式 + 9 条质检红线。

## 推荐流程

1. 拿到 A/B 级素材。
2. 选主角度（故事/方法/观点/演示/对比）。
3. 选钩子公式（5 种轮换，不连续重复）。
4. 写展开段（信息密度 + 节奏 + 人称）。
5. 写收束段（呼应钩子 + 参数化引流句）。
6. 跑质检 9 条红线。
7. 输出 Markdown → 用户审阅 → 存档。

## 仓库策略

这个包建议单独放在自己的 GitHub 仓库里。

除非它只是更大技能库的一部分，否则不要和别的项目混在一起。

## 与其他技能的搭配

- 配合 `content-material-scorer` 使用：先用评分器选素材，再用本 SOP 写脚本。
- 配合 `local-material-batch-skill` 使用：批量产出多平台脚本。
- 配合 `offline-html-deck-builder` 使用：把脚本转成可视化页面对外分享。
