# 预算 fallback 规则

本文件只在交通、住宿或当地消费无法取得当前报价时提供**低置信度区间**，不能称为实时价格，也不能代表可预订库存。

## 使用原则

1. 优先使用当前 provider 或网页查询结果。
2. 所有价格都记录 `source`、`fetched_at`、`price_type` 和 `confidence`。
3. 没有当前数据时只给宽区间，不给看似精确的酒店、票价或总价。
4. 总预算必须包含往返接驳、住宿、餐饮、当地交通、门票/活动和机动金。
5. 用户改变天数、人数、路线或住宿后必须重新计算。

## 每人每日低置信度区间

| 消费方式 | 住宿+餐饮+市内交通+普通活动 |
|---|---:|
| 节省 | ¥220–450 |
| 平衡 | ¥450–900 |
| 舒适 | ¥900–1800 |

偏远、高海拔或需要包车的方向应放大区间：

- 山南、日喀则：约 `1.1–1.3 ×`。
- 纳木错、珠峰方向：约 `1.3–1.8 ×`。
- 阿里方向：必须单独查询车辆、住宿、油费和证件服务，不使用普通日均价替代。

## 往返大交通低置信度区间

仅在 provider 无结果时用于方案排序：

| 方式 | 每人往返区间 |
|---|---:|
| 飞机及接驳 | ¥1600–5000 |
| 火车及接驳 | ¥900–2800 |
| 自驾/拼车 | ¥2500–8000 |

实际价格受出发地、日期、淡旺季、接驳次数和退改条件影响。展示给用户时必须写明“待实时核实”。

## 预算判断

- `estimated.low > 用户总预算`：明确标记最低估算超预算。
- `estimated.high <= 用户总预算`：可标记预算余量较充足。
- 介于两者之间：标记存在波动，需要先确认交通和住宿。
- 已选择项目与已花费用单独累计，不能用估算覆盖实际金额。
