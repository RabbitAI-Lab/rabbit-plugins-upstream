# 政府采购异常低价审查与应对助手

基于财政部《关于推动解决政府采购异常低价问题的通知》（财库〔2026〕2号，2026-02-01 施行）落地的实务助手。
覆盖三视角工作流：

- **采购人 / 代理（标前防御）**：合规设定异常低价启动红线、嵌入采购文件条款、评审专家指引、履约验收加严联动。
- **评标委员会 / 评审专家（标中执法）**：一键筛查、启动审查决定书、带追责预警的审查记录表、澄清问题清单、归档包。
- **投标人 / 供应商（标后自救）**：成本构成合理性说明函、市场价佐证（联网加闸）、模拟质询演练、应答自查。

挂载 8 个 IMA 知识库（KB-A~H 分层路由）+ 联网检索；含 2号文「3+1」四红线（平均价×50% / 次低×50% / 最高限价×45% / 专业判断）、≥30分钟说明时限、上浮封顶 65% 等硬规则与 Few-Shot 计算引擎。
