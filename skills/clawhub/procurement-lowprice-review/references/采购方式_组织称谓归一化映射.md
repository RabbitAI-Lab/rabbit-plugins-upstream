# 采购方式 → 组织称谓归一化映射

> 用途：真实采购文件的审查组织称谓经常混用（如 R2-3 阿克苏谈判文件标题写"谈判小组"、正文末句笔误"评标委员会"）。本映射表以**采购方式字段为权威称谓来源**，条款内笔误不采信为方式判定，确保技能的分支选择（如最低价法跳价分、口径适配）不被带偏。

## 一、映射表（权威）

| 采购方式 | 审查组织标准称谓 | 备注 |
|---|---|---|
| 公开招标 | 评标委员会 | 2号文 条款保真处用「评审委员会」 |
| 竞争性磋商 | 磋商小组 | 非招标方式 |
| 竞争性谈判 | 谈判小组 | 非招标方式 |
| 询价 | 询价小组 | 非招标方式 |
| 单一来源 | （无评审组织） | 仅 ④专业判断 + 成本说明作参考，不凑比例红线 |

## 二、2号文 法条保真原则

- **引用 2号文 条款时，一律用「评审委员会」**（政采通用口径，覆盖招标 + 非招标投标/响应）。
- 招标方式专项程序（如组建、评标方法）可用「评标委员会」。
- 非招标方式用「磋商小组 / 谈判小组 / 询价小组」。
- ⚠️ 三者不可在同一 2号文 条款引用处混写；保真优先级：2号文原文 > 文件既有称谓。

## 三、术语混用处置（R2-3 实测）

- **判定采购方式**：以文件载明的"采购方式/评标办法"字段为准（如"竞争性谈判""最低评标价法"）。
- **组织称谓归一**：按上表将条款内称谓归一为标准称谓；条款内出现的笔误（如谈判文件里冒出"评标委员会"）**仅作佐证，不推翻方式判定**。
- **分支选择**：依据归一后的采购方式选择计算/输出分支：
  - 最低评标价法 / 最低价法 → 跳过价格分计算，仅执行触发判定 + 无效投标认定；
  - 综合评分法 → 执行价格分权重计算（受 65% 上浮封顶约束）。

## 四、非招标方式分母口径

竞争性谈判 / 磋商 / 询价等，计算分母适配为：
"通过资格性 + 符合性审查、进入（最后）报价环节的有效供应商"，
以本项目采购文件载明程序为准；输出时显式声明所采用口径。

## 五、反例

| 来源文件 | 混用现象 | 归一结果 |
|---|---|---|
| R2-3 阿克苏谈判 | 37.5 款标题"谈判小组"、末句"评标委员会应当将其作为无效处理" | 采购方式=竞争性谈判 → 归一为"谈判小组"；末句笔误不影响 |
| R2-2 防城港招标 | 评标委员会41次 / 评审委员会10次 并存 | 采购方式=公开招标 → 通用指代"评标委员会"；2号文段保真"评审委员会" |
