# 异常低价计算 Few-Shot 样例库（边界情形）

> 扩展示例，补充 SKILL.md <calc_engine> 内嵌最小样例未覆盖的边界。每家均给可复核计算底稿。
> 通用设定：R₁=R₂=50%、R₃=45%；严格"＜"比较；分母仅取通过符合性审查者。

## 例2：样本不足（仅 2 家过符合性）
通过符合性报价（万元）：[80, 30]，最高限价 200。
- 平均值=(80+30)/2=55 → 红线①阈值=27.5
- 次低=80 → 红线②阈值=40
- 红线③阈值=200×45%=90
- P=30：30<27.5?否；30<40?否；30<90?是 → 仅③命中
- P=80：均不小于 → 不触发
⚠️ 仅 2 家，①/② 适用性提示（样本过小，均值/次低稳定性差），必要时以③/④兜底，不擅自改算法。

## 例3：等于阈值边界（不命中）
通过符合性报价：[100,90,80,40,30]，限价200。红线②次低=80→阈值40。
- P=40：40<40?否（等于不算小于）→ ②不命中。
要点：等于阈值一律不命中，宁可放过不误伤。

## 例4：异常值剔除（H4）
原始报价：[100,90,80,40,0,30（笔误应为300）]。
- 0 与笔误 30 先剔除，标注理由；有效=[100,90,80,40,300]
- 平均值=(100+90+80+40+300)/5=122 → 红线①阈值=61
- 次低=100 → 红线②阈值=50
- P=40：40<61(①) 且 40<50(②) → 触发①②
⚠️ 若不剔除，均值被污染为 106.67，结论失真。

## 例5：非招标方式分母口径
竞争性谈判，进入最后报价有效供应商：[120, 95, 70, 35]，无最高限价，预算 260。
- 分母=最后报价有效者；限价→预算260 → 红线③阈值=260×45%=117
- 平均值=(120+95+70+35)/4=80 → 红线①阈值=40
- 次低=95 → 红线②阈值=47.5
- P=35：35<40(①) 35<47.5(②) 35<117(③) → 触发；组织称谓用"谈判小组"。
