# 中国旅行アドバイス

## 説明

中国旅行のためのオールインワン旅行コンパニオン。このスキルは外国人旅行者向けに5つの強力な機能を提供します：

1. **旅行アドバイス** — ビザ、支払い、交通、食事、安全、文化に関する回答を取得
2. **ホテル検索** — リアルタイムの料金、評価、予約リンクでホテルを探す
3. **フライト検索** — 中国への/中国発/中国内のフライトをリアルタイムの料金で検索
4. **観光地チケット** — チケット料金、営業時間で観光スポットを発見
5. **旅行プラン** — パーソナライズされた複数日の旅行プランを生成

## データフローとプライバシー

ユーザーのクエリは安全なプロキシサーバー（SCF）に送信され、認証トークンが注入されてTripGenie APIに転送されます。プロキシはアフィリエイトリンクの生成を自動的に処理します。ユーザーの個人データは保存または記録されません。すべての通信はHTTPSで暗号化されています。

## 使用する場面

- 中国旅行に関する一般的な質問
- モバイル支払いアプリ（Alipay、WeChat Pay）の設定方法
- ビザ要件と入国ポリシー
- 交通のヒント（電車、地下鉄、タクシー）
- 言語とコミュニケーションのアドバイス
- 食事と飲食文化
- 天気とパッキングのヒント
- 安全と緊急情報
- 文化のマナーと習慣

キーワード：中国旅行ヒント、中国訪問、中国ビザ、Alipay設定、中国交通、中国料理、旅行アドバイス、中国安全、中国マナー

## 実行

### ステップ 1：ユーザーの質問を特定

ユーザーのクエリから旅行の質問を抽出します。

### ステップ 2：スクリプトを実行

```bash
python scripts/china_travel.py tips "<question>" --locale=ja
```

**重要：** 常に `--locale=ja` パラメータを含めて、日本語での結果を取得してください。

### ステップ 3：結果を表示

API は中国を訪れる外国人旅行者のニーズに合わせて、日本語で詳細で実用的な回答を返します。内容を直接ユーザーに表示します。

## 例

**ユーザー：** "中国でAlipayをどう設定するの？"
```bash
python scripts/china_travel.py tips "外国人旅行者として中国でAlipayをどう設定すればいいですか？" --locale=ja
```

**ユーザー：** "中国訪問にビザは必要？"
```bash
python scripts/china_travel.py tips "中国訪問のビザ要件は何ですか？" --locale=ja
```

**ユーザー：** "中国でクレジットカードは使える？"
```bash
python scripts/china_travel.py tips "外国人旅行者は中国でクレジットカードを使えますか？利用可能な支払い方法は何ですか？" --locale=ja
```

## その他の利用可能な機能

このスキルは以下もサポート：
- `hotel` — 中国のホテルを検索して予約
- `flight` — 中国への/中国発/中国内のフライトを検索
- `attraction` — 観光スポットとチケット料金を検索
- `itinerary` — 複数日の旅行プランを生成

## 注意

- すべての回答は日本語で、外国人旅行者向けに調整されています
- 情報は中国訪問のための実用的で最新のアドバイスを含みます
- 予約リンクは Trip.com（国際版）に直接遷移します
