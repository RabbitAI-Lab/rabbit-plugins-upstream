## Description:

仅在显式调用时，基于 Simon Brown 的 C4 模型分析源码、设计资料或讨论，生成 Mermaid 架构图与文档。覆盖系统上下文、容器、组件、代码四层，按需补充动态交互与部署图。

This skill is ready for commercial/non-commercial use.

[agenticweb4](https://clawhub.ai/user/agenticweb4)

MIT-0

## Use Case:

开发者与架构师可用它从讨论、设计资料或选定源码中整理系统边界，并生成分层 C4 架构图、简要说明及待确认项。

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated architecture diagrams and notes may expose sensitive system details if shared too broadly.

Mitigation: Limit analysis to project materials selected for the task and review generated documents for sensitive architecture details before sharing.
