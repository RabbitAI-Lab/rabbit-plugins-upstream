## Use Case: <br>
External users and developers use this skill to ask an agent to create meme concepts, captions, reaction images, text jokes, and format-specific meme variants for a target audience or community. <br>

### Deployment Geography for Use: <br>

## Known Risks and Mitigations: <br>
Risk: The skill sends meme prompts or provided image context to the CellCog service and requires a CellCog API key. <br>
Mitigation: Install only when CellCog use is intended, configure CELLCOG_API_KEY through the agent environment, and avoid submitting sensitive prompt or image context unless that external processing is acceptable. <br>
