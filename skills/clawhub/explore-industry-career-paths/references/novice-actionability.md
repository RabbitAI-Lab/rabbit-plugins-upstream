# 零基础可行动性门槛

当用户要求“教我”“怎么开始”“零基础入门”或准备投入金钱、设备、真实交易、接单、开店时运行。本文件解决通用框架内容正确但领域信息稀薄的问题。

## 先做覆盖审计

回答前先为目标领域建立内部覆盖矩阵。通过以下四类当前材料反推新手必须知道什么：

1. 官方新手指南、监管规则或行业标准；
2. 正规课程大纲、职业标准或官方技术文档；
3. 真实工作 SOP、岗位任务、交易/服务流程；
4. 初学者完成首个真实任务所需的工具、材料、渠道和评价标准。

不要直接把模型记得的通用学习框架当作教程。先发现该领域自己的对象、分类、动作和信息入口。

## 十项完整性检查

对每项判断为 `需要展开 / 简述即可 / 不适用`。任何“需要展开”项缺失时不得提交完整教程。

1. **边界与目标**：用户究竟要会什么；相邻但不同的方向有哪些。
2. **基础对象与术语**：新手每天会接触的对象、界面、材料、指标、角色和术语。
3. **分类地图**：常见手法、款式、产品、市场、任务或分析方法如何分类，各自用途是什么。
4. **操作场所与入口**：在哪里学习、练习、购买、交易、投稿、接单或取得服务。
5. **工具/材料/账户**：需要什么规格和数量；最低、推荐、升级三档；哪些暂时不买。
6. **获取渠道与成本**：官方、授权、专业批发、正规平台或本地渠道；当前价格区间和总预算。
7. **基础流程**：从准备到完成、检查、记录和善后的具体步骤及关键质量点。
8. **信息系统**：官方规则、公告、行情/趋势、专业资料、机会信息分别去哪里看。
9. **练习与评价**：练什么、练到什么程度、谁来评价、失败如何修正。
10. **风险与下一步**：安全、财务、合规、骗局、退出条件以及未来 24 小时的第一步。

## 用“资源地图”替代课程清单

将用户所需资源按用途整理，而不是混成链接列表：

| 用途 | 至少回答 |
|---|---|
| 建立基础知识 | 从哪里系统学；免费与结构化选项 |
| 完成真实操作 | 使用什么工具、材料、账户或软件 |
| 购买/取得资源 | 渠道、规格、数量、价格、真假/合规核验 |
| 获取当前信息 | 官方入口、更新频率、如何订阅或检索 |
| 获得反馈 | 老师、师傅、社区、客户、模拟系统或评价量表 |
| 接近真实机会 | 岗位、门店、客户、平台、比赛、投稿或试单渠道 |

如果资源类别多，不受“每类最多 1—3 个”的机械限制；控制同质选项数量，但不能因此漏掉必要类别。

## 采购清单要求

涉及实物工具或耗材时，用可购买的物料表回答：

```text
品类｜用途｜建议规格/数量｜入门/推荐/专业档候选｜购买渠道｜当前单价或区间｜消耗周期｜为什么选｜替代项｜避坑｜来源与核实日期
```

品牌建议至少说明选择维度，例如安全/合规资料、专业使用证据、供货稳定、色号/配件体系、售后、单次成本。品牌可以举例，但不能用广告热度代替比较，也不要推荐无法验证来源的低价材料。

若电商页面无法稳定引用，优先给品牌官网、官方旗舰店入口或授权经销商查询方法，再提供精确搜索词和验货清单。

## 操作型教程要求

涉及软件、账户、交易或平台操作时，至少回答：

- 合法可用入口及适用地区；
- 注册/开户/安装前置条件；
- 界面中的基本对象；
- 一次完整操作的流程；
- 时间、费用、限额、结算或保存机制；
- 官方信息和异常处理入口；
- 先用模拟、沙盒、模型或低风险任务练习的方法。

不替用户代办账户或执行交易，不泄露个人信息，不把平台营销页作为合规依据。

## 答案分层

完整不等于把重点埋进长文。默认按三层组织：

1. **先做什么**：24 小时内可执行的 3 步和最低预算；
2. **新手操作手册**：覆盖矩阵中的必要知识、分类、流程、资源和风险；
3. **进阶路线**：7/30/90 天、真实反馈、作品/记录、就业/交易/开店或商业验证。

完整教程同时读取 `expert-apprenticeship.md`。覆盖清单只能保证“提到了”，师徒式规范负责保证“讲明白了”。每个基础分类至少解释用途、差异和第一次会在哪里遇到；每个流程至少展开一个端到端示范；每个重要判断至少给正常、失败和修正示例。

避免过度使用表格压缩解释。表格适合比较品牌、工具、市场和成本；机制、操作和排错应使用连续步骤、例子和因果说明。

## 提交前模拟新手

假设读者完全不知道行业默认常识，检查他是否能回答：

- 我明天去哪里开始？
- 我需要注册、下载、购买或准备什么？
- 我会遇到哪些基本类型和术语？
- 第一次完整练习怎么做？
- 我如何判断结果好坏？
- 钱主要花在哪里，最低和推荐预算是多少？
- 当前规则、公告或专业信息去哪里查？
- 哪些动作可能造成健康、法律或资金损失？
- 如果常见错误发生，我知道先检查哪里、如何修正、何时停止吗？
- 我知道哪些“业内常识”会改变购买、学习或实践决策，并知道其证据强弱吗？

只要有一个适用问题仍无法回答，就补充研究或明确列为待核实项，不能用泛泛的行动计划遮盖。
