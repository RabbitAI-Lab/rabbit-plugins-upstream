# 当前资源检索与筛选

当用户需要课程、平台、学校、培训、招聘、协会、展会、比赛、社区、政策或本地机构时，必须联网搜索和验证。不要凭模型记忆生成当前资源清单。

“资源”也包括：原材料、工具设备、品牌/产品线、官方或授权购买渠道、交易/开户入口、行情与公告平台、软件、数据源、交易时间表和费用规则。只要这些会影响用户下一步行动，就必须研究，不能因为用户没有逐项点名而省略。

## 检索顺序

### 线上资源

按以下层次查找，并尽量使用原始页面：

1. 政府、监管机构和行业协会；
2. 官方技术文档和标准；
3. 大学、职业院校公开课程和正规继续教育；
4. 有清晰大纲、师资、实践和退款信息的可信教育机构；
5. 书籍、视频、播客和专业社区；
6. 真实工作案例、正式招聘页和可核实的从业者内容。

为每项候选记录：名称、资源类型、提供方、直接链接、语言、免费/收费、价格口径、大致时间、前置要求、适合阶段、推荐原因、局限、页面/内容更新时间和本次核实日期。

打开并检查最终推荐页；搜索结果摘要本身不算核实。认证价值必须由发证/监管/招聘端证据支持，不能照抄培训方宣传。

把字段完整性视为提交门槛，而不是可选模板。每个具名的当前资源都必须逐项呈现直接链接、页面/内容日期和本次核实日期；页面没有标示日期时写“页面未标示”，不要用文末一个整体核实日期替代各项记录。若正文形式比表格更清楚，在每项末尾使用同等信息的紧凑核实注记。

### 线下资源

先确认用户国家和城市；缺失时标注假设。查找：

- 人社、教育或职业培训官方目录；
- 正规职业学校和继续教育；
- 行业协会、实验室和创客空间；
- 工作室、门店和企业；
- 学徒、助理、实习和见习岗位；
- 行业展会、比赛和公开活动；
- 高校、图书馆和专业社群。

为每项候选记录：机构/渠道、城市/区域、官方入口或联系方式、参与方法、费用及口径、适合阶段、是否有实践和反馈、核实日期和风险提示。核实地点、营业/招生状态和活动日期；地图聚合页或营销转载不应成为唯一证据。

### 采购、平台与信息入口

- 实物技能：先列品类和规格，再找品牌与渠道；优先品牌官网、官方旗舰店、授权经销商、专业供应商和可核实的本地市场。记录单价、规格/容量、是否耗材、兼容性、真假核验和售后。
- 金融/软件/平台操作：先确认用户地区和合法可用性；优先监管机构、交易所、持牌机构查询页、官方产品页和公司投资者关系页。记录开户/注册条件、费用、数据延迟、适用市场和核实日期。
- 公告、规则与行情：分别给入口，说明如何搜索、订阅和验证；不要用一个综合资讯 App 替代法定披露源。

### 从业惯例和内行视角

为了讲清书面规则之外的真实做法，按需检索：

- 多位可识别从业者的长篇教学、访谈或工作复盘；
- 当前招聘任务、服务菜单、预约/售后规则、供应目录和公开报价；
- 顾客评价、投诉、监管处罚、返工争议和产品常见问答；
- 培训机构、品牌/供应商、平台、雇主和从业者对同一问题的不同说法。

先研究各方如何获利，再解释观点。匿名社区帖子只能用来发现检索词或待验证问题；至少用另一立场和一项可观察证据交叉验证。按 `expert-apprenticeship.md` 输出“表面说法—内行检查点—机制—证据—用户行动”，不罗列猎奇传闻。

品牌、平台或机构推荐至少提供选择维度和一个替代项。对安全、资金或高成本决策，不依据销量榜、达人推广、开户链接、返佣或单一评论作推荐。

## 检索词设计

组合使用：

```text
地区 + 官方目录/监管部门 + 职业或技能
地区 + 职业学校/继续教育/公开课 + 技能
地区 + 助理/学徒/见习/实习 + 岗位细分
行业协会/展会/比赛 + 官方 + 年份
技能 + official documentation/curriculum/portfolio review
岗位细分 + careers/jobs + 目标地区
```

需要当前价格、日期或规则时加入当前年份，但最终以页面明确日期为准。

## 默认筛选组合

最终通常只保留：

- 1—3 个零成本入门资源；
- 1—3 个结构化学习资源；
- 1—2 个实践或反馈渠道；
- 1—2 个进阶资源。

说明选择理由、证据等级、适用阶段和不适合的人。不要输出几十个未经筛选的链接；培训机构不是默认必选项。若两项资源功能重复，保留证据更强、更新更近、实践反馈更明确或成本更低者。

上述数量只限制同质候选，不限制必要资源类别。课程、采购、操作入口、官方信息、反馈和机会属于不同功能，不能为了控制链接数量而删掉整个类别。

## 停止检索

当必要类别已有少量可核实候选、关键安全/资质事实有官方依据，并且新增结果不再改变近期行动时停止检索。不要为了填满配额继续找链接；某一类别没有可靠候选时允许留空并给查找路径。

若连续遇到不可访问、重复、过期或低质量页面，停止在该渠道扩展，明确证据缺口，改用官方目录、联系核实问题或用户可执行的搜索词。把剩余不确定性写进输出，不以无限研究掩盖信息不足。

## 无法找到可靠具体资源时

不要填补虚构机构。提供：

- 当地政府网站的具体搜索词和栏目路径；
- 地图软件搜索词与筛选条件；
- 行业协会会员/活动目录入口；
- 招聘网站的岗位关键词和警报设置；
- 展会、比赛的官方报名渠道查找方法；
- 到店、访谈或试听时应询问的问题：资质、师资真实经历、实践比例、反馈方式、总费用、耗材、退费、证书主体、就业数据口径和安全流程。

明确标记“未找到可靠候选”或“需要用户自行核实”。

## 无法联网时

明确写明“以下未实时核实”。只提供平台/机构类型、建议搜索词、筛选标准和核实清单；不提供猜测链接、当前价格、开班日期、岗位数量或政策结论。

## 输出表字段

线上表：`名称｜类型/提供方｜链接｜语言/费用/时长｜前置与阶段｜推荐原因｜局限｜页面日期｜核实日期`

线下表：`机构或渠道｜地区｜官方入口｜参与方法｜费用｜实践/反馈｜适合阶段｜核实日期｜风险提示`

提交前逐项检查：链接已打开；价格/日期/招生或招聘状态没有从摘要猜测；页面日期与核实日期均已填写；费用或页面日期未知时明确写“未标示/需询价”，而不是留空。
