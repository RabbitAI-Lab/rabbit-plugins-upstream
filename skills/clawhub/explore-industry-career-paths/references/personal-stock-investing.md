# 个人股票投资与交易入门清单

用于“学炒股”“怎么买股票”“怎么分析行情”等个人投资学习问题。与 `novice-actionability.md`、`resource-sourcing.md`、`evidence-quality.md` 和 `risk-guardrails.md` 一起使用。内容是教育和研究框架，不是个性化投资建议。

完整教程同时读取 `expert-apprenticeship.md`。不要把安全边界误写成空泛：可以详细教授市场结构、信息检索、财报阅读、图表描述、交易机制、模拟操作和复盘，只是不替用户选择具体证券或承诺结果。

## 先确认边界

区分：长期投资、主动选股、短线交易、量化/程序化研究和证券职业。若用户未说明，默认目标是中国大陆居民以低风险方式学习股票市场基础和模拟交易；指出该假设对可开户市场、税费和交易入口的影响。

涉及真实资金前，询问或明确假设：居住/税务地区、可承受完全损失的金额、时间周期、是否有应急金和高息债务。不得以风险测评替用户决定买卖。

## 零基础市场地图

至少解释并用当前官方来源核实：

1. 股票、基金/ETF、债券、指数、期权等对象的差异；不要因用户说股票就鼓励个股交易。
2. A 股、港股、美股及用户可接触的其他市场：上市地点、币种、交易制度、涨跌/熔断或其他关键规则、结算、费用与主要风险。
3. 各市场正常交易时段、午休、盘前/盘后、时区、夏令时和节假日；用交易所当年日历，说明北京时间换算条件。
4. 主板、创业板、科创板等适用板块及准入差异；只解释与用户当前路径有关的部分。

不要凭记忆写交易时间或规则；引用交易所、监管机构或持牌机构的直接页面并标注核实日期。

## 在哪里开户和交易

回答“在哪里炒股”时至少说明：

- 交易所、证券公司/经纪商、行情软件和信息平台分别扮演什么角色；
- 用户所在地区可合法使用的开户路径、身份/银行卡/税务等前置条件；
- 如何在监管机构或自律组织查询机构牌照和投诉/处罚记录；
- 选择券商/经纪商的比较维度：牌照、可交易市场、佣金与隐性费用、汇兑、最低金额、交易工具、数据权限、客服、资产托管/保护、出入金和税务材料；
- 不把某个券商写成唯一选择，不使用开户链接、邀请码或返佣内容；
- 跨境开户、入金和产品可得性必须按用户身份、地区和当日规则核实。

提供“官方查牌照入口＋比较表＋开户前核对清单”，而不仅是平台名称。

## 交易机制基础

以一次模拟订单为主线解释：

1. 股票代码、报价、买一卖一、价差、成交量和盘口；
2. 市价、限价及当地常见订单类型；
3. 下单、成交、撤单、持仓、结算、分红和公司行动；
4. 佣金、平台费、交易税费、汇兑和滑点；
5. 停牌、涨跌限制、熔断、流动性和盘前/盘后风险；
6. 模拟交易入口及其与真实交易的差异。

规则必须匹配具体市场，不能把 A 股、美股和港股混写。

至少用一组虚构报价完整演示一次模拟限价单：如何读买卖报价、为什么选择订单类型、提交后可能出现哪些状态、什么时候能撤单、成交后成本和盈亏显示为何可能与直觉不同、如何在日志中记录。逐项解释界面字段，不假定用户理解“盘口、价差、成交、持仓、可用资金”等词。

## 信息与公告地图

按用途给出当前直接入口和使用方法：

| 用途 | 优先来源 |
|---|---|
| 上市公司法定披露 | 对应交易所公告检索、法定披露平台、公司投资者关系页 |
| 市场规则与交易日历 | 监管机构和交易所 |
| 财务报表 | 公司年报/季报、招股书及官方披露文件 |
| 宏观和行业数据 | 政府统计、央行、监管、行业协会及有方法说明的数据源 |
| 行情与公司行动 | 交易所、持牌券商或清晰标注数据来源的平台 |
| 新闻和观点 | 可信媒体和研究；与原始公告交叉核对 |

教用户如何订阅公告、按股票代码/公司名检索、检查发布日期和区分公告事实与评论。不能只列“看财经新闻”。

至少完整演示一次信息检索：从交易所或法定披露入口找到一家示例公司的最近定期报告和一份重大公告，指出报告目录中业务、风险、管理层讨论、三张报表和附注在哪里，说明先读什么、为什么、哪些二手解读必须回到原文核对。使用真实公司时只作教学示范，不形成买卖推荐。

## 分析行情的学习框架

同时介绍基本面、估值、市场/行业和技术图表，说明各自回答的问题及局限。

### 基本面

- 公司如何赚钱：产品、客户、收入、成本、现金流和资本需求；
- 财报三表的基本关系；
- 收入质量、利润与现金流差异、负债、稀释和公司治理；
- 同行业比较和周期位置；
- 估值的基本概念和假设敏感性；
- 从公告原文验证，而不是只读二手结论。

给出一组简化的虚构三表数字，演示收入、毛利、净利润、经营现金流、债务和股本变化如何连起来；至少展示一个“利润增长但现金流恶化”或类似反直觉案例，以及新手下一步应查的附注。不能只列财务指标名称。

### K 线和技术图表

至少解释：时间周期、开高低收、实体/影线、成交量、复权、趋势与区间、支撑/阻力的主观性、移动平均等常见工具。用图或逐根示例说明如何阅读，但明确：单个形态不能可靠预测未来，技术指标会滞后、参数可过拟合，必须结合风险、流动性、事件和统计验证。

教授分析流程而不是“看到某形态就买卖”：

```text
定义时间周期与假设 → 查看价格/成交量 → 标记趋势或区间 → 查找公告与事件 → 设定失效条件 → 记录结果 → 用足够样本复盘
```

用具体的虚构开高低收数据画出或描述至少三根 K 线，解释实体、上下影、颜色约定、时间周期、成交量和复权如何改变阅读。展示同一形态在不同趋势/成交量/事件背景下可能有不同含义，给出“观察描述”和“未经验证的预测”之间的区别。

### 行情分析

区分市场指数、行业、公司和事件四层；说明利率、汇率、政策、盈利预期和风险偏好可能如何传导。明确因果是假设，需要数据和反例验证。

## 新手实践路线

至少包含：

1. 建立术语和市场规则卡片；
2. 在官方或可靠平台找到三家公司最近的公告和财报；
3. 完成一家公司业务与三表简析；
4. 完成一张 K 线/成交量的描述性分析，不作价格预言；
5. 使用模拟交易执行限价单、撤单和记录；
6. 建立交易/投资日志：假设、证据、价格、仓位、费用、失效条件、结果和偏差；
7. 至少经过一个预设观察周期和复盘标准后，再决定是否使用极小额真实资金。

评价学习成果以能否解释机制、找到原始信息、计算成本、遵守风险规则和复盘为准，不以短期收益率为准。

提供一份填写完成的研究/模拟交易日志样例和一份空白模板。至少包含：市场与时间、标的仅作教学的说明、研究问题、原始公告、业务/财务摘要、图表观察、可能催化与反例、订单与费用假设、最大可承受损失、失效条件、结果、偏差和复盘。

## 股票学习的内行视角

当次研究并核实以下常见信息差，不要把未经证实的说法包装成内幕：

- 交易 App、财经媒体、券商内容、分析师、自媒体、荐股群和课程各靠什么获利，激励是否与用户收益一致；
- 免费行情的数据延迟、复权、口径和公司行动为何会让不同平台图表/指标不同；
- 公告事实、公司管理层叙事、卖方观点和市场价格反应为何是四件不同的事；
- “低估值、业绩增长、放量突破、热门赛道”等标签可能掩盖哪些反例；
- 频繁交易中佣金、税费、价差、滑点、汇兑、无法成交和情绪成本如何累积；
- 回测、技术形态和成功截图为什么容易产生数据窥探、过拟合和幸存者偏差；
- 普通投资者相对机构在信息、工具、速度和纪律上的真实劣势，以及哪些优势仍可能存在；
- 不同市场的停牌、涨跌/熔断、结算、披露、盘前盘后和流动性规则如何改变同一个策略。

每条用 `表面说法—内行检查点—机制—新手影响—证据—验证动作` 展开。所谓内幕消息、未公开重大信息或规避监管的方法不属于本模块，应明确拒绝。

## 必讲风险与坑

覆盖：本金损失、集中持仓、杠杆/融资、频繁交易成本、流动性、追涨杀跌、内幕消息/荐股群、虚假平台、杀猪盘、数据窥探、过拟合、幸存者偏差、只看 K 线、忽略公告与税费、跨境合规和账户安全。

不得给出具体证券的买卖指令、收益承诺、确定性点位或绕过地区限制的方法。若用户准备投入影响生活的资金，优先建议暂停、补应急储备并寻求合格专业意见。
