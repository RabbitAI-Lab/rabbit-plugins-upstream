# 输出模板

先给结论和行动，再给证据与方法。根据路由选最小充分模板；删除不适用字段，不要机械填满。

## 目录

1. 快速行业说明
2. 完整行业认知报告
3. 职业入行诊断
4. 技能学习教程
5. 线上资源表
6. 线下资源表
7. 7/30/90 天行动计划
8. 最小作品集计划
9. 第一份机会获取计划
10. 行业＋职业＋技能组合报告
11. 多职业对比决策表
12. 零基础操作手册
13. 老师傅带徒式完整手册

## 1. 快速行业说明

```text
路由判断与一句话结论
行业解决什么问题；用户/客户/付费者
价值链与谁赚什么钱
三个底层机制
关键监管/周期/风险
三个术语与一个常见误解
下一步与来源
```

## 2. 完整行业认知报告

```text
结论摘要与适用边界
需求、参与者与三类流动
价值链、商业模式与成本
关键指标与玩家分组
技术、监管和标准
周期、地域和趋势
三个底层机制、术语和误解
争议、未知与反向证据
对用户目标的含义
理解测试、行动和来源
```

## 3. 职业入行诊断

```text
职业细分、主/副类型与匹配结论
真实工作、产出与生活方式
六类门槛（强制/惯例/加分/伪门槛）
用户差距与可迁移能力
稳健/最小成本验证/进取路线
推荐路线、第一份机会与退出条件
```

## 4. 技能学习教程

```text
24 小时起步动作与最低预算
可验证能力目标与最低合格线
基础对象、术语、分类和完整流程
能力树、依赖与暂时不用学
工具/材料/账户：规格、品牌或平台候选、渠道、最低/推荐/不建议购买；成本
线上/线下学习、官方信息和实践入口
模仿 → 独立练习 → 反馈 → 修改 → 真实任务
每个项目的完成标准
最小作品/证明与第一次真实反馈
7/30/90 天与长期计划
风险、待核实项和来源
继续/调整/停止标准
```

## 5. 线上资源表

```text
名称｜类型/提供方｜直接链接｜语言/费用/时长｜前置/阶段｜为什么选｜局限｜页面日期｜核实日期
```

先给筛选逻辑；默认控制为少量零成本、结构化、实践反馈和进阶资源。

## 6. 线下资源表

```text
机构/渠道｜地区｜官方入口/联系方式｜参与方法｜费用｜实践与反馈｜适合阶段｜核实日期｜风险提示
```

找不到可靠机构时，用具体查找路径和到访问题清单替代。

## 7. 7/30/90 天行动计划

```text
阶段｜可交付成果｜练习/真实任务｜反馈事件｜时间/费用｜通过标准｜未通过时调整
```

7 天验证兴趣与任务，30 天达到最低线，90 天形成证明并接触机会，长期建立专长和信誉。

## 8. 最小作品集计划

```text
目标机会与评价者
作品 1—3：问题/约束、能力、过程、产出、反馈、修改、完成标准
呈现顺序与媒介
版权、隐私和协作说明
缺口与下一次评审
```

## 9. 第一份机会获取计划

```text
目标机会与最小可信证明
目标名单/渠道和选择理由
提交材料与联系话术要点
每周数量、跟进和反馈记录
低风险试单/见习/投稿的范围与验收
成功、调整和停止信号
```

## 10. 行业＋职业＋技能组合报告

```text
路由、结论与默认假设
与入行相关的简化行业背景
职业细分、真实任务和门槛
能力差距、学习阶梯和资源
推荐路线、作品证明和第一份机会
阶段计划、预算、风险与退出条件
证据与待核实项
```

只有用户需要系统行业认知时，才把简化行业背景升级为完整行业报告。

## 11. 多职业对比决策表

```text
方向｜真实核心任务｜强制/能力门槛｜证明与机会｜入门时间/费用｜生活方式｜当地需求证据｜可逆性｜与用户匹配证据
```

先排除触碰硬约束的方向，再指出关键取舍和信心等级。为前两名各设计一个 7 天可逆实验；不要用没有依据的总分代替判断。

## 12. 零基础操作手册

用于“教我怎么做”“零基础开始”以及会发生采购、开户、交易、真人服务或开店的请求。

```text
结论、默认假设与未来 24 小时三步
目标边界与相邻方向
基础对象/术语/分类地图
在哪里学习、操作、购买和获取当前信息
工具材料或账户平台清单（规格/数量/档位/渠道/成本/替代/避坑）
从准备到完成、检查、记录和善后的基础流程
方法/手法/分析框架及其适用场景和局限
三个递进练习、合格标准、反馈与回退动作
7/30/90 天路线和预算
真实机会或下一阶段验证
风险、来源、核实日期与待核实项
```

先用一页式起步清单降低行动门槛，再展开完整手册。不能用通用建议替代领域分类、采购/平台和操作细节。

## 13. 老师傅带徒式完整手册

用于用户明确要“教会我”“掰开揉碎”“看完就能上手”或同时涉及行业、技能和商业目标的请求。

```text
一页导航：目标、边界、先做三步、不得越过的安全线
全景地图：对象、术语、参与者、分类、完整流程
白话基础课：每个概念是什么、为什么、在哪里遇到
第一次完整示范：准备 → 步骤与理由 → 检查 → 错误修正 → 记录
工具/材料/账户/信息源：选择逻辑、具体候选、渠道、成本、替代和坑
方法深挖：每种基础方法的用途、操作/分析、质量标准、失败诊断
内行视角：表面说法 vs 实际检查点、利益、隐性成本、惯例与证据
完整样例＋可复用空白模板
三组递进练习、反馈来源和通过标准
7/30/90 天、第一份机会/真实验证和长期路线
风险、例外、来源、核实日期与仍需线下指导之处
```

表格只用于比较；重要机制和操作必须用步骤、例子和排错说明。结尾用复述题、操作题和异常诊断题检验是否真正学会。
