# 职业入行模块

## 先识别职业类型

为职业选择一个主类型，可附多个副类型，并说明判断依据：

| 类型 | 机会通常由什么决定 | 典型证明 |
|---|---|---|
| 雇佣技能型 | 岗位任务、团队匹配和招聘流程 | 项目、工作样本、面试任务 |
| 资质准入型 | 法定学历、考试、执照或注册 | 官方资质与受监管实践 |
| 手艺师徒型 | 安全熟练度、重复实践和现场信任 | 实操记录、师傅评价、客户结果 |
| 创意作品型 | 作品质量、品味、项目协作和版权 | 作品集、样稿、入选或项目经历 |
| 平台创作者型 | 持续内容、受众关系和平台分发 | 内容库、留存/转化数据、合作案例 |
| 自由职业/创业型 | 获客、交付、口碑和现金流 | 付费案例、复购、标准化服务 |

不要用类型替代具体职业事实。同一职业可能同时是创意作品型和自由职业型。

## 分析六类门槛

1. **硬性门槛**：学历、法定执照、证书、地域、语言、年龄或身体条件。
2. **能力门槛**：入门者必须能独立完成的真实任务及质量、速度和安全标准。
3. **证明门槛**：作品集、项目、实习、账号数据、客户案例、推荐或考试结果。
4. **机会门槛**：招聘、投稿、师承、经纪、工会/协会、平台规则和行业关系。
5. **经济门槛**：培训、设备、搬迁、无收入/低收入期和失败试验的成本。
6. **生活方式门槛**：工时、出差、身体负担、情绪劳动、心理压力和收入波动。

为每项门槛标记：

- **强制**：法律、监管、学校或用人机构明确要求；给出适用地区和官方来源。
- **惯例**：多数机会实际偏好但并非法律要求；用招聘样本或行业资料说明。
- **加分项**：提高竞争力但可替代。
- **伪门槛**：主要来自培训营销或个别叙事，缺乏机会端证据。

## 建立职业画像

说明日常真实任务、主要产出、协作对象、质量标准、典型场景、成长分支、收入结构和生活方式。区分“看起来吸引人的部分”和占用大多数时间的工作。

用一个真实工作日或完整项目示范：任务从哪里来、先看什么、使用什么工具、与谁确认、怎样交付、如何被评价、常见返工是什么。对入门者至少展开一个具体任务到“准备—执行—检查—提交—反馈—修改”的粒度。

读取 `expert-apprenticeship.md`，补充职业的隐性筛选规则：招聘描述没有写但机会端实际重视的证据、培训机构容易夸大的部分、工资/报价之外的无偿时间和成本、师傅或主管判断新人是否靠谱的细节，以及新人获得第一份机会时常见的利益和关系结构。不得把个别从业者经历写成普遍内幕。

涉及当前招聘时，抽样目标地区的真实职位页；标记样本数量、日期和偏差，不把少量职位当作整个市场。

## 设计至少三条路线

| 路线 | 核心策略 | 常见适用人群 |
|---|---|---|
| 稳健路线 | 先补强制条件和基础能力，再通过正规教育、实习或相邻岗位进入 | 风险承受低、需要稳定收入或职业受监管 |
| 最小成本验证路线 | 用短周期练习、访谈、跟岗/志愿任务和小作品验证兴趣与能力 | 方向未定、预算有限或在职转行 |
| 进取路线 | 高密度训练、集中作品、主动建立关系并快速争取真实项目 | 时间充足、承受波动且已有可迁移能力 |

每条路线必须写明：适合人群、前置条件、时间范围、费用范围与口径、能力证明、第一份机会、最大风险、阶段检查点以及调整/退出条件。避免给出无法支持的精确成功率。

## 找到第一份机会

1. 定义最小可信证明：一个雇主、编辑、师傅、客户或平台能够评价的真实产出。
2. 从低风险机会开始：公开任务、模拟委托、志愿项目、助理/见习、投稿、竞赛、开源贡献或小额付费试单。
3. 针对机会端反推材料：职位要求、投稿规则、门店任务或客户验收标准。
4. 建立反馈闭环：提交 → 获取具体评价 → 修改 → 再提交，并记录证据。
5. 设定数量与质量目标，但不鼓励垃圾式群发。

## 决策输出

最后回答四个问题：

- 用户与真实工作内容是否匹配，证据是什么？
- 最大缺口属于哪一类门槛？
- 哪条路线最适合当前约束，为什么？
- 在投入更多钱或辞职前，下一项可逆验证是什么？
