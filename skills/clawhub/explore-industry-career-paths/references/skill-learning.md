## 把目标写成可验证成果

把“学会 X”改写为：“在给定工具、时间和质量约束下，独立完成某个真实产出，并由目标受众按明确标准评价。”

示例结构：

```text
能力目标 = 真实任务 + 使用情境 + 完成标准 + 时间限制 + 外部评价者
```

不要把看完课程、记住术语或购买设备当作掌握技能。

## 建立能力树

1. 从目标机会的真实任务反推 3—7 个核心能力。
2. 为每个能力标出前置知识、工具、练习、常见错误和验证方式。
3. 标出初学者最低合格线：安全、正确、完整、可解释和可重复达到的最低标准。
4. 单列“暂时不用学”：不会阻止首个真实作品或机会的高级理论、昂贵工具或边缘技能。
5. 区分可迁移能力、领域知识和具体软件操作，避免把会用软件等同于专业能力。

在能力树之前先补一张“领域基础地图”：基本对象/部件、常见分类、基础术语、典型流程、工具或账户、质量/分析方法以及官方信息入口。用户如果连“会遇到什么”都不知道，不能直接进入周计划。读取 `novice-actionability.md` 做完整性检查。

每个能力必须展开到可教学的动作或判断。例如“掌握基础美甲”要拆成具体手法、款式和质量点；“学习股票分析”要拆成市场机制、公告/财报、基本面、K 线/成交量、费用和风险记录。不要保留只有领域专家才能自行补全的抽象标签。

## 选择工具和材料

对每类工具给出：

- **最低配置**：足以安全完成入门练习的现有或低成本方案；
- **推荐配置**：通过初步验证后能明显提升效率或质量的方案；
- **不建议购买**：价格高、学习阶段不需要、锁定平台或营销大于价值的项目。

分别估算一次性成本和持续成本，写明币种、地区、日期、是否含耗材/订阅/维护。价格会变化时必须实时核实或明确未核实。

材料密集型技能必须输出可购买物料表：品类、用途、规格/兼容性、数量、预算档、候选品牌/产品线、官方或授权渠道、当前价格、消耗周期、替代项和避坑。数字型技能也要输出操作资源表：软件/账户/数据源、适用地区、费用、注册条件、官方入口和替代项。

## 设计学习阶梯

严格沿以下闭环推进：

```text
知识 → 模仿 → 独立练习 → 外部反馈 → 修改 → 真实任务 → 能力证明
```

为每个层级给出：

1. 一个具体练习或项目；
2. 可观察的完成标准；
3. 时间盒和允许使用的帮助；
4. 反馈来源；
5. 失败后的修改动作；
6. 可保存的过程或结果证据。

在列练习前，先教会完成练习所需的基础流程和评价方法。不要让用户仅凭一个任务名称自行猜测操作步骤。

对完整教程，在用户独立练习前先提供一份老师示范：逐步写出动作、当下观察、判断理由、正常/异常信号和修正。再提供一份填写完成的练习记录样例及空白模板。读取 `expert-apprenticeship.md`，把老师傅的排错顺序和隐性质量标准纳入学习，而不是只增加练习数量。

至少包含三个逐级项目：受控模仿、独立变体和真实约束任务。创意领域不得把临摹冒充原创；可将临摹标注为研究练习，不放进对外原创作品集。

## 获取反馈

优先顺序：明确量表的自检 → 同伴互评 → 教师/从业者点评 → 真实用户或目标受众反馈 → 雇主/客户验收。

提问要具体，例如“哪一步不符合卫生流程”“哪个交互让你无法完成任务”“这段样稿的人物动机在哪里断裂”，不要只问“好不好”。保存修改前后版本和反馈来源。

## 建立最小能力证明

只保留能证明目标能力的 2—5 项材料：问题与约束、过程选择、最终产出、评价标准、反馈、修改和结果。为每项说明它对应哪类机会，不追求数量。

最低作品集应让评价者在短时间内回答：用户能做什么、在何种约束下完成、质量如何验证、是否能协作和修改。

## 制定阶段计划

### 7 天：验证任务与兴趣

- 完成一个极小真实产出；
- 观察至少两个真实工作样本或岗位/客户需求；
- 获得一次外部反馈；
- 记录喜欢、困难、风险和继续条件。

### 30 天：达到最低合格线

- 完成核心知识和受控模仿；
- 独立完成 2—3 个递进练习；
- 建立反馈—修改记录；
- 形成第一项可展示证明。

### 90 天：接近真实机会

- 在真实约束下完成项目；
- 形成最小作品集或能力证明；
- 接触目标雇主、客户、平台、门店、社区或投稿渠道；
- 复盘投入、质量、反馈率和下一阶段缺口。

### 长期：专长与机会复利

- 持续真实项目、复盘和专业反馈；
- 补充阻碍晋级的理论或资质；
- 建立信誉、协作网络和可迁移资产；
- 定期检查行业、工具和平台变化。

计划必须适配用户每周时间、预算和生活约束。用交付物和反馈事件标记进度，不以课程章节标记进度。

## 第一次真实反馈与机会

根据目标选择：公开作品挑战、社区评审、从业者付费点评、志愿任务、助理/见习、开源项目、模拟客户任务、投稿、小额试单、门店面试任务或用户测试。说明联系对象、提交内容、询问方式、数量目标和隐私/版权边界。

## 继续、调整或停止

- **继续**：能稳定达到阶段标准，外部反馈逐步改善，真实任务仍有兴趣且成本可承受。
- **调整**：某个细分方向或学习方式不匹配，但相邻能力有正反馈；缩小目标或换反馈渠道。
- **暂停/停止**：触碰健康、法律或财务红线；多轮真实反馈无改善且不愿继续；生活方式不可接受；投入超过预设上限。

在投入昂贵培训、设备或辞职前，必须先设置一个低成本检查点。
