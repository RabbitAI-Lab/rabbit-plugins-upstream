# 转行创业导师

一个面向中文零基础用户的 Codex Skill。它不只回答“这个行业是什么”，还会把转行、学技能、求职、接单或创业的模糊想法，推进成一轮可验证的现实行动：

```text
判断方向 → 7 天低风险实验 → 带证据复盘 → 修正路线 → 作品 / 第一份机会 / 第一位客户
```

## 适合谁

- 不知道某个行业或职业是否适合自己；
- 想从零学一项技能，并走到就业、接单或开店；
- 想转行，但分不清岗位、门槛、作品和求职证据；
- 想做副业或创业，需要先验证客户、交付与单次经济；
- 已经行动过，希望根据结果继续复盘，而不是每次重新问一遍。

它不会替用户做个性化荐股，不保证就业、客户、流量、营收或投资收益，也不会把培训证书包装成法定资质。

## 和直接问大模型的区别

1. **先路由**：区分行业认知、职业入行、技能学习和商业验证，避免答非所问。
2. **从零可执行**：要求讲清去哪里、用什么、怎么做、如何判断做对以及失败后怎样修正。
3. **先验证再重投入**：一般宽泛问题默认给 7 天低风险实验，不急着报课、租店或投广告。
4. **证据与风险底线**：当前价格、政策、课程、平台和本地资源要实时核实；高风险领域有明确边界。
5. **能接着用**：每轮留下进度卡。用户把行动证据带回来后，只处理当前最大瓶颈。

## 五种模式

| 模式 | 适用问题 | 默认交付 |
|---|---|---|
| 快速判断 | 值不值得、适不适合、有没有机会 | 结论、关键不确定性、7 天实验 |
| 系统入门 | 零基础、教会我、完整教程 | 基础地图、示范、练习、评价与排错 |
| 转行求职 | 入行、找工作、岗位要求 | 真实任务、能力差距、作品证据、第一份机会 |
| 创业验证 | 接单、副业、开店、一人公司 | 客户问题、最小供给、单次经济、停止线 |
| 继续复盘 | 我做完了、卡住了、继续上次 | 证据判断、唯一瓶颈、下一轮实验 |

## 质量验证

- 50 条回归输入覆盖行业、职业、技能、创业、歧义和风险恢复场景；
- 对照同一模型的普通回答与加载 Skill 后的回答，按任务匹配、内容质量、行动价值、证据风险和连续性五个维度评分；
- 编造事实、保证结果、危险操作、空泛零基础教程和忽略用户进度，均记为关键失败。

SkillHub 的 TRACE AI 自动评测曾给出 4.5/5（2026-09-01）。该分数只代表当时版本与自动化评测结果；v1.1 的真实提升仍应通过同模型对照测试和用户复用数据验证。
