# 转行创业顾问（Career Switch & Startup Advisor）

把「转行」和「创业/开店/做副业」的模糊想法，拆成行业地图、能力路线、真实成本、隐性惯例、第一份机会与低成本验证实验，输出零基础者能直接照着做的第一步。

## 这个技能能做什么

- **A 行业认知**：解释行业需求、价值链、商业模式、指标、玩家、技术、监管、周期与趋势
- **B 职业入行**：识别职业类型、门槛、路线、能力证明与第一份机会
- **C 技能学习与资源**：把目标转成能力树、分级练习、反馈机制、作品集与行动计划，并检索当前课程/机构/渠道
- **D 商业验证与第一份机会**：为接单、开店、自媒体、自由职业或创业设计低成本真实实验，给出「继续/修改/停止」判断信号

## 设计原则

- **先路由，再执行**：先识别对象与意图，再选最小充分的回答深度
- **新手可行动性门槛**：零基础用户至少要知道——在哪里学、用什么买什么、成本怎么分层、流程是什么、怎么判断做对、当前信息从哪核实、风险是什么、下一步做什么
- **解释而非点名**：讲清「是什么、为什么、具体怎么看怎么做、做对的信号、常见失败与修正」，并给出完整示范案例
- **证据分级 + 风险边界**：关键事实就近标注来源与可信度层级；涉及价格、政策等易变信息必须联网核实并标注核实日期；不编造链接；无法给确定答案时明确说出不确定性
- **老师傅带徒式讲解**：宁可多写步骤，不删掉完成第一次实践所需的知识

## 使用方式

在 WorkBuddy / OpenClaw 对话中直接提问即可触发，例如：

- 「零基础想学美甲接单，要买什么、学多久、怎么找第一单？」
- 「我想从互联网运营转行做宠物烘焙，值不值？第一步做什么？」
- 「开一家社区咖啡店，房租 8000，一天要卖多少杯才不亏？」
- 「我想搞副业做跨境电商，怎么用 500 块先验证有没有需求？」
