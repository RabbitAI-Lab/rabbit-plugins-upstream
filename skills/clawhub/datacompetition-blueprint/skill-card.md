## Description:

Use when working on data science competitions (Kaggle, CCF BDCI, DCIC, etc.) to build from baseline to topline solutions, covering data processing, feature engineering, model building, training techniques, and model fusion strategies.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and data science competitors use this skill as a reference for improving competition solutions from baseline models to stronger leaderboard submissions. It provides guidance and examples for data cleaning, feature engineering, model training, validation, ensembling, and post-processing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Competition-optimization guidance could be applied directly to production ML systems without appropriate validation, monitoring, security, and deployment review.

Mitigation: Use the skill as a competition reference; perform separate production validation, monitoring, security, and deployment review before applying any approach to production ML systems.

Risk: Example modeling snippets and leaderboard tactics can produce data leakage, overfitting, or misleading performance estimates if copied without task-specific validation.

Mitigation: Use proper cross-validation, leakage checks, independent validation data, and review of generated code before training or submitting models.
