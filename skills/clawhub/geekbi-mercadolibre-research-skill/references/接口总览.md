# Mercado Libre 接口总览

| 能力 | 脚本 | OpenAPI |
| --- | --- | --- |
| 站点解析 | `mercadolibre_site_list.py` | `/api/v1/mercadolibre/site/ai-list` |
| 商品搜索 | `mercadolibre_goods_search.py` | `/api/v1/mercadolibre/goods/ai-search` |
| 商品详情 | `mercadolibre_goods_info.py` | `/api/v1/mercadolibre/goods/ai-info` |
| 店铺搜索 | `mercadolibre_mall_search.py` | `/api/v1/mercadolibre/mall/ai-search` |
| 店铺详情 | `mercadolibre_mall_info.py` | `/api/v1/mercadolibre/mall/ai-info` |
| 类目列表 | `mercadolibre_category_list.py` | `/api/v1/mercadolibre/category/ai-list` |
| 类目父链 | `mercadolibre_category_info.py` | `/api/v1/mercadolibre/category/ai-info` |
| 评论搜索 | `mercadolibre_review_search.py` | `/api/v1/mercadolibre/review/ai-search` |

所有接口复用极鲸云 Agent Bearer 登录态。商品、店铺和评论最多访问前 200 条；类目仅为当前 ES 商品样本覆盖。
