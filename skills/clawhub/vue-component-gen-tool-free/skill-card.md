## Description: <br>
Vue组件生成(免费版) helps developers generate Vue 3 single-file component templates with Composition API, Options API, TypeScript, and optional SCSS support. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers use this skill to draft Vue 3 component code for personal projects, learning, and small applications. It is suited to explicit Vue component generation tasks that need template, script, style, props, emits, TypeScript, or SCSS scaffolding. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill declares write and exec capabilities, so an agent may propose file changes or npm and shell commands while scaffolding Vue components. <br>
Mitigation: Use it for explicit Vue component tasks, review generated files before committing them, and approve shell commands only when they match the project intent. <br>
Risk: Broad trigger wording may cause the skill to activate for loosely related coding requests. <br>
Mitigation: Invoke it only when Vue 3 component generation is the intended task and confirm the requested API style, TypeScript use, styling mode, and output path. <br>
