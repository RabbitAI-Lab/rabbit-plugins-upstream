# 项目任务与里程碑看板

[English](README.md)

管理项目、任务依赖、负责人、截止日期和工时，输出任务看板、逾期清单和日历文件。

## 功能

管理项目、任务依赖、负责人、截止日期和工时，输出任务看板、逾期清单和日历文件。

在当前助手的工作区运行，输出处理结果和报告，原文件保留。

## 用法示例

安装后，把任意一条发给 AI，并附上相关文件或网址。

```text
新建网站上线项目，拆成设计、开发、测试三项，测试要等开发完成。
```

```text
列出本周逾期和被前置任务阻塞的事项，按负责人汇总剩余工时。
```

```text
把项目里未完成任务的截止日期导出成日历，并生成一份任务表。
```

## 运行要求
