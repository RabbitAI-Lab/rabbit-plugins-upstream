## 零、先判环境（情绪周期）（2026-09-23 新增）

> **选股是末端。先看市场在什么周期，决定"做不做、做多重、做什么模式"。**
> 完整手册见 `references/emotion-cycle.md`；一键工具：`python3 skills/trading-desk/scripts/emotion.py [YYYYMMDD]`。

**顺序**：`emotion.py 定环境` → `定模式与仓位` → `锁主线` → `挑位置` → `计划卡` → `次日执行`。

- **环境四指标**：涨停/跌停家数、最高连板高度、封板率、**昨日涨停今日溢价+晋级率**（赚钱效应核心）。
- **五阶段**：冰点 / 启动回暖 / 发酵 / 高潮 / 退潮。对应仓位：0~2 / 3~5 / 5~7 / 5~6递减 / ≤2 成。
- **退潮、冰点、混沌期**：**低位低吸为主、禁止高位接力、宁可空仓**（胜率优先）。
- **主线与梯队**：先锁涨停最集中的主线，再分 龙一/中军/跟风；只做龙一与低位补涨，**不碰高位跟风**。

## 一、短线选股：有效形态

短线逻辑：**资金推动 + 形态启动 + 次日溢价**。顺序是 **①环境（见第零节）→ ②主线梯队 → ③位置 → ④形态 → ⑤资金**。

### 0. 位置优先（最重要，2026-09-23 新增）
同一只票，位置不同、生死不同：
- **启动位**（✅最安全）：平台/缩量整理后**首次温和放量**启动（当日涨幅 2~5%、量能环比 1.2~2 倍）；或强势股回踩不破关键位。
- **加速位**（⚠️高风险高收益）：缩量加速涨停 → 打板参与，必须轻仓 + 快进快出。
- **兑现位**（❌禁买）：当日涨幅 >5% / 量能环比 >2 倍 / 换手骤升 / 长上影 / 炸板 → **获利盘次日要跑，这是接盘位**。
- **硬规则**：**当日涨幅 >4% 且 量能环比 >1.5 倍**的票，一律**只观察不推荐**（除非启动/发酵期的主线龙一且有明确打板逻辑）。
  > 教训（9/22-9/23）：北方铜业、网宿科技当天已大涨+放巨量被选入 → 次日双双冲高回落。失败根因是**位置（买在兑现位）**，不是赛道。

### 1. 旱地拔葱（竞价/早盘异动）
- 高开放量（量比 > 2），资金净流入前排，突破平台。
- 关键：**不能一字板**（买不进），要能上车；大盘配合。

### 2. N字爆发（二次启动）
- 放量突破前高 → 回撤不破突破点 → 再次放量上攻。
- 买点在"回撤企稳再放量"处，止损设在突破点下方。

### 3. 一阳穿三阴（反转）
- 连续 3 根阴线后，一根大阳线吞掉前 3 根高点，成交量放大。
- 适合超跌反弹，止损设在阳线实体下沿。

### 4. VCP/缩量整理突破
- 高位横盘缩量、波动收敛后放量突破。
- 需板块效应配合，单票突破易假。

### 各阶段优选模式（详见 emotion-cycle.md 第三节）
- 启动/发酵期 → 打板（主线龙一首/二板）、弱转强接力。
- 发酵/高潮/混沌期 → 分歧低吸（分水岭 **+0 轴**，跌破不做）。
- 退潮期 → 只做总龙头反抽/龙回头，或空仓。

### 排除项（必剔除）
- 高位放天量滞涨、连续一字/连板透支、纯题材无资金、ST/退市风险、"N"字新股首日。
- **当日炸板（触涨停未封）/ 长上影 / 天量（量>前5日均量×2）** → **次日一律降级**（只观察不买入）。用 `risk_flags.py` 自动标。
- **资金流为「单日脉冲」**（近3日仅一日为正）而当日净额巨大 → 降级（次日获利抛压大）。用 `money_flow.py trend` 判定。

## 二、仓位与止损纪律

- 单票仓位上限：**10%~20%**（视把握度分档），总短线仓不超过约定上限。
- **止损**：跌破买入逻辑位（形态破坏/突破点/阳线实体下沿）无条件走，单笔亏损控制在 **-3%~-5%**。
- **止盈**：达到目标位、或次日冲高走弱即走；不恋战。"今天买、次日短线获利就走"。
- 不补仓摊低成本（短线大忌）；不打无准备之仗，没止损位不下单。

## 三、期货方向分析框架

### 判断步骤
1. **趋势**：日线均线排列（多头=MA5>MA10>MA20；空头反之）；顺势为主。
2. **位置**：标出近期关键支撑/压力（前高前低、缺口、整数关口）。
3. **持仓量**：
   - 增仓上涨 → 多头主动进攻，趋势强；
   - 增仓下跌 → 空头强；
   - 减仓上涨/下跌 → 多为平仓反抽，趋势不牢，谨慎。
4. **量价**：放量突破关键位可信；缩量到关键位易假。
5. **联动**：黑色看地产/基建政策；有色看美元/伦铜；农产品看天气/库存；原油看地缘/OPEC；股指看 A股情绪与北向。

### 输出格式
`品种 | 方向(偏多/偏空/观望) | 入场区间 | 止损 | 目标 | 逻辑`

- 不给"绝对"，给**倾向 + 条件**（例如"站上 X 偏多，跌破 Y 转空"）。
- 止损必须明确；震荡不参与（观望也是决策）。

## 四、资金流正确用法（2026-09-22 新增）

> 教训：光看「当日主力净额」是**滞后指标**（只说明昨天谁在买），预判不了次日抛压。
> 案例：9/21 彩虹股份主力净 +5.15 亿、入选；次日高开冲高回落、主力净流出 1.34 亿 → 冲高减仓/出货。

### 三条规则
1. **看趋势不看单日**：用近 **3 日**主力净额——**连续流入**才算强；**单日脉冲**（近3日仅部分为正）降级。
   `money_flow.py trend <code> 5`
2. **标注口径**：写进理由时一律标「**主力净额 +X亿（昨日，滞后）**」，不得当前瞻信号。
3. **次日开盘必须复核**：9:25~10:00 跑 `nextday_check.py <code>:<买价>:<止损>`，用「实时价 + 分时主力」定 留/减/走；拿不准用 `money_flow.py intraday`。

### 口径提醒
- 东财/新浪只公布 **净额（买入−卖出）**，**没有**「总流入/总卖出」绝对值；
  要精确主力总买卖需付费 Level-2 逐笔。
- **主力 = 超大单+大单**；**散户 = 中单+小单**；各净额之和 ≈ 0。
- 昨天主力**净买** X、今天主力**净卖** Y → 昨天进场的钱**还剩约 X−Y 没走**（判断是否“没出完”的依据）。

## 五、风控红线

- 杠杆品种（期货）**仓位轻、止损硬**；连续亏损后降低频率，不报复性交易。
- 每笔交易**先定止损再入场**。
- 单日/单周亏损达阈值即停手复盘。
- 一切分析仅供参考，盈亏自负。

## 六、日内灵敏指标组合（期货）（2026-09-22 新增）

> 核心认知：**没有“最灵敏的指标”，只有“最灵敏的用法”**。越灵敏 = 假信号越多。
> 正确姿势是分工：**灵敏指标找入场时机 → 慢指标定方向 → 量仓做确认**。

### 灵敏度排行（快到慢）
1. **盘口挂单 / 逐笔大单**（★★★★★）：最灵敏，能提前几秒看出砸盘/扫单；**骗单多**，需 Level-2。
2. **分时均价线（VWAP）+ 1分钟K 的 MA5/MA10**（★★★★★）：**最快、最不做假**。价在均价线上=多头掌控，跌破=转弱。日内首选。
3. **持仓量变化**（★★★★）：**期货独有**。增仓+价涨=多头进攻；增仓+价跌=空头进攻；**减仓上涨/下跌=平仓盘，不追**。
4. **KDJ（9,3,3 或更短）**（★★★★）：最灵敏的震荡指标，**假信号最多**、趋势中会钝化。
5. **MACD（缩参 6,13,5）**（★★★）：缩参才灵敏，默认 12,26,9 偏慢。
6. **RSI / CCI**（★★）：辅助。
7. **日线 MA / MACD**（★）：慢，但**定方向**用。

### 日内默认组合（给期货方向时自动带上）
- **方向**：日线 / 4小时趋势
- **入场**：1分钟价**站上/跌破分时均价线** ＋ **持仓量同步增** ＋ KDJ 金叉/死叉
- **止损**：固定点位 或 **ATR(14) × 1.5**
- **过滤**：**减仓行情不追**；**跨品种背离先查成本路线**（油制 vs 煤制，见下）

### 能化系成本路线速查（解释“反着来”）
- **油制（挂原油）**：塑料 LLDPE、PP、乙二醇 EG、PTA、沥青 → 原油大跌时**领跌**。
- **煤制/电石法（不挂原油）**：PVC、甲醇（煤头）、纯碱（联碱/氨碱）、玻璃 → 原油消息对它们**影响小**，走自身产业逻辑（开工/库存/地产）。
- → 原油异动时，油制与煤制品种**分道扬镳**属正常，不是背离。
