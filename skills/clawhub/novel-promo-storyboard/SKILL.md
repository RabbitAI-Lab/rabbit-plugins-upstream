# 小说推文分镜

当前 AI 必须阅读用户提供的实际原文，并按用户目标完成推广方案。`scripts/self_test.py` 不分析原文、不抽取人物、不生成标题、口播、镜头或 CTA；它只校验 AI 已写好的 JSON 并排版 Markdown。不得把脚本自测、示例或格式校验说成已完成改编。

## 输入和用户意图

用户可提供小说章节/梗概，以及平台、受众、推广目标、期望时长、画幅和 CTA 偏好；也可明确要求无口播。直接阅读用户提供的文本或文件，不要求用户先整理证据表。将明确提供的需求原样记录在 `user_intent`；没有提供的字段设为 `null` 并列入 `not_provided`，不得假定目标平台、受众、时长或推广目的。

## 实际创作

1. 明确原文范围，读完当前材料后选出一条适合该范围的推广主线。标题、钩子、口播与字幕须忠于原文；用简短 `source_anchor` 标明人物事实、情节和口播依据。
2. 原文没有交代的关系、动机、地点、时间、因果和结局标为未说明或写入 `source_notes.gaps`。不把推测包装成原作事实。
3. 创作性画面、过渡、声音、音乐和旁白补充放在 `creative_note` 或对应来源类型中，与原文锚点分开。引用锚点用于回读，不代表脚本验证了内容真实。
4. 推广分镜必须至少包含一个镜头。需要口播时逐段安排 `voiceover` 的 `start/end` 时间；用户要求无口播时 `voiceover` 使用空数组，镜头 `voiceover_ref` 设为 `null`。逐镜头安排画面 `start/end`、字幕、声音提示及来源锚点；检查时间不重叠、引用有效，方案总时长与两条时间线相符。
5. 行动引导不使用固定 CTA。用户要求时标为 `user_requested`；AI 认为适合并作为建议提出时标为 `agent_suggestion`；未要求、也无需建议时标为 `none` 并留空。不能把 AI 建议伪装成用户意图。
6. 尚有关键事实或用户目标待确认时使用 `needs_review` 并列明缺口；缺少可改编文本时使用 `needs_more_source`，只说明需要什么材料；只有已完成且无待确认缺口才使用 `complete`。
7. 需要文件时，AI 先写完整 `promo-package.json`，再运行脚本。脚本报错则修 JSON；不得回退到硬编码模板。

## 输出字段与命令

结构定义见 [输出字段](references/output-schema.md)。虚构示例只演示格式，不是自动生成的成品。

```bash
python3 scripts/self_test.py self-test
python3 scripts/self_test.py render --input /absolute/ai-promo-package.json --output /absolute/new-output-dir
```

输出包含用户意图、标题候选、开头钩子、人物卡、场景卡、口播时间线、画面与声音时间线、CTA 来源状态和待确认项。脚本只校验字段类型、时间关系、引用编号与输出文件，不判断原文真实性、创作质量、平台规范或推广效果。已有输出文件会阻止覆盖；输入 JSON 和用户原稿不会修改。

## 边界

- 不承诺爆款、收益、涨粉或平台审核结果。
- 不复刻其他账号的独特标题、台词或长段落；改编以用户有权使用的材料为前提。
- 涉及未成年人性内容、现实伤害教程、违法操作或仇恨煽动时停止并建议安全替代主题。
