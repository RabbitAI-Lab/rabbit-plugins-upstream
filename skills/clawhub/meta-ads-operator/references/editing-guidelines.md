# Editing Guidelines

## Safe edits
- reduzir budget
- corrigir metadata
- corrigir naming
- corrigir UTM
- pausar para conter risco

## Approval edits
- trocar objetivo
- aumentar budget acima de `10%`
- trocar audiencia de forma estrutural
- mudar evento de conversao
- editar varias variaveis criticas ao mesmo tempo

## Decision tree
- pequena correcao -> editar existente
- nova tese de publico -> criar novo conjunto
- nova tese criativa -> criar novo anuncio ou criativo
- mudanca quase igual -> duplicar com alteracao minima
- mudanca estrutural -> aprovar antes
