# Ad Set Structures

## Decision matrix

### ABO vs CBO
- `ABO`: use para validacao de tese e controle por audiencia
- `CBO`: use para escala, consolidacao de sinal e disputa entre conjuntos vencedores

### Broad vs Interest vs Lookalike
- `Broad`: bom ponto de partida quando ha pixel forte, oferta clara e criativo capaz de segmentar
- `Interest`: util quando a conta precisa de ancoragem tatica inicial
- `Lookalike`: util para partir de sinais de compradores, leads qualificados ou engajamento forte

### Remarketing windows
- `1D-7D`: alta intencao
- `8D-30D`: medio calor
- `31D-90D`: recuperacao ou reforco de prova

## Suggested structures
- Prospeccao: `1 a 3` conjuntos por grande tese
- Remarketing: janelas separadas por intensidade
- Evite fragmentacao sem ganho de leitura

## Placement stance
- Comece com `Advantage+ Placements` salvo restricao real de formato, marca ou inventario.
- Restrinja placements so quando houver evidencia de desalinhamento ou requisito operacional.
