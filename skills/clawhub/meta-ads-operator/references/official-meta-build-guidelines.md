# Official Meta Build Guidelines

## Official themes incorporated
- simplificar estrutura melhora aprendizado e leitura
- consolidar sinais costuma ser melhor que fragmentar demais
- placements amplos sao bom default
- variedade criativa ajuda performance

## Practical translation
- nao abrir muitos conjuntos so porque e possivel
- nao restrinja placements sem uma razao operacional ou analitica
- nao trate automacao como inimiga; trate como recurso a ser aceito ou recusado com criterio
