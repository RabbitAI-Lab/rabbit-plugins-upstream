# Creative Assembly

## Creative package
- hook
- corpo
- prova
- CTA
- formato
- destino coerente

## Minimum viable variation set
- pelo menos `3` angulos relevantes
- pelo menos `2` variacoes por angulo quando o budget permitir
- mix de formatos quando houver material

## Creative naming
Use:
`[Offer] [Angle] [Format] [Asset] [rN]`

## Assembly rules
- o criativo deve filtrar o publico certo, nao atrair qualquer clique
- CTA precisa refletir o destino real
- prova e beneficio precisam estar visiveis cedo
- se o placement exigir adaptacao, adapte sem quebrar o conceito

## Enhancement stance
- evite automacoes criativas que descaracterizem marca ou mensagem
- use automacao apenas quando houver ganho real e controle aceitavel
