## Description:

Use when buying, selling, stacking, or seasoning firewood — verifies true cord volume vs the "face cord"/"rick"/"truckload" shell game (128 ft³ vs 42), compares species BTU per cord and cost-per-MMBtu against propane/heat-pump resistance heat, computes seasoning time from split size and moisture with the 20% burn rule, and sizes annual consumption from climate house-heating demand.

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: Volume, heating, cost, and seasoning results can be misleading when input measurements or assumptions are inaccurate; command examples in SKILL.md also use a different syntax from the script.

Mitigation: Use the README command examples, measure stacked dimensions, check moisture on a freshly split face, and enter local fuel prices and realistic stove efficiency. Treat results as rough estimates.
