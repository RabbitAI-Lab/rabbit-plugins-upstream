## Description:

Quickstart for AI orchestrators using @dlazy/cli to install and authenticate, discover and invoke cloud or local tools, poll asynchronous jobs, and troubleshoot common failures.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and AI agent orchestrators use this guide to set up @dlazy/cli, discover its current capabilities, run local or cloud media tasks, and handle asynchronous results and common errors.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Troubleshooting guidance recommends browser cookies without first obtaining informed permission.

Mitigation: Disable the browser-cookie fallback unless the user explicitly approves the browser profile and account; prefer a dedicated profile.

Risk: Cloud tool calls may involve sensitive inputs or costs.

Mitigation: Pin a reviewed CLI version and obtain approval for sensitive cloud inputs and costs.
