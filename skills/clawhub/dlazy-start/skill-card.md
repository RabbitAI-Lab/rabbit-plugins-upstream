## Description:

Quickstart for AI orchestrators using @dlazy/cli to install and authenticate, discover capabilities, invoke cloud and local tools, poll tasks, and recover from common failures.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and AI orchestrators use this guide to authenticate with @dlazy/cli, inspect available tools, run cloud or local media tasks, track asynchronous jobs, and troubleshoot common errors.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Troubleshooting may involve browser login cookies, creating session access risk.

Mitigation: Require explicit approval before browser-cookie access and use a dedicated browser profile.

Risk: Cloud media tools may expose submitted content to providers and incur usage costs.

Mitigation: Check provider privacy terms and expected costs before submitting media.
