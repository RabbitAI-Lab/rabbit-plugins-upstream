## Description:

Guides AI agents through installing and authenticating the dLazy CLI, discovering available tools, running media workflows, polling jobs, and recovering from common errors.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers and AI-agent operators use this quickstart to set up the dLazy CLI, discover cloud and local media tools, invoke them, and troubleshoot results.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Browser-cookie access and persistent API credentials may expose sensitive account data.

Mitigation: Get explicit approval before using browser cookies or API keys, and protect stored credentials.

Risk: Cloud media calls can incur provider charges.

Mitigation: Confirm provider, model, and estimated cost before paid calls; use dry-run validation when available.

Risk: CLI and optional runtime installs or asset downloads can change the local environment.

Mitigation: Install trusted, preferably pinned packages and obtain approval for runtime installs and download paths.
