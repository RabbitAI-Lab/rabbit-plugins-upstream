## Known Risks and Mitigations:

Risk: Search terms and creator profile details are shared with SocialDataX during queries.

Mitigation: Send only query terms and profile details you are comfortable sharing with SocialDataX.

Risk: Paginated queries can consume account credits.

Mitigation: Set page limits to control credit usage.

Risk: The API key could be exposed if handled insecurely.

Mitigation: Keep the SocialDataX API key private.

Risk: Installing an unreviewed or moving package version can introduce unexpected changes.

Mitigation: Prefer a reviewed, fixed package version over @latest.
