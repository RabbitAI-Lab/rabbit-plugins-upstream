## Known Risks and Mitigations:

Risk: Automatic setup executes unverified remote code and may have broader installation effects than the skill describes.

Mitigation: Review and install a version-pinned CLI separately, stop if it is missing, and check bundled-skill installation and synchronization settings before use.

Risk: The connected Nozbe account can be used to change or delete data.

Mitigation: Connect only the intended Nozbe account and retain user approval for changes and deletions.
