“三驾马车修改版”策略深度解析
一、策略整体哲学：多元化资产配置的量化实践
这是一个将价值投资、成长投资和技术分析融合的多策略系统，其核心思想是“不把鸡蛋放在一个篮子里”，但不同于简单的分散投资，它进行了策略层面的多元化。

1.1 资金分配的底层逻辑
40%小市值策略：追求高成长性和小盘股溢价

40%白马策略：追求价值回归和稳健收益

20%ETF策略：追求市场贝塔和趋势收益

这种配置体现了现代投资组合理论中的策略分散化理念：不同策略的相关性较低，能够平滑整体收益曲线，降低单一市场环境下的风险。

1.2 策略命名的隐喻
“三驾马车”借用的是经济学中的增长动力比喻：

小市值策略：创新驱动（新兴企业成长）

白马策略：消费驱动（成熟企业价值）

ETF策略：投资驱动（市场趋势跟随）

二、小市值策略的微观机理
2.1 小市值效应的理论根源
学术基础：芝加哥大学Banz教授1981年发表论文，发现市值最小的股票组合收益率显著高于市值最大的股票组合。这被称为“小市值效应”或“规模效应”。

在中国的特殊表现：

制度性套利空间：A股小市值公司常成为并购重组对象

流动性溢价：机构投资者配置限制，小盘股流动性较差，投资者要求更高回报

信息不对称：研究覆盖少，存在信息差带来的投资机会

2.3 空仓机制的风险管理智慧
python
g.pass_months = [1, 4]  # 1月和4月空仓
为什么是这两个月？

1月空仓逻辑：

上一年度年报预告密集期（1月31日前）

“业绩变脸”高发期，地雷股集中引爆

小市值公司业绩波动大，风险更高

4月空仓逻辑：

上一年度正式年报披露截止月（4月30日前）

年报被出具非标意见的公司集中出现

ST戴帽、退市风险警示集中处理期

3月、12月下半月空仓补充：

3月16日后：避开一季报预告窗口

12月16日后：避开年度业绩预告窗口

这种设计体现了 “避开不确定性时期” 的投资哲学，宁可错过机会，也不承担不必要的风险。

3.3 因子权重的经济学意义
python
g.roe = 10  # ROE权重
g.roa = 6   # ROA权重
为什么是10:6？

ROE（净资产收益率）：股东最关心的指标，代表为股东创造价值的能力。

公式：ROE = 净利润 / 净资产

在A股市场，ROE是长期股价表现的最强相关性指标

ROA（总资产收益率）：衡量企业利用全部资产盈利的能力。

公式：ROA = 净利润 / 总资产

能识别高杠杆带来的虚假ROE

权重设计：

ROE权重更高，因为它是股东回报的直接体现

ROA作为重要补充，防止企业通过过度负债粉饰ROE

10:6的比例体现了 “股东回报优先，但兼顾经营质量” 的思想

风险补偿理论：动量策略承担了流动性风险、崩盘风险

五、风险控制体系的层次化设计
5.1 第一层：事前风控（Pre-trade）
标的筛选：

财务指标硬约束（ROE>15%、ROA>10%等）

流动性要求（换手率>0.5%）

价格限制（<50元，已持仓除外）

状态检查（非ST、非停牌）

仓位控制：

策略资金比例锁定（40%-40%-20%）

单策略持股数量限制（5只）

策略间持仓隔离

5.2 第二层：事中风控（Intra-trade）
止损体系：

硬止损8%：基于行为金融学的“损失厌恶”阈值研究

止盈100%：“让利润奔跑”但设置上限

软止损：涨停打开卖出

交易执行风控：

六、策略的A股适应性设计
6.1 对A股制度特征的利用
规避财报窗口期：A股的“业绩预告”制度导致1月、4月风险集中
涨停板制度利用：昨日涨停股今日享有“保护期”，体现对涨停连板模式的尊重
板块差异化对待：明确排除注册制板块，规避退市风险

6.2 对A股投资者结构的适应
散户主导的市场特征：

动量效应更强（趋势跟随）

小市值溢价更明显（炒作空间）

价值回归需要时间（需要耐心）

机构行为模式：

白马股抱团现象（策略2的暖市/热市逻辑）

季度末调仓效应（策略1的空仓期设计）

6.3 对A股历史规律的总结
大小盘轮动周期：A股3-4年一次的大小盘风格切换
春季躁动行情：策略1在非空仓月份的配置参与
年末效应：策略2的冷市防御准备

八、策略的哲学思考
8.1 投资理念的融合
这个策略本质上是 “价值为体，动量为用”：

价值投资提供安全边际（白马策略）

成长投资提供向上弹性（小市值策略）

趋势跟踪提供时机选择（ETF策略）

8.2 对市场有效性的态度
策略隐含地认为A股市场是 “半强式有效”：

基本面分析有效（策略1、2）

技术分析也有效（策略3）

但都有局限性，需要组合使用

8.3 对风险的认知
不追求消灭风险，而是管理风险：

通过分散降低非系统性风险

通过择时降低系统性风险

通过止损控制个体风险

九、总结：一个成熟量化系统的要素
这个“三驾马车修改版”策略体现了成熟量化系统的关键要素：

逻辑清晰的投资哲学：价值、成长、趋势三位一体

严谨的实证基础：小市值效应、价值溢价、动量效应

细致的规则设计：从选股到交易的全流程覆盖

多层次的风控体系：事前、事中、事后全方位

对本土市场的深刻理解：A股制度、投资者结构、历史规律

技术实现的严谨性：交易成本、执行顺序、状态检查

它不是一个追求短期暴利的策略，而是一个追求长期稳健复利的系统，体现了 “慢就是快” 的投资智慧。

最终的核心思想：在不确定的市场中，通过系统化的方法获取确定性的收益来源，让投资从艺术走向科学。
