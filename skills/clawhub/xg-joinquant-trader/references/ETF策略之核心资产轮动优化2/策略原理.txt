ETF轮动策略原理详细分析
这是一个基于动量效应和自适应波动率调整的全球多资产ETF轮动策略，让我详细解析其核心原理。

一、策略核心理念：智能趋势跟随
这个策略的核心思想是：
“在全球不同市场、不同资产类别中，动态识别当前最强的趋势，并用科学方法衡量趋势的‘质量’，然后全仓跟随这个最强趋势。”

创新2：自适应动量计算窗口
这是本策略最核心的创新点：

传统方法的缺陷
传统动量策略使用固定天数（如20天、60天）计算动量，但：

市场平稳时：需要较长周期确认趋势

市场剧烈波动时：短期趋势更重要

本策略的解决方案：动态调整
python
# 根据波动率自动调整动量计算天数
lookback = int(g.min_days + (g.max_days - g.min_days) * (1 - min(0.9, short_vol/long_vol)))
工作原理：

计算波动率：

long_vol：长期波动率（用60天ATR计算）

short_vol：短期波动率（用20天ATR计算）

判断市场状态：

text
短期波动率 / 长期波动率 = 波动率比率

如果比率低（如0.3）：
  说明市场近期平稳，波动减小
  → 使用更长的计算窗口（接近60天）
  
如果比率高（如0.8）：
  说明市场近期波动加剧
  → 使用较短的计算窗口（接近20天）
数学原理：

text
假设：长期波动率 = 2.0，短期波动率 = 1.0
则：短期/长期 = 0.5

lookback = 20 + (60-20) * (1 - min(0.9, 0.5))
         = 20 + 40 * (1 - 0.5)
         = 20 + 40 * 0.5
         = 40天
优势：

市场平稳时：用长期数据，避免噪音干扰

市场波动时：用短期数据，快速响应变化

完全自动化，无需人工调整

创新3：加权对数线性回归评分
传统动量计算的不足
简单计算收益率：

忽略趋势的稳定性

对近期和远期数据同等对待

本策略的改进
1. 加权回归：

python
weights = np.linspace(1, 2, len(y))  # 线性加权，越近期权重越高
slope, intercept = np.polyfit(x, y, 1, w=weights)
最近价格权重=2，最远价格权重=1

意义：更重视近期表现，但不过度忽略历史

2. 对数价格回归：

python
y = np.log(prices)  # 使用对数价格
更符合金融数据的特性

收益率计算更准确

3. 综合评分公式：

text
最终得分 = 年化收益率 × R²（判定系数）
年化收益率：趋势的强度（斜率）

R²：趋势的质量（线性程度）

两者相乘：既要涨得快，又要涨得稳

R²的意义：

R²接近1：价格完美直线上升，趋势可靠

R²接近0：价格随机波动，趋势不可靠

示例：两个ETF都涨10%

A：每天稳定涨1%（R²=0.95）

B：一天涨9%，其他天震荡（R²=0.3）

A得分远高于B

三、严格的风控体系
1. 近期大幅下跌过滤
python
# 条件1：三天内有一天跌超5%
con1 = min(prices[-1]/prices[-2], ...) < 0.95

# 条件2：连续三天下跌，累计跌超5%
con2 = (连续下跌) & (prices[-1]/prices[-4] < 0.95)

# 条件3：更严格的连续下跌检查
con3 = (连续四天中前三天下跌) & (prices[-2]/prices[-5] < 0.95)
逻辑：避免买入正在暴跌或刚暴跌完的资产

2. ETF溢价率控制
python
# 计算溢价率
premium_rate = (市场价格 - 基金净值) / 基金净值 * 100

# 如果溢价率≥5%，扣减1分
if premium_rate >= 5:
    score = score - 1
为什么重要：

溢价率高：买入价格虚高，风险大

溢价率5%：市场情绪过热，需谨慎

扣分而非直接排除：给小幅溢价留有余地

3. 得分范围过滤
python
data = data.query("0 < score < 6")
score > 0：只考虑正动量

score < 6：排除异常高得分（可能是数据错误或极端行情）

四、交易执行逻辑
持仓管理：冠军策略
python
target_num = 1  # 只持有一只ETF

集中火力，追求最大收益

买卖规则

买入：

有现金可用

目标ETF当前未持有

交易时机
python

为什么是9:50？

避开开盘剧烈波动（9:30-9:45）

让市场稍微稳定后再交易

确保获取准确的实时价格

五、策略工作流程示例

纳指ETF波动率高（short/long=0.8）

text

六、策略优势与风险
优势
全球视野：不局限于单一市场

智能适应：波动率自适应，适应各种市场环境

科学评分：综合考虑趋势强度和质量

严格风控：多层过滤，避免踩雷

纪律性强：完全规则驱动，避免情绪干扰

风险与局限性
冠军策略风险：

全仓单只ETF，波动大

一旦选错，损失集中

动量策略通病：

震荡市表现差（频繁换仓产生摩擦成本）

趋势反转时可能买在最高点

参数敏感性：

最小/最大天数（20/60）

溢价率阈值（5%）

下跌过滤条件

流动性风险：

部分ETF成交量小，买卖冲击成本高

极端行情下可能无法成交

数据依赖：

需要准确计算溢价率（依赖IOPV数据）

跨境ETF有时差问题（净值更新滞后）

七、策略适用环境
表现好的市场：
趋势明显的单边市（如2020年美股牛市）

板块轮动清晰的结构市

波动率稳定的市场（自适应机制有效）

表现差的市场：
震荡市/猴市（趋势不明，频繁打脸）

风格快速切换（今天成长，明天价值）

黑天鹅事件（所有资产齐跌，无处可躲）

八、总结：策略的本质
这是一个全球多资产智能趋势跟随系统，它的核心创新在于：

"用波动率自适应机制动态调整观察窗口，用加权对数回归科学评估趋势质量，在全球范围内寻找最强趋势，并设置多层安全网防止踩雷。"

找趋势：不仅看涨多少，还看涨得稳不稳

自适应：市场变，我也变，永远用最适合的尺度观察

全球化：哪里有机会就去哪里

控风险：暴跌不过滤、高溢价扣分、只做正趋势

最终目标：在不同的市场环境中，都能找到并骑上"当前跑得最快最稳的那匹马"，直到出现更快的马或这匹马累了（趋势结束）。
