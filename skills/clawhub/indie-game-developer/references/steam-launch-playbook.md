# Steam 发行深玩（Steam Launch Playbook）

> `steam-launch` 子技能列了能力清单，本篇把"怎么发好"展开成可操作 playbook：
> 商店页转化、愿望单漏斗、Next Fest 节奏、定价与区域、上线时间线。这是独立游戏
> 生死线，且是子技能装不下的策略方法论。

## 1. 发行时间线（倒排）

```
T-6 月  立项商店页（Coming Soon），开始积累愿望单
T-3 月  上线 Demo（节假日前 2 月最佳），开放测试
T-2 月  Next Fest 参与（2 月 / 6 月 / 10 月），冲愿望单峰值
T-1 月  媒体/主播预热，确定定价与区域
T-0     正式发布，首周折扣 + 直播
T+2 周  首周数据复盘，调整标签/折扣/视觉
```

**核心认知**：愿望单数量是上线首周销量的强预测指标。发力的不是发布日，是发布前 6 个月。

## 2. 商店页转化（对赌审计）

商店页 = 落地页，逐元素优化：

| 元素 | 作用 | 优化要点 |
|------|------|----------|
| 标签图（capsule） | 列表第一眼 | 在众多游戏里"读得出名字"，别只放美术 |
| 首屏截图 | 30 秒说服力 | 放"玩起来什么样"，非概念图；前 3 张最关键 |
| 预告片 | 黄金 30 秒 | 前 5 秒必须有 gameplay，不是 logo 动画 |
| 短描述 | 搜索/列表 | 前 1 句说清"是什么类型 + 独特卖点" |
| 标签（tags） | 发现流量 | 5–20 个，覆盖类型/题材/相似游戏 |
| 评测引用 | 信任 | 有媒体/KOL 评价就放，没就靠早期.access |

对照 [assets/steam-store-metadata-template.json](../assets/steam-store-metadata-template.json) 自检字段齐备（脚本校验见 [scripts/check_steam_metadata.py](../scripts/check_steam_metadata.py)）。

## 3. 愿望单漏斗诊断

愿望单增长慢，先定位卡在哪一环：

```
流量（看到商店页的人）──▶ 转化（加愿望单）
  │                          │
  ├ 低：曝光少 → 投标签/参与活动/主播   ├ 低：页不吸引 → 改截图/预告片/描述
  └ 渠道单一 → 扩 KOL/社区/特卖         └ 信任不足 → 放 Demo/评测
```

诊断方法：用 Steamworks 后台的"流量来源"区分；
- 流量低 → 加 Next Fest、联系主播、蹭相似游戏标签
- 转化低 → A/B 商店页元素（截图顺序、短描述），看加愿率
- 信任低 → 放可玩 Demo、收集好评测

## 4. 定价与区域

- **定价**：独立游戏常见 $9.99–$19.99；参考同类 + 内容量；首周 -10%~-15% 促转化
- **区域定价**：用 Steam 推荐区域差价（新兴市场更低），别一刀切
- **币种/税制**：Steam 代抽成 + 地区税，净收入低于预期，定价预留空间
- **折扣节奏**：首周小折 → 大型特卖（夏促/冬促）大折冲榜；频繁大折伤价值感

## 5. Next Fest 与 Demo 就绪

- Demo 必须与正式版"体验一致"，否则差评"Demo 骗人"
- Demo 内容 = 前 30–60 分钟最佳体验，留钩子引正式版
- Next Fest 前完成：商店页、预告片、标签、Demo 三端（Win/Mac/Steam Deck）可跑
- Steam Deck 验证：官方认证提升曝光，触控/手柄适配要过

## 6. 典型坑与规避

- **坑：上线前才做商店页**，愿望单为 0，首周扑街。*规避*：T-6 月立页，持续积愿。
- **坑：Demo 与正式版体验割裂**。*规避*：Demo 用正式版前段，非另做。
- **坑：标签乱填不相关游戏**。*规避*：选真实相似作，骗流量反伤转化。
- **坑：只在 Steam 发，忽略 Deck 验证**。*规避*：跑 Deck 验证拿认证徽章。
- **坑：首发全价无折扣**。*规避*：首周小折建立早期评价格局。
- **坑：预告片前 10 秒是 logo**。*规避*：前 5 秒必须 gameplay。

## 8. 上线后运营（发布不是终点）

| 阶段 | 动作 | 目标 |
|------|------|------|
| 首日 | 盯崩溃/评测，速回差评 | 守住首周好评率 |
| 首周 | 小折 + 直播，冲同时在线 | 冲榜单曝光 |
| 首月 | 热修 + 小更新，回应社区 | 稳定评分 |
| 大促 | 夏促/冬促大折 | 冲销量峰值 |
| 长期 | DLC / 社区 Mod / 多语言 | 延长生命周期 |

**好评率就是生命**：Steam 推荐算法看重好评率，差评初期不处理会滚雪球。建立"差评→复现→热修→公开回应"的快速闭环。

## 9. 关键指标定义（别被虚荣指标骗）

- **愿望单数**：上线首周销量的领先指标，但需区分"真感兴趣"与"顺手加"
- **加愿转化率**：商店页访客 → 加愿望单，衡量页质量（§2）
- **首周好评率**：决定算法推不推，目标 ≥80%（"多半好评"）
- **同时在线(CCU)**：冲榜与曝光的硬指标，受折扣/活动驱动
- **退款率**：隐藏杀手，玩法与预期不符会高退
- **媒体评测**：外部信任锚，早期争取 KOL 试玩

## 10. 媒体与 KOL 触达

- **T-3 月**起联系主播/媒体，提供 Key 与素材包
- 给 KOL 的是"可玩 Demo + 一句话卖点 + 差异化"，不是长篇文档
- 相似游戏的主播比泛娱乐主播转化高（受众精准）
- 准备 press kit：截图、预告片、logo、短描述、关键点（一键可取）

## 11. 多语言与无障碍（扩市场）

- 至少英 + 简中（全球两大市场）；德语/日语视受众
- 文本外置为 `localization.json`，别硬编码
- 字幕开关、色盲模式、按键重绑提升包容与好评
- Steam 翻译若接官方，提前排期（有审核时延）

## 13. 区域定价参考表

Steam 推荐用区域差价（新兴市场更低），别全球统一定价伤转化：

| 区域 | 相对基准 | 说明 |
|------|----------|------|
| 美区(基准) | 100% | 通常 $14.99 档 |
| 中国 | 60–70% | 价格敏感，占比高 |
| 俄罗斯/独联体 | 50–60% | 强区域差价 |
| 欧元区 | 95–105% | 含 VAT 差异 |
| 拉美 | 50–70% | 购买力低 |
| 日元区 | 90–100% | 取整定价 |

注意：区域差价过大会催生跨区代购（转售 Key），用 Steam 的"区域激活限制"缓解；但过度限制又伤正常玩家。定价是平衡术，上线后看各区域转化再微调。
