## Description:

A toolkit for indie game development that covers engine selection, production workflows, pixel art, visual polish, Steam publishing, QA, performance, and checks for asset references and store metadata.

This skill is ready for commercial/non-commercial use.

## Publisher:

[skills-repo](https://clawhub.ai/user/skills-repo)

### License/Terms of Use:

MIT

## Use Case:

Indie game developers and small teams use this skill to choose an engine, plan and build game features, refine visuals and pixel art, prepare Steam releases, and check project assets and store metadata.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Global installation scope and future external downloads may introduce changes that have not been reviewed.

Mitigation: Review installation scope and use reviewed, pinned installer and asset-tool versions.

Risk: Validation scans or corruption tests can affect files or saves if run against the wrong targets.

Mitigation: Keep scans within the game project and use disposable saves for corruption tests.
