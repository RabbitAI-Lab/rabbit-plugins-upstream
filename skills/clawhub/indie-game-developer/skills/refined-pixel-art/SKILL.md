# 精致手绘像素角色

> 把参考图的像素密度、轮廓和色簇语言转译成可控生成规范，产出真正逐格设计的角色，而不是套像素滤镜的高清插画。

## 能力

- **参考图分工**：区分风格参考、角色参考与编辑目标，明确每张图允许继承和禁止复制的内容
- **网格密度控制**：按用途选择 16×16、24×32、28×36 或 32×32 逻辑网格，不用“更像素”这类模糊词
- **色簇与轮廓设计**：用连续色簇、阶梯斜线、单像素高光和有限色板建立清晰剪影
- **生成提示词工程**：同时写正向规格、构图约束与负向约束，压制平滑插画、伪像素和背景污染
- **失败纠偏**：针对人物过大、细节过密、白底不纯、弓箭不可读等问题，每轮只调整一个变量
- **资产验收**：从网格、色板、轮廓、姿势、背景和小尺寸可读性六个维度判断是否可交付

## 使用方式

在 Claude Code 或 Codex 中调用：

```text
/refined-pixel-art 参考这张图的像素密度，生成 28×36 网格感的白底女弓箭手 icon
/refined-pixel-art 把这个角色从 16×16 超粗像素优化为精致手绘像素，保留轮廓与配色
/refined-pixel-art 审查这批像素人物，指出哪些只是高清插画加像素滤镜
```

需要完整方法与模板时读取：

- `../../references/refined-pixel-art-playbook.md`
- `../../assets/refined-pixel-character-prompt.md`

## 工作流

1. **定义用途** — 明确输出是头像、正方形 icon、全身 sprite、宣传图角色还是 sprite sheet。
2. **标注输入角色** — 为每张输入图指定“风格参考 / 角色参考 / 编辑目标”，列出允许继承与禁止复制项。
3. **锁定逻辑网格** — 先选像素密度，再谈细节；默认精致角色采用约 28×36 网格，icon 留出 12%–18% 边距。
4. **建立像素预算** — 限制色板、明暗层级、轮廓宽度、面部像素和材质分区，避免生成器自行加细节。
5. **组装提示词** — 使用模板填写角色、姿势、道具、背景和负向约束；明确 nearest-neighbor、hard edges 与 no antialiasing。
6. **生成并目视验收** — 在原尺寸和缩小尺寸下检查剪影、手脚、武器、色簇、背景与方格一致性。
7. **单变量纠偏** — 一轮只改网格密度、人物比例、动作、色板或背景中的一个，不在同轮重写全部约束。
8. **稳定命名落盘** — 使用 `<系列>-<角色>-<动作>-<密度>.png`，保留上一版便于比较，不静默覆盖。

## 适用场景

- 根据参考图生成原创的精致像素人物、职业角色和游戏 NPC
- 制作纯白或透明背景的正方形角色 icon
- 在超粗像素与高清伪像素之间找到可控的中等密度
- 保持角色设定不变，优化轮廓、色簇、材质和动作可读性
- 为图像生成模型编写稳定、可迭代的像素艺术提示词
- 审核现有资产是否满足真实像素网格与小尺寸辨识要求

## 限制

- 不复制受版权保护角色、服装、Logo 或完整场景；参考图只用于抽象视觉属性
- 不把“pixelated”“8-bit”单词本身视为有效规格，必须给出逻辑网格与色板预算
- 不保证图像模型严格遵守精确像素数；需通过目视或后处理验证
- 不负责动画帧时序与 sprite sheet 打包；这类任务交给 `pixel-art-studio`
- 不适合写实肖像、复杂透明材质、软毛发或依赖抗锯齿的画面
- 不在未检查生成结果时宣称背景为纯白、轮廓无抗锯齿或像素网格完全一致
