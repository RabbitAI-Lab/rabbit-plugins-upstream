## Description:

Edit English and Chinese text for clarity, style, and genre fit while preserving meaning, facts, quotations, citations, and necessary disclosures; the skill does not infer human or AI authorship or target detection evasion.

This skill is ready for commercial/non-commercial use.

## Publisher:

[songhonglei](https://clawhub.ai/user/songhonglei)

### License/Terms of Use:

MIT

## Use Case:

Writers, editors, and other users can use the skill to diagnose clarity, structure, tone, rhythm, rhetoric, and typography issues in English or Chinese text, or request a comparison rewrite that preserves meaning, facts, sources, quotations, and necessary disclosures. It adapts feedback to comments, articles, technical material, and literary prose.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A proposed rewrite could change meaning or factual details, or omit quotations, citations, or necessary disclosures.

Mitigation: Compare the rewrite with the original and verify dates, names, figures, sources, quotations, and disclosures before using it.

Risk: The optional preflight utility uses file and shell capabilities to inspect a selected draft.

Mitigation: Review the script and confirm the input path and command options before running it.
