## Use Case: <br>
Product managers and release teams use this skill to plan ProductBoard releases, organize features, track status, assign owners, and manage sprint, release, or quarterly planning workflows. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: ProductBoard actions may create features, update statuses, assign owners, change planning dates, or archive work items. <br>
Mitigation: Ask the agent to show planned creates, updates, owner assignments, date changes, and archival actions before applying them. <br>
Risk: The skill depends on a separate ProductBoard integration whose permissions determine what changes can be made. <br>
Mitigation: Install only if you trust that integration and connect it with appropriately limited ProductBoard permissions. <br>
