# wave-timeline — 起伏波浪线大事记

> 一条从左到右**贯穿整页**的起伏波浪线，整体**向右上推进**。波峰波谷上挂着事件圆圈，旁线连接到一段文字。隐喻：**过程曲折，最终取得成功**。

## 何时用 / 何时不用

| ✅ 用 | ❌ 不用 |
|---|---|
| 项目复盘、年度大事记、长跑叙事 | 时间点无波折（用 [lanes](lanes.md) 泳道） |
| 「这三年我们走过弯路但抵达了山顶」 | 多实体并行（用泳道） |
| 季度回顾、转型历程、里程碑叙事 | 时间粒度细到天（用真实时间轴图） |

**关键约束**：**整体向右上方推进**。起点 `y` 比终点 `y` 低 60–120px。**不能**画成水平的——水平就丢了"爬坡感"。

## 变体：起伏波浪大事记

### 坐标公式

```
画布    viewBox 0 0 1020 500
起点    (60, 350)        ← 左下
终点    (960, 80)        ← 右上
振幅    60–90px          ← 单峰高度
峰数    5–7 个峰
节点圆  r = 24，描边色配节点色
连接线  从圆边切点出发，到文字框
```

**波峰波谷在 y 上的分布**：从起点到终点**单调上升**，但局部有起伏。例如 7 峰分布：

```
峰 1  谷 1  峰 2  谷 2  峰 3  谷 3  峰 4  谷 4  峰 5  谷 5  峰 6  谷 6  终点
60    160   260   360   460   560   660   760   860   940   (起伏 ±60)
```

## 硬规则

1. **整条线的 y 必须单调不降**（从起点到终点）。允许局部波折，但终点必须**明显高于起点**。
2. **峰数 5–7。** 太少读不出"过程曲折"，太多糊成一片。
3. **节点圆用小圆 r=8–12，描边色配节点色。** 不要在大波浪线上再加大块形，破坏流动感。
4. **节点最多 5–6 个。** 大事记不是流水账，挑节点写。
5. **指示线从圆边切点出发**，不要穿过圆。
6. **起点和终点各一个小节点**——视觉上的"开篇/收官"。

## 连线

| 关系 | 画法 |
|---|---|
| 主波浪线 | 平滑 `C` 曲线串成的多段折线，**stroke-width 一致** |
| 节点 → 文字 | 短竖线（`stroke="#dcdcdc"`），无箭头 |
| 起终点圆 | 节点圆，描边色配节点色 |

## 文字排布

- **节点标签在节点上方**，避开主波浪线
- 起点标签在起点下方（因为起点是左下，标签上移会进波浪线）
- 终点标签在终点上方
- 底部用 `.lbl` 注解一句"过程曲折 / 收官"等总结语
- 节点标签 ≤ 6 个中文字

## 配套隐喻

`Wave timeline` 直接对应，无需换壳。
