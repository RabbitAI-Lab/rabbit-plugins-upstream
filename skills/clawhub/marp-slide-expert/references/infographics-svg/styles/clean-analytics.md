# clean-analytics

> 数据自信的研究可视化风格。青色主导、白底、大留白、超大数字、圆形签名形状。

## Token

```css
--c-primary:   #4EBDBA;   /* 主青：强调、数据标签、形状填充 */
--c-deep:      #3B9B9B;   /* 深青：主数据系列 */
--c-mid:       #6DCBC8;   /* 中青：次级填充 */
--c-light:     #B5DEDE;   /* 浅青：背景填充、气泡 */
--c-pale:      #E4F3F3;   /* 极浅青：区域淡填 */
--c-bg:        #FFFFFF;
--c-text:      #1A1A1A;   /* 主文字 */
--c-text-2:    #4A4A4A;   /* 次级文字 */
--c-accent:    #E87461;   /* 珊瑚：分类高亮、对照系列 */
--c-accent-2:  #F0A050;   /* 暖橙：次级标签 */
--c-series:    #4EBDBA #E87461 #7B68AE #D4A843 #4A6FA5;  /* 多系列，青色主导 */
```

## 字阶

| class | 用途 | 特征 |
|---|---|---|
| `.t` | 图形主标题 | 超粗窄体无衬线，字重 800 |
| `.hero` | 超大数字 | `.t` 的 1.8 倍，数字深黑 + 单位常规重 |
| `.tb` | 节点/标签 | 中粗 |
| `.sm` | 副标签 | 常规 |
| `.lbl` | 注脚 | 常规，浅灰 |

**混排标题**：关键词深黑粗体，连词青色常规重。中文可用 `<tspan>` 拆两段上色——这是本风格最快的识别特征。

## 形状语言

- **圆形和气泡是签名形状**——重叠圆（韦恩）、按大小分配的圆（气泡图）、圆形图标容器
- 圆角胶囊形做标签和分类 tag
- 简单几何线性图标，放在圆里
- 青色的横竖分隔线
- 超大数字做 hero 元素

## 变体

| 变体 | 焦点 |
|---|---|
| **Overview** | 概念图、生态图、青色气泡组合 |
| **Data-study** | 图表、超大数字、清晰坐标轴 |
| **Architecture** | 系统图、分类配色、流程箭头、嵌套容器 |

## 硬性规则

**Do**
- 青色是唯一主导色，传达分析可信度
- 保持白底干净
- 统计量用超大数字呈现
- 同类元素同色，跨图一致
- 大留白——信息密度高但不拥挤

**Don't**
- 手绘元素、纹理、粗糙边缘 → 一切必须数字化精确
- 装饰插画、卡通元素 → 图标只用简单几何线性
- 一张图里混超过 2 个强调色
- 渐变、投影、斜面、3D

## 适合

研究型数据可视化、量化分析、系统架构图、生态图、统计看板、机构能力总览、数据简报
