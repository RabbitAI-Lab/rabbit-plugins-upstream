# tricon-infographic

> 红色主调的议题图解风格——openclaw 课件主题。**暖红** + **深藏青** 标题，白底，锐利，章节叙事感强。

## Token

```css
--c-primary:   #c0392b;   /* 主红：强调色、关键短语、结论线 */
--c-bright:    #e74c3c;   /* 亮红：H3 标题、突出数据点 */
--c-navy:      #2c3e50;   /* 深藏青：H1/H2 标题、深色块底 */
--c-deep:      #1a1a2e;   /* 接近黑：背景深色（代码块、表头） */
--c-bg:        #FFFFFF;
--c-panel:     #f5f5f5;   /* 浅灰面板：方法论、侧栏 */
--c-text:      #1a1a2e;
--c-muted:     #6B7280;   /* 注脚、来源 */
```

**核心三色**：红 `#c0392b` + 亮红 `#e74c3c` + 深藏青 `#2c3e50`。白底。其他色彩一律不出现。

## 字阶

| class | 用途 | 特征 |
|---|---|---|
| `.t` | 主标题 | 无衬线粗体，深藏青 `#2c3e50` |
| `.tb` | 分区标题、节点 | 无衬线粗体，亮红 `#e74c3c` 或主红 `#c0392b` |
| `.qt` | 象限标题 | 无衬线粗体 |
| `.sm` | 正文、标签 | 无衬线常规 |
| `.lbl` | 注脚、来源 | 无衬线小字 + 灰色 `#6B7280` |

**openclaw 风格特征**：标题统一深藏青，分段标题/小标题用红，**红只用在「重点短语」**——一行标题里，关键词红、其他字深藏青。这是该风格最显著的修辞节奏。

## 形状语言

- **细红线做分区线**（`stroke="#c0392b" stroke-width="1"`），不粗
- **红面板**做强调段（红底白字，红用 `#c0392b`），一个 deck 1–2 处，不要堆
- 直角，**所有矩形 `rx=0`**——保持锐利
- 表格表头红底白字（`#c0392b`）
- 大留白，元素之间充分呼吸
- 极简装饰

## 硬性规则

**Do**
- 红蓝双线分工：标题深藏青 `#2c3e50`、强调 `#c0392b`，**不要全篇都是红色**
- 留白要够——openclaw 风格之所以「敢说」，是因为敢说之间有足够空间
- 强调段用整幅红面板 + 白字（一页最多一处）

**Don't**
- 装饰插画、图标、剪贴画——这是讲观点，不是做广告
- 渐变、投影、光泽、圆角
- 一张图超过 2–3 个颜色（核心是红 + 深藏青 + 白）
- 红色滥用——红应该出现在读者必须看到的几个瞬间，不能满篇

## 适合

议题图解、立场鲜明的观点表达、政策研究、机构发布物、学术社论式图示、任何"我方主张这一观点，需要你听完"的内容

## 不适合

- 量化数据分析（用 [clean-analytics](clean-analytics.md)）
- 战略咨询报告（用 [mckinsey-report](mckinsey-report.md)）
- 中性、克制、需要读者自己下结论的内容（红太有立场）

## 与 openclaw 课件的对应

| openclaw | 本风格 token |
|---|---|
| 主红 `#c0392b` | `--c-primary` |
| 亮红 `#e74c3c` | `--c-bright` |
| 深藏青标题 `#2c3e50` | `--c-navy` |
| 黑底代码块 `#1a1a2e` | `--c-deep` |
| 浅灰隔行 `#f5f5f5` | `--c-panel` |

要把一份已有的 openclaw 课件的图统一换到本风格，**只需把这五个 token 写到 deck 的 `style:` 块**，然后全文 svg 内的 `fill="#xxx"` 改成 `fill="var(--c-xxx)"`。视觉会完全一致。
