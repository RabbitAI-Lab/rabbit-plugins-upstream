# mckinsey-report

> 权威机构研究风格。蓝色主导、白底、双字族（衬线标题 + 无衬线正文）、行动式标题、大留白。

## Token

```css
--c-primary:   #2563EB;   /* 咨询蓝：标题、数据高亮、强调 */
--c-navy:      #1B2838;   /* 深藏青：主数据系列、关键数字 */
--c-secondary: #14B8A6;   /* 青：次级数据系列 */
--c-tertiary:  #93C5FD;   /* 浅蓝：第三级数据、区域填充 */
--c-bg:        #FFFFFF;
--c-text:      #1A1A1A;
--c-muted:     #6B7280;   /* 注脚、来源、次级标注 */
--c-panel:     #F5F5F5;   /* 侧栏/方法论底色 */
--c-series:    #1B2838 #2563EB #14B8A6 #93C5FD #E87461;  /* 蓝色主导 */
--c-alert:     #EC4899;   /* 洋红：严格保留给告警/不可能数据 */
```

## 字阶

**双字族是本风格的定义性特征**：衬线做标题和强调，无衬线做其余一切。**绝不用衬线写正文，也绝不用无衬线写主标题。**

| class | 用途 | 字体 |
|---|---|---|
| `.t` | 主标题 | 衬线粗体（Georgia / Songti SC） |
| `.tb` | 节点、象限名 | 衬线粗体 |
| `.sm` | 正文、标签 | 无衬线常规 |
| `.lbl` | 注脚、来源 | 无衬线小字，灰色 |

**行动式标题**：标题写成完整分析句（"Rearranging US imports has become progressively more difficult."），不是话题标签（"Import trends"）。这是咨询报告的核心修辞——图在陈述结论，不是在介绍主题。

## 硬性规则

**Do**
- 蓝色为唯一主导色族
- 维持双字族纪律
- 标题写成完整分析句
- 数据直接标注在元素旁，减少图例
- 白底 + 大量留白（严肃感来自空，不是来自满）

**Don't**
- 深色背景——正式出版物永远白底
- 圆角：数据容器和图表区用直角，全图贯穿
- 装饰插画、卡通元素
- 一张图超过 4–5 个颜色
- 渐变填充、投影、斜面
- 装饰边框和花饰

## 适合

战略咨询报告、经济研究、全球趋势分析、机构政策文件、投资与贸易分析、人力与行业盘点、数据驱动的管理层简报

## 配图建议

`structure-block`（对比矩阵、便当格）、`linear-sequence` 阶梯（情景推演）、`hierarchy-tree` 分层（组织与行业拆解）、`flow-cycle` 桑基（贸易流、资源配置）、`network-hub`（生态图）
