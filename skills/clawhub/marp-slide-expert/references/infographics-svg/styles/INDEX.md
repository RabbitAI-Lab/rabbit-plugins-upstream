# 风格层 — 配色与字阶

> **本文件自足**：6 套可矢量化风格。每套是一组 token（色板 + 字阶 + 形状语言 + 硬性规则），不是一段散文描述。

## 默认：跟着 deck 走

**画图默认用 deck 自己的调色板**（[../../style-bootstrap.md](../../style-bootstrap.md)），不要换。

**UPerform deck 默认调色板**：

| 角色 | 颜色 | 用在哪 |
|---|---|---|
| 主色 | 深蓝 `#1a1a2e` | 标题、深色块、背景 |
| 点缀 1 | 粉橙 `#E87461` / `#e74c3c` | 强调、警示、关键节点 |
| 点缀 2 | 金黄 `#F0A050` / `#D4A843` | 数据高亮、对比辅助 |

**配色纪律**：深蓝为主，粉橙 + 金黄作为后置点缀。**红色 `#c0392b` 在 UPerform deck 里只用在强调短语（如重点题、结论线）**，不作为大面积块色。

理由：图必须属于它所在的那份 deck。图的配色和正文标题、表格表头用的是同一套蓝橙黄，投影时才像一份东西，而不是拼贴。现有骨架模板全部按这套 palette 写好，直接抄即可。

**6 套备选风格只在两种情况下启用**：
1. 整份 deck 本身就是那个调性（用该风格的 token 改写整个 `style:` 块）
2. 用户明确点名要某个风格

**不要**在 UPerform 调色板的 deck 里单独插一张 teal 的图——那会让这一页看起来像从别人 deck 里复制的。

## 为什么只有 6 套

剩下的 15 套依赖图像模型的渲染能力——3D 体积、纸纹/霉斑、粉笔颗粒、半调网点、发光、手绘不规则边、人形插画、噪点做旧。平面矢量做不出这些，硬做会得到一个「声称是黏土风格但只是一堆圆角矩形」的图。**与其做一个失真的版本，不如不做。**

其中 **bandung-circuit**（米纸底 + 细线手绘图标）和 **aged-academia**（羊皮纸底 + 纸纹墨斑）曾经入选过，但复核后仍被砍掉：剥掉纸纹和手绘不规则边之后，它们剩下的只是「另一种颜色的便当格」，识别度归零，配色上又没有比现有 6 套更强的地方——**留着一个不伦不类的第七套，不如把 6 套做扎实。**

**将来要补的判据**：这个风格能不能只用「色板 + 字阶 + 直线/曲线/矩形/圆/椭圆 + 描边粗细」表达？不能就别进这个目录。

## 应用方式

风格不改变骨架的几何，只替换 token。三种做法：

**a) 直接改 SVG 里的 `fill` / `stroke`** — 最简单，不碰 deck
**b) 在 deck `style:` 块里加一组覆盖规则** — 适合整份 deck 换风格
**c) 用 CSS 变量** — 最灵活，`<style>` 里定义 `--c-primary` 等，SVG 里 `fill="var(--c-primary)"`

大多数情况用 (a)。换风格意味着**全篇统一换**，不是一张图一个风格。

## 通用底线（6 套都适用）

- 纯色填充，**禁止渐变**（`<linearGradient>` / `<radialGradient>`）
- 禁止投影、斜面、3D（`filter` / `feDropShadow`）
- 一色族 + 一个强调色，色相 ≤ 3
- 字号只走 class，不写死 `font-size`
- 颜色不单独承担语义（见 [../craft/connectors.md](../craft/connectors.md)）
