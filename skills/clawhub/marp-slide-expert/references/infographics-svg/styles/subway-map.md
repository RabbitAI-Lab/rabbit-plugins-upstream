# subway-map

> 地铁线路图风格。多条彩色线路、站点圆点、**只用 45° 和 90° 转角**。地理被大幅简化，服务于「怎么走」而不是「在哪」。

## Token

```css
--c-bg:        #FFFFFF;
--c-line-1:    #E03A3E;   /* 线路色板，互不冲突、可色盲区分 */
--c-line-2:    #2563EB;
--c-line-3:    #0E9F6E;
--c-line-4:    #F59E0B;
--c-line-5:    #8B5CF6;
--c-line-6:    #EC4899;
--c-station:   #FFFFFF;   /* 站点圆点：白底 + 线色描边 */
--c-interchange:#1A1A1A;  /* 换乘站：深色大圆 */
--c-text:      #1A1A1A;
--c-muted:     #6B7280;
```

## 字阶

| class | 用途 | 特征 |
|---|---|---|
| `.t` | 标题 | 无衬线粗体 |
| `.tb` | 站名 | 无衬线中粗 |
| `.sm` | 线路名 badge | 无衬线常规，**反白压在色条上** |
| `.lbl` | 注脚 | 无衬线小字 |

## 形状语言

- **线路 `stroke-width="6"`**（主线路）或 `4`（支线）——线宽本身是层级信号
- **站点圆点** `r=7`，白底 + 线色描边 `stroke-width="3"`
- **换乘站** `r=11`，深色实心或白底双线描边
- **线路名 badge**：色条圆角矩形 + 白字，放在线路起点
- **转角只有 45° 和 90°** —— 这是地铁图的纪律，不要用曲线过渡
- 站名标签沿线方向水平或 45° 摆放

```html
<path d="M120,300 H400 L520,180 H800" fill="none" stroke="#E03A3E" stroke-width="6"/>
<circle cx="400" cy="300" r="7" fill="#FFFFFF" stroke="#E03A3E" stroke-width="3"/>
<circle cx="520" cy="180" r="11" fill="#1A1A1A"/>
<text x="416" y="330" class="sm" fill="#1A1A1A">人民广场</text>
<rect x="60" y="272" width="72" height="28" rx="6" fill="#E03A3E"/>
<text x="96" y="292" class="sm" fill="#ffffff" text-anchor="middle">1 号线</text>
```

## 硬性规则

**Do**
- 线路色必须**色盲友好且互相可辨**——不用红绿直接对立做两条关键线路
- 站点间距大致均匀，不严格按真实比例（地铁图不等比例）
- 线路交叉处不相交，用换乘站圆点明确连接
- 站名标签不压线

**Don't**
- 曲线、圆弧过渡——只有 45° 和 90°
- 按真实地理比例绘制
- 线路颜色超过 6 条——再多人就分不清了
- 线路交叉处直接叠画（会看出一条线突然变粗或断掉）

## 适合

路线图、流程路径、网络拓扑、多方案对比、多方并行推进的路径说明

## 配图建议

`lanes` 泳道（并行推进）、`linear-sequence` 箭头串（线性路径）、`network-hub`（拓扑关系）、`flow-cycle`（带分支的路线）
