# technical-schematic

> 工程精度与干净几何的技术图纸风格。深蓝底或白底网格，琥珀色高亮，尺寸标注。

## Token

```css
/* 变体 A：Blueprint 蓝图（深底） */
--c-bg:        #1E3A5F;   /* 深蓝底 */
--c-ink:       #FFFFFF;   /* 白线白字 */
--c-grid:      #2E4E75;   /* 网格线 */
--c-primary:   #60A5FA;   /* 亮蓝：主要线条 */
--c-accent:    #F59E0B;   /* 琥珀：高亮、关键部件 */

/* 变体 B：白底图纸 */
--c-bg:        #FFFFFF;
--c-ink:       #1E3A5F;   /* 深蓝线深蓝字 */
--c-grid:      #E2E8F0;
--c-primary:   #2563EB;
--c-accent:    #F59E0B;
--c-cyan:      #06B6D4;   /* 青色：批注 */
```

## 字阶

| class | 用途 | 特征 |
|---|---|---|
| `.t` | 标题 | 无衬线粗体，可全大写 |
| `.tb` | 部件名 | 无衬线中粗 |
| `.sm` | 标注、说明 | 无衬线小字 |
| `.dim` | 尺寸标注 | 等宽感，小字 + 灰色，两端带箭头 |

## 形状语言

- **网格**：用 `<pattern>` 画，间距 20 或 40，透明度 0.3。蓝图变体的网格是识别特征
- **尺寸标注线**：细线 + 两端小箭头 + 中间数值（`stroke-width="1" stroke="#94A3B8"`）
- **引出标注**：从部件拉一条折线到文字（`M x,y V 中继 H 文字x`）
- 等角 30° 或 45°（等轴测变体）
- **等宽线重**：同层级的线粗细一致，这是工程图的纪律

```html
<defs><pattern id="grid" width="40" height="40" patternUnits="userSpaceOnUse">
<path d="M40,0 L0,0 0,40" fill="none" stroke="#2E4E75" stroke-width="1"/></pattern></defs>
<rect x="0" y="0" width="1020" height="460" fill="url(#grid)" opacity="0.35"/>
```

## 变体

| 变体 | 底色 | 强调 |
|---|---|---|
| **Blueprint 蓝图** | 深蓝 + 白线 | 网格、尺寸标注、技术符号 |
| **Isometric 等轴测** | 白底 | 30° 角块、干净填充 |

## 硬性规则

**Do**
- 几何精确：所有坐标取整或半整，不用随手估的数
- 同层级线宽一致
- 关键部件用琥珀色标出，其余用蓝/白
- 尺寸标注齐备（工程图没有尺寸就不是工程图）

**Don't**
- 手绘感、圆润的有机曲线
- 阴影、渐变、拟物
- 装饰性图标
- 深底变体里用纯白大面积填充（会刺眼，用 10% 白）

## 适合

技术架构、系统设计、工程规格、产品拆解、数据流与部署拓扑、协议与接口图

## 配图建议

`hierarchy-tree` 分层（系统架构）、`flow-cycle`（数据管道）、`network-hub`（部署拓扑）、`structure-block`（组件清单）
