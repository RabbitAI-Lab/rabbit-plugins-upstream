## Known Risks and Mitigations: <br>
Risk: The skill can change GitHub repositories when connected credentials have write permissions. <br>
Mitigation: Use least-privilege GitHub access and preview and explicitly confirm every write operation before execution. <br>
Risk: The security review classified the skill as suspicious because it advertises broader file and command automation without strong upfront boundaries. <br>
Mitigation: Use the skill only for GitHub repository work and avoid treating it as general local file or shell automation. <br>
