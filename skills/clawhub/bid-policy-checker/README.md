# 政采政策红利自检助手（bid-policy-checker）

参与政府采购的投标人，在投标准备阶段自判能否享受政策红利、正确申报、避开虚假声明雷区的辅助工具。输出通俗易懂的资格判定与申报指引。

## 功能范围

- 中小企业认定（依 GB/T 4754-2017 行业划型）
- 货物类"双小"认定（企业是中小企业 + 货物由中小企业制造）
- 专门面向中小企业项目的投标资格
- 价格评审优惠（含财库〔2022〕19号时效性校验）
- 联合体 / 分包中的小微企业份额（≥30%）
- 特殊群体视同：监狱企业（财库〔2014〕68号）、残疾人福利企业（财库〔2017〕141号）
- 《中小企业声明函》填写指引 + 需附证明
- 虚假声明的法律后果红线

## 设计要点

- **资格自检 + 安全申报**：只做"能不能享、怎么申报"，不代写整本标书。
- **决策树驱动**：Mermaid 决策树 + CoT 步骤。
- **时效性校验**：扣除比例按招标文件执行文号核验，19 号已加码至 10%–20%（货物服务）/ 3%–5%（工程），旧版 6%–10% 触发预警。
- **优惠不叠加**：小微 + 残疾人仅取最优（财政部政策问答）。
- **双法分轨**：仅限政府采购法体系；依法必须招标工程仅边界告知并转介。
- **法条溯源**：挂载知识库 `7463496212028405`「政府采购实务与合规」。
- **降级策略**：KB 无命中 / 数据矛盾 / 解析失败均不臆造。
- **文档完整性预检**：仅上传需求/技术规格时，提示补充完整招标文件（投标人须知、资格要求、评标办法），避免把"需求书无条款"误读为"项目无政策"。
