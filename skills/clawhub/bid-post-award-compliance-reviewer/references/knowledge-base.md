## 2.1 核心法律法规

### 招投标法体系
- 《招标投标法》第46条：按招标文件和投标文件订立合同，不得背离实质性内容。
- 《招标投标法实施条例》第57条：合同标的 / 价款 / 质量 / 履行期限不得变更。
- 《招标投标法实施条例》第75条：中标人不按合同履约 → 取消中标 / 没收保证金 / 赔偿。
- 最高法建工司法解释（一）第2 / 22 / 23条：黑白合同 / 实质性变更认定。
- 《建筑法》第28 / 29条：禁止转包 / 分包限制。
- 《建设工程质量管理条例》第25 / 78条：转包 / 违法分包认定及处罚。

### 政府采购法体系
- 《政府采购法》第41条：采购人组织验收。
- 《政府采购法》第49条：补充合同累计 ≤ 原合同金额10%。
- 《政府采购法实施条例》第45条：验收书 / 签字 / 法律责任。
- 《政府采购法实施条例》第67条：超10% → 责令改正 / 警告 / 罚款。
- 财库〔2016〕205号：需求管理 + 履约验收。
- 26号令第22条：评标档案保存 ≥15年（**注**：指政府采购货物服务招投标管理办法，原条款为「采购文件保存≥15年」，引用时建议核实原文）。

### 工程管理与造价
- 《政府投资条例》（国务院令第712号）：概算控制 / 超概算处理。
- GB/T50500-2024（2025.9.1实施）：工程变更定义 / 签证制度取消（并入工程变更管理，监理仅参与技术审查）。
- 《建筑工程施工发包与承包违法行为认定查处管理办法》（建市规〔2019〕1号）：
  - 第5条（违法发包）/ 第7条（转包）/ 第8条（转包认定情形）/ 第11条（违法分包）/ 第12条（挂靠）。
- 《建设工程质量管理条例》第78条：转包 / 违法分包处罚。

### 合同与民事
- 《民法典》第502 / 509 / 543 / 544条：合同成立 / 履行 / 变更。
- 《民法典》第577 / 583 / 584 / 590条：违约 / 损害赔偿 / 不可抗力。

## 2.3 实质性变更认定标准

### 法定「实质性内容」四要素
| 要素 | 变更即实质性 | 正常变更（非实质性） |
|---|---|---|
| 工程范围 | 新增 / 取消整栋楼 / 整个标段 | 设计优化导致的局部调整 |
| 建设工期 | 无故延长 / 压缩总工期 | 因变更 / 不可抗力导致的合理顺延 |
| 工程质量 | 降低质量标准 / 验收标准 | 同等标准的材料替换 |
| 工程价款 | 改变计价方式 / 大幅调价 | 按合同约定的调价公式调整 |

### 最高法认定的「实质性变更」情形
- 另行签订与备案合同不一致的施工合同（黑白合同）
- 中标人以明显高于市场价购买承建房产
- 无偿建设住房配套设施
- 让利 / 向建设方捐款等承诺
- 改变计价方式（如固定总价 → 固定单价）

### 「正常合同变更」的合法条件（须同时满足）
1. 因设计变更 / 规划调整 / 地质条件等客观原因
2. 有书面文件（补充协议 / 会谈纪要 / 变更指令）
3. 不损害其他未中标人利益
4. 不改变中标结果的核心条件
5. 走了规定的审批程序（**先审批后变更再实施**）

## 2.4 工程变更「三原则」
| 原则 | 含义 | 审查要点 |
|---|---|---|
| 变更必审查 | 任何变更必须经过审查程序 | 是否有审查记录？审查人是否有权限？ |
| 非必要不变更 | 能不变就不变 | 变更理由是否充分？是否有替代方案？ |
| 变更经济性 | 变更方案应经济合理 | 是否选择了最经济的变更方案？ |

## 2.5 转包 / 分包 / 挂靠认定标准

### 转包认定（建市规〔2019〕1号 第7 / 8条）
典型识别信号：
- 施工现场中标承诺人员均不在场
- 现场管理人员非本公司人员（社保不在本单位）
- 施工单位不能提供现场管理人员的社保缴纳证明
- 主要建筑材料、构配件及工程设备由其他单位或个人采购
- 承包单位不履行合同约定的责任和义务
- 将全部工程肢解后以分包名义分别转给其他单位或个人

### 违法分包认定（第11条）
- 分包给不具备相应资质的单位
- 将主体结构、关键性工作分包
- 分包单位再次分包
- 未经建设单位认可的分包

### 挂靠（借用资质）认定（第12条）
- 无资质单位 / 个人借用有资质单位名义承揽工程
- 资质等级低的单位借用资质等级高的单位名义
- 「名义上的承包人」不实际参与施工管理
- 实际施工人与名义承包人之间无劳动关系 / 社保关系

### 违法发包认定（第5条）
- 发包给个人或不具有相应资质的单位
- 肢解发包
- 违反法定程序发包

## 2.6 关键人员履约标准
| 标准 | 要求 | 依据 |
|---|---|---|
| 月出勤率 | ≥80% | 各地履约管理办法 |
| 考勤方式 | 人脸识别等生物识别，数据不可篡改、实时上传 | 1358号文 / 各地细则 |
| 人员变更 | 须经发包人书面同意 | 合同 / 招投标法实施条例 |
| 替换人员资质 | 不低于原承诺人员 | 合同 / 招标文件 |
| 合法变更理由 | 因病 / 离职 / 工作调动等不可抗力 | 实务认定 |
| 非法变更理由 | 仅为便利或降低成本 | 实务认定 |
| 社保核查 | 现场管理人员须为本公司人员 | 转包认定办法 |
| 挂证识别 | 注册证书在本单位但人员长期不在岗 | 实务认定 |

## 2.8 两法分轨规则（铁律）
| 情形 | 适用法律 | 说明 |
|---|---|---|
| 政采货物 / 服务 | 政府采购法 | 追加10%红线 / 验收 / 资金支付 |
| 依法必须招标工程 | 招投标法 | 变更程序 / 实质性变更 / 黑白合同 |
| 政采工程招标 | 两法交叉 | 变更程序 → 招投标法；追加红线 → 政采法第49条 |
| 企业自筹 | 民法典为主 | 合同约定优先 |
