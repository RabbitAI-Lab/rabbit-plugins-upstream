## Description:

灵造 helps agents support cross-platform creator research and self-media operations through playbook routing, public-content lookup workflows, draft and publishing checks, review loops, and scoped creator image generation.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agent users use this skill to route creator-operation requests, prepare content strategy, draft and improve publishable materials, inspect public creator/content signals, and generate scoped visual assets when Lingzao API access is configured.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Online features send public links, prompts, selected reference images, and lookup requests to the configured Lingzao service.

Mitigation: Use a Lingzao-scoped API key, review the configured base URL during setup, and confirm before expanding searches, transcript extraction, profile depth, comment pages, image count, or external knowledge-tool syncing.

Risk: Creator research and workflow suggestions can be mistaken for guarantees about growth, monetization, platform approval, or content reuse.

Mitigation: Keep outputs framed as public-content research and workflow support, avoid promising outcomes, and review final publishable content before use.
